# Changelog

SciOxide crates share one version and are released together.
Breaking changes increment the minor version before 1.0; compatible additions and fixes increment the patch version.

## [Unreleased]

## [0.1.0]

Initial public release of the 19 SciOxide numerical computing crates.

- Shared scalar types, structured errors, tolerances, execution and workspaces.
- Dense and sparse linear algebra, geometry, special functions and polynomial methods.
- Fourier transforms, signal processing, probability, statistics and automatic differentiation.
- Interpolation, differentiation, root finding, integration, optimization and differential equations.
- Interval arithmetic and verified numerical methods.
- `std` and `no_std + alloc` support with no external normal or build dependencies.
- English and Japanese handbook with interactive Rust examples, published separately from the crate artifacts.

See the [README](https://github.com/kakune/scioxide#crates) for the crate catalog and the [handbook](https://kakune.github.io/scioxide/) for methods and examples.
