# Security

Security fixes target the latest released version.
Before 1.0, upgrading to a new minor version may require API changes.

Report vulnerabilities privately using [GitHub private vulnerability reporting](https://github.com/kakune/scioxide/security/advisories/new).
Include the affected version, a minimal reproduction and the impact.
Numerical accuracy bugs without a security impact can be reported as ordinary issues.
Do not include credentials or confidential data in a report.
