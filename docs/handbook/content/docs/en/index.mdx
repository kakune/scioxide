This book is a guide to using SciOxide, a numerical computing library in Rust.
It assumes basic Rust syntax and introductory calculus and linear algebra.

It explains the relationship between mathematical formulas and algorithms, how to handle rounding error, and how to check results, with executable examples.
You learn how to call the APIs you need and assess their numerical results.

---

## What you learn in this book

Each chapter explains the mathematics, APIs, reasons for choosing a computational method, and worked examples in that order.

1. **Mathematical foundations of numerical computing (Theoretical Foundations)** Starting from basic calculus and linear algebra, follow algorithm derivations and error analysis rigorously through mathematical formulas.
   Learn about bounds on forward and backward error, sensitivity expressed by the condition number $\kappa$, and the mechanisms through which rounding error accumulates.
2. **Using the public APIs** Learn about arguments, preconditions, return values, and error classifications.
   Each API shows how to perform a single computation and how to reuse settings, plans, and workspaces.
3. **Reasons for choosing computational methods** Learn how factorizations, pivot selection, preconditioning, and step size control affect accuracy and computational complexity.
   When repeatedly solving problems of the same form, also learn how to reuse workspaces.
4. **Concrete real-world applications (Real-World Applications)** Work through verifiable problems in physics and engineering, including celestial orbits and gravity assists, parameter identification in an infectious disease model (SEIR), bifurcation analysis of reaction–diffusion equations (Turing patterns), linear systems, and waves.

## Interactive execution and interpreting numerical accuracy

### Interactive execution in the browser (Oxiquill)

Many code cells in this book are interactive cells compiled to WebAssembly (`wasm32-unknown-unknown`) that run directly in the browser.

- **Changing parameters**: Adjust sliders and choices to observe how step sizes, initial values, tolerances, matrix sizes, and other parameters affect behavior dynamically.
- **Checking with charts and tables**: Convergence and error histories appear in dynamic charts and tables with Japanese labels.
- **Execution environment restrictions**: The browser's Wasm environment executes sequentially on a single thread.
  Thread-parallel dispatch (`ThreadExecutor`), the real-time clock (`StdClock`), and execution time limits are unavailable.
  Also, `usize` is 32 bits wide.
  In addition, proof computations in `scioxide-validated` check the execution environment for directed rounding and run only in native x86/x86_64/AArch64 environments, so the browser treats the proof portion as not executed.
  Any accompanying reference values are distinguished from verified results.

### Distinguishing estimates, guarantees, and uncertainty

This book strictly distinguishes the following categories when assessing numerical results.

- **Estimate**: An approximation based on local error estimation or a heuristic.
  It serves as a convergence indicator but does not guarantee a rigorous error bound.
- **Tested Accuracy Contract**: A ULP contract whose bound has been checked through unit tests and oracle verification, such as elementary functions (4 ULP) and stable transformations (16 ULP) in `scioxide-core`.
- **Statistical Uncertainty**: Standard errors (SE) and confidence intervals (CI) in Monte Carlo methods and sampling estimates.
- **Verified Enclosure**: An interval proved to contain the true mathematical solution through directed-rounding interval arithmetic in `scioxide-validated`.

## Mathematical notation and error handling conventions

- **Vectors and matrices**: Vectors use bold lowercase letters, $\mathbf{x} = (x_1, \dots, x_n)^\mathsf{T}$, and matrices use bold uppercase letters, $\mathbf{A} \in \mathbb{R}^{m \times n}$.
- **Norms and condition numbers**: The Euclidean norm is $\|\mathbf{x}\|_2 = \sqrt{\mathbf{x}^\mathsf{T} \mathbf{x}}$, a matrix norm is $\|\mathbf{A}\|$, and the condition number is $\kappa(\mathbf{A}) = \|\mathbf{A}\| \|\mathbf{A}^{-1}\|$.
- **Error handling**: Fallible numerical APIs in SciOxide mainly return `Result<T, SciOxideError>`.
  `SciOxideError` is a type that keeps its internal structure private.
  Determine the reason for an error through `kind()` (the 20 `SciOxideErrorKind` categories) and `view()` (`SciOxideErrorView`).

Start with the [first computation](getting-started/), solve a linear system, and check the result.
Return to the core concepts pages whenever you are unsure how to read errors or results.
Once you have a goal, choose the relevant chapter from the crate directory and check its API guide for specific calls.
