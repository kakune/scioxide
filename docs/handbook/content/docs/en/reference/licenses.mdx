## Code and tables in executable examples

The executable examples download Wasm modules containing SciOxide crates.
The [complete SciOxide notices and data attribution](../../../scioxide-licenses/NOTICE.txt) accompany those modules and include the applicable notices for libm, pocketfft, LAPACK, Hairer/Wanner DOP853 coefficients, quadrature tables, PRIMA/Basin, CUTEst/SIF and MINPACK inputs, Random123 vectors, Joe–Kuo direction numbers, PyWavelets, Cephes, Boost.Math, Faddeeva and mpmath adaptations.
These notices cover both the affected source material and the binary redistribution conditions of the corresponding libraries and tables.
The [Oxiquill runtime notices](../../../oxiquill/licenses/THIRD_PARTY_LICENSES.txt) separately cover the site framework and its bundled runtime dependencies.

## Numerical reference data

An offline reference tool and its numerical output are distinct materials.
Using MPFR, GSL, SciPy or another library to compute a reference value does not itself redistribute that library's source code.
Independently generated reference data use SciOxide's license; copied input definitions retain the conditions stated in the owning crate's notices.
The complete notices identify the scope of those exceptions and distinguish programming problems constructed for verification from downloaded benchmark data.

## Literature examples

The regression-quartet example uses four original 13-point datasets constructed by `scripts/generators/regression_quartet.py` in the SciOxide repository.
Its coordinate formulas, residual seeds and normalization are documented in the example.
The original code and manufactured data use MIT OR Apache-2.0.
Anscombe (1973) is credited for the statistical idea; his original table is not reproduced or transformed into these data.
The [generation and rights record](../../../scioxide-licenses/NOTICE.txt) explains this distinction and gives the reproduction commands.
This approach uses an original implementation of a statistical method, consistent with the distinction between methods and their expression in [U.S. Copyright Office Circular 33](https://www.copyright.gov/circs/circ33.pdf).

The remission-duration example identifies the numerical clinical observations reported by Freireich et al. (1963) and Gehan (1965).
Its comparison with the MASS `gehan` dataset does not incorporate R/MASS code or an R dataset file in this site.
The original publications remain the sources of the numerical facts; SciOxide does not claim exclusive rights over those observations or mathematical formulas.
The example code and explanations were created by the SciOxide project, and the pages cite their sources in both Japanese and English.

The basis for using the clinical values is their character as numerical facts, not permission inferred from a citation or from MASS.
The [data attribution](../../../scioxide-licenses/NOTICE.txt) identifies the source publication and distinguishes numerical facts from protected compilations.
