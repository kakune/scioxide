Use the first character of an identifier to navigate to each crate's purpose-specific API tables.
Names are ordered case-insensitively; re-exported items appear separately for each crate.
Items in `scioxide-core::backend` include their namespace to distinguish them.

## How to use the index

Check purpose and input conditions in the API table, then follow explanatory sections or executable examples.
Read workspace, options, and termination states together with the computation's entry point.
Do not treat incomplete results as success; distinguish verified enclosures, error estimates, and statistical uncertainty.
