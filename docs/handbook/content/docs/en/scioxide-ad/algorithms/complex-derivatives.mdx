Many computations have complex values, including AC-circuit phasors, quantum-mechanical probability amplitudes, and signal spectra.
The quantity to minimize in such computations is often real, such as power $|V|^2$ or a sum of squared residuals $\sum_k |r_k|^2$.
A nonconstant real-valued function is not holomorphic in a complex variable, so the complex-analytic derivative $f'(z)$ alone cannot express gradients of these quantities.

`scioxide-ad` has no numeric type specifically for complex numbers.
Represent complex numbers with `scioxide_core::Complex<R>`, using a numeric type such as `Dual`, `MultiDual`, `Jet`, or `Var` for the real and imaginary component type `R`.
Differentiation is with respect to the two real coordinates of real and imaginary parts (real-linear differentiation); for holomorphic functions, $f'(z)$ can be read from it.
This page uses the overbar $\bar z$ for complex conjugation.
[Forward mode and dual numbers](../forward-mode/) and [Reverse mode and tapes](../reverse-mode-and-replay/) explain numeric types and forward- and reverse-mode differentiation.

## Complex arithmetic and ComplexElementary

`Complex<R>` is a `#[repr(C)]` struct exposing the fields `re` and `im`.
`scioxide_core` defines sums, differences, products, negation, real scaling, and division by a real number (`Complex<R> * R`, `Complex<R> / R`) generically over the component type, so these work directly when `R` is a numeric type.
Multiplication computes $(a + ib)(c + id) = (ac - bd) + i(ad + bc)$ with component operations.
Complex division and inherent methods such as `conj`, `norm`, and `exp` are defined only for `RealScalar` components (`f32` and `f64`).

The `scioxide_ad::ComplexElementary` trait supplies elementary functions for complex numbers with numeric-type components.
It is implemented for every `Complex<R>` with `R: Real`, and function names match the inherent methods on `Complex<f64>`.
Each function uses `R` operations on real and imaginary parts, so differentiation in any mode differentiates these real and imaginary expressions.

| Method | Quantity computed | Real and imaginary expressions |
|---|---|---|
| `inv` | $1/z$ | Divide by the constant $m = \max(\lvert x\rvert , \lvert y\rvert )$ formed from base values before forming $\bar z/\lvert z\rvert ^2$, then divide by $m$ to avoid overflow |
| `exp` | $e^z$ | $e^x(\cos y + i \sin y)$ |
| `ln` | Principal logarithm | $\ln\lvert z\rvert + i \arg z$. Use $\tfrac12 \ln(1 + (x^2 + y^2 - 1))$ for $\tfrac12 \le \lvert z\rvert \le 2$ and $\ln \operatorname{hypot}(x, y)$ otherwise; as in `Complex<f64>::ln`, compute the value by summing products exactly |
| `sqrt` | Principal square root (nonnegative real part) | For $x \ge 0$, use $a = \sqrt{(\lvert z\rvert + x)/2}$ and $b = y/(2a)$. For $x < 0$ swap their roles, avoiding cancellation in either component |
| `sin`, `cos` | $\sin z$, $\cos z$ | $\sin x \cosh y + i \cos x \sinh y$, $\cos x \cosh y - i \sin x \sinh y$ |
| `norm` | $\lvert z\rvert $ | $\operatorname{hypot}(x, y)$ |
| `arg` | $\arg z \in [-\pi, \pi]$ | $\operatorname{atan2}(y, x)$ |

`norm` and `arg` return a real number of associated type `Part` (`= R`); the others return `Complex<R>`.
Write complex division as `z * w.inv()` and conjugation as `Complex::new(z.re, -z.im)`.
The trait does not include `tan`, hyperbolic functions, or powers; construct them, for example $\tan z$ as `z.sin() * z.cos().inv()`.

For `Complex<f64>`, writing `z.exp()` calls the inherent method in `scioxide_core` rather than the trait.
Inside a generic function the component type is not known to be `RealScalar`, so the trait method is selected.
To call the trait implementation for `Complex<f64>`, write `ComplexElementary::exp(z)`.

Since these expressions contain functions with kinks, tapes count encounters with kinks at the following points ([Kinks and nonfinite-value policies](../nonsmooth-and-nonfinite-policies/)).
`exp`, `sin`, and `cos` contain no functions with kinks.

- `norm` and `sqrt`: the origin (a kink of `hypot`).
- `ln` and `arg`: the origin and negative real axis $y = 0$, $x < 0$ (a kink of `atan2`; `ln` also counts `hypot` at the origin).

Since $m$ in `inv` is a constant formed from base values and is not differentiated, `inv` counts no kinks.
The result is mathematically independent of $m$, so the derivative remains $-1/z^2$.

## Differentiation in real coordinates

Regard the complex function $f(z) = u(x, y) + i\,v(x, y)$ as a map $(x, y) \mapsto (u, v)$ from $\mathbb{R}^2$ to $\mathbb{R}^2$.
If $u, v$ are real-differentiable, their differential is represented by the 2×2 real Jacobian

$$
J = \begin{pmatrix} u_x & u_y \\ v_x & v_y \end{pmatrix}, \qquad
\begin{pmatrix} \dot u \\ \dot v \end{pmatrix} = J \begin{pmatrix} \dot x \\ \dot y \end{pmatrix}
$$

where notation such as $u_x = \partial u/\partial x$ is used.
The Jacobian–vector product (JVP) for tangent $\dot z = \dot x + i\dot y$ multiplies by $J$ and is defined whether or not $f$ is holomorphic.

To obtain it with `scioxide-ad`, evaluate the function with numeric types for real and imaginary parts.
In forward mode, input `Complex::new(MultiDual::variable(x, 0)?, MultiDual::variable(y, 1)?)` gives $(u_x, u_y)$ in the output's `re.gradient()` and $(v_x, v_y)$ in `im.gradient()`.
In reverse mode, pass $(x, y)$ to the tape as two real inputs, construct `Complex::new(x[0], x[1])` inside the function, and append its real and imaginary parts to the output.
The caller chooses input and output ordering.
With `Complex<Jet<f64, N>>`, normalized Taylor coefficients of $f(z(t))$ along the line $z(t) = z_0 + t\,\delta z$ are obtained as pairs of real and imaginary parts ([Taylor jets and higher-order coefficients](../taylor-jets/)).

Reverse mode requires choosing an inner product.
The usual inner product when complex numbers are viewed as points in $\mathbb{R}^2$ is the real inner product $\langle a, b\rangle = \operatorname{Re}(\bar a\, b) = a_x b_x + a_y b_y$.
The vector–Jacobian product (VJP) for output cotangent $w$ is $J^{\mathsf T} w$, computed directly by the reverse sweep of a tape with components arranged in order.

## Cauchy–Riemann relations and Wirtinger derivatives

$f$ is complex-differentiable at $z$ exactly when $u, v$ are real-differentiable at $z$ and satisfy the Cauchy–Riemann relations $u_x = v_y$ and $u_y = -v_x$.
A function complex-differentiable at every point in a neighborhood of $z$ is called holomorphic at $z$.
If $f$ is complex-differentiable at $z$, write $f'(z) = a + ib$ ($a = u_x$, $b = v_x$); then

$$
J = \begin{pmatrix} a & -b \\ b & a \end{pmatrix}
$$

and $J\dot z$ equals the complex product $f'(z)\,\dot z$.
Thus the JVP result $(u_x, v_x)$ for seed $(\dot x, \dot y) = (1, 0)$ in direction $x$ can be read as $f'(z) = u_x + i v_x$.
The transpose $J^{\mathsf T}$ maps by multiplication with $\overline{f'(z)}$, so the VJP is $\overline{f'(z)}\,w$.

For nonholomorphic functions, $J$ does not have this form.
For conjugation $\bar z$, $J = \operatorname{diag}(1, -1)$; for $|z|^2 = x^2 + y^2$ (regarded as a complex number with zero imaginary part), $J = \begin{pmatrix} 2x & 2y \\ 0 & 0 \end{pmatrix}$.
Here $u_x + i v_x$ is only the directional derivative $\partial f/\partial x$ in direction $x$ and cannot be read as $f'(z)$.
JVPs and VJPs are real differentials and remain defined directly for either function.

The four entries of the real Jacobian carry the same information as the two complex Wirtinger derivatives

$$
\begin{aligned}
\frac{\partial f}{\partial z} &= \frac12\left(\frac{\partial f}{\partial x} - i\,\frac{\partial f}{\partial y}\right) = \frac{(u_x + v_y) + i\,(v_x - u_y)}{2}, \\
\frac{\partial f}{\partial \bar z} &= \frac12\left(\frac{\partial f}{\partial x} + i\,\frac{\partial f}{\partial y}\right) = \frac{(u_x - v_y) + i\,(v_x + u_y)}{2}
\end{aligned}
$$


The Cauchy–Riemann relations are equivalent to $\partial f/\partial \bar z = 0$, in which case $f'(z) = \partial f/\partial z$.
$|\partial f/\partial \bar z|$ measures deviation from holomorphicity and equals half the length of the Cauchy–Riemann residual $(u_x - v_y, u_y + v_x)$.

The JVP can be written as $\dot f = \frac{\partial f}{\partial z}\,\dot z + \frac{\partial f}{\partial \bar z}\,\overline{\dot z}$.
Finding $g$ for which the real-inner-product identity $\operatorname{Re}(\bar w\,\dot f) = \operatorname{Re}(\bar g\,\dot z)$ holds for every $\dot z$ gives the VJP

$$
g = \overline{\left(\frac{\partial f}{\partial z}\right)}\, w + \frac{\partial f}{\partial \bar z}\, \bar w
$$

whose second term vanishes for a holomorphic function, recovering $g = \overline{f'(z)}\,w$.

## Gradients of real-valued functions

For a real-valued function $L(z)$, reverse mode in `scioxide-ad` returns the real-coordinate gradient $(\partial L/\partial x, \partial L/\partial y)$.
There are two conventions for combining it into one complex number.

$$
g = \frac{\partial L}{\partial x} + i\,\frac{\partial L}{\partial y} = 2\,\frac{\partial L}{\partial \bar z}, \qquad
h = \bar g = \frac{\partial L}{\partial x} - i\,\frac{\partial L}{\partial y} = 2\,\frac{\partial L}{\partial z}
$$

Since $L$ is real, $\partial L/\partial \bar z = \overline{\partial L/\partial z}$, giving the equalities in both expressions.
The first-order change is $dL = \operatorname{Re}(\bar g\,dz) = \operatorname{Re}(h\,dz)$; $g$ points in the direction of fastest increase of $L$, so gradient descent is $z \leftarrow z - \alpha g$ ($\alpha > 0$).
$h$ is the conjugate of this direction and represents the same $dL$, but substituting $h$ for $g$ in the real inner product gives an incorrect value.
For multiple variables, set $g_k = \partial L/\partial x_k + i\,\partial L/\partial y_k$ componentwise, giving $dL = \operatorname{Re}(g^{\mathsf H} dz)$.

`scioxide-ad` provides neither functions returning complex gradients nor functions converting between these two conventions.
The caller constructs $g$ (or $h = \bar g$ if needed) from the two real reverse-mode results.

For example, for $L = |z|^2 = z\bar z$ we have $\partial L/\partial \bar z = z$, giving $g = 2z$, consistent with the real-coordinate gradient $(2x, 2y)$.
For the squared magnitude $L = |f(z)|^2 = f\bar f$ of the value of $f$, the product rule and $\partial \bar f/\partial \bar z = \overline{\partial f/\partial z}$ give

$$
g = 2\left( f\,\overline{\frac{\partial f}{\partial z}} + \bar f\,\frac{\partial f}{\partial \bar z} \right)
$$

which for holomorphic $f$ becomes $g = 2 f(z)\,\overline{f'(z)}$.

The next cell computes $J$ for the selected $f$ with forward-mode `MultiDual<f64, 2>` and compares Wirtinger derivatives with closed forms.
Closed-form references are computed independently with inherent methods on `Complex<f64>` from `scioxide_core` ($e^z$, $1/z$, $1/(2\sqrt z)$, $-1/z^2$, $\cos z$; $(\bar z, z)$ for $|z|^2$ and $(0, 1)$ for $\bar z$).
It also computes the gradient of $L = |f(z)|^2$ with reverse-mode `grad`, combines it into $g$, and compares it with $g$ constructed by the formula above from the forward-mode $J$ and values.
The inputs are the function and evaluation point $z = x + iy$.

//|       - {"artifact":"wirtinger","path":"/rows/2/5","approx":{"value":0,"atol":1e-14}}
use scioxide_ad::{ComplexElementary, MultiDual, Real, grad};
use scioxide_core::Complex;

// Write the selected f as a generic function supporting any numeric type for real and imaginary parts.
fn apply<R: Real>(name: &str, z: Complex<R>) -> Complex<R> {
    match name {
        "exp z" => z.exp(),
        "ln z" => z.ln(),
        "sqrt z" => z.sqrt(),
        "1/z" => z.inv(),
        "sin z" => z.sin(),
        "|z|²" => Complex::new(z.re * z.re + z.im * z.im, R::zero()),
        _ => Complex::new(z.re, -z.im),
    }
}

// Forward mode: compute both columns of J at once with seeds (1, 0) for the real part and (0, 1) for the imaginary part.
let x = MultiDual::<f64, 2>::variable(re_z, 0).map_err(|e| e.to_string())?;
let y = MultiDual::<f64, 2>::variable(im_z, 1).map_err(|e| e.to_string())?;
let w = apply(&function, Complex::new(x, y));
let ([ux, uy], [vx, vy]) = (w.re.gradient(), w.im.gradient());
let value = Complex::new(w.re.value(), w.im.value());
let f_z = Complex::new(0.5 * (ux + vy), 0.5 * (vx - uy));
let f_zbar = Complex::new(0.5 * (ux - vy), 0.5 * (vx + uy));

// Closed form (independent check): construct (∂f/∂z, ∂f/∂z̄) with inherent methods on Complex<f64> in scioxide_core.
let z = Complex::new(re_z, im_z);
let (zero, one) = (Complex::new(0.0, 0.0), Complex::new(1.0, 0.0));
let (reference_z, reference_zbar) = match function.as_str() {
    "exp z" => (z.exp(), zero),
    "ln z" => (z.inv(), zero),
    "sqrt z" => ((z.sqrt() * 2.0).inv(), zero),
    "1/z" => (-(z * z).inv(), zero),
    "sin z" => (z.cos(), zero),
    "|z|²" => (z.conj(), z),
    _ => (zero, one),
};

// Reverse mode: combine the real-coordinate gradient of L = |f(z)|² into g = ∂L/∂x + i ∂L/∂y.
let gradient = grad(
    |p| {
        let f = apply(&function, Complex::new(p[0], p[1]));
        Ok(f.re * f.re + f.im * f.im)
    },
    &[re_z, im_z],
)
.map_err(|e| e.to_string())?;
let g = Complex::new(gradient.as_slice()[0], gradient.as_slice()[1]);
// Construct g = 2 (f conj(∂f/∂z) + conj(f) ∂f/∂z̄) from the forward-mode J and values (manual calculation).
let expected = (value * f_z.conj() + value.conj() * f_zbar) * 2.0;

let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });

    { "key": "0", "label": "Component" },
    { "key": "1", "label": "Value [-]", "type": "number", "format": sig8 },
    { "key": "2", "label": "∂/∂x [-]", "type": "number", "format": sig8 },
    { "key": "3", "label": "∂/∂y [-]", "type": "number", "format": sig8 }
]);
let jacobian_rows = vec![
    ("u = Re f", value.re, ux, uy),
    ("v = Im f", value.im, vx, vy),
];
emit_table_with_columns!(
    jacobian_columns,
    jacobian_rows,
    metadata = serde_json::json!({ "id": "jacobian" })
);
let columns = serde_json::json!([
    { "key": "0", "label": "Quantity" },
    { "key": "1", "label": "Real part [-]", "type": "number", "format": sig8 },
    { "key": "2", "label": "Imaginary part [-]", "type": "number", "format": sig8 },
    { "key": "3", "label": "Reference real part [-]", "type": "number", "format": sig8 },
    { "key": "4", "label": "Reference imaginary part [-]", "type": "number", "format": sig8 },
    { "key": "5", "label": "Magnitude of difference [-]", "type": "number", "format": sci2 }
]);
let gap = |a: Complex<f64>, b: Complex<f64>| (a - b).norm();
let rows = vec![
    (
        "∂f/∂z",
        f_z.re,
        f_z.im,
        reference_z.re,
        reference_z.im,
        gap(f_z, reference_z),
    ),
    (
        "∂f/∂z̄",
        f_zbar.re,
        f_zbar.im,
        reference_zbar.re,
        reference_zbar.im,
        gap(f_zbar, reference_zbar),
    ),
    (
        "g (gradient of L = |f|²)",
        g.re,
        g.im,
        expected.re,
        expected.im,
        gap(g, expected),
    ),
];
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "wirtinger" })
);

At the defaults $f = e^z$ and $z = 0.5 + i$, $\partial f/\partial z = 0.89081 + 1.38735i$ agrees with the reference $e^z$ to a difference of $3.1 \times 10^{-16}$, and $\partial f/\partial \bar z$ is exactly zero.
Both columns of $J$ satisfy $u_x = v_y$ and $u_y = -v_x$ bit for bit.
The gradient of $L = |e^z|^2 = e^{2x}$ is $g = 5.43656 + 4.4 \times 10^{-16} i$: its real part equals $2e^{2x} = 2e$, and its imaginary part is a rounding remainder.

Even for $\sqrt z$ at $z = -1.5 + 0.25i$ near the negative real axis, $|\partial f/\partial \bar z|$ is $3.5 \times 10^{-18}$, and $\partial f/\partial z$ agrees with $1/(2\sqrt z)$ to a difference of $1.1 \times 10^{-16}$.
The `sqrt` expression avoids cancellation, so Cauchy–Riemann relations hold at the rounding level even near the cut.

For nonholomorphic $|z|^2$ ($z = 1.5 + 2i$), $\partial f/\partial z = \bar z = 1.5 - 2i$ and $\partial f/\partial \bar z = z = 1.5 + 2i$, leaving a deviation from holomorphicity of $|\partial f/\partial \bar z| = |z| = 2.5$.
Here the first column $(u_x, v_x) = (3, 0)$ of $J$ is $\partial f/\partial x$ rather than $f'$.
The gradient $g = 37.5 + 50i$ of $L = |f|^2 = |z|^4$ equals $2\,\partial L/\partial \bar z = 4|z|^2 z$ and agrees bit for bit with the value assembled from forward mode.
For $\bar z$, $\partial f/\partial z = 0$ and $\partial f/\partial \bar z = 1$, and the gradient of $L = |\bar z|^2$ is $g = 2z = 1 + 2i$.

## Principal branches and branch cuts

`ln` and `sqrt` return principal values and have branch cuts (curves where values are discontinuous) on the negative real axis.
Crossing the cut from above to below makes $\operatorname{Im} \ln z$ jump by $2\pi$ from $\pi$ to $-\pi$, and $\sqrt z$ change sign from $i\sqrt{|x|}$ to $-i\sqrt{|x|}$.
Derivatives are those of the selected branch.
The derivative $1/z$ of $\ln$ approaches the same value on both sides of the cut without a jump, whereas the derivative $1/(2\sqrt z)$ of $\sqrt z$ changes sign along with the value.
On the cut, neither branch's derivative describes a change crossing the cut.

For points on the cut with imaginary part $\pm 0$, the sign of imaginary zero determines the side.

- `ln` and `arg` follow $\operatorname{atan2}(\pm 0, x) = \pm\pi$ ($x < 0$), returning upper-side values for $+0$ and lower-side values for $-0$.
  The inherent `ln` on `Complex<f64>` does the same.
- `sqrt` selects the side from the imaginary part's sign bit, returning the upper value $i\sqrt{|x|}$ for $+0$ and lower value $-i\sqrt{|x|}$ for $-0$.
  The inherent `sqrt` on `Complex<f64>` does the same.

Since the imaginary part of `ln` uses `atan2`, the tape counts one kink on the cut, giving `DomainError` under `KinkPolicy::Error`.
The expression for `sqrt` selects its branch with `select`, so it counts no kink even on the cut.
Neither `ln` nor `sqrt` is differentiable at the origin; returned derivatives follow the expression conventions and are not values of $f'$.

// Compute (value real part, value imaginary part, f′ real part u_x, f′ imaginary part v_x) with forward mode.
let local = |y: f64, root: bool| -> Result<[f64; 4], String> {
    let x = MultiDual::<f64, 2>::variable(re_z, 0).map_err(|e| e.to_string())?;
    let y = MultiDual::<f64, 2>::variable(y, 1).map_err(|e| e.to_string())?;
    let z = Complex::new(x, y);
    let w = if root { z.sqrt() } else { z.ln() };
    Ok([
        w.re.value(),
        w.im.value(),
        w.re.gradient()[0],
        w.im.gradient()[0],
    ])
};

        values[index].push([y, im]);
        slopes[2 * index].push([y, re_slope]);
        slopes[2 * index + 1].push([y, im_slope]);
    }
}

    )

        |p| Ok(Complex::new(p[0], p[1]).ln().im),

        &mut gradient,

At the default $\operatorname{Re} z = -1$, $\operatorname{Im} \ln z$ jumps by $2\pi$ from near $\pi$ above the cut to near $-\pi$ below it.
Meanwhile the real part of $f'$ stays near $-1$, and its imaginary part varies smoothly through zero according to $\operatorname{Im}(1/z) = -y/(x^2 + y^2)$.
The imaginary part of $\sqrt z$ jumps from 1 to $-1$, and the imaginary part of $f'$ also jumps from $-0.5$ to $0.5$.
The table's $|z f' - 1|$ and $|2\sqrt z\, f' - 1|$ are at most $2.2 \times 10^{-19}$ at every point, including $\pm 0$, showing that the returned derivative is the derivative of the returned value's branch.

At $\pm 0$, the values of $\ln$ split into $\pi$ and $-\pi$; the tape counts one kink and the gradient with `KinkPolicy::Error` gives `DomainError`.
At points $10^{-3}$ away from the cut, no kink is counted.
At $-0$, both $\operatorname{Im} \sqrt z$ from `ComplexElementary` and the inherent method give $-1$ (the lower side), and $f'$ is also $0.5i$ from the lower branch.
At $\operatorname{Re} z = -0.25$ the origin is nearer, so the magnitude of $f'$ increases to $1/|z| = 4$ for $\ln$ and $1/(2\sqrt{|z|}) = 1$ for $\sqrt{}$.
At $\operatorname{Re} z = -2$, the jump $2\sqrt{|x|}$ of $\sqrt z$ becomes $2\sqrt 2$.

## Summary

Write complex computations with numeric types as components of `Complex<R>`, division as `z * w.inv()`, and elementary functions as methods of `ComplexElementary` to obtain real- and imaginary-part derivatives in every mode.
For holomorphic functions, the result $u_x + i v_x$ of seed $(1, 0)$ in direction $x$ can be read as $f'(z)$; for nonholomorphic functions it is only $\partial f/\partial x$, so check that $\partial f/\partial \bar z$ is zero before treating it as $f'$.
Assemble the gradient of a real-valued function as $g = \partial L/\partial x + i\,\partial L/\partial y = 2\,\partial L/\partial \bar z$ from the two real reverse-mode results, and update to $z - \alpha g$ for gradient descent.
When exchanging values with code using the $h = 2\,\partial L/\partial z$ convention, take the conjugate yourself.
`ln` and `arg` count kinks on the negative real axis and at the origin, so a tape with `KinkPolicy::Error` returns `DomainError` at these points.
On the cut with imaginary part $\pm 0$, both `ln` and `sqrt` select the side by the imaginary sign and return the same values as inherent methods on `Complex<f64>`.
