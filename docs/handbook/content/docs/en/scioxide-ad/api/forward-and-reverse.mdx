This table covers numeric types for writing functions and forward- and reverse-mode items for first derivatives.
Numeric-type operations return no errors and propagate NaN and infinity according to IEEE 754.
Transformations that receive points and write results return errors; failures leave caller-owned outputs unchanged.
One-shot functions create new tapes and allocate results; `Tape` methods write to caller-owned outputs and do not allocate on tapes that have recorded the same function.
Item-name links point to the version 0.1.0 API reference on docs.rs.

## Summary

Write a function once for `R: Real`; use `f64` or `Lanes` for values, `Dual` for one directional derivative, `MultiDual` for several, and a `Tape` recording `Var` for gradients.
One-shot `grad`, `value_and_grad`, `vjp`, `jacobian`, or `jvp` suffices for a single differentiation.
For many points of the same function, create one `Tape` and repeat `gradient_into` or `linearize`, checking recording size and rerecording with `TapeReport`.
Write tape closures directly at the call site and make functions deterministic.
