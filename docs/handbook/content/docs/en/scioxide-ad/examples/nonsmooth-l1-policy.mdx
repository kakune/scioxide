L1 regularization in Lasso regression and compressed sensing sets unnecessary coefficients to exactly 0.
This happens because the penalty term $|w|$ has a kink at the origin and no classical derivative there.
A convention determines what automatic differentiation returns at this point; using the gradient without knowing that convention can misclassify an optimal solution as nonoptimal.
This example compares `scioxide-ad`'s convention (the midpoint of one-sided derivatives) with the subdifferential, and examines the tape's kink-counting rules and their effect on judging Lasso solutions.

## Subdifferentials and optimality conditions

For a design matrix $A \in \mathbb{R}^{m \times n}$ and observations $\boldsymbol{b} \in \mathbb{R}^m$, the Lasso objective is

$$
F(\boldsymbol{w}) = g(\boldsymbol{w}) + \lambda \lVert \boldsymbol{w} \rVert_1, \qquad
g(\boldsymbol{w}) = \frac{1}{2} \lVert A\boldsymbol{w} - \boldsymbol{b} \rVert_2^2, \qquad
\lVert \boldsymbol{w} \rVert_1 = \sum_{j} |w_j|
$$

where $\lambda > 0$ is the regularization coefficient.
$g$ is a smooth convex function with gradient $\nabla g(\boldsymbol{w}) = A^\mathsf{T}(A\boldsymbol{w} - \boldsymbol{b})$.

The subdifferential $\partial f(\boldsymbol{w})$ of a convex function $f$ at $\boldsymbol{w}$ is the set of slopes $\boldsymbol{\xi}$ satisfying $f(\boldsymbol{v}) \ge f(\boldsymbol{w}) + \boldsymbol{\xi}^\mathsf{T}(\boldsymbol{v} - \boldsymbol{w})$ for every $\boldsymbol{v}$.
The subdifferential of $|w|$ is $\{-1\}$ for $w < 0$, the interval $[-1, 1]$ for $w = 0$, and $\{1\}$ for $w > 0$.
A convex function is minimized at $\boldsymbol{w}^*$ if and only if $\boldsymbol{0} \in \partial F(\boldsymbol{w}^*)$; for Lasso, the componentwise conditions are

$$
\frac{\partial g}{\partial w_j}(\boldsymbol{w}^*) = -\lambda \operatorname{sgn}(w^*_j) \quad (w^*_j \ne 0), \qquad
\left| \frac{\partial g}{\partial w_j}(\boldsymbol{w}^*) \right| \le \lambda \quad (w^*_j = 0)
$$


A coefficient is exactly 0 because its subdifferential interval $\partial_j g + \lambda[-1, 1]$ contains 0, rather than because one particular slope is 0.

For $m = n = 1$, $A = 1$, and $b = y$, this is the scalar problem $L(w) = \tfrac{1}{2}(w - y)^2 + \lambda|w|$, with $\partial L(0) = [-y - \lambda,\ -y + \lambda]$.
Solving the condition $0 \in \partial L(w^*)$ by cases gives

$$
w^* = S_\lambda(y) = \operatorname{sgn}(y) \max(|y| - \lambda,\ 0)
$$


$S_\lambda$ is called soft thresholding.

For a locally Lipschitz function that need not be convex, use the Clarke generalized gradient $\partial_C f(w)$.
This is the convex hull of limits of gradients along sequences of differentiable points approaching $w$; for convex functions, it equals the subdifferential.
For a scalar piecewise smooth function, define the one-sided derivatives by

$$
f'_{\pm}(w) = \lim_{h \to 0\pm} \frac{f(w + h) - f(w)}{h}
$$

and write $\partial_C f(w) = [\min(f'_-, f'_+),\ \max(f'_-, f'_+)]$.
At the origin of $|w|$, $f'_- = -1$ and $f'_+ = 1$, and the endpoints of $\partial L(0)$ are $L'_{\pm}(0) = -y \pm \lambda$.

## Kink conventions in scioxide-ad

Every numeric type in `scioxide-ad` (`Dual`, `MultiDual`, `Jet`, and the tape's `Var`) uses the midpoint of one-sided derivatives at kinks.
The principal function rules follow; the full table is in [Handling kinks and nonfinite values](../../algorithms/nonsmooth-and-nonfinite-policies/).

| Function | Derivative | Kink |
|---|---|---|
| `abs` | $\operatorname{sgn} x$, and 0 at 0 | $x = 0$ |
| `min`, `max` | 1 for the returned operand; $\tfrac{1}{2}$ each at a tie | $a = b$ |
| `floor`, `ceil`, `round`, `trunc`, `signum` | 0 | Jump points |

At a single kink, the midpoint $\tfrac{1}{2}(f'_- + f'_+)$ is the center of the interval $\partial_C f$.
It is 0 at the origin of $|w|$ and $-y$ at the origin of $L$; both belong to the subdifferential.
For a composite function, the chain rule combines each operation's midpoint, so the result need not equal the midpoint of the composite function's one-sided derivatives.

`select` and comparisons are not kinks.
The derivative of `R::select(mask, a, b)` is that of the selected operand, so even for the same ReLU, writing `max(w, 0)` gives $\tfrac{1}{2}$ at the origin, while `select(w > 0, w, 0)` gives the false branch's 0.

The tape counts an operation with an active argument (connected to the differentiation target) at a kink once per operation and lane (one SIMD element).
Operations whose arguments are all constants are not recorded and are not counted.
Kinks are detected by exact comparison of the innermost value (`base`); points very close to a kink, such as $w = 10^{-300}$, are not counted.
If an intermediate value is constant over an interval and lies at a later operation's kink, every point in that interval is counted.
In `max(max(w, 0), 0)`, the inner `max` returns 0 for $w < 0$, making both operands of the outer `max` equal to 0, so one kink is counted at every point with $w < 0$.
Read the count for the latest recording with `TapeReport::kinks()` (returned by `Tape::report()`).
Forward-mode types only apply the convention and do not store a count.

Select the tape policy with `TapeOptions::with_kink_policy`.
`KinkPolicy::Midpoint` (the default) uses midpoints and returns the count.
If the count is nonzero, `KinkPolicy::Error` returns `DomainError` (argument `point`, reason `Undefined`) at the transformation boundary.
Outputs such as the gradient remain unchanged in that case.
`Error` checks that evaluation at a kink is not overlooked; it does not select a different value at the kink.
On intervals with constant intermediate values, such as `max(max(w, 0), 0)` above, `Error` rejects the entire interval.

The following block defines the model shared by the three cells.
`misfit` implements $g(\boldsymbol{w})$ and `lasso` implements $F(\boldsymbol{w})$; the design matrix `design` is row-major $m \times n$, and observations `data` form an array of length $m$.
Both are written once for the numeric type `R: Real`, evaluating the same expression with `f64`, `Dual`, and the tape's `Var`.

```rust
//| id: ad-l1-lasso-model
//| kind: definitions
//| title: "Lasso data-fitting term and objective"
//| crates: [scioxide-ad]
use scioxide_ad::Real;

/// Data-fitting term g(w) = ½‖Aw − b‖². design is row-major m × n.
pub(crate) fn misfit<R: Real>(w: &[R], design: &[f64], data: &[f64]) -> R {
    let n = w.len();
    data.iter()
        .enumerate()
        .map(|(i, &b)| {
            let row = &design[i * n..(i + 1) * n];
            let residual = w
                .iter()
                .zip(row)
                .fold(R::constant(-b), |sum, (&wj, &aij)| sum + wj * aij);
            residual * residual * 0.5
        })
        .sum()
}

/// Objective F(w) = g(w) + λ‖w‖₁.
pub(crate) fn lasso<R: Real>(w: &[R], design: &[f64], data: &[f64], penalty: f64) -> R {
    misfit(w, design, data) + w.iter().map(|&wj| wj.abs()).sum::<R>() * penalty
}
```

`max(w, 0)` returns the midpoint $\tfrac{1}{2}$ of the one-sided values 0 and 1, and the tape counts one kink.
Writing the same ReLU as `select` selects the false branch at the origin, giving derivative 0 and counting no kink.
The one-sided difference quotients are 0 and 1, showing that the midpoint convention is not applied.
`max(max(w, 0), 0)` composes ReLU twice and is the same function as ReLU, but multiplies the midpoint $\tfrac{1}{2}$ twice to return $\tfrac{1}{4}$; the tape counts two kinks.
Midpoints combined by the chain rule do not equal the midpoint of the composite function's one-sided derivatives ($\tfrac{1}{2}$ here).
At $w = -0.5$, the other four functions count no kinks, but `max(max(w, 0), 0)` counts one tie in the outer `max`.
Although this function is constantly 0 for $w < 0$, the tape counts every point with $w < 0$ as lying on a kink, and `KinkPolicy::Error` makes the entire interval an error.
The derivative of $L$ is $-y = -1.2$, the midpoint of the one-sided difference quotients $-2$ and $-0.4$ (within $10^{-8}$ of the closed form $-y \mp \lambda$), at the center of the interval $\partial L(0)$.

The interval does not contain 0, so the solution lies away from the origin at $w^* = 0.4$.

Setting $\lambda = 2$ gives the interval $[-3.2, 0.8]$ containing 0 and the solution $w^* = 0$.
The midpoint value at the origin still equals $-1.2$ and is nonzero, yet the origin is a minimizer.
A single slope cannot determine optimality; check whether the entire interval contains 0.
With $y = -1.2$, the interval is $[0.4, 2]$ and the solution is $w^* = -0.4$, reflecting the table and graph about the origin.

## Proximal gradients and stopping criteria

$F$ is nondifferentiable wherever a coefficient is 0; directly using its midpoint gradient in gradient descent makes coefficients oscillate around 0 and rarely stop exactly at 0.
The proximal-gradient method (ISTA, iterative shrinkage-thresholding algorithm) applies a gradient step only to smooth $g$ and handles $\lambda\lVert \cdot \rVert_1$ with a proximal mapping.

$$
\boldsymbol{w}_{k+1} = S_{t\lambda}\bigl(\boldsymbol{w}_k - t\,\nabla g(\boldsymbol{w}_k)\bigr)
$$

Here $S_{t\lambda}$ is componentwise soft thresholding, equal to the proximal mapping $\arg\min_{\boldsymbol{u}} \bigl\{ t\lambda\lVert \boldsymbol{u} \rVert_1 + \tfrac{1}{2}\lVert \boldsymbol{u} - \boldsymbol{v} \rVert_2^2 \bigr\}$ of $t\lambda\lVert \cdot \rVert_1$.
Choose the step $t$ to satisfy $0 < t \le 1/L_g$ for the Lipschitz constant $L_g$ of $\nabla g$ (the largest eigenvalue of $A^\mathsf{T}A$).
Then $F(\boldsymbol{w}_k)$ decreases monotonically and $F(\boldsymbol{w}_k) - F^* \le \lVert \boldsymbol{w}_0 - \boldsymbol{w}^* \rVert_2^2 / (2tk)$ holds.
If $A^\mathsf{T}A$ is positive definite with smallest eigenvalue $\mu > 0$, then for $t = 1/L_g$, $\lVert \boldsymbol{w}_k - \boldsymbol{w}^* \rVert_2$ contracts by a factor of at most $1 - \mu/L_g$ each time.
Instead of computing eigenvalues, use the Gershgorin upper bound $\bar{L} = \max_j \sum_l |(A^\mathsf{T}A)_{jl}| \ge L_g$ and set $t = 1/\bar{L}$.
The contraction factor is then at most $1 - \mu/\bar{L}$.

Thresholding sets entries satisfying $|v_j| \le t\lambda$ to exactly 0.
If $|\partial_j g(\boldsymbol{w}^*)| < \lambda$ (strict complementarity) holds at the solution for every zero entry, then after finitely many iterations, the set of zero entries of $\boldsymbol{w}_k$ matches that of $\boldsymbol{w}^*$ and remains unchanged.
Consequently, the tape's kink count when evaluating $F$ also becomes constant after finitely many iterations.

Judge stopping by the distance between $\boldsymbol{0}$ and $\partial F(\boldsymbol{w})$, rather than by gradient magnitude.
This is the norm of the minimum-norm element $\boldsymbol{r}(\boldsymbol{w})$ of the subdifferential, whose components are

$$
r_j = \partial_j g + \lambda \operatorname{sgn}(w_j) \quad (w_j \ne 0), \qquad
r_j = \operatorname{sgn}(\partial_j g)\,\max\bigl(|\partial_j g| - \lambda,\ 0\bigr) \quad (w_j = 0)
$$


$\lVert \boldsymbol{r}(\boldsymbol{w}) \rVert_2 = 0$ is equivalent to the optimality condition $\boldsymbol{0} \in \partial F(\boldsymbol{w})$.
In contrast, differentiating $F$ on the tape gives $\partial_j g + \lambda \cdot 0 = \partial_j g$ in entries with $w_j = 0$ under the midpoint convention.
At a solution, these may take any value in $|\partial_j g| \le \lambda$, so this “gradient” generally has nonzero norm even at the solution.
A stopping rule based on the midpoint gradient magnitude fails to stop even after reaching the solution.

## Selecting absorption-spectrum lines

The application is analysis of a gas absorption spectrum.
Measure absorbance $b_i$ at wavenumber offsets $\nu_i = 2i$ cm⁻¹ ($i = 0, \dots, 39$, $m = 40$ points) and model it as a superposition of $n = 8$ candidate absorption lines from a database.
Line $j$ ($j = 0, \dots, 7$) is centered at $c_j = 5 + 10j$ cm⁻¹ and has a Gaussian shape with standard deviation $\sigma = 5$ cm⁻¹; set

$$
A_{ij} = \exp\!\left( -\frac{(\nu_i - c_j)^2}{2\sigma^2} \right)
$$


The coefficient $w_j$ is the dimensionless absorbance at the center of line $j$, and lines of components absent from the sample have coefficient 0.
The observations are the absorbance from true coefficients with only lines 1, 4, and 5 having absorbances 0.8, 0.5, and 0.3, plus a constant baseline 0.02 absent from the model.
L1 regularization discourages explaining the baseline with extra lines according to $\lambda$.
At $\boldsymbol{w} = \boldsymbol{0}$, $\nabla g(\boldsymbol{0}) = -A^\mathsf{T}\boldsymbol{b}$, so for $\lambda \ge \lambda_{\max} = \lVert A^\mathsf{T}\boldsymbol{b} \rVert_\infty$ the solution is $\boldsymbol{w}^* = \boldsymbol{0}$.

The following block defines the problem shared by two cells.
`spectrum` returns the design matrix $A$ (row-major $m \times n$) and observations $\boldsymbol{b}$; `TRUTH` contains the true coefficients, and `line_center` gives line centers $c_j$ [cm⁻¹].

```rust
//| id: ad-l1-spectrum
//| kind: definitions
//| title: "Absorption-spectrum design matrix and observations"
//| crates: [scioxide-core]
use scioxide_core::RealScalar;

/// Number of candidate lines n and measurement points m.
pub(crate) const LINES: usize = 8;
pub(crate) const SAMPLES: usize = 40;
/// True coefficients (absorbance at line centers).
pub(crate) const TRUTH: [f64; LINES] = [0.0, 0.8, 0.0, 0.0, 0.5, 0.3, 0.0, 0.0];

/// Center of line j: c_j = 5 + 10j [cm⁻¹].
pub(crate) fn line_center(j: usize) -> f64 {
    5.0 + 10.0 * j as f64
}

/// Design matrix A_ij = exp(−(ν_i − c_j)²/(2σ²)) (ν_i = 2i cm⁻¹, σ = 5 cm⁻¹), and
/// observations b including baseline 0.02.
pub(crate) fn spectrum() -> (Vec<f64>, Vec<f64>) {
    let design: Vec<f64> = (0..SAMPLES * LINES)
        .map(|e| {
            let offset = 2.0 * (e / LINES) as f64 - line_center(e % LINES);
            RealScalar::exp(-offset * offset / 50.0)
        })
        .collect();
    let data = (0..SAMPLES)
        .map(|i| {
            (0..LINES)
                .map(|j| design[i * LINES + j] * TRUTH[j])
                .sum::<f64>()
                + 0.02
        })
        .collect();
    (design, data)
}
```

At each iteration, it obtains $\nabla g$ with a default-policy tape's `gradient_into` and advances one step, then uses the same tape to obtain the midpoint gradient and kink count for $F$.
It stops at $\lVert \boldsymbol{r} \rVert_2 \le 10^{-12}$, with a limit of 5000 iterations.

```rust
//| title: "Solve Lasso with proximal gradients and compare the midpoint gradient with subdifferential optimality conditions"
//| run: reactive
//| uses: [ad-l1-lasso-model, ad-l1-spectrum]
//| crates: [scioxide-ad, scioxide-core]
//| exports: [penalty, solution, misfit_gradient, midpoint_gradient]
//| inputs:
//|   penalty: {"type":"range","label":"Regularization coefficient λ [-]","description":"Larger values give more zero coefficients. All are 0 when λ ≥ λ_max.","min":0.005,"max":4,"step":0.005,"value":0.3}
//| cases:
//|   - {"id":"weak-penalty","label":"λ = 0.01","description":"Absent lines receive small coefficients to explain the baseline. No entries are zero, and the midpoint gradient also approaches 0.","inputs":{"penalty":0.01}}
//|   - {"id":"strong-penalty","label":"λ = 2","description":"The weakest line 5 also becomes 0, giving 6 zero entries.","inputs":{"penalty":2}}
//|   - {"id":"above-lambda-max","label":"λ = 3.7","description":"Since λ ≥ λ_max, the origin is the solution and iteration stops at 0 steps.","inputs":{"penalty":3.7}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"iterations","path":"/rows/0/0","range":{"min":50,"max":80}}
//|       - {"artifact":"iterations","path":"/rows/0/1","equals":5}
//|       - {"artifact":"iterations","path":"/rows/0/2","equals":5}
//|       - {"artifact":"iterations","path":"/rows/0/3","range":{"max":1e-12}}
//|       - {"artifact":"iterations","path":"/rows/0/4","approx":{"value":0.3740103139083049,"rtol":1e-9}}
//|   - case: weak-penalty
//|     expect:
//|       - {"artifact":"iterations","path":"/rows/0/1","equals":0}
//|       - {"artifact":"iterations","path":"/rows/0/2","equals":0}
//|       - {"artifact":"iterations","path":"/rows/0/4","range":{"max":1e-12}}
//|   - case: strong-penalty
//|     expect:
//|       - {"artifact":"iterations","path":"/rows/0/1","equals":6}
//|       - {"artifact":"iterations","path":"/rows/0/2","equals":6}
//|   - case: above-lambda-max
//|     expect:
//|       - {"artifact":"iterations","path":"/rows/0/0","equals":0}
//|       - {"artifact":"iterations","path":"/rows/0/2","equals":8}
//|       - {"artifact":"iterations","path":"/rows/0/4","approx":{"value":5.683309372964972,"rtol":1e-12}}
//|       - {"artifact":"iterations","path":"/rows/0/5","equals":1}
use scioxide_ad::{Tape, TapeOptions};
use scioxide_core::ExecutionContext;

let (design, data) = spectrum();
let (m, n, lambda) = (SAMPLES, LINES, penalty);
// Determine the step t = 1/L̄ from the Gershgorin upper bound L̄ ≥ L_g (the largest eigenvalue of AᵀA).
let gram = |j: usize, l: usize| {
    (0..m)
        .map(|i| design[i * n + j] * design[i * n + l])
        .sum::<f64>()
};
let bound = (0..n)
    .map(|j| (0..n).map(|l| gram(j, l).abs()).sum::<f64>())
    .fold(0.0, f64::max);
let step = 1.0 / bound;
// Soft thresholding S_τ(v). Set eliminated entries to exactly +0.
let soft = |v: f64, tau: f64| {
    if v.abs() <= tau {
        0.0
    } else {
        v - tau * v.signum()
    }
};
// Distance ‖r(w)‖₂ between 0 and ∂F(w) (minimum-norm subgradient norm).
let distance = |w: &[f64], g: &[f64]| {
    (0..n)
        .map(|j| {
            if w[j] != 0.0 {
                g[j] + lambda * w[j].signum()
            } else {
                (g[j].abs() - lambda).max(0.0)
            }
        })
        .map(|r| r * r)
        .sum::<f64>()
        .sqrt()
};
let norm = |v: &[f64]| v.iter().map(|x| x * x).sum::<f64>().sqrt();

let cx = ExecutionContext::sequential();
let mut tape = Tape::<f64>::new(TapeOptions::new());
let (mut w, mut grad_g, mut grad_f) = (vec![0.0; n], vec![0.0; n], vec![0.0; n]);
let (mut distances, mut midpoints, mut counts, mut skipped) = (vec![], vec![], vec![], 0);
let mut iterations = 0;
loop {
    tape.gradient_into(|x| Ok(misfit(x, &design, &data)), &w, &mut grad_g, cx)
        .map_err(|e| e.to_string())?;
    // Midpoint gradient of F and kink count in its recording.
    tape.gradient_into(
        |x| Ok(lasso(x, &design, &data, lambda)),
        &w,
        &mut grad_f,
        cx,
    )
    .map_err(|e| e.to_string())?;
    let (k, residual) = (iterations as f64, distance(&w, &grad_g));
    if residual > 0.0 {
        distances.push([k, residual]);
    } else {
        skipped += 1;
    }
    midpoints.push([k, norm(&grad_f)]);
    counts.push([k, tape.report().kinks() as f64]);
    if residual <= 1e-12 || iterations == 5000 {
        break;
    }
    w = (0..n)
        .map(|j| soft(w[j] - step * grad_g[j], step * lambda))
        .collect();
    iterations += 1;
}
let zeros = w.iter().filter(|&&x| x == 0.0).count();
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let columns = serde_json::json!([
    { "key": "0", "label": "Iterations", "type": "integer" },
    { "key": "1", "label": "Zero entries", "type": "integer" },
    { "key": "2", "label": "Kink count kinks()", "type": "integer" },
    { "key": "3", "label": "‖r(w)‖₂ [-]", "type": "number", "format": sci3 },
    { "key": "4", "label": "Midpoint gradient norm [-]", "type": "number", "format": sci3 },
    { "key": "5", "label": "Points omitted for ‖r‖₂ = 0", "type": "integer" }
]);
emit_table_with_columns!(
    columns,
    vec![(
        iterations,
        zeros,
        tape.report().kinks(),
        distance(&w, &grad_g),
        norm(&grad_f),
        skipped
    )],
    metadata = serde_json::json!({ "id": "iterations" })
);
emit_line_chart!(
    &vec![
        serde_json::json!({ "name": "‖r(w_k)‖₂ (distance from 0 to ∂F)", "points": distances }),
        serde_json::json!({
            "name": "Midpoint gradient norm",
            "points": midpoints,
            "style": { "lineType": "dashed" }
        })
    ],
    options = &serde_json::json!({
        "link": { "group": "lasso-iteration" },
        "xLabel": "Iteration k",
        "yLabel": "Norm [-]",
        "yType": "log",
        "annotations": [{ "kind": "line", "axis": "y", "value": 1e-12, "label": "Stopping threshold" }]
    })
);
emit_line_chart!(
    &vec![serde_json::json!({
        "name": "Kink count in recording F",
        "points": counts,
        "style": { "step": "end" }
    })],
    options = &serde_json::json!({
        "link": { "group": "lasso-iteration" },
        "xLabel": "Iteration k",
        "yLabel": "Kinks [count]",
        "yMin": 0,
        "yMax": 8
    })
);
export!(penalty, lambda);
export!(solution, w);
export!(misfit_gradient, grad_g);
export!(midpoint_gradient, grad_f);
```

At the default $\lambda = 0.3$, ISTA reaches $\lVert \boldsymbol{r} \rVert_2 = 6.8 \times 10^{-13}$ after 62 iterations, with 5 of the 8 entries exactly 0.
In the upper graph, $\lVert \boldsymbol{r} \rVert_2$ decreases at a nearly constant ratio in later iterations (about 0.64 per step), while the dashed midpoint gradient norm levels off at 0.374.
A stopping rule based on midpoint gradient norm never stops for this problem.
In the lower graph, the kink count starts at 8 for $\boldsymbol{w}_0 = \boldsymbol{0}$, drops to 1 after the first step, then rises to 3 at $k = 3$ and 5 at $k = 7$, remaining unchanged thereafter.
Finite identification of the zero-entry set appears directly in the tape's count.

With $\lambda = 0.01$, no entries are zero and no kinks are counted; the midpoint gradient norm falls to $8 \times 10^{-13}$ along with $\lVert \boldsymbol{r} \rVert_2$.
With $\lambda = 2$, the weakest line 5 also becomes 0, and both the zero-entry and kink counts are 6.
With $\lambda = 3.7 \ge \lambda_{\max}$, $\lVert \boldsymbol{r} \rVert_2 = 0$ at the origin, so iteration stops at 0 steps and that point is omitted from the logarithmic axis.
The midpoint gradient is then $-A^\mathsf{T}\boldsymbol{b}$ with norm 5.68.

## Checking the solution and strict policy

The following cell receives $\lambda$, the solution, $\nabla g$, and the midpoint gradient from the previous cell, and checks three things.
First, it checks the solution by solving the same problem with coordinate descent (updating each entry in turn with $w_j \leftarrow S_\lambda(\boldsymbol{a}_j^\mathsf{T}\boldsymbol{\rho}_j)/\lVert \boldsymbol{a}_j \rVert_2^2$, where $\boldsymbol{a}_j$ is column $j$ of $A$ and $\boldsymbol{\rho}_j$ is the residual excluding column $j$'s contribution).
Second, it checks the tape's $\nabla g$ against a manually implemented $A^\mathsf{T}(A\boldsymbol{w} - \boldsymbol{b})$.
Both are independent computations without automatic differentiation.
Third, it differentiates $F$ at the solution on a `KinkPolicy::Error` tape and checks whether the gradient array retains its initial 7 after failure.

The first table shows each entry's true coefficient, ISTA solution, difference from coordinate descent, $\partial_j g$, midpoint gradient $\partial_j F$, minimum-norm subgradient $r_j$, and optimality-condition result.
The check is $|r_j| \le 10^{-9}$ for $w_j \ne 0$ and $|\partial_j g| \le \lambda$ for $w_j = 0$.
The second table shows $\lambda_{\max}$, the gradient-check difference, and the strict-policy result (`kind()`, the argument and reason from `view()`, and the maximum gradient-array value after the call).

```rust
//| id: ad-l1-lasso-check
//| ref: ad-l1-lasso-check
//| title: "Check the Lasso solution with coordinate descent and optimality conditions, and read strict-policy errors"
//| run: reactive
//| uses: [ad-l1-lasso-model, ad-l1-spectrum]
//| crates: [scioxide-ad, scioxide-core]
//| dependsOn:
//|   ista: ad-l1-lasso-ista
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"coefficients","path":"/rows/1/2","approx":{"value":0.7605669454984567,"rtol":1e-9}}
//|       - {"artifact":"coefficients","path":"/rows/1/3","range":{"max":1e-11}}
//|       - {"artifact":"coefficients","path":"/rows/4/3","range":{"max":1e-11}}
//|       - {"artifact":"coefficients","path":"/rows/0/2","equals":0}
//|       - {"artifact":"coefficients","path":"/rows/0/5","approx":{"value":-0.17533447761511534,"rtol":1e-9}}
//|       - {"artifact":"coefficients","path":"/rows/0/7","equals":"Satisfied"}
//|       - {"artifact":"coefficients","path":"/rows/5/7","equals":"Satisfied"}
//|       - {"artifact":"checks","path":"/rows/0/0","approx":{"value":3.670424650674448,"rtol":1e-12}}
//|       - {"artifact":"checks","path":"/rows/0/1","range":{"max":1e-14}}
//|       - {"artifact":"checks","path":"/rows/0/2","equals":"DomainError"}
//|       - {"artifact":"checks","path":"/rows/0/3","equals":"point"}
//|       - {"artifact":"checks","path":"/rows/0/4","equals":"Undefined"}
//|       - {"artifact":"checks","path":"/rows/0/5","equals":7}
use scioxide_ad::{KinkPolicy, Tape, TapeOptions};
use scioxide_core::{DomainReason, ExecutionContext, SciOxideErrorKind, SciOxideErrorView};

let read = |name: &str| -> Result<Vec<f64>, String> {
    let values = ista[name].as_array().ok_or("Missing array")?;
    values
        .iter()
        .map(|v| v.as_f64().ok_or_else(|| "Not a number".to_string()))
        .collect()
};
let lambda = ista["penalty"].as_f64().ok_or("Missing λ")?;
let (w, grad_g, grad_f) = (
    read("solution")?,
    read("misfit_gradient")?,
    read("midpoint_gradient")?,
);
let (design, data) = spectrum();
let (m, n) = (SAMPLES, LINES);
let column_dot = |j: usize, v: &[f64]| (0..m).map(|i| design[i * n + j] * v[i]).sum::<f64>();
let soft = |v: f64, tau: f64| (v.abs() - tau).max(0.0) * v.signum();

// Independent check 1: coordinate descent (manual f64 computation). rest is the residual b − Av.
let mut v = vec![0.0; n];
let mut rest = data.clone();
for _ in 0..10_000 {
    let mut change = 0.0_f64;
    for j in 0..n {
        let norm2: f64 = (0..m).map(|i| design[i * n + j].powi(2)).sum();
        let next = soft(column_dot(j, &rest) + norm2 * v[j], lambda) / norm2;
        (0..m).for_each(|i| rest[i] -= design[i * n + j] * (next - v[j]));
        change = change.max((next - v[j]).abs());
        v[j] = next;
    }
    if change == 0.0 {
        break;
    }
}
// Independent check 2: difference between manually implemented ∇g = Aᵀ(Aw − b) and the tape's ∇g.
let fitted: Vec<f64> = (0..m)
    .map(|i| (0..n).map(|j| design[i * n + j] * w[j]).sum::<f64>() - data[i])
    .collect();
let gradient_check = (0..n)
    .map(|j| (column_dot(j, &fitted) - grad_g[j]).abs())
    .fold(0.0, f64::max);
let rows: Vec<_> = (0..n)
    .map(|j| {
        // Minimum-norm subgradient r_j and componentwise optimality conditions.
        let (r, optimal) = if w[j] != 0.0 {
            let r = grad_g[j] + lambda * w[j].signum();
            (r, r.abs() <= 1e-9)
        } else {
            let r = (grad_g[j].abs() - lambda).max(0.0) * grad_g[j].signum();
            (r, grad_g[j].abs() <= lambda)
        };
        let verdict = if optimal {
            "Satisfied"
        } else {
            "Not satisfied"
        };
        let gap = (w[j] - v[j]).abs();
        (
            line_center(j),
            TRUTH[j],
            w[j],
            gap,
            grad_g[j],
            grad_f[j],
            r + 0.0,
            verdict,
        )
    })
    .collect();

// Differentiate F at the solution on a KinkPolicy::Error tape. Initialize the gradient array with 7.
let options = TapeOptions::new().with_kink_policy(KinkPolicy::Error);
let mut strict = Tape::<f64>::new(options);
let mut gradient = vec![7.0; n];
let outcome = strict.gradient_into(
    |x| Ok(lasso(x, &design, &data, lambda)),
    &w,
    &mut gradient,
    ExecutionContext::sequential(),
);
let (kind, argument, reason) = match &outcome {
    Ok(_) => ("Success", "-", "-"),
    Err(error) => {
        let kind = match error.kind() {
            SciOxideErrorKind::DomainError => "DomainError",
            _ => "Other",
        };
        match error.view() {
            SciOxideErrorView::DomainError {
                argument,
                reason: DomainReason::Undefined,
                ..
            } => (kind, argument.as_str(), "Undefined"),
            _ => (kind, "-", "-"),
        }
    }
};
let largest = gradient.iter().fold(f64::NEG_INFINITY, |a, &b| a.max(b));
let lambda_max = (0..n)
    .map(|j| column_dot(j, &data).abs())
    .fold(0.0, f64::max);

let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let fixed6 = serde_json::json!({ "significantDigits": 6 });
let coefficient_columns = serde_json::json!([
    {
        "key": "0",
        "label": "Line center c_j [cm⁻¹]",
        "type": "number",
        "format": { "fractionDigits": 0 }
    },
    { "key": "1", "label": "True coefficient [-]", "type": "number", "format": fixed6 },
    { "key": "2", "label": "ISTA solution w_j [-]", "type": "number", "format": fixed6 },
    { "key": "3", "label": "Difference from coordinate descent [-]", "type": "number", "format": sci3 },
    { "key": "4", "label": "∂g/∂w_j [-]", "type": "number", "format": fixed6 },
    { "key": "5", "label": "Midpoint gradient ∂F/∂w_j [-]", "type": "number", "format": fixed6 },
    { "key": "6", "label": "Subgradient r_j [-]", "type": "number", "format": sci3 },
    { "key": "7", "label": "Optimality condition" }
]);
emit_table_with_columns!(
    coefficient_columns,
    rows,
    metadata = serde_json::json!({ "id": "coefficients" })
);
let check_columns = serde_json::json!([
    { "key": "0", "label": "λ_max = ‖Aᵀb‖∞ [-]", "type": "number", "format": fixed6 },
    { "key": "1", "label": "∇g check difference [-]", "type": "number", "format": sci3 },
    { "key": "2", "label": "KinkPolicy::Error kind()" },
    { "key": "3", "label": "Argument" },
    { "key": "4", "label": "Reason" },
    {
        "key": "5",
        "label": "Maximum gradient-array value after call [-]",
        "type": "number",
        "format": fixed6
    }
]);
emit_table_with_columns!(
    check_columns,
    vec![(lambda_max, gradient_check, kind, argument, reason, largest)],
    metadata = serde_json::json!({ "id": "checks" })
);
```

At the default $\lambda = 0.3$, only the true lines 1, 4, and 5 have solution coefficients 0.7606, 0.4712, and 0.2712; the other 5 entries are exactly 0.
The nonzero coefficients are 0.029–0.039 below the true values, showing the shrinkage bias of L1 regularization.
Differences from the coordinate-descent solution are at most $1.7 \times 10^{-13}$, and the tape's $\nabla g$ agrees with the manually implemented $A^\mathsf{T}(A\boldsymbol{w} - \boldsymbol{b})$ to within $1.1 \times 10^{-16}$.
For zero entries, $\partial_j g$ ranges from $-0.192$ to $-0.101$ and all satisfy $|\partial_j g| < \lambda$, so strict complementarity holds.
The midpoint gradient equals $\partial_j g$ in these entries and is at most $10^{-12}$ in nonzero entries.
The `KinkPolicy::Error` tape rejects evaluation at the solution with `DomainError` (argument `point`, reason `Undefined`), leaving the gradient array at 7.
A Lasso solution with zero entries lies on kinks, so this policy cannot evaluate the solution.

Selecting $\lambda = 0.01$ in the previous cell assigns coefficients of 0.014–0.018 even to absent lines, using those lines to explain part of the 0.02 baseline.
With no zero entries, the strict-policy tape succeeds and writes the same values as the midpoint gradient into the gradient array.
With $\lambda = 3.7$, every entry is 0; the largest $|\partial_j g|$, attained at line 1, equals $\lambda_{\max} = 3.670$ and is below $\lambda$.

## Summary

`scioxide-ad` returns the midpoint of one-sided derivatives at a kink: 0 at the origin of $|w|$ and the center $-y$ of the subdifferential interval for the scalar Lasso objective.
The midpoint is just one point in the interval and need not be 0 at a solution; do not judge optimality or stopping by gradient magnitude.
Handle penalties in L1-regularized problems with proximal mappings, as in proximal-gradient methods, and judge stopping by the distance $\lVert \boldsymbol{r} \rVert_2$ between $\boldsymbol{0}$ and the subdifferential.
The tape's `TapeReport::kinks()` counts operations with active arguments exactly on kinks; at a Lasso solution it equals the number of zero coefficients, and on intervals with constant intermediate values, such as $w < 0$ for `max(max(w, 0), 0)`, it is positive at every point.
Branches written with `select` are not counted as kinks, so express kinks through functions such as `abs`, `max`, and `min` when using the count for checks.
`KinkPolicy::Error` rejects evaluations with positive counts using `DomainError` (argument `point`, reason `Undefined`) and leaves outputs unchanged; use it to check computations that should not encounter kinks.
