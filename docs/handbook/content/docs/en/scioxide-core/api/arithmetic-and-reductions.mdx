These tables collect arithmetic and reductions managing intermediate range and rounding.
`checked_*` functions accept only finite inputs.
Non-finite input returns `NonFinite`, division by zero `DomainError`, and unrepresentable final results `NumericalInstability` (`Overflow`).
“One rounding” means the mathematical value rounded to nearest, ties to even (0 ULP error).
Notation is $u = \varepsilon/2$ and $\gamma_k = ku/(1-ku)$, with $\eta$ the smallest positive subnormal.
These functions do not allocate on the heap except owned forms returning `Vec` results (`softmax`, `log_softmax`, `softmax_axis`, `log_softmax_axis`, `logsumexp_axis`, `weighted_logsumexp_axis`).

## Stable and batched transformations

Real versions have 16 ULP contracts except `log1mexp` (`sincpi` returns a correctly rounded value or its neighbor).
Complex errors are at most $32\varepsilon\, m\, g + 8\eta$ per result component.
Here $m$ is the larger absolute real/imaginary component of the exact value; $g$ is the row-specific coefficient ($g = 1$ when unspecified).
All except `log1mexp` accept real and complex inputs, rejecting non-finite input with `NonFinite`.
Evaluate arguments in `f64` and round once to output precision.

## Summary

`checked_*` functions return finite-input results with one rounding or within each row's error bounds.
Accumulate partial sums or dot products in `RangeAccumulator` or `ProductSum` and round finally with `finish`.
Use stable transformations for cancellation-prone expressions and `transform_into` for arrays.
For log-sums and normalization, choose `logsumexp` and `softmax` families for vectors or `_axis` families for array axes.
Inside iteration, use `_into` forms with caller-provided output and workspace.
