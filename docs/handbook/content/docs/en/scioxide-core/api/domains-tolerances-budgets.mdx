These tables collect three kinds of values the caller determines before computation: variable ranges, acceptance thresholds, and resource limits.
For many types, the threshold at scale $s \ge 0$ is $\tau(s) = \tau_{\mathrm{abs}} + \tau_{\mathrm{rel}} s$.
`IntegralityTolerance` has only an absolute term; `RelativeTolerance` only a relative term.
Limits use a separate type, `Budget` (positive integers), rather than tolerances.

## Summary

Use `Interval` for finite endpoints, `ExtendedInterval` for unbounded intervals, and `Bounds` for per-variable bounds.
Pass acceptance thresholds with tolerance types suited to the assessed quantity's role.
Represent iteration or evaluation limits through `Budget`, using `budget!` for constants and `Budget::try_from` for runtime values.
Tolerance predicates return `Ok(false)` for unmet thresholds, so treat `Err` as invalid input.
