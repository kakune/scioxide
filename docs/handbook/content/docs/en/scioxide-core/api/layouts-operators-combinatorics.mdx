These tables collect array layouts, operator protocols and application contexts, sparse structures, triangular storage, coloring, and integer combinatorics.
Layouts and views borrow shapes, strides, and element slices without owning elements (only `row_major` layouts store strides internally).
Operators report required workspace lengths beforehand and write into caller storage.

## Summary

Construct unpadded row-major layouts with `row_major` and others with `StridedLayout::new`, passing arrays through `NdView` or `NdViewMut`.
Supply operators as trait implementations or `ClosureOperator`, preparing workspace lengths returned by `apply_workspace_len` and similar methods.
Validate sparse structures with `StructuralPatternView` and colorings with `ColoringSchedule::new` before use.
Combinatorial functions return `SizeOverflow` when results exceed the integer type, never wrapped values.
