Predissolving another salt sharing an ion with a sparingly soluble salt shifts dissolution equilibrium toward precipitation and reduces solubility.
This is the common-ion effect.
Solubility is the positive quadratic root and decreases as common-ion concentration increases.
The direct quadratic formula subtracts nearby values in this small root, losing significant digits.
This example obtains roots through `checked_quadratic_roots` and assesses their residual contract with `Tolerance`.

## Dissolution equilibrium and the quadratic equation

For dissolution equilibrium of a 1:1 sparingly soluble salt MX,

$$
\mathrm{MX(s)} \rightleftharpoons \mathrm{M^+(aq)} + \mathrm{X^-(aq)}
$$

the saturated solution's ion concentration product equals solubility product $K_{\mathrm{sp}} = [\mathrm{M^+}][\mathrm{X^-}]$.
Saturating MX in a solution containing common ion $\mathrm{X^-}$ at concentration $c$ [mol/L], with solubility $s$ [mol/L], gives $[\mathrm{M^+}] = s$ and $[\mathrm{X^-}] = s + c$, hence

$$
s(s + c) = K_{\mathrm{sp}} \quad \Longleftrightarrow \quad s^2 + c\,s - K_{\mathrm{sp}} = 0
$$


Assume activity coefficients of 1, neglecting complexes such as $\mathrm{AgI_2^-}$ and ion pairing.
At real concentrations where these cannot be neglected, side-reaction equilibria must be solved together.

| Salt | $K_{\mathrm{sp}}$（25 °C）[mol²/L²] | Pure-water solubility $\sqrt{K_{\mathrm{sp}}}$ [mol/L] |
|---|---|---|
| AgCl | $1.77 \times 10^{-10}$ | $1.33 \times 10^{-5}$ |
| AgBr | $5.35 \times 10^{-13}$ | $7.31 \times 10^{-7}$ |
| AgI | $8.52 \times 10^{-17}$ | $9.23 \times 10^{-9}$ |
| BaSO₄ | $1.08 \times 10^{-10}$ | $1.04 \times 10^{-5}$ |

Tabulated $K_{\mathrm{sp}}$ values are representative at 25 °C and vary slightly between references.

## Cancellation in the quadratic formula

The direct formula for the positive root is

$$
s = \frac{-c + \sqrt{c^2 + 4K_{\mathrm{sp}}}}{2}
$$


Dissolving AgI at $c = 1$ mol/L gives $c^2 + 4K_{\mathrm{sp}} = 1 + 3.408 \times 10^{-16}$, whose difference from 1 is only comparable to spacing in double precision $\varepsilon \approx 2.22 \times 10^{-16}$ near 1.
It rounds to $1 + 2\varepsilon$, with square root $1 + \varepsilon$ and result $\varepsilon / 2 \approx 1.11 \times 10^{-16}$.
The correct solubility is about $K_{\mathrm{sp}} / c = 8.52 \times 10^{-17}$ mol/L (approximately $5 \times 10^{7}$ silver ions per liter), giving about 30% error.
When $4K_{\mathrm{sp}}$ falls below half the spacing near $c^2$, $c^2 + 4K_{\mathrm{sp}}$ rounds to $c^2$ and the result becomes zero.

Rationalizing the numerator gives

$$
s = \frac{2K_{\mathrm{sp}}}{c + \sqrt{c^2 + 4K_{\mathrm{sp}}}}
$$

This expression involves only positive additions without cancellation; use it as an independent reference.
Only a few roundings occur in addition, square root, and division, giving reference relative error within a few $\varepsilon$.
For $4K_{\mathrm{sp}} \ll c^2$, expansion $s = K_{\mathrm{sp}}/c - K_{\mathrm{sp}}^2/c^3 + 2K_{\mathrm{sp}}^3/c^5 - \cdots$ gives $s \approx K_{\mathrm{sp}}/c$.

The following block defines helpers shared by two cells.
`solubility_product` returns tabulated $K_{\mathrm{sp}}$; `formula_root` implements the direct formula, and `rationalized_root` the rationalized formula.
The latter two are comparison and checking formulas using `f64` arithmetic and standard functions.

```rust
//| id: core-common-ion-model
//| kind: definitions
//| title: "Solubility products and two comparison formulas"
//| crates: [scioxide-core]
/// Solubility product K_sp at 25 °C [mol²/L²].
pub(crate) fn solubility_product(salt: &str) -> f64 {
    match salt {
        "AgCl" => 1.77e-10,
        "AgBr" => 5.35e-13,
        "BaSO4" => 1.08e-10,
        _ => 8.52e-17,
    }
}

/// Quadratic formula s = (−c + √(c² + 4K))/2, for comparison using intrinsic f64 methods.
pub(crate) fn formula_root(c: f64, k_sp: f64) -> f64 {
    (-c + (c * c + 4.0 * k_sp).sqrt()) / 2.0
}

/// Rationalized s = 2K/(c + √(c² + 4K)), an independent reference using intrinsic f64 methods.
pub(crate) fn rationalized_root(c: f64, k_sp: f64) -> f64 {
    2.0 * k_sp / (c + (c * c + 4.0 * k_sp).sqrt())
}
```

## Root residual contracts

`checked_quadratic_roots(a, b, c)` computes the larger-magnitude real root with cancellation-free formula $q/a$, then the other from $c/q$ ([Exact accumulation and range-safe arithmetic](oxref:core-quadratic-roots)).
It returns array `[Complex<S>; 2]` with real roots ascending.
Here the root product is $-K_{\mathrm{sp}} < 0$, so the first root is negative and the second positive solubility.

Near repeated roots, the condition number

$$
\kappa(x) = \frac{|a| x^2 + |b|\,|x| + |c|}{|x|\,|2ax + b|}
$$

becomes very large; instead of forward accuracy in ULP, residuals are guaranteed.
For real root $x$, define $T = |a| x^2 + |b| |x| + |c|$; then

$$
|a x^2 + b x + c| \le 32\,\varepsilon\, T + (2|a||x| + |b|)\,\eta + |a|\,\eta^2
$$


Here $\eta \approx 4.9 \times 10^{-324}$ is the smallest positive subnormal.
At these scales, the $\eta$ term is negligible; construct `Tolerance::new(0, 32ε)` and test $|f(s)| \le 32\varepsilon T$ through `is_residual_ok(residual, T)`.
Compute residuals exactly through `checked_sum_of_products` and round once.

For this problem's positive root, $2s + c > 0$ and $\kappa(s) = (s^2 + cs + K_{\mathrm{sp}})/(s(2s + c)) \le 2$.
Using $s^2 + cs = K_{\mathrm{sp}}$ in the numerator gives $\kappa(s) = 2(s + c)/(2s + c)$.
The problem is well-conditioned, so its residual bound also gives first-order relative error in $s$ at most $32\varepsilon\,\kappa(s) \le 64\varepsilon$.

## Computing solubility

For the selected salt and common-ion concentration $c$, compute $s$ using the direct formula, `checked_quadratic_roots`, and the rationalized formula, checking the residual contract.
Inputs are salt and $\log_{10}(c / (\mathrm{mol/L}))$ ($-8$–0 in steps of 0.5).
The first table shows all three solubilities and relative differences from the rationalized reference.
The second shows the negative root, positive-root residual, bound $32\varepsilon T$, and `is_residual_ok` decision.

```rust
//| id: core-common-ion-solubility
//| ref: core-common-ion-solubility
//| title: "Solubility in a solution containing a common ion"
//| run: reactive
//| crates: [scioxide-core]
//| uses: [core-common-ion-model]
//| inputs:
//|   salt: {"type":"select","label":"Sparingly soluble salt","options":["AgCl","AgBr","AgI","BaSO4"],"value":"AgI"}
//|   log_c: {"type":"range","label":"Common-ion concentration log₁₀(c / (mol/L)) [-]","description":"−8 means 10 nmol/L; 0 means 1 mol/L.","min":-8,"max":0,"step":0.5,"value":0}
//| cases:
//|   - {"id":"no-common-ion","label":"AgCl, c = 10 nmol/L","description":"The common-ion effect is negligible; solubility approaches its pure-water value.","inputs":{"salt":"AgCl","log_c":-8}}
//|   - {"id":"barium-sulfate","label":"BaSO₄, c = 10 mmol/L","description":"The common ion reduces solubility by three orders of magnitude.","inputs":{"salt":"BaSO4","log_c":-2}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"solubility","path":"/rows/0/1","approx":{"value":8.52e-17,"rtol":1e-12}}
//|       - {"artifact":"solubility","path":"/rows/1/2","approx":{"value":0.303,"atol":0.005}}
//|       - {"artifact":"solubility","path":"/rows/2/2","range":{"min":0,"max":1e-15}}
//|       - {"artifact":"residual","path":"/rows/0/3","equals":"Within bound"}
//|   - case: no-common-ion
//|     expect:
//|       - {"artifact":"solubility","path":"/rows/2/1","approx":{"value":1.3299e-5,"rtol":1e-3}}
//|       - {"artifact":"solubility","path":"/rows/2/2","range":{"min":0,"max":1e-15}}
//|       - {"artifact":"residual","path":"/rows/0/3","equals":"Within bound"}
//|   - case: barium-sulfate
//|     expect:
//|       - {"artifact":"solubility","path":"/rows/2/1","approx":{"value":1.08e-8,"rtol":1e-5}}
//|       - {"artifact":"solubility","path":"/rows/2/2","range":{"min":0,"max":1e-15}}
//|       - {"artifact":"residual","path":"/rows/0/3","equals":"Within bound"}
use scioxide_core::{RealScalar, Tolerance, checked_quadratic_roots, checked_sum_of_products};

let k_sp = solubility_product(salt.as_str());
let c = RealScalar::powf(10.0_f64, log_c);
let naive = formula_root(c, k_sp);
let reference = rationalized_root(c, k_sp);

// Roots of s² + c s − K_sp = 0 ascend, so the second is positive solubility.
let [negative, positive] = checked_quadratic_roots(1.0, c, -k_sp).map_err(|e| e.to_string())?;
let s = positive.re;
let relative = |value: f64| (value - reference).abs() / reference;
let digits = serde_json::json!({ "notation": "scientific", "significantDigits": 11 });
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let solubility_columns = serde_json::json!([
    { "key": "0", "label": "Method" },
    { "key": "1", "label": "Solubility s [mol/L]", "type": "number", "format": digits },
    {
        "key": "2",
        "label": "Relative reference difference [-]",
        "type": "number",
        "format": sci3,
        "nullText": "Reference"
    }
]);
emit_table_with_columns!(
    solubility_columns,
    vec![
        ("Rationalized formula (reference)", reference, None),
        ("Quadratic formula", naive, Some(relative(naive))),
        ("checked_quadratic_roots", s, Some(relative(s))),
    ],
    metadata = serde_json::json!({ "id": "solubility" })
);

// Compute residual s² + c s − K_sp exactly and test |f(s)| ≤ 32 ε T.
let residual =
    checked_sum_of_products(&[s, s, -k_sp], &[s, c, 1.0]).map_err(|e| e.to_string())?;
let scale = s * s + c * s + k_sp;
let contract = Tolerance::new(0.0, 32.0 * f64::EPSILON).map_err(|e| e.to_string())?;
let within = contract
    .is_residual_ok(residual.abs(), scale)
    .map_err(|e| e.to_string())?;
let residual_columns = serde_json::json!([
    { "key": "0", "label": "Negative root [mol/L]", "type": "number", "format": digits },
    { "key": "1", "label": "Residual s² + c s − K_sp [mol²/L²]", "type": "number", "format": sci3 },
    { "key": "2", "label": "Bound 32 ε T [mol²/L²]", "type": "number", "format": sci3 },
    { "key": "3", "label": "is_residual_ok(|residual|, T)" }
]);
emit_table_with_columns!(
    residual_columns,
    vec![(
        negative.re,
        residual,
        32.0 * f64::EPSILON * scale,
        if within { "Within bound" } else { "Outside bound" },
    )],
    metadata = serde_json::json!({ "id": "residual" })
);
```

For default AgI at $c = 1$ mol/L, the direct formula gives $1.11 \times 10^{-16}$ mol/L, 30% from reference.
The positive root from `checked_quadratic_roots` is $8.52 \times 10^{-17}$ mol/L, with zero reference difference.
Residual $7.3 \times 10^{-33}$ lies within bound $1.2 \times 10^{-30}$, and `is_residual_ok` accepts it.
The negative root is $-1$ mol/L and has no concentration interpretation.

For AgCl with $c$ reduced to $10^{-8}$ mol/L, the common-ion effect vanishes; solubility $1.3299 \times 10^{-5}$ mol/L approaches the pure-water $\sqrt{K_{\mathrm{sp}}} = 1.3304 \times 10^{-5}$ mol/L.
Both roots then have nearly equal magnitudes, and the direct formula has no cancellation.
For BaSO₄ at $c = 10^{-2}$ mol/L, solubility falls three orders from pure-water $1.04 \times 10^{-5}$ to $1.08 \times 10^{-8}$ mol/L, with direct-formula relative difference $9 \times 10^{-12}$.

## Error variation with common-ion concentration

Vary $c$ over 65 logarithmically spaced points from $10^{-8}$ to $1$ mol/L, plotting relative errors of the direct formula and `checked_quadratic_roots` on logarithmic axes.
The only input is salt.
A horizontal line marks machine epsilon $\varepsilon$.
Omit exact-zero relative errors from logarithmic series; tabulate their counts and maximum relative errors over all 65 points.

```rust
//| id: core-common-ion-error-sweep
//| ref: core-common-ion-error-sweep
//| title: "Common-ion concentration and relative solubility errors"
//| run: reactive
//| crates: [scioxide-core]
//| uses: [core-common-ion-model]
//| inputs:
//|   salt: {"type":"select","label":"Sparingly soluble salt","options":["AgCl","AgBr","AgI","BaSO4"],"value":"AgI"}
//| cases:
//|   - {"id":"silver-chloride","label":"AgCl","description":"Larger K_sp keeps quadratic-formula error from growing beyond about 10⁻⁷.","inputs":{"salt":"AgCl"}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"errors","path":"/rows/0/2","range":{"min":0.1,"max":1}}
//|       - {"artifact":"errors","path":"/rows/1/2","range":{"min":0,"max":1e-15}}
//|   - case: silver-chloride
//|     expect:
//|       - {"artifact":"errors","path":"/rows/0/2","range":{"min":1e-8,"max":1e-5}}
//|       - {"artifact":"errors","path":"/rows/1/2","range":{"min":0,"max":1e-15}}
use scioxide_core::{RealScalar, checked_quadratic_roots};

let k_sp = solubility_product(salt.as_str());
let mut curves = [Vec::new(), Vec::new()];
let mut zeros = [0_u32; 2];
let mut worst = [0.0_f64; 2];
for step in 0..=64 {
    let c = RealScalar::powf(10.0_f64, -8.0 + 8.0 * step as f64 / 64.0);
    let reference = rationalized_root(c, k_sp);
    let [_, positive] = checked_quadratic_roots(1.0, c, -k_sp).map_err(|e| e.to_string())?;
    // Index 0 is the quadratic formula; 1 is checked_quadratic_roots.
    for (method, value) in [formula_root(c, k_sp), positive.re].into_iter().enumerate() {
        let error = (value - reference).abs() / reference;
        worst[method] = RealScalar::max(worst[method], error);
        if error > 0.0 {
            curves[method].push([c, error]);
        } else {
            zeros[method] += 1;
        }
    }
}
emit_line_chart!(
    &vec![
        serde_json::json!({ "name": "Quadratic formula", "points": curves[0] }),
        serde_json::json!({ "name": "checked_quadratic_roots", "points": curves[1] }),
    ],
    options = &serde_json::json!({
        "xLabel": "Common-ion concentration c [mol/L]",
        "yLabel": "Relative error from reference [-]",
        "xType": "log",
        "yType": "log",
        "annotations": [{ "kind": "line", "axis": "y", "value": f64::EPSILON, "label": "ε" }]
    })
);
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let columns = serde_json::json!([
    { "key": "0", "label": "Method" },
    { "key": "1", "label": "Zero relative errors (among 65 points) [count]", "type": "integer" },
    { "key": "2", "label": "Maximum relative error [-]", "type": "number", "format": sci3 }
]);
emit_table_with_columns!(
    columns,
    vec![
        ("Quadratic formula", zeros[0], worst[0]),
        ("checked_quadratic_roots", zeros[1], worst[1]),
    ],
    metadata = serde_json::json!({ "id": "errors" })
);
```

For AgI, direct-formula relative error grows approximately with $\varepsilon\, c^2 / K_{\mathrm{sp}}$ as $c$ increases, reaching its maximum 0.30 at $c = 1$ mol/L.
This agrees with the estimate of order-one error around $c \approx \sqrt{K_{\mathrm{sp}}/\varepsilon} \approx 0.6$ mol/L.
`checked_quadratic_roots` matches the reference at 63 of 65 points (zero-error points are absent from the series); the remaining two errors are at most $2.1 \times 10^{-16}$, below $\varepsilon$.
Other salts also match at least 63 points, with maximum relative error at most $3 \times 10^{-16}$.
Agreement counts may vary by about one point because `powf` constructing the $c$ grid can round differently in the last digit across environments.
The rationalized reference itself has several rounding errors, so differences of order $10^{-16}$ do not identify which result is correct.

For AgCl, $K_{\mathrm{sp}}$ is six orders larger, limiting direct error to $1.7 \times 10^{-7}$ even at $c = 1$ mol/L.
Cancellation error depends on $c^2/K_{\mathrm{sp}}$, increasing for less soluble salts and higher common-ion concentrations.

## Summary

Common-ion solubility is the small quadratic root; the direct formula loses more significant digits as common-ion concentration rises.
`checked_quadratic_roots` uses cancellation-free formulas and returns real roots ascending, so positive solubility is the second array entry.
Root accuracy is guaranteed through residual $|f(s)| \le 32\varepsilon T$ and subnormal terms, assessable with `Tolerance::new(0, 32ε)` and `is_residual_ok`.
Check forward error against independent values such as the rationalized formula.
