[Richardson extrapolation and Ridders' method](../richardson-and-ridders/) derives how adaptive `AdaptiveDifference` forms error estimates from a Neville-type table and decides when to stop.
This page checks those rules on actual functions through two experiments.
The first varies maximum levels and tolerance, comparing termination, evaluations, and estimated errors of `Ridders` and `Richardson` with differences from references (actual errors).
The second adds noise to show termination with `RoundoffLimit` and cases where estimates understate actual errors.
See [Error estimates and rounding floors](oxref:differentiate-error-estimate) for their construction and [Step and stopping rules](oxref:differentiate-stopping-rules) for thresholds and termination.
Notation follows [Shared algorithm contracts and structure](oxref:differentiate-notation); $\varepsilon = 2^{-52}$ is double-precision machine epsilon.

The following block supplies definitions for both experiment cells.
`smooth` is differentiated function $f(x) = e^{\sin x}$, and `smooth_derivative` supplies derivative reference $f'(x) = \cos x \, e^{\sin x}$.
References use f64's inherent methods, while the differentiated function uses SciOxide `RealScalar` functions.

```rust
//| id: differentiate-adaptive-experiment-model
//| kind: definitions
//| title: "Differentiated function e^{sin x} and derivative reference"
//| crates: [scioxide-core]
use scioxide_core::{SciOxideError, RealScalar};

/// Differentiated function f(x) = e^{sin x}.
pub(crate) fn smooth(t: f64) -> Result<f64, SciOxideError> {
    Ok(RealScalar::exp(RealScalar::sin(t)))
}

/// Reference f'(x) = cos x · e^{sin x} (f64 inherent methods).
pub(crate) fn smooth_derivative(x: f64) -> f64 {
    x.cos() * x.sin().exp()
}
```

## Measuring levels and error estimates

The next cell computes the first derivative of $f(x) = e^{\sin x}$ with both methods, varying maximum levels $L$ from 3 to 12.
For each $L$, it changes settings with `with_max_levels` and recomputes from scratch, recording termination, evaluations, estimated error, and reference difference (actual error).
Tolerance $\tau$ sets both absolute and relative tolerances; the chart's horizontal line is pointwise threshold $\tau (1 + \lvert f'(x_0) \rvert)$.
Smaller tolerances prevent convergence, revealing estimated and actual error behavior under continued step reduction.
Termination differs by row, so it is shown as a table column.

```rust
//| id: differentiate-extrapolation-levels
//| ref: differentiate-extrapolation-levels
//| title: "Ridders and Richardson estimated and actual errors versus maximum levels"
//| run: reactive
//| uses: [differentiate-adaptive-experiment-model]
//| crates: [scioxide-core, scioxide-differentiate]
//| inputs:
//|   tolerance: {"type":"select","label":"Tolerance τ (absolute and relative)","options":["√ε (default)","1e-12","1e-15"],"value":"1e-12"}
//|   x0: {"type":"range","label":"Evaluation point x₀","min":-2.0,"max":2.0,"step":0.5,"value":0.5}
//| cases:
//|   - {"id":"library-default","label":"τ = √ε (library default)","description":"The large threshold makes both methods reach Converged with few levels.","inputs":{"tolerance":"√ε (default)"}}
//|   - {"id":"unreachable","label":"τ = 10⁻¹⁵","description":"The threshold is below the rounding floor, so Converged is not reached.","inputs":{"tolerance":"1e-15"}}
//|   - {"id":"estimate-below","label":"x₀ = −2","description":"At Ridders L = 5, 6, estimated error understates actual error.","inputs":{"x0":-2.0}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"levels","path":"/rows/0/3","equals":7}
//|       - {"artifact":"levels","path":"/rows/5/2","equals":"Converged"}
//|       - {"artifact":"levels","path":"/rows/5/5","range":{"max":1e-12}}
//|       - {"artifact":"levels","path":"/rows/17/2","equals":"Converged"}
//|       - {"artifact":"levels","path":"/rows/17/3","equals":21}
//|   - case: library-default
//|     expect:
//|       - {"artifact":"levels","path":"/rows/9/2","equals":"Converged"}
//|       - {"artifact":"levels","path":"/rows/9/5","range":{"max":1.5e-8}}
//|   - case: unreachable
//|     expect:
//|       - {"artifact":"levels","path":"/rows/9/2","equals":"RoundoffLimit"}
//|       - {"artifact":"levels","path":"/rows/9/5","range":{"max":1e-13}}
//|   - case: estimate-below
//|     expect:
//|       - {"artifact":"levels","path":"/rows/2/4","approx":{"value":5.0006e-9,"rtol":1e-3}}
//|       - {"artifact":"levels","path":"/rows/2/5","approx":{"value":2.8392e-8,"rtol":1e-3}}
//|       - {"artifact":"levels","path":"/rows/5/2","equals":"Converged"}
use scioxide_core::{ErrorTolerance, NormSelection};
use scioxide_differentiate::{AdaptiveDifference, AdaptiveDifferenceMethod};

let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let tau = match tolerance.as_str() {
    "√ε (default)" => f64::EPSILON.sqrt(),
    text => text.parse().map_err(|_| "Cannot read tolerance")?,
};
let base = AdaptiveDifference::default().with_tolerance(
    ErrorTolerance::scalar(tau, tau, NormSelection::Infinity).map_err(|e| e.to_string())?,
);
let exact = smooth_derivative(x0);
let mut rows = Vec::new();
let mut series = Vec::new();
let mut dropped = 0;
for (name, method) in [
    ("Ridders", AdaptiveDifferenceMethod::Ridders),
    ("Richardson", AdaptiveDifferenceMethod::Richardson),
] {
    let (mut estimated, mut actual) = (Vec::new(), Vec::new());
    for levels in 3..=12_usize {
        let adaptive = base.clone().with_method(method).with_max_levels(levels);
        let result = adaptive.derivative(smooth, x0).map_err(|e| e.to_string())?;
        let report = result.report();
        let value = result.values().ok_or("Derivative not published")?[0];
        let estimate = result.errors().ok_or("Error estimate not published")?[0];
        let error = (value - exact).abs();
        estimated.push([levels as f64, estimate]);
        // Count zero actual errors, which cannot be plotted logarithmically.
        if error > 0.0 {
            actual.push([levels as f64, error]);
        } else {
            dropped += 1;
        }
        let termination = report.termination().to_string();
        rows.push((
            name,
            levels,
            termination,
            report.evaluations(),
            estimate,
            error,
        ));
    }
    let diamond = serde_json::json!({ "symbol": "diamond", "showSymbol": true });
    series
        .push(serde_json::json!({ "name": format!("{name} estimated error"), "points": estimated }));
    series.push(serde_json::json!({
        "name": format!("{name} actual error"),
        "points": actual,
        "style": diamond
    }));
}
let threshold = tau * (1.0 + exact.abs());
emit_line_chart!(
    &series,
    options = &serde_json::json!({
        "xLabel": "Maximum levels L [-]",
        "yLabel": "Derivative error [-]",
        "yType": "log",
        "annotations": [{ "kind": "line", "axis": "y", "value": threshold, "label": "Threshold" }]
    })
);
let columns = serde_json::json!([
    { "key": "0", "label": "Method" },
    { "key": "1", "label": "Maximum levels L", "type": "integer" },
    { "key": "2", "label": "Termination reason" },
    { "key": "3", "label": "Evaluations [count]", "type": "integer" },
    { "key": "4", "label": "Estimated error [-]", "type": "number", "format": sci3 },
    { "key": "5", "label": "Actual error [-]", "type": "number", "format": sci3 }
]);
let caption = format!("Excluded {dropped} zero-actual-error points from the chart.");
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "levels", "caption": caption })
);
```

With default inputs (tolerance $10^{-12}$, $x_0 = 0.5$, threshold $2.4 \times 10^{-12}$), small $L$ gives termination `RefinementLimit`, with estimated and actual errors decreasing as $L$ grows.
`Ridders` first puts estimated error $8.5 \times 10^{-13}$ below threshold at level 7, reaching `Converged` at level 8 ($1 + 2 \times 8 = 17$ evaluations).
Increasing $L$ further leaves results unchanged because it stops at level 8.
`Richardson` uses only column 1, retaining order 4 and reducing errors by only a factor of about $r^4 = 16$ per level; `Converged` requires 10 levels (21 calls).

`Ridders` estimates exceed actual errors by 1–3 orders of magnitude; `Richardson` estimates are comparable to actual errors through level 8.
However, estimates are not bounds.
For $L = 5, 6$ of `Ridders` at $x_0 = -2$, estimated error $5.0 \times 10^{-9}$ is below actual error $2.8 \times 10^{-8}$.

Tolerance $10^{-15}$ places the threshold below the rounding floor, and neither method reaches `Converged`.
After level-8 estimate $2.2 \times 10^{-13}$, `Ridders` fails to improve for 3 levels; at $L \ge 11$ it stops at level 11 with `RoundoffLimit` (23 calls), still publishing values and estimates.
Even with library-default tolerance $\sqrt{\varepsilon}$, the large initial step $0.5$ makes both methods require 7 levels (15 calls) to converge.

## Rounding-dominated functions and second derivatives

The next cell computes first and second derivatives of $f(x) = e^x + \sigma \eta(x)$ at $x_0 = 1$ with default `AdaptiveDifference` methods `derivative` and `second_derivative`.
$\eta$ is the same pseudorandom noise in $[-1, 1)$ used in [Rounding, noise, and optimal step size](oxref:differentiate-noisy-functions), determined only by point and seed.
It varies noise magnitude $\sigma$ from 0 to $10^{-4}$ and tabulates termination, publication, evaluations, estimated errors, and actual errors.
Every derivative order equals $e$, giving the same first- and second-derivative threshold $\sqrt{\varepsilon}(1 + e) \approx 5.5 \times 10^{-8}$.
The next cell uses these rows and threshold for charts and conclusions.

```rust
//| id: differentiate-adaptive-roundoff
//| ref: differentiate-adaptive-roundoff
//| title: "Adaptive termination and error estimates versus noise magnitude"
//| run: reactive
//| uses: [differentiate-adaptive-experiment-model]
//| crates: [scioxide-core, scioxide-differentiate]
//| exports: [rows, success, threshold]
//| inputs:
//|   seed: {"type":"range","label":"Random seed","min":1,"max":20,"step":1,"value":3}
//| cases:
//|   - {"id":"other-seed","label":"Seed = 11","description":"Even with a different noise realization, σ = 10⁻⁶ stops with RoundoffLimit, and estimates understate actual errors even for first derivatives.","inputs":{"seed":11}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"sweep","path":"/rows/0/2","equals":"Converged"}
//|       - {"artifact":"sweep","path":"/rows/0/4","equals":13}
//|       - {"artifact":"sweep","path":"/rows/0/6","range":{"max":1e-12}}
//|       - {"artifact":"sweep","path":"/rows/10/2","equals":"RoundoffLimit"}
//|       - {"artifact":"sweep","path":"/rows/10/3","equals":"Available"}
//|       - {"artifact":"sweep","path":"/rows/10/6","range":{"max":1e-4}}
//|   - case: other-seed
//|     expect:
//|       - {"artifact":"sweep","path":"/rows/10/2","equals":"RoundoffLimit"}
//|       - {"artifact":"sweep","path":"/rows/10/5","range":{"max":1e-5}}
//|       - {"artifact":"sweep","path":"/rows/10/6","range":{"min":1e-5,"max":1e-4}}
use scioxide_core::{SciOxideError, RealScalar};
use scioxide_differentiate::AdaptiveDifference;

let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let seed = seed as u64;
// Noise model: mix point bits and seed with splitmix64 into a value in [-1, 1).
let noise = |t: f64| {
    let mut z = t.to_bits() ^ seed.wrapping_mul(0x9E37_79B9_7F4A_7C15);
    z = (z ^ (z >> 30)).wrapping_mul(0xBF58_476D_1CE4_E5B9);
    z = (z ^ (z >> 27)).wrapping_mul(0x94D0_49BB_1331_11EB);
    z ^= z >> 31;
    (z >> 11) as f64 / (1_u64 << 53) as f64 * 2.0 - 1.0
};
let x0 = 1.0_f64;
// Reference: all e^x derivatives equal e (f64 inherent methods).
let exact = x0.exp();
let adaptive = AdaptiveDifference::default();
let mut rows = Vec::new();
let mut success = Vec::new();
for amplitude in [0.0, 1e-14, 1e-12, 1e-10, 1e-8, 1e-6, 1e-4] {
    let f = |t: f64| Ok::<f64, SciOxideError>(RealScalar::exp(t) + amplitude * noise(t));
    let first = adaptive.derivative(f, x0).map_err(|e| e.to_string())?;
    let second = adaptive
        .second_derivative(f, x0)
        .map_err(|e| e.to_string())?;
    for (order, result) in [("First", &first), ("Second", &second)] {
        let report = result.report();
        let published = if report.output_available() {
            "Available"
        } else {
            "None"
        };
        rows.push((
            amplitude,
            order,
            report.termination().to_string(),
            published,
            report.evaluations(),
            result.errors().map(|e| e[0]),
            result.values().map(|v| (v[0] - exact).abs()),
        ));
        success.push(report.is_success());
    }
}
let columns = serde_json::json!([
    { "key": "0", "label": "Noise magnitude σ [-]", "type": "number", "format": sci3 },
    { "key": "1", "label": "Order" },
    { "key": "2", "label": "Termination reason" },
    { "key": "3", "label": "Published" },
    { "key": "4", "label": "Evaluations [count]", "type": "integer" },
    { "key": "5", "label": "Estimated error [-]", "type": "number", "format": sci3, "nullText": "None" },
    { "key": "6", "label": "Actual error [-]", "type": "number", "format": sci3, "nullText": "None" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "sweep" })
);
export!(rows, rows);
export!(success, success);
// Threshold τ_abs + τ_rel |f′| = √ε (1 + e) (default tolerance; derivatives of every order equal e).
export!(threshold, f64::EPSILON.sqrt() * (1.0 + exact));
```

Without noise ($\sigma = 0$), first and second derivatives reach `Converged` in 6 levels (13 calls); first-derivative estimated error is $2.5 \times 10^{-13}$ and actual error $1.8 \times 10^{-15}$.
At $\sigma \le 10^{-10}$, convergence occurs, but estimated errors increase with noise.
At $\sigma = 10^{-8}$ or above, shrinking steps increases noise contribution $\sigma / h$ ($\sigma / h^2$ for second derivatives), halting improvement of the best error estimate; both orders stop with `RoundoffLimit`.
Values and estimates are still published, as the “Published” column shows.
Seed 11 also stops with `RoundoffLimit` at $\sigma = 10^{-8}$ or above.

The next cell plots estimated and actual errors from the preceding table against noise magnitude $\sigma$, then emits the selected $\sigma$ first-derivative termination as the cell conclusion.
The horizontal line is threshold $\sqrt{\varepsilon}(1 + e)$; the vertical line is selected $\sigma$.
The logarithmic horizontal axis excludes row $\sigma = 0$.
The outcome is satisfied for termination `Converged` and partial otherwise.

```rust
//| id: differentiate-adaptive-noise-chart
//| ref: differentiate-adaptive-noise-chart
//| title: "Estimated and actual errors versus noise magnitude and termination at selected σ"
//| run: reactive
//| crates: [scioxide-core]
//| dependsOn:
//|   sweep: differentiate-adaptive-roundoff
//| inputs:
//|   sigma: {"type":"select","label":"Noise magnitude σ for conclusion","options":["0","1e-12","1e-8","1e-6","1e-4"],"value":"1e-6"}
//| cases:
//|   - {"id":"noiseless","label":"σ = 0","description":"Without noise, the first derivative stops with Converged and outcome satisfied.","inputs":{"sigma":"0"}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"path":"/outputs/1/state","equals":"partial"}
//|       - {"path":"/outputs/1/status","equals":"RoundoffLimit"}
//|   - case: noiseless
//|     expect:
//|       - {"path":"/outputs/1/state","equals":"satisfied"}
//|       - {"path":"/outputs/1/status","equals":"Converged"}
// Table rows: (σ, order, termination, published, evaluations, estimated error, actual error).
type Row = (f64, String, String, String, usize, Option<f64>, Option<f64>);
let rows: Vec<Row> =
    serde_json::from_value(sweep["rows"].clone()).map_err(|e| e.to_string())?;
let success: Vec<bool> =
    serde_json::from_value(sweep["success"].clone()).map_err(|e| e.to_string())?;
let threshold = sweep["threshold"].as_f64().ok_or("No threshold")?;
let selected: f64 = sigma.parse().map_err(|_| "Cannot read σ")?;
// Curves: first-derivative estimated and actual errors, second-derivative estimated and actual errors. σ = 0 cannot be plotted logarithmically.
let mut curves: Vec<Vec<[f64; 2]>> = vec![Vec::new(); 4];
let mut chosen = None;
for (row, &converged) in rows.iter().zip(&success) {
    let (amplitude, order, termination, _, evaluations, estimate, error) = row;
    let lane = if order == "First" { 0 } else { 2 };
    if let (true, Some(estimate), Some(error)) = (*amplitude > 0.0, estimate, error) {
        curves[lane].push([*amplitude, *estimate]);
        if *error > 0.0 {
            curves[lane + 1].push([*amplitude, *error]);
        }
    }
    if lane == 0 && *amplitude == selected {
        chosen = Some((converged, termination, *evaluations, *estimate, *error));
    }
}
let names = [
    "First-derivative estimate",
    "First-derivative actual error",
    "Second-derivative estimate",
    "Second-derivative actual error",
];
let series: Vec<_> = names
    .iter()
    .zip(&curves)
    .map(|(name, points)| serde_json::json!({ "name": name, "points": points }))
    .collect();
let mut annotations = vec![serde_json::json!({
    "kind": "line",
    "axis": "y",
    "value": threshold,
    "label": "Threshold √ε(1 + e)"
})];
if selected > 0.0 {
    annotations.push(serde_json::json!({
        "kind": "line",
        "axis": "x",
        "value": selected,
        "label": "Selected σ"
    }));
}
emit_line_chart!(
    &series,
    options = &serde_json::json!({
        "xLabel": "Noise magnitude σ [-]",
        "yLabel": "Derivative error [-]",
        "xType": "log",
        "yType": "log",
        "annotations": annotations
    })
);
let (converged, termination, evaluations, estimate, error) =
    chosen.ok_or("Selected σ absent from scan")?;
let outcome = if converged {
    Outcome::satisfied("First-derivative error estimate met tolerance")
} else {
    Outcome::partial("First-derivative extrapolation stopped before meeting tolerance")
        .explanation("The published value is the best estimate. Assess its estimated error before deciding whether to use it.")
};
let mut outcome = outcome.status(termination.clone());
outcome = outcome.diagnostic("Evaluations", evaluations as f64, None);
if let (Some(estimate), Some(error)) = (estimate, error) {
    outcome = outcome.diagnostic("Estimated error", estimate, None);
    outcome = outcome.diagnostic("Actual error", error, None);
}
emit_outcome!(outcome);
```

At default $\sigma = 10^{-6}$ (seed 3), the first derivative reaches `RoundoffLimit` in 7 levels (15 calls), publishing values and estimates with outcome partial.

For noisy functions, estimates may greatly understate actual errors.
With seed 3, actual-error points lie above estimated-error curves for first derivatives at $\sigma \ge 10^{-8}$ and second derivatives at $\sigma \ge 10^{-12}$.
Even with `Converged`, second derivatives at $\sigma = 10^{-12}$ and $10^{-10}$ have actual errors 2–12 times their estimates.
At $\sigma = 10^{-6}$, the estimated second-derivative error is $7.7 \times 10^{-7}$ versus actual error $9.5 \times 10^{-5}$; changing to seed 11 also gives estimated first-derivative error $2.7 \times 10^{-6}$ versus actual error $4.5 \times 10^{-5}$.
Noise is nonsmooth, violating the extrapolation expansion, so table-entry differences can be accidentally small.
On termination `RoundoffLimit`, do not trust estimates alone; choose steps from noise magnitude ([Noisy functions](oxref:differentiate-noisy-functions)) or check values independently.

## Summary

For $f(x) = e^{\sin x}$ and tolerance $10^{-12}$, `Ridders` reaches `Converged` in 8 levels (17 calls), while column-1-only `Richardson` needs 10 levels (21 calls); default `Ridders` therefore uses fewer calls at equal tolerance.
`Ridders` estimates exceed actual errors by 1–3 orders at $x_0 = 0.5$, but understate them at some levels at $x_0 = -2$, so they are not upper bounds.
Tolerance below the rounding floor prevents `Converged` and gives `RoundoffLimit`; choose tolerance from derivative scale and rounding floor.
Noisy functions give `RoundoffLimit` at $\sigma \ge 10^{-8}$, and second derivatives at $\sigma = 10^{-12}$ and $10^{-10}$ have actual errors 2–12 times estimates even with `Converged`.
Values and estimates remain published with `RoundoffLimit`; do not rely on those estimates alone, and select noise-based steps or check independently.
