For nonnegative quantities such as concentrations or probabilities, domain-limited functions such as $\sqrt{x}$ or $\ln x$, or bounded optimization variables, difference nodes must stay inside the domain.
`scioxide-differentiate` accepts coordinatewise lower and upper bounds as evaluation arguments and never evaluates outside them.
Fixed-step differences avoid placing nodes where boundary room is insufficient and switch to one-sided nodes in the direction with more room.
Adaptive differences use the same rule at each level; specified-node differences reject out-of-bounds nodes.
This page derives these rules and their effects on truncation and rounding errors.
Boundary handling guarantees samples stay inside bounds; accuracy is comparable to interior points when the function is smooth over the sampled range.

## Specifying boundaries

Represent interval constraints with scioxide-core [`Bounds`](https://docs.rs/scioxide-core/0.1.0/scioxide_core/struct.Bounds.html).
Supply each coordinate's lower and upper bounds with `Option`, as in `Bounds::new(vec![(Some(0.0), None), (Some(-1.0), Some(1.0))])`; `None` means no constraint on that side.
Intervals are closed; no coordinates gives `InvalidInput` (`Empty`), a lower bound exceeding its upper bound gives `InvalidInput` (`Inconsistent`), and nonfinite bounds give `NonFinite`.
For constraints on only some coordinates, use `Bounds::from_indexed(n, vec![(i, lower, upper)])` with coordinate indices.

`bounds` is an evaluation argument rather than a method or Plan, allowing one method value to serve different bounds.
Scalar `derivative` and `second_derivative` accept no bounds in either `FiniteDifference` or `AdaptiveDifference`.
For univariate bounds, use `FiniteDifference::derivative_into` for first derivatives (bounds `ExtendedInterval`), or single-coordinate `gradient` and `hessian` for either method.
Out-of-bounds points give `InvalidInput` (`x`, `OutOfRange`); bound coordinate counts mismatching the point give `DimensionMismatch`.
Below, $a = x - x_{\min}$ is the distance from evaluation point $x$ to the lower bound, and $h$ is the nominal step.
Default fixed-step $h$ is derived in [Taylor expansion and step-size selection](../taylor-and-step-size/): $h = \varepsilon^{1/3} \max(1, \lvert x \rvert)$ for central first derivatives and $h = \varepsilon^{1/4} \max(1, \lvert x \rvert)$ for second derivatives.

## Nodes selected by fixed-step central differences

Central differences in `FiniteDifference` select coordinate nodes in this order.

1. Compute positive room $x_{\max} - x$ and negative room $a = x - x_{\min}$.
   On unconstrained sides, room extends to the largest floating-point value.
2. If both sides have at least nominal step $h$, use three points $\{-h, 0, h\}$.
3. If either side has less than $h$, place one-sided nodes in the direction with more room, positive on ties.
   First derivatives use three points $\{0, h', 2h'\}$ and second derivatives four points $\{0, h', 2h', 3h'\}$, reducing the step to $h' = \min(h, \text{room}/2)$ ($\min(h, \text{room}/3)$ for second derivatives) to fit the chosen direction.
   If nodes leave bounds or merge under rounding, try the opposite direction.
4. If neither direction fits one-sided nodes but both have room (bounds extremely narrow relative to the step), try symmetric three-point nodes with the step reduced to the minimum of $h$ and both sides' room.
5. If none fits, return `InvalidInput` (`UnsupportedConfiguration`) before calling the function.
   The argument is `bounds` for a constrained coordinate and `x` otherwise.

In case 2, if rounding erases one displacement (for example without bounds when $h$ is less than half $\mathrm{ulp}(x)$), the result is case 5's error rather than a one-sided fallback ([U-shaped error curve from a step sweep](oxref:differentiate-step-u-curve)).
Weights always use rounded displacements; for 3 or more nodes they use Fornberg's recurrence ([Difference-stencil weights and arbitrary nodes](oxref:differentiate-fornberg)).
Even near boundaries, nodes are either symmetric triples or equally spaced inward one-sided nodes, independent of boundary distance $a$.

### Why asymmetric nodes are avoided

When $0 < a < h$, asymmetric three-point nodes $\{-a, 0, h\}$ with only the negative displacement reduced to $a$ can also form a first derivative without leaving bounds.
Their formula follows.

$$
D f(x) = -\frac{h}{a (a + h)} f(x - a) + \frac{h - a}{a h} f(x) + \frac{a}{h (a + h)} f(x + h).
$$

Dividing cubic moment $\sum_j w_j \Delta_j^3 = a h$ by $3!$ gives leading truncation term $(a h/6) f'''(x)$, which becomes smaller as $a$ becomes smaller.
However, for $a \ll h$ the weights at the negative node and center are both about $1/a$, giving absolute-weight sum about $2/a$.
With relative function-value error $\varepsilon_f$, rounding error is about $2 \varepsilon_f \lvert f \rvert / a$ and grows without bound near the boundary.
For second derivatives, the same triple's cubic moment is $2(h - a)$, reducing leading-error order $(h - a) f'''(x)/3$ to first order and increasing rounding to about $4 \varepsilon_f \lvert f \rvert / (a h)$.
Thus `FiniteDifference` avoids the side with insufficient room and uses inward one-sided nodes.

### Errors of one-sided formulas

Taylor expansion gives second-order accuracy for the one-sided three-point first derivative.

$$
\frac{-3 f(x) + 4 f(x + h) - f(x + 2h)}{2h} = f'(x) - \frac{h^2}{3} f'''(x) + O(h^3).
$$

The one-sided four-point second derivative is also second order because its cubic moment is $(-5 + 32 - 27) h^3 = 0$.

$$
\frac{2 f(x) - 5 f(x + h) + 4 f(x + 2h) - f(x + 3h)}{h^2} = f''(x) - \frac{11}{12} h^2 f^{(4)}(x) + O(h^3).
$$

One-sided leading coefficients exceed central ones (first derivative $h^2/6$, second derivative $h^2/12$).
Absolute-weight sums are also larger: first derivative $4/h$ (central $1/h$), second derivative $12/h^2$ (central $4/h^2$), giving several times the central error at equal $h$.
Neither depends on boundary distance $a$, however, so errors remain comparable to interior points even just inside boundaries.

Forward first differences use $\{0, h\}$ if positive room is at least $h$, otherwise $\{0, -h\}$ if negative room is at least $h$.
If neither direction has room $h$, reduce the step to available room in the roomier direction, positive on ties.
Forward second differences use $\{0, h, 2h\}$, selecting direction by the same rule with room compared against $2h$.

## Measuring errors against boundary distance

The next cell differentiates $f(x) = e^x$ with default central differences at points $x = a$ with varying distance $a$ from lower bound 0.
To supply bounds, first derivatives use single-coordinate `gradient` and second derivatives single-coordinate `hessian`.
Record points on each function call and tabulate minimum and maximum actual displacements in nominal-step $h$ units.
Leading truncation errors are predicted by the formulas above.
Compute the rounding guideline $u \sum_j \lvert w_j \rvert \lvert f \rvert$ ($u = \varepsilon/2$ is unit roundoff) by constructing `FiniteDifferenceStencil` from recorded nodes and using the physical-unit weights returned by `weights()`.
For comparison, compute errors of unused asymmetric triple $\{-a, 0, h\}$ with `FiniteDifferenceStencil::apply` applied to the same function values, showing them in the last column (undefined at $a = 0$ and $a \ge h$).
Exact values and leading terms are f64 references.
The chart shows absolute errors for a fine sweep of $a$ from $10^{-12}$ to $10^{-1}$; $a = 0$ appears only in the table because logarithmic axes cannot display it.

//|   - {"id":"second","label":"Second","description":"The large h makes rows a ≤ 10⁻⁴ use four one-sided nodes; asymmetric-triple errors grow with the first-order term and 1/(ah) rounding.","inputs":{"order":"Second"}}

//|   - case: default

//|       - {"artifact":"nodes","path":"/rows/6/7","equals":null}
//|   - case: second
//|     expect:
//|       - {"artifact":"nodes","path":"/rows/0/1","equals":4}
//|       - {"artifact":"nodes","path":"/rows/0/3","approx":{"value":3,"rtol":1e-9}}
//|       - {"artifact":"nodes","path":"/rows/5/3","approx":{"value":3,"rtol":1e-9}}
//|       - {"artifact":"nodes","path":"/rows/5/4","range":{"min":-1.8e-7,"max":1.8e-7}}
//|       - {"artifact":"nodes","path":"/rows/5/7","approx":{"value":7.36e-6,"rtol":0.02}}
//|       - {"artifact":"nodes","path":"/rows/6/1","equals":3}
use scioxide_core::{Bounds, SciOxideError, RealScalar};
use scioxide_differentiate::{FiniteDifference, FiniteDifferenceStencil};

// Default h = c·max(1, |x|); since x < 1 here, h = c.
let (m, h) = match order.as_str() {
    "First" => (1, f64::EPSILON.cbrt()),
    _ => (2, f64::EPSILON.sqrt().sqrt()),
};
let method = FiniteDifference::default();
let bounds = Bounds::new(vec![(Some(0.0), None)]).map_err(|e| e.to_string())?;
// Differentiate at x = a and return (nodes, measured error, leading term, rounding guideline, asymmetric-triple error).
let probe = |a: f64| {
    let mut seen = Vec::new();
    let f = |p: &[f64], y: &mut [f64]| {
        seen.push(p[0]);
        y[0] = RealScalar::exp(p[0]);
        Ok::<(), SciOxideError>(())
    };
    let result = if m == 1 {
        method.gradient(f, &[a], Some(&bounds), None)
    } else {
        method.hessian(f, &[a], Some(&bounds), None)
    }
    .map_err(|e| e.to_string())?;
    let value = result.values().ok_or("Derivative not published")?[0];
    seen.sort_by(f64::total_cmp);
    // Reference: every derivative of e^x equals e^a (f64 inherent methods).
    let g = a.exp();
    let (lo, hi) = (a - seen[0], seen[seen.len() - 1] - a);
    // Symmetric triples have leading terms h²/6 (h²/12 for second derivatives); one-sided terms are −h²/3 (−11h²/12 for second derivatives).
    let predicted = match (m, lo > 0.0) {
        (1, true) => lo * hi / 6.0 * g,
        (1, false) => -(hi / 2.0).powi(2) / 3.0 * g,
        (_, true) => lo * hi / 12.0 * g,
        _ => -11.0 / 12.0 * (hi / 3.0).powi(2) * g,
    };
    let stencil = FiniteDifferenceStencil::new(a, &seen, m).map_err(|e| e.to_string())?;
    let weights = stencil.weights().map_err(|e| e.to_string())?;
    let spread: f64 = weights.iter().map(|w| w.abs()).sum();
    // Comparison: error of asymmetric triple {−a, 0, h} with only negative displacement reduced to a.
    let asymmetric = if a > 0.0 && a < h {
        let nodes = [0.0, a, a + h];
        let values = nodes.map(RealScalar::exp);
        let stencil = FiniteDifferenceStencil::new(a, &nodes, m).map_err(|e| e.to_string())?;
        Some(stencil.apply(&values).map_err(|e| e.to_string())? - g)
    } else {
        None
    };
    let rounding = f64::EPSILON / 2.0 * spread * g;
    Ok::<_, String>((seen, value - g, predicted, rounding, asymmetric))
};
let mut rows = Vec::new();
for a in [0.0, 1e-10, 1e-8, 1e-6, 1e-5, 1e-4, 1e-2] {
    let (seen, error, predicted, rounding, asymmetric) = probe(a)?;
    let (low, high) = ((seen[0] - a) / h, (seen[seen.len() - 1] - a) / h);
    rows.push((
        a,
        seen.len(),
        low,
        high,
        error,
        predicted,
        rounding,
        asymmetric,
    ));
}
let (sci2, sci3, fixed3) = (
    serde_json::json!({ "notation": "scientific", "significantDigits": 2 }),
    serde_json::json!({ "notation": "scientific", "significantDigits": 3 }),
    serde_json::json!({ "fractionDigits": 3 }),
);
let columns = serde_json::json!([
    { "key": "0", "label": "Distance a [-]", "type": "number", "format": sci2 },
    { "key": "1", "label": "Nodes [count]", "type": "integer" },
    { "key": "2", "label": "Minimum displacement ÷ h [-]", "type": "number", "format": fixed3 },
    { "key": "3", "label": "Maximum displacement ÷ h [-]", "type": "number", "format": fixed3 },
    { "key": "4", "label": "Measured error [-]", "type": "number", "format": sci3 },
    { "key": "5", "label": "Leading truncation term [-]", "type": "number", "format": sci3 },
    { "key": "6", "label": "Rounding guideline [-]", "type": "number", "format": sci3 },
    { "key": "7", "label": "Asymmetric-triple error [-]", "type": "number", "format": sci3, "nullText": "—" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "nodes" })
);
// Chart: absolute errors at a = 10^(−12 + k/4). Exclude exactly zero errors from the logarithmic axis.
let (mut measured, mut skewed, mut rounding) = (Vec::new(), Vec::new(), Vec::new());
for k in 0..=44 {
    let a = 10.0_f64.powf(-12.0 + 0.25 * k as f64);
    let (_, error, _, guide, asymmetric) = probe(a)?;
    if error != 0.0 {
        measured.push([a, error.abs()]);
    }
    if let Some(e) = asymmetric.filter(|e| *e != 0.0) {
        skewed.push([a, e.abs()]);
    }
    rounding.push([a, guide]);
}
let dashed = serde_json::json!({ "lineType": "dashed" });
emit_line_chart!(
    &[
        serde_json::json!({ "name": "Measured error", "points": measured, "style": { "showSymbol": true } }),
        serde_json::json!({ "name": "Asymmetric-triple error", "points": skewed, "style": { "showSymbol": true } }),
        serde_json::json!({ "name": "Rounding guideline", "points": rounding, "style": dashed })
    ],
    options = &serde_json::json!({
        "xLabel": "Lower-bound distance a [-]",
        "yLabel": "Absolute derivative error [-]",
        "xType": "log",
        "yType": "log",
        "annotations": [{ "kind": "line", "axis": "x", "value": h, "label": "Nominal step h" }]
    })
);
```

Measured errors range from $5.2 \times 10^{-12}$ to $-4.0 \times 10^{-11}$, below the rounding guideline.
Asymmetric-triple errors grow from $-3.2 \times 10^{-11}$ at $a = 10^{-6}$ to $-1.1 \times 10^{-8}$ at $10^{-8}$ and $8.3 \times 10^{-8}$ at $10^{-10}$.

For second derivatives (case second), $h = \varepsilon^{1/4} \approx 1.22 \times 10^{-4}$; only $a = 10^{-2}$ uses symmetric nodes, while six rows $a \le 10^{-4}$ use one-sided quadruples $\{0, h, 2h, 3h\}$.

Across the plotted range, measured errors remain below $7.6 \times 10^{-8}$, while asymmetric-triple error reaches $1.5$ at $a = 10^{-12}$.
One-sided nodes keep errors within several times interior errors even when boundary distance is less than the step.

## Boundaries for adaptive, directional, and node differences

Adaptive `AdaptiveDifference` ([Richardson extrapolation and Ridders' method](../richardson-and-ridders/)) selects nodes for each level's step $h_\ell$ by the same rule as fixed-step central differences.
If both sides have room at least $h_\ell$, use symmetric $\{-h_\ell, 0, h_\ell\}$; otherwise use one-sided nodes in the roomier direction (first derivative $\{0, h', 2h'\}$, second derivative $\{0, h', 2h', 3h'\}$).
The initial step $0.5 \max(1, \lvert x \rvert)$ is large: for distance $a$, early levels with steps above $a$ are one-sided, switching to symmetric nodes once steps fall below $a$.
One-sided errors include every power of $h$, while symmetric errors include only even powers; extrapolation therefore assumes a separate expansion for each node shape.
A node-shape change restarts the table at column 0 and resets stagnation history.
The previous best estimate remains as a fallback, but new-configuration improvements are compared with that configuration's history.
Neither shape shrinks steps to boundary distance $a$, keeping rounding near the boundary comparable to interior points.

First-derivative levels take 2 evaluations with either shape.
One-sided second-derivative levels use four nodes and 3 evaluations, one more than symmetric levels' 2.
If step reduction yields unrepresentable nodes or the same nodes as the previous level, report termination is `StepSizeLimit`.
`AdaptiveDifference` has no equivalent of `FixedCoordinatePolicy`, so coordinates with equal bounds also stop with `StepSizeLimit`.

Directional derivatives ([Directional derivatives (Jacobian–vector products)](oxref:differentiate-jvp-step)) compute positive and negative room in $\alpha$ before line $\mathbf{x} + \alpha \mathbf{v}$ along $\mathbf{v}$ leaves bounds.
They then try symmetric, roomier-side one-sided, and reduced symmetric nodes in the same order as univariate fixed differences.
If a coordinate points toward a bound it already occupies, movement in that direction is impossible.
Rounded points are also checked for membership and distinctness; on failure, central differences try reduced symmetric nodes.
Fixed-step `FiniteDifference::jvp` with unplaceable nodes returns error `DifferentiationFailure` (cause `StepSizeLimit` of `ConvergenceFailure`), rather than a report.
Adaptive `AdaptiveDifference::jvp` uses the same per-level placement and stops with report termination `StepSizeLimit` if nodes cannot be placed.

Specified-node differences ([Plans and method values for specified-node differences](oxref:differentiate-node-checks)) do not move nodes to fit boundaries.
Out-of-bounds nodes are rejected with `InvalidInput` (`UnsupportedConfiguration`) before function calls.
The argument is `bounds` for fixed-point `PhysicalDifferencePlan` and `x` for displacement-based `RelativeDifference`.

Complex-step first-derivative perturbations ([Complex-step differentiation and analytic extensions](../complex-step/)) move only imaginary parts, retaining the evaluation point's real part and staying inside bounds.
Method `ComplexStep` operations accept no bounds.
`ComplexStepPlan` and `RelativeComplexStep`, forming second derivatives with real nodes, accept bounds and reject out-of-bounds real nodes with `InvalidInput` (`UnsupportedConfiguration`), as specified-node differences do ([Real-node method values and Plans](oxref:differentiate-complex-node-plans)).

The next cell computes first and second derivatives of $f(x) = e^x$ with `AdaptiveDifference` under lower bound 0, tabulating termination, levels, one-sided levels, evaluations, estimated error, and actual error versus boundary distance $a$.
Symmetric levels evaluate exactly one point below the base while one-sided levels evaluate none; record each call and count points below $a$ as symmetric levels.
Initial step is $0.5$, divided by $1.4$ per Ridders level, so $a = 0.05$ and $0.1$ change node shape partway through.
Exact value $e^a$ is an f64 reference.

//|   - case: default

//|       - {"artifact":"adaptive","path":"/rows/0/1","equals":"Converged"}

//|       - {"artifact":"adaptive","path":"/rows/0/4","equals":17}
//|       - {"artifact":"adaptive","path":"/rows/0/6","range":{"max":1e-11}}

//|       - {"artifact":"adaptive","path":"/rows/5/2","equals":11}
//|       - {"artifact":"adaptive","path":"/rows/5/3","equals":7}
//|       - {"artifact":"adaptive","path":"/rows/5/4","equals":23}
//|       - {"artifact":"adaptive","path":"/rows/5/6","range":{"max":1e-11}}
//|       - {"artifact":"adaptive","path":"/rows/7/3","equals":0}
//|       - {"artifact":"adaptive","path":"/rows/7/6","range":{"max":1e-11}}
//|   - case: second
//|     expect:
//|       - {"artifact":"adaptive","path":"/rows/0/1","equals":"Converged"}
//|       - {"artifact":"adaptive","path":"/rows/0/4","equals":28}
//|       - {"artifact":"adaptive","path":"/rows/1/6","range":{"max":1e-11}}
//|       - {"artifact":"adaptive","path":"/rows/5/1","equals":"Converged"}
//|       - {"artifact":"adaptive","path":"/rows/7/4","equals":13}

use scioxide_core::{Bounds, SciOxideError, RealScalar};
use scioxide_differentiate::AdaptiveDifference;

let second = order == "Second";
let method = AdaptiveDifference::default();
let bounds = Bounds::new(vec![(Some(0.0), None)]).map_err(|e| e.to_string())?;
let mut rows = Vec::new();
for a in [0.0, 1e-12, 1e-8, 1e-4, 1e-2, 0.05, 0.1, 1.0] {
    // Count points below evaluation point a; only symmetric levels evaluate one such point.
    let mut below = 0_usize;
    let f = |p: &[f64], y: &mut [f64]| {
        below += usize::from(p[0] < a);
        y[0] = RealScalar::exp(p[0]);
        Ok::<(), SciOxideError>(())
    };
    let result = if second {
        method.hessian(f, &[a], Some(&bounds))
    } else {
        method.gradient(f, &[a], Some(&bounds))
    }
    .map_err(|e| e.to_string())?;
    let report = result.report();
    // Limit-stopped values are not published, so show None.
    let estimate = result.errors().map(|e| e[0]);
    // Reference: e^x derivatives equal e^a (f64 inherent methods).
    let actual = result.values().map(|v| (v[0] - a.exp()).abs());
    rows.push((
        a,
        report.termination().to_string(),
        report.iterations(),
        report.iterations() - below,
        report.evaluations(),
        estimate,
        actual,
    ));
}

    { "key": "3", "label": "One-sided levels [count]", "type": "integer" },

    { "key": "5", "label": "Estimated error [-]", "type": "number", "format": sci3, "nullText": "None" },

```

For first-derivative defaults, all five rows $a \le 10^{-2}$ use one-sided nodes for all 8 levels, reaching `Converged` in 17 evaluations.
Actual errors range from $8.3 \times 10^{-13}$ to $9.1 \times 10^{-13}$ and estimates are $1.4 \times 10^{-10}$; results barely change between the boundary and distance $10^{-12}$.
At $a = 0.1$, 5 one-sided levels precede symmetric nodes; restarting the table gives `Converged` in 10 levels and 21 evaluations, with error $9.1 \times 10^{-15}$.
At $a = 0.05$, node shape changes after 7 one-sided levels, restarting extrapolation and stagnation history.
Adding 4 symmetric levels gives `Converged` in 11 levels and 23 evaluations, with actual error $1.1 \times 10^{-14}$ and estimate $6.1 \times 10^{-13}$.
Away from the boundary at $a = 1$, all 6 levels are symmetric, with 13 calls and error $1.8 \times 10^{-15}$.

For second derivatives (case second), one-sided levels take 3 calls; five rows $a \le 10^{-2}$ use $1 + 3 \times 9 = 28$ calls in 9 levels, all reaching `Converged` with errors $4.3 \times 10^{-13}$–$1.3 \times 10^{-11}$.
$a = 0.05$ uses $1 + 3 \times 7 + 2 \times 4 = 30$ calls for 7 one-sided and 4 symmetric levels; $a = 0.1$ uses 26 calls for 5 one-sided and 5 symmetric levels, both reaching `Converged`.
Even just inside the boundary, one-sided steps do not shrink to $a$, keeping errors comparable to boundary-point errors.
Distances where shapes change can increase evaluations because extrapolation and stagnation history restart.
Failure to keep improving in the same configuration may also give `RoundoffLimit`; inspect termination and estimates before using values.


## Coordinates with equal lower and upper bounds

Bounded optimization may produce coordinates fixed by equal lower and upper bounds.
Neither direction has room, so no difference nodes fit.
`FiniteDifference` selects their treatment with [`FixedCoordinatePolicy`](https://docs.rs/scioxide-differentiate/0.1.0/scioxide_differentiate/enum.FixedCoordinatePolicy.html) passed to `with_fixed_coordinates`.

| Value | Behavior |
|---|---|
| `RequireStencil` (default) | Nodes cannot be formed; returns `InvalidInput` (`bounds`, `UnsupportedConfiguration`) before calling the function |
| `FeasibleZero` | Sets that coordinate's partial derivative to 0 without evaluating its samples |

Only gradients (`gradient`, `gradient_into`) and scalar first derivatives (`derivative`, `derivative_into`) accept `FeasibleZero`.
Other operations (second derivatives, Hessians, Jacobians, directional derivatives) give `InvalidInput` (`self`, `Inconsistent`) on invocation.
Gradient evaluation without `bounds` gives `InvalidInput` (`bounds`, `Inconsistent`).
Scalar `derivative` accepts no bounds, so this policy acts only through bounded `derivative_into`.
A zeroed component still counts as completed and as one iteration.
The returned gradient is restricted to directions preserving fixed coordinates, not the original function's partial derivative in that coordinate.

Other methods have no equivalent of `FixedCoordinatePolicy`.
`AdaptiveDifference` cannot place nodes for fixed coordinates and stops with `StepSizeLimit` before starting that component's level.
A direction moving a fixed coordinate has no room either way and admits no directional nodes.
Specified-node differences reject nonzero displacements in fixed coordinates as out-of-bounds nodes.

The next two cells compute the gradient of $f(\mathbf{x}) = x_0^2 + x_0 x_1 + x_2^3$ at $\mathbf{x} = (1, 2, 0.5)$, setting a selected coordinate's bounds equal to its value.
The original gradient is $(2 x_0 + x_1, x_0, 3 x_2^2) = (4, 1, 0.75)$.
Shared definitions follow: `polynomial` represents $f$, `pinned_bounds` bounds fix only the selected coordinate, and `row` turns a result or error into a table row.
`row` reads kinds with `e.kind()`, arguments and reasons with `e.view()`, and cause reasons for `DifferentiationFailure`.

```rust
//| id: differentiate-fixed-coordinate-model
//| kind: definitions
//| title: "Bounds with a fixed coordinate and result-table rows"
//| crates: [scioxide-core, scioxide-differentiate]
use scioxide_core::{Bounds, SciOxideError, SciOxideErrorView};
use scioxide_differentiate::DifferentiationResult;

/// Evaluation point x = (1, 2, 0.5).
pub(crate) const POINT: [f64; 3] = [1.0, 2.0, 0.5];

/// Write f(x) = x₀² + x₀x₁ + x₂³ to y[0].
pub(crate) fn polynomial(p: &[f64], y: &mut [f64]) -> Result<(), SciOxideError> {
    y[0] = p[0] * p[0] + p[0] * p[1] + p[2] * p[2] * p[2];
    Ok(())
}

/// Bounds fix only coordinate fixed at its evaluation-point value; other coordinates are unconstrained.
pub(crate) fn pinned_bounds(fixed: usize) -> Result<Bounds<f64>, SciOxideError> {
    let value = POINT[fixed];
    Bounds::from_indexed(3, vec![(fixed, Some(value), Some(value))])
}

/// Table row: (computation, termination or error kind, argument, reason, evaluations, 3 gradient components).
pub(crate) type Row = (
    &'static str,
    String,
    Option<String>,
    Option<String>,
    Option<usize>,
    Option<f64>,
    Option<f64>,
    Option<f64>,
);

/// Convert a result or error into one row; read the cause reason for DifferentiationFailure.
pub(crate) fn row(
    name: &'static str,
    outcome: Result<DifferentiationResult<f64>, SciOxideError>,
) -> Row {
    match outcome {
        Ok(result) => {
            let report = result.report();
            let g = |i: usize| result.values().and_then(|v| v.get(i).copied());
            let termination = report.termination().to_string();
            let evaluations = Some(report.evaluations());
            (name, termination, None, None, evaluations, g(0), g(1), g(2))
        }
        Err(e) => {
            let (argument, reason) = match e.view() {
                SciOxideErrorView::InvalidInput {
                    argument, reason, ..
                } => (Some(argument.to_string()), Some(format!("{reason:?}"))),
                SciOxideErrorView::DifferentiationFailure { cause, .. } => match cause.view() {
                    SciOxideErrorView::ConvergenceFailure { reason, .. } => {
                        (None, Some(format!("{reason:?}")))
                    }
                    _ => (None, Some(format!("{:?}", cause.kind()))),
                },
                _ => (None, None),
            };
            let kind = format!("{:?}", e.kind());
            (name, kind, argument, reason, None, None, None, None)
        }
    }
}
```

## Summary

With `Bounds`, no method evaluates outside bounds.
When room is less than the step, fixed central differences switch to roomier-side one-sided $\{0, h, 2h\}$ ($\{0, h, 2h, 3h\}$ for second derivatives), retaining second order with leading coefficients and rounding guidelines several times central ones.
Node shape and errors do not depend on boundary distance, keeping near-boundary errors comparable to interior errors rather than growing as $1/a$ like distance-shrunk asymmetric nodes.
Adaptive differences use the same per-level rule and converge with interior-like accuracy near boundaries, but restart tables when steps cross boundary distance; inspect termination and estimates.
Directional derivatives use the same rule with linewise room; node differences reject out-of-bounds nodes.
Equal-bound coordinates give errors by default; only `FiniteDifference` gradients and first derivatives can treat them as 0 with `FeasibleZero`; other methods stop because nodes cannot fit.
