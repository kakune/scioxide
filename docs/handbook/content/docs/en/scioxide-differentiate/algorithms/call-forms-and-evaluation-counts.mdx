[Shared contracts and structure of numerical-differentiation algorithms](oxref:differentiate-call-forms-terms) defines one-shot, owned, and borrowed call forms and evaluation and iteration counting.
This page computes the same gradient through each form and family to check those rules empirically.
There are four checks.

- All three forms return identical values, and borrowed forms stopped by evaluation limits publish none.
- Reported evaluations equal actual function calls.
- Evaluations and iterations follow family-specific formulas.
- Nine one-shot functions return default-setting values matching each method's accuracy guidelines.

Reports and publication after limits, cancellation, and deadlines are covered in [Evaluation limits, reports, and result publication](../budgets-reports-and-publication/).

## Cyclic-sum function

The experiments use the following function of $n$ variables:

$$
f(\mathbf{x}) = \sum_{i=0}^{n-1} e^{x_i} \sin x_{i+1} \quad (x_n = x_0)
$$


The evaluation point is $x_i = 0.3 + 0.2\,i$.
The following block defines shared functions for two cells: `cyclic` represents $f$, and `cyclic_complex` is the complex version of the same expression for complex steps.
$e^{z}$ and $\sin z$ are holomorphic and real-valued on the real axis, making `cyclic_complex` an analytic extension of $f$.

```rust
//| id: differentiate-cyclic-model
//| kind: definitions
//| title: "Cyclic-sum function and complex version"
//| crates: [scioxide-core]
use scioxide_core::{Complex, RealScalar};

/// f(x) = Σᵢ e^{xᵢ} sin x_{i+1} (cyclic indices).
pub(crate) fn cyclic(p: &[f64]) -> f64 {
    (0..p.len())
        .map(|i| RealScalar::exp(p[i]) * RealScalar::sin(p[(i + 1) % p.len()]))
        .sum()
}

/// Analytic extension evaluating the same expression with complex numbers.
pub(crate) fn cyclic_complex(z: &[Complex<f64>]) -> Complex<f64> {
    (0..z.len()).fold(Complex::new(0.0, 0.0), |s, i| {
        s + z[i].exp() * z[(i + 1) % z.len()].sin()
    })
}
```

## Three forms and evaluation limits

The first cell computes the gradient for $n = 3$ through three forms of fixed-step central differences.
One-shot `gradient` returns only values; owned `FiniteDifference::gradient` returns report and values.
The output-buffer API `gradient_into` receives evaluation limit $B$, with $B$ varied by input.
The borrowed output starts filled with 7; after evaluation, changed components are counted.
For each form, the table shows termination, internally counted function calls, reported evaluations and iterations, publication, maximum difference from one-shot values, and changed borrowed-output components.

```rust
//| id: differentiate-call-forms
//| ref: differentiate-call-forms
//| title: "One-shot, owned, and borrowed forms and evaluation limits"
//| run: reactive
//| uses: [differentiate-cyclic-model]
//| crates: [scioxide-core, scioxide-differentiate]
//| inputs:
//|   limit: {"type":"range","label":"Evaluation limit B","description":"Evaluation limit supplied to borrowed central differences.","min":1,"max":10,"step":1,"value":5}
//| cases:
//|   - {"id":"enough-budget","label":"B = 7","description":"The limit covers central count 2n + 1 = 7, so the borrowed form completes and publishes the same values as the one-shot function.","inputs":{"limit":7}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"forms","path":"/rows/0/2","equals":7}
//|       - {"artifact":"forms","path":"/rows/1/1","equals":"Completed"}
//|       - {"artifact":"forms","path":"/rows/1/3","equals":7}
//|       - {"artifact":"forms","path":"/rows/1/6","equals":0}
//|       - {"artifact":"forms","path":"/rows/2/1","equals":"EvaluationLimit"}
//|       - {"artifact":"forms","path":"/rows/2/2","equals":5}
//|       - {"artifact":"forms","path":"/rows/2/3","equals":5}
//|       - {"artifact":"forms","path":"/rows/2/5","equals":"No"}
//|       - {"artifact":"forms","path":"/rows/2/6","equals":null}
//|       - {"artifact":"forms","path":"/rows/2/7","equals":0}
//|   - case: enough-budget
//|     expect:
//|       - {"artifact":"forms","path":"/rows/2/1","equals":"Completed"}
//|       - {"artifact":"forms","path":"/rows/2/3","equals":7}
//|       - {"artifact":"forms","path":"/rows/2/6","equals":0}
//|       - {"artifact":"forms","path":"/rows/2/7","equals":3}
use core::cell::Cell;
use scioxide_core::{Budget, BudgetKind, ExecutionContext, SciOxideError, SolveBudgets};
use scioxide_differentiate::{
    DerivativeRequest, DerivativeShape, FiniteDifference, FiniteDifferenceWorkspace, gradient,
};

let n = 3;
let x: Vec<f64> = (0..n).map(|i| 0.3 + 0.2 * i as f64).collect();
// Count actual function calls separately from the report.
let calls = Cell::new(0_usize);
let f = |p: &[f64], y: &mut [f64]| {
    calls.set(calls.get() + 1);
    y[0] = cyclic(p);
    Ok::<(), SciOxideError>(())
};
let one_shot = |p: &[f64]| {
    calls.set(calls.get() + 1);
    Ok(cyclic(p))
};
// One-shot function: returns values only.
let reference = gradient(one_shot, &x).map_err(|e| e.to_string())?;
let one_shot_calls = calls.replace(0);
let gap = |v: &[f64]| {
    v.iter()
        .zip(&reference)
        .fold(0.0_f64, |m, (a, b)| m.max((a - b).abs()))
};
// Owned: result includes report, values, and estimated errors (absent for fixed steps).
let method = FiniteDifference::default();
let owned = method
    .gradient(&f, &x, None, None)
    .map_err(|e| e.to_string())?;
let owned_calls = calls.replace(0);
// Borrowed: reserve workspace and call with evaluation limit B; fill output with 7 first.
let budget = Budget::try_from(limit as usize).map_err(|e| e.to_string())?;
let limited =
    method.with_budgets(SolveBudgets::unbounded().with_limit(BudgetKind::Evaluation, budget));
let request = DerivativeRequest::new(&limited, DerivativeShape::gradient(n));
let mut workspace = FiniteDifferenceWorkspace::workspace(request).map_err(|e| e.to_string())?;
let mut out = vec![7.0; n];
let context = ExecutionContext::sequential();
let report = limited
    .gradient_into(&f, &x, None, None, &mut out, &mut workspace, context)
    .map_err(|e| e.to_string())?;
let borrowed_calls = calls.replace(0);
let changed = out.iter().filter(|&&v| v != 7.0).count();
let written = report.output_available().then_some(&out[..]);
let shown = |available: bool| if available { "Yes" } else { "No" };
let reports = [
    (owned.report(), owned_calls, owned.values(), None),
    (&report, borrowed_calls, written, Some(changed)),
];
// (Form, termination, counted calls, evaluations, iterations, published, one-shot difference, changed components)
let mut rows = vec![(
    "One-shot function",
    None,
    one_shot_calls,
    None,
    None,
    "Yes",
    Some(0.0),
    None,
)];
let forms = ["Owned", "Borrowed"];
for (form, (r, counted, values, touched)) in forms.into_iter().zip(reports) {
    rows.push((
        form,
        Some(r.termination().to_string()),
        counted,
        Some(r.evaluations()),
        Some(r.iterations()),
        shown(r.output_available()),
        values.map(&gap),
        touched,
    ));
}
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let columns = serde_json::json!([
    { "key": "0", "label": "Form" },
    { "key": "1", "label": "Termination reason", "nullText": "No report" },
    { "key": "2", "label": "Counted calls [count]", "type": "integer" },
    { "key": "3", "label": "Evaluations [count]", "type": "integer", "nullText": "No report" },
    { "key": "4", "label": "Iterations [count]", "type": "integer", "nullText": "No report" },
    { "key": "5", "label": "Published" },
    { "key": "6", "label": "Difference from gradient [-]", "type": "number", "format": sci3, "nullText": "No values" },
    { "key": "7", "label": "Changed output components [count]", "type": "integer", "nullText": "No array" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "forms" })
);
```

At default $B = 5$, one-shot and owned forms both evaluate $2n + 1 = 7$ times and return identical values (difference 0).
Internally counted calls match reported evaluations; owned iterations equal the 3 coordinates.
The borrowed form evaluates the base and coordinates 0 and 1 in 5 calls; entering coordinate 2's iteration, its sixth evaluation is rejected, stopping with `EvaluationLimit`.
Iterations are 3 because coordinate 2's iteration was charged before evaluation rejection.
No values are published; all 3 output entries remain at their initial 7.
At $B = 7$, the output-buffer form also completes, publishes the same values as the owned and one-shot forms, and overwrites all 3 outputs.
Any $B$ at most 6 stops the output-buffer form with `EvaluationLimit` without publication.

## Evaluation and iteration counts by family

The second cell takes variable count $n$ and computes the same gradient with owned forms of four families.
Node method `RelativeDifference` receives displacements $(-0.01, 0, 0.01)$ for each coordinate.
The table's “Evaluation formula” is $n + 1$ for forward differences, $2n + 1$ for central differences, $n + 1$ for complex steps, $3n$ for `RelativeDifference`, and $1 + 2 \times (\text{iterations})$ for adaptive differences.
The adaptive formula adds 1 evaluation of $f(\mathbf{x})$ to 2 central-difference samples per coordinate per level.

```rust
//| id: differentiate-evaluation-counts
//| ref: differentiate-evaluation-counts
//| title: "Evaluation and iteration counts by family"
//| run: reactive
//| uses: [differentiate-cyclic-model]
//| crates: [scioxide-core, scioxide-differentiate]
//| inputs:
//|   n: {"type":"range","label":"Variable count n","description":"Evaluation-point length.","min":1,"max":8,"step":1,"value":3}
//| cases:
//|   - {"id":"eight-variables","label":"n = 8","description":"Fixed-step, complex-step, and node evaluation counts grow linearly in n, with iterations equal to n.","inputs":{"n":8}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"counts","path":"/rows/0/2","equals":4}
//|       - {"artifact":"counts","path":"/rows/0/4","equals":3}
//|       - {"artifact":"counts","path":"/rows/1/2","equals":7}
//|       - {"artifact":"counts","path":"/rows/2/2","equals":35}
//|       - {"artifact":"counts","path":"/rows/2/4","equals":17}
//|       - {"artifact":"counts","path":"/rows/2/5","equals":35}
//|       - {"artifact":"counts","path":"/rows/3/2","equals":4}
//|       - {"artifact":"counts","path":"/rows/4/2","equals":9}
//|   - case: eight-variables
//|     expect:
//|       - {"artifact":"counts","path":"/rows/0/2","equals":9}
//|       - {"artifact":"counts","path":"/rows/1/2","equals":17}
//|       - {"artifact":"counts","path":"/rows/1/4","equals":8}
//|       - {"artifact":"counts","path":"/rows/3/2","equals":9}
//|       - {"artifact":"counts","path":"/rows/4/2","equals":24}
use core::cell::Cell;
use scioxide_core::{Complex, SciOxideError};
use scioxide_differentiate::{
    AdaptiveDifference, ComplexStep, DerivativeOperation, DifferenceScheme,
    DifferentiationResult, FiniteDifference, NodeDifferenceOptions, RelativeDifference,
};

let n = n as usize;
let x: Vec<f64> = (0..n).map(|i| 0.3 + 0.2 * i as f64).collect();
// Count actual function calls separately from the report.
let calls = Cell::new(0_usize);
let f = |p: &[f64], y: &mut [f64]| {
    calls.set(calls.get() + 1);
    y[0] = cyclic(p);
    Ok::<(), SciOxideError>(())
};
let g = |z: &[Complex<f64>], y: &mut [Complex<f64>]| {
    calls.set(calls.get() + 1);
    y[0] = cyclic_complex(z);
    Ok::<(), SciOxideError>(())
};
let forward = FiniteDifference::default().with_scheme(DifferenceScheme::Forward);
let offsets = [-0.01, 0.0, 0.01];
let lists = vec![&offsets[..]; n];
let options = NodeDifferenceOptions::default();
let relative = RelativeDifference::new(DerivativeOperation::Gradient, &lists, 1, options)
    .map_err(|e| e.to_string())?;
let mut rows = Vec::new();
let mut record =
    |name, result: Result<DifferentiationResult<f64>, _>, formula: Option<usize>| {
        let result = result.map_err(|e: scioxide_core::SciOxideError| e.to_string())?;
        let r = result.report();
        // Adaptive gradients evaluate f(x) once and each coordinate twice per level.
        let formula = formula.unwrap_or(1 + 2 * r.iterations());
        let termination = r.termination().to_string();
        let counted = calls.replace(0);
        rows.push((
            name,
            termination,
            counted,
            r.evaluations(),
            r.iterations(),
            formula,
        ));
        Ok::<(), String>(())
    };
record(
    "Forward difference",
    forward.gradient(&f, &x, None, None),
    Some(n + 1),
)?;
let central = FiniteDifference::default();
record(
    "Central difference",
    central.gradient(&f, &x, None, None),
    Some(2 * n + 1),
)?;
let adaptive = AdaptiveDifference::default();
record("Adaptive difference", adaptive.gradient(&f, &x, None), None)?;
record(
    "Complex-step method",
    ComplexStep::default().gradient(&g, &x),
    Some(n + 1),
)?;
record(
    "RelativeDifference",
    relative.evaluate(&f, &x, None),
    Some(3 * n),
)?;
let columns = serde_json::json!([
    { "key": "0", "label": "Method" },
    { "key": "1", "label": "Termination reason" },
    { "key": "2", "label": "Counted calls [count]", "type": "integer" },
    { "key": "3", "label": "Evaluations [count]", "type": "integer" },
    { "key": "4", "label": "Iterations [count]", "type": "integer" },
    { "key": "5", "label": "Evaluation formula [count]", "type": "integer" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "counts" })
);
```

At default $n = 3$, every row's actual calls, reported evaluations, and formula agree.
Forward differences take $n + 1 = 4$ calls, central differences $2n + 1 = 7$, and complex steps $n + 1 = 4$; all have 3 coordinate iterations.
One of the $n + 1$ complex-step calls evaluates the base to check real-valuedness.
`RelativeDifference` evaluates the zero-displacement node as the point itself, without a separate base evaluation, giving $3n = 9$ calls.
Adaptive differences use 17 iterations (sum of levels over 3 coordinates) and 35 evaluations, matching $1 + 2 \times 17$.
Adaptive termination `Converged` means estimates met tolerance, unlike `Completed` in other families.
At $n = 8$, fixed-step, complex-step, and `RelativeDifference` evaluation counts become $9$, $17$, $9$, and $24$ as predicted, with 8 iterations.
Adaptive differences take 47 iterations and 95 evaluations; levels per coordinate vary little with $n$.

## Nine one-shot functions

One-shot functions run a default method once, returning derivative values only and converting unsuccessful termination into errors.
The next cell applies each of nine functions once to small functions with hand-derived derivatives and tabulates maximum exact-value errors.
Scalar functions use $f(x) = \sin x$; multivariate functions use $f(\mathbf{x}) = e^{x_0} \sin x_1$ and $\mathbf{F}(\mathbf{x}) = (x_0 x_1, \sin x_0)$ at $(x_0, 0.7)$ in direction $\mathbf{v} = (1, -1)$.
`physical_difference_derivative` receives 4 nodes $x_0 \pm 0.01$ and $x_0 \pm 0.02$ spaced by $0.01$; `sparse_jacobian` receives $(x_0^2, x_1^2)$ with a diagonal Jacobian and coloring assigning both columns the same color.
Exact-value references use f64's inherent methods.

```rust
//| id: differentiate-one-shot-functions
//| ref: differentiate-one-shot-functions
//| title: "Nine one-shot functions and errors against exact values"
//| run: reactive
//| crates: [scioxide-core, scioxide-differentiate]
//| inputs:
//|   x0: {"type":"range","label":"Evaluation point x0","description":"Scalar evaluation point and first multivariate coordinate.","min":-3.0,"max":3.0,"step":0.25,"value":1.0}
//| cases:
//|   - {"id":"large-point","label":"x0 = 3","description":"Default steps scale with max(1, |x0|), so large |x0| changes fixed-step error magnitudes, but every function succeeds.","inputs":{"x0":3.0}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"one-shots","path":"/rows/0/3","range":{"max":1e-9}}
//|       - {"artifact":"one-shots","path":"/rows/1/3","range":{"max":1e-6}}
//|       - {"artifact":"one-shots","path":"/rows/2/3","range":{"max":1e-15}}
//|       - {"artifact":"one-shots","path":"/rows/3/3","range":{"max":1e-8}}
//|       - {"artifact":"one-shots","path":"/rows/4/3","range":{"max":1e-9}}
//|       - {"artifact":"one-shots","path":"/rows/5/3","range":{"max":1e-6}}
//|       - {"artifact":"one-shots","path":"/rows/6/3","range":{"max":1e-9}}
//|       - {"artifact":"one-shots","path":"/rows/7/3","range":{"max":1e-9}}
//|       - {"artifact":"one-shots","path":"/rows/8/3","range":{"max":1e-8}}
//|       - {"artifact":"one-shots","path":"/rows/5/2","equals":4}
//|   - case: large-point
//|     expect:
//|       - {"artifact":"one-shots","path":"/rows/0/3","range":{"max":1e-9}}
//|       - {"artifact":"one-shots","path":"/rows/2/3","range":{"max":1e-15}}
//|       - {"artifact":"one-shots","path":"/rows/8/3","range":{"max":1e-8}}
use scioxide_core::{
    ColoringKind, ColoringSchedule, Complex, SciOxideError, RealScalar, StructuralPattern,
};
use scioxide_differentiate::{
    complex_step_derivative, derivative, gradient, hessian, jacobian, jvp,
    physical_difference_derivative, second_derivative, sparse_jacobian,
};

let sine = |t: f64| Ok::<f64, SciOxideError>(RealScalar::sin(t));
let surface = |p: &[f64]| Ok::<f64, SciOxideError>(RealScalar::exp(p[0]) * RealScalar::sin(p[1]));
let map = |p: &[f64], y: &mut [f64]| {
    y[0] = p[0] * p[1];
    y[1] = RealScalar::sin(p[0]);
    Ok::<(), SciOxideError>(())
};
let x = [x0, 0.7];
let v = [1.0, -1.0];
// References (f64 inherent methods).
let (e, s, c) = (x0.exp(), x[1].sin(), x[1].cos());
let jacobian_exact = [x[1], x0, x0.cos(), 0.0];
let max_error = |values: &[f64], exact: &[f64]| {
    values
        .iter()
        .zip(exact)
        .map(|(a, b)| (a - b).abs())
        .fold(0.0, f64::max)
};
let nodes = [x0 - 0.02, x0 - 0.01, x0 + 0.01, x0 + 0.02];
let pattern =
    StructuralPattern::new(2, 2, vec![0, 1, 2], vec![0, 1]).map_err(|e| e.to_string())?;
let schedule = ColoringSchedule::new(pattern, ColoringKind::DerivativeColumns, vec![0, 0])
    .map_err(|e| e.to_string())?;
let squares = |p: &[f64], y: &mut [f64]| {
    y[0] = p[0] * p[0];
    y[1] = p[1] * p[1];
    Ok::<(), SciOxideError>(())
};
let values: Vec<(&str, &str, Vec<f64>, Vec<f64>)> = vec![
    (
        "derivative",
        "Central difference",
        vec![derivative(sine, x0).map_err(|e| e.to_string())?],
        vec![x0.cos()],
    ),
    (
        "second_derivative",
        "Central difference",
        vec![second_derivative(sine, x0).map_err(|e| e.to_string())?],
        vec![-x0.sin()],
    ),
    (
        "complex_step_derivative",
        "Complex-step method",
        vec![
            complex_step_derivative(|z: Complex<f64>| Ok(z.sin()), x0)
                .map_err(|e| e.to_string())?,
        ],
        vec![x0.cos()],
    ),
    (
        "physical_difference_derivative",
        "4-node weights",
        vec![physical_difference_derivative(sine, x0, &nodes).map_err(|e| e.to_string())?],
        vec![x0.cos()],
    ),
    (
        "gradient",
        "Central difference",
        gradient(surface, &x).map_err(|e| e.to_string())?,
        vec![e * s, e * c],
    ),
    (
        "hessian",
        "Central difference",
        hessian(surface, &x).map_err(|e| e.to_string())?,
        vec![e * s, e * c, e * c, -e * s],
    ),
    (
        "jacobian",
        "Central difference",
        jacobian(map, &x, 2).map_err(|e| e.to_string())?,
        jacobian_exact.to_vec(),
    ),
    (
        "jvp",
        "Central difference",
        jvp(map, &x, &v, 2).map_err(|e| e.to_string())?,
        vec![x[1] - x0, x0.cos()],
    ),
    (
        "sparse_jacobian",
        "Coloring and adaptive differences",
        sparse_jacobian(squares, &x, &schedule).map_err(|e| e.to_string())?,
        vec![2.0 * x0, 2.0 * x[1]],
    ),
];
let rows: Vec<(&str, &str, usize, f64)> = values
    .iter()
    .map(|(name, method, got, exact)| (*name, *method, got.len(), max_error(got, exact)))
    .collect();
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let columns = serde_json::json!([
    { "key": "0", "label": "One-shot function" },
    { "key": "1", "label": "Internal method" },
    { "key": "2", "label": "Components", "type": "integer" },
    { "key": "3", "label": "Maximum exact-value error [-]", "type": "number", "format": sci2 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "one-shots" })
);
```

At default $x_0 = 1$, all nine functions succeed; fixed-step first-derivative errors (`derivative`, `gradient`, `jacobian`, `jvp`) range from $10^{-12}$ to $10^{-11}$, below the central-difference guideline $\varepsilon^{2/3} \approx 3.7 \times 10^{-11}$.
The second-derivative methods `second_derivative` and `hessian` have errors $1.8 \times 10^{-9}$ and $5.1 \times 10^{-8}$, around the central second-derivative guideline $\sqrt{\varepsilon} \approx 1.5 \times 10^{-8}$.
`complex_step_derivative` avoids subtraction and has zero error.
The four-node `physical_difference_derivative` formula has fourth-order accuracy; error $1.8 \times 10^{-10}$ matches leading term $h^4 \lvert f^{(5)}(x_0) \rvert / 30 = 10^{-8} \cos 1 / 30$.
Each component of the `sparse_jacobian` function is quadratic, so central differences have no truncation error and errors stay at rounding scale $4.4 \times 10^{-16}$.
At $x_0 = 3$, default steps triple in proportion to $\max(1, \lvert x_0 \rvert)$, increasing `gradient` error to $7.4 \times 10^{-10}$ and `hessian` error to $3.1 \times 10^{-7}$.
These functions return neither estimates nor termination; use owned forms of the same computation to inspect accuracy or failure reasons.

## Summary

The three forms give identical values with identical settings, differing in report access and acceptance of workspace and context.
Evaluation-limited borrowed forms return `EvaluationLimit` without overwriting output, allowing termination to guide whether values can be used.
Reported evaluations equal actual calls and can directly estimate function-evaluation cost.
Gradient evaluations are $n + 1$ or $2n + 1$ for fixed steps, $n + 1$ for complex steps, total nodes for node differences, and $1 + 2 \times (\text{iterations})$ for adaptive differences; only adaptive cost varies with function properties.
One-shot default results match method-specific accuracy guidelines, but provide neither estimates nor termination; use owned forms to inspect accuracy.
