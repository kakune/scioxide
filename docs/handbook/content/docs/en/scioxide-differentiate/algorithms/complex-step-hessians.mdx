Formula $\operatorname{Im} f(x + ih)/h$ in [Complex-step differentiation and analytic extensions](../complex-step/) computes first derivatives without subtraction.
This page extends the idea to second derivatives, Hessians, and directional derivatives.
Second derivatives and Hessians combine complex-step first derivatives with real-node differences, reducing accuracy relative to first derivatives.
Directional derivatives are first-order quantities, obtained similarly from one complex evaluation along the direction.
The analytic-extension assumption and base check are unchanged ([Declaring analytic extensions](oxref:differentiate-analytic-extension)).
Notation follows [Shared algorithm contracts and structure](oxref:differentiate-notation); $\varepsilon = 2^{-52}$ is double-precision machine epsilon.

## Second derivatives and Hessians

Real-part second-derivative formula $f''(x) \approx 2(f(x) - \operatorname{Re} f(x + ih))/h^2$ contains subtraction, reintroducing cancellation.
`scioxide-differentiate` instead applies a real-node first-derivative difference formula to complex-step derivative $g(t) = \operatorname{Im} f(t + i h)/h$ to obtain the second derivative.

$$
f''(x) \approx \sum_a w_a \, g(x + \Delta_a) = \sum_a w_a \, \frac{\operatorname{Im} f(x + \Delta_a + i h)}{h}.
$$

Here $\Delta_a$ denotes real-node displacements and $w_a$ their first-derivative weights.
For central displacements $\{-\Delta, 0, \Delta\}$, weights are $\{-1/(2\Delta), 0, 1/(2\Delta)\}$, and the central expansion of $g$ gives truncation $\Delta^2 f^{(4)}(x)/6 + \Delta^4 f^{(6)}(x)/120 + \cdots$.
Values of $g$ have rounding error about $\varepsilon \lvert f' \rvert$, giving this total-error estimate.

$$
E(\Delta) \approx \frac{\Delta^2}{6} \lvert f^{(4)}(x) \rvert + \frac{\varepsilon \lvert f'(x) \rvert}{\Delta}.
$$

The estimate is minimized at about $\Delta_* = (3 \varepsilon \lvert f' \rvert / \lvert f^{(4)} \rvert)^{1/3}$, or $\varepsilon^{1/3}$, with minimum about $\varepsilon^{2/3}$.
Real three-point second differences have estimate $\Delta^2 \lvert f^{(4)} \rvert / 12 + 4 \varepsilon \lvert f \rvert / \Delta^2$, minimized at about $\Delta = (48 \varepsilon \lvert f \rvert / \lvert f^{(4)} \rvert)^{1/4}$, or $\varepsilon^{1/4}$, with minimum about $\varepsilon^{1/2}$.
Complex steps combined with real nodes improve on this but do not attain first-derivative accuracy of about $\varepsilon$.

For multivariate functions, obtain Hessian entry $(i, j)$ by applying coordinate-$j$ real-node stencils to derivative $\partial f / \partial x_i$ obtained by coordinate-$i$ imaginary perturbations.
For $i = j$, both perturbations act on the same coordinate, giving the univariate formula above.

## Real-node method values and Plans

The library does not select real nodes; callers supply them explicitly.
[`RelativeComplexStep`](https://docs.rs/scioxide-differentiate/0.1.0/scioxide_differentiate/struct.RelativeComplexStep.html)`::new(&[&offsets, …], method)` stores coordinatewise displacements placing nodes at $x_j + \Delta$ per evaluation and evaluates with `evaluate(f, x, bounds)`.
[`ComplexStepPlan`](https://docs.rs/scioxide-differentiate/0.1.0/scioxide_differentiate/struct.ComplexStepPlan.html)`::new(point, &[&nodes, …], method)` fixes evaluation point and node positions at construction and evaluates with `evaluate(f, bounds)`.
`method` is `ComplexStep` supplying imaginary steps and execution settings; steps and zero-direction policies are checked at construction.
Both require at least 2 distinct nodes per axis; too few give `InvalidInput` (`OutOfRange`), duplicates `InvalidInput` (`Inconsistent`).
Fornberg weights are computed at construction; `RelativeComplexStep` recomputes them per evaluation from rounded displacements.
Both compute Hessians; scalar second derivatives are $1 \times 1$ Hessians.
Supplying `bounds` checks the point and every node before function calls, returning `InvalidInput` if outside bounds.
`RelativeComplexStep` also rejects nonfinite displaced nodes or nodes merged by rounding with `InvalidInput` (`x`, `UnsupportedConfiguration`) before function calls.
Use borrowed `evaluate_into` and workspaces like other Plans ([Reusing Plans, requirements, and workspaces](../plans-workspaces-and-reports/)).
No estimates are returned; unless stopped by limits, termination is `Completed` without accuracy claims.

Both compute every ordered pair $(i, j)$ and symmetrize mixed terms by averaging $(i, j)$ and $(j, i)$.
This differs from fixed differences, which compute and reflect the upper triangle.
The sample $\partial f / \partial x_i (\mathbf{x})$ at a node matching the evaluation point is evaluated once per coordinate $i$.
If each axis includes the base point and axis $j$ has $k_j$ nodes, the count including one base check is $1 + n\bigl(\sum_j k_j - (n - 1)\bigr)$.
Axes without the base point increase this count, up to $1 + n \sum_j k_j$.
A scalar second derivative using `RelativeComplexStep` with $k$ nodes on one axis takes $1 + k$ evaluations.

## Measuring second-derivative errors

The next cell computes the second derivative of $f(x) = e^x \sin x$ with one-axis `RelativeComplexStep` and displacements $\{-\Delta, 0, \Delta\}$, varying $\Delta$ from $10^{-1}$ to $10^{-10}$.
For comparison, `FiniteDifference::second_derivative` computes real three-point second differences with the same $\Delta$.
The reference evaluates $f^{(n)}(x) = 2^{n/2} e^x \sin(x + n\pi/4)$ in f64.
The table shows evaluations, minimum error and its $\Delta$, and the estimate's minimizing $\Delta_*$ above.
The next cell plots error curves and estimates.

```rust
//| id: differentiate-complex-second-derivative
//| ref: differentiate-complex-second-derivative
//| title: "Errors of complex-step second derivatives with real nodes versus real second differences"
//| run: reactive
//| crates: [scioxide-core, scioxide-differentiate]
//| exports: [curves]
//| inputs:
//|   x0: {"type":"range","label":"Evaluation point x₀","min":-1.0,"max":1.0,"step":0.25,"value":0.5}
//| cases:
//|   - {"id":"vanishing-fourth","label":"x₀ = 0","description":"f⁽⁴⁾(0) = 0 eliminates the leading truncation term, leaving Δ⁴ terms.","inputs":{"x0":0.0}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"second","path":"/rows/0/1","equals":4}
//|       - {"artifact":"second","path":"/rows/0/2","range":{"max":1e-9}}
//|       - {"artifact":"second","path":"/rows/1/1","equals":3}
//|       - {"artifact":"second","path":"/rows/1/2","range":{"min":1e-11,"max":1e-6}}
//|       - {"artifact":"second","path":"/rows/0/4","approx":{"value":7.7825e-6,"rtol":1e-3}}
//|   - case: vanishing-fourth
//|     expect:
//|       - {"artifact":"second","path":"/rows/0/4","equals":null}
//|       - {"artifact":"second","path":"/rows/1/4","equals":null}
//|       - {"artifact":"second","path":"/rows/0/2","range":{"max":1e-10}}
use scioxide_core::{Complex, SciOxideError, RealScalar};
use scioxide_differentiate::{
    ComplexStep, DifferenceScheme, DifferenceStep, FiniteDifference, RelativeComplexStep,
};

let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
// Reference: f^{(n)}(x) = 2^{n/2} e^x sin(x + nπ/4), expanded separately for each n (f64 inherent methods).
let derivative = |n: i32, x: f64| {
    let (s, c) = x.sin_cos();
    x.exp()
        * match n {
            0 => s,
            1 => s + c,
            2 => 2.0 * c,
            4 => -4.0 * s,
            _ => -8.0 * c,
        }
};
let exact = derivative(2, x0);
let complex = |z: &[Complex<f64>], y: &mut [Complex<f64>]| {
    y[0] = z[0].exp() * z[0].sin();
    Ok::<(), SciOxideError>(())
};
let real = |t: f64| Ok::<f64, SciOxideError>(RealScalar::exp(t) * RealScalar::sin(t));
let method = ComplexStep::default();
// Curves: complex steps with real nodes, real second differences, and their error estimates.
let mut curves: Vec<Vec<[f64; 2]>> = vec![Vec::new(); 4];
let mut best = [(f64::INFINITY, 0.0, 0_usize); 2];
for k in 2..=20 {
    let delta = 10.0_f64.powf(-0.5 * f64::from(k));
    let offsets = [-delta, 0.0, delta];
    let second = RelativeComplexStep::new(&[&offsets], method).map_err(|e| e.to_string())?;
    let r = second
        .evaluate(complex, &[x0], None)
        .map_err(|e| e.to_string())?;
    let fd = FiniteDifference::default()
        .with_scheme(DifferenceScheme::Central)
        .with_step(DifferenceStep::absolute(delta).map_err(|e| e.to_string())?);
    let q = fd.second_derivative(real, x0).map_err(|e| e.to_string())?;
    let observed = [
        r.values().ok_or("Second derivative not published")?[0],
        q.values().ok_or("Second difference not published")?[0],
    ];
    let evaluations = [r.report().evaluations(), q.report().evaluations()];
    // Scale rounding-estimate terms with maximum |f′| and |f| at nodes.
    let nodes = [x0 - delta, x0, x0 + delta];
    let slope = nodes
        .iter()
        .map(|&t| derivative(1, t).abs())
        .fold(0.0, f64::max);
    let size = nodes
        .iter()
        .map(|&t| derivative(0, t).abs())
        .fold(0.0, f64::max);
    let (d2, d4) = (delta * delta, delta.powi(4));
    let models = [
        (d2 * derivative(4, x0) / 6.0 + d4 * derivative(6, x0) / 120.0).abs()
            + f64::EPSILON * slope / delta,
        (d2 * derivative(4, x0) / 12.0 + d4 * derivative(6, x0) / 360.0).abs()
            + 4.0 * f64::EPSILON * size / d2,
    ];
    for lane in 0..2 {
        let error = (observed[lane] - exact).abs();
        if error > 0.0 {
            curves[lane].push([delta, error]);
        }
        curves[lane + 2].push([delta, models[lane]]);
        if error < best[lane].0 {
            best[lane] = (error, delta, evaluations[lane]);
        }
    }
}
// Estimate minimum from the leading truncation term only (undefined if f⁽⁴⁾ = 0).
let fourth = derivative(4, x0).abs();
let optimum = [
    (fourth > 0.0).then(|| (3.0 * f64::EPSILON * derivative(1, x0).abs() / fourth).cbrt()),
    (fourth > 0.0).then(|| (48.0 * f64::EPSILON * derivative(0, x0).abs() / fourth).powf(0.25)),
];
let names = ["Complex steps with real nodes", "Real second differences"];
let rows: Vec<_> = names
    .iter()
    .zip(best)
    .zip(optimum)
    .map(|((name, (error, delta, evaluations)), star)| (*name, evaluations, error, delta, star))
    .collect();
let columns = serde_json::json!([
    { "key": "0", "label": "Method" },
    { "key": "1", "label": "Evaluations [count]", "type": "integer" },
    { "key": "2", "label": "Minimum error [-]", "type": "number", "format": sci3 },
    { "key": "3", "label": "Corresponding Δ [-]", "type": "number", "format": sci3 },
    { "key": "4", "label": "Estimate minimum Δ* [-]", "type": "number", "format": sci3, "nullText": "None" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "second" })
);
export!(curves, curves);
```

At default $x_0 = 0.5$, complex steps with real nodes ($1 + 3 = 4$ evaluations) attain minimum error $6.5 \times 10^{-11}$ at $\Delta = 10^{-5}$, consistent with the estimate's minimizing step $\Delta_* = 7.8 \times 10^{-6}$.
The minimum real-second-difference error $4.5 \times 10^{-10}$ ($\Delta = 10^{-4}$, 3 calls) occurs where truncation and rounding signs cancel, far below estimate $7.3 \times 10^{-8}$ at the same $\Delta$.
At $x_0 = 0$, $f^{(4)}(0) = 0$ removes the leading truncation term, leaving $\Delta^4$ and making tabulated $\Delta_*$ undefined.
Then $f(0) = 0$ also reduces real-second-difference rounding; both methods give errors at most about $10^{-13}$ at $\Delta = 10^{-3}$.

## Hessian evaluation counts

The next cell computes the Hessian of $g(x, y) = e^x \sin y$ at $(0.5, 1.5)$ with two-axis `RelativeComplexStep` and `ComplexStepPlan` fixing the same nodes.
Each axis has either 3 nodes including the base (displacements $\pm 10^{-5}$) or 5 (displacements $\pm 10^{-3}$, $\pm 2 \times 10^{-3}$).

```rust
//| id: differentiate-complex-hessian-jvp
//| ref: differentiate-complex-hessian-jvp
//| title: "Complex-step Hessian evaluation counts and symmetry"
//| run: reactive
//| crates: [scioxide-core, scioxide-differentiate]
//| inputs:
//|   stencil: {"type":"select","label":"Real nodes per axis","options":["3 nodes, Δ = 1e-5","5 nodes, Δ = 1e-3"],"value":"3 nodes, Δ = 1e-5"}
//| cases:
//|   - {"id":"five-point","label":"5 nodes, Δ = 10⁻³","description":"More nodes increase calls and truncation order, reducing errors.","inputs":{"stencil":"5 nodes, Δ = 1e-3"}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"counts","path":"/rows/0/1","equals":11}
//|       - {"artifact":"counts","path":"/rows/0/2","equals":11}
//|       - {"artifact":"counts","path":"/rows/0/3","range":{"max":1e-9}}
//|       - {"artifact":"counts","path":"/rows/0/4","equals":0}
//|       - {"artifact":"counts","path":"/rows/1/1","equals":11}
//|       - {"artifact":"counts","path":"/rows/1/4","equals":0}
//|   - case: five-point
//|     expect:
//|       - {"artifact":"counts","path":"/rows/0/1","equals":19}
//|       - {"artifact":"counts","path":"/rows/1/1","equals":19}
//|       - {"artifact":"counts","path":"/rows/0/3","range":{"max":1e-11}}
use scioxide_core::{Complex, SciOxideError};
use scioxide_differentiate::{ComplexStep, ComplexStepPlan, RelativeComplexStep};

let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let offsets: Vec<f64> = match stencil.as_str() {
    "5 nodes, Δ = 1e-3" => vec![-2e-3, -1e-3, 0.0, 1e-3, 2e-3],
    _ => vec![-1e-5, 0.0, 1e-5],
};
let p = [0.5_f64, 1.5];
let method = ComplexStep::default();
// Reference: Hessian of g = e^x sin y (f64 inherent methods).
let (e, (s, c)) = (p[0].exp(), p[1].sin_cos());
let exact = [e * s, e * c, e * c, -e * s];
let g = |z: &[Complex<f64>], y: &mut [Complex<f64>]| {
    y[0] = z[0].exp() * z[1].sin();
    Ok::<(), SciOxideError>(())
};
// Count formula 1 + n(Σ k_j − (n − 1)), n = 2, k nodes per axis.
let k = offsets.len();
let formula = 1 + 2 * (2 * k - 1);
let relative = RelativeComplexStep::new(&[offsets.as_slice(), offsets.as_slice()], method)
    .map_err(|e| e.to_string())?;
let nodes: Vec<Vec<f64>> = p
    .iter()
    .map(|&x| offsets.iter().map(|o| x + o).collect())
    .collect();
let plan = ComplexStepPlan::new(&p, &[nodes[0].as_slice(), nodes[1].as_slice()], method)
    .map_err(|e| e.to_string())?;
let hessians = [
    ("RelativeComplexStep", relative.evaluate(g, &p, None)),
    ("ComplexStepPlan", plan.evaluate(g, None)),
];
let mut rows = Vec::new();
for (name, result) in hessians {
    let r = result.map_err(|e| e.to_string())?;
    let h = r.values().ok_or("Hessian not published")?;
    let error = h
        .iter()
        .zip(exact)
        .map(|(a, b)| (a - b).abs())
        .fold(0.0, f64::max);
    rows.push((
        name,
        r.report().evaluations(),
        formula,
        error,
        (h[1] - h[2]).abs(),
    ));
}
let columns = serde_json::json!([
    { "key": "0", "label": "Method" },
    { "key": "1", "label": "Evaluations [count]", "type": "integer" },
    { "key": "2", "label": "Predicted evaluations [count]", "type": "integer" },
    { "key": "3", "label": "Maximum absolute error [-]", "type": "number", "format": sci3 },
    { "key": "4", "label": "Asymmetry [-]", "type": "number", "format": sci3 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "counts" })
);
```

With default 3-node stencils, both `RelativeComplexStep` and `ComplexStepPlan` use predicted $1 + 2 \times (6 - 1) = 11$ evaluations and have identical error $2.7 \times 10^{-11}$.
Averaging both orders gives exactly zero asymmetry.
Five nodes ($\Delta = 10^{-3}$) increase calls to $1 + 2 \times (10 - 1) = 19$, raise truncation order from 2 to 4, and reduce error to $2.8 \times 10^{-13}$.

## Directional derivatives

Directional derivative $\mathbf{J}\mathbf{v}$ of vector function $\mathbf{F}$ along $\mathbf{v}$ is the derivative of univariate $\boldsymbol{\varphi}(t) = \mathbf{F}(\mathbf{x} + t \mathbf{v})$ at $t = 0$.
Applying the first-derivative formula to $\boldsymbol{\varphi}$ gives it from one complex evaluation with an imaginary directional perturbation.

$$
\mathbf{J}(\mathbf{x}) \mathbf{v} = \frac{\operatorname{Im} \mathbf{F}(\mathbf{x} + i h \mathbf{v})}{h} + \frac{h^2}{6} \boldsymbol{\varphi}'''(0) + O(h^4).
$$

Without subtraction, shrinking steps causes no cancellation, as for first derivatives.

`jvp(f, x, v, m)` and borrowed `jvp_into` of `ComplexStep` accept directions at evaluation.
The step is unchanged from `ComplexStep` step $h$ (default $\varepsilon$); coordinate $i$ receives imaginary perturbation $h v_i$.
Unlike real directional differences ([Directional-difference formulas](oxref:differentiate-jvp-formula)), the step is not divided by direction magnitude.
Two evaluations are needed: one base check and one perturbation.
For any nonzero component $v_i$, $h v_i$ underflowing to 0 or becoming nonfinite gives `InvalidInput` (`direction`, `UnsupportedConfiguration`) before function calls.
Directions with subnormal $h v_i$ are accepted for evaluation, but a nonzero returned imaginary component $\operatorname{Im} \mathbf{F}$ becoming subnormal gives `NumericalInstability` (`Underflow`) without publication, as for first derivatives ([Imaginary perturbations](oxref:differentiate-complex-perturbation)).

Select exactly zero direction behavior with `ZeroDirectionPolicy` passed to `with_zero_direction` ([Zero directions](oxref:differentiate-zero-direction)).
`MathematicalZero` (default) returns 0 without function calls; `ValidateBase` evaluates the base once, checks real-valuedness, then returns 0.
Using `ComplexStep` with nondefault `ZeroDirectionPolicy` for nondirectional operations gives `InvalidInput` (`Inconsistent`).

The next cell computes the directional derivative of $\mathbf{F}(x, y) = (e^{x} y^2, \sin(x y))$ at $(0.5, 1.5)$ using `ComplexStep::jvp` and compares with hand-derived $\mathbf{J}\mathbf{v}$.
Directions are $(1, -2)$ multiplied by a scale factor selected through the input, and zero directions with two `ZeroDirectionPolicy` policies.
Count actual calls inside the cell and display them beside reported evaluations.
Relative error divides maximum componentwise error by the largest reference-component magnitude; zero directions use absolute error.

```rust
//| id: differentiate-complex-jvp
//| ref: differentiate-complex-jvp
//| title: "Complex-step directional derivatives, direction magnitude, and evaluations for zero directions"
//| run: reactive
//| crates: [scioxide-core, scioxide-differentiate]
//| inputs:
//|   direction: {"type":"select","label":"Direction v","options":["(1, −2)","(1, −2) × 10⁻³⁰⁰","(1, −2) × 10⁻³¹⁰"],"value":"(1, −2)"}
//| cases:
//|   - {"id":"subnormal","label":"v = (1, −2) × 10⁻³⁰⁰","description":"Imaginary perturbation hv becomes subnormal; the function runs twice but its imaginary response is also subnormal, giving an Underflow error.","inputs":{"direction":"(1, −2) × 10⁻³⁰⁰"}}
//|   - {"id":"underflow","label":"v = (1, −2) × 10⁻³¹⁰","description":"hv underflows to 0, causing rejection before function calls.","inputs":{"direction":"(1, −2) × 10⁻³¹⁰"}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"jvp","path":"/rows/0/1","equals":2}
//|       - {"artifact":"jvp","path":"/rows/0/2","equals":2}
//|       - {"artifact":"jvp","path":"/rows/0/3","range":{"max":1e-15}}
//|       - {"artifact":"jvp","path":"/rows/1/2","equals":0}
//|       - {"artifact":"jvp","path":"/rows/2/2","equals":1}
//|   - case: subnormal
//|     expect:
//|       - {"artifact":"jvp","path":"/rows/0/1","equals":null}
//|       - {"artifact":"jvp","path":"/rows/0/2","equals":2}
//|       - {"artifact":"jvp","path":"/rows/0/4","equals":"NumericalInstability（Underflow）"}
//|   - case: underflow
//|     expect:
//|       - {"artifact":"jvp","path":"/rows/0/2","equals":0}
//|       - {"artifact":"jvp","path":"/rows/0/4","equals":"InvalidInput（direction, UnsupportedConfiguration）"}
use scioxide_core::{Complex, SciOxideError, SciOxideErrorView};
use scioxide_differentiate::{ComplexStep, ZeroDirectionPolicy};

let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let scale = match direction.as_str() {
    "(1, −2) × 10⁻³⁰⁰" => 1e-300,
    "(1, −2) × 10⁻³¹⁰" => 1e-310,
    _ => 1.0,
};
let p = [0.5_f64, 1.5];
let calls = std::cell::Cell::new(0_usize);
// F(x, y) = (e^x y², sin(xy)). Count calls.
let field = |z: &[Complex<f64>], y: &mut [Complex<f64>]| {
    calls.set(calls.get() + 1);
    y[0] = z[0].exp() * z[1] * z[1];
    y[1] = (z[0] * z[1]).sin();
    Ok::<(), SciOxideError>(())
};
let v = [scale, -2.0 * scale];
// Reference: J v = (e^x y² v₀ + 2 e^x y v₁, cos(xy)(y v₀ + x v₁)) (f64 inherent methods).
let (e, cxy) = (p[0].exp(), (p[0] * p[1]).cos());
let exact = [
    e * p[1] * p[1] * v[0] + 2.0 * e * p[1] * v[1],
    cxy * (p[1] * v[0] + p[0] * v[1]),
];
let directions = [
    ("Direction v", v, ZeroDirectionPolicy::MathematicalZero, exact),
    (
        "Zero direction (MathematicalZero)",
        [0.0; 2],
        ZeroDirectionPolicy::MathematicalZero,
        [0.0; 2],
    ),
    (
        "Zero direction (ValidateBase)",
        [0.0; 2],
        ZeroDirectionPolicy::ValidateBase,
        [0.0; 2],
    ),
];
let mut rows = Vec::new();
for (name, direction, policy, reference) in directions {
    calls.set(0);
    let method = ComplexStep::default().with_zero_direction(policy);
    let (evaluations, error, failure) = match method.jvp(field, &p, &direction, 2) {
        Ok(r) => {
            let jv = r.values().ok_or("Directional derivative not published")?;
            let size = reference[0].abs().max(reference[1].abs());
            let gap = (jv[0] - reference[0])
                .abs()
                .max((jv[1] - reference[1]).abs());
            let error = if size > 0.0 { gap / size } else { gap };
            (Some(r.report().evaluations()), Some(error), None)
        }
        // Retain only direction-check rejection and imaginary underflow in the table; propagate other errors as cell errors.
        Err(e) => match e.view() {
            SciOxideErrorView::InvalidInput {
                argument, reason, ..
            } => {
                let detail = format!("InvalidInput（{}, {reason:?}）", argument.as_str());
                (None, None, Some(detail))
            }
            SciOxideErrorView::NumericalInstability { issue, .. } => (
                None,
                None,
                Some(format!("NumericalInstability（{issue:?}）")),
            ),
            _ => return Err(e.to_string()),
        },
    };
    rows.push((name, evaluations, calls.get(), error, failure));
}
let columns = serde_json::json!([
    { "key": "0", "label": "Computation" },
    { "key": "1", "label": "Reported evaluations [count]", "type": "integer", "nullText": "—" },
    { "key": "2", "label": "Function calls [count]", "type": "integer" },
    { "key": "3", "label": "Relative error [-]", "type": "number", "format": sci3, "nullText": "—" },
    { "key": "4", "label": "Error", "nullText": "None" }
]);
emit_table_with_columns!(columns, rows, metadata = serde_json::json!({ "id": "jvp" }));
```

For default direction $(1, -2)$, reported evaluations and actual calls both equal 2; relative error $1.4 \times 10^{-16}$ is at rounding scale.
Scaling the direction by $10^{-300}$ makes imaginary perturbation $h v_i$ subnormal, about $2 \times 10^{-316}$.
The function runs twice, but the returned imaginary part is also subnormal with lost significant digits, giving `NumericalInstability` (`Underflow`) without publication.
Scaling by $10^{-310}$ underflows $h v_i$ to 0, causing `InvalidInput` (`direction`, `UnsupportedConfiguration`) before any function call.
For zero directions, `MathematicalZero` makes no call and `ValidateBase` makes only one base check.

## Summary

Complex steps obtain first-order quantities without subtraction; second derivatives and Hessians apply real-node first-derivative stencils to complex-step first derivatives.
Three-node error estimates are $\Delta^2 \lvert f^{(4)} \rvert / 6 + \varepsilon \lvert f' \rvert / \Delta$, limiting accuracy to about $\varepsilon^{2/3}$; callers choose displacements around $\varepsilon^{1/3}$.
Rounding grows more slowly than for real second differences and is less sensitive to displacement choice, often favoring this method for complex-evaluable functions even at second order.
Use `RelativeComplexStep` when points move or `ComplexStepPlan` for repeated fixed points and nodes; both take $1 + n\bigl(\sum_j k_j - (n - 1)\bigr)$ evaluations and symmetrize mixed terms.
Directional `ComplexStep::jvp` takes 2 calls; choose directions keeping imaginary perturbation $h v_i$ and response normal.
