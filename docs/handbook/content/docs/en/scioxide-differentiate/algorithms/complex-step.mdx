Real differences lose significant digits when subtracting close values as steps shrink, imposing an error floor.
If a function accepts complex arguments and is analytic near the real axis, imaginary steps obtain first derivatives without subtraction.
This is the complex-step method (Lyness and Moler 1967; Squire and Trapp 1998).
This page explains its derivation, errors, assumptions and `scioxide-differentiate` checks, first-derivative APIs, and behavior when assumptions fail.
Extensions to second derivatives, Hessians, and directions appear in [Complex-step second derivatives, Hessians, and directional derivatives](../complex-step-hessians/).
Notation follows [Shared algorithm contracts and structure](oxref:differentiate-notation); $\varepsilon = 2^{-52}$ is double-precision machine epsilon.

## Imaginary perturbations

Assume $f$ is real-valued on the real axis and analytic (complex-differentiable) nearby.
A Taylor expansion with imaginary step $h > 0$ separates even terms into the real part and odd terms into the imaginary part.

$$
f(x + i h) = f(x) + i h f'(x) - \frac{h^2}{2} f''(x) - i \frac{h^3}{6} f'''(x) + \frac{h^4}{24} f^{(4)}(x) + \cdots .
$$

Extracting the imaginary part and dividing by $h$ approximates the first derivative.

$$
\frac{\operatorname{Im} f(x + i h)}{h} = f'(x) - \frac{h^2}{6} f'''(x) + O(h^4).
$$

Truncation error is $O(h^2)$, with leading relative term $(h^2/6) \lvert f'''(x)/f'(x) \rvert$.
Without subtraction, shrinking $h$ causes no cancellation.
Real differences balance truncation against rounding; complex steps need only reduce $h$ until truncation is hidden by rounding.
At default step $h = \varepsilon$, relative truncation is $8.2 \times 10^{-33} \lvert f'''/f' \rvert$, below $\varepsilon$ when $\lvert f'''/f' \rvert \le 2 \times 10^{16}$.

Attainable accuracy depends on how accurately complex operations and elementary functions compute imaginary parts.
For sufficiently small $h$, imaginary-part computation performs the same operations as forward automatic differentiation (Martins et al. 2003).
Many functions give relative errors of a few times $\varepsilon$, without a guarantee.

The lower limit on $h$ requires $\operatorname{Im} f(x + ih) \approx h f'(x)$ to remain normal: $\lvert h f'(x) \rvert$ must be at least minimum normal `MIN_POSITIVE` ($2.2 \times 10^{-308}$ in f64).
Subnormal imaginary parts lose significant digits; `scioxide-differentiate` therefore returns `NumericalInstability` (`Underflow`) without publishing when a nonzero imaginary part becomes subnormal or $\operatorname{Im} f / h$ rounds to 0.
An exactly zero imaginary part returns derivative 0 without error.
Returned values cannot distinguish a truly zero derivative from a function whose imaginary part rounded to zero internally.
Step $h$ itself must also be at least `MIN_POSITIVE`; subnormal steps are rejected before function calls with `InvalidInput` (`OutOfRange`).
At default $h = \varepsilon$, the imaginary part remains normal when $\lvert f'(x) \rvert$ is at least $1/\varepsilon$ times `MIN_POSITIVE` (about $10^{-292}$).

Complex steps obtain first derivatives (including gradients, Jacobians, and directional derivatives) without subtraction; second derivatives require combination with real nodes ([Second derivatives and Hessians](oxref:differentiate-complex-second)).
Complex function evaluation costs a few times a real evaluation.

## Declaring analytic extensions

The method assumes the supplied complex function is an analytic extension of a real function.
An analytic extension is analytic near the real axis and equals the original real function on it.
In `scioxide-differentiate`, callers assert this assumption by passing complex-point functions to types such as [`ComplexStep`](https://docs.rs/scioxide-differentiate/0.1.0/scioxide_differentiate/struct.ComplexStep.html), without a wrapper type.
The assertion is neither checked nor proved.
These operations generally violate it and may silently return wrong derivatives.

- Conjugation $\bar z$, absolute value $\lvert z \rvert$, and extraction of real or imaginary parts alone.
- Branches depending on the imaginary part.
- Real-only functions applied to the real part, discarding the imaginary perturbation.

Branches based on real parts preserve assumptions when each branch is analytic.
For example, writing $\lvert x \rvert$ as “$-z$ if the real part is negative, otherwise $z$” gives the correct derivative at $x \ne 0$.

Only one inexpensive consequence of the assumptions is checked: real values at real-axis points.
Evaluate $f(x)$ at base $x$; a nonzero imaginary part gives `InvalidInput` (`function`, `UnsupportedConfiguration`).
This value is unused in the first-derivative formula, so gradients take $n + 1$ calls: one base check plus one per coordinate.

## ComplexStep

[`ComplexStep`](https://docs.rs/scioxide-differentiate/0.1.0/scioxide_differentiate/struct.ComplexStep.html) is the complex-step method value, storing imaginary step $h$ shared by all coordinates.
The default step is $h = \varepsilon$, changed with `with_step(h)`.
`ComplexStep` checks steps per evaluation: nonfinite steps give `NonFinite` (cause `Input`); steps below `MIN_POSITIVE` (nonpositive or subnormal) give `InvalidInput` (`self`, `OutOfRange`).
Methods select first-derivative operations `derivative(f, x)`, `gradient(f, x)`, `jacobian(f, x, m)`, and `jvp(f, x, v, m)`.
Gradients, Jacobians, and directions also have borrowed `gradient_into`, `jacobian_into`, and `jvp_into`; `derivative` has no borrowed form.
First-derivative perturbations move only imaginary parts, keeping real point $x$ unchanged, so no bounds `bounds` are accepted.
Set execution policy, evaluation limits, and workspace limits with `with_execution`, `with_budgets`, and `with_max_workspace_bytes`.

`f` for `derivative` accepts and returns complex numbers; other operations' `f` accepts complex-point arrays and writes complex values.
Returned derivatives are real, without estimates; termination is `Completed` unless evaluation or iteration limits intervene.
`Completed` indicates only planned evaluation completion, without accuracy claims.
Directional `jvp` takes 2 calls: a base check and an imaginary perturbation along the direction ([Directional derivatives](oxref:differentiate-complex-directional)).
Scalar first derivatives have one-shot [`complex_step_derivative`](https://docs.rs/scioxide-differentiate/0.1.0/scioxide_differentiate/fn.complex_step_derivative.html)`(f, x)`, which takes 2 evaluations at step $h = \varepsilon$ and returns only the value.

## Comparison with real differences

The next cell computes the first derivative of Squire and Trapp's example $f(x) = e^x / \sqrt{\sin^3 x + \cos^3 x}$ with real differences and complex steps, varying $h$ from $10^{-1}$ to $10^{-300}$.
Real differences use fixed-step `FiniteDifference`; complex steps use `derivative` on `ComplexStep` with changed steps, with complex functions written using scioxide-core `Complex` operations.
The reference evaluates the derivative formula in f64; the vertical axis is relative error against it.
Exactly zero relative errors and steps whose nodes merge under rounding cannot be plotted logarithmically; the table counts them.
A “—” in table column $h = 10^{-300}$ means merged nodes prevented a difference.

```rust
//| id: differentiate-complex-step-sweep
//| ref: differentiate-complex-step-sweep
//| title: "Relative errors of real differences and complex steps versus step size"
//| run: reactive
//| crates: [scioxide-core, scioxide-differentiate]
//| inputs:
//|   x0: {"type":"range","label":"Evaluation point x₀","min":0.5,"max":1.5,"step":0.25,"value":1.5}
//|   scheme: {"type":"select","label":"Real-difference formula","options":["Central difference","Forward difference"],"value":"Central difference"}
//| cases:
//|   - {"id":"forward","label":"Forward difference","description":"O(h) truncation limits the best real-difference error to about √ε.","inputs":{"scheme":"Forward difference"}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"best","path":"/rows/0/1","range":{"min":1e-13,"max":1e-10}}
//|       - {"artifact":"best","path":"/rows/0/3","equals":null}
//|       - {"artifact":"best","path":"/rows/1/1","range":{"max":5e-16}}
//|       - {"artifact":"best","path":"/rows/1/3","range":{"max":5e-16}}
//|   - case: forward
//|     expect:
//|       - {"artifact":"best","path":"/rows/0/1","range":{"min":1e-10,"max":1e-7}}
//|       - {"artifact":"best","path":"/rows/1/1","range":{"max":5e-16}}
use scioxide_core::{Complex, SciOxideError, SciOxideErrorKind, RealScalar};
use scioxide_differentiate::{ComplexStep, DifferenceScheme, DifferenceStep, FiniteDifference};

let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let (label, formula) = match scheme.as_str() {
    "Forward difference" => ("Forward difference", DifferenceScheme::Forward),
    _ => ("Central difference", DifferenceScheme::Central),
};
// Reference: f' = e^x (d − 1.5 (s²c − c²s)/d) / d², d = (s³ + c³)^{1/2} (f64 inherent methods).
let (s, c) = x0.sin_cos();
let d = (s.powi(3) + c.powi(3)).sqrt();
let exact = x0.exp() * (d - 1.5 * (s * s * c - c * c * s) / d) / (d * d);
let real = |t: f64| {
    let (s, c) = (RealScalar::sin(t), RealScalar::cos(t));
    Ok::<f64, SciOxideError>(RealScalar::exp(t) / RealScalar::sqrt(s * s * s + c * c * c))
};
let complex = |z: Complex<f64>| {
    let (s, c) = (z.sin(), z.cos());
    Ok::<_, SciOxideError>(z.exp() / (s * s * s + c * c * c).sqrt())
};
// Step exponents: increments of 0.5 from 10⁻¹ through 10⁻¹⁶; beyond that only complex steps are meaningful.
let mut exponents: Vec<f64> = (2..=32).map(|k| 0.5 * k as f64).collect();
exponents.extend([20.0, 30.0, 50.0, 100.0, 150.0, 200.0, 250.0, 300.0]);
// Per method: (points, zero-error count, relative error at h = 10⁻³⁰⁰).
let mut curves: [(Vec<[f64; 2]>, usize, Option<f64>); 2] = Default::default();
let mut collided = 0;
for p in exponents {
    let h = 10.0_f64.powf(-p);
    let method = FiniteDifference::default()
        .with_scheme(formula)
        .with_step(DifferenceStep::absolute(h).map_err(|e| e.to_string())?);
    let real_value = match method.derivative(real, x0) {
        Ok(result) => Some(result.values().ok_or("Derivative not published")?[0]),
        // Exclude only steps with nodes merged by rounding.
        Err(e) if e.kind() == SciOxideErrorKind::InvalidInput => None,
        Err(e) => return Err(e.to_string()),
    };
    let result = ComplexStep::default()
        .with_step(h)
        .derivative(complex, x0)
        .map_err(|e| e.to_string())?;
    let complex_value = Some(result.values().ok_or("Derivative not published")?[0]);
    for (curve, value) in curves.iter_mut().zip([real_value, complex_value]) {
        let Some(value) = value else {
            collided += 1;
            continue;
        };
        let error = ((value - exact) / exact).abs();
        if p == 300.0 {
            curve.2 = Some(error);
        }
        if error > 0.0 {
            curve.0.push([h, error]);
        } else {
            curve.1 += 1;
        }
    }
}
let mut rows = Vec::new();
for (name, (points, zeros, smallest)) in [label, "Complex-step method"].into_iter().zip(&curves)
{
    let best = points
        .iter()
        .copied()
        .fold([0.0, f64::INFINITY], |a, b| if b[1] < a[1] { b } else { a });
    let skipped = (name == label).then_some(collided);
    rows.push((name, best[1], best[0], *smallest, *zeros, skipped));
}
let series: Vec<_> = rows
    .iter()
    .zip(&curves)
    .map(|(row, curve)| serde_json::json!({ "name": row.0, "points": curve.0 }))
    .collect();
emit_line_chart!(
    &series,
    options = &serde_json::json!({
        "xLabel": "Step h [-]",
        "yLabel": "Relative derivative error [-]",
        "xType": "log",
        "yType": "log",
        "annotations": [{ "kind": "line", "axis": "y", "value": f64::EPSILON, "label": "ε" }]
    })
);
let columns = serde_json::json!([
    { "key": "0", "label": "Method" },
    { "key": "1", "label": "Best nonzero relative error [-]", "type": "number", "format": sci3 },
    { "key": "2", "label": "Corresponding step h [-]", "type": "number", "format": sci3 },
    { "key": "3", "label": "Relative error at h = 10⁻³⁰⁰ [-]", "type": "number", "format": sci3, "nullText": "—" },
    { "key": "4", "label": "Zero-relative-error points [count]", "type": "integer" },
    { "key": "5", "label": "Merged-node points [count]", "type": "integer", "nullText": "—" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "best" })
);
```

With defaults ($x_0 = 1.5$, central differences), both errors coincide along truncation $h^2$ over $h \ge 10^{-5}$.
Central error then grows from rounding, exceeding $10^{-5}$ at $h \le 3 \times 10^{-12}$; at 9 points $h \le 10^{-16}$, rounded nodes coincide and no difference can be formed.
The best table relative error $4.8 \times 10^{-12}$ ($h = 3.2 \times 10^{-6}$) is a point lowered by rounding variability; neighboring steps give $5.7 \times 10^{-11}$ and $1.3 \times 10^{-10}$.
Complex-step error decreases as $h^2$ down to $h = 3.2 \times 10^{-8}$, falls below $\varepsilon$ at $h \le 10^{-8}$, and remains unchanged through $h = 10^{-300}$.
At 19 of 39 points, results match the reference bitwise, giving exactly zero relative error.
Forward differences have truncation $O(h)$, limiting their best relative error to $7.0 \times 10^{-9}$.

## Behavior when assumptions fail

The next cell passes several complex functions to `derivative` of default `ComplexStep` and compares with real-function derivatives.
$z^2$ and $\sqrt{z}$ ($x_0 > 0$) are analytic extensions giving correct derivatives.
$z \bar z = \lvert z \rvert^2$ and $\lvert z \rvert$ equal $x^2$ and $\lvert x \rvert$ on the real axis but are nonanalytic.
Applying $\sin$ to the real part and returning a real value also matches $\sin x$ on the real axis, but discards the imaginary perturbation.
Their $f(x + ih)$ imaginary parts are zero, returning derivative 0 without error.
Choosing $z$ or $-z$ by real-part sign is an analytic extension at $x_0 \ne 0$ and correctly returns derivative $\operatorname{sign} x_0$ of $\lvert x \rvert$.
$(1 + i) z$ and principal $\sqrt{z}$ at $x_0 < 0$ are not real-valued on the real axis and fail the base check.

```rust
//| id: differentiate-analytic-contract
//| ref: differentiate-analytic-contract
//| title: "Complex-step results for nonanalytic complex functions"
//| run: reactive
//| crates: [scioxide-core, scioxide-differentiate]
//| inputs:
//|   point: {"type":"select","label":"Evaluation point x₀","options":["1.5","0.5","-0.5","-1.5"],"value":"1.5"}
//| cases:
//|   - {"id":"negative","label":"x₀ = −1.5","description":"Principal √z is imaginary on the negative real axis and fails the base check.","inputs":{"point":"-1.5"}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"contract","path":"/rows/0/3","approx":{"value":3.0,"rtol":1e-15}}
//|       - {"artifact":"contract","path":"/rows/1/3","approx":{"value":0.408248290463863,"rtol":1e-15}}
//|       - {"artifact":"contract","path":"/rows/2/3","equals":0}
//|       - {"artifact":"contract","path":"/rows/3/3","equals":0}
//|       - {"artifact":"contract","path":"/rows/4/3","equals":0}
//|       - {"artifact":"contract","path":"/rows/5/3","approx":{"value":1.0,"rtol":1e-15}}
//|       - {"artifact":"contract","path":"/rows/6/3","equals":null}
//|       - {"artifact":"contract","path":"/rows/6/4","equals":"InvalidInput（function, UnsupportedConfiguration）"}
//|   - case: negative
//|     expect:
//|       - {"artifact":"contract","path":"/rows/1/4","equals":"InvalidInput（function, UnsupportedConfiguration）"}
//|       - {"artifact":"contract","path":"/rows/5/3","approx":{"value":-1.0,"rtol":1e-15}}
use scioxide_core::{Complex, SciOxideError, SciOxideErrorView, RealScalar};
use scioxide_differentiate::ComplexStep;

let fixed6 = serde_json::json!({ "fractionDigits": 6 });
let x0: f64 = point.parse().map_err(|_| "Cannot read evaluation point")?;
let root_extension = if x0 > 0.0 { "Yes" } else { "No" };
type Case = (
    &'static str,
    &'static str,
    fn(Complex<f64>) -> Complex<f64>,
    Option<f64>,
);
// (Function, analytic extension of a real function?, complex function, real derivative). Derivatives are hand-derived references.
let cases: [Case; 7] = [
    ("z²", "Yes", |z| z * z, Some(2.0 * x0)),
    (
        "√z (principal value)",
        root_extension,
        |z| z.sqrt(),
        (x0 > 0.0).then(|| 0.5 / x0.sqrt()),
    ),
    ("z · conj(z)", "No", |z| z * z.conj(), Some(2.0 * x0)),
    (
        "|z|（norm）",
        "No",
        |z| Complex::new(z.norm(), 0.0),
        Some(x0.signum()),
    ),
    (
        "sin(Re z)",
        "No",
        |z| Complex::new(RealScalar::sin(z.re), 0.0),
        Some(x0.cos()),
    ),
    (
        "−z if Re z < 0, otherwise z",
        "Yes",
        |z| if z.re < 0.0 { -z } else { z },
        Some(x0.signum()),
    ),
    ("(1 + i) z", "No", |z| Complex::new(1.0, 1.0) * z, None),
];
let method = ComplexStep::default();
let mut rows = Vec::new();
for (name, analytic, function, reference) in cases {
    let (value, failure) = match method.derivative(|z| Ok::<_, SciOxideError>(function(z)), x0) {
        Ok(r) => (Some(r.values().ok_or("Derivative not published")?[0]), None),
        // Retain only base-check rejections in the table; propagate other errors as cell errors.
        Err(e) => match e.view() {
            SciOxideErrorView::InvalidInput {
                argument, reason, ..
            } => {
                let detail = format!("InvalidInput（{}, {reason:?}）", argument.as_str());
                (None, Some(detail))
            }
            _ => return Err(e.to_string()),
        },
    };
    rows.push((name, analytic, reference, value, failure));
}
let columns = serde_json::json!([
    { "key": "0", "label": "Complex function" },
    { "key": "1", "label": "Analytic real-function extension" },
    { "key": "2", "label": "Real derivative", "type": "number", "format": fixed6, "nullText": "None" },
    { "key": "3", "label": "Complex-step result", "type": "number", "format": fixed6, "nullText": "—" },
    { "key": "4", "label": "Error", "nullText": "None" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "contract" })
);
```

At default $x_0 = 1.5$, derivatives computed with $z^2$, $\sqrt{z}$, and the real-sign branch match the real derivatives.
$z \bar z$, $\lvert z \rvert$, and $\sin(\operatorname{Re} z)$ all return 0, unlike real derivatives 3, 1, and $\cos 1.5 = 0.0707$, without errors.
$(1 + i) z$ has a nonzero base imaginary part and is rejected with `InvalidInput` (`function`, `UnsupportedConfiguration`).
With negative $x_0$, $\sqrt{z}$ is also rejected because base value $\sqrt{x_0} = i \sqrt{\lvert x_0 \rvert}$ is nonreal; the real-sign branch returns $-1$.
The base check detects only nonreal values on the real axis, missing nonanalytic functions such as $z \bar z$ that are real there.
When complex steps return 0, inspect the function for assumption violations and compare with real differences.

## Summary

Complex steps compute first derivatives through $\operatorname{Im} f(x + ih)/h$ without subtraction, avoiding cancellation as steps shrink and giving relative errors of a few times $\varepsilon$ for many functions.
They assume an analytic extension, checking only real-valuedness at the base, so conjugation, absolute value, or real-part-only operations may silently return incorrect zero.
For zero results, inspect function implementation and compare with real differences.
Default `ComplexStep` step is $\varepsilon$; gradients and Jacobians take $n + 1$ evaluations without error estimates, and termination `Completed` makes no accuracy claim.
Use real or adaptive differences when complex evaluation is unavailable or estimates are needed.
