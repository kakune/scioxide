Numerical differentiation often repeats derivatives of the same shape in optimization iterations or time-evolution stages.
Repeated allocation costs time and can fail midway through computation.
`scioxide-differentiate` separates configuration-only method values, precomputed Plans, requirements expressing evaluation-storage sizes, and workspaces allocating and reusing that storage.
This page explains family type relationships, capacity checks and reservation, workspace reuse and rejection, and owned and borrowed forms.
Limits, reports, publication rules, and function-passing forms appear in [Evaluation limits, reports, and result publication](../budgets-reports-and-publication/).
Cross-crate workspace and reproducibility principles appear in [Execution forms, workspaces, and reproducibility](../../../concepts/workspaces-and-reproducibility/).

## Plans, requirements, and workspaces

SciOxide calls an immutable value a Plan when it holds data precomputed at construction (tables, nodes and weights, structures, etc.)
for reuse across many inputs.
Values holding only checked configuration are distinguished as method values.
Here `FiniteDifference`, `AdaptiveDifference`, and `ComplexStep` hold only configuration and check settings used by each operation per evaluation.
The length of the point $\mathbf{x}$ determines the input dimension $n$; arguments to the Jacobian and directional-derivative methods determine the function's output count $m$.
Method workspace sizes are therefore represented by method-and-shape pair [`DerivativeRequest`](https://docs.rs/scioxide-differentiate/0.1.0/scioxide_differentiate/struct.DerivativeRequest.html)`::new(&method, shape)`.
Shape [`DerivativeShape`](https://docs.rs/scioxide-differentiate/0.1.0/scioxide_differentiate/struct.DerivativeShape.html) has four cases `gradient(n)`, `jacobian(n, m)`, `hessian(n)`, and `jvp(n, m)`, with output lengths $n$, $mn$, $n^2$, and $m$.
For borrowed univariate derivatives, use one-variable gradient `gradient(1)` or, for second derivatives, shape `hessian(1)`.
Fixed-step first derivatives also have workspace-free `FiniteDifference::derivative_into` ([Owned and borrowed forms](oxref:differentiate-owned-borrowed)).

The three Plans are `ColoredJacobianPlan`, `PhysicalDifferencePlan`, and `ComplexStepPlan`.
`ColoredJacobianPlan` precomputes per-column row positions and tolerances from coloring; `PhysicalDifferencePlan` and `ComplexStepPlan` precompute supplied-node weights.
Node methods `RelativeDifference` and `RelativeComplexStep` store only displacements, recomputing weights per evaluation from displacements remaining after rounding.
All Plans and node methods use `new`, checking operations, dimensions, and settings at construction and fixing sizes.
All are function-independent and reusable after construction.
Only `PhysicalDifferencePlan` and `ComplexStepPlan` fix evaluation points at construction; others receive them on each call.
`ColoredJacobianPlan` borrows coloring `ColoringSchedule`.

For method values, workspace associated function `workspace_requirements(request)` returns storage-size requirements, and `workspace(request)` reserves them in an empty workspace and returns it.
For Plans and node methods, methods `workspace_requirements(())` and `workspace(())` do the same.
Requirement `bytes()` is the total byte size of arrays retained by a new workspace for that evaluation.
It includes nested arrays, excluding stack values, allocator metadata, and temporary preparation allocations.
Sizes depend on operation shape, value type, adaptive or colored levels, coloring nonzeros, and node counts, not point or boundary values.

| Method or Plan | Requirement call | Requirement type | Workspace type | Function-value type |
|---|---|---|---|---|
| `FiniteDifference<S>` | `FiniteDifferenceWorkspace::<S>::workspace_requirements(request)` | [`FiniteDifferenceRequirements<S>`](https://docs.rs/scioxide-differentiate/0.1.0/scioxide_differentiate/struct.FiniteDifferenceRequirements.html) | [`FiniteDifferenceWorkspace<S>`](https://docs.rs/scioxide-differentiate/0.1.0/scioxide_differentiate/struct.FiniteDifferenceWorkspace.html) | Real `S` |
| `AdaptiveDifference<S>` | `AdaptiveDifferenceWorkspace::<T>::workspace_requirements(request)` | [`AdaptiveDifferenceRequirements<T>`](https://docs.rs/scioxide-differentiate/0.1.0/scioxide_differentiate/struct.AdaptiveDifferenceRequirements.html) | [`AdaptiveDifferenceWorkspace<T>`](https://docs.rs/scioxide-differentiate/0.1.0/scioxide_differentiate/struct.AdaptiveDifferenceWorkspace.html) | Real or complex `T` |
| `ColoredJacobianPlan<S>` | `plan.workspace_requirements::<T>(())` | [`ColoredJacobianRequirements<T>`](https://docs.rs/scioxide-differentiate/0.1.0/scioxide_differentiate/struct.ColoredJacobianRequirements.html) (borrows Plan) | [`ColoredJacobianWorkspace<T>`](https://docs.rs/scioxide-differentiate/0.1.0/scioxide_differentiate/struct.ColoredJacobianWorkspace.html) | Real or complex `T` |
| `PhysicalDifferencePlan<S>` | `plan.workspace_requirements::<T>(())` | [`PhysicalDifferenceRequirements<T>`](https://docs.rs/scioxide-differentiate/0.1.0/scioxide_differentiate/struct.PhysicalDifferenceRequirements.html) | [`PhysicalDifferenceWorkspace<T>`](https://docs.rs/scioxide-differentiate/0.1.0/scioxide_differentiate/struct.PhysicalDifferenceWorkspace.html) | Real or complex `T` |
| `RelativeDifference<S>` | `method.workspace_requirements::<T>(())` | [`RelativeDifferenceRequirements<T>`](https://docs.rs/scioxide-differentiate/0.1.0/scioxide_differentiate/struct.RelativeDifferenceRequirements.html) (borrows method) | [`RelativeDifferenceWorkspace<T>`](https://docs.rs/scioxide-differentiate/0.1.0/scioxide_differentiate/struct.RelativeDifferenceWorkspace.html) | Real or complex `T` |
| `ComplexStep<S>` | `ComplexStepWorkspace::<S>::workspace_requirements(request)` | [`ComplexStepRequirements<S>`](https://docs.rs/scioxide-differentiate/0.1.0/scioxide_differentiate/struct.ComplexStepRequirements.html) | [`ComplexStepWorkspace<S>`](https://docs.rs/scioxide-differentiate/0.1.0/scioxide_differentiate/struct.ComplexStepWorkspace.html) | Complex `Complex<S>` |
| `ComplexStepPlan<S>`, `RelativeComplexStep<S>` | `plan.workspace_requirements(())` | `ComplexStepRequirements<S>` (borrows Plan or method) | `ComplexStepWorkspace<S>` | Complex `Complex<S>` |

`S` is the real coordinate type (`f32` or `f64`); `T` is the function-value type.
Adaptive, colored, and node differences accept complex-valued functions and differentiate both parts over real coordinates.
Array sizes vary with value types, requiring explicit types such as `AdaptiveDifferenceWorkspace::<f64>::workspace_requirements(request)` or `plan.workspace_requirements::<f64>(())`.
`ComplexStep` requirements do not borrow the method; however, passing shape `hessian(n)` to `ComplexStepWorkspace::workspace_requirements` returns `InvalidInput`.
Compute complex-step Hessians through `ComplexStepPlan` or `RelativeComplexStep` ([Complex-step differentiation and analytic extensions](../complex-step/)).
Borrowing requirements cannot outlive their Plans or methods.
Every workspace returns retained array size `retained_bytes()` in bytes without allocation, including capacity for earlier larger requirements.
`FiniteDifferenceWorkspace` also returns dimensions `input_dimension()` and `output_dimension()` of the last reserved or evaluated shape.

## Measuring requirements and workspaces

For six methods and Plans from the table (excluding `ComplexStepPlan` and `RelativeComplexStep`), the next cell reads requirements for $n$-variable gradients ($n \times n$ Jacobians for coloring), then applies `check`, `try_reserve`, and `check` to empty workspaces.
Coloring uses a diagonal structure with all columns the same color; node families use 3 nodes per axis.
The table shows selected $n$ requirement bytes, both `check` results, and post-reservation `retained_bytes()`; the chart plots requirements for $n = 1, \ldots, 16$ logarithmically, marking selected $n$ vertically.
Requirements include arrays depending on `usize` size, so browser wasm32 and native 64-bit values differ slightly.

```rust
//| id: differentiate-workspace-reuse
//| ref: differentiate-workspace-reuse
//| title: "Requirements and workspace reservation by family"
//| run: reactive
//| crates: [scioxide-core, scioxide-differentiate]
//| inputs:
//|   n: {"type":"range","label":"Variable count n [-]","min":1,"max":16,"step":1,"value":3}
//| cases:
//|   - {"id":"sixteen","label":"n = 16","description":"Colored requirements grow linearly with n through per-column extrapolation tables; complex-step requirements remain small at 24n + 16 bytes.","inputs":{"n":16}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"requirements","path":"/rows/0/2","equals":"NeedsGrowth"}
//|       - {"artifact":"requirements","path":"/rows/0/3","equals":"Sufficient"}
//|       - {"artifact":"requirements","path":"/rows/3/2","equals":"NeedsGrowth"}
//|       - {"artifact":"requirements","path":"/rows/3/3","equals":"Sufficient"}
//|       - {"artifact":"requirements","path":"/rows/5/3","equals":"Sufficient"}
//|       - {"artifact":"requirements","path":"/rows/2/1","equals":88}
//|   - case: sixteen
//|     expect:
//|       - {"artifact":"requirements","path":"/rows/2/1","equals":400}
//|       - {"artifact":"requirements","path":"/rows/3/3","equals":"Sufficient"}
use scioxide_core::{Capacity, ColoringKind, ColoringSchedule, SciOxideError, StructuralPattern};
use scioxide_differentiate::DerivativeOperation::Gradient;
use scioxide_differentiate::{
    AdaptiveDifference, AdaptiveDifferenceWorkspace, ColoredJacobianPlan,
    ColoredJacobianWorkspace, ComplexStep, ComplexStepWorkspace, DerivativeRequest,
    DerivativeShape, FiniteDifference, FiniteDifferenceWorkspace, NodeDifferenceOptions,
    PhysicalDifferencePlan, PhysicalDifferenceWorkspace, RelativeDifference,
    RelativeDifferenceWorkspace,
};

type Row = (&'static str, usize, &'static str, &'static str, usize);
fn capacity(c: Capacity) -> &'static str {
    match c {
        Capacity::Sufficient => "Sufficient",
        Capacity::NeedsGrowth => "NeedsGrowth",
    }
}
/// Get n-variable requirements for six families and apply check, try_reserve, check to empty workspace.
fn lifecycle(n: usize) -> Result<Vec<Row>, SciOxideError> {
    let x: Vec<f64> = (0..n).map(|i| 0.5 + 0.1 * i as f64).collect();
    let shape = DerivativeShape::gradient(n);
    let (fixed, adaptive) = (FiniteDifference::default(), AdaptiveDifference::default());
    let complex = ComplexStep::<f64>::default();
    let diagonal = StructuralPattern::new(n, n, (0..=n).collect(), (0..n).collect())?;
    let schedule =
        ColoringSchedule::new(diagonal, ColoringKind::DerivativeColumns, vec![0; n])?;
    let colored = ColoredJacobianPlan::new(&schedule, adaptive.clone())?;
    let offsets = [-1e-3, 0.0, 1e-3];
    let axes: Vec<&[f64]> = vec![&offsets[..]; n];
    let options = NodeDifferenceOptions::default();
    let relative = RelativeDifference::new(Gradient, &axes, 1, options)?;
    let nodes: Vec<Vec<f64>> = x
        .iter()
        .map(|c| offsets.iter().map(|d| c + d).collect())
        .collect();
    let node_refs: Vec<&[f64]> = nodes.iter().map(Vec::as_slice).collect();
    let physical = PhysicalDifferencePlan::new(Gradient, &x, &node_refs, 1, options)?;
    let mut rows = Vec::new();
    macro_rules! reserve {
        ($name:expr, $requirements:expr, $workspace:ty) => {{
            let r = $requirements;
            let mut w = <$workspace>::default();
            let before = w.check(&r)?;
            w.try_reserve(&r)?;
            let after = w.check(&r)?;
            let held = w.retained_bytes()?;
            rows.push(($name, r.bytes(), capacity(before), capacity(after), held));
        }};
    }
    let request = DerivativeRequest::new(&fixed, shape);
    let r = FiniteDifferenceWorkspace::workspace_requirements(request)?;
    reserve!("FiniteDifference", r, FiniteDifferenceWorkspace<f64>);
    let request = DerivativeRequest::new(&adaptive, shape);
    let r = AdaptiveDifferenceWorkspace::<f64>::workspace_requirements(request)?;
    reserve!("AdaptiveDifference", r, AdaptiveDifferenceWorkspace<f64>);
    let request = DerivativeRequest::new(&complex, shape);
    let r = ComplexStepWorkspace::workspace_requirements(request)?;
    reserve!("ComplexStep", r, ComplexStepWorkspace<f64>);
    let r = colored.workspace_requirements::<f64>(())?;
    reserve!("ColoredJacobianPlan", r, ColoredJacobianWorkspace<f64>);
    let r = physical.workspace_requirements::<f64>(())?;
    reserve!(
        "PhysicalDifferencePlan",
        r,
        PhysicalDifferenceWorkspace<f64>
    );
    let r = relative.workspace_requirements::<f64>(())?;
    reserve!("RelativeDifference", r, RelativeDifferenceWorkspace<f64>);
    Ok(rows)
}

let n = n as usize;
let (mut table, mut series) = (Vec::new(), Vec::new());
for k in 1..=16 {
    let rows = lifecycle(k).map_err(|e| e.to_string())?;
    series.resize_with(rows.len(), Vec::new);
    for (points, row) in series.iter_mut().zip(&rows) {
        points.push([k as f64, row.1 as f64]);
    }
    if k == n {
        table = rows;
    }
}
let series: Vec<_> = table
    .iter()
    .zip(series)
    .map(|(row, points)| serde_json::json!({ "name": row.0, "points": points }))
    .collect();
emit_chart!(serde_json::json!({
    "kind": "line",
    "dataZoom": true,
    "tooltip": true,
    "xLabel": "Variable count n [-]",
    "yLabel": "Requirement size [bytes]",
    "yType": "log",
    "series": series,
    "annotations": [{ "kind": "line", "axis": "x", "value": n, "label": "Selected n" }]
}));
let columns = serde_json::json!([
    { "key": "0", "label": "Method or Plan" },
    { "key": "1", "label": "Requirement size [bytes]", "type": "integer" },
    { "key": "2", "label": "check before reservation" },
    { "key": "3", "label": "check after reservation" },
    { "key": "4", "label": "Retained after reservation [bytes]", "type": "integer" }
]);
emit_table_with_columns!(
    columns,
    table,
    metadata = serde_json::json!({ "id": "requirements" })
);
```

At default $n = 3$, browser requirements range from 88 complex-step bytes to 13032 colored bytes, differing by about 150 times.
Every family's pre-reservation `check` gives `NeedsGrowth` and post-reservation gives `Sufficient`; post-reservation `retained_bytes()` equals required size.
Only colored requirements grow proportionally to $n$ at 4344 bytes per column; other families grow slowly because large parts are independent of $n$.
Colored workspaces hold a per-column extrapolation table (default 16 levels), scaling with nonzeros times levels.
Complex-step gradient workspaces hold only complex points ($16n$ bytes), function values (16 bytes), and gradients ($8n$ bytes), totaling $24n + 16$ bytes.

## Capacity checks and reservation

Construct empty workspace with `Default::default()` and satisfy requirements as follows.
`workspace(request)` and `workspace(())` perform the whole sequence at once.

1. `check(&requirements)` checks capacity without allocation, returning `Capacity::Sufficient` or `Capacity::NeedsGrowth`.
2. On `NeedsGrowth`, extend insufficient arrays with `try_reserve(&requirements)`.
3. Pass workspace reporting `Sufficient` to a borrowed form.

Set retained-workspace limits through `with_max_workspace_bytes` on `FiniteDifference`, `AdaptiveDifference`, `ComplexStep` or node options `NodeDifferenceOptions`.
Defaults impose no limits.
Plans and node methods use limits from construction settings (`AdaptiveDifference` for `ColoredJacobianPlan`; `ComplexStep` for `ComplexStepPlan` and `RelativeComplexStep`; `NodeDifferenceOptions` for `PhysicalDifferencePlan` and `RelativeDifference`).
Limits apply to all retained capacity, including storage left from earlier larger evaluations.

| Call | Error | Condition |
|---|---|---|
| `workspace_requirements` | `ResourceLimit` | Requirements exceed limit |
| `check` | `ResourceLimit` | Retained workspace exceeds limit |
| `try_reserve` | `ResourceLimit` | Estimated post-growth size exceeds limit (no allocation), or actual retained post-growth size exceeds it |
| `try_reserve` | `AllocationFailure` | Arrays cannot grow; earlier growth remains |
| Borrowed | `ResourceLimit` | Requirements or retained size exceed limit |
| Borrowed | `DimensionMismatch` | Capacity below requirements; expected is required bytes and actual is retained bytes |

Every call returns `SizeOverflow` if size cannot fit `usize`.
Allocators may return excess capacity, so `try_reserve` compares both estimated preallocation size and actual retained postallocation size against the limit.
If `try_reserve` stops with `AllocationFailure`, rerun `check` before evaluating.

Borrowed forms, ending in `_into`, never grow workspace.
Insufficient capacity or exceeded limits give errors without function calls.
One workspace serves every same-family evaluation whose requirements it meets.
For example, `FiniteDifferenceWorkspace` reserved for a Jacobian with $m$ outputs also serves gradients with the same $n$.
For larger evaluations, rerun `check` and `try_reserve` with their requirements.
After errors, workspace contents may change but remain valid and reusable.
If retained capacity exceeds limits, use a method with a larger limit or a fresh workspace.

## Workspace reuse and rejection

The next two cells check these rules with fixed-step `FiniteDifference` workspace.
The function is $f(\mathbf{x}) = \sum_i x_i^2$, with exact gradient $2\mathbf{x}$.
Jacobian evaluations also return second output $\sum_i x_i$.
Shared definition `squares` writes one or both values according to output length.

```rust
//| id: differentiate-workspace-model
//| kind: definitions
//| title: "Function writing sums of squares and sums"
//| crates: [scioxide-core]
use scioxide_core::SciOxideError;

/// y₀ = Σ xᵢ²; also write y₁ = Σ xᵢ if there are two outputs.
pub(crate) fn squares(p: &[f64], y: &mut [f64]) -> Result<(), SciOxideError> {
    y[0] = p.iter().map(|v| v * v).sum();
    if let Some(second) = y.get_mut(1) {
        *second = p.iter().sum();
    }
    Ok(())
}
```

The first cell reserves one $n$-variable gradient workspace, moves points slightly, and calls `gradient_into` 1000 times.
Compare total evaluations with theoretical $1000 (2n + 1)$, maximum gradient error with exact values, and retained-size growth after 1000 calls with 0.

```rust
//| id: differentiate-workspace-repeat
//| ref: differentiate-workspace-repeat
//| title: "1000 gradients with one workspace"
//| run: reactive
//| uses: [differentiate-workspace-model]
//| crates: [scioxide-core, scioxide-differentiate]
//| inputs:
//|   n: {"type":"range","label":"Variable count n [-]","min":1,"max":8,"step":1,"value":3}
//| cases:
//|   - {"id":"eight","label":"n = 8","description":"Total evaluations are 1000 · 17 = 17000; workspace does not grow after 1000 calls.","inputs":{"n":8}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"reuse","path":"/rows/0/1","equals":7000}
//|       - {"artifact":"reuse","path":"/rows/0/2","equals":7000}
//|       - {"artifact":"reuse","path":"/rows/0/3","range":{"max":1e-8}}
//|       - {"artifact":"reuse","path":"/rows/0/5","equals":0}
//|   - case: eight
//|     expect:
//|       - {"artifact":"reuse","path":"/rows/0/1","equals":17000}
//|       - {"artifact":"reuse","path":"/rows/0/3","range":{"max":1e-8}}
//|       - {"artifact":"reuse","path":"/rows/0/5","equals":0}
use scioxide_core::{ExecutionContext, SciOxideError};
use scioxide_differentiate::{
    DerivativeRequest, DerivativeShape, FiniteDifference, FiniteDifferenceWorkspace,
};

let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let n = n as usize;
let x: Vec<f64> = (0..n).map(|i| 0.5 + 0.1 * i as f64).collect();
let s = |e: SciOxideError| e.to_string();
let method = FiniteDifference::default();
let request = DerivativeRequest::new(&method, DerivativeShape::gradient(n));
let mut workspace = FiniteDifferenceWorkspace::workspace(request).map_err(s)?;
let held = workspace.retained_bytes().map_err(s)?;
// Compute gradients at 1000 points with one workspace, also reusing point and output arrays.
let (mut point, mut out) = (x.clone(), vec![0.0; n]);
let (mut total, mut worst) = (0, 0.0_f64);
for k in 0..1000 {
    for (p, v) in point.iter_mut().zip(&x) {
        *p = v + 0.001 * k as f64;
    }
    let scope = ExecutionContext::sequential();
    let report = method
        .gradient_into(squares, &point, None, None, &mut out, &mut workspace, scope)
        .map_err(s)?;
    total += report.evaluations();
    // Difference from exact gradient 2x.
    let errors = out.iter().zip(&point).map(|(g, p)| (g - 2.0 * p).abs());
    worst = errors.fold(worst, f64::max);
}
let growth = workspace.retained_bytes().map_err(s)? - held;
let columns = serde_json::json!([
    { "key": "0", "label": "Calls [count]", "type": "integer" },
    { "key": "1", "label": "Total evaluations [count]", "type": "integer" },
    { "key": "2", "label": "Theoretical 1000(2n + 1) [count]", "type": "integer" },
    { "key": "3", "label": "Maximum gradient error [-]", "type": "number", "format": sci3 },
    { "key": "4", "label": "Retained after reservation [bytes]", "type": "integer" },
    { "key": "5", "label": "Growth after 1000 calls [bytes]", "type": "integer" }
]);
let rows = vec![(1000, total, 1000 * (2 * n + 1), worst, held, growth)];
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "reuse" })
);
```

At default $n = 3$, total evaluations over 1000 `gradient_into` calls match theory $1000 (2n + 1) = 7000$.
Maximum gradient error is $9.7 \times 10^{-11}$.
Since $f$ is quadratic, central truncation is zero and this error is rounding.
Retained storage (1904 bytes in browsers) is unchanged after 1000 calls; workspace never grew during evaluation.

The second cell tries combinations of workspace and limits, comparing accepted and rejected cases.
The function counts calls to check rejection before evaluation.
The table shows evaluation results (termination or error kind), required bytes, retained bytes, limits, and function calls.

```rust
//| id: differentiate-workspace-errors
//| ref: differentiate-workspace-errors
//| title: "Workspace rejection for insufficient capacity and exceeded limits"
//| run: reactive
//| uses: [differentiate-workspace-model]
//| crates: [scioxide-core, scioxide-differentiate]
//| inputs:
//|   n: {"type":"range","label":"Variable count n [-]","min":1,"max":8,"step":1,"value":3}
//| cases:
//|   - {"id":"eight","label":"n = 8","description":"Required sizes grow with n, but rejection kinds and zero calls remain; accepted evaluations take 2n + 1 = 17 calls.","inputs":{"n":8}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"rejections","path":"/rows/0/1","equals":"ResourceLimit"}
//|       - {"artifact":"rejections","path":"/rows/0/5","equals":0}
//|       - {"artifact":"rejections","path":"/rows/1/1","equals":"DimensionMismatch"}
//|       - {"artifact":"rejections","path":"/rows/1/3","equals":0}
//|       - {"artifact":"rejections","path":"/rows/1/5","equals":0}
//|       - {"artifact":"rejections","path":"/rows/2/1","equals":"DimensionMismatch"}
//|       - {"artifact":"rejections","path":"/rows/2/5","equals":0}
//|       - {"artifact":"rejections","path":"/rows/3/1","equals":"Completed"}
//|       - {"artifact":"rejections","path":"/rows/3/5","equals":7}
//|       - {"artifact":"rejections","path":"/rows/4/1","equals":"ResourceLimit"}
//|       - {"artifact":"rejections","path":"/rows/4/5","equals":0}
//|   - case: eight
//|     expect:
//|       - {"artifact":"rejections","path":"/rows/2/1","equals":"DimensionMismatch"}
//|       - {"artifact":"rejections","path":"/rows/3/5","equals":17}
//|       - {"artifact":"rejections","path":"/rows/4/1","equals":"ResourceLimit"}
use scioxide_core::{ExecutionContext, SciOxideError};
use scioxide_differentiate::{
    DerivativeRequest, DerivativeShape, DifferentiationReport, FiniteDifference,
    FiniteDifferenceWorkspace,
};
use std::cell::Cell;

let n = n as usize;
let x: Vec<f64> = (0..n).map(|i| 0.5 + 0.1 * i as f64).collect();
let calls = Cell::new(0_usize);
// Count calls before evaluating squares.
let f = |p: &[f64], y: &mut [f64]| {
    calls.set(calls.get() + 1);
    squares(p, y)
};
let s = |e: SciOxideError| e.to_string();
let method = FiniteDifference::default();
let gradient = DerivativeRequest::new(&method, DerivativeShape::gradient(n));
let jacobian = DerivativeRequest::new(&method, DerivativeShape::jacobian(n, 2));
let need_gradient = FiniteDifferenceWorkspace::workspace_requirements(gradient)
    .map_err(s)?
    .bytes();
let need_jacobian = FiniteDifferenceWorkspace::workspace_requirements(jacobian)
    .map_err(s)?
    .bytes();
// Reserve gradient and Jacobian workspaces and read retained sizes.
let mut narrow = FiniteDifferenceWorkspace::workspace(gradient).map_err(s)?;
let mut wide = FiniteDifferenceWorkspace::workspace(jacobian).map_err(s)?;
let held = (
    Some(narrow.retained_bytes().map_err(s)?),
    Some(wide.retained_bytes().map_err(s)?),
);
let small = FiniteDifference::<f64>::default().with_max_workspace_bytes(16);
let tight = FiniteDifference::default().with_max_workspace_bytes(need_gradient);
let mut empty = FiniteDifferenceWorkspace::default();
let mut out = vec![0.0; 2 * n];
// Convert results to termination or error-kind names.
let result = |r: Result<DifferentiationReport, SciOxideError>| match r {
    Ok(report) => report.termination().to_string(),
    Err(e) => format!("{:?}", e.kind()),
};
let scope = ExecutionContext::sequential;
// Record each result and size, read call count, then reset it to 0.
calls.set(0);
let mut rows = Vec::new();
let mut record = |case, outcome, need, held: Option<usize>, limit: Option<usize>| {
    rows.push((case, outcome, need, held, limit, calls.replace(0)));
};
let request = DerivativeRequest::new(&small, DerivativeShape::gradient(n));
let r = FiniteDifferenceWorkspace::workspace_requirements(request);
let outcome = r.map_or_else(|e| format!("{:?}", e.kind()), |_| "Requirements returned".into());
let case = "Get requirements with a 16-byte limit";
record(case, outcome, need_gradient, None, Some(16));
let r = method.gradient_into(f, &x, None, None, &mut out[..n], &mut empty, scope());
record(
    "Gradient with empty workspace",
    result(r),
    need_gradient,
    Some(0),
    None,
);
let r = method.jacobian_into(f, &x, 2, None, None, &mut out, &mut narrow, scope());
record(
    "Jacobian with gradient workspace",
    result(r),
    need_jacobian,
    held.0,
    None,
);
let r = method.gradient_into(f, &x, None, None, &mut out[..n], &mut wide, scope());
record(
    "Gradient with Jacobian workspace",
    result(r),
    need_gradient,
    held.1,
    None,
);
let r = tight.gradient_into(f, &x, None, None, &mut out[..n], &mut wide, scope());
let case = "Same workspace, limit set to gradient requirements";
record(case, result(r), need_gradient, held.1, Some(need_gradient));
let columns = serde_json::json!([
    { "key": "0", "label": "Case" },
    { "key": "1", "label": "Result" },
    { "key": "2", "label": "Required size [bytes]", "type": "integer" },
    { "key": "3", "label": "Retained size [bytes]", "type": "integer", "nullText": "—" },
    { "key": "4", "label": "Limit [bytes]", "type": "integer", "nullText": "None" },
    { "key": "5", "label": "Function calls [count]", "type": "integer" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "rejections" })
);
```

At default $n = 3$, all four rejected cases make no function calls.
With a 16-byte limit, required 1904 bytes (browser value) exceed it, so `workspace_requirements` returns `ResourceLimit`.
Empty workspace for gradients or gradient workspace (1904 bytes) for a Jacobian (2024 bytes) has insufficient capacity, giving `DimensionMismatch`.
Conversely, Jacobian workspace meets gradient requirements and serves them unchanged, giving `Completed` with $2n + 1 = 7$ calls.
The same workspace under a method limited to gradient requirements, 1904 bytes, is rejected with `ResourceLimit` because retained 2024 bytes exceed it.
Limits cap retained capacity rather than current evaluation requirements.

## Owned and borrowed forms

The same computation has several forms depending on required control (terms are defined in [Call forms](oxref:differentiate-call-forms-terms)).
By workspace and output handling, they differ as follows.

| Form | Example | Accepts | Returns | Execution context |
|---|---|---|---|---|
| One-shot | `derivative(f, x)`, `gradient(f, x)`, `sparse_jacobian`, `complex_step_derivative` | Function and point | Values; unsuccessful termination gives errors | `ExecutionContext::sequential_native()` |
| Owned | `method.gradient(f, x, bounds, base)`, `plan.evaluate(f, bounds)` | Function, point, bounds, etc. | `DifferentiationResult` (values, estimates, report) | `ExecutionContext::sequential_native()` |
| Borrowed | `method.gradient_into(f, x, bounds, base, out, workspace, scope)`, `plan.evaluate_into(…)` | Owned arguments plus output, workspace, and context | `DifferentiationReport` (values written to output) | Supplied `scope` |
| API with a specified output buffer and no workspace | `FiniteDifference::derivative_into(f, x, bounds, base, out, scope)` | Univariate function, point, bounds, known $f(x)$, output buffer, execution context | `DifferentiationReport` | Supplied `scope` |

Owned forms allocate workspace and output per call.
One-shot functions, like owned forms, evaluate sequentially and return values only.
`derivative` internally calls workspace-free borrowed `derivative_into` without allocation; other one-shot functions allocate through owned forms.
Unsuccessful termination becomes errors by the same rules as `require_success` ([Report and publication rules](oxref:differentiate-report-rules)).
Borrowed forms with sufficient capacity allocate no numerical storage.
This also holds for adaptive termination `StepSizeLimit`.
Function-internal allocation and executor allocation while dispatching `Parallel` samples follow their respective contracts.

Pass `ExecutionContext::sequential()` or another context to `scope` for top-level work, or an active outer solve's `&mut SolveContext` for nested work.
The latter shares parent cancellation and deadlines and charges evaluations to parent limits ([Evaluation and iteration limits and solve accounting](oxref:differentiate-budgets)).
`FiniteDifference::derivative_into` computes univariate first derivatives with stack storage alone.
Pass bounds as `ExtendedInterval`; steps, formulas, and limits match univariate `gradient_into`.
This suits repeated derivatives inside univariate root-finding or optimization.

Owned result [`DifferentiationResult`](https://docs.rs/scioxide-differentiate/0.1.0/scioxide_differentiate/struct.DifferentiationResult.html) provides the following methods.

- `values()` returns row-major `Some` values only when output is published.
- `errors()` returns `Some` error estimates only when adaptive or colored output is published.
- `report()` returns the report; `into_parts()` splits report, values, and estimates.
- `into_values()` returns values only on success, otherwise errors from `require_success`.
  Read early-stopped adaptive best estimates with `values()` or `into_parts()`.

In borrowed forms, only adaptive differences and coloring accept separate estimate array `errors`, writing it together with values.

## Summary

Methods hold only settings and Plans immutable precomputed data; both are function-independent and reusable.
Get requirements with `DerivativeRequest` for methods or `()` for Plans and node methods, prepare workspace with `workspace` or `check` and `try_reserve`, and repeat borrowed evaluations without numerical allocation.
One workspace also serves other same-family evaluations meeting its requirements, such as gradients with storage reserved for larger Jacobians.
Insufficient capacity gives `DimensionMismatch`; exceeded requirements or retained-size limits give `ResourceLimit`, both before function calls and without growth during evaluation.
For repeated univariate first derivatives, workspace-free `FiniteDifference::derivative_into` suffices.
