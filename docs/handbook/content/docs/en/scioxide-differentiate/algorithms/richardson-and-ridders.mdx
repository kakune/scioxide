Fixed-step differences compute once at a chosen step and provide no error magnitude.
Repeated differences at shrinking steps estimate truncation from value changes and can eliminate leading terms to raise order.
This is Richardson extrapolation; repeating it in a table and selecting the entry of minimum estimated error gives Ridders' method.
This page derives extrapolation, table updates, rounding amplification, and estimates, explains stopping rules of `scioxide-differentiate` adaptive `AdaptiveDifference`, and compares returned values with a manually built table.
Effects of maximum levels, tolerance, and noise on termination and estimates are measured in [Measured adaptive error estimates and termination reasons](../adaptive-difference-experiments/).
Notation follows [Shared algorithm contracts and structure](oxref:differentiate-notation); $\varepsilon = 2^{-52}$ is double-precision machine epsilon.

## Richardson extrapolation

If $f$ is sufficiently smooth near $x$, Taylor expansion gives central $A(h)$ as a series of even powers of $h$.

$$
A(h) = \frac{f(x + h) - f(x - h)}{2h} = f'(x) + c_1 h^2 + c_2 h^4 + \cdots, \qquad c_k = \frac{f^{(2k+1)}(x)}{(2k+1)!}.
$$

Coefficients $c_k$ are unknown but independent of $h$.
Reducing the step by $r > 1$ to $A(h/r)$ changes the $h^2$ term to $c_1 h^2 / r^2$, so $r^2 A(h/r) - A(h)$ eliminates the term containing $c_1$.

$$
A_1(h) = \frac{r^2 A(h/r) - A(h)}{r^2 - 1} = A(h/r) + \frac{A(h/r) - A(h)}{r^2 - 1} = f'(x) - \frac{c_2 h^4}{r^2} + O(h^6).
$$

Combining two differences raises truncation order from 2 to 4.
$A_1$ also expands in even powers of $h$, so the same operation can eliminate the $h^4$ term, and the process can continue.

The formula's expansion determines which powers can be eliminated.
Central second differences also contain only even powers.

$$
\frac{f(x + h) - 2 f(x) + f(x - h)}{h^2} = f''(x) + \frac{h^2}{12} f^{(4)}(x) + \frac{h^4}{360} f^{(6)}(x) + \cdots .
$$

Three-point one-sided differences contain odd powers too, progressing through $h^2, h^3, h^4, \dots$ one power at a time.

$$
\frac{-3 f(x) + 4 f(x + h) - f(x + 2h)}{2h} = f'(x) - \frac{h^2}{3} f'''(x) - \frac{h^3}{4} f^{(4)}(x) + \cdots .
$$

Extrapolation assumes this power sequence; nonsmooth $f$ near the point can prevent purported elimination from reducing errors.

## Neville-type tables

Let $A_{i,0} = A(h_i)$ be differences at shrinking steps $h_i = h_0 / r^i$ ($i = 0, 1, 2, \dots$); build the table by this recurrence.

$$
A_{i,k} = A_{i,k-1} + \frac{A_{i,k-1} - A_{i-1,k-1}}{r^{p_k} - 1}, \qquad p_k = 2 + \iota (k - 1), \qquad 1 \le k \le i.
$$

$\iota$ is the power increment: 2 for even-power expansions (symmetric nodes), 1 for all-power expansions (one-sided nodes).
Let the desired derivative be $D$ and column $k-1$ entries have form $A_{i,k-1} = D + c\,h_i^{p_k} + \cdots$.
The step of $A_{i-1,k-1}$ is $r h_i$, giving $A_{i-1,k-1} = D + c\,r^{p_k} h_i^{p_k} + \cdots$ and difference $A_{i,k-1} - A_{i-1,k-1} = -c\,(r^{p_k} - 1) h_i^{p_k} + \cdots$.
Dividing by $r^{p_k} - 1$ and adding to $A_{i,k-1}$ eliminates $h_i^{p_k}$.
Column $k$ therefore removes terms through $h^{p_k}$ and has truncation order $p_{k+1}$.
For symmetric nodes ($p_k = 2k$), this equals Neville's algorithm evaluating the $h^2$ polynomial through $(h_i^2, A_{i,0})$ at $h = 0$.
The table adds one row per level.

```text
A₀,₀
A₁,₀  A₁,₁
A₂,₀  A₂,₁  A₂,₂
A₃,₀  A₃,₁  A₃,₂  A₃,₃
```

Row $i$ is computed left to right from new difference $A_{i,0}$ and the previous row, needing storage for only one row.
Truncation order increases toward the lower right.

Rounding grows with each column.
If absolute errors in $A_{i,k-1}$ and $A_{i-1,k-1}$ are at most $\delta$, recurrence error is at most $\delta (r^{p_k} + 1)/(r^{p_k} - 1)$.
For $r = 1.4$, amplification is 3.08 in column 1 and 1.70 in column 2; for $r = 2$, 1.67 and 1.13.
Smaller reduction ratios amplify more.
Difference $A_{i,0}$ itself has rounding about $\varepsilon \lvert f \rvert / h_i$ as in [Rounding, noise, and optimal step size](../roundoff-and-noisy-functions/), increasing as steps shrink.
Raising order cannot improve accuracy indefinitely; eventually rounding growth exceeds truncation reduction.

The following block supplies definitions shared by this page's two cells.
`smooth` is differentiated function $f(x) = e^{\sin x}$, and `smooth_derivative` supplies derivative reference $f'(x) = \cos x \, e^{\sin x}$.
References use f64's inherent methods, while the differentiated function uses SciOxide `RealScalar` functions.

```rust
//| id: differentiate-extrapolation-model
//| kind: definitions
//| title: "Differentiated function e^{sin x} and derivative reference"
//| crates: [scioxide-core]
use scioxide_core::{SciOxideError, RealScalar};

/// Differentiated function f(x) = e^{sin x}.
pub(crate) fn smooth(t: f64) -> Result<f64, SciOxideError> {
    Ok(RealScalar::exp(RealScalar::sin(t)))
}

/// Reference f'(x) = cos x · e^{sin x} (f64 inherent methods).
pub(crate) fn smooth_derivative(x: f64) -> f64 {
    x.cos() * x.sin().exp()
}
```

## Errors by Neville-table column

For the first derivative of $f(x) = e^{\sin x}$ at $x_0 = 0.5$, the next cell plots differences between table entries and references against step $h_i$.
Compute $A_{i,0}$ with central `FiniteDifference` fixed to step $h_i = 0.5 / r^i$ ($i = 0, 1, 2, \dots$); compute columns 1 onward by manually applying the recurrence above.
Dashed lines show column-0 leading truncation $h^2 \lvert f'''(x_0) \rvert / 6$ and rounding guideline $\varepsilon \lvert f(x_0) \rvert / h$.
On logarithmic axes, column $k$ errors decrease with slope $p_{k+1} = 2k + 2$, then rise from rounding at small steps.
The table gives minimum errors in columns 0–4 and their levels $i$ and steps.
The [manual-table comparison](#comparing-manually-built-tables-with-adaptive-values) cell uses this table and ratio.

```rust
//| id: differentiate-neville-tableau
//| ref: differentiate-neville-tableau
//| title: "Errors by column of a Neville-type table"
//| run: reactive
//| uses: [differentiate-extrapolation-model]
//| crates: [scioxide-core, scioxide-differentiate]
//| exports: [table, ratio]
//| inputs:
//|   ratio: {"type":"select","label":"Reduction ratio r","description":"1.4 is Ridders' ratio; 2 is Richardson's.","options":["1.4","2"],"value":"1.4"}
//| cases:
//|   - {"id":"halving","label":"r = 2","description":"Faster step reduction reaches rounding-dominated behavior in fewer levels.","inputs":{"ratio":"2"}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"columns","path":"/rows/0/2","range":{"min":1e-14,"max":1e-9}}
//|       - {"artifact":"columns","path":"/rows/3/2","range":{"max":1e-13}}
//|   - case: halving
//|     expect:
//|       - {"artifact":"columns","path":"/rows/0/2","range":{"min":1e-14,"max":1e-9}}
//|       - {"artifact":"columns","path":"/rows/3/2","range":{"max":1e-13}}
use scioxide_differentiate::{DifferenceScheme, DifferenceStep, FiniteDifference};

let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let r: f64 = ratio.parse().map_err(|_| "Cannot read reduction ratio")?;
let x0 = 0.5_f64;
let exact = smooth_derivative(x0);
// Reference: f‴(x) = cos x (cos²x − 3 sin x − 1) e^{sin x}, f(x) = e^{sin x} (f64 inherent methods).
let (s, c) = x0.sin_cos();
let third = c * (c * c - 3.0 * s - 1.0) * s.exp();
let value = s.exp();
// Reduce steps from h_0 = 0.5 to about 10⁻⁷, reaching rounding-dominated behavior.
let levels = ((0.5 / 1e-7_f64).ln() / r.ln()).ceil() as usize;
let width = 5;
let mut table: Vec<Vec<f64>> = Vec::new();
let mut curves: Vec<Vec<[f64; 2]>> = vec![Vec::new(); width];
let mut best = vec![(f64::INFINITY, 0_usize, 0.0_f64); width];
let mut reference = (Vec::new(), Vec::new());
for i in 0..levels {
    let h = 0.5 / r.powi(i as i32);
    let method = FiniteDifference::default()
        .with_scheme(DifferenceScheme::Central)
        .with_step(DifferenceStep::absolute(h).map_err(|e| e.to_string())?);
    let result = method.derivative(smooth, x0).map_err(|e| e.to_string())?;
    let mut row = vec![result.values().ok_or("Difference not published")?[0]];
    // Independent check: manually apply A_{i,k} = A_{i,k−1} + (A_{i,k−1} − A_{i−1,k−1}) / (r^{p_k} − 1), with p_k = 2k.
    for k in 1..=i {
        let factor = r.powi(2 * k as i32);
        row.push(row[k - 1] + (row[k - 1] - table[i - 1][k - 1]) / (factor - 1.0));
    }
    for (k, entry) in row.iter().enumerate().take(width) {
        let error = (entry - exact).abs();
        if error > 0.0 {
            curves[k].push([h, error]);
        }
        if error < best[k].0 {
            best[k] = (error, i, h);
        }
    }
    reference.0.push([h, h * h * third.abs() / 6.0]);
    reference.1.push([h, f64::EPSILON * value / h]);
    table.push(row);
}
let mut series: Vec<serde_json::Value> = curves
    .iter()
    .enumerate()
    .map(|(k, points)| serde_json::json!({ "name": format!("Column {k}"), "points": points }))
    .collect();
let dashed = serde_json::json!({ "lineType": "dashed", "showSymbol": false });
series.push(serde_json::json!({ "name": "h²|f‴|/6", "points": reference.0, "style": dashed }));
series.push(serde_json::json!({ "name": "ε|f|/h", "points": reference.1, "style": dashed }));
emit_line_chart!(
    &series,
    options = &serde_json::json!({
        "xLabel": "Step h [-]",
        "yLabel": "Entry error |A_{i,k} − f′(x₀)| [-]",
        "xType": "log",
        "yType": "log"
    })
);
let rows: Vec<_> = best
    .iter()
    .enumerate()
    .map(|(k, &(error, level, step))| (k, 2 * k + 2, error, level, step))
    .collect();
let columns = serde_json::json!([
    { "key": "0", "label": "Column k", "type": "integer" },
    { "key": "1", "label": "Error order p_{k+1}", "type": "integer" },
    { "key": "2", "label": "Minimum error [-]", "type": "number", "format": sci3 },
    { "key": "3", "label": "Corresponding level i", "type": "integer" },
    { "key": "4", "label": "Corresponding step h_i [-]", "type": "number", "format": sci3 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "columns" })
);
// Pass the manual table and ratio to the adaptive-comparison cell.
export!(table, table);
export!(ratio, r);
```

At default $r = 1.4$, column-0 error follows dashed $h^2 \lvert f'''(x_0) \rvert / 6$ with slope 2.
Below step $h \approx 5 \times 10^{-6}$, rounding dominates and errors increase variably around guideline $\varepsilon \lvert f \rvert / h$.
Columns 1 and 2 fall with slopes 4 and 6, reaching error floors around $10^{-14}$ at $h \approx 1.2 \times 10^{-3}$ and $3.2 \times 10^{-3}$ respectively.
Columns 3 and 4 give errors below $10^{-15}$ even at large step $8.8 \times 10^{-3}$.
Higher-order columns eliminate truncation at larger steps, attaining accuracy before difference rounding grows.
Column-0 minimum $2.1 \times 10^{-12}$ ($h = 7.1 \times 10^{-7}$) and column-1 minimum $9.8 \times 10^{-15}$ ($h = 7.9 \times 10^{-5}$) happen to be small through rounding variation.
For example, that column-0 error is far below rounding guideline $5 \times 10^{-10}$ at the same step.
At $r = 2$, rounding amplification in column 1 onward falls to at most 1.67, but coarser steps provide fewer levels near the minimum, so column minima are not below those at $r = 1.4$.

## Error estimates and rounding floors

Extrapolation tables provide error estimates as well as values.
Adaptive differences in `scioxide-differentiate` offer two [`AdaptiveDifferenceMethod`](https://docs.rs/scioxide-differentiate/0.1.0/scioxide_differentiate/enum.AdaptiveDifferenceMethod.html) methods differing in ratio, columns, and truncation estimate $T_{i,k}$.

| Method | Ratio $r$ | Columns | Truncation estimate $T_{i,k}$ |
|---|---|---|---|
| `Ridders` (default) | 1.4 | All columns ($1 \le k \le i$) | $\max(\lvert A_{i,k} - A_{i,k-1} \rvert, \lvert A_{i,k} - A_{i-1,k-1} \rvert)$ |
| `Richardson` | 2 | Column 1 only | $\lvert A_{i,1} - A_{i-1,1} \rvert / (r^{2 + \iota} - 1)$ for $i \ge 2$; same formula as `Ridders` for $i = 1$ |

`Ridders` uses Ridders' (1982) method, estimating errors for every table entry.
It treats the last elimination's change as the error magnitude, rather than deriving an estimate from the expansion.
`Richardson` repeats one extrapolation $A_{i,1}$ while halving steps and derives its error from the expansion.
Setting $q = 2 + \iota$, the difference of $A_{i,1} = D + c\,h_i^{q} + \cdots$ and $A_{i-1,1} = D + c\,r^{q} h_i^{q} + \cdots$ is $-c\,(r^{q} - 1) h_i^{q}$; dividing by $r^{q} - 1$ gives leading error $\lvert c \rvert h_i^{q}$ of $A_{i,1}$.
Both have equal calls per level, but faster step reduction makes `Richardson` reach rounding sooner at equal levels.

Error estimate $E_{i,k}$ adds propagated-rounding estimate $\rho_{i,k}$ to truncation estimate $T_{i,k}$.
$\rho_{i,k}$ acts as the minimum estimated error and is called the rounding floor here.
Column-0 floors are estimated from weights and function values by this formula.

$$
\rho_{i,0} = \frac{4 \varepsilon}{s_i^{m}} \sum_j \lvert w_j \rvert \bigl(\lvert \operatorname{Re} f_j \rvert + \lvert \operatorname{Im} f_j \rvert\bigr).
$$

Here $s_i$ is the farthest-node distance at level $i$; $w_j$ are difference weights for displacements normalized by $s_i$; $f_j$ is the value at node $j$; $m$ is derivative order.
Extrapolated floors propagate through the same linear combination as the recurrence, adding result rounding $\varepsilon \lvert A_{i,k} \rvert$.

$$
\rho_{i,k} = \frac{r^{p_k} \rho_{i,k-1} + \rho_{i-1,k-1}}{r^{p_k} - 1} + \varepsilon \lvert A_{i,k} \rvert, \qquad E_{i,k} = T_{i,k} + \rho_{i,k}.
$$

Adding floors avoids claiming sub-rounding accuracy even when table differences become smaller than rounding.
At each level, the extrapolated entry so far (columns 1 onward) with minimum $E_{i,k}$ is the best estimate, whose value and estimated error return.
Estimates are not upper bounds; they assume the extrapolation expansion holds.
Nonsmooth $f$ near the point invalidates that assumption and can make estimates understate errors.

## Step and stopping rules

[`AdaptiveDifference`](https://docs.rs/scioxide-differentiate/0.1.0/scioxide_differentiate/struct.AdaptiveDifference.html) constructs central nodes $\{x_i - h, x_i, x_i + h\}$ at each level and adds that difference to the table.
Initial step is $0.5 \max(1, \lvert x_i \rvert)$, divided by $r$ each level.
With bounds, use symmetric nodes if the level's step fits; otherwise use roomier-side nodes $\{x_i, x_i + h, x_i + 2h\}$ (through $x_i + 3h$ for second derivatives; [Domain boundaries and one-sided differences](oxref:differentiate-bounded-other-methods)).
Steps are not reduced to boundary distance; early near-boundary levels are one-sided, switching to symmetric once steps fall below that distance.
Since coordinates round, recurrences use actual ratios derived from rounded nodes rather than nominal $r$.
Node-shape changes or actual ratios at most 1 invalidate a shared expansion, restarting the table at column 0.

Each threshold uses [`ErrorTolerance`](https://docs.rs/scioxide-core/0.1.0/scioxide_core/struct.ErrorTolerance.html) absolute $\tau_{\mathrm{abs},i}$ and relative $\tau_{\mathrm{rel}}$ tolerances as $\tau_{\mathrm{abs},i} + \tau_{\mathrm{rel}} \lvert A \rvert$ ($A$ is the tested entry value).
Only maximum norm `NormSelection::Infinity` is accepted, testing componentwise.
Mixed Hessian terms publish at both $(i, j)$ and $(j, i)$, using the smaller threshold.
A level meets the threshold when, for every output, some current-level entry's $E_{i,k}$ and the best estimate's error are both at or below the threshold.

A component's extrapolation stops for one of these reasons ([`DifferentiationTermination`](https://docs.rs/scioxide-differentiate/0.1.0/scioxide_differentiate/enum.DifferentiationTermination.html)).

| Termination | Condition | Values and estimates published |
|---|---|---|
| `Converged` | Threshold met at 2 consecutive levels (count restarts with the table) | Yes |
| `RoundoffLimit` | After obtaining estimates, no output's best error improved for 3 consecutive levels | If every component has an estimate |
| `RefinementLimit` | Maximum $L$ levels exhausted | If every component has an estimate |
| `StepSizeLimit` | Reduced steps cannot place distinct finite nodes inside bounds (zero steps, rounding onto the base, or identical nodes to previous level) | If every component has an estimate |
| `EvaluationLimit`, `IterationLimit` | Evaluation or iteration (level) limit reached | No |
| `Cancelled`, `DeadlineReached` | External cancellation or deadline | No |

`Converged` needs at least 3 levels.
Level 1 alone has no estimate, and requiring 2 consecutive successes avoids accepting accidental agreement.
`RoundoffLimit` infers rounding dominance when shrinking steps no longer lowers estimates; it does not directly detect rounding.
Gradient and Jacobian tables restart per coordinate; report termination is that of the first component stopping without `Converged`.
Evaluation or iteration limits, cancellation, and deadlines take precedence over earlier component termination.
A component stopping without any estimate prevents evaluation of remaining components.

Check publication through [`DifferentiationReport::output_available`](https://docs.rs/scioxide-differentiate/0.1.0/scioxide_differentiate/struct.DifferentiationReport.html#method.output_available).
As the table shows, `RoundoffLimit`, `RefinementLimit`, or `StepSizeLimit` can still publish values and estimates when every component has an estimate.
Inspect both termination and estimates before using values.
Adaptive report `is_success()` is true only for `Converged`; `require_success()` converts other terminations into errors such as `ConvergenceFailure` (`RoundoffLimit` becomes `Stagnation`; `RefinementLimit` becomes `TruncationLimit`).

## Options and evaluation counts

[`AdaptiveDifference`](https://docs.rs/scioxide-differentiate/0.1.0/scioxide_differentiate/struct.AdaptiveDifference.html) defaults to `Ridders`, tolerance $\tau_{\mathrm{abs}} = \tau_{\mathrm{rel}} = \sqrt{\varepsilon} \approx 1.5 \times 10^{-8}$ (maximum norm), at most 16 levels, initial $0.5 \max(1, \lvert x_i \rvert)$, sequential execution, and no limits.
Change them with `with_method`, `with_tolerance`, `with_max_levels`, `with_step`, `with_execution`, `with_max_workspace_bytes`, and `with_budgets`.
Levels must be 3–64 and norm maximum; violations give `InvalidInput` (`self`, `OutOfRange`) at evaluation.
For variables far below 1 or nearby poles or domain endpoints, specify initial steps with `with_step` ([Derivatives and error estimates for the van der Waals equation](../../examples/van-der-waals-adaptive/)).
Absolute tolerances have derivative units; match them with `with_tolerance` when derivative magnitudes are far from 1.
With default $\sqrt{\varepsilon}$ and tiny derivatives such as $10^{-30}$, estimated errors much larger than the derivative still satisfy the threshold if they are below $\sqrt{\varepsilon}$, yielding `Converged` with wrong values ([Temperature sensitivity of the Arrhenius equation with complex steps](../../examples/arrhenius-complex-step/)).

`AdaptiveDifference` selects operations by methods `derivative(f, x)`, `second_derivative(f, x)`, `gradient(f, x, bounds)`, `jacobian(f, x, m, bounds)`, `hessian(f, x, bounds)`, and `jvp(f, x, v, m, bounds)`.
Gradients, Jacobians, Hessians, and directions also have borrowed `_into`.
Unlike fixed `FiniteDifference`, it accepts no known `base`; scalar `derivative` and `second_derivative` accept no bounds.
Returned [`DifferentiationResult`](https://docs.rs/scioxide-differentiate/0.1.0/scioxide_differentiate/struct.DifferentiationResult.html) holds derivatives in `values()` and componentwise estimates in `errors()`.
Coordinates are real and values real or complex; derivatives are with respect to real coordinates.

Counts add one base evaluation to these per-level calls.

- Gradients and Jacobians: 2 per coordinate; directions: 2; second derivatives and Hessian diagonals: 2 (3 for one-sided levels).
- Mixed Hessian terms combine both axes' first-derivative nodes, up to 8 points, reusing bitwise-identical points; symmetric axes need 4 calls.

A scalar first derivative converging in 3 levels takes 7 calls; using all 16 takes 33.
No one-shot function returns error estimates.
For default scalar first and second derivatives with estimates, call `derivative(f, x)` and `second_derivative(f, x)` of `AdaptiveDifference::default()`.

## Comparing manually built tables with adaptive values

`AdaptiveDifference` uses initial $0.5 \max(1, \lvert x_0 \rvert)$ and ratio $r$ to build the same table as [Errors by Neville-table column](#errors-by-neville-table-column), selecting minimum estimated error without exposing the table itself.
The next cell uses that manual table independently to identify which entry matches the value returned by `AdaptiveDifference`.
Match its ratio with `Ridders` for $r = 1.4$ or `Richardson` for $r = 2$; tolerance $\tau$ sets both absolute and relative values.
The table shows termination, levels, calls, actual error, and the closest extrapolated entry through levels used by `AdaptiveDifference` (column 1 only for `Richardson`).

```rust
//| id: differentiate-neville-adaptive-check
//| ref: differentiate-neville-adaptive-check
//| title: "Comparing adaptive values with entries in a manually constructed Neville-type table"
//| run: reactive
//| uses: [differentiate-extrapolation-model]
//| crates: [scioxide-core, scioxide-differentiate]
//| dependsOn:
//|   tableau: differentiate-neville-tableau
//| inputs:
//|   tolerance: {"type":"select","label":"Tolerance τ (absolute and relative)","options":["√ε (default)","1e-12"],"value":"√ε (default)"}
//| cases:
//|   - {"id":"tight","label":"τ = 10⁻¹²","description":"More levels select lower rows, but values still match table entries.","inputs":{"tolerance":"1e-12"}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"adaptive","path":"/rows/0/1","equals":"Converged"}
//|       - {"artifact":"adaptive","path":"/rows/0/3","equals":15}
//|       - {"artifact":"adaptive","path":"/rows/0/7","range":{"max":1e-13}}
//|   - case: tight
//|     expect:
//|       - {"artifact":"adaptive","path":"/rows/0/3","equals":17}
//|       - {"artifact":"adaptive","path":"/rows/0/7","range":{"max":1e-13}}
use scioxide_core::{ErrorTolerance, NormSelection};
use scioxide_differentiate::{AdaptiveDifference, AdaptiveDifferenceMethod};

let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let table: Vec<Vec<f64>> =
    serde_json::from_value(tableau["table"].clone()).map_err(|e| e.to_string())?;
let r = tableau["ratio"].as_f64().ok_or("No reduction ratio")?;
// Ratio 2 is Richardson; 1.4 is Ridders. Both start at 0.5 max(1, |x₀|) = 0.5.
let (method, name) = if r == 2.0 {
    (AdaptiveDifferenceMethod::Richardson, "Richardson")
} else {
    (AdaptiveDifferenceMethod::Ridders, "Ridders")
};
let tau = match tolerance.as_str() {
    "√ε (default)" => f64::EPSILON.sqrt(),
    text => text.parse().map_err(|_| "Cannot read tolerance")?,
};
let x0 = 0.5_f64;
let adaptive = AdaptiveDifference::default()
    .with_method(method)
    .with_tolerance(
        ErrorTolerance::scalar(tau, tau, NormSelection::Infinity).map_err(|e| e.to_string())?,
    )
    .derivative(smooth, x0)
    .map_err(|e| e.to_string())?;
let report = adaptive.report();
let derivative = adaptive.values().ok_or("Derivative not published")?[0];
// Find the extrapolated entry nearest the adaptive result through used levels (Richardson column 1 only).
let last_column = if method == AdaptiveDifferenceMethod::Richardson {
    1
} else {
    report.iterations()
};
let mut nearest = (f64::INFINITY, 0_usize, 0_usize);
for (i, row) in table.iter().enumerate().take(report.iterations()) {
    for (k, entry) in row.iter().enumerate().take(last_column + 1).skip(1) {
        if (entry - derivative).abs() < nearest.0 {
            nearest = ((entry - derivative).abs(), i, k);
        }
    }
}
let check = [(
    name,
    report.termination().to_string(),
    report.iterations(),
    report.evaluations(),
    (derivative - smooth_derivative(x0)).abs(),
    nearest.1,
    nearest.2,
    nearest.0,
)];
let columns = serde_json::json!([
    { "key": "0", "label": "Method" },
    { "key": "1", "label": "Termination reason" },
    { "key": "2", "label": "Levels", "type": "integer" },
    { "key": "3", "label": "Evaluations [count]", "type": "integer" },
    { "key": "4", "label": "Actual error [-]", "type": "number", "format": sci3 },
    { "key": "5", "label": "Nearest-entry level i", "type": "integer" },
    { "key": "6", "label": "Its column k", "type": "integer" },
    { "key": "7", "label": "Difference from entry [-]", "type": "number", "format": sci3 }
]);
emit_table_with_columns!(
    columns,

    metadata = serde_json::json!({ "id": "adaptive" })
```

At default tolerance $\sqrt{\varepsilon}$, `Ridders` reaches `Converged` in 7 levels ($i = 0$ through 6; $1 + 2 \times 7 = 15$ calls), returning a bitwise match to manual level 6, column 6.
Actual error is $1.1 \times 10^{-15}$.
At $\tau = 10^{-12}$, 8 levels (17 calls) return the level-7, column-5 entry.
The minimum estimate need not lie at the lower-right corner; column 5's estimate here is smaller than every other entry's.
Selecting $r = 2$ in the table cell makes `Richardson` also reach `Converged` in 7 levels with defaults, matching level 6, column 1.
`Richardson` uses column 1 only and stops on tolerance, giving actual error $1.5 \times 10^{-10}$.
This confirms selection from the recurrence's table, not accuracy of the selected value.

## Summary

Richardson combines differences with steps reduced by $r$ to eliminate leading $h^{p}$ and raise order through a Neville table, while each column amplifies rounding.
`Ridders` of `AdaptiveDifference` (default, $r = 1.4$) estimates the error of every table entry and selects the one with the smallest estimated error; `Richardson` ($r = 2$) repeats one extrapolation and estimates errors from differences between successive values.
Estimates add truncation estimates and rounding floors, without upper-bound guarantees; check consequential values independently.
Two consecutive threshold successes give `Converged`; 3 nonimproving extrapolated levels with the same node configuration give `RoundoffLimit`.
Boundary-triggered configuration changes reset tables and stagnation history, retaining prior best estimates as fallback.
Both terminations publish values and estimates if every component has an estimate; inspect termination and estimates together.
Initial $0.5 \max(1, \lvert x \rvert)$ means very small variables or nearby poles require explicit `with_step` steps; derivative scales far from 1 require matching absolute tolerance through `with_tolerance`.
