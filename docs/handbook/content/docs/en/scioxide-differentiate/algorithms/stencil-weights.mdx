Forward and central differences are special cases using two or three equally spaced points.
Irregular tables, one-sided nodes near boundaries, or five- and seven-point high-order formulas require weights from node positions.
This page derives moment conditions, explains their stable solution through Fornberg's recurrence, and examines noise amplification as nodes increase.
In `scioxide-differentiate`, `FiniteDifferenceStencil` constructs weights for caller-held values.
For callable functions with supplied nodes, see [Plans and method values for specified-node differences](../node-difference-plans/).

## Moment conditions

Choose an evaluation point $x_0$ and $N$ distinct nodes $x_1, \dots, x_N$, and approximate the derivative of order $m$ by a linear combination of function values.

$$
f^{(m)}(x_0) \approx \sum_{j=1}^{N} w_j f(x_j).
$$

Coefficients $w_j$ are difference weights; nodes and weights together form a stencil.
Assume $f$ is sufficiently smooth near $x_0$.
Writing displacements $\Delta_j = x_j - x_0$ and expanding $f(x_j)$ around $x_0$ gives this approximation.

$$
\sum_{j=1}^{N} w_j f(x_j) = \sum_{k \ge 0} \frac{f^{(k)}(x_0)}{k!} \sum_{j=1}^{N} w_j \Delta_j^{\,k} .
$$

For the right side to equal $f^{(m)}(x_0)$, the $k = m$ coefficient must be 1 and all other $k$ coefficients 0.
With $N$ unknowns, impose $N$ conditions for $k = 0, \dots, N - 1$.

$$
\sum_{j=1}^{N} w_j \Delta_j^{\,k} = k! \, \delta_{km} \qquad (k = 0, 1, \dots, N - 1).
$$

These are moment conditions.
Coefficient matrix $(\Delta_j^{\,k})$ is a transposed Vandermonde matrix.
Distinct nodes make it nonsingular, giving unique weights whenever $m < N$.
The formula differentiates polynomials through degree $N - 1$ exactly.

Error starts with the first unconstrained $k = N$ term.
With node spread $s = \max_j \lvert \Delta_j \rvert$, $\Delta_j^{\,k} = O(s^k)$ and weights $O(s^{-m})$ give truncation $O(s^{N - m})$.

$$
\sum_{j} w_j f(x_j) - f^{(m)}(x_0) = \frac{f^{(N)}(x_0)}{N!} \sum_{j} w_j \Delta_j^{\,N} + O(s^{N + 1 - m}).
$$

For nodes symmetric about $x_0$, weights have odd parity when $m$ is odd and even parity otherwise.
Terms $\sum_j w_j \Delta_j^{\,k}$ with odd $k - m$ therefore cancel to zero.
If $N - m$ is odd, term $k = N$ vanishes, raising order by one to $N + 1 - m$.
If $N - m$ is even, term $k = N$ remains and order stays $N - m$.
Three-point central formulas are second order for both first ($N - m = 2$) and second ($N - m = 1$) derivatives.
Five-point central formulas are fourth order for both.

## Why not solve Vandermonde systems directly?

For real nodes, transposed Vandermonde conditioning grows exponentially with node count.
General Gaussian elimination costs $O(N^3)$ and loses more significant digits as nodes increase.
Algorithms exploiting Vandermonde structure, such as Björck–Pereyra or Fornberg below, often compute weights more accurately than conditioning suggests.
Fornberg simultaneously constructs weights of orders $0$ through $m$ in $O(N^2 (m + 1))$ operations, so `scioxide-differentiate` uses it.

## Fornberg's recurrence

Fornberg's (1988) method updates Lagrange-interpolant derivatives while adding one node at a time.
Take the evaluation point as origin and order displacement nodes $\alpha_0, \alpha_1, \dots$.
Write $\delta^{m}_{n,\nu}$ for the weight multiplying the value at node $\alpha_\nu$ when approximating the derivative of order $m$ using $n + 1$ nodes $\alpha_0, \dots, \alpha_n$.
Initialize $\delta^{0}_{0,0} = 1$.
Setting $c_0 = 1$ and $c_n = \prod_{\nu < n} (\alpha_n - \alpha_\nu)$, adding node $\alpha_n$ updates existing weights as follows.

$$
\delta^{m}_{n,\nu} = \frac{\alpha_n \, \delta^{m}_{n-1,\nu} - m \, \delta^{m-1}_{n-1,\nu}}{\alpha_n - \alpha_\nu} \qquad (\nu < n).
$$

The new node's weight uses the previous stage's final weight.

$$
\delta^{m}_{n,n} = \frac{c_{n-1}}{c_n} \left( m \, \delta^{m-1}_{n-1,n-1} - \alpha_{n-1} \, \delta^{m}_{n-1,n-1} \right).
$$

Terms with negative $m$ and weights of $m > n$ are treated as 0.
After all nodes, $\delta^{m}_{N-1,\nu}$ gives the desired weights, simultaneously with orders $0$ through $m$.
Each addition costs existing nodes times order count $m + 1$, totaling $O(N^2 (m + 1))$.

## SciOxide implementation

[`FiniteDifferenceStencil`](https://docs.rs/scioxide-differentiate/0.1.0/scioxide_differentiate/struct.FiniteDifferenceStencil.html)`::new(c, nodes, order)` constructs order-`order` derivative weights at `c` for caller-selected nodes `nodes`.
Nodes may be irregularly spaced or lie on one side of `c`.
Node order is preserved; `apply(values)` weights values in that order and returns derivatives in physical units.
Values may be real or complex.
`order = 0` gives interpolation.
Weight construction performs three adjustments.

First divide displacements by their largest absolute value $s = \max_j \lvert x_j - c \rvert$ and run the recurrence on normalized displacements in $[-1, 1]$.
Products $c_n$ change geometrically with node count; rescaling controls displacement magnitudes to prevent overflow.
Physical weights are normalized weights divided by $s^m$.

Next, add nodes from nearest to farthest from the base.
On clustered grids, adding distant nodes first causes large intermediate magnitude changes.

Finally, if normalized displacements are closed under sign reversal (every node has a mirror), enforce weight parity.
Odd-order weights should be antisymmetric and even-order symmetric; replace each pair with its sign-adjusted average to remove rounding-induced parity errors.

When $m \ge 1$, `apply` subtracts from every sample the midpoint of the nearest node's value and its mirror's value before weighting.
Without a mirror, subtract only the nearest value.
Weights sum mathematically to 0, leaving the result unchanged and making constant data exactly zero even with rounded weights.
Dot products use an accumulator (`scioxide_core::RangeAccumulator`) retaining unrounded products and round only once at the end.
Preparation costs $O(N^2 (m + 1))$; each `apply` call takes $O(N)$ operations without allocation.

Read weights and auxiliary quantities through these methods.

| Method | Returned value |
|---|---|
| `normalized_weights()` | Weights $w_j$ for normalized displacements $(x_j - c)/s$ |
| `weights()`, `weights_into(out)` | Physical weights $w_j / s^m$ (`weights` allocates an array; `weights_into` uses a caller array) |
| `scale()` | Displacement scale $s$ |
| `weight_amplification()` | Absolute normalized-weight sum $A_w = \sum_j \lvert w_j \rvert$ |
| `coordinate()`, `nodes()`, `derivative_order()` | Point $c$, nodes, and order $m$ |

`weights` divides each weight by $s^m$ once without intermediate rounding of $s^m$.
Weights zero by symmetry, such as central weights of three-point first differences, are exactly zero.
`weights_into` computes every weight before writing, leaving `out` unchanged on errors.
For weighted sums, use `apply` with base subtraction and unrounded accumulation.

`new` rejects nonfinite points or nodes with `NonFinite`, empty nodes or $m \ge N$ with `InvalidInput` (`nodes`, `OutOfRange`), and duplicates with `InvalidInput` (`nodes`, `Inconsistent`).
Nodes becoming indistinguishable after normalization or recurrence overflow give `NumericalInstability`.
`apply` gives `DimensionMismatch` for value-count mismatches, `NonFinite` for nonfinite values, and `NumericalInstability` for result overflow or nonzero underflow to zero.
`weights` and `weights_into` give `NumericalInstability` for physical-weight overflow or underflow to zero; `weights_into` gives `DimensionMismatch` for mismatched `out` length.

## Absolute-weight sums and noise amplification

For value errors $e_j$ ($\lvert e_j \rvert \le \sigma$), their derivative-error contribution is bounded as follows.

$$
\Bigl\lvert \sum_j w_j e_j \Bigr\rvert \le \sigma \sum_j \lvert w_j \rvert .
$$

If $e_j$ are independent with mean zero and variance $\sigma^2$, the standard deviation is $\sigma \sqrt{\sum_j w_j^2}$.
`weight_amplification()` returns normalized absolute sum $A_w$; its physical counterpart is $A_w / s^m$.
This measures value-error amplification, not total derivative error including truncation.

For equally spaced central first derivatives, $A_w$ grows moderately: 1 for 3 nodes, 3 for 5, 5.5 for 7.
With spacing $h$, $s = (N - 1) h / 2$ gives physical sums $1/h$, $1.5/h$, and $1.83/h$, so added nodes barely change noise amplification.
One-sided first derivatives instead grow rapidly: physical sums $4/h$ for 3 nodes, $10.7/h$ for 5, $27.7/h$ for 7 ($A_w$ is 8, 42.7, 166), worsening noisy results despite higher order.
Higher-order benefits depend on balancing truncation reduction against this amplification.

## Measuring moment conditions and leading errors

The next cell selects node layout, count, and derivative order to construct `FiniteDifferenceStencil` and compute moment residuals $\sum_j w_j \xi_j^{\,k} / k! - \delta_{km}$ from normalized $\xi_j$ and weights.
At $k < N$, residuals are rounding-sized; the first nonzero moment $\mu_{k^\ast}$ at $k \ge N$ determines leading error $f^{(k^\ast)}(x_0) s^{k^\ast - m} \mu_{k^\ast}$.
The function is $f(x) = e^x$, point $x_0 = 0.3$, and basic spacing $0.1$.
Move equal-grid position $t_j$ to $t_j (1 + 0.15 t_j)$ to obtain irregular nodes.
The main computation is `FiniteDifferenceStencil::apply`; exact and leading values are f64 references, while moment residuals are weight postprocessing.
Also differentiate with half spacing and compare observed order $\log_2$ of the error ratio with leading order.
Rounding guideline $u \sum_j \lvert w_j \rvert \lvert f \rvert$ uses physical weights returned by `weights()`.

use scioxide_differentiate::FiniteDifferenceStencil;

let (x0, spacing) = (0.3_f64, 0.1_f64);
let count = count as usize;
let order: usize = order.parse().map_err(|_| "Cannot read derivative order")?;
// Supply displacements as basic-spacing multiples t_j.
let offsets: Vec<f64> = (0..count)
    .map(|j| {
        let t = j as f64 - (count - 1) as f64 / 2.0;

            "One-sided, uniform" => j as f64,
            "Central, uniform" => t,
            _ => t * (1.0 + 0.15 * t),

    let nodes: Vec<f64> = offsets.iter().map(|t| x0 + d * t).collect();
    let stencil = FiniteDifferenceStencil::new(x0, &nodes, order)?;
    let values: Vec<f64> = nodes.iter().map(|&x| RealScalar::exp(x)).collect();

// Leading prediction f^(k*)(x0) s^(k*−m) μ_k*, using reference e^{x0}.
let predicted = exact * s.powi((k_star - order) as i32) * mu;
// Rounding guideline u Σ|w_j| |f|; read physical w_j / s^m with weights().

let spread: f64 = weights.iter().map(|w| w.abs()).sum();
// Observed order: log₂ of the error ratio under halved spacing.
let observed = ((derivative - exact) / (halved - exact)).abs().log2();
let summary = vec![(

    stencil.weight_amplification(),

)];
let columns = serde_json::json!([
    { "key": "0", "label": "Scale s [-]", "type": "number", "format": fixed3 },
    { "key": "1", "label": "A_w [-]", "type": "number", "format": fixed3 },
    { "key": "2", "label": "Leading order k* − m", "type": "integer" },
    { "key": "3", "label": "Measured error [-]", "type": "number", "format": sci3 },
    { "key": "4", "label": "Leading prediction [-]", "type": "number", "format": sci3 },
    { "key": "5", "label": "Rounding guideline [-]", "type": "number", "format": sci3 },
    { "key": "6", "label": "Observed order [-]", "type": "number", "format": fixed2 }
]);

);

Asymmetry leaves moment $k = 5$ ($-6.5 \times 10^{-4}$) nonzero, giving leading order $N - m = 4$.
Measured error $-4.11 \times 10^{-6}$ differs from leading $-4.00 \times 10^{-6}$ by 3%, from the next $k = 6$ term.
Halving spacing gives observed order 4.02; rounding guideline $4.0 \times 10^{-15}$ lies 9 orders below error.

Five uniform central nodes with $m = 1$ retain moment $k = 5$, keeping order $N - m = 4$.
At $m = 2$ on the same nodes (case central-second), moments $k = 5$ with odd $k - m$ vanish through $2 \times 10^{-18}$, moving the leading term to $k = 6$.
Order rises by one from $N - m = 3$ to 4, with observed 4.00.
Leading prediction $-1.500 \times 10^{-6}$ matches Taylor-derived $-h^4 f^{(6)}(x_0) / 90$.
$A_w = 21.33$ matches absolute sum $64/3$ from weights $(-1, 16, -30, 16, -1)/(12 h^2)$ multiplied by $s^2 = 4h^2$.

Three uniform one-sided nodes (case one-sided-three) give $A_w = 8$.
Physical sum $8/s = 4/h$ is four times three-point central $1/h$.
Leading prediction is $-h^2 f'''(x_0)/3 = -4.50 \times 10^{-3}$ and observed order 2.05.
The magnitude of the measured error $-4.85 \times 10^{-3}$ exceeds the prediction by 8% because the one-sided formula also retains the $k = 4$ term $-h^3 f^{(4)}(x_0)/4$.

## Measuring node counts and noise amplification

The next cell constructs uniform central first derivatives with 3, 5, and 7 nodes, plotting errors for noisy $f(x) = e^x + \sigma \eta(x)$ at $x_0 = 0.5$ against spacing $h$.
$\eta$ is the same point-bit-and-seed pseudorandom noise in $[-1, 1)$ as [Rounding, noise, and optimal step size](oxref:differentiate-noisy-functions).
Pass node values to `apply` and construct weights with `FiniteDifferenceStencil`.

Use an upper-bound model to interpret errors.
An $N$-node formula has leading $c_N h^{N-1} f^{(N)}(x_0)$ and noise error at most $\sigma \sum_j \lvert w_j \rvert = \sigma B_N / h$, with $B_N = h \sum_j \lvert w_j \rvert$ independent of spacing.

$$
E_N(h) = c_N h^{p} e^{x_0} + \frac{\sigma B_N}{h}, \qquad p = N - 1 .
$$

The spacing that minimizes $E_N$ and the resulting minimum value follow.

$$
h^\ast = \left( \frac{\sigma B_N}{p \, c_N e^{x_0}} \right)^{1/(p+1)}, \qquad E_N(h^\ast) = \frac{\sigma B_N}{h^\ast} \left( 1 + \frac{1}{p} \right).
$$

The cell reads unit-spacing weights with `weights()` and obtains $B_N$ and $c_N = \lvert \sum_j w_j t_j^{\,N} \rvert / N!$.
Taylor values are $c_3 = 1/6$, $c_5 = 1/30$, and $c_7 = 1/140$.
Dashed lines show model $E_N(h)$ and symbols measured errors; count and exclude zero errors from logarithmic axes.

//| crates: [scioxide-core, scioxide-differentiate]

//|   - case: default

//|       - {"artifact":"noise","path":"/rows/2/2","approx":{"value":1.8333333333333333,"rtol":1e-12}}
//|       - {"artifact":"noise","path":"/rows/0/3","approx":{"value":0.16666666666666666,"rtol":1e-12}}
//|       - {"artifact":"noise","path":"/rows/1/3","approx":{"value":0.03333333333333333,"rtol":1e-12}}
//|       - {"artifact":"noise","path":"/rows/2/3","approx":{"value":0.007142857142857143,"rtol":1e-12}}
//|       - {"artifact":"noise","path":"/rows/0/7","range":{"max":5.8e-6}}
//|       - {"artifact":"noise","path":"/rows/2/5","approx":{"value":1.8665e-7,"rtol":1e-3}}
//|   - case: large-noise
//|     expect:
//|       - {"artifact":"noise","path":"/rows/2/4","range":{"min":0.4,"max":0.45}}
//|       - {"artifact":"noise","path":"/rows/0/7","range":{"max":2.7e-3}}
//|   - case: other-seed
//|     expect:
//|       - {"artifact":"noise","path":"/rows/1/7","range":{"max":6e-7}}
use scioxide_core::RealScalar;
use scioxide_differentiate::FiniteDifferenceStencil;

let sigma: f64 = sigma.parse().map_err(|_| "Cannot read σ")?;
let seed = seed as u64;
// Noise model: mix point bits and seed with splitmix64 into a value in [-1, 1).
let noise = |t: f64| {
    let mut z = t.to_bits() ^ seed.wrapping_mul(0x9E37_79B9_7F4A_7C15);
    z = (z ^ (z >> 30)).wrapping_mul(0xBF58_476D_1CE4_E5B9);
    z = (z ^ (z >> 27)).wrapping_mul(0x94D0_49BB_1331_11EB);
    z ^= z >> 31;
    (z >> 11) as f64 / (1_u64 << 53) as f64 * 2.0 - 1.0
};
let x0 = 0.5_f64;
// Reference: every f derivative is e^{x0} (f64 inherent methods).
let exact = x0.exp();
let mut series = Vec::new();
let mut rows = Vec::new();
for count in [3_usize, 5, 7] {
    // From unit-spacing node weights t_j, compute B_N = h Σ|w_j| and c_N = |Σ w_j t_j^N| / N!.
    let unit: Vec<f64> = (0..count).map(|j| j as f64 - (count / 2) as f64).collect();
    let reference = FiniteDifferenceStencil::new(0.0, &unit, 1).map_err(|e| e.to_string())?;
    let weights = reference.weights().map_err(|e| e.to_string())?;
    let spread: f64 = weights.iter().map(|w| w.abs()).sum();
    let factorial: f64 = (1..=count).map(|i| i as f64).product();
    let moment: f64 = weights
        .iter()
        .zip(&unit)
        .map(|(w, t)| w * t.powi(count as i32))
        .sum();
    let leading = moment.abs() / factorial;
    let p = (count - 1) as f64;
    let h_star = (sigma * spread / (p * leading * exact)).powf(1.0 / (p + 1.0));
    let e_star = sigma * spread / h_star * (1.0 + 1.0 / p);
    let (mut measured, mut model, mut dropped) = (Vec::new(), Vec::new(), 0_usize);
    let mut best = (f64::INFINITY, 0.0);
    for k in 0..=40 {
        let h = 10.0_f64.powf(-8.0 + 0.2 * k as f64);
        let nodes: Vec<f64> = unit.iter().map(|t| x0 + h * t).collect();
        let stencil = FiniteDifferenceStencil::new(x0, &nodes, 1).map_err(|e| e.to_string())?;
        let values: Vec<f64> = nodes
            .iter()
            .map(|&x| RealScalar::exp(x) + sigma * noise(x))
            .collect();
        let error = (stencil.apply(&values).map_err(|e| e.to_string())? - exact).abs();
        model.push([h, leading * h.powf(p) * exact + sigma * spread / h]);
        if error > 0.0 {
            measured.push([h, error]);
        } else {
            dropped += 1;
        }

## Summary

Weights approximating a derivative of order $m$ at $N$ nodes are uniquely determined by the moment conditions $\sum_j w_j \Delta_j^{\,k} = k!\,\delta_{km}$ ($k < N$), giving truncation error $O(s^{N - m})$, or $O(s^{N + 1 - m})$ for symmetric nodes with odd $N - m$.
The first surviving moment predicts leading error, and halved-spacing ratios check order.
`FiniteDifferenceStencil` runs Fornberg on normalized displacements, returns physical weights through `weights` and noise guideline $A_w$ through `weight_amplification`.
Adding nodes to equally spaced central differences barely increases noise amplification, but one-sided formulas increase it rapidly; choose noisy-data node counts and spacings with the upper-bound model $E_N(h)$.
For tables alone, use `apply` of `FiniteDifferenceStencil`; for callable functions, pass nodes to a node Plan or method.
