This table covers types specifying derivative operations, formulas, and steps; fixed-step method values; and differences with caller-selected nodes.
Fixed-step `FiniteDifference` accepts only real function values and returns no error estimate.
Its termination reason `Completed` indicates only that planned evaluations finished.
Node differences support real and complex values, rejecting out-of-bounds nodes rather than moving them to fit bounds.
Every evaluation leaves borrowed output unchanged on errors or when output is not published; borrowed forms with sufficient workspace allocate no numerical storage.

## Fixed-step finite differences

| Item | Kind | Role | Contract essentials | Explanation | Executable example |

| [`FiniteDifference`](https://docs.rs/scioxide-differentiate/0.1.0/scioxide_differentiate/struct.FiniteDifference.html) | Struct | Fixed-step forward- and central-difference method value | Holds settings only; defaults to `Central`, default steps, sequential execution, unlimited `SolveBudgets`, no workspace limit, `RequireStencil`, and `MathematicalZero`. `with_scheme`, `with_step`, `with_execution`, `with_max_workspace_bytes`, `with_budgets`, `with_fixed_coordinates`, `with_zero_direction`, `scheme()`, `step()`. Settings are checked on every operation. Owned forms `derivative(f, x)`, `second_derivative(f, x)`, `gradient(f, x, bounds, base)`, `hessian(f, x, bounds, base)`, `jacobian(f, x, m, bounds, base)`, and `jvp(f, x, v, m, bounds, base)` return `DifferentiationResult`; borrowed forms `gradient_into`, `hessian_into`, `jacobian_into`, and `jvp_into` accept output, workspace, and `scope` and return `DifferentiationReport` ($m$ in `jvp_into` is output length). `derivative_into(f, x, bounds, base, out, scope)` computes a univariate first derivative using stack storage alone, without workspace (bounds are `ExtendedInterval`; empty bounds give `InvalidInput` (`bounds`, `Empty`)). Real function values only. Weights use actual rounded displacements, and samples are summed after subtracting $f(x)$. `base` supplies known $f(x)$, saving one evaluation. Central counts: first derivatives, gradients, and Jacobians $2n + 1$; second derivatives and Hessians $1 + 2n^2$; directional derivatives 3. Forward counts are $n + 1$, $1 + 2n + n(n-1)/2$, and 2. Hessians evaluate only the upper triangle and reflect it, evaluating bitwise-identical points only once within one evaluation. Central Hessians with one-sided nodes near bounds use at most $1 + 3n + 4n(n-1)$ calls before point reuse. Directional steps are $c / \max_i(\lvert v_i \rvert / \max(1, \lvert x_i \rvert))$ ($c$ is the default-step factor); failure to place distinct nodes inside bounds gives `DifferentiationFailure` (cause `StepSizeLimit` of `ConvergenceFailure`). Returns no error estimates; `Completed` makes no accuracy claim | [Forward and central differences](oxref:differentiate-forward-central), [SciOxide default steps](oxref:differentiate-default-steps) | [First derivatives with central, adaptive, and complex-step methods](oxref:differentiate-first-derivatives), [Truncation-error orders of forward and central differences](oxref:differentiate-truncation-order), [Saving evaluations with known base values and effects of incorrect base values](oxref:differentiate-known-base) |

Depends only on shape and method `max_workspace_bytes`, not point, bounds, or step. `bytes()` gives heap-array bytes for a new workspace. | [`FiniteDifferenceStencil`](https://docs.rs/scioxide-differentiate/0.1.0/scioxide_differentiate/struct.FiniteDifferenceStencil.html) | Struct | Difference weights for caller-selected nodes | `new(c, nodes, d)` computes weights for the derivative of order $d$ from Fornberg's recurrence on normalized displacements $(x_j - c)/s$ ($s = \max_j \lvert x_j - c \rvert$), taking $O(N^2(d+1))$ for $N$ nodes; $d = 0$ means interpolation. `apply(values)` returns $s^{-d} \sum_j w_j f(x_j)$ from real or complex values in node order ($O(N)$, no allocation); mismatched lengths give `DimensionMismatch`, nonfinite values `NonFinite`, and result overflow or underflow `NumericalInstability`. `weights()` and allocation-free `weights_into(out)` return the formula's actual weights $w_j / s^d$ (weights zero by symmetry are exactly zero).
