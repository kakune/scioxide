This table covers one-shot functions, workspace sizing types, function-passing forms, evaluation results and reports, and derivative-source policies.
One-shot functions return only derivative values with defaults and convert unsuccessful termination into errors.
Except for `derivative`, they allocate workspace and results on every call; reuse method values and workspaces inside repeated iterations.
Only `output_available()` determines whether output may be used; termination reason `Completed` makes no accuracy claim, and error estimates are not upper bounds.

## One-shot functions

| Item | Kind | Role | Contract essentials | Explanation | Executable example |
|---|---|---|---|---|---|
| [`derivative`](https://docs.rs/scioxide-differentiate/0.1.0/scioxide_differentiate/fn.derivative.html) | Function | First derivative of $f: \mathbb{R} \to \mathbb{R}$ with default central differences | `derivative(f, x)`, `f: Fn(S) -> Result<S, SciOxideError>` (`S` is `f32` or `f64`). With $(f(x + h) - f(x - h))/(2h)$ and $h = \varepsilon^{1/3}\max(1, \lvert x \rvert)$, takes 3 evaluations including $f(x)$, without allocation. For smooth functions of moderate magnitude, errors are about $\varepsilon^{2/3}$ ($3.7 \times 10^{-11}$ in `f64`, $2.4 \times 10^{-5}$ in `f32`). Returns values only; unsuccessful termination becomes an error. Nonfinite $x$ gives `NonFinite`; function errors and nonfinite values give `DifferentiationFailure`. Use `FiniteDifference` for bounds, formulas, steps, and known $f(x)$; use `AdaptiveDifference` for error estimates | [Call forms](oxref:differentiate-call-forms-terms), [Nine one-shot functions](oxref:differentiate-one-shot-catalog) | [Nine one-shot functions and errors against exact values](oxref:differentiate-one-shot-functions) |
| [`second_derivative`](https://docs.rs/scioxide-differentiate/0.1.0/scioxide_differentiate/fn.second_derivative.html) | Function | Second derivative with default central differences | `second_derivative(f, x)` accepts the same `f` signature as `derivative`. With $(f(x + h) - 2f(x) + f(x - h))/h^2$ and $h = \varepsilon^{1/4}\max(1, \lvert x \rvert)$, takes 3 evaluations. Error about $\sqrt{\varepsilon}$ ($1.5 \times 10^{-8}$ in `f64`). Allocates workspace and result. Errors match `derivative`, plus `AllocationFailure` for allocation failure | [Call forms](oxref:differentiate-call-forms-terms), [Nine one-shot functions](oxref:differentiate-one-shot-catalog) | [Nine one-shot functions and errors against exact values](oxref:differentiate-one-shot-functions) |
| [`gradient`](https://docs.rs/scioxide-differentiate/0.1.0/scioxide_differentiate/fn.gradient.html) | Function | Gradient of $f: \mathbb{R}^n \to \mathbb{R}$ with default central differences | `gradient(f, x)`, `f: Fn(&[S]) -> Result<S, SciOxideError>`. Coordinate $i$ uses step $\varepsilon^{1/3}\max(1, \lvert x_i \rvert)$, with $2n + 1$ evaluations and no bounds. Empty $x$ returns an empty gradient without calling the function. Elementwise errors about $\varepsilon^{2/3}$. Errors match `derivative`, plus `AllocationFailure` for allocation failure | [Call forms](oxref:differentiate-call-forms-terms), [Nine one-shot functions](oxref:differentiate-one-shot-catalog) | [Nine one-shot functions and errors against exact values](oxref:differentiate-one-shot-functions), [One-shot, owned, and borrowed forms and evaluation limits](oxref:differentiate-call-forms) |
| [`hessian`](https://docs.rs/scioxide-differentiate/0.1.0/scioxide_differentiate/fn.hessian.html) | Function | Hessian with default central differences | `hessian(f, x)` accepts the same `f` signature as `gradient`; result is row-major $n \times n$. Coordinate $i$ uses step $\varepsilon^{1/4}\max(1, \lvert x_i \rvert)$; diagonal terms use second differences and mixed terms products of first differences. Only the upper triangle is evaluated, making the result exactly symmetric. $1 + 2n^2$ evaluations and errors about $\sqrt{\varepsilon}$. If $n^2$ exceeds `usize`, gives `SizeOverflow` | [Call forms](oxref:differentiate-call-forms-terms), [Nine one-shot functions](oxref:differentiate-one-shot-catalog) | [Nine one-shot functions and errors against exact values](oxref:differentiate-one-shot-functions) |
| [`jacobian`](https://docs.rs/scioxide-differentiate/0.1.0/scioxide_differentiate/fn.jacobian.html) | Function | Jacobian of $f: \mathbb{R}^n \to \mathbb{R}^m$ with default central differences | `jacobian(f, x, m)` accepts `f: Fn(&[S], &mut [S]) -> Result<(), SciOxideError>`, which writes $m$ values to the output array. Result is row-major $m \times n$, with $\partial f_i / \partial x_j$ at position $in + j$. $2n + 1$ evaluations and errors about $\varepsilon^{2/3}$. If $mn$ exceeds `usize`, gives `SizeOverflow` | [Call forms](oxref:differentiate-call-forms-terms), [Nine one-shot functions](oxref:differentiate-one-shot-catalog) | [Nine one-shot functions and errors against exact values](oxref:differentiate-one-shot-functions) |
| [`jvp`](https://docs.rs/scioxide-differentiate/0.1.0/scioxide_differentiate/fn.jvp.html) | Function | Jacobian–vector product with default central differences | `jvp(f, x, v, m)` accepts the same `f` signature as `jacobian`. One central difference along $\mathbf{v}$ with step $\varepsilon^{1/3} / \max_i(\lvert v_i \rvert / \max(1, \lvert x_i \rvert))$. Takes 3 evaluations regardless of $n$; $\mathbf{v} = \mathbf{0}$ gives $\mathbf{0}$ without calling the function. Length mismatches give `DimensionMismatch`; nonfinite $x$ or $\mathbf{v}$ gives `NonFinite`; failure to place distinct points gives `DifferentiationFailure` (cause `StepSizeLimit` of `ConvergenceFailure`) | [Call forms](oxref:differentiate-call-forms-terms), [Nine one-shot functions](oxref:differentiate-one-shot-catalog) | [Nine one-shot functions and errors against exact values](oxref:differentiate-one-shot-functions) |
| [`sparse_jacobian`](https://docs.rs/scioxide-differentiate/0.1.0/scioxide_differentiate/fn.sparse_jacobian.html) | Function | Sparse Jacobian by coloring with default adaptive differences | `sparse_jacobian(f, x, &schedule)` accepts `f: Fn(&[S], &mut [T]) -> Result<(), SciOxideError>`, which writes all rows with real or complex values. Returns stored entries of `DerivativeColumns` coloring (such as scioxide-sparse `derivative_coloring`) in row order. With `AdaptiveDifference` defaults, extrapolates until every entry's estimated error is at most $\sqrt{\varepsilon}(1 + \lvert J_{ij} \rvert)$ for 2 consecutive levels and the best estimate also meets it (at least 3 levels), using at most $1 + 32c$ evaluations for $c$ colors. Initial step $0.5\max(1, \lvert x_j \rvert)$ must fit the function domain. Coloring other than `DerivativeColumns` gives `InvalidInput` (`schedule`, `UnsupportedConfiguration`); $x$ length mismatching columns gives `DimensionMismatch`; any entry missing tolerance gives `ConvergenceFailure`. Use `ColoredJacobianPlan` for bounds or error estimates | [One-shot functions and workspaces](oxref:differentiate-sparse-one-shot), [Nine one-shot functions](oxref:differentiate-one-shot-catalog) | [Nine one-shot functions and errors against exact values](oxref:differentiate-one-shot-functions) |
| [`complex_step_derivative`](https://docs.rs/scioxide-differentiate/0.1.0/scioxide_differentiate/fn.complex_step_derivative.html) | Function | First derivative of a real function by complex steps of $\varepsilon$ | `complex_step_derivative(f, x)`; `f: Fn(Complex<S>) -> Result<Complex<S>, SciOxideError>` is an analytic extension. Takes 2 evaluations with $\operatorname{Im} f(x + i\varepsilon)/\varepsilon$ ($f(x)$ must be real); accuracy follows rounding error in $f$ evaluation (about $\varepsilon \lvert f'(x) \rvert$). Nonzero imaginary part in $f(x)$ gives `InvalidInput` (`function`, `UnsupportedConfiguration`); nonzero imaginary parts becoming subnormal or quotients rounding to 0 give `NumericalInstability` (`Underflow`). Use `ComplexStep` for changed steps, gradients, or Jacobians | [ComplexStep](oxref:differentiate-complex-step-api), [Nine one-shot functions](oxref:differentiate-one-shot-catalog) | [Nine one-shot functions and errors against exact values](oxref:differentiate-one-shot-functions) |
| [`physical_difference_derivative`](https://docs.rs/scioxide-differentiate/0.1.0/scioxide_differentiate/fn.physical_difference_derivative.html) | Function | First derivative from values at selected nodes | `physical_difference_derivative(f, x, nodes)`, `f: Fn(S) -> Result<T, SciOxideError>`, with real or complex values. Constructs $\sum_k w_k f(x_k)$ with Fornberg weights, exact for polynomials of degree below node count. Nodes need not be equally spaced or include $x$. One evaluation per node. Nonfinite $x$ or nodes give `NonFinite`; fewer than 2 nodes give `InvalidInput` (`nodes`, `OutOfRange`); duplicates give `InvalidInput` (`nodes`, `Inconsistent`) | [One-shot functions for scalar functions](oxref:differentiate-physical-one-shot), [Nine one-shot functions](oxref:differentiate-one-shot-catalog) | [Scalar derivatives and evaluation counts with one-shot functions and displacement nodes](oxref:differentiate-node-scalar-derivative), [Nine one-shot functions and errors against exact values](oxref:differentiate-one-shot-functions) |

## Passing functions

| Item | Kind | Role | Contract essentials | Explanation | Executable example |
|---|---|---|---|---|---|
| [`SampleFunction`](https://docs.rs/scioxide-differentiate/0.1.0/scioxide_differentiate/trait.SampleFunction.html) | Trait (externally sealed) | Function forms accepted by method values and Plans | Implemented only by closures of `FnMut(&[S], &mut [T]) -> Result<(), SciOxideError>`, `Contextual`, and `Parallel`; other types cannot implement it. Functions receive points and must write all $m$ output entries with finite values. Unwritten or nonfinite entries give `DifferentiationFailure` (cause `NonFinite` with origin `Callback`); returned function errors are retained as causes of `DifferentiationFailure`, recording sample location and evaluation count. Closures run sequentially on the caller's thread and stop at the first error. Method `derivative` and `second_derivative` and one-shot `derivative`, `second_derivative`, `gradient`, `hessian`, `physical_difference_derivative`, and `complex_step_derivative` accept value-returning closures. One-shot `jacobian`, `jvp`, and `sparse_jacobian` take `Fn(&[S], &mut [T])` closures, not `Contextual` or `Parallel` | [Passing functions](oxref:differentiate-sample-functions), [Type relationships](oxref:differentiate-api-types) | [Three function-passing forms and reading reports](oxref:differentiate-api-minimal) |
| [`Contextual`](https://docs.rs/scioxide-differentiate/0.1.0/scioxide_differentiate/struct.Contextual.html) | Struct | Function also receiving solve context | `f` in `Contextual(f)` is `FnMut(&[S], &mut [T], &mut SolveContext) -> Result<(), SciOxideError>`. Use to count nested solves or other function-internal work toward this evaluation's evaluation and iteration limits, or when execution context is needed. Runs sequentially on the caller's thread. Report `evaluations()` excludes nested-solve evaluations | [Passing functions](oxref:differentiate-sample-functions), [Type relationships](oxref:differentiate-api-types) | [Three function-passing forms and reading reports](oxref:differentiate-api-minimal) |
| [`Parallel`](https://docs.rs/scioxide-differentiate/0.1.0/scioxide_differentiate/struct.Parallel.html) | Struct | Function supporting parallel evaluation of independent samples | `f` in `Parallel(f)` is `Fn(&[S], &mut [T]) -> Result<(), SciOxideError> + Sync`. Dispatches independent samples to the execution-context executor according to method or Plan policy (`with_execution`). `Sequential` and `Auto` needing only one worker run inline; `Parallel(n)` dispatches even one sample to the executor (`Auto` counts one work unit per sample, with at most 16 workers). In either case, every sample in a level is evaluated before the first error is returned. Only adaptive differences and coloring batch a level's samples; fixed-step, complex-step, and node differences dispatch one sample at a time. Results are collected in sample order, so deterministic functions yield identical values regardless of worker count | [Passing functions](oxref:differentiate-sample-functions), [Type relationships](oxref:differentiate-api-types) | [Three function-passing forms and reading reports](oxref:differentiate-api-minimal) |
