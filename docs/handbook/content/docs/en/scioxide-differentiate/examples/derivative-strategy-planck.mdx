Newton, quasi-Newton, and implicit ODE methods need derivatives each iteration.
Sources are hand-derived analytic expressions, automatic differentiation, and differences.
A common priority is analytic first, then automatic, then differences when unavailable.
`DerivativeStrategy` in `scioxide-differentiate` represents that order and queries candidates through a caller-supplied function.
Using Planck temperature derivatives, this example checks availability switching, exhaustion errors, and wavelength-dependent difference errors.
It then checks Wien's displacement law as a zero wavelength derivative.

## Planck's law and derivatives

Planck's law gives blackbody spectral radiance $B_\lambda$ [W·sr⁻¹·m⁻³] at wavelength $\lambda$ and temperature $T$.

$$
B_\lambda(T) = \frac{2 h c^2}{\lambda^5} \frac{1}{e^{x} - 1}, \qquad x = \frac{h c}{\lambda k_B T}.
$$

$h = 6.62607015 \times 10^{-34}\,\mathrm{J \cdot s}$ is Planck's constant, $c = 299792458\,\mathrm{m/s}$ light speed, and $k_B = 1.380649 \times 10^{-23}\,\mathrm{J/K}$ Boltzmann's constant, all SI-defined values.
Dimensionless $x$ is photon energy $hc/\lambda$ divided by thermal energy $k_B T$.

From $\ln B_\lambda = \ln(2hc^2) - 5 \ln \lambda - \ln(e^x - 1)$, $\partial x / \partial T = -x/T$, and $\partial x / \partial \lambda = -x/\lambda$ follow two logarithmic derivatives.

$$
\frac{T}{B_\lambda} \frac{\partial B_\lambda}{\partial T} = \frac{x}{1 - e^{-x}},
\qquad
\frac{\lambda}{B_\lambda} \frac{\partial B_\lambda}{\partial \lambda} = -5 + \frac{x}{1 - e^{-x}}.
$$

These avoid division between $e^x$ values; evaluating $1 - e^{-x}$ with `exp_m1` avoids cancellation for any $x$ and supplies references.
At short wavelengths $x \gg 1$ (Wien regime), $B_\lambda \propto e^{-x}$, and the temperature derivative of $\ln B_\lambda$ grows to about $x/T$.
At long wavelengths $x \ll 1$ (Rayleigh–Jeans regime), $B_\lambda \propto T$ and relative temperature derivatives approach $1/T$.
At $T = 300\,\mathrm{K}$, visible $\lambda = 0.5\,\mathrm{\mu m}$ gives $x \approx 96$, $\lambda = 10\,\mathrm{\mu m}$ gives $x \approx 4.8$, and $\lambda = 100\,\mathrm{\mu m}$ gives $x \approx 0.48$.

Setting the wavelength logarithmic derivative to zero gives $x = 5(1 - e^{-x})$; positive root $x_W$ maximizes $B_\lambda$ in wavelength.
The root is $x_W = 5 + W_0(-5e^{-5}) = 4.965114231744276\ldots$ in Lambert W ([Wien's displacement law and exact transcendental solutions](oxref:special-example-wien-closed-form)).
Peak wavelength $\lambda_{\max} T = hc/(k_B x_W) = 2.897771955 \times 10^{-3}\,\mathrm{m \cdot K}$ is Wien's displacement law.
$T = 300\,\mathrm{K}$ gives $\lambda_{\max} = 9.659\,\mathrm{\mu m}$; $T = 5800\,\mathrm{K}$ gives $0.4996\,\mathrm{\mu m}$.

The following model is shared by three cells.
`radiance` computes $B_\lambda$ from wavelength [μm] and temperature [K], generic over numeric `Real` to evaluate identically with `f64` or scioxide-ad dual numbers.
`exact_temperature_slope` supplies a temperature-log-derivative reference using `f64` inherent `exp_m1`.
`WIEN_X` is $x_W$ computed from Lambert W.

```rust
//| id: differentiate-planck-model
//| kind: definitions
//| title: "Planck's law and temperature-derivative references"
//| crates: [scioxide-ad]
use scioxide_ad::Real;

/// SI definitions: Planck h [J·s], light speed c [m/s], Boltzmann k_B [J/K].
pub(crate) const PLANCK: f64 = 6.62607015e-34;
pub(crate) const LIGHT: f64 = 299792458.0;
pub(crate) const BOLTZMANN: f64 = 1.380649e-23;
/// hc/k_B [m·K].
pub(crate) const HC_OVER_K: f64 = PLANCK * LIGHT / BOLTZMANN;
/// Positive root of x = 5(1 − e^{−x}): x_W = 5 + W₀(−5e^{−5}).
pub(crate) const WIEN_X: f64 = 4.965114231744276;

/// x = hc/(λ k_B T); accept λ in μm and T in K.
pub(crate) fn photon_ratio(lambda_um: f64, temp: f64) -> f64 {
    HC_OVER_K / (lambda_um * 1e-6 * temp)
}

/// Spectral radiance B_λ(T) [W·sr⁻¹·m⁻³]; evaluate the same expression with f64 or dual numbers.
/// Round x in the same order as photon_ratio to match reference x.
pub(crate) fn radiance<V: Real>(lambda_um: V, temp: V) -> V {
    let lambda = lambda_um * 1e-6;
    let x = V::constant(HC_OVER_K) / (lambda * temp);
    V::constant(2.0 * PLANCK * LIGHT * LIGHT) / lambda.powi(5) / (x.exp() - 1.0)
}

/// Reference: ∂B/∂T = (B/T)·x/(1 − e^{−x}); use exp_m1 for e^x − 1 and 1 − e^{−x}.
pub(crate) fn exact_temperature_slope(lambda_um: f64, temp: f64) -> f64 {
    let x = photon_ratio(lambda_um, temp);
    let value = 2.0 * PLANCK * LIGHT * LIGHT / (lambda_um * 1e-6).powi(5) / x.exp_m1();
    value / temp * x / -(-x).exp_m1()
}
```

## Policies and candidates

`select(provider)` of [`DerivativeStrategy`](https://docs.rs/scioxide-differentiate/0.1.0/scioxide_differentiate/enum.DerivativeStrategy.html) passes [`DerivativeCandidate`](https://docs.rs/scioxide-differentiate/0.1.0/scioxide_differentiate/enum.DerivativeCandidate.html) to `provider` in policy order.
Each policy fixes its order as named.

| Policy | Candidate order |
|---|---|
| `Analytic` | `Analytic` |
| `Automatic` | `AutomaticDifferentiation` |
| `Forward` | `FiniteDifference(Forward)` |
| `Central` | `FiniteDifference(Central)` |
| `AnalyticOrForward` (default) | `Analytic` → `FiniteDifference(Forward)` |
| `AnalyticOrCentral` | `Analytic` → `FiniteDifference(Central)` |
| `AnalyticOrAutomaticOrForward` | `Analytic` → `AutomaticDifferentiation` → `FiniteDifference(Forward)` |

`provider` takes a candidate, returning `Ok(Some(value))` if it can compute the derivative, otherwise `Ok(None)`.
Only `Ok(None)` advances; `Err` returns immediately without changing kind.
If no candidate yields a value, return `InvalidInput` (`UnsupportedConfiguration`, argument `strategy`).
`select` returns the chosen candidate paired with the unchanged value from `provider`.
`select` neither evaluates nor counts functions; `provider` handles accounting.

Difference candidates carry formulas as `FiniteDifference(scheme)`.
`provider` must pass received `scheme` to method `FiniteDifference`'s `with_scheme`, or the policy's formula is ignored.
Policies `Central` and `AnalyticOrCentral` use central differences; other compound policies use forward.
Complex and adaptive differences are not candidates; use `ComplexStep` or `AdaptiveDifference` directly without policies.
`scioxide-differentiate` neither implements automatic differentiation nor depends on `scioxide-ad`.
`provider` supplies values for candidate `AutomaticDifferentiation`; this example uses `scioxide-ad` dual numbers, adding `scioxide-ad` to cell `crates`.

This type is used in solver settings.
scioxide-rootfind `Newton` and `SafeguardedNewton` accept policies through `new(strategy)`; its nonlinear-system settings and scioxide-optimize derivative-based solvers use `with_derivative_strategy`.
scioxide-optimize line-search local methods (`Bfgs`, `Lbfgs`, `GradientDescent`, `NonlinearCg`, `NewtonOptimizer`) default to `AnalyticOrCentral`, falling back centrally; others default to `AnalyticOrForward`.
scioxide-ode implicit solvers also have `with_derivative_strategy`, defaulting to `AnalyticOrAutomaticOrForward` with automatic differentiation between sources.
Their `provider` returns `Ok(None)` when the user-function type does not provide the requested analytic or automatic derivative; difference candidates reuse previously computed $f(x)$ as the base value to save a call.

## Switching by source availability

At $\lambda = 10\,\mathrm{\mu m}$ and $T = 300\,\mathrm{K}$ ($x \approx 4.8$), the next cell toggles analytic and automatic sources and calls `select` for seven policies.
The analytic candidate evaluates textbook $\partial B_\lambda / \partial T = B_\lambda\, x e^{x} / (T (e^{x} - 1))$ with SciOxide `exp`.
Automatic differentiation uses scioxide-ad dual `Dual`.
Dual numbers pair values and derivatives as $a + b\epsilon$ ($\epsilon^2 = 0$), propagating derivatives by chain rule per operation ([Forward mode and dual numbers](../../../scioxide-ad/algorithms/forward-mode/)).
Evaluating the same `radiance` with $T$ set to `Dual::variable(T)` makes the coefficient of $\epsilon$ the temperature derivative.
Difference candidates use received formulas with default `FiniteDifference` steps.
The table shows candidate-query order for `provider`, chosen candidates, relative error against `exp_m1` references, and error kinds.

```rust
//| id: differentiate-planck-strategy
//| ref: differentiate-planck-strategy
//| title: "Switching DerivativeStrategy candidates according to source availability"
//| run: reactive
//| uses: [differentiate-planck-model]
//| crates: [scioxide-ad, scioxide-core, scioxide-differentiate]
//| inputs:
//|   analytic: {"type":"checkbox","label":"Provide analytic derivatives","value":false}
//|   automatic: {"type":"checkbox","label":"Provide automatic derivatives","value":true}
//| cases:
//|   - {"id":"analytic","label":"Analytic available","description":"Every analytic-first policy stops at first candidate Analytic.","inputs":{"analytic":true}}
//|   - {"id":"differences-only","label":"Differences only","description":"Without automatic derivatives, Automatic errors; AnalyticOrAutomaticOrForward reaches its third, forward candidate.","inputs":{"automatic":false}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"selection","path":"/rows/0/2","equals":null}
//|       - {"artifact":"selection","path":"/rows/0/4","equals":"InvalidInput"}
//|       - {"artifact":"selection","path":"/rows/1/2","equals":"AutomaticDifferentiation"}
//|       - {"artifact":"selection","path":"/rows/1/3","range":{"max":1e-14}}
//|       - {"artifact":"selection","path":"/rows/2/3","range":{"min":1.4e-8,"max":2.9e-8}}
//|       - {"artifact":"selection","path":"/rows/3/3","range":{"max":2e-11}}
//|       - {"artifact":"selection","path":"/rows/4/1","equals":"Analytic → FiniteDifference(Forward)"}
//|       - {"artifact":"selection","path":"/rows/4/2","equals":"FiniteDifference(Forward)"}
//|       - {"artifact":"selection","path":"/rows/5/2","equals":"FiniteDifference(Central)"}
//|       - {"artifact":"selection","path":"/rows/6/1","equals":"Analytic → AutomaticDifferentiation"}
//|   - case: analytic
//|     expect:
//|       - {"artifact":"selection","path":"/rows/0/3","range":{"max":1e-14}}
//|       - {"artifact":"selection","path":"/rows/4/1","equals":"Analytic"}
//|       - {"artifact":"selection","path":"/rows/6/2","equals":"Analytic"}
//|       - {"artifact":"selection","path":"/rows/3/2","equals":"FiniteDifference(Central)"}
//|   - case: differences-only
//|     expect:
//|       - {"artifact":"selection","path":"/rows/1/4","equals":"InvalidInput"}
//|       - {"artifact":"selection","path":"/rows/6/1","equals":"Analytic → AutomaticDifferentiation → FiniteDifference(Forward)"}
//|       - {"artifact":"selection","path":"/rows/6/2","equals":"FiniteDifference(Forward)"}
use scioxide_ad::{Dual, Real};
use scioxide_core::RealScalar;
use scioxide_differentiate::{
    DerivativeCandidate, DerivativeStrategy, DifferenceScheme, FiniteDifference,
};

let (lambda_um, temp) = (10.0_f64, 300.0_f64);
let reference = exact_temperature_slope(lambda_um, temp);
let name = |candidate: DerivativeCandidate| match candidate {
    DerivativeCandidate::Analytic => "Analytic",
    DerivativeCandidate::AutomaticDifferentiation => "AutomaticDifferentiation",
    DerivativeCandidate::FiniteDifference(DifferenceScheme::Forward) => {
        "FiniteDifference(Forward)"
    }
    DerivativeCandidate::FiniteDifference(DifferenceScheme::Central) => {
        "FiniteDifference(Central)"
    }
};
let strategies = [
    ("Analytic", DerivativeStrategy::Analytic),
    ("Automatic", DerivativeStrategy::Automatic),
    ("Forward", DerivativeStrategy::Forward),
    ("Central", DerivativeStrategy::Central),
    ("AnalyticOrForward", DerivativeStrategy::AnalyticOrForward),
    ("AnalyticOrCentral", DerivativeStrategy::AnalyticOrCentral),
    (
        "AnalyticOrAutomaticOrForward",
        DerivativeStrategy::AnalyticOrAutomaticOrForward,
    ),
];
let mut rows = Vec::new();
for (label, strategy) in strategies {
    let mut asked = Vec::new();
    let selected = strategy.select(|candidate| {
        asked.push(name(candidate));
        match candidate {
            DerivativeCandidate::Analytic if analytic => {
                // Analytic: ∂B/∂T = B x e^x / (T (e^x − 1)).
                let x = photon_ratio(lambda_um, temp);
                let growth = RealScalar::exp(x);
                let slope = radiance(lambda_um, temp) * x * growth / (temp * (growth - 1.0));
                Ok(Some(slope))
            }
            DerivativeCandidate::AutomaticDifferentiation if automatic => {
                // Make only temperature dual with tangent 1 and evaluate the same model.
                let value = radiance(Dual::constant(lambda_um), Dual::variable(temp));
                Ok(Some(value.derivative()))
            }
            DerivativeCandidate::FiniteDifference(scheme) => {
                let method = FiniteDifference::default().with_scheme(scheme);
                let result = method.derivative(|t: f64| Ok(radiance(lambda_um, t)), temp)?;
                Ok(result.values().map(|values| values[0]))
            }
            _ => Ok(None),
        }
    });
    let (chosen, error, kind) = match selected {
        Ok((candidate, slope)) => (
            Some(name(candidate)),
            Some(((slope - reference) / reference).abs()),
            None,
        ),
        Err(e) => (None, None, Some(format!("{:?}", e.kind()))),
    };
    rows.push((label, asked.join(" → "), chosen, error, kind));
}
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let columns = serde_json::json!([
    { "key": "0", "label": "Policy" },
    { "key": "1", "label": "Queried candidates" },
    { "key": "2", "label": "Chosen candidate", "nullText": "None" },
    { "key": "3", "label": "Relative reference error [-]", "type": "number", "format": sci3, "nullText": "—" },
    { "key": "4", "label": "Error kind", "nullText": "None" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "selection" })
);
```

Defaults provide automatic but no analytic derivatives.
`AnalyticOrAutomaticOrForward` queries `Analytic`, receives `Ok(None)`, then obtains a value from `AutomaticDifferentiation`.
Dual derivatives agree with references within rounding.
`AnalyticOrForward` omits automatic candidates and advances forward, giving relative error $2.5 \times 10^{-8}$.
This combines leading-truncation $h B''/(2B')$ value $2.1 \times 10^{-8}$ with rounding.
Policies `Central` and `AnalyticOrCentral` reduce relative errors to $1.5 \times 10^{-13}$.
Leading truncation is $5.5 \times 10^{-12}$; smaller relative errors result from accidental cancellation with rounding.
Default central errors are typically of order $\varepsilon^{2/3} \approx 3.7 \times 10^{-11}$.
Policy `Analytic` has its sole candidate return `Ok(None)`, exhausting candidates and returning `InvalidInput`.

Enabling analytic derivatives makes all four analytic-first policies stop at first `Analytic`, with rounding-scale errors.
Policies `Forward` and `Central` use differences regardless of analytic availability.
Disabling automatic derivatives makes `Automatic` error; `AnalyticOrAutomaticOrForward` queries all three and selects forward differences.
Default `AnalyticOrForward` never queries automatic derivatives, retaining forward error $10^{-8}$ even for dual-capable functions.

## Relative difference errors versus wavelength

The next cell sweeps wavelength $\lambda$ from 0.3 to 300 μm at 10 points per decade and computes the relative errors of forward-difference, central-difference, and dual-number temperature derivatives against reference values.
Difference errors should grow at short wavelengths where the temperature derivative of $\ln B_\lambda$ is large.

For $x \gg 1$, set $a = hc/(\lambda k_B)$ to write $B_\lambda \approx (2hc^2/\lambda^5)\, g(T)$ and $g(T) = e^{-a/T}$.
Differentiating $g$ through $x = a/T$ gives $g''/g' = (x - 2)/T$ and $g'''/g' = (x^2 - 6x + 6)/T^2$.
Defaults use $h = \eta T$ with $\eta$ equal to $\varepsilon^{1/2} \approx 1.5 \times 10^{-8}$ forward or $\varepsilon^{1/3} \approx 6.1 \times 10^{-6}$ central ([Taylor expansion and step-size selection](oxref:differentiate-default-steps)).
Leading truncations $h g''/(2g')$ and $h^2 g'''/(6g')$ give relative errors $\eta (x - 2)/2$ forward and $\eta^2 (x^2 - 6x + 6)/6$ central, both increasing with $x$.

The chart plots three relative errors logarithmically; vertical dashes mark selected-temperature Wien maximum $\lambda_{\max}$.
Exclude exactly zero errors from logarithmic axes and show their count last.
The table shows one value per decade.

```rust
//| id: differentiate-planck-wien
//| ref: differentiate-planck-wien
//| title: "Forward, central, and automatic relative errors versus wavelength"
//| run: reactive
//| uses: [differentiate-planck-model]
//| crates: [scioxide-ad, scioxide-core, scioxide-differentiate]
//| inputs:
//|   temp: {"type":"select","label":"Temperature T [K]","options":["300","1000","5800"],"value":"300"}
//| cases:
//|   - {"id":"sun","label":"T = 5800 K","description":"At equal wavelengths x falls, reducing short-wave difference errors and increasing long-wave cancellation errors.","inputs":{"temp":"5800"}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"samples","path":"/rows/0/1","approx":{"value":159.86,"atol":0.01}}
//|       - {"artifact":"samples","path":"/rows/0/2","approx":{"value":1.17618e-6,"rtol":1e-2}}
//|       - {"artifact":"samples","path":"/rows/0/3","approx":{"value":1.50361e-7,"rtol":1e-3}}
//|       - {"artifact":"samples","path":"/rows/2/3","range":{"max":1e-10}}
//|       - {"artifact":"samples","path":"/rows/0/4","range":{"max":1e-14}}
//|       - {"artifact":"samples","path":"/rows/1/4","range":{"max":1e-14}}
//|       - {"artifact":"samples","path":"/rows/2/4","range":{"max":1e-14}}

//|     expect:
//|       - {"artifact":"samples","path":"/rows/0/1","approx":{"value":8.2685,"atol":1e-3}}
//|       - {"artifact":"samples","path":"/rows/0/2","range":{"max":1e-7}}
//|       - {"artifact":"samples","path":"/rows/3/4","range":{"max":1e-13}}

use scioxide_differentiate::{DifferenceScheme, FiniteDifference};

let temp: f64 = temp.parse().map_err(|_| "Cannot read temperature")?;
let schemes = [DifferenceScheme::Forward, DifferenceScheme::Central];

let mut rows = Vec::new();

    // λ from 0.3 to 300 μm, 10 points per decade.
    let lambda_um = 0.3 * 10.0_f64.powf(f64::from(k) / 10.0);
    let reference = exact_temperature_slope(lambda_um, temp);
    let mut errors = [0.0; 3];
    for (error, scheme) in errors.iter_mut().zip(schemes) {
        let result = FiniteDifference::default()
            .with_scheme(scheme)
            .derivative(|t: f64| Ok(radiance(lambda_um, t)), temp)
            .map_err(|e| e.to_string())?;
        let slope = result.values().ok_or("Derivative not published")?[0];
        *error = ((slope - reference) / reference).abs();
    }
    let value = radiance(Dual::constant(lambda_um), Dual::variable(temp));
    errors[2] = ((value.derivative() - reference) / reference).abs();
    for (series, &error) in points.iter_mut().zip(&errors) {
        // Count and exclude zero errors from logarithmic axes.
        if error > 0.0 {
            series.push([lambda_um, error]);
        } else {
            dropped += 1;
        }
    }
    if k % 10 == 0 {
        rows.push((
            lambda_um,
            photon_ratio(lambda_um, temp),
            errors[0],
            errors[1],
            errors[2],
        ));
    }
}
// Wien displacement λ_max T = hc/(k_B x_W) [μm].
let peak_um = HC_OVER_K / (WIEN_X * temp) * 1e6;
let names = ["Forward difference", "Central difference", "Automatic differentiation, Dual"];
let series: Vec<_> = names
    .iter()
    .zip(&points)
    .map(|(name, p)| {
        serde_json::json!({
            "name": name,
            "points": p,
            "style": { "showSymbol": true }
        })
    })
    .collect();
emit_chart!(
    serde_json::json!({
        "kind": "line",
        "dataZoom": true,
        "tooltip": true,
        "series": series,
        "xLabel": "Wavelength λ [μm]",
        "yLabel": "∂B/∂T relative error [-]",
        "xType": "log",
        "yType": "log",
        "xMin": 0.3,
        "xMax": 300.0,
        "yMin": 1e-17,
        "yMax": 1e-5,
        "annotations": [{
            "kind": "line",
            "axis": "x",
            "value": peak_um,
            "label": "λ_max（Wien）",
            "style": { "lineType": "dashed" }
        }]
    }),
    metadata = serde_json::json!({ "id": "errors" })
);
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let digits3 = serde_json::json!({ "significantDigits": 3 });
let columns = serde_json::json!([
    { "key": "0", "label": "Wavelength λ [μm]", "type": "number", "format": digits3 },
    { "key": "1", "label": "x = hc/(λk_BT) [-]", "type": "number", "format": digits3 },
    { "key": "2", "label": "Forward relative error [-]", "type": "number", "format": sci3 },
    { "key": "3", "label": "Central relative error [-]", "type": "number", "format": sci3 },
    { "key": "4", "label": "Automatic relative error [-]", "type": "number", "format": sci3 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "samples" })
);
```

At default $T = 300\,\mathrm{K}$, 0.3 μm ($x \approx 160$) gives forward error $1.18 \times 10^{-6}$ and central $1.50 \times 10^{-7}$.
Estimates $\eta(x - 2)/2 = 1.176 \times 10^{-6}$ and $\eta^2(x^2 - 6x + 6)/6 = 1.504 \times 10^{-7}$ agree within 0.3% forward and 0.01% central.
The remaining forward 0.3% difference is rounding.
Longer wavelengths lower $x$ and errors; central error minimizes at $2.5 \times 10^{-12}$ at 38 μm with $x \approx 1.3$.
Beyond 10 μm, rounding error in forward differences becomes comparable to truncation error, and the total error fluctuates between $10^{-10}$ and $10^{-7}$.
At still longer waves with $x \ll 1$, model subtraction $e^x - 1$ causes cancellation, raising relative function errors to about $\varepsilon / x$.
Thus at 300 μm ($x \approx 0.16$), central error returns to $4 \times 10^{-11}$.
Dual-number relative errors are at most $10^{-15}$ at all wavelengths, matching the reference values at 7 points.
At 5800 K, equal-wavelength $x$ falls by about 1/19; 0.3 μm ($x \approx 8.3$) errors fall to $4.1 \times 10^{-8}$ forward and $1.6 \times 10^{-10}$ central.
Conversely, 300 μm ($x \approx 0.0083$) cancellation raises errors to $9.8 \times 10^{-7}$ forward, $7.7 \times 10^{-10}$ central, and even dual $2.1 \times 10^{-14}$ near $\varepsilon/x$.
Computing model $e^x - 1$ through `exp_m1` avoids cancellation.

## Wavelength derivatives at Wien's maximum

At the maximum of $B_\lambda$, $\partial B_\lambda / \partial \lambda = 0$, making relative derivative errors undefined.
Compare dimensionless logarithmic derivative $\lambda \, \partial B_\lambda / \partial \lambda \,/\, B_\lambda = -5 + x/(1 - e^{-x})$ instead.
At $T = 300\,\mathrm{K}$, the next cell selects $\lambda = r \lambda_{\max}$ and differentiates the same `radiance` in wavelength with forward, central, and dual methods.
If $x_W$ is a root of $x = 5(1 - e^{-x})$, the exact expression evaluated at $r = 1$ is zero within rounding error, independently checking the value of $x_W$ obtained with Lambert W.

```rust

//| ref: differentiate-planck-peak
//| title: "Wavelength logarithmic derivatives around Wien's maximum"
//| run: reactive
//| uses: [differentiate-planck-model]

//| inputs:
//|   ratio: {"type":"range","label":"Wavelength ratio r = λ/λ_max [-]","min":0.9,"max":1.1,"step":0.01,"value":1.0}
//| cases:
//|   - {"id":"short-side","label":"r = 0.95","description":"Below peak wavelength, logarithmic derivatives are positive and B_λ increases with wavelength.","inputs":{"ratio":0.95}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"peak","path":"/rows/3/1","range":{"min":-1e-14,"max":1e-14}}
//|       - {"artifact":"peak","path":"/rows/0/2","range":{"max":1e-7}}
//|       - {"artifact":"peak","path":"/rows/1/2","range":{"max":1e-9}}
//|       - {"artifact":"peak","path":"/rows/2/2","range":{"max":1e-14}}
//|   - case: short-side
//|     expect:
//|       - {"artifact":"peak","path":"/rows/3/1","approx":{"value":0.2546674654457526,"rtol":1e-12}}
//|       - {"artifact":"peak","path":"/rows/1/1","approx":{"value":0.2546674654457526,"rtol":1e-8}}
//|       - {"artifact":"peak","path":"/rows/2/1","approx":{"value":0.2546674654457526,"rtol":1e-13}}
use scioxide_ad::{Dual, Real};
use scioxide_differentiate::{DifferenceScheme, FiniteDifference};

let temp = 300.0_f64;
// Wien displacement λ_max T = hc/(k_B x_W) [μm].
let peak_um = HC_OVER_K / (WIEN_X * temp) * 1e6;
let lambda_um = ratio * peak_um;
let value = radiance(lambda_um, temp);
// Reference: λ ∂B/∂λ / B = −5 + x/(1 − e^{−x}), using f64 inherent methods.
let x = photon_ratio(lambda_um, temp);
let exact = -5.0 + x / -(-x).exp_m1();
let mut rows = Vec::new();
for (name, scheme) in [
    ("Forward difference", DifferenceScheme::Forward),
    ("Central difference", DifferenceScheme::Central),
] {
    let result = FiniteDifference::default()
        .with_scheme(scheme)
        .derivative(|l: f64| Ok(radiance(l, temp)), lambda_um)
        .map_err(|e| e.to_string())?;
    let slope = result.values().ok_or("Derivative not published")?[0];
    let logarithmic = lambda_um * slope / value;
    rows.push((name, logarithmic, Some((logarithmic - exact).abs())));
}
// Make only wavelength dual with tangent 1.
let dual = radiance(Dual::variable(lambda_um), Dual::constant(temp));
let logarithmic = lambda_um * dual.derivative() / value;
rows.push((
    "Automatic differentiation, Dual",
    logarithmic,
    Some((logarithmic - exact).abs()),
));
rows.push(("Exact expression −5 + x/(1 − e^{−x})", exact, None));
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let columns = serde_json::json!([
    { "key": "0", "label": "Method" },
    { "key": "1", "label": "λ∂B/∂λ / B [-]", "type": "number", "format": sci3 },
    { "key": "2", "label": "Difference from exact expression [-]", "type": "number", "format": sci3, "nullText": "—" }
]);
let caption = format!("λ = {lambda_um:.4} μm, x = {x:.6}, T = 300 K");
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "peak", "caption": caption })
);
```

At $r = 1$, $\lambda = 9.659\,\mathrm{\mu m}$ and the exact expression gives $8.9 \times 10^{-16}$, which is zero within rounding error, confirming that $x_W = 4.965114231744276$ gives the maximum.
Differences return truncation-sized values instead of zero, differing from the exact expression by $1.3 \times 10^{-8}$ forward and $1.7 \times 10^{-10}$ central.
Dual value $9.0 \times 10^{-16}$ matches the exact expression within rounding.
Ratios $r$ below 1 give positive and above 1 negative logarithmic derivatives, reversing $B_\lambda$ variation around the maximum.
At $r = 0.95$, exact value is 0.25467; errors $7.3 \times 10^{-8}$ forward and $9.0 \times 10^{-11}$ central remain truncation-sized as at $r = 1$.
As a function of $x$, this logarithmic derivative has slope $(1 - e^{-x} - x e^{-x})/(1 - e^{-x})^2 = 0.972$ at $x_W$.
Difference-derived zeros therefore shift $x$ by error divided by 0.972, about $1.7 \times 10^{-10}$ centrally.

## Summary

`DerivativeStrategy::select` queries in policy order, advances only on `Ok(None)`, and returns `InvalidInput` when exhausted.
Difference candidates carry formula `scheme`; `provider` must configure it on `FiniteDifference`.
Default `AnalyticOrForward` omits automatic derivatives; dual-capable solvers choosing `AnalyticOrAutomaticOrForward` avoid forward error $10^{-8}$.
For the temperature derivative of Planck's law, difference relative errors grow at short wavelengths where the slope $x/T$ of $\ln B_\lambda$ is large, then grow again at long wavelengths with $x \ll 1$ because of cancellation in the model's $e^x - 1$.
At 300 K dual errors stay at or below $10^{-15}$ throughout, but neither automatic nor difference methods remove cancellation in model $e^x - 1$ itself; reformulate with `exp_m1` or similar.
Near extrema, relative derivative error is meaningless; compare dimensionless quantities such as logarithmic derivatives.
