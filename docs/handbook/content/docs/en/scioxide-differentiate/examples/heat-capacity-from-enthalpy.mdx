Thermodynamic properties are often supplied as tables at irregular temperatures.
The first temperature derivative of enthalpy $H(T)$ at constant pressure is the constant-pressure heat capacity $C_p = (\partial H / \partial T)_p$; the second temperature derivative of enthalpy is $\mathrm{d}C_p / \mathrm{d}T$.
Assuming only table values and no callable function, this example passes nodes to `FiniteDifferenceStencil` to compute both derivatives.
Analytic derivatives of the table-generating formula independently check effects of node count and rounding width.

## Nitrogen Shomate equation and enthalpy table

NIST Chemistry WebBook gives ideal-gas nitrogen $\mathrm{N_2}$ thermodynamics over 100–500 K through Shomate equations (coefficients from NIST-JANAF tables, Chase 1998).
With $t = T / 1000$ ($T$ in K), heat capacity and enthalpy follow.

$$
C_p = A + B t + C t^2 + D t^3 + \frac{E}{t^2} \quad [\mathrm{J/(mol \cdot K)}],
$$

$$
H - H_{298.15} = A t + \frac{B}{2} t^2 + \frac{C}{3} t^3 + \frac{D}{4} t^4 - \frac{E}{t} + F - H_0 \quad [\mathrm{kJ/mol}].
$$

$H_{298.15}$ is enthalpy at 298.15 K; $H_0$ is the constant labeled $H$ in NIST's table.
Coefficients are $A = 28.98641$, $B = 1.853978$, $C = -9.647459$, $D = 16.63537$, $E = 0.000117$, $F = -8.671914$, and $H_0 = 0$.
They give $C_p(298.15\,\mathrm{K}) = 29.124\,\mathrm{J/(mol \cdot K)}$ and $H(500\,\mathrm{K}) - H_{298.15} = 5.911\,\mathrm{kJ/mol}$.
Differentiating $C_p$ with respect to $T$ gives the following through $\mathrm{d}t/\mathrm{d}T = 1/1000$.

$$
\frac{\mathrm{d}C_p}{\mathrm{d}T} = \frac{1}{1000} \left( B + 2 C t + 3 D t^2 - \frac{2E}{t^3} \right) \quad [\mathrm{J/(mol \cdot K^2)}].
$$

These $C_p$ and $\mathrm{d}C_p/\mathrm{d}T$ are independent checks derived without differences.

The table uses these nine irregular temperatures including standard 298.15 K.

$$
T = 200,\ 250,\ 280,\ 298.15,\ 300,\ 350,\ 400,\ 450,\ 500 \ \mathrm{K}.
$$

298.15 K and 300 K are only 1.85 K apart; other gaps range from 18.15 to 50 K.
Table values round Shomate enthalpy to grid width $\delta$, selecting $\delta$ from 0 (unrounded), 0.001 kJ/mol, or 0.01 kJ/mol.
$\delta = 0.001\,\mathrm{kJ/mol}$ corresponds to three-decimal-place kJ/mol tables.
$H$ has units kJ/mol and $C_p$ J/(mol·K); multiply derivative results by 1000 to match units.

The following block defines shared code for the two cells.
`enthalpy` represents table-generating $H - H_{298.15}$; `heat_capacity` and `heat_capacity_slope` give check values $C_p$ and $\mathrm{d}C_p/\mathrm{d}T$; `tabulated_enthalpy` rounds table values at width $\delta$.
`nearest_nodes` selects $k$ points nearest temperature $T_0$ and returns their table indices sorted by temperature.
All use only f64 arithmetic and inherent methods to generate table and reference values.

```rust
//| id: differentiate-heat-capacity-model
//| kind: definitions
//| title: "Nitrogen Shomate equation and irregular enthalpy table"
/// NIST Chemistry WebBook N₂ gas Shomate coefficients A, B, C, D, E, F for 100–500 K; H₀ = 0.
const SHOMATE: [f64; 6] = [28.98641, 1.853978, -9.647459, 16.63537, 0.000117, -8.671914];

/// Table temperatures [K]; only the 298.15–300 K gap is as narrow as 1.85 K.
pub(crate) const TABLE_TEMPERATURES: [f64; 9] = [
    200.0, 250.0, 280.0, 298.15, 300.0, 350.0, 400.0, 450.0, 500.0,
];

/// H(T) − H(298.15 K) [kJ/mol], generating table values.
pub(crate) fn enthalpy(temperature: f64) -> f64 {
    let [a, b, c, d, e, f] = SHOMATE;
    let t = temperature / 1000.0;
    a * t + b / 2.0 * t * t + c / 3.0 * t.powi(3) + d / 4.0 * t.powi(4) - e / t + f
}

/// Check Cp(T) [J/(mol·K)].
pub(crate) fn heat_capacity(temperature: f64) -> f64 {
    let [a, b, c, d, e, _] = SHOMATE;
    let t = temperature / 1000.0;
    a + b * t + c * t * t + d * t.powi(3) + e / (t * t)
}

/// Check dCp/dT [J/(mol·K²)].
pub(crate) fn heat_capacity_slope(temperature: f64) -> f64 {
    let [_, b, c, d, e, _] = SHOMATE;
    let t = temperature / 1000.0;
    (b + 2.0 * c * t + 3.0 * d * t * t - 2.0 * e / t.powi(3)) / 1000.0
}

/// Round table values to grid width δ [kJ/mol]; δ = 0 leaves them unrounded.
pub(crate) fn tabulated_enthalpy(rounding: f64) -> Vec<f64> {
    TABLE_TEMPERATURES
        .iter()
        .map(|&temperature| {
            let value = enthalpy(temperature);
            if rounding > 0.0 {
                (value / rounding).round() * rounding
            } else {
                value
            }
        })
        .collect()
}

/// Select k points nearest T0 and return temperature-sorted indices; ties favor lower temperatures.
pub(crate) fn nearest_nodes(t0: f64, count: usize) -> Vec<usize> {
    let mut order: Vec<usize> = (0..TABLE_TEMPERATURES.len()).collect();
    order.sort_by(|&i, &j| {
        let (left, right) = (TABLE_TEMPERATURES[i] - t0, TABLE_TEMPERATURES[j] - t0);
        left.abs().total_cmp(&right.abs())
    });
    let mut chosen = order[..count.min(order.len())].to_vec();
    chosen.sort_unstable();
    chosen
}
```

## Node selection and error bounds

[`FiniteDifferenceStencil`](https://docs.rs/scioxide-differentiate/0.1.0/scioxide_differentiate/struct.FiniteDifferenceStencil.html)`::new(T0, nodes, m)` uses Fornberg recurrence to form order-$m$ derivative weights at $T_0$ from values at nodes $T_j$.
The approximation is this weighted sum.

$$
H^{(m)}(T_0) \approx \sum_j w_j H(T_j), \qquad w_j = \frac{\hat w_j}{s^m}, \qquad s = \max_j \lvert T_j - T_0 \rvert .
$$

$\hat w_j$ are weights for normalized displacements $(T_j - T_0)/s$; $w_j$ are physical weights in K⁻ᵐ.
A $k$-node formula is exact through polynomial degree $k - 1$ and has truncation $O(\Delta^{k - m})$ for node spread $\Delta$.
Weight computation takes $O(k^2(m + 1))$ operations; `apply` summation takes $O(k)$.
Derivative order $m$ at least node count $k$ gives `InvalidInput` (`OutOfRange`); duplicated nodes give `InvalidInput` (`Inconsistent`).

`FiniteDifferenceStencil` uses supplied nodes unchanged, without reselection.
Here callers select $k$ points nearest temperature $T_0$.
At endpoints such as $T_0 = 500\,\mathrm{K}$, all selected nodes are at most $T_0$, making a one-sided formula.

Each table-value rounding error is at most $\delta/2$, so the rounding contribution to derivative error is bounded as follows ([Absolute-weight sums and noise amplification](oxref:differentiate-noise-amplification)).

$$
\Bigl\lvert \sum_j w_j e_j \Bigr\rvert \le \frac{\delta}{2} \sum_j \lvert w_j \rvert = \frac{\delta}{2} \cdot \frac{A_w}{s^m}, \qquad \lvert e_j \rvert \le \frac{\delta}{2} .
$$

$A_w = \sum_j \lvert \hat w_j \rvert$ comes from `weight_amplification()`; $s$ from `scale()`.
Total error cannot exceed truncation plus this rounding bound.
Including both 298.15 K and 300 K introduces large weights effectively dividing their difference by 1.85 K, amplifying rounding.

## Heat capacity and its derivative at a selected temperature

The next cell selects temperature $T_0$, node count $k$, and rounding width $\delta$, building first- and second-derivative stencils at the same nodes to obtain $C_p$ and $\mathrm{d}C_p/\mathrm{d}T$.
The first table shows selected nodes, values, and physical weights $w_j$.
Weights apply to $\mathrm{d}H/\mathrm{d}T$ and $\mathrm{d}^2H/\mathrm{d}T^2$, excluding the factor 1000 converting to J/(mol·K).
The second compares both stencil results with analytic Shomate values, showing rounding bound $1000 \cdot (\delta/2) \sum_j \lvert w_j \rvert$ and error-to-bound ratios.
Unrounded tables have zero bounds, so ratios are omitted.

```rust
//| id: differentiate-heat-capacity-stencil
//| ref: differentiate-heat-capacity-stencil
//| title: "Heat capacity and its temperature derivative from irregularly spaced enthalpy tables"
//| run: reactive
//| uses: [differentiate-heat-capacity-model]
//| crates: [scioxide-core, scioxide-differentiate]
//| inputs:
//|   t0: {"type":"range","label":"Evaluation temperature T0 [K]","description":"Derivative temperature; endpoint 500 K uses one-sided formulas.","min":220,"max":500,"step":20,"value":300}
//|   node_count: {"type":"range","label":"Node count k","description":"Number of table points selected nearest T0.","min":3,"max":7,"step":1,"value":5}
//|   rounding: {"type":"select","label":"Table rounding width δ [kJ/mol]","options":["None","0.001","0.01"],"value":"None"}
//| cases:
//|   - {"id":"table-end","label":"T0 = 500 K","description":"All nodes lie at lower temperatures, making a one-sided formula with larger errors even without rounding.","inputs":{"t0":500}}
//|   - {"id":"coarse-rounding","label":"δ = 0.01 kJ/mol","description":"Rounding exceeds truncation and even reverses dCp/dT's sign; errors remain inside rounding bounds.","inputs":{"rounding":"0.01"}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"nodes","path":"/rows/2/0","approx":{"value":298.15,"atol":1e-9}}
//|       - {"artifact":"summary","path":"/rows/0/1","approx":{"value":29.12478708,"atol":1e-6}}
//|       - {"artifact":"summary","path":"/rows/0/3","range":{"max":1e-7}}
//|       - {"artifact":"summary","path":"/rows/1/1","approx":{"value":5.48386e-4,"rtol":1e-4}}
//|       - {"artifact":"summary","path":"/rows/0/5","equals":null}
//|   - case: table-end
//|     expect:
//|       - {"artifact":"summary","path":"/rows/0/1","approx":{"value":29.5814235,"atol":1e-4}}
//|       - {"artifact":"summary","path":"/rows/0/3","range":{"min":1e-7,"max":1e-4}}
//|   - case: coarse-rounding
//|     expect:
//|       - {"artifact":"summary","path":"/rows/0/3","range":{"min":0.5}}
//|       - {"artifact":"summary","path":"/rows/0/5","range":{"max":1}}
//|       - {"artifact":"summary","path":"/rows/1/1","range":{"max":0}}
//|       - {"artifact":"summary","path":"/rows/1/5","range":{"max":1}}
use scioxide_differentiate::FiniteDifferenceStencil;

let delta: f64 = if rounding == "None" {
    0.0
} else {
    rounding.parse().map_err(|_| "Cannot read rounding width")?
};
let chosen = nearest_nodes(t0, node_count as usize);
let table = tabulated_enthalpy(delta);
let nodes: Vec<f64> = chosen.iter().map(|&i| TABLE_TEMPERATURES[i]).collect();
let values: Vec<f64> = chosen.iter().map(|&i| table[i]).collect();
// Construct first (dH/dT) and second (d²H/dT²) weights on the same nodes.
let first = FiniteDifferenceStencil::new(t0, &nodes, 1).map_err(|e| e.to_string())?;
let second = FiniteDifferenceStencil::new(t0, &nodes, 2).map_err(|e| e.to_string())?;
let first_weights = first.weights().map_err(|e| e.to_string())?;
let second_weights = second.weights().map_err(|e| e.to_string())?;
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let sci7 = serde_json::json!({ "notation": "scientific", "significantDigits": 7 });
let fixed2 = serde_json::json!({ "fractionDigits": 2 });
let fixed6 = serde_json::json!({ "fractionDigits": 6 });
let node_columns = serde_json::json!([
    { "key": "0", "label": "Node T_j [K]", "type": "number", "format": fixed2 },
    { "key": "1", "label": "Table H_j [kJ/mol]", "type": "number", "format": fixed6 },
    { "key": "2", "label": "dH/dT weight w_j [K⁻¹]", "type": "number", "format": sci3 },
    { "key": "3", "label": "d²H/dT² weight w_j [K⁻²]", "type": "number", "format": sci3 }
]);
let node_rows: Vec<(f64, f64, f64, f64)> = (0..nodes.len())
    .map(|j| (nodes[j], values[j], first_weights[j], second_weights[j]))
    .collect();
emit_table_with_columns!(
    node_columns,
    node_rows,
    metadata = serde_json::json!({ "id": "nodes" })
);

let mut rows: Vec<(&str, f64, f64, f64, f64, Option<f64>)> = Vec::new();
for (name, stencil, exact) in [
    ("Cp [J/(mol·K)]", &first, heat_capacity(t0)),
    ("dCp/dT [J/(mol·K²)]", &second, heat_capacity_slope(t0)),
] {
    // Convert derivatives from kJ/mol table units to J/mol units.
    let value = 1000.0 * stencil.apply(&values).map_err(|e| e.to_string())?;
    let order = stencil.derivative_order() as i32;
    // Rounding bound 1000 (δ/2) Σ|w_j|, with Σ|w_j| = A_w / s^m.
    let bound =
        1000.0 * delta / 2.0 * stencil.weight_amplification() / stencil.scale().powi(order);
    let error = (value - exact).abs();
    rows.push((
        name,
        value,
        exact,
        error,
        bound,
        (bound > 0.0).then(|| error / bound),
    ));
}
let columns = serde_json::json!([
    { "key": "0", "label": "Quantity [units]" },
    { "key": "1", "label": "Stencil value", "type": "number", "format": sci7 },
    { "key": "2", "label": "Shomate value", "type": "number", "format": sci7 },
    { "key": "3", "label": "Error", "type": "number", "format": sci3 },
    { "key": "4", "label": "Rounding-error bound", "type": "number", "format": sci3 },
    { "key": "5", "label": "Error / bound [-]", "type": "number", "format": sci3, "nullText": "Zero bound" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "summary" })
);
```

At defaults $T_0 = 300\,\mathrm{K}$ and $k = 5$ without rounding, nodes are 250, 280, 298.15, 300, and 350 K.
$C_p$ error is $1.6 \times 10^{-8}\,\mathrm{J/(mol \cdot K)}$; $\mathrm{d}C_p/\mathrm{d}T$ error is $1.9 \times 10^{-8}\,\mathrm{J/(mol \cdot K^2)}$.
Absolute errors are comparable, but small $\mathrm{d}C_p/\mathrm{d}T = 5.48 \times 10^{-4}$ gives larger relative $3.5 \times 10^{-5}$ versus $5.7 \times 10^{-10}$ for $C_p$.
For $\mathrm{d}H/\mathrm{d}T$, weights at 298.15 K and 300 K are $-0.596$ and $0.591\,\mathrm{K^{-1}}$, two orders above other nodes' magnitudes, at most $0.007\,\mathrm{K^{-1}}$.

Rounding to $\delta = 0.01\,\mathrm{kJ/mol}$ shifts $C_p$ by 2.30 J/(mol·K), while $\mathrm{d}C_p/\mathrm{d}T$ becomes $-0.216\,\mathrm{J/(mol \cdot K^2)}$ with reversed sign.
Both errors stay below rounding bounds, with ratios 0.39 and 0.36.
At $T_0 = 500\,\mathrm{K}$, all nodes are lower-temperature one-sided; even unrounded $C_p$ errors grow to order $10^{-6}$.

## Errors versus evaluation temperature

The next cell sweeps $T_0$ from 210 K through 490 K in 10 K increments, plotting $C_p$ errors for stencils with $k = 3, 5, 7$ nodes.
Nearest-node sets switch with $T_0$, so errors vary nonsmoothly with $T_0$.
Vertical dotted lines mark table temperatures.
Nearest $k$-point sets change when $T_0$ crosses midpoints of two table temperatures.
For each $k$, the table shows maximum error and its temperature, and maximum error-to-bound ratio.
Here bounds add unrounded-table errors (truncation) and rounding bound $1000 \cdot (\delta/2) \sum_j \lvert w_j \rvert$, so ratios should not exceed 1.
Count and exclude exactly zero errors from logarithmic axes, and show their count in the table.

```rust
//| id: differentiate-heat-capacity-sweep
//| ref: differentiate-heat-capacity-sweep
//| title: "Heat-capacity errors versus temperature and node count"
//| run: reactive
//| uses: [differentiate-heat-capacity-model]
//| crates: [scioxide-core, scioxide-differentiate]
//| inputs:
//|   rounding: {"type":"select","label":"Table rounding width δ [kJ/mol]","options":["None","0.001","0.01"],"value":"0.001"}
//| cases:
//|   - {"id":"exact-table","label":"Unrounded","description":"Only truncation remains, decreasing as nodes increase.","inputs":{"rounding":"None"}}
//|   - {"id":"coarse-rounding","label":"δ = 0.01 kJ/mol","description":"Rounding dominates; every k gives errors exceeding 10% of heat capacity.","inputs":{"rounding":"0.01"}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"worst","path":"/rows/2/1","range":{"min":0.3,"max":1}}
//|       - {"artifact":"worst","path":"/rows/2/2","approx":{"value":230,"atol":1e-9}}
//|       - {"artifact":"worst","path":"/rows/0/3","range":{"max":1}}
//|       - {"artifact":"worst","path":"/rows/2/3","range":{"max":1}}
//|   - case: exact-table
//|     expect:
//|       - {"artifact":"worst","path":"/rows/2/1","range":{"max":1e-5}}
//|       - {"artifact":"worst","path":"/rows/0/3","equals":null}
//|   - case: coarse-rounding
//|     expect:
//|       - {"artifact":"worst","path":"/rows/0/1","range":{"min":2.9}}
//|       - {"artifact":"worst","path":"/rows/2/3","range":{"max":1}}
use scioxide_differentiate::FiniteDifferenceStencil;

let delta: f64 = if rounding == "None" {
    0.0
} else {
    rounding.parse().map_err(|_| "Cannot read rounding width")?
};
let table = tabulated_enthalpy(delta);
let exact_table = tabulated_enthalpy(0.0);
let mut series = Vec::new();
let mut rows: Vec<(String, f64, f64, Option<f64>, usize)> = Vec::new();
for k in [3_usize, 5, 7] {
    let mut points = Vec::new();
    let (mut worst, mut worst_t0, mut ratio, mut skipped) = (0.0_f64, 0.0, 0.0_f64, 0);
    for step in 0..=28 {
        let t0 = 210.0 + 10.0 * f64::from(step);
        let chosen = nearest_nodes(t0, k);
        let nodes: Vec<f64> = chosen.iter().map(|&i| TABLE_TEMPERATURES[i]).collect();
        let stencil = FiniteDifferenceStencil::new(t0, &nodes, 1).map_err(|e| e.to_string())?;
        let derivative = |source: &[f64]| {
            let values: Vec<f64> = chosen.iter().map(|&i| source[i]).collect();
            stencil.apply(&values).map(|v| 1000.0 * v)
        };
        let error = (derivative(&table).map_err(|e| e.to_string())? - heat_capacity(t0)).abs();
        // Unrounded-table errors are truncation; total errors cannot exceed truncation plus rounding bounds.
        let truncation =
            (derivative(&exact_table).map_err(|e| e.to_string())? - heat_capacity(t0)).abs();
        let bound = 1000.0 * delta / 2.0 * stencil.weight_amplification() / stencil.scale();
        if bound > 0.0 {
            ratio = ratio.max(error / (truncation + bound));
        }
        if error > worst {
            (worst, worst_t0) = (error, t0);
        }
        if error > 0.0 {
            points.push([t0, error]);
        } else {
            skipped += 1;
        }
    }
    let ratio = (delta > 0.0).then_some(ratio);
    rows.push((format!("k = {k}"), worst, worst_t0, ratio, skipped));
    series.push(serde_json::json!({
        "name": format!("k = {k}"),
        "points": points,
        "style": { "showSymbol": true }
    }));
}
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let fixed3 = serde_json::json!({ "fractionDigits": 3 });
let columns = serde_json::json!([
    { "key": "0", "label": "Node count" },
    { "key": "1", "label": "Maximum error [J/(mol·K)]", "type": "number", "format": sci3 },
    { "key": "2", "label": "Temperature of maximum error T0 [K]", "type": "number", "format": { "fractionDigits": 0 } },
    { "key": "3", "label": "Maximum error / bound [-]", "type": "number", "format": fixed3, "nullText": "Unrounded" },
    { "key": "4", "label": "Excluded zero-error points [count]", "type": "integer" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "worst" })
);
// Mark table temperatures with vertical dotted lines.
let annotations: Vec<_> = TABLE_TEMPERATURES
    .iter()
    .map(|&t| {
        serde_json::json!({
            "kind": "line",
            "axis": "x",
            "value": t,
            "style": { "lineType": "dotted" }
        })
    })
    .collect();
emit_line_chart!(
    &series,
    options = &serde_json::json!({
        "xLabel": "Evaluation temperature T0 [K]",
        "yLabel": "Cp absolute error [J/(mol·K)]",
        "yType": "log",
        "xMin": 200.0,
        "xMax": 500.0,
        "annotations": annotations
    })
);
```

At default $\delta = 0.001\,\mathrm{kJ/mol}$, maximum errors for every $k$ arise from sets including the close 298.15 K and 300 K pair.
$k = 3$ reaches 0.17 J/(mol·K) at 310 K; $k = 7$ reaches 0.61 J/(mol·K) at 230 K, so added nodes do not reduce errors.
The largest error-to-bound ratio is 0.79, within truncation plus rounding bounds.
Without rounding, only truncation remains, and maxima fall with $k$ from $1.1 \times 10^{-2}$ at $k = 3$ to $7.1 \times 10^{-7}\,\mathrm{J/(mol \cdot K)}$ at $k = 7$.
At $\delta = 0.01\,\mathrm{kJ/mol}$, maxima reach 4.3–12 J/(mol·K), above 10% of heat capacity.
For table differentiation, estimate rounding bounds from significant digits and remove one node from overly close pairs to reduce weights.

## Summary

Differentiate irregular tables by constructing `FiniteDifferenceStencil` at selected nodes and passing values to `apply`.
Heat capacity $C_p$ uses a first-derivative stencil, and its temperature derivative $\mathrm{d}C_p/\mathrm{d}T$ uses a second-derivative stencil; multiply by 1000 to convert kJ/mol tables to J/(mol·K).
Table-rounding errors are bounded by $(\delta/2) \sum_j \lvert w_j \rvert$ from `weight_amplification()` and `scale()`; overly close nodes enlarge weights and amplify rounding.
More nodes reduce truncation, but rounded tables can include large-weight sets and endpoints use one-sided formulas, so errors need not fall.
Choose node counts by comparing truncation order and rounding bounds estimated from table significant digits.
