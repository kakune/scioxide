`scioxide-differentiate` computes derivatives using only function values.
It computes first and second derivatives of scalar functions, multivariate gradients, Jacobians, Hessians, and Jacobian–vector products (directional derivatives) using fixed-step differences, adaptive differences with shrinking steps and extrapolation, caller-selected node differences, and the complex-step method.
For sparse Jacobians, coloring perturbs columns without nonzeros in a shared row together, reducing evaluations.
This page introduces difference errors and a first computation, then explains result interpretation, chapter structure, and related crates.

## Approximating derivatives from function values

For models with difficult analytic derivatives, external computations whose source cannot be changed, or data available only as tables, derivatives must be estimated from function values.
When a function's code can be modified, automatic differentiation (scioxide-ad) has no truncation error and is generally more accurate ([Choosing numerical differentiation](choosing/)).

Differences approximate derivatives by linear combinations of nearby function values.
For example, expanding $f(x \pm h)$ around $x$ in a Taylor series makes central difference $(f(x + h) - f(x - h)) / (2h)$ equal to $f'(x) + h^2 f'''(x)/6 + O(h^4)$.
Difference errors have two main sources.

| Source | Magnitude | Effect of decreasing step $h$ |
|---|---|---|
| Truncation error (discarded higher-order Taylor terms) | $O(h^p)$ for formula order $p$ ($p = 2$ for central differences) | Decreases |
| Rounding error and function noise (amplified by subtracting nearby values) | About $\varepsilon_f \lvert f \rvert / h$ for first derivatives | Increases |

$\varepsilon_f$ is the magnitude of relative error in function values.
For expressions combining a few elementary functions, it is several times machine epsilon $\varepsilon = 2^{-52} \approx 2.2 \times 10^{-16}$; for iterative computations or measurements, it is larger.
Their sum forms a U-shaped curve against the step, with the minimum at the optimal step.
For central differences, the minimum lies at $h \sim \varepsilon^{1/3}$, with error of order $\varepsilon^{2/3} \approx 3.7 \times 10^{-11}$ ([Rounding, noise, and optimal step size](algorithms/roundoff-and-noisy-functions/)).
The complex-step method avoids subtraction, so rounding error is not amplified for first derivatives.
Adaptive differences estimate error from changes in differences as the step shrinks.

Spatial discretization of partial differential equations also uses differences, but assembles differential operators across an entire domain into matrices to solve equations; scioxide-pde handles that task.
This crate computes derivatives of a supplied function at specified points.

## First computation

The next cell computes derivative $f'(x) = e^x(\sin x + \cos x)$ of $f(x) = e^x \sin x$ with `derivative(f, x)` on three method values.
Method values are types holding configuration only; methods select the operation ([Call forms](oxref:differentiate-call-forms-terms)).

- `FiniteDifference::default()` uses central differences with default step $h = \varepsilon^{1/3} \max(1, \lvert x \rvert)$ and takes 3 evaluations, including $f(x)$.
- `AdaptiveDifference::default()` shrinks the step and extrapolates with Ridders' method, returning an error estimate.
- `ComplexStep::default()` uses default step $h = \varepsilon$ to obtain $\operatorname{Im} f(x + ih)/h$ without subtraction, evaluating $f(x)$ and $f(x + ih)$ twice in total.

One-shot functions `derivative(f, x)` and `complex_step_derivative(g, x)` return the same central-difference and complex-step values but return only values; this cell uses method values to tabulate termination reasons and evaluation counts.
The differentiated function uses `RealScalar` and scioxide-core's `Complex` operations; the exact-value reference is computed with f64's inherent methods.
The input is evaluation point $x_0$.
The table shows values at $x_0$, errors against the exact value, estimated errors (adaptive differences only), termination reasons, and evaluation counts.
The chart plots errors of the three methods at 121 points on $x \in [-3, 3]$ with a logarithmic axis.
Exactly zero errors cannot be plotted logarithmically; they are excluded and counted in the second table.

```rust
//| id: differentiate-first-derivatives
//| ref: differentiate-first-derivatives
//| title: "First derivatives with central, adaptive, and complex-step methods"
//| run: reactive
//| crates: [scioxide-core, scioxide-differentiate]
//| inputs:
//|   x0: {"type":"range","label":"Evaluation point x0","description":"Point used for table values, marked by a vertical line on the chart.","min":-3.0,"max":3.0,"step":0.25,"value":1.0}
//| cases:
//|   - {"id":"large-x","label":"x0 = 3","description":"Both e^x and the default step are large, increasing central-difference error to order 10^-9.","inputs":{"x0":3.0}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"methods","path":"/rows/0/1","approx":{"value":3.756049227094728,"rtol":1e-9}}
//|       - {"artifact":"methods","path":"/rows/0/2","range":{"min":1e-12,"max":1e-10}}
//|       - {"artifact":"methods","path":"/rows/0/4","equals":"Completed"}
//|       - {"artifact":"methods","path":"/rows/0/5","equals":3}
//|       - {"artifact":"methods","path":"/rows/1/1","approx":{"value":3.756049227094728,"rtol":1e-14}}
//|       - {"artifact":"methods","path":"/rows/1/3","range":{"min":1e-14,"max":1e-10}}
//|       - {"artifact":"methods","path":"/rows/1/4","equals":"Converged"}
//|       - {"artifact":"methods","path":"/rows/2/1","approx":{"value":3.756049227094728,"rtol":1e-15}}
//|       - {"artifact":"methods","path":"/rows/2/3","equals":null}
//|       - {"artifact":"methods","path":"/rows/2/5","equals":2}
//|   - case: large-x
//|     expect:
//|       - {"artifact":"methods","path":"/rows/0/2","range":{"min":1e-10,"max":1e-8}}
//|       - {"artifact":"methods","path":"/rows/1/1","approx":{"value":-17.050059711659983,"rtol":1e-14}}
//|       - {"artifact":"methods","path":"/rows/2/1","approx":{"value":-17.050059711659983,"rtol":1e-15}}
use scioxide_core::{Complex, SciOxideError, RealScalar};
use scioxide_differentiate::{
    AdaptiveDifference, ComplexStep, DifferentiationResult, FiniteDifference,
};

// Write f(x) = e^x sin x with SciOxide functions; pass a complex version for the complex-step method.
let f = |t: f64| Ok::<f64, SciOxideError>(RealScalar::exp(t) * RealScalar::sin(t));
let g = |z: Complex<f64>| Ok::<_, SciOxideError>(z.exp() * z.sin());
// Reference: f'(x) = e^x (sin x + cos x) (independent computation with f64's inherent methods).
let exact = |x: f64| x.exp() * (x.sin() + x.cos());
let run = |x: f64| -> Result<[DifferentiationResult<f64>; 3], String> {
    Ok([
        FiniteDifference::default()
            .derivative(f, x)
            .map_err(|e| e.to_string())?,
        AdaptiveDifference::default()
            .derivative(f, x)
            .map_err(|e| e.to_string())?,
        ComplexStep::default()
            .derivative(g, x)
            .map_err(|e| e.to_string())?,
    ])
};
let names = ["Central difference", "Adaptive difference (Ridders)", "Complex-step method"];
let mut rows = Vec::new();
for (name, result) in names.iter().zip(run(x0)?) {
    let report = result.report();
    let value = result.values().ok_or("Derivative not published")?[0];
    rows.push((
        *name,
        value,
        (value - exact(x0)).abs(),
        result.errors().map(|e| e[0]),
        report.termination().to_string(),
        report.evaluations(),
    ));
}
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let digits16 = serde_json::json!({ "significantDigits": 16 });
let columns = serde_json::json!([
    { "key": "0", "label": "Method" },
    { "key": "1", "label": "f′(x0) [-]", "type": "number", "format": digits16 },
    { "key": "2", "label": "Error against exact value [-]", "type": "number", "format": sci3 },
    { "key": "3", "label": "Estimated error [-]", "type": "number", "format": sci3, "nullText": "None" },
    { "key": "4", "label": "Termination reason" },
    { "key": "5", "label": "Evaluations [count]", "type": "integer" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "methods" })
);
// Errors at 121 points in x ∈ [-3, 3]. Count and exclude exactly zero errors, which cannot be plotted logarithmically.
let mut points: [Vec<[f64; 2]>; 3] = Default::default();
let mut zeros = [0_usize; 3];
for k in 0..=120 {
    let x = -3.0 + 0.05 * k as f64;
    for (i, result) in run(x)?.iter().enumerate() {
        let error = (result.values().ok_or("Derivative not published")?[0] - exact(x)).abs();
        if error > 0.0 {
            points[i].push([x, error]);
        } else {
            zeros[i] += 1;
        }
    }
}
let dropped: Vec<_> = (0..3).map(|i| (names[i], zeros[i])).collect();
let columns = serde_json::json!([
    { "key": "0", "label": "Method" },
    { "key": "1", "label": "Zero-error points excluded from chart [count]", "type": "integer" }
]);
emit_table_with_columns!(
    columns,
    dropped,
    metadata = serde_json::json!({ "id": "dropped" })
);
let series: Vec<_> = (0..3)
    .map(|i| {
        serde_json::json!({
            "name": names[i],
            "points": points[i],
            "style": { "showSymbol": true }
        })
    })
    .collect();
emit_line_chart!(
    &series,
    options = &serde_json::json!({
        "xLabel": "Evaluation point x [-]",
        "yLabel": "Absolute derivative error [-]",
        "yType": "log",
        "annotations": [{ "kind": "line", "axis": "x", "value": x0, "label": "x0" }]
    })
);
```

At default $x_0 = 1$, central differences have error $2.3 \times 10^{-11}$ with 3 evaluations.
Adaptive differences reduce error to $8.9 \times 10^{-16}$ in 13 evaluations; estimated error $9.4 \times 10^{-13}$ exceeds the actual error.
The complex-step method takes 2 evaluations and has exactly zero error at this point.

In the chart, central-difference error grows on the positive side where both $e^x$ and step $\varepsilon^{1/3} \max(1, \lvert x \rvert)$ increase, reaching $4 \times 10^{-10}$ to $2.5 \times 10^{-9}$ at $x \in [2, 3]$.
Central-difference error decreases near points where leading truncation term $h^2 f'''(x)/6$ vanishes: $x = \pi/4$ and $x = -3\pi/4$, where $f'''(x) = 2e^x(\cos x - \sin x) = 0$.
Adaptive and complex-step errors stay below $3 \times 10^{-14}$ throughout; the complex-step error is exactly zero at 48 of the 121 points.
At $x_0 = 3$, central-difference error grows to $2.5 \times 10^{-9}$, while adaptive differences (17 evaluations) and complex-step errors remain around $10^{-14}$.

## Reading results

Owned method forms (such as `derivative` and `gradient`), and owned `evaluate` provided by Plans and node methods, return [`DifferentiationResult`](https://docs.rs/scioxide-differentiate/0.1.0/scioxide_differentiate/struct.DifferentiationResult.html).
`values()` is the derivative array (Jacobians and Hessians are row-major), returning `Some` only when output is published.
`errors()` gives elementwise estimated errors, returning `Some` only when adaptive differences or coloring publish output.
Error estimates come from extrapolation-table differences and propagated rounding errors; they are not upper bounds.
`into_values()` extracts values from successful evaluations and converts unsuccessful termination reasons into errors.
To use the best estimate when adaptive differences stop partway, read it with `values()` or `into_parts()`.
One-shot functions such as `derivative`, `gradient`, and `jacobian` return values only, converting unsuccessful termination reasons to the same errors as `into_values()`.

[`DifferentiationReport`](https://docs.rs/scioxide-differentiate/0.1.0/scioxide_differentiate/struct.DifferentiationReport.html), returned by `report()`, stores the producing method `source()`, termination reason `termination()`, function-evaluation count `evaluations()`, iteration count `iterations()`, count of estimated elements `completed_entries()`, and publication flag `output_available()`.
See [Call forms](oxref:differentiate-call-forms-terms) for evaluation and iteration counting.
The termination reason is one of the following [`DifferentiationTermination`](https://docs.rs/scioxide-differentiate/0.1.0/scioxide_differentiate/enum.DifferentiationTermination.html) variants.

| Termination reason | Meaning | Value published | `into_values()` error |
|---|---|---|---|
| `Completed` | Evaluated the full fixed-step, node, or complex-step formula (no accuracy claim) | Yes | None |
| `Converged` | In adaptive differences or coloring, every element's estimated error met tolerance at two consecutive levels, and the best estimate's error also meets tolerance | Yes | None |
| `RoundoffLimit` | Best estimated error failed to improve for 3 consecutive levels (often because rounding exceeds truncation error) | If every element has an estimate | `ConvergenceFailure` (`Stagnation`) |
| `RefinementLimit` | Reached the maximum level count | If every element has an estimate | `ConvergenceFailure` (`TruncationLimit`) |
| `StepSizeLimit` | No smaller step gives distinct finite sample points inside the interval | If every element has an estimate | `ConvergenceFailure` (`StepSizeLimit`) |
| `EvaluationLimit`, `IterationLimit` | Reached an evaluation or iteration limit | No | `ConvergenceFailure` (reason with the same name) |
| `Cancelled`, `DeadlineReached` | Execution-context cancellation or deadline | No | `ExecutionStopped` |

`is_success()` is true only for `Completed` and `Converged`.
Adaptive differences and coloring may publish values without termination reason `Converged`; inspect both termination and estimated errors before using them.
Invalid inputs and function errors return `Err` rather than reports; read classification with `e.kind()` ([Shared contracts and structure of numerical-differentiation algorithms](oxref:differentiate-input-checks)).

## Relationships with other crates

`scioxide-differentiate` depends only on scioxide-core.
Intervals `Bounds` and `ExtendedInterval`, evaluation and iteration limits `SolveBudgets`, `BudgetKind`, and `Budget`, tolerance `ErrorTolerance`, execution contexts `ExecutionContext`, `SolveContext`, and `SolveScope`, execution policy `ExecutionPolicy`, complex numbers `Complex`, sparse structure `StructuralPattern`, and coloring `ColoringSchedule` are scioxide-core types.
Sparse-Jacobian column coloring can be constructed with scioxide-sparse's `derivative_coloring`, but this crate depends only on `ColoringSchedule`, without depending on scioxide-sparse.
scioxide-ad provides automatic differentiation, appearing only by name as a candidate in derivative-source policy `DerivativeStrategy`.
Solvers in scioxide-rootfind, scioxide-optimize, and scioxide-ode accept Jacobian or gradient sources through `DerivativeStrategy`.

## Summary

`scioxide-differentiate` computes first and second derivatives, gradients, Jacobians, Hessians, and directional derivatives from function values using fixed-step, adaptive, node, complex-step, and coloring methods.
Difference error combines truncation and rounding in a U-shaped curve against step size; default steps approximate its minimum.
For functions admitting an analytic complex extension, complex-step first derivatives have errors of rounding magnitude; use adaptive differences when error estimates are needed.
Values are published only when `output_available()` is true; `Completed` makes no accuracy claim, and error estimates are not upper bounds, so inspect termination and estimated errors before use.
