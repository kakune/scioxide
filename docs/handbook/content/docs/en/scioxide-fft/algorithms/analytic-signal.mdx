Read the envelope and instantaneous phase of an amplitude-modulated wave from a complex signal with the negative-frequency components removed from the real signal (the analytic signal).
`scioxide-fft` does not provide Hilbert-transform or analytic-signal functions.
These are provided by `hilbert` and `envelope` in `scioxide-signal`.
This page constructs the same computation from `rfft` and `ifft` in `scioxide-fft`, derives the discrete frequency weights, and compares the result with `hilbert`.

## Definition of the analytic signal

Using the Fourier transform $X(f)$, define the Hilbert transform $\mathcal{H}\{x\}$ of a real signal $x(t)$ by

$$
\mathcal{F}\{\mathcal{H}\{x\}\}(f) = -i\,\mathrm{sgn}(f)\,X(f)
$$

as above.
This operation delays the phase of positive frequencies by $\pi/2$ and advances the phase of negative frequencies by $\pi/2$.
The spectrum of the analytic signal $z = x + i\,\mathcal{H}\{x\}$ is $2X(f)$ at positive frequencies, 0 at negative frequencies, and $X(0)$ at $f = 0$.
$\lvert z\rvert$ is called the instantaneous amplitude, and $\arg z$ the instantaneous phase.

$\lvert z\rvert$ can be read as the modulation envelope when the envelope spectrum lies in a band below the carrier frequency (Bedrosian's theorem).
For example, if the envelope $a(t)\ge0$ is band-limited to $\lvert f\rvert<f_c$, the Hilbert transform of $a(t)\cos 2\pi f_ct$ is $a(t)\sin 2\pi f_ct$, giving $\lvert z\rvert=a$.

## Weights for the discrete analytic signal

The discrete analytic signal that treats $N$ samples as one period is obtained by multiplying the DFT $X_k$ by the weights

$$
w_k = \begin{cases} 1 & k = 0,\ \text{or } N \text{ is even and } k = N/2 \\ 2 & 0 < k < N/2 \\ 0 & N/2 < k < N \end{cases}
$$

and taking the inverse transform to obtain $z_n$ (S. L. Marple, "Computing the discrete-time analytic signal via FFT", *IEEE Trans. Signal Process.* 47(9), 1999).
For odd lengths there is no Nyquist bin, so all of $0 < k \le \lfloor N/2\rfloor$ is doubled.
For a real sequence, $X_{N-k}=\overline{X_k}$, while $X_0$ and, for even lengths, $X_{N/2}$ are real.
The weights satisfy $w_k+w_{N-k}=2$ ($0<k<N$) and $w_0=1$, so $\operatorname{Re} z_n = x_n$ holds.
`scioxide_signal::hilbert` uses the same weights.

The construction using `scioxide-fft` proceeds as follows.

1. Compute $X_0, \dots, X_{\lfloor N/2\rfloor}$ with `rfft`.
2. Create a complex sequence of length $N$, put $w_k X_k$ into $k \le \lfloor N/2\rfloor$, and set the rest (negative frequencies) to 0.
3. Take the inverse transform with `ifft` to obtain $z_n$.
   The cost is $O(N \log N)$.

Because the discrete analytic signal treats the samples as a periodic sequence, a signal with a noninteger number of periods in the window has an endpoint discontinuity that spreads across the frequency band and distorts the envelope near the edges.

### Envelope of an amplitude-modulated wave

The following cell computes the analytic signal of the amplitude-modulated wave $x_n = (1 + 0.5\cos 2\theta_n)\cos c\,\theta_n$, $\theta_n = 2\pi n/N$ using the procedure above.
The inputs are the sample count $N$ and the number $c$ of carrier periods in the window.
When $c$ is an integer and $c + 2 < N/2$, $x$ is the sum of 3 positive frequencies, and the true envelope $1 + 0.5\cos 2\theta_n$ is recovered up to rounding error.
The outputs are an envelope plot and a table showing maxima of $\operatorname{Re} z - x$, the difference from `scioxide_signal::hilbert`, and the difference from the true envelope.

```rust
//| id: fft-analytic-signal-weights
//| ref: fft-analytic-signal-weights
//| title: "Compare an analytic signal constructed with rfft and ifft against signal's hilbert"
//| run: reactive
//| crates: [scioxide-core, scioxide-fft, scioxide-signal]
//| inputs:
//|   samples: {"type":"integer","label":"Sample count N","description":"Odd lengths have no Nyquist bin.","min":32,"max":64,"value":48}
//|   carrier_cycles: {"type":"range","label":"Carrier periods in the window c [-]","description":"A noninteger value makes the signal discontinuous at the window endpoints.","min":6,"max":12,"step":0.25,"value":10}
//| cases:
//|   - {"id":"odd-length","label":"N = 45","description":"For odd lengths, the weights have the same form and recover the envelope exactly.","inputs":{"samples":45}}
//|   - {"id":"fractional-carrier","label":"c = 9.5","description":"The periods do not fit the window, distorting the envelope near the edges.","inputs":{"carrier_cycles":9.5}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"errors","path":"/rows/0/1","range":{"max":1e-14}}
//|       - {"artifact":"errors","path":"/rows/1/1","range":{"max":1e-14}}
//|       - {"artifact":"errors","path":"/rows/2/1","range":{"max":1e-13}}
//|   - case: odd-length
//|     expect:
//|       - {"artifact":"errors","path":"/rows/1/1","range":{"max":1e-14}}
//|       - {"artifact":"errors","path":"/rows/2/1","range":{"max":1e-13}}
//|   - case: fractional-carrier
//|     expect:
//|       - {"artifact":"errors","path":"/rows/1/1","range":{"max":1e-14}}
//|       - {"artifact":"errors","path":"/rows/2/1","range":{"min":0.05}}
use scioxide_core::Complex;
use scioxide_fft::{Normalization, ifft, rfft};

// Amplitude-modulated wave x_n (f64 cos is used only to generate the input and true envelope)
let count = samples as usize;
let theta = |k: usize| 2.0 * std::f64::consts::PI * k as f64 / count as f64;
let truth: Vec<f64> = (0..count)
    .map(|k| 1.0 + 0.5 * (2.0 * theta(k)).cos())
    .collect();
let x: Vec<f64> = (0..count)
    .map(|k| truth[k] * (carrier_cycles * theta(k)).cos())
    .collect();

// 1. Compute X_0, …, X_⌊N/2⌋ with rfft
let bins = rfft(&x, Normalization::Inverse).map_err(|e| e.to_string())?;
// 2. Weights w_k: 1 for DC and even-length Nyquist, 2 for 0 < k < N/2, and 0 for negative frequencies
let mut weighted = vec![Complex::new(0.0, 0.0); count];
for (k, &value) in bins.bins().iter().enumerate() {
    let edge = k == 0 || 2 * k == count;
    weighted[k] = if edge { value } else { value * 2.0 };
}
// 3. Recover the analytic signal z_n with ifft
let z = ifft(&weighted, Normalization::Inverse).map_err(|e| e.to_string())?;

// Reference computation: signal's hilbert (analytic signal with the same weights)
let reference = scioxide_signal::hilbert(&x).map_err(|e| e.to_string())?;
let real_error = z
    .iter()
    .zip(&x)
    .map(|(zn, xn)| (zn.re - xn).abs())
    .fold(0.0_f64, f64::max);
let signal_error = z
    .iter()
    .zip(&reference)
    .map(|(p, q)| (*p - *q).norm())
    .fold(0.0_f64, f64::max);
let envelope_error = z
    .iter()
    .zip(&truth)
    .map(|(zn, e)| (zn.norm() - e).abs())
    .fold(0.0_f64, f64::max);

let series = |values: Vec<f64>| -> Vec<[f64; 2]> {
    values
        .into_iter()
        .enumerate()
        .map(|(k, v)| [k as f64, v])
        .collect()
};
emit_line_chart!(
    &vec![
        serde_json::json!({ "name": "Signal x", "points": series(x.clone()) }),
        serde_json::json!({ "name": "Instantaneous amplitude |z|", "points": series(z.iter().map(|v| v.norm()).collect()) }),
        serde_json::json!({
            "name": "True envelope",
            "points": series(truth.clone()),
            "style": { "lineType": "dashed" }
        }),
    ],
    options = &serde_json::json!({
        "xLabel": "Sample index n [-]",
        "yLabel": "Amplitude [-]",
        "xMin": 0.0,
        "xMax": 64.0,
        "yMin": -1.6,
        "yMax": 1.8
    })
);
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let columns = serde_json::json!([
    { "key": "0", "label": "Quantity" },
    { "key": "1", "label": "Maximum [-]", "type": "number", "format": sci2 }
]);
emit_table_with_columns!(
    columns,
    vec![
        ("max |Re z − x|", real_error),
        ("max |z − hilbert(x)|", signal_error),
        ("max ||z| − true envelope|", envelope_error),
    ],
    metadata = serde_json::json!({ "id": "errors" })
);
```

At the defaults $N = 48$, $c = 10$, the difference between $\operatorname{Re} z$ and $x$ is $4.4\times10^{-16}$, the difference from `hilbert` is $5.6\times10^{-16}$, and the difference from the true envelope is $6.4\times10^{-15}$; all are on the scale of rounding error.
They remain on the same scale for the odd length $N = 45$.
At $c = 9.5$ the signal does not join at the window endpoints, and the maximum envelope difference is 0.99.
The plot shows the difference concentrated near both ends of the window.
This difference comes from the periodicity assumed by the discrete Hilbert transform, rather than incorrect weights; the difference from `hilbert` remains on the scale of rounding error.

## Summary

Obtain the discrete analytic signal by weighting the `rfft` result by 1 at DC and even-length Nyquist and by 2 at positive frequencies, setting negative frequencies to 0, and transforming back with `ifft`.
With these weights the real part matches the input, and the result agrees with `scioxide_signal::hilbert` within rounding error.
$\lvert z_n\rvert$ can be interpreted as the envelope when the envelope band lies below the carrier and the signal completes an integer number of periods in the window.
For repeated calculations or multidimensional arrays, use `AnalyticSignalNdPlan` from `scioxide-signal`.
