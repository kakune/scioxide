DFTs of real images or volumes have conjugate symmetry, just as one-dimensional real sequences do.
`rfftn` uses this to pack one axis to half its size, and `irfftn` reconstructs the real array from packed bins.
This page explains packed-axis selection and shape, packed-spectrum types and inverse-transform checks, and `fftshift_nd` for reordering full-length spectra for display.
[Multidimensional Fourier transforms](../multidimensional-transforms/) covers axis separability and batch axes; [Real FFTs and Hermitian symmetry](../real-and-hermitian-transforms/) covers one-dimensional packed storage and tolerance $\tau$.

## Packing real arrays

The DFT of a real array of shape $(N_0,\ldots,N_{D-1})$ is conjugated when wavenumbers on all transformed axes are reversed simultaneously.

$$
X_{-\mathbf k}=\overline{X_{\mathbf k}}\qquad(\text{indices on each axis are reduced }\bmod N_d)
$$

Halving one axis determines the rest by symmetry, so `rfftn(input, shape, axes, normalization)` packs only the last axis of `axes` into $\lfloor N/2\rfloor+1$ values, leaving other selected axes full-length.
The packed axis need not be the array's last axis.
Empty `axes` gives `InvalidInput` (`Empty`); other errors match `fftn`.
For shape `[24, 32]`, `axes = [0, 1]` gives packed shape `[24, 17]`, while `axes = [1, 0]` gives `[13, 32]`.

The forward transform first applies a real FFT on the packed axis, then complex FFTs on the remaining axes over the packed shape.
The inverse reverses this order, first undoing complex axes and finally applying a real inverse transform on the packed axis.
If the packed axis has even length or an odd proper multiple of 3, 5, or 7, its real FFT costs approximately half a same-length complex FFT.
Remaining axes operate over the packed shape, also roughly halving their sequence counts.

For plans selecting `FftLayout::Real` or `Hermitian` with `FftNdPlan`, pass the packed side as a complex view with shape `packed_shape()`.
`packed_shape()` returns the shape with the last selected axis changed to $\lfloor N/2\rfloor+1$.

## HermitianSpectrumNd and inverse transforms

`HermitianSpectrumNd<S>` owns packed-bin `Vec` together with the real-array shape and sequence of transformed axes.

- `shape()` returns the real array's logical shape; `axes()` returns the transformed axes (the last is packed).
- `bins()` and `bins_mut()` borrow bins in packed-shape row-major order; `into_vec()` discards shape and axes and extracts the bins.
- `from_vec(shape, axes, bins)` checks axis bounds (`OutOfBounds`), empty axis sequences and length-0 axes (`InvalidInput`, `Empty`), duplicate axes (`InvalidInput`, `Inconsistent`), and bin count (`DimensionMismatch`).
  It does not check finite values or symmetry.

`irfftn` and `hfftn` use the shape and axes stored in `HermitianSpectrumNd`, so axes are not passed separately.
On the packed-axis coordinate-0 plane (DC plane) and, for even lengths, coordinate-$N/2$ plane (Nyquist plane), conjugate partners lie at positions obtained by reversing wavenumbers on selected axes other than the packed axis.
Unselected-axis indices are not reversed, so pairs are determined within each batch.
Bins on these planes need not all be real.
The inverse checks pairs using [tolerance](oxref:fft-hermitian-check) $\tau=\max(8\varepsilon M,\eta)$ derived from each batch's maximum component $M$.
If the real-part difference or imaginary-part sum of pair $(X,Y)$ exceeds $2\tau$, it returns `InvalidInput` (`OutOfRange`); otherwise it projects the pair to their average in workspace.
With only one selected axis, each sequence checks only the DC and Nyquist imaginary parts, as in one-dimensional `irfft`.
After complex axes are inverted, imaginary parts remaining on DC/Nyquist planes beyond the rounding-error bound give `NumericalInstability` (`Breakdown`).

`hfftn` and `ihfftn` handle conjugate-symmetric time arrays with real frequency arrays; they are multidimensional versions of `hfft` and `ihfft`.
Packing is the same as for `rfftn`.

## fftshift and ifftshift

Full-length spectra put zero frequency first, followed by positive and then negative frequencies.
`fftshift` rotates one-dimensional sequences and `fftshift_nd(input, shape, axes)` selected axes of row-major arrays, moving zero frequency to index $\lfloor N/2\rfloor$ on each axis.
`ifftshift` and `ifftshift_nd` reverse these operations.
They only reorder elements, without recomputing values or correcting phases.

On a length-$N$ axis, `fftshift` rotates left by $\lceil N/2\rceil$ and `ifftshift` by $\lfloor N/2\rfloor$.
These rotations are the same for even lengths but differ for odd lengths.
For length-5 `[0, 1, 2, 3, 4]`, `fftshift` gives `[3, 4, 0, 1, 2]`; a second `fftshift` does not restore the input, whereas `ifftshift` does.
A packed spectrum has no negative frequencies, so reordering `rfft` or `rfftn` output does not produce a full-length spectrum.
`fftshift_nd` and `ifftshift_nd` also accept length-0 axes; duplicates give `InvalidInput` (`Inconsistent`) and out-of-bounds axes give `OutOfBounds`.
They accept any element type, so reordering an index array reveals each element's destination.

## Experiment on packed shapes and reordering

The following cell transforms an asymmetric real array $x$ with `rfftn`, examining its packed shape and differences from corresponding bins of full-length complex `fftn`.
Compare conjugate-pair deviations on DC/Nyquist planes against inverse-transform tolerance $\tau=\max(8\varepsilon M,\eta)$.
Both deviations and $\tau$ are independent values computed from their formulas in the cell.
It also measures restoration of the original array through `irfftn` and through `ihfftn` followed by `hfftn`.
Read `shape()` and `axes()` from the `HermitianSpectrumNd` returned by `rfftn`, checking that logical shape is the original shape rather than the packed shape.
Reconstruct a copy of `bins()` with the same shape and axes using `from_vec`, apply `irfftn`, and count elements differing from the inverse of the original spectrum.
Finally reorder the full-length spectrum with `fftshift_nd`, recording the zero-frequency destination and counting elements differing from the original after restoration with `ifftshift_nd`.

```rust
//| id: fft-rfftn-packing
//| ref: fft-rfftn-packing
//| title: "Packed shapes of real arrays and frequency reordering"
//| run: reactive
//| crates: [scioxide-core, scioxide-fft]
//| inputs:
//|   rows_count: {"type":"range","label":"Rows M","description":"Axis-0 length.","min":2,"max":12,"step":1,"value":6}
//|   cols_count: {"type":"range","label":"Columns N","description":"Axis-1 length.","min":2,"max":12,"step":1,"value":8}
//|   axis_order: {"type":"select","label":"Transform-axis order axes","description":"The last axis is packed.","options":["[0, 1]","[1, 0]"],"value":"[0, 1]"}
//| cases:
//|   - {"id":"odd-sizes","label":"M = 5, N = 7","description":"Odd lengths. No Nyquist plane exists, so only the DC plane is checked.","inputs":{"rows_count":5,"cols_count":7}}
//|   - {"id":"reversed-axes","label":"axes = [1, 0]","description":"Axis 0 is packed, giving packed shape [4, 8].","inputs":{"axis_order":"[1, 0]"}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"layout","path":"/rows/0/2","equals":1}
//|       - {"artifact":"layout","path":"/rows/0/3","equals":6}
//|       - {"artifact":"layout","path":"/rows/0/4","equals":5}
//|       - {"artifact":"layout","path":"/rows/0/5","equals":30}
//|       - {"artifact":"checks","path":"/rows/0/1","range":{"max":1e-13}}
//|       - {"artifact":"checks","path":"/rows/2/1","range":{"max":1e-13}}
//|       - {"artifact":"checks","path":"/rows/3/1","range":{"max":1e-14}}
//|       - {"artifact":"checks","path":"/rows/4/1","range":{"max":1e-14}}
//|       - {"artifact":"shift","path":"/rows/0/0","equals":3}
//|       - {"artifact":"shift","path":"/rows/0/1","equals":4}
//|       - {"artifact":"shift","path":"/rows/0/2","equals":0}
//|       - {"artifact":"spectrum","path":"/rows/0/0","equals":6}
//|       - {"artifact":"spectrum","path":"/rows/0/1","equals":8}
//|       - {"artifact":"spectrum","path":"/rows/0/3","equals":1}
//|       - {"artifact":"spectrum","path":"/rows/0/4","equals":0}
//|   - case: odd-sizes
//|     expect:
//|       - {"artifact":"layout","path":"/rows/0/4","equals":4}
//|       - {"artifact":"layout","path":"/rows/0/5","equals":20}
//|       - {"artifact":"checks","path":"/rows/3/1","range":{"max":1e-14}}
//|       - {"artifact":"shift","path":"/rows/0/0","equals":2}
//|       - {"artifact":"shift","path":"/rows/0/1","equals":3}
//|       - {"artifact":"spectrum","path":"/rows/0/0","equals":5}
//|       - {"artifact":"spectrum","path":"/rows/0/1","equals":7}
//|   - case: reversed-axes
//|     expect:
//|       - {"artifact":"layout","path":"/rows/0/2","equals":0}
//|       - {"artifact":"layout","path":"/rows/0/3","equals":4}
//|       - {"artifact":"layout","path":"/rows/0/4","equals":8}
//|       - {"artifact":"layout","path":"/rows/0/5","equals":32}
//|       - {"artifact":"checks","path":"/rows/0/1","range":{"max":1e-13}}
//|       - {"artifact":"checks","path":"/rows/3/1","range":{"max":1e-14}}
//|       - {"artifact":"spectrum","path":"/rows/0/2","equals":1}
//|       - {"artifact":"spectrum","path":"/rows/0/3","equals":0}
//|       - {"artifact":"spectrum","path":"/rows/0/4","equals":0}
use scioxide_core::Complex;
use scioxide_fft::{
    HermitianSpectrumNd, Normalization, fftn, fftshift_nd, hfftn, ifftshift_nd, ihfftn, irfftn,
    rfftn,
};

let (m, n) = (rows_count.round() as usize, cols_count.round() as usize);
let shape = [m, n];
let axes = if axis_order == "[1, 0]" {
    [1, 0]
} else {
    [0, 1]
};
let (other_axis, packed_axis) = (axes[0], axes[1]);
let norm = Normalization::Inverse;
// Asymmetric real array (constructed with arithmetic alone).
let x: Vec<f64> = (0..m * n)
    .map(|i| 1.0 / (1.0 + i as f64) + 0.5 * ((i * 7) % 5) as f64)
    .collect();
// HermitianSpectrumNd stores packed bins together with the real array's logical shape and axis sequence.
let spectrum: HermitianSpectrumNd<f64> =
    rfftn(&x, &shape, &axes, norm).map_err(|e| e.to_string())?;
let mut packed_shape = shape;
packed_shape[packed_axis] = shape[packed_axis] / 2 + 1;
let packed_cols = packed_shape[1];
// Compare with the full-length complex transform at each packed coordinate (r, c).
let complex: Vec<Complex<f64>> = x.iter().map(|&v| Complex::new(v, 0.0)).collect();
let full = fftn(&complex, &shape, &[0, 1], norm).map_err(|e| e.to_string())?;
let packed_gap = spectrum
    .bins()
    .iter()
    .enumerate()
    .map(|(i, z)| (*z - full[(i / packed_cols) * n + i % packed_cols]).norm())
    .fold(0.0_f64, f64::max);
// On DC/Nyquist planes, measure deviations between other-axis coordinates c and (−c) mod N in the same form as SciOxide's validation.
let bin = |packed: usize, other: usize| {
    let mut coordinate = [0, 0];
    coordinate[packed_axis] = packed;
    coordinate[other_axis] = other;
    spectrum.bins()[coordinate[0] * packed_cols + coordinate[1]]
};
let mut endpoints = vec![0];
if shape[packed_axis] % 2 == 0 {
    endpoints.push(shape[packed_axis] / 2);
}
let length = shape[other_axis];
let mut mismatch = 0.0_f64;
for &plane in &endpoints {
    for c in 0..length {
        let (p, q) = (bin(plane, c), bin(plane, (length - c) % length));
        let gap = if 2 * c % length == 0 {
            p.im.abs()
        } else {
            0.5 * (p.re - q.re).abs().max((p.im + q.im).abs())
        };
        mismatch = mismatch.max(gap);
    }
}
let maximum = spectrum
    .bins()
    .iter()
    .map(|z| z.re.abs().max(z.im.abs()))
    .fold(0.0_f64, f64::max);
let tau = (8.0 * f64::EPSILON * maximum).max(f64::from_bits(1));
let real_gap = |a: &[f64]| {
    a.iter()
        .zip(&x)
        .map(|(p, q)| (p - q).abs())
        .fold(0.0_f64, f64::max)
};
let recovered = irfftn(&spectrum, norm).map_err(|e| e.to_string())?;
// Extract bins, reconstruct with the same shape and axes, and compare inverse results.
let rebuilt =
    HermitianSpectrumNd::from_vec(spectrum.shape(), spectrum.axes(), spectrum.bins().to_vec())
        .map_err(|e| e.to_string())?;
let rebuilt_back = irfftn(&rebuilt, norm).map_err(|e| e.to_string())?;
let rebuilt_mismatched = rebuilt_back
    .iter()
    .zip(&recovered)
    .filter(|(a, b)| a != b)
    .count();
let dual = ihfftn(&x, &shape, &axes, norm).map_err(|e| e.to_string())?;
let dual_back = hfftn(&dual, norm).map_err(|e| e.to_string())?;
// Reordering: zero-frequency destination and number of round-trip mismatches.
let shifted = fftshift_nd(&full, &shape, &[0, 1]).map_err(|e| e.to_string())?;
// Reorder an index array identically to find the destination of original index 0 (zero frequency) without relying on equal values.
let indices: Vec<usize> = (0..m * n).collect();
let moved_indices = fftshift_nd(&indices, &shape, &[0, 1]).map_err(|e| e.to_string())?;
let dc_index = moved_indices
    .iter()
    .position(|&i| i == 0)
    .ok_or("Zero-frequency element not found")?;
let restored = ifftshift_nd(&shifted, &shape, &[0, 1]).map_err(|e| e.to_string())?;
let mismatched = restored.iter().zip(&full).filter(|(a, b)| a != b).count();

let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let layout_columns = serde_json::json!([
    { "key": "0", "label": "Rows M", "type": "integer" },
    { "key": "1", "label": "Columns N", "type": "integer" },
    { "key": "2", "label": "Packed axis", "type": "integer" },
    { "key": "3", "label": "Packed-shape axis 0", "type": "integer" },
    { "key": "4", "label": "Packed-shape axis 1", "type": "integer" },
    { "key": "5", "label": "Bin count", "type": "integer" }
]);
emit_table_with_columns!(
    layout_columns,
    vec![(
        m,
        n,
        packed_axis,
        packed_shape[0],
        packed_shape[1],
        spectrum.bins().len()
    )],
    metadata = serde_json::json!({ "id": "layout" })
);
let spectrum_columns = serde_json::json!([
    { "key": "0", "label": "shape() axis 0", "type": "integer" },
    { "key": "1", "label": "shape() axis 1", "type": "integer" },
    { "key": "2", "label": "First axes() entry", "type": "integer" },
    { "key": "3", "label": "Last axes() entry (packed axis)", "type": "integer" },
    { "key": "4", "label": "Elements differing from inverse reconstructed with from_vec", "type": "integer" }
]);
emit_table_with_columns!(
    spectrum_columns,
    vec![(
        spectrum.shape()[0],
        spectrum.shape()[1],
        spectrum.axes()[0],
        spectrum.axes()[1],
        rebuilt_mismatched
    )],
    metadata = serde_json::json!({ "id": "spectrum" })
);
let check_columns = serde_json::json!([
    { "key": "0", "label": "Quantity" },
    { "key": "1", "label": "Value [-]", "type": "number", "format": sci3 }
]);
emit_table_with_columns!(
    check_columns,
    vec![
        ("Maximum corresponding-bin difference between rfftn and fftn", packed_gap),
        ("DC/Nyquist-plane conjugate-pair deviation", mismatch),
        ("Tolerance τ = max(8εM, η)", tau),
        ("Maximum difference between irfftn(rfftn(x)) and x", real_gap(&recovered)),
        ("Maximum difference between hfftn(ihfftn(x)) and x", real_gap(&dual_back)),
    ],
    metadata = serde_json::json!({ "id": "checks" })
);
let shift_columns = serde_json::json!([
    { "key": "0", "label": "Zero-frequency destination row", "type": "integer" },
    { "key": "1", "label": "Zero-frequency destination column", "type": "integer" },
    { "key": "2", "label": "Round-trip mismatching elements", "type": "integer" }
]);
emit_table_with_columns!(
    shift_columns,
    vec![(dc_index / n, dc_index % n, mismatched)],
    metadata = serde_json::json!({ "id": "shift" })
);
```

At the default 6×8 and `axes = [0, 1]`, axis 1 is packed, giving shape `[6, 5]` and 30 bins.
Changing to `axes = [1, 0]` packs axis 0, giving shape `[4, 8]` and 32 bins.
Packed bins differ from full-length `fftn` by $4.4\times10^{-15}$, reflecting rounding differences between paths computing the same bins.
DC/Nyquist conjugate-pair deviation is $4.4\times10^{-16}$, about 1/200 of tolerance $\tau=9.3\times10^{-14}$, so `rfftn` output can be passed directly to the inverse.
Round-trip errors for `irfftn` and for `ihfftn` followed by `hfftn` are both $8.9\times10^{-16}$.
For odd lengths 5×7 there is no Nyquist plane, and the DC-plane pair deviation is exactly 0.
`shape()` on `HermitianSpectrumNd` returns original `[6, 8]` rather than packed shape, and `axes()` returns the supplied axis sequence unchanged (with `axes = [1, 0]`, the last is axis 0).
The inverse of a spectrum reconstructed with `from_vec` agrees in every element with the inverse of the original spectrum.
`fftshift_nd` moves zero frequency to $(\lfloor M/2\rfloor,\lfloor N/2\rfloor)$: $(3,4)$ at the default and $(2,3)$ for 5×7; restoring with `ifftshift_nd` gives elementwise identity with the original.

## Summary

Reversing wavenumbers on all axes conjugates a real-array DFT, so `rfftn` packs only the last axis of `axes` into $\lfloor N/2\rfloor+1$ values; packed shape depends on axis order.
`HermitianSpectrumNd` stores packed bins, logical shape, and axes together, letting `irfftn` and `hfftn` determine the original shape.
The inverse checks DC/Nyquist-plane conjugate pairs against tolerance $2\tau$, projecting within tolerance and returning `InvalidInput` beyond it.
`fftshift_nd` and `ifftshift_nd` only reorder full-length spectra; for odd lengths they use different rotations.
