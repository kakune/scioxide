The cosmological two-point correlation function $\xi(r)$ is the three-dimensional Fourier transform of power spectrum $P(k)$.
[Computing correlation functions from power spectra with FFTLog](../fftlog-correlation-function/) converted this transform to order-$\mu = 1/2$ FFTLog and checked the conversion factors with a power-law closed form.
This page applies the same conversion to a synthetic spectrum mimicking baryon acoustic oscillations (BAO).
Compare with closed forms to examine how wavenumber range and point count change correlation-function error and peak location.

## Conversion function

Use $h\,\mathrm{Mpc}^{-1}$ for wavenumber $k$ (h/Mpc in figures and tables), $h^{-1}\mathrm{Mpc}$ for distance $r$ (Mpc/h), and $(h^{-1}\mathrm{Mpc})^3$ for $P$.
As in [Converting the spherical Bessel transform to FFTLog](oxref:fft-fftlog-correlation-mapping), transform $a(k) = k^{3/2}P(k)$ with order-$1/2$ FFTLog, then obtain $\xi(r) = A(r)/((2\pi)^{3/2} r^{3/2})$ from $A(r)$.
Interpret API input grid `log_radius(j)` as $\ln k_j$ and output grid `log_frequency(j)` as $\ln r_j$.

The following definition collects the conversion in one function (the same definition as on the preceding page).
`correlation_function` samples $P(k)$ on an $n$-point logarithmic grid over $[k_{\min}, k_{\max}]$ and returns output-grid $r$ and $\xi(r)$.
The offset is selected near 0 with `fftlog_low_ringing_offset`, so the range of $r$ is approximately $[1/k_{\max}, 1/k_{\min}]$.

```rust
//| id: fft-fftlog-acoustic-transform
//| kind: definitions
//| title: "Function computing ξ(r) from P(k) with order-1/2 FFTLog"
//| crates: [scioxide-core, scioxide-fft]
use scioxide_core::{Complex, ExecutionContext};
use scioxide_fft::{FftDirection, FftLogPlan, FftLogPlanSpec, fftlog_low_ringing_offset};

/// FFTLog output-grid distances r [Mpc/h], correlation function ξ(r) [-], and log multiplier condition number.
pub(crate) struct Correlation {
    pub(crate) radii: Vec<f64>,
    pub(crate) values: Vec<f64>,
    pub(crate) log_condition: f64,
}

/// Sample P(k) [(Mpc/h)³] on an n-point logarithmic grid with k ∈ [k_min, k_max] [h/Mpc],
/// and return ξ(r) = (2π)^{−3/2} r^{−3/2} A(r), A(r) = ∫ k^{3/2} P(k) J_{1/2}(kr) r dk.
pub(crate) fn correlation_function(
    power: impl Fn(f64) -> f64,
    k_min: f64,
    k_max: f64,
    n: usize,
    bias: f64,
) -> Result<Correlation, String> {
    let log_step = (k_max / k_min).ln() / (n - 1) as f64;
    let offset = fftlog_low_ringing_offset(log_step, 0.5, 0.0, bias).map_err(|e| e.to_string())?;
    let spec = FftLogPlanSpec::new(
        n,
        log_step,
        0.5,
        offset,
        Complex::new(bias, 0.0),
        FftDirection::Forward,
    )
    .with_log_radius_center(0.5 * (k_min * k_max).ln());
    let plan = FftLogPlan::new(spec).map_err(|e| e.to_string())?;
    // Use API input grid (log_radius) as wavenumber k
    let mut input = Vec::with_capacity(n);
    for j in 0..n {
        let k = plan.log_radius(j).map_err(|e| e.to_string())?.exp();
        input.push(Complex::new(k.powf(1.5) * power(k), 0.0));
    }
    let mut output = vec![Complex::new(0.0, 0.0); n];
    let mut workspace = plan.workspace(()).map_err(|e| e.to_string())?;
    plan.execute_into(
        &input,
        &mut output,
        &mut workspace,
        ExecutionContext::sequential(),
    )
    .map_err(|e| e.to_string())?;
    // Interpret output grid (log_frequency) as distance r and convert to ξ = A / ((2π)^{3/2} r^{3/2})
    let norm = (2.0 * std::f64::consts::PI).powf(1.5);
    let mut radii = Vec::with_capacity(n);
    let mut values = Vec::with_capacity(n);
    for (j, a) in output.iter().enumerate() {
        let r = plan.log_frequency(j).map_err(|e| e.to_string())?.exp();
        radii.push(r);
        values.push(a.re / (norm * r.powf(1.5)));
    }
    let log_condition = plan.diagnostics().log_multiplier_condition;
    Ok(Correlation {
        radii,
        values,
        log_condition,
    })
}
```

## Spectrum mimicking the acoustic scale

Sound waves in baryons and photons in the early universe leave a feature at acoustic scale $r_s \approx 105\,h^{-1}\mathrm{Mpc}$ (comoving distance) in the matter distribution.
It appears as oscillations in $k$ in the power spectrum and a peak at $r \approx r_s$ in the correlation function.
Check this correspondence with the following synthetic model.

$$
P(k) = P_0\, e^{-\sigma^2 k^2/2}\left[1 + \alpha\, j_0(k r_s)\right], \qquad
P_0 = 1\,(h^{-1}\mathrm{Mpc})^3,\quad \sigma = 8\,h^{-1}\mathrm{Mpc},\quad \alpha = 0.2
$$

This is a model constructed to have a closed form, not a measured matter power spectrum.
The correlation functions of its Gaussian and oscillatory parts are, respectively,

$$
\xi_G(r) = \frac{P_0\, e^{-r^2/(2\sigma^2)}}{(2\pi)^{3/2}\sigma^3}, \qquad
\xi_{\mathrm{osc}}(r) = \frac{\alpha P_0 \left[e^{-(r-r_s)^2/(2\sigma^2)} - e^{-(r+r_s)^2/(2\sigma^2)}\right]}{2\,(2\pi)^{3/2}\,\sigma\, r\, r_s}
$$

as above.
Obtain the second expression by converting $\sin(kr)\sin(kr_s)$ to a difference of cosines with the product-to-sum identity and using the Gaussian cosine integral $\int_0^\infty e^{-\sigma^2k^2/2}\cos(ck)\,dk = \sqrt{\pi/2}\,e^{-c^2/(2\sigma^2)}/\sigma$.
$\xi_{\mathrm{osc}}$ is a peak centered at $r = r_s$ with width $\sigma$; plotting $r^2\xi(r)$, as customary for correlation functions, makes it easier to see.
The factor $1/r$ and weight $r^2$ shift the maximum of $r^2\xi$ slightly away from $r_s$.

## Wavenumber range and peak location

The following cell fixes $k_{\min} = 10^{-5}\,h\,\mathrm{Mpc}^{-1}$ and takes upper cutoff $k_{\max}$, point count $n$, and $r_s$ as inputs.
$P$ falls to $e^{-8} \approx 3\times 10^{-4}$ at $k = 0.5\,h\,\mathrm{Mpc}^{-1}$, so smaller $k_{\max}$ truncates the Gaussian tail.
Measure error over $2 \le r \le 150\,h^{-1}\mathrm{Mpc}$ by dividing the closed-form difference by $\xi_G(0)$ (avoiding division by small tail reference values).
Find peak location by interpolating the maximum grid-point $r^2\xi$ with a parabola in $\ln r$ and compare with a closed-form maximum sampled every $0.01\,h^{-1}\mathrm{Mpc}$.
The first plot shows $r^2\xi(r)$ and the second the absolute closed-form difference, with linked $r$ axes.

```rust
//| id: fft-fftlog-correlation-function
//| ref: fft-fftlog-correlation-function
//| title: "Compare an acoustic-scale-like peak from FFTLog with a closed form"
//| run: reactive
//| crates: [scioxide-core, scioxide-fft]
//| uses: [fft-fftlog-acoustic-transform]
//| inputs:
//|   bao_scale: {"type":"range","label":"Acoustic scale r_s [Mpc/h]","description":"Move the P(k) oscillation period 2π/r_s and ξ(r) peak location.","min":90,"max":120,"step":5,"value":105}
//|   k_max: {"type":"range","label":"Upper wavenumber k_max [h/Mpc]","description":"Grid upper endpoint. Below 0.5 it truncates the Gaussian tail of P.","min":0.25,"max":2,"step":0.25,"value":1}
//|   sample_count: {"type":"range","label":"Logarithmic-grid points n","description":"Change spacing Δ while retaining the range.","min":256,"max":1024,"step":256,"value":512}
//| cases:
//|   - {"id":"truncated","label":"k_max = 0.25","description":"Truncates the P(0.25) = 0.14 tail, raising the maximum difference to 0.19 times ξ_G(0) and shifting the peak.","inputs":{"k_max":0.25}}
//|   - {"id":"small-scale","label":"r_s = 90","description":"The peak moves near 90 Mpc/h.","inputs":{"bao_scale":90}}
//|   - {"id":"coarse","label":"n = 256","description":"Coarser spacing with the same range leaves the error unchanged.","inputs":{"sample_count":256}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"summary","path":"/rows/0/1","approx":{"value":1.264e-14,"rtol":0.01}}
//|       - {"artifact":"summary","path":"/rows/0/2","approx":{"value":3.29e-6,"rtol":0.02}}
//|       - {"artifact":"summary","path":"/rows/0/3","approx":{"value":105.59,"atol":0.02}}
//|       - {"artifact":"summary","path":"/rows/0/4","approx":{"value":105.61,"atol":0.005}}
//|   - case: truncated
//|     expect:
//|       - {"artifact":"summary","path":"/rows/0/2","approx":{"value":0.1905,"rtol":0.01}}
//|       - {"artifact":"summary","path":"/rows/0/3","approx":{"value":111.95,"atol":0.05}}
//|   - case: small-scale
//|     expect:
//|       - {"artifact":"summary","path":"/rows/0/3","approx":{"value":90.68,"atol":0.02}}
//|       - {"artifact":"summary","path":"/rows/0/4","approx":{"value":90.71,"atol":0.005}}
//|   - case: coarse
//|     expect:
//|       - {"artifact":"summary","path":"/rows/0/2","approx":{"value":3.17e-6,"rtol":0.02}}
//|       - {"artifact":"summary","path":"/rows/0/3","approx":{"value":105.46,"atol":0.02}}
let (rs, sigma, alpha) = (bao_scale, 8.0_f64, 0.2_f64);
let (k_min, n) = (1e-5_f64, sample_count as usize);
// P(k) = e^{−σ²k²/2} [1 + α j₀(k r_s)] [(Mpc/h)³] (input generated with f64 functions)
let model = |k: f64| {
    let x = k * rs;
    (-0.5 * sigma * sigma * k * k).exp() * (1.0 + alpha * x.sin() / x)
};
let xi = correlation_function(model, k_min, k_max, n, 0.0)?;

// Independent check: closed forms for ξ_G and ξ_osc
let norm = (2.0 * std::f64::consts::PI).powf(1.5);
let gauss = |r: f64| (-0.5 * (r / sigma).powi(2)).exp();
let closed = |r: f64| {
    let peak = gauss(r - rs) - gauss(r + rs);
    gauss(r) / (norm * sigma.powi(3)) + alpha * peak / (2.0 * norm * sigma * r * rs)
};
let scale = 1.0 / (norm * sigma.powi(3)); // ξ_G(0)
let (mut weighted, mut reference, mut errors) = (Vec::new(), Vec::new(), Vec::new());
let mut largest = 0.0_f64;
let mut best: Option<usize> = None;
for (j, (&r, &value)) in xi.radii.iter().zip(&xi.values).enumerate() {
    let error = (value - closed(r)).abs();
    if (2.0..=150.0).contains(&r) {
        largest = largest.max(error / scale);
    }
    if (1.0..=300.0).contains(&r) {
        weighted.push([r, r * r * value]);
        reference.push([r, r * r * closed(r)]);
        if error > 0.0 {
            errors.push([r, error]);
        }
    }
    // Search for the grid-point maximum of r² ξ within r_s ± 30 Mpc/h
    let inside = (rs - 30.0..=rs + 30.0).contains(&r);
    if inside && best.is_none_or(|b| r * r * value > xi.radii[b].powi(2) * xi.values[b]) {
        best = Some(j);
    }
}
// Interpolate the grid-point maximum with a parabola in ln r (using both neighbors)
// Within the input range, r_s ± 30 always lies inside the output grid and has both neighboring points
let j = best.ok_or("No grid points in the peak-search range")?;
let y = |i: usize| xi.radii[i].powi(2) * xi.values[i];
let (left, mid, right) = (y(j - 1), y(j), y(j + 1));
let shift = 0.5 * (left - right) / (left - 2.0 * mid + right);
let step = (xi.radii[j + 1] / xi.radii[j]).ln();
let peak = xi.radii[j] * (shift * step).exp();
// Independent check: maximum of closed-form r² ξ evaluated at 0.01 Mpc/h spacing
let exact_peak = (0..=6000)
    .map(|i| rs - 30.0 + 0.01 * i as f64)
    .fold((0.0_f64, f64::MIN), |(at, high), r| {
        let value = r * r * closed(r);
        if value > high { (r, value) } else { (at, high) }
    })
    .0;

emit_line_chart!(
    &vec![
        serde_json::json!({
            "name": "FFTLog",
            "points": weighted,
            "style": { "showSymbol": true }
        }),
        serde_json::json!({
            "name": "Closed form",
            "points": reference,
            "style": { "lineType": "dashed" }
        }),
    ],
    options = &serde_json::json!({
        "xLabel": "Distance r [Mpc/h]",
        "yLabel": "r² ξ(r) [(Mpc/h)²]",
        "xType": "log",
        "xMin": 1.0,
        "xMax": 300.0,
        "annotations": [{ "kind": "line", "axis": "x", "value": rs, "label": "r_s" }],
        "link": { "group": "acoustic-r" }
    })
);
emit_line_chart!(
    &vec![serde_json::json!({ "name": "Absolute difference from closed form", "points": errors })],
    options = &serde_json::json!({
        "xLabel": "Distance r [Mpc/h]",
        "yLabel": "|ξ − closed form| [-]",
        "xType": "log",
        "yType": "log",
        "xMin": 1.0,
        "xMax": 300.0,
        "yMin": 1e-20,
        "yMax": 1e-3,
        "link": { "group": "acoustic-r" }
    })
);
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let fixed2 = serde_json::json!({ "fractionDigits": 2 });
let fixed4 = serde_json::json!({ "fractionDigits": 4 });
let columns = serde_json::json!([
    { "key": "0", "label": "Spacing Δ [-]", "type": "number", "format": fixed4 },
    { "key": "1", "label": "P tail P(k_max) [(Mpc/h)³]", "type": "number", "format": sci2 },
    { "key": "2", "label": "Maximum difference / ξ_G(0) (2 ≤ r ≤ 150) [-]", "type": "number", "format": sci2 },
    { "key": "3", "label": "FFTLog peak location [Mpc/h]", "type": "number", "format": fixed2 },
    { "key": "4", "label": "Closed-form peak location [Mpc/h]", "type": "number", "format": fixed2 }
]);
let log_step = (k_max / k_min).ln() / (n - 1) as f64;
emit_table_with_columns!(
    columns,
    vec![(log_step, model(k_max), largest, peak, exact_peak)],
    metadata = serde_json::json!({ "id": "summary" })
);
```

At the defaults $r_s = 105$, $k_{\max} = 1$, $n = 512$, the $P$ tail is $P(1) = 1.3\times 10^{-14}$, and maximum difference is $3.3\times 10^{-6}$ times $\xi_G(0)$.
The difference is largest near the output grid's left endpoint $r \approx 1\,h^{-1}\mathrm{Mpc}$.
There, $A(r) = (2\pi)^{3/2} r^{3/2}\xi(r)$ does not decay to 0, introducing a jump in the periodized output.
Near $r_s$, the difference is of order $4\times 10^{-12}$, less than $10^{-4}$ times the $\xi_{\mathrm{osc}}$ peak height $7\times 10^{-8}$.
FFTLog interpolation locates the peak at $105.59$ and the closed form at $105.61\,h^{-1}\mathrm{Mpc}$; both lie 0.6 beyond $r_s$.
At $r_s = 90$ the locations become $90.68$ and $90.71$, so the peak follows $r_s$.

At $k_{\max} = 0.25$, truncating the $P(0.25) = 0.14$ tail raises maximum difference to 0.19 times $\xi_G(0)$ and moves the $r^2\xi$ peak to $111.9\,h^{-1}\mathrm{Mpc}$, increasing its height about 2.8-fold.
At $k_{\max} = 2$, the output's left endpoint extends to $r \approx 0.5$, lowering the maximum difference ratio to $1.3\times 10^{-6}$.
Setting $n = 256$ leaves the range unchanged, so the maximum difference ratio stays nearly unchanged at $3.2\times 10^{-6}$; the coarser grid shifts the interpolated peak to $105.46$.
To reduce this model's error, reconsider the wavenumber range rather than the point count.

## Summary

The $r^2\xi$ peak appears near $r_s$, but factor $1/r$ and weight $r^2$ can prevent coincidence with $r_s$; interpret it against a closed form or wider-range computation.
In this model, truncating the $P$ tail at upper wavenumber $k_{\max}$ increases error and changes peak position and height.
Increasing points without changing range barely affects error; point count only refines peak-location interpolation.
Error is largest near left output endpoint $r \approx 1/k_{\max}$; near the peak, differences are sufficiently small relative to peak height.
