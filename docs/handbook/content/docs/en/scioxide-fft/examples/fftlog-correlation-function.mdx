If cosmic matter density fluctuations $\delta(\mathbf{x})$ are statistically homogeneous and isotropic, their two-point correlation function $\xi(r) = \langle\delta(\mathbf{x})\,\delta(\mathbf{x}+\mathbf{r})\rangle$ depends only on distance $r$.
Their power spectrum $P(k)$ is the three-dimensional Fourier transform of $\xi$ and depends only on wavenumber magnitude $k$.
Observed $k$ spans many decades, for example $10^{-4}$–$10\,h\,\mathrm{Mpc}^{-1}$, and $r$ spans $1$–$10^{3}\,h^{-1}\mathrm{Mpc}$, making logarithmic-grid [FFTLog](../../algorithms/fftlog/) suitable.

This page converts the correlation-function formula to the FFTLog convention and checks conversion factors and bias choices against a closed form for power-law spectra.
[Investigating acoustic-scale peaks with FFTLog](../fftlog-acoustic-peak/) uses a synthetic spectrum mimicking baryon acoustic oscillations (BAO) to examine wavenumber range versus correlation-function peak location.
It does not cover cosmological-parameter inference from observations.

## Units

Use units $h\,\mathrm{Mpc}^{-1}$ for wavenumber $k$ and $h^{-1}\mathrm{Mpc}$ for distance $r$.
$h$ is the dimensionless ratio of the Hubble constant to $100\,\mathrm{km\,s^{-1}\,Mpc^{-1}}$; measuring distances in $h^{-1}\mathrm{Mpc}$ makes the formulas independent of the value of $h$.
Figures and tables write $h\,\mathrm{Mpc}^{-1}$ as h/Mpc and $h^{-1}\mathrm{Mpc}$ as Mpc/h.
Power spectrum $P(k)$ has volume units $(h^{-1}\mathrm{Mpc})^3$, while correlation function $\xi$ is dimensionless.

## Converting the spherical Bessel transform to FFTLog

Integrating the three-dimensional Fourier transform over angles under isotropy gives

$$
\xi(r) = \frac{1}{2\pi^2} \int_0^\infty k^2 P(k)\, j_0(kr)\,dk, \qquad
j_0(z) = \frac{\sin z}{z}
$$

the expression above.
Substituting $j_0(z) = \sqrt{\pi/(2z)}\,J_{1/2}(z)$ gives

$$
a(k) = k^{3/2} P(k), \qquad
A(r) = \int_0^\infty a(k)\, J_{1/2}(kr)\, r\,dk, \qquad
\xi(r) = \frac{A(r)}{(2\pi)^{3/2}\, r^{3/2}}
$$

the expression above.
$A$ is the forward FFTLog transform $\int a(r) J_\mu(kr)\,k\,dr$ with names $r$ and $k$ interchanged, so its order is $\mu = 1/2$.
Interpret API input coordinate `log_radius(j)` as $\ln k_j$ and output coordinate `log_frequency(j)` as $\ln r_j$.
`with_log_radius_center` sets the input center $\ln k_c$, while the offset sets $\ln(k_c r_c)$.

The following definition collects the conversion into one function.
The [acoustic-scale example](../fftlog-acoustic-peak/) uses the same function.
`correlation_function` samples $P(k)$ on an $n$-point logarithmic grid over $[k_{\min}, k_{\max}]$, returning output-grid $r$ and $\xi(r)$.
The offset is selected near 0 with `fftlog_low_ringing_offset`, so the range of $r$ is approximately $[1/k_{\max}, 1/k_{\min}]$.

```rust
//| id: fft-fftlog-correlation-model
//| kind: definitions
//| title: "Function computing ξ(r) from P(k) with order-1/2 FFTLog"
//| crates: [scioxide-core, scioxide-fft]
use scioxide_core::{Complex, ExecutionContext};
use scioxide_fft::{FftDirection, FftLogPlan, FftLogPlanSpec, fftlog_low_ringing_offset};

/// FFTLog output-grid distances r [Mpc/h], correlation function ξ(r) [-], and log multiplier condition number.
pub(crate) struct Correlation {
    pub(crate) radii: Vec<f64>,
    pub(crate) values: Vec<f64>,
    pub(crate) log_condition: f64,
}

/// Sample P(k) [(Mpc/h)³] on an n-point logarithmic grid with k ∈ [k_min, k_max] [h/Mpc],
/// and return ξ(r) = (2π)^{−3/2} r^{−3/2} A(r), A(r) = ∫ k^{3/2} P(k) J_{1/2}(kr) r dk.
pub(crate) fn correlation_function(
    power: impl Fn(f64) -> f64,
    k_min: f64,
    k_max: f64,
    n: usize,
    bias: f64,
) -> Result<Correlation, String> {
    let log_step = (k_max / k_min).ln() / (n - 1) as f64;
    let offset = fftlog_low_ringing_offset(log_step, 0.5, 0.0, bias).map_err(|e| e.to_string())?;
    let spec = FftLogPlanSpec::new(
        n,
        log_step,
        0.5,
        offset,
        Complex::new(bias, 0.0),
        FftDirection::Forward,
    )
    .with_log_radius_center(0.5 * (k_min * k_max).ln());
    let plan = FftLogPlan::new(spec).map_err(|e| e.to_string())?;
    // Use API input grid (log_radius) as wavenumber k
    let mut input = Vec::with_capacity(n);
    for j in 0..n {
        let k = plan.log_radius(j).map_err(|e| e.to_string())?.exp();
        input.push(Complex::new(k.powf(1.5) * power(k), 0.0));
    }
    let mut output = vec![Complex::new(0.0, 0.0); n];
    let mut workspace = plan.workspace(()).map_err(|e| e.to_string())?;
    plan.execute_into(
        &input,
        &mut output,
        &mut workspace,
        ExecutionContext::sequential(),
    )
    .map_err(|e| e.to_string())?;
    // Interpret output grid (log_frequency) as distance r and convert to ξ = A / ((2π)^{3/2} r^{3/2})
    let norm = (2.0 * std::f64::consts::PI).powf(1.5);
    let mut radii = Vec::with_capacity(n);
    let mut values = Vec::with_capacity(n);
    for (j, a) in output.iter().enumerate() {
        let r = plan.log_frequency(j).map_err(|e| e.to_string())?.exp();
        radii.push(r);
        values.push(a.re / (norm * r.powf(1.5)));
    }
    let log_condition = plan.diagnostics().log_multiplier_condition;
    Ok(Correlation {
        radii,
        values,
        log_condition,
    })
}
```

## Power-law closed form

Set $P(k) = P_0\,(k/k_0)^p$, $P_0 = 1\,(h^{-1}\mathrm{Mpc})^3$, and $k_0 = 1\,h\,\mathrm{Mpc}^{-1}$.
Using $\int_0^\infty t^{s-1}\sin t\,dt = \Gamma(s)\sin(\pi s/2)$ ($-1 < s < 1$) at $s = p + 2$ and rewriting with Γ duplication and reflection formulas gives

$$
\xi(r) = \frac{2^p\,\Gamma\!\left(\frac{p+3}{2}\right)}{\pi^{3/2}\,\Gamma\!\left(-\frac{p}{2}\right)} \left(\frac{r}{r_0}\right)^{-(p+3)}, \qquad r_0 = 1\,h^{-1}\mathrm{Mpc}
$$

the expression above.
The integral converges at the origin for $p > -3$ and, including oscillation, at infinity for $p < -1$ (absolute convergence requires $p < -2$).
At $p = -2$, $\xi(r) = 1/(4\pi r)$.

FFTLog input is $a(k) = k^{p+3/2}$, so bias $q = p + 3/2$ makes $a(k)\,k^{-q}$ constant.
A constant has no jump under periodic extension, and output $A(r)\,r^{q}$ is also constant, so FFTLog agrees with the closed form within rounding error.
Only the multiplier at $\omega = 0$ is used, and $U_{1/2}(p + 3/2) = 2^{p+3/2}\,\Gamma((p+3)/2)/\Gamma(-p/2)$ gives the closed-form coefficient.
This agreement therefore checks order $\mu = 1/2$, factor $(2\pi)^{-3/2} r^{-3/2}$, and the grid reinterpretation.
Shifting bias as $q = p + 3/2 + \delta$ makes $a(k)k^{-q} = k^{-\delta}$ differ by a factor $e^{13.8\,\lvert\delta\rvert}$ between grid endpoints, creating a large jump in the periodic extension.

The following cell transforms on a 256-point grid over $k \in [10^{-3}, 10^{3}]\,h\,\mathrm{Mpc}^{-1}$ and computes relative differences from the closed form.
Inputs are power exponent $p$ and bias shift $\delta$.
Evaluate the closed-form coefficient with `scioxide_special::ln_gamma` and power functions with intrinsic f64 methods (independent check).
The first plot shows $\xi(r)$ on log-log axes and the second relative differences on a logarithmic axis, with linked $r$ axes.
At $\delta \ne 0$ some FFTLog $\xi$ values are negative; omit them from the log-log plot and report their count in the table.

```rust
//| id: fft-fftlog-power-law
//| ref: fft-fftlog-power-law
//| title: "Check bias and conversion factors with a power-law closed form"
//| run: reactive
//| crates: [scioxide-core, scioxide-fft, scioxide-special]
//| uses: [fft-fftlog-correlation-model]
//| inputs:
//|   exponent: {"type":"range","label":"Power exponent p","description":"P(k) = k^p. The integral converges for −3 < p < −1.","min":-2.5,"max":-1.5,"step":0.1,"value":-2}
//|   bias_shift: {"type":"range","label":"Bias shift δ","description":"q = p + 3/2 + δ. Nonzero shifts introduce a periodic-extension jump.","min":-0.4,"max":0.4,"step":0.2,"value":0}
//| cases:
//|   - {"id":"shallow","label":"p = −1.5","description":"ξ ∝ r^{−1.5}. Matching the bias gives rounding-scale agreement.","inputs":{"exponent":-1.5}}
//|   - {"id":"bias-off","label":"δ = 0.2","description":"The periodized input k^{−0.2} has a jump, causing relative differences of order 10⁻³ even centrally and above 1 at grid edges.","inputs":{"bias_shift":0.2}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"summary","path":"/rows/0/0","approx":{"value":-0.5,"atol":1e-12}}
//|       - {"artifact":"summary","path":"/rows/0/2","range":{"max":1e-14}}
//|       - {"artifact":"summary","path":"/rows/0/3","equals":0}
//|   - case: shallow
//|     expect:
//|       - {"artifact":"summary","path":"/rows/0/2","range":{"max":1e-14}}
//|       - {"artifact":"summary","path":"/rows/0/4","range":{"max":1e-12}}
//|   - case: bias-off
//|     expect:
//|       - {"artifact":"summary","path":"/rows/0/1","approx":{"value":5.73e-3,"rtol":0.01}}
//|       - {"artifact":"summary","path":"/rows/0/2","approx":{"value":5.87,"rtol":0.01}}
//|       - {"artifact":"summary","path":"/rows/0/3","equals":14}
use scioxide_special::ln_gamma;

let p = exponent;
let bias = p + 1.5 + bias_shift;
let (k_min, k_max, n) = (1e-3_f64, 1e3_f64, 256_usize);
// P(k) = (k / 1 h/Mpc)^p [(Mpc/h)³] (input generated with f64 powf)
let xi = correlation_function(|k| k.powf(p), k_min, k_max, n, bias)?;

// Independent check: ξ(r) = 2^p Γ((p+3)/2) / (π^{3/2} Γ(−p/2)) r^{−(p+3)}
let pi = std::f64::consts::PI;
let log_coefficient = p * 2.0_f64.ln() - 1.5 * pi.ln()
    + ln_gamma((p + 3.0) / 2.0).map_err(|e| e.to_string())?
    - ln_gamma(-p / 2.0).map_err(|e| e.to_string())?;
let coefficient = log_coefficient.exp();
let (mut fftlog, mut exact, mut relative) = (Vec::new(), Vec::new(), Vec::new());
let (mut central, mut whole, mut dropped) = (0.0_f64, 0.0_f64, 0_usize);
for (&r, &value) in xi.radii.iter().zip(&xi.values) {
    let reference = coefficient * r.powf(-(p + 3.0));
    let difference = (value - reference).abs() / reference;
    whole = whole.max(difference);
    if (0.1..=10.0).contains(&r) {
        central = central.max(difference);
    }
    exact.push([r, reference]);
    relative.push([r, difference]);
    // Exclude and count nonpositive values, which cannot be plotted on log-log axes
    if value > 0.0 {
        fftlog.push([r, value]);
    } else {
        dropped += 1;
    }
}
let relative: Vec<[f64; 2]> = relative
    .into_iter()
    .filter(|point| point[1] > 0.0)
    .collect();

emit_line_chart!(
    &vec![
        serde_json::json!({ "name": "FFTLog", "points": fftlog, "style": { "showSymbol": true } }),
        serde_json::json!({ "name": "Closed form", "points": exact, "style": { "lineType": "dashed" } }),
    ],
    options = &serde_json::json!({
        "xLabel": "Distance r [Mpc/h]",
        "yLabel": "Correlation function ξ(r) [-]",
        "xType": "log",
        "yType": "log",
        "xMin": 1e-3,
        "xMax": 1e3,
        "link": { "group": "power-law-r" }
    })
);
emit_line_chart!(
    &vec![serde_json::json!({ "name": "Relative difference", "points": relative })],
    options = &serde_json::json!({
        "xLabel": "Distance r [Mpc/h]",
        "yLabel": "|ξ − closed form| / closed form [-]",
        "xType": "log",
        "yType": "log",
        "xMin": 1e-3,
        "xMax": 1e3,
        "yMin": 1e-17,
        "yMax": 1e3,
        "link": { "group": "power-law-r" }
    })
);
let fixed2 = serde_json::json!({ "fractionDigits": 2 });
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let columns = serde_json::json!([
    { "key": "0", "label": "Bias q [-]", "type": "number", "format": fixed2 },
    { "key": "1", "label": "Maximum relative difference (0.1 ≤ r ≤ 10) [-]", "type": "number", "format": sci2 },
    { "key": "2", "label": "Maximum relative difference (entire grid) [-]", "type": "number", "format": sci2 },
    { "key": "3", "label": "Omitted ξ ≤ 0 points [count]", "type": "integer" },
    { "key": "4", "label": "Log multiplier condition number [-]", "type": "number", "format": fixed2, "nullText": "∞" }
]);
let condition = Some(xi.log_condition).filter(|c| c.is_finite());
emit_table_with_columns!(
    columns,
    vec![(bias, central, whole, dropped, condition)],
    metadata = serde_json::json!({ "id": "summary" })
);
```

At the defaults $p = -2$, $\delta = 0$, bias is $q = -0.5$ and the maximum relative difference over the entire grid is $7.6\times 10^{-16}$.
At $p = -1.5$ ($q = 0$) it is also $6.1\times 10^{-16}$, giving rounding-scale agreement with the closed form.
Setting $\delta = 0.2$ leaves relative difference $5.7\times 10^{-3}$ even in central $0.1 \le r \le 10\,h^{-1}\mathrm{Mpc}$; it reaches 5.9 at the edges and produces 14 points with $\xi \le 0$.
At $\delta = -0.4$, even the central relative difference is 1.6.
Agreement for matched bias checks FFTLog conventions; it does not imply the same accuracy for general spectra.
The default log multiplier condition number is 2.26, but only component $\omega = 0$ is used, so it does not affect this agreement.

## Summary

Transform isotropic $P(k)$ to $\xi(r)$ by applying order-$\mu = 1/2$ FFTLog to $a(k) = k^{3/2}P(k)$ and multiplying by $(2\pi)^{-3/2} r^{-3/2}$.
Interpret API input grids as wavenumbers and output grids as distances, keeping units consistent as the pair $h\,\mathrm{Mpc}^{-1}$ and $h^{-1}\mathrm{Mpc}$.
For power laws, matching bias to $q = p + 3/2$ gives rounding-scale closed-form agreement, checking conversion factors and grid reinterpretation.
A bias shift of only $0.2$ can raise edge relative errors above 1; for general spectra, check accuracy against closed forms or wider-range computations.
