These examples use FFT APIs for oscillations, images, integer arithmetic, PDEs, astronomical observations, and cosmology.
Each performs its main computation with `scioxide-fft` and checks it independently using defining sums, integer arithmetic, manufactured solutions, or closed forms.
Each page specifies input units and normalization.

| Example | Subject and investigation | Main APIs | Independent check |
|---|---|---|---|
| [Noninteger periods and spectral leakage](spectral-leakage/) | Window main lobes, distant leakage, and amplitude correction | `rfft`, `rfftfreq` | Dirichlet-kernel closed form |
| [Image-block compression with the DCT](dct-image-compression/) | Retaining low-frequency coefficients in $8\times8$ blocks and reconstructing jumps | `dctn`, `idctn` | DCT-II defining sum and squared error from Parseval's identity |
| [Multiprecision integer multiplication by convolution](fft-integer-multiplication/) | Coefficient rounding errors and integer recovery versus base and digit count | `rfft`, `irfft`, `HermitianSpectrum`, `next_fast_len` | Integer-only coefficient double sums and carrying |
| [Two-dimensional periodic Poisson equation](spectral-poisson/) | Exponential convergence, rounding floor, and zero-mean right-side condition | `rfftn`, `irfftn`, `fftfreq`, `rfftfreq` | Difference from a manufactured (known) solution and sample means of right side and solution |
| [Zoom FFT resolution](zoom-fft-tone-resolution/) | Observation-time-limited resolution and frequency-grid spacing | `zoom_fft`, `fft` | DTFT defining sum and zero-padded FFT |
| [NUFFT at irregular observation times](nonuniform-periodogram/) | Variable-star light-curve Fourier sums, requested accuracy versus kernel width, grid, and work | `NufftPlan`, `NufftPlanSpec`, `NufftDiagnostics` | Direct sum with accurately reduced phases (normalized by input 1-norm) |
| [Correlation functions with FFTLog](fftlog-correlation-function/) | Conversion of the spherical Bessel transform from power spectrum to correlation function and bias choice | `FftLogPlan`, `FftLogPlanSpec`, `fftlog_low_ringing_offset` | Power-law closed form |
| [Investigating acoustic-scale peaks with FFTLog](fftlog-acoustic-peak/) | Effects of wavenumber range and point count on error and peak location in $r^2\xi$ for a spectrum mimicking acoustic oscillations | `FftLogPlan`, `FftLogPlanSpec`, `fftlog_low_ringing_offset` | Closed forms for Gaussian and oscillatory parts and the maximum of closed-form $r^2\xi$ |

## Summary

When reading examples, distinguish input changes that alter the transformed problem from changes affecting only the evaluation grid.
Round-trip agreement and closeness to a continuous integral or known solution are separate checks; the latter requires independent checks such as manufactured solutions or defining sums.
Before comparing table errors, check whether they are absolute or divided by input 1-norm, sample count $N$, or maximum reference value.
When rounding results to integers, as in integer multiplication, assess true error against integer-only checks rather than distance to the nearest integer.
