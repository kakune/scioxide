An integrand may be available only at fixed points, as with measurements or simulation output.
It then cannot be reevaluated at new points as in adaptive quadrature; integration must use only the supplied samples.
This page covers trapezoidal and Simpson rules on nonuniform grids, Romberg integration of equally spaced samples, cumulative integration, and integration along multidimensional array axes.

If arbitrary evaluations are possible, use adaptive quadrature in [Embedded pairs and globally adaptive quadrature](../adaptive-quadrature/) or [Weighted quadrature for endpoint weights, principal values, and complex contours](../weighted-rules-and-sensitivities/).

---

## Sampled-data Plans and error estimates

Denote samples at coordinates $x_i$ by $y_i = f(x_i)$.
`SampledTrapezoidPlan`, `SampledSimpsonPlan`, and `SampledRombergPlan` prepare coordinates once and repeatedly integrate sample sequences on them.
They return neither a report (`IntegrationReport`) nor an error estimate.
Users estimate error from differences between rules of different orders or from integration of subsampled data.

For a single integration on the same coordinates, the one-shot functions `trapezoid(&samples, &coordinates)`, `simpson(&samples, &coordinates)`, and `cumulative_trapezoid(&samples, &coordinates)` suffice.
They create the corresponding Plan and workspace on the spot, returning the full-interval value or a `Vec` of cumulative values at each sample.
There are no configurable options, and results equal those of the Plan.
Unlike other one-shot functions, they return the value itself rather than `Integral`, without an error estimate.
Mismatched sample and coordinate counts give `DimensionMismatch`; coordinate conditions and errors are the same as for the Plan.
Use a Plan for repeated integration on the same coordinates, reuse of cumulative workspaces, cumulative Simpson or Romberg integration, or array-axis integration.

## Trapezoidal rule on a nonuniform grid

For strictly monotonic coordinates $x_0, \dots, x_{n-1}$ (increasing or decreasing), the trapezoidal rule is

$$
\int f\,dx \approx \sum_{i=0}^{n-2} \frac{h_i\,(y_i + y_{i+1})}{2}, \qquad h_i = x_{i+1} - x_i
$$


Each interval's error is $-h_i^3 f''(\xi_i)/12$, giving total error $-\frac{1}{12}\sum_i h_i^3 f''(\xi_i)$, which decreases as $O(h^2)$ with maximum spacing $h$.
It is exact for linear polynomials; decreasing coordinates integrate from $x_0$ to $x_{n-1}$ with reversed sign.
Fewer than 2 samples give 0.

`SampledTrapezoidPlan::new(&coordinates)` retains rounded weights $h_i/2$, storing only one weight for equal spacing.
The result is the exact sum of weight–sample products rounded once.
Preparation costs $O(n)$; application costs $O(nd)$ for $d$ real components.

## Simpson's rule on a nonuniform grid

For each interval pair $[x_{2k}, x_{2k+2}]$, `SampledSimpsonPlan` integrates a quadratic through 3 samples.
With spacings $h_1 = x_1 - x_0$, $h_2 = x_2 - x_1$, and $h = h_1 + h_2$, integrating Lagrange basis functions gives pair weights

$$
w_0 = \frac{h\,(2h_1 - h_2)}{6h_1}, \qquad w_1 = \frac{h^3}{6h_1h_2}, \qquad w_2 = \frac{h\,(2h_2 - h_1)}{6h_2}
$$

which reduce to ordinary Simpson $\frac{h}{6}(1, 4, 1)$ when $h_1 = h_2$.
Integrating the interpolation error $f'''(\xi)(x-x_0)(x-x_1)(x-x_2)/6$ gives

$$
\int_{x_0}^{x_2}(x-x_0)(x-x_1)(x-x_2)\,dx = \frac{h^3(h_1 - h_2)}{12}
$$

so the leading pair-error term is $f'''\,h^3(h_1-h_2)/72$, followed by $O(h^5 f^{(4)})$.
With equal spacing, the first term vanishes, giving exactness through cubics and total error $O(h^4)$.
Smoothly varying grids ($h_2 - h_1 = O(h^2)$) also retain $O(h^4)$, but arbitrary nonuniform grids reduce this to $O(h^3)$.
Nonuniform Simpson is exact for quadratics.

With an odd interval count, integrate the final interval using the quadratic through the last 3 samples.
With 2 samples use trapezoidal; with fewer than 2 return 0.
If a cumulative integral ends at a sample within a pair, integrate that pair's quadratic up to that sample.
Extreme spacing ratios make weights large, amplifying sample errors.
The Plan requires only finite weights.

Each weight uses exact products of coordinate differences, rounding numerator and denominator once each and the quotient once more, staying within 2 ulp of its exact value.
For equally spaced pairs, left and right weights agree bit for bit.
Since spacings themselves are not computed, coordinates whose width overflows, such as $[-10^{308}, 0, 10^{308}]$, can also be prepared.
Only weights outside the finite range give `NumericalInstability`; repeated coordinates or direction reversal give `InvalidInput`, and non-finite coordinates give `NonFinite`.

## Romberg integration of equally spaced samples

`SampledRombergPlan::new(samples, spacing)` integrates $2^k + 1$ equally spaced samples with signed spacing `spacing`.
Apply Richardson extrapolation to the trapezoidal sums $T_0, \dots, T_k$ at step size $2^k h, \dots, 2h, h$,

$$
R_{j,m} = R_{j,m-1} + \frac{R_{j,m-1} - R_{j-1,m-1}}{4^m - 1}, \qquad R_{j,0} = T_j
$$

and take $R_{k,k}$ as the result.
$R_{k,k}$ is exact for polynomials through degree $2k+1$; extrapolation is prepared as a single weight per sample.
The theory appears in [Euler–Maclaurin expansion and Romberg extrapolation](../romberg-extrapolation/).
Nonuniform coordinates are not accepted; a sample count other than $2^k + 1$ or zero spacing gives `InvalidInput`.

## Cumulative and axiswise integration

For trapezoidal and Simpson, `cumulative_into` writes integrals from $x_0$ to each $x_i$: the first is 0, and the last equals `integrate_into`.
Cumulative Romberg gives Romberg values on prefixes ending at indices $1, 2, 4, \dots, 2^k$, returned by `cumulative_indices()`.
Each prefix uses only its own samples.

Create `SampledWorkspace`, which temporarily retains results, from the Plan.
`plan.workspace(components)` serves `integrate_into` with storage for one result.
`plan.cumulative_workspace(components)` serves `cumulative_into`, with one result slot per sample for trapezoidal and Simpson or per `cumulative_indices()` index for Romberg; it also serves `integrate_into`.
`components` counts real components per value: 1 for real and 2 for complex.
Calls check only workspace component count and capacity, so sufficient capacity permits reuse with another Plan (the next experiment also uses trapezoidal cumulative workspace for Simpson).
Results are written only after all computation finishes, leaving output unchanged on error.

Use `axis_into(&samples, axis, &mut output, &mut workspace)` to integrate along one multidimensional array axis.
`samples` is scioxide-core's `NdView` (a slice paired with `StridedLayout`); each lane along `axis` is integrated as in `integrate_into`.
`output` is a `NdViewMut` with shape `samples` excluding `axis`.
`cumulative_axis_into` writes each lane's cumulative integrals; the length of `axis` in `output` becomes the cumulative result count.
Create axiswise workspaces `SampledAxisWorkspace` from array shape `Shape` using `plan.axis_workspace(shape, axis, components)` and `plan.cumulative_axis_workspace(shape, axis, components)`.
Shape and axis must match subsequent calls.
An `axis` at least the rank gives `OutOfBounds`, mismatched shapes give `DimensionMismatch`, non-finite samples give `NonFinite`, and result overflow gives `NumericalInstability` (`NumericalIssue::Overflow`).

## Cumulative integration on a nonuniform grid

Sample $f(x) = \sin x$ on $[0, \pi]$ using the grid $x_i = \pi (i/n)^p$ ($i = 0, \dots, n$).
$p = 1$ is equally spaced; $p > 1$ clusters points near the origin.
Compute the cumulative integral $\int_0^{x_i}\sin x\,dx = 1 - \cos x_i$ with trapezoidal and Simpson Plans, plotting error at each sample point.
The table shows full-interval error and observed order $\log_2(e_n/e_{2n})$ from errors on a grid with twice as many intervals.
For comparison, integrate $2^k + 1 \ge n + 1$ equally spaced samples on the same interval with `SampledRombergPlan`.
Compute the reference $\cos$ with f64 standard functions and samples $\sin x_i$ with SciOxide's `RealScalar::sin`.

Use the one-shot functions `trapezoid` and `simpson` for full-interval integration on the grid with twice as many intervals.
A single integration on the same coordinates needs no explicit Plan or workspace.
The last table column compares the results of one-shot `cumulative_trapezoid` and `simpson` with the Plan.
One-shot functions merely create the same Plan on the spot, so this difference is 0.

Inputs are the interval count $n$ and grid-stretching exponent $p$.
Exactly zero-error points cannot be plotted logarithmically, so they are omitted and counted in the table.
Coordinates and samples are passed to the next experiment.

```rust
//| id: integrate-sampled-cumulative
//| ref: integrate-sampled-cumulative
//| title: "Compare cumulative integration on a nonuniform grid with a closed form"
//| run: reactive
//| crates: [scioxide-core, scioxide-integrate]
//| exports: [coordinates, samples]
//| inputs:
//|   intervals: {"type":"range","label":"Interval count n [-]","description":"Sample count is n + 1. For odd n, Simpson integrates the last interval with a quadratic through 3 samples.","min":4,"max":64,"step":1,"value":16}
//|   stretch: {"type":"range","label":"Grid-stretching exponent p [-]","description":"x_i = π (i/n)^p. p = 1 gives equal spacing.","min":1,"max":3,"step":0.25,"value":2}
//| cases:
//|   - {"id":"uniform","label":"p = 1","description":"With equal spacing, Simpson error is small, O(h⁴).","inputs":{"stretch":1}}
//|   - {"id":"odd-intervals","label":"n = 15","description":"For an odd interval count, integrate the final interval with the quadratic through the last 3 samples.","inputs":{"intervals":15}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"methods","path":"/rows/0/4","range":{"min":1.9,"max":2.1}}
//|       - {"artifact":"methods","path":"/rows/1/4","range":{"min":3.8,"max":4.2}}
//|       - {"artifact":"methods","path":"/rows/2/2","range":{"min":0,"max":1e-8}}
//|       - {"artifact":"methods","path":"/rows/0/6","equals":0}
//|       - {"artifact":"methods","path":"/rows/1/6","equals":0}
//|   - case: uniform
//|     expect:
//|       - {"artifact":"methods","path":"/rows/1/2","range":{"min":0,"max":1e-4}}
//|       - {"artifact":"methods","path":"/rows/1/4","range":{"min":3.8,"max":4.2}}
//|   - case: odd-intervals
//|     expect:
//|       - {"artifact":"methods","path":"/rows/1/2","range":{"min":1e-4,"max":1e-2}}
use scioxide_core::RealScalar;
use scioxide_integrate::{
    SampledRombergPlan, SampledSimpsonPlan, SampledTrapezoidPlan, cumulative_trapezoid,
    simpson, trapezoid,
};

let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let fixed2 = serde_json::json!({ "fractionDigits": 2 });
let pi = std::f64::consts::PI;
// Grid x_i = π (i/m)^p with m intervals and samples sin x_i.
let grid = |m: usize| -> (Vec<f64>, Vec<f64>) {
    let x: Vec<f64> = (0..=m)
        .map(|i| pi * RealScalar::powf(i as f64 / m as f64, stretch))
        .collect();
    let y = x.iter().map(|&t| RealScalar::sin(t)).collect();
    (x, y)
};
let n = intervals as usize;
let (coordinates, samples) = grid(n);

// Compute cumulative integrals ∫₀^{x_i} sin x dx with trapezoidal and Simpson rules.
let trapezoid_plan = SampledTrapezoidPlan::new(&coordinates).map_err(|e| e.to_string())?;
let simpson_plan = SampledSimpsonPlan::new(&coordinates).map_err(|e| e.to_string())?;
// Create cumulative workspace from the trapezoidal Plan and reuse it for Simpson with the same sample count.
let mut workspace = trapezoid_plan
    .cumulative_workspace(1)
    .map_err(|e| e.to_string())?;
let mut cumulative = [vec![0.0_f64; n + 1], vec![0.0_f64; n + 1]];
trapezoid_plan
    .cumulative_into(&samples, &mut cumulative[0], &mut workspace)
    .map_err(|e| e.to_string())?;
simpson_plan
    .cumulative_into(&samples, &mut cumulative[1], &mut workspace)
    .map_err(|e| e.to_string())?;

// One-shot functions create the same Plan on the spot, so their results should agree with the Plan.
let one_shot = cumulative_trapezoid(&samples, &coordinates).map_err(|e| e.to_string())?;
let one_shot_total = simpson(&samples, &coordinates).map_err(|e| e.to_string())?;
let one_shot_gap = [
    one_shot
        .iter()
        .zip(&cumulative[0])
        .map(|(a, b)| (a - b).abs())
        .fold(0.0, f64::max),
    (one_shot_total - cumulative[1][n]).abs(),
];

// Difference from reference 1 − cos x (f64 standard functions). Count zeros because they cannot be plotted logarithmically.
let mut curves = [Vec::new(), Vec::new()];
let mut zeros = [0_usize; 2];
for (i, &x) in coordinates.iter().enumerate().skip(1) {
    let exact = 1.0 - x.cos();
    for c in 0..2 {
        let error = (cumulative[c][i] - exact).abs();
        if error > 0.0 {
            curves[c].push([x, error]);
        } else {
            zeros[c] += 1;
        }
    }
}
let series = |name: &str, points: &Vec<[f64; 2]>| {
    let style = serde_json::json!({ "showSymbol": true });
    serde_json::json!({ "name": name, "points": points, "style": style })
};
emit_line_chart!(
    &vec![
        series("Trapezoidal", &curves[0]),
        series("Simpson", &curves[1])
    ],
    options = &serde_json::json!({
        "xLabel": "Upper endpoint x_i [-]",
        "yLabel": "Cumulative integral error [-]",
        "yType": "log",
        "xMin": 0.0,
        "xMax": pi
    })
);

// Full-interval integration on a grid with twice as many intervals (one-shot calls). Observed order is log₂(e_n / e_2n).
let (refined, refined_samples) = grid(2 * n);
let refined_errors = [
    (trapezoid(&refined_samples, &refined).map_err(|e| e.to_string())? - 2.0).abs(),
    (simpson(&refined_samples, &refined).map_err(|e| e.to_string())? - 2.0).abs(),
];

// Comparison: Romberg integration of 2^k + 1 ≥ n + 1 equally spaced samples on the same interval.
let count = n.next_power_of_two() + 1;
let spacing = pi / (count - 1) as f64;
let uniform: Vec<f64> = (0..count)
    .map(|i| RealScalar::sin(i as f64 * spacing))
    .collect();
let romberg = SampledRombergPlan::new(count, spacing).map_err(|e| e.to_string())?;
let mut romberg_workspace = romberg.workspace(1).map_err(|e| e.to_string())?;
let mut romberg_total = 0.0_f64;
romberg
    .integrate_into(&uniform, &mut romberg_total, &mut romberg_workspace)
    .map_err(|e| e.to_string())?;

// The exact full-interval value is 2. Observed order is defined only when both errors are positive.
let order =
    |coarse: f64, fine: f64| (coarse > 0.0 && fine > 0.0).then(|| (coarse / fine).log2());
let mut rows = Vec::new();
for (c, name) in ["Trapezoidal", "Simpson"].into_iter().enumerate() {
    // e and f are errors with n and 2n intervals; z counts omitted plot points; g is the difference from the one-shot result.
    let (e, f) = ((cumulative[c][n] - 2.0).abs(), refined_errors[c]);
    let (z, g) = (Some(zeros[c]), Some(one_shot_gap[c]));
    rows.push((name, n + 1, e, Some(f), order(e, f), z, g));
}
let romberg_error = (romberg_total - 2.0).abs();
rows.push((
    "Romberg (equally spaced)",
    count,
    romberg_error,
    None,
    None,
    None,
    None,
));
let columns = serde_json::json!([
    { "key": "0", "label": "Method" },
    { "key": "1", "label": "Samples [count]", "type": "integer" },
    { "key": "2", "label": "Full-interval error [-]", "type": "number", "format": sci2 },
    { "key": "3", "label": "Error with 2n intervals [-]", "type": "number", "format": sci2, "nullText": "Not computed" },
    { "key": "4", "label": "Observed order [-]", "type": "number", "format": fixed2, "nullText": "Undefined" },
    { "key": "5", "label": "Points omitted from plot [count]", "type": "integer", "nullText": "No plot" },
    { "key": "6", "label": "Difference from one-shot result [-]", "type": "number", "format": sci2, "nullText": "Not applicable" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "methods" })
);
export!(coordinates, &coordinates);
export!(samples, &samples);
```

With the defaults ($n = 16$, $p = 2$), full-interval errors were $1.3 \times 10^{-2}$ for trapezoidal and $2.1 \times 10^{-4}$ for Simpson.
Doubling intervals gave observed orders 2.00 for trapezoidal and 4.00 for Simpson, retaining Simpson's $O(h^4)$ even on the smoothly stretched grid.
Romberg with the same count of 17 equally spaced samples gave error $5 \times 10^{-9}$; when sample locations can be chosen, an equally spaced grid with extrapolation is advantageous.
The $p = 2$ grid has about twice the uniform spacing near $\pi$, giving larger errors than equal spacing ($p = 1$).

At $n = 15$, Simpson integrates the final interval with the quadratic through the last 3 samples, increasing its error to $1.2 \times 10^{-3}$.
Here the interval counts for $n$ and $2n$ differ in parity, giving an observed order around 6 that cannot be interpreted as convergence order.

## Integration along an array axis

Construct a two-dimensional array $F_{ji} = e^{-y_j}\sin x_i$ ($y_j = 0, 1, 2$) from the previous experiment's coordinates and samples, and integrate along the $x$ axis (axis 1) with Simpson.
The array is row-major with shape $3 \times (n+1)$.
Each row's exact value is $2e^{-y_j}$; compute reference $e^{-y}$ with f64 standard functions.
Also apply `cumulative_axis_into` to the same array, verifying that each row's final cumulative value agrees with `axis_into`.
There are no inputs; it follows the previous experiment's $n$ and $p$.

```rust
//| id: integrate-sampled-axis
//| ref: integrate-sampled-axis
//| title: "Integration and cumulative integration along an axis of a two-dimensional array"
//| run: reactive
//| crates: [scioxide-core, scioxide-integrate]
//| dependsOn:
//|   grid: integrate-sampled-cumulative
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"axis","path":"/rows/0/2","range":{"min":0,"max":1e-3}}
//|       - {"artifact":"axis","path":"/rows/2/1","approx":{"value":0.27064,"rtol":1e-3}}
//|       - {"artifact":"axis","path":"/rows/1/3","equals":0}
use scioxide_core::{NdView, NdViewMut, RealScalar, Shape, StridedLayout};
use scioxide_integrate::SampledSimpsonPlan;

let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let digits10 = serde_json::json!({ "significantDigits": 10 });
let read = |key: &str| -> Result<Vec<f64>, String> {
    serde_json::from_value(grid[key].clone()).map_err(|e| e.to_string())
};
let (coordinates, samples) = (read("coordinates")?, read("samples")?);
let m = coordinates.len();

// Two-dimensional array F[j][i] = e^(−y_j) sin x_i (row-major, shape 3 × m).
let heights = [0.0_f64, 1.0, 2.0];
let mut values = Vec::with_capacity(3 * m);
for &y in &heights {
    values.extend(samples.iter().map(|&s| RealScalar::exp(-y) * s));
}
let (shape, strides) = ([3, m], [m, 1]);
let layout = StridedLayout::new(&shape, &strides).map_err(|e| e.to_string())?;
let view = NdView::new(&values, layout).map_err(|e| e.to_string())?;
let plan = SampledSimpsonPlan::new(&coordinates).map_err(|e| e.to_string())?;

// Integrate along axis 1 (x). Output shape excludes axis 1, giving [3].
let mut totals = [0.0_f64; 3];
let total_layout = StridedLayout::new(&[3], &[1]).map_err(|e| e.to_string())?;
let mut total_view = NdViewMut::new(&mut totals, total_layout).map_err(|e| e.to_string())?;
let mut workspace = plan
    .axis_workspace(Shape::new(&shape).map_err(|e| e.to_string())?, 1, 1)
    .map_err(|e| e.to_string())?;
plan.axis_into(&view, 1, &mut total_view, &mut workspace)
    .map_err(|e| e.to_string())?;

// Cumulative integration along axis 1. Output has the input shape [3, m], with each row's last value equal to the integral above.
let mut prefixes = vec![0.0_f64; 3 * m];
let prefix_layout = StridedLayout::new(&shape, &strides).map_err(|e| e.to_string())?;
let mut prefix_view =
    NdViewMut::new(&mut prefixes, prefix_layout).map_err(|e| e.to_string())?;
let mut cumulative_workspace = plan
    .cumulative_axis_workspace(Shape::new(&shape).map_err(|e| e.to_string())?, 1, 1)
    .map_err(|e| e.to_string())?;
plan.cumulative_axis_into(&view, 1, &mut prefix_view, &mut cumulative_workspace)
    .map_err(|e| e.to_string())?;

let mut rows = Vec::new();
for (j, &y) in heights.iter().enumerate() {
    // Reference 2 e^(−y) (f64 standard functions).
    let exact = 2.0 * (-y).exp();
    let last = prefixes[j * m + m - 1];
    rows.push((
        y,
        totals[j],
        (totals[j] - exact).abs(),
        (last - totals[j]).abs(),
    ));
}
let columns = serde_json::json!([
    { "key": "0", "label": "y_j [-]", "type": "number", "format": { "fractionDigits": 0 } },
    { "key": "1", "label": "Integral along axis 1 [-]", "type": "number", "format": digits10 },
    { "key": "2", "label": "Difference from 2e^(−y_j) [-]", "type": "number", "format": sci2 },
    { "key": "3", "label": "Difference from final cumulative value [-]", "type": "number", "format": sci2 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "axis" })
);
```

With defaults, each row equals the one-dimensional Simpson result multiplied by $e^{-y_j}$, with error reduced by the same factor.
The final cumulative value agrees bit for bit with the axis integral.

## Summary

Integrate fixed samples with `SampledTrapezoidPlan`, `SampledSimpsonPlan`, or `SampledRombergPlan`, preparing coordinates just once in a Plan.
For one integration on the same coordinates, one-shot `trapezoid`, `simpson`, or `cumulative_trapezoid` suffices and gives the same result as the Plan.
On nonuniform grids, trapezoidal has error $O(h^2)$; Simpson gives $O(h^4)$ on smoothly varying grids and $O(h^3)$ on arbitrary grids.
If sample locations can be chosen, $2^k+1$ equally spaced samples and Romberg extrapolation give high accuracy with few samples.
Sample integration returns no error estimate; estimate accuracy and observed order from differences between rules or from a grid with twice as many intervals.
Use `cumulative_into` for cumulative integration and `axis_into` and `SampledAxisWorkspace` for integration along one multidimensional array axis; output remains unchanged on error.
