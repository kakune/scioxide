[Tensor-product rules and Genz–Malik adaptive cubature](../multidimensional-and-monte-carlo/) shows tensor-product evaluation counts growing as $n^d$; [Monte Carlo integration estimators and statistics](../monte-carlo-integration/) shows Monte Carlo error decreasing only as $N^{-1/2}$, independently of dimension.
Smooth integrands with weak interactions between variables allow methods between these extremes.
This page covers sparse grids with deterministic node selection and quasi-Monte Carlo (QMC) using randomized low-discrepancy sequences.
Sparse grids mitigate the curse of dimensionality by combining nodes differently; randomized QMC arranges points to reduce variance while retaining statistical standard errors.

## Nested Clenshaw–Curtis rules

Sparse grids start from a sequence of one-dimensional rules $Q_0, Q_1, \dots$ at levels $l = 0, 1, 2, \dots$.
`SparseGridPlan` uses a one-node midpoint rule for $Q_0$ and $2^l+1$-node [Clenshaw–Curtis rules](oxref:integrate-clenshaw-curtis) for $Q_l$ ($l\ge1$).
Clenshaw–Curtis nodes map $\cos(\pi i/2^l)$ ($i = 0, \dots, 2^l$) to the interval; every node at level $l$ is also a node at level $l+1$.
The midpoint is also a level-1 node, making the entire sequence nested.
Nesting allows all previous-level function values to be reused at the next level.
A level-$l \ge 1$ rule exactly integrates polynomials through degree $2^l+1$; the midpoint rule is exact through degree 1.

## Smolyak difference rules

With difference rules $\Delta_l = Q_l - Q_{l-1}$ ($Q_{-1}=0$), the level-$L$ one-dimensional rule is the telescoping sum $Q_L = \sum_{l=0}^{L}\Delta_l$.
In $d$ dimensions, define a surplus for each multi-index $\boldsymbol k=(k_1,\dots,k_d)$ as the tensor product of difference rules:

$$
\Delta_{\boldsymbol k} f = (\Delta_{k_1}\otimes\cdots\otimes\Delta_{k_d})f
$$

For index set $\mathcal I$, use the estimate

$$
A_{\mathcal I}[f] = \sum_{\boldsymbol k\in\mathcal I}\Delta_{\boldsymbol k} f
$$


If $\mathcal I$ contains all indices through level $L$ on every axis (a box), $A_{\mathcal I}$ equals the level-$L$ tensor-product rule.
Taking $\mathcal I = \{\boldsymbol k : |\boldsymbol k|_1 \le q\}$ (a simplex) gives the classical Smolyak rule.
$\Delta_{\boldsymbol k} f$ is the product of increments from increasing each axis level once; for smooth functions with bounded mixed derivatives, it decreases rapidly as $|\boldsymbol k|_1$ increases.
Thus omitting indices with large level sums gives small errors.

For node count $N$ and bounded mixed derivatives through order $r$ in each variable, classical Smolyak error is of order $O(N^{-r}(\log N)^{(d-1)(r+1)})$.
Compared with tensor-product error $O(N^{-r/d})$, dimensional dependence is reduced to a logarithmic factor.
The index set must be downward closed (if $\boldsymbol k \in \mathcal I$ and $k_j > 0$, then $\boldsymbol k - \boldsymbol e_j \in \mathcal I$), ensuring correct telescoping cancellation.

## Dimension-adaptive refinement

When variables differ in importance, a simplex-shaped index set spends nodes on unimportant axes as well.
`SparseGridPlan` uses Gerstner–Griebel dimension adaptivity to grow $\mathcal I$ for the integrand.

1. Divide indices into accepted (old) and candidate (active) sets.
   Initially evaluate only $\boldsymbol 0$.
2. Accept the candidate with largest surplus magnitude normalized by tolerance.
3. Add forward neighbors $\boldsymbol k + \boldsymbol e_j$ of the accepted index whose backward neighbors are all accepted, preserving downward closure, and compute their surpluses.
4. Estimate using the sum of accepted surpluses $\sum_{\boldsymbol k \in \text{old}} \Delta_{\boldsymbol k} f$.

Evaluate only previously unevaluated nodes of new candidates.
No node is evaluated twice within one call.
New nodes are authorized together against the evaluation limit; a rejected candidate is canceled without evaluation, leaving that direction unexplored.

### Error estimation and termination

For candidates and accepted indices with unresolved forward neighbors, estimate error as four times the sum of surplus magnitudes:

$$
\eta = 4 \sum_{\boldsymbol k \in \text{active} \,\cup\, \text{unresolved old}} |\Delta_{\boldsymbol k} f|
$$


Stop with `HeuristicToleranceReached` when $\eta$ is within tolerance and every axis's level-1 index $\boldsymbol e_j$ is accepted.
Requiring level-1 acceptance prevents accidentally small surpluses, for example from symmetry, from hiding unexplored directions.
Unexplored surpluses are not guaranteed small, so this estimate carries `ErrorReliability::Heuristic` and is not an error bound.
Unlike Gauss–Kronrod rules, surplus estimates do not separately include a roundoff floor.
`is_success()` is true, but check by varying tolerance or comparing with known values.

`SparseGridOptions` holds tolerance, maximum level per axis (at most 52), a limit on total accepted and candidate indices, an evaluation limit for distinct nodes, and execution policy.
Defaults are absolute and relative $\sqrt\varepsilon$ with the root mean square norm, maximum level 4, 64 indices, 4096 evaluations, and sequential execution; change `SparseGridOptions::default()` with `with_tolerance`, `with_max_level`, `with_max_indices`, `with_max_evaluations`, and `with_execution_policy`.
Settings whose maximum-level one-dimensional node count $2^{L}+1$ exceeds the evaluation limit are rejected during preparation with `InvalidInput`.
After the initial estimate, reaching the evaluation limit gives `BudgetLimit(Evaluation)`; reaching the index limit or exhausting candidates under the maximum level gives `RefinementLimit`; both return the current estimate and an error estimate recomputed by the same method.
Stopping before the initial estimate returns `ConvergenceFailure` or `ExecutionStopped` as an error.
If a narrow box axis has no representable interior initial midpoint, the call returns `NumericalInstability` (`Breakdown`).
If later mapped nodes coincide through rounding, return the last completed estimate and error estimate with termination status `GeometryFailure`.

### Plan and workspace

`SparseGridPlan::new(d, options)` prepares difference rules through the maximum level for use on arbitrary boxes and integrands.
The `SparseGridWorkspace` returned by `plan.workspace(components)` stores index sets and evaluated node values in $O(I(d+c)+E(d+c))$ memory, where $I$ is the index limit and $E$ the evaluation limit.
Plans with equal or lower limits can share workspace; `plan.integrate_into(f, &bounds, &mut out, &mut workspace, scope)` does not allocate.
Workspace with a different dimension or insufficient index or evaluation capacity for the plan limits is rejected with `InvalidInput` (`Inconsistent`).
Node values are reused only within a call, not carried into the next call.
`plan.integrate(f, &bounds)` is the convenience form that constructs workspace internally.

Workspace returns diagnostics from the preceding call.
`cached_nodes()` is the count of distinct evaluated nodes, and `component_errors()` contains componentwise error estimates.
For each axis $j$, `directional_indicators()` sums $4\max_c|\Delta_{\boldsymbol k} f|$ over indices included in the error estimate with $k_j > 0$, indicating directions where estimated error remains.
A zero indicator on an axis does not imply zero omitted error along that axis.

## Randomized quasi-Monte Carlo

Quasi-Monte Carlo averages over low-discrepancy sequences, such as Sobol sequences, that fill the unit cube uniformly instead of using random points.
The Koksma–Hlawka inequality $|I-Q_N|\le V_{\mathrm{HK}}(f)\,D_N^*$ bounds error by integrand variation $V_{\mathrm{HK}}$ and point star discrepancy $D_N^*=O((\log N)^d/N)$.
Neither is practically computable, so the inequality does not provide a practical error estimate.

Instead, use $R$ independently randomized sequence replicates.
`scioxide_random::QmcReplicatePlan::new(&QmcPlan::sobol(d)?, &root, QmcReplicateOptions)` constructs $R$ Sobol replicates with linear matrix scrambling and digital shifts from independent random streams ($R \ge 2$, power-of-two point counts).
Each randomized point is marginally uniform on $[0,1)^d$, making every replicate estimate $\hat I_r$ unbiased.
The structure between points is retained, so for smooth integrands the variance of $\hat I_r$ decreases faster than ordinary Monte Carlo's $\sigma^2/N$.
The final estimate is the replicate mean $\bar I$, with uncertainty computed from between-replicate variability:

$$
\widehat{\operatorname{SE}} = \frac{s_R}{\sqrt R},\qquad s_R^2 = \frac{1}{R-1}\sum_{r=1}^R(\hat I_r-\bar I)^2
$$

Return a Student-t interval with $R-1$ degrees of freedom.
Variance across individual points within one sequence does not measure QMC uncertainty, because those points are dependent.
[scioxide-random randomization and error estimation from replicates](oxref:random-qmc-replicate-error) and [Comparing Monte Carlo and randomized Sobol](../../../scioxide-random/examples/monte-carlo-vs-sobol/) describe randomization and the behavior of replicate-based error estimation.

### Execution with MonteCarloIntegrator

Run randomized QMC through `MonteCarloIntegrator::integrate_into`, passing `&QmcReplicatePlan` as the uniform source (`UniformSource`).
Set the plan's `MonteCarloOptions` replicate count to the QMC replicate count and its sample count to the number of points per replicate.
A mismatch gives `InvalidInput`; a point dimension differing from the proposal's uniform count gives `DimensionMismatch`.
`workspace.statistics()` uses basis `VarianceBasis::Replicates` and degrees of freedom $R - 1$.
`workspace.children()` returns replicate estimates, but child statistics are `None` because points within a replicate are dependent.
The same plan and workspace also accept pseudorandom `RandomStreams`, allowing both sources to be compared at equal evaluation counts.

## Expected multilayer transmission

When light traverses $d$ layers and layer $j$ has uniformly uncertain optical thickness in $[0,\tau_j]$, expected transmission is

$$
\mathbb E\left[e^{-\sum_j\tau_j u_j}\right] = \int_{[0,1]^d}e^{-\sum_j\tau_j u_j}\,d\boldsymbol u = \prod_{j=1}^d\frac{1-e^{-\tau_j}}{\tau_j}
$$


Set $\tau_j=\tau_1/j$ to decrease uncertainty in later layers and give axes different importance.
The following definitions block contains transmission `transmission` shared by two cells and the independent reference `exact_transmission`, evaluating the product on the right with SciOxide `exp_m1`.

```rust
//| id: integrate-transmission-model
//| kind: definitions
//| title: "Multilayer transmission integrand and exact expected transmission"
//| crates: [scioxide-core]
use scioxide_core::RealScalar;

// Transmission exp(−Σ τ_j u_j) (u is a unit-cube point; tau contains each layer's maximum optical thickness).
pub(crate) fn transmission(u: &[f64], tau: &[f64]) -> f64 {
    RealScalar::exp(-u.iter().zip(tau).map(|(x, t)| x * t).sum::<f64>())
}

// Expected transmission Π (1 − e^{−τ_j}) / τ_j. Compute 1 − e^{−τ} with exp_m1 to avoid cancellation.
pub(crate) fn exact_transmission(tau: &[f64]) -> f64 {
    tau.iter().map(|&t| -RealScalar::exp_m1(-t) / t).product()
}
```

`directional_indicators()` values have the same order of magnitude on all five axes.

Important axes with large $\tau_j$ have used more levels before reaching this point.

```rust
let last = rows.last().ok_or("The table is empty")?;
let outcome = if completed {
    Outcome::satisfied("All runs used all prescribed samples (no accuracy claim)")
} else {
    Outcome::partial("Some runs stopped before using all prescribed samples")
};
emit_outcome!(
    outcome
        .explanation("Standard errors describe statistical uncertainty, not error bounds.")
        .status(last.5.clone())
        .diagnostic("Maximum evaluation count", last.1 as f64, None)
        .diagnostic("Monte Carlo standard error", last.3, None)
);
```

With defaults (seed 7), randomized QMC gives difference $3.9\times10^{-4}$ (standard error $5.6\times10^{-4}$) at 256 evaluations and $2.5\times10^{-7}$ (standard error $2.6\times10^{-7}$) at 65536.
Increasing evaluation count by 256 reduces standard error by about 2100, a decay of about $N^{-1.4}$, faster than $N^{-1/2}$.
Ordinary Monte Carlo gives difference $5.2\times10^{-4}$ (standard error $3.6\times10^{-4}$) at the same 65536 evaluations; its standard error decreases by about 18 from 256 evaluations, following $N^{-1/2}$.
With the default seed, every row's difference-to-standard-error ratio is within $\pm 1.5$.
At seed 23, the Monte Carlo row with 256 evaluations has ratio $-3.3$.
Standard error is a statistical guide to error magnitude; exceeding it by large amounts has small but nonzero probability.
Randomized QMC standard errors use replicate variability with 7 degrees of freedom, so their estimates themselves fluctuate with relative standard deviation around 30%.

For this smooth integrand, sparse grids reach the smallest errors with the fewest evaluations.
Randomized QMC is slower than sparse grids but provides statistical standard errors instead of error estimates, retaining unbiasedness when integrand smoothness is lost.

## Summary

Sparse grids sum tensor products of differences between nested Clenshaw–Curtis rules, reducing the tensor-product curse of dimensionality to a logarithmic factor for smooth functions with bounded mixed derivatives.
`SparseGridPlan` uses dimension-adaptive refinement, adding indices along large-surplus directions to concentrate nodes on important axes; `directional_indicators()` shows this imbalance.
Success is `HeuristicToleranceReached`, and error estimates are heuristic; check by varying tolerance or comparing with known values.
Randomized QMC passes independent `QmcReplicatePlan` replicates to `MonteCarloIntegrator`, returning standard errors and intervals from replicate variability with $R-1$ degrees of freedom, giving the same statistical-uncertainty interface as ordinary Monte Carlo with fewer evaluations.
Both lose efficiency for discontinuities or localized peaks; consider [Adaptive Monte Carlo (VEGAS and MISER)](../adaptive-monte-carlo/) or domain subdivision.
