This table summarizes types for one-dimensional integration over bounded and infinite intervals.
Pass intervals as scioxide-core `Interval` values; constructing an `Interval` rejects non-finite or reversed endpoints.
Zero-width intervals return exact zero and `DegenerateDomain` without evaluation.
Fixed rules apply nodes and weights once, terminate with `FixedRuleCompleted`, and make no accuracy claim.
Adaptive and multilevel rules terminate with `ToleranceReached` (`HeuristicToleranceReached` for double-exponential transforms) when tolerance is met; stopping at a limit returns a full-domain estimate with an unsuccessful termination reason.
Shared result types and `SubdivisionOptions` are listed on the [API guide's first page](../).

## Sampled-data integration

Sampled-data plans prepare coordinates once and repeatedly integrate sample sequences at those coordinates.
Create workspace with the plan's `workspace(components)`, `cumulative_workspace(components)`, `axis_workspace(shape, axis, components)`, or `cumulative_axis_workspace(shape, axis, components)`.
For a single integration, use one-shot functions `trapezoid`, `simpson`, and `cumulative_trapezoid`.
They return neither reports nor error estimates and compute all results before writing, leaving output unchanged on error.
Result overflow gives `NumericalInstability`; non-finite samples give `NonFinite`.
