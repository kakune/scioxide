Damped oscillations occur in RLC transient currents, free structural vibration, nuclear magnetic resonance free-induction decay, and many other responses.
Their time integral represents net circuit charge or a Laplace-transform value of the response.
Positive and negative lobes nearly cancel at high frequency, leaving integrals far smaller than signal magnitude and making error criteria decisive.
This example computes finite-time integrals using oscillatory weights and infinite integrals through extrapolated cycle sums, checking both against closed forms.

## Damped oscillations and closed-form integrals

Consider dimensionless signal with decay rate $a > 0$ [s⁻¹] and angular frequency $\omega > 0$ [rad/s],

$$
f(t) = e^{-a t}\cos(\omega t)
$$


Its time constant is $\tau = 1/a$ and period $P = 2\pi/\omega$, with $\omega/(2\pi a)$ oscillations per time constant.
For current $I_0 f(t)$ of amplitude $I_0$, for example, $I_0 \int f\,dt$ is the transferred charge.
Below, $f$ is dimensionless and integral units are s.

Two integrations by parts give antiderivative

$$
F(t) = \frac{e^{-at}\left[-a\cos(\omega t) + \omega\sin(\omega t)\right]}{a^2 + \omega^2}
$$


Thus finite-time and infinite-time integrals are, up to time $T$,

$$
I(T) = \int_0^T f(t)\,dt = F(T) - F(0), \qquad
I_\infty = \int_0^\infty f(t)\,dt = \frac{a}{a^2 + \omega^2}
$$


$I_\infty$ is also Laplace transform $\mathcal{L}\{f\}(s) = (s + a)/[(s + a)^2 + \omega^2]$ evaluated at $s = 0$.
For $\omega \gg a$, $I_\infty \approx a/\omega^2$, reducing magnitude to order $\omega^{-2}$ relative to signal magnitude 1.

## Cancellation and error criteria

Measure cancellation against absolute-value integral $A(T) = \int_0^T |f(t)|\,dt$ through ratio

$$
C(T) = \frac{|I(T)|}{A(T)}
$$


Compute $A(T)$ from closed forms by splitting at zeros $t_k = (k + \tfrac{1}{2})\pi/\omega$ of $\cos(\omega t)$ and summing absolute half-period integrals $F(t_{k+1}) - F(t_k)$.
For $C(T) \ll 1$, the integral is a difference of nearly equal positive and negative contributions.

Relative tolerance $\varepsilon_{\mathrm{rel}}|Q|$ then tightens proportionally to small $|Q|$ and loses meaning near $T$ where the integral crosses zero.
Signal magnitude has scale $A(T)$; use physically meaningful absolute tolerance $\varepsilon_{\mathrm{abs}}$ to control stopping.

## Quadrature with oscillatory weights

`WeightedQuadraturePlan::fourier` handles integrals $\int_a^b g(t)\cos(\omega t)\,dt$; callbacks return only smooth amplitude $g(t) = e^{-at}$.
Returning values already multiplied by $\cos(\omega t)$ applies the weight twice and computes a different integral.

For subdomain half-width $h$, regions satisfying $|\omega| h > 2$ use modified Clenshaw–Curtis: multiply Chebyshev interpolation of $g$ by modified moments of $\cos(\omega t)$.
Weights handle oscillation exactly, so evaluation counts depend on smoothness of $g$ rather than the interval's half-period count.
For $|\omega| h \le 2$, apply Gauss–Kronrod to product $g(t)\cos(\omega t)$.
Error estimates use nested-rule differences; moment subdomains take the larger of that and an estimate from the two highest Chebyshev coefficients.
`WeightedQuadratureOptions::with_moment_levels` sets bisection depth for prepared moments, default 16 levels.
At this depth, regions still satisfying $|\omega| h > 2$ are not bisected further; unmet tolerance gives `RefinementLimit`.
This is Fourier-weighted quadrature ([Cancellation in oscillatory integrals and tails of Fourier integrals](oxref:integrate-fourier-weight-moments)).

## Infinite integrals and cycle sums

Compute infinite integral $I_\infty$ directly through `FourierTailPlan` without truncating at $T$.
`FourierDomain::Upper { lower: 0.0 }` represents half-line $[0, \infty)$.
The Plan divides it into intervals of length

$$
L = \frac{(2\lfloor|\omega|\rfloor + 1)\pi}{|\omega|}
$$

(an odd number of half-periods), integrating each by Fourier-weighted quadrature above.
Odd half-period groups give alternating interval signs and an alternating partial-sum series.
Wynn's ε algorithm extrapolates partial sums, estimating tail contributions from changes in extrapolated values.

This tail estimate is empirical.
The Plan integrates at least 6 intervals and accepts estimates only after both interval magnitudes and maximum sampled $|g|$ decrease at least as fast as $|t|^{-1/5}$ for 3 consecutive intervals.
Meeting tolerance terminates with `HeuristicToleranceReached`.
This counts as success, but observed-decay estimates are not upper bounds.
Without established decay, keep adding intervals; reaching limit `FourierTailOptions::with_max_cycles` (default 128) gives `RefinementLimit`.
After accepting all tails, an aggregate error estimate still above tolerance gives `Stagnation`.
The `TailDiagnostics` returned by workspace `component_errors` contains integrated interval count (`shells`) and tail state (`status`), with accepted state `HeuristicallyTruncated`.

## Truncation error bound

Using finite-time $I(T)$ truncated at $T$ instead of $I_\infty$ leaves model truncation error

$$
R(T) = I_\infty - I(T) = \frac{e^{-aT}\left[a\cos(\omega T) - \omega\sin(\omega T)\right]}{a^2 + \omega^2}
$$

regardless of quadrature accuracy.
Cauchy–Schwarz $|a\cos\theta - \omega\sin\theta| \le \sqrt{a^2 + \omega^2}$ gives the phase-independent bound

$$
|R(T)| \le \frac{e^{-aT}}{\sqrt{a^2 + \omega^2}}
$$


Equality holds at suitable phases of $\omega T$, so the bound cannot be improved.
Tightening finite-interval quadrature below this error still leaves $I_\infty$ approximation limited by truncation.

The following block defines helpers shared by two cells.
`amplitude` is quadrature amplitude $e^{-at}$; `primitive` antiderivative $F$; `finite_integral` and `infinite_integral` correspond to $I(T)$ and $I_\infty$; `tail_bound` is the truncation bound.
Closed forms are independent checks using `f64` standard functions.

```rust
//| id: integrate-damped-oscillation-model
//| kind: definitions
//| title: "Damped amplitude and closed-form integrals"
//| crates: [scioxide-core]
use scioxide_core::{SciOxideError, RealScalar};

/// Quadrature amplitude g(t) = e^{−at}. The weight handles cos(ωt).
pub(crate) fn amplitude(decay_rate: f64, time: f64) -> Result<f64, SciOxideError> {
    Ok(RealScalar::exp(-decay_rate * time))
}

/// Antiderivative F(t) = e^{−at}(−a cos ωt + ω sin ωt)/(a² + ω²). Reference f64 standard functions.
pub(crate) fn primitive(a: f64, omega: f64, time: f64) -> f64 {
    let phase = omega * time;
    (-a * time).exp() * (-a * phase.cos() + omega * phase.sin()) / (a * a + omega * omega)
}

/// I(T) = F(T) − F(0).
pub(crate) fn finite_integral(a: f64, omega: f64, end: f64) -> f64 {
    primitive(a, omega, end) - primitive(a, omega, 0.0)
}

/// I∞ = a/(a² + ω²).
pub(crate) fn infinite_integral(a: f64, omega: f64) -> f64 {
    a / (a * a + omega * omega)
}

/// Truncation bound e^{−aT}/√(a² + ω²). Reference f64 standard functions.
pub(crate) fn tail_bound(a: f64, omega: f64, end: f64) -> f64 {
    (-a * end).exp() / (a * a + omega * omega).sqrt()
}
```

## Infinite integration and truncation error

Receiving $a$, $\omega$, and $\varepsilon$, the next cell integrates the tail from $T_0$ onward,

$$
\int_{T_0}^{\infty} f(t)\,dt = I_\infty - I(T_0) = R(T_0)
$$

with `FourierTailPlan`.
At $T_0 = 0$ this is $I_\infty$ itself; at $T_0 > 0$ it directly computes truncation error $R(T_0)$ from cutting off at $T_0$.
Choose $T_0$ as multiple $k_0$ of time constant $1/a$.
The first table compares quadrature with closed form $R(T_0)$ and shows estimates, evaluations, interval count, tail state, and status.
The plot shows $I(T)$ over $T \in [0, 8/a]$ with band $I_\infty \pm e^{-aT}/\sqrt{a^2 + \omega^2}$.
Dashed $I_\infty$ is the quadrature at $T_0 = 0$; a vertical line marks selected $T_0$.
At most 6000 plot points may not resolve every oscillation for many periods, but each is a value of $I(T)$ inside the band.
The second table compares actual truncation error $|R(T)|$ with the closed-form bound at $T = k/a$ ($k = 1, \ldots, 8$).
