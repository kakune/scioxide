Product reliability and structural safety-factor analyses often require the probability that performance combining many uncertain factors exceeds a criterion.
The integral's dimension equals the number of factors, so grid quadrature becomes impractical as its evaluation count grows exponentially with dimension.
This example uses Monte Carlo integration to estimate the probability that mean independent component performance exceeds a threshold, checking it against exact Irwin–Hall probabilities, standard errors, confidence intervals, and independent replicates.

## Exceedance probability as an indicator integral

Assume the performances $U_1, \ldots, U_d$ of $d$ components are independent and uniform on $[0, 1]$.
Performance is dimensionless, mapping its specification range to 0 through 1; probability is dimensionless as well.
Since the joint density is 1 on the unit hypercube, the probability that mean performance $\bar{U} = \frac{1}{d}\sum_j U_j$ reaches or exceeds threshold $q$ is the indicator integral

$$
p = \Pr(\bar{U} \ge q) = \int_{[0, 1]^d} \mathbf{1}\left\{\sum_{j=1}^{d} u_j \ge d q\right\} du_1 \cdots du_d
$$


The integrand jumps from 0 to 1 across the hyperplane $\sum_j u_j = dq$, making high-order rules that assume smoothness ineffective.

## Exact probability from the Irwin–Hall distribution

The sum $S_d = \sum_j U_j$ has the Irwin–Hall distribution; inclusion–exclusion gives its distribution function as

$$
F_d(s) = \Pr(S_d \le s) = \frac{1}{d!}\sum_{k=0}^{\lfloor s \rfloor} (-1)^k \binom{d}{k} (s - k)^d \qquad (0 \le s \le d)
$$


For $q > 1/2$, directly computing $1 - F_d(dq)$ loses digits by subtracting numbers close to 1.
Using the fact that $1 - U_j$ is also uniform on $[0, 1]$ gives

$$
p = \Pr\left(\sum_j U_j \ge dq\right) = \Pr\left(\sum_j (1 - U_j) \le d(1 - q)\right) = F_d\bigl(d(1 - q)\bigr)
$$

allowing direct evaluation of the lower-tail sum.
For $d \le 10$, binomial coefficients and factorials are exactly representable integers, and each summand requires only arithmetic.

## Monte Carlo estimator and standard error

The mean $\hat{p} = \frac{1}{N}\sum_i Y_i$ of indicator values $Y_i \in \{0, 1\}$ at $N$ uniform points $\boldsymbol{u}_i$ is an unbiased estimator of $p$, with

$$
\operatorname{SE}(\hat{p}) = \sqrt{\frac{p(1 - p)}{N}}, \qquad \frac{\operatorname{SE}(\hat{p})}{p} = \sqrt{\frac{1 - p}{Np}} \approx \frac{1}{\sqrt{Np}} \quad (p \ll 1)
$$


Here $Np$ is the expected count of event points among $N$ points; relative precision depends only on this count, not directly on dimension $d$.
However, as $d$ increases, the central limit theorem concentrates $\bar{U}$ around $1/2$ with variance $1/(12d)$, so $p$ for $q > 1/2$ decreases rapidly, reducing $Np$ even at fixed $N$.

`MonteCarloIntegrator` derives estimator variance $s^2/N$ from the observations' sample variance $s^2$.
`MonteCarloStatistics` returns this variance through `estimator_variance()`, takes its square root as standard error, and by default constructs a 95 % confidence interval using Student's t distribution with $N - 1$ degrees of freedom.
These are statistical statements assuming finite variance.
If no event is observed ($K = \sum_i Y_i = 0$), both estimate and sample variance are 0 and the interval has zero width.
This indicates insufficient samples for the event's rarity, rather than zero probability.
Then use binomial intervals or bounds such as $p \lesssim 3/N$ (the 95 % one-sided upper bound called the rule of three) or a Clopper–Pearson interval.

## Random streams and replicates

`RandomStreams::new(&root, stream)` draws uniform values from stream number `stream` of splittable generator `root`.
Samples are divided into blocks of 1024, and block $b$ draws from substream $(\text{stream}, b)$ of `root`, so results are independent of execution parallelism.
Setting `MonteCarloOptions::with_replicates(R)` computes $R$ independent replicates, each using $N$ points, in one call.
Replicates use nonoverlapping blocks, and workspace `children` returns each replicate's estimate and statistics based on its observations.
The overall estimate is the mean of $R$ estimates; overall `statistics` derives standard error from replicate variability (`VarianceBasis::Replicates`, $R - 1$ degrees of freedom).

The following block provides definitions shared by three cells.
`exceedance` gives exact probability $F_d(d(1 - q))$, and `estimate_exceedance` implements indicator integration with `MonteCarloIntegrator`.
Random seed, sample count, and replicate count are inputs to each cell.

```rust
//| id: integrate-reliability-model
//| kind: definitions
//| title: "Exact Irwin–Hall probabilities and Monte Carlo procedure"
//| crates: [scioxide-core, scioxide-integrate, scioxide-random]
use scioxide_core::{
    ExecutionContext, SciOxideError, Interval, RealScalar, checked_binomial, checked_factorial,
};
use scioxide_integrate::{
    IntegrationReport, MonteCarloIntegrator, MonteCarloOptions, MonteCarloWorkspace, RandomStreams,
};
use scioxide_random::Philox4x64;

/// p = Pr(Σ U_j ≥ dq) = F_d(d(1 − q)) (inclusion–exclusion, arithmetic only).
pub(crate) fn exceedance(d: usize, q: f64) -> Result<f64, SciOxideError> {
    let s = d as f64 * (1.0 - q);
    let mut sum = 0.0;
    for k in 0..=(RealScalar::floor(s) as usize).min(d) {
        let term = checked_binomial(d, k)? as f64 * RealScalar::powi(s - k as f64, d as i32);
        sum += if k % 2 == 0 { term } else { -term };
    }
    Ok(sum / checked_factorial(d)? as f64)
}

/// Integrate indicator 1{Σ u_j ≥ dq} over [0, 1]^d using stream 0 of root.
pub(crate) fn estimate_exceedance(
    d: usize,
    q: f64,
    options: MonteCarloOptions,
    root: &Philox4x64,
) -> Result<(f64, IntegrationReport<f64>, MonteCarloWorkspace<f64>), SciOxideError> {
    let bounds = vec![Interval::new(0.0, 1.0)?; d];
    let plan = MonteCarloIntegrator::new(&bounds, options)?;
    let mut workspace = plan.workspace(1, ExecutionContext::sequential())?;
    let threshold = d as f64 * q;
    let event = |u: &[f64]| {
        Ok(if u.iter().sum::<f64>() >= threshold {
            1.0
        } else {
            0.0
        })
    };
    let mut value = 0.0;
    let report = plan.integrate_into(
        &event,
        RandomStreams::new(root, 0),
        &mut value,
        &mut workspace,
        ExecutionContext::sequential(),
    )?;
    Ok((value, report, workspace))
}
```

## A single estimate and theory

The next cell selects component count $d$, sample count $N = 2^m$, threshold $q$, and random seed and estimates exceedance probability once.
The table gives estimate, exact value, reported and theoretical standard errors, 95 % confidence interval, standardized difference $z$ (the difference between estimate and exact value, divided by reported standard error), event count $K$, and expectation $Np$.
The outcome indicates whether events were observed and standard error could be defined.
The next cell receives $d$, $N$, and $q$.

At the defaults ($d = 6$, $N = 2^{13} = 8192$, $q = 0.7$, seed 42), the exact probability is $p = 0.04505$ and the observed event count is $K = 397$ (expectation $Np = 369.1$).
The estimate $\hat{p} = 0.04846$ has reported standard error $2.37 \times 10^{-3}$, close to theoretical value $2.29 \times 10^{-3}$.
The standardized difference is $z = 1.44$, or 1.4 standard errors; the 95 % interval $[0.0438, 0.0531]$ contains the exact value.
Seed 7 gives $\hat{p} = 0.04456$ and $z = -0.22$.
Estimates vary across seeds on the standard-error scale, and about one seed in 20 has $|z|$ above 2.

At $q = 0.86$ and $N = 2^8$, $Np = 0.12$, and this seed observes no events.
Estimate, standard error, and interval are all 0, and the outcome is failed.
The rule-of-three bound $3/N = 0.012$ includes exact value $4.9 \times 10^{-4}$ but is a coarse estimate.

## Independent replicates and interval coverage

Whether one estimate's interval contains the exact value depends on chance; repeated replicates check the meaning of the interval.
The next cell computes $R$ replicates in one call with the same $d$, $N$, and $q$.
The chart gives each replicate's estimate and observation-based 95 % interval as an error bar, with the exact value as a horizontal line and exact value $\pm 2$ theoretical standard errors as a band.
The table gives replicate mean and its replicate-based standard error, standardized mean-minus-exact difference $z$, replicate standard deviation and theoretical value $\sqrt{p(1 - p)/N}$, and the fraction of intervals containing the exact value (coverage).
Coverage itself varies with binomial standard error $\sqrt{0.95 \times 0.05/R}$.

At the defaults ($d = 6$, $N = 2^{11}$, $q = 0.68$, $R = 20$, seed 1), the exact value is $p = 0.06453$ and $Np = 132$.
The mean of 20 replicates is $0.06387$; with replicate-based standard error $1.01 \times 10^{-3}$, this gives $z = -0.65$.
Replicate standard deviation $4.5 \times 10^{-3}$ is 17 % below theoretical value $5.4 \times 10^{-3}$, comparable to the relative variability $1/\sqrt{2(R - 1)} \approx 0.16$ of a standard deviation estimated from 20 values.
Coverage is 1.0; its difference from nominal 0.95 is comparable to coverage standard error 0.049.
For $R = 40$, coverage is 0.95 and the mean's $z$ is $-1.31$.

Setting $q = 0.84$ gives $Np \approx 2.2$, and 3 of the 20 replicates observe no events.
Their intervals are the zero-width $[0, 0]$ and exclude the exact value.
Coverage is 0.85, about two coverage standard errors below nominal 0.95.
For few events, the normal approximation behind observation-variance intervals breaks down, and they no longer contain the exact value at the nominal frequency.
For rare events, use binomial intervals or importance sampling that concentrates points where events are likely ([adaptive Monte Carlo: VEGAS and MISER](../../algorithms/adaptive-monte-carlo/)).

## Summary

Mean-performance exceedance probability is an indicator integral over the unit hypercube and can be checked against exact Irwin–Hall probabilities.
The Monte Carlo estimator's standard error is $\sqrt{p(1 - p)/N}$; relative precision depends on expected event count $Np$.
Read the estimate-minus-exact difference through $z$, standardized by reported standard error, and check interval meaning through coverage across independent replicates made with `with_replicates`.
If no events are observed, standard error and interval are both 0; treat this as failure and switch to binomial upper bounds, more samples, or importance sampling.
Fix the seed as an input and interpret statistical variability together with results from other seeds.
