Integration difficulty depends less on integrand magnitude than on concentration in narrow regions, cancellation, endpoint singularities, structures not aligned with axes, and high dimension.
Each example applies SciOxide quadrature to a concrete problem and independently checks its result using a closed form, known value, separate method, or accuracy refinement.
Derivations of the methods and small experiments appear in [numerical integration mathematics and algorithms](../algorithms/).

## Checks before using a result

Before using quadrature results for design or decisions, check the following in order.

1. Read the termination.
   `IntegrationTermination::is_success` is true for `FixedRuleCompleted`, `ToleranceReached`, `HeuristicToleranceReached`, `SampleBudgetCompleted`, and `DegenerateDomain`, indicating that computation finished as configured.
   `FixedRuleCompleted` means only that summation over the prescribed nodes finished; it makes no accuracy claim.
   `ToleranceReached` means that an error estimate from the difference between two rules meets the tolerance; `HeuristicToleranceReached` means that a heuristic estimate, such as one based on observed decay, meets it.
   Neither proves that no narrow structure is hidden between nodes.
   `BudgetLimit(Evaluation)`, `BudgetLimit(Subdivision)`, `RefinementLimit`, `Stagnation`, and similar terminations do not indicate success.
   Treat the returned value as an estimate and consider a larger limit, prior subdivision, or a change of variables.
2. Choose an error criterion.
   When the integral is near 0, as in oscillatory integrals with strong cancellation, relative tolerance $\varepsilon_{\mathrm{rel}}|Q|$ is ineffective; set a physically meaningful absolute tolerance $\varepsilon_{\mathrm{abs}}$.
   Conversely, if $\varepsilon_{\mathrm{abs}}$ is comparable to or greater than the integral, the tolerance may be met with almost no resolution of the integral.
3. Separate model truncation from numerical error.
   When truncating an infinite interval to a finite one, estimate the model's truncation error separately from finite-interval quadrature error.
4. Check independently.
   Check the value using a change of variables, another method, closed or asymptotic forms, or comparisons across node or sample counts.
   For statistical estimates, use repeated seeds or independent replicates to check standard errors and interval meaning.
   If a guaranteed enclosure is required, use validated quadrature in `scioxide-validated`.
