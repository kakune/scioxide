Probability densities of quantum harmonic oscillator eigenstates contain Gaussian factor $e^{-\xi^2}$.
Position moments are integrals of polynomials times this weight, so Gauss–Hermite with weight $e^{-\xi^2}$ obtains exact values from finitely many nodes.
Derive the required node count and check with `GaussianRulePlan`.
For nonpolynomial $\langle\cos q\xi\rangle$, examine rapid error decay with node count and compare DE evaluation counts for the same integral.
Finally compute first-order energy shifts from quartic anharmonicity.

[Gauss nodes and Hermite polynomial zeros](../../../scioxide-poly/examples/gauss-nodes-as-zeros/) covers the zeros used as nodes and their computation.

## Eigenstates and closed-form expectations

For mass $m$ and angular frequency $\omega$, use length unit $\sqrt{\hbar/(m\omega)}$ and dimensionless position $\xi = x/\sqrt{\hbar/(m\omega)}$.
Hamiltonian $H_0 = \hbar\omega\,(-\tfrac12\,d^2/d\xi^2 + \tfrac12\xi^2)$ has levels $E_n^{(0)} = \hbar\omega\,(n + \tfrac12)$ and normalized eigenfunctions

$$
\psi_n(\xi) = \bigl(2^n n!\sqrt\pi\bigr)^{-1/2} H_n(\xi)\,e^{-\xi^2/2}
$$


$H_n$ is the physicists' Hermite polynomial ($H_0 = 1$, $H_1 = 2\xi$).
Energies below use units $\hbar\omega$.

Ladder operators give closed forms for expectations $\langle A\rangle_n = \int A(\xi)\,\psi_n(\xi)^2\,d\xi$.
Annihilation $a$ and creation $a^\dagger$ satisfy $a\,|n\rangle = \sqrt n\,|n - 1\rangle$ and $a^\dagger|n\rangle = \sqrt{n + 1}\,|n + 1\rangle$, with position $\xi = (a + a^\dagger)/\sqrt2$.
Expand $\xi^k|n\rangle$ in basis $|m\rangle$ and sum squared coefficients to obtain $\langle\xi^{2k}\rangle_n = \lVert\xi^k|n\rangle\rVert^2$, giving

$$
\langle\xi^2\rangle_n = n + \tfrac12, \qquad \langle\xi^4\rangle_n = \tfrac34\,(2n^2 + 2n + 1)
$$


$\langle\xi^2\rangle_n = n + \tfrac12$ also agrees with the virial theorem: mean potential energy is half the total.

Since $e^{iq\xi}$ is displacement operator $D(\alpha)$ ($\alpha = iq/\sqrt2$), the position-cosine expectation is

$$
\langle\cos q\xi\rangle_n = e^{-q^2/4}\,L_n\!\left(\frac{q^2}{2}\right)
$$


Here $L_n$ is the Laguerre polynomial and $q$ is a dimensionless wavenumber.
This amplitude describes state-preserving processes in momentum-transfer scattering or light absorption; its thermal average gives the Debye–Waller factor.

## Node count for exact Gauss–Hermite integration

Write $h_n(\xi) = (2^n n!\sqrt\pi)^{-1/2}H_n(\xi)$; since $\psi_n^2 = h_n^2\,e^{-\xi^2}$,

$$
\langle\xi^{2k}\rangle_n = \int_{-\infty}^{\infty} h_n(\xi)^2\,\xi^{2k}\,e^{-\xi^2}\,d\xi
$$


Putting weight $e^{-\xi^2}$ into the rule leaves callback polynomial $f(\xi) = h_n(\xi)^2\xi^{2k}$ of degree $2n + 2k$.
An $N$-node Gauss rule is exact through degree $2N - 1$ ([Gaussian quadrature and Clenshaw–Curtis rules](../../algorithms/gaussian-and-clenshaw-curtis/)).
Thus when

$$
2n + 2k \le 2N - 1 \iff N \ge n + k + 1
$$

holds, quadrature is exact apart from rounding.

One node earlier, $N = n + k$, polynomial $f$ has degree exactly $2N$.
Let $\pi_N = 2^{-N}H_N$ be monic Hermite of degree $N$.
Dividing degree-$2N$ polynomial $f$ by $\pi_N^2$ gives constant quotient $c$ and remainder of degree at most $2N - 1$, with $f = c\,\pi_N^2 + (\text{degree } 2N - 1 \text{ or less})$.
$c$ is leading coefficient $2^n/(n!\sqrt\pi)$ of $f$.
At nodes, $\pi_N = 0$, so term $c\,\pi_N^2$ contributes nothing to the quadrature value and the error is exactly

$$
\langle\xi^{2k}\rangle_n - Q_N = c\int \pi_N^2\,e^{-\xi^2}\,d\xi = \frac{2^n}{n!\sqrt\pi}\cdot\frac{\sqrt\pi\,N!}{2^N} = \frac{(n + k)!}{n!\,2^k}
$$


Positive error means quadrature underestimates the true value.
For $n = 4$ and $k = 2$, for example, $\langle\xi^4\rangle_4 = 30.75$ versus $N = 6$ quadrature value $30.75 - 7.5 = 23.25$.
Adding just one node drops this error to rounding level.

$\cos q\xi$ is not polynomial, so no finite node count integrates $h_n^2\cos q\xi$ exactly.
But $\cos q\xi$ is entire, giving faster-than-any-power decay in node count (spectral convergence).
Error decreases only once $h_n^2\cos q\xi$ can be well approximated by degree-$2N - 1$ polynomials; until then it fluctuates around $10^{-2}$ to $10^{-1}$.
This node count increases with both degree $2n$ of $h_n^2$ and oscillation rate $q$ of $\cos q\xi$.

## Recurrence for normalized Hermite polynomials

Forming $h_n$ from $H_n$ by multiplying by $(2^n n!\sqrt\pi)^{-1/2}$ causes intermediate values to fall outside the double-precision range for large $n$.
For example, $2^n n!$ exceeds the double-precision maximum (about $1.8\times10^{308}$) at $n = 151$.
scioxide-poly's `OrthogonalFamily::HermiteH.evaluate(n, ξ)` avoids intermediate overflow and returns $H_n(\xi)$ itself, but an unrepresentable final value gives `NumericalInstability` ([Theory and numerical computation of orthogonal polynomial families](../../../scioxide-poly/algorithms/orthogonal-families/)).
Instead, use the normalized three-term recurrence

$$
h_0 = \pi^{-1/4}, \quad h_1 = \sqrt2\,\xi\,h_0, \quad
h_{j+1} = \sqrt{\frac{2}{j + 1}}\;\xi\,h_j - \sqrt{\frac{j}{j + 1}}\;h_{j-1}
$$


Changing the initial value to $\pi^{-1/4}e^{-\xi^2/2}$ makes the same recurrence directly produce eigenfunction $\psi_j(\xi)$.
Use this for quadrature without built-in weights (DE).

The next definitions are shared by two cells.
`hermite_recurrence(n, ξ, start)` implements the recurrence: `start` equal to $h_0$ gives $h_n(\xi)$, while $\psi_0(\xi)$ gives $\psi_n(\xi)$.
`ladder_state(n, k)` computes expansion coefficients of $\xi^k|n\rangle$ using only ladder rules; `ladder_moment(n, k)` returns the sum of their squares $\langle\xi^{2k}\rangle_n$.
Both cells use these as independent references.

```rust
//| id: integrate-oscillator-model
//| kind: definitions
//| title: "Normalized Hermite recurrence and ladder-operator references"
//| crates: [scioxide-core]
use scioxide_core::RealScalar;

/// Advance h_{j+1} = √(2/(j+1)) ξ h_j − √(j/(j+1)) h_{j−1} from start = h_0 for n steps.
pub(crate) fn hermite_recurrence(n: usize, xi: f64, start: f64) -> f64 {
    let (mut previous, mut current) = (0.0, start);
    for j in 0..n {
        let next = RealScalar::sqrt(2.0 / (j + 1) as f64) * xi * current
            - RealScalar::sqrt(j as f64 / (j + 1) as f64) * previous;
        previous = current;
        current = next;
    }
    current
}

/// Expansion of ξ^k |n⟩. Apply ξ|m⟩ = (√m |m−1⟩ + √(m+1) |m+1⟩)/√2 k times.
pub(crate) fn ladder_state(n: usize, k: usize) -> Vec<f64> {
    let mut state = vec![0.0; n + k + 1];
    state[n] = 1.0;
    let half = RealScalar::sqrt(0.5_f64);
    for _ in 0..k {
        let mut next = vec![0.0; n + k + 1];
        for (m, &c) in state.iter().enumerate().filter(|(_, c)| **c != 0.0) {
            // Nonzero coefficient indices are at most n + k − 1, so m + 1 is in range.
            if m > 0 {
                next[m - 1] += c * RealScalar::sqrt(m as f64) * half;
            }
            next[m + 1] += c * RealScalar::sqrt((m + 1) as f64) * half;
        }
        state = next;
    }
    state
}

/// ⟨ξ^{2k}⟩_n = ‖ξ^k |n⟩‖².
pub(crate) fn ladder_moment(n: usize, k: usize) -> f64 {
    ladder_state(n, k).iter().map(|c| c * c).sum()
}
```

## Node counts and errors

Select quantum number $n$, moment order $k$, and wavenumber $q$; compute $\langle\xi^{2k}\rangle_n$ and $\langle\cos q\xi\rangle_n$ with Gauss–Hermite node counts $N = 1, 2, \dots, 40$.
Pass both integrands together as two-component `[h_n² ξ^{2k}, h_n² cos qξ]` and apply over the real line with `GaussianSupport::RealLine`.
The returned value for each component is $\int f_i(\xi)\,e^{-\xi^2}\,d\xi$.
References are ladder result $\langle\xi^{2k}\rangle_n$ and $e^{-q^2/4}L_n(q^2/2)$ computed with scioxide-poly `OrthogonalFamily::Laguerre.evaluate`.

Plot relative error of $\langle\xi^{2k}\rangle_n$ and absolute error of $\langle\cos q\xi\rangle_n$ logarithmically against node count.
A vertical line marks $N = n + k + 1$.
The table compares the reference with results just before exactness, $N = n + k$, at exactness, $N = n + k + 1$, and at maximum count $N = 40$.
The $N = n + k$ row converts deficit $(n + k)!/(n!\,2^k)$ derived above to relative error.
Pass inputs and error curves to the next cell.

Defaults ($n = 4$, $k = 2$, $q = 3$) give quadrature 23.25 at $N = 6$; relative error 0.244 equals theoretical deficit $7.5/30.75$.
At $N = 7$, relative error falls to about $10^{-15}$ and stays at rounding level with more nodes.
The $\langle\xi^{2k}\rangle$ symbols dropping over ten orders at vertical $N = 7$ show degree-of-exactness effects.
Absolute error of $\langle\cos 3\xi\rangle_4$ fluctuates between $0.009$ and $0.37$ through $N = 11$, then drops about one order per added node to rounding level near $N = 25$.

For `high-level` ($n = 15$, $k = 1$), $N = 16$ gives 7.5; its deficit 8 from $\langle\xi^2\rangle_{15} = 15.5$ matches $(n + k)!/(n!\,2^k) = 16/2$.
At $N = 17$, relative error is about $10^{-14}$.
Larger $n$ delays decay of $\langle\cos q\xi\rangle$ error, which remains above $10^{-2}$ until around $N = 27$ even for $q = 3$.
For `short-wave` ($q = 8$), even $N = 40$ retains error around $4\times10^{-8}$.
For non-exact integrands, estimate errors by changing nodes or comparing independent methods.

At $k = 0$, quadrature in row $N = n$ is 0 (rounding level), not normalization $\langle 1\rangle_n = 1$.
Its $n$ nodes are zeros of $H_n$, so $h_n^2 = 0$ at every node.
The deficit formula also gives $(n + 0)!/(n!\,2^0) = 1$, matching relative error 1.

## Evaluation counts versus DE

An approach that does not incorporate the weight into the rule is the real-line DE map $\xi = \sinh(\tfrac{\pi}{2}\sinh t)$ (sinh–sinh).
Passing `DoubleExponentialDomain::RealLine` to `DoubleExponentialIntegrator` integrates the full integrand including $\psi_n(\xi)^2$ by trapezoidal sums, estimating error from step-halved differences $|Q_h - Q_{2h}|$ and tail-truncation estimates ([Double-exponential transformations for improper integrals and endpoint singularities](../../algorithms/improper-singular-and-oscillatory/)).
Observed-decay estimates give `HeuristicToleranceReached` even on convergence.

Receiving $n$, $k$, and $q$, the next cell varies equal absolute/relative tolerances from $10^{-4}$ to $10^{-14}$ and integrates the same two components by DE.
Use the $\psi_n$ recurrence, returning 0 when distant $\psi_0 = \pi^{-1/4}e^{-\xi^2/2}$ underflows to 0.
Overlay evaluation-count/error curves with Gauss–Hermite on the same logarithmic axes.

//| ref: integrate-oscillator-double-exponential
//| title: "Compute the same expectations by DE and compare evaluations and errors"

//| uses: [integrate-oscillator-model]
//| crates: [scioxide-core, scioxide-integrate, scioxide-poly]

//|   solve: integrate-oscillator-hermite-exactness

//|   - case: default
//|     expect:
//|       - {"artifact":"tolerances","path":"/rows/4/2","range":{"min":0,"max":1e-12}}
//|       - {"artifact":"tolerances","path":"/rows/4/3","range":{"min":0,"max":1e-12}}
//|       - {"artifact":"tolerances","path":"/rows/4/5","equals":"HeuristicToleranceReached"}
use scioxide_core::{ErrorTolerance, NormSelection, RealScalar};
use scioxide_integrate::{
    DoubleExponentialDomain, DoubleExponentialIntegrator, DoubleExponentialPoint, LevelOptions,
};
use scioxide_poly::OrthogonalFamily;

let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });

    read("level")? as usize,
    read("power")? as usize,
    read("wavenumber")?,
);
let curve = |name: &str| -> Result<Vec<[f64; 2]>, String> {
    serde_json::from_value(solve[name].clone()).map_err(|e| e.to_string())
};
let moment = ladder_moment(n, k);
let laguerre = OrthogonalFamily::Laguerre
    .evaluate(n, q * q / 2.0)
    .map_err(|e| e.to_string())?;
let cosine = RealScalar::exp(-q * q / 4.0) * laguerre;
let h0 = 1.0 / RealScalar::sqrt(RealScalar::sqrt(<f64 as RealScalar>::PI));
// Full weighted integrands [ψ_n² ξ^{2k}, ψ_n² cos qξ].
let state = |point: DoubleExponentialPoint<f64>| {
    let xi = point.coordinate();
    let psi = hermite_recurrence(n, xi, h0 * RealScalar::exp(-xi * xi / 2.0));
    // If distant ψ_0 underflows to 0, return integrand 0 to avoid overflow in ξ^{2k}.
    if psi == 0.0 {
        return Ok([0.0; 2]);
    }
    Ok([
        psi * psi * RealScalar::powi(xi, 2 * k as i32),
        psi * psi * RealScalar::cos(q * xi),
    ])
};

        .map_err(|e| e.to_string())?;
    let options = LevelOptions::default().with_tolerance(tolerance);
    let de = DoubleExponentialIntegrator::new(DoubleExponentialDomain::RealLine, options)
        .map_err(|e| e.to_string())?;
    let (value, report): ([f64; 2], _) = de.integrate(&state).map_err(|e| e.to_string())?;
    let evaluations = report.evaluations() as f64;
    let errors = [
        (value[0] - moment).abs() / moment,
        (value[1] - cosine).abs(),
    ];
    // Omit zero-error points from logarithmic plots but retain table rows.
    if errors[0] > 0.0 {
        moment_points.push([evaluations, errors[0]]);
    }
    if errors[1] > 0.0 {
        cosine_points.push([evaluations, errors[1]]);
    }
    let status = report.termination().to_string();
    rows.push((
        exponent,
        report.evaluations(),
        errors[0],
        errors[1],
        report.error_estimate(),
        status,
    ));
}

Defaults ($n = 4$, $k = 2$, $q = 3$) give errors at most $2\times10^{-13}$ for both components in only 131 evaluations at tolerance $10^{-4}$.
Estimate $6\times10^{-5}$ is 8 orders larger than actual errors.
DE estimates use changes from the previous level; faster convergence therefore returns the error of a coarser preceding sum.
Tolerances $10^{-6}$ through $10^{-12}$ stop in 259 evaluations with exactly zero $\langle\xi^{2k}\rangle$ error (not plotted logarithmically, retained in the table).
Requesting $10^{-14}$ gives `Stagnation` after 515 evaluations.
The rounding floor of the error estimate, $50\varepsilon A$ ($A$ sums $|f|$, here about 30.75), is $3.4\times10^{-13}$, above request $10^{-14}(1 + |Q|) \approx 3.2\times10^{-13}$.
This is unsuccessful, but returned values have the same accuracy as the preceding level.

Gauss–Hermite attains that accuracy with $n + k + 1 = 7$ evaluations for $\langle\xi^{2k}\rangle$ and about 25 for $\langle\cos 3\xi\rangle$.
With known weight $e^{-\xi^2}$ and polynomial or entire remainder, weighted rules use fewer evaluations: about one twentieth for moments (7 versus 131) and one fifth for $\langle\cos 3\xi\rangle$ (about 25 versus 131).
DE, however, returns error estimates and works without knowing the weight form.
Choose according to integrand knowledge or use DE to check Gauss–Hermite independently.

## Level shifts from quartic anharmonicity

Real molecular potentials depart from parabolic shapes.
Consider a Hamiltonian with a quartic term in dimensionless position,

$$
H = H_0 + \lambda\,\hbar\omega\,\xi^4
$$

where $\lambda$ is dimensionless coupling.
First-order Rayleigh–Schrödinger level shifts equal the perturbation expectation,

$$
E_n^{(1)} = \lambda\,\langle\xi^4\rangle_n = \tfrac34\,\lambda\,(2n^2 + 2n + 1)
$$

in units $\hbar\omega$.
The second-order correction comes from matrix elements $c_m = \langle m|\xi^4|n\rangle$ of $\xi^4$ connecting $|n\rangle$ to $|n \pm 2\rangle$ and $|n \pm 4\rangle$,

$$
E_n^{(2)} = \sum_{m \ne n} \frac{\lambda^2 c_m^2}{E_n^{(0)} - E_m^{(0)}} = -\lambda^2\sum_{m \ne n}\frac{c_m^2}{m - n} = -\frac{\lambda^2}{8}\,(34n^3 + 51n^2 + 59n + 21)
$$


First-order corrections grow as $n^2$ and second-order corrections as $n^3$, so ratio $|E_n^{(2)}/E_n^{(1)}|$ grows roughly proportionally to $\lambda n$.
Where this ratio nears 1, the first few perturbation terms no longer describe levels.

For $n = 0, 1, \dots, n_{\max}$, compute $\langle\xi^2\rangle_n$ and $\langle\xi^4\rangle_n$ with $N = n + 3$ Gauss–Hermite nodes.
Integrand $h_n^2\xi^4$ has degree $2n + 4$, so $N = n + 3$ is the minimum node count satisfying $N \ge n + k + 1$ exactly.
Check quadrature against closed forms $n + \tfrac12$ and $\tfrac34(2n^2 + 2n + 1)$.
Form $c_m$ with `ladder_state(n, 4)` from the definitions block and compute the second-order correction directly from the sum above.
Plot unperturbed levels and levels through first and second order against $n$, and tabulate their values and ratio $|E^{(2)}/E^{(1)}|$.

## Summary

Eigenstate expectation $\langle\xi^{2k}\rangle_n$ becomes a degree-$2n + 2k$ polynomial integral after removing weight $e^{-\xi^2}$.
Pass `OrthogonalFamily::HermiteH` to `GaussianRulePlan` and call `integrate_weighted` with `GaussianSupport::RealLine` for rounding-level accuracy at $N \ge n + k + 1$ nodes; $N = n + k$ underestimates by deficit $(n + k)!/(n!\,2^k)$.
Gauss status `FixedRuleCompleted` claims no accuracy; for quantities such as $\langle\cos q\xi\rangle$ whose integrands are not covered by polynomial exactness, check errors using differences with added nodes, closed forms, or DE comparisons.
Compute the integrand's $h_n$ factor with the normalized three-term recurrence to avoid large intermediates such as $2^n n!$.
First-order anharmonic correction is $\lambda\langle\xi^4\rangle_n$; perturbation truncation fails as ratio $|E^{(2)}/E^{(1)}|$ approaches 1.
