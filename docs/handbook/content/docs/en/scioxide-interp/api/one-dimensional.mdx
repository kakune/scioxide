This table covers univariate interpolants and their antiderivative preparation.
Four groups are global polynomials (barycentric, Newton, Hermite, Neville), diagonal rational Bulirsch–Stoer, piecewise cubics (Akima, PCHIP, cubic splines), and B-splines.
Floater–Hormann appears in [Rational interpolation APIs](../rational/).

Node-taking methods use standard `new(x, y)` with rustdoc defaults.
Hermite also takes derivative samples `dy`.
Nodes must be finite and strictly increasing; to reject near-duplicates too, pass `SampleOptions` (`Exact` or tolerance-based `Tolerant` in `NodeSeparation`) to detailed `with_options`.
Named constructors choose other preparation kinds.
`CubicSpline::with_boundary` accepts `SplineBoundary`; `AkimaInterpolator::with_method` accepts `AkimaMethod`; barycentric `from_equispaced`, `from_chebyshev_roots`, and `from_chebyshev_lobatto` generate node families from values and interval endpoints.
Values are same-shaped affine real, complex, array, or vector values, with identical scalar computations per real component.
Vector outputs therefore match componentwise scalar interpolation.
B-splines use knots `BSplineBasis` and control values instead of nodes; sample-through piecewise lines use `BSpline::linear`.

Evaluate through shared traits with points `[x]` and per-call extrapolation policies.
Inside domains, every interpolant supports scalar `value_at(x)` and `values_at(xs)` of `Univariate`, plus `derivative_at(x)` and `integrate(a, b)` according to traits.
Barycentric, Newton, and Hermite implement `Interpolant` and `Differentiable`; integrate with `PreparedPolynomialAntiderivative` returned by `prepare_antiderivative`.
Akima, PCHIP, and cubic splines implement `Interpolant`, `Differentiable`, and `Integrable`; B-splines additionally `TwiceDifferentiable`.
Neville and Bulirsch–Stoer provide values only.
For repeated cubic or univariate B-spline integrals, construct `PreparedSplineAntiderivative` through `prepare_antiderivative`.

Construction failures return `Err`.
Empty, insufficient, or nonincreasing nodes give `InvalidInput`; node/value length or shape mismatches `DimensionMismatch`; nonfinite inputs `NonFinite`.
`*_into` forms such as `evaluate_into` use workspace from interpolant `workspace()` without allocation.
Failed calls leave output unchanged.
Owned `evaluate`, `gradient`, `evaluate_many` and scalar forms may allocate output or workspace.
Success guarantees no accuracy; Neville corrections remain estimates.

## Summary

For few samples of smooth functions, use global polynomials; Chebyshev nodes allow barycentric `from_chebyshev_lobatto` and similar construction in $O(n)$.
For one value with an error guideline, use Neville `evaluate_with_error` and interpret corrections as estimates.
Choose PCHIP for monotonicity, Akima/Makima for local secants without monotonicity guarantees, cubic splines for $C^2$, or B-splines for knot-controlled continuity.
For second derivatives choose B-splines implementing `TwiceDifferentiable`; prepare antiderivatives once through `prepare_antiderivative` for repeated integrals.
