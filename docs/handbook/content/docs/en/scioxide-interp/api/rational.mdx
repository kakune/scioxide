This table covers rational interpolation and approximation.
There are three entry points.
AAA and AAA–Lawson fit samples through `aaa`, `aaa_with_options`, and `aaa_into`; Floater–Hormann `FloaterHormannInterpolator` interpolates real nodes without real poles; Padé `PadeApproximant` uses Taylor coefficients.

AAA fits and doublet removal return barycentric `BarycentricRational` in form $r(z) = \sum_j a_j/(z - z_j) \big/ \sum_j b_j/(z - z_j)$.
Lawson independently updates numerator $a_j$ and denominator $b_j$, so results need not interpolate support samples.
Floater–Hormann is a separate real-node affine-value type using the same evaluation arithmetic as barycentric polynomials.
Padé stores numerator and denominator polynomials around an expansion center.
AAA, `BarycentricRational`, and `PadeApproximant` use field arithmetic, so values are real or complex `NumericScalar` and closed approximation domains explicit through `RationalDomain`.
Evaluate through `Interpolant` with real points `[x]` or complex points `[re, im]`; real approximation domains also have univariate scalar `value_at(x)`.
All methods here provide values only, without gradient traits.

AAA has no precomputed Plan.
One-shot `aaa(nodes, values)` uses defaults and gives `ConvergenceFailure` if thresholds are unmet.
Detailed `aaa_with_options(nodes, values, domain, options)` returns owned `RationalFit`; borrowed `aaa_into` writes `RationalFit` and `RationalWorkspace` reserved according to `RationalRequest`.
Both return accepted approximations in `Ok` even after support, iteration, or work limits.
Read status through `termination()` of `RationalFit::report()` and count only `Converged` as success.
Sample residuals measure given samples, not guaranteed intersample errors.
Rationals may have poles; pole evaluations give `NumericalInstability` (`Breakdown`) for `BarycentricRational` or `DomainError` for Padé.
Estimate poles, zeros, and residues separately through `BarycentricRational::diagnostics` and interpret them as estimates.

## Summary

Use `aaa` for default sample fitting, `aaa_with_options` for limits, tolerances, or Lawson; for repeated equal-sized allocation-free fits reserve with `RationalRequest` and use `aaa_into`.
In detailed results, check `termination()` of `RationalFit::report()` equals `Converged` and inspect maximum sample residual `max_residual()`.
`SupportLimit` and `BudgetExhausted` still return approximations; decide use from residuals.
Returned `BarycentricRational` may have poles; estimate poles, residues, and doublets with `diagnostics`, comparing residuals before and after `cleanup_doublets` before accepting new representations.
Use Floater–Hormann for real-axis-pole-free interpolation or Padé for Taylor data, checking `coefficient_residual` and `denominator_rank` for Padé.
