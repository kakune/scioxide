[Reconstructing a regular-grid temperature field with bilinear and bicubic interpolation](../bicubic-temperature-field/) compared error magnitudes and distributions on a fixed grid.
This page measures how errors decrease as the grid is refined and compares them with theoretical convergence orders.
The temperature field is defined on the same unit square $[0,1]^2$ [m] by

$$
T(x, y) = 20 + A \sin(m \pi x) \cos(m \pi y) + 0.8 x y\quad[{}^\circ\mathrm C]
$$

where $A=4$ °C and $m$ is the number of half-wavelengths along each axis.
Its gradient is

$$
\frac{\partial T}{\partial x} = A m \pi \cos(m \pi x) \cos(m \pi y) + 0.8 y, \qquad \frac{\partial T}{\partial y} = -A m \pi \sin(m \pi x) \sin(m \pi y) + 0.8 x\quad[{}^\circ\mathrm C/\mathrm m]
$$


## Theoretical convergence orders

The bilinear value error is $O(h^2)$ in grid spacing $h$.
This follows by adding the linear-interpolation errors $\tfrac12 s(1-s)h^2 T_{xx}$ along the two axes.

Given grid-point values and exact derivatives, bicubic Hermite interpolation has value error $O(h^4)$ and gradient error $O(h^3)$.
`BicubicInterpolator::new` estimates derivatives with a quadratic through three nodes, with error $O(h^2)$ (a centered difference with $h^2T_{xxx}/6$ at equally spaced interior nodes).
The error in the local-coordinate slope $hT_x$ is $O(h^3)$, adding an $h^3$ term to the value error inside a cell.
In one dimension, if the slope errors $e$ at both ends are nearly equal, this term is

$$
h\,e\,t(1-t)(1-2t),\qquad t=\frac{x-x_i}{h}\in[0,1]
$$

where the maximum of $|t(1-t)(1-2t)|$ is about 0.096.
The expected value error is therefore $O(h^3)$, and the expected gradient error is $O(h^2)$.
Inside an equally spaced grid, this construction equals the tensor product of Keys's (1981) cubic convolution interpolation ($a=-1/2$); Keys also shows that the value error is $O(h^3)$.
The coefficient of the $h^3$ term is proportional to $T_{xxx}$, while that of the exact Hermite interpolation's $h^4$ term is proportional to $T_{xxxx}$, so their ratio is approximately proportional to $m\pi h$.
On coarse grids, the $h^4$ term contributes more, and observed orders can lie between 3 and 4.

The following block defines quantities shared by the two cells on this page.
`temperature` and `temperature_gradient` define the analytic field $T$ and $\nabla T$; `grid_models` constructs the two interpolants from values on an equally spaced $n\times n$ grid, and `validation_points` supplies validation points.
The analytic field's sine and cosine are computed with `RealScalar::sin` and `RealScalar::cos`.

```rust
//| id: interp-bicubic-convergence-model
//| kind: definitions
//| title: "Analytic temperature field and two grid interpolants"
//| crates: [scioxide-core, scioxide-interp]
use scioxide_core::{SciOxideError, RealScalar};
use scioxide_interp::{BicubicInterpolator, BilinearInterpolator};

/// Oscillation amplitude A [°C].
pub(crate) const AMPLITUDE: f64 = 4.0;

/// T(x, y) = 20 + A sin(mπx) cos(mπy) + 0.8xy [°C].
pub(crate) fn temperature(m: f64, x: f64, y: f64) -> f64 {
    let w = m * std::f64::consts::PI;
    20.0 + AMPLITUDE * RealScalar::sin(w * x) * RealScalar::cos(w * y) + 0.8 * x * y
}

/// ∇T = (∂T/∂x, ∂T/∂y) [°C/m].
pub(crate) fn temperature_gradient(m: f64, x: f64, y: f64) -> [f64; 2] {
    let w = m * std::f64::consts::PI;
    [
        AMPLITUDE * w * RealScalar::cos(w * x) * RealScalar::cos(w * y) + 0.8 * y,
        -AMPLITUDE * w * RealScalar::sin(w * x) * RealScalar::sin(w * y) + 0.8 * x,
    ]
}

/// Two interpolants from values on an equally spaced grid with n points per axis (row-major z[j·n + i] = T(x_i, y_j)).
pub(crate) fn grid_models(
    n: usize,
    m: f64,
) -> Result<(BilinearInterpolator<f64>, BicubicInterpolator<f64>), SciOxideError> {
    let nodes: Vec<f64> = (0..n).map(|i| i as f64 / (n - 1) as f64).collect();
    let values: Vec<f64> = nodes
        .iter()
        .flat_map(|&y| nodes.iter().map(move |&x| temperature(m, x, y)))
        .collect();
    let bilinear = BilinearInterpolator::new(nodes.clone(), nodes.clone(), values.clone())?;
    let bicubic = BicubicInterpolator::new(nodes.clone(), nodes, values)?;
    Ok((bilinear, bicubic))
}

/// Radical-inverse function in base base (the kth point of the van der Corput sequence).
fn radical_inverse(mut k: usize, base: usize) -> f64 {
    let (mut value, mut scale) = (0.0, 1.0 / base as f64);
    while k > 0 {
        value += (k % base) as f64 * scale;
        k /= base;
        scale /= base as f64;
    }
    value
}

/// Validation points: 2000 [x, y] points of the Halton sequence in bases 2 and 3.
pub(crate) fn validation_points() -> Vec<[f64; 2]> {
    (1..=2000)
        .map(|k| [radical_inverse(k, 2), radical_inverse(k, 3)])
        .collect()
}
```

## Convergence of value errors

A comparison on a fixed grid alone does not show how errors decrease as the grid is refined.
The next cell fixes $m$, varies the node count per axis from 4 to 55, and measures the value RMSE at validation points as a function of grid spacing $h = 1/(n-1)$ [m].
Validation uses 2000 points of the Halton sequence in bases 2 and 3 (a low-discrepancy sequence).
With an equally spaced validation grid, some ratios between its spacing and the interpolation grid spacing sample only limited positions within each cell, biasing the RMSE estimate differently for each grid.
The $h^3$ error has the form $t(1-t)(1-2t)$, changing sign with the position $t$ inside a cell, so this bias can strongly disrupt observed orders.
The Halton sequence covers positions within cells uniformly, avoiding this bias.
The cell also measures bicubic gradient errors on the same grid and passes them to the next cell.
The table's observed order is $\log(e_1/e_2)/\log(h_1/h_2)$ between adjacent rows.
It also checks reproduction of the supplied grid-point values through the maximum difference at grid points.
The plot uses logarithmic scales on both axes: points show observed RMSE, while dashed lines have slopes of order 2 and 3 through the finest grid.

```rust
//| id: interp-bicubic-value-convergence
//| ref: interp-bicubic-value-convergence
//| title: "Measure the convergence order of value errors as the grid is refined"
//| run: reactive
//| uses: [interp-bicubic-convergence-model]
//| crates: [scioxide-core, scioxide-interp]
//| exports: [spatial_cycles, refinement]
//| inputs:
//|   spatial_cycles: {"type":"range","label":"Number of half-wavelengths m [-]","description":"Change the spatial frequency of the temperature oscillation the grid must represent.","min":1,"max":4,"step":1,"value":2}
//| cases:
//|   - {"id":"fine-oscillation","label":"m = 4","description":"Coarse grids alias the oscillation, disrupting observed orders.","inputs":{"spatial_cycles":4}}
//|   - {"id":"slow-oscillation","label":"m = 1","description":"The oscillation is slow, giving orders close to theory even on coarse grids.","inputs":{"spatial_cycles":1}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"values","path":"/rows/0/3","equals":null}
//|       - {"artifact":"values","path":"/rows/8/3","approx":{"value":2.01,"atol":0.02}}
//|       - {"artifact":"values","path":"/rows/8/5","range":{"min":3.1,"max":3.3}}
//|       - {"artifact":"values","path":"/rows/4/5","range":{"min":3.3,"max":3.5}}
//|       - {"artifact":"values","path":"/rows/8/6","range":{"max":1e-13}}
//|   - case: fine-oscillation
//|     expect:
//|       - {"artifact":"values","path":"/rows/1/2","approx":{"value":1.9987,"atol":1e-3}}
//|       - {"artifact":"values","path":"/rows/1/3","range":{"max":1}}
//|   - case: slow-oscillation
//|     expect:
//|       - {"artifact":"values","path":"/rows/8/5","range":{"min":3.1,"max":3.3}}
use scioxide_core::RealScalar;
use scioxide_interp::{Differentiable, ExtrapolationPolicy, Interpolant};

let m = spatial_cycles.round();
let reject = ExtrapolationPolicy::Reject;
let grid = validation_points();
// Each refinement row: [h, bilinear RMSE, bicubic RMSE, gradient-error RMS, maximum gradient error]
let (mut rows, mut refinement) = (Vec::new(), Vec::new());
let mut previous: Option<[f64; 3]> = None;
for n in [4_usize, 5, 7, 10, 14, 20, 28, 40, 55] {
    let (bilinear, bicubic) = grid_models(n, m).map_err(|e| e.to_string())?;
    let (mut squared, mut gradient_squared, mut gradient_worst) = ([0.0_f64; 2], 0.0_f64, 0.0_f64);
    for &p in &grid {
        let exact = temperature(m, p[0], p[1]);
        let linear = bilinear.evaluate(p, reject).map_err(|e| e.to_string())?;
        let cubic = bicubic.evaluate(p, reject).map_err(|e| e.to_string())?;
        squared[0] += (linear - exact) * (linear - exact);
        squared[1] += (cubic - exact) * (cubic - exact);
        // Norm of the difference from the analytic gradient for independent checks
        let [gx, gy] = bicubic.gradient(p, reject).map_err(|e| e.to_string())?;
        let [ex, ey] = temperature_gradient(m, p[0], p[1]);
        let error = RealScalar::hypot(gx - ex, gy - ey);
        gradient_squared += error * error;
        gradient_worst = gradient_worst.max(error);
    }
    let count = grid.len() as f64;
    let rmse = squared.map(|s| RealScalar::sqrt(s / count));
    // Grid points should reproduce the supplied values
    let mut node_error = 0.0_f64;
    for j in 0..n {
        for i in 0..n {
            let point = [i as f64 / (n - 1) as f64, j as f64 / (n - 1) as f64];
            let value = bicubic.evaluate(point, reject).map_err(|e| e.to_string())?;
            node_error = node_error.max((value - temperature(m, point[0], point[1])).abs());
        }
    }
    let h = 1.0 / (n - 1) as f64;
    // Leave observed order blank in the first row, which has no previous row for comparison
    let order =
        |now: f64, before: f64, h0: f64| RealScalar::ln(before / now) / RealScalar::ln(h0 / h);
    let orders = previous.map(|[h0, b, c]| (order(rmse[0], b, h0), order(rmse[1], c, h0)));
    previous = Some([h, rmse[0], rmse[1]]);
    let gradient_rms = RealScalar::sqrt(gradient_squared / count);
    refinement.push([h, rmse[0], rmse[1], gradient_rms, gradient_worst]);
    rows.push((n, h, rmse[0], orders.map(|o| o.0), rmse[1], orders.map(|o| o.1), node_error));
}
// Line with order-p slope through the finest grid (2 for bilinear, 3 for bicubic)
let last = refinement[refinement.len() - 1];
let guide = |column: usize, power: f64| -> Vec<[f64; 2]> {
    refinement
        .iter()
        .map(|r| [r[0], last[column] * RealScalar::powf(r[0] / last[0], power)])
        .collect()
};
let points = |column: usize| -> Vec<[f64; 2]> {
    refinement.iter().map(|r| [r[0], r[column]]).collect()
};
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let fixed2 = serde_json::json!({ "fractionDigits": 2 });
let columns = serde_json::json!([
    { "key": "0", "label": "Nodes per axis n", "type": "integer" },
    {
        "key": "1",
        "label": "Grid spacing h [m]",
        "type": "number",
        "format": { "significantDigits": 4 }
    },
    { "key": "2", "label": "Bilinear RMSE [°C]", "type": "number", "format": sci3 },
    {
        "key": "3",
        "label": "Observed bilinear order",
        "type": "number",
        "format": fixed2,
        "nullText": "—"
    },
    { "key": "4", "label": "Bicubic RMSE [°C]", "type": "number", "format": sci3 },
    {
        "key": "5",
        "label": "Observed bicubic order",
        "type": "number",
        "format": fixed2,
        "nullText": "—"
    },
    { "key": "6", "label": "Grid-point reproduction error [°C]", "type": "number", "format": sci3 }
]);
emit_table_with_columns!(columns, rows, metadata = serde_json::json!({ "id": "values" }));
let dashed = serde_json::json!({ "lineType": "dashed", "showSymbol": false });
let marked = serde_json::json!({ "showSymbol": true });
emit_line_chart!(
    &vec![
        serde_json::json!({ "name": "Bilinear", "points": points(1), "style": marked }),
        serde_json::json!({ "name": "Bicubic", "points": points(2), "style": marked }),
        serde_json::json!({ "name": "Order-2 slope", "points": guide(1, 2.0), "style": dashed }),
        serde_json::json!({ "name": "Order-3 slope", "points": guide(2, 3.0), "style": dashed }),
    ],
    options = &serde_json::json!({
        "link": { "group": "grid-spacing" },
        "xLabel": "Grid spacing h [m]",
        "yLabel": "Value RMSE [°C]",
        "xType": "log",
        "yType": "log"
    })
);
export!(spatial_cycles, m);
export!(refinement, &refinement);
```

At $m=2$, the observed bilinear order rises from 1.53 to 2.01, approaching the theoretical value 2.
The observed bicubic order rises from 3.05 on the coarse grid to 3.40 at $n=14$, then falls to 3.20 on finer grids.
The rising part occurs on coarse grids with at most 1.5 intervals per half-wavelength, where the error has not yet reached its asymptotic form.
The falling part reflects the $h^4$ term's contribution decreasing in proportion to $m\pi h$ as the observed order approaches the asymptotic value 3.
An observed order above 3 only shows that the $h^4$ term remains present; it does not imply an asymptotic order of 4.
Grid-point reproduction error is zero on every grid: bicubic interpolation passes exactly through grid-point values.

At $m=1$, the observed bicubic order likewise rises from 3.16 to 3.39, then falls to 3.19.
At $m=4$, coarse-grid orders are disrupted, and the observed bilinear order from $n=4$ to 5 is 0.31.
At $n=5$, aliasing gives $\sin(4\pi x_i)=0$ at every node $x_i=i/4$; both RMSEs are 1.999 °C, plateauing at the oscillation scale $A/2$.
For $n=10$ and above, with more than two intervals per half-wavelength, the observed bicubic order exceeds 3.

## Convergence of gradient errors

Heat flux $\mathbf q=-k\nabla T$ requires an accurate gradient.
The next cell receives the bicubic `gradient` errors measured by the cell above on the same grids and validation points, and shows the root mean square (RMS) and maximum of the difference norm $|\nabla C-\nabla T|$ from the analytic gradient as functions of grid spacing.
The gradient unit is °C/m; multiplying by thermal conductivity $k$ [W/(m·K)] gives heat-flux error [W/m²].
The theoretical expectation is second order.
Maximum errors tend to be larger near the plate edges, where one-sided differences are used.
The plot's horizontal axis is linked to the plot above, and its dashed line has order-2 slope through the finest grid.

```rust
//| id: interp-bicubic-gradient-convergence
//| ref: interp-bicubic-gradient-convergence
//| title: "Inspect error and gradient convergence as the grid is refined"
//| run: reactive
//| crates: [scioxide-core]
//| dependsOn:
//|   values: interp-bicubic-value-convergence
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"gradients","path":"/rows/0/2","approx":{"value":9.79,"atol":0.01}}
//|       - {"artifact":"gradients","path":"/rows/0/3","equals":null}
//|       - {"artifact":"gradients","path":"/rows/8/3","approx":{"value":2.08,"atol":0.05}}
use scioxide_core::RealScalar;

let m = values["spatial_cycles"]
    .as_f64()
    .ok_or("Missing number of half-wavelengths")?;
let refinement: Vec<[f64; 5]> =
    serde_json::from_value(values["refinement"].clone()).map_err(|e| e.to_string())?;
// Gradient oscillation scale A m π [°C/m] (A = 4 °C)
let scale = 4.0 * m * std::f64::consts::PI;
let mut rows = Vec::new();
for (k, r) in refinement.iter().enumerate() {
    // Leave observed order blank in the first row, which has no previous row for comparison
    let order = (k > 0).then(|| {
        let before = refinement[k - 1];
        RealScalar::ln(before[3] / r[3]) / RealScalar::ln(before[0] / r[0])
    });
    let nodes = (1.0 / r[0]).round() as usize + 1;
    rows.push((nodes, r[0], r[3], order, r[4], r[3] / scale, r[2]));
}
let last = refinement[refinement.len() - 1];
let guide: Vec<[f64; 2]> = refinement
    .iter()
    .map(|r| [r[0], last[3] * RealScalar::powf(r[0] / last[0], 2.0)])
    .collect();
let curve: Vec<[f64; 2]> = refinement.iter().map(|r| [r[0], r[3]]).collect();
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let columns = serde_json::json!([
    { "key": "0", "label": "Nodes per axis n", "type": "integer" },
    {
        "key": "1",
        "label": "Grid spacing h [m]",
        "type": "number",
        "format": { "significantDigits": 4 }
    },
    { "key": "2", "label": "Gradient-error RMS [°C/m]", "type": "number", "format": sci3 },
    {
        "key": "3",
        "label": "Observed order",
        "type": "number",
        "format": { "fractionDigits": 2 },
        "nullText": "—"
    },
    { "key": "4", "label": "Maximum gradient error [°C/m]", "type": "number", "format": sci3 },
    { "key": "5", "label": "RMS / Amπ [-]", "type": "number", "format": sci3 },
    { "key": "6", "label": "Value RMSE (bicubic) [°C]", "type": "number", "format": sci3 }
]);
emit_table_with_columns!(columns, rows, metadata = serde_json::json!({ "id": "gradients" }));
emit_line_chart!(
    &vec![
        serde_json::json!({
            "name": "Bicubic gradient-error RMS",
            "points": curve,
            "style": { "showSymbol": true }
        }),
        serde_json::json!({
            "name": "Order-2 slope",
            "points": guide,
            "style": { "lineType": "dashed", "showSymbol": false }
        }),
    ],
    options = &serde_json::json!({
        "link": { "group": "grid-spacing" },
        "xLabel": "Grid spacing h [m]",
        "yLabel": "Gradient-error RMS [°C/m]",
        "xType": "log",
        "yType": "log"
    })
);
```

At $m=2$, the gradient-error RMS decreases from 9.79 °C/m at $n=4$ to 0.0186 °C/m at $n=55$; the observed order falls from 2.20 to 2.08, approaching the expected 2.
The gradient oscillation scale for this field is $Am\pi\approx25.1$ °C/m, so the RMS of 2.09 °C/m at $n=7$ is 8% of that scale.
Even at $n=55$, the maximum error is 0.093 °C/m, five times the RMS.
Setting $m=4$ in the cell above gives an RMS of 17.3 °C/m and a maximum error of 48.7 °C/m at $n=7$, comparable to the oscillation scale $Am\pi\approx50.3$ °C/m; even the gradient direction is unreliable.
The corresponding value RMSE is 0.80 °C; although this looks small compared with the 4 °C amplitude, the gradient can be far off.
When evaluating heat flux, verify gradient error by refining the grid.

## Summary

Measure convergence order as $\log(e_1/e_2)/\log(h_1/h_2)$ from error ratios as the grid is refined.
For this temperature field, bilinear value errors decrease with order 2, bicubic value errors with estimated derivatives with order 3, and gradient errors with order 2, agreeing with theoretical expectations.
The observed bicubic order exceeds 3 on coarse grids because the $h^4$ term is not yet negligible; infer the asymptotic order from how the order changes on fine grids.
An equally spaced validation grid can interact with the interpolation grid and bias RMSE, so use uniformly scattered validation points such as a Halton sequence.
Coarse grids with few intervals per half-wavelength disrupt orders, and aliased grids have errors that plateau at the oscillation scale.
Even with small value errors, gradient errors can be comparable to the oscillation scale; check gradient errors separately when heat flux is needed.
