Interpolation properties depend on what is to be estimated between samples.
Each example fixes units and models and compares outputs with analytic, known, or independently computed values.
Assess table errors and termination as well as visual smoothness.

## Examples and independent checks

## Controls and comparisons

First inspect result scales at defaults.
Then change one input and compare affected errors or constraints.
For random examples, vary seeds and compare variation with repeated-trial standard errors (SE).
When increasing samples or grid resolution, inspect observed error orders together with conditioning and computational work.

Synthetic fields and models with known truth measure actual errors unavailable with observations.
Do not generalize their observed accuracy unchanged to other geometries or noise.
Interpret out-of-domain values and unconverged partial results only under each example's conditions.

## Summary

First decide whether each example computes values, derivatives, integrals, poles, or curvature.
Under changed inputs, compare changes in independent checks.
Check unused-point errors and required properties such as monotonicity and nonnegativity rather than sample agreement alone.
