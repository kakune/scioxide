A calibration table pairs known input concentrations with the corresponding sensor outputs.
Assume the response increases monotonically over the range of interest and consider samples satisfying

$$
x_0<x_1<\cdots<x_n,\qquad y_0\le y_1\le\cdots\le y_n
$$


If the interpolating curve is also monotone on each interval, it introduces no maxima or minima absent from the samples.
Recovering a unique concentration from one output in inverse calibration requires a strictly monotone interpolating curve over the range of interest.
On flat intervals, multiple concentrations can correspond to the same output, so nonstrict monotonicity alone does not ensure uniqueness.
This example interpolates the same calibration table with a natural cubic spline and PCHIP, comparing value monotonicity, node slopes, and inverse-calibration uniqueness and sensitivity in turn.

## Calibration table and notation

This calibration table contains illustrative values rather than sourced measurements.
Input concentration $x$ is in mmol/L and sensor output $y$ in mV, with five equally spaced nodes.

| Node $i$ | 0 | 1 | 2 | 3 | 4 |
|---|---|---|---|---|---|
| Concentration $x_i$ [mmol/L] | 0 | 1 | 2 | 3 | 4 |
| Output $y_i$ [mV] | 0 | 0.8 | $0.8+\Delta_2$ | 2.7 | $2.7+\Delta_4$ |

Call $\Delta_2=y_2-y_1$ the central increment and $\Delta_4=y_4-y_3$ the final increment.
Making $\Delta_2$ small creates a nearly flat interval between steep intervals.
Write the width of interval $[x_i,x_{i+1}]$ as $h_i=x_{i+1}-x_i$ and its secant slope as

$$
\delta_i = \frac{y_{i+1} - y_i}{h_i}
$$


Since $h_i=1$ mmol/L in this table, the numerical value of $\delta_i$ [mV/(mmol/L)] equals each interval's increment [mV].

The following block defines quantities shared by this page's three cells.
`CONCENTRATIONS` gives node concentrations $x_i$, `calibration_outputs` gives outputs $y_i$, and `calibration_models` constructs PCHIP and a natural cubic spline from the same table.

```rust
//| id: interp-monotone-model
//| kind: definitions
//| title: "Calibration table and two interpolants"
//| crates: [scioxide-core, scioxide-interp]
use scioxide_core::SciOxideError;
use scioxide_interp::{CubicSpline, PchipInterpolator, SplineBoundary};

/// Node concentrations x_i [mmol/L], equally spaced with h_i = 1.
pub(crate) const CONCENTRATIONS: [f64; 5] = [0.0, 1.0, 2.0, 3.0, 4.0];

/// Sensor outputs y_i [mV] (illustrative values). Δ₂ = y₂ − y₁, Δ₄ = y₄ − y₃.
pub(crate) fn calibration_outputs(central: f64, terminal: f64) -> Vec<f64> {
    vec![0.0, 0.8, 0.8 + central, 2.7, 2.7 + terminal]
}

/// PCHIP and natural cubic spline (S″ = 0 at both ends) for the same calibration table.
pub(crate) fn calibration_models(
    central: f64,
    terminal: f64,
) -> Result<(PchipInterpolator<f64>, CubicSpline<f64>), SciOxideError> {
    let nodes = CONCENTRATIONS.to_vec();
    let outputs = calibration_outputs(central, terminal);
    let pchip = PchipInterpolator::new(nodes.clone(), outputs.clone())?;
    let natural = CubicSpline::with_boundary(nodes, outputs, SplineBoundary::Natural)?;
    Ok((pchip, natural))
}
```

## Natural cubic spline overshoot

A natural cubic spline connects nodes with cubic polynomials and has continuous derivatives through order two throughout ($C^2$).
Its second derivative is zero at both endpoints.
Among functions passing through the samples with square-integrable second derivatives, the natural cubic spline minimizes

$$
J(S) = \int_{x_0}^{x_n} S''(x)^2\,dx
$$

(Holladay's theorem; de Boor, Chapter V).
In this sense it minimizes bending, but imposes no conditions preserving value ranges or slope signs.

Node second derivatives are determined by a tridiagonal system linking all nodes, so a rapid change on one interval affects the shape on distant intervals too.
When secant slopes change sharply from steep to flat intervals, $S'(x)<0$ can occur near the flat interval, introducing maxima or minima absent from the samples.
This is called overshoot.
Even with monotone samples, spline values can leave the sample range.

## PCHIP slopes and the Fritsch–Carlson conditions

Piecewise cubic Hermite interpolation (PCHIP) is a $C^1$ piecewise cubic curve with only values and first derivatives continuous at nodes.
Instead of requiring continuous second derivatives, it determines each node slope from nearby samples alone and preserves monotonicity.

On interval $[x_i,x_{i+1}]$, set $t=(x-x_i)/h_i\in[0,1]$.
Given endpoint values $y_i,y_{i+1}$ and endpoint slopes $d_i,d_{i+1}$, the cubic Hermite polynomial is

$$
p_i(t) = (2t^3 - 3t^2 + 1) y_i + (t^3 - 2t^2 + t) h_i d_i + (-2t^3 + 3t^2) y_{i+1} + (t^3 - t^2) h_i d_{i+1}
$$


On an interval with $\delta_i>0$, use endpoint slopes divided by the secant, $\alpha_i=d_i/\delta_i$ and $\beta_i=d_{i+1}/\delta_i$; then $p_i'(x)/\delta_i$ is a quadratic in $t$ determined only by $\alpha_i,\beta_i$.
Fritsch and Carlson (1980) found the region of $(\alpha_i,\beta_i)$ where this quadratic is nonnegative on $[0,1]$.
$\alpha_i\ge0$ and $\beta_i\ge0$ are necessary conditions; the square $0\le\alpha_i,\beta_i\le3$ lies within this region and is sufficient.
On a flat interval with $\delta_i=0$, setting both endpoint slopes to zero makes the value constant throughout the interval.
See [PCHIP, cubic splines, and Akima](../../algorithms/pchip-and-splines/) for the full region and its derivation.

### Choosing node slopes

For each component, `PchipInterpolator` chooses node slopes by the following rules.

1. At an interior node with $\delta_{i-1}\delta_i\le0$, $x_i$ is a data extremum or the end of a plateau, so set $d_i=0$.
2. At an interior node with $\delta_{i-1}\delta_i>0$, use an interval-width-weighted harmonic mean (the Fritsch–Butland formula with Brodlie weights).
   $$
   d_i = \frac{w_1 + w_2}{\dfrac{w_1}{\delta_{i-1}} + \dfrac{w_2}{\delta_i}}, \qquad w_1 = 2h_i + h_{i-1}, \quad w_2 = h_i + 2h_{i-1}
   $$
3. At the left endpoint, form the slope at $x_0$ of the quadratic through the first three nodes:

   $$
   d_0=\frac{(2h_0+h_1)\delta_0-h_0\delta_1}{h_0+h_1}=\delta_0+\frac{h_0}{h_0+h_1}(\delta_0-\delta_1)
   $$


   If its sign differs from $\delta_0$, set $d_0=0$; if $\delta_0$ and $\delta_1$ have opposite signs and $|d_0|>3|\delta_0|$, limit it to $d_0=3\delta_0$.
   At the right endpoint, apply the same rule using $\delta_{n-1},\delta_{n-2}$ and $h_{n-1},h_{n-2}$.

The harmonic mean is pulled toward the smaller secant and satisfies $0<d_i\le3\min(\delta_{i-1},\delta_i)$.
Thus $(\alpha_i,\beta_i)$ for interior intervals lies in the square above, preventing steep-interval slopes from carrying into flat intervals.
For same-sign secants, the endpoint formula gives $|d_0|<2|\delta_0|$; when the sign changes, limiting places it within the square.
Preparation costs $O(n)$ for $n$ nodes; evaluating values and derivatives costs $O(\log n)$, including interval binary search.
Read the computed slopes with `slopes()`.

## Comparing value monotonicity

The next cell takes central increment $\Delta_2$ and final increment $\Delta_4$ and evaluates PCHIP and a natural cubic spline at 241 points on $[0,4]$.
It evaluates `value_at` with `ExtrapolationPolicy::Reject`, so points outside the calibration domain cause errors.
The table shows counts of adjacent evaluation-point pairs with decreasing values, evaluation points outside the calibration range $[y_0,y_4]$, and the minimum and maximum evaluated values.
The plot shades the calibration-value range; a monotone interpolating curve stays within it.

## Checking node slopes and sensitivity

The next cell receives $\Delta_2$ and $\Delta_4$ from above and reads PCHIP node slopes `slopes()` and both interpolants' derivatives $dy/dx$ through `derivative_at`.
The derivative is output change per concentration, representing local sensor sensitivity [mV/(mmol/L)].
The first table is an independent check: compute the slope rules above in their general form including interval widths $h_i$ using f64 arithmetic, and show differences from `slopes()`.
The second table lists each interval's secant $\delta_i$ and ratios $\alpha_i=d_i/\delta_i$ and $\beta_i=d_{i+1}/\delta_i$, checking that every interval lies in the square $[0,3]^2$.
The third table shows the minimum sensitivity evaluated at 241 points and its concentration.
The plot's horizontal axis is linked to the previous cell's plot; below the zero line, that interpolant decreases as concentration increases.

//|       - {"artifact":"sensitivity","path":"/rows/1/1","approx":{"value":-0.236,"atol":1e-3}}

let central = table["central_increment"]
    .as_f64()
    .ok_or("Missing central increment")?;
let terminal = table["terminal_increment"]
    .as_f64()
    .ok_or("Missing final increment")?;
let (pchip, natural) = calibration_models(central, terminal).map_err(|e| e.to_string())?;
let x = CONCENTRATIONS;
let y = calibration_outputs(central, terminal);
let h: Vec<f64> = x.windows(2).map(|p| p[1] - p[0]).collect();
let delta: Vec<f64> = (0..4).map(|i| (y[i + 1] - y[i]) / h[i]).collect();

// Independent check: limit the slope of the one-sided three-point quadratic by sign and magnitude
let end_slope = |d1: f64, d2: f64, h1: f64, h2: f64| {
    let proposal = d1 + h1 / (h1 + h2) * (d1 - d2);
    if proposal * d1 <= 0.0 {
        0.0
    } else if d1 * d2 < 0.0 && proposal.abs() > 3.0 * d1.abs() {
        3.0 * d1
    } else {
        proposal
    }
};
let mut expected = vec![end_slope(delta[0], delta[1], h[0], h[1])];
for i in 1..4 {
    // Use a weighted harmonic mean for matching signs, otherwise zero
    let (w1, w2) = (2.0 * h[i] + h[i - 1], h[i] + 2.0 * h[i - 1]);
    expected.push(if delta[i - 1] * delta[i] > 0.0 {
        (w1 + w2) / (w1 / delta[i - 1] + w2 / delta[i])
    } else {
        0.0
    });
}
expected.push(end_slope(delta[3], delta[2], h[3], h[2]));
let slopes = pchip.slopes();
let node_rows: Vec<(usize, f64, f64, f64, f64)> = (0..5)
    .map(|i| (i, x[i], slopes[i], expected[i], slopes[i] - expected[i]))
    .collect();
// Per-interval α = d_i/δ_i and β = d_{i+1}/δ_i. Undefined on flat intervals (δ_i = 0).
let ratio_rows: Vec<(usize, f64, Option<f64>, Option<f64>)> = (0..4)

    .collect();

        .iter()
        .fold([0.0, f64::INFINITY], |m, &p| if p[1] < m[1] { p } else { m });
    (name.to_string(), p[1], p[0])

        { "key": "2", "label": "Its concentration [mmol/L]", "type": "number", "format": fixed4 }

Both compute the same formulas with floating-point operations in the same order, agreeing even in rounding.
The interior $d_1=2/(1/0.8+1/0.1)=0.1778$ is less than twice the smaller of the two secants 0.8 and 0.1.
The right endpoint slope is zero.
The one-sided formula gives negative $(3\delta_3-\delta_2)/2=(0.9-1.8)/2$, opposite in sign to $\delta_3$, so it is replaced with zero.
This zero limits the slope to prevent an extremum within the rightmost interval; it does not mean the data are flat at the right endpoint.
At $\Delta_4=1.2$ mV, the one-sided formula's value 0.9 is used unchanged.

In the ratio table, $\alpha_1=1.778$ and $\beta_1=1.895$ are largest on the nearly flat interval $[1,2]$, and every interval lies within the square $[0,3]^2$.
The rightmost interval's $\beta_3=0$ results from the endpoint limiting above.

In the sensitivity table and plot, PCHIP sensitivity has minimum zero at the right endpoint and is nonnegative throughout.
With defaults, natural-spline sensitivity is smallest at the right endpoint, at $-0.236$ mV/(mmol/L), and is also negative in the first half of interval $[1,2]$.
At $\Delta_2=0.05$ mV, it falls to $-0.284$ mV/(mmol/L) at $x=1.35$ mmol/L.
Negative-sensitivity ranges coincide with the decreasing pairs in the cell above.

## Inverse-calibration sensitivity

Inverse calibration estimates concentration $x^*$ from measured output $y^*$ by solving $p(x)=y^*$.
If $p$ is strictly increasing, each $y^*$ within the calibration domain $[y_0,y_n]$ has a unique root.
If $p$ is not monotone, multiple concentrations may correspond to the same $y^*$.

If $p$ is strictly monotone and $p'(x^*)>0$, the inverse $x(y)$ is smooth near $y^*$, with $x'(y)=1/p'(x)$.
For output error $e_y$, a first-order Taylor expansion gives concentration-estimation error $e_x$ as

$$
e_x \approx \frac{e_y}{p'(x^*)}
$$

(errors use $e$ to distinguish them from secants denoted by $\delta_i$).
Concentration-error amplification relative to output error is $1/|p'(x^*)|$, the absolute condition number of inverse calibration.
Where sensitivity $p'(x)$ is large, estimated concentrations respond weakly to output errors, giving good conditioning.
In flat regions with $p'(x)\approx0$, even small output errors greatly change concentration estimates, giving poor conditioning.
This poor conditioning comes from the flat sensor response itself and cannot be eliminated by changing interpolation methods.

For the concentration half-width corresponding to output width $y^*\pm u_y$,

$$
w = \frac{x(y^*+u_y)-x(y^*-u_y)}{2} = \frac{u_y}{p'(x^*)} + \frac{x'''(y^*)}{6}u_y^3 + O(u_y^5)
$$

the $x''$ terms cancel between the two sides.
Thus, if $y^*\pm u_y$ lies within one cubic piece, the relative difference between first-order prediction $u_y/p'(x^*)$ and the actual half-width decreases in proportion to $u_y^2$.
PCHIP second derivatives jump at nodes, so this cancellation fails if the width crosses a node's output.

`scioxide-interp` provides no inverse-function API.
The next cell divides $[0,4]$ into 400 intervals to find sign changes of $p(x)-y^*$, then bisects each sign-changing interval 60 times to find roots.
Bisection uses only value evaluations, providing an independent check of the first-order prediction from sensitivity obtained with `derivative_at`.
General root-finding methods and their comparison are covered in [the scioxide-rootfind chapter](../../../scioxide-rootfind/).

## Inverse-calibration experiment

The next cell receives $\Delta_2$ and $\Delta_4$ from above and takes measured output $y^*$ [mV] and output-error width $u_y$ [mV] as inputs.
Take $y^*\pm u_y$ inside the calibration-value range $[y_0,y_4]$; the cell returns an error if it lies outside.
The first table shows preimages of $y^*$ under both interpolants in ascending order, with sensitivity at each preimage.
The second table shows PCHIP sensitivity $p'(x^*)$, first-order prediction $u_y/p'(x^*)$, bisection half-width $w$, and their relative difference.
The scan tests signs on intervals of width 0.01 mmol/L and can miss roots closer together than that.

//| id: interp-monotone-inverse
//| ref: interp-monotone-inverse
//| title: "Check inverse-calibration uniqueness and sensitivity by bisection"
//| run: reactive
//| uses: [interp-monotone-model]
//| crates: [scioxide-interp]
//| dependsOn:
//|   table: interp-monotone-calibration
//| inputs:
//|   measured_output: {"type":"range","label":"Measured output y* [mV]","description":"Output to invert through calibration.","min":0.1,"max":2.9,"step":0.02,"value":0.76}
//|   output_uncertainty: {"type":"range","label":"Output-error width u_y [mV]","description":"Output width to compare with the first-order prediction.","min":0.002,"max":0.05,"step":0.002,"value":0.01}
//| cases:
//|   - {"id":"flat-output","label":"y* = 0.84 mV","description":"Inside the flat interval, sensitivity falls and the same u_y spans a wider concentration range.","inputs":{"measured_output":0.84}}
//|   - {"id":"narrow-band","label":"u_y = 0.002 mV","description":"Reducing width to 1/5 reduces relative difference from the first-order prediction to about 1/25.","inputs":{"output_uncertainty":0.002}}
//|   - {"id":"wide-band","label":"u_y = 0.05 mV","description":"The width crosses the node output 0.8 mV, invalidating the first-order prediction.","inputs":{"output_uncertainty":0.05}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"roots","path":"/rows/0/2","approx":{"value":0.8641,"atol":1e-4}}
//|       - {"artifact":"roots","path":"/rows/1/0","equals":"Natural cubic spline"}
//|       - {"artifact":"roots","path":"/rows/3/2","approx":{"value":1.8017,"atol":1e-4}}
//|       - {"artifact":"inverse","path":"/rows/0/0","approx":{"value":0.406,"atol":1e-3}}
//|   - case: flat-output
//|     expect:
//|       - {"artifact":"inverse","path":"/rows/0/0","approx":{"value":0.066,"atol":1e-3}}
//|   - case: narrow-band
//|     expect:
//|       - {"artifact":"inverse","path":"/rows/0/3","range":{"max":5e-4}}
//|   - case: wide-band
//|     expect:
//|       - {"artifact":"inverse","path":"/rows/0/3","range":{"min":0.1}}
use scioxide_interp::{Interpolant, Univariate};

// Roots of p(x) = target: scan 400 intervals for sign changes and bisect each interval 60 times
fn crossings<M: Interpolant<f64, 1, Value = f64>>(
    model: &M,
    target: f64,
) -> Result<Vec<f64>, String> {
    let f = |x: f64| {
        model
            .value_at(x)
            .map(|v| v - target)
            .map_err(|e| e.to_string())
    };
    let mut roots = Vec::new();
    let (mut a0, mut f0) = (0.0, f(0.0)?);
    for k in 1..=400 {
        let b0 = 4.0 * f64::from(k) / 400.0;
        let g0 = f(b0)?;
        if (f0 <= 0.0 && g0 > 0.0) || (f0 >= 0.0 && g0 < 0.0) {
            let (mut a, mut b, mut fa) = (a0, b0, f0);
            for _ in 0..60 {
                let mid = 0.5 * (a + b);
                let fm = f(mid)?;
                if (fm > 0.0) == (fa > 0.0) {
                    (a, fa) = (mid, fm);
                } else {
                    b = mid;
                }
            }
            roots.push(0.5 * (a + b));
        }
        (a0, f0) = (b0, g0);
    }
    Ok(roots)
}

let central = table["central_increment"]
    .as_f64()
    .ok_or("Missing central increment")?;
let terminal = table["terminal_increment"]
    .as_f64()
    .ok_or("Missing final increment")?;
let (pchip, natural) = calibration_models(central, terminal).map_err(|e| e.to_string())?;
let pchip_roots = crossings(&pchip, measured_output)?;
let natural_roots = crossings(&natural, measured_output)?;
// Sensitivity at each preimage is the analytic derivative from derivative_at
let mut root_rows: Vec<(&str, usize, f64, f64)> = Vec::new();
for (k, &root) in pchip_roots.iter().enumerate() {
    let slope = pchip.derivative_at(root).map_err(|e| e.to_string())?;
    root_rows.push(("PCHIP", k + 1, root, slope));
}
for (k, &root) in natural_roots.iter().enumerate() {
    let slope = natural.derivative_at(root).map_err(|e| e.to_string())?;
    root_rows.push(("Natural cubic spline", k + 1, root, slope));
}

// PCHIP is strictly monotone, so there is one root
let x_star = *pchip_roots
    .first()
    .ok_or("y* is outside the calibration-value range [y₀, y₄]")?;
let slope = pchip.derivative_at(x_star).map_err(|e| e.to_string())?;
let upper = crossings(&pchip, measured_output + output_uncertainty)?;
let lower = crossings(&pchip, measured_output - output_uncertainty)?;
let half_width = match (upper.first(), lower.first()) {
    (Some(u), Some(l)) => 0.5 * (u - l),
    _ => return Err("y* ± u_y is outside the calibration-value range [y₀, y₄]".to_string()),
};
let predicted = output_uncertainty / slope;

let fixed4 = serde_json::json!({ "fractionDigits": 4 });
let sig4 = serde_json::json!({ "significantDigits": 4 });
emit_table_with_columns!(
    serde_json::json!([
        { "key": "0", "label": "Method" },
        { "key": "1", "label": "Preimage index", "type": "integer" },
        { "key": "2", "label": "Preimage x [mmol/L]", "type": "number", "format": fixed4 },
        { "key": "3", "label": "Sensitivity p′(x) [mV/(mmol/L)]", "type": "number", "format": fixed4 }
    ]),
    root_rows,
    metadata = serde_json::json!({ "id": "roots" })
);
emit_table_with_columns!(
    serde_json::json!([
        {
            "key": "0",
            "label": "PCHIP sensitivity p′(x*) [mV/(mmol/L)]",
            "type": "number",
            "format": sig4
        },
        { "key": "1", "label": "First-order prediction u_y/p′(x*) [mmol/L]", "type": "number", "format": sig4 },
        { "key": "2", "label": "Bisection half-width w [mmol/L]", "type": "number", "format": sig4 },

With defaults $\Delta_2=0.1$ mV and $y^*=0.76$ mV, the natural cubic spline has three preimages: 0.8520, 1.3666, and 1.8017 mmol/L.
On interval $[1,2]$, the spline falls from the node value 0.8 mV to below 0.76 mV before rising again, so three concentrations correspond to the same output.
The middle preimage has negative sensitivity, so increasing output moves the concentration estimate downward.
PCHIP has only one preimage, 0.8641 mmol/L.

PCHIP sensitivity is $p'(x^*)=0.406$ mV/(mmol/L); for $u_y=0.01$ mV, the first-order prediction is 0.02464 mmol/L and the bisection half-width is 0.02477 mmol/L.
At $u_y=0.002$ mV, the relative difference shrinks to 0.02%, about 1/25, agreeing with the estimate proportional to $u_y^2$ above.
At $u_y=0.05$ mV, $y^*+u_y=0.81$ mV crosses the node output 0.8 mV; bisection gives 0.150 mmol/L compared with the prediction 0.123.
At $y^*=0.84$ mV within the flat interval, sensitivity falls to 0.066, and the same $u_y=0.01$ mV gives a concentration width of about 0.15 mmol/L.
Setting $\Delta_2=1.6$ mV in the first cell gives one preimage for both interpolants and raises sensitivity to 1.06.

## Summary

PCHIP can interpolate monotone calibration tables while preserving monotonicity on each interval.
The natural cubic spline's $C^2$ smoothness preserves neither value ranges nor slope signs and can destroy inverse-calibration uniqueness.
Read PCHIP slopes with `slopes()` and recompute them explicitly from the interior weighted harmonic mean and one-sided endpoint formula; ratios $\alpha_i,\beta_i$ within $[0,3]$ verify monotonicity.
In inverse calibration, $1/|p'(x^*)|$ is output-error amplification; flat regions are ill conditioned with any interpolant.
For large output errors or widths crossing nodes, check first-order predictions against actual inversion by bisection or another method.
