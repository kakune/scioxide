When estimating fields from scattered points such as weather stations, interpolation matches sample values and even weak regularization leaves nearly zero sample residuals, so those residuals cannot select the kernel shape parameter.
Vary Gaussian RBF width and estimate accuracy at unobserved points through errors when leaving out one sample at a time.
Using the Franke function with known true values, examine how well cross-validation errors reflect actual approximation errors.

## Test function and observation points

On $[0,1]^2$,

$$
\begin{aligned}
f(x,y)={}&\tfrac34e^{-[(9x-2)^2+(9y-2)^2]/4}
+\tfrac34e^{-(9x+1)^2/49-(9y+1)/10}\\
&+\tfrac12e^{-[(9x-7)^2+(9y-3)^2]/4}
-\tfrac15e^{-(9x-4)^2-(9y-7)^2}
\end{aligned}
$$


It contains two peaks of different widths and heights, a gentle slope, and a narrow depression, making the whole field difficult to represent with a single basis scale.
The original source is [Franke, Scattered Data Interpolation: Tests of Some Methods](https://doi.org/10.1090/S0025-5718-1982-0637296-4).
Always include the square's four corners among observations, generating the remaining points with uniform random numbers.
Including all corners makes both the bounding rectangle and convex hull of the full point set equal the square.
The domain of `RbfInterpolator` is the points' bounding rectangle, while that of `CloughTocherInterpolator` is the Delaunay triangulation's convex hull, allowing comparison over the same square.

## Gaussian RBFs and conditioning

The Gaussian kernel is $\varphi(r)=\exp[-(\epsilon r)^2]$, with shape parameter $\epsilon>0$.
Interpolation finds weights $w$ for $s(\boldsymbol x)=\sum_jw_j\varphi(\|\boldsymbol x-\boldsymbol x_j\|)$ without polynomial terms by solving $(K+\lambda I)w=y$ with kernel matrix $K_{ij}=\varphi(\|\boldsymbol x_i-\boldsymbol x_j\|)$.
The Gaussian-kernel $K$ is positive definite for distinct points (Bochner's theorem), so `RbfInterpolator` uses Cholesky factorization.
If factorization breaks down or numerical-rank or condition checks fail, it switches to singular value decomposition.
Even with SVD, insufficient numerical rank under the configured threshold returns an error of `Singular`.
Construction uses $O(n^3)$ time and $O(n^2)$ memory; evaluation costs $O(n)$ per point.
$\lambda>0$ is diagonal regularization specified through `RbfRegularization::Diagonal(λ)`, relaxing exact sample matching to smooth the data.
Pass kernel `RbfKernel::Gaussian(ε)` alongside the samples, set regularization and the numerical-rank threshold (relative $10^{-14}$ here, machine epsilon by default) through `RbfOptions` setters, and construct with the detailed form `RbfInterpolator::with_options(points, values, kernel, options)`.

Small $\epsilon$ makes the basis flat and the columns of $K$ nearly equal, causing the condition number to grow rapidly (the flat limit).
With regularization, however, the smallest eigenvalue of $A=K+\lambda I$ is at least $\lambda$, giving $\|A^{-1}\|_2\le1/\lambda$.
Kernel values are at most 1, so $\|A\|_1\le n+\lambda$; together with $\|A^{-1}\|_1\le\sqrt n\,\|A^{-1}\|_2$, the 1-norm reciprocal condition number satisfies

$$
\kappa_1^{-1}\ge\frac{\lambda}{\sqrt n\,(n+\lambda)}
$$

`RbfConditioning::reciprocal_condition_number` returns a 1-norm reciprocal-condition estimate from Cholesky or LU factors, or the 2-norm singular-value ratio $\sigma_{\min}/\sigma_{\max}$ from SVD.
The 1-norm estimate is neither an upper nor a lower bound.
However, the Hager–Higham estimator underestimates $\|A^{-1}\|_1$ in exact arithmetic, so the estimate is usually at least the true reciprocal condition number.
The 2-norm reciprocal condition number $\lambda_{\min}/\lambda_{\max}\ge\lambda/(n+\lambda)$ satisfies the same lower bound.

`franke` defines $f$; `stations` supplies corner and uniformly random observations; `test_grid` gives centers of a $20\times20$ grid; `shape_parameter` defines $\epsilon=2^{k/2}$; `rbf_options` sets regularization and rank threshold; `without` omits one sample; `mean_and_half_width` gives the mean and 1.96 SE.

```rust
//| id: interp-station-franke-model
//| kind: definitions
//| title: "Franke function, observations, and validation helpers"
//| crates: [scioxide-core, scioxide-interp, scioxide-random]
use scioxide_core::{SciOxideError, RankThreshold, RealScalar};
use scioxide_interp::{RbfOptions, RbfRegularization};
use scioxide_random::{Rng, SeedableRng, SplitMix64};

/// Franke's test function (Franke 1982).
pub(crate) fn franke(x: f64, y: f64) -> f64 {
    let (u, v) = (9.0 * x, 9.0 * y);
    0.75 * RealScalar::exp(-((u - 2.0) * (u - 2.0) + (v - 2.0) * (v - 2.0)) / 4.0)
        + 0.75 * RealScalar::exp(-(u + 1.0) * (u + 1.0) / 49.0 - (v + 1.0) / 10.0)
        + 0.5 * RealScalar::exp(-((u - 7.0) * (u - 7.0) + (v - 3.0) * (v - 3.0)) / 4.0)
        - 0.2 * RealScalar::exp(-(u - 4.0) * (u - 4.0) - (v - 7.0) * (v - 7.0))
}

/// count points combining the square's four corners (indices 0–3) and uniform random points in [0, 1)².
pub(crate) fn stations(count: usize, seed: f64) -> Result<Vec<[f64; 2]>, SciOxideError> {
    let mut sites = vec![[0.0, 0.0], [1.0, 0.0], [1.0, 1.0], [0.0, 1.0]];
    let mut rng = SplitMix64::from_seed(seed as u64);
    while sites.len() < count {
        sites.push([rng.next_float()?, rng.next_float()?]);
    }
    Ok(sites)
}

/// Centers of a 20 × 20 grid independent of the samples.
pub(crate) fn test_grid() -> Vec<[f64; 2]> {
    (0..400)
        .map(|k| {
            [
                ((k / 20) as f64 + 0.5) / 20.0,
                ((k % 20) as f64 + 0.5) / 20.0,
            ]
        })
        .collect()
}

/// Shape parameter ε = 2^(k/2).
pub(crate) fn shape_parameter(k: i32) -> f64 {
    RealScalar::powf(2.0, f64::from(k) / 2.0)
}

/// Regularization and numerical-rank threshold (relative 10⁻¹⁴).
pub(crate) fn rbf_options(
    regularization: RbfRegularization<f64>,
) -> Result<RbfOptions<f64>, SciOxideError> {
    Ok(RbfOptions::new()
        .with_regularization(regularization)
        .with_rank_threshold(RankThreshold::new(0.0, 1e-14)?))
}

/// Samples with point index omitted removed.
pub(crate) fn without(
    sites: &[[f64; 2]],
    values: &[f64],
    omitted: usize,
) -> (Vec<[f64; 2]>, Vec<f64>) {
    sites
        .iter()
        .zip(values)
        .enumerate()
        .filter(|(i, _)| *i != omitted)
        .map(|(_, (&p, &v))| (p, v))
        .unzip()
}

/// Sample mean and 95% interval half-width 1.96 SE (SE = sample standard deviation / √m).
pub(crate) fn mean_and_half_width(x: &[f64]) -> (f64, f64) {
    let m = x.len() as f64;
    let mean = x.iter().sum::<f64>() / m;
    let variance = x.iter().map(|v| (v - mean) * (v - mean)).sum::<f64>() / (m - 1.0);
    (mean, 1.96 * RealScalar::sqrt(variance / m))
}
```

With default $n=24$, reducing $\epsilon$ from 16 lowers the unregularized reciprocal-condition estimate from 0.16 to $5.8\times10^{-14}$ at $\epsilon=0.5$; the two candidates at $\epsilon\le0.35$ fail construction with an error of `Singular`.
None of the successfully constructed candidates switches to SVD; their values are 1-norm estimates from Cholesky factors.
Adding regularization places a floor under reciprocal condition numbers: $2.1\times10^{-10}$–$3.5\times10^{-8}$ at $\lambda=10^{-8}$ and at least $2.0\times10^{-6}$ at $\lambda=10^{-4}$.
Floors on the flat side are two to four times the lower bound $\lambda/(\sqrt n(n+\lambda))$ ($8.5\times10^{-11}$ at $\lambda=10^{-8}$ and $8.5\times10^{-7}$ at $10^{-4}$); no candidate falls below its bound.
At $\epsilon\ge4$, the kernel matrix is well conditioned, and regularization $\lambda\le10^{-4}$ barely changes the estimate.
Setting $n=40$ reduces point spacing and makes bases relatively flatter at the same $\epsilon$; the estimate at $\epsilon=16$ falls to 0.023, while without regularization four candidates fail construction and one switches to SVD.
A large reciprocal condition number indicates only that the system can be solved stably, not that interpolation is accurate.

## Leave-one-out cross-validation

Let $s_{-i}$ be the model constructed without sample $i$, and use held-out errors $e_i=s_{-i}(\boldsymbol x_i)-y_i$ to define

$$
E_{\mathrm{CV}}=\sqrt{\frac1{|I|}\sum_{i\in I}e_i^2}
$$


Removing a corner shrinks the bounding rectangle and puts the omitted point outside the RBF domain, so always retain the corners and omit only interior points $I$ in turn.
This validates interior points with known boundary values, rather than leaving out every point.
`RbfInterpolator` provides no closed-form leave-one-out error calculation, so reconstruct it for every omitted point.
Each reconstruction costs $O(n^3)$, for total cost $O(n^4)$.
For closed-form leave-one-out predictions, use Gaussian-process `GaussianProcessModel::leave_one_out_into` ([Local models and kriging prediction variance](../../algorithms/local-models-and-kriging/)).

$E_{\mathrm{CV}}$ itself is an estimate from a limited number of points.
Convert the standard error of mean squared error $\mathrm{SE}=s_{e^2}/\sqrt{|I|}$ to $\mathrm{SE}/(2E_{\mathrm{CV}})$ with the delta method to obtain the 95% interval half-width of $E_{\mathrm{CV}}$.
For comparison, measure the full model's RMS difference $E_{\mathrm{test}}$ from the true function at centers of a $20\times20$ grid independent of samples.
Express agreement between the rankings of $E_{\mathrm{CV}}$ and $E_{\mathrm{test}}$ across shape parameters through Spearman's rank correlation $r_s=1-6\sum d_i^2/[m(m^2-1)]$ ($d_i$ is the difference between candidate $i$'s two ranks, and $m$ is the candidate count).
Also compare $E_{\mathrm{test}}$ at the $\epsilon$ minimizing $E_{\mathrm{CV}}$ with the minimum of $E_{\mathrm{test}}$.

It uses the same 13 shape parameters as the previous cell.

use scioxide_interp::{
    ExtrapolationPolicy, Interpolant, RbfInterpolator, RbfKernel, RbfRegularization,
};

let grid = test_grid();
let lambda = RealScalar::powi(10.0, exponent as i32);

    let epsilon = shape_parameter(k);
    let kernel = RbfKernel::Gaussian(epsilon);
    // Interior leave-one-out squared errors and independent-grid mean squared error of the full model
    let trial = (|| -> Result<(Vec<f64>, f64), SciOxideError> {
        let mut squares = Vec::new();
        for omitted in 4..count {
            let (x, y) = without(&sites, &values, omitted);
            let model = RbfInterpolator::with_options(x, y, kernel, options)?;
            let e = model.evaluate(sites[omitted], policy)? - values[omitted];

            RbfInterpolator::with_options(sites.clone(), values.clone(), kernel, options)?;

                Some(test),

    }

## Comparison with Clough–Tocher

Clough–Tocher interpolation splits each Delaunay triangle into three at its centroid and places a cubic Bézier patch on each, producing globally $C^1$ interpolation.
Vertex gradients are estimated globally using Nielson's minimum-norm network method, and the termination status in `CloughTocherReport` reports whether Gauss–Seidel iteration converged.
Even if gradient estimation fails to converge, interpolation remains a $C^1$ surface matching sample-point values; only vertex-gradient accuracy is reduced.
The ordinary form `CloughTocherInterpolator::new` returns an error on nonconvergence, so this comparison, which counts nonconverged cases, uses the detailed form `with_options` returning an interpolator with a report.
It has no scale input like a shape parameter, making it a baseline for measuring the effect of RBF shape-parameter selection.

The next cell receives point count, seed, and regularization from above and computes interior leave-one-out and independent-grid errors for the specified-shape RBF and Clough–Tocher.
Clough–Tocher is also reconstructed from its Delaunay triangulation for every omitted point.
Errors for the same omitted point are paired, so also compare the mean and 1.96 SE of squared-error differences $d_i=e_{\mathrm{RBF},i}^2-e_{\mathrm{CT},i}^2$.
The input is shape-parameter exponent $k$ ($\epsilon=2^{k/2}$).
Default $k=3$ ($\epsilon\approx2.83$) is the candidate minimizing $E_{\mathrm{CV}}$ with the previous cell's defaults.
The first table shows both methods' $E_{\mathrm{CV}}$, intervals, $E_{\mathrm{test}}$, and counts of gradient-estimation nonconvergence; the second shows paired differences.

let count = scan["count"].as_u64().ok_or("Missing point count")? as usize;

let sites = stations(count, seed).map_err(|e| e.to_string())?;

let lambda = RealScalar::powi(10.0, exponent as i32);
let options = rbf_options(RbfRegularization::Diagonal(lambda)).map_err(|e| e.to_string())?;
let policy = ExtrapolationPolicy::Reject;
// Construct an RBF from the supplied points and return values at query points
let rbf = |points: &[[f64; 2]], data: &[f64], queries: &[[f64; 2]]| {

        .iter()
        .map(|&q| model.evaluate(q, policy))
        .collect::<Result<Vec<_>, SciOxideError>>()
};

        CloughTocherInterpolator::with_options(&mesh, &samples, CloughTocherOptions::new())?;

        .collect::<Result<Vec<_>, SciOxideError>>()?;

Clough–Tocher gradient estimation converges in all 20 omitted-point fits and the full-point fit.

Clough–Tocher, without a shape parameter, provides a baseline when the RBF parameter is poorly chosen, but which method is better depends on point count and configuration.

## Summary

Interpolation through samples leaves nearly zero sample residuals, so choose shape parameters using errors outside the sample set, such as leave-one-out errors.
Leave-one-out error is an estimate depending on point configuration and count; compare candidates with 95% intervals and avoid conclusions about differences between overlapping intervals.
Gaussian RBF conditioning worsens rapidly as $\epsilon$ decreases; diagonal regularization $\lambda$ keeps reciprocal condition numbers at least $\lambda/(\sqrt n(n+\lambda))$ but relaxes sample matching.
A reciprocal-condition estimate indicates only whether the system can be solved stably, not approximation accuracy.
Comparison with a method lacking a scale input, such as Clough–Tocher, reveals how strongly shape-parameter selection affects accuracy.
