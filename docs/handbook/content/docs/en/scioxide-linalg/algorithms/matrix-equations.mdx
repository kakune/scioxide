Linear equations with matrix unknowns arise in controllability and observability, stability tests, model reduction, and optimal control design.
This page explains existence conditions and computational algorithms for Sylvester, Lyapunov, and nonlinear algebraic Riccati equations, `scioxide-linalg` one-shot functions and plans, acceptance tests, and diagnostics.
All these solvers use [Schur](../eigenproblems/) or [QZ decomposition](../generalized-eigenproblems/).

## Sylvester equations and Bartels–Stewart

For $A \in \mathbb{K}^{m \times m}$, $B \in \mathbb{K}^{n \times n}$, $C \in \mathbb{K}^{m \times n}$, and sign $s = \pm 1$, Sylvester equation $AX + sXB = C$ is equivalent to the following linear system for the vector of entries of $X$:

$$
(I_n \otimes A + s\, B^{\mathsf T} \otimes I_m)\, \operatorname{vec}(X) = \operatorname{vec}(C)
$$


The coefficient eigenvalues are $\lambda_i(A) + s\,\mu_j(B)$, so the solution is unique exactly when no pair satisfies $\lambda_i + s\,\mu_j = 0$ (for $s = 1$, $A$ and $-B$ share no eigenvalue).
Forming and solving the $mn \times mn$ matrix costs $O(m^3 n^3)$; Bartels–Stewart instead computes Schur decompositions $A = Q_A T_A Q_A^{\mathsf H}$ and $B = Q_B T_B Q_B^{\mathsf H}$, solves triangular $T_A Y + s\,Y T_B = Q_A^{\mathsf H} C Q_B$ by substitution, and transforms back as $X = Q_A Y Q_B^{\mathsf H}$.
Cost is $O(m^3 + n^3)$ for Schur decompositions plus $O(m^2 n + m n^2)$ for each right-hand-side transformation and substitution.
For real matrices, `scioxide-linalg` uses real Schur forms with $1 \times 1$ and $2 \times 2$ diagonal blocks, grouping substitution into regions of order at most 32 and updating between regions by matrix products.
Solve other orientations such as $A^{\mathsf T} X + XB = C$ by passing transposed or adjoint coefficient views.

Separation $\operatorname{sep}(A, -sB) = \min_{X \ne 0} \lVert AX + sXB \rVert_F / \lVert X \rVert_F$ determines solution sensitivity.
Perturbing coefficients by $\lVert \Delta A \rVert_F \le \epsilon \lVert A \rVert_F$, $\lVert \Delta B \rVert_F \le \epsilon \lVert B \rVert_F$, and $\lVert \Delta C \rVert_F \le \epsilon \lVert C \rVert_F$ gives $A\,\Delta X + s\,\Delta X\,B = \Delta C - \Delta A\,X - s X\,\Delta B + O(\epsilon^2)$ from the perturbed equation and the textbook bound in Higham, *Accuracy and Stability of Numerical Algorithms*, Chapter 16:

$$
\frac{\lVert \Delta X \rVert_F}{\lVert X \rVert_F} \le \epsilon\, \frac{(\lVert A \rVert_F + \lVert B \rVert_F) \lVert X \rVert_F + \lVert C \rVert_F}{\operatorname{sep}(A, -sB)\, \lVert X \rVert_F} + O(\epsilon^2) \le 2\epsilon\, \frac{\lVert A \rVert_F + \lVert B \rVert_F}{\operatorname{sep}(A, -sB)} + O(\epsilon^2)
$$

The last inequality follows from $\lVert C \rVert_F \le (\lVert A \rVert_F + \lVert B \rVert_F) \lVert X \rVert_F$.
Ratio $(\lVert A \rVert_F + \lVert B \rVert_F) / \operatorname{sep}$ indicates conditioning; as an upper bound from repeated triangle inequalities, it may overestimate true sensitivity.
$\operatorname{sep}$ is at most minimum eigenvalue gap $\min_{i,j} \lvert \lambda_i + s\,\mu_j \rvert$, equal for normal $A$ and $B$ but potentially far smaller for nonnormal matrices.

Calling forms such as one-shot functions, plans, and caller-provided-output APIs are named in [Workspaces, execution contexts, and attempt records](oxref:linalg-execution-forms).
One-shot `solve_sylvester(&a, &b, SylvesterSign::Plus, &c)` returns $X$ ($AX - XB = C$ for `Minus`); solutions rejected by residual tests give an `NumericalInstability` (`LossOfSignificance`) error.
For repeated solves changing right-hand sides with fixed coefficients, plan `SylvesterPlan::new(&a, &b, sign, options)` prepares two Schur decompositions once and solves per right-hand side through `solve(&c)` (`build(..., cx)` counts preparation iterations as nested work in context `cx`).
`solve(&c)` returns `MatrixEquationResult`; `solution()` returns only accepted solutions as `Some`, `report()` returns report `MatrixEquationReport`, and `into_accepted()` returns a solution or error.
Caller-provided-output `solve_into(&c, out, &mut ws, cx)` uses `LinalgWorkspace` of `plan.workspace(())` (sized through `workspace_requirements(())`), leaving `out` unchanged on rejection.

Rejected candidates are not committed, but diagnostics remain in reports.
Report `termination()` uses direct-method termination reason `DirectSolveTermination`, either `Accepted` or `ResidualRejected` for Sylvester/Lyapunov; this value alone determines acceptance.
Acceptance uses the original-equation residual $R = T_1 + T_2 + T_3$ (for Sylvester, $T_1 = AX$, $T_2 = sXB$, $T_3 = -C$) and tests

$$
\lVert R \rVert_F \le \tau_{\mathrm{abs}} + \tau_{\mathrm{rel}} \left( \lVert T_1 \rVert_F + \lVert T_2 \rVert_F + \lVert T_3 \rVert_F \right)
$$

where `residual()` returns $\lVert R \rVert_F$ and `backward_error()` returns its ratio to the parenthesized right-hand-side quantity (backward error).
`separation()` is a 1-norm version of separation, estimating $1/\lVert L^{-1} \rVert_1$ for the Schur-coordinate equation operator $L$ ($L(Y) = T_A Y + s\,Y T_B$ for Sylvester).
Since $\lVert L^{-1} \rVert_1$ is estimated from below by Hager–Higham (exact for at most four unknowns), the report may exceed true 1-norm separation and does not guarantee sensitivity.
It is `None` when estimation is disabled with `Estimation::Skip` or for empty equations, and zero if estimation did not finish.
`work()` measures work for transformations, substitution, separation estimation, and residual checks.
Defaults in `MatrixEquationOptions` are residual tolerance $\tau_{\mathrm{abs}} = \tau_{\mathrm{rel}} = \sqrt{\varepsilon_{\mathrm{mach}}}$ (`with_tolerance`), separation estimation enabled (`with_separation(Estimation::Estimate)`), and one million work units per solve (changed with `LinalgExecutionOptions::with_iteration_budget`).
Exceeding work limits gives `ConvergenceFailure`; floating-point violation of solvability producing exactly zero diagonal-block equation pivots gives `Singular`.
Explicit iteration limits also bound QR iterations in Schur decompositions during plan preparation.
Without an explicit limit, these permit $30\max(n, 1)$ iterations, usually taking about two per eigenvalue; smaller limits cause plan construction to fail.

## Lyapunov equations and Gramians

Continuous-time Lyapunov equation $AX + XA^{\mathsf H} = Q$ is Sylvester with $B = A^{\mathsf H}$, uniquely solvable when $\lambda_i + \overline{\lambda_j} \ne 0$ for all eigenvalue pairs.
For stable $A$ (all eigenvalues have negative real parts), the solution is

$$
X = -\int_0^{\infty} e^{At}\, Q\, e^{A^{\mathsf H} t}\, dt
$$


For stable $A$ and $Q = -BB^{\mathsf H}$, solution $X = \int_0^\infty e^{At} BB^{\mathsf H} e^{A^{\mathsf H}t}\, dt$ is the positive-semidefinite controllability Gramian; positive definiteness is equivalent to controllability of system $(A, B)$.
Discrete-time equation $AXA^{\mathsf H} - X + Q = 0$ (Stein equation) is uniquely solvable when $\lambda_i \overline{\lambda_j} \ne 1$, satisfied when every eigenvalue of $A$ lies inside the unit circle.

One-shot `solve_lyapunov(&a, LyapunovKind::Continuous, &q)` (`Discrete` for discrete time) returns $X$.
Plan `LyapunovPlan::new(&a, kind, options)` computes $A$'s Schur decomposition once in $O(n^3)$ and reuses it on both sides; `solve(&q)` solves each right-hand side in $O(n^3)$.
Pass an adjoint view of $A$ to solve $A^{\mathsf H} X + XA = Q$.
If $Q$ is exactly Hermitian, replaces the computed solution with Hermitian part $(X + X^{\mathsf H})/2$ before checking residuals; report `symmetry_defect()` gives preprojection departure $\max_{ij} \lvert x_{ij} - \overline{x_{ji}} \rvert$ (`None` for Sylvester).
Acceptance and reports follow Sylvester equations.

The following cell solves the continuous-time equation ($Q = -I$) for damped oscillator $A = \begin{bmatrix} -\delta & \omega \\ -\omega & -\delta \end{bmatrix}$ and the discrete-time equation ($Q = I$) for $A_d = (1 - \delta) R(\omega)$ ($R(\omega)$ rotates by angle $\omega$ [rad]), using `LyapunovPlan`.
Both solutions are scalar multiples of the identity: $X = I/(2\delta)$ in continuous time and $X = I/(1 - (1-\delta)^2)$ in discrete time, diverging as $\delta \to 0$ approaches the stability boundary.
The table shows solution entry $(1,1)$, closed form, relative difference over all entries (maximum divided by the closed-form value), backward error, separation estimate, and termination reason; the outcome indicates whether both were accepted.

With defaults $\delta = 10^{-3}$ and $\omega = 1$, the two solutions agree with closed forms within relative differences $2.3 \times 10^{-16}$ and $1.9 \times 10^{-15}$; backward errors are at most $10^{-16}$ and both reach `Accepted`.
The 1-norm separation estimate need not equal Frobenius separation $2\delta$, but both equations here give $2.0 \times 10^{-3}$, indicating distance to the stability boundary.
At $\delta = 10^{-8}$, solutions reach $5 \times 10^{7}$, separation estimates shrink to $2.0 \times 10^{-8}$, and discrete-solution relative difference grows to $5.8 \times 10^{-9}$.
For the discrete equation, perturbing $A$ changes $AXA^{\mathsf H}$ by at most $2\epsilon \lVert A \rVert_2 \lVert A \rVert_F \lVert X \rVert_F$; this example has $\lVert A \rVert_2 \approx 1$, so the preceding estimate $(\lVert A \rVert_F + \lVert A^{\mathsf H} \rVert_F)/\operatorname{sep} \approx 1.4 \times 10^{8}$ applies directly.
Multiplying by unit roundoff $1.1 \times 10^{-16}$ gives relative-error guide $1.6 \times 10^{-8}$; observed relative differences lie within it, while backward error remains small at $6.4 \times 10^{-19}$ and acceptance stays `Accepted`.
Small backward error only means the solution exactly solves slightly perturbed coefficients; small forward error depends on separation.
The continuous solution is exact here because $X$ is a scalar multiple of the identity and rounding errors cancel; general matrices may exhibit comparable errors.
At $\delta = 1$, the discrete-time coefficient matrix vanishes and the solution is the identity; estimated separations are 1.33 continuous and 1.0 discrete.

## Algebraic Riccati equations

The optimal regulator $\min \int_0^\infty (x^{\mathsf H} Q x + u^{\mathsf H} R u)\, dt$ ($\dot x = Ax + Bu$) has solution $u = -Kx$, $K = R^{-1} B^{\mathsf H} X$, where $X$ is the stabilizing solution of the continuous algebraic Riccati equation (CARE)

$$
A^{\mathsf H} X + X A - X B R^{-1} B^{\mathsf H} X + Q = 0
$$

meaning that all eigenvalues of $A - BK$ lie in the open left half-plane.
For $Q \succeq 0$ and $R \succ 0$, a stabilizing solution exists exactly when $(A, B)$ is stabilizable and $(Q, A)$ has no unobservable eigenvalues on the imaginary axis.
When it exists, the stabilizing solution is unique and positive-semidefinite.
If $(Q, A)$ is detectable, it is also the unique positive-semidefinite solution.

Although quadratic in $X$, it becomes an eigenproblem through Hamiltonian matrix $H = \begin{bmatrix} A & -BR^{-1}B^{\mathsf H} \\ -Q & -A^{\mathsf H} \end{bmatrix}$.
CARE is equivalent to $H \begin{bmatrix} I \\ X \end{bmatrix} = \begin{bmatrix} I \\ X \end{bmatrix} (A - BK)$; for a stabilizing solution, eigenvalues of $A - BK$ are the stable eigenvalues of $H$.
Eigenvalues of $H$ occur in pairs $\lambda$ and $-\bar\lambda$, so exactly $n$ are stable when none lie on the imaginary axis.
Writing their invariant subspace as $\operatorname{span}\begin{bmatrix} U_1 \\ U_2 \end{bmatrix}$ gives $X = U_2 U_1^{-1}$ if $U_1$ is nonsingular.

`RiccatiPlan` handles general forms including descriptor $E$ and cross-term $S$; `RiccatiKind::Continuous` uses $A^{\mathsf H} X E + E^{\mathsf H} X A - (E^{\mathsf H} X B + S) R^{-1} (B^{\mathsf H} X E + S^{\mathsf H}) + Q = 0$ and $K = R^{-1}(B^{\mathsf H} X E + S^{\mathsf H})$, while discrete-time `Discrete` uses $A^{\mathsf H} X A - E^{\mathsf H} X E - (A^{\mathsf H} X B + S)(R + B^{\mathsf H} X B)^{-1}(B^{\mathsf H} X A + S^{\mathsf H}) + Q = 0$ and $K = (R + B^{\mathsf H} X B)^{-1}(B^{\mathsf H} X A + S^{\mathsf H})$.
Here too, stabilizing solutions place eigenvalues of closed-loop pencil $(A - BK, E)$ in the open left half-plane, or the open unit disk in discrete time.

Preparation constructs extended pencil $\mathcal{H} - \lambda \mathcal{J}$ of order $2n + m$, retaining control unknowns $u$.
CARE has the following form; eliminating $u$ from third row $S^{\mathsf H} x + B^{\mathsf H} \mu + R u = 0$ of $(x, \mu, u)$ recovers the eigenproblem $H \begin{bmatrix} x \\ \mu \end{bmatrix} = \lambda \begin{bmatrix} x \\ \mu \end{bmatrix}$ for $H$ above when $E = I$ and $S = 0$ (DARE uses an analogous pencil).

$$
\mathcal{H} = \begin{bmatrix} A & 0 & B \\ -Q & -A^{\mathsf H} & -S \\ S^{\mathsf H} & B^{\mathsf H} & R \end{bmatrix}, \qquad
\mathcal{J} = \begin{bmatrix} E & 0 & 0 \\ 0 & E^{\mathsf H} & 0 \\ 0 & 0 & 0 \end{bmatrix}
$$

Working directly with the pencil instead of eliminating $u$ avoids forming potentially ill-conditioned $R^{-1}$ or $(R + B^{\mathsf H} X B)^{-1}$.
After optional balancing, column-pivoted QR of $[B; -S; R]$ removes the last $m$ columns; QZ reduces the remaining $2n \times 2n$ pencil to generalized Schur form, reordering $n$ stable eigenvalues (negative real parts in continuous time, magnitude below 1 in discrete time) first.
Pencil eigenvalues occur in continuous pairs $\lambda$ and $-\bar\lambda$ or discrete pairs $\lambda$ and $1/\bar\lambda$ (Hamiltonian and symplectic structures).
Recover $X = U_2 (E U_1)^{-1}$ from the first $n$ right Schur columns $[U_1; U_2]$; preparation costs $O((n + m)^3)$.
Stabilizability and detectability are caller assumptions, not checked by the plan.
If the computed spectrum does not separate by the stability tolerance into $n$ stable and $n$ unstable eigenvalues (eigenvalues near the imaginary axis or unit circle, stable count other than $n$, $0/0$ eigenvalues, or subspace reciprocal-condition estimate at or below $\varepsilon_{\mathrm{mach}}$), preparation gives `NumericalInstability` (`IllConditioned`).
$Q$ or $R$ not exactly Hermitian gives `InvalidInput`.

For one state and one input with $E = 1$, $S = 0$, $Q > 0$, $R > 0$, and $B \ne 0$, computes the unique positive quadratic root without forming a pencil, applying the same stability test.
Selects roots using the cancellation-free side of the quadratic formula and the product of roots; coefficient products use an extended exponent range.
This path neither balances nor computes subspaces, reporting state scale `state_scaling()` as 1, subspace reciprocal conditioning as 1, and symmetry departure as zero.
Other cases use reordered QZ of the balanced pencil.
Default balancing `RiccatiBalancing::Scale` is a power-of-two similarity using permutation-free Parlett–Reinsch iteration to balance off-diagonal row/column sums of $\lvert \mathcal{H} \rvert + \lvert \mathcal{J} \rvert$, giving costates reciprocal state scales while preserving control scales (Benner's symplectic balancing).
`state_scaling()` returns diagonal $d$ of state scaling $x = Dz$; $X$ and $K$ always return in original coordinates.

One-shot `solve_riccati(problem, kind)` returns accepted $(X, K)$.
Unlike default `RiccatiOptions`, it recomputes eigenvalues of closed-loop pencil $(A - BK, E)$ by QZ ($O(n^3)$), requiring each eigenvalue's stability margin to exceed the stability tolerance in addition to residual acceptance.
Prepare plan `RiccatiPlan::new(problem, kind, options)` with `RiccatiProblem` (views of $A, B, Q, R$ and optional $E, S$); `solve()` returns result `RiccatiResult`.
Caller-provided-output `solve_into(x, k, &mut ws, cx)` uses `LinalgWorkspace` of `workspace(())`.
Each solve recovers $X$, checks Hermitian departure against residual tolerance, replaces it by $(X + X^{\mathsf H})/2$ (excess gives `NumericalInstability`), computes $K$, and checks original-equation residuals.
Residual acceptance uses a ratio to the sum of Frobenius norms of four terms $T_1 + T_2 + T_3 + T_4$ (continuous $A^{\mathsf H} X E$, $E^{\mathsf H} X A$, $-(E^{\mathsf H} X B + S) K$, $Q$), matching the Sylvester form.
`RiccatiOptions` selects residual tolerance (default $\sqrt{\varepsilon_{\mathrm{mach}}}$), distance tolerance `with_stability_tolerance` from the imaginary axis/unit circle (default $\tau_{\mathrm{abs}} = \tau_{\mathrm{rel}} = \varepsilon_{\mathrm{mach}}$), balancing `with_balancing` (`RiccatiBalancing::{None, Scale}`; default `Scale`), and `with_closed_loop_verification(Estimation::Estimate)` for checking closed-loop eigenvalues with a separate QZ ($O(n^3)$), disabled by default.
QZ and reordering each permit 30 000 iterations, changed through the iteration limit of `LinalgExecutionOptions` incorporated with `with_execution_options`.

Result `solution()` and `gain()` return `Some` only on acceptance; `report()` returns report `RiccatiReport`.
Report `termination()` is one of `DirectSolveTermination`'s `Accepted`, `ResidualRejected`, or `StabilityRejected`; `StabilityRejected` takes precedence if both checks fail.
`into_accepted()` and one-shot functions turn rejection into `NumericalInstability` errors: `IllConditioned` for stability rejection and `LossOfSignificance` for residual rejection (one-shot always checks closed-loop stability, so either can occur).
Assess solutions together with residual `residual()`, backward error `backward_error()`, symmetry departure `symmetry_defect()`, subspace reciprocal condition number `subspace_reciprocal_condition()` (the smaller of $E U_1$'s 1-norm reciprocal-condition estimate and $U_1$'s smallest singular value, between 0 and 1), and stability margin `stability_margin()` when closed-loop checks are requested.
Eigenvalue $\lambda = \alpha/\beta$ has stability margin $-\operatorname{Re}(\alpha) / \max(\lvert\alpha\rvert, \lvert\beta\rvert)$ in continuous time or $(\lvert\beta\rvert - \lvert\alpha\rvert) / \max(\lvert\alpha\rvert, \lvert\beta\rvert)$ in discrete time; the report gives the minimum over all eigenvalues.
Both range from $-1$ to $1$, with positive values stable; infinite eigenvalues ($\beta = 0$) give $-1$.
Work `work()` counts solution recovery, residual verification, optional closed-loop verification, and nested iterations, excluding preparation.

//|       - {"artifact":"riccati","path":"/rows/0/1","approx":{"value":2.414213562373095,"rtol":1e-12}}
//|       - {"artifact":"riccati","path":"/rows/2/1","approx":{"value":-1.4142135623730951,"rtol":1e-12}}

    Estimation, Matrix, RiccatiKind, RiccatiOptions, RiccatiPlan, RiccatiProblem,
};

let one = |v: f64| Matrix::from_rows(&[[v]]).map_err(|e| e.to_string());

    a: am.view(),
    b: bm.view(),
    q: qm.view(),
    r: rm.view(),
    e: None,
    s: None,
};

    RiccatiPlan::new(problem, RiccatiKind::Continuous, options).map_err(|e| e.to_string())?;

let report = result.report();
// Closed form (b = 1): x = r(a + √(a² + q/r)), K = x/r, pole a − K = −√(a² + q/r).
let root = (a * a + q / r).sqrt();
let (x_exact, k_exact) = (r * (a + root), a + root);
// Rejected solutions and gains are not committed, leaving computed values and relative differences empty.
let x = result.solution().map(|x| x.as_slice()[0]);
let k = result.gain().map(|k| k.as_slice()[0]);
// Relative differences are undefined for zero closed forms (x and K when q = 0, a < 0).
let relative = |value: Option<f64>, exact: f64| {
    value
        .filter(|_| exact != 0.0)
        .map(|v| (v - exact).abs() / exact.abs())
};
let pole = k.map(|k| a - k);
let rows = vec![
    ("x", x, x_exact, relative(x, x_exact)),
    ("K", k, k_exact, relative(k, k_exact)),

]);

    columns,
    rows,
    metadata = serde_json::json!({ "id": "riccati" })
);

let diagnostics = vec![(
    direct_termination_name(termination),
    report.backward_error(),
    report.subspace_reciprocal_condition(),
    report.stability_margin(),
    plan.state_scaling()[0],
)];
let digits3 = serde_json::json!({ "significantDigits": 3 });
let digits4 = serde_json::json!({ "significantDigits": 4 });
let diagnostic_columns = serde_json::json!([
    { "key": "0", "label": "Termination reason" },

        "key": "3",

        "format": digits4,

    },

]);

    diagnostic_columns,
    diagnostics,
    metadata = serde_json::json!({ "id": "diagnostics" })

    Outcome::satisfied("The stabilizing solution passed residual and closed-loop checks")
} else {
    Outcome::failed("The solution failed residual or closed-loop checks")
};
let mut outcome = outcome
    .status(direct_termination_name(termination))
    .diagnostic("Backward error", report.backward_error(), None);
if let Some(margin) = report.stability_margin() {
    outcome = outcome.diagnostic("Stability margin", margin, None);
}
emit_outcome!(outcome);

## Summary

Sylvester equations have unique solutions when $\lambda_i + s\,\mu_j \ne 0$; Bartels–Stewart uses two Schur decompositions and triangular substitution, costing $O(m^3 + n^3)$ preparation and $O(m^2 n + mn^2)$ per right-hand side.
Separation $\operatorname{sep}$ determines sensitivity; near Lyapunov stability boundaries separation shrinks and solutions grow, so inspect reported separation estimates.
Algebraic Riccati equations use stable deflating subspaces from reordered QZ of extended pencils; existence conditions such as stabilizability remain caller assumptions because plans do not check them.
For single solves, one-shot functions (`solve_sylvester`, `solve_lyapunov`, `solve_riccati`) suffice, with rejection as errors.
`solve_riccati` also verifies closed-loop stability.
Plans' `solve` checks original-equation residuals without committing rejected candidates; assess solutions using `termination()`, backward error, separation, and stability margins rather than treating `Ok` as acceptance.
