Solutions $x(t) = e^{tA}x(0)$ of linear ODEs $\dot x = Ax$, quantum time evolution $e^{-iHt}$, control discretization, and continuous-time Markov transition probabilities use matrix exponentials.
Other matrix functions, including logarithms, square roots, and powers, serve matrix interpolation, rotation averaging, and equation transformations.
This page explains matrix-function definitions, `scioxide-linalg` computational algorithms and calling forms, sensitivity through Fréchet derivatives and condition numbers, and sparse matrix powers and functions.
Sylvester, Lyapunov, and Riccati equations are covered on the [next page](../matrix-equations/).

## Definitions and principal values

Extend scalar function $f$ to matrices as follows: if $f$ has power series $\sum c_k z^k$ whose convergence disk contains every eigenvalue of $A$, set $f(A) = \sum c_k A^k$; if diagonalizable as $A = V \Lambda V^{-1}$, set $f(A) = V f(\Lambda) V^{-1}$.
When both apply, they give the same matrix.
For nondiagonalizable matrices, define $f(A) = Z f(J) Z^{-1}$ using Jordan form $A = Z J Z^{-1}$; for $J = \lambda I + \nu N$ of $2 \times 2$ ($N = \begin{bmatrix} 0 & 1 \\ 0 & 0 \end{bmatrix}$, $N^2 = 0$), Taylor terms of degree two and above vanish, giving

$$
f(J) = f(\lambda) I + \nu f'(\lambda) N
$$


A large condition number of $V$ makes computing $V f(\Lambda) V^{-1}$ unstable, so practical algorithms avoid eigenvectors.

Logarithms, square roots, and noninteger powers are multivalued; `scioxide-linalg` returns principal values.
The principal logarithm has eigenvalue imaginary parts in $(-\pi, \pi)$ and is undefined when $A$ has eigenvalues on the closed nonpositive real axis $(-\infty, 0]$.
The principal square root has eigenvalues with nonnegative real parts, mapping negative real eigenvalue $\lambda$ to scalar principal value $i\sqrt{\lvert\lambda\rvert}$.
Zero imaginary parts are treated as $+0$, so $x - 0i$ also maps to $i\sqrt{\lvert x \rvert}$, although IEEE `csqrt` returns $-i\sqrt{\lvert x \rvert}$.
Real-matrix functions may be complex; real outputs are accepted only when imaginary parts lie within tolerance, reporting their discarded magnitude.

## Computational algorithms

| Function | `MatrixFunction` | Algorithm |
|---|---|---|
| Exponential | `Exp` | Padé approximants of degrees 3, 5, 7, 9, 13 with scaling and squaring directly on $A$ (Al-Mohy–Higham 2009, Algorithm 6.1). No Schur decomposition |
| Logarithm | `Log` | Inverse scaling and squaring by repeated square roots on Schur form (real Schur for real matrices) until $\lVert T - I \rVert_1 \le 1/4$; Padé approximation of $\log(I + X)$ evaluated by 8-point Gauss–Legendre quadrature (4-point for `f32`). Diagonal blocks come directly from eigenvalues |
| Square root | `Sqrt` | Recurrence on Schur form determining upper-triangular square-root entries outward from the diagonal, blocked into order-32 regions without splitting $2 \times 2$ blocks. Uses real Schur form for real matrices without negative real eigenvalues |
| Power | `Power(p)` | Integer $p$ uses binary powering of Schur factors (inverts first for negative powers), without branch cuts. Integers $\lvert p \rvert \ge 2^{62}$ split as $p = m 2^k$ ($\lvert m \rvert < 2^{62}$), squaring $A^m$ $k$ times. Otherwise $\exp(p \log A)$ |
| Sign | `Sign` | Parlett recurrence on complex Schur form (using $\operatorname{sign}(T)^2 = I$). No eigenvalues on the imaginary axis |
| Trigonometric/hyperbolic | `Sin`, `Cos`, `Tan`, `Sinh`, `Cosh`, `Tanh` | Schur–Parlett (Davies–Higham) on complex Schur form with exact Taylor coefficients. `Tan` and `Tanh` give `Singular` for exactly zero diagonals of triangular $\cos(T)$ or $\cosh(T)$ |
| Arbitrary analytic | `Analytic(&f)` | Schur–Parlett. Supply $f$ as a `Sync` value implementing `AnalyticMatrixFunction` (convergence radius, Taylor coefficients, remainder bounds) |

Exponential scaling and squaring uses the $[m/m]$-type Padé approximant $r_m$ of $e^{z}$ at $2^{-s}A$, computing $e^{A} \approx r_m(2^{-s}A)^{2^s}$ through $s$ squarings.
In exact arithmetic, the following holds wherever $\log$ is defined.

$$
r_m(2^{-s}A)^{2^s} = e^{A + \Delta A}, \qquad
\Delta A = 2^{s} h_{2m+1}(2^{-s}A), \qquad
h_{2m+1}(X) = \log\bigl(e^{-X} r_m(X)\bigr) = \sum_{k \ge 2m+1} c_k X^k
$$

Thus approximation error is expressible as backward error $\Delta A$ in $A$.
Al-Mohy–Higham selects degree $m \in \{3, 5, 7, 9, 13\}$ and scaling count $s$ from $d_k = \lVert A^k \rVert_1^{1/k}$ to keep the bound on $\lVert \Delta A \rVert_1 / \lVert A \rVert_1$ at or below unit roundoff $u$ ($2^{-53}$ for `f64`).
For nonnormal matrices, $d_k$ can be much smaller than $\lVert A \rVert_1$, avoiding overscaling from choosing by $\lVert A \rVert_1$, which adds squarings and accumulated rounding error.
`scioxide-linalg` computes $d_k$ from 1-norms of computed powers of $A$ rather than estimating it.
This backward error covers Padé truncation, excluding rounding during squaring.

For upper-triangular $T$, $F = f(T)$ is also upper triangular and satisfies $FT = TF$, allowing entries above the diagonal to be determined successively from $f_{ii} = f(t_{ii})$ by the following Parlett recurrence.

$$
f_{ij} = t_{ij} \frac{f_{ii} - f_{jj}}{t_{ii} - t_{jj}} + \sum_{k=i+1}^{j-1} \frac{f_{ik} t_{kj} - t_{ik} f_{kj}}{t_{ii} - t_{jj}}, \qquad i < j
$$

Nearby eigenvalues make denominator $t_{ii} - t_{jj}$ small and strongly amplify error.
Schur–Parlett therefore groups and reorders Schur diagonals connected by eigenvalue distances at most 0.1, evaluates each cluster by Taylor series about its mean eigenvalue, and assembles $f(T)$ by solving between-cluster Sylvester equations generalizing the recurrence above to blocks.
Built-in Taylor series stop when the remainder bound is at most $\varepsilon_{\mathrm{mach}}$ times the current value's 1-norm.
For trigonometric/hyperbolic functions, the remainder bound after $s$ terms on cluster $T_b = cI + D + N$ (diagonal $D$, strictly upper-triangular $N$, order $m$) is

```text
e^(γ+μ) Σ_{k<m} (νᵏ / k!) μ^((s−k)₊) / ((s−k)₊)!
```

(Davies and Higham, 2003, §2).
Here $\mu = \max_i \lvert d_i \rvert$, $\nu = \lVert N \rVert_1$, and $(x)_+ = \max(x, 0)$; $\gamma$ is $\lvert \operatorname{Im} c \rvert$ for $\sin$, $\cos$, and $\tan$, or $\lvert \operatorname{Re} c \rvert$ for hyperbolic functions.
Nonnormality $\nu$ enters only at powers below $m$, so even large $\nu$ in small nonnormal clusters adds only about $m$ terms before termination.
Coefficients and remainder bounds for arbitrary analytic functions are caller-supplied mathematical assumptions; solvers do not verify analyticity, and incorrect values produce incorrect results.

Real matrices transform through orthogonal $Q$ to quasi-upper-triangular real Schur form $Q^{\mathsf T} A Q = T$, with $T$ diagonals containing $1 \times 1$ real-eigenvalue blocks and $2 \times 2$ conjugate-pair blocks.
A real matrix $A$ has a real principal logarithm when its eigenvalues avoid $(-\infty, 0]$ and a real principal square root without negative real eigenvalues, so these use only real arithmetic on real Schur form as in the table.
Other functions use complex Schur form $A = Q T Q^{\mathsf H}$ (unitary $Q$, upper-triangular $T$), discarding small imaginary parts for real output.

## One-shot functions and plans

Calling forms such as one-shot functions, standard forms, caller-provided-output APIs, and plans are named in [Workspaces, execution contexts, and attempt records](oxref:linalg-execution-forms).
One-shot `matrix_function(&a, function)` returns $f(A)$ in a new matrix with the same scalar type as $A$.
It constructs the plan below with defaults and evaluates sequentially with `ExecutionContext::sequential_native()`.
For real matrices whose $f(A)$ is complex (such as square roots with negative real eigenvalues), gives `DomainError` for argument `a`; call with complex matrices or use complex plan output.
Every built-in function costs $O(n^3)$.

Plan `MatrixFunctionPlan::new(&a, function, &options)` prepares one fixed function for repeated values, Fréchet derivatives, and condition numbers at the same $A$ (`build(&a, function, &options, cx)` counts preparation Schur iterations as nested work in context `cx`).
Exponential plans merely retain $A$ without eigenvalue computation; other plans compute and retain the preceding section's real or complex Schur form once in $O(n^3)$.
Spectrum on branch cuts ($(-\infty, 0]$ for logarithms/noninteger powers, imaginary axis for sign) gives `DomainError` for argument `self` during preparation.
`evaluate_into(out, &mut ws, cx)` writes values into $n \times n$ output, which may be real or complex.
Workspace is complex `LinalgWorkspace` constructed through forms such as `plan.workspace(&MatrixFunctionWorkspaceRequest::Evaluate)`, holding about 15 matrices of order $n$ for evaluation or $2n$ for Fréchet derivatives and conditioning; `Condition` workspace also supports the other two operations (`Evaluate` and `Frechet`).

`MatrixFunctionOptions` combines numerical settings `MatrixFunctionSettings` (`with_function_settings`) and execution controls `LinalgExecutionOptions` (`with_execution_options`).
Defaults are tolerance $\tau_{\mathrm{abs}} = \tau_{\mathrm{rel}} = \sqrt{\varepsilon_{\mathrm{mach}}}$ (analytic remainders and discarded imaginary parts in real output) and maximum Taylor degree 256 (`with_series_limit`).
Without an explicit iteration limit, each evaluation permits one million work units, each a block operation such as a matrix product, triangular solve, square-root step, or Taylor term; reaching the limit gives `ConvergenceFailure`.
The same limit also bounds QR iterations in preparation Schur decompositions for `MatrixFunctionPlan`.
Without an explicit limit these permit $30\max(n, 1)$ iterations, usually about two per eigenvalue; smaller limits cause preparation to fail.
Report `MatrixFunctionReport` returns work `work()`, spectrum-to-branch-cut distance `branch_distance()` (to $(-\infty, 0]$ for logarithms, square roots, and noninteger powers; to the imaginary axis for sign; `None` otherwise), maximum discarded imaginary part `imaginary_defect()` for real output, and output componentwise 1-norm `output_norm()` (a `Scaled` value because it may exceed the scalar range).

The following cell computes the exponential, logarithm, and square root of $A = \lambda I + \nu N$ ($\lambda > 0$) through plan caller-provided-output APIs, comparing formula $f(J) = f(\lambda) I + \nu f'(\lambda) N$ above.
Formula $f(\lambda)$ and $f'(\lambda)$ are reference values computed with standard `f64` functions.
Table differences are relative for nonzero entries and absolute for zero entries, reporting their maximum.
The second table applies the exponential to $\log A$ computed by one-shot `matrix_function`, checking recovery of $A$.

```rust
//| id: linalg-matrix-log-jordan
//| ref: linalg-matrix-log-jordan
//| title: "Exponentials, logarithms, and square roots of Jordan blocks"
//| run: reactive
//| crates: [scioxide-core, scioxide-linalg]
//| inputs:
//|   lambda: {"type":"range","label":"Eigenvalue λ [-]","description":"Repeated eigenvalue of A = λI + νN.","min":0.1,"max":10,"step":0.1,"value":2}
//|   nu: {"type":"range","label":"Superdiagonal ν [-]","description":"Off-diagonal magnitude. Zero makes A diagonal.","min":0,"max":10,"step":0.5,"value":1}
//| cases:
//|   - {"id":"near-cut","label":"λ = 0.1","description":"Eigenvalues approach the branch cut; log A's off-diagonal grows to ν/λ = 10.","inputs":{"lambda":0.1}}
//|   - {"id":"diagonal","label":"ν = 0","description":"A becomes diagonal with zero off-diagonal entries.","inputs":{"nu":0}}

//|   - case: default

let functions = [
    ("exp", MatrixFunction::Exp, lambda.exp(), lambda.exp()),
    ("log", MatrixFunction::Log, lambda.ln(), 1.0 / lambda),
    (
        "sqrt",
        MatrixFunction::Sqrt,
        lambda.sqrt(),
        0.5 / lambda.sqrt(),

        .iter()

                p.abs()
            } else {
                (p - q).abs() / q.abs()
            })

    let off_diagonal = out.as_slice()[1];

        name,
        off_diagonal,
        exact[1],
```

With defaults $\lambda = 2$ and $\nu = 1$, all entries of all three functions agree with formulas within $2.4 \times 10^{-16}$, and $\exp(\log A)$ agrees with $A$.
The $A$ for $\nu \ne 0$ is not diagonalizable, preventing use of $V f(\Lambda) V^{-1}$, but eigenvector-free algorithms (directly on $A$ for exponentials, Schur form for logarithms/square roots) handle it.
Logarithm/square-root branch distance equals eigenvalue $\lambda$; exponentials have no branch cut and show “None.”
At $\lambda = 0.1$, branch distance shrinks to 0.1 and the off-diagonal of $\log A$ grows to $\nu / \lambda = 10$, while differences remain at about $2.0 \times 10^{-16}$.
Differences also remain unchanged at $\nu = 10$; the difference between $\exp(\log A)$ and $A$ is $1.2 \times 10^{-14}$.
Work depends on function and $\lVert A \rVert$; larger $\lVert A \rVert$ increases exponential Padé degree and scaling, so with fixed $\nu = 1$, setting $\lambda = 0.1, 2, 10$ increases work to 17, 37, and 39 units.
Square roots take four units for every input.

## Fréchet derivatives and condition numbers

A linear map $E \mapsto L_f(A, E)$ satisfying $f(A + E) = f(A) + L_f(A, E) + o(\lVert E \rVert)$ is the Fréchet derivative; it exists when $f$ is analytic on an open set containing eigenvalues of $A$.
For exponentials, $L_{\exp}(A, E) = \int_0^1 e^{sA} E\, e^{(1-s)A}\, ds$; unless $A$ and $E$ commute, generally $L_{\exp}(A, E) \ne e^{A} E$.
`frechet_into(&e, out, ws, cx)` uses the block-matrix identity

$$
f\left( \begin{bmatrix} A & E \\ 0 & A \end{bmatrix} \right) = \begin{bmatrix} f(A) & L_f(A, E) \\ 0 & f(A) \end{bmatrix}
$$

to compute $L_f(A, E)$ as its upper-right block, costing approximately eight times an evaluation of $f(A)$.
Direction $E$ is scaled by a power of two to match $A$ before evaluation and rescaled afterward, adding no rounding unless result components are subnormal.
Square roots are nondifferentiable when an eigenvalue lies in $(-\infty, 0]$, giving `DomainError` for argument `self`.

Condition numbers measured in componentwise 1-norm $\lVert X \rVert = \sum_{ij} \lvert x_{ij} \rvert$ are

$$
\operatorname{cond}_{\mathrm{abs}}(f, A) = \max_{E \ne 0} \frac{\lVert L_f(A, E) \rVert}{\lVert E \rVert}, \qquad
\operatorname{cond}_{\mathrm{rel}}(f, A) = \frac{\operatorname{cond}_{\mathrm{abs}}(f, A) \lVert A \rVert}{\lVert f(A) \rVert}
$$

The relative condition number is the largest first-order amplification of small relative input perturbations into relative output errors.
`condition_into(out, ws, cx)` writes $f(A)$ and estimates both condition numbers by Hager–Higham 1-norm estimation, using at most 17 applications in total of the Fréchet derivative and its adjoint without forming the $n^2 \times n^2$ derivative matrix.
Result `MatrixFunctionConditionReport`'s `absolute()` is a lower bound on $\operatorname{cond}_{\mathrm{abs}}$ apart from rounding, exact for $n \le 2$; `relative()` is `None` if $f(A) = 0$.
As a lower bound, it may underestimate true conditioning and never gives a certified upper bound.
Adjoint derivatives need real Taylor coefficients, so `condition_into` supports only built-ins and returns `InvalidInput` for `Analytic` functions.

The following cell compares `frechet_into` for nonnormal $A = \begin{bmatrix} -1 & \alpha \\ 0 & -2 \end{bmatrix}$ and direction $E = \begin{bmatrix} 0 & 0 \\ 1 & 0 \end{bmatrix}$ with centered difference $(e^{A + hE} - e^{A - hE}) / (2h)$ ($h = 10^{-1}, \dots, 10^{-13}$).
Centered-difference matrix exponentials use one-shot `matrix_function`.
Centered-difference errors combine truncation $O(h^2)$ and rounding $O(\varepsilon_{\mathrm{mach}} / h)$, so should minimize near $h \approx \varepsilon_{\mathrm{mach}}^{1/3} \approx 6 \times 10^{-6}$.
The table shows entry $(1, 0)$ of $L(A, E)$, differences from incorrect commuting formula $e^{A}E$, minimum centered-difference error and corresponding $h$, and condition estimates; the plot shows errors versus $h$ on logarithmic axes.

## Sparse matrix powers and functions

For sparse $A$, $A^k$ and $f(A)$ generally cease to be sparse.
`SparsePowerPlan::new(a.view(), k, &options)` determines nonzero patterns of $A^k$ and intermediate matrices during preparation through symbolic binary-powering products, without using values (reads only `a`'s pattern, combining duplicate entries).
Starting from the first factor gives $k > 0$ product count $\lfloor \log_2 k \rfloor + \operatorname{popcount}(k) - 1$; $k = 0$ is the identity and $k = 1$ a copy of $A$.
Negative powers factor $A$ by sparse LU, compute $A^{-1}$ columnwise, and set $A^{-k} = (A^{-1})^k$.
$A^{-1}$ is zero outside weakly connected graph components of $A$ but may be dense within them, so its pattern includes every block entry and bounds LU-factor entry counts by the same number.
Settings `SparsePowerOptions` hold only entry limit `with_max_entries` (unlimited by default) and execution controls `with_execution_options`.
Byte limits from `with_execution_options` cover all workspace including intermediate products and LU; iteration limits bound products and LU operations.
Sparse-product parallelism is 1 for `Sequential`, at most 64 for `Auto`, and $\min(n, 64)$ for `Parallel(n)`; results do not depend on parallelism.

`SparseFunctionPlan::new(a.view(), function, &options)` evaluates each connected block of $A$ densely, leaving exact zeros outside blocks.
Each block uses the same algorithm as dense plans.
Output patterns include every block entry, retaining numerically zero values as explicit zeros.
Preparation only finds blocks and creates the output pattern, taking time proportional to stored entries; evaluating blocks of order $b$ costs $O(b^3)$, favoring matrices with small blocks.
Settings `SparseFunctionOptions` hold entry limit `with_max_entries` (unlimited by default), dense numerical settings `with_function_settings`, error estimation `with_error_estimate` (default `Estimation::Skip`), and execution controls `with_execution_options`.
`with_error_estimate(Estimation::Estimate)` returns first-order forward-error indicator $\sum_b \operatorname{cond}_{\mathrm{abs}}(f, A_b) \lVert A_b \rVert \varepsilon_{\mathrm{mach}}$ from the Fréchet condition number of each block $A_b$ ($\lVert A_b \rVert$ is the sum of component magnitudes), not a proven upper bound (unavailable for `Analytic` functions).
Real outputs require real results; obtain complex square roots of real matrices with negative real eigenvalues through `evaluate_into` and complex output.

Both plans reject with `ResourceLimit` during preparation, before numerical computation, when input/intermediate/output entry counts exceed `with_max_entries` or workspace exceeds `LinalgExecutionOptions::with_byte_limit`'s byte limit.
`evaluate(a.view())` computes values using new output/workspace and returns `SparseMaterialization` (CSR `value()` and report `report()`); `a` must match the preparation pattern.
Construct caller-provided-output `evaluate_into(a.view(), &mut out, &mut ws, cx)`'s output with `create_output()`; preallocate workspace `SparseMaterializationWorkspace` through `workspace(())` or `SparseMaterializationRequirements` returned by `workspace_requirements(())` (workspace fits only one plan pattern).
Report `SparseMaterializationReport` gives output-pattern entry count `structural_fill()`, nonzero-value count `nonzero_fill()`, maximum intermediate entry count `peak_intermediate_fill()` (including input), workspace bytes `admitted_workspace_bytes()` checked against limits, work `work()` (sparse-product count for powers, adding $2n$ for negative powers; block-evaluation units for functions), and optional error estimate `estimated_error()`.

The following cell uses two plans for the $k$th power and exponential $e^{A}$ of $A = -L$, modeling one-dimensional heat conduction along $c$ rods of length $m$ ($L$ is order $n = cm$, with each rod's $\operatorname{tridiag}(-1, 2, -1)$ on the diagonal).
Rods are disconnected, so $A$ has $c$ connected blocks, each an $m \times m$ tridiagonal matrix.
$A^k$ has block half-bandwidth $w = \min(k, m - 1)$ and expected entry count $c\,[m(2w + 1) - w(w + 1)]$; $e^{A}$ fills each block, giving $c\,m^2$; compare these predictions with entry limits.
References are repeated dense products for $A^k$ (integer entries, exact) and closed-form block eigendecompositions $e^{A_b} = \sum_{l} e^{\mu_l} v_l v_l^{\mathsf T}$ ($\mu_l = -2 + 2\cos\theta_l$, $(v_l)_p = \sqrt{2/(m+1)} \sin(p\theta_l)$, $\theta_l = l\pi/(m+1)$) for $e^{A}$, computed using standard `f64` functions.
Preparation-rejected computations show `ResourceLimit` in the “Preparation” column and empty report columns.

```rust
//| id: linalg-sparse-power
//| ref: linalg-sparse-power
//| title: "Fill and limits for sparse matrix powers and exponentials"
//| run: reactive
//| crates: [scioxide-core, scioxide-linalg, scioxide-sparse]
//| inputs:
//|   block_order: {"type":"range","label":"Grid points per rod m","description":"Order of one connected block.","min":5,"max":50,"step":5,"value":25}
//|   blocks: {"type":"range","label":"Rod count c","description":"Disconnected block count. n = cm.","min":1,"max":4,"step":1,"value":2}
//|   exponent: {"type":"range","label":"Power k","description":"Compute A^k.","min":1,"max":10,"step":1,"value":4}
//|   max_entries: {"type":"range","label":"Entry-count limit","description":"Entry limit for input, intermediate matrices, and output.","min":100,"max":6000,"step":100,"value":2000}
//| cases:
//|   - {"id":"one-rod","label":"c = 1, m = 50","description":"For one rod, e^A becomes dense with 2500 entries, rejected by limit 2000.","inputs":{"blocks":1,"block_order":50}}
//|   - {"id":"dense-blocks","label":"m = 5, k = 10","description":"For k ≥ m − 1, A^k also fills every block.","inputs":{"block_order":5,"exponent":10}}
//|   - {"id":"tight-limit","label":"Limit 300","description":"The predicted 410 entries of A^k also exceed the limit; both are rejected during preparation.","inputs":{"max_entries":300}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"fill","path":"/rows/0/1","equals":410}
//|       - {"artifact":"fill","path":"/rows/0/3","equals":410}
//|       - {"artifact":"fill","path":"/rows/0/5","equals":2}
//|       - {"artifact":"fill","path":"/rows/0/7","range":{"max":0}}
//|       - {"artifact":"fill","path":"/rows/1/3","equals":1250}
//|       - {"artifact":"fill","path":"/rows/1/7","range":{"max":1e-14}}
//|   - case: one-rod
//|     expect:
//|       - {"artifact":"fill","path":"/rows/0/2","equals":"Prepared"}
//|       - {"artifact":"fill","path":"/rows/1/2","equals":"ResourceLimit"}
//|       - {"artifact":"fill","path":"/rows/1/3","equals":null}
//|       - {"artifact":"fill","path":"/rows/0/7","range":{"max":0}}
//|   - case: dense-blocks
//|     expect:
//|       - {"artifact":"fill","path":"/rows/0/3","equals":50}
//|       - {"artifact":"fill","path":"/rows/1/3","equals":50}
//|       - {"artifact":"fill","path":"/rows/1/7","range":{"max":1e-14}}
//|   - case: tight-limit
//|     expect:
//|       - {"artifact":"fill","path":"/rows/0/1","range":{"min":301}}
//|       - {"artifact":"fill","path":"/rows/0/2","equals":"ResourceLimit"}
//|       - {"artifact":"fill","path":"/rows/1/2","equals":"ResourceLimit"}
use scioxide_core::SciOxideErrorKind;
use scioxide_linalg::{
    Estimation, Matrix, MatrixFunction, SparseFunctionOptions, SparseFunctionPlan,
    SparsePowerOptions, SparsePowerPlan,
};
use scioxide_sparse::{ExplicitZeroPolicy, sparse_diagonals};

let (m, c, k) = (
    block_order.round() as usize,
    blocks.round() as usize,
    exponent.round() as usize,
);
let n = c * m;
// A = −L: diagonal −2, neighbors 1. Zero and drop entries across rod boundaries (i a multiple of m).
let off: Vec<f64> = (1..n).map(|i| if i % m == 0 { 0.0 } else { 1.0 }).collect();
let a = sparse_diagonals(n, n, &[0, 1, -1], &[&vec![-2.0; n][..], &off, &off])
    .and_then(|a| a.view().to_csr(ExplicitZeroPolicy::Drop))
    .map_err(|e| e.to_string())?;
let w = k.min(m - 1);
let predicted = [c * (m * (2 * w + 1) - w * (w + 1)), c * m * m];
// Reference: repeated dense products for A^k; block eigendecompositions for e^A (standard f64 functions).
let dense = Matrix::from_csr(&a).map_err(|e| e.to_string())?;
let mut power = dense.clone();
for _ in 1..k {
    power = power.view().mul_mat(&dense).map_err(|e| e.to_string())?;
}
let theta = |l: usize| l as f64 * std::f64::consts::PI / (m + 1) as f64;
let heat = |i: usize, j: usize| -> f64 {
    if i / m != j / m {
        return 0.0;
    }
    let (p, q) = ((i % m + 1) as f64, (j % m + 1) as f64);
    let terms = (1..=m).map(|l| {
        let mode = (p * theta(l)).sin() * (q * theta(l)).sin();
        mode * (-2.0 + 2.0 * theta(l).cos()).exp()
    });
    2.0 / (m + 1) as f64 * terms.sum::<f64>()
};
let exponential = Matrix::from_vec(n, n, (0..n * n).map(|x| heat(x / n, x % n)).collect())
    .map_err(|e| e.to_string())?;
let limit = max_entries.round() as usize;
let power_options = SparsePowerOptions::new().with_max_entries(limit);
let function_options = SparseFunctionOptions::new()
    .with_max_entries(limit)
    .with_error_estimate(Estimation::Estimate);
let results = [
    SparsePowerPlan::new(a.view(), k as i64, &power_options).and_then(|p| p.evaluate(a.view())),
    SparseFunctionPlan::new(a.view(), MatrixFunction::Exp, &function_options)
        .and_then(|p| p.evaluate(a.view())),
];
let names = ["A^k（SparsePowerPlan）", "e^A（SparseFunctionPlan）"];
let references = [&power, &exponential];
let mut rows = Vec::new();
for (index, result) in results.into_iter().enumerate() {
    let (name, expected) = (names[index], predicted[index]);
    match result {
        // Computations exceeding entry or byte limits are rejected before numerical computation.
        Err(e) if e.kind() == SciOxideErrorKind::ResourceLimit => {
            rows.push((
                name,
                expected,
                "ResourceLimit",
                None,
                None,
                None,
                None,
                None,
            ));
        }
        Err(e) => return Err(e.to_string()),
        Ok(result) => {
            let report = result.report();
            let computed = Matrix::from_csr(result.value()).map_err(|e| e.to_string())?;
            let gap = computed
                .as_slice()
                .iter()
                .zip(references[index].as_slice())
                .fold(0.0_f64, |acc, (p, q)| acc.max((p - q).abs()));
            let fill = Some(report.structural_fill());
            let peak = Some(report.peak_intermediate_fill());
            let work = Some(report.work());
            rows.push((
                name,
                expected,
                "Prepared",
                fill,
                peak,
                work,
                report.estimated_error(),
                Some(gap),
            ));
        }
    }
}
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let columns = serde_json::json!([
    { "key": "0", "label": "Computation" },
    { "key": "1", "label": "Expected entries", "type": "integer" },
    { "key": "2", "label": "Preparation" },
    { "key": "3", "label": "Output-pattern entries", "type": "integer", "nullText": "-" },
    { "key": "4", "label": "Maximum intermediate entries", "type": "integer", "nullText": "-" },
    { "key": "5", "label": "Work [units]", "type": "integer", "nullText": "-" },
    { "key": "6", "label": "Error estimate [-]", "type": "number", "format": sci2, "nullText": "None" },
    {
        "key": "7",
        "label": "Maximum difference from reference [-]",
        "type": "number",
        "format": sci2,
        "nullText": "-"
    }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "fill" })
);
```

With defaults $m = 25$, $c = 2$, and $k = 4$, $A^k$ output patterns have the predicted 410 entries and zero difference from dense products (all entries are integers).
Product count (work) is $\lfloor \log_2 4 \rfloor + 1 - 1 = 2$, becoming $3 + 2 - 1 = 4$ for $k = 10$.
$e^{A}$'s output pattern fills both blocks with $2 \times 25^2 = 1250$ entries, omitting $n^2 - 1250 = 1250$ entries across rods.
Difference from closed form is $4.4 \times 10^{-16}$; first-order estimate $4.4 \times 10^{-14}$ exceeds the actual difference here but is not an upper bound.
One rod ($c = 1$, $m = 50$) makes $e^{A}$ dense with $50^2 = 2500$ entries, giving `ResourceLimit` during preparation under limit 2000.
$A^k$ for the same input is accepted with 430 entries.
At $m = 5$ and $k = 10$, $k \ge m - 1$ makes $A^k$ also fill each block; both plans' output patterns have $2 \times 5^2 = 50$ entries.
Lowering the limit to 300 also excludes $A^k$'s 410 entries, rejecting both before numerical computation.

## Summary

Matrix functions avoid eigenvectors: exponentials use Padé scaling and squaring with truncation backward error at most unit roundoff; logarithms/square roots use Schur form, and other functions Schur–Parlett.
Use one-shot `matrix_function` for a single value or `MatrixFunctionPlan` for repeated values, Fréchet derivatives, and conditioning at the same matrix.
Logarithms, square roots, and powers return principal values; for real output, inspect discarded imaginary parts and branch distances in reports.
Fréchet derivatives correctly describe changes in noncommuting directions and estimate conditioning, but lower-bound estimates cannot guarantee errors.
Sparse powers/functions determine patterns in preparation; functions fill connected blocks densely and reject excess fill with `ResourceLimit` before computation.
