Estimating linear-system solution accuracy requires condition number $\kappa_1(A) = \lVert A \rVert_1 \lVert A^{-1} \rVert_1$.
$\lVert A \rVert_1$ comes from entries, but exact $\lVert A^{-1} \rVert_1$ requires all $n$ columns of $A^{-1}$, or $n$ solves.
This page explains `OneNormEstimator`, estimating 1-norms from at most 17 products, and `operator_norm`, computing exact norms from $n$ applications, comparing them on inverse 1-norms.
The meaning of the condition number and its relation to SVD-based $\kappa_2$ are covered in [Computing and estimating condition numbers](oxref:linalg-condition-estimation).
Shared conventions for method objects, workspace requirements, owning-result/scoped APIs, and termination reason `SpectralTermination` are in [Matrix-function actions on vectors and method objects](oxref:linalg-action-conventions).

## Hager–Higham estimation

The 1-norm is maximum absolute column sum $\lVert A \rVert_1 = \max_j \sum_i \lvert a_{ij} \rvert$, equal to the maximum of $f(x) = \lVert Ax \rVert_1$ over $\lVert x \rVert_1 = 1$.
Since $f$ is convex, the maximum occurs at vertices $\pm e_j$ of the 1-norm unit ball; $f(e_j)$ is the sum of absolute values in column $j$.
Hager's method solves this maximization by climbing from vertex to vertex using only products $Ax$ and $A^{\mathsf H}x$.
Taking sign vector $\xi$ of $y = Ax$ ($\xi_i = y_i / \lvert y_i \rvert$; 1 if $y_i = 0$) and $z = A^{\mathsf H}\xi$ gives $f(x) = z^{\mathsf H}x$ and, for each $j$, $f(e_j) \ge \lvert z_j \rvert$.
Thus selecting $j$ maximizing $\lvert z_j \rvert$ and moving to $x = e_j$ increases the estimate when $\lVert z \rVert_\infty > z^{\mathsf H} x$.

`OneNormEstimator` follows these steps.

1. For $n \le 4$, apply $A$ to every coordinate unit vector and return the exact value.
2. For larger $n$, start at $x = (1, \dots, 1)/n$ and use estimate $\lVert Ax \rVert_1$.
   Stop if the estimate fails to increase; otherwise select $j$ from $z = A^{\mathsf H}\xi$ and set $x = e_j$.
   Also stop if selected $j$ repeats the preceding step.
   At most eight steps, each using one forward and one adjoint product (only forward if stopping without improvement).
3. Finally apply once to alternating-sign vector $x_i = (-1)^i (1 + i/(n-1))$ ($i = 0, \dots, n-1$, $\lVert x \rVert_1 = 3n/2$), replacing the estimate if $\lVert Ax \rVert_1 / \lVert x \rVert_1$ is larger.
   This vector guards against matrices for which initial vector $(1, \dots, 1)/n$ is uninformative (Higham, 1988).

Product counts are at most $8 \times 2 + 1 = 17$ independently of $n$.
Every estimate is $\lVert Ax \rVert_1$ for some $x$ normalized to $\lVert x \rVert_1 = 1$, giving a lower bound on $\lVert A \rVert_1$ apart from rounding.
It gives no upper bound or guaranteed limit on underestimation (Higham, 2002, Chapter 15).
For many matrices, estimates equal the true value or lie within a factor of 10, but can fall below half, as in the seed-63 matrix below.
Applied to $A^{-1}$, each product is one LU solve ($O(n^2)$), making estimation $O(n^2)$, cheaper than $O(n^3)$ for forming $A^{-1}$.

`OneNormEstimator` is a settings-only [method object](oxref:linalg-method-values), reading order $n$ from the operator on each call.
`OneNormEstimator::new()` defaults to 64 forward/adjoint applications combined, changed with `with_applications`.
Each application also counts once against execution settings' (`with_execution_options`) iteration limit.
Owning-result `estimate(&op)` and scoped `estimate_scoped(&op, &mut workspace, context)` return report `OneNormReport` with estimate `estimate()`, application count `applications()`, and termination reason `termination()`.
Termination is `Converged` on completing the procedure, `EvaluationLimit` at application limits, or `ExecutionStopped` for cancellation/deadlines.
Stopped estimates are the largest among completed products, or zero if none completed.
Nonsquare operators give `DimensionMismatch`; NaN or infinity returned by operators gives `NonFinite`; estimates beyond floating-point range give `NumericalInstability`.
The [Vandermonde conditioning and 1-norm estimation](oxref:linalg-condition-estimates) cell shows preallocating `OneNormWorkspace` from requirements `OneNormRequirements` and calling scoped APIs.
`LuDecomposition::condition_estimate` returns reciprocal condition number $1/\kappa_1$ from $\lVert A \rVert_1$ computed exactly during factorization and $\lVert A^{-1} \rVert_1$ estimated by the same procedure.

## Exact norms from unit vectors

For exact values, use standard `operator_norm(&op, MatrixNorm::One)`.
Apply the operator to $n$ unit vectors $e_j$, computing the 1-, $\infty$-, and Frobenius norms (`MatrixNorm::One`, `Infinity`, `Frobenius`) exactly apart from rounding from columns $Ae_j$.
No adjoint products are used, allowing rectangular operators.
Cost is $n$ applications; operators must be linear and return identical values for identical inputs.
With-options `operator_norm_with_options` accepts execution settings; scoped `operator_norm_scoped(&op, kind, &options, &mut workspace, context)` also accepts workspace and context.
Query workspace size with `OperatorWorkspaceRequest::norm`.
Each column consumes one iteration; reaching the limit gives `ConvergenceFailure` and cancellation gives `ExecutionStopped` errors; unlike estimation, no partial value returns.
Dense matrices also offer `MatrixView::norm(MatrixNorm)`, computing norms directly from entries.

## Inverse 1-norms and conditioning

The following cell applies `OneNormEstimator` to inverse operator `inverse_operator()` from LU of matrix $A$, estimating $\lVert A^{-1} \rVert_1$ and comparing exact `operator_norm_scoped` ($n$ solves), `LuDecomposition::condition_estimate`, and closed form.
Choose a one-dimensional Laplacian $T = \operatorname{tridiag}(-1, 2, -1)$ or a matrix of independent standard-normal entries, order $n \in [4, 200]$, random seed, and application limit (64 or 1).
The inverse of $T$ is discrete Green's function $(T^{-1})_{ij} = \min(i, j)(n + 1 - \max(i, j))/(n + 1)$ ($i, j = 1, \dots, n$), with column sums $j(n + 1 - j)/2$, giving $\lVert T^{-1} \rVert_1 = \max_j j(n+1-j)/2$.
The table gives each method's termination reason, solve count, $\lVert A^{-1} \rVert_1$, $\kappa_1(A)$, and ratio to the exact value.
Tests check Laplacians against closed forms and normal-random matrices against exact calculations; the outcome follows estimation termination.

```rust
//| id: linalg-one-norm-estimate
//| ref: linalg-one-norm-estimate
//| title: "Estimating the inverse 1-norm with a few solves"
//| run: reactive
//| crates: [scioxide-core, scioxide-linalg]
//| inputs:
//|   family: {"type":"select","label":"Matrix","description":"Check Laplacians by closed form and normal-random matrices by exact computation.","options":["Laplacian","Normal random"],"value":"Laplacian"}
//|   points: {"type":"range","label":"Degree n","description":"Square-matrix order.","min":4,"max":200,"step":2,"value":100}
//|   seed: {"type":"range","label":"Random seed","description":"Seed for the normal-random matrix.","min":1,"max":100,"step":1,"value":1}
//|   limit: {"type":"select","label":"Application-count limit","description":"Limit passed to with_applications (default 64).","options":["64","1"],"value":"64"}
//| cases:
//|   - {"id":"random","label":"Normal random (seed 1)","description":"Example where the estimate equals the exact value.","inputs":{"family":"Normal random"}}
//|   - {"id":"underestimate","label":"Normal random (seed 63)","description":"Example where the estimate stays below half the exact value.","inputs":{"family":"Normal random","seed":63}}
//|   - {"id":"budget","label":"Limit one application","description":"Stops with EvaluationLimit, returning the first product ‖A⁻¹e/n‖₁ (average column sum).","inputs":{"limit":"1"}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"one-norm","path":"/rows/0/1","equals":"Converged"}
//|       - {"artifact":"one-norm","path":"/rows/0/3","approx":{"value":1275,"rtol":1e-10}}
//|       - {"artifact":"one-norm","path":"/rows/1/3","approx":{"value":1275,"rtol":1e-10}}
//|       - {"artifact":"one-norm","path":"/rows/3/3","equals":1275}
//|       - {"path":"/outputs/1/state","equals":"satisfied"}
//|   - case: random
//|     expect:
//|       - {"artifact":"one-norm","path":"/rows/0/5","approx":{"value":1,"atol":1e-10}}
//|       - {"artifact":"one-norm","path":"/rows/3/3","equals":null}
//|   - case: underestimate
//|     expect:
//|       - {"artifact":"one-norm","path":"/rows/0/5","range":{"min":0.3,"max":0.6}}
//|       - {"path":"/outputs/1/state","equals":"satisfied"}
//|   - case: budget
//|     expect:
//|       - {"artifact":"one-norm","path":"/rows/0/1","equals":"EvaluationLimit"}
//|       - {"artifact":"one-norm","path":"/rows/0/2","equals":1}
//|       - {"artifact":"one-norm","path":"/rows/0/3","approx":{"value":858.5,"rtol":1e-10}}
//|       - {"path":"/outputs/1/state","equals":"partial"}
use scioxide_core::{Budget, ExecutionContext};
use scioxide_linalg::{
    LinalgExecutionOptions, LinalgWorkspace, LuDecomposition, Matrix, MatrixNorm,
    OneNormEstimator, SpectralTermination, operator_norm_scoped,
};

let n = points.round() as usize;
let laplacian = family == "Laplacian";
// Seeded standard-normal pseudorandom numbers (xorshift64* and Box–Muller).
let mut state = (seed.round() as u64).wrapping_mul(0x9E37_79B9_7F4A_7C15) | 1;
let mut uniform = move || {
    state ^= state >> 12;
    state ^= state << 25;
    state ^= state >> 27;
    ((state.wrapping_mul(0x2545_F491_4F6C_DD1D) >> 11) as f64 + 0.5) / (1u64 << 53) as f64
};
let noise: Vec<f64> = (0..n * n)
    .map(|_| {
        let (u, v) = (uniform(), uniform());
        (-2.0 * u.ln()).sqrt() * (2.0 * std::f64::consts::PI * v).cos()
    })
    .collect();
// T = tridiag(−1, 2, −1), or a matrix with independent standard-normal entries.
let mut a = Matrix::zeros(n, n).map_err(|e| e.to_string())?;
for (idx, value) in a.as_mut_slice().iter_mut().enumerate() {
    let (i, j) = (idx / n, idx % n);
    *value = match (laplacian, i.abs_diff(j)) {
        (false, _) => noise[idx],
        (true, 0) => 2.0,
        (true, 1) => -1.0,
        (true, _) => 0.0,
    };
}
let norm = a.view().norm(MatrixNorm::One).map_err(|e| e.to_string())?;
let lu = LuDecomposition::factor(&a).map_err(|e| e.to_string())?;
// Inverse operator x ↦ A⁻¹x also supports adjoint products; each application is one solve.
let inverse = lu.inverse_operator();
let limit = Budget::try_from(limit.parse::<usize>().map_err(|e| e.to_string())?)
    .map_err(|e| e.to_string())?;
let report = OneNormEstimator::new()
    .with_applications(limit)
    .estimate(&inverse)
    .map_err(|e| e.to_string())?;
// Exact value: scoped API applying all n unit vectors (n solves).
let exact = operator_norm_scoped(
    &inverse,
    MatrixNorm::One,
    &LinalgExecutionOptions::new(),
    &mut LinalgWorkspace::new(),
    ExecutionContext::sequential(),
)
.map_err(|e| e.to_string())?;
// Laplacian closed form ‖T⁻¹‖₁ = maxⱼ j(n + 1 − j)/2 (independent check).
let closed = laplacian.then(|| {
    (1..=n)
        .map(|j| (j * (n + 1 - j)) as f64 / 2.0)
        .fold(0.0, f64::max)
});
// LU conditioning also estimates ‖A⁻¹‖₁ with the same Hager–Higham procedure.
let rcond = lu
    .condition_estimate()
    .map_err(|e| e.to_string())?
    .reciprocal()
    .value();
let lu_inverse = 1.0 / (rcond * norm);
let name = match report.termination() {
    SpectralTermination::Converged => "Converged",
    SpectralTermination::EvaluationLimit => "EvaluationLimit",
    SpectralTermination::IterationLimit => "IterationLimit",
    SpectralTermination::InvariantSubspace => "InvariantSubspace",
    SpectralTermination::AccuracyLimit => "AccuracyLimit",
    SpectralTermination::ExecutionStopped(_) => "ExecutionStopped",
};

let sci4 = serde_json::json!({ "notation": "scientific", "significantDigits": 4 });
let fixed4 = serde_json::json!({ "fractionDigits": 4 });
let columns = serde_json::json!([
    { "key": "0", "label": "Method" },
    { "key": "1", "label": "Termination reason", "nullText": "—" },
    { "key": "2", "label": "Solves [count]", "type": "integer", "nullText": "—" },
    { "key": "3", "label": "‖A⁻¹‖₁ [-]", "type": "number", "format": sci4, "nullText": "Not applicable" },
    { "key": "4", "label": "κ₁(A) [-]", "type": "number", "format": sci4, "nullText": "Not applicable" },
    { "key": "5", "label": "Ratio to exact value [-]", "type": "number", "format": fixed4, "nullText": "Not applicable" }
]);
let rows = vec![
    (
        "OneNormEstimator::estimate",
        Some(name),
        Some(report.applications()),
        Some(report.estimate()),
        Some(norm * report.estimate()),
        Some(report.estimate() / exact),
    ),
    (
        "operator_norm_scoped (exact)",
        None,
        Some(n),
        Some(exact),
        Some(norm * exact),
        Some(1.0),
    ),
    (
        "LuDecomposition::condition_estimate",
        None,
        None,
        Some(lu_inverse),
        Some(1.0 / rcond),
        Some(lu_inverse / exact),
    ),
    (
        "Closed form maxⱼ j(n + 1 − j)/2",
        None,
        None,
        closed,
        closed.map(|v| norm * v),
        closed.map(|v| v / exact),
    ),
];
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "one-norm" })
);

let outcome = match report.termination() {
    SpectralTermination::Converged => Outcome::satisfied("Estimation iteration converged")
        .explanation("The value estimates ‖A⁻¹‖₁ from below; it is not an upper bound."),
    SpectralTermination::AccuracyLimit => Outcome::failed("Estimation failed the accuracy check"),
    _ => Outcome::partial("Stopped at a limit, returning the largest estimate so far"),
};
emit_outcome!(
    outcome
        .status(name)
        .diagnostic("Solve count", report.applications() as f64, None)
        .diagnostic("Ratio to exact value", report.estimate() / exact, None)
);
```

For the default Laplacian ($n = 100$), estimation reaches `Converged` in five solves; $\lVert T^{-1} \rVert_1 = 1275$ agrees with the exact 100-solve value and closed form $50 \cdot 51/2 = 1275$ ($\kappa_1 = 5100$).
The five comprise a product of the operator with $(1, \dots, 1)/n$, a product with the adjoint operator, a product with $e_j$ selecting the largest column, another product with the adjoint operator (stopping when the same column is selected again), and a product with the alternating-sign vector.
All entries of $T^{-1}$ are positive, so the first adjoint product already finds the largest column.
An application limit of 1 stops with `EvaluationLimit`, returning the first product's 1-norm, average column sum $(n+1)(n+2)/12 = 858.5$, as the estimate (0.67 times exact).
For normal-random seed 1, the estimate equals exact $24.07$; for seed 63, estimate $17.11$ is only 0.44 times exact $38.69$, underestimating $\kappa_1$ by more than half.
`LuDecomposition::condition_estimate` uses the same procedure and returns the same value within rounding in every case.

## Summary

To learn only the scale of $\lVert A^{-1} \rVert_1$ or $\kappa_1(A)$, LU's `condition_estimate` or inverse-operator `OneNormEstimator` needs at most 17 solves, independently of $n$.
Estimates are lower bounds apart from rounding, with no upper guarantee; interpret them as order-of-magnitude guides that may underestimate by several times.
Use `OneNormEstimator` results when termination is `Converged`; values stopped with `EvaluationLimit` are merely maxima over completed products.
For exact values or rectangular operators, compute `operator_norm` (`operator_norm_scoped` with caller-owned workspace and context) in $n$ applications.
