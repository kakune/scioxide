Comparing orientations of two data sets, simultaneously diagonalizing two observation matrices, and solving singular systems by fixing free degrees of freedom concern the subspaces spanned by matrices and their relationships more than the matrices themselves.
This page explains subspace computations from SVD, GSVD and CS decomposition for two matrices, polar decomposition into rotation and stretch, and singular-system solves with caller-declared null spaces.
Rank assessment and singular-value perturbations assume the material in [Singular value decomposition, numerical rank, and regularized solutions](../svd-and-rank/).
Call forms (standard, with options, and with caller-provided output) and workspace requests are defined in [Workspaces, execution contexts, and attempt records](oxref:linalg-execution-forms).

## Range and null-space bases

If the SVD $A = U \Sigma V^{\mathsf H}$ of $A \in \mathbb{K}^{m \times n}$ is assessed to have rank $r$, the first $r$ columns of $U$ form an orthonormal basis for the range $\mathcal{R}(A)$, and the remaining $n - r$ columns of $V$ for the null space $\mathcal{N}(A)$.
`orth(&a, policy)` and `null_space(&a, policy)` return this basis in a `SubspaceBasis`; read the columnwise basis with `basis()` and its `SubspaceReport` with `report()`.
The report contains the policy-selected rank `rank()` (`RankReport`) and `condition()` for the threshold-independent reciprocal condition number $\sigma_{\min}/\sigma_{\max}$; with no singular values, `condition()` is `None`.
`RankPolicy` determines rank; changing policy does not change the SVD result.
Basis vectors themselves are not unique; any orthonormal basis of the same subspace is valid.
When the gap between $\sigma_r$ and $\sigma_{r+1}$ is small, Wedin's theorem makes the subspace itself sensitive to perturbations.

The `null_space` result $Z$ ($n \times (n - r)$) satisfies $\lVert AZ \rVert_2 = \sigma_{r+1}$; when $r = m$, $AZ = 0$ holds to rounding accuracy.
For $m \ge n$ it uses thin SVD; for wide matrices ($m < n$), it uses full SVD to include the $n - m$ structural-complement vectors omitted by thin SVD.
Obtain the left null space ($A^{\mathsf H} z = 0$) by passing `a.adjoint()`.
The APIs `orth_into` and `null_space_into` write bases to the caller's `Matrix` and return reports; obtain workspace requirements by passing `SubspaceBasisWorkspaceRequest::orth` or `null_space` requests to `LinalgWorkspace::workspace_requirements`.
Requests size for the maximum rank and therefore suffice for every input of the same shape.
NaNs or infinities give `NonFinite`, an SVD iteration limit gives `ConvergenceFailure`, and singular-value overflow gives `NumericalInstability`.

## Principal angles between subspaces

The principal angles $0 \le \theta_1 \le \dots \le \theta_q \le \pi/2$ of subspaces $\mathcal{V}, \mathcal{W}$ of $\mathbb{K}^m$ (dimensions $p \ge q$) are defined successively by

$$
\cos\theta_k = \max_{x \in \mathcal{V},\, y \in \mathcal{W}} \lvert x^{\mathsf H} y \rvert \quad (\lVert x \rVert_2 = \lVert y \rVert_2 = 1,\ x \perp x_1, \dots, x_{k-1},\ y \perp y_1, \dots, y_{k-1})
$$

where $x_k, y_k$ are maximizing vectors.
With orthonormal bases $Q_A, Q_B$, write $x = Q_A a$ and $y = Q_B b$; the problem maximizes the bilinear form of $Q_A^{\mathsf H} Q_B$, and the min-max characterization of singular values gives

$$
Q_A^{\mathsf H} Q_B = Y \operatorname{diag}(\cos\theta_1, \dots, \cos\theta_q) Z^{\mathsf H}
$$

This is the Björck–Golub characterization.
When $p = q$, the largest principal angle gives the subspace distance $\lVert P_{\mathcal{V}} - P_{\mathcal{W}} \rVert_2 = \sin\theta_{\max}$ ($P$ denotes orthogonal projection).

For small angles, $\cos\theta \approx 1 - \theta^2/2$, so recovering angles from cosines loses information at $\theta \lesssim \sqrt{\varepsilon}$ through rounding ($\varepsilon$ is machine epsilon).
Only when an angle is below 45°, `scioxide-linalg` also computes sines as singular values of the complementary projection $(I - Q_L Q_L^{\mathsf H}) Q_S$ ($Q_L$ is the larger-dimensional basis and $Q_S$ the smaller), recovering each angle from whichever of sine or cosine is better conditioned (Knyazev–Argentati).
The bases $Q_A, Q_B$ come from SVDs of the column spaces truncated to the policy-selected rank.

`subspace_angles(&a, &b, policy)` returns a `SubspaceAngles` containing the principal angles between the matrices' column spaces in radians.
Read angles with `angles()`; they are descending, opposite to the definition above.
Their count is $\min(\operatorname{rank} A, \operatorname{rank} B)$, empty if either rank is 0.
The `SubspaceAnglesReport` returned by `report()` records how each input was interpreted through the `SubspaceReport` values `first()` and `second()`.
If fewer angles than expected appear, use this report to check which input lost rank.
The API `subspace_angles_into(&a, &b, policy, &options, &mut angles, &mut workspace, context)` writes angles to the caller's `Vec` and returns the same `SubspaceAnglesReport`.
Obtain workspace requirements from `SubspaceAnglesWorkspaceRequest::new(rows, first_cols, second_cols, &options)`.
Output capacity up to $\min(m, n_A, n_B)$ entries is reserved before computation; calls allocate nothing when workspace and output capacities suffice.
At most four SVDs are performed (two ranges, the basis cross-product, and the complementary residual if needed), each counting iterations in a child scope of the iteration limit.
Different input row counts give `DimensionMismatch` and an SVD limit gives `ConvergenceFailure`; failure leaves output values unchanged.

## Orthogonal Procrustes problem

Aligning two point-coordinate sets $A, B \in \mathbb{R}^{n \times 3}$ by an orthogonal transformation is the orthogonal Procrustes problem: minimize $\lVert AR - B \rVert_F$ subject to $R^{\mathsf H} R = I$.
Since $\lVert AR - B \rVert_F^2 = \lVert A \rVert_F^2 + \lVert B \rVert_F^2 - 2 \operatorname{Re} \operatorname{tr}(R^{\mathsf H} A^{\mathsf H} B)$, it suffices to maximize the trace.
With $A^{\mathsf H} B = U \Sigma V^{\mathsf H}$, $\operatorname{tr}(R^{\mathsf H} U \Sigma V^{\mathsf H}) = \operatorname{tr}(W \Sigma)$ ($W = V^{\mathsf H} R^{\mathsf H} U$ is unitary and $\lvert w_{ii} \rvert \le 1$).
Its real part $\sum_i \sigma_i \operatorname{Re} w_{ii}$ is at most $\operatorname{tr} \Sigma$, with equality at $W = I$, or $R = U V^{\mathsf H}$.
If $\Sigma$ is nonsingular, the minimizer is unique; zero singular values leave components of $W$ free in those directions, making it nonunique.
The only constraint is orthogonality, so the solution need not be a rotation ($\det R = 1$).
For coplanar points, a reflection can give the same residual; `scioxide-linalg` does not impose $\det R = 1$ as Kabsch's method does.

`orthogonal_procrustes(&a, &b, policy)` returns a `ProcrustesAlignment`; read the transformation multiplying from the right with `transformation()` and its `ProcrustesReport` with `report()`.
The report contains residual `residual_norm()` independently computed from $A$, $B$, and computed $R$, rank and conditioning `cross_product()` of the cross-product $A^{\mathsf H} B$, `scale()` for the singular-value sum $\sum_i \sigma_i(A^{\mathsf H} B)$, and uniqueness `uniqueness()`.
`scale()` diagnoses the maximum objective value; it is not a multiplier to apply to the result.
The uniqueness value `ProcrustesUniqueness` has three variants; the policy affects only assessment and does not truncate the solution.

- `Unique`: no cross-product singular value is zero, and the policy retains all of them.
- `NumericallyUnresolved`: no singular value is zero, but the policy treats at least one as zero.
- `Nonunique`: a computed singular value is exactly zero and the minimizer is nonunique.

The API `orthogonal_procrustes_into(&a, &b, policy, &options, &mut r, &mut workspace, context)` writes the column-count × column-count transformation to the caller's `Matrix` and returns the same `ProcrustesReport`.
Obtain requirements from `ProcrustesWorkspaceRequest::new(rows, cols, &options)`; their size is $O(\text{cols}^2)$, and residuals are formed in blocks of 256 rows.
For $A, B$ of shape $m \times n$, the product costs $O(m n^2)$ and the single SVD $O(n^3)$.
Shape mismatch gives `DimensionMismatch`, NaNs or infinities `NonFinite`, overflow in the cross-product or its singular-value sum `NumericalInstability`, and an SVD iteration limit `ConvergenceFailure`.

Since $R$ is nonsingular, the column spaces of $AR$ and $A$ coincide; principal angles depend only on noise, not the rotation angle.

With defaults $\theta = 40^\circ$ and $e = -6$, the estimated $R$ differs from the true rotation by $5.2 \times 10^{-7}$ and has residual $2.8 \times 10^{-6}$, both of the order of the noise.
$\det R = 1$ makes the estimate a rotation, and cross-product rank 3 gives uniqueness `Unique`.
The principal angles are $2.1 \times 10^{-6}$, $7.5 \times 10^{-7}$, and $1.5 \times 10^{-7}$; angles that would vanish without noise are set by the noise magnitude.
At $e = -1$, the difference grows to 0.052, the residual to 0.28, and the largest principal angle to 0.20 rad.

Putting points in plane $z = 0$ reduces the ranks of $A$ and the cross-product to 2, gives uniqueness `Nonunique`, and makes the reciprocal condition number of $A$ zero.
Noise gives $B$ third-direction components of order $10^{-6}$, so it is assessed as rank 3 (reciprocal condition number $3.6 \times 10^{-7}$), and only two principal angles, the smaller rank, are returned.
At the default angle the returned $R$ also has $\det R = 1$, but reflecting the normal direction gives the same residual; the problem does not determine which to return.
Indeed, $\theta = 180^\circ$ and $e = -14$ return a reflection with $\det R = -1$ at residual $2.9 \times 10^{-14}$, differing from the true rotation by 2.
When only rotations are meaningful and uniqueness is not `Unique`, check $\det R$.

## Generalized singular value decomposition

For two matrices $A \in \mathbb{K}^{m \times n}$ and $B \in \mathbb{K}^{p \times n}$ acting on the same unknown $x \in \mathbb{K}^n$, such as generalized Tikhonov regularization $\min \lVert Ax - b \rVert_2^2 + \lambda \lVert Bx \rVert_2^2$, use GSVD (generalized singular value decomposition) to diagonalize them together.
`GsvdDecomposition` normalizes inputs by a common scale $s$ (`input_scale()`, the maximum absolute entry of $A$ and $B$, or 1 if both are zero), then computes

$$
A / s = U D_1 \begin{bmatrix} 0 & R \end{bmatrix} Q^{\mathsf H}, \qquad B / s = V D_2 \begin{bmatrix} 0 & R \end{bmatrix} Q^{\mathsf H}
$$

where $U, V, Q$ are unitary, $R$ is $r \times r$ nonsingular upper triangular, and $r$ is the numerical rank of $[A; B]/s$.
Each column of $D_1$ ($m \times r$) and $D_2$ ($p \times r$) has at most one nonzero; the pairs $(\alpha_j, \beta_j)$ satisfy $\alpha_j^2 + \beta_j^2 = 1$.
`GeneralizedSingularValue` stores these pairs without division; read them with `alpha()` and `beta()`.
The ratio $\alpha_j / \beta_j$ (`ratio()`) is a generalized singular value; its square is an eigenvalue of the pencil $A^{\mathsf H} A - \lambda B^{\mathsf H} B$ on directions outside the common null space described below, but GSVD avoids forming these products.
Directions with $\beta_j = 0$ have infinite values: `ratio()` gives `DomainError`; ratio overflow gives `NumericalInstability`.
Rank-deficient directions of $[A; B]$ form the common null space $\mathcal{N}(A) \cap \mathcal{N}(B)$, spanned by the first $n - r$ columns of $Q$; `common_null_space()` returns its basis.
`generalized_values()` follows column order of $D_1$ and $D_2$ (row order of $R$), not magnitude order.

`GsvdDecomposition::factor(&a, &b)` is the standard form selecting the rank of $[A; B]/s$ with `RankPolicy::Exact`; the form with options `factor_with_options(&a, &b, &GsvdOptions::new(policy))` accepts policy and execution settings (`GsvdOptions::default()` selects `Exact`).
The algorithm first determines the common row space and rank $r$ by thin SVD $[A; B]/s = W \Sigma Z^{\mathsf H}$ of the stacked matrix.
It then splits the first $r$ columns of $W$ into block $W_A$ for rows of $A$ and block $W_B$ for rows of $B$, rotating both blocks' columns by the right singular vectors of the block with fewer rows.
Since $W_A^{\mathsf H} W_A + W_B^{\mathsf H} W_B = I$, this rotation simultaneously diagonalizes both Gram matrices, making both blocks' columns orthogonal to rounding accuracy.
Jacobi rotation sweeps across the two blocks (usually one or two) finish orthogonalizing columns on the $A$ and $B$ sides, yielding $U D_1$ and $V D_2$.
Finally, RQ factorization of the remaining right factor gives $[0\ R]\, Q^{\mathsf H}$.
No Gram or inverse matrix is formed; factors are committed only after checking that reconstruction residual is at most the norm of discarded singular values plus a rounding allowance, otherwise the result is `NumericalInstability`.
The iteration limit counts one for the stacked SVD and one per sweep; without an explicit limit, at most 40 sweeps run.
Change the limit with `LinalgExecutionOptions::with_iteration_budget` passed to `GsvdOptions::with_execution_options`; the two nested SVDs count iterations in separate child scopes, each under the same limit.
The report `GsvdReport` contains stacked-matrix rank `rank()`, reciprocal condition number `condition()`, `retained_reciprocal_condition()` for the retained reciprocal condition number $\sigma_r/\sigma_1$, `discarded_norm()` for discarded singular-value norm $(\sum_{i>r} \sigma_i^2)^{1/2}$, reconstruction errors `residual_a()` and `residual_b()` for $A$ and $B$ (Frobenius norms in normalized units), and sweep count `sweeps()`.
These are computed estimates, not certified bounds.
`report()` returns `None` for an empty result that has never been computed.
Obtain workspace for the API `factor_into` from `GsvdWorkspaceRequest::new(m, p, n, &options)`.

A = s \begin{bmatrix} a & 0 & 0 \\ 0 & 1 & 0 \end{bmatrix}, \qquad
B = s \begin{bmatrix} 4 & 0 & 0 \\ 0 & 0 & 0 \end{bmatrix}
$$

It varies the common multiplier $s = 10^{k}$.

## CS and polar decompositions

CS decomposition splits a unitary matrix $X$ partitioned into $2 \times 2$ blocks as follows:

$$
X = \begin{bmatrix} U_1 & \\ & U_2 \end{bmatrix} \begin{bmatrix} C & -S \\ S & C \end{bmatrix} \begin{bmatrix} V_1 & \\ & V_2 \end{bmatrix}^{\mathsf H}, \qquad C = \operatorname{diag}(\cos\theta_i),\ S = \operatorname{diag}(\sin\theta_i)
$$

The general form including identity blocks is omitted.
This decomposition is central to GSVD; angles $\theta_i$ are principal angles between the span of the first $q$ columns of $X$ and the coordinate subspace of its first $p$ rows.
`CsdDecomposition::factor(&x, p, q)` is the standard form factoring $n \times n$ $X$ partitioned at $p, q$; the form with options `factor_with_options` accepts `LinalgExecutionOptions`.
The decomposition returns ascending angles `angles()`, cosines `cosines()`, sines `sines()`, four unitary factors `u1_matrix()`, `u2_matrix()`, `v1_matrix()`, `v2_matrix()`, and central matrix `cs_matrix()`.
It rotates the first $q$ columns by right singular vectors of whichever block has fewer rows—the upper $p$ or lower $n - p$ rows—making both blocks' columns orthogonal to rounding accuracy.
Without this rotation, a smaller block with fewer than $q$ rows has repeated zero Gram eigenvalues, making Jacobi sweeps converge only linearly.
One-sided Jacobi sweeps (usually one or two) then finish orthogonalizing columns within both blocks; their column norms give cosines and sines, retaining relative accuracy even for small values.
$V_2$ comes from the remaining columns without a second Jacobi iteration; the SVD and each sweep cost $O(nq^2)$.
Input unitarity is checked by $\lVert X^{\mathsf H} X - I \rVert_F \le 32 n \varepsilon$; failure gives `InvalidInput`.
Factors are committed only when reconstruction and each factor's orthogonality errors are at most $128 n \varepsilon$; otherwise the result is `NumericalInstability`.
As in GSVD, the default sweep limit is 40 (preparation counts once); the nested SVD has the same limit in a child scope, and reaching either limit gives `ConvergenceFailure`.
The report `CsdReport` contains input unitarity error `input_unitarity_error()`, reconstruction error `residual()`, orthogonality error `orthogonality_error()` (the largest of the four factors), and sweep count `sweeps()`, as estimates recomputed from the factors.

Polar decomposition has form $A = UH$ (`PolarSide::Right`) or $A = HU$ (`PolarSide::Left`); $U$ has orthonormal columns when $m \ge n$ and orthonormal rows when $m < n$, while $H$ is Hermitian positive semidefinite.
From thin SVD $A = U_k \Sigma_k V_k^{\mathsf H}$, compute $U = U_k V_k^{\mathsf H}$ and either $H = V_k \Sigma_k V_k^{\mathsf H} = (A^{\mathsf H} A)^{1/2}$ for `Right` or $H = U_k \Sigma_k U_k^{\mathsf H} = (A A^{\mathsf H})^{1/2}$ for `Left`; $U$ is the closest orthonormal matrix to $A$ in the Frobenius norm.
$H$ is unique; $U$ is unique only when $A$ has rank $k$.
`PolarDecomposition::factor(&a, side)` is the standard form diagnosing with `RankPolicy::Exact`; the form with options `factor_with_options(&a, side, &PolarOptions::new(policy))` accepts a policy (`PolarOptions::default()` uses `Exact`).
Divide the input by maximum absolute entry $s$ (`input_scale()`) before SVD, then multiply $H$ by $s$ afterward.
$H$ is exactly Hermitian because only its upper triangle is computed and mirrored with real diagonal entries.
With $\tau = 128 \max(m, n)\, \varepsilon$, commit factors only if residual is at most $\tau \lVert A/s \rVert_F$ and orthogonality error of $U$ at most $\tau$; otherwise the result is `NumericalInstability`.
`PolarReport` records reconstruction error `residual()` ($\lVert A - UH \rVert_F / s$), orthogonality error `orthogonality_error()`, rank `rank()`, reciprocal condition number `condition()`, and whether the policy-selected rank is below $k$ and the completion of $U$ is nonunique (`completion_nonunique()`).
The rank policy affects diagnostics only and does not truncate factors.
The cost is thin SVD plus $O(mnk + h^2 k + mnh)$ for constructing factors and checking reconstruction ($h = n$ for `Right`, $h = m$ for `Left`); factors occupy $O(mn + h^2)$ scalars besides SVD workspace.

## Singular systems with declared null spaces

Some problems have physically known singular coefficient matrices and null spaces, such as Poisson equations with pure Neumann boundaries or rigid motions of unsupported structures.
Given orthonormal bases $L, R \in \mathbb{K}^{n \times k}$ for left and right null spaces ($A^{\mathsf H} L = 0$, $A R = 0$), the augmented system is

$$
\begin{bmatrix} A & L \\ R^{\mathsf H} & 0 \end{bmatrix} \begin{bmatrix} x \\ \mu \end{bmatrix} = \begin{bmatrix} b \\ c \end{bmatrix}
$$

This is nonsingular if $L$ and $R$ span the complete null spaces.
Multiplying the first equation by $L^{\mathsf H}$ and using $L^{\mathsf H} A = 0$ gives $\mu = L^{\mathsf H} b$, so $\mu$ represents the component of $b$ outside the range.
If $b$ is compatible ($L^{\mathsf H} b = 0$), $\mu = 0$ and $x$ satisfies $Ax = b$; the second equation $R^{\mathsf H} x = c$ fixes the solution's free degrees of freedom (gauge).

`BorderedSystem::new(&operator, left, right, operator_scale, &BorderedSystemOptions::default())` borrows the operator and bases $L, R$ supplied as `BlockVectorView` (scioxide-core) to construct the augmented system.
Construction checks orthonormality of each basis and verifies columnwise that $\lVert A r_j \rVert_2$ and $\lVert A^{\mathsf H} l_j \rVert_2$ are at most $\mathrm{atol} + \mathrm{rtol} \cdot$ `operator_scale` using validation tolerance `with_validation_tolerance` (default $\mathrm{atol} = \mathrm{rtol} = \sqrt{\varepsilon}$).
`operator_scale` is a caller-supplied estimate of $\lVert A \rVert$.
It cannot check whether the bases span the complete null spaces; incomplete bases leave the augmented system singular.
$k = 0$, $k > n$, negative `operator_scale`, or a failed basis check gives `InvalidInput`; shape mismatch gives `DimensionMismatch`; each of the $2k$ column checks counts once toward the iteration limit.
Use `build` for construction with an execution context; the augmented system does not retain the context.

`augmented()` returns the augmented system as a matrix-free `BorderedSystemOperator` (order $n + k$, adjoint $[A^{\mathsf H}\ R;\ L^{\mathsf H}\ 0]$).
One application uses $A$ or $A^{\mathsf H}$ once plus $O(nk)$ border work, so it can be passed directly to iterative methods.
`prepare_rhs(&b, &c, policy)` constructs a right-hand side $[\hat b; c]$ of length $n + k$.
`CompatibilityPolicy::RequireCompatible` leaves $\hat b = b$ and returns `DomainError` if $\lVert L^{\mathsf H} b \rVert_2$ exceeds $\mathrm{atol} + \mathrm{rtol} \lVert b \rVert_2$ from the compatibility tolerance (`with_compatibility_tolerance`, default $\sqrt{\varepsilon}$).
`CompatibilityPolicy::Project` replaces it with the projection onto the range $\hat b = b - L L^{\mathsf H} b$.
The `BorderedSystemDiagnostics` returned by `diagnose(&b, &prepared, &x)` holds the supplied basis column count $k$ (`nullity()`, not a computed rank), plus values recomputed for the original system: $\lVert L^{\mathsf H} b \rVert_2$ (`compatibility_defect()`), $\lVert b - \hat b \rVert_2$ (`projection_norm()`), $\lVert Ax - b \rVert_2$ (`original_residual_norm()`), $\lVert Ax - \hat b \rVert_2$ (`projected_residual_norm()`), and $\lVert R^{\mathsf H} x - c \rVert_2$ (`gauge_defect()`).
Obtain workspace for `prepare_rhs_into` and `diagnose_scoped` from `workspace_requirements(BorderedSystemWorkspaceRequest::PrepareRhs)` ($n + 2k$ scalars) and `Diagnose` ($3n$ scalars plus operator workspace), respectively.

The following cell solves static equilibrium $Ku = f$ for 8 unsupported masses joined in a spring chain of stiffness $k_s = 2000$ N/m.
Stiffness matrix $K = k_s G$ ($G$ is the 8-vertex path-graph Laplacian) is symmetric, with rigid translation $r = (1, \dots, 1)/\sqrt{8}$ spanning both null spaces; set $L = R = r$.
$Ku = f$ is solvable only for zero resultant force $\sum_i f_i = 0$ ($L^{\mathsf T} f = 0$); displacement $u$ is then determined up to translation, fixed by gauge $r^{\mathsf T} u = 0$ (zero center-of-mass displacement).
The load pulls the endpoints with $\mp 10$ N and adds force $\delta$ at node 3; inputs are $\delta$ ($-5$–$5$ N) and treatment of components outside the range.
The augmented system is symmetric indefinite, so solve with MINRES (`MinresSolver`).
For an independent reference, force balance over nodes $0$ through $i$ gives tension $-\sum_{j \le i} \hat f_j$ in spring $i$; compute $u_{i+1} = u_i - \frac{1}{k_s} \sum_{j \le i} \hat f_j$ successively, then subtract the mean displacement.
Two tables show displacements and `BorderedSystemDiagnostics` values; the cell's conclusion uses the MINRES termination reason.
If `RequireCompatible` rejects the load, the outcome is failed.

//| id: linalg-bordered-spring-chain
//| ref: linalg-bordered-spring-chain
//| title: "Augmented system and gauge condition for a free spring chain"
//| run: reactive
//| crates: [scioxide-core, scioxide-linalg]
//| inputs:
//|   imbalance: {"type":"range","label":"Additional force δ at node 3 [N]","description":"A nonzero value gives nonzero resultant force, violating equilibrium Σf = 0.","min":-5,"max":5,"step":0.5,"value":0}
//|   compatibility: {"type":"select","label":"Treatment of components outside the range","options":["RequireCompatible","Project"],"value":"RequireCompatible"}
//| cases:
//|   - {"id":"project","label":"δ = 2 N, Project","description":"Projects out the resultant-force component, leaving ‖L Lᵀ f‖₂ in the original-system residual.","inputs":{"imbalance":2,"compatibility":"Project"}}

//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"displacement","path":"/rows/0/1","approx":{"value":-17.5,"rtol":1e-12}}
//|       - {"artifact":"displacement","path":"/rows/7/1","approx":{"value":17.5,"rtol":1e-12}}
//|       - {"artifact":"diagnostics","path":"/rows/0/4","range":{"max":1e-10}}
//|       - {"artifact":"diagnostics","path":"/rows/0/5","range":{"max":1e-15}}
//|       - {"path":"/outputs/2/state","equals":"satisfied"}
//|   - case: project
//|     expect:
//|       - {"artifact":"displacement","path":"/rows/0/1","approx":{"value":-17.5625,"rtol":1e-12}}
//|       - {"artifact":"diagnostics","path":"/rows/0/1","approx":{"value":0.70710678118654752,"rtol":1e-12}}
//|       - {"artifact":"diagnostics","path":"/rows/0/3","approx":{"value":0.70710678118654752,"rtol":1e-10}}
//|       - {"path":"/outputs/2/state","equals":"satisfied"}
//|   - case: reject
//|     expect:
//|       - {"path":"/outputs/0/state","equals":"failed"}
//|       - {"path":"/outputs/0/status","equals":"DomainError"}
use scioxide_core::{BlockVectorView, Budget, SciOxideErrorKind, ResidualTolerance};
use scioxide_linalg::{
    BorderedSystem, BorderedSystemOptions, CompatibilityPolicy, LinearSolveTermination, Matrix,
    MatrixNorm, MinresSolver, Preconditioning,
};

let (n, spring, pull) = (8_usize, 2.0e3_f64, 10.0_f64);
// Stiffness K = k_s G of an unsupported spring chain (G is the path-graph Laplacian).
let entries = (0..n * n)
    .map(|idx| {
        let (i, j) = (idx / n, idx % n);
        if i == j {
            spring * if i == 0 || i == n - 1 { 1.0 } else { 2.0 }
        } else if i.abs_diff(j) == 1 {
            -spring
        } else {
            0.0
        }
    })
    .collect();
let stiffness = Matrix::from_vec(n, n, entries).map_err(|e| e.to_string())?;
let operator = stiffness.view().try_finite().map_err(|e| e.to_string())?;
// Both null spaces are rigid translation (1, …, 1)/√n.
let mode = vec![1.0 / (n as f64).sqrt(); n];
let basis = BlockVectorView::new(&mode, n, 1).map_err(|e| e.to_string())?;
let scale = stiffness
    .view()
    .norm(MatrixNorm::One)
    .map_err(|e| e.to_string())?;
let options = BorderedSystemOptions::default();
let system =
    BorderedSystem::new(&operator, basis, basis, scale, &options).map_err(|e| e.to_string())?;
// Load [N]: pull the endpoints with ∓P and add δ at node 3.
let mut load = vec![0.0; n];
(load[0], load[n - 1]) = (-pull, pull);
load[3] += imbalance;
let policy = if compatibility == "Project" {
    CompatibilityPolicy::Project
} else {
    CompatibilityPolicy::RequireCompatible
};
// Gauge rᵀu = c = 0 (zero center-of-mass displacement).
let prepared = match system.prepare_rhs(&load[..], &[0.0][..], policy) {
    Ok(rhs) => Some(rhs),
    // RequireCompatible rejects loads with ‖Lᵀ f‖₂ above tolerance using DomainError.
    Err(error) if error.kind() == SciOxideErrorKind::DomainError => None,
    Err(error) => return Err(error.to_string()),
};

    let tolerance = ResidualTolerance::new(1e-12, 1e-12).map_err(|e| e.to_string())?;
    let solver = MinresSolver::new(tolerance, Budget::try_from(50).map_err(|e| e.to_string())?);
    let result = solver
        .solve_with_options(&system.augmented(), &rhs, Preconditioning::None, None)
        .map_err(|e| e.to_string())?;
    let (u, multiplier) = (
        &result.solution().as_slice()[..n],
        result.solution().as_slice()[n],
    );
    let diagnostics = system
        .diagnose(&load[..], &rhs, u)
        .map_err(|e| e.to_string())?;

        .map(|i| (i, 1e3 * u[i], 1e3 * (exact[i] - mean)))

        .iter()
        .map(|row| (row.1 - row.2).abs())

        rows,

        { "key": "2", "label": "‖f − f̂‖₂ [N]", "type": "number", "format": sci2 },
        { "key": "3", "label": "‖Ku − f‖₂ [N]", "type": "number", "format": sci2 },
        { "key": "4", "label": "‖Ku − f̂‖₂ [N]", "type": "number", "format": sci2 },

## Summary

For range or null-space bases and principal angles, use `orth`, `null_space`, or `subspace_angles`, select `RankPolicy` to match data error, and check the assessment with report `rank` and `condition`.
If fewer principal angles appear than expected, inspect `SubspaceAnglesReport` to see which input lost rank.
Use `orthogonal_procrustes` for point-cloud alignment; when only rotations are meaningful and uniqueness is not `Unique`, check $\det R$ for reflections.
Use GSVD for problems involving two matrices simultaneously, reading infinite values with $\beta = 0$ and the common null space separately from ratios.
Solve singular systems with known null spaces through the augmented system of `BorderedSystem`; choose rejection or projection of incompatible right-hand sides from the physics, and check the original residual and gauge defect with `diagnose`.
