This table summarizes singular-value and eigenvalue decompositions, subspaces obtained from their results, generalized decompositions, and bordered systems with declared nullspaces.
Eigenvalue and singular-value types distinguish values-only types (`SvdValues`, `…ValuesResult`, `…ValuesBuffer`) from types also computing vectors (`…Decomposition`).

Factorizations offer three calling forms.
Their definitions are in [Calling forms](oxref:linalg-api-forms).
Standard forms (`compute(a)`, `decompose(a)`, `factor(a)`) use default settings; with-options forms (such as `compute_with_options`) take settings as their final argument.
Both are owning-result APIs allocating results and executing sequentially with `ExecutionContext::sequential_native()`; setting a time limit gives `CapabilityUnavailable`.
Caller-provided-output APIs (`compute_into`, `decompose_into`, `factor_into`) accept settings and caller-owned output, workspace, and context and write the output.
Obtain workspace requirements by passing a request (`…WorkspaceRequest`) to the result type's `workspace_requirements`.

Shape mismatch, non-finite inputs, `ConvergenceFailure` at iteration limits, and other factorization failures return `Err` and leave caller-provided output unchanged.
Owning-result `…ValuesResult` holds values and work report `EigenReport`; caller-provided-output `…ValuesBuffer` holds no report.
Condition-number and separation fields are estimates, not upper bounds.

## Summary

For singular values or eigenvalues, start with standard forms (`compute(a)`, `decompose(a)`) of `SvdValues` or `…ValuesResult` for values alone, or `…Decomposition` when vectors are also needed.
To change tolerances, order, balancing, or iteration limits, pass settings to with-options forms; for repeated problems of the same size, preallocate workspace from requests and use caller-provided-output APIs.
Numerical rank, subspaces, and Procrustes uniqueness classifications all depend on `RankPolicy` thresholds, inspected through report `rank` and `condition`.
GSVD, CS, and polar decompositions reject factors with reconstruction residuals above tolerance (also orthogonality errors for CS and polar) with `NumericalInstability`.
For singular systems with known nullspaces, construct a nonsingular augmented system through `BorderedSystem`, solve by direct or iterative methods, and check original-system residuals through `diagnose`.
