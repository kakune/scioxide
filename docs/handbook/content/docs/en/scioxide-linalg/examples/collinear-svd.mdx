Suppose the power consumption $y$ [W] of a device is to be explained by the readings $x$ and $z$ [°C] of two nearby temperature sensors through $y = \beta_1 x + \beta_2 z + \varepsilon$.
When the two sensors give nearly identical readings, the two columns of the design matrix become nearly parallel, making the individual coefficients difficult to determine (multicollinearity).
This example measures collinearity using the singular values of the design matrix and examines which directions in the least-squares coefficients become unstable.

---

## Coefficient variance and singular values

Let the SVD of the design matrix $X = [x, z] \in \mathbb{R}^{n \times 2}$ be $X = U \Sigma V^{\mathsf T}$; when the components of the noise $\varepsilon$ are independent with mean 0 and standard deviation $\sigma_\varepsilon$, the covariance of the least-squares estimate $\hat\beta = X^{+} y$ is

$$
\operatorname{Cov}(\hat\beta) = \sigma_\varepsilon^2 (X^{\mathsf T}X)^{-1} = \sum_{j} \frac{\sigma_\varepsilon^2}{\sigma_j^2}\, v_j v_j^{\mathsf T}
$$


The variance of the combination $v_2^{\mathsf T}\hat\beta$ along the direction associated with the small singular value $\sigma_2$ is $\sigma_\varepsilon^2/\sigma_2^2$, which increases as $\sigma_2$ decreases.
Meanwhile, the covariance of the predictions $\hat y = X\hat\beta$ is $\sigma_\varepsilon^2 U U^{\mathsf T}$ and remains at the noise scale regardless of the singular values.
Collinearity prevents the individual coefficients from being determined separately rather than reducing prediction accuracy.

## Closed forms for singular values and standard errors

Take $n = 20$ observations, repeating each value of $x$ twice ($x = 15.0, 15.0, 15.5, 15.5, \dots$ °C).
Suppose the other sensor reads $z_i = x_i + \delta (-1)^i$.
The alternating signs $s_i = (-1)^i$ are orthogonal to $x$ ($x^{\mathsf T}s = 0$), so setting $a = x^{\mathsf T}x$ and $c = n\delta^2/2$ gives

$$
X^{\mathsf T}X = \begin{pmatrix} a & a \\ a & a + 2c \end{pmatrix}, \qquad
\sigma_1^2 = a + c + \sqrt{a^2 + c^2}, \qquad \sigma_2^2 = \frac{2ac}{\sigma_1^2} \approx \frac{n\delta^2}{2}
$$

To avoid cancellation, compute $\sigma_2^2$ from the product $\sigma_1^2\sigma_2^2 = \det X^{\mathsf T}X = 2ac$.
For $n = 20$, we have $\sigma_2 \approx 3.16\,\delta$ and condition number $\kappa_2 = \sigma_1/\sigma_2 \approx \sqrt{2a}/(3.16\,\delta)$, which increases inversely with $\delta$.
The inverse $(X^{\mathsf T}X)^{-1} = \tfrac{1}{2ac}\bigl(\begin{smallmatrix} a + 2c & -a \\ -a & a \end{smallmatrix}\bigr)$ gives the following standard errors of the coefficients and their combinations:

```text
SE(β₁) = σ_ε √((a + 2c)/(2ac)),   SE(β₂) = σ_ε / √(2c),
SE(β₁ + β₂) = σ_ε / √a,           SE(β₁ − β₂) = σ_ε √((4a + 2c)/(2ac))
```


When $\delta$ is small, $\mathrm{SE}(\beta_1 - \beta_2) \approx 2\sigma_\varepsilon/(\delta\sqrt n)$ becomes large, whereas $\mathrm{SE}(\beta_1 + \beta_2) = \sigma_\varepsilon/\sqrt a$ is independent of $\delta$.

The following definitions block shares this model between two cells.
`design` corresponds to $X$; `observations` produces noisy $y$ using the true coefficients $\beta = (2, 1)$ W/°C and normally distributed noise; `fit` computes the singular values, least-squares solution, numerical rank, and truncated solution using `ThinSvdDecomposition`; and `closed_form` and `standard_errors` correspond to the closed forms above.

```rust
//| id: linalg-collinear-model
//| kind: definitions
//| title: "Collinear design matrix and closed-form singular values and standard errors"
//| crates: [scioxide-core, scioxide-linalg]
use scioxide_core::{SciOxideError, RankThreshold};
use scioxide_linalg::{Matrix, RankPolicy, ThinSvdDecomposition};

pub(crate) const N: usize = 20;

/// Design matrix X = [x, z] (each row contains x_i and z_i = x_i + δ(−1)^i).
pub(crate) fn design(delta: f64) -> Result<Matrix<f64>, SciOxideError> {
    let data = (0..N)
        .flat_map(|i| {
            let x = 15.0 + 0.5 * (i / 2) as f64;
            [x, x + delta * if i % 2 == 0 { 1.0 } else { -1.0 }]
        })
        .collect();
    Matrix::from_vec(N, 2, data)
}

/// Seeded standard-normal pseudorandom numbers (xorshift64* and Box–Muller).
pub(crate) fn gaussian(seed: u64, len: usize) -> Vec<f64> {
    let mut state = seed.wrapping_mul(0x9E37_79B9_7F4A_7C15) | 1;
    let mut uniform = move || {
        state ^= state >> 12;
        state ^= state << 25;
        state ^= state >> 27;
        ((state.wrapping_mul(0x2545_F491_4F6C_DD1D) >> 11) as f64 + 0.5) / (1u64 << 53) as f64
    };
    (0..len)
        .map(|_| {
            let (u, v) = (uniform(), uniform());
            (-2.0 * u.ln()).sqrt() * (2.0 * std::f64::consts::PI * v).cos()
        })
        .collect()
}

/// SVD fit results: singular values, least-squares solution, numerical rank, and solution truncated at 10⁻³σ₁.
pub(crate) struct Fit {
    pub(crate) sigma: [f64; 2],
    pub(crate) beta: [f64; 2],
    pub(crate) rank: usize,
    pub(crate) truncated: [f64; 2],
}

/// Fit y = 2x + z + σ_ε g (where g is standard normal noise) using SVD.
pub(crate) fn fit(delta: f64, noise: f64, seed: u64) -> Result<Fit, SciOxideError> {
    let x = design(delta)?;
    let g = gaussian(seed, N);
    let rows = x.as_slice();
    let y: Vec<f64> = (0..N)
        .map(|i| 2.0 * rows[2 * i] + rows[2 * i + 1] + noise * g[i])
        .collect();
    let svd = ThinSvdDecomposition::compute(&x)?;
    let beta = svd.solve(&y[..], RankPolicy::Exact, 0.0)?;
    let rank = svd.analyze_rank(RankPolicy::DimensionScaledEpsilon)?.rank();
    // If σ₂ < 10⁻³ σ₁, the minimum-norm solution discards the σ₂ direction.
    let threshold = RankPolicy::Threshold(RankThreshold::new(0.0, 1e-3)?);
    let truncated = svd.solve(&y[..], threshold, 0.0)?;
    let s = svd.singular_values();
    Ok(Fit {
        sigma: [s[0], s[1]],
        beta: [beta.as_slice()[0], beta.as_slice()[1]],
        rank,
        truncated: [truncated.as_slice()[0], truncated.as_slice()[1]],
    })
}

/// Closed-form (a, c, σ₁, σ₂) (reference values using standard f64 functions).
pub(crate) fn closed_form(delta: f64) -> (f64, f64, f64, f64) {
    let a: f64 = (0..N).map(|i| (15.0 + 0.5 * (i / 2) as f64).powi(2)).sum();
    let c = N as f64 * delta * delta / 2.0;
    let s1 = (a + c + (a * a + c * c).sqrt()).sqrt();
    (a, c, s1, (2.0 * a * c).sqrt() / s1)
}

/// Standard errors [SE(β₁), SE(β₂), SE(β₁ + β₂), SE(β₁ − β₂)] (reference values).
pub(crate) fn standard_errors(delta: f64, noise: f64) -> [f64; 4] {
    let (a, c, _, _) = closed_form(delta);
    [
        noise * ((a + 2.0 * c) / (2.0 * a * c)).sqrt(),
        noise / (2.0 * c).sqrt(),
        noise / a.sqrt(),
        noise * ((4.0 * a + 2.0 * c) / (2.0 * a * c)).sqrt(),
    ]
}
```

The next cell selects the sensor offset $\delta = 10^p$ °C ($p \in [-10, -1]$), noise $\sigma_\varepsilon = 10^q$ W ($q \in [-8, -1]$), and random seed, and compares the singular values from `ThinSvdDecomposition::compute` with the closed forms.
It also computes the numerical rank using `RankPolicy::DimensionScaledEpsilon`, the least-squares solution using `RankPolicy::Exact`, and the solution truncated at a threshold of $10^{-3}\sigma_1$.
The second table places the errors of the coefficients and their sum and difference beside their standard errors, checking whether noise explains the errors by seeing whether the error-to-standard-error ratios fall roughly within $\pm 2$.
$\delta$, $\sigma_\varepsilon$, and the seed are passed to the next cell.

```rust
let sig3 = serde_json::json!({ "significantDigits": 3 });

    { "key": "0", "label": "Quantity" },
    { "key": "1", "label": "SVD", "type": "number", "format": sci10 },
    { "key": "2", "label": "Closed form", "type": "number", "format": sci10 },
    { "key": "3", "label": "Relative difference [-]", "type": "number", "format": sci3 }
]);
let relative = |p: f64, q: f64| (p - q).abs() / q;
let kappa = result.sigma[0] / result.sigma[1];
let singular_rows = vec![
    ("σ₁", result.sigma[0], s1, relative(result.sigma[0], s1)),
    ("σ₂", result.sigma[1], s2, relative(result.sigma[1], s2)),
    ("κ₂ = σ₁/σ₂", kappa, s1 / s2, relative(kappa, s1 / s2)),

        "Numerical rank (DimensionScaledEpsilon)",
        result.rank as f64,
        2.0,
        relative(result.rank as f64, 2.0),
    ),

    singular_rows,
    metadata = serde_json::json!({ "id": "singular" })

// Target for the truncated solution: the pair (1.5, 1.5) from (β₁ + β₂)/2 if σ₂ is discarded, or the true values (2, 1) if it is retained.
let cut = result.sigma[1] < 1e-3 * result.sigma[0];
let target = if cut { [1.5, 1.5] } else { [2.0, 1.0] };
let [b1, b2] = result.beta;
let coefficient_rows = vec![
    ("β₁", b1, 2.0, Some(se[0])),
    ("β₂", b2, 1.0, Some(se[1])),
    ("β₁ + β₂", b1 + b2, 3.0, Some(se[2])),
    ("β₁ − β₂", b1 - b2, 1.0, Some(se[3])),
    ("β₁ of truncated solution", result.truncated[0], target[0], None),
    ("β₂ of truncated solution", result.truncated[1], target[1], None),
];
let coefficient_rows: Vec<_> = coefficient_rows
    .into_iter()
    .map(|(name, value, truth, se)| {
        let error = value - truth;
        (name, value, truth, error.abs(), se, se.map(|s| error / s))
    })
    .collect();
let coefficient_columns = serde_json::json!([
    { "key": "0", "label": "Quantity" },
    { "key": "1", "label": "Estimate [W/°C]", "type": "number", "format": sig8 },
    { "key": "2", "label": "True value / target [W/°C]", "type": "number", "format": sig3 },
    { "key": "3", "label": "Error magnitude [W/°C]", "type": "number", "format": sci3 },
    { "key": "4", "label": "Standard error [W/°C]", "type": "number", "format": sci3, "nullText": "—" },
    { "key": "5", "label": "Error / standard error [-]", "type": "number", "format": fixed2, "nullText": "—" }

```

With the defaults $\delta = 10^{-6}$ °C, $\sigma_\varepsilon = 10^{-3}$ W, and seed 1, $\sigma_2 = 3.162 \times 10^{-6}$ agrees with the closed form to relative difference $6.5 \times 10^{-10}$, and the condition number reaches $3.5 \times 10^{7}$.
The `DimensionScaledEpsilon` threshold is $n\varepsilon\sigma_1 \approx 4.9 \times 10^{-13}$; since $\sigma_2$ is well above it, the numerical rank remains 2.
For the individual coefficients, the error in $\beta_1$ reaches 422 W/°C, but this is 1.9 times the standard error $\mathrm{SE}(\beta_1) = 224$ W/°C and is explained by the noise $\sigma_\varepsilon$ divided by $\sigma_2$.
The coefficient sum $\beta_1 + \beta_2 = 3.0000123$ lies along $v_1 \propto (1, 1)$, so its error $1.2 \times 10^{-5}$ W/°C stays at the scale of the standard error $\sigma_\varepsilon/\sqrt a = 1.3 \times 10^{-5}$ W/°C.
For normally distributed noise, the error-to-standard-error ratio follows a standard normal distribution; changing the seed changes its sign and magnitude, and it falls within $\pm 1.96$ with approximately 95% probability.
Even when $\delta$ is reduced to $10^{-10}$ °C, the numerical rank remains 2, but the computed $\sigma_2$ has an absolute error of order $u\sigma_1$, so the relative difference from the closed form grows to $5.7 \times 10^{-6}$.
Rounding $z_i = x_i + \delta(-1)^i$ to floating point itself also adds a perturbation of the same order to $X$.

## Condition number and error as δ varies

The next cell receives $\sigma_\varepsilon$ and the seed from the previous cell and repeats the same fit at 19 points $\delta = 10^{-1}, 10^{-1.5}, \dots, 10^{-10}$ °C.

Each tenfold decrease in $\delta$ increases both the condition number and coefficient error tenfold, and the SVD condition number overlaps the dashed closed-form line ($\kappa_2 = 346$ at $\delta = 10^{-1}$ °C and $3.5 \times 10^{11}$ at $\delta = 10^{-10}$ °C).

The ratio is independent of $\delta$ because the noise component $u_2^{\mathsf T}\varepsilon$ in the small-singular-value direction is nearly independent of $\delta$.
Changing the noise $\sigma_\varepsilon$ shifts the error line up or down in proportion to $\sigma_\varepsilon$ while leaving the condition number line unchanged.

## Stabilization by truncation and its price

The last two rows of the coefficient table give the minimum-norm solution that discards singular values below $10^{-3}\sigma_1$.
With the default $\delta$, $\sigma_2$ is discarded and the solution approaches $(1.5, 1.5)$, which has only the $v_1$ direction; this is stable against noise but differs from the true values $(2, 1)$.
Truncation adds the assumption that components the data cannot determine are zero: it preserves the coefficient sum but loses information about the difference $\beta_1 - \beta_2$.
At $\delta = 10^{-1}$ °C, $\sigma_2/\sigma_1 \approx 3 \times 10^{-3}$ exceeds the threshold and is retained, giving the ordinary least-squares solution.
As a guide, choose the threshold from the ratio of the data noise level $\sigma_\varepsilon$ to the singular values rather than the rounding level (`DimensionScaledEpsilon`).

## Summary

When two explanatory variables give nearly identical values, the smallest singular value of the design matrix falls to $\delta\sqrt{n/2}$ and the condition number increases inversely with $\delta$.
The variance of the coefficient combination along direction $v_j$ is $\sigma_\varepsilon^2/\sigma_j^2$, so the small-singular-value direction (here $\beta_1 - \beta_2$) cannot be determined, while the large-singular-value direction ($\beta_1 + \beta_2$) is determined stably; both errors are explained by the closed-form standard errors.
The numerical rank depends on singular values relative to the threshold; even when a threshold at the rounding level does not indicate rank loss, noise can move the coefficients substantially.
When collinearity is suspected, inspect the singular values and use only coefficient combinations that can be determined, or suppress small-singular-value directions with [truncated SVD or Tikhonov regularization](../../algorithms/svd-and-rank/).
