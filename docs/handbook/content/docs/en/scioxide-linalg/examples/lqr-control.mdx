For machines and circuits described by the linear state equation $\dot x = Ax + Bu$, two basic control questions are which state directions are easy to move and what inputs stabilize the system.
The former is measured by the controllability Gramian, computed by solving a Lyapunov equation.
One answer to the latter is a linear quadratic regulator (LQR), which minimizes a quadratic cost in the state and input and is computed by solving an algebraic Riccati equation.
This example checks the two matrix equations using separate computational paths and closed forms.
Details of the solvers and reports are in [Sylvester, Lyapunov, and Riccati equations](../../algorithms/matrix-equations/).

## Controllability Gramian

If $A$ is stable (all eigenvalues have negative real parts), the following controllability Gramian is finite:

$$
W = \int_0^\infty e^{At} B B^{\mathsf T} e^{A^{\mathsf T} t}\, dt
$$

Differentiating the integrand with respect to $t$ and integrating shows that it satisfies the continuous-time Lyapunov equation $AW + WA^{\mathsf T} = -BB^{\mathsf T}$.
Among inputs that move the state from the origin to $x_f$ without a time limit, the minimum input energy $\int \lVert u \rVert^2 dt$ required is $x_f^{\mathsf T} W^{-1} x_f$.
Directions with smaller eigenvalues of $W$ require more energy to move the state.

For the oscillating system $m\ddot x + c\dot x + kx = u$ with mass $m$ [kg], damping coefficient $c$ [N·s/m], spring constant $k$ [N/m], and force $u$ [N], the state $(x, \dot x)$ gives

$$
A = \begin{bmatrix} 0 & 1 \\ -k/m & -c/m \end{bmatrix}, \quad B = \begin{bmatrix} 0 \\ 1/m \end{bmatrix}, \qquad W = \begin{bmatrix} 1/(2kc) & 0 \\ 0 & 1/(2mc) \end{bmatrix}
$$

These follow by expanding and solving the components of the Lyapunov equation.
The minimum energy to reach state $x_f = (1, 0)$ with displacement 1 m is $1/W_{11} = 2kc$ [N²·s], increasing with spring stiffness and damping.

As another computational path, compute the finite-time Gramian $W(T) = \int_0^T e^{At}BB^{\mathsf T}e^{A^{\mathsf T}t}dt$ using Van Loan's method.
Writing the exponential of the block matrix $C = \begin{bmatrix} -A & BB^{\mathsf T} \\ 0 & A^{\mathsf T} \end{bmatrix}$ as $e^{CT} = \begin{bmatrix} F_{11} & F_{12} \\ 0 & F_{22} \end{bmatrix}$ gives $W(T) = F_{22}^{\mathsf T} F_{12}$, which approaches $W$ as $T \to \infty$.
For damped oscillations ($c^2 < 4mk$), the integrand decays at rate $e^{-(c/m)t}$, so the difference $1 - W_{11}(T)/W_{11}$ approaches 0 at roughly this rate as well.
In the overdamped case ($c^2 > 4mk$), the slower mode decays more slowly than this, requiring more time to approach the limit.

Solve the Lyapunov equation with `LyapunovPlan`.
`LyapunovPlan::new(&a, LyapunovKind::Continuous, options)` is a Plan that computes the Schur form of $A$ once; `solve(&q)` solves $AX + XA^{\mathsf T} = Q$ using the Bartels–Stewart method and checks the residual of the original equation.
Pass the right-hand side as $Q = -BB^{\mathsf T}$, including the sign.
For the equation's three terms $T_1 = AX$, $T_2 = XA^{\mathsf T}$, and $T_3 = -Q$ and residual $R = T_1 + T_2 + T_3$, `MatrixEquationOptions::new()` accepts the solution when $\lVert R \rVert_F \le \mathrm{atol} + \mathrm{rtol}\,(\lVert T_1 \rVert_F + \lVert T_2 \rVert_F + \lVert T_3 \rVert_F)$ ($\mathrm{atol} = \mathrm{rtol} = \sqrt{\varepsilon_{\mathrm{mach}}}$).
The backward error is $\lVert R \rVert_F$ divided by the sum of the term norms.
The matrices on this page contain numerical values in SI units, with different units for different entries, so residuals and backward errors are measured using those numerical magnitudes.
The `solve` result contains the solution and report `MatrixEquationReport` (termination reason, residual, backward error, and separation estimate); a solution that fails the checks is not published and has `solution()` equal to `None`.
If no report is needed, the one-shot function `solve_lyapunov(&a, LyapunovKind::Continuous, &q)` returns only the solution matrix and turns rejection into a `NumericalInstability` error.
Compute the matrix exponential with the one-shot function `matrix_function(&c, MatrixFunction::Exp)` (scaling and squaring with Padé approximation).

//|       - {"artifact":"gramian","path":"/rows/2/1","approx":{"value":2.5,"rtol":1e-11}}

//|   - case: stiff-spring

//|       - {"artifact":"energy","path":"/rows/0/1","approx":{"value":40,"rtol":1e-12}}
//|       - {"path":"/outputs/3/state","equals":"satisfied"}
use scioxide_linalg::{
    DirectSolveTermination, LyapunovKind, LyapunovPlan, Matrix, MatrixEquationOptions,
    MatrixFunction, matrix_function,
};

let (m, c, k) = (mass, damping, stiffness);
// State (x [m], ẋ [m/s]), input u [N]. A = [[0, 1], [−k/m, −c/m]], B = [0, 1/m]ᵀ.
let a = Matrix::from_rows(&[[0.0, 1.0], [-k / m, -c / m]]).map_err(|e| e.to_string())?;
// LyapunovKind::Continuous solves A X + X Aᵀ = Q. For the controllability Gramian, Q = −B Bᵀ.
let rhs = Matrix::from_rows(&[[0.0, 0.0], [0.0, -1.0 / (m * m)]]).map_err(|e| e.to_string())?;
// The Plan computes the Schur form of A once; solve returns the solution and report.
let plan = LyapunovPlan::new(&a, LyapunovKind::Continuous, MatrixEquationOptions::new())
    .map_err(|e| e.to_string())?;
let result = plan.solve(&rhs).map_err(|e| e.to_string())?;
let report = result.report();
// Rejected solutions are not published (None).
let w: Option<Vec<f64>> = result.solution().map(|s| s.as_slice().to_vec());
// Closed form W = diag(1/(2kc), 1/(2mc)) (row-major entries).
let exact = [1.0 / (2.0 * k * c), 0.0, 0.0, 1.0 / (2.0 * m * c)];
let scale = exact[0].max(exact[3]);
// Van Loan: exp([[−A, BBᵀ], [0, Aᵀ]] T) = [[F₁₁, F₁₂], [0, F₂₂]] gives W(T) = F₂₂ᵀ F₁₂.
let finite = |t: f64| -> Result<[f64; 4], String> {
    let block = Matrix::from_rows(&[
        [0.0, -t, 0.0, 0.0],
        [k * t / m, c * t / m, 0.0, t / (m * m)],
        [0.0, 0.0, 0.0, -k * t / m],
        [0.0, 0.0, t, -c * t / m],
    ])
    .map_err(|e| e.to_string())?;
    let exp = matrix_function(&block, MatrixFunction::Exp).map_err(|e| e.to_string())?;
    let f = exp.as_slice();
    let mut out = [0.0_f64; 4];
    for i in 0..2 {
        for j in 0..2 {
            out[i * 2 + j] = (0..2)
                .map(|l| f[(l + 2) * 4 + i + 2] * f[l * 4 + j + 2])
                .sum();
        }
    }
    Ok(out)
};
// T = 24m/c, 12 times the reciprocal of the amplitude decay rate c/(2m).
let horizon = 24.0 * m / c;
let late = finite(horizon)?;
let rows: Vec<_> = [
    (0, "W₁₁ [m²/(N²·s)]"),
    (1, "W₁₂ [m²/(N²·s²)]"),
    (3, "W₂₂ [m²/(N²·s³)]"),
]
.iter()
.map(|&(index, name)| {
    let lyapunov = w.as_ref().map(|w| w[index]);
    let difference = lyapunov.map(|v| (v - exact[index]).abs() / scale);
    (name, lyapunov, exact[index], late[index], difference)
})
.collect();
let sig10 = serde_json::json!({ "significantDigits": 10 });
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let columns = serde_json::json!([
    { "key": "0", "label": "Component" },
    { "key": "1", "label": "Lyapunov", "type": "number", "format": sig10, "nullText": "Unpublished" },
    { "key": "2", "label": "Closed form", "type": "number", "format": sig10 },
    { "key": "3", "label": "W(T), T = 24m/c", "type": "number", "format": sig10 },
    { "key": "4", "label": "Relative difference [-]", "type": "number", "format": sci2, "nullText": "None" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "gramian" })
);
let termination = report.termination();
// Display termination reasons by their enum variant names.
let name = match termination {
    DirectSolveTermination::Accepted => "Accepted",
    DirectSolveTermination::RankDeficient => "RankDeficient",
    DirectSolveTermination::IllConditioned => "IllConditioned",
    DirectSolveTermination::ResidualRejected => "ResidualRejected",
    DirectSolveTermination::StabilityRejected => "StabilityRejected",
};
let energy_columns = serde_json::json!([
    { "key": "0", "label": "1/W₁₁ [N²·s]", "type": "number", "format": sig10, "nullText": "None" },
    { "key": "1", "label": "2kc [N²·s]", "type": "number", "format": sig10 },
    { "key": "2", "label": "Residual ‖R‖_F", "type": "number", "format": sci2 },
    { "key": "3", "label": "Backward error [-]", "type": "number", "format": sci2 },
    { "key": "4", "label": "Separation estimate", "type": "number", "format": sci2, "nullText": "None" },
    { "key": "5", "label": "Termination reason" }
]);
emit_table_with_columns!(
    energy_columns,
    vec![(
        w.as_ref().map(|w| 1.0 / w[0]),
        2.0 * k * c,
        report.residual(),
        report.backward_error(),
        report.separation(),
        name,
    )],
    metadata = serde_json::json!({ "id": "energy" })
);
// Plot W₁₁(T)/W₁₁ for T ∈ [0, T/2].
let mut points = Vec::new();
for step in 0..=40 {
    let t = 0.5 * horizon * f64::from(step) / 40.0;
    points.push([t, finite(t)?[0] / exact[0]]);
}
emit_line_chart!(
    &vec![serde_json::json!({ "name": "W₁₁(T)/W₁₁", "points": points })],
    options = &serde_json::json!({
        "xLabel": "Integration upper limit T [s]",
        "yLabel": "Ratio W₁₁(T)/W₁₁ [-]",
        "annotations": [
            { "kind": "line", "axis": "y", "value": 1.0, "label": "Limit as T → ∞" }
        ]
    })
);
let outcome = if termination.is_success() {
    Outcome::satisfied("Lyapunov solution accepted by the residual check")
} else {
    Outcome::failed("Lyapunov solution rejected")
};
emit_outcome!(
    outcome
        .status(name)
        .diagnostic("Residual", report.residual(), None)
        .diagnostic("Backward error", report.backward_error(), None)
);
```

With the defaults $m = 2$ kg, $c = 1$ N·s/m, and $k = 8$ N/m, the Lyapunov solution agrees with the closed form $W = \operatorname{diag}(0.0625, 0.25)$ within relative difference $3 \times 10^{-16}$, and the off-diagonal entry is of order $10^{-18}$.
The minimum energy to reach displacement 1 m is $2kc = 16$ N²·s, and both the residual and backward error are $6 \times 10^{-17}$.
Van Loan's $W(T)$ agrees with $W$ to 10 digits at $T = 24m/c = 48$ s.
In the plot, $W_{11}(T)/W_{11}$ exceeds 0.99 at $T = 9.6$ s; with $c = 0.1$ N·s/m, whose decay rate $c/m$ is ten times smaller, it does so at 96 s, ten times later.
Then $W$ increases tenfold in proportion to $1/c$, and reaching the same displacement requires only one tenth the energy, 1.6 N²·s.
At $k = 20$ N/m, $W_{11}$ decreases to 0.025 and the minimum energy increases to 40 N²·s.
For the overdamped parameters $m = 0.5$ kg, $c = 3$ N·s/m, and $k = 1$ N/m, the slower mode has eigenvalue $-0.35$ 1/s, so $W_{11}(T)$ at $T = 24m/c = 4$ s is 7 % below $W_{11}$.

## Optimal regulator for an inverted pendulum

Stabilize a pendulum with a particle of mass $m$ [kg] at the end of a light rod of length $\ell$ [m] in the inverted position using pivot torque $u$ [N·m].
For small angle $\theta$ [rad], the equation of motion is $m\ell^2\ddot\theta = mg\ell\,\theta + u$ ($g = 9.81$ m/s²), and the state $(\theta, \dot\theta)$ gives

$$
A = \begin{bmatrix} 0 & 1 \\ a & 0 \end{bmatrix}, \quad B = \begin{bmatrix} 0 \\ b \end{bmatrix}, \qquad a = \frac{g}{\ell}, \quad b = \frac{1}{m\ell^2}
$$


One of the eigenvalues $\pm\sqrt{a}$ is positive, so the pendulum falls without input.
The input minimizing cost $J = \int_0^\infty (q_1\theta^2 + q_2\dot\theta^2 + r u^2)\, dt$ is $u = -Kx$ with $K = r^{-1}B^{\mathsf T}X$, where $X$ is the stabilizing solution of the algebraic Riccati equation

$$
A^{\mathsf T}X + XA - XBr^{-1}B^{\mathsf T}X + Q = 0, \qquad Q = \operatorname{diag}(q_1, q_2)
$$

A stabilizing solution makes all eigenvalues of the closed loop $A - BK$ have negative real parts.
If $(A, B)$ is stabilizable and $(Q^{1/2}, A)$ is detectable, a unique stabilizing solution exists and is positive semidefinite.
This pendulum meets these conditions: $B$ and $AB = (b, 0)^{\mathsf T}$ are linearly independent, so $(A, B)$ is controllable, and $Q$ is positive definite.
When $\theta$ is measured in rad, $\dot\theta$ in rad/s, and $u$ in N·m, supply weights $q_1$, $q_2 = 1$, and $r$ as dimensionless numbers.
Expanding the components gives the following closed-form solution for $X = \begin{bmatrix} x_1 & x_2 \\ x_2 & x_3 \end{bmatrix}$:

$$
x_2 = \frac{r}{b^2}\Bigl(a + \sqrt{a^2 + q_1 b^2/r}\Bigr), \quad x_3 = \sqrt{\frac{r}{b^2}(2x_2 + q_2)}, \quad x_1 = \frac{b^2}{r}x_2x_3 - a\,x_3
$$


The closed-loop characteristic equation is $\lambda^2 + bk_2\lambda + (bk_1 - a) = 0$; since $bk_1 - a = \sqrt{a^2 + q_1b^2/r} > 0$ and $bk_2 = (b^2/r)\,x_3 > 0$, the closed loop is stable.
The minimum cost from initial state $x_0$ is $J^\ast = x_0^{\mathsf T} X x_0$.
To check this independently, solve the Lyapunov equation $A_K^{\mathsf T}P + PA_K = -(Q + K^{\mathsf T}rK)$ for the closed loop $A_K = A - BK$.
Since $P$ gives the cost $J = x_0^{\mathsf T}Px_0$ of the same control law, we expect $P = X$.

Solve the Riccati equation with `RiccatiPlan`.
Pass the coefficients as matrix views in `RiccatiProblem { a, b, q, r, e, s }`; `e: None` represents $E = I$ and `s: None` represents the cross term $S = 0$.
`RiccatiPlan::new(problem, RiccatiKind::Continuous, options)` constructs an extended pencil of order $2n + m$ and obtains the stable deflating subspace using the QZ method and eigenvalue reordering ($O((n+m)^3)$ for $n$ states and $m$ inputs).
It does not check stabilizability or detectability; preparation fails with a `NumericalInstability` (`IllConditioned`) error if pencil eigenvalues are near the imaginary axis or the number of stable eigenvalues is not $n$.
`solve()` extracts $X$ and $K$ from the subspace and checks the residual of the original equation (default tolerances $\sqrt{\varepsilon_{\mathrm{mach}}}$).
With `RiccatiOptions::with_closed_loop_verification(Estimation::Estimate)`, `solve()` also computes eigenvalues of the closed-loop pencil $(A - BK, E)$ using QZ.
The report's `stability_margin()` is the minimum margin $-\operatorname{Re}\alpha/\max(\lvert\alpha\rvert, \lvert\beta\rvert)$ in homogeneous coordinates for eigenvalue $\lambda = \alpha/\beta$; with $E = I$ and $\beta > 0$, this becomes $-\operatorname{Re}\lambda/\max(\lvert\lambda\rvert, 1)$.
If this value is at most the stability tolerance (default $\mathrm{atol} = \mathrm{rtol} = \varepsilon_{\mathrm{mach}}$), the termination reason is `StabilityRejected`.
Only accepted solutions have `solution()` and `gain()` return $X$ and $K$.
Unlike the defaults of `RiccatiOptions`, the one-shot function `solve_riccati(problem, RiccatiKind::Continuous)` enables closed-loop verification (another $O(n^3)$ QZ computation) and returns accepted $(X, K)$.
Rejection becomes an error: `NumericalInstability` (`IllConditioned`) when the closed-loop stability margin is at most the tolerance, or `NumericalInstability` (`LossOfSignificance`) when the residual exceeds tolerance.
The `RiccatiPlan` in this cell requests the same verification, so the two paths perform the same computation.

    b: bm.view(),
    q: qm.view(),
    r: rm.view(),
    e: None,
    s: None,
};
// The Plan obtains the stable deflating subspace with a QZ decomposition of the extended pencil; solve extracts X and K.
// Enabling closed-loop pole verification (QZ) includes the stability margin in the report.
let options = RiccatiOptions::new().with_closed_loop_verification(Estimation::Estimate);
let plan =
    RiccatiPlan::new(problem, RiccatiKind::Continuous, options).map_err(|e| e.to_string())?;
let result = plan.solve().map_err(|e| e.to_string())?;
let report = result.report();
let termination = report.termination();
let name = match termination {
    DirectSolveTermination::Accepted => "Accepted",
    DirectSolveTermination::RankDeficient => "RankDeficient",
    DirectSolveTermination::IllConditioned => "IllConditioned",
    DirectSolveTermination::ResidualRejected => "ResidualRejected",
    DirectSolveTermination::StabilityRejected => "StabilityRejected",
};
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let sig4 = serde_json::json!({ "significantDigits": 4 });
let columns = serde_json::json!([
    { "key": "0", "label": "Termination reason" },
    { "key": "1", "label": "Residual ‖Res‖_F", "type": "number", "format": sci2 },
    { "key": "2", "label": "Backward error [-]", "type": "number", "format": sci2 },
    { "key": "3", "label": "Deflating subspace reciprocal condition number [-]", "type": "number", "format": sig4 },
    { "key": "4", "label": "Stability margin [-]", "type": "number", "format": sig4, "nullText": "None" }
]);
emit_table_with_columns!(
    columns,
    vec![(
        name,
        report.residual(),
        report.backward_error(),
        report.subspace_reciprocal_condition(),
        report.stability_margin(),
    )],
    metadata = serde_json::json!({ "id": "riccati" })
);
// X and K are published only when accepted.
let mut gain_export = None;
if let Some((x, gain)) = result.solution().zip(result.gain()) {
    let (x, k) = (x.as_slice(), gain.as_slice());
    // Closed-form X and K (for checking).
    // x₂ = (r/b²)(a + √(a² + q₁b²/r)), x₃ = √((r/b²)(2x₂ + q₂)), x₁ = (b²/r)x₂x₃ − a x₃.
    let x2 = r / (b * b) * (a + (a * a + q1 * b * b / r).sqrt());
    let x3 = (r / (b * b) * (2.0 * x2 + q2)).sqrt();
    let closed = [b * b / r * x2 * x3 - a * x3, x2, x2, x3];
    let scale = closed.iter().fold(0.0_f64, |s, v| s.max(v.abs()));
    let differ = |u: &[f64]| {
        u.iter()
            .zip(&closed)
            .fold(0.0_f64, |s, (p, q)| s.max((p - q).abs()))
            / scale
    };
    // The one-shot function also verifies closed-loop poles and returns only accepted X and K.
    let (x_one, _) =
        solve_riccati(problem, RiccatiKind::Continuous).map_err(|e| e.to_string())?;
    // Closed loop A_K = A − BK and the Lyapunov equation for the cost of the same control law
    // A_Kᵀ P + P A_K = −(Q + Kᵀ r K).
    let ak = Matrix::from_rows(&[[0.0, 1.0], [a - b * k[0], -b * k[1]]])
        .map_err(|e| e.to_string())?;
    let weight = Matrix::from_rows(&[
        [-(q1 + r * k[0] * k[0]), -r * k[0] * k[1]],
        [-r * k[0] * k[1], -(q2 + r * k[1] * k[1])],
    ])
    .map_err(|e| e.to_string())?;
    let p = solve_lyapunov(ak.view().transpose(), LyapunovKind::Continuous, &weight)
        .map_err(|e| e.to_string())?;
    let check_columns = serde_json::json!([
        { "key": "0", "label": "k₁ [N·m/rad]", "type": "number", "format": sig4 },
        { "key": "1", "label": "k₂ [N·m·s/rad]", "type": "number", "format": sig4 },
        { "key": "2", "label": "Relative difference of X from closed form [-]", "type": "number", "format": sci2 },
        { "key": "3", "label": "Difference of solve_riccati X from closed form [-]", "type": "number", "format": sci2 },
        { "key": "4", "label": "Relative difference of P from closed form [-]", "type": "number", "format": sci2 },
        { "key": "5", "label": "Minimum cost J* = x₀ᵀXx₀ [-]", "type": "number", "format": sig4 },
        { "key": "6", "label": "Initial torque u(0) [N·m]", "type": "number", "format": sig4 }
    ]);
    emit_table_with_columns!(
        check_columns,
        vec![(
            k[0],
            k[1],
            differ(x),
            differ(x_one.as_slice()),
            differ(p.as_slice()),
            0.01 * x[0],
            -0.1 * k[0],
        )],
        metadata = serde_json::json!({ "id": "checks" })
    );
    // Closed-loop poles: eigenvalue solver and roots of λ² + bk₂λ + (bk₁ − a) = 0 using closed-form K.
    let poles = GeneralEigenvaluesResult::compute(&ak).map_err(|e| e.to_string())?;
    let mut computed: Vec<(f64, f64)> =
        poles.eigenvalues().iter().map(|z| (z.re, z.im)).collect();
    let (damping, stiffness) = (b * b / r * x3, b * b / r * x2 - a);
    let discriminant = damping * damping - 4.0 * stiffness;
    let mut formula = if discriminant >= 0.0 {
        let root = discriminant.sqrt();
        vec![
            (-0.5 * (damping + root), 0.0),
            (-0.5 * (damping - root), 0.0),
        ]
    } else {
        let root = (-discriminant).sqrt();
        vec![(-0.5 * damping, -0.5 * root), (-0.5 * damping, 0.5 * root)]
    };
    computed.sort_by(|p, q| p.partial_cmp(q).unwrap_or(std::cmp::Ordering::Equal));
    formula.sort_by(|p, q| p.partial_cmp(q).unwrap_or(std::cmp::Ordering::Equal));
    let pole_rows: Vec<_> = computed
        .iter()
        .zip(&formula)
        .enumerate()
        .map(|(j, (z, f))| (j + 1, z.0, z.1, f.0, f.1))
        .collect();
    let pole_columns = serde_json::json!([
        { "key": "0", "label": "Pole", "type": "integer" },
        { "key": "1", "label": "Real part [1/s]", "type": "number", "format": sig4 },
        { "key": "2", "label": "Imaginary part [1/s]", "type": "number", "format": sig4 },
        { "key": "3", "label": "Closed-form real part [1/s]", "type": "number", "format": sig4 },
        { "key": "4", "label": "Closed-form imaginary part [1/s]", "type": "number", "format": sig4 }
    ]);
    emit_table_with_columns!(
        pole_columns,
        pole_rows,
        metadata = serde_json::json!({ "id": "poles" })
    );
    gain_export = Some([k[0], k[1]]);
}
// Pass coefficients and gain to the response cell (gain is null if rejected).
export!(a, a);
export!(b, b);
export!(gain, gain_export);
let outcome = if termination.is_success() {
    Outcome::satisfied("Riccati solution accepted by residual and closed-loop stability checks")
} else {
    Outcome::failed("Riccati solution rejected")
};
let mut outcome = outcome
    .status(name)
    .diagnostic("Residual", report.residual(), None)
    .diagnostic("Backward error", report.backward_error(), None);
if let Some(margin) = report.stability_margin() {
    outcome = outcome.diagnostic("Stability margin", margin, None);
}
emit_outcome!(outcome);
```


With the defaults $m = 0.2$ kg, $\ell = 0.5$ m, $q_1 = 10$, and $r = 0.1$, `RiccatiPlan` returns `Accepted`, with residual $4.0 \times 10^{-14}$ and backward error $1.3 \times 10^{-15}$.
The gain is $K = (11.03\ \mathrm{N·m/rad}, 3.332\ \mathrm{N·m·s/rad})$; $X$ agrees with the closed form to relative difference $3 \times 10^{-16}$ and differs by the same amount from the `solve_riccati` solution.
The Lyapunov equation's $P$ also agrees with the closed form to a difference of at most $10^{-17}$, independently confirming that $X$ gives the minimum cost.
The open-loop poles $\pm 4.43$ 1/s move to two negative real closed-loop poles $-63.48$ and $-3.166$, and the eigenvalue solver agrees with the characteristic roots to 14 digits.
Both poles lie on the negative real axis with magnitudes at least 1, so the stability margin is 1.
The minimum cost is $J^\ast = 0.03348$ and the initial torque is $-1.103$ N·m.

With $q_1 = 100$ and $r = 0.001$, the poles move to $-632.4$ and $-10.00$, and the initial torque magnitude increases to 31.7 N·m.
With $q_1 = 1$ and $r = 1$, the slow pole approaches the imaginary axis at $-1.340$.
With $m = 1$ kg, $\ell = 1$ m, $q_1 = 100$, and $r = 1$, the poles form a complex conjugate pair $-3.487 \pm 1.360\mathrm{i}$, and the stability margin decreases to $3.487/\lvert\lambda\rvert = 0.932$.

## Closed-loop response

The closed loop $\dot x = A_Kx$ has solution $x(t) = e^{A_Kt}x_0$; from initial state $x_0 = (\theta_0, 0)$, the angle for real poles $\lambda_1 \ne \lambda_2$ is

$$
\theta(t) = \theta_0\,\frac{\lambda_2 e^{\lambda_1 t} - \lambda_1 e^{\lambda_2 t}}{\lambda_2 - \lambda_1}
$$

For a complex conjugate pair $\lambda = \sigma \pm \mathrm{i}\omega$, it is $\theta(t) = \theta_0 e^{\sigma t}(\cos\omega t - (\sigma/\omega)\sin\omega t)$.
The next cell receives $a$, $b$, and $K$ from the previous cell, selects initial angle $\theta_0$ (0.02–0.3 rad), and evaluates $e^{A_Kt}$ with `matrix_function` for $t = 0, 0.05, \ldots, 3$ s.
The table shows the angle and torque $u = -Kx$ at 6 times and the difference between the matrix-exponential angle and the closed form above, divided by $\theta_0$.
The two plots show angle and torque, with linked time axes.

```rust
//| id: linalg-lqr-response
//| ref: linalg-lqr-response
//| title: "Closed-loop response of the inverted pendulum"
//| run: reactive
//| crates: [scioxide-core, scioxide-linalg]
//| dependsOn:
//|   solve: linalg-lqr-riccati
//| inputs:
//|   initial_angle: {"type":"range","label":"Initial angle θ₀ [rad]","description":"Initial angular velocity is 0.","min":0.02,"max":0.3,"step":0.02,"value":0.1}
//| cases:
//|   - {"id":"large-angle","label":"θ₀ = 0.3 rad","description":"In the linear closed loop, both angle and torque are proportional to θ₀ and become 3 times larger.","inputs":{"initial_angle":0.3}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"response","path":"/rows/2/1","approx":{"value":0.004439,"rtol":1e-3}}
//|       - {"artifact":"response","path":"/rows/2/3","range":{"max":1e-12}}
//|       - {"artifact":"response","path":"/rows/0/2","approx":{"value":-1.102900283638495,"rtol":1e-10}}
//|   - case: large-angle
//|     expect:
//|       - {"artifact":"response","path":"/rows/2/1","approx":{"value":0.013317,"rtol":1e-3}}
//|       - {"artifact":"response","path":"/rows/4/3","range":{"max":1e-12}}
use scioxide_linalg::{Matrix, MatrixFunction, matrix_function};

let a = solve["a"].as_f64().ok_or("a is missing")?;
let b = solve["b"].as_f64().ok_or("b is missing")?;
let gain = solve["gain"]
    .as_array()
    .ok_or("Riccati solution rejected")?;
let k1 = gain[0].as_f64().ok_or("k₁ is missing")?;
let k2 = gain[1].as_f64().ok_or("k₂ is missing")?;
let ak = Matrix::from_rows(&[[0.0, 1.0], [a - b * k1, -b * k2]]).map_err(|e| e.to_string())?;
// Closed form (for checking): θ(t) from roots of the characteristic equation λ² + bk₂λ + (bk₁ − a) = 0.
let (damping, stiffness) = (b * k2, b * k1 - a);
let discriminant = damping * damping - 4.0 * stiffness;
let modal = |t: f64| {
    if discriminant > 0.0 {
        let root = discriminant.sqrt();
        let (l1, l2) = (-0.5 * (damping + root), -0.5 * (damping - root));
        initial_angle * (l2 * (l1 * t).exp() - l1 * (l2 * t).exp()) / (l2 - l1)
    } else {
        let (sigma, omega) = (-0.5 * damping, 0.5 * (-discriminant).sqrt());
        initial_angle
            * (sigma * t).exp()
            * ((omega * t).cos() - sigma / omega * (omega * t).sin())
    }
};
// Response x(t) = exp(A_K t) x₀ and torque u = −K x from initial state x₀ = (θ₀, 0).
let (mut angle, mut torque, mut rows) = (Vec::new(), Vec::new(), Vec::new());
for step in 0..=60 {
    let t = 0.05 * f64::from(step);
    let scaled = ak.view().try_scale(t).map_err(|e| e.to_string())?;
    let e = matrix_function(&scaled, MatrixFunction::Exp).map_err(|e| e.to_string())?;
    let (theta, omega) = (
        initial_angle * e.as_slice()[0],
        initial_angle * e.as_slice()[2],
    );
    let u = -(k1 * theta + k2 * omega);
    angle.push([t, theta]);
    torque.push([t, u]);
    if matches!(step, 0 | 10 | 20 | 30 | 40 | 60) {
        rows.push((t, theta, u, (theta - modal(t)).abs() / initial_angle));
    }
}
let sig4 = serde_json::json!({ "significantDigits": 4 });
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let columns = serde_json::json!([
    { "key": "0", "label": "Time t [s]", "type": "number", "format": { "fractionDigits": 1 } },
    { "key": "1", "label": "Angle θ [rad]", "type": "number", "format": sig4 },
    { "key": "2", "label": "Torque u [N·m]", "type": "number", "format": sig4 },
    { "key": "3", "label": "Difference from closed form / θ₀ [-]", "type": "number", "format": sci2 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "response" })
);
emit_line_chart!(
    &vec![serde_json::json!({ "name": "Angle θ", "points": angle })],
    options = &serde_json::json!({
        "link": { "group": "lqr-response" },
        "xLabel": "Time t [s]",
        "yLabel": "Angle θ [rad]"
    })
);
emit_line_chart!(
    &vec![serde_json::json!({ "name": "Torque u", "points": torque })],
    options = &serde_json::json!({
        "link": { "group": "lqr-response" },
        "xLabel": "Time t [s]",
        "yLabel": "Torque u [N·m]"
    })
);
```

With the default $\theta_0 = 0.1$ rad, the initial torque has magnitude 1.10 N·m, and the angle returns monotonically to 0, reaching 0.0044 rad after 1 s.
The matrix-exponential angle agrees with the closed form to a difference of at most $10^{-15}$ times $\theta_0$.
Since the closed loop is linear, both angle and torque triple at $\theta_0 = 0.3$ rad.
Setting the previous cell to $q_1 = 100$ and $r = 0.001$ restores the angle faster, but the torque changes sign after 0.05 s.
With $q_1 = 1$ and $r = 1$, the slow pole leaves an angle of 0.0019 rad even after 3 s.

## Summary

Compute the controllability Gramian by solving a Lyapunov equation with `solve_lyapunov` or `LyapunovPlan`, and use the Plan report to read acceptance and residuals.
Use Van Loan's method for a finite-time Gramian $W(T)$ or an independent check; in the default damped-oscillation example, taking $T$ as 12 times the amplitude e-folding time $2m/c$ (a decrease by a factor of $e$) agreed with the infinite-time value to 10 digits.
Use the LQR gain after confirming acceptance in the `RiccatiPlan` report (residual, deflating subspace reciprocal condition number, and stability margin from `with_closed_loop_verification`); if no report is needed, use `solve_riccati`, which also verifies closed-loop stability.
Recomputing the cost of the same gain with the Lyapunov solution $P$ makes $P = X$ a check of the gain's optimality.
Increasing weight $q_1/r$ moves the closed-loop poles left and restores the angle faster, but increases the initial torque; choose weights by balancing input limits and response speed.
