A birth–death process is a stochastic process whose state increases or decreases by one at each transition, such as the number of customers waiting at a counter, individuals in a population, or molecules in a chemical reaction.
In discrete time, suppose the states are $n \in \{0, 1, \dots, K\}$, with each step moving to $n + 1$ with probability $p$ or $n - 1$ with probability $q$ and staying put with the remaining probability (without moving outside the endpoints).
Time is measured in single transitions, called steps.
This example computes the long-time distribution (stationary distribution) as a linear algebra null-space problem and estimates the speed of approach (mixing time) from eigenvalues.

---

## Stationary distribution and null space

Entry $P_{ij}$ of the transition matrix $P$ is the probability of moving from state $i$ to $j$, and each row sums to 1.
For a birth–death chain, $P$ is tridiagonal with $P_{n,n+1} = p$, $P_{n,n-1} = q$, and $P_{nn} = 1 - p - q$ (at the endpoints, $P_{00} = 1 - p$ and $P_{KK} = 1 - q$).
The probability distribution $x_t$ (a row vector) evolves as $x_{t+1} = x_t P$, so the stationary distribution $\pi$ satisfies

$$
\pi^{\mathsf T} P = \pi^{\mathsf T} \quad\Longleftrightarrow\quad (P^{\mathsf T} - I)\, \pi = 0, \qquad \sum_n \pi_n = 1
$$


If the chain is irreducible (every state can reach every other state), the null space of $P^{\mathsf T} - I$ is one-dimensional, and normalizing its basis to sum to 1 gives $\pi$.
`null_space(&a, policy)` returns an orthonormal null-space basis from the SVD right singular vectors, with `RankPolicy` determining which singular values count as 0 ([Range and null-space bases](oxref:linalg-range-null-bases)).
This page uses `RankPolicy::DimensionScaledEpsilon`, which treats singular values at most $(K+1)\varepsilon$ times the largest as 0.

## Detailed balance and closed forms

Birth–death processes are reversible, with balanced probability flow between neighboring states (detailed balance).

$$
\pi_n\, p = \pi_{n+1}\, q \quad\Longrightarrow\quad \pi_n = \frac{1 - \rho}{1 - \rho^{K+1}}\, \rho^{n}, \qquad \rho = \frac{p}{q}
$$

For $\rho = 1$, the distribution is uniform, $1/(K+1)$.
Probability concentrates near state 0 for $\rho < 1$ and near $K$ for $\rho > 1$.

Under detailed balance, the similarity transformation $S = D^{1/2} P D^{-1/2}$ with $D = \operatorname{diag}(\pi)$ is symmetric tridiagonal, with off-diagonal entries $\sqrt{pq}$ and the same diagonal as $P$.
All eigenvalues of $P$ are therefore real and can be computed as eigenvalues of $S$ using a tridiagonal eigensolver.
For an orthonormal eigenvector $u$ of $S$, the right eigenvector of $P$ is $x = D^{-1/2}u$ and its left eigenvector is $y = D^{1/2}u$.

The eigenvalues also have a closed form.
The differences $\delta_n = x_{n+1} - x_n$ ($n = 0, \dots, K-1$) of a right eigenvector $Px = \lambda x$ form an eigenvector of the order-$K$ tridiagonal Toeplitz matrix with diagonal $1 - p - q$, subdiagonal $q$, and superdiagonal $p$, giving

$$
\lambda_1 = 1, \qquad \lambda_{j+1} = 1 - p - q + 2\sqrt{pq}\,\cos\frac{j\pi}{K+1} \quad (j = 1, \dots, K)
$$

The constant vector with $\delta = 0$ corresponds to $\lambda_1 = 1$.
For $p + q \le 1$, the value at $j = 1$ is second largest in magnitude, so $\lvert\lambda_2\rvert = 1 - p - q + 2\sqrt{pq}\cos(\pi/(K+1))$.
The gap $\gamma = 1 - \lvert\lambda_2\rvert$ is

$$
\gamma = (\sqrt p - \sqrt q)^2 + 2\sqrt{pq}\left(1 - \cos\frac{\pi}{K+1}\right)
$$

For $p \ne q$, the first term remains even as $K$ grows.
For $p = q$, the first term vanishes, and $\gamma \approx p\pi^2/(K+1)^2$ decreases in proportion to $K^{-2}$.

The following definitions block shares this model between two cells.
`entry` corresponds to transition probability $P_{ij}$, `transition` to transition matrix $P$, and `stationary` to the detailed-balance closed-form stationary distribution ($q = 0.4$ is fixed).

```rust
//| id: linalg-birth-death-model
//| kind: definitions
//| title: "Birth–death transition matrix and closed-form stationary distribution"
//| crates: [scioxide-core, scioxide-linalg]
use scioxide_core::SciOxideError;
use scioxide_linalg::Matrix;

/// Decrease probability q (fixed).
pub(crate) const Q: f64 = 0.4;

/// Transition probabilities P_ij for states 0, …, K (increase probability p, decrease probability q, no moves outside the endpoints).
pub(crate) fn entry(k: usize, p: f64, i: usize, j: usize) -> f64 {
    if j == i + 1 {
        p
    } else if j + 1 == i {
        Q
    } else if i == j {
        let leave = if i == 0 {
            p
        } else if i == k {
            Q
        } else {
            p + Q
        };
        1.0 - leave
    } else {
        0.0
    }
}

/// Transition matrix P ((K + 1) × (K + 1), each row sums to 1).
pub(crate) fn transition(k: usize, p: f64) -> Result<Matrix<f64>, SciOxideError> {
    let dim = k + 1;
    let data = (0..dim * dim)
        .map(|idx| entry(k, p, idx / dim, idx % dim))
        .collect();
    Matrix::from_vec(dim, dim, data)
}

/// Closed form πₙ = (1 − ρ)ρⁿ/(1 − ρ^{K+1}) (ρ = p/q; uniform for ρ = 1; reference values).
pub(crate) fn stationary(k: usize, p: f64) -> Vec<f64> {
    let rho = p / Q;
    let dim = k + 1;
    (0..dim)
        .map(|n| {
            if (rho - 1.0).abs() < 1e-12 {
                1.0 / dim as f64
            } else {
                (1.0 - rho) / (1.0 - rho.powi(dim as i32)) * rho.powi(n as i32)
            }
        })
        .collect()
}
```

The next cell fixes $q = 0.4$ and selects maximum state $K \in [5, 60]$ and increase probability $p \in [0.04, 0.56]$.
It compares the null-space $\pi$ with the closed form, and computes $\lvert\lambda_2\rvert$ through two paths for comparison with the closed form.
The tridiagonal path passes $S$ to `HermitianEigenDecomposition::tridiagonal(&diag, &off)`, while the general path passes nonsymmetric $P$ to `GeneralEigenvaluesResult::compute(&p)`.
`null_space` and both eigenvalue computations use functions of the owned-result API with default settings ([Calling forms](oxref:linalg-execution-forms)).
The table shows null-space dimension and rank, the maximum difference between $\pi$ and the closed form, the closed-form $\lvert\lambda_2\rvert$ and each path's error, and the gap; the plot overlays $\pi$ and the closed form (dashed).
$K$, $p$, the tridiagonal path's $\lvert\lambda_2\rvert$, and closed-form $\pi$ are passed to the next cell.

```rust
//| run: reactive
//| uses: [linalg-birth-death-model]
//| crates: [scioxide-core, scioxide-linalg]
//| exports: [states, birth, lambda2, pi]
//| inputs:
//|   states: {"type":"range","label":"Maximum state K","description":"States are 0, 1, …, K.","min":5,"max":60,"step":1,"value":20}

//|   - case: default
//|     expect:
//|       - {"artifact":"stationary","path":"/rows/0/0","equals":1}
//|       - {"artifact":"stationary","path":"/rows/0/1","equals":20}
//|       - {"artifact":"stationary","path":"/rows/0/2","range":{"max":1e-13}}
//|       - {"artifact":"stationary","path":"/rows/0/4","range":{"max":1e-14}}

//|   - case: strongly-tilted
//|     expect:
//|       - {"artifact":"stationary","path":"/rows/0/4","range":{"max":1e-14}}
//|       - {"artifact":"stationary","path":"/rows/0/5","range":{"min":1e-12,"max":1e-6}}
//|   - case: balanced
//|     expect:
//|       - {"artifact":"stationary","path":"/rows/0/6","approx":{"value":0.0089353,"atol":1e-6}}
use scioxide_linalg::{
    GeneralEigenvaluesResult, HermitianEigenDecomposition, Matrix, RankPolicy, null_space,
};

let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let fixed8 = serde_json::json!({ "fractionDigits": 8 });
let fixed6 = serde_json::json!({ "fractionDigits": 6 });
let (k, p) = (states.round() as usize, birth);
let dim = k + 1;
let matrix = transition(k, p).map_err(|e| e.to_string())?;
// Compute a basis for the null space of (Pᵀ − I) and normalize it to sum to 1.
let data = (0..dim * dim)
    .map(|idx| {
        let (i, j) = (idx / dim, idx % dim);
        entry(k, p, j, i) - if i == j { 1.0 } else { 0.0 }
    })
    .collect();
let shifted = Matrix::from_vec(dim, dim, data).map_err(|e| e.to_string())?;
let kernel =
    null_space(&shifted, RankPolicy::DimensionScaledEpsilon).map_err(|e| e.to_string())?;
let basis = kernel.basis();
let column: Vec<f64> = (0..dim)
    .map(|i| basis.as_slice()[i * basis.cols()])
    .collect();
let total: f64 = column.iter().sum();
let pi: Vec<f64> = column.iter().map(|v| v / total).collect();
let exact = stationary(k, p);
let pi_error = pi
    .iter()
    .zip(&exact)
    .fold(0.0_f64, |m, (a, b)| m.max((a - b).abs()));
// λ₂: symmetrized tridiagonal S (same diagonal as P, off-diagonal √(pq)) and general eigenvalues of nonsymmetric P.
let diag: Vec<f64> = (0..dim).map(|i| entry(k, p, i, i)).collect();
let off = vec![(p * Q).sqrt(); dim - 1];
let tri = HermitianEigenDecomposition::tridiagonal(&diag, &off).map_err(|e| e.to_string())?;
let mut by_size: Vec<f64> = tri.eigenvalues().iter().map(|v| v.abs()).collect();
by_size.sort_by(|a, b| b.total_cmp(a));
let general = GeneralEigenvaluesResult::compute(&matrix).map_err(|e| e.to_string())?;
let mut general_size: Vec<f64> = general.eigenvalues().iter().map(|z| z.norm()).collect();
general_size.sort_by(|a, b| b.total_cmp(a));
let (lambda2, lambda2_general) = (by_size[1], general_size[1]);
// Check: closed form |λ₂| = 1 − p − q + 2√(pq) cos(π/(K+1)) (reference using standard f64 functions).
let angle = std::f64::consts::PI / dim as f64;
let closed = 1.0 - p - Q + 2.0 * (p * Q).sqrt() * angle.cos();

let columns = serde_json::json!([
    { "key": "0", "label": "Null-space dimension", "type": "integer" },
    { "key": "1", "label": "Rank", "type": "integer" },
    { "key": "2", "label": "max |πₙ − closed form| [-]", "type": "number", "format": sci2 },
    { "key": "3", "label": "|λ₂| (closed form) [-]", "type": "number", "format": fixed8 },
    { "key": "4", "label": "Tridiagonal |λ₂| error [-]", "type": "number", "format": sci2 },
    { "key": "5", "label": "General eigenvalue |λ₂| error [-]", "type": "number", "format": sci2 },
    { "key": "6", "label": "Gap 1 − |λ₂| [-]", "type": "number", "format": fixed6 }
]);
let row = (
    basis.cols(),
    kernel.report().rank().rank(),
    pi_error,
    closed,
    (lambda2 - closed).abs(),
    (lambda2_general - closed).abs(),
    1.0 - lambda2,
);
emit_table_with_columns!(
    columns,
    vec![row],
    metadata = serde_json::json!({ "id": "stationary" })
);
let points = |values: &[f64]| -> Vec<[f64; 2]> {
    values
        .iter()
        .enumerate()
        .map(|(n, &v)| [n as f64, v])
        .collect()
};
emit_line_chart!(
    &vec![
        serde_json::json!({ "name": "π from null space", "points": points(&pi) }),
        serde_json::json!({
            "name": "Closed form",
            "points": points(&exact),
            "style": { "lineType": "dashed" }
        })
    ],
    options = &serde_json::json!({ "xLabel": "State n [-]", "yLabel": "Stationary probability π_n [-]" })
);
export!(states, k);
export!(birth, p);
export!(lambda2, lambda2);
export!(pi, exact);
```

With the defaults $K = 20$ and $p = 0.32$ ($\rho = 0.8$), the null space is one-dimensional (rank 20), and the normalized basis agrees with the closed form to absolute error $1.3 \times 10^{-15}$.
The tridiagonal path agrees with the closed form $\lvert\lambda_2\rvert = 0.98754974$ in every displayed digit, and the general eigenvalue path agrees to error $2.2 \times 10^{-16}$.
The gap is 0.0125.

For $p = 0.04$ ($\rho = 0.1$), the probability at state 20 falls to about $10^{-20}$.
The absolute error in null-space basis entries is of the order of unit roundoff, making relative errors large for small probabilities.
This is why the table shows absolute errors; to compute small probabilities with good relative accuracy, use another method such as the detailed-balance recurrence $\pi_{n+1} = \rho\,\pi_n$.

At the same $p = 0.04$, the general eigenvalue path's $\lvert\lambda_2\rvert$ error grows to $1.7 \times 10^{-9}$, while the tridiagonal path's error remains $2.2 \times 10^{-16}$.
The right and left eigenvectors $x = D^{-1/2}u$ and $y = D^{1/2}u$ of $P$ have strongly skewed component magnitudes in opposite directions, so the [eigenvalue condition number](oxref:linalg-nonnormal-eigen-sensitivity) $\lVert x \rVert_2 \lVert y \rVert_2 / \lvert y^{\mathsf T}x \rvert$ of nonsymmetric $P$ is large.
This amplification remains for this matrix even after the default balancing (`PermuteAndScale`) in `GeneralEigenOptions`.
Eigenvalues of symmetric $S$ have condition number 1, so the tridiagonal path has no such amplification.

For $p = 0.4$ ($\rho = 1$), the distribution is uniform and the gap agrees with the closed form $0.8(1 - \cos(\pi/21)) = 0.0089353$, the smallest among $p$ values spaced by 0.04.

## Mixing time

Measure the distance from the evolving distribution to stationarity using total variation distance $d_{\mathrm{TV}}(t) = \tfrac12 \sum_n \lvert x_t(n) - \pi_n \rvert$.
$x_t - \pi$ can be expanded in left eigenvectors $y_j = D^{1/2}u_j$, and each component decays as $\lambda_j^t$, so for large $t$, $d_{\mathrm{TV}}(t)$ decays in proportion to $\lvert\lambda_2\rvert^t$.
The time to reach $d_{\mathrm{TV}} \le 1/4$ from the worst initial state is called the mixing time $t_{\mathrm{mix}}$; a reversible irreducible chain satisfies

$$
t_{\mathrm{mix}} \le \frac{\ln(4/\pi_{\min})}{\gamma}
$$

See Chapter 12 of Levin, Peres, and Wilmer's *Markov Chains and Mixing Times*.
Here $\gamma = 1 - \lvert\lambda_2\rvert$ is the gap measured from the largest eigenvalue magnitude other than $1$, and $\pi_{\min}$ is the smallest stationary probability.

The next cell receives $K$, $p$, $\lvert\lambda_2\rvert$, and closed-form $\pi$ from the previous cell and selects the initial state (0 or $K$) and duration $T \in [50, 2000]$ steps.
Starting with probability 1 at the initial state, it evolves the distribution using the transposed-view product $x_{t+1}^{\mathsf T} = P^{\mathsf T} x_t^{\mathsf T}$ (standard `mul_vec`) and plots total variation distance on a logarithmic axis.
The table shows $\lvert\lambda_2\rvert$, the gap, the first time $d_{\mathrm{TV}} \le 1/4$ is reached, the mixing-time upper bound, total variation distance at time $T$, and the decay factor $(d_{\mathrm{TV}}(T)/d_{\mathrm{TV}}(T-50))^{1/50}$ over the final 50 steps.
The decay factor is an independent check against $\lvert\lambda_2\rvert$ and is not computed if $d_{\mathrm{TV}}(T)$ has reached the rounding-error level (at most $10^{-12}$).
The dashed reference line $\lvert\lambda_2\rvert^t$ passes through the last time whose total variation distance exceeds $10^{-12}$.
The horizontal line marks the threshold $d_{\mathrm{TV}} = 1/4$, and the vertical line marks the first time below it.

## Summary

The stationary distribution of an irreducible Markov chain is the one-dimensional null space of $P^{\mathsf T} - I$, found by normalizing the basis from `null_space` to sum to 1.
The null-space basis has absolute errors of the order of unit roundoff, so use the detailed-balance recurrence when probabilities below $10^{-15}$ are needed.
For eigenvalues of a reversible chain, pass the matrix symmetrized by detailed balance to a symmetric eigensolver such as `HermitianEigenDecomposition::tridiagonal`.
In this example, solving nonsymmetric $P$ directly with `GeneralEigenvaluesResult` increases the $\lvert\lambda_2\rvert$ error to $1.7 \times 10^{-9}$ at $\rho = 0.1$, where probabilities are strongly skewed.
The gap $\gamma = 1 - \lvert\lambda_2\rvert$ gives the mixing-time upper bound $\ln(4/\pi_{\min})/\gamma$, and total variation distance decays at rate $\lvert\lambda_2\rvert^t$ at late times.
