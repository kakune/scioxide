In walls made of insulation and metal layers, or materials whose thermal conductivity varies strongly with temperature, diffusion equation coefficients vary by many orders of magnitude in space.
Matrices obtained by discretizing these equations have large condition numbers, increasing conjugate gradient (CG) iteration counts.
Preconditioning chooses a symmetric positive definite matrix $M$ close to $A$ whose inverse action $M^{-1}r$ is inexpensive, replacing the condition number governing CG convergence from that of $A$ to that of $M^{-1/2}AM^{-1/2}$.
The least expensive choice is Jacobi preconditioning $M = \operatorname{diag}(A)$, which uses only diagonal entries to cancel row and column scale differences.
This example examines conductivity profiles where Jacobi preconditioning greatly reduces conditioning and profiles where it only roughly halves it, using closed-form condition numbers and CG iteration bounds.

## Discretizing steady heat conduction

Consider a rod of length $L = 1$ m and cross-sectional area 1 m² with conductivity $k(x)$ [W/(m·K)], keeping the left endpoint at 0 K and the right at 1 K (differences from a reference temperature).
Without internal heat sources, the steady temperature $u(x)$ [K] satisfies

$$
-\frac{d}{dx}\Bigl(k(x) \frac{du}{dx}\Bigr) = 0, \qquad u(0) = 0, \quad u(1) = 1
$$


Divide the interval into $N + 1$ equal parts, place temperatures $u_i$ at nodes $x_i = ih$ ($h = 1/(N+1)$ m), and define the thermal conductance between adjacent nodes as $c_{i+1/2} = k(x_{i+1/2})/h$ [W/K].
Heat-flow balance [W] at interior node $i$ gives

$$
-c_{i-1/2}\, u_{i-1} + \bigl(c_{i-1/2} + c_{i+1/2}\bigr) u_i - c_{i+1/2}\, u_{i+1} = 0
$$


Moving boundary values $u_0 = 0$ and $u_{N+1} = 1$ to the right-hand side gives $Au = b$ with tridiagonal matrix $A$ [W/K].
Only $b_N = c_{N+1/2}$ [W] is nonzero on the right-hand side.
$A$ is symmetric with positive diagonal entries; the sum of absolute off-diagonal entries in each row is at most the diagonal, and strictly smaller in both endpoint rows.
Gershgorin's theorem gives nonnegative eigenvalues of $A$.
A tridiagonal matrix with nonzero off-diagonal entries is irreducible, so strict diagonal dominance in one row makes $A$ nonsingular (Taussky's theorem), hence $A$ is symmetric positive definite.

### Exact solution from thermal resistances in series

Without heat sources, the heat flow $q = c_{i+1/2}(u_{i+1} - u_i)$ is the same in every interval.
The temperature is therefore determined by thermal resistances $1/c_{i+1/2}$ [K/W] in series, and the exact discrete solution is

$$
u_i = \frac{\sum_{j=0}^{i-1} 1/c_{j+1/2}}{\sum_{j=0}^{N} 1/c_{j+1/2}}
$$


This solves the discrete equations themselves without discretization error, directly measuring the CG solution error.

### Two conductivity profiles

Set the minimum conductivity to 1 W/(m·K) for both profiles and vary the number of decades $d$ in the maximum-to-minimum ratio $10^d$ to compare:

- Exponential variation: $k(x) = 10^{dx}$.
  It increases smoothly by $d$ orders of magnitude from left to right.
- Two-material layers: divide the rod into 10 layers of thickness 0.1 m, alternating $k = 10^d$ and $k = 1$ from the left.

The following block provides definitions shared by two cells.
`bar` builds conductances $c_{j+1/2}$ and the diagonal and off-diagonal of $A$ from the profile and $d$; `exact` returns the exact solution from thermal resistances in series.
`scaled_off_diagonal` returns the off-diagonal of the Jacobi-preconditioned matrix in the next section.
`extremes` returns the smallest and largest eigenvalues of a symmetric tridiagonal matrix; `condition` returns their ratio, the condition number.
Select the extreme eigenvalues individually using `EigenIndexRange` and specify `EigenvalueAccuracy::Relative` to compute each to relative accuracy in its own magnitude using Sturm-sequence bisection.
The default `EigenvalueAccuracy::Absolute` (QL/QR or divide-and-conquer) stops at absolute accuracy relative to the whole spectral scale, so matrices with condition numbers near $10^{12}$ can have smallest-eigenvalue relative error of order $\varepsilon_{\mathrm{mach}}\kappa$.

```rust
//| id: linalg-preconditioned-cg-model
//| kind: definitions
//| title: "Tridiagonal matrix for a rod with nonuniform conductivity"
//| crates: [scioxide-core, scioxide-linalg]
use scioxide_core::SciOxideError;
use scioxide_linalg::{
    EigenIndexRange, EigenvalueAccuracy, HermitianEigenOptions, HermitianEigenvaluesResult,
};

/// Conductivity profile k(x) [W/(m·K)]. Both have minimum 1 W/(m·K).
#[derive(Clone, Copy, PartialEq)]
pub(crate) enum Profile {
    /// k(x) = 10^(d x).
    Exponential,
    /// Alternate k = 10^d and k = 1 in layers of thickness 0.1 m from the left.
    Layered,
}

/// Rod matrix A [W/K] with N interior nodes.
pub(crate) struct Bar {
    /// Conductance c_{j+1/2} = k/h [W/K] for interval j (between nodes j and j + 1), j = 0, …, N.
    pub(crate) conductance: Vec<f64>,
    /// Diagonal of A: c_{i−1/2} + c_{i+1/2}.
    pub(crate) diagonal: Vec<f64>,
    /// Off-diagonal of A: −c_{i+1/2} (length N − 1).
    pub(crate) off_diagonal: Vec<f64>,
}

/// Rod with nodes interior nodes and conductivity variation decades orders of magnitude (h = 1/(N + 1) m).
pub(crate) fn bar(nodes: usize, decades: f64, profile: Profile) -> Bar {
    let h = 1.0 / (nodes + 1) as f64;
    let conductivity = |x: f64| match profile {
        Profile::Exponential => 10.0_f64.powf(decades * x),
        Profile::Layered if (x * 10.0).floor() as usize % 2 == 0 => 10.0_f64.powf(decades),
        Profile::Layered => 1.0,
    };
    let conductance: Vec<f64> = (0..=nodes)
        .map(|j| conductivity((j as f64 + 0.5) * h) / h)
        .collect();
    let diagonal = (0..nodes)
        .map(|i| conductance[i] + conductance[i + 1])
        .collect();
    let off_diagonal = (1..nodes).map(|i| -conductance[i]).collect();
    Bar {
        conductance,
        diagonal,
        off_diagonal,
    }
}

impl Bar {
    /// Exact discrete solution u_i [K] from thermal resistances in series (reference for checking).
    pub(crate) fn exact(&self) -> Vec<f64> {
        let total: f64 = self.conductance.iter().map(|c| 1.0 / c).sum();
        let mut partial = 0.0;
        self.conductance[..self.diagonal.len()]
            .iter()
            .map(|c| {
                partial += 1.0 / c;
                partial / total
            })
            .collect()
    }

    /// Off-diagonal of Jacobi-preconditioned matrix D^{−1/2} A D^{−1/2} (all diagonal entries are 1).
    pub(crate) fn scaled_off_diagonal(&self) -> Vec<f64> {
        self.off_diagonal
            .iter()
            .enumerate()
            .map(|(i, o)| o / (self.diagonal[i] * self.diagonal[i + 1]).sqrt())
            .collect()
    }
}

/// Smallest and largest eigenvalues (λ_min, λ_max) of a symmetric positive definite tridiagonal matrix.
/// Compute only extreme eigenvalues by Sturm bisection with relative accuracy in each magnitude.
pub(crate) fn extremes(diagonal: &[f64], off_diagonal: &[f64]) -> Result<(f64, f64), SciOxideError> {
    let n = diagonal.len();
    let options =
        HermitianEigenOptions::default().with_eigenvalue_accuracy(EigenvalueAccuracy::Relative);
    let eigenvalue = |index: usize| -> Result<f64, SciOxideError> {
        let range = EigenIndexRange::new(index, index + 1)?;
        let values = HermitianEigenvaluesResult::tridiagonal_with_options(
            diagonal,
            off_diagonal,
            &options.with_index_range(range),
        )?;
        Ok(values.eigenvalues()[0])
    };
    Ok((eigenvalue(0)?, eigenvalue(n - 1)?))
}

/// Condition number κ = λ_max/λ_min.
pub(crate) fn condition(diagonal: &[f64], off_diagonal: &[f64]) -> Result<f64, SciOxideError> {
    let (lowest, highest) = extremes(diagonal, off_diagonal)?;
    Ok(highest / lowest)
}
```

## Conditioning and Jacobi preconditioning

CG iteration counts depend on the condition number $\kappa = \lambda_{\max}/\lambda_{\min}$ of $M^{-1/2}AM^{-1/2}$ under preconditioner $M$ (next section).
With Jacobi preconditioning $M = D = \operatorname{diag}(A)$, this is tridiagonal with all diagonal entries 1 and off-diagonal entries $a_{i,i+1}/\sqrt{a_{ii}a_{i+1,i+1}}$.
Denote its condition number by $\kappa_J$ and that of unpreconditioned $A$ by $\kappa(A)$.

For a uniform rod ($d = 0$), eigenvalues of $A = c\,\operatorname{tridiag}(-1, 2, -1)$ are $2c\,(1 - \cos(j\pi h))$ ($j = 1, \ldots, N$), giving condition number

$$
\kappa_0 = \cot^2\frac{\pi h}{2} \approx \frac{4}{\pi^2 h^2}
$$


The diagonal is constant $2c$, so Jacobi preconditioning only divides $A$ by a constant and $\kappa_J = \kappa(A) = \kappa_0$.

For exponential variation, the conductance ratio between neighboring intervals is constant, $q = c_{i+3/2}/c_{i+1/2} = 10^{dh}$.
All off-diagonal entries of the preconditioned matrix then equal $-s$ with $s = 1/(\sqrt q + 1/\sqrt q)$, making it exactly the Toeplitz matrix $\operatorname{tridiag}(-s, 1, -s)$.
Its eigenvalues are $1 - 2s\cos(j\pi h)$, giving the closed-form condition number

$$
\kappa_J = \frac{1 + 2s\cos(\pi h)}{1 - 2s\cos(\pi h)}
$$


For $q > 1$, $s < 1/2$; increasing $d$ strengthens diagonal dominance and makes $\kappa_J$ smaller than $\kappa_0$.
Meanwhile $\kappa(A)$ increases because diagonal magnitudes span a factor of $10^d$.

In two-material layers, $k$ is constant within each layer, so the preconditioned matrix has the same form as a uniform rod within layers, differing only at layer boundaries.
The similar matrix $D^{-1}A$ has diagonal 1 and absolute off-diagonal row sums at most 1; Gershgorin's theorem gives $\lambda_{\max} \le 2$, almost the uniform rod's $1 + \cos(\pi h)$.
For the smooth temperature distribution associated with the smallest eigenvalue, $u^{\mathsf T}Au$ is determined by thermal resistances in series, or harmonic-mean conductivity $\bar k_h$, whereas $u^{\mathsf T}Du$ is determined by the diagonal, or arithmetic mean $\bar k_a$.
This gives the following guide for equal-thickness layers:

$$
\kappa_J \approx \kappa_0\,\frac{\bar k_a}{\bar k_h}, \qquad \frac{\bar k_a}{\bar k_h} = \frac{(10^d + 1)^2}{4 \cdot 10^d} \approx \frac{10^d}{4}
$$


This is a homogenization estimate, not an upper bound.
Diagonal scaling cannot cancel the ratio of arithmetic to harmonic mean.

## Iteration bounds and preconditioned CG

The $k$th CG iterate $x_k$ minimizes the $A$-norm $\lVert e_k \rVert_A = \sqrt{e_k^{\mathsf T}Ae_k}$ of error $e_k = x_k - x^\ast$ in Krylov subspace $x_0 + \mathcal K_k(M^{-1}A, M^{-1}r_0)$ (unpreconditioned: $M = I$).
A Chebyshev polynomial bound gives, with $\rho = (\sqrt\kappa - 1)/(\sqrt\kappa + 1)$,

$$
\lVert e_k \rVert_A \le 2\rho^k\,\lVert e_0 \rVert_A
$$

Here $\kappa$ is the condition number of $M^{-1/2}AM^{-1/2}$.
However, `CgSolver` tests the true residual rather than the error's $A$-norm, stopping when $\lVert b - Ax_k \rVert_2 \le \mathrm{atol} + \mathrm{rtol}\,\lVert b \rVert_2$ for `ResidualTolerance::new(atol, rtol)`.
This page uses $\mathrm{atol} = 0$ and $\mathrm{rtol} = \varepsilon = 10^{-10}$.
Using $\lambda_{\min}(A)\lVert e \rVert_A^2 \le \lVert Ae \rVert_2^2 \le \lambda_{\max}(A)\lVert e \rVert_A^2$ to transfer the error bound to the residual gives, from $x_0 = 0$ ($r_0 = b$),

$$
\frac{\lVert r_k \rVert_2}{\lVert b \rVert_2} \le 2\sqrt{\kappa(A)}\,\rho^k
$$


Define the iteration upper bound as the smallest $k$ for which the right-hand side is at most $\varepsilon$:

$$
k_\kappa = \left\lceil \frac{\ln\bigl(2\sqrt{\kappa(A)}/\varepsilon\bigr)}{\ln(1/\rho)} \right\rceil \approx \frac{\sqrt\kappa}{2}\,\ln\frac{2\sqrt{\kappa(A)}}{\varepsilon}
$$


In exact arithmetic, CG reaches the exact solution in at most $N$ iterations (at most the number of distinct eigenvalues of $M^{-1}A$), giving iteration count at most $\min(k_\kappa, N)$.
Floating-point CG loses orthogonality of residuals and search directions through rounding, so termination in $N$ iterations is not guaranteed.
The upper bound $k_\kappa$ is known to remain approximately valid as a guide under rounding errors (Greenbaum, 1989).
For a one-dimensional problem, $\kappa_0 \approx 0.4N^2$, so $k_\kappa$ is roughly 10 times $N$.
If rounding does not destroy finite termination, $N$ determines the iteration count.

### Calling CgSolver and supplying preconditioning

`CgSolver::new(tolerance, max_iterations)` is a method object taking tolerance `ResidualTolerance` and iteration limit `Budget`; it holds only settings and reads dimensions at each call.
Each iteration performs one product with $A$ and one application of $M^{-1}$; workspace consists of six vectors of length $N$.
The recursively updated residual is replaced with the true residual $b - Ax$ every 50 iterations, and convergence is accepted only after recomputing the true residual.
Adding `with_history(true)` records the residual norm at every iteration.
The first value is the initial true residual and the last is the returned solution's true residual; between them, only every 50th value and convergence candidates use true residuals, with the others recursively updated.
There are two calling forms (defined in [Workspaces, execution contexts, and trial records](oxref:linalg-execution-forms)).

- The standard form `solver.solve(&a, &b)` solves from initial guess 0 without preconditioning and returns the solution vector.
  Stopping before tolerance gives a `ConvergenceFailure` error.
- The form with options `solver.solve_with_options(&a, &b, preconditioning, x0)` takes preconditioning and an initial guess (0 for `None`), returning `IterativeSolveResult` (solution, report, and residual history).
  Nonconvergence still returns `Ok`, with the solution being the iterate with smallest verified true residual at checkpoints ([Cancellation, budget stops, and interpreting accepted iterates](../accepted-state-and-cancellation/)).

Pass preconditioning through `Preconditioning`.
`Preconditioning::None` means $M = I$; `Preconditioning::Inverse(&p)` uses the action of a value `p` implementing scioxide-core's `Preconditioner`.
`p` applies $M^{-1}$ rather than $M$.
CG applies $M^{-1}$ symmetrically, so $M^{-1}$ must be symmetric positive definite.
The solver stops with `Breakdown(Preconditioner)` if it detects $r^{\mathsf T}M^{-1}r \le 0$ and with `Breakdown(NonPositiveCurvature)` if it detects search-direction curvature $p^{\mathsf T}Ap \le 0$.

The preconditioners on this page come from scioxide-sparse.
`JacobiPreconditioner::new(&a)` computes $D^{-1}$ once from the CSR matrix diagonal and returns a `Singular` error for a zero diagonal entry.
`IncompleteFactor::ic0(&a)` builds an incomplete Cholesky factorization IC(0) with the same nonzero pattern as the lower triangle of $A$ ([Incomplete factorizations and iterative preconditioning](../../../scioxide-sparse/algorithms/incomplete-factorizations/)).
Tridiagonal Cholesky produces no fill, so IC(0) here is complete Cholesky factorization and $M = A$.
In exact arithmetic $\kappa = 1$, and CG finishes in one iteration.
Assemble the matrix in CSR form from three diagonals using `sparse_diagonals`.
`CsrMatrix` implements `LinearOperator` and can be passed directly to CG.

### Residual floor from rounding errors

Computing residual $b - Ax$ for a floating-point solution $x$ introduces errors of order $\varepsilon_{\mathrm{mach}}\lVert A \rVert_2\lVert x \rVert_2$ from matrix–vector product rounding alone.
Thus no method can be expected to reduce relative residual $\lVert b - Ax \rVert_2/\lVert b \rVert_2$ far below the guide $\varepsilon_{\mathrm{mach}}\lVert A \rVert_2\lVert x \rVert_2/\lVert b \rVert_2$.
When this guide exceeds tolerance $\varepsilon$, even a solution with backward error of order $\varepsilon_{\mathrm{mach}}$ is not judged converged.
Backward error $\eta = \lVert b - Ax \rVert_2/(\lVert A \rVert_2\lVert x \rVert_2 + \lVert b \rVert_2)$ is the smallest relative change in $A$ and $b$ that makes computed $x$ an exact solution.
The ratio of relative residual to $\eta$ is $(\lVert A \rVert_2\lVert x \rVert_2 + \lVert b \rVert_2)/\lVert b \rVert_2$, so the two table columns reveal $\lVert A \rVert_2\lVert x \rVert_2/\lVert b \rVert_2$.
`CgSolver` uses this floor to detect stagnation.
When a checkpoint's true residual does not improve on the previous minimum, the solver compares the smallest residual $\lVert r_{\mathrm{best}} \rVert_2$ with the rounding-error floor

$$
16\,\varepsilon_{\mathrm{mach}}\bigl(\lVert b \rVert_2 + \lVert A(s \circ x) \rVert_2\bigr)
$$

If it is at most the floor, the solver stops with `Stagnation`.
$x$ is the iterate with smallest verified true residual, not the latest iterate.
$s$ is a fixed sign sequence with components $\pm 1$, and $s \circ x$ changes the signs of entries of $x$ accordingly.
Near the solution, products $a_{ij}x_j$ cancel, reducing $\lVert Ax \rVert_2$; $\lVert A(s \circ x) \rVert_2$ estimates the magnitude $\lVert \lvert A \rvert \lvert x \rvert \rVert_2$ without that cancellation using one product with $A$.
This product also counts as an operator evaluation.
Since $\lVert A(s \circ x) \rVert_2 \le \lVert A \rVert_2\lVert x \rVert_2$, when $\lVert A \rVert_2\lVert x \rVert_2$ is much larger than $\lVert b \rVert_2$, the floor divided by $\lVert b \rVert_2$ is at most roughly 16 times the guide.
The check is skipped at checkpoints where residuals continue decreasing, so an overestimated floor does not stop a progressing solve.
The floor does not change the tolerance.

The final outcome uses the Jacobi row's termination reason: satisfied for `Converged`, partial for a budget stop or stagnation, and failed for breakdown; diagnostics include the rounding guide.

use scioxide_core::{Budget, ResidualTolerance};
use scioxide_linalg::{CgSolver, LinearSolveTermination, Preconditioning, Vector, VectorView};
use scioxide_sparse::{IncompleteFactor, JacobiPreconditioner, sparse_diagonals};

let n = nodes.round() as usize;
let profile = if profile == "Two-material layers" {
    Profile::Layered
} else {
    Profile::Exponential
};
let model = bar(n, decades, profile);
let a = sparse_diagonals(
    n,
    n,
    &[-1, 0, 1],
    &[&model.off_diagonal, &model.diagonal, &model.off_diagonal],
)
.map_err(|e| e.to_string())?;
// b_N = c_{N+1/2} [W] from moving the right endpoint temperature 1 K to the right-hand side.
let mut rhs = vec![0.0_f64; n];
rhs[n - 1] = model.conductance[n];
let b = Vector::from_vec(rhs);
let exact = model.exact();
// Stopping condition ‖b − Ax‖₂ ≤ ε‖b‖₂ (ε = 10⁻¹⁰). Iteration limit 20N.
let epsilon = 1e-10;
let tolerance = ResidualTolerance::new(0.0, epsilon).map_err(|e| e.to_string())?;
let budget = Budget::try_from(20 * n).map_err(|e| e.to_string())?;
let solver = CgSolver::new(tolerance, budget).with_history(true);
// Condition number (eigenvalues) and iteration bound from ‖r_k‖/‖b‖ ≤ 2√κ(A)·ρ^k, ρ = (√κ − 1)/(√κ + 1).
let (lowest, highest) =
    extremes(&model.diagonal, &model.off_diagonal).map_err(|e| e.to_string())?;
let kappa_a = highest / lowest;
let kappa_j =
    condition(&vec![1.0; n], &model.scaled_off_diagonal()).map_err(|e| e.to_string())?;
// Relative residual rounding guide ε_mach‖A‖₂‖x‖₂/‖b‖₂ (x is exact solution, ‖A‖₂ = λ_max(A)).
let exact_norm = VectorView::from(exact.as_slice())
    .norm2()
    .map_err(|e| e.to_string())?;
let floor = f64::EPSILON * highest * exact_norm / model.conductance[n];
let bound = |kappa: f64| {
    let rate = (kappa.sqrt() + 1.0) / (kappa.sqrt() - 1.0);
    ((2.0 * kappa_a.sqrt() / epsilon).ln() / rate.ln()).ceil() as u64
};
// scioxide-sparse preconditioners. Both apply M⁻¹.
let jacobi = JacobiPreconditioner::new(&a).map_err(|e| e.to_string())?;
let cholesky = IncompleteFactor::ic0(&a).map_err(|e| e.to_string())?;
// Standard form: initial guess 0, no preconditioning. Errors if tolerance is not reached.
let plain = match solver.solve(&a, &b) {
    Ok(_) => "Ok (solution)".to_string(),
    Err(e) => format!("Err({:?})", e.kind()),
};
// Show termination reasons by variant name.
let name_of = |t: LinearSolveTermination| match t {
    LinearSolveTermination::Converged => "Converged".to_string(),
    LinearSolveTermination::LeastSquaresConverged => "LeastSquaresConverged".to_string(),
    LinearSolveTermination::ConditionLimit => "ConditionLimit".to_string(),
    LinearSolveTermination::IterationLimit => "IterationLimit".to_string(),
    LinearSolveTermination::EvaluationLimit => "EvaluationLimit".to_string(),
    LinearSolveTermination::Stagnation => "Stagnation".to_string(),
    LinearSolveTermination::Breakdown(cause) => format!("Breakdown({cause:?})"),
    LinearSolveTermination::ExecutionStopped(reason) => format!("ExecutionStopped({reason:?})"),
};
let methods = [
    (
        "None",
        Preconditioning::None,
        Some(kappa_a),
        Some(plain),
    ),
    (
        "Jacobi",
        Preconditioning::Inverse(&jacobi),
        Some(kappa_j),
        None,
    ),
    ("IC(0)", Preconditioning::Inverse(&cholesky), None, None),
];
let mut rows = Vec::new();
let mut series = Vec::new();
let mut jacobi_report = None;
for (name, preconditioning, kappa, plain) in methods {
    // Form with options: pass preconditioning and initial guess (None means 0), receive solution and report.
    let result = solver
        .solve_with_options(&a, &b, preconditioning, None)
        .map_err(|e| e.to_string())?;
    let report = result.report();
    let error = result
        .solution()
        .as_slice()
        .iter()
        .zip(&exact)
        .fold(0.0_f64, |m, (p, q)| m.max((p - q).abs()));
    let residual = report.true_residual().map(|r| r.scaled_norm());
    // Normwise backward error η = ‖b − Ax‖₂ / (‖A‖₂‖x‖₂ + ‖b‖₂), ‖A‖₂ = λ_max(A).
    let x_norm = result
        .solution()
        .view()
        .norm2()
        .map_err(|e| e.to_string())?;
    let backward = report
        .true_residual()
        .map(|r| r.raw_norm() / (highest * x_norm + model.conductance[n]));
    rows.push((
        name,
        kappa,
        kappa.map(bound),
        report.iterations(),
        name_of(report.termination()),
        residual,
        backward,
        error,
        plain,
    ));
    // Omit residuals exactly 0 because they cannot be plotted on a logarithmic axis.
    let points: Vec<[f64; 2]> = result
        .history()
        .unwrap_or(&[])
        .iter()
        .enumerate()
        .filter(|(_, r)| **r > 0.0)
        .map(|(k, r)| [k as f64, r / model.conductance[n]])
        .collect();
    series.push(serde_json::json!({ "name": name, "points": points }));
    if name == "Jacobi" {
        jacobi_report = Some((report, error));
    }
}
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let columns = serde_json::json!([
    { "key": "0", "label": "Preconditioner" },
    { "key": "1", "label": "Condition number κ [-]", "type": "number", "format": sci2, "nullText": "Not computed" },
    { "key": "2", "label": "Iteration upper bound k_κ [count]", "type": "integer", "nullText": "Not computed" },

    { "key": "8", "label": "Standard form solve", "nullText": "Takes no preconditioner" }
]);

## Summary

For smoothly varying diffusion coefficients, Jacobi alone reduces the condition number to at most the uniform-rod value; for coefficient jumps such as material layers, the arithmetic-to-harmonic mean ratio (about $10^d/4$) remains, so choose a preconditioner using off-diagonal information.
Use the smaller of condition-based bound $k_\kappa$ and unknown count $N$ as an iteration-limit guide; for ill-conditioned unpreconditioned problems, allow for rounding to exceed $N$ manyfold.
Use the form with options `solve_with_options` to supply preconditioning or use an unconverged solution, and check the report's termination reason and true residual.
When specifying tolerance relative to $\lVert b \rVert$, choose it above rounding guide $\varepsilon_{\mathrm{mach}}\lVert A \rVert\lVert x \rVert/\lVert b \rVert$.
A tolerance below the guide causes stopping with `Stagnation` or `IterationLimit`, so judge the returned solution using backward error and comparison with a known solution.
