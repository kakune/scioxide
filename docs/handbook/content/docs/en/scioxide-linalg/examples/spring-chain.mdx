Connect $N$ particles between fixed walls at both ends using $N + 1$ springs of stiffness $k$ [N/m].
Finding equilibrium displacements under applied forces is a one-dimensional stiffness problem in structural mechanics, with the same form as a string or rod discretized by second differences.
This example derives the tridiagonal stiffness matrix, solves it with `TridiagonalLuDecomposition` in $O(N)$ operations, and compares with the exact solution at every node.

---

## Stiffness equation

Let particle $i$ have displacement $u_i$ [m] and applied force $f_i$ [N], with endpoints $u_0 = u_{N+1} = 0$; force balance on particle $i$ is

$$
k(u_{i-1} - u_i) + k(u_{i+1} - u_i) + f_i = 0
\quad\Longleftrightarrow\quad
-k u_{i-1} + 2k u_i - k u_{i+1} = f_i
$$


Collecting all particles gives the stiffness equation $Ku = f$ with $K = k \operatorname{tridiag}(-1, 2, -1)$.
The quadratic form is $u^{\mathsf T} K u = k \sum_{i=0}^{N} (u_{i+1} - u_i)^2$, positive for $u \ne 0$ when both ends are fixed, so $K$ is symmetric positive definite.

## Exact solutions

For a point load applying force $P$ [N] only to particle $j$, no external forces act on either side of the load, so $u_{i-1} - 2u_i + u_{i+1} = 0$ makes the displacement linear there.
The pair of lines that vanish at both ends and have force imbalance $P$ at the load point is the discrete Green's function

$$
u_i = \frac{P}{k} \cdot \frac{\min(i, j)\,\bigl(N + 1 - \max(i, j)\bigr)}{N + 1}
$$


The maximum displacement occurs at the load point, $u_j = P\,j(N+1-j)/((N+1)k)$, and equals $P(N+1)/(4k)$ at the center ($j = (N+1)/2$).
This equals $P$ divided by the equivalent stiffness $4k/(N+1)$ of two parallel chains, each with $j$ springs in series (stiffness $k/j$).

For a distributed load applying the same force $q$ [N] to every particle, the exact solution is the quadratic satisfying $-k(u_{i-1} - 2u_i + u_{i+1}) = q$:

$$
u_i = \frac{q}{2k}\, i\,(N + 1 - i)
$$

The second difference of a quadratic is exactly constant.
The maximum displacement is $q(N+1)^2/(8k)$ at the center.

## Relation to a continuum

For a string of length $L$ [m] under tension $T$ [N] with point load $P$, the deflection $w(s)$ satisfies $-T w'' = P\,\delta(s - s_0)$ and $w(0) = w(L) = 0$, giving a piecewise-linear solution with its peak at the load point.
Dividing the string into $N+1$ intervals and discretizing with second differences gives the same equation as a spring–mass chain with $k = T/h$ ($h = L/(N+1)$).
Piecewise-linear functions and parabolas are represented exactly by second differences, so for point and uniform distributed loads, the discrete solution equals the continuous solution at the nodes without discretization error.
General distributed loads introduce second-difference discretization error $O(h^2)$ (the periodic-boundary example in [Tridiagonal, banded, and Toeplitz matrices](../../algorithms/structured-systems/)).

## Solving with tridiagonal LU factorization

`TridiagonalLuDecomposition::factor(&matrix)` performs LU factorization with adjacent pivoting on a tridiagonal matrix constructed with `TridiagonalMatrix::new(lower, main, upper)` ([Tridiagonal, banded, and Toeplitz matrices](../../algorithms/structured-systems/)).
Both factorization and each solve require $O(N)$ operations and memory, nearly 3 orders less even at $N = 101$ than dense LU's approximately $\tfrac23 N^3$ operations.
The diagonal $d_i = k(i+1)/i$ arising during elimination always exceeds the entry $k$ below it, so adjacent pivoting never swaps rows, giving the same computation as the Thomas algorithm here.
For many load combinations on the same chain, retain the factors and repeat only the $O(N)$ solves.

There are two solve forms (defined in [Workspaces, execution contexts, and trial records](../../algorithms/workspaces-and-execution/)).
The standard form `factor.solve(StructuredOperation::Normal, &f)` solves with default `DirectSolveOptions` (`RankPolicy::Exact`), returns a solution `Vector`, and turns rejection into an error (`Singular` for rank deficiency).
The form with options `factor.solve_with_options(StructuredOperation::Normal, &f, &options)` takes acceptance conditions and returns a `DirectSolveResult` containing the solution and report.
Here `DirectSolveOptions::new(RankPolicy::DimensionScaledEpsilon).with_residual(Estimation::Estimate)` explicitly selects a dimension-scaled rank threshold and requests the normalized backward error

```text
η = ‖Ku − f‖∞ / (‖K‖∞ ‖u‖∞ + ‖f‖∞),   ‖K‖∞ = 4k
```

The report entry is `report().residual()`.
`solution()` returns the solution only when the report's `DirectSolveTermination` is `Accepted`.

The next cell solves a point load $P$ at position $j/(N+1)$ using the form with options, and a distributed load $q = P/N$ with the same total $P$ using the standard form on the same factors.
Inputs are particle count $N \in [5, 1001]$, stiffness $k \in [20, 400]$ N/m, load $P \in [1, 50]$ N, and load position $j/(N+1) \in [0.05, 0.95]$.
For each load the table shows the maximum displacement and exact value, maximum nodal error relative to displacement magnitude (relative error), relative residual $\eta$ from a manually computed tridiagonal product, reported backward error, and row-swap count.
The plot shows displacements and exact solutions (dashed) for the two loads.

```rust
//| id: linalg-spring-chain
//| ref: linalg-spring-chain
//| title: "Equilibrium displacements of a spring chain using tridiagonal LU"
//| run: reactive
//| crates: [scioxide-linalg]
//| inputs:
//|   nodes: {"type":"range","label":"Particle count N","description":"Number of particles between the fixed walls.","min":5,"max":1001,"step":2,"value":41}
//|   stiffness: {"type":"range","label":"Spring constant k [N/m]","description":"The same for every spring.","min":20,"max":400,"step":5,"value":120}
//|   load: {"type":"range","label":"Load P [N]","description":"Point-load magnitude. The distributed load q = P/N has the same total P.","min":1,"max":50,"step":1,"value":18}
//|   position: {"type":"range","label":"Load position j/(N+1)","description":"0.5 is the center. Apply the load to the nearest particle.","min":0.05,"max":0.95,"step":0.05,"value":0.5}
//| cases:
//|   - {"id":"long-chain","label":"N = 1001","description":"Conditioning grows in proportion to N², increasing relative error.","inputs":{"nodes":1001}}
//|   - {"id":"off-center","label":"j/(N+1) = 0.1","description":"Moving the load toward an endpoint reduces maximum displacement in proportion to j(N+1−j).","inputs":{"position":0.1}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"displacement","path":"/rows/0/2","approx":{"value":1.575,"rtol":1e-12}}
//|       - {"artifact":"displacement","path":"/rows/0/3","approx":{"value":1.575,"rtol":1e-14}}
//|       - {"artifact":"displacement","path":"/rows/0/5","range":{"max":1e-14}}
//|       - {"artifact":"displacement","path":"/rows/1/3","approx":{"value":0.8067073170731708,"rtol":1e-12}}
//|       - {"artifact":"displacement","path":"/rows/1/5","range":{"max":1e-14}}
//|       - {"artifact":"displacement","path":"/rows/0/8","equals":0}
//|       - {"path":"/outputs/2/state","equals":"satisfied"}
//|   - case: long-chain
//|     expect:
//|       - {"artifact":"displacement","path":"/rows/0/5","range":{"min":1e-15,"max":1e-11}}
//|       - {"artifact":"displacement","path":"/rows/0/6","range":{"max":1e-15}}
//|       - {"path":"/outputs/2/state","equals":"satisfied"}
//|   - case: off-center
//|     expect:
//|       - {"artifact":"displacement","path":"/rows/0/3","approx":{"value":0.5428571428571429,"rtol":1e-12}}
//|       - {"artifact":"displacement","path":"/rows/0/5","range":{"max":1e-14}}
use scioxide_linalg::{
    DirectSolveOptions, DirectSolveTermination, Estimation, RankPolicy, StructuredOperation,
    TridiagonalLuDecomposition, TridiagonalMatrix,
};

let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let fixed = serde_json::json!({ "significantDigits": 10 });
let n = nodes.round() as usize;
let k = stiffness;
// Load point j (one-based).
let j = ((position * (n + 1) as f64).round() as usize).clamp(1, n);
let matrix = TridiagonalMatrix::new(vec![-k; n - 1], vec![2.0 * k; n], vec![-k; n - 1])
    .map_err(|e| e.to_string())?;
let factor = TridiagonalLuDecomposition::factor(&matrix).map_err(|e| e.to_string())?;
let swaps = factor
    .pivots()
    .iter()
    .enumerate()
    .filter(|&(i, &p)| p != i)
    .count();

// Point load: explicitly set the rank policy with options and request reported backward error.
let mut point = vec![0.0_f64; n];
point[j - 1] = load;
let accept = DirectSolveOptions::new(RankPolicy::DimensionScaledEpsilon)
    .with_residual(Estimation::Estimate);
let result = factor
    .solve_with_options(StructuredOperation::Normal, &point[..], &accept)
    .map_err(|e| e.to_string())?;
let termination = result.report().termination();
let backward = result.report().residual().map(|r| r.scaled_norm());
let u = result
    .solution()
    .ok_or("The solution was not accepted")?
    .as_slice()
    .to_vec();
// Distributed load: reuse the same factors with standard solve (rejection is an error).
let q = load / n as f64;
let uniform = vec![q; n];
let v = factor
    .solve(StructuredOperation::Normal, &uniform[..])
    .map_err(|e| e.to_string())?;
let v = v.as_slice().to_vec();

// Check: exact-solution difference and relative residual η from a manual tridiagonal product.
let green = |i: usize| load / k * (i.min(j) * (n + 1 - i.max(j))) as f64 / (n + 1) as f64;
let parabola = |i: usize| q / (2.0 * k) * (i * (n + 1 - i)) as f64;
let check = |x: &[f64], f: &[f64], exact: &dyn Fn(usize) -> f64| {
    let (mut peak, mut exact_peak, mut error, mut residual) =
        (0.0_f64, 0.0_f64, 0.0_f64, 0.0_f64);
    for i in 1..=n {
        let left = if i > 1 { x[i - 2] } else { 0.0 };
        let right = if i < n { x[i] } else { 0.0 };
        residual = residual.max((k * (2.0 * x[i - 1] - left - right) - f[i - 1]).abs());
        peak = peak.max(x[i - 1].abs());
        exact_peak = exact_peak.max(exact(i));
        error = error.max((x[i - 1] - exact(i)).abs());
    }
    let f_norm = f.iter().fold(0.0_f64, |m, v| m.max(v.abs()));
    (
        peak,
        exact_peak,
        error,
        error / peak,
        residual / (4.0 * k * peak + f_norm),
    )
};
let (p_peak, p_exact, p_error, p_relative, p_eta) = check(&u, &point, &green);
let (u_peak, u_exact, u_error, u_relative, u_eta) = check(&v, &uniform, &parabola);
let columns = serde_json::json!([
    { "key": "0", "label": "Load" },
    { "key": "1", "label": "Solve form" },
    { "key": "2", "label": "Maximum displacement [m]", "type": "number", "format": fixed },
    { "key": "3", "label": "Exact maximum [m]", "type": "number", "format": fixed },
    { "key": "4", "label": "Maximum nodal error [m]", "type": "number", "format": sci2 },
    { "key": "5", "label": "Relative error [-]", "type": "number", "format": sci2 },
    { "key": "6", "label": "Relative residual η (manual) [-]", "type": "number", "format": sci2 },
    { "key": "7", "label": "Backward error (report) [-]", "type": "number", "format": sci2, "nullText": "Not requested" },
    { "key": "8", "label": "Row swaps [count]", "type": "integer" }
]);
let rows = vec![
    (
        "Point load P",
        "With options",
        p_peak,
        p_exact,
        p_error,
        p_relative,
        p_eta,
        backward,
        swaps,
    ),
    (
        "Distributed load q = P/N",
        "Standard form",
        u_peak,
        u_exact,
        u_error,
        u_relative,
        u_eta,
        None,
        swaps,
    ),
];
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "displacement" })
);
let curve = |values: &[f64]| -> Vec<[f64; 2]> {
    (1..=n)
        .map(|i| [i as f64 / (n + 1) as f64, values[i - 1]])
        .collect()
};
let exact_curve = |exact: &dyn Fn(usize) -> f64| -> Vec<[f64; 2]> {
    (1..=n)
        .map(|i| [i as f64 / (n + 1) as f64, exact(i)])
        .collect()
};
let dashed = serde_json::json!({ "lineType": "dashed" });
let (green_curve, parabola_curve) = (exact_curve(&green), exact_curve(&parabola));
emit_line_chart!(
    &vec![
        serde_json::json!({ "name": "Point-load displacement", "points": curve(&u) }),
        serde_json::json!({ "name": "Discrete Green's function", "points": green_curve, "style": dashed }),
        serde_json::json!({ "name": "Distributed-load displacement", "points": curve(&v) }),
        serde_json::json!({ "name": "Exact quadratic solution", "points": parabola_curve, "style": dashed })
    ],
    options = &serde_json::json!({ "xLabel": "Position i/(N+1) [-]", "yLabel": "Displacement u_i [m]" })
);

let status = match termination {
    DirectSolveTermination::Accepted => "Accepted",
    DirectSolveTermination::RankDeficient => "RankDeficient",
    DirectSolveTermination::IllConditioned => "IllConditioned",
    DirectSolveTermination::ResidualRejected => "ResidualRejected",
    DirectSolveTermination::StabilityRejected => "StabilityRejected",
};
let outcome = if termination.is_success() {
    Outcome::satisfied("Point-load solution accepted")
} else {
    Outcome::failed("Point-load solution rejected")
};
let mut outcome = outcome
    .status(status)
    .diagnostic("Relative error", p_relative, None)
    .diagnostic("Row swaps", swaps as f64, None);
if let Some(eta) = backward {
    outcome = outcome.diagnostic("Backward error", eta, None);
}
emit_outcome!(outcome);
```

With default central load $N = 41$, $k = 120$ N/m, and $P = 18$ N, the displacement at the load is $P(N+1)/(4k) = 1.575$ m, the relative nodal error is $7.8 \times 10^{-16}$, and relative residual $\eta$ is $3.4 \times 10^{-17}$.
The reported backward error $3.7 \times 10^{-17}$ is the same quantity as manually computed $\eta$ and agrees within rounding, with termination reason `Accepted`.
The distributed load ($q = 18/41$ N), reusing the factors through the standard form, also agrees with central displacement $q(N+1)^2/(8k) = 0.8067$ m to relative difference $9.6 \times 10^{-16}$.
The displacement plot is piecewise linear with a peak at the load for the point load and parabolic for the distributed load; both overlap the dashed exact solutions.
Moving the load toward $j/(N+1) = 0.1$ ($j = 4$) shifts the peak and reduces maximum displacement to $0.5429$ m in proportion to $j(N+1-j)$.

At $N = 1001$, the relative residual remains of order $10^{-16}$, but relative error grows to $2.4 \times 10^{-13}$.
The condition number of $K$ is $\kappa_2 \approx 4(N+1)^2/\pi^2 \approx 4 \times 10^{5}$, and forward error of a backward-stable solution can be amplified by this condition number.
No input causes row swaps.
Displacement magnitudes increase in proportion to $N/k$, so interpret error relative to displacement magnitude.

## Summary

Spring–mass equilibrium gives a symmetric positive definite tridiagonal stiffness equation, solvable by `TridiagonalLuDecomposition` in $O(N)$ operations.
The exact point-load solution is a discrete Green's function and the uniform distributed-load solution is quadratic; both are represented exactly by second differences, allowing exact-solution comparisons at every node.
The same factors can be reused with either `solve_with_options` for reports or standard `solve` for just the solution.
Even when relative residual and reported backward error remain at unit roundoff, relative error can be amplified by condition number $O(N^2)$.
For this diagonally dominant matrix, adjacent pivoting performs no row swaps and matches the Thomas algorithm.
