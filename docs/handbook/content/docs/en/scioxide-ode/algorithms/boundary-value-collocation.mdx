Initial value problems supply all of $y(t_0)$ and advance one time step at a time.
Two-point boundary value problems (BVPs) split conditions between endpoints of $[a, b]$ and may include unknown parameters $p$.

$$
y'(x) = f(x, y(x), p), \qquad g\bigl(y(a), y(b), p\bigr) = 0, \qquad a \le x \le b
$$

The state $y$ has $n$ components, $p$ contains $k$ unknown parameters, and boundary conditions $g$ must number $n + k$.
The coordinate $x$ is real; states and parameters may be complex.
Complex Jacobians are treated as complex-linear, requiring holomorphic $f$ and $g$.

The crate `scioxide-ode` provides whole-interval collocation through `BvpPlan` and one-shot `solve_bvp`.
It does not provide shooting, which finds unknown left-end initial values through root finding.
Shooting amplifies initial-value errors for exponentially growing solutions.
If needed, compose it from initial value integrator objects and scioxide-rootfind.

## Three-stage Lobatto IIIA collocation equations

Combine mesh values $y_j$ at $a = x_0 < x_1 < \dots < x_{m-1} = b$ and unknown parameters $p$ into $mn + k$ unknowns.
On each interval $[x_j, x_{j+1}]$ (width $h_j$), use cubic Hermite polynomial $u(x)$ through endpoint values $y_j, y_{j+1}$ and slopes $f_j = f(x_j, y_j, p)$ and $f_{j+1}$.
The interpolant $u$ has continuous values and first derivatives across interval boundaries ($C^1$).
The midpoint value of $u$ is

$$
y_{j+1/2} = \frac{y_j + y_{j+1}}{2} - \frac{h_j}{8}\,(f_{j+1} - f_j)
$$

with slope $f_{j+1/2} = f(x_j + h_j/2,\ y_{j+1/2},\ p)$ there.
Collocation equations take Simpson-rule form,

$$
\frac{y_{j+1} - y_j}{h_j} - \frac{f_j + 4 f_{j+1/2} + f_{j+1}}{6} = 0, \qquad j = 0, \dots, m-2
$$


This enforces $u' = f$ at endpoints and midpoint, giving three-stage Lobatto IIIA.
Combining $(m-1)n$ collocation equations and $n+k$ boundary conditions matches the $mn + k$ unknowns.
For smooth solutions, mesh-point errors are $O(h^4)$ (fourth-order).
The solution is $C^1$ cubic Hermite interpolation of mesh values and slopes; `BvpSolution::evaluate_into(x, &mut y)` returns values anywhere in $[a, b]$, and `evaluate_with_derivative_into` returns values and derivatives.
At mesh points, stored values and slopes are returned directly; evaluating one point costs $O(\log m + n)$ for $m$ mesh points.

## Newton iteration and linear solvers

Solve these $mn + k$ nonlinear equations by damped Newton with backtracking line search.
The inner solver is scioxide-rootfind Newton–Krylov, normalizing collocation residuals in units of 1/1000 of tolerance and boundary residuals in units of 1/1000 of boundary tolerance for stopping.
Supply controls through `BvpNewtonOptions`.
Defaults match scioxide-rootfind's `NewtonKrylovOptions`: at most 100 Newton iterations per mesh, Armijo constant $10^{-4}$, minimum relative step $\varepsilon^{2/3}$ ($\varepsilon$ is machine epsilon), nonmonotone line-search weight 0.85, and Eisenstat–Walker stopping for Krylov corrections.
Override through `with_max_iterations`, `with_backtracking`, `with_nonmonotone`, and `with_forcing`, supplying through `BvpOptions::with_newton`.

Select Newton correction linear solvers through `BvpBackend`.
Only the selected solver is used, without switching.

| `BvpBackend` | Correction-system solution | Memory and suitable cases |
|---|---|---|
| `Sparse { limits }` (default) | Pivoted sparse LU of an assembled block-sparse matrix | Memory proportional to mesh size. Under `limits: None`, determine fill and memory bounds per mesh |
| `Dense` | Partial-pivoted LU of an assembled dense matrix | Memory proportional to $(mn + k)^2$, restricting use to few mesh points and small dimensions |
| `Krylov { iterations, restart }` | Restarted GMRES without matrix assembly | No matrix storage. Without preconditioning, larger meshes readily exhaust iterations |

Systems implement `BvpSystem`, supplying dimension `dimension`, unknown-parameter count `parameter_dimension` (default 0), `rhs` writing right-hand side $f(x, y, p)$, and `boundary` writing $n + k$ boundary residuals $g(y(a), y(b), p)$.
Select Jacobians through `BvpProblem`.
`BvpProblem::analytic(&system)` uses local Jacobians from `BvpJacobian` (right-hand-side $\partial f/\partial y$ and $\partial f/\partial p$, boundary $\partial g/\partial y(a)$, $\partial g/\partial y(b)$, and $\partial g/\partial p$, all row-major).
The policy `BvpProblem::numerical(&system)` uses forward differences: local blocks for direct solvers, full-collocation Jacobian–vector products for `Krylov`.

## Residual error estimation and mesh refinement

After solving, residual $r(x) = u'(x) - f(x, u(x), p)$ measures how well $u$ satisfies the differential equation.
Normalize each component $i$ as $\tilde r_i = r_i / (\varepsilon_{\mathrm{abs}} + \varepsilon_{\mathrm{rel}} |f_i(x, u(x), p)|)$ and require on every interval

$$
\left( \frac{1}{h_j} \int_{x_j}^{x_{j+1}} \lVert \tilde r(x) \rVert_2^2 \, dx \right)^{1/2} \le 1
$$


Use five-point Lobatto quadrature for the integral.
Endpoint collocation gives $u' = f$ at both endpoints, so evaluate the right-hand side only at three points: midpoint and offsets $\pm\sqrt{3/7}\,h_j/2$.
One residual evaluation calls the right-hand side $4m - 3$ times for $m$ mesh points, and boundary conditions once.
The maximum interval residual is report `max_residual()`; boundary residual $\max_i |g_i|$ is `boundary_residual()`.

Termination is `BvpTermination::Converged` when all of the following hold.

- Every interval has normalized residual at most 1 (`max_residual() <= 1`).
- Boundary residuals satisfy boundary tolerance.
  Boundary tolerance is absolute only; its relative part must be zero.
- With singular terms, residual $S\,y(a)$ also meets boundary tolerance.

Otherwise bisect every interval whose normalized residual exceeds 1 and solve on the new mesh from current solution $u$.
Default tolerances are $\varepsilon_{\mathrm{abs}} = \varepsilon_{\mathrm{rel}} = 10^{-3}$ for differential equations and $10^{-3}$ for boundaries, with at most 20 refinements, configurable through `BvpOptions::with_tolerances` and `with_refinements`.

Control concerns residuals, not error $u - y$.
They are close for well-conditioned problems, but report residuals do not bound errors.
Check against analytical solutions, invariants, or solutions with more mesh points.

## Two solutions of the Bratu problem

The Bratu problem, a one-dimensional thermal-runaway combustion model (Gelfand problem),

$$
u'' + \lambda e^{u} = 0, \qquad u(0) = u(1) = 0
$$

becomes first-order system $n = 2$ with $y = (u, u')$.
The dimensionless parameter $\lambda > 0$ measures heat release, and $u$ is dimensionless temperature.
The analytical solution is

$$
u(x) = 2\ln\cosh\frac{\theta}{4} - 2\ln\cosh\frac{(x - 1/2)\,\theta}{2}, \qquad \theta = \sqrt{2\lambda}\,\cosh\frac{\theta}{4}
$$

where the equation for $\theta$ has two roots when $0 < \lambda < \lambda_c \approx 3.513831$.
The BVP therefore has a lower solution with small $u$ and an upper solution with large values.
At $\lambda = 1$ they are $\theta = 1.517165$ ($u(1/2) = 0.140539$) and $\theta = 10.938703$ ($u(1/2) = 4.091467$).
scioxide-rootfind follows the same problem's finite-difference approximation using [Pseudo-arclength continuation](oxref:rootfind-bratu-branch), obtaining both solutions at the same $\lambda = 1$ ([Tracking solution branches by continuation](../../../scioxide-rootfind/algorithms/continuation-and-deflation/)).

The following block defines helpers shared by two cells.
The type `Bratu { lambda, slope }` supplies a system with given $\lambda$ when `slope` is `None`, or treats $\lambda$ as unknown parameter $p_0$ and adds boundary condition $u'(0) = s$ when it is `Some(s)`.
Its `BvpJacobian` implementation returns analytical local Jacobians.
The function `bratu_exact` is the analytical solution, and `reference_root` Brent root finding for references.

```rust
//| id: ode-bratu-model
//| kind: definitions
//| title: "Bratu system, local Jacobians, and reference values"
//| crates: [scioxide-core, scioxide-ode, scioxide-rootfind]
use scioxide_core::{
    SciOxideError, Interval, RealScalar, ResidualTolerance, SolveContext, StepTolerance,
};
use scioxide_linalg::Matrix;
use scioxide_ode::{BvpJacobian, BvpSolution, BvpSystem};
use scioxide_rootfind::{Brent, ScalarFn, ScalarRootOptions, ScalarRootSolver};

/// Bratu u'' + λeᵘ = 0, u(0) = u(1) = 0 as first-order system y = (u, u').
/// For slope = Some(s), treat λ as unknown p[0] and add third boundary condition u'(0) = s.
pub(crate) struct Bratu {
    pub(crate) lambda: f64,
    pub(crate) slope: Option<f64>,
}
impl Bratu {
    fn lambda(&self, p: &[f64]) -> f64 {
        if self.slope.is_some() {
            p[0]
        } else {
            self.lambda
        }
    }
}
impl BvpSystem<f64> for Bratu {
    fn dimension(&self) -> usize {
        2
    }
    fn parameter_dimension(&self) -> usize {
        usize::from(self.slope.is_some())
    }
    fn rhs(
        &self,
        _: f64,
        y: &[f64],
        p: &[f64],
        out: &mut [f64],
        _: &mut SolveContext<'_, '_>,
    ) -> Result<(), SciOxideError> {
        out[0] = y[1];
        out[1] = -self.lambda(p) * scioxide_core::RealScalar::exp(y[0]);
        Ok(())
    }
    fn boundary(
        &self,
        a: &[f64],
        b: &[f64],
        _: &[f64],
        out: &mut [f64],
        _: &mut SolveContext<'_, '_>,
    ) -> Result<(), SciOxideError> {
        out[0] = a[0];
        out[1] = b[0];
        if let Some(s) = self.slope {
            out[2] = a[1] - s;
        }
        Ok(())
    }
}
/// Local Jacobians are row-major. Boundary row 0 depends on u at y(a), row 1 on u at y(b), and row 2 on u' at y(a).
impl BvpJacobian<f64> for Bratu {
    fn rhs_jacobian(
        &self,
        _: f64,
        y: &[f64],
        p: &[f64],
        state: &mut [f64],
        parameters: &mut [f64],
        _: &mut SolveContext<'_, '_>,
    ) -> Result<(), SciOxideError> {
        let e = scioxide_core::RealScalar::exp(y[0]);
        state.copy_from_slice(&[0.0, 1.0, -self.lambda(p) * e, 0.0]);
        if self.slope.is_some() {
            parameters.copy_from_slice(&[0.0, -e]);
        }
        Ok(())
    }
    fn boundary_jacobian(
        &self,
        _: &[f64],
        _: &[f64],
        _: &[f64],
        a: &mut [f64],
        b: &mut [f64],
        parameters: &mut [f64],
        _: &mut SolveContext<'_, '_>,
    ) -> Result<(), SciOxideError> {
        let rows = a.len() / 2;
        a.fill(0.0);
        b.fill(0.0);
        parameters.fill(0.0);
        a[0] = 1.0;
        b[2] = 1.0;
        if rows == 3 {
            a[5] = 1.0;
        }
        Ok(())
    }
}
/// Analytical u(x) = 2 ln cosh(θ/4) − 2 ln cosh((x − 1/2)θ/2) (reference from f64 inherent methods).
pub(crate) fn bratu_exact(x: f64, theta: f64) -> f64 {
    2.0 * (theta / 4.0).cosh().ln() - 2.0 * ((x - 0.5) * theta / 2.0).cosh().ln()
}
/// Initial guess u = A sin(πx), u' = Aπ cos(πx), one row per mesh point.
pub(crate) fn sine_guess(mesh: &[f64], amplitude: f64) -> Result<Matrix<f64>, SciOxideError> {
    let pi = core::f64::consts::PI;
    let values = mesh.iter().flat_map(|&x| {
        let (s, c) = RealScalar::sin_cos(pi * x);
        [amplitude * s, amplitude * pi * c]
    });
    Matrix::from_vec(mesh.len(), 2, values.collect())
}
/// One table row: (solution branch, θ, u(1/2), max|u − u_analytical|, maximum normalized residual, mesh points, refinements, termination status).
pub(crate) type Row = (&'static str, f64, f64, f64, f64, usize, usize, String);
/// Compare at 101 points with the analytical solution, returning a row, convergence flag, and plotted points.
pub(crate) fn summarize(
    branch: &'static str,
    theta: f64,
    solution: &BvpSolution<f64>,
) -> Result<(Row, bool, Vec<[f64; 2]>), SciOxideError> {
    let (mut y, mut points, mut worst) = ([0.0; 2], Vec::new(), 0.0_f64);
    for x in (0..=100).map(|i| f64::from(i) / 100.0) {
        solution.evaluate_into(x, &mut y)?;
        worst = worst.max((y[0] - bratu_exact(x, theta)).abs());
        points.push([x, y[0]]);
    }
    solution.evaluate_into(0.5, &mut y)?;
    let report = solution.report().ok_or_else(|| {
        SciOxideError::invalid_input(
            scioxide_core::argument!("solution"),
            scioxide_core::InvalidInputReason::Empty,
            "no report",
        )
    })?;
    let status = format!("{:?}", report.termination());
    let residual = report.max_residual();
    let row = (
        branch,
        theta,
        y[0],
        worst,
        residual,
        report.nodes(),
        report.refinements(),
        status,
    );
    Ok((row, report.is_success(), points))
}
/// Reference roots: Brent zero of g on [lo, hi] to 10⁻¹⁵.
pub(crate) fn reference_root(
    g: impl Fn(f64) -> f64,
    lo: f64,
    hi: f64,
) -> Result<f64, SciOxideError> {
    let options = ScalarRootOptions::default()
        .with_residual_tolerance(ResidualTolerance::new(1e-15, 0.0)?)
        .with_step_tolerance(StepTolerance::new(1e-15, 1e-15)?);
    let f = ScalarFn::new(|t: f64| Ok(g(t)));
    let result = Brent.solve(&f, Interval::new(lo, hi)?, &options)?;
    Ok(result.point())
}
```

Limits are 400 mesh points and 64 MiB workspace; the linear solver is default sparse LU.

- At tolerance $10^{-9}$, the lower converges with 321 points and difference $4.0 \times 10^{-13}$.

- At $\lambda = 0.2$, the upper solution reaches $u(1/2) \approx 6.41$, but Newton from amplitude $A = 4$ also converges to the lower solution.

- At $\lambda = 3.4$, the two $u(1/2)$ values approach 0.909143 and 1.515097, converging with 81 and 119 mesh points.

## Passing a fold with an unknown parameter

With given $\lambda$ and unknown $u$, no solution exists at $\lambda > \lambda_c$, and Newton Jacobians approach singularity near $\lambda_c$.
Instead make $\lambda$ an unknown parameter ($k = 1$), prescribing left-end slope $u'(0) = s$ as a third boundary condition.
In the analytical solution, $s = \theta \tanh(\theta/4)$ grows monotonically with $\theta$, so specifying $s$ uniquely determines a point on the solution branch and keeps equations nonsingular even at the fold.
This follows the same idea as adding an arclength condition in scioxide-rootfind pseudo-arclength continuation.

The next cell sweeps 16 $s$ values through the maximum, solving systems whose `parameter_dimension()` returns 1 with `BvpProblem::numerical` (difference Jacobians).
The Plan depends only on state dimension and unknown-parameter count, so the same `BvpPlan` handles 16 systems with different $s$.
Initial unknown-parameter guesses are always $\lambda_0 = 1$; compare computed $\lambda$ (`BvpSolution::parameters()`) with analytical $\lambda = \theta^2 / (2\cosh^2(\theta/4))$.

## Singular endpoint terms

Radial cylindrical or spherical equations have coefficients $1/(x - a)$ at left endpoint $x = a$.
The constructor `BvpPlan::with_singular(S)` sets the right-hand side to

$$
y' = \frac{S\,y}{x - a} + f(x, y, p)
$$

adding a term with constant $n \times n$ matrix $S$.
It assumes $S\,y(a) = 0$ for a $C^1$ solution, with boundary conditions consistent with that constraint.
Use endpoint derivative $y'(a) = (I - S)^{+} f(a, y(a), p)$ at $x = a$ ($^{+}$ is a pseudoinverse), projecting $y(a)$ into the nullspace of $S$ in each solution.
Report `regularity_residual()` is $\max|S\,y(a)|$.
`with_singular` precomputes pseudoinverses of $S$ and $I - S$ by SVD; if $f(a, y(a), p)$ lies outside the range of $I - S$ under boundary tolerance, solving gives `InvalidInput`.

As an example, consider the Lane–Emden equation for stellar structure with index 5:

$$
w'' + \frac{2}{x}\,w' + w^5 = 0, \qquad w'(0) = 0, \qquad w(1) = \frac{\sqrt 3}{2}
$$

(Shampine 2003).
The exact solution is $w = (1 + x^2/3)^{-1/2}$.
Setting $y = (w, w')$ gives $S = \begin{bmatrix} 0 & 0 \\ 0 & -2 \end{bmatrix}$ and $f = (w', -w^5)$; requiring $S\,y(0) = (0, -2w'(0))$ to vanish matches boundary condition $w'(0) = 0$.

The next cell uses closure-based right-hand sides and boundaries in `BvpFn`, solving three Plans at tolerances $10^{-3}$, $10^{-6}$, and $10^{-9}$ with the same `BvpWorkspace` and `BvpSolution`.
The constructor `BvpFn::new(dimension, rhs, boundary)` creates closure systems without unknown parameters; one-shot `solve_bvp` uses it internally too.
Prepare workspace through `try_reserve` from estimate `BvpRequirements` of `workspace_requirements`; `solve_into` grows it if refinement exceeds capacity.
Limits are 64 MiB workspace and 2000 mesh points; inputs select the linear solver and refinement limit.

```rust

//|   - case: default

//|       - {"artifact":"emden","path":"/rows/2/5","range":{"max":1e-10}}
//|       - {"artifact":"emden","path":"/rows/0/5","range":{"max":1e-5}}

//|   - case: dense
//|     expect:
//|       - {"artifact":"emden","path":"/rows/2/1","equals":"MemoryLimit"}

//|       - {"artifact":"emden","path":"/rows/0/1","equals":"Converged"}

//|     expect:
//|       - {"artifact":"emden","path":"/rows/2/1","equals":"RefinementLimit"}
//|       - {"path":"/outputs/1/state","equals":"partial"}

    BvpBackend, BvpFn, BvpOptions, BvpPlan, BvpProblem, BvpSolution, BvpTermination,
    BvpWorkspace,

// With y = (w, w'), w'' + (2/x)w' + w⁵ = 0. Excluding singular S y/x, f = (w', −w⁵).
let emden = BvpFn::new(
    2,
    |_x: f64, y: &[f64], dy: &mut [f64]| {
        dy[0] = y[1];
        dy[1] = -scioxide_core::RealScalar::powi(y[0], 5);
        Ok(())
    },
    // Boundary conditions w'(0) = 0 and w(1) = √3/2.
    |a: &[f64], b: &[f64], r: &mut [f64]| {
        r[0] = a[1];
        r[1] = b[0] - 0.75_f64.sqrt();
        Ok(())
    },
);
let singular = Matrix::from_rows(&[[0.0, 0.0], [0.0, -2.0]]).map_err(|e| e.to_string())?;
let budget = |n: usize| Budget::try_from(n);
let backend = match backend.as_str() {
    "Dense" => BvpBackend::Dense,
    "Sparse" => BvpBackend::Sparse { limits: None },
    _ => BvpBackend::Krylov {
        iterations: budget(200).map_err(|e| e.to_string())?,
        restart: budget(40).map_err(|e| e.to_string())?,
    },
};
let mesh: Vec<f64> = (0..=10).map(|i| f64::from(i) / 10.0).collect();

// Reuse one workspace and output across three tolerance-specific Plans.
let mut workspace = BvpWorkspace::new();
let mut solution = BvpSolution::new();
let (mut rows, mut last) = (Vec::new(), None);

    let options = BvpOptions::new()
        .with_max_nodes(2000)
        .with_max_workspace_bytes(64 << 20)
        .with_backend(backend)
        .with_refinements(budget(refinements as usize).map_err(|e| e.to_string())?)
        .with_tolerances(
            ResidualTolerance::new(tol, tol).map_err(|e| e.to_string())?,
            ResidualTolerance::new(tol, 0.0).map_err(|e| e.to_string())?,
        );
    let plan = BvpPlan::new(2, 0, &mesh, options)
        .and_then(|plan| plan.with_singular(singular.view()))
        .map_err(|e| e.to_string())?;
    let requirements = plan
        .workspace_requirements(&problem)
        .map_err(|e| e.to_string())?;
    // Allocate enough for the initial mesh; solve_into grows it if refinement needs more.
    workspace
        .try_reserve(&requirements)
        .map_err(|e| e.to_string())?;
    let report = plan
        .solve_into(
            &problem,
            guess.view(),
            &[],
            &mut solution,
            &mut workspace,
            ExecutionContext::sequential(),
        )
        .map_err(|e| e.to_string())?;
    // Independent check: exact w = (1 + x²/3)^(−1/2) (reference from f64 inherent methods).
    let mut y = [0.0; 2];
    let mut worst = 0.0_f64;
    for x in (0..=100).map(|i| f64::from(i) / 100.0) {

            .evaluate_into(x, &mut y)
            .map_err(|e| e.to_string())?;

    last = Some(report.termination());
    let status = format!("{:?}", report.termination());

    let bytes = (requirements.required_bytes(), report.workspace_bytes());
    rows.push((
        tol,
        status,
        report.nodes(),
        residual,
        regularity,
        worst,
        bytes.0,
        bytes.1,

let columns = serde_json::json!([
    { "key": "0", "label": "Tolerance [-]", "type": "number", "format": sci2 },
    { "key": "1", "label": "Termination status" },
    { "key": "2", "label": "Mesh points", "type": "integer" },
    { "key": "3", "label": "Maximum normalized residual [-]", "type": "number", "format": sci2 },
    { "key": "4", "label": "max |S y(0)| [-]", "type": "number", "format": sci2 },
    { "key": "5", "label": "max |w − w_exact| [-]", "type": "number", "format": sci2 },

let outcome = match termination {
    BvpTermination::Converged => Outcome::satisfied("Met residual conditions at tolerance 10⁻⁹"),

    _ => Outcome::partial("Refinement stopped at a limit")
```

## Plans, workspaces, and termination statuses

The constructor `BvpPlan::new(dimension, parameter_dimension, mesh, options)` borrows no system, validates dimension, initial mesh (at least two strictly increasing finite points), and settings, and compares initial-mesh memory estimates with limits.
At solve time, check problem `dimension()` and `parameter_dimension()` against the Plan, returning `InvalidInput` on mismatch.
The Plan is immutable and supports any same-dimension problem.
Supply initial state guesses as `MatrixView` with one row per initial mesh point and one column per state component; unknown-parameter guesses are a slice.
Each solve starts from the Plan's initial mesh.

The constructor `BvpOptions::new()` returns settings without mesh-point or workspace-byte limits.
Supply limits through `with_max_nodes` and `with_max_workspace_bytes`.
Byte counts bound linear-solver memory estimates, rather than allocated amounts.
The estimate for `Dense` grows quadratically in unknown count $mn + k$; `Sparse { limits: None }` includes sparse-LU allowance determined by the workspace bound (twice one-quarter of the bound).
Each refinement compares its estimate with the bound; exceeding it prevents refinement and stops with `MemoryLimit`.

There are three APIs.

- One-shot `solve_bvp(rhs, boundary, mesh, guess)` wraps closures in `BvpFn` and uses defaults (tolerance $10^{-3}$, sparse LU, difference Jacobians).
  Termination other than `Converged` becomes an error (`ConvergenceFailure`, or `ResourceLimit` for mesh and memory limits).
- `BvpPlan::solve(&problem, guess, &parameters)` allocates new workspace and output, solves sequentially, and returns `BvpSolution`.
  It returns solutions even without `Converged`; check through `report()`.
- `BvpPlan::solve_into(&problem, guess, &parameters, &mut solution, &mut workspace, scope)` reuses workspace and output.
  Construct `BvpWorkspace` through `BvpPlan::workspace(&problem)`, or `BvpWorkspace::new()` and `try_reserve(&requirements)`, reusing across Plans and problems.
  The method `check(&requirements)` indicates whether capacity suffices.
  Workspace already used on the final mesh plus sufficient output capacity avoids allocation.

If any mesh produced a solution, `solve_into` returns `Ok` and a report even without status `Converged`.
The report `BvpReport` holds termination status `termination()`, `is_success()`, refinement count `refinements()`, mesh-point count `nodes()`, `max_residual()`, `boundary_residual()`, `regularity_residual()`, evaluation counts `counts()` and `accounting()`, and final memory estimate `workspace_bytes()`; it is also stored in `BvpSolution::report()`.
Errors leave the output solution unchanged, with workspace `last_attempt()` recording failed-attempt counts.
Evaluation limits, cancellation, or deadlines stopping before mesh evaluation also give errors rather than termination statuses.
Right-hand sides and boundary conditions are evaluated sequentially.

| `BvpTermination` | Meaning | Solution treatment |
|---|---|---|
| `Converged` | All residual, boundary, and singular-term conditions satisfied | Usable |
| `NodeLimit` | Next refinement would exceed `max_nodes` mesh points | Estimate on the final mesh |
| `MemoryLimit` | Next refinement memory estimate would exceed `max_workspace_bytes` | Same as above |
| `RefinementLimit` | Refinement-count limit reached | Same as above |
| `ResourceLimit(kind)` | Outer solve work limit prevents another refinement | Same as above |
| `MeshStagnation` | No representable floating-point midpoint in an interval to bisect | Same as above |
| `BoundaryFailure` | All interval residuals satisfy requirements, but boundary residuals exceed tolerance; refinement cannot improve this | Does not satisfy tolerance |
| `Nonlinear(reason)` | Newton did not converge on this mesh (`reason` is scioxide-rootfind's `RootTermination`) | Does not satisfy tolerance |

Non-`Converged` solutions can still be inspected and used as initial guesses for subsequent computations.
Termination status does not identify solution branches; compare with references or solutions from other initial guesses.

## Summary

Two-point BVPs combine endpoint conditions and collocation equations into equations for all unknowns.
The Plan `BvpPlan` solves three-stage Lobatto IIIA (fourth-order) equations with Newton, bisecting intervals whose normalized residual exceeds 1 and solving again.
Only `termination()` equal to `Converged` satisfies tolerance; `max_residual()` and `boundary_residual()` are residuals rather than error bounds, so verify against analytical solutions or finer meshes.
For multiple solutions, initial guesses determine convergence; near folds, making $\lambda$ unknown and prescribing another quantity permits tracking beyond the fold along the branch.
For many mesh points use default sparse LU; `Dense` first faces memory limits and unpreconditioned `Krylov` iteration limits.
