When assessing numerical integration, consider error order and stability separately.
Error order describes how rapidly error decreases as step size $h$ decreases.
Stability describes whether errors grow during long integration at fixed step size.
Even high-order methods produce exponentially diverging solutions if the step lies outside the stability region.
Even a nondivergent method departs from the true solution if local errors are large.

This page covers propagation of local truncation error into global error, measuring order by step halving, Dahlquist linear stability theory, and stiffness from widely separated component timescales.
We use the following notation.
The initial value problem is $y'(t) = f(t, y(t))$, $y(t_0) = y_0 \in \mathbb{R}^d$; $t_n$ is the endpoint of step $n$, $y_n$ the numerical solution there, and $h = t_{n+1} - t_n$ the step size.

## Local truncation error and global error

### Local truncation error

Let $y_{n+1}^*$ be the numerical solution after one step starting from the true solution $y(t_n)$ at time $t_n$.
The local truncation error is the one-step discretization error

$$
d_{n+1} = y(t_{n+1}) - y_{n+1}^*
$$


A method has order $p$ if $d_{n+1} = O(h^{p+1})$ for sufficiently smooth $f$.
For linear multistep methods, the leading term has the form $C_{p+1} h^{p+1} y^{(p+1)}(t_n)$.
For Runge–Kutta methods, it is a weighted sum of elementary differentials combining $f$ and its partial derivatives, with weights determined by the method coefficients.

### Global error bound

Let the global error be $e_n = y(t_n) - y_n$.
If $f$ has Lipschitz constant $L > 0$ in $y$ ($\|f(t, u) - f(t, v)\| \le L \|u - v\|$), then $\|e_{n+1}\| \le (1 + hL)\|e_n\| + \|d_{n+1}\|$ over one step (for a one-step method).
Iterating this and using the discrete Grönwall inequality gives

$$
\|e_n\| \le \frac{\max_k \|d_k\|}{h L} \left( e^{L(t_n - t_0)} - 1 \right) \le \frac{C h^{p+1}}{h L} e^{L (T - t_0)} = O(h^p)
$$


Here $T$ is the integration endpoint, and $C$ bounds the leading local-error coefficient.
Local error $O(h^{p+1})$ accumulates over $N = (T - t_0)/h$ steps, reducing global error order by one to $O(h^p)$.
The factor $e^{L(T - t_0)}$ bounds the rate at which two nearby solutions separate.
It becomes large for chaotic systems or long integrations, so satisfying local tolerances does not determine endpoint accuracy.
For systems with invariants, choose structure-preserving methods such as [Geometric integrators](../geometric-integrators/).

Adaptive methods in `scioxide-ode` control only local error.
Check endpoint accuracy against known solutions or solutions at different tolerances.

## Observed order by step halving

Even without an analytical solution, order can be measured from numerical solutions $Y_h$, $Y_{h/2}$, and $Y_{h/4}$ at step sizes $h$, $h/2$, and $h/4$.
If $Y_h - y(T) \approx C h^p$ in the asymptotic regime, then

$$
\frac{\|Y_h - Y_{h/2}\|}{\|Y_{h/2} - Y_{h/4}\|} \approx \frac{C h^p (1 - 2^{-p})}{C (h/2)^p (1 - 2^{-p})} = 2^p
$$

so the observed order is

$$
p_{\text{obs}} = \log_2 \frac{\|Y_h - Y_{h/2}\|}{\|Y_{h/2} - Y_{h/4}\|}
$$


Checking that observed order approaches nominal order can reveal errors in the right-hand side or coefficients.
It departs from nominal order when steps are too large for the asymptotic regime or too small to avoid rounding-error dominance.

Nominal order applies in the asymptotic regime of small $h\lambda$.
For stiff problems, halving steps while $|h\lambda| \gg 1$ remains true can reduce implicit Runge–Kutta observed order to the stage order (the approximation order of stage values $Y_i$).
This is called order reduction.
The following Prothero–Robinson problem

$$
y' = \lambda \bigl(y - \cos t\bigr) - \sin t, \qquad y(0) = 1
$$

has exact solution $y = \cos t$ independently of $\lambda$ and becomes stiffer as $\lambda < 0$ becomes more negative.

The following block supplies definitions shared by this page's two cells.
The function `fixed_step_endpoint` solves a one-component system with a fixed-step method for $[0, T]$, returning terminal value $y_N$.
Explicit methods diverge on the stiff problem, stopping with a `NonFinite` error when the state becomes nonfinite; such solutions become `None`.
Other errors and reports not reaching the endpoint propagate as failures.

```rust
//| id: ode-fixed-step-endpoint
//| kind: definitions
//| title: "Solve a one-component system with a fixed-step method and return its terminal value"
//| crates: [scioxide-core, scioxide-linalg, scioxide-ode]
use scioxide_core::{ErrorTolerance, ExecutionContext, SciOxideErrorKind};
use scioxide_linalg::Vector;
use scioxide_ode::{OdeMethod, OdeOptions, OdeProblem, OdeState, OdeSystem};

/// Terminal value after solving [0, end] from y(0) = 1 with step `step`. Divergent solutions are None.
pub(crate) fn fixed_step_endpoint<M: OdeMethod<f64> + Clone, Sys: OdeSystem<f64>>(
    method: &M,
    system: &Sys,
    tolerance: &ErrorTolerance<f64>,
    end: f64,
    step: f64,
) -> Result<Option<f64>, String> {
    let problem = OdeProblem::new(system, end);
    let options = OdeOptions::new()
        .with_error_tolerance(tolerance.clone())
        .with_initial_step(step);
    let mut workspace = method
        .workspace(&problem, &options)
        .map_err(|e| e.to_string())?;
    let mut state = OdeState::new(0.0, Vector::from_vec(vec![1.0]));
    let run = method.advance(
        &problem,
        &options,
        &mut state,
        &mut (),
        &mut workspace,
        ExecutionContext::sequential(),
    );
    match run {
        Ok(report) if report.is_success() => Ok(Some(state.values()[0])),
        Ok(report) => Err(format!("{:?}", report.termination())),
        Err(e) if e.kind() == SciOxideErrorKind::NonFinite => Ok(None),
        Err(e) => Err(e.to_string()),
    }
}
```

## Dahlquist test equation and absolute stability regions

To examine long-term stability, use the Dahlquist linear test equation

$$
y' = \lambda y, \qquad \lambda \in \mathbb{C}, \quad \operatorname{Re}\lambda < 0
$$


The true solution $y(t) = y_0 e^{\lambda t}$ decays to zero for $t \to \infty$.
Applying Runge–Kutta to this equation expresses the numerical solution using complex $z = h\lambda$ as

$$
y_{n+1} = R(z)\, y_n
$$


The rational function $R(z)$ (a polynomial for explicit methods) is called the stability function.
For Runge–Kutta coefficient matrix $A$ and weights $b$, $R(z) = 1 + z\, b^{\mathsf{T}} (I - zA)^{-1} \mathbf{1}$.
The numerical sequence $y_n$ is bounded if and only if $|R(z)| \le 1$; the set satisfying this condition,

$$
\mathcal{S} = \{ z \in \mathbb{C} \mid |R(z)| \le 1 \}
$$

is called the absolute stability region.
For an $d$-dimensional linear system $y' = Ay$ with diagonalizable $A$, the same argument applies to every eigenvalue $\lambda_i$, requiring every $h\lambda_i$ to lie in $\mathcal{S}$.

### Stability functions of representative methods

| Method | Stability function $R(z)$ | Stable negative-real-axis interval |
|---|---|---|
| Forward Euler | $1 + z$ | $[-2, 0]$ |
| Classical RK4 | $1 + z + z^2/2 + z^3/6 + z^4/24$ | $[-2.785, 0]$ |
| Backward Euler | $1/(1 - z)$ | Entire negative real axis |
| Implicit trapezoidal | $(1 + z/2)/(1 - z/2)$ | Entire negative real axis |
| Two-stage Gauss | $(1 + z/2 + z^2/12)/(1 - z/2 + z^2/12)$ | Entire negative real axis |
| Three-stage Radau IIA | $(1 + 2z/5 + z^2/20)/(1 - 3z/5 + 3z^2/20 - z^3/60)$ | Entire negative real axis |

Explicit methods have polynomial $R$, so $|R(z)| \to \infty$ as $|z| \to \infty$, giving bounded stability regions.
For implicit trapezoidal and Gauss methods, $R$ is a diagonal Padé approximant of $e^z$, with $|R| = 1$ on the imaginary axis.
Radau IIA's $R$ is a Padé approximant with higher denominator than numerator degree, approaching zero as $|z| \to \infty$.
Three-stage SDIRK (`Sdirk`) has rational $R$ with denominator $(1 - \gamma z)^3$, also approaching zero as $|z| \to \infty$.

### Stability intervals reported by methods

Each method returns real- and imaginary-axis intervals satisfying $|R(z)| \le 1$ as `OdeLinearStability` through `OdeMethod::linear_stability`.
The value `OdeLinearStability::Axes { real, imaginary }` indicates that the numerical solution does not grow when $h\lambda$ lies in negative-real interval $[-\mathrm{real}, 0]$ or imaginary interval $[-i\,\mathrm{imaginary}, i\,\mathrm{imaginary}]$.
The value `None` means the entire half-line or axis is stable; 0 means no nonzero step is stable.
Finite values are decimal constants rounded down from the stability boundary: 2 for forward Euler, 2.7852 for classical RK4, 3.3065 for `DormandPrince5`, and 6.3936 for `DormandPrince853`.
Since `Rkf45` advances with the fifth-order solution, its imaginary-axis interval is 0.
A-stable implicit methods and `RosenbrockW` return `None` on both axes.
The method `Bdf` with maximum order at least 3 reports the whole negative real axis and an imaginary-axis interval of 0.
Methods without reported stability regions, such as Adams, return `Undeclared`.

These statements concern the test equation.
For the method of lines (spatially semidiscrete systems), combine them with spatial-discretization eigenvalue ranges to determine explicit step-size bounds.
For example, solving a semidiscrete diffusion system with eigenvalues in $[-\rho, 0]$ using `DormandPrince5` requires $h \le 3.3065/\rho$ for stability.
A system knowing such a bound can supply it per step through `OdeSystem::step_limit` ([Explicit Runge–Kutta methods and step-size control](../explicit-runge-kutta-and-control/)).

## A-stability and L-stability

For stiff systems, the extent of stability along the negative real axis determines the step-size bound.

A method is A-stable if its absolute stability region $\mathcal{S}$ contains the left half-plane $\mathbb{C}^- = \{ z \mid \operatorname{Re} z \le 0 \}$.
With A-stable methods, a linear system's numerical solution does not diverge for any step size $h > 0$ while all eigenvalues have negative real parts.
Backward Euler, implicit trapezoidal, Gauss, Radau IIA, and `Sdirk` are A-stable.

Even among A-stable methods, damping rates at large $|z|$ differ greatly.
For implicit trapezoidal,

$$
\lim_{z \to -\infty} R_{\text{TR}}(z) = \lim_{z \to -\infty} \frac{1 + z/2}{1 - z/2} = -1
$$


For components decaying rapidly in the true solution ($h\lambda \ll -1$), the numerical amplification factor approaches $-1$.
The component barely decays, leaving apparent oscillations with alternating sign each step.
A method is L-stable if it is A-stable and also satisfies

$$
\lim_{|z| \to \infty} R(z) = 0
$$


Backward Euler, `Sdirk`, and `RadauIia` are L-stable, reducing fast components almost to zero in one step when the step greatly exceeds their timescales.
L-stability, however, describes damping of fast components, not accurate reproduction of their decay rate $e^{h\lambda}$.

## Stiffness

A system is called stiff when the eigenvalues $\lambda_i$ of $y' = Ay$ all have negative real parts whose magnitudes span many orders.
The magnitude ratio $\max_i |\operatorname{Re}\lambda_i| / \min_i |\operatorname{Re}\lambda_i|$ is sometimes called the stiffness ratio.
Fast components decay on a timescale of order $1/|\lambda_{\max}|$, after which only slow components determine the solution.
Explicit methods must keep $h|\lambda_{\max}|$ within the stability region, restricting steps to order $1/|\lambda_{\max}|$ even after fast components disappear.
A practical definition of stiffness is that stability rather than accuracy determines the step size.
In nonlinear systems, eigenvalues of Jacobian $\partial f/\partial y$ vary along the solution, so stiffness also changes over time.

For stiff systems, use implicit methods ([Implicit Runge–Kutta methods and mass matrices](../implicit-runge-kutta-and-mass-matrices/), [Linear multistep methods](../multistep-methods/)) or Rosenbrock-type methods ([Rosenbrock methods and automatic stiffness switching](../rosenbrock-and-stiffness-switching/)).
These solve linear systems of the form $I - h\gamma J$ each step, increasing per-step cost but allowing accuracy to determine the step size.
For unknown or changing stiffness, `AutoStiff` and `AdamsBdf` estimate stiffness from step histories and switch methods.

### Transient growth in nonnormal systems

If $A$ is normal ($AA^{\mathsf{H}} = A^{\mathsf{H}}A$), then $\|e^{At}\|_2 = \max_i e^{t \operatorname{Re}\lambda_i}$, and eigenvalues alone determine stability.
When $A$ is strongly nonnormal, as in fluid shear flows or some reaction networks, even with all eigenvalues having negative real parts,

$$
\sup_{t \ge 0} \|e^{At}\| \gg 1
$$

and the solution norm grows greatly over a short interval.
This is called transient growth.
The same applies numerically: even with every $h\lambda_i$ in the stability region, $\|R(hA)^n\|$ can grow large transiently.
The pseudospectrum (the set of $z$ satisfying $\|(zI - A)^{-1}\| > 1/\delta$) explains this behavior (Trefethen and Embree).
For nonnormal systems, examine $\|e^{At}\|$ and the numerical-solution norm over time as well as eigenvalues.

## Summary

An order-$p$ method has global error $O(h^p)$ over a finite interval, but the constant includes interval length and an exponential involving the Lipschitz constant, so local tolerances alone do not determine endpoint accuracy over long integrations.
Measuring observed order by step halving checks method and right-hand-side implementations and reveals reduction toward stage order in stiff problems.
For stiff systems, the stability function determines step size; A-stable methods avoid divergence, while damping fast components requires L-stability.
Read the method's reported real- and imaginary-axis stability intervals through `OdeMethod::linear_stability` and combine them with spatial-discretization eigenvalue ranges to select explicit step sizes.
For nonnormal systems, check transient growth as well as eigenvalues.
