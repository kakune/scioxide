The tables on this page collect types solving two-point boundary value problems $y' = f(x, y, p)$ ($a \le x \le b$), $g(y(a), y(b), p) = 0$ by collocation.
Here $y$ is a state with $n$ components, $p$ contains $k$ unknown parameters, and $g$ gives $n + k$ boundary conditions; the interval $[a, b]$ is the range of the Plan's mesh.
Three-stage Lobatto IIIA (Simpson) collocation equations on each interval determine mesh values and $p$ through damped Newton iteration, returning a $C^1$ piecewise cubic Hermite interpolant with fourth-order accuracy at mesh points.
Interval residual magnitudes $u' - f(x, u, p)$ determine where to add mesh points, and the problem is solved again until tolerances are satisfied.
Solutions stopped before satisfying tolerances also return as `Ok`; only `BvpTermination` determines success.
Invalid inputs, numerical failure, and stops due to outer solve limits or cancellation give `Err`.

| [`BvpSolution`](https://docs.rs/scioxide-ode/0.1.0/scioxide_ode/struct.BvpSolution.html) | Struct | $C^1$ piecewise cubic solution, parameters, and interval residuals | Hermite interpolation of mesh values and derivatives $f(x_j, y_j, p)$ on each interval. `new()` is an empty solution, written by `solve_into`, growing memory only when the final mesh exceeds capacity.
