The tables on this page collect time-evolution solvers with problem types distinct from `OdeSystem`.
Every solver executes by passing the problem, settings, caller-owned state, output sink, and workspace to an integrator object or Plan.
Stops at attempt or evaluation limits, cancellation, or deadlines also return `Ok` reports; the report's termination status alone determines success.
After an error, the state retains the last accepted point; progress is carried by workspace `last_attempt()` and by `PartialFailure` in the owned-value API's `solve`.
