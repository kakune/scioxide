This page's tables cover solution derivatives with respect to parameters and initial values, and execution of independent problems with varying parameters.
Forward sensitivity integrates an augmented system with initial value problem methods, adding equations of state size for each parameter direction.
Adjoints compute scalar-objective gradients through forward integration, checkpoint recomputation, and a backward sweep.
Adjoint gradients are written only on success; failures leave outputs unchanged.
