The tables on this page collect types solving initial value problems $M y' = f(t, y)$, $y(t_0) = y_0$.
Here $t$ is real time, $y$ a real or complex state with $n$ components, and $M$ a constant nonsingular mass matrix (identity by default).
The function `OdeMethod::advance` returns `Result<OdeSolveReport, SciOxideError>`.
Stops at attempt or evaluation limits, minimum step sizes, cancellation, or deadlines also return `Ok` reports; the report's termination status alone determines success.
Failed calls retain progress through the last accepted point in workspace `last_attempt()`.

## Output, reports, and failures

Dense output is constructed within a method's accepted steps and has no public type.
When times are specified through `OdeOutputSchedule::Times`, the sink receives their positions and values through `emit_requested`.
Specifying times for a method without dense output is rejected with `InvalidInput` before callbacks.
