The tables on this page collect integrator objects implementing `OdeMethod` and components solving implicit stage equations.
Integrator objects hold only coefficients and method-specific settings; dimension-dependent memory belongs to workspace.
Each method uses either adaptive steps controlled by local error estimates or fixed supplied steps, with differing support for dense output, events, and mass matrices ([Choosing a method](../../choosing/)).
Fixed-step methods use the `OdeOptions::with_initial_step` value (or an estimated initial step if absent) throughout, shortening only the final step to the endpoint.
Unsupported feature settings are rejected before integration with `InvalidInput` (`UnsupportedConfiguration`).
Implicit stage-solver failure causes adaptive methods to halve the step and retry, while fixed-step methods return the error directly.
