Quantities whose rates and fluctuation magnitudes both scale with current value, such as stock prices, follow geometric Brownian motion (GBM),

$$
dY = a\,Y\,dt + \sigma\,Y\,dW, \qquad Y(0) = Y_0
$$


Here $a$ is drift rate and $\sigma$ fluctuation strength (volatility).
GBM has exact solutions on the same Wiener path, permitting direct measurement of pathwise numerical errors, or strong errors.
This example shares a Brownian-bridge path while varying only steps, checking interpretation differences and both solvers' strong orders.
[Stochastic differential equation interpretations and solvers](../../algorithms/stochastic-equations/) explains interpretations, drift corrections, and strong convergence.

## Exact solutions under both interpretations

Even with identical coefficients, Itô and Stratonovich solutions differ:

$$
Y^{\mathrm I}(t) = Y_0 \exp\!\left(\left(a - \frac{\sigma^2}{2}\right)t + \sigma W(t)\right), \qquad
Y^{\mathrm S}(t) = Y_0 \exp\bigl(a t + \sigma W(t)\bigr)
$$


Stratonovich follows by integrating $d \log Y = a\,dt + \sigma \circ dW$ with the ordinary chain rule; Itô includes correction $-\sigma^2/2$ from Itô's formula.
Expectations are $\mathbb E\, Y^{\mathrm I}(t) = Y_0 e^{at}$ and $\mathbb E\, Y^{\mathrm S}(t) = Y_0 e^{(a + \sigma^2/2)t}$.
Use $a = 0.4$, $\sigma = 0.7$, $Y_0 = 1$, and $t \in [0, 1]$ below (time in years; $a$ and $\sigma^2$ in 1/year).

The method `EulerMaruyama` converges to Itô; `StochasticHeun` to Stratonovich.
Scalar noise suggests strong order 1 for stochastic Heun and 1/2 for Euler–Maruyama.

## Reusing a path with different steps

To measure strong error against step size, change only steps, never the Wiener path.
Fresh random increments for each step count instead compare different paths.

This example constructs path $W(t_1), \dots, W(t_{1024})$ on fine grid $t_i = i/1024$ with scioxide-random's `BrownianBridgePlan`.
Brownian bridges determine coarse-to-fine values: first $W(1)$, then $W(1/2)$ conditional on endpoints ([Hierarchical stochastic paths with Brownian bridges](../../../scioxide-random/examples/brownian-bridge/)).
Coarse-grid values therefore depend only on initial coordinates and remain unchanged as the grid is refined.
Supply increments $\Delta W_i = W(t_{i+1}) - W(t_i)$ to `SdeProblem` and use `with_step_boundaries` to place step boundaries every $1024/N$ intervals; the $N$-step solution sums intervening increments.
This constructs solutions with step counts $N = 4, 8, \dots, 256$ on the same path.

The following block supplies the model and path construction shared by this page's cells.
The type `Gbm` implements GBM `SdeSystem`; `fine_times` is the fine grid, `bridge_increments` builds bridge paths and increments from standard normal coordinates, `step_boundaries` supplies $N$-step boundaries, and `gbm_exact` gives exact solutions for both interpretations.

```rust
//| id: ode-gbm-model
//| kind: definitions
//| title: "Geometric Brownian coefficients, bridge increments, and exact solutions"
//| crates: [scioxide-core, scioxide-random, scioxide-ode]
use scioxide_core::{SciOxideError, RealScalar, SolveContext};
use scioxide_ode::SdeSystem;
use scioxide_random::{BrownianBridgePlan, SamplingWorkspace};

/// dY = a Y dt + σ Y dW (a = 0.4, σ = 0.7 [1/year]).
pub(crate) struct Gbm;
pub(crate) const DRIFT: f64 = 0.4;
pub(crate) const VOLATILITY: f64 = 0.7;
/// Fine-grid interval count.
pub(crate) const FINE: usize = 1024;

impl SdeSystem<f64> for Gbm {
    fn dimension(&self) -> usize {
        1
    }

    fn noise_dimension(&self) -> usize {
        1
    }

    fn drift(
        &self,
        _: f64,
        y: &[f64],
        out: &mut [f64],
        _: &mut SolveContext<'_, '_>,
    ) -> Result<(), SciOxideError> {
        out[0] = DRIFT * y[0];
        Ok(())
    }

    fn diffusion_product(
        &self,
        _: f64,
        y: &[f64],
        dw: &[f64],
        out: &mut [f64],
        _: &mut SolveContext<'_, '_>,
    ) -> Result<(), SciOxideError> {
        out[0] = VOLATILITY * y[0] * dw[0];
        Ok(())
    }
}

/// Fine grid t_i = i/1024 (i = 0, …, 1024).
pub(crate) fn fine_times() -> Vec<f64> {
    (0..=FINE).map(|i| i as f64 / FINE as f64).collect()
}

/// Build path = (W(t₁), …, W(t₁₀₂₄)) from z and write increments W(t_{i+1}) − W(t_i).
pub(crate) fn bridge_increments(
    bridge: &BrownianBridgePlan<f64>,
    z: &[f64],
    path: &mut [f64],
    increments: &mut [f64],
    workspace: &mut SamplingWorkspace<f64>,
) -> Result<(), SciOxideError> {
    bridge.apply_into(z, path, workspace)?;
    increments[0] = path[0];
    for i in 1..FINE {
        increments[i] = path[i] - path[i - 1];
    }
    Ok(())
}

/// Boundaries for N steps: 0, 1024/N, 2·1024/N, …, 1024 (fine-grid indices).
pub(crate) fn step_boundaries(steps: usize) -> Vec<usize> {
    (0..=steps).map(|k| k * FINE / steps).collect()
}

/// Exact solutions: Itô exp((a − σ²/2)t + σW), Stratonovich exp(at + σW), with Y₀ = 1.
pub(crate) fn gbm_exact(stratonovich: bool, t: f64, w: f64) -> f64 {
    let correction = if stratonovich {
        0.0
    } else {
        VOLATILITY * VOLATILITY / 2.0
    };
    RealScalar::exp((DRIFT - correction) * t + VOLATILITY * w)
}
```

## Measuring strong order

Estimate strong error $\mathbb E\,|Y(1) - Y_N|$ by averaging many paths.
The next cell solves $N = 4, 8, \dots, 256$ on each of $M$ paths, computing mean error and standard error (SE) per step count.
The log–log slope of error $e(h) \approx C h^{\gamma}$ gives strong order $\gamma$.
This is asymptotic as $h \to 0$; coarse steps retain higher-order terms, so the table also gives adjacent-step local slopes $\log_2\bigl(e(2h)/e(h)\bigr)$.
Split paths equally into 10 groups, passing group mean errors to the next cell.

```rust
//| id: ode-gbm-strong-errors
//| ref: ode-gbm-strong-errors
//| title: "Collect strong errors at different steps on the same paths"
//| run: button
//| cache: inputs
//| uses: [ode-gbm-model]
//| crates: [scioxide-core, scioxide-linalg, scioxide-random, scioxide-ode]
//| exports: [group_errors]
//| inputs:
//|   paths: {"type":"range","label":"Path count M [paths]","description":"Split equally into 10 groups. Slope confidence intervals shrink as 1/√M.","min":100,"max":600,"step":100,"value":300}
//|   seed: {"type":"range","label":"Random seed","min":1,"max":1000,"step":1,"value":26}
//| cases:
//|   - {"id":"few-paths","label":"M = 100","description":"SE widens.","inputs":{"paths":100}}
//|   - {"id":"other-seed","label":"Seed 5","description":"Another path ensemble.","inputs":{"seed":5}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"errors","path":"/rows/6/6","range":{"min":0.9,"max":1.15}}
//|       - {"artifact":"errors","path":"/rows/0/1","range":{"min":0.15,"max":0.2}}
use scioxide_core::{ExecutionContext, RealScalar};
use scioxide_linalg::MatrixView;
use scioxide_ode::{OdeState, SdeMethod, SdeOptions, SdeProblem, SdeWorkspace};
use scioxide_random::{BrownianBridgePlan, Distribution, Normal, SeedableRng, SplitMix64};

let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let fixed3 = serde_json::json!({ "fractionDigits": 3 });
let (groups, levels) = (10_usize, [4_usize, 8, 16, 32, 64, 128, 256]);
let m = (paths.round() as usize / groups) * groups;
let times = fine_times();
let bridge = BrownianBridgePlan::new(&times).map_err(|e| e.to_string())?;
let mut bridge_workspace = bridge.workspace(()).map_err(|e| e.to_string())?;
let standard = Normal::<f64>::standard();
let mut rng = SplitMix64::from_seed(seed.round() as u64);
let (mut z, mut path, mut increments) = (vec![0.0; FINE], vec![0.0; FINE], vec![0.0; FINE]);
let boundaries: Vec<Vec<usize>> = levels.iter().map(|&n| step_boundaries(n)).collect();
let options = SdeOptions::new();
let methods = [SdeMethod::EulerMaruyama, SdeMethod::StochasticHeun];
// errors[k][l][p] = |Y(1) − Y_N| for solver k, step count levels[l], path p.
let mut errors = vec![vec![vec![0.0; m]; levels.len()]; 2];
// Reuse workspace across all solutions.
let mut workspace = SdeWorkspace::new();
for p in 0..m {
    for value in &mut z {
        *value = standard.sample(&mut rng).map_err(|e| e.to_string())?;
    }
    bridge_increments(
        &bridge,
        &z,
        &mut path,
        &mut increments,
        &mut bridge_workspace,
    )
    .map_err(|e| e.to_string())?;
    let view = MatrixView::from_slice(FINE, 1, &increments).map_err(|e| e.to_string())?;
    for (k, method) in methods.into_iter().enumerate() {
        let exact = gbm_exact(k == 1, 1.0, path[FINE - 1]);
        for (l, cuts) in boundaries.iter().enumerate() {
            let problem = SdeProblem::new(&Gbm, &times, view).with_step_boundaries(cuts);
            let mut state = OdeState::from_slice(0.0, &[1.0]).map_err(|e| e.to_string())?;
            let cx = ExecutionContext::sequential();
            let report = method
                .advance(&problem, &options, &mut state, &mut (), &mut workspace, cx)
                .map_err(|e| e.to_string())?;
            if !report.is_success() {
                return Err(format!("{method:?} incomplete: {:?}", report.termination()));
            }
            errors[k][l][p] = (state.values()[0] - exact).abs();
        }
    }
}
let mean = |v: &[f64]| v.iter().sum::<f64>() / v.len() as f64;
// group_errors[k][l][g] = mean error for group g.
let size = m / groups;
let group_errors: Vec<Vec<Vec<f64>>> = (0..2)
    .map(|k| {
        (0..levels.len())
            .map(|l| {
                (0..groups)
                    .map(|g| mean(&errors[k][l][g * size..(g + 1) * size]))
                    .collect()
            })
            .collect()
    })
    .collect();
export!(group_errors, &group_errors);
let mut rows = Vec::new();
for (l, &n) in levels.iter().enumerate() {
    let stats = |k: usize| {
        let e = &errors[k][l];
        let mu = mean(e);
        let var = e.iter().map(|v| (v - mu) * (v - mu)).sum::<f64>() / (m - 1) as f64;
        (mu, RealScalar::sqrt(var / m as f64))
    };
    // Adjacent-step local slope log₂(e(2h)/e(h)).
    let local = |k: usize| {
        (l > 0)
            .then(|| RealScalar::ln(mean(&errors[k][l - 1]) / mean(&errors[k][l])) / 2f64.ln())
    };
    let ((em, em_se), (heun, heun_se)) = (stats(0), stats(1));
    rows.push((n, em, em_se, heun, heun_se, local(0), local(1)));
}
let columns = serde_json::json!([
    { "key": "0", "label": "Step count N [-]", "type": "integer" },
    { "key": "1", "label": "EM mean error [Y₀]", "type": "number", "format": sci3 },
    { "key": "2", "label": "EM SE [Y₀]", "type": "number", "format": sci3 },
    { "key": "3", "label": "Heun mean error [Y₀]", "type": "number", "format": sci3 },
    { "key": "4", "label": "Heun SE [Y₀]", "type": "number", "format": sci3 },
    { "key": "5", "label": "EM local slope [-]", "type": "number", "format": fixed3, "nullText": "-" },
    { "key": "6", "label": "Heun local slope [-]", "type": "number", "format": fixed3, "nullText": "-" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "errors" })
);
```

With defaults ($M = 300$, seed 26), Euler–Maruyama mean error falls from 0.173 at $N = 4$ to 0.026 at $N = 256$; stochastic Heun falls from 0.070 to $1.39 \times 10^{-3}$.
Euler–Maruyama local slopes 0.41–0.52 scatter around 1/2.
Stochastic-Heun local slopes are 0.86–0.94 below 1 for $N \le 64$, then 1.02 and 1.03 at $N = 128$ and $256$.
Stochastic Heun uses twice the evaluations per step, but its equal-cost error $2.8 \times 10^{-3}$ at $N = 128$ is about one-ninth of Euler–Maruyama's 0.026 at $N = 256$.

Estimate slopes by least-squares fitting $\log e$ against $\log h$ for points with step count at least $N_{\min}$.
Estimate slope uncertainty from variation among group slopes.
For group slopes $\gamma_1, \dots, \gamma_{10}$ with mean $\bar\gamma$ and standard deviation $s_\gamma$, the 95% interval is $\bar\gamma \pm t_{0.975, 9}\, s_\gamma/\sqrt{10}$ ($t_{0.975, 9} = 2.262$).
The next cell takes $N_{\min}$ and computes the all-path mean-error slope, group-slope mean, and confidence interval.
Dashed guides of slopes 1/2 and 1 pass through the finest-step error.

```rust
//| id: ode-gbm-strong-order
//| ref: ode-gbm-strong-order
//| title: "Read strong order from strong-error slopes and confidence intervals"
//| run: reactive
//| crates: [scioxide-core]
//| dependsOn:
//|   collected: ode-gbm-strong-errors
//| inputs:
//|   fit_from: {"type":"range","label":"Exponent of minimum fitted step count (N_min = 2^k)","description":"Exclude coarse steps from fitting.","min":2,"max":6,"step":1,"value":4}
//| cases:
//|   - {"id":"all-levels","label":"N_min = 4","description":"Including coarse steps makes stochastic-Heun slopes fall below 1.","inputs":{"fit_from":2}}
//|   - {"id":"fine-levels","label":"N_min = 64","description":"Fitting only the finest three points widens confidence intervals.","inputs":{"fit_from":6}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"orders","path":"/rows/0/1","range":{"min":0.4,"max":0.6}}
//|       - {"artifact":"orders","path":"/rows/1/1","range":{"min":0.9,"max":1.1}}
//|   - case: all-levels
//|     expect:
//|       - {"artifact":"orders","path":"/rows/1/1","range":{"min":0.85,"max":1.0}}
use scioxide_core::RealScalar;

let fixed3 = serde_json::json!({ "fractionDigits": 3 });
let group_errors: Vec<Vec<Vec<f64>>> =
    serde_json::from_value(collected["group_errors"].clone()).map_err(|e| e.to_string())?;
let levels = [4_usize, 8, 16, 32, 64, 128, 256];
let first = (fit_from.round() as usize).saturating_sub(2);
let log_h: Vec<f64> = levels[first..]
    .iter()
    .map(|&n| RealScalar::ln(1.0 / n as f64))
    .collect();
let mean = |v: &[f64]| v.iter().sum::<f64>() / v.len() as f64;
// Least-squares slope of log e against log h (errors at N ≥ N_min).
let slope = |e: &[f64]| {
    let y: Vec<f64> = e.iter().map(|v| RealScalar::ln(*v)).collect();
    let (xm, ym) = (mean(&log_h), mean(&y));
    let num: f64 = log_h.iter().zip(&y).map(|(x, v)| (x - xm) * (v - ym)).sum();
    num / log_h.iter().map(|x| (x - xm) * (x - xm)).sum::<f64>()
};
let (mut rows, mut series) = (Vec::new(), Vec::new());
for (k, name) in ["EulerMaruyama", "StochasticHeun"].into_iter().enumerate() {
    let errors = &group_errors[k];
    let groups = errors[0].len();
    let overall: Vec<f64> = errors.iter().map(|e| mean(e)).collect();
    let slopes: Vec<f64> = (0..groups)
        .map(|g| slope(&errors[first..].iter().map(|e| e[g]).collect::<Vec<_>>()))
        .collect();
    let gm = mean(&slopes);
    let var = slopes.iter().map(|s| (s - gm) * (s - gm)).sum::<f64>() / (groups - 1) as f64;
    // 97.5% t-distribution quantile (9 degrees of freedom).
    let half = 2.262 * RealScalar::sqrt(var / groups as f64);
    let theory = if k == 0 { 0.5 } else { 1.0 };
    rows.push((
        name,
        slope(&overall[first..]),
        gm,
        gm - half,
        gm + half,
        theory,
    ));
    let points: Vec<[f64; 2]> = levels
        .iter()
        .zip(&overall)
        .map(|(&n, &e)| [1.0 / n as f64, e])
        .collect();
    // Slope-γ guide through the finest-step error.
    let finest = overall[levels.len() - 1];
    let reference: Vec<[f64; 2]> = levels
        .iter()
        .map(|&n| [1.0 / n as f64, finest * (256.0 / n as f64).powf(theory)])
        .collect();
    series.push(serde_json::json!({ "name": format!("{name} mean error"), "points": points }));
    series.push(serde_json::json!({
        "name": format!("Slope {theory} (reference)"),
        "points": reference,
        "style": { "lineType": "dashed" }
    }));
}
emit_line_chart!(
    &series,
    options = &serde_json::json!({
        "xLabel": "Step size h [years]",
        "yLabel": "Strong error E|Y(1) − Y_N| [Y₀]",
        "xType": "log",
        "yType": "log"
    })
);
let columns = serde_json::json!([
    { "key": "0", "label": "Solver" },
    { "key": "1", "label": "All-path slope [-]", "type": "number", "format": fixed3 },
    { "key": "2", "label": "Mean group slope [-]", "type": "number", "format": fixed3 },

]);
emit_table_with_columns!(
```

At default $N_{\min} = 16$, Euler–Maruyama slope is 0.448; group-slope 95% interval $[0.363, 0.556]$ contains theoretical 1/2.
Stochastic-Heun slope is 0.957, with interval $[0.923, 0.981]$ narrowly excluding 1.
At $N_{\min} = 4$, its slope falls to 0.936 with interval $[0.913, 0.955]$; at $N_{\min} = 64$, the slope is 1.029 and the interval $[0.904, 1.131]$ includes 1.
Confidence intervals describe path-selection variability only, excluding systematic higher-order effects at coarse steps.
Including more coarse steps narrows intervals but shifts their centers away from asymptotic order.
Compare slopes with theory using an asymptotic range with settled local slopes, also considering interval widening from fewer fitted points.

## Summary

Even with identical GBM coefficients, Itô and Stratonovich differ by drift $\sigma^2/2$; `EulerMaruyama` converges to the former and `StochasticHeun` to the latter.
To measure strong error versus step size, coarsen one Brownian-bridge or equivalent path through `with_step_boundaries`, changing steps without changing paths.
Log–log slopes of many-path mean errors verify Euler–Maruyama strong order 1/2 and scalar-noise stochastic-Heun order 1.
Estimate slope uncertainty across path groups, rather than inferring order from a single path's error.
Intervals reflect sampling variation only; choose the fitted step range where local slopes have settled asymptotically.
