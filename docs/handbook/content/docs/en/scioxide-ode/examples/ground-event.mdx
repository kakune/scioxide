A falling body's impact time is determined by the state condition height $h(t) = 0$, rather than prescribed in advance.
Checking impact at observation intervals $\Delta t$ delays detection by up to $\Delta t$.
Event detection (`EventFunction`) in `scioxide-ode` finds event-function zeros on accepted-step dense output, obtaining impact time and speed without shrinking steps to observation times.
Time accuracy depends on event-time tolerance and trajectory error.
This example checks both against the analytical quadratic-drag solution.

## Falling with quadratic drag

Take upward as positive and release the body from rest at height $h(0) = h_0$ [m] with velocity $v(0) = 0$.
With gravitational acceleration $g = 9.81\ \mathrm{m/s^2}$ and quadratic drag coefficient per unit mass $c \ge 0$ [1/m], the equations are

$$
\frac{dh}{dt} = v, \qquad \frac{dv}{dt} = -g - c\,v\,|v|
$$


During descent $v < 0$, so upward drag $-c\,v|v| = c v^2$ slows the fall.
Downward speed $u = -v \ge 0$ satisfies the Riccati-type equation

$$
\frac{du}{dt} = g - c u^2
$$


Using terminal speed $u_\infty = \sqrt{g/c}$ and inverse speed timescale $a = \sqrt{gc}$ [1/s], separation of variables gives

$$
u(t) = \sqrt{\frac{g}{c}}\,\tanh(a t), \qquad s(t) = h_0 - h(t) = \frac{1}{c}\ln\cosh(a t)
$$


Here $s$ is distance fallen.
Impact condition $s(t^*) = h_0$ gives impact time and speed

$$
t^* = \frac{\operatorname{arcosh}\bigl(e^{c h_0}\bigr)}{\sqrt{gc}}, \qquad u(t^*) = \sqrt{\frac{g}{c}}\,\tanh\bigl(\sqrt{gc}\,t^*\bigr)
$$


As $c \to 0$, these approach free-fall $t^* = \sqrt{2h_0/g}$ and $u(t^*) = \sqrt{2gh_0}$.

The following block defines helpers shared by two cells.
The type `FallingBody(c)` is the right-hand side, `Ground` the impact event, and `ground_contact` analytical impact time and speed (free fall at $c = 0$).

```rust
//| id: ode-falling-body-model
//| kind: definitions
//| title: "Quadratic-drag fall and the impact event"
//| crates: [scioxide-core, scioxide-ode]
use scioxide_core::{SciOxideError, SolveContext};
use scioxide_ode::{EventDirection, EventFunction, OdeSystem};

/// Gravitational acceleration g [m/s²].
pub(crate) const GRAVITY: f64 = 9.81;
/// State (h, v). h' = v, v' = −g − c v|v| (quadratic drag per unit mass c [1/m]).
pub(crate) struct FallingBody(pub(crate) f64);
impl OdeSystem<f64> for FallingBody {
    fn dimension(&self) -> usize {
        2
    }
    fn rhs(
        &self,
        _: f64,
        y: &[f64],
        out: &mut [f64],
        _: &mut SolveContext<'_, '_>,
    ) -> Result<(), SciOxideError> {
        out[0] = y[1];
        out[1] = -GRAVITY - self.0 * y[1] * y[1].abs();
        Ok(())
    }
}
/// Impact event g = h. Stop integration on a downward crossing.
pub(crate) struct Ground;
impl EventFunction<f64> for Ground {
    fn eval(&self, _: f64, y: &[f64]) -> Result<f64, SciOxideError> {
        Ok(y[0])
    }
    fn direction(&self) -> EventDirection {
        EventDirection::Falling
    }
    fn is_terminal(&self) -> bool {
        true
    }
}
/// Analytical impact time t* = arcosh(e^{c h₀})/√(gc) and impact speed √(g/c) tanh(√(gc) t*).
/// For c = 0, free-fall √(2h₀/g) and √(2gh₀). References from f64 inherent methods.
pub(crate) fn ground_contact(drag: f64, height: f64) -> (f64, f64) {
    if drag > 0.0 {
        let rate = (GRAVITY * drag).sqrt();
        let time = (drag * height).exp().acosh() / rate;
        (time, (GRAVITY / drag).sqrt() * (rate * time).tanh())
    } else {
        (
            (2.0 * height / GRAVITY).sqrt(),
            (2.0 * GRAVITY * height).sqrt(),
        )
    }
}
```

## Impact detection on dense output

Use event function $g_{\mathrm{ev}}(t, h, v) = h$, stopping on positive-to-negative crossing (`EventDirection::Falling`), with `is_terminal` equal to `true`.
Within a sign-changing accepted step, Alefeld–Potra–Shi enclosure (TOMS 748) contracts a time bracket on Dormand–Prince 5(4) fourth-order dense output, maintaining the sign change.
Supply the stopping width through `OdeEventOptions::with_localization(StepTolerance, iterations)`; absolute and relative defaults are both $4\varepsilon \approx 8.9 \times 10^{-16}$, with 64 iterations.
[Dense output and events](../../algorithms/dense-output-and-events/) explains the mechanism.

The next cell fixes local integration tolerance $10^{-10}$ and varies height, drag coefficient, maximum step, and event-time tolerance for analytical comparison.
The upper plot shows height $h(t)$, the lower downward speed $u(t)$, with linked time axes.
“Final interval width” is the width retained at localization termination by `EventEvidence::Crossing` in event record `EventInfo::evidence()`.
The cell's $h_0$ and $c$ also pass to the next cell.

```rust
//| id: ode-ground-event
//| ref: ode-ground-event
//| title: "Locate quadratic-drag impact on dense output"
//| run: reactive
//| uses: [ode-falling-body-model]
//| crates: [scioxide-core, scioxide-linalg, scioxide-ode]
//| exports: [drop_height, quadratic_drag]
//| inputs:
//|   drop_height: {"type":"range","label":"Initial height h₀ [m]","description":"Vary distance fallen and impact time.","min":5,"max":300,"step":5,"value":100}
//|   quadratic_drag: {"type":"range","label":"Quadratic drag coefficient c [1/m]","description":"Vary terminal speed and departure from free fall. Zero gives free fall.","min":0,"max":0.08,"step":0.001,"value":0.015}
//|   event_maximum_step: {"type":"range","label":"Maximum step [s]","description":"Maximum accepted-step width bracketing the event.","min":0.02,"max":1,"step":0.02,"value":0.3}
//|   localization_exponent: {"type":"range","label":"Exponent q of event-time tolerance 10^q [s]","description":"Interval width stopping TOMS 748 (equal absolute and relative values).","min":-14,"max":-4,"step":1,"value":-8}
//| cases:
//|   - {"id":"free-fall","label":"c = 0","description":"Compare with free-fall √(2h₀/g).","inputs":{"quadratic_drag":0}}
//|   - {"id":"loose-localization","label":"q = −4","description":"Looser localization width can increase time error to that width.","inputs":{"localization_exponent":-4}}
//|   - {"id":"fine-steps","label":"Maximum step 0.02 s","description":"Smaller steps reduce trajectory error.","inputs":{"event_maximum_step":0.02}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"contact","path":"/rows/0/2","approx":{"value":5.684185817716974,"rtol":1e-12}}
//|       - {"artifact":"contact","path":"/rows/0/3","range":{"max":1e-10}}
//|       - {"artifact":"contact","path":"/rows/1/3","range":{"max":1e-8}}
//|       - {"path":"/outputs/3/state","equals":"satisfied"}
//|   - case: free-fall
//|     expect:
//|       - {"artifact":"contact","path":"/rows/0/2","approx":{"value":4.515236409857309,"rtol":1e-12}}
//|       - {"artifact":"contact","path":"/rows/0/3","range":{"max":1e-10}}
//|   - case: loose-localization
//|     expect:
//|       - {"artifact":"contact","path":"/rows/0/3","range":{"max":1e-4}}
//|   - case: fine-steps
//|     expect:
//|       - {"artifact":"contact","path":"/rows/0/3","range":{"max":1e-12}}
use scioxide_core::{
    Budget, ErrorTolerance, EvaluationRole, ExecutionContext, NormSelection, StepTolerance,
};
use scioxide_linalg::Vector;
use scioxide_ode::{
    DormandPrince5, EventEvidence, EventFunction, OdeEventOptions, OdeMethod, OdeOptions,
    OdeOutputSchedule, OdeProblem, OdeState, OdeTrajectory,
};

let (c, h0) = (quadratic_drag, drop_height);
let (t_star, u_star) = ground_contact(c, h0);
let end = 1.5 * t_star;
// Fix local integration tolerance at 10⁻¹⁰; only event-time tolerance changes by input.
let tolerance = ErrorTolerance::scalar(1e-10, 1e-10, NormSelection::RootMeanSquare)
    .map_err(|e| e.to_string())?;
let width = 10.0_f64.powf(localization_exponent);
let localization = StepTolerance::new(width, width).map_err(|e| e.to_string())?;
let iterations = Budget::try_from(200).map_err(|e| e.to_string())?;
let options = OdeOptions::new()
    .with_error_tolerance(tolerance)
    .with_initial_step(event_maximum_step.min(0.05))
    .with_maximum_step(event_maximum_step)
    .with_output_schedule(OdeOutputSchedule::times(
        (0..=300).map(|i| end * f64::from(i) / 300.0).collect(),
    ))
    .with_event_options(OdeEventOptions::new().with_localization(localization, iterations));
let system = FallingBody(c);
let events: &[&dyn EventFunction<f64>] = &[&Ground];
let problem = OdeProblem::new(&system, end).with_events(events);
let method = DormandPrince5::new();
let mut workspace = method
    .workspace(&problem, &options)
    .map_err(|e| e.to_string())?;
let mut state = OdeState::new(0.0, Vector::from_vec(vec![h0, 0.0]));
let mut path = OdeTrajectory::new();
let report = method
    .advance(
        &problem,
        &options,
        &mut state,
        &mut path,
        &mut workspace,
        ExecutionContext::sequential(),
    )
    .map_err(|e| e.to_string())?;
// A terminal event stops output at impact time. Plot component k multiplied by sign.
let curve = |k: usize, sign: f64| -> Vec<[f64; 2]> {
    let states = path.states().iter().map(|y| sign * y.as_slice()[k]);
    path.times()
        .iter()
        .copied()
        .zip(states)
        .map(|(t, y)| [t, y])
        .collect()
};
let (height, speed) = (curve(0, 1.0), curve(1, -1.0));
let contact =
    serde_json::json!({ "kind": "line", "axis": "x", "value": t_star, "label": "t*" });
emit_line_chart!(
    &vec![serde_json::json!({ "name": "h(t)", "points": height })],
    options = &serde_json::json!({
        "link": { "group": "ground-time" },
        "xLabel": "Time t [s]",
        "yLabel": "Height h [m]",
        "yMin": 0.0,
        "annotations": [contact]
    })
);
// With drag, speed approaches terminal √(g/c) (no horizontal line for c = 0).
let terminal: Vec<_> = (c > 0.0)
    .then(|| (GRAVITY / c).sqrt())
    .map(|u| serde_json::json!({ "kind": "line", "axis": "y", "value": u, "label": "√(g/c)" }))
    .into_iter()
    .collect();
emit_line_chart!(
    &vec![serde_json::json!({ "name": "u(t)", "points": speed })],
    options = &serde_json::json!({
        "link": { "group": "ground-time" },
        "xLabel": "Time t [s]",
        "yLabel": "Downward speed u [m/s]",
        "annotations": terminal
    })
);
let event = path.events().first().ok_or("Impact event not found")?;
let (t_hit, y_hit) = (event.time(), event.state());
let bracket = match event.evidence() {
    EventEvidence::Crossing { bracket, .. } | EventEvidence::Contact { bracket, .. } => {
        Some(bracket.width().map_err(|e| e.to_string())?)
    }
    EventEvidence::SampledZero => None,
};
let compare = |name, value: f64, exact: f64| {
    (name, Some(value), Some(exact), Some((value - exact).abs()))
};
let rows = vec![
    compare("Impact time [s]", t_hit, t_star),
    compare("Impact speed [m/s]", -y_hit[1], u_star),
    compare("Height at impact [m]", y_hit[0], 0.0),
    ("Final interval width [s]", bracket, None, None),
];
let digits11 = serde_json::json!({ "significantDigits": 11 });
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let columns = serde_json::json!([
    { "key": "0", "label": "Quantity" },
    { "key": "1", "label": "Event detection", "type": "number", "format": digits11, "nullText": "-" },
    { "key": "2", "label": "Analytical", "type": "number", "format": digits11, "nullText": "-" },
    { "key": "3", "label": "Difference", "type": "number", "format": sci2, "nullText": "-" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "contact" })
);
let termination = report.termination().ok_or("No termination status")?;
let outcome = if termination == scioxide_ode::OdeTermination::TerminalEvent {
    Outcome::satisfied("Stopped at impact time on the terminal event")
} else {
    Outcome::failed("Integration stopped before impact")
};
let counts = report.counts();
let rhs = counts.provider(EvaluationRole::RightHandSide) as f64;
let event_calls = counts.provider(EvaluationRole::Event) as f64;
emit_outcome!(
    outcome
        .status(termination.to_string())
        .diagnostic("Accepted steps", report.accepted_steps() as f64, None)
        .diagnostic("Right-hand-side evaluations", rhs, None)
        .diagnostic("Event-function evaluations", event_calls, None)
);
export!(drop_height, h0);
export!(quadratic_drag, c);
```

With defaults ($h_0 = 100$ m, $c = 0.015$ 1/m, maximum step 0.3 s, event-time tolerance $10^{-8}$ s), impact is detected after 65 accepted steps and 397 right-hand-side evaluations.
Computed impact time differs from analytical 5.6841858177 s by $4.0 \times 10^{-12}$ s, and impact speed differs by $3.5 \times 10^{-10}$ m/s.
Final localization width is $3.3 \times 10^{-8}$ s; returned time lies within it, but its analytical difference is much smaller than that width.
Tightening tolerance to $10^{-14}$ contracts width to $3.4 \times 10^{-14}$ s, yet time difference remains $2.7 \times 10^{-11}$ s.
Here trajectory error, rather than localization, determines time accuracy.
Loosening tolerance to $10^{-4}$ gives width $3.4 \times 10^{-4}$ s and time difference $7.8 \times 10^{-6}$ s, within tolerance.
Maximum step 0.02 s increases accepted steps to 285, reducing time difference to $1.6 \times 10^{-13}$ s.
Maximum step 1 s gives the default result too; default 0.3 s does not constrain tolerance-selected steps.
At $c = 0$, solutions are quadratic in time, making Dormand–Prince 5(4) and fourth-order dense output exact apart from rounding.
Impact-time difference is zero and speed difference $1.4 \times 10^{-14}$ m/s, with errors only from localization and rounding.

## Impact-time delay from observation grids

Without events, outputting only at intervals $\Delta t$ (`OdeOutputSchedule::times`) and treating the first observation with $h \le 0$ as impact gives delay from $0$ inclusive to $\Delta t$ exclusive.
The next cell receives $h_0$ and $c$ from the preceding cell, varying 24 observation intervals and comparing delays against analytical impact time.
The sink is closure `FnMut(t, y)` recording the first time with $h \le 0$; it implements `OdeOutputSink`.

```rust
//| id: ode-ground-sampling-bias
//| ref: ode-ground-sampling-bias
//| title: "Delay when detecting impact on an observation grid"
//| run: reactive
//| uses: [ode-falling-body-model]
//| crates: [scioxide-core, scioxide-linalg, scioxide-ode]
//| dependsOn:
//|   event: ode-ground-event
//| inputs:
//|   maximum_sampling_interval: {"type":"range","label":"Maximum observation interval [s]","description":"Examined range of observation interval Δt (24 choices).","min":0.1,"max":3,"step":0.1,"value":1}
//| cases:
//|   - {"id":"coarse","label":"Maximum interval 3 s","description":"Wider intervals increase delay variation.","inputs":{"maximum_sampling_interval":3}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"sampling","path":"/rows/0/2","range":{"min":0,"max":0.25}}
//|       - {"artifact":"sampling","path":"/rows/3/3","range":{"min":0,"max":1}}
//|   - case: coarse
//|     expect:
//|       - {"artifact":"sampling","path":"/rows/3/3","range":{"min":0,"max":1}}
use scioxide_core::{ErrorTolerance, ExecutionContext, NormSelection};
use scioxide_linalg::Vector;
use scioxide_ode::{
    DormandPrince5, OdeMethod, OdeOptions, OdeOutputSchedule, OdeProblem, OdeState,
};

let h0 = event["drop_height"].as_f64().ok_or("Missing initial height")?;
let c = event["quadratic_drag"].as_f64().ok_or("Missing drag coefficient")?;
let (t_star, _) = ground_contact(c, h0);
let tolerance = ErrorTolerance::scalar(1e-10, 1e-10, NormSelection::RootMeanSquare)
    .map_err(|e| e.to_string())?;
let system = FallingBody(c);
let method = DormandPrince5::new();
let (mut delay, mut rows) = (Vec::new(), Vec::new());
for k in 1..=24 {
    // Observe states only at intervals Δt, without events.
    let dt = maximum_sampling_interval * f64::from(k) / 24.0;
    let n = (1.5 * t_star / dt).ceil() as u32;
    let times: Vec<f64> = (0..=n).map(|i| f64::from(i) * dt).collect();
    let options = OdeOptions::new()
        .with_error_tolerance(tolerance.clone())
        .with_output_schedule(OdeOutputSchedule::times(times));
    let problem = OdeProblem::new(&system, f64::from(n) * dt);
    let mut state = OdeState::new(0.0, Vector::from_vec(vec![h0, 0.0]));
    // Treat the first observed h ≤ 0 as impact.
    let mut sampled = None;
    let mut sink = |t: f64, y: &[f64]| {
        if sampled.is_none() && y[0] <= 0.0 {
            sampled = Some(t);
        }
        Ok::<(), scioxide_core::SciOxideError>(())
    };
    let mut workspace = method
        .workspace(&problem, &options)
        .map_err(|e| e.to_string())?;
    let context = ExecutionContext::sequential();
    let report = method
        .advance(
            &problem,
            &options,
            &mut state,
            &mut sink,
            &mut workspace,
            context,
        )
        .map_err(|e| e.to_string())?;
    if !report.is_success() {
        return Err(format!("Integration stopped early: {:?}", report.termination()));
    }
    let sampled = sampled.ok_or("No impact in observations")?;
    delay.push([dt, sampled - t_star]);
    if k % 6 == 0 {
        rows.push((dt, sampled, sampled - t_star, (sampled - t_star) / dt));
    }
}
// Delay is at least 0 and below Δt. Dashed upper bound Δt.
let bound: Vec<_> = delay.iter().map(|p| [p[0], p[0]]).collect();
let dashed = serde_json::json!({ "lineType": "dashed", "showSymbol": false });
emit_line_chart!(
    &vec![
        serde_json::json!({ "name": "Observation-based impact delay", "points": delay, "kind": "scatter" }),
        serde_json::json!({ "name": "Upper bound Δt", "points": bound, "style": dashed })
    ],
    options = &serde_json::json!({
        "xLabel": "Observation interval Δt [s]",
        "yLabel": "Impact-detection delay [s]",
        "yIncludeZero": true
    })
);
let fixed3 = serde_json::json!({ "fractionDigits": 3 });
let columns = serde_json::json!([
    { "key": "0", "label": "Observation interval Δt [s]", "type": "number", "format": fixed3 },
    { "key": "1", "label": "Observed impact [s]", "type": "number", "format": fixed3 },
    { "key": "2", "label": "Delay [s]", "type": "number", "format": { "fractionDigits": 4 } },
    { "key": "3", "label": "Delay / Δt [-]", "type": "number", "format": fixed3 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "sampling" })
);
```

With defaults, interval $\Delta t = 0.25$ s gives delay 0.066 s.
Every interval from $\Delta t = 0.5$ to 1 s detects impact at the 6.000 s observation, delayed by 0.316 s.
Delay-to-$\Delta t$ ratios vary from 0.26 to 0.63, determined by grid alignment with impact time.
Maximum interval 3 s gives delay 1.07 s at $\Delta t = 2.25$ s.
Reducing observation delay requires finer intervals; event detection returns times at the preceding cell's accuracy independently of observation intervals.

## Summary

Event times come from dense output without observation-interval delays.
Time error follows the larger of the remaining localization width (at most event-time tolerance, default $4\varepsilon$) and trajectory error.
TOMS 748 often contracts much further than tolerance, leaving trajectory error dominant under defaults.
For more accurate impact times, tighten integration tolerances or maximum step sizes.
Loosening tolerance through `OdeEventOptions::with_localization` can increase time error to that width.
Observation-grid delays lie below $\Delta t$ and vary with grid alignment relative to impact time.
