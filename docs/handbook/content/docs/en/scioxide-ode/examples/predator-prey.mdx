Lotka–Volterra is a nonlinear ODE system describing periodic changes in prey and predator populations.
It has a first integral constant along exact trajectories.
This page uses first-integral drift as an error indicator without an analytical solution, examining its relation to `DormandPrince5` tolerances.
Finally, rewrite in logarithmic canonical variables and compare long-term Störmer–Verlet drift.

## Lotka–Volterra equations

Let prey count be $x(t) > 0$, predator count $y(t) > 0$ [individuals], and time $t$ measured in days.
Without carrying-capacity limits, populations follow these coupled equations.

$$
\frac{dx}{dt} = \alpha x - \beta x y = x(\alpha - \beta y), \qquad
\frac{dy}{dt} = \delta x y - \gamma y = y(\delta x - \gamma)
$$

All coefficients are positive, with meanings and units:

- $\alpha$ [1/day]: prey growth rate
- $\beta$ [(individual·day)⁻¹]: prey loss rate from predator encounters
- $\delta$ [(individual·day)⁻¹]: predator increase rate from predation
- $\gamma$ [1/day]: predator mortality rate

Setting both right-hand sides to zero gives the positive equilibrium

$$
x^* = \frac{\gamma}{\delta}, \qquad y^* = \frac{\alpha}{\beta}
$$


Its Jacobian has purely imaginary eigenvalues $\lambda = \pm i\sqrt{\alpha\gamma}$, making the equilibrium a center.
Small oscillations near equilibrium have period $2\pi/\sqrt{\alpha\gamma}$, increasing with amplitude.
Here fix $\alpha = 1.1$ and $\gamma = 0.7$ [1/day], giving small-amplitude period about 7.16 days.

## First integral

Eliminating time from the ratio of $dx/dt$ and $dy/dt$ gives the phase-plane orbit equation

$$
\frac{dy}{dx} = \frac{y(\delta x - \gamma)}{x(\alpha - \beta y)}
$$


Separating variables gives

$$
\left( \frac{\alpha}{y} - \beta \right) dy = \left( \delta - \frac{\gamma}{x} \right) dx
$$

integrating gives the first integral

$$
H(x, y) = \delta x - \gamma \ln x + \beta y - \alpha \ln y
$$


Differentiating along a trajectory gives

$$
\frac{dH}{dt} = \left( \delta - \frac{\gamma}{x} \right) x(\alpha - \beta y) + \left( \beta - \frac{\alpha}{y} \right) y(\delta x - \gamma) = 0
$$

so exact trajectories remain on closed level curves $H(x, y) = H(x_0, y_0)$.
The convex $H$ is minimized at equilibrium, so each level set is one closed curve around it.

Numerical first-integral drift $\Delta H(t) = H(x(t), y(t)) - H(x_0, y_0)$ measures error without an analytical solution.
Even with $\Delta H = 0$, phase error (position along the orbit) can remain.
The quantity $\Delta H$ measures only the error due to an orbit moving onto neighboring level curves.

The following block supplies shared definitions for this page's cells.
The type `LotkaVolterra` provides the right-hand side; `invariant` corresponds to $H$.
The function `solve_dormand_prince` solves $[0, T]$ with `DormandPrince5` at absolute and relative tolerance $\varepsilon$ and maximum step 0.4 days.
Logarithms in $H$ are verification references computed with `f64` standard functions.

```rust
//| id: ode-predator-prey-model
//| kind: definitions
//| title: "Lotka–Volterra right-hand side and first integral"
//| crates: [scioxide-core, scioxide-linalg, scioxide-ode]
use scioxide_core::{Budget, ErrorTolerance, SciOxideError, NormSelection, SolveContext};
use scioxide_linalg::Vector;
use scioxide_ode::{
    DormandPrince5, OdeMethod, OdeOptions, OdeOutputSchedule, OdeProblem, OdeSolveReport,
    OdeState, OdeSystem, OdeTrajectory,
};

/// x′ = x(α − βy), y′ = y(δx − γ). Component order (x, y).
#[derive(Clone, Copy)]
pub(crate) struct LotkaVolterra {
    pub(crate) alpha: f64,
    pub(crate) beta: f64,
    pub(crate) delta: f64,
    pub(crate) gamma: f64,
}

impl LotkaVolterra {
    /// First integral H = δx − γ ln x + βy − α ln y. Reference from f64 standard functions.
    pub(crate) fn invariant(&self, y: &[f64]) -> f64 {
        self.delta * y[0] - self.gamma * y[0].ln() + self.beta * y[1] - self.alpha * y[1].ln()
    }
}

impl OdeSystem<f64> for LotkaVolterra {
    fn dimension(&self) -> usize {
        2
    }

    fn rhs(
        &self,
        _: f64,
        y: &[f64],
        out: &mut [f64],
        _: &mut SolveContext<'_, '_>,
    ) -> Result<(), SciOxideError> {
        out[0] = y[0] * (self.alpha - self.beta * y[1]);
        out[1] = y[1] * (self.delta * y[0] - self.gamma);
        Ok(())
    }
}

/// Solve [0, T] with DormandPrince5, tolerance ε (absolute and relative, RMS norm), maximum step 0.4 days.
pub(crate) fn solve_dormand_prince(
    system: &LotkaVolterra,
    y0: [f64; 2],
    horizon: f64,
    eps: f64,
    schedule: OdeOutputSchedule<f64>,
) -> Result<(OdeTrajectory<f64>, OdeSolveReport<f64>), SciOxideError> {
    let tolerance = ErrorTolerance::scalar(eps, eps, NormSelection::RootMeanSquare)?;
    let options = OdeOptions::new()
        .with_error_tolerance(tolerance)
        .with_maximum_step(0.4)
        .with_max_steps(Budget::try_from(200_000)?)
        .with_output_schedule(schedule);
    let problem = OdeProblem::new(system, horizon);
    let initial = OdeState::new(0.0, Vector::from_vec(y0.to_vec()));
    let solution = DormandPrince5::new()
        .solve(&problem, &options, initial)
        .map_err(SciOxideError::from)?;
    let (_, report, path) = solution.into_parts();
    Ok((path, report))
}
```

## Tolerances and drift

The quantity $\lvert \Delta H \rvert$ accumulates local errors and should decrease as tolerance $\varepsilon$ decreases.
For fifth-order methods with tolerance-limited steps, keeping local error at $\varepsilon$ makes steps proportional to $\varepsilon^{1/5}$ and step counts proportional to $\varepsilon^{-1/5}$.
The next cell receives coefficients and initial values above and solves $[0, T]$ at 17 tolerances $\varepsilon$ from $10^{-3}$ to $10^{-11}$.
The log–log plots show the maximum $\lvert \Delta H \rvert$ over accepted steps and the number of accepted steps.
The horizontal axes $\varepsilon$ of the two plots are linked.

## Canonical logarithmic variables and Störmer–Verlet

General Runge–Kutta such as `DormandPrince5` does not preserve the first integral; at fixed tolerance, $\lvert \Delta H \rvert$ grows roughly linearly with integration duration.
Lotka–Volterra becomes a canonical Hamiltonian system in logarithmic variables $p = \ln x$ and $q = \ln y$.
Expressing $H$ in $p$ and $q$ gives

$$
H(q, p) = T(p) + V(q), \qquad T(p) = \delta e^{p} - \gamma p, \qquad V(q) = \beta e^{q} - \alpha q
$$

with equations of motion

$$
\frac{dq}{dt} = \frac{\partial H}{\partial p} = \delta e^{p} - \gamma = \frac{1}{y}\frac{dy}{dt}, \qquad
\frac{dp}{dt} = -\frac{\partial H}{\partial q} = \alpha - \beta e^{q} = \frac{1}{x}\frac{dx}{dt}
$$

matching the original equations.
The Hamiltonian $H$ separates as $T(p) + V(q)$, allowing explicit Störmer–Verlet.
Störmer–Verlet is second-order and symplectic; fixed step $h$ makes $\lvert \Delta H \rvert$ oscillate over width $O(h^2)$ without growing over long times ([Geometric integration](../../algorithms/geometric-integrators/)).

The next cell receives coefficients and initial values above, solving through $T$ in two ways.
The method `DormandPrince5` uses tolerance $\varepsilon$ and outputs every accepted state.
The method `solve_hamiltonian` accepts $\nabla T(p) = \delta e^{p} - \gamma$ and $\nabla V(q) = \beta e^{q} - \alpha$, advancing one day at a time with Störmer–Verlet step $h$.
The logarithmic plot shows maximum $\lvert \Delta H \rvert$ through time $t$; the table compares steps, evaluations, and terminal $\lvert \Delta H \rvert$.

```rust
let eps = 10.0_f64.powf(long_tolerance_exponent);
let (path, report) = solve_dormand_prince(
    &system,
    y0,
    long_horizon,
    eps,
    OdeOutputSchedule::AcceptedSteps,
)
.map_err(|e| e.to_string())?;
// Subsample to about 400 plotted points (maxima use every step).
let spacing = long_horizon / 400.0;
let (mut running, mut next, mut dp_curve) = (0.0_f64, 0.0, Vec::new());
for (&t, y) in path.times().iter().zip(path.states()) {
    running = running.max((system.invariant(y.as_slice()) - h0).abs());
    if t >= next && running > 0.0 {
        dp_curve.push([t, running]);
        next = t + spacing;
    }
}
let dp_final =
    (system.invariant(path.states().last().ok_or("No output")?.as_slice()) - h0).abs();

// Störmer–Verlet: q = ln y, p = ln x. Call solve_hamiltonian successively for each day.
let per_day = (1.0 / verlet_step).round() as usize;
let step = 1.0 / per_day as f64;
let velocity = |p: &[f64], v: &mut [f64]| {
    v[0] = delta * RealScalar::exp(p[0]) - 0.7;
    Ok(())
};
let gradient = |q: &[f64], g: &mut [f64]| {
    g[0] = beta * RealScalar::exp(q[0]) - 1.1;
    Ok(())
};
let (mut q, mut p) = (RealScalar::ln(y0[1]), RealScalar::ln(y0[0]));
let (mut sv_running, mut sv_curve, mut sv_final) = (0.0_f64, Vec::new(), 0.0_f64);
for day in 1..=days {
    let state = solve_hamiltonian(velocity, gradient, &[q], &[p], step, per_day)
        .map_err(|e| SciOxideError::from(e).to_string())?;
    (q, p) = (state.position()[0], state.momentum()[0]);
    // Check: transform back to (x, y) = (e^p, e^q) and measure H drift (f64 standard functions).
    sv_final = (system.invariant(&[p.exp(), q.exp()]) - h0).abs();
    sv_running = sv_running.max(sv_final);
    if day % (days / 400).max(1) == 0 && sv_running > 0.0 {
        sv_curve.push([day as f64, sv_running]);
    }
}
emit_line_chart!(
    &vec![
        serde_json::json!({ "name": "DormandPrince5", "points": dp_curve }),
        serde_json::json!({ "name": "Störmer–Verlet", "points": sv_curve })
    ],
    options = &serde_json::json!({
        "xLabel": "Time t [days]",
        "yLabel": "Maximum |ΔH| through t [-]",
        "yType": "log"
    })
);
let columns = serde_json::json!([
    { "key": "0", "label": "Method" },
    { "key": "1", "label": "Accepted steps", "type": "integer" },
    { "key": "2", "label": "Evaluations", "type": "integer" },
    { "key": "3", "label": "Maximum |ΔH| [-]", "type": "number", "format": sci2 },
    { "key": "4", "label": "Terminal |ΔH| [-]", "type": "number", "format": sci2 }
]);
// Störmer–Verlet counts ∇T and ∇V once each per step, plus ∇V(q₀) at each call's start.
let rows = vec![
    (
        "DormandPrince5".to_string(),
        report.accepted_steps(),
        report.counts().provider(EvaluationRole::RightHandSide),
        running,
        dp_final,
    ),
    (
        "Störmer–Verlet".to_string(),
        days * per_day,
        days * (2 * per_day + 1),
        sv_running,
        sv_final,
    ),
];
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "long-time" })
);
```

With defaults ($T = 1000$ days, $\varepsilon = 10^{-6}$, $h = 0.02$ days), maximum $\lvert \Delta H \rvert$ for `DormandPrince5` is $2.0 \times 10^{-5}$ and grows approximately linearly with time in the plot.
Störmer–Verlet maximum $\lvert \Delta H \rvert$ is $1.5 \times 10^{-5}$, not increasing beyond its value reached by day 100.
At $T = 100$ days, `DormandPrince5` gives $2.1 \times 10^{-6}$ and Störmer–Verlet $1.5 \times 10^{-5}$, so `DormandPrince5` has less drift over short times.
At $T = 2000$ days, `DormandPrince5` grows to $3.9 \times 10^{-5}$ while Störmer–Verlet remains at $1.5 \times 10^{-5}$.
At $h = 0.01$ days, Störmer–Verlet drift is $3.8 \times 10^{-6}$, matching $O(h^2)$ behavior: halving steps reduces drift to about one-quarter.
Default evaluation counts are 21968 for `DormandPrince5` and 101000 for Störmer–Verlet; `DormandPrince5` needs fewer evaluations for comparable drift over this duration.
Störmer–Verlet's advantage is drift independent of integration duration.

## Summary

Lotka–Volterra first integral $H$ measures part of numerical error without an analytical solution.
For `DormandPrince5`, $\lvert \Delta H \rvert$ decreases roughly with tolerance; where other constraints such as maximum step sizes determine step size, looser tolerances do not change it.
At fixed tolerance, extending integration increases `DormandPrince5` drift with time.
Störmer–Verlet in canonical logarithmic variables keeps drift within a width proportional to $h^2$, without continual long-term growth.
To preserve invariants on long periodic orbits, check whether the system admits a separable Hamiltonian form ([Choosing a method](../../choosing/)).
