Robertson kinetics is a standard stiff ODE test with three concentrations changing over times from 10⁻⁵ s to beyond 10¹⁰ s.
The intermediate concentration stays at most around 10⁻⁵, so the same absolute tolerance as other components cannot control its error.
This page solves the same system with `RosenbrockW`, `Bdf`, and `RadauIia`, comparing componentwise and shared absolute tolerances.
Check solutions against the intermediate's quasi-steady approximation, t = 40 s references, and tighter-tolerance convergence.

## Robertson kinetics

Let concentrations of species A, B, and C be $y_1$, $y_2$, and $y_3$, with three reactions:

$$
\mathrm{A} \xrightarrow{k_1} \mathrm{B}, \qquad
\mathrm{B} + \mathrm{B} \xrightarrow{k_2} \mathrm{C} + \mathrm{B}, \qquad
\mathrm{B} + \mathrm{C} \xrightarrow{k_3} \mathrm{A} + \mathrm{C}
$$

Rate constants are $k_1 = 0.04$ s⁻¹, $k_2 = 3 \times 10^7$, and $k_3 = 10^4$ [concentration⁻¹ s⁻¹].
Mass action gives concentration changes

$$
\begin{aligned}
y_1' &= -k_1 y_1 + k_3 y_2 y_3, \\
y_2' &= k_1 y_1 - k_3 y_2 y_3 - k_2 y_2^2, \\
y_3' &= k_2 y_2^2
\end{aligned}
$$


Initial values are $(y_1, y_2, y_3) = (1, 0, 0)$, with dimensionless concentrations scaled by initial A.
Summing equations gives $(y_1 + y_2 + y_3)' = 0$, preserving the sum at 1.

One eigenvalue of Jacobian

$$
J = \begin{pmatrix}
-k_1 & k_3 y_3 & k_3 y_2 \\
k_1 & -k_3 y_3 - 2 k_2 y_2 & -k_3 y_2 \\
0 & 2 k_2 y_2 & 0
\end{pmatrix}
$$

is zero for conservation; the other two are negative.
The eigenvalue with larger magnitude is of order $k_3 y_3 + 2 k_2 y_2$ in magnitude and reaches about $-10^4$ s⁻¹ late as $y_3$ approaches 1.
The solution changes on a 10¹⁰ s scale, producing timescale ratios up to 10¹⁴.
Explicit steps would be restricted to order $10^{-4}$ s, making explicit integration impractical over this interval.

## Quasi-steady-state approximation

The intermediate $y_2$ forms and is consumed rapidly, tracking near balance between production and consumption.
Setting $y_2' \approx 0$ gives a quadratic in $y_2$,

$$
k_2 y_2^2 + k_3 y_3 y_2 - k_1 y_1 = 0
$$

with positive root

$$
y_2^{\mathrm{qss}} = \frac{-k_3 y_3 + \sqrt{k_3^2 y_3^2 + 4 k_1 k_2 y_1}}{2 k_2}
$$

(the quasi-steady-state approximation).
Substituting numerical $y_1$ and $y_3$ should closely match $y_2$ after the initial transient of about $t < 10^{-2}$ s.
This independently checks $y_2$ alone.

## Componentwise absolute tolerances

Adaptive methods accept componentwise local estimates $e_i$ using

$$
r = \left\lVert \frac{e_i}{\mathrm{atol}_i + \mathrm{rtol} \cdot \max(\lvert y_i \rvert, \lvert \hat y_i \rvert)} \right\rVert \le 1
$$

([Error, order, and stability](../../algorithms/error-order-and-stability/)).
The component $y_2$ peaks around $3.65 \times 10^{-5}$, is about $9.2 \times 10^{-6}$ at t = 40 s, and later falls from $10^{-11}$ to $10^{-13}$.
For $\mathrm{rtol} = 10^{-4}$, $\mathrm{rtol} \cdot \lvert y_2 \rvert$ is at most $10^{-9}$, so setting $\mathrm{atol}_2 = 10^{-6}$ makes denominator $\mathrm{atol}_2$ dominant.
A one-step error of order $10^{-6}$, one-tenth of $y_2(40)$, is therefore accepted.
To reduce only $\mathrm{atol}_2$ to match component magnitude, supply componentwise absolute tolerances to `ErrorTolerance::try_vector`.
Mismatched vector length gives `InvalidInput` during pre-integration validation.

The sum $y_1 + y_2 + y_3 = 1$ is linear, preserved to rounding by Runge–Kutta, Rosenbrock, and BDF provided stage equations are solved.
Even a 30% error in $y_2$ preserves the sum (the $\mathrm{atol}_2 = 10^{-6}$ example below), so conservation does not prove accuracy.

The following block supplies shared definitions for this page's cells.
The type `Robertson` supplies right-hand side and analytical Jacobian, returning zero time derivative for this autonomous system.
The function `quasi_steady` returns $y_2^{\mathrm{qss}}$; `integrate` solves $[0, t_{\mathrm{end}}]$ with supplied method, tolerances, and output times.

```rust
//| id: ode-robertson-model
//| kind: definitions
//| title: "Robertson right-hand side, Jacobian, and quasi-steady approximation"
//| crates: [scioxide-core, scioxide-linalg, scioxide-ode]
use scioxide_core::{Budget, ErrorTolerance, SciOxideError, RealScalar, SolveContext};
use scioxide_linalg::{MatrixViewMut, Vector};
use scioxide_ode::{
    OdeMethod, OdeOptions, OdeOutputSchedule, OdeProblem, OdeSolveReport, OdeState, OdeSystem,
    OdeTrajectory,
};

pub(crate) const K1: f64 = 0.04;
pub(crate) const K2: f64 = 3.0e7;
pub(crate) const K3: f64 = 1.0e4;

/// y₁′ = −k₁y₁ + k₃y₂y₃, y₂′ = k₁y₁ − k₃y₂y₃ − k₂y₂², y₃′ = k₂y₂².
pub(crate) struct Robertson;

impl OdeSystem<f64> for Robertson {
    fn dimension(&self) -> usize {
        3
    }

    fn rhs(
        &self,
        _: f64,
        y: &[f64],
        out: &mut [f64],
        _: &mut SolveContext<'_, '_>,
    ) -> Result<(), SciOxideError> {
        let (r1, r2, r3) = (K1 * y[0], K2 * y[1] * y[1], K3 * y[1] * y[2]);
        out[0] = -r1 + r3;
        out[1] = r1 - r3 - r2;
        out[2] = r2;
        Ok(())
    }

    fn jacobian(
        &self,
        _: f64,
        y: &[f64],
        j: &mut MatrixViewMut<'_, f64>,
        _: &mut SolveContext<'_, '_>,
    ) -> Result<Option<()>, SciOxideError> {
        let rows = [
            [-K1, K3 * y[2], K3 * y[1]],
            [K1, -K3 * y[2] - 2.0 * K2 * y[1], -K3 * y[1]],
            [0.0, 2.0 * K2 * y[1], 0.0],
        ];
        for (r, row) in rows.iter().enumerate() {
            for (c, &value) in row.iter().enumerate() {
                j.set(r, c, value)?;
            }
        }
        Ok(Some(()))
    }

    fn time_derivative(
        &self,
        _: f64,
        _: &[f64],
        out: &mut [f64],
        _: &mut SolveContext<'_, '_>,
    ) -> Result<Option<()>, SciOxideError> {
        out.fill(0.0);
        Ok(Some(()))
    }
}

/// Quasi-steady y₂ = (−k₃y₃ + √(k₃²y₃² + 4k₁k₂y₁)) / (2k₂).
pub(crate) fn quasi_steady(y1: f64, y3: f64) -> f64 {
    let b = K3 * y3;
    (-b + RealScalar::sqrt(b * b + 4.0 * K1 * K2 * y1)) / (2.0 * K2)
}

/// Solve from (1, 0, 0) through end with at most 50000 attempted steps.
pub(crate) fn integrate<M: OdeMethod<f64> + Clone>(
    method: &M,
    tolerance: ErrorTolerance<f64>,
    end: f64,
    schedule: OdeOutputSchedule<f64>,
) -> Result<(OdeTrajectory<f64>, OdeSolveReport<f64>), SciOxideError> {
    let options = OdeOptions::new()
        .with_error_tolerance(tolerance)
        .with_max_steps(Budget::try_from(50_000)?)
        .with_output_schedule(schedule);
    let initial = OdeState::new(0.0, Vector::from_vec(vec![1.0, 0.0, 0.0]));
    let solution = method
        .solve(&OdeProblem::new(&Robertson, end), &options, initial)
        .map_err(SciOxideError::from)?;
    let (_, report, path) = solution.into_parts();
    Ok((path, report))
}
```

## Integration over 15 orders of time

The next cell selects relative tolerance $\mathrm{rtol}$ and absolute tolerance $\mathrm{atol}_2$ for $y_2$, solving through $[0, 4 \times 10^{10}]$ s with three methods.
Absolute tolerances of $y_1$ and $y_3$ stay fixed at $10^{-8}$.
Choosing $\mathrm{atol}_2 = 10^{-8}$ gives the same absolute tolerance for all components.

- `RosenbrockW` (`RosenbrockMethod::Ros34Pw2`): third-order linearly implicit.
- `Bdf` (`MultistepOrder::Automatic(5)`): BDF orders 1–5.
- `RadauIia`: fifth-order L-stable implicit Runge–Kutta.

Output is 61 logarithmically spaced times from $10^{-5}$ s to $4 \times 10^{10}$ s plus t = 40 s, interpolated by dense output between accepted steps.
The table gives statuses, steps, evaluations, t = 40 s values, the number of output points with $y_2 \le 0$, and maximum output-point sum error.
The cell passes concentration time series to the next cell.

```rust
//| id: ode-robertson-solve
//| ref: ode-robertson-solve
//| title: "Solve Robertson kinetics with three methods while varying componentwise absolute tolerances"
//| run: button
//| cache: inputs
//| uses: [ode-robertson-model]
//| crates: [scioxide-core, scioxide-linalg, scioxide-ode]
//| exports: [concentrations, intermediate]
//| inputs:
//|   intermediate_atol_exponent: {"type":"range","label":"Exponent q of y₂ absolute tolerance atol₂ = 10^q","description":"At −8, all three absolute tolerances coincide.","min":-14,"max":-6,"step":1,"value":-14}
//|   relative_exponent: {"type":"range","label":"Exponent p of relative tolerance rtol = 10^p","description":"Relative tolerance shared by all components.","min":-8,"max":-3,"step":1,"value":-4}
//| cases:
//|   - {"id":"uniform-atol","label":"atol₂ = 10⁻⁶","description":"Absolute tolerance hides y₂ error, making RosenbrockW y₂ at t = 40 s about 30% below reference.","inputs":{"intermediate_atol_exponent":-6}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"methods","path":"/rows/2/1","equals":"ReachedEnd"}
//|       - {"artifact":"methods","path":"/rows/2/7","approx":{"value":0.715827,"rtol":1e-4}}
//|       - {"artifact":"methods","path":"/rows/2/8","approx":{"value":9.1855e-6,"rtol":1e-3}}
//|       - {"artifact":"methods","path":"/rows/2/11","range":{"max":1e-12}}
//|       - {"path":"/outputs/1/state","equals":"satisfied"}
use scioxide_core::{ErrorTolerance, EvaluationRole, NormSelection};
use scioxide_ode::{
    Bdf, MultistepOrder, OdeOutputSchedule, OdeTrajectory, RadauIia, RosenbrockMethod,
    RosenbrockW,
};

let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let digits6 = serde_json::json!({ "significantDigits": 6 });
let atol = [1e-8, 10.0_f64.powf(intermediate_atol_exponent), 1e-8];
let rtol = 10.0_f64.powf(relative_exponent);
let tolerance = ErrorTolerance::try_vector(&atol, rtol, NormSelection::RootMeanSquare)
    .map_err(|e| e.to_string())?;
// Output times: 61 logarithmically spaced points from 10⁻⁵ s to 4×10¹⁰ s, plus reference time t = 40 s.
let (first, last) = (1e-5_f64, 4e10_f64);
let mut times: Vec<f64> = (0..60)
    .map(|k| first * (last / first).powf(f64::from(k) / 60.0))
    .collect();
times.push(last);
times.push(40.0);
times.sort_by(f64::total_cmp);
let schedule = OdeOutputSchedule::times(times);
let rosenbrock = RosenbrockW::new(RosenbrockMethod::Ros34Pw2).map_err(|e| e.to_string())?;
let bdf = Bdf::with_order_policy(MultistepOrder::Automatic(5)).map_err(|e| e.to_string())?;
let runs = vec![
    (
        "RosenbrockW",
        integrate(&rosenbrock, tolerance.clone(), last, schedule.clone()),
    ),
    (
        "Bdf",
        integrate(&bdf, tolerance.clone(), last, schedule.clone()),
    ),
    (
        "RadauIia",
        integrate(&RadauIia::new(), tolerance, last, schedule),
    ),
];
let positive = |path: &OdeTrajectory<f64>, k: usize| -> Vec<[f64; 2]> {
    path.times()
        .iter()
        .zip(path.states())
        .map(|(&t, y)| [t, y.as_slice()[k]])
        .filter(|p| p[1] > 0.0)
        .collect()
};
let (mut rows, mut intermediate) = (Vec::new(), Vec::new());
let (mut stopped, mut first_stop) = (Vec::new(), None);
for (name, run) in &runs {
    let (path, report) = run.as_ref().map_err(|e| e.to_string())?;
    let termination = report.termination().ok_or("No termination status")?;
    if !termination.is_success() {
        stopped.push(*name);
        first_stop.get_or_insert(termination.to_string());
    }
    let at40 = path
        .times()
        .iter()
        .position(|&t| t == 40.0)
        .map(|i| path.states()[i].as_slice().to_vec());
    let nonpositive = path
        .states()
        .iter()
        .filter(|y| y.as_slice()[1] <= 0.0)
        .count();
    let sum_error = path
        .states()
        .iter()
        .map(|y| (y.as_slice().iter().sum::<f64>() - 1.0).abs())
        .fold(0.0_f64, f64::max);
    let counts = report.counts();
    rows.push((
        name.to_string(),
        termination.to_string(),
        report.accepted_steps(),
        report.rejected_steps(),
        counts.provider(EvaluationRole::RightHandSide),
        counts.provider(EvaluationRole::Jacobian),
        counts.provider(EvaluationRole::Factorization),
        at40.as_ref().map(|y| y[0]),
        at40.as_ref().map(|y| y[1]),
        at40.as_ref().map(|y| y[2]),
        nonpositive,
        sum_error,
    ));
    intermediate.push(
        serde_json::json!({ "name": format!("y₂（{name}）"), "points": positive(path, 1) }),
    );
}
let (radau, _) = runs[2].1.as_ref().map_err(|e| e.to_string())?;
let reduced: Vec<[f64; 2]> = radau
    .times()
    .iter()
    .zip(radau.states())
    .map(|(&t, y)| [t, quasi_steady(y.as_slice()[0], y.as_slice()[2])])
    .filter(|p| p[1] > 0.0)
    .collect();
intermediate.push(serde_json::json!({
    "name": "Quasi-steady y₂^qss",
    "points": reduced,
    "style": { "lineType": "dashed" }
}));
let concentrations = vec![
    serde_json::json!({ "name": "y₁（RadauIia）", "points": positive(radau, 0) }),
    serde_json::json!({ "name": "y₃（RadauIia）", "points": positive(radau, 2) }),
];
let columns = serde_json::json!([
    { "key": "0", "label": "Method" },
    { "key": "1", "label": "Termination status" },
    { "key": "2", "label": "Accepted steps", "type": "integer" },
    { "key": "3", "label": "Rejected steps", "type": "integer" },
    { "key": "4", "label": "Right-hand-side evaluations", "type": "integer" },
    { "key": "5", "label": "Jacobian evaluations", "type": "integer" },
    { "key": "6", "label": "LU factorizations", "type": "integer" },
    { "key": "7", "label": "y₁(40) [-]", "type": "number", "format": digits6, "nullText": "Not reached" },
    { "key": "8", "label": "y₂(40) [-]", "type": "number", "format": sci3, "nullText": "Not reached" },
    { "key": "9", "label": "y₃(40) [-]", "type": "number", "format": digits6, "nullText": "Not reached" },
    { "key": "10", "label": "Output points with y₂ ≤ 0", "type": "integer" },
    { "key": "11", "label": "max |y₁ + y₂ + y₃ − 1| [-]", "type": "number", "format": sci3 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "methods" })
);
export!(concentrations, concentrations);
export!(intermediate, intermediate);

let outcome = if stopped.is_empty() {
    Outcome::satisfied("All three methods reached 4×10¹⁰ s")
} else {
    Outcome::partial(format!("{} stopped before the endpoint", stopped.join(", ")))
        .explanation("Treat stopped integrators' values as estimates through the last accepted state.")
};
emit_outcome!(outcome.status(first_stop.unwrap_or_else(|| "ReachedEnd".to_string())));
```

With defaults ($\mathrm{atol}_2 = 10^{-14}$, $\mathrm{rtol} = 10^{-4}$), all three reach $4 \times 10^{10}$ s in at most 450 steps.
The method `RadauIia` takes 154 steps (1250 right-hand-side evaluations, 244 LU factorizations), `Bdf` 421, and `RosenbrockW` 434.
Adapting to solution changes spans 15 orders of time in hundreds of steps; accepted `RadauIia` steps span 19 orders from $2.5 \times 10^{-9}$ s to $1.1 \times 10^{10}$ s.
At t = 40 s, $y_2$ is $9.1856 \times 10^{-6}$ for `RadauIia` and $9.1852 \times 10^{-6}$ for `Bdf`, agreeing with references to at least four digits; `RosenbrockW` gives $8.95 \times 10^{-6}$, 2.6% smaller.

For `RosenbrockW`, $y_2$ is nonpositive at 11 of 62 output points.
At accepted-step endpoints, $y_2$ from `RosenbrockW` remains nonnegative, so negative values originate in between-step dense output.
The method `RosenbrockW` uses cubic Hermite interpolation; interpolating $y_2$ across changes of many orders within large steps near $10^{9}$ s overshoots below zero.
The methods `Bdf` and `RadauIia` interpolate history or collocation polynomials, producing no negatives in this example.

At $\mathrm{atol}_2 = 10^{-6}$, $y_2(40)$ from `RosenbrockW` becomes $6.39 \times 10^{-6}$, about 30% below reference, with 14 nonpositive points.
The $y_2(40)$ of `Bdf` is $9.187 \times 10^{-6}$, with relative difference only $2 \times 10^{-4}$.
Every computation has maximum sum error at most $4 \times 10^{-14}$, hiding even the 30% $y_2$ error in conservation checks.
At $\mathrm{rtol} = 10^{-8}$, all three $y_2(40)$ values agree to six digits at $9.18553 \times 10^{-6}$, but `RosenbrockW` needs 3878 steps, about six times `RadauIia` with 683.

## Convergence at t = 40 s

Frequently cited t = 40 s references are $y_1 \approx 0.715827$, $y_2 \approx 9.1855 \times 10^{-6}$, and $y_3 \approx 0.284164$.
Rather than relying on quoted values, check convergence to one value as tolerances tighten.
The next cell varies $\mathrm{rtol}$ over eight choices from $10^{-4}$ to $10^{-11}$, uses absolute tolerances $(\mathrm{atol}_1, \mathrm{atol}_2, \mathrm{atol}_3) = \mathrm{rtol} \cdot (10^{-4}, 10^{-9}, 10^{-4})$, and solves through $[0, 40]$ s with `RadauIia` and `Bdf`.
Use the tightest $\mathrm{rtol} = 10^{-11}$ result from `RadauIia` as reference, plotting relative $y_2(40)$ differences logarithmically.
The table gives $y_1(40)$, $y_2(40)$, relative reference differences, and accepted steps for each computation.

```rust
//| id: ode-robertson-convergence
//| ref: ode-robertson-convergence
//| title: "Tighten tolerances to check t = 40 s convergence"
//| run: button
//| uses: [ode-robertson-model]
//| crates: [scioxide-core, scioxide-linalg, scioxide-ode]
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"convergence","path":"/rows/14/2","approx":{"value":0.7158270687,"rtol":1e-9}}
//|       - {"artifact":"convergence","path":"/rows/14/3","approx":{"value":9.185534765e-6,"rtol":1e-8}}
//|       - {"artifact":"convergence","path":"/rows/12/4","range":{"max":1e-12}}
//|       - {"artifact":"convergence","path":"/rows/15/4","range":{"max":1e-9}}
use scioxide_core::{ErrorTolerance, NormSelection};
use scioxide_ode::{Bdf, MultistepOrder, OdeOutputSchedule, RadauIia};

let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let digits10 = serde_json::json!({ "significantDigits": 10 });
let bdf = Bdf::with_order_policy(MultistepOrder::Automatic(5)).map_err(|e| e.to_string())?;
let radau = RadauIia::new();
let mut runs = Vec::new();
for k in 4..=11 {
    let rtol = 10.0_f64.powi(-k);
    let atol = [rtol * 1e-4, rtol * 1e-9, rtol * 1e-4];
    let tolerance = ErrorTolerance::try_vector(&atol, rtol, NormSelection::RootMeanSquare)
        .map_err(|e| e.to_string())?;
    for (name, run) in [
        (
            "RadauIia",
            integrate(
                &radau,
                tolerance.clone(),
                40.0,
                OdeOutputSchedule::FinalOnly,
            ),
        ),
        (
            "Bdf",
            integrate(&bdf, tolerance, 40.0, OdeOutputSchedule::FinalOnly),
        ),
    ] {
        let (path, report) = run.map_err(|e| e.to_string())?;
        let termination = report.termination().ok_or("No termination status")?;
        if !termination.is_success() {
            return Err(format!(
                "{name} (rtol = {rtol:e}) stopped with {termination}"
            ));
        }
        let y = path
            .states()
            .last()
            .ok_or("No output")?
            .as_slice()
            .to_vec();
        runs.push((name, rtol, y, report.accepted_steps()));
    }
}

    let gap = (y[1] - reference[1]).abs() / reference[1];
    if gap > 0.0 {
        series[usize::from(*name == "Bdf")].push([*rtol, gap]);
    }
    rows.push((
        name.to_string(),
        *rtol,
        y[0],
        y[1],
        (gap > 0.0).then_some(gap),
        *steps,
    ));
}
```

Reference differences cannot measure the reference's own error.
Convergence of two methods toward the same value supports a reference with small numerical error.

## Summary

Robertson component magnitudes differ by five to 13 orders, requiring componentwise absolute tolerances through `ErrorTolerance::try_vector`.
Overly large absolute tolerance for small components hides their errors; $y_2(40)$ from `RosenbrockW` differed by 30%.
Sum $y_1 + y_2 + y_3$ remains conserved to $10^{-14}$ even then, so conservation cannot verify accuracy.
Check $y_2$ time series with quasi-steady estimates, and t = 40 s values with tighter-tolerance `RadauIia` and `Bdf` convergence.
Output-time values are dense interpolants; large steps, such as cubic Hermite in `RosenbrockW`, can give negative concentrations.
Distinguish them from step-end values.
