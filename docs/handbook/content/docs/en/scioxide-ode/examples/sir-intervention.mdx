The SIR model (Susceptible–Infectious–Recovered) is a nonlinear ODE system describing epidemic spread and decline.
With contact-reducing intervention and time-varying contact rates, infectious fraction $I(t)$ peaks when effective reproduction number $\mathcal{R}_e(t)$ falls below 1.
This example locates peak times by dense-output events independently of output grids, checking solutions using total-population conservation $S + I + R = 1$ and the final-size relation.

## SIR model and conservation

In a closed homogeneous population, susceptible fraction $S(t)$, infectious fraction $I(t)$, and recovered or isolated fraction $R(t)$ satisfy

$$
\frac{dS}{dt} = -\beta(t) S I, \qquad \frac{dI}{dt} = \beta(t) S I - \gamma I, \qquad \frac{dR}{dt} = \gamma I
$$


Here $\beta(t)$ is contact rate [1/day], $\gamma$ recovery rate [1/day], and $1/\gamma$ mean infectious duration.
Use $\gamma = 1/7$ here (seven-day infectious period).
The three right-hand sides sum to zero, conserving $S + I + R$ at its initial value 1.

Rewrite $\dot I$ as

$$
\frac{dI}{dt} = \gamma\bigl(\mathcal{R}_e(t) - 1\bigr) I, \qquad \mathcal{R}_e(t) = \frac{\beta(t)}{\gamma}\,S(t)
$$


The quantity $\mathcal{R}_e$ is mean new infections per infectious individual under current conditions (effective reproduction number); $I$ grows while $\mathcal{R}_e > 1$ and decreases while $\mathcal{R}_e < 1$.
Thus $I$ peaks when event function $g(t, S, I, R) = \beta(t) S - \gamma$ crosses positive to negative (`EventDirection::Falling`).
The pre-intervention $\mathcal{R}_0 = \beta_0/\gamma$ is the basic reproduction number.

## Logistic intervention

Represent contact reduction by fraction $r \in [0, 1)$ centered at $t_c$ with a logistic transition width $w$ [day].

$$
L(t) = \frac{1}{1 + e^{-(t - t_c)/w}}, \qquad \beta(t) = \beta_0\bigl[1 - r L(t)\bigr]
$$

Discontinuous contact changes invalidate Runge–Kutta local error estimation there and force extremely small steps.
Smooth changes permit adaptive integration directly.
Since $L$ equals $\tfrac12\bigl[1 + \tanh\bigl((t - t_c)/(2w)\bigr)\bigr]$, use this form to avoid exponential overflow.
If $r \ge 0$, $\beta(t)$ does not increase and $S(t)$ keeps decreasing, making $\mathcal{R}_e(t)$ monotone decreasing.
Thus this model crosses $\mathcal{R}_e$ below 1 only once, with at most one peak.

Without intervention ($r = 0$), integrating $dS/dR = -\mathcal{R}_0 S$ gives the final-size relation for sufficiently late $S_\infty$:

$$
S_\infty = S_0 \exp\bigl(-\mathcal{R}_0 (1 - S_\infty)\bigr)
$$

with $R(0) = 0$ and $I(\infty) = 0$.
Use it as an independent numerical check.

The following block defines helpers shared by two cells.
The type `Sir` supplies the right-hand side and contact rate $\beta(t)$; `Peak` is peak event $g = \beta(t)S - \gamma$.

```rust
//| id: ode-sir-model
//| kind: definitions
//| title: "SIR model with intervention and the peak event"
//| crates: [scioxide-core, scioxide-ode]
use scioxide_core::{SciOxideError, RealScalar, SolveContext};
use scioxide_ode::{EventDirection, EventFunction, OdeSystem};

/// SIR fractions (S, I, R). Contact rate β(t) = β₀[1 − r L(t)], with logistic L.
#[derive(Clone, Copy)]
pub(crate) struct Sir {
    pub(crate) beta0: f64,
    pub(crate) gamma: f64,
    pub(crate) reduction: f64,
    pub(crate) center: f64,
    pub(crate) width: f64,
}
impl Sir {
    /// Compute L(t) = 1/(1 + e^{−(t − tc)/w}) as ½[1 + tanh((t − tc)/(2w))] to avoid exponential overflow.
    pub(crate) fn beta(&self, t: f64) -> f64 {
        let switch = 0.5 * (1.0 + RealScalar::tanh((t - self.center) / (2.0 * self.width)));
        self.beta0 * (1.0 - self.reduction * switch)
    }
}
impl OdeSystem<f64> for Sir {
    fn dimension(&self) -> usize {
        3
    }
    /// S' = −βSI, I' = βSI − γI, R' = γI.
    fn rhs(
        &self,
        t: f64,
        y: &[f64],
        out: &mut [f64],
        _: &mut SolveContext<'_, '_>,
    ) -> Result<(), SciOxideError> {
        let (incidence, removal) = (self.beta(t) * y[0] * y[1], self.gamma * y[1]);
        out.copy_from_slice(&[-incidence, incidence - removal, removal]);
        Ok(())
    }
}
/// Infectious-fraction peak I' = 0, when g = β(t)S − γ crosses positive to negative.
pub(crate) struct Peak(pub(crate) Sir);
impl EventFunction<f64> for Peak {
    fn eval(&self, t: f64, y: &[f64]) -> Result<f64, SciOxideError> {
        Ok(self.0.beta(t) * y[0] - self.0.gamma)
    }
    fn direction(&self) -> EventDirection {
        EventDirection::Falling
    }
    fn is_terminal(&self) -> bool {
        false
    }
}
```

## Intervention and peak events

The next cell varies basic reproduction number $\mathcal{R}_0$, initial infectious fraction $I_0$, intervention center, reduction fraction, and transition width, solving 240 days with `DormandPrince5` (local tolerance $10^{-9}$, maximum step 0.5 days).
States use dense output every 0.5 days; peaks are located separately as events.
The upper plot stacks $S, I, R$, the lower shows $\mathcal{R}_e(t)$, with linked time axes.
The table gives event-based peaks, $\mathcal{R}_e$ at event times, output-grid maximum times, cumulative infected fractions, and population-conservation error.
Parameters pass to the next cell.

```rust
//| id: ode-sir-intervention
//| ref: ode-sir-intervention
//| title: "SIR interventions and infection-peak events"
//| run: reactive
//| uses: [ode-sir-model]
//| crates: [scioxide-core, scioxide-linalg, scioxide-ode]
//| exports: [beta0, gamma, reduction, width, initial_infected]
//| inputs:
//|   sir_basic_reproduction_number: {"type":"range","label":"Basic reproduction number R₀ [-]","description":"Secondary infections per person before intervention.","min":1.1,"max":4,"step":0.1,"value":2.4}
//|   sir_initial_infected_exponent: {"type":"range","label":"Exponent q of initial infectious fraction I₀ = 10^q","description":"Vary epidemic onset timing.","min":-6,"max":-2,"step":0.5,"value":-4}
//|   sir_intervention_day: {"type":"range","label":"Intervention center tc [day]","description":"Stage of epidemic spread at which contact is reduced.","min":5,"max":100,"step":5,"value":35}
//|   sir_contact_reduction: {"type":"range","label":"Contact reduction fraction r [-]","description":"Post-intervention contact rate β₀(1 − r).","min":0,"max":0.9,"step":0.05,"value":0.45}
//|   sir_transition_width: {"type":"range","label":"Transition width w [day]","description":"Timescale of contact-rate change.","min":0.5,"max":12,"step":0.5,"value":3}
//| cases:
//|   - {"id":"no-intervention","label":"r = 0","description":"Without intervention the peak is high and final-size verification applies.","inputs":{"sir_contact_reduction":0}}
//|   - {"id":"fast-spread","label":"R₀ = 4","description":"The peak precedes intervention.","inputs":{"sir_basic_reproduction_number":4}}
//|   - {"id":"late-start","label":"I₀ = 10⁻⁶","description":"Delayed epidemic with a lower post-intervention peak.","inputs":{"sir_initial_infected_exponent":-6}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"peak","path":"/rows/0/0","approx":{"value":44.962,"atol":0.01}}
//|       - {"artifact":"peak","path":"/rows/0/2","approx":{"value":1,"atol":1e-8}}
//|       - {"artifact":"peak","path":"/rows/0/5","range":{"max":1e-13}}
//|       - {"path":"/outputs/3/state","equals":"satisfied"}
//|   - case: no-intervention
//|     expect:
//|       - {"artifact":"peak","path":"/rows/0/4","approx":{"value":0.8786,"atol":1e-3}}
//|   - case: fast-spread
//|     expect:
//|       - {"artifact":"peak","path":"/rows/0/0","range":{"max":30}}
//|   - case: late-start
//|     expect:
//|       - {"artifact":"peak","path":"/rows/0/0","range":{"min":100}}
use scioxide_core::{Budget, ErrorTolerance, ExecutionContext, NormSelection};
use scioxide_linalg::Vector;
use scioxide_ode::{
    DormandPrince5, EventFunction, OdeMethod, OdeOptions, OdeOutputSchedule, OdeProblem,
    OdeState, OdeTrajectory,
};

let gamma = 1.0 / 7.0; // Mean infectious period 7 days
let model = Sir {
    beta0: sir_basic_reproduction_number * gamma,
    gamma,
    reduction: sir_contact_reduction,
    center: sir_intervention_day,
    width: sir_transition_width,
};
let i0 = 10.0_f64.powf(sir_initial_infected_exponent);
let tolerance = ErrorTolerance::scalar(1e-9, 1e-9, NormSelection::RootMeanSquare)
    .map_err(|e| e.to_string())?;
// Output dense values every 0.5 days, locating the peak independently as an event.
let options = OdeOptions::new()
    .with_error_tolerance(tolerance)
    .with_initial_step(0.05)
    .with_maximum_step(0.5)
    .with_max_steps(Budget::try_from(30_000).map_err(|e| e.to_string())?)
    .with_output_schedule(OdeOutputSchedule::times(
        (0..=480).map(|i| f64::from(i) / 2.0).collect(),
    ));
let event = Peak(model);
let events: &[&dyn EventFunction<f64>] = &[&event];
let problem = OdeProblem::new(&model, 240.0).with_events(events);
let method = DormandPrince5::new();
let mut workspace = method
    .workspace(&problem, &options)
    .map_err(|e| e.to_string())?;
let mut state = OdeState::new(0.0, Vector::from_vec(vec![1.0 - i0, i0, 0.0]));
let mut path = OdeTrajectory::new();
let report = method
    .advance(
        &problem,
        &options,
        &mut state,
        &mut path,
        &mut workspace,
        ExecutionContext::sequential(),
    )
    .map_err(|e| e.to_string())?;
let samples = || {
    path.times()
        .iter()
        .zip(path.states())
        .map(|(&t, y)| (t, y.as_slice()))
};
let names = ["Susceptible S", "Infectious I", "Removed R"];
let series: Vec<_> = (0..3)
    .map(|k| {
        let points: Vec<_> = samples().map(|(t, y)| [t, y[k]]).collect();
        serde_json::json!({ "name": names[k], "points": points, "stack": "population" })
    })
    .collect();
// Since S + I + R = 1, the stacked area's upper edge staying at 1 also shows conservation.
emit_area_chart!(
    &series,
    options = &serde_json::json!({
        "link": { "group": "sir-time" },
        "xLabel": "Time t [day]",
        "yLabel": "Population fraction [-]",
        "yMin": 0.0,
        "yMax": 1.0
    })
);
let re: Vec<_> = samples()
    .map(|(t, y)| [t, model.beta(t) * y[0] / gamma])
    .collect();
// Shading marks contact-rate transition [tc − w, tc + w].
let (from, to) = (model.center - model.width, model.center + model.width);
let transition = serde_json::json!({ "kind": "range", "axis": "x", "from": from, "to": to });
let threshold =
    serde_json::json!({ "kind": "line", "axis": "y", "value": 1.0, "label": "Re = 1" });
emit_line_chart!(
    &vec![serde_json::json!({ "name": "Re(t)", "points": re })],
    options = &serde_json::json!({
        "link": { "group": "sir-time" },
        "xLabel": "Time t [day]",
        "yLabel": "Effective reproduction number Re [-]",
        "annotations": [transition, threshold]
    })
);
// Independent checks: population conservation and comparison with output-grid maxima.
let conservation = samples()
    .map(|(_, y)| (y.iter().sum::<f64>() - 1.0).abs())
    .fold(0.0, f64::max);
let sampled = samples()
    .max_by(|a, b| a.1[1].total_cmp(&b.1[1]))
    .ok_or("Empty trajectory")?
    .0;
let peak = path.events().first();
let row = (
    peak.map(|e| e.time()),
    peak.map(|e| 100.0 * e.state()[1]),
    peak.map(|e| model.beta(e.time()) * e.state()[0] / gamma),
    sampled,
    1.0 - state.values()[0],
    conservation,
    report.accepted_steps(),
);
let fixed1 = serde_json::json!({ "fractionDigits": 1 });
let fixed3 = serde_json::json!({ "fractionDigits": 3 });
let fixed4 = serde_json::json!({ "fractionDigits": 4 });
let fixed10 = serde_json::json!({ "fractionDigits": 10 });
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let columns = serde_json::json!([
    { "key": "0", "label": "Peak time [day]", "type": "number", "format": fixed3, "nullText": "None" },
    { "key": "1", "label": "Peak I [%]", "type": "number", "format": fixed3, "nullText": "None" },
    { "key": "2", "label": "Re at event time [-]", "type": "number", "format": fixed10, "nullText": "None" },
    { "key": "3", "label": "Grid-maximum time [day]", "type": "number", "format": fixed1 },
    { "key": "4", "label": "Cumulative infected fraction 1 − S(240) [-]", "type": "number", "format": fixed4 },
    { "key": "5", "label": "max |S + I + R − 1| [-]", "type": "number", "format": sci2 },
    { "key": "6", "label": "Accepted steps [count]", "type": "integer" }
]);
emit_table_with_columns!(
    columns,
    vec![row],
    metadata = serde_json::json!({ "id": "peak" })
);
export!(beta0, model.beta0);
export!(gamma, gamma);
export!(reduction, model.reduction);
export!(width, model.width);
export!(initial_infected, i0);
let termination = report.termination().ok_or("No termination status")?;
let outcome = if report.is_success() {
    Outcome::satisfied("Integrated through 240 days")
} else {
    Outcome::partial("Stopped before 240 days at the step limit")
};
emit_outcome!(outcome.status(termination.to_string()).diagnostic(
    "Conservation error",
    conservation,
    None
));
```

With defaults ($\mathcal{R}_0 = 2.4$, $I_0 = 10^{-4}$, intervention centered at day 35, reduction 45%, transition width three days), the event peak is day 44.962 at infectious fraction 8.828%; event-time $\mathcal{R}_e$ equals 1 to all 10 table digits.
The 0.5-day output grid peaks at day 45.0, with a timing offset caused by grid spacing.
Cumulative infected fraction is 0.5538, with population error $6.7 \times 10^{-16}$ at rounding magnitude.
Runge–Kutta stages preserve linear invariants, so this small error does not establish solution accuracy.
Without intervention ($r = 0$), the peak rises to 21.860% on day 47.645, with cumulative fraction 0.8786.
At $\mathcal{R}_0 = 4$, a 40.17% peak occurs before intervention on day 24.385, with cumulative fraction 0.9693.
At $I_0 = 10^{-6}$, the epidemic is delayed to a low 3.281% peak after intervention on day 141.005.

## Intervention timing, peak, and final size

Intervention effects depend on timing as well as reduction fraction.
The next cell receives $\mathcal{R}_0$, $I_0$, reduction fraction, and width, varying center day $t_c$ from 0 to 120 in five-day steps to measure peak heights and day-240 cumulative infected fractions.
Output only the terminal state (default `OdeOutputSchedule::FinalOnly`), receiving peaks as events.
Horizontal lines show no-intervention values; both plots share the horizontal axis.
The first table row has no intervention, comparing cumulative fraction with the final-size relation solved by fixed-point iteration.

```rust
//| id: ode-sir-intervention-timing
//| ref: ode-sir-intervention-timing
//| title: "Peak and final size versus intervention center day"
//| run: button
//| uses: [ode-sir-model]
//| crates: [scioxide-core, scioxide-linalg, scioxide-ode]
//| dependsOn:
//|   run: ode-sir-intervention
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"timing","path":"/rows/0/3","approx":{"value":0.87861295,"atol":1e-6}}
//|       - {"artifact":"timing","path":"/rows/0/4","approx":{"value":0.87861295,"atol":1e-6}}
//|       - {"artifact":"timing","path":"/rows/1/2","range":{"max":5}}
use scioxide_core::{ErrorTolerance, ExecutionContext, NormSelection};
use scioxide_linalg::Vector;
use scioxide_ode::{
    DormandPrince5, EventFunction, OdeMethod, OdeOptions, OdeProblem, OdeState, OdeTrajectory,
};

let read = |key: &str| run[key].as_f64().ok_or(format!("Missing {key}"));
let (beta0, gamma, i0) = (read("beta0")?, read("gamma")?, read("initial_infected")?);
let (reduction, width) = (read("reduction")?, read("width")?);
let tolerance = ErrorTolerance::scalar(1e-9, 1e-9, NormSelection::RootMeanSquare)
    .map_err(|e| e.to_string())?;
// Output only terminal states, receiving peaks as events.
let options = OdeOptions::new()
    .with_error_tolerance(tolerance)
    .with_initial_step(0.05)
    .with_maximum_step(0.5);
let method = DormandPrince5::new();
// Solve at center day tc and return (peak time, peak I [%], 1 − S(240)).
let simulate =
    |reduction: f64, center: f64| -> Result<(Option<f64>, Option<f64>, f64), String> {
        let model = Sir {
            beta0,
            gamma,
            reduction,
            center,
            width,
        };
        let event = Peak(model);
        let events: &[&dyn EventFunction<f64>] = &[&event];
        let problem = OdeProblem::new(&model, 240.0).with_events(events);
        let mut workspace = method
            .workspace(&problem, &options)
            .map_err(|e| e.to_string())?;
        let mut state = OdeState::new(0.0, Vector::from_vec(vec![1.0 - i0, i0, 0.0]));
        let mut path = OdeTrajectory::new();
        let context = ExecutionContext::sequential();
        let report = method
            .advance(
                &problem,
                &options,
                &mut state,
                &mut path,
                &mut workspace,
                context,
            )
            .map_err(|e| e.to_string())?;
        if !report.is_success() {
            return Err(format!("Integration stopped early: {:?}", report.termination()));
        }
        let peak = path.events().first();
        let size = 1.0 - state.values()[0];
        Ok((
            peak.map(|e| e.time()),
            peak.map(|e| 100.0 * e.state()[1]),
            size,
        ))
    };
// Independent check: without intervention S∞ = S₀ exp(−R₀(1 − S∞)) (final-size relation as t → ∞).
let r0 = beta0 / gamma;
let s_inf = (0..500).fold(0.0, |s, _| (1.0 - i0) * (-r0 * (1.0 - s)).exp());
let (time, height, size) = simulate(0.0, 0.0)?;
let mut rows = vec![(None, time, height, size, Some(1.0 - s_inf))];
let (mut peaks, mut sizes) = (Vec::new(), Vec::new());
for k in 0..=24 {
    let center = 5.0 * f64::from(k);
    let (time, height, size) = simulate(reduction, center)?;
    if let Some(h) = height {
        peaks.push([center, h]);
    }
    sizes.push([center, size]);
    if k % 4 == 0 {
        rows.push((Some(center), time, height, size, None));
    }
}
let none_peak =
    serde_json::json!({ "kind": "line", "axis": "y", "value": height, "label": "No intervention" });
let none_size =
    serde_json::json!({ "kind": "line", "axis": "y", "value": size, "label": "No intervention" });
let symbols = serde_json::json!({ "showSymbol": true });
emit_line_chart!(
    &vec![serde_json::json!({ "name": "Peak I", "points": peaks, "style": symbols })],
    options = &serde_json::json!({
        "link": { "group": "sir-day" },
        "xLabel": "Intervention center tc [day]",
        "yLabel": "Peak infectious fraction [%]",
        "yIncludeZero": true,
        "annotations": [none_peak]
    })
);
emit_line_chart!(
    &vec![serde_json::json!({ "name": "1 − S(240)", "points": sizes, "style": symbols })],
    options = &serde_json::json!({
        "link": { "group": "sir-day" },
        "xLabel": "Intervention center tc [day]",
        "yLabel": "Cumulative infected fraction [-]",
        "yIncludeZero": true,
        "annotations": [none_size]
    })
);
let (fixed3, fixed4) = (
    serde_json::json!({ "fractionDigits": 3 }),
    serde_json::json!({ "fractionDigits": 4 }),
);
let columns = serde_json::json!([
    { "key": "0", "label": "Intervention center tc [day]", "type": "number", "nullText": "No intervention" },
    { "key": "1", "label": "Peak time [day]", "type": "number", "format": fixed3, "nullText": "None" },
    { "key": "2", "label": "Peak I [%]", "type": "number", "format": fixed3, "nullText": "None" },
    { "key": "3", "label": "Cumulative infected fraction 1 − S(240) [-]", "type": "number", "format": fixed4 },
    { "key": "4", "label": "Final-size relation [-]", "type": "number", "format": fixed4, "nullText": "-" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "timing" })
);
```

With default parameters and no intervention, day-240 cumulative fraction 0.87861295 agrees with final-size solution 0.87861295 to difference $8 \times 10^{-10}$ ($I$ is nearly zero by day 240).
Centering intervention at day 0 makes the contact rate approach $\beta_0(1 - r)$ in the first few days, lowering the peak to 3.22% on day 152.2 and cumulative fraction to 0.4312.
A day-40 center gives peak 13.57%; from day 60 onward, peaks precede intervention and remain nearly unchanged from no intervention.
Cumulative fraction still decreases slightly after a post-peak intervention, to 0.837 at day 60.

## Summary

SIR population is conserved to rounding error because Runge–Kutta preserves linear invariants; this does not prove accuracy.
Check accuracy against the no-intervention final-size relation.
Peaks are events where $\mathcal{R}_e$ falls below 1, independent of output grids.
Intervention persists once started, so earlier action reduces peak and final size; post-peak intervention does not change peak height.
Trajectory accuracy determines event-time accuracy; [Impact events for a falling body with air resistance](../ground-event/) explains how to check it.
