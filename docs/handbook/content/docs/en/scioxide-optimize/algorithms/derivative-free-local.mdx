Function values may be computable while stable derivatives are unavailable.
For measurement devices or simulations with branches, value-only local improvement methods are candidates.
Supplying no derivatives does not imply convergence on discontinuous or highly noisy functions.

## Derivative-free local methods

When simulation code is external or high-frequency discretization errors make difference gradients meaningless, search methods evaluating only objective values are needed.
SciOxide's derivative-free local methods are Nelder–Mead (`NelderMead`), updating points by value comparison, and Powell's conjugate-direction method (`Powell`), repeating one-dimensional minimizations along directions.
This page covers Nelder–Mead; Powell is in [Powell's conjugate-direction method](../powell-conjugate-directions/).
`NelderMead` does not handle bounds; passing `BoundedObjective` gives `InvalidInput` (`UnsupportedConfiguration`).
Use `Powell` to search inside a finite box.

Both advance through value comparisons and can handle objectives with nondifferentiable points.
For smooth objectives with many variables and cheap evaluations, gradient methods with numerical differences often use fewer evaluations.

## Nelder–Mead simplex operations

In $n$ dimensions, form a simplex of $n+1$ affinely independent vertices $\{\mathbf{x}_1, \dots, \mathbf{x}_{n+1}\}$.
Sort vertices by increasing objective value,

$$
f(\mathbf{x}_1) \le f(\mathbf{x}_2) \le \dots \le f(\mathbf{x}_{n+1})
$$

identifying best $\mathbf{x}_1$, second-worst $\mathbf{x}_n$, and worst $\mathbf{x}_{n+1}$.
Through centroid $\mathbf{c} = \frac{1}{n}\sum_{i=1}^n \mathbf{x}_i$ excluding the worst point, try replacement candidates in the following order (writing $f_r=f(\mathbf{x}_r)$ and similarly).

1. Evaluate reflection $\mathbf{x}_r=\mathbf{c}+(\mathbf{c}-\mathbf{x}_{n+1})$; if $f_1\le f_r<f_n$, replace with $\mathbf{x}_r$.
2. If $f_r<f_1$, evaluate expansion $\mathbf{x}_e=\mathbf{c}+\gamma(\mathbf{c}-\mathbf{x}_{n+1})$; replace with $\mathbf{x}_e$ if $f_e<f_r$, otherwise $\mathbf{x}_r$.
3. If $f_n\le f_r<f_{n+1}$, evaluate outside contraction $\mathbf{x}_{oc}=\mathbf{c}+\beta(\mathbf{c}-\mathbf{x}_{n+1})$; replace if $f_{oc}\le f_r$.
4. If $f_r\ge f_{n+1}$, evaluate inside contraction $\mathbf{x}_{ic}=\mathbf{c}-\beta(\mathbf{c}-\mathbf{x}_{n+1})$; replace if $f_{ic}<f_{n+1}$.
5. If contraction is rejected, shrink all vertices except the best as $\mathbf{x}_i\leftarrow\mathbf{x}_1+\delta(\mathbf{x}_i-\mathbf{x}_1)$.

Each iteration uses 1 evaluation for reflection alone, 2 if expansion or contraction is tried, and $n$ additional evaluations for shrinkage.
NaN or infinite points rank worse than every finite value, so the simplex contracts or shrinks away from them.
However, the starting value must be finite or error `NonFinite` results.

### Dimension-adaptive coefficients

`NelderMead` uses Gao–Han adaptive coefficients: for $n \ge 2$, expansion $\gamma = 1 + 2/n$, contraction $\beta = 3/4 - 1/(2n)$, shrinkage $\delta = 1 - 1/n$.
At $n = 2$ these match standard coefficients $\gamma=2$ and $\beta=\delta=1/2$; $n = 1$ also uses standard coefficients.
With increasing dimension, $\gamma$ approaches 1, $\beta$ approaches 3/4, and $\delta$ approaches 1, making expansion, contraction, and shrinkage changes smaller.
Gao–Han explained high-dimensional efficiency loss under standard coefficients through expansion and contraction and proposed these dimension-dependent coefficients (Gao–Han, 2012).

### Convergence theory

Nelder–Mead has no general theory guaranteeing convergence to stationary points for arbitrary $n$.
McKinnon gave a two-dimensional strictly convex continuously differentiable example where the simplex shrinks to a nonstationary point.
Independently check returned points through gradients, known solutions, or similar evidence.

## Simplex geometry and stopping

If the matrix with columns $\mathbf{x}_{i+1}-\mathbf{x}_1$ ($i=1,\dots,n$), the edges of an $n$-dimensional simplex, loses rank, unexplored directions remain.
`NelderMead` normalizes each edge by its largest absolute component and assesses numerical rank of column-pivoted QR using `RankThreshold` (default absolute and relative $\sqrt{\varepsilon_{\mathrm{mach}}}$).
`NelderMeadGeometry` describes the last checked geometry: `FullRank` means normalized edges have numerical rank $n$, `Degenerate` means rank loss, and `Incomplete` means no check since simplex creation or modification.

For simplex `Degenerate`, rebuild around the best point (repair, $n$ evaluations).
Repair count is limited by `with_max_repairs` (default 2); reaching it stops with `Stagnation`.
Unless explicit, the initial simplex comprises the start and $n$ points adding 0.05 times coordinate reference scale $s_x$ (default 1) to starting coordinate $i$.
Pass an $(n+1)\times n$ matrix to `NelderMeadOptions::with_initial_simplex` for an explicit initial simplex (its first row must equal the start).

Stopping uses objective spread (largest minus smallest vertex value) and simplex diameter (maximum pairwise $\infty$-norm distance).

$$
\max_i f_i-\min_i f_i\le\tau^f_{\mathrm{abs}}+\tau^f_{\mathrm{rel}}\,s_f,\qquad
\max_{i,j}\|\mathbf{x}_i-\mathbf{x}_j\|_\infty\le\tau^x_{\mathrm{abs}}+\tau^x_{\mathrm{rel}}\,s_x
$$

Only both inequalities plus simplex `FullRank` give `Converged`.
$s_f$ and $s_x$ are objective and coordinate reference scales set by `with_reference_scales` (both default 1); they do not follow current objective or coordinate magnitudes.
Set tolerances with `with_function_tolerance` (`ResidualTolerance`) and `with_step_tolerance` (`StepTolerance`); all default to $\sqrt{\varepsilon_{\mathrm{mach}}}$, giving threshold $2\sqrt{\varepsilon_{\mathrm{mach}}}\approx2.98\times10^{-8}$.
Small objective spread alone does not place a flattened elongated simplex near a minimizer, so inspect diameter and geometry together.

Other terminations are `IterationLimit` at the iteration limit (default 1000), `EvaluationLimit` at the evaluation limit including initial simplex and repair (default 2000, `with_max_evaluations`), and time limits.
These and `Stagnation` return the best vertex so far as an estimate.
`NelderMeadDiagnostics` holds objective spread, diameter and their thresholds, geometry, numerical rank, and repair count.

`NelderMeadOptions` contains immutable settings; `NelderMead::new` checks reference scales and initial simplex.
Prepared `NelderMeadWorkspace` holds simplex and vertex values in $O(n^2)$ memory; after calls, inspect the last simplex with `simplex()` and `values()`.
Check required capacity with `NelderMeadWorkspaceRequirements`.

## Rosenbrock and simplex search

$f(x,y)=100(y-x^2)^2+(1-x)^2$ has a curved narrow valley and analytical minimizer $(1,1)$ with $f=0$.
As a sum of squares, $f\ge0$; $(1,1)$, where both terms vanish, is a global minimizer.
Inputs are starting first coordinate $x$ (second fixed at 1) and coordinate reference scale $s_x$; the objective reference scale stays 1.
$s_x$ changes both initial simplex size $0.05\,s_x$ and diameter threshold $\sqrt{\varepsilon_{\mathrm{mach}}}(1+s_x)$.
The chart shows best value $f_{\mathrm{best}}-f^*$ ($f^*=0$) by evaluation on a logarithmic axis.
Tables show the reached point, analytical-point distance, evaluations, termination, stopping spread and diameter with thresholds, geometry, and repairs.
Finally, show termination as the computation outcome.

```rust

//| ref: optimize-nelder-mead-rosenbrock
//| title: "Interpret Nelder–Mead reached points and evaluation counts"
//| run: reactive
//| crates: [scioxide-core, scioxide-optimize]
//| inputs:
//|   initial: {"type":"range","label":"Starting x [-]","min":-2,"max":2,"step":0.25,"value":-1.25}
//|   coordinate_scale: {"type":"select","label":"Coordinate reference scale sₓ [-]","description":"Change initial simplex size 0.05 sₓ and diameter threshold √ε (1 + sₓ).","options":["0.1","1","10"],"value":"1"}
//| cases:
//|   - {"id":"start-right","label":"Starting x = 2","description":"Enters from outside the valley and stops after 160 evaluations, 1.2×10⁻⁸ from the analytical point.","inputs":{"initial":2}}
//|   - {"id":"start-left","label":"Starting x = −2","description":"Follows the curved valley farther and stops after 235 evaluations.","inputs":{"initial":-2}}
//|   - {"id":"coarse-scale","label":"sₓ = 10","description":"Initial simplex expands to 0.5 and diameter tolerance also loosens by a factor 5.5.","inputs":{"coordinate_scale":"10"}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"summary","path":"/rows/0/2","range":{"min":0,"max":1e-6}}
//|       - {"artifact":"summary","path":"/rows/0/4","range":{"min":180,"max":260}}
//|       - {"artifact":"summary","path":"/rows/0/5","equals":"Converged"}
//|       - {"artifact":"stopping","path":"/rows/0/4","equals":"FullRank"}
//|       - {"artifact":"stopping","path":"/rows/0/3","approx":{"value":2.9802322e-8,"rtol":1e-6}}
//|       - {"path":"/outputs/3/state","equals":"satisfied"}
//|   - case: start-right
//|     expect:
//|       - {"artifact":"summary","path":"/rows/0/2","range":{"min":0,"max":1e-6}}
//|       - {"path":"/outputs/3/state","equals":"satisfied"}
//|   - case: start-left
//|     expect:
//|       - {"artifact":"summary","path":"/rows/0/2","range":{"min":0,"max":1e-6}}
//|       - {"path":"/outputs/3/state","equals":"satisfied"}

//|     expect:
//|       - {"artifact":"stopping","path":"/rows/0/3","approx":{"value":1.6391277e-7,"rtol":1e-6}}

use scioxide_optimize::{NelderMead, NelderMeadOptions, ObjectiveFn, OptimizeDiagnostics};
use std::cell::RefCell;

let scale: f64 = coordinate_scale
    .parse()
    .map_err(|_| "Cannot read reference scale".to_string())?;
// Record evaluated values in order and plot best-value history.
let history = RefCell::new(Vec::new());
let f = ObjectiveFn::new(2, |x: &[f64]| {
    let (valley, offset) = (x[1] - x[0] * x[0], 1.0 - x[0]);
    let value = 100.0 * valley * valley + offset * offset;
    history.borrow_mut().push(value);
    Ok(value)
});
let options = NelderMeadOptions::default().with_reference_scales(scale, 1.0);
let result = NelderMead::new(options)
    .map_err(|e| e.to_string())?
    .minimize(&f, &[initial, 1.0])
    .map_err(|e| e.to_string())?;
let x = result.x();
let OptimizeDiagnostics::NelderMead(diagnostic) = result.method_diagnostics() else {
    return Err("Missing diagnostics for this algorithm".to_string());
};
// Best value f_best − f* (f* = 0). Omit nonpositive values from logarithmic axes and count them.
let mut best = f64::INFINITY;
let mut dropped = 0_usize;
let mut progress = Vec::new();
for (k, &value) in history.borrow().iter().enumerate() {
    best = best.min(value);
    if best > 0.0 {
        progress.push([(k + 1) as f64, best]);
    } else {
        dropped += 1;
    }
}

    options = &serde_json::json!({

        "yLabel": "Best-value/minimum difference [-]",
        "yType": "log"

);

let columns = serde_json::json!([

    { "key": "2", "label": "Distance to analytical point [-]", "type": "number", "format": sci3 },
    { "key": "3", "label": "Objective [-]", "type": "number", "format": sci3 },
    { "key": "4", "label": "Evaluations [count]", "type": "integer" },
    { "key": "5", "label": "Termination reason" },
    { "key": "6", "label": "Points omitted from chart [count]", "type": "integer" }
]);
let termination = result.termination();
emit_table_with_columns!(
    columns,
    vec![(
        x[0],
        x[1],
        distance,
        result.fun(),
        result.fun_evals(),
        termination.to_string(),
        dropped
    )],
    metadata = serde_json::json!({ "id": "summary" })
);
let none = "Not computed";
let stopping_columns = serde_json::json!([
    { "key": "0", "label": "Value spread [-]", "type": "number", "format": sci3, "nullText": none },
    { "key": "1", "label": "Its threshold [-]", "type": "number", "format": sci3, "nullText": none },
    { "key": "2", "label": "Diameter [-]", "type": "number", "format": sci3, "nullText": none },
    { "key": "3", "label": "Its threshold [-]", "type": "number", "format": sci3, "nullText": none },
    { "key": "4", "label": "Geometry" },
    { "key": "5", "label": "Repairs [count]", "type": "integer" }

emit_table_with_columns!(
    stopping_columns,
    vec![(
        diagnostic.objective_spread(),
        diagnostic.function_threshold(),
        diagnostic.diameter(),
        diagnostic.step_threshold(),
        format!("{:?}", diagnostic.geometry()),
        diagnostic.repairs()
    )],
    metadata = serde_json::json!({ "id": "stopping" })

let outcome = if termination.is_success() {
    Outcome::satisfied("Objective spread and simplex diameter are below thresholds, with no simplex rank loss")
} else {
    Outcome::partial("Stopped before meeting stopping criteria")
        .explanation("Treat the returned best vertex as an estimate.")
};
emit_outcome!(
    outcome
        .status(termination.to_string())
        .diagnostic("Objective evaluations", result.fun_evals() as f64, None)
        .diagnostic("Distance to analytical point", distance, None)
);
```

Check the analytical sum-of-squares fact separately from the cell's termination criterion.
At default start $(-1.25,1)$, `Converged` occurs after 221 evaluations, with analytical-point distance $8.3\times10^{-9}$.
Best values fall slowly from 37 to 0.08 during roughly the first 110 evaluations along the curved valley; the next roughly 100 near the minimum fall almost linearly on log axes to order $10^{-16}$.
At termination, objective spread $3.8\times10^{-17}$ and diameter $2.2\times10^{-8}$ are both below threshold $2.98\times10^{-8}$; geometry is `FullRank` and no repairs occurred.
Start $x=2$ uses 160 evaluations and $x=-2$ 235, depending on distance traveled along the valley.
Diameter below threshold does not guarantee a comparable distance to the minimizer.
Here the analytical solution confirms distance $8.3\times10^{-9}$ is comparable to diameter.
At $s_x=10$ the diameter threshold loosens to $1.6\times10^{-7}$; stopping after 202 evaluations gives diameter $9.4\times10^{-8}$ and analytical-point distance $2.5\times10^{-8}$.
Here loosening the threshold also roughly triples the reached-point error.

## Summary

Nelder–Mead moves $n+1$ vertices through reflection, expansion, outside/inside contraction, and shrinkage, replacing the worst point solely by objective comparisons.
`NelderMead` uses dimension-adaptive Gao–Han coefficients, matching standard coefficients at $n=2$.
`Converged` means only that spread and diameter are below reference-scale thresholds with no simplex rank loss; it does not imply a zero gradient.
Thresholds loosen with reference scales $s_f$ and $s_x$; align variable and objective units before choosing scales, then check reached points with known solutions or other methods.
Use Powell for bound-constrained problems or when specifying direction sets.
