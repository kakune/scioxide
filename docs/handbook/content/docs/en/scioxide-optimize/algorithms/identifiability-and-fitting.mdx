A small fitting residual does not necessarily mean that the data uniquely determine each parameter.
This is the problem of identifiability.
For example, observe exponential decay $y(t) = A e^{-k t}$ over $[0,T]$; if $kT \ll 1$, then $A e^{-k t} \approx A - (A k) t$.
The data approximately determine only the intercept $A$ and slope $-Ak$, and information on $k$ appears only in the slope.
If $k$ increases by $\delta k$ and $A$ also increases to keep the midpoint value $Ae^{-kT/2}$ unchanged, the prediction changes by about $Ae^{-kt}\,\delta k\,(T/2-t)$; its magnitude is small in proportion to $T$ and is easily obscured by noise.

In general, if the Jacobian $\mathbf{J}$ of predictions $\mathbf{m}(\boldsymbol\theta)\in\mathbb{R}^m$ with respect to parameters $\boldsymbol\theta\in\mathbb{R}^n$ has a direction $\mathbf{v}$ satisfying $\mathbf{J}\mathbf{v}\approx\mathbf{0}$, moving the parameters in that direction barely changes the predictions.
This is difficulty identifying parameters near the estimate (lack of local identifiability).
This page uses linearization at an estimate obtained by [nonlinear least squares](../nonlinear-least-squares/) to interpret identifiability through singular values, covariance and profile likelihood.
Types for passing estimated parameters to scioxide-stats estimation are covered in [Passing solvers to statistical estimation](../statistical-fitting-solvers/).

## Singular values and covariance

Near the estimate $\hat{\boldsymbol\theta}$, changes in predictions can be approximated by $\delta\mathbf{m}\approx\mathbf{J}\,\delta\boldsymbol\theta$.
With the singular value decomposition $\mathbf{J}=\mathbf{U}\boldsymbol\Sigma\mathbf{V}^\mathsf{T}=\sum_i\sigma_i\mathbf{u}_i\mathbf{v}_i^\mathsf{T}$ ($\sigma_1\ge\dots\ge\sigma_n\ge0$), a unit parameter displacement in the direction of right singular vector $\mathbf{v}_i$ changes predictions by magnitude $\sigma_i$.
Right singular vectors corresponding to small singular values describe weakly observed parameter combinations.
The number of singular values exceeding a threshold $\tau$ is the numerical rank.
If the numerical rank is below $n$, observations do not determine at least one combination (structural non-identifiability within the linearization).
Forming $\mathbf{J}^\mathsf{T}\mathbf{J}$ before measuring the condition number squares it, so diagnose identifiability using singular values of $\mathbf{J}$ itself.
Changing units changes column scales, singular values and condition number $\kappa_2(\mathbf{J})=\sigma_1/\sigma_n$, so specify parameter scales when comparing them.

Assuming independent homoscedastic noise, a correct model, full column rank and a valid local linear approximation, the parameter covariance is approximated by

$$
\widehat{\operatorname{Cov}}(\hat{\boldsymbol\theta}) = s^2(\mathbf{J}^\mathsf{T}\mathbf{J})^{-1} = s^2\,\mathbf{J}^{+}\mathbf{J}^{+\mathsf{T}} = s^2\sum_i\frac{\mathbf{v}_i\mathbf{v}_i^\mathsf{T}}{\sigma_i^2}, \qquad s^2=\frac{\|\mathbf{r}(\hat{\boldsymbol\theta})\|^2}{m-n}
$$

where $\mathbf{J}^{+}$ is the pseudoinverse and $s^2$ is the estimated noise variance.
The standard error of a parameter combination along $\mathbf{v}_i$ is $s/\sigma_i$, so directions with smaller singular values have greater uncertainty.
Each parameter's standard error $\mathrm{SE}(\theta_j)$ is the square root of its diagonal entry, and correlation is the off-diagonal entry divided by the two standard errors.
The closer the absolute correlation is to 1, the harder it is to distinguish the two parameters.
For $n=2$, parameter correlation equals the negative cosine of the angle between the two Jacobian columns (inverting a $2\times2$ matrix reverses the sign of its off-diagonal entries).
If residuals are made dimensionless by dividing by measurement uncertainties $\sigma_i$, one can also check that $s^2\approx1$ when the model and $\sigma_i$ are correct.

This approximation cannot be used directly for boundary solutions, rank deficiency or strong nonlinearity.
In those cases, examine solution uncertainty through profiles, resampling or changes to the observation range.

## Relation to profile likelihood

For normally distributed noise with variance $\sigma^2$, the negative log likelihood is $\Phi(\boldsymbol\theta)/\sigma^2$ plus a constant ($\Phi=\tfrac12\|\mathbf{r}\|^2$).
Using the profile $\Phi_{\mathrm{prof}}(\theta_j)=\min_{\boldsymbol\theta_{-j}}\Phi$ obtained by fixing one parameter $\theta_j$ and optimizing the others, the likelihood ratio statistic

$$
\Lambda(\theta_j) = \frac{2\,(\Phi_{\mathrm{prof}}(\theta_j)-\Phi(\hat{\boldsymbol\theta}))}{s^2}
$$

approximately follows a $\chi^2$ distribution with one degree of freedom at the true $\theta_j$.
The region $\Lambda\le3.84$ (the 95th percentile of $\chi^2_1$) gives an approximate 95% confidence interval.
For a model linear in its parameters, the likelihood ratio statistic follows the parabola $\Lambda=((\theta_j-\hat\theta_j)/\mathrm{SE}(\theta_j))^2$, and this interval equals the Wald interval $\hat\theta_j\pm1.96\,\mathrm{SE}(\theta_j)$.
Disagreement indicates that the linearization is invalid over the interval's width.
If the profile is flat and does not reach $3.84$, observations barely determine that parameter.
The [enzyme reaction example](../../examples/enzyme-identifiability/) compares sensitivities of two parameters as the observation range changes.
The [pharmacokinetics example](../../examples/pharmacokinetics-sampling-design/) uses the one-compartment model $C_0e^{-kt}$ of the same form as the next cell to examine how the observation endpoint affects the width of the profile objective valley.

## Changes in singular values and confidence intervals with the observation interval

Observe exponential decay $y=Ae^{-kt}$ (true values $A=2$ [concentration] and $k=0.35$ h$^{-1}$) at 21 points in $[0,T]$ and add normal noise with standard deviation 0.04 [concentration].
Inputs are the observation endpoint $T$ [h] and the pseudorandom noise seed.
Fit with default `LeastSquares` (LM) settings, decompose the Jacobian at the estimate with `ThinSvdDecomposition`, and obtain singular values, numerical rank, and standard errors and correlation from covariance constructed using the pseudoinverse.
If the fit does not satisfy the success criterion, the cell stops with an error.
Compute the profile of $k$ directly from its formula, using the closed form $A(k)=\sum_i e^{-kt_i}y_i/\sum_i e^{-2kt_i}$ for $A$ when $k$ is fixed.
The plot overlays $\Lambda(k)$ and the parabola from covariance (dashed), with reference lines for the 95th percentile 3.84 of $\chi^2_1$ and the true $k$.
The first table gives singular values, estimates and standard errors; the second gives correlation, $s$, the Wald interval and the profile interval (Λ interval) read from $\Lambda\le3.84$.
If the profile interval reaches an endpoint of grid $[0.05, 0.8]$ for $k$, that end is shown as “outside grid” because the interval extends beyond the grid.

```rust
//| id: optimize-identifiability-svd-profile
//| ref: optimize-identifiability-svd-profile
//| title: "Vary the observation interval and compare singular values, covariance and profile intervals"
//| run: reactive
//| crates: [scioxide-core, scioxide-linalg, scioxide-optimize, scioxide-random]
//| inputs:
//|   observation_end: {"type":"range","label":"Observation endpoint T [h]","description":"Vary the time range over which the decay curve is observed.","min":0.3,"max":8,"step":0.1,"value":3}
//|   seed: {"type":"range","label":"Noise seed [-]","description":"Change the pseudorandom sequence of observation noise.","min":1,"max":50,"step":1,"value":7}
//| cases:
//|   - {"id":"short-window","label":"T = 0.3 h","description":"σ₂ falls to 0.76, SE(k) becomes 0.062 h⁻¹, about six times its value at T = 3 h, and corr(A, k) becomes 0.85. The profile interval widens to [0.19, 0.43] h⁻¹.","inputs":{"observation_end":0.3}}
//|   - {"id":"other-seed","label":"Seed 1","description":"Changing the noise sequence moves the k estimate to 0.363 h⁻¹ and its 95% interval to [0.348, 0.378] h⁻¹, which still contains the true 0.35.","inputs":{"seed":1}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"spectrum","path":"/rows/0/0","approx":{"value":7.936,"atol":1e-3}}
//|       - {"artifact":"spectrum","path":"/rows/0/1","approx":{"value":1.8397,"atol":1e-3}}
//|       - {"artifact":"spectrum","path":"/rows/0/3","equals":2}
//|       - {"artifact":"spectrum","path":"/rows/0/6","approx":{"value":0.34408,"atol":1e-4}}
//|       - {"artifact":"spectrum","path":"/rows/0/7","approx":{"value":0.010148,"atol":1e-5}}
//|       - {"artifact":"intervals","path":"/rows/0/0","approx":{"value":0.767,"atol":1e-3}}
//|       - {"artifact":"intervals","path":"/rows/0/4","approx":{"value":0.3256,"atol":3e-3}}
//|       - {"artifact":"intervals","path":"/rows/0/5","approx":{"value":0.3631,"atol":3e-3}}
//|   - case: short-window
//|     expect:
//|       - {"artifact":"spectrum","path":"/rows/0/1","approx":{"value":0.7586,"atol":1e-3}}
//|       - {"artifact":"spectrum","path":"/rows/0/7","approx":{"value":0.06235,"atol":1e-4}}
//|       - {"artifact":"intervals","path":"/rows/0/0","approx":{"value":0.847,"atol":1e-3}}
//|   - case: other-seed
//|     expect:
//|       - {"artifact":"spectrum","path":"/rows/0/6","approx":{"value":0.36264,"atol":1e-4}}
//|       - {"artifact":"intervals","path":"/rows/0/4","range":{"min":0.34,"max":0.35}}
//|       - {"artifact":"intervals","path":"/rows/0/5","range":{"min":0.37,"max":0.39}}
use scioxide_core::RealScalar;
use scioxide_linalg::{Matrix, RankPolicy, ThinSvdDecomposition};
use scioxide_optimize::{LeastSquares, LeastSquaresFn, LeastSquaresOptions};
use scioxide_random::{Distribution, Normal, SeedableRng, SplitMix64};

let sig4 = serde_json::json!({ "significantDigits": 4 });
let sig5 = serde_json::json!({ "significantDigits": 5 });
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
// Obtain observations y_i = 2 e^{−0.35 t_i} + 0.04 z_i (standard normal z_i, seed supplied as input) at 21 points in [0, T].
let (m, noise) = (21_usize, 0.04_f64);
let times: Vec<f64> = (0..m)
    .map(|i| observation_end * i as f64 / (m - 1) as f64)
    .collect();
let mut rng = SplitMix64::from_seed(seed as u64);
let z = Normal::new(0.0_f64, 1.0)
    .map_err(|e| e.to_string())?
    .sample_n(&mut rng, m)
    .map_err(|e| e.to_string())?;
let data: Vec<f64> = times
    .iter()
    .zip(&z)
    .map(|(&t, &e)| 2.0 * RealScalar::exp(-0.35 * t) + noise * e)
    .collect();
let jacobian_at = |p: &[f64], t: &[f64]| -> Vec<f64> {
    t.iter()
        .flat_map(|&ti| {
            let e = RealScalar::exp(-p[1] * ti);
            [e, -p[0] * ti * e]
        })
        .collect()
};
let (rt, ry, jt) = (times.clone(), data.clone(), times.clone());
let problem = LeastSquaresFn::new::<f64>(2, m, move |p: &[f64], r: &mut [f64]| {
    for ((ri, &t), &y) in r.iter_mut().zip(&rt).zip(&ry) {
        *ri = p[0] * RealScalar::exp(-p[1] * t) - y;
    }
    Ok(())
})
.map_err(|e| e.to_string())?
.with_jacobian(move |p: &[f64], j: &mut Matrix<f64>| {
    j.as_mut_slice().copy_from_slice(&jacobian_at(p, &jt));
    Ok(())
});
let result = LeastSquares::new(LeastSquaresOptions::default())
    .map_err(|e| e.to_string())?
    .solve(&problem, &[1.5, 0.2])
    .map_err(|e| e.to_string())?;
result.require_success().map_err(|e| e.to_string())?;
let fit = result.x().to_vec();
let cost = result.cost().map_err(|e| e.to_string())?;

// Singular values of the Jacobian at the estimate, and covariance s² (JᵀJ)⁻¹ = s² J⁺ J⁺ᵀ (s² = ‖r‖² / (m − 2)).
let j = Matrix::from_vec(m, 2, jacobian_at(&fit, &times)).map_err(|e| e.to_string())?;
let svd = ThinSvdDecomposition::compute(&j).map_err(|e| e.to_string())?;
let sigma = svd.singular_values().to_vec();
let rank = svd
    .analyze_rank(RankPolicy::DimensionScaledEpsilon)
    .map_err(|e| e.to_string())?
    .rank();
let pinv = svd
    .pseudoinverse(RankPolicy::DimensionScaledEpsilon)
    .map_err(|e| e.to_string())?;
let s2 = 2.0 * cost / (m - 2) as f64;
let p = pinv.as_slice();
let cov = |a: usize, b: usize| s2 * (0..m).map(|i| p[a * m + i] * p[b * m + i]).sum::<f64>();
let (se_a, se_k) = (RealScalar::sqrt(cov(0, 0)), RealScalar::sqrt(cov(1, 1)));
let correlation = cov(0, 1) / (se_a * se_k);

// Formula for comparison: profile Φ_prof(k), with k fixed and A eliminated in closed form, and
// likelihood ratio statistic 2(Φ_prof(k) − Φ̂)/s². Linearization gives the parabola ((k − k̂)/SE_k)².
let profile = |k: f64| {
    let w: Vec<f64> = times.iter().map(|&t| RealScalar::exp(-k * t)).collect();
    let a = w.iter().zip(&data).map(|(u, y)| u * y).sum::<f64>()
        / w.iter().map(|u| u * u).sum::<f64>();
    w.iter()
        .zip(&data)
        .map(|(u, y)| 0.5 * (a * u - y) * (a * u - y))
        .sum::<f64>()
};
let grid: Vec<f64> = (0..=400).map(|i| 0.05 + 0.75 * i as f64 / 400.0).collect();
let statistic: Vec<[f64; 2]> = grid
    .iter()
    .map(|&k| [k, 2.0 * (profile(k) - cost) / s2])
    .collect();
let quadratic: Vec<[f64; 2]> = grid
    .iter()
    .map(|&k| [k, ((k - fit[1]) / se_k) * ((k - fit[1]) / se_k)])
    .collect();
// Region at or below the χ²₁ 95th percentile 3.84. Endpoints reaching the grid edge extend beyond the grid, so use None.
let inside: Vec<usize> = (0..grid.len())
    .filter(|&i| statistic[i][1] <= 3.84)
    .collect();
let low = inside.first().filter(|&&i| i > 0).map(|&i| grid[i]);
let high = inside
    .last()
    .filter(|&&i| i + 1 < grid.len())
    .map(|&i| grid[i]);
emit_line_chart!(
    &vec![
        serde_json::json!({"name": "Profile likelihood ratio 2(Φ_prof − Φ̂)/s²", "points": statistic}),
        serde_json::json!({
            "name": "Linearized (covariance) parabola",
            "points": quadratic,
            "style": {"lineType": "dashed"}
        }),
    ],
    options = &serde_json::json!({
        "xLabel": "Fixed decay rate k [1/h]",
        "yLabel": "Likelihood ratio statistic Λ [-]",
        "xMin": 0.05,
        "xMax": 0.8,
        "yMin": 0.0,
        "yMax": 10.0,
        "annotations": [
            {"kind": "line", "axis": "y", "value": 3.84, "label": "95th percentile of χ²₁"},
            {"kind": "line", "axis": "x", "value": 0.35, "label": "True k"}
        ]
    })
);
let spectrum = serde_json::json!([
    { "key": "0", "label": "σ₁ [-]", "type": "number", "format": sig4 },
    { "key": "1", "label": "σ₂ [-]", "type": "number", "format": sig4 },
    { "key": "2", "label": "κ₂(J) [-]", "type": "number", "format": sig4 },
    { "key": "3", "label": "Numerical rank", "type": "integer" },
    { "key": "4", "label": "Estimated A [concentration]", "type": "number", "format": sig5 },
    { "key": "5", "label": "SE(A) [concentration]", "type": "number", "format": sci3 },
    { "key": "6", "label": "Estimated k [1/h]", "type": "number", "format": sig5 },
    { "key": "7", "label": "SE(k) [1/h]", "type": "number", "format": sci3 }
]);
emit_table_with_columns!(
    spectrum,
    vec![(
        sigma[0],
        sigma[1],
        sigma[0] / sigma[1],
        rank,
        fit[0],
        se_a,
        fit[1],
        se_k
    )],
    metadata = serde_json::json!({ "id": "spectrum" })
);
let intervals = serde_json::json!([
    { "key": "0", "label": "Correlation corr(A, k) [-]", "type": "number", "format": sig4 },
    { "key": "1", "label": "s [concentration]", "type": "number", "format": sig4 },
    { "key": "2", "label": "Wald interval lower endpoint [1/h]", "type": "number", "format": sig4 },
    { "key": "3", "label": "Wald interval upper endpoint [1/h]", "type": "number", "format": sig4 },
    { "key": "4", "label": "Λ interval lower endpoint [1/h]", "type": "number", "format": sig4, "nullText": "Outside grid" },
    { "key": "5", "label": "Λ interval upper endpoint [1/h]", "type": "number", "format": sig4, "nullText": "Outside grid" }
]);
emit_table_with_columns!(
    intervals,
    vec![(
        correlation,
        RealScalar::sqrt(s2),
        fit[1] - 1.96 * se_k,
        fit[1] + 1.96 * se_k,
        low,
        high
    )],
    metadata = serde_json::json!({ "id": "intervals" })
);
```

At the default $T=3$ h and seed 7, $\sigma_1=7.94$, $\sigma_2=1.84$, $\kappa_2(\mathbf{J})=4.3$ and numerical rank 2; the estimates are $k=0.3441\pm0.0101\,\mathrm{h^{-1}}$ (estimate ± standard error) and $\mathrm{corr}(A,k)=0.77$.
The value $s=0.049$ is comparable to the added noise standard deviation 0.04.
The Wald interval $[0.324, 0.364]$ and profile interval $[0.326, 0.363]$ nearly coincide, and both contain the true 0.35.
At $T=0.3$ h, $\sigma_2$ falls to 0.76, $\mathrm{SE}(k)=0.062\,\mathrm{h^{-1}}$ is about six times as large, and correlation approaches 0.85.
A short observation interval does not reveal the decay's curvature, so moving $A$ and $k$ together barely changes the predictions.
The Jacobian column correlation $-0.846$ at $T=0.3$ h in the [nonlinear least squares example](oxref:optimize-least-squares-identifiability) and the parameter correlation $0.847$ here differ slightly because observation perturbations differ, but have opposite signs and nearly equal magnitudes.

Changing the seed moves estimates by about their standard errors (seed 1 gives $k=0.363$).
Whether an interval contains the true value is random and varies with the seed; a single seed cannot establish coverage.
To check coverage, reconstruct intervals for many seeds and count the fraction containing the true value.

## Minimum-norm corrections for underdetermined problems

As an extreme case where numerical rank is below the parameter count, minimize one residual $x_1+x_2-a$ over two parameters.
The input is the observed sum $a$, and the initial value is zero.
Because one residual is fewer than two parameters, `LeastSquares` uses an SVD minimum-norm step.
By default, no factorization is retained at a point where the gradient test stops the solve; specify `with_condition_estimation(Estimation::Estimate)` to retain the final linearization's numerical rank in the result.
Infinitely many solutions have sum $a$; independently verify that minimum-norm corrections from zero select $(a/2,a/2)$.
The output table gives the two parameters, sum residual, difference from the minimum-norm solution, numerical rank and its maximum, and termination reason.

```rust
//| id: optimize-underdetermined-minimum-norm
//| ref: optimize-underdetermined-minimum-norm
//| title: "Select a minimum-norm correction for two parameters from one observation"
//| run: reactive
//| crates: [scioxide-optimize, scioxide-linalg]
//| inputs:
//|   target_sum: {"type":"range","label":"Observed sum a [-]","description":"Vary the sum supplied by one observation.","min":1,"max":6,"step":0.5,"value":4}
//| cases:
//|   - {"id":"sum-one","label":"a = 1","description":"The minimum-norm solution moves to (0.5, 0.5), while the numerical rank remains 1.","inputs":{"target_sum":1}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"minimum-norm","path":"/rows/0/0","approx":{"value":2.0,"atol":1e-12}}
//|       - {"artifact":"minimum-norm","path":"/rows/0/1","approx":{"value":2.0,"atol":1e-12}}
//|       - {"artifact":"minimum-norm","path":"/rows/0/3","range":{"min":0,"max":1e-12}}
//|       - {"artifact":"minimum-norm","path":"/rows/0/4","equals":1}
//|       - {"artifact":"minimum-norm","path":"/rows/0/6","equals":"GradientSmall"}
//|   - case: sum-one
//|     expect:
//|       - {"artifact":"minimum-norm","path":"/rows/0/0","approx":{"value":0.5,"atol":1e-12}}
//|       - {"artifact":"minimum-norm","path":"/rows/0/4","equals":1}
use scioxide_linalg::{Estimation, Matrix};
use scioxide_optimize::{
    LeastSquares, LeastSquaresFn, LeastSquaresGlobalization, LeastSquaresOptions,
};

let sig6 = serde_json::json!({ "significantDigits": 6 });
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let a = target_sum;
let problem = LeastSquaresFn::new(2, 1, move |x: &[f64], r: &mut [f64]| {
    r[0] = x[0] + x[1] - a;
    Ok(())
})
.map_err(|e| e.to_string())?
.with_jacobian(|_x: &[f64], j: &mut Matrix<f64>| {
    j.as_mut_slice().copy_from_slice(&[1.0, 1.0]);
    Ok(())
});
// With one residual < two parameters, Gauss–Newton uses an SVD minimum-norm step.
// The default does not retain a factorization at a gradient stop; request condition estimation to retain the numerical rank.
let result = LeastSquares::new(
    LeastSquaresOptions::default()
        .with_globalization(LeastSquaresGlobalization::gauss_newton())
        .with_condition_estimation(Estimation::Estimate),
)
.map_err(|e| e.to_string())?
.solve(&problem, &[0.0, 0.0])
.map_err(|e| e.to_string())?;
let rank = result
    .rank()
    .ok_or("No rank report for the final linearization".to_string())?;
let x = result.x();
// Independent check: among points with sum a, (a/2, a/2) has minimum distance from zero.
let columns = serde_json::json!([
    { "key": "0", "label": "x₁ [-]", "type": "number", "format": sig6 },
    { "key": "1", "label": "x₂ [-]", "type": "number", "format": sig6 },
    { "key": "2", "label": "|x₁ + x₂ − a| [-]", "type": "number", "format": sci2 },
    { "key": "3", "label": "Maximum difference from (a/2, a/2) [-]", "type": "number", "format": sci2 },
    { "key": "4", "label": "Numerical rank", "type": "integer" },
    { "key": "5", "label": "Maximum rank", "type": "integer" },
    { "key": "6", "label": "Termination reason" }
]);
emit_table_with_columns!(
    columns,
    vec![(
        x[0],
        x[1],
        (x[0] + x[1] - a).abs(),
        (x[0] - a / 2.0).abs().max((x[1] - a / 2.0).abs()),
        rank.rank(),
        rank.maximum_rank(),
        result.termination().to_string()
    )],
    metadata = serde_json::json!({ "id": "minimum-norm" })
);
```

At the default $a=4$, the parameters agree with $(2, 2)$ to about $10^{-15}$, and the termination reason is `GradientSmall`.
The Jacobian $[1\ 1]$ has numerical rank 1, below the parameter count 2.
Moving parameters in direction $(1,-1)/\sqrt2$, corresponding to singular value 0, leaves the residual unchanged, so the data do not determine this direction.
The minimum-norm solution is selected by the correction rule from the initial value; the data have not determined both parameters individually.

## Summary

A small residual does not mean individual parameters are determined; check singular values and numerical rank of the Jacobian at the estimate with `ThinSvdDecomposition` or `LeastSquaresResult::rank()` (when `Estimation::Estimate` is specified).
Standard errors and correlation are available from $s^2(\mathbf{J}^\mathsf{T}\mathbf{J})^{-1}$, but they are approximations assuming independent normal noise, a correct model, full column rank and a valid linearization.
Agreement between profile likelihood and Wald intervals supports using linearization; a flat profile or correlation near 1 signals a need to reconsider the observation interval or experimental design.
If numerical rank is below the parameter count, undetermined directions remain even when a minimum-norm solution is returned.
