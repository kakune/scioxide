The four conditions derived in [Nonlinear constraints and KKT conditions](../nonlinear-constraints/) are satisfied only approximately as residuals in numerical computation.
This page explains how SciOxide's constrained solvers define those residuals and which criteria produce `Converged`.
Finally, independently recompute reported residuals and multipliers on a problem with an analytical solution, and verify that multipliers give the sensitivity of the optimal value.

## KKT residuals and termination tests

Derivative-based constrained solvers (`PenaltyMethod`, `AugmentedLagrangian`, `Sqp` and `InteriorPoint`) report the KKT residuals separately in the `OptimalityDiagnostics` returned by `OptimizeResult::diagnostics()`.
The residuals are defined below and are all nonnegative.

| Residual | Accessor | Definition |
|---|---|---|
| Primal feasibility | `primal_feasibility()` | Maximum of $\max_i\lvert c_i\rvert$, $\max_j\max(0,g_j)$ and box violation |
| Stationarity | `stationarity()` | $\lVert\nabla_{\mathbf{x}}\mathcal{L}\rVert_2$ (including bound multiplier terms) |
| Dual feasibility | `dual_feasibility()` | Maximum $\max(0,-\mu_j)$ over inequality and bound multipliers |
| Complementarity | `complementarity()` | $\max_j\lvert\mu_jg_j\rvert$ (same form for bounds) |
| Box violation | `bound_violation()` | Maximum amount by which a variable exceeds its lower or upper bound |

A residual value of `None` means unevaluated, not zero.
The function-value-only methods `Cobyla` and `Cobyqa` do not observe original derivatives, so `stationarity()` is `None`.

To align objective and constraint scales, the four solvers normalize the problem using derivatives at the initial point.
The derivatives are taken at the initial point projected onto the box for `Sqp`, and at the initial point moved into the box interior for `InteriorPoint`.
Divide the objective by $f_s=\max_k\lvert\partial f/\partial x_k(\mathbf{x}_0)\rvert$ and each constraint row by the largest absolute component of its gradient.
A row with zero gradient is divided by its absolute value; if that is also zero, its scale is 1.
For an objective with zero gradient, divide by 1 in `PenaltyMethod` and `AugmentedLagrangian`, and by $\max(1,\lvert f(\mathbf{x}_0)\rvert)$ in `Sqp` and `InteriorPoint`.
Scales are fixed at the initial point and remain unchanged during iteration.

Termination tests use this normalized problem.
Each residual $r$ is compared with threshold $a + b\,s$ formed from absolute tolerance $a$ and relative tolerance $b$.
The reference quantity $s$ is $\max(1,\lVert\mathbf{x}\rVert_\infty)$ for primal feasibility, $\lVert\nabla f\rVert_2 + \sum_i\lvert\lambda_i\rvert\lVert\nabla c_i\rVert_2$ (plus bound multiplier magnitudes) for stationarity, $\lvert f\rvert$ for complementarity, and the largest absolute multiplier for dual feasibility; all are normalized quantities.
The default `OptimalityTolerances` is $a=b=\sqrt{\varepsilon_{\mathrm{mach}}}\approx1.49\times10^{-8}$ for every role ($\varepsilon_{\mathrm{mach}}$ is double-precision machine epsilon).
The solver returns `Converged` only when every residual is at or below its own threshold.

However, residuals returned by `diagnostics()` are converted back to the original units.
Multiply normalized stationarity and complementarity by $f_s$; recompute primal feasibility from original constraint values and dual feasibility from multipliers in original units.
Direct comparison of reported residuals with tolerances can therefore differ by the normalization factor.

Multipliers returned by `SqpState` and `InteriorPointState` are also converted back to original units.
Multiplying a constraint by a constant divides its multiplier by that constant ([Nonlinear constraints and KKT conditions](oxref:optimize-kkt-conditions)); when interpreting physical tension or shadow prices, convert according to your own constraint scaling.

## Experiment on KKT conditions and sensitivity

Find the point on the unit disk closest to $\mathbf{p}=(a,\,0.5)$.

$$
\min_{x,y}\ (x-a)^2+(y-0.5)^2
\quad\text{subject to}\quad
g_1 = x^2+y^2-1-\varepsilon \le 0,\quad
g_2 = y-1 \le 0
$$

If $r=\lVert\mathbf{p}\rVert_2>1$, the solution is $\mathbf{x}^*=\mathbf{p}/r$, the multipliers are $\mu_1^*=r-1$ and $\mu_2^*=0$, and the optimal value is $f^*=(r-1)^2$.
If $r\le1$, $\mathbf{p}$ itself is the solution and both multipliers are zero.
The constraint $g_2$ is included to verify that it is inactive at the solution and complementarity makes its multiplier zero.
Relaxing the constraint by $\varepsilon$ changes the disk radius to $\sqrt{1+\varepsilon}$ and gives $\mathrm{d}f^*/\mathrm{d}\varepsilon=-\mu_1^*$.

The following block defines helpers shared by two cells.
The `solve_disk(a, relax)` function solves the problem with $\varepsilon$ set to `relax` from the origin using `Sqp`, and returns the result and multipliers $(\mu_1,\mu_2)$ at the accepted point.

```rust
//| id: optimize-kkt-disk-model
//| kind: definitions
//| title: "Solve disk projection with Sqp"
//| crates: [scioxide-core, scioxide-optimize]
use scioxide_core::ExecutionContext;
use scioxide_optimize::{
    ConstrainedProblem, ConstraintFn, Constraints, ObjectiveFn, OptimizeResult, Sqp,
};

/// Minimize the squared distance to (a, 0.5) subject to g₁ = x² + y² − 1 − relax ≤ 0 and g₂ = y − 1 ≤ 0.
pub(crate) fn solve_disk(a: f64, relax: f64) -> Result<(OptimizeResult<f64>, Vec<f64>), String> {
    let b = 0.5;
    let objective = ObjectiveFn::new(2, move |x: &[f64]| {
        Ok((x[0] - a) * (x[0] - a) + (x[1] - b) * (x[1] - b))
    })
    .with_gradient(move |x: &[f64], g: &mut [f64]| {
        g.copy_from_slice(&[2.0 * (x[0] - a), 2.0 * (x[1] - b)]);
        Ok(())
    });
    let disk = ConstraintFn::new(2, move |x: &[f64]| {
        Ok(x[0] * x[0] + x[1] * x[1] - 1.0 - relax)
    })
    .with_jacobian(|x: &[f64], row: &mut [f64]| {
        row.copy_from_slice(&[2.0 * x[0], 2.0 * x[1]]);
        Ok(())
    });
    let cap = ConstraintFn::new(2, |x: &[f64]| Ok(x[1] - 1.0)).with_jacobian(
        |_: &[f64], row: &mut [f64]| {
            row.copy_from_slice(&[0.0, 1.0]);
            Ok(())
        },
    );
    let constraints = Constraints::new(2)
        .map_err(|e| e.to_string())?
        .inequality(disk)
        .map_err(|e| e.to_string())?
        .inequality(cap)
        .map_err(|e| e.to_string())?;
    let problem = ConstrainedProblem::new(&objective, &constraints).map_err(|e| e.to_string())?;
    let solver = Sqp::default();
    let mut work = solver.workspace(&problem).map_err(|e| e.to_string())?;
    let mut result = OptimizeResult::empty();
    solver
        .minimize_into(
            &problem,
            &[0.0, 0.0],
            &mut result,
            &mut work,
            ExecutionContext::sequential(),
        )
        .map_err(|e| e.to_string())?;
    Ok((result, work.state().multipliers().to_vec()))
}
```

The first cell solves the $\varepsilon=0$ problem and compares the point and multipliers with their analytical values.
Compare reported residuals with values recomputed from the returned point and multipliers using the definitions in the table above.
The input is component $x$ of the point, $a$; pass $a$ and the computed multiplier $\mu_1$ to the next cell.

```rust
//| id: optimize-kkt-disk-residuals
//| ref: optimize-kkt-disk-residuals
//| title: "Compare disk projection points, multipliers and KKT residuals with analytical values"
//| run: reactive
//| uses: [optimize-kkt-disk-model]
//| crates: [scioxide-core, scioxide-optimize]
//| exports: [target_x, multiplier]
//| inputs:
//|   target_x: {"type":"range","label":"Point x component a [-]","description":"The disk constraint becomes active when (a, 0.5) lies outside the disk.","min":0,"max":3,"step":0.1,"value":2}
//| cases:
//|   - {"id":"inside","label":"a = 0.5 (inside disk)","description":"The point lies inside the disk and both multipliers are zero.","inputs":{"target_x":0.5}}
//|   - {"id":"far","label":"a = 3 (large multiplier)","description":"The disk multiplier is √9.25 − 1 ≈ 2.041.","inputs":{"target_x":3}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"solution","path":"/rows/2/3","range":{"max":1e-8}}
//|       - {"artifact":"solution","path":"/rows/3/1","range":{"min":-1e-8,"max":1e-8}}
//|       - {"artifact":"residuals","path":"/rows/0/2","range":{"max":1e-7}}
//|       - {"path":"/outputs/2/state","equals":"satisfied"}
//|   - case: inside
//|     expect:
//|       - {"artifact":"solution","path":"/rows/0/3","range":{"max":1e-8}}
//|       - {"artifact":"solution","path":"/rows/2/1","range":{"min":-1e-8,"max":1e-8}}
//|       - {"path":"/outputs/2/state","equals":"satisfied"}
//|   - case: far
//|     expect:
//|       - {"artifact":"solution","path":"/rows/2/2","approx":{"value":2.0413812651491097,"rtol":1e-12}}
//|       - {"artifact":"solution","path":"/rows/2/3","range":{"max":1e-8}}
//|       - {"path":"/outputs/2/state","equals":"satisfied"}
use scioxide_core::RealScalar;

let (a, b) = (target_x, 0.5);
let (result, mu) = solve_disk(a, 0.0)?;
let (x, y) = (result.x()[0], result.x()[1]);
// Analytical solution (independent check). For r > 1, project to p/r; the multiplier is r − 1.
let r = RealScalar::sqrt(a * a + b * b);
let shrink = if r > 1.0 { 1.0 / r } else { 1.0 };
let excess = (r - 1.0).max(0.0);
let exact = [a * shrink, b * shrink, excess, 0.0, excess * excess];
let found = [x, y, mu[0], mu[1], result.fun()];
let names = ["x", "y", "Disk multiplier μ₁", "Multiplier μ₂ for y ≤ 1", "Optimal value f*"];
let distance = (x - exact[0]).abs().max((y - exact[1]).abs());
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let fixed10 = serde_json::json!({ "fractionDigits": 10 });
emit_table_with_columns!(
    serde_json::json!([
        { "key": "0", "label": "Quantity" },
        { "key": "1", "label": "Sqp [-]", "type": "number", "format": fixed10 },
        { "key": "2", "label": "Analytical solution [-]", "type": "number", "format": fixed10 },
        { "key": "3", "label": "Difference [-]", "type": "number", "format": sci3 }
    ]),
    (0..5)
        .map(|i| (names[i], found[i], exact[i], (found[i] - exact[i]).abs()))
        .collect::<Vec<_>>(),
    metadata = serde_json::json!({ "id": "solution" })
);
// Recompute all four residuals by definition from the returned point and multipliers (independent check).
let g = [x * x + y * y - 1.0, y - 1.0];
let grad = [
    2.0 * (x - a) + 2.0 * mu[0] * x,
    2.0 * (y - b) + 2.0 * mu[0] * y + mu[1],
];
let recomputed = [
    RealScalar::sqrt(grad[0] * grad[0] + grad[1] * grad[1]),
    g[0].max(g[1]).max(0.0),
    (-mu[0]).max(-mu[1]).max(0.0),
    (mu[0] * g[0]).abs().max((mu[1] * g[1]).abs()),
];
let d = result.diagnostics();
let reported = [
    d.stationarity(),
    d.primal_feasibility(),
    d.dual_feasibility(),
    d.complementarity(),
];
let residuals = ["Stationarity", "Primal feasibility", "Dual feasibility", "Complementarity"];
emit_table_with_columns!(
    serde_json::json!([
        { "key": "0", "label": "Residual" },
        { "key": "1", "label": "Reported value [-]", "type": "number", "format": sci3, "nullText": "None" },
        { "key": "2", "label": "Recomputed from point and multipliers [-]", "type": "number", "format": sci3 }
    ]),
    (0..4)
        .map(|i| (residuals[i], reported[i], recomputed[i]))
        .collect::<Vec<_>>(),
    metadata = serde_json::json!({ "id": "residuals" })
);
export!(target_x, a);
export!(multiplier, mu[0]);
let termination = result.termination();
let outcome = if termination.is_success() {
    Outcome::satisfied("KKT residuals satisfied the tolerances")
} else {
    Outcome::partial("Stopped before satisfying the KKT residual tests")
        .explanation("Treat the returned point and multipliers as the last accepted estimates.")
};
emit_outcome!(
    outcome
        .status(termination.to_string())
        .diagnostic("Iterations", result.iterations() as f64, None)
        .diagnostic("Analytical-solution difference", distance, None)
);
```

At the default $a=2$, `Sqp` reaches `Converged` in four iterations.
The point agrees with the analytical solution $\mathbf{p}/r$ ($r=\sqrt{4.25}$) within $5.2\times10^{-15}$, and disk multiplier $\mu_1=1.0615528128$ agrees with $r-1$ to a difference of $1.6\times10^{-12}$.
The constraint $g_2$ is inactive with value $-0.76$ at the solution; its multiplier is zero, satisfying complementarity.
The four reported residuals match values recomputed from the returned point and multipliers (stationarity $3.2\times10^{-12}$, primal feasibility and complementarity $1.1\times10^{-14}$).
This agreement verifies that reported values use original units.

At $a=0.5$, the point lies inside the disk, stops with $\mathbf{p}$ after one iteration, and both multipliers are zero.
At $a=3$, multiplier 2.0413812651 agrees with $\sqrt{9.25}-1$ to a difference of $1.2\times10^{-14}$, while the point difference is $4.3\times10^{-9}$.
The stationarity residual is then $2.7\times10^{-8}$, within the `Converged` criterion.
Point accuracy is determined by residual thresholds and does not reach the order of machine epsilon.

The next cell solves two problems with the disk constraint shifted by $\varepsilon=\pm h$ and compares the central difference $\{f^*(h)-f^*(-h)\}/(2h)$ of optimal values with $-\mu_1$ from the previous cell.
Central difference truncation error is $O(h^2)$, while optimal-value error $\delta$ is amplified to $\delta/h$ in the difference.
The only input is difference width $h=10^{q}$; point $a$ and the multiplier come from the previous cell.

```rust
//| id: optimize-kkt-disk-sensitivity
//| ref: optimize-kkt-disk-sensitivity
//| title: "Compare differences in optimal values under constraint relaxation with the multiplier"
//| run: reactive
//| uses: [optimize-kkt-disk-model]
//| crates: [scioxide-core, scioxide-optimize]
//| dependsOn:
//|   base: optimize-kkt-disk-residuals
//| inputs:
//|   step_exponent: {"type":"range","label":"Difference width exponent q (h = 10^q) [-]","min":-7,"max":-1,"step":1,"value":-3}
//| cases:
//|   - {"id":"narrow-step","label":"h = 10⁻⁷","description":"The discrepancy is comparable to optimal-value rounding error amplified by 1/h.","inputs":{"step_exponent":-7}}
//|   - {"id":"wide-step","label":"h = 10⁻¹","description":"Widening the difference step makes O(h²) truncation error apparent.","inputs":{"step_exponent":-1}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"sensitivity","path":"/rows/0/5","range":{"max":1e-5}}
//|       - {"artifact":"sensitivity","path":"/rows/0/6","equals":"Converged / Converged"}
//|   - case: narrow-step
//|     expect:
//|       - {"artifact":"sensitivity","path":"/rows/0/5","range":{"max":1e-8}}
//|   - case: wide-step
//|     expect:
//|       - {"artifact":"sensitivity","path":"/rows/0/5","range":{"min":1e-5,"max":1e-2}}
use scioxide_core::RealScalar;

let a = base["target_x"].as_f64().ok_or("Missing point x component")?;
let multiplier = base["multiplier"].as_f64().ok_or("Missing multiplier")?;
let h = RealScalar::powf(10.0, step_exponent);
let (plus, _) = solve_disk(a, h)?;
let (minus, _) = solve_disk(a, -h)?;
let slope = (plus.fun() - minus.fun()) / (2.0 * h);
let status = format!("{} / {}", plus.termination(), minus.termination());
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let fixed10 = serde_json::json!({ "fractionDigits": 10 });
emit_table_with_columns!(
    serde_json::json!([
        { "key": "0", "label": "h [-]", "type": "number", "format": sci3 },
        { "key": "1", "label": "f*(h) [-]", "type": "number", "format": fixed10 },
        { "key": "2", "label": "f*(−h) [-]", "type": "number", "format": fixed10 },
        { "key": "3", "label": "Central difference [-]", "type": "number", "format": fixed10 },
        { "key": "4", "label": "−μ₁ [-]", "type": "number", "format": fixed10 },
        { "key": "5", "label": "Difference [-]", "type": "number", "format": sci3 },
        { "key": "6", "label": "Termination reason (+h / −h)" }
    ]),
    vec![(
        h,
        plus.fun(),
        minus.fun(),
        slope,
        -multiplier,
        (slope + multiplier).abs(),
        status
    )],
    metadata = serde_json::json!({ "id": "sensitivity" })
);
```

At the default $h=10^{-3}$, central difference $-1.0615530705$ agrees with $-\mu_1$ to a difference of $2.6\times10^{-7}$.
This discrepancy comes from central difference truncation error $O(h^2)$; it grows to $2.6\times10^{-3}$ at $h=10^{-1}$, increasing by $10^4$ when $h$ increases 100-fold.
At $h=10^{-7}$, the difference decreases to $4.9\times10^{-10}$.
The truncation error is then about $2.6\times10^{-15}$ by extrapolation from the discrepancy at $h=10^{-3}$; the expected discrepancy is roughly $1.3\times10^{-9}$, obtained by amplifying optimal-value rounding error $\varepsilon_{\mathrm{mach}}\lvert f^*\rvert\approx2.5\times10^{-16}$ by $1/(2h)$.
The solver multiplier and the difference in optimal values from separately solving perturbed constraints are independent quantities; their agreement numerically demonstrates that the multiplier is an optimal-value sensitivity.

## Summary

The `OptimizeResult::diagnostics()` report returns stationarity, primal feasibility, dual feasibility, complementarity and box violation in original units; `None` means unevaluated.
The `Converged` test compares residuals with thresholds of the form $a+b\,s$ on a problem normalized by initial derivatives, so account for normalization factors when comparing reported values with tolerances.
With the returned point and multipliers, residuals can be recomputed from their definitions for checking.
Check multipliers as sensitivities against differences in optimal values under relaxed constraints, choosing difference width to balance truncation and rounding errors.
Residual thresholds determine point accuracy, so also check an analytical solution or another method.
