In box-constrained minimization, the components lying on bounds at the optimum (the active set) are unknown in advance.
Classical L-BFGS-B (Byrd–Lu–Nocedal–Zhu, hereafter BLNZ) estimates the active set by following the piecewise linear projected gradient path on a quadratic model, then minimizes the model over the remaining components.
SciOxide's `LbfgsB` does not have these two stages; it uses the projected direction described in [One projected L-BFGS iteration](oxref:optimize-lbfgsb-iteration).
This page derives the two classical stages, tabulates differences from `LbfgsB`, and uses an obstacle problem to examine changes in active bounds during iteration.
Notation follows [Box constraints and projected L-BFGS](../bound-constrained-lbfgsb/): $\mathbf{B}_k$ denotes the L-BFGS Hessian approximation and $P_{[\mathbf{l},\mathbf{u}]}$ denotes projection onto the box.

## Generalized Cauchy point

BLNZ L-BFGS-B uses the quadratic model around the current point $\mathbf{x}_k$:

$$
m_k(\mathbf{x})=f_k+\mathbf{g}_k^\mathsf{T}(\mathbf{x}-\mathbf{x}_k)+\tfrac12(\mathbf{x}-\mathbf{x}_k)^\mathsf{T}\mathbf{B}_k(\mathbf{x}-\mathbf{x}_k)
$$

where $\mathbf{B}_k$ is positive definite.
The first stage seeks the first local minimum of $m_k$ along the projected steepest descent path $\mathbf{x}(t)=P_{[\mathbf{l},\mathbf{u}]}(\mathbf{x}_k-t\mathbf{g}_k)$ ($t\ge0$).
The time at which component $i$ reaches a bound (its breakpoint) is

$$
t_i=\begin{cases}(x_i-u_i)/g_i & (g_i<0)\\ (x_i-l_i)/g_i & (g_i>0)\\ \infty & (g_i=0)\end{cases}
$$

and, after sorting breakpoints in ascending order, the path is linear between adjacent breakpoints.
On interval $[t_{j-1},t_j]$, only components that have not reached bounds move in direction $-g_i$.
Denote this direction by $\mathbf{d}^{(j)}$, the interval's initial point by $\mathbf{x}^{(j)}$, and $\mathbf{z}^{(j)}=\mathbf{x}^{(j)}-\mathbf{x}_k$; the model on the interval is the following univariate quadratic in $\Delta t=t-t_{j-1}$:

$$
m_k(\mathbf{x}^{(j)}+\Delta t\,\mathbf{d}^{(j)}) = m_k(\mathbf{x}^{(j)}) + f'_j\,\Delta t + \tfrac12 f''_j\,\Delta t^2,\qquad
f'_j=\mathbf{g}_k^\mathsf{T}\mathbf{d}^{(j)}+\mathbf{d}^{(j)\mathsf{T}}\mathbf{B}_k\mathbf{z}^{(j)},\quad f''_j=\mathbf{d}^{(j)\mathsf{T}}\mathbf{B}_k\mathbf{d}^{(j)}
$$


If $f'_j\ge0$, the interval's initial point is a local minimum; otherwise, stop inside the interval if $\Delta t^*=-f'_j/f''_j$ is shorter than the interval length $t_j-t_{j-1}$.
If neither applies, continue to the next interval.
The resulting point is the generalized Cauchy point $\mathbf{x}^{\mathrm{c}}$; components at bounds in $\mathbf{x}^{\mathrm{c}}$ form the active set $\mathcal{A}$.
Using the compact representation of $\mathbf{B}_k$ allows $f'_j$ and $f''_j$ to be updated as intervals advance without forming $\mathbf{B}_k$ (BLNZ 1995, Section 4).

The generalized Cauchy point advances a projected gradient step to the first local minimum of the model along its path.
For projected gradient methods and trust-region methods using a generalized Cauchy point, results establish finite identification of the optimal active set under strict complementarity at the optimum (positive multipliers for components on bounds) (Calamai–Moré 1987, Conn–Gould–Toint 1988).
Classical L-BFGS-B assigns active set estimation to this point.

## Subspace minimization

The next stage fixes components $\mathcal{A}$ at their $\mathbf{x}^{\mathrm{c}}$ values and minimizes $m_k$ over the remaining free components $\mathcal{F}$.
With $\mathbf{Z}$ the matrix selecting free components, the reduced model in $\hat{\mathbf{d}}\in\mathbb{R}^{|\mathcal{F}|}$ is

$$
\hat m(\hat{\mathbf{d}})=\hat{\mathbf{r}}^\mathsf{T}\hat{\mathbf{d}}+\tfrac12\hat{\mathbf{d}}^\mathsf{T}\hat{\mathbf{B}}\hat{\mathbf{d}},\qquad
\hat{\mathbf{r}}=\mathbf{Z}^\mathsf{T}\bigl(\mathbf{g}_k+\mathbf{B}_k(\mathbf{x}^{\mathrm{c}}-\mathbf{x}_k)\bigr),\quad
\hat{\mathbf{B}}=\mathbf{Z}^\mathsf{T}\mathbf{B}_k\mathbf{Z}
$$

and its unconstrained minimizer is $\hat{\mathbf{d}}^{\mathrm{u}}=-\hat{\mathbf{B}}^{-1}\hat{\mathbf{r}}$.
Compute $\hat{\mathbf{B}}^{-1}$ by applying the Sherman–Morrison–Woodbury formula to the compact representation; the cost comprises terms proportional to $|\mathcal{F}|$ and factorization of a small matrix whose size depends only on $m$.
If the resulting point $\mathbf{x}^{\mathrm{c}}+\mathbf{Z}\hat{\mathbf{d}}^{\mathrm{u}}$ lies outside the box, shorten the step until it lies inside.
The search direction is the difference between this point and $\mathbf{x}_k$, and a line search chooses a step satisfying the strong Wolfe conditions.
Stop when the projected gradient $\|P_{[\mathbf{l},\mathbf{u}]}(\mathbf{x}-\mathbf{g})-\mathbf{x}\|_\infty$ is at or below `pgtol` or the relative objective decrease $(f_k-f_{k+1})/\max(|f_k|,|f_{k+1}|,1)$ is at or below `factr`$\cdot\varepsilon_{\mathrm{mach}}$.

## Differences from classical L-BFGS-B

The `LbfgsB` method and classical L-BFGS-B solve the same box-constrained problem by the following different procedures.

| Aspect | Classical L-BFGS-B | `LbfgsB` |
|---|---|---|
| Active set | Components at bounds at the generalized Cauchy point | Components at bounds at the current point whose gradient points outward |
| Search direction | Toward the model minimizer in the free-component subspace | Remove outward components from $-\mathbf{P}_F\mathbf{H}_k\mathbf{P}_F\mathbf{g}_k$ and project the unit-step endpoint |
| Step | Strong Wolfe line search | Armijo backtracking along the projected segment |
| Pairs with insufficient curvature | Skip update | Powell damping (default $\eta=0.2$) |
| Stopping | Projected gradient or relative objective decrease | Projected gradient only |
| Interior components of projected gradient | $\min(\lvert g_i\rvert,\text{distance})$ clipped by distance to the bound | Unmodified $\lvert g_i\rvert$ |

The last row shows that, for the same tolerance, the `LbfgsB` stopping test is at least as strict as the classical test componentwise.
For interior components, the classical quantity $|x_i-P(x_i-g_i)|$ does not exceed $|g_i|$; for bound components, both become zero under the same sign condition.

Because `LbfgsB` has no generalized Cauchy point, the active set identification results above and classical convergence analysis do not apply directly.
The properties holding for `LbfgsB` are that search directions are descent directions, trial points remain inside the box, and success is tested using the original projected gradient.
History is discarded only for numerical breakdown or loss of descent, so once active bounds settle, the method continues as L-BFGS on free components while retaining history unless descent is lost.
Iteration counts depend on history length and bound locations, with no monotone relationship, as the next example illustrates.

## Active bounds changing during iteration

Solve an obstacle problem with load $q_i$ applied to displacements $x_1,\dots,x_{12}$ ($x_0=x_{13}=0$) of 12 nodes of a string fixed at both ends, confined between floor $x_i\ge0$ and ceiling $x_i\le u$.

$$
\min_{0\le\mathbf{x}\le u}\ f(\mathbf{x})=\frac12\sum_{i=0}^{12}(x_{i+1}-x_i)^2-\sum_{i=1}^{12}q_ix_i, \qquad q_i=0.6\sin\frac{2\pi i}{13}+0.25
$$

All quantities are dimensionless.
The objective is a strongly convex quadratic (with finite-difference Hessian $\mathbf{L}=\mathbf{C}^\mathsf{T}\mathbf{C}$), so its minimizer is unique.
The load points upward for $i\le7$ and downward for $i\ge8$, producing intervals touching the ceiling and floor.
Inputs are ceiling height $u$ and history length $m$; every initial component is $u/2$.

As an independent reference, rewrite the same problem as $\tfrac12\|\mathbf{C}\mathbf{x}-\mathbf{d}\|^2$ ($\mathbf{C}$ is the $13\times12$ difference matrix, $\mathbf{C}^\mathsf{T}\mathbf{d}=\mathbf{q}$) and solve it using the active set method `BoundedLinearLeastSquares` (BVLS, [Nonnegative and bounded linear least squares](../linear-least-squares/)).
Because $\tfrac12\|\mathbf{C}\mathbf{x}-\mathbf{d}\|^2=\tfrac12\mathbf{x}^\mathsf{T}\mathbf{L}\mathbf{x}-\mathbf{q}^\mathsf{T}\mathbf{x}+\text{constant}$, both have the same minimizer.
Construct the iteration history from independent runs with iteration limits $k=1,2,\dots,50$.
The plot shows objective difference $f-f^*$ from BVLS and the maximum projected gradient component on logarithmic axes, with a horizontal stopping threshold.
The first table shows only iterations where the active bound pattern changes; the second gives the result at the default iteration limit and its difference from the BVLS solution.
Finally, use the termination reason at the default iteration limit as the computation outcome.

```rust
//| run: reactive
//| crates: [scioxide-core, scioxide-linalg, scioxide-optimize]

//|   ceiling: {"type":"range","label":"Upper bound u [-]","description":"Vary the displacement upper bound and the number of components touching it.","min":0.5,"max":4,"step":0.25,"value":1.5}
//|   history: {"type":"range","label":"History length m [pairs]","description":"Vary the L-BFGS curvature history length.","min":1,"max":10,"step":1,"value":10}
//| cases:
//|   - {"id":"low-ceiling","label":"u = 0.5","description":"Six components touch upper bounds and four touch lower bounds; the pattern settles at iteration 4 and GradientSmall is reached in 20 iterations.","inputs":{"ceiling":0.5}}
//|   - {"id":"high-ceiling","label":"u = 4","description":"Only three components touch upper bounds. All components become interior at iteration 2; the pattern matches BVLS at iteration 7 and GradientSmall is reached in 28 iterations.","inputs":{"ceiling":4}}
//|   - {"id":"short-history","label":"m = 1","description":"With one history pair, GradientSmall is reached in 21 iterations and the iteration-3 pattern differs from the default (m = 10). Omit two points where rounding makes f − f* nonpositive from the logarithmic axis.","inputs":{"history":1}}
//| tests:
//|   - case: default

//|       - {"artifact":"summary","path":"/rows/0/0","equals":"GradientSmall"}
//|       - {"artifact":"summary","path":"/rows/0/1","range":{"min":18,"max":36}}
//|       - {"artifact":"summary","path":"/rows/0/5","range":{"min":0,"max":5e-7}}
//|       - {"artifact":"summary","path":"/rows/0/6","equals":"Converged"}
//|       - {"artifact":"changes","path":"/rows/0/1","equals":"··UU·······L"}
//|       - {"artifact":"changes","path":"/rows/4/1","equals":"·UUUU····LLL"}
//|       - {"path":"/outputs/3/state","equals":"satisfied"}
//|   - case: low-ceiling
//|     expect:
//|       - {"artifact":"summary","path":"/rows/0/0","equals":"GradientSmall"}
//|       - {"artifact":"summary","path":"/rows/0/1","range":{"min":15,"max":30}}
//|       - {"artifact":"summary","path":"/rows/0/5","range":{"min":0,"max":5e-7}}
//|       - {"path":"/outputs/3/state","equals":"satisfied"}
//|   - case: high-ceiling
//|     expect:
//|       - {"artifact":"summary","path":"/rows/0/0","equals":"GradientSmall"}
//|       - {"artifact":"summary","path":"/rows/0/1","range":{"min":18,"max":40}}
//|       - {"artifact":"summary","path":"/rows/0/5","range":{"min":0,"max":5e-7}}
//|       - {"artifact":"changes","path":"/rows/1/1","equals":"············"}
//|   - case: short-history
//|     expect:
//|       - {"artifact":"summary","path":"/rows/0/0","equals":"GradientSmall"}
//|       - {"artifact":"summary","path":"/rows/0/1","range":{"min":14,"max":32}}
//|       - {"artifact":"summary","path":"/rows/0/5","range":{"min":0,"max":5e-7}}
//|       - {"artifact":"summary","path":"/rows/0/7","equals":2}
use scioxide_core::{Bounds, Budget};
use scioxide_linalg::Matrix;
use scioxide_optimize::{
    BoundedLinearLeastSquares, BoundedObjective, LbfgsB, LbfgsBOptions,
    LinearLeastSquaresProblem, ObjectiveFn, ObjectiveFunction, OptimizeTermination,
};

// Apply load q to string displacements x_1..x_n (fixed ends x_0 = x_{n+1} = 0) and confine them to 0 ≤ x ≤ u.
// f(x) = ½ Σ (x_{i+1} − x_i)² − qᵀx, with gradient (L x − q)_i = 2x_i − x_{i−1} − x_{i+1} − q_i.
let n = 12_usize;
let u = ceiling;
let q: Vec<f64> = (0..n)
    .map(|i| {
        let t = (i + 1) as f64 / (n + 1) as f64;
        0.6 * scioxide_core::RealScalar::sin(2.0 * core::f64::consts::PI * t) + 0.25
    })
    .collect();
let gradient_of = |x: &[f64], q: &[f64]| -> Vec<f64> {
    (0..x.len())
        .map(|i| {
            let left = if i > 0 { x[i - 1] } else { 0.0 };
            let right = if i + 1 < x.len() { x[i + 1] } else { 0.0 };
            2.0 * x[i] - left - right - q[i]
        })
        .collect()
};
let (qf, qg) = (q.clone(), q.clone());
let objective = ObjectiveFn::new(n, move |x: &[f64]| {
    let mut energy = 0.0;
    for i in 0..=x.len() {
        let left = if i > 0 { x[i - 1] } else { 0.0 };
        let right = if i < x.len() { x[i] } else { 0.0 };
        energy += 0.5 * (right - left) * (right - left);
    }
    Ok(energy - x.iter().zip(&qf).map(|(a, b)| a * b).sum::<f64>())
})
.with_gradient(move |x: &[f64], g: &mut [f64]| {
    g.copy_from_slice(&gradient_of(x, &qg));
    Ok(())
});
let bounds = Bounds::new(vec![(Some(0.0), Some(u)); n]).map_err(|e| e.to_string())?;
let problem = BoundedObjective::new(&objective, &bounds).map_err(|e| e.to_string())?;
let start = vec![0.5 * u; n];
let memory = Budget::try_from(history as usize).map_err(|e| e.to_string())?;

// Independent reference: solve the same problem as ½‖C x − d‖² (difference matrix C, Cᵀd = q) with BVLS.
let mut c = vec![0.0_f64; (n + 1) * n];
for j in 0..n {
    c[j * n + j] = 1.0;
    c[(j + 1) * n + j] = -1.0;
}
let mut d = vec![0.0_f64; n + 1];
for i in 0..n {
    d[i + 1] = d[i] - q[i];
}
let c = Matrix::from_vec(n + 1, n, c).map_err(|e| e.to_string())?;
let linear = LinearLeastSquaresProblem::from_dense(&c, &d)
    .map_err(|e| e.to_string())?
    .with_bounds(&bounds)
    .map_err(|e| e.to_string())?;
let reference = BoundedLinearLeastSquares::<f64>::default()
    .solve(&linear)
    .map_err(|e| e.to_string())?;
if !reference.is_success() {
    return Err(format!("BVLS did not converge: {}", reference.termination()));
}
let x_ref = reference.x();
let f_ref = objective.eval(x_ref).map_err(|e| e.to_string())?;

// Use independent runs with iteration limits k = 1, 2, … to examine points and active bounds after each iteration.
let pattern_of = |x: &[f64]| -> String {
    x.iter()
        .map(|&xi| {
            if xi == 0.0 {
                'L'
            } else if xi == u {
                'U'
            } else {
                '·'
            }
        })
        .collect()
};
// Maximum projected gradient component: exclude lower-bound components with g ≥ 0 and upper-bound components with g ≤ 0 (the same quantity as the stopping test).
let projected_of = |x: &[f64]| -> f64 {
    x.iter()
        .zip(gradient_of(x, &q))
        .map(|(&xi, gi)| {
            if (xi == 0.0 && gi >= 0.0) || (xi == u && gi <= 0.0) {
                0.0
            } else {
                gi.abs()
            }
        })
        .fold(0.0_f64, f64::max)
};
let (mut gap, mut stationarity, mut changes) = (Vec::new(), Vec::new(), Vec::new());
let mut dropped = 0_usize;
let mut previous = pattern_of(&start);
for k in 1..=50_usize {
    let options = LbfgsBOptions::default()
        .with_memory(memory)
        .with_max_iterations(Budget::try_from(k).map_err(|e| e.to_string())?);
    let result = LbfgsB::new(options)
        .minimize(&problem, &start)
        .map_err(|e| e.to_string())?;
    let iteration = result.iterations() as f64;
    // Count but do not plot points with f − f* ≤ 0 (matching BVLS due to rounding) on the logarithmic axis.
    if result.fun() - f_ref > 0.0 {
        gap.push([iteration, result.fun() - f_ref]);
    } else {
        dropped += 1;
    }
    stationarity.push([iteration, projected_of(result.x())]);
    let pattern = pattern_of(result.x());
    if pattern != previous {
        changes.push((
            result.iterations(),
            pattern.clone(),
            projected_of(result.x()),
        ));
        previous = pattern;
    }
    if result.is_success() {
        break;
    }
}
let last = LbfgsB::new(LbfgsBOptions::default().with_memory(memory))
    .minimize(&problem, &start)
    .map_err(|e| e.to_string())?;
// Stopping threshold √ε (1 + max(1, |f| / max(1, ‖x‖∞))) (default GradientTolerance).
let coordinate = last.x().iter().fold(1.0_f64, |a, &v| a.max(v.abs()));
let threshold = <f64 as scioxide_core::RealScalar>::SQRT_EPSILON
    * (1.0 + (last.fun().abs() / coordinate).max(1.0));
emit_line_chart!(
    &vec![
        serde_json::json!({ "name": "f − f* (BVLS reference)", "points": gap }),
        serde_json::json!({ "name": "Maximum projected gradient component", "points": stationarity }),
    ],
    options = &serde_json::json!({
        "xLabel": "Iteration k [count]",
        "yLabel": "Objective difference or projected gradient [-]",
        "yType": "log",
        "xMin": 0.0,
        "xMax": 50.0,
        "annotations": [{ "kind": "line", "axis": "y", "value": threshold, "label": "Stopping threshold" }]
    })
);
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let change_columns = serde_json::json!([
    { "key": "0", "label": "Iterations [count]", "type": "integer" },
    { "key": "1", "label": "Component state (L lower / U upper / · interior)" },
    { "key": "2", "label": "Maximum projected gradient component [-]", "type": "number", "format": sci3 }
]);
emit_table_with_columns!(
    change_columns,
    changes,
    metadata = serde_json::json!({ "id": "changes" })
);
let difference = last
    .x()
    .iter()
    .zip(x_ref)
    .map(|(a, b)| (a - b).abs())
    .fold(0.0_f64, f64::max);
let summary_columns = serde_json::json!([
    { "key": "0", "label": "LbfgsB termination reason" },
    { "key": "1", "label": "Iterations [count]", "type": "integer" },
    { "key": "2", "label": "Objective evaluations [count]", "type": "integer" },
    { "key": "3", "label": "Maximum projected gradient component [-]", "type": "number", "format": sci3 },
    { "key": "4", "label": "Stopping threshold [-]", "type": "number", "format": sci3 },
    { "key": "5", "label": "Maximum difference from BVLS solution [-]", "type": "number", "format": sci3 },
    { "key": "6", "label": "BVLS termination reason" },
    { "key": "7", "label": "Points omitted from chart [count]", "type": "integer" }
]);
let termination = last.termination();
emit_table_with_columns!(
    summary_columns,
    vec![(
        termination.to_string(),
        last.iterations(),
        last.fun_evals(),
        projected_of(last.x()),
        threshold,
        difference,
        reference.termination().to_string(),
        dropped
    )],
    metadata = serde_json::json!({ "id": "summary" })
);
let outcome = if termination.is_success() {
    Outcome::satisfied("Projected gradient fell below the stopping threshold")
} else if matches!(termination, OptimizeTermination::LineSearchFailed(_)) {
    Outcome::failed("Line search could not find an acceptable step")
} else {
    Outcome::partial("Stopped before meeting the projected-gradient criterion")
};
emit_outcome!(
    outcome
        .status(termination.to_string())
        .diagnostic("Iterations", last.iterations() as f64, None)
        .diagnostic("Maximum difference from BVLS solution", difference, None)
);
```

## Summary

Classical L-BFGS-B determines its active set at the first local minimum of the model on the projected steepest descent path (the generalized Cauchy point), then minimizes the model over the remaining components.
The `LbfgsB` method lacks these two stages: it freezes components by gradient and direction signs and uses Armijo search along a projected segment, so classical active set identification and convergence analyses do not apply.
Stopping uses only the projected gradient and does not clip interior components by distance to the bound, making it at least as strict as the classical test for the same tolerance.
Any number of active bounds can change in one iteration; after the pattern settles, the method continues as L-BFGS on free components while retaining history.
For quadratic problems, comparison with an active set BVLS solution checks termination reasons and solution error separately.
