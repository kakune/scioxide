Powell's conjugate direction method is a derivative-free local method that repeatedly minimizes in one dimension along a set of directions and constructs a new direction from the net displacement of a cycle.
Like [Nelder–Mead](../derivative-free-local/), it uses only function values, but it constructs directions using quadratic structure and can also search within a finite box.
This page derives the algorithm from conjugate direction properties and explains direction replacement, boxes and fixed variables, and one-dimensional search limits and termination in SciOxide's `Powell`.

## Conjugate directions and the parallel subspace property

Consider the quadratic function $f(\mathbf{x})=\tfrac12\mathbf{x}^\mathsf{T}\mathbf{A}\mathbf{x}-\mathbf{b}^\mathsf{T}\mathbf{x}$ with positive definite matrix $\mathbf{A}$.
A set of directions $\mathbf{d}_1,\dots,\mathbf{d}_n$ is conjugate with respect to $\mathbf{A}$ when it satisfies $\mathbf{d}_i^\mathsf{T}\mathbf{A}\mathbf{d}_j=0$ ($i\ne j$).
Successive exact one-dimensional minimizations along conjugate directions reach the minimizer $\mathbf{A}^{-1}\mathbf{b}$ in $n$ steps from any starting point.
Each minimization preserves minimality along the preceding directions.

The parallel subspace property is the key to constructing conjugate directions without derivatives.
Suppose that one-dimensional minimizations from two different points along the same direction $\mathbf{d}$ give minimizers $\mathbf{x}_a$ and $\mathbf{x}_b$.
The directional derivatives vanish at the minimizers, giving $\mathbf{d}^\mathsf{T}(\mathbf{A}\mathbf{x}_a-\mathbf{b})=0$ and $\mathbf{d}^\mathsf{T}(\mathbf{A}\mathbf{x}_b-\mathbf{b})=0$; subtraction yields

$$
\mathbf{d}^\mathsf{T}\mathbf{A}(\mathbf{x}_b-\mathbf{x}_a)=0
$$


The direction joining these points is conjugate to $\mathbf{d}$, giving a conjugate direction from function values alone.

Powell's method uses this property each cycle.
Starting at $\mathbf{x}_0$, minimize successively along directions $\mathbf{d}_1,\dots,\mathbf{d}_n$ to reach $\mathbf{x}_N$, minimize once more along the net displacement $\mathbf{d}_{\mathrm{new}}=\mathbf{x}_N-\mathbf{x}_0$, and replace one old direction by $\mathbf{d}_{\mathrm{new}}$.
For a quadratic, exact one-dimensional minimization and a linearly independent direction set produce a conjugate set and reach the minimizer within $n$ cycles (Powell 1964).
In practice, repeated replacement can make the directions nearly linearly dependent, so a replacement criterion avoids this.

## Direction replacement and rank

Let $f_0=f(\mathbf{x}_0)$ and $f_N=f(\mathbf{x}_N)$ be the objective values over one cycle, $f_E=f(2\mathbf{x}_N-\mathbf{x}_0)$ the extrapolated value, and $\Delta f$ the largest reduction along any one direction during the cycle.
`Powell` considers replacing the direction with the greatest reduction only when Powell's criterion holds:

$$
f_E<f_0 \quad\text{and}\quad 2(f_0-2f_N+f_E)(f_0-f_N-\Delta f)^2<\Delta f\,(f_0-f_E)^2
$$


Otherwise it keeps the same set for the next cycle.
The criterion follows Powell's argument requiring that the determinant of the direction set not decrease after replacement (Powell 1964; Brent 1973, Chapter 7).

Before accepting a candidate, the method also checks the direction set's numerical rank.
It divides each direction by its largest absolute component, zeros rows for fixed variables, applies column-pivoted QR to the $n\times n$ direction matrix, and determines numerical rank with `RankThreshold` (default absolute and relative tolerances both $\sqrt{\varepsilon_{\mathrm{mach}}}$).
If rank is below the number of free variables, it discards the replacement and increments `PowellDiagnostics::rejected_replacements`.
If accepted, it minimizes along the new direction, moves the last old direction into the replaced column, and places the new direction in the last column.
`replacements` counts replacements.

This matrix has maximum rank $n$, but with fixed variables its rank can reach only the number of free variables.
Compare free-variable count (`free_dimension`) and rank (`rank`) in `PowellDiagnostics` to distinguish apparent rank deficiency due to fixed variables from actual degeneration of the direction set.
If the initial directions (coordinate axes by default, specified as columns of an $n\times n$ matrix through `PowellOptions::with_directions`) do not span the free variables, `InvalidInput` occurs before solving.

## Boxes and fixed variables

`Powell` accepts an unconstrained objective or `BoundedObjective` with a finite box.
A box requires finite lower and upper bounds on every variable; a one-sided bound gives `InvalidInput`.
Variables with equal lower and upper bounds are fixed; their direction components are zeroed so they do not move.
One-dimensional minimization takes place over the interval along the direction that stays in the box, keeping all trial points inside it.
A cycle whose extrapolated point $2\mathbf{x}_N-\mathbf{x}_0$ leaves the box skips the replacement criterion.
If every variable is fixed, the method evaluates the starting point once and stops with `Converged`.

## One-dimensional search and termination

Each direction is minimized in one dimension by the Brent method in `ScalarMinimizer`.
Without bounds, it searches for a bracket starting at steps 0 and 1; with a box, it minimizes over the entire interval along the direction inside the box.
A whole-interval search can settle in another valley far from the current point.
Thus, for a box, if the whole-interval search does not improve the current value, it evaluates one trial on each side of the current point at steps $+1$ and $-1$ (or at the interval endpoint if closer).
If a trial is lower than the current value, it minimizes again by Brent between the current point and that trial; if both are higher, it minimizes within the bracket formed by the two trials around the current point.
This avoids missing a decrease immediately near the current point.
One-dimensional search uses `ScalarMinimumOptions` in `PowellOptions::with_scalar_options` (default absolute and relative tolerances $\sqrt{\varepsilon_{\mathrm{mach}}}$, 1000 iterations, 2000 evaluations).
If a one-dimensional search stagnates or reaches its own iteration limit, only that direction's search ends and the next direction begins.
Reaching `Powell`'s overall evaluation limit, time limit, or cancellation stops the entire method.
A one-dimensional result is accepted only if the objective decreases; trials returning NaN or infinity are treated as worse than every finite value.

At the end of each cycle, examine the largest coordinate displacement $\delta_x$ among individual direction moves and net displacement, and the cycle's objective reduction $\delta_f=|f_0-f_N|$; if both conditions hold:

$$
\delta_x\le\tau^x_{\mathrm{abs}}+\tau^x_{\mathrm{rel}}\max(\|\mathbf{x}_0\|_\infty,\|\mathbf{x}_N\|_\infty),\qquad
\delta_f\le\tau^f_{\mathrm{abs}}+\tau^f_{\mathrm{rel}}\max(|f_0|,|f_N|)
$$

the method stops with `Converged`.
Specify tolerances with `with_step_tolerance` and `with_function_tolerance`; all default to $\sqrt{\varepsilon_{\mathrm{mach}}}$.
A cycle with zero net displacement stops with `Stagnation`; the cycle limit (default 1000, `with_max_iterations`) gives `IterationLimit`; the objective evaluation limit including one-dimensional searches (default 2000, `with_max_evaluations`) gives `EvaluationLimit`.
Termination other than `Converged` returns the best evaluated point as an estimate.
In `PowellDiagnostics`, `step`, `step_scale`, `function_change`, and `function_scale` are the last completed cycle's $\delta_x$, coordinate scale, $\delta_f$, and objective scale.

A cycle's evaluation count sums the evaluations of $n$ one-dimensional minimizations, one extrapolated-point evaluation (omitted outside the box), and one additional one-dimensional minimization if a direction is replaced.
With a box, each direction that fails to improve during whole-interval search adds at most two trial evaluations and another one-dimensional minimization's evaluations.
Operations other than evaluations cost $O(n^2)$ per cycle; each replacement candidate passing Powell's criterion adds $O(n^3)$ for column-pivoted QR of the direction matrix.
One-dimensional minimization evaluation counts depend on objective shape and tolerance; a tolerance of $\sqrt{\varepsilon_{\mathrm{mach}}}$ often needs several dozen evaluations per minimization.
`PowellOptions` is immutable configuration; `Powell::new` checks initial direction shape and finiteness.
A prepared `PowellWorkspace` retains direction matrix, QR, and trial-point memory ($O(n^2)$); check required capacity with `PowellWorkspaceRequirements`.

## Fixed variables and direction rank

Fix the second of two components at 1 and minimize $|x_1-a|+x_2^2$.
The input is the target $a$; use starting point $(0,1)$.
Outputs are a table comparing the minimizer with the analytic solution and a table of free-variable count, projected direction matrix numerical rank and size $n$, evaluation count, and termination reason.
The independent analytic solution is $(a,1)$, with objective value 1.
Check that rank 1 of the projected $2\times2$ direction matrix is less than $n=2$ but sufficient when it equals the free-variable count 1.
Finally, show termination as the computation outcome.

```rust
//| id: optimize-powell-fixed-coordinate
//| ref: optimize-powell-fixed-coordinate
//| title: "Find the analytic minimizer with a direction set containing a fixed variable"
//| run: reactive
//| crates: [scioxide-optimize, scioxide-core, scioxide-linalg]
//| inputs:
//|   target_coordinate: {"type":"range","label":"Free component target a [-]","min":-1,"max":1,"step":0.25,"value":0.25}
//| cases:
//|   - {"id":"target-at-start","label":"a = 1","description":"The target lies 1 unit from the starting point; 70 evaluations give x₁ = 1.","inputs":{"target_coordinate":1}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"solution","path":"/rows/0/1","equals":1}
//|       - {"artifact":"solution","path":"/rows/0/2","range":{"min":0,"max":1e-8}}
//|       - {"artifact":"rank","path":"/rows/0/0","equals":1}
//|       - {"artifact":"rank","path":"/rows/0/1","equals":1}
//|       - {"artifact":"rank","path":"/rows/0/2","equals":2}
//|       - {"artifact":"rank","path":"/rows/0/3","range":{"min":70,"max":110}}
//|       - {"artifact":"rank","path":"/rows/0/4","equals":"Converged"}
//|       - {"path":"/outputs/2/state","equals":"satisfied"}
//|   - case: target-at-start
//|     expect:
//|       - {"artifact":"solution","path":"/rows/0/2","range":{"min":0,"max":1e-8}}
//|       - {"artifact":"rank","path":"/rows/0/4","equals":"Converged"}
//|       - {"path":"/outputs/2/state","equals":"satisfied"}
use scioxide_core::Bounds;
use scioxide_optimize::{ObjectiveFn, OptimizeResult, Powell, PowellOptions};

let a = target_coordinate;
let objective = ObjectiveFn::new(2, move |x: &[f64]| Ok((x[0] - a).abs() + x[1] * x[1]));
// The second component is fixed by equal lower and upper bounds. Directions are the two identity matrix columns.
let bounds = Bounds::new(vec![(Some(-2.0), Some(2.0)), (Some(1.0), Some(1.0))])
    .map_err(|e| e.to_string())?;
let matrix = [1.0_f64, 0.0, 0.0, 1.0];
let directions =
    scioxide_linalg::Matrix::from_vec(2, 2, matrix.to_vec()).map_err(|e| e.to_string())?;
let bounded =
    scioxide_optimize::BoundedObjective::new(&objective, &bounds).map_err(|e| e.to_string())?;
let options = PowellOptions::default().with_directions(directions);
let solver = Powell::new(options).map_err(|e| e.to_string())?;
// Allocate workspace and result storage first, then solve through the prepared call.
let mut work = solver.workspace(2).map_err(|e| e.to_string())?;
let mut result = OptimizeResult::empty();
result.try_reserve(2).map_err(|e| e.to_string())?;
solver
    .minimize_into(
        &bounded,
        &[0.0, 1.0],
        &mut result,
        &mut work,
        scioxide_core::ExecutionContext::sequential(),
    )
    .map_err(|e| e.to_string())?;
let diagnostic = match result.method_diagnostics() {
    scioxide_optimize::OptimizeDiagnostics::Powell(diagnostic) => diagnostic,
    _ => return Err("Missing diagnostics for this algorithm".to_string()),
};
let (rank, maximum_rank) = diagnostic
    .rank()
    .map_or((0, 0), |r| (r.rank(), r.maximum_rank()));
// Independent check: measure the difference from the analytic solution (a, 1) and minimum 1 in original coordinates.
let x = result.x();
let general = serde_json::json!({ "significantDigits": 10 });
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let columns = serde_json::json!([
    { "key": "0", "label": "x₁ [-]", "type": "number", "format": general },
    { "key": "1", "label": "x₂ [-]", "type": "number", "format": general },
    { "key": "2", "label": "|x₁ − a| [-]", "type": "number", "format": sci3 },
    { "key": "3", "label": "Objective value − 1 [-]", "type": "number", "format": sci3 }
]);
emit_table_with_columns!(
    columns,
    vec![(x[0], x[1], (x[0] - a).abs(), result.fun() - 1.0)],
    metadata = serde_json::json!({ "id": "solution" })
);
let rank_columns = serde_json::json!([
    { "key": "0", "label": "Free variables [count]", "type": "integer" },
    { "key": "1", "label": "Projected direction matrix numerical rank", "type": "integer" },
    { "key": "2", "label": "Direction matrix size n", "type": "integer" },
    { "key": "3", "label": "Objective evaluations [count]", "type": "integer" },
    { "key": "4", "label": "Termination reason" }
]);
let termination = result.termination();
emit_table_with_columns!(
    rank_columns,
    vec![(
        diagnostic.free_dimension(),
        rank,
        maximum_rank,
        result.fun_evals(),
        termination.to_string()
    )],
    metadata = serde_json::json!({ "id": "rank" })
);
let outcome = if termination.is_success() {
    Outcome::satisfied("Cycle displacement and objective reduction fell below their tolerances")
} else {
    Outcome::partial("Stopped before meeting stopping criteria")
};
emit_outcome!(
    outcome
        .status(termination.to_string())
        .diagnostic("Objective evaluations", result.fun_evals() as f64, None)
        .diagnostic("|x₁ − a|", (x[0] - a).abs(), None)
);
```

At the default $a=0.25$, 2 cycles and 87 evaluations reach `Converged` with $|x_1-a|=2.5\times10^{-10}$; the second component stays fixed at 1.
The first cycle brings $x_1$ nearly to $a$; in the second cycle confirming termination, whole-interval search gives no reduction and adds two side-trial evaluations and one-dimensional minimization within their bracket.
There is 1 free variable and the projected direction matrix's numerical rank is 1; this is below its size $n=2$ but equals the free-variable count.
`RankReport::is_full_rank()` compares against the maximum possible rank 2 of this $2\times2$ matrix and returns `false`; it does not indicate degeneration in the free space.
The objective's $|x_1-a|$ is not differentiable at the minimizer, but Powell's method only compares values, so this causes no problem.

## Rotated elliptical valleys and initial directions

Examine the effect of initial directions on cycle and evaluation counts using the quadratic $f(\mathbf{x})=\tfrac12(\mathbf{x}-\mathbf{c})^\mathsf{T}\mathbf{A}(\mathbf{x}-\mathbf{c})$ with $n=8$.
The eigenvalues of $\mathbf{A}=\mathbf{Q}\boldsymbol{\Lambda}\mathbf{Q}^\mathsf{T}$ are $\lambda_k=\kappa^{k/7}$ ($k=0,\dots,7$), giving condition number $\kappa$.
$\mathbf{Q}$ rotates each coordinate pair $(x_1,x_2)$, $(x_3,x_4)$, … by angle $\theta$; at $\theta=0$ the coordinate axes are eigenvectors.
The minimizer is $c_i=1+0.5(i-1)$ and the starting point is the origin.
Eigenvectors are mutually conjugate with respect to $\mathbf{A}$, so supplying the columns of $\mathbf{Q}$ as initial directions reaches the minimizer in one cycle and confirms termination in the next.
Compare with a run starting from coordinate axes by reading cycle count, evaluations, replacements, and difference from the minimizer.
Finally, show the coordinate-axis run's termination reason as the computation outcome.

```rust
//| id: optimize-powell-rotated-quadratic
//| ref: optimize-powell-rotated-quadratic
//| title: "Compare a direction set starting from coordinate axes with a conjugate set"
//| run: reactive
//| crates: [scioxide-core, scioxide-linalg, scioxide-optimize]
//| inputs:
//|   condition: {"type":"select","label":"Condition number κ [-]","description":"Eigenvalue spread. At 1 the quadratic is isotropic.","options":["1","100","10000"],"value":"100"}
//|   angle: {"type":"range","label":"Rotation angle θ [°]","description":"Angle rotating eigenvectors away from coordinate axes. At 0° the coordinate axes are conjugate.","min":0,"max":45,"step":5,"value":30}
//| cases:
//|   - {"id":"aligned","label":"θ = 0°","description":"The coordinate axes are eigenvectors, so both sets stop after 2 cycles.","inputs":{"angle":0}}
//|   - {"id":"budget","label":"κ = 10⁴, θ = 45°","description":"The coordinate-axis run reaches the 2000-evaluation limit.","inputs":{"condition":"10000","angle":45}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"directions","path":"/rows/0/1","equals":"Converged"}
//|       - {"artifact":"directions","path":"/rows/0/2","range":{"min":5,"max":15}}
//|       - {"artifact":"directions","path":"/rows/0/6","range":{"min":0,"max":1e-7}}
//|       - {"artifact":"directions","path":"/rows/1/1","equals":"Converged"}
//|       - {"artifact":"directions","path":"/rows/1/2","equals":2}
//|       - {"artifact":"directions","path":"/rows/1/6","range":{"min":0,"max":1e-12}}
//|       - {"path":"/outputs/1/state","equals":"satisfied"}
//|   - case: aligned
//|     expect:
//|       - {"artifact":"directions","path":"/rows/0/2","equals":2}
//|       - {"artifact":"directions","path":"/rows/1/2","equals":2}
//|   - case: budget
//|     expect:
//|       - {"artifact":"directions","path":"/rows/0/1","equals":"EvaluationLimit"}
//|       - {"artifact":"directions","path":"/rows/0/3","equals":2000}
//|       - {"artifact":"directions","path":"/rows/1/1","equals":"Converged"}
//|       - {"path":"/outputs/1/state","equals":"partial"}
use scioxide_core::RealScalar;
use scioxide_linalg::Matrix;
use scioxide_optimize::{
    ObjectiveFn, OptimizeDiagnostics, OptimizeResult, Powell, PowellOptions,
};

let n = 8_usize;
let kappa: f64 = condition
    .parse()
    .map_err(|_| "Cannot read condition number".to_string())?;
let theta = RealScalar::to_radians(angle);
let (cos, sin) = (RealScalar::cos(theta), RealScalar::sin(theta));
// Q: rotate coordinate pairs (0, 1), (2, 3), … by θ. Columns of Q are eigenvectors of A.
let mut q = vec![0.0_f64; n * n];
for pair in (0..n).step_by(2) {
    q[pair * n + pair] = cos;
    q[pair * n + pair + 1] = -sin;
    q[(pair + 1) * n + pair] = sin;
    q[(pair + 1) * n + pair + 1] = cos;
}
let lambda: Vec<f64> = (0..n)
    .map(|k| RealScalar::powf(kappa, k as f64 / (n - 1) as f64))
    .collect();
// A = Q Λ Qᵀ (row-major).
let mut a = vec![0.0_f64; n * n];
for row in 0..n {
    for col in 0..n {
        a[row * n + col] = (0..n)
            .map(|k| q[row * n + k] * lambda[k] * q[col * n + k])
            .sum();
    }
}
let center: Vec<f64> = (0..n).map(|i| 1.0 + 0.5 * i as f64).collect();
let objective = ObjectiveFn::new(n, |x: &[f64]| {
    let d: Vec<f64> = x.iter().zip(&center).map(|(xi, ci)| xi - ci).collect();
    let mut value = 0.0;
    for row in 0..n {
        for col in 0..n {
            value += 0.5 * d[row] * a[row * n + col] * d[col];
        }
    }
    Ok(value)
});
let start = vec![0.0; n];
let solve = |options: PowellOptions<f64>| -> Result<OptimizeResult<f64>, String> {
    Powell::new(options)
        .map_err(|e| e.to_string())?
        .minimize(&objective, &start)
        .map_err(|e| e.to_string())
};
let coordinate = solve(PowellOptions::default())?;
let eigen = Matrix::from_vec(n, n, q.clone()).map_err(|e| e.to_string())?;
let conjugate = solve(PowellOptions::default().with_directions(eigen))?;
let mut rows = Vec::new();
for (name, run) in [
    ("Coordinate axes", &coordinate),
    ("Eigenvectors (conjugate)", &conjugate),
] {
    let OptimizeDiagnostics::Powell(diagnostic) = run.method_diagnostics() else {
        return Err("Missing diagnostics for this algorithm".to_string());
    };
    // Independent check: maximum component difference from the analytic minimizer c.
    let error = run
        .x()
        .iter()
        .zip(&center)
        .fold(0.0_f64, |m, (xi, ci)| m.max((xi - ci).abs()));
    rows.push((
        name,
        run.termination().to_string(),
        run.iterations(),
        run.fun_evals(),
        diagnostic.replacements(),
        diagnostic.rejected_replacements(),
        error,
    ));
}
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let columns = serde_json::json!([
    { "key": "0", "label": "Initial directions" },
    { "key": "1", "label": "Termination reason" },
    { "key": "2", "label": "Cycles [count]", "type": "integer" },
    { "key": "3", "label": "Objective evaluations [count]", "type": "integer" },
    { "key": "4", "label": "Replacements [count]", "type": "integer" },
    { "key": "5", "label": "Discarded replacements [count]", "type": "integer" },
    { "key": "6", "label": "Maximum difference from minimizer [-]", "type": "number", "format": sci3 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "directions" })
);
let termination = coordinate.termination();
let outcome = if termination.is_success() {
    Outcome::satisfied("The coordinate-axis run met the stopping criteria")
} else {
    Outcome::partial("The coordinate-axis run stopped before meeting the stopping criteria")
        .explanation("Treat the returned point as an estimate and reconsider the evaluation limit or initial search directions.")
};
emit_outcome!(
    outcome
        .status(termination.to_string())
        .diagnostic("Objective evaluations", coordinate.fun_evals() as f64, None)
        .diagnostic("Cycles", coordinate.iterations() as f64, None)
);
```

At the defaults $\kappa=100$ and $\theta=30^\circ$, the eigenvector run stops after 2 cycles (358 objective evaluations) with zero difference from the minimizer.
The coordinate-axis run reaches `Converged` after 9 cycles and 1510 evaluations, differing from the minimizer by $1.9\times10^{-9}$.
Powell's criterion never holds in this run, so there are 0 replacements and cycles retain the coordinate axes.
Cycles failing the criterion do not increment `rejected_replacements`; this quantity counts only replacements discarded by the rank check.
At $\theta=0^\circ$ the coordinate axes are eigenvectors, so both runs use the same 2 cycles and 398 evaluations.
At $\kappa=10^4$ and $\theta=45^\circ$, the coordinate-axis run makes 3 replacements but reaches the 2000-evaluation limit after 10 cycles, stops with `EvaluationLimit`, and returns a point differing from the minimizer by $2.9\times10^{-7}$ as an estimate.
Supply conjugate directions when known; otherwise read the evaluation limit together with the termination reason.

## Summary

Powell's method performs one-dimensional minimizations along its direction set each cycle and replaces an old direction with the net displacement to approach a conjugate set.
For quadratics, the parallel subspace property makes net displacement conjugate, but repeated replacement can make directions nearly dependent; `Powell` selects replacements using Powell's criterion and the direction matrix's numerical rank.
`Converged` means that coordinate displacement and objective reduction over a cycle fell below tolerance; it does not imply a zero gradient.
With fixed variables, direction matrix rank can reach only the free-variable count, so compare `free_dimension` and `rank` when assessing degeneration.
If conjugate directions are known, supplying them through `with_directions` reduces cycles and evaluations; a run reaching its evaluation limit returns its best point as an estimate.
