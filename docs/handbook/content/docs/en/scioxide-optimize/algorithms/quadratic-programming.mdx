Convex quadratic programming (QP) minimizes a quadratic objective subject to linear equalities, inequalities, and variable bounds.
Many problems take this form, including least squares, portfolio variance minimization, model predictive control, and SQP subproblems.
Writing the objective as $f(\mathbf{x})=\tfrac12\mathbf{x}^\mathsf{T}\mathbf{Q}\mathbf{x}+\mathbf{c}^\mathsf{T}\mathbf{x}$ gives gradient $\mathbf{Q}\mathbf{x}+\mathbf{c}$.
Omitting the factor $\tfrac12$ changes both the gradient and optimum; check it first when transferring another formulation.

## KKT conditions and solution uniqueness

Consider the problem with only linear inequalities

$$
\min_{\mathbf{x} \in \mathbb{R}^n} \frac{1}{2}\mathbf{x}^\mathsf{T}\mathbf{Q}\mathbf{x} + \mathbf{c}^\mathsf{T}\mathbf{x} \quad \text{subject to} \quad \mathbf{A}\mathbf{x} \le \mathbf{b}
$$

where $\mathbf{Q}$ is a symmetric $n\times n$ matrix and $\mathbf{A}\in\mathbb{R}^{m\times n}$.
Linear constraints always satisfy a constraint qualification, so at a local minimizer there are multipliers satisfying the KKT conditions

$$
\mathbf{Q}\mathbf{x}+\mathbf{c}+\mathbf{A}^\mathsf{T}\boldsymbol{\lambda}=\mathbf{0},\quad \mathbf{A}\mathbf{x}\le\mathbf{b},\quad \boldsymbol{\lambda}\ge\mathbf{0},\quad \lambda_j(\mathbf{A}\mathbf{x}-\mathbf{b})_j=0
$$

with $\boldsymbol{\lambda}$.
If $\mathbf{Q}\succeq0$ (positive semidefinite), the objective is convex and every KKT point is a global minimizer.
If $\mathbf{Q}\succ0$ (positive definite), the objective is strongly convex and a minimizer, if it exists, is unique.
In the semidefinite case, flat objective directions remain, allowing multiple minimizers or unbounded decrease along the linear term.
Even when $\mathbf{Q}$ is not positive definite in original coordinates, positive definiteness restricted to the feasible displacement space makes the minimizer unique.

## Choosing a method

Create the objective with `QpProblem::new(q, c)`, add row constraints with `with_constraints` and variable bounds with `with_bounds`.
In `QpProblem`, variables without bounds are free, unlike `LpProblem`, which treats variables without explicit bounds as $x\ge0$ by default.
The enum `HessianSymmetry` selects how nonsymmetric $\mathbf{Q}$ is handled.
The default `RequireSymmetric` requires exact symmetry; under this policy, `QpProblem::new` rejects nonsymmetric $\mathbf{Q}$ with `InvalidInput` (`Inconsistent`).
Constructing with `QpProblem::new_with_symmetry(q, c, HessianSymmetry::SymmetricPart)` interprets nonsymmetric $\mathbf{Q}$ as its symmetric part $(\mathbf{Q}+\mathbf{Q}^\mathsf{T})/2$, which gives the same objective.

`QpSolver` selects a method according to the `QpMethod` supplied through `with_method`.

- `Automatic` (default) uses projected Barzilai–Borwein for variable bounds only and an active-set method when general row constraints exist.
- `ActiveSet` uses the active-set method even for bound-only problems.
- `PrimalDual` uses a primal-dual predictor–corrector method on an augmented KKT system.

Regardless of the selected method, the following two cases use dedicated paths.
A problem with $\mathbf{Q}=\mathbf{0}$ is solved as LP by bounded revised simplex (`SimplexSolver`) unless `KktProvider` has been replaced.
Problems without constraints or bounds solve $\mathbf{Q}\mathbf{x}=-\mathbf{c}$ by $\mathrm{LDL}^\mathsf{T}$ factorization, or rank-aware spectral decomposition when $\mathbf{Q}$ is singular.
The projected BB method for bound-only problems is covered in [box-constrained convex quadratic programming and projected gradients](../bound-constrained-qp/).

## Active-set method

Let active set $\mathcal{W}_k$ contain the indices of constraints holding with equality at $\mathbf{x}_k$.
The active-set method obtains a step $\mathbf{p}$ minimizing the quadratic model while retaining the constraints in $\mathcal{W}_k$ as equalities from the KKT linear system

$$
\begin{bmatrix} \mathbf{Q} & \mathbf{A}_{\mathcal{W}}^\mathsf{T} \\ \mathbf{A}_{\mathcal{W}} & \mathbf{0} \end{bmatrix} \begin{bmatrix} \mathbf{p} \\ \boldsymbol{\lambda}_{\mathcal{W}} \end{bmatrix} = - \begin{bmatrix} \mathbf{Q}\mathbf{x}_k + \mathbf{c} \\ \mathbf{A}_{\mathcal{W}}\mathbf{x}_k - \mathbf{b}_{\mathcal{W}} \end{bmatrix}
$$


Since iterates remain feasible, $\mathbf{A}_{\mathcal{W}}\mathbf{x}_k=\mathbf{b}_{\mathcal{W}}$, and $\boldsymbol{\lambda}_{\mathcal{W}}$ contains the multipliers at $\mathbf{x}_k+\mathbf{p}$.

When moving along $\mathbf{p}$, stop before violating an inactive constraint.
The step length is

$$
\alpha_k=\min\Big(1,\ \min_{i\notin\mathcal{W}_k,\ \mathbf{a}_i^\mathsf{T}\mathbf{p}>0}\frac{b_i-\mathbf{a}_i^\mathsf{T}\mathbf{x}_k}{\mathbf{a}_i^\mathsf{T}\mathbf{p}}\Big)
$$

and if $\alpha_k<1$, add the constraint attaining the minimum (the blocking constraint) to the active set.

When $\mathbf{p} = \mathbf{0}$, $\nabla f(\mathbf{x}_k)=-\mathbf{A}_{\mathcal{W}}^\mathsf{T}\boldsymbol{\lambda}_{\mathcal{W}}$ holds.
In a direction $\mathbf{d}$ that releases only constraint $j$ inward ($\mathbf{A}_{\mathcal{W}}\mathbf{d}=-\mathbf{e}_j$), $\nabla f^\mathsf{T}\mathbf{d}=\lambda_j$; removing a constraint with negative multiplier $\lambda_j < 0$ therefore decreases the objective.
Remove any constraint with a negative multiplier from the active set; if none exists, every KKT condition holds and the method terminates.
For a strongly convex QP with $\mathbf{Q}\succ0$, steps with $\alpha_k>0$ strictly reduce the objective and never revisit the same active set; without degeneracy, finitely many active-set changes reach the optimum (Nocedal and Wright, 2006, Section 16.5).

If the initial point (`QpWarmStart` or 0 projected into the bounds) is infeasible, `QpSolver`'s active-set method first constructs a feasible point using a linear program with one auxiliary variable (Phase I), then begins iteration.
It removes the constraint with the most negative multiplier; after 8 consecutive nonprogressing iterations, it switches to a smallest-index rule to prevent cycling.
Variable bounds are not expanded into general rows; active coordinates are eliminated directly, and variables with equal bounds are treated as equalities.
If $\mathbf{Q}$ restricted to free variables is positive definite, the method retains its Cholesky factorization and a QR factorization of projected general rows, updating them in quadratic work as constraints enter or leave.
For semidefinite subproblems whose restricted $\mathbf{Q}$ is singular, it switches to a rank-aware KKT solve.
Finding an unbounded direction that hits no constraint gives `SuspectedUnbounded`; if that direction passes verification as an unboundedness certificate for the original problem, the status becomes `Unbounded`.
Initial factorization costs $O(n^3)$ and memory usage is $O(n^2)$.

## Primal-dual interior-point method

The primal-dual method keeps inequality slacks $\mathbf{s}$ and multipliers $\mathbf{z}$ positive while gradually satisfying complementarity.
Writing inequalities as $\mathbf{A}\mathbf{x}+\mathbf{s}=\mathbf{b}$ and $\mathbf{s}\ge\mathbf{0}$, the KKT conditions with complementarity relaxed to $\sigma\mu$ are

$$
\mathbf{Q}\mathbf{x}+\mathbf{c}+\mathbf{A}^\mathsf{T}\mathbf{z}=\mathbf{0},\quad \mathbf{A}\mathbf{x}+\mathbf{s}-\mathbf{b}=\mathbf{0},\quad \mathbf{S}\mathbf{Z}\mathbf{e}=\sigma\mu\mathbf{e}
$$

where $\mathbf{S}=\operatorname{diag}(\mathbf{s})$, $\mathbf{Z}=\operatorname{diag}(\mathbf{z})$, $\mu=\mathbf{s}^\mathsf{T}\mathbf{z}/m$ is average complementarity, and $\sigma\in[0,1]$ is the centering parameter.
Eliminating $\Delta\mathbf{s}$ from the Newton equations leaves the augmented KKT system

$$
\begin{bmatrix}\mathbf{Q}&\mathbf{A}^\mathsf{T}\\ \mathbf{A}&-\mathbf{Z}^{-1}\mathbf{S}\end{bmatrix}
\begin{bmatrix}\Delta\mathbf{x}\\ \Delta\mathbf{z}\end{bmatrix}=-\begin{bmatrix}\mathbf{r}_d\\ \mathbf{r}_p+\mathbf{Z}^{-1}\mathbf{r}_c\end{bmatrix}
$$

where $\mathbf{r}_d,\mathbf{r}_p,\mathbf{r}_c$ are the residuals of the three equations above.
Predictor and corrector differ only in their right-hand sides and can reuse the same factorization.

`PrimalDual` first simplifies equality rows, constructs a feasible point through Phase I, and starts with inequality slacks at least 1 and multipliers 1.
Variable bounds are eliminated coordinate by coordinate rather than added as augmented-system rows.
Each iteration computes a predictor direction with $\sigma=0$, determines Mehrotra's centering parameter $\sigma=(\mu_{\mathrm{aff}}/\mu)^3$ from the average complementarity $\mu_{\mathrm{aff}}$ after moving along it, and uses the same factorization to compute a corrector direction with second-order correction $-\Delta\mathbf{s}_{\mathrm{aff}}\circ\Delta\mathbf{z}_{\mathrm{aff}}$.
The step length is 0.995 times the smaller of 1 and the distance to the boundary, keeping slacks and multipliers positive.
Interior-point iterates do not lie exactly on the boundary, so solutions with active constraints are only approached within tolerance.

## Convexity checks

`QpSolver` solves only convex QP and checks before solving that $\mathbf{Q}$ (its symmetric part for `SymmetricPart`) is positive semidefinite.
If Gershgorin disks or Cholesky establish positive definiteness, it proceeds; otherwise it computes eigenvalues.
If the smallest eigenvalue is below $-(\tau_{\mathrm{abs}}+\tau_{\mathrm{rel}}\max_{ij}|Q_{ij}|)$ ($\tau_{\mathrm{abs}}$ and $\tau_{\mathrm{rel}}$ are the rank tolerances of `OptimalityTolerances`, both defaulting to $10^{-8}$), it returns a `InvalidInput` (`InvalidInputReason::UnsupportedConfiguration`) error without solving.
It provides neither local nor global solutions of nonconvex QP; use [sequential quadratic programming (SQP)](../sqp-and-interior-point/) or [nonlinear interior-point methods](../nonlinear-interior-point/) for local solutions, or consider [global search](../global-search/).

## Workspace and reuse

`QpWorkspace` holds active-set working memory and trial records and accepts any QP.
Replace KKT factorization through `QpWorkspace::with_kkt_provider`; built-in choices are `DenseKktProvider` (dense $\mathrm{LDL}^\mathsf{T}$ with Ruiz equilibration and rook pivoting) and `SparseKktProvider` (sparse $\mathrm{LDL}^\mathsf{T}$, reusing ordering and symbolic analysis when the pattern is unchanged).
The replacement factorization receives a system containing only general rows after active coordinates are eliminated.
The solver checks the returned solution's residual in the original system, detecting inaccurate solves.
Replacing factorization does not establish objective convexity.

`QpSolver::with_warm_start(QpWarmStart::new(point)?)` supplies an initial point.
Each solve checks its length (`DimensionMismatch` if wrong) and feasibility (`InvalidInput` if infeasible).
For a single solve, `QpProblem::solve()` uses the default `QpSolver` (`Automatic`, 1000-iteration limit, tolerance $10^{-8}$), returning unsuccessful termination through `Err`.
A verified infeasible or unbounded problem gives `DomainError`.

Results use `ProgrammingResult`; `primal_feasibility()`, `stationarity()`, `dual_feasibility()`, and `complementarity()` return residuals for the original problem.
Pass the original `QpProblem` (or a verification problem borrowed through `QpVerificationProblem::from_problem`) and result to `ProgrammingVerifier::verify` to recompute the original-coordinate certificate independently of the solver.
Visible coefficients also permit a positive semidefiniteness check and potentially `Accepted`; for `QpVerificationProblem::new` with an operator-supplied Hessian, passing KKT conditions yields only `KktOnly`.
Details are in [certificates and verification for linear and quadratic programming](../programming-certificates/).

## Checking the original KKT conditions

Minimize $x^2+2y^2$ subject to $x+y=t$, $0\le x\le u$, and $y\ge0$.
If the upper bound is inactive, substitution of $y=t-x$ followed by differentiation gives analytic solution $(2t/3,t/3)$ and equality multiplier $-4t/3$.
For $u<2t/3$, the upper bound is active and the solution is $(u,t-u)$.
Stationarity $2x+\lambda+\alpha_u=0$ and $4y+\lambda=0$ give equality multiplier $\lambda=-4(t-u)$ and upper-bound multiplier $\alpha_u=4t-6u>0$.
Inputs are the sum's right-hand side $t$ and upper bound $u$ on $x$.
The cell compares solutions and multipliers from three methods with the analytic solution, displaying stationarity residuals computed with analytic multipliers and statuses from independent `ProgrammingVerifier` verification of the solver results.
Read equality and upper-bound multipliers from the result certificate (`ProgrammingResult::certificate()`).

```rust
//| id: optimize-qp-kkt
//| ref: optimize-qp-kkt
//| title: "Check QP solutions and multipliers against the original equations"
//| run: reactive
//| crates: [scioxide-core, scioxide-linalg, scioxide-optimize]
//| inputs:
//|   total: {"type":"range","label":"Variable sum t [-]","min":0.5,"max":2,"step":0.25,"value":1}
//|   x_cap: {"type":"range","label":"Upper bound u on x [-]","description":"The upper bound becomes active for u < 2t/3.","min":0.1,"max":2,"step":0.1,"value":2}
//| cases:
//|   - {"id":"active-cap","label":"Upper bound u = 0.4 (active)","description":"The solution moves to (0.4, 0.6), with equality multiplier −2.4 and upper-bound multiplier 1.6.","inputs":{"x_cap":0.4}}
//|   - {"id":"large-total","label":"Sum t = 2","description":"The upper bound remains inactive, with solution (4/3, 2/3) and equality multiplier −8/3.","inputs":{"total":2}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"methods","path":"/rows/0/1","equals":"Converged"}
//|       - {"artifact":"methods","path":"/rows/1/1","equals":"Converged"}
//|       - {"artifact":"methods","path":"/rows/2/1","equals":"Converged"}
//|       - {"artifact":"methods","path":"/rows/0/4","range":{"min":0,"max":1e-12}}
//|       - {"artifact":"methods","path":"/rows/2/4","range":{"min":0,"max":1e-8}}
//|       - {"artifact":"methods","path":"/rows/0/5","approx":{"value":-1.3333333333333333,"atol":1e-12}}
//|       - {"artifact":"methods","path":"/rows/0/8","equals":"Accepted"}
//|       - {"artifact":"methods","path":"/rows/2/8","equals":"Accepted"}
//|   - case: active-cap
//|     expect:
//|       - {"artifact":"methods","path":"/rows/0/4","range":{"min":0,"max":1e-12}}
//|       - {"artifact":"methods","path":"/rows/0/5","approx":{"value":-2.4,"atol":1e-10}}
//|       - {"artifact":"methods","path":"/rows/0/6","approx":{"value":1.6,"atol":1e-10}}
//|       - {"artifact":"methods","path":"/rows/2/4","range":{"min":0,"max":1e-7}}
//|   - case: large-total
//|     expect:
//|       - {"artifact":"methods","path":"/rows/1/2","approx":{"value":1.3333333333333333,"atol":1e-12}}
//|       - {"artifact":"analytic","path":"/rows/0/2","approx":{"value":-2.6666666666666665,"atol":1e-12}}
use scioxide_core::Bounds;
use scioxide_linalg::Matrix;
use scioxide_optimize::{
    LinearConstraintSense, LinearConstraints, ProgrammingCertificate, ProgrammingVerifier,
    QpMethod, QpProblem, QpSolver, QpVerificationProblem,
};
let general = serde_json::json!({ "significantDigits": 6 });
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
// Objective x² + 2y² = ½ xᵀ diag(2, 4) x, equality x + y = t, 0 ≤ x ≤ u, y ≥ 0.
let h = Matrix::from_vec(2, 2, vec![2.0_f64, 0.0, 0.0, 4.0]).map_err(|e| e.to_string())?;
let c = LinearConstraints::new(
    Matrix::from_vec(1, 2, vec![1.0, 1.0]).map_err(|e| e.to_string())?,
    vec![total],
    vec![LinearConstraintSense::Equal],
)
.map_err(|e| e.to_string())?;
let bounds = Bounds::new(vec![(Some(0.0), Some(x_cap)), (Some(0.0), None)])
    .map_err(|e| e.to_string())?;
let p = QpProblem::new(h, vec![0.0; 2])
    .and_then(|p| p.with_constraints(c))
    .and_then(|p| p.with_bounds(bounds))
    .map_err(|e| e.to_string())?;
// Independent analytic solution: (2t/3, t/3) for an inactive upper bound, (u, t − u) when active.
let (ax, ay) = if x_cap >= 2.0 * total / 3.0 {
    (2.0 * total / 3.0, total / 3.0)
} else {
    (x_cap, total - x_cap)
};
// Determine equality multiplier λ and upper-bound multiplier α_u from stationarity Qx + λ(1, 1) + (α_u, 0) = 0.
let lambda = -4.0 * ay;
let alpha = -2.0 * ax - lambda;
let view = QpVerificationProblem::from_problem(&p);
let verifier = ProgrammingVerifier::default();
let mut rows = Vec::new();
for (name, method) in [
    ("Automatic", QpMethod::Automatic),
    ("ActiveSet", QpMethod::ActiveSet),
    ("PrimalDual", QpMethod::PrimalDual),
] {
    let r = QpSolver::default()
        .with_method(method)
        .solve(&p)
        .map_err(|e| e.to_string())?;
    let x = r.x();
    let (row, upper) = match r.certificate() {
        Some(ProgrammingCertificate::Optimality { dual, .. }) => {
            (Some(dual.rows[0]), Some(dual.upper[0]))
        }
        _ => (None, None),
    };
    let stationary = (2.0 * x[0] + lambda + alpha)
        .abs()
        .max((4.0 * x[1] + lambda).abs());
    let report = verifier.verify(&view, &r).map_err(|e| e.to_string())?;
    rows.push((
        name,
        r.termination().to_string(),
        x[0],
        x[1],
        (x[0] - ax).abs().max((x[1] - ay).abs()),
        row,
        upper,
        stationary,
        format!("{:?}", report.status()),
        r.iterations(),
    ));
}
let columns = serde_json::json!([
    { "key": "0", "label": "Method" },
    { "key": "1", "label": "Termination reason" },
    { "key": "2", "label": "x [-]", "type": "number", "format": general },
    { "key": "3", "label": "y [-]", "type": "number", "format": general },
    { "key": "4", "label": "Analytical-solution difference [-]", "type": "number", "format": sci2 },
    { "key": "5", "label": "Equality multiplier [-]", "type": "number", "format": general, "nullText": "None" },
    { "key": "6", "label": "x upper-bound multiplier [-]", "type": "number", "format": general, "nullText": "None" },
    { "key": "7", "label": "Stationarity residual with analytic multipliers [-]", "type": "number", "format": sci2 },
    { "key": "8", "label": "Verification status" },
    { "key": "9", "label": "Iterations [count]", "type": "integer" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "methods" })
);
let analytic_columns = serde_json::json!([
    { "key": "0", "label": "Analytic solution x [-]", "type": "number", "format": general },
    { "key": "1", "label": "Analytic solution y [-]", "type": "number", "format": general },
    { "key": "2", "label": "Equality multiplier λ [-]", "type": "number", "format": general },
    { "key": "3", "label": "Upper-bound multiplier α_u [-]", "type": "number", "format": general }
]);
emit_table_with_columns!(
    analytic_columns,
    vec![(ax, ay, lambda, alpha)],
    metadata = serde_json::json!({ "id": "analytic" })
);
```

At the defaults $t=1$ and $u=2$, all three methods give `Converged` and verification status `Accepted`.
`Automatic` and `ActiveSet` both use the active-set method because general rows exist; after 5 iterations they match analytic solution $(2/3,1/3)$ without rounding error, with equality multiplier $-4/3$.
`PrimalDual` reaches difference $4.5\times10^{-11}$ from the analytic solution in 8 iterations, with nonzero upper-bound multiplier $6.6\times10^{-12}$.
This shows that the interior-point solution approaches the analytic solution only within tolerance.
With $u=0.4$ the upper bound becomes active; after 4 iterations the active-set method returns $(0.4,0.6)$, equality multiplier $-2.4$, and upper-bound multiplier $1.6$, matching analytic values.
`PrimalDual` then differs from the analytic solution by $7.6\times10^{-9}$, and by $9.2\times10^{-12}$ for $u=0.1$; the difference depends on where iteration stops.
The stationarity residual from analytic multipliers is an independent check computed without internally estimated solver multipliers.

## Summary

KKT conditions characterize convex QP optimality: with $\mathbf{Q}\succeq0$ a KKT point is a global minimizer, and with $\mathbf{Q}\succ0$ it is unique.
The active-set method solves equality-constrained KKT systems, adds blocking constraints, removes constraints with negative multipliers, and returns solutions satisfying active constraints accurately up to rounding error.
The primal-dual interior-point method approaches from inside the boundary and satisfies active constraints only within tolerance, but its iteration count is independent of the number of active-set changes.
`QpMethod::Automatic` uses projected BB for bounds only and an active-set method for general row constraints; `ActiveSet` and `PrimalDual` fix the method explicitly.
`QpSolver` rejects $\mathbf{Q}$ that is not positive semidefinite with `InvalidInput`; send nonconvex problems to SQP or global search and convex results to `ProgrammingVerifier` for checks in original coordinates.
