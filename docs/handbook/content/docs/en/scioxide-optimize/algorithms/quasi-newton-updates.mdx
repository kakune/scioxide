Quasi-Newton methods rebuild a Hessian approximation from difference pairs $(\mathbf{s}, \mathbf{y})$ ($\mathbf{s} = \mathbf{x}_{k+1} - \mathbf{x}_k$, $\mathbf{y} = \nabla f(\mathbf{x}_{k+1}) - \nabla f(\mathbf{x}_k)$) observed during iteration.
The [BFGS update](oxref:optimize-bfgs-update) preserves positive definiteness when $\mathbf{s}^\mathsf{T}\mathbf{y} > 0$, but nonconvex functions or inaccurate line searches can violate this condition, and rounding can damage the updated matrix even when the condition holds.
This page explains which pairs SciOxide uses, modifies, or discards, and compares these updates with SR1, which does not preserve positive definiteness.
Notation follows [first-order methods, nonlinear conjugate gradients, and quasi-Newton methods](../first-order-and-quasi-newton/): $\mathbf{B}$ approximates the Hessian and $\mathbf{H}$ its inverse.

## Curvature criterion and action

`CurvaturePolicy::new(action, threshold)` contains threshold $\eta \in (0, 1)$ and action `CurvatureAction` (rustdoc writes the threshold as $\theta$).
In Hessian form (`HessianForm::Hessian`), pair $(\mathbf{s}, \mathbf{y})$ is used unchanged when

$$
\mathbf{s}^\mathsf{T}\mathbf{y} \ge \eta\,\mathbf{s}^\mathsf{T}\mathbf{B}\mathbf{s}
$$


The right side is the current approximation's predicted curvature along $\mathbf{s}$; the left side is observed curvature.
Inverse form (`HessianForm::Inverse`) exchanges the roles of $\mathbf{s}$ and $\mathbf{y}$ and tests $\mathbf{y}^\mathsf{T}\mathbf{s} \ge \eta\,\mathbf{y}^\mathsf{T}\mathbf{H}\mathbf{y}$.
Scaling the objective by a constant scales both sides equally, so the criterion is independent of objective units.

Pairs failing the criterion have two possible actions.

- `CurvatureAction::Damp` (default, $\eta = 0.2$) uses Powell [damping](oxref:optimize-damped-bfgs) to replace $\mathbf{y}$ by $\theta\mathbf{y} + (1-\theta)\mathbf{B}\mathbf{s}$, giving $\mathbf{s}^\mathsf{T}\bar{\mathbf{y}} = \eta\,\mathbf{s}^\mathsf{T}\mathbf{B}\mathbf{s}$ before updating.
- `CurvatureAction::Skip` discards the pair and retains the previous approximation.

Either action discards a pair if the predicted curvature $\mathbf{s}^\mathsf{T}\mathbf{B}\mathbf{s}$ is not positive.
Both unchanged and modified pairs are discarded if $\mathbf{s}^\mathsf{T}\mathbf{y}$ is at most $\varepsilon_{\mathrm{mach}}\lVert\mathbf{s}\rVert_2\lVert\mathbf{y}\rVert_2$, because their angle is nearly a right angle and rounding dominates the update.

## Update reports and skip reasons

One update returns `HessianUpdateReport`: `Updated` (used the observed pair unchanged), `Damped` (used a modified pair), or `Skipped(UpdateSkipReason)`.
A skipped update leaves the matrix unchanged.
`UpdateSkipReason` distinguishes the following reasons.

- `Curvature`: the curvature criterion failed with `Skip` selected, predicted curvature was not positive, or the modified pair was nearly orthogonal.
- `SmallDenominator`: the absolute SR1 denominator is at most $\sqrt{\varepsilon_{\mathrm{mach}}}$ times the product of the norms of the two vectors forming it.
- `Unrepresentable`: an updated matrix entry cannot be represented in floating point.
- `NotPositiveDefinite`: the BFGS matrix is not positive definite after rounding.
  An originally nonpositive-definite caller-supplied matrix also skips the update with this reason before updating.

`Bfgs` and `Lbfgs` count iteration reports and return them in `updates()`, `damped_updates()`, `skipped_updates()`, and `last_update()` of `GlobalizationDiagnostics`.
`Bfgs` only checks that its own approximation has positive updated diagonal entries; it does not compute a Cholesky factorization.

## Updating matrices directly

`HessianUpdateWorkspace` is workspace for updating a caller-owned dense $n \times n$ matrix by BFGS or SR1.
`new()` allocates nothing; `try_reserve(n)` prepares an $O(n^2)$ candidate matrix and Cholesky storage.
`update(&mut matrix, &s, &y, form, rule)` updates in place; `update_into(source, output, &s, &y, form, rule, execution)` preserves the original matrix and writes the result elsewhere.
`form` is `HessianForm`, and `rule` is `HessianUpdate::Bfgs(policy)` or `HessianUpdate::Sr1`.
The supplied matrix must be finite and exactly symmetric; incorrect shape or symmetry gives `InvalidInput`, and nonfinite entries give `NonFinite`.
An SR1 update costs $O(n^2)$.
BFGS checks positive definiteness of both supplied and updated matrices, using the diagonal for diagonally dominant matrices and otherwise Cholesky factorization ($O(n^3)$).

## SR1 update

The symmetric rank-one (SR1) update uses $\mathbf{r} = \mathbf{y} - \mathbf{B}\mathbf{s}$ to set

$$
\mathbf{B}_{+} = \mathbf{B} + \frac{\mathbf{r}\mathbf{r}^\mathsf{T}}{\mathbf{r}^\mathsf{T}\mathbf{s}}
$$


This is the unique symmetric rank-one correction satisfying the secant condition $\mathbf{B}_+\mathbf{s} = \mathbf{y}$.
For a quadratic $f(\mathbf{x}) = \tfrac12\mathbf{x}^\mathsf{T}\mathbf{A}\mathbf{x} - \mathbf{b}^\mathsf{T}\mathbf{x}$, $n$ linearly independent steps with nonzero denominators give $\mathbf{B}_n = \mathbf{A}$ regardless of line search (Nocedal–Wright, Theorem 6.1).
The denominator $\mathbf{r}^\mathsf{T}\mathbf{s}$ can have either sign, so unlike BFGS, SR1 does not preserve positive definiteness and can represent negative curvature.
A small denominator makes the update too large; SciOxide skips it with `SmallDenominator` when $|\mathbf{r}^\mathsf{T}\mathbf{s}| \le \sqrt{\varepsilon_{\mathrm{mach}}}\lVert\mathbf{s}\rVert_2\lVert\mathbf{r}\rVert_2$.
Inverse form uses the dual formula with $\mathbf{r} = \mathbf{s} - \mathbf{H}\mathbf{y}$ and denominator $\mathbf{r}^\mathsf{T}\mathbf{y}$.
A direction from an SR1 approximation need not descend, so combine it with a trust-region method that separately ensures a descent direction.

The following cell updates identity Hessian approximation $\mathbf{B}_0=\mathbf{I}$ with $\mathbf{s}=(1,0)$ and $\mathbf{y}=(-2,0)$ ($\mathbf{s}^\mathsf{T}\mathbf{y}=-2<0$) in three ways: SR1, default BFGS (Powell damping), and BFGS with `CurvatureAction::Skip`.
The table shows update reports, updated diagonal entries, differences from hand-computed matrices, the largest secant residual $|\mathbf{B}\mathbf{s}-\mathbf{y}|$, and the smallest eigenvalue.
Hand calculation gives $\operatorname{diag}(-2,1)$ for SR1 from $\mathbf{r}=(-3,0)$ and $\mathbf{r}^\mathsf{T}\mathbf{s}=-3$.
Damped BFGS gives $\theta=0.8/3$ and $\bar{\mathbf{y}}=(0.2,0)$ from $\mathbf{s}^\mathsf{T}\mathbf{B}\mathbf{s}=1$, producing $\operatorname{diag}(0.2,1)$ after updating.
`Skip` discards the update and retains the identity.

```rust
//| id: optimize-sr1-indefinite-secant
//| ref: optimize-sr1-indefinite-secant
//| title: "Compare SR1 and BFGS updates for a negative-curvature difference pair"
//| run: reactive
//| crates: [scioxide-core, scioxide-optimize, scioxide-linalg]
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"updates","path":"/rows/0/1","equals":"Updated"}
//|       - {"artifact":"updates","path":"/rows/0/4","range":{"min":0,"max":1e-15}}
//|       - {"artifact":"updates","path":"/rows/0/5","range":{"min":0,"max":1e-15}}
//|       - {"artifact":"updates","path":"/rows/0/6","approx":{"value":-2.0,"atol":1e-15}}
//|       - {"artifact":"updates","path":"/rows/1/1","equals":"Damped"}
//|       - {"artifact":"updates","path":"/rows/1/4","range":{"min":0,"max":1e-14}}
//|       - {"artifact":"updates","path":"/rows/1/5","approx":{"value":2.2,"atol":1e-14}}
//|       - {"artifact":"updates","path":"/rows/1/6","approx":{"value":0.2,"atol":1e-14}}
//|       - {"artifact":"updates","path":"/rows/2/1","equals":"Skipped(Curvature)"}
//|       - {"artifact":"updates","path":"/rows/2/4","equals":0}
//|       - {"artifact":"updates","path":"/rows/2/6","approx":{"value":1.0,"atol":1e-15}}
use scioxide_core::RealScalar;
use scioxide_linalg::Matrix;
use scioxide_optimize::{
    CurvatureAction, CurvaturePolicy, HessianForm, HessianUpdate, HessianUpdateWorkspace,
};

let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let sig4 = serde_json::json!({ "significantDigits": 4 });
// Update B₀ = I by three rules using the same difference pair s = (1, 0), y = (−2, 0) (sᵀy = −2 < 0).
let (s, y) = ([1.0_f64, 0.0], [-2.0_f64, 0.0]);
let skip = CurvaturePolicy::new(CurvatureAction::Skip, 0.2).map_err(|e| e.to_string())?;
let rules = [
    ("SR1", HessianUpdate::Sr1, [-2.0, 0.0, 0.0, 1.0]),
    (
        "BFGS (default: Powell damping η = 0.2)",
        HessianUpdate::Bfgs(CurvaturePolicy::default()),
        [0.2, 0.0, 0.0, 1.0],
    ),
    (
        "BFGS（Skip）",
        HessianUpdate::Bfgs(skip),
        [1.0, 0.0, 0.0, 1.0],
    ),
];
let mut work = HessianUpdateWorkspace::new();
work.try_reserve(2).map_err(|e| e.to_string())?;
let mut rows = Vec::new();
for (name, rule, expected) in rules {
    let mut model =
        Matrix::from_vec(2, 2, vec![1.0_f64, 0.0, 0.0, 1.0]).map_err(|e| e.to_string())?;
    let report = work
        .update(&mut model, &s, &y, HessianForm::Hessian, rule)
        .map_err(|e| e.to_string())?;
    let m = model.as_slice();
    // Independent check: difference from the hand-computed matrix, largest component of B s − y, and smallest eigenvalue of a 2×2 symmetric matrix.
    let matrix_error = m
        .iter()
        .zip(expected)
        .map(|(a, b)| (a - b).abs())
        .fold(0.0_f64, f64::max);
    let secant = (m[0] * s[0] + m[1] * s[1] - y[0])
        .abs()
        .max((m[2] * s[0] + m[3] * s[1] - y[1]).abs());
    let (mean, half) = (0.5 * (m[0] + m[3]), 0.5 * (m[0] - m[3]));
    let smallest = mean - RealScalar::sqrt(half * half + m[1] * m[2]);
    rows.push((
        name,
        format!("{report:?}"),
        m[0],
        m[3],
        matrix_error,
        secant,
        smallest,
    ));
}
let columns = serde_json::json!([
    { "key": "0", "label": "Update rule" },
    { "key": "1", "label": "Update report" },
    { "key": "2", "label": "B₁₁ [-]", "type": "number", "format": sig4 },
    { "key": "3", "label": "B₂₂ [-]", "type": "number", "format": sig4 },
    { "key": "4", "label": "Difference from hand-computed matrix [-]", "type": "number", "format": sci3 },
    { "key": "5", "label": "Largest secant residual |B s − y| [-]", "type": "number", "format": sig4 },
    { "key": "6", "label": "Smallest eigenvalue [-]", "type": "number", "format": sig4 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "updates" })
);
```

The updated SR1 matrix matches $\operatorname{diag}(-2,1)$, with zero secant residual, smallest eigenvalue $-2$, and report `Updated`.
Damped BFGS returns `Damped` and matches matrix $\operatorname{diag}(0.2,1)$ within $1.7\times10^{-16}$.
Its smallest eigenvalue 0.2 preserves positive definiteness, but its secant condition uses the modified $\bar{\mathbf{y}}$, leaving residual 2.2 against the original $\mathbf{y}$.
`Skip` returns `Skipped(Curvature)`, retaining the identity and residual 3.

## L-BFGS and curvature policy

L-BFGS stores only the latest $m$ pairs, so discarded pairs do not refresh its memory.
`Lbfgs` checks a new pair using the inverse-form criterion $\mathbf{y}^\mathsf{T}\mathbf{s} \ge \eta\,\mathbf{y}^\mathsf{T}\tilde{\mathbf{H}}\mathbf{y}$ against the matrix $\tilde{\mathbf{H}}$ that the pair will update (Nocedal–Wright, Equations 7.19 and 7.20).
$\tilde{\mathbf{H}}$ starts from the new pair's initial matrix $\gamma\mathbf{I}$ ($\gamma = \mathbf{s}^\mathsf{T}\mathbf{y}/\mathbf{y}^\mathsf{T}\mathbf{y}$) and applies BFGS updates from pairs that remain after the new pair is added ($m-1$ pairs excluding the oldest when memory is full).
The two-loop recursion reconstructs its initial matrix from the latest pair whenever it forms a direction, so the criterion uses that same matrix.
With empty memory, $\mathbf{y}^\mathsf{T}\tilde{\mathbf{H}}\mathbf{y} = \gamma\,\mathbf{y}^\mathsf{T}\mathbf{y} = \mathbf{s}^\mathsf{T}\mathbf{y}$, so pairs with $\mathbf{s}^\mathsf{T}\mathbf{y} > 0$ pass for every threshold $\eta < 1$.
For a failing pair, `Damp` modifies it to $\bar{\mathbf{s}} = \theta\mathbf{s} + (1-\theta)\tilde{\mathbf{H}}\mathbf{y}$ and stores it; `Skip` does not store it.
Pairs with $\mathbf{s}^\mathsf{T}\mathbf{y} \le 0$ fail the criterion; damping uses the currently stored approximation instead of $\tilde{\mathbf{H}}$ as its reference.

The following cell solves the same $n = 20$ quadratic (condition number $\kappa$) as the [comparison experiment](oxref:optimize-bfgs-condition), using `Bfgs` and `Lbfgs` ($m = 10$) with both `Damp` and `Skip`.
Inputs are condition number $\kappa$ and criterion threshold $\eta$.
Every pair in a convex quadratic satisfies $\mathbf{s}^\mathsf{T}\mathbf{y} = \mathbf{s}^\mathsf{T}\mathbf{A}\mathbf{s} > 0$, so preserving BFGS positive definiteness does not require discarding pairs.
Moreover, $\mathbf{y} = \mathbf{A}\mathbf{s}$ gives $\mathbf{y}^\mathsf{T}\mathbf{A}^{-1}\mathbf{y} = \mathbf{s}^\mathsf{T}\mathbf{y}$, so ratio $\mathbf{s}^\mathsf{T}\mathbf{y}/\mathbf{y}^\mathsf{T}\tilde{\mathbf{H}}\mathbf{y}$ measures how well $\tilde{\mathbf{H}}$ approximates $\mathbf{A}^{-1}$ along $\mathbf{y}$ and is 1 for an exact approximation.
The table shows termination reasons, iterations, unchanged updates, damped updates, and discarded updates for each combination.
The cell's conclusion uses the termination reason of `Lbfgs` with default action `Damp`.

```rust
//| id: optimize-lbfgs-curvature-policy
//| ref: optimize-lbfgs-curvature-policy
//| title: "Vary curvature actions and compare BFGS and L-BFGS update counts"
//| run: reactive
//| crates: [scioxide-core, scioxide-optimize]
//| inputs:
//|   condition_number: {"type":"range","label":"Hessian condition number κ [-]","description":"Vary the eigenvalue spread of the quadratic function.","min":2,"max":10000,"step":2,"value":400}
//|   threshold: {"type":"range","label":"Criterion threshold η [-]","description":"Damp or skip pairs whose observed curvature is less than η times that predicted by the matrix they update.","min":0.05,"max":0.95,"step":0.05,"value":0.2}
//| cases:
//|   - {"id":"kappa-10000","label":"κ = 10⁴","description":"At default η = 0.2, none of the four combinations damps or skips any pair, and Lbfgs has the same iteration count for Damp and Skip.","inputs":{"condition_number":10000}}
//|   - {"id":"strict-threshold","label":"κ = 10⁴, η = 0.8","description":"More pairs fail the criterion; Skip L-BFGS keeps discarding pairs and stops at the 1000-iteration limit.","inputs":{"condition_number":10000,"threshold":0.8}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"policies","path":"/rows/0/2","equals":"GradientSmall"}
//|       - {"artifact":"policies","path":"/rows/1/2","equals":"GradientSmall"}
//|       - {"artifact":"policies","path":"/rows/2/2","equals":"GradientSmall"}
//|       - {"artifact":"policies","path":"/rows/3/2","equals":"GradientSmall"}
//|       - {"artifact":"policies","path":"/rows/2/5","equals":0}
//|       - {"artifact":"policies","path":"/rows/3/6","equals":0}
//|       - {"path":"/outputs/1/state","equals":"satisfied"}
//|   - case: kappa-10000
//|     expect:
//|       - {"artifact":"policies","path":"/rows/1/6","equals":0}
//|       - {"artifact":"policies","path":"/rows/2/2","equals":"GradientSmall"}
//|       - {"artifact":"policies","path":"/rows/3/2","equals":"GradientSmall"}
//|       - {"artifact":"policies","path":"/rows/3/6","equals":0}
//|   - case: strict-threshold
//|     expect:
//|       - {"artifact":"policies","path":"/rows/1/6","equals":0}
//|       - {"artifact":"policies","path":"/rows/2/2","equals":"GradientSmall"}
//|       - {"artifact":"policies","path":"/rows/2/5","range":{"min":100,"max":1000}}
//|       - {"artifact":"policies","path":"/rows/3/2","equals":"IterationLimit"}
//|       - {"artifact":"policies","path":"/rows/3/6","range":{"min":500,"max":1000}}
//|       - {"path":"/outputs/1/state","equals":"satisfied"}
use scioxide_core::{Budget, RealScalar};
use scioxide_optimize::{
    Bfgs, BfgsOptions, CurvatureAction, CurvaturePolicy, Lbfgs, LbfgsOptions, ObjectiveFn,
    OptimizeDiagnostics, OptimizeResult,
};

// f(x) = ½ Σ λᵢ xᵢ², λᵢ = κ^{i/(n−1)} (same problem as the comparison experiment).
let n = 20_usize;
let lambda: Vec<f64> = (0..n)
    .map(|i| RealScalar::powf(condition_number, i as f64 / (n - 1) as f64))
    .collect();
let (lv, lg) = (lambda.clone(), lambda.clone());
let objective = ObjectiveFn::new(n, move |x: &[f64]| {
    Ok(0.5 * x.iter().zip(&lv).map(|(v, l)| l * v * v).sum::<f64>())
})
.with_gradient(move |x: &[f64], g: &mut [f64]| {
    for ((gi, v), l) in g.iter_mut().zip(x).zip(&lg) {
        *gi = l * v;
    }
    Ok(())
});
let start = vec![1.0_f64; n];
let memory = Budget::try_from(10).map_err(|e| e.to_string())?;
let mut rows = Vec::new();
let mut default_lbfgs = None;
for (method, name) in ["Bfgs", "Lbfgs"].into_iter().enumerate() {
    for (action, label) in [
        (CurvatureAction::Damp, "Damp"),
        (CurvatureAction::Skip, "Skip"),
    ] {
        let policy = CurvaturePolicy::new(action, threshold).map_err(|e| e.to_string())?;
        let result: OptimizeResult<f64> = if method == 0 {
            Bfgs::new(BfgsOptions::default().with_curvature_policy(policy))
                .minimize(&objective, &start)
        } else {
            let options = LbfgsOptions::default().with_memory(memory);
            Lbfgs::new(options.with_curvature_policy(policy)).minimize(&objective, &start)
        }
        .map_err(|e| e.to_string())?;
        let OptimizeDiagnostics::FirstOrder(d) = result.method_diagnostics() else {
            return Err("No first-order diagnostics".into());
        };
        rows.push((
            name,
            label,
            result.termination().to_string(),
            result.iterations(),
            d.updates(),
            d.damped_updates(),
            d.skipped_updates(),
        ));
        if method == 1 && action == CurvatureAction::Damp {
            default_lbfgs = Some(result);
        }
    }
}
let columns = serde_json::json!([
    { "key": "0", "label": "Method" },
    { "key": "1", "label": "Action" },
    { "key": "2", "label": "Termination reason" },
    { "key": "3", "label": "Iterations [count]", "type": "integer" },
    { "key": "4", "label": "Unchanged updates [count]", "type": "integer" },
    { "key": "5", "label": "Damped updates [count]", "type": "integer" },
    { "key": "6", "label": "Discarded updates [count]", "type": "integer" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "policies" })
);
// Use the termination reason of L-BFGS with default action (Damp) as the cell's conclusion.
let result = default_lbfgs.ok_or("Missing L-BFGS result")?;
let outcome = if result.is_success() {
    Outcome::satisfied("Damp L-BFGS gradient norm fell below tolerance")
} else {
    Outcome::partial("Damp L-BFGS stopped at a limit and returned its last accepted point")
};
emit_outcome!(outcome.status(result.termination().to_string()).diagnostic(
    "Iterations",
    result.iterations() as f64,
    None
));
```

At the defaults $\kappa = 400$ and $\eta = 0.2$, no combination damps or skips any pair; `Bfgs` uses all 94 updates unchanged and `Lbfgs` all 157 updates unchanged, reaching `GradientSmall`.
Actions affect only failing pairs, so `Damp` and `Skip` produce identical iterations.
The same holds at $\kappa = 10^4$: `Lbfgs` stops after 758 iterations and `Bfgs` after 139 with either action.
Raising the threshold to $\eta = 0.8$ makes many pairs fail for `Lbfgs` with $\kappa = 10^4$.
`Damp` damps 360 pairs in 785 iterations and reaches `GradientSmall`, while `Skip` discards 904 pairs, barely refreshes its memory, and stops at the 1000-iteration limit with `IterationLimit`.
`Bfgs` never modifies a pair even at this $\eta$.
When using `Skip` or large $\eta$ in L-BFGS, inspect the proportions of `skipped_updates()` and `damped_updates()` together with the termination reason.

## Summary

By default BFGS applies Powell damping to pairs whose observed curvature is below $\eta$ times the approximation's prediction (default 0.2); `CurvatureAction::Skip` discards them.
Read pair handling from `HessianUpdateReport` and `UpdateSkipReason`, or aggregate iteration counts in `GlobalizationDiagnostics`.
Use `HessianUpdateWorkspace` to update caller-owned matrices; account for up to $O(n^3)$ work to check positive definiteness in BFGS.
SR1 represents indefinite curvature but does not guarantee a descent direction, so combine it with trust-region methods.
L-BFGS tests a new pair against the matrix it will update; discarded pairs do not refresh memory, so reconsider the action and threshold when the discarded fraction is large.
