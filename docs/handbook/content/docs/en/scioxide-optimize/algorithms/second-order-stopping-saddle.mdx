A zero-gradient point need not be a local minimum; saddles and local maxima also meet the gradient criterion.
This page explains the criterion when second-order stopping is enabled in `SteihaugCg` of `TrustRegionOptimizer` and the trials that escape saddle points.
Subproblem solution follows [truncated conjugate gradients and negative curvature](../truncated-cg-trust-region/); acceptance-ratio and radius rules follow [acceptance ratio and radius updates](oxref:optimize-trust-region-ratio).

## Second-order criterion through inertia

The gradient criterion is first order, so even zero-gradient saddles and local maxima stop with `GradientSmall`.
Setting `second_order_stopping` of `SteihaugCg` to `true` factors a dense Hessian by symmetric indefinite LDLᵀ at small-gradient points and examines its inertia.
With no negative eigenvalues, the method stops with `Converged` and sets `NewtonDiagnostics::second_order_checked()` to `true`.
With negative eigenvalues, it constructs a negative-curvature direction $\mathbf{v}$ ($\mathbf{v}^\mathsf{T}\mathbf{B}\mathbf{v}<0$) from a negative pivot block, orients it so that $\mathbf{g}^\mathsf{T}\mathbf{v}\le0$, and proposes a radius-length step along it.
If checking this direction's curvature against the original matrix does not give negative curvature, it returns a `NumericalInstability` (`Breakdown`) error.

Zero eigenvalues are not counted as negative, so a degenerate stationary point with a positive semidefinite Hessian can also give `Converged`.
A dense Hessian is required; even with an analytic Hessian, objectives with `has_hessian_vector_product` equal to `true` are rejected with `InvalidInput` (`UnsupportedConfiguration`).
This setting initializes the radius to $\max(\|\mathbf{g}_0\|,1)$, ensuring at least radius 1 even from a zero-gradient point.

## Saddle point of a double well

The following cell seeks stable particle positions in $V(x,y)=x^4/4-x^2/2+y^2/2$ (dimensionless), combining a double well and a transverse harmonic potential.
$(0,0)$ is a saddle (Hessian $\operatorname{diag}(-1,1)$); $(\pm1,0)$ are local minima with $V=-1/4$.
The starting point is $(x_0,0.5)$; the input is displacement $x_0$ from symmetry axis $x=0$.
At $x_0=0$, the gradient's $x$ component always vanishes, so gradient-only iteration stays on the symmetry axis and heads toward the saddle.
Compare dogleg, `SteihaugCg`, and `SteihaugCg` with second-order stopping, independently computing the smallest eigenvalue of analytic Hessian $\operatorname{diag}(3x^2-1,1)$ at the final point.
Finally, report the second-order run's termination reason as the computation outcome.

```rust
//| id: optimize-trust-second-order-saddle
//| ref: optimize-trust-second-order-saddle
//| title: "Compare first-order stopping at a saddle with second-order escape along negative curvature"
//| run: reactive
//| crates: [scioxide-core, scioxide-linalg, scioxide-optimize]
//| inputs:
//|   offset: {"type":"range","label":"Displacement from symmetry axis x₀ [-]","description":"The x component of starting point (x₀, 0.5). At 0 the gradient's x component vanishes.","min":0,"max":0.2,"step":0.01,"value":0}
//| cases:
//|   - {"id":"off-axis","label":"x₀ = 0.1","description":"Symmetry is broken and every method reaches local minimum (1, 0).","inputs":{"offset":0.1}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"methods","path":"/rows/0/1","equals":"GradientSmall"}
//|       - {"artifact":"methods","path":"/rows/0/7","approx":{"value":-1.0,"atol":1e-9}}
//|       - {"artifact":"methods","path":"/rows/1/7","approx":{"value":-1.0,"atol":1e-9}}
//|       - {"artifact":"methods","path":"/rows/2/1","equals":"Converged"}
//|       - {"artifact":"methods","path":"/rows/2/2","approx":{"value":1.0,"atol":1e-6}}
//|       - {"artifact":"methods","path":"/rows/2/6","equals":"Available"}
//|       - {"artifact":"methods","path":"/rows/2/7","approx":{"value":1.0,"atol":1e-5}}
//|       - {"path":"/outputs/1/state","equals":"satisfied"}
//|   - case: off-axis
//|     expect:
//|       - {"artifact":"methods","path":"/rows/0/2","approx":{"value":1.0,"atol":1e-6}}
//|       - {"artifact":"methods","path":"/rows/1/2","approx":{"value":1.0,"atol":1e-6}}
//|       - {"path":"/outputs/1/state","equals":"satisfied"}
use scioxide_core::Budget;
use scioxide_linalg::Matrix;
use scioxide_optimize::{
    ObjectiveFn, OptimizeDiagnostics, OptimizeResult, TrustRegionOptimizer, TrustRegionOptions,
    TrustRegionSubproblem,
};

// V(x, y) = x⁴/4 − x²/2 + y²/2. (0, 0) is a saddle and (±1, 0) are local minima.
let potential = ObjectiveFn::new(2, |p: &[f64]| {
    Ok(0.25 * p[0] * p[0] * p[0] * p[0] - 0.5 * p[0] * p[0] + 0.5 * p[1] * p[1])
})
.with_gradient(|p: &[f64], g: &mut [f64]| {
    g[0] = p[0] * p[0] * p[0] - p[0];
    g[1] = p[1];
    Ok(())
})
.with_hessian(|p: &[f64], h: &mut Matrix<f64>| {
    h.as_mut_slice()
        .copy_from_slice(&[3.0 * p[0] * p[0] - 1.0, 0.0, 0.0, 1.0]);
    Ok(())
});
let inner = Budget::try_from(20).map_err(|e| e.to_string())?;
let solve = |subproblem: TrustRegionSubproblem| -> Result<OptimizeResult<f64>, String> {
    TrustRegionOptimizer::new(TrustRegionOptions::default().with_subproblem(subproblem))
        .minimize(&potential, &[offset, 0.5])
        .map_err(|e| e.to_string())
};
let dogleg = solve(TrustRegionSubproblem::Dogleg)?;
let first_order = solve(TrustRegionSubproblem::SteihaugCg {
    max_inner_iterations: inner,
    second_order_stopping: false,
})?;
let second_order = solve(TrustRegionSubproblem::SteihaugCg {
    max_inner_iterations: inner,
    second_order_stopping: true,
})?;
let mut rows = Vec::new();
for (name, run) in [
    ("Dogleg", &dogleg),
    ("SteihaugCg", &first_order),
    ("SteihaugCg (second-order stopping)", &second_order),
] {
    let OptimizeDiagnostics::Newton(diag) = run.method_diagnostics() else {
        return Err("Missing diagnostics for this algorithm".to_string());
    };
    let x = run.x();
    // Independent check: smallest eigenvalue of analytic Hessian diag(3x² − 1, 1) at the final point.
    let lowest = (3.0 * x[0] * x[0] - 1.0).min(1.0);
    rows.push((
        name,
        run.termination().to_string(),
        x[0],
        x[1],
        run.fun(),
        run.iterations(),
        if diag.second_order_checked() {
            "Available"
        } else {
            "None"
        },
        lowest,
    ));
}
let general = serde_json::json!({ "significantDigits": 6 });
let columns = serde_json::json!([
    { "key": "0", "label": "Method" },
    { "key": "1", "label": "Termination reason" },
    { "key": "2", "label": "x [-]", "type": "number", "format": general },
    { "key": "3", "label": "y [-]", "type": "number", "format": general },
    { "key": "4", "label": "V [-]", "type": "number", "format": general },
    { "key": "5", "label": "Iterations [count]", "type": "integer" },
    { "key": "6", "label": "Curvature check" },
    { "key": "7", "label": "Smallest Hessian eigenvalue [-]", "type": "number", "format": general }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "methods" })
);
let termination = second_order.termination();
let outcome = if termination.is_success() {
    Outcome::satisfied("Confirmed no negative Hessian eigenvalues at a small-gradient point")
} else {
    Outcome::partial("Stopped before meeting second-order stopping")
};
emit_outcome!(
    outcome
        .status(termination.to_string())
        .diagnostic("x", second_order.x()[0], None)
        .diagnostic("V", second_order.fun(), None)
);
```

At default $x_0=0$, dogleg and `SteihaugCg` both reach saddle $(0,0)$ in 1 iteration and stop with `GradientSmall`.
The starting gradient is $(0,0.5)$, so the first trial moves only $y$ and reaches a point with zero gradient.
The final Hessian's smallest eigenvalue is $-1$; this point is not a local minimum but the gradient-only criterion reports success.
The second-order run finds a negative eigenvalue at the saddle, moves radius 1 along $x$, reaches local minimum $(1,0)$ with $V=-0.25$ in 2 iterations, and terminates with `Converged` (smallest eigenvalue 1).
At $x_0=0.1$ symmetry is broken and all three methods reach $(1,0)$.

## Summary

The gradient criterion is first order, so `GradientSmall` reports success even at a zero-gradient saddle.
`SteihaugCg` with `second_order_stopping` enabled examines dense Hessian inertia at small-gradient points and takes a radius-length step along negative curvature if negative eigenvalues exist.
With no negative eigenvalues, it returns `Converged` and sets `second_order_checked()` to `true`.
Since this criterion does not count zero eigenvalues as negative, independently check final curvature at degenerate stationary points with positive semidefinite Hessians.
Starting on the symmetry plane of a symmetric problem can send gradient-only iteration toward a saddle; enable second-order stopping or compare shifted starting points.
