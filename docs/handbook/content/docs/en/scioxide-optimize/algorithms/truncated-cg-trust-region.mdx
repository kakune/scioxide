[Dogleg trust regions](oxref:optimize-trust-region-dogleg) factor a dense Hessian by Cholesky, requiring $O(n^2)$ memory and $O(n^3)$ work per iteration for many variables.
When a Hessian–vector product (HVP) costs about $O(n)$, approximately solving the subproblem with conjugate gradients avoids forming the matrix.
`TrustRegionOptimizer` with `TrustRegionSubproblem::SteihaugCg` uses Steihaug truncated conjugate gradients for this purpose.
This page explains its procedure, termination, and HVP-only workspace.
Second-order stopping to avoid zero-gradient saddles is covered in [second-order stopping and saddle points](../second-order-stopping-saddle/).
Notation follows [Newton and trust-region methods](../newton-and-trust-region/): $\mathbf{B}_k$ is the model matrix and $\Delta_k$ the trust radius.

## Steihaug truncated conjugate gradients

For subproblem $\min_{\|\mathbf{p}\|\le\Delta_k}\ \mathbf{g}_k^\mathsf{T}\mathbf{p}+\tfrac12\mathbf{p}^\mathsf{T}\mathbf{B}_k\mathbf{p}$, apply conjugate gradients to $\mathbf{B}_k\mathbf{p}=-\mathbf{g}_k$ starting at $\mathbf{p}_0=\mathbf{0}$.
Using residual $\mathbf{r}_j=\mathbf{B}_k\mathbf{p}_j+\mathbf{g}_k$ and search direction $\mathbf{d}_j$ ($\mathbf{d}_0=-\mathbf{r}_0=-\mathbf{g}_k$), each iteration proceeds as follows.

1. Compute curvature $\kappa_j=\mathbf{d}_j^\mathsf{T}\mathbf{B}_k\mathbf{d}_j$ with one HVP.
   If $\kappa_j\le0$, stop where $\mathbf{p}_j+t\,\mathbf{d}_j$ ($t\ge0$) meets the sphere (`NegativeCurvature`).
2. Set $\alpha_j=\mathbf{r}_j^\mathsf{T}\mathbf{r}_j/\kappa_j$; if $\|\mathbf{p}_j+\alpha_j\mathbf{d}_j\|\ge\Delta_k$, stop at the intersection of the same line and sphere (`Boundary`).
3. Update $\mathbf{p}_{j+1}=\mathbf{p}_j+\alpha_j\mathbf{d}_j$ and $\mathbf{r}_{j+1}=\mathbf{r}_j+\alpha_j\mathbf{B}_k\mathbf{d}_j$; stop if $\|\mathbf{r}_{j+1}\|/\|\mathbf{g}_k\|\le\eta_k$ (`ResidualSmall`).
4. Set $\beta_j=\|\mathbf{r}_{j+1}\|^2/\|\mathbf{r}_j\|^2$ and $\mathbf{d}_{j+1}=-\mathbf{r}_{j+1}+\beta_j\mathbf{d}_j$, and return to step 1.

The tolerance is $\eta_k=\max(\sqrt{\varepsilon_{\mathrm{mach}}},\min(0.1,\sqrt{\|\mathbf{g}_k\|}))$.
When inner iterations reach `max_inner_iterations`, use the current $\mathbf{p}_j$ directly as the trial step (`IterationLimit`).
These four stopping cases are `NewtonCgTermination` values; read the last subproblem's termination from `NewtonDiagnostics::cg_termination()` and product count from `cg_iterations()`.
Runs such as dogleg that do not use conjugate gradients for subproblems return `NotRun`.
`NewtonCgTermination` describes only the inner solve; overall minimization termination is returned separately by `OptimizeTermination`.

While curvature stays positive, conjugate-gradient iterate norms $\|\mathbf{p}_j\|$ strictly increase and model values decrease monotonically (Nocedal–Wright, Theorem 7.3).
Thus stopping at the boundary when a step would exceed the radius never gives a model value above preceding iterates.
The first iteration minimizes along $-\mathbf{g}_k$, so the resulting step reduces the model at least as much as the Cauchy point.
This gives the outer iterations the same global convergence results as dogleg (Nocedal–Wright, Theorems 4.5 and 4.6).
Near a solution where the model is positive definite and steps fit inside the radius, $\eta_k$ approaches 0 with $\sqrt{\|\mathbf{g}_k\|}$, giving superlinear outer convergence (inexact Newton results, Nocedal–Wright, Section 7.1).

Each inner iteration uses one HVP and $O(n)$ vector operations.
Outer acceptance, radius, and stopping rules follow [acceptance ratio and radius updates](oxref:optimize-trust-region-ratio).

## Using only Hessian–vector products

For a closure objective, pass to `ObjectiveFn::with_hessian_vector_product` a `(&[S], &[S], &mut [S])` closure receiving direction $\mathbf{d}$ and writing product $\nabla^2 f(\mathbf{x})\,\mathbf{d}$ to the output.
When implementing `ObjectiveFunction` yourself, implement `hessian_vector_product_into` and make `has_hessian_vector_product` return `true`.
When the objective provides HVP, `SteihaugCg` forms no dense Hessian and computes predicted reduction for the acceptance ratio using the same HVP.
Without HVP, it constructs a dense matrix from an analytic Hessian or differences of gradients and uses matrix–vector products.

Request objective-specific workspace through `TrustRegionWorkspaceRequest::of(&f)`.
Combining `SteihaugCg` with an HVP objective makes `TrustRegionOptimizerWorkspaceRequirements::dense()` equal `false`; the workspace contains no dense Hessian.
`TrustRegionWorkspaceRequest::dense(n)` requests workspace with a dense Hessian; dogleg always uses it.
Pass a `TrustRegionOptimizerWorkspace` constructed by `TrustRegionOptimizer::workspace(request)` to `minimize_into` to resolve same-size problems without reallocating memory.

The next cell finds equilibrium of a string fixed at both ends, supported by a hardening foundation (restoring force proportional to displacement cubed), under uniform load.
Its nondimensionalized energy is

$$
f(\mathbf{x})=\frac12\sum_{i=0}^{n}(x_{i+1}-x_i)^2+\sum_{i=1}^{n}\frac{x_i^4}{4}-\sum_{i=1}^{n}x_i,\qquad x_0=x_{n+1}=0
$$

and the Hessian is tridiagonal $\mathbf{L}+\operatorname{diag}(3x_i^2)$.
HVP $(\mathbf{L}+\operatorname{diag}(3x_i^2))\mathbf{d}$ costs $O(n)$; the Hessian is positive definite everywhere, giving a unique minimizer.
Inputs are node count $n$ and inner iteration limit, with starting point $\mathbf{x}=\mathbf{0}$.
Compare `SteihaugCg` (HVP only) with dogleg supplied the same problem's dense Hessian; use the difference between solutions and the largest gradient component recomputed at the solution as independent checks.
Finally, report `SteihaugCg`'s termination reason as the computation outcome.

```rust
//| id: optimize-trust-steihaug-matrix-free
//| ref: optimize-trust-steihaug-matrix-free
//| title: "Solve string equilibrium using Hessian–vector products only"
//| run: reactive
//| crates: [scioxide-core, scioxide-linalg, scioxide-optimize]
//| inputs:
//|   nodes: {"type":"range","label":"Nodes n [count]","description":"Change variable count and thus dense Hessian storage and factorization work.","min":10,"max":300,"step":10,"value":100}
//|   inner_limit: {"type":"range","label":"Inner iteration limit [count]","description":"Change the HVP limit per subproblem. One iteration gives only the Cauchy point.","min":1,"max":40,"step":1,"value":40}
//| cases:
//|   - {"id":"cauchy-only","label":"1 inner iteration","description":"Every subproblem stops at the Cauchy point, increasing outer iterations.","inputs":{"inner_limit":1}}
//|   - {"id":"small","label":"n = 10","description":"With few variables, even a dense Hessian needs only 100 stored values.","inputs":{"nodes":10}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"methods","path":"/rows/0/1","equals":"None"}
//|       - {"artifact":"methods","path":"/rows/1/1","equals":"Available"}
//|       - {"artifact":"methods","path":"/rows/0/2","equals":"GradientSmall"}
//|       - {"artifact":"methods","path":"/rows/0/6","equals":"ResidualSmall"}
//|       - {"artifact":"methods","path":"/rows/0/7","range":{"min":0,"max":1e-6}}
//|       - {"artifact":"check","path":"/rows/0/0","range":{"min":0,"max":1e-6}}
//|       - {"artifact":"check","path":"/rows/0/1","approx":{"value":1.0,"atol":1e-6}}
//|       - {"path":"/outputs/2/state","equals":"satisfied"}
//|   - case: cauchy-only
//|     expect:
//|       - {"artifact":"methods","path":"/rows/0/5","equals":1}
//|       - {"artifact":"methods","path":"/rows/0/6","equals":"IterationLimit"}
//|       - {"artifact":"methods","path":"/rows/0/3","range":{"min":10,"max":30}}
//|       - {"path":"/outputs/2/state","equals":"satisfied"}
use scioxide_core::{Budget, ExecutionContext};
use scioxide_linalg::Matrix;
use scioxide_optimize::{
    ObjectiveFn, OptimizeDiagnostics, OptimizeResult, TrustRegionOptimizer, TrustRegionOptions,
    TrustRegionSubproblem, TrustRegionWorkspaceRequest,
};

let n = nodes as usize;
// Energy ½Σ(x_{i+1} − x_i)² + Σ x_i⁴/4 − Σ x_i (fixed ends x_0 = x_{n+1} = 0).
let energy = |x: &[f64]| -> Result<f64, scioxide_core::SciOxideError> {
    let mut total = 0.0;
    for i in 0..=x.len() {
        let left = if i > 0 { x[i - 1] } else { 0.0 };
        let right = if i < x.len() { x[i] } else { 0.0 };
        total += 0.5 * (right - left) * (right - left);
    }
    Ok(total + x.iter().map(|&v| 0.25 * v * v * v * v - v).sum::<f64>())
};
// Gradient (L x)_i + x_i³ − 1.
let gradient = |x: &[f64], g: &mut [f64]| -> Result<(), scioxide_core::SciOxideError> {
    for i in 0..x.len() {
        let left = if i > 0 { x[i - 1] } else { 0.0 };
        let right = if i + 1 < x.len() { x[i + 1] } else { 0.0 };
        g[i] = 2.0 * x[i] - left - right + x[i] * x[i] * x[i] - 1.0;
    }
    Ok(())
};
// Write HVP (L + diag(3x²)) d in O(n).
let product = |x: &[f64], d: &[f64], out: &mut [f64]| -> Result<(), scioxide_core::SciOxideError> {
    for i in 0..x.len() {
        let left = if i > 0 { d[i - 1] } else { 0.0 };
        let right = if i + 1 < x.len() { d[i + 1] } else { 0.0 };
        out[i] = 2.0 * d[i] - left - right + 3.0 * x[i] * x[i] * d[i];
    }
    Ok(())
};
let matrix_free = ObjectiveFn::new(n, energy)
    .with_gradient(gradient)
    .with_hessian_vector_product(product);
// Comparison: supply the same Hessian as an n × n dense matrix.
let dense = ObjectiveFn::new(n, energy)
    .with_gradient(gradient)
    .with_hessian(|x: &[f64], h: &mut Matrix<f64>| {
        let n = x.len();
        let entries = h.as_mut_slice();
        entries.fill(0.0);
        for i in 0..n {
            entries[i * n + i] = 2.0 + 3.0 * x[i] * x[i];
            if i + 1 < n {
                entries[i * n + i + 1] = -1.0;
                entries[(i + 1) * n + i] = -1.0;
            }
        }
        Ok(())
    });
let inner = Budget::try_from(inner_limit as usize).map_err(|e| e.to_string())?;
let steihaug = TrustRegionOptimizer::new(TrustRegionOptions::default().with_subproblem(
    TrustRegionSubproblem::SteihaugCg {
        max_inner_iterations: inner,
        second_order_stopping: false,
    },
));
let request = TrustRegionWorkspaceRequest::of(&matrix_free);
let stores_dense = steihaug
    .workspace_requirements(request)
    .map_err(|e| e.to_string())?
    .dense();
let mut workspace = steihaug.workspace(request).map_err(|e| e.to_string())?;
let mut result = OptimizeResult::empty();
let start = vec![0.0; n];
steihaug
    .minimize_into(
        &matrix_free,
        &start,
        &mut result,
        &mut workspace,
        ExecutionContext::sequential(),
    )
    .map_err(|e| e.to_string())?;
let dogleg = TrustRegionOptimizer::<f64>::default();
let dogleg_dense = dogleg
    .workspace_requirements(TrustRegionWorkspaceRequest::of(&dense))
    .map_err(|e| e.to_string())?
    .dense();
let reference = dogleg.minimize(&dense, &start).map_err(|e| e.to_string())?;

// Independent check: recompute the gradient at the returned point and read its largest component.
let residual = |x: &[f64]| -> Result<f64, String> {
    let mut g = vec![0.0; x.len()];
    gradient(x, &mut g).map_err(|e| e.to_string())?;
    Ok(g.iter().fold(0.0_f64, |m, v| m.max(v.abs())))
};
let mut rows = Vec::new();
for (name, stored, run) in [
    ("SteihaugCg (HVP only)", stores_dense, &result),
    ("Dogleg (dense)", dogleg_dense, &reference),
] {
    let OptimizeDiagnostics::Newton(diag) = run.method_diagnostics() else {
        return Err("Missing diagnostics for this algorithm".to_string());
    };
    rows.push((
        name,
        if stored { "Available" } else { "None" },
        run.termination().to_string(),
        run.iterations(),
        run.fun_evals(),
        diag.cg_iterations(),
        format!("{:?}", diag.cg_termination()),
        residual(run.x())?,
    ));
}
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let columns = serde_json::json!([
    { "key": "0", "label": "Method" },
    { "key": "1", "label": "Dense Hessian" },
    { "key": "2", "label": "Termination reason" },
    { "key": "3", "label": "Outer iterations [count]", "type": "integer" },
    { "key": "4", "label": "Objective evaluations [count]", "type": "integer" },
    { "key": "5", "label": "Last subproblem HVPs [count]", "type": "integer" },
    { "key": "6", "label": "Last subproblem termination" },
    { "key": "7", "label": "Largest gradient component (recomputed) [-]", "type": "number", "format": sci3 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "methods" })
);
let difference = result
    .x()
    .iter()
    .zip(reference.x())
    .fold(0.0_f64, |m, (a, b)| m.max((a - b).abs()));
let check_columns = serde_json::json!([
    { "key": "0", "label": "Largest solution difference [-]", "type": "number", "format": sci3 },
    {
        "key": "1",
        "label": "Central displacement x_{n/2} [-]",
        "type": "number",
        "format": { "significantDigits": 8 }
    }
]);
emit_table_with_columns!(
    check_columns,
    vec![(difference, result.x()[n / 2])],
    metadata = serde_json::json!({ "id": "check" })
);
let termination = result.termination();
let outcome = if termination.is_success() {
    Outcome::satisfied("Gradient fell below the stopping threshold")
} else {
    Outcome::partial("Stopped before meeting the gradient criterion")
};
emit_outcome!(
    outcome
        .status(termination.to_string())
        .diagnostic("Outer iterations", result.iterations() as f64, None)
        .diagnostic("Largest solution difference", difference, None)
);
```

At default $n=100$ and inner limit 40, `SteihaugCg` reaches `GradientSmall` in 6 outer iterations (7 objective evaluations); its final subproblem stops with `ResidualSmall` after 4 HVPs.
Its workspace has no dense Hessian; dogleg stores an $100\times100$ matrix and stops after 5 iterations.
The largest solution difference is $2.2\times10^{-9}$; the largest gradient component recomputed at the `SteihaugCg` solution is $1.0\times10^{-8}$.
Near the string center, neighboring displacements are almost equal and equilibrium approaches $x^3=1$, agreeing with central displacement 1.
An inner limit of 1 stops each subproblem at its Cauchy point (`IterationLimit`, 1 HVP), increasing outer iterations to 16.
At $n=300$, `SteihaugCg` still needs 6 outer iterations, whereas dogleg factors an $300\times300$ matrix by Cholesky at each iteration.

## Summary

Steihaug truncated conjugate gradients stops conjugate gradients on $\mathbf{B}_k\mathbf{p}=-\mathbf{g}_k$ at negative curvature, the radius boundary, or the residual criterion and uses that point as the trial step.
The first inner iteration gives the Cauchy point, so truncation still reduces the model at least as much as that point; outer acceptance and radius rules match dogleg.
When the objective provides HVP, `SteihaugCg` forms no dense Hessian, and workspace requested through `TrustRegionWorkspaceRequest::of(&f)` has `dense()` equal to `false`.
Smaller inner limits move subproblems toward the Cauchy point and increase outer iterations; choose the limit by balancing HVP work against outer iteration count.
Check solutions against another method and a gradient recomputed at the returned point.
