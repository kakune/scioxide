This table collects local solvers with nonlinear equalities $h(x)=0$, inequalities $g(x)\le0$, and variable bounds, plus their options, workspace, and diagnostics.
Register constraints in `Constraints` (equalities first, then inequalities; intersect multiple bound sets componentwise).
Borrow objectives and constraints together through `ConstrainedProblem::new(&objective, &constraints)` and pass them to each solver's `minimize` / `minimize_into`.
For one default SQP solve, `minimize_constrained(f, x0, &constraints)` accepts a value closure, initial point, and `Constraints`, returning structured errors without success.
The inherent `minimize` returns unsuccessful termination in an `Ok` result; `Optimizer` provides the same call.
Option types do not contain constraints.
An empty bound intersection is rejected before evaluation by `Constraints::bounds` with `InvalidInput`.
`ConstrainedProblem::new` returns `DimensionMismatch` for objective/constraint dimension mismatch or `InvalidInput` for an objective-owned box.
All solvers return `DimensionMismatch` for wrong initial dimensions, `NonFinite` for nonfinite starts, user function errors unchanged, and `CapabilityUnavailable` for configured time limits without an execution-context clock.
Iteration, evaluation, or time limits, stagnation, and cancellation return an `Ok` result with an `OptimizeTermination` termination reason when an accepted point exists.
`is_success()` is true only when original KKT residuals (primal feasibility, stationarity, dual feasibility, complementarity) meet `OptimalityTolerances`; COBYLA and COBYQA instead test trust radius and model-based stationarity measures.
Extract method observations from `OptimizeDiagnostics` variants (`FirstOrder`, `Sqp`, `InteriorPoint`, `Cobyla`, `Cobyqa`) returned by `OptimizeResult::method_diagnostics()`.
Constraint representations and results are in [shared objective, constraint, and result contracts](../problems-and-results/); inner BFGS is in [local methods](../local-methods/).

## Penalty and augmented Lagrangian methods

Both solvers share the same outer iteration.
Each outer iteration minimizes an objective augmented by constraint violation using inner `Bfgs` and increases penalty parameter $\mu$ (initially 1) tenfold according to feasibility progress.
Insufficient feasibility improvement triggers a restoration subproblem reducing only constraint violation.
Bounds are inequality rows, so iterates can leave the box before convergence.

## Sequential quadratic programming (SQP)

At each iteration, `Sqp` forms a subproblem from a quadratic objective model and linearized constraints, accepting its solution by $\ell_1$ merit backtracking (Armijo coefficient $10^{-4}$, step halving, at most 40 trials).
With nonlinear constraints, rejection of the first trial triggers one second-order correction; continued rejection enters feasibility restoration.
Damped BFGS updates the Lagrangian Hessian approximation.
The initial point is projected into the box, and every later observation remains inside.

## SQP subproblems and replacement

Subproblems solve $\min_d\ \tfrac12 d^\mathsf{T}Hd+g^\mathsf{T}d$ or $\tfrac12\lVert Ad-b\rVert^2$ under linearized constraints and displacement bounds.
The default provider is `DenseSqpSubproblem`.
For built-in or replacement providers, proposals returned as `Converged` are independently checked against subproblem KKT conditions by the outer solver before use.
Checks cover shapes, finiteness, multiplier signs, linearized and displacement-bound feasibility, complementarity, and stationarity; failures are treated as `Stagnation`.

## Nonlinear primal-dual interior points

`InteriorPoint` introduces slack and dual variables for inequalities and bounds, moving primal and dual variables together along KKT Newton directions as barrier parameter $\mu$ decreases.
The initial point may be infeasible; violation above tolerance first triggers feasibility restoration (Phase I).
The barrier parameter starts at 0.1 with inequalities or bounds (otherwise 0) and decreases by factor 0.2 when barrier error is at most $10\mu$.
Its floor is 0.1 times the smallest feasibility, stationarity, or complementarity threshold.
Unexpected KKT inertia adds regularization; failed merit backtracking and second-order correction trigger restoration.
Restoration failure stops with `Stagnation`.
Supply exact curvature through `ConstrainedProblem::with_lagrangian_hessian`; otherwise damped BFGS is used.

## Derivative-free constrained methods (COBYLA and COBYQA)

Both solvers use only objective and constraint values, building models from interpolation sets and choosing steps inside trust regions.
COBYLA uses linear interpolation at $d+1$ points; COBYQA uses minimum-Frobenius-norm quadratic interpolation at $2d+1$ points ($d$ is the number of variables not fixed by the box).
A trial is accepted when the objective plus penalty-weighted constraint violation (merit function) actually decreases; actual/predicted reduction controls radius contraction or expansion.
`Converged` requires interpolation spacing (resolution `resolution()`) at the final radius, trust radius at most 1.5 times resolution, feasible center, poised interpolation geometry (uniquely determining a model) passing rank checks, and model stationarity below a threshold combining resolution and rounding.
COBYLA also uses a linear-model step shorter than half the resolution as an alternative stationarity measure.
If the box fixes every variable, a feasible projected start gives `Converged` and otherwise `Stagnation`.
This criterion does not establish derivative-based stationarity.
Bounds hold for every observation; nonlinear feasibility is checked at accepted centers.
Results contain no gradient.

## KKT factorization providers

`InteriorPoint` and the [linear and quadratic programming](../linear-and-quadratic-programming/) solvers `InteriorPointLp` and `QpSolver` replace symmetric augmented-system (KKT) factorization and solution through this interface.
Replace providers with each workspace's `with_kkt_provider`.
The default SQP subproblem `DenseSqpSubproblem` uses `DenseKktProvider` internally.
Successful factorization does not guarantee solution accuracy, so solvers independently check residuals.

## Summary

Choose solvers by constraint form and derivative availability.
Use `Sqp` or `InteriorPoint` with derivatives and mixed bounds and nonlinear constraints; use `AugmentedLagrangian` or `PenaltyMethod` to proceed from infeasible starts using only inner BFGS; use `Cobyla` or `Cobyqa` with function values alone.
For every method, `Ok` does not imply success; inspect `termination()` and `is_success()`, and interpret KKT residuals in `diagnostics()` separately from observations in method-specific variants of `method_diagnostics()`.
Inspect `SqpDiagnostics::multipliers_ambiguous` and inertia for multiplier uniqueness; do not treat COBYLA or COBYQA model stationarity as proof of derivative-based stationarity.
Use `minimize_constrained` for one default SQP solve with errors for unsuccessful termination.
Prepare and reuse method-specific workspace for repeated same-shaped problems.
