This table collects nonlinear least squares minimizing objectives of form $\tfrac12\sum_i w_i\,\rho(\cdot)$ from residual vector $r(x)$, linear least squares $\tfrac12\lVert Ax-b\rVert^2$ with nonnegativity or bounds, and optimization adapters for scioxide-stats fitting.
Nonlinear least-squares objectives (`cost`) include weights and losses with factor $\tfrac12$.
Supply residual problems through `LeastSquaresProblem` or closure wrapper `LeastSquaresFn`, listed in [shared objective, constraint, and result contracts](../problems-and-results/).
Solvers and functions accepting initial points give `DimensionMismatch` for dimension mismatch, `NonFinite` for nonfinite starts, and propagate user errors unchanged.
Iteration limits or stagnation after initial acceptance return termination in an `Ok` result; determine success through `is_success()`.
Default one-shot functions `least_squares`, `curve_fit`, `nnls`, and `bvls` return the same structured errors as result `require_success()` for unsuccessful termination.

## Nonlinear least-squares solvers and workspace

One type, `LeastSquares`, switches by settings between two `LeastSquaresGlobalization` variants: `GaussNewton` (step backtracking) and `LevenbergMarquardt` (trust-region damping).
They share rank-aware linearization, losses, and stopping; step safeguards and trial acceptance differ.
With default `OriginalGradient`, both globalizations stop successfully with `GradientSmall` when accepted gradient $J^\mathsf{T}r$ (original units including weights and losses) has norm at or below the gradient threshold of `LeastSquaresOptions`.
Explicit `Minpack` replaces this gradient check with other convergence criteria and returns `Converged`, without necessarily making the original gradient small.
Small displacement alone gives `StepSmall` and no acceptable trial gives `Stagnation`; neither is success.
Accepted parameters and residuals update together, so rejected or failed trials never partially modify accepted state.

## Nonnegative and bounded linear least squares

Solve $\min\tfrac12\lVert Ax-b\rVert^2$ using `Nnls` under $x\ge0$ or `BoundedLinearLeastSquares` under arbitrary bounds.
Both use active sets, distinguish bound and free components, and recompute original-coordinate KKT conditions for termination.
They do not return a clipped unconstrained solution as the answer.
Only `Converged` means success; dense rank truncation never skips KKT checks.

## Adapters to scioxide-stats fitting

These adapters supply optimization solvers as components to scioxide-stats fitting (the `FitSolver` trait).
Original solvers perform the numerical work unchanged, and scioxide-stats independently recomputes the original objective before writing outputs.
Termination maps to scioxide-stats `StatsTermination` as follows: `Converged` and `GradientSmall` are converged; iteration, evaluation, memory, node, depth, proposal, and sample limits are limit reached; `Cancelled` and `TimeLimit` are stopped; others are not converged.

## Summary

Use least-squares solvers when residual structure is available.
For one default Levenberg–Marquardt solve, use `least_squares` or `curve_fit` for fitting a model to observation pairs.
To choose settings, use `LeastSquares` and select `LeastSquaresGlobalization::GaussNewton` or `LeastSquaresGlobalization::LevenbergMarquardt`.
For distant initial values or strongly correlated parameters, choose the damped latter method.
`LeastSquaresOptions::with_loss` changes outlier sensitivity, but its scale must match observation units and noise magnitude.
Under default stopping, only `GradientSmall` is success; use points from `StepSmall` or `Stagnation` with `rank()`, `condition_estimate()`, and residuals to investigate possible identifiability issues.
For linear problems with nonnegativity or bounds, solve with `nnls` or `bvls`, or configured `Nnls` or `BoundedLinearLeastSquares`, and inspect bound components and multipliers through `kkt()` and `activity()`.
For scioxide-stats fitting, supply one of the three adapters and read original solver diagnostics through `result()`.
