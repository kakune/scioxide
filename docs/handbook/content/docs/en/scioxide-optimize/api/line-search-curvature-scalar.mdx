This table collects line searches and quasi-Newton curvature updates used within local methods, plus standalone scalar minimization.
Line search chooses step length $\alpha>0$ along descent direction $p$; inability to accept returns `LineSearchTermination::Unsuccessful` and its reason in an `Ok` result.
Structural errors (non-descent directions or length mismatches), nonfinite base values or trial gradients, and callback failure return errors without modifying caller trial-point storage.
Nonfinite trial values and out-of-domain trials are rejected without errors and shorten the step.
Curvature updates validate candidates before committing; a failing update retains the previous approximation and returns `Skipped`.

| [`BacktrackingLineSearch`](https://docs.rs/scioxide-optimize/0.1.0/scioxide_optimize/struct.BacktrackingLineSearch.html) | Struct | Armijo sufficient-decrease backtracking | Multiplies the initial step by contraction $\rho$ until $f(x+\alpha p)\le f(x)+c_1\alpha\nabla f(x)^\mathsf T p$ holds. Defaults $\alpha_0=1$, $\alpha_{\min}=\varepsilon$, $c_1=10^{-4}$, $\rho=0.5$, 40 iterations. `new(alpha_init, alpha_min, c1, rho, max_iterations)` rejects nonfinite values with `NonFinite` and violations of $0<\alpha_{\min}\le\alpha_0$ or $c_1,\rho\in(0,1)$ with `InvalidInput`. Default for `GradientDescent` and `NewtonOptimizer`; `LbfgsB` internally uses the same search with an objective rounding margin (equivalent to $8\varepsilon$). Accessors `initial_step`, `minimum_step`, `sufficient_decrease`, `contraction_factor`, `max_iterations` | [Armijo and backtracking](oxref:optimize-armijo-condition), [Steepest descent and ill-conditioning](oxref:optimize-steepest-descent) | [Vary curvature ratio and initial step to inspect Armijo acceptance intervals](oxref:optimize-armijo-scaling) |
| [`StrongWolfeLineSearch`](https://docs.rs/scioxide-optimize/0.1.0/scioxide_optimize/struct.StrongWolfeLineSearch.html) | Struct | Interval expansion and zoom with strong Wolfe | Accepts only after checking both Armijo and $\lvert\nabla f(x+\alpha p)^\mathsf T p\rvert\le c_2\lvert\nabla f(x)^\mathsf T p\rvert$ at the step (comparisons allow a relative margin of eight machine epsilons). Zoom uses safeguarded quadratic interpolation and midpoints, rather than Moré–Thuente. A rejected trial becomes the upper endpoint, preventing further expansion beyond it. Defaults $\alpha_0=1$, $\alpha_{\min}$ equal to the smallest normal number times $\varepsilon$, $c_1=10^{-4}$, $c_2=0.9$, 40 iterations, with `for_nonlinear_cg` equal to $c_2=0.1$. `new` rejects nonfinite values with `NonFinite` and violations of $0<\alpha_{\min}\le\alpha_0$ and $0<c_1<c_2<1$ with `InvalidInput`. Stopping through `with_step_tolerance` (interval width) gives unsuccessful `StepSizeLimit`. Default for `Bfgs`, `Lbfgs`, `NonlinearCg`, `PenaltyMethod`, `AugmentedLagrangian` | [Nonlinear conjugate gradients](oxref:optimize-nonlinear-cg), [Bracketing and zoom procedure](oxref:optimize-strong-wolfe-zoom) | [Trace strong Wolfe bracketing and zoom trials](oxref:optimize-strong-wolfe-trials) |

## Scalar minimization

Search for an interval minimum using values only.
A minimum bracket comprises three ordered points whose middle value is no greater than either endpoint and strictly below at least one; it differs from root-finding sign-change brackets and does not prove a global minimum.

## Summary

Choose line-search options (strong Wolfe for default BFGS methods, Armijo backtracking for gradient descent and Newton); after rejection, `LineSearchFailure` distinguishes limits, minimum steps, and stagnation, which local solvers return as `OptimizeTermination::LineSearchFailed`.
For custom line searches, report each proposal and rejection to `LineSearchScope` and return validated results through methods such as `LineSearchResult::try_accepted`.
For insufficient BFGS curvature, select damping or skipping with `CurvaturePolicy` and inspect counts in `GlobalizationDiagnostics` held by `FirstOrder` of `method_diagnostics()`.
Use `minimize_scalar` for one default Brent minimization over interval $[a, b]$.
Configured scalar minimization starts from an interval, bracket, or two-point seed; do not treat the best observation as a minimizer unless `termination()` is `Converged`.
