Higher expected returns generally compete with lower return variance.
For allocations $w_i\ge0$, $\sum_iw_i=1$ among $n$ assets, plot this tradeoff using expected return $\mu^\mathsf Tw$ and variance $w^\mathsf T\Sigma w$.
The curve collecting minimum-variance allocations at every expected return is the minimum-variance set; its branch above the minimum-variance point in return is the efficient frontier.
The example's assets have expected returns $\mu=(0.03,0.07,0.11)$, standard deviations $\sigma=(0.08,0.14,0.20)$ and common pairwise correlation $\rho$.
These are hypothetical illustrative values; returns are annual rates expressed as decimals (0.03 means 3% per year), with standard deviations in the same annual-rate units.

The common-correlation covariance matrix is $\Sigma_{ij}=\sigma_i\sigma_j(\rho+(1-\rho)\delta_{ij})$.
Correlation-matrix eigenvalues are $1-\rho$ and $1+(n-1)\rho$, so positive semidefiniteness of $\Sigma$ requires $\rho\ge-1/(n-1)$.
For three assets this is $\rho\ge-0.5$, satisfied by input range $[-0.4,0.8]$.
Variance is a convex quadratic in $w$, and the feasible set intersects a simplex with a return equality; fixing return therefore gives a convex QP.

## Quadratic programming with fixed return

For target return $R$, the QP minimizes variance subject to $\sum_iw_i=1$, $\mu^\mathsf Tw=R$ and $0\le w_i\le1$.
Setting $Q=2\Sigma$ makes SciOxide objective $\tfrac12w^\mathsf TQw$ equal variance.
Vary $R$ over 31 points from minimum return 0.03 to maximum return $0.03+0.04(n-1)$, calling `QpSolver` at each point.

[Approximate the efficient frontier with NSGA-II](../efficient-frontier-nsga2/) treats the same tradeoff as two-objective minimization and approximates the frontier through multiobjective evolutionary computation.
That page also uses the closed form derived here as its frontier reference.

## Independent check by eliminating constraints

With two assets and fixed return, $w_2=(R-0.03)/0.04$ uniquely determines allocation.
With three assets, eliminating both equalities leaves one variable.
Set $\beta=(R-0.03)/0.04$; reference allocation $b=(1-\beta,\beta,0)$ and direction $d=(1,-2,1)$ satisfy the sum and return equalities, giving $w=b+td$.
Components of $d$ sum to 0 and $\mu^\mathsf Td=0.03-0.14+0.11=0$, so changing $t$ preserves both equalities.
Here $t$ is exactly the third asset's weight $w_3$.

Variance becomes $b^\mathsf T\Sigma b+2t\,d^\mathsf T\Sigma b+t^2d^\mathsf T\Sigma d$, with vertex $t_*=-d^\mathsf T\Sigma b/(d^\mathsf T\Sigma d)$.
Projecting $t_*$ onto the interval $\max(0,\beta-1)\le t\le\beta/2$ allowed by nonnegative allocations gives the minimum without short selling.
For a one-variable convex quadratic, projection onto an interval gives its minimum on that interval.
This independent check does not solve the QP KKT system again.

Unprojected $t_*$ minimizes when negative weights (short selling) are allowed.
The resulting minimum variance equals the Markowitz closed form

$$
\sigma^2(R)=\frac{AR^2-2BR+C}{AC-B^2},\qquad
A=\mathbf 1^\mathsf T\Sigma^{-1}\mathbf 1,\quad B=\mathbf 1^\mathsf T\Sigma^{-1}\mu,\quad C=\mu^\mathsf T\Sigma^{-1}\mu
$$

and, with three assets, gives the same value as the vertex of the one-variable quadratic after eliminating both equalities.
Allowing short selling yields no greater variance because nonnegativity constraints are absent; returns where both curves coincide have inactive nonnegativity constraints.

The following definitions collect the covariance matrix, variance and both closed forms as Rust items.
`minimum_variance` is minimum variance at return $R$; when `long_only` is true, it projects $t_*$ onto the interval.

```rust
//| id: optimize-efficient-frontier-model
//| kind: definitions
//| title: "Mean–variance model and closed form after eliminating equalities"
//| crates: [scioxide-core]
pub(crate) struct Portfolio {
    pub(crate) n: usize,
    pub(crate) covariance: Vec<f64>,
}
impl Portfolio {
    // Build Σᵢⱼ = σᵢσⱼ(ρ + (1 − ρ)δᵢⱼ) from standard deviations (0.08, 0.14, 0.20) and common correlation ρ.
    pub(crate) fn new(n: usize, correlation: f64) -> Self {
        let sd = [0.08, 0.14, 0.20];
        let covariance = (0..n)
            .flat_map(|i| {
                (0..n).map(move |j| sd[i] * sd[j] * if i == j { 1.0 } else { correlation })
            })
            .collect();
        Self { n, covariance }
    }
    pub(crate) fn variance(&self, w: &[f64]) -> f64 {
        (0..self.n)
            .map(|i| {
                (0..self.n)
                    .map(|j| w[i] * self.covariance[i * self.n + j] * w[j])
                    .sum::<f64>()
            })
            .sum()
    }
    // Independent check: minimize the one-variable quadratic after eliminating equalities.
    // For three assets, w = b + t d, b = (1 − β, β, 0), d = (1, −2, 1); t is the third weight.
    // If long_only, project vertex t* onto max(0, β − 1) ≤ t ≤ β/2; otherwise allow short selling.
    pub(crate) fn minimum_variance(&self, r: f64, long_only: bool) -> f64 {
        let b = (r - 0.03) / 0.04;
        if self.n == 2 {
            return self.variance(&[1.0 - b, b]);
        }
        let base = [1.0 - b, b, 0.0];
        let direction = [1.0, -2.0, 1.0];
        let linear: f64 = (0..3)
            .map(|i| {
                (0..3)
                    .map(|j| direction[i] * self.covariance[i * 3 + j] * base[j])
                    .sum::<f64>()
            })
            .sum();
        let vertex = -linear / self.variance(&direction);
        let t = if long_only {
            vertex.clamp((b - 1.0).max(0.0), b / 2.0)
        } else {
            vertex
        };
        let w: Vec<_> = (0..3).map(|i| base[i] + t * direction[i]).collect();
        self.variance(&w)
    }
}
```

## Minimum-variance set by QP

The following cell solves QPs at 31 target returns and compares the closed form after eliminating equalities.
Inputs are asset count and common correlation; outputs are the minimum-variance-set plot, a per-return table of minimum variance and closed-form differences, and the QP outcome.
The horizontal axis is standard deviation $\sqrt{w^\mathsf T\Sigma w}$ and the vertical axis expected return; points on the branch below the minimum-variance point are dominated by points with the same variance and higher return.

```rust
//| id: optimize-efficient-frontier
//| ref: optimize-efficient-frontier
//| title: "Compare the minimum-variance QP set with a closed form"
//| run: reactive
//| uses: [optimize-efficient-frontier-model]
//| crates: [scioxide-core, scioxide-linalg, scioxide-optimize]
//| inputs:
//|   assets: {"type":"range","label":"Asset count n [assets]","min":2,"max":3,"step":1,"value":3}
//|   correlation: {"type":"range","label":"Common correlation ρ [-]","min":-0.4,"max":0.8,"step":0.1,"value":0.2}
//| cases:
//|   - {"id":"two-assets","label":"Two assets","description":"Fixed return uniquely determines allocation, so QP, closed form and the short-selling curve coincide.","inputs":{"assets":2}}
//|   - {"id":"negative-correlation","label":"Common correlation −0.4","description":"Variance cancellation moves the minimum-variance point among the 31 points to return 0.0567 and standard deviation 0.031.","inputs":{"correlation":-0.4}}
//|   - {"id":"high-correlation","label":"Common correlation 0.8","description":"The minimum-variance point without short selling invests only in asset 1 (return 0.03, standard deviation 0.08); the short-selling curve lies below it.","inputs":{"correlation":0.8}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"frontier","path":"/rows/4/1","approx":{"value":0.0054989675,"atol":1e-9}}
//|       - {"artifact":"frontier","path":"/rows/4/2","range":{"min":-1e-12,"max":1e-12}}
//|       - {"artifact":"frontier","path":"/rows/30/1","approx":{"value":0.04,"atol":1e-9}}
//|       - {"artifact":"frontier","path":"/rows/15/4","equals":"Converged"}
//|       - {"path":"/outputs/2/state","equals":"satisfied"}
//|   - case: two-assets
//|     expect:
//|       - {"artifact":"frontier","path":"/rows/30/1","approx":{"value":0.0196,"atol":1e-9}}
//|       - {"artifact":"frontier","path":"/rows/30/3","approx":{"value":0.0196,"atol":1e-9}}
//|   - case: negative-correlation
//|     expect:
//|       - {"artifact":"frontier","path":"/rows/10/1","approx":{"value":0.00096957265,"atol":1e-10}}
//|   - case: high-correlation
//|     expect:
//|       - {"artifact":"frontier","path":"/rows/0/1","approx":{"value":0.0064,"atol":1e-12}}
//|       - {"artifact":"frontier","path":"/rows/1/1","range":{"min":0.0064}}
//|       - {"artifact":"frontier","path":"/rows/0/3","range":{"max":0.0064}}
use scioxide_core::{Bounds, RealScalar};
use scioxide_linalg::Matrix;
use scioxide_optimize::{LinearConstraintSense, LinearConstraints, QpProblem, QpSolver};
let n = assets as usize;
let model = Portfolio::new(n, correlation);
let q = Matrix::from_vec(n, n, model.covariance.iter().map(|v| 2.0 * v).collect())
    .map_err(|e| e.to_string())?;
let mut rows = Vec::new();
let mut frontier = Vec::new();
let mut exact = Vec::new();
let mut short = Vec::new();
let mut all_success = true;
for k in 0..=30 {
    let r = 0.03 + 0.04 * (n - 1) as f64 * k as f64 / 30.0;
    // Equality rows: Σwᵢ = 1 and μᵀw = R.
    let mut a = vec![1.0; n];
    a.extend((0..n).map(|i| 0.03 + 0.04 * i as f64));
    let c = LinearConstraints::new(
        Matrix::from_vec(2, n, a).map_err(|e| e.to_string())?,
        vec![1.0, r],
        vec![LinearConstraintSense::Equal; 2],
    )
    .map_err(|e| e.to_string())?;
    let problem = QpProblem::new(q.clone(), vec![0.0; n])
        .and_then(|p| p.with_constraints(c))
        .and_then(|p| p.with_bounds(Bounds::new(vec![(Some(0.0), Some(1.0)); n])?))
        .map_err(|e| e.to_string())?;
    let result = QpSolver::default()
        .solve(&problem)
        .map_err(|e| e.to_string())?;
    all_success &= result.is_success();
    // Independent check: eliminate both equalities and minimize the remaining one-variable quadratic.
    let exact_variance = model.minimum_variance(r, true);
    let short_variance = model.minimum_variance(r, false);
    let variance = model.variance(result.x());
    frontier.push([RealScalar::sqrt(variance), r]);
    exact.push([RealScalar::sqrt(exact_variance), r]);
    short.push([RealScalar::sqrt(short_variance), r]);
    rows.push((
        r,
        variance,
        variance - exact_variance,
        short_variance,
        result.termination().to_string(),
    ));
}
let minimum = frontier
    .iter()
    .copied()
    .min_by(|a, b| a[0].total_cmp(&b[0]))
    .ok_or("Empty frontier")?;
let line = |id: &str, name: &str, points: &Vec<[f64; 2]>, style: serde_json::Value| {
    serde_json::json!({ "id": id, "kind": "line", "name": name, "points": points, "style": style })
};
emit_chart!(serde_json::json!({
    "kind": "xy",
    "xLabel": "Return standard deviation [annual rate]",
    "yLabel": "Expected return [annual rate]",
    "xMin": 0,
    "xMax": 0.22,
    "yMin": 0.02,
    "yMax": 0.12,
    "dataZoom": true,
    "tooltip": true,
    "annotations": [
        { "kind": "line", "axis": "y", "value": minimum[1], "label": "Return at minimum-variance point" }
    ],
    "layers": [
        line("qp", "QP", &frontier, serde_json::json!({ "showSymbol": true })),
        line("long-only", "Closed form (no short selling)", &exact, serde_json::json!({ "lineType": "dashed" })),
        line("short", "Closed form (short selling allowed)", &short, serde_json::json!({ "lineType": "dotted" }))
    ]
}));
let fixed4 = serde_json::json!({ "fractionDigits": 4 });
let sig6 = serde_json::json!({ "significantDigits": 6 });
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let columns = serde_json::json!([
    { "key": "0", "label": "Expected return R [annual rate]", "type": "number", "format": fixed4 },
    { "key": "1", "label": "QP minimum variance [annual rate²]", "type": "number", "format": sig6 },
    { "key": "2", "label": "Difference from closed form [annual rate²]", "type": "number", "format": sci2 },
    { "key": "3", "label": "Minimum variance with short selling [annual rate²]", "type": "number", "format": sig6 },
    { "key": "4", "label": "QP termination reason" }
]);
let max_difference = rows.iter().map(|r| r.2.abs()).fold(0.0_f64, f64::max);
emit_table_with_columns!(columns, rows, metadata = serde_json::json!({ "id": "frontier" }));
let outcome = if all_success {
    Outcome::satisfied("All 31 QPs satisfy their stopping tests")
} else {
    Outcome::partial("Some QPs did not satisfy their stopping tests")
        .explanation("Inspect termination reasons in the table and treat variance at those returns as estimates.")
};
emit_outcome!(
    outcome
        .status(if all_success { "Converged" } else { "Some solves unconverged" })
        .diagnostic("Maximum difference from closed form", max_difference, None)
        .diagnostic("Standard deviation at minimum-variance point", minimum[0], None)
);
```

For the default three assets and $\rho=0.2$, the minimum-variance point among the 31 points has return 0.0407 and variance 0.005499 (standard deviation 0.0742); differences between QP and closed form at the 31 points are around $10^{-17}$.
Minimizing the closed form over finer return increments gives minimum return 0.0412 and variance 0.005498, differing from the grid point by 0.0005 in return.
Near both return endpoints, the short-selling curve lies left of the no-short-selling curve, where nonnegativity constraints determine the minimum.
The curves coincide over approximately 0.036–0.090 return, where all weights at the short-selling minimum are also nonnegative.
With two assets, return uniquely determines allocation, so all three curves coincide.
Correlation $-0.4$ induces variance cancellation, moving the minimum-variance point among the 31 points to return 0.0567 and variance 0.00097 (the closed-form minimum-variance point has return 0.0562).
At correlation 0.8, variance reduction weakens; the minimum-variance allocation without short selling holds only asset 1 (return 0.03, standard deviation 0.08).

## Summary

Fixed-return mean–variance optimization is a convex QP; for two and three assets, a one-variable closed form after eliminating equalities independently checks QP results.
For three assets, $t$ in $w=b+td$ is the third weight; projection onto nonnegative-allocation interval $\max(0,\beta-1)\le t\le\beta/2$ gives the minimum without short selling, and the unprojected vertex gives the Markowitz closed form.
Where the closed forms diverge, nonnegativity constraints raise minimum variance.
When more assets remove the closed form, assess QP frontiers through termination reasons, KKT residuals and independent-verification status.
