Recover coefficients $x_*\in\mathbb R^n$ with few nonzero components from $m$ linear observations $y=Ax_*+\varepsilon$.
Compressed sensing in signal processing and regression selecting influential variables from many predictors have this form.
With fewer observations than coefficients, $A$ has a nontrivial null space, so residuals alone cannot determine coefficients uniquely.
LASSO (least absolute shrinkage and selection operator) adds an $\ell_1$ penalty and solves

$$
\min_x F(x)=f(x)+\lambda\|x\|_1,\qquad f(x)=\frac12\|Ax-y\|_2^2
$$


$F$ is convex, but $\|x\|_1$ is nondifferentiable at zero components.
LASSO favors sparse solutions but need not recover the true nonzero support.
Column correlations, measurement count, noise and penalty strength affect results.

## KKT conditions and the zero solution

Let $g=\nabla f(x)=A^\mathsf T(Ax-y)$.
Using subdifferentials at nondifferentiable points gives optimality (KKT) condition $0\in g+\lambda\partial\|x\|_1$.
Componentwise, nonzero entries satisfy $g_i+\lambda\operatorname{sign}(x_i)=0$ and zero entries $|g_i|\le\lambda$.
Define component $i$ violation as $|g_i+\lambda\operatorname{sign}(x_i)|$ for nonzero entries and $\max(|g_i|-\lambda,0)$ for zero entries; their maximum is the KKT violation.
It equals the $\infty$-norm distance between $0$ and subdifferential $\partial F(x)$.

Substituting $x=0$ gives $g=-A^\mathsf Ty$, so the zero solution is optimal when $\lambda\ge\lambda_{\max}=\|A^\mathsf Ty\|_\infty$.
Conversely, $\lambda<\lambda_{\max}$ violates the zero-component condition, so the zero solution is not optimal.
This threshold depends only on data and independently checks the regularization path's right endpoint without the solver's termination test.

## Computing the regularization path

The proximal map of $\lambda\|\cdot\|_1$ is soft thresholding,

$$
\operatorname{prox}_{s\lambda\|\cdot\|_1}(v)_i=\operatorname{sign}(v_i)\max(|v_i|-s\lambda,0)
$$

which sets components with $|v_i|\le s\lambda$ exactly to 0.
FISTA steps along the gradient of smooth part $f$, thresholds small components to zero, and accelerates by extrapolation from previous iterates.
For $L$ in step $1/L$, use $L=\|A\|_F^2$, an upper bound on Lipschitz constant $\|A\|_2^2$ of $\nabla f$; each iteration costs $O(mn)$.
Count nonzero iterate entries through $x_i\ne0$ without choosing a rounding threshold.

A regularization path is the sequence of coefficients solved at varying $\lambda$.
Here solve independently from zero at 20 values $\lambda/\lambda_{\max}=0.05,0.10,\dots,1.00$.
Continuation (warm starts) from the previous $\lambda$ solution could reduce iterations, but is omitted to keep each result independent.
[Solve LASSO with FISTA and ADMM and check KKT conditions](../lasso-kkt-verification/) covers FISTA stopping, ADMM comparison and KKT checks of returned coefficients.

## Model and random data

Use $n=12$ coefficients with true nonzeros $\pm1$ at the first entries, alternating in sign.
Matrix entries are uniform $[-1,1]$ divided by $\sqrt m$; their expected squares are $1/(3m)$, giving column norms around $1/\sqrt3$.
Noise is zero-mean uniform; the input specifies its half-width.
Generate matrices and noise from SplitMix64 with the supplied seed.

```rust
//| id: optimize-lasso-path
//| ref: optimize-lasso-path
//| title: "Inspect the regularization path and nonzero support recovery along λ/λmax"
//| run: button
//| timeoutMs: 120000
//| crates: [scioxide-core, scioxide-optimize, scioxide-random]
//| inputs:
//|   measurements: {"type":"range","label":"Measurements m [points]","min":6,"max":20,"step":2,"value":10}
//|   sparsity: {"type":"range","label":"True nonzero entries [count]","min":1,"max":4,"step":1,"value":2}
//|   noise: {"type":"range","label":"Noise half-width [-]","min":0,"max":0.2,"step":0.02,"value":0.02}
//|   seed: {"type":"range","label":"Random seed [-]","min":1,"max":100,"step":1,"value":17}
//| cases:
//|   - {"id":"noisy","label":"Noise half-width 0.2","description":"λmax rises to 0.28923; at λ/λmax = 0.10, 8 entries are nonzero and correct classifications fall to 6.","inputs":{"noise":0.2}}
//|   - {"id":"many-measurements","label":"20 measurements","description":"At m = 20 > n, λ/λmax ≤ 0.80 retains only the 2 true nonzeros, correctly classifying all 12 entries.","inputs":{"measurements":20}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"summary","path":"/rows/0/0","approx":{"value":0.26306004,"atol":1e-7}}
//|       - {"artifact":"summary","path":"/rows/0/2","equals":20}
//|       - {"artifact":"summary","path":"/rows/0/3","approx":{"value":1,"atol":1e-12}}
//|       - {"artifact":"support","path":"/rows/1/1","equals":5}
//|       - {"artifact":"support","path":"/rows/1/2","equals":9}
//|   - case: noisy
//|     expect:
//|       - {"artifact":"summary","path":"/rows/0/0","approx":{"value":0.28922713,"atol":1e-7}}
//|       - {"artifact":"support","path":"/rows/1/2","equals":6}
//|   - case: many-measurements
//|     expect:
//|       - {"artifact":"support","path":"/rows/15/2","equals":12}
use scioxide_core::{Budget, SciOxideError, NumericScalar, RealScalar};
use scioxide_optimize::{CompositeProblem, Fista, ProximalMap, ProximalOptions, SmoothGradient};
use scioxide_random::{BitGenerator, SeedableRng, SplitMix64, decode_u64};
// Smooth part f(x) = ½‖Ax − y‖². a stores m×n matrix A row by row.
struct Loss {
    a: Vec<f64>,
    y: Vec<f64>,
    n: usize,
}
impl SmoothGradient<f64> for Loss {
    fn dimension(&self) -> usize {
        self.n
    }
    fn value(&self, x: &[f64]) -> Result<f64, SciOxideError> {
        let rows = self.a.chunks_exact(self.n).zip(&self.y);
        let squares = rows.map(|(row, y)| (dot(row, x) - y) * (dot(row, x) - y));
        Ok(0.5 * squares.sum::<f64>())
    }
    fn gradient_into(&self, x: &[f64], out: &mut [f64]) -> Result<(), SciOxideError> {
        out.fill(0.0);
        for (row, y) in self.a.chunks_exact(self.n).zip(&self.y) {
            let r = dot(row, x) - y;
            out.iter_mut().zip(row).for_each(|(g, a)| *g += a * r);
        }
        Ok(())
    }
}
fn dot(u: &[f64], v: &[f64]) -> f64 {
    u.iter().zip(v).map(|(a, b)| a * b).sum()
}
// Soft thresholding for g(x) = λ‖x‖₁: prox_{sλ‖·‖₁}(v)ᵢ = sign(vᵢ) max(|vᵢ| − sλ, 0). The value is λ.
struct Shrink(f64);
impl ProximalMap<f64> for Shrink {
    fn apply_into(&self, x: &[f64], step: f64, out: &mut [f64]) -> Result<(), SciOxideError> {
        for (o, &v) in out.iter_mut().zip(x) {
            let shrunk = RealScalar::max(NumericScalar::abs(v) - step * self.0, 0.0);
            *o = RealScalar::copysign(shrunk, v);
        }
        Ok(())
    }
}
// A entries are uniform [−1, 1] divided by √m. Then draw noise row by row.
let (m, n) = (measurements as usize, 12_usize);
let mut rng = SplitMix64::from_seed(seed as u64);
let mut uniform = || -> Result<f64, String> {
    let bits = rng.next_uniform_u64().map_err(|e| e.to_string())?;
    Ok(decode_u64::<f64>(bits) * 2.0 - 1.0)
};
let scale = RealScalar::sqrt(m as f64);
let a: Vec<f64> = (0..m * n)
    .map(|_| uniform().map(|v| v / scale))
    .collect::<Result<_, _>>()?;
let truth: Vec<f64> = (0..n)
    .map(|i| match i {
        i if i >= sparsity as usize => 0.0,
        i if i % 2 == 0 => 1.0,
        _ => -1.0,
    })
    .collect();
let mut y = Vec::with_capacity(m);
for row in a.chunks_exact(n) {
    y.push(dot(row, &truth) + noise * uniform()?);
}
let loss = Loss { a, y, n };
// The gradient at zero is −Aᵀy, so λmax = ‖Aᵀy‖∞. L = ‖A‖_F² upper-bounds ‖A‖₂².
let zero = vec![0.0; n];
let mut gradient = vec![0.0; n];
loss.gradient_into(&zero, &mut gradient)
    .map_err(|e| e.to_string())?;
let lambda_max = gradient
    .iter()
    .fold(0.0, |m, &g| RealScalar::max(m, NumericScalar::abs(g)));
let lipschitz = loss.a.iter().map(|v| v * v).sum::<f64>();
let budget = Budget::try_from(3000_usize).map_err(|e| e.to_string())?;
let solver = Fista::new(ProximalOptions::new(lipschitz).with_max_iterations(budget))
    .map_err(|e| e.to_string())?;
let mut paths = vec![Vec::new(); n];
let mut support = Vec::new();
let (mut converged, mut first_zero) = (0_usize, None);
for k in 1..=20 {
    let fraction = k as f64 / 20.0;
    let result = solver
        .minimize(
            &CompositeProblem::new(&loss, &Shrink(fraction * lambda_max)),
            &zero,
        )
        .map_err(|e| e.to_string())?;
    let x = result.x();
    for (path, &v) in paths.iter_mut().zip(x) {
        path.push([fraction, v]);
    }
    // The proximal map sets small entries exactly to 0; count nonzero support through xᵢ ≠ 0.
    let nonzero = x.iter().filter(|&&v| v != 0.0).count();
    let matches = x
        .iter()
        .zip(&truth)
        .filter(|(x, t)| (**x != 0.0) == (**t != 0.0));
    support.push((fraction, nonzero, matches.count()));
    converged += usize::from(result.is_success());
    if nonzero == 0 && first_zero.is_none() {
        first_zero = Some(fraction);
    }
}
let series: Vec<_> = paths
    .iter()
    .zip(&truth)
    .enumerate()
    .map(|(i, (p, &t))| {
        let line = if t == 0.0 { "dotted" } else { "solid" };
        serde_json::json!({ "name": format!("Coefficient {i}"), "points": p, "style": { "lineType": line } })
    })
    .collect();
let threshold =
    serde_json::json!([{ "kind": "line", "axis": "x", "value": 1.0, "label": "λmax" }]);
emit_line_chart!(
    &series,
    options = &serde_json::json!({
        "xLabel": "λ / λmax [-]",
        "yLabel": "Coefficient [-]",
        "link": { "group": "lasso-ratio" },
        "annotations": threshold
    })
);
let counts = |column: fn(&(f64, usize, usize)) -> usize| -> Vec<[f64; 2]> {
    support
        .iter()
        .map(|row| [row.0, column(row) as f64])
        .collect()
};
emit_line_chart!(
    &vec![
        serde_json::json!({ "name": "Nonzero entries", "points": counts(|r| r.1), "style": { "step": "end" } }),
        serde_json::json!({ "name": "Correct classifications", "points": counts(|r| r.2), "style": { "step": "end" } }),
    ],
    options = &serde_json::json!({
        "xLabel": "λ / λmax [-]",
        "yLabel": "Entries [count]",
        "link": { "group": "lasso-ratio" },
        "annotations": threshold
    })
);
let fixed2 = serde_json::json!({ "fractionDigits": 2 });
let sig5 = serde_json::json!({ "significantDigits": 5 });
emit_table_with_columns!(
    serde_json::json!([
        { "key": "0", "label": "λ / λmax [-]", "type": "number", "format": fixed2 },
        { "key": "1", "label": "Nonzero entries [count]", "type": "integer" },
        { "key": "2", "label": "Correct classifications [count]", "type": "integer" }
    ]),
    support,
    metadata = serde_json::json!({ "id": "support" })
);
emit_table_with_columns!(
    serde_json::json!([
        { "key": "0", "label": "λmax = ‖Aᵀy‖∞ [-]", "type": "number", "format": sig5 },
        { "key": "1", "label": "L = ‖A‖_F² [-]", "type": "number", "format": sig5 },
        { "key": "2", "label": "Converged solves [count]", "type": "integer" },
        { "key": "3", "label": "Smallest λ/λmax giving the zero solution [-]", "type": "number", "format": fixed2, "nullText": "None" }
    ]),
    vec![(lambda_max, lipschitz, converged, first_zero)],
    metadata = serde_json::json!({ "id": "summary" })
);
```

For defaults (10 measurements, 2 nonzeros, noise half-width 0.02, seed 17), $\lambda_{\max}=0.26306$ and $L=4.6246$, and all 20 solves terminate with `Converged`.
The smallest all-zero grid point is $\lambda/\lambda_{\max}=1.00$, with nonzeros remaining at 0.95, so the zero threshold is $\lambda_{\max}$ as predicted.
Decreasing $\lambda$ from $\lambda_{\max}$ first activates entry 7, whose true value is zero.
The zero-solution KKT condition first fails at the largest $|A_i^\mathsf Ty|$ component, so the column determining $\lambda_{\max}$ need not belong to the true support.
True nonzero entry 1 enters at $\lambda/\lambda_{\max}=0.80$, and entry 0 at $0.60$.
From $0.15$ to $0.60$, 4 entries are nonzero, including false positives 4 and 7, with 10 correct classifications.
At $0.10$ and below, entry 9 also enters, leaving 9 correct classifications.
No $\lambda$ classifies all 12 correctly; independently of solver accuracy, data with $m<n$ and the LASSO model limit support recovery.

Increasing measurements to 20 leaves only the 2 true nonzeros at $\lambda/\lambda_{\max}\le0.80$ and correctly classifies all 12 entries.
With noise half-width 0.2, $\lambda_{\max}$ rises to 0.28923; at $\lambda/\lambda_{\max}=0.10$, 8 entries are nonzero and only 6 correctly classified.

## Summary

LASSO KKT conditions differ between zero and nonzero entries; threshold $\lambda_{\max}=\|A^\mathsf Ty\|_\infty$ for optimality of the zero solution follows directly from data.
This checks the path's right endpoint; decreasing $\lambda$ first activates the component with largest $|A_i^\mathsf Ty|$.
That component need not lie in the true support, so recovery depends on measurement count, noise and column correlations.
Coefficient shrinkage and false positives are properties of the LASSO model and persist with greater solver accuracy.
Assess solution accuracy separately through KKT violations and termination reasons.
