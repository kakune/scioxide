[Search a multimodal layout design](../rastrigin-de/) ran differential evolution (DE) with one seed and checked stationarity by BFGS from its best point.
DE uses randomness, so its finite-generation best value is a seed-dependent random variable.
This page solves the same Rastrigin function $f(x,y)=2A+\sum\{x_i^2-A\cos(2\pi x_i)\}$ (global minimum at the origin, $f=0$) $R$ times, varying only seeds.
Count known-global-minimum attainment, report rates with 95% confidence intervals, and compare settings with matching evaluation limits.

## Attainment rates and binomial models

Count a run as reaching the origin when its best point's distance is below $10^{-3}$.
This convenient criterion applies only to known-answer test problems.
Independent seeds give attainment count $K$ among $R$ runs a binomial distribution $\mathrm{Bin}(R,p)$ ($p$ is single-run origin-attainment probability for these settings).
The estimate is $\hat p=K/R$ with standard error $\sqrt{p(1-p)/R}$.

Wald interval $\hat p\pm1.96\sqrt{\hat p(1-\hat p)/R}$ has zero width at $K=0$ or $K=R$, and coverage well below nominal 95% for small $R$.
Wilson intervals solve $|\hat p-p|\le z\sqrt{p(1-p)/R}$ ($z=1.96$) for $p$, giving

$$
\frac{\hat p+\dfrac{z^2}{2R}}{1+\dfrac{z^2}{R}}
\pm
\frac{z}{1+\dfrac{z^2}{R}}
\sqrt{\frac{\hat p(1-\hat p)}{R}+\frac{z^2}{4R^2}}
$$


Even at $K=0$ the upper bound is positive; for $R=20$ it is $0.161$.
Strong overlap between settings' intervals prevents concluding a rate difference at that run count.

Per-run evaluations are bounded by $N_p(G+1)$ ($N_p$ population, $G$ generation limit).
Match this bound when changing populations and generations together.
Larger populations explore more basins simultaneously, but fewer generations allow less refinement of each basin.
Default population $\max(15n,4)$ of `DifferentialEvolutionOptions` scales with variable count $n$.

## Repeat across seeds

Run $r$ $(r=0,\dots,R-1)$ uses seed $s_0+10007r$; box $[-5.12,5.12]^2$, population, generation limit and start $(3.5,-3.5)$ remain identical across runs.
Use default mutation factor $F=0.8$, crossover probability $C_R=0.9$ and spread tolerance (absolute and relative both $\sqrt{\varepsilon_{\mathrm{mach}}}$).

Inputs are runs $R$, population, generation limit, amplitude $A$ and base seed $s_0$.
Outputs are:

- Best-value and origin-distance plot per run (logarithmic vertical axis)
- Per-run seed, best value, distance, generations, evaluations and termination table
- Table of attainments, rates and 95% Wilson intervals, mean/standard deviation of best values, and evaluation limits

Fix distance criterion $10^{-3}$ and count every run without selecting favorable seeds.
Exactly zero best values or distances cannot appear on log axes; tabulate their counts.

```rust
//| id: optimize-rastrigin-multiseed
//| ref: optimize-rastrigin-multiseed
//| title: "Repeat finite-generation differential evolution with independent seeds"
//| run: reactive
//| crates: [scioxide-core, scioxide-optimize]
//| inputs:
//|   multiseed_runs: {"type":"range","label":"Runs R [count]","description":"Change the independent-run count used to estimate attainment.","min":8,"max":32,"step":2,"value":20}
//|   multiseed_population: {"type":"range","label":"Population Nₚ [points]","description":"Change diversity and per-generation work.","min":8,"max":48,"step":4,"value":20}
//|   multiseed_generations: {"type":"range","label":"Generation limit G [generations]","description":"Change each run's search length.","min":15,"max":150,"step":5,"value":55}
//|   multiseed_amplitude: {"type":"range","label":"Irregularity amplitude A [-]","description":"Change the strength of local-minimum basins.","min":3,"max":18,"step":1,"value":10}
//|   multiseed_base_seed: {"type":"range","label":"Base seed s₀ [-]","description":"Run r uses seed s₀ + 10007r.","min":1,"max":1000,"step":1,"value":97}
//| cases:
//|   - {"id":"long-budget","label":"Generation limit G = 150","description":"The per-run evaluation bound grows to 3020; attainment is 19/20 (95% Wilson interval 0.764–0.991).","inputs":{"multiseed_generations":150}}
//|   - {"id":"tiny-budget","label":"Generation limit G = 15","description":"At evaluation bound 320, no run reaches the origin (interval 0–0.161), and mean best value rises to 2.43.","inputs":{"multiseed_generations":15}}
//|   - {"id":"other-seeds","label":"Base seed s₀ = 1000","description":"Changing only seeds gives 7/20 attainments (interval 0.181–0.567), overlapping default 0.081–0.416.","inputs":{"multiseed_base_seed":1000}}
//|   - {"id":"deep-search","label":"Nₚ = 12, G = 90","description":"Evaluation bound 1092 nearly matches the default; attainment rises to 11/20 (interval 0.342–0.742), but remaining runs stop at neighboring minimum f = 0.995.","inputs":{"multiseed_population":12,"multiseed_generations":90}}
//|   - {"id":"wide-search","label":"Nₚ = 40, G = 25","description":"At evaluation bound 1040, attainment is 0/20 (interval 0–0.161); every run stops at its generation limit.","inputs":{"multiseed_population":40,"multiseed_generations":25}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"summary","path":"/rows/0/1","equals":4}
//|       - {"artifact":"summary","path":"/rows/2/1","approx":{"value":0.08066,"atol":1e-4}}
//|       - {"artifact":"summary","path":"/rows/3/1","approx":{"value":0.41602,"atol":1e-4}}
//|       - {"artifact":"summary","path":"/rows/6/1","equals":1120}
//|   - case: long-budget
//|     expect:
//|       - {"artifact":"summary","path":"/rows/0/1","equals":19}
//|       - {"artifact":"summary","path":"/rows/6/1","equals":3020}
//|   - case: tiny-budget
//|     expect:
//|       - {"artifact":"summary","path":"/rows/0/1","equals":0}
//|       - {"artifact":"summary","path":"/rows/3/1","approx":{"value":0.16113,"atol":1e-4}}
//|       - {"artifact":"summary","path":"/rows/6/1","equals":320}
//|   - case: other-seeds
//|     expect:
//|       - {"artifact":"summary","path":"/rows/0/1","equals":7}
//|   - case: deep-search
//|     expect:
//|       - {"artifact":"summary","path":"/rows/0/1","equals":11}
//|       - {"artifact":"summary","path":"/rows/6/1","equals":1092}
//|   - case: wide-search
//|     expect:
//|       - {"artifact":"summary","path":"/rows/0/1","equals":0}
//|       - {"artifact":"summary","path":"/rows/6/1","equals":1040}
use scioxide_core::{Bounds, Budget, RealScalar};
use scioxide_optimize::{
    BoundedObjective, DifferentialEvolution, DifferentialEvolutionOptions, ObjectiveFn,
};
use std::f64::consts::PI;

let sig4 = serde_json::json!({ "significantDigits": 4 });
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let a = multiseed_amplitude;
let objective = ObjectiveFn::new(2, move |p: &[f64]| {
    Ok(2.0 * a
        + p.iter()
            .map(|&v| v * v - a * RealScalar::cos(2.0 * PI * v))
            .sum::<f64>())
});
let bounds = Bounds::new(vec![(Some(-5.12_f64), Some(5.12)); 2]).map_err(|e| e.to_string())?;
let bounded = BoundedObjective::new(&objective, &bounds).map_err(|e| e.to_string())?;
let (runs, population, generations) = (
    multiseed_runs.round() as usize,
    multiseed_population.round() as usize,
    multiseed_generations.round() as usize,
);
let (mut rows, mut values, mut distances, mut reached) =
    (Vec::new(), Vec::new(), Vec::new(), 0_usize);
for run in 0..runs {
    // Vary only seeds; keep box, population, generations and start identical.
    let seed = multiseed_base_seed.round() as u64 + 10_007 * run as u64;
    let options = DifferentialEvolutionOptions::default()
        .with_max_generations(Budget::try_from(generations).map_err(|e| e.to_string())?)
        .with_population_size(Budget::try_from(population).map_err(|e| e.to_string())?)
        .with_seed(seed);
    let r = DifferentialEvolution::new(options)
        .map_err(|e| e.to_string())?
        .minimize(&bounded, &[3.5_f64, -3.5])
        .map_err(|e| e.to_string())?;
    let distance = r.x().iter().map(|v| v * v).sum::<f64>().sqrt();
    // Count distance below 10⁻³ as origin attainment (usable only on known-answer test problems).
    if distance < 1.0e-3 {
        reached += 1;
    }
    values.push(r.fun());
    distances.push(distance);
    rows.push((
        run + 1,
        seed,
        r.fun(),
        distance,
        r.iterations(),
        r.fun_evals(),
        r.termination().to_string(),
    ));
}
let mean = values.iter().sum::<f64>() / runs as f64;
let sd = (values.iter().map(|v| (v - mean).powi(2)).sum::<f64>() / (runs - 1) as f64).sqrt();
// 95% Wilson interval for rate p̂ = K/R.
let (p, n, z) = (reached as f64 / runs as f64, runs as f64, 1.96_f64);
let centre = (p + z * z / (2.0 * n)) / (1.0 + z * z / n);
let half = z / (1.0 + z * z / n) * (p * (1.0 - p) / n + z * z / (4.0 * n * n)).sqrt();
// At K = 0 the lower bound is exactly 0; set only tiny negative roundoff to 0.
let (lower, upper) = ((centre - half).max(0.0), centre + half);
// Zero objectives/distances are omitted from log plots (counts appear in the table).
let positive = |v: &[f64]| {
    v.iter()
        .enumerate()
        .filter(|&(_, &x)| x > 0.0)
        .map(|(i, &x)| [i as f64 + 1.0, x])
        .collect::<Vec<_>>()
};
let zero_count = values
    .iter()
    .chain(&distances)
    .filter(|&&v| v <= 0.0)
    .count();
emit_scatter_chart!(
    &vec![
        serde_json::json!({ "name": "Best value f", "points": positive(&values) }),
        serde_json::json!({
            "name": "Distance from origin",
            "points": positive(&distances),
            "style": { "symbol": "triangle" }
        }),
    ],
    options = &serde_json::json!({
        "xLabel": "Run index r + 1 [-]",
        "yLabel": "Best f / distance from origin [-]",
        "yType": "log",
        "annotations": [
            { "kind": "line", "axis": "y", "value": 1.0e-3, "label": "Attainment distance 10⁻³" }
        ]
    })
);
let run_columns = serde_json::json!([
    { "key": "0", "label": "Run", "type": "integer" },
    { "key": "1", "label": "Seed", "type": "integer" },
    { "key": "2", "label": "Best value f [-]", "type": "number", "format": sci3 },
    { "key": "3", "label": "Distance from origin [-]", "type": "number", "format": sci3 },
    { "key": "4", "label": "Generations [count]", "type": "integer" },
    { "key": "5", "label": "Objective evaluations [count]", "type": "integer" },
    { "key": "6", "label": "Termination reason" }
]);
emit_table_with_columns!(
    run_columns,
    rows,
    metadata = serde_json::json!({ "id": "runs" })
);
let summary_columns = serde_json::json!([
    { "key": "0", "label": "Aggregate" },
    { "key": "1", "label": "Value", "type": "number", "format": sig4 }
]);
emit_table_with_columns!(
    summary_columns,
    vec![
        ("Origin attainments K [count]", reached as f64),
        ("Attainment rate p̂ = K/R [-]", p),
        ("95% Wilson lower bound [-]", lower),
        ("95% Wilson upper bound [-]", upper),
        ("Mean best value [-]", mean),
        ("Best-value standard deviation [-]", sd),
        (
            "Per-run evaluation limit Nₚ(G+1) [count]",
            (population * (generations + 1)) as f64
        ),
        ("Zeros omitted from log axes [count]", zero_count as f64),
    ],
    metadata = serde_json::json!({ "id": "summary" })
);
```

For default 20 runs (population 20, generation limit 55, $A=10$), every run reaches the generation limit and stops with `SearchBudgetCompleted`.
Four reach the origin; attainment rate $\hat p=0.20$ has 95% Wilson interval $0.081$–$0.416$.
Mean best value is 0.119 with standard deviation 0.254.
Sixteen runs have $f<0.1$, but 12 still fail to bring origin distance below $10^{-3}$.
The remaining four best values range from $f=0.23$ to $0.995$, including one neighboring minimum 0.995.
Base seed 1000 gives 7 attainments (0.35, interval 0.181–0.567), overlapping the default interval.
Twenty runs lack precision to distinguish seed changes from setting changes.

Generation limit 150 gives 19 attainments (interval 0.764–0.991); limit 15 gives none (0–0.161).
All 20 runs at limit 150 contract and stop with `PopulationStagnation`, including one contracting at neighboring minimum $f=0.995$.
That one run demonstrates stagnation is not success.

Keeping evaluation bounds around 1100 while reallocating population and generations changes results substantially.
Population 12, 90 generations (bound 1092) raises attainments to 11 (interval 0.342–0.742), but all 9 misses stop at neighboring minimum $f=0.995$, raising mean best value to 0.448 above default.
Population 40, 25 generations (bound 1040) gives no attainments, with best values from 0.04 to 1.2.
Among these two allocations on this two-dimensional problem, smaller populations with more generations reach the origin more often.
Attainment rates and mean best values measure different properties; choose the selection criterion by purpose.
Higher dimensions also increase default population $15n$; do not transfer two-dimensional conclusions directly.

## Stopping and checking unknown-answer problems

Real designs cannot use answers such as $f^\star=0$.
Instead combine evidence: independently seeded best values cluster, population search and multistart local methods find the same basin, doubling evaluations yields little improvement, and constraints and physical models are independently reevaluated.

Tighter bounds ease search but may exclude true solutions.
Finite bounds are required by DE and are model assumptions about feasible design ranges, not merely numerical settings.
If best points remain on boundaries, reconsider those bounds or objective monotonicity.

Reproducibility requires recording seed, population, generation limit, $F$, $C_R$, strategy and bounds.
Stating only “used differential evolution” cannot reproduce results.

## Summary

Assess stochastic search across independent seeds, reporting attainment counts with 95% Wilson intervals rather than relying on one seed.
Zero attainments still give positive Wilson upper bounds; never observed success does not mean success is impossible.
Match evaluation bounds $N_p(G+1)$ across settings and increase runs before judging differences with overlapping intervals.
Attainment rates and mean best values measure different properties; inspect tables for stagnated runs clustered at neighboring minima.
For unknown answers, assess candidates through independent-seed clustering, agreement with multistart local methods and improvements after doubling evaluations.
