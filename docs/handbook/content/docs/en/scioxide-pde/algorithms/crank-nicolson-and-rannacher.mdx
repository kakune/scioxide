Crank–Nicolson is second-order accurate and unconditionally stable, making it a common choice for time integration of diffusion equations.
With nonsmooth initial data such as a step, however, grid-scale oscillations decay slowly.
This page explains the cause through amplification factors, describes Rannacher startup, which replaces only the first intervals with backward Euler, and shows how to configure it with `RannacherStartup`.
The Fourier number $r=\alpha\Delta t/h^2$, θ-method amplification factors, and `ParabolicProblem` schemes are defined in [Time integration of parabolic equations](../parabolic-time-integration/).

## Short-wavelength amplification and Rannacher startup

Crank–Nicolson is an A-stable second-order method with much smaller temporal error than backward Euler for smooth temperature fields.
For large $r$, however, the amplification factor of the shortest wavelength ($\theta=\pi$) approaches the following limit.

$$
\lim_{r\to\infty}G_{\mathrm{CN}}(\pi)=\lim_{r\to\infty}\frac{1-2r}{1+2r}=-1
$$


A component that should decay rapidly in the semidiscrete system persists with almost no damping, reversing sign at each step.
With a step-like initial temperature or an abrupt boundary-temperature change, this appears as grid-scale oscillations.

Rannacher startup replaces each of the first few intervals (each of width $\Delta t$) with two backward Euler steps of size $\Delta t/2$.
A backward Euler half step has amplification factor $1/(1+2r\sin^2(\theta/2))$, so the factor over one interval is

$$
G_{\mathrm{R}}(\theta)=\left(\frac{1}{1+2r\sin^2(\theta/2)}\right)^2
$$

which approaches 0 as $r\to\infty$ even at $\theta=\pi$.
Short-wavelength components of the initial step are strongly damped during startup.
For a smooth solution, refining the step with a fixed number of startup intervals adds backward Euler's local error $O(\Delta t^2)$ only a fixed number of times, retaining overall error $O(\Delta t^2)$.
Luskin and Rannacher (1982) showed that Crank–Nicolson with startup recovers second-order convergence at positive times even for nonsmooth initial data.

In `scioxide-pde`, pass a `Budget` specifying the startup interval count to `ParabolicOptions::with_rannacher_startup(intervals)`.
This sets `RannacherStartup::BackwardEuler { intervals }` and advances the first $n$ intervals $[0,\,n\Delta t]$ from time 0 with backward Euler half steps ($n$ is the interval count; if the final time is earlier, startup ends there).
The default is `RannacherStartup::Disabled`, with no startup.
Combining startup with any scheme other than the built-in `ParabolicScheme::CrankNicolson`, or with `with_ode_method`, is rejected by the `initial_state` and `advance` preflight checks with `InvalidInput` (`UnsupportedConfiguration`).
`initial_state` writes the startup end time into the state from the current settings; read it with `PdeState::startup_end`.
Resuming interrupted integration from the same state preserves the remaining startup.
The `advance` and `resume` preflight checks verify that the state's startup end matches the value determined by the supplied settings.
If the state's time precedes $n\Delta t$, the correct value is that configuration's startup end $n\Delta t$; otherwise it is “none.”
Thus, passing a state created without startup to startup-enabled settings during the startup interval is rejected by preflight checks with `InvalidInput` (`Inconsistent`), leaving the state unchanged.
The same holds when a state created with startup is passed to settings without startup during that interval.
After the startup interval, a state can advance under either setting.

## Measuring amplification by mode

Compare modal amplification after eight time intervals for wave numbers $\theta\in[0,\pi]$ using backward Euler, Crank–Nicolson, and Crank–Nicolson with Rannacher startup.
Inputs are the Fourier number $r$ and the number of startup intervals.

The cell uses `StructuredFdmPlan::dirichlet_laplacian` to construct a 17-point grid ($h=1/16$) on $[0,1]$ with $\alpha=1$ and Dirichlet conditions at both ends, then advances eight intervals at fixed step $\Delta t=rh^2$.
It starts from sine modes $\sin(j\pi x)$ ($j=1,\dots,15$, $\theta=j\pi/16$) and measures amplification by projecting the final field onto the initial mode.
Each of the three schemes allocates its workspace once through `workspace` and reuses it for `initial_state` and `advance` over all 15 modes.
Dashed curves show closed-form amplification (the dotted curve is exact semidiscrete decay); points show values solved with `ParabolicProblem`.
The table lists closed forms over one and eight intervals at $\theta=\pi$, predicted and measured values for the shortest grid-representable mode $\theta=15\pi/16$, and the factorization count when solving the first mode.
Results for the same phenomenon with step initial data appear in the [rod heat-diffusion example](../../examples/heat-crank-nicolson/).
[Implicit-stage linear systems and factorizations](oxref:pde-implicit-stage-linear-systems) explains how factorization counts are determined.

```rust
//| ref: pde-parabolic-mode-damping

//| run: reactive
//| crates: [scioxide-pde, scioxide-core]
//| inputs:
//|   fourier_number: {"type":"range","label":"Fourier number r = αΔt/h² [-]","description":"Change diffusion strength per interval.","min":0.05,"max":5,"step":0.05,"value":1.5}
//|   rannacher_intervals: {"type":"range","label":"Rannacher startup intervals [-]","description":"Change how many initial intervals are replaced by two backward Euler half steps.","min":0,"max":4,"step":1,"value":1}
//| cases:
//|   - {"id":"mild-diffusion","label":"Mild diffusion r = 0.05","description":"At θ = 15π/16, amplification after eight intervals is positive, 0.20–0.24, for every scheme, without sign reversal.","inputs":{"fourier_number":0.05}}
//|   - {"id":"stiff-step","label":"Stiff step r = 5","description":"At θ = π, one-interval CN amplification is −0.82, leaving 0.20 after eight intervals. One startup interval reduces it to −2.0×10⁻³.","inputs":{"fourier_number":5}}
//|   - {"id":"long-startup","label":"Four startup intervals","description":"With r = 1.5 and four startup intervals, amplification at θ = π after eight intervals falls to 9.5×10⁻⁷.","inputs":{"rannacher_intervals":4}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"damping","path":"/rows/1/2","approx":{"value":1.7346653e-7,"rtol":1e-6}}

//|       - {"artifact":"damping","path":"/rows/3/4","approx":{"value":-4.7076772e-4,"rtol":1e-6}}
//|       - {"artifact":"damping","path":"/rows/1/5","range":{"min":0,"max":1e-15}}
//|       - {"artifact":"damping","path":"/rows/2/5","range":{"min":0,"max":1e-15}}
//|       - {"artifact":"damping","path":"/rows/3/5","range":{"min":0,"max":1e-15}}
//|       - {"artifact":"damping","path":"/rows/0/4","equals":null}
//|   - case: mild-diffusion
//|     expect:
//|       - {"artifact":"damping","path":"/rows/1/4","approx":{"value":0.23556877,"rtol":1e-6}}
//|       - {"artifact":"damping","path":"/rows/2/4","approx":{"value":0.20395824,"rtol":1e-6}}
//|       - {"artifact":"damping","path":"/rows/3/4","approx":{"value":0.20597864,"rtol":1e-6}}
//|       - {"artifact":"damping","path":"/rows/3/5","range":{"min":0,"max":1e-14}}
//|   - case: stiff-step
//|     expect:
//|       - {"artifact":"damping","path":"/rows/2/1","approx":{"value":-0.81818182,"rtol":1e-7}}
//|       - {"artifact":"damping","path":"/rows/2/2","approx":{"value":0.20081613,"rtol":1e-6}}
//|       - {"artifact":"damping","path":"/rows/2/4","approx":{"value":0.19769205,"rtol":1e-6}}
//|       - {"artifact":"damping","path":"/rows/3/4","approx":{"value":-0.0020362201,"rtol":1e-6}}
//|       - {"artifact":"damping","path":"/rows/2/5","range":{"min":0,"max":1e-14}}
//|   - case: long-startup
//|     expect:
//|       - {"artifact":"damping","path":"/rows/3/2","approx":{"value":9.5367432e-7,"rtol":1e-6}}
//|       - {"artifact":"damping","path":"/rows/3/4","approx":{"value":9.8145674e-7,"rtol":1e-6}}
//|       - {"artifact":"damping","path":"/rows/3/5","range":{"min":0,"max":1e-17}}
use scioxide_core::{Budget, ExecutionContext, RealScalar};
use scioxide_pde::{
    FieldData, FieldPoint, ParabolicOptions, ParabolicProblem, ParabolicScheme,
    StructuredFdmPlan,
};

let r = fourier_number;
let startup = rannacher_intervals.round() as usize;
let intervals = 8_i32;
let pi = core::f64::consts::PI;
// Closed forms (independent check). s = sin²(θ/2). Return each scheme's amplification (one interval, after eight intervals).
let closed_form = |theta: f64| {
    let s = RealScalar::powi(RealScalar::sin(theta / 2.0), 2);
    let exact = RealScalar::exp(-4.0 * r * s);
    let euler = 1.0 / (1.0 + 4.0 * r * s);
    let cn = (1.0 - 2.0 * r * s) / (1.0 + 2.0 * r * s);
    let half_pair = RealScalar::powi(1.0 / (1.0 + 2.0 * r * s), 2);
    let with_startup = RealScalar::powi(half_pair, startup as i32)
        * RealScalar::powi(cn, intervals - startup as i32);
    [
        (exact, RealScalar::powi(exact, intervals)),
        (euler, RealScalar::powi(euler, intervals)),
        (cn, RealScalar::powi(cn, intervals)),
        (if startup > 0 { half_pair } else { cn }, with_startup),
    ]
};
let names = [
    "Exact semidiscrete decay",
    "Backward Euler",
    "Crank–Nicolson",
    "Rannacher startup + CN",
];
let cells = 16_usize;
let h = 1.0 / cells as f64;
let dt = r * h * h;
let plan = StructuredFdmPlan::dirichlet_laplacian([0.0], [1.0], [cells + 1])
    .map_err(|e| e.to_string())?;
let source = FieldData::zero();
let problem =
    ParabolicProblem::new(&plan, &source, intervals as f64 * dt).map_err(|e| e.to_string())?;
// Advance 15 sine modes for eight intervals per scheme and measure amplification by projection onto the initial mode.
let measure =
    |scheme: ParabolicScheme, startup: usize| -> Result<(Vec<[f64; 2]>, usize), String> {
        let mut options = ParabolicOptions::new().with_step(dt).with_scheme(scheme);
        if startup > 0 {
            options = options
                .with_rannacher_startup(Budget::try_from(startup).map_err(|e| e.to_string())?);
        }
        let mut workspace = problem.workspace().map_err(|e| e.to_string())?;
        let mut measured = Vec::new();
        let mut factorizations = 0;
        for mode in 1..cells {
            let k = mode as f64 * pi;
            let initial = FieldData::time_invariant(move |p: FieldPoint<f64, 1>| {
                Ok(RealScalar::sin(k * p.point[0]))
            });
            let mut state = problem
                .initial_state(&initial, &options)
                .map_err(|e| e.to_string())?;
            let start = state.coordinates().to_vec();
            let report = problem
                .advance(
                    &options,
                    &mut state,
                    &mut (),
                    &mut workspace,
                    ExecutionContext::sequential(),
                )
                .map_err(|e| e.to_string())?;
            if !report.is_success() {
                return Err(format!("{}: {}", scheme.name(), report.termination()));
            }
            if mode == 1 {
                factorizations = report.diagnostics().num_factorizations();
            }
            let dot = |a: &[f64], b: &[f64]| a.iter().zip(b).map(|(x, y)| x * y).sum::<f64>();
            measured.push([
                mode as f64 * h,
                dot(state.coordinates(), &start) / dot(&start, &start),
            ]);
        }
        Ok((measured, factorizations))
    };
let runs = [
    measure(ParabolicScheme::BackwardEuler, 0)?,
    measure(ParabolicScheme::CrankNicolson, 0)?,
    measure(ParabolicScheme::CrankNicolson, startup)?,
];
let mut layers = Vec::new();
let mut rows = Vec::new();
let shortest = pi * (cells - 1) as f64 * h;
for (method, name) in names.iter().enumerate() {
    let curve = (0..=200)
        .map(|i| {
            let theta = pi * i as f64 / 200.0;
            [theta / pi, closed_form(theta)[method].1]
        })
        .collect::<Vec<_>>();
    let style = if method == 0 { "dotted" } else { "dashed" };
    layers.push(serde_json::json!({
        "id": format!("closed-{method}"),
        "kind": "line",
        "name": format!("{name} (closed form)"),
        "points": curve,
        "style": { "lineType": style }
    }));
    let predicted = closed_form(shortest)[method].1;
    let run = method.checked_sub(1).map(|m| &runs[m]);
    let highest = run.map(|(measured, _)| measured[cells - 2][1]);
    rows.push((
        *name,
        closed_form(pi)[method].0,
        closed_form(pi)[method].1,
        predicted,
        highest,
        highest.map(|value| (value - predicted).abs()),
        run.map(|(_, factorizations)| *factorizations),
    ));
    if let Some((measured, _)) = run {
        layers.push(serde_json::json!({
            "id": format!("measured-{method}"),
            "kind": "scatter",
            "name": format!("{name}（ParabolicProblem）"),
            "points": measured
        }));
    }
}
// Values below 0 indicate short-wavelength components persisting with sign reversals.
emit_chart!(serde_json::json!({
    "kind": "xy",
    "xLabel": "Normalized wave number θ/π [-]",
    "yLabel": "Signed amplification after eight intervals [-]",
    "dataZoom": true,
    "tooltip": true,
    "annotations": [{ "kind": "line", "axis": "y", "value": 0.0 }],
    "layers": layers
}));
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let sci5 = serde_json::json!({ "notation": "scientific", "significantDigits": 5 });
let columns = serde_json::json!([
    { "key": "0", "label": "Scheme" },
    { "key": "1", "label": "θ = π, one interval (closed form) [-]", "type": "number", "format": sci5 },
    { "key": "2", "label": "θ = π, after eight intervals (closed form) [-]", "type": "number", "format": sci5 },
    { "key": "3", "label": "θ = 15π/16, after eight intervals (closed form) [-]", "type": "number", "format": sci5 },
    { "key": "4", "label": "θ = 15π/16, after eight intervals (measured) [-]", "type": "number", "format": sci5, "nullText": "Not solved" },
    { "key": "5", "label": "Difference between measurement and closed form [-]", "type": "number", "format": sci3, "nullText": "—" },
    { "key": "6", "label": "Factorizations [count]", "type": "integer", "nullText": "—" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "damping" })
);
```

At the defaults $r=1.5$ and one startup interval, the differences between measured and closed-form values at $\theta=15\pi/16$ were $1.6\times10^{-22}$ for backward Euler, $2.2\times10^{-18}$ for Crank–Nicolson, and $2.7\times10^{-19}$ for Rannacher startup.
All three `ParabolicProblem` schemes reproduce closed-form amplification to roundoff level.
At $\theta=\pi$, Crank–Nicolson amplification over one interval is $-0.5$, leaving $(-0.5)^8=3.9\times10^{-3}$ after eight intervals.
One startup interval reduces this to $(1/16)\cdot(-0.5)^7=-4.9\times10^{-4}$, and four startup intervals to $9.5\times10^{-7}$.
Backward Euler gives $1.7\times10^{-7}$; all schemes remain far from the exact semidiscrete decay $1.4\times10^{-21}$.
For $r=0.05$, every scheme's amplification is positive, with values at $\theta=15\pi/16$ after eight intervals clustered at 0.20–0.24 and no sign reversal.

## Summary

Crank–Nicolson is A-stable but not L-stable: at large Fourier number $r$, shortest-wavelength amplification approaches $-1$, leaving sign-reversing grid-scale oscillations from step initial data.
Rannacher startup replaces the first few intervals with two backward Euler half steps each, driving their amplification toward 0 and suppressing oscillations.
Keeping the number of startup intervals fixed preserves second-order convergence for smooth solutions.
In `scioxide-pde`, specify the interval count through `ParabolicOptions::with_rannacher_startup`; startup can be combined only with the built-in `CrankNicolson`.
The state stores remaining startup, and preflight checks reject states inconsistent with settings during startup, so create initial states with the same settings used for advancing.
