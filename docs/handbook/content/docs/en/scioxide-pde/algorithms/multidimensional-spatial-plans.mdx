This page covers finite differences (FDM) with unknowns at the vertices of orthogonal structured grids.
`StructuredFdmPlan` handles grids with $D=1,2,3$ in a single type and discretizes linear diffusion–advection–reaction equations coupling $q$ fields.
It explains the derivation of conservative form over dual volumes, coefficient types, boundary conditions, matrix nonsymmetry from advection, and component coupling, then measures convergence orders using two-dimensional manufactured solutions.
Cell-centered finite volumes are covered in [Multidimensional finite volumes](../multidimensional-finite-volumes/), and finite elements on triangles and tetrahedra in [Finite elements on simplex meshes](../simplex-finite-elements/).

Spatial plans implement the shared [`SpatialDiscretization`](oxref:pde-spatial-discretization-contract).
A plan samples coefficients once during preparation and holds the time-independent operator $A$.
Boundary data and sources are called whenever the load $b(t)$ is evaluated.
The same `EllipticProblem`, `ParabolicProblem`, and `HyperbolicProblem` as in one dimension perform the solves; to use an iterative method, inject a Krylov method from `scioxide-linalg` with `EllipticWorkspace::with_linear_solver`.

## Finite differences on structured grids

`StructuredFdmPlan` discretizes the following system at the vertices of a $D$-dimensional orthogonal grid (`SegmentMesh`, `QuadMesh`, `HexMesh`, or generally `CellMesh`).

$$
-\nabla\cdot(k_c\nabla u_c)+\nabla\cdot(\mathbf{v}_cu_c)+\sum_{c'=1}^{q}C_{cc'}u_{c'}=f_c,\qquad c=1,\dots,q
$$

$u_c$ is the field of component $c$, $k_c\ge0$ the diffusion coefficient, $\mathbf{v}_c$ the advection velocity, $C$ the reaction matrix, and $f_c$ the source.
Diffusion and advection act independently on each component; only the reaction matrix $C$ couples components.

Supply coefficients through the trait `StructuredFdmCoefficients`.

- `diffusion(axis, component, point)` returns the diffusion coefficient in the direction of axis `axis` at the face center.
  Negative values are rejected during preparation; 0 is accepted.
  Different values can be returned for each axis, representing diagonal anisotropy aligned with the coordinate axes, but not a full tensor with cross terms.
- `advection(axis, component, point)` returns the signed velocity component along the axis.
  The default is 0.
- `reaction(row, column, point)` returns $C_{\text{row},\text{column}}$ at a vertex.
  The default is 0; complex values can be returned when the value type `V` is complex.

For a full diffusion tensor, use [Multidimensional finite volumes](../multidimensional-finite-volumes/) or [Finite elements on simplex meshes](../simplex-finite-elements/).

Unknowns are grouped by field: vertex $i$ of component $c$ is at index $c\,n+i$ (where $n$ is the number of unique vertices).
Vertex indices vary fastest along axis 0; on periodic axes, the vertices on both sides of the seam are combined into one unknown.
`node_point` and `volumes` return unique vertex coordinates and dual volumes; `pack_fields` and `apply_fields` convert between vertex fields on the full grid and the unknown sequence.

### Conservative form over dual volumes

The dual volume $V_i$ of vertex $i$ is a box bounded along each axis by midpoints to adjacent vertices.
The dual width $w_a(i)$ along axis $a$ is the average of the two neighboring grid spacings at an interior vertex and half the neighboring spacing at a boundary vertex, giving $V_i=\prod_a w_a(i)$.
Integrating the equation over $V_i$ and using the divergence theorem turns the diffusion and advection terms on the left into a sum of fluxes through the faces of $V_i$.

The face between a vertex and its neighbor $j$ along axis $a$ is centered at the edge midpoint $\mathbf{x}_f$ for spacing $h$, with area $A=\prod_{b\ne a}w_b(i)$.
Approximate the flux through this face from $i$ to $j$ as follows.

$$
F_{ij}=\underbrace{\frac{k(\mathbf{x}_f)\,A}{h}}_{g}\,(u_i-u_j)+\underbrace{\frac{v_a(\mathbf{x}_f)\,A}{2}}_{\beta}\,(u_i+u_j)
$$

The first term is a centered difference for the diffusive flux $-k\,\partial u/\partial x_a$; the second replaces the face value of the advective flux $v_au$ by the average of the two sides.
Representing reaction and source by vertex values gives $V_i\sum_{c'}C_{cc'}u_{c'}(\mathbf{x}_i)$ and $V_if_c(\mathbf{x}_i)$ (lumping).
The equation at vertex $i$ is $\sum_jF_{ij}+V_i\sum_{c'}C_{cc'}u_{c'}=V_if_c$; each face adds $g+\beta$ to the diagonal of row $i$ and $-g+\beta$ to column $j$.

The same $F_{ij}$ enters the equation at $j$ with the opposite sign, so interior-face fluxes cancel between the two dual volumes.
The interior truncation error is second order on uniform and smoothly varying grids, degrading to first order on arbitrary nonuniform grids.
In one dimension, these differences equal P1 finite elements with midpoint quadrature for stiffness and lumped reaction and load.

### Advection and matrix nonsymmetry

The equation in row $j$ includes $-F_{ij}$, so column $i$ of row $j$ receives $-g-\beta$.
The difference between the off-diagonal pair $(-g+\beta,\,-g-\beta)$ is $2\beta$, so advection makes the matrix nonsymmetric.
The same applies when the reaction matrix $C$ is nonsymmetric.
The larger entry of the pair, $-g+|\beta|$, becomes positive when the grid Péclet number $\mathrm{Pe}_h=|v|h/k$ exceeds 2.
The matrix then ceases to be an M-matrix, and the discrete maximum principle no longer holds, so solutions can oscillate near boundary layers.
The plan uses only centered averaging and provides no upwinding.
For advection-dominated problems, refine the grid until $\mathrm{Pe}_h\le2$ or use the finite volume method in [Conservation laws and numerical fluxes](../conservation-laws/).

CG cannot be used for nonsymmetric matrices.
Without an injected iterative method, `EllipticProblem` solves matrices in two or more dimensions by sparse LU factorization with fill-reducing ordering, making no symmetry assumption ([Default direct methods](oxref:pde-elliptic-solver-selection)).
For an iterative method, inject a solver for nonsymmetric systems such as GMRES (`scioxide_linalg::GmresSolver`).

### Boundary conditions

Specify boundary conditions with `StructuredBoundaries` (`BoundaryConditions` with `BoundarySet` regions), with exactly one condition required for each exterior-face/component pair.
Neumann data (`BoundaryCondition::natural`) specify the outward conormal flux $\mathbf{n}\cdot k\nabla u=g$; Robin conditions specify $\mathbf{n}\cdot k\nabla u+\alpha u=g$.
Each boundary vertex receives a fraction $1/2^{D-1}$ of the area from each incident exterior face, and data are added to the load with that area.
At Neumann and Robin faces, the advective outflow $(\mathbf{v}\cdot\mathbf{n})\,u$ passes through the face unchanged.

A Dirichlet face fixes the values of its vertices.
Dirichlet takes precedence at vertices shared by Neumann and Dirichlet faces; if two Dirichlet conditions prescribe different values at the same vertex, load evaluation fails by default (`DirichletConflictPolicy::Reject`).
`assemble_csr` eliminates fixed degrees of freedom symmetrically.
It decouples constrained rows and columns with diagonals set to 1, transferring constrained-column contributions in free rows to the load.
Thus, without advection and with symmetric $C$, the matrix is symmetric and can be solved by CG if positive definite.

If every boundary specifies conormal flux (Neumann or Robin with $\alpha=0$) and there is neither advection nor reaction, a constant mode remains for each component.
Check this with `has_constant_modes`, verify load compatibility with `check_constant_mode_compatibility`, then impose a [gauge](oxref:pde-nullspace-by-discretization).

### Component coupling and complexity

The reaction matrix $C$ connects only components at the same vertex, so reaction has at most $q^2$ nonzeros per vertex.
Boundary conditions can differ by component using `BoundaryCondition::for_component`.
A row has at most $2D+q$ nonzeros from itself, $2D$ neighbors, and the other $q-1$ components; preparation time and storage are proportional to the vertex count $n$ (for fixed $q$).
Passing `SpatialLimits::new(max_unknowns, max_entries, max_storage_bytes)` to `with_options` checks limits on unknowns, assembly triplets, and storage before allocation.
`StructuredFdmPlan::dirichlet_laplacian(lower, upper, nodes)` constructs $-\Delta$ with homogeneous Dirichlet conditions on a rectangular box in one call.

## Convergence of the two-dimensional Poisson equation

The following cell supplies the manufactured solution $u=x(1-x)\sin(m\pi y)$ for $-\Delta u=f$ on the unit square and solves with $N\times N$ vertices ($N=9,17,33$).
The source is $f=(2+(m\pi)^2x(1-x))\sin(m\pi y)$, with $u=0$ on the entire boundary.
The symmetrically eliminated matrix is symmetric positive definite, so CG (`scioxide_linalg::CgSolver`) is injected into the workspace of `EllipticProblem` and iterates to a relative residual of $10^{-12}$.
Read the iteration count from `PdeDiagnostics::num_linear_iterations` in the report.
The table shows the maximum vertex error and observed order $p=\log_2(e_{2h}/e_h)$ computed from the ratio to the next coarser grid.

```rust
//| id: pde-structured-poisson-order
//| ref: pde-structured-poisson-order
//| title: "Solve the Poisson equation on a two-dimensional structured grid and measure convergence order"
//| run: button
//| crates: [scioxide-core, scioxide-linalg, scioxide-pde, scioxide-spatial]
//| inputs:
//|   structured_mode: {"type":"range","label":"Sine mode m [-]","description":"Vary the manufactured solution's wavenumber in the y direction.","min":1,"max":3,"step":1,"value":1}
//| cases:
//|   - {"id":"third-mode","label":"m = 3","description":"The error at N = 33 rises to 1.65×10⁻³, but the observed order is 2.016, preserving second-order convergence.","inputs":{"structured_mode":3}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"orders","path":"/rows/2/1","equals":1089}
//|       - {"artifact":"orders","path":"/rows/2/2","equals":4809}
//|       - {"artifact":"orders","path":"/rows/2/3","range":{"min":15,"max":30}}
//|       - {"artifact":"orders","path":"/rows/0/4","approx":{"value":1.6581716e-3,"rtol":1e-6}}
//|       - {"artifact":"orders","path":"/rows/2/4","approx":{"value":1.0294922e-4,"rtol":1e-6}}
//|       - {"artifact":"orders","path":"/rows/0/5","equals":null}
//|       - {"artifact":"orders","path":"/rows/2/5","approx":{"value":2.002,"atol":1e-3}}
//|   - case: third-mode
//|     expect:
//|       - {"artifact":"orders","path":"/rows/2/4","approx":{"value":1.6534476e-3,"rtol":1e-6}}
//|       - {"artifact":"orders","path":"/rows/2/5","approx":{"value":2.016,"atol":1e-3}}
use scioxide_core::{Budget, ExecutionContext, SciOxideError, LinearOperator, ResidualTolerance};
use scioxide_linalg::CgSolver;
use scioxide_pde::{
    BoundaryCondition, BoundaryData, EllipticOptions, EllipticProblem, EllipticWorkspace,
    FieldData, FieldPoint, SpatialDiscretization, SpatialLimits, StructuredBoundaries,
    StructuredFdmCoefficients, StructuredFdmPlan,
};
use scioxide_spatial::{AxisSide, AxisTopology, BoundarySet, CoordinateAxis, Grid2d, QuadMesh};
use std::f64::consts::PI;

// -Δu = f: diffusion 1. Advection and reaction default to 0.
struct Laplace;
impl StructuredFdmCoefficients<f64, f64, 2> for Laplace {
    fn diffusion(&self, _: usize, _: usize, _: [f64; 2]) -> Result<f64, SciOxideError> {
        Ok(1.0)
    }
}
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let fixed3 = serde_json::json!({ "fractionDigits": 3 });
let k = structured_mode * PI;
// Manufactured solution u = x(1−x) sin(mπy) and source f = −Δu (using f64 sin for reference values).
let exact = move |p: [f64; 2]| p[0] * (1.0 - p[0]) * (k * p[1]).sin();
let source = FieldData::time_invariant(move |p: FieldPoint<f64, 2>| {
    let [x, y] = p.point;
    Ok((2.0 + k * k * x * (1.0 - x)) * (k * y).sin())
});
let elliptic = EllipticOptions::new();
let mut rows: Vec<(usize, usize, usize, usize, f64, Option<f64>)> = Vec::new();
for n in [9_usize, 17, 33] {
    let axis = CoordinateAxis::uniform(0.0, 1.0, n).map_err(|e| e.to_string())?;
    let grid = Grid2d::new([axis.clone(), axis], [AxisTopology::Bounded; 2])
        .map_err(|e| e.to_string())?;
    let mesh = QuadMesh::new(grid).map_err(|e| e.to_string())?;
    let mut conditions = Vec::new();
    for axis in 0..2 {
        for side in [AxisSide::Start, AxisSide::End] {
            let region =
                BoundarySet::axis_side(&mesh, axis, side).map_err(|e| e.to_string())?;
            conditions.push(BoundaryCondition::dirichlet(region, BoundaryData::zero()));
        }
    }
    let boundaries =
        StructuredBoundaries::new(&mesh, 1, conditions).map_err(|e| e.to_string())?;
    let limits = SpatialLimits::new(n * n, 20 * n * n, 1 << 24);
    let plan = StructuredFdmPlan::with_options(mesh, &Laplace, &boundaries, limits)
        .map_err(|e| e.to_string())?;
    // Solve the symmetrically eliminated operator with CG. Inject the iterative method into the workspace.
    let cg = CgSolver::new(
        ResidualTolerance::new(0.0, 1e-12).map_err(|e| e.to_string())?,
        Budget::try_from(4 * plan.unknowns()).map_err(|e| e.to_string())?,
    );
    let mut workspace = EllipticWorkspace::new().with_linear_solver(Box::new(cg));
    let mut values = vec![0.0; plan.unknowns()];
    let report = EllipticProblem::new(&plan, &source)
        .solve_into(
            &elliptic,
            &mut values,
            &mut workspace,
            ExecutionContext::sequential(),
        )
        .map_err(|e| e.to_string())?;
    if !report.is_success() {
        return Err(format!("N={n}: CG did not converge {}", report.termination()));
    }
    let mut error = 0.0_f64;
    for (node, u) in values.iter().enumerate() {
        let p = plan.dof_point(node).map_err(|e| e.to_string())?.point;
        error = error.max((u - exact(p)).abs());
    }
    let nonzeros = plan.assemble_csr().map_err(|e| e.to_string())?.nnz();
    // Grid spacing halves at each level, so the observed order is log₂ of the error ratio.
    let order = rows.last().map(|r| (r.4 / error).log2());
    let iterations = report.diagnostics().num_linear_iterations();
    rows.push((n, plan.rows(), nonzeros, iterations, error, order));
}
let columns = serde_json::json!([
    { "key": "0", "label": "Vertices per side N", "type": "integer" },
    { "key": "1", "label": "Unknowns", "type": "integer" },
    { "key": "2", "label": "CSR nonzero entries", "type": "integer" },
    { "key": "3", "label": "CG iterations", "type": "integer" },
    { "key": "4", "label": "Maximum vertex error [-]", "type": "number", "format": sci3 },
    { "key": "5", "label": "Observed order [-]", "type": "number", "format": fixed3, "nullText": "—" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "orders" })
);
```

With the default ($m=1$), maximum vertex errors at $N=9,17,33$ were $1.66\times10^{-3}$, $4.12\times10^{-4}$, and $1.03\times10^{-4}$, decreasing to about 1/4 of the previous error each time the spacing halved, with an observed order of 2.002.
For $m=3$, it is also 2.016.
The solution is quadratic in $x$ and has no centered-difference truncation error, so error arises only from the sine function in the $y$ direction.
There are $N^2$ unknowns, including boundary vertices; boundary rows retain only their diagonal entries.

CG requires only 21 iterations for 1089 unknowns.
On a uniform grid, $\sin(m\pi y_j)$ is an eigenvector of the difference operator in the $y$ direction, so load and solution lie along that single mode, and the Krylov subspace effectively grows within a one-dimensional problem in the $x$ direction.
General loads require more iterations; consider preconditioning (such as Jacobi or incomplete factorizations in `scioxide-sparse`).

## Convergence of a coupled advection–diffusion–reaction system

The following cell solves a two-component system on the unit square, coupled through reaction, with variable-coefficient diffusion and advection only in the first component.

$$
\begin{aligned}
-\nabla\cdot(k\nabla u_1)+b\,\partial_xu_1+u_1+\gamma u_2&=f_1,\\
-\Delta u_2-\gamma u_1+u_2&=f_2,
\end{aligned}
\qquad k(x,y)=1+\tfrac12xy
$$

The manufactured solutions are $u_1=\sin\pi x\sin\pi y$ and $u_2=\sin2\pi x\sin\pi y$, with $u_1=u_2=0$ on the entire boundary.
$b$ is the uniform advection velocity in the $x$ direction, and $\gamma$ is the off-diagonal entry of the reaction matrix $C=\begin{pmatrix}1&\gamma\\-\gamma&1\end{pmatrix}$.
The matrix is symmetric if $b=\gamma=0$ and nonsymmetric if either is nonzero.
It uses the default sparse LU factorization of `EllipticProblem` without injecting an iterative method.
The table's asymmetry measure is $\max_{ij}|a_{ij}-a_{ji}|/\max_{ij}|a_{ij}|$ for the assembled matrix $A$.

```rust
//| id: pde-structured-fdm-order
//| ref: pde-structured-fdm-order
//| title: "Solve a reaction-coupled two-component advection–diffusion–reaction system and measure convergence orders and matrix asymmetry"
//| run: button
//| crates: [scioxide-core, scioxide-pde, scioxide-spatial]
//| inputs:
//|   velocity: {"type":"range","label":"Advection velocity b [-]","description":"Velocity of the first component in the x direction.","min":0,"max":40,"step":5,"value":10}
//|   coupling: {"type":"range","label":"Reaction off-diagonal γ [-]","description":"Off-diagonal entry of the reaction matrix [[1, γ], [−γ, 1]].","min":0,"max":2,"step":0.5,"value":1}
//| cases:
//|   - {"id":"symmetric","label":"b = 0, γ = 0","description":"Without advection or nonsymmetric reaction, the matrix asymmetry measure is 0.","inputs":{"velocity":0,"coupling":0}}
//|   - {"id":"strong-advection","label":"b = 40","description":"At N = 9 and 17, the grid Péclet upper bound exceeds 2 and positive off-diagonal entries appear, but the smooth solution retains second-order convergence.","inputs":{"velocity":40}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"system","path":"/rows/0/2","equals":0}
//|       - {"artifact":"system","path":"/rows/2/3","range":{"min":0.01,"max":1}}
//|       - {"artifact":"system","path":"/rows/2/6","approx":{"value":2.0,"atol":0.1}}
//|       - {"artifact":"system","path":"/rows/2/7","approx":{"value":2.0,"atol":0.1}}
//|   - case: symmetric
//|     expect:
//|       - {"artifact":"system","path":"/rows/2/3","range":{"max":1e-15}}
//|       - {"artifact":"system","path":"/rows/2/6","approx":{"value":2.0,"atol":0.1}}
//|   - case: strong-advection
//|     expect:
//|       - {"artifact":"system","path":"/rows/0/1","approx":{"value":5,"rtol":1e-12}}
//|       - {"artifact":"system","path":"/rows/0/2","range":{"min":1}}
//|       - {"artifact":"system","path":"/rows/2/2","equals":0}
//|       - {"artifact":"system","path":"/rows/2/6","approx":{"value":2.0,"atol":0.2}}
use scioxide_core::SciOxideError;
use scioxide_pde::{
    BoundaryCondition, BoundaryData, EllipticOptions, EllipticProblem, FieldData, FieldPoint,
    SpatialDiscretization, StructuredBoundaries, StructuredFdmCoefficients, StructuredFdmPlan,
};
use scioxide_spatial::{AxisSide, AxisTopology, BoundarySet, CoordinateAxis, Grid2d, QuadMesh};
use std::collections::HashMap;
use std::f64::consts::PI;

// First component: diffusion k = 1 + xy/2 and x-direction velocity b. Second component: diffusion 1. Reaction [[1, γ], [−γ, 1]].
struct System {
    velocity: f64,
    coupling: f64,
}
impl StructuredFdmCoefficients<f64, f64, 2> for System {
    fn diffusion(&self, _: usize, component: usize, p: [f64; 2]) -> Result<f64, SciOxideError> {
        Ok(if component == 0 {
            1.0 + 0.5 * p[0] * p[1]
        } else {
            1.0
        })
    }
    fn advection(
        &self,
        axis: usize,
        component: usize,
        _: [f64; 2],
    ) -> Result<f64, SciOxideError> {
        Ok(if axis == 0 && component == 0 {
            self.velocity
        } else {
            0.0
        })
    }
    fn reaction(&self, row: usize, column: usize, _: [f64; 2]) -> Result<f64, SciOxideError> {
        let c = [[1.0, self.coupling], [-self.coupling, 1.0]];
        Ok(c[row][column])
    }
}
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let fixed2 = serde_json::json!({ "fractionDigits": 2 });
let fixed3 = serde_json::json!({ "fractionDigits": 3 });
let (b, g) = (velocity, coupling);
// Manufactured solutions (using f64 sin and cos for reference values).
let u1 = |x: f64, y: f64| (PI * x).sin() * (PI * y).sin();
let u2 = |x: f64, y: f64| (2.0 * PI * x).sin() * (PI * y).sin();
let source = FieldData::time_invariant(move |p: FieldPoint<f64, 2>| {
    let [x, y] = p.point;
    let (sx, cx, sy, cy) = (
        (PI * x).sin(),
        (PI * x).cos(),
        (PI * y).sin(),
        (PI * y).cos(),
    );
    let (a, c) = (u1(x, y), u2(x, y));
    Ok(if p.component == 0 {
        // −∇·(k∇u₁) = 2π²k u₁ − ∇k·∇u₁, with advection b ∂u₁/∂x.
        let diffusion =
            2.0 * PI * PI * (1.0 + 0.5 * x * y) * a - 0.5 * PI * (y * cx * sy + x * sx * cy);
        diffusion + b * PI * cx * sy + a + g * c
    } else {
        5.0 * PI * PI * c - g * a + c
    })
});
let coefficients = System {
    velocity: b,
    coupling: g,
};
let mut rows: Vec<(usize, f64, usize, f64, f64, f64, Option<f64>, Option<f64>)> = Vec::new();
for n in [9_usize, 17, 33] {
    let axis = CoordinateAxis::uniform(0.0, 1.0, n).map_err(|e| e.to_string())?;
    let grid = Grid2d::new([axis.clone(), axis], [AxisTopology::Bounded; 2])
        .map_err(|e| e.to_string())?;
    let mesh = QuadMesh::new(grid).map_err(|e| e.to_string())?;
    let mut conditions = Vec::new();
    for axis in 0..2 {
        for side in [AxisSide::Start, AxisSide::End] {
            let region =
                BoundarySet::axis_side(&mesh, axis, side).map_err(|e| e.to_string())?;
            conditions.push(BoundaryCondition::dirichlet(region, BoundaryData::zero()));
        }
    }
    // A condition without a specified component applies to both components.
    let boundaries =
        StructuredBoundaries::new(&mesh, 2, conditions).map_err(|e| e.to_string())?;
    let plan =
        StructuredFdmPlan::new(mesh, &coefficients, &boundaries).map_err(|e| e.to_string())?;
    let solution = EllipticProblem::new(&plan, &source)
        .solve_with_options(&EllipticOptions::new())
        .map_err(|e| e.to_string())?;
    if !solution.report().is_success() {
        return Err(format!("N={n}: {}", solution.report().termination()));
    }
    // Asymmetry max|a_ij − a_ji| / max|a_ij| and the number of positive off-diagonal entries within the u₁ component.
    let matrix = plan.assemble_csr().map_err(|e| e.to_string())?;
    let mut entries = HashMap::new();
    let mut positive = 0_usize;
    for row in 0..matrix.rows() {
        for index in matrix.row_ptr()[row]..matrix.row_ptr()[row + 1] {
            let (column, value) = (matrix.col_indices()[index], matrix.values()[index]);
            if row != column && row < n * n && column < n * n && value > 0.0 {
                positive += 1;
            }
            entries.insert((row, column), value);
        }
    }
    let scale = entries.values().fold(0.0_f64, |m, v| m.max(v.abs()));
    let defect = entries.iter().fold(0.0_f64, |m, (&(i, j), &v)| {
        m.max((v - entries.get(&(j, i)).copied().unwrap_or(0.0)).abs())
    });
    let mut errors = [0.0_f64; 2];
    for (unknown, value) in solution.values().iter().enumerate() {
        let site = plan.dof_point(unknown).map_err(|e| e.to_string())?;
        let [x, y] = site.point;
        let exact = if site.component == 0 {
            u1(x, y)
        } else {
            u2(x, y)
        };
        errors[site.component] = errors[site.component].max((value - exact).abs());
    }
    let h = 1.0 / (n - 1) as f64;
    // Since k ≥ 1, bh bounds the grid Péclet number bh/k from above.
    let peclet = b * h;
    let orders = rows
        .last()
        .map(|r| ((r.4 / errors[0]).log2(), (r.5 / errors[1]).log2()));
    let (p1, p2) = (orders.map(|o| o.0), orders.map(|o| o.1));
    rows.push((
        n,
        peclet,
        positive,
        defect / scale,
        errors[0],
        errors[1],
        p1,
        p2,
    ));
}
```

With the defaults ($b=10$, $\gamma=1$), maximum errors in $u_1$ at $N=9,17,33$ were $1.69\times10^{-2}$, $4.30\times10^{-3}$, and $1.07\times10^{-3}$, decreasing to about 1/4 of the previous error each time, with an observed order of 2.001.
The observed order for $u_2$ is also 2.006: even with variable coefficients, advection, and component coupling, the second-order interior truncation error yields the same global error order.
The asymmetry at $N=33$ is $5.3\times10^{-2}$; since the ratio of the advection term $\beta=bA/2$ to the diffusion term $g=kA/h$ is proportional to $h$, it roughly halves whenever the grid spacing halves.
For $b=\gamma=0$, the asymmetry is exactly 0.
This is because coefficient $k$ is sampled once at the face center, with the same value entering the rows on both sides of the face.

With $b=40$, the grid Péclet upper bound at $N=9$ is 5, and 42 positive off-diagonal entries appear within the $u_1$ component.
There are still 183 at $N=17$, falling to 0 at $N=33$ (upper bound 1.25).
This manufactured solution is smooth with no boundary layer, so even when the matrix ceases to be an M-matrix, the observed order is 1.998 and second-order convergence is retained.
For a solution with a boundary layer, using a grid with $\mathrm{Pe}_h>2$ can make the discrete solution oscillate before the boundary layer.

## Summary

`StructuredFdmPlan` discretizes coupled diffusion–advection–reaction equations at structured-grid vertices as balances of fluxes through dual-volume faces.
Diffusion is sampled by axis at face centers, supporting diagonal anisotropy aligned with the axes; use finite volumes or finite elements for full tensors.
Advection uses the average across each face without upwinding, so choose a grid with grid Péclet number $|v|h/k$ at most 2.
Advection or nonsymmetric reaction makes the matrix nonsymmetric; solve with the default sparse LU factorization or a method such as GMRES, while pure diffusion problems can use injected CG.
For two-dimensional manufactured solutions, maximum vertex errors converged at second order for both the Poisson equation and the coupled advection–diffusion–reaction system.
