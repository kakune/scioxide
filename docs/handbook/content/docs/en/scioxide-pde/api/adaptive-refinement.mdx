This page collects the items used in mesh refinement driven by error estimates.
`AdaptiveMesh` in `scioxide-spatial` owns mesh topology and refinement execution (balance checks and commitment); this crate provides nodal spaces, diffusion assembly, error estimation, marking, and field transfer.
The user chooses the linear-system solver.
One cycle proceeds by solving, estimating with `AmrEstimator::estimate_into`, marking with `AmrMarking::mark`, changing topology with `AdaptiveMesh::adapt(marks.request())`, constructing a new `AmrSpace` and transferring labels with `AmrBoundaryTags::transfer`, then transferring fields with `AmrNodalTransfer` or `AmrCellTransfer`.
Replace old spaces, labels, and fields with the new ones only after every stage succeeds.
Boundary conditions use the same `BoundaryCondition` vocabulary as other families and bind to an adaptive-mesh revision through `TaggedBoundaries::adaptive`.

## Summary

Construct adaptive refinement as a cycle in which the user successively calls estimation, marking, topology modification, and field transfer.
The estimator is an indicator for shape-regular scalar diffusion, not an upper bound on error.
Marking deterministically selects a fraction of total squared contributions; `scioxide-spatial` performs balance checks and commitment.
For field transfer, choose cell-average conservation (`AmrCellTransfer`) or nodal interpolation and $L^2$ projection (`AmrNodalTransfer`) according to the task.
Every preparation can restrict resources with `AmrLimits`, supplying limits or an execution context through `with_options` or `build`.
