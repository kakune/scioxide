This page collects items for obtaining parameter gradients of a discretized PDE objective $J$ by adjoint methods.
Linear Plans assemble derivatives of their coefficients, sources, and boundary data as `PdeParameterization`, used by `PdeEllipticAdjointPlan` and `PdeTransientAdjointPlan`.
For other residuals, `PdeDiscretizationDerivatives` performs implicit differentiation using derivative operators supplied by the caller.
Mesh coordinates are not differentiated; geometry, quadrature, and the boundary partition remain fixed.
Adjoint Plans in `scioxide-ode` handle reverse time sweeps and checkpoints; supply the objective through `scioxide_ode::AdjointObjective`.
The resulting gradient is for the discretized problem and does not guarantee gradient accuracy for the continuous problem.

## Steady-problem adjoints

At equilibrium $R(u,p)=0$, solve the adjoint equation $R_u^{*}\lambda=J_u$ to obtain the total gradient $dJ/dp=J_p-R_p^{*}\lambda$.
The user computes the equilibrium first, and the Plan checks it using the primal tolerance.

## Time-evolution adjoints

`PdeTransientAdjointPlan` differentiates the fixed-step time discretization itself, integrated by `ParabolicProblem` with the same `ParabolicScheme`, over the method-of-lines system $Mu_f'=b_f(t,p)-(A(p)u)_f$ of free unknowns.
Backward Euler corresponds to `DaeAdjointSolver::backward_euler`, Crank–Nicolson to `DaeAdjointSolver::trapezoid`, and DOPRI5 to `OdeAdjointSolver` with the adapter's step limit.

## Summary

For linear Plans, construct coefficient, source, and boundary-data derivatives with `parameterize`, then obtain gradients with `PdeEllipticAdjointPlan` for steady problems or `PdeTransientAdjointPlan` for parabolic evolution.
For other residuals, bind residual and derivative operators with `PdeDiscretizationDerivatives`; the Plan independently checks results from caller-provided linear solver `PdeLinearSolve`.
The user computes the equilibrium first; the adjoint Plan checks it with the primal tolerance before committing the gradient to output.
Pass gradients across refinement to the adjacent epoch through the pullback of `PdeTransferDerivatives`.
No adjoint differentiates mesh coordinates; all resulting gradients are for the discretized problem.
