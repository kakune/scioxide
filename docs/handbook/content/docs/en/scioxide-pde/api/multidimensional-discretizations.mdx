This page collects four plans that prepare spatial operators in one to three dimensions.
Every plan handles $D=1,2,3$ with a single type and implements `SpatialDiscretization`, `scioxide_core::LinearOperator`, and `DifferentiableDiscretization`.
Coefficients are sampled during preparation; sources and boundary data are evaluated at the requested time each time the load is evaluated.
Plans do not solve systems of equations.
Pass them to `EllipticProblem`, `ParabolicProblem`, or `HyperbolicProblem`, or choose a Krylov method from `scioxide-linalg` or a direct method from `scioxide-sparse` yourself and check convergence through its termination reason.
Meshes are structured grids `CellMesh` (`SegmentMesh`, `QuadMesh`, `HexMesh`) and simplex meshes `SimplexMesh` (`IntervalMesh`, `TriangleMesh`, `TetrahedronMesh`) from `scioxide-spatial`; boundary conditions and fields from a different mesh revision are rejected.
Each plan prepares without limits through `new`; `with_options` supplies resource limits and quadrature and execution settings.

## Finite differences on structured grids

Discretize $-\nabla\cdot(k\nabla u)+\nabla\cdot(vu)+Cu=f$ with vertex values for each component.
Diffusion and advection are diagonal in components; the reaction matrix $C$ couples components.
Unknowns are grouped by component in vertex order, with axis 0 varying fastest.
Vertices at the seam of a periodic axis are identified as a single unknown.
Each interior face supplies conductance $k\cdot\text{area}/h$ from $k$ sampled at the face center; reaction and source terms are lumped over dual control volumes.
Consequently, in one dimension the equations coincide with P1 finite elements using midpoint-rule stiffness and lumped reaction and load.
Interior truncation error is second order on uniform or smoothly varying axes and first order on arbitrary nonuniform axes; boundary relations are second order.

## Finite elements on simplex meshes

Assemble elliptic weak forms with coupled anisotropic diffusion $K_{ab}$ and a reaction matrix using continuous P1 or P2 elements on intervals, triangles, and tetrahedra.
Geometry is either an affine map determined by vertices or a quadratic map sharing physical coordinates at edge midpoints, chosen independently of the solution degree.
Natural-boundary data are outward conormal fluxes $n\cdot\sum_b K_{ab}\nabla u_b$; Robin data add $\alpha u$.
Dirichlet nodes are eliminated symmetrically.
Preparation allocates once; borrowed application and evaluation allocate nothing.
For fixed degree and component count, storage and application cost are proportional to the number of cells.
When coefficients declare spatial constancy, the plan evaluates diffusion and reaction only once; for affine geometry it also computes reference-element basis moments once and transforms them with each cell's map.
Matrix structure (including numerical zero entries) is fixed during preparation; `assemble_csr_into` uses the workspace of `assembly_workspace` to rewrite values into existing CSR with the same structure without allocation.

## Cell-centered finite volumes

Discretize $-\nabla\cdot(K\nabla u)+cu=f$ with cell values.
$K$ may be a full real symmetric positive-definite tensor; asymmetry at the rounding level is projected to the symmetric part.
Interior face fluxes are constructed by eliminating the shared face value using the two cells' half-cell laws; adjacent cells use the same flux with opposite signs, so interior contributions cancel.
Preparation rejects nonpositive half-cell conductances, but positive conductance does not imply an M-matrix for general skewed geometry or anisotropic tensors.
Boundary data remain symbolic and are evaluated at the requested time for loads and face fluxes.
Dirichlet values enter through boundary-face laws, so there are no constrained unknowns.
Only single-component scalar fields are supported.

## Summary

The four plans construct operators and loads under the same contract and can be passed to steady and time-evolution solves or to your own solver.
Structured-grid FDM and simplex FEM eliminate Dirichlet nodes symmetrically; cell-centered FVM imposes Dirichlet values through face laws and has no constrained unknowns.
FVM face fluxes are conservative, oriented toward increasing coordinates on structured grids and outward from the first incident cell on simplex meshes.
When repeatedly assembling simplex FEM matrices, use the workspace of `assembly_workspace` to rewrite CSR with the same structure without allocation.
Preparation resources can be limited before allocation with `SpatialLimits` and `SimplexFemLimits`.
