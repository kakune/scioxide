Small transverse vibrations of a tensioned string are a basic physical model for hyperbolic partial differential equations.
Smooth-looking displacements over a short time need not imply high accuracy.
The spatial grid introduces wavelength-dependent phase speeds (numerical dispersion), gradually delaying wave phase.

This page evolves one eigenmode of a string fixed at both ends using FDM, FEM, and FVM plans with `HyperbolicProblem`.
Separate final error into time-integration error and phase lag from the spatial grid, and measure which dominates.
See [String overtone pitches and mass matrices](../string-overtone-dispersion/) for grid-induced overtone pitch shifts.

## Wave equation for a string fixed at both ends

Let $u(x, t)$ [m] be transverse displacement of a string of length $L$ [m], with uniform linear density $\rho$ [kg/m] and tension $T$ [N].
The difference in transverse tension components acting on a small interval $[x, x + \Delta x]$ and Newton's equation of motion give the one-dimensional wave equation

$$
\rho\, u_{tt} = T\, u_{xx}
\quad\Longleftrightarrow\quad
u_{tt} = c^2 u_{xx}, \qquad c = \sqrt{T/\rho}
$$


$c$ [m/s] is the wave speed.
Fixing both ends gives homogeneous Dirichlet conditions $u(0, t) = u(L, t) = 0$.

With zero initial velocity and initial displacement in eigenmode $m$, $u(x, 0) = A\sin(k_m x)$ ($k_m = m\pi/L$), of amplitude $A$ [m], the exact solution is the standing wave

$$
u(x, t) = A\cos(\omega_m t)\sin(k_m x), \qquad \omega_m = c\,k_m = \frac{m\pi c}{L}
$$

Its period is $P_m = 2\pi/\omega_m = 2L/(mc)$.
This example considers a string of length $L = 0.65$ m and wave speed $c = 143$ m/s.
The fundamental frequency is $c/(2L) = 110$ Hz, corresponding to a guitar's fifth string (A2).
Set amplitude $A = 1$ mm.

## Semidiscrete system and two errors

Replacing $u_{xx}$ with a three-point central difference on uniform grid spacing $h = L/(N - 1)$ gives the ordinary differential system (semidiscrete system) for unknowns $u_j(t) \approx u(x_j, t)$:

$$
\ddot u_j = c^2\,\frac{u_{j-1} - 2u_j + u_{j+1}}{h^2}
$$


Discrete sine $\sin(k_m x_j)$ is an eigenvector of this system, whose exact semidiscrete solution is $u_j(t) = A\cos(\omega_{h,m} t)\sin(k_m x_j)$.
Its angular frequency is

$$
\omega_{h,m} = \frac{2c}{h}\sin\frac{k_m h}{2} < \omega_m
$$

This is slightly smaller than the continuous frequency $\omega_m$.
P1 FEM elements give the same formula on a uniform grid when using lumped mass (the diagonal matrix of mass-matrix row sums).

Thus the difference between the numerical and exact continuous solutions has two parts.

1. **Spatial error:** the semidiscrete solution oscillates with phase $\omega_{h,m} t$, accumulating phase lag $(\omega_m - \omega_{h,m})t$ by time $t$.
2. **Temporal error:** time integration only approximates the semidiscrete solution; their difference is time-integration error.

Measure temporal error by comparing the following modal amplitude, obtained by projecting the numerical solution onto the eigenvector,

$$
a(t) = \frac{\sum_j u_j(t)\sin(k_m x_j)}{A\sum_j \sin^2(k_m x_j)}
$$

with $\cos(\omega_{h,m}t)$.
This excludes spatial error, allowing the two errors to be read separately.

## Time integration and step limits

`HyperbolicProblem::new(&plan, &source, end)` constructs $M\ddot u = b(t) - Au$ from the plan operator $A$ and lumped mass $M$.
`solve_with_options(&displacement, &velocity, &options)` integrates the first-order system of displacement followed by velocity from $t = 0$ to `end` with adaptive Dormand–Prince 5(4) (DOPRI5).
Default absolute and relative local-error tolerances are both $10^{-8}$, and errors are measured in the RMS norm.
For wave problems, pass $c^2$ as the diffusion coefficient to the three plans through their coefficient providers.

The default `CflPolicy::Automatic` of `HyperbolicOptions` limits step sizes to $0.9 \times 0.9971/\sqrt\rho$ using an upper bound $\rho$ on the spectral radius of mass-normalized stiffness.
0.9971 is the endpoint of the interval $|y| \le 0.9971$ on the imaginary axis where DOPRI5's stability function $R(z)$ satisfies $|R(iy)| \le 1$.
Eigenvalues of the first-order displacement/velocity system are $\pm i\sqrt{\lambda}$ ($\lambda$ are eigenvalues of mass-normalized stiffness), so step $\Delta t$ is stable if $\Delta t\sqrt\rho \le 0.9971$.
For three-point differences, $\rho \approx 4c^2/h^2$, giving a limit of about $0.45\,h/c$.
`CflPolicy::Disabled` removes this limit, selecting steps solely through local-error control.
Selecting `PdeOutputSchedule::TimeSteps` returns the initial field and the field at each accepted step through `PdeSolution::trajectory`.

## Tracking modes with three plans

The next cell solves the same initial data with FDM (`StructuredFdmPlan`), P1 FEM (`SimplexFemPlan`), and cell-centered FVM (`StructuredFvmPlan`).
Inputs are mode number $m$, grid-point count $N$, integer cycle count $K$, local-error tolerance, and whether to impose the stability step limit.
Set final time $t_{\mathrm{end}} = (K + 1/8)P_m$.
At exact integer cycles the slope of $\cos$ is zero, making phase lag hard to detect in displacement differences, so offset by 1/8 cycle.

Outputs are a final-displacement plot, a table of termination reason, accepted and rejected steps, and maximum error against the continuous solution for each plan, and conclusions of all three solves.
Maximum error is divided by amplitude $A$.
The three plans share `SpatialDiscretization`, so solve them with one function `track` and read unknown locations through `dof_point`.
FVM unknowns are cell-center values.
Also compute modal amplitude $a(t)$ at each step and pass it to the next cell.

```rust
use scioxide_core::{ErrorTolerance, SciOxideError, NormSelection};
use scioxide_pde::{
    BoundaryCondition, BoundaryData, CflPolicy, FieldData, FieldPoint, FvmCoefficients,
    HyperbolicOptions, HyperbolicProblem, PdeOutputSchedule, SimplexFemCoefficients,
    SimplexFemGeometry, SimplexFemOrder, SimplexFemPlan, SpatialDiscretization,
    StructuredBoundaries, StructuredFdmCoefficients, StructuredFdmPlan, StructuredFvmPlan,
    TaggedBoundaries,
};
use scioxide_spatial::{
    AxisSide, AxisTopology, BoundarySet, CoordinateAxis, Grid1d, IntervalMesh, Point,
    SegmentMesh, SimplexBoundaryTags,
};
use std::f64::consts::PI;

// For wave problems, pass squared wave speed c² [m²/s²] as the diffusion coefficient.
struct SquaredSpeed(f64);
impl StructuredFdmCoefficients<f64, f64, 1> for SquaredSpeed {
    fn diffusion(&self, _: usize, _: usize, _: [f64; 1]) -> Result<f64, SciOxideError> {
        Ok(self.0)
    }
}
impl FvmCoefficients<f64, f64, 1> for SquaredSpeed {
    fn diffusion(&self, _: [f64; 1]) -> Result<[[f64; 1]; 1], SciOxideError> {
        Ok([[self.0]])
    }
}
impl SimplexFemCoefficients<f64, f64, 1> for SquaredSpeed {
    fn evaluate(&self, _: [f64; 1], k: &mut [f64], c: &mut [f64]) -> Result<(), SciOxideError> {
        (k[0], c[0]) = (self.0, 0.0);
        Ok(())
    }
}
/// Solve and return (termination reason, accepted, rejected, maximum continuous-solution error / A, final displacement, times, a(t)).
type Track = (String, usize, usize, f64, Vec<[f64; 2]>, Vec<f64>, Vec<f64>);
fn track<P: SpatialDiscretization<f64, f64, 1>>(
    plan: &P,
    options: &HyperbolicOptions<f64>,
    [k, omega, amplitude, end]: [f64; 4],
) -> Result<Track, String> {
    let source = FieldData::zero();
    // Initial displacement A sin(kx) (supplied using f64 sin as a reference), initial velocity 0.
    let displacement = FieldData::time_invariant(move |p: FieldPoint<f64, 1>| {
        Ok(amplitude * (k * p.point[0]).sin())
    });
    let problem = HyperbolicProblem::new(plan, &source, end).map_err(|e| e.to_string())?;
    let solution = problem
        .solve_with_options(&displacement, &FieldData::zero(), options)
        .map_err(|e| e.error().to_string())?;
    let mut x = Vec::new();
    for unknown in 0..plan.unknowns() {
        x.push(plan.dof_point(unknown).map_err(|e| e.to_string())?.point[0]);
    }
    let u = solution.values();
    let error = x
        .iter()
        .zip(u)
        .map(|(x, v)| (v / amplitude - (omega * end).cos() * (k * x).sin()).abs())
        .fold(0.0_f64, f64::max);
    // At each accepted step compute a(t) = Σ u sin(kx) / (A Σ sin²(kx)).
    let norm: f64 = x.iter().map(|x| (k * x).sin().powi(2)).sum::<f64>() * amplitude;
    let trajectory = solution.trajectory();
    let modal = trajectory
        .states()
        .iter()
        .map(|state| {
            state
                .iter()
                .zip(&x)
                .map(|(v, x)| v * (k * x).sin())
                .sum::<f64>()
                / norm
        })
        .collect();
    let report = solution.report();
    let d = report.diagnostics();
    Ok((
        report.termination().to_string(),
        d.num_accepted_steps(),
        d.num_rejected_steps(),
        error,
        x.iter().zip(u).map(|(x, v)| [*x, v / amplitude]).collect(),
        trajectory.times().to_vec(),
        modal,
    ))
}
// String of length L = 0.65 m, c = 143 m/s (fundamental frequency 110 Hz), amplitude A = 1 mm.
let (length, c, amplitude) = (0.65, 143.0, 1e-3);
let nodes = string_grid_nodes as usize;
let k = string_mode_number * PI / length;
let (omega, h) = (c * k, length / (nodes - 1) as f64);
let end = (string_completed_cycles + 0.125) * 2.0 * PI / omega;
let axis = CoordinateAxis::uniform(0.0, length, nodes).map_err(|e| e.to_string())?;
let grid = Grid1d::new([axis], [AxisTopology::Bounded]).map_err(|e| e.to_string())?;
let segment = SegmentMesh::new(grid).map_err(|e| e.to_string())?;
let mut ends = Vec::new();
for side in [AxisSide::Start, AxisSide::End] {
    let set = BoundarySet::axis_side(&segment, 0, side).map_err(|e| e.to_string())?;
    ends.push(BoundaryCondition::dirichlet(set, BoundaryData::zero()));
}
let ends = StructuredBoundaries::new(&segment, 1, ends).map_err(|e| e.to_string())?;
let points = (0..nodes)
    .map(|i| Point::new([i as f64 * h]))
    .collect::<Result<Vec<_>, _>>()
    .map_err(|e| e.to_string())?;
let interval = IntervalMesh::new(points, (0..nodes - 1).map(|i| [i, i + 1]).collect())
    .map_err(|e| e.to_string())?;
let faces = interval.boundary_faces().map(|f| (f, 0)).collect();
let tags = SimplexBoundaryTags::new(&interval, faces).map_err(|e| e.to_string())?;
let fixed = vec![BoundaryCondition::dirichlet(0, BoundaryData::zero())];
let tagged = TaggedBoundaries::new(&interval, &tags, 1, fixed).map_err(|e| e.to_string())?;
let speed = SquaredSpeed(c * c);
let fdm = StructuredFdmPlan::new(segment.clone(), &speed, &ends).map_err(|e| e.to_string())?;
let fvm = StructuredFvmPlan::new(segment, &speed, &ends).map_err(|e| e.to_string())?;
let (affine, p1) = (SimplexFemGeometry::Affine, SimplexFemOrder::P1);
let fem =
    SimplexFemPlan::new(interval, affine, p1, &speed, &tagged).map_err(|e| e.to_string())?;
let tolerance: f64 = string_tolerance.parse().map_err(|_| "Cannot read tolerance")?;
let control = ErrorTolerance::scalar(tolerance, tolerance, NormSelection::RootMeanSquare)
    .map_err(|e| e.to_string())?;
let cfl = if string_cfl == "Automatic" {
    CflPolicy::Automatic
} else {
    CflPolicy::Disabled
};
let options = HyperbolicOptions::new()
    .with_error_tolerance(control)
    .with_cfl_policy(cfl)
    .with_output_schedule(PdeOutputSchedule::TimeSteps);
let parameters = [k, omega, amplitude, end];
let results = [
    ("FDM", track(&fdm, &options, parameters)?),
    ("FEM", track(&fem, &options, parameters)?),
    ("FVM", track(&fvm, &options, parameters)?),
];
let exact: Vec<[f64; 2]> = (0..=200)
    .map(|i| i as f64 * length / 200.0)
    .map(|x| [x, (omega * end).cos() * (k * x).sin()])
    .collect();
let mut series = vec![serde_json::json!({
    "name": "Exact continuous solution",
    "style": { "lineType": "dashed", "symbol": "none" },
    "points": exact
})];
let mut rows = Vec::new();
let mut tracks = Vec::new();
for (name, (status, accepted, rejected, error, points, times, modal)) in results {
    series.push(
        serde_json::json!({ "name": name, "style": { "symbol": "circle" }, "points": points }),
    );
    rows.push((name, status, accepted, rejected, error));
    tracks.push(
        serde_json::json!({ "name": name, "times": times, "amplitude": modal, "error": error }),
    );
}
emit_line_chart!(
    &series,
    options = &serde_json::json!({
        "xLabel": "Position along the string x [m]",
        "yLabel": "Final displacement u/A [-]",
        "yMin": -1.1,
        "yMax": 1.1
    })
);
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let columns = serde_json::json!([
    { "key": "0", "label": "Plan" },
    { "key": "1", "label": "Termination reason" },
    { "key": "2", "label": "Accepted steps [count]", "type": "integer" },
    { "key": "3", "label": "Rejected steps [count]", "type": "integer" },
    { "key": "4", "label": "Maximum continuous-solution error /A [-]", "type": "number", "format": sci3 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "runs" })
);
// Semidiscrete angular frequency ω_h = (2c/h) sin(kh/2) (independent closed-form value).
let semi_discrete = 2.0 * c / h * (k * h / 2.0).sin();
export!(omega, omega);
export!(semi_discrete, semi_discrete);
export!(end, end);
export!(tracks, tracks);
let completed = rows.iter().all(|row| row.1 == "Completed");
let outcome = if completed {
    Outcome::satisfied("All three plans integrated to the final time")
} else {
    Outcome::partial("Some plans did not reach the final time")
};
emit_outcome!(
    outcome
        .status(
            rows.iter()
                .map(|row| row.1.as_str())
                .collect::<Vec<_>>()
                .join(", ")
        )
        .diagnostic(
            "Maximum accepted step count",
            rows.iter().map(|r| r.2).max().unwrap_or(0) as f64,
            None
        )
        .diagnostic("Final time", end, Some("s"))
);
```

With defaults ($m = 3$, $N = 49$, $K = 6$), all three plans terminate with `Completed` and accept 440 steps each.
Maximum continuous-solution error is $4.23 \times 10^{-2}$ for FDM and FEM, and $4.21 \times 10^{-2}$ for FVM.
FDM and FEM values agree to rounding error, confirming that lumped-mass P1 elements on a uniform grid give the same semidiscrete system as three-point differences.

Step count is determined by the stability limit rather than local-error control.
Advancing to final time $t_{\mathrm{end}} = 1.86 \times 10^{-2}$ s at default limit $0.9 \times 0.9971/\sqrt\rho \approx 4.25 \times 10^{-5}$ s gives about 437 steps, close to the 440 accepted.
Removing the limit lets local-error control alone choose steps, reducing accepted steps to 324.
Relaxing tolerance to $10^{-6}$ leaves steps at the limit, so neither step count nor continuous-solution error changes.
Tightening tolerance to $10^{-10}$ makes local-error control choose steps below the limit, increasing accepted steps to 808.

At $K = 20$ error grows to $1.3 \times 10^{-1}$, while at $N = 81$ it falls to $1.6 \times 10^{-2}$.
Error unchanged by tolerance but affected by grid and observation time suggests that phase lag from the spatial grid dominates.
The next cell checks this by comparing with temporal error.

## Separating temporal error and phase lag

The next cell compares modal amplitude $a(t)$ from the preceding cell with exact semidiscrete solution $\cos(\omega_{h,m}t)$.
The maximum difference is time-integration error.
Also compare final error predicted solely from phase lag,

$$
e_{\mathrm{phase}} = \bigl|\cos(\omega_{h,m}t_{\mathrm{end}}) - \cos(\omega_m t_{\mathrm{end}})\bigr|
$$

with the maximum continuous-solution error measured in the preceding cell.
The semidiscrete solution retains spatial shape $\sin(k_m x_j)$, so agreement shows that phase lag explains nearly all final error.

```rust
//| id: pde-string-time-error
//| ref: pde-string-time-error
//| title: "Compare modal amplitude with the semidiscrete solution to separate temporal error and phase lag"
//| run: reactive
//| crates: [scioxide-core]
//| dependsOn:
//|   runs: pde-string-mode-comparison
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"split","path":"/rows/0/1","range":{"min":1e-10,"max":1e-6}}
//|       - {"artifact":"split","path":"/rows/0/2","approx":{"value":4.2315507e-2,"rtol":1e-3}}
//|       - {"artifact":"split","path":"/rows/0/3","approx":{"value":4.2315507e-2,"rtol":1e-3}}
//|       - {"artifact":"phase","path":"/rows/0/2","approx":{"value":1.6056e-3,"rtol":1e-3}}
use scioxide_core::RealScalar;

let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let fixed4 = serde_json::json!({ "fractionDigits": 4 });
let omega = runs["omega"].as_f64().ok_or("Missing ω")?;
let semi = runs["semi_discrete"].as_f64().ok_or("Missing ω_h")?;
let end = runs["end"].as_f64().ok_or("Missing final time")?;
let tracks = runs["tracks"].as_array().ok_or("Missing results for each plan")?;
// Final error from phase lag alone: |cos(ω_h t) − cos(ω t)|.
let phase_only = (RealScalar::cos(semi * end) - RealScalar::cos(omega * end)).abs();
let mut series = Vec::new();
let mut rows = Vec::new();
for track in tracks {
    let name = track["name"].as_str().ok_or("Missing plan name")?;
    let times: Vec<f64> =
        serde_json::from_value(track["times"].clone()).map_err(|e| e.to_string())?;
    let modal: Vec<f64> =
        serde_json::from_value(track["amplitude"].clone()).map_err(|e| e.to_string())?;
    let measured = track["error"].as_f64().ok_or("Missing continuous-solution error")?;
    // Temporal error a(t) − cos(ω_h t).
    let points: Vec<[f64; 2]> = times
        .iter()
        .zip(&modal)
        .map(|(&t, &a)| [t, a - RealScalar::cos(semi * t)])
        .collect();
    let time_error = points.iter().map(|p| p[1].abs()).fold(0.0_f64, f64::max);
    rows.push((name.to_owned(), time_error, measured, phase_only));
    series.push(serde_json::json!({ "name": name, "points": points }));
}
emit_line_chart!(
    &series,
    options = &serde_json::json!({
        "xLabel": "Time t [s]",
        "yLabel": "a(t) − cos(ω_h t) [-]"
    })
);
let columns = serde_json::json!([
    { "key": "0", "label": "Plan" },
    { "key": "1", "label": "Maximum temporal error [-]", "type": "number", "format": sci3 },
    { "key": "2", "label": "Maximum continuous-solution error /A [-]", "type": "number", "format": sci3 },
    { "key": "3", "label": "Error predicted by phase lag [-]", "type": "number", "format": sci3 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "split" })
);
let phase_columns = serde_json::json!([
    { "key": "0", "label": "Continuous ω [rad/s]", "type": "number", "format": fixed4 },
    { "key": "1", "label": "Semidiscrete ω_h [rad/s]", "type": "number", "format": fixed4 },
    { "key": "2", "label": "Relative difference 1 − ω_h/ω [-]", "type": "number", "format": sci3 },
    { "key": "3", "label": "Final phase lag [rad]", "type": "number", "format": sci3 }
]);
emit_table_with_columns!(
    phase_columns,
    vec![(omega, semi, 1.0 - semi / omega, (omega - semi) * end)],
    metadata = serde_json::json!({ "id": "phase" })
);
```

By default, temporal error for all three plans is $5.5 \times 10^{-8}$, six orders of magnitude smaller than continuous-solution error $4.23 \times 10^{-2}$.
Error $4.231555 \times 10^{-2}$ predicted solely by phase lag agrees with measured FDM error $4.231550 \times 10^{-2}$ to six digits; their difference $5 \times 10^{-8}$ is the same size as temporal error.
Semidiscrete angular frequency is 0.16% smaller than the continuous frequency, accumulating 0.062 rad phase lag over 6.125 cycles.
Nearly all final error comes from phase lag introduced by the spatial grid rather than time integration.

FVM temporal error is also $5.5 \times 10^{-8}$, the same as FDM.
Cell-center values $\sin(k_m x_j)$ are also eigenvectors of the semidiscrete system, with the same angular frequency $\omega_{h,m}$.
Flux using half-cell distance $h/2$ at Dirichlet boundary faces gives the same formula as a mirror image placing $-u_0$ in the exterior cell.
FVM continuous-solution error is slightly smaller, $4.21 \times 10^{-2}$, because it is measured at cell centers.
By default, nodes $x = L/2$ lie on antinodes (points with $|\sin(k_3 x)| = 1$), but cell centers do not; their maximum $|\sin(k_3 x_j)|$ is $\cos(\pi/32) = 0.9952$.
$4.2316 \times 10^{-2} \times 0.9952 = 4.211 \times 10^{-2}$ agrees with the FVM error.

## Summary

Tracking a fixed-end string eigenmode with three plans gives adaptive DOPRI5 temporal error no larger than $10^{-7}$; final displacement error is determined by spatial-grid phase lag.
Comparing modal amplitudes received through `PdeOutputSchedule::TimeSteps` with the exact semidiscrete solution measures time-integration and spatial errors separately.
With default `CflPolicy::Automatic`, stability limits determine step count, so relaxing tolerance does not reduce steps.
To reduce error, increase grid points per wavelength rather than changing temporal tolerance.
