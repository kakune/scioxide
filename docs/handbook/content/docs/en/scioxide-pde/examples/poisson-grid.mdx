The Poisson equation is elliptic and describes steady heat conduction, electrostatic potential, and steady groundwater seepage, among other phenomena.
It describes balance at each point between internal generation and flux entering or leaving the surroundings.
This example supplies an exact solution to the one-dimensional Poisson equation $-u''=f$ using manufactured solutions (choosing a solution first and deriving the source).
Prepare `StructuredFdmPlan`, `SimplexFemPlan` (P1 elements), and `StructuredFvmPlan` on the same vertex grid and solve all with `EllipticProblem`.
Check amplitude predictions from discrete eigenvalues, the distinction between algebraic residuals and discretization errors, and refinement convergence orders.

## Steady conduction in a rod and manufactured solution

Use dimensionless quantities, dividing position along a rod of length $L$ by $L$ and temperature by a reference temperature difference.
A uniform rod $\Omega=(0,1)$ with conductivity $k=1$ has volumetric heating $f(x)$, with both ends held at $0$.
Over a small interval of length $\Delta x$, the difference in outward end-face flux $q=-u'$ balances heating, giving $q(x+\Delta x)-q(x)=f\,\Delta x$; setting $\Delta x\to0$ gives the following boundary-value problem.

$$
-\frac{d^2u}{dx^2}=f(x),\qquad x\in(0,1),\qquad u(0)=u(1)=0
$$

Choosing exact solution $u_*(x)=\sin(m\pi x)$ as sine mode $m$ gives source $f(x)=(m\pi)^2\sin(m\pi x)$.
Supply $f$ through `FieldData::time_invariant` and impose endpoint values $0$ as Dirichlet conditions to measure error $\max_i|u_i-u_*(x_i)|$ directly.
Cells compute the manufactured solution and source using `sin` of `f64` as reference values.

## Three discretizations and discrete eigenvalues

The grid has $N$ vertices $x_i=ih$ ($h=1/(N-1)$); all three plans use the same vertices.
See [FDM, FEM, and FVM for elliptic problems](../../algorithms/elliptic-fdm-fem-fvm/) for derivations; here only differences affecting results are listed.

- **Finite differences (FDM)**: `StructuredFdmPlan` uses vertex values as unknowns and balances heat over interval $[x_i-h/2,x_i+h/2]$ surrounding each vertex.
  On a one-dimensional uniform grid, rows are three-point central differences $(2u_i-u_{i-1}-u_{i+1})/h=h f_i$.
  Conductivity is sampled at interval midpoints.
- **Finite elements (FEM)**: `SimplexFemPlan` takes each interval as an element and discretizes the weak form using piecewise linear (P1) basis functions.
  Load $\int f\varphi_i\,dx$ is computed by elementwise quadrature; one-dimensional P1 defaults to two-point Gauss–Legendre.
- **Finite volumes (FVM)**: `StructuredFvmPlan` uses values at centers of $N-1$ cells as unknowns.
  Conductivity is sampled at cell centers, and flux between adjacent cells follows two half-cell thermal resistances in series.
  Dirichlet conditions enter as boundary-face laws without fixing unknowns.

Different conductivity-sampling locations change results for discontinuous material properties.
Here $k=1$ removes this effect; see the [two-layer-wall example](../layered-wall-conduction/) for discontinuous properties.
All three plans implement `SpatialDiscretization`, so unknown locations are read through `dof_point` independently of family.
Compare FDM/FEM vertex values and FVM cell-center values with the exact solution at their respective locations.

For uniform-grid central differences, $\sin(m\pi x_i)$ is an eigenvector of the discrete operator, with eigenvalue divided by $h$ given by:

$$
\lambda_h=\frac{4}{h^2}\sin^2\left(\frac{m\pi h}{2}\right)
$$

Since the load is $(m\pi)^2h$ times this eigenvector, the FDM nodal solution equals $\rho=(m\pi)^2/\lambda_h$ times the exact solution.
$\sin z<z$ gives $\rho>1$, and since $\rho-1=(m\pi h)^2/12+O(h^4)$, the error is $O(h^2)$.

FEM nodal values have a different property.
For one-dimensional P1 elements with constant coefficients and exact load integration, nodal values match the exact solution.
This follows because the one-dimensional Green's function belongs to the P1 space.
Nodal error therefore comes only from load quadrature; two-point Gauss–Legendre predicts $O(h^4)$.

Both cells use the following definitions of three plans on the same grid and pairing solved values with unknown locations.

```rust
//| id: pde-poisson-rod-model
//| kind: definitions
//| title: "Three plans and solves for a one-dimensional rod"
//| crates: [scioxide-core, scioxide-pde, scioxide-spatial]
use scioxide_core::SciOxideError;
use scioxide_pde::{
    BoundaryData, BoundaryKind, ConstantDiffusion, EllipticProblem, FieldData,
    SimplexFemGeometry, SimplexFemOrder, SimplexFemPlan, SpatialDiscretization,
    StructuredBoundaries, StructuredFdmPlan, StructuredFvmPlan, TaggedBoundaries,
};
use scioxide_spatial::{IntervalMesh, Point};

/// Three plans on the same grid of N vertices. Conductivity k = 1, both ends u = 0.
pub(crate) struct Rod {
    pub(crate) fdm: StructuredFdmPlan<f64, f64, 1>,
    pub(crate) fem: SimplexFemPlan<f64, f64, 1>,
    pub(crate) fvm: StructuredFvmPlan<f64, f64, 1>,
}

pub(crate) fn rod(nodes: usize) -> Result<Rod, SciOxideError> {
    let fdm = StructuredFdmPlan::dirichlet_laplacian([0.0], [1.0], [nodes])?;
    let unit = ConstantDiffusion::new(1.0);
    let mesh = fdm.mesh().clone();
    let ends =
        StructuredBoundaries::uniform(&mesh, 1, BoundaryKind::Dirichlet, BoundaryData::zero())?;
    let fvm = StructuredFvmPlan::new(mesh, &unit, &ends)?;
    // FEM places the same vertices as FDM in an interval mesh.
    let mut points = Vec::with_capacity(nodes);
    for node in 0..nodes {
        points.push(Point::new(fdm.node_point(node)?)?);
    }
    let segments = (0..nodes - 1).map(|i| [i, i + 1]).collect();
    let interval = IntervalMesh::new(points, segments)?;
    let tagged =
        TaggedBoundaries::uniform(&interval, 1, BoundaryKind::Dirichlet, BoundaryData::zero())?;
    let fem = SimplexFemPlan::new(
        interval,
        SimplexFemGeometry::Affine,
        SimplexFemOrder::P1,
        &unit,
        &tagged,
    )?;
    Ok(Rod { fdm, fem, fvm })
}

/// Solve with the default direct method and return unknown-location/value pairs [x, u], together with
/// direct-method backward error (scaled residual in the `linear_residual_report` norm).
pub(crate) fn solve<P: SpatialDiscretization<f64, f64, 1>>(
    plan: &P,
    source: &FieldData<f64, f64, 1>,
) -> Result<(Vec<[f64; 2]>, Option<f64>), SciOxideError> {
    let solution = EllipticProblem::new(plan, source).solve_with_options(&Default::default())?;
    let mut points = Vec::with_capacity(solution.values().len());
    for (unknown, &u) in solution.values().iter().enumerate() {
        points.push([plan.dof_point(unknown)?.point[0], u]);
    }
    let backward = solution
        .report()
        .diagnostics()
        .linear_residual_report()
        .map(|r| r.scaled_norm());
    Ok((points, backward))
}
```

`EllipticProblem::solve_with_options` uses default `EllipticOptions`, solving with a tridiagonal direct method if the eliminated matrix is tridiagonal, otherwise sparse LU.
All three one-dimensional plans assemble tridiagonal matrices.
Direct-method solutions are returned only after checking original-equation residuals against the backward-error tolerance of $\sqrt{\varepsilon}$; a failed check gives an error.

```rust
use std::f64::consts::PI;

let wave = poisson_mode_number * PI;
let nodes = poisson_grid_nodes as usize;
let h = 1.0 / (nodes - 1) as f64;
// Manufactured solution u* = sin(mπx) and source f = (mπ)² sin(mπx) (f64 sin as a reference).
let source = FieldData::time_invariant(move |p: FieldPoint<f64, 1>| {
    Ok(wave * wave * (wave * p.point[0]).sin())
});
let plans = rod(nodes).map_err(|e| e.to_string())?;
let solutions = [
    (
        "FDM (vertices)",
        solve(&plans.fdm, &source).map_err(|e| e.to_string())?,
    ),
    (
        "FEM (vertices)",
        solve(&plans.fem, &source).map_err(|e| e.to_string())?,

    (
        "FVM (cell centers)",
        solve(&plans.fvm, &source).map_err(|e| e.to_string())?,

    .map(|i| [i as f64 / 200.0, (wave * i as f64 / 200.0).sin()])
    .collect();

    "name": "Exact solution",
    "points": exact_points,
    "style": { "lineType": "dashed" }

let mut rows = Vec::new();
for (label, (points, backward)) in &solutions {
    let error = points
        .iter()
        .map(|[x, u]| (u - (wave * x).sin()).abs())
        .fold(0.0_f64, f64::max);
    rows.push((*label, error, *backward));
    series.push(serde_json::json!({
        "name": label,
        "points": points,
        "style": { "showSymbol": true }
    }));
}
// Measure FDM amplitude ratio at the vertex maximizing |sin(mπx)| and compare with discrete-eigenvalue prediction ρ.
let fdm_points = &solutions[0].1.0;
let [x_peak, u_peak] = *fdm_points
    .iter()
    .max_by(|a, b| {
        (wave * a[0])
            .sin()
            .abs()
            .total_cmp(&(wave * b[0]).sin().abs())
    })
    .ok_or("No vertices")?;
let measured = u_peak / (wave * x_peak).sin();
let predicted = wave * wave / (4.0 / (h * h) * (wave * h / 2.0).sin().powi(2));
emit_line_chart!(
    &series,
    options = &serde_json::json!({ "xLabel": "Position x/L [-]", "yLabel": "Temperature u [-]" })
);
let columns = serde_json::json!([
    { "key": "0", "label": "Method (unknown locations)" },
    { "key": "1", "label": "Maximum error [-]", "type": "number", "format": sci3 },
    { "key": "2", "label": "Direct-method backward error [-]", "type": "number", "format": sci3, "nullText": "None" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "methods" })
);
let amplitude_columns = serde_json::json!([
    { "key": "0", "label": "FDM amplitude ratio (measured) [-]", "type": "number", "format": fixed7 },
    { "key": "1", "label": "Prediction ρ = (mπ)²/λ_h [-]", "type": "number", "format": fixed7 },
    { "key": "2", "label": "Difference [-]", "type": "number", "format": sci3 }
]);
emit_table_with_columns!(
    amplitude_columns,
    vec![(measured, predicted, (measured - predicted).abs())],
    metadata = serde_json::json!({ "id": "amplitude" })
);
```

With defaults ($m=3$, $N=41$), maximum errors for FDM and FVM are both $4.6\times10^{-3}$; FEM nodal error is $2.1\times10^{-6}$.
Measured FDM amplitude ratio 1.0046392 agrees with the discrete-eigenvalue prediction at the rounding level.
All three methods have direct-method backward error around $10^{-16}$.
This measures the accuracy of solving the algebraic equations and is distinct from discretization error.
Even with small backward error, the difference between discrete and exact solutions remains of order $10^{-3}$.
At $m=7$, vertices per wavelength fall to about 11 and FDM error grows to $2.6\times10^{-2}$.

## Grid refinement and observed orders

Measure maximum error for vertex-count sequence $N=9,13,17,25,33,49,65,97$ and compute observed order $p_{\mathrm{obs}}=\log(e_1/e_2)/\log(h_1/h_2)$ from the two finest grids.
FDM and cell-centered FVM are expected to be second order, reducing error to $1/4$ when grid spacing halves.
The preceding argument predicts fourth-order FEM nodal error.
On log-log axes, plot observations as symbols and slope-2 and slope-4 reference lines dashed.

With default $m=2$, observed orders are FDM 2.001, FEM 4.001, and FVM 1.999.
FEM points follow the dashed slope-4 line, consistent with nodal error coming solely from load quadrature.
Increasing mode number leaves coarse grids unable to resolve the wave, bending the curve; grids finer than about 10 points per wavelength approach theoretical slopes.
At $m=6$, FDM error reaches 0.63 on the 9-point grid, but the two finest grids give observed orders FDM 2.006, FEM 4.006, and FVM 2.015.

Fourth-order FEM convergence is superconvergence specific to nodes of one-dimensional P1 elements with constant coefficients.
Errors between nodes and $L^2$ errors retain normal P1 order (second order in $L^2$); fourth-order nodal convergence is also not expected for P1 elements in two or more dimensions.

## Summary

Manufactured solutions allow direct comparison of errors from three discretizations with the exact solution.
The three plans implement `SpatialDiscretization`, so one `EllipticProblem` solves each by the same procedure, and `dof_point` reads unknown locations.
Uniform-grid FDM nodal solutions equal $\rho=(m\pi)^2/\lambda_h$ times the exact solution, allowing advance error predictions to check the implementation.
FDM and FVM converge at second order; one-dimensional P1 FEM nodal values converge at fourth order.
Direct-method backward error measures algebraic accuracy and cannot estimate discretization error.
