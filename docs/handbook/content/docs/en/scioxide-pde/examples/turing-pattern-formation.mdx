[Turing-instability dispersion relations and discrete modes](../turing-reaction-diffusion/) used linear analysis to determine which perturbation wavenumbers grow and how fast in the Schnakenberg system on a square.
This page time-integrates the same system in two dimensions to form patterns and check those predictions.
Check three features: growth rate while perturbations are small, dominant wavenumber of developed patterns, and perturbation decay for $d<d_c$.

Match the preceding page with feed rates $a=0.1$ and $b=0.9$, diffusion coefficients $D_u=1$ and $D_v=d$, and uniform steady state $(u^*,v^*)=(1,\,0.9)$.
Dispersion relation $\operatorname{Re}\lambda(k)$ is defined in [Dispersion relation](oxref:pde-turing-dispersion); critical diffusion ratio $d_c\approx8.5676$ and critical wavenumber $k_c\approx0.5845$ in [Critical diffusion ratio and wavenumber](oxref:pde-turing-critical-ratio).
The fastest-growing wavenumber at $d=20$ is $k_{\max}\approx0.4867$, and discrete-grid mode growth rates are $\operatorname{Re}\lambda_h=\operatorname{Re}\lambda(k_h)$.
All quantities are dimensionless.

## Semidiscrete system and mass normalization

Discretizing space with `StructuredFdmPlan` gives the following semidiscrete system for vertex values $\mathbf{y}=[\mathbf{u};\mathbf{v}]$ (grouped by component).

$$
M\dot{\mathbf{y}} = -A\mathbf{y} + M\,\mathbf{R}(\mathbf{y}), \qquad \mathbf{R}(\mathbf{y})=\bigl(f(u_i,v_i)\bigr)_i \oplus \bigl(g(u_i,v_i)\bigr)_i
$$

$A$ is the plan operator (`LinearOperator::apply_into`), $M$ lumped mass (`SpatialDiscretization::lumped_mass`); reaction is computed from vertex values.
Discretizing space first and then integrating the resulting ODE system is the method of lines ([Method of lines and semidiscrete systems](../../algorithms/method-of-lines-and-nonlinear/)).

`ParabolicProblem` integrates only linear $M\dot{\mathbf{u}}=\mathbf{b}(t)-A\mathbf{u}$ and cannot handle this system's nonlinear reaction.
Instead, express right-hand side $\mathbf{F}(\mathbf{y})=-A\mathbf{y}+M\mathbf{R}(\mathbf{y})$ as a unit-mass `OdeSystem` and pass it to `MethodOfLinesPlan`.
Here use `OdeFn` from `scioxide-ode` to create `OdeSystem` from a closure.
`MethodOfLinesPlan::new(dimension, mass, scales)` checks positive diagonal mass $M$ and field scales $D$ (`None` uses the identity).
`bind` borrows `OdeSystem`, returning `MethodOfLinesSystem` representing $\dot{\mathbf{z}}=M^{-1}D^{-1}\mathbf{F}(D\mathbf{z})$.
`encode_into` and `decode_into` convert physical values $\mathbf{y}$ and normalized state $\mathbf{z}=D^{-1}\mathbf{y}$; `error_tolerance` transfers physical absolute tolerances into normalized coordinates.
Here $D$ is the identity, so normalization only divides by mass.

The following definitions block shares reaction coefficients, a two-component difference plan, and continuous/discrete dispersion relations among this page's three cells.
Its contents match [Turing-instability dispersion relations and discrete modes](../turing-reaction-diffusion/), adding reaction feed rates and the uniform steady state.
Fix grid spacing at $h=1$, with $L+1$ vertices per side.
`StructuredFdmCoefficients::diffusion` returns diffusion coefficients by axis and component: component 0 is $u$, component 1 is $v$.
`BoundaryCondition::natural` prescribes outward conormal flux $\mathbf{n}\cdot D\nabla u$ and applies to both components when none is specified.

```rust
//| id: pde-turing-formation-model
//| kind: definitions
//| title: "Schnakenberg coefficients, two-component difference plan, and dispersion relation"
//| crates: [scioxide-core, scioxide-pde, scioxide-spatial]
use scioxide_core::{SciOxideError, RealScalar};
use scioxide_pde::{
    BoundaryCondition, BoundaryData, StructuredBoundaries, StructuredFdmCoefficients,
    StructuredFdmPlan,
};
use scioxide_spatial::{AxisSide, AxisTopology, BoundarySet, CoordinateAxis, Grid2d, QuadMesh};

/// Feed rates a, b.
pub(crate) const SUPPLY: [f64; 2] = [0.1, 0.9];
/// Uniform steady state (u*, v*) = (a + b, b/(a + b)²).
pub(crate) const STEADY: [f64; 2] = [1.0, 0.9];
/// Jacobian J₀ = [[f_u, f_v], [g_u, g_v]] at (u*, v*).
pub(crate) const JACOBIAN: [[f64; 2]; 2] = [[0.8, 1.0], [-1.8, -1.0]];

/// Diffusion coefficients D_u = 1, D_v = d. Component 0 is u and component 1 v, identical on both axes.
pub(crate) struct Diffusion {
    pub(crate) ratio: f64,
}
impl StructuredFdmCoefficients<f64, f64, 2> for Diffusion {
    fn diffusion(&self, _: usize, component: usize, _: [f64; 2]) -> Result<f64, SciOxideError> {
        Ok([1.0, self.ratio][component])
    }
}

/// Vertex grid on [0, L]² with h = 1 and zero outward flux on all four sides for both components.
pub(crate) fn turing_plan(
    length: usize,
    ratio: f64,
) -> Result<StructuredFdmPlan<f64, f64, 2>, SciOxideError> {
    let axis = CoordinateAxis::uniform(0.0, length as f64, length + 1)?;
    let grid = Grid2d::new([axis.clone(), axis], [AxisTopology::Bounded; 2])?;
    let mesh = QuadMesh::new(grid)?;
    let mut conditions = Vec::new();
    for axis in 0..2 {
        for side in [AxisSide::Start, AxisSide::End] {
            let region = BoundarySet::axis_side(&mesh, axis, side)?;
            conditions.push(BoundaryCondition::natural(region, BoundaryData::zero()));
        }
    }
    let boundaries = StructuredBoundaries::new(&mesh, 2, conditions)?;
    StructuredFdmPlan::new(mesh, &Diffusion { ratio }, &boundaries)
}

/// Largest real eigenvalue part of J₀ − κ diag(1, d). κ is continuous k² or discrete k_h².
pub(crate) fn growth_rate(kappa: f64, ratio: f64) -> f64 {
    let [[fu, fv], [gu, gv]] = JACOBIAN;
    let trace = fu + gv - (1.0 + ratio) * kappa;
    let det = (fu - kappa) * (gv - ratio * kappa) - fv * gu;
    let disc = trace * trace - 4.0 * det;
    if disc >= 0.0 {
        0.5 * (trace + RealScalar::sqrt(disc))
    } else {
        0.5 * trace
    }
}

/// On an h = 1 grid, one-axis mode m contributes 4 sin²(mπ/2L) to squared discrete wavenumber.
pub(crate) fn axis_wavenumber2(mode: usize, length: usize) -> f64 {
    let s = RealScalar::sin(mode as f64 * core::f64::consts::PI / (2.0 * length as f64));
    4.0 * s * s
}

/// (m_x, m_y, Re λ_h) for all modes (m_x, m_y) ≠ (0, 0).
pub(crate) fn discrete_modes(length: usize, ratio: f64) -> Vec<(usize, usize, f64)> {
    let mut modes = Vec::new();
    for my in 0..=length {
        for mx in 0..=length {
            if mx + my > 0 {
                let kh2 = axis_wavenumber2(mx, length) + axis_wavenumber2(my, length);
                modes.push((mx, my, growth_rate(kh2, ratio)));
            }
        }
    }
    modes
}

/// Unstable-band endpoints [k₁, k₂]. Two roots of h: k² = (s ∓ √(s² − 4d det J₀))/(2d), s = d f_u + g_v.
pub(crate) fn unstable_band(ratio: f64) -> Option<[f64; 2]> {
    let [[fu, fv], [gu, gv]] = JACOBIAN;
    let slope = ratio * fu + gv;
    let disc = slope * slope - 4.0 * ratio * (fu * gv - fv * gu);
    (slope > 0.0 && disc > 0.0).then(|| {
        let s = RealScalar::sqrt(disc);
        [(slope - s) / (2.0 * ratio), (slope + s) / (2.0 * ratio)].map(RealScalar::sqrt)
    })
}

/// Find continuous fastest-growing wavenumber k_max by scanning 0 < k ≤ 1.5 in increments of 10⁻⁴.
pub(crate) fn fastest_wavenumber(ratio: f64) -> f64 {
    (1..=15_000)
        .map(|i| 1e-4 * i as f64)
        .max_by(|a, b| growth_rate(a * a, ratio).total_cmp(&growth_rate(b * b, ratio)))
        .unwrap_or(0.0)
}
```

## Stiffness and Rosenbrock-W

For $d=20$ and $h=1$, diffusion $M^{-1}A$ eigenvalues of $v$ reach $8d/h^2=160$.
The explicit classical four-stage Runge–Kutta method (RK4) has real-axis stability interval about $2.79$, limiting time steps to $\Delta t\lesssim2.79/160\approx0.017$ and requiring about 5700 steps to $t=100$.
Pattern growth has time scale $1/\operatorname{Re}\lambda\approx4$, so accuracy alone permits steps much larger than $0.017$.
This property, where stability rather than accuracy determines step size, is called stiffness and motivates implicit methods.

`RosenbrockW` from `scioxide-ode` is a linearly implicit Rosenbrock-W method.
Each stage solves one linear system with matrix $I-\Delta t\,\gamma J$ ($\gamma$ is the method's diagonal coefficient, $J$ approximates $\partial\mathbf{F}/\partial\mathbf{z}$), without Newton iterations.
As a W-method, it retains its order even with approximate $J$.
`RosenbrockMethod::Ros34Pw2` uses Rang and Angermann's four-stage third-order coefficients and is L-stable with an exact Jacobian.
`RosenbrockW` accepts only unit-mass systems, so insert mass-dividing `MethodOfLinesPlan`.

Solve stage systems with sparse LU through `OdeStageBackend::Sparse`.
Jacobian nonzero locations comprise two diagonal diffusion blocks (the $A$ structure returned by `assemble_csr`) and two reaction diagonals coupling $u_i$ and $v_i$ at each vertex.
Pass this structure to both `MethodOfLinesPlan::with_jacobian_pattern` and the sparse LU stage solver.
`SparseLuLimits::new(max_factor_entries, max_workspace_bytes)` limits factorization nonzero count and workspace bytes.
Since `OdeFn` supplies no Jacobian, `RosenbrockW` approximates $J$ by differences with column coloring of the structure.
No time derivative $\partial\mathbf{F}/\partial t$ is supplied either, so time differences compute it; the autonomous right-hand side makes those differences zero.

## Running integration

The next cell uses a square of side $L=32$ ($33\times33$ vertices, 2178 unknowns), adds uniform random perturbations of amplitude $10^{-3}$ to both uniform-steady-state components, and integrates to $t=100$.
Relative tolerance is $10^{-4}$ and absolute tolerance $10^{-6}$.
Inputs are diffusion-coefficient ratio $d$ and random seed.
Receive dense output at $t=2,4,\dots,100$ (cubic Hermite interpolation within each step) using `OdeOutputSchedule::times` and record perturbation magnitude $\|\mathbf{u}-u^*\|_{\mathrm{RMS}}=\bigl(\frac{1}{N}\sum_i(u_i-u^*)^2\bigr)^{1/2}$ ($N$ is vertex count).
Convert `OdeSolveReport` to a PDE report with `PdeSolveReport::try_from` and turn termination reason `PdeTermination` into an outcome.
`Completed` gives satisfied; stopping at a time-step or evaluation limit or execution stop passes the field at the last accepted time and gives partial.
ODE failures return as errors rather than termination reasons.
Pass perturbation-magnitude history and $u$ at $t=20$ and $t=100$ for the next two cells.

```rust
//| id: pde-turing-pattern
//| ref: pde-turing-pattern
//| title: "Integrate the two-dimensional Schnakenberg system with a two-component difference plan, the method of lines, and Rosenbrock-W"
//| run: button
//| timeoutMs: 120000
//| cache: inputs
//| uses: [pde-turing-formation-model]
//| crates: [scioxide-core, scioxide-linalg, scioxide-ode, scioxide-pde, scioxide-random, scioxide-sparse, scioxide-spatial]
//| exports: [ratio, domain_length, early_time, history, early, last]
//| inputs:
//|   ratio: {"type":"range","label":"Diffusion ratio d = D_v/D_u [-]","description":"Below d_c ≈ 8.57, perturbations decay and no pattern forms.","min":6,"max":30,"step":1,"value":20}
//|   seed: {"type":"range","label":"Random seed [-]","description":"Selects the initial perturbation.","min":1,"max":20,"step":1,"value":1}
//| cases:
//|   - {"id":"below-critical","label":"d = 8 < d_c","description":"Perturbations decay and u returns to the uniform steady value 1.","inputs":{"ratio":8}}
//|   - {"id":"other-seed","label":"Seed 2","description":"Spot arrangement changes, but perturbation-magnitude history remains nearly the same.","inputs":{"seed":2}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"path":"/outputs/0/state","equals":"satisfied"}
//|   - case: below-critical
//|     expect:
//|       - {"path":"/outputs/0/state","equals":"satisfied"}
//|   - case: other-seed
//|     expect:
//|       - {"path":"/outputs/0/state","equals":"satisfied"}
use scioxide_core::{
    ErrorTolerance, ExecutionContext, SciOxideError, LinearOperator, NormSelection, RealScalar,
    StructuralPattern,
};
use scioxide_linalg::Vector;
use scioxide_ode::{
    OdeFn, OdeMethod, OdeOptions, OdeOutputSchedule, OdeProblem, OdeStageBackend, OdeState,
    RosenbrockMethod, RosenbrockW,
};
use scioxide_pde::{MethodOfLinesPlan, PdeSolveReport, SpatialDiscretization};
use scioxide_random::{Rng, SeedableRng, SplitMix64};
use scioxide_sparse::SparseLuLimits;
use std::cell::RefCell;

let (length, early_time, final_time) = (32_usize, 20.0, 100.0);
let plan = turing_plan(length, ratio).map_err(|e| e.to_string())?;
let nodes = plan.unknowns() / 2;
// Jacobian structure: two diagonal blocks of A plus reaction terms coupling u_i and v_i.
let csr = plan.assemble_csr().map_err(|e| e.to_string())?;
let (mut row_ptr, mut cols) = (vec![0], Vec::with_capacity(csr.nnz() + 2 * nodes));
for row in 0..2 * nodes {
    if row >= nodes {
        cols.push(row - nodes);
    }
    cols.extend_from_slice(&csr.col_indices()[csr.row_ptr()[row]..csr.row_ptr()[row + 1]]);
    if row < nodes {
        cols.push(row + nodes);
    }
    row_ptr.push(cols.len());
}
let pattern =
    StructuralPattern::new(2 * nodes, 2 * nodes, row_ptr, cols).map_err(|e| e.to_string())?;
let mol = MethodOfLinesPlan::new(2 * nodes, Some(plan.lumped_mass()), None)
    .and_then(|mol| mol.with_jacobian_pattern(pattern.clone()))
    .map_err(|e| e.to_string())?;
// Physical right-hand side F(y) = −A y + M R(y). MethodOfLinesPlan handles division by M.
let (mass, [a, b]) = (plan.lumped_mass(), SUPPLY);
let scratch = RefCell::new(vec![
    0.0;
    plan.apply_workspace_len().map_err(|e| e.to_string())?
]);
let rhs = |_: f64, y: &[f64], out: &mut [f64]| -> Result<(), SciOxideError> {
    plan.apply_into(y, out, &mut scratch.borrow_mut())?;
    let (u, v) = y.split_at(nodes);
    for i in 0..nodes {
        let uuv = u[i] * u[i] * v[i];
        out[i] = mass[i] * (a - u[i] + uuv) - out[i];
        out[nodes + i] = mass[nodes + i] * (b - uuv) - out[nodes + i];
    }
    Ok(())
};
let model = OdeFn::new(2 * nodes, rhs).map_err(|e| e.to_string())?;
let mut mol_workspace = mol.workspace().map_err(|e| e.to_string())?;
let system = mol
    .bind(&model, &mut mol_workspace)
    .map_err(|e| e.to_string())?;
// Initial data: uniform steady state plus uniform random perturbations of amplitude 10⁻³ (component order [u, v]).
let mut rng = SplitMix64::from_seed(seed as u64);
let mut physical = Vec::with_capacity(2 * nodes);
for steady in STEADY {
    for _ in 0..nodes {
        let r: f64 = rng.next_float().map_err(|e| e.to_string())?;
        physical.push(steady + 1e-3 * (2.0 * r - 1.0));
    }
}
let mut initial = vec![0.0; 2 * nodes];
mol.encode_into(&physical, &mut initial)
    .map_err(|e| e.to_string())?;
let solver = RosenbrockW::<f64>::new(RosenbrockMethod::Ros34Pw2)
    .map_err(|e| e.to_string())?
    .with_backend(OdeStageBackend::Sparse {
        pattern,
        limits: SparseLuLimits::new(1 << 20, 1 << 28),
    });
let tolerance = ErrorTolerance::scalar(1e-6, 1e-4, NormSelection::RootMeanSquare)
    .and_then(|tolerance| mol.error_tolerance(&tolerance))
    .map_err(|e| e.to_string())?;
let times: Vec<f64> = (1..=50).map(|i| 2.0 * i as f64).collect();
let options = OdeOptions::new()
    .with_error_tolerance(tolerance)
    .with_output_schedule(OdeOutputSchedule::times(times));
let problem = OdeProblem::new(&system, final_time);
let mut workspace = solver
    .workspace(&problem, &options)
    .map_err(|e| e.to_string())?;
// Record perturbation magnitude ‖u − u*‖_RMS at each output time and retain u at t = 20.
let rms = |u: &[f64]| {
    let sum: f64 = u.iter().map(|u| (u - STEADY[0]) * (u - STEADY[0])).sum();
    RealScalar::sqrt(sum / u.len() as f64)
};
let (mut history, mut field) = (vec![[0.0, rms(&physical[..nodes])]], vec![0.0; 2 * nodes]);
let mut early = Vec::new();
let mut state = OdeState::new(0.0, Vector::from_vec(initial));
let raw = solver
    .advance(
        &problem,
        &options,
        &mut state,
        &mut |t: f64, z: &[f64]| {
            mol.decode_into(z, &mut field)?;
            history.push([t, rms(&field[..nodes])]);
            if t == early_time {
                early = field[..nodes].to_vec();
            }
            Ok(())
        },
        &mut workspace,
        ExecutionContext::sequential(),
    )
    .map_err(|e| e.to_string())?;
let report = PdeSolveReport::try_from(&raw).map_err(|e| e.to_string())?;
mol.decode_into(state.values(), &mut field)
    .map_err(|e| e.to_string())?;
export!(ratio, &ratio);
export!(domain_length, &length);
export!(early_time, &early_time);
export!(history, &history);
export!(early, &early);
export!(last, &field[..nodes].to_vec());
let diagnostics = report.diagnostics();
let outcome = if report.is_success() {
    Outcome::satisfied("Time integration completed to t = 100")
} else {
    Outcome::partial("Time integration stopped before t = 100")
        .explanation("Passed fields are from the last accepted time, not t = 100.")
};
let steps = |n: usize| n as f64;
emit_outcome!(
    outcome
        .status(report.termination().to_string())
        .diagnostic("Time reached", report.final_time(), None)
        .diagnostic(
            "Accepted steps",
            steps(diagnostics.num_accepted_steps()),
            None
        )
        .diagnostic(
            "Rejected steps",
            steps(diagnostics.num_rejected_steps()),
            None
        )
        .diagnostic("LU factorizations", steps(diagnostics.num_factorizations()), None)
);
```

With defaults ($d=20$, seed 1), integration reaches $t=100$ with `Completed`, taking 87 accepted steps, 2 rejected steps, and 87 sparse LU factorizations.
Rosenbrock-W uses the current step in factorization, so factorization count nearly matches accepted step count.
This is about 1/60 the explicit RK4 stability-limited count (about 5700 steps).
At $d=8$, perturbations quickly shrink and only 23 steps are accepted.

## Pattern shape and growth stages

The next cell uses the preceding results to plot a heatmap of $u$ at $t=100$ and perturbation magnitude over time.
Time-history points are measurements and the dashed curve is linear theory.
The dashed curve fits $e^{\operatorname{Re}\lambda_h t}$ of the fastest-growing discrete mode to the measured value at $t=20$, omitting portions exceeding 1.
During the linear stage measurements follow this slope; as perturbations approach 1, nonlinear terms act and growth saturates.
The table gives the measured logarithmic slope from $t=10$ to $t=20$ and the maximum $\operatorname{Re}\lambda_h$.

```rust
//| id: pde-turing-pattern-growth
//| ref: pde-turing-pattern-growth
//| title: "View spot-pattern heatmaps and perturbation growth from the linear stage to saturation"

//| uses: [pde-turing-formation-model]
//| crates: [scioxide-core]

//|   pattern: pde-turing-pattern

//|       - {"artifact":"rates","path":"/rows/0/0","range":{"min":0.23,"max":0.26}}
//|       - {"artifact":"rates","path":"/rows/0/1","approx":{"value":0.26315624593311115,"rtol":1e-9}}

let fixed4 = serde_json::json!({ "fractionDigits": 4 });

    serde_json::from_value(get("history")).map_err(|e| e.to_string())?;

// Vertices are ordered with x index varying fastest. Since h = 1, indices are coordinates.
let side = length + 1;
let map: Vec<[f64; 3]> = last
    .iter()
    .enumerate()
    .map(|(node, u)| [(node % side) as f64, (node / side) as f64, *u])
    .collect();
emit_chart!(
    serde_json::json!({
        "kind": "heatmap",
        "data": map,
        "xLabel": "Position x [-]",
        "yLabel": "Position y [-]",

let rate = discrete_modes(length, ratio)
    .iter()
    .fold(f64::MIN, |r, m| r.max(m.2));
let (start, anchor) = (history[5], history[10]);
let theory: Vec<[f64; 2]> = history
    .iter()
    .map(|p| {

    })
    .filter(|p| p[1] <= 1.0)
    .collect();
let measured = RealScalar::ln(anchor[1] / start[1]) / (anchor[0] - start[0]);
let columns = serde_json::json!([

emit_table_with_columns!(

    vec![(measured, rate)],
    metadata = serde_json::json!({ "id": "rates" })
);
emit_chart!(

        "kind": "xy",
        "xLabel": "Time t [-]",
        "yLabel": "Perturbation magnitude ‖u − u*‖_RMS [-]",
        "yType": "log",
        "dataZoom": true,
        "tooltip": true,
        "layers": [
            { "id": "measured", "kind": "scatter", "name": "Measured", "points": history },
            {
                "id": "linear",
                "kind": "line",
                "name": "Linear theory e^{Re λ_h t}",
                "points": theory,
                "style": { "lineType": "dashed" }
            }
        ]
    }),
    metadata = serde_json::json!({ "id": "growth" })
);
```

At default $t=100$, $u$ ranges from $0.200$ to $2.990$, and the heatmap shows separated round spots with high $u$.
Most initial random perturbations lie outside the unstable band and decay quickly, so magnitude falls from $5.7\times10^{-4}$ at $t=0$ to $2.5\times10^{-4}$ at $t=2$.
It then grows linearly, with slope $0.247$ from $t=10$ to $t=20$, slightly below maximum discrete-mode growth rate $0.2632$.
Perturbations sum many modes with near-maximum growth rates, so their logarithmic slope approximates a weighted average of those rates, below the maximum.
After $t\approx30$, measurements depart from the dashed curve, reaching $0.678$ at $t=40$ and remaining nearly constant at $0.75$–$0.76$ from $t=50$ onward.

Setting $d=8$ above reduces perturbation magnitude to $4.3\times10^{-6}$ at $t=100$.
The slope from $t=90$ to $t=100$ is $-0.029$, near $\operatorname{Re}\lambda_h=-0.0272$ of the slowest-decaying discrete mode.
This agrees with the linear prediction that every mode decays at $d<d_c$.

## Dominant-mode analysis with DCT

Vertex cosine modes form the DCT-I basis, so a two-dimensional DCT-I of $u-\bar u$ ($\bar u$ is the vertex mean) using `dctn` from `scioxide-fft` yields amplitude $c_{m_x,m_y}$ of each mode $(m_x,m_y)$.
The forward transform of `Normalization::Inverse` is the following unscaled sum ($x_j$ are $L+1$ values along one axis).

$$
X_{m}=x_0+(-1)^{m}x_{L}+2\sum_{j=1}^{L-1}x_j\cos\frac{\pi jm}{L}
$$

Substituting $x_j=c\cos(\pi jm/L)$ gives $X_m=cLw_m$ ($w_0=w_L=2$, otherwise $w_m=1$), hence two-dimensional amplitude $c_{m_x,m_y}=X_{m_x,m_y}/(L^2w_{m_x}w_{m_y})$.
`dctn` uses FFTs, taking $O(n\log n)$ operations for vertex count $n$.

For $u$ at $t=20$ and $t=100$, the next cell tabulates the mode maximizing $|c|$ (dominant mode), its wavenumber $k=\pi\sqrt{m_x^2+m_y^2}/L$, and its $\operatorname{Re}\lambda_h$.
For another comparison, group modes sharing $s=\operatorname{round}(\sqrt{m_x^2+m_y^2})$ into shells and sum $c^2$ per shell.
Plot that sum against shell wavenumber $\pi s/L$ with a logarithmic vertical axis, marking $k_{\max}$ by a vertical line and the unstable band by a range.
Shell width is $\pi/L\approx0.098$, limiting wavenumber comparisons to this resolution.

```rust
//| id: pde-turing-spectrum
//| ref: pde-turing-spectrum
//| title: "Find dominant-mode wavenumbers with DCT-I and compare with the fastest-growing wavenumber"
//| run: button
//| uses: [pde-turing-formation-model]
//| crates: [scioxide-core, scioxide-fft]
//| dependsOn:
//|   pattern: pde-turing-pattern
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"modes","path":"/rows/0/0","equals":"t = 20"}
//|       - {"artifact":"modes","path":"/rows/0/4","range":{"min":0.45,"max":0.56}}
//|       - {"artifact":"modes","path":"/rows/0/6","approx":{"value":0.4908738521234052,"rtol":1e-12}}
//|       - {"artifact":"modes","path":"/rows/1/4","range":{"min":0.45,"max":0.7}}
use scioxide_core::RealScalar;
use scioxide_fft::{DctType, Normalization, dctn};
use std::f64::consts::PI;

let fixed4 = serde_json::json!({ "fractionDigits": 4 });
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let get = |key: &str| pattern[key].clone();
let ratio: f64 = serde_json::from_value(get("ratio")).map_err(|e| e.to_string())?;
let length: usize = serde_json::from_value(get("domain_length")).map_err(|e| e.to_string())?;
let early_time: f64 = serde_json::from_value(get("early_time")).map_err(|e| e.to_string())?;
let early: Vec<f64> = serde_json::from_value(get("early")).map_err(|e| e.to_string())?;
let last: Vec<f64> = serde_json::from_value(get("last")).map_err(|e| e.to_string())?;
let (side, size) = (length + 1, length as f64);
let weight = |m: usize| if m == 0 || m == length { 2.0 } else { 1.0 };
// Amplitude c = X / (L² w_x w_y). Sum c² in each shell s = round(|m|) and select the mode maximizing |c|.
let analyse = |u: &[f64]| -> Result<((usize, usize, f64), Vec<[f64; 2]>), String> {
    let mean = u.iter().sum::<f64>() / u.len() as f64;
    let centred: Vec<f64> = u.iter().map(|u| u - mean).collect();
    let types = [DctType::I; 2];
    let transform = dctn(
        &centred,
        &[side, side],
        &[0, 1],
        &types,
        Normalization::Inverse,
    )
    .map_err(|e| e.to_string())?;
    let (mut shells, mut dominant) = (vec![0.0; 2 * side], (0, 0, 0.0_f64));
    for my in 0..side {
        for mx in 0..side {
            let c = transform[my * side + mx] / (size * size * weight(mx) * weight(my));
            let s = RealScalar::round(RealScalar::sqrt((mx * mx + my * my) as f64)) as usize;
            shells[s] += c * c;
            if mx + my > 0 && c.abs() > dominant.2 {
                dominant = (mx, my, c.abs());
            }
        }
    }
    let spectrum = (1..side)
        .filter(|&s| shells[s] > 0.0)
        .map(|s| [PI * s as f64 / size, shells[s]])
        .collect();
    Ok((dominant, spectrum))
};
let (mut rows, mut layers) = (Vec::new(), Vec::new());
for (time, u) in [(early_time, &early), (100.0, &last)] {
    let ((mx, my, amplitude), spectrum) = analyse(u)?;
    let kh2 = axis_wavenumber2(mx, length) + axis_wavenumber2(my, length);
    let peak = spectrum.iter().fold(
        [0.0, 0.0],
        |b: [f64; 2], p| if p[1] > b[1] { *p } else { b },
    );
    let k = PI * RealScalar::sqrt((mx * mx + my * my) as f64) / size;
    let label = format!("t = {time}");
    let rate = growth_rate(kh2, ratio);
    rows.push((label.clone(), mx, my, amplitude, k, rate, peak[0]));
    layers.push(
        serde_json::json!({ "id": label, "kind": "line", "name": label, "points": spectrum }),
    );
}
let columns = serde_json::json!([
    { "key": "0", "label": "Time" },
    { "key": "1", "label": "Dominant mode m_x", "type": "integer" },
    { "key": "2", "label": "Dominant mode m_y", "type": "integer" },
    { "key": "3", "label": "Amplitude |c| [-]", "type": "number", "format": sci3 },
    { "key": "4", "label": "Dominant-mode wavenumber k [-]", "type": "number", "format": fixed4 },
    { "key": "5", "label": "Re λ_h of that mode [-]", "type": "number", "format": fixed4 },
    { "key": "6", "label": "Wavenumber of shell maximizing summed c² [-]", "type": "number", "format": fixed4 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "modes" })
);
let k_max = fastest_wavenumber(ratio);
let mut annotations =
    vec![serde_json::json!({ "kind": "line", "axis": "x", "value": k_max, "label": "k_max" })];
if let Some([low, high]) = unstable_band(ratio) {
    let band = serde_json::json!({ "kind": "range", "axis": "x", "from": low, "to": high });
    annotations.push(band);
}
emit_chart!(
    serde_json::json!({
        "kind": "xy",
        "xLabel": "Shell wavenumber π s / L [-]",
        "yLabel": "Squared-amplitude sum per shell Σ c² [-]",
        "yType": "log",
        "dataZoom": true,
        "tooltip": true,
        "annotations": annotations,
        "layers": layers
    }),
    metadata = serde_json::json!({ "id": "spectrum" })
);
```

By default, the dominant mode at $t=20$ is $(5,1)$ ($k=0.5006$, $\operatorname{Re}\lambda_h=0.2629$); the shell maximizing summed $c^2$ is $s=5$ ($k=0.4909$).
This shell contains $k_{\max}=0.4867$ and fastest-growing discrete mode $(5,0)$; linear-stage pattern wavenumber agrees with $k_{\max}$ to shell-width resolution.
Mode $(5,1)$ dominates because its growth rate differs from the maximum by only $3\times10^{-4}$, leaving almost no amplitude difference by $t=20$.
Initial random amplitudes determine which mode wins.
At $t=20$, shells outside the unstable band are many orders of magnitude smaller than those inside; the highest-wavenumber shell has decayed to around $10^{-25}$.

The dominant mode at $t=100$ is $(5,3)$ ($k=0.5725$), and the largest shell is $s=6$ ($k=0.5890$), both larger than $k_{\max}$.
Repeating with seeds 2 through 5 gives the same largest shell $s=5$ at $t=20$, but dominant wavenumbers at $t=100$ range from $0.50$ to $0.66$.
Linear analysis predicts a characteristic wavelength growing while perturbations are small.
After saturation, spot spacing also depends on nonlinear terms and initial data, and is not determined by $k_{\max}$ alone.

## Summary

For nonlinear reaction–diffusion systems, write right-hand side $-A\mathbf{y}+M\mathbf{R}(\mathbf{y})$ using the operator and lumped mass from `StructuredFdmPlan`, normalize mass with `MethodOfLinesPlan`, and integrate using `RosenbrockW` with sparse LU stages.
Diffusion stiffness stability-limits explicit steps, but Rosenbrock-W advances default $d=20$ to $t=100$ in 87 steps.
The linear-stage perturbation growth rate is near the largest discrete-mode $\operatorname{Re}\lambda_h$; at $d<d_c$, decay is near the slowest discrete decay rate.
DCT-I dominant wavenumbers agree with $k_{\max}$ to shell-width resolution in the linear stage, but saturated patterns depart from $k_{\max}$ and also vary with initial data.
Use dispersion relations to estimate wavelengths, then confirm actual arrangement and spacing through time integration.
