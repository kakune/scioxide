Heat diffusion, string vibrations, electrostatic potentials, elastic deformation, and fluid flow are described by partial differential equations (PDEs) expressing conservation laws over infinitesimal volumes.
`scioxide-pde` discretizes these equations in space and uses SciOxide solvers for the resulting linear systems, systems of ordinary differential equations, and nonlinear equations.

Each spatial-discretization type handles one through three dimensions.
The structured-grid finite-difference method (FDM) `StructuredFdmPlan`, cell-centered finite-volume methods (FVM) `StructuredFvmPlan` and `SimplexFvmPlan`, and P1 and P2 finite-element method (FEM) `SimplexFemPlan` for intervals, triangles, and tetrahedra implement the shared contract `SpatialDiscretization`.
`EllipticProblem` solves steady problems, `ParabolicProblem` diffusion equations, and `HyperbolicProblem` wave equations through the same procedure for any plan.
Elasticity, incompressible flow, hyperbolic conservation laws, adaptive mesh refinement (AMR), and discrete adjoints each have dedicated plans.

`scioxide-spatial` handles meshes, boundary sets, and field locations; `scioxide-sparse` sparse matrices; `scioxide-linalg` iterative methods; `scioxide-rootfind` Newton–Krylov methods; and `scioxide-ode` time integration.
Every operation proceeds through configuration, preparation, and execution; prepared plans are immutable and `Send + Sync + Clone`, so the same plan can be solved repeatedly.

## First computation and interpreting results

Consider light entering one side of a fused-silica plate of thickness $L=10$ mm and being absorbed exponentially with absorption length $\delta$.
The plate absorbs a heat flux of $I_0=10^4$ W/m² (1 W/cm²), and both surfaces are held at $T_0=20$ °C.
Neglecting temperature variation along the surfaces, the temperature $T(x)$ obeys the one-dimensional steady heat-conduction equation:

$$
-k\,T''(x)=q(x),\qquad q(x)=\frac{I_0}{\delta}e^{-x/\delta},\qquad T(0)=T(L)=T_0
$$

Here $x$ is depth from the illuminated surface, $k=1.4$ W/(m·K) is thermal conductivity, and $q$ is heat generation per unit volume due to absorbed light.
Integrating twice yields the exact solution

$$
T(x)=T_0+\frac{I_0\delta}{k}\Bigl[\bigl(1-e^{-x/\delta}\bigr)-\frac{x}{L}\bigl(1-e^{-L/\delta}\bigr)\Bigr]
$$

which provides an independent check of the numerical solution.

The computation proceeds as follows.

1. Use `CoordinateAxis::uniform`, `Grid1d`, and `SegmentMesh` to construct a uniform grid with $N+1$ vertices.
2. Use `StructuredBoundaries::uniform` to impose the Dirichlet condition $T=T_0$ on both surfaces.
3. Specify thermal conductivity with `ConstantDiffusion::new(k)` and prepare a finite-difference plan with `StructuredFdmPlan::new`.
4. Specify heat generation $q$ with `FieldData::time_invariant` and solve with `EllipticProblem::new(&plan, &source).solve_with_options(&EllipticOptions::new())`.

The following cell solves the same problem on two grids with $N+1$ vertices and $2N+1$ vertices, the latter halving the grid spacing.
The inputs are the coarse-grid vertex count and absorption length $\delta$.
The chart plots the exact solution (dashed) and nodal temperatures on both grids.
The table lists the grid-spacing to absorption-length ratio $h/\delta$, maximum temperature, maximum error against the exact solution, observed order from the ratio of the two grid errors, direct-method backward error, and termination reason.
The observed order is $\log_2(e_h/e_{h/2})$; a value near 2 means the error decreases with the square of the grid spacing.

```rust
//| id: pde-index-absorbing-slab
//| ref: pde-index-absorbing-slab
//| title: "Compute steady temperatures in a light-absorbing plate with finite differences and check errors by halving the grid spacing"
//| run: reactive
//| crates: [scioxide-core, scioxide-pde, scioxide-spatial]
//| inputs:
//|   vertex_count: {"type":"range","label":"Coarse-grid vertices N+1 [-]","description":"The fine grid has 2N+1 vertices.","min":5,"max":129,"step":4,"value":9}
//|   absorption_depth: {"type":"range","label":"Absorption length δ [mm]","description":"Depth at which heat generation falls to 1/e. Smaller values concentrate heating near the surface.","min":0.2,"max":5,"step":0.1,"value":1}
//| cases:
//|   - {"id":"fine-grid","label":"65 vertices","description":"h/δ becomes 0.16 and 0.08; the fine-grid maximum error is 2.4×10⁻³ K and the observed order is 2.00.","inputs":{"vertex_count":65}}
//|   - {"id":"thin-absorber","label":"Absorption length 0.2 mm","description":"The grid spacing exceeds the absorption length, so the coarse grid misses the location and value of the maximum temperature.","inputs":{"absorption_depth":0.2}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"slab","path":"/rows/0/0","equals":9}
//|       - {"artifact":"slab","path":"/rows/0/3","approx":{"value":0.5755317,"rtol":1e-6}}
//|       - {"artifact":"slab","path":"/rows/0/4","equals":null}
//|       - {"artifact":"slab","path":"/rows/1/4","approx":{"value":1.918,"atol":0.005}}
//|       - {"artifact":"slab","path":"/rows/1/5","range":{"min":0,"max":1e-14}}
//|       - {"artifact":"slab","path":"/rows/1/6","equals":"Completed"}
//|       - {"path":"/outputs/2/state","equals":"satisfied"}
//|   - case: fine-grid
//|     expect:
//|       - {"artifact":"slab","path":"/rows/1/3","approx":{"value":2.432245e-3,"rtol":1e-5}}
//|       - {"artifact":"slab","path":"/rows/1/4","approx":{"value":1.9986,"atol":0.002}}
//|   - case: thin-absorber
//|     expect:
//|       - {"artifact":"slab","path":"/rows/0/1","approx":{"value":6.25,"rtol":1e-12}}
//|       - {"artifact":"slab","path":"/rows/0/2","approx":{"value":20.0944,"atol":1e-3}}
//|       - {"artifact":"slab","path":"/rows/1/4","range":{"min":0.6,"max":0.9}}
use scioxide_core::{SciOxideError, RealScalar};
use scioxide_pde::{
    BoundaryData, BoundaryKind, ConstantDiffusion, EllipticOptions, EllipticProblem, FieldData,
    FieldPoint, PdeSolveReport, SpatialDiscretization, StructuredBoundaries, StructuredFdmPlan,
};
use scioxide_spatial::{AxisTopology, CoordinateAxis, Grid1d, SegmentMesh};

// Plate thickness L [m], thermal conductivity k [W/(m·K)], absorbed heat flux I₀ [W/m²], and surface temperature T₀ [°C].
let thickness = 0.01;
let conductivity = 1.4;
let absorbed = 1.0e4;
let face = 20.0;
let depth = absorption_depth * 1.0e-3;
// Exact solution for the independent check: T(x) = T₀ + (I₀δ/k)[(1 − e^{−x/δ}) − (x/L)(1 − e^{−L/δ})].
let exact = move |x: f64| {
    let through = 1.0 - RealScalar::exp(-thickness / depth);
    let inside = 1.0 - RealScalar::exp(-x / depth) - x / thickness * through;
    face + absorbed * depth / conductivity * inside
};
// Solve on a grid with n vertices and return (depth [mm], temperature [°C]) pairs and a report.
let solve = |n: usize| -> Result<(Vec<[f64; 2]>, PdeSolveReport<f64>), SciOxideError> {
    let axis = CoordinateAxis::uniform(0.0, thickness, n)?;
    let mesh = SegmentMesh::new(Grid1d::new([axis], [AxisTopology::Bounded])?)?;
    let walls = BoundaryData::constant(face);
    let faces = StructuredBoundaries::uniform(&mesh, 1, BoundaryKind::Dirichlet, walls)?;
    let plan = StructuredFdmPlan::new(mesh, &ConstantDiffusion::new(conductivity), &faces)?;
    // Heat generation from absorbed light q(x) = (I₀/δ) e^{−x/δ} [W/m³].
    let source = FieldData::time_invariant(move |p: FieldPoint<f64, 1>| {
        Ok(absorbed / depth * RealScalar::exp(-p.point[0] / depth))
    });
    let solution =
        EllipticProblem::new(&plan, &source).solve_with_options(&EllipticOptions::new())?;
    let mut points = Vec::with_capacity(n);
    for (unknown, &t) in solution.values().iter().enumerate() {
        points.push([plan.dof_point(unknown)?.point[0] * 1.0e3, t]);
    }
    Ok((points, solution.report().clone()))
};
let exact_points: Vec<[f64; 2]> = (0..=200)
    .map(|i| {
        let x = thickness * i as f64 / 200.0;
        [x * 1.0e3, exact(x)]
    })
    .collect();
let mut series = vec![serde_json::json!({
    "name": "Exact solution",
    "points": exact_points,
    "style": { "lineType": "dashed" }
})];
let coarse = vertex_count as usize;
let mut rows = Vec::new();
let mut errors: Vec<f64> = Vec::new();
let mut reports = Vec::new();
for n in [coarse, 2 * coarse - 1] {
    let (points, report) = solve(n).map_err(|e| e.to_string())?;
    let error = points
        .iter()
        .map(|[x, t]| (t - exact(x * 1.0e-3)).abs())
        .fold(0.0_f64, f64::max);
    let peak = points.iter().map(|p| p[1]).fold(f64::MIN, f64::max);
    // Compute observed order from the error ratio against the coarse grid (undefined for the coarse grid itself).
    let order = errors
        .last()
        .map(|&previous| RealScalar::log2(previous / error));
    let backward = report
        .diagnostics()
        .linear_residual_report()
        .map(|r| r.scaled_norm());
    let ratio = thickness / (n - 1) as f64 / depth;
    let status = report.termination().to_string();
    rows.push((n, ratio, peak, error, order, backward, status));
    series.push(serde_json::json!({
        "name": format!("Finite differences ({n} vertices)"),
        "points": points,
        "style": { "showSymbol": true }
    }));
    errors.push(error);
    reports.push(report);
}
emit_line_chart!(
    &series,
    options = &serde_json::json!({ "xLabel": "Depth x [mm]", "yLabel": "Temperature T [°C]" })
);
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let fixed2 = serde_json::json!({ "fractionDigits": 2 });
let fixed3 = serde_json::json!({ "fractionDigits": 3 });
let columns = serde_json::json!([
    { "key": "0", "label": "Vertices [-]", "type": "integer" },
    { "key": "1", "label": "h/δ [-]", "type": "number", "format": fixed2 },
    { "key": "2", "label": "Maximum temperature [°C]", "type": "number", "format": fixed3 },
    { "key": "3", "label": "Maximum error [K]", "type": "number", "format": sci2 },
    { "key": "4", "label": "Observed order [-]", "type": "number", "format": fixed2, "nullText": "—" },
    { "key": "5", "label": "Backward error [-]", "type": "number", "format": sci2, "nullText": "None" },
    { "key": "6", "label": "Termination reason" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "slab" })
);
let fine = &reports[1];
let outcome = if reports.iter().all(|r| r.is_success()) {
    Outcome::satisfied("Solved the reduced linear systems on both grids")
        .explanation("This checks backward error; read discretization error from the maximum error and observed order in the table.")
} else {
    Outcome::partial("The solve did not complete")
};
emit_outcome!(
    outcome
        .status(fine.termination().to_string())
        .diagnostic("Fine-grid maximum error", errors[1], Some("K"))
        .diagnostic("Error ratio", errors[0] / errors[1], None)
);
```

With the default 9 vertices, the grid spacing $h=1.25$ mm exceeds the 1 mm absorption length, and the maximum nodal temperature of 24.195 °C falls below the exact maximum of 24.784 °C (at a depth of 2.30 mm).
The maximum nodal error is 0.58 K.
On the grid with 17 vertices, the maximum error falls to 0.15 K; the observed order of 1.92 is close to the second-order finite-difference error $O(h^2)$.
Going from 65 to 129 vertices gives an observed order of 2.00 and reduces the maximum error to $2.4\times10^{-3}$ K.
Reducing the absorption length to 0.2 mm gives $h/\delta$ values of 6.25 and 3.13, with observed order only 0.77.
Heat generation is concentrated in a layer thinner than the grid spacing, so the grid cannot resolve the temperature variation.
The observed order approaches 2 only once $h/\delta$ is sufficiently smaller than 1.

In every row, the direct-method backward error is below $10^{-16}$ and the termination reason is `Completed`.
Nevertheless, temperature errors exceeding 0.1 K can remain.
Backward error and termination reason indicate only that the linear system was solved; spatial discretization error must be checked separately against a known solution or by grid refinement.

### Interpreting return values

Read the return value of `solve_with_options` in the following order.

1. `Err(SciOxideError)` covers input shapes and gauge settings; coefficient or source callbacks; assembly and factorization failures; backward errors exceeding tolerance; and exceeded computation limits.
   Inspect the classification with `kind()` and `view()`.
2. Because `solve_with_options` uses the default direct method, the termination reason in `Ok(solution)` is `Completed` and `solution.report().is_success()` is true.
   When an iterative solver is injected into the workspace and `solve_into` is used, reaching an iteration limit, for example, can return an unconverged value and a report with false `is_success()` inside `Ok` ([Interpreting results, errors, and diagnostics](oxref:pde-api-reading-results)).
   In either case, inspect `is_success()` before using the field.
3. On success, `solution.values()` is a field ordered by the discretization's unknowns.
   Unknowns lie at vertices for FDM and P1 FEM, vertices and edge midpoints for P2 FEM, and cells for FVM; obtain each unknown's coordinates with `dof_point`.
4. `solution.report().diagnostics()` holds the selected linear solver's name (`method()`), iteration count and residual, and direct-method backward error (`linear_residual_report()`).

Time-dependent `solve_with_options` returns the same report structure, adding counts of attempted, accepted, and rejected time steps to its diagnostics.
Time-dependent `solve` and `solve_with_options`, which return owned results, return errors in `PartialFailure` and retain the last accepted state as progress (`PdeProgress`) when it can be saved.

## Summary

`scioxide-pde` assembles operators, lumped masses, and loads through spatial plans and solves with `EllipticProblem`, `ParabolicProblem`, and `HyperbolicProblem` regardless of dimension or discretization method.
Check the termination reason with `is_success()` before reading fields and diagnostics, and use `dof_point` to locate each field value.
Small backward errors or residuals still leave discretization error, so assess accuracy through known solutions, observed orders under grid refinement, and conserved quantities.
As in the first computation, whether the grid spacing sufficiently resolves the solution's variation scale (here the absorption length) determines whether the observed order approaches theory.
