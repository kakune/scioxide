An orthogonal expansion $p(x)=\sum_{k=0}^n\gamma_k\phi_k(x)$ can be differentiated and integrated in the same basis without conversion to monomials.
This avoids the coefficient growth seen in [Preparing, evaluating, and converting orthogonal bases](oxref:poly-orthogonal-monomial-growth).
This page derives derivative and antiderivative coefficients from three-term derivative relations and explains physical-coordinate scaling and integration constants.
Three cells check affine scaling and differences between polynomial APIs and Plan-derived operators against closed forms.
The previous page explained `OrthogonalBasisSpec`, specifying family, normalization, and affine coordinates, and Plan `OrthogonalBasisPlan`.

## Derivatives and integration constants

The affine transformation $t=(x-\mathrm{shift})/s$ ($s=\mathrm{scale}$) gives

$$
\frac{d}{dx}=\frac1s\frac{d}{dt},\qquad dx=s\,dt
$$


Omitting these factors yields correct values but inconsistent derivative and integral units.

Calculus with coefficients in the same family uses relations expressing basis functions through derivatives.
For Chebyshev first kind,

$$
2T_k=\frac{T_{k+1}'}{k+1}-\frac{T_{k-1}'}{k-1}\quad(k\ge2),\qquad T_0=T_1',\qquad T_1=\frac{T_2'}4
$$

holds (DLMF 18.9).
Applying this to $p=\sum_{k=0}^n\gamma_kT_k(t)$ gives derivative $p'(x)=\sum_{k=0}^{n-1}\delta_kT_k(t)$ coefficients backward from $\delta_n=\delta_{n+1}=0$ as

$$
\delta_k=\delta_{k+2}+\frac{2(k+1)\gamma_{k+1}}{s}\quad(k=n-1,\dots,1),\qquad
\delta_0=\frac{\gamma_1}{s}+\frac{\delta_2}{2}
$$


Antiderivative $F=\sum_{j=0}^{n+1}\Gamma_jT_j(t)$ coefficients, with $\gamma_{n+1}=\gamma_{n+2}=0$, are

$$
\Gamma_j=\frac{s(\gamma_{j-1}-\gamma_{j+1})}{2j}\quad(j\ge2),\qquad
\Gamma_1=s\Bigl(\gamma_0-\frac{\gamma_2}2\Bigr)
$$

leaving only constant coefficient $\Gamma_0$ as the integration constant.
Other families also have a three-term relation $\phi_k=A_k\phi_{k+1}'+B_k\phi_k'+C_k\phi_{k-1}'$ (Legendre $(2k+1)P_k=P_{k+1}'-P_{k-1}'$, Laguerre $L_k=L_k'-L_{k+1}'$, Hermite $2(k+1)H_k=H_{k+1}'$); SciOxide uses these family-specific bands for the same $O(n)$ computation.
Each antiderivative coefficient combines at most 3 input coefficients linearly, so its rounding error stays within a few $u$ times the sum of absolute summands ($u$ is unit roundoff).
Backward derivative recurrences accumulate errors from the end; $\delta_k$ sums terms of magnitude $\sum_{j>k}j|\gamma_j|$, so expansions with large high-degree coefficients can give large relative errors at low degrees.
Both retry with extended exponent range when ordinary arithmetic approaches range loss.

Polynomial APIs return owned `ApproxPolynomial` results.

- `derivative()` returns the derivative in the same family, normalization, and coordinates.
  Coefficient count follows expansion length; the Plan's maximum degree may exceed the expansion's.
  The returned polynomial's Plan is prepared again for derivative degree.
- `antiderivative(anchor, value)` returns an antiderivative satisfying $F(\mathrm{anchor})=\mathrm{value}$ in physical coordinates, increasing degree by one.
  Determine $\Gamma_0$ by evaluating the antiderivative with $\Gamma_0=0$ at `anchor` using [Clenshaw](oxref:poly-clenshaw), then dividing the adjustment needed to reach `value` by $\phi_0$.
  Non-finite `anchor` or `value` gives `NonFinite`.
- `integral(lower, upper)` returns the unweighted definite integral $\int_{\mathrm{lower}}^{\mathrm{upper}}p(x)\,dx$.
  It evaluates the antiderivative satisfying $F(\mathrm{lower})=0$ at `upper`; cancellation reduces relative accuracy if $|F(\mathrm{upper})|$ is much smaller than intermediate $|F|$.
  Equal endpoints return exactly 0.
  Endpoint types match coefficients; complex endpoints require complex-coefficient polynomials (polynomial integrals are path-independent).

Plan-derived operators use lengths set by the Plan's maximum degree.

- `plan.derivative_operator()` returns a Plan-borrowing `OrthogonalDerivative` without allocation at construction.
  As a `LinearOperator`, it has `max(degree, 1)` rows and `degree + 1` columns; inputs must have exactly `degree + 1` entries including trailing zeros.
  `apply` allocates and returns output; `apply_into` takes scratch at least row-count length and writes output only on success.
- `plan.antiderivative_plan()` prepares an output Plan with degree raised by one and owns it as `OrthogonalAntiderivative`.
  `output_plan()` returns the output basis; `workspace_requirements(())` returns scratch length `degree + 2`.
  `apply_into(input, (anchor, value), output, scratch, context)` maps length-`degree + 1` input to length-`degree + 2` output without allocation.
  Results are assembled in scratch, then moved to `output` after checking execution-context stops at API entry and immediately before writing, preserving `output` on failure.
  Length mismatches give `DimensionMismatch`; stops give `ExecutionStopped`.

## Checking calculus under coordinate changes

Construct $p=1+2T_1(t)+T_2(t)=2t+2t^2$ below.
Inputs are coordinate center $x_0$ and scale $s$ (both dimensionless); outputs are values, physical derivatives, and antiderivatives satisfying $F(x_0)=0$ at points corresponding to $t=-1,-1/2,0,1/2,1$, plus the full-interval integral over $[x_0-s,x_0+s]$.
Independent checks differentiate and integrate the quadratic on the right termwise, giving closed forms $p'=(2+4t)/s$ and $F=s(t^2+2t^3/3)$ and full-interval integral $4s/3$.
Check that first-table differences stay at rounding level and the second-table integral matches the closed form.

```rust
//| id: poly-chebyshev-calculus
//| ref: poly-chebyshev-calculus
//| title: "Affine coordinates and calculus scaling"
//| run: reactive
//| crates: [scioxide-poly]
//| inputs:
//|   center: {"type":"range","label":"Center x₀ [-]","min":-3,"max":3,"step":0.5,"value":1}
//|   width: {"type":"range","label":"Scale s [-]","min":0.5,"max":4,"step":0.5,"value":2}
//| cases:
//|   - {"id":"narrow-shifted","label":"x₀ = −3, s = 0.5","description":"Reducing the scale by a factor of 4 multiplies derivatives at the same t by 4 and antiderivatives by 1/4.","inputs":{"center":-3,"width":0.5}}
//|   - {"id":"wide","label":"s = 4","description":"Doubling scale halves derivatives and doubles antiderivatives and integrals.","inputs":{"width":4}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"values","path":"/rows/4/2","approx":{"value":3,"rtol":1e-14}}
//|       - {"artifact":"values","path":"/rows/4/3","approx":{"value":3.3333333333333335,"rtol":1e-14}}
//|       - {"artifact":"values","path":"/rows/4/5","range":{"max":1e-14}}
//|       - {"artifact":"values","path":"/rows/0/6","range":{"max":1e-14}}
//|       - {"artifact":"integral","path":"/rows/0/1","approx":{"value":2.6666666666666665,"rtol":1e-14}}
//|   - case: narrow-shifted
//|     expect:
//|       - {"artifact":"values","path":"/rows/4/2","approx":{"value":12,"rtol":1e-14}}
//|       - {"artifact":"values","path":"/rows/4/3","approx":{"value":0.8333333333333334,"rtol":1e-13}}
//|       - {"artifact":"integral","path":"/rows/0/1","approx":{"value":0.6666666666666666,"rtol":1e-13}}
//|   - case: wide
//|     expect:
//|       - {"artifact":"values","path":"/rows/4/2","approx":{"value":1.5,"rtol":1e-14}}
//|       - {"artifact":"values","path":"/rows/4/3","approx":{"value":6.666666666666667,"rtol":1e-14}}
//|       - {"artifact":"integral","path":"/rows/0/1","approx":{"value":5.333333333333333,"rtol":1e-14}}
use scioxide_poly::{
    ApproxPolynomial, BasisNormalization, OrthogonalBasisSpec, OrthogonalFamily,
};

let fixed4 = serde_json::json!({ "fractionDigits": 4 });
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let spec = OrthogonalBasisSpec::new(
    OrthogonalFamily::ChebyshevT,
    BasisNormalization::Classical,
    center,
    width,
)
.map_err(|e| e.to_string())?;
let polynomial =
    ApproxPolynomial::orthogonal(vec![1.0_f64, 2.0, 1.0], spec).map_err(|e| e.to_string())?;
let derivative = polynomial.derivative().map_err(|e| e.to_string())?;
let primitive = polynomial
    .antiderivative(center, 0.0)
    .map_err(|e| e.to_string())?;
let mut rows = Vec::new();
for t in [-1.0_f64, -0.5, 0.0, 0.5, 1.0] {
    let x = center + width * t;
    let p = polynomial.evaluate(x).map_err(|e| e.to_string())?;
    let d = derivative.evaluate(x).map_err(|e| e.to_string())?;
    let f = primitive.evaluate(x).map_err(|e| e.to_string())?;
    // Independent check: p=2t+2t², dp/dx=(2+4t)/s, F=s(t²+2t³/3).
    rows.push((
        x,
        p,
        d,
        f,
        (p - (2.0 * t + 2.0 * t * t)).abs(),
        (d - (2.0 + 4.0 * t) / width).abs(),
        (f - width * (t * t + 2.0 * t * t * t / 3.0)).abs(),
    ));
}
let columns = serde_json::json!([
    { "key": "0", "label": "x [-]", "type": "number", "format": fixed4 },
    { "key": "1", "label": "p [-]", "type": "number", "format": fixed4 },
    { "key": "2", "label": "p′ [-]", "type": "number", "format": fixed4 },
    { "key": "3", "label": "F [-]", "type": "number", "format": fixed4 },
    { "key": "4", "label": "Value discrepancy [-]", "type": "number", "format": sci2 },
    { "key": "5", "label": "Derivative discrepancy [-]", "type": "number", "format": sci2 },
    { "key": "6", "label": "Integral discrepancy [-]", "type": "number", "format": sci2 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "values" })
);
let integral = polynomial
    .integral(center - width, center + width)
    .map_err(|e| e.to_string())?;
let exact = 4.0 * width / 3.0;
let integral_columns = serde_json::json!([
    { "key": "0", "label": "Quantity" },
    { "key": "1", "label": "SciOxide [-]", "type": "number", "format": fixed4 },
    { "key": "2", "label": "Closed form [-]", "type": "number", "format": fixed4 },
    { "key": "3", "label": "Discrepancy [-]", "type": "number", "format": sci2 }
]);
emit_table_with_columns!(
    integral_columns,
    vec![("Full-interval integral", integral, exact, (integral - exact).abs())],
    metadata = serde_json::json!({ "id": "integral" })
);
```

Doubling scale preserves values at the same $t$, halves derivatives, and doubles antiderivatives.
Changing center shifts only physical coordinates; values and calculus checks at the same $t$ stay unchanged.
With default $x_0=1$ and $s=2$, the full integral matches $8/3$ and every discrepancy column is at most $4.5\times10^{-16}$.
Non-default inputs also keep discrepancies at most $9\times10^{-16}$.

## Expansion length and Plan degree

Polynomial `derivative()` and `antiderivative()` form coefficients by expansion length.
Plan-derived operators `OrthogonalDerivative` and `OrthogonalAntiderivative` instead set input and output lengths by maximum Plan degree.
The next two cells put the same $p=1+2T_1+T_2$ in a maximum-degree-$N$ Plan, comparing polynomial API and operator coefficients with hand-computed closed forms from the formulas above.
Inputs are scale $s$ and maximum Plan degree $N$, with center 0.
Closed forms are $p'=(2+4T_1)/s$ and $F=s(1/2+T_1/2+T_2/2+T_3/6)$ ($F(0)=0$); missing coefficients are shown as “—”.

The following block defines helpers shared by two cells.
`COEFFICIENTS` gives coefficients $(1,2,1)$ of $p$; `expansion_on_plan` prepares a Chebyshev basis centered at 0 with scale $s$ and maximum degree $N$, placing polynomial $p$ on it; `padded` pads coefficients with trailing zeros to $N+1$ entries for operators.
`coefficient_rows` and `coefficient_columns` tabulate polynomial API, Plan operator, and closed-form coefficients by degree, using `None` for absent coefficients to distinguish them from zeros.
`count_columns` supplies columns for a two-column operator-length table.

```rust
//| id: poly-orthogonal-calculus-model
//| kind: definitions
//| title: "Quadratic Chebyshev expansion on a maximum-degree-N Plan and comparison tables"
//| crates: [scioxide-poly]
use scioxide_poly::{
    ApproxPolynomial, BasisNormalization, OrthogonalBasis, OrthogonalBasisSpec, OrthogonalFamily,
};

/// Expansion coefficients in ascending degree order for p = T₀ + 2T₁ + T₂.
pub(crate) const COEFFICIENTS: [f64; 3] = [1.0, 2.0, 1.0];

/// Prepare a Chebyshev basis centered at 0 with scale s and maximum degree N, and place p on that Plan.
/// The polynomial owns the Plan; borrow it with basis().plan().
pub(crate) fn expansion_on_plan(
    width: f64,
    degree: usize,
) -> Result<ApproxPolynomial<f64, OrthogonalBasis<f64>>, String> {
    let spec = OrthogonalBasisSpec::new(
        OrthogonalFamily::ChebyshevT,
        BasisNormalization::Classical,
        0.0,
        width,
    )
    .map_err(|e| e.to_string())?;
    let plan = spec
        .prepare(degree, Default::default())
        .map_err(|e| e.to_string())?;
    ApproxPolynomial::orthogonal_with_plan(COEFFICIENTS.to_vec(), plan, Default::default())
        .map_err(|e| e.to_string())
}

/// Plan operators take N + 1 inputs, so pad with trailing zeros.
pub(crate) fn padded(degree: usize) -> Vec<f64> {
    let mut values = COEFFICIENTS.to_vec();
    values.resize(degree + 1, 0.0);
    values
}

/// Rows for degrees 0..=last: (k, polynomial API, Plan operator, closed form).
/// Use None for absent coefficients to distinguish them from zeros.
pub(crate) fn coefficient_rows(
    polynomial: &[f64],
    plan: &[f64],
    exact: &[f64],
    last: usize,
) -> Vec<(usize, Option<f64>, Option<f64>, Option<f64>)> {
    let entry = |values: &[f64], k: usize| values.get(k).copied();
    (0..=last)
        .map(|k| (k, entry(polynomial, k), entry(plan, k), entry(exact, k)))
        .collect()
}

/// Table columns for coefficient_rows. polynomial and plan name the two compared APIs.
pub(crate) fn coefficient_columns(polynomial: &str, plan: &str) -> serde_json::Value {
    let fixed6 = serde_json::json!({ "fractionDigits": 6 });
    serde_json::json!([
        { "key": "0", "label": "Degree k", "type": "integer" },
        { "key": "1", "label": polynomial, "type": "number", "format": fixed6, "nullText": "—" },
        { "key": "2", "label": plan, "type": "number", "format": fixed6, "nullText": "—" },
        { "key": "3", "label": "Closed form", "type": "number", "format": fixed6, "nullText": "—" }
    ])
}

/// Columns of the quantity/value table showing operator lengths.
pub(crate) fn count_columns() -> serde_json::Value {
    serde_json::json!([
        { "key": "0", "label": "Quantity" },
        { "key": "1", "label": "Value", "type": "integer" }
    ])
}
```

The first cell compares derivatives.
`derivative()` forms coefficients by expansion length and prepares the returned polynomial's Plan again for derivative degree.
`derivative_operator()` borrows the Plan, acting as an operator with `max(N, 1)` rows and $N+1$ columns.
The second table shows operator rows and columns and degree of the polynomial Plan returned by `derivative()`.

```rust
//| id: poly-orthogonal-calculus-operators
//| ref: poly-orthogonal-calculus-operators
//| title: "Derivative coefficients determined by expansion length and Plan degree"
//| run: reactive
//| uses: [poly-orthogonal-calculus-model]
//| crates: [scioxide-core, scioxide-poly]
//| inputs:
//|   width: {"type":"range","label":"Scale s [-]","min":0.5,"max":4,"step":0.5,"value":2}
//|   plan_degree: {"type":"range","label":"Maximum Plan degree N","min":2,"max":6,"step":1,"value":4}
//| cases:
//|   - {"id":"exact-degree","label":"N = 2","description":"Plan degree equals expansion degree; operator and polynomial APIs return equal-length coefficients.","inputs":{"plan_degree":2}}
//|   - {"id":"long-plan","label":"N = 6, s = 0.5","description":"Longer Plans give trailing zeros in operator output; reducing the scale by a factor of 4 multiplies coefficients by 4.","inputs":{"plan_degree":6,"width":0.5}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"derivative","path":"/rows/0/1","approx":{"value":1,"rtol":1e-14}}
//|       - {"artifact":"derivative","path":"/rows/1/2","approx":{"value":2,"rtol":1e-14}}
//|       - {"artifact":"derivative","path":"/rows/2/1","equals":null}
//|       - {"artifact":"derivative","path":"/rows/3/2","equals":0}
//|       - {"artifact":"shapes","path":"/rows/0/1","equals":4}
//|       - {"artifact":"shapes","path":"/rows/1/1","equals":5}
//|       - {"artifact":"shapes","path":"/rows/2/1","equals":1}
//|   - case: exact-degree
//|     expect:
//|       - {"artifact":"derivative","path":"/rows/1/2","approx":{"value":2,"rtol":1e-14}}
//|       - {"artifact":"derivative","path":"/rows/2/2","equals":null}
//|       - {"artifact":"shapes","path":"/rows/0/1","equals":2}
//|   - case: long-plan
//|     expect:
//|       - {"artifact":"derivative","path":"/rows/1/2","approx":{"value":8,"rtol":1e-14}}
//|       - {"artifact":"derivative","path":"/rows/5/2","equals":0}
//|       - {"artifact":"shapes","path":"/rows/0/1","equals":6}
use scioxide_core::LinearOperator;
use scioxide_poly::PolynomialBasis;

let degree = plan_degree as usize;
let polynomial = expansion_on_plan(width, degree)?;
// Polynomial APIs form coefficients from expansion length (3 coefficients).
let derivative = polynomial.derivative().map_err(|e| e.to_string())?;
// Plan operators produce max(N, 1) coefficients from N + 1 inputs.
let operator = polynomial.basis().plan().derivative_operator();
let rows_out = LinearOperator::<f64>::rows(&operator);
let mut by_operator = vec![0.0_f64; rows_out];
let scratch_len =
    LinearOperator::<f64>::apply_workspace_len(&operator).map_err(|e| e.to_string())?;
let mut scratch = vec![0.0_f64; scratch_len];
operator
    .apply_into(&padded(degree), &mut by_operator, &mut scratch)
    .map_err(|e| e.to_string())?;
// Independent check: manually derive p′ = (2 + 4T₁)/s from T_k differentiation formulas.
let exact = [2.0 / width, 4.0 / width];
let rows = coefficient_rows(
    derivative.basis().coefficients(),
    &by_operator,
    &exact,
    degree,
);
emit_table_with_columns!(
    coefficient_columns("derivative()", "derivative_operator()"),
    rows,
    metadata = serde_json::json!({ "id": "derivative" })
);
let shapes = vec![
    ("Operator rows", rows_out),
    ("Operator columns", LinearOperator::<f64>::cols(&operator)),
    (
        "Maximum Plan degree of derivative()",
        derivative.basis().plan().degree(),
    ),
];
emit_table_with_columns!(
    count_columns(),
    shapes,
    metadata = serde_json::json!({ "id": "shapes" })
);
```

`derivative()` returns 2 coefficients independently of $N$, matching the closed form.
The returned polynomial's Plan is also prepared again for derivative degree (1 here).
The operator returns $N$ coefficients, with zeros beyond expansion degree.
Thus a Plan prepared once through degree $N$ supports polynomial API differentiation of shorter expansions as well.
Direct operator use requires zero-padding inputs to the Plan's length.

The next cell compares antiderivatives in the same way.
`antiderivative(0, 0)` produces 4 coefficients from expansion length; `antiderivative_plan()` prepares an output Plan one degree higher, writing $N+2$ coefficients from $N+1$ inputs.
The second table shows output Plan degree, output length, and scratch length.

```rust
//| id: poly-orthogonal-antiderivative-plan
//| ref: poly-orthogonal-antiderivative-plan
//| title: "Antiderivative coefficients determined by expansion length and Plan degree"
//| run: reactive
//| uses: [poly-orthogonal-calculus-model]
//| crates: [scioxide-core, scioxide-poly]
//| inputs:
//|   width: {"type":"range","label":"Scale s [-]","min":0.5,"max":4,"step":0.5,"value":2}
//|   plan_degree: {"type":"range","label":"Maximum Plan degree N","min":2,"max":6,"step":1,"value":4}
//| cases:
//|   - {"id":"exact-degree","label":"N = 2","description":"Plan degree equals expansion degree; prepared antiderivative and polynomial APIs return the same 4 coefficients.","inputs":{"plan_degree":2}}
//|   - {"id":"long-plan","label":"N = 6, s = 0.5","description":"Longer Plans give trailing output zeros; reducing the scale by a factor of 4 also multiplies coefficients by 1/4.","inputs":{"plan_degree":6,"width":0.5}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"antiderivative","path":"/rows/0/1","approx":{"value":1,"rtol":1e-14}}
//|       - {"artifact":"antiderivative","path":"/rows/3/2","approx":{"value":0.3333333333333333,"rtol":1e-14}}
//|       - {"artifact":"antiderivative","path":"/rows/4/1","equals":null}
//|       - {"artifact":"antiderivative","path":"/rows/5/2","equals":0}
//|       - {"artifact":"lengths","path":"/rows/0/1","equals":5}
//|       - {"artifact":"lengths","path":"/rows/1/1","equals":6}
//|       - {"artifact":"lengths","path":"/rows/2/1","equals":6}
//|   - case: exact-degree
//|     expect:
//|       - {"artifact":"antiderivative","path":"/rows/3/2","approx":{"value":0.3333333333333333,"rtol":1e-14}}
//|       - {"artifact":"lengths","path":"/rows/1/1","equals":4}
//|   - case: long-plan
//|     expect:
//|       - {"artifact":"antiderivative","path":"/rows/3/2","approx":{"value":0.08333333333333333,"rtol":1e-14}}
//|       - {"artifact":"antiderivative","path":"/rows/7/2","equals":0}
//|       - {"artifact":"lengths","path":"/rows/1/1","equals":8}
use scioxide_core::ExecutionContext;
use scioxide_poly::PolynomialBasis;

let degree = plan_degree as usize;
let polynomial = expansion_on_plan(width, degree)?;
// Polynomial APIs form 4 coefficients from expansion length and set the integration constant through F(0) = 0.
let primitive = polynomial
    .antiderivative(0.0, 0.0)
    .map_err(|e| e.to_string())?;
// Prepared antiderivatives write N + 2 coefficients from N + 1 inputs.
let integral = polynomial
    .basis()
    .plan()
    .antiderivative_plan()
    .map_err(|e| e.to_string())?;
let output_degree = integral.output_plan().degree();
let mut by_plan = vec![0.0_f64; output_degree + 1];
let scratch_len = integral
    .workspace_requirements(())
    .map_err(|e| e.to_string())?
    .scratch_len();
let mut scratch = vec![0.0_f64; scratch_len];
integral
    .apply_into(
        &padded(degree),
        (0.0, 0.0),
        &mut by_plan,
        &mut scratch,
        ExecutionContext::sequential(),
    )
    .map_err(|e| e.to_string())?;
// Independent check: manually derive F = s(1/2 + T₁/2 + T₂/2 + T₃/6) from T_k integration formulas.
let exact = [width / 2.0, width / 2.0, width / 2.0, width / 6.0];
let rows = coefficient_rows(
    primitive.basis().coefficients(),
    &by_plan,
    &exact,
    degree + 1,
);
emit_table_with_columns!(
    coefficient_columns("antiderivative()", "antiderivative_plan()"),
    rows,
    metadata = serde_json::json!({ "id": "antiderivative" })
);
let lengths = vec![
    ("Maximum output Plan degree", output_degree),
    ("Output length", by_plan.len()),
    ("Scratch length", scratch.len()),
];
emit_table_with_columns!(
    count_columns(),
    lengths,
    metadata = serde_json::json!({ "id": "lengths" })
);
```

`antiderivative()` returns 4 coefficients independently of $N$, matching the closed form.
Prepared antiderivatives return $N+2$ coefficients with zeros at $k\ge4$.
Output Plan degree is $N+1$; scratch length equals output length $N+2$.

## Summary

Orthogonal expansions can be differentiated and integrated in the same basis through family-specific three-term relations in $O(n)$, without monomial conversion.
Physical derivatives multiply by $1/s$ and integrals by $s$; specify center and scale and check units.
Specify integration constants at physical anchor $F(\mathrm{anchor})=\mathrm{value}$; `integral` is an unweighted definite integral.
Polynomial calculus lengths follow expansion length, while operators and prepared antiderivatives follow maximum Plan degree; pad operator inputs to matching lengths.
Reuse `OrthogonalDerivative` and `OrthogonalAntiderivative` for repeated calculus, querying scratch lengths from each requirement.
