This table covers exact-coefficient operations, Plans for repeated coefficient operations, and multivariate representations.
The caller supplies exact coefficient types implementing `ExactCoefficient` (`ExactField` for division).
The contract requires exact equality, addition, subtraction, and multiplication (division only for `ExactField`).
SciOxide implements these for no types, so floating-point types cannot be passed to exact operations.
The caller's coefficient type determines time and memory for coefficient operations and cloning.

## Product trees and multipoint evaluation

Floating-point product and remainder trees are not provided.
Use `ExactPolynomialProductTree` above for exact-coefficient multipoint evaluation and interpolation.
For approximate multipoint values, use `ApproxPolynomial::evaluate_batch` or `evaluate_batch_into` evaluating each point sequentially; interpolate samples with barycentric `ApproxPolynomial::interpolate_barycentric`.

## Summary

Use `ExactPolynomial` and `ExactRationalFunction` when coefficients must be exact, including exact-coefficient functions and types for resultants and partial fractions.
For repeated floating-point products or composition, retain `PolynomialOperationPlan` with shapes declared by `PolynomialOperationRequest` and a workspace, reading returned `PolynomialProductAlgorithm` and condition estimates.
Repeat exact products, composition, and Taylor shifts through Plan-free `exact_*_into` with `ExactPolynomialWorkspace` sized to the largest output.
Use `ExactPolynomialProductTree` for exact multipoint operations; use pointwise evaluation and barycentric interpolation for approximate values.
For multiple variables, specify monomial order and substitution term limits, and treat Bernstein ranges as estimates including rounding.
