For complex Newton iteration, the converged root depends on the initial value.
Initial values converging to the same root form its basin of attraction.
Convergence is quadratic sufficiently near simple roots, but is not guaranteed from distant points.
Basins of cubic polynomial $z^3-1$ are a classical problem posed by Cayley in 1879.
This page follows Newton iteration for $z^3-1$ from one point, identifying its basin through trajectory, backward error, and analytical-root distances.
A full grid colored by basin appears in [rootfind's complex roots](../../../scioxide-rootfind/algorithms/complex-roots/).

## Newton map and roots

The three roots of $p(z)=z^3-1$ are cube roots of unity spaced by $2\pi/3$ on the unit circle,

$$
r_0=1,\qquad r_1=e^{2\pi i/3}=-\frac12+\frac{\sqrt3}2i,\qquad r_2=e^{4\pi i/3}=-\frac12-\frac{\sqrt3}2i
$$


Since the derivative is $p'(z)=3z^2$, Newton map $N:\mathbb C\setminus\{0\}\to\mathbb C$ is the rational function

$$
N(z)=z-\frac{p(z)}{p'(z)}=z-\frac{z^3-1}{3z^2}=\frac{2z^3+1}{3z^2}
$$


Iteration is $z_{k+1}=N(z_k)$.
Setting $\omega=e^{2\pi i/3}$ gives $N(\omega z)=\omega N(z)$ and $N(\bar z)=\overline{N(z)}$, so the three basins map into one another by $2\pi/3$ rotations and reflection across the real axis.

### Quadratic convergence near roots

Every root is a fixed point satisfying $N(r_j)=r_j$; from

$$
N'(z)=\frac{6z^2\cdot3z^2-(2z^3+1)\cdot6z}{9z^4}=\frac{2(z^3-1)}{3z^3}
$$

we obtain $N'(r_j)=0$.
The fixed-point derivative vanishes, so nearby error $e_k=z_k-r_j$ decreases quadratically as

$$
e_{k+1}\approx\frac{p''(r_j)}{2p'(r_j)}e_k^2=\frac{e_k^2}{r_j}
$$

where $p''/(2p')=1/z$.
Since $|r_j|=1$, ratio $|e_{k+1}|/|e_k|^2$ approaches 1.
This roughly doubles correct digits per iteration.

### Derivative zeros and basin boundaries

Newton correction $p(z_k)/p'(z_k)$ is undefined where $p'(z)=0$, namely at the origin.
Near the origin, a small denominator sends iterates far away.
Far away, $N(z)\approx2z/3$, so displaced points return toward the origin with geometric ratio $2/3$.
All three basin boundaries are the same set (this map's Julia set), which also contains the origin.
Every neighborhood of a boundary point contains points from all three basins.
Thus tiny changes in initial values near boundaries can change the eventual root.
Boundary points themselves do not converge to any root.

## Iteration trajectories and backward error

`checked_basis_evaluation` returns a value, first and second derivatives, and componentwise backward error

$$
\eta(z)=\frac{|p(z)|}{\sum_k|a_k||z|^k}=\frac{|z^3-1|}{1+|z|^3}
$$

(`normalized_residual`) in one Horner pass.
Backward error $\eta(z)$ means a relative coefficient perturbation of $\eta$ makes $z$ an exact root.
At distant points, $\eta\approx1$, so $z$ is not a root of any nearby polynomial.
Near simple roots, forward error is indicated by conditioning times backward error, $|e|\approx\kappa\,\eta$.
Here $\kappa$ is absolute condition number $\sum_k|a_k||z|^k/|p'(z)|$ returned by `root_condition`; roots of $z^3-1$ have $\kappa=2/|3r_j^2|=2/3$.

`newton_correction` returns quotient $p(z)/p'(z)$, or `None` when $p'(z)=0$.
If either $p$ or $p'$ exceeds binary64 range, form the quotient in extended exponent range before projecting back to binary64.
Use `roundoff_limited` for stopping.
It becomes true when backward error is at most evaluation roundoff allowance $\gamma_{32}=32\varepsilon/(1-32\varepsilon)\approx7.1\times10^{-15}$, indicating that further iteration cannot improve $z$.
32 counts 8 real roundings per complex Horner stage for 4 coefficients; $\varepsilon=2^{-52}$ is machine epsilon.
The allowance estimates rounding and is not a root enclosure.
Backward error and roundoff allowances are derived in [Rounding error and diagnostics for Horner evaluation](oxref:poly-checked-evaluation-backward-error).

The following definitions block provides the model shared by two cells.
`COEFFICIENTS` gives ascending-power coefficients of $p(z)=z^3-1$, `cube_roots` the analytical roots $r_0,r_1,r_2$, and `nearest_root` nearest-root index and distance.
The three roots are independent references, unused by iteration.

```rust
//| id: poly-complex-newton-model
//| kind: definitions
//| title: "Coefficients and three analytical roots of z³ − 1"
//| crates: [scioxide-core]
use scioxide_core::{Complex, RealScalar};

/// Ascending-power coefficients of p(z) = z³ − 1.
pub(crate) const COEFFICIENTS: [f64; 4] = [-1.0, 0.0, 0.0, 1.0];

/// Analytical roots r₀ = 1, r₁ = e^{2πi/3}, r₂ = e^{4πi/3}.
pub(crate) fn cube_roots() -> [Complex<f64>; 3] {
    let half_root_three = RealScalar::sqrt(3.0_f64) / 2.0;
    [
        Complex::new(1.0, 0.0),
        Complex::new(-0.5, half_root_three),
        Complex::new(-0.5, -half_root_three),
    ]
}

/// Nearest analytical-root index and distance.
pub(crate) fn nearest_root(z: Complex<f64>) -> (usize, f64) {
    cube_roots()
        .iter()
        .map(|&root| (z - root).norm())
        .enumerate()
        .fold((0, f64::INFINITY), |best, item| {
            if item.1 < best.1 { item } else { best }
        })
}
```

The next cell iterates from polar initial point $(|z_0|,\theta_0)$, tabulating points, backward errors, distance $e_k$ to the nearest analytical root, and ratio $e_{k+1}/e_k^2$.
Rows with next distance $e_{k+1}$ below $10^{-13}$ are strongly affected by rounding and leave the ratio blank.
Inputs are initial angle [deg], initial radius (dimensionless), and update limit [count].
Independent checks are endpoint distance to analytical roots, ratio $e_{k+1}/e_k^2\to1$, and $e_k\approx\tfrac23\eta(z_k)$.
The final outcome reports the stopping reason.
Stopping by `roundoff_limited` gives `satisfied`, by the update limit `partial`, and at a point with $p'(z)=0$ gives `failed`.
Pass the trajectory to the next cell for plotting.

```rust
//| id: poly-complex-newton
//| ref: poly-complex-newton
//| title: "Following complex Newton trajectories for z^3−1"
//| run: reactive
//| uses: [poly-complex-newton-model]
//| crates: [scioxide-core, scioxide-poly]
//| exports: [trajectory]
//| inputs:
//|   initial_angle_deg: {"type":"range","label":"Initial angle θ₀ [deg]","description":"Change the starting direction and examine the root reached.","min":0,"max":360,"step":5,"value":55}
//|   initial_radius: {"type":"range","label":"Initial radius |z₀| [-]","description":"Change distance from the zero-derivative origin or from distant points.","min":0.1,"max":2,"step":0.1,"value":0.8}
//|   iteration_limit: {"type":"range","label":"Update limit [count]","description":"Change allowed updates for long trajectories near boundaries.","min":8,"max":40,"step":1,"value":24}
//| cases:
//|   - {"id":"small-radius","label":"|z₀| = 0.1","description":"Starting near the origin sends the trajectory far away before convergence to r₂.","inputs":{"initial_radius":0.1}}
//|   - {"id":"large-radius","label":"|z₀| = 2","description":"At the same angle, radius 2 converges to r₁.","inputs":{"initial_radius":2}}
//|   - {"id":"short-limit","label":"Limit of 8 updates","description":"Truncates before backward error reaches roundoff allowance, giving partial.","inputs":{"iteration_limit":8}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"iterations","path":"/rows/2/1","approx":{"value":12.497492723727037,"rtol":1e-6}}
//|       - {"artifact":"iterations","path":"/rows/14/5","approx":{"value":1.0,"atol":1e-3}}
//|       - {"artifact":"iterations","path":"/rows/16/4","range":{"max":1e-15}}
//|       - {"path":"/outputs/1/state","equals":"satisfied"}
//|   - case: small-radius
//|     expect:
//|       - {"artifact":"iterations","path":"/rows/14/2","approx":{"value":-0.8660254037844386,"atol":1e-12}}
//|       - {"path":"/outputs/1/state","equals":"satisfied"}
//|   - case: large-radius
//|     expect:
//|       - {"artifact":"iterations","path":"/rows/10/2","approx":{"value":0.8660254037844386,"atol":1e-12}}
//|       - {"path":"/outputs/1/state","equals":"satisfied"}
//|   - case: short-limit
//|     expect:
//|       - {"artifact":"iterations","path":"/rows/8/3","approx":{"value":0.9209752733086967,"rtol":1e-6}}
//|       - {"path":"/outputs/1/state","equals":"partial"}
use scioxide_core::Complex;
use scioxide_poly::{PolynomialRootBasisRef, checked_basis_evaluation};
use std::f64::consts::PI;

let limit = iteration_limit.round() as usize;
let mut point = Complex::from_polar(initial_radius, initial_angle_deg * PI / 180.0);
// (k, Re z_k, Im z_k, η(z_k), |z_k − r|)
let mut rows: Vec<(usize, f64, f64, f64, f64)> = Vec::new();
// Stopping reasons: backward error within roundoff allowance, update limit, zero derivative
let stop = loop {
    let evaluation =
        checked_basis_evaluation(&COEFFICIENTS, point, PolynomialRootBasisRef::Monomial)
            .map_err(|e| e.to_string())?;
    let k = rows.len();
    rows.push((
        k,
        point.re,
        point.im,
        evaluation.normalized_residual(),
        nearest_root(point).1,
    ));
    if evaluation.roundoff_limited() {
        break "Reached rounding level";
    }
    if k == limit {
        break "Update limit";
    }
    // Form p/p′ in extended exponent range, then project. None when p′(z) = 0.
    let Some(correction) = evaluation.newton_correction().map_err(|e| e.to_string())? else {
        break "Zero derivative";
    };
    point = point - correction;
};
let updates = rows.len() - 1;
let (root_index, distance) = nearest_root(point);

// Quadratic-convergence check: e_{k+1}/e_k² approaches |1/r| = 1. Exclude rows whose next error is near rounding level.
let table: Vec<_> = rows
    .iter()
    .enumerate()
    .map(|(k, &(_, re, im, eta, e))| {
        let ratio = rows
            .get(k + 1)
            .filter(|next| next.4 >= 1e-13)
            .map(|next| next.4 / (e * e));
        (k, re, im, eta, e, ratio)
    })
    .collect();
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let fixed6 = serde_json::json!({ "fractionDigits": 6 });
let fixed3 = serde_json::json!({ "fractionDigits": 3 });
let columns = serde_json::json!([
    { "key": "0", "label": "Iteration k [count]", "type": "integer" },
    { "key": "1", "label": "Re z_k [-]", "type": "number", "format": fixed6 },
    { "key": "2", "label": "Im z_k [-]", "type": "number", "format": fixed6 },
    { "key": "3", "label": "Backward error η(z_k) [-]", "type": "number", "format": sci3 },
    { "key": "4", "label": "Nearest-root distance e_k [-]", "type": "number", "format": sci3 },
    { "key": "5", "label": "e_(k+1)/e_k² [-]", "type": "number", "format": fixed3, "nullText": "—" }
]);
emit_table_with_columns!(
    columns,
    table,
    metadata = serde_json::json!({ "id": "iterations" })
);
let trajectory: Vec<[f64; 2]> = rows.iter().map(|row| [row.1, row.2]).collect();
export!(trajectory, &trajectory);

let outcome = match stop {
    "Reached rounding level" => Outcome::satisfied(format!(
        "Backward error reached roundoff allowance and root r{root_index} was reached"
    )),
    "Update limit" => {
        Outcome::partial("Stopped at the update limit before backward error reached roundoff allowance")
            .explanation("The final point is intermediate; do not assign the nearest root as its convergence destination.")
    }
    _ => Outcome::failed("Reached p′(z) = 0; Newton correction is undefined"),
};
emit_outcome!(
    outcome
        .status(stop)
        .diagnostic("Updates", updates as f64, None)
        .diagnostic("Backward error η", rows[updates].3, None)
        .diagnostic("Nearest-root distance", distance, None)
);
```

### Reading the results

With defaults $\theta_0=55^\circ$ and $|z_0|=0.8$, the first update moves to $(0.13,-0.05)$ near the origin (a zero of $p'$), and the second jumps to $(12.5,12.3)$.
Following $N(z)\approx2z/3$, it returns toward the origin and converges to root $r_0$ in 16 updates.
Distant iterates have backward error near 1 and are not meaningful root candidates.

Backward errors just before convergence are $1.9\times10^{-3}\to2.5\times10^{-6}\to4.3\times10^{-12}\to5.5\times10^{-24}$, with exponents nearly doubling.
Ratio $e_{k+1}/e_k^2$ approaches 1 through $0.96\to0.9992\to1.000004$, matching quadratic-convergence coefficient $1/|r_0|=1$.
Each distance $e_k$ closely matches $\tfrac23\eta(z_k)$ ($1.30\times10^{-3}$ versus $\tfrac23\times1.95\times10^{-3}$ at $k=13$).
Final backward error lies far below allowance $7.1\times10^{-15}$ because the iterate has form $1+3.7\times10^{-24}i$, allowing direct evaluation of $|p(z)|\approx3|\mathrm{Im}\,z|$.
The real part rounds to 1, so $e_{16}$ measures only imaginary error.
Ratio $e_{16}/e_{15}^2\approx0.46$ does not represent the convergence coefficient, so the $k=15$ row leaves it blank.

Radius 0.1 jumps to $(-11.4,-31.3)$ on the first update and converges to $r_2$ in 14; radius 2 converges to $r_1$ in 10.
At the same angle, three radii lead to three roots, so this ray crosses basin boundaries at least twice.
Starting toward a root, such as angle $0^\circ$, follows the real axis and converges to $r_0=1$ in 5 updates.
At angle $60^\circ$ and radius 0.5, $z_0^3=-1/8$, so $N(z_0)=r_2$, converging in one update.

An 8-update limit truncates before backward error meets its allowance, giving outcome `partial`.
The final point has backward error 0.92 and nearest-root distance 0.99 and must not be treated as a root approximation.
`newton_correction` returns `None` only at $z=0$ where $p'(z)=3z^2$ is exactly 0 (binary64-underflowing evaluation retries with extended exponents, so even small $z$ does not become 0).
The initial-value grid excludes points giving $N(z_0)=0$ ($2z_0^3=-1$, radius $2^{-1/3}\approx0.794$), so `failed` is unlikely in the default input range.
General polynomial iteration should nevertheless handle $p'(z)=0$ as a separate termination status.

## Summary

Newton destinations depend on initial values; trajectories near the zero-derivative origin may jump far away, return at geometric ratio $2/3$, then head to another root.
Near roots, quadratic convergence makes ratio $e_{k+1}/e_k^2$ approach $1/|r_j|$ and backward-error exponents nearly double.
Stop through `roundoff_limited`, comparing backward error with roundoff allowance $\gamma_{32}$ and ending further iteration.
Treat reaching roundoff level, update-limit truncation, and zero derivatives as separate statuses; do not assign truncated points to their nearest root.
This is a finite trajectory from one initial value, neither a full basin diagram nor a convergence proof.
