In receptor–ligand binding, receptor occupancy approaches 1 as ligand concentration increases.
This response is a ratio of linear expressions; multiplying numerator and denominator by the same factor preserves the function except at that factor's zeros.
Distinguish exact from merely nearby common factors, examining cancellation criteria through `ApproxRationalFunction::simplify` and resulting function-value changes.
Approximate-GCD algorithms and reports are defined in [Polynomial GCDs and approximate GCDs](../../algorithms/approximate-gcd/).

## Mass action and rational saturation models

Consider one-to-one reversible binding equilibrium between receptor $R$ and ligand $L$.

$$
R + L \underset{k_{\text{off}}}{\overset{k_{\text{on}}}{\rightleftharpoons}} RL
$$

Let binding rate constant be $k_{\text{on}}$ (concentration⁻¹·time⁻¹) and dissociation rate constant $k_{\text{off}}$ (time⁻¹).
At equilibrium, forward and reverse rates agree, giving $k_{\text{on}}[R][L] = k_{\text{off}}[RL]$.
Define dissociation constant $K_d = k_{\text{off}} / k_{\text{on}} = [R][L]/[RL]$ (concentration units, such as nM).
Let total receptor concentration be $[R]_{\text{tot}} = [R] + [RL]$.
When ligand greatly exceeds receptor and binding depletion is negligible, free ligand concentration $[L]$ is treated as constant and fractional receptor occupancy is

$$
\theta = \frac{[RL]}{[R]_{\text{tot}}} = \frac{[RL]}{[R] + [RL]} = \frac{[L]/K_d}{1 + [L]/K_d}
$$

Dimensionless concentration $x = [L] / K_d$ gives the standard rational saturation function.

$$
\theta(x) = \frac{x}{1 + x} \quad (x \ge 0)
$$

This is also the Langmuir adsorption isotherm and a Hill-coefficient-1 binding curve.
It responds linearly as $\theta(x) \approx x$ for $x \ll 1$, reaches $\theta(1) = 0.5$ at half-saturation concentration $x = 1$ ($[L] = K_d$), and approaches 1 as $x \to \infty$.
Remaining saturation deficit $1 - \theta(x) = 1/(1 + x)$ decreases only as $O(1/x)$; a visually horizontal curve is not fully saturated.
90% occupancy needs $x = 9$; 99% needs $x = 99$.
The same form appears in Michaelis–Menten enzyme kinetics $v/V_{\max} = c/(K_m + c)$.

## Common factors and removable singularities

Combining models or identifying parameters can introduce the same linear factor $(x - r)$ in numerator and denominator.

$$
\theta_{\text{raw}}(x) = \frac{x(x - r)}{(x + 1)(x - r)} = \frac{x^2 - rx}{x^2 + (1 - r)x - r}
$$

Algebraically cancelling $(x - r)$ gives reduced expression $\theta(x) = x/(x + 1)$, but the functions differ as follows.

1. Removable singularity: unreduced $\theta_{\text{raw}}$ becomes $0/0$ at $x = r$ and cannot be evaluated there.
   The reduced expression returns finite $r/(r+1)$ at $x = r$ ($r \ne -1$).
2. Pole: $x = -1$ has zero denominator and nonzero numerator, with unbounded value magnitude.
   It lies outside physical domain $x \ge 0$, but sets Taylor convergence radius for $\theta(x) = x - x^2 + x^3 - \cdots$ at the origin to 1, its distance to the nearest pole.

`ApproxRationalFunction::new` only makes the denominator monic and scales the numerator by the same leading coefficient, without automatic cancellation.
Calling `evaluate` on the unreduced expression at $x = r$ returns `DomainError` because the denominator is 0.
Cancellation occurs on calling `simplify`.
`simplify` computes approximate GCD $g$, using quotients of numerator and denominator divided by $g$ as new numerator and denominator.
The normalized remainder divides maximum absolute remainder coefficient by maximum absolute original numerator (or denominator) coefficient.
Cancellation is accepted only if both normalized remainders are at most the policy tolerance $\varepsilon_{\rm abs}/\max_i|a_i| + \varepsilon_{\rm rel}$.
The default policy has $\varepsilon_{\rm abs} = \varepsilon_{\rm rel} = \sqrt{\varepsilon} \approx 1.5 \times 10^{-8}$.

The following definitions block is shared by three cells.
`rational_from_roots` constructs $\prod_i(x-a_i)/\prod_j(x-b_j)$ from numerator and denominator roots through `ApproxPolynomial::from_roots_with_options` and `ApproxRationalFunction::new` without cancelling common factors.
`coefficient_pair` and `from_coefficient_pair` transfer rational functions between cells as numerator/denominator coefficient pairs.
`compare` evaluates original and reduced expressions at each $x$ through `evaluate`, returning $(x, \text{original value}, \text{reduced value})$.

```rust
//| id: poly-rational-saturation-model
//| kind: definitions
//| title: "Rational functions from roots and comparisons before and after cancellation"
//| crates: [scioxide-poly]
use scioxide_poly::{
    ApproxPolynomial, ApproxRationalFunction, PolynomialApproximationPolicy, PolynomialBasis,
};

/// Construct ∏(x − aᵢ) / ∏(x − bⱼ) without cancelling common factors.
pub(crate) fn rational_from_roots(
    numerator_roots: &[f64],
    denominator_roots: &[f64],
    policy: PolynomialApproximationPolicy<f64>,
) -> Result<ApproxRationalFunction<f64>, String> {
    let numerator = ApproxPolynomial::from_roots_with_options(numerator_roots, policy)
        .map_err(|e| e.to_string())?;
    let denominator = ApproxPolynomial::from_roots_with_options(denominator_roots, policy)
        .map_err(|e| e.to_string())?;
    ApproxRationalFunction::new(numerator, denominator).map_err(|e| e.to_string())
}

/// Ascending numerator/denominator coefficient pair for transferring rational functions between cells.
pub(crate) fn coefficient_pair(rational: &ApproxRationalFunction<f64>) -> [Vec<f64>; 2] {
    [
        rational.numerator().basis().coefficients().to_vec(),
        rational.denominator().basis().coefficients().to_vec(),
    ]
}

/// Reconstruct a rational function from its coefficient pair.
pub(crate) fn from_coefficient_pair(
    [numerator, denominator]: [Vec<f64>; 2],
) -> Result<ApproxRationalFunction<f64>, String> {
    let numerator = ApproxPolynomial::monomial(numerator).map_err(|e| e.to_string())?;
    let denominator = ApproxPolynomial::monomial(denominator).map_err(|e| e.to_string())?;
    ApproxRationalFunction::new(numerator, denominator).map_err(|e| e.to_string())
}

/// (x, original value, cancelled value) at each x.
pub(crate) fn compare(
    original: &ApproxRationalFunction<f64>,
    reduced: &ApproxRationalFunction<f64>,
    points: impl IntoIterator<Item = f64>,
) -> Result<Vec<(f64, f64, f64)>, String> {
    points
        .into_iter()
        .map(|x| {
            let before = original.evaluate(x).map_err(|e| e.to_string())?;
            let after = reduced.evaluate(x).map_err(|e| e.to_string())?;
            Ok((x, before, after))
        })
        .collect()
}
```

## Cancelling exact common factors

The next cell constructs $\theta_{\text{raw}}$ for $r < 0$ outside the physical domain and cancels using default-policy `simplify`.
The input is common-factor root $r$.
The first table shows approximate GCD degree, Sylvester reciprocal conditioning, and relative rank threshold.
The second shows numerator and denominator degrees and coefficients after cancellation alongside $[0, 1]$ and $[1, 1]$, the coefficients of $x/(x+1)$.
The independent check compares coefficients after cancellation with coefficients of $x/(x+1)$.
Pass original and cancelled expressions to the next cell to compare physical-domain values.

```rust
//| id: poly-rational-saturation
//| ref: poly-rational-saturation
//| title: "Cancelling a rational saturation response with diagnostics"
//| run: reactive
//| uses: [poly-rational-saturation-model]
//| crates: [scioxide-poly]
//| exports: [original, reduced]
//| inputs:
//|   removable_root: {"type":"range","label":"Common-factor root r [-]","description":"Move the removable singularity outside the physical domain.","min":-6,"max":-0.5,"step":0.5,"value":-2}
//| cases:
//|   - {"id":"double-pole","label":"r = −1","description":"Denominator becomes (x + 1)²; cancelling one factor leaves pole x = −1.","inputs":{"removable_root":-1}}
//|   - {"id":"rounded-factor","label":"r = −1.5","description":"Cancelled coefficients retain rounding-level errors.","inputs":{"removable_root":-1.5}}

//|   - case: default
//|     expect:

//|     expect:
//|       - {"artifact":"parts","path":"/rows/1/2","equals":1}

//|       - {"artifact":"summary","path":"/rows/0/0","equals":1}

};

// Construct numerator x(x − r) and denominator (x + 1)(x − r) with default policy
let r = removable_root;
let policy = PolynomialApproximationPolicy::default();

// Compute approximate GCD and cancel common factor (x − r)
let simplification = model.simplify().map_err(|e| e.to_string())?;
let simplified = simplification.rational();
let report = simplification.gcd_report();
// Relative rank threshold τ/σ_max (None for zero inputs, which build no Sylvester matrix)
let threshold = report
    .sylvester_rank()
    .map(|rank| rank.threshold() / rank.scale());
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let exact = serde_json::json!({ "significantDigits": 17 });
let summary_columns = serde_json::json!([
    { "key": "0", "label": "Approximate GCD degree", "type": "integer" },
    { "key": "1", "label": "Reciprocal condition number [-]", "type": "number", "format": sci3, "nullText": "None" },
    { "key": "2", "label": "Threshold τ/σ_max [-]", "type": "number", "format": sci3, "nullText": "None" }
]);
emit_table_with_columns!(
    summary_columns,
    vec![(
        report.effective_degree(),
        report.reciprocal_condition(),
        threshold
    )],
    metadata = serde_json::json!({ "id": "summary" })
);
// Degrees by part, cancelled ascending coefficients, and normalized remainders
type Monomial = ApproxPolynomial<f64, MonomialBasis<f64>>;
let part = |name: &'static str, before: &Monomial, after: &Monomial, error: f64| {
    let coefficients = after.basis().coefficients();
    let linear = coefficients.get(1).copied();
    (
        name,
        before.degree(),
        after.degree(),
        coefficients[0],
        linear,
        error,
    )
};
let parts_columns = serde_json::json!([
    { "key": "0", "label": "Part" },
    { "key": "1", "label": "Original degree", "type": "integer" },
    { "key": "2", "label": "Cancelled degree", "type": "integer" },
    { "key": "3", "label": "Cancelled constant coefficient [-]", "type": "number", "format": exact },
    { "key": "4", "label": "Cancelled linear coefficient [-]", "type": "number", "format": exact, "nullText": "None" },
    { "key": "5", "label": "Normalized remainder [-]", "type": "number", "format": sci3 }
]);
let numerator_error = simplification.numerator_error();
let denominator_error = simplification.denominator_error();
emit_table_with_columns!(
    parts_columns,
    vec![
        part(
            "Numerator",
            model.numerator(),
            simplified.numerator(),
            numerator_error
        ),
        part(
            "Denominator",
            model.denominator(),
            simplified.denominator(),
            denominator_error
        ),
    ],
    metadata = serde_json::json!({ "id": "parts" })
);
export!(original, &coefficient_pair(&model));
export!(reduced, &coefficient_pair(simplified));
```

At default $r = -2$, approximate GCD degree is 1; numerator and denominator both drop from degree 2 to 1, with coefficients exactly $[0, 1]$ and $[1, 1]$.
Degree stays 1 across 12 values of $r$ from $-6$ to $-0.5$ in steps of 0.5.
The Sylvester matrix's reciprocal condition number ranges from $1.8 \times 10^{-18}$ ($r = -5.5$) to $5.8 \times 10^{-17}$ ($r = -1.5$).
This is below relative threshold $\tau = 4\varepsilon \approx 8.9 \times 10^{-16}$ of default rank policy `DimensionScaledEpsilon` (4 is Sylvester order).
Normalized remainders are 0 in 10 of 12 cases.
At $r = -1.5$, normalized numerator remainder is $2.2 \times 10^{-16}$ and coefficients after cancellation are $[2.2 \times 10^{-16}, 1]$ and $[1 + 2.2 \times 10^{-16}, 1]$.
At $r = -4$, normalized remainders are $8.9 \times 10^{-16}$ for numerator and $5.3 \times 10^{-16}$ for denominator.
All are at rounding level; final digits may vary natively.
Even exactly divisible common factors can have rounding-level approximate-GCD errors because factors come from singular vectors and least-squares refinement.
At $r = -1$, denominator $(x+1)^2$ retains pole $x = -1$ after cancelling one common factor $(x+1)$.

## Simplifying nearby common factors

Numerator $x(x+2)$ and denominator $(x+1)(x+2+\delta)$ have no common factor for $\delta \ne 0$.
This models coefficients of a removable-singularity model perturbed by $\delta$ through measurement or identification errors.
Nevertheless, if rank threshold $\tau$ in policy `PolynomialApproximationPolicy` exceeds the Sylvester matrix's reciprocal condition number, approximate GCD selects degree-1 factor $x + c$ ($c \approx 2$).
Precisely, equilibrated Sylvester singular values at most $\tau\,\sigma_{\max}$ are treated as zero, and their count becomes GCD degree.
`simplify` accepts cancellation only if normalized remainders from dividing each input by $x + c$ are within relative tolerance; otherwise `NumericalInstability` (`IllConditioned`).
On acceptance, the simplified function differs from the original.
The remainder theorem (remainder $p(-c)$ from $p(x)$ divided by $x + c$) and synthetic division give closed forms in $c$ for the simplified function and two normalized remainders.

$$
\frac{x + 2 - c}{x + 3 + \delta - c}, \qquad
\frac{|c^2 - 2c|}{2}, \qquad
\frac{|c^2 - (3+\delta)c + 2 + \delta|}{3 + \delta}
$$

Denominators 2 and $3 + \delta$ are maximum absolute numerator and denominator coefficients.
$c$ lies between 2 and $2 + \delta$, so simplified origin value $(2 - c)/(3 + \delta - c)$ is a negative value on the scale of $-\delta$.
Simplification removes original exact zero $x = 0$ (occupancy 0).

Inputs to the next cell are $p$ in perturbation $\delta = 2^{-p}$, $q_r$ in rank threshold $\tau = 2^{-q_r}$, and $q_t$ in relative tolerance $2^{-q_t}$.
Absolute tolerance is 0.
Obtain an approximate-GCD report separately through `approximate_gcd`, showing degree and remainders even if simplification is rejected.
The first table shows the reciprocal condition number, rank threshold, selected degree, and GCD constant coefficient $c$.
The second compares normalized numerator/denominator remainders with remainder-theorem values from $c$ and tolerance.
If accepted, the third table compares original and simplified values at five physical concentrations and checks simplified values against the closed form above.

```rust
//| id: poly-rational-near-cancellation
//| ref: poly-rational-near-cancellation
//| title: "Simplifying nearby factors and changes in function values"
//| run: reactive
//| uses: [poly-rational-saturation-model]
//| crates: [scioxide-core, scioxide-linalg, scioxide-poly]
//| inputs:
//|   exponent: {"type":"range","label":"p in perturbation δ=2⁻ᵖ","min":12,"max":40,"step":2,"value":30}
//|   rank_power: {"type":"range","label":"q_r in rank threshold 2^(−q_r)","description":"Reciprocal conditioning at most this value sets common-factor degree to 1.","min":10,"max":50,"step":2,"value":20}
//|   tolerance_power: {"type":"range","label":"q_t in tolerance 2^(−q_t)","description":"Normalized remainders at most this value permit cancellation.","min":10,"max":50,"step":2,"value":20}
//| cases:
//|   - {"id":"large-perturbation","label":"p = 12","description":"Reciprocal conditioning exceeds rank threshold, selecting a constant GCD.","inputs":{"exponent":12}}
//|   - {"id":"strict-tolerance","label":"q_t = 40","description":"Degree 1 is selected, but excessive remainders reject simplification.","inputs":{"tolerance_power":40}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"gcd","path":"/rows/0/3","equals":1}
//|       - {"artifact":"gcd","path":"/rows/0/4","approx":{"value":2,"atol":1e-8}}
//|       - {"artifact":"residuals","path":"/rows/0/1","approx":{"value":1.86e-10,"rtol":0.02}}
//|       - {"artifact":"values","path":"/rows/0/4","approx":{"value":-1.86e-10,"rtol":0.02}}
//|       - {"artifact":"values","path":"/rows/2/3","approx":{"value":0.5,"atol":1e-9}}
//|   - case: large-perturbation
//|     expect:
//|       - {"artifact":"gcd","path":"/rows/0/3","equals":0}
//|       - {"artifact":"values","path":"/rows/0/4","approx":{"value":0,"atol":1e-15}}
//|   - case: strict-tolerance
//|     expect:
//|       - {"artifact":"gcd","path":"/rows/0/3","equals":1}
//|       - {"artifact":"residuals","path":"/rows/1/1","range":{"min":9.1e-13}}
use scioxide_core::{RankThreshold, RealScalar, Tolerance};
use scioxide_linalg::RankPolicy;
use scioxide_poly::{PolynomialApproximationPolicy, PolynomialBasis, approximate_gcd};

let delta = RealScalar::powi(2.0_f64, -(exponent as i32));
let rank_threshold = RealScalar::powi(2.0_f64, -(rank_power as i32));
let tolerance = RealScalar::powi(2.0_f64, -(tolerance_power as i32));
let policy = PolynomialApproximationPolicy::new(
    Tolerance::new(0.0, tolerance).map_err(|e| e.to_string())?,
    RankPolicy::Threshold(RankThreshold::new(0.0, rank_threshold).map_err(|e| e.to_string())?),
);
// Numerator x(x + 2), denominator (x + 1)(x + 2 + δ)
let rational = rational_from_roots(&[0.0, -2.0], &[-1.0, -2.0 - delta], policy)?;
let gcd =
    approximate_gcd(rational.numerator(), rational.denominator()).map_err(|e| e.to_string())?;
let report = gcd.report();
// For degree 1, GCD = x + c; c is undefined for degree 0
let c = match gcd.polynomial().basis().coefficients() {
    [constant, _] => Some(*constant),
    _ => None,
};
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let c16 = serde_json::json!({ "significantDigits": 16 });
let gcd_columns = serde_json::json!([
    { "key": "0", "label": "Perturbation δ [-]", "type": "number", "format": sci3 },
    { "key": "1", "label": "Reciprocal condition number [-]", "type": "number", "format": sci3, "nullText": "None" },
    { "key": "2", "label": "Rank threshold τ [-]", "type": "number", "format": sci3 },
    { "key": "3", "label": "Approximate GCD degree", "type": "integer" },
    { "key": "4", "label": "GCD constant coefficient c [-]", "type": "number", "format": c16, "nullText": "None" }
]);
let degree = report.effective_degree();
emit_table_with_columns!(
    gcd_columns,
    vec![(
        delta,
        report.reciprocal_condition(),
        rank_threshold,
        degree,
        c
    )],
    metadata = serde_json::json!({ "id": "gcd" })
);
// Independent check: remainder-theorem normalized remainder |p(−c)|/max|p_i| (degree 1 only)
let predicted = [
    c.map(|c| (c * c - 2.0 * c).abs() / 2.0),
    c.map(|c| (c * c - (3.0 + delta) * c + 2.0 + delta).abs() / (3.0 + delta)),
];
let [numerator_error, denominator_error] = report.operand_errors();
let residual_columns = serde_json::json!([
    { "key": "0", "label": "Part" },
    { "key": "1", "label": "Normalized remainder [-]", "type": "number", "format": sci3 },
    { "key": "2", "label": "Remainder-theorem value [-]", "type": "number", "format": sci3, "nullText": "None" },
    { "key": "3", "label": "Relative tolerance [-]", "type": "number", "format": sci3 }
]);
emit_table_with_columns!(
    residual_columns,
    vec![
        ("Numerator", numerator_error, predicted[0], tolerance),
        ("Denominator", denominator_error, predicted[1], tolerance),
    ],
    metadata = serde_json::json!({ "id": "residuals" })
);
// Independent check: simplified closed form from c by synthetic division (unchanged original for degree 0)
let closed = |x: f64| match c {
    Some(c) => (x + 2.0 - c) / (x + 3.0 + delta - c),
    None => x * (x + 2.0) / ((x + 1.0) * (x + 2.0 + delta)),
};
let fixed2 = serde_json::json!({ "fractionDigits": 2 });
let value = serde_json::json!({ "significantDigits": 12 });
let value_columns = serde_json::json!([
    { "key": "0", "label": "Concentration x [-]", "type": "number", "format": fixed2 },
    { "key": "1", "label": "Original value [-]", "type": "number", "format": value },
    { "key": "2", "label": "Simplified value [-]", "type": "number", "format": value },
    { "key": "3", "label": "Simplified closed form [-]", "type": "number", "format": value },
    { "key": "4", "label": "Change from simplification [-]", "type": "number", "format": sci3 }
]);
// Compare original and simplified values at five concentrations only if simplification is accepted
match rational.simplify() {
    Ok(simplified) => {
        let points = [0.0, 0.25, 1.0, 4.0, 16.0];
        let rows: Vec<_> = compare(&rational, simplified.rational(), points)?
            .into_iter()
            .map(|(x, before, after)| (x, before, after, closed(x), after - before))
            .collect();
        emit_table_with_columns!(
            value_columns,
            rows,
            metadata = serde_json::json!({ "id": "values" })
        );
    }
    Err(error) => emit_text!(&format!(
        "Simplification rejected: {:?}, {:?}",
        error.kind(),
        error.view()
    )),
}
```

With defaults $p = 30$ ($\delta \approx 9.3 \times 10^{-10}$) and $q_r = q_t = 20$, the reciprocal condition number $2.2 \times 10^{-11}$ is below rank threshold $9.5 \times 10^{-7}$, selecting degree 1.
Normalized remainders $1.9 \times 10^{-10}$ and $2.5 \times 10^{-10}$ are also at most the tolerance $9.5 \times 10^{-7}$, accepting cancellation.
For every $p$, the reciprocal condition number is about $0.023\,\delta$; GCD constant $c \approx 2 + 0.2\,\delta$ lies between nearby roots $-2$ and $-2-\delta$ toward $-2$.
Normalized report remainders match remainder-theorem values to at least 9 significant digits; simplified values match the $c$ closed form to displayed digits.
Simplification changes values most at $x = 0$, by $-1.9 \times 10^{-10}$, decreasing with concentration to $-3.5 \times 10^{-12}$ at $x = 16$.
Negative origin occupancy means the simplified model loses the original zero property.

Setting $p = 12$ makes the reciprocal condition number $5.7 \times 10^{-6}$ exceed rank threshold; degree 0 (constant GCD) is selected, leaving the expression unchanged after simplification.
Setting $q_t = 40$ still selects degree 1, but normalized remainders exceed tolerance $9.1 \times 10^{-13}$ and `simplify` returns `NumericalInstability` (`IllConditioned`).
Thus rank policy determines common-factor degree and tolerance determines cancellation acceptance; they are separate policy components.
`DomainError` from `evaluate`, detecting poles from denominator values and estimated evaluation errors, is a separate condition from both.
Even a nearly unchanged simplified curve is an approximation under selected tolerances, not proof distinguishing true poles from removable singularities.

## Summary

Receptor occupancy $\theta(x) = x/(1+x)$ ($x = [L]/K_d$) is rational; common numerator/denominator factors are cancelled only on calling `simplify`.
Exact common factors give physical-domain agreement to rounding accuracy; cancelling merely nearby factors changes the function and removes the origin zero in this example.
Common-factor degree compares Sylvester reciprocal conditioning with rank threshold; acceptance compares normalized remainders with tolerance.
Read both report values before using simplified expressions.
Match rank thresholds and tolerances to coefficient errors (measurement, identification, rounding), without exceeding their magnitude.
Check value changes over the intended domain and preservation of model properties such as zeros and poles after simplification.
