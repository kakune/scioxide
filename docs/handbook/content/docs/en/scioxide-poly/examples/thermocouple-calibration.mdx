Thermocouple measurements require forward calibration from temperature to EMF and inverse calibration from measured EMF to temperature.
The calibration derivative connects them.
Use the NIST Type T thermocouple reference function (copper and copper–nickel alloy), rather than illustrative coefficients.
Check evaluation, differentiation, orthogonal integration, and matrices with roots as eigenvalues independently against NIST tables and approximate inverses.

## Reference sources and domain

Use the degree-8 polynomial over 0–400 °C from Table 9.3.1 of [NIST Monograph 175](https://doi.org/10.6028/NIST.MONO.175) (Burns et al., 1993).
The same coefficients appear in millivolts in the [NIST ITS-90 thermocouple database](https://its90.nist.gov/) (SRD 60).
Table 9.3.1 uses microvolts and ITS-90 Celsius temperature $t_{90}$, with reference junction 0 °C.
Coefficients and outputs below use the same units, denoting temperature by $T$.
The domain is 0–400 °C; negative temperatures (−270–0 °C) require a separate degree-14 polynomial.

$$
E(T)=\sum_{k=0}^8c_kT^k\quad[\mu\mathrm V],\qquad T\in[0,400]\quad[{}^\circ\mathrm C].
$$

| $k$ | Numerical $c_k$ (units $\mu\mathrm V/({}^\circ\mathrm C)^k$) |
|---|---|
| 0 | 0 |
| 1 | $3.8748106364\times10^1$ |
| 2 | $3.3292227880\times10^{-2}$ |
| 3 | $2.0618243404\times10^{-4}$ |
| 4 | $-2.1882256846\times10^{-6}$ |
| 5 | $1.0996880928\times10^{-8}$ |
| 6 | $-3.0815758772\times10^{-11}$ |
| 7 | $4.5479135290\times10^{-14}$ |
| 8 | $-2.7512901673\times10^{-17}$ |

Table 9.3.3 of the same Monograph lists computed EMF $E$ to 0.1 µV and Seebeck coefficient $S=dE/dT$ to 0.001 µV/°C at every 1 °C.
Table A9.1 approximates temperature as a degree-6 voltage polynomial, differing from the reference function by −0.03 to 0.03 °C over 0–400 °C.
These three tables provide independent checks.

Correct coefficient arithmetic does not imply that an individual thermocouple matches the reference function.
Material variation, reference junctions, and instrument correction are separate issues.
Only voltage uncertainty is considered here, not certification of overall measurement calibration.

The following block provides definitions shared by three cells.
`TYPE_T_COEFFICIENTS` corresponds to Table 9.3.1 coefficients $c_0, \dots, c_8$ in ascending powers; `reference_function` to monomial $E(T)$.

```rust
//| id: poly-thermocouple-model
//| kind: definitions
//| title: "Type T reference function (0–400 °C)"
//| crates: [scioxide-core, scioxide-poly]
use scioxide_core::SciOxideError;
use scioxide_poly::{ApproxPolynomial, MonomialBasis};

/// NIST Monograph 175 Table 9.3.1 coefficients c₀, …, c₈ (0–400 °C). E in µV, T in °C.
pub(crate) const TYPE_T_COEFFICIENTS: [f64; 9] = [
    0.0,
    3.8748106364e1,
    3.3292227880e-2,
    2.0618243404e-4,
    -2.1882256846e-6,
    1.0996880928e-8,
    -3.0815758772e-11,
    4.5479135290e-14,
    -2.7512901673e-17,
];

/// Monomial-basis polynomial.
pub(crate) type Calibration = ApproxPolynomial<f64, MonomialBasis<f64>>;

/// Monomial reference function E(T) [µV].
pub(crate) fn reference_function() -> Result<Calibration, SciOxideError> {
    ApproxPolynomial::monomial(TYPE_T_COEFFICIENTS.to_vec())
}
```

## Sensitivity and voltage uncertainty

Seebeck coefficient $S(T)=dE/dT$ has units $\mu\mathrm V/{}^\circ\mathrm C$.
Over 0–400 °C, $S$ increases from $38.748$ to $61.805$ µV/°C.
Table 9.3.3 $dS/dT$ stays positive from 66.58 nV/°C² at 0 °C to 18.40 nV/°C² at 400 °C; thus $S$ increases monotonically and $E$ is strictly increasing and invertible.
Small voltage variations correspond to $\Delta T\approx\Delta E/S(T)$.
Considering only voltage standard uncertainty $u_E$, first-order propagation gives

$$
u_T\approx\frac{u_E}{|S(T)|}
$$


This estimates standard uncertainty through linear propagation, not a finite-error enclosure or confidence interval.
Small $S$ requires reassessment of linearization and inverse conditioning.

Cells construct calibration with `ApproxPolynomial::monomial` and a newly owned sensitivity polynomial with `derivative`.
Monomial `derivative` merely rearranges coefficients $k c_k$, with one multiplication rounding per coefficient.
Read both polynomial values through `evaluate` (Horner).

## Checking EMF and sensitivity

Inputs are observation temperature $T$ and voltage standard uncertainty $u_E$.
The first table compares EMF and sensitivity at 0, 100, 200, 300, and 400 °C with Table 9.3.3.
Rounded reference values agree when EMF discrepancies lie within ±0.05 µV and sensitivity discrepancies within ±0.0005 µV/°C.
The second table shows observation-point EMF, sensitivity, and first-order $u_T$.
Calibration and sensitivity plots have linked temperature axes; vertical lines mark the selected temperature.

Across five points, maximum EMF discrepancy is 0.030 µV (400 °C) and sensitivity discrepancy 0.0003 µV/°C (300 °C), both within table rounding widths.
At default 200 °C, $S = 53.150$ µV/°C makes $u_E = 1$ µV correspond to $u_T = 0.0188$ °C.

Changing temperature changes sensitivity; the same $u_E=1$ µV gives $u_T$ decreasing from 0.0258 °C at 0 °C to 0.0162 °C at 400 °C.

## Inverse calibration and root conditioning

Recover temperature from measured EMF $E_{\rm meas}$ by finding the root of $E(T)-E_{\rm meas}=0$ in $[0,400]$.
Subtract a constant polynomial with `try_sub`, convert through `to_orthogonal` to Legendre centered at 200 with scale 200, then construct a matrix with roots as eigenvalues through `root_matrix` (a recurrence-based comrade matrix in this basis).
The monomial companion matrix has coefficient ratios $c_k/c_8$ as entries, with magnitudes spanning up to about $10^{18}$.
Mapping temperature to $t=(T-200)/200\in[-1,1]$ gives comparable expansion coefficient magnitudes.
scioxide-linalg computes matrix eigenvalues with nonsymmetric solver `GeneralEigenvaluesResult::compute` (balancing, Hessenberg reduction, Francis QR).
Comrade eigenvalues use physical coordinate $T$; substitute candidates with real parts in $[0, 400]$ into the original expression to check residuals.
Monotonic $E$ has one real root in the interval, corresponding to the candidate with smallest imaginary part.

Root accuracy is indicated by absolute condition number

$$
\kappa(T^*) = \frac{\sum_k |a_k|\,|T^*|^k}{|p'(T^*)|}
$$

(Higham, *Accuracy and Stability of Numerical Algorithms*, 2002, §5.1).
Here $p(T) = E(T) - E_{\rm meas}$, $a_k$ are its monomial coefficients, and $p'(T^*) = S(T^*)$.
Relative coefficient perturbations $\eta$ move the root by at most first-order $\kappa\,\eta$ [°C].
`ApproxPolynomial::root_condition` returns this quantity.
Table 9.3.1 has 11 significant coefficient digits; choosing $\eta = 5 \times 10^{-11}$ estimates coefficient-rounding effects on inverse temperature.

Independently compare with approximate inverse $T_{\rm A9.1}(E)=\sum_{i=1}^6d_iE^i$ in Table A9.1.
Coefficients $d_i$ convert SRD 60 millivolt values to microvolts and match Table A9.1.

The input is measured EMF $E_{\rm meas}$, restricted inside reference range 0–20871.97 µV.
The table shows eigenvalue-based inverse temperature, selected imaginary part, voltage residual, root conditioning, estimated coefficient-rounding shift $\kappa\,\eta$, approximate inverse temperature, and their discrepancy.

```rust
//| id: poly-thermocouple-inverse
//| ref: poly-thermocouple-inverse
//| title: "Inverse calibration using a polynomial root matrix versus NIST's approximate inverse"
//| run: reactive
//| uses: [poly-thermocouple-model]
//| crates: [scioxide-core, scioxide-linalg, scioxide-poly]
//| inputs:
//|   measured_voltage: {"type":"range","label":"Measured EMF E_meas [µV]","min":0,"max":20800,"step":100,"value":9300}
//| cases:
//|   - {"id":"low-voltage","label":"E_meas = 400 µV","description":"Approximate inverse error is near the ±0.03 °C limit.","inputs":{"measured_voltage":400}}
//|   - {"id":"high-voltage","label":"E_meas = 20800 µV","description":"Near the upper domain endpoint 400 °C.","inputs":{"measured_voltage":20800}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"inverse","path":"/rows/0/0","approx":{"value":200.223831132723,"rtol":1e-12}}
//|       - {"artifact":"inverse","path":"/rows/0/2","range":{"min":-1e-9,"max":1e-9}}
//|       - {"artifact":"inverse","path":"/rows/0/6","range":{"min":-0.03,"max":0.03}}
//|   - case: low-voltage
//|     expect:
//|       - {"artifact":"inverse","path":"/rows/0/0","approx":{"value":10.2280948171119,"rtol":1e-11}}
//|       - {"artifact":"inverse","path":"/rows/0/6","range":{"min":-0.03,"max":0.03}}
//|   - case: high-voltage
//|     expect:
//|       - {"artifact":"inverse","path":"/rows/0/0","approx":{"value":398.835321823694,"rtol":1e-12}}
//|       - {"artifact":"inverse","path":"/rows/0/6","range":{"min":-0.03,"max":0.03}}
use scioxide_linalg::GeneralEigenvaluesResult;
use scioxide_poly::{
    ApproxPolynomial, BasisNormalization, OrthogonalBasisSpec, OrthogonalFamily,
};

let calibration = reference_function().map_err(|e| e.to_string())?;
// Represent p(T) = E(T) − E_meas in Legendre form mapping [0, 400] °C to t = (T − 200)/200 ∈ [−1, 1]
let spec = OrthogonalBasisSpec::new(
    OrthogonalFamily::Legendre,
    BasisNormalization::Classical,
    200.0_f64,
    200.0,
)
.map_err(|e| e.to_string())?;
let target = ApproxPolynomial::monomial(vec![measured_voltage]).map_err(|e| e.to_string())?;
let equation = calibration.try_sub(&target).map_err(|e| e.to_string())?;
let converted = equation.to_orthogonal(spec).map_err(|e| e.to_string())?;
let matrix = converted
    .polynomial()
    .root_matrix()
    .map_err(|e| e.to_string())?;
let roots = GeneralEigenvaluesResult::compute(&matrix).map_err(|e| e.to_string())?;
// Among candidates with in-range real parts (allowing 1e-6 °C for eigenvalue rounding), select smallest imaginary part
let root = roots
    .eigenvalues()
    .iter()
    .filter(|z| z.re >= -1e-6 && z.re <= 400.0 + 1e-6)
    .min_by(|a, b| a.im.abs().total_cmp(&b.im.abs()))
    .ok_or("No inverse candidate in the domain")?;
let inverse = root.re;
let residual = equation.evaluate(inverse).map_err(|e| e.to_string())?;
// Absolute root conditioning for monomial coefficients: Σ|a_k||T|^k / |p′(T)|
let condition = equation
    .root_condition(inverse)
    .map_err(|e| e.to_string())?
    .absolute()
    .value();
// Independent check: Table A9.1 inverse approximation (E in µV, 0–400 °C, error ±0.03 °C)
let approximate_inverse = ApproxPolynomial::monomial(vec![
    0.0_f64,
    2.592800e-2,
    -7.602961e-7,
    4.637791e-11,
    -2.165394e-15,
    6.048144e-20,
    -7.293422e-25,
])
.map_err(|e| e.to_string())?;
let nist = approximate_inverse
    .evaluate(measured_voltage)
    .map_err(|e| e.to_string())?;
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let fixed4 = serde_json::json!({ "fractionDigits": 4 });
let columns = serde_json::json!([
    { "key": "0", "label": "Inverse temperature [°C]", "type": "number", "format": { "fractionDigits": 10 } },
    { "key": "1", "label": "Eigenvalue imaginary part [°C]", "type": "number", "format": sci3 },
    { "key": "2", "label": "Residual E(T) − E_meas [µV]", "type": "number", "format": sci3 },
    { "key": "3", "label": "Absolute root conditioning κ [°C]", "type": "number", "format": sci3, "nullText": "None" },
    { "key": "4", "label": "κ × 5e-11 [°C]", "type": "number", "format": sci3, "nullText": "None" },
    { "key": "5", "label": "Table A9.1 temperature [°C]", "type": "number", "format": fixed4 },
    { "key": "6", "label": "Table A9.1 − inverse temperature [°C]", "type": "number", "format": fixed4 }
]);
emit_table_with_columns!(
    columns,
    vec![(
        inverse,
        root.im,
        residual,
        condition,
        condition.map(|kappa| kappa * 5e-11),
        nist,
        nist - inverse
    )],
    metadata = serde_json::json!({ "id": "inverse" })
);
```

At default $E_{\rm meas}=9300$ µV, inverse temperature is 200.2238311327 °C and the chosen eigenvalue is real.
A separate 50-digit decimal Newton root, 200.22383113272314… °C, differs by $1.1\times10^{-13}$ °C; recovered voltage residual is $5.5\times10^{-12}$ µV.
Absolute conditioning is $\kappa \approx 560$ °C; machine epsilon $\varepsilon \approx 2.2\times10^{-16}$ times it gives $\kappa\varepsilon \approx 1.2 \times 10^{-13}$ °C, of the same order as actual error.
Estimated coefficient-rounding shift $\kappa\eta \approx 2.8\times10^{-8}$ °C is also far below magnitudes relevant to thermocouple measurement.
The approximate inverse differs by −0.0096 °C, within Table A9.1's ±0.03 °C.

At $E_{\rm meas} = 400$ µV the discrepancy is 0.024 °C; at 20800 µV it is −0.020 °C.
Checking 100–20800 µV in 100 µV increments with the same decimal arithmetic gives maximum absolute discrepancy 0.025 °C at 500 µV, every point within ±0.03 °C.
The eigenvalue inverse and independent approximation agree within the approximation's stated error.
Conditioning increases with temperature, reaching $\kappa \approx 7.1 \times 10^{3}$ °C at 20800 µV.
$\sum_k|a_k||T|^k$ grows with high-order terms while denominator sensitivity $S$ changes only 1.6-fold over 0–400 °C.

## Interval mean and independent checks

For a uniform temperature sweep from 0 to $T_{\max}$, mean EMF is

$$
\overline E=\frac1{T_{\max}}\int_0^{T_{\max}}E(T)\,dT
$$


This is uniform in temperature, not an average over arbitrary temporal or spatial distributions.
Monomial `ApproxPolynomial::integral` evaluates a termwise antiderivative by Horner, the same computation as manually written termwise integration.
For a separate path, convert to Legendre and compute through `integral`.
Orthogonal `integral` forms antiderivative coefficients in that expansion and evaluates through Clenshaw recurrence.
The independent check is termwise integral $\sum_k c_kT_{\max}^{k}/(k+1)$; $T_{\max}^k$ uses f64 `powi` as a reference.

The input is upper averaging temperature $T_{\max}$.
The table shows mean EMF and termwise-integral discrepancies.

```rust
//| id: poly-thermocouple-average
//| ref: poly-thermocouple-average
//| title: "Mean EMF over temperature from Legendre integration"
//| run: reactive
//| uses: [poly-thermocouple-model]
//| crates: [scioxide-core, scioxide-poly]
//| inputs:
//|   upper_temperature: {"type":"range","label":"Upper averaging temperature T_max [°C]","min":50,"max":400,"step":50,"value":400}
//| cases:
//|   - {"id":"short-range","label":"T_max = 50 °C","description":"On a short interval, the mean differs by 3% from the linear-term-only value.","inputs":{"upper_temperature":50}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"average","path":"/rows/0/1","approx":{"value":9667.49773081383,"rtol":1e-12}}
//|       - {"artifact":"average","path":"/rows/0/2","range":{"min":-1e-9,"max":1e-9}}
//|   - case: short-range
//|     expect:
//|       - {"artifact":"average","path":"/rows/0/1","approx":{"value":1000.66239223867,"rtol":1e-12}}
//|       - {"artifact":"average","path":"/rows/0/2","range":{"min":-1e-9,"max":1e-9}}
use scioxide_poly::{BasisNormalization, OrthogonalBasisSpec, OrthogonalFamily};

let calibration = reference_function().map_err(|e| e.to_string())?;
// Legendre expansion mapping [0, 400] °C to t = (T − 200)/200 ∈ [−1, 1]
let spec = OrthogonalBasisSpec::new(
    OrthogonalFamily::Legendre,
    BasisNormalization::Classical,
    200.0_f64,
    200.0,
)
.map_err(|e| e.to_string())?;
let expansion = calibration.to_orthogonal(spec).map_err(|e| e.to_string())?;
let average = expansion
    .polynomial()
    .integral(0.0, upper_temperature)
    .map_err(|e| e.to_string())?
    / upper_temperature;
// Independent check: termwise Σ c_k T_max^k / (k + 1) (reference f64 powi)
let reference_average = TYPE_T_COEFFICIENTS
    .iter()
    .enumerate()
    .map(|(k, &c)| c * upper_temperature.powi(k as i32) / (k + 1) as f64)
    .sum::<f64>();
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let columns = serde_json::json!([
    { "key": "0", "label": "Upper temperature T_max [°C]", "type": "number", "format": { "fractionDigits": 0 } },
    { "key": "1", "label": "Mean EMF [µV]", "type": "number", "format": { "fractionDigits": 6 } },
    { "key": "2", "label": "Termwise-integral discrepancy [µV]", "type": "number", "format": sci3 }
]);
emit_table_with_columns!(
    columns,
    vec![(upper_temperature, average, average - reference_average)],
    metadata = serde_json::json!({ "id": "average" })
);
```

Mean EMF is 9667.4977 µV at $T_{\max}=400$ °C and 1000.6624 µV at $T_{\max}=50$ °C, both differing from termwise integration by at most $4\times10^{-12}$ µV.
The mean at $T_{\max}=50$ °C exceeds linear-only value $c_1T_{\max}/2 = 968.70$ µV by 3.3%, retaining higher-order contributions.
Agreement of basis integration and termwise integration is a numerical check, not an assessment of material or instrument uncertainty.

## Summary

Use calibration with consistent sources, units, reference junctions, and domain, first checking rounded reference-table agreement.
The derivative gives local inverse sensitivity, converting voltage uncertainty to temperature through $u_T\approx u_E/S$.
Substitute inverse eigenvalue candidates into the original formula and inspect temperature discrepancy, voltage residual, and root conditioning separately.
Definite integrals correspond to specified temperature distributions; explicitly convert monomials to orthogonal expansions for an independent path from termwise integration here.
