Probability laws in `scioxide-random` implement sampling, density, CDF, quantiles, moments, and other capabilities as separate traits.
There is no default implementation filling in a law's missing capabilities through numerical integration or similar methods.
This page explains capability-trait conventions, subtraction-free tails, numerical inversion of quantiles without closed forms, and types that combine laws.
Sampling from densities not built in is covered in [Sampling from user densities](../user-density-sampling/), multivariate laws in [Probability laws for multivariate values, matrices, and groups](../multivariate-and-matrix-laws/), and test-statistic laws in [Test-statistic laws and the finite-sample KS distribution](../test-statistic-laws/).
Batch-generation and workspace conventions are in [Mathematics of random numbers, distributions, and sampling designs](../).

## Capability traits

| Trait | Computed quantity | Convention |
|---|---|---|
| `Distribution`, `CountDistribution` | Samples | Continuous samples use floating-point values on `Rng`; count samples use full-width uniform words |
| `Density`, `LogDensity` | $f(x)$, $\ln f(x)$ | Outside support: 0 (logarithm $-\infty$), without error. Endpoint values depend on the law (`Uniform` is half-open; divergent endpoints give $+\infty$) |
| `Mass`, `LogMass` | $P(X = k)$ | Exact integer $k$ (`usize` or `i64`) |
| `Cdf`, `LogCdf` | $F(x) = P(X \le x)$ | Counts include the atom at $k$, without continuity correction |
| `Survival`, `LogSurvival` | $S(x) = P(X > x)$ | Computed directly without forming $1 - F$ |
| `Quantile` | $\inf\{x : F(x) \ge p\}$ | Left endpoint of a flat interval of $F$. $p = 0, 1$ gives support endpoints (possibly infinite). Continuous laws using numerical inversion evaluate the smaller tail |
| `InverseSurvival` | Point satisfying $S(x) = p$ | Does not form $1 - p$. Right endpoint of a flat interval |
| `Mean`, `Variance`, `Entropy` | Mean, variance, entropy (nats) | Implemented only with a law-specific formula or evaluation method. Nonexistent values give `DomainError` with reason `Undefined`. Successful variance for a nondegenerate scalar law is positive; cancellation or underflow to 0, or failure to achieve tolerance, gives an error rather than 0 |
| `Support`, `CountSupport`, `SignedCountSupport` | Support closure, integer support endpoints | `contains` returns exact membership of finite points |

Capability availability can depend on either type or parameters.
`Cauchy` does not implement `Mean`, so code requesting its mean does not compile.
`StudentT::new(1.0)` implements `Mean`, but `mean()` returns `DomainError` at runtime.
For integer laws, $Q(1)$ cannot be represented unless support is bounded above, giving `NotImplemented`.
Law queries reject NaN and infinite coordinates as `NonFinite`.
However, `log_interval_probability` accepts $\pm\infty$ as interval endpoints.

## Tail and interval probabilities

When upper-tail probability $S(x)$ is small, $1 - F(x)$ loses information through rounding.
For a normal distribution at $x = 40$, $1 - F$ rounds to 0, while `log_sf(40)` returns approximately $-804.6$.
`isf(p)` returns the point with $S(x) = p$ at relative accuracy even for probabilities such as $p = 10^{-300}$, where $1 - p$ rounds to 1.

`log_interval_probability(&law, a, b)` computes interval probability $\ln P(a < X \le b)$ for a continuous law.
It chooses the smaller pair among endpoint lower log-probabilities $\ln F$ and upper log-probabilities $\ln S$, differencing with $\ln(e^{u} - e^{v}) = u + \ln(1 - e^{v - u})$ to retain relative accuracy even when both CDF values round to 1.
It accepts infinite endpoints, returns $-\infty$ for an empty interval, and rejects NaN or endpoints with $a > b$ as `InvalidInput`.
At most three tail evaluations are used, subject to the default `LawOptions` work limit.
`log_interval_probability_with_options(&law, a, b, options)` uses the supplied `LawOptions` limits.
`log_interval_probability_scoped(&law, a, b, options, scope)` performs the calculation as a stage in the caller's execution scope (`ExecutionContext` or an outer solve's `SolveContext`), checking cancellation and deadlines before each tail evaluation and counting law work toward the outer solve's evaluations.

The following cell finds the standard normal point with upper-tail probability $p = 10^{-e}$ using `isf` and compares its back-transformed value from `log_sf` and an alternative `scioxide_special::erfc` path $\ln\bigl(\operatorname{erfc}(x/\sqrt{2})/2\bigr)$ against $\ln p$.
It also shows whether `quantile` through $1 - p$ returns a finite value.
It then compares the log-probability of interval $(a, a + 1]$ using `log_interval_probability` and CDF subtraction and finds median $m$ of the law `Truncated::new(normal, a, a + 1.0)` truncated to that interval.
To check the median, it computes conditional CDF $\bigl(\operatorname{erfc}(a/\sqrt{2}) - \operatorname{erfc}(m/\sqrt{2})\bigr)/\bigl(\operatorname{erfc}(a/\sqrt{2}) - \operatorname{erfc}((a+1)/\sqrt{2})\bigr)$ using `erfc` and reports its difference from 0.5.

```rust
//| id: random-direct-tail-inversion
//| ref: random-direct-tail-inversion
//| title: "Invert tiny upper-tail probabilities and find a truncated law's median"
//| run: reactive
//| crates: [scioxide-random, scioxide-core, scioxide-special]
//| inputs:
//|   tail_exponent: {"type":"range","label":"Upper-tail exponent e (p = 10⁻ᵉ)","min":2,"max":300,"step":2,"value":100}
//|   lower: {"type":"range","label":"Lower truncation endpoint a","description":"The probability of interval (a, a + 1] is about 4.9 × 10⁻¹⁹⁸ at a = 30.","min":0,"max":30,"step":1,"value":10}
//| cases:
//|   - {"id":"moderate-tail","label":"e = 2, a = 0","description":"For e ≤ 16, 1 − p does not round to 1, so quantile(1 − p) is also finite; at a = 0, CDF subtraction also works.","inputs":{"tail_exponent":2,"lower":0}}
//|   - {"id":"extreme","label":"e = 300, a = 30","description":"p = 10⁻³⁰⁰ and an interval of probability about 4.9 × 10⁻¹⁹⁸.","inputs":{"tail_exponent":300,"lower":30}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"inversion","path":"/rows/0/0","approx":{"value":21.2734535610,"atol":1e-8}}
//|       - {"artifact":"inversion","path":"/rows/0/3","equals":false}
//|       - {"artifact":"interval","path":"/rows/0/0","approx":{"value":-53.231310,"atol":1e-5}}
//|       - {"artifact":"interval","path":"/rows/0/2","equals":0}
//|       - {"artifact":"interval","path":"/rows/0/3","approx":{"value":10.0684093695,"atol":1e-8}}
//|       - {"artifact":"interval","path":"/rows/0/4","range":{"min":-1e-8,"max":1e-8}}
//|   - case: moderate-tail
//|     expect:
//|       - {"artifact":"inversion","path":"/rows/0/3","equals":true}
//|       - {"artifact":"interval","path":"/rows/0/2","range":{"min":0.34,"max":0.35}}
//|   - case: extreme
//|     expect:
//|       - {"artifact":"inversion","path":"/rows/0/0","approx":{"value":37.0470962994,"atol":1e-8}}
//|       - {"artifact":"interval","path":"/rows/0/3","approx":{"value":30.0230704678,"atol":1e-8}}
//|       - {"artifact":"interval","path":"/rows/0/4","range":{"min":-1e-8,"max":1e-8}}
use scioxide_core::RealScalar;
use scioxide_random::{
    Cdf, InverseSurvival, LogSurvival, Normal, Quantile, Truncated, log_interval_probability,
};

let fixed10 = serde_json::json!({ "fractionDigits": 10 });
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let sig8 = serde_json::json!({ "significantDigits": 8 });
let erfc =
    |x: f64| scioxide_special::erfc(x / std::f64::consts::SQRT_2).map_err(|e| e.to_string());
let normal = Normal::new(0.0_f64, 1.0).map_err(|e| e.to_string())?;
let log_p = -tail_exponent * std::f64::consts::LN_10;
let p = RealScalar::exp(log_p); // Normal number for e ≤ 300
// Invert the upper tail directly, then recover ln p through log_sf and an independent erfc path.
let x = normal.isf(p).map_err(|e| e.to_string())?;
let recovered = normal.log_sf(x).map_err(|e| e.to_string())?;
let by_erfc = RealScalar::ln(erfc(x)? / 2.0);
// Comparison: binary64 1 − p rounds to 1 for p ≤ 2⁻⁵⁴, so quantile returns +∞.
let via_complement = normal.quantile(1.0 - p).map_err(|e| e.to_string())?;
let columns = serde_json::json!([
    { "key": "0", "label": "isf(p)", "type": "number", "format": fixed10 },
    { "key": "1", "label": "log_sf(isf(p)) − ln p", "type": "number", "format": sci2 },
    { "key": "2", "label": "erfc path − ln p", "type": "number", "format": sci2 },
    { "key": "3", "label": "quantile(1 − p) is finite", "type": "boolean" }
]);
emit_table_with_columns!(
    columns,
    vec![(
        x,
        recovered - log_p,
        by_erfc - log_p,
        RealScalar::is_finite(via_complement)
    )],
    metadata = serde_json::json!({ "id": "inversion" })
);
// Probability of interval (a, a+1]: logarithmic evaluation versus CDF subtraction.
let (a, b) = (lower, lower + 1.0);
let log_mass = log_interval_probability(&normal, a, b).map_err(|e| e.to_string())?;
let by_hand = RealScalar::ln((erfc(a)? - erfc(b)?) / 2.0);
let difference =
    normal.cdf(b).map_err(|e| e.to_string())? - normal.cdf(a).map_err(|e| e.to_string())?;
// Law truncated to the interval. Inversion on the smaller tail finds the median even for large a.
let conditional = Truncated::new(normal.clone(), a, b).map_err(|e| e.to_string())?;
let median = conditional.quantile(0.5).map_err(|e| e.to_string())?;
let half = (erfc(a)? - erfc(median)?) / (erfc(a)? - erfc(b)?) - 0.5;
let columns = serde_json::json!([
    { "key": "0", "label": "ln P(a < X ≤ a+1)", "type": "number", "format": sig8 },
    { "key": "1", "label": "Difference from erfc path", "type": "number", "format": sci2 },
    { "key": "2", "label": "cdf(a+1) − cdf(a)", "type": "number", "format": sig8 },
    { "key": "3", "label": "Median m", "type": "number", "format": fixed10 },
    { "key": "4", "label": "F(m) − 0.5 via erfc", "type": "number", "format": sci2 }
]);
emit_table_with_columns!(
    columns,
    vec![(log_mass, log_mass - by_hand, difference, median, half)],
    metadata = serde_json::json!({ "id": "interval" })
);
```

With the defaults ($e = 100$, $a = 10$), `isf(p)` is $21.2734535610$; the value recovered by `log_sf` differs from $\ln p$ by $-2.8 \times 10^{-14}$, and the difference from the `erfc` path is 0.
In binary64, $1 - p$ rounds to 1 for $p \le 2^{-54} \approx 5.6 \times 10^{-17}$, so `quantile(1 − p)` is finite at $e \le 16$ and becomes $+\infty$ at $e \ge 18$.
CDF subtraction gives probability 0 for interval $(10, 11]$, but `log_interval_probability` returns $-53.231310$ (about $7.6 \times 10^{-24}$), differing from the `erfc` path by $-7.1 \times 10^{-15}$.
The truncated median is $10.0684093695$; the conditional CDF computed by `erfc` differs from 0.5 by $1.3 \times 10^{-15}$.
Even at $e = 300$ and $a = 30$, `isf` is $37.0470963$, the interval log-probability is $-454.32$ (about $4.9 \times 10^{-198}$), and the median is $30.0230704678$, with conditional CDF differing from 0.5 by only $7.1 \times 10^{-14}$.

## LawOptions and numerical inversion

Laws without closed forms use accuracy and limits from `LawOptions` for queries, moments, and entropy calculations.
`new(parameters…)` constructs a law with default settings; `with_options(parameters…, options)` uses supplied settings.
The law's constructor validates settings and returns `InvalidInput` if relative tolerance lies outside $[64\varepsilon, 0.1)$.

| Setting | Default | Applies to |
|---|---|---|
| Tolerance `tolerance` | Absolute and relative both $\sqrt{\varepsilon} \approx 1.5 \times 10^{-8}$ | Positive-term sums and quadrature stop at relative tolerance. Probabilities may also stop at absolute tolerance |
| Work `work_budget` | 65,536 | One preparation, query, or moment calculation |
| Uniform words `sample_word_budget` | 65,536 | Uniform words requested by one sample of a law combining multiple stages |
| Storage `max_bytes` | 64 MiB | Each buffer allocated by the law |

Work counts recurrence updates, quadrature integrand evaluations, special-function iterations, and preparation stages as one unit each.
Root bracketing and bisection, nested integration, and component-law queries share one limit for the same operation.
Rejection and sequential search within a sample stop after 1,024 candidates for every law.
Reaching a work, uniform-word, or candidate limit returns `ConvergenceFailure`, never an approximation as success ([Rejection and work limits](oxref:random-algorithms-rejection-limits)).
Values stopped at tolerance are estimates, without a guaranteed error bound.
Calculations repeatedly evaluating CDFs, such as quantiles of `StudentizedRange`, two-sided KS, and generalized hyperbolic laws, may exceed default work; increase it with `with_work_budget`.

Laws without closed-form quantiles numerically invert log-probabilities.
`invert_log_probability(&law, ln p, upper)` is the public inversion function, accepting finite negative $\ln p$ and returning `InvalidInput` otherwise.
Its residual is only the sign $\pm 1$ of $\ln F(x) - \ln p$ (comparing $\ln S(x)$ with the target for `upper`); it brackets a root on the support, then shrinks the interval by bisection.
Using only signs avoids derivatives and allows termination on flat or noisy tails; no probability subtraction is used, so $\ln p$ may be smaller than the smallest representable floating-point probability.
On flat intervals, lower-tail inversion returns the left endpoint and upper-tail inversion the right.
Default `InversionOptions` uses 4,096 iterations, 65,536 work units (the default for one law operation; iterative laws can consume many units per tail evaluation), and absolute and relative interval-width tolerances of machine epsilon.
`invert_log_probability` returns only the upper endpoint of the final bisection interval; an unsuccessful root solve returns `ConvergenceFailure` carrying the termination reason (`ExecutionStopped` for cancellation or a deadline).
`invert_log_probability_with_options(&law, ln p, upper, &options)` takes settings and returns `InversionReport` containing value `value()`, root-solve result `root()`, and evaluation count `evaluations()`.
This version may return a report even after an unsuccessful root solve, so check `root().is_success()` before using `value()`.
Exhausting work or failing to find a finite bracket gives an error.
Like `log_interval_probability_scoped`, `invert_log_probability_scoped(&law, ln p, upper, &options, scope)` performs inversion as a stage in the caller's execution scope.

Many built-in laws without closed-form quantiles use the same bracketing and bisection within the work of `LawOptions`.
If $p > 1/2$, they form $\ln(1 - p)$ using `ln_1p` and invert the opposite tail, avoiding comparisons of large probabilities near $1 - p$.
For laws with smooth tails, the residual is a log-probability difference rather than a sign, also allowing termination when its magnitude falls within 1/8 of the relative tolerance.
An interior quantile rounding to a support endpoint gives `NumericalInstability`.
`LevyStable` uses Brent's method and noncentral distributions use safeguarded Newton iteration as law-specific inversion methods.

## Composed laws

| Type | Law | Capabilities and computation |
|---|---|---|
| `Affine::new(law, μ, σ)` | $\mu + \sigma X$ ($\sigma \ne 0$ finite) | Inherits only underlying capabilities; each operation evaluates the underlying law once. Negative $\sigma$ swaps upper and lower tails, and quantiles and `isf` |
| `Truncated::new(law, a, b)` | Conditional law $a < X \le b$ | Requires finite $a < b$ and nonzero interval probability (logarithmic representability suffices). Interval probability and tails are formed logarithmically from the underlying law's smaller tail. Quantiles, `isf`, and sampling require underlying `Quantile` and `InverseSurvival` |
| `OrderStatistic::new(law, rank, count)` | The `rank`th among `count` independent values (one-based) | Computes CDF $I_{F(x)}(k, n - k + 1)$ from the smaller tail; quantiles and samples numerically invert it, requiring no underlying sampler |
| `Mixture::new(components, &weights)` | Finite mixture | Evaluation sums component evaluations in $O(n)$. Sampling selects a component through Walker's alias table in $O(1)$ and uses that component's `Distribution`. No `Entropy` because it requires numerical integration. Components of different types can be borrowed through `&dyn ContinuousLaw` for evaluation only |
| `Transformed::abs(law)`, `exp(law)`, `log(law)` | $\lvert X \rvert$, $e^X$, $\ln X$ | Transforms density and tails; quantiles numerically invert tails, samples transform underlying samples. `log` returns `LogTransformed` using underlying `LogCoordinateLaw`. No moments or entropy |
| `Histogram::from_masses(edges, masses)`, `from_densities(edges, densities)` | Piecewise uniform law | Preparation takes $O(n)$ time and storage; density, tails, quantiles, and sampling use cumulative-mass binary search in $O(\log n)$. Mean, variance, and entropy take $O(n)$ |

`Truncated`, `OrderStatistic`, `Mixture`, and `Transformed` involve numerical computation and use default `LawOptions`; `with_options` (`abs_with_options`, `exp_with_options`, and `log_with_options` for `Transformed`) takes settings as the final argument.

`ContinuousLaw` is an object-safe trait combining the evaluation capabilities required by composed laws (`Density`, `LogDensity`, `Cdf`, `Survival`, `LogCdf`, `LogSurvival`, `Support`), implemented by all types with those capabilities.
The CDF of $Y = \ln X$ is $F_X(e^y)$ and its density $e^y f_X(e^y)$, but these formulas cannot be evaluated directly at points where $e^y$ rounds to 0, such as $y = -800$.
Therefore `Transformed::log` requires the underlying law to support `LogCoordinateLaw` evaluations of positive coordinates supplied in logarithmic form $y$ ($\ln F_X(e^y)$, $\ln S_X(e^y)$, and $y + \ln f_X(e^y)$ including the Jacobian).
`Exponential`, `Gamma`, `GeneralizedGamma`, `LogNormal`, `Histogram`, and results of `Transformed::exp` (marker `ExponentialTransform`) implement this; `ln(exp(X))` evaluates the underlying law directly.

## Summary

Laws implement capabilities trait by trait; nonexistent means and variances are distinguished by compile-time errors from missing implementations or runtime `DomainError`.
Handle small upper-tail probabilities without subtraction using `sf`, `log_sf`, `isf`, and `log_interval_probability`; `quantile` through `1 - p` is unusable at $p \le 2^{-54}$.
Numerical calculations for laws with `LawOptions` and for `invert_log_probability` stop at work limits, returning `ConvergenceFailure` when reached, so increase limits for laws repeatedly computing quantiles.
When reports are needed, use `invert_log_probability_with_options` and check the termination status of `root()` before using the value.
Truncation, order statistics, mixtures, transformations, and histograms inherit underlying capabilities, so check at the type level that the underlying law has the required capabilities before combining them.
