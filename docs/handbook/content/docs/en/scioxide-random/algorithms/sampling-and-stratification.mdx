When converting uniform words to finite-set indices or permutations, small mapping biases become systematic errors as trial counts grow.
When placing points in an interval, stratification reduces the clusters and gaps of independent uniform points.
This page explains index selection, permutation, and sampling-without-replacement algorithms in `scioxide-random` and the reduction in integration error from stratification.
Weighted sampling uses Walker–Vose aliases through `WeightedSampler`; its construction and complexity are in [Discrete distributions and count laws](oxref:random-discrete-alias-method).
Latin hypercubes, the multidimensional form of stratification, are covered in [Latin hypercube designs and discrepancy](../latin-hypercube-and-discrepancy/).

## Modulo bias and Lemire rejection

Forming an index on $\{0, \dots, n-1\}$ from a uniform $w$-bit word $W \in \{0, \dots, 2^w - 1\}$ as $W \bmod n$ biases probabilities when $2^w$ is not divisible by $n$.
This is because the $t = 2^w \bmod n$ smallest indices have $\lfloor 2^w/n \rfloor + 1$ preimages and the others $\lfloor 2^w/n \rfloor$.
For example, $w = 32$ and $n = 3 \cdot 2^{30}$ give $\lfloor 2^{32}/n \rfloor = 1$ and $t = 2^{30}$, making the $2^{30}$ smallest indices twice as probable as the others.

`uniform_index(n, rng)` removes this bias with Lemire's nearly divisionless rejection method.
Dividing product $W n$ by $2^w$ gives quotient $\lfloor W n / 2^w \rfloor$ as the index and remainder $\ell = W n \bmod 2^w$ for rejection testing.
There are $\lfloor 2^w/n \rfloor$ or one more words whose quotient is $k$.
Lemire showed that rejecting words with $\ell < t$ removes exactly one preimage from each overrepresented index.
Every accepted index has exactly $\lfloor 2^w/n \rfloor$ preimages, giving an exactly uniform result.

Rejection probability is $t / 2^w$, which is below $1/2$ by $t < n$ and $t \le 2^w - n$.
Computing remainder $t$ requires division, but since $t < n$, words satisfying $\ell \ge n$ can be accepted without computing $t$.
Division occurs only when $\ell < n$.
Products $W n$ are multiples of $n$, with exactly one in each interval $[q 2^w, q 2^w + n)$ of length $n$ ($q = 0, \dots, n-1$), so exactly $n$ words satisfy $\ell < n$.
Thus division occurs with probability $n / 2^w$.
For $n \le 2^{32}$, it uses 32-bit uniform words; for larger $n$, 64-bit words.

If all 1,024 attempted uniform words are rejected, it returns `ConvergenceFailure` (`IterationLimit`).
Since each rejection probability is below $1/2$, the chance of 1,024 consecutive rejections with a uniform generator is below $2^{-1024}$.
In practice this failure occurs when generator uniform words are not uniform (for example, repeated identical words).
A bound $n = 0$ gives `InvalidInput`.
Rejected words remain consumed; `uniform_index` does not rewind the generator.
Callers decide how to handle generator state after failure.

## Permutations and sampling without replacement

`shuffle(slice, rng)` uses Fisher–Yates (Durstenfeld): for positions $i = N-1, \dots, 1$ of a length-$N$ array from the end backward, choose $j$ from $\{0, \dots, i\}$ using `uniform_index` and exchange positions $i$ and $j$.
The element for position $i$ is uniform among the $i + 1$ elements whose positions remain undecided.
Thus each particular permutation has probability $\prod_{i=1}^{N-1} 1/(i+1) = 1/N!$, equal across all permutations.
There are $N - 1$ draws; `shuffle` neither allocates storage nor clones elements.
On failure, the generator remains advanced and the array retains its partially shuffled input.

`shuffle_in_place(slice, rng, policy, workspace)` makes the same draws under `SamplingPolicy`, producing the same permutation as `shuffle` on success.
Output policy follows [Batch sampling and state handling](oxref:random-algorithms-batches-and-state).
`Atomic` clones elements into workspace equal to the array length (0 below length 2), shuffles there, and swaps with the array only on success.
`Incremental` uses no workspace and leaves completed exchanges in the array on failure.
Generator handling follows the state policy in `policy`.

`choose(slice, rng)` selects one element uniformly; an empty array returns `Ok(None)` without consuming words.
`sample_indices(n, k, rng)` selects $k$ distinct indices from $\{0, \dots, n-1\}$ in an owned `Vec`, switching methods by sampling fraction.

| Condition | Method | Complexity | Order |
|---|---|---|---|
| $k \ge \lfloor n/16 \rfloor$ | Fisher–Yates only the first $k$ positions of an array containing $0, \dots, n-1$ | $O(n)$ time and storage | Uniform random ordered sample |
| $k < \lfloor n/16 \rfloor$ | Floyd's method with an open-addressed set of at most $4k$ slots | Expected $O(k)$ time and storage | Unspecified |

Partial Fisher–Yates exchanges position $i = 0, \dots, k-1$ with a uniform position in $\{i, \dots, n-1\}$ and discards the remaining positions.
If $k = n$, this is a uniform permutation of $0, \dots, n-1$.

For $j = n-k, \dots, n-1$, Floyd's method draws $t \in \{0, \dots, j\}$ uniformly and inserts $t$ if $t$ is absent, otherwise $j$.
After stage $j$, the set is a uniform size-$s = j - (n-k) + 1$ subset of $\{0, \dots, j\}$.
This follows by induction.
If a size-$s$ set $S$ contains $j$, it is obtained as $S$ when the preceding set is $S \setminus \{j\}$ and $t$ is any of $S$ ($s$ possibilities).
If it does not contain $j$, it is obtained as $S$ when, for some $x \in S$, the preceding set is $S \setminus \{x\}$ and $t = x$ ($s$ possibilities).
Every preceding set has probability $1/\binom{j}{s-1}$, so either case has probability $s / \bigl((j+1)\binom{j}{s-1}\bigr) = 1/\binom{j+1}{s}$.
The collision replacement $j$ first becomes a candidate at that stage, requiring exactly $k$ index draws.

Both methods allocate before the first draw; allocation failure returns `AllocationFailure` without consuming words.
$k > n$ gives `InvalidInput`; $k = 0$ returns an empty `Vec` without consuming words.
On failure, nothing is returned and the generator remains advanced by consumed words.

## Stratified-sampling variance

Estimate $I = \int_0^1 f(x)\,dx$ using the mean of $m$ samples.
Plain Monte Carlo estimator variance is $\sigma_f^2/m$ ($\sigma_f^2 = \mathrm{Var}\,f(U)$, where $U$ is uniform on $[0, 1)$).
Stratification divides $[0, 1)$ into $m$ equal strata $[j/m, (j+1)/m)$ and generates one independent point $u_j = (j + U_j)/m$ per stratum.
One-dimensional `latin_hypercube(m, 1, rng)` generates these $m$ points (shuffling does not affect a one-dimensional estimate).

Let random variable $J$ denote the stratum containing uniform $U$; the law of total variance is

$$
\mathrm{Var}\,f(U) = \mathrm{Var}\bigl(\mathrm{E}[f(U) \mid J]\bigr) + \mathrm{E}\bigl[\mathrm{Var}(f(U) \mid J)\bigr]
$$


In plain Monte Carlo, each stratum's sample count fluctuates, so both terms contribute to variance.
With one point per stratum, the stratified estimator eliminates the first, between-stratum variance term, giving

$$
\mathrm{Var}\,\hat{I}_{\mathrm{strat}} = \frac{1}{m^2} \sum_{j=0}^{m-1} \mathrm{Var}\bigl(f(u_j)\bigr) = \frac{1}{m}\,\mathrm{E}\bigl[\mathrm{Var}(f(U) \mid J)\bigr] \le \frac{\sigma_f^2}{m}
$$


For smooth $f$, within a stratum of width $h = 1/m$ the approximation $f(u) \approx f(x_j) + f'(x_j)(u - x_j)$ gives variance of order $f'(x_j)^2 h^2 / 12$ (where $x_j$ is the stratum midpoint).
Summing over $m$ strata gives

$$
\mathrm{Var}\,\hat{I}_{\mathrm{strat}} \approx \frac{1}{12 m^3}\int_0^1 f'(x)^2\,dx
$$

so standard error decreases as $m^{-3/2}$.
Compared with plain Monte Carlo's $m^{-1/2}$, the error ratio at equal sample size grows proportionally to $m$.

For $f(x) = e^x$ ($I = e - 1$), the following cell independently repeats plain Monte Carlo and stratified estimates $R$ times each, measuring root mean square error (RMSE) at $m = 8, 16, \dots, 2^k$.
Inputs are replicate count $R$, exponent $k$ of maximum sample size $m = 2^k$, and seed.
Theoretical references are plain Monte Carlo's $\sqrt{\sigma_f^2/m}$ from $\sigma_f^2 = (e^2 - 1)/2 - (e-1)^2 \approx 0.2420$ and stratification asymptotic $\sqrt{(e^2-1)/(24 m^3)}$ from $\int_0^1 (e^x)^2 dx = (e^2 - 1)/2$.
Both are analytically derived independent checks; the table gives RMSE-to-theory ratios.
The relative standard error of RMSE itself from $R$ replicates is approximately $1/\sqrt{2R}$ for normal errors, so ratios fluctuate around 1 at this scale.

```rust
//| id: random-stratified-rmse
//| ref: random-stratified-rmse
//| title: "Measure plain Monte Carlo and stratified errors across sample sizes"
//| run: reactive
//| crates: [scioxide-core, scioxide-random]
//| inputs:
//|   replications: {"type":"range","label":"Replicate count R [count]","description":"Relative RMSE standard error is about 1/√(2R).","min":50,"max":400,"step":50,"value":200}
//|   maximum_exponent: {"type":"range","label":"Maximum sample-size exponent k (m = 2ᵏ) [-]","min":6,"max":12,"step":1,"value":10}
//|   seed: {"type":"range","label":"Random seed [-]","min":1,"max":1000,"step":1,"value":3}
//| cases:
//|   - {"id":"many-replications","label":"R = 400, seed 9","description":"More replicates reduce ratio fluctuations to a standard error of about 0.035.","inputs":{"replications":400,"seed":9}}
//|   - {"id":"large-m","label":"k = 12","description":"At m = 4096, stratified RMSE falls to about 10⁻⁶.","inputs":{"maximum_exponent":12}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"rmse","path":"/rows/7/0","range":{"min":1024,"max":1024}}
//|       - {"artifact":"rmse","path":"/rows/7/3","range":{"min":0.8,"max":1.2}}
//|       - {"artifact":"rmse","path":"/rows/7/6","range":{"min":0.8,"max":1.2}}
//|       - {"artifact":"rmse","path":"/rows/0/6","range":{"min":0.8,"max":1.2}}
//|   - case: many-replications
//|     expect:
//|       - {"artifact":"rmse","path":"/rows/7/3","range":{"min":0.85,"max":1.15}}
//|       - {"artifact":"rmse","path":"/rows/7/6","range":{"min":0.85,"max":1.15}}
//|   - case: large-m
//|     expect:
//|       - {"artifact":"rmse","path":"/rows/9/0","range":{"min":4096,"max":4096}}
//|       - {"artifact":"rmse","path":"/rows/9/4","range":{"min":5e-7,"max":4e-6}}
//|       - {"artifact":"rmse","path":"/rows/9/6","range":{"min":0.8,"max":1.2}}
use scioxide_core::RealScalar;
use scioxide_random::{Rng, SeedableRng, SplitMix64, latin_hypercube};

let sci4 = serde_json::json!({ "notation": "scientific", "significantDigits": 4 });
let fixed3 = serde_json::json!({ "fractionDigits": 3 });
// Independent analytical values: I = e − 1, σ² = Var e^U, ∫(e^x)² dx = (e² − 1)/2.
let e = std::f64::consts::E;
let exact = e - 1.0;
let variance = (e * e - 1.0) / 2.0 - exact * exact;
let r = replications.round() as usize;
let mut rng = SplitMix64::from_seed(seed.round() as u64);
let (mut simple_curve, mut strat_curve) = (Vec::new(), Vec::new());
let (mut simple_theory, mut strat_theory, mut rows) = (Vec::new(), Vec::new(), Vec::new());
for k in 3..=maximum_exponent.round() as u32 {
    let m = 1_usize << k;
    let (mut simple_square, mut strat_square) = (0.0_f64, 0.0_f64);
    for _ in 0..r {
        // Plain Monte Carlo: m independent uniforms.
        let mut sum = 0.0;
        for _ in 0..m {
            let u: f64 = rng.next_float().map_err(|e| e.to_string())?;
            sum += RealScalar::exp(u);
        }
        simple_square += RealScalar::powi(sum / m as f64 - exact, 2);
        // Stratified: one point from each stratum [j/m, (j+1)/m).
        let points: Vec<f64> = latin_hypercube(m, 1, &mut rng).map_err(|e| e.to_string())?;
        let estimate = points.iter().map(|&u| RealScalar::exp(u)).sum::<f64>() / m as f64;
        strat_square += RealScalar::powi(estimate - exact, 2);
    }
    let simple = RealScalar::sqrt(simple_square / r as f64);
    let strat = RealScalar::sqrt(strat_square / r as f64);
    let simple_ref = RealScalar::sqrt(variance / m as f64);
    let strat_ref = RealScalar::sqrt((e * e - 1.0) / (24.0 * RealScalar::powi(m as f64, 3)));
    simple_curve.push([m as f64, simple]);
    strat_curve.push([m as f64, strat]);
    simple_theory.push([m as f64, simple_ref]);
    strat_theory.push([m as f64, strat_ref]);
    rows.push((
        m,
        simple,
        simple_ref,
        simple / simple_ref,
        strat,
        strat_ref,
        strat / strat_ref,
    ));
}
let observed = serde_json::json!({ "showSymbol": true, "symbol": "circle" });
let dashed = serde_json::json!({ "lineType": "dashed" });
let series = |name: &str, points: &Vec<[f64; 2]>, style: &serde_json::Value| {
    serde_json::json!({
        "name": name,
        "points": points,
        "style": style
    })
};
emit_line_chart!(
    &vec![
        series("Plain Monte Carlo (measured)", &simple_curve, &observed),
        series(
            "Plain Monte Carlo theory √(σ²/m)",
            &simple_theory,
            &dashed
        ),
        series("Stratified (measured)", &strat_curve, &observed),
        series("Stratification asymptotic √((e²−1)/(24m³))", &strat_theory, &dashed),
    ],
    options = &serde_json::json!({
        "xLabel": "Sample size m [count]",
        "yLabel": "RMSE [-]",
        "xType": "log",
        "yType": "log"
    })
);
let columns = serde_json::json!([
    { "key": "0", "label": "Sample size m [count]", "type": "integer" },
    { "key": "1", "label": "Plain MC RMSE [-]", "type": "number", "format": sci4 },
    { "key": "2", "label": "Theory √(σ²/m) [-]", "type": "number", "format": sci4 },
    { "key": "3", "label": "Plain MC ratio [-]", "type": "number", "format": fixed3 },
    { "key": "4", "label": "Stratified RMSE [-]", "type": "number", "format": sci4 },
    { "key": "5", "label": "Asymptotic [-]", "type": "number", "format": sci4 },
    { "key": "6", "label": "Stratified ratio [-]", "type": "number", "format": fixed3 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "rmse" })
);
emit_text!(format!(
    "Ratio standard error ≈ 1/√(2R) = {:.3}",
    1.0 / RealScalar::sqrt(2.0 * r as f64)
));
```

On log-log axes, plain Monte Carlo RMSE follows dashed slope $-1/2$ and stratified RMSE follows slope $-3/2$.
With the defaults ($R = 200$, seed 3), plain Monte Carlo-to-theory ratios range from 0.918 to 1.135, and stratified-to-asymptotic ratios from 0.943 to 1.050.
The ratio standard error is about 0.050, so the most extreme plain Monte Carlo ratio, 1.135 at $m = 512$, is 2.7 standard errors away.
If ratios were independent, the chance that any of 16 ratios differs by at least 2.7 standard errors is about 11%, making this deviation consistent with chance.
Setting $R = 400$ and seed 9 gives ratio standard error 0.035, with ratios in 0.959–1.068 and 0.974–1.029.

At $m = 1024$, plain Monte Carlo RMSE is $1.521 \times 10^{-2}$ versus stratified $1.653 \times 10^{-5}$, about 920 times smaller at the same sample size.
The theoretical ratio is $m\sqrt{24\sigma_f^2/(e^2 - 1)} \approx 0.954\,m \approx 977$; the measured ratio is consistent with fluctuations in the two RMSE estimates (about 5% each).
Stratification gains increase with smoothness of $f$; the asymptotic form fails for oscillations finer than a stratum or discontinuities.

## Summary

`uniform_index` removes modulo bias through Lemire rejection; rejection probability below $1/2$ makes reaching the 1,024-word cutoff practically confined to nonuniform generator words.
Permutations and sampling without replacement build on this index selection; `sample_indices` uses partial Fisher–Yates for $k \ge \lfloor n/16 \rfloor$ and unordered Floyd sampling for smaller $k$.
To restore arrays or generators after failure, supply a state policy to `shuffle_in_place` rather than `shuffle`.
Stratification removes between-stratum variance; ratios to theoretical values verify RMSE decay $m^{-3/2}$ for smooth integrands.
