These tables cover real-valued probability laws.
Every law implements `Distribution`, `Density`, `LogDensity`, `Cdf`, `LogCdf`, `Survival`, `LogSurvival`, `Quantile`, `InverseSurvival`, and `Support` and works with `f32` and `f64`.
“Key contracts” describes parameter conditions, location and scale handling, availability of `Mean`, `Variance`, and `Entropy`, and numerical methods.
Parameter-domain violations give `DomainError`; nonfinite parameters give `NonFinite`.
However, term count $n = 0$ for `IrwinHall` gives `InvalidInput`.
Laws using `LawOptions` use defaults with `new` and reject out-of-range tolerances supplied to `with_options` as `InvalidInput`.
Add location and scale to standard-form-only laws with `Affine::new(law, location, scale)`.
Sampling methods are explained in [Continuous-distribution transforms, rejection, and tail control](../../algorithms/continuous-distributions/).
