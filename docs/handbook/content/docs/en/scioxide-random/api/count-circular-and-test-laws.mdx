These tables cover integer-valued counting laws, angle and direction laws, and test-statistic laws.
Counting laws implement `Mass`, `LogMass`, `Cdf`, `LogCdf`, `Survival`, `LogSurvival`, `Quantile`, `InverseSurvival`, `Mean`, `Variance`, and a support trait (`CountSupport` for nonnegative counts, `SignedCountSupport` for signed counts).
`Binomial` is the only counting law implementing `Entropy`.
Generate samples with `sample`, `sample_n`, and `sample_n_into` of `CountDistribution` ([Integer samples and CountDistribution](oxref:random-discrete-count-distribution)); laws with `LawOptions` count words per sample through `sample_word_budget`.
For laws taking `LawOptions`, constructor `new` uses default settings, while `with_options` takes settings as its last argument.
