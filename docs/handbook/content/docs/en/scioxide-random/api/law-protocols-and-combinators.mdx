These tables cover capability traits shared by probability laws and types composing laws or sampling user densities.
Laws implement only capabilities they support; no numerical-integration fallback supplies nonexistent quantities.
Capability conventions are explained in [Distribution capabilities, tail probabilities, and numerical inversion](../../algorithms/laws-tails-and-multivariate-models/).
