These tables cover vector- and matrix-valued laws and Plans for multivariate rectangle probabilities.
For any `BitGenerator`, vector and matrix laws provide `sample_width`, `workspace_requirements(policy, n)`, `workspace(policy, n)`, `sample` returning one sample as an owned `Vec`, `sample_n(rng, n)` returning $n$ samples as rows of an owned `Vec`, row-batch `sample_n_into(rng, policy, output, workspace)`, and `sample_indexed_into` using `root.split(row)` row by row.
Constructor `new` uses default `LawOptions`; `with_options` takes settings as its final argument.
Matrix samples are returned as row-major flat arrays of `shape()`.
Most laws provide support testing `contains_support`, but `NormalInverseGamma`, `MatrixNormal`, `MatrixT`, group Haar measures, and `RandomCorrelation` do not.
Parameter-domain violations give `DomainError`, shape mismatches `DimensionMismatch`, and exceeding the storage limit in `LawOptions` gives `ResourceLimit`.
