For $n$ people independently born with equal probability on $D = 365$ days, the probability of at least one shared birthday exceeds 1/2 at $n = 23$.
The same calculation gives the probability that two parallel workers receive the same randomly assigned seed.
This page compares exact probability, exponential approximation, and simulation through `uniform_index`, quantifying approximation errors and simulation confidence intervals.
Using this formula for 64-bit seed collisions and understanding stream-selection guarantees is covered in [Random-seed collisions and stream splitting](../seed-collisions-and-streams/).

## Exact probability and exponential approximation

Draw $k$ values uniformly with replacement from $D$ possibilities.
The probability of no match is the product of probabilities $1 - i/D$ that the $i$th value ($i = 0, 1, \dots$) differs from the preceding $i$ values, giving the exact collision probability

$$
P(k, D) = 1 - \prod_{i=0}^{k-1}\left(1 - \frac{i}{D}\right)
$$


For $k > D$, the pigeonhole principle gives $P = 1$.
The cell sums the product logarithmically as $\sum_i \ln(1 - i/D)$ and computes $1 - e^{x}$ with `RealScalar::exp_m1`, avoiding lost digits even for small $P$.

Retaining only the first-order term of $\ln(1 - x) = -x - x^2/2 - \cdots$ gives

$$
P_{\mathrm{approx}}(k, D) = 1 - \exp\!\left(-\frac{k(k-1)}{2D}\right)
$$


This page uses this form.
Replacing $k(k-1)$ by $k^2$ gives the also common $1 - \exp(-k^2/(2D))$, but for $D = 365$ and $k = 23$ it gives $0.5155$, exceeding exact $0.5073$ by $0.0082$.
The omitted second-order term $\sum_i i^2/(2D^2) \approx k^3/(6D^2)$ makes $P_{\mathrm{approx}}$ underestimate the exact value by about $(1 - P)\,k^3/(6D^2)$.
For $D = 365$ and $k = 23$, this estimate is $0.0075$, closely matching actual difference $-0.0073$.
The population giving $P = 1/2$ follows from $k(k-1)/(2D) = \ln 2$ as $k_{1/2} \approx 1/2 + \sqrt{2D\ln 2}$, approximately $1.1774\sqrt D$ for large $D$.

## Simulation and Wilson intervals

With $C$ collisions in $R$ trials, $\hat P = C/R$ has standard error $\sqrt{P(1-P)/R}$.
For $\hat P$ near 0 or 1, interval $\hat P \pm 1.96\sqrt{\hat P(1-\hat P)/R}$ can extend beyond $[0, 1]$ and coverage falls below nominal 95%.
Instead, use the Wilson 95% interval

$$
\frac{\hat P + \frac{z^2}{2R} \pm z\sqrt{\frac{\hat P(1-\hat P)}{R} + \frac{z^2}{4R^2}}}{1 + \frac{z^2}{R}}, \qquad z = 1.96
$$


Exact Clopper–Pearson limits from test inversion are computed by scioxide-stats' `binomial_confidence_limits` ([Distribution fitting and inverted confidence limits](../../../scioxide-stats/algorithms/distribution-fitting-and-confidence-limits/)).

Each trial draws $k$ days with `uniform_index(D, &mut rng)`.
`uniform_index` uses [Lemire rejection](oxref:random-sampling-lemire) on full-width uniform words to produce unbiased indices $0, \dots, D-1$ without workspace allocation.
A stamp array with a different trial number per trial detects repeated days, stopping at the first collision.
Each population $k$ uses a separate `Pcg64::split(k)` stream, so changing the population grid leaves the result for any $k$ unchanged.

The following cell takes population $n$ (2–100), days $D$ (50–1000), trials $R$ per $k$, and random seed.
The graph shows exact probabilities for $k = 1, \dots, \max(\lceil 3\sqrt D\rceil, n)$ as a dashed curve, the approximation as a dotted curve, and simulated $\hat P$ markers with Wilson bands at about 15 values of $k$.
The vertical line marks input $n$.
The first table row is input $n$; following rows correspond to marker $k$ values.

```rust
//| id: random-birthday-probability
//| ref: random-birthday-probability
//| title: "Compare collision probabilities through exact formulas, approximations, and simulation"
//| run: reactive
//| crates: [scioxide-core, scioxide-random]
//| inputs:
//|   people: {"type":"range","label":"Population n [people]","description":"Population in the first table row and vertical line.","min":2,"max":100,"step":1,"value":23}
//|   days: {"type":"range","label":"Days D [days]","description":"Possible birthdays. Smaller values increase collision probability at a fixed population.","min":50,"max":1000,"step":5,"value":365}
//|   trials: {"type":"range","label":"Trials per k R [trials]","description":"Changes Wilson interval widths.","min":500,"max":4000,"step":500,"value":2000}
//|   birthday_seed: {"type":"range","label":"Random seed [-]","description":"Pcg64 seed. Uses split(k) streams for each population k.","min":1,"max":1000,"step":1,"value":123}
//| cases:
//|   - {"id":"hundred-days","label":"D = 100 days, n = 13 people","description":"Exact P is 0.5572; the approximation is 0.0156 smaller, close to (1 − P)n³/(6D²) = 0.0162.","inputs":{"days":100,"people":13}}
//|   - {"id":"more-trials","label":"R = 4000 trials","description":"Wilson widths are about 1/√2 of those at R = 2000.","inputs":{"trials":4000}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"comparison","path":"/rows/0/0","equals":23}
//|       - {"artifact":"comparison","path":"/rows/0/1","approx":{"value":0.5072972,"atol":1e-6}}
//|       - {"artifact":"comparison","path":"/rows/0/3","approx":{"value":-0.0072955,"atol":1e-6}}
//|       - {"artifact":"comparison","path":"/rows/0/4","range":{"min":0.47,"max":0.55}}
//|   - case: hundred-days
//|     expect:
//|       - {"artifact":"comparison","path":"/rows/0/1","approx":{"value":0.5572250,"atol":1e-6}}
//|       - {"artifact":"comparison","path":"/rows/0/4","range":{"min":0.52,"max":0.6}}
//|   - case: more-trials
//|     expect:
//|       - {"artifact":"comparison","path":"/rows/0/4","range":{"min":0.48,"max":0.54}}
//|       - {"artifact":"comparison","path":"/rows/0/6","range":{"min":0.51,"max":0.56}}
use scioxide_core::RealScalar;
use scioxide_random::{Pcg64, SeedableRng, SplittableRng, uniform_index};

let (n, d, r) = (
    people.round() as usize,
    days.round() as usize,
    trials.round() as usize,
);
// Independent check: exact P = 1 − ∏(1 − i/D). For k > D, the i = D factor is 0, giving P = 1.
let exact = |k: usize| {
    let log_q: f64 = (0..k.min(d + 1))
        .map(|i| RealScalar::ln_1p(-(i as f64) / d as f64))
        .sum();
    -RealScalar::exp_m1(log_q)
};
let approx = |k: usize| -RealScalar::exp_m1(-((k * (k - 1)) as f64) / (2.0 * d as f64));
let root = Pcg64::from_seed(birthday_seed.round() as u64);
let mut stamp = vec![0_u32; d];
let mut epoch = 0_u32;
let mut simulate = |k: usize| -> Result<usize, String> {
    let mut rng = root.split(k as u64).map_err(|e| e.to_string())?;
    let mut collisions = 0;
    for _ in 0..r {
        epoch += 1; // Change trial numbers instead of clearing stamps
        for _ in 0..k {
            let day = uniform_index(d, &mut rng).map_err(|e| e.to_string())?;
            if stamp[day] == epoch {
                collisions += 1;
                break;
            }
            stamp[day] = epoch;
        }
    }
    Ok(collisions)
};
let k_max = (3.0 * RealScalar::sqrt(d as f64)).ceil() as usize;
let step = k_max.div_ceil(15);
let grid: Vec<usize> = (1..)
    .map(|j| j * step)
    .take_while(|&k| k <= k_max)
    .collect();
let z = 1.96_f64;
let (mut rows, mut band, mut marks) = (Vec::new(), Vec::new(), Vec::new());
for &k in std::iter::once(&n).chain(grid.iter().filter(|&&k| k >= 2)) {
    let p_hat = simulate(k)? as f64 / r as f64;
    // Wilson 95% interval.
    let centre = (p_hat + z * z / (2.0 * r as f64)) / (1.0 + z * z / r as f64);
    let spread =
        RealScalar::sqrt(p_hat * (1.0 - p_hat) / r as f64 + z * z / (4.0 * (r * r) as f64));
    let half = z * spread / (1.0 + z * z / r as f64);
    let (p, se) = (
        exact(k),
        RealScalar::sqrt(exact(k) * (1.0 - exact(k)) / r as f64),
    );
    rows.push((
        k,
        p,
        approx(k),
        approx(k) - p,
        p_hat,
        centre - half,
        centre + half,
        (p_hat - p) / se,
    ));
    if rows.len() > 1 {
        band.push([k as f64, p_hat, centre - half, centre + half]);
        marks.push([k as f64, p_hat]);
    }
}
let x_max = k_max.max(n);
let exact_line: Vec<[f64; 2]> = (1..=x_max).map(|k| [k as f64, exact(k)]).collect();
let approx_line: Vec<[f64; 2]> = (1..=x_max).map(|k| [k as f64, approx(k)]).collect();
emit_chart!(serde_json::json!({
    "kind": "xy",
    "dataZoom": true,
    "tooltip": true,
    "xLabel": "Population k [people]",
    "yLabel": "Shared-birthday probability [-]",
    "xMin": 0.0,
    "xMax": x_max as f64,
    "yMin": 0.0,
    "yMax": 1.0,
    "layers": [
        { "id": "wilson", "kind": "band", "name": "Wilson 95% interval", "points": band },
        { "id": "simulated", "kind": "scatter", "name": "Simulated P̂", "points": marks },
        {
            "id": "exact",
            "kind": "line",
            "name": "Exact P",
            "points": exact_line,
            "style": { "lineType": "dashed" }
        },
        {
            "id": "approx",
            "kind": "line",
            "name": "Approximation 1 − exp(−k(k−1)/(2D))",
            "points": approx_line,
            "style": { "lineType": "dotted" }
        }
    ],
    "annotations": [{ "kind": "line", "axis": "x", "value": n as f64, "label": "Input n" }]
}));
let fixed4 = serde_json::json!({ "fractionDigits": 4 });
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let fixed2 = serde_json::json!({ "fractionDigits": 2 });
let columns = serde_json::json!([
    { "key": "0", "label": "Population k [people]", "type": "integer" },
    { "key": "1", "label": "Exact P [-]", "type": "number", "format": fixed4 },
    { "key": "2", "label": "Approximate P [-]", "type": "number", "format": fixed4 },
    { "key": "3", "label": "Approximate − exact [-]", "type": "number", "format": sci3 },
    { "key": "4", "label": "P̂ [-]", "type": "number", "format": fixed4 },
    { "key": "5", "label": "Wilson lower bound [-]", "type": "number", "format": fixed4 },
    { "key": "6", "label": "Wilson upper bound [-]", "type": "number", "format": fixed4 },
    { "key": "7", "label": "z = (P̂ − P)/SE [-]", "type": "number", "format": fixed2 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "comparison" })
);
```

For default $n = 23$ and $D = 365$, exact probability is $0.50730$ and approximation $0.50000$, differing by $-0.0073$.
The approximation difference grows with $k$, reaches its largest magnitude, $-0.0103$ at $k = 33$, then shrinks as $P$ approaches 1.
For seed 123 and $R = 2000$, the simulation at $k = 23$ gives $\hat P = 0.5150$ with Wilson interval $[0.4931, 0.5369]$ and difference $0.69\,\mathrm{SE}$ from exact.
Among the graph's 14 $k$ values, two points, $k = 16$ ($2.37\,\mathrm{SE}$) and $k = 36$ ($2.49\,\mathrm{SE}$), fall outside the 95% interval.
Each point has about 5% chance of exclusion, so 14 points have expected exclusions 0.7 and probability about 15% of two or more exclusions.
Setting $D = 100$ gives $P = 0.5572$ at 13 people, widening the approximation difference to $-0.0156$.

## Summary

Exact shared-birthday probability for $n$ people is $1 - \prod_{i<n}(1 - i/D)$; for $D = 365$ it exceeds 1/2 at $n = 23$.
Logarithmic sums and `exp_m1` evaluate the product without losing digits even for small $P$.
Approximation $1 - \exp(-n(n-1)/(2D))$ underestimates by about $(1-P)n^3/(6D^2)$, with maximum difference about 0.01 for $D = 365$.
Compare simulated proportions with exact values using Wilson intervals, and interpret excluded-point counts against the expectation from 5% per point.
