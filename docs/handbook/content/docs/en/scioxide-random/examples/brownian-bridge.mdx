Displacements of particles in Brownian motion and fluctuations in log stock prices are represented by a Wiener process $W(t)$.
Its paths are inputs to numerical stochastic differential equations and option pricing.
This example constructs paths from standard normal coordinates using `BrownianBridgePlan` and verifies their Wiener properties.
This page checks quadratic variation of one path; variance and covariance across many paths are checked in [Variance and covariance of Brownian path ensembles](../brownian-ensemble/).
The coordinate assignment order and its QMC advantages were explained in [Assigning coordinates with a Brownian bridge](oxref:random-qmc-brownian-bridge).

## Wiener process properties

A standard Wiener process satisfies $W(0) = 0$ and has mutually independent increments $W(t) - W(s)$ ($s < t$) on disjoint intervals, each distributed as $\mathcal{N}(0, t - s)$.
For $s \le t$, write $W(t) = W(s) + (W(t) - W(s))$; the latter increment is independent of $W(s)$, giving

$$
\mathrm{Cov}(W(s), W(t)) = \mathrm{Var}\,W(s) = \min(s, t)
$$


Time is measured in seconds; displacement uses the scale with $\mathrm{Var}\,W(t) = t$ (units $\sqrt{\mathrm{s}}$).
A particle's one-dimensional displacement with diffusion coefficient $D$ is $X(t) = \sqrt{2D}\,W(t)$, giving $\mathrm{Var}\,X(t) = 2Dt$; this factor restores physical units.

On uniform grid $t_i = iT/n$, increments $\Delta W_i = W(t_{i+1}) - W(t_i)$ independently follow $\mathcal{N}(0, T/n)$.
$(\Delta W_i)^2 / (T/n)$ is chi-squared with 1 degree of freedom, mean 1, and variance 2.
Consequently, quadratic variation

$$
Q_n = \sum_{i=0}^{n-1} (\Delta W_i)^2, \qquad \mathrm{E}[Q_n] = T, \qquad \mathrm{sd}(Q_n) = \frac{T}{n}\sqrt{2n} = T\sqrt{2/n}
$$

converges to $T$ as $n \to \infty$.
This is the discrete counterpart of the Itô rule $(dW)^2 = dt$.
Partial sums $Q(t_k) = \sum_{i<k} (\Delta W_i)^2$ up to time $t_k$ similarly fluctuate around $t_k$ with mean $t_k$ and standard deviation $(T/n)\sqrt{2k}$.

## Assigning coordinates with a Brownian bridge

`BrownianBridgePlan::new(times)` accepts a strictly increasing time grid $t_0 < t_1 < \dots < t_n$.
Among $n$ standard normal coordinates $z_0, \dots, z_{n-1}$, $z_0$ determines endpoint $W(t_n) = \sqrt{t_n - t_0}\,z_0$.
The remaining coordinates are assigned to midpoint index $c = \lfloor (a + b)/2 \rfloor$ between known values $W(t_a)$ and $W(t_b)$, breadth-first from left to right.
Given those two values, the conditional distribution of $W(t_c)$ is

$$
W(t_c) \mid W(t_a), W(t_b) \sim \mathcal{N}\!\left( \frac{(t_b - t_c) W(t_a) + (t_c - t_a) W(t_b)}{t_b - t_a},\; \frac{(t_c - t_a)(t_b - t_c)}{t_b - t_a} \right)
$$


The mean linearly interpolates the endpoints; variance is 0 at either endpoint and greatest in the middle.
At construction, the plan computes and stores interpolation weights and conditional standard deviations in $O(n)$ time and storage, generating each path in $O(n)$.
With 8 intervals, coordinates are used at time indices $8, 4, 2, 6, 1, 3, 5, 7$ in that order.
The grid may be nonuniform, and $n$ need not be a power of 2.

Each stage samples the conditional distribution exactly, giving the same joint path distribution as sequentially added increments.
Thus the Wiener properties above hold unchanged (under the `apply` contract, $\mathrm{Cov}(W(t_i), W(t_j)) = \min(t_i, t_j) - t_0$).
The difference is that leading coordinates determine the broad path shape.
QMC sequences have more uniform leading coordinates, allowing them to represent the parts carrying more path variance.

An invalid grid makes `new` fail.
Fewer than two times gives `InvalidInput`, NaN or infinite times `NonFinite`, and non-strictly-increasing times `DomainError`.
`apply` and `apply_into` return `DimensionMismatch` for coordinate length other than $n$ and `NonFinite` for NaN or infinite coordinates.
`apply_into` also returns `DimensionMismatch` if output length differs from $n$.

## One path and its quadratic variation

The following cell generates $n$ standard normal coordinates from a seed with `Normal::sample_n` and computes $W(t_1), \dots, W(t_n)$ using `BrownianBridgePlan::apply`.
Inputs are random seed, interval count $n$, and terminal time $T$ [s].
`apply` returns the path in a new `Vec`, excluding $W(t_0) = 0$.
The cell computes increments and quadratic variation from path differences.
This computation does not pass through the plan, so comparison with closed forms $\mathrm{E}[Q_n] = T$ and $\mathrm{sd}(Q_n) = T\sqrt{2/n}$ is independent.

The upper graph overlays the path with the pointwise $\pm 2\sqrt{t}$ band (containing $W(t)$ with approximately 95% probability).
The lower graph overlays partial quadratic variation $Q(t)$ (markers), theoretical $t$ (dashed), and a $\pm 2$ standard-deviation band.
Time axes of both graphs are linked.

```rust
//| id: random-brownian-bridge
//| ref: random-brownian-bridge
//| title: "Generate one Brownian bridge path and measure quadratic variation"
//| run: reactive
//| crates: [scioxide-core, scioxide-random]
//| inputs:
//|   path_seed: {"type":"range","label":"Random seed","min":1,"max":1000,"step":1,"value":17}
//|   time_steps: {"type":"range","label":"Time-step count n [intervals]","description":"Changes quadratic-variation standard deviation T√(2/n).","min":16,"max":1024,"step":16,"value":256}
//|   time_horizon: {"type":"range","label":"Terminal time T [s]","min":0.25,"max":4,"step":0.25,"value":1}
//| cases:
//|   - {"id":"fine-grid","label":"n = 1024","description":"Quadrupling steps halves the standard deviation of Q_n to 0.0442 s.","inputs":{"time_steps":1024}}
//|   - {"id":"other-seed","label":"Seed 1","description":"Q_n also lies near T for another path.","inputs":{"path_seed":1}}
//|   - {"id":"long-horizon","label":"T = 4 s","description":"With the same seed, paths scale by √4 = 2 and Q_n by 4, leaving standardized values unchanged.","inputs":{"time_horizon":4}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"summary","path":"/rows/0/2","approx":{"value":0.8744,"atol":1e-3}}
//|       - {"artifact":"summary","path":"/rows/0/3","approx":{"value":0.088388,"atol":1e-5}}
//|       - {"artifact":"summary","path":"/rows/0/4","range":{"min":-4,"max":4}}
//|   - case: fine-grid
//|     expect:
//|       - {"artifact":"summary","path":"/rows/0/3","approx":{"value":0.044194,"atol":1e-5}}
//|       - {"artifact":"summary","path":"/rows/0/4","range":{"min":-4,"max":4}}
//|   - case: other-seed
//|     expect:
//|       - {"artifact":"summary","path":"/rows/0/4","range":{"min":-4,"max":4}}
//|   - case: long-horizon
//|     expect:
//|       - {"artifact":"summary","path":"/rows/0/2","approx":{"value":3.4976,"atol":4e-3}}
//|       - {"artifact":"summary","path":"/rows/0/4","approx":{"value":-1.4214,"atol":1e-3}}
use scioxide_core::RealScalar;
use scioxide_random::{BrownianBridgePlan, Distribution, Normal, SeedableRng, SplitMix64};

let n = time_steps.round() as usize;
let times: Vec<f64> = (0..=n)
    .map(|i| time_horizon * i as f64 / n as f64)
    .collect();
// Plan validating the grid and retaining each stage's weights and conditional standard deviation.
let plan = BrownianBridgePlan::new(&times).map_err(|e| e.to_string())?;
// Standard normal coordinates z. z[0] determines W(T), later coordinates the midpoints.
let mut rng = SplitMix64::from_seed(path_seed.round() as u64);
let z = Normal::<f64>::standard()
    .sample_n(&mut rng, n)
    .map_err(|e| e.to_string())?;
let path = plan.apply(&z).map_err(|e| e.to_string())?;
// Prepend W(t_0) = 0 because output excludes it.
let mut full = Vec::with_capacity(n + 1);
full.push(0.0);
full.extend_from_slice(&path);
// Compute partial quadratic variation Q(t_k) from path differences (independent check).
let mut running = Vec::with_capacity(n + 1);
let mut accumulated = 0.0_f64;
running.push(accumulated);
for w in full.windows(2) {
    accumulated += (w[1] - w[0]) * (w[1] - w[0]);
    running.push(accumulated);
}
let dt = time_horizon / n as f64;
let sd = time_horizon * RealScalar::sqrt(2.0 / n as f64);
let curve: Vec<[f64; 2]> = times.iter().zip(&full).map(|(&t, &w)| [t, w]).collect();
let envelope: Vec<[f64; 4]> = times
    .iter()
    .map(|&t| {
        let half_width = 2.0 * RealScalar::sqrt(t);
        [t, 0.0, -half_width, half_width]
    })
    .collect();
let partial_sums: Vec<[f64; 2]> = times.iter().zip(&running).map(|(&t, &q)| [t, q]).collect();
let theory: Vec<[f64; 2]> = times.iter().map(|&t| [t, t]).collect();
// The standard deviation of Q(t_k) is dt √(2k).
let qv_band: Vec<[f64; 4]> = times
    .iter()
    .enumerate()
    .map(|(k, &t)| {
        let spread = 2.0 * dt * RealScalar::sqrt(2.0 * k as f64);
        [t, t, t - spread, t + spread]
    })
    .collect();
emit_chart!(serde_json::json!({
    "kind": "xy",
    "link": { "group": "bridge-path-time" },
    "dataZoom": true,
    "tooltip": true,
    "xLabel": "Time t [s]",
    "yLabel": "Displacement W(t) [√s]",
    "xMin": 0.0,
    "xMax": time_horizon,
    "layers": [
        { "id": "envelope", "kind": "band", "name": "Pointwise ±2√t", "points": envelope },
        { "id": "path", "kind": "line", "name": "W(t)", "points": curve }
    ]
}));
emit_chart!(serde_json::json!({
    "kind": "xy",
    "link": { "group": "bridge-path-time" },
    "dataZoom": true,
    "tooltip": true,
    "xLabel": "Time t [s]",
    "yLabel": "Partial quadratic variation Q(t) [s]",
    "xMin": 0.0,
    "xMax": time_horizon,
    "layers": [
        { "id": "band", "kind": "band", "name": "t ± 2 standard deviations", "points": qv_band },
        {
            "id": "theory",
            "kind": "line",
            "name": "Theoretical E[Q(t)] = t",
            "style": { "lineType": "dashed" },
            "points": theory
        },
        { "id": "measured", "kind": "scatter", "name": "Q(t)", "points": partial_sums }
    ]
}));
let digits4 = serde_json::json!({ "significantDigits": 4 });
let fixed2 = serde_json::json!({ "fractionDigits": 2 });
let columns = serde_json::json!([
    { "key": "0", "label": "Terminal value W(T) [√s]", "type": "number", "format": digits4 },
    { "key": "1", "label": "W(T)/√T [-]", "type": "number", "format": digits4 },
    { "key": "2", "label": "Quadratic variation Q_n [s]", "type": "number", "format": digits4 },
    { "key": "3", "label": "Theoretical standard deviation T√(2/n) [s]", "type": "number", "format": digits4 },
    { "key": "4", "label": "z = (Q_n − T)/standard deviation [-]", "type": "number", "format": fixed2 }
]);
emit_table_with_columns!(
    columns,
    vec![(
        full[n],
        full[n] / RealScalar::sqrt(time_horizon),
        accumulated,
        sd,
        (accumulated - time_horizon) / sd,
    )],
    metadata = serde_json::json!({ "id": "summary" })
);
```

The path starts at 0, fluctuates up and down, and stays in the $\pm 2\sqrt{t}$ band at most times.
This is a pointwise band, so a path crossing it somewhere is not unusual.
If path fluctuations are consistently too small or large relative to the band, check coordinate scales or conditional standard deviations.
Partial quadratic variation increases whether the path rises or falls, following dashed $t$.
The nearly linear $Q(t)$ despite large path fluctuations expresses $(dW)^2 = dt$.

With the defaults (seed 17, $n = 256$, $T = 1$ s), terminal value is $-0.0217$ $\sqrt{\mathrm{s}}$ and quadratic variation $Q_n = 0.8744$ s.
Its difference from theoretical $T = 1$ s is $-1.42$ times theoretical standard deviation $0.0884$ s.
With the same seed, $n = 1024$ gives $Q_n = 0.9492$ s (standard deviation $0.0442$ s, $-1.15$ times); seed 1 gives $Q_n = 1.0315$ s at $n = 256$ ($0.36$ times).
Increasing interval count $n$ reduces standard deviation $T\sqrt{2/n}$, bringing $Q_n$ closer to $T$.
Setting $T = 4$ s scales the same-seed path by $\sqrt{4} = 2$ and quadratic variation by 4 to $3.4976$ s, leaving standardized $-1.42$ unchanged.
With the same grid and coordinates, plan weights are independent of $T$; only conditional standard deviations scale by $\sqrt{T}$.

## Summary

`BrownianBridgePlan` validates the time grid once and retains conditional coefficients, allowing arbitrarily many paths with one plan.
Output is $W(t_1), \dots, W(t_n)$ without $W(t_0) = 0$, so prepend 0 when computing increments.
One path's quadratic variation fluctuates around $T$ with standard deviation $T\sqrt{2/n}$; a finer grid checks bridge coefficients and scaling from a single path.
If $z = (Q_n - T)/(T\sqrt{2/n})$ does not remain of order $\pm 2$ across seeds, check coordinate scaling or grid construction.
Coordinate assignment order preserves path distributions, allowing the same plan with pseudorandom or QMC points.
