Monte Carlo estimation errors are described as decreasing as $N^{-1/2}$ with sample size $N$.
This example independently repeats estimator $\hat\pi = 2\ell/(d\hat p)$ from [Estimating π with Buffon's needle](../buffon-needle/) at each sample size to measure its error decay.
Fit measured root mean square errors on log-log axes and check whether the slope agrees with $-1/2$ within standard error (SE).
Needle placement, crossing probability $p = 2\ell/(\pi d)$, and delta-method standard errors were derived on the preceding page.

## Independent replicates and theoretical errors

Intermediate estimates from a single stream include earlier samples in later estimates, making errors at different points dependent.
The following cell performs $R$ independent replicates for each $N = 2^8, \dots, 2^{16}$, computing root mean square error $\mathrm{RMSE} = \sqrt{\tfrac1R\sum (\hat\pi - \pi)^2}$ and mean absolute error.
Replicates use streams selected by `root.substream(exponent_of_N, replicate_index)`.
Replicates for different $N$ use separate streams with different additive constants.
Replicates at the same $N$ use subsequences spaced $2^{64}$ transitions apart; each consumes far fewer than $2^{64}$ words, so none overlap.
Theoretical references are $\mathrm{SE}(N) = \pi\sqrt{(1-p)/(pN)}$ and, under normal approximation, $\mathrm E|\hat\pi - \pi| = \mathrm{SE}\sqrt{2/\pi}$.
Inputs are ratio $\ell/d$, replicate count $R$, and random seed.
At $R = 32$, about 4.2 million needles take roughly 1 second in the browser, so the cell runs by button.

The slope uses least squares on $x_j = \ln N_j$ and $y_j = \ln \mathrm{RMSE}_j$.
For $R$ normally distributed errors, $\mathrm{RMSE}^2$ follows $\mathrm{SE}^2 \chi^2_R / R$, giving approximate variance $1/(2R)$ for $\ln \mathrm{RMSE}$.
Points for each $N$ are independent, so slope SE is $\sqrt{1/(2R)}\,/\sqrt{\sum_j (x_j - \bar x)^2}$.
Least-squares fitting and residual interpretation are covered in [Regression, ANOVA, and GLM](../../../scioxide-stats/algorithms/regression-anova-and-glm/).

The log-log graph plots measured RMSE and mean absolute error as markers joined by dotted lines, with theory dashed.
Markers following dashed slope $-1/2$ indicate errors shrinking according to SE theory.
The table shows values at each $N$ and the fitted slope.

```rust
//| id: random-buffon-convergence
//| ref: random-buffon-convergence
//| title: "Measure error slope −1/2 using independent replicates"
//| run: button
//| crates: [scioxide-core, scioxide-random]
//| inputs:
//|   slope_ratio: {"type":"range","label":"Needle-length / line-spacing ratio ℓ/d [-]","description":"Changes the error level but not the slope.","min":0.2,"max":1,"step":0.1,"value":0.8}
//|   replicates: {"type":"range","label":"Replicates per N R [count]","description":"Changes fluctuations in RMSE and slope estimates.","min":8,"max":64,"step":8,"value":32}
//|   slope_seed: {"type":"range","label":"Random seed [-]","description":"Pcg64 seed. Replicates use streams selected by substream.","min":1,"max":1000,"step":1,"value":7}
//| cases:
//|   - {"id":"many-replicates","label":"R = 64","description":"Slope standard error falls from 0.0233 to 0.0165.","inputs":{"replicates":64}}
//|   - {"id":"short-needle","label":"ℓ/d = 0.3","description":"Error level rises about 2.1 times and slope becomes −0.479.","inputs":{"slope_ratio":0.3}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"slope","path":"/rows/0/0","range":{"min":-0.58,"max":-0.42}}
//|       - {"artifact":"slope","path":"/rows/0/1","approx":{"value":0.02328,"atol":0.0001}}
//|       - {"artifact":"errors","path":"/rows/8/4","range":{"min":0.6,"max":1.4}}
//|   - case: many-replicates
//|     expect:
//|       - {"artifact":"slope","path":"/rows/0/0","range":{"min":-0.56,"max":-0.44}}
//|       - {"artifact":"slope","path":"/rows/0/1","approx":{"value":0.01646,"atol":0.0001}}
//|   - case: short-needle
//|     expect:
//|       - {"artifact":"slope","path":"/rows/0/0","range":{"min":-0.58,"max":-0.42}}
use scioxide_core::RealScalar;
use scioxide_random::{
    Distribution, OutputPolicy, Pcg64, SamplingPolicy, SamplingRequest, SeedableRng,
    SplittableRng, Uniform, UniformDirection,
};

let r = replicates.round() as usize;
let pi = std::f64::consts::PI; // Reference (true value)
let p = 2.0 * slope_ratio / pi; // Closed-form crossing probability (independent reference)
let direction = UniformDirection::<f64>::new(2).map_err(|e| e.to_string())?;
let offset = Uniform::new(0.0_f64, 0.5).map_err(|e| e.to_string())?;
let policy = SamplingPolicy::rollback(OutputPolicy::Incremental);
let mut direction_workspace = direction
    .workspace(policy, 1 << 16)
    .map_err(|e| e.to_string())?;
let mut offset_workspace = policy
    .workspace(SamplingRequest::scalars(1 << 16))
    .map_err(|e| e.to_string())?;
let (mut uv, mut y) = (vec![0.0_f64; 2 << 16], vec![0.0_f64; 1 << 16]);
let root = Pcg64::from_seed(slope_seed.round() as u64);
let (mut rows, mut fit) = (Vec::new(), Vec::new());
let (mut rmse_points, mut mae_points) = (Vec::new(), Vec::new());
let (mut se_line, mut mae_line) = (Vec::new(), Vec::new());
for exponent in 8..=16_u64 {
    let n = 1_usize << exponent;
    let (mut sum_sq, mut sum_abs) = (0.0, 0.0);
    for replicate in 0..r {
        let mut rng = root
            .substream(exponent, replicate as u64)
            .map_err(|e| e.to_string())?;
        direction
            .sample_n_into(&mut rng, policy, &mut uv[..2 * n], &mut direction_workspace)
            .map_err(|e| e.to_string())?;
        offset
            .sample_n_into(&mut rng, policy, &mut y[..n], &mut offset_workspace)
            .map_err(|e| e.to_string())?;
        let hits = y[..n]
            .iter()
            .zip(uv.chunks_exact(2))
            .filter(|&(&y, u)| y <= 0.5 * slope_ratio * u[1].abs())
            .count();
        if hits == 0 {
            return Err(format!("π̂ is undefined because no needles crossed at N = {n}"));
        }
        let error = 2.0 * slope_ratio * n as f64 / hits as f64 - pi;
        sum_sq += error * error;
        sum_abs += error.abs();
    }
    let (rmse, mae) = (RealScalar::sqrt(sum_sq / r as f64), sum_abs / r as f64);
    // Independent check: SE(N) = π √((1 − p)/(pN)) from true p.
    let n_f = n as f64;
    let se = pi * RealScalar::sqrt((1.0 - p) / (p * n_f));
    rmse_points.push([n_f, rmse]);
    mae_points.push([n_f, mae]);
    se_line.push([n_f, se]);
    mae_line.push([n_f, se * RealScalar::sqrt(2.0 / pi)]);
    fit.push((RealScalar::ln(n_f), RealScalar::ln(rmse)));
    rows.push((n, rmse, mae, se, rmse / se));
}
// Fit ln RMSE to ln N by least squares.
let m = fit.len() as f64;
let x_mean = fit.iter().map(|f| f.0).sum::<f64>() / m;
let y_mean = fit.iter().map(|f| f.1).sum::<f64>() / m;
let sxx: f64 = fit.iter().map(|f| (f.0 - x_mean) * (f.0 - x_mean)).sum();
let sxy: f64 = fit.iter().map(|f| (f.0 - x_mean) * (f.1 - y_mean)).sum();
let slope = sxy / sxx;
let slope_se = RealScalar::sqrt(1.0 / (2.0 * r as f64)) / RealScalar::sqrt(sxx);
// Observations use markers joined by dotted lines; theory is dashed. xy charts lack logarithmic x axes, so use a line chart.
let dashed = serde_json::json!({ "lineType": "dashed" });
let circle =
    serde_json::json!({ "lineType": "dotted", "showSymbol": true, "symbol": "circle" });
let diamond =
    serde_json::json!({ "lineType": "dotted", "showSymbol": true, "symbol": "diamond" });
emit_chart!(serde_json::json!({
    "kind": "line",
    "dataZoom": true,
    "tooltip": true,
    "xLabel": "Sample size N [needles]",
    "yLabel": "π̂ error [-]",
    "xType": "log",
    "yType": "log",
    "series": [
        { "name": "RMSE (replicates)", "style": circle, "points": rmse_points },
        { "name": "Mean |π̂ − π| (replicates)", "style": diamond, "points": mae_points },
        { "name": "Theoretical SE(N)", "style": dashed, "points": se_line },
        { "name": "Theoretical SE(N)·√(2/π)", "style": dashed, "points": mae_line }
    ]
}));
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let fixed3 = serde_json::json!({ "fractionDigits": 3 });
let fixed4 = serde_json::json!({ "fractionDigits": 4 });
let columns = serde_json::json!([
    { "key": "0", "label": "N [needles]", "type": "integer" },
    { "key": "1", "label": "RMSE [-]", "type": "number", "format": sci3 },
    { "key": "2", "label": "Mean |π̂ − π| [-]", "type": "number", "format": sci3 },
    { "key": "3", "label": "Theoretical SE(N) [-]", "type": "number", "format": sci3 },
    { "key": "4", "label": "RMSE / SE [-]", "type": "number", "format": fixed3 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "errors" })
);
let slope_columns = serde_json::json!([
    { "key": "0", "label": "Slope [-]", "type": "number", "format": fixed4 },
    { "key": "1", "label": "Slope SE [-]", "type": "number", "format": fixed4 },
    { "key": "2", "label": "(slope + 1/2)/SE [-]", "type": "number", "format": fixed3 }
]);
emit_table_with_columns!(
    slope_columns,
    vec![(slope, slope_se, (slope + 0.5) / slope_se)],
    metadata = serde_json::json!({ "id": "slope" })
);
```

For default $\ell/d = 0.8$, $R = 32$, and seed 7, RMSE-to-theoretical-SE ratios range from 0.82 to 1.16 across nine points.
Relative RMSE variation at $R = 32$ is about $1/\sqrt{2R} = 0.125$, consistent with this range given the replicate count.
The fitted slope is $-0.4999$ with SE $0.0233$, differing from $-1/2$ by $0.004\,\mathrm{SE}$.
For seeds 1–5, slopes range from $-0.512$ to $-0.487$.
At $R = 64$, slope SE falls to $0.0165$ and slope becomes $-0.509$.
For $\ell/d = 0.3$, error level rises about 2.1 times and slope becomes $-0.479$ (difference $0.91\,\mathrm{SE}$).

## Nonlinearity at small sample sizes

$N$ begins at $2^8$ because reciprocal nonlinearity inflates errors for small $N$.
Approximating $\hat p$ normally and expanding the variance of $\hat\pi$ through order $N^{-2}$ gives $1 + 8(1-p)/(pN)$ times the delta-method value.
For $p = 0.509$, the increase is about 12% at $N = 64$ and 3% at $N = 256$.
The increase vanishes with $N$, so including small $N$ in the fit makes slopes steeper than $-1/2$.

## Summary

Measure Monte Carlo error decay using independent streams selected through `substream`, rather than intermediate estimates from one stream.
RMSE from $R$ replicates fluctuates relatively by about $1/\sqrt{2R}$ around theoretical SE, which must be allowed for in comparisons.
Compare log-log least-squares slopes with $-1/2$ using SE $\sqrt{1/(2R)}/\sqrt{\sum_j (x_j - \bar x)^2}$; here the difference was within 1 SE.
A slope of $-1/2$ means quadrupling samples halves SE.
For nonlinear estimators such as reciprocals, omit small-$N$ points that steepen the slope.
