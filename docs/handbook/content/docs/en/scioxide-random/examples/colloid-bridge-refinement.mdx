[Colloidal diffusion and the Stokes–Einstein relation](../colloid-diffusion/) generated particle positions at frame intervals $\Delta t$.
Motion between frames is sometimes needed.
Examples include simulating exposure-time motion blur or using a coarse path in calculations with finer steps.
This page refines coarse trajectories with `BrownianBridgePlan` and checks that frames can be filled without changing existing points.

## Refining trajectories with bridges

Each position component is $\sqrt{2D}\,W(t)$, standard Wiener process $W(t)$ scaled by $\sqrt{2D}$.
A Brownian bridge adds points from the conditional midpoint distribution at $t_m$ given fixed endpoints $W(t_l)$ and $W(t_r)$:

$$
W(t_m) \mid W(t_l), W(t_r) \sim \mathcal N\!\left(W(t_l) + \frac{t_m - t_l}{t_r - t_l}\bigl(W(t_r) - W(t_l)\bigr),\ \frac{(t_m - t_l)(t_r - t_m)}{t_r - t_l}\right)
$$


The conditional mean joins endpoints linearly; conditional variance is greatest in the middle and 0 at both endpoints.

`BrownianBridgePlan::new(&times)` validates and retains time grid $t_0 < t_1 < \dots < t_n$, precomputing each stage's weights and conditional standard deviations in $O(n)$.
`apply_into(z, output, workspace)` maps $n$ standard normal coordinates `z` to standard Wiener values $W(t_1), \dots, W(t_n)$ starting at $W(t_0) = 0$ in $O(n)$, writing `output` only on success.
Coordinate `z[0]` determines endpoint $W(t_n) = \sqrt{t_n - t_0}\,z_0$; the rest are assigned to known-endpoint interval midpoints breadth-first, from left to right.
With 8 intervals, coordinates fill path indices 8, 4, 2, 6, 1, 3, 5, 7 in that order.

Breadth-first bisection of a grid with $8 \cdot 2^r$ intervals splits the same intervals in the same order as an 8-interval grid for its first 7 bisections.
Thus the first 8 coordinates determine the 8-interval grid points through identical conditional distributions.
Making fine-grid times equal to coarse-grid times as floating-point values also makes their weights identical.
The trajectory from passing `z[..8]` to the 8-interval plan agrees at coarse points with that from passing all `z` to the fine plan.
Generating coarse points first and adding coordinates later to fill frames preserves their distribution.
Plan and workspace use is explained in [Hierarchical generation of stochastic paths with a Brownian bridge process](../brownian-bridge/).

## Variance of refined trajectories

The following cell generates one component of the preceding page's default particle ($a = 0.5$ μm, water at 293.15 K, $D = 0.4286$ μm²/s) over 8 frames of $\Delta t = 0.1$ s (0.8 s), subdividing each into $2^r$ steps.
Inputs are refinement level $r$, particle count $N$, and random seed.
Two components per particle are treated as independent samples, giving sample count $M = 2N$.

The first graph shows the first sample's refined trajectory as a line and coarse points from the 8-interval plan as markers.
The second shows fine-grid displacement variance as markers with a 95% interval band and theoretical $2Dt$ dashed.
Both graphs share a time axis; zooming one shows the same range in the other.
Since zero mean is known, variance is estimated as mean square $\hat v = \sum x^2/M$, with SE $2Dt\sqrt{2/M}$.
The first table compares terminal displacement, fine-increment, and coarse-increment variances with theoretical $2Dt$; the second reports the maximum coarse-point difference before and after refinement.

```rust
//| id: random-colloid-bridge
//| ref: random-colloid-bridge
//| title: "Refine trajectories with Brownian bridges and check variances"
//| run: reactive
//| crates: [scioxide-core, scioxide-random]
//| inputs:
//|   refine_level: {"type":"range","label":"Refinement level r [-]","description":"Divide each frame into 2^r steps.","min":1,"max":5,"step":1,"value":3}
//|   bridge_particles: {"type":"range","label":"Particle count N [count]","description":"Changes variance standard error.","min":64,"max":1024,"step":64,"value":256}
//|   bridge_seed: {"type":"range","label":"Random seed [-]","description":"SplitMix64 seed.","min":1,"max":1000,"step":1,"value":7}
//| cases:
//|   - {"id":"finest","label":"r = 5 (256 steps)","description":"Even at δt = 0.003125 s, coarse-point differences remain 0, and fine-increment variance differs from theoretical 0.002679 μm² by 0.43 SE.","inputs":{"refine_level":5}}
//|   - {"id":"many-particles","label":"N = 1024 particles","description":"Terminal variance standard error halves from 0.0429 to 0.0214 μm².","inputs":{"bridge_particles":1024}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"grid","path":"/rows/0/2","range":{"min":0,"max":1e-12}}
//|       - {"artifact":"variances","path":"/rows/1/3","approx":{"value":0.01071456,"atol":1e-7}}
//|       - {"artifact":"variances","path":"/rows/1/1","range":{"min":0.0104,"max":0.011}}
//|       - {"artifact":"variances","path":"/rows/0/1","range":{"min":0.58,"max":0.8}}
//|   - case: finest
//|     expect:
//|       - {"artifact":"grid","path":"/rows/0/1","equals":256}
//|       - {"artifact":"grid","path":"/rows/0/2","range":{"min":0,"max":1e-12}}
//|       - {"artifact":"variances","path":"/rows/1/3","approx":{"value":0.00267864,"atol":1e-7}}
//|   - case: many-particles
//|     expect:
//|       - {"artifact":"variances","path":"/rows/0/2","approx":{"value":0.021434,"atol":1e-5}}
use scioxide_core::RealScalar;
use scioxide_random::{
    BrownianBridgePlan, Distribution, Normal, OutputPolicy, SamplingPolicy, SamplingRequest,
    SeedableRng, SplitMix64,
};

// Preceding page's default particle: a = 0.5 μm, T = 293.15 K, η = 1.002 mPa·s. D [μm²/s].
let d = 1.380649e-23 * 293.15 / (6.0 * std::f64::consts::PI * 1.002e-3 * 0.5e-6) * 1e12;
let (frame, coarse_n) = (0.1_f64, 8_usize);
let split = 1_usize << refine_level as u32;
let fine_n = coarse_n * split;
// Construct fine times as frame · (i / 2^r) to match coarse times exactly.
let coarse_t: Vec<f64> = (0..=coarse_n).map(|j| frame * j as f64).collect();
let fine_t: Vec<f64> = (0..=fine_n)
    .map(|i| frame * (i as f64 / split as f64))
    .collect();
let coarse = BrownianBridgePlan::new(&coarse_t).map_err(|e| e.to_string())?;
let fine = BrownianBridgePlan::new(&fine_t).map_err(|e| e.to_string())?;
let mut coarse_ws = coarse.workspace(()).map_err(|e| e.to_string())?;
let mut fine_ws = fine.workspace(()).map_err(|e| e.to_string())?;
let standard = Normal::<f64>::standard();
let mut rng = SplitMix64::from_seed(bridge_seed as u64);
let policy = SamplingPolicy::rollback(OutputPolicy::Atomic);
let mut z_ws = policy
    .workspace(SamplingRequest::scalars(fine_n))
    .map_err(|e| e.to_string())?;
let (mut z, mut w_coarse, mut w_fine) =
    (vec![0.0; fine_n], vec![0.0; coarse_n], vec![0.0; fine_n]);
let scale = RealScalar::sqrt(2.0 * d); // Convert W(t) [√s] to displacement [μm]
let mut var_t = vec![0.0; fine_n]; // Displacement sums of squares at each time (zero mean is known)
let (mut fine_sq, mut coarse_sq, mut max_gap) = (0.0, 0.0, 0.0_f64);
let (mut path, mut knots) = (vec![[0.0, 0.0]], vec![[0.0, 0.0]]);
let samples = 2 * bridge_particles as usize; // Particle count × 2 components
for sample in 0..samples {
    standard
        .sample_n_into(&mut rng, policy, &mut z, &mut z_ws)
        .map_err(|e| e.to_string())?;
    coarse
        .apply_into(&z[..coarse_n], &mut w_coarse, &mut coarse_ws)
        .map_err(|e| e.to_string())?;
    fine.apply_into(&z, &mut w_fine, &mut fine_ws)
        .map_err(|e| e.to_string())?;
    let mut previous = 0.0;
    for (i, &w) in w_fine.iter().enumerate() {
        let x = scale * w;
        var_t[i] += x * x;
        fine_sq += (x - previous) * (x - previous);
        previous = x;
        if sample == 0 {
            path.push([fine_t[i + 1], x]);
        }
    }
    let mut previous = 0.0;
    for (j, &w) in w_coarse.iter().enumerate() {
        // w_fine[(j + 1) 2^r − 1] is the value at coarse time t_{j+1}.
        max_gap = max_gap.max(scale * (w_fine[(j + 1) * split - 1] - w).abs());
        coarse_sq += scale * scale * (w - previous) * (w - previous);
        previous = w;
        if sample == 0 {
            knots.push([coarse_t[j + 1], scale * w]);
        }
    }
}
let m = samples as f64;
let fine_dt = frame / split as f64;
let check = |name: &'static str, sum_sq: f64, count: f64, t: f64| {
    let (v, theory) = (sum_sq / count, 2.0 * d * t);
    let se = theory * RealScalar::sqrt(2.0 / count);
    (name, v, se, theory, (v - theory) / se)
};
let rows = vec![
    check(
        "Terminal x(0.8 s) variance",
        var_t[fine_n - 1],
        m,
        frame * coarse_n as f64,
    ),
    check("Fine-increment variance", fine_sq, m * fine_n as f64, fine_dt),
    check("Coarse-increment variance", coarse_sq, m * coarse_n as f64, frame),
];
let (mut band, mut marks, mut theory) = (Vec::new(), Vec::new(), Vec::new());
for (i, &s) in var_t.iter().enumerate() {
    let (t, v) = (fine_t[i + 1], s / m);
    let se = 2.0 * d * t * RealScalar::sqrt(2.0 / m);
    band.push([t, v, v - 1.96 * se, v + 1.96 * se]);
    marks.push([t, v]);
    theory.push([t, 2.0 * d * t]);
}
emit_chart!(
    serde_json::json!({
        "kind": "xy",
        "link": { "group": "colloid-bridge-time" },
        "xLabel": "Time t [s]",
        "yLabel": "Displacement x component [μm]",
        "xMin": 0.0,
        "xMax": 0.8,
        "dataZoom": true,
        "tooltip": true,
        "layers": [
            {"id": "fine", "kind": "line", "name": "Refined trajectory", "points": path},
            {"id": "coarse", "kind": "scatter", "name": "8-interval plan points", "points": knots}
        ]
    }),
    metadata = serde_json::json!({ "id": "path" })
);
emit_chart!(
    serde_json::json!({
        "kind": "xy",
        "link": { "group": "colloid-bridge-time" },
        "xLabel": "Time t [s]",
        "yLabel": "Variance of one displacement component [μm²]",
        "xMin": 0.0,
        "xMax": 0.8,
        "yMin": 0.0,
        "dataZoom": true,
        "tooltip": true,
        "layers": [
            {"id": "ci", "kind": "band", "name": "Variance 95% interval", "points": band},
            {"id": "variance", "kind": "scatter", "name": "Refined trajectory variance", "points": marks},
            {"id": "theory", "kind": "line", "name": "Theoretical 2Dt", "points": theory,
                "style": {"lineType": "dashed"}}
        ]
    }),
    metadata = serde_json::json!({ "id": "variance" })
);
let sig4 = serde_json::json!({ "significantDigits": 4 });
let sig3 = serde_json::json!({ "significantDigits": 3 });
let fixed2 = serde_json::json!({ "fractionDigits": 2 });
let columns = serde_json::json!([
    { "key": "0", "label": "Quantity" },
    { "key": "1", "label": "Estimate [μm²]", "type": "number", "format": sig4 },
    { "key": "2", "label": "SE [μm²]", "type": "number", "format": sig3 },
    { "key": "3", "label": "Theoretical 2Dt [μm²]", "type": "number", "format": sig4 },
    { "key": "4", "label": "(estimate − theory)/SE [-]", "type": "number", "format": fixed2 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "variances" })
);
let columns = serde_json::json!([
    { "key": "0", "label": "Fine step δt [s]", "type": "number", "format": sig4 },
    { "key": "1", "label": "Fine-step count [count]", "type": "integer" },
    { "key": "2", "label": "Maximum coarse-point difference [μm]", "type": "number", "format": sig3 }
]);
emit_table_with_columns!(
    columns,
    vec![(fine_dt, fine_n, max_gap)],
    metadata = serde_json::json!({ "id": "grid" })
);
```

Default $r = 3$ splits each frame into 8 steps, producing a 64-step trajectory with $\delta t = 0.0125$ s spacing.
In the first graph, the refined line passes through all 8 coarse points.
Maximum coarse-point difference is 0: the 8-interval and fine plans produce identical floating-point values from identical coordinates.
For two components of $N = 256$ particles (512 samples), variances are as follows.

- Terminal variance is $0.7078 \pm 0.0429$ μm² (theoretical $0.6857$), with difference $0.52\,\mathrm{SE}$.
- Fine-increment variance is $0.010796 \pm 0.000084$ μm² (theoretical $0.010715$), with difference $0.98\,\mathrm{SE}$.
- Coarse-increment variance is $0.08476 \pm 0.00189$ μm² (theoretical $0.08572$), with difference $-0.51\,\mathrm{SE}$.

Second-graph markers follow dashed $2Dt$, with band widths growing proportionally to $t$.
Zooming the first graph restricts the second to the same time range, allowing variance and trajectory to be read together.

In case r = 5, coarse differences remain 0 even after refinement to $\delta t = 0.003125$ s.
Fine-increment variance is $0.0026832$ μm² (theoretical $0.0026786$), with difference $0.43\,\mathrm{SE}$.
Changing $r$ changes coordinates per sample $8 \cdot 2^r$, so samples after the first use different coordinates and variance estimates differ across $r$.
The first sample's coarse points (first-graph markers) use only the first 8 coordinates and remain identical independently of $r$.
Case N = 1024 particles halves terminal variance SE to $0.0214$ μm², with difference $-0.09\,\mathrm{SE}$.

## Summary

`BrownianBridgePlan` determines the endpoint first and fills midpoints breadth-first, so the first 8 coordinates of a $8 \cdot 2^r$-interval plan produce the same points as an 8-interval plan.
Constructing a coarse trajectory first and adding coordinates for refinement leaves coarse points unchanged and terminal and increment variances at $2Dt$.
Constructing coincident fine and coarse times as identical floating-point values makes coarse points agree including rounding error.
The same seed with different refinement levels consumes different coordinate counts, so compare levels through variances and SE rather than seeds.
