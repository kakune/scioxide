[GEV annual maximum discharges and the 100-year discharge](../gev-flood-return-level/) calculated the return level $z_T$ of a river with known parameters using a closed form and the quantile of `GeneralizedExtremeValue`.
In practice, the available annual maximum discharge record spans several decades to about a century.
This page simulates records for the same river ($\mu = 1200$ m³/s, $\sigma = 350$ m³/s, $\xi = 0.15$), examining how far the upper observations lie from the return-level curve and how many years exceed $z_T$.

## Distribution of the number of exceedance years

When each annual maximum discharge $X_1, \dots, X_N$ independently follows a GEV distribution, the number of years $K$ exceeding $z_T$ follows the binomial distribution $\mathrm{Binomial}(N, 1/T)$.
Samples from `GeneralizedExtremeValue` use inverse transformation, passing uniform random values $U$ in the open interval $(0, 1)$ through the closed-form quantile function.
A sample from `Affine` is obtained by applying $\mu + \sigma Z$ to a sample from the base distribution.
Because the distribution function is continuous, event $\{X > z_T\}$ is equivalent to $\{U > 1 - 1/T\}$.
Thus, with the same seed, the number of years $K$ exceeding $z_T$ is independent of $\mu$, $\sigma$, and $\xi$ unless a value falls on a rounding boundary.

When $N/T$ is only a few years, the distribution of $K$ is right-skewed, and the normal approximation $N/T \pm 1.96\sqrt{N(1/T)(1 - 1/T)}$ can have a negative lower endpoint.
This page calls the range between the binomial 2.5% quantile $k_{\mathrm{lo}}$ and 97.5% quantile $k_{\mathrm{hi}}$ (`Binomial::quantile`) the “binomial 95% range.”
`quantile(p)` returns the smallest $k$ for which $P(K \le k) \ge p$, so $P(K \le k_{\mathrm{hi}}) \ge 0.975$ and $P(K < k_{\mathrm{lo}}) < 0.025$; the probability that $K$ lies in the inclusive range exceeds 95%.
Interpret the observed $K$ using the lower-tail probability $P(K' \le K)$ and upper-tail probability $P(K' \ge K)$ (where $K'$ follows the same binomial distribution).

The next two cells use the same annual-maximum model, so a definitions block provides a function constructing a GEV with Coles' sign convention, location, and scale.

```rust
//| id: random-gev-record-model
//| kind: definitions
//| title: "Construct a GEV with Coles shape ξ, location, and scale"
//| crates: [scioxide-random]
use scioxide_random::{Affine, GeneralizedExtremeValue};

/// Annual maximum discharge law with location μ [m³/s], scale σ [m³/s], and Coles shape ξ. The scioxide-random shape is c = −ξ.
pub(crate) fn annual_maximum_law(
    location: f64,
    scale: f64,
    xi: f64,
) -> Result<Affine<GeneralizedExtremeValue<f64>, f64>, String> {
    let gev = GeneralizedExtremeValue::new(-xi).map_err(|e| e.to_string())?;
    Affine::new(gev, location, scale).map_err(|e| e.to_string())
}
```

## Simulated records and the return-level plot

The plot uses a logarithmic horizontal axis for return period and a vertical axis for annual maximum discharge.
Draw the GEV return level (`isf(1/T)`) as a dashed line, the Gumbel law with the same $\mu, \sigma$ as a dotted line, and the simulated record as symbols joined by a dotted line.
Assign return period $T_i = 1/(1 - p_i)$ to the $i$th smallest simulated value using the Gringorten plotting position $p_i = (i - 0.44)/(N + 0.12)$.
Retain only points separated by at least 0.04 in $\log_{10} T$, thinning the dense lower observations while keeping all upper points.

Upper-tail points are a small set of order statistics and can deviate substantially from the dashed line.
The record maximum $X_{(N)}$ follows $P(X_{(N)} \le z) = F(z)^N$, so its central 95% range is bounded by the two discharges solving $F(z)^N = 0.025$ and $0.975$.
The cell computes this range with `isf(1 − q^{1/N})` ($q = 0.025, 0.975$), evaluating $1 - q^{1/N}$ as $-\operatorname{expm1}(\ln q / N)$ with `expm1` to avoid cancellation.
Inputs are $\mu$, $\sigma$, $\xi$, year count $N$ (100–5000 years), and a random seed.
The first table compares exceedance year counts $K$ at five $T$ values with expectations $N/T$, binomial 95% ranges, and both tail probabilities; the second compares the record maximum with its central 95% range.

```rust
//| id: random-gev-simulated-record
//| ref: random-gev-simulated-record
//| title: "Compare simulated annual maximum discharge records with return-level curves"
//| run: reactive
//| uses: [random-gev-record-model]
//| crates: [scioxide-core, scioxide-random]
//| inputs:
//|   location: {"type":"range","label":"Location μ [m³/s]","min":800,"max":1600,"step":50,"value":1200}
//|   scale: {"type":"range","label":"Scale σ [m³/s]","min":200,"max":500,"step":25,"value":350}
//|   xi: {"type":"range","label":"Shape ξ [-] (Coles' sign, c = −ξ)","description":"Positive gives an unbounded heavy tail, zero gives Gumbel, and negative gives upper endpoint μ − σ/ξ.","min":-0.3,"max":0.4,"step":0.05,"value":0.15}
//|   years: {"type":"range","label":"Years to simulate N [years]","description":"Change the upper-tail point count and expected exceedance year count N/T.","min":100,"max":5000,"step":100,"value":2000}
//|   seed: {"type":"range","label":"Random seed [-]","min":1,"max":1000,"step":1,"value":123}
//| cases:
//|   - {"id":"short-record","label":"N = 100 years","description":"The expectation N/T is around 1 year, and the lower endpoint of the binomial 95% range is 0 for T ≥ 50 years.","inputs":{"years":100}}
//|   - {"id":"bounded","label":"ξ = −0.2","description":"The curve is concave and approaches the upper endpoint 2950 m³/s. The exceedance year table stays the same as the default.","inputs":{"xi":-0.2}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"exceedances","path":"/rows/2/1","range":{"min":5,"max":40}}
//|       - {"artifact":"exceedances","path":"/rows/2/3","equals":12}
//|       - {"artifact":"exceedances","path":"/rows/2/4","equals":29}
//|       - {"artifact":"maximum","path":"/rows/0/1","approx":{"value":4865.918806954238,"atol":1e-6}}
//|       - {"artifact":"maximum","path":"/rows/0/2","approx":{"value":11532.021729320773,"atol":1e-5}}
//|   - case: short-record
//|     expect:
//|       - {"artifact":"exceedances","path":"/rows/2/3","equals":0}
//|       - {"artifact":"exceedances","path":"/rows/2/4","equals":3}
//|   - case: bounded
//|     expect:
//|       - {"artifact":"exceedances","path":"/rows/2/1","range":{"min":5,"max":40}}
use scioxide_core::RealScalar;
use scioxide_random::{
    Affine, Binomial, Cdf, Distribution, GumbelRight, InverseSurvival, Quantile, SeedableRng,
    SplitMix64, Survival,
};

let law = annual_maximum_law(location, scale, xi)?;
let gumbel =
    Affine::new(GumbelRight::<f64>::new(), location, scale).map_err(|e| e.to_string())?;
let n = years as usize;
let mut rng = SplitMix64::from_seed(seed as u64);
let mut flows = Vec::with_capacity(n);
for _ in 0..n {
    flows.push(law.sample(&mut rng).map_err(|e| e.to_string())?);
}
flows.sort_by(f64::total_cmp);
let mut theory = Vec::new();
let mut reference = Vec::new();
for k in 0..=64 {
    let t = RealScalar::powf(10.0, 0.05 + 3.95 * k as f64 / 64.0);
    theory.push([t, law.isf(1.0 / t).map_err(|e| e.to_string())?]);
    reference.push([t, gumbel.isf(1.0 / t).map_err(|e| e.to_string())?]);
}
// Gringorten positions p_i = (i − 0.44)/(N + 0.12). Keep only points at least 0.04 apart in log₁₀ T.
let mut empirical = Vec::new();
let mut last_t = f64::INFINITY;
for (i, &x) in flows.iter().enumerate().rev() {
    let t = 1.0 / (1.0 - (i as f64 + 0.56) / (n as f64 + 0.12));
    if t < 1.2 {
        break;
    }
    if RealScalar::log10(last_t / t) >= 0.04 {
        empirical.push([t, x]);
        last_t = t;
    }
}
emit_chart!(
    serde_json::json!({
        "kind": "line",
        "xLabel": "Return period T [years]",
        "yLabel": "Annual maximum discharge [m³/s]",
        "xType": "log",
        "xMin": 1,
        "xMax": 10000,
        "dataZoom": true,
        "tooltip": true,
        "annotations": [{"kind": "line", "axis": "x", "value": 100, "label": "T = 100 years"}],
        "series": [
            {"name": "GEV z_T", "points": theory, "style": {"lineType": "dashed"}},
            {"name": "Gumbel（ξ = 0）", "points": reference, "style": {"lineType": "dotted"}},
            {
                "name": "Simulated record (Gringorten positions)",
                "points": empirical,
                "style": {"lineType": "dotted", "showSymbol": true, "symbol": "circle"}
            }
        ]
    }),
    metadata = serde_json::json!({ "id": "levels" })
);
let mut counts = Vec::new();
for t in [10_u32, 50, 100, 200, 500] {
    let p = 1.0 / f64::from(t);
    let z = law.isf(p).map_err(|e| e.to_string())?;
    let k = flows.iter().filter(|&&x| x > z).count();
    // K ~ Binomial(N, 1/T). Central 95% range and both tail probabilities of the observed K.
    let binomial = Binomial::new(n, p).map_err(|e| e.to_string())?;
    let low = binomial.quantile(0.025).map_err(|e| e.to_string())?;
    let high = binomial.quantile(0.975).map_err(|e| e.to_string())?;
    let below = binomial.cdf(k).map_err(|e| e.to_string())?;
    let above = if k == 0 {
        1.0
    } else {
        binomial.sf(k - 1).map_err(|e| e.to_string())?
    };
    counts.push((t, k, n as f64 * p, low, high, below, above));
}
let fixed1 = serde_json::json!({ "fractionDigits": 1 });
let sig3 = serde_json::json!({ "significantDigits": 3 });
let columns = serde_json::json!([
    { "key": "0", "label": "T [years]", "type": "integer" },
    { "key": "1", "label": "Exceedance years K [years]", "type": "integer" },
    { "key": "2", "label": "Expectation N/T [years]", "type": "number", "format": fixed1 },
    { "key": "3", "label": "Binomial 95% range lower endpoint [years]", "type": "integer" },
    { "key": "4", "label": "Binomial 95% range upper endpoint [years]", "type": "integer" },
    { "key": "5", "label": "P(K′ ≤ K) [-]", "type": "number", "format": sig3 },
    { "key": "6", "label": "P(K′ ≥ K) [-]", "type": "number", "format": sig3 }
]);
emit_table_with_columns!(
    columns,
    counts,
    metadata = serde_json::json!({ "id": "exceedances" })
);
// Distribution of maximum X_(N): P(X_(N) ≤ z) = F(z)^N. Central 95% endpoints are isf(1 − q^(1/N)).
let mut ends = Vec::new();
for q in [0.025_f64, 0.975] {
    let tail = -RealScalar::exp_m1(RealScalar::ln(q) / n as f64);
    ends.push(law.isf(tail).map_err(|e| e.to_string())?);
}
let columns = serde_json::json!([
    { "key": "0", "label": "Record maximum [m³/s]", "type": "number", "format": fixed1 },
    { "key": "1", "label": "2.5% quantile of maximum [m³/s]", "type": "number", "format": fixed1 },
    { "key": "2", "label": "97.5% quantile of maximum [m³/s]", "type": "number", "format": fixed1 }
]);
emit_table_with_columns!(
    columns,
    vec![(flows[n - 1], ends[0], ends[1])],
    metadata = serde_json::json!({ "id": "maximum" })
);
```

With the default inputs ($N = 2000$ years, seed 123), points at $T \le 100$ years lie near the dashed line, while higher points lie above it.
The maximum 8885.9 m³/s has plotting position $T_N = (N + 0.12)/0.56 \approx 3572$ years and exceeds the dashed-line discharge of 6826 m³/s there by about 2060 m³/s.
The maximum's central 95% range is 4865.9–11532.0 m³/s, containing this record's maximum.
Read deviations of upper-tail points from the dashed line as fluctuations in the order statistics of one record.

Writing $u = -\ln y_T$, the difference between the GEV and Gumbel return levels is $\sigma[(e^{\xi u} - 1)/\xi - u]$.
The exponential function is convex, so $e^{\xi u} \ge 1 + \xi u$; the difference is nonnegative for $\xi > 0$ and nonpositive for $\xi < 0$, vanishing only at $u = 0$, or $T = 1/(1 - e^{-1}) \approx 1.58$ years.
For the default $\xi = 0.15$, the dotted Gumbel curve touches the dashed curve there and lies below it everywhere else, so assuming $\xi = 0$ underestimates the upper tail.

The 100-year discharge is exceeded in $K = 25$ years, within the binomial 95% range of 12–29 years with expectation 20 years.
At 500 years, $K = 9$ exceedance years lie above the range of 1–8 years, with $P(K' \ge 9) = 0.021$.
Exceedances at the five $T$ values share the same record's upper observations and are not mutually independent.
At $T = 500$ years, $K$ depends only on the record's top nine points; it depends on fewer maxima for larger $T$ values.

In the “N = 100 years” case, the binomial 95% range has lower endpoint 0 for $T \ge 50$ years, and the 100-year range is 0–3 years.
For this seed, the 2000-year record maximum of 8885.9 m³/s occurs in the first 100 years, exceeding the 100-year record maximum's 97.5% quantile of 6947.6 m³/s.
By definition, a 100-year record maximum exceeds its 97.5% quantile with probability 2.5%; this seed produces a record in that tail.
In the “ξ = −0.2” case, the curve is concave and approaches the upper endpoint 2950 m³/s; the record maximum is 2699.3 m³/s, while the exceedance year table matches the default.
This confirms $\{X > z_T\} = \{U > 1 - 1/T\}$ for samples generated by inverse transformation.

## Exceedance counts in short records

The probability that a record of $n$ years has no exceedance of the $T$-year discharge is

$$
P(K = 0) = \left(1 - \frac{1}{T}\right)^n \approx e^{-n/T}
$$

which is 0.366 for $n = T = 100$.
The following cell simulates $R$ records of $n$ years for the default river and counts years $K$ exceeding $z_T$ (`isf(1/T)`) in each record.
Because the distribution of $K$ is independent of $\mu, \sigma, \xi$, inputs are limited to return period $T$ (10–500 years), record length $n$ (10–300 years), record count $R$ (200–4000), and a seed.

The plot shows the probability mass $P(K = k)$ of `Binomial` as a dashed step curve and record proportions as symbols, with the proportions' 95% range $P \pm 1.96\sqrt{P(1-P)/R}$ as a band around the probability mass.
The first table gives the record count, proportion, binomial probability, and proportion SE $\sqrt{P(1-P)/R}$ for each $k$.
The second table compares the hand calculation $(1 - 1/T)^n$ of $P(K = 0)$, its Poisson approximation, the simulated record proportion, the binomial 95% range, and the normal approximation range.

```rust
//| id: random-gev-record-exceedance
//| ref: random-gev-record-exceedance
//| title: "Occurrences of a T-year discharge in finite records"
//| run: reactive
//| uses: [random-gev-record-model]
//| crates: [scioxide-core, scioxide-random]
//| inputs:
//|   return_period: {"type":"range","label":"Return period T [years]","min":10,"max":500,"step":10,"value":100}
//|   record_years: {"type":"range","label":"Years per record n [years]","min":10,"max":300,"step":10,"value":100}
//|   records: {"type":"range","label":"Record count R [records]","description":"Change the proportion standard error √(P(1−P)/R).","min":200,"max":4000,"step":200,"value":2000}
//|   seed: {"type":"range","label":"Random seed [-]","min":1,"max":1000,"step":1,"value":7}
//| cases:
//|   - {"id":"thirty-years","label":"n = 30 years","description":"74.0% of records never contain a 100-year discharge, and the binomial 95% range is 0–2 years.","inputs":{"record_years":30}}
//|   - {"id":"ten-year-flood","label":"T = 10 years","description":"With expectation 10 years, the distribution is nearly symmetric, and the binomial 95% range 5–16 years approaches the normal approximation 4.12–15.88 years.","inputs":{"return_period":10}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"zero-count","path":"/rows/0/1","approx":{"value":0.3660323412732292,"atol":1e-10}}
//|       - {"artifact":"zero-count","path":"/rows/2/1","range":{"min":0.32,"max":0.42}}
//|       - {"artifact":"zero-count","path":"/rows/4/1","equals":3}
//|       - {"artifact":"zero-count","path":"/rows/5/1","approx":{"value":-0.9501753767289751,"atol":1e-9}}
//|   - case: thirty-years
//|     expect:
//|       - {"artifact":"zero-count","path":"/rows/0/1","approx":{"value":0.7397003733882802,"atol":1e-10}}
//|       - {"artifact":"zero-count","path":"/rows/2/1","range":{"min":0.69,"max":0.79}}
//|   - case: ten-year-flood
//|     expect:
//|       - {"artifact":"zero-count","path":"/rows/3/1","equals":5}
//|       - {"artifact":"zero-count","path":"/rows/4/1","equals":16}
use scioxide_core::RealScalar;
use scioxide_random::{
    Binomial, Distribution, InverseSurvival, Mass, Quantile, SeedableRng, SplitMix64,
};

// Default river (μ = 1200 m³/s, σ = 350 m³/s, ξ = 0.15). The distribution of K is independent of these three values.
let law = annual_maximum_law(1200.0, 350.0, 0.15)?;
let level = law.isf(1.0 / return_period).map_err(|e| e.to_string())?;
let (n, r) = (record_years as usize, records as usize);
let mut rng = SplitMix64::from_seed(seed as u64);
let mut tally = vec![0_usize; n + 1];
for _ in 0..r {
    let mut k = 0;
    for _ in 0..n {
        if law.sample(&mut rng).map_err(|e| e.to_string())? > level {
            k += 1;
        }
    }
    tally[k] += 1;
}
let p = 1.0 / return_period;
let binomial = Binomial::new(n, p).map_err(|e| e.to_string())?;
let k_max = binomial.quantile(0.9999).map_err(|e| e.to_string())?;
let last = tally.iter().rposition(|&c| c > 0).ok_or("No records")?;
let k_max = k_max.max(last);
let (mut rows, mut theory, mut observed, mut band) =
    (Vec::new(), Vec::new(), Vec::new(), Vec::new());
for k in 0..=k_max {
    let pmf = binomial.pmf(k).map_err(|e| e.to_string())?;
    let share = tally[k] as f64 / r as f64;
    let se = RealScalar::sqrt(pmf * (1.0 - pmf) / r as f64);
    rows.push((k, tally[k], share, pmf, se));
    theory.push([k as f64, pmf]);
    observed.push([k as f64, share]);
    band.push([k as f64, pmf, pmf - 1.96 * se, pmf + 1.96 * se]);
}

        "yLabel": "Probability / record proportion [-]",
        "yMin": 0,
        "dataZoom": true,
        "tooltip": true,
        "layers": [
            {"id": "range", "kind": "band", "name": "95% range for proportions", "points": band},
            {
                "id": "binomial",
                "kind": "line",
                "name": "Binomial(n, 1/T) probability",
                "style": {"lineType": "dashed", "step": "middle"},
                "points": theory
            },
            {"id": "records", "kind": "scatter", "name": "Simulated record proportion", "points": observed}
        ]
    }),
    metadata = serde_json::json!({ "id": "distribution" })
);
let sig4 = serde_json::json!({ "significantDigits": 4 });
let sig3 = serde_json::json!({ "significantDigits": 3 });
let columns = serde_json::json!([
    { "key": "0", "label": "K [years]", "type": "integer" },
    { "key": "1", "label": "Records [records]", "type": "integer" },
    { "key": "2", "label": "Fraction [-]", "type": "number", "format": sig4 },
    { "key": "3", "label": "Binomial probability [-]", "type": "number", "format": sig4 },
    { "key": "4", "label": "Proportion SE [-]", "type": "number", "format": sig3 }

    columns,
    rows,
    metadata = serde_json::json!({ "id": "counts" })

let mean = n as f64 * p;
let sd = RealScalar::sqrt(mean * (1.0 - p));
let low = binomial.quantile(0.025).map_err(|e| e.to_string())?;
let high = binomial.quantile(0.975).map_err(|e| e.to_string())?;
let summary = vec![
    (
        "P(K = 0)：(1 − 1/T)^n [-]",
        RealScalar::powf(1.0 - p, n as f64),
    ),
    (
        "P(K = 0): Poisson approximation e^(−n/T) [-]",
        RealScalar::exp(-mean),
    ),
    ("P(K = 0): record proportion [-]", tally[0] as f64 / r as f64),
    ("Binomial 95% range lower endpoint [years]", low as f64),
    ("Binomial 95% range upper endpoint [years]", high as f64),
    ("Normal approximation n/T − 1.96 SD [years]", mean - 1.96 * sd),
    ("Normal approximation n/T + 1.96 SD [years]", mean + 1.96 * sd),
];
let columns = serde_json::json!([
    { "key": "0", "label": "Quantity" },
    { "key": "1", "label": "Value", "type": "number", "format": sig4 }
]);
emit_table_with_columns!(
    columns,
    summary,
    metadata = serde_json::json!({ "id": "zero-count" })
);
```

With the default inputs ($T = 100$ years, $n = 100$ years, $R = 2000$ records, seed 7), the hand calculation of $P(K = 0)$ is 0.3660 and the Poisson approximation is 0.3679.
The proportion of simulated records with no exceedances is 0.3805, differing by $+1.35$ SE for SE 0.0108.
The proportions 0.361, 0.1865, and 0.0545 for $K = 1, 2, 3$ are also within 2 SE of their binomial probabilities 0.370, 0.185, and 0.061.
The plotted symbols lie inside the band for $K \le 5$, but those for $K = 6, 7$ (3 records and 1 record) lie above it.
Expected record counts from binomial probabilities are 0.93 and 0.13; for $K$ with only a few records, the normal approximation band cannot identify outliers.
The binomial 95% range is 0–3 years, while the normal approximation −0.95–2.95 years has a negative lower endpoint.
About 37% of 100-year records never contain a 100-year discharge, so the record maximum alone cannot determine that discharge.

In the “n = 30 years” case, $P(K = 0) = 0.7397$ (simulated records 0.751), so about three quarters of 30-year records have no exceedance of the 100-year discharge.
In the “T = 10 years” case, the expectation rises to 10 years and the distribution becomes nearly symmetric, bringing the binomial 95% range 5–16 years close to the normal approximation 4.12–15.88 years.

## Estimation from observed exceedance counts

This page simulated records with known parameters.
To estimate return levels from actual records, substitute maximum likelihood estimates of $(\mu, \sigma, \xi)$ into the [closed-form return level](oxref:random-gev-return-level-closed-form) and report the result together with its confidence interval.
To construct a confidence interval directly for the annual exceedance probability $1/T$ from observed exceedance years $K$, `binomial_confidence_limits` in scioxide-stats returns a Clopper–Pearson interval.
For short records with $K$ equal to 0 or 1, intervals are wide and the record alone cannot tightly constrain $z_T$.

## Summary

The number of years exceeding $z_T$ follows the binomial distribution $\mathrm{Binomial}(N, 1/T)$, so comparisons with expectations of a few years or fewer should use quantiles and tail probabilities from `Binomial` rather than a normal approximation.
Inverse-transform samples satisfy $\{X > z_T\} = \{U > 1 - 1/T\}$, so exceedance year counts with the same seed are independent of $\mu, \sigma, \xi$.
The record's upper points are a small, highly variable set of order statistics; interpret the record maximum by comparison with ranges from distribution $F(z)^N$.
A record of $n = T$ years has about a 37% chance of having no exceedance of the discharge with that return period, and its maximum is not an estimate of $z_T$.
