When approximating an integral $I = \int f(\mathbf{x})\,d\mathbf{x}$ on the unit hypercube $[0, 1)^d$ by the point average $\hat{I}_N = \frac{1}{N}\sum_{n=1}^{N} f(\mathbf{x}_n)$, choosing independent uniform random points gives Monte Carlo (MC), while choosing a low-discrepancy sequence gives quasi-Monte Carlo (QMC).
This example compares their errors on an integrand with an analytical solution and measures randomized QMC error through independent replicates.
The theory of sequence construction and randomization is in [Sobol sequences and Gray codes](oxref:random-qmc-sobol-gray) and [Error estimation through randomization and replication](oxref:random-qmc-replicate-error).
[Estimate standard errors with QmcReplicatePlan](../qmc-replicate-standard-error/) covers attaching standard errors to integrals without known analytical solutions.

## Mean transmittance through absorbing layers

Consider light passing through $d$ absorbing layers in succession.
When each layer $j$ has independently varying optical thickness $x_j$ [-] uniform on $[0, 1)$, the combined transmittance is $f(\mathbf{x}) = \exp(-\sum_j x_j)$ and the mean transmittance is

$$
I = \int_{[0, 1)^d} \exp\Bigl(-\sum_{j=1}^d x_j\Bigr)\,d\mathbf{x} = \prod_{j=1}^d \int_0^1 e^{-x_j}\,dx_j = (1 - e^{-1})^d
$$


The integrand factors by coordinate, so the integral also factors into one-dimensional integrals.
For $d = 4$, $I = 0.15966$.

The MC estimator is unbiased, with variance $\sigma_f^2 / N$.
Here $\sigma_f^2 = \mathrm{E}[f^2] - I^2$ is the variance at one point; because $\mathrm{E}[f^2] = \prod_j \int_0^1 e^{-2x}\,dx = \bigl(\tfrac{1 - e^{-2}}{2}\bigr)^d$,

$$
\sigma_f^2 = \Bigl(\frac{1 - e^{-2}}{2}\Bigr)^d - (1 - e^{-1})^{2d}
$$


The MC root mean square error (RMSE) is $\sigma_f/\sqrt{N}$ and decreases as $N^{-1/2}$.

The following definitions block shares the transmittance $f$, analytical solution $I$, and one-point standard deviation $\sigma_f$ between the two cells on this page.
$\sigma_f$ is an independent reference used for the theoretical MC error.

```rust
//| id: random-transmittance-model
//| kind: definitions
//| title: "Absorbing-layer transmittance and analytical solution"
//| crates: [scioxide-core]
use scioxide_core::RealScalar;

/// Transmittance f(x) = exp(−Σⱼ xⱼ).
pub(crate) fn transmittance(x: &[f64]) -> f64 {
    RealScalar::exp(-x.iter().sum::<f64>())
}

/// Analytical solution I = (1 − e⁻¹)ᵈ.
pub(crate) fn exact_mean(d: usize) -> f64 {
    RealScalar::powi(1.0 - RealScalar::exp(-1.0_f64), d as i32)
}

/// One-point standard deviation σ_f = √(((1 − e⁻²)/2)ᵈ − I²). MC RMSE is σ_f/√N.
pub(crate) fn mc_sigma(d: usize) -> f64 {
    let second = RealScalar::powi(0.5 * (1.0 - RealScalar::exp(-2.0_f64)), d as i32);
    let mean = exact_mean(d);
    RealScalar::sqrt(second - mean * mean)
}
```

## QMC error and randomization

$f$ is smooth and has finite Hardy–Krause variation $V_{\mathrm{HK}}(f)$.
The Koksma–Hlawka inequality bounds QMC error by $V_{\mathrm{HK}}(f)\,D_N^*$, and Sobol star discrepancy is $D_N^* = O((\log N)^d / N)$, so the bound decreases faster than MC for small $d$ and large $N$.
However, this inequality is an upper bound, and both $V_{\mathrm{HK}}$ and $D_N^*$ are difficult to compute in practice, so it cannot estimate the error magnitude.
Instead, randomize the sequence and measure error from variation between independent randomized replicates.

There are two randomization methods for Sobol sequences.
`QmcPlan::with_scramble(QmcScramble::DigitalShift(seed))` shifts each coordinate's 64-bit word by exclusive-or with a word constructed from the seed and coordinate index (a digital shift).
This preserves the sequence's net structure; with uniform seeds, each coordinate is uniform on a grid of spacing $2^{-53}$.
However, all coordinate shifts come from one seed, so their independence is not guaranteed and this randomization alone does not establish an unbiased estimator.

`QmcPlan::with_randomization(QmcRandomization::LinearMatrixShift, rng)` draws 65 words per coordinate from the generator, multiplies by a lower-triangular 64 × 64 binary matrix with diagonal 1 (an invertible matrix over GF(2)), and then applies a digital shift (Matoušek's linear scramble).
Treating generator outputs as independent uniform random values makes each randomized point uniform on $[0, 1)^d$, giving an unbiased estimator apart from discretization on a grid of spacing $2^{-53}$.
Drawing from independent streams gives independent replicates.
Randomizations that mix digits can reduce variance faster than digital shifts for smooth integrands (Owen 1997 proved variance $O(N^{-3}(\log N)^{d-1})$ for nested uniform scrambling).

Both randomizations preserve the balance of initial blocks of $2^k$ points, the net property.
Therefore compare point counts $N$ that are powers of 2.

## Error curves for one point sequence

The following cell generates independent uniform points (`next_float` of `SplitMix64`) and a Sobol sequence randomized with `DigitalShift` from the same seed, plotting absolute errors $|\hat{I}_N - I|$ at $N = 16, 32, \dots, 2^m$ on logarithmic axes.
Inputs are dimension $d$, exponent $m$ setting the maximum point count $2^m$, and a random seed.
The dashed line is the theoretical MC RMSE $\sigma_f/\sqrt{N}$, indicating the typical MC error scale.
Omit points with exactly zero error because they cannot be plotted on logarithmic axes, while including all $N$ values in the table.

```rust
let mut pseudo = SplitMix64::from_seed(seed);
let plan = QmcPlan::sobol(d)
    .map_err(|e| e.to_string())?
    .with_scramble(QmcScramble::DigitalShift(seed))
    .map_err(|e| e.to_string())?;

        // Omit points with exactly zero error because logarithmic axes cannot show them.
        if mc_error > 0.0 {
            mc_curve.push([n as f64, mc_error]);
        }
        if qmc_error > 0.0 {
            qmc_curve.push([n as f64, qmc_error]);
        }
        reference.push([n as f64, scale]);

    { "key": "3", "label": "σ_f/√N [-]", "type": "number", "format": sci3 }
```

MC symbols fluctuate around the dashed line while descending with slope $-1/2$; Sobol symbols descend more steeply.
If MC symbols persistently remain more than an order of magnitude from the dashed line, suspect random-number quality or the integrand implementation.

With the default inputs ($d = 4$, $N = 2^{12}$, seed 41), errors at $N = 4096$ are $5.88 \times 10^{-4}$ for MC ($\sigma_f/\sqrt{N} = 1.52 \times 10^{-3}$) and $3.99 \times 10^{-6}$ for Sobol.
At $d = 8$, errors at $N = 4096$ are $4.70 \times 10^{-4}$ for MC ($\sigma_f/\sqrt{N} = 3.73 \times 10^{-4}$) and $1.70 \times 10^{-5}$ for Sobol.
Sobol symbols barely descend after $N = 512$; increasing dimension reduces the advantage at a given point count.
The error of one point sequence is one randomization realization, so its curve can dip deeply by chance; this curve alone cannot determine the ratio between the methods.

## RMSE and convergence order from independent randomized replicates

Estimate RMSE as $\sqrt{\frac{1}{R}\sum_r e_r^2}$ from errors $e_r = \hat{I}_N^{(r)} - I$ in $R$ independent replicates.
Using the analytical solution $I$ makes this quantity measure RMSE including any estimator bias.
When errors are normally distributed with mean 0, $\sum_r e_r^2 / \mathrm{RMSE}^2$ follows a chi-squared distribution with $R$ degrees of freedom, with relative standard deviation $\sqrt{2/R}$.
Taking the square root approximately halves the relative error, so the estimated RMSE has relative standard error about $1/\sqrt{2R}$.

The following cell selects a stream for each replicate with `split` from root generator `Pcg64` seeded with $s$ and measures RMSE for $N = 32, 64, \dots, 2^m$ using $d = 4$.
Replicate $r$ uses stream $2r$ for independent uniform points and stream $2r + 1$ for Sobol randomization, so neither replicates nor methods share random values.
Each replicate successively records means over the first $N$ points of one sequence, so errors at different $N$ within a replicate are correlated.
The randomization input selects `LinearMatrixShift` (drawing 65 words per coordinate from the stream) or `DigitalShift` (using one stream word as a seed).

The first plot compares measured RMSE (symbols) with the MC theoretical value $\sigma_f/\sqrt{N}$ (dashed) on logarithmic axes.
The second plots the ratio of MC RMSE to theory with estimated $\pm 2$ SE error bars, comparing it against the line at 1.
These two plots and the previous cell's plot share point count $N$ on the horizontal axis, so their zooming and panning are linked.
The table gives RMSE at each $N$, the MC RMSE standard error (relative $1/\sqrt{2R}$), and the ratio of the two RMSEs.
The second table gives slopes from least-squares fitting of $\log \mathrm{RMSE}$ against $\log N$, estimates of convergence order.

```rust
//| id: random-rqmc-replications
//| ref: random-rqmc-replications
//| title: "Compare RMSE and convergence order using independent randomized replicates"
//| run: reactive
//| uses: [random-transmittance-model]
//| crates: [scioxide-core, scioxide-random]
//| inputs:
//|   randomization: {"type":"select","label":"Sobol randomization","options":["LinearMatrixShift (65 words per coordinate)","DigitalShift (one-word seed)"],"value":"LinearMatrixShift (65 words per coordinate)"}
//|   points_per_replication_exponent: {"type":"range","label":"Maximum point count exponent m (N = 2ᵐ)","min":7,"max":12,"step":1,"value":10}
//|   randomization_count: {"type":"range","label":"Replicate count R","description":"Relative standard error of the RMSE estimate is 1/√(2R).","min":8,"max":48,"step":4,"value":24}
//|   base_seed: {"type":"range","label":"Root-generator seed s","min":1,"max":1000,"step":1,"value":100}
//| cases:
//|   - {"id":"digital-shift","label":"DigitalShift","description":"A digital shift alone gives a shallower Sobol RMSE slope.","inputs":{"randomization":"DigitalShift (one-word seed)"}}
//|   - {"id":"more-points","label":"N = 2¹²","description":"More points widen the RMSE ratio.","inputs":{"points_per_replication_exponent":12}}
//|   - {"id":"other-seed","label":"Root seed 1","description":"MC RMSE remains close to theory with another set of replicates.","inputs":{"base_seed":1}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"rmse","path":"/rows/5/0","equals":1024}
//|       - {"artifact":"rmse","path":"/rows/5/3","approx":{"value":3.0368e-3,"atol":1e-6}}
//|       - {"artifact":"rmse","path":"/rows/5/1","range":{"min":1.5e-3,"max":4.5e-3}}
//|       - {"artifact":"slopes","path":"/rows/0/0","range":{"min":-0.8,"max":-0.2}}
//|   - case: digital-shift
//|     expect:
//|       - {"artifact":"slopes","path":"/rows/0/0","range":{"min":-0.8,"max":-0.2}}
//|   - case: more-points
//|     expect:
//|       - {"artifact":"slopes","path":"/rows/0/0","range":{"min":-0.7,"max":-0.3}}
//|   - case: other-seed
//|     expect:
//|       - {"artifact":"rmse","path":"/rows/5/1","range":{"min":1.5e-3,"max":4.5e-3}}
use scioxide_core::RealScalar;
use scioxide_random::{
    BitGenerator, Pcg64, QmcPlan, QmcRandomization, QmcScramble, QuasiRng, Rng, SeedableRng,
    SplittableRng,
};

let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let fixed1 = serde_json::json!({ "fractionDigits": 1 });
let fixed2 = serde_json::json!({ "fractionDigits": 2 });
let d = 4_usize;
let m = points_per_replication_exponent.round() as u32;
let (n_max, r) = (1_usize << m, randomization_count.round() as usize);
let (exact, sigma) = (exact_mean(d), mc_sigma(d));
let matrix_scramble = randomization.starts_with("LinearMatrixShift");
// squares[k] is the sum of squared errors for N = 2^(k+5) (MC, Sobol).
let levels = (m - 4) as usize;
let mut squares = vec![[0.0_f64; 2]; levels];
let (mut pseudo_point, mut point) = (vec![0.0_f64; d], vec![0.0_f64; d]);
let root = Pcg64::from_seed(base_seed.round() as u64);
for replication in 0..r as u64 {
    // Replicate r uses root stream 2r for MC and 2r + 1 for Sobol randomization.
    let mut pseudo = root.split(2 * replication).map_err(|e| e.to_string())?;
    let mut stream = root.split(2 * replication + 1).map_err(|e| e.to_string())?;
    let base = QmcPlan::sobol(d).map_err(|e| e.to_string())?;
    let plan = if matrix_scramble {
        base.with_randomization(QmcRandomization::LinearMatrixShift, &mut stream)
    } else {
        let seed = stream.next_u64().map_err(|e| e.to_string())?;
        base.with_scramble(QmcScramble::DigitalShift(seed))
    }
    .map_err(|e| e.to_string())?;
    let mut sobol = plan.sequence::<f64>().map_err(|e| e.to_string())?;
    let (mut mc_sum, mut qmc_sum) = (0.0_f64, 0.0_f64);
    for n in 1..=n_max {
        for value in pseudo_point.iter_mut() {
            *value = pseudo.next_float().map_err(|e| e.to_string())?;
        }
        mc_sum += transmittance(&pseudo_point);
        sobol
            .next_point_into(&mut point)
            .map_err(|e| e.to_string())?;
        qmc_sum += transmittance(&point);
        if n >= 32 && n.is_power_of_two() {
            let k = n.trailing_zeros() as usize - 5;
            let (e_mc, e_qmc) = (mc_sum / n as f64 - exact, qmc_sum / n as f64 - exact);
            squares[k][0] += e_mc * e_mc;
            squares[k][1] += e_qmc * e_qmc;
        }
    }
}
// Relative standard error of estimated RMSE: 1/√(2R) (for normally distributed, mean-zero errors).
let relative_se = 1.0 / RealScalar::sqrt(2.0 * r as f64);
let (mut mc_curve, mut qmc_curve, mut theory_curve) = (Vec::new(), Vec::new(), Vec::new());
let (mut ratio_bars, mut rows) = (Vec::new(), Vec::new());
for (k, square) in squares.iter().enumerate() {
    let n = 1_usize << (k + 5);
    let theory = sigma / RealScalar::sqrt(n as f64);
    let mc = RealScalar::sqrt(square[0] / r as f64);
    let qmc = RealScalar::sqrt(square[1] / r as f64);
    mc_curve.push([n as f64, mc]);
    qmc_curve.push([n as f64, qmc]);
    theory_curve.push([n as f64, theory]);
    let ratio = mc / theory;
    ratio_bars.push([
        n as f64,
        ratio,
        ratio * (1.0 - 2.0 * relative_se),
        ratio * (1.0 + 2.0 * relative_se),
    ]);
    rows.push((n, mc, mc * relative_se, theory, qmc, mc / qmc));
}
// Convergence order: slope from least-squares fitting log RMSE against log N.
let slope = |curve: &[[f64; 2]]| {
    let logs: Vec<[f64; 2]> = curve
        .iter()
        .map(|p| [RealScalar::ln(p[0]), RealScalar::ln(p[1])])
        .collect();
    let count = logs.len() as f64;
    let mean_x = logs.iter().map(|p| p[0]).sum::<f64>() / count;
    let mean_y = logs.iter().map(|p| p[1]).sum::<f64>() / count;
    let sxy: f64 = logs.iter().map(|p| (p[0] - mean_x) * (p[1] - mean_y)).sum();
    let sxx: f64 = logs.iter().map(|p| (p[0] - mean_x) * (p[0] - mean_x)).sum();
    sxy / sxx
};
emit_line_chart!(
    &vec![
        serde_json::json!({"name": "MC RMSE", "points": mc_curve, "style": {"symbol": "circle"}}),
        serde_json::json!({
            "name": "Randomized Sobol RMSE",
            "points": qmc_curve,
            "style": {"symbol": "triangle"}
        }),
        serde_json::json!({
            "name": "MC theory σ_f/√N",
            "points": theory_curve,
            "style": {"lineType": "dashed"}
        }),
    ],
    options = &serde_json::json!({
        "link": { "group": "sobol-points" },
        "xLabel": "Point count N [points]",
        "yLabel": "RMSE (R replicates) [-]",
        "xType": "log",
        "yType": "log"
    })
);
// Ratio of MC RMSE to theory ± 2 SE. Correct results scatter around 1.
emit_chart!(
    serde_json::json!({
        "kind": "errorbar",
        "link": { "group": "sobol-points" },
        "dataZoom": true,
        "tooltip": true,
        "xLabel": "Point count N [points]",
        "yLabel": "MC RMSE / σ_f√(1/N) [-]",
        "xType": "log",
        "yMin": 0.0,
        "yMax": 2.0,
        "series": [{ "name": "Ratio and ± 2 SE", "points": ratio_bars }],
        "annotations": [{ "kind": "line", "axis": "y", "value": 1.0, "label": "Theoretical value" }]
    }),
    metadata = serde_json::json!({ "id": "mc-ratio" })
);
let columns = serde_json::json!([
    { "key": "0", "label": "N [points]", "type": "integer" },
    { "key": "1", "label": "MC RMSE [-]", "type": "number", "format": sci3 },
    { "key": "2", "label": "SE of MC RMSE [-]", "type": "number", "format": sci3 },
    { "key": "3", "label": "MC theory σ_f/√N [-]", "type": "number", "format": sci3 },
    { "key": "4", "label": "Sobol RMSE [-]", "type": "number", "format": sci3 },
    { "key": "5", "label": "MC / Sobol ratio [-]", "type": "number", "format": fixed1 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "rmse" })
);
let slope_columns = serde_json::json!([
    { "key": "0", "label": "MC slope [-]", "type": "number", "format": fixed2 },
    { "key": "1", "label": "Randomized Sobol slope [-]", "type": "number", "format": fixed2 }
]);
emit_table_with_columns!(
    slope_columns,
    vec![(slope(&mc_curve), slope(&qmc_curve))],
    metadata = serde_json::json!({ "id": "slopes" })
);
```

MC symbols follow the dashed line with slope $-1/2$, and ratio error bars generally overlap the line at 1.
If the ratio persistently deviates from 1 by much more than its error bars, the MC sampling or theoretical calculation is incorrect.
Randomized Sobol symbols lie far below MC and descend more steeply.

With the default inputs (`LinearMatrixShift`, $N = 32$ through $1024$, $R = 24$, $s = 100$), MC RMSE at $N = 1024$ is $2.34 \times 10^{-3}$ (theory $3.04 \times 10^{-3}$), randomized Sobol RMSE is $1.77 \times 10^{-5}$, and their ratio is $132$.
The ratio of MC RMSE to theory is $0.77$, below 1 by about 1.6 times the estimated RMSE relative standard error $1/\sqrt{48} \approx 0.14$.
Point counts within the same replicate are correlated, so ratios at adjacent $N$ tend to deviate in the same direction.
Fitted slopes are $-0.50$ for MC and $-1.23$ for Sobol.

Switching randomization to `DigitalShift` leaves MC unchanged, makes the Sobol slope shallower at $-1.02$, and reduces the ratio at $N = 1024$ to $28.5$.
For this smooth integrand, digit-mixing `LinearMatrixShift` reduces error faster than a digital shift alone.
Extending to $N = 2^{12}$ gives slopes over `LinearMatrixShift` of $-0.50$ for MC and $-1.34$ for Sobol, widening the ratio at $N = 4096$ to $422$.
Changing the root seed to 1 gives slopes of $-0.52$ for MC and $-1.38$ for Sobol.
Slopes fitted from small point counts vary by about $\pm 0.2$ with seed and point-count range, so one fitted value does not establish a convergence order.
Estimated RMSE has relative standard error $1/\sqrt{2R} \approx 0.14$, so interpret ratios with a width of about $\pm 30\%$ as well.

## Summary

For smooth integrands, randomized Sobol RMSE decreases faster than that of independent uniform random points.
An error curve from one point sequence is one realization; estimate error magnitude from independent randomized replicates and interpret the estimated RMSE relative standard error $1/\sqrt{2R}$ as its uncertainty width.
`DigitalShift` makes each coordinate uniform but does not guarantee independence across coordinates, so use generator-based `LinearMatrixShift` for independent replicates.
Convergence orders fitted from small point counts vary with seed; check them over a wider point-count range.
