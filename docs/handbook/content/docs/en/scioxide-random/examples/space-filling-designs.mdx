Computer experiments run expensive simulations a limited number of times and use the results to examine relationships between inputs and outputs.
Input combinations should spread evenly through the space and cover each input's range uniformly.
This example constructs a Latin hypercube design with `latin_hypercube_into` and checks its promised properties, or invariants, using code separate from its construction.
The invariants checked are that each input's strata are used exactly once and that this property survives swap-based improvement.
Construction, variance theory, and closed-form discrepancy are explained in [Latin hypercube designs and discrepancy](../../algorithms/latin-hypercube-and-discrepancy/).
[Place soil sampling points with Poisson disk sampling](../field-sampling-poisson-disk/) covers another design that guarantees a minimum interpoint distance.

## Computer experiment inputs and Latin hypercubes

Suppose $n = 32$ combinations of the following three inputs are selected for a heat-exchanger simulation.

| Input | Symbol | Range |
|---|---|---|
| Mass flow rate | $\dot{m}$ | 0.1–0.5 kg/s |
| Inlet temperature | $T_{\mathrm{in}}$ | 20–80 °C |
| Wall thermal conductivity | $k$ | 15–400 W/(m·K) |

Construct the design in the unit cube $[0, 1)^3$ and map each coordinate $x$ to its physical quantity with $\text{lower bound} + (\text{upper bound} - \text{lower bound})\,x$.
This maps each axis stratum to a physical stratum, transferring the unit-cube property directly to the physical ranges.

A Latin hypercube (LHS) divides each input into 32 strata of width $1/32$ and places exactly one point in every stratum for every input.
`latin_hypercube` and its configurable form place one value in each input stratum $i$ and independently permute each column using Fisher–Yates.
Positions within strata are uniform random values by default and stratum midpoints with `LatinHypercubeOptions::with_centered(true)`.
This evenly examines each input's main effect but gives no guarantee about combinations of the three inputs.
The stratum property alone cannot exclude a design with all points near a diagonal.

## Discrepancy and swap-based improvement

Measure imbalance in combinations by the squared centered $L^2$ discrepancy (Hickernell),

$$
\mathrm{CD}^2 = \Bigl(\tfrac{13}{12}\Bigr)^d - \frac{2}{n}\sum_{i}\prod_{k}\Bigl(1 + \tfrac12 a_{ik} - \tfrac12 a_{ik}^2\Bigr) + \frac{1}{n^2}\sum_{i}\sum_{j}\prod_{k}\Bigl(1 + \tfrac12 a_{ik} + \tfrac12 a_{jk} - \tfrac12|x_{ik} - x_{jk}|\Bigr)
$$


Here $x_{ik}$ is coordinate $k$ of point $i$, $a_{ik} = |x_{ik} - \tfrac12|$, and $d = 3$ is the input count.
For each cube point $\mathbf{x}$, consider the box spanned by it and the vertex nearest to $\mathbf{x}$, square the difference between the fraction of design points in the box and its volume, and average over $\mathbf{x}$.
Summing this quantity over projections onto every coordinate subset gives $\mathrm{CD}^2$; smaller values mean a more uniform point distribution.
For independent uniform points, the expectation of $\mathrm{CD}^2$ is $\bigl((5/4)^d - (13/12)^d\bigr)/n$, giving $2.130 \times 10^{-2}$ for $d = 3$ and $n = 32$.

Setting `max_proposals` of `LatinHypercubeOptions` positive makes the function choose an input and propose swapping its values between two points.
Accept a proposal only if $\mathrm{CD}^2$ strictly decreases; otherwise restore the original values.
The two points are selected independently and may coincide; such a proposal changes nothing and counts as no improvement.
Swapping only permutes values within a column, preserving the use of each stratum exactly once.
Subtracting and recomputing only terms changed by the swap evaluates one proposal in $O(nd)$.
See [Swap-based improvement](oxref:random-sampling-exchange) for details.

`LatinHypercubeReport` returns termination status `termination()`, attempted proposal count `proposals()`, and $\mathrm{CD}^2$ before and after improvement (`initial_discrepancy()`, `final_discrepancy()`).
Without requested proposals, both $\mathrm{CD}^2$ values are `None` and termination status is `Complete`.
It stops with `BudgetExhausted` when proposals reach `max_proposals` or with `Stagnation` after `stagnation_limit` consecutive proposals without improvement (default 100).
Detecting cancellation or a deadline in `ExecutionContext` before a proposal stops with `Stopped`.
At every termination status, the design retains all 32 points and includes all accepted swaps so far.
Swapping is a greedy local search, so no termination status establishes that the design is optimal.
The cell therefore concludes satisfied for `Complete` and partial otherwise.

## Construct the design and check invariants

The following cell constructs a design in caller-provided output with `latin_hypercube_into` and reads `LatinHypercubeReport`.
`latin_hypercube_into` constructs the complete design in workspace and copies it to the output only on success.
`Rollback` specifies that failure restores the generator to its state before the call.
Inputs are the maximum number of swap proposals, whether to use stratum midpoints, and a random seed.

The cell performs three independent checks.
Recount the frequencies of strata $\lfloor 32 x \rfloor$ for each input and total the strata whose counts are not 1.
Recompute the final $\mathrm{CD}^2$ in two ways: with `DiscrepancyMethod::Centered` of `discrepancy` and directly from the formula above in the cell.
Also construct the design from the same seed with the owning form `latin_hypercube_with_options(n, d, rng, options)` and find the maximum difference between the two forms.

The scatter plot shows the flow-rate/inlet-temperature projection in physical units.
The upper table gives the progression of $\mathrm{CD}^2$ and comparison references; the lower table gives invariant checks.

```rust
//| id: random-lhs-marginal-invariants
//| ref: random-lhs-marginal-invariants
//| title: "Check that Latin hypercube swaps preserve one use of every stratum"
//| run: reactive
//| crates: [scioxide-core, scioxide-random]
//| inputs:
//|   proposal_limit: {"type":"range","label":"Swap proposal limit [proposals]","min":0,"max":512,"step":32,"value":128}
//|   centered: {"type":"checkbox","label":"Use stratum midpoints (centered)","value":false}
//|   seed: {"type":"range","label":"Random seed","min":1,"max":1000,"step":1,"value":42}
//| cases:
//|   - {"id":"no-optimization","label":"Proposal limit 0","description":"Perform no swaps; termination status is Complete and reported discrepancy is None.","inputs":{"proposal_limit":0}}
//|   - {"id":"long-optimization","label":"Proposal limit 512","description":"Quadrupling proposals lowers CD² further and stops at the limit with BudgetExhausted.","inputs":{"proposal_limit":512}}
//|   - {"id":"centered","label":"Stratum midpoints","description":"Placing points at stratum midpoints still uses each stratum once.","inputs":{"centered":true}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"discrepancy","path":"/rows/0/0","equals":128}
//|       - {"artifact":"discrepancy","path":"/rows/0/1","approx":{"value":3.503e-3,"atol":2e-6}}
//|       - {"artifact":"discrepancy","path":"/rows/0/2","approx":{"value":1.685e-3,"atol":2e-6}}
//|       - {"artifact":"discrepancy","path":"/rows/0/3","range":{"min":0,"max":0}}
//|       - {"artifact":"discrepancy","path":"/rows/0/4","approx":{"value":2.1304e-2,"atol":1e-6}}
//|       - {"artifact":"invariants","path":"/rows/0/0","equals":0}
//|       - {"artifact":"invariants","path":"/rows/0/1","range":{"min":0,"max":1e-14}}
//|       - {"artifact":"invariants","path":"/rows/0/2","equals":0}
//|       - {"path":"/outputs/3/state","equals":"partial"}
//|   - case: no-optimization
//|     expect:
//|       - {"artifact":"discrepancy","path":"/rows/0/1","equals":null}
//|       - {"artifact":"invariants","path":"/rows/0/0","equals":0}
//|       - {"path":"/outputs/3/state","equals":"satisfied"}
//|   - case: long-optimization
//|     expect:
//|       - {"artifact":"discrepancy","path":"/rows/0/2","range":{"min":1e-3,"max":1.685e-3}}
//|       - {"artifact":"invariants","path":"/rows/0/0","equals":0}
//|       - {"path":"/outputs/3/state","equals":"partial"}
//|   - case: centered
//|     expect:
//|       - {"artifact":"invariants","path":"/rows/0/0","equals":0}
//|       - {"artifact":"invariants","path":"/rows/0/1","range":{"min":0,"max":1e-14}}
use scioxide_core::{ExecutionContext, RealScalar};
use scioxide_random::{
    DiscrepancyMethod, LatinHypercubeOptions, LatinHypercubeTermination, Rollback,
    SamplingWorkspace, SeedableRng, SplitMix64, discrepancy, latin_hypercube_into,
    latin_hypercube_with_options,
};

let (n, d, seed) = (32_usize, 3_usize, seed.round() as u64);
let options = LatinHypercubeOptions::default()
    .with_centered(centered)
    .with_max_proposals(proposal_limit.round() as usize);
// Form writing to caller-provided output. Workspace grows to the required size.
let mut workspace = SamplingWorkspace::new();
let mut design = vec![0.0_f64; n * d];
let report = latin_hypercube_into(
    d,
    &mut SplitMix64::from_seed(seed),
    Rollback,
    options,
    &mut design,
    &mut workspace,
    ExecutionContext::sequential(),
)
.map_err(|e| e.to_string())?;
// The owning form returns the same design from the same settings and seed.
let (owned, _) =
    latin_hypercube_with_options::<f64, _>(n, d, &mut SplitMix64::from_seed(seed), options)
        .map_err(|e| e.to_string())?;
let owned_difference = owned
    .iter()
    .zip(&design)
    .map(|(a, b)| (a - b).abs())
    .fold(0.0_f64, f64::max);
// Recount frequencies of floor(32 x) strata for each input and total the strata whose counts differ from 1 (independent check).
let mut violations = 0_usize;
for column in 0..d {
    let mut counts = vec![0_usize; n];
    for row in design.chunks_exact(d) {
        counts[(row[column] * n as f64).floor() as usize] += 1;
    }
    violations += counts.iter().filter(|&&c| c != 1).count();
}
// Compute CD² directly from Hickernell's formula (independent check).
let half = |x: f64| (x - 0.5).abs();
let mut single = 0.0;
let mut pair = 0.0;
for a in design.chunks_exact(d) {
    single += a
        .iter()
        .map(|&x| 1.0 + 0.5 * half(x) - 0.5 * half(x) * half(x))
        .product::<f64>();
    for b in design.chunks_exact(d) {
        pair += a
            .iter()
            .zip(b)
            .map(|(&x, &y)| 1.0 + 0.5 * half(x) + 0.5 * half(y) - 0.5 * (x - y).abs())
            .product::<f64>();
    }
}
let nf = n as f64;
let constant = RealScalar::powi(13.0_f64 / 12.0, d as i32);
let hickernell = constant - 2.0 * single / nf + pair / (nf * nf);
let recomputed =
    discrepancy(&design, d, DiscrepancyMethod::Centered).map_err(|e| e.to_string())?;
// Independent uniform-point expectation ((5/4)^d − (13/12)^d)/n (comparison reference).
let iid_expected = (RealScalar::powi(1.25_f64, d as i32) - constant) / nf;
// Projection mapped to mass flow rates 0.1–0.5 kg/s and inlet temperatures 20–80 °C.
let projection: Vec<[f64; 2]> = design
    .chunks_exact(d)
    .map(|row| [0.1 + 0.4 * row[0], 20.0 + 60.0 * row[1]])
    .collect();
emit_scatter_chart!(
    &projection,
    options = &serde_json::json!({
        "xLabel": "Mass flow rate ṁ [kg/s]",
        "yLabel": "Inlet temperature T_in [°C]",
        "xMin": 0.1,
        "xMax": 0.5,
        "yMin": 20.0,
        "yMax": 80.0
    })
);
let sci4 = serde_json::json!({ "notation": "scientific", "significantDigits": 4 });
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let none = "No proposals";
let columns = serde_json::json!([
    { "key": "0", "label": "Attempted proposals [proposals]", "type": "integer" },
    { "key": "1", "label": "Initial CD² [-]", "type": "number", "format": sci4, "nullText": none },
    { "key": "2", "label": "Final CD² [-]", "type": "number", "format": sci4, "nullText": none },
    { "key": "3", "label": "Difference from discrepancy [-]", "type": "number", "format": sci2, "nullText": none },
    { "key": "4", "label": "Independent uniform-point expectation [-]", "type": "number", "format": sci4 }
]);
emit_table_with_columns!(
    columns,
    vec![(
        report.proposals(),
        report.initial_discrepancy(),
        report.final_discrepancy(),
        report
            .final_discrepancy()
            .map(|last| (last - recomputed).abs()),
        iid_expected,
    )],
    metadata = serde_json::json!({ "id": "discrepancy" })
);
let check_columns = serde_json::json!([
    { "key": "0", "label": "Strata with count other than 1 (total over 3 inputs) [strata]", "type": "integer" },
    { "key": "1", "label": "Difference from Hickernell's formula [-]", "type": "number", "format": sci2 },
    { "key": "2", "label": "Maximum difference from owning form [-]", "type": "number", "format": sci2 }
]);
emit_table_with_columns!(
    check_columns,
    vec![(
        violations,
        (recomputed - hickernell).abs(),
        owned_difference
    )],
    metadata = serde_json::json!({ "id": "invariants" })
);
let termination = report.termination();
let outcome = if termination == LatinHypercubeTermination::Complete {
    Outcome::satisfied("Latin hypercube completed without requesting swaps")
        .explanation("The design has only the stratum property; discrepancy improvement was not attempted.")
} else {
    Outcome::partial("Swap-based improvement stopped partway").explanation(
        "The design retains all 32 points and uses each stratum once. CD² is the value reached by local search.",
    )
};
emit_outcome!(
    outcome
        .status(format!("{termination:?}"))
        .diagnostic("Attempted proposals", report.proposals() as f64, None)
        .diagnostic("CD²", recomputed, None)
);
```

Each scatter-plot axis has 32 strata, with one point in each column and each row.
Two points in one column or row violate the stratum invariant.
With proposal limit 0, both reported $\mathrm{CD}^2$ values are `None`, so the table displays “No proposals.”

With the default inputs (proposal limit 128, seed 42), termination status is `BudgetExhausted` and the cell concludes partial.
There are 0 strata with counts other than 1.
$\mathrm{CD}^2$ decreases from $3.503 \times 10^{-3}$ to $1.685 \times 10^{-3}$, and the value recomputed with `discrepancy` matches the reported value bit for bit.
The difference from direct computation using Hickernell's formula is $1.6 \times 10^{-15}$, at rounding scale.
The maximum difference between the owning and `latin_hypercube_into` designs is 0.
Even before swaps, the LHS $\mathrm{CD}^2$ is only about one sixth of the independent uniform-point expectation $2.130 \times 10^{-2}$.
$\mathrm{CD}^2$ sums projection terms for coordinate subsets $u$; for independent uniform points, the expectation of the $u$ term is $\bigl((1/4)^{|u|} - (1/12)^{|u|}\bigr)/n$.
At $d = 3$, the three one-dimensional projection terms account for about 73% of the expectation; LHS stratification nearly eliminates this contribution.

With proposal limit 512, no run of 100 unimproved proposals occurs; the limit is reached with `BudgetExhausted`, and $\mathrm{CD}^2$ falls to $1.430 \times 10^{-3}$.
With stratum midpoints (centered), the initial value is $2.485 \times 10^{-3}$ and the value after 128 proposals is $1.576 \times 10^{-3}$.
With proposal limit 0, no swaps occur, termination status is `Complete`, and the cell concludes satisfied.
More proposals lower $\mathrm{CD}^2$, but the partial conclusion reflects that the attained value is not guaranteed to be minimal.

## Summary

Latin hypercube swaps permute values within columns and preserve stratification; recounting confirms that each input's 32 strata are used exactly once.
Stratification alone reduces $\mathrm{CD}^2$ to a fraction of the independent uniform-point expectation, and swap-based local search lowers it further.
Reported $\mathrm{CD}^2$ can be reproduced with `discrepancy` and Hickernell's formula; the owning form and caller-output form return the same design from the same seed.
Interpret designs requesting swaps as local-search results regardless of termination status, and assess imbalance in input combinations through $\mathrm{CD}^2$.
A unit-cube design can be used in physical ranges by affine mapping of each axis while preserving stratification.
