[Tracing solution branches with continuation](../continuation-and-deflation/) covered predictor–corrector tracing of one branch.
The same continuation machinery supports three further situations.
First, homotopy solves equations lacking good initial guesses by continuation from equations with known solutions.
Second, saved state allows long continuations to stop and resume.
Third, diagnostics identify candidate branch points along the traced branch.

## Homotopy

Without a good initial guess for desired equation $\mathbf{G}(\mathbf{x}) = \mathbf{0}$, start from an equation $\mathbf{S}(\mathbf{x}) = \mathbf{0}$ with known solution and

$$
\mathbf{H}(\mathbf{x}, \lambda) = (1 - \lambda)\,\mathbf{S}(\mathbf{x}) + \lambda\,\mathbf{G}(\mathbf{x})
$$

continue from $\lambda = 0$ to 1; this is the homotopy method.
`LinearHomotopy::new(&start, &target)` constructs $\mathbf{H}: \mathbb{R}^{n+1} \to \mathbb{R}^n$ from same-dimension $n$ square maps $\mathbf{S}$ and $\mathbf{G}$, with $\lambda$ as final input, for use in `ContinuationProblem`.
One $\mathbf{H}$ residual uses one residual each from $\mathbf{S}$ and $\mathbf{G}$; one directional derivative uses a directional derivative and residual from each.
A fold can turn $\lambda$ back before it reaches 1; a branch point can cause corrector failure.
`ContinuationPath::Parameters(vec![1.0])` stops exactly at $\lambda = 1$ but cannot pass folds.
Pseudo-arclength can pass folds but need not stop at $\lambda = 1$; find history points whose $\lambda$ crosses 1, then use a nearby point as the initial guess to resolve original $\mathbf{G}$.
Chow–Mallet-Paret–Yorke probability-one homotopy (reaching $\lambda = 1$ from almost every starting point under map conditions) and complex homotopy finding all polynomial-system solutions are unavailable.

For complex equations, use `RealifiedProblem` to convert maps to real coordinates alternating real and imaginary parts.
`RealifiedProblem::square` represents square maps for Newton or deflation; `RealifiedProblem::with_real_parameter` supports continuation with only the final input a real parameter.
Conversion assumes holomorphicity (complex differentiability) and computes directional derivatives as complex products $G'(\mathbf{z})\mathbf{v}$; supply nonholomorphic maps directly as real maps.
`with_real_parameter` passes $\lambda$ to the map as a complex number with zero imaginary part.

## Saving state and restarting

`Continuation` holds path and settings; `ContinuationState` holds accepted points, tangents, history, and distance traveled.
`ContinuationWorkspace` prepared according to `ContinuationWorkspaceRequirements` is scratch storage for correction and tangent computation.
Workspace contains no solution continuation; restart requires a checkpoint created from state.
`ContinuationState::history()` holds `ContinuationObservation` per accepted point including the seed ($\lambda$, pseudo-arclength, original residual norm, corrector iterations, rejected proposals, candidate folds, diagnostics); inspect coordinates through `history_point(i)`.

`ContinuationCheckpoint` created with `checkpoint()` from accepted state is an in-memory restart copy.
No persistent file format is specified.
`Continuation::resume` validates path/settings, problem shape, and saved-state consistency before restoring caller state and advancing one point.
Local work consumed before saving carries forward; provide new execution context and limits at restart.
Failed validation changes neither the checkpoint nor caller state.

The following cell traces circle $F(x, \lambda) = x^2 + \lambda^2 - 1$ from seed $(-1, 0)$ over pseudo-arclength $s$.
It checkpoints at accepted point $k$, restores into new state/workspace with `resume`, completes the path, and compares against uninterrupted continuation.
The table's attempted-step count is `ContinuationState::iterations()` and includes rejected trials.
Accepted pseudo-arclength totals $s$, but true circular arclength $\theta$ (angle counterclockwise from the seed) is longer by $\arcsin\Delta s - \Delta s \approx \Delta s^3/6$ per step.
Difference $\theta - s$ provides an independent check.
The final outcome is satisfied if both paths end with `Complete`, including endpoint differences.

```rust
//| id: rootfind-continuation-checkpoint
//| ref: rootfind-continuation-checkpoint
//| title: "Restart a circular branch from an intermediate checkpoint and compare"
//| run: reactive
//| crates: [scioxide-core, scioxide-rootfind]
//| inputs:
//|   arclength: {"type":"range","label":"Traced pseudo-arclength s [-]","description":"Reaches fold (0, 1) slightly before π/2 (true arclength θ = π/2).","min":1,"max":3,"step":0.25,"value":2.5}
//|   saved: {"type":"range","label":"Checkpoint accepted-point index k [-]","description":"Accepted-point index counting the corrected seed as k = 0.","min":0,"max":6,"step":1,"value":3}
//| cases:
//|   - {"id":"before-turn","label":"s = 1.5 (before the fold)","description":"Endpoint λ = 0.998033276 remains on the x < 0 side before fold (0, 1).","inputs":{"arclength":1.5}}
//|   - {"id":"past-turn","label":"s = 1.75 (past the fold)","description":"Endpoint x = 0.187869227 is beyond the fold, on the decreasing-λ side.","inputs":{"arclength":1.75}}
//|   - {"id":"seed-checkpoint","label":"k = 0 (save at corrected seed)","description":"Restarting a seed checkpoint also reproduces 16 points and 15 cumulative iterations.","inputs":{"saved":0}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"paths","path":"/rows/0/1","equals":"Complete"}
//|       - {"artifact":"paths","path":"/rows/1/1","equals":"Complete"}
//|       - {"artifact":"paths","path":"/rows/1/2","equals":16}
//|       - {"artifact":"paths","path":"/rows/0/3","approx":{"value":0.809947218,"atol":5e-10}}
//|       - {"artifact":"paths","path":"/rows/1/3","approx":{"value":0.809947218,"atol":5e-10}}
//|       - {"artifact":"paths","path":"/rows/1/4","approx":{"value":0.586502775,"atol":5e-10}}
//|       - {"artifact":"paths","path":"/rows/1/5","equals":15}
//|       - {"artifact":"paths","path":"/rows/1/6","range":{"max":1e-15}}
//|       - {"artifact":"paths","path":"/rows/1/7","approx":{"value":1.49e-2,"atol":5e-5}}
//|       - {"path":"/outputs/1/state","equals":"satisfied"}
//|   - case: before-turn
//|     expect:
//|       - {"artifact":"paths","path":"/rows/1/3","approx":{"value":-0.062686362,"atol":5e-10}}
//|       - {"artifact":"paths","path":"/rows/1/4","approx":{"value":0.998033276,"atol":5e-10}}
//|       - {"path":"/outputs/1/state","equals":"satisfied"}
//|   - case: past-turn
//|     expect:
//|       - {"artifact":"paths","path":"/rows/1/3","approx":{"value":0.187869227,"atol":5e-10}}
//|       - {"artifact":"paths","path":"/rows/1/4","approx":{"value":0.982194051,"atol":5e-10}}
//|       - {"path":"/outputs/1/state","equals":"satisfied"}
//|   - case: seed-checkpoint
//|     expect:
//|       - {"artifact":"paths","path":"/rows/1/2","equals":16}
//|       - {"artifact":"paths","path":"/rows/1/5","equals":15}
//|       - {"path":"/outputs/1/state","equals":"satisfied"}
use scioxide_core::{Budget, ExecutionContext, RealScalar, ResidualTolerance};
use scioxide_rootfind::{
    Continuation, ContinuationCheckpoint, ContinuationOptions, ContinuationPath,
    ContinuationProblem, ContinuationState, ResidualFn, RootTermination,
};
// F(x, λ) = x² + λ² − 1 and directional derivative F_y v = 2(x v_x + λ v_λ). y = (x, λ).
let circle = ResidualFn::with_parameter(1, |y: &[f64], out: &mut [f64]| {
    out[0] = y[0] * y[0] + y[1] * y[1] - 1.0;
    Ok(())
})
.with_jvp(|y: &[f64], v: &[f64], out: &mut [f64]| {
    out[0] = 2.0 * (y[0] * v[0] + y[1] * v[1]);
    Ok(())
});
let problem = ContinuationProblem::new(&circle).map_err(|e| e.to_string())?;
let options = ContinuationOptions::new(
    0.05,
    1e-8,
    0.2,
    Budget::try_from(400).map_err(|e| e.to_string())?,
)
.map_err(|e| e.to_string())?
.with_residual_tolerance(ResidualTolerance::new(1e-12, 0.0).map_err(|e| e.to_string())?);
let continuation = Continuation::new(ContinuationPath::PseudoArclength(arclength), options)
    .map_err(|e| e.to_string())?;
// Complete the path using new state and workspace; if from is present, advance the first point with resume,
// and return the checkpoint taken upon reaching accepted point k.
let trace = |from: Option<&ContinuationCheckpoint<f64>>| {
    let mut state = continuation
        .state(&problem, &[-1.0, 0.0])
        .map_err(|e| e.to_string())?;
    let mut workspace = continuation
        .workspace(&problem)
        .map_err(|e| e.to_string())?;
    let (mut pending, mut kept) = (from, None);
    loop {
        let sequential = ExecutionContext::sequential();
        let report = match pending.take() {
            Some(c) => continuation.resume(
                &problem,
                c,
                &mut state,
                |_, _| Ok(()),
                &mut workspace,
                sequential,
            ),
            None => continuation.advance(
                &problem,
                &mut state,
                |_, _| Ok(()),
                &mut workspace,
                sequential,
            ),
        }
        .map_err(|e| e.to_string())?;
        if kept.is_none() && state.history().len() == saved as usize + 1 {
            kept = Some(state.checkpoint().map_err(|e| e.to_string())?);
        }
        if report.termination() != RootTermination::Advanced {
            return Ok::<_, String>((state, kept));
        }
    }
};
let (whole, checkpoint) = trace(None)?;
let checkpoint = checkpoint.ok_or("Path ended before reaching accepted point k")?;
let (resumed, _) = trace(Some(&checkpoint))?;
// Independent check: difference between true arclength θ measured counterclockwise from seed (−1, 0) and requested pseudo-arclength s.
let row = |name: &str, state: &ContinuationState<f64>| {
    let (x, lambda) = (state.point()[0], state.point()[1]);
    (
        name.to_string(),
        state.termination().to_string(),
        state.history().len(),
        x,
        lambda,
        state.iterations(),
        state.residual_norm(),
        RealScalar::atan2(lambda, -x) - arclength,
    )
};
let rows = vec![
    row("Uninterrupted", &whole),
    row("Restarted from checkpoint", &resumed),
];
let fixed9 = serde_json::json!({ "notation": "standard", "fractionDigits": 9 });
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let columns = serde_json::json!([
    { "key": "0", "label": "Path" },
    { "key": "1", "label": "Termination status" },
    { "key": "2", "label": "Accepted points [count]", "type": "integer" },
    { "key": "3", "label": "Endpoint x [-]", "type": "number", "format": fixed9 },
    { "key": "4", "label": "Endpoint λ [-]", "type": "number", "format": fixed9 },
    { "key": "5", "label": "Attempted steps [count]", "type": "integer" },
    { "key": "6", "label": "Residual norm [-]", "type": "number", "format": sci2, "nullText": "Unevaluated" },
    { "key": "7", "label": "True arclength θ − pseudo-arclength s [-]", "type": "number", "format": sci3 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "paths" })
);

// Maximum-component difference between restarted and uninterrupted endpoints.
let gap = whole
    .point()
    .iter()
    .zip(resumed.point())
    .map(|(a, b)| (a - b).abs())
    .fold(0.0, f64::max);
let termination = resumed.termination();
let outcome = if termination.is_success() && whole.is_success() {
    Outcome::satisfied("Restarted path completed the requested pseudo-arclength")
} else {
    Outcome::partial("Path stopped before completing the requested pseudo-arclength")
};
emit_outcome!(
    outcome
        .status(termination.to_string())
        .diagnostic("Endpoint difference", gap, None)
        .diagnostic("Attempted steps", resumed.iterations() as f64, None)
);
```

At defaults $s = 2.5$ and $k = 3$, both paths accept 16 points and terminate with `Complete`, matching endpoint $(0.809947218, 0.586502775)$ and 15 attempted steps.
Attempt counts match because checkpoints retain prior work accounting.
The endpoint residual is $2.2 \times 10^{-16}$, and $\theta - s = 1.49 \times 10^{-2}$.
Steps grow 1.5-fold from 0.05 through 0.075, 0.1125, and 0.16875 to cap 0.2, followed by ten 0.2 steps and one final 0.09375 remainder (16 points including the seed).
The per-step $\arcsin \Delta s - \Delta s$ estimate gives $1.36 \times 10^{-2}$ from ten 0.2 steps plus $1.3 \times 10^{-3}$ from the other five, totaling $1.49 \times 10^{-2}$ and matching observations.
Since true arclength $\theta$ exceeds $s$, fold $(0, 1)$ ($\theta = \pi/2$) is reached at $s \approx 1.56$ slightly before π/2; beyond it $\lambda$ decreases.

## Bifurcation diagnostics

Specifying `ContinuationOptions::with_dense_diagnostics(threshold)` assembles $[F_{\mathbf{x}}\ F_\lambda]$ columnwise from $n + 1$ Jacobian-vector products per accepted point, computing dense diagnostics (storage $O(n^2)$ and work $O(n^3)$ per point).
Rank estimates compare singular values with relative threshold `threshold`; LU determines determinant signs of bordered $B = \begin{bmatrix} F_{\mathbf{y}} \\ \mathbf{t}^{\mathsf T}M \end{bmatrix}$.
`ContinuationDiagnostic` holds estimated rank `augmented_rank`, smallest-to-largest singular-value ratio `reciprocal_condition`, determinant sign `bordered_sign`, and branch-point candidate `branch_point_candidate`.
Dense diagnostics flag candidates when rank is below $n$ or LU finds $B$ singular.
Across simple branch points, $\det B$ changes sign, so continuation also flags points where `bordered_sign` has opposite sign to the preceding accepted point.
At folds, $F_{\mathbf{y}}$ retains rank $n$ and $B$ remains nonsingular; these diagnostics therefore do not flag folds.
Find folds from sign changes in the tangent's $\lambda$ component (`turning_point_candidate`).
For large/sparse problems, implement `ContinuationDiagnosticProvider` and supply it through `ContinuationProblem::with_diagnostic` instead of dense diagnostics.
All values are numerical estimates, not proofs of bifurcation existence.
Without requested diagnostics, `diagnostic()` is `None` and must not be treated as zero.

## Summary

Without a good initial guess, connect from a known equation through `LinearHomotopy`, then resolve the original equation using a point near the continuation endpoint.
Folds or branch points may prevent reaching $\lambda = 1$; complex homotopy for all solutions is unavailable.
`ContinuationState` retains solution continuation, while `ContinuationWorkspace` holds scratch space; restart using `ContinuationCheckpoint` created from state.
Restart carries prior work forward and reproduces uninterrupted points and attempt counts.
Diagnostics from `with_dense_diagnostics` or `ContinuationDiagnosticProvider` estimate candidate branch points without proving existence.
