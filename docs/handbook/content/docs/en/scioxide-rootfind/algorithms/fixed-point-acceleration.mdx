Self-consistent fields and iterative model updates seek fixed points satisfying $x = G(x)$.
The fixed-point residual $r(x) = G(x) - x$ differs from the actual movement applied by iteration.
Small relaxation $\alpha$ makes step $\alpha\, r(x)$ small without necessarily making residual $r(x)$ small.
Contraction theory bounds position errors using computable residuals.

## Contractions and error bounds

If map $G$ sends complete metric space $D$ (such as a closed subset of $\mathbb{R}^n$) to itself and satisfies

$$
\|G(x)-G(y)\|\le q\|x-y\|,\qquad 0\le q<1
$$

then $G$ is a contraction with factor $q$.
Banach's fixed-point theorem gives a unique fixed point $x_*$ in $D$, approached by Picard iteration $x_{k+1} = G(x_k)$ from every $x_0 \in D$.
Error satisfies $\|x_{k+1} - x_*\| = \|G(x_k) - G(x_*)\| \le q \|x_k - x_*\|$, giving linear convergence and approximately $\ln 10 / \ln(1/q)$ iterations per decimal digit of error reduction.
This is approximately ten iterations for $q = 0.8$ and 45 for $q = 0.95$.

The triangle inequality gives $\|x_k - x_*\| \le \|x_k - G(x_k)\| + \|G(x_k) - G(x_*)\| \le \|r(x_k)\| + q \|x_k - x_*\|$, hence:

$$
\|x_k-x_*\|\le\frac{\|G(x_k)-x_k\|}{1-q}
$$

This a posteriori bound converts computable residuals to position errors; coefficient $1/(1-q)$ grows as $q$ approaches 1.
It requires a known contraction factor $q$ valid throughout the domain.
Do not use residual ratios from a few iterations directly as $q$ for a proof.
For differentiable maps, spectral radius of $G'(x_*)$ below 1 is the basic local convergence condition.

## Relaxation and seven methods

Relaxed iteration uses $G_\alpha(x) = x + \alpha\, r(x)$.
Near a fixed point, the linear error part is $I + \alpha(G'(x_*) - I)$, mapping eigenvalue $\lambda$ of $G'(x_*)$ to $1 + \alpha(\lambda - 1)$.
Relaxation changes both speed and stability, but small $\alpha$ does not cure every divergence.

| `FixedPointMethod` | Update idea | Cautions |
|---|---|---|
| `Picard` | $x + \alpha r$ | Basic relaxed iteration without history |
| `Steffensen` | Evaluate the relaxed map twice, applying Aitken $\Delta^2$ acceleration per component | Two evaluations per iteration. Skip acceleration for small denominators; no coupling between components |
| `Anderson` | Type-II acceleration from least squares of residual differences | Sensitive to history linear dependence and component scales |
| `BroydenFirst` | Update approximate inverse residual Jacobian $H$ (initial $-\alpha I$) with first (good) Broyden satisfying secant conditions | Skip updates with small secant denominators |
| `BroydenSecond` | Update the same $H$ (initial $-\alpha I$) with second (bad) Broyden | Rank-one update along residual-difference directions |
| `DiagonalBroyden` | Broyden updates of Jacobian diagonals alone | Does not capture strong intercomponent coupling. Reset excessively small diagonals to $\alpha$ |
| `ExcitingMixing` | Increase mixing coefficients by $\alpha$ while residual signs persist; reset to $\alpha$ when signs change | Real only. Cap `with_maximum_mixing` (default 1); default $\alpha = 1$ gives the same update as `Picard` |

For scalars, Steffensen uses $y = G_\alpha(x)$, $z = G_\alpha(y)$, and $x - (y - x)^2 / (z - 2y + x)$.
This is the limit treating $x$, $y$, and $z$ as three terms with geometrically decreasing errors, giving exact linear-map fixed points in one iteration.
For smooth scalar fixed points with $G'(x_*) \ne 1$, local quadratic convergence is expected, but multivariate Newton convergence theorems do not directly apply to componentwise extensions.

## Anderson acceleration and history

Anderson forms $m$ columns of point differences $\Delta X = [x_{k-m+1} - x_{k-m}, \dots, x_k - x_{k-1}]$ and matching residual differences $\Delta R$ from the latest $m + 1$ points, solving least squares:

$$
\gamma_k = \arg\min_\gamma \|r_k - \Delta R\, \gamma\|_2
$$

$r_k - \Delta R\, \gamma$ cancels the current residual as much as possible using past residual combinations.
The type-II proposal is

$$
x_{k+1}=x_k+\alpha r_k-(\Delta X+\alpha\Delta R)\gamma_k
$$

reducing to Picard when $m = 0$.
For linear maps, untruncated-history Anderson ($\alpha = 1$) is known to be equivalent to GMRES on equation $(I - G')x = G(0)$ (Walker and Ni, 2011).
Thus with history length $m$ at least dimension $n$, linear problems solve in at most approximately $n + 1$ iterations apart from rounding.
The same reasoning makes nonlinear iteration faster near fixed points when history covers the dominant directions of $G'$.

The implementation divides history matrices by component scales and uses column-pivoted Householder QR to determine numerical rank.
Default rank criterion is `RankPolicy::DimensionScaledEpsilon`, changeable through `with_rank_policy`.
Default regularization is zero; if rank $r$ is below $m$, discard pivot-order column $r + 1$ (the first numerically dependent column), count a skipped update, and refactor.
Only when `with_regularization` supplies $\lambda > 0$ does each iteration instead solve Tikhonov least squares with extra rows $\sqrt\lambda\, I$, counting these regularizations.
Failure even after regularization produces a `InvalidInput` error.

History methods retain at most $m = \min(m_{\max}, n)$ pairs, the minimum of requested `with_history` length and dimension $n$ (default $m_{\max}$ is five).
Main storage is $O(nm)$ and least-squares work per iteration approximately $O(nm^2)$.
Longer histories are not always faster; stale history or nearly dependent differences can hinder convergence.
When history fills, `HistoryRestart::Oldest` discards the oldest pair and `Restart` discards all history.
Observe this through `history_rank`, `skipped_updates`, `restarts`, and `regularized_solves` in `FixedPointDiagnostics`.

## Inputs and stopping criteria

For `FixedPointInput::Map`, `ResidualOperator` returns $G(x)$ and the solver forms residual $G(x) - x$.
For `FixedPointInput::Residual`, callbacks return $F(x)$, giving basic proposal $x + \alpha F(x)$.
Supplying $F = x - G(x)$ reverses the sign; verify the definition.
`ResidualFn` provides this action through a closure.

Stopping criteria are as follows.

- `ResidualTolerance`: the L2 norm of component-scaled residuals meets tolerance.
  Defaults are absolute 0 and relative $\sqrt{\varepsilon}$ against the initial residual norm; `with_residual_scale` fixes a reference.
  An exact initial fixed point succeeds without iteration.
- `Stagnation`: the proposal equals the current point, or its step meets coordinate tolerance $\|\Delta x\|_2 \le \tau_a + \tau_r \max(1, \|x\|_2)$ (default $\tau_a = \tau_r = \sqrt\varepsilon$) without decreasing scaled residuals.
  Zero coordinate tolerances disable the latter check.
  This does not guarantee a root; residual acceptance alone decides success.
- `IterationLimit`: iteration limit reached (default 200).

`with_residual_tolerance` sets residual tolerances, `with_step_tolerance` coordinate tolerances, and `with_component_scales` positive component divisors.
Divisors apply to stopping and Anderson least squares alike.

`FixedPointSolver` retains the method, input meaning, and `FixedPointOptions`.
Using `FixedPointWorkspaceRequirements` returned by `workspace_requirements`, construct `FixedPointWorkspace` with `workspace` and reuse it with `FixedPointResult::new(n)` through `solve_into`.
Owned-result `solve` performs this preparation internally.
Without settings or diagnostics, one-call `fixed_point(g, initial)` finds fixed points of $G$ using depth-$\min(5, n)$ Anderson and defaults, returning points only on success and other termination as errors such as `ConvergenceFailure`.
Iteration/evaluation-limit stops expose the last accepted point with unconverged termination; other `Err` errors preserve borrowed outputs.
`residual_norm()` in `FixedPointResult` is the returned point's unscaled residual $G(x) - x$ L2 norm; `scaled_residual_norm()` is the scaled norm used for stopping.

## Comparing contraction factors and histories

The following map contracts on $\mathbb{R}^6$, with analytic fixed point $x_* = 0$.

$$
G(x)_i = q \sin x_{i+1} \quad (i = 1, \dots, 6,\ x_7 = x_1), \qquad 0 < q < 1
$$

From $\lvert \sin a - \sin b \rvert \le \lvert a - b \rvert$ and norm preservation by cyclic index shifting, the Euclidean contraction factor is at most $q$.
Its fixed-point Jacobian is a cyclic permutation times $q$, with eigenvalues $q e^{2\pi i k/6}$ ($k = 0, \dots, 5$) equally spaced on radius-$q$ circle.
All eigenvalue magnitudes are $q$; the four other than $\pm q$ are nonreal.
Componentwise acceleration or relaxation therefore does not accelerate it; history must handle six directions together.

The following cell runs seven methods from common initial $x_i = \cos i$ with default tolerances.
Inputs are contraction $q$, relaxation $\alpha$, and history length $m$; outputs give termination, iterations, map evaluations, known-fixed-point distances, residual-derived bounds $\|r\|/(1-q)$, and history diagnostics.
The final outcome is satisfied if all seven succeed, partial if any stop, with Anderson termination and maximum distance-to-bound ratio.

```rust
//| id: rootfind-fixed-point-methods
//| ref: rootfind-fixed-point-methods
//| title: "Seven fixed-point methods and contraction error bounds"
//| run: reactive
//| crates: [scioxide-core, scioxide-rootfind]
//| inputs:
//|   q: {"type":"range","label":"Contraction factor q [-]","min":0.2,"max":0.95,"step":0.05,"value":0.8}

//|       - {"artifact":"methods","path":"/rows/1/2","equals":70}

//|       - {"artifact":"methods","path":"/rows/2/6","equals":6}
//|   - case: slow-contraction
//|     expect:
//|       - {"artifact":"methods","path":"/rows/0/1","equals":"IterationLimit"}
//|       - {"artifact":"methods","path":"/rows/0/2","equals":200}

//|       - {"artifact":"methods","path":"/rows/2/1","equals":"ResidualTolerance"}

use scioxide_core::{EvaluationRole, RealScalar};
use scioxide_rootfind::{
    FixedPointInput, FixedPointMethod, FixedPointOptions, FixedPointSolver, HistoryRestart,
    ResidualFn,
};

// G(x)_i = q sin x_{i+1} (cyclic indices modulo six). Fixed point is zero.
const N: usize = 6;
let map = ResidualFn::new(N, |x: &[f64], out: &mut [f64]| {
    for i in 0..N {
        out[i] = q * RealScalar::sin(x[(i + 1) % N]);
    }
    Ok(())
});
let initial: Vec<f64> = (1..=N).map(|i| RealScalar::cos(i as f64)).collect();
let methods = [
    FixedPointMethod::Picard,
    FixedPointMethod::Steffensen,
    FixedPointMethod::Anderson,
    FixedPointMethod::BroydenFirst,
    FixedPointMethod::BroydenSecond,
    FixedPointMethod::DiagonalBroyden,
    FixedPointMethod::ExcitingMixing,
];
let (mut rows, mut all_success, mut worst_ratio) = (Vec::new(), true, 0.0_f64);
let mut anderson = None;
for method in methods {
    let options = FixedPointOptions::default()
        .with_damping(damping)
        .with_history(history as usize, HistoryRestart::Oldest);
    let solver = FixedPointSolver::<f64>::new(method, FixedPointInput::Map, options)
        .map_err(|e| e.to_string())?;
    let result = solver.solve(&map, &initial).map_err(|e| e.to_string())?;
    // Independent check: Euclidean distance from known fixed point zero.
    let error = RealScalar::sqrt(result.point().iter().map(|x| x * x).sum::<f64>());
    // A posteriori contraction bound ‖G(x) − x‖ / (1 − q).
    let bound = result.residual_norm().ok_or("Residual not yet evaluated")? / (1.0 - q);
    let diagnostics = result.diagnostics();
    all_success &= result.is_success();
    if bound > 0.0 {
        worst_ratio = worst_ratio.max(error / bound);
    }
    if method == FixedPointMethod::Anderson {
        anderson = Some((result.termination(), result.iterations()));
    }
    rows.push((
        format!("{method:?}"),
        result.termination().to_string(),
        result.iterations(),
        result.counts().provider(EvaluationRole::Function),
        error,
        bound,
        diagnostics.history_rank(),
        diagnostics.skipped_updates(),
        diagnostics.restarts(),
    ));
}
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let columns = serde_json::json!([
    { "key": "0", "label": "Method" },
    { "key": "1", "label": "Termination reason" },
    { "key": "2", "label": "Iterations [count]", "type": "integer" },
    { "key": "3", "label": "Map evaluations [count]", "type": "integer" },
    { "key": "4", "label": "Fixed-point distance [-]", "type": "number", "format": sci2 },
    { "key": "5", "label": "Residual-derived bound [-]", "type": "number", "format": sci2 },
    { "key": "6", "label": "History rank [-]", "type": "integer" },
    { "key": "7", "label": "Skipped updates [count]", "type": "integer" },
    { "key": "8", "label": "Restarts [count]", "type": "integer" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "methods" })
);
let (status, iterations) = anderson.ok_or("No Anderson result")?;
let outcome = if all_success {
    Outcome::satisfied("All seven methods met residual tolerance")
} else {
    Outcome::partial("Some methods stopped before meeting residual tolerance")
        .explanation("Inspect the termination-reason column to identify stopped methods.")
};
emit_outcome!(
    outcome
        .status(status.to_string())
        .diagnostic("Anderson iterations", iterations as f64, None)
        .diagnostic("Maximum distance-to-bound ratio", worst_ratio, None)
);
```

At defaults ($q = 0.8$, $\alpha = 1$, $m = 5$), every method ends with `ResidualTolerance`.
Picard takes 80 iterations (81 evaluations); distance $2.3 \times 10^{-8}$ lies within bound $1.1 \times 10^{-7}$.
Anderson stops after 13 iterations (14 evaluations), Broyden variants after 37 and 42, and Steffensen after 70 with 141 evaluations, exceeding Picard's evaluations.
`DiagonalBroyden` takes 144 iterations, slower than Picard.
The fixed-point Jacobian has zero diagonal, so a diagonal-only model cannot represent the map.
With default cap 1 and $\alpha = 1$, `ExcitingMixing` cannot increase mixing coefficients and matches Picard; restart counts indicate residual-component sign changes.

Anderson iterations vary with history: 75 at $m = 1$, 67 at $m = 2$, 36 at $m = 4$, 13 at $m = 5$, and 11 at $m = 6$ and $m = 8$.
History rank saturates at $\min(m, 6)$; once $m \ge 6$ covers all six eigenvalue directions, further length adds nothing.
At $q = 0.95$, Picard reaches 200 iterations with `IterationLimit` and distance $3.3 \times 10^{-5}$, while Anderson converges in 22.
At the same $q = 0.95$, `BroydenFirst` diverges, returning a point at distance $1.5 \times 10^{21}$ with `IterationLimit`; never use it without checking termination.
At $\alpha = 0.2$ Picard also reaches its limit, while `ExcitingMixing` increases coefficients to cap 1 and converges in 118.
At the same $\alpha = 0.2$, `BroydenFirst` diverges and stops with `IterationLimit`; stronger relaxation does not necessarily stabilize Broyden updates.
Every row's fixed-point distance stays within its residual-derived bound.
The bound follows mathematically from contraction, but rounded residual evaluations prevent it being an interval-certified enclosure.

## Checking with a linear map

In addition to nonlinear comparisons, use one-dimensional linear map $G(x) = q x + 1$.
Its closed-form fixed point is $1/(1 - q)$ and Picard errors decrease by exactly factor $q^k$.
The following cell solves with `Picard`, `Steffensen`, and `Anderson` from $x_0 = 0$, using absolute residual tolerance $10^{-12}$ and coordinate tolerance $10^{-14}$.
Input is contraction $q$; outputs give termination, fixed points, reported residuals `residual_norm()`, closed-form discrepancies (independent checks), map counts, and an outcome from all three termination reasons.

```rust
//| id: rootfind-fixed-point-acceleration
//| ref: rootfind-fixed-point-acceleration
//| title: "Compare contraction and history acceleration using a known fixed point"
//| run: reactive
//| crates: [scioxide-core, scioxide-rootfind]
//| inputs:
//|   contraction_rate: {"type":"range","label":"Contraction factor q [-]","description":"Changes basic iteration convergence speed.","min":0.2,"max":0.9,"step":0.1,"value":0.8}
//| cases:
//|   - {"id":"slow-contraction","label":"q = 0.9 (weak contraction)","description":"Picard increases to 264 evaluations; Steffensen and Anderson remain at three.","inputs":{"contraction_rate":0.9}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"linear","path":"/rows/0/1","equals":"ResidualTolerance"}
//|       - {"artifact":"linear","path":"/rows/0/3","approx":{"value":9.6e-13,"rtol":1e-2}}
//|       - {"artifact":"linear","path":"/rows/0/4","approx":{"value":4.8e-12,"rtol":1e-2}}
//|       - {"artifact":"linear","path":"/rows/0/5","equals":125}
//|       - {"artifact":"linear","path":"/rows/1/1","equals":"ResidualTolerance"}
//|       - {"artifact":"linear","path":"/rows/1/5","equals":3}
//|       - {"artifact":"linear","path":"/rows/2/1","equals":"ResidualTolerance"}
//|       - {"artifact":"linear","path":"/rows/2/5","equals":3}
//|       - {"path":"/outputs/1/state","equals":"satisfied"}
//|   - case: slow-contraction
//|     expect:
//|       - {"artifact":"linear","path":"/rows/0/1","equals":"ResidualTolerance"}
//|       - {"artifact":"linear","path":"/rows/0/5","equals":264}
//|       - {"artifact":"linear","path":"/rows/1/5","equals":3}
//|       - {"artifact":"linear","path":"/rows/2/5","equals":3}
//|       - {"path":"/outputs/1/state","equals":"satisfied"}
use scioxide_core::{Budget, EvaluationRole, ResidualTolerance, StepTolerance};
use scioxide_rootfind::{
    FixedPointInput, FixedPointMethod, FixedPointOptions, FixedPointSolver, ResidualFn,
};

// Residual and coordinate-step tolerances and iteration limit.
let options = FixedPointOptions::default()
    .with_residual_tolerance(
        ResidualTolerance::new(1.0e-12_f64, 0.0).map_err(|e| e.to_string())?,
    )
    .with_step_tolerance(StepTolerance::new(1.0e-14, 0.0).map_err(|e| e.to_string())?)
    .with_max_iterations(Budget::try_from(800).map_err(|e| e.to_string())?);

// Contraction G(x) = q x + 1.
let map = ResidualFn::new(1, |x: &[f64], out: &mut [f64]| {
    out[0] = contraction_rate * x[0] + 1.0;
    Ok(())
});
// Independent check: closed-form fixed point 1/(1 − q).
let expected = 1.0 / (1.0 - contraction_rate);
let (mut rows, mut all_success, mut largest_error) = (Vec::new(), true, 0.0_f64);
for method in [
    FixedPointMethod::Picard,
    FixedPointMethod::Steffensen,
    FixedPointMethod::Anderson,
] {
    let result = FixedPointSolver::new(method, FixedPointInput::Map, options.clone())
        .map_err(|e| e.to_string())?
        .solve(&map, &[0.0])
        .map_err(|e| e.to_string())?;
    let x = result.point()[0];
    let residual = result.residual_norm().ok_or("Residual not yet evaluated")?;
    all_success &= result.is_success();
    largest_error = largest_error.max((x - expected).abs());
    rows.push((
        format!("{method:?}"),
        result.termination().to_string(),
        x,
        residual,
        (x - expected).abs(),
        result.counts().provider(EvaluationRole::Function),
    ));
}
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let digits16 = serde_json::json!({ "notation": "standard", "significantDigits": 16 });
let columns = serde_json::json!([
    { "key": "0", "label": "Method" },
    { "key": "1", "label": "Termination reason" },
    { "key": "2", "label": "Fixed point x [-]", "type": "number", "format": digits16 },
    { "key": "3", "label": "Reported residual |G(x) − x| [-]", "type": "number", "format": sci2 },
    { "key": "4", "label": "Closed-form discrepancy [-]", "type": "number", "format": sci2 },
    { "key": "5", "label": "Map evaluations [count]", "type": "integer" }
]);
// Row order: Picard, Steffensen, Anderson. Attach Anderson's row to the outcome.
let (anderson_status, anderson_evaluations) = (rows[2].1.clone(), rows[2].5 as f64);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "linear" })
);
let outcome = if all_success {
    Outcome::satisfied("All three methods met residual tolerance")
} else {
    Outcome::partial("Some methods stopped before meeting residual tolerance")
};
emit_outcome!(
    outcome
        .status(anderson_status)
        .diagnostic("Anderson map evaluations", anderson_evaluations, None)
        .diagnostic("Maximum closed-form discrepancy", largest_error, None)
);
```

Picard uses 125 evaluations at $q = 0.8$ and 264 at $q = 0.9$, stopping when reported residuals reach at most tolerance $10^{-12}$.
For this linear map, $r(x) = (q - 1)(x - x_*)$, so closed-form discrepancies are exactly $1/(1 - q)$ times reported residuals, giving $9.6 \times 10^{-13} / 0.2 = 4.8 \times 10^{-12}$ at $q = 0.8$.
Steffensen and Anderson reach rounding-accurate fixed points in three evaluations for every $q$.
One Steffensen Aitken extrapolation gives exact linear-map fixed points, and Anderson cancels linear residuals with one history column.
This linear-problem acceleration does not guarantee evaluation counts for general nonlinear problems.

## Summary

First verify the map definition and residual $G(x) - x$ sign convention.
With known global contraction $q$, convert reported residuals to position bounds through $\|r\|/(1-q)$; both bounds and iterations grow as $q$ approaches 1.
For nonreal eigenvalues or $q$ near 1, Anderson history near dimension is effective; inspect `history_rank` and `skipped_updates` to assess it.
Acceleration uses history and additional evaluations, so compare map counts as well as iterations.
