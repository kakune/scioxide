Newton for systems $\mathbf{F}(\mathbf{x}) = \mathbf{0}$ solves linear equation $J(\mathbf{x}_k)\mathbf{s}_k = -\mathbf{F}(\mathbf{x}_k)$ each iteration.
For many unknowns $n$, constructing and factoring the $n^2$ Jacobian entries of $J$ dominates cost and storage.
Krylov methods such as GMRES solve without $J$ entries, using only Jacobian-vector products (JVPs) $J\mathbf{v}$.
`NewtonKrylovSolver` combines these approaches, solving with only residual action `ResidualOperator` and JVP action `JacobianOperator` from scioxide-core.
Dense-Jacobian methods appear in [Nonlinear systems and globalization](../nonlinear-systems/).

## Inexact Newton methods and forcing terms

Solving linear equations to rounding accuracy while nonlinear residuals remain large does not accelerate outer convergence.
Inexact Newton stops linear solves once

$$
\lVert \mathbf{F}(\mathbf{x}_k) + J(\mathbf{x}_k)\,\mathbf{s}_k \rVert \le \eta_k \lVert \mathbf{F}(\mathbf{x}_k) \rVert, \qquad 0 \le \eta_k < 1
$$

the inequality above is met.
$\eta_k$ is called the forcing term.
The Dembo–Eisenstat–Steihaug theorem gives the following when the root's Jacobian is nonsingular and $\mathbf{x}_0$ is sufficiently nearby.

- $\eta_k \le \eta_{\max} < 1$ gives local linear convergence.
- $\eta_k \to 0$ gives superlinear convergence.
- $\eta_k = O(\lVert \mathbf{F}(\mathbf{x}_k) \rVert)$ gives quadratic convergence.

Excessively small $\eta_k$ increases inner iterations without improving outer convergence (oversolving).
Eisenstat–Walker avoids this waste by selecting $\eta_k$ from how accurately the linear model predicts actual residuals.

`NewtonKrylovForcing` specifies forcing rules, selected through `with_forcing`.

- `Constant(η)` uses constant $0 < \eta < 1$.
- `EisenstatWalker { initial, minimum, maximum }` (default) uses Eisenstat–Walker choice 1.
  Defaults are `initial` 0.5, `minimum` $\varepsilon$, and `maximum` 0.9.

Choice 1 uses differences between new residuals and linear predictions for corrections actually accepted with step $\alpha_k$.

$$
\eta_{k+1} = \frac{\bigl|\,\lVert \mathbf{F}(\mathbf{x}_{k+1}) \rVert - \lVert \mathbf{F}(\mathbf{x}_k) + \alpha_k J(\mathbf{x}_k)\mathbf{s}_k \rVert\,\bigr|}{\lVert \mathbf{F}(\mathbf{x}_k) \rVert}
$$

Only when safeguarding lower bound $\eta_k^{(1+\sqrt5)/2}$ from previous $\eta_k$ exceeds 0.1 is $\eta_{k+1}$ raised to at least that bound.
Then constrain it to `[minimum, maximum]` and, for finite-difference JVPs, additionally require at least $\sqrt\varepsilon$.
Finite-difference JVP relative errors are $O(\sqrt\varepsilon)$, preventing both satisfaction and verification of stricter requests.
Eisenstat–Walker (1996) proved local superlinear convergence of this rule under its assumptions.

## Inner GMRES and correction verification

Inner linear equations use scioxide-linalg's restarted `GmresSolver`.
Right preconditioning may change per call; flexible GMRES (FGMRES) retains all preconditioned directions.
Defaults allow at most 200 inner iterations per Newton iteration and restart length $m$ of 30, configurable through `with_krylov`.
Krylov-basis storage is $O(nm)$, without a dense Jacobian.
Shorter restarts save memory but can discard useful convergence information and increase inner iterations.

For inner correction $\mathbf{d}$, `NewtonKrylovSolver` evaluates one more JVP to recompute $\mathbf{F} + J\mathbf{d}$.
This verified linear residual determines correction acceptance, line-search slope $\mathbf{F}^{\mathsf T} J\mathbf{d}$, and the next forcing term.
Even if it misses requested $\eta_k \lVert \mathbf{F} \rVert$, corrections are retained if the verified linear residual is at most $\bar\eta\,\lVert \mathbf{F} \rVert$.
Here $\bar\eta = \max(\eta_{\max}, \eta_{\mathrm{floor}})$; $\eta_{\max}$ is the forcing-rule upper bound ($\eta$ for `Constant(η)`), and $\eta_{\mathrm{floor}}$ is $\sqrt\varepsilon$ for finite-difference JVPs and zero otherwise.
The slope then satisfies $\mathbf{F}^{\mathsf T}J\mathbf{d} = \mathbf{F}^{\mathsf T}(\mathbf{F} + J\mathbf{d}) - \lVert \mathbf{F} \rVert^2 \le -(1 - \bar\eta)\lVert \mathbf{F} \rVert^2$, making the correction a merit-function descent direction.
Exceeding this bound stops with `LinearFailure`.

Pass preconditioning through `NewtonKrylovProblem::with_preconditioner` as `Preconditioner` (scioxide-core) applying approximate inverse $M^{-1}$, used as GMRES right preconditioning.
Preconditioning accelerates linear iterations without changing nonlinear solutions.
To replace the linear solver itself, implement `NonlinearLinearSolver` and pass it through `NewtonKrylovProblem::with_linear_solver`, for example a direct or custom preconditioned iterative method.
Replacement solvers receive Newton equations as `NonlinearLinearization`; `operator()` exposes scaled Jacobian action $R^{-1} J V$ ($R$ and $V$ are diagonal residual/variable divisors, identity without component scales below); `point()`/`residual()`/`row_divisors()`/`variable_divisors()` expose current point, residual, and divisors.
Replacement solvers must honor accuracy requests and report nonconvergence; returned corrections undergo the same verification.
Specifying both `with_linear_solver` and `with_preconditioner` gives a `InvalidInput` error during workspace preparation or solve startup.

## Nonmonotone line search

Outer corrections use backtracking acceptance for merit function $\phi(\mathbf{x}) = \tfrac12 \lVert \mathbf{F}(\mathbf{x}) \rVert^2$.
The Armijo reference is Zhang–Hager weighted average $C_k$ rather than current $\phi(\mathbf{x}_k)$.

$$
\phi(\mathbf{x}_k + \alpha\mathbf{d}) \le C_k + c\,\alpha\,\mathbf{F}^{\mathsf T} J \mathbf{d}, \qquad
Q_{k+1} = wQ_k + 1, \quad C_{k+1} = \frac{wQ_k C_k + \phi(\mathbf{x}_{k+1})}{Q_{k+1}}
$$

Initial values are $Q_0 = 1$ and $C_0 = \phi(\mathbf{x}_0)$; default weights are $w = 0.85$ (`with_nonmonotone`) and $c = 10^{-4}$.
Since $C_k \ge \phi(\mathbf{x}_k)$, accepted corrections can temporarily increase $\lVert \mathbf{F} \rVert$.
Setting $w = 0$ recovers ordinary monotone Armijo.
Averaging avoids repeated step reduction demanded by monotone criteria when accurate Newton corrections cross curved valleys.

Start with step 1; replace rejected steps by quadratic-interpolation minima, cubic from the second rejection, constrained to 0.1–0.5 times the preceding step.
Nonfinite trial residuals or callback `DomainError` (`OutsideDomain`) halve the step without interpolation.
Stop searching when relative movement $\alpha \max_i |d_i| / \max(1, |x_i|)$ falls below the minimum (default $\varepsilon^{2/3}$).
Change $c$ and the minimum through `with_backtracking(c, minimum)`.

## Finite-difference actions

Without analytic JVPs, `NewtonKrylovProblem::numerical` uses forward differences.
Reusing known $\mathbf{F}(\mathbf{x})$, for nonzero direction $\mathbf{v}$ use:

$$
J(\mathbf{x})\mathbf{v} \approx \frac{\mathbf{F}(\mathbf{x} + \sigma\mathbf{v}) - \mathbf{F}(\mathbf{x})}{\sigma}, \qquad
\sigma = \frac{\sqrt\varepsilon}{\max_i \bigl(|v_i| / \max(1, |x_i|)\bigr)}
$$

The largest component movement is $\sqrt\varepsilon\max(1, |x_i|)$, adding one residual evaluation per product.
When `NonlinearScaling` is supplied, variable divisors replace $\max(1, |x_i|)$.
Combined truncation and rounding error is order $\sqrt\varepsilon$, so forcing terms below $\sqrt\varepsilon$ do not improve corrections.
No such accuracy can be assumed for noisy or discontinuous residuals.
Use `NewtonKrylovProblem::with_jacobian` to supply analytic or AD JVPs.

## Component scales

Implement `NonlinearScaling` to provide residual and variable component divisors through `NewtonKrylovProblem::with_scaling`.
`scales_into` writes positive finite divisors for every component and declares scratch requirements through `scaling_workspace_len`.
Update divisors at accepted points, holding them fixed throughout linear corrections and trial searches from that point.
Changing divisors restarts nonmonotone reference $C_k$ from $\phi$ in the new units.
Residual norms, stopping, and line searches use divided values; result residual vectors retain provider units.

## Termination reasons

Default residual tolerances are absolute 0 and relative $\sqrt\varepsilon$, referenced to the initial residual norm (2-norm after division).
`with_residual_scale` supplies a fixed reference, while `with_residual_tolerance` changes tolerance.

| Termination reason | Conditions |
|---|---|
| `ResidualTolerance` (sole success) | Accepted-point residual meets tolerance |
| `Stagnation` | Step at or below the `StepTolerance` threshold (default absolute/relative $\sqrt\varepsilon$; component scaling compares variable-divided steps with relative reference 1) without residual reduction, or trial point rounds to the original point |
| `GlobalizationFailure` | Nonnegative slope $\mathbf{F}^{\mathsf T} J\mathbf{d}$, step below minimum, or repeated out-of-domain trials preventing movement |
| `LinearFailure(t)` | Inner GMRES stops on breakdown (`Breakdown`) or condition limits (`ConditionLimit`), or verified linear residual exceeds its allowed maximum (`t` is `Stagnation` if the inner solver reported success, otherwise its termination reason). Inner evaluation limits yield `WorkLimit` |
| `IterationLimit` | Outer iteration limit reached (default 100, `with_max_iterations`) |
| `WorkLimit`, `Cancelled`, `TimeLimit` | `SolveBudgets` or the execution context stopped work |

Inner convergence does not ensure outer convergence; outer `termination()` and inner `NewtonKrylovObservation::linear_termination()` are separate decisions.
Scalars use `NumericScalar`, accepting real and complex values; complex merit functions use summed squares of real and imaginary parts.

## Supplying actions and evaluation counts

Solve $F_i(\mathbf{x}) = x_i^2 - 1$ ($i = 1, \dots, 8$) without constructing a Jacobian.
The analytic action is $J(\mathbf{x})\mathbf{v} = 2\mathbf{x} \odot \mathbf{v}$ (componentwise products), written into `JacobianOperator::jvp_into`.
Inputs are common initial component value $x_0$ and action source (analytic or forward differences); positive starts approach the all-ones root.
Outputs give termination, iterations, residual norms, maximum errors against the exact root (independent checks), and counts by work type.
Counts separate `counts()` (Newton scope) and `accounting().nested()` (inner GMRES scope).

use scioxide_rootfind::{
    NewtonKrylovOptions, NewtonKrylovProblem, NewtonKrylovSolver, RootTermination,
};
// F_i(x) = x_i² − 1 (i = 1, …, 8). Positive initial guesses approach the all-ones root.
struct Squares(usize);
impl ResidualOperator<f64> for Squares {
    fn input_dimension(&self) -> usize {
        self.0
    }
    fn output_dimension(&self) -> usize {
        self.0
    }
    fn residual_workspace_len(&self) -> Result<usize, SciOxideError> {
        Ok(0)
    }
    fn residual_into(
        &self,
        x: &[f64],
        y: &mut [f64],
        _: &mut [f64],
    ) -> Result<(), SciOxideError> {
        y.iter_mut().zip(x).for_each(|(y, x)| *y = x * x - 1.0);
        Ok(())
    }
}
// J(x)v = 2x ⊙ v. No Jacobian entries are constructed.
impl JacobianOperator<f64> for Squares {
    fn jvp_workspace_len(&self) -> Result<usize, SciOxideError> {
        Ok(0)
    }
    fn jvp_into(
        &self,
        x: &[f64],
        v: &[f64],
        y: &mut [f64],
        _: &mut [f64],
    ) -> Result<(), SciOxideError> {
        y.iter_mut()
            .zip(x)
            .zip(v)
            .for_each(|((y, x), v)| *y = 2.0 * x * v);
        Ok(())
    }
}

} else {

};

    .map_err(|e| e.to_string())?
    .solve(&problem, &[initial; 8])
    .map_err(|e| e.to_string())?;
// Independent check: maximum error against the exact all-ones root.
let error = result
    .point()
    .iter()
    .fold(0.0_f64, |m, x| m.max((x - 1.0).abs()));
let termination = result.termination();
let residual_norm = result.residual_norm().ok_or("Residual unevaluated")?;

let columns = serde_json::json!([
    { "key": "0", "label": "Termination reason" },
    { "key": "1", "label": "Newton iterations [count]", "type": "integer" },
    { "key": "2", "label": "Residual norm ‖F‖₂ [-]", "type": "number", "format": sci2 },
    { "key": "3", "label": "max |x_i − 1| [-]", "type": "number", "format": sci2 }
]);
emit_table_with_columns!(
    columns,
    vec![(termination.to_string(), result.iterations(), residual_norm, error)],
    metadata = serde_json::json!({ "id": "summary" })
);
// Work: counts() covers Newton alone; accounting().nested() covers inner GMRES.
let (own, nested) = (result.counts(), result.accounting().nested());

    ("Residual evaluations", EvaluationRole::Residual),
    ("Action Jv evaluations", EvaluationRole::LinearOperator),
    ("Linear solves", EvaluationRole::LinearSolve),
];
let rows: Vec<_> = roles
    .iter()
    .map(|&(name, role)| (name, own.provider(role), nested.provider(role)))
    .chain([("Iterations", own.iterations(), nested.iterations())])
    .collect();
let columns = serde_json::json!([
    { "key": "0", "label": "Work type" },
    { "key": "1", "label": "Newton scope [count]", "type": "integer" },
    { "key": "2", "label": "Inner scope [count]", "type": "integer" }

    rows,
    metadata = serde_json::json!({ "id": "work" })
);
let outcome = if termination.is_success() {
    Outcome::satisfied("Residual met default tolerance")
} else if matches!(
    termination,
    RootTermination::GlobalizationFailure | RootTermination::LinearFailure(_)
) {
    Outcome::failed("Line search or inner solve returned no usable correction")
} else {
    Outcome::partial("Stopped before meeting residual tolerance")
};
emit_outcome!(
    outcome
        .status(termination.to_string())
        .diagnostic("Residual norm", residual_norm, None)
        .diagnostic("Maximum root error", error, None)
        .diagnostic("Newton iterations", result.iterations() as f64, None)
);

At default $x_0 = 0.4$ with analytic actions, five iterations reach `ResidualTolerance` with residual norm $2.1 \times 10^{-14}$ and maximum root error $3.8 \times 10^{-15}$.
Seven Newton-scope residual evaluations include the initial point and line-search trials, including rejected ones.
Five $J\mathbf{v}$ actions verify corrections, counted separately from 15 inner GMRES actions (three per solve).
Forward differences add residual evaluations per action, giving 12 Newton-scope residual evaluations and ten internally.
Zero-direction products return zero without residual evaluation, so inner residual evaluations are fewer than action counts.
Finite-difference actions count as `EvaluationRole::Residual`; GMRES restarts are not counted separately in either scope.
At $x_0 = 4$, six iterations are needed.
At $x_0 = 0.1$, both analytic and forward-difference actions stop after five iterations with residual norm $3.4 \times 10^{-9}$.
Default threshold $\sqrt\varepsilon\,\lVert \mathbf{F}(\mathbf{x}_0) \rVert$ is nearly equal for both starts: $4.2 \times 10^{-8}$ at $x_0 = 0.1$ and $3.5 \times 10^{-8}$ at $x_0 = 0.4$; neither threshold nor action-source differences explain the residual difference.
Both stop at the first accepted point below threshold, whose residual depends on the iteration path.
Local quadratic convergence would reduce the residual to rounding level with one more iteration, but meeting tolerance stops computation.

## Bratu iteration history

Discretize $u'' + \lambda e^u = 0$, $u(0) = u(1) = 0$ with centered differences at $N$ interior points ($h = 1/(N+1)$).
Residual components are $F_i = (u_{i-1} - 2u_i + u_{i+1})/h^2 + \lambda e^{u_i}$.
The following cell varies grid count $N$, $\lambda$, and forcing rules, using forward-difference actions alone to obtain the lower branch from $u = 0$.
Use absolute tolerance $10^{-7}$.
Enable history with `NewtonKrylovOptions::with_history(true)` and inspect `NewtonKrylovObservation` for linearization-point residuals, forcing terms, inner iterations, verified relative linear residuals $\lVert \mathbf{F} + J\mathbf{d} \rVert / \lVert \mathbf{F} \rVert$, inner termination, and accepted steps.
An independent check measures deviation from $u_i = u_{N+1-i}$, required by reflection symmetry of the problem.

    { "key": "1", "label": "Linearization-point residual ‖F‖ [-]", "type": "number", "format": sci2 },
    { "key": "2", "label": "Forcing term η [-]", "type": "number", "format": sci3 },
    { "key": "3", "label": "Inner iterations [count]", "type": "integer" },
    { "key": "4", "label": "‖F + Jd‖/‖F‖ [-]", "type": "number", "format": sci3, "nullText": "None" },
    { "key": "5", "label": "Inner termination reason" },
    { "key": "6", "label": "Accepted step α [-]", "type": "number", "format": sig3 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "history" })
);
// Independent check: reflection-symmetric boundaries require u_i = u_{N+1−i}.
let symmetry = result
    .point()
    .iter()
    .zip(result.point().iter().rev())
    .map(|(a, b)| (a - b).abs())
    .fold(0.0_f64, f64::max);
let termination = result.termination();
let residual_norm = result.residual_norm().ok_or("Residual unevaluated")?;
let columns = serde_json::json!([
    { "key": "0", "label": "Outer termination reason" },
    { "key": "1", "label": "Residual norm ‖F‖ [-]", "type": "number", "format": sci2 },
    { "key": "2", "label": "Reflection-symmetry error [-]", "type": "number", "format": sci2 }

emit_table_with_columns!(
    columns,
    vec![(termination.to_string(), residual_norm, symmetry)],
    metadata = serde_json::json!({ "id": "final" })
);
let outcome = if termination.is_success() {
    Outcome::satisfied("Residual met absolute tolerance 10⁻⁷")
} else if matches!(
    termination,
    RootTermination::GlobalizationFailure | RootTermination::LinearFailure(_)
) {
    Outcome::failed("Line search or inner solve returned no usable correction")
} else {
    Outcome::partial("Stopped before meeting residual tolerance")
};
emit_outcome!(
    outcome
        .status(termination.to_string())
        .diagnostic("Residual norm", residual_norm, None)
        .diagnostic("Outer iterations", result.iterations() as f64, None)
        .diagnostic("Reflection-symmetry error", symmetry, None)
);

With default $N = 16$, $\lambda = 2$, and Eisenstat–Walker, four outer iterations reach `ResidualTolerance` with residual norm $8.8 \times 10^{-8}$.
Forcing terms are 0.5, 0.326, 0.163, and $2.8 \times 10^{-5}$.
The second and third are safeguarded previous-value powers $(1+\sqrt5)/2$ ($0.5^{1.618} = 0.326$, $0.326^{1.618} = 0.163$); next the bound falls below 0.1, allowing unmodified choice 1.
Verified relative linear residuals satisfy forcing terms every iteration; inner counts are 7, 8, 7, and 10 (32 total).
Constant 0.1 needs six outer and 39 total inner iterations; from the second iteration onward residuals decrease roughly 10–20-fold per iteration, ending at norm $4.6 \times 10^{-8}$.
This follows the earlier theorem: constant forcing gives linear convergence; forcing approaching zero gives superlinear convergence.
Reflection errors are $3.0 \times 10^{-10}$ with Eisenstat–Walker and $1.4 \times 10^{-10}$ with constant 0.1, both below final residual norms.

At $N = 32$ and $\lambda = 3$, outer iterations rise only by one to five, but inner totals reach 121; the final inner solve takes 60, restarting beyond length 30.
Grid refinement increases the linear-system condition number as $O(h^{-2})$, increasing inner work even when outer iterations barely change.
Symmetry alone does not prove a correct solution; check residuals and termination too.

## Inputs, outputs, and workspaces

`NewtonKrylovInput` borrows initial guesses as contiguous slices or correctly strided one-dimensional views.
`NewtonKrylovSolver::workspace_requirements` returns `NewtonKrylovWorkspaceRequirements` (nonlinear vectors, residual/action scratch, difference storage, and Krylov-basis requirements); `workspace` allocates `NewtonKrylovWorkspace`.
`NewtonKrylovResult` holds the last accepted point, its residual, authoritative termination, and history, reusable with workspace through `solve_into`.
`solve_into` preserves output on error.
Limits or cancellation after an accepted point write that point and an incomplete termination reason to outputs.
`last_linear()` diagnoses the last inner solve; `history()` is a sequence recorded only for `with_history(true)`.
History aids diagnostics but consumes storage.

`backend::solve_newton_partitioned` is a low-level function running one Newton–Krylov solve as a child inside another solver; ordinary users do not need it.
It shares the parent's `SolveContext` evaluation limits, cancellation, and deadlines, uses solver-configured iteration/work limits, and adds evaluations including failed work to the parent.
Prepared workspace and results avoid allocations, but unlike `solve_into`, errors do not preserve outputs.

Matrix-free methods are not always faster; action costs and preconditioner quality determine total cost.
For small dense problems, also compare `NewtonSystem`, `Broyden`, and `TrustRegionSystem` in [Nonlinear systems and globalization](../nonlinear-systems/).

## Summary

`NewtonKrylovSolver` solves systems using only action $J\mathbf{v}$, stopping inner GMRES at accuracy determined by forcing $\eta_k$.
Default Eisenstat–Walker selects $\eta_k$ from linear prediction errors to avoid oversolving; constant $\eta$ gives only linear convergence.
Inner corrections are rechecked with JVPs; exceeding allowed maximum linear residuals stops with `LinearFailure`.
Nonmonotone line searches may increase $\lVert \mathbf{F} \rVert$ temporarily; determine success from sole successful reason `ResidualTolerance`.
Finite-difference actions impose forcing floor $\sqrt\varepsilon$; supply analytic or AD JVPs for greater accuracy.
