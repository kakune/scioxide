Chemical equilibria, power-flow calculations, and robot inverse kinematics form systems of nonlinear equations in $n$ unknowns $\mathbf{x} = (x_1, \dots, x_n)^{\mathsf T}$, with equally many equations.

$$
\mathbf{F}(\mathbf{x}) = \bigl(F_1(\mathbf{x}), \dots, F_n(\mathbf{x})\bigr)^{\mathsf T} = \mathbf{0}, \qquad \mathbf{F}: \mathbb{R}^n \to \mathbb{R}^n
$$

In coupled systems, changing one variable changes multiple residual components.
This page covers Newton and globalization using Jacobian $J(\mathbf{x})$ with entries $J_{ij} = \partial F_i / \partial x_j$.
Solving with actions $J\mathbf{v}$ alone appears in [Matrix-free Newton–Krylov methods](../matrix-free-newton-krylov/).

## Multivariate Newton methods

If $\mathbf{F}$ is continuously differentiable, near current point $\mathbf{x}_k$ it admits linear approximation:

$$
\mathbf{F}(\mathbf{x}_k + \mathbf{s}) = \mathbf{F}(\mathbf{x}_k) + J(\mathbf{x}_k)\,\mathbf{s} + o(\lVert \mathbf{s} \rVert)
$$

Correction $\mathbf{s}_k$ making this model zero is the Newton direction.

$$
J(\mathbf{x}_k)\,\mathbf{s}_k = -\mathbf{F}(\mathbf{x}_k), \qquad \mathbf{x}_{k+1} = \mathbf{x}_k + \mathbf{s}_k
$$

Dense LU solution of $J$ costs $O(n^3)$ per iteration with storage $O(n^2)$.
Finite-difference Jacobians add $n$ residual evaluations per iteration for forward differences or $2n$ for central differences.

### Local convergence theorem

Assume the following (Dennis–Schnabel, *Numerical Methods for Unconstrained Optimization and Nonlinear Equations*, Theorem 5.2.1).

- At root $\mathbf{x}^*$, $J(\mathbf{x}^*)$ is nonsingular with $\lVert J(\mathbf{x}^*)^{-1} \rVert \le \beta$.
- On radius-$r$ ball $B(\mathbf{x}^*, r)$, $J$ is Lipschitz continuous with $\lVert J(\mathbf{x}) - J(\mathbf{y}) \rVert \le \gamma \lVert \mathbf{x} - \mathbf{y} \rVert$.

Then if $\lVert \mathbf{x}_0 - \mathbf{x}^* \rVert < \min\bigl(r, 1/(2\beta\gamma)\bigr)$, Newton iterations are defined and converge quadratically according to

$$
\lVert \mathbf{x}_{k+1} - \mathbf{x}^* \rVert \le \beta\gamma\,\lVert \mathbf{x}_k - \mathbf{x}^* \rVert^2
$$

These root-local assumptions usually cannot be checked beforehand.

Kantorovich's theorem establishes existence and convergence using initial-point quantities alone.
Let $\lVert J(\mathbf{x}_0)^{-1} \rVert \le \beta$ and $\lVert J(\mathbf{x}_0)^{-1}\mathbf{F}(\mathbf{x}_0) \rVert \le \eta$, and assume $J$ is Lipschitz with constant $\gamma$ on a sufficiently large ball centered at $\mathbf{x}_0$.
If $h = \beta\gamma\eta \le 1/2$, a root exists in closed ball of radius $r_0 = \bigl(1 - \sqrt{1 - 2h}\bigr)/(\beta\gamma)$, and Newton from $\mathbf{x}_0$ converges to it.
Small initial correction $\eta$ and a slowly varying Jacobian (small $\gamma$) favor these conditions.
`scioxide-rootfind` does not check them.
Existence/uniqueness verification using outward-rounded intervals is covered in [scioxide-validated: interval arithmetic with guaranteed containment](../../../scioxide-validated/).

Newton iteration is affine invariant.
Applying Newton to $A\mathbf{F}(\mathbf{x}) = \mathbf{0}$ multiplied by nonsingular $A$ leaves correction $-(AJ)^{-1}A\mathbf{F} = -J^{-1}\mathbf{F}$ unchanged.
Rescaling equations therefore leaves exact-arithmetic iterates unchanged.
It changes residual-norm stopping, globalization, and floating-point linear-solve errors.

## Stopping criteria and termination reasons

`NewtonSystem`, `Broyden`, and `TrustRegionSystem` share stopping criteria.
Acceptance requires $\lVert \mathbf{F}(\mathbf{x}_k) \rVert_2 \le \varepsilon_{\mathrm{abs}} + \varepsilon_{\mathrm{rel}}\,\rho$, defaulting to $\varepsilon_{\mathrm{abs}} = 0$, $\varepsilon_{\mathrm{rel}} = \sqrt{\varepsilon}$, and reference $\rho = \lVert \mathbf{F}(\mathbf{x}_0) \rVert_2$ (initial residual norm).
`with_residual_scale(s)` replaces reference $\rho$ with fixed $s$; `with_residual_tolerance` changes $\varepsilon_{\mathrm{abs}}$ and $\varepsilon_{\mathrm{rel}}$.
Initial points already meeting this return `ResidualTolerance` after zero iterations.

| Termination reason | Conditions |
|---|---|
| `ResidualTolerance` (success) | Accepted-point residual meets the criterion above |
| `Stagnation` | Newton/Broyden step $\lVert \Delta\mathbf{x} \rVert_2$ is at most threshold $\varepsilon_{\mathrm{abs}} + \varepsilon_{\mathrm{rel}}\max(1, \lVert \mathbf{x} \rVert_2)$ from `StepTolerance` (default absolute/relative $\sqrt\varepsilon$) without residual reduction, including identical updated points without line search. For trust regions, radius exhaustion or repeated lack of progress (below) |
| `GlobalizationFailure` | Line search finds no acceptable step. For trust regions, repeated out-of-domain residual trials shrink radius until `StepTolerance` or no movement |
| `IterationLimit` | Outer iteration limit reached (default 100, `with_max_iterations`) |
| `WorkLimit`, `Cancelled`, `TimeLimit` | `SolveBudgets` or the execution context stopped work |

Only `ResidualTolerance` denotes success; other returned points are unconverged candidates.
Newton without line search returns `Singular` for zero LU pivots; Broyden without line search returns the same for numerically rank-deficient models.
Limits, cancellation, or deadlines before any accepted point return `ConvergenceFailure` or `ExecutionStopped` errors rather than results.

Small residuals do not imply small solution errors.
Near simple roots, $\mathbf{x} - \mathbf{x}^* \approx J(\mathbf{x}^*)^{-1}\mathbf{F}(\mathbf{x})$ gives position error of order $\lVert J(\mathbf{x}^*)^{-1} \rVert\,\lVert \mathbf{F}(\mathbf{x}) \rVert$.
Evaluation errors $\delta$ in $\mathbf{F}$ prevent any method achieving position accuracy much better than $\lVert J(\mathbf{x}^*)^{-1} \rVert\,\delta$.

## Equation scales and conditioning

Different component units or typical magnitudes let large components dominate residual norms.
For example, mixing pressure and mole-fraction residuals makes large pressure values control stopping.
Using representative equation scales $D_F = \operatorname{diag}(s_1, \dots, s_n)$ and variable scales $D_x = \operatorname{diag}(d_1, \dots, d_n)$,

$$
\hat{\mathbf{F}}(\hat{\mathbf{x}}) = D_F^{-1}\,\mathbf{F}(D_x \hat{\mathbf{x}}), \qquad \hat J = D_F^{-1}\,J\,D_x
$$

nondimensionalization as above compares components with equal weights.
Newton iterates remain unchanged, but stopping, line-search merit functions, and trust-region shapes change.
Condition number $\kappa(\hat J)$ also changes; relative errors of partially pivoted LU corrections are approximately order $\kappa(\hat J)\,\varepsilon$.
Dense system solvers accept no component-scale arguments; nondimensionalize equations and variables before passing them.
Matrix-free `NewtonKrylovSolver` accepts component divisors through `NonlinearScaling`.

## Globalization by line search

Far from roots, Newton corrections can be too large, increasing residuals or leaving the domain.
Globalization seeks progress from distant points while reducing residuals.
Merit function $\phi(\mathbf{x}) = \tfrac12 \lVert \mathbf{F}(\mathbf{x}) \rVert_2^2$ has gradient $\nabla\phi = J^{\mathsf T}\mathbf{F}$, whose inner product with the Newton direction is:

$$
\nabla\phi(\mathbf{x}_k)^{\mathsf T}\mathbf{s}_k = \mathbf{F}^{\mathsf T} J \bigl(-J^{-1}\mathbf{F}\bigr) = -\lVert \mathbf{F}(\mathbf{x}_k) \rVert_2^2 < 0
$$

At nonroots, exact Newton directions therefore descend $\phi$.

`BacktrackingLineSearch` follows Dennis–Schnabel Algorithm A6.3.1, starting from step $\alpha = 1$ and accepting the sufficient-decrease (Armijo) condition

$$
\phi(\mathbf{x}_k + \alpha\,\mathbf{s}_k) \le \phi(\mathbf{x}_k) + c\,\alpha\,\mathbf{F}(\mathbf{x}_k)^{\mathsf T} J(\mathbf{x}_k)\,\mathbf{s}_k
$$

at the first satisfactory $\alpha$.
Default $c = 10^{-4}$ can be changed through `BacktrackingLineSearch::new(c, min_relative_step)` to a value in $0 < c < 1$.
Replace a rejected step by the minimizer of a quadratic interpolant of observed $\phi$, using a cubic interpolant from the second rejection, and constrain it to 0.1–0.5 times the previous step.
Nonfinite trial residuals or callback `DomainError` (`OutsideDomain`) halve the step without interpolation.
Stop searching if relative movement $\alpha \max_i |s_i| / \max(1, |x_i|)$ falls below `min_relative_step` (default $\varepsilon^{2/3}$).

Global line-search convergence theory (Dennis–Schnabel §§6.3, 6.5; Nocedal–Wright §11.2) assumes bounded and uniformly nonsingular $J$ over the $\phi(\mathbf{x}) \le \phi(\mathbf{x}_0)$ set.
Under these assumptions $\lVert \mathbf{F}(\mathbf{x}_k) \rVert \to 0$; near roots $\alpha = 1$ is accepted, restoring quadratic convergence.
If $J$ approaches singularity en route, iterates may approach points satisfying $J^{\mathsf T}\mathbf{F} = \mathbf{0}$ and $\mathbf{F} \ne \mathbf{0}$, stationary points of $\phi$ that are not roots.

`NewtonSystem` defaults to no line search, applying full corrections.
With `NewtonSystemOptions::with_line_search` enabling search, numerically rank-deficient LU uses the Dennis–Schnabel perturbed-model correction:

$$
\bigl(J^{\mathsf T}J + \mu I\bigr)\mathbf{s} = -J^{\mathsf T}\mathbf{F}, \qquad \mu = \sqrt{n\varepsilon}\,\lVert J^{\mathsf T}J \rVert_1
$$

Exhausted Newton-direction search also switches once to this correction at the same point; another exhaustion stops with `GlobalizationFailure`.
With iterative linear solvers through `with_linear_solver`, always solve Newton equations; exhausted searches immediately give `GlobalizationFailure`.
Nonnegative search slope $\mathbf{F}^{\mathsf T} J \mathbf{s}$ also counts as search exhaustion.

## Broyden quasi-Newton methods

For expensive Jacobians, retain approximation $B_k$ updated by secant condition $B_{k+1}\mathbf{s}_k = \mathbf{y}_k$ ($\mathbf{y}_k = \mathbf{F}(\mathbf{x}_{k+1}) - \mathbf{F}(\mathbf{x}_k)$).
The first update (`BroydenUpdate::First`) is the closest secant-satisfying matrix to $B_k$ in Frobenius norm.

$$
B_{k+1} = B_k + \frac{(\mathbf{y}_k - B_k\mathbf{s}_k)\,\mathbf{s}_k^{\mathsf T}}{\mathbf{s}_k^{\mathsf T}\mathbf{s}_k}
$$

The second update (`BroydenUpdate::Second`) updates inverse $H = B^{-1}$ through $H_{k+1} = H_k + (\mathbf{s}_k - H_k\mathbf{y}_k)\,\mathbf{y}_k^{\mathsf T} / (\mathbf{y}_k^{\mathsf T}\mathbf{y}_k)$, equivalently $B_{k+1} = B_k + (\mathbf{y}_k - B_k\mathbf{s}_k)(B_k^{\mathsf T}\mathbf{y}_k)^{\mathsf T} / (\mathbf{y}_k^{\mathsf T}B_k\mathbf{s}_k)$ for $B$.
If $B_0$ is sufficiently close to $J(\mathbf{x}^*)$ and $\mathbf{x}_0$ sufficiently near the root, Broyden converges superlinearly (Broyden–Dennis–Moré).
Without line search, each iteration needs one residual evaluation but is not quadratically convergent.

`Broyden` evaluates the Jacobian once initially to form $B_0$.
The first update retains forward matrix $B$ and cached inverse; cached directions failing to satisfy the $B$ system to rounding accuracy trigger pivoted-LU resolution of $B$.
The second retains explicit QR factors with plane-rotation rank-one updates.
The first skips updates with zero step length; the second skips updates when the denominator satisfies $|\mathbf{y}^{\mathsf T}B\mathbf{s}| \le \sqrt{\varepsilon}\,\lVert B^{\mathsf T}\mathbf{y} \rVert\,\lVert \mathbf{s} \rVert$.
Line search uses model slope $\mathbf{F}^{\mathsf T}B\mathbf{d}$, with the same perturbed-model corrections as Newton for numerical rank deficiency.
If a secant-updated model exhausts searching, reevaluate the Jacobian at the accepted point and retry.
If that model also exhausts, switch once to perturbed correction; further exhaustion gives `GlobalizationFailure`.
Jacobian evaluation may therefore occur beyond the initial point; inspect result `counts()` counts.

## Dogleg trust-region methods

Line search fixes direction and shrinks length.
Trust regions limit the range where a linear model is trusted to radius $\Delta_k$, selecting corrections minimizing model residuals there.

$$
\min_{\lVert D\mathbf{p} \rVert_2 \le \Delta_k} \tfrac12 \lVert \mathbf{F}(\mathbf{x}_k) + J(\mathbf{x}_k)\,\mathbf{p} \rVert_2^2
$$

Dogleg approximately solves this subproblem.
Join the scaled steepest-descent Cauchy point minimizing the model to Gauss–Newton point $-J^{-1}\mathbf{F}$ by a broken line; choose its trust-boundary intersection, or Gauss–Newton if inside.
Actual-to-predicted reduction ratio $\rho_k$ determines acceptance and the next radius.

`TrustRegionSystem` uses Powell's hybrid method.

- Diagonal scale $D$ uses Jacobian column 2-norms (1 for zero columns).
  Recompute whenever evaluating Jacobians until the first accepted trial; afterward retain componentwise maxima against newly evaluated column norms.
- Compute Gauss–Newton from unpivoted QR, replacing zero diagonals of $R$ by $\varepsilon$ times that column's largest absolute entry.
- Initial radius is $100\lVert D\mathbf{x}_0 \rVert$ ($100\lVert \mathbf{F}(\mathbf{x}_0) \rVert$ if $D\mathbf{x}_0 = \mathbf{0}$); before first acceptance, shrink it to at most trial-correction norm $\lVert D\mathbf{p} \rVert$.
- $\rho_k$ is actual relative reduction in $\lVert \mathbf{F} \rVert_2^2$ divided by linear-model predicted relative reduction.
- If $\rho_k < 0.1$, halve the radius.
  If $\rho_k \ge 0.5$ or consecutive successes occur, expand to at least $2\lVert D\mathbf{p} \rVert$; if $|\rho_k - 1| \le 0.1$, set it to $2\lVert D\mathbf{p} \rVert$.
- Accept trials if $\rho_k \ge 10^{-4}$.
- After every trial, apply scaled Broyden model updates; reevaluate Jacobians only after two consecutive $\rho_k < 0.1$.

Termination `Stagnation` occurs for any of the following.

- Radius meets `StepTolerance` relative to accepted-point $\lVert D\mathbf{x} \rVert$.
- $0.1\max(0.1\Delta, \lVert D\mathbf{p} \rVert) \le \varepsilon \lVert D\mathbf{x} \rVert$ leaves no representable improvement.
- Five consecutive trials using reevaluated Jacobians fail to reduce $\lVert \mathbf{F} \rVert_2^2$ by 10%.
- Ten consecutive trials fail to reduce $\lVert \mathbf{F} \rVert_2^2$ by 0.1%.

Nonfinite trial residuals or callbacks returning `DomainError` (`OutsideDomain`) halve the radius and retry.
If this reaches radius `StepTolerance` or prevents movement, stop with `GlobalizationFailure`.
Uncomputable dogleg corrections (zero model curvature with nonzero gradient, or nonfinite corrections) produce `NumericalInstability` errors.
Trust-region global theory (Dennis–Schnabel §6.4; Nocedal–Wright Chapters 4 and §11.2) guarantees approach to stationary points $J^{\mathsf T}\mathbf{F} = \mathbf{0}$ of $\phi$ under assumptions, not convergence to roots.
`TrustRegionSystemOptions` has no line-search or iterative-linear-solver settings, using only QR models.

## Globalization from distant starts

Freudenstein–Roth (Moré–Garbow–Hillstrom test problem 2) has root $(5, 4)$ and a nonroot local minimum of $\phi$ near $(11.41, -0.8968)$.

$$
F_1(x, y) = -13 + x + \bigl((5 - y)\,y - 2\bigr)\,y, \qquad
F_2(x, y) = -29 + x + \bigl((y + 1)\,y - 14\bigr)\,y
$$

There $\lVert \mathbf{F} \rVert_2 \approx 6.999$ and $J^{\mathsf T}\mathbf{F} = \mathbf{0}$, so globalization reducing $\phi$ can be attracted to it.
The following cell solves from one initial point with five settings, listing termination, iterations, residual norms, distance from root $(5, 4)$, and residual/Jacobian evaluation counts.
Analytic Jacobians make counts available as `EvaluationRole::Residual` and `EvaluationRole::Jacobian` in `counts()`.
Root distance provides the independent check.
Select standard Moré–Garbow–Hillstrom start $(0.5, -2)$, near-root $(6, 3)$, or $(0, 2)$.
The outcome reports `TrustRegionSystem` termination, also the default for `solve_system`.

## Equation scales and stopping

Find the intersection of circle $F_1(x, y) = x^2 + y^2 - 1$ and line $F_2(x, y) = \alpha\,(x - y - 0.2)$ from $(0.8, 0.4)$ (solution $(0.8, 0.6)$).
Vary second-equation multiplier $\alpha$ from $10^{-3}$ to $10^6$, solving `NewtonSystem` with two settings.
One uses default stopping (relative $\sqrt\varepsilon$ against initial residuals); the other fixes reference 1 with `with_residual_scale(1.0)`.
The table gives initial residual $\lVert \mathbf{F}(\mathbf{x}_0) \rVert = 0.2\sqrt{1 + \alpha^2}$, solution condition number $\kappa_2(J(\mathbf{x}^*))$ (2×2 closed-form reference), termination, iterations, and analytic-solution distance.
Analytic-solution distance is the independent check.
Input $q$ adds the $\alpha = 10^q$ row.

### Interpreting results

- Iterates are independent of scale.
  With reference fixed at 1, every $\alpha$ reaches `ResidualTolerance` in four iterations with identical distance $7.1 \times 10^{-16}$.
  This demonstrates the affine invariance described earlier.
- Default stopping is affected by scale.
  Initial residual $0.2\sqrt{1 + \alpha^2}$ increases with $\alpha$, increasing the relative-$\sqrt\varepsilon$ threshold.
  But the second equation is linear, so after the first correction $F_2 \approx 0$; later residuals are nearly $|F_1|$, independently of $\alpha$.
  At $\alpha \le 10$, four iterations give distance $7.1 \times 10^{-16}$; at $10^2 \le \alpha \le 10^5$, three stop with $3.8 \times 10^{-8}$; at $\alpha = 10^6$, two stop with $2.7 \times 10^{-4}$.
  Every row reports successful `ResidualTolerance`; termination alone does not reveal these accuracy differences.
- The condition number is minimized at $\alpha \approx 1.4$ with 1.15, growing both ways to $1.43 \times 10^3$ at $\alpha = 10^{-3}$ and $7.14 \times 10^5$ at $\alpha = 10^6$.
  This two-variable example reaches distance $10^{-16}$ even with a condition number of order $10^6$, but systems with condition numbers above $10^8$ or finite-difference Jacobians may slow or stall through correction errors $\kappa\varepsilon$.

The outcome uses default solving at input $\alpha$, reporting solution distances as diagnostics even for `satisfied`.
Relative stopping against initial residuals is meaningful when component scales are aligned.
For one disproportionately scaled equation, nondimensionalize equations and variables or give a physically meaningful reference with `with_residual_scale`.

## Residual and Jacobian types

`ResidualOperator` (scioxide-core) specifies input/output dimensions, an action writing residuals into caller arrays, and residual-evaluation scratch length.
Dense solvers handle nonempty square systems, retaining caller-defined input/residual component order.
`ResidualFn` provides actions through closures; `with_jacobian` adds row-major dense Jacobians (entry $(i, j)$ at $\partial F_i/\partial x_j$).
`DenseJacobian` expresses analytic or AD dense-Jacobian capabilities.
Callers implement AD capabilities explicitly; arbitrary Rust residual functions are not differentiated automatically.
Select Jacobian sources with `DerivativeStrategy` of `with_derivative_strategy`.
Dense solvers default to `AnalyticOrForward`, using analytic Jacobians if supplied, otherwise forward differences ($n$ residual evaluations each).

`NewtonSystemOptions`, `BroydenOptions`, and `TrustRegionSystemOptions` retain method settings, sharing tolerance, scale, iteration-limit, `SolveBudgets`, execution-policy, and workspace-memory options.
Line-search rules use `RootLineSearch`, implemented by `BacktrackingLineSearch`.
`NewtonSystemOptions` accepts `with_line_search` and `with_linear_solver` (iterative linear solvers replacing LU); `BroydenOptions` accepts only `with_line_search`.
`TrustRegionSystemOptions` has neither setting.
Globalization avoids unsuitable corrections without guaranteeing root convergence from arbitrary starts.

## Prepared outputs and workspaces

`solve` and `solve_into` accept initial slices `&[S]`, returning `DimensionMismatch` for dimension mismatches and `NonFinite` for NaN/infinite components.
`workspace_requirements` of `SystemRootSolver` returns `SystemWorkspaceRequirements`; `workspace` allocates `SystemWorkspace`.
Workspace stores iteration vectors, Jacobians, factors, and numerical-difference scratch; requirements depend on method and residual scratch as well as dimension.
Prepare `SystemRootResult` and repeat `solve_into` to avoid repeated allocations.
Without settings or diagnostics, one-call `solve_system(f, initial)` solves residual closure `f(x, out)` with default `TrustRegionSystem` (forward-difference Jacobians and Broyden updates), returning `Vec` points only on success and errors such as `ConvergenceFailure` otherwise.
Input/workspace mismatches, numerical breakdown, and residual-callback errors preserve outputs.
Limit stops after accepted points write unconverged results to outputs.

Result `residual_norm()` is `None` if unevaluated.
`counts()` returns solver-local residual/Jacobian/factorization/linear-solve counts through `EvaluationCounts`; `accounting()` includes nested work.
When comparing many cheap iterations against fewer expensive ones, inspect evaluations as well as iterations, as in [Comparisons from distant starts](#globalization-from-distant-starts).
Dense storage is $O(n^2)$ and factorization $O(n^3)$; consider [Matrix-free Newton–Krylov methods](../matrix-free-newton-krylov/) for large systems.

## Summary

System Newton solves linearized equations and converges quadratically with nonsingular root Jacobians and sufficiently nearby starts.
Default stopping is relative $\sqrt\varepsilon$ against initial residuals; disproportionate equation scales can leave large errors even with successful `ResidualTolerance`.
Nondimensionalize or provide references through `with_residual_scale`, checking solution-error estimates $\lVert J^{-1} \rVert \lVert \mathbf{F} \rVert$ as well as residuals.
For distant starts use `NewtonSystem` with `with_line_search` or `TrustRegionSystem`; for expensive Jacobians use `Broyden`.
As Freudenstein–Roth demonstrates, any globalization can stop at nonroot stationary points of $\phi$; do not use `GlobalizationFailure` or `Stagnation` points as solutions, but resolve from new starts.
