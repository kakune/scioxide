When no bracket is known or rapid convergence near a root is desired, open methods choose the next point from derivatives or interpolation at the current points.
Open methods do not preserve a bracket; distant initial guesses can diverge, leave the domain, or approach another root.
Zero derivatives and periodic cycles of iterates can also occur.
Local convergence orders depend on assumptions such as smoothness and root multiplicity.

## Deriving Newton–Raphson and quadratic convergence

Assume function $f: \mathbb{R} \to \mathbb{R}$ is twice continuously differentiable ($f \in C^2$) near the root.
Taylor expansion around current point $x_k$ gives, for some $\xi$ between $x_k$ and $x_k + s$:

$$
f(x_k + s) = f(x_k) + f'(x_k) s + \frac{f''(\xi)}{2} s^2
$$

Dropping the quadratic term and solving linear model $f(x_k) + f'(x_k) s = 0$ gives the Newton–Raphson update.

$$
s_k = -\frac{f(x_k)}{f'(x_k)}, \qquad x_{k+1} = x_k - \frac{f(x_k)}{f'(x_k)}
$$

### Error recurrence at simple roots

Let true root $x^*$ be simple ($f'(x^*) \ne 0$), with error $e_k = x_k - x^*$.
Apply the expansion from $x_k$ toward the root ($s = -e_k$), substituting $f(x^*) = 0$ to obtain:

$$
0 = f(x_k) - f'(x_k)\, e_k + \frac{f''(\xi_k)}{2} e_k^2
$$

Dividing by $f'(x_k)$ and comparing with the update gives

$$
e_{k+1} = e_k - \frac{f(x_k)}{f'(x_k)} = \frac{f''(\xi_k)}{2 f'(x_k)}\, e_k^2
$$

follows.
On interval $I = [x^* - r, x^* + r]$ centered at the root, assume $f' \ne 0$ and set $M = \max_I \lvert f'' \rvert / (2 \min_I \lvert f' \rvert)$; then $x_k \in I$ implies $\lvert e_{k+1} \rvert \le M \lvert e_k \rvert^2$.
If $\lvert e_0 \rvert \le r$ and $M \lvert e_0 \rvert < 1$, then $\lvert e_1 \rvert < \lvert e_0 \rvert$, keeping iterations in $I$ and ensuring convergence.
In the limit $e_{k+1} / e_k^2 \to f''(x^*) / (2 f'(x^*))$, convergence is quadratic, approximately doubling correct digits per iteration.

The convergence region depends on $M$, which compares variation in the derivative with its magnitude.
Scaling the entire function by a constant leaves Newton updates unchanged, so small $\lvert f'(x^*) \rvert$ alone cannot determine basin size.
Each iteration uses one function and one first-derivative evaluation; if their costs match, order per evaluation is $\sqrt 2 \approx 1.414$ ([Convergence order and evaluation efficiency](oxref:rootfind-convergence-order)).

Outside this region, Newton provides no global convergence guarantee.
If $f'(x_k) = 0$, no update can be formed and scioxide-rootfind stops with `Stagnation`.
Iterations can also cycle.
For example, solving $f(x) = x^3 - 2x + 2$ from $x_0 = 0$ alternates between the same two points $x_1 = 1$ and $x_2 = 0$.
`Newton` retains only the previous point, so it does not classify this alternation as stagnation; it reaches default limit 100 with `IterationLimit` and returns observed point $x = 1$ ($f(1) = 1$) minimizing $\lvert f \rvert$.
With a known bracket, `SafeguardedNewton` keeps updates inside it ([Bracketing safeguards and runtime selection](#bracketing-safeguards-and-runtime-selection)).

## Loss of order at repeated roots

A repeated root $x^*$ of multiplicity $m \ge 2$ permits representation $f(x) = (x - x^*)^m g(x)$ ($g(x^*) \ne 0$).
Differentiating the product gives

$$
f'(x) = m (x - x^*)^{m-1} g(x) + (x - x^*)^m g'(x)
$$

so Newton's correction is:

$$
\frac{f(x)}{f'(x)} = \frac{(x - x^*) g(x)}{m g(x) + (x - x^*) g'(x)} = \frac{x - x^*}{m} \bigl( 1 + O(x - x^*) \bigr)
$$

Substitution into the update yields error recurrence

$$
e_{k+1} = \left( 1 - \frac{1}{m} \right) e_k + O(e_k^2)
$$

and reduces convergence to linear with error ratio $1 - 1/m$.
For $m = 2$, error halves per iteration; for $m = 4$, it is multiplied by $3/4$.

Repeated roots also change the residual-to-position-error relationship.
Near the root $\lvert f(x_k) \rvert \approx \lvert g(x^*) \rvert \lvert e_k \rvert^m$; thus for $m = 4$, even position error $10^{-3}$ gives residual only order $10^{-12}$, satisfying residual-only tolerances prematurely.
With evaluation rounding error $\delta$, position cannot be determined more finely than order $(\delta / \lvert g(x^*) \rvert)^{1/m}$ ([Residual and position error](oxref:rootfind-residual-and-position-error)).

If multiplicity $m$ is known, changing the update to $x_{k+1} = x_k - m f(x_k)/f'(x_k)$ restores quadratic convergence.
Alternatively, roots of $u(x) = f(x)/f'(x)$ are simple, so solve $u$ as a new function with Newton ($u'$ requires $f''$).
scioxide-rootfind applies neither modification automatically; supply a modified function as `ScalarFunction` when needed.

## Local cubic convergence of Halley's method

If second derivatives are available, Halley's method is an option.
Applying Newton to $g(x) = f(x) / \sqrt{\lvert f'(x) \rvert}$ gives the same roots of $g$ as $f$, with update:

$$
x_{k+1} = x_k - \frac{2 f(x_k) f'(x_k)}{2 f'(x_k)^2 - f(x_k) f''(x_k)} = x_k - \frac{s_k}{1 - a_k}, \qquad s_k = \frac{f(x_k)}{f'(x_k)},\ a_k = \frac{f(x_k) f''(x_k)}{2 f'(x_k)^2}
$$

Near a simple root of $f \in C^3$, errors satisfy

$$
e_{k+1} = \left( \frac{f''(x^*)^2}{4 f'(x^*)^2} - \frac{f'''(x^*)}{6 f'(x^*)} \right) e_k^3 + O(e_k^4)
$$

giving cubic convergence.
Each iteration evaluates the function and first and second derivatives once each; equal costs give order per evaluation $\sqrt[3]{3} \approx 1.442$.

Far from roots, $a_k$ can approach 1, making the denominator zero, or the denominator can change sign and reverse the update.
scioxide-rootfind's `Halley` uses Halley updates only for $\lvert a_k \rvert < 1$, reverting to the Newton update $x_k - s_k$ for $\lvert a_k \rvert \ge 1$.
Near a root, $a_k \to 0$, so this switch preserves local cubic convergence.
`Halley` and `SafeguardedHalley` always require analytic first and second derivatives.

## Secant and Muller methods

When derivatives are unavailable or expensive, interpolation through past points substitutes for them.

### Secant method

Secant (`Secant`) approximates derivatives by the slope through the two latest points $x_k$ and $x_{k-1}$.

$$
x_{k+1} = x_k - f(x_k) \frac{x_k - x_{k-1}}{f(x_k) - f(x_{k-1})}
$$

Near simple roots, errors satisfy $e_{k+1} \approx \bigl(f''(x^*)/(2 f'(x^*))\bigr) e_k e_{k-1}$.
Writing $\lvert e_k \rvert \sim \lvert e_{k-1} \rvert^p$ gives $p^2 = p + 1$, with convergence order the golden ratio $\varphi = (1 + \sqrt 5)/2 \approx 1.618$.
Only one new function evaluation is needed per iteration, making it faster per evaluation than Newton (approximately 1.414) when derivative costs equal function costs.
Equal function values prevent forming a secant and stop with `Stagnation`.

### Muller method

Muller (`Muller`) constructs the quadratic through the three latest points $x_{k-2}$, $x_{k-1}$, and $x_k$ using divided differences, selecting the root closer to $x_k$ as the next point.
Writing the quadratic as $q(x) = A (x - x_k)^2 + B (x - x_k) + f(x_k)$ gives correction

$$
x_{k+1} - x_k = \frac{-2 f(x_k)}{B \pm \sqrt{B^2 - 4 A f(x_k)}}
$$

where choosing the denominator sign with greater magnitude selects the root near $x_k$ and avoids cancellation.
Convergence order is approximately 1.839, the real root of $p^3 = p^2 + p + 1$, with one function evaluation per iteration.

Real `Muller` stops with `ComplexStepRequired` when negative discriminant $B^2 - 4 A f(x_k)$ requires a complex next point, without entering the complex domain.
The returned point is the last accepted real point.
To follow complex roots, supply a complex function and use `ComplexMuller` ([Complex roots and basins of attraction](../complex-roots/)).

## Newton convergence at repeated roots

Solve $f(x) = (x - 1)^m$ (root $x^* = 1$, multiplicity $m$) with `Newton` from point $x_0 = 1 + \lvert e_0 \rvert$ with initial error $\lvert e_0 \rvert = \lvert x_0 - 1 \rvert$.
The following cell resolves with increasing iteration limits $k = 1, 2, \dots$, reading position error at iteration $k$ from result `point()`.
Inputs are multiplicity $m$ (1–8) and initial error $\lvert e_0 \rvert$ (0.1–2).
Outputs compare observed errors against a model multiplying error by $1 - 1/m$ per iteration (dashed), and tabulate stopping positions for defaults and absolute-residual-only tolerance $\sqrt{\varepsilon}$.
The final outcome uses the solve's termination reason with default criteria.

```rust
//| id: rootfind-newton-multiplicity
//| ref: rootfind-newton-multiplicity
//| title: "Measure Newton position errors at repeated roots per iteration"
//| run: reactive
//| crates: [scioxide-core, scioxide-rootfind, scioxide-differentiate]
//| inputs:
//|   multiplicity: {"type":"range","label":"Root multiplicity m [-]","description":"Changes the order of the flat repeated root.","min":1,"max":8,"step":1,"value":4}
//|   initial_error: {"type":"range","label":"Initial position error |e₀| [-]","description":"Changes initial distance from true root 1.","min":0.1,"max":2,"step":0.1,"value":1}
//| cases:
//|   - {"id":"simple-root","label":"m = 1 (simple root)","description":"Since f is linear, both criteria reach the root in one iteration with ResidualTolerance.","inputs":{"multiplicity":1}}
//|   - {"id":"flat-root","label":"m = 8 (flat repeated root)","description":"Absolute residual alone accepts after 17 iterations, leaving position error 1.0 × 10⁻¹.","inputs":{"multiplicity":8}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"stops","path":"/rows/0/1","equals":"StepTolerance"}
//|       - {"artifact":"stops","path":"/rows/0/2","equals":114}
//|       - {"artifact":"stops","path":"/rows/0/4","approx":{"value":5.77e-15,"rtol":1e-2}}
//|       - {"artifact":"stops","path":"/rows/1/1","equals":"ResidualTolerance"}
//|       - {"artifact":"stops","path":"/rows/1/2","equals":16}
//|       - {"artifact":"stops","path":"/rows/1/3","approx":{"value":1.0e-8,"rtol":5e-2}}
//|       - {"artifact":"stops","path":"/rows/1/4","approx":{"value":1.00e-2,"rtol":1e-2}}
//|       - {"path":"/outputs/2/state","equals":"satisfied"}
//|   - case: simple-root
//|     expect:
//|       - {"artifact":"stops","path":"/rows/0/1","equals":"ResidualTolerance"}
//|       - {"artifact":"stops","path":"/rows/0/2","equals":1}
//|       - {"artifact":"stops","path":"/rows/1/1","equals":"ResidualTolerance"}
//|       - {"artifact":"stops","path":"/rows/1/2","equals":1}
//|   - case: flat-root
//|     expect:
//|       - {"artifact":"stops","path":"/rows/1/1","equals":"ResidualTolerance"}
//|       - {"artifact":"stops","path":"/rows/1/2","equals":17}
//|       - {"artifact":"stops","path":"/rows/1/4","approx":{"value":1.03e-1,"rtol":1e-2}}
//|       - {"path":"/outputs/2/state","equals":"satisfied"}
use scioxide_core::{Budget, RealScalar, ResidualTolerance};
use scioxide_differentiate::DerivativeStrategy;
use scioxide_rootfind::{Newton, ScalarFn, ScalarRootOptions, ScalarRootSolver};

// Solve the same repeated root with default combined step/residual criteria and residual-only criteria.
let m = multiplicity.round() as i32;
let function = ScalarFn::new(|x: f64| Ok(RealScalar::powi(x - 1.0, m)))
    .with_derivative(|x: f64| Ok(f64::from(m) * RealScalar::powi(x - 1.0, m - 1)));
let x0 = 1.0 + initial_error;
let (mut series, mut rows, mut model_end) = (Vec::new(), Vec::new(), 0_usize);
let mut default_result = None;
for residual_only in [false, true] {
    let name = if residual_only {
        "Absolute residual only"
    } else {
        "Default step and residual"
    };
    let (mut measured, mut last) = (vec![[0.0, initial_error]], None);
    // Increase limits successively and inspect each iterate's position through exposed results.
    for k in 1..=300_usize {
        let mut options = ScalarRootOptions::default()
            .with_max_iterations(Budget::try_from(k).map_err(|e| e.to_string())?);
        if residual_only {
            options = options.with_residual_tolerance(
                ResidualTolerance::new(f64::EPSILON.sqrt(), 0.0).map_err(|e| e.to_string())?,
            );
        }
        let result = Newton::new(DerivativeStrategy::Analytic)
            .solve(&function, x0, &options)
            .map_err(|e| e.to_string())?;
        let error = (result.point() - 1.0).abs();
        if error > 0.0 {
            measured.push([result.counts().iterations() as f64, error]);
        }
        let done = result.termination().is_success();
        last = Some(result);
        if done {
            break;
        }
    }
    let result = last.ok_or("No solution record")?;
    model_end = model_end.max(result.counts().iterations());
    rows.push((
        name,
        result.termination().to_string(),
        result.counts().iterations(),
        result.residual().abs(),
        (result.point() - 1.0).abs(),
    ));
    if !residual_only {
        default_result = Some(result);
    }
    series.push(
        serde_json::json!({"name": name, "points": measured, "style": {"showSymbol": true}}),
    );
}
// Independent check: theoretical error reduction per iteration is 1 − 1/m.
let model: Vec<_> = (0..=model_end)
    .filter_map(|k| {
        let e = initial_error * RealScalar::powi(1.0 - 1.0 / f64::from(m), k as i32);
        (e > 0.0).then_some([k as f64, e])
    })
    .collect();
series.push(serde_json::json!({
    "name": "Model (1 − 1/m)^k |e₀|",
    "points": model,
    "style": {"lineType": "dashed"}
}));
emit_line_chart!(
    &series,
    options = &serde_json::json!({
        "xLabel": "Iteration k [count]",
        "yLabel": "Position error |x_k − 1| [-]",
        "yType": "log",
        "xMin": 0.0,
        "xMax": 300.0,
        "yMin": 1e-16,
        "yMax": 2.0
    })
);
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let columns = serde_json::json!([
    { "key": "0", "label": "Criterion" },
    { "key": "1", "label": "Termination reason" },
    { "key": "2", "label": "Iterations [count]", "type": "integer" },
    { "key": "3", "label": "Residual |f(x)| [-]", "type": "number", "format": sci3 },
    { "key": "4", "label": "Position error |x − 1| [-]", "type": "number", "format": sci3 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "stops" })
);
// Determine the outcome from the solve with default criteria.
let result = default_result.ok_or("No default-criterion result")?;
let caveat = "Success means step and residual criteria were met. Check repeated-root position accuracy through table errors.";
let outcome = if result.is_success() {
    Outcome::satisfied("Accepted with default criteria").explanation(caveat)
} else {
    Outcome::partial("Iteration limit reached before default criteria were met")
};
emit_outcome!(
    outcome
        .status(result.termination().to_string())
        .diagnostic("Iterations", result.counts().iterations() as f64, None)
        .diagnostic("Position error", (result.point() - 1.0).abs(), None)
);
```

Chart axis ranges stay fixed across inputs.
At $m = 1$, errors reach zero; omit three unplottable points in total, one observed point per method and one model point.
Inspect reached positions and termination reasons in the table.

### Results

- Order loss: for $m = 1$, $f$ is linear, reaching the root in one iteration with `ResidualTolerance`.
  At $m = 4$, observed errors overlap model $0.75^k \lvert e_0 \rvert$, requiring approximately eight iterations per decimal digit of error reduction.
- Residual versus position error: with absolute-residual-only criteria, $m = 4$ and initial error 1 are accepted after 16 iterations at residual $1.0 \times 10^{-8}$, but position error remains $1.0 \times 10^{-2}$.
  At $m = 8$, acceptance takes 17 iterations with position error $1.0 \times 10^{-1}$.
- Default criteria: iteration continues until coordinate steps are of order $4\varepsilon(1 + \lvert x \rvert) \approx 8\varepsilon$ and residual falls to at most $\sqrt{\varepsilon}$ times its initial value; at $m = 4$, it stops after 114 iterations with `StepTolerance` and position error $5.8 \times 10^{-15}$.
  This is possible because $x - 1$ is exact near the root and $(x - 1)^m$ has no evaluation-rounding floor.
  Evaluating an expanded polynomial for $f$ buries residuals in rounding error of order $\varepsilon$, determining position only to order $\varepsilon^{1/m}$.
  `StepTolerance` indicates satisfied step/residual criteria, not certified repeated-root position accuracy.

## Stopping criteria and returned points

Real and complex methods without brackets (`Newton`, `Halley`, `Secant`, `Muller` and their complex versions) share an iteration framework for stopping.

- Initial points are evaluated in order, with equal points evaluated once.
  An exact initial zero stops with `ResidualTolerance` without evaluating remaining initial points.
- Criteria are checked after every new point evaluation.
  An exact zero or an explicitly configured `with_residual_tolerance` residual criterion gives `ResidualTolerance`.
  Coordinate step $\lvert x_{k+1} - x_k \rvert$ at most $4\varepsilon + 4\varepsilon \max(\lvert x_k \rvert, \lvert x_{k+1} \rvert)$ together with $\lvert f(x_{k+1}) \rvert \le \sqrt{\varepsilon}\, s$ gives `StepTolerance`.
  Scale $s$ is the value supplied by `with_residual_scale` or, if absent, the maximum initial $\lvert f \rvert$; it remains fixed during solving ([Default stopping criteria for methods in one variable](oxref:rootfind-scalar-default-stopping)).
- A candidate matching a retained point reuses that observation for checking; unsuccessful acceptance gives `Stagnation`.
  Small steps without residual reduction and zero derivative/secant/parabolic denominators preventing updates also give `Stagnation`.
- `Stagnation` and `IterationLimit` return the observed point minimizing $\lvert f \rvert$, retaining earlier points on ties.
  Numerical-difference probes also participate in this comparison.
  If the minimum is exactly zero, termination changes to `ResidualTolerance`.
  Thus even an exact-root probe does not stop the iteration there until stagnation or a limit.
- `ComplexStepRequired` and limit-related stops (`WorkLimit`, `Cancelled`, `TimeLimit`) return the last accepted point.
- Nonfinite function values or analytic derivatives produce a `NonFinite` error.

## Providing function values and derivatives

`ScalarFunction` requires function values and optionally provides analytic first/second derivatives and AD first derivatives.
Adding `with_derivative` to `ScalarFn` gives `ScalarFnWithDerivative`; additionally adding `with_second_derivative` gives `ScalarFnWithDerivatives`.
For AD, implement `automatic_derivative` and select that capability through `DerivativeStrategy` of `Newton`.
The solver does not automatically differentiate ordinary Rust callback code.

`DerivativeStrategy` distinguishes analytic (`Analytic`), AD (`Automatic`), forward differences (`Forward`), central differences (`Central`), default `AnalyticOrForward` falling back to forward differences without analytic derivatives, `AnalyticOrCentral` falling back to central differences, and `AnalyticOrAutomaticOrForward` additionally trying AD.
If no specified source is usable, a `InvalidInput` error results.
Each derivative request counts one first-derivative evaluation (`EvaluationRole::Jacobian`) per attempted source.
Difference probes count under the same role as function evaluations (default `EvaluationRole::Function`, changed by `with_evaluation_role`) and undergo domain/nonfinite checks.
Analytic-derivative Newton evaluates the function once at the new point per iteration; forward differences add one probe, central differences two.
For example, solving $x^2 - 2$ from $x_0 = 1$ with defaults terminates after six iterations with `StepTolerance` in every case; function evaluations including the initial point total seven with analytic derivatives, 13 with forward differences, and 19 with central differences.
Excessively small difference steps increase rounding error; stricter iteration tolerances alone do not improve derivative accuracy.
Consider derivative sources and difference steps separately ([Taylor expansions and step selection](../../../scioxide-differentiate/algorithms/taylor-and-step-size/)).
Scalar-method storage for differences and bracketing safeguards is fixed-size; no caller-workspace form is provided.

## Bracketing safeguards and runtime selection

`SafeguardedInitialGuess` combines an interval and an initial point inside it.
`SafeguardedInitialGuess::new` returns `InvalidInput` for initial points outside the interval and `NonFinite` for nonfinite ones, detecting invalid input before function evaluation.
`SafeguardedNewton` and `SafeguardedHalley` first evaluate endpoints to check the sign change, then test Newton (or Halley) candidates with two conditions each iteration.

1. The candidate lies inside the interval.
   Rounded candidates coinciding with endpoints move to their adjacent interior floating-point values before evaluation.
2. Movement from the current point is at most half that two iterations earlier (half the interval width for the first two iterations).

Failure of either condition uses the midpoint and resets movement history.
Updating the bracket at each evaluated point gives interval-width stopping `BracketTolerance` as in bracketing methods; `StepTolerance` is unused.
`Stagnation` and `IterationLimit` return the bracket endpoint with smaller $\lvert f \rvert$.
The existence argument for a root inside assumes continuity.

Individual `ScalarRootSolver` specifies initialization through an associated type, preventing mistakes such as passing a single point to a bracketing method.
Runtime-selected `ScalarRootMethod` maps `Bracket`, `Guess`, `Pair`, `Triple`, and `Safeguarded` of `ScalarRootInput` to each method.
Mismatched methods and initialization forms are rejected before function evaluation.

`solve_scoped` accepts an execution scope, sharing evaluation limits and cancellation with nested solves.
Read stopped results by combining `termination()`, `point()`, `residual_report()`, and `counts()` of `RootResult`.
Derivative-based and bracketing comparisons appear in [Kepler's equation and eccentricity](../../examples/kepler-equation/).

## Summary

Newton is locally quadratic, Halley cubic, secant approximately order 1.618, and Muller approximately 1.839 near simple roots; none guarantees convergence from distant guesses.
When derivative costs match function costs, secant is more efficient per evaluation than Newton; finite-difference Newton needs still more evaluations.
At repeated roots, order drops to linear and small residuals can leave large position errors; check position accuracy through $\lvert f \rvert / \lvert f' \rvert$ or multiplicity-based estimates together with termination reasons.
With a known interval, use `SafeguardedNewton` or `SafeguardedHalley` to keep updates inside it.
Points returned with `Stagnation` or `IterationLimit` minimize observed residuals; inspect termination before using them as root approximations.
