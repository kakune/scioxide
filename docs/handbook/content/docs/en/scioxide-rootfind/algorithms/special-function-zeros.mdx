Eigenfrequency calculations require more than finding one point where a function vanishes.
For example, the desired quantity may be the $m$th positive zero $j_{\nu,m}$ of Bessel $J_\nu$ in ascending order.
Repeated ordinary Newton solves with different guesses can converge repeatedly to one zero or skip intervening zeros.
`special_zeros_with_options` specifies family, branch, starting index, and count to compute values and indices together.

## Families and branches

`special_zeros_with_options(family, branch, start, count, &options)` accepts family `SpecialZeroFamily`, branch `SpecialZeroBranch`, starting index, count, and `SpecialZeroOptions`.
Unsupported combinations and out-of-range orders return `InvalidInput` before evaluating functions.
`special_zeros(family, count)` computes `count` zeros from index 1 on sequence `Real` with defaults, returning their real parts only if every check passes; other termination becomes errors such as `ConvergenceFailure`.
Function and derivative zeros form different sequences; specify the intended sequence.

| Family | Real-axis sequence (`Real`) | Origin (`Origin`) | Complex sequence (`Complex`) |
|---|---|---|---|
| `BesselJ(ν)` ($\nu > -1/2$) | Positive zeros | — | — |
| `BesselJPrime(ν)` ($\nu \ge 0$) | Positive zeros excluding origin | When $\nu = 0$ ($J_0'(0) = 0$) | — |
| `BesselY(ν)`, `BesselYPrime(ν)` ($\nu \ge 0$) | Positive zeros | — | For $\nu = 0, 1$, conjugation only |
| `AiryAi`, `AiryAiPrime` | Negative real zeros | — | — |
| `AiryBi`, `AiryBiPrime` | Negative real zeros | — | Conjugation only |
| `Kelvin(KelvinZeroFunction)` | Positive zeros of order-zero ber, bei, ker, kei and derivatives | bei, ber′, bei′ | — |
| `Erf`, `FresnelC`, `FresnelS` | No zeros (`NoZeros`) | Yes | erf permits conjugation/sign reversal; Fresnel all three operations |
| `FresnelCPrime`, `FresnelSPrime` | Positive zeros | Only $S'$ | All three operations |

`SpecialZeroBranch::Real` denotes real-axis sequences, `Origin` the origin alone, and `Complex { conjugate, negate, rotate }` the standard upper-half-plane sequence transformed in order by conjugation, sign reversal, and multiplication by $i$.
`SpecialZeroBranch::UPPER` is the untransformed upper-half-plane sequence.
Real Airy zeros are indexed outward from the origin; other real sequences increase from the smallest zero.
Real-axis and complex sequence indices begin at 1.
Origin requests require starting index zero and count at most one, only for families vanishing there ($J_0'$, erf, $C$, $S$, $S'$, bei, ber′, bei′).
Origin multiplicities are known (three for $S$ and ber′, two for $S'$ and bei, one otherwise), available through `SpecialZero::multiplicity()`.
erf and Fresnel $C$/$S$ have no real zeros except the origin, so `Real` requests return `NoZeros` as empty sequences.

## Initial approximations and index determination

Indexed zero computation must identify which zero as well as approximate its value.
`special_zeros_with_options` assigns indices by family as follows.

- Bessel $J_0$, $J_1$, $J_{5/2}$, $J_1'$, $Y_0$, and $Y_1$ use tabulated initial guesses through the eighth zero.
  Otherwise, when $\beta = (m + \nu/2 - 1/4)\pi$ ($1/4$ is $3/4$ for $Y_\nu$ and $J_\nu'$) satisfies $\beta > 8$ and $\beta > 2(\nu^2 + 1)$, use McMahon (DLMF 10.21.19–20); for $\nu \ge 32$ and zeros near turning point $x \approx \nu$, use Olver uniform asymptotics (DLMF 10.21).
  Given an initial guess, check for a sign change in a bracket extending 0.35 times neighboring-guess spacing (or $\pi$ without one) on each side, then polish with Newton, replacing out-of-bracket steps by bisection.
  Without a guess or sign change, count rightward sign changes from $\max(\nu, 1/8)$ in steps $(\pi/4)/\sqrt{1 + 1/(4x^2)}$ (less than one-quarter oscillation period), using the interval for change $m$.
  Bracket zeros of $J_\nu'$ and $Y_\nu'$ using their interlacing between adjacent zeros of $J_\nu$ or $Y_\nu$.
- Kelvin uses tables and McMahon-type expansions (DLMF 10.70), checking for a sign change in an interval extending $0.4\pi$ to each side.
  Failed sign checks fall back to the same counting search as Bessel.
- Airy uses tables through the eighth zero, then DLMF 9.9.18–19 expansions, checking endpoint signs.
  Endpoint signs may use Airy differential-equation Taylor polynomials with checked error propagation and remainders.
- Complex erf and Fresnel zeros use tables through index eight and asymptotics above it (DLMF 7.13).
  Apply complex Newton nearby, stopping with `Unverified` if iterates leave a circle with radius 0.45 times the next-guess distance.
  Real zeros of $C'(z) = \cos(\pi z^2/2)$ and $S'(z) = \sin(\pi z^2/2)$ have closed forms $\sqrt{2m - 1}$ and $\sqrt{2m}$.

Round polished points to the output type, apply branch transformations such as conjugation, and reevaluate the original function at final coordinates.
If rounding/transformation moves a coordinate more than 0.45 times neighboring-zero spacing ($\pi$ for real Bessel/Kelvin zeros, otherwise neighboring-guess distance), reject the requested index with `Unverified`.
Estimated error $(|f| + \delta f)/|f'| + |\text{displacement}|$ ($\delta f$ bounds evaluation error in $f$) exceeding tolerance, or zero magnitude not increasing beyond the preceding zero, also yields `Unverified`.
Tolerance is `StepTolerance` in `SpecialZeroOptions::with_tolerance`, default absolute/relative $\sqrt\varepsilon$ with relative scale equal to zero magnitude.

This procedure is a numerical heuristic, not a proof against skipping or double-counting zeros.
Sign changes use floating-point evaluations; preventing two zeros per step relies on oscillation-period estimates.
Intervals from `SpecialZero::bracket()` are not outward-rounded enclosures either.
SciOxide provides no certified enclosures for special-function zeros.
scioxide-validated's one-call `roots` and verifier `ScalarRootVerifier` prove root existence/uniqueness with interval Newton when callers supply interval extensions of values and derivatives, but provide no Bessel or similar interval extensions ([scioxide-validated: interval arithmetic with guaranteed containment](../../../scioxide-validated/)).

## McMahon expansion

With fixed $\nu$ and $m \to \infty$, writing $\beta = (m + \nu/2 - 1/4)\pi$ and $\mu = 4\nu^2$ gives

$$
j_{\nu,m} \sim \beta - \frac{\mu - 1}{8\beta} - \frac{4(\mu - 1)(7\mu - 31)}{3(8\beta)^3} - \cdots
$$

McMahon's expansion ([DLMF 10.21.19](https://dlmf.nist.gov/10.21#vi)).
$\beta$ is a zero of large-$x$ asymptotic $J_\nu(x) \approx \sqrt{2/(\pi x)}\cos(x - \nu\pi/2 - \pi/4)$; subsequent terms correct it.
This fixes $\nu$ in the asymptotic limit and is not uniformly accurate for large $\nu$.
For small $m$ and large $\nu$, truncated expansions cannot serve as high-accuracy references.
At $\nu = 1/2$, $J_{1/2}(x) = \sqrt{2/(\pi x)}\,\sin x$ gives $j_{1/2,m} = m\pi$.
Then $\mu - 1 = 0$, and every term from $\beta^{-1}$ onward vanishes.

## Bessel zero table

The following cell varies order $\nu$ and starting index $m$, finding six consecutive zeros of $J_\nu$.
The table shows zeros, $J_\nu$ values there, differences from McMahon through term $\beta^{-3}$, and error estimates.
For index checks, count $J_\nu$ sign changes outward from the origin on a 0.01 grid, reporting counts through 0.25 beyond each zero.
Function values use scioxide-special's `bessel_j`, sharing the root finder's evaluation path; independent value checks therefore use McMahon and exact zeros $m\pi$ at $\nu = 1/2$.
The outcome shows `SpecialZeroReport` termination.

```rust
//| cases:
//|   - {"id":"high-order","label":"ν = 6, m = 1 (order exceeds index)","description":"McMahon discrepancy grows to −0.105 at m = 1, making fixed-order expansions unsuitable as references.","inputs":{"order":6}}
//|   - {"id":"high-order-large-index","label":"ν = 6, m = 25 (large index)","description":"With index far above order, McMahon discrepancy shrinks to −2.9 × 10⁻⁶.","inputs":{"order":6,"start":25}}
//|   - {"id":"half-order","label":"ν = 1/2 (exact zeros mπ)","description":"Zeros at ν = 1/2 are mπ; McMahon differences are zero.","inputs":{"order":0.5}}

//|       - {"artifact":"zeros","path":"/rows/0/4","approx":{"value":-0.10507,"atol":5e-5}}
//|       - {"path":"/outputs/1/state","equals":"satisfied"}
//|   - case: high-order-large-index

//|       - {"artifact":"zeros","path":"/rows/0/0","equals":25}
//|       - {"artifact":"zeros","path":"/rows/0/1","equals":25}

//|       - {"path":"/outputs/1/state","equals":"satisfied"}
use scioxide_rootfind::{
    RootTermination, SpecialZeroBranch, SpecialZeroFamily, SpecialZeroOptions,
    special_zeros_with_options,
};
use scioxide_special::bessel_j;

// Compute positive J_ν zeros m through m+5 in ascending order.
let zeros = special_zeros_with_options(
    SpecialZeroFamily::BesselJ(order),
    SpecialZeroBranch::Real,
    start as usize,
    6,
    &SpecialZeroOptions::default(),
)
.map_err(|e| e.to_string())?;
let report = zeros.report();
// Index check: count J_ν sign changes outward from the origin on a 0.01 grid.
// Adjacent-zero spacing exceeds three, so no grid step contains two zeros.
let step = 0.01;
let last = zeros.roots().last().map_or(0.0, |z| z.point().re);
let samples = (last / step) as usize + 50;
let mut values = Vec::with_capacity(samples);
for k in 1..=samples {
    let x = k as f64 * step;
    values.push((x, bessel_j(order, x).map_err(|e| e.to_string())?));
}
let mut rows = Vec::new();
for zero in zeros.roots() {
    let m = zero.index();
    let x = zero.point().re;
    // Count sign changes through 0.25 beyond each zero (the next zero lies farther away).
    let counted = values
        .windows(2)
        .filter(|w| w[1].0 <= x + 0.25 && (w[0].1 < 0.0) != (w[1].1 < 0.0))
        .count();
    // Independent reference: McMahon expansion through β⁻³ (DLMF 10.21.19, f64 arithmetic).
    let beta = (m as f64 + order / 2.0 - 0.25) * core::f64::consts::PI;
    let mu = 4.0 * order * order;
    let mcmahon = beta
        - (mu - 1.0) / (8.0 * beta)
        - 4.0 * (mu - 1.0) * (7.0 * mu - 31.0) / (3.0 * (8.0 * beta).powi(3));
    let residual = bessel_j(order, x).map_err(|e| e.to_string())?;
    rows.push((m, counted, x, residual, x - mcmahon, zero.estimated_error()));
}
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let columns = serde_json::json!([
    { "key": "0", "label": "Index m [-]", "type": "integer" },
    { "key": "1", "label": "Index from sign changes [-]", "type": "integer" },
    { "key": "2", "label": "Zero j_ν,m [-]", "type": "number", "format": { "fractionDigits": 12 } },
    { "key": "3", "label": "J_ν(zero) [-]", "type": "number", "format": sci2 },
    { "key": "4", "label": "McMahon discrepancy [-]", "type": "number", "format": sci2 },
    { "key": "5", "label": "Estimated error [-]", "type": "number", "format": sci2 }
]);
emit_table_with_columns!(columns, rows, metadata = serde_json::json!({ "id": "zeros" }));

let termination = report.termination();
let outcome = if report.is_success() {
    Outcome::satisfied("All six requested zeros passed original-function checks")
} else if matches!(termination, RootTermination::Unverified) {
    Outcome::failed("Some requested indices failed zero checks")
        .explanation("The table includes only the checked prefix.")
} else {
    Outcome::partial("Search stopped at a limit")
        .explanation("The table includes only the checked prefix.")
};
let largest = zeros
    .roots()
    .iter()
    .map(|z| z.estimated_error())
    .fold(0.0_f64, f64::max);
emit_outcome!(
    outcome
        .status(termination.to_string())
        .diagnostic("Completed count", report.completed() as f64, None)
        .diagnostic("Maximum estimated error", largest, None)
);
```

At defaults $\nu = 0$ and $m = 1$, all six zeros pass checks and the outcome is `Complete`.
Sign-change counts match requested indices.
Absolute $J_0$ values are at most $1.8 \times 10^{-16}$, with estimated errors from $8.1 \times 10^{-17}$ to $9.7 \times 10^{-16}$.
McMahon discrepancies shrink with index, from $1.8 \times 10^{-3}$ at $m = 1$ to $1.3 \times 10^{-7}$ at $m = 6$.
These reflect expansion truncation, not zero errors.
At $\nu = 6$ and $m = 1$, discrepancy grows to $-0.105$, falling to $-2.9 \times 10^{-6}$ at $m = 25$; fixed-order expansions fail when $\nu$ is large relative to $m$.
At $\nu = 1/2$, expansion discrepancy is zero and zeros match double-precision $m\pi$.

## Results and workspaces

`SpecialZeros` returned by `special_zeros_with_options` holds a checked `SpecialZero` sequence and `SpecialZeroReport`.
Each zero holds index `index()`, coordinate `point()`, original residual `residual_norm()`, Newton correction magnitude `correction()`, estimated error `estimated_error()`, reciprocal derivative `inverse_slope()`, sign interval `bracket()`, and multiplicity `multiplicity()`.
`inverse_slope()` is the zero's absolute condition number $1/|f'(z)|$: function error $\delta f$ shifts the zero by $\delta f/|f'|$.
Kelvin residuals use exponentially normalized functions (such as `ber x · exp(−x/√2)`), with true `residual_is_scaled()`.
Report `termination()` is authoritative: `Complete` completes the requested sequence; `NoZeros` identifies a known-empty sequence.
At limits or `Unverified`, only the first `completed()` checked zeros fulfill requests; `candidate()` is the unverified candidate for the first incomplete request.

`SpecialZeroOptions` configures zero tolerances (`with_tolerance`), shared search/polish/check evaluation limits (`with_evaluation_budget`, default $2^{26}$), search iterations and per-special-evaluation work (`with_work_per_zero`, default $2^{20}$), Newton polishing iterations (`with_refinement_steps`, default 100), `SolveBudgets`, execution policy, and workspace memory limits.
`SpecialZeroWorkspaceRequirements` from `SpecialZeroWorkspace::workspace_requirements(count, &options)` describes workspace requirements, depending only on zero count.
Pass workspace from `SpecialZeroWorkspace::workspace(count, &options)` and output `&mut [Option<SpecialZero>]` to `special_zeros_into` for allocation-free reuse.
`special_zeros_into` preserves all outputs on error and writes only checked prefixes at limits.
`counts()` covers sequence-processing work alone; per-zero polishing and special evaluations count in nested scopes, inspected through `accounting()`.
Estimated errors and numerical index checks differ from interval-certified enclosures.

## Summary

Specify family, branch, and indices, using the full requested sequence only when `termination()` is `Complete` or `NoZeros`.
Incomplete results check only the first `completed()` zeros; never use `candidate()` as a solution.
Indices are numerical decisions from initial-guess sign brackets and sign-change counting; for important calculations, check indices independently using sign counts, asymptotics, or known exact zeros.
McMahon approximates $m \to \infty$ at fixed $\nu$; it is unsuitable as a reference when $\nu$ is large relative to $m$.
