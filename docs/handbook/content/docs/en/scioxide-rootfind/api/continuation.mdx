This table collects continuation methods tracing solution branches of $n$ equations $F(x, \lambda) = 0$ with parameter $\lambda$, and deflation methods finding additional roots by excluding known ones.
Both use scioxide-rootfind's Newton–Krylov method for correction and independently check the original equation's residual.
`Continuation` holds only a validated path and settings; accepted points, tangents, and history reside in caller-owned `ContinuationState`.
Candidate folds and bifurcations are numerical observations, not proofs.

## Summary

Continuation traces solution branches with `ContinuationProblem` and `Continuation`.
`follow` returns state advanced to the end of the path; `advance` accepts at most one point per call, so continue calling while the termination reason is `Advanced`; `Complete` means the path has been completed.
Original residuals at each accepted point and candidate folds remain in `ContinuationState` history.
Corrections and tangents default to unpreconditioned GMRES; for large or poorly scaled problems, supply a prepared solver through `with_linear_solver`.
For deflation, add validated roots to `DeflationSet` and check additional roots using `DeflatedProblem::solve`'s termination reason and original residual.
Examine how pseudo-arclength continuation passes folds in [Tracing solution branches with continuation](../../algorithms/continuation-and-deflation/), and deflation's effects on the Bratu problem in [Finding additional solutions with deflation](../../algorithms/deflation/).
