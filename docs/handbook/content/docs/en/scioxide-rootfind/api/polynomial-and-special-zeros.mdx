This table collects items computing all roots of polynomial $p(z) = \sum_k a_k z^k$ and indexed special-function zeros.
Polynomial nonconvergence (`IterationLimit`), failed verification (`Unverified`), and numerical breakdown (`NumericalFailure`) appear as reports inside `Ok` for `polynomial_roots_with_options` and `polynomial_roots_into`; returned roots are then candidates.
Inspect `is_validated` in `diagnostics()` to determine whether each candidate passed checks using the original coefficients.
Special-zero `special_zeros_with_options` and `special_zeros_into` return only the verified prefix even when stopping at resource limits or similar conditions.
One-call `polynomial_roots` and `special_zeros` turn such unsuccessful termination into errors.
Both determine success with shared `RootTermination`.
Backward errors, condition numbers, and estimated errors are estimates, not interval-arithmetic proofs.

Complex-zero Newton refinement evaluates the function and derivative as a pair at the same coordinate.
Iteration stops when the correction reaches coordinate rounding level $2\varepsilon \max(\lvert z \rvert, 1)$, or when the function value enters its own evaluation-error range and corrections stop shrinking.
Final verification includes evaluation uncertainty.

## Summary

Compute all polynomial roots with `polynomial_roots_with_options`, interpreting termination, backward errors, and conditioning in `PolynomialRootReport`; use `polynomial_roots` when only checked roots are needed.
Pass polynomials prepared in scioxide-poly orthogonal or other bases to the same functions without monomial conversion.
For repeated problems of the same degree, use workspace prepared through `PolynomialRootWorkspace::workspace(degree, &options)` and `polynomial_roots_into`.
For special-function zeros, specify family, branch, and indices in `special_zeros_with_options`, inspect `SpecialZeroReport` termination and verified count `completed`, and use `special_zeros` for real-axis zero values alone.
See [Computing all roots of real polynomials](../../algorithms/polynomial-root-pipeline/) for method accuracy and cost, and [Circular-membrane eigenfrequencies and Bessel zeros](../../examples/circular-membrane/) for zero applications and checks.
