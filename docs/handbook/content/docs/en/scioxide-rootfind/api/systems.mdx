This table collects $n$-variable systems $\mathbf{F}(\mathbf{x}) = \mathbf{0}$ and fixed points $\mathbf{x} = G(\mathbf{x})$.
All methods return results in `Ok` after limits, stagnation, or globalization failure; inspect termination reasons for success.
`Err` covers invalid inputs/settings/workspaces, nonfinite inputs/evaluations, callback errors, and numerical breakdown (such as singular Jacobians in `NewtonSystem` without line search).
Output-writing `solve_into` APIs preserve outputs on errors.

## Summary

For only solutions with defaults, use one-call `solve_system` and `fixed_point`.
Solve systems with formable Jacobians using `NewtonSystem`, `TrustRegionSystem`, or `Broyden`; large action-only $Jv$ problems use `NewtonKrylovSolver`.
`NewtonSystem` defaults to no line search; add one through `with_line_search` or use `TrustRegionSystem` for distant guesses.
Replace inner solvers with `NewtonSystemOptions::with_linear_solver` or `NonlinearLinearSolver`; outer solvers verify their corrections.
Choose fixed-point rules with `FixedPointSolver`, interpreting independent residuals and termination.
For parameterized problems and additional solutions, inspect [Continuation and deflation](../continuation/).
