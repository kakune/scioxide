Circular-pipe pressure loss follows Darcy–Weisbach $\Delta p=f\,(L/D)\,\rho u^2/2$.
Here $f$ is Darcy friction factor, $D$ diameter, $L$ length, $\rho$ fluid density, and $u$ cross-sectional mean velocity.
Fanning factors are one quarter of $f$; do not mix conventions.
This page uses Colebrook for fully developed turbulent pipe flow, excluding laminar–turbulent transition at Reynolds $\mathrm{Re}$ approximately 2300–4000.

## Transformation to a positive variable

For relative roughness $\varepsilon_r=\varepsilon/D$ ($\varepsilon$ is roughness height) and $\mathrm{Re}$, setting $x=1/\sqrt f$ gives Colebrook:

$$
g(x)=x+2\log_{10}\left(\frac{\varepsilon_r}{3.7}+\frac{2.51x}{\mathrm{Re}}\right)=0
$$

For $x>0$,

$$
g'(x)=1+\frac{2}{\ln10}\,\frac{2.51/\mathrm{Re}}{\varepsilon_r/3.7+2.51x/\mathrm{Re}}>1
$$

so $g$ is strictly increasing with a unique root.
Over inputs $5\times10^3\le\mathrm{Re}\le10^8$ and $10^{-6}\le\varepsilon_r\le0.050$, $g(1)<0<g(30)$ makes fixed interval $[1,30]$ bracket the root.

From $g'>1$ and the mean value theorem, approximate root $\hat x$ satisfies position bound $|\hat x-x_*|\le|g(\hat x)|$.
Since $f=x^{-2}$, first-order relative friction-factor error is $2|\hat x-x_*|/x_*$.
Thus residual $g$ estimates $x$ errors and then $f$ relative errors.
Here $x$ ranges approximately 3.7–12.5, making relative-$f$ estimate $2|g|/x$ smaller than $|g|$.

## Acceptance rules and residual scales

Default bracketing `ScalarRootOptions` does not accept based on residual size.
It accepts sign-changing width at most $4\varepsilon+4\varepsilon\max(|x_{\rm lo}|,|x_{\rm hi}|)$ or exact function zeros, giving `BracketTolerance` and `ResidualTolerance` respectively.
Here $\varepsilon$ is double-precision machine epsilon $2.2\times10^{-16}$.
Explicit tolerance $\rho_a+\rho_r s$ through `with_residual_tolerance` adds residual-only acceptance.
Absolute $\rho_a$ uses function units (dimensionless like $x$ here); relative $\rho_r$ multiplies residual scale $s$.

`with_residual_scale(s)` supplies relative reference scale $s>0$ in function units.
For bracketing this alone enables residual acceptance; without explicit tolerances, $|g|\le\sqrt\varepsilon\,s$ ($\sqrt\varepsilon\approx1.5\times10^{-8}$) stops with `ResidualTolerance`.
Without supplied scales, reference $s$ is the larger endpoint $|g|$ magnitude of the initial bracket.
Nonfinite or nonpositive scales yield `InvalidInput` before callbacks.

The magnitude of $x$ itself is a natural scale here.
Taking $s=x_H$ (Haaland below), $|g|\le\sqrt\varepsilon\,x_H$ makes relative-$x$ errors approximately at most $\sqrt\varepsilon$ and relative-$f$ errors order $3\times10^{-8}$.
Colebrook itself is empirical with uncertainty of a few percent, so this numerical accuracy suffices for engineering.

## Approximations and bracket search

Haaland's approximation is:

$$
x_H=-1.8\log_{10}\left[\left(\frac{\varepsilon_r}{3.7}\right)^{1.11}+\frac{6.9}{\mathrm{Re}}\right]
$$

`find_bracket_with_options` starts there, receiving monotone increase of $g$ (`BracketSearchDirection::Increasing`) and domain $x>0$ to find sign-changing brackets.
Declared increase expands only toward the root according to initial signs.
Monotonicity is the caller's declaration, not verified by the solver.
Use multiplicative `BracketExpansion::Multiplicative` expansion, multiplying/dividing endpoints by growth (default 2), because the domain is positive only.

Also compare Swamee–Jain approximation $f_{SJ}=0.25/[\log_{10}(\varepsilon_r/3.7+5.74/\mathrm{Re}^{0.9})]^2$.
Both approximations are empirical; tighter root tolerances do not remove their biases.
Use approximations for initialization/comparison, finally solving original Colebrook.

## Wright ω closed form

Set $c=\ln10/2$, $b=c\,\mathrm{Re}/2.51$, and $A=b\,\varepsilon_r/3.7$.
Colebrook becomes $c\,x=-\ln(\varepsilon_r/3.7+2.51x/\mathrm{Re})$; setting $w=c\,x+A$ gives $\varepsilon_r/3.7+2.51x/\mathrm{Re}=w/b$, hence:

$$
w+\ln w=A+\ln b
$$

so $w=\omega(A+\ln b)$.
$\omega$ is Wright ω, solving $\omega+\ln\omega=z$ and evaluated by scioxide-special's `wright_omega`.
Computing $x=(w-A)/c$ at high Re and roughness makes $w$ and $A$ both large, causing cancellation.
Equivalent $x=(\ln b-\ln w)/c$ avoids subtracting these large values.
[Clamond's paper](https://arxiv.org/abs/0810.5564) also discusses closed forms and numerical evaluation.

The following block defines helpers shared by two cells.
`colebrook_residual` gives $g(x)$, `haaland` gives $x_H$, and `omega_closed_form` gives closed-form $x$ in both representations.

```rust
//| id: rootfind-colebrook-model
//| kind: definitions
//| title: "Colebrook residual, Haaland approximation, and Wright ω closed forms"
//| crates: [scioxide-core, scioxide-special]
use scioxide_core::{SciOxideError, RealScalar};

/// Residual g(x) = x + 2 log₁₀(ε_r/3.7 + 2.51x/Re). x = 1/√f.
pub(crate) fn colebrook_residual(x: f64, re: f64, roughness: f64) -> f64 {
    x + 2.0 * RealScalar::log10(roughness / 3.7 + 2.51 * x / re)
}

/// Haaland x_H = −1.8 log₁₀[(ε_r/3.7)^1.11 + 6.9/Re].
pub(crate) fn haaland(re: f64, roughness: f64) -> f64 {
    -1.8 * RealScalar::log10(RealScalar::powf(roughness / 3.7, 1.11) + 6.9 / re)
}

/// Return Wright-ω closed-form x as both (ln b − ln w)/c and (w − A)/c.
pub(crate) fn omega_closed_form(re: f64, roughness: f64) -> Result<(f64, f64), SciOxideError> {
    let c = core::f64::consts::LN_10 / 2.0;
    let b = c * re / 2.51;
    let a = b * roughness / 3.7;
    let w = scioxide_special::wright_omega(a + RealScalar::ln(b))?;
    Ok(((RealScalar::ln(b) - RealScalar::ln(w)) / c, (w - a) / c))
}
```

Choose default width, absolute tolerance $|g|\le10^{-12}$, or residual scale $s=x_H$.
Solve `Brent`, `Toms748`, and `Chandrupatla` on fixed $[1,30]$, then solve `Brent` again on the `find_bracket_with_options` bracket.

`Brent` and `Toms748` observe exact zeros and stop with `ResidualTolerance`; `Chandrupatla` stops on width `BracketTolerance`.
Fixed brackets use 7–8 evaluations; `Brent` starting on `find_bracket_with_options` bracket $[3.37,6.75]$ uses five.
Bracket search finds opposite signs with two evaluations at $x_H=6.747$ and $x_H/2$, totaling seven including search.

Acceptance `Residual |g| ≤ 1e-12` reduces fixed-bracket counts to 6–7, with maximum relative discrepancy from the ω solution $1.7\times10^{-13}$ (`Toms748`).
With `Residual scale x_H`, threshold is $\sqrt\varepsilon\,x_H\approx1.0\times10^{-7}$; fixed-bracket `Brent` stops in five evaluations at residual $5.9\times10^{-8}$.
Relative discrepancy $-1.7\times10^{-8}$ matches estimate $2|g|/x\approx1.8\times10^{-8}$ above.
Every rule's root errors are far below approximation biases (Haaland $-0.94\,\%$, Swamee–Jain $+0.76\,\%$).

For rough high-Re inputs $\mathrm{Re}=10^8$ and $\varepsilon_r=0.050$, $w-A\approx4$ relative to $A\approx6\times10^5$ makes cancellation-prone $x=(w-A)/c$ reach relative discrepancy $-2.7\times10^{-11}$.
Differences between $x=(\ln b-\ln w)/c$ and bracketing stay below $2.2\times10^{-16}$.
Here Swamee–Jain errors fall to $9\times10^{-6}$ while Haaland differs by $+0.20\,\%$.

```rust
// Solve Colebrook for x = 1/√f and return f = x⁻²
let friction = |re: f64, rough: f64| -> Result<f64, String> {
    let colebrook = ScalarFn::new(|x: f64| Ok(colebrook_residual(x, re, rough)));
    let result = Brent
        .solve(&colebrook, interval, &options)
        .map_err(|e| e.to_string())?;
    if !result.is_success() {
        return Err(format!("Unconverged factor at Re = {re}: {}", result.termination()));
    }
    Ok(1.0 / (result.point() * result.point()))
};
let selected = friction(re, roughness)?;
let mut series = Vec::new();
for (name, rough) in [
    ("ε/D = 1e-6", 1e-6),
    ("ε/D = 1e-4", 1e-4),
    ("ε/D = 1e-3", 1e-3),
    ("ε/D = 1e-2", 1e-2),
    ("ε/D = 0.05", 0.05),
    ("Selected ε/D", roughness),
] {
    let mut points = Vec::new();
    for k in 0..=40 {
        let r = 4000.0 * RealScalar::powf(1e8 / 4000.0, k as f64 / 40.0);
        points.push([r, friction(r, rough)?]);
    }
    series.push(serde_json::json!({ "name": name, "points": points }));
}
let laminar: Vec<_> = (0..=20)
    .map(|k| {
        let r = 500.0 + 90.0 * k as f64;
        [r, 64.0 / r]
    })
    .collect();
series.push(serde_json::json!({
    "name": "Laminar 64/Re",
    "points": laminar,
    "style": { "lineType": "dashed" }
}));
// Use emit_chart! for test references and explicitly configure zoom/tooltips
emit_chart!(
    serde_json::json!({
        "kind": "line",
        "dataZoom": true,
        "tooltip": true,
        "series": series,
        "xLabel": "Reynolds number Re [-]",
        "yLabel": "Darcy factor f [-]",
        "xType": "log",
        "yType": "log",
        "xMin": 500.0,
        "xMax": 1e8,
        "yMin": 0.005,
        "yMax": 0.15,
        "annotations": [
            { "kind": "line", "axis": "x", "value": re, "label": "Selected Re" },
            { "kind": "line", "axis": "y", "value": selected, "label": "Selected-flow f" }
        ]
    }),
    metadata = serde_json::json!({ "id": "moody" })
);
```

Smooth-pipe curves ($\varepsilon_r=10^{-6}$) continue falling with Re, reaching $f=0.0064$ at $\mathrm{Re}=10^8$.
Rough curves approach horizontal at high Re; at $\varepsilon_r=0.05$, $f\approx0.072$ becomes Re-independent (fully rough region).
The fully rough value is $x=-2\log_{10}(\varepsilon_r/3.7)$ from Colebrook with $2.51x/\mathrm{Re}\to0$, giving $f=0.0716$ at $\varepsilon_r=0.05$.
The laminar dashed curve gives $f=0.028$ at $\mathrm{Re}=2300$, separated from turbulence by the transition region.
The selected $\varepsilon_r$ curve may overlap fixed-roughness curves.
Both axes are logarithmic, receiving raw positive Re and $f$ values.

## Summary

Transforming Colebrook with $x=1/\sqrt f$ gives a monotone one-variable equation with $g'>1$, whose root is bracketed by fixed $[1,30]$ over every input here.
$|g|$ bounds $x$ errors; multiply by $2/x$ to estimate relative $f$ errors.
Bracketing defaults accept widths; `with_residual_tolerance` or `with_residual_scale` adds residual-only acceptance, reducing evaluations to match required accuracy.
Passing $x$ magnitude (here $x_H$) to `with_residual_scale` computes $f$ to approximately relative $3\times10^{-8}$, stopping with fewer evaluations than defaults.
The Wright-ω representation $x=(\ln b-\ln w)/c$ avoids subtracting large values and provides an independent check.
