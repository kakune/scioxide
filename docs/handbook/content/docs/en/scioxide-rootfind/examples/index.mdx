A small residual alone does not establish that a root-finding result is correct.
Check results using bracketing intervals in one variable, conservation laws and physical constraints for systems, relationships among the root set (conjugacy and Vieta's formulas) for polynomials, and indices and known properties for special-function zeros.
Every example in this chapter includes an independent check using a method distinct from the main computation.
Each page specifies units: the IRR example uses amounts [10,000 yen], chemical equilibrium uses concentration [mM], vibrating systems and circular membranes use angular frequency [rad/s] and frequency [Hz], and the potential well uses energy [meV].

## Checks suited to problem structure

### One variable: intervals and residuals

A successful bracketing method returns `Bracket` recording an interval whose endpoint function values have opposite signs.
Under continuity, this supports the existence of a root inside the interval, but it is based on floating-point evaluations and is not a proof.
If multiple roots are possible, first scan to collect all sign-changing intervals, then solve each interval.
A scan can miss two roots closer than the scan spacing or repeated roots without a sign change.
Even when an open method (such as Newton's method) converges to a root, it does not establish that no other root is nearby.

### Systems: conservation laws and constraints

The interval-based existence argument does not directly extend to multiple variables, so check the problem's conserved quantities (material balance, charge, energy) independently in addition to the residual norm.
For quantities that must remain positive, such as concentration or temperature, a change of variables such as $x = e^{u}$ preserves positivity throughout the iteration.

### Polynomials: the root set

When computing all polynomial roots, check each residual $\lvert p(z_i) \rvert$, that the root count equals the degree, and, for real coefficients, that nonreal roots occur in conjugate pairs.
Also use Vieta's formulas (sum $-a_{n-1}/a_n$ and product $(-1)^n a_0/a_n$ of roots) and normalized backward error $\eta(z) = \lvert p(z) \rvert / \sum_k \lvert a_k \rvert \lvert z \rvert^k$.
Near repeated roots, even small backward errors determine root positions only to order $\varepsilon^{1/m}$ for multiplicity $m$.

### Special-function zeros: indices

When a problem requires the $m$th zero, verify its index as well as its value.
Comparisons with asymptotic expansions, interlacing with zeros of neighboring orders, and evaluating the function using another implementation provide independent checks.

## Summary

In every example, verify successful termination before using the values.
For one-variable problems with a known derivative lower bound (Kepler's equation and Colebrook's equation), divide the residual by that bound to estimate a position-error bound.
For problems that collect roots by scanning, compare all roots and their count if the problem can be converted to a polynomial; otherwise, refine the scan and check that the result is unchanged.
For systems, check solutions using relationships independent of the iteration, such as closed forms or conservation laws, in addition to residuals.
