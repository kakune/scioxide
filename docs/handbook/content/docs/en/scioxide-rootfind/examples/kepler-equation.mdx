On elliptical planetary or satellite orbits, mean anomaly $M$ increases in proportion to time since periapsis.
Orbital positions have simple expressions in eccentric anomaly $E$, but $E$ does not increase uniformly.
Kepler's equation relates them for eccentricity $0\le e<1$ as follows:

$$
M=E-e\sin E
$$

Angles use rad, with $0\le M\le2\pi$ covering one revolution.
With the focus at the origin and periapsis along the $x$ axis, the orbital-plane coordinates and distance from the central body, all divided by semimajor axis $a$, are:

$$
\frac{x}{a}=\cos E-e,\qquad
\frac{y}{a}=\sqrt{1-e^2}\sin E,\qquad
\frac r a=1-e\cos E
$$

True anomaly $\nu=\operatorname{atan2}(y,x)$ is the actual polar angle from the periapsis direction as viewed from the focus.
Finding $E$ from $M$ determines position from time.

## Root uniqueness and error bounds

Writing $f(E)=E-e\sin E-M$ gives:

$$
f'(E)=1-e\cos E\ge1-e>0,\qquad f''(E)=e\sin E
$$

Because $f$ is strictly increasing, root $E_*$ is unique.
Since $f(0)=-M\le0$ and $f(2\pi)=2\pi-M\ge0$, interval $[0,2\pi]$ brackets the root (an endpoint is the root for $M=0$ and $M=2\pi$).
From $|E_*-M|=e|\sin E_*|\le e$, narrower interval $[M-e,M+e]$ is also available.

The mean value theorem gives, for approximate solution $\widehat E$,

$$
|\widehat E-E_*|=\frac{|f(\widehat E)|}{f'(\xi)}\le\frac{|f(\widehat E)|}{1-e}
$$

where $\xi$ lies between $\widehat E$ and $E_*$.
This bounds exact function values.
Computed floating-point $f$ contains rounding errors of order $u\,(|E|+M)$ in terms of unit roundoff $u=2^{-53}\approx1.1\times10^{-16}$.
Thus at $E\approx2$ rad, residual differences smaller than $10^{-15}$ are meaningless.
Applying the bound to computed residuals also does not produce a certified error bound.

The same derivative $f'(E_*)$ determines the problem's condition number.
A change of $\delta M$ in $M$ changes the root by $\delta E\approx\delta M/f'(E_*)$.
For $e\to1$ near periapsis ($M\approx0$), $f'(E_*)=1-e\cos E_*$ can fall to order $1-e$, increasing angular errors for the same residual.

The following block provides definitions shared by three cells.
`Kepler` supplies analytic $f$, $f'$, and $f''$ as `ScalarFunction`; `full_turn` constructs bracket $[0,2\pi]$.
`reference_solve` advances `Bisection`, which is excluded from the comparison, with default stopping criteria and returns results only on success.
With default `ScalarRootOptions`, bracketing methods do not accept on residual alone and continue bisection until interval width is at most $4\varepsilon+4\varepsilon\max(|E_{\rm lo}|,|E_{\rm hi}|)$ ($\varepsilon=2^{-52}$ is double-precision machine epsilon).
Bisection of $[0,2\pi]$ reaches this width after approximately 52 iterations, below the default iteration limit of 100.

```rust
//| id: rootfind-kepler-model
//| kind: definitions
//| title: "Kepler function and bisection reference solution"
//| crates: [scioxide-core, scioxide-rootfind]
use scioxide_core::{SciOxideError, Interval, RealScalar};
use scioxide_rootfind::{Bisection, RootResult, ScalarFunction, ScalarRootOptions, ScalarRootSolver};

/// f(E) = E − e sin E − M and its analytic first and second derivatives.
pub(crate) struct Kepler {
    pub(crate) eccentricity: f64,
    pub(crate) mean_anomaly: f64,
}

impl ScalarFunction<f64> for Kepler {
    fn eval(&self, x: f64) -> Result<f64, SciOxideError> {
        Ok(x - self.eccentricity * RealScalar::sin(x) - self.mean_anomaly)
    }

    fn derivative(&self, x: f64) -> Result<Option<f64>, SciOxideError> {
        Ok(Some(1.0 - self.eccentricity * RealScalar::cos(x)))
    }

    fn second_derivative(&self, x: f64) -> Result<Option<f64>, SciOxideError> {
        Ok(Some(self.eccentricity * RealScalar::sin(x)))
    }
}

/// f(0) = −M ≤ 0 ≤ f(2π) = 2π − M, so [0, 2π] brackets the root.
pub(crate) fn full_turn() -> Result<Interval<f64>, String> {
    Interval::new(0.0, core::f64::consts::TAU).map_err(|e| e.to_string())
}

/// Reference: bisection to the default stopping criterion (width of a few ulp). Return only on success.
pub(crate) fn reference_solve(
    eccentricity: f64,
    mean_anomaly: f64,
) -> Result<RootResult<f64>, String> {
    let function = Kepler {
        eccentricity,
        mean_anomaly,
    };
    let result = Bisection
        .solve(&function, full_turn()?, &ScalarRootOptions::default())
        .map_err(|e| e.to_string())?;
    if result.is_success() {
        Ok(result)
    } else {
        Err(format!("Reference bisection stopped with {}", result.termination()))
    }
}
```

## Initial-guess rules

Newton uses $E_{k+1}=E_k-f(E_k)/f'(E_k)$; Halley also uses the second derivative and advances by:

$$
E_{k+1}=E_k-\frac{2f(E_k)f'(E_k)}{2f'(E_k)^2-f(E_k)f''(E_k)}
$$

Near simple roots, Newton converges quadratically and Halley cubically.
Neither has a bracket, so convergence depends on initial guess $E_0$.

Newton starting at $E_0=\pi$ converges for every $0\le e<1$ and $M$.
For $M<\pi$, $f(\pi)=\pi-M>0$ places the root left of $\pi$, and $f''=e\sin E\ge0$ on $[0,\pi]$ makes $f$ convex.
Tangents of convex increasing functions lie below the graph, so iterations from the root's right decrease monotonically without crossing it and converge to the root.
For $M>\pi$, $f$ is concave on $[\pi,2\pi]$, and the same argument holds with left and right interchanged.
For $M=\pi$, $E_0=\pi$ is already the root.

$E_0=M$ is exact for circular orbits ($e=0$) and a good initial guess for small $e$.
For $0<M<\pi$, however, $f(M)=-e\sin M<0$ starts left of the root, and convexity makes the first step jump across it to the right.
The step length is $e\sin M/(1-e\cos M)$; for $e\to1$ and $M\to0$, the denominator becomes small, potentially jumping into concave interval $(\pi,2\pi)$ or outside $2\pi$.
The monotonicity argument then fails, increasing iterations.

Safeguarded Newton (`SafeguardedNewton`) accepts a sign-changing interval as well as an initial guess and shrinks the interval after each evaluation.
A Newton step is accepted only inside the interval and when no longer than half the step two updates earlier; otherwise bisection is used.
`Brent`, `Toms748`, and `Chandrupatla` use only interval $[0,2\pi]$ and function values, without derivatives.

## Comparing six methods

The following cell takes eccentricity $e$, mean anomaly $M$ [rad], and initial-guess rule ($E_0=M$ or $\pi$), computing the same $E_*$ with six methods.
Methods are selected with `ScalarRootMethod` and receive the same `ScalarRootOptions`.
Stopping conditions are residual $|f|\le10^{-12}$ rad or interval/step width at most $10^{-12}$ rad.
Tolerance explicitly set through `with_residual_tolerance` applies to both open and bracketing methods, enabling acceptance by residual alone.
Step-based acceptance for open methods (`StepTolerance`) also requires the residual to fall to at most $\sqrt{\varepsilon}$ times initial $|f|$.

The table's first row is the definitions block's bisection reference, including termination and evaluation counts.
Columns give termination, computed $E$, residual $f(E)$, reference discrepancy, residual-derived bound $|f|/(1-e)$, and function/first-/second-derivative evaluation counts.
Counts are per `EvaluationRole` in `RootResult::counts`; computation times are not compared.
Do not interpret derivative evaluations as costing the same as function evaluations.
The final outcome indicates whether all six methods and the reference terminated successfully.

Reference bisection stops on interval-width criterion `BracketTolerance` after 54 function evaluations.
Newton uses six function and five first-derivative evaluations; Halley four function and three each first/second-derivative evaluations; safeguarded Newton eight function and five first-derivative evaluations.
The three bracketing methods use only 9–10 function evaluations.
Brent has the largest reference discrepancy, $-6.3\times10^{-14}$ rad, within bound $1.8\times10^{-13}$ rad derived from residual $-7.1\times10^{-14}$ rad.
Other methods differ by at most $4.4\times10^{-16}$ rad, only a few ulp from bisection.
Brent alone retains a discrepancy because its final interpolated residual $7.1\times10^{-14}$ rad fell below tolerance $10^{-12}$ rad and stopped there.
Other methods stop after their final steps reduce residuals to rounding level ($2.2\times10^{-16}$ rad).

With $e=0.99$, $M=0.1$ rad, and $E_0=M$, Newton's first step jumps to $M+e\sin M/(1-e\cos M)\approx6.7$ rad, beyond $2\pi$.
Newton rises to 16 function and 15 first-derivative evaluations; Halley to 14 function and 13 each first/second-derivative evaluations.
Changing the initial guess to $\pi$ gives monotone convergence as shown in [Initial-guess rules](#initial-guess-rules), reducing Newton to eight and seven evaluations, Halley to six and five each.
The three bracketing methods and bisection use no initial guess, so their table entries do not change with it.
For this input $f'(E_*)\approx0.33$, so Chandrupatla's reference discrepancy $-1.8\times10^{-13}$ rad is approximately three times residual $-5.9\times10^{-14}$ rad.

    .with_step_tolerance(StepTolerance::new(1e-12, 0.0).map_err(|e| e.to_string())?);
let guess = SafeguardedInitialGuess::new(interval, initial).map_err(|e| e.to_string())?;
let methods = [
    (
        ScalarRootMethod::Newton(DerivativeStrategy::Analytic),
        ScalarRootInput::Guess(initial),
    ),
    (ScalarRootMethod::Halley, ScalarRootInput::Guess(initial)),
    (
        ScalarRootMethod::SafeguardedNewton(DerivativeStrategy::Analytic),
        ScalarRootInput::Safeguarded(guess),
    ),
    (ScalarRootMethod::Brent, ScalarRootInput::Bracket(interval)),
    (ScalarRootMethod::Toms748, ScalarRootInput::Bracket(interval)),
    (ScalarRootMethod::Chandrupatla, ScalarRootInput::Bracket(interval)),
];
let (mut series, mut rows, mut unsuccessful) = (Vec::new(), Vec::new(), 0_usize);
for (method, input) in methods {
    let name = ScalarRootSolver::<f64>::name(&method);
    let (mut points, mut failures, mut worst) = (Vec::new(), 0_usize, (0_usize, 0.0_f64));
    for k in 0..100 {
        let e = 0.01 * f64::from(k);
        let function = Kepler {
            eccentricity: e,
            mean_anomaly: mean,
        };
        let result = method
            .solve(&function, input, &options)
            .map_err(|e| e.to_string())?;
        // Sum of function, first-derivative, and second-derivative evaluation counts
        let total = result
            .counts()
            .total_providers()
            .map_err(|e| e.to_string())?;
        if result.is_success() {
            points.push([e, total as f64]);
        } else {
            failures += 1;
        }
        if total > worst.0 {
            worst = (total, e);
        }
    }
    unsuccessful += failures;
    series.push(serde_json::json!({ "name": name, "points": points }));
    rows.push((name, failures, worst.0, worst.1));
}
let columns = serde_json::json!([
    { "key": "0", "label": "Method" },
    { "key": "1", "label": "Unsuccessful solves [count]", "type": "integer" },
    { "key": "2", "label": "Maximum evaluations [count]", "type": "integer" },
    { "key": "3", "label": "e at maximum [-]", "type": "number", "format": { "fractionDigits": 2 } }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "sweep" })
);
emit_scatter_chart!(
    &series,
    options = &serde_json::json!({
        "xLabel": "Eccentricity e [-]",
        "yLabel": "Total evaluations [count]",
        "yType": "log",
        "xMin": 0.0,
        "xMax": 1.0,
        "annotations": [{ "kind": "line", "axis": "x", "value": eccentricity, "label": "Selected e" }]
    })
);

let outcome = if unsuccessful == 0 {
    Outcome::satisfied("All 600 solves met acceptance criteria")
} else {
    Outcome::partial("Some solves stopped without meeting acceptance criteria")
        .explanation("Check methods in the table's unsuccessful-count column. Those points are omitted from the chart.")
};
emit_outcome!(
    outcome
        .status(format!("Successful {}/600", 600 - unsuccessful))
        .diagnostic("Unsuccessful solves", unsuccessful as f64, None)
);

At defaults $M=0.1$ rad and $E_0=M$, all six methods succeed for all 100 eccentricities.
Evaluation counts rise in steps with $e$, reaching 31 for Newton and 40 for Halley at $e=0.99$.
Safeguarded Newton peaks at 19, and the three bracketing methods at 12–15.
With initial guess $\pi$, Newton peaks at 15 and Halley at 16, without continuing growth as $e$ approaches 1.
Away from periapsis, as at $M=1.2$ rad, either guess needs at most approximately 13 evaluations, with little difference between guesses.

Totals weight calls with different roles equally and do not compare cost.
For Kepler's equation, $f'$ and $f''$ can use the same $\sin E$ and $\cos E$ as $f$, so an additional derivative costs less than a function value.
However, the three `ScalarFunction` methods (`eval`, `derivative`, `second_derivative`) are invoked separately; table and chart counts count those calls.

## Fourier–Bessel series check

Kepler's equation has a series solution using Bessel function $J_n$,

$$
E=M+\sum_{n=1}^{\infty}\frac2nJ_n(ne)\sin(nM)
$$

obtained by expanding $E-M=e\sin E$ as a Fourier sine series in $M$ with coefficients expressed through $J_n(ne)$ (a Kapteyn-type series).
This series converges for every $0\le e<1$.
Using Debye asymptotics for $J_n(n\operatorname{sech}\alpha)$ ([DLMF 10.19.3](https://dlmf.nist.gov/10.19)) and writing $\operatorname{sech}\alpha=e$ gives term magnitudes

$$
|J_n(ne)|\approx\frac{q(e)^n}{\sqrt{2\pi n\sqrt{1-e^2}}},\qquad
q(e)=\frac{e\,\exp\sqrt{1-e^2}}{1+\sqrt{1-e^2}}<1
$$

decreasing like a geometric series with ratio $q(e)$.
Since $q(0.6)\approx0.742$, $q(0.9)\approx0.969$, and $q(0.99)\approx0.9991$, convergence is extremely slow for $e\to1$.
Asymptotic estimates require approximately 100 terms at $e=0.6$, 860 at $e=0.9$, and 24000 at $e=0.99$ before term magnitudes fall below $10^{-16}$.

The Laplace limit of approximately 0.6627 is the convergence radius of a different series, reexpanding the solution in powers of $e$.
Its value $\lambda$ is the root of $\lambda\exp\sqrt{1+\lambda^2}/(1+\sqrt{1+\lambda^2})=1$, replacing $\sqrt{1-e^2}$ by $\sqrt{1+\lambda^2}$ in $q$ above.
Do not confuse these series and restrict the Fourier–Bessel domain to $e<0.6627$.

The following cell evaluates $J_n(ne)$ with `scioxide_special::bessel_j`, comparing $N=8,16,\dots$-term partial sums against the definitions block's bisection reference.
Input term count $N_{\max}$ is the truncation limit.
The table shows partial-sum reference discrepancies, magnitude of term $N$, and asymptotically predicted term magnitude $2q^N/(N\sqrt{2\pi N\sqrt{1-e^2}})$.
The prediction sets the $|\sin(nM)|\le1$ factor to 1, so actual terms may be smaller.
The series is independent of root finding and contains Bessel-value errors and summation rounding.
This cell has its own $e$ and $M$ inputs.
This allows checking series convergence as $e$ rises to 0.99 separately from the six-method comparison.

The final chart plots orbital positions from reference $E$.
The dashed curve is the ellipse itself ($E$ over one revolution); markers give equal-time positions $M=2\pi k/12$ ($k=0,\dots,11$); the large marker is the input-$M$ position; the origin marker is the central body at the focus.
Equal-time positions are sparse near periapsis and dense near apoapsis, visually consistent with constant areal velocity.

## Summary

Kepler's $f$ satisfies $f'\ge1-e>0$, giving a unique root always bracketed by $[0,2\pi]$.
The residual-to-angular-error factor is $1/f'(E_*)$; near periapsis for $e\to1$, equal residuals give larger errors.
Choosing initial $E_0=\pi$ makes Newton converge monotonically for every $e$ and $M$ by convexity.
$E_0=M$ is good near circular orbits but produces large initial jumps and more evaluations near periapsis at high eccentricity.
Interpret role-specific evaluation counts together with termination reasons, checking results through both independent computations such as Fourier–Bessel series and reference solutions from another method.
