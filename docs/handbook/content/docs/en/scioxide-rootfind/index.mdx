Root finding computes a point at which a given function is zero.

$$
f(x) = 0 \quad (x \in \mathbb{R}\ \text{or}\ \mathbb{C}), \qquad \mathbf{F}(\mathbf{x}) = \mathbf{0} \quad (\mathbf{x} \in \mathbb{R}^n), \qquad p(z) = \sum_{k=0}^{n} a_k z^k = 0
$$

Many problems take this form, including equilibrium temperatures, internal rates of return, chemical equilibria, orbital positions, and eigenvalues of vibrating systems.
The choice of method depends on the number of unknowns, whether an interval bracketing a root is known, whether derivatives are available, and how many roots are needed.
Most methods improve an approximation iteratively, so the condition that stopped the iteration must be read together with the result.

`scioxide-rootfind` handles the following problems.

| Problem | Main entry points |
|---|---|
| Real equations in one variable (bracketing methods, open methods using derivatives, and safeguarded methods) | `find_root`, `find_bracket`, `Brent`, `Toms748`, `Chandrupatla`, `Bisection`, `Newton`, `Halley`, `SafeguardedNewton`, `Secant`, `Muller`, and `ScalarRootMethod` for selecting a method at runtime |
| Complex equations in one variable | `ComplexNewton`, `ComplexHalley`, `ComplexSecant`, `ComplexMuller` |
| Systems of nonlinear equations | `solve_system`, `NewtonSystem`, `Broyden`, `TrustRegionSystem`, and matrix-free `NewtonKrylovSolver` |
| Fixed points $x = G(x)$ and acceleration | `fixed_point`, `FixedPointSolver` (Picard, Anderson, Steffensen, Broyden-type methods, and others) |
| All roots of a polynomial | `polynomial_roots`, `polynomial_roots_with_options`, `PolynomialRootInput` |
| Solution branches of parameterized equations and additional solutions | `Continuation`, `LinearHomotopy`, `DeflatedProblem` |
| Indexed zeros of special functions | `special_zeros`, `special_zeros_with_options` (Bessel, Airy, Kelvin, error functions, and Fresnel integrals) |

`find_root`, `find_bracket`, `solve_system`, `fixed_point`, `polynomial_roots`, and `special_zeros` are one-call functions that solve with default settings.
They return an answer only on success; other termination conditions become `ConvergenceFailure`, `ExecutionStopped`, or `NumericalInstability` errors.
Use the other types and functions in the table to change settings or inspect the termination reason, residual, and evaluation counts.

## First computation: Kepler's equation

The position of a body in an elliptical orbit is determined from the eccentricity $e$ and mean anomaly $M$ by solving Kepler's equation

$$
f(E) = E - e \sin E - M = 0, \qquad 0 \le e < 1
$$

for the eccentric anomaly $E$.
Because $f'(E) = 1 - e\cos E \ge 1 - e > 0$, $f$ is strictly increasing and has exactly one root.
Furthermore, $\lvert \sin E \rvert \le 1$ gives

$$
f(M - e) = -e\bigl(1 + \sin(M - e)\bigr) \le 0, \qquad f(M + e) = e\bigl(1 - \sin(M + e)\bigr) \ge 0
$$

so the interval $[M - e, M + e]$ brackets the root.
When the properties of a function yield a bracketing interval in this way, a bracketing method is a natural first candidate.

The following cell passes this interval to `Brent` to compute the eccentric anomaly.
The inputs are eccentricity $e$ and mean anomaly $M$ [rad]; the defaults $e = 0.6$ and $M = 1.2$ rad match [Kepler's equation and accounting for solver evaluations](../scioxide-core/examples/kepler-solve-accounting/) in scioxide-core.
In addition to the default stopping criterion on the interval width, `with_residual_tolerance` sets an absolute residual tolerance of $10^{-12}$ rad.
The table shows the termination reason, approximate solution $\hat E$, residual $f(\hat E)$, angular error estimated from the residual $\lvert f(\hat E) \rvert / f'(\hat E)$, and number of function evaluations.
The final outcome in the cell indicates whether the termination reason denotes success.

```rust
//| id: rootfind-kepler-methods
//| ref: rootfind-kepler-methods
//| title: "Solve Kepler's equation with Brent's method"
//| run: reactive
//| crates: [scioxide-core, scioxide-rootfind]
//| inputs:
//|   eccentricity: {"type":"range","label":"Eccentricity e [-]","min":0,"max":0.95,"step":0.05,"value":0.6}
//|   mean_anomaly: {"type":"range","label":"Mean anomaly M [rad]","min":0.1,"max":6,"step":0.1,"value":1.2}
//| cases:
//|   - {"id":"circular","label":"e = 0 (circular orbit)","description":"The interval contracts to the single point M, which is an exact root, so one evaluation suffices.","inputs":{"eccentricity":0}}
//|   - {"id":"eccentric","label":"e = 0.95, M = 0.1 rad (root with a small slope)","description":"A residual of 6.0 × 10⁻¹³ rad gives an estimated angular error of 2.0 × 10⁻¹² rad.","inputs":{"eccentricity":0.95,"mean_anomaly":0.1}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"solution","path":"/rows/0/0","equals":"ResidualTolerance"}
//|       - {"artifact":"solution","path":"/rows/0/1","approx":{"value":1.786141603274,"atol":5e-12}}
//|       - {"artifact":"solution","path":"/rows/0/2","range":{"min":-1e-12,"max":1e-12}}
//|       - {"artifact":"solution","path":"/rows/0/4","equals":6}
//|       - {"path":"/outputs/1/state","equals":"satisfied"}
//|   - case: circular
//|     expect:
//|       - {"artifact":"solution","path":"/rows/0/0","equals":"ResidualTolerance"}
//|       - {"artifact":"solution","path":"/rows/0/1","approx":{"value":1.2,"atol":1e-15}}
//|       - {"artifact":"solution","path":"/rows/0/4","equals":1}
//|       - {"path":"/outputs/1/state","equals":"satisfied"}
//|   - case: eccentric
//|     expect:
//|       - {"artifact":"solution","path":"/rows/0/0","equals":"ResidualTolerance"}
//|       - {"artifact":"solution","path":"/rows/0/2","approx":{"value":-6.0e-13,"atol":5e-14}}
//|       - {"artifact":"solution","path":"/rows/0/3","approx":{"value":2.0e-12,"atol":5e-14}}
//|       - {"path":"/outputs/1/state","equals":"satisfied"}
use scioxide_core::{EvaluationRole, Interval, NumericScalar, RealScalar, ResidualTolerance};
use scioxide_rootfind::{Brent, ScalarFn, ScalarRootOptions, ScalarRootSolver};

let (e, m) = (eccentricity, mean_anomaly);
let function = ScalarFn::new(|x: f64| Ok(x - e * RealScalar::sin(x) - m));
// The interval [M − e, M + e], derived from |sin E| ≤ 1, brackets the root.
let bracket = Interval::new(m - e, m + e).map_err(|e| e.to_string())?;
// In addition to interval width, accept when the residual satisfies |f| ≤ 10⁻¹² rad (absolute tolerance).
let options = ScalarRootOptions::default()
    .with_residual_tolerance(ResidualTolerance::new(1e-12, 0.0).map_err(|e| e.to_string())?);
let result = Brent
    .solve(&function, bracket, &options)
    .map_err(|e| e.to_string())?;
// Estimated position error |f(Ê)| / f′(Ê). f′(E) = 1 − e cos E ≥ 1 − e > 0.
let slope = 1.0 - e * RealScalar::cos(result.point());
let residual = NumericScalar::abs(result.residual());
let evaluations = result.counts().provider(EvaluationRole::Function);
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let digits13 = serde_json::json!({ "significantDigits": 13 });
let columns = serde_json::json!([
    { "key": "0", "label": "Termination reason" },
    { "key": "1", "label": "Eccentric anomaly Ê [rad]", "type": "number", "format": digits13 },
    { "key": "2", "label": "Residual f(Ê) [rad]", "type": "number", "format": sci2 },
    { "key": "3", "label": "Estimated error |f(Ê)|/f′(Ê) [rad]", "type": "number", "format": sci2 },
    { "key": "4", "label": "Function evaluations [count]", "type": "integer" }
]);
let termination = result.termination();
emit_table_with_columns!(
    columns,
    vec![(
        termination.to_string(),
        result.point(),
        result.residual(),
        residual / slope,
        evaluations
    )],
    metadata = serde_json::json!({ "id": "solution" })
);

let outcome = if termination.is_success() {
    Outcome::satisfied("Brent's method accepted the root")
} else {
    Outcome::partial("Brent's method stopped before meeting the acceptance criteria")
        .explanation("The returned point is the last accepted approximation; check its residual and interval before using it as a root.")
};
emit_outcome!(
    outcome
        .status(termination.to_string())
        .diagnostic("Residual |f(Ê)|", residual, Some("rad"))
        .diagnostic("Function evaluations", evaluations as f64, None)
);
```

With the default inputs, termination is `ResidualTolerance`, the eccentric anomaly is approximately 1.78614 rad, the residual is $-1.6 \times 10^{-15}$ rad, and there are six function evaluations, including the two interval endpoints.
For $e = 0$, the interval contracts to the single point $M$, which is an exact root, so one evaluation suffices.
The residual has the same unit as an angle, rad, but is not itself the angular error.
Near a root, $\lvert \hat E - E^* \rvert \approx \lvert f(\hat E) \rvert / f'(E^*)$; because $f' \ge 1 - e$, the angular error corresponding to the same residual can grow as $e$ approaches 1.
For example, with $e = 0.95$ and $M = 0.1$ rad, the slope at the root is approximately 0.30, so a residual of $6.0 \times 10^{-13}$ rad gives an estimated error of $2.0 \times 10^{-12}$ rad.

## Interpreting results

A scalar solve returns `RootResult`; inspect the following quantities separately.

- Termination reason: `RootResult::termination()` (`RootTermination`) is the sole authoritative indication of success or failure.
  Methods in one variable have the following three successful termination conditions.
  - `ResidualTolerance`: an exact zero was observed, or the residual criterion explicitly set by `with_residual_tolerance` was met.
    For bracketing methods, specifying a residual scale with `with_residual_scale` also enables residual-based acceptance.
  - `StepTolerance`: in a method without a bracket, the step became no larger than the coordinate tolerance, and the residual decreased to at most $\sqrt{\varepsilon}$ times the maximum starting $\lvert f \rvert$.
  - `BracketTolerance`: in bracketing and safeguarded methods (such as `SafeguardedNewton`), the width of a sign-changing interval met the coordinate tolerance.

  Computations that find a set (all polynomial roots or special-function zeros) also treat `Complete` and `NoZeros` as success.
  Results are returned as `Ok` even for `IterationLimit`, `Stagnation`, `ComplexStepRequired`, a limit (`WorkLimit`), cancellation (`Cancelled`), or a deadline (`TimeLimit`), so inspect `is_success()` before using the values.
  However, stopping at a limit, cancellation, or deadline before any point has been accepted returns an error.
- Residual and position error: `residual()` is the function value $f(\hat x)$ at the approximate solution.
  Near a simple root, $\lvert \hat x - x^* \rvert \approx \lvert f(\hat x) \rvert / \lvert f'(x^*) \rvert$, so a root with small $\lvert f' \rvert$ may have a large position error despite a small residual ([Methods for finding roots of equations](oxref:rootfind-residual-and-position-error)).
- Bracket record: in bracketing and safeguarded methods, `RootResult::bracket()` returns the coordinates and function values of the last evaluated interval endpoints as `Bracket`.
  This is returned for `IterationLimit`, `Stagnation`, and limit termination as well as for success.
  It records a sign change evaluated in floating-point arithmetic, supporting the existence of a root under a continuity assumption, but is not a proof using interval arithmetic.
  Methods without a bracket return `None`.
- Evaluation counts and limits: `counts()` returns counts for function (`EvaluationRole::Function`), first-derivative (`Jacobian`), and second-derivative (`Hessian`) evaluations, and iterations.
  `ScalarRootOptions::with_evaluation_role` changes which component counts function evaluations.
  Set the iteration limit with `with_max_iterations` and limits such as evaluation counts with scioxide-core's `SolveBudgets` through `with_budgets`.

## Summary

`scioxide-rootfind` solves scalar equations, systems, polynomials, fixed-point problems, parameterized equations, and special-function zeros with types and functions suited to each problem.
If the function's properties yield a bracketing interval, construct it, as with $[M - e, M + e]$ for Kepler's equation, and pass it to a bracketing method.
Determine success from `termination()`, and do not use values returned with `IterationLimit` or `Stagnation` as solutions.
The residual has the function's units, so estimate position error with $\lvert f \rvert / \lvert f' \rvert$ and interpret a bracket record as evidence under a continuity assumption.
