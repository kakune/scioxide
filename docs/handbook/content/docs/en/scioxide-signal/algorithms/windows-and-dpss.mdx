The DFT of a signal observed over a finite duration is the true spectrum blurred by the spectrum of the observation interval's shape (the window).
This page expresses that blur (spectral leakage) mathematically and derives criteria for choosing window functions.
It covers `window` for generating window samples, `window_metrics` for measuring metrics, and DPSS (`DpssTapers`) for maximizing energy concentration in a band.
STFT and spectral estimation use the windows selected here ([STFT and reconstruction](../stft/), [Spectral estimation](../spectral-estimation/)).

## Finite observations and spectral leakage

A sequence observed over a length-$N$ interval $0 \le n \le N-1$ is $x_w[n] = x[n]\,w[n]$, the infinite sequence $x[n]$ multiplied by a window $w[n]$ (zero outside the interval).
Under the discrete-time Fourier transform (DTFT) $X(e^{j\omega}) = \sum_n x[n] e^{-j\omega n}$, multiplication in time becomes periodic convolution in frequency.

$$
X_w(e^{j\omega}) = \frac{1}{2\pi} \int_{-\pi}^{\pi} X(e^{j\theta})\, W(e^{j(\omega - \theta)})\, d\theta
$$

Here $\omega$ is angular frequency in radians per sample.
For a complex sinusoid $x[n] = e^{j\omega_0 n}$ of angular frequency $\omega_0$, $X$ is a delta function at $\omega_0$, giving $X_w(e^{j\omega}) = W(e^{j(\omega - \omega_0)})$.
Thus a single spectral line spreads into the window's spectral shape, leaking into other frequencies.

Observation without an explicit window corresponds to a rectangular window $w[n] = 1$, whose spectrum is the Dirichlet kernel

$$
W_{\mathrm{R}}(e^{j\omega}) = e^{-j\omega (N-1)/2}\, \frac{\sin(N\omega/2)}{\sin(\omega/2)}
$$


Since a length-$N$ DFT has bin spacing $2\pi/N$, measuring frequency in bins $\nu = N\omega/(2\pi)$ places the zeros of the main lobe (the central peak) at $\nu = \pm 1$.
Peaks outside the main lobe are called sidelobes.
The rectangular window's peak sidelobe is at $\nu \approx 1.43$, only 13.3 dB below the main lobe, and its height decays only as $1/\nu$.
Consequently, leakage from strong components obscures weak components at distant frequencies.

A window can lower sidelobes at the expense of a wider main lobe.
Sidelobes decay faster when the window value and low-order derivatives approach zero at the endpoints.
This is because an endpoint discontinuity in the DTFT produces $1/\nu$ decay, while continuity through derivative order $p$ gives $1/\nu^{p+2}$ decay.
Main-lobe width (frequency resolution) and sidelobe height (leakage suppression) cannot improve simultaneously; this tradeoff determines window selection.

## Window families and parameters

`WindowKind` is an enumeration of window families and their parameters, with 24 variants.
Formulas use the sampled length $N_s$ (the requested length, plus one for periodic windows), index $i = 0, \dots, N_s - 1$, center $c = (N_s - 1)/2$, and centered coordinate $z = 2i/(N_s - 1) - 1 \in [-1, 1]$.

A cosine-sum window has the form

$$
w[i] = \sum_{j=0}^{m-1} (-1)^j a_j \cos\!\left( \frac{2\pi j i}{N_s - 1} \right)
$$

where coefficients $a_j$ determine the family.
For periodic windows, each term's spectrum is a sum of rectangular-window Dirichlet kernels shifted by $\pm j$ bins, whose sidelobes cancel each other.

| Category | Variants | Definition highlights |
|---|---|---|
| Cosine sums | `Hann` ($a = [0.5, 0.5]$), `Hamming` ($[0.54, 0.46]$), `Blackman` ($[0.42, 0.5, 0.08]$), `Nuttall`, `BlackmanHarris` (4 terms), `FlatTop` (5 terms), `GeneralCosine(&[f64])`, `GeneralHamming { alpha }` | Coefficients appear in each variant's rustdoc. `GeneralCosine` accepts positive-sign coefficients, expressing Hann as `[0.5, 0.5]` |
| Piecewise polynomials | `Boxcar`, `Triang`, `Bartlett`, `Parzen`, `Bohman`, `Barthann` | `Triang` is triangular with nonzero endpoints; `Bartlett` is triangular with zero endpoints |
| Parametric shape families | `Kaiser { beta }`, `KaiserBesselDerived { beta }`, `Gaussian { sigma }`, `GeneralGaussian { power, sigma }`, `Tukey { alpha }`, `Exponential { tau, center }` | Kaiser is $I_0(\beta\sqrt{1 - z^2}) / I_0(\beta)$ ($I_0$ is the modified Bessel function of the first kind of order zero). Increasing $\beta$ widens the main lobe and lowers sidelobes |
| Families with specified sidelobe height | `Chebyshev { attenuation }`, `Taylor { nbar, sidelobe_level, normalize }` | The Dolph–Chebyshev window sets every sidelobe `attenuation` dB below the main lobe and is computed with a length-$N_s$ FFT. The Taylor window keeps the `nbar` sidelobes nearest the main lobe at nearly constant height |
| Other | `Cosine` ($\sin(\pi(i + 1/2)/N_s)$), `Lanczos` ($\operatorname{sinc} z$) | |

Parameters are accepted as `f64` regardless of output type, and samples are evaluated in `f64` before conversion to the output type.
NaN or infinite parameters produce `NonFinite`; out-of-range values (negative $\beta$; nonpositive $\sigma$, $\tau$, `attenuation`, or `sidelobe_level`; zero `nbar`; empty coefficient sequences) produce `InvalidInput`.
Kaiser–Bessel-derived windows accept only even lengths and symmetric windows; an explicit center for `Exponential` is allowed only for periodic windows.
A length-0 window is empty, and a length-1 window is $[1]$.

The function `window(kind, length, symmetry, normalization)` returns samples as a `Vec`.
`Window::new` with the same arguments computes and retains samples as a value, borrowing them with `samples()` or extracting them with `into_samples()`.
Use `Window` when reusing samples or storing a window in a struct field.

Most families cost $O(N)$; symmetric windows evaluate only half and reflect it.
Taylor windows cost $O(N \bar n + \bar n^2)$, while Dolph–Chebyshev windows use FFTs and cost $O(N \log N)$.
For an $m$-term cosine sum with $A = \sum_j |a_j|$, $J = \sum_j j|a_j|$, and $u = 2^{-53}$, the absolute error of a window sample, excluding cosine evaluation error, is at most approximately $2muA + 10\pi u J$.
Near window zeros, this absolute error provides no relative accuracy.

## Symmetric and periodic windows

`WindowSymmetry` selects the sampling convention.

- `Symmetric` (default) generates a symmetric length-$N$ sequence including both endpoints.
  It satisfies $w[i] = w[N-1-i]$ and is used for linear-phase FIR filter coefficients ([FIR design and minimum phase](../fir-design-and-minimum-phase/)).
- `Periodic` generates a symmetric length-$N + 1$ sequence and removes the last sample.
  The remaining $N$ samples form one period of a period-$N$ function, suitable for DFT analysis.

For periodic windows, each cosine-sum term matches a length-$N$ DFT basis function.
Thus a Hann window sums to $N/2$ and has sum of squares $3N/8$; adding Hann windows shifted by $N/2$ gives a constant.
A symmetric Hann window adds one endpoint to a period-$N - 1$ Hann window; its sum is $(N-1)/2$ and sum of squares is $3(N-1)/8$.
The two conventions differ by order $1/N$, more visibly for short windows.

## Window scaling

`WindowNormalization` selects scaling applied after removing the final sample of a periodic window.
`Native` (default) uses the family definition's scale; `UnitPeak` divides by the maximum absolute value, and `UnitEnergy` divides by the Euclidean norm.
Requesting `UnitPeak` or `UnitEnergy` when every sample is zero produces `DomainError`.

Scaling leaves ENBW unchanged and only multiplies coherent gain by a constant.
`StftPlan` and `SpectralEstimatePlan` divide coefficients by the window sum or sum of squares, so scaling does not affect result units.

## Coherent gain and equivalent noise bandwidth

Window performance is measured by the ratio of its gain for a sinusoid to its gain for white noise.

Consider a real sinusoid $A\cos(2\pi k n/N + \phi)$ of amplitude $A$ at a bin-centered frequency $\nu = k$.
Ignoring leakage from the negative-frequency component, bin $k$ of the windowed DFT has value $|X_k| = A\,|\sum_n w[n]|/2$.
Define coherent gain as

$$
G_c = \frac{1}{N} \sum_{n=0}^{N-1} w[n]
$$

so that the one-sided amplitude is $A = 2|X_k| / (N G_c)$.
Shifting the sinusoid's frequency half a bin from the center reduces the peak height by a factor of $|W(\nu = 1/2)|/|W(0)|$.
This is called scalloping loss.

For white noise of variance $\sigma^2$, $\mathrm{E}|X_k|^2 = \sigma^2 \sum_n w[n]^2$.
Suppose an ideal rectangular band of height $|W(0)|^2 = (\sum_n w[n])^2$ and width $B$ bins passes the same noise power; solving for $B$ gives the equivalent noise bandwidth (ENBW):

$$
\mathrm{ENBW} = N \frac{\sum_{n} w[n]^2}{\left( \sum_{n} w[n] \right)^2} \quad [\text{bins}]
$$


Noise with one-sided power spectral density $S$ contributes power $S \cdot \mathrm{ENBW} \cdot f_s/N$ to a single bin, where $f_s$ is the sampling rate.
By the Cauchy–Schwarz inequality, ENBW $\ge 1$, with equality only for a rectangular window.

`window_metrics(samples)` computes $G_c$ and ENBW from the actual samples and returns them through `coherent_gain()` and `equivalent_noise_bandwidth()` of `WindowMetrics`.
Sums are computed after dividing by the largest $|w[n]|$, using compensated summation in `f64`.
Empty samples produce `InvalidInput`, NaN or infinity produces `NonFinite`, and zero-sum samples produce `DomainError` because ENBW is undefined.
$G_c$ is a signed mean and includes cancellation for windows with negative samples (such as Flat-top).

The next cell generates symmetric and periodic Hann windows and compares measurements with the closed forms above.
For periodic windows, $G_c = 1/2$ and ENBW $= 1.5$ bins.
For symmetric windows, $G_c = (N-1)/(2N)$ and ENBW $= 1.5N/(N-1)$.
The closed-form column is an independent check using these formulas.

// Independent check: periodic windows sum over one period of a period-N Hann window; symmetric windows sum over one period of a period-(N − 1) Hann window

## Comparing window performance

The window frequency response $W(e^{j\omega})$ can be evaluated on a fine grid by taking the DFT of its samples followed by zeros.
Zero-padding a length-$N$ window to $ZN$ points gives DTFT values on a grid spaced $1/Z$ bins apart.
Zero-padding only refines the grid; it does not change frequency resolution.

The next cell generates length-$N$ periodic windows with `window` and derives the following quantities from `power_spectrum` ($|W_k|^2 / (ZN)$) of sequences zero-padded by a factor of $Z = 32$.

- 3 dB width: twice the frequency where $|W|^2$ falls to half its central value.
  Values between grid points are interpolated linearly in dB.
- First zero: the first local minimum of $|W|^2$ outside the main lobe.
- Peak sidelobe: the ratio of the largest $|W|^2$ beyond the first zero to its central value.
  A parabola in dB is fitted to the local maximum and its two neighboring grid points to locate the vertex.
- Scalloping loss: the ratio of $|W|^2$ at a half-bin offset to its central value.
- ENBW: the difference between `window_metrics` and the value $\sum_k |W_k|^2 / (Z |W_0|^2)$ derived from Parseval's relation.

The windows are rectangular, Hann, Hamming, Blackman, four-term Blackman–Harris, five-term Flat-top, and Kaiser with input-selected $\beta$.
The plot shows normalized power $|W(\nu)|^2 / |W(0)|^2$ on a logarithmic axis.

```rust
//| id: signal-window-leakage-comparison
//| ref: signal-window-leakage-comparison
//| title: "Measure window main lobes and sidelobes with zero-padded DFTs"
//| run: reactive
//| crates: [scioxide-core, scioxide-signal]
//| inputs:
//|   window_length: {"type":"range","label":"Window length N [samples]","description":"Periodic window length. Metrics remain nearly independent of N.","min":64,"max":2048,"step":64,"value":1024}
//|   kaiser_beta: {"type":"range","label":"Kaiser window β [-]","description":"Larger values widen the main lobe and lower sidelobes.","min":0,"max":14,"step":0.5,"value":8.5}
//| cases:
//|   - {"id":"short-window","label":"N = 64","description":"Even short periodic windows have nearly the same metrics as N = 1024.","inputs":{"window_length":64}}
//|   - {"id":"kaiser-zero","label":"β = 0","description":"The Kaiser window matches the rectangular window.","inputs":{"kaiser_beta":0}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"windows","path":"/rows/0/1","approx":{"value":0.886,"atol":0.001}}
//|       - {"artifact":"windows","path":"/rows/0/3","approx":{"value":-13.26,"atol":0.01}}
//|       - {"artifact":"windows","path":"/rows/1/2","approx":{"value":2.0,"atol":0.01}}
//|       - {"artifact":"windows","path":"/rows/1/5","approx":{"value":1.5,"atol":1e-12}}
//|       - {"artifact":"windows","path":"/rows/1/6","range":{"max":1e-12}}
//|   - case: kaiser-zero
//|     expect:
//|       - {"artifact":"windows","path":"/rows/6/1","approx":{"value":0.886,"atol":0.001}}
//|       - {"artifact":"windows","path":"/rows/6/5","approx":{"value":1.0,"atol":1e-12}}
use scioxide_core::RealScalar;
use scioxide_signal::{
    WindowKind, WindowNormalization, WindowSymmetry, power_spectrum, window, window_metrics,
};

let n = window_length.round() as usize;
let zoom = 32_usize;
let kinds = [
    ("Rectangular", WindowKind::Boxcar),
    ("Hann", WindowKind::Hann),
    ("Hamming", WindowKind::Hamming),
    ("Blackman", WindowKind::Blackman),
    ("Blackman–Harris (4 terms)", WindowKind::BlackmanHarris),
    ("Flat-top (5 terms)", WindowKind::FlatTop),
    ("Kaiser", WindowKind::Kaiser { beta: kaiser_beta }),
];
let decibel = |r: f64| 10.0 * RealScalar::log10(r);
let mut rows = Vec::new();
let mut curves = Vec::new();
for (name, kind) in kinds {
    let w = window::<f64>(kind, n, WindowSymmetry::Periodic, WindowNormalization::Native)
        .map_err(|e| e.to_string())?;
    let metrics = window_metrics(&w).map_err(|e| e.to_string())?;
    // Zero-pad the window by a factor of Z and compute |W_k|² on a grid spaced 1/Z bins apart
    let mut padded = vec![0.0; zoom * n];
    padded[..n].copy_from_slice(&w);
    let power = power_spectrum(&padded).map_err(|e| e.to_string())?;
    let half: Vec<f64> = power[..=zoom * n / 2].iter().map(|p| p / power[0]).collect();
    // 3 dB width: interpolate linearly in dB between the first grid point below half power and its predecessor
    let k3 = half.iter().position(|&r| r < 0.5).ok_or("No 3 dB point")?;
    let (a, b) = (decibel(half[k3 - 1]), decibel(half[k3]));
    let crossing = (k3 - 1) as f64 + (a - decibel(0.5)) / (a - b);
    let width = 2.0 * crossing / zoom as f64;
    // First zero: the first local minimum below half power
    let null = (1..half.len() - 1)
        .find(|&k| half[k] < 0.5 && half[k] <= half[k - 1] && half[k] <= half[k + 1])
        .ok_or("No local minimum outside the main lobe")?;
    // Peak sidelobe: locate a dB parabola's vertex around the local-maximum grid point
    let peak = (null..half.len() - 1)
        .max_by(|&i, &j| half[i].total_cmp(&half[j]))
        .ok_or("No sidelobe")?;
    let (l, c, r) = (decibel(half[peak - 1]), decibel(half[peak]), decibel(half[peak + 1]));
    let curvature = l - 2.0 * c + r;
    let sidelobe = if curvature < 0.0 {
        c - (r - l).powi(2) / (8.0 * curvature)
    } else {
        c
    };
    let scallop = decibel(half[zoom / 2]);
    // Independent check: ENBW from Parseval's relation
    let spectral_enbw = power.iter().sum::<f64>() / power[0] / zoom as f64;
    let enbw = metrics.equivalent_noise_bandwidth();
    rows.push((
        name,
        width,
        null as f64 / zoom as f64,
        sidelobe,
        scallop,
        enbw,
        (spectral_enbw - enbw).abs(),
    ));
    if matches!(name, "Rectangular" | "Hann" | "Blackman–Harris (4 terms)" | "Kaiser") {
        let points: Vec<[f64; 2]> = half[..=16 * zoom]
            .iter()
            .enumerate()
            .filter(|(_, r)| **r > 0.0)
            .map(|(k, &r)| [k as f64 / zoom as f64, r])
            .collect();
        curves.push(serde_json::json!({ "name": name, "points": points }));
    }
}

let fixed3 = serde_json::json!({ "fractionDigits": 3 });
let fixed2 = serde_json::json!({ "fractionDigits": 2 });
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let columns = serde_json::json!([
    { "key": "0", "label": "Window" },
    { "key": "1", "label": "3 dB width [bins]", "type": "number", "format": fixed3 },
    { "key": "2", "label": "First zero [bins]", "type": "number", "format": fixed3 },
    { "key": "3", "label": "Peak sidelobe [dB]", "type": "number", "format": fixed2 },
    { "key": "4", "label": "Scalloping loss [dB]", "type": "number", "format": fixed2 },
    { "key": "5", "label": "ENBW [bins]", "type": "number", "format": fixed3 },
    { "key": "6", "label": "Difference from Parseval ENBW check [bins]", "type": "number", "format": sci2 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "windows" })
);
emit_line_chart!(
    &curves,
    options = &serde_json::json!({
        "xLabel": "Frequency from main-lobe center ν [bins]",
        "yLabel": "Normalized power |W(ν)|²/|W(0)|² [-]",
        "yType": "log",
        "xMin": 0.0,
        "xMax": 16.0,
        "yMin": 1e-14,
        "yMax": 2.0
    })
);
```

With the default $N = 1024$ and $\beta = 8.5$, the table gives the following values.
The rectangular window has 3 dB width 0.885 bins, peak sidelobe −13.26 dB, and scalloping loss −3.92 dB.
These agree with the Dirichlet kernel values (0.886 bins, −13.26 dB, and $20\log_{10}(2/\pi) = -3.92$ dB for $N \to \infty$).
The Hann window gives 1.441 bins, −31.47 dB, and ENBW 1.500 bins; the Hamming window gives 1.303 bins, −42.67 dB, and ENBW 1.363 bins.
The four-term Blackman–Harris window gives 1.899 bins, −92.01 dB, and ENBW 2.004 bins; its main lobe widens as its sidelobes are lowered.
The Flat-top window is widest, with 3 dB width 3.724 bins and ENBW 3.770 bins, but its scalloping loss is −0.0098 dB, allowing almost direct readings of sinusoidal amplitudes between bins.
The first zeros of cosine-sum windows occur at 1–5 bins, equal to their number of terms.
This is because each term is a shifted Dirichlet kernel, and their zeros coincide.
ENBW from `window_metrics` differs from the value given by Parseval's relation by at most $10^{-13}$.

For $\beta = 0$, the Kaiser window has the same row as the rectangular window; at $\beta = 14$ it changes to 3 dB width 2.045 bins and peak sidelobe −105.93 dB.
Even shortening to $N = 64$ leaves 3 dB width, ENBW, and scalloping loss unchanged to three decimal places.
The peak sidelobe rises to −42.45 dB for Hamming and −88.16 dB for Flat-top; windows with lower sidelobes show larger differences at short lengths.
In the plot, rectangular-window sidelobes decay in power as $1/\nu^2$ and Hann sidelobes as $1/\nu^6$, while Blackman–Harris sidelobes lie nearly flat around −92 dB.

## Band-concentrated windows

Once the window's main-lobe width is fixed, the window minimizing energy leakage outside that band is obtained from an eigenvalue problem.
Let the half-bandwidth measured in cycles per sample be $W$ ($0 < W < 1/2$).
For a length-$N$ sequence $v$ with DTFT $V(f)$, define concentration as the fraction of total energy in band $|f| \le W$:

$$
\lambda = \frac{\int_{-W}^{W} |V(f)|^2\, df}{\int_{-1/2}^{1/2} |V(f)|^2\, df} = \frac{v^{\mathsf T} C v}{v^{\mathsf T} v}, \qquad C_{mn} = \frac{\sin(2\pi W (m - n))}{\pi (m - n)}, \quad C_{nn} = 2W
$$


The second equality follows from Parseval's relation and $\int_{-W}^{W} e^{2\pi j f (m-n)} df = C_{mn}$.
Since concentration is a Rayleigh quotient, eigenvectors $v_0, v_1, \dots$ of the Toeplitz matrix $C$, ordered by decreasing eigenvalue, maximize concentration among sequences orthogonal to all preceding ones.
These are discrete prolate spheroidal sequences (DPSS, or Slepian windows), and $\lambda_k$ is the associated eigenvalue.

About $2NW$ eigenvalues of $C$ (the Shannon number) cluster near 1, with the remainder near 0.
Differences between eigenvalues near 1 are exponentially small, so directly decomposing $C$ loses the distinction between eigenvectors in roundoff.
Slepian exhibited a symmetric tridiagonal matrix commuting with $C$:

$$
T_{ii} = \left( \frac{N - 1}{2} - i \right)^2 \cos(2\pi W), \qquad T_{i-1,i} = T_{i,i-1} = \frac{i (N - i)}{2}
$$


Commuting symmetric matrices share eigenvectors, and $T$ has well-separated eigenvalues, allowing stable computation of $T$ eigenvectors.
`DpssTapers` divides $T$ by $N^2$ to keep coefficient magnitudes consistent independently of $N$, and selects the largest $K$ eigenpairs by bisection and inverse iteration.
Memory use is $O(NK)$.
Each window's concentration $\lambda_k$ is recomputed by finding its autocorrelation with FFTs and taking an inner product with $C$.

### DPSS API

`DpssTapers::<S>::new(length, time_bandwidth, taper_count, options)` accepts the time–bandwidth product $NW$ as `time_bandwidth` and sets $W = NW/N$.
$N$ is the sampled length, adding one to the requested length for periodic windows.
`DpssOptions` holds the sampling convention (default `Symmetric`), window scaling (default `UnitEnergy`), and tridiagonal eigensolver settings (`scioxide_linalg::HermitianEigenOptions`).
Computation uses `f64` regardless of output type.

Windows occupy contiguous rows in `samples()`; `taper(k)` borrows window $k$.
Signs are chosen so even-order windows have positive sums and odd-order windows have a positive first significant sample.
`concentration_ratios()` returns $\lambda_k$ for the sampled length-$N$ unit-energy window before periodization and scaling.

The `DpssReport` returned by `report()` holds eigensolver work (`counts()`) and scaled residual (`residual()`).
The scaled residual of eigenpair $(\mu, v)$ is $\lVert (T - \mu I) v \rVert_\infty / ((\lVert T \rVert_\infty + |\mu|) \lVert v \rVert_\infty)$; the maximum over all windows is retained.
The only variant of termination status `DpssTermination` is `Completed`; computation failure returns an error.
`Completed` makes no accuracy claim, so judge accuracy from the residual and concentration.

Failures are as follows.
Length 0 produces `InvalidInput` (`Empty`); `taper_count` outside 1 through the requested length `length` or `time_bandwidth` outside $(0, \text{length}/2)$ produces `InvalidInput`; NaN or infinite `time_bandwidth` produces `NonFinite`.
Both ranges are checked against the requested length before adding one, even for periodic windows.
Eigensolver failure produces `ConvergenceFailure` or `NumericalInstability`.
A computed concentration outside $[0, 1]$ by more than $64\varepsilon N$ also produces `NumericalInstability` (`LossOfSignificance`).
A length-1 window is $[1]$, with concentration $2W$.

The next cell computes DPSS and compares concentration with a direct sum of the Toeplitz matrix $C$ quadratic form $v^{\mathsf T} C v / v^{\mathsf T} v$ ($O(N^2)$, an independent check without FFTs).
It also checks orthogonality using the maximum inner product between windows.
Termination status appears as an outcome, with residual and minimum concentration as diagnostics.

```rust
//| id: signal-dpss-concentration
//| ref: signal-dpss-concentration
//| title: "Check DPSS concentration with a Toeplitz quadratic form"
//| run: reactive
//| crates: [scioxide-core, scioxide-signal]
//| inputs:
//|   length: {"type":"range","label":"Window length N [samples]","description":"Window length.","min":16,"max":256,"step":16,"value":128}
//|   time_bandwidth: {"type":"range","label":"Time–bandwidth product NW [-]","description":"Determines the half-bandwidth W = NW/N.","min":1,"max":6,"step":0.5,"value":4}
//|   taper_count: {"type":"range","label":"Number of windows K","description":"Concentration drops sharply beyond the Shannon number 2NW.","min":1,"max":12,"step":1,"value":8}
//| cases:
//|   - {"id":"beyond-shannon","label":"K = 12","description":"Windows of order beyond 2NW = 8 have energy outside the band.","inputs":{"taper_count":12}}
//|   - {"id":"narrow-band","label":"NW = 1.5, K = 3","description":"A narrower band has fewer windows with concentration near 1.","inputs":{"time_bandwidth":1.5,"taper_count":3}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"tapers","path":"/rows/0/1","approx":{"value":1.0,"atol":1e-9}}
//|       - {"artifact":"tapers","path":"/rows/0/3","range":{"max":1e-12}}
//|       - {"artifact":"tapers","path":"/rows/7/3","range":{"max":1e-12}}
//|       - {"artifact":"tapers","path":"/rows/7/4","range":{"max":1e-12}}
//|       - {"path":"/outputs/2/state","equals":"satisfied"}
//|   - case: beyond-shannon
//|     expect:
//|       - {"artifact":"tapers","path":"/rows/11/1","range":{"max":0.1}}
//|       - {"artifact":"tapers","path":"/rows/11/3","range":{"max":1e-12}}
//|       - {"path":"/outputs/2/state","equals":"satisfied"}
use scioxide_core::RealScalar;
use scioxide_signal::{DpssOptions, DpssTapers, DpssTermination};

let n = length.round() as usize;
let count = taper_count.round() as usize;
let tapers = DpssTapers::<f64>::new(n, time_bandwidth, count, DpssOptions::default())
    .map_err(|e| e.to_string())?;
let bandwidth = time_bandwidth / n as f64;

// Independent check: form the first column of C, c[ℓ] = sin(2πWℓ)/(πℓ), c[0] = 2W, and compute vᵀCv by direct summation
let pi = core::f64::consts::PI;
let kernel: Vec<f64> = (0..n)
    .map(|lag| match lag {
        0 => 2.0 * bandwidth,
        _ => RealScalar::sin(2.0 * pi * bandwidth * lag as f64) / (pi * lag as f64),
    })
    .collect();
let mut rows = Vec::with_capacity(count);
for k in 0..count {
    let v = tapers.taper(k).map_err(|e| e.to_string())?;
    let mut quadratic = 0.0;
    for (m, &vm) in v.iter().enumerate() {
        for (l, &vl) in v.iter().enumerate() {
            quadratic += vm * vl * kernel[m.abs_diff(l)];
        }
    }
    let energy: f64 = v.iter().map(|x| x * x).sum();
    let direct = quadratic / energy;
    // Orthogonality: maximum inner product with preceding windows (ideally 0 because energy is one)
    let mut overlap = 0.0_f64;
    for j in 0..k {
        let u = tapers.taper(j).map_err(|e| e.to_string())?;
        let dot: f64 = u.iter().zip(v).map(|(a, b)| a * b).sum();
        overlap = overlap.max(dot.abs());
    }
    let lambda = tapers.concentration_ratios()[k];
    rows.push((k, lambda, 1.0 - lambda, (lambda - direct).abs(), overlap));
}

let fixed12 = serde_json::json!({ "fractionDigits": 12 });
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let columns = serde_json::json!([
    { "key": "0", "label": "Order k", "type": "integer" },
    { "key": "1", "label": "Concentration λ_k [-]", "type": "number", "format": fixed12 },
    { "key": "2", "label": "Out-of-band fraction 1 − λ_k [-]", "type": "number", "format": sci3 },
    { "key": "3", "label": "Difference from direct sum [-]", "type": "number", "format": sci3 },
    { "key": "4", "label": "Maximum inner product with preceding windows [-]", "type": "number", "format": sci3 }
]);
emit_table_with_columns!(
    columns,
    rows.clone(),
    metadata = serde_json::json!({ "id": "tapers" })
);

let series: Vec<serde_json::Value> = (0..count.min(4))
    .map(|k| {
        let v = tapers.samples()[k * n..(k + 1) * n].to_vec();
        let points: Vec<[f64; 2]> = v.iter().enumerate().map(|(i, &x)| [i as f64, x]).collect();
        serde_json::json!({ "name": format!("v_{k}"), "points": points })
    })
    .collect();
emit_line_chart!(
    &series,
    options = &serde_json::json!({
        "xLabel": "Sample index i [-]",
        "yLabel": "Window coefficient v_k[i] (unit energy) [-]"
    })
);

let report = tapers.report();
let minimum = rows.iter().map(|r| r.1).fold(1.0_f64, f64::min);
let outcome = match report.termination() {
    DpssTermination::Completed => {
        Outcome::satisfied("Computed eigenpairs and all windows (no accuracy claim)")
    }
};
emit_outcome!(
    outcome
        .status(format!("{:?}", report.termination()))
        .diagnostic("Scaled eigenpair residual", report.residual().scaled_norm(), None)
        .diagnostic("Minimum concentration", minimum, None)
);
```

With the default $N = 128$, $NW = 4$, and $K = 8$, concentration decreases from $\lambda_0 = 1 - 2.8 \times 10^{-10}$ to $\lambda_5 = 0.9926$, $\lambda_6 = 0.937$, and $\lambda_7 = 0.699$.
Concentration begins to depart from 1 at orders near the Shannon number $2NW = 8$.
Setting $K = 12$ gives $\lambda_8 = 0.299$, $\lambda_9 = 0.064$, and $\lambda_{11} = 7.5 \times 10^{-4}$; these orders have most of their energy outside the band.
With $NW = 1.5$, $\lambda_0 = 0.9989$, $\lambda_1 = 0.969$, and $\lambda_2 = 0.733$, only two windows have concentration near 1.
At both ends of every input range, `concentration_ratios()` differs from the direct quadratic-form sum by at most $1.3 \times 10^{-14}$, inner products between windows are at most $5 \times 10^{-16}$, and scaled eigenpair residuals are at most $2.3 \times 10^{-16}$.
The $1 - \lambda_k$ column subtracts numbers near 1, so values of order $10^{-15}$ (such as $\lambda_0$ at $NW = 6$) represent only roundoff.

DPSS minimize out-of-band leakage outside $[-W, W]$ for each window.
Computing and averaging periodograms with $K$ windows, fewer than the Shannon number, reduces estimation variance while retaining resolution at bandwidth $2W$ (the multitaper method).
scioxide-signal has no multitaper estimation function; pass each window from `DpssTapers` to `SpectralEstimatePlan` and average the results in the caller.

## Summary

Finite observations produce convolution with the window spectrum, so choose windows through the tradeoff between main-lobe width (resolution) and sidelobe height (leakage).
Use periodic windows for DFT analysis and symmetric windows for linear-phase FIR design.
Use coherent gain to convert sinusoidal amplitudes and ENBW to convert noise power.
Use `window_metrics` and zero-padded `power_spectrum` to check gain, 3 dB width, and sidelobes of the actual samples.
Use DPSS to concentrate energy in a specified band, judging quality from concentration and residuals.
[STFT and reconstruction](../stft/) covers the short-time Fourier transform, which shifts windows along time; [Spectral estimation](../spectral-estimation/) covers windowed spectral-density estimates.
