These tables summarize public items for local signal properties.
One-shot functions (`median_filter`, `find_peaks`, `peak_properties`, `savitzky_golay`, `vector_strength`, `waveform`, `detrend`) allocate and return results.
Caller-provided-output APIs such as `find_peaks_into`, `detrend_into`, and `waveform_into` write into caller output and workspace without allocating during execution.
All functions leave output unchanged on failure.

## Tracking peaks across scales

Prepare scales and Ricker kernels with `RidgePlan::new(scales, options)`.
For one record, `plan.find_peaks(input)` returns ridges.
For repeated computations, prepare `RidgeWorkspace` with `plan.workspace(max_input_len)` and pass it with output to `plan.find_peaks_into`.
It returns ridges meeting minimum length and strength, without estimating noise thresholds.

## Summary

Remove outliers with `median_filter` or the Hampel filter in `LocalFilterPlan`, and Gaussian noise with Wiener filtering; pass state storage to `LocalFilterStream` for processing as data arrive.
Measure peak geometry with `find_peaks`; pass `PeakOptions` to `find_peaks_with_options` for selection, and track structures across scales with `RidgePlan::find_peaks`.
Choose smoothing approaches by purpose from local polynomials (`savitzky_golay`, `SavitzkyGolayPlan`), difference penalties (Whittaker–Henderson), and spline coefficients, and inspect diagnostics.
Plans retain wavelet coefficient ordering and boundary extension; use the same plan's `analyze_axis_into` for transforms along an array axis.
See the [API guide](../) for the API list and type relationships.
