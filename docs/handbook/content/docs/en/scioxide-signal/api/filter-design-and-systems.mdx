These tables cover filter design and application and state-space models of linear time-invariant (LTI) systems.
FIR and IIR design functions accept digital frequencies as ratios to Nyquist frequency.
`FirDesign::termination()` is the sole FIR design termination status; successful IIR design returns `IirDesign` with finite stable poles and otherwise returns an error.
Designs and conversions that iteratively find roots, eigenvalues, or extrema (`design_iir`, `iir_prototype`, `select_iir_order`, `design_fir_remez`, `design_real_gammatone`, `to_zpk`, `place_poles`) provide standard forms executing sequentially in a new root scope and scoped APIs (`_scoped`) accepting an execution context or outer solver's `SolveContext` last ([Call forms](../#call-forms)).
Standard `select_iir_order`, `design_fir_remez`, and `place_poles` return `ConvergenceFailure` when targets are unmet; options forms (`_with_options`) and scoped APIs return the final result and termination in `Ok`.
Assemble settings with `with_*`; design or plan preparation validates them.

## Summary

Choose FIR design functions by approximation criterion; inspect `termination()` and, for equation-based designs, `condition_estimate()` before using coefficients.
Standard Remez turns nonconvergence into errors; use options form `design_fir_remez_with_options` and read termination to inspect approximations stopped by limits.
Design IIR filters with `design_iir` (or first select order, family, and band with `select_iir_order`), convert to second-order sections with `to_sos()`, and apply with `filter` or `forward_backward`.
For chunked processing or explicit states, use method object `IirFilter` with caller-owned `IirState`.
Check minimum-phase conversion through grid diagnostics and independent frequency responses; make state-space time conventions explicit with `LtiTime` and select discretization methods.
Local filters and smoothing are listed in [Local filters, features, smoothing, and wavelets](../features-and-smoothing/).
