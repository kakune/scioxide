These tables summarize public items for frequency-domain analysis.
Frequency units differ by item.
`welch`, `SpectralEstimatePlan`, and `StftPlan` accept sample rates and use cycles per unit time; `lomb_scargle` and `LombScargle` use angular frequencies (radians per unit time); `power_spectrum` and `cross_spectrum` use DFT bin indices.

## Summary

Construct and check windows with `window` and `window_metrics`; use `DpssTapers` for band concentration.
Compute equally spaced power spectral densities with one-shot `welch`; use `SpectralEstimatePlan` for window, overlap, and scaling choices or cross-spectra and coherence.
For irregular-sample period searches, begin with `lomb_scargle`; use method object `LombScargle` to change weights or settings or repeat computations at the same times.
Frequency units differ: `welch` uses cycles and `lomb_scargle` angular frequencies.
STFT inversion requires NOLA; check it with `check_overlap` and `StftPlan::dual_window`.
Use `hilbert` for one-dimensional analytic signals and `AnalyticSignalNdPlan` or Riesz transforms for multidimensional signals; both assume periodic extension.
Convolution items are in [Convolution, correlation, and resampling](../convolution-and-resampling/), and filter design in [Filter design, minimum phase, and LTI systems](../filter-design-and-systems/).
