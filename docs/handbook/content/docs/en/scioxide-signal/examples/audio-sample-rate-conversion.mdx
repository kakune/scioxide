CD audio is often sampled at 44.1 kHz, while video and broadcast audio often use 48 kHz; mixing them for editing requires sample-rate conversion.
This example converts between the two rates using three methods from `scioxide-signal`.
They are `resample` with its default polyphase filter, `PolyphasePlan::rational` supplied with a custom sharp low-pass filter, and `resample_periodic`, which treats the record as one period.
Measure sinusoidal amplitude error, aliasing of components beyond the Nyquist frequency, and round-trip error to judge which method suits each application.

## The ratio 160/147 and the higher sampling rate

$48000 / 44100 = 160/147$, and 160 and 147 are coprime, so the ratio cannot be reduced further.
Conversion from 44.1 kHz to 48 kHz interpolates by a factor of $L = 160$ and decimates by $M = 147$; the reverse direction uses $L = 147$ and $M = 160$.
In either direction, the higher sampling rate after interpolation is $44100 \times 160 = 48000 \times 147 = 7.056$ MHz, with a Nyquist frequency of 3.528 MHz.
The polyphase form avoids constructing this 7.056 MHz sequence and computes only about $1/L$ of the $K$ coefficient–sample products per output sample ([Polyphase decomposition and complexity](oxref:signal-polyphase)).

Place the low-pass cutoff at 22.05 kHz, the lower of the two Nyquist frequencies.
For conversion from 44.1 kHz to 48 kHz, interpolation images at frequency $44.1\ \mathrm{kHz} - f$ can fall below the output Nyquist frequency of 24 kHz.
For conversion from 48 kHz to 44.1 kHz, input components above 22.05 kHz alias to $44.1\ \mathrm{kHz} - f$.
In either direction, the unwanted component appears at frequency $44.1\ \mathrm{kHz} - f$, and its amplitude is determined by the filter gain $\lvert H \rvert / L$ at the higher sampling rate.
A passband extending to 20 kHz, conventionally taken as the upper limit of human hearing, requires the filter to cut off within the narrow interval from 20 kHz to 22.05 kHz.

## Two low-pass filters

The default `resample(x, 160, 147)` uses the `rational_default` design with a Kaiser window of $\beta = 5$ ([Default low-pass filter](oxref:signal-resampling-filter)).
It has $20 \times 160 + 1 = 3201$ coefficients and a cutoff frequency of 22.05 kHz (the $-6$ dB point).
The transition band is about 30% of the cutoff frequency in width, so components near 20 kHz are weakened and those just above 22.05 kHz are not sufficiently attenuated.

Design the sharp comparison filter with `design_fir_window` for the same 7.056 MHz sequence.
Use $2 \times 60 \times 160 + 1 = 19201$ coefficients, a Kaiser window with $\beta = 8.6$, and an ideal cutoff of 21.025 kHz, halfway between 20 kHz and 22.05 kHz.
Kaiser's empirical formula predicts stopband attenuation of $A \approx 87$ dB and a transition width of about 2 kHz; this design places the passband up to 20 kHz and the stopband from 22.05 kHz.
Normalize the DC gain to the interpolation factor $L$ and pass the coefficients to `PolyphasePlan::rational(&taps, up, down, ResampleAlignment::Centered)`.
The number of products per output sample is about $19201/160 \approx 120$, six times the default of about 20.

The following block defines functions shared by the two cells.
`sharp_taps` designs the sharp filter above, and `tone` creates a sinusoid of frequency $f$ using `scioxide_signal::waveform`.
`amplitude` excludes 100 samples at each end of the record and estimates amplitude by evaluating the Blackman–Harris-windowed DTFT at the known frequency.
The window's maximum sidelobe is $-92$ dB, so leakage from other components at least 500 Hz away is negligible relative to the measured amplitude.

```rust
//| id: signal-audio-rate-model
//| kind: definitions
//| title: "Definitions for conversion between 44.1 kHz and 48 kHz"
//| crates: [scioxide-core, scioxide-signal]
use scioxide_core::RealScalar;
use scioxide_signal::{
    FirBand, FirNormalization, FirSymmetry, Waveform, WindowKind, WindowNormalization,
    WindowSymmetry, design_fir_window, waveform, window,
};

/// The two sampling rates [Hz] and sample counts for a 0.1 s record
pub(crate) const LOW_RATE: f64 = 44_100.0;
pub(crate) const HIGH_RATE: f64 = 48_000.0;
pub(crate) const DURATION: f64 = 0.1;

/// Sharp low-pass filter for the 7.056 MHz sequence: 19201 coefficients, Kaiser window β = 8.6, cutoff 21.025 kHz, DC gain up
pub(crate) fn sharp_taps(up: usize) -> Result<Vec<f64>, String> {
    let nyquist = 0.5 * LOW_RATE * 160.0;
    let band = [FirBand::new(0.0, 21_025.0 / nyquist, 1.0, 1.0)];
    let gain = FirNormalization::At {
        frequency: 0.0,
        gain: up as f64,
    };
    let kaiser = WindowKind::Kaiser { beta: 8.6 };
    let design = design_fir_window(19_201, FirSymmetry::Even, &band, kaiser, gain)
        .map_err(|e| e.to_string())?;
    Ok(design.coefficients().to_vec())
}

/// Sinusoid a sin(2π f t) of duration DURATION seconds at sampling rate rate [Hz]
pub(crate) fn tone(frequency: f64, amplitude: f64, rate: f64) -> Result<Vec<f64>, String> {
    let count = (DURATION * rate).round() as usize;
    let times: Vec<f64> = (0..count).map(|n| n as f64 / rate).collect();
    let sine = Waveform::Sine {
        frequency,
        phase: 0.0,
    };
    let values = waveform(sine, &times).map_err(|e| e.to_string())?;
    Ok(values.iter().map(|v| amplitude * v).collect())
}

/// Exclude 100 samples at each end and estimate the amplitude at frequency f [Hz] from the Blackman–Harris-windowed DTFT
pub(crate) fn amplitude(values: &[f64], frequency: f64, rate: f64) -> Result<f64, String> {
    let interior = &values[100..values.len() - 100];
    let taper = window::<f64>(
        WindowKind::BlackmanHarris,
        interior.len(),
        WindowSymmetry::Symmetric,
        WindowNormalization::Native,
    )
    .map_err(|e| e.to_string())?;
    let omega = core::f64::consts::TAU * frequency / rate;
    let (mut re, mut im) = (0.0, 0.0);
    for (j, (y, w)) in interior.iter().zip(&taper).enumerate() {
        re += w * y * RealScalar::cos(omega * j as f64);
        im -= w * y * RealScalar::sin(omega * j as f64);
    }
    Ok(2.0 * RealScalar::sqrt(re * re + im * im) / taper.iter().sum::<f64>())
}
```

## Passband gain and aliasing

The next cell selects the conversion direction and converts unit-amplitude sinusoids at 90 frequencies up to the input Nyquist frequency with each of the two filters.
For each output, measure the amplitude at the original frequency $f$ (the passed component) and the amplitude of the unwanted component at frequency $44.1\ \mathrm{kHz} - f$ (an image or alias).
Do not measure frequencies beyond the output Nyquist frequency or points where the two frequencies are within 500 Hz of each other.
The chart plots the four amplitudes on a logarithmic axis, with vertical lines at 20 kHz and 22.05 kHz.
For each filter, the table shows the number of coefficients, the deviation from 1 of the passed amplitude at or below 20 kHz, the amplitude of a 20 kHz sinusoid, the maximum unwanted amplitude, and the difference between the measured passed amplitude and $\lvert H \rvert / L$ computed from the coefficient DTFT (an independent check).
The cell runs on a button because the two filters require 182 conversions in total.

```rust
//| id: signal-audio-rate-response
//| ref: signal-audio-rate-response
//| title: "Measure passed components and aliasing with sinusoids for two filters"
//| run: button
//| uses: [signal-audio-rate-model]
//| inputs:
//|   direction: {"type":"select","label":"Conversion direction","description":"Choose whether to measure interpolation images or decimation aliases.","options":["44.1 kHz → 48 kHz","48 kHz → 44.1 kHz"],"value":"48 kHz → 44.1 kHz"}
//| cases:
//|   - {"id":"upward","label":"44.1 kHz → 48 kHz","description":"Images of inputs above 20.1 kHz enter the output band.","inputs":{"direction":"44.1 kHz → 48 kHz"}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"filters","path":"/rows/0/1","equals":3201}
//|       - {"artifact":"filters","path":"/rows/1/1","equals":19201}
//|       - {"artifact":"filters","path":"/rows/1/2","range":{"max":1e-3}}
//|       - {"artifact":"filters","path":"/rows/1/6","range":{"max":1e-6}}
//|   - case: upward
//|     expect:
//|       - {"artifact":"filters","path":"/rows/1/5","range":{"max":1e-3}}
use scioxide_signal::{PolyphasePlan, ResampleAlignment};

let upward = direction == "44.1 kHz → 48 kHz";
let (input_rate, output_rate, up, down) = if upward {
    (LOW_RATE, HIGH_RATE, 160, 147)
} else {
    (HIGH_RATE, LOW_RATE, 147, 160)
};
let default_plan =
    PolyphasePlan::<f64>::rational_default(up, down, ResampleAlignment::Centered)
        .map_err(|e| e.to_string())?;
let sharp = sharp_taps(up)?;
let sharp_plan = PolyphasePlan::rational(&sharp, up, down, ResampleAlignment::Centered)
    .map_err(|e| e.to_string())?;
let mut series = vec![Vec::new(); 4];
let mut rows = Vec::new();
for (index, plan) in [&default_plan, &sharp_plan].into_iter().enumerate() {
    let taps = plan.coefficients();
    let (mut ripple, mut leak, mut model) = (0.0_f64, 0.0_f64, 0.0_f64);
    for i in 0..90 {
        let f = 0.5 * input_rate * (i as f64 + 0.5) / 90.0;
        let output = plan
            .resample(&tone(f, 1.0, input_rate)?)
            .map_err(|e| e.to_string())?;
        let alias = LOW_RATE - f;
        if f < 0.5 * output_rate && (alias - f).abs() > 500.0 {
            let gain = amplitude(&output, f, output_rate)?;
            series[index].push([f / 1000.0, gain]);
            if f <= 20_000.0 {
                ripple = ripple.max((gain - 1.0).abs());
            }
            // Independent check: coefficient DTFT |H| / L at the 7.056 MHz rate (f64 cos and sin provide reference values)
            let theta = core::f64::consts::TAU * f / (input_rate * up as f64);
            let (re, im) = taps
                .iter()
                .enumerate()
                .fold((0.0, 0.0), |(re, im), (n, h)| {
                    (
                        re + h * (theta * n as f64).cos(),
                        im - h * (theta * n as f64).sin(),
                    )
                });
            model = model.max((gain - (re * re + im * im).sqrt() / up as f64).abs());
        }
        if alias > 0.0 && alias < 0.5 * output_rate && (alias - f).abs() > 500.0 {
            let unwanted = amplitude(&output, alias, output_rate)?;
            series[index + 2].push([f / 1000.0, unwanted]);
            leak = leak.max(unwanted);
        }
    }
    let edge_tone = plan
        .resample(&tone(20_000.0, 1.0, input_rate)?)
        .map_err(|e| e.to_string())?;
    let at_edge = amplitude(&edge_tone, 20_000.0, output_rate)?;
    let name = if index == 0 {
        "Default (β = 5)"
    } else {
        "Sharp (β = 8.6)"
    };
    rows.push((
        name,
        taps.len(),
        ripple,
        at_edge,
        taps.len() as f64 / up as f64,
        leak,
        model,
    ));
}
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let fixed4 = serde_json::json!({ "fractionDigits": 4 });
let fixed1 = serde_json::json!({ "fractionDigits": 1 });
let columns = serde_json::json!([
    { "key": "0", "label": "Filter" },
    { "key": "1", "label": "Coefficient count K [-]", "type": "integer" },
    { "key": "2", "label": "Maximum |amplitude − 1| at or below 20 kHz [-]", "type": "number", "format": sci2 },
    { "key": "3", "label": "Amplitude at 20 kHz [-]", "type": "number", "format": fixed4 },
    { "key": "4", "label": "Products per output K/L [count]", "type": "number", "format": fixed1 },
    { "key": "5", "label": "Maximum unwanted component [-]", "type": "number", "format": sci2 },
    { "key": "6", "label": "Maximum difference from DTFT [-]", "type": "number", "format": sci2 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "filters" })
);
let names = [
    "Passed component (default)",
    "Passed component (sharp)",
    "Unwanted component (default)",
    "Unwanted component (sharp)",
];
emit_line_chart!(
    &names
        .iter()
        .zip(&series)
        .map(|(name, points)| {
            serde_json::json!({
                "name": name,
                "points": points,
                "style": { "symbol": "circle" }
            })
        })
        .collect::<Vec<_>>(),
    options = &serde_json::json!({
        "xLabel": "Input frequency f [kHz]",
        "yLabel": "Output amplitude [-]",
        "yType": "log",
        "xMin": 0.0,
        "xMax": 0.5 * input_rate / 1000.0,
        "annotations": [
            { "kind": "line", "axis": "x", "value": 20.0, "label": "20 kHz" },
            { "kind": "line", "axis": "x", "value": 22.05, "label": "22.05 kHz" }
        ]
    })
);
```

In the default conversion from 48 kHz to 44.1 kHz, the default filter's passed amplitude remains close to 1 up to 18.3 kHz, but drops to 0.950 at 19.6 kHz and 0.909 ($-0.83$ dB) at 20 kHz.
The 22.53 kHz input aliases to 21.57 kHz with amplitude 0.38, the largest unwanted component.
The sharp filter has an amplitude deviation of $2.1 \times 10^{-5}$ at or below 20 kHz and suppresses the unwanted component to a maximum of $3.3 \times 10^{-5}$ (about $-90$ dB).
This increases the products per output sample from 21.8 to 130.6.
For both filters, the measured passed amplitude differs from the coefficient DTFT by at most $2.7 \times 10^{-6}$, confirming the amplitude measurement method.
For conversion from 44.1 kHz to 48 kHz, images of inputs from 20.2 kHz to 21.7 kHz appear from 22.4 kHz to 23.9 kHz, reaching amplitudes of 0.12 to 0.41 with the default filter.
The sharp filter also keeps these images at or below $2.3 \times 10^{-5}$.

## Round-trip error and Fourier resampling

The next cell converts a 0.1 s record at 44.1 kHz (4410 samples) to 48 kHz (4800 samples), then back to 44.1 kHz.
The record sums four sinusoids of amplitude 0.25, at 1, 5, and 10 kHz and an input-selected frequency $f_{\max}$.
The three methods are the default `resample`, `PolyphasePlan::rational` with the sharp filter, and `resample_periodic` (4410 → 4800 → 4410), which treats the record as one period.
Compare the intermediate 48 kHz result with the true values obtained by evaluating the same sinusoidal sum at 48 kHz sample times, and compare the round-trip record with the original.
Report maximum errors over the interior excluding 10 ms at each end, and over the full record.
When all frequencies are multiples of 10 Hz, the 0.1 s record contains an integer number of periods and is periodic.
Shifting the frequencies by 3 Hz makes the record nonperiodic, violating the Fourier-resampling assumption that the record is one period.

```rust
//| id: signal-audio-rate-round-trip
//| ref: signal-audio-rate-round-trip
//| title: "Compare three methods for a round trip between 44.1 kHz and 48 kHz"
//| run: button
//| uses: [signal-audio-rate-model]
//| inputs:
//|   top: {"type":"range","label":"Highest component f_max [kHz]","description":"Moving closer to the passband edge increases polyphase-filter error.","min":12,"max":21,"step":0.5,"value":15}
//|   shifted: {"type":"checkbox","label":"Shift frequencies by 3 Hz (nonperiodic record)","description":"The 0.1 s record no longer contains an integer number of periods.","value":false}
//| cases:
//|   - {"id":"shifted","label":"Shift by 3 Hz","description":"The 48 kHz values from resample_periodic develop errors at the ends.","inputs":{"shifted":true}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"round-trip","path":"/rows/2/2","range":{"max":1e-12}}
//|       - {"artifact":"round-trip","path":"/rows/2/4","range":{"max":1e-12}}
//|   - case: shifted
//|     expect:
//|       - {"artifact":"round-trip","path":"/rows/2/2","range":{"min":1e-3}}
use scioxide_signal::{PolyphasePlan, ResampleAlignment, resample, resample_periodic};

let offset = if shifted { 3.0 } else { 0.0 };
let frequencies = [1000.0, 5000.0, 10_000.0, 1000.0 * top].map(|f| f + offset);
let mixture = |rate: f64| -> Result<Vec<f64>, String> {
    let mut total = tone(frequencies[0], 0.25, rate)?;
    for &f in &frequencies[1..] {
        total
            .iter_mut()
            .zip(tone(f, 0.25, rate)?)
            .for_each(|(t, v)| *t += v);
    }
    Ok(total)
};
let original = mixture(LOW_RATE)?;
// True values evaluated at 48 kHz sample times (independent reference)
let truth = mixture(HIGH_RATE)?;
let upward = PolyphasePlan::rational(&sharp_taps(160)?, 160, 147, ResampleAlignment::Centered)
    .map_err(|e| e.to_string())?;
let downward =
    PolyphasePlan::rational(&sharp_taps(147)?, 147, 160, ResampleAlignment::Centered)
        .map_err(|e| e.to_string())?;

let default_mid = resample(&original, 160, 147).map_err(|e| e.to_string())?;
let default_back = resample(&default_mid, 147, 160).map_err(|e| e.to_string())?;
let sharp_mid = upward.resample(&original).map_err(|e| e.to_string())?;
let sharp_back = downward.resample(&sharp_mid).map_err(|e| e.to_string())?;
let fourier_mid = resample_periodic(&original, truth.len()).map_err(|e| e.to_string())?;
let fourier_back =
    resample_periodic(&fourier_mid, original.len()).map_err(|e| e.to_string())?;

// Maximum errors over the interior excluding 10 ms at each end, and over the full record
let errors = |values: &[f64], reference: &[f64], rate: f64| {
    let margin = (0.01 * rate) as usize;
    let (mut inner, mut all) = (0.0_f64, 0.0_f64);
    for (j, (v, r)) in values.iter().zip(reference).enumerate() {
        let e = (v - r).abs();
        all = all.max(e);
        if j >= margin && j + margin < reference.len() {
            inner = inner.max(e);
        }
    }
    (inner, all)
};
let rows: Vec<(&str, f64, f64, f64, f64)> = [
    ("resample (default)", &default_mid, &default_back),
    ("PolyphasePlan::rational (sharp)", &sharp_mid, &sharp_back),
    ("resample_periodic", &fourier_mid, &fourier_back),
]
.into_iter()
.map(|(name, mid, back)| {
    let (mid_inner, mid_all) = errors(mid, &truth, HIGH_RATE);
    let (back_inner, back_all) = errors(back, &original, LOW_RATE);
    (name, mid_inner, mid_all, back_inner, back_all)
})
.collect();
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let columns = serde_json::json!([
    { "key": "0", "label": "Method" },
    { "key": "1", "label": "48 kHz error (interior) [-]", "type": "number", "format": sci2 },
    { "key": "2", "label": "48 kHz error (full record) [-]", "type": "number", "format": sci2 },
    { "key": "3", "label": "Round-trip error (interior) [-]", "type": "number", "format": sci2 },
    { "key": "4", "label": "Round-trip error (full record) [-]", "type": "number", "format": sci2 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "round-trip" })
);
emit_text!(format!(
    "Record length: {} samples at 44.1 kHz, {} samples at 48 kHz (resample output: {} samples)",
    original.len(),
    truth.len(),
    default_mid.len()
));
```

At the default $f_{\max} = 15$ kHz, all frequencies are multiples of 10 Hz; the full-record error of the 48 kHz values from `resample_periodic` is $7.3 \times 10^{-13}$, and the round-trip error is $9.4 \times 10^{-16}$.
The interior 48 kHz errors of the polyphase FIR methods are $1.0 \times 10^{-3}$ for the default filter and $8.1 \times 10^{-6}$ for the sharp filter; round-trip errors are about twice as large, $2.1 \times 10^{-3}$ and $1.8 \times 10^{-5}$ respectively.
Full-record errors range from 0.02 to 0.04 and are dominated by endpoint transients from treating values outside the record as 0.
The sharp filter has a longer coefficient sequence, so the endpoint effects also last longer.
After shifting frequencies by 3 Hz, the 48 kHz values from `resample_periodic` deviate by $6.8 \times 10^{-4}$ in the interior and $0.093$ over the full record, while the round-trip error remains $1.1 \times 10^{-15}$.
A Fourier-resampling round trip zero-pads and truncates the DFT, so it always returns to the original record, but the intermediate 48 kHz values are not necessarily correct.
At $f_{\max} = 21$ kHz, the highest component enters the transition band of both filters, giving interior errors of 0.13 for the default filter and 0.12 for the sharp filter.

## Summary

Conversion between 44.1 kHz and 48 kHz has the irreducible ratio 160/147; in either direction, error is determined by low-pass filtering the 7.056 MHz sequence with a 22.05 kHz cutoff.
The default `resample` requires only about 20 products per output, but reduces amplitudes near 20 kHz and does not sufficiently suppress aliases of components just above 22.05 kHz.
To preserve the audio band up to 20 kHz and strongly suppress aliasing, design coefficients with `design_fir_window` and pass them to `PolyphasePlan::rational`, accepting the increased computation.
`resample_periodic` is accurate to rounding error when the record contains an integer number of periods, but produces endpoint errors for general audio records; use polyphase FIR for conversion during editing.
