An RLC circuit with resistance $R$, inductance $L$, and capacitance $C$ connected in series is a standard second-order LTI system.
With supply voltage as input and capacitor voltage as output, the circuit acts as a low-pass filter whose resonance peak becomes sharper as resistance decreases.
This example represents the circuit in state space, obtains Bode plots and a resonance peak from the frequency response and step-response overshoot from the time response, and compares both with closed forms.
Finally, choose a sampling rate, discretize with zero-order hold and the Tustin transform, and compare errors at sample points.
See [State-space models and LTI systems](../../algorithms/lti-systems/) for a general explanation of state-space models and discretization.

## Circuit equations and state-space model

Let current be $i(t)$ [A], capacitor voltage $v_C(t)$ [V], and supply voltage $u(t)$ [V].
Kirchhoff's voltage law and the capacitor relation $i = C\,dv_C/dt$ give

$$
L \frac{di}{dt} = u - R i - v_C, \qquad C \frac{dv_C}{dt} = i
$$


Ordering the state as $x = (i, v_C)$ and output as $y = (v_C, i)$ gives the state-space model

$$
A = \begin{bmatrix} -R/L & -1/L \\ 1/C & 0 \end{bmatrix}, \quad
B = \begin{bmatrix} 1/L \\ 0 \end{bmatrix}, \quad
C_{\mathrm{out}} = \begin{bmatrix} 0 & 1 \\ 1 & 0 \end{bmatrix}, \quad
D = \begin{bmatrix} 0 \\ 0 \end{bmatrix}
$$

Write the output matrix as $C_{\mathrm{out}}$ to distinguish it from capacitance $C$.
Time is measured in seconds and angular frequency in rad/s.

The natural angular frequency and damping ratio are

$$
\omega_0 = \frac{1}{\sqrt{LC}}, \qquad \zeta = \frac{R}{2}\sqrt{\frac{C}{L}}
$$

and the transfer function to capacitor voltage is

$$
H(s) = \frac{V_C(s)}{U(s)} = \frac{\omega_0^2}{s^2 + 2\zeta\omega_0 s + \omega_0^2}
$$


The transfer function to current (admittance) is $Y(s) = Cs\,H(s)$, giving $Y = 1/R$ at $s = i\omega_0$.
This example fixes $L = 10$ mH and $C = 1$ μF, giving $\omega_0 = 10^4$ rad/s ($f_0 \approx 1.59$ kHz).
Choose resistance $R$ from 2–180 Ω, giving $\zeta = R/200$ from 0.01 to 0.9.

## Closed forms for resonance and transient response

Substituting $s = i\omega$ gives the amplitude

$$
|H(i\omega)| = \frac{1}{\sqrt{(1 - \Omega^2)^2 + (2\zeta\Omega)^2}}, \qquad \Omega = \omega / \omega_0
$$


At $\omega = \omega_0$, $|H| = 1/(2\zeta)$ and the phase is $-90°$.
For $\zeta < 1/\sqrt{2}$, amplitude reaches its maximum $1/(2\zeta\sqrt{1 - \zeta^2})$ at $\omega_r = \omega_0\sqrt{1 - 2\zeta^2}$.
For $\zeta \ge 1/\sqrt{2}$ there is no peak, and amplitude decreases monotonically from its DC value of 1.

Applying a 1 V voltage step from the zero state gives, for $0 < \zeta < 1$,

$$
\begin{aligned}
v_C(t) &= 1 - e^{-\zeta\omega_0 t} \left( \cos\omega_d t + \frac{\zeta}{\sqrt{1 - \zeta^2}} \sin\omega_d t \right), \\
i(t) &= \frac{C\omega_0}{\sqrt{1 - \zeta^2}}\, e^{-\zeta\omega_0 t} \sin\omega_d t, \qquad \omega_d = \omega_0\sqrt{1 - \zeta^2}
\end{aligned}
$$


$v_C$ reaches its maximum at $t_p = \pi/\omega_d$, with overshoot $e^{-\pi\zeta/\sqrt{1 - \zeta^2}}$ V above the final value of 1 V.

The following block defines the model shared by the two cells.
`rlc_model` constructs the state-space model above; `natural_frequency` and `damping_ratio` give $\omega_0$ and $\zeta$; `step_voltage` and `step_current` give the closed-form step responses.
The closed forms are reference values for checks, computed with `f64` standard functions.

```rust
//| id: signal-rlc-model
//| kind: definitions
//| title: "Series RLC state-space model and closed-form step responses"
//| crates: [scioxide-core, scioxide-linalg, scioxide-signal]
use scioxide_core::SciOxideError;
use scioxide_linalg::Matrix;
use scioxide_signal::{LtiTime, StateSpace};

/// Inductance L [H] and capacitance C [F].
pub(crate) const INDUCTANCE: f64 = 10.0e-3;
pub(crate) const CAPACITANCE: f64 = 1.0e-6;

/// Continuous system with state (i, v_C), input u, and output (v_C, i).
pub(crate) fn rlc_model(resistance: f64) -> Result<StateSpace<f64>, SciOxideError> {
    let (l, c) = (INDUCTANCE, CAPACITANCE);
    let a = Matrix::from_vec(2, 2, vec![-resistance / l, -1.0 / l, 1.0 / c, 0.0])?;
    let b = Matrix::from_vec(2, 1, vec![1.0 / l, 0.0])?;
    let output = Matrix::from_vec(2, 2, vec![0.0, 1.0, 1.0, 0.0])?;
    let d = Matrix::zeros(2, 1)?;
    StateSpace::new(
        LtiTime::Continuous,
        a.view(),
        b.view(),
        output.view(),
        d.view(),
    )
}

/// Natural angular frequency ω₀ = 1/√(LC) [rad/s].
pub(crate) fn natural_frequency() -> f64 {
    1.0 / (INDUCTANCE * CAPACITANCE).sqrt()
}

/// Damping ratio ζ = (R/2)√(C/L) [-].
pub(crate) fn damping_ratio(resistance: f64) -> f64 {
    0.5 * resistance * (CAPACITANCE / INDUCTANCE).sqrt()
}

/// Capacitor voltage v_C(t) [V] for a 1 V step (0 < ζ < 1). Reference value.
pub(crate) fn step_voltage(resistance: f64, time: f64) -> f64 {
    let (w0, z) = (natural_frequency(), damping_ratio(resistance));
    let root = (1.0 - z * z).sqrt();
    let phase = w0 * root * time;
    1.0 - (-z * w0 * time).exp() * (phase.cos() + z / root * phase.sin())
}

/// Current i(t) [A] for a 1 V step (0 < ζ < 1). Reference value.
pub(crate) fn step_current(resistance: f64, time: f64) -> f64 {
    let (w0, z) = (natural_frequency(), damping_ratio(resistance));
    let root = (1.0 - z * z).sqrt();
    CAPACITANCE * w0 / root * (-z * w0 * time).exp() * (w0 * root * time).sin()
}
```

## Bode plots and resonance peak

The next cell selects resistance $R$ and computes `frequency_response` on a 400-point logarithmic grid from $10^2$ to $10^6$ rad/s.
Returned values are ordered as `[frequency][output][input]`; outputs are $v_C$ then $i$, so at frequency $k$, $H$ is at index $2k$ and $Y$ at $2k + 1$.
The upper chart plots amplitude $|H|$ on logarithmic axes and the lower chart plots phase $\arg H$ [°], both with dashed closed-form references.
The angular-frequency axes of the two charts are linked.
The table compares values evaluated at $\omega_0$ and $\omega_r$ with closed forms and reports the maximum relative error over the full grid.
This cell also passes $R$ to the next cell.

```rust
//| id: signal-rlc-bode
//| ref: signal-rlc-bode
//| title: "Bode plots and resonance peak of a series RLC circuit"
//| run: reactive
//| uses: [signal-rlc-model]
//| crates: [scioxide-core, scioxide-linalg, scioxide-signal]
//| exports: [resistance]
//| inputs:
//|   resistance: {"type":"range","label":"Resistance R [Ω]","description":"Change the damping ratio ζ = R/200.","min":2,"max":180,"step":2,"value":20}
//| cases:
//|   - {"id":"overdamped-peak","label":"R = 160 Ω","description":"The resonance peak disappears at ζ = 0.8 > 1/√2.","inputs":{"resistance":160}}
//|   - {"id":"sharp","label":"R = 2 Ω","description":"At ζ = 0.01, the peak gain becomes about 50.","inputs":{"resistance":2}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"resonance","path":"/rows/0/1","approx":{"value":5.0,"rtol":1e-12}}
//|       - {"artifact":"resonance","path":"/rows/0/3","range":{"max":1e-12}}
//|       - {"artifact":"resonance","path":"/rows/2/3","range":{"max":1e-12}}
//|       - {"artifact":"resonance","path":"/rows/3/3","range":{"max":1e-12}}
//|       - {"artifact":"resonance","path":"/rows/4/1","range":{"max":1e-12}}
//|   - case: overdamped-peak
//|     expect:
//|       - {"artifact":"resonance","path":"/rows/3/1","equals":null}
//|   - case: sharp
//|     expect:
//|       - {"artifact":"resonance","path":"/rows/0/1","approx":{"value":50.0,"rtol":1e-10}}
use scioxide_core::Complex;

let sig6 = serde_json::json!({ "significantDigits": 6 });
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let model = rlc_model(resistance).map_err(|e| e.to_string())?;
let (w0, z) = (natural_frequency(), damping_ratio(resistance));
// Closed form H(iω) = ω₀² / (ω₀² − ω² + 2iζω₀ω) (reference).
let exact = |w: f64| {
    let denominator = Complex::new(w0 * w0 - w * w, 2.0 * z * w0 * w);
    Complex::new(w0 * w0, 0.0) / denominator
};

let omegas: Vec<f64> = (0..400)
    .map(|k| 10.0_f64.powf(2.0 + 4.0 * k as f64 / 399.0))
    .collect();
let response = model
    .frequency_response(&omegas)
    .map_err(|e| e.to_string())?;
let values = response.values();
let grid_error = omegas
    .iter()
    .enumerate()
    .map(|(k, &w)| (values[2 * k] - exact(w)).norm() / exact(w).norm())
    .fold(0.0, f64::max);

// Evaluate at ω₀ and, if a peak exists, at ω_r = ω₀√(1 − 2ζ²).
let peak = (z * z < 0.5).then(|| w0 * (1.0 - 2.0 * z * z).sqrt());
let mut points = vec![w0];
points.extend(peak);
let special = model
    .frequency_response(&points)
    .map_err(|e| e.to_string())?;
let at = special.values();
let relative = |a: f64, b: f64| (a - b).abs() / b.abs();
let peak_value = peak.map(|_| at[2].norm());
let peak_exact = 1.0 / (2.0 * z * (1.0 - z * z).sqrt());
let rows = vec![
    (
        "|H(iω₀)| [V/V]",
        Some(at[0].norm()),
        Some(1.0 / (2.0 * z)),
        Some(relative(at[0].norm(), 0.5 / z)),
    ),
    (
        "arg H(iω₀) [°]",
        Some(at[0].arg().to_degrees()),
        Some(-90.0),
        Some(relative(at[0].arg().to_degrees(), -90.0)),
    ),
    (
        "|Y(iω₀)| [S]",
        Some(at[1].norm()),
        Some(1.0 / resistance),
        Some(relative(at[1].norm(), 1.0 / resistance)),
    ),
    (
        "|H(iω_r)| (peak height) [V/V]",
        peak_value,
        peak.map(|_| peak_exact),
        peak_value.map(|v| relative(v, peak_exact)),
    ),
    (
        "Maximum relative error in H over the grid [-]",
        Some(grid_error),
        None,
        None,
    ),
];
let columns = serde_json::json!([
    { "key": "0", "label": "Quantity" },
    { "key": "1", "label": "Computed value", "type": "number", "format": sig6, "nullText": "No peak" },
    { "key": "2", "label": "Closed form", "type": "number", "format": sig6, "nullText": "—" },
    { "key": "3", "label": "Relative difference [-]", "type": "number", "format": sci3, "nullText": "—" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "resonance" })
);

let series = |f: &dyn Fn(Complex<f64>) -> f64| -> (Vec<[f64; 2]>, Vec<[f64; 2]>) {
    let computed = omegas
        .iter()
        .enumerate()
        .map(|(k, &w)| [w, f(values[2 * k])])
        .collect();
    let reference = omegas.iter().map(|&w| [w, f(exact(w))]).collect();
    (computed, reference)
};
let (magnitude, magnitude_exact) = series(&|h| h.norm());
let (phase, phase_exact) = series(&|h| h.arg().to_degrees());
let resonance_line = serde_json::json!([{
    "kind": "line",
    "axis": "x",
    "value": w0,
    "label": "ω₀",
    "style": { "lineType": "dotted" }
}]);
let dashed = serde_json::json!({ "lineType": "dashed", "showSymbol": false });
emit_line_chart!(
    &vec![
        serde_json::json!({ "name": "frequency_response", "points": magnitude }),
        serde_json::json!({ "name": "Closed form", "points": magnitude_exact, "style": dashed }),
    ],
    options = &serde_json::json!({
        "link": { "group": "rlc-omega" },
        "xLabel": "Angular frequency ω [rad/s]",
        "yLabel": "Amplitude |H| [V/V]",
        "xType": "log",
        "yType": "log",
        "annotations": resonance_line
    })
);
emit_line_chart!(
    &vec![
        serde_json::json!({ "name": "frequency_response", "points": phase }),
        serde_json::json!({ "name": "Closed form", "points": phase_exact, "style": dashed }),
    ],
    options = &serde_json::json!({
        "link": { "group": "rlc-omega" },
        "xLabel": "Angular frequency ω [rad/s]",
        "yLabel": "Phase arg H [°]",
        "xType": "log",
        "yMin": -180.0,
        "yMax": 0.0,
        "annotations": resonance_line
    })
);
export!(resistance, resistance);
```

At the default $R = 20$ Ω ($\zeta = 0.1$), $|H(i\omega_0)|$ agrees with the closed-form $1/(2\zeta) = 5$ without rounding error, and the phase has relative difference $6.3 \times 10^{-16}$ from $-90°$.
The admittance magnitude $|Y(i\omega_0)|$ also agrees with $1/R = 0.05$ S, confirming the output ordering ($v_C$ then $i$).
The peak height is 5.0252 at $\omega_r \approx$ 9899.5 rad/s, with relative difference $1.8 \times 10^{-16}$ from the closed form.
The maximum relative error over the grid is $1.3 \times 10^{-15}$, so evaluation using Hessenberg form remains at the rounding-error level even near resonance.
In the chart, amplitude is 1 for $\omega \ll \omega_0$ and decreases along $(\omega_0/\omega)^2$ as a straight line of slope $-2$ for $\omega \gg \omega_0$, while phase moves from $0°$ to $-180°$.

In the “R = 160 Ω” case, $\zeta = 0.8 > 1/\sqrt{2}$ and the peak row shows “No peak”.
In the “R = 2 Ω” case, $|H(i\omega_0)| = 50$ and phase drops rapidly toward $-180°$ near $\omega_0$.
As resistance decreases, resonance sharpens and the bandwidth over which amplitude is at least $1/\sqrt{2}$ of the peak shrinks to about $2\zeta\omega_0$.

## Step response and discretization error

The next cell receives $R$ from the previous cell and computes the response to a 1 V step from zero state in three ways.

1. Compute the continuous-system `step_response` on a grid with 1 μs spacing.
   The plan constructs the zero-order-hold transition for the step once and advances with it, so values at sample points are exact for constant input apart from rounding error.
2. Compute `step_response` for the discrete system obtained by zero-order-hold discretization at sampling rate $f_s$.
3. Compute `step_response` for the discrete system obtained by Tustin-transform discretization ($\alpha = 1/2$) at the same $f_s$.

Set discrete-grid spacing to $1/f_s$, matching the discretization sample period.
The table shows maximum errors against the closed forms for $v_C$ [V] and $i$ [mA], and compares overshoot and peak time read from the continuous-system grid with closed forms.
The chart overlays the two discrete systems' samples on the closed-form $v_C$ (dashed).

```rust
//| id: signal-rlc-step
//| ref: signal-rlc-step
//| title: "Step response and discretization error of a series RLC circuit"
//| run: reactive
//| uses: [signal-rlc-model]
//| dependsOn:
//|   bode: signal-rlc-bode
//| crates: [scioxide-core, scioxide-linalg, scioxide-signal]
//| inputs:
//|   sample_rate_khz: {"type":"range","label":"Sampling rate f_s [kHz]","description":"Change the discretization sample period 1/f_s.","min":5,"max":100,"step":5,"value":20}
//| cases:
//|   - {"id":"fast-sampling","label":"f_s = 100 kHz","description":"Faster sampling reduces Tustin-transform error.","inputs":{"sample_rate_khz":100}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"step","path":"/rows/0/1","range":{"max":1e-12}}
//|       - {"artifact":"step","path":"/rows/1/1","range":{"max":1e-12}}
//|       - {"artifact":"step","path":"/rows/2/1","range":{"min":1e-3}}
//|       - {"artifact":"overshoot","path":"/rows/0/3","range":{"max":1e-5}}
//|   - case: fast-sampling
//|     expect:
//|       - {"artifact":"step","path":"/rows/1/1","range":{"max":1e-12}}
use scioxide_signal::DiscretizationMethod;

let sig6 = serde_json::json!({ "significantDigits": 6 });
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let resistance = bode["resistance"].as_f64().ok_or("Cannot receive resistance R")?;
let model = rlc_model(resistance).map_err(|e| e.to_string())?;
let horizon = 5.0e-3;

// values() is ordered [sample][output][input], with outputs v_C then i.
let max_errors = |times: &[f64], values: &[f64]| {
    times
        .iter()
        .enumerate()
        .fold((0.0_f64, 0.0_f64), |(ev, ei), (k, &t)| {
            let dv = (values[2 * k] - step_voltage(resistance, t)).abs();
            let di = (values[2 * k + 1] - step_current(resistance, t)).abs() * 1.0e3;
            (ev.max(dv), ei.max(di))
        })
};

let fine_step = 1.0e-6;
let fine: Vec<f64> = (0..=5000).map(|k| k as f64 * fine_step).collect();
let continuous = model.step_response(&fine).map_err(|e| e.to_string())?;
let mut rows = vec![(
    "Continuous system (1 μs spacing)",
    max_errors(&fine, continuous.values()),
)];

let h = 1.0e-3 / sample_rate_khz;
let steps = (horizon / h).round() as usize;
let grid: Vec<f64> = (0..=steps).map(|k| k as f64 * h).collect();
let mut chart = Vec::new();
for (name, method) in [
    ("Zero-order hold", DiscretizationMethod::ZeroOrderHold),
    (
        "Tustin transform",
        DiscretizationMethod::GeneralizedBilinear { alpha: 0.5 },
    ),
] {
    let response = model
        .discretize(h, method)
        .and_then(|discrete| discrete.step_response(&grid))
        .map_err(|e| e.to_string())?;
    rows.push((name, max_errors(&grid, response.values())));
    let points: Vec<[f64; 2]> = grid
        .iter()
        .enumerate()
        .map(|(k, &t)| [t * 1.0e3, response.values()[2 * k]])
        .collect();
    chart.push(
        serde_json::json!({ "name": name, "points": points, "style": { "symbol": "circle" } }),
    );
}
let rows: Vec<(&str, f64, f64)> = rows.into_iter().map(|(n, (v, i))| (n, v, i)).collect();
let columns = serde_json::json!([
    { "key": "0", "label": "Method" },
    { "key": "1", "label": "Maximum v_C error [V]", "type": "number", "format": sci3 },
    { "key": "2", "label": "Maximum i error [mA]", "type": "number", "format": sci3 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "step" })
);

// Overshoot: compare the continuous-grid maximum and its time with the closed form.
let (peak_index, peak_voltage) =
    continuous
        .values()
        .iter()
        .step_by(2)
        .enumerate()
        .fold(
            (0, f64::MIN),
            |best, (k, &v)| if v > best.1 { (k, v) } else { best },
        );
let (w0, z) = (natural_frequency(), damping_ratio(resistance));
let root = (1.0 - z * z).sqrt();
let overshoot = (-std::f64::consts::PI * z / root).exp();
let peak_time = std::f64::consts::PI / (w0 * root);
let overshoot_columns = serde_json::json!([
    { "key": "0", "label": "Overshoot (grid) [V]", "type": "number", "format": sig6 },
    { "key": "1", "label": "Overshoot (closed form) [V]", "type": "number", "format": sig6 },
    { "key": "2", "label": "Peak time (grid) [ms]", "type": "number", "format": sig6 },
    { "key": "3", "label": "Relative overshoot difference [-]", "type": "number", "format": sci3 }
]);
emit_table_with_columns!(
    overshoot_columns,
    vec![(
        peak_voltage - 1.0,
        overshoot,
        fine[peak_index] * 1.0e3,
        (peak_voltage - 1.0 - overshoot).abs() / overshoot,
    )],
    metadata = serde_json::json!({ "id": "overshoot" })
);
emit_text!(&format!(
    "Closed-form peak time t_p = π/ω_d = {:.4} ms",
    peak_time * 1.0e3
));

let reference: Vec<[f64; 2]> = fine
    .iter()
    .step_by(10)
    .map(|&t| [t * 1.0e3, step_voltage(resistance, t)])
    .collect();
chart.push(serde_json::json!({
    "name": "Closed form",
    "points": reference,
    "style": { "lineType": "dashed", "showSymbol": false }
}));
emit_line_chart!(
    &chart,
    options = &serde_json::json!({
        "xLabel": "Time t [ms]",
        "yLabel": "Capacitor voltage v_C [V]",
        "yMin": 0.0,
        "yMax": 2.0
    })
);
```

At the defaults ($R = 20$ Ω, $f_s = 20$ kHz), the continuous-system response at 1 μs spacing agrees with the closed form to differences of $4.7 \times 10^{-14}$ V for $v_C$ and $5.7 \times 10^{-13}$ mA for $i$.
The zero-order-hold discrete system also differs by only $8.9 \times 10^{-16}$ V and is exact at sample points for a step input.
The Tustin-transform error is 0.186 V, with a delay caused by treating the step jump as a slope between samples ([Discretization error and stability](oxref:signal-lti-discretization-error)).
Overshoot is 0.729245 V on the grid and 0.729248 V in closed form, with relative difference $3.3 \times 10^{-6}$, within the effect of the peak-location offset from the 1 μs grid spacing.
The peak time is 0.316 ms on the grid and $\pi/\omega_d \approx 0.3157$ ms in closed form.

In the “f_s = 100 kHz” case, Tustin-transform error decreases to 0.042 V.
Reducing the sample period to 1/5 reduces error to about 1/4.4, approximately proportional to the sample period.
Because zero-order hold is exact regardless of sampling rate, choose it for digital-control simulations with step or piecewise-constant inputs.
For filter designs that preserve frequency-response shape, choose the Tustin transform with prewarping.

## Summary

A series RLC circuit is represented by a second-order state-space model with state $(i, v_C)$; both frequency and time responses agree with closed forms at the rounding-error level.
Values from `frequency_response` are ordered as `[frequency][output][input]`, so establish the output order before interpreting indices.
Both resonance peak height $1/(2\zeta\sqrt{1 - \zeta^2})$ and overshoot $e^{-\pi\zeta/\sqrt{1 - \zeta^2}}$ are determined by damping ratio $\zeta = (R/2)\sqrt{C/L}$.
For discretization with a step input, zero-order hold is exact, while the Tustin transform has error proportional to the sample period.
See [State-space models and LTI pole placement](oxref:signal-pole-placement) for moving poles by state feedback, and [IIR filter design](../../algorithms/iir-design/) for design as an IIR filter.
