These tables collect items for direct sparse matrix solvers.
LU, Cholesky/LDL, and QR each have immutable symbolic analysis (`*Symbolic` such as `SparseLuSymbolic`), numerical factors owning that analysis, refactorization workspace types, and limit (`*Limits`) and requirement (`*Requirements`) types.

One-shot functions `solve` and `least_squares` and preparation constructors such as `SparseLu::new(&a)` take no limits and perform symbolic analysis in AMD order followed by numerical factorization.
The entry limit starts from an estimate and doubles on each `ResourceLimit` (for Cholesky, it is exactly the fill predicted by analysis); no byte limit is imposed.
The standard form `factor(symbolic, matrix)` factors with default `SparseSolveOptions` and `ExecutionContext::sequential_native()`, while the scoped API `factor_scoped(symbolic, matrix, options, scope)` uses caller-supplied options and scope; both allocate factors and temporary workspace.

Refactorization `refactor` accepts only matrices with the same structure as the analysis (including stored zeros), constructs a candidate in preallocated workspace, then swaps it in.
`refactor` allocates nothing, and failure leaves the last successful factors (including permutations and values) usable.
Numerical factorization is sequential; LU and QR count one iteration per column, and Cholesky and LDL one per row.
Exceeding limits returns `ResourceLimit`; reaching the iteration limit in options or scope returns `ConvergenceFailure` (`IterationLimit`).

Triangular-system, LU, Cholesky, and LDL factors implement `LinearOperator`, `AdjointOperator`, and `BlockOperator` as actions of $\mathbf{A}^{-1}$, so they can be passed to iterative solvers.
These implementations use default options and do not count iterations.
`SparseQr` does not implement operator traits; solve equations with `SparseQrMinimumNormPlan`.

## Hermitian pivot blocks and inertia

The [`backend::hermitian`](https://docs.rs/scioxide-sparse/0.1.0/scioxide_sparse/backend/hermitian/index.html) module provides three functions computing the determinant, eigenvalues, and linear-system solution of the $2 \times 2$ block $\begin{pmatrix} a & \bar{b} \\ b & c \end{pmatrix}$ ($a$ and $c$ real) shared by dense and sparse LDL factorizations.
All three accept blocks with finite entries and real diagonals and compute intermediate values as extended-range `Scaled` with a separate exponent, avoiding overflow and underflow.
Results also use extended-range values; the caller chooses when to round to the scalar type.
All use constant work and memory and allocate nothing.
Inertia `LdlInertia` and pivot blocks `LdlPivotBlock` are at the crate root.
