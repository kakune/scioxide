These tables collect structure-based sparse matrix ordering and coloring items and graph algorithms.
Ordering, coloring, and structural transpose accept `scioxide_core::StructuralPatternView` without reading values.
In graphs constructed from matrices or structures, stored entries (including zeros) become edges.
Only maximum flow constructs its network from a sequence of capacitated edges `CapacityEdge`.
Weights and costs are finite, so infinite distances, degrees, or weight sums return overflow as `NumericalInstability` (`Overflow`).

One-shot functions (`shortest_paths`, `connected_components`, `maximum_flow`, `maximum_bipartite_matching`, `minimum_cost_assignment`, `laplacian`) return answers from problem data.
Among these, `shortest_paths` returns a reachable negative cycle and `minimum_cost_assignment` returns absence of a complete assignment as `DomainError`.
Plan (`GraphPlan`, `MaxFlowPlan`, `AssignmentPlan`) methods return the same situations as values of `PathOutcome::NegativeCycle` and `AssignmentOutcome::Infeasible`.
Bipartite matching has no Plan; its workspace type supplies requirements.

After preparing a Plan once, preallocated workspace permits repeated allocation-free solves.
Standard Plan forms (`shortest_paths`, `maximum_flow`, `solve`) use unlimited default `GraphExecutionOptions` and new workspace, executing with `ExecutionContext::sequential_native()`.
Scoped APIs (`shortest_paths_scoped`, `maximum_flow_scoped`, `solve_scoped`, `maximum_bipartite_matching_scoped`) accept options, workspace, and a root or child scope and compute within preallocated workspace without allocation.
Insufficient workspace is rejected with `DimensionMismatch` without growing it; reaching an iteration limit gives `ConvergenceFailure`, while cancellation or deadline expiry gives `ExecutionStopped`.
Results borrow the workspace; failure does not commit partial results to output.
Read the last attempt's success or failure and counted iterations through workspace `last_attempt()`.
Traversal, connected components, and spanning forests have fixed work and take no scope.
