These tables collect items for sparse assembly and canonical finalization, format conversion, arithmetic, and products.
All stored values are finite; nonfinite values are rejected as `NonFinite` at insertion or construction.

A finalized matrix's structure (positions storing values) does not change when values are updated.
COO, CSR, and CSC allow value-only updates with `set_value`, `copy_values_from`, and `update_values`; only CSR also allows full structural replacement with `try_assign_pattern` (all values become 0).
BSR and DIA have no value-update methods.

Matrix-vector products, arithmetic, and sparse products default to `scioxide_core::Accuracy::Standard` (ordinary floating-point arithmetic rescaled to avoid overflow).
Selecting `Exact` accumulates each sum exactly and rounds once.
Operations writing output do so only after checks and computation finish, leaving output and matrices unchanged on failure.
