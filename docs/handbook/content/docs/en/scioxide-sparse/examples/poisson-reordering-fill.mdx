Finite-difference discretization of the Poisson equation $-\nabla^2 u = f$ for two-dimensional steady heat conduction or electrostatics gives a sparse symmetric positive definite matrix with $N$ unknowns.
Memory and work for Cholesky solution depend on factor fill rather than the matrix's nonzero count, and fill varies greatly with the numbering of unknowns.
This example reorders and factors the five-point Laplacian on an $n \times n$ grid using three orderings and compares bandwidth, envelope, factor nonzeros, and operation counts.
Independent checks use the envelope-theorem inequality, the closed form of natural-order fill, and a linear system with a known exact solution.

The periodic-boundary version of the same equation is solved with FFTs in [Spectral solution of the two-dimensional periodic Poisson equation](../../../scioxide-fft/examples/spectral-poisson/), and finite-difference convergence order is examined in scioxide-pde's [Following a Poisson problem from conservation laws to grid convergence](../../../scioxide-pde/examples/poisson-grid/).

## Five-point finite-difference matrix

Place $n \times n$ interior grid points in the square $[0, 1]^2$ with grid spacing $h = 1/(n + 1)$ and impose $u = 0$ on the boundary (Dirichlet conditions).
The five-point difference at grid point $(i, j)$ ($0 \le i, j < n$, with $i$ the grid row and $j$ the column) is

$$
4u_{i,j} - u_{i-1,j} - u_{i+1,j} - u_{i,j-1} - u_{i,j+1} = h^2 f_{i,j}
$$

with boundary values taken as 0.
Numbering grid points in row-major order as $k = in + j$ gives the band matrix $\mathbf{A} \in \mathbb{R}^{N \times N}$ ($N = n^2$), with 4 on the diagonal and $-1$ at horizontal neighbors ($k \pm 1$) and vertical neighbors ($k \pm n$).

The eigenvectors of $\mathbf{A}$ are $\sin\frac{p\pi(i + 1)}{n + 1}\sin\frac{q\pi(j + 1)}{n + 1}$, and the eigenvalues are

$$
\lambda_{pq} = 4\sin^2\frac{p\pi}{2(n + 1)} + 4\sin^2\frac{q\pi}{2(n + 1)}, \qquad p, q = 1, \dots, n
$$

all positive, so $\mathbf{A}$ is symmetric positive definite.
The 2-norm condition number is $\kappa_2(\mathbf{A}) = \lambda_{nn}/\lambda_{11} = \cot^2\frac{\pi}{2(n + 1)}$, giving 116 at $n = 16$ and 972 at $n = 48$.

The following block contains definitions shared by the three cells.
`PoissonGrid::new` assembles the matrix above, `analyze` performs symbolic analysis with the selected ordering (`GridOrdering`), and `profile` computes the reordered matrix's bandwidth and envelope (defined in the next section).
Symbolic analysis is given a factor-entry limit of $Nn = n^3$ and a byte limit of 64 MiB.
Natural-order fill is $n^3 - n^2 + n - 1$, derived in the next section, and fits this limit; the other two orderings have less fill (table below).
Memory for factors and workspace is allocated up to the entry limit, so set that limit close to the required amount.
For AMD factorization without choosing an ordering, the constructor `SparseCholesky::new` performs preparation together and sets the limit to the entry count predicted by symbolic analysis.
Cholesky does not use the Schur-complement workspace used in $\mathbf{L}\mathbf{D}\mathbf{L}^{\mathsf{H}}$ factorization, so set that limit to 0.

```rust
//| id: sparse-poisson-model
//| kind: definitions
//| title: "Five-point Laplacian and symbolic analysis with three orderings"
//| crates: [scioxide-core, scioxide-sparse]
use scioxide_core::{SciOxideError, Permutation, Triangle};
use scioxide_sparse::{
    CsrMatrix, DuplicatePolicy, ExplicitZeroPolicy, SparseBuilder, SparseOrdering,
    SparseSymmetricLimits, SparseSymmetricSymbolic, reverse_cuthill_mckee,
};

/// Choice of unknown numbering.
#[derive(Clone, Copy)]
pub(crate) enum GridOrdering {
    Natural,
    ReverseCuthillMcKee,
    MinimumDegree,
}

impl GridOrdering {
    pub(crate) const ALL: [GridOrdering; 3] = [
        Self::Natural,
        Self::ReverseCuthillMcKee,
        Self::MinimumDegree,
    ];

    pub(crate) fn label(self) -> &'static str {
        match self {
            Self::Natural => "Natural order",
            Self::ReverseCuthillMcKee => "RCM",
            Self::MinimumDegree => "AMD",
        }
    }
}

/// Five-point Laplacian on a square with n interior points per side (row-major numbering k = in + j).
pub(crate) struct PoissonGrid {
    pub(crate) side: usize,
    pub(crate) matrix: CsrMatrix<f64>,
}

impl PoissonGrid {
    pub(crate) fn new(side: usize) -> Result<Self, SciOxideError> {
        let unknowns = side * side;
        let mut builder = SparseBuilder::new(unknowns, unknowns);
        for p in 0..unknowns {
            builder.push(p, p, 4.0)?;
            // Horizontal neighbors must be in the same grid row and vertical neighbors in the same grid column.
            for q in [p.wrapping_sub(1), p + 1, p.wrapping_sub(side), p + side] {
                if q < unknowns && (q / side == p / side || q % side == p % side) {
                    builder.push(p, q, -1.0)?;
                }
            }
        }
        let matrix = builder.finish_csr(DuplicatePolicy::Reject, ExplicitZeroPolicy::Drop)?;
        Ok(Self { side, matrix })
    }

    /// Symbolic analysis reading the lower triangle in the chosen ordering (factor-entry limit N n).
    pub(crate) fn analyze(
        &self,
        ordering: GridOrdering,
    ) -> Result<SparseSymmetricSymbolic, SciOxideError> {
        let pattern = self.matrix.structural_pattern();
        let rcm;
        let chosen = match ordering {
            GridOrdering::Natural => SparseOrdering::Natural,
            GridOrdering::ReverseCuthillMcKee => {
                rcm = reverse_cuthill_mckee(pattern)?;
                SparseOrdering::Supplied(&rcm)
            }
            GridOrdering::MinimumDegree => SparseOrdering::FillReducing,
        };
        let limits = SparseSymmetricLimits::new(self.matrix.rows() * self.side, 0, 1 << 26);
        SparseSymmetricSymbolic::analyze(pattern, chosen, Some(Triangle::Lower), limits)
    }

    /// Bandwidth β and envelope size env = Σₖ (k − fₖ) of reordered P A Pᵀ.
    pub(crate) fn profile(&self, permutation: &Permutation) -> (usize, usize) {
        let (row_ptr, cols) = (self.matrix.row_ptr(), self.matrix.col_indices());
        let new_of = permutation.old_to_new();
        let (mut bandwidth, mut envelope) = (0, 0);
        for (k, &old) in permutation.new_to_old().iter().enumerate() {
            // First nonzero column fₖ in row k (including the diagonal, so fₖ ≤ k).
            let first = cols[row_ptr[old]..row_ptr[old + 1]]
                .iter()
                .fold(k, |f, &c| f.min(new_of[c]));
            bandwidth = bandwidth.max(k - first);
            envelope += k - first;
        }
        (bandwidth, envelope)
    }
}
```

## Bandwidth, envelope, and fill

Define the matrix **bandwidth** as $\beta = \max\{\lvert k - l \rvert : a_{kl} \ne 0\}$, the first nonzero column in row $k$ as $f_k = \min\{l : a_{kl} \ne 0\}$, and the **envelope** (profile) size as $\mathrm{env}(\mathbf{A}) = \sum_k (k - f_k)$.
Elimination creates no nonzeros to the left of a row's first nonzero, so row $k$ of the Cholesky factor has nonzeros only in columns $f_k$ through $k$ (the envelope theorem; [Reverse Cuthill–McKee and the envelope](oxref:sparse-rcm-envelope)).
Thus the number of strictly lower-triangular factor nonzeros satisfies

$$
\mathrm{nnz}(\mathbf{L}) \le \mathrm{env}(\mathbf{P}\mathbf{A}\mathbf{P}^{\mathsf{T}})
$$

where $\mathbf{P}$ is the permutation matrix representing the ordering.

In natural ordering, points in grid row 0 ($k < n$) have only a left neighbor, giving $k - f_k = 1$ (0 at $k = 0$); all other points have a neighbor directly above, giving $k - f_k = n$.
Consequently,

$$
\mathrm{env}(\mathbf{A}) = (n - 1) + n(N - n) = n^3 - n^2 + n - 1
$$

Elimination completely fills this envelope.
By the fill-path theorem ([Elimination graphs and fill](oxref:sparse-elimination-graph-fill)), for $l < k$ the factor entry $L_{kl}$ is nonzero exactly when a path joins $k$ and $l$ through only vertices numbered below $l$.
If $k$ lies in grid row 1 or later and $k - n \le l < k$, there is a path from $k$ to $k - n$ directly above, along that grid row to the column of $l$, and, if $l$ shares the grid row of $k$, finally down to $l$.
Every intermediate vertex is numbered below $l$, so factor nonzeros fill the entire envelope and the inequality becomes an equality.
Thus natural ordering gives $\mathrm{nnz}(\mathbf{L}) = n^3 - n^2 + n - 1 = O(N^{3/2})$.

Eliminating column $l$ requires $c_l(c_l + 1)/2$ multiply-adds to update the Schur complement, where $c_l$ is the column nonzero count.
Counting multiplication and addition separately, the leading floating-point operation count for the entire factorization is $\sum_l c_l^2$.
Natural ordering has $c_l \approx n$, so its operation count is proportional to $Nn^2 = N^2$.

Reverse Cuthill–McKee (RCM) numbers vertices by breadth-first-search levels to reduce bandwidth and envelope.
`reverse_cuthill_mckee` repeatedly searches from a minimum-degree vertex to choose a pseudoperipheral starting vertex, so the grid search starts at a corner.
The levels then consist of antidiagonals with at most $n$ points, leaving bandwidth of order $n$, as in natural ordering.
Each row's envelope width is approximately its level size, so the envelope is roughly the sum of squared level sizes, approximately $\frac{2}{3}n^3$, growing proportionally to $N^{3/2}$ as in natural ordering.
Approximate minimum degree (AMD) does not form a band and eliminates vertices with the fewest current neighbors first, giving a larger envelope but much less fill.
AMD is `SparseOrdering::FillReducing`, the default for symbolic analysis of direct factorizations.

For grid problems, nested dissection achieves fill $O(N \log N)$ and operation count $O(N^{3/2})$ (George, 1973).
`scioxide-sparse` does not provide nested dissection; supply an ordering constructed from a grid partition with `SparseOrdering::Supplied`.

## Comparing three orderings

The following cell analyzes the $n \times n$ grid matrix with `SparseSymmetricSymbolic::analyze` using natural ordering, RCM (the ordering from `reverse_cuthill_mckee` supplied through `Supplied`), and AMD (`FillReducing`), then factors it with `SparseCholesky::factor`.
The input is the number of points per grid side $n$ (8–48).

The table's bandwidth and envelope are counted independently from the structure of reordered $\mathbf{P}\mathbf{A}\mathbf{P}^{\mathsf{T}}$.
$\mathrm{nnz}(\mathbf{L})$ is the factor nonzero count predicted from structure by symbolic analysis (`cholesky_entries`), and the Cholesky factor stores exactly this many entries.
A nonnegative difference from the envelope, $\mathrm{env} - \mathrm{nnz}(\mathbf{L})$, checks the envelope theorem; the last row is the closed form for natural ordering.
The operation-count estimate $\sum_l c_l^2$ is obtained by counting nonzeros in each column of the computed factor.
The last column is the error $\lVert\hat{\mathbf{x}} - \mathbf{1}\rVert_\infty$ of solution $\hat{\mathbf{x}}$ obtained by solving $\mathbf{A}\mathbf{x} = \mathbf{A}\mathbf{1}$ with exact solution $\mathbf{x} = \mathbf{1}$.

```rust
//| id: sparse-poisson-reordering
//| ref: sparse-poisson-reordering
//| title: "Bandwidth, envelope, and fill of a two-dimensional Poisson matrix with three orderings"
//| run: reactive
//| uses: [sparse-poisson-model]
//| crates: [scioxide-core, scioxide-sparse]
//| inputs:
//|   grid_n: {"type":"range","label":"Points per grid side n","description":"The number of unknowns is N = n².","min":8,"max":48,"step":4,"value":16}
//| cases:
//|   - {"id":"large-grid","label":"n = 48","description":"The natural-order/AMD factor nonzero ratio grows to 3.6 and the operation-count ratio to about 6.","inputs":{"grid_n":48}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"orderings","path":"/rows/0/1","equals":16}
//|       - {"artifact":"orderings","path":"/rows/0/2","equals":3855}
//|       - {"artifact":"orderings","path":"/rows/0/3","equals":3855}
//|       - {"artifact":"orderings","path":"/rows/0/4","equals":0}
//|       - {"artifact":"orderings","path":"/rows/1/3","equals":2840}
//|       - {"artifact":"orderings","path":"/rows/2/3","equals":1885}
//|       - {"artifact":"orderings","path":"/rows/2/4","range":{"min":0}}
//|       - {"artifact":"orderings","path":"/rows/2/6","range":{"max":1e-13}}
//|       - {"artifact":"orderings","path":"/rows/3/3","equals":3855}
//|   - case: large-grid
//|     expect:
//|       - {"artifact":"orderings","path":"/rows/0/3","equals":108335}
//|       - {"artifact":"orderings","path":"/rows/3/3","equals":108335}
//|       - {"artifact":"orderings","path":"/rows/2/3","equals":30264}
//|       - {"artifact":"orderings","path":"/rows/0/6","range":{"max":1e-12}}
use scioxide_sparse::SparseCholesky;

let grid = PoissonGrid::new(grid_n as usize).map_err(|e| e.to_string())?;
let (n, unknowns) = (grid.side, grid.matrix.rows());
// Right-hand side b = A1 for exact solution x = 1.
let b = grid
    .matrix
    .apply(&vec![1.0; unknowns])
    .map_err(|e| e.to_string())?;
let mut rows = Vec::new();
for ordering in GridOrdering::ALL {
    let symbolic = grid.analyze(ordering).map_err(|e| e.to_string())?;
    // Independent check: count bandwidth and envelope from the first nonzero column of each row of P A Pᵀ.
    let (bandwidth, envelope) = grid.profile(symbolic.permutation());
    let predicted = symbolic.cholesky_entries();
    let factor =
        SparseCholesky::factor(symbolic, grid.matrix.view()).map_err(|e| e.to_string())?;
    // Estimate operations Σ c² from the nonzero count c in each column.
    let mut counts = vec![0usize; unknowns];
    for (_, column, _) in factor.lower_entries() {
        counts[column] += 1;
    }
    let flops: usize = counts.iter().map(|c| c * c).sum();
    let x = factor.solve(&b).map_err(|e| e.to_string())?;
    let error = x.iter().map(|v| (v - 1.0).abs()).fold(0.0_f64, f64::max);
    let slack = envelope as i64 - predicted as i64;
    rows.push((
        ordering.label(),
        bandwidth,
        envelope,
        predicted,
        slack,
        Some(flops),
        Some(error),
    ));
}
let closed = n * n * n - n * n + n - 1;
rows.push(("Natural-order closed form", n, closed, closed, 0, None, None));

let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let columns = serde_json::json!([
    { "key": "0", "label": "Ordering" },
    { "key": "1", "label": "Bandwidth β", "type": "integer" },
    { "key": "2", "label": "Envelope env", "type": "integer" },
    { "key": "3", "label": "nnz(L)", "type": "integer" },
    { "key": "4", "label": "env − nnz(L)", "type": "integer" },
    { "key": "5", "label": "Operations Σ c²", "type": "integer", "nullText": "Not applicable" },
    { "key": "6", "label": "Error ‖x̂ − 1‖∞ [-]", "type": "number", "format": sci2, "nullText": "Not applicable" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "orderings" })
);
```

At the default $n = 16$ ($N = 256$), natural ordering has bandwidth 16 and envelope 3855; its 3855 factor nonzeros match both the closed form $n^3 - n^2 + n - 1$ and the envelope, giving equality in $\mathrm{nnz}(\mathbf{L}) \le \mathrm{env}$.
RCM keeps bandwidth at 16 and reduces the envelope to 2840, with the factor nonzero count also equal to the envelope, 2840.
AMD does not form a band, so bandwidth 228 and envelope 5824 are larger, but the factor nonzero count 1885 is the smallest.
The envelope-theorem upper bound is loose for AMD, with an envelope difference of 3939.
The operation estimate $\sum_l c_l^2$ is 60335 for natural ordering, 35240 for RCM, and 19909 for AMD.

At $n = 48$ ($N = 2304$), factor nonzero counts are 108335 for natural ordering, 74824 for RCM, and 30264 for AMD.
The natural-order/AMD ratio grows to 3.6, and the operation-count ratio to about 6 (5163279 versus 869322).

Solution errors are at most $3.3 \times 10^{-15}$ for every ordering at $n = 16$, and at most $2.0 \times 10^{-14}$ even at $n = 48$.
Both are smaller than the condition number times machine epsilon, $\kappa_2(\mathbf{A})\varepsilon$ ($2.6 \times 10^{-14}$ at $n = 16$ and $2.2 \times 10^{-13}$ at $n = 48$).
Cholesky factorization of a symmetric positive definite matrix is backward stable under any symmetric ordering (Higham, 2002), so error magnitude depends on conditioning rather than ordering, and reordering barely changes solution accuracy.

## Fill and grid size

The following cell performs symbolic analysis for 12 grids, $n = 4, 8, \dots, 48$, under the three orderings and plots the selected quantity against unknown count $N = n^2$ on logarithmic axes.
Bandwidth, envelope, and $\mathrm{nnz}(\mathbf{L})$ depend only on structure, so no numerical factorization is performed.
Symbols joined by lines show the three orderings, while dashed lines show the natural-order closed forms ($n$ for bandwidth and $n^3 - n^2 + n - 1$ for envelope and $\mathrm{nnz}(\mathbf{L})$).
On a log-log plot, a quantity proportional to $N^a$ is a straight line of slope $a$.
The table shows the values at $n = 24$ and $n = 48$ and the slope $\Delta\log(\text{quantity})/\Delta\log N$ between them.

However, these slopes are values between two grids and do not give the asymptotic order of AMD fill growth.

Selecting the envelope shows that natural-order and RCM values equal $\mathrm{nnz}(\mathbf{L})$ for all 12 grids, confirming complete filling of the envelope independently of grid size.
RCM's envelope is 74824 at $n = 48$, close to $\frac{2}{3}n^3 = 73728$.
AMD's envelope grows faster than natural ordering with slope 1.62, reaching 220529 at $n = 48$, twice the natural-order value.
Selecting bandwidth gives $n$ and slope 0.5 for both natural ordering and RCM, while AMD's bandwidth is 2236 at $n = 48$, close to $N = 2304$.

## Factor nonzero patterns

The following cell plots nonzero locations in factor $\mathbf{L}$ under the selected ordering as a heatmap with row and column indices as axes, distinguishing positions also present in the lower triangle of reordered $\mathbf{P}\mathbf{A}\mathbf{P}^{\mathsf{T}}$ (1) from new fill (2); 0 denotes zero and the diagonal is marked 1.
Inputs are points per grid side $n$ (4–12) and the ordering.
The color range is fixed at 0–2 to facilitate comparison between orderings.
The table counts strictly lower-triangular nonzeros of $\mathbf{P}\mathbf{A}\mathbf{P}^{\mathsf{T}}$ present in the factor pattern and compares them with the grid edge count $2n(n - 1)$.
Structurally, elimination never removes an original nonzero, so these counts agree for every ordering.

```rust
let grid = PoissonGrid::new(grid_n as usize).map_err(|e| e.to_string())?;
let (n, unknowns) = (grid.side, grid.matrix.rows());
let chosen = match ordering.as_str() {
    "RCM" => GridOrdering::ReverseCuthillMcKee,
    "AMD" => GridOrdering::MinimumDegree,
    _ => GridOrdering::Natural,
};
let symbolic = grid.analyze(chosen).map_err(|e| e.to_string())?;
let new_of = symbolic.permutation().old_to_new().to_vec();
let factor = SparseCholesky::factor(symbolic, grid.matrix.view()).map_err(|e| e.to_string())?;
// 0: zero; 1: positions also in the original lower triangle and the diagonal; 2: fill.
let mut cell = vec![0.0_f64; unknowns * unknowns];
for (i, j, _) in factor.lower_entries() {
    cell[i * unknowns + j] = 2.0;
}
let mut original = 0;
for (r, c, _) in grid.matrix.iter() {
    let (i, j) = (new_of[r].max(new_of[c]), new_of[r].min(new_of[c]));
    if i > j && cell[i * unknowns + j] == 2.0 {
        cell[i * unknowns + j] = 1.0;
        original += 1;
    }
}
let fill = cell.iter().filter(|&&v| v == 2.0).count();
let mut data = Vec::new();
for i in 0..unknowns {
    data.push([i as f64, i as f64, 1.0]);
    for j in 0..i {
        data.push([j as f64, i as f64, cell[i * unknowns + j]]);
    }
}

let columns = serde_json::json!([
    { "key": "0", "label": "Ordering" },
    { "key": "1", "label": "Original strictly lower-triangular nonzeros", "type": "integer" },
    { "key": "2", "label": "Edges 2n(n − 1)", "type": "integer" },
    { "key": "3", "label": "Fill", "type": "integer" },
    { "key": "4", "label": "nnz(L)", "type": "integer" }
]);
let row = (
    ordering.clone(),
    original,
    2 * n * (n - 1),
    fill,
    factor.factor_entries(),
);
emit_table_with_columns!(
    columns,
    vec![row],
    metadata = serde_json::json!({ "id": "counts" })
);
emit_chart!(
    serde_json::json!({
        "kind": "heatmap",
        "data": data,
        "xLabel": "Column j (after reordering) [-]",
        "yLabel": "Row i (after reordering) [-]",
        "colorMin": 0.0,
        "colorMax": 2.0,
        "tooltip": true,
        "style": { "animation": false }
    }),
    metadata = serde_json::json!({
        "id": "pattern",
        "title": "Factor nonzeros (1: original entries and diagonal; 2: fill)"
    })
);
```

For natural ordering at the default $n = 8$, 112 original strictly lower-triangular nonzeros (the grid edge count $2n(n - 1) = 112$) gain 343 fill entries, giving $\mathrm{nnz}(\mathbf{L}) = 455 = n^3 - n^2 + n - 1$.
The factor is a band filling all 8 columns left of the diagonal in each row from grid row 1 onward.
RCM reduces fill to 252, with nonzeros still arranged diagonally in a band.
AMD has 183 fill entries and its nonzeros do not form a band.
The 112 original entries and 183 fill entries give 295 factor nonzeros, arranged in a block structure corresponding to the elimination tree.

## Summary

For the five-point Poisson matrix, the natural-order Cholesky factor fills its envelope, with nonzero count $n^3 - n^2 + n - 1$ growing as $O(N^{3/2})$.
RCM also retains grid bandwidth $n$; it reduces envelope and fill but leaves their growth order unchanged from natural ordering.
AMD eliminates vertices with few current neighbors without forming a band; despite its larger envelope, at $n = 48$ it reduces factor nonzeros to 28 % and operation count to 17 % of natural ordering.
AMD (`FillReducing`) is the default for symbolic analysis of direct factorizations, so this reduction is obtained without specifying an ordering.
Symbolic-analysis `cholesky_entries` gives the fill amount before factorization, so comparing orderings and estimating memory do not require numerical factorization.
For every ordering, solution errors remain at the rounding level consistent with conditioning; reordering changes memory and work while barely affecting accuracy.
