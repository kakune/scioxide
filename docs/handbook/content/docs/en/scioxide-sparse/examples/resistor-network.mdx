The steady state of a network containing only resistors is determined by Kirchhoff's current law at each node and Ohm's law on each branch.
In **nodal analysis**, where node potentials are the unknowns, the coefficient matrix is the network graph's Laplacian, a sparse symmetric positive semidefinite matrix.
This example assembles a grid network with varying resistances, grounds one node, solves with `SparseCholesky`, and computes effective resistances for every branch.
Independent checks use Foster's theorem for the sum of effective resistances, an eigenfunction expansion for effective resistances on a uniform grid, and a small circuit that can be reduced by hand using series and parallel combinations.

## Nodal analysis

Consider a connected network with nodes $0, \dots, n - 1$ and branches $e = \{u, v\}$ of resistance $R_e$ [Ω] (conductance $g_e = 1/R_e$ [S]).
If node $i$ has potential $V_i$ [V] and external current $I_i$ [A] is injected into node $i$, the current law gives

$$
\mathbf{L}\mathbf{V} = \mathbf{I}, \qquad \mathbf{L} = \mathbf{D} - \mathbf{G}
$$

$\mathbf{G}$ is the conductance weight matrix, $\mathbf{D}$ is the diagonal matrix of total conductance incident to each node, and $\mathbf{L}$ is the conductance-weighted graph Laplacian ([Graph Laplacian](oxref:sparse-graph-laplacian)).
Choose an orientation for each branch $e$ and set $\mathbf{b}_e = \mathbf{e}_u - \mathbf{e}_v$; then

$$
\mathbf{L} = \sum_{e \in E} g_e\, \mathbf{b}_e \mathbf{b}_e^{\mathsf{T}}, \qquad \mathbf{x}^{\mathsf{T}}\mathbf{L}\mathbf{x} = \sum_{e = \{u, v\}} g_e (x_u - x_v)^2
$$

If $\mathbf{x}$ represents potentials, the right-hand expression is the total power dissipated in the branches [W]; it is nonnegative for every $\mathbf{x}$, so $\mathbf{L}$ is positive semidefinite.
Adding a constant to all potentials does not change currents, so $\mathbf{L}\mathbf{1} = \mathbf{0}$; if the network is connected, $\mathbf{L}$ has rank $n - 1$.

Ground reference node $g$, setting $V_g = 0$, and let $\mathbf{L}_g$ be the $(n - 1) \times (n - 1)$ matrix obtained by removing its row and column.
Under $x_g = 0$, if $\mathbf{x}^{\mathsf{T}}\mathbf{L}\mathbf{x} = 0$ then $x_u = x_v$ on every branch, so $\mathbf{x}$ is constant in a connected network, and $x_g = 0$ implies $\mathbf{x} = \mathbf{0}$.
Thus $\mathbf{L}_g$ is symmetric positive definite and can be solved by Cholesky factorization.
If the network is disconnected, potentials in parts disconnected from ground are undetermined and $\mathbf{L}_g$ is singular.

The potential difference $V_u - V_v$ when 1 A is injected into node $u$ and withdrawn from node $v$ is called the **effective resistance** between $u$ and $v$.
Using the pseudoinverse $\mathbf{L}^{+}$ of $\mathbf{L}$ and $\mathbf{b}_{uv} = \mathbf{e}_u - \mathbf{e}_v$ gives

$$
R_{\mathrm{eff}}(u, v) = \mathbf{b}_{uv}^{\mathsf{T}}\, \mathbf{L}^{+}\, \mathbf{b}_{uv}
$$

In computation, solve $\mathbf{L}_g \mathbf{x} = \mathbf{b}_{uv}$ (omitting the $g$ component), set $x_g = 0$, and take $R_{\mathrm{eff}} = x_u - x_v$.
This works because potential differences do not depend on the reference.

## Assembly and grounding

Place each branch conductance $1/R_e$ once at upper-triangular position $(\min(u, v), \max(u, v))$ using `SparseBuilder`.
Parallel branches joining the same pair of nodes contribute to the same position, so sum conductances with `DuplicatePolicy::Sum`.
`GraphPlan::new(view, GraphDirection::Undirected)` interprets stored $(u, v)$ as an undirected edge joining $u$ and $v$ and expands it into adjacency in both directions.
If both $(u, v)$ and $(v, u)$ are stored, the edge weight is the smaller value; they are not added.
Sum parallel branches at the preceding assembly stage.

`GraphPlan::laplacian::<f64>(LaplacianDegree::Out, LaplacianNormalization::Unnormalized)` returns $\mathbf{L} = \mathbf{D} - \mathbf{G}$ as `LaplacianPlan`, and `into_matrix()` extracts the CSR matrix.
Negative weights are rejected with `DomainError`.
The function `laplacian(view)` returns the same $\mathbf{D} - \mathbf{G}$ but interprets the matrix as a directed graph, so it requires a weight matrix storing both triangles.

For grounding, remove the row and column of the last node $g = n - 1$ and transfer the remaining entries to a new `SparseBuilder`.
`SparseCholesky::new` performs preparation together: it reorders with approximate minimum degree (AMD), reads both triangles and checks exact symmetry of values, then factors without taking limits.
For a disconnected network, $\mathbf{L}_g$ is singular and a pivot during elimination becomes zero or of rounding-error magnitude.
A nonpositive pivot gives `NumericalInstability`, but a small positive pivot allows factorization to succeed and meaningless potentials to be returned.
Check network connectivity with `connected_components` or `GraphPlan::weak_components` before factorization.
Factorization is performed once; each effective resistance requires one forward/backward substitution pair, with work proportional to the factor nonzero count.

The following block contains definitions shared by the three cells.
`GroundedNetwork::new` covers assembly through factorization of $\mathbf{L}_g$, `potentials(u, v)` gives all node potentials when 1 A is injected into $u$ and withdrawn from $v$, and `effective_resistance(u, v)` corresponds to $R_{\mathrm{eff}}(u, v)$.
`grid_branches(m, resistance)` returns branches joining horizontal and vertical neighbors on an $m \times m$ grid ($n = m^2$; node $(i, j)$ has index $im + j$), with each branch resistance set by `resistance`.

```rust
//| id: sparse-resistor-model
//| kind: definitions
//| title: "Grounded Laplacian and effective resistance"
//| crates: [scioxide-core, scioxide-sparse]
use scioxide_core::SciOxideError;
use scioxide_sparse::{
    DuplicatePolicy, ExplicitZeroPolicy, GraphDirection, GraphPlan, LaplacianDegree,
    LaplacianNormalization, SparseBuilder, SparseCholesky,
};

/// Resistor network with the last node g = n − 1 grounded and a Cholesky factorization of L_g.
pub(crate) struct GroundedNetwork {
    pub(crate) nodes: usize,
    factor: SparseCholesky<f64>,
}

impl GroundedNetwork {
    /// Form L = D − G from branches (u, v, R [Ω]) and factor L_g after removing row and column g (n ≥ 2).
    pub(crate) fn new(nodes: usize, branches: &[(usize, usize, f64)]) -> Result<Self, SciOxideError> {
        // Place conductance 1/R once in the upper triangle and combine parallel branches with Sum.
        let mut builder = SparseBuilder::new(nodes, nodes);
        for &(u, v, resistance) in branches {
            builder.push(u.min(v), u.max(v), 1.0 / resistance)?;
        }
        let conductance = builder.finish_csr(DuplicatePolicy::Sum, ExplicitZeroPolicy::Drop)?;
        // Read as an undirected graph, making upper-triangular entries into edges in both directions.
        let graph = GraphPlan::new(conductance.view(), GraphDirection::Undirected)?;
        let laplacian = graph
            .laplacian::<f64>(LaplacianDegree::Out, LaplacianNormalization::Unnormalized)?
            .into_matrix();
        // Grounding: remove row and column of node g = n − 1.
        let g = nodes - 1;
        let mut reduced = SparseBuilder::new(g, g);
        for (i, j, value) in laplacian.iter().filter(|&(i, j, _)| i < g && j < g) {
            reduced.push(i, j, value)?;
        }
        let grounded = reduced.finish_csr(DuplicatePolicy::Reject, ExplicitZeroPolicy::Preserve)?;
        let factor = SparseCholesky::new(&grounded)?;
        Ok(Self { nodes, factor })
    }

    /// All node potentials [V] when 1 A is injected into node u and withdrawn from v (V_g = 0).
    pub(crate) fn potentials(&self, u: usize, v: usize) -> Result<Vec<f64>, SciOxideError> {
        let g = self.nodes - 1;
        let mut current = vec![0.0; g];
        if u < g {
            current[u] += 1.0;
        }
        if v < g {
            current[v] -= 1.0;
        }
        let mut potential = self.factor.solve(&current)?;
        potential.push(0.0);
        Ok(potential)
    }

    /// Effective resistance R_eff(u, v) = V_u − V_v [Ω].
    pub(crate) fn effective_resistance(&self, u: usize, v: usize) -> Result<f64, SciOxideError> {
        let potential = self.potentials(u, v)?;
        Ok(potential[u] - potential[v])
    }
}

/// Branches (p, q, R [Ω]) to right and lower neighbors in an m × m grid. resistance() sets R for each branch.
pub(crate) fn grid_branches(
    m: usize,
    mut resistance: impl FnMut() -> f64,
) -> Vec<(usize, usize, f64)> {
    let n = m * m;
    let mut branches = Vec::new();
    for p in 0..n {
        for q in [p + 1, p + m] {
            if q < n && (q / m == p / m || q % m == p % m) {
                branches.push((p, q, resistance()));
            }
        }
    }
    branches
}
```

## Foster's theorem

For a connected network, the sum over all branches satisfies

$$
\sum_{e \in E} \frac{R_{\mathrm{eff}}(e)}{R_e} = n - 1
$$

the relation above holds.
This is Foster's theorem (Foster, 1949).
Each term on the left can be written as $g_e\, \mathbf{b}_e^{\mathsf{T}}\mathbf{L}^{+}\mathbf{b}_e = \mathrm{tr}(\mathbf{L}^{+} g_e \mathbf{b}_e\mathbf{b}_e^{\mathsf{T}})$, and $\sum_e g_e\mathbf{b}_e\mathbf{b}_e^{\mathsf{T}} = \mathbf{L}$, so the sum equals $\mathrm{tr}(\mathbf{L}^{+}\mathbf{L})$.
$\mathbf{L}^{+}\mathbf{L}$ is the orthogonal projection onto the range of $\mathbf{L}$, so its trace is the rank $n - 1$.
This identity depends only on the node count, independently of resistances and network shape, so it checks all branch effective resistances together.

Each term's magnitude is determined by the effective resistance $R_{\mathrm{rest}}$ between $u$ and $v$ in the network with branch $e = \{u, v\}$ removed.
Branch $e$ is parallel to the rest of the network, so $R_{\mathrm{eff}}(e) = R_e R_{\mathrm{rest}}/(R_e + R_{\mathrm{rest}})$ and

$$
\frac{R_{\mathrm{eff}}(e)}{R_e} = \frac{R_{\mathrm{rest}}}{R_e + R_{\mathrm{rest}}} \in (0, 1]
$$

A branch with lower resistance than the remaining paths has a term closer to 1; a branch whose removal disconnects the network ($R_{\mathrm{rest}} = \infty$) has term 1.
If a spanning tree is chosen with probability proportional to the product of its branch conductances, this term also equals the probability that the tree contains branch $e$ (by Kirchhoff's matrix-tree theorem).
A spanning tree has exactly $n - 1$ branches, so the probabilities summing to $n - 1$ gives another proof of Foster's theorem.

## Eigenfunction expansion of a uniform grid

For an $m \times m$ grid with all resistances 1 Ω, Laplacian eigenvectors are known in closed form, allowing effective resistances to be computed independently of nodal analysis.
The Laplacian eigenvalues and orthonormal eigenvectors of a path with $m$ nodes are, for $k = 0, \dots, m - 1$,

$$
\mu_k = 4\sin^2\frac{k\pi}{2m}, \qquad \phi_k(i) = c_k \cos\frac{k\pi(i + 1/2)}{m}, \qquad c_0 = \sqrt{1/m},\ c_k = \sqrt{2/m}\ (k \ge 1)
$$

The grid is the Cartesian product of two paths, so its eigenvector at node $(i, j)$ is $\phi_k(i)\phi_l(j)$ and its eigenvalue is $\mu_k + \mu_l$.
Expanding $\mathbf{L}^{+}$ in eigenvectors while omitting $(k, l) = (0, 0)$ with eigenvalue 0 gives effective resistance between nodes $p = (i, j)$ and $q = (i', j')$ as

$$
R_{\mathrm{eff}}(p, q) = \sum_{(k, l) \ne (0, 0)} \frac{\bigl(\phi_k(i)\phi_l(j) - \phi_k(i')\phi_l(j')\bigr)^2}{\mu_k + \mu_l}
$$

(Wu, 2004).

When 1 A is injected into corner 0 and withdrawn from grounded corner $n - 1$, grid symmetry gives the following relations for potentials $V_p$.
Rotating the grid by 180° maps node $p = (i, j)$ to $\bar{p} = (m - 1 - i, m - 1 - j)$ (index $n - 1 - p$) and exchanges the injection and withdrawal corners, so the vector of $V_{\bar{p}}$ solves the reversed-current system.
That solution is the negative of the original potentials plus a constant; $V_{n-1} = 0$ at $p = 0$ sets the constant to $V_0 = R_{\mathrm{eff}}$, giving $V_p + V_{\bar{p}} = R_{\mathrm{eff}}$.
Reflection in the main diagonal, $(i, j) \to (j, i)$, fixes the two corners, so $V_{(i, j)} = V_{(j, i)}$ also holds.
On the antidiagonal $i + j = m - 1$, $\bar{p} = (j, i)$, so the two relations give potential $R_{\mathrm{eff}}/2$.

```rust
let spectral = |m: usize| {
    let (pi, size) = (core::f64::consts::PI, m as f64);
    let mu = |k: usize| 4.0 * (k as f64 * pi / (2.0 * size)).sin().powi(2);
    let phi = |k: usize, i: usize| {
        let scale = if k == 0 { 1.0 } else { 2.0 };
        (scale / size).sqrt() * (k as f64 * pi * (i as f64 + 0.5) / size).cos()

    }
    sum

```

At the default $m = 6$, nodal analysis and eigenfunction expansion agree within $2.2 \times 10^{-15}$ Ω in all 5 table rows.
The $m = 2$ square gives 1 Ω, $m = 3$ gives 1.5 Ω, $m = 4$ gives $13/7 = 1.857$ Ω, and $m = 6$ gives 2.3657 Ω.
Chart potentials are 2.366 V at injection corner 0, equal to $R_{\mathrm{eff}}$, exactly half that, 1.183 V, on the antidiagonal, and 0 V at ground.

Even at $m = 16$ with 256 nodes, corner-to-corner effective resistance is only 3.6085 Ω.
Doubling $m$ from 2 to 4, 8, and 16 adds 0.86–0.88 Ω each time, so effective resistance grows approximately with the logarithm of $m$.
Approximating the grid by a uniform sheet with sheet resistance 1 Ω, the 1 A injected at a corner spreads over a quarter-plane, so the potential difference between the corner and a point at distance $r$ grows approximately as $(2/\pi)\ln r$.
Combining both corners' contributions gives growth $(4/\pi)\ln m$, and the increment per doubling, $(4/\pi)\ln 2 = 0.883$ Ω, is close to the table increments.
The difference from the eigenfunction expansion is at most $6.1 \times 10^{-14}$ Ω, a relative difference in effective resistance of order $2 \times 10^{-14}$.

## Series and parallel combinations

The following cell builds a small circuit on nodes 0–3 with $R_1$ between 0–1, parallel $R_2$ and $R_3$ between 1–2, $R_4$ between 2–3, and $R_5$ between 0–2.
Node 1 connects only to 0 and 2, so $R_1$ and $R_2 \parallel R_3 = R_2R_3/(R_2 + R_3)$ join nodes 0 and 2 in series.
Putting this in parallel with $R_5$ and finally in series with $R_4$ gives the combined resistance between nodes 0 and 3 as

$$
R_{03} = R_{02} + R_4, \qquad R_{02} = \left( \frac{1}{R_1 + R_2 \parallel R_3} + \frac{1}{R_5} \right)^{-1}
$$

which can be calculated by hand.
Injecting 1 A into node 0 and withdrawing it from grounded node 3 gives $V_0 = R_{03}$ and $V_2 = R_4 \times 1$ A; the current $R_{02}/(R_1 + R_2 \parallel R_3)$ [A] through path $R_1$ gives $V_1 = V_2 + (R_2 \parallel R_3)\,R_{02}/(R_1 + R_2 \parallel R_3)$.
Parallel branches $R_2$ and $R_3$ are supplied as two contributions to the same node pair, and assembly `DuplicatePolicy::Sum` sums their conductances.

The table compares nodal-analysis potentials $V_0$, $V_1$, and $V_2$ with hand calculations.
Inputs are $R_1$ and $R_5$ [Ω]; the others are fixed at $R_2 = 2$, $R_3 = 3$, and $R_4 = 1$ Ω.

## Summary

The nodal-analysis matrix of a resistor network is the conductance-weighted graph Laplacian and can be built with `GraphPlan` and `LaplacianPlan` from an upper-triangular conductance matrix.
`GraphPlan` does not sum parallel branches, so add their conductances with assembly `DuplicatePolicy::Sum` before passing them in.
The Laplacian has constant vectors in its null space; grounding one node and removing its row and column gives a symmetric positive definite system for a connected network, solvable with `SparseCholesky::new`.
In a disconnected network the grounded matrix is singular, and even successful factorization can return meaningless potentials, so check connectivity with `connected_components` before factorization.
Effective resistance is the potential difference in a system with unit current injected and withdrawn at two nodes; after one factorization, each branch requires one forward/backward substitution pair.
Foster's theorem, $\sum_e R_{\mathrm{eff}}(e)/R_e = n - 1$, holds regardless of resistance variation and checks all branch computations together; on a uniform grid, individual effective resistances can also be compared with eigenfunction-expansion values.
