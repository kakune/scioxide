Given $n$ sites, their convex hull is the smallest convex set containing them; a Delaunay triangulation is a subdivision into simplices with sites as vertices whose circumspheres contain no other sites; a Voronoi diagram partitions space into sets of points nearest to each site.
Delaunay triangulations and Voronoi diagrams are dual; a Delaunay triangulation comes from the convex hull of sites lifted onto a paraboloid one dimension higher.
Each consists of a combinatorial structure describing which sites lie on which faces, and coordinate values such as circumcenters (centers of circumspheres) and barycentric coordinates.
`scioxide-spatial` determines the combinatorial structure using exact geometric predicates and returns coordinate values as rounded values.
This page explains site handling, each structure's definition and algorithm, complexity, APIs, and failure classifications, then checks results on lattice points.
See [Exact geometric predicates](../exact-predicates/) for predicate signs, [Degeneracy policies, resource limits, and construction information](../tessellation-degeneracy-and-limits/) for the two degeneracy policies, resource limits, and construction information, and [Point location and barycentric coordinates in Delaunay triangulations](../point-location/) for locating a containing simplex and barycentric coordinates.

## Site canonicalization and degeneracy handling

`ConvexHull`, `Delaunay`, `Voronoi`, and `SphericalVoronoi` accept a `PointSet` containing one point per row.
Dimension $d$ is at least 1, with a default upper limit of 8 (`GeometryLimits` in [Resource limits](oxref:spatial-tessellation-limits)).

Construction first sorts sites lexicographically by coordinates and merges rows with equal coordinates into one site (`-0.0` and `0.0` are considered equal).
A site's index after sorting is called its canonical index.
All subsequent indices (simplex vertices, convex-hull facets, simplices returned by `find_simplex`, and Voronoi regions) use these canonical indices.
Use the following two mappings on `ConvexHull` and `Delaunay` to relate sites to input rows.

- `input_mapping()[r]` returns the canonical index of the site containing input row $r$.
- `representatives()[s]` returns site $s$'s representative input row: the lowest-index row with the same coordinates.

`Voronoi` does not hold these mappings directly; access them through `voronoi.delaunay()`.
`SphericalVoronoi` has only `input_mapping()`.

`points()` returns sorted site coordinates in canonical-index order.
Canonical indices generally differ from input-row indices even without duplicates.
Use `representatives()` when looking up input data (observations or names) for a site.
Sorting makes the result depend only on the set of sites, independently of input-row order.
For a table checking the mapping between input rows with duplicates and canonical indices, see the [cell checking input-row/site correspondence and locating a simplex containing a query point](oxref:spatial-delaunay-point-location).

The sites must span $\mathbb{R}^d$.
Construction returns `Singular` if fewer than $d+1$ distinct sites exist or all sites lie in a single hyperplane (a line in the plane).

A configuration where a predicate is exactly 0, such as four planar points on one circle, is called degenerate.
Choose degeneracy handling through `GeometryDegeneracy` in `GeometryOptions`.

- `Deterministic` (default) merges duplicate sites and resolves exact zeros of lifted determinants (corresponding to `incircle` and `insphere`) in Delaunay triangulations and Voronoi diagrams by symbolic perturbation.
  Symbolic perturbation determines a determinant's sign as if the infinitesimal $\epsilon^{2^k}$ were added to the lifted coordinate of the site with canonical index $k$.
  In a zero determinant, the term for the first site whose cofactor is nonzero dominates; the result is the sign of that cofactor (the orientation of the remaining points) multiplied by the row-position sign $\pm 1$.
  It selects one regular triangulation globally rather than resolving each tie separately.
  The idea is the same as Edelsbrunner–Mücke's simulation of simplicity.
- `Strict` returns `InvalidInput` for duplicate sites.
  For Delaunay triangulations and Voronoi diagrams it also returns `InvalidInput` when two adjacent output simplices share an empty circumsphere, meaning the triangulation is not unique.
  Ties that do not affect output simplices are accepted.

Both policies leave coordinates unchanged and use the same symbolic perturbation, so their results agree on inputs accepted by `Strict`.
Convex-hull construction does not use lifting.
Sites on a facet's hyperplane are considered invisible from that facet, so only extreme points become vertices without symbolic perturbation.
For a lattice-point comparison of the two policies' results and construction work, see the [degeneracy-policy and construction-information cell](oxref:spatial-delaunay-degeneracy-policy).

## Convex-hull construction

The convex hull $\operatorname{conv} P$ is the smallest convex set containing the site set $P$; its boundary consists of $(d-1)$-dimensional faces.
`ConvexHull` stores the boundary divided into $(d-1)$-simplex facets.
Nonsimplicial faces, such as square faces of a cube, are split into several facets; `coplanar_faces()` assigns the same face index to facets on the same supporting hyperplane.
Facet vertices are only extreme points of the convex hull.
Boundary sites that are not extreme points, such as sites along the interior of a square's edge, do not become vertices.

The algorithm is randomized incremental construction (Clarkson–Shor), with insertion order fixed by hashes of canonical indices rather than random numbers.

1. Examine sites from the start of the insertion order and use exact determinant signs to select $d+1$ affinely independent sites as the initial simplex.
2. Add remaining sites one at a time in the prescribed order.
   For each uninserted site, record one facet visible from it (a conflict list).
3. Remove every facet visible from the inserted point $p$ (facets with $p$ outside), then fill the hole with facets connecting each ridge of its boundary (the horizon) to $p$.
   Sites lying inside the convex hull are excluded from further processing.

Visibility is determined by the sign of the orientation predicate of the facet and $p$, all evaluated exactly.
Thus the combinatorial structure is exact for the supplied coordinates, without inconsistencies from rounding.

Insertion order is increasing order of keyed SplitMix64 hashes of canonical indices.
No random-number generator is used.
The same site set always yields the same order and result, independently of input-row order.
By Clarkson–Shor analysis, uniformly random insertion order gives expected complexity $O(n \log n)$ in two and three dimensions, and $O(n^{\lfloor d/2 \rfloor})$ for $d \ge 4$.
This expectation averages over choices of order.
The fixed hash order mimics a randomized order but does not guarantee this complexity for individual inputs.
In higher dimensions, the convex-hull facet count itself grows in proportion to $n^{\lfloor d/2 \rfloor}$ in the worst case (the upper bound theorem), making facet-count and memory limits relevant.

Construct with `ConvexHull::new(&points)` and traverse the boundary with `facet_count()`, `facet(i)` (vertex canonical indices in increasing order), and `neighbors(i)` (facets sharing the ridge opposite each vertex).
`facets()` returns a reference to a flat sequence of all facet vertices, with $d$ entries per facet.
`contains(point)` tests membership in the closed convex hull with one exact orientation predicate per facet, at cost $O(\text{number of facets})$.
`contains` allocates workspace on each call; for many points, pass a preallocated workspace to `contains_scoped(point, &mut workspace, cx)`.
A point length different from the hull dimension returns `DimensionMismatch`; NaN or infinity returns `NonFinite`.

## Delaunay triangulation by paraboloid lifting

A triangulation with sites as vertices is a Delaunay triangulation if no simplex's circumsphere contains another site in its interior.
In the plane, a Delaunay triangulation maximizes the smallest interior angle among all triangulations (Lawson, Sibson).
Examine this property in [Delaunay maximization of the minimum angle](../../examples/delaunay-min-angle/).

A Delaunay triangulation is obtained by lifting point $x \in \mathbb{R}^d$ to the paraboloid point:

$$
\hat x = (x, \|x\|^2) \in \mathbb{R}^{d+1}
$$

For a circle through three planar points $a, b, c$ with center $m$ and radius $\rho$, $\|x\|^2 - 2 m \cdot x + \|m\|^2 - \rho^2$ is negative inside the circle and positive outside.
This is equivalent to whether $\hat x$ lies below or above the plane $z = 2 m \cdot x - \|m\|^2 + \rho^2$ through $\hat a, \hat b, \hat c$.
Thus “point $q$ is inside the circumcircle” is equivalent to “$\hat q$ lies below the plane of the three lifted points,” and `incircle` is precisely the orientation predicate of the four lifted points.
Projecting the lower facets of the lifted convex hull (visible from the negative direction of the last coordinate) onto $\mathbb{R}^d$ gives a Delaunay triangulation, because their simplices' circumspheres contain no other sites.

`Delaunay` applies the same incremental algorithm as the convex hull to this lifting and selects lower facets as simplices.
With exactly $d+1$ sites, that single simplex is the triangulation.
When at least $d+2$ sites lie on one sphere with no other sites inside, a lower face is nonsimplicial and the triangulation is not unique.
Even if sites lie on the same sphere, another site inside it prevents them from being vertices of the same Delaunay simplex, so they do not affect uniqueness.
`Deterministic` chooses one triangulation by symbolic perturbation; `Strict` rejects when the unperturbed lifted determinant of two adjacent simplices is zero (they share an empty circumsphere).

Each simplex's circumcenter and barycentric coordinates come from a rounded affine map constructed once with `f64` during construction.
For thin simplices with ill-conditioned maps, only circumcenter, barycentric-coordinate, and gradient queries on that simplex return `NumericalInstability`; the triangulation's combinatorial structure remains usable.
[Point location and barycentric coordinates in Delaunay triangulations](../point-location/) covers locating containing simplices, barycentric coordinates and piecewise-linear interpolation, and map conditioning tests.

`simplex_count()` and `simplex(s)` return the simplex count and vertices of simplex $s$ (canonical indices in increasing order); `simplices()` returns a reference to all simplex vertices as a flat sequence with $d+1$ entries per simplex.
`neighbors(s)` returns the simplex sharing the face opposite each vertex of simplex $s$, or `None` if that face lies on the convex-hull boundary.
`circumcenter_into(s, &mut output)` writes simplex $s$'s circumcenter; `incident_simplices(v)` returns simplices containing site $v$ in increasing order.
`point_set()` returns in $O(1)$ time a reference to sites as a `PointSet` that can be passed to `KdTree`.
`triangle_mesh()` and `tetrahedron_mesh()` convert planar and three-dimensional triangulations to positively oriented `TriangleMesh` and `TetrahedronMesh`, with vertices in sorted site order.
A dimension mismatch returns `InvalidInput`.

## Voronoi diagrams and duality

The Voronoi region of site $p_i$ is:

$$
V_i = \{ x \in \mathbb{R}^d : \|x - p_i\| \le \|x - p_j\| \ \forall j \}
$$

A Delaunay simplex's circumcenter is equidistant from its $d+1$ sites, with no other site closer, so it is a Voronoi vertex.
Connecting neighboring simplex circumcenters gives Voronoi ridges; outward rays extend from circumcenters of simplices with faces on the convex-hull boundary.
`Voronoi::new` constructs a Delaunay triangulation and assembles its dual Voronoi diagram.
Access the triangulation with `delaunay()`.

For cocircular or cospherical configurations, adjacent simplices on the same unperturbed sphere are grouped and assigned one Voronoi vertex per group.
Four planar points on one circle yield one vertex for two triangles.
The vertex coordinates are the circumcenter of the lowest-index simplex in the group having an affine map.
Circumcenters of other simplices in the group are rounded versions of the same point computed by different paths, so they agree only within rounding error.
`simplex_vertices()[s]` returns the Voronoi-vertex index of simplex $s$.

- `vertex_count()` and `vertex(i)` return the vertex count and coordinates.
  `vertices()` returns all vertex coordinates, or `NumericalInstability` if any vertex's coordinates cannot be computed.
- `ridges()` returns `VoronoiRidge` ordered by site pairs.
  `sites()` returns the two sites whose regions share a ridge (in increasing order), `vertices()` the ridge's Voronoi vertices, and `is_unbounded()` whether the ridge extends to infinity.
  Delaunay edges corresponding to diagonals within a cocircular group have no ridge.
- `rays()` returns `VoronoiRay` ordered by the lowest-index simplex with the corresponding convex-hull face, then by opposite-vertex index.
  `vertex()` is the initial Voronoi vertex, `sites()` the sites equidistant from every point on the ray (at least $d$ sites on the convex-hull face, in increasing order), and `direction()` the rounded outward unit vector.
  Convex-hull facets on the same hyperplane with the same Voronoi vertex merge into one ray.
  For a ray whose direction cannot be computed reliably, `direction()` returns `NumericalInstability`.
- `region_vertices(site)` iterates over a region's Voronoi vertices in increasing index order, not angular order.
- `region_is_unbounded(site)` returns whether a region is unbounded in $O(1)$ time, true exactly for sites on the convex-hull boundary.

## Spherical Voronoi diagrams

`SphericalVoronoi::new(&points, center, radius, tolerance)` constructs the geodesic-distance Voronoi diagram of sites on a sphere with center $c$ and radius $r$.
Each site must satisfy $\big|\,\|p - c\| - r\,\big| \le \tau$, where $\tau$ is the threshold of `tolerance` at $r$.
Sites without three coordinates give `DimensionMismatch`; NaN or infinity in `center` gives `NonFinite`.
A radius that is not finite and positive, a site off the sphere, or duplicate sites under `Strict` give `InvalidInput`.

Construction builds the three-dimensional convex hull of sites in their original coordinates, determining the combinatorial structure with exact predicates on those coordinates.
The convex hull of points on a sphere is a spherical Delaunay triangulation.
Coordinates mapped to the unit sphere, $(p - c)/r$, are used only for sphere-membership tests, normals, and areas.
These coordinates retain the difference $p - c$ without rounding, divide by $r$, and round only once at the end, so the coordinates can be computed even when the difference is too large for `f64`.
If $n$ is the outward unit normal of each convex-hull face (merging coplanar facets), $c + r n$ is its dual Voronoi vertex.
`region(site)` returns a region's vertices in cyclic order; `neighbors(site)` returns sites sharing an arc in increasing order.
If a site lies inside the sphere within tolerance and therefore is not a convex-hull vertex, its region has fewer than three vertices, giving `InvalidInput`.

`areas()` sums a fan of spherical triangles formed by site $g$ and consecutive vertices $a$ and $b$, multiplies by $r^2$, and returns each region's area.
Each triangle's solid angle $\Omega$ is obtained by evaluating the Van Oosterom–Strackee formula on the unit sphere

$$
\tan\frac{\Omega}{2} = \frac{|g \cdot (a \times b)|}{1 + g \cdot a + a \cdot b + b \cdot g}
$$

in floating-point arithmetic.
Evaluation with `atan2` retains accuracy for both small triangles and triangles close to a hemisphere.
A region or area that cannot be computed reliably returns `NumericalInstability`.
The total area equals $4\pi r^2$ within rounding error.
[Angular-distance neighbor search in a star catalog](../../examples/celestial-neighbor-search/) checks total area and largest and smallest regions in a celestial Voronoi diagram with bright stars as sites.

## Checking duality on lattice points

A $g \times g$ lattice is a typical degenerate configuration: each four neighboring points lie on one circle.
The next cell constructs `Voronoi` and `ConvexHull` from lattice sites with the default `Deterministic`, counts their elements, and compares with theoretical values.
Input row $p$ is lattice point $(p \bmod g,\ \lfloor p/g \rfloor)$, with spacing 1.
Selecting “Perturb coordinates” shifts each coordinate by less than $1/256$ using the fractional part of $k = (p+1)^2$ times a constant close to an irrational number.
Shifts proportional to $p$ can align with the lattice columns and leave three points exactly collinear, so the square of $p$ is used.

For a planar triangulation, Euler's relation gives $T = 2n - b - 2$ triangles (where $b$ is the number of Delaunay edges on the convex-hull boundary) and $(3T + b)/2$ edges.
On the lattice, the two triangles of each square share one Voronoi vertex, and square diagonals have no Voronoi ridge.
The empty-circle property is checked independently by ordering each triangle's vertices counterclockwise and classifying all other sites with `incircle`.
The table places measured and predicted counts side by side for each element; rows without prediction formulas for the perturbed configuration show “No prediction.”

```rust
//| id: spatial-delaunay-voronoi-duality
//| ref: spatial-delaunay-voronoi-duality
//| title: "Count elements of a lattice Delaunay triangulation and Voronoi diagram and compare with theoretical values"
//| run: reactive
//| crates: [scioxide-spatial]
//| inputs:
//|   grid_side: {"type":"range","label":"Points per lattice side g","description":"Sites form a g × g lattice with spacing 1.","min":3,"max":9,"step":1,"value":5}
//|   perturb: {"type":"checkbox","label":"Perturb coordinates to remove cocircularity","description":"Shift each coordinate by a fixed amount less than 1/256.","value":false}
//| cases:
//|   - {"id":"perturbed","label":"Perturbed lattice","description":"Cocircularity disappears, giving one Voronoi vertex per triangle.","inputs":{"perturb":true}}
//|   - {"id":"perturbed-large","label":"Perturbed 9 × 9 lattice","description":"Even at g = 9, no cocircularity remains, and measured counts agree with predictions from Euler's relation.","inputs":{"grid_side":9,"perturb":true}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"counts","path":"/rows/2/1","equals":4}
//|       - {"artifact":"counts","path":"/rows/3/1","equals":32}
//|       - {"artifact":"counts","path":"/rows/5/1","equals":32}
//|       - {"artifact":"counts","path":"/rows/6/1","equals":16}
//|       - {"artifact":"counts","path":"/rows/7/1","equals":40}
//|   - case: perturbed
//|     expect:
//|       - {"artifact":"counts","path":"/rows/1/1","equals":11}
//|       - {"artifact":"counts","path":"/rows/2/1","equals":11}
//|       - {"artifact":"counts","path":"/rows/3/1","equals":37}
//|       - {"artifact":"counts","path":"/rows/5/1","equals":0}
//|       - {"artifact":"counts","path":"/rows/7/1","equals":61}
//|   - case: perturbed-large
//|     expect:
//|       - {"artifact":"counts","path":"/rows/3/1","equals":148}
//|       - {"artifact":"counts","path":"/rows/4/1","equals":0}
//|       - {"artifact":"counts","path":"/rows/5/1","equals":0}
use scioxide_spatial::{ConvexHull, PointSet, PredicateSign, Voronoi, incircle, orient2d};

let g = grid_side as usize;
let n = g * g;
// Input row p is lattice point (p mod g, ⌊p/g⌋).
// For perturbation, the fractional part of k = (p + 1)² times a constant close to an irrational number determines a shift below 1/256.
let mut sites = Vec::with_capacity(n);
for p in 0..n {
    let (mut dx, mut dy) = (0.0, 0.0);
    if perturb {
        let k = (p as f64 + 1.0) * (p as f64 + 1.0);
        dx = ((k * 0.754_877_666_246_692_7).fract() - 0.5) / 128.0;
        dy = ((k * 0.569_840_290_998_053_3).fract() - 0.5) / 128.0;
    }
    sites.push([(p % g) as f64 + dx, (p / g) as f64 + dy]);
}
let points = PointSet::from_points(&sites).map_err(|e| e.to_string())?;
let voronoi = Voronoi::new(&points).map_err(|e| e.to_string())?;
let hull = ConvexHull::new(&points).map_err(|e| e.to_string())?;

let delaunay = voronoi.delaunay();
let coordinates = delaunay.points();
let site = |v: usize| [coordinates[2 * v], coordinates[2 * v + 1]];
let (mut inside, mut on_circle, mut b) = (0_usize, 0_usize, 0_usize);
for s in 0..delaunay.simplex_count() {
    let v = delaunay.simplex(s).map_err(|e| e.to_string())?;
    let across = delaunay.neighbors(s).map_err(|e| e.to_string())?;
    b += across.iter().filter(|x| x.is_none()).count();
    // Order vertices counterclockwise and classify other sites with exact incircle (independent check).
    let (a, mut p, mut q) = (site(v[0]), site(v[1]), site(v[2]));
    if orient2d(&a, &p, &q).map_err(|e| e.to_string())? == PredicateSign::Negative {
        core::mem::swap(&mut p, &mut q);
    }
    for other in (0..n).filter(|d| !v.contains(d)) {
        match incircle(&a, &p, &q, &site(other)).map_err(|e| e.to_string())? {
            PredicateSign::Positive => inside += 1,
            PredicateSign::Zero => on_circle += 1,
            PredicateSign::Negative => {}
        }
    }
}

let t = delaunay.simplex_count();
let mut bounded = 0;
for s in 0..n {
    bounded += usize::from(!voronoi.region_is_unbounded(s).map_err(|e| e.to_string())?);
}
// Prediction: counts per square on the lattice; values from Euler's relation for the perturbed configuration.
let (squares, inner) = ((g - 1) * (g - 1), (g - 2) * (g - 2));
let pick = |grid: usize, generic: usize| Some(if perturb { generic } else { grid });
let grid_only = |grid: usize| (!perturb).then_some(grid);
let edges = (3 * t + b) / 2;
let rows: Vec<(&str, usize, Option<usize>, &str)> = vec![
    ("Sites n", n, Some(g * g), "g²"),
    (
        "Delaunay edges on hull b",
        b,
        grid_only(4 * (g - 1)),
        "4(g − 1), none",
    ),
    (
        "ConvexHull facets",
        hull.facet_count(),
        pick(4, b),
        "4, b",
    ),
    ("Triangles T", t, Some(2 * n - b - 2), "2n − b − 2"),
    ("Sites inside circumcircles", inside, Some(0), "0 (empty-circle property)"),
    (
        "Other sites on circumcircles",
        on_circle,
        grid_only(2 * squares),
        "2(g − 1)², none",
    ),
    (
        "Voronoi vertices",
        voronoi.vertex_count(),
        pick(squares, t),
        "(g − 1)², T",
    ),
    (
        "Voronoi ridges",
        voronoi.ridges().len(),
        pick(2 * g * (g - 1), edges),
        "2g(g − 1), (3T + b)/2",
    ),
    ("Rays", voronoi.rays().len(), Some(b), "b"),
    ("Bounded regions", bounded, pick(inner, n - b), "(g − 2)², n − b"),
];
let columns = serde_json::json!([
    { "key": "0", "label": "Element counted" },
    { "key": "1", "label": "Measured [count]", "type": "integer" },
    { "key": "2", "label": "Predicted [count]", "type": "integer", "nullText": "No prediction" },
    { "key": "3", "label": "Prediction formula (lattice, perturbed configuration)" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "counts" })
);
```

With defaults ($g = 5$, unperturbed lattice), the convex-hull boundary has $b = 16$ Delaunay edges and there are $T = 2 \cdot 25 - 16 - 2 = 32$ triangles.
The `ConvexHull` facets are only the square's four edges; the 12 sites along edge interiors are not extreme points and do not become vertices.
No triangle contains another site inside its circumcircle.
Each triangle has exactly one other site on its circumcircle (the square's remaining corner), giving a count of 32, equal to the triangle count.
There are 16 Voronoi vertices, one per square, and 40 ridges, matching lattice edges; square diagonals have no ridges.

For “Perturbed lattice,” the count of sites on circumcircles becomes 0, and the Voronoi-vertex count equals the 37 triangles.
There are $(3T + b)/2 = 61$ ridges, with every Delaunay edge producing a ridge.
Perturbation moves some sites formerly along hull-edge interiors inward; $b$ decreases from 16 to 11, matching the number of `ConvexHull` facets.
For $g$ from 3 to 9, measured and predicted table values agree for both the unperturbed lattice and perturbed configurations, and perturbed configurations have 0 other sites on circumcircles.

## Summary

Read convex-hull, Delaunay, Voronoi, and spherical Voronoi results using sorted sites' canonical indices, and return to input data through index mappings.
`ConvexHull` and `Delaunay` have `input_mapping()` and `representatives()`; `Voronoi` uses the same mappings through `delaunay()`, while `SphericalVoronoi` has only `input_mapping()`.
Exact predicates determine the combinatorial structure; the default `Deterministic` resolves cocircular and cospherical ties into one triangulation by symbolic perturbation, and the Voronoi diagram merges each group into one vertex.
Circumcenters, Voronoi vertices, ray directions, and spherical areas are rounded values; handle queries returning `NumericalInstability` separately while continuing to use the combinatorial structure.
