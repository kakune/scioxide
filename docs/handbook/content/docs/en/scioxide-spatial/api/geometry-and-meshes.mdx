This table groups items representing structured grids and simplex meshes in one to three dimensions and fields on them.
Indices are ordered with axis 0 varying fastest; index $[x, y, z]$ in extent $[n_x, n_y, n_z]$ has linear position $x + n_x (y + n_y z)$.
Structured-grid connectivity comes from integer indices, without adjacency tables.
Simplex meshes store explicit connectivity and validate orientation and manifold connectivity during construction, but do not check global self-intersection (embedding).
Field/mesh combinations are checked in `MeshToken` and return `InvalidInput` for mismatched revisions.

## Summary

A structured grid is a Cartesian product of coordinate axes; connectivity is computed from indices in $O(1)$ without adjacency-table storage.
Simplex meshes validate orientation and connectivity during construction and name boundaries with `SimplexBoundaryTags`.
Fields carry location types (vertex, cell, face, edge) and their construction revision; combining with a different mesh revision gives `InvalidInput`.
Periodic seams pair two faces; access the partner through `Periodic` of `face_topology`.
[Foundations of points, ranges, grids, and meshes](../../algorithms/geometry-grids-and-meshes/) explains grids and fields; [Adaptive mesh API](../adaptive-meshes/) covers refined meshes.
