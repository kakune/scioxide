This table groups determinant-sign predicates and tessellations whose combinatorial structure uses those predicates.
Predicates establish signs through floating-point filters and otherwise compute exactly, returning correct signs for the supplied finite values.
Convex hulls, Delaunay triangulations, Voronoi diagrams, and spherical Voronoi diagrams sort sites lexicographically, merge coincident sites, and return canonical indices.
`ConvexHull` and `Delaunay` map to input rows with `input_mapping` and `representatives`; `Voronoi` accesses these through `delaunay()`, while `SphericalVoronoi` has only `input_mapping`.
Circumcenters, barycentric coordinates, vertex coordinates, and areas are constructed values involving rounding.
For Delaunay and Voronoi structures, only methods returning values that cannot be computed reliably give `NumericalInstability`.
Halfspace intersections certify each vertex's error during construction; spherical Voronoi diagrams compute regions and areas during construction.
For these two, any failed certification or computation makes the entire construction give `NumericalInstability`.

## Summary

Predicate signs are correct for represented input floating-point numbers; `Zero` means an exactly zero determinant.
Exact signs determine tessellation topology; ties use symbolic perturbation in sorted-site order (`Strict` rejects duplicate sites and nonunique triangulation inputs with `InvalidInput`).
Tessellation indices are canonical indices; return to input rows through `input_mapping` and `representatives` (`Voronoi` uses `delaunay()`).
Only halfspace-intersection vertices have certified construction-error bounds; check other constructed values against independent calculations.
Limit construction resources with `GeometryLimits` and inspect used work with `GeometryProvenance`.
See [Exact geometric predicates](../../algorithms/exact-predicates/) for sign determination and [Convex hulls, Delaunay triangulations, and Voronoi diagrams](../../algorithms/delaunay-voronoi-and-hulls/) and [Halfspace intersection](../../algorithms/halfspace-intersection/) for constructing tessellations and intersections.
