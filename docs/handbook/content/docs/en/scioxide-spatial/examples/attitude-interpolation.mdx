When a spacecraft changes orientation through successive targets, timed target orientations (key orientations) are supplied and its attitude-control system follows an interpolated trajectory between them.
An angular-velocity jump requires a torque impulse to realize it.
This example converts yaw–pitch–roll key orientations to `Rotation`, interpolates with `Slerp` and `RotationSpline`, and compares angular velocity and acceleration.
It also moves key pitch toward 90° to examine Euler-angle conversion.

## Orientation kinematics and required torque

Representing body orientation relative to an inertial frame by rotation $R(t)$ defines body-frame angular velocity $\omega$ [rad/s] through

$$
\dot R = R\,\hat\omega
$$

where $\hat\omega$ is the cross-product matrix of $\omega$.
For a rigid body with constant inertia tensor $I$, the torque required to follow an orientation trajectory is determined by Euler's equation of motion:

$$
\tau = I\,\dot\omega + \omega \times (I\,\omega)
$$

$\tau$ is linear in angular acceleration $\alpha = \dot\omega$ but quadratic in $\omega$.
A jump in $\omega$ creates a delta-function impulse in $\tau$; a jump in $\alpha$ creates a jump in $\tau$.
A trajectory with continuous $\omega$ and $\alpha$ therefore also has continuous $\tau$.

## Specifying key orientations

Supply key orientations as intrinsic Z-Y-X Euler angles used in aerospace: yaw $\psi$, pitch $\theta$, and roll $\phi$:

$$
R = R_z(\psi)\,R_y(\theta)\,R_x(\phi)
$$

`EulerSequence::new([Z, Y, X], EulerFrame::Intrinsic)` specifies this sequence and `Rotation::from_euler` constructs rotations from angles [rad].
Place $K$ keys at times $t_k = 10k$ s ($k = 0, \ldots, K - 1$), using yaw turn $A$ and pitch $P$ to define the key angles:

$$
\psi_k = A\,\frac{k}{K - 1}, \qquad
\theta_k = P \sin\frac{\pi k}{K - 1}, \qquad
\phi_k = (-1)^k\,\frac{A}{4}
$$

Yaw turns at a constant rate from $0$ to $A$; pitch is 0 at both ends and reaches maximum $P$ at the center; roll alternates direction.
For odd $K$, central-key pitch is exactly $P$, giving a gimbal-locked orientation at $P = 90°$.

When $\lvert\cos\theta\rvert$ for the pitch is at most the tolerance threshold ($2\sqrt\varepsilon \approx 2.98 \times 10^{-8}$ for `Tolerance::from_sqrt_epsilon()`), `Rotation::as_euler` sets `gimbal_lock` true, sets roll to 0, and puts the determined combination into yaw (difference $\psi - \phi$ for pitch +90°, sum $\psi + \phi$ for −90°).
Even before lock, yaw and roll errors are amplified to $\varepsilon/\lvert\cos\theta\rvert$.
[Angle ranges and gimbal lock](oxref:spatial-gimbal-lock) gives the derivation.

The following block defines quantities shared by two cells.
`yaw_pitch_roll` gives intrinsic Z-Y-X, `key_angles` the key angles [deg] above, and `key_rotations` key times and rotations.
`distance` is rotation distance $d(R_a, R_b) = \angle(R_a^{-1}R_b)$ [rad]; `norm3` is the Euclidean norm of a three-component vector.

```rust
//| id: spatial-attitude-keys
//| kind: definitions
//| title: "Key orientations from intrinsic Z-Y-X Euler angles"
//| crates: [scioxide-core, scioxide-spatial]
use scioxide_core::{SciOxideError, RealScalar};
use scioxide_spatial::{EulerFrame, EulerSequence, Rotation, RotationAxis};

/// Key spacing Δt [s].
pub(crate) const KEY_SPACING: f64 = 10.0;

/// Intrinsic Z-Y-X yaw–pitch–roll sequence.
pub(crate) fn yaw_pitch_roll() -> Result<EulerSequence, SciOxideError> {
    let axes = [RotationAxis::Z, RotationAxis::Y, RotationAxis::X];
    EulerSequence::new(axes, EulerFrame::Intrinsic)
}

/// Key k angles (ψ, θ, φ) [deg]: ψ = A k/(K−1), θ = P sin(πk/(K−1)), φ = (−1)^k A/4.
pub(crate) fn key_angles(count: usize, slew: f64, pitch: f64) -> Vec<[f64; 3]> {
    let last = (count - 1) as f64;
    (0..count)
        .map(|k| {
            let s = k as f64 / last;
            let sign = if k % 2 == 0 { 1.0 } else { -1.0 };
            let theta = pitch * RealScalar::sin(<f64 as RealScalar>::PI * s);
            [slew * s, theta, sign * slew / 4.0]
        })
        .collect()
}

/// Key times t_k = k Δt [s] and rotations.
pub(crate) fn key_rotations(
    count: usize,
    slew: f64,
    pitch: f64,
) -> Result<(Vec<f64>, Vec<Rotation<f64>>), SciOxideError> {
    let sequence = yaw_pitch_roll()?;
    let times = (0..count).map(|k| KEY_SPACING * k as f64).collect();
    let rotations = key_angles(count, slew, pitch)
        .into_iter()
        .map(|a| Rotation::from_euler(sequence, a.map(RealScalar::to_radians)))
        .collect::<Result<Vec<_>, _>>()?;
    Ok((times, rotations))
}

/// Rotation distance d(a, b) = ∠(a⁻¹ b) [rad].
pub(crate) fn distance(a: Rotation<f64>, b: Rotation<f64>) -> Result<f64, SciOxideError> {
    Ok(a.inverse().compose(b)?.as_axis_angle().1)
}

/// Euclidean norm of a three-component vector.
pub(crate) fn norm3(v: [f64; 3]) -> f64 {
    RealScalar::hypot(RealScalar::hypot(v[0], v[1]), v[2])
}
```

With defaults ($K = 5$, $A = 120°$, $P = 60°$), no key is classified as locked; recovered angles agree within $10^{-13}$ degrees and the largest rotation distance is $3.5 \times 10^{-16}$ rad.
At $P = 90°$, the central key ($t = 20$ s, $\psi = 60°$, $\phi = 30°$) gives `gimbal_lock` and recovered angles $(30°, 90°, 0°)$.
Yaw 30° is $\psi - \phi$; yaw and roll each differ by 30°, but rotation distance is $1.7 \times 10^{-16}$ rad, representing the same orientation.

This matches the order of amplification $1/\lvert\cos\theta\rvert \approx 115$ from $\cos 89.5° = 8.7 \times 10^{-3}$.

## Comparing Slerp and rotation splines

`Slerp` rotates at constant angular velocity $v_i/\Delta t$ on each interval, where $v_i$ is the rotation vector of relative rotation $R_i^{-1}R_{i+1}$.
Interval angular speed therefore equals the relative-rotation angle divided by $\Delta t$.
`RotationSpline` interpolates piecewise cubic rotation vectors, makes angular velocity continuous by construction, and satisfies angular-acceleration continuity to tolerance through fixed-point iteration.
Derivations are in [Spherical linear interpolation (Slerp)](oxref:spatial-slerp) and [Rotation splines](../../algorithms/rotation-spline/).

The next cell receives key count, turn angle, and pitch from the preceding cell and constructs `Slerp` on the same keys.
Table `slerp` shows the following for each interval.

- Relative-rotation angle $\angle(R_i^{-1}R_{i+1})$ [deg] and Slerp angular speed obtained by dividing by $\Delta t$.
- Angular speed from `Slerp::evaluate` rotations at interval fractions $1/4$ and $3/4$, dividing their distance by elapsed time.
  Constant angular velocity should agree with the value above.
- Angular-velocity-vector jump $\lvert\Delta\omega\rvert = \lvert v_i - v_{i-1}\rvert/\Delta t$ [deg/s] at the knot starting each interval.

Slerp acceleration is zero inside intervals and impulsive at knots.
This cell passes piecewise-constant angular speeds to the next cell as step-line points.

```rust
//| id: spatial-attitude-slerp
//| ref: spatial-attitude-slerp
//| title: "Slerp interval angular velocities and knot jumps"
//| run: reactive
//| uses: [spatial-attitude-keys]
//| crates: [scioxide-core, scioxide-spatial]
//| dependsOn:
//|   keys: spatial-attitude-euler-keys
//| exports: [slerp_curve]
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"slerp","path":"/rows/0/3","approx":{"value":8.5721531170,"atol":1e-8}}
//|       - {"artifact":"slerp","path":"/rows/0/4","approx":{"value":8.5721531170,"atol":1e-8}}
//|       - {"artifact":"slerp","path":"/rows/0/5","equals":null}
//|       - {"artifact":"slerp","path":"/rows/1/5","range":{"min":1}}
use scioxide_core::RealScalar;
use scioxide_spatial::Slerp;

let count = keys["key_count"].as_f64().ok_or("Missing key count")? as usize;
let slew = keys["slew"].as_f64().ok_or("Missing turn angle")?;
let pitch = keys["pitch"].as_f64().ok_or("Missing pitch")?;
let (times, rotations) = key_rotations(count, slew, pitch).map_err(|e| e.to_string())?;
let slerp = Slerp::new(&times, &rotations).map_err(|e| e.to_string())?;
let degrees = |x: f64| RealScalar::to_degrees(x);
let dt = KEY_SPACING;

// Angular-velocity vector v_i/Δt on interval i (v_i is the rotation vector of relative rotation R_i⁻¹ R_{i+1}).
let mut rates = Vec::new();
let mut slerp_curve = Vec::new();
for i in 0..count - 1 {
    let relative = rotations[i]
        .inverse()
        .compose(rotations[i + 1])
        .map_err(|e| e.to_string())?;
    rates.push(relative.as_rotation_vector().map(|x| x / dt));
    let speed = degrees(norm3(rates[i]));
    slerp_curve.push([times[i], speed]);
    slerp_curve.push([times[i + 1], speed]);
}

let mut rows = Vec::new();
for i in 0..count - 1 {
    let angle = degrees(norm3(rates[i]) * dt);
    // Divide the Slerp rotation distance at interval fractions 1/4 and 3/4 by elapsed time.
    let (ta, tb) = (times[i] + 0.25 * dt, times[i] + 0.75 * dt);
    let ra = slerp.evaluate(ta).map_err(|e| e.to_string())?;
    let rb = slerp.evaluate(tb).map_err(|e| e.to_string())?;
    let measured = degrees(distance(ra, rb).map_err(|e| e.to_string())?) / (tb - ta);
    let change = |a: [f64; 3], b: [f64; 3]| norm3([a[0] - b[0], a[1] - b[1], a[2] - b[2]]);
    let jump = (i > 0).then(|| degrees(change(rates[i], rates[i - 1])));
    rows.push((times[i], times[i + 1], angle, angle / dt, measured, jump));
}

let seconds = serde_json::json!({ "fractionDigits": 0 });
let fixed4 = serde_json::json!({ "significantDigits": 4 });
let columns = serde_json::json!([
    { "key": "0", "label": "Start t_i [s]", "type": "number", "format": seconds },
    { "key": "1", "label": "End t_{i+1} [s]", "type": "number", "format": seconds },
    { "key": "2", "label": "Relative-rotation angle [deg]", "type": "number", "format": fixed4 },
    { "key": "3", "label": "|ω| = angle/Δt [deg/s]", "type": "number", "format": fixed4 },
    { "key": "4", "label": "|ω|（evaluate）[deg/s]", "type": "number", "format": fixed4 },
    { "key": "5", "label": "Initial |Δω| [deg/s]", "type": "number", "format": fixed4, "nullText": "—" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "slerp" })
);
export!(slerp_curve, &slerp_curve);
```

With defaults ($K = 5$, $A = 120°$, $P = 60°$), relative-rotation angles across four intervals are 85.7°, 43.9°, 86.9°, and 68.5°, giving Slerp speeds 8.57, 4.39, 8.69, and 6.85 deg/s after division by 10 s.
Differences from values obtained using `evaluate` are at most $10^{-14}$ deg/s, confirming constant angular velocity inside each interval.
Slerp angular-velocity vectors jump by 10.7–13.0 deg/s at knots.
A rigid body following this trajectory needs torque impulses at every knot.

The next cell constructs `RotationSpline` on the same keys.
The fixed-point iteration limit is an input, defaulting to 32.
Continuity tolerance uses default relative part $\sqrt\varepsilon$ with no absolute part, making the test independent of time units.
The upper chart shows angular speed $\lvert\omega\rvert$ [deg/s] overlaid on the preceding cell's Slerp steps.
The lower chart shows spline angular-acceleration magnitude $\lvert\alpha\rvert$ [deg/s²]; the time axes are linked and vertical lines mark knots.
Table `intervals` shows each interval's largest spline $\lvert\omega\rvert$ and $\lvert\alpha\rvert$ (sampled every 0.1 s) and angular-acceleration jump $\lvert\Delta\alpha\rvert$ at its initial knot.
Jumps are differences between left limits extrapolated quadratically from three left-side points (spacing $h = 10^{-2}$ s) and knot values (truncation error $O(h^3)$).
Finally, an outcome reports spline termination status.

```rust
//| id: spatial-attitude-interpolation
//| ref: spatial-attitude-interpolation
//| title: "Compare a rotation spline's angular velocity and acceleration with Slerp"
//| run: reactive
//| uses: [spatial-attitude-keys]
//| crates: [scioxide-core, scioxide-spatial]
//| dependsOn:
//|   keys: spatial-attitude-euler-keys
//|   slerp: spatial-attitude-slerp
//| inputs:
//|   iteration_limit: {"type":"range","label":"Fixed-point iteration limit [iterations]","description":"Default: 32 iterations.","min":0,"max":32,"step":1,"value":32}
//| cases:
//|   - {"id":"too-few-iterations","label":"Iteration limit 2","description":"Continuity tolerance is not reached and no spline is returned.","inputs":{"iteration_limit":2}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"intervals","path":"/rows/1/4","range":{"max":1e-5}}
//|       - {"artifact":"intervals","path":"/rows/2/2","range":{"min":10}}
//|       - {"path":"/outputs/3/state","equals":"satisfied"}
//|   - case: too-few-iterations
//|     expect:
//|       - {"artifact":"intervals","path":"/rows/1/4","equals":null}
//|       - {"path":"/outputs/2/state","equals":"failed"}
use scioxide_core::RealScalar;
use scioxide_spatial::{
    RotationSpline, RotationSplineOptions, RotationSplineSample, RotationSplineTermination,
};

let count = keys["key_count"].as_f64().ok_or("Missing key count")? as usize;
let slew = keys["slew"].as_f64().ok_or("Missing turn angle")?;
let pitch = keys["pitch"].as_f64().ok_or("Missing pitch")?;
let slerp_curve = slerp["slerp_curve"].clone();
let (times, rotations) = key_rotations(count, slew, pitch).map_err(|e| e.to_string())?;
let options = RotationSplineOptions::new().with_max_iterations(iteration_limit as usize);
let result =
    RotationSpline::with_options(&times, &rotations, options).map_err(|e| e.to_string())?;
let degrees = |x: f64| RealScalar::to_degrees(x);

// Samples every 0.1 s and interval maxima.
let (mut speed, mut acceleration) = (Vec::new(), Vec::new());
let mut peaks = vec![(0.0_f64, 0.0_f64); count - 1];
if let Some(spline) = &result.spline {
    let samples = 100 * (count - 1);
    for j in 0..=samples {
        let t = 0.1 * j as f64;
        let s = spline.evaluate(t).map_err(|e| e.to_string())?;
        let (w, a) = (
            degrees(norm3(s.angular_velocity)),
            degrees(norm3(s.angular_acceleration)),
        );
        speed.push([t, w]);
        acceleration.push([t, a]);
        let i = (j / 100).min(count - 2);
        peaks[i] = (peaks[i].0.max(w), peaks[i].1.max(a));
    }
}
// Left limit at knot t: quadratic extrapolation from three left-side points, 3a(t − h) − 3a(t − 2h) + a(t − 3h).
let h = 1e-2;
let left_acceleration = |spline: &RotationSpline<f64>, t: f64| -> Result<[f64; 3], String> {
    let at = |j: f64| -> Result<RotationSplineSample<f64>, String> {
        spline.evaluate(t - j * h).map_err(|e| e.to_string())
    };
    let (s1, s2, s3) = (at(1.0)?, at(2.0)?, at(3.0)?);
    Ok([0, 1, 2].map(|m| {
        3.0 * s1.angular_acceleration[m] - 3.0 * s2.angular_acceleration[m]
            + s3.angular_acceleration[m]
    }))
};

let mut rows = Vec::new();
for i in 0..count - 1 {
    let mut jump = None;
    if let (Some(spline), true) = (&result.spline, i > 0) {
        let left = left_acceleration(spline, times[i])?;
        let right = spline.evaluate(times[i]).map_err(|e| e.to_string())?;
        let a = right.angular_acceleration;
        let difference = [0, 1, 2].map(|m| a[m] - left[m]);
        jump = Some(degrees(norm3(difference)));
    }
    let peak = result.spline.as_ref().map(|_| peaks[i]);
    rows.push((
        times[i],
        times[i + 1],
        peak.map(|p| p.0),
        peak.map(|p| p.1),
        jump,
    ));
}

let knot_lines: Vec<serde_json::Value> = (1..count - 1)
    .map(|k| serde_json::json!({ "kind": "line", "axis": "x", "value": times[k] }))
    .collect();
let end = times[count - 1];
// Draw only Slerp when no spline is returned.
let mut speed_layers = vec![serde_json::json!({
    "id": "slerp",
    "kind": "line",
    "name": "Slerp",
    "points": slerp_curve
})];
if result.spline.is_some() {
    speed_layers.push(serde_json::json!({
        "id": "spline",
        "kind": "line",
        "name": "Rotation spline",
        "points": speed
    }));
}
emit_chart!(serde_json::json!({
    "kind": "xy",
    "link": { "group": "attitude-time" },
    "dataZoom": true,
    "tooltip": true,
    "xLabel": "Time t [s]",
    "yLabel": "Angular-speed magnitude |ω| [deg/s]",
    "xMin": 0.0,
    "xMax": end,
    "layers": speed_layers,
    "annotations": knot_lines
}));
if result.spline.is_some() {
    emit_chart!(serde_json::json!({
        "kind": "xy",
        "link": { "group": "attitude-time" },
        "dataZoom": true,
        "tooltip": true,
        "xLabel": "Time t [s]",
        "yLabel": "Angular-acceleration magnitude |α| [deg/s²]",
        "xMin": 0.0,
        "xMax": end,
        "layers": [
            { "id": "spline", "kind": "line", "name": "Rotation spline", "points": acceleration }
        ],
        "annotations": knot_lines
    }));
}
let seconds = serde_json::json!({ "fractionDigits": 0 });
let fixed4 = serde_json::json!({ "significantDigits": 4 });
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let columns = serde_json::json!([
    { "key": "0", "label": "Start t_i [s]", "type": "number", "format": seconds },
    { "key": "1", "label": "End t_{i+1} [s]", "type": "number", "format": seconds },
    { "key": "2", "label": "Maximum |ω| [deg/s]", "type": "number", "format": fixed4, "nullText": "—" },
    { "key": "3", "label": "Maximum |α| [deg/s²]", "type": "number", "format": fixed4, "nullText": "—" },
    { "key": "4", "label": "Initial |Δα| [deg/s²]", "type": "number", "format": sci2, "nullText": "—" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "intervals" })
);

let outcome = match result.termination {
    RotationSplineTermination::Converged => {
        Outcome::satisfied("Angular-acceleration jumps meet continuity tolerance at every internal knot")
    }
    RotationSplineTermination::IterationLimit => Outcome::failed(
        "Angular-acceleration jumps did not meet tolerance within the iteration limit; no spline is returned",
    )
    .explanation("Increase the iteration limit or add more closely spaced key orientations."),
};
emit_outcome!(
    outcome
        .status(format!("{:?}", result.termination))
        .diagnostic("Fixed-point iteration count", result.iterations as f64, None)
        .diagnostic("Continuity residual", result.continuity_residual, Some("rad/s²"))
);
```

With defaults, `RotationSpline::with_options` reaches `Converged` after five fixed-point iterations; the continuity residual (largest internal-knot angular-acceleration jump) is $1.1 \times 10^{-9}$ rad/s².
Spline $\lvert\omega\rvert$ varies continuously over 1.8–11.2 deg/s, reaching 11.2 deg/s near $t = 25$ s, above Slerp's maximum 8.69 deg/s.
Making velocity continuous changes speed inside intervals.
Interval maxima of $\lvert\alpha\rvert$ are 2.6–3.2 deg/s²; knot jumps are comparable to extrapolation truncation error (at most $1.0 \times 10^{-7}$ deg/s²).
An iteration limit of two gives `IterationLimit` with residual $4.7 \times 10^{-5}$ rad/s²; the outcome is `failed` and spline table entries are empty.

## Summary

Convert Euler-angle orientations to rotations with `Rotation::from_euler`, then interpolate and compare as rotations.
Conversion back with `as_euler` amplifies yaw and roll errors by $1/\lvert\cos\theta\rvert$ near pitch 90°; if `gimbal_lock` is true, only yaw–roll difference (sum at pitch −90°) is meaningful.
`Slerp` has constant interval angular speed equal to relative-rotation angle divided by $\Delta t$, with knot jumps requiring torque impulses for a rigid body following it.
`RotationSpline` makes angular velocity and angular acceleration continuous, hence required torque $\tau = I\alpha + \omega \times I\omega$ for a rigid body with constant inertia is continuous too, while angular speed varies within intervals.
Splines are returned only for `Converged`; if the outcome is `failed`, increase the iteration limit or revise key orientations.
