Finite-volume methods count mass from cell averages, orientation calculations assume rotations preserve dimensions, and finite elements assume element interpolation reproduces linear fields exactly.
This example checks these three assumptions against analytic solutions, showing rounding-scale preservation of cell-average mass, rotated lengths, and barycentric linear-field interpolation.
Only the midpoint-rule mass substitute included for comparison has discretization error, deviating from the analytic solution according to grid size.
Larger-than-rounding differences in cell averages, rotations, or interpolation indicate incorrect inputs or API use.

## Nonuniform-grid cell averages and rod mass

Let a 1 m rod have linear density $\rho(x) = \rho_0 x^2$ ($\rho_0 = 1$ kg/m³, $x$ [m]).
Partitioning interval $[0, 1]$ by $x_i = (i/n)^p$ gives a grid refined toward the origin for $p > 1$.
The mean density of cell $[x_i, x_{i+1}]$ is

$$
\bar{\rho}_i = \frac{1}{x_{i+1} - x_i}\int_{x_i}^{x_{i+1}} x^2\,dx = \frac{x_i^2 + x_i x_{i+1} + x_{i+1}^2}{3}
$$

and $\sum_i \bar{\rho}_i (x_{i+1} - x_i)$ agrees with rod mass $M = 1/3$ kg within rounding error.
Substituting midpoint density leaves midpoint-rule error $\sum_i h_i^3/12$ ($h_i = x_{i+1} - x_i$).
For uniform spacing ($p = 1$), this is $1/(12n^2)$.

The next cell constructs `SegmentMesh` from a nonuniform axis, stores cell averages in `CellField`, and compares sums using cell averages and midpoint densities.
`CellField` only associates values with cells; it neither computes averages nor guarantees conservation.
The table's mesh generation is `MeshToken::generation` of the field's mesh.
Generation increments for each revision changing geometry or topology and starts at 0 for a new mesh.
The plot shows stepwise cell averages and $\rho(x) = x^2$ (dashed).
The table shows mass minus analytic $1/3$ kg, midpoint-density differences, uniform-grid theoretical value $1/(12n^2)$, field-value count, and mesh generation.
The theoretical value is undefined for nonuniform grids, so the entry shows “p ≠ 1.”

```rust
//| id: spatial-cell-averages
//| ref: spatial-cell-averages
//| title: "Recover a rod's mass from cell averages on a nonuniform grid"
//| run: reactive
//| crates: [scioxide-spatial]
//| inputs:
//|   mesh_cells: {"type":"range","label":"Cell count n","min":16,"max":80,"step":8,"value":32}
//|   mesh_power: {"type":"range","label":"Grid grading exponent p [-]","min":1,"max":3,"step":0.25,"value":1.5}
//| cases:
//|   - {"id":"uniform","label":"p = 1","description":"Uniform spacing gives midpoint-rule error 1/(12n²).","inputs":{"mesh_power":1}}
//|   - {"id":"strong-grading","label":"p = 3","description":"Coarse cells near the end increase midpoint-rule error.","inputs":{"mesh_power":3}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"mass","path":"/rows/0/1","range":{"max":1e-15}}
//|       - {"artifact":"mass","path":"/rows/0/2","approx":{"value":1.1e-4,"rtol":0.05}}
//|       - {"artifact":"mass","path":"/rows/0/4","equals":32}
//|   - case: uniform
//|     expect:
//|       - {"artifact":"mass","path":"/rows/0/2","approx":{"value":8.138020833e-5,"rtol":1e-8}}
//|       - {"artifact":"mass","path":"/rows/0/3","approx":{"value":8.138020833e-5,"rtol":1e-8}}
//|   - case: strong-grading
//|     expect:
//|       - {"artifact":"mass","path":"/rows/0/1","range":{"max":1e-15}}
//|       - {"artifact":"mass","path":"/rows/0/2","approx":{"value":3.1e-4,"rtol":0.05}}
//|       - {"artifact":"mass","path":"/rows/0/3","equals":null}
use scioxide_spatial::{AxisTopology, CellField, CoordinateAxis, Grid1d, SegmentMesh};

let n = mesh_cells.round() as usize;
// Nodes x_i = (i/n)^p [m] (input generation uses inherent f64 methods).
let nodes: Vec<f64> = (0..=n)
    .map(|i| (i as f64 / n as f64).powf(mesh_power))
    .collect();
let axis = CoordinateAxis::explicit(nodes.clone()).map_err(|e| e.to_string())?;
let grid = Grid1d::new([axis], [AxisTopology::Bounded]).map_err(|e| e.to_string())?;
let mesh = SegmentMesh::new(grid).map_err(|e| e.to_string())?;

// Store analytically integrated cell-average density [kg/m] as a field associated with cells.
let averages: Vec<f64> = nodes
    .windows(2)
    .map(|p| (p[0] * p[0] + p[0] * p[1] + p[1] * p[1]) / 3.0)
    .collect();
let field = CellField::<f64, 1>::new(&mesh, averages).map_err(|e| e.to_string())?;
let mass: f64 = field
    .values()
    .iter()
    .zip(nodes.windows(2))
    .map(|(rho, p)| rho * (p[1] - p[0]))
    .sum();
let midpoint: f64 = nodes
    .windows(2)
    .map(|p| (0.5 * (p[0] + p[1])).powi(2) * (p[1] - p[0]))
    .sum();

// Cell averages are constant within cells; draw steps horizontally from each left endpoint to the next node.
let mut steps: Vec<[f64; 2]> = field
    .values()
    .iter()
    .zip(&nodes)
    .map(|(&rho, &x)| [x, rho])
    .collect();
steps.push([nodes[n], field.values()[n - 1]]);
let exact: Vec<[f64; 2]> = (0..=100)
    .map(|i| {
        let x = i as f64 / 100.0;
        [x, x * x]
    })
    .collect();
emit_line_chart!(
    &vec![
        serde_json::json!({
            "name": "Cell-average density",
            "points": steps,
            "style": { "step": "end" }
        }),
        serde_json::json!({
            "name": "ρ(x) = x²",
            "points": exact,
            "style": { "lineType": "dashed" }
        }),
    ],
    options = &serde_json::json!({ "xLabel": "Position x [m]", "yLabel": "Linear density ρ [kg/m]" })
);

let digits16 = serde_json::json!({ "significantDigits": 16 });
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let columns = serde_json::json!([
    { "key": "0", "label": "Mass from cell averages [kg]", "type": "number", "format": digits16 },
    { "key": "1", "label": "|Mass − 1/3| [kg]", "type": "number", "format": sci3 },
    { "key": "2", "label": "Midpoint-density |difference| [kg]", "type": "number", "format": sci3 },
    { "key": "3", "label": "1/(12n²) [kg]", "type": "number", "format": sci3, "nullText": "p ≠ 1" },
    { "key": "4", "label": "Field values [count]", "type": "integer" },
    { "key": "5", "label": "Mesh generation", "type": "integer" }
]);
// Theoretical midpoint-rule error 1/(12n²) is defined only for uniform spacing.
let uniform_error = (mesh_power == 1.0).then(|| 1.0 / (12.0 * (n * n) as f64));
let row = (
    mass,
    (mass - 1.0 / 3.0).abs(),
    (midpoint - 1.0 / 3.0).abs(),
    uniform_error,
    field.len(),
    field.mesh_token().generation().get(),
);
emit_table_with_columns!(
    columns,
    vec![row],
    metadata = serde_json::json!({ "id": "mass" })
);
```

With defaults $n = 32$ and $p = 1.5$, cell-average mass agrees with $1/3$ kg to the last digit, while midpoint-density mass differs by $1.1 \times 10^{-4}$ kg.
At “p = 1,” midpoint-rule error is $8.14 \times 10^{-5}$ kg, matching theoretical $1/(12n^2)$.
At “p = 3,” coarse end cells increase the error to $3.1 \times 10^{-4}$ kg.
Cell-average differences remain $5.6 \times 10^{-17}$ kg even at $p = 3$, with only summation rounding left.

## Length preservation and inverse rotation

Rotation matrix $R \in \mathrm{SO}(3)$ preserves lengths ($\|Rx\| = \|x\|$), and its inverse restores the original ($R^{-1}Rx = x$).
The next cell rotates 96 unit-circle points in the $xy$ plane through angle $\theta$ about axis $(a, 1, 0.5)$.
The axis of `Rotation::from_axis_angle` need not be unit length; its length does not affect results.
`Rotation::apply` constructs a rotation matrix with ordinary floating-point arithmetic and rounds each matrix-vector product component once from an exact sum of products.
The scene draws the original circle, rotated circle, and rotation axis, with circle radius as all three axes' unit.
The table shows rotation unit quaternion $[x, y, z, w]$, length change $\bigl|\|Rx\|^2 - 1\bigr|$, and the largest componentwise error after inverse rotation.

```rust
//| id: spatial-rotation-invariants
//| ref: spatial-rotation-invariants
//| title: "Vary the rotation axis and angle to check lengths and the inverse transformation"
//| run: reactive
//| crates: [scioxide-core, scioxide-spatial]
//| inputs:
//|   rotation_degrees: {"type":"range","label":"Rotation angle θ [deg]","min":-180,"max":180,"step":5,"value":60}
//|   axis_tilt: {"type":"range","label":"Rotation-axis x component a [-]","min":0,"max":2,"step":0.1,"value":0.7}
//| cases:
//|   - {"id":"half-turn","label":"θ = 180°","description":"Quaternion scalar part w approaches 0.","inputs":{"rotation_degrees":180}}
//|   - {"id":"axis-in-yz","label":"a = 0","description":"The rotation axis lies in the yz plane.","inputs":{"axis_tilt":0}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"invariants","path":"/rows/0/4","range":{"max":1e-15}}
//|       - {"artifact":"invariants","path":"/rows/0/5","range":{"max":1e-15}}
//|   - case: half-turn
//|     expect:
//|       - {"artifact":"invariants","path":"/rows/0/3","range":{"min":0,"max":1e-15}}
//|       - {"artifact":"invariants","path":"/rows/0/4","range":{"max":1e-15}}
//|   - case: axis-in-yz
//|     expect:
//|       - {"artifact":"invariants","path":"/rows/0/0","approx":{"value":0,"atol":1e-15}}
//|       - {"artifact":"invariants","path":"/rows/0/5","range":{"max":1e-15}}
use scioxide_core::RealScalar;
use scioxide_spatial::Rotation;

let axis = [axis_tilt, 1.0, 0.5];
let angle = RealScalar::to_radians(rotation_degrees);
let rotation = Rotation::from_axis_angle(axis, angle).map_err(|e| e.to_string())?;
let inverse = rotation.inverse();
let mut points = Vec::new();
let mut edges = Vec::new();
let mut norm_error = 0.0_f64;
let mut inverse_error = 0.0_f64;
for i in 0..96 {
    // Unit-circle points (cos φ, sin φ, 0).
    let (sin_phi, cos_phi) = RealScalar::sin_cos(core::f64::consts::TAU * f64::from(i) / 96.0);
    let point = [cos_phi, sin_phi, 0.0];
    let rotated = rotation.apply(point).map_err(|e| e.to_string())?;
    let restored = inverse.apply(rotated).map_err(|e| e.to_string())?;
    // Length preservation |Rx|² = 1 and inverse-rotation recovery error.
    let squared: f64 = rotated.iter().map(|x| x * x).sum();
    norm_error = norm_error.max((squared - 1.0).abs());
    for (r, p) in restored.iter().zip(point) {
        inverse_error = inverse_error.max((r - p).abs());
    }
    for (group, position) in [("original", point), ("rotated", rotated)] {
        points.push(serde_json::json!({
            "id": format!("{group}-{i}"),
            "position": position,
            "group": group
        }));
        edges.push(serde_json::json!({
            "from": format!("{group}-{i}"),
            "to": format!("{group}-{}", (i + 1) % 96)
        }));
    }
}
// Draw the axis as two points at ±1.3 times its normalized vector and a joining edge.
let length = RealScalar::sqrt(axis.iter().map(|x| x * x).sum::<f64>());
for (id, sign) in [("axis-plus", 1.3), ("axis-minus", -1.3)] {
    let position: Vec<f64> = axis.iter().map(|x| sign * x / length).collect();
    points.push(serde_json::json!({ "id": id, "position": position, "group": "axis" }));
}
edges.push(serde_json::json!({ "from": "axis-plus", "to": "axis-minus" }));
let unit = |label: &str| serde_json::json!({ "label": label, "unit": "Circle radius" });
emit_scene3d!(
    serde_json::json!({
        "points": points,
        "edges": edges,
        "groups": [
            { "id": "original", "label": "Original unit circle (xy plane)" },
            { "id": "rotated", "label": "Rotated circle" },
            { "id": "axis", "label": "Rotation axis" }
        ],
        "axes": { "x": unit("x"), "y": unit("y"), "z": unit("z") }
    }),
    metadata = serde_json::json!({ "id": "circles", "title": "Rotating the unit circle" })
);

let q = rotation.as_quaternion();
let fixed6 = serde_json::json!({ "fractionDigits": 6 });
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let columns = serde_json::json!([
    { "key": "0", "label": "x [-]", "type": "number", "format": fixed6 },
    { "key": "1", "label": "y [-]", "type": "number", "format": fixed6 },
    { "key": "2", "label": "z [-]", "type": "number", "format": fixed6 },
    { "key": "3", "label": "w [-]", "type": "number", "format": fixed6 },
    { "key": "4", "label": "max | |Rx|² − 1 | [-]", "type": "number", "format": sci2 },
    { "key": "5", "label": "Largest component error after inverse rotation [-]", "type": "number", "format": sci2 }
]);
let row = (q[0], q[1], q[2], q[3], norm_error, inverse_error);
emit_table_with_columns!(
    columns,
    vec![row],
    metadata = serde_json::json!({ "id": "invariants" })
);
```

All tested inputs (defaults and two cases) give length changes at most $4.4 \times 10^{-16}$ and recovery errors at most $3.3 \times 10^{-16}$, within a few rounding units of `f64`.
Of equivalent quaternions $q$ and $-q$, `Rotation` stores the one whose first nonzero component of $(w, x, y, z)$ is positive.
At “θ = 180°,” $w = \cos 90°$ rounds to $6.1 \times 10^{-17}$, so this rule chooses the representative with positive $w$.
At “a = 0,” quaternion component $x$ is 0 and vector part $(x, y, z) = \sin(\theta/2)\,\hat{\boldsymbol{n}}$ points along normalized axis $\hat{\boldsymbol{n}} = (0, 1, 0.5)/\sqrt{1.25}$.

## Four cocircular points and a linear temperature field

The four corners of a square of side $L$ are cocircular; either diagonal gives a Delaunay triangulation.
`scioxide-spatial` deterministically chooses one through [symbolic perturbation](oxref:spatial-tessellation-sites) based on lexicographically sorted canonical indices; dual Voronoi vertices merge at the common circumcenter $(L/2, L/2)$.

For a linear plate temperature $T(x, y) = 1 + 2x + 3y$ [K] ($x, y$ [m]), barycentric interpolation $\sum_i \lambda_i T(\boldsymbol{p}_i)$ with $\lambda$ reproduces $T$ within rounding error in every triangle.
This is a finite-element patch test.
The next cell locates a containing triangle with `find_simplex` and interpolates temperature using `barycentric_into` barycentric coordinates.
Vertices returned by `simplex(s)` are canonical indices; map back with `representatives()` to input rows (square corners numbered counterclockwise from 0) for the table.
The first table shows the query, triangle vertices, barycentric coordinates, interpolated-minus-analytic temperature, and distance $|\sum_i \lambda_i \boldsymbol{p}_i - \boldsymbol{q}|$ between the barycentrically reconstructed point and query.
Since `barycentric_into` returns coordinates with $\lambda_0 = 1 - \lambda_1 - \lambda_2$, $\sum\lambda = 1$ is not a check; reconstruct with vertex coordinates to verify barycentric coordinates independently.
The second table shows triangle and Voronoi-vertex counts, vertex difference from center $(L/2, L/2)$, and whether symbolic tie resolution was used.

```rust
//| id: spatial-delaunay-affine-dual
//| ref: spatial-delaunay-affine-dual
//| title: "Check triangulation and linear-field reproduction for four cocircular points"
//| run: reactive
//| crates: [scioxide-core, scioxide-spatial]
//| inputs:
//|   square_side: {"type":"range","label":"Square side L [m]","description":"Scale coordinates by similarity.","min":0.5,"max":3,"step":0.25,"value":1}
//|   query_fraction: {"type":"range","label":"Query horizontal position x/L [-]","description":"Move the query into another triangle.","min":0.1,"max":0.9,"step":0.1,"value":0.3}
//| cases:
//|   - {"id":"other-triangle","label":"x/L = 0.9","description":"The query enters the other triangle.","inputs":{"query_fraction":0.9}}
//|   - {"id":"large-square","label":"L = 3 m","description":"Similarity scaling preserves barycentric coordinates.","inputs":{"square_side":3}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"interpolation","path":"/rows/0/3","approx":{"value":0.33,"atol":1e-12}}
//|       - {"artifact":"interpolation","path":"/rows/0/8","range":{"max":1e-14}}
//|       - {"artifact":"interpolation","path":"/rows/0/9","range":{"max":1e-15}}
//|       - {"artifact":"dual","path":"/rows/0/0","equals":2}
//|       - {"artifact":"dual","path":"/rows/0/1","equals":1}
//|       - {"artifact":"dual","path":"/rows/0/3","equals":"Used"}
//|   - case: other-triangle
//|     expect:
//|       - {"artifact":"interpolation","path":"/rows/0/8","range":{"max":1e-14}}
//|   - case: large-square
//|     expect:
//|       - {"artifact":"interpolation","path":"/rows/0/3","approx":{"value":0.33,"atol":1e-12}}
//|       - {"artifact":"dual","path":"/rows/0/2","range":{"max":1e-14}}
use scioxide_core::RealScalar;
use scioxide_spatial::{PointSet, Voronoi};

let side = square_side;
// Order square corners counterclockwise from 0 (input rows).
let coordinates = [0.0, 0.0, side, 0.0, side, side, 0.0, side];
let points = PointSet::from_rows(&coordinates, 2).map_err(|e| e.to_string())?;
// Construct Voronoi and use its Delaunay triangulation for location and interpolation.
let dual = Voronoi::new(&points).map_err(|e| e.to_string())?;
let geometry = dual.delaunay();

let query = [query_fraction * side, 0.37 * side];
let location = geometry
    .find_simplex(&query)
    .map_err(|e| e.to_string())?
    .ok_or("Query lies outside the square")?;
let mut weights = [0.0; 3];
let mut scratch = [0.0; 3];
geometry
    .barycentric_into(location.simplex, &query, &mut weights, &mut scratch)
    .map_err(|e| e.to_string())?;

// Interpolate linear field T = 1 + 2x + 3y [K] from vertex values and compare with the analytic value.
let temperature = |p: &[f64]| 1.0 + 2.0 * p[0] + 3.0 * p[1];
let vertices = geometry
    .simplex(location.simplex)
    .map_err(|e| e.to_string())?;
let sites = geometry.points();
let interpolated: f64 = vertices
    .iter()
    .zip(weights)
    .map(|(&v, w)| w * temperature(&sites[2 * v..2 * v + 2]))
    .sum();
// Map canonical indices back to input rows (corner indices).
let corners: Vec<String> = vertices
    .iter()
    .map(|&v| geometry.representatives()[v].to_string())
    .collect();
let voronoi_vertices = dual.vertices().map_err(|e| e.to_string())?;
let center_error = voronoi_vertices
    .iter()
    .map(|v| (v - side / 2.0).abs())
    .fold(0.0_f64, f64::max);

let fixed3 = serde_json::json!({ "fractionDigits": 3 });
let fixed6 = serde_json::json!({ "fractionDigits": 6 });
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let columns = serde_json::json!([
    { "key": "0", "label": "Query x [m]", "type": "number", "format": fixed3 },
    { "key": "1", "label": "Query y [m]", "type": "number", "format": fixed3 },
    { "key": "2", "label": "Triangle vertices (corner indices)" },
    { "key": "3", "label": "λ₀ [-]", "type": "number", "format": fixed6 },
    { "key": "4", "label": "λ₁ [-]", "type": "number", "format": fixed6 },
    { "key": "5", "label": "λ₂ [-]", "type": "number", "format": fixed6 },
    { "key": "6", "label": "Interpolated temperature [K]", "type": "number", "format": fixed6 },
    { "key": "7", "label": "Analytic value [K]", "type": "number", "format": fixed6 },
    { "key": "8", "label": "|Temperature difference| [K]", "type": "number", "format": sci2 },
    { "key": "9", "label": "|Σλᵢpᵢ − q| [m]", "type": "number", "format": sci2 }
]);
let exact = temperature(&query);
// Reconstruct point Σ λᵢ pᵢ from barycentric coordinates (independent check using vertex coordinates).
let rebuilt = vertices
    .iter()
    .zip(weights)
    .fold([0.0, 0.0], |acc, (&v, w)| {
        [acc[0] + w * sites[2 * v], acc[1] + w * sites[2 * v + 1]]
    });
let row = (
    query[0],
    query[1],
    corners.join(", "),
    weights[0],
    weights[1],
    weights[2],
    interpolated,
    exact,
    (interpolated - exact).abs(),
    RealScalar::hypot(rebuilt[0] - query[0], rebuilt[1] - query[1]),
);
emit_table_with_columns!(
    columns,
    vec![row],
    metadata = serde_json::json!({ "id": "interpolation" })
);
let ties = if geometry.provenance().resolved_ties {
    "Used"
} else {
    "Unused"
};
let dual_columns = serde_json::json!([
    { "key": "0", "label": "Triangles [count]", "type": "integer" },
    { "key": "1", "label": "Voronoi vertices [count]", "type": "integer" },
    { "key": "2", "label": "Voronoi vertex–center difference [m]", "type": "number", "format": sci2 },
    { "key": "3", "label": "Tie resolution" }
]);
let dual_row = (
    geometry.simplex_count(),
    dual.vertex_count(),
    center_error,
    ties,
);
emit_table_with_columns!(
    dual_columns,
    vec![dual_row],
    metadata = serde_json::json!({ "id": "dual" })
);
```

With default input, query $(0.3, 0.37)$ lies in triangle of corners 0, 3, and 1, with barycentric coordinates $(0.33, 0.37, 0.30)$ and interpolated temperature equal to analytic 2.71 K.
The barycentrically reconstructed point also equals the query, with distance 0.
The triangulation chooses the diagonal joining corner 1 $(L, 0)$ and corner 3 $(0, L)$.
At “x/L = 0.9,” the query lies in triangle of corners 3, 1, and 2, with temperature difference $4.4 \times 10^{-16}$ K.
There are two triangles and one Voronoi vertex at their common circumcenter.
“Used” tie resolution means symbolic perturbation resolved at least one exactly zero predicate; here it selects a triangulation of four cocircular points.
At “L = 3 m,” barycentric coordinates remain $(0.33, 0.37, 0.30)$, showing consistency under similarity transformations.

## Summary

Correct cell averages preserve mass within rounding even on nonuniform grids; midpoint substitutes retain discretization errors depending on grading.
Rotations preserve lengths at the $10^{-16}$ scale and inverse rotations recover original points; larger discrepancies suggest invalid input or application order.
Four cocircular points receive a deterministic Delaunay triangulation through symbolic perturbation, with Voronoi vertices merged at one common circumcenter.
Barycentric interpolation reproduces linear fields within rounding; large interpolation errors call for checking canonical-vertex/input-row correspondence.
