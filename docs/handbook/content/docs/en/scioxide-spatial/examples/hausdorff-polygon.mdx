CAD and numerically controlled machine tools approximate circular arcs with short segments to construct machining paths.
Segment count is determined by the maximum departure of the approximate path from the circle.
Hausdorff distance expresses the maximum discrepancy between shapes; `directed_hausdorff` computes it for point sets.
This example samples both a circle of radius $R = 25$ mm and an inscribed regular $n$-gon, comparing directed Hausdorff distance with closed-form sagitta.
It also examines what vertex-only sampling measures and how one outlier changes the result.

## Directed Hausdorff distance

The directed Hausdorff distance from point set $A$ to $B$ is:

$$
h(A, B) = \max_{a \in A} \min_{b \in B} |a - b|
$$


Every point of $A$ is within $h(A, B)$ of $B$; a point $a^*$ attaining $h(A, B)$ and its nearest point $b^*$ form a distance-realizing pair (witness).
In general $h(A, B) \ne h(B, A)$; the larger directed value $H(A, B) = \max(h(A, B), h(B, A))$ is the symmetric Hausdorff distance.

`directed_hausdorff(&source, &target)` computes $h(\text{source}, \text{target})$ using Euclidean distance, returning distance `distance` and witness indices `source` and `target`.
It traverses both sets in a fixed-seed random order, terminating the inner search when a distance falls below the current maximum (Taha and Hanbury 2015).
Worst-case complexity for $m$ and $n$ points is $O(mnd)$.
Expected complexity under random order is reported much smaller (Taha–Hanbury), with the reduction depending on point configuration.
Results and witnesses are traversal-order independent; witness indices are the smallest among points attaining the maximum.
An empty set returns `DomainError`; mismatched dimensions return `DimensionMismatch`.

## Hausdorff distance between a circle and inscribed regular polygon

An edge of a regular $n$-gon inscribed in a radius-$R$ circle is a chord subtending central angle $2\theta$ ($\theta = \pi/n$).
Its midpoint is $R\cos\theta$ from the center; the difference from the arc midpoint,

$$
H_n = R\,(1 - \cos\theta) = 2R\sin^2\frac{\pi}{2n} \approx \frac{\pi^2 R}{2n^2}
$$

is the sagitta.
Circle-to-polygon distance is maximal at arc midpoints, equaling $H_n$; polygon-to-circle distance is maximal at chord midpoints, equaling $H_n$.
Thus both directed Hausdorff distances equal $H_n$, decreasing to about 1/4 when $n$ doubles.
At $R = 25$ mm and $n = 12$, this is $H_{12} = 0.8519$ mm.

## Sampling error

`directed_hausdorff` works on finite point sets, so both circle and polygon are represented by points.
Use $s$ samples per edge: circle angles $2\pi(i + t/s)/n$ and points $v_i + (t/s)(v_{i+1} - v_i)$ dividing polygon edge $v_i v_{i+1}$ into $s$ parts ($i = 0, \ldots, n - 1$, $t = 0, \ldots, s - 1$).
Samples include vertices and, for even $s$, arc and edge midpoints.

For even $s$, the nearest polygon sample to an arc midpoint is its chord midpoint, at distance exactly $H_n$.
Other circle samples have smaller continuous-polygon distances than $H_n$; as checked below, measured values equal $H_n$ within rounding.
For odd $s$, arc midpoints are unsampled and the nearest sample is offset by angle $\varphi = \pi/(ns)$.
Its distance $R(\cos\varphi - \cos\theta) \approx H_n(1 - 1/s^2)$ to the chord approximates the measurement.
Relative error is around $1/s^2$ independently of $n$, so sampling does not alter convergence order in $n$.
For every $s$, the circle-to-polygon value does not exceed $\sqrt{H_n^2 + (\Delta/2)^2}$.
Here $\Delta = 2R\sin\theta/s$ is edge-sample spacing; the perpendicular foot from a circle point to an edge lies within $\Delta/2$ of its nearest sample.

Vertex-only sampling instead measures $2R\sin(\pi/(2n)) \approx \pi R/n$ from arc midpoints to nearest vertices.
This is roughly half an edge length, describing vertex spacing rather than polygonal shape, and decreases only at order $-1$ in $n$.

The following block defines quantities shared by two cells.
`circle_samples` and `polygon_samples` return these samples in $(x, y)$ order with one point per row.
Vertex-only samples use `polygon_samples(radius, sides, 1)`.
Cells borrow coordinates with `PointSet::from_rows(&coordinates, 2)` and pass them to `directed_hausdorff` without cloning.

```rust
//| id: spatial-hausdorff-polygon-model
//| kind: definitions
//| title: "Circle and inscribed regular-polygon samples"
//| crates: [scioxide-core]
use scioxide_core::RealScalar;

/// Circle points: s per edge, angles 2π(i + t/s)/n.
pub(crate) fn circle_samples(radius: f64, sides: usize, per_edge: usize) -> Vec<f64> {
    let total = sides * per_edge;
    (0..total)
        .flat_map(|k| {
            let angle = 2.0 * core::f64::consts::PI * k as f64 / total as f64;
            [
                radius * RealScalar::cos(angle),
                radius * RealScalar::sin(angle),
            ]
        })
        .collect()
}

/// Points dividing each inscribed regular n-gon edge into s parts (including vertices).
pub(crate) fn polygon_samples(radius: f64, sides: usize, per_edge: usize) -> Vec<f64> {
    let vertex = |i: usize| {
        let angle = 2.0 * core::f64::consts::PI * (i % sides) as f64 / sides as f64;
        [
            radius * RealScalar::cos(angle),
            radius * RealScalar::sin(angle),
        ]
    };
    (0..sides * per_edge)
        .flat_map(|k| {
            let (i, t) = (k / per_edge, (k % per_edge) as f64 / per_edge as f64);
            let (a, b) = (vertex(i), vertex(i + 1));
            [a[0] + t * (b[0] - a[0]), a[1] + t * (b[1] - a[1])]
        })
        .collect()
}
```

## Both directions and outliers

The next cell selects edge count $n$, samples per edge $s$, and outlier distance $\delta$ [mm], computing directed distances both ways between circle samples $C$ and polygon samples $P$.
When $\delta > 0$, use $C$ with one extra point at $(R + \delta, 0)$ outside vertex $v_0 = (R, 0)$.
This models a measurement error placing one point outside the circle; $h(C, P)$ should become $\max(\text{sampling prediction}, \delta)$ while $h(P, C)$ stays unchanged.
For each direction, the table shows measured distance, sagitta $H_n$, ratio, sampling prediction ($R(\cos\varphi - \cos\theta)$ for odd $s$), and polar angles of the witness points.
If point-count product of $C$ and $P$ is at most $1.1 \times 10^6$, construct an all-pairs matrix with `pairwise` and compare exhaustive maxima of row and column minima.

```rust
//| id: spatial-hausdorff-polygon-approximation
//| ref: spatial-hausdorff-polygon-approximation
//| title: "Measure directed Hausdorff distances both ways between a circle and an inscribed regular polygon"
//| run: reactive
//| uses: [spatial-hausdorff-polygon-model]
//| crates: [scioxide-core, scioxide-spatial]
//| exports: [radius, per_edge]
//| inputs:
//|   sides: {"type":"range","label":"Edge count n","min":3,"max":128,"step":1,"value":12}
//|   per_edge: {"type":"range","label":"Samples per edge s","min":2,"max":32,"step":1,"value":8}
//|   outlier: {"type":"range","label":"Outlier distance δ [mm]","min":0,"max":5,"step":0.1,"value":0}
//| cases:
//|   - {"id":"odd-samples","label":"s = 3","description":"Arc midpoints are unsampled; the measured value is about 8/9 of H_n.","inputs":{"per_edge":3}}
//|   - {"id":"outlier","label":"δ = 2.5 mm","description":"One circle-side outlier changes only h(C, P) to δ.","inputs":{"outlier":2.5}}
//|   - {"id":"fine","label":"n = 128, s = 32","description":"The point-count product is large, so exhaustive checking is skipped.","inputs":{"sides":128,"per_edge":32}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"directions","path":"/rows/0/1","approx":{"value":0.85185434277329,"rtol":1e-12}}
//|       - {"artifact":"directions","path":"/rows/0/3","approx":{"value":1.0,"atol":1e-12}}
//|       - {"artifact":"directions","path":"/rows/0/5","approx":{"value":345.0,"atol":1e-9}}
//|       - {"artifact":"directions","path":"/rows/0/7","approx":{"value":0.85185434277329,"rtol":1e-12}}
//|       - {"artifact":"directions","path":"/rows/1/1","approx":{"value":0.85185434277329,"rtol":1e-12}}
//|   - case: odd-samples
//|     expect:
//|       - {"artifact":"directions","path":"/rows/0/1","approx":{"value":0.75704351279462,"rtol":1e-12}}
//|       - {"artifact":"directions","path":"/rows/0/4","approx":{"value":0.75672179506693,"rtol":1e-12}}
//|   - case: outlier
//|     expect:
//|       - {"artifact":"directions","path":"/rows/0/1","approx":{"value":2.5,"rtol":1e-14}}
//|       - {"artifact":"directions","path":"/rows/0/5","approx":{"value":0.0,"atol":1e-12}}
//|       - {"artifact":"directions","path":"/rows/1/1","approx":{"value":0.85185434277329,"rtol":1e-12}}
//|   - case: fine
//|     expect:
//|       - {"artifact":"directions","path":"/rows/0/3","approx":{"value":1.0,"atol":1e-11}}
//|       - {"artifact":"directions","path":"/rows/0/7","equals":null}
use scioxide_core::RealScalar;
use scioxide_spatial::{PointSet, directed_hausdorff, pairwise};

let radius = 25.0; // [mm]
let (n, s) = (sides as usize, per_edge as usize);
let mut circle = circle_samples(radius, n, s);
if outlier > 0.0 {
    circle.extend([radius + outlier, 0.0]);
}
let polygon = polygon_samples(radius, n, s);
let circle_set = PointSet::from_rows(&circle, 2).map_err(|e| e.to_string())?;
let polygon_set = PointSet::from_rows(&polygon, 2).map_err(|e| e.to_string())?;
let forward = directed_hausdorff(&circle_set, &polygon_set).map_err(|e| e.to_string())?;
let backward = directed_hausdorff(&polygon_set, &circle_set).map_err(|e| e.to_string())?;

// Sagitta H_n = 2R sin²(θ/2) and odd-s prediction R(cos φ − cos θ) (φ = π/(ns)).
// Both use products of sines to avoid cancellation in 1 − cos θ.
let theta = core::f64::consts::PI / n as f64;
let sagitta = 2.0 * radius * RealScalar::sin(theta / 2.0) * RealScalar::sin(theta / 2.0);
let phi = if s % 2 == 0 { 0.0 } else { theta / s as f64 };
let sampled =
    2.0 * radius * RealScalar::sin((theta + phi) / 2.0) * RealScalar::sin((theta - phi) / 2.0);

// Exhaustive check: maximum row minima (circle points) and maximum column minima (polygon points) of the distance matrix.
let (rows, columns) = (circle_set.len(), polygon_set.len());
let brute = if rows * columns <= 1_100_000 {
    let matrix = pairwise(&circle_set, &polygon_set).map_err(|e| e.to_string())?;
    let matrix = matrix.as_slice();
    let row_max = (0..rows)
        .map(|i| {
            matrix[i * columns..(i + 1) * columns]
                .iter()
                .copied()
                .fold(f64::MAX, f64::min)
        })
        .fold(0.0, f64::max);
    let column_max = (0..columns)
        .map(|j| {
            (0..rows)
                .map(|i| matrix[i * columns + j])
                .fold(f64::MAX, f64::min)
        })
        .fold(0.0, f64::max);
    Some((row_max, column_max))
} else {
    None
};

let degrees = |points: &[f64], k: usize| {
    let angle = RealScalar::atan2(points[2 * k + 1], points[2 * k]).to_degrees();
    if angle < 0.0 { angle + 360.0 } else { angle }
};
let table = vec![
    (
        "Circle C → polygon P",
        forward.distance,
        sagitta,
        forward.distance / sagitta,
        sampled.max(outlier),
        degrees(&circle, forward.source),
        degrees(&polygon, forward.target),
        brute.map(|b| b.0),
    ),
    (
        "Polygon P → circle C",
        backward.distance,
        sagitta,
        backward.distance / sagitta,
        sampled,
        degrees(&polygon, backward.source),
        degrees(&circle, backward.target),
        brute.map(|b| b.1),
    ),
];
let fixed6 = serde_json::json!({ "significantDigits": 6 });
let fixed4 = serde_json::json!({ "fractionDigits": 4 });
let fixed2 = serde_json::json!({ "fractionDigits": 2 });
let columns = serde_json::json!([
    { "key": "0", "label": "Direction" },
    { "key": "1", "label": "Directed Hausdorff distance h [mm]", "type": "number", "format": fixed6 },
    { "key": "2", "label": "Sagitta H_n [mm]", "type": "number", "format": fixed6 },
    { "key": "3", "label": "h / H_n [-]", "type": "number", "format": fixed4 },
    { "key": "4", "label": "Sampling prediction [mm]", "type": "number", "format": fixed6 },
    { "key": "5", "label": "Witness source polar angle [deg]", "type": "number", "format": fixed2 },
    { "key": "6", "label": "Witness target polar angle [deg]", "type": "number", "format": fixed2 },
    { "key": "7", "label": "Exhaustive value [mm]", "type": "number", "format": fixed6, "nullText": "Skipped" }
]);
emit_table_with_columns!(
    columns,
    table,
    metadata = serde_json::json!({ "id": "directions" })
);
export!(radius, &radius);
export!(per_edge, &s);
```

With defaults ($n = 12$, $s = 8$, no outlier), both distances equal $0.851854$ mm, with ratio $1 + 2 \times 10^{-15}$ to sagitta $H_{12}$.
The source witness has polar angle $345°$, midway along the arc (or edge) between vertices $330°$ and $360°$.
The 12 arc midpoints have exactly equal distances mathematically, but the witness uses the smallest index attaining the largest rounded distance, selecting $345°$ through rounding differences.
The exhaustive value from the `pairwise` distance matrix agrees.
Setting $s = 3$ removes arc midpoints from samples, lowering the measurement to $0.757044$ mm (0.8887 times $H_{12}$).
Relative difference from prediction $R(\cos\varphi - \cos\theta) = 0.756722$ mm is $4 \times 10^{-4}$; the source witness is at angle $130°$, offset $5°$ from the midpoint.

Adding an outlier at $\delta = 2.5$ mm makes $h(C, P)$ equal $2.5$ mm with the outlier as source witness (angle $0°$), 2.9 times $H_{12}$.
Meanwhile, $h(P, C)$ remains $0.851854$ mm.
One outlier raises symmetric Hausdorff distance to that outlier's distance.
`scioxide-spatial` provides no partial Hausdorff distance replacing the maximum by a quantile; remove outliers before comparing measured sets.
At $n = 128$ and $s = 32$, point-count product exceeds $1.1 \times 10^6$ and exhaustive checking is skipped.

## Convergence with edge count

The next cell receives $R$ and $s$, increases edge count from $n = 4$ to $128$, and measures $h(C, P)$.
It also measures $h(C, V)$ with vertex-only polygon sampling for comparison.
The plot uses logarithmic axes for both dimensions, symbols for measurements, and dashed closed forms $H_n$ and $2R\sin(\pi/(2n))$.
The first table gives values per $n$; the second compares least-squares slopes of $\ln h$ against $\ln n$ for $n \ge 8$ with theoretical $-2$ and $-1$.

```rust
//| id: spatial-hausdorff-polygon-convergence
//| ref: spatial-hausdorff-polygon-convergence
//| title: "Measure Hausdorff-distance convergence with edge count"
//| run: reactive
//| uses: [spatial-hausdorff-polygon-model]
//| crates: [scioxide-core, scioxide-spatial]
//| dependsOn:
//|   setup: spatial-hausdorff-polygon-approximation
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"slopes","path":"/rows/0/1","approx":{"value":-1.99636,"atol":1e-4}}
//|       - {"artifact":"slopes","path":"/rows/1/1","approx":{"value":-0.99818,"atol":1e-4}}
//|       - {"artifact":"convergence","path":"/rows/10/3","approx":{"value":1.0,"atol":1e-11}}
//|       - {"artifact":"convergence-chart","path":"/spec/series/1/points/0/1","approx":{"value":7.3223304703363,"rtol":1e-12}}
use scioxide_core::RealScalar;
use scioxide_spatial::{PointSet, directed_hausdorff};

let radius = setup["radius"].as_f64().ok_or("Missing radius")?;
let s = setup["per_edge"].as_u64().ok_or("Missing sample count")? as usize;
let sides = [4, 6, 8, 12, 16, 24, 32, 48, 64, 96, 128];
let mut rows = Vec::with_capacity(sides.len());
for n in sides {
    let circle = circle_samples(radius, n, s);
    let polygon = polygon_samples(radius, n, s);
    let vertices = polygon_samples(radius, n, 1);
    let circle_set = PointSet::from_rows(&circle, 2).map_err(|e| e.to_string())?;
    let polygon_set = PointSet::from_rows(&polygon, 2).map_err(|e| e.to_string())?;
    let vertex_set = PointSet::from_rows(&vertices, 2).map_err(|e| e.to_string())?;
    let edges = directed_hausdorff(&circle_set, &polygon_set).map_err(|e| e.to_string())?;
    let corners = directed_hausdorff(&circle_set, &vertex_set).map_err(|e| e.to_string())?;
    let half = core::f64::consts::PI / (2.0 * n as f64);
    let sagitta = 2.0 * radius * RealScalar::sin(half) * RealScalar::sin(half);
    let spacing = 2.0 * radius * RealScalar::sin(half);
    rows.push((
        n,
        sagitta,
        edges.distance,
        edges.distance / sagitta,
        spacing,
        corners.distance,
    ));
}

// Least-squares slope of ln h against ln n for n ≥ 8
let slope = |pick: &dyn Fn(&(usize, f64, f64, f64, f64, f64)) -> f64| {
    let points: Vec<(f64, f64)> = rows
        .iter()
        .filter(|r| r.0 >= 8)
        .map(|r| (RealScalar::ln(r.0 as f64), RealScalar::ln(pick(r))))
        .collect();
    let k = points.len() as f64;
    let (mx, my) = points
        .iter()
        .fold((0.0, 0.0), |(a, b), p| (a + p.0 / k, b + p.1 / k));
    let sxx: f64 = points.iter().map(|p| (p.0 - mx) * (p.0 - mx)).sum();
    let sxy: f64 = points.iter().map(|p| (p.0 - mx) * (p.1 - my)).sum();
    sxy / sxx
};
let fits = vec![
    ("Edge samples h(C, P)", slope(&|r| r.2), -2.0),
    ("Vertices only h(C, V)", slope(&|r| r.5), -1.0),
];

let series = |pick: &dyn Fn(&(usize, f64, f64, f64, f64, f64)) -> f64| -> Vec<[f64; 2]> {
    rows.iter().map(|r| [r.0 as f64, pick(r)]).collect()
};
let dashed = serde_json::json!({ "lineType": "dashed", "showSymbol": false });
let (circle_mark, diamond_mark) = (
    serde_json::json!({ "symbol": "circle" }),
    serde_json::json!({ "symbol": "diamond" }),
);
let (edges, sagitta) = (series(&|r| r.2), series(&|r| r.1));
let (corners, spacing) = (series(&|r| r.5), series(&|r| r.4));
emit_chart!(
    serde_json::json!({
        "kind": "line",
        "xType": "log",
        "yType": "log",
        "xLabel": "Edge count n [-]",
        "yLabel": "Directed Hausdorff distance [mm]",
        "xMin": 4.0,
        "xMax": 128.0,
        "dataZoom": true,
        "tooltip": true,
        "series": [
            { "id": "edges", "name": "Edge samples h(C, P)", "points": edges, "style": circle_mark },
            { "id": "sagitta", "name": "Sagitta H_n", "points": sagitta, "style": dashed },
            { "id": "corners", "name": "Vertices only h(C, V)", "points": corners, "style": diamond_mark },
            { "id": "spacing", "name": "2R sin(π/(2n))", "points": spacing, "style": dashed }
        ]
    }),
    metadata = serde_json::json!({ "id": "convergence-chart" })
);

let fixed6 = serde_json::json!({ "significantDigits": 6 });
let fixed4 = serde_json::json!({ "fractionDigits": 4 });
let columns = serde_json::json!([
    { "key": "0", "label": "Edge count n", "type": "integer" },
    { "key": "1", "label": "Sagitta H_n [mm]", "type": "number", "format": fixed6 },
    { "key": "2", "label": "h(C, P) [mm]", "type": "number", "format": fixed6 },
    { "key": "3", "label": "h(C, P) / H_n [-]", "type": "number", "format": fixed4 },
    { "key": "4", "label": "2R sin(π/(2n)) [mm]", "type": "number", "format": fixed6 },
    { "key": "5", "label": "h(C, V) [mm]", "type": "number", "format": fixed6 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "convergence" })
);
let fit_columns = serde_json::json!([
    { "key": "0", "label": "Samples" },
    { "key": "1", "label": "Fitted slope [-]", "type": "number", "format": fixed4 },
    { "key": "2", "label": "Theoretical slope [-]", "type": "number", "format": fixed4 }
]);
emit_table_with_columns!(
    fit_columns,
    fits,
    metadata = serde_json::json!({ "id": "slopes" })
);
```

With default $s = 8$, ratios of $h(C, P)$ to $H_n$ agree with 1 within $10^{-12}$ for every $n$; the fitted slope is $-1.9964$.
Since $H_n = 2R\sin^2(\pi/(2n))$ is not exactly proportional to $n^{-2}$, the slope over $n \ge 8$ differs slightly from $-2$.
The ratio's deviation from 1 increases to $6 \times 10^{-13}$ at $n = 128$.
Distances use differences of coordinates around 25 mm, with rounding errors around $\varepsilon R \approx 6 \times 10^{-15}$ mm; relative to $H_{128} = 0.0075$ mm this gives that error scale.
Vertex-only $h(C, V)$ equals $2R\sin(\pi/(2n))$ with slope $-0.9982$; even at $n = 128$ it is $0.61$ mm, about 80 times $H_{128}$.
Making $s$ odd in the preceding cell leaves $h(C, P)/H_n$ nearly constant at $1 - 1/s^2$ (0.887–0.889 for $s = 3$), with slope nearly unchanged at $-1.9962$.
Then $h(C, V)$ also lacks arc midpoints and falls below $2R\sin(\pi/(2n))$, but its slope $-0.9992$ remains $-1$.

## Summary

The maximum discrepancy of a circle and inscribed regular $n$-gon is sagitta $2R\sin^2(\pi/(2n)) \approx \pi^2 R/(2n^2)$, equal to $0.85$ mm for $R = 25$ mm and $n = 12$.
To measure this with directed Hausdorff distance, sample polygon edges as well as vertices.
Vertices alone measure spacing $\approx \pi R/n$ and suggest convergence order $-1$.
Including arc and edge midpoints gives $H_n$ within rounding; omitting them leaves relative errors around $1/s^2$ without changing order.
Directed Hausdorff distance depends on direction; one outlier raises one direction to its distance, so read both directed values together with witness points.
