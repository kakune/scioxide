Differences between molecular structures are often expressed by root-mean-square deviation (RMSD) of atomic positions after rotating and translating one to superimpose them.
This compares crystal structures with computationally optimized structures or molecular-dynamics frames with a reference.
This example adds known rigid transformations and noise modeling measurement errors to four experimentally determined small-molecule structures and superimposes them with `estimate_rigid_transform_with_options`.
It compares RMSD with expectations derived from noise magnitude and examines planar and linear molecules.

Atomic-mass weighting makes the weighted centroid the center of mass.

## Observation model and RMSD

Let $p_i$ be reference atomic positions and define observed positions by:

$$
q_i = R_{\text{true}}\, p_i + t_{\text{true}} + e_i, \qquad e_i \sim N(0, \sigma^2 I_3)
$$


$e_i$ is independent isotropic noise per atom, with equal variance $\sigma^2$ [Å²] in all coordinates.
Superposition finds the rigid transformation minimizing $\sum_i w_i \lvert R p_i + t - q_i\rvert^2$; RMSD is the square root of the quotient obtained by dividing that minimum by weight sum $W$, corresponding to `RigidEstimationResult::rms_residual`.
This is the Kabsch method derived in [Rigid registration and singular value decomposition](../../algorithms/rigid-registration/).

## Expected RMSD

For noise small relative to molecular size, deviations of the estimated transformation from truth use six small parameters (three translation, three rotation), and residuals become linear projections of noise.
For least squares with weights $w_i$, the expected residual sum of squares is:

$$
\mathrm{E}\left[\sum_i w_i \lvert r_i\rvert^2\right] = \sigma^2\left(\operatorname{tr} D - \operatorname{tr}\!\left[(A^\top D A)^{-1} A^\top D^2 A\right]\right)
$$


$r_i$ is atom $i$'s residual; $A$ is the $3n \times 6$ matrix mapping small rigid displacements to atomic displacements; $D$ is the $3n \times 3n$ diagonal matrix repeating $w_i$ per coordinate, and $\operatorname{tr} D = 3W$.
Using coordinates $x_i$ about the weighted centroid makes $A^\top D A$ block diagonal, with translation block $W I_3$ and rotation block (inertia tensor with weights $w_i$)

$$
I_w = \sum_i w_i\left(\lvert x_i\rvert^2 I_3 - x_i x_i^\top\right)
$$

as its two blocks.
Consequently:

$$
\frac{\mathrm{E}\left[\mathrm{RMSD}^2\right]}{\sigma^2} \approx 3 - \frac{1}{W}\left(\frac{3\sum_i w_i^2}{W} + \operatorname{tr}\!\left(I_w^{-1} I_{w^2}\right)\right)
$$

$I_{w^2}$ is the inertia tensor with weights $w_i^2$ about the same centroid.
Uniform weights give $\sum_i w_i^2 / W = 1$ and $I_{w^2} = I_w$, hence:

$$
\mathrm{E}\left[\mathrm{RMSD}^2\right] \approx \frac{\sigma^2 (3n - 6)}{n}
$$


This matches the degrees-of-freedom count: fitting six parameters from $3n$ coordinates leaves the remainder in residuals.
Atomic-mass weights yield a smaller coefficient because translation fitting absorbs most noise of heavy atoms.
This formula is a first-order approximation in noise.
The replicate cell below checks the noise range where it applies.

For linear molecules, rotation about the molecular axis moves no atom, making $I_w$ singular and invalidating the formula.
For the same reason, observations do not determine that rotation ([Uniqueness and rank tests](oxref:spatial-kabsch-uniqueness)).
For planar molecules (benzene), rotation about any in-plane axis moves atoms, so $I_w$ is nonsingular; cross-covariance has rank 2, but rotation remains unique.

The following block defines quantities shared by two cells.
`MOLECULES` supplies coordinates of these four molecules, `Element::mass` atomic masses, `weights` uniform or mass weights, and `bonds` atom pairs within 1.6 Å (scene bonds).
`expected_rms_squared` computes derived coefficient $c = \mathrm{E}[\mathrm{RMSD}^2]/\sigma^2$ from inertia tensors, returning `None` if $I_w$ is singular.
The 3×3 inverse uses cofactors; this coefficient is an independent reference.

/// Uniform (all 1) or atomic-mass weights.
pub(crate) fn weights(molecule: &Molecule, by_mass: bool) -> Vec<f64> {
    molecule
        .atoms
        .iter()
        .map(|(element, _)| if by_mass { element.mass() } else { 1.0 })
        .collect()
}

/// Atom pairs within 1.6 Å (bonds).
pub(crate) fn bonds(molecule: &Molecule) -> Vec<(usize, usize)> {
    let atoms = molecule.atoms;
    let mut pairs = Vec::new();
    for i in 0..atoms.len() {
        for j in i + 1..atoms.len() {
            let d2: f64 = (0..3)
                .map(|k| (atoms[i].1[k] - atoms[j].1[k]) * (atoms[i].1[k] - atoms[j].1[k]))
                .sum();
            if d2 <= 1.6 * 1.6 {
                pairs.push((i, j));
            }
        }
    }
    pairs
}

/// Inertia tensor about the weighted centroid: Σ wᵢ (|xᵢ|² I − xᵢ xᵢᵀ).
fn inertia(points: &[[f64; 3]], w: &[f64], centroid: [f64; 3]) -> [[f64; 3]; 3] {
    let mut tensor = [[0.0; 3]; 3];
    for (p, &wi) in points.iter().zip(w) {
        let x = [0, 1, 2].map(|k| p[k] - centroid[k]);
        let r2 = x[0] * x[0] + x[1] * x[1] + x[2] * x[2];
        for a in 0..3 {
            for b in 0..3 {
                let delta = if a == b { r2 } else { 0.0 };
                tensor[a][b] += wi * (delta - x[a] * x[b]);
            }
        }
    }
    tensor
}

/// Linearized E[RMSD²]/σ² = 3 − (3 Σwᵢ²/W + tr(I_w⁻¹ I_{w²}))/W.
/// None for singular I_w (linear molecules). The 3×3 inverse uses cofactors (reference).
pub(crate) fn expected_rms_squared(molecule: &Molecule, w: &[f64]) -> Option<f64> {
    let points: Vec<[f64; 3]> = molecule.atoms.iter().map(|(_, p)| *p).collect();
    let total: f64 = w.iter().sum();
    let centroid =
        [0, 1, 2].map(|k| points.iter().zip(w).map(|(p, wi)| wi * p[k]).sum::<f64>() / total);
    let squared: Vec<f64> = w.iter().map(|wi| wi * wi).collect();
    let a = inertia(&points, w, centroid);
    let b = inertia(&points, &squared, centroid);
    let cofactor = |i: usize, j: usize| {
        let (r0, r1) = ((j + 1) % 3, (j + 2) % 3);
        let (c0, c1) = ((i + 1) % 3, (i + 2) % 3);
        a[r0][c0] * a[r1][c1] - a[r0][c1] * a[r1][c0]
    };
    let det: f64 = (0..3).map(|j| a[0][j] * cofactor(j, 0)).sum();
    let scale = a[0][0] + a[1][1] + a[2][2];
    if det <= 1e-12 * scale * scale * scale {
        return None;
    }
    let trace: f64 = (0..3)
        .flat_map(|i| (0..3).map(move |j| (i, j)))
        .map(|(i, j)| cofactor(i, j) * b[j][i])
        .sum::<f64>()
        / det;
    Some(3.0 - (3.0 * squared.iter().sum::<f64>() / total + trace) / total)
}

/// Construct observations qᵢ = R pᵢ + t + eᵢ (each eᵢ component N(0, σ²)) and superimpose.
pub(crate) fn observe_and_fit(
    molecule: &Molecule,
    truth: RigidTransform<f64>,
    noise: &Normal<f64>,
    w: &[f64],
    rng: &mut SplitMix64,
) -> Result<(Vec<f64>, Result<RigidEstimationResult<f64>, SciOxideError>), SciOxideError> {
    let n = molecule.atoms.len();
    let mut source = Vec::with_capacity(3 * n);
    let mut target = Vec::with_capacity(3 * n);
    for (_, p) in molecule.atoms {
        source.extend_from_slice(p);
        for x in truth.apply(*p)? {
            target.push(x + noise.sample(rng)?);
        }
    }
    let p = PointSet::from_rows(&source, 3)?;
    let q = PointSet::from_rows(&target, 3)?;
    let fit = estimate_rigid_transform_with_options(&p, &q, Some(w), RigidEstimationOptions::new());
    Ok((target, fit))
}

## Superposition from one observation

The next cell draws a uniform (Haar-measure) rotation matrix using seeded scioxide-random `SpecialOrthogonalGroup`, converts it to `Rotation` through `Rotation::from_matrix`, and uses it as the true rotation.
Translation is fixed at $(5, -3, 2)$ Å.
For each of four molecules, add coordinate noise $N(0, \sigma^2)$ with `Normal` and superimpose using selected weights.
Table `molecules` shows atom count, rank, singular values, RMSD, square root of expectation $\sqrt{\mathrm{E}[\mathrm{RMSD}^2]}$, rotation error $d(R_{\text{true}}, R)$ [deg], and failure classifications.
Singular values are dimensionless, computed after dividing cross-covariance by its largest absolute entry.
Single-observation RMSD fluctuates around expectation; compare expectations using replicate means in the next cell.
The scene shows the chosen reference structure and observations transformed back to its frame by estimated inverse $T^{-1}$, in common units [Å].
For carbon dioxide, whose transformation cannot be estimated, show observations unchanged.

## Comparing replicate means with expectations

The next cell holds true rotation fixed, redraws noise for $N$ superpositions, and computes RMSD² sample mean $\overline{\mathrm{RMSD}^2}$ and standard error $\mathrm{SE} = s/\sqrt{N}$ (sample standard deviation $s$) for both weight choices.
Table `statistics` shows mean, standard error, linearized expectation $\sigma^2 c$, and discrepancy in standard-error units $z = (\overline{\mathrm{RMSD}^2} - \sigma^2 c)/\mathrm{SE}$.
If the approximation applies, $\lvert z\rvert$ should generally be at most 2.
As $\sigma$ approaches molecular size, approximation errors exceed standard errors and $\lvert z\rvert$ grows.
Carbon dioxide fails every replicate, so only failure count is shown.
Many replicates take time, so this cell uses button execution.

use scioxide_core::{RealScalar, Tolerance};
use scioxide_random::{Normal, SeedableRng, SpecialOrthogonalGroup, SplitMix64};
use scioxide_spatial::{RigidTransform, Rotation};

let mut rng = SplitMix64::from_seed(stat_seed as u64);
let law = SpecialOrthogonalGroup::<f64>::new(3).map_err(|e| e.to_string())?;
let m = law.sample(&mut rng).map_err(|e| e.to_string())?;
let matrix = [[m[0], m[1], m[2]], [m[3], m[4], m[5]], [m[6], m[7], m[8]]];
let rotation =
    Rotation::from_matrix(matrix, Tolerance::from_sqrt_epsilon()).map_err(|e| e.to_string())?;
let truth = RigidTransform::new(rotation, [5.0, -3.0, 2.0]).map_err(|e| e.to_string())?;
let normal = Normal::new(0.0, stat_noise).map_err(|e| e.to_string())?;
let count = replications as usize;
let variance = stat_noise * stat_noise;

let mut rows = Vec::new();
for item in &MOLECULES {
    for (label, by_mass) in [("Uniform", false), ("Atomic mass", true)] {
        let w = weights(item, by_mass);
        let (mut sum, mut sum_squares, mut failures) = (0.0, 0.0, 0_usize);
        for _ in 0..count {
            let (_, fit) = observe_and_fit(item, truth, &normal, &w, &mut rng)
                .map_err(|e| e.to_string())?;
            match fit {
                Ok(fit) => {
                    let value = fit.rms_residual * fit.rms_residual;
                    sum += value;
                    sum_squares += value * value;
                }
                Err(_) => failures += 1,
            }
        }
        let successes = (count - failures) as f64;
        let theory = expected_rms_squared(item, &w).map(|c| variance * c);
        let (mean, se) = if successes > 1.0 {
            let mean = sum / successes;
            let sample_variance = (sum_squares - successes * mean * mean) / (successes - 1.0);
            (
                Some(mean),
                Some(RealScalar::sqrt(sample_variance / successes)),
            )
        } else {
            (None, None)
        };
        let z = match (mean, se, theory) {
            (Some(mean), Some(se), Some(theory)) if se > 0.0 => Some((mean - theory) / se),
            _ => None,
        };
        rows.push((
            item.name,
            label,
            item.atoms.len(),
            mean,
            se,
            theory,
            theory.map(|t| t / variance),
            z,
            failures,
        ));
    }
}

]);

);

With defaults ($\sigma = 0.05$ Å, $N = 500$, seed 3), all six rows have $z$ between −1.50 and 0.83, so means and linearized expectations agree within two standard errors.
Coefficient $c$ is 2.5, 1.8, and 2.33 ($(3n - 6)/n$) for benzene, methane, and ethanol with uniform weights, and 2.20, 1.08, and 1.63 with atomic-mass weights.
Carbon dioxide fails all 500 replicates and has no defined expectation.
At “σ = 2 Å,” the six non-carbon-dioxide rows also have $z$ from −1.87 to 1.64 and relative mean/expectation differences from −3.4 to +3.7%.
Standard errors at $N = 500$ are 1.1–2.4% of expectations, so this agreement shows only that first-order approximation bias is below a few percent.
At “σ = 3 Å,” methane (uniform) and ethanol (mass-weighted) have $z$ 3.6 and 3.9; at “σ = 5 Å,” both reach 6.9, with means above expectations.

## Summary

Pass atomic coordinate sets and weights to `estimate_rigid_transform_with_options` to obtain RMSD as `rms_residual`; mass weights make the centroid the center of mass.
For isotropic noise $\sigma$, estimate expected RMSD² by $\sigma^2(3n - 6)/n$ with uniform weights or by the inertia-tensor formula for general weights.
For the three non-carbon-dioxide molecules, neither $\sigma = 0.05$ Å nor 2 Å produced mean/expectation differences distinguishable at $N = 500$ standard errors (1.1–2.4% of expectation).
RMSD far above this expectation indicates structural differences unexplained by measurement error alone.
Planar molecules such as benzene uniquely determine rotation at rank 2; linear molecules such as carbon dioxide leave axial rotation undetermined and give `InvalidInput`.
Compare linear molecules using rotation-invariant quantities such as interatomic distances.
