Nearest-neighbor distances can test whether trees in a forest, cell nuclei in tissue, or stores on a map are uniformly random.
Clark and Evans (1954) introduced ratio $R$ of mean nearest-neighbor distance to its expectation under uniformly random points (complete spatial randomness, CSR).
$R < 1$ indicates clustering; $R > 1$ indicates regular arrangements with mutual avoidance.
This example derives closed-form kth-neighbor ($k$) distributions and means for uniform points, comparing with batch `KdTree` measurements using standard errors.
It also checks KD-tree results against exhaustive distances and measures upward distance errors from $(1 + \varepsilon)$ approximate search.

## kth-neighbor distances for uniform points

Place $N$ independent uniform points on torus $T = [0, 1)^2$, formed by identifying opposite unit-square edges.
Define distance between points $x, y$ using minimum-image differences modulo 1 on each axis:

$$
d(x, y) = \sqrt{\sum_{i=1}^{2} \min\bigl(|x_i - y_i|,\ 1 - |x_i - y_i|\bigr)^2}
$$


Let $R_k$ be the distance from point $x$ to its $k$th-nearest point.

For $r \le 1/2$, a radius-$r$ disk about $x$ does not overlap itself on the torus and has area $\pi r^2$.
The number of remaining $N - 1$ points in the disk follows binomial distribution $\mathrm{Bin}(N - 1, p)$ with $p = \pi r^2$.
Event $R_k \le r$ means at least $k$ points enter the disk, giving distribution function:

$$
F_k(r) = P(R_k \le r) = 1 - \sum_{j=0}^{k-1} \binom{N-1}{j} p^j (1 - p)^{N-1-j}, \qquad p = \pi r^2,\ 0 \le r \le \tfrac{1}{2}
$$


For $k = 1$ this is $F_1(r) = 1 - (1 - \pi r^2)^{N-1}$; taking $N \to \infty$ while retaining point density $\rho = N$ (points per unit area) approaches Poisson-process distribution $1 - e^{-\rho \pi r^2}$.

For distance $D$ to another point, $P(\pi D^2 \le u) = u$ holds for $u \le \pi/4$; the distribution function of $\pi D^2$ agrees in this range with uniform $[0, 1]$.
$U = \pi R_k^2$ is the $k$th-smallest of $N - 1$ such values (an order statistic), hence follows beta distribution $\mathrm{Beta}(k, N - k)$.
Writing $E[\sqrt{U}]$ using the beta function gives mean:

$$
E[R_k] = \frac{\Gamma(k + \tfrac{1}{2})\,\Gamma(N)}{\sqrt{\pi}\,\Gamma(k)\,\Gamma(N + \tfrac{1}{2})}
\approx \frac{\Gamma(k + \tfrac{1}{2})}{\Gamma(k)\sqrt{\pi \rho}}
$$


The approximate right side is the Poisson-process value; at $k = 1$ it is the Clark–Evans expectation $1/(2\sqrt{\rho})$.
The binomial/Poisson ratio is $\sqrt{N}\,\Gamma(N)/\Gamma(N + \tfrac12) \approx 1 + 1/(8N)$, with relative difference $2.5 \times 10^{-4}$ at $N = 500$.
These formulas extend the $r \le 1/2$ expressions over the full domain and therefore incur errors from probability $P(\mathrm{Bin}(N - 1, \pi/4) < k)$ of $R_k > 1/2$.
This probability is below $10^{-48}$ at $N \ge 100$ and $k \le 10$ and is negligible.

For a Poisson process, $E[R_1^2] = 1/(\pi\rho)$, so nearest-neighbor variance is $(4 - \pi)/(4\pi\rho) \approx 0.0683/\rho$.
Using measured mean $\bar r$, the Clark–Evans ratio is:

$$
R = \frac{\bar r}{E[R_1]} = 2\bar r\sqrt{\rho}
$$


Table ratios below use binomial mean $E[R_j]$ rather than the Poisson approximation (measured mean / $E[R_j]$), in the same form for ranks $j \ge 2$.
At $j = 1$, this ratio differs relatively from Clark–Evans $R$ by $2.5 \times 10^{-4}$.

## Standard errors and correlations between points

The $N$ distances within one configuration are dependent.
Mutual nearest neighbors count the same distance twice; in a planar Poisson process, fraction $6\pi/(8\pi + 3\sqrt{3}) \approx 0.62$ of points belongs to such pairs (Cox 1981).
Thus dividing one configuration's sample standard deviation by $\sqrt{N}$ underestimates the mean's standard error.

Generate $M$ independent configurations; from configuration means $m_1, \ldots, m_M$ compute overall mean $\bar m$ and standard error $\mathrm{SE} = s/\sqrt{M}$ ($s$ is the sample standard deviation of $m_i$).
If theory holds, $z = (\bar m - E[R_k])/\mathrm{SE}$ approximately follows a $t$ distribution with $M - 1$ degrees of freedom; at $M = 20$, event $|z| > 2.09$ has probability 5%.
$z$ is a statistical comparison; not every random seed gives $|z| < 2$.

## Periodic boundaries and edge effects

`KdTreeOptions::with_periodic_box(Some(&[1.0, 1.0]))` supplies a periodic box of side 1 on each axis and measures minimum-image distances.
Coordinates on each axis $i$ must lie in $[0, L_i)$ for box length $L_i$; out-of-range points give `InvalidInput`.
Pass options to the tree with `KdTree::with_options(&points, TreeMetric::Euclidean, options)`.
Without a periodic box (`None`), search uses ordinary Euclidean distance; `KdTree::new(&points)` constructs this default tree.

Near unit-square edges, part of each search disk lies outside the square and contains no neighbors.
Removing periodic boundaries therefore makes $R_k$ exceed theory.
Donnelly (1978) approximated mean nearest-neighbor distance in a region of area $A$ and perimeter $L$ with simulation-fitted coefficients:

$$
E[R_1] \approx 0.5\sqrt{\frac{A}{N}} + \left(0.0514 + \frac{0.041}{\sqrt{N}}\right)\frac{L}{N}
$$


For the unit square ($A = 1$, $L = 4$) at $N = 500$, this gives $0.02279$, 1.9% above torus value $0.02237$.
Larger $k$ expands search disks and increases the fraction crossing boundaries, increasing bias.

## Batch KD-tree queries

`KdTree` splits points at the median of the widest coordinate axis in each node, with depth at most $\lceil \log_2 N \rceil$.
Construction costs $O(dN\log N)$ work and $O(N + d)$ memory; coordinates are borrowed without cloning.
Nearest-neighbor queries prune subtrees whose box distance from the query exceeds the current $k$th distance.
Friedman, Bentley, and Finkel's (1977) analysis gives expected query cost $O(\log N)$ for low-dimensional uniform points.

Passing $k + 1$ to `KdTree::nearest_batch_into` finds $k + 1$ neighbors for every row at once.
Queries are tree points, so each row starts with the point itself (distance 0); neighbor rank $j$ appears at zero-based row position $j$.
Results sort by increasing distance, then increasing point index for ties.
Allocate workspace with `SearchWorkspaceRequest::new(k + 1, options).with_batch(N, N(k + 1), NonZeroUsize::MIN)`; queries themselves allocate no memory.
Wasm executes sequentially, so pass `ExecutionContext::sequential()` here.

The following block defines quantities shared by two cells.
`uniform_points` generates unit-square uniform points with `fill_uniforms` and returns them in $(x, y)$ order.
`fill_uniforms` values lie in $[0, 1)$, so every point satisfies periodic-box requirements.
`nearest_neighbors` constructs a KD tree and batch-queries neighbors for all points.
`epsilon` is approximate-search allowance $\varepsilon$; zero gives exact search.

```rust
//| id: spatial-nearest-neighbor-model
//| kind: definitions
//| title: "Unit-square uniform points and batch KD-tree queries"
//| crates: [scioxide-core, scioxide-random, scioxide-spatial]
use core::num::NonZeroUsize;
use scioxide_core::{ExecutionContext, SciOxideError};
use scioxide_random::{SplitMix64, fill_uniforms};
use scioxide_spatial::{
    KdTree, KdTreeOptions, Neighbor, PointSet, SearchOptions, SearchWorkspaceRequest, TreeMetric,
};

/// Return n uniform points in unit square [0, 1)², one (x, y) per row.
pub(crate) fn uniform_points(rng: &mut SplitMix64, n: usize) -> Result<Vec<f64>, SciOxideError> {
    let mut coordinates = vec![0.0; 2 * n];
    let mut attempts = 0;
    fill_uniforms(rng, &mut coordinates, &mut attempts)?;
    Ok(coordinates)
}

/// Find neighbors points per row in increasing distance order. Every row starts with itself (distance 0).
/// If periodic, use the unit square as a periodic box and measure minimum-image distances.
pub(crate) fn nearest_neighbors(
    coordinates: &[f64],
    neighbors: usize,
    periodic: bool,
    epsilon: f64,
) -> Result<Vec<Neighbor<f64>>, SciOxideError> {
    let n = coordinates.len() / 2;
    let points = PointSet::from_rows(coordinates, 2)?;
    let side = [1.0, 1.0];
    let options = KdTreeOptions::default().with_periodic_box(periodic.then_some(&side[..]));
    let tree = KdTree::with_options(&points, TreeMetric::Euclidean, options)?;
    let search = SearchOptions::new().with_epsilon(epsilon);
    let request = SearchWorkspaceRequest::new(neighbors, search).with_batch(
        n,
        n * neighbors,
        NonZeroUsize::MIN,
    );
    let mut workspace = tree.workspace(request)?;
    let mut found = vec![Neighbor::default(); n * neighbors];
    tree.nearest_batch_into(
        &points,
        neighbors,
        search,
        &mut found,
        &mut workspace,
        ExecutionContext::sequential(),
    )?;
    Ok(found)
}
```

## kth-neighbor distance distributions and means

The next cell selects point count $N$, neighbor rank $k$, periodicity, independent-configuration count $M$, and random seed, measuring ranks 1 through $k$ in $M$ configurations.
Draw directly from generator `SplitMix64`; identical seeds produce identical configuration sequences.
The plot compares the empirical distribution of all $k$th distances (symbols) with binomial $F_k$ (dashed).
The horizontal axis is dimensionless distance $r\sqrt{\rho}$, multiplying distance by $\sqrt{\rho} = \sqrt{N}$; under Poisson approximation the distribution becomes independent of $N$.
For each rank $j = 1, \ldots, k$, the table shows binomial mean, Poisson approximation, measured mean, standard error, $z$, and measured/theoretical mean ratio.
This cell also passes $N$, $k$, periodicity, and seed to the next cell's checks.

//|   - case: many-points
//|     expect:
//|       - {"artifact":"means","path":"/rows/9/1","approx":{"value":0.039401321076731,"rtol":1e-10}}
//|       - {"artifact":"means","path":"/rows/9/6","range":{"min":0.99,"max":1.01}}
use scioxide_core::RealScalar;
use scioxide_random::{SeedableRng, SplitMix64};

let (n, k, m) = (
    point_count as usize,
    neighbor_order as usize,
    replicates as usize,
);
let pi = core::f64::consts::PI;
let mut rng = SplitMix64::from_seed(seed as u64);
// replicate_means[r][j − 1]: mean jth-neighbor distance in configuration r
let mut replicate_means = Vec::with_capacity(m);
let mut pooled = Vec::with_capacity(m * n);
for _ in 0..m {
    let coordinates = uniform_points(&mut rng, n).map_err(|e| e.to_string())?;
    let found =
        nearest_neighbors(&coordinates, k + 1, periodic, 0.0).map_err(|e| e.to_string())?;
    // Each row starts with itself at position 0, so the jth neighbor is at position j.
    let rows = found.chunks_exact(k + 1);
    let means: Vec<f64> = (1..=k)
        .map(|j| rows.clone().map(|row| row[j].distance).sum::<f64>() / n as f64)
        .collect();
    pooled.extend(rows.map(|row| row[k].distance * (n as f64).sqrt()));
    replicate_means.push(means);
}

// Compute binomial mean Γ(j + 1/2) Γ(N) / (√π Γ(j) Γ(N + 1/2)) by recurrence.
let gamma_ratio_n = (1..n).fold(2.0 / RealScalar::sqrt(pi), |q, i| {
    q * i as f64 / (i as f64 + 0.5)
});
let gamma_ratio = |j: usize| {
    (1..j).fold(RealScalar::sqrt(pi) / 2.0, |q, i| {
        q * (i as f64 + 0.5) / i as f64
    })
};
let mut rows = Vec::with_capacity(k);
for j in 1..=k {
    let theory = gamma_ratio(j) * gamma_ratio_n / RealScalar::sqrt(pi);
    let poisson = gamma_ratio(j) / RealScalar::sqrt(pi * n as f64);
    let values: Vec<f64> = replicate_means.iter().map(|means| means[j - 1]).collect();
    let mean = values.iter().sum::<f64>() / m as f64;
    let variance = values.iter().map(|v| (v - mean) * (v - mean)).sum::<f64>() / (m - 1) as f64;
    let se = RealScalar::sqrt(variance / m as f64);
    rows.push((
        j,
        theory,
        poisson,
        mean,
        se,
        (mean - theory) / se,
        mean / theory,
    ));
}

// Empirical distribution (120 quantiles) and binomial F_k (horizontal axis r√ρ)
pooled.sort_by(f64::total_cmp);
let total = pooled.len();
let empirical: Vec<[f64; 2]> = (1..=120)
    .map(|q| q * total / 120 - 1)
    .map(|i| [pooled[i], (i + 1) as f64 / total as f64])
    .collect();
// Compute F_k by upper sum Σ_{j ≥ k} C(N − 1, j) pʲ (1 − p)^(N−1−j), avoiding cancellation when F_k ≪ 1.
let binomial_cdf = |scaled: f64| {
    let p = pi * scaled * scaled / n as f64;
    let mut term = RealScalar::powf(1.0 - p, (n - 1) as f64);
    let mut upper = 0.0;
    for j in 0..n {
        if j >= k {
            upper += term;
        }
        term *= (n - 1 - j) as f64 / (j + 1) as f64 * p / (1.0 - p);
    }
    upper
};
let theory_curve: Vec<[f64; 2]> = (0..=200)
    .map(|i| 3.5 * i as f64 / 200.0)
    .map(|s| [s, binomial_cdf(s)])
    .collect();
emit_chart!(
    serde_json::json!({
        "kind": "xy",
        "xLabel": "Normalized distance r√ρ [-]",
        "yLabel": "Distribution P(R_k ≤ r) [-]",
        "xMin": 0.0,
        "xMax": 3.5,
        "yMin": 0.0,
        "yMax": 1.0,
        "dataZoom": true,
        "tooltip": true,
        "layers": [
            {
                "id": "theory",
                "kind": "line",
                "name": "Binomial F_k (closed form)",
                "points": theory_curve,
                "style": { "lineType": "dashed", "showSymbol": false }
            },
            {
                "id": "empirical",
                "kind": "scatter",
                "name": "Empirical distribution (KD tree)",
                "points": empirical,
                "style": { "symbol": "circle" }
            }
        ]
    }),
    metadata = serde_json::json!({ "id": "cdf" })
);

let fixed5 = serde_json::json!({ "significantDigits": 5 });
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let fixed2 = serde_json::json!({ "fractionDigits": 2 });
let fixed4 = serde_json::json!({ "fractionDigits": 4 });
let columns = serde_json::json!([
    { "key": "0", "label": "Rank j", "type": "integer" },
    { "key": "1", "label": "Binomial mean E[R_j] [-]", "type": "number", "format": fixed5 },
    { "key": "2", "label": "Poisson approximation [-]", "type": "number", "format": fixed5 },
    { "key": "3", "label": "Measured mean [-]", "type": "number", "format": fixed5 },
    { "key": "4", "label": "Standard error [-]", "type": "number", "format": sci3 },
    { "key": "5", "label": "z [-]", "type": "number", "format": fixed2 },
    { "key": "6", "label": "Measured mean / binomial mean [-]", "type": "number", "format": fixed4 }

    metadata = serde_json::json!({ "id": "means" })

export!(periodic, &periodic);

## Exhaustive checks and approximate search

Computing all-pairs distances exhaustively checks that KD-tree pruning misses no neighbors.
Exhaustive computation needs $O(N^2)$ distances and selection of $k$ per point, substantially heavier than KD-tree $O(N\log N)$.
Only at $N \le 1000$, the next cell directly computes minimum-image distances (Euclidean without periodicity) in `f64` and compares indices and distances through rank $k$ with KD-tree results.
This reference calculation is independent of SciOxide distance functions.
Across-seam differences use $(1 - \max(a, b)) + \min(a, b)$, matching the KD tree, rather than $1 - |\Delta|$ ($a, b$ are the two axis coordinates).
In $1 - |\Delta|$, $|\Delta|$ is already rounded, so identical mathematical distances can differ from KD-tree final digits.

Setting `SearchOptions::with_epsilon(ε)` to $\varepsilon > 0$ prunes boxes farther than $1/(1 + \varepsilon)$ times the current $k$th distance, reducing visited nodes.
The returned $i$th distance $\tilde d_i$ then only satisfies $d_i \le \tilde d_i \le (1 + \varepsilon) d_i$ relative to true $i$th distance $d_i$.
Using these distances for statistics biases means upward and gives Clark–Evans ratios above 1.

The cell receives $N$, $k$, periodicity, and seed, regenerating the first configuration's points.

//| title: "Check KD-tree neighbors against exhaustive and approximate searches"

//| uses: [spatial-nearest-neighbor-model]

//|   - {"id":"coarse","label":"ε = 2","description":"A wider allowance increases mean-distance bias.","inputs":{"epsilon":2}}

//|   - case: default
//|     expect:
//|       - {"artifact":"search","path":"/rows/2/1","equals":0}
//|       - {"artifact":"search","path":"/rows/2/2","range":{"max":1e-15}}
//|       - {"artifact":"search","path":"/rows/2/4","range":{"min":1.0,"max":1.5}}
//|       - {"artifact":"search","path":"/rows/2/6","equals":0}

//|   - case: exact
//|     expect:
//|       - {"artifact":"search","path":"/rows/2/3","equals":0}
//|       - {"artifact":"search","path":"/rows/2/7","equals":0}
//|   - case: coarse
//|     expect:
//|       - {"artifact":"search","path":"/rows/2/6","equals":0}
//|       - {"artifact":"search","path":"/rows/2/7","approx":{"value":0.056222785,"rtol":1e-6}}
use scioxide_random::{SeedableRng, SplitMix64};

let n = sample["point_count"].as_u64().ok_or("Missing point count")? as usize;
let k = sample["neighbor_order"].as_u64().ok_or("Missing rank")? as usize;
let periodic = sample["periodic"].as_bool().ok_or("Missing periodic-boundary setting")?;
let seed = sample["seed"].as_u64().ok_or("Missing seed")?;
let mut rng = SplitMix64::from_seed(seed);
let coordinates = uniform_points(&mut rng, n).map_err(|e| e.to_string())?;
let exact = nearest_neighbors(&coordinates, k + 1, periodic, 0.0).map_err(|e| e.to_string())?;
let approximate =
    nearest_neighbors(&coordinates, k + 1, periodic, epsilon).map_err(|e| e.to_string())?;

// Exhaustive reference distances (direct f64 computation). Periodic axis differences use min(|Δ|, (1 − max) + min).
// Compute across-seam differences as (1 − max(a, b)) + min(a, b), rather than 1 − |Δ|, to match KD-tree rounding.
let reference_distance = |i: usize, j: usize| {
    let squared: f64 = (0..2)
        .map(|axis| {
            let (a, b) = (coordinates[2 * i + axis], coordinates[2 * j + axis]);
            let delta = (a - b).abs();
            let wrapped = if periodic {
                delta.min((1.0 - a.max(b)) + a.min(b))
            } else {
                delta
            };
            wrapped * wrapped
        })
        .sum();
    squared.sqrt()
};
// Like the KD tree, sort by increasing distance then index and retain k points.
let order = |a: &(f64, usize), b: &(f64, usize)| a.0.total_cmp(&b.0).then(a.1.cmp(&b.1));
let brute: Option<Vec<Vec<(f64, usize)>>> = (n <= 1000).then(|| {
    (0..n)
        .map(|i| {
            let mut all: Vec<(f64, usize)> = (0..n)
                .filter(|&j| j != i)
                .map(|j| (reference_distance(i, j), j))
                .collect();
            all.select_nth_unstable_by(k - 1, order);
            all.truncate(k);
            all.sort_by(order);
            all
        })
        .collect()
});

let mut rows = Vec::with_capacity(k);
for j in 1..=k {
    let pairs = || (0..n).map(|i| (exact[i * (k + 1) + j], approximate[i * (k + 1) + j]));
    let mismatches = brute.as_ref().map(|b| {
        (0..n)
            .filter(|&i| b[i][j - 1].1 != exact[i * (k + 1) + j].index)
            .count()
    });
    let largest_gap = brute.as_ref().map(|b| {
        (0..n)
            .map(|i| (b[i][j - 1].0 - exact[i * (k + 1) + j].distance).abs())
            .fold(0.0, f64::max)
    });
    let changed = pairs().filter(|(e, a)| e.index != a.index).count();
    let ratio_max = pairs()
        .map(|(e, a)| a.distance / e.distance)
        .fold(0.0, f64::max);
    let exceeded = pairs()
        .filter(|(e, a)| a.distance > (1.0 + epsilon) * e.distance)
        .count();
    let exact_mean = pairs().map(|(e, _)| e.distance).sum::<f64>();
    let approximate_mean = pairs().map(|(_, a)| a.distance).sum::<f64>();
    rows.push((
        j,
        mismatches,
        largest_gap,
        100.0 * changed as f64 / n as f64,
        ratio_max,
        1.0 + epsilon,
        exceeded,
        approximate_mean / exact_mean - 1.0,
    ));
}

## Summary

For unit-torus uniform points, rank-$k$ distances have binomial closed-form distribution $F_k$ and mean $\Gamma(k + \tfrac12)\Gamma(N)/(\sqrt{\pi}\Gamma(k)\Gamma(N + \tfrac12))$.
Compare measurements using standard errors from independent configuration means and assess discrepancies with $z$.
Distances within one configuration correlate through mutual-neighbor pairs; dividing their standard deviation by $\sqrt{N}$ does not give a standard error.
Removing periodicity biases means upward through edge effects; tests on bounded regions need periodic boxes or edge handling such as Donnelly correction.
Approximate search in `SearchOptions::with_epsilon` can enlarge each distance by a factor of up to $1 + \varepsilon$, so use $\varepsilon = 0$ when computing distance statistics.
