Forward kinematics computes end-effector position and orientation from robot-arm joint angles.
Each joint is a rigid transformation from the parent link's coordinate frame to its child's, and their composition determines the end-effector position.
Rigid-transformation composition depends on order, making the order of `compose` calls central to the calculation.
This example constructs a planar three-link arm with `RigidTransform` and compares with closed forms to check composition order, inverses, and homogeneous matrices.

## Arm model and closed form

Let link $i$ ($i = 1, 2, 3$) have length $l_i$ [m] and joint $i$ angle $\theta_i$.
Joint 1 is at the origin; all angles are about $z$ (perpendicular to the page), with $\theta_1$ measured from $x$ and $\theta_2, \theta_3$ from the preceding link.
Link $i$ has orientation $\Theta_i = \theta_1 + \cdots + \theta_i$, and joint-2, joint-3, and end-effector positions are

$$
x_i = \sum_{j=1}^{i} l_j \cos\Theta_j, \qquad y_i = \sum_{j=1}^{i} l_j \sin\Theta_j
$$

with $i = 1, 2, 3$ denoting joint 2, joint 3, and the end effector, respectively.
End-effector orientation is $\Theta_3 = \theta_1 + \theta_2 + \theta_3$.

## Joint rigid transformations and composition order

The map from joint $i$'s frame to link $i$'s tip frame rotates by $\theta_i$ about $z$, then advances $l_i$ along the rotated link:

$$
T_i(p) = R_z(\theta_i)\,(p + l_i e_x) = R_z(\theta_i)\,p + R_z(\theta_i)\,l_i e_x
$$

This is a `RigidTransform` with rotation $R_z(\theta_i)$ and translation $R_z(\theta_i)\,l_i e_x$ ($e_x = (1, 0, 0)$).
To obtain the end-effector (link-3 tip) position in the base frame, apply $T_3$, $T_2$, and $T_1$ in order from the child side.

$$
p_{\text{end effector}} = T_1\bigl(T_2\bigl(T_3(0)\bigr)\bigr) = (T_1 \circ T_2 \circ T_3)(0)
$$

`a.compose(b)` returns map $a \circ b$ applying `b` first, so write the composition as `t1.compose(t2)?.compose(t3)?`.
`compose` composes rotations by quaternion multiplication and renormalizes to unit length; translation $R_a t_b + t_a$ rounds each exact sum-of-products component once, as in `apply`.
Intermediate $T_1(0)$ and $(T_1 \circ T_2)(0)$ give joint-2 and joint-3 positions.
Expanding gives $l_1 e(\Theta_1) + l_2 e(\Theta_2) + l_3 e(\Theta_3)$ ($e(\phi) = (\cos\phi, \sin\phi, 0)$), agreeing with the closed form.

Reversed composition $T_3 \circ T_2 \circ T_1$ gives the end effector of another arm, joining lengths $l_3, l_2, l_1$ at angles $\theta_3, \theta_2, \theta_1$.
All rotations are about $z$ and commute, giving orientation $\theta_1 + \theta_2 + \theta_3$ in either order.
Translations do not commute, so end-effector positions generally differ.
Rigid transformations combine rotation and translation and are noncommutative even with aligned rotation axes.

`RigidTransform::inverse` returns $(R, t)^{-1} = (R^\top, -R^\top t)$; both $T^{-1} \circ T$ and $T \circ T^{-1}$ should be identity maps.
`as_matrix` returns the following row-major 4×4 homogeneous matrix acting on column vector $[x, y, z, 1]^\top$:

$$
\begin{pmatrix} R & t \\ 0 & 1 \end{pmatrix}
$$

Composition corresponds to multiplication of homogeneous matrices.

The following block defines quantities shared by two cells.
`joint` returns $T_i$; `closed_form` returns closed-form joint and end-effector positions.
The closed form is an independent verification reference.

```rust
//| id: spatial-robot-arm-model
//| kind: definitions
//| title: "Joint transformations and closed forms for a planar three-link arm"
//| crates: [scioxide-core, scioxide-spatial]
use scioxide_core::{SciOxideError, RealScalar};
use scioxide_spatial::{RigidTransform, Rotation};

/// T_i(p) = R_z(θ) (p + l e_x). angle is in degrees and length in m.
pub(crate) fn joint(angle: f64, length: f64) -> Result<RigidTransform<f64>, SciOxideError> {
    let rotation = Rotation::from_axis_angle([0.0, 0.0, 1.0], RealScalar::to_radians(angle))?;
    RigidTransform::new(rotation, rotation.apply([length, 0.0, 0.0])?)
}

/// Closed-form joint-2, joint-3, and end-effector positions (x_i, y_i) [m] (reference).
pub(crate) fn closed_form(angles: [f64; 3], lengths: [f64; 3]) -> [[f64; 2]; 3] {
    let mut heading = 0.0;
    let mut point = [0.0, 0.0];
    let mut out = [[0.0; 2]; 3];
    for i in 0..3 {
        heading += RealScalar::to_radians(angles[i]);
        point[0] += lengths[i] * RealScalar::cos(heading);
        point[1] += lengths[i] * RealScalar::sin(heading);
        out[i] = point;
    }
    out
}

/// Signed rotation angle about z [deg] ((−180°, 180°]).
pub(crate) fn heading(rotation: Rotation<f64>) -> f64 {
    let (axis, angle) = rotation.as_axis_angle();
    let signed = if axis[2] < 0.0 { -angle } else { angle };
    RealScalar::to_degrees(signed)
}
```

## Closed-form comparison and reversed composition

The next cell selects joint angles $\theta_1, \theta_2, \theta_3$ [deg] and lengths $l_1, l_2, l_3$ [m], constructs joint `RigidTransform` values, and maps the origin with $T_1$, $T_1 \circ T_2$, and $T_1 \circ T_2 \circ T_3$.
For joint 2, joint 3, and the end effector, table `positions` shows composed positions, closed-form positions, distances between them, and positions from reversed $T_3$, $T_3 \circ T_2$, and $T_3 \circ T_2 \circ T_1$.
Table `heading` compares orientations from both orders (signed angle about $z$) with $\theta_1 + \theta_2 + \theta_3$.
The plot draws the arm as a polyline, overlaid with dashed closed forms and dotted reversed compositions.
Both $x$ and $y$ axes are fixed at $\pm 3$ m from maximum link lengths, preventing rescaling as inputs change.
This cell passes angles and lengths to the next cell.

```rust
//| id: spatial-robot-arm-kinematics
//| ref: spatial-robot-arm-kinematics
//| title: "Compose joint rigid transformations and compare the end-effector position with a closed form"
//| run: reactive
//| uses: [spatial-robot-arm-model]
//| crates: [scioxide-core, scioxide-spatial]
//| exports: [angles, lengths]
//| inputs:
//|   theta1: {"type":"range","label":"Joint-1 angle θ₁ [deg]","description":"Link-1 orientation measured from x.","min":-180,"max":180,"step":5,"value":30}
//|   theta2: {"type":"range","label":"Joint-2 angle θ₂ [deg]","description":"Link-2 orientation measured from link 1.","min":-180,"max":180,"step":5,"value":45}
//|   theta3: {"type":"range","label":"Joint-3 angle θ₃ [deg]","description":"Link-3 orientation measured from link 2.","min":-180,"max":180,"step":5,"value":-60}
//|   length1: {"type":"range","label":"Link-1 length l₁ [m]","min":0.1,"max":1,"step":0.05,"value":0.5}
//|   length2: {"type":"range","label":"Link-2 length l₂ [m]","min":0.1,"max":1,"step":0.05,"value":0.4}
//|   length3: {"type":"range","label":"Link-3 length l₃ [m]","min":0.1,"max":1,"step":0.05,"value":0.25}
//| cases:
//|   - {"id":"straight","label":"θ = (0°, 0°, 0°)","description":"Fully extending the arm gives the same end position (l₁ + l₂ + l₃, 0) even with reversed composition.","inputs":{"theta1":0,"theta2":0,"theta3":0}}
//|   - {"id":"folded","label":"θ = (90°, 180°, 90°)","description":"Folding back at joint 2 makes position strongly order-dependent.","inputs":{"theta1":90,"theta2":180,"theta3":90}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"positions","path":"/rows/2/1","approx":{"value":0.7780217765,"atol":1e-9}}
//|       - {"artifact":"positions","path":"/rows/2/2","approx":{"value":0.7010750918,"atol":1e-9}}
//|       - {"artifact":"positions","path":"/rows/2/5","range":{"max":1e-15}}
//|       - {"artifact":"positions","path":"/rows/2/6","range":{"min":0.5}}
//|       - {"artifact":"heading","path":"/rows/0/1","approx":{"value":15,"atol":1e-12}}
//|       - {"artifact":"heading","path":"/rows/1/1","approx":{"value":15,"atol":1e-12}}
//|   - case: straight
//|     expect:
//|       - {"artifact":"positions","path":"/rows/2/1","approx":{"value":1.15,"atol":1e-15}}
//|       - {"artifact":"positions","path":"/rows/2/6","approx":{"value":1.15,"atol":1e-15}}
//|   - case: folded
//|     expect:
//|       - {"artifact":"positions","path":"/rows/2/1","approx":{"value":0.25,"atol":1e-15}}
//|       - {"artifact":"positions","path":"/rows/2/2","approx":{"value":0.1,"atol":1e-15}}
//|       - {"artifact":"positions","path":"/rows/2/5","range":{"max":1e-15}}
//|       - {"artifact":"positions","path":"/rows/2/6","approx":{"value":0.5,"atol":1e-15}}
//|       - {"artifact":"positions","path":"/rows/2/7","approx":{"value":-0.15,"atol":1e-15}}
//|       - {"artifact":"heading","path":"/rows/0/1","approx":{"value":0,"atol":1e-12}}
use scioxide_core::RealScalar;
use scioxide_spatial::RigidTransform;

let angles = [theta1, theta2, theta3];
let lengths = [length1, length2, length3];
let joints = [
    joint(theta1, length1).map_err(|e| e.to_string())?,
    joint(theta2, length2).map_err(|e| e.to_string())?,
    joint(theta3, length3).map_err(|e| e.to_string())?,
];
// Correct order: T₁, T₁∘T₂, T₁∘T₂∘T₃ (compose applies its argument first).
let mut forward = Vec::new();
let mut chain = RigidTransform::identity();
for t in joints {
    chain = chain.compose(t).map_err(|e| e.to_string())?;
    forward.push(chain);
}
// Reversed order: T₃, T₃∘T₂, T₃∘T₂∘T₁.
let mut reversed = Vec::new();
let mut chain = RigidTransform::identity();
for t in joints.iter().rev() {
    chain = chain.compose(*t).map_err(|e| e.to_string())?;
    reversed.push(chain);
}
let reference = closed_form(angles, lengths);
let names = ["Joint 2", "Joint 3", "End effector"];
let mut rows = Vec::new();
for i in 0..3 {
    let p = forward[i].apply([0.0; 3]).map_err(|e| e.to_string())?;
    let r = reversed[i].apply([0.0; 3]).map_err(|e| e.to_string())?;
    let c = reference[i];
    let gap = RealScalar::hypot(p[0] - c[0], p[1] - c[1]);
    rows.push((names[i], p[0], p[1], c[0], c[1], gap, r[0], r[1]));
}
let fixed6 = serde_json::json!({ "notation": "standard", "fractionDigits": 6 });
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let columns = serde_json::json!([
    { "key": "0", "label": "Point" },
    { "key": "1", "label": "Composed x [m]", "type": "number", "format": fixed6 },
    { "key": "2", "label": "Composed y [m]", "type": "number", "format": fixed6 },
    { "key": "3", "label": "Closed-form x [m]", "type": "number", "format": fixed6 },
    { "key": "4", "label": "Closed-form y [m]", "type": "number", "format": fixed6 },
    { "key": "5", "label": "Composition/closed-form distance [m]", "type": "number", "format": sci2 },
    { "key": "6", "label": "Reversed-order x [m]", "type": "number", "format": fixed6 },
    { "key": "7", "label": "Reversed-order y [m]", "type": "number", "format": fixed6 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "positions" })
);

// Orientation: z rotations commute, so both orders give θ₁ + θ₂ + θ₃.
let total = theta1 + theta2 + theta3;
// Wrap into (−180°, 180°].
let mut wrapped = total - 360.0 * RealScalar::round(total / 360.0);
if wrapped <= -180.0 {
    wrapped += 360.0;
}
let heading_rows = vec![
    ("T₁∘T₂∘T₃", heading(forward[2].rotation()), wrapped),
    ("T₃∘T₂∘T₁", heading(reversed[2].rotation()), wrapped),
];
let fixed9 = serde_json::json!({ "fractionDigits": 9 });
let heading_columns = serde_json::json!([
    { "key": "0", "label": "Composition" },
    { "key": "1", "label": "Rotation orientation [deg]", "type": "number", "format": fixed9 },
    { "key": "2", "label": "θ₁ + θ₂ + θ₃ [deg]", "type": "number", "format": fixed9 }
]);
emit_table_with_columns!(
    heading_columns,
    heading_rows,
    metadata = serde_json::json!({ "id": "heading" })
);

let polyline = |points: &[[f64; 2]]| {
    let mut line = vec![[0.0, 0.0]];
    line.extend_from_slice(points);
    line
};
let arm: Vec<[f64; 2]> = rows.iter().map(|r| [r.1, r.2]).collect();
let swapped: Vec<[f64; 2]> = rows.iter().map(|r| [r.6, r.7]).collect();
emit_chart!(serde_json::json!({
    "kind": "xy",
    "dataZoom": true,
    "tooltip": true,
    "xLabel": "x [m]",
    "yLabel": "y [m]",
    "xMin": -3.0,
    "xMax": 3.0,
    "yMin": -3.0,
    "yMax": 3.0,
    "layers": [
        {
            "id": "arm",
            "kind": "line",
            "name": "Joints and end effector from T₁∘T₂∘T₃",
            "points": polyline(&arm),
            "style": { "showSymbol": true }
        },
        {
            "id": "closed-form",
            "kind": "line",
            "name": "Closed form",
            "points": polyline(&reference),
            "style": { "lineType": "dashed", "showSymbol": false }
        },
        {
            "id": "swapped",
            "kind": "line",
            "name": "T₃∘T₂∘T₁ (reversed order)",
            "points": polyline(&swapped),
            "style": { "lineType": "dotted", "showSymbol": true }
        }
    ]
}));
export!(angles, angles);
export!(lengths, lengths);
```

With defaults ($\theta = (30°, 45°, -60°)$, $l = (0.5, 0.4, 0.25)$ m), joint 2 is at $(0.433013, 0.250000)$ m, joint 3 at $(0.536540, 0.636370)$ m, and the end effector at $(0.778022, 0.701075)$ m, differing from closed forms by at most $2.5 \times 10^{-16}$ m.
Reversed $T_3 \circ T_2 \circ T_1$ places the end effector at $(0.994333, -0.190624)$ m, a different point 0.92 m away.
Both rotation orientations are 15° ($= 30° + 45° - 60°$), with differences around $10^{-14}$ degrees.
At $\theta = (0°, 0°, 0°)$, both orders place the end effector at $(1.15, 0)$ m.
All translations then lie on $x$ and rotations are identity, so compositions commute in this case.
At $\theta = (90°, 180°, 90°)$, end positions split into $(0.25, 0.10)$ m and $(0.50, -0.15)$ m, both with orientation 0°.

## Inverse transformations and homogeneous matrices

The next cell reconstructs end-effector composition $T = T_1 \circ T_2 \circ T_3$ using preceding angles and lengths and checks whether compositions $T^{-1} \circ T$ and $T \circ T^{-1}$ with inverse $T^{-1}$ are identity, using rotation angles [rad] and translation magnitudes [m].
Table `matrix` shows $T$'s 4×4 homogeneous matrix: the last column gives end position and the upper-left 3×3 gives orientation.
Columns 1–3 are dimensionless, with rotation entries and bottom zeros; column 4's upper entries are translation [m] and its bottom 1 is dimensionless.
Reconstruct a transformation from this matrix with `RigidTransform::from_matrix` and add its difference from original $T$ to table `inverse`.

```rust
//| id: spatial-robot-arm-inverse
//| ref: spatial-robot-arm-inverse
//| title: "Check the inverse transformation and homogeneous matrix of the end-effector composition"
//| run: reactive
//| uses: [spatial-robot-arm-model]
//| crates: [scioxide-core, scioxide-spatial]
//| dependsOn:
//|   arm: spatial-robot-arm-kinematics
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"inverse","path":"/rows/0/1","range":{"max":1e-15}}
//|       - {"artifact":"inverse","path":"/rows/0/2","range":{"max":1e-15}}
//|       - {"artifact":"inverse","path":"/rows/1/2","range":{"max":1e-15}}
//|       - {"artifact":"inverse","path":"/rows/2/2","range":{"max":1e-15}}
//|       - {"artifact":"matrix","path":"/rows/0/4","approx":{"value":0.7780217765,"atol":1e-9}}
//|       - {"artifact":"matrix","path":"/rows/3/4","equals":1}
use scioxide_core::{RealScalar, Tolerance};
use scioxide_spatial::RigidTransform;

let read = |name: &str| -> Result<[f64; 3], String> {
    let values = arm[name].as_array().ok_or("Missing array")?;
    let mut out = [0.0; 3];
    for (o, v) in out.iter_mut().zip(values) {
        *o = v.as_f64().ok_or("Not a number")?;
    }
    Ok(out)
};
let (angles, lengths) = (read("angles")?, read("lengths")?);
let mut tool = RigidTransform::identity();
for i in 0..3 {
    let t = joint(angles[i], lengths[i]).map_err(|e| e.to_string())?;
    tool = tool.compose(t).map_err(|e| e.to_string())?;
}
let inverse = tool.inverse().map_err(|e| e.to_string())?;
let matrix = tool.as_matrix();
let rebuilt = RigidTransform::from_matrix(matrix, Tolerance::from_sqrt_epsilon())
    .map_err(|e| e.to_string())?;
// Deviation from identity: rotation angle and translation magnitude.
let deviation = |map: RigidTransform<f64>| {
    let t = map.translation();
    (
        map.rotation().as_axis_angle().1,
        RealScalar::hypot(RealScalar::hypot(t[0], t[1]), t[2]),
    )
};
let mut rows = Vec::new();
for (label, map) in [
    ("T⁻¹∘T", inverse.compose(tool).map_err(|e| e.to_string())?),
    ("T∘T⁻¹", tool.compose(inverse).map_err(|e| e.to_string())?),
    (
        "from_matrix(T)∘T⁻¹",
        rebuilt.compose(inverse).map_err(|e| e.to_string())?,
    ),
] {
    let (angle, shift) = deviation(map);
    rows.push((label, angle, shift));
}
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let columns = serde_json::json!([
    { "key": "0", "label": "Composition" },
    { "key": "1", "label": "Rotation angle [rad]", "type": "number", "format": sci2 },
    { "key": "2", "label": "Translation magnitude [m]", "type": "number", "format": sci2 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "inverse" })
);
let matrix_rows: Vec<(&str, f64, f64, f64, f64)> = ["1", "2", "3", "4"]
    .iter()
    .zip(matrix)
    .map(|(name, row)| (*name, row[0], row[1], row[2], row[3]))
    .collect();
let fixed6 = serde_json::json!({ "notation": "standard", "fractionDigits": 6 });
let matrix_columns = serde_json::json!([
    { "key": "0", "label": "Row" },
    { "key": "1", "label": "Column 1 [-]", "type": "number", "format": fixed6 },
    { "key": "2", "label": "Column 2 [-]", "type": "number", "format": fixed6 },
    { "key": "3", "label": "Column 3 [-]", "type": "number", "format": fixed6 },
    { "key": "4", "label": "Column 4 [m]", "type": "number", "format": fixed6 }
]);
emit_table_with_columns!(
    matrix_columns,
    matrix_rows,
    metadata = serde_json::json!({ "id": "matrix" })
);
```

With defaults, both $T^{-1} \circ T$ and $T \circ T^{-1}$ have zero rotation angles and translation magnitudes $2.9 \times 10^{-17}$ m and $8.2 \times 10^{-17}$ m, agreeing with identity at rounding scale.
The upper-left 3×3 is a 15° rotation about $z$ ($\cos 15° = 0.965926$, $\sin 15° = 0.258819$); the last column is end position $(0.778022, 0.701075, 0)$ m and the last row $(0, 0, 0, 1)$.
The transformation reconstructed with `from_matrix` differs from $T$ by rotation angle $5.6 \times 10^{-17}$ rad and translation $1.0 \times 10^{-16}$ m.

## Summary

Represent joints by `RigidTransform` that rotate then advance along the link; compose in $T_1 \circ T_2 \circ T_3$ order because `compose` applies its argument first, matching joint and end positions to closed forms within rounding.
Reversing composition leaves planar orientation $\theta_1 + \theta_2 + \theta_3$ unchanged but changes end position because translations do not commute.
Composition with `inverse` differs from identity at rounding scale; the `as_matrix` homogeneous matrix stores position in its last column and orientation at upper left, and `from_matrix` restores the original transformation.
For spatial arms, represent each joint by rotation/translation `RigidTransform` and `compose` from the base side in order to compute forward kinematics the same way.
