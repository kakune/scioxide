Significance probabilities for Student's $t$ test and the $F$ test, binomial tails, and posterior distributions in Bayesian inference are expressed in terms of the regularized incomplete beta function.
It is a probability obtained by dividing an integral over part of $[0, 1]$ by the complete integral $B(a, b)$; forming small tail probabilities by subtraction from 1 loses significant digits.
This page explains how beta and log-beta functions and the regularized incomplete beta function are evaluated, including its complement, logarithms, and inverses.
Gamma function evaluation is covered in [Gamma functions, polygamma functions, and the Pochhammer symbol](../gamma-family/), incomplete gamma functions in [Incomplete gamma functions](../incomplete-gamma/), and error functions and their inverses in [Error functions, Dawson's integral, and inverse error functions](../error-functions/).
ULP (unit in the last place) denotes the spacing of floating-point numbers at the true value, and $\varepsilon = 2^{-52}$ is binary64 machine epsilon.

## Beta and log-beta functions

For $a, b > 0$, the beta function (Euler's integral of the first kind) is defined by the following integral (DLMF 5.12.1).

$$
B(a, b) = \int_0^1 t^{a-1} (1 - t)^{b-1} \, dt = \frac{\Gamma(a)\Gamma(b)}{\Gamma(a + b)}.
$$

The substitution $t = 1 - u$ gives the symmetry $B(a, b) = B(b, a)$, and the quotient of gamma functions provides analytic continuation to complex $a, b$.
`beta` and `ln_beta` accept real and complex numbers (`NumericScalar`).
Real arguments require $a, b > 0$; a zero shape gives `DomainError` (`Pole`), and a negative shape gives `DomainError` (`OutsideDomain`).
When $B(a, b)$ exceeds the type's range (when either shape is roughly smaller than $1/\text{maximum value}$), the result is `NumericalInstability` (`Overflow`); the options form `beta_with_options` returns scaled and logarithmic forms.
`ln_beta` does not overflow for either large or small shapes.

When $a, b$ exceeds 171, $\Gamma(a)$ itself exceeds the binary64 range, so the product and quotient of gamma functions cannot be formed directly.
Taking logarithms to obtain $\ln \Gamma(a) + \ln \Gamma(b) - \ln \Gamma(a + b)$ subtracts three large numbers for large shapes and suffers cancellation when the result is small.
Real `beta` and `ln_beta` select a method according to the size of the shapes.

- If either shape is 1, use $B(1, b) = 1/b$.
- If both are integers or half-integers and $a + b \le 32$, form a finite product using the recurrence $B(a + 1, b) = B(a, b)\, a/(a + b)$, starting from values such as $B(1, 1) = 1$ and $B(\tfrac12, \tfrac12) = \pi$.
  As long as the product of the integer factors obtained by doubling each factor is below $2^{53}$, the product is exact, so rounding occurs only once at the end.
- If both are below 64 (and the smaller is at least $10^{-150}$), reduce each gamma argument to near 1 using $\Gamma(x + 1) = x\Gamma(x)$, evaluate it with a series for $1/\Gamma$, and form the ratio $\Gamma(a)\Gamma(b)/\Gamma(a + b)$ using double-word arithmetic (representing a value as the sum of two binary64 numbers, with about 106 bits of precision).
  Repeat the entire calculation in double-word arithmetic only when rounding uncertainty in the inexpensive approximation could change the rounding of the final result.
- For larger shapes, cancel the leading terms of Stirling's formula $\ln \Gamma(x) = (x - \tfrac12)\ln x - x + \tfrac12 \ln 2\pi + c(x)$ before evaluation.
  Setting $s = a + b$ gives

$$
\ln B(a, b) = \left(a - \tfrac12\right)\ln\frac{a}{s} + \left(b - \tfrac12\right)\ln\frac{b}{s} - \tfrac12 \ln s + \tfrac12 \ln 2\pi + c(a) + c(b) - c(s)
$$

  in which the large term $s \ln s$ cancels.
  Here $c(x)$ is the correction in Stirling's series ($1/(12x) - 1/(360x^3) + \cdots$), and $\ln(b/s) = -\ln(1 + a/b)$ is evaluated using `ln_1p` when $a/b$ is small.
  For a small shape $a < 32$ paired with large $b$, use $\ln \Gamma(a)$ directly and handle the cancellation between $-a \ln s$ and $(b - \tfrac12)\ln(b/s) + a$ in double-word arithmetic.

Where $\ln B(a, b)$ is near 0 (near $B(a, b) = 1$), retain the cancelling components in an exact accumulation before rounding.
For complex arguments, form $\exp(\ln\Gamma(a) + \ln\Gamma(b) - \ln\Gamma(a + b))$ using the Lanczos approximation to $\ln\Gamma$; the sum in `ln_beta` is not reduced to the principal branch.

Over the range checked against independently generated reference values, real `beta` and `ln_beta` have errors within 4 ULP in binary64 and 1 ULP in binary32.
The range for `ln_beta` includes neighborhoods of zeros of $\ln B$; in a separate sample of 4160 points, the maximum errors are 1.0 ULP for `beta` and 0.5 ULP for `ln_beta`.
binary32 calculations use binary64 internally and round only once.
Complex arguments have no uniform ULP target; assess accuracy using the estimated error in the options form.
Neither function has a scoped API because its operation count has an upper bound independent of the arguments.

## Regularized incomplete beta function

The regularized incomplete beta function truncates the integral at the upper endpoint $x$ and normalizes it by $B(a, b)$ (DLMF 8.17.1, 8.17.2).

$$
I_x(a, b) = \frac{1}{B(a, b)} \int_0^x t^{a-1} (1 - t)^{b-1} \, dt, \qquad 0 \le x \le 1.
$$

$I_x(a, b)$ is the cumulative distribution function of a beta distribution with shapes $a, b$; it increases monotonically from $I_0 = 0$ to $I_1 = 1$ and has the complementary symmetry $I_x(a, b) = 1 - I_{1-x}(b, a)$ (DLMF 8.17.4).
The tail of a binomial distribution $X \sim \mathrm{Bin}(n, p)$ is $P(X \ge k) = I_p(k, n - k + 1)$, and the two-sided probability for Student's $t$ distribution (with $\nu$ degrees of freedom) is $P(\lvert T \rvert \ge t) = I_{\nu/(\nu + t^2)}(\nu/2, 1/2)$.

Real `beta_inc` accepts $a, b \ge 0$ and $0 \le x \le 1$.
At a zero shape it returns the limits $I_x(0, b) = 1$ ($x > 0$) and $I_x(a, 0) = 0$ ($x < 1$), and the options form has termination status `Limit`.
At $a = b = 0$, at $a = 0$ with $x = 0$, and at $b = 0$ with $x = 1$, the limit depends on the direction, giving `DomainError` (`Undefined`); negative shapes and $x$ outside $[0, 1]$ give `DomainError` (`OutsideDomain`).
For complex $z$, it evaluates $I_z(a, b) = z^a\, {}_2F_1(a, 1 - b; a + 1; z)/(a B(a, b))$ (DLMF 8.17.7) using principal powers, with branch cuts $(-\infty, 0]$ and $[1, \infty)$.
The shapes may remain real while only $z$ is complex.

### Choosing the direction

Evaluation of the incomplete beta function first chooses whether to work on the $x$ or $1 - x$ side.
The continued fraction below converges rapidly for $x < (a + 1)/(a + b + 2)$; when $x$ is larger, evaluating $I_{1-x}(b, a)$ and applying symmetry is faster (DLMF §8.17(v)).
`beta_inc` chooses the direction at this boundary.
The boundary is near the beta distribution's mean $a/(a + b)$, so the value $J$ on the selected side is often below $\tfrac12$, but it can be close to 1 when the shapes differ greatly.
When applying symmetry, form $1 - J$ as $-\operatorname{expm1}(\ln J)$, avoiding subtraction from a rounded exponential even when $J$ is close to 1.

### Finite sums, power series, and continued fractions

For $(a, b, x)$ in the selected direction, try the methods in this order.

1. If both shapes are integers and $a + b \le 33$, accumulate the finite binomial sum $I_x(a, b) = \sum_{j=a}^{n} \binom{n}{j} x^j (1 - x)^{n - j}$ ($n = a + b - 1$) with compensated summation.
   There are $b$ terms; if an intermediate power becomes subnormal, proceed to the next method.
2. Where $B(a, b)$ is representable in binary64 (on the half-integer grid or for $a + b < 128$), sum a power series in binary64 and return it if its estimated relative uncertainty is at most $16\varepsilon$.
   The power series is either the endpoint series $I_x = x^a\, {}_2F_1(a, 1 - b; a + 1; x)/(a B)$ (DLMF 8.17.7; the term ratio is at most $1/2$ when $x \le 1/2$ and $b x \le 1/2$) or the hypergeometric series $I_x = x^a (1 - x)^b\, {}_2F_1(a + b, 1; a + 1; x)/(a B)$ (DLMF 8.17.8; all terms are positive, and it converges within 166 terms if the term ratio is at most $0.8$).
3. Otherwise, form the prefactor $x^a (1 - x)^b / (a B(a, b))$ logarithmically and multiply by the endpoint series or the following continued fraction (DLMF §8.17(v)).

$$
I_x(a, b) = \frac{x^a (1 - x)^b}{a B(a, b)} \cfrac{1}{1 + \cfrac{d_1}{1 + \cfrac{d_2}{1 + \cdots}}}, \qquad
d_{2m} = \frac{m(b - m)x}{(a + 2m - 1)(a + 2m)}, \quad d_{2m+1} = -\frac{(a + m)(a + b + m)x}{(a + 2m)(a + 2m + 1)}.
$$

Evaluate the continued fraction forward using the modified Lentz method.
The modified Lentz method updates a continued-fraction approximation by the product of two ratios; when an intermediate denominator approaches 0, it substitutes a value of small magnitude to avoid division by zero, and stops when the update ratio is within about $\varepsilon$ of 1.
The first denominator $1 - (a + b)x/(a + 1)$ becomes as small as $2/(a + b + 2)$ at the direction boundary $x = (a + 1)/(a + b + 2)$.
If this denominator is below $1/2$, bits lost to cancellation are amplified by subsequent updates, so the entire continued fraction is evaluated in double-word arithmetic.

### Large shapes and the prefactor

For large shapes, the prefactor's exponent $a \ln x + b \ln(1 - x) - \ln B(a, b)$ is a difference of large terms.
For example, at $a = 100$, $b = 9901$, and $x = 0.01$, the terms are $a \ln x \approx -460.5$, $b \ln(1 - x) \approx -99.5$, and $\ln B(a, b) \approx -561.4$; after subtracting $\ln a$, the exponent is $-3.23$.
Rounding each term to binary64 introduces an absolute error of $561 \varepsilon \approx 1.2 \times 10^{-13}$ into the exponent, which directly becomes the prefactor's relative error.
`beta_inc` forms this exponent in double-word arithmetic, using the Stirling form above for $\ln B(a, b)$.
For $x < \sqrt{\varepsilon}$, $\ln(1 - x)$ is formed from the series for $\operatorname{ln1p}(-x)$; otherwise it is the logarithm of the double-word subtraction $1 - x$.

`scioxide-special` does not implement a uniform asymptotic expansion for large shapes, such as Temme's expansion.
It uses the continued fraction even for large shapes; near the mean, the number of terms increases slowly with the shapes.
The case $n = 10^5$, $k = 1000$ ($a = 1000$, $b = 99001$) in the cell below finishes in 89 iterations.
The work budget (`Budget` in `BetaOptions`, default 65536) counts these iterations and power-series terms.

### Complements, logarithms, and inverses

`beta_inc_q` evaluates the upper tail $1 - I_x(a, b) = I_{1-x}(b, a)$ directly, retaining relative accuracy even for small upper tails.
`beta_inc_log` and `beta_inc_log_q` compute $\ln I_x(a, b)$ and $\ln(1 - I_x(a, b))$ without forming the probabilities.
Even when a probability is below the type's smallest subnormal number, its logarithm is returned as a finite value.
`beta_inc_log` at $x = 0$ and `beta_inc_log_q` at $x = 1$ return $-\infty$ as the value.
These three functions return a binary64 finite sum or power series if its relative uncertainty can be shown to be at most $16\varepsilon$; otherwise they form the logarithm of the smaller tail in double-word arithmetic and obtain the requested side as its complement in the form $\ln(1 - e^{\ell})$.

There are four inverse functions.
They return $x$ satisfying $I_x(a, b) = p$ for `beta_inc_inv`, $1 - I_x(a, b) = q$ for `beta_inc_q_inv`, $\ln I_x(a, b) = \ln p$ for `beta_inc_inv_log`, and $\ln(1 - I_x(a, b)) = \ln q$ for `beta_inc_q_inv_log`.
All start from an asymptotic initial guess and apply Halley's method (a cubically convergent variant of Newton's method) in the coordinate $\ln(x/(1 - x))$, safeguarded by a root bracket; the last few steps use tails evaluated in double-word arithmetic and stop at the type's precision.
The inverses require $a, b > 0$; $a \le 0$, $b \le 0$, $p$ outside $[0, 1]$, and positive $\ln p$ give `DomainError` (`OutsideDomain`), while $\ln p = -\infty$ gives `NonFinite`.
$p = 0$ returns $x = 0$ and $p = 1$ returns $x = 1$ (reversed for `beta_inc_q_inv`).
Use the logarithmic inverses when the probability is below the type's range.

### Accuracy of incomplete beta functions

Over the range checked against independently generated reference values, real incomplete beta functions and their complements, logarithms, and inverses have errors within 32 ULP in binary64 and 1 ULP in binary32.
In a separate sample of 4160 points, the maximum error of `beta_inc` is 12 ULP.
The estimated error in the options form applies a 32 ULP envelope, calibrated against reference values, to the value; it is not an interval with guaranteed containment.
Complex `beta_inc` has no uniform ULP target.
Every function that uses iteration has a scoped API.

## Quartiles of a symmetric beta distribution

The next cell uses the four inverses with distinct inputs to find the first quartile $x_1$ ($I_{x_1}(a, a) = 1/4$) of a symmetric beta distribution with shapes $a = b$.
Pass $p = 1/4$ to `beta_inc_inv`, $q = 3/4$ to `beta_inc_q_inv`, and their logarithms to the logarithmic inverses; all should give the same $x_1$.
The table also shows the residual obtained by substituting $x_1$ back into `beta_inc`.
There are three checks: symmetry requires the sum with the third quartile to equal 1; the identity $I_x(a, a) = \tfrac12 I_{4x(1-x)}(a, \tfrac12)$ ($0 \le x \le \tfrac12$); and the difference from the quartile for shapes with a closed form.
The closed-form quartiles are $\sin^2(\pi/8)$, $1/4$, and $\tfrac12 - \sin(\pi/18)$, obtained by solving $I_x(\tfrac12, \tfrac12) = (2/\pi)\arcsin\sqrt{x}$, $I_x(1, 1) = x$, and $I_x(2, 2) = 3x^2 - 2x^3$.

```rust
    { "key": "2", "label": "First quartile x₁ [-]", "type": "number", "format": digits16 },
```

For the default $a = b = 2$, all four inverses return $x_1 = 0.3263518223330697$ (only `beta_inc_q_inv_log` is 1 ULP smaller at 0.3263518223330696), and the residual after substitution into `beta_inc` is $\pm 1.1 \times 10^{-16}$.
The difference from the closed form $\tfrac12 - \sin(\pi/18)$ is $5.6 \times 10^{-17}$, the symmetry residual is 0, and the identity residual is $2.2 \times 10^{-16}$; all are at the scale of binary64 rounding.
With $a = b = \tfrac12$, the cumulative curve rises steeply at both ends and flattens in the center; every residual is 0, including the difference from the quartile $\sin^2(\pi/8) = 0.1464466094067262$.
For $a = b = 100$, the distribution concentrates near $\tfrac12$, with $x_1 = 0.4761369702994594$ and an interquartile range of 0.048.
The identity residual then increases to $5.1 \times 10^{-15}$.
This occurs because $4x_1(1 - x_1) = 0.9977$ is close to 1, where the slope of $I_y(100, \tfrac12)$ (a density of about 95) amplifies rounding in the coordinate $y$; it is not an error in the function.
Agreement of the four inverses checks consistency; the closed form and the identity provide independent checks.

## Binomial tails and cancellation in subtraction

Let a process have defect rate $p = 0.01$, and let $X \sim \mathrm{Bin}(n, p)$ be the number of defects in a sample inspection of $n$ items.
The probability of finding at least $k$ defects is $P(X \ge k) = I_p(k, n - k + 1)$, and the probability of at most $k - 1$ defects is $P(X < k) = 1 - I_p(k, n - k + 1)$.
The next cell evaluates both probabilities with `beta_inc` and `beta_inc_q` and the logarithm of the lower probability with `beta_inc_log_q`, at $k$ located 0, 3, 6, and 10 standard deviations $\sqrt{\mu}$ above the mean $\mu = np$, and at $k = 1$.
For the smaller tail, compare the relative errors of direct evaluation and subtraction of the larger tail from 1.
The reference accumulates $\ln P(X = j)$ by compensated summation of logarithms of the probability-mass ratios $P(X = j + 1)/P(X = j) = (n - j)p/((j + 1)(1 - p))$, normalizes by the total sum, and sums the masses (an independent computation using only f64 intrinsic methods).
The last two table columns show the algorithm identifier and iteration count returned by `beta_inc_q_with_options`.

```rust
let mut log_pmf = vec![0.0_f64; n + 1];
let mut compensation = 0.0;
for j in 0..n {
    let step = (((n - j) as f64 * p) / ((j + 1) as f64 * (1.0 - p))).ln() - compensation;
    let next = log_pmf[j] + step;
    compensation = (next - log_pmf[j]) - step;
    log_pmf[j + 1] = next;
}
let log_sum = |terms: &[f64]| {
    let top = terms.iter().copied().fold(f64::NEG_INFINITY, f64::max);
    top + terms.iter().map(|t| (t - top).exp()).sum::<f64>().ln()
};
let log_total = log_sum(&log_pmf);
let mut ks: Vec<usize> = [0.0, 3.0, 6.0, 10.0]
    .iter()
    .map(|c| (mean + c * RealScalar::sqrt(mean)).ceil() as usize)
    .collect();
ks.insert(0, 1);
ks.dedup();
let mut rows = Vec::new();
for k in ks {
    // P(X ≥ k) = I_p(k, n − k + 1), P(X < k) = 1 − I_p(k, n − k + 1).
    let (a, b) = (k as f64, (n - k + 1) as f64);
    let upper = beta_inc(a, b, p).map_err(|e| e.to_string())?;
    let detailed =
        beta_inc_q_with_options(a, b, p, BetaOptions::default()).map_err(|e| e.to_string())?;
    let lower = detailed.clone().try_value().map_err(|e| e.to_string())?;
    let log_lower = beta_inc_log_q(a, b, p).map_err(|e| e.to_string())?;
    let ref_lower = log_sum(&log_pmf[..k]) - log_total;
    let ref_upper = log_sum(&log_pmf[k..]) - log_total;
    // The smaller tail and the value obtained by subtracting the larger tail from 1. Leave errors undefined for values rounded to 0.
    let (direct, subtracted, reference) = if ref_lower < ref_upper {
        (lower, 1.0 - upper, ref_lower)
    } else {
        (upper, 1.0 - lower, ref_upper)
    };
    let relative = |value: f64| (value > 0.0).then(|| (value / reference.exp() - 1.0).abs());
    // If the larger tail is the lower one, form the reference with ln P(X < k) = ln1p(−P(X ≥ k)).
    let ref_log_lower = if ref_lower < ref_upper {
        ref_lower
    } else {
        (-ref_upper.exp()).ln_1p()
    };
    rows.push((
        k,
        lower,
        upper,
        relative(direct),
        relative(subtracted),
        log_lower,
        log_lower - ref_log_lower,
        detailed.algorithm().to_string(),
        detailed.counts().iterations(),
    ));
}
let columns = serde_json::json!([
    { "key": "0", "label": "k [items]", "type": "integer" },
    { "key": "1", "label": "P(X < k)（beta_inc_q） [-]", "type": "number", "format": sci3 },
    { "key": "2", "label": "P(X ≥ k)（beta_inc） [-]", "type": "number", "format": sci3 },
    { "key": "3", "label": "Smaller-tail relative error [-]", "type": "number", "format": sci3, "nullText": "Rounded to 0" },
    { "key": "4", "label": "Subtraction relative error [-]", "type": "number", "format": sci3, "nullText": "Rounded to 0" },
    { "key": "5", "label": "ln P(X < k)（beta_inc_log_q） [-]", "type": "number", "format": fixed3 },
    { "key": "6", "label": "Logarithmic absolute error [-]", "type": "number", "format": sci3 },
    { "key": "7", "label": "beta_inc_q algorithm" },
    { "key": "8", "label": "Iterations [count]", "type": "integer" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "tails" })
);
```

For the default $n = 10^4$ ($\mu = 100$), `beta_inc_q` returns $P(X < 1) = 0.99^{10000} = 2.249 \times 10^{-44}$ in the $k = 1$ row with relative error $2.2 \times 10^{-16}$.
Forming the same probability from `beta_inc` as $1 - I_p(1, 10000)$ gives 0.
For $k = 160$, the upper tail $1.71 \times 10^{-8}$ has relative error $2.7 \times 10^{-15}$ using `beta_inc`, but $2.3 \times 10^{-9}$ when subtracting the lower probability 0.99999998 from 1, losing about 6 digits.
For $k = 200$, the upper tail $5.6 \times 10^{-19}$ becomes 0 under subtraction.
The values from $10^{-15}$ to $10^{-14}$ in the relative-error columns reflect rounding in the reference recurrence; this reference cannot distinguish smaller errors.
The algorithm identifiers `probability/lower_log_tail@1` and `upper_log_tail@1` denote paths that form the logarithm of the smaller tail in double-word arithmetic; the continued fraction for $a = 100$, $b = 9901$ finishes in 42 iterations.

With $n = 100$, $a + b = 101 < 128$, so many rows use the binary64 power-series path (`upper_linear_tail`); forming the upper tail $7.1 \times 10^{-5}$ at $k = 7$ by subtraction gives relative error $5.6 \times 10^{-13}$.
For $n = 10^5$, $P(X = 0) = e^{-1005.03}$ is below the smallest binary64 subnormal $4.9 \times 10^{-324}$; `beta_inc_q` returns 0, whereas `beta_inc_log_q` returns $\ln P(X < 1) = -1005.0336$.
Even at $k = 1000$ ($a = 1000$, $b = 99001$) for the same $n$, the continued fraction finishes in 89 iterations.
At this $n$, reference rounding error grows to $7 \times 10^{-14}$, and the table's relative errors are of that magnitude.

## API

The functions in this family are listed below.
The Complex column indicates whether a function accepts `NumericScalar` and supports complex arguments.
Options forms return `SpecialFunctionResult`, containing an estimated error, termination status, work counts, and algorithm identifier.
Only computations whose work depends on the arguments provide a scoped API `*_scoped(.., options, scope)`.

| Standard form | Computes | Complex | Options form | Scoped API |
|---|---|---|---|---|
| `beta` | $B(a, b)$ | Yes | `beta_with_options` | None |
| `ln_beta` | $\ln B(a, b)$ | Yes | `ln_beta_with_options` | None |
| `beta_inc` | $I_x(a, b)$ | Yes | `beta_inc_with_options` | `beta_inc_scoped` |
| `beta_inc_q` | $1 - I_x(a, b)$ | Real only | `beta_inc_q_with_options` | `beta_inc_q_scoped` |
| `beta_inc_log` | $\ln I_x(a, b)$ | Real only | `beta_inc_log_with_options` | `beta_inc_log_scoped` |
| `beta_inc_log_q` | $\ln(1 - I_x(a, b))$ | Real only | `beta_inc_log_q_with_options` | `beta_inc_log_q_scoped` |
| `beta_inc_inv` | $x$ satisfying $I_x(a, b) = p$ | Real only | `beta_inc_inv_with_options` | `beta_inc_inv_scoped` |
| `beta_inc_q_inv` | $x$ satisfying $1 - I_x(a, b) = q$ | Real only | `beta_inc_q_inv_with_options` | `beta_inc_q_inv_scoped` |
| `beta_inc_inv_log` | $x$ satisfying $\ln I_x(a, b) = \ln p$ | Real only | `beta_inc_inv_log_with_options` | `beta_inc_inv_log_scoped` |
| `beta_inc_q_inv_log` | $x$ satisfying $\ln(1 - I_x(a, b)) = \ln q$ | Real only | `beta_inc_q_inv_log_with_options` | `beta_inc_q_inv_log_scoped` |

All use `BetaOptions` options with only a work budget (`Budget`, default 65536).
Precision is fixed: increasing the budget does not improve accuracy, but allows slowly converging inputs to finish.
If an incomplete beta function reaches the budget, its standard form returns `ConvergenceFailure` (`IterationLimit`); the options form returns a result with termination status `IterationLimit` if an estimate remains available.

## Summary

The beta function uses recurrence products on the integer and half-integer grid, gamma ratios for moderate shapes, and a Stirling form with leading terms cancelled for large shapes; `ln_beta` avoids overflow and meets the 4 ULP target even near zeros of $\ln B$.
The incomplete beta function chooses the direction in which the continued fraction converges rapidly using the boundary $(a + 1)/(a + b + 2)$, then tries finite sums, binary64 power series, and double-word prefactors with modified Lentz continued fractions in order.
Avoid forming small tails by subtraction from 1; use `beta_inc_q` for upper tails, and logarithmic forms and logarithmic inverses for probabilities below the type's range.
Even for large shapes, the continued fraction finishes in a few dozen iterations, so the default work budget suffices.
