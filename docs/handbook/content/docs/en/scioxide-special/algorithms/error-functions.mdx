Normal probabilities, fundamental heat-equation solutions, and diffusion hitting probabilities can be expressed using the error function, an integral of the Gaussian $e^{-t^2}$.
For large $x$, the upper tail $\operatorname{erfc}(x)$ decreases as $e^{-x^2}$, and subtraction $1 - \operatorname{erf}(x)$ retains no significant digits.
This page explains region-dependent evaluation and accuracy of the error-function family (`erf`, `erfc`, `erfcx`, `log_erfc`, `erfi`, `dawson`) and inverses (`erfinv`, `erfcinv`).
Standard normal functions use the $\operatorname{erfcx}$ kernel and inverse error functions described here; see [Normal tails and Owen's T function](../normal-tails-and-faddeeva/).
[Faddeeva function and Voigt profile](../faddeeva-and-voigt/) covers evaluation for complex arguments.
ULP (unit in the last place) denotes the spacing of floating-point numbers at the true value, and $\varepsilon = 2^{-52}$ is binary64 machine epsilon.

## Error function and complementary error function

The error function and complementary error function arise from Gaussian integrals and are defined as follows (DLMF 7.2.1, 7.2.2).

$$
\operatorname{erf}(z) = \frac{2}{\sqrt{\pi}} \int_0^z e^{-t^2} \, dt, \qquad \operatorname{erfc}(z) = 1 - \operatorname{erf}(z) = \frac{2}{\sqrt{\pi}} \int_z^\infty e^{-t^2} \, dt.
$$

Both are entire; $\operatorname{erf}$ is odd, and $\operatorname{erfc}(-z) = 2 - \operatorname{erfc}(z)$.
The standard normal cumulative distribution function is $\Phi(x) = \tfrac12 \operatorname{erfc}(-x/\sqrt{2})$.
`erf`, `erfc`, `erfcx`, `log_erfc`, `erfi`, and `dawson` accept real and complex numbers (`NumericScalar`).
Complex values are computed through the Faddeeva function, whose method is explained in [Faddeeva function](oxref:special-faddeeva-definition).
Real `erf`, `erfc`, and `dawson` have no error conditions for finite arguments; NaN and infinite arguments give `NonFinite`.

### Why tails avoid subtraction

At $x = 6$, $\operatorname{erfc}(6) = 2.15 \times 10^{-17}$, and $\operatorname{erf}(6) = 1 - 2.15 \times 10^{-17}$ rounds to 1 in binary64.
Forming the upper probability as `1.0 - erf(x)` gives 0; even at $x = 3$, only about the first 11 digits remain correct.
When subtracting numbers near 1, the relative error is the rounding error before subtraction ($\varepsilon/2$ near 1) divided by the magnitude of the result.
`erfc` evaluates the tail without subtracting from 1.

### Evaluation of real erf and erfc

Real `erf` and `erfc` use approximations with a fixed operation count, computed in binary64 and rounded once for binary32.

- For $\lvert x \rvert \le 1$, `erf` uses the Cephes-derived rational function $x\,P(x^2)/Q(x^2)$ in $x^2$.
- For $\lvert x \rvert < 1$, `erfc` directly evaluates a degree-18 Chebyshev interpolant of $\operatorname{erfc}(\tfrac12 + t)$ ($\lvert t \rvert \le \tfrac12$), avoiding the subtraction $1 - \operatorname{erf}$.
- For $\lvert x \rvert \ge 1$, use $\operatorname{erfc}(x) = e^{-x^2}\operatorname{erfcx}(x)$ and $\operatorname{erf}(x) = 1 - \operatorname{erfc}(x)$.
  Correct the rounding error $e$ in $x^2$ (the low word of an error-free product of $x \cdot x = s + e$) with $e^{-s}(1 - e)$, preventing exponent-argument rounding from entering the result's relative error.
- For negative $x$, use $\operatorname{erfc}(x) = 2 - \operatorname{erfc}(-x)$.

Beyond $x \approx 26.54$, $\operatorname{erfc}(x)$ falls below the normal range and becomes subnormal, reducing relative accuracy.
Beyond $x \approx 27.23$ it falls below half the smallest subnormal and rounds to 0; for $x > 27.3$, return 0 without computation.
Neither case is an error.
Use `erfcx` or `log_erfc` for tails in that range.
Real `erf` and `erfc` have no numerical ULP targets; the specified behavior is binary64 computation followed by a single rounding to binary32.
Since real evaluation has fixed work, scoped APIs such as `erf_scoped` and `erfc_scoped` accept only complex arguments; passing real arguments does not compile.

### Scaled complementary error function and log_erfc

The scaled complementary error function is $\operatorname{erfcx}(z) = e^{z^2}\operatorname{erfc}(z) = w(iz)$, where $w$ is the Faddeeva function (DLMF 7.2.3).
For large positive $x$ it decreases slowly as $\operatorname{erfcx}(x) \approx 1/(x\sqrt{\pi})$, remaining nonzero even where $\operatorname{erfc}$ underflows.
For negative $x$ it grows as $2e^{x^2}$ and gives `NumericalInstability` (`Overflow`) below $x \approx -26.63$ in binary64 and at $x < -9.38$ in binary32 (options forms return scaled and logarithmic forms).

Real $\operatorname{erfcx}$ selects methods by interval with a fixed operation count.

- For $[-1, 1)$, divide into 32 intervals of width $1/16$; for $[1, 32)$, divide each binary interval ($[2^k, 2^{k+1})$) into 16, storing a degree-9 Chebyshev interpolant in monomial form on each interval.
  The interpolant has relative error at most $2^{-56}$ on each interval; storing the center value in two words leaves only one final rounding.
  Within a binary interval, the center shares the same binary interval and leading significand bits as $x$, so the difference $t = x - c$ is exact (Sterbenz's lemma).
- For $x \ge 32$, evaluate $\operatorname{erfcx}(x) = (1 + u S(u))/(\sqrt{\pi}x)$ ($u = x^{-2}$) with compensated division.
  $S$ is a degree-5 polynomial interpolating $(\sqrt{\pi}x\operatorname{erfcx}(x) - 1)/u$ on $u \in [0, 1/1024]$; $S(0) = -\tfrac12$ equals the second-term coefficient in the DLMF 7.12.1 asymptotic expansion $\operatorname{erfcx}(x) \sim \frac{1}{\sqrt{\pi}x}\sum_{m=0}^{\infty} (-1)^m \frac{(1/2)_m}{x^{2m}}$.
- For $x < -1$, use $\operatorname{erfcx}(x) = 2e^{x^2} - \operatorname{erfcx}(-x)$ with $x^2$ split exactly.

`log_erfc` computes $\ln\operatorname{erfc}(x)$ using $\operatorname{ln1p}(-\operatorname{erf}(x))$ for $x < \tfrac12$ and $\ln\operatorname{erfcx}(x) - x^2$ elsewhere.
It retains values even at $x$ where $\operatorname{erfc}(x)$ underflows; errors occur only at $x > 1.3 \times 10^{154}$, where $x^2$ overflows.
For complex arguments, it is the principal logarithm of $\operatorname{erfc}(z)$, with a branch cut wherever $\operatorname{erfc}(z)$ lies on the negative real axis.

Over the range checked against independent references, real `erfcx` and `log_erfc` meet error targets of 4 ULP in binary64 and 1 ULP in binary32.
Options-form estimates use envelopes of 2 binary64 units for `erfcx` and 4 units for `log_erfc`, with widths measured in ULP of the value.

### Imaginary error function and Dawson's integral

The imaginary error function $\operatorname{erfi}(z) = -i\operatorname{erf}(iz) = \frac{2}{\sqrt{\pi}}\int_0^z e^{t^2}\,dt$ is odd and entire; for real $x$ it grows as $e^{x^2}/(x\sqrt{\pi})$.
Dawson's integral $D(z) = e^{-z^2}\int_0^z e^{t^2}\,dt$ (DLMF 7.2.5) is odd; on the real axis, it reaches its maximum $0.54104$ at $x^* = 0.92414$ and decreases as $1/(2x)$ for $x \to \infty$.
On the real axis, the two functions satisfy $\operatorname{erfi}(x) = \frac{2}{\sqrt{\pi}}e^{x^2}D(x)$.

Real `dawson` uses tables of the same form as $\operatorname{erfcx}$.
For $\lvert x \rvert < \tfrac12$, use $D = x(1 + vQ(v))$ ($v = x^2$; $Q$ is a degree-8 polynomial); for $[\tfrac12, 8)$, use degree-9 Chebyshev interpolation on binary intervals subdivided into 16; for $x \ge 8$, use $D = (1 + uT(u))/(2x)$ ($u = x^{-2}$; $T$ is a degree-15 polynomial).
Error targets checked against independent references are 4 ULP in binary64 and 1 ULP in binary32; options-form estimated errors use 2 binary64 units.
Options forms also return the derivative $D'(x) = 1 - 2xD(x)$, evaluated as $D' = -uT(u)$ in the asymptotic region to avoid cancellation.

Real `erfi` is formed by multiplying `dawson` by $2/\sqrt{\pi}$ and $e^{x^2}$.
Keeping $e^{x^2}$ as a separate scale lets the options form `erfi_with_options` return scaled values (significand and binary exponent) and logarithmic forms even when $\lvert x \rvert > 26.7$ puts the value beyond binary64 range.
The standard form then gives `NumericalInstability` (`Overflow`).
`erfi` has no uniform ULP target; the options form combines Dawson-kernel error, the final multiplication, and rounding in $x^2$ into its error estimate.

### Inverse error functions

Normal quantiles and inverse-transform random sampling require the inverse error function $x = \operatorname{erfinv}(y)$ ($-1 \le y \le 1$), finding $x$ from $y = \operatorname{erf}(x)$.
For $y \to \pm 1$, $\operatorname{erf}'(x) = \frac{2}{\sqrt{\pi}}e^{-x^2} \to 0$, so the inverse is sensitive to the difference $1 - \lvert y \rvert$ from 1; merely rounding $y$ to binary64 can move $x$ substantially.
When the complementary probability $q = 1 - \lvert y \rvert$ is known, pass $q$ directly to `erfcinv`, which solves $\operatorname{erfc}(x) = q$.

`erfinv` and `erfcinv` are real-only (`RealScalar`) and use noniterative piecewise rational approximations with Boost.Math inverse-error coefficients.
Below, $p$ is the argument of `erfinv` and $q = 1 - \lvert p \rvert$ its complement.

- For $\lvert p \rvert \le \tfrac12$, use $p(\lvert p \rvert + 10)(c + R(\lvert p \rvert))$ ($R$ is rational and $c$ is constant).
- For $q \ge \tfrac14$, use $\sqrt{-2\ln q}/(c + R(q - \tfrac14))$.
- For $q < \tfrac14$, use the variable $t = \sqrt{-\ln q}$ and separate $t(c + R(t - t_0))$ on four intervals: $t < 3$, $t < 6$, $t < 18$, and above ($t_0 = 1.125$, 3, 6, 18).

`erfcinv` forms $\ln q$ directly from $q = \min(p, 2 - p)$, avoiding loss of small tail probabilities through subtraction from 1 and supporting positive subnormal probabilities.
At the endpoints it returns `erfinv(±1) = ±∞`, `erfcinv(0) = +∞`, and `erfcinv(2) = −∞`, with options-form termination status `Limit`.
Outside $[-1, 1]$ or $[0, 2]$, it gives `DomainError` (`OutsideDomain`).
Both meet targets of 4 ULP in binary64 and 1 ULP in binary32; for `erfcinv`, this includes subnormal $p$.
Options-form estimated errors also use 4 units (1 unit for binary32).
There are no scoped APIs because work is fixed.

## Complementary-error tails and asymptotic expansions

The next cell evaluates `erfc`, `1.0 - erf(x)`, `erfcx`, and `log_erfc` at eight points from $x = 1$ to 28, then uses `erfcinv` to recover $x$.
For an independent check, it sums the DLMF 7.12.1 asymptotic expansion truncated at $N$ terms in f64 and reports the relative difference from `erfcx`.
The asymptotic expansion is divergent: at small $x$, adding terms does not keep reducing error; the error reaches a minimum at some term count.
Changing control $N$ moves the $x$ at which the expansion starts agreeing with `erfcx`.
The lower table shows $D(x^*)$ and the options-form derivative at Dawson's maximum $x^* = 0.9241388730045918$; scaled and logarithmic forms of $\operatorname{erfi}(30)$ beyond binary64 range; and the difference of its logarithm from that of the leading asymptotic term, a reference computed in f64.

```rust
//| id: special-erfc-tail
//| ref: special-erfc-tail
//| title: "Compare complementary-error tails with an asymptotic expansion"
//| run: reactive
//| crates: [scioxide-special]
//| inputs:
//|   terms: {"type":"range","label":"Asymptotic term count N","min":1,"max":12,"step":1,"value":6}
//| cases:
//|   - {"id":"one-term","label":"N = 1","description":"Only the leading term 1/(x√π). Relative differences are of order 1/(2x²), still 6 × 10⁻⁴ at x = 28.","inputs":{"terms":1}}
//|   - {"id":"many-terms","label":"N = 12","description":"Agreement reaches the rounding level for x ≥ 10, but at x = 1 and 3, adding terms does not reduce relative differences below 10⁻⁴.","inputs":{"terms":12}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"tail","path":"/rows/2/1","approx":{"value":2.1519736712498913e-17,"rtol":1e-14}}
//|       - {"artifact":"tail","path":"/rows/2/2","equals":0}
//|       - {"artifact":"tail","path":"/rows/4/1","approx":{"value":5.395865611607901e-176,"rtol":1e-14}}
//|       - {"artifact":"tail","path":"/rows/4/4","range":{"max":1e-13}}
//|       - {"artifact":"tail","path":"/rows/7/1","equals":0}
//|       - {"artifact":"tail","path":"/rows/7/5","approx":{"value":-787.9052061945577,"rtol":1e-14}}
//|       - {"artifact":"tail","path":"/rows/7/6","equals":null}
//|       - {"artifact":"dawson","path":"/rows/0/1","approx":{"value":0.5410442246351817,"rtol":1e-14}}
//|       - {"artifact":"dawson","path":"/rows/1/1","range":{"min":-1e-15,"max":1e-15}}
//|       - {"artifact":"dawson","path":"/rows/4/1","approx":{"value":896.0269940046969,"rtol":1e-14}}
//|       - {"artifact":"dawson","path":"/rows/5/1","range":{"min":5.55e-4,"max":5.57e-4}}
//|   - case: one-term
//|     expect:
//|       - {"artifact":"tail","path":"/rows/7/4","range":{"min":6e-4,"max":7e-4}}
//|   - case: many-terms
//|     expect:
//|       - {"artifact":"tail","path":"/rows/3/4","range":{"max":1e-15}}
//|       - {"artifact":"tail","path":"/rows/1/4","range":{"min":1e-5}}
use scioxide_special::{
    ErrorFunctionOptions, dawson_with_options, erf, erfc, erfcinv, erfcx, erfi_with_options,
    log_erfc,
};

let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let fixed4 = serde_json::json!({ "fractionDigits": 4 });
let digits10 = serde_json::json!({ "significantDigits": 10 });
let n_terms = terms as u32;
let mut rows = Vec::new();
for x in [1.0, 3.0, 6.0, 10.0, 20.0, 26.0, 27.0, 28.0] {
    let tail = erfc(x).map_err(|e| e.to_string())?;
    let naive = 1.0 - erf(x).map_err(|e| e.to_string())?;
    let scaled = erfcx(x).map_err(|e| e.to_string())?;
    let logarithm = log_erfc(x).map_err(|e| e.to_string())?;
    // Independent check: sum erfcx(x) ~ (1/(x√π)) Σ_{m<N} (−1)^m (1/2)_m / x^{2m} (DLMF 7.12.1) in f64.
    let mut term = 1.0;
    let mut sum = 0.0;
    for m in 0..n_terms {
        sum += term;
        term *= -(f64::from(m) + 0.5) / (x * x);
    }
    let asymptotic = sum / (x * std::f64::consts::PI.sqrt());
    // Recover x with erfcinv. Recovery is impossible where erfc rounds to 0.
    let back = if tail > 0.0 {
        Some(erfcinv(tail).map_err(|e| e.to_string())? - x)
    } else {
        None
    };
    let difference = (scaled / asymptotic - 1.0).abs();
    rows.push((x, tail, naive, scaled, difference, logarithm, back));
}
let columns = serde_json::json!([
    { "key": "0", "label": "x [-]", "type": "number", "format": fixed4 },
    { "key": "1", "label": "erfc(x) [-]", "type": "number", "format": sci3 },
    { "key": "2", "label": "1 − erf(x) [-]", "type": "number", "format": sci3 },
    { "key": "3", "label": "erfcx(x) [-]", "type": "number", "format": sci3 },
    { "key": "4", "label": "Relative difference from asymptotic expansion [-]", "type": "number", "format": sci3 },
    { "key": "5", "label": "log_erfc(x) [-]", "type": "number", "format": fixed4 },
    { "key": "6", "label": "Difference after erfcinv recovery [-]", "type": "number", "format": sci3, "nullText": "Cannot recover" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "tail" })
);
// At Dawson's maximum x*, D′(x*) = 1 − 2x* D(x*) = 0.
let peak = 0.924_138_873_004_591_8;
let dawson =
    dawson_with_options(peak, ErrorFunctionOptions::default()).map_err(|e| e.to_string())?;
let slope = dawson.clone().try_derivative().map_err(|e| e.to_string())?;
let value = dawson.try_value().map_err(|e| e.to_string())?;
// erfi(30) exceeds binary64 range; inspect scaled and logarithmic options-form values.
let erfi =
    erfi_with_options(30.0_f64, ErrorFunctionOptions::default()).map_err(|e| e.to_string())?;
let scaled = erfi.scaled().ok_or("No scaled form")?.value().real();
let log = erfi
    .logarithmic()
    .and_then(|l| l.value().log_magnitude())
    .ok_or("No logarithmic form")?;
let others = vec![
    ("D(x*)", value),
    ("D′(x*) (options-form derivative)", slope),
    ("erfi(30) significand", scaled.significand()),
    ("erfi(30) binary exponent", scaled.exponent() as f64),
    ("ln erfi(30)", log),
    // Reference (f64 intrinsic methods): difference from the logarithm of the leading asymptotic term erfi(x) ≈ e^{x²}/(x√π).
    // The next term predicts 1/(2x²) = 5.56 × 10⁻⁴.
    (
        "ln erfi(30) − (x² − ln(x√π))",
        log - (900.0 - (30.0 * std::f64::consts::PI.sqrt()).ln()),
    ),
];
let other_columns = serde_json::json!([
    { "key": "0", "label": "Quantity" },
    { "key": "1", "label": "Value [-]", "type": "number", "format": digits10 }
]);
emit_table_with_columns!(
    other_columns,
    others,
    metadata = serde_json::json!({ "id": "dawson" })
);
```

For the default $N = 6$, `1.0 - erf(x)` differs from `erfc` starting at the 12th digit at $x = 3$ and becomes 0 at $x \ge 6$.
`erfc` returns $5.40 \times 10^{-176}$ at $x = 20$ and the subnormal $5.2 \times 10^{-319}$ at $x = 27$, becoming 0 at $x = 28$.
Even at $x = 28$, `erfcx` and `log_erfc` return 0.02014 and $-787.9052$.
At $x = 1$, the relative difference from the expansion is 1.03, making it unusable; it is $6.4 \times 10^{-8}$ at $x = 6$, $3.9 \times 10^{-14}$ at $x = 20$, and at most $2 \times 10^{-15}$ at $x \ge 26$.
For $N = 12$, relative differences at $x \ge 10$ fall to at most $1.1 \times 10^{-16}$, but at $x = 3$ remain at $1.2 \times 10^{-4}$.
Terms of the expansion decrease to a minimum at $m \approx x^2$ and then grow, so the attainable error at $x = 3$ is of order $e^{-x^2} = 1.2 \times 10^{-4}$.
Recovery through `erfcinv` has error 0 or $8.9 \times 10^{-16}$ (1 ULP) for $x \le 26$; the subnormal $\operatorname{erfc}(27)$ has fewer significant digits, giving $8.8 \times 10^{-9}$.

In the lower table, $D(x^*) = 0.5410442246$ and the options-form derivative $D'(x^*) = 0$ match the properties of the maximum.
The scaled form of $\operatorname{erfi}(30)$ is $1.6174271718 \times 2^{1292} \approx 1.4 \times 10^{389}$ and the logarithmic form is $896.0269940$.
The difference $5.56 \times 10^{-4}$ from the leading asymptotic logarithm $900 - \ln(30\sqrt{\pi}) = 896.0264377$ agrees with the next term $1/(2x^2) = 5.56 \times 10^{-4}$ in the expansion $\operatorname{erfi}(x) \sim \frac{e^{x^2}}{x\sqrt{\pi}}\bigl(1 + \frac{1}{2x^2} + \cdots\bigr)$.

## API

The functions in this family are listed below.
The Complex column indicates whether a function accepts `NumericScalar` and supports complex arguments.
Options forms return `SpecialFunctionResult`, containing an estimated error, termination status, work counts, and algorithm identifier.
Scoped APIs `*_scoped(.., options, scope)` accept only complex arguments.

| Standard form | Computes | Complex | Options form | Scoped API |
|---|---|---|---|---|
| `erf` | $\operatorname{erf}(z)$ | Yes | `erf_with_options` | `erf_scoped` (complex only) |
| `erfc` | $\operatorname{erfc}(z)$ | Yes | `erfc_with_options` | `erfc_scoped` (complex only) |
| `erfcx` | $e^{z^2}\operatorname{erfc}(z)$ | Yes | `erfcx_with_options` | `erfcx_scoped` (complex only) |
| `log_erfc` | $\ln\operatorname{erfc}(z)$ | Yes | `log_erfc_with_options` | `log_erfc_scoped` (complex only) |
| `erfi` | $-i\operatorname{erf}(iz)$ | Yes | `erfi_with_options` | `erfi_scoped` (complex only) |
| `dawson` | $D(z)$ | Yes | `dawson_with_options` | `dawson_scoped` (complex only) |
| `erfinv` | $x$ satisfying $\operatorname{erf}(x) = p$ | Real only | `erfinv_with_options` | None |
| `erfcinv` | $x$ satisfying $\operatorname{erfc}(x) = p$ | Real only | `erfcinv_with_options` | None |

All use `ErrorFunctionOptions` options with only a work budget (`Budget`, default 65536).
Real evaluations finish in one work unit, so the budget affects only complex evaluations.

## Summary

`erfc` evaluates the error-function tail directly as $e^{-x^2}\operatorname{erfcx}(x)$; avoid the subtraction `1.0 - erf(x)`.
Use `erfcx` or `log_erfc` where $\operatorname{erfc}$ becomes subnormal at $x > 26.54$ and zero at $x > 27.23$.
`erfcx` and Dawson's integral use interval interpolation and asymptotic tables with fixed operation counts, meeting the 4 ULP target.
Even when `erfi` exceeds binary64 range, options-form scaled and logarithmic values remain available.
Inverse error functions use noniterative rational approximations; pass complementary tail probabilities directly to `erfcinv`.
