Both error functions with complex arguments and Voigt profiles describing spectroscopic absorption lines are computed using the Faddeeva function $w(z)$.
Real error functions use the interval-specific tables explained in [Error functions, Dawson's integral, and inverse error functions](../error-functions/).
In the complex plane, $e^{-z^2}$ grows or decays depending on direction, requiring different methods by region.
This page explains the evaluation regions and methods for `faddeeva`, reflection into the lower half-plane and overflow handling, and Voigt profiles `voigt_profile` and `voigt_complex`.
$\varepsilon = 2^{-52}$ is binary64 machine epsilon; an estimated error of $n$ units denotes a width of $n\varepsilon$ times the value's magnitude.

## Faddeeva function

The Faddeeva function (complex error function) is the entire function defined as follows (DLMF 7.2.3).

$$
w(z) = e^{-z^2}\operatorname{erfc}(-iz) = e^{-z^2}\left(1 + \frac{2i}{\sqrt{\pi}}\int_0^z e^{t^2}\,dt\right).
$$

On the imaginary axis, $w(iy) = \operatorname{erfcx}(y)$; on the real axis, $\operatorname{Re} w(x) = e^{-x^2}$ and $\operatorname{Im} w(x) = \frac{2}{\sqrt{\pi}}D(x)$, where $D$ is Dawson's integral.
Since $\operatorname{erfc}(\zeta) = e^{-\zeta^2}w(i\zeta)$, complex `erf`, `erfc`, `erfcx`, `erfi`, `dawson`, and `log_erfc` all use $w$.
`faddeeva` accepts only complex numbers (`Complex<S>`); its value is bounded in the upper half-plane, with $w(z) \approx i/(\sqrt{\pi}z)$ for $\lvert z \rvert \to \infty$.

In the upper half-plane $\operatorname{Im} z \ge 0$, the method depends on the location of $z = x + iy$ (here $x$ means $\lvert \operatorname{Re} z \rvert$).

- On the imaginary axis ($x = 0$) and real axis ($y = 0$), use the real $\operatorname{erfcx}$ and Dawson kernels.
- For large $\lvert z \rvert$, namely where $y > 7$ or where $x > 6$ and $y > 0.1$ (all $y > 10^{-10}$ when $x > 8$, and all $y > 0$ when $x > 28$), truncate Laplace's continued fraction $w(z) = \dfrac{i/\sqrt{\pi}}{z - \dfrac{1/2}{z - \dfrac{1}{z - \dfrac{3/2}{z - \cdots}}}}$ at depth $\lfloor 3.9 + 11.398/(0.08254x + 0.1421y + 0.2023)\rfloor$ and evaluate backward.
  For $\max(x, y) > 10^7$, use the leading term $i/(\sqrt{\pi}z)$.
- Elsewhere, use the series of Algorithm 916 by Zaghloul and Ali (2011).
  It sums Gaussians with spacing $a = 0.5183$, forming Gaussian factors from one exponential and powers of a decay factor, and stops when a term is at most $\varepsilon$ times the sum.
  Use the real kernel for the leading term $e^{-x^2}\operatorname{erfcx}(y)$; for $x < 5 \times 10^{-4}$, form difference terms with $\sinh$ to avoid cancellation.

In the lower half-plane, use the reflection $w(z) = 2e^{-z^2} - w(-z)$ (DLMF §7.4).
Where $\lvert \operatorname{Im} z \rvert > \lvert \operatorname{Re} z \rvert$, $e^{-z^2}$ grows without bound; if the value exceeds the type's range, standard forms return `NumericalInstability` (`Overflow`), while the options form `faddeeva_with_options` returns a logarithmic form.
If $\operatorname{Re} z \cdot \operatorname{Im} z$ overflows and prevents forming the phase of $e^{-z^2}$, the result is `NumericalInstability` (`LossOfSignificance`).
Series and continued-fraction terms count toward the work budget; a scoped API `faddeeva_scoped` is available.
There is no uniform ULP target; options forms estimate 64 units for the value and 128 units for the derivative $w'(z) = 2i/\sqrt{\pi} - 2zw(z)$.

## Voigt profile

A spectroscopic absorption line is the convolution of Doppler broadening from atomic thermal motion (a Gaussian with standard deviation $\sigma$) and broadening from spontaneous emission or collisions (a Lorentzian with half-width at half-maximum $\gamma$).
This convolution is the Voigt profile, expressible through the Faddeeva function as follows.

$$
V(x; \sigma, \gamma) = \frac{w(z)}{\sigma\sqrt{2\pi}}, \qquad z = \frac{x + i\gamma}{\sigma\sqrt{2}}.
$$

$\operatorname{Re} V$ is the Voigt profile and integrates to 1 over $x$.
$\operatorname{Im} V$ is the dispersion line shape, describing changes in refractive index.
`voigt_profile` returns only the real part, while `voigt_complex` returns the complex $V$.
At $\sigma = 0$ it becomes the Lorentzian $(\gamma + ix)/(\pi(x^2 + \gamma^2))$; at $\gamma = 0$ the real part becomes a Gaussian density.
For $\sigma < \tfrac12\sqrt{\varepsilon}\max(\lvert x \rvert, \gamma)$, the Gaussian width is below the result's resolution, so use the Lorentzian limit formula.
$\sigma < 0$, $\gamma < 0$, and $\sigma = \gamma = 0$ give `DomainError` (`OutsideDomain`).
Both use upper-half-plane Faddeeva evaluation and have scoped APIs `voigt_profile_scoped` and `voigt_complex_scoped`.
There is no uniform ULP target; the options form of `voigt_profile` estimates 64 units, while that of `voigt_complex` returns error estimates propagated to the value and derivative.

The Voigt full width at half-maximum $f_V$ has no closed form.
From Gaussian FWHM $f_G = 2\sqrt{2\ln 2}\,\sigma$ and Lorentzian FWHM $f_L = 2\gamma$, the approximation $f_V \approx 0.5346 f_L + \sqrt{0.2166 f_L^2 + f_G^2}$ of Olivero and Longbothum (1977) gives accuracy of about 0.02%.
Far from the center, Lorentzian wings dominate, with $V(x) \approx \frac{\gamma}{\pi x^2}\left(1 + \frac{3\sigma^2 - \gamma^2}{x^2}\right)$.

## Voigt profile of the sodium D2 line

The next cell computes the Doppler width $\sigma = (\nu_0/c)\sqrt{k_B T/m}$ of the sodium D2 line (vacuum wavelength 589.16 nm, atomic mass 22.990 u) from temperature $T$, combines it with Lorentzian half-width $\gamma$, and plots the Voigt profile using `voigt_profile`.
The horizontal axis is detuning $\Delta$ [GHz] from line center, and the vertical axis is the line shape $V(\Delta)$ [GHz⁻¹]; dashed curves overlay a Gaussian with the same $\sigma$ and a Lorentzian with the same $\gamma$.
The table provides six checks: FWHM from bisection versus the Olivero–Longbothum approximation; area from Simpson quadrature on $[0, 20 f_V]$ plus analytic wing integration versus 1; the wing ratio at $\Delta = 20 f_V$ versus its asymptotic form; the center value versus its $\operatorname{erfcx}$ relation; `faddeeva` on the imaginary axis versus `erfcx`; and the real part of `voigt_complex` versus `voigt_profile`.
The final three check relations among functions; the first three are independent checks.

```rust
//| id: special-voigt-sodium-line
//| ref: special-voigt-sodium-line
//| title: "Compare the sodium D2 Voigt profile with Gaussian and Lorentzian limits"
//| run: reactive
//| crates: [scioxide-core, scioxide-special]
//| inputs:
//|   temperature: {"type":"range","label":"Temperature T [K]","min":300,"max":1500,"step":100,"value":500}
//|   lorentz: {"type":"select","label":"Lorentzian half-width γ [GHz]","options":["0.005","0.05","0.5","5"],"value":"0.5"}
//| cases:
//|   - {"id":"doppler","label":"T = 300 K, γ = 0.005 GHz","description":"Doppler broadening dominates, and the center overlaps the Gaussian line shape.","inputs":{"temperature":300,"lorentz":"0.005"}}
//|   - {"id":"pressure","label":"T = 1500 K, γ = 5 GHz","description":"Lorentzian broadening dominates, and the profile approaches a Lorentzian.","inputs":{"temperature":1500,"lorentz":"5"}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"voigt","path":"/rows/0/1","approx":{"value":2.296460217975133,"rtol":1e-10}}
//|       - {"artifact":"voigt","path":"/rows/0/3","range":{"max":2e-4}}
//|       - {"artifact":"voigt","path":"/rows/1/3","range":{"max":1e-8}}
//|       - {"artifact":"voigt","path":"/rows/2/3","range":{"max":1e-5}}
//|       - {"artifact":"voigt","path":"/rows/3/3","range":{"max":1e-15}}
//|       - {"artifact":"voigt","path":"/rows/4/3","range":{"max":1e-15}}
//|       - {"artifact":"voigt","path":"/rows/5/3","range":{"max":1e-15}}
//|   - case: doppler
//|     expect:
//|       - {"artifact":"voigt","path":"/rows/0/3","range":{"max":2e-4}}
//|       - {"artifact":"voigt","path":"/rows/1/3","range":{"max":1e-8}}
//|   - case: pressure
//|     expect:
//|       - {"artifact":"voigt","path":"/rows/0/3","range":{"max":2e-4}}
//|       - {"artifact":"voigt","path":"/rows/1/3","range":{"max":1e-8}}
use scioxide_core::{Complex, RealScalar};
use scioxide_special::{erfcx, faddeeva, voigt_complex, voigt_profile};
use std::f64::consts::{LN_2, PI};

let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let digits6 = serde_json::json!({ "significantDigits": 6 });
let gamma: f64 = lorentz.parse().map_err(|_| "Cannot parse the half-width")?;
// Doppler standard deviation σ = ν₀ √(kT/m) / c [GHz] (vacuum wavelength 589.16 nm, mass 22.990 u).
let (c, kb, mass) = (299_792_458.0, 1.380_649e-23, 22.990 * 1.660_539_066_6e-27);
let nu0 = c / 589.16e-9;
let sigma = nu0 * RealScalar::sqrt(kb * temperature / mass) / c * 1e-9;
let profile = |d: f64| voigt_profile(d, sigma, gamma).map_err(|e| e.to_string());
let peak = profile(0.0)?;
// FWHM: solve V(Δ) = V(0)/2 by bisection (V decreases monotonically for Δ > 0).
let (mut lo, mut hi) = (0.0, 10.0 * (sigma + gamma));
for _ in 0..60 {
    let mid = 0.5 * (lo + hi);
    if profile(mid)? > 0.5 * peak {
        lo = mid
    } else {
        hi = mid
    }
}
let fwhm = lo + hi;
let (f_g, f_l) = (2.0 * RealScalar::sqrt(2.0 * LN_2) * sigma, 2.0 * gamma);
// Olivero and Longbothum (1977) approximation (about 0.02% error).
let olivero = 0.5346 * f_l + RealScalar::sqrt(0.2166 * f_l * f_l + f_g * f_g);
// Area: composite Simpson quadrature on [0, L] plus the Lorentzian wing beyond L, γ/(πL)(1 + (3σ² − γ²)/(3L²)).
let (length, n) = (20.0 * fwhm, 4000);
let step = length / n as f64;
let mut area = 0.0;
for i in 0..=n {
    let weight = if i == 0 || i == n {
        1.0
    } else if i % 2 == 1 {
        4.0
    } else {
        2.0
    };
    area += weight * profile(step * i as f64)?;
}
let tail = gamma / (PI * length)
    * (1.0 + (3.0 * sigma * sigma - gamma * gamma) / (3.0 * length * length));
let area = 2.0 * (area * step / 3.0 + tail);
// Wing ratio V(L) πL²/γ → 1 + (3σ² − γ²)/L².
let wing = profile(length)? * PI * length * length / gamma;
let wing_theory = 1.0 + (3.0 * sigma * sigma - gamma * gamma) / (length * length);
// Imaginary-axis relation w(iy) = erfcx(y): V(0) σ√(2π) = Re w(iγ/(σ√2)).
let y = gamma / (sigma * 2.0_f64.sqrt());
let on_axis = faddeeva(Complex::new(0.0, y))
    .map_err(|e| e.to_string())?
    .re;
let scaled_peak = peak * sigma * (2.0 * PI).sqrt();
let complex = voigt_complex(0.5 * fwhm, sigma, gamma).map_err(|e| e.to_string())?;
let rows = vec![
    (
        "FWHM f_V [GHz] and Olivero–Longbothum approximation",
        fwhm,
        olivero,
    ),
    ("Area ∫V dΔ [-] and 1", area, 1.0),
    (
        "Wing ratio V(L)πL²/γ [-] and 1 + (3σ² − γ²)/L²",
        wing,
        wing_theory,
    ),
    (
        "V(0)σ√(2π) [-] and erfcx(γ/(σ√2))",
        scaled_peak,
        erfcx(y).map_err(|e| e.to_string())?,
    ),
    (
        "Re w(iy) [-] and erfcx(y)",
        on_axis,
        erfcx(y).map_err(|e| e.to_string())?,
    ),
    (
        "Re voigt_complex(f_V/2) and voigt_profile(f_V/2)",
        complex.re,
        0.5 * peak,
    ),
];
let rows: Vec<_> = rows
    .into_iter()
    .map(|(name, value, check)| (name, value, check, (value / check - 1.0).abs()))
    .collect();
let mut voigt = Vec::new();
let mut gauss = Vec::new();
let mut lorentzian = Vec::new();
for i in 0..=400 {
    let d = -8.0 + 0.04 * i as f64;
    voigt.push([d, profile(d)?]);
    gauss.push([
        d,
        (-0.5 * d * d / (sigma * sigma)).exp() / (sigma * (2.0 * PI).sqrt()),
    ]);
    lorentzian.push([d, gamma / (PI * (d * d + gamma * gamma))]);
}
emit_line_chart!(
    &vec![
        serde_json::json!({ "name": "Voigt", "points": voigt }),
        serde_json::json!({ "name": "Gaussian (same σ)", "points": gauss, "dashed": true }),
        serde_json::json!({ "name": "Lorentzian (same γ)", "points": lorentzian, "dashed": true })
    ],
    options = &serde_json::json!({
        "xLabel": "Detuning Δ [GHz]",
        "yLabel": "Line shape V(Δ) [GHz⁻¹]",
        "yType": "log",
        "yMin": 1e-4
    })
);
let columns = serde_json::json!([
    { "key": "0", "label": "Check" },
    { "key": "1", "label": "SciOxide value", "type": "number", "format": digits6 },
    { "key": "2", "label": "Comparison value", "type": "number", "format": digits6 },
    { "key": "3", "label": "Relative difference [-]", "type": "number", "format": sci3 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "voigt" })
);
```

For the default $T = 500$ K, $\sigma = 0.722$ GHz (Gaussian FWHM 1.700 GHz) and Lorentzian FWHM 1.0 GHz give a Voigt FWHM of 2.2965 GHz, agreeing with the Olivero–Longbothum approximation 2.2968 GHz within relative $1.5 \times 10^{-4}$.
The area differs from 1 by $8.8 \times 10^{-10}$, and the wing ratio from its asymptotic form by $6.4 \times 10^{-7}$; the latter is the size of the omitted $\Delta^{-4}$ term.
On the logarithmic chart, the center resembles a Gaussian; beyond $\lvert\Delta\rvert$ of 3 GHz, the Gaussian drops rapidly while the Voigt profile overlaps the Lorentzian wings.
The final three rows show rounding-level agreement of relations such as the center value $V(0)\sigma\sqrt{2\pi} = \operatorname{erfcx}(\gamma/(\sigma\sqrt{2})) = 0.62094$.
For $T = 300$ K and $\gamma = 0.005$ GHz, the profile is nearly Gaussian; its FWHM 1.32187 GHz agrees with the approximation within $1.5 \times 10^{-5}$.
For $T = 1500$ K and $\gamma = 5$ GHz, the Lorentzian component dominates; the FWHM 10.855 GHz differs from the approximation by $2.0 \times 10^{-4}$, at the approximation's 0.02% accuracy level.

## API

The functions in this family are listed below.
`faddeeva` accepts and returns `Complex<S>`; `voigt_profile` returns a real number, and `voigt_complex` returns `Complex<S>`.
All options use `ProbabilityOptions`, containing only a work budget (`Budget`, default 65536) and no accuracy request.
Options forms return `SpecialFunctionResult`, containing an estimated error, termination status, work counts, and algorithm identifier.

| Standard form | Computes | Options form | Scoped API | Options-form estimated error |
|---|---|---|---|---|
| `faddeeva` | $w(z)$ | `faddeeva_with_options` | `faddeeva_scoped` | 64 units for value, 128 for derivative |
| `voigt_profile` | $\operatorname{Re} V(x; \sigma, \gamma)$ | `voigt_profile_with_options` | `voigt_profile_scoped` | 64 units |
| `voigt_complex` | $V(x; \sigma, \gamma)$ | `voigt_complex_with_options` | `voigt_complex_scoped` | Propagated to value and derivative |

None has a uniform ULP target.
Estimated errors are estimates returned by options forms, not intervals with guaranteed containment.
Iterations reaching the budget give `ConvergenceFailure` (`IterationLimit`) in standard forms; options forms and scoped APIs return results with termination status `IterationLimit` if an estimate is available.

## Summary

The Faddeeva function uses real $\operatorname{erfcx}$ and Dawson kernels on the axes, Laplace continued fractions for large $\lvert z \rvert$, and Algorithm 916 series elsewhere.
The lower half-plane uses the reflection $w(z) = 2e^{-z^2} - w(-z)$; where $\lvert \operatorname{Im} z \rvert > \lvert \operatorname{Re} z \rvert$ makes the value exceed the type's range, inspect the options-form logarithmic representation.
Voigt profiles are evaluated with `voigt_profile`, switching to the Lorentzian limit when the Gaussian width is below the resolution.
With no uniform ULP target, assess accuracy using options-form error estimates and independent checks such as area and asymptotic wings.
