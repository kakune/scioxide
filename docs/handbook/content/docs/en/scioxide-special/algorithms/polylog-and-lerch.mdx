The polylogarithm $\operatorname{Li}_s(z)$ appears in integrals of Bose–Einstein and Fermi–Dirac distributions.
The number density of an ideal Bose gas is proportional to $\operatorname{Li}_{3/2}(z)$ as a function of fugacity $z$, and the complete Fermi–Dirac integral is $F_j(\eta) = -\operatorname{Li}_{j+1}(-e^{\eta})$.
The Lerch transcendent $\Phi(z, s, a)$ unifies the polylogarithm and Hurwitz zeta function in one series.

This page explains polylogarithms and the Lerch transcendent for general order $s$: definitions and cuts, evaluation methods selected by scioxide-special according to order and argument, work and scoped APIs, accuracy guarantees, and API selection.
The order-2 dilogarithm uses a separate fixed-term kernel and is covered in [Dilogarithm, Spence function, and Clausen function](../polylog-lerch-and-clausen/).
[Riemann and Hurwitz zeta functions and the Dirichlet eta function](../zeta-functions/) covers zeta evaluation; its kernel computes the value at $z = 1$.
The final cell numerically checks the polylogarithm multiplication formula, the Lerch $a$-shift identity, and $\operatorname{Li}_s(1) = \zeta(s)$, displaying the method selected for each argument.

## Definitions and cuts

### Polylogarithm

For order $s$ and $z$ with $|z| < 1$, the polylogarithm is defined by the following power series (DLMF 25.12.10).

$$
\operatorname{Li}_s(z) = \sum_{k=1}^{\infty} \frac{z^k}{k^s}
$$

Analytic continuation in $z$ makes $\operatorname{Li}_s$ single-valued on the plane cut along $[1, \infty)$.
Powers use the principal value $k^{-s} = e^{-s \ln k}$; on the cut, the signed zero of the imaginary part ($+0$ or $-0$) selects the upper or lower bank.

Differentiation lowers the order by one: $z \, \frac{d}{dz}\operatorname{Li}_s(z) = \operatorname{Li}_{s-1}(z)$.
Integer orders reduce to elementary functions: $\operatorname{Li}_1(z) = -\ln(1 - z)$ and $\operatorname{Li}_0(z) = z/(1 - z)$.
For $s = -n$ ($n = 1, 2, \dots$), repeated application of $z \, d/dz$ gives the rational function below.

$$
\operatorname{Li}_{-n}(z) = \frac{z\,A_n(z)}{(1 - z)^{n+1}}, \qquad A_n(z) = \sum_{k=0}^{n-1} A(n, k)\, z^k
$$

$A(n, k)$ are Eulerian numbers, computed by the recurrence $A(n, k) = (k + 1)A(n - 1, k) + (n - k)A(n - 1, k - 1)$.
At $z = 1$, $\operatorname{Li}_s(1) = \zeta(s)$ for $s \ne 1$; when $\operatorname{Re} s \le 1$, the value is the analytic continuation of $\zeta$, rather than a limit of the divergent series.
$s = 1$, $z = 1$ is a pole.

Summing rotations of $z$ by the $m$ $m$th roots of unity gives the multiplication formula $\sum_{j=0}^{m-1} \operatorname{Li}_s(z\,e^{2\pi i j/m}) = m^{1-s}\operatorname{Li}_s(z^m)$.
For $m = 2$, this is the following identity, obtained by extracting even-indexed terms from the defining series.

$$
\operatorname{Li}_s(z) + \operatorname{Li}_s(-z) = 2^{1-s} \operatorname{Li}_s(z^2)
$$

### Lerch transcendent

The Lerch transcendent is defined by the following series (DLMF 25.14.1).

$$
\Phi(z, s, a) = \sum_{n=0}^{\infty} \frac{z^n}{(a + n)^s}, \qquad |z| < 1
$$

Continue in $z$ to the plane cut along $[1, \infty)$, taking powers with the principal value $(a + n)^{-s} = e^{-s \ln(a + n)}$.
Special cases include $\Phi(1, s, a) = \zeta(s, a)$ (the Hurwitz zeta function), $z\,\Phi(z, s, 1) = \operatorname{Li}_s(z)$, and $\Phi(z, 0, a) = 1/(1 - z)$.
The following $a$-shift identity follows by extracting the first term of the defining series.

$$
\Phi(z, s, a) = z\,\Phi(z, s, a + 1) + a^{-s}
$$

$a = 0, -1, -2, \dots$ are poles.
However, if $s$ is a nonpositive integer, the term is a polynomial in $a + n$ and no pole occurs.
At $a = 1/2$ and $z = -1$, it gives the Dirichlet beta function $\beta(s) = 2^{-s}\Phi(-1, s, 1/2)$, and $\beta(2)$ is Catalan's constant $G = 0.9159655941\ldots$.

## Evaluation methods

### Dispatch by order and argument

`polylog(s, z)` selects the following kernels according to order and argument.

1. $s = 2$ uses the dilogarithm kernel.
2. $z = 0$ returns zero; $z = 1$ returns $\zeta(s)$ using the Riemann zeta kernel.
3. $s = 1$ computes $-\ln(1 - z)$, using the form $\ln(1 + \cdot)$ to avoid cancellation for small $z$.
4. $s = 0$ is $z/(1 - z)$, rewritten using $1/z$ for $|z| > 2$.
5. $s = -n$ ($n \ge 1$) uses the Eulerian-number rational function after mapping toward the unit circle through $\operatorname{Li}_{-n}(1/z) = (-1)^{n+1}\operatorname{Li}_{-n}(z)$ when $|z| > 2$.
   When $n \ge 10$ and $|\ln z| \le n$, avoid cancellation in high-degree polynomials by expanding $\operatorname{Li}_0$ into partial fractions as a function of $\mu = \ln z$ and differentiating $n$ times to obtain the pole sum $\operatorname{Li}_{-n}(z) = n!\sum_{k \in \mathbb{Z}} (2\pi i k - \ln z)^{-n-1}$.
   For $n > 100$ when this condition fails, use the defining series.
6. For negative noninteger $s$ and $|z| \ge 0.95$, use the $\ln z$ series below if $|\ln z| \le 3.5$; otherwise apply Jonquière's inversion formula (DLMF 25.12.12–25.12.13) to reduce to $\operatorname{Li}_s(1/z)$ and the Hurwitz zeta function.
7. Otherwise evaluate $\operatorname{Li}_s(z) = z\,\Phi(z, s, 1)$ with the Lerch transcendent kernel.

### Lerch transcendent kernel

The `lerch_phi(z, s, a)` kernel first rejects nonpositive integer $a$ when $s$ is not a nonpositive integer, as a pole.
$z = 0$ returns $a^{-s}$; $z = 1$ returns the Hurwitz zeta function (Riemann zeta for $a = 1$); $s = 0$ returns $1/(1 - z)$.
For $a = 1$ with orders covered by 5 or 6 above, it uses the same polylogarithm path.

For the remaining cases, sum terms with $\operatorname{Re}(a + n) < 1$ directly, then use the shift identity above at $a' = a + n$ ($\operatorname{Re} a' \ge 1$) to reduce to $\Phi(z, s, a')$.
Evaluation of $\Phi(z, s, a')$ has three paths according to $z$.

1. For $|z| < 0.95$, sum the defining series with compensated summation (Kahan summation, retaining rounding error in a separate variable and restoring it at the next term).
   Form each term as $\exp(-s\ln(a' + n) + n\ln z)$, extracting a common scale before summation when the exponent risks exceeding double precision.
   Estimate the remaining tail by a geometric series using an upper bound on all subsequent term ratios, and truncate once the tail is below $2 \times 10^{-15}$ times the sum.
2. For $|\ln z| < 1$, $\operatorname{Re} s < 1/2$, noninteger $s$, and $\lvert a' - 1\rvert < 0.75$, use a power series in $\ln z$ (Erdélyi et al. 1953, §1.11).

   $$
   \Phi(z, s, a) = z^{-a}\left[\Gamma(1 - s)\,(-\ln z)^{s-1} + \sum_{n=0}^{\infty} \zeta(s - n, a)\,\frac{(\ln z)^n}{n!}\right], \qquad \lvert\ln z\rvert < 2\pi
   $$

   As $z \to 1$, the defining series decays slowly, but terms in this series decrease roughly as $(\lvert\ln z\rvert/2\pi)^n$.
   Each term evaluates the Hurwitz zeta function $\zeta(s - n, a)$, and that work also contributes to the number of work units.
   The condition $\lvert a' - 1\rvert < 0.75$ restricts evaluation to where Hurwitz zeta avoids loss of digits as the order $s - n$ becomes large and negative.
3. Otherwise (points with $|z| \ge 0.95$ away from 1, orders with $\operatorname{Re} s \ge 1/2$, or $a'$ away from 1), use the integral representation (DLMF 25.14.5).

   $$
   \Phi(z, s, a) = \frac{1}{\Gamma(s)} \int_0^{\infty} \frac{t^{s-1} e^{-at}}{1 - z e^{-t}}\, dt, \qquad \operatorname{Re} s > 0,\ \operatorname{Re} a > 0
   $$

   Rotate the integration path by up to 0.35 radians to avoid integrand poles $t = \ln z + 2\pi i k$, apply a 32-point Gauss–Legendre rule adaptively by interval bisection, and sum over intervals of successively doubled length.
   Integrate near the origin using a Taylor expansion, multiplying separately by $1/\Gamma(s)$ to continue analytically to orders $\operatorname{Re} s \le 0$ and remove apparent poles at $s = 0, -1, -2, \dots$.
   The estimated error sums the differences between coarse and fine rules on each interval and the estimated summation rounding.

### Work and scoped APIs

Every path consumes one work unit per series term, quadrature node, or recurrence step; nested zeta and Gamma evaluations consume the same limit.
Work varies from zero units (the logarithm at $s = 1$) to thousands (integral representation), so `polylog` and `lerch_phi` have scoped APIs `polylog_scoped` and `lerch_phi_scoped`.
Scoped APIs apply the parent solve's work limit and cancellation to this evaluation as well.
At the limit, both standard and options forms return `ConvergenceFailure` without an intermediate value.

## Errors and accuracy guarantees

| Function | Real arguments | Complex arguments |
|---|---|---|
| `polylog` | $s = 2$ is identical to `dilog`, targeting 64 ULP for both `f32` and `f64`. Other orders have no uniform ULP bound | No uniform bound |
| `lerch_phi` | No uniform bound | No uniform bound |

Where no uniform bound applies, inspect the estimated error in the form with options.
Estimated errors are derived from truncation and rounding, not enclosing intervals (intervals guaranteed to contain the true value).
Reference tests compare values and derivatives with independent references, checking complex arguments within the larger of relative $5 \times 10^{-9}$ and absolute $5 \times 10^{-12}$ (`f64`).

In the cell below, estimated errors for integral-representation paths are roughly $5 \times 10^{-15}$ times the value.
On the $\ln z$-series path, Hurwitz zeta errors accumulate; at $s = 0.3$ and $z = 0.98$ below, the estimated error is $1.7 \times 10^{-14}$ times the value.

## API

| Function | Scalar | Form with options | Scoped API | Options |
|---|---|---|---|---|
| `polylog(s, z)` | `NumericScalar`. `z` can be complex while `s` remains real; `s` can also be complex | `polylog_with_options` | `polylog_scoped` | `PolylogOptions` |
| `lerch_phi(z, s, a)` | `NumericScalar`. `z` can be complex while `s` and `a` remain real; both can also be complex | `lerch_phi_with_options` | `lerch_phi_scoped` | `LerchOptions` |

Argument order differs between the functions.
`polylog` puts the order first, `polylog(s, z)`; `lerch_phi` puts the argument first, `lerch_phi(z, s, a)`.

Errors are classified as follows.

- `polylog` gives `DomainError` (`Pole`) at $s = 1$, $z = 1$.
  For real types, $z > 1$ gives `DomainError` (`OutsideDomain`), except at $s = 2$ (returning the real part) and nonpositive integer $s$.
- `lerch_phi` gives `DomainError` (`Pole`) on `a` when $a$ is a nonpositive integer and $s$ is not a nonpositive integer.
  However, real types first reject $a \le 0$ with noninteger $s$ as `DomainError` (`OutsideDomain`) on `a`, so `Pole` occurs when $s$ is a positive integer.
  Complex types evaluate negative noninteger $a$ using principal powers.
  $z = 1$, $s = 1$ gives `Pole` on `s`; for real types, $z > 1$ gives `OutsideDomain` on `z` unless $s$ is a nonpositive integer.
- Both give `NonFinite` for non-finite inputs and `NumericalInstability` when analytic continuation cannot produce a finite estimate.

The default work limits in `PolylogOptions` and `LerchOptions` are 65536 units; these are not accuracy requests, but limits allowing slowly converging cases to finish.
For $z > 1$, real polylogarithm values are available only at $s = 2$ (the real part) and nonpositive integer orders; for other orders on the cut, use a complex type and select the bank.
Large negative orders can produce values beyond the type's range.
In that case, the complex form with options returns a logarithmic form with ordinary-value projection status `Overflow`.
The real `polylog` returns a scalar-conversion error (`kind()` is `ScalarConversion`) in the same cases (such as $s = -200$, $z = 0.5$).
Use the complex form with options when values beyond the range are needed.

## Multiplication formula and Lerch kernel paths

The next cell takes order $s$ and argument $z$ as inputs and checks three general-order relations.
The first is the multiplication formula $\operatorname{Li}_s(z) + \operatorname{Li}_s(-z) = 2^{1-s}\operatorname{Li}_s(z^2)$; $z$, $-z$, and $z^2$ may follow different Lerch kernel paths.
The second is the $a$-shift identity $\Phi(z, s, 3/2) = z\,\Phi(z, s, 5/2) + (3/2)^{-s}$, and the third compares $\operatorname{Li}_s(1)$ with real `riemann_zeta`.
Since the two sides use different arguments and paths, their agreement independently checks each path's implementation.
The second table shows the method (algorithm identifier) selected by the form with options `polylog_with_options` at $z$ and $\pm 0.97$, its estimated error, and work units.

```rust
//| id: special-polylog-lerch-paths
//| ref: special-polylog-lerch-paths
//| title: "Polylogarithm duplication formula and Lerch kernel paths"
//| run: reactive
//| crates: [scioxide-special, scioxide-core]
//| inputs:
//|   s: {"type":"range","label":"Order s [-]","description":"s = 1 is a pole at z = 1, so the third comparison row is blank.","min":-2.5,"max":4,"step":0.1,"value":2.5}
//|   z: {"type":"range","label":"Argument z [-]","description":"Use the defining series for |z| < 0.95 and other methods outside that range.","min":-0.99,"max":0.99,"step":0.01,"value":0.5}
//| cases:
//|   - {"id":"near-one","label":"s = 0.3, z = 0.98","description":"Uses the ln z series path.","inputs":{"s":0.3,"z":0.98}}
//|   - {"id":"negative-order","label":"s = −1.5, z = −0.97","description":"Negative noninteger order with |z| ≥ 0.95.","inputs":{"s":-1.5,"z":-0.97}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"relations","path":"/rows/0/3","range":{"max":1e-14}}
//|       - {"artifact":"relations","path":"/rows/1/3","range":{"max":1e-14}}
//|       - {"artifact":"relations","path":"/rows/2/3","range":{"max":1e-14}}
//|       - {"artifact":"paths","path":"/rows/0/3","equals":"lerch_compensated_series"}
//|       - {"artifact":"paths","path":"/rows/1/3","equals":"lerch_regularized_mellin"}
//|   - case: near-one

//|       - {"artifact":"relations","path":"/rows/2/3","range":{"max":1e-14}}
//|       - {"artifact":"paths","path":"/rows/0/3","equals":"lerch_logarithmic_series"}
//|   - case: negative-order
//|     expect:
//|       - {"artifact":"relations","path":"/rows/0/3","range":{"max":1e-14}}
//|       - {"artifact":"relations","path":"/rows/1/3","range":{"max":1e-14}}
//|       - {"artifact":"relations","path":"/rows/2/3","range":{"max":1e-14}}
use scioxide_core::RealScalar;
use scioxide_special::{PolylogOptions, lerch_phi, polylog, polylog_with_options, riemann_zeta};

let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let fixed12 = serde_json::json!({ "fractionDigits": 12 });
let li = |t: f64| polylog(s, t).map_err(|e| e.to_string());

// Duplication formula and a-shift. Compute powers on the right with elementary functions.
// Normalize differences by value magnitudes to obtain relative differences (negative orders give values near 10⁴).
// When both sides are zero (such as ζ(−2) = 0), show the difference itself.
let relative = |a: f64, b: f64| {
    let scale = a.abs().max(b.abs());
    if scale > 0.0 {
        (a - b).abs() / scale
    } else {
        (a - b).abs()
    }
};
let mut rows: Vec<(&str, Option<f64>, Option<f64>, Option<f64>)> = Vec::new();
let lhs = li(z)? + li(-z)?;

rows.push((
    "Li_s(z) + Li_s(−z) versus 2^{1−s} Li_s(z²)",
    Some(lhs),
    Some(rhs),
    Some(relative(lhs, rhs)),
));
let lhs = phi(1.5)?;
let rhs = z * phi(2.5)? + RealScalar::powf(1.5, -s);
rows.push((
    "Φ(z, s, 3/2) versus zΦ(z, s, 5/2) + (3/2)^{−s}",
    Some(lhs),
    Some(rhs),
    Some(relative(lhs, rhs)),
));

    metadata = serde_json::json!({ "id": "relations" })

        polylog_with_options(s, point, PolylogOptions::default()).map_err(|e| e.to_string())?;
    let value = result.value().ok_or("Missing value")?;

        point,
```

For the defaults $s = 2.5$ and $z = 0.5$, the shift-identity relative difference is $7.8 \times 10^{-16}$, and the relative difference from $\zeta(s)$ is $1.7 \times 10^{-16}$.
The multiplication-formula relative difference is somewhat larger, $5.4 \times 10^{-15}$, due to cancellation between $\operatorname{Li}_s(0.5) = 0.555$ and $\operatorname{Li}_s(-0.5) = -0.462$ on the left, giving $0.093$.
In the path table, $z = 0.5$ uses the defining series (`lerch_compensated_series`, 37 units), while $z = \pm 0.97$ uses the integral representation (`lerch_regularized_mellin`, 1596–2172 units), greatly increasing work from series terms to quadrature nodes.
In the near-one case ($s = 0.3$, $z = 0.98$), $z = 0.98$ and $0.97$ switch to the $\ln z$ series (`lerch_logarithmic_series`), with estimated error $3 \times 10^{-13}$, a relative error of $1.7 \times 10^{-14}$ for a value of 19.
The negative-order case ($s = -1.5$, $z = -0.97$) follows the negative-noninteger-order path; both $z = \pm 0.97$ use the $\ln z$ series, keeping the multiplication-formula relative difference to $1.3 \times 10^{-15}$ even for large values such as $\operatorname{Li}_{-1.5}(0.97) \approx 8210$.
For integer orders, the table shows the logarithm path for $s = 1$ (`polylog_logarithm`, zero units), `polylog_geometric` for $s = 0$ (one unit), and the Eulerian-number rational function for negative integers (`polylog_eulerian_rational`, four units at $s = -2$).
At $s = 1$, $z = 1$ is a pole, so the third comparison row displays “Pole.”
Estimated errors are not enclosing intervals, but when large relative to the value, they indicate accumulated rounding or truncation dominating that path.

## Summary

`polylog` and `lerch_phi` switch among the defining series, $\ln z$ series, and integral representation according to $z$; integer and negative orders use rational functions, pole sums, and Jonquière's inversion formula.
Work varies from zero to thousands of units, so when calling within an iteration, include it in the parent work through scoped APIs and inspect algorithm identifiers and work units in the form with options.
Orders other than $s = 2$ have no uniform ULP bound, so compare the estimated error in the form with options with the value and check independent relations such as multiplication and shift identities.
Real types accept $z > 1$ only at $s = 2$ and nonpositive integer orders; for other orders on the cut, select the bank with a complex type.

See [Dilogarithm, Spence function, and Clausen function](../polylog-lerch-and-clausen/) for evaluation of the order-2 dilogarithm and the Clausen function, its imaginary part on the unit circle.
See [Fermi–Dirac integrals](../fermi-dirac-integrals/) for evaluation and asymptotic forms of Fermi–Dirac integrals expressed with polylogarithms.
