This page lists Airy functions, cylindrical Bessel functions $J_\nu, Y_\nu, I_\nu, K_\nu$, Hankel functions, their argument derivatives and exponential scalings, logarithmic $K_\nu$, Jahnke–Emden Lambda functions, and weighted Bessel integrals.
Airy, Bessel, and Hankel operations accept real (`f32`, `f64`) and complex (`Complex<f32>`, `Complex<f64>`) inputs under one function name through `NumericScalar`.
Pass Bessel and Hankel order $\nu$ in the same type as argument $z$, or as a real value when $z$ is complex ([`Parameter`](oxref:special-api-argument-types)).
Each row lists the standard form returning only a value, the form with options `*_with_options` returning `SpecialFunctionResult`, and the scoped API `*_scoped(.., options, scope)` accepting a solve scope ([Three calling forms](oxref:special-api-call-forms)).
Work varies with argument and order, so every function on this page has a scoped API.
Work limits are set by `AiryOptions`, `BesselOptions`, and `BesselIntegralOptions` (all defaulting to 65536 units); see [Result types and options](../results-and-options/) for these types.
No order-sequence functions return multiple orders together; call separately for each order.

## Airy functions

Airy functions solve $y''(z) - z\,y(z) = 0$; they are entire, have no poles, and accept all finite arguments.
Non-finite inputs give `NonFinite`, unrepresentable results give `NumericalInstability` (`Overflow`), and evaluation unfinished at the work limit gives `ConvergenceFailure`.
For real $\lvert x\rvert \le 16$, use degree-35 Taylor polynomials about the nearest integer (derived from the differential equation, evaluated with compensated summation where cancellation occurs); outside this range, use DLMF §9.7 asymptotic expansions.
Phase is reduced accurately on the negative axis.
Real Ai, Bi, and their scaled forms target 64 ULP in both precisions on reference data, using condition-number-based absolute errors near zeros.
Complex arguments have no uniform ULP specification.
When representable, the forms with options also return derivatives $\operatorname{Ai}'(z)$ and $\operatorname{Bi}'(z)$ (multiplied by the same factor for scaled forms).

## Cylindrical Bessel functions J and Y

The conventions here apply to cylindrical Bessel and Hankel functions from this section through “Derivatives”; all use `BesselOptions`.
Complex orders and arguments use principal powers with a cut on the negative real axis.
The imaginary signed zero (`+0i` or `-0i`) selects the upper or lower bank; at the complex origin, singular values are rejected according to order-dependent limits.
Errors are classified as `NonFinite` for non-finite inputs, `DomainError` for domain violations and poles, `NumericalInstability` for unrepresentable results and breakdowns, and `ConvergenceFailure` for work unfinished at the limit.
For real orders and arguments, J, Y, I, K (including scaled forms), and Hankel functions target 64 ULP in both precisions on reference data, using condition-number-based absolute errors near zeros.
J and Y data includes orders below 1000 with $x \le 10^8$ and orders near $\sqrt{x}$.
Complex orders and arguments have no uniform ULP specification; forms with options return estimated errors.
For complex orders and arguments, J uses power and Temme series near the origin, Miller backward recurrence normalized by a Wronskian at moderate $\lvert z\rvert$, Hankel asymptotic expansions at large $\lvert z\rvert$, and Debye expansions for $\lvert\nu\rvert \ge 64$.
Y uses Temme series near the origin and scaled recurrences and connection formulas at larger $\lvert z\rvert$.

## Derivatives

Derivatives have order $k$ (argument `degree: u32`) with respect to argument $z$, holding function order $\nu$ fixed; argument order is `(order, z, degree)`.
Derivative order zero returns the function value.
The $k$th derivative is a binomial sum of neighboring orders ($2^{-k}\sum_m (-1)^m \binom{k}{m} J_{\nu-k+2m}$ for $J$), so work is proportional to $k$.
Y, K, and Hankel derivatives (including scaled forms) treat the origin as `DomainError` (`Pole`) even for derivative order zero.
Thus `bessel_k_derivative(ν, 0.0, 0)` is an error, unlike the `Ok(+∞)` returned by `bessel_k`.
J and I derivatives give `Pole` at the origin when real noninteger orders satisfy $\nu < k$, or complex orders satisfy $\operatorname{Re}\nu \le k$, because the derivative is unbounded.
If $k$ exceeds the remaining limit, evaluation gives `ConvergenceFailure` (`IterationLimit`); if a derivative exceeds the scalar range, it gives `NumericalInstability` (`Overflow`).
Derivatives have no uniform ULP specification; forms with options return estimated errors including rounding of the binomial sum.

## Exponential scaling for complex arguments

Scaled J, Y, and Hankel forms also accept `NumericScalar`, with the same order-type rules as the original functions.
J and Y return the input scalar type; Hankel returns `Complex<T::Real>`.
For real J and Y, the scaling factor is 1, and domains follow the original real functions.
Options are `BesselOptions`.
Order, domain, normalization, and the bank of the negative-real-axis cut follow the original functions.
Derivatives in the forms with options multiply the original derivative by the same factor without differentiating the factor itself.
Scaled real J and Y have the same accuracy as the original functions.
Scaled complex J and Y and scaled Hankel functions, including real inputs, have no uniform ULP specification.
