These tables cover Coulomb wave functions and hydrogenic radial functions, as well as combinatorial functions such as factorials, binomial coefficients, and Stirling numbers.
Coulomb wave functions, `hydrogenic_radial`, and combinatorial functions that accept real and complex arguments (`generalized_binomial`, `pochhammer`, `pochhammer_relative`) each accept `NumericScalar` (`f32`, `f64`, `Complex<f32>`, `Complex<f64>`) through a single function.
`coulomb_normalization` and its sequences, and combinatorial functions that accept only integer indices, return `RealScalar` (`f32`, `f64`) values.
Each row lists the standard form that returns only the value, the form with options `*_with_options` that returns `SpecialFunctionResult`, and the scoped API `*_scoped(.., options, scope)` that evaluates within a solve scope ([three calling forms](oxref:special-api-call-forms)).
There is no scoped API for `coulomb_normalization`, factorials and binomial coefficients and their logarithms, Pochhammer symbols, Bernoulli numbers, or Euler numbers, whose computational work is bounded independently of the arguments.
The option types are `CoulombOptions` and `CombinatorialOptions`; both contain only a work limit (65536 by default) and are listed in [Result types and options](../results-and-options/).

## Coulomb wave functions

Coulomb wave functions solve the radial Coulomb equation $w'' + [1 - 2\eta/z - \ell(\ell+1)/z^2]\,w = 0$ (DLMF 33.2.1).
$\ell$ is the order, $\eta$ the charge (Sommerfeld) parameter, and $z$ the radius.
The regular solution behaves as $F_\ell \sim C_\ell(\eta)z^{\ell+1}$ at $z \to 0$, and $C_\ell(\eta)$ is the normalization constant returned by `coulomb_normalization`.
For large real $z$, $F_\ell \sim \sin\theta$ and $G_\ell \sim \cos\theta$ ($\theta = z - \eta\ln(2z) - \ell\pi/2 + \sigma_\ell(\eta)$, $\sigma_\ell(\eta) = \arg\Gamma(\ell+1+\mathrm{i}\eta)$), and the Wronskian is $F'G - FG' = 1$.

The arguments are $\ell$, $\eta$, and $z$, in that order.
The order $\ell > -1/2$ and $\eta$ are real and are passed as the real type `T::Real` even when the radius is complex.
The radius is a nonnegative real number or a complex number; complex radii have a cut along the negative real axis, with the signed zero of the imaginary part selecting the side.
$\ell \le -1/2$ and negative real radii produce `DomainError` (`OutsideDomain`).
For positive real radii, an outward asymptotic expansion (DLMF 33.11.1) is used when $(\ell^2 + \eta^2)/z$ is less than approximately 59, with work of a few hundred units.
Otherwise, Steed's method evaluates the continued fractions in DLMF 33.8, with work of approximately $z - \eta$ units.
The default limit of 65536 handles $\ell, \lvert\eta\rvert \le 1300$ at all radii of $2\times 10^4$ or greater; for larger orders or charges, the limit must be increased when the radius lies between approximately $6\times 10^4$ and $(\ell^2 + \eta^2)/59$.
For complex radii, the method combines a series at the origin, continuation by Taylor series of the equation, and asymptotic expansions and continued fractions for $H^\pm = G \pm \mathrm{i}F$.

For all rows, non-finite input produces `NonFinite`, a value outside the scalar type's range produces `NumericalInstability` (`Overflow`), and reaching the work limit produces `ConvergenceFailure` (`IterationLimit`).
For real arguments, the target is 64 ULP in both precisions over the checked range; comparisons near zeros of the waves use absolute error.
There is no uniform ULP specification for complex radii; tests cover orders up to 50, $\lvert\eta\rvert \le 100$, and $10^{-3} \le \lvert z\rvert \le 10^4$.

## Sequences of Coulomb functions

A sequence of orders $\ell, \ell+1, \dots$ is committed to the output only when the recurrence between adjacent orders (DLMF 33.4) is reused.
The recurrence proceeds downward from the highest order for $F$, $F'$, and $F/z$, and upward from order $\ell$ for $G$ and $G'$; both directions are numerically stable.
The computational cost is one scalar evaluation and $O(\mathrm{count})$ recurrence steps.

The APIs returning owned values, `coulomb_sequence`, `coulomb_wave_sequence`, and `coulomb_normalization_sequence`, accept a count `count` and return values for orders $\ell, \dots, \ell+\mathrm{count}-1$ in a `Vec`.
All elements share the default `CoulombOptions` (65536 units), and two vectors of `count` elements are allocated (allocation failure produces `AllocationFailure`).
The `*_into` forms accept options, output `output`, temporary storage `staging`, and a scope, in that order, write as many detailed results as the length of `output`, and return `Result<(), SciOxideError>` without allocating.
Each element is first written to `staging` and copied to `output` only after all elements succeed, so a failure leaves `output` unchanged.
If `staging` is shorter than `output`, the result is `DimensionMismatch`.
The caller provides `output` and `staging`, initialized with `SpecialFunctionResult::zero()` or `CoulombWaveResult::zero()`.
In the `*_into` forms, all elements share the limit in `options`, each element carries the counts for the entire sequence, and reaching the limit produces `ConvergenceFailure` with the attempted counts.
If order $\ell + k$ is non-finite or rounds to the preceding order, the result is `DomainError` (`OutsideDomain`) for argument `count` in the APIs returning owned values and argument `output` in the `*_into` forms.
Parameters are checked even when the count is 0 or the output is empty.

## Factorials and multifactorials

Functions with integer indices return `RealScalar` values; the indices are `usize`, so their type cannot represent negative values.
If a value exceeds the scalar type's range, the standard form returns `NumericalInstability` (`Overflow`), while the form with options retains scaled and logarithmic forms.
For `factorial`, `ln_factorial`, and `binomial`, the targets over the checked range are 4 ULP for binary64 and 1 ULP for binary32.
The other functions in this section and the next three sections have no uniform ULP specification; estimated errors from the forms with options are tested against independent reference values and exact identities.
