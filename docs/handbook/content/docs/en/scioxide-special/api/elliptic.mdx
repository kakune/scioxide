These tables cover public items for Legendre elliptic integrals, Carlson symmetric integrals, and Jacobi elliptic functions.
All functions accept `NumericScalar` (`f32`, `f64`, `Complex<f32>`, `Complex<f64>`), using the same names for real and complex arguments.
Each row lists the standard form that returns only the value, the form with options `*_with_options` that accepts `EllipticOptions` and returns `SpecialFunctionResult`, and the scoped API `*_scoped(.., options, scope)` that evaluates within a solve scope ([three calling forms](oxref:special-api-call-forms)).
`EllipticOptions` holds only a work limit (default 65536) and appears in [Result types and options](../results-and-options/).

The parameter is $m = k^2$ (the square of the modulus $k$); the same functions that DLMF writes with modulus $k$, such as $K(k)$, are expressed here using $m$.
The amplitude $\phi$ is in radians.
For the incomplete elliptic integrals `elliptic_f` and `elliptic_e_inc` and the Jacobi functions, the parameter may also be passed as a real number when the amplitude or $u$ is complex (`Parameter`).
For all rows, non-finite input produces `NonFinite`, unrepresentable results or computational breakdown produce `NumericalInstability`, and reaching the work limit produces `ConvergenceFailure` (`IterationLimit`) in both standard and options forms, without returning an intermediate value.
For complex arguments, each factor in the integrand uses the principal square root; arguments on a cut select the side through the signed zero of the imaginary part (`+0i` for the upper side, `-0i` for the lower side).
The cuts are at parameter $[1, \infty)$ for complete elliptic integrals and along the negative real axis of each coordinate for Carlson integrals.
There is no uniform ULP specification for complex evaluations.

## Incomplete elliptic integrals

Incomplete integrals accept the amplitude $\phi$ and parameter $m$, in that order.
A real amplitude is reduced to $[0, \pi/2]$ using the integrand's period $\pi$, adding twice the complete integral for each period removed.
An incomplete integral of the third kind is not provided.
If needed, set $s = \sin\phi$, $c = \cos\phi$, and $\Delta^2 = 1 - ms^2$, and construct $\Pi(n; \phi \mid m) = s\,R_F(c^2, \Delta^2, 1) + \tfrac{n}{3}s^3 R_J(c^2, \Delta^2, 1, 1 - ns^2)$ (DLMF §19.25) with `carlson_rf` and `carlson_rj`.

## Carlson symmetric forms

Carlson symmetric integrals are standard forms symmetric under interchange of their arguments; Legendre integrals reduce to these forms (for example, $K(m) = R_F(0, 1 - m, 1)$).
Evaluation uses Carlson duplication (DLMF §19.36(i)).
Each step reduces the relative spread of the arguments by approximately a factor of 1/4; once the spread is below 0.001, a fifth-degree series completes the sum.
Each step counts toward the work of `EllipticOptions`.
For real arguments, negative coordinates produce `DomainError` (`OutsideDomain`); the only exceptions are $p < 0$ in $R_J$ and $y < 0$ in $R_C$, which return Cauchy principal values.
Real evaluation targets 64 ULP over the checked range; the largest measured binary64 error of $R_F$, $R_D$, and $R_J$ is 4.8 ULP.

## Jacobi elliptic functions

The arguments are $u$ and the parameter $m$; $m$ is passed with the same type as $u$ or, if $u$ is complex, as a real number ([`Parameter`](oxref:special-api-argument-types)).
Complex $m$ requires complex $u$.
$\operatorname{sn}(u \mid m) = \sin\operatorname{am}(u \mid m)$, $\operatorname{cn}(u \mid m) = \cos\operatorname{am}(u \mid m)$, and $\operatorname{dn}^2 = 1 - m\operatorname{sn}^2$; the values at $u = 0$ are $(0, 1, 1)$.
Real $u$ and $m$ accept all finite pairs; $m < 0$ and $m > 1$ are handled by real transformations (DLMF §22.17).
For real $m$, evaluation reduces by the real period, then uses the arithmetic–geometric mean and amplitude descent with inverse sines (DLMF 22.20).
For complex $m$, evaluation reduces by modular transformations, then uses quotients of Jacobi theta functions (DLMF §20.7, §22.2).
For complex $u$, sn, cn, and dn are meromorphic, with poles at $u = 2jK + (2l + 1)\mathrm{i}K'$ ($K = K(m)$, $K' = K(1 - m)$, and integer $j, l$).
If reduction cannot determine the value at or immediately near a pole, the result is `DomainError` (`Pole`) or `NumericalInstability` (`LossOfSignificance`).
Real evaluation targets 64 ULP over the checked range; the median binary64 error of sn is at most 1.2 ULP (this is not the maximum).
