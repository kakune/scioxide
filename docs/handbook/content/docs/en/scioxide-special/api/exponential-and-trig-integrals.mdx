This page covers APIs for exponential integrals, trigonometric and hyperbolic integrals, logarithmic integrals, the inverse tangent integral, Dawson's integral, and Fresnel integrals.
Only Fresnel integrals and Dawson's integral accept `NumericScalar` (`f32`, `f64`, `Complex<f32>`, `Complex<f64>`); the others are real functions on `RealScalar` (`f32`, `f64`).
Each row lists the standard form returning only a value, the form with options `*_with_options` returning `SpecialFunctionResult`, and the scoped API `*_scoped(.., options, scope)` accepting a solve scope ([Three calling forms](oxref:special-api-call-forms)).
The option types are `ErrorFunctionOptions` for Dawson's integral, shared with the error function family, and `IntegralOptions` for the others; both contain only a work limit (`Budget`) and are listed in [Result types and options](../results-and-options/).
Functions with a fixed operation count independently of the arguments ($E_1$, $\operatorname{Ei}$ and their scaled forms, `expint_3`, logarithmic integrals, and the inverse tangent integral) have no scoped APIs.
Real Dawson's integral also has a fixed operation count, so `dawson_scoped` accepts only complex arguments, for which the cost varies with the argument.

All functions on this page return `NonFinite` for non-finite input, `NumericalInstability` for unrepresentable results or numerical breakdown, and `ConvergenceFailure` for computations that do not finish within the limit.
The tables state each function's `DomainError` conditions and conventions.
For real binary64 $E_1$, $\operatorname{Ei}$, $E_n$ (including $E_2$), `expint_3`, $\operatorname{Si}$, and $\operatorname{Ci}$, the target on comparison data independently generated at 160 and 240 digits is 8 ULP away from zeros; near zeros, checks use absolute error bounds that account for cancellation.
Estimated errors from the forms with options for $E_1$, $\operatorname{Ei}$, and $E_n$ (including their scaled forms), $\operatorname{Si}$, and $\operatorname{Ci}$ are envelopes calibrated against comparison data (`StatisticallyCalibrated`) when computation completes, and conservative model bounds (`ModelBased`) when it stops early.
Estimated errors from forms with options for `expint_3`, hyperbolic integrals, logarithmic integrals, the inverse tangent integral, and Fresnel integrals are always model bounds (`ModelBased`).
Scaled forms, hyperbolic integrals, logarithmic integrals, the inverse tangent integral, and Fresnel integrals (real and complex) have no uniform ULP specification; their forms with options return estimated errors.

## Exponential integrals

$E_1$ and $\operatorname{Ei}$ use scaled piecewise rational approximations, multiplying by the exponential factor only once at the end.
For $n \ge 2$, $E_n$ uses a power series with compensated summation for $x \le 1$ and a continued fraction for larger $x$, evaluated in the scaled form $e^x E_n(x)$.
Scaled forms return values with the dominant exponential factor removed inside the kernel, so they also work at arguments where the original function overflows or underflows.
For scaled exponential integrals, the derivative returned by the form with options is the derivative of the scaled function itself (for example, $\tfrac{d}{dx}(e^x E_n(x)) = e^x(E_n(x) - E_{n-1}(x))$).

## Trigonometric and hyperbolic integrals

$\operatorname{Si}$ and $\operatorname{Ci}$ use Chebyshev expansions in $t = (x^2 - 8)/8$ for $\lvert x\rvert \le 4$, rational approximations in $1/x^2$ for the auxiliary functions $f$ and $g$ for $4 < \lvert x\rvert < 48$, and asymptotic expansions of the auxiliary functions for $\lvert x\rvert \ge 48$.
$\operatorname{Shi}$ and $\operatorname{Chi}$ use power series for $\lvert x\rvert \le 1$ and combine the scaled kernels of `expint_ei` and `expint_e1` outside that range.
They grow at the rate $e^{\lvert x\rvert}/(2\lvert x\rvert)$ with $\lvert x\rvert$; in binary64, the standard form produces `NumericalInstability` (`Overflow`) near $\lvert x\rvert > 717$ (the form with options retains scaled and logarithmic forms), so use scaled forms in that range.
