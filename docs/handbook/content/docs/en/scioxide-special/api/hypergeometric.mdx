This table collects public items for generalized hypergeometric functions and named low-order hypergeometric functions.
Functions accept `NumericScalar` (`f32`, `f64`, `Complex<f32>`, `Complex<f64>`), using the same names for real and complex numbers.
Each row lists the ordinary form returning only a value, detailed form `*_with_options` taking `HypergeometricOptions` and returning `SpecialFunctionResult`, and scoped form `*_scoped(.., options, scope)` evaluating within a solve scope ([Three call forms](oxref:special-api-call-forms)).
`HypergeometricOptions` holds only a work limit (default 65536) and appears in [Result types and options](../results-and-options/).
Named-function parameters $a$, $b$, and $c$ may be supplied as real numbers even when argument $z$ is complex (`Parameter`).

As a shared rule, all parameters and arguments must be finite; nonfinite inputs yield `NonFinite`.
A nonpositive integer denominator parameter yields `DomainError` (`Pole`).
However, if a numerator parameter is a nonpositive integer larger than that denominator parameter, the series terminates before the denominator zero, giving a polynomial that can be evaluated.
Unrepresentable results or computational breakdown yield `NumericalInstability`; reaching the work limit yields `ConvergenceFailure`.
Detailed forms of named functions return a derivative with respect to the argument from contiguous relations, in addition to values and error estimates.
`hyp_pfq_with_options` does not return derivatives.
Estimated errors are not interval enclosures.

Real ${}_0F_1$, ${}_1F_1$, ${}_2F_1$, and $U$ target 64 ULP in both precisions over the compared ranges, using absolute-error comparisons near function zeros.
General ${}_pF_q$, ${}_2F_0$, regularized ${}_2F_1$, complex arguments, and parameter derivatives have no uniform ULP contract.
Their reported error estimates are checked against independently computed high-precision reference values.
Complex ${}_1F_1$ is tested at every phase up to $\lvert z\rvert = 10^4$, and ${}_2F_1$ to within distance $10^{-15}$ of $z = 1$.

## Generalized hypergeometric series and retained parameters

The generalized hypergeometric function is ${}_pF_q(a; b; z) = \sum_{k=0}^\infty \frac{(a_1)_k \cdots (a_p)_k}{(b_1)_k \cdots (b_q)_k}\frac{z^k}{k!}$, where $(x)_k = x(x+1)\cdots(x+k-1)$ is the Pochhammer symbol.
For a single evaluation without retaining parameters, use `hyp_pfq` and its detailed or scoped forms.
To evaluate many arguments with the same parameters, or obtain regularized series or parameter derivatives, construct `HypergeometricFunction` to validate and retain parameters.
Its `evaluate` allocates workspace on each call, while `evaluate_scoped` reuses a `HypergeometricWorkspace` constructed once with `workspace()` and does not allocate.
