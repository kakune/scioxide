This page covers real functions derived from Bessel functions: Kelvin, Struve, and parabolic cylinder functions, and integrals of order-zero Bessel and Struve functions.
Arguments and orders use `RealScalar` (`f32`, `f64`); the sole exception is `parabolic_d_complex`, which takes integer order `u32` and complex argument `Complex<S>`.
Functions taking an order use argument order `(order, x)`.
Each row lists the standard form returning only a value, the form with options `*_with_options` returning `SpecialFunctionResult`, and the scoped API `*_scoped(.., options, scope)` accepting a solve scope ([Three calling forms](oxref:special-api-call-forms)).
Work varies with argument and order, so every function on this page has a scoped API.
The option types `KelvinOptions`, `StruveOptions`, `ParabolicCylinderOptions`, and `BesselIntegralOptions` contain only a work limit (`Budget`) and are listed in [Result types and options](../results-and-options/).

All functions on this page return `NonFinite` for non-finite input, `NumericalInstability` for unrepresentable results or numerical breakdown, and `ConvergenceFailure` for computations that do not finish within the limit.
The tables state each function's `DomainError` conditions and conventions.
Only binary64 Struve functions have a uniform ULP specification.
Kelvin functions, parabolic cylinder functions, and integrals are checked by tests comparing values, derivatives, and estimated errors with independent reference values, but have no uniform ULP target.

## Kelvin functions

Kelvin functions are the real and imaginary parts of $I_0$ and $K_0$ evaluated on the ray $x e^{\mathrm{i}\pi/4}$: $\operatorname{ber} x + \mathrm{i}\operatorname{bei} x = I_0(x e^{\mathrm{i}\pi/4})$ and $\operatorname{ker} x + \mathrm{i}\operatorname{kei} x = K_0(x e^{\mathrm{i}\pi/4})$ (DLMF 10.61).
ber and bei sum power series (DLMF 10.65) in double-double precision for $\lvert x\rvert \le 10$; for larger $\lvert x\rvert$, they compute $I_0(\lvert x\rvert e^{\mathrm{i}\pi/4})$ with a power series below 20 and an asymptotic expansion (DLMF 10.67) at 20 and above.
ker and kei compute $K_0(x e^{\mathrm{i}\pi/4})$ with a double-double power series below 20 and an asymptotic expansion at 20 and above.
Values and derivatives use the same expansion.
ber and bei grow at the rate $e^{\lvert x\rvert/\sqrt{2}}$ with $\lvert x\rvert$ and produce `NumericalInstability` (`Overflow`) on overflow; ker and kei decay at the rate $e^{-x/\sqrt{2}}$.
Where ordinary values are unrepresentable, use named functions multiplied by exponential factors, such as `ber_scaled` and `ker_scaled` (`berp_scaled` and related functions for derivatives).

## Struve functions

Struve functions $\mathbf{H}_\nu$ and $\mathbf{L}_\nu$ are particular solutions of the inhomogeneous Bessel and modified Bessel equations.
For $x \ge 20$, evaluation attempts to sum $\mathbf{K}_\nu$ and $\mathbf{M}_\nu$ in $\mathbf{H}_\nu = Y_\nu + \mathbf{K}_\nu$ and $\mathbf{L}_\nu = I_\nu + \mathbf{M}_\nu$ by asymptotic expansions (DLMF 11.6), accepting them only when truncation error (and, for $\mathbf{L}_\nu$, the exponentially small difference $I_\nu - I_{-\nu}$) is below binary64 rounding.
Otherwise, the defining series is summed in double-double precision, so cancellation between terms loses only double-double rounding accuracy.
Orders $\nu = -(n + 1/2)$ use Bessel closed forms (DLMF 11.4.4, 11.4.5).
In binary64, the target on comparison data for $\nu \in [-5, 10]$ and $x \in [10^{-3}, 100]$ is 64 ULP; near zeros of $\mathbf{H}_\nu$, the target is absolute error at most $4\varepsilon\max(1, \lvert\mathbf{H}_\nu\rvert)$.
There is no uniform ULP target outside this range or for binary32.
Values are computed in binary64; values outside the binary64 range produce `NumericalInstability` (`Overflow`), and values exceeding only the binary32 range produce `ScalarConversion`.

## Parabolic cylinder functions

Parabolic cylinder functions solve $y'' + (\nu + \tfrac12 - \tfrac{x^2}{4}) y = 0$ ($D_\nu$, $V$) and $y'' + (\tfrac{x^2}{4} - a) y = 0$ ($W$) (DLMF 12).
$D_\nu$ uses power series about the origin with compensated summation for $\lvert\nu\rvert \le 2$ and $\lvert x\rvert \le 3$, and an asymptotic expansion (DLMF 12.9) for $\lvert x\rvert \ge \max(32, 2(\lvert\nu\rvert + 1))$.
In between, negative orders use quadrature of an integral representation (DLMF 12.5), while positive orders use forward order recurrence (DLMF 12.8, approximately $\nu$ steps); negative $x$ uses a connection formula with $V$.
$V_\nu$ and $W$ continue the solution from origin values using a Taylor method for the differential equation ($V_\nu$ uses an asymptotic expansion for large $\lvert x\rvert$).
Forms with options for real functions return empirical estimated errors (`Heuristic`).
Tests of $D_\nu$ and $V_\nu$ compare with reference values for $\lvert\nu\rvert \le 20$ and $\lvert x\rvert \le 10^4$.

## Bessel and Struve integrals

Integrals of order-zero Bessel and Struve functions use termwise-integrated power series for $\lvert x\rvert \le 12$, Chebyshev expansions for $12 < \lvert x\rvert < 32$, and asymptotic expansions of tail integrals for $\lvert x\rvert \ge 32$ (integrals of $I_0$ and $\mathbf{L}_0$ use power series for $\lvert x\rvert < 32$ and asymptotic expansions above that range).
Forms with options return estimated errors and derivatives with respect to $x$.
The derivative is the integrand for forms $\int_0^x$ and its negative for forms $\int_x^\infty$.
Logarithmic integration constants are defined by finite parts of Mellin transforms (DLMF 10.22).
Integrand normalization follows the named order-zero functions.
