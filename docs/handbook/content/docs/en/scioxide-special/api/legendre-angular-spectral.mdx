These tables cover public items related to angular eigenfunctions.
Legendre functions and spherical harmonics return values; each row lists the standard form returning only the value, the form with options `*_with_options` that accepts options and returns `SpecialFunctionResult`, and the scoped API `*_scoped(.., options, scope)` that evaluates within a solve scope ([three calling forms](oxref:special-api-call-forms)).
Angular momentum coupling coefficients, Mathieu functions, spheroidal functions, and ellipsoidal harmonics are evaluated with a plan holding prepared coefficients (`*Plan`), or a one-shot function that creates one plan internally and evaluates it once.
Plans provide `new` for preparation with default execution and `build(.., scope)` for preparation within a solve scope; evaluation methods have ordinary and `*_scoped` forms.
Preparation and each evaluation have separate work limits.
One-shot functions allocate on every call (allocation failure produces `AllocationFailure`), share one default limit between preparation and evaluation, and return only the value.
Create a plan when estimated errors or diagnostics are needed.
`LegendreOptions` for Legendre functions and spherical harmonics is listed in [Result types and options](../results-and-options/); options for angular momentum and spectral functions are listed on this page.

For all rows, non-finite input produces `NonFinite`, unrepresentable results or computational breakdown produce `NumericalInstability`, and reaching the work limit produces `ConvergenceFailure`.

## Legendre functions

Real Legendre functions $P$ and $Q$ and associated functions target 64 ULP in both precisions over the checked range; comparisons near zeros use absolute error.
The largest measured binary64 error of $P$ is 0.5 ULP; tests include degrees through 20,000.
Degrees are nonnegative integers `degree: usize`; each recurrence step uses one unit of work.
Degrees requiring more than the default 65536 units produce `ConvergenceFailure` (`IterationLimit`).

## Spherical harmonics

Options use `LegendreOptions`, shared with Legendre functions (65536 units by default).
Normalized associated Legendre functions use recurrence with binary scaling, avoiding overflow and underflow even at high degrees.
$e^{\mathrm{i}m\phi}$ is formed by repeated squaring of $e^{\mathrm{i}\phi}$, avoiding rounding in the product $m\phi$.
The computational cost is approximately $\ell + \log_2\lvert m\rvert$ units.
There is no uniform ULP specification.
Estimated errors from forms with options use a rounding model for the normalized recurrence, growing like $32\varepsilon(1 + \ell + \lvert m\rvert)^2$ relative to term magnitudes.

## Angular momentum coupling coefficients

Angular momentum $j \in \{0, 1/2, 1, 3/2, \dots\}$ is represented exactly by doubled integers $2j$.
Coupling coefficients are sums of factorial ratios in Racah's formulas (DLMF §34.2, §34.4); each factorial is represented as a product of prime powers, and terms are summed as exact multiword integers (Johansson and Forssén, 2016).
Rounding occurs only in the final conversion to the scalar type.
Triangle, parity, and magnetic-quantum-number sum selection rules are checked first; forbidden coefficients return exact 0.
There is no uniform ULP specification; the relative estimated error of a plan's detailed result is the floating-point operation count of the final conversion multiplied by $8\varepsilon$.

One-shot functions accept integer arrays of doubled quantum numbers (`gaunt` uses undoubled degrees and orders) and allocate a plan and workspace sized for the maximum angular momentum on each call.
For repeated evaluations, construct `AngularPlan` once.
Plan methods returning owned values allocate workspace on every call; `*_scoped` methods reuse `AngularWorkspace` and evaluate without allocating.

## Mathieu and spheroidal functions

Mathieu and spheroidal plans solve the symmetric tridiagonal eigenvalue problem obtained by truncating the three-term recurrence for expansion coefficients; Sturm bisection and inverse iteration find only the eigenpair for the requested mode, and the plan stores its coefficients.
The coefficient count starts at $\max(\text{minimum}, \text{mode index} + 8)$ and doubles until two successive truncations agree within tolerance.
If they do not agree, no plan is committed to the output.
Preparation and evaluation both use binary64 for either scalar type.
The tolerance in `SpectralOptions` controls changes in characteristic values and coefficients and estimates of the omitted tail; relaxing it reduces work.
There is no fixed ULP bound.
The residual and tail estimate in `diagnostics()` and each evaluation's estimated error (including truncation error) guide assessment; they are not guaranteed bounds.
Complex coordinates can amplify the tail of coefficients that were not retained.

One-shot functions such as `mathieu_a` create one plan with standard normalization (`SpectralNormalization::Standard`) and default `SpectralOptions`; preparation and evaluation share a work limit of 2,097,152 units.
Modes outside the default truncation range produce `InvalidInput` (`OutOfRange`) for argument `order` in Mathieu one-shot functions and argument `n` in spheroidal one-shot functions.
If the two truncations do not agree by the default maximum of 256 coefficients, the result is `ConvergenceFailure` (`TruncationLimit`).
Create a plan for evaluation at many points, different normalization or options, or estimated errors.

## Ellipsoidal harmonics

Ellipsoidal harmonics based on Lamé functions are prepared with `EllipsoidalHarmonicPlan` and evaluated in triaxial ellipsoidal coordinates with semifocal distances $0 < h < k$.
The Lamé function of the first kind $E_n^p(s)$ is the $p$th solution of Lamé's equation expressible as a polynomial times focal factors, with leading coefficient 1.
Preparation uses binary64 for both precisions; after solving the symmetric tridiagonal eigenvalue problem for the Chebyshev coefficients in $s/h$, it recomputes the eigenvector from the three-term recurrence toward its largest component.
Work and temporary memory are $O(n^2)$; coefficients retained by the plan are $O(n)$.
First-kind values use Clenshaw recurrence for the Chebyshev sum; second-kind values and normalization constants use adaptive quadrature controlled by the relative tolerance in `EllipsoidalOptions`.
Second-kind functions and normalization constants follow the definitions of Dassios (2012).
There is no fixed ULP bound.
`spectral_residual()` is the eigenvalue problem residual; each evaluation's estimated error is derived from coefficient error, conditioning of the Chebyshev sum, and quadrature tolerance.
Neither is a guaranteed bound.
