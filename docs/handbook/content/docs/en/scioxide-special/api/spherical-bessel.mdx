This page collects integer-order $n$ spherical Bessel $j_n, y_n, i_n, k_n$, spherical Hankel, Riccati–Bessel, and hyperbolic-space spherical $H_\ell(\lambda, \eta)$ functions.
Spherical Bessel and Hankel functions accept real (`f32`, `f64`) or complex (`Complex<f32>`, `Complex<f64>`) arguments under one `NumericScalar` function name, taking orders as `u32`.
Riccati–Bessel and H3d accept only real `RealScalar`.
Each row lists ordinary value-only forms, detailed `*_with_options` returning `SpecialFunctionResult`, and scoped `*_scoped(.., options, scope)` taking solve scopes ([Three call forms](oxref:special-api-call-forms)).
Work grows with order, so every function here has scoped forms.
Argument order is `(order, z)` (`(order, lambda, eta)` for H3d).
All use work limits `SphericalBesselOptions` (combined recurrence and series work, default 65536 units); see [Result types and options](../results-and-options/).
No order-sequence functions return multiple orders together; call separately for each order.
Nonfinite inputs yield `NonFinite`, domain violations and poles `DomainError`, unrepresentable results or breakdown `NumericalInstability`, and evaluations exceeding work limits `ConvergenceFailure`.
These functions have no uniform ULP contract.
Tests compare values and error estimates against independent references, using mixed absolute/relative tolerances near zeros.

## Spherical Bessel functions

Spherical Bessel functions are defined from half-integer cylindrical functions by $f_n(z) = \sqrt{\pi/(2z)}\,F_{n+1/2}(z)$ ($F = J, Y, I, K$).
Complex values use $\sqrt{z}$ and principal cylindrical branches.
Real $j_n$ and $i_n$ use power series for $\lvert x\rvert \le 1$ and order recurrences otherwise (Miller backward recurrence where forward recurrence is unstable); $y_n$ and $k_n$ use forward recurrence.
Complex functions use power series for $\lvert z\rvert < 1/4$ and cylindrical functions of order $n + 1/2$ otherwise.
Normalization of $k_n$ includes $\pi/2$, giving $k_0(x) = \pi e^{-x} / (2x)$.

## Spherical Hankel functions and complex scaled forms

Spherical Hankel and scaled forms accept real or complex `NumericScalar` arguments, returning complex `Complex<T::Real>` even for real arguments.
Off the real axis, they compute through modified Bessel functions of order $n + 1/2$.
For scaled forms, detailed derivatives are original-function derivatives multiplied by the same factor; the scale factor itself is not differentiated.
