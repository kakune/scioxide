These tables cover thermal integrals appearing in heat capacity, degenerate electron gases, metallic transport, and synchrotron radiation.
All functions accept only real arguments and return `RealScalar` (`f32`, `f64`) values.
Each row lists the standard form that returns only the value, the form with options `*_with_options` that returns `SpecialFunctionResult`, and the scoped API `*_scoped(.., options, scope)` that evaluates within a solve scope ([three calling forms](oxref:special-api-call-forms)).
`fermi_dirac_m1`, `fermi_dirac_0`, `fermi_dirac_inc_0`, and synchrotron functions, whose work is bounded independently of the arguments, have no scoped APIs.
The option types are `DebyeOptions`, `FermiDiracOptions`, `TransportOptions`, and `SynchrotronOptions`; each contains only a work limit (128 by default for `TransportOptions` and `SynchrotronOptions`, 65536 for the others) and is listed in [Result types and options](../results-and-options/).

For all rows, non-finite input produces `NonFinite`, unrepresentable results or computational breakdown produce `NumericalInstability`, and reaching the work limit produces `ConvergenceFailure`.
These functions have no uniform ULP specification.
Forms with options return derived error bounds; tests in both precisions check values, returned error bounds, scaled forms, and logarithmic forms.
Very small values underflow to 0 or subnormals, but forms with options retain logarithmic forms.

## Debye functions

The normalized Debye function is $D_n(x) = \dfrac{n}{x^n}\displaystyle\int_0^x \frac{t^n}{e^t - 1}\,dt$ ($x \ge 0$), decreasing from $D_n(0) = 1$ and behaving like $n \cdot n!\,\zeta(n+1)/x^n$ for large $x$.
The domain is finite $x \ge 0$; negative $x$ produces `DomainError` (`OutsideDomain`).
There are no poles.
For $x \le 4$, uses a Chebyshev expansion in $x^2/8$; for $x > 4$, subtracts the exponentially convergent tail $\sum_k e^{-kx}\,(\text{polynomial in }1/(kx))$ from the large-$x$ limit.
For $n \ge 2$, uses logarithms without forming $x^n$ directly.

## Fermi–Dirac integrals

The Gamma-normalized Fermi–Dirac integral is $F_j(x) = \dfrac{1}{\Gamma(j+1)}\displaystyle\int_0^\infty \frac{t^j}{e^{t-x} + 1}\,dt = -\operatorname{Li}_{j+1}(-e^x)$ ($j > -1$, DLMF §25.12(iii)), satisfying $F_j' = F_{j-1}$.
$j = -1$ is its analytic continuation, the logistic function $1/(1 + e^{-x})$.
All finite real $x$ is accepted, with no poles or cuts.
On the negative side, values can underflow to 0 (approximately $x < -745$ in binary64).
On the positive side, $F_j(x) \approx x^{j+1}/\Gamma(j+2)$ outside the scalar range produces `NumericalInstability` (`Overflow`); the form with options returns the value in logarithmic form.
Half-integer orders and orders 1 and 2 use the series $\sum_k (-1)^{k+1}e^{kx}/k^{j+1}$ for $x < -1$ and Chebyshev expansions on four intervals for $-1 \le x < 30$.
For $x \ge 30$, half-integer orders use a Sommerfeld asymptotic expansion, and integer orders use the exact inversion formula $F_j(x) = (\text{polynomial}) \pm F_j(-x)$.

## Transport integrals

Transport integrals are $J_n(x) = \displaystyle\int_0^x \frac{t^n e^t}{(e^t - 1)^2}\,dt$ ($n = 2, \dots, 5$), appearing in Bloch–Grüneisen expressions for electrical and thermal conduction in metals.
The domain is finite $x \ge 0$; negative $x$ produces `DomainError` (`OutsideDomain`).
$J_n(0) = 0$; they increase as $x \to \infty$ and approach $n!\,\zeta(n)$.
There are no finite poles.
For $x \le 4$, multiplies a Chebyshev expansion in $x^2/8$ by $x^{n-1}$; for $x > 4$, subtracts an exponentially convergent tail from the limit.

## Synchrotron functions

Synchrotron functions are expressed in terms of the modified Bessel function of the second kind $K_\nu$ (Rybicki and Lightman, 1979, Chapter 6); their domain is finite $x \ge 0$, and negative $x$ produces `DomainError` (`OutsideDomain`).
The origin value is 0; for large $x$, they decay like $\sqrt{\pi x/2}\,e^{-x}$ and underflow near $x > 745$ in binary64.
Scaled forms return values multiplied by $e^x$, remaining within range even in this tail.
For $x \le 1$, uses Chebyshev expansions in $x^2/8$ with fractional powers of $x$ factored out; for $(1, 4]$, uses separate Chebyshev expansions; for $x > 4$, uses Chebyshev expansions in $1/(x + c)$ of the scaled tail, with fixed computational cost.
Consequently, none of the forms has a scoped API.
