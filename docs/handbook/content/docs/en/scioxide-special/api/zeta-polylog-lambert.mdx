These tables cover public items for zeta functions, polylogarithms and related functions, Lambert W, and Wright omega.
Functions accepting `NumericScalar` (`f32`, `f64`, `Complex<f32>`, `Complex<f64>`) use the same names for real and complex arguments.
Only `hurwitz_zeta_log`, `clausen`, `lambert_w0`, and `lambert_wm1` accept exclusively `RealScalar`; complex Lambert W is a separate function `lambert_w_complex` taking a branch index.
Each row lists the standard form returning only the value, the form with options `*_with_options` that accepts options and returns `SpecialFunctionResult`, and the scoped API `*_scoped(.., options, scope)` that evaluates within a solve scope ([three calling forms](oxref:special-api-call-forms)).
`dilog`, `spence`, and `clausen`, whose work is nearly constant independently of the arguments, have no scoped APIs.
The option types are `ZetaOptions` for zeta and eta functions, `PolylogOptions` for dilogarithm, Spence, and polylogarithm functions, `LerchOptions` for Lerch functions, `ClausenOptions` for Clausen functions, and `LambertOptions` for Lambert W and Wright omega.
Each contains only a work limit (128 by default for `ClausenOptions`, 65536 for the others) and is listed in [Result types and options](../results-and-options/).

For all rows, non-finite input produces `NonFinite`, unrepresentable results or computational breakdown produce `NumericalInstability`, and reaching the work limit produces `ConvergenceFailure`.
Complex evaluation uses principal powers and logarithms; signed zero of the imaginary part selects the side on cuts.
There is no uniform ULP specification for complex evaluations.

## Riemann and Hurwitz zeta and eta functions

Real Riemann zeta and eta functions and real Hurwitz zeta for $s > 1$ are within 64 ULP in both precisions over the checked range; estimated errors from forms with options are at most $64\varepsilon\lvert v\rvert$ ($v$ is the value).
Real Hurwitz zeta for $s < 1$ returns a derived absolute error and is tested for $s \in [-60, 1)$ and $q \in (0, 1000]$.
Relative error can be large near its zeros, without producing an error.

## Polylogarithms and Lerch functions

Real dilogarithm and Spence functions target 64 ULP in both precisions over the checked range.
General-order polylogarithms, Lerch functions, and complex arguments have no uniform ULP specification; values and derivatives are checked against independent reference values.
Real dilogarithm and Spence evaluations use a fixed term count and have no scoped APIs.

## Lambert W and Wright omega

Real $W_0$, $W_{-1}$, and Wright omega target 64 ULP in both precisions over the checked range; comparisons near the branch point $-1/e$ use absolute error.
All use Halley iteration; near the branch point, iteration starts from a series in the branch coordinate $u = W + 1$.
Complex branches have no uniform ULP specification; estimated errors derive from the Halley correction and residual.
