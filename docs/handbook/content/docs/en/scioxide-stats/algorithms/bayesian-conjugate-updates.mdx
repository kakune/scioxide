Bayesian inference represents uncertainty in an unknown parameter $\theta$ by a probability distribution.
Writing knowledge before observations $y$ as prior $p(\theta)$ and the observation model as likelihood $p(y \mid \theta)$, Bayes' theorem gives the distribution after observation (posterior):

$$
p(\theta \mid y) = \frac{p(y \mid \theta)\, p(\theta)}{\int p(y \mid \theta')\, p(\theta')\, d\theta'} \;\propto\; p(y \mid \theta)\, p(\theta)
$$


The normalizing denominator (marginal likelihood) generally requires integration, but particular prior forms make the posterior belong to the same family as the prior, allowing updates by parameter addition alone.
This property is called conjugacy.
This page derives three conjugate pairs provided by `scioxide-stats` (Beta–binomial, Gamma–Poisson, normal–inverse-gamma), computes posterior summaries (means and equal-tailed credible intervals), and obtains distributions of future observations (posterior predictive distributions).
For nonconjugate models, Markov chain Monte Carlo (MCMC) samples the posterior; `scioxide-stats` provides no sampler, only diagnostics and summaries of sampled chains.
See [MCMC convergence diagnostics and posterior summaries](../mcmc-diagnostics/).

## Conjugate updates and posterior summaries

For conjugate pairs, posterior distributions depend only on sufficient statistics (successes and trials for binomial data; count, mean, and sum of squared deviations for normal data).
Updating observations together or one at a time therefore gives the same posterior.
Prior types in `scioxide-stats` (`BetaBinomialPrior`, `GammaPoissonPrior`, `NormalInverseGammaPrior`) represent both priors and posteriors; update methods return new values without changing the originals.
Parameters are stored as extended-range values with a wider exponent range and rounded to `S` when read through `parameters()`.
If rounded values overflow `S`, return `NumericalInstability`.
Update cost is $O(1)$ per observation.

A prior whose density cannot integrate to 1 (cannot be normalized) is called improper.
Even an improper prior can give a proper posterior after sufficient observations.
Each type's `is_proper()` reports whether parameters define a proper distribution; requesting posterior or predictive distributions from an improper state returns `InvalidInput`.

Use posterior means and credible intervals as summaries.
An equal-tailed credible interval of probability $c$ is $[q_{(1-c)/2},\, q_{(1+c)/2}]$, leaving probability $(1-c)/2$ in each posterior tail; conditional on observations, posterior probability that $\theta$ lies in it is $c$.
A frequentist confidence interval instead covers the true value in proportion $c$ of repetitions of the same sampling procedure, a different interpretation.
As the next sections show, some priors give numerically identical intervals, but their interpretations remain distinct.

`credible_interval(law, probability, options)` returns equal-tailed credible intervals for `law` distributions from `scioxide-random` (providing lower/upper log-tail probabilities and support).
Invert $\ln F(x) = \ln\frac{1-c}{2}$ for the lower endpoint and $\ln S(x) = \ln\frac{1-c}{2}$ for the upper ($S = 1 - F$ is the survival function), using settings `InversionOptions`.
Using the survival function for the upper endpoint instead of the $1 - (1-c)/2$ quantile of $F$ avoids upper-tail cancellation.
Each endpoint separately uses the evaluation limit of `options`, bounding total work by twice that limit.
Nonconvergent inversion returns `ConvergenceFailure`; infinite endpoints return `NonFinite`.
Result `CredibleInterval` holds interval `bounds()` and probability `probability()`.

The evaluation limit in `InversionOptions` (default 65,536) counts internal special-function iterations for tail probabilities as well as bisection evaluations.
Even when upper-tail evaluation uses many continued-fraction iterations, as for the upper endpoint of beta distribution $\mathrm{Beta}(5.5, 25.5)$, the default limit suffices because it permits the same work as one distribution operation in `scioxide-random`.
Cells on this page use default `InversionOptions`.

Highest posterior density (HPD) intervals are not provided.
For a unimodal posterior, obtain one by minimizing width $[Q(u), Q(u + c)]$ over $u \in (0, 1-c)$ using quantiles from `scioxide-random`.
No posterior-mode (maximum a posteriori estimate) function is provided either; compute it from the closed forms below.

## Bernoulli/binomial observations and Beta–binomial conjugate updates

For $k$ successes in $n$ trials with success probability $p$, likelihood is proportional to $p^k(1-p)^{n-k}$.
A beta prior $\mathrm{Beta}(\alpha, \beta)$ with density $\propto p^{\alpha-1}(1-p)^{\beta-1}$ gives posterior

$$
p \mid k \;\sim\; \mathrm{Beta}(\alpha + k,\; \beta + n - k)
$$


$\alpha$ and $\beta$ can be interpreted as prior pseudo-counts of successes and failures.
Posterior $\mathrm{Beta}(a, b)$ has mean, variance, and mode

$$
E[p] = \frac{a}{a+b}, \qquad
\mathrm{Var}[p] = \frac{ab}{(a+b)^2(a+b+1)}, \qquad
\mathrm{mode} = \frac{a-1}{a+b-2}\ (a, b > 1)
$$

Posterior mean $\frac{\alpha + k}{\alpha + \beta + n}$ averages prior mean $\frac{\alpha}{\alpha+\beta}$ and sample proportion $k/n$ with weights $\alpha+\beta$ and $n$.
For $a \le 1$ or $b \le 1$, the density diverges at an endpoint or is monotone, with no interior mode.

The posterior predictive distribution of successes $Y$ in $m$ future trials is beta-binomial $\mathrm{BetaBinomial}(m, a, b)$, averaging the binomial distribution over the posterior:

$$
E[Y] = m\frac{a}{a+b}, \qquad
\mathrm{Var}[Y] = \frac{m\,ab\,(a+b+m)}{(a+b)^2(a+b+1)}
$$


Its variance is $(a+b+m)/(a+b+1)$ times binomial variance $m\,\bar p(1-\bar p)$ with $p$ fixed at its posterior mean, widened by uncertainty in $p$.

Three common priors are: uniform $\mathrm{Beta}(1, 1)$, Jeffreys prior $\mathrm{Beta}(1/2, 1/2)$ (proportional to the square root of Fisher information and invariant under reparameterization), and Haldane prior $\mathrm{Beta}(0, 0)$ (improper, with density $\propto p^{-1}(1-p)^{-1}$).
Haldane posterior mean equals sample proportion $k/n$, but the posterior stays improper for $k = 0$ or $k = n$.

`BetaBinomialPrior::new(alpha, beta)` constructs a proper prior, returning `NonFinite` for NaN/infinite parameters and `InvalidInput` for nonpositive parameters.
`BetaBinomialPrior::improper(alpha, beta)` constructs an improper prior with at least one zero parameter, returning `InvalidInput` if both are positive.
`update(successes, trials)` returns the posterior, leaving the distribution unchanged for zero trials and returning `InvalidInput` if successes exceed trials.
`update_frequency(successes, trials, frequency)` performs update $\mathrm{Beta}(\alpha + fk, \beta + f(n-k))$ repeating the same observation $f$ times, for aggregated data.
`update_batch(&[(successes, trials)])` takes in a sequence of observations in order.
`posterior_law()` returns `Beta` from `scioxide-random`; `predictive(m)` returns `BetaBinomial`.

## Poisson observations and Gamma–Poisson conjugate updates

Counting events at rate $\lambda$ per unit time over exposure $t$ (time, area, person-time, etc.)
gives count $k$ following $\mathrm{Poisson}(\lambda t)$, with likelihood proportional to $\lambda^k e^{-\lambda t}$.
A gamma prior $\mathrm{Gamma}(a, \beta)$ of shape $a$ and rate $\beta$, density $\propto \lambda^{a-1}e^{-\beta\lambda}$, gives posterior

$$
\lambda \mid k \;\sim\; \mathrm{Gamma}(a + k,\; \beta + t)
$$

Here $a$ is a prior pseudo-count and $\beta$ a pseudo-exposure.
Posterior mean is $(a+k)/(\beta+t)$ and variance $(a+k)/(\beta+t)^2$.
The posterior predictive count $Y$ for future exposure $t'$ is negative binomial with success probability $\beta/(\beta + t')$ and success count $a$:

$$
E[Y] = \frac{a\,t'}{\beta}, \qquad
\mathrm{Var}[Y] = \frac{a\,t'(\beta + t')}{\beta^2}
$$

Its variance exceeds its mean (overdispersion).
Here $a$ and $\beta$ are posterior parameters.

The Jeffreys prior for a Poisson rate is $p(\lambda) \propto \lambda^{-1/2}$, an improper distribution corresponding to $\mathrm{Gamma}(1/2, 0)$.
Improper priors $\mathrm{Gamma}(0, 0)$ and $\mathrm{Gamma}(1, 0)$ connect to frequentist inference.
From Poisson-process waiting-time relation $P(X \ge k;\, \lambda t) = P(G_k \le \lambda t)$ ($G_k \sim \mathrm{Gamma}(k, 1)$), the lower Garwood confidence bound ([Parameter inversion and exact confidence limits from tail probabilities](oxref:stats-inversion-confidence-limit-computation)) equals the $(1-c)/2$ quantile of posterior $\mathrm{Gamma}(k, t)$, and the upper bound the $(1+c)/2$ quantile of $\mathrm{Gamma}(k+1, t)$.
The credible interval of Jeffreys posterior $\mathrm{Gamma}(k + 1/2, t)$ lies between these bounds.

In `GammaPoissonPrior::new(shape, rate)`, `rate` is rate (inverse scale), not scale.
`GammaPoissonPrior::improper(shape, rate)` constructs an improper prior with at least one zero parameter.
`update(count, exposure)` returns `NonFinite` for NaN/infinite exposure and `InvalidInput` for negative exposure or zero exposure with positive count.
The caller fixes exposure units, and $\lambda$ is the rate per such unit.
`update_frequency(count, exposure, frequency)` and `update_batch(&[(count, exposure)])` have the same meanings as for binomial observations.
`posterior_law()` returns `Gamma` from `scioxide-random` (shape $a$, scale $1/\beta$).
`predictive(exposure)` returns `NegativeBinomial`; zero exposure gives a point mass at zero.
If positive exposure is so small that $\beta/(\beta + t')$ rounds to 1, return `InvalidInput`.

## Normal observations and normal–inverse-gamma conjugate updates

For observations from normal $N(\mu, \sigma^2)$ with both unknown mean $\mu$ and variance $\sigma^2$, the conjugate prior is normal–inverse-gamma $\mathrm{NIG}(m, \kappa, a, b)$:

$$
\sigma^2 \sim \mathrm{InvGamma}(a, b), \qquad \mu \mid \sigma^2 \sim N\!\left(m,\; \frac{\sigma^2}{\kappa}\right)
$$


$m$ is location, $\kappa$ a pseudo-count for the mean (precision multiplier), $a$ variance shape, and $b$ variance scale; $2a$ corresponds to a pseudo-count for variance.
For $n$ observations with mean $\bar x$ and squared-deviation sum $Q = \sum_i (x_i - \bar x)^2$, the posterior is

$$
\kappa_n = \kappa + n, \quad
m_n = \frac{\kappa m + n\bar x}{\kappa_n}, \quad
a_n = a + \frac{n}{2}, \quad
b_n = b + \frac{Q}{2} + \frac{\kappa n (\bar x - m)^2}{2\kappa_n}
$$

(Gelman et al., BDA, 3rd ed., §3.3).
The last term of $b_n$ increases variance estimates for disagreement between prior location $m$ and sample mean $\bar x$.

Posterior marginals are as follows.

- Mean: $\mu = m_n + \sqrt{b_n/(a_n\kappa_n)}\; T$, where $T$ is Student's t with $2a_n$ degrees of freedom.
- Variance: $\sigma^2 \sim \mathrm{InvGamma}(a_n, b_n)$.
  Posterior mean $b_n/(a_n - 1)$ exists only for $a_n > 1$.
- Standard deviation: $\sigma = \sqrt{\sigma^2}$.
  Posterior mean $\sqrt{b_n}\,\Gamma(a_n - 1/2)/\Gamma(a_n)$ exists only for $a_n > 1/2$.
- Prediction for a new observation of precision multiplier $w$ (variance $\sigma^2/w$): t distribution with degrees of freedom $2a_n$, location $m_n$, and scale $\sqrt{(b_n/a_n)(1/w + 1/\kappa_n)}$.

Reference prior $p(\mu, \sigma^2) \propto 1/\sigma^2$ corresponds to an improper distribution with $m = 0$, $\kappa = 0$, $a = -1/2$, and $b = 0$.
Its posterior has $\kappa_n = n$, $m_n = \bar x$, $a_n = (n-1)/2$, and $b_n = Q/2$, and is proper if $n \ge 2$ and $Q > 0$.
Writing sample variance as $s^2 = Q/(n-1)$, the posterior distribution of the mean is $\bar x + (s/\sqrt n)\,T_{n-1}$ and the posterior distribution of the variance is $Q/\chi^2_{n-1}$.
Thus reference-prior equal-tailed credible intervals for $\mu$ numerically equal Student-t confidence interval $\bar x \pm t_{n-1,(1+c)/2}\, s/\sqrt n$, and those for $\sigma^2$ equal $\chi^2$ confidence interval $[Q/\chi^2_{n-1,(1+c)/2},\, Q/\chi^2_{n-1,(1-c)/2}]$.

`NormalInverseGammaPrior::new(location, precision, shape, scale)` constructs a proper prior, returning `NonFinite` for NaN/infinite location and `InvalidInput` for other nonpositive parameters (`NonFinite` for NaN/infinite values).
`reference()` returns the reference prior.
`parameters()` returns parameters in order $(m, \kappa, a, b)$.
Observation methods are as follows.

- `update(value)` takes one observation; `update_batch(values)` takes a slice, using $O(n)$ time and $O(1)$ storage.
  NaN/infinite observations return `NonFinite`.
- `update_moments(&OnlineMoments)` and `update_snapshot(MomentsSnapshot)` update in $O(1)$ from count, mean, and squared-deviation sum of accumulators in [Online means, variances, higher moments, and covariance](../online-moments-and-covariance/).
  Accumulators merge, allowing posterior construction after combining distributed aggregates.
- `update_weighted(&OnlineWeightedMoments)` and `update_weighted_snapshot` update from weighted accumulators.
  Frequency weights (`Frequency`) count observations that many times.
  Analytic weights (`Analytic`) treat observation $x_i$ as having variance $\sigma^2/w_i$, weight $\bar x$ and $Q$, increase $\kappa$ by $\sum w_i$, and increase $a$ by half the observation count.
  Uniformly multiplying analytic weights by a constant changes the model.
  Reliability weights (`Reliability`) do not define a likelihood and are rejected by the `ConjugateWeights` type constraint (do not compile).

`posterior_law()` returns joint distribution `NormalInverseGamma` from `scioxide-random`.
`marginals()` returns grouped marginals `NormalPosteriorMarginals`; `mean_law()` gives the mean's t distribution (`Affine<StudentT>`), `variance_law()` inverse-gamma variance, and `standard_deviation_law()` standard deviation (both `Affine<GeneralizedGamma>`).
Each distribution provides density, tail probabilities, quantiles, moments, and sampling.
`predictive(precision_multiplier)` returns the predictive distribution (`Affine<StudentT>`) of a new observation; pass $w = 1$ for precision matching the data.
All return `InvalidInput` for improper posteriors.

`NormalPosteriorMarginals::credible_summary(probability, options)` computes posterior means and equal-tailed intervals for mean, variance, and standard deviation, returning `NormalCredibleSummary { mean, variance, standard_deviation }`.
Each component is `CredibleSummary { mean, interval }`; if the posterior mean does not exist, `mean` is `None`.
Functions using data directly with the reference prior are `normal_posterior_marginals(values)` for marginals and `normal_credible_summary(values, probability, options)` for summaries.
The latter gives each of six interval endpoints its own evaluation limit from `options`.
Fewer than two values or all-equal values return `InvalidInput`.

### Batch updates through matrix views

Use `normal_posteriors_into(requests, execution, output, staging, context)` to obtain posteriors for many independent series (manufacturing lots, sensors, etc.)
at once.
Request `NormalPosteriorRequest::new(prior, values)` pairs a prior with an `scioxide-linalg` matrix view and reads all entries as observations in row-major order.
Views may be strided or transposed; matrix shape does not affect the posterior.
`with_weights(Weights::<_, M>::new(view))` adds frequency or analytic weights matching observation shape; read contents with `prior()`, `values()`, and `weights()`.
Up to 64 workers process requests in parallel under `execution` (`ExecutionPolicy`); each reads its observations in fixed order, making results independent of worker count.
`staging` is a scratch array at least as long as the request count; on success every element of `output` is `Some`.
Cost is proportional to total observation count.
Mismatched `output`/`staging` lengths or weight/observation shapes return `InvalidInput`; NaN/infinite observations or weights return `NonFinite`; negative weights return `InvalidInput`; noninteger frequency weights return `ScalarConversion`.

The next cell receives samples and prior selection and recomputes the same posterior by batch updates.
Rows 1 and 2 pass the same eight values through $1 \times 8$ and $2 \times 4$ matrix views, comparing with the preceding posterior.
Row 3 uses frequency weight 2 and compares with `update_batch` for samples repeated twice.
Row 4 uses analytic weight 2 and compares with hand calculations substituting weighted $\bar x$ and $Q_w = \sum_i w_i (x_i - \bar x_w)^2$ into the formulas above.
Row 5 merges `OnlineMoments` from the first and last four values and passes it to `update_moments`.

```rust
let analytic = (
    (k0 * m0 + weight_sum * mean) / kappa,
    kappa,
    a0 + count as f64 / 2.0,
    b0 + weighted_scatter / 2.0 + k0 * weight_sum * (mean - m0) * (mean - m0) / (2.0 * kappa),
);
// Merge first-half and second-half accumulators before updating
let mut merged = OnlineMoments::from_slice(&values[..count / 2], MomentOrder::Second)
    .map_err(|e| e.to_string())?;
let second = OnlineMoments::from_slice(&values[count / 2..], MomentOrder::Second)
    .map_err(|e| e.to_string())?;
merged.merge(&second).map_err(|e| e.to_string())?;
let from_moments = start.update_moments(&merged).map_err(|e| e.to_string())?;
let (rm, rk, ra, rb) = (reference[0], reference[1], reference[2], reference[3]);
let checks = [
    ("1 × 8 view", output[0], (rm, rk, ra, rb)),
    ("2 × 4 view", output[1], (rm, rk, ra, rb)),
    ("Frequency weight 2", output[2], duplicated),
    ("Analytic weight 2", output[3], analytic),
    ("Merged OnlineMoments", Some(from_moments), (rm, rk, ra, rb)),
];
let mut rows = Vec::new();
for (name, result, (cm, ck, ca, cb)) in checks {
    let posterior = result.ok_or("Missing posterior")?;
    let (m, kappa, a, b) = posterior.parameters().map_err(|e| e.to_string())?;
    let gap = [m - cm, kappa - ck, a - ca, b - cb]
        .iter()
        .fold(0.0_f64, |g, d| g.max(d.abs()));
    rows.push((name, m, kappa, a, b, gap));
}
let fixed4 = serde_json::json!({ "fractionDigits": 4 });
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let columns = serde_json::json!([
    { "key": "0", "label": "Request" },
    { "key": "1", "label": "Location m [Ω]", "type": "number", "format": fixed4 },
    { "key": "2", "label": "Precision multiplier κ [-]", "type": "number", "format": fixed4 },
    { "key": "3", "label": "Shape a [-]", "type": "number", "format": fixed4 },
    { "key": "4", "label": "Scale b [Ω²]", "type": "number", "format": fixed4 },
    { "key": "5", "label": "Difference from check", "type": "number", "format": sci2 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "batch" })
);
```

The two reshaped-view rows and merged `OnlineMoments` agree with the preceding posterior to rounding level (differences at most $10^{-13}$).
Frequency weight 2 matches repeated-sample updating, giving $\kappa = 16$ and $a = 7.5$.
Analytic weight 2 gives the same $\kappa = 16$ and $b = 4.455$ Ω², but $a$ depends only on observation count 8 and stays at 3.5.
Analytic weights express precision rather than increasing observation count, so posterior variance shape is unchanged.

## Summary

Binomial, Poisson, and normal observations give posteriors through updates of `BetaBinomialPrior`, `GammaPoissonPrior`, and `NormalInverseGammaPrior`, using only $O(1)$ additions per observation.
For summaries, extract distributions from `scioxide-random` with `posterior_law()` or `marginals()` and compute equal-tailed intervals with `credible_interval`.
Evaluation limits count internal special-function iterations; allow for this work when changing limits.
For improper priors (Haldane, Poisson Jeffreys, reference prior), check posterior propriety with `is_proper()` before summarizing.
Obtain future-observation distributions with `predictive`, accounting for their extra width from parameter uncertainty compared with fixed-parameter distributions.
Reference-prior credible intervals numerically match t and $\chi^2$ confidence intervals; Jeffreys intervals are narrower than exact Clopper–Pearson or Garwood bounds, so choose interval interpretation to suit your purpose.
