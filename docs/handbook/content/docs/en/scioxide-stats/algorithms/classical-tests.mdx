Hypothesis testing expresses how extreme an observed statistic is under a null hypothesis $H_0$ as a probability, to judge whether the data contradict $H_0$.
This probability (the p value) is obtained from the statistic's null distribution.
Deriving the null distribution requires assumptions such as independent observations, normality, and equal variances.
When assumptions fail, the nominal significance level $\alpha$ differs from the actual probability of rejecting $H_0$ (the actual type I error rate, called the actual rejection rate below).
This discrepancy is called calibration error.

This page explains the assumptions, statistics, null distributions, distributions selected by `Auto` in `TestCalibration`, effect sizes, and intervals of classical scioxide-stats tests (those returning `ClassicalTestResult`), and measures actual rejection rates in cells to examine calibration error.
Tests of distribution shape, normality, and variance homogeneity appear in [Distribution goodness-of-fit and variance homogeneity tests](../distribution-and-variance-tests/); contingency-table tests and multiple comparisons appear in [Contingency-table tests, multiple comparisons, and combining p values](../contingency-and-multiple-testing/).

## Test results and common settings

### Quantities in a result

Every classical test distinguishes the following quantities in its returned `ClassicalTestResult<S>`.

| Quantity | Definition | Access |
|---|---|---|
| Test statistic | A function of the sample compared with the null distribution. Each test defines its orientation (which group tends to be larger as the statistic increases) | `statistic()` |
| p value | Probability under $H_0$ of a statistic at least as extreme as observed. The alternative hypothesis determines the direction of extremeness | `p_value()` (`f64`, $[0, 1]$) |
| Effect size | Estimate of the magnitude of a population difference or association. It does not shrink as sample size increases and is reported separately from the p value | `effect()` (`Option<(ClassicalEffect, S)>`) |
| Confidence interval | Two-sided interval for the effect size. A statistical estimate, rather than a numerical enclosure | `interval()` and `confidence()` (`Some` only for tests providing an interval) |
| Null distribution used | Distribution used to compute the p value | `method()` (`ClassicalMethod`) |
| Assumed sampling design | How the test assumes observations were collected | `sample_policy()` (`TestSamplePolicy`) |

`ClassicalEffect` describes the meaning of the effect size: `MeanDifference` (difference between means, or between a mean and the null value), `Proportion` (success probability), `Quantile` (population quantile), `RateDifference` (rate difference), `Association` (correlation or association coefficient), `Superiority` (probability of superiority $P(X > Y) + P(X = Y)/2$), or `RankBiserial` (paired rank-biserial correlation $(W^+ - W^-)/(W^+ + W^-)$).
`ClassicalMethod` is the null distribution actually used: `StudentT { degrees_of_freedom }`, `Normal`, `Exact`, `PoissonE`, or `Permutation { exact, replicates }`.
Also, `retained()` returns the sample size used, `omitted()` the number of observations omitted for missingness or other reasons, `omitted_null_mass()` the omitted null probability from truncating a sum (only the Poisson E test returns a nonzero value), and `missing_policy()` and `non_finite_policy()` the missing-data and nonfinite-value policies applied to the input.
`into_parts()` decomposes these into a single tuple in the order above.

### Sampling design

`TestSamplePolicy` is an enum recording the sampling design assumed by the test.
Variants are `Independent` (one independent sample), `IndependentGroups` (two independent groups), `Paired` (independent rows of paired observations), `Blocks` (independent complete blocks with repeated treatments), `Counts` (event counts and their trial counts or exposures), and `Summary` (summaries of means, unbiased variances, and sample sizes).
The design is a test assumption; scioxide-stats does not verify that the data were collected under that design.
For example, applying `t_test_independent` to paired data still returns `IndependentGroups` from the result's `sample_policy()`, and its p value ignores the correlation within pairs.

### One-shot calls and detailed forms

Each test has a one-shot function accepting just samples (such as `t_test_independent(&x, &y)`) and a detailed form `_with_options` accepting settings last ([Call forms](oxref:stats-execution-forms)).
The one-shot function performs the same computation as the detailed form with default settings.
The settings accepted by detailed forms of classical tests fall into three categories.

- Detailed forms accepting only `ClassicalOptions` are `t_test_one_sample_with_options`, `t_test_paired_with_options`, `mann_whitney_test_with_options`, `rank_sum_test_with_options`, `bws_test_with_options`, `page_trend_test_with_options`, `pearson_test_with_options`, `point_biserial_test_with_options`, `spearman_test_with_options`, `chatterjee_test_with_options`, `somers_test_with_options`, `somers_contingency_test_with_options`, `binomial_test_with_options`, `quantile_test_with_options`, and `poisson_means_test_with_options`.
  Only the value of `ClassicalOptions` differs from the one-shot call; it controls the alternative hypothesis, calibration, interval confidence level, exact-computation limit, workspace limit, and continuity correction.
- Detailed forms accepting a method choice and `ClassicalOptions` are `t_test_independent_with_options` and `t_test_from_summaries_with_options` (variance handling `TTestVariance`), `wilcoxon_test_with_options` (zero-difference handling `SignedRankZeros`), and `brunner_munzel_test_with_options` (reference distribution `BrunnerMunzelCalibration`).
  Even the one-shot `kendall_test` accepts the normalization type `KendallVariant`; `kendall_test_with_options` additionally accepts `ClassicalOptions`.
- `kruskal_wallis_test_with_options` and `friedman_test_with_options` accept `StatisticsOptions` rather than `ClassicalOptions`.
  They use only the workspace byte limit `max_bytes()`; the alternative and calibration cannot be selected (the only null distribution is a chi-squared approximation).

The following table summarizes the defaults of `ClassicalOptions` and the effect of changing them.
Fields are private; `with_*` creates a new settings value with the specified change.

| Setting | Default | Meaning |
|---|---|---|
| `with_alternative` (`TestAlternative`) | `TwoSided` | Alternative direction. `Less` uses the lower tail and `Greater` the upper tail as the p value; `TwoSided` uses $\min(1, 2\min(p_-, p_+))$. Chatterjee and Page tests accept only `Greater`, and their one-shot calls also use `Greater` |
| `with_calibration` (`TestCalibration`) | `Auto` | How the null distribution is obtained (next section) |
| `with_confidence` (`ConfidenceProbability`) | 0.95 | Coverage probability of the two-sided effect-size interval. Does not affect the p value |
| `with_max_work` | 100 000 | Maximum states enumerated for an exact null distribution (label assignments or dynamic-programming updates). For the Poisson E test, the maximum number of joint-probability evaluations |
| `with_max_workspace_bytes` | `usize::MAX` (unlimited) | Maximum workspace bytes for exact and permutation distributions |
| `with_continuity` (`ContinuityCorrection`) | `HalfUnit` | Continuity correction when normally approximating a discrete rank statistic. `None` disables it |

## Null distributions and calibration

### Exact null distributions, asymptotic approximations, and continuity correction

There are three ways to obtain a p value.

- An exact null distribution enumerates all label assignments that are equally probable under $H_0$ (swapping two groups, reversing paired signs, permuting pairings, or permuting ranks within blocks).
  Enumeration uses the observed ranks (midranks for ties), so it remains exact with ties.
  However, the number of states grows combinatorially with sample size.
- An asymptotic approximation computes the p value from the statistic's large-sample distribution (normal, Student's t, or chi-squared).
  Its computational cost is small, but in small samples the actual rejection rate differs from $\alpha$.
- A permutation p value constructs a statistic's distribution from samples with randomly permuted labels (`classical_permutation_test`, [Resampling](../resampling/)).
  It has Monte Carlo error but applies when exact enumeration is too large or no asymptotic distribution is available.

When normally approximating a discrete rank statistic $T$, a continuity correction reduces its distance from the center by half a unit before standardization.
For normal approximations in the Mann–Whitney and Wilcoxon signed-rank tests, scioxide-stats subtracts 0.5 from $|T - E T|$ when `ContinuityCorrection::HalfUnit` (for a one-sided test, it shifts by 0.5 toward the tail).

### How Auto selects a method

`TestCalibration` requests one of three ways to obtain the null distribution.

- `Auto` (the default) uses the exact distribution if its state count is at most `max_work`, and an asymptotic approximation otherwise.
  A test with only one method uses that method.
- `Exact` requests an exact distribution.
  It returns `ConvergenceFailure` if the state count exceeds `max_work`, or `InvalidInput` if the test has no exact distribution.
- `Asymptotic` requests the test's documented asymptotic or analytical reference distribution.
  A test without one returns `InvalidInput`.

A test that cannot use the requested method returns an error without switching methods.
Check the method actually used in the result's `method()`.
The following table summarizes state counts and sample sizes using exact distributions under the default `max_work = 100 000` ($n$ and $m$ are group sizes, $b$ is the number of blocks, and $k$ is the number of treatments).

|---|---|---|---|---|---|---|

## Student and Welch t tests

### Statistics and null distributions

The one-sample t test assumes independent observations $x_1, \dots, x_n$ from a normal distribution $N(\mu, \sigma^2)$ and tests $H_0: \mu = \mu_0$.
From the sample mean $\bar x$ and unbiased variance $s^2 = \sum_i (x_i - \bar x)^2/(n-1)$, form

$$
t = \frac{\bar x - \mu_0}{s/\sqrt{n}}, \qquad \nu = n - 1
$$

Under $H_0$, $t$ follows Student's t distribution with $\nu$ degrees of freedom exactly.
`t_test_one_sample(x, null_mean)` implements this test, with effect size $\bar x - \mu_0$ and interval $\bar x - \mu_0 \pm t_{\nu,\,1-\gamma/2}\, s/\sqrt n$ ($1 - \gamma$ is the confidence level).
The paired two-sample test `t_test_paired(x, y)` applies the one-sample test to differences $d_i = x_i - y_i$, computed with an extended exponent range to avoid overflow.

Use `t_test_independent` for the difference between the means of independent samples $X = (x_1, \dots, x_n)$ and $Y = (y_1, \dots, y_m)$.
Welch's test (`TTestVariance::Welch`, the one-shot default), which does not assume equal variances, uses the statistic

$$
t = \frac{\bar X - \bar Y}{\sqrt{s_X^2/n + s_Y^2/m}}
$$

Its degrees of freedom are given by the Welch–Satterthwaite approximation

$$
\nu = \frac{\left(s_X^2/n + s_Y^2/m\right)^2}{\dfrac{(s_X^2/n)^2}{n - 1} + \dfrac{(s_Y^2/m)^2}{m - 1}}
$$

and need not be integers.
The null distribution of Welch's t is approximate, so passing `TestCalibration::Exact` returns `InvalidInput`.
Student's test assuming a common variance (`TTestVariance::Pooled`) uses the pooled variance $s_p^2 = ((n-1)s_X^2 + (m-1)s_Y^2)/(n+m-2)$ and has an exact t null distribution with $n + m - 2$ degrees of freedom.
Use Welch's test unless equal variances can be justified.
The equal-variance test has an actual rejection rate far above $\alpha$ when the smaller group has the larger variance (cell below).

When only means, unbiased variances, and sample sizes are available, construct two `TTestSummary { mean, variance, count }` values and pass them to `t_test_from_summaries` (Welch) or `t_test_from_summaries_with_options` (selectable variance handling).
The result's `sample_policy()` is `Summary`.

Means and variances use the same extended-range accumulation as `OnlineMoments`, giving cost $O(n + m)$ and workspace $O(1)$.
A zero standard error (all observations equal) returns `NumericalInstability` (`Breakdown`); fewer than two observations in either group returns `InvalidInput`.
Standardized effect sizes such as Cohen's $d$ are not provided.
If needed, divide the effect size `effect()` by a sample standard deviation (`sample_standard_deviation`).

### Rejection rates when normality and equal variances fail

Repeatedly generate data under a true $H_0$ to examine how actual rejection rates change when the t test's assumptions of normality and equal variances fail.
The next cell repeatedly draws a sample $x$ of size $n$ and a sample $y$ of size $3n$ from populations with mean 0, and performs one-sample t tests of $\mu_0 = 0$ (two-sided and both one-sided alternatives), an equal-variance t test, and a Welch t test at $\alpha = 0.05$, for $R$ repetitions.
The standard deviation of $x$ is $\sigma_x/\sigma_y$ times that of $y$.
The proportion rejected estimates the actual rejection rate, and its 95% interval is obtained as the Clopper–Pearson interval from `binomial_test_with_options`.
The p value of the same binomial test tests the hypothesis that the actual rejection rate equals the nominal $\alpha$.
The last row is the proportion of Welch 95% intervals containing the true difference 0 (coverage), with nominal value 0.95.

For normal populations and $\sigma_x = \sigma_y$ (the default), the five tests have rejection rates from 0.040 to 0.053 and coverage is 0.9545.
The interval [0.032, 0.050] for `Greater` narrowly excludes 0.05, but if six 95% intervals were independent, at least one would miss the truth with probability $1 - 0.95^6 \approx 0.26$.
Avoiding a conclusion of miscalibration from one interval alone follows the same reasoning as [multiple comparisons](oxref:stats-multiple-comparisons-and-adjustment).
With a standard-deviation ratio of 2, the equal-variance test's rejection rate is 0.156, while Welch's remains at 0.053.
For an exponential population ($\mathrm{Exp}(1) - 1$, a right-skewed distribution with mean 0), the one-sample two-sided rejection rate is 0.095 at $n = 10$, while `Less` gives 0.125 and `Greater` gives 0.011: the one-sided rejection rates deviate in opposite directions.
In a skewed population, $\bar x$ and $s$ are positively correlated, making the distribution of $t$ left-skewed.
The two-sample Welch test with unequal group sizes also has a rejection rate of 0.076 for this population.
Increasing $n$ reduces the discrepancy through the central limit theorem, but even at $n = 60$, `Less` is 0.094 and `Greater` is 0.025; the one-sided rejection rates remain farther from nominal than the interval widths.

## Rank tests and nonparametric location tests

Replacing observations with ranks $R_i$ (midranks for ties) makes the statistic invariant under increasing transformations and caps the influence of outliers at the largest rank.
Rank tests assume only that group labels (or paired signs) are exchangeable under the null hypothesis, so they do not assume normality.
Their null hypotheses instead concern whole distributions, such as “the two distributions are equal,” and differ in meaning from a test of mean differences.

### Mann–Whitney and Wilcoxon rank-sum tests

Use `mann_whitney_test` to compare two independent groups.
Let $R_1$ be the sum of the midranks of $x$ in the combined sample, and use the statistic

$$
U = R_1 - \frac{n(n+1)}{2}
$$


Larger $U$ indicates a tendency for larger $x$; the effect size $U/(nm)$ estimates the probability of superiority $P(X > Y) + P(X = Y)/2$ (`ClassicalEffect::Superiority`).
The null hypothesis is that both groups follow the same continuous distribution, making all $\binom{n+m}{n}$ label assignments equally likely.
`Auto` enumerates all assignments when their number is at most `max_work`; otherwise it uses a normal approximation with continuity correction and the tie-corrected variance

$$
\operatorname{Var} U = \frac{nm}{(n+m)(n+m-1)} \sum_{i=1}^{n+m}\left(R_i - \frac{n+m+1}{2}\right)^2
$$


Ranking costs $O(N \log N)$, with $N = n + m$.

`rank_sum_test` uses $z$, the same $U$ standardized by the variance $nm(n+m+1)/12$ without tie or continuity corrections, and computes p values only by normal approximation.
It is not an alias for `mann_whitney_test`: it returns `InvalidInput` for tied samples and also rejects `Exact`.
Use `mann_whitney_test` for tied data or exact p values.

The Hodges–Lehmann location-shift estimator and its interval are not provided.
To estimate a location shift, form all pairwise differences $x_i - y_j$ and compute their median with `median`; obtain an interval through [resampling](../resampling/).

### Wilcoxon signed-rank test

Use `wilcoxon_test(differences)` to test the null hypothesis that paired differences $d_i$ follow a distribution symmetric about 0.
Assign midranks to absolute differences; let $W^+$ be the sum of positive-difference ranks and $W^-$ the sum of negative-difference ranks.
The statistic is $\min(W^+, W^-)$ for two-sided tests and $W^+$ for one-sided tests; the effect size is the rank-biserial correlation $(W^+ - W^-)/(W^+ + W^-)$ (`ClassicalEffect::RankBiserial`).
Under the null, each difference independently has either sign with probability 1/2, so the exact distribution is obtained by counting subset sums weighted by doubled ranks (dynamic programming), remaining exact with ties.
Let $K$ be the sum of doubled ranks ($n(n+1)$ without ties); this computation uses $O(Kn)$ time and $O(K)$ workspace.
`Auto` uses the exact distribution when $Kn$ is at most `max_work`, and a continuity-corrected normal approximation otherwise.

Select how zero differences are handled with `SignedRankZeros`.
`Discard` (the one-shot default, Wilcoxon method) removes zeros before ranking.
`Pratt` ranks the zeros too, then excludes their ranks from both sums.
`Split` adds half the sum of zero ranks to each of $W^+$ and $W^-$.
If all differences are 0, the p value is 1.
Select other handling with `wilcoxon_test_with_options(differences, zeros, options)`.

### Brunner–Munzel and BWS tests

The Mann–Whitney null hypothesis equates the group distributions, so differences in shape or spread can push the rejection rate above $\alpha$ even when the probability of superiority is 1/2.
`brunner_munzel_test` uses only $p = P(X > Y) + P(X = Y)/2 = 1/2$ as its null hypothesis, allowing differences in shape and spread (the nonparametric Behrens–Fisher problem).
Its statistic is $(\hat p - 1/2)/\hat\sigma$, where $\hat\sigma$ is the standard error computed from placements.
Select the reference distribution with `BrunnerMunzelCalibration`: `Student` (the one-shot default) uses a t distribution with Satterthwaite-type degrees of freedom, while `Normal` uses the standard normal distribution.
An exact label-assignment distribution does not match this null hypothesis, so `Exact` returns `InvalidInput`.
It also returns `InvalidInput` when the two groups' placements have no overlap and $\hat\sigma^2 = 0$.

`bws_test` uses the Baumgartner–Weiß–Schindler statistic $B$, summing squared differences between each group's ranks and their expected positions, with greater weight in the tails.
It responds to both location and shape differences.
It uses no asymptotic distribution and computes only exact p values by enumerating $\binom{n+m}{n}$ assignments, so `Asymptotic` returns `InvalidInput`, and even `Auto` returns an error when the state count exceeds `max_work`.
For large samples, prepare ranks with `BwsPlan` and obtain a Monte Carlo permutation p value ([Resampling](../resampling/)).

The median test (`median_test`) and scale rank tests (`mood_scale_test`, `ansari_bradley_test`) appear in [Distribution goodness-of-fit and variance homogeneity tests](../distribution-and-variance-tests/).

## Correlation and association tests

These test independence of paired observations $(x_i, y_i)$ by testing whether a correlation coefficient is 0.
Different coefficients detect different forms of association.

- `pearson_test` uses the sample correlation $r$ as its statistic and computes the p value from the fact that $t = r\sqrt{(n-2)/(1-r^2)}$ follows a t distribution with $n - 2$ degrees of freedom exactly under bivariate normality.
  The result's `method()` returns `Exact`.
  For $n > 3$ it includes the approximate Fisher z-transform interval $\tanh(\operatorname{atanh} r \pm z_{1-\gamma/2}/\sqrt{n-3})$.
  If either sample is constant, it returns `InvalidInput`.
- `point_biserial_test(binary, values)` is the Pearson correlation between a 0/1 variable and a continuous variable (point-biserial correlation); it returns `InvalidInput` if `binary` contains anything other than 0 and 1.
- `spearman_test` uses the Pearson correlation $\rho$ of midranks as its statistic.
  `Auto` enumerates every pairing when $n!$ is at most `max_work`; otherwise it applies the same t approximation as Pearson to $\rho$.
- `kendall_test(x, y, variant)` counts the difference $S$ between concordant and discordant pairs ($O(n \log n)$), normalizing with `KendallVariant::TauB` ($\tau_b = S/\sqrt{(n_0 - n_1)(n_0 - n_2)}$, suitable for square contingency tables) or `TauC` (Stuart's $\tau_c = 2S/(n^2 (m-1)/m)$, suitable for rectangular tables).
  `Auto` enumerates when $n!$ is within the limit; otherwise it uses a normal approximation based on the tie-corrected variance of $S$.
- `weighted_kendall_tau(x, y, importance, combination)` returns a pair-weighted Kendall coefficient (Vigna's weighted $\tau$), without computing a null distribution.
  Select the weight combination with `Additive` ($w_i + w_j$) or `Multiplicative` ($w_i w_j$) in `KendallWeightCombination`; `importance = None` uses hyperbolic weights $1/(r+1)$, giving higher ranks greater weight.
- `chatterjee_test` is Chatterjee's $\xi_n$, approaching 1 when $y$ is a measurable function of $x$ and 0 under independence.
  It detects nonmonotone associations (such as $y = x^2$), but $\xi_n$ increases only in the positive direction, so only the alternative `Greater` is accepted.
  `Auto` enumerates when $n!$ is within the limit; otherwise it uses a normal approximation with a variance valid even for ties in $y$.
- `somers_test` uses Somers' $D(Y|X) = S/(n(n-1)/2 - T_x)$ with predictor $x$ and response $y$ as its statistic, computing p values only by a normal approximation with the Brown–Benedetti asymptotic variance ($O(n^2)$).
  `somers_contingency_test(table)` computes the same statistic directly from an ordinal contingency table (rows are predictors, columns responses), without expanding observations ($O((RC)^2)$).
  Both reject `Exact`.

Correlation-test null hypotheses concern independence (zero correlation for Pearson); only Pearson's test returns an interval for the correlation magnitude.
For intervals for Spearman or Kendall coefficients, use the bootstrap in [Resampling](../resampling/).

## Count and quantile tests

- `binomial_test(successes, trials, null_probability)` is an exact binomial test of success probability $\pi = \pi_0$.
  A one-sided p value is a binomial tail probability; the two-sided p value sums the probabilities of all outcomes whose probability is at most that of the observed $k$ (using relative tolerance $64\varepsilon$ for comparisons).
  The effect size is $k/n$, the interval is Clopper–Pearson, and `Asymptotic` is `InvalidInput`.
- `quantile_test(x, null_quantile, p)` is an exact test that the population $p$ quantile equals `null_quantile`.
  It compares the count $T_1$ of observations below `null_quantile` and count $T_2$ at or below it with the binomial distribution $B(n, p)$; `Less` uses $T_1$, `Greater` uses $T_2$, and two-sided uses the smaller tail.
  The effect size is the order statistic $x_{(\lceil np \rceil)}$, and interval endpoints are also order statistics.
  When no pair of order statistics achieves the requested coverage probability, the interval is `None`.
- `poisson_means_test(counts, exposures, difference)` uses event counts $k_1, k_2$ over exposures $t_1, t_2$ to test the rate difference $\lambda_1 - \lambda_2 = d$ with the Krishnamoorthy–Thomson E test.
  It sums joint Poisson probabilities of outcomes more extreme than observed at the common rate estimated under the null, so it is not an exact test (`ClassicalMethod::PoissonE`).
  The sum is restricted to the grid between each marginal's $10^{-13}$ and $1 - 10^{-13}$ quantiles; the omitted probability (at most about $4 \times 10^{-13}$) is returned through `omitted_null_mass()`.
  If the grid size exceeds `max_work`, it returns `ConvergenceFailure`, and `Exact` returns `InvalidInput`.

When only confidence limits for a proportion or rate are needed, use `binomial_confidence_limits` and related APIs in [Distribution fitting and confidence limits](../distribution-fitting-and-confidence-limits/).

## Block designs and comparisons of three or more groups

- `page_trend_test(data, treatment_order)` tests the ordered alternative that treatment effects increase in the order `treatment_order` in a randomized complete block design (each treatment is observed once per block).
  Rows of `data` are blocks and columns are treatments; with $R_j$ the treatment sums of within-block midranks, the statistic is $L = \sum_j j R_j$.
  `Auto` enumerates the $(k!)^b$ within-block permutations if their count is within the limit, and otherwise uses a tie-corrected normal approximation.
  It accepts only the alternative `Greater`.
- `friedman_test(samples)` tests equality of the effects of $k$ treatments in the same randomized complete block design.
  It ranks within each block and computes the tie-corrected $Q$ from treatment rank sums $R_j$, using the upper tail of a chi-squared distribution with $k - 1$ degrees of freedom as the p value.
  Fewer than two blocks or three treatments returns `InvalidInput`.
- `kruskal_wallis_test(groups)` tests whether $k$ independent groups share a distribution using the tie-corrected $H$ formed from rank sums of all observations.
  The p value uses a chi-squared approximation with $k - 1$ degrees of freedom and is not exact in small samples.
  For an exact p value, use $H$ as the statistic in a permutation test.

Friedman and Kruskal–Wallis return `GroupTest` (statistic, p value, degrees of freedom, and `GroupTestMethod`); their detailed forms can change only the workspace limit `StatisticsOptions::max_bytes()`.
One-way ANOVA for normal populations (`GroupTestMethod::Anova` and `Welch` in `PreparedGroups::anova`, `PreparedGroups::alexander_govern`) and post-hoc comparisons (`PostHocComparison`) appear in [Regression, ANOVA, and GLMs](../regression-anova-and-glm/).

## Batch execution and permutation p values

To apply the same test to many rows, pass the test kind `ClassicalBatchTest`, matrix view `BatchView`, output storage, and `ClassicalBatchWorkspace` to `classical_tests_into`.
Each row's result is `Option<ClassicalTestResult>`, and the count of observations removed by the missing-data policy (such as `MissingPolicy::Skip`) is in `omitted()`.
Adjusting for multiplicity after obtaining many p values is covered in [Contingency-table tests, multiple comparisons, and combining p values](../contingency-and-multiple-testing/).

To replace an existing test's p value with a permutation p value, pass its result, a function computing the same statistic from permuted indices, and `ResamplingPlan` to `classical_permutation_test`.
The result's `ClassicalPermutationResult` contains a `ClassicalMethod::Permutation` test result only when permutation execution finishes.
The borrowed form `classical_permutation_test_into` and construction of resampling plans appear in [Resampling](../resampling/).

```rust
    metadata = serde_json::json!({ "id": "p-values" })
);

let names = [
    "Welch t test",
    "Mann–Whitney test",
    "Brunner–Munzel test",
];
let mut rows = Vec::new();
for (name, result) in names.into_iter().zip(run(outlier_val)) {
    let r = result.map_err(|e| e.to_string())?;
    let (kind, effect) = r.effect().ok_or("Effect size is absent")?;
    let interval = r.interval();
    rows.push((
        name,
        r.statistic(),
        r.p_value(),
        format!("{kind:?}"),
        effect,
        interval.map(|i| i.lower()),
        interval.map(|i| i.upper()),
    ));
}
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let f4 = serde_json::json!({ "fractionDigits": 4 });
let columns = serde_json::json!([
    { "key": "0", "label": "Test" },
    { "key": "1", "label": "Statistic [-]", "type": "number", "format": f4 },
    { "key": "2", "label": "p value [-]", "type": "number", "format": sci3 },
    { "key": "3", "label": "Effect-size kind" },
    { "key": "4", "label": "Effect size [-]", "type": "number", "format": f4 },
    { "key": "5", "label": "Lower 95% interval endpoint [-]", "type": "number", "format": f4, "nullText": "None" },
    { "key": "6", "label": "Upper 95% interval endpoint [-]", "type": "number", "format": f4, "nullText": "None" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "selected" })

```

At $x_{\text{out}} = 0$, where the outlier is within the first group's value range, all three tests detect the difference with p values below $\alpha = 0.05$ (Welch 0.0014, Mann–Whitney 0.0035, Brunner–Munzel 0.00006).
As the outlier grows, the first group's unbiased variance increases proportionally to its square, enlarging the denominator of Welch's t.
At the same time the mean difference shrinks, becoming almost 0 near $x_{\text{out}} = 17$ and reversing sign beyond it.
Consequently, the t-test p value is 0.043 at $x_{\text{out}} = 4$ and 0.089 at 5, crossing 0.05, then reaches 0.985 at 17 and misses the true difference (a type II error).
For Mann–Whitney, once the outlier exceeds the second group's maximum (3.23), it is counted as the largest rank, 21, regardless of magnitude, so the statistic and p value (0.022) stay unchanged for $x_{\text{out}} \ge 4$.
Brunner–Munzel also uses only ranks (placements), so its p value likewise stays at 0.012.
The rank tests' effect size (probability of superiority 0.2) describes the groups' degree of overlap even when an outlier changes the mean difference.

## Summary

Classical test results separately return the statistic, p value, effect size, interval, null distribution used, and assumed sampling design; read `method()` and `effect()` alongside the p value.
`TestCalibration::Auto` enumerates when the exact null distribution's state count is at most `max_work` and switches to an asymptotic approximation otherwise, but tests without approximations, such as BWS, return errors.
When normality and equal variances fail, actual t-test rejection rates depart from the nominal $\alpha$: the equal-variance test overrejects when the smaller group has the larger variance, and one-sided rejection rates deviate in opposite directions for skewed populations.
Rank-test p values are stable against outliers, but their null hypotheses concern equal distributions (probability of superiority 1/2 for Brunner–Munzel), making a different claim from a mean-difference test.
