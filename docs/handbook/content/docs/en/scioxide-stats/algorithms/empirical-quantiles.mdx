The inverse $Q(p) = F^{-1}(p)$ of a population distribution function $F$ is uniquely defined, but quantiles constructed from finite samples have multiple definitions.
Statistical software uses different defaults, and these definitions give different results for small samples.
This page explains empirical distribution functions, Hyndman and Fan's nine quantile definitions, selection costs, tie handling, and expectiles.
It explains why scioxide-stats records the definition in its results and experimentally compares bias and spread for all nine definitions.

## Empirical distribution function

The **empirical distribution function** (empirical CDF) of a sample $X_1, \dots, X_n$ is a right-continuous step function jumping by $1/n$ at each observation.

$$
F_n(x) = \frac{1}{n} \sum_{i=1}^n \mathbf 1\{X_i \le x\}
$$

For independent identically distributed samples, $\sup_x |F_n(x) - F(x)| \to 0$ holds almost surely as $n \to \infty$ (the Glivenko–Cantelli theorem).
The Dvoretzky–Kiefer–Wolfowitz inequality $P(\sup_x |F_n(x) - F(x)| > \varepsilon) \le 2e^{-2n\varepsilon^2}$ describes the convergence rate, with deviations of approximate order $1/\sqrt n$.

The quantile estimator $\hat Q_n(p)$ has the following asymptotic normality when $F$ has a positive continuous density $f$ at $Q(p)$.

$$
\sqrt n \bigl(\hat Q_n(p) - Q(p)\bigr) \xrightarrow{d} \mathcal N\!\left(0,\; \frac{p(1-p)}{f(Q(p))^2}\right)
$$

In low-density tails ($p$ near 0 or 1), variance increases, making quantile estimates less stable at the same sample size.
This limit is shared by all nine definitions; their differences appear as bias of order $O(1/n)$.

`EmpiricalDistribution::new(values, weights)` copies and sorts the sample in $O(n \log n)$, rejecting empty samples with `InvalidInput` and nonfinite values with `NonFinite`.
`weights` is `Unweighted`, `Weights::<_, Frequency>` (integer counts), or `Weights::<_, Mass>` (relative masses); zero-weight observations are ignored in every query.
`cdf(x)` returns $P(X \le x)$ in $O(\log n)$ time.
`survival(x)` computes $P(X > x)$ by directly summing upper-tail weights instead of subtracting a cumulative probability from 1, preserving relative accuracy for small tail probabilities.
NaN queries return `InvalidInput`; infinite queries return the respective limiting probabilities 0 or 1.
`estimated_cdf(x, rule)` returns a distribution-function estimate corresponding to the quantile definition.
For types 4–9, it inverts the piecewise-linear quantile function, giving plotting positions of the form `(h − α)/(n + 1 − α − β)`.
`total_weight()` returns total weight $W$ (count, mass sum, or frequency sum).

Use `cdf` to evaluate many query points jointly for independent samples arranged as array batches.
`cdf(view, queries, method)` uses defaults; `cdf_with_options` accepts `StatisticsOptions` (missing-data and nonfinite-value policies and byte limit).
Select `method` from `CdfMethod::Empirical` ($P(X \le x)$), `Survival` ($P(X > x)$), or `Estimated(rule)` (the same estimate as `estimated_cdf`).
Each batch is sorted in $O(n \log n)$ and queries use binary search.
Mass weights traverse sorted queries and samples together in one pass each.
Results are arranged in `output[b·m + j]` order (batch $b$, query point $j$, and number of query points $m$).
For repeated queries of the same shape, request `CdfRequirements` with `CdfWorkspace::workspace_requirements(view, m, options, context)`, construct workspace with `CdfWorkspace::workspace(&req)`, and reuse it with `cdf_into` to avoid allocations after the first call.
Frequency weights give the same results as replicating observations without expanding them; mass weights support only `Empirical`, `Survival`, and type-1 `Estimated`.

## Hyndman and Fan's nine definitions

Let $X_{(1)} \le \dots \le X_{(n)}$ denote ascending order statistics.
Hyndman and Fan (1996) express quantiles in the following form using the integer part $j = \lfloor h \rfloor$ and fraction $g = h - j$ of a one-based position $h = np + m$.

$$
\hat Q(p) = (1 - \gamma) X_{(j)} + \gamma X_{(j+1)}
$$

Indices below 1 use $X_{(1)}$, and those above $n$ use $X_{(n)}$.
Types 1–3 are discontinuous in $p$, returning observations or averages of adjacent observations.
Types 4–9 linearly interpolate adjacent order statistics with $\gamma = g$.
The last table column gives the probability position $p_k$ (plotting position) for which $\hat Q(p_k) = X_{(k)}$.

| Type | `QuantileMethod` | $m$ | $\gamma$ | Position $p_k$ |
|---|---|---|---|---|
| 1 | `NearestRank` | $0$ | 1 for $g > 0$, 0 for $g = 0$ | Inverse ECDF |
| 2 | `AveragedInverseCdf` | $0$ | 1 for $g > 0$, 1/2 for $g = 0$ | Average adjacent observations at jumps |
| 3 | `ClosestObservation` | $-1/2$ | 0 if $g = 0$ and $j$ is even, 1 otherwise | Nearest observation (even rank at equal distances) |
| 4 | `InterpolatedInverseCdf` | $0$ | $g$ | $k/n$ |
| 5 | `Hazen` | $1/2$ | $g$ | $(k - 1/2)/n$ |
| 6 | `Weibull` | $p$ | $g$ | $k/(n+1)$ |
| 7 | `Linear` | $1 - p$ | $g$ | $(k-1)/(n-1)$ |
| 8 | `MedianUnbiased` | $(p+1)/3$ | $g$ | $(k - 1/3)/(n + 1/3)$ |
| 9 | `NormalUnbiased` | $p/4 + 3/8$ | $g$ | $(k - 3/8)/(n + 1/4)$ |

Type-6 positions $k/(n+1)$ equal the expectation of $F(X_{(k)})$ for continuous distributions.
Type 8 makes the median of $\hat Q(p)$ approximately $Q(p)$ regardless of distribution shape (median unbiasedness); Hyndman and Fan recommend it.
Type 9 makes the expectation of $\hat Q(p)$ approximately $Q(p)$ for normal populations (mean unbiasedness).
The [Bias and spread of the nine definitions](#bias-and-spread-of-the-nine-definitions) section checks these properties using normal samples.

scioxide-stats shares a position kernel across all nine definitions, treating f64 $p$ as an exact binary rational when multiplying to obtain $j$, and rounding only the fraction $g$.
Rounding therefore does not change the decision whether $np$ is an integer.
For every definition, $p = 0$ returns the minimum and $p = 1$ the maximum.
Construct probabilities with `QuantileProbability::new(p)`; values outside $[0, 1]$ are rejected with `InvalidInput` and nonfinite values with `NonFinite`.

Pass the definition through `QuantileRule`.
`QuantileRule::new(method)` selects one of the nine definitions and can only be constructed for weight types implementing trait `InterpolatedQuantiles` (`Unweighted` and `Frequency`).
Frequency weights apply the definition to a sample repeating each observation by its count, without constructing that sample.
Mass weights have no sample size $n$, leaving the interpolation position $h = np + m$ undefined.
Masses therefore support only `QuantileRule::inverse_ecdf()` (the left-continuous inverse weighted ECDF, corresponding to type 1), and `QuantileRule::<Mass>::new` cannot compile.
The result `QuantileResult` contains value `value`, probability `probability`, and definition `convention`.
`QuantileConvention` distinguishes unweighted `Unweighted(QuantileMethod)`, mass `MassInverseEcdf`, and frequency `Frequency(QuantileMethod)`, allowing type numbers to be matched when comparing with other software.

## Computing quantiles by selection

One quantile does not require sorting the entire sample.
`quantile_in_place(samples, p, rule)` rearranges a caller-owned scratch array to select a quantile.
Trait `SelectionSamples` determines the accepted array forms; the algorithm and cost depend on that form.

| Scratch array | Definitions | Algorithm | Cost |
|---|---|---|---|
| `&mut [S]` (unweighted) | All nine | Rust's `select_nth_unstable_by` selects position $j$; when interpolation is needed, the lower partition's maximum supplies the neighboring order statistic | Average $O(n)$ |
| `Weights<&mut [(S, S)], Mass>` (observation-mass pairs) | Inverse ECDF | Deterministic three-way introselect | Worst-case $O(n)$ |
| `Weights<&mut [(S, u64)], Frequency>` (observation-frequency pairs) | All nine | Sorting | $O(n \log n)$ |

Pairs move as units.
No form allocates.
The array is unchanged until validation and index precomputation finish, leaving the original input on failure.
On success, the array is a permutation of the input.
Masses are accumulated internally with exact integer arithmetic so rounding cannot alter comparisons with target mass $pW$.
For repeated queries of one sample, use `EmpiricalDistribution`, sorting once with $O(n \log n)$ and answering unweighted quantile queries in $O(1)$.

`statistic(values, Unweighted, Statistic::quantile(p, rule))` and `Statistic::iqr(method)` (interquartile range $Q(3/4) - Q(1/4)$) use the same selection in internal workspace without sorting the whole sample.
The fraction of observations at or below a value (percentile-of-score) is counted in one pass.
Mode and tie corrections sort to find runs of equal values.

## Ties and ranking

`rank_slice(values, method)` assigns one-based ranks to observations.
Select equal-value (tie) handling with `RankMethod`.
For sample $[1, 2, 2, 4]$, the results are as follows.

| `RankMethod` | Ranks | Example use |
|---|---|---|
| `Average` | $[1, 2.5, 2.5, 4]$ | Usual rank-test convention (Wilcoxon, Spearman) |
| `Minimum` | $[1, 2, 2, 4]$ | Competition ranking |
| `Maximum` | $[1, 3, 3, 4]$ | Maximum rank occupied by the tied group |
| `Dense` | $[1, 2, 2, 3]$ | Consecutive distinct-value indices |
| `Ordinal` | $[1, 2, 3, 4]$ | Break ties in input order |

Ranks are returned as `Rank`, retaining even half-integer average ranks exactly as integer pairs (lower and upper bounds).
Conversion `to_f64` to f64 returns `Err` when exact representation fails (integers above $2^{53}$ or half-integers at least $2^{52}$).
Forms writing preallocated outputs include `rank_slice_into` for one slice and `rank_axes_into` for ranking each batch of `BatchView`.
Both reuse `StatisticsWorkspace`, avoiding allocations for repeated ranking.
In `rank_axes_into`, observations omitted by missing-data or nonfinite-value policies become `None` and are not counted in ranks.

Compute the percentile of score $s$ with `Statistic::percentile_of_score(s, kind)`.
Let $L$ count observations below $s$ and $U$ those at or below $s$; `PercentileKind` selects $c$ on the percentage scale $100\,c/n$ as follows.
`Strict` uses $c = L$, `Weak` uses $c = U$, and `Mean` uses $c = (L + U)/2$.
`Rank` uses the average rank $c = (L + U + 1)/2$ of equal observations if $s$ is present in the sample, and $c = L$ otherwise.

For tie-group sizes $t_g$, rank variance is multiplied by the following reduction factor.

$$
T = 1 - \frac{\sum_g (t_g^3 - t_g)}{n^3 - n}
$$

Obtain this factor with `Statistic::tie_correction()` and use it to correct rank-test normal-approximation variances.

## Expectiles

A quantile $Q(p)$ minimizes the asymmetric absolute loss $\sum_i |p - \mathbf 1\{x_i \le q\}|\,|x_i - q|$.
The minimizer after replacing absolute loss with squared loss is an **expectile** (Newey and Powell, 1987).

$$
e_\tau = \arg\min_e \sum_{i=1}^n \bigl|\tau - \mathbf 1\{x_i \le e\}\bigr|\,(x_i - e)^2
$$

At the minimum, $(1-\tau)\sum_{x_i \le e}(e - x_i) = \tau \sum_{x_i > e}(x_i - e)$ balances; at $\tau = 1/2$ it gives the arithmetic mean.
Unlike quantiles, expectiles respond to the magnitudes of tail observations themselves.

`Statistic::expectile(p)` is defined for unweighted (`Unweighted`) and mass-weighted (`Mass`) samples (trait `ExpectileWeights`).
Subtracting the right side of the balance equation from the left gives a function strictly decreasing in $e$ and linear between adjacent observations.
scioxide-stats uses median selection to bisect order statistics and narrow a root bracket, determining the function's sign exactly at every pivot.
It solves the linear equation in the final interval in closed form, requiring no iterative stopping tolerance.
Average cost is $O(n)$, without sorting the sample.
At $p = 0$ and $p = 1$ it returns the minimum and maximum positive-weight observations.
The result `ExpectileResult` contains the value and `relative_balance_residual`, the balance residual at the rounded result divided by weighted absolute deviations.
This residual helps check the computation and is not an error bound.

## Comparing two conventions

For fixed sample $[1, 2, 4, 10]$, vary cumulative probability $p$ from 0 to 1 and plot type-1 (inverse ECDF) and type-7 (linear interpolation) quantiles computed with `EmpiricalDistribution::quantile`.
Both are also compared with direct position-formula evaluations (an independent f64-arithmetic check), reporting the maximum difference.
The table shows all nine definitions at the selected $p$.

At the default $p = 0.75$ (third quartile), $np = 3$ is exactly an integer, so types 1, 3, and 4 return observation 4; type 2 returns the mean of both sides of the jump, 7.
Interpolating types range from 5.5 (type 7) to 8.5 (type 6) because their position constants $m$ differ; type 5 gives 7, type 8 gives 7.5, and type 9 gives 7.375.
With four observations, the third quartile ranges from 4 to 8.5 depending on its definition.
At $p = 0.6$, $np = 2.4$ is noninteger, so types 1 and 2 both return the third observation 4, while type 3 returns the second observation 2.
At $p = 0$ and $p = 1$, all nine definitions return minimum 1 and maximum 10.
Types 1 and 7 agree with the position-formula check within $1.8 \times 10^{-15}$ at all 201 points; differences are rounding effects from interpolation formulas written differently.

## Bias and spread of the nine definitions

For small samples, the nine definitions give systematically different values at the same $p$.
Which definition is “correct” depends on the desired estimator properties.
The choice differs between wanting the mean close to truth (mean unbiasedness) and wanting probability 1/2 of falling below truth (median unbiasedness).

The next cell generates standard-normal samples of size $n$ for $R = 4000$ repetitions and computes $\hat Q(p)$ by all nine definitions for each sample.
The true quantile $Q(p) = \Phi^{-1}(p)$ is obtained as the two-sided critical value $\Phi^{-1}((1 + (2p-1))/2)$ of `ConfidenceProbability::new(2p − 1)`.
The table reports bias $E[\hat Q] - Q$ and its Monte Carlo standard error, the estimate of $P(\hat Q < Q)$, and standard deviation.
The last column gives the standard deviation $\sqrt{p(1-p)/n}\,/\,\varphi(Q(p))$ from the asymptotic variance above ($\varphi$ is the standard-normal density).

```rust
//| id: stats-quantile-bias
//| ref: stats-quantile-bias
//| title: "Compare bias and spread of nine quantile definitions on normal samples"
//| run: button
//| crates: [scioxide-stats, scioxide-random, scioxide-core]
//| inputs:
//|   sample_size: {"type":"range","label":"Sample size n","description":"Number of normal observations drawn per repetition.","min":5,"max":50,"step":1,"value":10}
//|   probability: {"type":"range","label":"Cumulative probability p [-]","description":"Probability of the estimated quantile.","min":0.55,"max":0.99,"step":0.01,"value":0.9}
//|   sampling_seed: {"type":"integer","label":"Random seed","min":0,"max":100000,"value":11}
//| cases:
//|   - {"id":"large-sample","label":"n = 50","description":"Bias decreases and differences between definitions shrink.","inputs":{"sample_size":50}}
//|   - {"id":"extreme-tail","label":"p = 0.99","description":"Position h exceeds n, so seven definitions return the maximum. Even the maximum is often below Q(0.99).","inputs":{"probability":0.99}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"bias","path":"/rows/0/6","approx":{"value":0.5405654216790318,"rtol":1e-9}}
//|       - {"artifact":"bias","path":"/rows/6/2","approx":{"value":-0.236,"atol":0.003}}
//|       - {"artifact":"bias","path":"/rows/6/4","approx":{"value":0.7045,"atol":0.005}}
//|       - {"artifact":"bias","path":"/rows/7/4","approx":{"value":0.478,"atol":0.005}}
//|       - {"artifact":"bias","path":"/rows/8/2","approx":{"value":0.031,"atol":0.003}}
//|   - case: large-sample
//|     expect:
//|       - {"artifact":"bias","path":"/rows/8/2","range":{"min":-0.008,"max":0.012}}
//|       - {"artifact":"bias","path":"/rows/6/2","approx":{"value":-0.051,"atol":0.003}}
//|   - case: extreme-tail
//|     expect:
//|       - {"artifact":"bias","path":"/rows/0/2","approx":{"value":-0.801,"atol":0.003}}
//|       - {"artifact":"bias","path":"/rows/8/4","approx":{"value":0.906,"atol":0.005}}
use scioxide_core::RealScalar;
use scioxide_random::{Distribution, Normal, SeedableRng, SplitMix64};
use scioxide_stats::{
    ConfidenceProbability, EmpiricalDistribution, QuantileMethod, QuantileProbability,
    QuantileRule, Unweighted,
};

const REPLICATES: usize = 4000;
let methods = [
    QuantileMethod::NearestRank,
    QuantileMethod::AveragedInverseCdf,
    QuantileMethod::ClosestObservation,
    QuantileMethod::InterpolatedInverseCdf,
    QuantileMethod::Hazen,
    QuantileMethod::Weibull,
    QuantileMethod::Linear,
    QuantileMethod::MedianUnbiased,
    QuantileMethod::NormalUnbiased,
];
let n = sample_size as usize;
let p = QuantileProbability::new(probability).map_err(|e| e.to_string())?;
// The true quantile Φ⁻¹(p) equals the two-sided normal critical value at probability 2p − 1.
let truth: f64 = ConfidenceProbability::new(2.0 * probability - 1.0)
    .map_err(|e| e.to_string())?
    .normal_critical_value()
    .map_err(|e| e.to_string())?;
let density =
    RealScalar::exp(-0.5 * truth * truth) / RealScalar::sqrt(2.0 * core::f64::consts::PI);
let asymptotic_sd = RealScalar::sqrt(probability * (1.0 - probability) / n as f64) / density;

let standard = Normal::new(0.0_f64, 1.0).map_err(|e| e.to_string())?;
let mut rng = SplitMix64::from_seed(sampling_seed as u64);
let mut sums = [0.0_f64; 9];
let mut squares = [0.0_f64; 9];
let mut below = [0_usize; 9];
let mut sample = vec![0.0_f64; n];
for _ in 0..REPLICATES {
    for x in sample.iter_mut() {
        *x = standard.sample(&mut rng).map_err(|e| e.to_string())?;
    }
    // After one sort, each of the nine definitions answers queries in O(1).
    let law = EmpiricalDistribution::new(&sample, Unweighted).map_err(|e| e.to_string())?;
    for (j, &method) in methods.iter().enumerate() {
        let q = law
            .quantile(p, QuantileRule::new(method))
            .map_err(|e| e.to_string())?
            .value();
        sums[j] += q - truth;
        squares[j] += (q - truth) * (q - truth);
        below[j] += usize::from(q < truth);
    }
}
let r = REPLICATES as f64;
let mut rows = Vec::new();
for (j, method) in methods.iter().enumerate() {
    let bias = sums[j] / r;
    let variance = (squares[j] / r - bias * bias) * r / (r - 1.0);
    let sd = RealScalar::sqrt(variance);
    rows.push((
        j as u32 + 1,
        format!("{method:?}"),
        bias,
        sd / RealScalar::sqrt(r),
        below[j] as f64 / r,
        sd,
        asymptotic_sd,
    ));
}
let fixed3 = serde_json::json!({ "fractionDigits": 3 });
let fixed4 = serde_json::json!({ "fractionDigits": 4 });
let columns = serde_json::json!([
    { "key": "0", "label": "Type", "type": "integer" },
    { "key": "1", "label": "QuantileMethod", "type": "string" },
    { "key": "2", "label": "Bias E[Q̂] − Q [-]", "type": "number", "format": fixed4 },
    { "key": "3", "label": "Bias standard error [-]", "type": "number", "format": fixed4 },
```

At the defaults $n = 10$ and $p = 0.9$, the true quantile is $Q(0.9) = 1.2816$.
Type 7 has bias $-0.236$ (standard error 0.007) and $P(\hat Q < Q) = 0.705$, often falling below truth.
Type 6 instead has $+0.191$ and $P(\hat Q < Q) = 0.382$.
Type 8 gives $P(\hat Q < Q) = 0.478$ and type 9 bias $+0.031$ (standard error 0.008), closest to median and mean unbiasedness respectively.
However, at $n = 10$ both retain deviations of 3–4 Monte Carlo standard errors, so these properties are approximate.
The f64 value 0.9 is slightly above $9/10$, so $np$ is noninteger; types 1 and 2 both return the maximum $X_{(10)}$ (bias $+0.244$).
This follows because scioxide-stats computes $np$ exactly; expecting $np = 9$ from decimal reasoning about $p$ gives a different result.
Standard deviations range from 0.46 to 0.59 by type; the asymptotic value 0.54 lies between them.

At $n = 50$, biases decrease to $-0.051$ for type 7, $+0.009$ for type 8, and $+0.005$ for type 9.
Standard deviations of 0.23–0.25 approach the asymptotic value 0.242.
At $p = 0.99$, position $h$ exceeds $n = 10$, so all seven definitions except types 4 and 7 return the maximum $X_{(10)}$.
Even the maximum often falls below truth, with $P(\hat Q < Q) = 0.906$ and bias $-0.80$.
No definition estimates quantiles deep in the tails well relative to sample size.

## Summary

There are nine sample-quantile definitions, visibly changing medians and quartiles in small samples.
Differences appear as bias of order $O(1/n)$; for normal samples, type 9's mean and type 8's median are approximately the true value.
scioxide-stats requires an explicit definition through `QuantileRule` and records it in `QuantileConvention`; match type numbers when comparing software.
Mass weights support only the inverse ECDF (corresponding to type 1); other definitions cannot compile.
Use selection-based `quantile_in_place` for a single query, sorted `EmpiricalDistribution` for repeated queries, and `cdf_into` for many batches and query points.
Use `RankMethod` to choose tie handling and expectiles as a location measure responding to tail magnitudes.
