When a computational model has uncertain inputs, one may want to know how much output variability comes from each input.
Local sensitivity measured by partial derivatives describes only linear behavior near a point.
Global sensitivity analysis measures contributions over the full input distribution, including nonlinearities and interactions between inputs.
This page defines Sobol indices partitioning output variance by input and explains pick-freeze estimators from model evaluations, their errors, and the `scioxide-stats` APIs.
Numerical examples use the Ishigami function, whose indices have closed forms.

## Variance decomposition and Sobol indices

Assume mutually independent components of input $X=(X_1,\dots,X_d)$ and square-integrable output $Y=f(X)$.
Then $f$ has a unique decomposition into terms for subsets of components (the Hoeffding decomposition or Sobol ANOVA decomposition).

$$
f(X) = f_0 + \sum_{i} f_i(X_i) + \sum_{i<j} f_{ij}(X_i,X_j) + \cdots + f_{1\cdots d}(X_1,\dots,X_d)
$$

Here, $f_0=E[Y]$ and $f_i(X_i)=E[Y\mid X_i]-f_0$; higher-order terms are also determined successively from conditional expectations.
Every term averages to 0 over any of its variables, making the terms mutually orthogonal.
The output variance $V=\mathrm{Var}(Y)$ is therefore the sum of term variances.

$$
V = \sum_i V_i + \sum_{i<j} V_{ij} + \cdots + V_{1\cdots d},
\qquad V_i = \mathrm{Var}\bigl(E[Y\mid X_i]\bigr)
$$

Define the first-order and total-order Sobol indices for $X_i$ by

$$
S_i = \frac{V_i}{V},
\qquad
S_{Ti} = \frac{E\bigl[\mathrm{Var}(Y\mid X_{\sim i})\bigr]}{V} = 1 - \frac{\mathrm{Var}\bigl(E[Y\mid X_{\sim i}]\bigr)}{V}
$$

(Sobol 1993, 2001).
$X_{\sim i}$ contains all components except $X_i$.
$S_i$ is the variance fraction explained by $X_i$ alone, corresponding to the expected fraction of variance removed by fixing $X_i$ to its true value.
$S_{Ti}$ is the fraction of variance from all terms containing $X_i$, corresponding to the expected variance fraction remaining when every input except $X_i$ is fixed.

The indices have the following properties.

- $0\le S_i\le S_{Ti}\le1$, and $S_{Ti}-S_i$ is the interaction fraction involving $X_i$.
- $\sum_i S_i\le1$, with equality only when $f$ is additive (no interaction terms).
  $\sum_i S_{Ti}\ge1$, with each interaction counted once for every variable it involves.
- If $S_{Ti}=0$, $X_i$ does not affect output and can be fixed to a constant (factor fixing).
  Inputs with larger $S_i$ give larger expected variance reductions when fixed to their true values, so $S_i$ ranks inputs whose uncertainty should be reduced first (factor prioritization).

With dependent inputs, decomposition terms are no longer orthogonal and the index partition is not unique.
`scioxide-stats` handles only Sobol indices for independent inputs; it provides neither dependent-input indices such as Shapley effects, screening methods such as Morris, nor moment-independent indices.
If dependent inputs can be represented by a transformation from independent variables, such as a Rosenblatt transformation, compute indices for those independent variables.

## Closed forms for the Ishigami function

The Ishigami and Homma (1990) function of three independent uniform variables $X_j\sim U(-\pi,\pi)$ is

$$
f(X) = \sin X_1 + a\sin^2 X_2 + b\,X_3^4\sin X_1
$$

and is a standard example for validating sensitivity estimators.
Using $E[\sin X_1]=0$, $E[\sin^2 X_1]=1/2$, $E[X_3^4]=\pi^4/5$, and $\mathrm{Var}(X_3^4)=\pi^8/9-\pi^8/25=16\pi^8/225$ gives variance components

$$
V_1 = \frac12\left(1+\frac{b\pi^4}{5}\right)^2,
\qquad V_2 = \frac{a^2}{8},
\qquad V_{13} = \frac{8b^2\pi^8}{225},
\qquad V_3=V_{12}=V_{23}=V_{123}=0
$$

and total variance $V=\frac12+\frac{a^2}{8}+\frac{b\pi^4}{5}+\frac{b^2\pi^8}{18}$ (Saltelli et al. 2008).
For $a=7$ and $b=0.1$, the values are as follows.

| Input | $S_i$ | $S_{Ti}$ |
|---|---|---|
| $X_1$ | 0.3139 | 0.5576 |
| $X_2$ | 0.4424 | 0.4424 |
| $X_3$ | 0 | 0.2437 |

$X_3$ has first-order index 0 and appears irrelevant if only main effects are considered.
However, through its product term with $X_1$, it contributes to 24% of output variance and appears only in $S_{T3}$.
$X_2$ has only an additive term, so $S_2=S_{T2}$.

The following definitions serve this page's three cells.
`ishigami` corresponds to $f$, `to_input` transforms unit-interval coordinates $u\in[0,1)$ to $X_j=\pi(2u-1)$, and `ishigami_exact` gives the closed-form indices above.
The sine in `ishigami` is computed with SciOxide's `RealScalar::sin`.

```rust
//| id: stats-sobol-ishigami-model
//| kind: definitions
//| title: "Ishigami function and closed-form Sobol indices"
//| crates: [scioxide-core]
use core::f64::consts::PI;
use scioxide_core::{SciOxideError, RealScalar};

/// Ishigami coefficients a and b
pub(crate) const ISHIGAMI_A: f64 = 7.0;
pub(crate) const ISHIGAMI_B: f64 = 0.1;

/// Map unit-interval coordinate u ∈ [0, 1) to X = π(2u − 1) ∈ [−π, π)
pub(crate) fn to_input(u: f64) -> f64 {
    PI * (2.0 * u - 1.0)
}

/// f(x) = sin x₁ + a sin² x₂ + b x₃⁴ sin x₁
pub(crate) fn ishigami(x: &[f64]) -> Result<f64, SciOxideError> {
    let (sin1, sin2) = (RealScalar::sin(x[0]), RealScalar::sin(x[1]));
    let square3 = x[2] * x[2];
    Ok(sin1 + ISHIGAMI_A * sin2 * sin2 + ISHIGAMI_B * square3 * square3 * sin1)
}

/// Closed-form first-order indices (S₁, S₂, S₃) and total-order indices (S_T1, S_T2, S_T3)
pub(crate) fn ishigami_exact() -> ([f64; 3], [f64; 3]) {
    let (a, b) = (ISHIGAMI_A, ISHIGAMI_B);
    let pi4 = PI * PI * PI * PI;
    let main1 = 1.0 + b * pi4 / 5.0;
    let v1 = 0.5 * main1 * main1;
    let v2 = a * a / 8.0;
    let v13 = 8.0 * b * b * pi4 * pi4 / 225.0;
    let v = v1 + v2 + v13;
    ([v1 / v, v2 / v, 0.0], [(v1 + v13) / v, v2 / v, v13 / v])
}
```

## Pick-freeze designs and estimators

The quantity $V_i$ and the numerator of $S_{Ti}$ can be written as expectations of output products or differences at two points sharing some inputs.
Construct independent $n\times d$ sample matrices $A$ and $B$; write $A_B^{(i)}$ for the matrix replacing only column $i$ of $A$ with column $i$ of $B$.
In row $k$, $B_k$ and $A_{B,k}^{(i)}$ share only $X_i$, while $A_k$ and $A_{B,k}^{(i)}$ share everything except $X_i$.
The method freezes shared components and picks new values for the rest, hence “pick-freeze.”
Then the following identities hold.

$$
\mathrm{Cov}\bigl(f(B),\,f(A_B^{(i)})\bigr) = V_i,
\qquad
\tfrac12 E\Bigl[\bigl(f(A)-f(A_B^{(i)})\bigr)^2\Bigr] = E\bigl[\mathrm{Var}(Y\mid X_{\sim i})\bigr]
$$


One estimate requires model evaluations on rows of $A$, $B$, and $d$ matrices $A_B^{(i)}$, totaling $n(d+2)$ evaluations.

Many formulas estimate the same expectations but have substantially different variances.
$f_0$ and $V$ use the pooled mean $m$ and variance $\hat V=\frac{1}{2n}\sum_k\bigl[(f(A_k)-m)^2+(f(B_k)-m)^2\bigr]$ of $2n$ outputs from $f(A)$ and $f(B)$.
Classical estimators (Sobol 1993, Homma and Saltelli 1996) subtract $f_0^2$ from a mean product.

$$
\hat S_i^{\text{Sobol}} = \frac{\frac1n\sum_k f(B_k)\,f(A_{B,k}^{(i)}) - m^2}{\hat V},
\qquad
\hat S_{Ti}^{\text{HS}} = 1-\frac{\frac1n\sum_k f(A_k)\,f(A_{B,k}^{(i)}) - m^2}{\hat V}
$$

When output mean $|f_0|$ is large relative to its standard deviation, this subtracts two large quantities, causing cancellation, and introduces estimation error in $m^2$ into the indices.
`scioxide-stats` uses the Saltelli et al. (2010) estimator for first-order indices and the Jansen (1999) estimator for total-order indices.

$$
\hat S_i = \frac{1}{n\hat V}\sum_k \bigl(f(B_k)-m\bigr)\bigl(f(A_{B,k}^{(i)})-f(A_k)\bigr),
\qquad
\hat S_{Ti} = \frac{1}{2n\hat V}\sum_k \bigl(f(A_k)-f(A_{B,k}^{(i)})\bigr)^2
$$

The first-order formula subtracts a term that leaves the expectation unchanged because $f(A_k)$ is independent of $B_k$, avoiding estimation of $f_0^2$.
`scioxide-stats` subtracts $m$ from $f(B_k)$ in Saltelli et al.'s formula.
Since $f(A_B^{(i)})-f(A)$ has expectation 0, the expectation is unchanged, and adding a constant to outputs leaves the formula unchanged.
$f(A_{B}^{(i)})-f(A)$ cancels components not sharing $X_i$, reducing variance as a control variate would.
Jansen's total-order formula averages squared differences, so it is nonnegative and independent of $f_0$.
From test-function comparisons, Saltelli et al. (2010) recommend Jansen's formula for total-order indices and this form for first-order indices.
Both estimators are consistent, with standard errors decreasing as $O(n^{-1/2})$.
At finite $n$, estimates may be negative or exceed 1; `scioxide-stats` does not clip them to $[0,1]$.

## API for computing indices from outputs

`SobolEvaluations` is a structure borrowing pick-freeze design outputs.
`a[k]` is $f(A_k)$ and `b[k]` is $f(B_k)$; `hybrids` is an array of length $nd$ placing $f(A_{B,k}^{(i)})$ for row $k$ and component $i$ at `hybrids[k * d + i]`.
Set `dimensions` to $d$.
When arranging model evaluations yourself, such as importing external simulator results, pack them in this form and pass them to `sobol_indices`.

`sobol_indices(evaluations)` computes the Saltelli and Jansen estimators above and returns `SobolIndices`.
The cost is $O(nd)$, with sums accumulated over an extended exponent range.
Adding a constant or multiplying outputs by a nonzero constant therefore changes estimates only within rounding error.
The following cases return errors.

- Zero `dimensions`, $n<4$ or `b` with length other than $n$, or `hybrids` with length other than $nd$ returns `InvalidInput`.
- NaN or infinite outputs return `NonFinite`.
- Zero pooled output variance makes indices undefined and returns `NumericalInstability`.

`SobolIndices` is the estimation result; `first_order()` returns $\hat S_i$ and `total_order()` returns $\hat S_{Ti}$ in input order.
`rows()` returns design row count $n$ (summed over repetitions for randomized quasi-Monte Carlo).
`randomized_standard_error()` returns paired standard errors for $(\hat S_i, \hat S_{Ti})$ from randomized quasi-Monte Carlo repetitions, and `None` for other methods.

## Monte Carlo estimation

`sobol_indices_monte_carlo(dimensions, rows, root, sampler, model)` generates $A$ and $B$ from independent random numbers, evaluates the model, and estimates indices.

- Random values for row $k$ come from a child stream of `root.split(k)`, making results independent of execution partitioning without advancing `root` itself.
  From the child stream, `sampler(j, rng)` draws $A_{k,j}$ and $B_{k,j}$ alternately in component $j=0,1,\dots$ order.
- `sampler(j, rng)` returns one value from the marginal distribution of component $j$.
  For uniform distributions, transform `rng.next_float()`; for general distributions use an inverse CDF or `sample` of a `scioxide-random` distribution.
- `model` is called at $A_k$, $B_k$, and every $A_{B,k}^{(i)}$, totaling $n(d+2)$ calls.
  All outputs are retained, requiring $O(nd)$ memory.
- Zero `dimensions`, `rows` below 4, or a value not fitting in `u64` returns `InvalidInput`.
  Nonfinite returns from `sampler` or `model` yield `NonFinite`, zero output variance yields `NumericalInstability`, and callback errors propagate unchanged.

The returned `SobolMonteCarloResult` provides `SobolIndices` through `indices()` and retained outputs as `SobolEvaluations` through `evaluations()`.
Outputs are retained to compute bootstrap intervals or other estimators without reevaluating the model.
To specify worker count, memory limit (`StatisticsOptions::max_bytes`), and cancellation, use the scoped form `sobol_indices_monte_carlo_scoped` accepting `StatisticsOptions` and an execution context.
When called inside another computation, model evaluations count against the parent's work budget.
Outputs exceeding the memory limit return `ResourceLimit`; cancellation returns `ExecutionStopped`.

The next cell estimates Ishigami indices by Monte Carlo with $n$ rows and compares them with closed forms.
Inputs are row count $n$ and random seed; model evaluation count is $5n$.
Retained outputs $f(A)$, $f(B)$, and $f(A_B^{(i)})$ and the random seed are passed to the next section's cell.

## Comparing estimators and bootstrap intervals

Monte Carlo estimate uncertainty can be assessed by resampling design rows.
The outputs $\bigl(f(A_k), f(B_k), f(A_{B,k}^{(1)}),\dots,f(A_{B,k}^{(d)})\bigr)$ of row $k$ are independent and identically distributed across rows.
Draw $n$ row indices with replacement and recompute indices using each row's outputs together, repeating $R$ times.
The interval from the $(1-c)/2$ to $(1+c)/2$ quantiles of resampled indices is the percentile interval at confidence level $c$ (Efron and Tibshirani 1993, Chapter 13).

`sobol_bootstrap(evaluations, root, replicates, confidence)` computes these intervals and returns `SobolBootstrap`.

- Random values for resample $r$ use the substream of `root` determined only by $r$.
- Quantiles use Hyndman and Fan type 7 (linear interpolation).
- Computation is sequential, costing $O(Rnd)$ with memory for $n$ row indices and $2Rd$ resampled indices.
- `evaluations` violating `sobol_indices` returns that error; `replicates < 2` returns `InvalidInput`; zero resampled output variance returns `NumericalInstability`.
- Use scoped `sobol_bootstrap_scoped` to specify memory limits and cancellation.

`first_order()` and `total_order()` of `SobolBootstrap` return per-input intervals as `(lower, upper)` pairs.
`confidence()` returns the confidence level, and `replicates()` the resample count.
These intervals assume independent rows.
Points within one quasi-random sequence are dependent, so resampling its rows does not produce valid intervals.
For quasi-Monte Carlo, derive standard errors from independent randomized repetitions as in the next section.

The next cell receives the preceding outputs, repacks them as `SobolEvaluations`, and computes indices with `sobol_indices`.
It computes classical estimators (Sobol first-order, Homma–Saltelli total-order) from the same outputs using f64 arithmetic, and also shows differences between `sobol_indices` and manually computed Saltelli and Jansen formulas.
The “Constant added to output $c$” input adds $c$ to every output before computation.
$c$ leaves true indices unchanged; if estimates vary with $c$, the estimator is sensitive to mean magnitude.

use scioxide_stats::{ConfidenceProbability, SobolEvaluations, sobol_bootstrap, sobol_indices};

let read = |key: &str| -> Result<Vec<f64>, String> {
    let values = design[key].as_array().ok_or(format!("Missing {key}"))?;
    values
        .iter()
        .map(|v| {
            v.as_f64()
                .map(|y| y + offset)
                .ok_or(format!("Nonnumeric value in {key}"))
        })
        .collect()
};
let (a, b, hybrids) = (read("a")?, read("b")?, read("hybrids")?);
let seed = design["seed"].as_u64().ok_or("Random seed is absent")?;
let evaluations = SobolEvaluations {
    a: &a,
    b: &b,
    hybrids: &hybrids,
    dimensions: 3,
};
let indices = sobol_indices(evaluations).map_err(|e| e.to_string())?;

// Independent check: compute estimators with f64 arithmetic. Compute m and V from the 2n values f(A), f(B)
let n = a.len() as f64;
let m = a.iter().chain(&b).sum::<f64>() / (2.0 * n);
let v = a.iter().chain(&b).map(|y| (y - m) * (y - m)).sum::<f64>() / (2.0 * n);
let (exact_first, exact_total) = ishigami_exact();
let mut rows = Vec::new();
for i in 0..3 {
    let ab = |k: usize| hybrids[k * 3 + i];
    let (mut saltelli, mut jansen, mut sobol, mut homma) = (0.0, 0.0, 0.0, 0.0);
    for k in 0..a.len() {
        saltelli += (b[k] - m) * (ab(k) - a[k]);
        jansen += (a[k] - ab(k)) * (a[k] - ab(k));
        sobol += b[k] * ab(k);
        homma += a[k] * ab(k);
    }
    let (s, t) = (indices.first_order()[i], indices.total_order()[i]);
    let classical_first = (sobol / n - m * m) / v;
    let classical_total = 1.0 - (homma / n - m * m) / v;
    let first_gap = (s - saltelli / (n * v)).abs();
    let total_gap = (t - jansen / (2.0 * n * v)).abs();
    rows.push((
        format!("S{}", i + 1),
        exact_first[i],
        s,
        classical_first,

## Randomized quasi-Monte Carlo

Quasi-Monte Carlo (QMC) uses low-discrepancy sequence points in place of random values.
The first $2^k$ Sobol points occupy elementary intervals of the unit cube evenly, so errors in smooth-integrand averages can fall to $O(n^{-1}(\log n)^{s})$ ($s$ is dimension).
A deterministic sequence alone cannot estimate error magnitude; independently randomize (scramble) it $R$ times and estimate standard errors from variation across repetitions (L'Ecuyer and Lemieux 2002).

`sobol_indices_qmc(plan, dimensions, points, transform, model)` constructs pick-freeze designs with randomized quasi-Monte Carlo.

- `plan` is `QmcReplicatePlan`, a $2d$-dimensional sequence independently randomized $R$ times.
  Sobol sequences use linear matrix scrambling and digital shifts (Matoušek 1998), with a power-of-two point count per repetition.
- Each point's first $d$ coordinates form a row of $A$; its last $d$ form a row of $B$.
  `transform(j, u)` maps unit coordinate $u$ to input component $j$, for example using a marginal inverse CDF.
- Each repetition $r$ computes $\hat S^{(r)}$ using the same estimators as `sobol_indices`; the result is their mean, and standard error is their standard deviation divided by $\sqrt R$.
  `randomized_standard_error()` returns this standard error.
  It estimates error from variation across repetitions and is not an error bound.
- `model` is called $R\cdot N(d+2)$ times ($N$ is the number of points per repetition).
- Zero `dimensions`, `points` below 4 or differing from the point count in `plan`, fewer than two repetitions, or `plan` dimension other than $2d$ returns `InvalidInput`.
  Nonfinite returns from `transform` also yield `InvalidInput`; nonfinite returns from `model` yield `NonFinite`; zero output variance in any repetition yields `NumericalInstability`.

Use scoped `sobol_indices_qmc_scoped` for parallel repetitions, memory limits, and cancellation.
Estimates are independent of repetition scheduling.

The next cell estimates Ishigami indices with randomized quasi-Monte Carlo using $N=2^k$ points and $R$ repetitions.
For comparison, Monte Carlo uses the same evaluation count ($RN$ rows), and both methods' errors relative to closed forms are displayed.
The last column divides randomized quasi-Monte Carlo error by its standard error; absolute values mostly below 2 suggest the standard error represents the error scale.
With few repetitions $R$, standard errors themselves are uncertain and this ratio fluctuates.

## Summary

Sobol indices partition output variance by input: first-order $S_i$ represents an individual contribution and total-order $S_{Ti}$ includes interactions.
`scioxide-stats` computes first-order Saltelli (2010) and total-order Jansen (1999) estimates from $n(d+2)$ pick-freeze evaluations without sensitivity to output mean magnitude.
Use `sobol_indices_monte_carlo` for independent-random designs and pass retained outputs to `sobol_bootstrap` for intervals from resampled row tuples.
For smooth models, randomized quasi-Monte Carlo in `sobol_indices_qmc` yields smaller errors at the same evaluation count; standard errors come from independent randomized repetitions.
Dependent-input indices are not provided; rewrite inputs as transformations of independent variables before using these methods.
