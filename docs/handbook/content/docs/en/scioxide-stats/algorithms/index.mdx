These pages derive scioxide-stats estimators mathematically and connect their properties to implementation contracts.
This page collects shared notation and conventions.

## Notation

| Symbol | Meaning |
|---|---|
| $x_1, \dots, x_n$ | Observations; $n$ is the record count |
| $X_{(1)} \le \dots \le X_{(n)}$ | Ascending order statistics |
| $\bar x$, $\bar x_w$ | Arithmetic and weighted means |
| $M_k = \sum_i (x_i - \bar x)^k$ | Sum of order-$k$ central moments; $m_k = M_k/n$ is the population central moment |
| $s^2$, $\sigma^2$ | Sample variance (divisor $n-1$), population variance |
| $w_i$, $W = \sum w_i$, $Q = \sum w_i^2$ | Weights, total weight, sum of squared weights |
| $n_{\mathrm{eff}} = W^2/Q$ | Kish effective sample size |
| $F_n$, $Q(p)$ | Empirical distribution function, quantile function |
| $\mathrm{SE}$ | Estimated standard error of an estimator |
| $u$, $\varepsilon$ | Unit roundoff ($2^{-53}$ for f64), machine epsilon ($2^{-52}$) |

Unless stated otherwise, variance and covariance refer to sample values (divisor $n-1$).
Formulas explicitly distinguish population values where needed.

## Input validation and missing data

scioxide-stats functions validate inputs before computing statistics.
By default, nonfinite values (NaN and infinity) are rejected as `NonFinite`; empty samples and invalid weights or probabilities are rejected as `InvalidInput`.
Computation does not continue by guessing values for invalid inputs.
Functions aggregating matrices or N-dimensional arrays accept borrowed layout views and policies.

`BatchView` borrows core's `StridedLayout` and selects the sample axis with `Axis::All` or `Axis::Index(i)`.
For multivariate data, `with_coordinates` specifies the coordinate axis and the remaining axes define independent batches.
Moments, order statistics, bins, distribution functions, kernel densities, and isotonic regression share this view.
`Weights::<_, Model>::new` pairs weight storage with its meaning.
`Frequency` represents u64 replication counts, `Mass` relative masses, `Reliability` reliability, and `Analytic` inverse variance.
Unsupported statistic-weight combinations are excluded by types.

Missingness markers and weights use observation order, with batch indices outermost and sample indices innermost, regardless of physical strides.
One is attached to each whole observation, rather than each coordinate.
`MissingPolicy` controls marked missing elements and `NonFinitePolicy` controls present NaN and infinite values, choosing rejection (default `Reject`) or omission from estimation (`Skip`).
Missingness is checked before reading values.
`StatisticsOptions` combines acceptance policies, execution intent, moment order, and the byte limit for retained storage.
The default is sequential execution rejecting missing and nonfinite values; `ExecutionContext` supplies worker capabilities and limits.
Selecting `MergePolicy::StablePartitions` combines execution-plan partitions in a fixed order, producing results independent of executor completion order.
Omitted counts remain in results or diagnostics, such as `BinnedDiagnostics::skipped`, `IsotonicDiagnostics::excluded`, and test `omitted`.
Data do not establish whether omission changes the sample's meaning, such as whether missingness depends on values.

Select means, variances, robust quantities, and order statistics with `Statistic`.
Compute common unweighted quantities directly with one-shot `mean`, `sample_variance`, `sample_standard_deviation`, `median`, `quantile` (type 7), `minimum`, `maximum`, and `mean_confidence_interval`.
`statistic(values, weights, selector)` and axis reductions `statistics(view, selector)` and `rolling_statistics` allocate workspace internally; `statistics_into` and `rolling_statistics_into` use reserved `StatisticsWorkspace`.
For the median, pass probability 0.5 and `QuantileRule` to `Statistic::quantile`.
The result `StatisticValue` separates complex locations from real spread.

Query workspace requirements with `workspace_requirements` and prepare storage with `try_reserve`, `check`, and `workspace`.
Requirements include retained models or shapes, worker storage, and staging of every output.
After reservation, borrowed execution allocates nothing during numerical processing and leaves outputs unchanged on failure.

## Call forms

The same computation has several call forms according to the required control.
This chapter names argument and return shapes as follows.

| Form | Example | Accepts | Returns | Execution context |
|---|---|---|---|---|
| One-shot function | `mean(&x)`, `t_test_independent(&x, &y)`, `chi2_contingency_test(table)`, `kaplan_meier(&observations)`, `bootstrap(statistic, &x, &mut rng)`, `glm_fit(design, family, &y)` | Problem data only (plus a generator for randomized functions) | Answer | `sequential_native()` |
| One-shot constructor | `GaussianKde::new(&x)`, `PreparedPca::new(data)`, `PreparedCca::new(x, y)` | Data only | Prepared value | `sequential_native()` |
| Ordinary | `PreparedGlm::fit(inputs)`, `PreparedRegression::fit(&y)`, `PreparedHuber::fit(&y)`, `PreparedArimaFit::fit(initial, bounds, solver)` | Prepared value and inputs only | Newly allocated result | `sequential_native()` |
| Detailed | `t_test_independent_with_options(&x, &y, TTestVariance::Pooled, options)`, `GaussianKde::with_options(view, batch, options)`, `kaplan_meier_with_options(&observations, confidence, options)`, `statistics_with_options(view, selector, options)` | Inputs and method choices, with options last | Newly allocated result | `sequential_native()` |
| Borrowed | `statistics_into(view, selector, options, &mut out, &mut ws, context)`, `kaplan_meier_into(..., &mut out, &mut ws, context)` | Inputs, options, output, workspace, and context, in that order | Writes output | Supplied context |
| Scoped | `fit_scoped(request, solver, options, scope)`, `cox_fit_scoped(...)`, `sobol_indices_monte_carlo_scoped(..., options, scope)`, `PreparedGlm::fit_scoped(inputs, scope)` | Inputs, options, and context last | Value | Supplied context |

Ordinary and detailed forms return newly allocated results and are also called owned forms in API-guide tables.
One-shot functions and constructors fix the following choices; specify other choices through detailed forms.

| Choice | One-shot value |
|---|---|
| Weights | Unweighted (except functions focused on a weight model) |
| Sample-spread divisor | $n-1$ |
| Quantiles | Hyndman–Fan type 7 (linear interpolation) |
| Mean interval | Two-sided 95% Student t interval with $n-1$ degrees of freedom |
| Test alternative | Two-sided (`Greater` for Chatterjee and Page) |
| Test calibration | `Auto` |
| Continuity correction | Half a unit (Yates' correction for Pearson statistics in 2×2 tables) |
| Independent two-sample t test | Welch (does not assume equal variances) |
| Zero differences in signed-rank tests | Omit (`Discard`) |
| Brunner–Munzel reference distribution | Student's t |
| Center for variance tests | Median |
| k-sample Anderson–Darling ties | Midranks |
| Observations equal to the pooled median in median tests | Count below the median (`Below`) |
| Isotonic regression direction | Increasing |
| Robust-slope intercept | Median residual intercept $y_i - \hat\beta_1 x_i$ (`Joint`) |
| Kernel-density bandwidth | Scott's rule, full covariance |
| Missing and nonfinite values | Reject |
| Bootstrap | Independent BCa, 9999 repetitions, 95% |
| Permutations | Independent randomized assignments, 9999 repetitions |

Randomized one-shot functions also accept a generator and never choose a seed internally.
Options types have private fields, infallible setters, and `Default`; preparation or execution validates their values.
Pass `ExecutionContext` for a root computation's scoped context, or a mutable parent `SolveContext` when calling inside another computation.
In the latter case, child evaluations and random generation count against the parent's work budget.

## Estimates, statistical uncertainty, and rounding error

This chapter distinguishes three kinds of “error.”

- Rounding error is the difference from exact arithmetic caused by floating-point operations.
  Accumulators retain internal states in extended-range values with separate binary exponents, independently rounding public variances or standard errors at each query.
  Rounding ranges checked by tests are not forward-error guarantees for every dataset.
- Statistical uncertainty is estimate variability across samples from the same population.
  Standard errors, confidence intervals, and p values represent it under recorded assumptions such as independence, normality, or exchangeability.
- Monte Carlo error results from finite resampling or simulation repetitions.
  Bootstrap `mean_monte_carlo_error`, permutation-test `tail_uncertainty`, and power Wilson intervals represent it.

Confidence intervals, credible intervals, and test p values are not numerical enclosures guaranteed to contain truth.
Computations requiring certified enclosures appear in the scioxide-validated chapter.

## Committing results and termination reasons

- Mathematically undefined quantities (empty-sample means, one-point sample variances, constant-sequence correlations, or empty-bin means) return `None`.
  Invalid input, unrepresentable results, and numerical breakdown return `Err` rather than replacement values of 0 or NaN.
  Accumulator summary queries return `Result<Option<S>, SciOxideError>`, with only overflowing quantities becoming `Err`.
- Accumulator `observe` and `merge` and borrowed `_into` functions update state or output only after every check and computation succeeds.
  Errors leave caller-owned state and output unchanged.
  Workspace contents may change on failure but remain reusable.
- Ordinary, detailed, scoped, and borrowed forms of iterative or budgeted procedures return reports in `Ok` even after stopping at a limit, cancellation, or deadline, expressing success or failure through one termination-reason enum.
  `StatsTermination::Completed` means requested work is complete, `Converged` means a numerical stopping condition is satisfied, and `ExactFit` means a fit has no residual.
  Check `is_success()` and each method's assumptions; do not treat unfinished values as converged estimates.
- One-shot functions return no unfinished estimates and convert unsuccessful termination reasons to errors.
  `Stopped` becomes `ExecutionStopped`, `RankDeficient` becomes `Singular`, and `BudgetExhausted`, `NotConverged`, `NoProgress`, and `Separated` become `ConvergenceFailure`.
  The reason for `ConvergenceFailure` depends on procedure and termination reason; for example, `BudgetExhausted` in GLM and Huber regression is `IterationLimit` (the API guide's [Termination reasons](oxref:stats-api-termination-reasons) table gives all mappings).
- Quantile definitions, tail-mean boundary handling, interval methods and degrees of freedom, and calibrations actually used by tests are recorded in result types.

## Summary

Inputs are validated before computation; nonfinite values and invalid settings are reported as errors without guessed replacements.
Use one-shot functions for one-time computations with defaults, detailed forms to change settings, borrowed forms to reuse workspace, and scoped forms inside other computations.
Rounding error, statistical uncertainty, and Monte Carlo error are different quantities; confidence intervals and p values are not numerical enclosures.
For iterative procedure results, check termination-reason `is_success()` before using them as estimates.
