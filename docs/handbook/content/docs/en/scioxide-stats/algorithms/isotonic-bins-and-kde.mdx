This page covers three methods estimating function shapes from samples without assuming a parametric distribution model.
Isotonic regression imposes only an increasing-shape constraint; binning counts samples within grid cells to form frequencies or densities; kernel density estimation places a smooth kernel at each observation and adds them.
Each method returns diagnostics identifying used and omitted observations alongside estimates.
Each section explains definitions and algorithms and checks results against closed forms or independent quadrature.

## Isotonic regression and PAVA

### Problem and solution shape

For observations $y_1,\dots,y_n$ and weights $w_i\ge0$, the problem minimizing weighted squared error over nondecreasing sequences,

$$
\min_{f_1\le f_2\le\cdots\le f_n}\ \sum_{i=1}^nw_i(y_i-f_i)^2
$$

is called isotonic regression.
It applies when theory establishes a monotone relationship but not its shape, such as dose versus response rate or credit rating versus default rate.
The constraint set is a closed convex cone, and the objective is strictly convex for positive weights, so a unique solution exists.
The solution is a step function of constant intervals (blocks), with each block's value equal to its observations' weighted mean (Barlow et al., 1972).

### PAVA algorithm

PAVA (pool adjacent violators algorithm) pushes observations from left to right as individual blocks; while the preceding block exceeds the new block (violating order), it merges them and replaces their values with the weighted mean

$$
\bar y_{A\cup B}=\frac{W_A\bar y_A+W_B\bar y_B}{W_A+W_B}
$$


$W_A,W_B$ are the sums of weights in the respective blocks.
The merged value lies between the original values, so merging can create a new violation with the left neighbor; merging then continues.
Blocks are held on a stack and each observation is merged at most once, giving both time and memory cost $O(n)$.
Unlike iterative optimization, it reaches the exact solution in finitely many steps and has no stopping tolerance.
Optimality follows from the Karush–Kuhn–Tucker conditions.
For increasing constraints, optimality requires every weighted-residual partial sum $\sum w_i(y_i-f_i)$ from the start of a block to be nonnegative (the preceding portion's mean is at least the block value), and block values to increase strictly.

### Functions, results, and workspace

`isotonic_regression(values)` fits unweighted observations in increasing observation order and returns `IsotonicResult`.
Supply weights, direction, and missing-data policy with the detailed form `isotonic_regression_with_options(values, weights, direction, options)`; use `IsotonicDirection::Decreasing` for decreasing constraints.
Both directions are nonstrict, allowing equal adjacent fitted values.
Trait `IsotonicWeights` restricts weight models to unweighted `Unweighted` and relative-mass `Mass`.
Passing frequency weights `Frequency` causes a compile error.

`IsotonicResult` returns fitted values `fitted()`, maximal constant intervals `blocks()`, and diagnostics `diagnostics()`.
`IsotonicBlock` contains inclusive start index `start`, exclusive end index `end`, value `value`, and weight sum `weight`.
`IsotonicDiagnostics` contains block count `block_count`, used count `retained`, omitted count `excluded`, weight sum `weight`, and fitted weighted squared error `squared_error`; weight sum and squared error become `None` if they overflow the scalar type.
Zero-weight observations are omitted before their values are read, so their values may be NaN.
Omitted positions receive the preceding fitted value; omitted leading positions receive the first fitted position's value, keeping the whole output monotone.
A nonempty input with zero total weight, negative or NaN or infinite weights, or nonfinite positive-weight observations under rejection policy returns an error.

For repeated allocation-free fitting, request `IsotonicRequirements` up to length $n$ with `IsotonicWorkspace::scalar_requirements(n, options)`, create workspace with `IsotonicWorkspace::workspace`, and pass fitted output `output` and `blocks` storage to `isotonic_regression_into`.
To fit every multidimensional-array lane (one sequence along the sample axis), estimate requirements with `IsotonicWorkspace::workspace_requirements(view, options, context)` and use `isotonic_regression_axes_into`.
Outputs are combined in `IsotonicBatchOutput`: `fitted` contains fitted values with the input shape, `blocks` per-lane intervals, and `lanes` per-lane `IsotonicLaneResult` (block start `block_offset` and diagnostics).
Lanes are independent and give the same results in parallel execution.

### Check interval merging against a closed form

The next cell fits five observations $(0,a,1,4,\mathrm{NaN})$ with weights $(1,w,1,1,0)$ under increasing constraints.
Since $a>1$, the second and third points violate order; PAVA merges them into one block of value $(wa+1)/(w+1)$.
The fifth point has zero weight, so its value is not read; it receives the preceding fitted value 4.
The closed-form weighted squared error is $w\{a-(wa+1)/(w+1)\}^2+\{1-(wa+1)/(w+1)\}^2=w(a-1)^2/(w+1)$.

Changing $a$ from 2 to 3.8 leaves block boundaries unchanged; only weighted-mean values move.
The fit and closed form differ by 0 for every input.

## Cartesian-grid binning

### Grid and positions

`BinPlan` constructs a Cartesian grid from boundary sequences for each coordinate axis.
`BinPlan::new(edges)` accepts at least two finite, strictly increasing boundaries per axis; `BinPlan::uniform(axes)` constructs $m$ equally spaced bins from each axis's $(\mathrm{low},\mathrm{high},m)$ (using `low` and `high` directly as endpoint boundaries).
Each bin is half-open $[e_k,e_{k+1})$; only the last bin on each axis includes upper endpoint $e_m$.
Bins use row-major indexing (last axis varies fastest).

`BinPlan::locate(point)` returns a point's position as `BinLocation`.
Points inside the grid are `BinLocation::Inside(index)`, points below an axis minimum are `Underflow(axis)`, and points above an axis maximum are `Overflow(axis)`.
A point outside several axes is classified by its first offending axis, so every point is counted exactly once.

### Normalizing frequencies and densities

`BinnedStatistic` selects the quantity computed per bin.
`Count` counts observations (replications for frequency weights, positive-weight observations for mass weights); `Mass` is the weight sum.
Observation $i$ has mass $m_i$ equal to 1 when unweighted, replication count for frequency weights, and its weight for mass weights.
`RelativeFrequency` and `Density` use different normalizations.

$$
\text{relative frequency}_k=\frac{M_k}{M_{\mathrm{admitted}}},\qquad \text{density}_k=\frac{M_k}{M_{\mathrm{retained}}\,V_k}
$$

$M_k$ is the sum of observation masses $m_i$ in bin $k$; $V_k$ is bin volume (width in one dimension), $M_{\mathrm{admitted}}$ is all accepted mass including outside the grid, and $M_{\mathrm{retained}}$ is mass inside the grid.
Relative frequencies sum to the fraction inside the grid, $M_{\mathrm{retained}}/M_{\mathrm{admitted}}$, less than 1 when out-of-range observations exist.
Density satisfies $\sum_k\text{density}_kV_k=1$ and is a probability density on the grid.
Other quantities include cumulative mass `CumulativeFrequency` for one-dimensional grids and `Sum`, `Mean`, `StandardDeviation` (weighted population standard deviation), `Minimum`, `Maximum`, and `Median` summarizing separate per-observation values.

The result `BinEstimate` contains count `count`, mass `mass: Option<S>`, and computed quantity `value: Option<S>`.
Undefined empty-bin means, standard deviations, minima, maxima, and medians are `None`, never NaN.
Empty-bin counts, masses, sums, and frequencies are 0.
`BinnedDiagnostics` reports accepted mass `admitted_mass`, inside mass `retained_mass`, mass below and above bounds `underflow_mass` and `overflow_mass`, and omitted observations `skipped` per batch.

`binned_statistics(plan, view, values, statistic, options)` allocates output and workspace and returns `BinnedResult` (`bins` and `diagnostics`).
For repeated binning, construct `BinnedWorkspace::workspace` from `BinnedRequirements` returned by `BinnedWorkspace::workspace_requirements` and pass caller-owned output to `binned_statistics_into`.
Missing values for a value-requiring quantity, shape mismatches, insufficient capacity, or zero normalization mass return errors without changing outputs.

For one-dimensional counts alone, `histogram(values, bins)` counts samples in `bins` equally spaced bins from minimum to maximum and returns `Histogram`.
`Histogram::edges()` contains $b+1$ boundaries (the last bin includes the right endpoint), and `counts()` contains integer bin counts; extract both with `into_parts()`.
The cost is $O(n\log b+b)$; empty samples, nonfinite values, constant samples (equal minimum and maximum), and zero bins return errors.
Bin-count rules such as Sturges, Scott, and Freedman–Diaconis are not provided; callers choose the count or `BinPlan` boundaries.

An example directly counting boundary and out-of-range observations appears in [Distribution functions and binning for samples with ties and out-of-range values](../../examples/ecdf-and-bins/).

## Gaussian kernel density estimation

### Estimator and bandwidth

The Gaussian kernel density estimator for $d$-dimensional observations $\mathbf x_1,\dots,\mathbf x_n$ and weights $w_i$ (sum $W$) is

$$
\hat f(\mathbf x)=\sum_{i=1}^n\frac{w_i}{W}\,\phi_{\mathbf H}(\mathbf x-\mathbf x_i),\qquad
\phi_{\mathbf H}(\mathbf u)=\frac{\exp\!\bigl(-\tfrac12\mathbf u^{\mathsf T}\mathbf H^{-1}\mathbf u\bigr)}{(2\pi)^{d/2}\sqrt{\det\mathbf H}}
$$


The kernel covariance $\mathbf H$ (bandwidth matrix) determines smoothness.
Small $\mathbf H$ gives sharp peaks at observations and large variance; large values smooth peaks and increase bias.
In one dimension with $\mathbf H=h^2$, the leading terms of mean integrated squared error $\mathrm{MISE}=\mathrm E\int(\hat f-f)^2$ are

$$
\mathrm{AMISE}(h)=\frac{1}{2\sqrt\pi\,nh}+\frac{h^4}{4}\int f''(x)^2\,dx
$$

The minimizing $h$ is proportional to $n^{-1/5}$ (Silverman, 1986, §3.3).
Since $\int f''^2$ depends on unknown $f$, bandwidth rules replace this quantity by assuming $f$ is normal.

`KdeBandwidth` selects how bandwidth is determined.
`Scott`, `Silverman`, and `Factor(c)` use $\mathbf H=c^2\hat{\boldsymbol\Sigma}$, scaling the weighted unbiased sample covariance $\hat{\boldsymbol\Sigma}$ by factor $c$.
The factor multiplies standard deviations, so covariance is multiplied by $c^2$.
`KdeCovariance::Full` retains $\hat{\boldsymbol\Sigma}$ and coordinate correlations; `KdeCovariance::Diagonal` uses only diagonal entries for coordinate-independent kernels.
The factors are $c=n_{\mathrm{eff}}^{-1/(d+4)}$ for `Scott` and $c=\{n_{\mathrm{eff}}(d+2)/4\}^{-1/(d+4)}$ for `Silverman`.
In one dimension, `Silverman` is $c=(4/(3n))^{1/5}\approx1.06\,n^{-1/5}$, matching the AMISE optimum $h=1.06\,\sigma n^{-1/5}$ for normal $f$.
Silverman's (1986) robust rule $0.9\min(\hat\sigma,\mathrm{IQR}/1.34)\,n^{-1/5}$ is not provided.
To use that bandwidth, compute it yourself and pass it through `StandardDeviations`.
Cross-validation and plug-in (Sheather–Jones) bandwidth selection are also not provided; evaluate candidate factors yourself if needed.
$n_{\mathrm{eff}}$ is the count including replications for unweighted and frequency-weighted data, and the Kish effective sample size $(\sum w_i)^2/\sum w_i^2$ for mass weights.
`StandardDeviations(s)` specifies diagonal $\mathbf H$ using standard deviations; `Covariance(H)` supplies symmetric positive-definite $\mathbf H$ directly in row-major order.
Factor rules fail for singular $\hat{\boldsymbol\Sigma}$ (one observation or a constant sample), while absolute specifications can construct estimators even for such samples.

Factor rules are designed for unimodal populations close to normal.
For bimodal distributions, sample variance includes peak separation and becomes large, giving overly broad rule-based bandwidths that smooth the peaks.

### Preparation and evaluation

`GaussianKde::new(values)` prepares an estimator from a one-dimensional unweighted sample with `Scott` bandwidth.
`GaussianKde::with_options(view, batch, options)` prepares one batch of `BatchView` using bandwidth, covariance structure, support interval, and acceptance policy from `KdeOptions`; `GaussianKde::build(view, batch, options, context)` also accepts an execution context.
Positive-weight observations are copied as kernel centers, requiring $O(nd)$ preparation memory.
`bandwidth_factor()` returns factor $c$ used (`None` for absolute specifications), while `effective_size()` returns $n_{\mathrm{eff}}$.

Evaluate a point's density with `pdf(point)` and log density with `log_pdf(point)`; both allocate $d$ scratch values.
`log_pdf` computes $\ln\hat f$ directly as a log sum, remaining finite at distant points where $\hat f$ underflows.
`evaluate(points)` jointly evaluates multiple row-major points, costing $O(nd^2)$ per point.
For many allocation-free evaluations, construct `KdeWorkspace::workspace` from `KdeRequirements` returned by `KdeWorkspace::workspace_requirements(kde, queries, options, context)` and call `kde_into(kde, queries, scale, options, output, workspace, context)`.
In `scale`, `KdeScale::Density` writes density $\hat f$ and `KdeScale::LogDensity` writes $\ln\hat f$ to outputs.

Integrals have closed forms.
`integrate_kde(other)` computes the product integral $\int\hat f\hat g$ of two estimators as a sum of normal densities over center pairs in $O(nm)$; `integrate_gaussian(mean, covariance)` computes the product integral $\int\hat f\phi$ with a normal density in $O(n)$.
Both require estimators without support intervals.
For a true normal-mixture density, integrated squared error $\mathrm{ISE}=\int(\hat f-f)^2=\int\hat f^2-2\int\hat ff+\int f^2$ can be computed exactly without quadrature.

### Bandwidth and integrated squared error

The next cell draws $n/2$ samples from each component of an equal mixture $f$ of normal distributions with means $\pm\Delta/2$ and variance 1.
Vary factor $c$ from 0.1 to 1 in steps of 0.05; use `kde_into` to evaluate $\hat f$ on the $[-12,12]$ grid with spacing $1/20$ and obtain $\mathrm{ISE}(c)$ by composite Simpson quadrature.
Compare the `Scott` and `Silverman` factors with the ISE-minimizing factor in the table and chart.
Compute ISE for `Scott` also from the closed forms using `integrate_kde` and `integrate_gaussian`, checking Simpson quadrature.
$\int f^2$ follows from normal-density product integrals $\int\phi(x-\mu_1)\phi(x-\mu_2)\,dx=\phi_{\sqrt2}(\mu_1-\mu_2)$ ($\phi_{\sqrt2}$ is the normal density with standard deviation $\sqrt2$).
The density chart overlays the `Scott` estimator evaluated with `kde_into`, a histogram density dividing `histogram` counts by $n$ and bin width, and true density (dashed).
The last table row shows `KdeScale::LogDensity` at a point $x=\Delta/2+60$ far from the peaks and confirms that density `Density` underflows to 0.

```rust
//| id: stats-kde-bandwidth-ise
//| ref: stats-kde-bandwidth-ise
//| title: "Compare kernel-density bandwidths and integrated squared errors for a bimodal normal mixture"
//| run: button
//| crates: [scioxide-core, scioxide-random, scioxide-stats]
//| inputs:
//|   separation: {"type":"range","label":"Peak separation Δ [-]","description":"Zero gives a unimodal standard-normal distribution.","min":0,"max":5,"step":0.5,"value":4}
//|   sample_size: {"type":"range","label":"Sample size n [count]","description":"Draw n/2 observations from each component.","min":50,"max":400,"step":50,"value":200}
//|   sampling_seed: {"type":"integer","label":"Random seed","min":0,"max":100000,"value":11}
//| cases:
//|   - {"id":"unimodal","label":"Δ = 0","description":"For a unimodal normal distribution, Silverman's factor gives ISE close to the minimum.","inputs":{"separation":0}}
//|   - {"id":"large-sample","label":"n = 400","description":"The rule-based factors and ISE decrease.","inputs":{"sample_size":400}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"bandwidths","path":"/rows/0/1","approx":{"value":0.3466,"atol":1e-4}}
//|       - {"artifact":"bandwidths","path":"/rows/1/1","approx":{"value":0.3671,"atol":1e-4}}
//|       - {"artifact":"bandwidths","path":"/rows/2/1","approx":{"value":0.2,"atol":1e-9}}
//|       - {"artifact":"bandwidths","path":"/rows/3/4","equals":null}
//|       - {"artifact":"bandwidths","path":"/rows/0/2","approx":{"value":4.8912e-3,"atol":1e-6}}
//|       - {"artifact":"bandwidths","path":"/rows/0/3","approx":{"value":4.8912e-3,"atol":1e-6}}
use scioxide_core::{ExecutionContext, RealScalar, StridedLayout};
use scioxide_random::{Distribution, Normal, SeedableRng, SplitMix64};
use scioxide_stats::{
    Axis, BatchView, GaussianKde, KdeBandwidth, KdeOptions, KdeScale, KdeWorkspace,
    StatisticsOptions, histogram, kde_into,
};

let n = sample_size as usize;
let centers = [-0.5 * separation, 0.5 * separation];
let mut rng = SplitMix64::from_seed(sampling_seed as u64);
let standard = Normal::<f64>::new(0.0, 1.0).map_err(|e| e.to_string())?;
let mut sample = Vec::with_capacity(n);
for i in 0..n {
    sample.push(centers[i % 2] + standard.sample(&mut rng).map_err(|e| e.to_string())?);
}
let shape = [n];
let unit = [1_usize];
let layout = StridedLayout::new(&shape, &unit).map_err(|e| e.to_string())?;
let view = BatchView::new(&sample, layout, Axis::Index(0)).map_err(|e| e.to_string())?;
let build = |bandwidth: KdeBandwidth<'_, f64>| {
    GaussianKde::with_options(view, 0, KdeOptions::new().with_bandwidth(bandwidth))
};
let (options, context) = (StatisticsOptions::new(), ExecutionContext::sequential());
let evaluate =
    |kde: &GaussianKde<f64>, points: &[f64], scale: KdeScale| -> Result<Vec<f64>, String> {
        let shape = [points.len()];
        let layout = StridedLayout::new(&shape, &unit).map_err(|e| e.to_string())?;
        let queries =
            BatchView::new(points, layout, Axis::Index(0)).map_err(|e| e.to_string())?;
        let req = KdeWorkspace::workspace_requirements(kde, queries, options, context)
            .map_err(|e| e.to_string())?;
        let mut workspace = KdeWorkspace::workspace(&req).map_err(|e| e.to_string())?;
        let mut output = vec![0.0; points.len()];
        kde_into(
            kde,
            queries,
            scale,
            options,
            &mut output,
            &mut workspace,
            context,
        )
        .map_err(|e| e.to_string())?;
        Ok(output)
    };
// True density f(x) = ½φ(x + Δ/2) + ½φ(x − Δ/2).
let normal = |x: f64| RealScalar::exp(-0.5 * x * x) / (2.0 * core::f64::consts::PI).sqrt();
let truth_at = |x: f64| 0.5 * normal(x - centers[0]) + 0.5 * normal(x - centers[1]);
// Compute ISE ≈ ∫(f̂ − f)² by composite Simpson quadrature on [−12, 12] with spacing 1/20.
let grid: Vec<f64> = (0..=480).map(|j| -12.0 + f64::from(j) / 20.0).collect();
let simpson_ise = |kde: &GaussianKde<f64>| -> Result<f64, String> {
    let values = evaluate(kde, &grid, KdeScale::Density)?;
    let mut sum = 0.0;
    for (j, (&x, &v)) in grid.iter().zip(&values).enumerate() {
        let weight = if j == 0 || j == 480 {
            1.0
        } else if j % 2 == 1 {
            4.0
        } else {
            2.0
        };
        sum += weight * (v - truth_at(x)) * (v - truth_at(x));
    }
    Ok(sum / 60.0)
};
let mut sweep = Vec::new();
for i in 2..=20 {
    let factor = 0.05 * f64::from(i);
    let kde = build(KdeBandwidth::Factor(factor)).map_err(|e| e.to_string())?;
    sweep.push([factor, simpson_ise(&kde)?]);
}
let best = sweep.iter().fold(
    [0.0, f64::INFINITY],
    |a, p| if p[1] < a[1] { *p } else { a },
```

## Kernel densities truncated to a support interval

For physical quantities restricted to a bounded interval $[a,b]$, ordinary KDE leaks mass outside, integrating to less than 1 inside.
Supplying a support interval (`Interval` per coordinate) through `KdeOptions::with_support` truncates each kernel to the interval and divides by its mass inside, setting density outside to 0.

$$
\hat f(\mathbf x)=\sum_i\frac{w_i}{W}\,\frac{\phi_{\mathbf H}(\mathbf x-\mathbf x_i)\,\mathbf 1\{\mathbf x\in B\}}{\int_B\phi_{\mathbf H}(\mathbf u-\mathbf x_i)\,d\mathbf u}
$$

The denominator is normal probability over box $B$, obtained in closed form as a product of coordinate-wise normal CDF differences.
Truncation therefore requires diagonal $\mathbf H$; combining correlated kernels with a support interval returns an error.
All kernel centers must lie inside the support interval.
`integrate_box(lower, upper)` similarly computes box probabilities for diagonal-kernel estimators from CDF differences (boundaries may be infinite).

Truncation and normalization give unit mass inside but do not eliminate boundary bias.
When $f'\ne0$ at the boundary, this method has boundary bias $O(h)$, larger than the interior $O(h^2)$ (Jones, 1993).
Corrections giving boundary bias $O(h^2)$, such as reflection or boundary kernels, are not provided.

The next cell places truncated kernels with specified standard deviation $h$ at five centers $0.1,0.25,0.5,0.75,0.9$ in the unit interval $[0,1]$.
It compares mass over $[0,1]$ from `integrate_box` with the integral of `pdf` from composite Simpson quadrature on 1024 subintervals, and checks zero density outside at $x=-0.1$.

```rust
//| id: stats-truncated-kde-normalization
//| ref: stats-truncated-kde-normalization
//| title: "Integrate a truncated kernel density with independent grid quadrature"
//| run: reactive
//| crates: [scioxide-core, scioxide-stats]
//| inputs:
//|   bandwidth: {"type":"range","label":"Kernel standard deviation h [-]","description":"Larger values increase the mass adjustment from truncation.","min":0.05,"max":0.4,"step":0.05,"value":0.15}
//| cases:
//|   - {"id":"narrow","label":"h = 0.05","description":"Individual center peaks separate and Simpson error increases.","inputs":{"bandwidth":0.05}}
//|   - {"id":"wide","label":"h = 0.4","description":"Every kernel extends far outside the interval, while mass remains 1.","inputs":{"bandwidth":0.4}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"mass","path":"/rows/0/1","approx":{"value":1,"atol":1e-14}}
//|       - {"artifact":"mass","path":"/rows/2/1","range":{"min":0,"max":1e-9}}
//|       - {"artifact":"mass","path":"/rows/3/1","equals":0}
//|   - case: wide
//|     expect:
//|       - {"artifact":"mass","path":"/rows/0/1","approx":{"value":1,"atol":1e-14}}
use scioxide_core::{Interval, StridedLayout};
use scioxide_stats::{Axis, BatchView, GaussianKde, KdeBandwidth, KdeCovariance, KdeOptions};

let centers = [0.1_f64, 0.25, 0.5, 0.75, 0.9];
let (shape, strides) = ([5_usize], [1_usize]);
let layout = StridedLayout::new(&shape, &strides).map_err(|e| e.to_string())?;
let view = BatchView::new(&centers, layout, Axis::Index(0)).map_err(|e| e.to_string())?;
let widths = [bandwidth];
let support = [Interval::new(0.0, 1.0).map_err(|e| e.to_string())?];
let options = KdeOptions::new()
    .with_bandwidth(KdeBandwidth::StandardDeviations(&widths))
    .with_covariance(KdeCovariance::Diagonal)
    .with_support(Some(&support));
let kde = GaussianKde::with_options(view, 0, options).map_err(|e| e.to_string())?;
// Independent check: integrate density on [0, 1] using composite Simpson quadrature with 1024 subintervals.
let n = 1024_usize;
let (mut sum, mut curve) = (0.0_f64, Vec::new());
for i in 0..=n {
    let x = i as f64 / n as f64;
    let value = kde.pdf(&[x]).map_err(|e| e.to_string())?;
    let weight = if i == 0 || i == n {
        1.0
    } else if i % 2 == 0 {
        2.0
    } else {
        4.0
    };
    sum += weight * value;
    if i % 8 == 0 {
        curve.push([x, value]);
    }
}
let simpson = sum / (3 * n) as f64;
let analytic = kde
    .integrate_box(&[0.0], &[1.0])
    .map_err(|e| e.to_string())?;
let outside = kde.pdf(&[-0.1]).map_err(|e| e.to_string())?;
let (lowest, highest) = curve.iter().fold((f64::INFINITY, 0.0_f64), |(lo, hi), p| {
    (lo.min(p[1]), hi.max(p[1]))
});
emit_line_chart!(
    &vec![serde_json::json!({ "name": "Truncated kernel density", "points": curve })],
    options = &serde_json::json!({
        "xLabel": "Coordinate x [-]",
        "yLabel": "Probability density [1/unit]",
        "xMin": 0.0,
        "xMax": 1.0,
        "yMin": 0.0,
        "yMax": 3.0,
        "annotations": [{ "kind": "line", "axis": "y", "value": 1.0, "label": "Uniform density" }]
    })
);
let fixed15 = serde_json::json!({ "fractionDigits": 15 });
let columns = serde_json::json!([
    { "key": "0", "label": "Quantity" },
    { "key": "1", "label": "Value [-]", "type": "number", "format": fixed15 }
]);
let rows = vec![
    ("Mass on [0, 1] from integrate_box", analytic),
    ("Mass on [0, 1] from Simpson quadrature", simpson),
    ("Absolute difference between masses", (simpson - analytic).abs()),
    ("Density outside at x = −0.1", outside),
    ("Minimum grid density", lowest),
    ("Maximum grid density", highest),
];
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "mass" })
);
```

At the default $h=0.15$, mass on `integrate_box` is 1, differing from Simpson quadrature by $2.9\times10^{-12}$; density outside at $x=-0.1$ is 0.
Density ranges from 0.711 to 1.174.
At $h=0.05$, individual center peaks separate and the density range widens to 0.140–1.652; the Simpson difference increases to $3.6\times10^{-11}$.
At $h=0.4$, every kernel extends far outside the interval, but renormalization keeps mass at 1.

## Summary

PAVA reaches the exact isotonic solution in finitely many $O(n)$ steps; each block value can be checked as a closed-form weighted mean.
Zero-weight observations are omitted without reading values, and the omitted count remains in `IsotonicDiagnostics::excluded`.
Binning relative frequencies divide by all accepted mass including out-of-range observations; densities divide by inside mass and bin volume, giving different sums for samples with out-of-range observations.
KDE factors `Scott` and `Silverman` are rules tuned to unimodal normal distributions and oversmooth bimodal data; when multimodality is suspected, specify bandwidth anew with `Factor` or `StandardDeviations`.
Truncated kernels give unit mass for quantities with bounded support, but boundary bias of order $O(h)$ remains.
