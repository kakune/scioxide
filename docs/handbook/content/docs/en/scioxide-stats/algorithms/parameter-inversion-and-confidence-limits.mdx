A distribution's tail probability $P_\theta(X \le x)$ is used as a function of the parameter $\theta$ as well as of $x$.
“What rate makes the probability of observing no more than this count equal to 2.5%?”
and “How many items must be inspected to detect a defect with 95% probability?”
both lead to equations that solve a tail probability for a parameter.
This page first formulates this inversion for continuous and integer parameters, explains the monotonicity that determines uniqueness, and describes how to handle absent or inconclusive solutions.
It then uses inversion to invert tests and obtain confidence limits for a binomial success probability (Clopper–Pearson), a Poisson rate (Garwood), a normal variance, and noncentrality parameters of noncentral distributions.
Exact coverage calculations show why “exact” limits for discrete distributions are conservative.
[Distribution fitting and the observed information matrix](../distribution-fitting-and-confidence-limits/) covers fitting distribution parameters to a sample to obtain point estimates and asymptotic standard errors.
[Call forms](oxref:stats-execution-forms) defines the call forms (one-shot functions, detailed forms, and scoped forms).

## Parameter inversion from probabilities

A distribution's tail probability can also be viewed as a function of its parameters.
“What parameter gives $P(X \le x) = p$?”
is an equation for a parameter, distinct from quantile inversion (which solves for $x$).
Confidence limits by test inversion, sample sizes that achieve a target power, and degrees of freedom that give a specified probability all lead to equations of this form.

### Continuous parameters

For a function $g(\theta) = \ln P_\theta(\text{tail})$ and target $p$, solve the following equation on a finite interval $[\theta_a, \theta_b]$:

$$
g(\theta) = \ln p
$$


The target is represented by `ParameterProbability`: `new(p, side)` accepts $p \in (0, 1)$, and `from_log(ln_p, side)` accepts a finite negative logarithm.
Storing the target as a logarithm allows tail probabilities smaller than $10^{-300}$.
`side` is a `TailSide`: `Lower` denotes the lower tail $P(X \le x)$, and `Upper` denotes the upper tail $P(X > x)$.

Uniqueness depends on the monotonicity of $g$.
`ParameterMonotonicity` declares the direction of $g$ over the entire interval (`Increasing`, `Decreasing`, `Constant`, or `Unknown`); the solver trusts this declaration and checks for contradictions only at the endpoints.
The declaration must be established analytically; it must not be inferred from trial evaluations.

`invert_parameter_scoped(log_tail, bracket, target, monotonicity, options, scope)` proceeds as follows.

1. For `Unknown`, return `Inconclusive` without evaluating $g$.
2. Evaluate $g$ at both endpoints.
   For `Constant`, return `InvalidInput` if the endpoint values differ, the entire interval `Multiple(interval)` if they equal the target, and `NoSolution` otherwise.
3. Return `Inconclusive` if the endpoint values are equal, `InvalidInput` if their ordering contradicts the declaration, and `NoSolution` if the target lies outside the endpoint values.
4. Shrink the interval by bisection using only strict comparisons of the sign of $g(\theta) - \ln p$.
5. On convergence, evaluate $g$ at the solution and both endpoints of the final interval to compute the logarithmic residual $g(\hat\theta) - \ln p$ and the divided difference (slope) over the interval.

Because bisection uses only signs, it can proceed even where the tail probability rounds to 0 and $g = -\infty$.
Bisection stops according to the root settings in `InversionOptions` from `scioxide-random` (interval-width tolerances, with absolute and relative defaults of $\varepsilon$, and an iteration limit of 4096); `InversionOptions::work_budget` limits the total number of evaluations (default 65,536).
This work limit counts calls to $g$, excluding iterations inside $g$.
For named parameters, `LawOptions` separately controls the limits for evaluations that iterate internally, such as F and noncentral distribution tails (next section).

The resulting `ParameterInversionReport` contains the solution set `solution()`, the bisection result `root()` (a `RootResult` from `scioxide-rootfind`, or `None` if determined without bisection), and the tail evaluation count `evaluations()`.
The solution set `ParameterSolution` has four variants.

- `Unique { value, bracket, log_residual, log_tail_slope }`: a unique solution, or the best approximation if bisection stops early.
  `bracket` is the final interval, but rounding errors in the tail can place the true solution outside it; it is not a guaranteed enclosure.
  `log_residual` and `log_tail_slope` are `Some` only when bisection converges; the slope is `None` if it is zero or nonfinite.
- `Multiple(interval)`: the tail is constant and equal to the target, so every parameter in the interval is a solution.
- `NoSolution`: the target lies outside the tail's range on the interval.
- `Inconclusive`: monotonicity is `Unknown`, or the endpoint tail values are equal.

Even `Unique` is an unconverged approximation if the termination status in `root()` does not indicate success.
The residual and slope estimate the error magnitude as $|\hat\theta - \theta^*| \approx |\mathrm{residual}/\mathrm{slope}|$, but once the final interval shrinks to the rounding level, rounding errors dominate the divided difference itself; use it only as a rough indication of the number of accurate digits.

Errors are `InvalidInput` for infinite interval endpoints, NaN or positive values returned by $g$, or endpoint values that contradict the monotonicity declaration; `ConvergenceFailure` (`EvaluationLimit`) for reaching the work limit during endpoint or final evaluations; and `ExecutionStopped` for cancellation or a deadline before bisection starts.
If the work limit is reached or cancellation occurs during bisection, the result is `Unique` with the last interval and an unsuccessful termination status, rather than an error.

There are three call forms.
The one-shot function `invert_parameter(log_tail, lower, upper, target, monotonicity)` accepts two numbers for the interval, uses the default `InversionOptions`, and returns `ConvergenceFailure` if bisection does not converge.
The detailed form `invert_parameter_with_options(log_tail, bracket, target, monotonicity, options)` accepts an `Interval` and `InversionOptions`, and returns unsuccessful bisection in a report as well.
The scoped form `invert_parameter_scoped(…, options, scope)` accepts an execution context or parent `SolveContext` last, and counts evaluations against the parent's work limit.

### Named distribution parameters

`ProbabilityParameter` names commonly used distribution parameters.
Each variant selects one unknown parameter and fixes the other parameters and the evaluation point.
`log_tail(parameter, side, resources)` returns the logarithm of the tail; `resources` (`LawOptions` from `scioxide-random`) controls evaluation limits for F and noncentral distributions.
`monotonicity(side)` returns the direction in the table below for the selected tail (reversed for the upper tail).
If the evaluation point is outside the support (such as $x \le 0$ for a gamma distribution), the tail is constant, so it returns `Constant`.

| Variant | Unknown parameter | Direction of the lower tail $P(X \le x)$ |
|---|---|---|
| `GammaShape { x, scale }` | Gamma shape | Decreasing for $x > 0$ |
| `GammaScale { x, shape }` | Gamma scale | Decreasing for $x > 0$ |
| `GammaRate { x, shape }` | Gamma rate (reciprocal of scale) | Increasing for $x > 0$ |
| `BetaAlpha { x, beta }` | First beta shape $\alpha$ | Decreasing for $0 < x < 1$ |
| `BetaBeta { x, alpha }` | Second beta shape $\beta$ | Increasing for $0 < x < 1$ |
| `ChiSquaredDegrees { x }` | Degrees of freedom of the $\chi^2$ distribution | Decreasing for $x > 0$ |
| `StudentTDegrees { x }` | t degrees of freedom | Increasing for $x > 0$, decreasing for $x < 0$, constant for $x = 0$ |
| `FNumeratorDegrees { x, denominator }` | Numerator degrees of freedom of the F distribution | Decreasing when denominator degrees of freedom equal 2; `Unknown` otherwise |
| `FDenominatorDegrees { x, numerator }` | Denominator degrees of freedom of the F distribution | Increasing when numerator degrees of freedom equal 2; `Unknown` otherwise |
| `ChiSquaredNoncentrality { x, degrees }` | Noncentral $\chi^2$ noncentrality $\lambda \ge 0$ | Decreasing for $x > 0$ |
| `FNoncentrality { x, numerator, denominator }` | Noncentral F noncentrality | Decreasing for $x > 0$ |
| `StudentTNoncentrality { x, degrees }` | Noncentral t noncentrality $\delta \in \mathbb{R}$ | Decreasing |
| `BinomialProbability { count, trials }` | Binomial success probability | Decreasing for `count < trials` |
| `PoissonMean { count }` | Poisson mean (not the rate per unit exposure) | Decreasing |

Monotonicity in an F degree-of-freedom parameter is established only when the other degree-of-freedom parameter is 2; otherwise it is `Unknown`, and the solution is `Inconclusive`.
If you can establish monotonicity on your interval, pass its direction to `invert_parameter_scoped` to solve.

`ParameterInversionRequest { model, bracket, target, options, tail_options }` bundles a named equation into one request.
`solve()` calls `invert_parameter_scoped` sequentially, and `solve_scoped(scope)` calls it in the supplied context; monotonicity comes from `model.monotonicity`.
A nonfinite interval or one that exceeds the parameter domain returns `InvalidInput` (negative values are excluded except for noncentral t; shape, scale, rate, and degrees of freedom exclude 0; binomial probability cannot exceed 1).
There is no implicit bracket search; the search stays inside `bracket`.
`invert_parameters_into(requests, execution, output, staging, context)` solves independent requests in parallel and writes reports to `output[i]`.
Each request has its own evaluation limit; absent solutions, interval solutions, and `Inconclusive` are normal reports, but any request with unconverged bisection results in `ConvergenceFailure` (`EvaluationLimit`).
If the lengths of `output` and `staging` do not match the number of requests, the result is `InvalidInput`.

### Integer parameters

For an integer parameter $n$ such as the number of trials, equality need not hold, so the search finds the smallest integer that satisfies an inequality.
On the integer interval `domain.0..=domain.1`, find the smallest $n$ satisfying $g(n) \ge \ln p$ for an increasing tail or $g(n) \le \ln p$ for a decreasing tail.
Weak monotonicity (allowing flat portions) is sufficient.
Evaluating both endpoints before bisection requires at most $\lceil \log_2(\text{number of integers in the interval}) \rceil + 2$ evaluations.

The resulting `IntegerParameterReport` exposes public fields for the solution `solution` and evaluation count `evaluations`.
The solution `IntegerParameterSolution` is `Threshold { first, previous }` with the smallest integer and its predecessor (if in the interval), `All { lower, upper }` if every integer in the interval satisfies the inequality, `None` if none does, or `Inconclusive` if monotonicity is unknown.
The call forms are the one-shot function `invert_integer_parameter(log_tail, domain, target, monotonicity)`, the detailed form `invert_integer_parameter_with_options` accepting `InversionOptions`, and the scoped form `invert_integer_parameter_scoped`.
Unlike the continuous case, only the evaluation limit in `InversionOptions` is used, not its root settings.
A reversed interval gives `InvalidInput`, and reaching the work limit gives `ConvergenceFailure` (`EvaluationLimit`).

`IntegerProbabilityParameter` represents named integer parameters.
`BinomialTrials { count, probability }` is the binomial number of trials; `NegativeBinomialShape { count, probability }` is $r$ in the distribution of the number of failures before the $r$th success.
For both, the lower tail $P(X \le \mathrm{count})$ decreases as the integer parameter increases, so the search finds the smallest parameter satisfying $P(X \le \mathrm{count}) \le p$ for a lower-tail target or $P(X > \mathrm{count}) \ge p$ for an upper-tail target.
For example, the number of inspections required to “detect at least one defect with probability at least $1-\beta$” in a process with defect probability $q$ is obtained using `BinomialTrials { count: 0, probability: q }` with the lower-tail target $\beta$, agreeing with the closed form $\lceil \ln\beta / \ln(1-q) \rceil$.
The methods are `solve(domain, target)` (default `InversionOptions`), `solve_with_options(domain, target, options)`, and `solve_scoped(domain, target, options, scope)`.
A probability outside $[0, 1]$ gives `InvalidInput`; for the negative binomial, probability 0, `domain.0 = 0`, or `domain.1` exceeding $2/\varepsilon$ ($2^{53}$ for f64) also gives `InvalidInput`.
`IntegerParameterInversionRequest { model, domain, target, options }` and `invert_integer_parameters_into` solve independent integer requests in parallel.

### Inversion examples and closed forms

The next cell uses the inversion functions directly and compares them with closed forms.
The first row uses `ParameterInversionRequest` to solve the `PoissonMean { count: k }` equation $P(X \le k; \mu) = (1-c)/2$ on $[0, 1000]$.
This solution equals the closed form $\mu = \chi^2_{(1+c)/2}(2k+2)/2$ using a $\chi^2$ quantile (the Garwood upper limit below multiplied by exposure); the reference slope is $\frac{d}{d\mu}\ln P(X \le k;\mu) = -P(X = k;\mu)/P(X \le k;\mu)$.
The second row uses `IntegerProbabilityParameter::BinomialTrials` on the integer interval $[1, 10^6]$ to find the number of inspections needed to detect at least one defect with probability at least $c$ in a process with a 1% defect probability, and compares it with $\lceil \ln(1-c)/\ln 0.99 \rceil$.

The slope $-0.75$, however, differs from the reference value $-0.6997$ by 7%.

## Computing confidence limits by parameter inversion

### Test inversion

A confidence set can be constructed by testing the null hypothesis $H_0: \theta = \theta_0$ at level $\alpha$ for each $\theta_0$ and collecting the values $\theta_0$ that are not rejected (Casella–Berger §9.2).
If the test keeps the type I error probability at most $\alpha$ for every $\theta_0$, the resulting set contains the true $\theta$ with probability at least $1-\alpha$.

When the distribution function $F(t;\theta)$ of a statistic $T$ decreases monotonically in $\theta$ (larger $\theta$ makes larger $T$ more likely), the endpoints of the two-sided confidence set $[\theta_L, \theta_U]$ for the observation $t$ solve the equations that place probability $\alpha/2$ in each tail:

$$
P_{\theta_L}(T \ge t) = \frac{\alpha}{2}, \qquad P_{\theta_U}(T \le t) = \frac{\alpha}{2}
$$


Writing the confidence coefficient as $c = 1 - \alpha$, `TestAlternative::TwoSided` places $(1-c)/2$ in each tail.
`Greater` computes only the lower confidence limit, and the set extends to the upper end of the parameter domain.
`Less` computes only the upper confidence limit, and the set extends to the lower end.
For a one-sided limit, the tail probability is $1-c$.

For a continuous statistic, solving the equations gives coverage exactly $c$; for a discrete statistic such as a binomial or Poisson count, $P_\theta(T \ge t)$ takes only discrete values as $t$ varies.
Intervals obtained by test inversion, called exact limits, therefore have coverage at least $c$ for every $\theta$ but are conservative, exceeding $c$ at many values of $\theta$.
“Exact” here means constructed from the sampling distribution without approximation, not coverage exactly $c$.

### Confidence-limit functions

The resulting `ParameterConfidenceLimits` contains the confidence set `set()` (a `ExtendedInterval` from `scioxide-core`, including endpoints and possibly empty or unbounded), the nominal confidence coefficient `confidence()`, the alternative hypothesis of the inverted test `alternative()`, the total tail evaluation count for both endpoints `evaluations()`, and the inversion reports `lower_report()` and `upper_report()` for the endpoints.
If an endpoint is a domain boundary (such as the lower limit 0 for zero successes) or the set is empty, its report is `None`.
Coverage is nominal under the assumed sampling distribution.

The general functions accept the logarithm of the statistic's distribution function, `log_cdf(θ)` $= \ln F(t;\theta)$.
`log_cdf` must be strictly monotone on the domain `domain`; pass its direction through `direction` (`Increasing` or `Decreasing`).
The search interval `bracket` must contain every limit that is not a domain boundary; a limit outside the interval but inside the domain produces `InvalidInput` rather than being treated as a boundary.
If an endpoint equation has no solution in the domain, the limit becomes a domain boundary or the set is empty.
An endpoint without a unique solution or with unconverged bisection gives `ConvergenceFailure`.
Both endpoints share the evaluation limit.

| Call | Confidence coefficient and alternative | Interval argument |
|---|---|---|
| `invert_confidence_limits(log_cdf, domain, lower, upper, direction)` | Two-sided 95% | Two numbers |
| `invert_confidence_limits_with_options(log_cdf, domain, bracket, confidence, alternative, direction, options)` | Specified | `Interval` |
| `invert_confidence_limits_scoped(…, options, scope)` | Specified | `Interval`, with context last |

Dedicated functions cover commonly used models.
All one-shot functions use two-sided 95% limits and default `InversionOptions`; the detailed forms `*_with_options` accept `ConfidenceProbability`, `TestAlternative`, and `InversionOptions`, while the scoped forms `*_scoped` (`binomial_confidence_limits_scoped`, `poisson_rate_confidence_limits_scoped`, `normal_variance_confidence_limits_scoped`, `noncentrality_confidence_limits_scoped`) accept the execution context last.

- Binomial success probability (Clopper–Pearson): `binomial_confidence_limits(successes, trials)`.
  With $k$ successes in $X \sim \mathrm{Bin}(n, p)$, the lower limit solves $P(X \ge k; p_L) = \alpha/2$ and the upper limit solves $P(X \le k; p_U) = \alpha/2$.
  For $k = 0$ the lower limit is 0, and for $k = n$ the upper limit is 1; these require no equation solve.
  Using beta quantiles, these are $p_L = B^{-1}(\alpha/2; k, n-k+1)$ and $p_U = B^{-1}(1-\alpha/2; k+1, n-k)$.
  The interval is fixed at $[0, 1]$; zero trials or more successes than trials gives `InvalidInput`.
- Poisson rate (Garwood): `poisson_rate_confidence_limits(count, exposure, lower, upper)`.
  For $k$ events during exposure $E$, let $X \sim \mathrm{Poisson}(\lambda E)$; the limits for rate $\lambda$ solve $P(X \ge k; \lambda_L E) = \alpha/2$ and $P(X \le k; \lambda_U E) = \alpha/2$, or, in terms of $\chi^2$ quantiles, are $\lambda_L = \chi^2_{\alpha/2}(2k)/(2E)$ and $\lambda_U = \chi^2_{1-\alpha/2}(2k+2)/(2E)$.
  For $k = 0$, the lower limit is 0.
  The caller chooses the rate search interval `[lower, upper]` to contain the limits.
  Exposure that is not finite and positive gives `InvalidInput`.
- Normal variance: `normal_variance_confidence_limits(scatter, degrees, lower, upper)`.
  For the sum of squared deviations $Q = \sum (x_i - \bar x)^2$ and degrees of freedom $\nu$ (usually $n-1$), $Q/\sigma^2 \sim \chi^2(\nu)$, giving limits $[Q/\chi^2_{1-\alpha/2}(\nu),\; Q/\chi^2_{\alpha/2}(\nu)]$.
  If $Q$ is not finite and positive, or the lower interval endpoint is at most 0, the result is `InvalidInput`.
- Noncentrality: `noncentrality_confidence_limits(model, lower, upper)`.
  `model` is one of `StudentTNoncentrality`, `ChiSquaredNoncentrality`, or `FNoncentrality` from `ProbabilityParameter`, carrying the observed statistic and degrees of freedom.
  The domain is the entire real line for noncentral t and $[0, \infty)$ for the others.
  The detailed and scoped forms also accept `LawOptions` to limit each tail evaluation.
  Use these for confidence intervals for effect sizes (such as a standardized mean difference interval from an observed t statistic).

This family does not provide approximate intervals other than test-inversion intervals, such as Wilson, Agresti–Coull, mid-p corrections, or likelihood-ratio intervals.
If an interval with average coverage near the nominal value is needed, the equal-tailed credible interval from the Jeffreys prior compared below can be constructed with `credible_interval` in [Conjugate priors and Bayesian updating](../bayesian-conjugate-updates/).

### Coverage for discrete distributions

For the binomial success probability, compare the Clopper–Pearson interval, the normal-approximation Wald interval $\hat p \pm z_{1-\alpha/2}\sqrt{\hat p(1-\hat p)/n}$, and the equal-tailed credible interval under the Jeffreys prior $\mathrm{Beta}(1/2, 1/2)$.
Under the true value $p$, the coverage probability of interval $C(k)$ is

$$
\mathrm{cov}(p) = \sum_{k=0}^{n} \binom{n}{k} p^k (1-p)^{n-k}\, \mathbf{1}\{p \in C(k)\}
$$

and can be computed exactly without simulation (Brown, Cai, and DasGupta 2001).
The next cell tabulates the three intervals at input $k$ and $n$, constructs every interval for $k = 0, \dots, n$, and plots coverage for $p = 0.005, 0.010, \dots, 0.995$.
As an independent check of Clopper–Pearson, beta quantiles $B^{-1}(\alpha/2; k, n-k+1)$ and $B^{-1}(1-\alpha/2; k+1, n-k)$ are computed with `Beta::quantile` from `scioxide-random` and displayed alongside.
Wald intervals are shown without clipping to $[0, 1]$.

```rust

//| ref: stats-confidence-inversion
//| title: "Compare Clopper–Pearson limits and coverage for a binomial success probability with Wald and Jeffreys intervals"
//| run: reactive
//| crates: [scioxide-core, scioxide-random, scioxide-stats]
//| inputs:
//|   k: {"type":"range","label":"Success count k [count]","min":0,"max":30,"step":1,"value":7}
//|   n: {"type":"range","label":"Number of trials n [trials]","min":30,"max":100,"step":1,"value":30}
//|   conf: {"type":"range","label":"Confidence coefficient c [-]","min":0.8,"max":0.99,"step":0.01,"value":0.95}
//| cases:
//|   - {"id":"zero","label":"k = 0","description":"The Clopper–Pearson lower limit is 0, and the Wald interval collapses to zero width.","inputs":{"k":0}}
//|   - {"id":"all","label":"k = n = 30","description":"The upper limit is 1, so only the lower-limit equation is solved.","inputs":{"k":30}}
//|   - {"id":"large","label":"n = 100, c = 0.9","description":"Wald undercoverage remains near the boundary of p even for large n.","inputs":{"n":100,"conf":0.9}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"intervals","path":"/rows/0/1","approx":{"value":0.0993378649580198,"rtol":1e-9}}
//|       - {"artifact":"intervals","path":"/rows/0/4","approx":{"value":0.0993378649580198,"rtol":1e-9}}
//|       - {"artifact":"intervals","path":"/rows/0/2","approx":{"value":0.422836522978220,"rtol":1e-9}}
//|       - {"artifact":"intervals","path":"/rows/2/1","approx":{"value":0.110920907158253,"rtol":1e-9}}
//|       - {"artifact":"coverage","path":"/rows/0/1","range":{"min":0.95}}
//|       - {"artifact":"coverage","path":"/rows/1/2","approx":{"value":0.879254152714465,"rtol":1e-9}}
//|       - {"artifact":"coverage","path":"/rows/2/2","approx":{"value":0.950832660908552,"rtol":1e-9}}
//|   - case: zero
//|     expect:
//|       - {"artifact":"intervals","path":"/rows/0/1","equals":0}
//|       - {"artifact":"intervals","path":"/rows/0/2","approx":{"value":0.115703308222028,"rtol":1e-9}}
//|       - {"artifact":"intervals","path":"/rows/1/3","equals":0}
//|   - case: all
//|     expect:
//|       - {"artifact":"intervals","path":"/rows/0/1","approx":{"value":0.884296691777972,"rtol":1e-9}}
//|       - {"artifact":"intervals","path":"/rows/0/2","equals":1}
//|   - case: large
//|     expect:
//|       - {"artifact":"coverage","path":"/rows/0/1","range":{"min":0.9}}
//|       - {"artifact":"coverage","path":"/rows/1/1","approx":{"value":0.392556295986216,"rtol":1e-9}}
use scioxide_random::{Beta, Binomial, InversionOptions, Mass, Quantile};
use scioxide_stats::{
    BetaBinomialPrior, ConfidenceProbability, TestAlternative,
    binomial_confidence_limits_with_options, credible_interval,
};

let (k, n) = (k as usize, n as usize);
let c = ConfidenceProbability::new(conf).map_err(|e| e.to_string())?;
let options = InversionOptions::<f64>::default();
let z: f64 = c.normal_critical_value().map_err(|e| e.to_string())?;
// All intervals (lower, upper) for k = 0, …, n, and the Clopper–Pearson evaluation counts
let mut clopper = Vec::with_capacity(n + 1);
let mut wald = Vec::with_capacity(n + 1);
let mut jeffreys = Vec::with_capacity(n + 1);
for j in 0..=n {
    let limits =
        binomial_confidence_limits_with_options(j, n, c, TestAlternative::TwoSided, &options)
            .map_err(|e| e.to_string())?;
    let (lower, upper) = limits.set().bounds().ok_or("Empty confidence set")?;
    let (lower, upper) = (lower.ok_or("Missing lower bound")?, upper.ok_or("Missing upper bound")?);
    clopper.push((lower, upper, limits.evaluations()));
    let p_hat = j as f64 / n as f64;
    let half = z * scioxide_core::RealScalar::sqrt(p_hat * (1.0 - p_hat) / n as f64);
    wald.push((p_hat - half, p_hat + half));
    let posterior = BetaBinomialPrior::new(0.5, 0.5).and_then(|prior| prior.update(j, n));
    let law = posterior
        .and_then(|post| post.posterior_law())
        .map_err(|e| e.to_string())?;
    let bounds = credible_interval(&law, c, &options)
        .map_err(|e| e.to_string())?
        .bounds();
    jeffreys.push((bounds.lower(), bounds.upper()));
}
// Check: Clopper–Pearson can be expressed using beta quantiles (at k = 0 and k = n, endpoints are domain boundaries)
let half_alpha = (1.0 - conf) / 2.0;
let beta_quantile = |a: f64, b: f64, p: f64| Beta::new(a, b).and_then(|law| law.quantile(p));
let reference_lower = if k == 0 {
    0.0
} else {
    beta_quantile(k as f64, (n - k + 1) as f64, half_alpha).map_err(|e| e.to_string())?
};
let reference_upper = if k == n {
    1.0
} else {
    beta_quantile((k + 1) as f64, (n - k) as f64, 1.0 - half_alpha)
        .map_err(|e| e.to_string())?
};
let (cp, wd, jf) = (clopper[k], wald[k], jeffreys[k]);
let rows = vec![
    (
        "Clopper–Pearson",
        cp.0,
        cp.1,
        cp.1 - cp.0,
        Some(reference_lower),
        Some(reference_upper),
        Some(cp.2),
    ),
    ("Wald", wd.0, wd.1, wd.1 - wd.0, None, None, None),
    ("Jeffreys", jf.0, jf.1, jf.1 - jf.0, None, None, None),
];
let fixed5 = serde_json::json!({ "fractionDigits": 5 });
let columns = serde_json::json!([
    { "key": "0", "label": "Interval" },
    { "key": "1", "label": "Lower limit [-]", "type": "number", "format": fixed5 },
    { "key": "2", "label": "Upper limit [-]", "type": "number", "format": fixed5 },
    { "key": "3", "label": "Width [-]", "type": "number", "format": fixed5 },
    { "key": "4", "label": "Beta-quantile lower limit [-]", "type": "number", "format": fixed5, "nullText": "－" },
    { "key": "5", "label": "Beta-quantile upper limit [-]", "type": "number", "format": fixed5, "nullText": "－" },
    { "key": "6", "label": "Tail evaluations", "type": "integer", "nullText": "－" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "intervals" })
);

// Exact coverage cov(p) = Σ_k P(X = k; p) 1{p ∈ C(k)}
let mut curves = [Vec::new(), Vec::new(), Vec::new()];
for i in 1..200 {
    let p = i as f64 / 200.0;
    let law = Binomial::new(n, p).map_err(|e| e.to_string())?;
    let mut coverage = [0.0; 3];
    for j in 0..=n {
        let mass = law.pmf(j).map_err(|e| e.to_string())?;
        let intervals = [(clopper[j].0, clopper[j].1), wald[j], jeffreys[j]];
        for (sum, (lower, upper)) in coverage.iter_mut().zip(intervals) {
            if lower <= p && p <= upper {
                *sum += mass;
            }
        }
    }
    for (curve, value) in curves.iter_mut().zip(coverage) {
        curve.push([p, value]);
    }
}
let names = ["Clopper–Pearson", "Wald", "Jeffreys"];
let summary: Vec<_> = names
    .iter()
    .zip(&curves)
    .map(|(name, curve)| {
        let low = curve.iter().fold(1.0_f64, |m, point| m.min(point[1]));
        let mean = curve.iter().map(|point| point[1]).sum::<f64>() / curve.len() as f64;
        (*name, low, mean)
    })
    .collect();
let summary_columns = serde_json::json!([
    { "key": "0", "label": "Interval" },
    { "key": "1", "label": "Minimum coverage [-]", "type": "number", "format": fixed5 },
    { "key": "2", "label": "Coverage averaged over p [-]", "type": "number", "format": fixed5 }
]);
emit_table_with_columns!(
    summary_columns,
    summary,
    metadata = serde_json::json!({ "id": "coverage" })
);
let series: Vec<_> = names
    .iter()
    .zip(&curves)
    .map(|(name, curve)| serde_json::json!({ "name": name, "points": curve }))
    .collect();
emit_line_chart!(
    &series,
    options = &serde_json::json!({
        "xLabel": "True success probability p [-]",
        "yLabel": "Coverage probability [-]",
        "annotations": [{"kind": "line", "axis": "y", "value": conf, "label": "Nominal confidence coefficient c"}]
    })
);
```

With the defaults ($k = 7$, $n = 30$, $c = 0.95$), the Clopper–Pearson interval $[0.09934, 0.42284]$ agrees with the beta quantiles to at least 14 digits; inversion at the two endpoints uses 122 tail evaluations in total.
The Wald interval $[0.0820, 0.3847]$ and Jeffreys interval $[0.1109, 0.4044]$ are both narrower than the Clopper–Pearson interval.
In the coverage plot, the Clopper–Pearson curve stays above the nominal line for every $p$, with a minimum of 0.9538 and an average over $p$ of 0.9737.
Wald coverage averages 0.879 and falls to 0.14 when $p$ is near 0 or 1.
Jeffreys coverage averages 0.951, close to nominal, but falls to 0.889 near the boundaries; it does not guarantee nominal coverage for every $p$.
The coverage curves are sawtoothed because the set of $k$ whose intervals contain the parameter changes discretely as $p$ varies.

For “k = 0,” the Clopper–Pearson lower limit is the domain boundary 0, leaving only the upper limit 0.1157 to invert, so the evaluation count halves to 61.
The Wald standard error is 0 at $\hat p = 0$, collapsing the interval to the zero-width $[0, 0]$.
For “k = n = 30,” the upper limit is instead 1.
Even for “n = 100, c = 0.9,” the minimum Wald coverage is 0.39; increasing the sample leaves undercoverage near the boundary values of $p$.
Choose Clopper–Pearson when nominal coverage must hold for all $p$; choose Jeffreys when balancing average coverage and width is the priority.
Use Wald intervals only as approximations when $n\hat p(1-\hat p)$ is sufficiently large.

### Checking against closed forms

The next cell computes two-sided limits for a Poisson rate, a normal variance, and noncentral t noncentrality, and checks them against closed forms and endpoint tail probabilities.
For Poisson, $k$ failures are observed during exposure $E = 1000$ h; the rate search interval is $[0, 1]$ /h.
For normal variance, 10 measurements have a sum of squared deviations of $Q = 12$ mm² ($\nu = 9$); for noncentral t, the observed value is $t = 2.5$ with 10 degrees of freedom; the search intervals are $[0.01, 100]$ mm² and $[-10, 10]$, respectively.
The table's “upper-tail probability at lower limit” is $P_{\theta_L}(T \ge t)$, and “lower-tail probability at upper limit” is $P_{\theta_U}(T \le t)$; both should equal $(1-c)/2$.
The closed-form references use $\chi^2$ quantiles computed with `ChiSquared::quantile`; noncentral t has no closed form.

```rust
//| id: stats-distribution-fitting-and-confidence-limits-api-2
//| ref: stats-distribution-fitting-and-confidence-limits-api-2
//| title: "Check confidence limits for a Poisson rate, normal variance, and noncentrality against closed forms and endpoint tail probabilities"
//| run: reactive
//| crates: [scioxide-core, scioxide-random, scioxide-stats]
//| inputs:
//|   k: {"type":"range","label":"Failure count k [count]","min":0,"max":20,"step":1,"value":3}
//|   conf: {"type":"range","label":"Confidence coefficient c [-]","min":0.8,"max":0.99,"step":0.01,"value":0.95}
//| cases:
//|   - {"id":"zero","label":"k = 0","description":"The Poisson lower limit is the domain boundary 0, so no equation is solved.","inputs":{"k":0}}
//|   - {"id":"high","label":"c = 0.99","description":"All intervals widen.","inputs":{"conf":0.99}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"limits","path":"/rows/0/1","approx":{"value":6.186721228956e-4,"rtol":1e-9}}
//|       - {"artifact":"limits","path":"/rows/0/3","approx":{"value":6.186721228956e-4,"rtol":1e-9}}
//|       - {"artifact":"limits","path":"/rows/0/5","approx":{"value":0.025,"rtol":1e-9}}
//|       - {"artifact":"limits","path":"/rows/1/2","approx":{"value":4.443803384692,"rtol":1e-9}}
//|       - {"artifact":"limits","path":"/rows/2/1","approx":{"value":0.2145640243388,"rtol":1e-6}}
//|       - {"artifact":"limits","path":"/rows/2/6","approx":{"value":0.025,"rtol":1e-9}}
//|   - case: zero
//|     expect:
//|       - {"artifact":"limits","path":"/rows/0/1","equals":0}
//|       - {"artifact":"limits","path":"/rows/0/5","equals":null}
//|       - {"artifact":"limits","path":"/rows/0/2","approx":{"value":3.688879454114e-3,"rtol":1e-9}}
//|   - case: high
//|     expect:
//|       - {"artifact":"limits","path":"/rows/1/1","approx":{"value":0.5087041229441,"rtol":1e-9}}
use scioxide_core::Interval;
use scioxide_random::{
    ChiSquared, InversionOptions, LawOptions, LogCdf, LogMass, LogSurvival, NoncentralStudentT,
    Poisson, Quantile,
};
use scioxide_stats::{
    ConfidenceProbability, IntegerParameterSolution, IntegerProbabilityParameter,
    ParameterConfidenceLimits, ParameterInversionRequest, ParameterProbability,
    ParameterSolution, ProbabilityParameter, TailSide, TestAlternative,
    noncentrality_confidence_limits_with_options,
    normal_variance_confidence_limits_with_options,
    poisson_rate_confidence_limits_with_options,
};

let count = k as usize;
let c = ConfidenceProbability::new(conf).map_err(|e| e.to_string())?;
let options = InversionOptions::<f64>::default();
let two_sided = TestAlternative::TwoSided;
let half_alpha = (1.0 - conf) / 2.0;
let (exposure, scatter, nu, t_obs, t_nu) = (1000.0, 12.0, 9.0, 2.5, 10.0);
let interval = |a: f64, b: f64| Interval::new(a, b).map_err(|e| e.to_string());
let poisson = poisson_rate_confidence_limits_with_options(
    count,
    exposure,
    interval(0.0, 1.0)?,
    c,
    two_sided,
    &options,
)
.map_err(|e| e.to_string())?;
let variance = normal_variance_confidence_limits_with_options(
    scatter,
    nu,
    interval(0.01, 100.0)?,
    c,
    two_sided,
    &options,
)
.map_err(|e| e.to_string())?;
let model = ProbabilityParameter::StudentTNoncentrality {
    x: t_obs,
    degrees: t_nu,
};
let law_options = LawOptions::default();
let delta = noncentrality_confidence_limits_with_options(
    model,
    interval(-10.0, 10.0)?,
    c,
    two_sided,
    &options,
    law_options,
)
.map_err(|e| e.to_string())?;
let ends = |limits: &ParameterConfidenceLimits<f64>| -> Result<(f64, f64), String> {
    let (lower, upper) = limits.set().bounds().ok_or("Empty confidence set")?;
    Ok((lower.ok_or("Missing lower bound")?, upper.ok_or("Missing upper bound")?))
};
let ((pl, pu), (vl, vu), (dl, du)) = (ends(&poisson)?, ends(&variance)?, ends(&delta)?);
// Endpoint tails: upper P(T ≥ t) at the lower limit, lower P(T ≤ t) at the upper limit
let poisson_tail = |rate: f64, upper_tail: bool| -> Result<Option<f64>, String> {
    let law = Poisson::new(rate * exposure).map_err(|e| e.to_string())?;
    let value = if upper_tail {
        if count == 0 {
            return Ok(None);
        } // The lower limit is a domain boundary; no equation is solved
        law.log_sf(count - 1)
    } else {
        law.log_cdf(count)
    };
    value
        .map(|v| Some(scioxide_core::RealScalar::exp(v)))
        .map_err(|e| e.to_string())
};
let chi = ChiSquared::new(nu).map_err(|e| e.to_string())?;
let chi_cdf = |var: f64| {
    chi.log_cdf(scatter / var)
        .map(scioxide_core::RealScalar::exp)
        .map_err(|e| e.to_string())
};
let nct_cdf = |d: f64| {
    let law =
        NoncentralStudentT::with_options(t_nu, d, law_options).map_err(|e| e.to_string())?;
    law.log_cdf(t_obs)
        .map(scioxide_core::RealScalar::exp)
        .map_err(|e| e.to_string())
};
// Closed-form reference (χ² quantiles)
let chi_quantile = |df: f64, p: f64| {
    ChiSquared::new(df)
        .and_then(|law| law.quantile(p))
        .map_err(|e| e.to_string())
};
let garwood_lower = if count == 0 {
    0.0
} else {
    chi_quantile(2.0 * k, half_alpha)? / (2.0 * exposure)
};
let garwood_upper = chi_quantile(2.0 * k + 2.0, 1.0 - half_alpha)? / (2.0 * exposure);
let rows = vec![
    (
        "Poisson rate [1/h]",
        pl,
        pu,
        Some(garwood_lower),
        Some(garwood_upper),
        poisson_tail(pl, true)?,
        poisson_tail(pu, false)?,
        poisson.evaluations(),
    ),
    (
        "Normal variance [mm²]",
        vl,
        vu,
        Some(scatter / chi_quantile(nu, 1.0 - half_alpha)?),
        Some(scatter / chi_quantile(nu, half_alpha)?),
        Some(1.0 - chi_cdf(vl)?),
        Some(chi_cdf(vu)?),
        variance.evaluations(),
    ),
    (
        "Noncentral t noncentrality [-]",
        dl,
        du,
        None,
        None,
        Some(1.0 - nct_cdf(dl)?),
        Some(nct_cdf(du)?),
        delta.evaluations(),
    ),
];
let sci6 = serde_json::json!({ "notation": "scientific", "significantDigits": 6 });
let columns = serde_json::json!([
    { "key": "0", "label": "Parameter" },
    { "key": "1", "label": "Lower limit", "type": "number", "format": sci6 },
    { "key": "2", "label": "Upper limit", "type": "number", "format": sci6 },
    { "key": "3", "label": "Closed-form lower limit", "type": "number", "format": sci6, "nullText": "No closed form" },
    { "key": "4", "label": "Closed-form upper limit", "type": "number", "format": sci6, "nullText": "No closed form" },
    { "key": "5", "label": "Upper-tail probability at lower limit [-]", "type": "number", "format": sci6, "nullText": "Domain boundary" },
    { "key": "6", "label": "Lower-tail probability at upper limit [-]", "type": "number", "format": sci6 },
    { "key": "7", "label": "Tail evaluations", "type": "integer" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "limits" })
);
```

With the defaults ($k = 3$, $c = 0.95$), the Poisson rate limits $[6.187 \times 10^{-4}, 8.767 \times 10^{-3}]$ /h and normal-variance limits $[0.6308, 4.4438]$ mm² agree to at least 13 digits with the closed forms using $\chi^2$ quantiles.
There is no closed form for the noncentrality limits $[0.2146, 4.6912]$, but every row's endpoint tail probabilities agree with $(1-c)/2 = 0.025$ to at least 12 digits, confirming that the equations are solved.
Each endpoint takes about 60 evaluations because interval-halving bisection continues until the width reaches the $\varepsilon$ level.
For “k = 0,” the lower Poisson rate limit is the domain boundary 0 and no equation is solved, so the endpoint-tail column is blank and the evaluation count is 61.
The upper limit $3.689 \times 10^{-3}$ /h equals $-\ln 0.025 / 1000$.
For “c = 0.99,” all intervals widen, and the lower normal-variance limit falls to 0.5087 mm².

## Summary

To invert a tail probability for a continuous parameter, use `invert_parameter` (or `_with_options` or `_scoped` to supply work limits or a context); for an integer parameter, use `invert_integer_parameter`; pass an analytically established monotonicity direction through `ParameterMonotonicity`.
Named distribution parameters can be solved through `ProbabilityParameter`, `ParameterInversionRequest`, and `IntegerProbabilityParameter` without establishing monotonicity yourself.
Even when the resulting `ParameterSolution` is `Unique`, it is only an approximation unless the termination status in `root()` indicates success; check before use.
Confidence limits for binomial, Poisson, normal-variance, and noncentrality parameters follow from test inversion; choose the search interval to contain every limit that is not a domain boundary.
The discrete Clopper–Pearson and Garwood limits are conservative in exchange for never falling below nominal coverage at any parameter; compare Jeffreys credible intervals when average coverage matters more.
