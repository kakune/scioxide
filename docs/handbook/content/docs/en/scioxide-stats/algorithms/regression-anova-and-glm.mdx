Regression models how the mean of a response $y$ depends on explanatory variables $x$, estimates the coefficients, and assesses their uncertainty.
This page describes five families of regression in scioxide-stats.
Linear regression estimates coefficients by least squares and tests them with classical covariance or heteroskedasticity-robust HC3 covariance.
Analysis of variance (ANOVA) compares nested linear regression models whose explanatory variables are group indicators.
Generalized linear models (GLMs) use link and variance functions for nonnormal responses such as counts and proportions.
Robust regression limits the influence of outliers, and orthogonal distance regression (ODR) handles measurement error in the explanatory variables as well.

Each family has a Plan type (`Prepared*`) that prepares the model and design in advance, and a `fit` method that fits a response.
When only the response changes for a fixed design, prepare once and fit repeatedly.
The families and their types are as follows.

| Family | Plan | Main results | One-shot call |
|---|---|---|---|
| Linear regression (dense design) | `PreparedRegression` | `LinearRegressionFit`, `RegressionContrast` | `ordinary_least_squares`, `linear_regression` |
| Linear regression (operator design) | `PreparedOperatorRegression` | `OperatorRegressionResult` | None |
| Group comparisons | `PreparedGroups` | `GroupTest`, `PostHocResult` | `kruskal_wallis_test`, `friedman_test` |
| GLM | `PreparedGlm`, `PreparedOperatorGlm` | `GlmResult`, `GlmCoefficientInference` | `glm_fit` |
| Robust regression | `PreparedHuber`, `RobustSlopeWorkspace` | `HuberFit`, `RobustSlope` | `huber_location`, `robust_slope` |
| Orthogonal distance regression | `PreparedOdr` | `OdrFit` | `linear_odr` |

## Least-squares regression and rank-deficient design matrices

For $n$ observations, let the response be $y\in\mathbb R^n$, the design matrix of explanatory variables be $X\in\mathbb R^{n\times p}$, and the row weights be $w_i\ge0$, with $W=\mathrm{diag}(w_1,\dots,w_n)$.
Weighted least squares solves the following problem.

$$
\hat\beta=\arg\min_{\beta}\ \|W^{1/2}(y-X\beta)\|_2
$$

If the errors $\varepsilon=y-X\beta$ are uncorrelated with mean 0 and variance $\sigma^2W^{-1}$, then $\hat\beta$ has the smallest variance among linear unbiased estimators (the Gauss–Markov theorem).
If the errors are normal, $\hat\beta$ is also the maximum likelihood estimator, and the $t$ and $F$ tests described below are exact.
The model does not include an intercept automatically; add a column of ones to the design when an intercept is needed.
Choose weights from [`Unweighted`](../weighted-estimation-and-confidence/), `Frequency` (integer replication counts), and `Analytic` (inverse relative variances); rows with weight 0 do not affect the fit.

[`PreparedRegression`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/struct.PreparedRegression.html) copies the design and factorizes $A=W^{1/2}X$ once.
It does not form the normal equations $A^{\mathsf T}A\beta=A^{\mathsf T}W^{1/2}y$.
The condition number of $A^{\mathsf T}A$ is $\kappa(A)^2$, so solving the normal equations amplifies rounding errors by a factor of $\kappa(A)^2$.
Select the factorization with [`RegressionFactorization`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/enum.RegressionFactorization.html).
The default `Auto` uses Householder QR with column pivoting and switches to a thin singular value decomposition (SVD) when $p>n$ or the design is numerically rank deficient.
`Svd` always uses SVD.
Preparation costs $O(np^2)$ with QR, and each subsequent fit costs $O(np)$.

Numerical rank is determined using the threshold specified by [`RankPolicy`](https://docs.rs/scioxide-linalg/0.1.0/scioxide_linalg/enum.RankPolicy.html); the default is a dimension-scaled multiple of $\varepsilon$ (`DimensionScaledEpsilon`).
When the rank is $r<p$, the least-squares solution is not unique: every member of $\hat\beta+\ker A$ gives the same residual.
scioxide-stats treats singular values below the threshold as zero and returns the solution with the smallest norm $\|\beta\|_2$ (the solution from the pseudoinverse $A^{+}$).
Even when the coefficients themselves are not unique, the fitted values $X\hat\beta$, residuals, and estimable linear combinations $c^{\mathsf T}\beta$ (those for which $c$ lies in the row space of $A$) are unique.

Least-squares solutions computed by QR and SVD are backward stable.
The relative error in the coefficients is roughly the sum of $\varepsilon\,\kappa(A)$ and a term $\varepsilon\,\kappa(A)^2\tan\theta$ for large residuals ($\theta$ is the angle between $y$ and the column space of $A$; Golub and Van Loan 2013, Section 5.3).
[`PreparedRegression::condition`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/struct.PreparedRegression.html#method.condition) returns an estimate of the 1-norm condition number for QR and the ratio of the largest to smallest singular values for SVD.
This is an estimate, not an upper bound.

The fit result [`LinearRegressionFit`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/struct.LinearRegressionFit.html) contains the coefficients `coefficients`, fitted values `fitted` (including rows with weight 0), residuals `residuals`, weighted residuals `weighted_residuals`, rank and threshold `rank`, residual degrees of freedom `degrees_of_freedom` ($n_{\text{eff}}-r$), and residual norms `residual_norm` and `weighted_residual_norm`.
`normal_residual_norm` is $\|X^{\mathsf H}W(y-X\hat\beta)\|_2$ and is zero at an exact least-squares solution, so it indicates how closely the computed $\hat\beta$ satisfies the optimality condition.
$n_{\text{eff}}$ is the number of rows for unweighted data, the sum of counts for `Frequency`, and the number of positive-weight rows for `Analytic`.

There are four call forms.
`ordinary_least_squares(design, &y)` is a one-shot call with no weights and default settings.
`plan.fit(&y)` allocates the output and workspace for fitting; `plan.fit_into(&y, &mut output, &mut workspace, context)` writes into a [`RegressionWorkspace`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/struct.RegressionWorkspace.html) created with `output()` and `workspace()` and performs no allocation when the workspace is available.
[`regression_batch_into`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/fn.regression_batch_into.html) fits multiple responses with the same Plan and runs in parallel when the execution context permits.
For a line with one explanatory variable, $y=\beta_0+\beta_1x$, [`linear_regression`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/fn.linear_regression.html) computes $\hat\beta_1=S_{xy}/S_{xx}$ and $\hat\beta_0=\bar y-\hat\beta_1\bar x$ over an extended exponent range in $O(n)$.
The resulting [`LinearRegression`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/struct.LinearRegression.html) returns the slope, intercept, and correlation coefficient through `line()`.
`slope_inference` and `intercept_inference` return $t$ tests and intervals with $n-2$ degrees of freedom, or `None` for two observations (zero degrees of freedom).

### Coefficient tests and covariance (classical and HC3)

[`PreparedRegression::contrast`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/struct.PreparedRegression.html#method.contrast) tests $H_0:c^{\mathsf T}\beta=c_0$ for a contrast vector $c$ and null value $c_0$, returning the estimate $c^{\mathsf T}\hat\beta-c_0$, standard error, p-value, and two-sided confidence interval (for $c^{\mathsf T}\beta$ without subtracting the null value) in [`RegressionContrast`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/struct.RegressionContrast.html).
`coefficient_inference` returns $p$ results, applying a unit-vector contrast to each column.
Select the standard error estimator with [`RegressionCovariance`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/enum.RegressionCovariance.html).

$$
\widehat{\mathrm{Var}}_{\text{classical}}(\hat\beta)=\hat\sigma^2(A^{\mathsf T}A)^{-1},\quad \hat\sigma^2=\frac{\mathrm{RSS}}{n_{\text{eff}}-r},\qquad
\widehat{\mathrm{Var}}_{\text{HC3}}(\hat\beta)=(A^{\mathsf T}A)^{-1}\Big(\sum_i\frac{e_i^2}{(1-h_i)^2}a_ia_i^{\mathsf T}\Big)(A^{\mathsf T}A)^{-1}
$$

Here $a_i^{\mathsf T}$ is row $i$ of $A$, $e_i$ is the weighted residual, and $h_i=a_i^{\mathsf T}(A^{\mathsf T}A)^{-1}a_i$ is the leverage.
Classical estimation assumes equal error variances across observations (homoskedasticity) and uses a $t$ distribution with $n_{\text{eff}}-r$ degrees of freedom for p-values and intervals.
This test is exact for normal, homoskedastic errors.

Under heteroskedasticity, where error variances differ among observations, classical estimation is biased and particularly underestimates standard errors when observations with large variances also have high leverage.
The sandwich estimator (White 1980) estimates the middle matrix from each observation's $e_i^2$ and is consistent without assuming a form for the variance.
Because $e_i^2$ tends to underestimate the true variance at high-leverage observations, HC3 (MacKinnon and White 1985) compensates by multiplying by $(1-h_i)^{-2}$.
HC3 inference uses an asymptotic normal distribution, so small-sample interval coverage may differ from the nominal level; it is slightly below the nominal level in the cell below as well.
Long and Ervin (2000) show by simulation that HC3 is closer to the nominal level than HC0–HC2 for $n<250$.
HC3 returns `InvalidInput` when `Frequency` weights include values other than 1 (expand the rows before passing them), or when any row has leverage 1.

A nonestimable contrast $c$ (outside the row space of $A$) produces `InvalidInput`.
Residual degrees of freedom $n_{\text{eff}}-r$ of zero or less also produce `InvalidInput`.
`contrast` and `compare_nested` require real designs, while fitting itself also accepts complex designs.

Linear regression does not provide covariance robust to both autocorrelation and heteroskedasticity (HAC, such as Newey–West), cluster-robust covariance, or HC0–HC2.
For time-series regression with autocorrelated errors, estimate coefficient standard errors by resampling $(x_t,y_t)$ pairs with the `MovingBlock` design in [Resampling](../resampling/), or model the error autocorrelation with an [ARIMA model](../time-series/).

## Interval coverage under heteroskedasticity

The next cell checks the effect of HC3 through coverage.
Set the explanatory variable to $x_i=1+9u_i^3$ (with $u_i$ equally spaced on $[0,1]$), placing a few high-leverage points at the right end.
The response is $y_i=2+0.5x_i+\sigma(x_i)\varepsilon_i$, the error standard deviation is $\sigma(x)=0.5x^h$, and $\varepsilon_i$ is standard normal.
$h=0$ gives homoskedasticity; increasing $h$ raises the variance at the high-leverage right end.

Because the design is fixed, create `PreparedRegression` once and fit 2000 response sets using the same factorization.
The first table shows the slope estimate and two standard errors for one response set.
As an independent check, compare the classical standard error with the simple-regression closed form $s/\sqrt{S_{xx}}$ (`linear_regression`) and the HC3 standard error with the simple-regression formula $\sqrt{\sum_i d_i^2e_i^2/(1-h_i)^2}\,/S_{xx}$ ($d_i=x_i-\bar x$, $h_i=1/n+d_i^2/S_{xx}$).
The second table shows the proportion of 2000 slope 95% intervals containing the true value 0.5 and its binomial standard error.
The plot shows residuals from the first response set; larger $h$ makes their spread increase to the right.

## Analysis of variance (ANOVA) and group comparisons

For $k$ groups, let their sizes be $n_g$, means $\bar y_g$, variances $s_g^2$, total size $N$, and overall mean $\bar y$.
One-way ANOVA tests the null hypothesis that all group means are equal using the following $F$ statistic.

$$
F=\frac{\sum_g n_g(\bar y_g-\bar y)^2/(k-1)}{\sum_g(n_g-1)s_g^2/(N-k)}
$$

If each group follows a normal distribution with equal variance, $F$ follows an $F$ distribution with $(k-1,N-k)$ degrees of freedom under the null hypothesis.
This test is equivalent to comparing nested linear regression models with group indicators as explanatory variables.
Let $\mathrm{RSS}_f$ and $\mathrm{RSS}_r$ be the residual sums of squares and $r_f$ and $r_r$ the ranks of the full model $y_{gi}=\mu+\alpha_g+\varepsilon_{gi}$ and intercept-only reduced model $y_{gi}=\mu+\varepsilon_{gi}$; the following $F$ equals $F$ above.

$$
F=\frac{(\mathrm{RSS}_r-\mathrm{RSS}_f)/(r_f-r_r)}{\mathrm{RSS}_f/(n_{\text{eff}}-r_f)}
$$

[`PreparedRegression::compare_nested`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/struct.PreparedRegression.html#method.compare_nested) performs this $F$ test, first checking that each column of the reduced model lies in the column space of the full model.
Because degrees of freedom come from the ranks, the full model's design may be rank deficient.
No function constructs ANOVA tables for two or more factors (sequential, Type II, or Type III sums of squares), but constructing design columns by adding one term at a time and calling `compare_nested` in sequence gives $F$ tests for sequential sums of squares.

[`PreparedGroups`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/struct.PreparedGroups.html) stores only each group's size, mean, and variance over an extended exponent range and performs the following tests.
`anova(GroupTestMethod::Anova)` is the $F$ test above, `anova(GroupTestMethod::Welch)` is Welch's (1951) approximate $F$ test without the equal-variance assumption, and `alexander_govern()` is the Alexander–Govern (1994) approximate $\chi^2$ test summing squares of normalized transformations of each group's $t$ statistic.
The resulting `GroupTest` contains the statistic, upper-tail p-value, and degrees of freedom (also the denominator degrees of freedom `denominator_degrees` for an $F$ test).
[`group_tests_into`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/fn.group_tests_into.html) performs the same test on multiple sets of groups.
Rank-based Kruskal–Wallis and Friedman tests are covered in [Classical and rank tests](../classical-tests/).

After an overall test detects a difference, use multiple comparisons to identify which pairs of groups differ.
`pairwise(PostHocMethod::TukeyKramer)` compares every pair assuming equal variances, while `pairwise(PostHocMethod::GamesHowell)` uses Welch–Satterthwaite degrees of freedom for each pair.
Both adjust p-values using the studentized range distribution.
Under normality and equal variances, the Tukey–Kramer method keeps the familywise error rate at or below the nominal level (Hayter 1984); the Games–Howell method is an approximation to this.
`compare_control(control, alternative)` implements Dunnett's method for comparing each group with a control, numerically integrating probabilities from a multivariate $t$ distribution.
`PostHocOptions` sets the numerical integration tolerance and evaluation limit; each comparison's `probability_error` returns an estimate of the p-value error, not an upper bound.

### Operator regression (LSQR and LSMR)

A large sparse design matrix or an operator that computes products without forming a matrix cannot be factorized with QR or SVD.
[`PreparedOperatorRegression`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/struct.PreparedOperatorRegression.html) borrows the design as a `AdjointOperator` (an operator providing only the products $Xv$ and $X^{\mathsf H}u$) and solves the least-squares problem by a Krylov subspace method.
`Lsqr` (Paige and Saunders 1982) in [`OperatorRegressionMethod`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/enum.OperatorRegressionMethod.html) is equivalent to applying conjugate gradients to the normal equations, and the residual $\|r\|_2$ decreases monotonically.
`Lsmr` (Fong and Saunders 2011) is equivalent to applying MINRES to the normal equations, and $\|A^{\mathsf H}r\|_2$ decreases monotonically.
Both use Golub–Kahan bidiagonalization; each iteration requires one product with $X$, one with $X^{\mathsf H}$, and $O(n+p)$ operations.

[`OperatorRegressionOptions`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/struct.OperatorRegressionOptions.html) defaults to LSMR, residual and normal-equation residual tolerances derived from scalar precision, 4096 iterations, and no byte limit.
Starting from $\beta=0$ keeps iterates in the range of $A^{\mathsf H}$ (the row space of $A$), so they converge to the minimum-norm solution even for a rank-deficient design.
Operator regression does not compute rank, so `rank` and `degrees_of_freedom` in the resulting `LinearRegressionFit` are `None`, and inference such as `contrast` is unavailable.

[`OperatorRegressionResult`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/struct.OperatorRegressionResult.html) contains the fit `fit()` and report `report()`.
The termination status `termination` of [`OperatorRegressionReport`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/struct.OperatorRegressionReport.html) is scioxide-linalg's `LinearSolveTermination`; `is_success()` is true for `Converged` and `LeastSquaresConverged`.
`iterations` is the iteration count; `krylov` estimates the condition number and rank deficiency of the projected problem, not the rank of the design.
`output_committed` indicates whether results were written to the output; it is false when execution was stopped or the evaluation limit left insufficient allowance for the two products needed to compute residuals, and `fit()` is then `None`.
The last iterate is written even when the iteration limit is reached, so `output_committed` does not imply convergence.
The workspace is [`OperatorRegressionWorkspace`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/struct.OperatorRegressionWorkspace.html), with size $O(n+p+s)$ ($s$ is the workspace length required by the operator).

## ANOVA of plant dry weights

The next three blocks compare dry weights [g] of a control and two treatment groups (10 plants each) using R's `PlantGrowth` data (Dobson 1983).
The first block contains definitions shared by two cells: `GROUPS` holds observations for the three groups, `response()` holds responses for the 30 plants in group order, and `indicator_design(overparameterized)` is the group-indicator design.
When `overparameterized` is true, the design has four columns: an intercept and indicators for all three groups; its rank is 3 because the column of ones equals the sum of the indicators.
Otherwise, it has three full-rank columns: an intercept with the control group as the baseline, and indicators for treatments 1 and 2.

## Generalized linear models (GLMs)

A generalized linear model (McCullagh and Nelder 1989) assumes that the response $y_i$ follows an exponential dispersion family and that its mean $\mu_i$ is related to a linear predictor $\eta_i$ by a monotone link function $g$.

$$
g(\mu_i)=\eta_i=x_i^{\mathsf T}\beta+o_i,\qquad \mathrm E[y_i]=\mu_i,\qquad \mathrm{Var}[y_i]=\frac{\phi\,V(\mu_i)}{w_im_i}
$$

Here $V$ is the variance function, $o_i$ the offset, $w_i$ the row weight, $m_i$ the binomial trial count (1 for other families), and $\phi$ the dispersion parameter.
The five families in [`GlmFamily`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/enum.GlmFamily.html) and their link functions in [`GlmLink`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/enum.GlmLink.html) are as follows.

| Family | Response domain | $V(\mu)$ | Link $g(\mu)$ | Unit deviance $d(y,\mu)$ |
|---|---|---|---|---|
| `Gaussian` | $y\in\mathbb R$ | $1$ | `Identity`: $\mu$ | $(y-\mu)^2$ |
| `Binomial` | $0\le y\le1$ (success proportion) | $\mu(1-\mu)$ | `Logit`: $\ln\{\mu/(1-\mu)\}$ | $2[y\ln(y/\mu)+(1-y)\ln\{(1-y)/(1-\mu)\}]$ |
| `Poisson` | $y\ge0$ | $\mu$ | `Log`: $\ln\mu$ | $2[y\ln(y/\mu)-(y-\mu)]$ |
| `Gamma` | $y>0$ | $\mu^2$ | `Inverse`: $1/\mu$ | $2[(y-\mu)/\mu-\ln(y/\mu)]$ |
| `InverseGaussian` | $y>0$ | $\mu^3$ | `InverseSquared`: $1/\mu^2$ | $(y-\mu)^2/(y\mu^2)$ |

Each family has a fixed canonical link (up to sign), so selecting the family determines the link (`GlmFamily::link`).
The Gamma and inverse Gaussian links require $\eta>0$.
Noncanonical links such as probit, complementary log-log, and the Gamma log link, negative binomial and Tweedie distributions, quasi-likelihood families, generalized estimating equations (GEEs), mixed models, and penalized GLMs are not provided.
When these are needed, write the log-likelihood as a [`FitObjective`](../distribution-fitting-and-confidence-limits/), supply an optimizer through `FitSolver`, and minimize it with `fit_into`.

[`PreparedGlm::new`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/struct.PreparedGlm.html#method.new) accepts the design, family, weights, trial counts `trials` (binomial only, default 1), offsets `offsets` (default 0), and exposures `exposure` (Poisson only, with their logarithms added to the offsets).
Weights are `Unweighted`, `Frequency`, or `Analytic`; `Reliability` weights, which do not define a likelihood, are rejected at compile time.
An effective sample size $n_{\text{eff}}$ no greater than the number of columns produces `InvalidInput`.

### Iteratively reweighted least squares

The maximum likelihood estimator minimizes the deviance $D(\beta)=\sum_iw_im_id(y_i,\mu_i)$.
With a canonical link, the observed and expected log-likelihood information are equal, so Fisher scoring coincides with Newton's method and each iteration becomes the following weighted least-squares problem (iteratively reweighted least squares, IRLS).

$$
z_i=\eta_i+(y_i-\mu_i)\,g'(\mu_i),\qquad
W_i=\frac{w_im_i}{V(\mu_i)\,g'(\mu_i)^2},\qquad
\beta^{\text{new}}=\arg\min_\beta\sum_iW_i(z_i-x_i^{\mathsf T}\beta-o_i)^2
$$

scioxide-stats IRLS starts with the weighted response mean as the initial mean (restricted to $[4\sqrt\varepsilon,1-4\sqrt\varepsilon]$ for binomial and at least $4\sqrt\varepsilon$ for Poisson, Gamma, and inverse Gaussian) and solves each weighted least-squares problem by thin SVD in $O(np^2)$.
If deviance increases, halve the step up to 32 times.
Convergence requires both the coefficient-change tolerance (relative to the largest coefficient magnitude) and the score $\nabla\ell(\beta)$ norm tolerance (relative to $1+D$) to be satisfied.
The default limits are 100 iterations and 4096 iterations per SVD; change them with [`GlmOptions`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/struct.GlmOptions.html).

### Termination statuses and their conditions

The `termination` field in the report [`GlmReport`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/struct.GlmReport.html) contains a termination status from `StatsTermination`.
`is_success()` is true only for `Converged`.
The conditions for each status are as follows.

| Status | Condition | Fit |
|---|---|---|
| `Converged` | Both coefficient change and score satisfy their tolerances on the second or a later iteration | Last iterate |
| `BudgetExhausted` | The iteration limit or the execution context's iteration or evaluation limit is reached | Last accepted iterate (none if no iterate was accepted) |
| `Stopped(_)` | Cancellation or a deadline stops execution | As above |
| `RankDeficient` | The numerical rank of the weighted design $W^{1/2}X$ at an iteration is smaller than $p$ | As above |
| `Separated` | For a binomial family, the largest absolute coefficient exceeds 32 and a fitted value is closer than $4\sqrt\varepsilon$ to 0 or 1; or, for a binomial family, 32 halvings fail to reduce deviance | As above |
| `NoProgress` | For a nonbinomial family, 32 halvings fail to reduce deviance | As above |

`RankDeficient` occurs at the first iteration when design columns are linearly dependent, but can also occur during iteration.
If all counts in a Poisson group are zero, its maximum likelihood estimate is $\mu=0$, that is, $\eta=-\infty$; fitted values approach zero at each iteration, weights $W_i=\mu_i$ approach zero, and the column numerically disappears.
The equivalent binomial situation (complete or quasi-complete separation; Albert and Anderson 1984) is detected as `Separated` from diverging coefficients and saturated fitted values.
`NotConverged` does not occur in IRLS; it is used when an injected optimizer does not report convergence.

Read the fit through the [`GlmFitView`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/struct.GlmFitView.html) returned by `fit()` on [`GlmResult`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/struct.GlmResult.html); it is `None` if no iterate was accepted.
`GlmFitView` and the owning type [`GlmFit`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/struct.GlmFit.html) contain coefficients, fitted means $\hat\mu_i$, response residuals $y_i-\hat\mu_i$, linear predictors $\hat\eta_i$ (including offsets), deviance $D$, Pearson statistic $X^2=\sum w_im_i(y_i-\hat\mu_i)^2/V(\hat\mu_i)$, score norm, Pearson dispersion estimate $X^2/(n_{\text{eff}}-p)$, residual degrees of freedom, and the last iteration's numerical rank.
Deviance is twice the log-likelihood ratio against the saturated model; where the normal approximation applies, goodness of fit can be assessed with a $\chi^2$ distribution with $n_{\text{eff}}-p$ degrees of freedom.
For Poisson and binomial families, a value of $X^2/(n_{\text{eff}}-p)$ well above 1 suggests overdispersion.

### Coefficient covariance and Wald tests

For a converged, full-rank fit, select the covariance estimator with [`GlmCovariance`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/enum.GlmCovariance.html).
Let $A$ be the design weighted by the final IRLS weights, and let $B=A^{\mathsf T}A$ (the Fisher information at dispersion 1).
`Model` is $\phi B^{-1}$, where $\phi$ is 1 for binomial and Poisson families and the Pearson estimate for other families.
`Hc0` is the sandwich $B^{-1}(\sum_is_is_i^{\mathsf T})B^{-1}$ based on score contributions $s_i$; `Hc3` additionally multiplies by $(1-h_i)^{-2}$; both remain consistent with a misspecified variance function.
`PreparedGlm::covariance` returns the covariance matrix, while `coefficient_inference` returns a sequence of [`GlmCoefficientInference`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/struct.GlmCoefficientInference.html) containing each coefficient's estimate, standard error, two-sided Wald-test p-value $2\{1-\Phi(|\hat\beta_j|/\mathrm{se})\}$, and interval $\hat\beta_j\pm z\,\mathrm{se}$.
Both are asymptotic results and cost $O(n^2p+np^2)$.
An unconverged fit, rank deficiency, or mismatch between the response and fit produces `InvalidInput`.
Likelihood-ratio tests and coefficient profile-likelihood intervals are not provided, but fitting each nested model and comparing the deviance difference $D_r-D_f$ with a $\chi^2$ distribution with $p_f-p_r$ degrees of freedom gives a likelihood-ratio test (for families with known $\phi$).

### Call forms and related types

[`GlmInputs`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/struct.GlmInputs.html) bundles the response, `GlmOptions`, and solver.
The solver [`GlmSolver`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/enum.GlmSolver.html) defaults to `Irls`; `Injected` asks the user's `FitSolver` to minimize [`GlmObjective`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/struct.GlmObjective.html) (half the deviance $\tfrac12\sum w_im_id(y_i,\mu_i(\beta))$ and its gradient, costing $O(np)$ per evaluation).
`Injected` also accepts coefficient bounds and integrality constraints, checks the optimizer's final point, and counts it as one accepted iteration.

| Form | Call | Allocation |
|---|---|---|
| One-shot | `glm_fit(design, family, &y)` | Plan, output, and workspace; error if convergence fails |
| Standard | `plan.fit(inputs)` | Output and workspace |
| Scoped | `plan.fit_scoped(inputs, scope)` | Output and workspace; shares computation limits with the parent computation |
| Borrowed | `plan.fit_into(inputs, &mut output, &mut workspace, scope)` | None |
| Batch | `glm_batch_into(inputs, outputs, workspace, context)` | None |

The borrowed form's [`GlmOutput`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/struct.GlmOutput.html) is created with `plan.output()` and retains only the last accepted iterate.
Create [`GlmWorkspace`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/struct.GlmWorkspace.html) with `plan.workspace(options)`; `last_attempt()` returns the last execution record, and `last_accepted()` returns the last accepted iterate [`GlmAccepted`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/struct.GlmAccepted.html).
Even if a one-shot call returns an error, the workspace form allows intermediate iterates to be inspected with `last_accepted()`.
[`glm_batch_into`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/fn.glm_batch_into.html) fits multiple responses by IRLS using one `PreparedGlm`, with inputs `GlmBatchInputs`, per-response outputs `GlmBatchOutput` (output and report), and per-worker workspaces `GlmBatchWorkspace` (created by `plan.batch_workspace`).

For sparse matrices or operator designs, use [`PreparedOperatorGlm`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/struct.PreparedOperatorGlm.html).
The model and IRLS are the same, but each iteration's weighted least-squares problem is solved by LSMR starting from the previous coefficients, with iteration limit `GlmOptions::factor_iterations`.
LSMR does not compute rank, so the result has no rank, dispersion parameter, or degrees of freedom, and no covariance is computed.
The workspace is [`GlmOperatorWorkspace`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/struct.GlmOperatorWorkspace.html); the `Injected` solver produces `NotImplemented`.

## Poisson regression of intersection accident counts

The next cell fits Poisson regression to daily accident counts recorded for five days at each of three intersections.
The design consists of an intercept and indicators for intersections 2 and 3, with $\ln\mu_g=\beta_0+\beta_g$.
In this one-factor log-linear model, each group's score equation is $\sum_{i\in g}(y_i-\mu_g)=0$, so the maximum likelihood estimate is the group mean $\hat\mu_g=\bar y_g$ and the coefficients are $\hat\beta_0=\ln\bar y_1$ and $\hat\beta_g=\ln(\bar y_g/\bar y_1)$.
The Fisher information also gives closed forms for the `Model` standard errors: $\mathrm{se}(\hat\beta_0)=1/\sqrt{n_1\bar y_1}$ and $\mathrm{se}(\hat\beta_g)=\sqrt{1/(n_1\bar y_1)+1/(n_g\bar y_g)}$.
The deviance is $D=2\sum_i y_i\ln(y_i/\bar y_{g(i)})$ (within each group, $\sum(y_i-\bar y_g)=0$).

Changing the input scenario reproduces the different termination cases.
“Iteration limit 3” stops before convergence; “All counts at intersection 3 are zero” has no Poisson maximum likelihood estimate; “All failures in binomial group 3” gives quasi-complete separation when logistic regression is fitted to 0/1 responses in the same arrangement; “Linearly dependent columns” adds a column equal to the sum of the intersection 2 and 3 indicators.

## Robust regression and slope estimators

Moving just one observation arbitrarily can move the least-squares estimate arbitrarily far (breakdown point $1/n$, asymptotically 0).
Robust regression places a bound on the influence of outliers.

### Huber M-estimation

Huber's (1964) M-estimator minimizes the sum of the following loss applied to residuals divided by a scale.

$$
\hat\beta=\arg\min_\beta\sum_i\rho_c\!\left(\frac{y_i-x_i^{\mathsf T}\beta}{\hat\sigma}\right),\qquad
\rho_c(u)=\begin{cases}u^2/2&(|u|\le c)\\ c|u|-c^2/2&(|u|>c)\end{cases}
$$

Because the loss derivative $\psi_c(u)=\max(-c,\min(c,u))$ is bounded, the influence of large residuals is capped at $c\hat\sigma$.
[`PreparedHuber`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/struct.PreparedHuber.html) solves this by IRLS (Holland and Welsch 1977).
The first iteration is ordinary least squares; subsequent iterations form weights $w_i=\min(1,c\hat\sigma/|r_i|)$ from the previous residuals and solve weighted least squares by thin SVD, reestimating the scale $\hat\sigma=\mathrm{MAD}(r)/0.6745$ (the median absolute deviation from the median residual, calibrated for a normal distribution) at every iteration.
It stops with `Converged` when the largest coefficient change satisfies the tolerance, or with `ExactFit` (zero scale) when all residuals are zero to within rounding error.
Each iteration costs $O(np^2)$.

[`HuberOptions`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/struct.HuberOptions.html) defaults to $c=1.345$, giving 95% asymptotic efficiency under normality, 100 iterations, and 4096 iterations per SVD.
A numerically rank-deficient weighted design, or zero MAD without a perfect fit, produces a `InvalidInput` error rather than a termination status.
M-estimation resists response outliers but is vulnerable to explanatory-variable outliers (high-leverage points); one such point can break the estimator.

Read the result from [`HuberFit`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/struct.HuberFit.html) (the owning type returned by `plan.fit(&y)`) or from [`HuberFitView`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/struct.HuberFitView.html), returned by [`HuberOutput`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/struct.HuberOutput.html) in the borrowed form `fit_into`; it contains coefficients, residuals, final weights, scale, iteration count, rank, and report `HuberReport` (termination status, counters, and accepted-iteration count).
`last_accepted()` on [`HuberWorkspace`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/struct.HuberWorkspace.html) returns the last accepted iterate as [`HuberAccepted`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/struct.HuberAccepted.html).
`huber_location(&x)` is M-estimation of location using a design with only a column of ones.

### Theil–Sen and Siegel slopes

Rank-based slope estimators are available for a line with one explanatory variable.
The Theil–Sen estimator (Theil 1950, Sen 1968) is the median of all pairwise slopes $(y_j-y_i)/(x_j-x_i)$ for $x_i\ne x_j$ and has breakdown point $1-1/\sqrt2\approx29\%$.
Sen's confidence interval derives $C=z\sqrt{\mathrm{Var}(S)}$ from the variance $\mathrm{Var}(S)$ of Kendall's statistic (corrected for ties in $x$ and $y$) and uses the $(N-C)/2$th and $(N+C)/2+1$th order statistics of the $N$ pairwise slopes as endpoints.
Siegel's (1982) repeated median is $\mathrm{median}_i\,\mathrm{median}_{j\ne i}(y_j-y_i)/(x_j-x_i)$ and has a 50% breakdown point, but returns no interval.
Both cost $O(n^2)$, finding medians by selection rather than sorting.
Theil–Sen stores $n(n-1)/2$ slopes and uses $O(n^2)$ memory; Siegel uses $O(n)$.

Select the intercept estimator with [`RobustIntercept`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/enum.RobustIntercept.html).
The default `Joint` is $\mathrm{median}_i(y_i-\hat\beta_1x_i)$; `Separate` is $\mathrm{median}(y)-\hat\beta_1\mathrm{median}(x)$ for Theil–Sen and the repeated median of intercepts for Siegel.
`robust_slope(&x, &y, method)` is a one-shot call with `Joint` and 95% confidence; `robust_slope_with_options` lets you select the intercept estimator and confidence level.
For repeated problems of the same size, create a [`RobustSlopeWorkspace`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/struct.RobustSlopeWorkspace.html) with `RobustSlopeWorkspace::new(n, method, options)` and call `evaluate`.
The resulting [`RobustSlope`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/struct.RobustSlope.html) contains the slope, intercept, Sen interval (`None` for Siegel), and estimator type.

Least trimmed squares (LTS), least median of squares (LMS), MM-estimation, S-estimation, Tukey's biweight, and quantile regression are not provided.
With multiple explanatory variables and suspected explanatory-variable outliers, the scioxide-stats estimators cannot provide a high breakdown point; first diagnose outliers using residuals and leverage.

## Orthogonal distance regression (ODR)

Consider an errors-in-variables model, where explanatory variables also have measurement error.
For true values $t_i$, let $x_i=t_i+\delta_i$ and $y_i=\beta_0+\beta_1t_i+\varepsilon_i$, where $\delta_i$ and $\varepsilon_i$ are independent normal errors with standard deviations $\sigma_x$ and $\sigma_y$.
Least-squares regression of $y$ on $x$ makes the slope approach $\kappa\beta_1$ instead of $\beta_1$, multiplying it by the reliability ratio $\kappa=\sigma_t^2/(\sigma_t^2+\sigma_x^2)$ ($\sigma_t^2$ is the variance of the true values; attenuation, Fuller 1987).
This bias does not disappear as $n$ increases.

Orthogonal distance regression also treats the explanatory-variable corrections $\delta_i$ as unknowns and minimizes the following sum of weighted distances.

$$
S(\beta,\delta)=\sum_i\left[\sum_j\left(\frac{\delta_{ij}}{\sigma_{x,ij}}\right)^2+\sum_j\left(\frac{f_j(\beta,x_i+\delta_i)-y_{ij}}{\sigma_{y,ij}}\right)^2\right]
$$

With normal errors, this is maximum likelihood estimation of $(\beta,\delta)$.
For the affine model $y=\beta_0+\beta_1x_1+\dots+\beta_px_p$ with observation-independent standard deviations, [`linear_odr_with_options`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/fn.linear_odr_with_options.html) solves the problem in closed form.
Divide each column of the centered $[X\ y]$ by its standard deviation and use the right singular vector $v$ for the smallest singular value $\sigma_{\min}$ of the thin SVD as the hyperplane normal (scaled total least squares; Golub and Van Loan 1980).
The slopes are $\beta_j=-\sigma_yv_j/(\sigma_jv_y)$, the minimum objective is $\sigma_{\min}^2$, and the computation costs $O(n(p+1)^2)$ without an optimizer.
With one explanatory variable, this is Deming regression with known error-variance ratio $\lambda=\sigma_y^2/\sigma_x^2$, and the slope has the following closed form.

$$
\hat\beta_1=\frac{S_{yy}-\lambda S_{xx}+\sqrt{(S_{yy}-\lambda S_{xx})^2+4\lambda S_{xy}^2}}{2S_{xy}}
$$

The slope depends only on the ratio of $\sigma_x$ to $\sigma_y$ and is unchanged when both are scaled by the same factor.
The objective value is inversely proportional to the square of that factor.
An incorrect ratio biases estimation; estimate the error standard deviations separately, for example from repeated measurements, before using this method.

`linear_odr_with_options` returns `InvalidInput` when the gap between the two smallest singular values is at most $\varepsilon\max(n,p+1)\sigma_1$ (the hyperplane is not unique), or when the hyperplane is nearly parallel to the response axis ($|v_y|\le(p+1)\varepsilon$).
The resulting [`OdrFit`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/struct.OdrFit.html) contains coefficients (intercept followed by slopes), per-observation corrections $\delta$, and report [`OdrReport`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/struct.OdrReport.html).
The report contains the termination status (always `Converged` for the closed form), objective value `chi_square`, counters (zero for the closed form), and identifiability diagnostic [`OdrIdentifiabilityDiagnostic`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/enum.OdrIdentifiabilityDiagnostic.html).
The closed-form diagnostic is `SingularGap { gap, threshold }`, containing the gap between the two smallest singular values and its threshold.
`linear_odr` is a one-shot call defaulting to `OdrOptions` (which holds only a byte limit).

For nonlinear models, use [`PreparedOdr`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/struct.PreparedOdr.html).
Supply the model as an implementation of [`OdrModel`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/trait.OdrModel.html), returning the parameter, explanatory-variable, and response counts, the response $f_r(\beta,x)$, and its partial derivatives with respect to $\beta_j$ and $x_j$.
Receive the corrected explanatory variables $x+\delta$ through [`OdrPredictors`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/struct.OdrPredictors.html).
[`AffineOdrModel`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/struct.AffineOdrModel.html) implements an affine model and supports line ODR with standard deviations that vary among observations.
`PreparedOdr` contains no optimizer within scioxide-stats; it passes an objective implementing `FitObjective` and `FitDerivatives` ($n(p+q)$ residuals and their Jacobian) to the user's `FitSolver` (such as Levenberg–Marquardt; Boggs, Byrd and Schnabel 1987).
[`OdrInputs`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/struct.OdrInputs.html) bundles the initial point $z=[\beta,\delta]$ (constructible with `initial_parameters`), bounds, integrality constraints, and solver; `fit_into` writes to [`OdrOutput`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/struct.OdrOutput.html) and [`OdrWorkspace`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/struct.OdrWorkspace.html).
The termination status is the `StatsTermination` reported by the solver.
`local_identifiability(z)` computes the numerical rank of the residual Jacobian at $z$ ($n(p+q)$ rows and $k+np$ columns) by thin SVD and returns it in [`OdrIdentifiability`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/struct.OdrIdentifiability.html).
The $np$ correction columns always have full rank; if `coefficient_rank`, the rank minus $np$, is smaller than the parameter count $k$, the data do not determine the parameters locally at that point.
`gaussian_negative_log_likelihood(z)` returns the normal error model's negative log-likelihood, including its constant term.

Correlated errors and implicit models are not provided.
Coefficient standard errors are also unavailable; if needed, obtain them by bootstrapping observation pairs using [Resampling](../resampling/).

## Outliers and measurement error in comparing two measurement methods

The next cell constructs a method-comparison scenario in which the same samples are measured by two methods.
The true values $t_i$ are 20 equally spaced points on $[2,10]$; measurements by the reference method are $x_i=t_i+\delta_i$ ($\sigma_x=1$), and measurements by the new method are $y_i=0.5+1.1t_i+\varepsilon_i$ ($\sigma_y=\sigma_x\sqrt\lambda$).
The outlier-size input is added to $y$ for the 19th sample.
Fit least squares, Huber, Theil–Sen, Siegel, and ODR (with known $\lambda$) to one data set; compare the ODR slope with Deming's closed form and the Theil–Sen slope with a manual median of pairwise slopes.
Then generate 300 data sets with the same settings and compare each estimator's mean slope and its standard error with the true slope 1.1 and the expected least-squares slope without outliers.
For the least-squares slope $b=S_{xy}/S_{xx}$, let $S_{tt}=\sum_i(t_i-\bar t)^2$ and $D=S_{xx}$; then $\mathrm E[S_{xy}]=\beta_1S_{tt}$, $\mathrm E[D]=S_{tt}+(n-1)\sigma_x^2$, $\mathrm{Var}(D)=4\sigma_x^2S_{tt}+2(n-1)\sigma_x^4$, and $\mathrm{Cov}(S_{xy},D)=2\beta_1\sigma_x^2S_{tt}$.
Expanding the expectation of the ratio to second order by the delta method gives the following approximation.

$$
\mathrm E[b]\approx\frac{\beta_1S_{tt}}{\mathrm E[D]}\left(1-\frac{2\sigma_x^2}{\mathrm E[D]}+\frac{\mathrm{Var}(D)}{\mathrm E[D]^2}\right)
$$

Here the first-order term $\beta_1S_{tt}/\mathrm E[D]$ is 0.947 and the second-order approximation is 0.959.

```rust
//| id: stats-regression-comparison
//| ref: stats-regression-comparison
//| title: "Least-squares, Huber, Theil–Sen, Siegel, and ODR slopes for method-comparison data"
//| run: button
//| crates: [scioxide-core, scioxide-linalg, scioxide-random, scioxide-stats]
//| inputs:
//|   outlier: {"type":"range","label":"Outlier added to the 19th y [-]","min":0,"max":20,"step":2,"value":0}
//|   ratio: {"type":"select","label":"Error-variance ratio λ = σ_y² / σ_x²","options":["0.25","1","4"],"value":"1"}
//|   sampling_seed: {"type":"integer","label":"Random seed","min":0,"max":100000,"value":7}
//| cases:
//|   - {"id":"outlier","label":"Outlier 12","description":"The least-squares and ODR slopes change considerably, while Huber, Theil–Sen, and Siegel barely change.","inputs":{"outlier":12}}
//|   - {"id":"precise-y","label":"λ = 0.25","description":"The y error is small. ODR returns a steeper slope than least squares and corrects attenuation.","inputs":{"ratio":"0.25"}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"slopes","path":"/rows/4/1","approx":{"value":1.0310822957963381,"rtol":1e-09}}
//|       - {"artifact":"slopes","path":"/rows/4/3","approx":{"value":1.0310822957963381,"rtol":1e-09}}
//|       - {"artifact":"slopes","path":"/rows/2/3","approx":{"value":0.9241637563233183,"rtol":1e-09}}
//|       - {"artifact":"slopes","path":"/rows/2/1","approx":{"value":0.9241637563233183,"rtol":1e-09}}
//|       - {"artifact":"slopes","path":"/rows/0/4","range":{"min":0.935,"max":0.975}}
//|       - {"artifact":"slopes","path":"/rows/4/4","range":{"min":1.08,"max":1.12}}
//|       - {"artifact":"slopes","path":"/rows/5/4","approx":{"value":0.9592,"atol":0.0005}}
//|   - case: outlier
//|     expect:
//|       - {"artifact":"slopes","path":"/rows/0/4","approx":{"value":1.2661562549666567,"rtol":1e-06}}
//|       - {"artifact":"slopes","path":"/rows/1/4","approx":{"value":1.0170539805512073,"rtol":1e-06}}
//|       - {"artifact":"slopes","path":"/rows/4/4","approx":{"value":1.985066757597699,"rtol":1e-06}}
//|   - case: precise-y
//|     expect:
//|       - {"artifact":"slopes","path":"/rows/4/4","approx":{"value":1.0974951464685623,"rtol":1e-06}}
//|       - {"artifact":"slopes","path":"/rows/4/3","approx":{"value":1.0351768832191592,"rtol":1e-09}}
use scioxide_core::RealScalar;
use scioxide_linalg::Matrix;
use scioxide_random::{Distribution, Normal, SeedableRng, SplitMix64};
use scioxide_stats::{
    HuberOptions, PreparedHuber, RobustSlopeMethod, linear_odr, ordinary_least_squares,
    robust_slope,
};

let n = 20;
let lambda: f64 = ratio.parse().map_err(|_| "λ is not a number")?;
let (sx, sy) = (1.0, RealScalar::sqrt(lambda));
let t: Vec<f64> = (0..n)
    .map(|i| 2.0 + 8.0 * i as f64 / (n - 1) as f64)
    .collect();
let normal = Normal::<f64>::new(0.0, 1.0).map_err(|e| e.to_string())?;
let mut rng = SplitMix64::from_seed(sampling_seed as u64);
let mut draw = || -> Result<(Vec<f64>, Vec<f64>), String> {
    let (mut x, mut y) = (Vec::with_capacity(n), Vec::with_capacity(n));
    for &ti in &t {
        x.push(ti + sx * normal.sample(&mut rng).map_err(|e| e.to_string())?);
        y.push(0.5 + 1.1 * ti + sy * normal.sample(&mut rng).map_err(|e| e.to_string())?);
    }
    y[n - 2] += outlier;
    Ok((x, y))
};
// (Slope, intercept) for five estimators
let estimate = |x: &[f64], y: &[f64]| -> Result<[(f64, f64); 5], String> {
    let rows: Vec<f64> = x.iter().flat_map(|&v| [1.0, v]).collect();
    let design = Matrix::from_vec(n, 2, rows).map_err(|e| e.to_string())?;
    let ols = ordinary_least_squares(design.view(), y).map_err(|e| e.to_string())?;
    let huber = PreparedHuber::new(design.view(), HuberOptions::default())
        .map_err(|e| e.to_string())?
        .fit(y)
        .map_err(|e| e.to_string())?;
    let ts = robust_slope(x, y, RobustSlopeMethod::TheilSen).map_err(|e| e.to_string())?;
    let sg = robust_slope(x, y, RobustSlopeMethod::Siegel).map_err(|e| e.to_string())?;
    let predictors = Matrix::from_vec(n, 1, x.to_vec()).map_err(|e| e.to_string())?;
    let odr = linear_odr(predictors.view(), y, &[sx], sy).map_err(|e| e.to_string())?;
    let (b, h, o) = (
        ols.coefficients().as_slice(),
        huber.coefficients().as_slice(),
        odr.coefficients(),
    );
    Ok([
        (b[1], b[0]),
        (h[1], h[0]),
        (ts.slope(), ts.intercept()),
        (sg.slope(), sg.intercept()),
        (o[1], o[0]),
    ])
};
let (x, y) = draw()?;
let single = estimate(&x, &y)?;
// Independent check: Deming's closed form and the median of pairwise slopes
let (mx, my) = (
    x.iter().sum::<f64>() / n as f64,
    y.iter().sum::<f64>() / n as f64,
);
let sxx: f64 = x.iter().map(|v| (v - mx) * (v - mx)).sum();
let syy: f64 = y.iter().map(|v| (v - my) * (v - my)).sum();
let sxy: f64 = x.iter().zip(&y).map(|(a, b)| (a - mx) * (b - my)).sum();
let gap = syy - lambda * sxx;
let deming = (gap + RealScalar::sqrt(gap * gap + 4.0 * lambda * sxy * sxy)) / (2.0 * sxy);
let mut slopes = Vec::new();
for i in 0..n {
    for j in i + 1..n {
        slopes.push((y[j] - y[i]) / (x[j] - x[i]));
    }
}
slopes.sort_by(f64::total_cmp);
let theil_sen = 0.5 * (slopes[slopes.len() / 2 - 1] + slopes[slopes.len() / 2]);
let names = [
    "Least squares",
    "Huber",
    "Theil–Sen",
    "Siegel",
    "ODR (known λ)",
];
let checks = [None, None, Some(theil_sen), None, Some(deming)];
// Simulation of 300 data sets: mean slope and standard error
let m = 300;
let mut sum = [0.0; 5];
let mut sum2 = [0.0; 5];
for _ in 0..m {
    let (x, y) = draw()?;
    for (k, (slope, _)) in estimate(&x, &y)?.into_iter().enumerate() {
        sum[k] += slope;
        sum2[k] += slope * slope;
    }
}
let mut rows: Vec<_> = (0..5)
    .map(|k| {
        let mean = sum[k] / m as f64;
        let var = (sum2[k] - m as f64 * mean * mean) / (m as f64 - 1.0);
        let se = RealScalar::sqrt(var / m as f64);
        let (slope, intercept) = single[k];
        (
            names[k],
            Some(slope),
            Some(intercept),
            checks[k],
            mean,
            Some(se),
        )
    })
    .collect();
// Second-order approximation to the expected least-squares slope without outliers (delta method)
// With D = S_xx, E[D] = S_tt + (n − 1)σ_x², Var(D) = 4σ_x² S_tt + 2(n − 1)σ_x⁴,
// E[b] ≈ β₁ S_tt / E[D] · (1 − 2σ_x² / E[D] + Var(D) / E[D]²)
let tbar = t.iter().sum::<f64>() / n as f64;
let stt: f64 = t.iter().map(|v| (v - tbar) * (v - tbar)).sum();
let (s2, nm1) = (sx * sx, n as f64 - 1.0);
let mean_d = stt + nm1 * s2;
let var_d = 4.0 * s2 * stt + 2.0 * nm1 * s2 * s2;
let first = 1.1 * stt / mean_d;
let second = first * (1.0 - 2.0 * s2 / mean_d + var_d / (mean_d * mean_d));
rows.push((
    "Expected least squares (second-order approximation)",
    None,
    None,
    None,
    second,
    None,
));
let fixed4 = serde_json::json!({ "fractionDigits": 4 });
let columns = serde_json::json!([
    { "key": "0", "label": "Estimator" },
    { "key": "1", "label": "Slope [-]", "type": "number", "format": fixed4, "nullText": "—" },
    { "key": "2", "label": "Intercept [-]", "type": "number", "format": fixed4, "nullText": "—" },
    { "key": "3", "label": "Slope check [-]", "type": "number", "format": fixed4, "nullText": "—" },
    { "key": "4", "label": "Mean slope over 300 data sets [-]", "type": "number", "format": fixed4 },
    {
        "key": "5",
        "label": "Standard error of the mean [-]",
        "type": "number",
        "format": fixed4,
        "nullText": "—"
    }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "slopes" })
);
let points: Vec<[f64; 2]> = x.iter().zip(&y).map(|(&a, &b)| [a, b]).collect();
let line = |slope: f64, intercept: f64| -> Vec<[f64; 2]> {
    [0.0, 12.0]
        .iter()
        .map(|&v| [v, intercept + slope * v])
        .collect()
};
emit_chart!(serde_json::json!({
    "kind": "xy",
    "xLabel": "Reference-method measurement x [-]",
    "yLabel": "New-method measurement y [-]",
    "dataZoom": true,
    "tooltip": true,
    "layers": [
        { "id": "data", "kind": "scatter", "name": "Measurements", "points": points },
        {
            "id": "truth",
            "kind": "line",
            "name": "True relationship y = 0.5 + 1.1t",
            "points": line(1.1, 0.5),
            "style": { "lineType": "dashed" }
        },
        {
            "id": "ols",
            "kind": "line",
            "name": "Least squares",
            "points": line(single[0].0, single[0].1)
        },
        {
            "id": "huber",
            "kind": "line",
            "name": "Huber",
            "points": line(single[1].0, single[1].1)
        },
        {
            "id": "theil-sen",
            "kind": "line",
            "name": "Theil–Sen",
            "points": line(single[2].0, single[2].1)
        },
        { "id": "odr", "kind": "line", "name": "ODR", "points": line(single[4].0, single[4].1) }
    ]
}));
```

With the default inputs without outliers ($\lambda=1$, seed 7), the mean least-squares slope over 300 data sets is $0.953\pm0.007$, agreeing with the second-order approximation 0.959 within the standard error and 13% below the true 1.1.
The mean ODR slope is $1.100\pm0.009$; supplying the known $\lambda$ corrects attenuation.
Huber (0.952), Theil–Sen (0.967), and Siegel (0.990) protect against response outliers but do not account for explanatory-variable error, so all exhibit attenuation to varying degrees.
For the first data set, the ODR slope agrees with Deming's closed form and the Theil–Sen slope agrees with the manually computed median to within rounding error.

Adding an outlier of 12 moves the mean slopes over 300 data sets to 1.266 for least squares and 1.985 for ODR, while Huber (1.017), Theil–Sen (1.039), and Siegel (1.041) barely change.
ODR uses squared loss and is as vulnerable to outliers as least squares; in this example it moves farther than least squares.
Even at $\lambda=0.25$ (small $y$ error), the mean ODR slope is 1.097, close to 1.1; supplying $\lambda$ correctly allows correction regardless of the ratio.
When explanatory-variable error and outliers coexist, diagnose and remove outliers before fitting ODR.

## Summary

Linear regression factorizes the design once with `PreparedRegression` and fits each response with $O(np)$.
Even for rank-deficient designs, the minimum-norm solution, fitted values, and estimable contrasts are unique; nonestimable contrasts produce `InvalidInput`.
Use `RegressionCovariance::Hc3` when heteroskedasticity is suspected; HAC is unavailable for autocorrelation, so use a block bootstrap or time-series model.
One-way ANOVA gives the same $F$ through either `PreparedGroups` or `compare_nested`, and multiple comparisons use `pairwise` and `compare_control`.
For GLMs, check `termination` of `GlmReport` with `is_success()`; `RankDeficient` and `Separated` suggest that the maximum likelihood estimate may not exist.
Use Huber, Theil–Sen, or Siegel for response outliers and ODR with the error-variance ratio for explanatory-variable measurement error.
