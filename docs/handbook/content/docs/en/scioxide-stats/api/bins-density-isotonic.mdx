This page covers three methods that retain the full sample to estimate the shape of a distribution or regression function (binning, Gaussian kernel density estimation, and isotonic regression), along with their shared input types.
Like empirical distribution functions, binning and kernel density estimation accept `BatchView` (a borrowed N-dimensional array with observation, coordinate, and remaining batch axes) and `StatisticsOptions`.
Axis-wise isotonic regression uses the same `BatchView` as order statistics.
The `_into` functions allocate nothing after computing requirements and calling `try_reserve` on the workspace; on error they leave all caller-owned outputs unchanged.
Owned functions perform the same calculation sequentially with fresh workspace, allocating and returning the output.
For unweighted one-dimensional samples, the one-shot functions `histogram(values, bins)`, `GaussianKde::new(values)`, and `isotonic_regression(values)` use default settings.

## Statistical evaluation inputs and policies

Binning, kernel density estimation, and axis-wise isotonic regression use shared `BatchView` and `StatisticsOptions` with reserved workspace.
See [Shared input and output contracts](oxref:stats-input-validation-and-missing).

## Kernel density estimation

| Item | Kind | Role | Contract essentials | Explanation | Executable example |
|---|---|---|---|---|---|
| [`GaussianKde`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/struct.GaussianKde.html) | Struct | Prepared weighted Gaussian kernel density | Prepares $\hat f(x) = (1/W)\sum_i w_i \varphi_H(x - x_i)$. The one-shot function `new(values)` uses Scott's rule and full covariance for a one-dimensional unweighted sample. `with_options(view, batch, options)` prepares from batch `batch` of `BatchView` in sequential native execution; `build(view, batch, options, context)` accepts an execution context. Copies positive-weight observations as kernel centers. `build` rejects out-of-range batches, invalid weights, rejected missing/nonfinite values, batches with no positive-weight observations, observations outside the support, invalid support or its combination with correlated kernels, invalid bandwidths, and bandwidth estimation without residual degrees of freedom with `InvalidInput`; non-positive-definite kernel covariance is also an error. `pdf` and `log_pdf` allocate $d$ working values per call; `evaluate(points)` evaluates row-major query points with one working vector in $O(nd^2)$ per point. `integrate_box` requires diagonal kernel covariance. `integrate_kde` and `integrate_gaussian` are closed-form integrals, unavailable for estimates with support constraints | [Preparation and evaluation](oxref:stats-isotonic-kde-prepare-and-evaluate) | [Compare KDE bandwidths and integrated squared error for a bimodal normal mixture](oxref:stats-kde-bandwidth-ise), [Integrate a truncated kernel density by independent grid quadrature](oxref:stats-truncated-kde-normalization) |
| [`KdeBandwidth`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/enum.KdeBandwidth.html) | Enum | Bandwidth policy | `Scott` uses $c = n_{\mathrm{eff}}^{-1/(d+4)}$, `Silverman` uses $c = (n_{\mathrm{eff}}(d+2)/4)^{-1/(d+4)}$, and `Factor` uses a finite positive factor $c$. These three set kernel covariance to $H = c^2\hat\Sigma$ ($\hat\Sigma$ is the unbiased weighted sample covariance), failing if $\hat\Sigma$ is singular. `StandardDeviations` ($d$ standard deviations for diagonal $H$) and `Covariance` (row-major $d \times d$ symmetric positive-definite matrix $H$) specify absolute bandwidths and also accept single-point or constant samples | [Estimator and bandwidth](oxref:stats-kde-estimators-and-bandwidth) | [Compare KDE bandwidths and integrated squared error for a bimodal normal mixture](oxref:stats-kde-bandwidth-ise), [Integrate a truncated kernel density by independent grid quadrature](oxref:stats-truncated-kde-normalization) |
| [`KdeCovariance`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/enum.KdeCovariance.html) | Enum | Estimated covariance structure | Structure of the sample covariance used by bandwidth rules. `Full` preserves coordinate correlations, while `Diagonal` uses only variances, making kernels independent across coordinates | [Estimator and bandwidth](oxref:stats-kde-estimators-and-bandwidth) | [Integrate a truncated kernel density by independent grid quadrature](oxref:stats-truncated-kde-normalization) |
| [`KdeOptions`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/struct.KdeOptions.html) | Struct | Preparation choices | Defaults (`new` / `default`) are Scott's rule, full covariance, no support constraint, and default `StatisticsOptions`. Configure with `with_bandwidth`, `with_covariance`, `with_support`, and `with_admission`. Providing support (one interval per coordinate) truncates each kernel to the support box and renormalizes it, requiring all observations within the support and diagonal kernel covariance. `with_admission` specifies observation missing/nonfinite policies with `StatisticsOptions` | [Preparation and evaluation](oxref:stats-isotonic-kde-prepare-and-evaluate), [Kernel density truncated to support intervals](oxref:stats-kde-support-truncation) | [Compare KDE bandwidths and integrated squared error for a bimodal normal mixture](oxref:stats-kde-bandwidth-ise), [Integrate a truncated kernel density by independent grid quadrature](oxref:stats-truncated-kde-normalization) |
| [`kde_into`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/fn.kde_into.html) | Function | Batch query-point evaluation | `kde_into(kde, queries, scale, options, output, workspace, context)` writes one value per query point with batches outermost; `KdeScale` selects density or log density. Query points are not excluded. Insufficient workspace gives `DimensionMismatch`; output length mismatches and missing/nonfinite query points give `InvalidInput`. Errors leave outputs unchanged | [Bandwidth and integrated squared error](oxref:stats-kde-bandwidth-and-ise), [Preparation and evaluation](oxref:stats-isotonic-kde-prepare-and-evaluate) | [Compare KDE bandwidths and integrated squared error for a bimodal normal mixture](oxref:stats-kde-bandwidth-ise) |
| [`KdeWorkspace`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/struct.KdeWorkspace.html) | Struct | Point and triangular-solve workspace with output staging | `workspace_requirements(kde, queries, options, context)` computes requirements from kernel and query-point views; mismatched query and kernel dimensions give `InvalidInput`, and exceeding limits gives `ResourceLimit`. Prepare with `workspace` / `try_reserve` / `check`. After reservation, `kde_into` allocates nothing | [Preparation and evaluation](oxref:stats-isotonic-kde-prepare-and-evaluate) | [Compare KDE bandwidths and integrated squared error for a bimodal normal mixture](oxref:stats-kde-bandwidth-ise) |
| [`KdeRequirements`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/struct.KdeRequirements.html) | Struct | Kernel-density reservation requirements | Returned by `KdeWorkspace::workspace_requirements`. `required_bytes()` is workspace bytes excluding outputs, already checked against `max_bytes` | [Preparation and evaluation](oxref:stats-isotonic-kde-prepare-and-evaluate) | [Compare KDE bandwidths and integrated squared error for a bimodal normal mixture](oxref:stats-kde-bandwidth-ise) |
