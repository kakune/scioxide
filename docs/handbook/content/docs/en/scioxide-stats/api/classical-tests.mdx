This page collects classical tests for independent samples, paired observations, and complete blocks, together with their shared option and result types.
Every test except `weighted_kendall_tau` has a one-shot function `f(data)` and detailed form `f_with_options(data, options)`, both returning the shared `ClassicalTestResult`.
One-shot functions call their detailed forms with `ClassicalOptions::default()` (two-sided alternative, `Auto` calibration, 95% intervals, at most 100 000 exact states, half-unit continuity correction); only Chatterjee and Page tests set the alternative to `Greater`.
One-shot defaults are `Welch` for independent two-sample $t$ tests, `Discard` for zero differences in signed-rank tests, and reference distribution `Student` for Brunner–Munzel tests.
The result's `method` records the reference distribution actually used (Student $t$, normal approximation, exact null distribution, or permutation), rather than the requested calibration; `p_value()` always returns a numerical value in $[0,1]$.
Inputs failing length or finiteness checks, undefined statistics such as constant samples, and explicit requests for unsupported calibrations return `Err` without switching methods.
The basic classification is `InvalidInput`; nonfinite values give `NonFinite`, length mismatches `DimensionMismatch`, zero standard error in $t$ tests `NumericalInstability`, an `Exact` request whose exact calculation exceeds `max_work` gives `ConvergenceFailure`, and workspace exceeding `max_workspace_bytes` gives `ResourceLimit`.
Reported intervals are statistical estimates, not enclosures guaranteed to contain the true value.
