This page collects tests for integer-count data and procedures for handling p-values from many tests.
Validate contingency tables with `ContingencyView` (borrowed row-major `usize` counts) before passing them; counts are not expanded into individual observations.
Marginal sums and totals use `u128` integers, with overflow giving `SizeOverflow`.
The one-shot functions `chi2_contingency_test(table)`, `fisher_exact_test(table)`, `barnard_exact_test(table)`, and `boschloo_exact_test(table)` test with default settings.
To choose settings, use `power_divergence_contingency_test` or a detailed form `…_with_options`.
Chi-squared p-values approximate a large-sample asymptotic distribution; they are not exact probabilities under a finite null distribution.
Exact tests do not switch to approximations: under the limits in `ClassicalOptions`, examining more than `max_work` tables gives `ConvergenceFailure`, and workspace exceeding `max_workspace_bytes` gives `ResourceLimit`.
Multiple-testing adjustments return values in original hypothesis order, writing outputs only after every p-value is adjusted successfully.
