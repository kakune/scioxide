This page covers parametric distribution fitting and power-transformation parameter selection.
scioxide-stats prepares objectives (negative log likelihood or sums of squared residuals for moment/quantile matching) but contains no optimization algorithm.
A caller-supplied `FitSolver` implementation performs minimization.
scioxide-stats checks solver capabilities before calling it, then reevaluates the objective at the returned candidate before writing outputs.
The fitting entry points (`fit`, `ppcc_max`, `power_transform_normmax`) have one-shot, detailed, and scoped forms; `fit` also has a borrowed form `fit_into`.
One-shot forms run sequentially with one-shot defaults (`StatisticsOptions::default()`), accepting only successful termination (`Converged`).
`BudgetExhausted` and `NotConverged` become `ConvergenceFailure` errors with `NestedSolver`; `Stopped` becomes `ExecutionStopped`.
Detailed forms `…_with_options` accept `StatisticsOptions`; scoped forms `…_scoped` also accept an execution context or parent `SolveContext`.
Both return unsuccessful termination as a report in `Ok`.
The borrowed form `fit_into` writes into caller-owned output and `FitWorkspace`.
Solvers obey their own iteration limit, the shared evaluation limit, and stop requests; the parent's iteration limit does not constrain them.
Judge success solely by `StatsTermination`.
`Converged` is the solver's claim that its stopping criterion is satisfied, not a guarantee of statistical identifiability or global optimality.
