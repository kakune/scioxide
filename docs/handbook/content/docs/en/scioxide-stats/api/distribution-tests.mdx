This table collects tests of distribution shape, normality, equality of scale, and medians.
The shared result type is `DistributionTestResult`, which identifies the calibration actually used for the p-value (`DistributionMethod`) and whether the null-distribution parameters were fixed or estimated from the sample (`NullParameters`).
Each test has a one-shot function `f(data)` and a detailed form `f_with_options(data, …, options)` that accepts `ClassicalOptions`.
The one-shot functions use `ClassicalOptions::default()`.
In addition, `levene_test` and `fligner_test` use the center `Median`, `anderson_k_sample_test` uses `Midrank`, and `median_test` uses the tie rule `Below`; the two-group Yates correction in `median_test` is enabled by the default `ClassicalOptions::continuity` (`HalfUnit`).
For a null hypothesis with estimated parameters, the null distribution for a fixed-parameter test does not give the correct p-value, so use the parametric bootstrap in `goodness_of_fit_test_into`, which re-estimates parameters for every replicate.
Omnibus tests require the alternative `TwoSided` in `ClassicalOptions` and return an upper-tail probability; tests with only approximate calibration reject requests for `TestCalibration::Exact`.
These rejections produce `InvalidInput`, and non-finite values produce `NonFinite`.
When `Exact` is requested, an exact method exceeding `max_work` produces `ConvergenceFailure`, and workspace exceeding `max_workspace_bytes` produces `ResourceLimit`.
