This page collects statistics computed by sorting or selecting sample values.
These include quantiles, tail means, ranks, modes, expectiles, and empirical distribution functions.
Every result returns the convention used (such as `QuantileConvention`, `TailMeanConvention`, or `RankMethod`) with the value so callers can record it.
The `_in_place` functions rearrange the caller's scratch array in place without copying it.
They validate the array before rearranging it, leaving it unchanged for invalid input.
On success, the array is a permutation of the input.
The axis-wise `_into` functions allocate nothing after workspace is reserved with `try_reserve` and leave output unchanged on error.
