This page collects accumulators that update means, variances, higher central moments, and covariance without retaining samples, confidence intervals for means derived from their results, and batch reductions along axes of strided array views (`BatchView`).
Accumulator `observe` and `merge` allocate nothing and update state only after all checks pass.
On error, state remains unchanged.
Undefined statistics (such as an empty sample's mean, a single point's sample variance, or a constant sequence's correlation) use `None`; unrepresentable values and computational breakdown return `Err`.
Internal state uses `f64` while values lie in the ordinary range of `f64` and switches to extended-range arithmetic with a separate binary exponent outside that range.
The mean is stored as a compensated value with high and low parts.
`snapshot` only copies this state and cannot fail.
A summary's means, variances, and standard errors are rounded independently on each query and returned in `Result<Option<S>, SciOxideError>`.
For a quantity outside the range of `S` (overflow), only that query returns `Err`; other queries are unaffected.
`MomentsSnapshot::scaled_variance_of_sample_mean` returns the estimated variance $s^2/n$ of the sample mean as an extended-exponent `Scaled<S>`, preserving values that would overflow or underflow when rounded to `S`.
