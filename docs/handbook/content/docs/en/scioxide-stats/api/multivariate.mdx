This page collects procedures that estimate multivariate quantities from dense matrices with observations in rows and variables in columns.
Input uses scioxide-linalg's `MatrixView` (contiguous or strided borrows); sparse matrices and operators are not implicitly made dense.
Factorizations use scioxide-linalg's SVD and Hermitian eigendecomposition; numerical rank is an estimate dependent on the convention explicitly set by `RankPolicy`, not a guarantee.
One-shot functions and constructors such as `sample_covariance(data)` and `PreparedPca::new(data)` use default `MultivariateOptions`; detailed forms `…_with_options` accept numerical-rank conventions and memory limits.
`max_bytes` limits preparation memory, results, and requested workspace, returning `ResourceLimit` when exceeded.
PCA and CCA check limits against the full thin-SVD size before rank is known.

Solves affine model $y = \beta_0 + \beta_1 x_1 + \dots + \beta_p x_p$ in closed form with error standard deviations shared across all observations; termination is always `Converged`. Returns the same `OdrFit` / `OdrReport` as nonlinear ODR with an injected solver | [Orthogonal distance regression (ODR)](oxref:stats-regression-odr) | [Least-squares, Huber, Theil–Sen, Siegel, and ODR slopes for method-comparison data](oxref:stats-regression-comparison) |

| [`PreparedOdr`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/struct.PreparedOdr.html) | Struct | Nonlinear ODR objective with independent normal errors | Parameters are $z = [\beta, \delta_1, \dots, \delta_n]$ (length $k + np$). | [`OdrIdentifiability`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/struct.OdrIdentifiability.html) | Struct | Numerical rank of the residual Jacobian at a point | `coefficient_rank()` is the overall rank minus the $np$ predictor corrections; `coefficient_count()` is $k$, and `full_rank()` is `RankReport` for the full residual Jacobian. | [`OdrFit`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/struct.OdrFit.html) | Struct | Orthogonal distance regression result | `coefficients()` contains model parameters $\beta$ (intercept then slopes for the affine model); `predictor_corrections()` contains $p$ corrections $\delta$ per observation; `report()` is `OdrReport`.
