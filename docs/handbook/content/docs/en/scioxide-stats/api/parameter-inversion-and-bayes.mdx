This page collects procedures for recovering distribution parameters from probabilities and summarizing Bayesian posteriors.
Inversion searches within an explicit interval for a parameter making tail probability $P(X \le x)$ or $P(X > x)$ equal to a target at a fixed observation.
Tails are evaluated in logarithmic form through scioxide-random distributions, and roots are refined with scioxide-rootfind.
If monotonicity is not guaranteed or tail values are indistinguishable, it returns `Inconclusive` rather than guessing a root.
Inversion and confidence-limit functions have three forms.
One-shot functions accept interval endpoints by value and use default `InversionOptions`, with two-sided 95% coverage for confidence limits.
Detailed forms `…_with_options` accept `InversionOptions` and, depending on the function, an interval of `Interval`, confidence level, and alternative, running sequentially; scoped forms `…_scoped` additionally accept an execution context or parent `SolveContext` sharing evaluation limits and cancellation.
Confidence limits are frequentist sets under a sampling model; credible intervals describe posterior mass and are not interchangeable with them.
Neither is a numerical enclosure.
