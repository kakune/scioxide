This page collects procedures that approximate sampling distributions through randomness or enumeration.
Callers supply randomness through scioxide-random generators; no implicit environmental randomness is used.
`SamplingPolicy` selects whether generator state remains advanced or rolls back on error and whether output is committed together or per replicate.
Indexed streams (`ReplicateOptions::indexed`) leave the root generator unchanged and use a split stream per replicate, making results independent of worker count.
One-shot functions `bootstrap`, `jackknife`, `permutation_test`, and `monte_carlo_test` accept a statistic function, samples, and (except `jackknife`) a generator, construct a plan with one-shot defaults, and return inference only.
Defaults are 9999 replicates of an independent design with a two-sided 95% BCa interval for `bootstrap`; 9999 randomized permutations of two independent groups for a two-sided test for `permutation_test`; and 9999 null samples for a two-sided test for `monte_carlo_test`.
One-shot functions return errors unless all replicates complete.
To choose a design, method, and count, construct `ResamplingPlan` and run `evaluate`, which allocates output and workspace, or borrowed `evaluate_into`, which uses caller-owned output and `workspace()` workspace.
Plan execution returns a report in `Ok` even when stopped by a computation-count limit, cancellation, or deadline; determine completion through `StatsTermination`.
Reports from early stopping carry no inference.
Intervals and p-values are statistical estimates, not guaranteed enclosures.
