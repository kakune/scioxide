This page collects estimators for data whose time order matters.
Survival times use `SurvivalObservation` (independent subjects observed on interval $(\text{entry}, \text{time}]$); events and censoring at the same time both belong to the risk set immediately before that time.
All intervals are pointwise asymptotic approximations, not simultaneous bands.
One-shot survival-curve and log-rank functions accept only observations and use default `SurvivalOptions`, with two-sided 95% survival-curve intervals.
For Cox regression and ARIMA, scioxide-stats prepares the objective and an injected solver implementing `FitSolver` minimizes it.
One-shot `cox_fit` uses default settings and accepts only successful termination, converting other terminations to errors.
Detailed `cox_fit_with_options` and scoped `cox_fit_scoped` forms return fits even when stopped at a limit.
Determine success only from the termination reason in `FitReport`; create inference and forecast models only from validated candidates.
Time-series summaries retain missing observations on the original time grid rather than compacting them and changing time intervals.
