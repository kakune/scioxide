Rounding to instrument resolution produces repeated values (ties), while a histogram delimited by a tolerance window encounters values outside it.
In both cases, counting is ambiguous until boundary conventions are specified.
Using deviations of component lengths from their nominal value (in mm), this page checks how scioxide-stats empirical distribution functions and binning count boundary and out-of-range observations against hand counts.

## Distribution functions for tied samples

For $n$ observations $x_1, \dots, x_n$, define the empirical distribution and survival functions by

$$
F_n(x) = \frac{\#\{i : x_i \le x\}}{n}, \qquad S_n(x) = \frac{\#\{i : x_i > x\}}{n}
$$


$F_n$ is a right-continuous step function jumping at observed values; $m$ tied observations produce a jump of $m/n$ at that value.
The deviations $[1, 2, 2, 4]$ mm read at 1 mm resolution have a tie at 2; at $x = 2$ both observations equal to 2 are included, giving

$$
F_4(2) = \frac{3}{4}, \qquad S_4(2) = \frac{1}{4}
$$


$F_n(x) + S_n(x) = 1$ holds for every $x$.
`EmpiricalDistribution::survival` directly counts observations greater than $x$ rather than computing $1 - F_n$.
This avoids cancellation in subtraction from 1 when tail probabilities are small; ties follow the same convention as `cdf`.
Queries on a sorted sample use binary search in $O(\log n)$ time.
A NaN query gives `InvalidInput`; $\pm\infty$ returns 0 or 1.

Tie handling depends on the quantile definition.
The type 1 (`NearestRank`) quantile is the observation at rank $\lceil np \rceil$, corresponding to the left-continuous inverse $\inf\{x : F_n(x) \ge p\}$ of $F_n$.
Type 7 (`Linear`) linearly interpolates the order statistics on either side of zero-based position $h = (n-1)p$.
At $p = 0.75$, type 1 returns the rank-3 observation, 2 mm; type 7 interpolates $x_{(2)} = 2$ and $x_{(3)} = 4$ (zero-based) at position $h = 2.25$, giving 2.5 mm.

`EmpiricalDistribution::estimated_cdf` returns a CDF estimate obtained by inverting the selected quantile definition.
For type 7, let $k$ count observations at or below $x$, with $x_{(k)} \le x \le x_{(k+1)}$ (one-based); setting $h = k + (x - x_{(k)})/(x_{(k+1)} - x_{(k)})$ gives the returned value $(h-1)/(n-1)$.
Linearly joining observations makes this continuous, unlike the steps of $F_n$.
At $x = 2$, $k = 3$ and $h = 3$ give $2/3$; the type 7 quantile function maps back through $Q_7(2/3) = 2$.

To evaluate many query points or several independent samples together, pass `BatchView`, a sequence of query points, and `CdfMethod` to the function `cdf`.
`CdfMethod::Empirical` returns $F_n$, `Survival` returns $S_n$, and `Estimated(rule)` matches `estimated_cdf`.
Each batch is sorted in $O(n \log n)$ time, and queries use binary search.
The returned vector groups query points by batch; batch $b$ and query $j$ occupy position $b m + j$ ($m$ is the query count).

The next cell varies query point $x$, evaluating $F_4(x)$, $S_4(x)$, and the type 7 CDF estimate with both a presorted `EmpiricalDistribution` and batch `cdf`, and compares them with direct observation counts.
The plot shows $F_4$, $S_4$, and the type 7 estimate at 101 points from 0 mm to 5 mm, evaluated with batch `cdf`.
Type 1 and type 7 quantiles at $p = 0.75$ are also compared with hand calculations from ranks and positions.

```rust
//| id: stats-cdf-tied-support

//| run: reactive
//| crates: [scioxide-core, scioxide-stats]
//| inputs:
//|   query: {"type":"range","label":"Query point x [mm]","description":"Vary across tied 2 mm observations and unobserved values such as 3 mm.","min":0,"max":5,"step":0.5,"value":2}
//| cases:
//|   - {"id":"gap","label":"x = 3 mm","description":"At unobserved values F is flat; only the type 7 estimate changes.","inputs":{"query":3}}
//|   - {"id":"below","label":"x = 0 mm","description":"Below the minimum, F = 0 and S = 1.","inputs":{"query":0}}
//|   - {"id":"above","label":"x = 5 mm","description":"Above the maximum, F = 1 and S = 0.","inputs":{"query":5}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"probabilities","path":"/rows/0/1","equals":0.75}
//|       - {"artifact":"probabilities","path":"/rows/1/2","equals":0.25}
//|       - {"artifact":"probabilities","path":"/rows/2/3","equals":1}
//|       - {"artifact":"probabilities","path":"/rows/0/4","approx":{"value":0.6666666666666666,"rtol":1e-12}}
//|       - {"artifact":"quantiles","path":"/rows/0/1","equals":2}
//|       - {"artifact":"quantiles","path":"/rows/1/1","approx":{"value":2.5,"rtol":1e-12}}
//|   - case: gap
//|     expect:
//|       - {"artifact":"probabilities","path":"/rows/0/1","equals":0.75}
//|       - {"artifact":"probabilities","path":"/rows/1/4","approx":{"value":0.8333333333333334,"rtol":1e-12}}
//|   - case: below
//|     expect:
//|       - {"artifact":"probabilities","path":"/rows/0/1","equals":0}
//|       - {"artifact":"probabilities","path":"/rows/0/2","equals":1}
//|   - case: above
//|     expect:
//|       - {"artifact":"probabilities","path":"/rows/1/1","equals":1}
//|       - {"artifact":"probabilities","path":"/rows/1/2","equals":0}
use scioxide_core::{RealScalar, StridedLayout};
use scioxide_stats::{
    Axis, BatchView, CdfMethod, EmpiricalDistribution, QuantileMethod, QuantileProbability,
    QuantileRule, Unweighted, cdf,
};

// Deviations read at 1 mm resolution [mm]. Two values equal 2 (sorted).
let sample = [1.0_f64, 2.0, 2.0, 4.0];
let n = sample.len() as f64;
let law = EmpiricalDistribution::new(&sample, Unweighted).map_err(|e| e.to_string())?;
let type7 = QuantileRule::new(QuantileMethod::Linear);
let cumulative = law.cdf(query).map_err(|e| e.to_string())?;
let survival = law.survival(query).map_err(|e| e.to_string())?;
let estimated = law.estimated_cdf(query, type7).map_err(|e| e.to_string())?;
// Pass the same sample to batch cdf. Query points are x and the plot's 101 points.
let (shape, strides) = ([4_usize], [1_usize]);
let layout = StridedLayout::new(&shape, &strides).map_err(|e| e.to_string())?;
let view = BatchView::new(&sample, layout, Axis::Index(0)).map_err(|e| e.to_string())?;
let grid: Vec<f64> = (0..=100).map(|i| 0.05 * f64::from(i)).collect();
let batch = |points: &[f64], method| cdf(view, points, method).map_err(|e| e.to_string());
let batch_cdf = batch(&[query], CdfMethod::Empirical)?[0];
let batch_survival = batch(&[query], CdfMethod::Survival)?[0];
let batch_estimated = batch(&[query], CdfMethod::Estimated(type7))?[0];
// Independent check: count observations at or below x and greater than x.
let below = sample.iter().filter(|&&v| v <= query).count() as f64 / n;
let above = sample.iter().filter(|&&v| v > query).count() as f64 / n;
let curve = |values: Vec<f64>| -> Vec<[f64; 2]> {
    grid.iter().zip(values).map(|(&x, y)| [x, y]).collect()
};
let empirical_curve = curve(batch(&grid, CdfMethod::Empirical)?);
let survival_curve = curve(batch(&grid, CdfMethod::Survival)?);
let estimated_curve = curve(batch(&grid, CdfMethod::Estimated(type7))?);
let step = serde_json::json!({ "step": "end" });
emit_line_chart!(
    &vec![

        serde_json::json!({ "name": "S₄(x) = P(X > x)", "points": survival_curve, "style": step }),
        serde_json::json!({ "name": "Type 7 CDF estimate", "points": estimated_curve })
    ],
    options = &serde_json::json!({
        "xLabel": "Deviation from nominal value x [mm]",
        "yLabel": "Probability [-]",
        "annotations": [{ "kind": "line", "axis": "x", "value": query, "label": "Query point x" }]
    })
);
let fixed4 = serde_json::json!({ "fractionDigits": 4 });
let columns = serde_json::json!([
    { "key": "0", "label": "Path" },
    { "key": "1", "label": "F(x) [-]", "type": "number", "format": fixed4 },
    { "key": "2", "label": "S(x) [-]", "type": "number", "format": fixed4 },
    { "key": "3", "label": "F(x) + S(x) [-]", "type": "number", "format": fixed4 },
    { "key": "4", "label": "Type 7 estimate [-]", "type": "number", "format": fixed4, "nullText": "—" }
]);
let rows = vec![
    (
        "EmpiricalDistribution",
        cumulative,
        survival,
        cumulative + survival,
        Some(estimated),
    ),
    (
        "Batch cdf",
        batch_cdf,
        batch_survival,
        batch_cdf + batch_survival,

emit_table_with_columns!(

    rows,
    metadata = serde_json::json!({ "id": "probabilities" })

// Quantiles at p = 0.75 and hand calculations from ranks/positions.
let p = QuantileProbability::new(0.75).map_err(|e| e.to_string())?;
let q1 = law.quantile(p, QuantileRule::new(QuantileMethod::NearestRank));
let q1 = q1.map_err(|e| e.to_string())?.value();
let q7 = law.quantile(p, type7).map_err(|e| e.to_string())?.value();
let rank = RealScalar::ceil(n * 0.75) as usize; // Type 1: one-based rank ⌈np⌉
let h = (n - 1.0) * 0.75; // Type 7: zero-based position (n − 1)p
let low = RealScalar::floor(h) as usize;
let by_hand7 = sample[low] + (h - low as f64) * (sample[low + 1] - sample[low]);
let fixed2 = serde_json::json!({ "fractionDigits": 2 });
let quantile_columns = serde_json::json!([
    { "key": "0", "label": "Quantile at p = 0.75" },
    { "key": "1", "label": "API value [mm]", "type": "number", "format": fixed2 },
    { "key": "2", "label": "Hand calculation [mm]", "type": "number", "format": fixed2 }
]);
let quantiles = vec![
    ("Type 1 (NearestRank)", q1, sample[rank - 1]),
    ("Type 7 (Linear)", q7, by_hand7),
];
emit_table_with_columns!(
    quantile_columns,
    quantiles,
    metadata = serde_json::json!({ "id": "quantiles" })
);
```

At the default $x = 2$ mm, all three paths return $F = 0.75$ and $S = 0.25$, summing to 1.
Both tied observations enter the $F$ side.
The type 7 CDF estimate is $2/3 \approx 0.6667$ with both `EmpiricalDistribution` and batch `cdf`.

At the unobserved $x = 3$ mm, $F$ and $S$ stay flat at their $x = 2$ values, while $h = 3.5$ gives a higher type 7 estimate of $2.5/3 \approx 0.8333$.
At $x = 0$, $F = 0$ and $S = 1$; at $x = 5$, $F = 1$ and $S = 0$; the type 7 estimate also becomes 0 and 1.
The plotted step jumps two increments, from 0.25 to 0.75, at value 2, showing the jump's increase with the number of ties.

At $p = 0.75$, type 1 returns observation 2 mm at rank $\lceil 4 \times 0.75 \rceil = 3$; type 7 linearly interpolates at zero-based position $3 \times 0.75 = 2.25$ to return 2.5 mm, matching hand calculations.
Type 1 stays at the tied value; type 7 interpolates toward the next observation, 4 mm.

## Binning observations outside the range and on boundaries

Divide tolerance window $[0, b]$ mm into two equal bins and count seven deviations $[-0.25, 0, 0.25, 0.5, 0.75, 1.0, 1.25]$ mm.
`BinPlan::uniform(&[(lower, upper, number_of_bins)])` divides each axis into equal-width bins; outer edges equal the specified endpoints, while internal edge $i$ is the rounded value of $\text{lower}\cdot(n-i)/n + \text{upper}\cdot i/n$.
Bins are left-closed and right-open $[e_i, e_{i+1})$; only the final bin includes upper endpoint $e_m$.
Values below the window's lower endpoint count as underflow, and values above its upper endpoint as overflow, entering no bin.
A lower endpoint at least as large as the upper endpoint, zero bins, or adjacent edges rounding to the same value gives `InvalidInput`.

The function `binned_statistics(&plan, view, values, statistic, options)` distributes each batch's observations in `BatchView` into bins, computing the per-bin quantity selected by `BinnedStatistic`.
Observation mass is 1 for unweighted data, the count for frequency weights, and the weight for mass weights.

- `Count` is the bin's observation count; `Mass` is its total mass.
- `RelativeFrequency` divides bin mass by all accepted observation mass, including out-of-range observations.
  The sum over bins therefore equals the fraction in the window rather than 1.
- `Density` divides bin mass by in-window mass and bin width.
  Multiplying by bin widths and summing gives 1, describing the distribution's shape within the window.
- `CumulativeFrequency` is cumulative mass from the left; `Sum`, `Mean`, `StandardDeviation`, `Minimum`, `Maximum`, and `Median` summarize separately supplied per-observation values `values` within each bin.

The resulting `BinnedResult` stores per-bin `BinEstimate` (`count`, `mass`, `value`) in `bins` and per-batch `BinnedDiagnostics` in `diagnostics`.
Diagnostics include accepted mass `admitted_mass`, in-window mass `retained_mass`, underflow and overflow masses `underflow_mass` and `overflow_mass`, and the count of observations skipped by policy `skipped`.
Mass values overflowing in `f64` become `None`.
Undefined values, such as empty-bin means or medians, are `None` rather than NaN.

The next cell varies upper endpoint $b$, obtaining counts, relative frequencies, and densities, and comparing with hand counts using left-closed/right-open bins except for the final bin's included upper endpoint.
Varying upper endpoint $b$ moves observations at 1.0 mm and 1.25 mm between boundaries, the window interior, and outside the window.

```rust
//| id: stats-bin-boundary-normalization
//| ref: stats-bin-boundary-normalization
//| title: "Distinguish relative frequency including out-of-range observations from in-range density"
//| run: reactive
//| crates: [scioxide-core, scioxide-stats]
//| inputs:
//|   upper_edge: {"type":"range","label":"Tolerance-window upper endpoint b [mm]","description":"The 1.0 mm observation lies on the final bin's upper endpoint at b = 1.0.","min":0.75,"max":1.5,"step":0.25,"value":1}
//| cases:
//|   - {"id":"narrow","label":"b = 0.75 mm","description":"The 0.75 mm observation stays in the window at its upper endpoint; 1.0 mm and 1.25 mm become overflow.","inputs":{"upper_edge":0.75}}
//|   - {"id":"edge-125","label":"b = 1.25 mm","description":"The 1.25 mm observation lies at the upper endpoint, and internal edge 0.625 mm falls between 0.5 mm and 0.75 mm.","inputs":{"upper_edge":1.25}}
//|   - {"id":"wide","label":"b = 1.5 mm","description":"No overflow remains.","inputs":{"upper_edge":1.5}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"bins","path":"/rows/1/2","equals":3}
//|       - {"artifact":"bins","path":"/rows/1/3","equals":3}
//|       - {"artifact":"bins","path":"/rows/0/5","approx":{"value":0.8,"rtol":1e-12}}
//|       - {"artifact":"totals","path":"/rows/0/1","approx":{"value":0.7142857142857143,"rtol":1e-12}}
//|       - {"artifact":"totals","path":"/rows/1/1","approx":{"value":1.0,"rtol":1e-12}}
//|       - {"artifact":"totals","path":"/rows/5/1","equals":1}
//|   - case: narrow
//|     expect:
//|       - {"artifact":"totals","path":"/rows/3/1","equals":4}
//|       - {"artifact":"totals","path":"/rows/5/1","equals":2}
//|   - case: edge-125
//|     expect:
//|       - {"artifact":"bins","path":"/rows/0/2","equals":3}
//|       - {"artifact":"bins","path":"/rows/0/1","approx":{"value":0.625,"rtol":1e-12}}
//|   - case: wide
//|     expect:
//|       - {"artifact":"totals","path":"/rows/5/1","equals":0}
//|       - {"artifact":"totals","path":"/rows/0/1","approx":{"value":0.8571428571428571,"rtol":1e-12}}
use scioxide_core::StridedLayout;
use scioxide_stats::{
    Axis, BatchView, BinPlan, BinnedResult, BinnedStatistic, StatisticsOptions,
    binned_statistics,
};

// Deviations from the nominal value [mm]. −0.25 lies below the window; 1.25 lies above it when b < 1.25.
let samples = [-0.25_f64, 0.0, 0.25, 0.5, 0.75, 1.0, 1.25];
let (shape, strides) = ([7_usize], [1_usize]);
let layout = StridedLayout::new(&shape, &strides).map_err(|e| e.to_string())?;
let view = BatchView::new(&samples, layout, Axis::Index(0)).map_err(|e| e.to_string())?;
let plan = BinPlan::uniform(&[(0.0, upper_edge, 2)]).map_err(|e| e.to_string())?;
let run = |statistic| {
    binned_statistics(&plan, view, None, statistic, StatisticsOptions::default())
        .map_err(|e| e.to_string())
};
let counts = run(BinnedStatistic::Count)?;
let relative = run(BinnedStatistic::RelativeFrequency)?;
let density = run(BinnedStatistic::Density)?;
let width = upper_edge / 2.0;
// Independent check: count with left-closed/right-open bins, including the upper endpoint only in the final bin.
let by_hand = |k: usize| {
    let (lo, hi) = (k as f64 * width, (k + 1) as f64 * width);
    let inside = |x: f64| x >= lo && (x < hi || (k == 1 && x == upper_edge));
    samples.iter().filter(|&&x| inside(x)).count()
};
let value = |result: &BinnedResult<f64>, k: usize| {
    result.bins[k]
        .value
        .ok_or_else(|| "Undefined bin value".to_string())
};
let mut rows = Vec::new();
for k in 0..2 {
    let (lo, hi) = (k as f64 * width, (k + 1) as f64 * width);
    let (r, d) = (value(&relative, k)?, value(&density, k)?);
    rows.push((lo, hi, counts.bins[k].count, by_hand(k), r, d));
}
let fixed4 = serde_json::json!({ "fractionDigits": 4 });
let columns = serde_json::json!([
    { "key": "0", "label": "Lower edge [mm]", "type": "number", "format": fixed4 },
    { "key": "1", "label": "Upper edge [mm]", "type": "number", "format": fixed4 },
    { "key": "2", "label": "Count [observations]", "type": "integer" },
    { "key": "3", "label": "Direct count [observations]", "type": "integer" },
    { "key": "4", "label": "Relative frequency [-]", "type": "number", "format": fixed4 },
    { "key": "5", "label": "Density [1/mm]", "type": "number", "format": fixed4 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "bins" })
);
let d = &relative.diagnostics[0];
let relative_sum = value(&relative, 0)? + value(&relative, 1)?;
let density_sum = width * (value(&density, 0)? + value(&density, 1)?);
let totals = vec![
    ("Sum of relative frequencies [-]", Some(relative_sum)),
    ("Sum of density × width [-]", Some(density_sum)),
    ("Accepted mass admitted_mass [observations]", d.admitted_mass),
    ("In-window mass retained_mass [observations]", d.retained_mass),
    ("Underflow mass underflow_mass [observations]", d.underflow_mass),
    ("Overflow mass overflow_mass [observations]", d.overflow_mass),
];
let total_columns = serde_json::json!([
    { "key": "0", "label": "Quantity" },
    { "key": "1", "label": "Value", "type": "number", "format": fixed4, "nullText": "Overflow" }
]);
emit_table_with_columns!(
    total_columns,
    totals,
    metadata = serde_json::json!({ "id": "totals" })
);
```

At the default $b = 1.0$ mm, bin $[0, 0.5)$ contains two observations, 0 and 0.25; final bin $[0.5, 1.0]$ contains three, 0.5, 0.75, and boundary value 1.0; counts match direct counting.
$-0.25$ is underflow and 1.25 overflow, leaving mass 5 in the window out of accepted mass 7.
Relative frequencies are $2/7$ and $3/7$, summing to $5/7 \approx 0.7143$; densities are $2/(5 \times 0.5) = 0.8$ and $3/(5 \times 0.5) = 1.2$, summing to 1 after multiplication by widths.

At $b = 0.75$, 0.75 stays in the window at the final bin's upper endpoint, while 1.0 and 1.25 become overflow (in-window mass 4, relative-frequency sum 0.5714).
At $b = 1.25$, the internal edge becomes 0.625 mm, placing 0.5 mm in the first bin and 0.75 mm in the last, with counts 3 and 3.
Overflow is 0, and the relative-frequency sum is 0.8571.
At $b = 1.5$, in-window mass is also 6, overflow is 0, and relative frequencies sum to 0.8571.
In every case, density × width sums to 1, and relative frequencies sum to in-window mass divided by accepted mass.

## Summary

For tied samples, the empirical distribution function includes every boundary observation in $P(X \le x)$, while the survival function counts only strictly greater observations, so their sum is 1 for every $x$.
Tie handling depends on the quantile definition: type 1 stays at the tied value, while type 7 interpolates between neighboring observations.
For a continuous CDF estimate, use `estimated_cdf` or `CdfMethod::Estimated`, stating which quantile definition is inverted.
For binning, the left-closed/right-open rule and final-bin upper-endpoint treatment determine boundary assignments, while diagnostics retain out-of-range observation mass.
Read relative frequencies for the fraction outside the window and densities for the distribution's shape within it.
