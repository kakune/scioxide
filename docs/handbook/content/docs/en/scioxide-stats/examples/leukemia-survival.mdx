Survival analysis is the statistical study of the time until an event such as relapse, death, or failure.
For a subject whose event has not occurred when follow-up ends, the event time is known only to be later than that point.
This is called right censoring; with censored data, simple means or proportions underestimate the time to the event.
This page computes estimators and tests that handle censoring correctly using leukemia trial data commonly found in survival analysis textbooks, and compares the results with published values.

Data sources and the rights associated with the example code and numerical facts from the literature are explained in [Licenses and data attribution](../../../reference/licenses/).

## Data from the 6-MP clinical trial

E. J. Freireich et al., "The effect of 6-mercaptopurine on the duration of steroid-induced remissions in acute leukemia", *Blood* 21 (1963), 699–716, divided 42 children with acute leukemia in remission into 21 matched pairs, randomly assigned them to 6-mercaptopurine (6-MP) or placebo, and recorded remission duration in weeks.
E. A. Gehan, *Biometrika* 52 (1965), 203–223, presented these remission durations as an example of a two-sample test; Cox (1972) and many later textbooks use them.

| Group | Remission duration [weeks] (+ indicates censoring) |
|---|---|
| Placebo (21 subjects) | 1, 1, 2, 2, 3, 4, 4, 5, 5, 8, 8, 8, 8, 11, 11, 12, 12, 15, 17, 22, 23 |
| 6-MP (21 subjects) | 6, 6, 6, 6+, 7, 9+, 10, 10+, 11+, 13, 16, 17+, 19+, 20+, 22, 23, 25+, 32+, 32+, 34+, 35+ |

All 21 placebo subjects relapsed; in the 6-MP group, 9 relapsed and 12 were censored.
Each value was checked against the `gehan` data in R's MASS package (the table in Gehan 1965).
The original trial used a paired sequential testing design; here, as in Gehan and Cox, it is treated as an unpaired comparison of two groups.

The definitions block contains both groups' remission durations, a function converting them to `SurvivalObservation`, and functions constructing vertices for step plots.
`SurvivalObservation::new(entry, time, outcome)` constructs an observation containing the interval $(\mathrm{entry}, \mathrm{time}]$ and whether an event occurred (`SurvivalOutcome::Event`) or censoring occurred (`SurvivalOutcome::Censored`) at `time`.
Subjects whose `entry` is `None` enter the risk set from the start; nonfinite times or `entry ≥ time` return `InvalidInput`.
These data have no delayed entry (left truncation), so every `entry` is `None`.

```rust
    (6.0, true),
    (6.0, true),
    (6.0, false),
    (7.0, true),
    (9.0, false),
    (10.0, true),
    (10.0, false),

    (25.0, false),
    (32.0, false),
    (32.0, false),
    (34.0, false),
    (35.0, false),
];
pub(crate) const GROUPS: [&str; 2] = ["Placebo", "6-MP"];
/// Final follow-up time for each group [weeks].
pub(crate) const LAST_FOLLOW_UP: [f64; 2] = [23.0, 35.0];

/// Observations in [placebo, 6-MP] order, without delayed entry.
pub(crate) fn groups() -> Result<[Vec<SurvivalObservation<f64>>; 2], SciOxideError> {
    let observe = |&(time, event): &(f64, bool)| {
        let outcome = if event {
            SurvivalOutcome::Event
        } else {
            SurvivalOutcome::Censored
        };
        SurvivalObservation::new(None, time, outcome)
    };
    let placebo: Vec<(f64, bool)> = PLACEBO.iter().map(|&time| (time, true)).collect();
    Ok([
        placebo.iter().map(observe).collect::<Result<_, _>>()?,
        MERCAPTOPURINE
            .iter()
            .map(observe)
            .collect::<Result<_, _>>()?,
    ])
}

/// Convert right-continuous steps (tᵢ, vᵢ) into vertices from value start at time 0 through end.
pub(crate) fn step_points(start: f64, steps: &[(f64, f64)], end: f64) -> Vec<[f64; 2]> {
    let mut points = vec![[0.0, start]];
    points.extend(steps.iter().map(|&(t, v)| [t, v]));
    let [last_time, last_value] = points[points.len() - 1];
    if end > last_time {
        points.push([end, last_value]);
    }
    points
}

/// A stepwise interval band. Band x-coordinates must be strictly increasing, so
/// place the preceding value for each (tᵢ, vᵢ, lower, upper) at tᵢ − 10⁻⁶ weeks to form steps.
pub(crate) fn step_band(steps: &[(f64, f64, f64, f64)], end: f64) -> Vec<[f64; 4]> {
    let mut band = vec![[0.0, 1.0, 1.0, 1.0]];
    for &(t, value, lower, upper) in steps {
        let [_, previous, low, high] = band[band.len() - 1];
        band.push([t - 1e-6, previous, low, high]);
        band.push([t, value, lower, upper]);
    }
    let [last_time, value, low, high] = band[band.len() - 1];
    if end > last_time {
        band.push([end, value, low, high]);
    }
    band
}
```

## Kaplan–Meier and Nelson–Aalen estimation

Let $T$ be the event time, with survival function $S(t) = P(T > t)$, hazard $h(t) = \lim_{\Delta \to 0} P(t \le T < t+\Delta \mid T \ge t)/\Delta$, and cumulative hazard $H(t) = \int_0^t h(u)\,du$.
For a continuous distribution, $S(t) = \exp\{-H(t)\}$.
Assume censoring is independent of the event time (independent censoring).
If this assumption fails, for example because patients in worse condition are more likely to leave follow-up, all the estimators below are biased.

Let $t_1 < t_2 < \cdots$ be the distinct event times, $n_i$ the number at risk immediately before $t_i$, and $d_i$ the number of events at $t_i$.
When events and censoring occur at the same time, censored subjects are included in the risk set at $t_i$ (censoring is treated as occurring immediately after the events).
The Kaplan–Meier product-limit estimate and Greenwood sum are

$$
\hat S(t) = \prod_{t_i \le t} \left(1 - \frac{d_i}{n_i}\right),\qquad
\hat\sigma^2(t) = \sum_{t_i \le t} \frac{d_i}{n_i(n_i - d_i)}
$$

Here $\hat\sigma^2$ estimates the variance of $\ln \hat S(t)$ (Kaplan and Meier 1958; Klein and Moeschberger 2003, Chapter 4).
`kaplan_meier_with_options` constructs pointwise intervals using the log-log transformation.
With normal critical value $z$ for the confidence level and $r = z\hat\sigma/|\ln \hat S|$, the interval is $[\hat S^{\exp(r)}, \hat S^{\exp(-r)}]$.
This interval stays within $[0, 1]$ and has coverage closer to nominal in small samples than an interval using Greenwood's variance directly.
At $\hat S = 0$, $\ln \hat S$ is undefined, so `interval` is `None`.
The Greenwood sum omits terms with $d_i = n_i$.

The Nelson–Aalen estimator directly estimates the cumulative hazard.

$$
\hat H(t) = \sum_{t_i \le t} \frac{d_i}{n_i},\qquad \widehat{\operatorname{Var}}\,\hat H(t) = \sum_{t_i \le t} \frac{d_i}{n_i^2}
$$

`nelson_aalen_with_options` constructs the interval as $\hat H \exp(\mp z\sqrt{\widehat{\operatorname{Var}}}/\hat H)$.
Since $1 - x \le e^{-x}$, $\hat S_{\mathrm{KM}}(t) \le \exp\{-\hat H(t)\}$, so $-\ln \hat S_{\mathrm{KM}}$ is at least $\hat H$.
Their difference grows later in follow-up as the risk set shrinks.

Both functions sort observations by time ($O(n \log n)$), compute all time points in one scan ($O(n)$), and return one point per distinct event time.
The one-shot calls `kaplan_meier` and `nelson_aalen` fix the confidence level at the default 95%.
For repeated processing of many samples, use `kaplan_meier_into` and `nelson_aalen_into` to write into output arrays while reusing `SurvivalWorkspace`.
Empty observations return `InvalidInput`; memory use exceeding the `SurvivalOptions::with_max_bytes` limit returns `ResourceLimit`.

The cell below computes Kaplan–Meier and Nelson–Aalen curves for both groups and compares the 6-MP curve with published values.
The published values are $\hat S(t)$ to four decimal places from the table in Chapter 2 of D. G. Kleinbaum and M. Klein, *Survival Analysis: A Self-Learning Text*, 3rd ed., Springer, 2012.

## Logrank testing and Cox regression

The logrank test examines the null hypothesis $h_1(t) = h_2(t)$ that the two groups' hazards are equal.
At each event time $t$, let $r_k$ be the number at risk in group $k$ and $d_k$ the event count, with $r = r_1 + r_2$ and $d = d_1 + d_2$.
The hypergeometric distribution for the 2 × 2 table (group × event status) with fixed margins gives the sums

$$
O_1 = \sum_t d_1,\qquad E_1 = \sum_t \frac{d\,r_1}{r},\qquad
V = \sum_t \frac{d\,(r-d)\,r_1 r_2}{r^2 (r-1)}
$$

Compare the statistic $(O_1 - E_1)^2 / V$ with a $\chi^2$ distribution with 1 degree of freedom (Mantel 1966).
The p-value is an upper-tail probability from an asymptotic distribution, rather than an exact or permutation p-value.
Summing 2 × 2 tables across time points follows the same principle as the Mantel–Haenszel estimate in the [kidney stone example](../simpsons-paradox/).
`logrank_test(first, second)` returns $O$, $E$, $V$, and the statistic; an empty group or $V = 0$ (no events) returns `InvalidInput`.
Power decreases when the hazard ratio changes with time.

The Cox proportional hazards model sets the hazard for a subject with covariates $x_i$ to $h(t \mid x_i) = h_0(t)\exp(x_i^\top\beta)$ and estimates $\beta$ by partial likelihood without specifying the baseline hazard $h_0$ (Cox 1972).
Here $x_i = 1$ for 6-MP and $x_i = 0$ for placebo, so $\exp(\beta)$ is the 6-MP hazard ratio relative to placebo.
For $d$ tied events, the Breslow approximation uses the risk-set sum $\sum_{j \in R} w_j$ ($w_j = \exp(x_j^\top\beta)$) for all $d$ denominators; the Efron approximation uses $\sum_{j \in R} w_j - (k/d)\sum_{j \in D} w_j$ for denominator $k$.
These data include tied events, such as three at week 6 and four at week 8, so the two approximations give slightly different results.

`PreparedCox::new(observations, design, ties, options)` prepares the negative log partial likelihood $\ell(\beta)$ and evaluates `FitObjective::value`, `FitDerivatives::gradient` (negative score), and `hessian` (observed information).
Exponentials use an extended-exponent representation and covariates enter as between-subject differences, avoiding overflow even for large linear predictors.
One evaluation costs $O(enp)$, where $e$ is the event count, $n$ the observation count, and $p$ the covariate count.
Fit with `cox_fit_with_options(problem, initial, solver, options)`; minimization is delegated to the caller-provided solver `FitSolver`.
Here the solver is `LbfgsBFitSolver` (L-BFGS-B) from `scioxide-optimize`.
Only when the solver reports `Converged` does `CoxFit::report` return `CoxReport`, containing observed information, coefficient Wald intervals $\hat\beta \pm z\,\mathrm{SE}$, hazard ratios, baseline cumulative hazard, and Schoenfeld residuals.
The one-shot `cox_fit` returns an error if the fit does not converge.

Three tests can be constructed from the same partial likelihood.

- The score test is $U(0)^2 / I(0)$, where $U$ is the score and $I$ the observed information.
  Under the Breslow approximation, $U(0) = O_2 - E_2$, matching the logrank numerator.
  $I(0) = \sum_t d\,r_1 r_2 / r^2$ removes the tie correction $(r-d)/(r-1)$ from logrank's $V$, so without tied events the score and logrank statistics coincide.
- The likelihood-ratio test is $2\{\ell(0) - \ell(\hat\beta)\}$.
- The Wald test is $\hat\beta^2 / \widehat{\operatorname{Var}}(\hat\beta)$.

The logrank quantities also give the one-step hazard-ratio approximation $\exp\{(O_2 - E_2)/V\}$ (Peto's estimate).
This corresponds to one Newton step from $\beta = 0$ and is biased when the hazard ratio is far from 1.

With the default Efron approximation, $\hat\beta = -1.572$ (standard error 0.412), and the hazard ratio is 0.208 (95% interval: 0.093–0.466).
The estimated relapse hazard in the 6-MP group is about one fifth of that in the placebo group, and the interval excludes 1.
From $O = (21, 9)$, $E = (10.75, 19.25)$, and $V = 6.257$, the logrank test returns statistic 16.79 and p-value $4.2 \times 10^{-5}$.
The score test (17.25), likelihood-ratio test (16.35), and Wald test (14.53) are asymptotically equivalent tests of the same null hypothesis; all give p < 0.001 for this sample.

Switching to the Breslow approximation gives $\hat\beta = -1.509$, hazard ratio 0.221, and score statistic 15.93.
The score $U(0) = O_2 - E_2 = -10.25$ then matches the logrank numerator; only the denominators ($I(0) = 6.596$ and $V = 6.257$) differ.
Peto's one-step estimate 0.194 and the O/E ratio 0.239 bracket the maximum-likelihood estimate 0.208.

In both groups, the maximum difference between the Cox and Kaplan–Meier curves is 0.08, smaller than the Kaplan–Meier 95% interval half-width (0.17–0.25 for 6-MP), showing no major conflict with proportional hazards.
For a numerical check, plot `CoxReport::schoenfeld_residuals` Schoenfeld residuals against event time and look for a trend (Grambsch and Therneau 1994).
`scioxide-stats` returns these residuals but does not provide a proportional-hazards test based on them.

## Error and complexity

- Kaplan–Meier, Nelson–Aalen, and logrank use an $O(n \log n)$ sort and an $O(n)$ scan, computing values in double precision.
  The 6-MP $\hat S$ is a product of rational numbers, so its differences from the four-decimal published values arise only from rounding.
- Pointwise intervals are marginal intervals at each time, rather than simultaneous bands for the entire curve.
  Whole-curve coverage requires bands such as Hall–Wellner, which `scioxide-stats` does not provide.
- Logrank and Cox test p-values are asymptotic approximations.
  This sample has 30 events, so the approximation is considered reasonable; with only a few events, check using permutation p-values (for example, `classical_permutation_test`).
- For Cox fitting, one partial-likelihood evaluation costs $O(enp)$, and L-BFGS-B evaluates the value and gradient each iteration.
  With 42 observations, 30 events, and one covariate, this example runs in about 0.2 seconds even in wasm.
  With a single covariate, Newton's method gives the same values.
  If an eigenvalue of the observed information $I(\hat\beta)$ is at or below the `CoxInferenceOptions::rank_tolerance` threshold, the information is considered rank deficient, and covariance and intervals are `None`.

## Summary

For censored remission durations, the Kaplan–Meier estimate reproduces the published 6-MP survival curve to four decimal places; the medians are 8 weeks for placebo and 23 weeks for 6-MP.
Log-log interval widths change with the confidence level, and the intervals are undefined at points where $\hat S = 0$.
The logrank statistic 16.79 has the same numerator as the Breslow Cox score statistic, differing only in the denominator's tie correction.
Cox regression estimates the 6-MP hazard ratio as 0.208 (Efron, 95% interval: 0.093–0.466), changing to 0.221 (Breslow) with the treatment of tied events.
Check proportional hazards by comparing Kaplan–Meier and model curves and inspecting Schoenfeld residuals.
