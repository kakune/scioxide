When the same input occurs twice in an expression, ordinary interval arithmetic lets the two occurrences vary independently.
For example, $x-x$ for $x\in[1-h,1+h]$ is truly zero, but interval subtraction returns $[-2h,2h]$.
Affine arithmetic assigns shared symbols to input uncertainty and preserves correlations in addition and subtraction.
Beyond simple cancellation examples, this page covers remainders of nonlinear products and the information lost when reducing symbols.

## Affine forms

Represent a real affine form with center $x_0$, coefficients $x_i$, noise symbols $\varepsilon_i\in[-1,1]$, and remainder set $\Delta_x$.

$$
\widehat x=x_0+\sum_{i=1}^{m}x_i\varepsilon_i+\Delta_x.
$$

Noise symbols are not random variables; they represent uncertainty specified only by a range.
When the same symbol occurs in two forms, its value is shared.
The remainder set encloses errors not tracked by symbols: an interval for real values, or a rectangle of real and imaginary parts for complex values.
For a real symmetric remainder $[-r_x,r_x]$, marginal ranges can be enclosed by $[x_0-s_x,x_0+s_x]$ and $s_x=\sum_i|x_i|+r_x$.
Extracting this interval alone loses information about symbols shared with other forms.

Addition and subtraction add or subtract coefficients of matching symbols.
For example, with $\widehat x=1+0.1\varepsilon_1$ and $\widehat y=2+0.2\varepsilon_1$, the difference $2\widehat x-\widehat y$ is zero.
This cancellation does not hold for $\widehat y$ constructed with a different symbol $\varepsilon_2$.
Equal input intervals differ from shared uncertainty.

### Remainders of products and nonlinear functions

Let two forms without remainders be $\widehat x=x_0+u$ and $\widehat y=y_0+v$.
Their product is given by

$$
\widehat x\widehat y=x_0y_0+y_0u+x_0v+uv
$$


The first three terms can be represented by a center and coefficients of existing symbols, but $uv$ is quadratic and cannot be stored directly in an affine form.
Using $|uv|\le s_xs_y$ from $|u|\le s_x$ and $|v|\le s_y$ encloses this part with a new error term.
The implementation also includes existing remainders and rounding errors in the evaluation, recording errors within the available symbol capacity.

Univariate functions likewise linearize as $f(x_0+u)=f(x_0)+f'(x_0)u+\mathcal R$ and enclose the remaining $\mathcal R$.
For a smooth function and a narrow input, the nonlinear remainder is of second order in the input width.
However, when $f'(x_0)\ne0$, the true range itself has first-order width, so the total output width is not always second order.
Crossing a pole or domain boundary violates the linearization assumptions and can trigger a switch to an interval-only result.
In that case, also read `AffineFallback` and `AffineReport::status()`.

## Context and ownership

`AffineContext::new(input_symbols, options)` creates a set of input symbols.
`from_coefficients(&context, center, coefficients)` maps coefficient positions to that context's input symbols.
Use `context.symbol(i)` and `AffineTerm::new` to specify symbols explicitly.
Separately created contexts have distinct symbols even when their settings and coefficients match; combining their forms produces `InvalidInput`.
Share the same context or its clone.

| Value | What it stores | Use |
|---|---|---|
| `AffineForm` | Center, remainder, and term capacity | Normal use with owned results from `unary` and `binary` |
| Arrays of `AffineState` and `AffineTerm` | State and terms separately | Caller-managed storage |
| `AffineView` / `AffineViewMut` | Read-only / writable borrow | Reuse outputs with `unary_into`, `binary_into`, and similar methods |
| `AffineWorkspace` | Temporary storage during operations | Repeated computation with the same context and scalar type |

`AffineUnary` and `AffineBinary` select operations, and `AffineProjection` selects projection onto the real or imaginary part.
In complex forms, one real noise symbol shares coefficients in the real and imaginary parts.
Separately manipulating only the marginal intervals of those parts therefore loses this correlation as well.

## A quadratic expression with cancellation of first-order terms

Consider $p(x)=x(1-x)$ for $x=1/2+h\varepsilon$.
Expanding gives $p(x)=1/4-h^2\varepsilon^2$, so the true range is $[1/4-h^2,1/4]$.
Ordinary interval multiplication treats the two factors, each with interval $[1/2-h,1/2+h]$, independently, giving width $2h$.
In affine arithmetic, first-order terms cancel, leaving the enclosure of nonlinear $\varepsilon^2$ as the main source of width.

The following cell compares ordinary interval and affine products with half-width $h,h/2,h/4$.
All quantities are dimensionless, and $h\le1/4$ keeps the factors nonnegative.
Inputs are chosen to be exactly representable in binary; the range computed by hand is displayed as an independent reference.
In wasm, only the reference table is shown, and proof computation is marked as not executed.

```rust
//| id: validated-affine-quadratic
//| ref: validated-affine-quadratic
//| title: "First-order correlation and second-order remainder"
//| run: button
//| crates: [scioxide-core, scioxide-validated]
//| inputs:
//|   half_width: {"type":"range","label":"Half-width h [-]","min":0.03125,"max":0.25,"step":0.03125,"value":0.125}
//| cases:
//|   - {"id":"wide","label":"h = 1/4","inputs":{"half_width":0.25}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"reference","path":"/rows/0/1","approx":{"value":0.234375,"atol":1e-15}}
//|   - case: wide
//|     expect:
//|       - {"artifact":"reference","path":"/rows/0/1","approx":{"value":0.1875,"atol":1e-15}}
use scioxide_core::{SciOxideError, SciOxideErrorView, InvalidInputReason};
use serde_json::json;
let unsupported = |error: &SciOxideError| {
    matches!(error.view(),
SciOxideErrorView::InvalidInput { argument, reason: InvalidInputReason::UnsupportedConfiguration, .. }
if argument == scioxide_core::argument!("rounding_environment"))
};
use scioxide_validated::{
    AffineBinary, AffineContext, AffineForm, AffineOptions, DecoratedInterval as D,
};
let reference: Vec<_> = (0..3)
    .map(|k| {
        let h = half_width / 2.0_f64.powi(k);
        (h, 0.25 - h * h, 0.25, h * h)
    })
    .collect();
emit_table_with_columns!(
    [
        "Half-width h",
        "True lower endpoint (f64 reference)",
        "True upper endpoint",
        "True width (f64 reference)"
    ],
    &reference,
    metadata = json!({"id":"reference"})
);
let proof = (|| -> Result<_, SciOxideError> {
    let context = AffineContext::new(1, AffineOptions::new().with_max_symbols(8))?;
    let mut work = context.workspace::<f64>()?;
    let one = AffineForm::constant(&context, 1.0)?;
    let mut rows = Vec::new();
    for &(h, _, _, _) in &reference {
        let x = AffineForm::from_coefficients(&context, 0.5, &[h])?;
        let y = one.binary(&x, AffineBinary::Sub, &mut work)?;
        let p = x.binary(&y, AffineBinary::Mul, &mut work)?;
        let ordinary = x.report().real();
        let interval = ordinary.mul(&D::point(1.0)?.sub(&ordinary)?)?;
        let (lo, hi) = p.report().real().set().bounds().unwrap();
        let (il, iu) = interval.set().bounds().unwrap();
        rows.push((
            h,
            lo,
            hi,
            hi.unwrap() - lo.unwrap(),
            iu.unwrap() - il.unwrap(),
            p.report().retained_symbols(),
        ));
    }
    Ok(rows)
})();
let outcome = match proof {
    Ok(rows) => {
        let fmt = json!({"notation":"scientific","significantDigits":6});
        emit_table_with_columns!(
            json!([
                {"key":"0","label":"Half-width h","type":"number","format":fmt},
                {"key":"1","label":"Affine lower endpoint","type":"number","format":fmt},
                {"key":"2","label":"Affine upper endpoint","type":"number","format":fmt},
                {"key":"3","label":"Affine width","type":"number","format":fmt},
                {"key":"4","label":"Interval-arithmetic width","type":"number","format":fmt},
                {"key":"5","label":"Symbols retained","type":"integer"}
            ]),
            rows,
            metadata = json!({"id":"bounds"})
        );
        Outcome::satisfied("Enclosed the range for three input widths")
    }
    Err(e) if unsupported(&e) => Outcome::unavailable("Proof computation not executed in this environment"),
    Err(e) => return Err(e.to_string()),
};
emit_outcome!(outcome);
```


At the default half-width $1/8$, the ordinary interval product has width $1/4$, while the affine width equals the true width $1/64$.
Halving the half-width halves the ordinary interval product's width and, in this example, quarters the affine width.
If the affine enclosure is wider than the true range, the difference is overestimation from enclosing quadratic dependencies with an interval.
This compares expressions and methods under the same input width; it is not a fixed accuracy guarantee.
Before expecting the same contraction for a general $p(x)$, check whether the first-order term vanishes.

## Symbol compression and complexity

Repeated nonlinear operations add error symbols, so `AffineOptions::with_max_symbols` sets an upper limit.
`reduce(k, workspace)` moves the smallest coefficients into the remainder, reducing the symbols to at most $k$.
This preserves inclusion but loses some correlations with other forms, so cancellation in later differences is not assured.
`retained_symbols` and `discarded_symbols` give symbol counts, while `correlation_lost` records the history of lost correlations.
Once `correlation_lost` becomes true, it remains true in subsequent results.

Basic operations on $m$ terms take $O(m)$ time; variants returning owned results allocate result storage.
The `_into` form allocates term buffers for the context's maximum symbol count and reuses temporary storage.
Exceeding the byte limit produces `ResourceLimit`, distinct from mere widening.
A result with `AffineFallback` cannot use the symbol-based approximation; inspect the real- and imaginary-part enclosures.

## Summary

Affine forms preserve linear correlations by combining coefficients of shared symbols.
Remainders of nonlinear products and functions are enclosed by error terms, so compare range width separately from overestimation width.
Symbol compression preserves inclusion by discarding correlations; inspect the diagnostics and subsequent operations.
The [cancellation example](../../examples/affine-cancellation/) examines a difference that is zero, and the [API list](../../api/intervals-and-affine/) describes contracts for owned and borrowed types.

For background on affine arithmetic, see de Figueiredo and Stolfi, *Affine arithmetic: concepts and applications*, Numerical Algorithms 37 (2004), 147–158.
