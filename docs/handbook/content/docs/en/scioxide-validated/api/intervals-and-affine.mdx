Interval APIs distinguish set representation, arithmetic enclosures, elementary-function branches, and affine forms retaining correlations.
Before choosing a type, decide whether the input is a point or an uncertain set, and whether correlations of the same variable must be used.

## Construction and conversion

`DecoratedInterval::point(v)` constructs a singleton interval for stored value $v$.
For example, `point(0.1_f64)` represents the value rounded to binary, not a guarantee for decimal $1/10$ itself.
To enclose $1/10$, divide singleton intervals 1 and 10 with interval division.
The endpoints of `new(lower, upper)` are finite and ordered; represent empty sets or infinite endpoints through conversion from `ExtendedInterval`, `empty()`, or `entire()`.

`Interval::try_from` requires a bounded, nonempty result and does not silently truncate unbounded enclosures to ordinary finite intervals.
`set().bounds()` returns an outer `None` for an empty set and an endpoint `None` for an infinite endpoint.
Distinguishing these two kinds of `None` avoids displaying the empty set and all real numbers identically.

## Choosing interval pieces and correlations

`ElementaryEnclosure::pieces()` retains at most two branches; `contains()` tests membership in their union.
`hull()` fills gaps to form one interval, so inspect pieces and status first when examining discontinuities such as tangent poles.
`EnclosureStatus` classifies the domain, and `Decoration` records definition and continuity; neither measures interval-width quality.

Affine forms track correlations of the same input, so retain `AffineForm` during operations.
Extracting `report().real()` or `imaginary()` and operating on it as an interval does not pass shared-symbol information to later operations.
Shared contexts, term buffers, and compression diagnostics are explained in the [mathematics of affine arithmetic](../../algorithms/affine-arithmetic/).
The [quadratic-remainder experiment](oxref:validated-affine-quadratic) compares interval products with correlation-preserving products.
