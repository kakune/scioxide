The quadrature API separates integrand assumptions, enclosures of requested quantities, and reverification of generated proposals.
The shortest form without configuration is `integrate(value, second_derivative, lower, upper)`.
Use `QuadratureVerifier` for tolerances, singularities, infinite tails, or multiple components.

## From oracle to certificate

1. Specify domain pieces and assumptions in an array of `QuadraturePiece`.
   Finite regular pieces and singular or tail pieces require different enclosures.
2. Branch on `request.query` in the oracle and write the requested quantity for every component to `IntervalBox`.
   Return `Unavailable` for requests that cannot be enclosed; do not replace unknown values with zero.
3. Construct `QuadratureVerifier::new(&pieces, components, &oracle, options)`.
   The verifier borrows the pieces and oracle.
4. Obtain a proposal and generation report with `generate(&tolerance, max_panels)`.
5. If a proposal exists, pass it to `verify(certificate.view())` and check the reverification status.

| Observation | Meaning |
|---|---|
| `has_enclosure()` | A proposal records a finite enclosure over the entire domain |
| `ToleranceReached` | Accuracy specified during generation was met |
| `panels()` | Number of panels forming the proposal |
| `Verified` | The proposal includes bounds recomputed from the original problem |

`Verified` alone does not imply achievement of the specified tolerance.
Wide proposals stopped by capacity limits can also be verified, so assess accuracy using both the generation report and verification status.
`QuadratureCertificateView::total` contains rectangles for componentwise totals; real problems do not use imaginary parts.

## Allocation and handling after termination

For repeated calls, prepare `QuadratureCertificate::new(capacity, components)` and `workspace(ProofRequest::refinement(capacity))`.
Passing the same workspace to `generate_into` and `verify_scoped` avoids allocations once required capacity is available.
Read each entry's stopped batch-verification status separately from single verification.
Certificates from previous calls may remain, so do not display totals without reading `has_enclosure()`.

The [three-assumption experiment](oxref:validated-quadrature-assumptions) generates and reverifies in the same cell and allows changes to panel capacity and tolerance.
See [quadrature mathematics](../../algorithms/certified-quadrature/) for remainder derivations and inequalities required at singularities and tails.
