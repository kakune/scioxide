The linear-system API separates operators enclosing problem coefficients, preconditioners applying approximate inverses, and certificates storing solution centers and radii.
For dense point-coefficient matrices, the [one-shot `solve`](../) suffices; use `LinearVerifier` to include input uncertainty.

## Assembling inputs

1. Construct `DenseIntervalOperator::point` for a point matrix or `new(lower, upper)` for componentwise lower and upper bounds.
   `MatrixView` borrows the original storage, so retain the matrix while using the verifier.
2. Prepare a preconditioning operator.
   Usually construct `LuIntervalInverse` from an LU factorization, but another fixed-matrix action is allowed; the verifier checks its accuracy.
3. Represent the right-hand side as an array of `IntervalBox`.
   `point_enclosure` represents stored points; `interval_enclosure` represents specified bounds.
4. Construct `LinearVerifier::new(&system, &inverse, options)` and choose to solve, propose an approximation, or verify a certificate.

| Operation | Caller supplies | Meaning of output |
|---|---|---|
| `solve` | Right-hand side | Verified center and radii, or no proof |
| `propose` | Right-hand side and your approximation | Certified radii for that approximation |
| `verify` | Right-hand side and borrowed center and radii | Status indicating acceptance of the proposed enclosure |
| `bounds` | Matrix bound to the verifier | Nonsingularity and upper bounds on matrix norms and condition number |

The owned form of `solve` returns `(report, Option<certificate>)`, with a certificate when the report is `Verified`.
`solve_into` writes to an existing certificate but leaves output unchanged on unsuccessful calls.
An old certificate may remain without indicating current success, so always read the report first.

## Reuse and independent checks

For repeated calls on the same problem, reserve temporary storage with `workspace(number_of_rhs_columns)` and pass output and execution scope to `*_into`.
Coefficient proofs are not reused permanently; each call recomputes bounds from the original problem.
For multiple right-hand sides, `solve_block_into` shares a matrix scan within a single call.

The [interval-coefficient example](oxref:validated-linear-uncertainty) illustrates input width and contraction, and the [rational Hilbert matrix](oxref:validated-hilbert-rational-system) illustrates constructing coefficients including rounding.
Proof inequalities are derived in [linear-system mathematics](../../algorithms/verified-linear-systems/).
