$x-x$ sharing the same uncertainty is exactly zero.
Ordinary interval subtraction treats the two occurrences independently, returning $[-2r,2r]$ for $x\in[1-r,1+r]$.
The cell passes the same affine form twice to cancel it and compares the result with ordinary interval subtraction.
Half-width $r$ is dimensionless.

## Shared and independent symbols

Writing $x=1+r\varepsilon$ and $\varepsilon\in[-1,1]$, the difference of the same form makes coefficient $r-r$ zero and leaves $x-x=0$.
Conversely, two inputs $x_1=1+r\varepsilon_1$ and $x_2=1+r\varepsilon_2$ belonging to the same interval have true difference range $[-2r,2r]$.
Input interval endpoints alone do not reveal this distinction.
Symbols in affine forms express their origin in the same input.

The cell's `from_coefficients(&context, 1.0, &[radius])` specifies center 1 and a coefficient for one input symbol.
Passing that same `x` twice to `binary` preserves the correlation.
Constructing identical coefficients in two separate contexts does not represent correlation; mixing them is an error in the first place.

```rust
//| id: validated-affine-cancellation
//| ref: validated-affine-cancellation
//| title: "Correlation and cancellation in affine forms"
//| run: button
//| crates: [scioxide-core, scioxide-validated, scioxide-linalg]
//| inputs:
//|   radius: {"type":"range","label":"Half-width r","min":0.01,"max":0.5,"step":0.005,"value":0.125}
//| cases:
//|   - {"id":"wide","label":"r = 0.5","inputs":{"radius":0.5}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"reference","path":"/rows/0/1","approx":{"value":0,"atol":1e-13}}
//|   - case: wide
//|     expect:
//|       - {"artifact":"reference","path":"/rows/0/1","approx":{"value":0,"atol":1e-13}}
use scioxide_core::{SciOxideError, SciOxideErrorView, InvalidInputReason};
use scioxide_validated::DecoratedInterval as D;
use serde_json::json;
let unsupported = |error: &SciOxideError| {
    matches!(error.view(),
SciOxideErrorView::InvalidInput { argument,
reason: InvalidInputReason::UnsupportedConfiguration, .. }
if argument == scioxide_core::argument!("rounding_environment"))
};
use scioxide_validated::{AffineBinary, AffineContext, AffineForm, AffineOptions};
emit_table_with_columns!(
    ["Half-width r", "Exact x − x"],
    vec![(radius, 0.0)],
    metadata = json!({"id":"reference"})
);
let result = (|| -> Result<_, SciOxideError> {
    let context = AffineContext::new(1, AffineOptions::new())?;
    let mut work = context.workspace::<f64>()?;
    let x = AffineForm::from_coefficients(&context, 1.0, &[radius])?;
    let affine = x.binary(&x, AffineBinary::Sub, &mut work)?.report().real();
    let interval = x.report().real();
    let independent = interval.sub(&interval)?;
    let rows = [("Interval subtraction", independent), ("Affine subtraction", affine)].map(|(name, x)| {
        let (lo, hi) = x.set().bounds().unwrap();
        (name, lo, hi)
    });
    Ok(rows)
})();
let outcome = match result {
    Ok(rows) => {
        emit_table_with_columns!(
            json!([
                {"key":"0","label":"Method"},
                {"key":"1","label":"Lower endpoint","type":"number"},
                {"key":"2","label":"Upper endpoint","type":"number"}
            ]),
            rows,
            metadata = json!({"id":"cancellation"})
        );
        Outcome::satisfied("Enclosure computation completed")
    }
    Err(error) if unsupported(&error) => Outcome::unavailable("Proof computation not executed in this environment")
        .explanation("Run the proof in a supported native environment."),
    Err(error) => return Err(error.to_string()),
};
emit_outcome!(outcome);
```

## Results and application to general expressions

Increasing the half-width increases the interval-subtraction width proportionally to $4r$, while affine subtraction of the same form remains zero.
Exact zero is obtained because the inputs are identical and their coefficients cancel.
Subtracting intermediate results of different nonlinear computations need not cancel exactly, even from the same input, because each has new error terms.

Storing only `report().real()` after an operation gives a marginal interval and loses shared symbols.
To use correlations in later computations, retain `AffineForm` and defer interval conversion until needed for display or an external API.
The [quadratic-expression experiment](oxref:validated-affine-quadratic) covers preservation of first-order correlation with a remaining nonlinear remainder.

## Summary

Shared noise symbols represent repeated occurrences of the same uncertainty.
Use the same context and symbols for cancellation.
The [mathematics of affine arithmetic](../../algorithms/affine-arithmetic/) also covers nonlinear operations and symbol compression.
