Each example distinguishes the object of the proof from independent reference values.
In wasm, the rounding-environment check rejects proof computations, so only reference values and inputs are displayed, and the proof is marked as not executed.

| Example | API | Independent check and lessons |
|---|---|---|
| [Interval dependency](interval-dependency/) | `DecoratedInterval` | Known ranges and different expressions for the same mapping |
| [Rump's expression](rump-polynomial/) | Four arithmetic operations | Cancellation in i128 and a rational value |
| [Kepler's equation](kepler-uniqueness/) | `ScalarRootVerifier` | Monotonicity, existence and uniqueness, and overly narrow proposals |
| [Hilbert matrix](hilbert-verified-solve/) | `solve` | Difference between a rational matrix and a rounded matrix |
| [Error function](erf-certified-quadrature/) | `integrate` | Comparison with a series and enclosure of constants |
| [Wilkinson polynomial](wilkinson-root-counts/) | `PolynomialRootPlan` | Coefficient rounding and limits of root-count decisions |
| [Cancellation in affine forms](affine-cancellation/) | `AffineForm` | Exact cancellation of the difference of the same variable |
| [Intersection of a circle and a line](nonlinear-system-proof/) | `SystemRootVerifier` | Analytic intersections, box inclusion and contraction factor, and implementation of four operators |
