Verify intersections of the unit circle and line $x=y$ as a nonlinear system.
Analytically, the two points are $(x,y)=(1/\sqrt2,1/\sqrt2)$ and $(-1/\sqrt2,-1/\sqrt2)$.
Here, the claim is limited to one box around the positive intersection, demonstrating how to prove existence and uniqueness from an approximation.
Coordinates and residuals are all dimensionless.

## Residual and Jacobian

Let the unknowns be $u=(x,y)^T$, with residual and Jacobian defined as follows:

$$
F(u)=\begin{pmatrix}x^2+y^2-1\\x-y\end{pmatrix},\qquad
J(u)=\begin{pmatrix}2x&2y\\1&-1\end{pmatrix}
$$


The action on direction $v=(v_x,v_y)^T$ is $J(u)v=(2xv_x+2yv_y,\ v_x-v_y)^T$ and can be evaluated without assembling a matrix each time.
For search box $X$ and direction box $V$, interval evaluation of the same expressions encloses actions for every $u\in X$ and $v\in V$.
Use `square()` for the first component's squares, avoiding loss of same-variable dependency through general multiplication.

## Implementing point and interval actions

`SystemRootVerifier` accepts `IntervalJacobianOperator<f64>`.
This trait also requires ordinary residual and Jacobian actions, so implement the following four traits.

| Trait | Input | Output in this example |
|---|---|---|
| `ResidualOperator` | Point $u$ | Ordinary-precision $F(u)$ |
| `JacobianOperator` | Point $u$ and direction $v$ | Ordinary-precision $J(u)v$ |
| `IntervalResidualOperator` | Box $X$ | Enclosure of $F(X)$ |
| `IntervalJacobianOperator` | Box $X$ and direction box $V$ | Enclosure of $J(X)V$ |

Ordinary actions return approximations; the last two provide the basis for the root proof.
Array component 0 is $x$ and component 1 is $y$; residuals likewise follow circle, then line.
A real `IntervalBox` has an exactly zero imaginary part; the verifier checks this form before calling interval actions.
This example needs no additional temporary storage, so all workspace lengths are 0.

Interval actions compute both components before updating outputs because the second computation may fail after the first succeeds.
This respects the operator convention against returning `Err` with partially written output.
The executable cell imports the definitions below with `uses`.

```rust
//| id: validated-circle-line-model
//| kind: definitions
//| title: "Circle–line residual and Jacobian actions"
//| crates: [scioxide-core, scioxide-validated]
use scioxide_core::{Complex, SciOxideError, JacobianOperator, ResidualOperator};
use scioxide_validated::{
    DecoratedInterval as D, IntervalBox, IntervalJacobianOperator, IntervalResidualOperator,
};
pub(crate) struct CircleLine;
fn shape(lengths: &[usize]) -> Result<(), SciOxideError> {
    for &n in lengths {
        if n != 2 {
            return Err(SciOxideError::dimension_mismatch([2], [n]));
        }
    }
    Ok(())
}
impl ResidualOperator<f64> for CircleLine {
    fn input_dimension(&self) -> usize {
        2
    }
    fn output_dimension(&self) -> usize {
        2
    }
    fn residual_workspace_len(&self) -> Result<usize, SciOxideError> {
        Ok(0)
    }
    fn residual_into(
        &self,
        x: &[f64],
        out: &mut [f64],
        _: &mut [f64],
    ) -> Result<(), SciOxideError> {
        shape(&[x.len(), out.len()])?;
        out.copy_from_slice(&[x[0] * x[0] + x[1] * x[1] - 1.0, x[0] - x[1]]);
        Ok(())
    }
}
impl JacobianOperator<f64> for CircleLine {
    fn jvp_workspace_len(&self) -> Result<usize, SciOxideError> {
        Ok(0)
    }
    fn jvp_into(
        &self,
        x: &[f64],
        v: &[f64],
        out: &mut [f64],
        _: &mut [f64],
    ) -> Result<(), SciOxideError> {
        shape(&[x.len(), v.len(), out.len()])?;
        out.copy_from_slice(&[2.0 * x[0] * v[0] + 2.0 * x[1] * v[1], v[0] - v[1]]);
        Ok(())
    }
}
impl IntervalResidualOperator<f64> for CircleLine {
    fn residual_enclosure_workspace_len(&self) -> Result<usize, SciOxideError> {
        Ok(0)
    }
    fn residual_enclosure_into(
        &self,
        x: &[IntervalBox<f64>],
        out: &mut [IntervalBox<f64>],
        _: &mut [IntervalBox<f64>],
    ) -> Result<(), SciOxideError> {
        shape(&[x.len(), out.len()])?;
        let (a, b) = (D::from(x[0].re), D::from(x[1].re));
        // Compute all components before writing output, leaving it unchanged on intermediate errors.
        let circle = a.square()?.add(&b.square()?)?.sub(&D::point(1.0)?)?;
        let line = a.sub(&b)?;
        let zero = D::point(0.0)?.set();
        out.copy_from_slice(&[
            Complex::new(circle.set(), zero),
            Complex::new(line.set(), zero),
        ]);
        Ok(())
    }
}
impl IntervalJacobianOperator<f64> for CircleLine {
    fn jvp_enclosure_workspace_len(&self) -> Result<usize, SciOxideError> {
        Ok(0)
    }
    fn jvp_enclosure_into(
        &self,
        x: &[IntervalBox<f64>],
        v: &[IntervalBox<f64>],
        out: &mut [IntervalBox<f64>],
        _: &mut [IntervalBox<f64>],
    ) -> Result<(), SciOxideError> {
        shape(&[x.len(), v.len(), out.len()])?;
        let (a, b) = (D::from(x[0].re), D::from(x[1].re));
        let (u, w) = (D::from(v[0].re), D::from(v[1].re));
        let first = D::point(2.0)?.mul(&a.mul(&u)?.add(&b.mul(&w)?)?)?;
        let second = u.sub(&w)?;
        let zero = D::point(0.0)?.set();
        out.copy_from_slice(&[
            Complex::new(first.set(), zero),
            Complex::new(second.set(), zero),
        ]);
        Ok(())
    }
}
```


## Box width and proof success

Fixing the center at $c=(3/4,3/4)^T$ gives $F(c)=(1/8,0)^T$.
The inverse Jacobian at this point is

$$
R=\begin{pmatrix}1/3&1/2\\1/3&-1/2\end{pmatrix}
$$

so the point Newton correction $c-RF(c)$ has both components equal to $17/24\approx0.708333$.
This alone does not equal the true intersection $1/\sqrt2\approx0.707107$.
The Krawczyk map adds derivative variation over the whole box, further enclosing the corrected point.

For $X=[3/4-h,3/4+h]^2$, exact arithmetic gives $\|I-RJ(X)\|_\infty\le4h/3$.
Even when this is below 1, existence is not proved without checking $K(X)\subseteq X$.
An overly small $h$ fails to cover the difference between the center and true intersection; an overly large $h$ widens derivative enclosures and prevents a contraction bound.
This explains the need for a moderately sized box.

The cell varies only the half-width and compares analytic-reference membership with verifier status, established facts, and contraction factor.
The value $1/3$ in the preconditioner is an f64 approximation, and the preconditioner is not assumed to be an exact inverse.
`SystemRootCertificateView` borrows the box and center, so retain them until verification finishes.
In wasm, only the reference table appears, and the proof status is not executed.

```rust
//| id: validated-circle-line-proof
//| ref: validated-circle-line-proof
//| title: "Box enclosing the intersection and Krawczyk decision"
//| run: button
//| crates: [scioxide-core, scioxide-linalg, scioxide-validated]
//| uses: [validated-circle-line-model]
//| inputs:
//|   half_width: {"type":"range","label":"Box half-width h [-]","min":0.01,"max":0.75,"step":0.01,"value":0.25}
//| cases:
//|   - {"id":"miss","label":"Box excluding the intersection","inputs":{"half_width":0.01}}
//|   - {"id":"wide","label":"Wide box","inputs":{"half_width":0.75}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"reference","path":"/rows/0/0","approx":{"value":0.7071067811865476,"atol":1e-15}}
//|   - case: miss
//|     expect:
//|       - {"artifact":"reference","path":"/rows/0/3","equals":false}
//|   - case: wide
//|     expect:
//|       - {"artifact":"reference","path":"/rows/0/3","equals":true}
use scioxide_core::{SciOxideError, SciOxideErrorView, InvalidInputReason};
use serde_json::json;
let unsupported = |error: &SciOxideError| {
    matches!(error.view(),
SciOxideErrorView::InvalidInput { argument, reason: InvalidInputReason::UnsupportedConfiguration, .. }
if argument == scioxide_core::argument!("rounding_environment"))
};
use scioxide_linalg::MatrixView;
use scioxide_validated::{
    DenseIntervalOperator, RootClaim, RootVerificationStatus, SystemRootCertificateView,
    SystemRootVerifier, ValidatedOptions, interval_enclosure,
};
let root = 0.5_f64.sqrt();
let lo = 0.75 - half_width;
let hi = 0.75 + half_width;
emit_table_with_columns!(
    [
        "Analytic positive intersection (f64 reference)",
        "Box lower endpoint",
        "Box upper endpoint",
        "Reference point in box"
    ],
    vec![(root, lo, hi, lo <= root && root <= hi)],
    metadata = json!({"id":"reference"})
);
let proof = (|| -> Result<_, SciOxideError> {
    // Fixed f64 approximation to the inverse of J(3/4,3/4). The verifier checks its accuracy.
    let r = [1.0 / 3.0, 0.5, 1.0 / 3.0, -0.5];
    let inverse = DenseIntervalOperator::point(MatrixView::from_slice(2, 2, &r)?)?;
    let function = CircleLine;
    let verifier = SystemRootVerifier::new(&function, &inverse, ValidatedOptions::new())?;
    let region = [interval_enclosure(lo, hi)?; 2];
    let center = [0.75, 0.75];
    verifier.verify(SystemRootCertificateView {
        region: &region,
        center: &center,
        claim: RootClaim::Unique,
    })
})();
let outcome = match proof {
    Ok(report) => {
        emit_table_with_columns!(
            json!([
                {"key":"0","label":"Verification status"},
                {"key":"1","label":"Established fact"},
                {"key":"2","label":"Contraction upper bound","type":"number","nullText":"Not computed"}
            ]),
            vec![(
                format!("{:?}", report.status()),
                format!("{:?}", report.evidence()),
                report.defect()
            )],
            metadata = json!({"id":"proof"})
        );
        match report.status() {
            RootVerificationStatus::Proved => {
                Outcome::satisfied("A unique intersection exists in this box")
            }
            RootVerificationStatus::Refuted => {
                Outcome::failed("Refuted the claim of a unique intersection")
            }
            _ => Outcome::partial("Uniqueness undetermined in this box"),
        }
        .status(format!("{:?}", report.status()))
    }
    Err(e) if unsupported(&e) => Outcome::unavailable("Proof computation not executed in this environment"),
    Err(e) => return Err(e.to_string()),
};
emit_outcome!(outcome);
```


The default half-width $1/4$ satisfies both box inclusion and contraction conditions.
A box of half-width $0.01$ excludes the reference root; if the residual enclosure proves absence, claim `Unique` is `Refuted`.
A box of half-width $0.75$ contains the reference root, but its contraction upper bound reaches 1, leaving uniqueness undetermined by the same verification.
Use the three settings to distinguish reference-point membership from proof success.

## Adapting the implementation to another problem

Match the residual and Jacobian-action component order, input dimension, and output dimension.
Do not change only the derivative expression so that it represents a map different from the residual.
Interval-action enclosures must include rounding errors from function evaluation itself.
A point Jacobian evaluated once cannot serve as the derivative over an entire box.

Even when owning `SystemRootCertificate` and changing the domain through `view_mut()`, reverify after changing a claim.
For repeated calls with the same dimension, reserve `RootWorkspace` and use `verify_scoped`.
One verification of this two-variable problem takes 7 operator evaluations and 2 iterations, plus the costs of each action.
To examine roots over an entire domain, use `isolate` and `verify_isolation`; do not mistake success in one box for enumeration of all roots.

## Summary

Represent the same nonlinear system with both point and interval actions.
Krawczyk verification requires box inclusion and contraction conditions in addition to a sufficiently accurate approximate inverse.
Narrower boxes are not always easier to prove; consider both root location and derivative variation.
See [root mathematics](../../algorithms/root-certificates/) for the distinction between individual claims and isolation of all roots.
