二つの天体が重心のまわりを円運動し、質量を無視できる第三の物体がその重力場の中を運動する問題を平面円制限三体問題という。
地球と月の近くを飛ぶ探査機は、太陽の引力と月の軌道の離心率を無視すれば、このモデルで近似できる。
このページでは回転座標系の運動方程式を `scioxide-ode` で積分して月への最近接の時刻を事象として求め、共線平衡点 L1 の位置を `scioxide-rootfind` の Brent 法で求めて、到達できる領域を Jacobi 積分で判定する。
時間積分の誤差が事象の時刻へどう伝わるかを、保存量のずれと許容誤差による精度改善で確かめる。
重力二体問題（Kepler 問題）を数百周積分したときのエネルギーと角運動量の誤差の増え方は[Kepler 問題の長時間積分](../../scioxide-ode/examples/kepler-long-time/)が扱う。
このページは時間積分、事象検出、求根を組み合わせたときの誤差の読み方に絞る。

## 主天体の円運動と無次元化

質量 $m_1 \ge m_2$ の二天体（主天体）の相対位置 $\mathbf{d} = \mathbf{r}_2 - \mathbf{r}_1$ は、二体問題

$$
\ddot{\mathbf{d}} = -\frac{G(m_1+m_2)}{\lvert\mathbf{d}\rvert^3}\,\mathbf{d}
$$

に従う。
$G$ は万有引力定数である。
半径 $a$ の円軌道は角速度 $n = \sqrt{G(m_1+m_2)/a^3}$ で一様に回る解である。
長さの単位を $a$、質量の単位を $m_1+m_2$、時間の単位を $1/n$ に取ると $G = 1$、$a = 1$、$n = 1$ となり、主天体の公転周期は $2\pi$ になる。
質量比を $\mu = m_2/(m_1+m_2)$ とすると、主天体は重心から距離 $\mu$ と $1-\mu$ の位置を回る。
主天体とともに回る座標系（回転系）では、二つの主天体は $(-\mu,0)$ と $(1-\mu,0)$ に静止する。

既定値の $\mu = 0.01215$ は地球–月系の質量比として広く使われる値である。
地球と月の距離 384400 km と恒星月 27.32 日で換算すると、時間の単位は約 4.35 日、速さの単位は約 1.02 km/s になる。
この換算では、無次元時刻 10 は約 43.5 日、半径 0.01 は約 3840 km（月の半径の約 2.2 倍）にあたる。
月の軌道の離心率（約 0.055）、太陽の引力、天体の大きさを無視するので、これらの値は教材用の近似であり、軌道設計 の精度はない。
初期状態 $(0.8, 0, 0, 0.25)$ も教材として選んだ値で、月から約 0.188（約 7.2 万 km）の点を回転系の速さ約 0.26 km/s で出発する。

## 運動方程式と Jacobi 積分

慣性系の位置 $\mathbf{R}$ と回転系の位置 $\mathbf{r} = (x, y)$ は、角 $t$ の回転行列 $\mathsf{Q}(t)$ で $\mathbf{R} = \mathsf{Q}(t)\,\mathbf{r}$ と結ばれる。
回転の角速度ベクトルを $\boldsymbol{\omega} = (0, 0, 1)$ とし、時間で 2 回微分すると

$$
\ddot{\mathbf{R}} = \mathsf{Q}(t)\bigl(\ddot{\mathbf{r}} + 2\,\boldsymbol{\omega}\times\dot{\mathbf{r}} + \boldsymbol{\omega}\times(\boldsymbol{\omega}\times\mathbf{r})\bigr)
$$

を得る。
右辺の第 2 項が Coriolis 加速度、第 3 項が遠心加速度である。
平面では $\boldsymbol{\omega}\times\dot{\mathbf{r}} = (-\dot y, \dot x)$、$\boldsymbol{\omega}\times(\boldsymbol{\omega}\times\mathbf{r}) = -(x, y)$ である。
主天体までの距離を $r_1 = \sqrt{(x+\mu)^2+y^2}$、$r_2 = \sqrt{(x-1+\mu)^2+y^2}$ とし、有効ポテンシャルを

$$
\Omega(x,y)=\frac{x^2+y^2}{2}+\frac{1-\mu}{r_1}+\frac{\mu}{r_2}
$$

と定める。
$\Omega$ はポテンシャルの符号を反転した量で、第 1 項が遠心力、残りの 2 項が二天体の重力にあたる。
慣性系の運動方程式 $\ddot{\mathbf{R}} = -\nabla\bigl(-(1-\mu)/r_1 - \mu/r_2\bigr)$ を回転系に移すと

$$
\ddot x = 2\dot y + \Omega_x, \qquad \ddot y = -2\dot x + \Omega_y
$$

になる。
添字は偏微分で、$\Omega_x = x - (1-\mu)(x+\mu)/r_1^3 - \mu(x-1+\mu)/r_2^3$、$\Omega_y = y - (1-\mu)y/r_1^3 - \mu y/r_2^3$ である。
状態の成分順は $(x, y, v_x, v_y)$ で、$v_x = \dot x$、$v_y = \dot y$ は回転系での速度である。

第 1 式に $v_x$、第 2 式に $v_y$ を掛けて足すと、Coriolis 項は $2v_y v_x - 2v_x v_y = 0$ で消え、

$$
\frac{d}{dt}\,\frac{v_x^2+v_y^2}{2} = \Omega_x v_x + \Omega_y v_y = \frac{d\Omega}{dt}
$$

が残る。
したがって Jacobi 積分 $C = 2\Omega - v_x^2 - v_y^2$ は運動に沿って一定である。
主天体が動くので、慣性系での第三体の比エネルギー $E = \lvert\dot{\mathbf{R}}\rvert^2/2 - (1-\mu)/r_1 - \mu/r_2$ と角運動量 $h = (\mathbf{R}\times\dot{\mathbf{R}})_z$ はそれぞれ一定ではない。
慣性系の速度 $\dot{\mathbf{R}} = \mathsf{Q}(t)(\mathbf{v} + \boldsymbol{\omega}\times\mathbf{r})$ を代入すると $E = \lvert\mathbf{v}\rvert^2/2 + (x v_y - y v_x) + (x^2+y^2)/2 - (1-\mu)/r_1 - \mu/r_2$、$h = (x v_y - y v_x) + x^2 + y^2$ となり、

$$
E - h = \frac{\lvert\mathbf{v}\rvert^2}{2} - \Omega = -\frac{C}{2}
$$

を得る。
保存されるのはエネルギーと角運動量の組み合わせ $E - n h$（ここでは $n = 1$）である。

`DormandPrince853` のような陽的 Runge–Kutta 法はシンプレクティックではなく、$C$ を厳密には保存しない。
各刻みの局所打ち切り誤差 $\boldsymbol{\delta}$ は $C$ を $\nabla C\cdot\boldsymbol{\delta}$ だけ変え、刻みごとの変化が打ち消し合う仕組みはないので、$C$ のずれは積分時間とともに増えることが多い。
回転系の Hamiltonian は運動量と位置の積の項 $y p_x - x p_y$ を含み、$T(p) + V(q)$ の形に分離できない。
分離可能な Hamiltonian を前提とする `StormerVerlet` は、この系にはそのまま使えない。
$C$ のずれは積分誤差の独立な目安だが、1 個のスカラーなので、等高面 $C = \text{一定}$ に沿った誤差（軌道上の位相のずれ）は映さない。
$C$ のずれが小さくても、軌道の位相の精度は保証されない。

第 2 天体（月）への最近接は相対位置 $\mathbf{r}_{\mathrm{rel}} = (x-1+\mu, y)$ の距離の 2 乗の時間微分の半分

$$
g = \frac{1}{2}\frac{d}{dt}\lvert\mathbf{r}_{\mathrm{rel}}\rvert^2 = (x-1+\mu)\,v_x + y\,v_y
$$

の零点のうち、$g$ が負から正へ変わる上昇交差として検出する。
距離が減少から増加へ転じる点なので、上昇交差は距離の極小にあたる。
半径 0.01 の円に入る事象 $r_2 - 0.01 = 0$ の下降交差は、衝突として積分を止める。
この半径は月の半径を再現する値ではなく、$r_2 \to 0$ の特異点への接近を止めるモデル上の値である。
特異点に近づくと加速度が $1/r_2^2$ で大きくなり、刻み幅が縮んで `StepSizeLimit` で止まるか、右辺が有限でなくなって `NonFinite` のエラーになる。

次の定義のブロックは右辺、Jacobi 積分、事象関数と、積分を 1 回行う関数 `trajectory` を置く。
`Orbit(mu)` は `OdeSystem` を実装し、`dimension` が 4、`rhs` が上の式を `out` に書く。
`acceleration` は回転系の加速度 $(\ddot x, \ddot y)$ を返し、右辺と事象関数の時間微分の計算で共有する。
`Encounter(mu, collision)` は、`collision` が偽なら最近接の $g$（`Rising`、終端でない）、真なら衝突の $r_2 - 0.01$（`Falling`、終端）を表す `EventFunction` である。
`total_derivative` は事象関数の全微分 $dg/dt$ を返し、最近接では $dg/dt = \lvert\mathbf{v}\rvert^2 + \mathbf{r}_{\mathrm{rel}}\cdot\ddot{\mathbf{r}}$、衝突では動径速度 $\mathbf{r}_{\mathrm{rel}}\cdot\mathbf{v}/r_2$ である。
`Section(x0)` は直線 $x = x_0$ を正の側から負の側へ横切る事象を表す。

```rust
//| id: app-cr3bp-model
//| kind: definitions
//| title: 回転系の運動方程式と事象
//| crates: [scioxide-core, scioxide-linalg, scioxide-ode]
use scioxide_core::{ErrorTolerance, ExecutionContext, SciOxideError, NormSelection, SolveContext};
use scioxide_ode::{
    DormandPrince853, EventDirection, EventFunction, OdeMethod, OdeOptions, OdeOutputSchedule,
    OdeProblem, OdeSolveReport, OdeState, OdeSystem, OdeTrajectory,
};
pub(crate) struct Orbit(pub(crate) f64);
impl Orbit {
    pub(crate) fn omega(&self, y: &[f64]) -> f64 {
        let mu = self.0;
        0.5 * (y[0] * y[0] + y[1] * y[1])
            + (1.0 - mu) / (y[0] + mu).hypot(y[1])
            + mu / (y[0] - 1.0 + mu).hypot(y[1])
    }
    pub(crate) fn jacobi(&self, y: &[f64]) -> f64 {
        2.0 * self.omega(y) - y[2] * y[2] - y[3] * y[3]
    }
    // 回転系の加速度 (x'', y'') = (2 v_y + Ω_x, −2 v_x + Ω_y)。
    pub(crate) fn acceleration(&self, y: &[f64]) -> [f64; 2] {
        let mu = self.0;
        let dx = y[0] + mu;
        let ex = dx - 1.0;
        let r = dx.hypot(y[1]).powi(3);
        let s = ex.hypot(y[1]).powi(3);
        [
            2.0 * y[3] + y[0] - (1.0 - mu) * dx / r - mu * ex / s,
            -2.0 * y[2] + y[1] - (1.0 - mu) * y[1] / r - mu * y[1] / s,
        ]
    }
}
impl OdeSystem<f64> for Orbit {
    fn dimension(&self) -> usize {
        4
    }
    fn rhs(
        &self,
        _: f64,
        y: &[f64],
        out: &mut [f64],
        _: &mut SolveContext<'_, '_>,
    ) -> Result<(), SciOxideError> {
        let [ax, ay] = self.acceleration(y);
        out.copy_from_slice(&[y[2], y[3], ax, ay]);
        Ok(())
    }
}
// Encounter(μ, false) は最近接 g = r_rel·v、Encounter(μ, true) は衝突 r_2 − 0.01。
pub(crate) struct Encounter(pub(crate) f64, pub(crate) bool);
impl EventFunction<f64> for Encounter {
    fn eval(&self, _: f64, y: &[f64]) -> Result<f64, SciOxideError> {
        Ok(if self.1 {
            (y[0] - 1.0 + self.0).hypot(y[1]) - 0.01
        } else {
            (y[0] - 1.0 + self.0) * y[2] + y[1] * y[3]
        })
    }
    fn has_total_derivative(&self) -> bool {
        true
    }
    // slope は状態の時間微分 (v_x, v_y, x'', y'')。
    fn total_derivative(&self, _: f64, y: &[f64], slope: &[f64]) -> Result<f64, SciOxideError> {
        let (ex, ey) = (y[0] - 1.0 + self.0, y[1]);
        Ok(if self.1 {
            (ex * slope[0] + ey * slope[1]) / ex.hypot(ey)
        } else {
            slope[0] * y[2] + slope[1] * y[3] + ex * slope[2] + ey * slope[3]
        })
    }
    fn direction(&self) -> EventDirection {
        if self.1 {
            EventDirection::Falling
        } else {
            EventDirection::Rising
        }
    }
    fn is_terminal(&self) -> bool {
        self.1
    }
}
pub(crate) struct Section(pub(crate) f64);
impl EventFunction<f64> for Section {
    fn eval(&self, _: f64, y: &[f64]) -> Result<f64, SciOxideError> {
        Ok(y[0] - self.0)
    }
    fn direction(&self) -> EventDirection {
        EventDirection::Falling
    }
    fn is_terminal(&self) -> bool {
        false
    }
}
pub(crate) fn trajectory(
    mu: f64,
    initial: &[f64],
    end: f64,
    tol: f64,
    events: &[&dyn EventFunction<f64>],
) -> Result<(OdeTrajectory<f64>, OdeSolveReport<f64>), SciOxideError> {
    let model = Orbit(mu);
    let problem = OdeProblem::new(&model, end).with_events(events);
    let options = OdeOptions::new()
        .with_error_tolerance(ErrorTolerance::scalar(tol, tol, NormSelection::Infinity)?)
        .with_maximum_step(0.05)
        .with_output_schedule(OdeOutputSchedule::times(
            (0..=400).map(|i| end * i as f64 / 400.0).collect(),
        ));
    let method = DormandPrince853::new();
    let mut ws = method.workspace(&problem, &options)?;
    let mut state = OdeState::from_slice(0.0, initial)?;
    let mut path = OdeTrajectory::new();
    let report = method.advance(
        &problem,
        &options,
        &mut state,
        &mut path,
        &mut ws,
        ExecutionContext::sequential(),
    )?;
    Ok((path, report))
}
```

`trajectory` の中では、`OdeProblem::new(&model, end).with_events(events)` が右辺と事象関数の配列を借用して問題を作り、初期時刻は `OdeState::from_slice(0.0, initial)` が与える（`initial` は複製される）。
`ErrorTolerance::scalar(tol, tol, NormSelection::Infinity)` は絶対・相対の許容誤差をともに `tol` とし、成分ごとの局所誤差の推定 $e_i$ を $\mathrm{tol} + \mathrm{tol}\max(\lvert y_{n,i}\rvert, \lvert y_{n+1,i}\rvert)$ で割った値の最大値ノルムで刻みの受理を判定する（[誤差の正規化と受理の判定](oxref:ode-error-normalization)）。
負や有限でない `tol` はここで `InvalidInput` か `NonFinite` のエラーになる。
`with_maximum_step(0.05)` は刻み幅の上限で、理由は次の節で述べる。
`OdeOutputSchedule::times` に渡した 401 個の等間隔の時刻では連続出力の値を出力し、出力の時刻は刻み幅の選択に影響しない。
`method.workspace(&problem, &options)` は次元と事象の数に合う作業領域を確保し、`advance` は `state` を終端（または終端の事象の時刻）の状態に書き換え、出力と事象を `OdeTrajectory` に渡して `OdeSolveReport` を返す。
この関数は呼び出しごとに作業領域を作り直すので、繰り返し呼ぶと確保が積分ごとに起こる。
`advance` は事象の局所化が反復の上限に達したときの `ConvergenceFailure`、右辺や事象関数が有限でない値を返したときの `NonFinite` をエラーとして返し、刻み幅の下限による停止は `Ok` のレポートの `termination()` で返す。

## 時間積分と事象検出のアルゴリズム

`DormandPrince853` は 12 段の陽的 Runge–Kutta 法で、次数 8 の解で進み、5 次と 3 次の埋め込み推定を組み合わせて局所誤差を推定する。
最初の刻みは右辺を 13 回、以後の刻みは 12 回評価し、出力や事象が連続出力を読む刻みでは 7 次の連続拡張のために 3 回の評価が加わる（[方式ごとの連続拡張の次数](oxref:ode-dense-output-orders)）。
この問題は剛性がなく、右辺が滑らかで、厳しい許容誤差を求めるので、高次の陽的方式が少ない評価回数で済む。
刻みの受理は局所誤差だけを制御し、大域誤差は刻みごとの誤差が流れに沿って伝わった和である。
天体に近づく区間では近くの軌道どうしが急速に離れやすく、同じ許容誤差でも大域誤差は時間とともに増える。

事象の検出は受理した刻みの両端で事象関数を評価して符号の変化を探し、変化があればその刻みの連続出力 $\tilde{\mathbf{y}}(t)$ の上で $\psi(t) = g(t, \tilde{\mathbf{y}}(t))$ の零点を TOMS 748 の囲い込み法で求める（[連続拡張の上での求根](oxref:ode-event-localization)）。
既定の探索の方針 `EventSearchPolicy::Endpoints` は端点の符号だけを見るので、1 刻みの中で $g$ が正、負、正と変わると、遠ざかりと近づきの組を見逃す（[探索の方針と零点の見逃し](oxref:ode-event-search-policy)）。
`with_maximum_step(0.05)` は、1 刻みが最近接と最遠点の間隔より十分短くなるようにする上限である。
`Encounter` は全微分を持つので、`options` に `with_event_options(OdeEventOptions::new().with_search(EventSearchPolicy::DerivativeAssisted(n)))`（`n` は小区間の数を表す `Budget`）を加えれば、刻みを $n$ 等分した点の符号と $dg/dt$ の符号の変化から刻みの中の交差の組も探せる。
衝突の事象は `Falling` だけを数えるので、円 $r_2 = 0.01$ に接して戻る軌道（接触）は記録されない。
接触の記録は向きが `Either` の事象に限られる。

事象の時刻 $t^*$ の誤差には三つの源がある。
一つ目は局所化で残る囲い込み区間の幅で、既定では幅が $4\varepsilon + 4\varepsilon\lvert t\rvert$ の程度になるまで絞られる（$\varepsilon \approx 2.2\times10^{-16}$ は機械イプシロン）。
二つ目は連続拡張の誤差で、刻みの始点が正確なら刻み幅 $h$ に対して $O(h^{8})$ の程度である。
三つ目は刻みの始点にすでに積み重なった大域誤差 $\delta\mathbf{y}$ である。
状態が $\delta\mathbf{y}$ ずれると $\psi$ の値は $\nabla_{\mathbf{y}} g\cdot\delta\mathbf{y}$ ずれ、零点は

$$
\delta t^* \approx -\frac{\nabla_{\mathbf{y}} g\cdot\delta\mathbf{y}}{dg/dt\,(t^*)}
$$

だけ動く。
$1/\lvert dg/dt\rvert$ が時刻の条件数の役を持つ。
最近接では $dg/dt = \lvert\mathbf{v}\rvert^2 + \mathbf{r}_{\mathrm{rel}}\cdot\ddot{\mathbf{r}}$ で、相対速度が小さく距離の極小が浅いと小さくなり、時刻は状態の誤差に敏感になる。
衝突では $dg/dt$ が動径速度なので、円をかすめる接線に近い進入では小さくなり、さらに少し状態がずれるだけで円に入るかどうか自体が変わる。
囲い込み区間の幅は求根が収束したことの根拠であり、ODE の解の精度は表さない。

最近接の距離 $\lvert\mathbf{r}_{\mathrm{rel}}(t^*)\rvert$ は時刻の誤差に 1 次では反応しない。
極小では $d\lvert\mathbf{r}_{\mathrm{rel}}\rvert/dt = 0$ なので、時刻が $\delta t$ ずれても距離の変化は $\delta t^2$ に比例する。
距離の誤差は主に位置の大域誤差から来る。

L1 の位置は $y = 0$ 上の $\Omega_x(x, 0) = 0$ の根で、二天体の間 $-\mu < x < 1-\mu$ では

$$
f(x) = x - \frac{1-\mu}{(x+\mu)^2} + \frac{\mu}{(1-\mu-x)^2}
$$

である。
$f'(x) = 1 + 2(1-\mu)/(x+\mu)^3 + 2\mu/(1-\mu-x)^3 > 0$ なので根は区間に一つだけの単純根で、$f$ は左端の近くで負、右端の近くで正になる。
`Brent` は根を挟む区間を保ちながら、逆 2 次補間と割線法の刻みを使い、縮みが不十分なら二分法に切り替える Brent–Dekker 法である（[Brent–Dekker 法の補間と保護](oxref:rootfind-brent)）。
単純根の近くでは超線形収束し、どの反復でも根を挟む区間を保つ。
`ScalarRootOptions::default()` は区間の幅が $4\varepsilon + 4\varepsilon\max(\lvert a\rvert, \lvert b\rvert)$ 以下になったら `BracketTolerance` で成功とし、反復の上限は 100 回である。
L1 の求根は時間積分と独立なので、その誤差は最後の区間の幅（$10^{-15}$ の程度）に留まり、計算時間のほとんどは時間積分が占める。

## 最近接と到達可能な領域

$\mathbf{v} = 0$ で $C = 2\Omega$ となる曲線（零速度曲線）の内側 $2\Omega \ge C$ だけが、Jacobi 積分 $C$ の軌道の到達できる領域（Hill 領域）である。
L1 での値を $C_{L1} = 2\Omega(x_{L1}, 0)$ とすると、$C > C_{L1}$ なら地球側と月側の領域は分かれ、$C < C_{L1}$ なら L1 近傍の通路が開く。
通路が開くことは通過できることを意味し、特定の軌道がそこを通ることまでは意味しない。
$\mu = 0.01215$ では $x_{L1} \approx 0.836918$、$C_{L1} \approx 3.18834$ で、初期状態の $C \approx 3.13954$ はこれより小さい。
月の外側の L2 の値 $C_{L2} \approx 3.17216$ よりも小さいので、月の外側への通路も開いている。

次のセルは入力の質量比 $\mu$ と許容誤差の指数 $k$（許容誤差 $10^{k}$）で初期状態 $(0.8, 0, 0, 0.25)$ を無次元時刻 10 まで積分し、最近接と衝突の事象を表にする。
同じセルで L1 を Brent 法で求め、$C$、$C_{L1}$ と、出力時刻での $C$ のずれの最大値を 2 つ目の表に出す。
`path.events()` は事象を時刻の順に返し、`index()` は `events` の配列の位置（0 が最近接、1 が衝突）である。
`evidence()` の `Crossing` と `Contact` の `bracket` から局所化区間の幅を読み、`SampledZero`（標本がちょうど 0）では幅を未定義にする。
最後の列は `total_derivative` に事象の状態と `acceleration` から作った傾きを渡して求めた $dg/dt$ で、時刻の条件数の逆数にあたる。
Brent 法の結果は `is_success()` で確かめ、未収束ならエラーにする。
終了状態は `report.termination()` で、`ReachedEnd` なら終了時刻まで、`TerminalEvent` なら衝突で止まったことを示す。

```rust
//| id: app-cr3bp-jacobi
//| ref: app-cr3bp-jacobi
//| uses: [app-cr3bp-model]
//| title: 最近接事象と Jacobi 積分
//| run: button
//| crates: [scioxide-core, scioxide-linalg, scioxide-ode, scioxide-rootfind]
//| inputs:
//|   mu: {"type":"range","label":"質量比 μ [-]","min":0.005,"max":0.03,"step":0.00005,"value":0.01215}
//|   exponent: {"type":"range","label":"許容誤差の指数","min":-12,"max":-6,"step":1,"value":-10}
//| cases:
//|   - {"id":"collision","label":"μ = 0.03","description":"月の質量比を大きくすると、最初の接近で半径 0.01 の円に入り、衝突の事象で積分が止まる。","inputs":{"mu":0.03}}
//|   - {"id":"loose","label":"許容誤差 1e-6","description":"許容誤差を緩めると Jacobi 積分のずれが増える。","inputs":{"exponent":-6}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"invariant","path":"/rows/0/3","range":{"max":1e-7}}
//|       - {"artifact":"events","path":"/rows/0/1","approx":{"value":5.16510,"atol":1e-5}}
//|       - {"artifact":"events","path":"/rows/2/4","approx":{"value":0.103,"atol":0.005}}
//|   - case: collision
//|     expect:
//|       - {"artifact":"events","path":"/rows/0/0","equals":"衝突"}
//|       - {"artifact":"events","path":"/rows/0/1","approx":{"value":0.53170,"atol":1e-4}}
//|   - case: loose
//|     expect:
//|       - {"artifact":"invariant","path":"/rows/0/3","range":{"min":1e-9,"max":1e-7}}
use scioxide_core::{SciOxideError, Interval};
use scioxide_ode::{EventEvidence, EventFunction, OdeTermination};
use scioxide_rootfind::{Brent, ScalarFn, ScalarRootOptions, ScalarRootSolver};
let events: [&dyn EventFunction<f64>; 2] = [&Encounter(mu, false), &Encounter(mu, true)];
let initial = [0.8, 0.0, 0.0, 0.25];
let model = Orbit(mu);
let (path, report) = trajectory(mu, &initial, 10.0, 10.0_f64.powf(exponent), &events)
    .map_err(|e| e.to_string())?;
// L1 は二天体の間で Ω_x(x, 0) = 0 を満たす単純根。
let f =
    ScalarFn::new(|x: f64| Ok(x - (1.0 - mu) / (x + mu).powi(2) + mu / (1.0 - mu - x).powi(2)));
let l1 = Brent
    .solve(
        &f,
        Interval::new(-mu + 1e-4, 1.0 - mu - 1e-4).map_err(|e| e.to_string())?,
        &ScalarRootOptions::default(),
    )
    .map_err(|e| e.to_string())?;
if !l1.is_success() {
    return Err("L1 の求根が未収束".into());
}
let c = model.jacobi(&initial);
let cl1 = model.jacobi(&[l1.point(), 0.0, 0.0, 0.0]);
let drift = path
    .states()
    .iter()
    .map(|y| (model.jacobi(y.as_slice()) - c).abs())
    .fold(0.0, f64::max);
let rows = path
    .events()
    .iter()
    .map(|event| {
        let y = event.state();
        let width = match event.evidence() {
            EventEvidence::Crossing { bracket, .. }
            | EventEvidence::Contact { bracket, .. } => bracket.width().ok(),
            EventEvidence::SampledZero => None,
        };
        // dg/dt(t*)。時刻の誤差は δt* ≈ δg / |dg/dt| で増幅される。
        let [ax, ay] = model.acceleration(y);
        let slope = [y[2], y[3], ax, ay];
        let rate = events[event.index()].total_derivative(event.time(), y, &slope)?;
        let name = if event.index() == 0 {
            "最近接"
        } else {
            "衝突"
        };
        let distance = (y[0] - 1.0 + mu).hypot(y[1]);
        Ok((name, event.time(), distance, width, rate))
    })
    .collect::<Result<Vec<_>, SciOxideError>>()
    .map_err(|e| e.to_string())?;
let sig6 = serde_json::json!({ "significantDigits": 6 });
let columns = serde_json::json!([
    { "key": "0", "label": "事象", "type": "string" },
    { "key": "1", "label": "時刻 [-]", "type": "number", "format": sig6 },
    { "key": "2", "label": "第2天体との距離 [-]", "type": "number", "format": sig6 },
    { "key": "3", "label": "局所化区間の幅 [-]", "type": "number", "format": sig6, "nullText": "未定義" },
    { "key": "4", "label": "dg/dt [-]", "type": "number", "format": { "significantDigits": 4 } }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "events" })
);
let columns = serde_json::json!([
    { "key": "0", "label": "L1 の x [-]", "type": "number", "format": sig6 },
    { "key": "1", "label": "初期 C [-]", "type": "number", "format": sig6 },
    { "key": "2", "label": "C_L1 [-]", "type": "number", "format": sig6 },
    { "key": "3", "label": "最大 |ΔC| [-]", "type": "number", "format": sig6 }
]);
emit_table_with_columns!(
    columns,
    vec![(l1.point(), c, cl1, drift)],
    metadata = serde_json::json!({ "id": "invariant" })
);
let points: Vec<_> = path
    .states()
    .iter()
    .map(|y| [y.as_slice()[0], y.as_slice()[1]])
    .collect();
emit_line_chart!(
    &vec![serde_json::json!({"name":"回転系の軌道","points":points})],
    options = &serde_json::json!({"xLabel":"x [-]","yLabel":"y [-]"})
);
let outcome = match report.termination() {
    Some(OdeTermination::ReachedEnd) => Outcome::satisfied("終了時刻まで積分した"),
    Some(OdeTermination::TerminalEvent) => Outcome::satisfied("衝突の事象で積分を止めた"),
    _ => Outcome::partial("積分が途中で停止した"),
};
emit_outcome!(
    outcome
        .status(format!("{:?}", report.termination()))
        .diagnostic("最大 |ΔC|", drift, None)
);
```

既定の入力では衝突は起こらず、時刻 5.165、6.700、8.545、9.928 の 4 回の最近接が表に並び、距離はそれぞれ約 0.677、1.117、1.048、0.663 である。
グラフは回転系の軌道で、月（$x \approx 0.988$）から約 0.188 の点を出た軌道は、月から離れて地球（$x \approx -0.012$）のまわりを約 2 周する。
出発点では $v_x = 0$、$y = 0$ なので $g = 0$ だが、積分の開始時刻の零点は事象として数えない。
局所化区間の幅は $10^{-15}$ の程度で、局所化の許容誤差（$4\varepsilon$）まで絞られたことを示すが、時刻の精度は示さない。
$dg/dt$ は 1 回目と 4 回目で約 6.1 と 5.1、2 回目と 3 回目で約 0.27 と 0.10 である。
2 回目と 3 回目は月から遠く相対速度が小さい浅い極小で、同じ状態の誤差に対する時刻のずれは 1 回目の 20〜60 倍になる。
$C$ のずれの最大値は許容誤差 $10^{-10}$ で約 $3\times10^{-10}$ である。
このずれは連続出力の値で測るので、連続拡張の誤差も含む。

許容誤差の指数を $-6$ にすると、$C$ のずれは約 $10^{-8}$ に増え、最近接の時刻は小数第 7 桁で変わる。
質量比を 0.005 にすると最近接は 1 回だけになり、0.03 にすると時刻約 0.53 で半径 0.01 の円に入り、衝突の事象で積分が止まる。
衝突の行の $dg/dt$ は負の動径速度（$\mu = 0.03$ で約 $-2.3$）で、絶対値が小さいほど進入が接線に近く、衝突の有無が初期状態や許容誤差に敏感になる。
事象の数が許容誤差によって変わるとき、または $dg/dt$ がほぼ 0 の事象があるときは、結果を信頼する前に最大刻みと許容誤差を変えて確かめる。

## 許容誤差による精度改善

前のセルの表は 1 つの許容誤差の結果なので、時刻の誤差そのものは分からない。
次のセルは $\mu = 0.01215$ の同じ初期状態を許容誤差 $10^{-5}$ から $10^{-12}$ まで変えて積分し、許容誤差 $10^{-13}$ の解を基準解として最近接の時刻と距離、終端の位置の差を測る。
基準解との比較は精度改善による検算であり、基準解自身の誤差（$10^{-12}$ 程度以下）は差に含まれる。
事象の数が基準解と違う場合は対応が取れないので、時刻と距離の差を未定義にする。
右辺の評価回数は `report.counts().provider(EvaluationRole::RightHandSide)` で、受理した刻みの数は `report.accepted_steps()` で読む。

```rust
//| id: app-cr3bp-refinement
//| ref: app-cr3bp-refinement
//| uses: [app-cr3bp-model]
//| title: 許容誤差を変えたときの最近接の時刻と Jacobi 積分
//| run: button
//| crates: [scioxide-core, scioxide-linalg, scioxide-ode]
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"refinement","path":"/rows/0/6","range":{"min":199,"max":206}}
//|       - {"artifact":"refinement","path":"/rows/5/2","range":{"max":1e-7}}
//|       - {"artifact":"refinement","path":"/rows/7/2","range":{"max":1e-9}}
use scioxide_core::EvaluationRole;
use scioxide_ode::{EventFunction, OdeTrajectory};
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let (mu, end) = (0.01215, 10.0);
let initial = [0.8, 0.0, 0.0, 0.25];
let model = Orbit(mu);
let c0 = model.jacobi(&initial);
let approach = Encounter(mu, false);
let events: [&dyn EventFunction<f64>; 1] = [&approach];
// 許容誤差 1e-13 の解を基準解とする（精度改善による検算）。
let (reference, _) =
    trajectory(mu, &initial, end, 1e-13, &events).map_err(|e| e.to_string())?;
let distance = |y: &[f64]| (y[0] - 1.0 + mu).hypot(y[1]);
let last = |p: &OdeTrajectory<f64>| p.states().last().map(|y| y.as_slice().to_vec());
let reference_end = last(&reference).ok_or("基準解の出力がない")?;
let (mut rows, mut series) = (Vec::new(), vec![Vec::new(), Vec::new(), Vec::new()]);
for k in 5..=12 {
    let tol = 10.0_f64.powi(-k);
    let (path, report) =
        trajectory(mu, &initial, end, tol, &events).map_err(|e| e.to_string())?;
    let matched = path.events().len() == reference.events().len();
    let pairs = || path.events().iter().zip(reference.events());
    let time_error = matched.then(|| {
        pairs()
            .map(|(a, b)| (a.time() - b.time()).abs())
            .fold(0.0, f64::max)
    });
    let distance_error = matched.then(|| {
        pairs()
            .map(|(a, b)| (distance(a.state()) - distance(b.state())).abs())
            .fold(0.0, f64::max)
    });
    let end_state = last(&path).ok_or("出力がない")?;
    let end_error = (end_state[0] - reference_end[0]).hypot(end_state[1] - reference_end[1]);
    let drift = path
        .states()
        .iter()
        .map(|y| (model.jacobi(y.as_slice()) - c0).abs())
        .fold(0.0, f64::max);
    let evaluations = report.counts().provider(EvaluationRole::RightHandSide);

    let values = [time_error, Some(end_error), Some(drift)];

        if let Some(v) = v.filter(|&v| v > 0.0) {
            s.push([tol, v]);
        }
    }
    let steps = report.accepted_steps();
    rows.push((
        tol,
        path.events().len(),
        time_error,
        distance_error,
        end_error,
        drift,

        let style = serde_json::json!({ "showSymbol": true });
        serde_json::json!({ "name": name, "points": points, "style": style })
    })
    .collect();

    options = &serde_json::json!({
        "xLabel": "許容誤差 [-]",
        "yLabel": "基準解との差 [-]",
        "xType": "log",
        "yType": "log"
    })
);
let columns = serde_json::json!([
    { "key": "0", "label": "許容誤差 [-]", "type": "number", "format": sci3 },
    { "key": "1", "label": "最近接の数", "type": "integer" },

]);

    columns,
    rows,
    metadata = serde_json::json!({ "id": "refinement" })
);
```

グラフの横軸は許容誤差、縦軸は基準解との差で、破線は許容誤差そのものを表す。
許容誤差 $10^{-5}$ から $10^{-7}$ では受理した刻みが約 200 回でそろい、差も変わらない。
無次元時刻 10 を最大刻み 0.05 で進むと 200 刻みになるので、この範囲で刻み幅を決めているのは最大刻みである。
許容誤差を $10^{-8}$ 以下にすると刻みが増え始め、時刻の差は許容誤差 $10^{-10}$ で約 $4\times10^{-9}$、$10^{-12}$ で約 $2\times10^{-11}$ に下がる。
許容誤差 $10^{-9}$ 以下では時刻の差は許容誤差より大きく、終端の位置の差と同じ程度で動くので、時刻の誤差は局所化の幅ではなく積分の大域誤差と $1/\lvert dg/dt\rvert$ の増幅で決まる。
最近接の距離の差は時刻の差の 5〜8 分の 1 程度である。
極小での距離は時刻のずれに 1 次では反応しないので、この差は位置の大域誤差から来る。
右辺の評価は 1 刻みあたり 15〜17 回（12 段、連続拡張の 3 段、棄却した刻みの評価）で、許容誤差 $10^{-12}$ でも約 4800 回である。
許容誤差を小さくしても差が下がらなくなったら、最大刻みか基準解の精度が限界を決めている。

## L4 の線形振動

正三角形の頂点にあたる平衡点 L4 は $(x_4, y_4) = (1/2-\mu, \sqrt3/2)$ にあり、$r_1 = r_2 = 1$ である。
L4 からのずれ $(\xi, \eta)$ について運動方程式を 1 次まで展開すると

$$
\ddot\xi - 2\dot\eta = \Omega_{xx}\,\xi + \Omega_{xy}\,\eta, \qquad \ddot\eta + 2\dot\xi = \Omega_{xy}\,\xi + \Omega_{yy}\,\eta
$$

を得る。
L4 での 2 階偏微分は $\Omega_{xx} = 3/4$、$\Omega_{yy} = 9/4$、$\Omega_{xy} = b = 3\sqrt3(1-2\mu)/4$ である。
$(\xi, \eta) \propto e^{\lambda t}$ を代入して行列式を 0 とおくと、特性方程式 $\lambda^4 + \lambda^2 + 27\mu(1-\mu)/4 = 0$ を得る。
$\lambda = i\omega$ とおくと $\omega^4 - \omega^2 + 27\mu(1-\mu)/4 = 0$ で、

$$
\omega^2 = \frac{1 \pm \sqrt{D}}{2}, \qquad D = 1 - 27\mu(1-\mu)
$$

である。
$D > 0$ なら $\omega^2$ は二つとも正で、ずれは速い振動と遅い振動の重ね合わせになる。
$D > 0$ となる質量比の小さい側の境界は $\mu_R = (1-\sqrt{23/27})/2 \approx 0.03852$（Routh の値）である。
$\mu = 0.01215$ では遅い周期が約 21.07、速い周期が約 6.58 で、地球–月系の L4 は線形安定である。
これは線形安定性の条件であり、有限振幅での永久的な閉じ込めを証明するものではない。

遅い固有モードだけを励起するために、固有ベクトルの実部を初期摂動にする。
第 1 式に $e^{i\omega t}$ を代入すると $(-\omega^2 - 3/4)\,\xi = (2i\omega + b)\,\eta$ なので、$c = -\omega^2 - 3/4$ として $\eta = c\,(b - 2i\omega)\,\xi/(b^2 + 4\omega^2)$ である。
$t = 0$ で $\xi = A$、$\dot\xi = 0$ とすると、$\eta(0) = A c b/(b^2+4\omega^2)$、$\dot\eta(0) = 2A c\,\omega^2/(b^2+4\omega^2)$ になる。
ここで $A = 10^{-5}$（コードの `epsilon`）は摂動の大きさである。

次のセルは入力の質量比 $\mu$ でこの初期状態を無次元時刻 60 まで許容誤差 $10^{-12}$ で積分し、直線 $x = x_4$ を同じ向きに横切る時刻の間隔の平均を線形周期 $2\pi/\omega$ と比べる。
断面の通過は `Section(x4)` の終端でない事象として検出し、`path.events()` の隣り合う時刻の差を周期とする。
グラフは L4 からの距離の時間変化である。
$D \le 0$ の入力では線形周期を定義せず（列は未定義）、摂動の増大を観察する。

```rust
//| id: app-cr3bp-l4
//| ref: app-cr3bp-l4
//| uses: [app-cr3bp-model]
//| title: L4 の摂動と線形周期
//| run: button
//| crates: [scioxide-core, scioxide-linalg, scioxide-ode]
//| inputs:
//|   mu: {"type":"range","label":"質量比 μ [-]","min":0.01,"max":0.05,"step":0.005,"value":0.02}
//| cases:
//|   - {"id":"unstable","label":"μ = 0.04","description":"Routh の値を超えると線形周期は定義されず、L4 からの距離が増える。","inputs":{"mu":0.04}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"period","path":"/rows/0/1","approx":{"value":15.861084572979225,"atol":0.001}}
//|   - case: unstable
//|     expect:
//|       - {"artifact":"period","path":"/rows/0/0","equals":null}
//|       - {"artifact":"period","path":"/rows/0/1","range":{"min":8.7,"max":9.0}}
let x = 0.5 - mu;
let y = 3.0_f64.sqrt() / 2.0;
let disc = 1.0 - 27.0 * mu * (1.0 - mu);
let frequency = if disc > 0.0 {
    Some(((1.0 - disc.sqrt()) / 2.0).sqrt())
} else {
    None
};
let epsilon = 1e-5;
let mut initial = [x + epsilon, y, 0.0, 0.0];
if let Some(w) = frequency {
    let b = 3.0 * 3.0_f64.sqrt() * (1.0 - 2.0 * mu) / 4.0;
    let c = -w * w - 0.75;
    let den = b * b + 4.0 * w * w;
    initial[1] += epsilon * c * b / den;
    initial[3] = epsilon * c * 2.0 * w * w / den;
}
let section = Section(x);
let events: [&dyn scioxide_ode::EventFunction<f64>; 1] = [&section];
let (path, report) =
    trajectory(mu, &initial, 60.0, 1e-12, &events).map_err(|e| e.to_string())?;
let periods: Vec<_> = path
    .events()
    .windows(2)
    .map(|w| w[1].time() - w[0].time())
    .collect();
let measured = if periods.is_empty() {
    None
} else {
    Some(periods.iter().sum::<f64>() / periods.len() as f64)
};
let reference = frequency.map(|w| 2.0 * core::f64::consts::PI / w);
let points: Vec<_> = path
    .times()
    .iter()
    .zip(path.states())
    .map(|(&t, v)| [t, (v.as_slice()[0] - x).hypot(v.as_slice()[1] - y)])
    .collect();
emit_line_chart!(
    &vec![serde_json::json!({"name":"L4 からの距離","points":points})],
    options = &serde_json::json!({"xLabel":"時刻 [-]","yLabel":"距離 [-]"})
);
let sig6 = serde_json::json!({ "significantDigits": 6 });
let columns = serde_json::json!([
    { "key": "0", "label": "線形周期 [-]", "type": "number", "format": sig6, "nullText": "未定義" },
    { "key": "1", "label": "断面通過の平均間隔 [-]", "type": "number", "format": sig6, "nullText": "未定義" },
    { "key": "2", "label": "比較できた周期数", "type": "integer" }
]);
emit_table_with_columns!(
    columns,
    vec![(reference, measured, periods.len())],
    metadata = serde_json::json!({ "id": "period" })
);
let outcome = if report.is_success() {
    Outcome::satisfied("有限時間の積分が完了した")
} else {
    Outcome::partial("積分が途中で停止した")
};
emit_outcome!(outcome.status(format!("{:?}", report.termination())));
```

既定の $\mu = 0.02$ では線形周期は約 15.8611 で、3 周期の平均間隔は小数第 5 桁まで一致する。
残る差は約 $8\times10^{-6}$ で、$A$ を 10 倍にすると差もほぼ 10 倍になるので、非線形項の影響と考えられる。
グラフの距離は $A$ の程度の範囲で周期的に変動し、振幅は時間とともに増えない。
$\mu$ を 0.01 にすると周期は約 23.4 に延び、0.035 では約 10.6 に縮む。
$\mu = 0.04$ と 0.05 は $\mu_R$ より大きく、特性根が実部 $\alpha > 0$ を持つ複素数 $\alpha \pm i\beta$ になる。
距離は $e^{\alpha t}$ で増え、$\mu = 0.04$ では $\alpha \approx 0.068$ なので時刻 60 で約 57 倍になる。
このときの平均間隔（約 8.9）は増大する振動の $2\pi/\beta \approx 8.85$ に近い値である。
$\mu = 0.05$ では $\alpha \approx 0.18$ で振幅が大きくなり、線形化の近似が成り立たなくなる。

## まとめと次に読むページ

最近接は距離の 2 乗の時間微分 $g = \mathbf{r}_{\mathrm{rel}}\cdot\mathbf{v}$ の上昇交差として検出でき、時刻の誤差は局所化の幅よりも、積分の大域誤差を $1/\lvert dg/dt\rvert$ 倍したもので決まる。
表の $dg/dt$ が小さい事象（浅い極小や接線に近い進入）は、許容誤差と最大刻みを変えて時刻と事象の数が安定するかを確かめる。
Jacobi 積分のずれは積分誤差の独立な目安だが、位相のずれは映さないので、精度改善による時刻の比較と組み合わせる。
許容誤差を小さくしても刻みの数が変わらないときは最大刻みが精度を決めているので、事象の見逃しを防ぐ上限と精度の要求を分けて選ぶ。
L1 の値 $C_{L1}$ との比較で通路が開いているかを判定でき、L4 の周期は特性方程式の根と断面通過の間隔で照合できる。

二体問題を長時間積分したときの、シンプレクティックな方式と `DormandPrince853` のエネルギーと角運動量の誤差の違いは[Kepler 問題の長時間積分](../../scioxide-ode/examples/kepler-long-time/)で確かめられる。
事象の探索の方針、局所化の許容誤差、接触の検出は[連続出力と事象検出](../../scioxide-ode/algorithms/dense-output-and-events/)で詳しく調べられる。
[軌道遷移の最適化](../orbital-transfer-optimization/)では二体問題に限って二回の速度変更の合計を最小化し、最小点が Hohmann 遷移になることと、最適化した楕円を `DormandPrince853` で積分した遠日点半径が一致することを確かめる。
