母数を一点で推定する代わりに分布として与えると、出力にもばらつきが生じる。
このページでは伝達率、回復率、初期の感染者比率を独立な一様分布とし、SIR の最終規模に対する寄与を分ける。
これらの分布は教材の仮定であり、観測から推定した事後分布ではない。
最終規模には Lambert W 関数による閉形式があるので、ODE の積分の誤差と標本化の誤差を別々に確かめられる。

## 問題設定と入力分布

閉じた均一な集団で、出生、死亡、移動、再感染はないとする。
人口に対する感受性者、感染者、回復者（SEIR のページの除去者）の比率を $(s,i,r)$、時間の単位を日とし、

$$
s'=-\beta si,\qquad i'=\beta si-\gamma i,\qquad r'=\gamma i
$$

とする。
記号は[SEIR の前進感度](../epidemiology-seir/)と同じで、潜伏期の区分がない場合に当たる。
右辺の和はゼロなので $s+i+r=1$ が保たれる。
初期の回復者比率はゼロ、感染者比率は $i_0>0$、感受性者比率は $s_0=1-i_0$ である。
時間を $\tau=\gamma t$ と無次元化すると $ds/d\tau=-R_0si$、$di/d\tau=(R_0s-1)i$ となり、$R_0=\beta/\gamma$ は基本再生産数である。
したがって最終規模は $R_0$ と $i_0$ だけで決まり、$\beta$ と $\gamma$ は比を通して交互作用を持つ。

入力 $X=(\beta,\gamma,i_0)$ は互いに独立で、次の区間の一様分布に従うとする。

| 入力 | 区間 | 意味 |
|---|---|---|
| $\beta$ [日⁻¹] | $[0.3,0.6]$ | 接触による伝達率 |
| $\gamma$ [日⁻¹] | $[0.1,0.2]$ | 回復率（感染期間 5〜10 日） |
| $i_0$ | $[0.001,0.01]$ | 初期の感染者比率 |

$R_0$ は 1.5 から 6 を動くので、どの標本でも流行が起きる。
出力は最終的な回復者比率 $z=r_\infty$ で、流行の終わりまでに一度でも感染した人の比率である。

## 最終規模の独立検算

$i>0$ の間は $r'>0$ なので、$r$ を独立変数にとれる。
$s'$ を $r'$ で割ると $ds/dr=-R_0s$ となり、$r(0)=0$ から $s=s_0\exp(-R_0r)$ を得る。
$t\to\infty$ で $i\to0$ なので $s_\infty+r_\infty=1$ であり、$z$ は

$$
1-z=s_0\exp(-R_0z)
$$

を満たす。
$F(z)=1-z-s_0e^{-R_0z}$ は $F(0)=i_0>0$、$F(1)<0$ の凹関数なので、$(0,1)$ に根をちょうど一つ持つ。
$u=-R_0(1-z)$ とおくと $ue^u=-R_0s_0e^{-R_0}$ となるので、最終的な回復者比率は

$$
z=r_\infty=1+\frac{W_0(-R_0s_0e^{-R_0})}{R_0}
$$

となる。
$W_0$ は Lambert W 関数の主枝で、$W_0\ge-1$ である（DLMF §4.13）。
$s_\infty=-W/R_0$ なので、主枝は流行の終わりの実効再生産数 $R_0s_\infty$ が 1 以下になる根に当たる。
もう一つの実枝 $W_{-1}$ は $F$ の負の根を与え、比率としての意味を持たない。
初期の感染者比率を変える場合は $s_0$ を省いてはいけない。
$i_0=0$ を厳密に置いた無感染の解 $z=0$（$W_{-1}$ 側）と、微小な感染を導入した極限 $1-z=e^{-R_0z}$（$W_0$ 側）も区別する。

`scioxide_special::lambert_w0` は Halley 反復で $W_0$ を求め、`f64` の試験範囲で誤差は 64 ulp 以内である（[実数の枝の評価法](oxref:special-lambert-real-branches)）。
$W_0$ の相対条件数は $1/(1+W_0)$ で、引数が分岐点 $-1/e$ に近づく $R_0\to1$、$i_0\to0$ の極限で大きくなる。
この範囲では $R_0=1.5$、$i_0=0.001$ が最悪で、条件数は約 2.7 にとどまる。

ピークの高さも保存量から求まる。
$di/ds=-1+1/(R_0s)$ を積分すると $i+s-\log s/R_0$ が保存され、$i'=0$ となる $s=1/R_0$ で

$$
i_{\max}=1-\frac{1+\log(R_0s_0)}{R_0}
$$

を得る。

## ODE の積分とピークの事象

閉形式を持たないモデルと同じ手順をとるため、感度推定の主計算には ODE の終端値 $r(400)$ を出力に使う。
`DormandPrince5` は 7 段の陽的 Runge–Kutta 法の 5(4) 次の埋め込み対で、二つの解の差を局所打ち切り誤差の推定に使う（[埋め込み対による局所誤差の推定](oxref:ode-embedded-pairs)）。
FSAL の性質により、二歩目からは一刻みあたり右辺を 6 回評価する。

`ErrorTolerance::scalar(1e-9, 1e-9, NormSelection::Infinity)` の引数は絶対許容誤差、相対許容誤差、ノルムの順である。
各成分で $\lvert e_k\rvert\le10^{-9}+10^{-9}\max(\lvert y_{n,k}\rvert,\lvert y_{n+1,k}\rvert)$ なら刻みを受理する（[誤差の正規化と受理の判定](oxref:ode-error-normalization)）。
これは局所誤差の制御で、大域誤差の保証ではない。

ピークの後、$i$ はおよそ率 $\gamma(1-R_0s_\infty)$ で指数的に減る。
この率は $\beta=0.3$、$\gamma=0.2$ の端で最も小さく、約 0.075 日⁻¹ なので、400 日で $i$ は十分に小さくなる。
$R_0$ を 1 に近づけるとこの率がゼロに近づき、$r(400)$ と $r_\infty$ の差が積分の誤差を上回る。

ピークは事象関数 $g=\beta s-\gamma$ の正から負への通過（`EventDirection::Falling`）で求める。
$i'=i\,g$ なので、$g$ の符号の変化が $i$ の極大に当たる。
検出器は受理した刻みの連続出力の上で符号を調べ、変わった区間で TOMS 748 法により根を求める（[連続拡張の上での求根](oxref:ode-event-localization)）。
既定の探索は刻みの両端だけを見るので一刻みの中の二根は見落とすが、このモデルでは $R_0s$ が単調に減るので根は一つである。

終端値の誤差は $10^{-9}$ 程度で、出力の標準偏差 0.073 よりはるかに小さい。
一方、数十行の設計の標本化誤差は 0.1 程度ある。
このページの設定では、指数の誤差は標本化誤差で決まる。

## Sobol 指数

入力が独立なら、出力は互いに直交する成分の和 $z=f_0+\sum_jf_j(X_j)+\sum_{j<k}f_{jk}(X_j,X_k)+f_{123}$ に一意に分解できる（Sobol の分解、ANOVA 分解）。
成分が直交するので、分散も $V=\sum_jV_j+\sum_{j<k}V_{jk}+V_{123}$ と分かれる。
一次指数 $S_j=\mathrm{Var}(\mathbb E[z\mid X_j])/\mathrm{Var}(z)=V_j/V$ は、入力 $X_j$ だけによる寄与を表す。
全効果指数 $S_{Tj}$ はその入力を含む交互作用も含め、

$$
S_{Tj}=\frac{\mathbb E[\mathrm{Var}(z\mid X_{\sim j})]}{V}=1-\frac{\mathrm{Var}(\mathbb E[z\mid X_{\sim j}])}{V}
$$

と書ける。
$X_{\sim j}$ は $X_j$ 以外の入力で、$S_{Tj}$ が小さい入力は定数に置き換えても出力の分散がほとんど変わらない。
この分解は入力の独立性を前提とする。
有限標本の推定値は 0 から 1 の範囲を外れる場合があり、表示のために切り詰めない。

閉形式を各軸 20 点の Gauss–Legendre 積則で積分すると、精密値は次のようになる（32 点でも表示の桁は変わらない）。

| 入力 | $S_j$ | $S_{Tj}$ |
|---|---|---|
| $\beta$ | 0.498 | 0.605 |
| $\gamma$ | 0.395 | 0.502 |
| $i_0$ | $2.0\times10^{-5}$ | $4.6\times10^{-5}$ |

平均は約 0.91823、分散は約 0.0052778 である。
$\beta$ と $\gamma$ の $S_{Tj}-S_j$ はどちらも約 0.107 で、これが比 $\beta/\gamma$ による交互作用の大きさである。
$i_0$ は 1% 程度しか $s_0$ を変えないので、寄与はほぼない。

## pick-freeze 推定量と評価回数

独立な $N\times d$ の標本の行列 $A$、$B$ を用意し、$A$ の第 $j$ 列を $B$ の第 $j$ 列に置き換えた行列を $A_B^{(j)}$ とする（[pick-freeze 法による推定](oxref:stats-ishigami-pick-freeze)）。
$f(A_B^{(j)})$ と $f(B)$ は $X_j$ だけを共有するので、積の期待値から $f_0^2$ を引くと $V_j$ になる。
$f(A_B^{(j)})$ と $f(A)$ は $X_j$ 以外を共有するので、差の二乗の期待値の半分が $\mathbb E[\mathrm{Var}(z\mid X_{\sim j})]$ になる。
$f(A)$ と $f(B)$ の $2N$ 個の出力の平均を $m$、分散を $\hat V$ として、scioxide-stats は

$$
\hat S_j=\frac1{N\hat V}\sum_{k=1}^N\bigl(f(B)_k-m\bigr)\bigl(f(A_B^{(j)})_k-f(A)_k\bigr),\qquad
\hat S_{Tj}=\frac1{2N\hat V}\sum_{k=1}^N\bigl(f(A)_k-f(A_B^{(j)})_k\bigr)^2
$$

を使う。
一次は Saltelli ら（2010）、全効果は Jansen（1999）の推定量で、偏りは $O(1/N)$ である。
評価の回数は $N(d+2)$、この問題では $5N$ である。
scioxide-stats は一次と全効果の指数を提供し、二次の指数 $S_{jk}$ は提供しない。

行が独立なら、$\hat V$ の揺らぎを無視して $\mathrm{SE}(\hat S_j)\approx\sigma_j/\sqrt N$ と近似できる。
$\sigma_j$ は和の一項を $V$ で割った値の標準偏差である。
$10^5$ 行の独立な計算で見積もると $\sigma_\beta\approx1.3$、$\sigma_\gamma\approx1.1$ で、$N=64$ の一次指数の SE は 0.13〜0.16 になる。
$i_0$ では全効果の項の標準偏差が約 $1.9\times10^{-4}$ で、一次の項の約 $9.7\times10^{-3}$ より 50 倍小さい。
寄与の小さい入力を見分けるには、全効果指数のほうが向いている。

## Monte Carlo と乱択準 Monte Carlo の誤差

独立な乱数による Monte Carlo 法の誤差は $O(N^{-1/2})$ で減る。
準 Monte Carlo 法は低ディスクレパンシーの点列を使い、Koksma–Hlawka の不等式から誤差は $V_{\mathrm{HK}}(f)\,D_N^*$ 以下になる（[ディスクレパンシーと Koksma–Hlawka の不等式](oxref:random-qmc-koksma-hlawka)）。
$V_{\mathrm{HK}}$ は Hardy–Krause の意味の変動、$D_N^*$ はスター・ディスクレパンシーで、$D$ 次元の Sobol 点列では $O((\log N)^D/N)$ である。
pick-freeze 設計は $A$ と $B$ の行を一つの点の前半と後半から作るので $D=2d=6$ で、$N=64$ では $(\log N)^6/N\approx81$ となり、上界は何も述べない。

そこで `QmcReplicatePlan` は Sobol 点列に Matoušek の線形の scramble を独立に $R$ 回かけ、複製のばらつきから誤差を測る。
ランダム化した各点は $[0,1)^6$ で一様で、独立反復 $r$ の推定値を $\hat S^{(r)}$ とすると、

$$
\bar S=\frac1R\sum_{r=1}^R\hat S^{(r)},\qquad
\mathrm{SE}=\sqrt{\frac{1}{R(R-1)}\sum_{r=1}^R\bigl(\hat S^{(r)}-\bar S\bigr)^2}
$$

を返す（[QmcReplicatePlan の準備と推定](oxref:random-sobol-replicate-standard-error)）。
SE は経験的な推定で、上界ではない。
$R=8$ では自由度が 7 なので、95% 区間には $t$ 分布の分位点 2.36 を使う。
滑らかな被積分関数に対し、scramble した網の分散は $O(N^{-3}(\log N)^{D-1})$ で減る（Owen 1997、線形の scramble も同じ分散を持つことは Owen 2003）。
ただしこれは大きな $N$ の極限で、既定では各複製が 8 点しかないので MC との差は小さい。
網の均等さは先頭の $2^m$ 点で成り立つので、`QmcReplicatePlan::new` は Sobol 点列に 2 の冪でない点数を渡すと `InvalidInput` を返す。
セルの $N$ を 32、64、128 から選ぶのはこのためである。

平均と分散の表は、`QmcScramble::DigitalShift(seed)` でずらしただけの 3 次元 Sobol 点列を一本使う。
複製がないので経験的な SE はなく、一つのシードから全座標のずらし量を作るので、座標ごとのずらし量が互いに独立である保証もない。

## API の流れ

`closed(p)` は `p = [β, γ, i₀]` から閉形式の $z$ を返し、`lambert_w0` の `DomainError` は `?` で伝える。
`solve(p)` は `OdeFn::new(3, …)` で成分順 $(s,i,r)$ の右辺を作り、`OdeProblem::new(&model, 400.0).with_events(&events)` で右辺と事象を借用する問題を作る。
`advance` は `OdeState` をその場で進め、出力先の `OdeTrajectory` は既定の `FinalOnly` の予定で終端の状態と事象を記録する。
上限や最小刻みで止まっても `Ok` を返すので、`report.is_success()`（`ReachedEnd` か `TerminalEvent`）を確かめ、それ以外とピークの未検出はエラーにする。

`sobol_indices_monte_carlo(3, n, &root, sampler, model)` は行 $k$ の生成器を `root.split(k)` で作り、座標ごとに `sampler(j, rng)` を $A$ と $B$ について交互に呼ぶ。
`root` 自体は進まないので、同じ `root` で閉形式を評価した `reference` は ODE の推定と同じ点を使い、二つの差は積分の誤差だけを表す。
返り値の `evaluations()` は全出力を持ち、行が独立な MC では `sobol_bootstrap` に渡して percentile 区間を作れる。

`QmcReplicatePlan::new(&QmcPlan::sobol(6)?, &root, options)` は 6 次元の Sobol 点列（Joe–Kuo の方向数）を 8 回ランダム化する。
`sobol_indices_qmc(&plan, 3, n / 8, transform, model)` の `points` は各複製の点数と一致し、点列の次元は $2d$ でなければならず、違えば `InvalidInput` になる。
点の前半 3 座標が $A$、後半が $B$ の行になり、`transform(j, u)` が単位区間の値を入力に写す。
Sobol 点列は先頭の座標ほど射影が良いので、寄与が大きいと見込む $\beta$ を先頭に置く。
`randomized_standard_error()` は RQMC の推定にだけ `Some` を返す。
どちらの推定でも、モデルが NaN や無限大を返すと `NonFinite`、出力の分散がゼロだと `NumericalInstability` になる。

評価回数は MC と RQMC がともに $5N$ である。
既定の $N=64$ では ODE の求解が 707 回（MC 320、RQMC 320、平均の表の Sobol 列 64、代表点 3）で、これが計算時間の大部分を占める。
平均の表の MC の列は設計の $f(A)$ を `OnlineMoments` で集計し直すので、追加の求解はない。

次のセルは上の入力分布で指数を推定し、代表の三点で ODE と閉形式を比べ、平均と分散を MC と Sobol 点列で比べる。
入力は設計の行数 $N$ と乱数のシードで、シードは MC の標本、RQMC のランダム化、平均の表のずらしをすべて変える。

//| tests:

//|       - {"artifact":"moments","path":"/rows/2/0","equals":32}
//|       - {"artifact":"indices","path":"/rows/2/2","range":{"min":0,"max":1e-3}}
//|   - case: large-design
//|     expect:
//|       - {"artifact":"moments","path":"/rows/2/0","equals":128}
//|       - {"artifact":"indices","path":"/rows/2/2","range":{"min":0,"max":1e-3}}
use scioxide_core::{ErrorTolerance, ExecutionContext, SciOxideError, NormSelection};
use scioxide_ode::{
    DormandPrince5, EventDirection, EventFunction, OdeFn, OdeMethod, OdeOptions, OdeProblem,
    OdeState, OdeTrajectory,
};
use scioxide_random::QuasiRng;
use scioxide_random::{
    Philox4x64, QmcPlan, QmcReplicateOptions, QmcReplicatePlan, Rng, SeedableRng,
};
use scioxide_stats::{sobol_indices_monte_carlo, sobol_indices_qmc};
let transform = |j: usize, u: f64| [0.3, 0.1, 0.001][j] + [0.3, 0.1, 0.009][j] * u;
let closed = |p: &[f64]| -> Result<f64, SciOxideError> {
    let r = p[0] / p[1];
    Ok(1.0 + scioxide_special::lambert_w0(-r * (1.0 - p[2]) * (-r).exp())? / r)
};
struct Peak(f64, f64);
impl EventFunction<f64> for Peak {
    fn eval(&self, _: f64, y: &[f64]) -> Result<f64, SciOxideError> {
        Ok(self.0 * y[0] - self.1)
    }
    fn direction(&self) -> EventDirection {
        EventDirection::Falling
    }
    fn is_terminal(&self) -> bool {
        false
    }
}
let solve = |p: &[f64]| -> Result<(f64, f64, f64), SciOxideError> {
    let model = OdeFn::new(3, |_: f64, y: &[f64], dy: &mut [f64]| {
        let infection = p[0] * y[0] * y[1];
        let recovery = p[1] * y[1];
        dy.copy_from_slice(&[-infection, infection - recovery, recovery]);
        Ok(())
    })?;
    let peak = Peak(p[0], p[1]);
    let events: [&dyn EventFunction<f64>; 1] = [&peak];
    let problem = OdeProblem::new(&model, 400.0).with_events(&events);
    let method = DormandPrince5::new();
    let options = OdeOptions::new().with_error_tolerance(ErrorTolerance::scalar(
        1e-9,
        1e-9,
        NormSelection::Infinity,
    )?);
    let mut state = OdeState::from_slice(0.0, &[1.0 - p[2], p[2], 0.0])?;
    let mut ws = method.workspace(&problem, &options)?;
    let mut path = OdeTrajectory::new();
    let report = method.advance(
        &problem,
        &options,
        &mut state,
        &mut path,
        &mut ws,
        ExecutionContext::sequential(),
    )?;
    if !report.is_success() {
        return Err(SciOxideError::external("SIR の積分が未完了"));
    }
    let peak = path
        .events()
        .first()

    sobol_indices_monte_carlo(3, n, &root, sampler, closed).map_err(|e| e.to_string())?;

## 表の読み方

最初の表の「MC」は ODE の終端値、「閉形式 MC」は同じ点の閉形式による推定である。
既定の入力（$N=64$、シード 7）では、一次指数は MC で $\beta$ が約 0.45、$\gamma$ が約 0.21、RQMC で約 $0.62\pm0.10$、$0.39\pm0.10$ になる。
精密値との差は MC で見積もった SE の 1.4 倍以内、RQMC で SE の 1.3 倍程度以内に収まる。
$\gamma$ の RQMC の全効果は約 $0.84\pm0.21$ で精密値から SE の 1.6 倍離れるが、$\pm2.36\,\mathrm{SE}$ の区間には入る。
$i_0$ の一次指数は $\pm0.004$ 程度で符号も定まらないが、全効果は $10^{-4}$ 未満で、寄与が小さいことを示す。
「MC」と「閉形式 MC」の差は $10^{-9}$ 程度で、これが SE と同じ桁になったら積分の許容誤差か区間を見直す。

二つ目の表では、$R_0=1.5$、3、6 の最終規模が約 0.584、0.941、0.998、ピークが約 0.064、0.302、0.536 になる。
終端値と閉形式の差は $3\times10^{-10}$ 程度、ピークの差は $10^{-9}$ 以下で、局所誤差の許容誤差と整合する。

平均と分散の表は標本数を $N/4$、$N/2$、$N$ と増やした結果である。
$N=64$ では MC 平均が約 0.903（SE 約 0.010）で精密値 0.91823 から SE の 1.5 倍ずれ、Sobol 点列の平均の誤差は $10^{-4}$ 未満である。
1024 点の閉形式の値も精密値と $4\times10^{-5}$ 程度違い、厳密な期待値として扱えない。
MC 平均の SE は独立標本の式であり、同じ式を Sobol 点列へ流用しない。

設計の行数を増やしても、特定のシードで誤差が単調に減るとは限らない。
シード 7 の $N=128$ では、Sobol 点列の平均の誤差が $N=64$ より大きい。
$N=32$ では RQMC の各複製が 4 点になって SE が大きくなり、$\gamma$ の MC の全効果は約 1.09 と 1 を超える。
小さい一次指数と大きい標準誤差の組み合わせを、寄与がない証拠とは解釈しない。
シードを変えると指数の順位が入れ替わる、全効果が一次より明らかに小さい、といった場合は標本が足りない。

## まとめと次に読むページ

この SIR の最終規模では $\beta$ と $\gamma$ が分散のほぼすべてを説明し、両者の交互作用は約 0.11、$i_0$ の寄与は $10^{-4}$ 未満である。
閉形式 $z=1+W_0(-R_0s_0e^{-R_0})/R_0$ を同じ点で評価すると、ODE の誤差と標本化誤差を分けられる。
pick-freeze 推定の評価回数は $N(d+2)$ で、$N=64$ では一次指数の SE が 0.1 程度残るので、順位を決める前にシードを変えて SE を確かめる。
RQMC の各複製の点数は 2 の冪で選び、SE には自由度 $R-1$ の $t$ 分布の分位点を使う。

[Sobol 指数の実験](../../scioxide-stats/examples/ishigami-sensitivity/)では既知の指数を使い、推定量自体の誤差と標本数に対する減り方を確認できる。
[QmcReplicatePlan の標準誤差](../../scioxide-random/examples/qmc-replicate-standard-error/)では、複製の SE から作った区間が真値を含む割合を調べられる。
[介入のある SIR モデル](../../scioxide-ode/examples/sir-intervention/)では、接触率が時間とともに変わる場合のピークの事象と最終規模の関係式を確かめられる。
