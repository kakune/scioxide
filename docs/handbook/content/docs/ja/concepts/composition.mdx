補間してから積分する、ODEを解いてからパラメータを推定する、といった計算では複数のクレートを組み合わせる。
後段の計算を厳しく収束させても、前段の入力誤差や離散化誤差は消えない。
各段階の誤差が最終量にどう伝わるかを考え、許容誤差と計算回数の上限を決める。

モデル計算、逆問題、独立検算をつなぐときは、値の単位・定義域・診断情報を各境界で確認する。

## 一次感度解析による誤差伝播の数理

外側の目的量または観測量を $Q = G(u, p)$ とする。
ここで、$p$ は設計パラメータ、$u = S(p)$ は内側のソルバー（ODE や連立方程式など）によって解かれた状態ベクトルである。
内側計算において数値誤差 $\delta u$ が混入したとき、最終的な観測量 $Q$ に生じる誤差 $\delta Q$ は、Taylor 展開の一次項により以下のように記述される。

$$
\delta Q \approx G_u \delta u + (G_p + G_u S_p) \delta p.
$$

ここで、$G_u = \partial G/\partial u$、$G_p = \partial G/\partial p$、$S_p = \partial S/\partial p$ は、それぞれ状態、パラメータ、内側の解の感度である。
$\delta u$ は同じパラメータでの内側計算の誤差を表し、パラメータ摂動 $\delta p$ による状態変化 $S_p\delta p$ と区別する。
内側計算の誤差は観測感度 $G_u$ に応じて拡大または縮小される。

- **差を観測する場合**：$G(u)=u_1-u_2$ の絶対感度は一定だが、差が小さいと相対誤差が大きくなる。
  絶対感度と相対感度を混同しない。
- **平均を観測する場合**：正負の局所誤差は相殺されることがある。
  ただし、同じ向きの偏りまで小さくなるとは限らない。

## 許容誤差の適正配分と誤差の下限

複合計算パイプラインの設計では、全体の誤差を支配している「ボトルネック」を見極める必要がある。
外側の観測・モデル誤差の下限を $e_{\mathrm{model}}$、空間・時間離散化誤差を $e_h$、観測感度を $A$ とするとき、最終誤差の上界モデルは以下のように表される。

$$
e_{\mathrm{total}} \le e_{\mathrm{model}} + e_h + A e_{\mathrm{in}}.
$$

ここで $e_{\mathrm{in}}$ は内側計算の状態誤差、$A$ は観測量への誤差増幅を評価する係数である。
不等号を保証するには各項が誤差の上界であり、$A$ が対象範囲での感度の上界になっている必要がある。
推定値を代入した和は誤差の見積もりであり、厳密な上界とは限らない。
反復の残差許容誤差を状態誤差に換算するときは、条件数なども必要になる。

次のセルは、無次元化した誤差寄与を足し合わせるモデルである。
入力は感度、離散化誤差、モデル・観測誤差、内側の状態誤差の4つ。
ソルバーの実測値ではない。
グラフでは内側誤差を減らしたときの合成上界を、表では選択した点の寄与と割合を確認する。
内側の寄与が他の寄与より小さくなると、曲線の改善が緩やかになる。

```rust
//| id: concept-composed-error-budget
//| title: 外側感度・離散化誤差・観測誤差の下限を動かして複合パイプラインの支配誤差を探す
//| run: reactive
//| crates: [scioxide-core]
//| inputs:
//|   amplification_exponent: {"type":"range","label":"外側感度の指数 a（A=10ᵃ）","description":"内側誤差が最終量へ伝わる増幅感度。","min":0,"max":6,"step":1,"value":3}
//|   discretization_exponent: {"type":"range","label":"離散化誤差の指数 h（eₕ=10ʰ）","description":"空間格子や時間刻みが作る離散化誤差。","min":-10,"max":-2,"step":1,"value":-5}
//|   floor_exponent: {"type":"range","label":"モデル・観測誤差の下限の指数 f（e_model=10ᶠ）","description":"計測器や理論モデル自体の誤差の下限。","min":-10,"max":-2,"step":1,"value":-4}
//|   inner_error_exponent: {"type":"range","label":"内側の状態誤差の指数 i（eᵢₙ=10ⁱ）","description":"内側計算の状態誤差の上界または推定値。残差許容誤差とは区別する。","min":-14,"max":-2,"step":1,"value":-8}
// 各誤差寄与を足す一次の上界モデル。ソルバーの実測誤差ではない。
let amplification = 10.0_f64.powf(amplification_exponent);
let discretization = 10.0_f64.powf(discretization_exponent);
let observation = 10.0_f64.powf(floor_exponent);
let inner = 10.0_f64.powf(inner_error_exponent);
let floor = observation + discretization;
let propagated = amplification * inner;
let total = floor + propagated;
let mut total_curve = Vec::new();
let mut inner_curve = Vec::new();
for i in 0..=144 {
    let inner_error = 10.0_f64.powf(-14.0 + i as f64 / 12.0);
    let contribution = amplification * inner_error;
    total_curve.push([inner_error, floor + contribution]);
    inner_curve.push([inner_error, contribution]);
}
let series = vec![
    serde_json::json!({"name":"誤差上界のモデル", "points":total_curve}),
    serde_json::json!({"name":"内側誤差の寄与", "points":inner_curve, "style": {"lineType": "dashed"}}),
];
// 横線は内側誤差を 0 にしても残る誤差の下限、縦線 eᵢₙ = 誤差の下限 / A は二つの寄与が釣り合う点。
emit_line_chart!(
    &series,
    options = &serde_json::json!({"xLabel": "内側誤差 eᵢₙ [-]", "yLabel": "誤差寄与 e [-]", "xType": "log", "yType": "log",
"annotations": [{"kind": "line", "axis": "y", "value": floor, "label": "モデル・離散化誤差の合計"},
{"kind": "line", "axis": "x", "value": floor / amplification, "label": "釣り合い 誤差の下限/A"},
{"kind": "line", "axis": "x", "value": inner, "label": "選んだ eᵢₙ", "style": {"lineType": "dotted"}}]})
);
let largest = observation.max(discretization).max(propagated);
let rows: Vec<_> = [
    ("モデル・観測", observation),
    ("離散化", discretization),
    ("内側誤差 × 感度", propagated),
]
.into_iter()
.map(|(name, value)| {
    let comparison = if value == largest {
        "最大の寄与（同値を含む）"
    } else {
        "その他"
    };
    (name, value, value / total * 100.0, comparison)
})
.collect();
let sci3 = serde_json::json!({"notation": "scientific", "significantDigits": 3});
emit_table_with_columns!(
    [
        serde_json::json!({"key":"name", "label":"寄与", "type":"string"}),
        serde_json::json!({"key":"value", "label":"値 [-]", "type":"number", "format":sci3}),
        serde_json::json!({"key":"share", "label":"割合 [%]", "type":"number"}),
        serde_json::json!({"key":"comparison", "label":"比較", "type":"string"})
    ],
    rows,
    metadata = serde_json::json!({"id":"contributions"})
);
emit_table_with_columns!(
    serde_json::json!([
    {"key":"0","label":"合成上界のモデル [-]","type":"number","format":{"significantDigits":6},"nullText":"未定義"},
    {"key":"1","label":"内側と他の寄与が釣り合う eᵢₙ [-]","type":"number","format":{"significantDigits":6},"nullText":"未定義"}
    ]),
    vec![(total, floor / amplification)],
    metadata = serde_json::json!({"id":"total"})
);
```

内側の寄与が大きい間は、その誤差を減らすと合成上界も下がる。
他の寄与より十分小さくなると、内側だけを改善しても上界はほとんど変わらない。
この曲線は誤差の上界モデルであり、誤差の符号による相殺や実際の下限を示すものではない。

## 入れ子の計算回数の上限の管理（`SolveScope`）と許容誤差の配分

最適化の内側で ODE を解く場合など、求解が入れ子になる計算では `SolveScope` を使って計算量を集計できる。
`SolveScope::from(&mut context)` で作る子の求解は、期限・キャンセル・エグゼキューターを親から引き継ぎ、局所的な上限も持つ。
通常の簡易 API を呼ぶだけで、すべての計算が自動的に一つの回数の集計へ統合されるわけではない。

- **局所反復枠の隔離**: 反復・提案回数（`BudgetKind::Iteration` / `Proposal`）の上限は各階層に局所的である。
  内側ソルバーが 50 回反復しても、親ソルバー自身の反復（`own()`）の回数には加算されない。
  子の処理は親の計数では入れ子の回数（`nested()`）として記録され、`total()` で合計を読める。
- 評価回数や標本数などの共有上限は、子の処理を親を含む外側の求解にも数える。
  計算回数が上限内に収まるかの確認は、いずれかの上限を超えたのに一部だけ使用済みになることを防ぐ。
- **トランザクションの独立性**: 子ソルバーの進捗受理（Accepted State）が親ソルバーの状態を勝手に前進させることはなく、各階層が自身のトランザクションを独立に維持する。

関連する型は、[`scioxide-core` の求解の識別と状態の一覧](oxref:core-api-solve-state)から確認できる。

## 典型的なクレート接続パターンと境界仕様

代表的な複合パイプラインにおいて遵守すべき境界仕様を整理する。

### 1. 補間 $\to$ 数値求積 $\to$ 求根（物性値逆算）

離散物性テーブルから `scioxide-interp` で連続スプライン曲線を構成し、それを `scioxide-integrate` で積分して累積熱量を求め、目的熱量に達する温度を `scioxide-rootfind` で解く。

- **境界仕様**: スプライン補間が保証する定義域 $[T_{\min}, T_{\max}]$ を超える外挿評価を厳密に遮断する。
  また、累積熱量 $E(T) = \int_{T_0}^T c(T')\,dT'$ の導関数 $E'(T) = c(T)$（被積分関数である比熱そのもの）が微小な領域では、求積の微小誤差が解の温度 $T$ に大きな誤差をもたらすため、求根の停止判定に逆感度重み付けを組み込む。

### 2. 常微分方程式 $\to$ 高速フーリエ変換（振動スペクトル解析）

`scioxide-ode` の適応時間刻みソルバーで非線形振動を解き、得られた変位信号を `scioxide-fft` で周波数解析する。

- **境界仕様**: 適応 ODE ソルバーの内部ステップ点は不等間隔である。
  不等間隔点列をそのまま FFT へ渡してはならない。
  例えば連続補間出力（連続補間出力）を用いて等間隔サンプリング点列へと再構成し、Nyquist 周波数を考慮したサンプリング間隔 $\Delta t$ と必要に応じて窓関数（Hann / Blackman）を適用して FFT に入力する。

### 3. 自動微分 $\to$ 数理最適化（パラメータ同定・逆問題）

`scioxide-ad` で目的関数の導関数を求め、`scioxide-optimize` の準 Newton 法（BFGS）へ渡す。
自動微分には差分刻みに由来する打ち切り誤差はないが、モデルの離散化誤差と丸め誤差は残る。

- **境界仕様**: 自動微分の前進モード（二重数）と後退モード（リバースモード）の変数の成分順序が、最適化パラメータベクトルの添字と一致していることを検証する。
  局所的な非滑らか点（絶対値や条件分岐）が存在する場合、劣勾配の取り扱い方針を明示する。

## まとめと次に読むページ

クレートをつなぐときは、値だけでなく単位、定義域、誤差の意味を引き継ぐ。
残差許容誤差と状態誤差を区別し、感度を使って最終量への寄与を見積もる。
内側と外側のどちらを改善すべきかは、各段階の誤差と計算量を比較して決める。
具体的な道具は[クレート一覧](../../crates/)から選び、回数の集計の詳細は[求解のライフサイクルと計算回数の管理](../../scioxide-core/algorithms/solve-lifecycle-and-accounting/)で、内側の求解を親の上限に数える規則は[入れ子の求解・回数の集計・診断](../../scioxide-core/algorithms/nested-solves-and-diagnostics/)で確認できる。
