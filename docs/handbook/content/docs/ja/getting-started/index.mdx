この小さな例を通して、SciOxideの呼び出し方と、残差・後退誤差・条件数の読み方を学ぶ。

## 連立一次方程式の行列表記と厳密解

次の 2 元連立一次方程式を取り上げる。

$$
\begin{aligned}
3x_1 + x_2 &= 9, \\
x_1 + 2x_2 &= 8.
\end{aligned}
$$

係数行列 $\mathbf{A} \in \mathbb{R}^{2 \times 2}$、未知数ベクトル $\mathbf{x} \in \mathbb{R}^2$、右辺ベクトル $\mathbf{b} \in \mathbb{R}^2$ を用いて $\mathbf{A}\mathbf{x} = \mathbf{b}$ と表すと、各要素は以下のように定まる。

$$
\mathbf{A} =
\begin{bmatrix}
3 & 1 \\
1 & 2
\end{bmatrix},
\qquad
\mathbf{x} =
\begin{bmatrix}
x_1 \\ x_2
\end{bmatrix},
\qquad
\mathbf{b} =
\begin{bmatrix}
9 \\ 8
\end{bmatrix}.
$$

行列式は $\det(\mathbf{A}) = 3 \times 2 - 1 \times 1 = 5 \neq 0$ なので、行列 $\mathbf{A}$ は正則である。
厳密解は $\mathbf{x}^* = (2, 3)^\mathsf{T}$ と一意に求まる。

## 数値求解と残差・後退誤差による客観的検証

計算機上で得られた近似解を $\hat{\mathbf{x}}$ とする。
浮動小数点演算を伴う数値計算では有限桁の丸め誤差が生じるため、得られた解が方程式をどの程度満たしているかを独立に検算しなければならない。
その客観的な指標が**残差ベクトル** $\mathbf{r}$ とそのユークリッドノルム $\|\mathbf{r}\|_2$ である。

$$
\mathbf{r} = \mathbf{A}\hat{\mathbf{x}} - \mathbf{b},
\qquad
\|\mathbf{r}\|_2 = \sqrt{\sum_{i=1}^n r_i^2}.
$$

さらに、数値線形代数では問題の尺度に依存しない<strong>後退誤差（Backward Error）</strong>を重視する。
Wilkinson の後退誤差解析によれば、求解アルゴリズムが安定であれば、得られた計算解 $\hat{\mathbf{x}}$ はわずかに摂動した係数系 $(\mathbf{A} + \Delta\mathbf{A})\hat{\mathbf{x}} = \mathbf{b} + \Delta\mathbf{b}$ の厳密解とみなせる。
規格化された無次元の後退誤差ノルム $\eta$ は以下のように定義される。

$$
\eta = \frac{\|\mathbf{A}\hat{\mathbf{x}} - \mathbf{b}\|}{\|\mathbf{A}\|_2 \|\hat{\mathbf{x}}\|_2 + \|\mathbf{b}\|_2}.
$$

後退誤差が機械精度水準（倍精度 `f64` において $u \approx 1.11 \times 10^{-16}$ に対し数 $u$ 程度）に収まっていれば、その計算結果は、小さい入力摂動で説明できる。
1つの例だけで、アルゴリズム全体の後退安定性を証明したことにはならない。

SciOxide の `scioxide-linalg` クレートでは、`LuDecomposition::factor(&a)` で LU 分解の因子を作り、因子の `solve(&b)` で右辺に対して解く。
`factor` は厳密に零のピボットに出会うと `Singular` のエラーを返し、`solve(&b)` は解のベクトルを返す。
1 本の右辺を解くだけなら、分解と求解をまとめた `scioxide_linalg::solve(&a, &b)` を使える。
受理の条件や診断を指定するときは、`solve_with_options(&b, &DirectSolveOptions)` を使う。
`DirectSolveOptions` は階数判定の方針（`RankPolicy`）、条件数による棄却の閾値、後退誤差の診断を要求するかどうかを指定する。
`solve_with_options` は、方針によって棄却された場合も `Err` ではなく `Ok` を返し、`solution()` が `None` になって、理由は `report().termination()` に記録される。
後退誤差の診断は既定では計算せず、`with_residual(Estimation::Estimate)` で要求したときだけ `report().residual()` に入る。
その `scaled_norm()` は元の行列に対する∞ノルムの後退誤差 $\|\mathbf{b} - \mathbf{A}\hat{\mathbf{x}}\|_\infty / (\|\mathbf{A}\|_\infty\|\hat{\mathbf{x}}\|_\infty + \|\mathbf{b}\|_\infty)$ であり、上式の 2 ノルムの $\eta$ とはノルムの選び方が異なる。
以下のセルは後退誤差の診断を読むので `solve_with_options` を使い、この API 診断値に加えて、元の行列による残差の 2 ノルムと解析厳密解に対する前進誤差を独立に算出する。

```rust
//| id: first-linear-system
//| title: 2元連立方程式の求解と残差・後退誤差による検算
//| run: button
//| crates: [scioxide-linalg]
use scioxide_linalg::{
    DirectSolveOptions, Estimation, LuDecomposition, Matrix, RankPolicy, Vector,
};

// 行優先の配列で A を作る。右辺 b に対する厳密解は (2, 3)。
let a = Matrix::from_vec(2, 2, vec![3.0_f64, 1.0, 1.0, 2.0]).map_err(|e| e.to_string())?;
let b = Vector::from_vec(vec![9.0_f64, 8.0]);
let factor = LuDecomposition::factor(&a).map_err(|e| e.to_string())?;
// 階数は厳密に判定し（零ピボットだけを不足とする）、後退誤差の診断を明示的に要求する。
let solve = DirectSolveOptions::new(RankPolicy::Exact).with_residual(Estimation::Estimate);
let result = factor
    .solve_with_options(&b, &solve)
    .map_err(|e| e.to_string())?;
let x = result
    .solution()
    .ok_or("指定した方針では解が受理されなかった")?;

// API の診断とは独立に、元の A に掛け直して残差と前進誤差を求める。
let ax = a.view().mul_vec(x).map_err(|e| e.to_string())?;
let residual = ax
    .as_slice()
    .iter()
    .zip(b.as_slice())
    .map(|(v, b)| (v - b).powi(2))
    .sum::<f64>()
    .sqrt();
let forward_error = x
    .as_slice()
    .iter()
    .zip([2.0, 3.0])
    .map(|(v, exact)| (v - exact).powi(2))
    .sum::<f64>()
    .sqrt();
let report = result.report().residual().ok_or("残差診断がない")?;
emit_table_with_columns!(
    serde_json::json!([
    {"key":"0","label":"x₁","type":"number","format":{"significantDigits":6},"nullText":"未定義"},
    {"key":"1","label":"x₂","type":"number","format":{"significantDigits":6},"nullText":"未定義"},
    {"key":"2","label":"残差の 2 ノルム","type":"number","format":{"significantDigits":6},"nullText":"未定義"},
    {"key":"3","label":"API の後退誤差 (∞ノルム)","type":"number","format":{"significantDigits":6},"nullText":"未定義"},
    {"key":"4","label":"前進誤差","type":"number","format":{"significantDigits":6},"nullText":"未定義"}
    ]),
    vec![(
        x.as_slice()[0],
        x.as_slice()[1],
        residual,
        report.scaled_norm(),
        forward_error
    )]
);
emit_outcome!(
    Outcome::satisfied("直接法の解が受理された")
        .status(format!("{:?}", result.report().termination()))
        .diagnostic("独立に求めた残差", residual, None)
);
```

## 逆行列の計算を回避する計算機的根拠

解を数式で $\mathbf{x}=\mathbf{A}^{-1}\mathbf{b}$ と書いても、計算機で逆行列を作る必要はない。
分解した因子を使って直接解く方法は、演算回数、誤差、疎性の点で有利なことが多い。

第 1 に演算回数の違いがある。
$n \times n$ 行列の逆行列 $\mathbf{A}^{-1}$ を陽に計算してベクトル $\mathbf{b}$ に掛ける操作には、LU分解に加えて逆行列を構成する処理と行列ベクトル積が必要になる。
三角行列の構造を使う標準的な逆行列形成では、主要項だけで合計およそ $2n^3$ 回の浮動小数点演算を要する。
一方、部分ピボット付き LU 分解を行って 1 本の右辺ベクトル $\mathbf{b}$ に対して前進代入と後退代入を直接適用する場合の演算回数はおよそ $\frac{2}{3}n^3 + 2n^2$ 回であり、計算量は逆行列を求める場合の約 3 分の 1 で済む。

第 2 に後退誤差解析における精度の違いがある。
James Wilkinson の解析が示すように、明示的に求めた近似逆行列 $\mathbf{X} \approx \mathbf{A}^{-1}$ を掛ける計算 $\hat{\mathbf{x}} = \mathbf{X}\mathbf{b}$ は、逆行列自体の丸め誤差がベクトル乗算でさらに拡大するため、LU 分解と三角連立代入の直接適用に比べて数値的不安定性を招きやすい。

第3に、疎行列の逆行列は一般には疎とは限らず、メモリ使用量が増える。
例えば局所的な差分から作った行列でも、逆行列は離れた点同士の影響を含む。
分解にもフィルインは生じるので、疎な直接法では並べ替えやメモリ使用量の見積もりも必要になる。

この例の `LuDecomposition` は、行交換を表す置換行列 $\mathbf{P}$ を用いた部分ピボット付き LU 分解 $\mathbf{P}\mathbf{A}=\mathbf{L}\mathbf{U}$ を行う。
その後、三角方程式を解いて解ベクトルを求める。
SciOxide には他の分解や反復法もあり、対称性や正定値性などの条件に応じて選ぶ。

## 条件数と残差の乖離：悪条件系における誤差増幅

数値解析において最も警戒すべき事象の一つが、「残差ノルム $\|\mathbf{r}\|_2$ が機械精度水準であるにもかかわらず、真の解との誤差（前進誤差）が著しく大きい」という現象である。
残差の小ささは、直ちに解の正確さを保証しない。

この機構を観察するために、パラメータ $\varepsilon > 0$ を含む以下の近特異な連立方程式を考える。

$$
\begin{bmatrix}
1 & 1 \\
1 & 1 + \varepsilon
\end{bmatrix}
\begin{bmatrix} x_1 \\ x_2 \end{bmatrix}
=
\begin{bmatrix} 2 \\ 2 + \varepsilon \end{bmatrix}.
$$

この方程式系の行列式は $\det(\mathbf{A}) = (1+\varepsilon) - 1 = \varepsilon$ である。
$\varepsilon > 0$ である限り行列は正則であり、真の解は $\mathbf{x}^* = (1, 1)^\mathsf{T}$ である。
ここで、右辺の第 2 成分に微小な観測誤差や丸め摂動 $\delta$ が混入した右辺ベクトル $\tilde{\mathbf{b}} = (2, 2 + \varepsilon + \delta)^\mathsf{T}$ に対する解 $\tilde{\mathbf{x}}$ を求めると、代数的に以下が導かれる。

$$
\tilde{x}_1 = 1 - \frac{\delta}{\varepsilon},
\qquad
\tilde{x}_2 = 1 + \frac{\delta}{\varepsilon}.
$$

真の解からの前進誤差ノルムは $\|\tilde{\mathbf{x}} - \mathbf{x}^*\|_2 = \sqrt{2} \frac{|\delta|}{\varepsilon}$ となる。
入力に加わった誤差 $\delta$ は、$1/\varepsilon$ という係数で増幅される。
仮に $\varepsilon = 10^{-4}$、$\delta = 10^{-7}$ であるとすると、前進誤差は $10^{-3}$ の水準に達する。
一方で、得られた解 $\tilde{\mathbf{x}}$ を測定方程式 $\mathbf{A}\tilde{\mathbf{x}} - \tilde{\mathbf{b}}$ に代入した残差は、依然として倍精度の丸め限界水準に留まる。

この誤差増幅率を支配する物理的・数学的尺度が、行列の**条件数（Condition Number）** $\kappa(\mathbf{A}) = \|\mathbf{A}\| \|\mathbf{A}^{-1}\|$ である。
対称行列の 2 ノルム条件数は最大特異値と最小特異値の比 $\sigma_{\max} / \sigma_{\min}$ に等しく、本系では $\varepsilon \to 0$ において $\kappa_2(\mathbf{A}) \approx 4/\varepsilon$ へと漸近する。
元の解 $x^*$ との誤差を評価する場合、残差も元の右辺 $b$ に対して取る必要がある。
対応するノルムで次の不等式が成立する。

$$
\frac{\|\tilde{\mathbf{x}} - \mathbf{x}^*\|}{\|\mathbf{x}^*\|}
\le
\kappa(\mathbf{A}) \frac{\|\mathbf{A}\tilde{\mathbf{x}} - \mathbf{b}\|}{\|\mathbf{b}\|}.
$$

条件数 $\kappa(\mathbf{A})$ が巨大な悪条件系では、残差が微小であっても解の信頼できる有効桁数は著しく損なわれる。
測定後の右辺に対する残差が小さくても、元の右辺との食い違いは残る。
以下のセルでは、`scioxide_linalg::SvdValues` を用いて特異値分解から2ノルム条件数を数値的に求め、理論予測および実測前進誤差と比較している。
実測値には行列と右辺を浮動小数点数に変換する誤差も含まれるため、微小な $\delta$ では実数で導いた理論値からずれる。
このセルは診断を読まないので、解は LU 分解と求解をまとめた `scioxide_linalg::solve(&a, &b)` で求める。

```rust
//| id: first-conditioned-linear-system
//| title: 近特異な2元系における条件数と前進誤差の増幅
//| run: reactive
//| crates: [scioxide-linalg]
//| inputs:
//|   matrix_gap_exponent: {"type":"range","label":"log₁₀ ε (方程式の独立度)","description":"εが小さいほど2本の直線が平行に近づき悪条件化する。","min":-8,"max":-1,"step":0.25,"value":-4}
//|   rhs_perturbation_exponent: {"type":"range","label":"log₁₀ δ (右辺の測定誤差)","description":"右辺ベクトルに加わる微小な観測誤差摂動。","min":-10,"max":-3,"step":0.25,"value":-7}
use scioxide_linalg::{Matrix, SvdValues, Vector, solve};

// 条件数・前進誤差・測定方程式の残差を、同じ行列について求める。
fn evaluate(epsilon: f64, delta: f64) -> Result<(f64, f64, f64), String> {
    let a = Matrix::from_vec(2, 2, vec![1.0, 1.0, 1.0, 1.0 + epsilon])
        .map_err(|e| e.to_string())?;
    let b = Vector::from_vec(vec![2.0, 2.0 + epsilon + delta]);
    let svd = SvdValues::compute(&a).map_err(|e| e.to_string())?;
    let values = svd.singular_values();
    let condition = values[0] / values[1];
    // 診断は読まないので、LU 分解と求解をまとめた solve を使う。零ピボットはエラーになる。
    let x = solve(&a, &b).map_err(|e| e.to_string())?;
    let ax = a.view().mul_vec(&x).map_err(|e| e.to_string())?;
    let residual = ax
        .as_slice()
        .iter()
        .zip(b.as_slice())
        .map(|(v, b)| (v - b).powi(2))
        .sum::<f64>()
        .sqrt();
    let error = x
        .as_slice()
        .iter()
        .map(|v| (v - 1.0).powi(2))
        .sum::<f64>()
        .sqrt();
    Ok((condition, error, residual))
}
let epsilon = 10.0_f64.powf(matrix_gap_exponent);
let delta = 10.0_f64.powf(rhs_perturbation_exponent);
let (condition, error, residual) = evaluate(epsilon, delta)?;
emit_table_with_columns!(
    serde_json::json!([
    {"key":"0","label":"ε","type":"number","format":{"significantDigits":6},"nullText":"未定義"},
    {"key":"1","label":"δ","type":"number","format":{"significantDigits":6},"nullText":"未定義"},
    {"key":"2","label":"条件数 κ₂","type":"number","format":{"significantDigits":6},"nullText":"未定義"},
    {"key":"3","label":"実測前進誤差","type":"number","format":{"significantDigits":6},"nullText":"未定義"},
    {"key":"4","label":"理論前進誤差","type":"number","format":{"significantDigits":6},"nullText":"未定義"},
    {"key":"5","label":"測定系の残差","type":"number","format":{"significantDigits":6},"nullText":"未定義"}
    ]),
    vec![(
        epsilon,
        delta,
        condition,
        error,
        2.0_f64.sqrt() * delta / epsilon,
        residual
    )]
);

let mut measured = Vec::new();
let mut predicted = Vec::new();
let mut conditions = Vec::new();
let mut zeros = 0;
for i in 0..=112 {
    let gap = 10.0_f64.powf(-8.0 + 7.0 * i as f64 / 112.0);
    let (kappa, error, _) = evaluate(gap, delta)?;
    if error > 0.0 {
        measured.push([gap, error]);
    } else {
        zeros += 1;
    }
    predicted.push([gap, 2.0_f64.sqrt() * delta / gap]);
    conditions.push([gap, kappa]);
}
let series = vec![
    serde_json::json!({"name":"実測前進誤差", "points":measured}),
    serde_json::json!({"name":"理論値 √2 δ/ε", "points":predicted, "style": {"lineType": "dashed"}}),
    serde_json::json!({"name":"条件数 κ₂", "points":conditions}),
];
emit_line_chart!(
    &series,
    options = &serde_json::json!({"xLabel": "行列の差 ε [-]", "yLabel": "誤差・条件数 [-]", "xType": "log", "yType": "log",
"annotations": [{"kind": "line", "axis": "x", "value": epsilon, "label": "選んだ ε"}]})
);
emit_text!(&format!("前進誤差が0で対数グラフから除いた点数：{zeros}"));
```

## 科学技術計算における解の解釈体系

連立一次方程式の求解を通して明らかになった知見は、非線形求根、最適化、微分方程式など、SciOxide ワークスペース全体の設計哲学に直接反映されている。

1. **内部構造を公開しないエラー型と構造的分類**: 数値計算はパニックを起こさず、構造化された `Result<T, SciOxideError>` を返す。
   `SciOxideError` は内部構造を公開しない型（opaque struct）であり、文字列の照合ではなく `e.kind()`（`SciOxideErrorKind` の 20 種類）や `e.view()`（`SciOxideErrorView`）を通じて失敗理由を構造的に判別する。
2. **終了理由と受容判定の分離**: 計算ループが停止したことと、許容誤差を満たして解が受理されたことは同義ではない。
   回数上限への到達や停滞による停止を識別し、得られた近似解の信頼度（`PartialResultTrust`）を評価する。
3. **残差と前進誤差の分離**: 観測可能な残差の小ささだけに頼らず、問題の条件数 $\kappa$ と後退誤差 $\eta$ を併せて評価することで、結果を使うための根拠を確認する。

連立方程式は、分解因子を作ってから右辺に対して解く。
結果は元の行列へ戻して検算し、残差と前進誤差を区別する。
