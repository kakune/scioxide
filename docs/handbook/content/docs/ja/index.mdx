本書はRustの数値計算ライブラリSciOxideを使うための学習書である。
Rustの基本構文と、初歩の微積分・線形代数を前提とする。

数式とアルゴリズムの関係、丸め誤差への対処、結果の検算方法を、実行できる例とともに説明する。
必要な API の呼び出し方と、その計算結果を判断する方法を学ぶ。

---

## 本書で学ぶこと

各章では、数理、API、計算方法を選ぶ理由、実例を順に説明する。

1. **数値計算の基礎と数理 (Theoretical Foundations)** 微積分や線形代数の基礎から出発し、アルゴリズムの導出と誤差評価を数式で厳密に追う。
   前進誤差・後退誤差の境界、条件数 $\kappa$ による感度、丸め誤差の蓄積メカニズムを説明する。
2. **公開 API の使い方** 引数、事前条件、戻り値、エラー分類を説明する。
   一度だけ計算する呼び出し方と、設定や Plan、作業領域を再利用する呼び出し方を、各 API に即して示す。
3. **計算方法を選ぶ理由** 分解法、ピボット選択、前処理、刻み幅制御が精度と計算量にどう関わるかを説明する。
   同じ形の問題を繰り返し解く場合は、作業領域を再利用する方法も扱う。
4. **具体的な実世界応用例 (Real-World Applications)** 天体力学の軌道・スイングバイ、感染症数理モデル（SEIR）のパラメータ同定、反応拡散方程式（Turing パターン）の分岐解析、線形方程式や波動など、検証可能な物理・工学課題を扱う。

## インタラクティブ実行環境と計算精度の読み方

### ブラウザ上での対話的実行（Oxiquill）

本書に掲載されたコードセルの多くは、WebAssembly（`wasm32-unknown-unknown`）にコンパイルされ、ブラウザ上で直接実行可能なインタラクティブセルである。

- **パラメータ変更**: スライダーや選択肢を操作することで、刻み幅、初期値、許容誤差、行列サイズなどの挙動を動的に観察できる。
- **グラフと表による検証**: 収束過程や誤差推移が動的チャートおよび日本語の表形式で出力される。
- **実行環境の制約**: ブラウザ上の Wasm 実行環境はシングルスレッドの逐次実行であり、スレッド並列ディスパッチ（`ThreadExecutor`）、実時間クロック（`StdClock`）、実行時間上限は利用できない。
  また、`usize` は 32 ビット幅となる。
  さらに、`scioxide-validated` の証明計算は方向付き丸めの実行環境を検査し、x86/x86_64/AArch64 のネイティブ環境だけで動くため、ブラウザでは証明部分を未実行として扱う。
  参考値を併記する場合も、証明付きの結果とは区別する。

### 推定・保証・不確かさの区別

本書では数値計算の結果を評価するにあたり、以下の区分を厳格に使い分ける。

- **推定値 (Estimate)**: 局所誤差推定やヒューリスティックによる近似値。
  収束判定の指標となるが、厳密な誤差限界を保証するものではない。
- **精度の保証 (Tested Accuracy Contract)**: `scioxide-core` の初等関数（4 ULP）や安定変換（16 ULP）のように、単体テスト・オラクル検証によって上限が確認された ULP 仕様。
- **統計的不確かさ (Statistical Uncertainty)**: モンテカルロ法やサンプリング推定における標準誤差（SE）や信頼区間（CI）。
- **包含が保証された区間 (Verified Enclosure)**: `scioxide-validated` による有向丸め区間演算によって、数学的な真の解が含まれることが証明された区間。

## 全 19 クレートの体系（依存関係順）

SciOxide は、共通基盤から高度な方程式ソルバー・応用まで、依存関係が閉じた 19 のクレートから構成されている。
前のクレートが後のクレートの前提となる。

| クレート | 役割と主な機能 | 依存する主要クレート |
|---|---|---|
| [`scioxide-core`](scioxide-core/) | 基本スカラー型（`RealScalar`）、許容誤差（`Tolerance`）、範囲安全算術・厳密累積、実行方針、求解の回数集計 | （なし） |
| [`scioxide-sparse`](scioxide-sparse/) | 疎行列形式（CSR/CSC/COO）、並べ替え（AMD/RCM）、不完全分解・直接法（Krylov 法は linalg が担当） | `core` |
| [`scioxide-linalg`](scioxide-linalg/) | 密行列演算、行列分解（LU/Cholesky/QR/SVD）、Krylov 部分空間法反復ソルバー（CG/GMRES 等）、固有値問題 | `core`, `sparse` |
| [`scioxide-spatial`](scioxide-spatial/) | 空間幾何・計算幾何、k-d 木最近傍探索、Delaunay 三角分割、Voronoi 図、凸包 | `core`, `linalg`, `sparse` |

## 数学記法とエラー処理規約

- **ベクトルと行列**: ベクトルは太字小文字 $\mathbf{x} = (x_1, \dots, x_n)^\mathsf{T}$、行列は太字大文字 $\mathbf{A} \in \mathbb{R}^{m \times n}$ と表記する。
- **ノルムと条件数**: ユークリッドノルムは $\|\mathbf{x}\|_2 = \sqrt{\mathbf{x}^\mathsf{T} \mathbf{x}}$、行列ノルムは $\|\mathbf{A}\|$、条件数は $\kappa(\mathbf{A}) = \|\mathbf{A}\| \|\mathbf{A}^{-1}\|$ と表記する。
- **エラー処理**: 失敗しうるSciOxideの数値 API は、主に `Result<T, SciOxideError>` を返す。
  `SciOxideError` は内部構造を公開しない型であり、`kind()`（`SciOxideErrorKind` の 20 種類）および `view()`（`SciOxideErrorView`）を通じてエラー理由を判定する。

まずは[最初の計算](getting-started/)で、連立方程式を解いて検算する。
誤差や結果の読み方に迷ったら、共通概念のページへ戻る。
目的が決まったらクレート一覧から担当する章を選び、API ガイドで具体的な呼び出し方を確認する。
