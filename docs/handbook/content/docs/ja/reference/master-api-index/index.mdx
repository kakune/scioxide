識別子の先頭文字から、各クレートの用途別 API 表へ進む。
大文字と小文字を区別せずに並べ、再出力に反映された項目はクレートごとに掲載する。
`scioxide-core::backend` の項目は名前空間を付けて区別する。

## 名前から探す

| 名前の範囲 | 項目数 |
|---|---|
| [A–C](a-c/) | 982 |
| [D–H](d-h/) | 872 |
| [I–N](i-n/) | 793 |
| [O–R](o-r/) | 736 |
| [S](s/) | 581 |
| [T–Z](t-z/) | 249 |

## 読み方

API 表で用途と入力条件を確認し、説明節や実行例へ進む。
作業領域、オプション、終了状態は計算の API と合わせて読む。
未完了の結果を成功とみなさず、包含が保証された区間、誤差推定、統計的な不確かさを区別する。
