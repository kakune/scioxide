交流回路のフェーザ、量子力学の確率振幅、信号のスペクトルのように、複素数を値に持つ計算は多い。
そうした計算で最小化したい量は、電力 $|V|^2$ や残差の二乗和 $\sum_k |r_k|^2$ のような実数であることが多い。
定数でない実数値の関数は複素変数について正則ではないので、複素解析の導関数 $f'(z)$ だけではこれらの量の勾配を表せない。

`scioxide-ad` は複素数のための数値型を持たない。
複素数は `scioxide_core::Complex<R>` で表し、実部と虚部の型 `R` に `Dual`、`MultiDual`、`Jet`、`Var` などの数値型を使う。
微分は実部と虚部の 2 つの実座標についての微分（実線形の微分）で、正則な関数ではそこから $f'(z)$ が読める。
このページでは上線 $\bar z$ を複素共役に使う。
数値型と前進・逆モードの微分は[前進モードと二重数](../forward-mode/)と[逆モードとテープ](../reverse-mode-and-replay/)で説明する。

## Complex の算術と ComplexElementary

`Complex<R>` は出力に反映されたフィールド `re`、`im` を持つ `#[repr(C)]` の構造体である。
和、差、積、符号反転、実数倍と実数での割り算（`Complex<R> * R`、`Complex<R> / R`）は `scioxide_core` が成分の型について汎用に定めているので、`R` が数値型でもそのまま使える。
積は $(a + ib)(c + id) = (ac - bd) + i(ad + bc)$ を成分の演算で計算する。
複素数どうしの割り算と、`conj`、`norm`、`exp` などの固有メソッドは成分が `RealScalar`（`f32`・`f64`）のときだけ定義されている。

数値型を成分に持つ複素数の初等関数は、`scioxide_ad::ComplexElementary` トレイトが与える。
`R: Real` のすべての `Complex<R>` に実装され、関数の名前は `Complex<f64>` の固有メソッドにそろえてある。
各関数は実部と虚部の `R` の演算で書かれているので、どのモードでも微分は実部と虚部の式の微分になる。

| メソッド | 計算する量 | 実部と虚部の式 |
|---|---|---|
| `inv` | $1/z$ | 基底の値から作った定数 $m = \max(\lvert x\rvert , \lvert y\rvert )$ で割ってから $\bar z/\lvert z\rvert ^2$ を作り、最後に $m$ で割ってあふれを避ける |
| `exp` | $e^z$ | $e^x(\cos y + i \sin y)$ |
| `ln` | 主値の対数 | $\ln\lvert z\rvert + i \arg z$。$\tfrac12 \le \lvert z\rvert \le 2$ では $\tfrac12 \ln(1 + (x^2 + y^2 - 1))$、ほかでは $\ln \operatorname{hypot}(x, y)$ で、値は `Complex<f64>::ln` と同じく積を正確に足して求める |
| `sqrt` | 主値の平方根（実部が非負） | $x \ge 0$ では $a = \sqrt{(\lvert z\rvert + x)/2}$、$b = y/(2a)$。$x < 0$ では役割を入れ替え、どちらの成分も桁落ちしない |
| `sin`、`cos` | $\sin z$、$\cos z$ | $\sin x \cosh y + i \cos x \sinh y$、$\cos x \cosh y - i \sin x \sinh y$ |
| `norm` | $\lvert z\rvert $ | $\operatorname{hypot}(x, y)$ |
| `arg` | $\arg z \in [-\pi, \pi]$ | $\operatorname{atan2}(y, x)$ |

`norm` と `arg` は関連型 `Part`（`= R`）の実数を返し、ほかは `Complex<R>` を返す。
複素数どうしの割り算は `z * w.inv()`、共役は `Complex::new(z.re, -z.im)` と書く。
`tan`、双曲線関数、冪などはトレイトにないので、たとえば $\tan z$ は `z.sin() * z.cos().inv()` のように組み立てる。

`Complex<f64>` に対して `z.exp()` と書くと、トレイトではなく `scioxide_core` の固有メソッドが呼ばれる。
汎用関数の中では成分の型が `RealScalar` と分からないので、トレイトのメソッドが選ばれる。
`Complex<f64>` でトレイトの実装を呼びたいときは `ComplexElementary::exp(z)` と書く。

式が折れ点の関数を含むので、テープは次の点で折れ点に当たった回数を数える（[折れ点と非有限値の扱い](../nonsmooth-and-nonfinite-policies/)）。
`exp`、`sin`、`cos` は折れ点の関数を含まない。

- `norm` と `sqrt` は原点（`hypot` の折れ点）。
- `ln` と `arg` は原点と負の実軸 $y = 0$、$x < 0$（`atan2` の折れ点。
  `ln` は原点で `hypot` の分も数える）。

`inv` の $m$ は基底の値から作る定数で微分されないので、`inv` は折れ点を数えない。
結果は数学的には $m$ によらないので、導関数は $-1/z^2$ のままである。

## 実座標による微分

複素関数 $f(z) = u(x, y) + i\,v(x, y)$ を、$\mathbb{R}^2$ から $\mathbb{R}^2$ への写像 $(x, y) \mapsto (u, v)$ とみなす。
$u, v$ が実数の意味で微分可能なら、その微分は 2×2 の実ヤコビ行列

$$
J = \begin{pmatrix} u_x & u_y \\ v_x & v_y \end{pmatrix}, \qquad
\begin{pmatrix} \dot u \\ \dot v \end{pmatrix} = J \begin{pmatrix} \dot x \\ \dot y \end{pmatrix}
$$

で表される（$u_x = \partial u/\partial x$ などと書く）。
接ベクトル $\dot z = \dot x + i\dot y$ に対するヤコビ行列・ベクトル積（JVP）は $J$ を掛けることであり、$f$ が正則かどうかに関係なく定義される。

`scioxide-ad` でこれを求めるには、実部と虚部を数値型にして関数を評価する。
前進モードでは `Complex::new(MultiDual::variable(x, 0)?, MultiDual::variable(y, 1)?)` を入力にすると、出力の `re.gradient()` が $(u_x, u_y)$、`im.gradient()` が $(v_x, v_y)$ になる。
逆モードでは $(x, y)$ を 2 つの実数の入力としてテープに渡し、関数の中で `Complex::new(x[0], x[1])` を作り、実部と虚部を出力に積む。
入力と出力をどの順に並べるかは呼び出し側が決める。
`Complex<Jet<f64, N>>` を使うと、直線 $z(t) = z_0 + t\,\delta z$ に沿った $f(z(t))$ の正規化 Taylor 係数が実部と虚部の組で得られる（[Taylor ジェットと高階の係数](../taylor-jets/)）。

逆モードでは内積を決める必要がある。
複素数を $\mathbb{R}^2$ の点とみなしたときの通常の内積は、実内積 $\langle a, b\rangle = \operatorname{Re}(\bar a\, b) = a_x b_x + a_y b_y$ である。
出力の余接（cotangent）$w$ に対するベクトル・ヤコビ行列積（VJP）は $J^{\mathsf T} w$ で、成分を並べたテープの逆走査がそのままこれを計算する。

## Cauchy–Riemann の関係と Wirtinger 微分

$f$ が $z$ で複素微分可能であることは、$u, v$ が $z$ で実数の意味で微分可能で、Cauchy–Riemann の関係 $u_x = v_y$、$u_y = -v_x$ を満たすことと同値である。
$z$ の近傍のすべての点で複素微分可能な関数を、$z$ で正則であるという。
$f$ が $z$ で複素微分可能なとき、$f'(z) = a + ib$（$a = u_x$、$b = v_x$）とおくと

$$
J = \begin{pmatrix} a & -b \\ b & a \end{pmatrix}
$$

となり、$J\dot z$ は複素数の積 $f'(z)\,\dot z$ に一致する。
したがって $x$ 方向のシード $(\dot x, \dot y) = (1, 0)$ の JVP の結果 $(u_x, v_x)$ を、$f'(z) = u_x + i v_x$ として読める。
転置 $J^{\mathsf T}$ は $\overline{f'(z)}$ を掛ける写像なので、VJP は $\overline{f'(z)}\,w$ である。

正則でない関数では、$J$ はこの形にならない。
共役 $\bar z$ では $J = \operatorname{diag}(1, -1)$、$|z|^2 = x^2 + y^2$（虚部 0 の複素数とみなす）では $J = \begin{pmatrix} 2x & 2y \\ 0 & 0 \end{pmatrix}$ である。
このとき $u_x + i v_x$ は $x$ 方向の方向微分 $\partial f/\partial x$ にすぎず、$f'(z)$ としては読めない。
JVP と VJP は実数の意味の微分なので、どちらの関数でもそのまま定義される。

実ヤコビ行列の 4 成分は Wirtinger 微分

$$
\begin{aligned}
\frac{\partial f}{\partial z} &= \frac12\left(\frac{\partial f}{\partial x} - i\,\frac{\partial f}{\partial y}\right) = \frac{(u_x + v_y) + i\,(v_x - u_y)}{2}, \\
\frac{\partial f}{\partial \bar z} &= \frac12\left(\frac{\partial f}{\partial x} + i\,\frac{\partial f}{\partial y}\right) = \frac{(u_x - v_y) + i\,(v_x + u_y)}{2}
\end{aligned}
$$

の 2 つの複素数と同じ情報を持つ。
Cauchy–Riemann の関係は $\partial f/\partial \bar z = 0$ と同値で、そのとき $f'(z) = \partial f/\partial z$ である。
$|\partial f/\partial \bar z|$ は正則性からのずれの大きさで、Cauchy–Riemann の残差 $(u_x - v_y, u_y + v_x)$ の長さの半分である。

JVP は $\dot f = \frac{\partial f}{\partial z}\,\dot z + \frac{\partial f}{\partial \bar z}\,\overline{\dot z}$ と書ける。
実内積の等式 $\operatorname{Re}(\bar w\,\dot f) = \operatorname{Re}(\bar g\,\dot z)$ がすべての $\dot z$ で成り立つ $g$ を求めると、VJP は

$$
g = \overline{\left(\frac{\partial f}{\partial z}\right)}\, w + \frac{\partial f}{\partial \bar z}\, \bar w
$$

になり、正則なら第 2 項が消えて $g = \overline{f'(z)}\,w$ に戻る。

## 実数値の関数の勾配

実数値の関数 $L(z)$ では、`scioxide-ad` の逆モードが返すのは実座標の勾配 $(\partial L/\partial x, \partial L/\partial y)$ である。
これを 1 つの複素数にまとめる規約は 2 つある。

$$
g = \frac{\partial L}{\partial x} + i\,\frac{\partial L}{\partial y} = 2\,\frac{\partial L}{\partial \bar z}, \qquad
h = \bar g = \frac{\partial L}{\partial x} - i\,\frac{\partial L}{\partial y} = 2\,\frac{\partial L}{\partial z}
$$

$L$ が実数なので $\partial L/\partial \bar z = \overline{\partial L/\partial z}$ が成り立ち、2 つの式の等号が従う。
一次の変化は $dL = \operatorname{Re}(\bar g\,dz) = \operatorname{Re}(h\,dz)$ で、$g$ は $L$ を最も速く増やす方向を指すので、勾配降下は $z \leftarrow z - \alpha g$（$\alpha > 0$）である。
$h$ はこの方向の共役で、同じ $dL$ を表すが、$h$ を $g$ の代わりに実内積に入れると誤った値になる。
変数が複数あるときは成分ごとに $g_k = \partial L/\partial x_k + i\,\partial L/\partial y_k$ とし、$dL = \operatorname{Re}(g^{\mathsf H} dz)$ である。

`scioxide-ad` は複素数の勾配を返す関数も、2 つの規約を変換する関数も提供しない。
逆モードの 2 つの実数の結果から呼び出し側が $g$（必要なら $h = \bar g$）を組み立てる。

たとえば $L = |z|^2 = z\bar z$ では $\partial L/\partial \bar z = z$ なので $g = 2z$ で、実座標の勾配 $(2x, 2y)$ と一致する。
$f$ の値の大きさの 2 乗 $L = |f(z)|^2 = f\bar f$ では、積の規則と $\partial \bar f/\partial \bar z = \overline{\partial f/\partial z}$ から

$$
g = 2\left( f\,\overline{\frac{\partial f}{\partial z}} + \bar f\,\frac{\partial f}{\partial \bar z} \right)
$$

で、$f$ が正則なら $g = 2 f(z)\,\overline{f'(z)}$ である。

次のセルは選んだ $f$ について $J$ を `MultiDual<f64, 2>` の前進モードで求め、Wirtinger 微分を閉形式と比べる。
閉形式の参照値は `scioxide_core` の `Complex<f64>` の固有メソッドで独立に計算する（$e^z$、$1/z$、$1/(2\sqrt z)$、$-1/z^2$、$\cos z$、$|z|^2$ では $(\bar z, z)$、$\bar z$ では $(0, 1)$）。
さらに $L = |f(z)|^2$ の勾配を逆モードの `grad` で求めて $g$ にまとめ、前進モードの $J$ と値から上の式で作った $g$ と比べる。
入力は関数と評価点 $z = x + iy$ である。

```rust
//| id: ad-complex-real-linear
//| ref: ad-complex-real-linear
//| title: 複素関数の実ヤコビ行列、Wirtinger 微分、|f|² の勾配
//| run: reactive
//| crates: [scioxide-ad, scioxide-core]
//| inputs:
//|   function: {"type":"select","label":"関数 f(z)","description":"z̄ と |z|² は正則でない。","options":["exp z","ln z","sqrt z","1/z","sin z","|z|²","z̄"],"value":"exp z"}
//|   re_z: {"type":"range","label":"Re z","min":-2,"max":2,"step":0.25,"value":0.5}
//|   im_z: {"type":"range","label":"Im z","min":-2,"max":2,"step":0.25,"value":1}
//| cases:
//|   - {"id":"square-root","label":"sqrt z、z = −1.5 + 0.25i","description":"負の実軸に近い点でも Cauchy–Riemann の関係が成り立つ。","inputs":{"function":"sqrt z","re_z":-1.5,"im_z":0.25}}
//|   - {"id":"modulus","label":"|z|²、z = 1.5 + 2i","description":"正則でなく、∂f/∂z̄ = z が残る。","inputs":{"function":"|z|²","re_z":1.5,"im_z":2}}
//|   - {"id":"conjugate","label":"z̄","description":"∂f/∂z = 0、∂f/∂z̄ = 1。","inputs":{"function":"z̄"}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"wirtinger","path":"/rows/0/1","approx":{"value":0.8908079042931287,"rtol":1e-14}}
//|       - {"artifact":"wirtinger","path":"/rows/0/5","approx":{"value":0,"atol":1e-14}}
//|       - {"artifact":"wirtinger","path":"/rows/1/5","approx":{"value":0,"atol":1e-14}}
//|       - {"artifact":"wirtinger","path":"/rows/2/5","approx":{"value":0,"atol":1e-13}}
//|   - case: square-root
//|     expect:
//|       - {"artifact":"wirtinger","path":"/rows/0/5","approx":{"value":0,"atol":1e-14}}
//|       - {"artifact":"wirtinger","path":"/rows/1/5","approx":{"value":0,"atol":1e-14}}
//|       - {"artifact":"wirtinger","path":"/rows/2/5","approx":{"value":0,"atol":1e-13}}
//|   - case: modulus
//|     expect:
//|       - {"artifact":"jacobian","path":"/rows/0/2","approx":{"value":3,"atol":1e-14}}
//|       - {"artifact":"wirtinger","path":"/rows/1/1","approx":{"value":1.5,"atol":1e-14}}
//|       - {"artifact":"wirtinger","path":"/rows/1/2","approx":{"value":2,"atol":1e-14}}
//|       - {"artifact":"wirtinger","path":"/rows/2/5","approx":{"value":0,"atol":1e-11}}
//|   - case: conjugate
//|     expect:
//|       - {"artifact":"wirtinger","path":"/rows/0/1","approx":{"value":0,"atol":1e-15}}
//|       - {"artifact":"wirtinger","path":"/rows/1/1","approx":{"value":1,"atol":1e-15}}
//|       - {"artifact":"wirtinger","path":"/rows/2/5","approx":{"value":0,"atol":1e-14}}
use scioxide_ad::{ComplexElementary, MultiDual, Real, grad};
use scioxide_core::Complex;

// 選んだ f を、実部と虚部がどの数値型でも動く汎用関数として書く。
fn apply<R: Real>(name: &str, z: Complex<R>) -> Complex<R> {
    match name {
        "exp z" => z.exp(),
        "ln z" => z.ln(),
        "sqrt z" => z.sqrt(),
        "1/z" => z.inv(),
        "sin z" => z.sin(),
        "|z|²" => Complex::new(z.re * z.re + z.im * z.im, R::zero()),
        _ => Complex::new(z.re, -z.im),
    }
}

// 前進モード: 実部のシード (1, 0)、虚部のシード (0, 1) で J の 2 列を一度に求める。
let x = MultiDual::<f64, 2>::variable(re_z, 0).map_err(|e| e.to_string())?;
let y = MultiDual::<f64, 2>::variable(im_z, 1).map_err(|e| e.to_string())?;
let w = apply(&function, Complex::new(x, y));
let ([ux, uy], [vx, vy]) = (w.re.gradient(), w.im.gradient());
let value = Complex::new(w.re.value(), w.im.value());
let f_z = Complex::new(0.5 * (ux + vy), 0.5 * (vx - uy));
let f_zbar = Complex::new(0.5 * (ux - vy), 0.5 * (vx + uy));

// 閉形式（独立検算）: scioxide_core の Complex<f64> の固有メソッドで (∂f/∂z, ∂f/∂z̄) を作る。
let z = Complex::new(re_z, im_z);
let (zero, one) = (Complex::new(0.0, 0.0), Complex::new(1.0, 0.0));
let (reference_z, reference_zbar) = match function.as_str() {
    "exp z" => (z.exp(), zero),
    "ln z" => (z.inv(), zero),
    "sqrt z" => ((z.sqrt() * 2.0).inv(), zero),
    "1/z" => (-(z * z).inv(), zero),
    "sin z" => (z.cos(), zero),
    "|z|²" => (z.conj(), z),
    _ => (zero, one),
};

// 逆モード: L = |f(z)|² の実座標の勾配を g = ∂L/∂x + i ∂L/∂y にまとめる。
let gradient = grad(
    |p| {
        let f = apply(&function, Complex::new(p[0], p[1]));
        Ok(f.re * f.re + f.im * f.im)
    },
    &[re_z, im_z],
)
.map_err(|e| e.to_string())?;
let g = Complex::new(gradient.as_slice()[0], gradient.as_slice()[1]);
// 前進モードの J と値から g = 2 (f conj(∂f/∂z) + conj(f) ∂f/∂z̄) を作る（手計算）。
let expected = (value * f_z.conj() + value.conj() * f_zbar) * 2.0;

let sig8 = serde_json::json!({ "significantDigits": 8 });
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let jacobian_columns = serde_json::json!([
    { "key": "0", "label": "成分" },
    { "key": "1", "label": "値 [-]", "type": "number", "format": sig8 },
    { "key": "2", "label": "∂/∂x [-]", "type": "number", "format": sig8 },
    { "key": "3", "label": "∂/∂y [-]", "type": "number", "format": sig8 }
]);
let jacobian_rows = vec![
    ("u = Re f", value.re, ux, uy),
    ("v = Im f", value.im, vx, vy),
];
emit_table_with_columns!(
    jacobian_columns,
    jacobian_rows,
    metadata = serde_json::json!({ "id": "jacobian" })
);
let columns = serde_json::json!([
    { "key": "0", "label": "量" },
    { "key": "1", "label": "実部 [-]", "type": "number", "format": sig8 },
    { "key": "2", "label": "虚部 [-]", "type": "number", "format": sig8 },
    { "key": "3", "label": "参照の実部 [-]", "type": "number", "format": sig8 },
    { "key": "4", "label": "参照の虚部 [-]", "type": "number", "format": sig8 },
    { "key": "5", "label": "差の大きさ [-]", "type": "number", "format": sci2 }
]);
let gap = |a: Complex<f64>, b: Complex<f64>| (a - b).norm();
let rows = vec![
    (
        "∂f/∂z",
        f_z.re,
        f_z.im,
        reference_z.re,
        reference_z.im,
        gap(f_z, reference_z),
    ),
    (
        "∂f/∂z̄",
        f_zbar.re,
        f_zbar.im,
        reference_zbar.re,
        reference_zbar.im,
        gap(f_zbar, reference_zbar),
    ),
    (
        "g（L = |f|² の勾配）",
        g.re,
        g.im,
        expected.re,
        expected.im,
        gap(g, expected),
    ),
];
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "wirtinger" })
);
```

既定の $f = e^z$、$z = 0.5 + i$ では、$\partial f/\partial z = 0.89081 + 1.38735i$ が参照値 $e^z$ と $3.1 \times 10^{-16}$ の差で一致し、$\partial f/\partial \bar z$ は正確に 0 である。
$J$ の 2 列は $u_x = v_y$、$u_y = -v_x$ をビット単位で満たす。
$L = |e^z|^2 = e^{2x}$ の勾配は $g = 5.43656 + 4.4 \times 10^{-16} i$ で、実部は $2e^{2x} = 2e$ に等しく、虚部は丸めで残った値である。

負の実軸に近い $z = -1.5 + 0.25i$ の $\sqrt z$ でも、$|\partial f/\partial \bar z|$ は $3.5 \times 10^{-18}$ で、$\partial f/\partial z$ は $1/(2\sqrt z)$ と $1.1 \times 10^{-16}$ の差で一致する。
`sqrt` の式が桁落ちを避けているので、切断の近くでも Cauchy–Riemann の関係が丸めの水準で成り立つ。

正則でない $|z|^2$（$z = 1.5 + 2i$）では $\partial f/\partial z = \bar z = 1.5 - 2i$、$\partial f/\partial \bar z = z = 1.5 + 2i$ で、正則性からのずれ $|\partial f/\partial \bar z| = |z| = 2.5$ が残る。
このとき $J$ の第 1 列 $(u_x, v_x) = (3, 0)$ は $\partial f/\partial x$ であって $f'$ ではない。
$L = |f|^2 = |z|^4$ の勾配 $g = 37.5 + 50i$ は $2\,\partial L/\partial \bar z = 4|z|^2 z$ に等しく、前進モードから組み立てた値とビット単位で一致する。
$\bar z$ では $\partial f/\partial z = 0$、$\partial f/\partial \bar z = 1$ で、$L = |\bar z|^2$ の勾配は $g = 2z = 1 + 2i$ である。

## 主枝と分枝切断

`ln` と `sqrt` は主値を返し、分枝切断（値が不連続になる曲線）は負の実軸にある。
上側から下側へ切断をまたぐと、$\operatorname{Im} \ln z$ は $\pi$ から $-\pi$ へ $2\pi$ 跳び、$\sqrt z$ は $i\sqrt{|x|}$ から $-i\sqrt{|x|}$ へ符号を変える。
導関数は選ばれた枝の導関数である。
$\ln$ の導関数 $1/z$ は切断の両側で同じ値に近づくので跳ばないが、$\sqrt z$ の導関数 $1/(2\sqrt z)$ は値と一緒に符号を変える。
切断の上では、どちらの枝の微分も切断をまたぐ変化を表さない。

虚部が $\pm 0$ の切断上の点では、虚部のゼロの符号で側が決まる。

- `ln` と `arg` は $\operatorname{atan2}(\pm 0, x) = \pm\pi$（$x < 0$）に従い、$+0$ で上側、$-0$ で下側の値を返す。
  `Complex<f64>` の固有メソッドの `ln` も同じである。
- `sqrt` は虚部の符号ビットで側を選ぶので、$+0$ で上側の値 $i\sqrt{|x|}$、$-0$ で下側の値 $-i\sqrt{|x|}$ を返す。
  `Complex<f64>` の固有メソッドの `sqrt` も同じである。

`ln` の虚部は `atan2` なので、テープは切断上の点で折れ点を 1 回数え、`KinkPolicy::Error` の下では `DomainError` になる。
`sqrt` の式は `select` で枝を選ぶので、切断上でも折れ点を数えない。
原点では `ln` も `sqrt` も微分できず、返る導関数は式の規約によるもので、$f'$ の値ではない。

次のセルは実部 $x < 0$ を固定して虚部 $y$ を $-0.5$ から $0.5$ まで動かし、$\ln z$ と $\sqrt z$ の値の虚部と、前進モードの $J$ の第 1 列から読んだ $f' = u_x + i v_x$ を描く。
2 つのグラフは横軸 $\operatorname{Im} z$ で連動する。
表は $y = +10^{-3}, +0, -0, -10^{-3}$ の 4 点で、値、$f'$、枝の導関数との整合（$\ln$ では $|z f' - 1|$、$\sqrt{}$ では $|2\sqrt z\, f' - 1|$）を示す。
$\ln$ の表には `Tape<f64>` で $\operatorname{Im} \ln z$ の勾配を求めたときの折れ点の数と、`KinkPolicy::Error` での結果も示す。
$\sqrt{}$ の表には比較のため `Complex<f64>` の固有メソッドの $\operatorname{Im} \sqrt z$ も示す。

既定の $\operatorname{Re} z = -1$ では、$\operatorname{Im} \ln z$ が上側の $\pi$ 付近から下側の $-\pi$ 付近へ $2\pi$ 跳ぶ。
一方 $f'$ の実部は $-1$ 付近にとどまり、虚部は $\operatorname{Im}(1/z) = -y/(x^2 + y^2)$ に従って 0 を通って滑らかに変わる。
$\sqrt z$ の虚部は 1 から $-1$ へ跳び、$f'$ の虚部も $-0.5$ から $0.5$ へ跳ぶ。
表の $|z f' - 1|$ と $|2\sqrt z\, f' - 1|$ は、$\pm 0$ を含むどの点でも $2.2 \times 10^{-19}$ 以下で、返った導関数が返った値の枝の導関数であることを示す。

$\pm 0$ では $\ln$ の値が $\pi$ と $-\pi$ に分かれ、テープは折れ点を 1 回数え、`KinkPolicy::Error` の勾配は `DomainError` になる。
切断から $10^{-3}$ 離れた点では折れ点を数えない。
$-0$ では `ComplexElementary` の $\operatorname{Im} \sqrt z$ も固有メソッドも $-1$（下側）で、$f'$ も下側の枝の $0.5i$ である。
$\operatorname{Re} z = -0.25$ では原点に近づくので、$f'$ の大きさが $\ln$ で $1/|z| = 4$、$\sqrt{}$ で $1/(2\sqrt{|z|}) = 1$ に増える。
$\operatorname{Re} z = -2$ では $\sqrt z$ の跳び $2\sqrt{|x|}$ が $2\sqrt 2$ になる。

## まとめ

複素数の計算は `Complex<R>` の成分に数値型を入れて書き、割り算は `z * w.inv()`、初等関数は `ComplexElementary` のメソッドで書けば、どのモードでも実部と虚部についての微分が得られる。
正則な関数では $x$ 方向のシード $(1, 0)$ の結果 $u_x + i v_x$ を $f'(z)$ として読めるが、正則でない関数ではそれは $\partial f/\partial x$ にすぎないので、$\partial f/\partial \bar z$ が 0 であることを確かめてから $f'$ として扱う。
実数値の関数の勾配は逆モードの 2 つの実数の結果から $g = \partial L/\partial x + i\,\partial L/\partial y = 2\,\partial L/\partial \bar z$ として組み立て、勾配降下では $z - \alpha g$ に進む。
$h = 2\,\partial L/\partial z$ の規約を使うコードと値をやり取りするときは、呼び出し側で共役をとる。
`ln` と `arg` は負の実軸と原点で折れ点を数えるので、`KinkPolicy::Error` のテープではこれらの点で `DomainError` になる。
虚部が $\pm 0$ の切断上では、`ln` と `sqrt` はどちらも虚部の符号で側を選び、`Complex<f64>` の固有メソッドと同じ値を返す。
