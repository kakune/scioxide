自動微分は関数を初等演算の列に分け、各演算の局所的な導関数（偏導関数）を連鎖律でつなぐ。
したがって導関数の精度とロバスト性は、各演算の偏導関数をどの式で評価するかで決まる。
このページは `Real` の初等関数が使う偏導関数の式、引数の領域で式を切り替える関数、安定変換の 1・2 階の導関数、導関数の精度の保証を説明する。
前進モードとテープの仕組みそのものは[前進モードと二重数](../forward-mode/)と[逆モードとテープ](../reverse-mode-and-replay/)で扱う。
配列を受け取る `logsumexp`・`softmax_into` と内積・行列積の微分は[正規化と行列積の微分](../normalization-and-matrix-products/)で扱う。

## 初等関数の局所規則

$y = f(x)$ を 1 つの初等関数とする。
ラッパー型（`Dual`、`MultiDual`、`Var`）の上の `f` は、値 $y$ を一段下の型 `Primal` の演算で計算し、偏導関数 $f'(x)$ も `Primal` の演算で評価する。
`Primal` はラッパー型の値の部分の型で、`Dual<f64>` では `f64`、`Dual<Dual<f64>>` では `Dual<f64>` である。
`Dual` は接ベクトル（tangent）を $\dot y = f'(x)\,\dot x$ と保持する。
`Var` は $f'(x)$ を文（statement、テープの 1 記録）の偏導関数として保存し、逆走査（記録を末尾から先頭へたどる走査）で $\bar x$ に $f'(x)\,\bar y$ を足す。
$\bar x$、$\bar y$ は随伴（adjoint）で、最終の出力の $x$、$y$ についての偏導関数である。
値は `Primal` の演算そのものなので、微分の方式によらず、包まない型で同じ関数を評価した値とビットで一致する。

偏導関数を `Primal` の演算で評価するので、型を入れ子にすると、外側の型は偏導関数の式そのものを微分する。
たとえば `Dual<Dual<f64>>` の 2 階微分は、内側の規則が書いた $f'$ の式（評価した形）を外側の二重数で微分した値である。
数学的に同じ $f'$ でも、式の書き方が 2 階微分の丸めと定義域を決める。

`Real` が持つ初等関数は次のとおりである。
二項関数はメソッドのレシーバーが第 1 引数で、`y.atan2(x)` は点 $(x, y)$ の偏角 $\operatorname{atan2}(y, x) \in [-\pi, \pi]$、`x.log(b)` は $\log_b x$、`a.powf(b)` は $a^b$ を返す。

| 区分 | 単項関数 | 二項関数ほか |
|---|---|---|
| べきと根 | `recip`、`sqrt`、`cbrt` | `powf`、`powm1`、`powi(n)` |
| 指数と対数 | `exp`、`exp2`、`exp_m1`、`ln`、`ln_1p`、`log2`、`log10` | `log`、`logaddexp`、`xlogy`、`xlog1py` |
| 三角関数と逆関数 | `sin`、`cos`、`tan`、`asin`、`acos`、`atan` | `atan2`、`hypot`、`sin_cos` |
| 双曲線関数と逆関数 | `sinh`、`cosh`、`tanh`、`asinh`、`acosh`、`atanh` | |
| 角度の換算 | `to_degrees`、`to_radians` | |
| 安定変換 | `softplus`、`sigmoid`、`log_sigmoid`、`logit`、`exprel`、`cosm1`、`sinc`、`sincpi`、`sin_pi`、`cos_pi`、`tan_pi`、`sin_degrees`、`cos_degrees`、`tan_degrees` | |
| 折れ点を持つ関数 | `abs`、`signum`、`floor`、`ceil`、`round`、`trunc`、`fract` | `min`、`max`、`clamp`、`%` |

`sin_cos` は `sin` と `cos` を別々に呼んだ結果とビットで一致する。
最後の行の関数の導関数は[折れ点と非有限値の扱い](../nonsmooth-and-nonfinite-policies/)で扱う。

偏導関数の式はすでに計算した値 $y$ を再利用し、引き算による打ち消しを避ける形で書かれている。
主なものを挙げる。

| 関数 | 偏導関数の式 | 式を選んだ理由 |
|---|---|---|
| `recip`、`sqrt`、`cbrt` | $-y^2$、$0.5/y$、$(1/y)/(3y)$ | 値 $y$ を再利用する |
| `exp_m1` | $e^x$ | $y + 1$ は $x \ll 0$ で打ち消すが、$e^x$ は相対精度を保つ |
| `tan` | $1 + y^2$ | 値 $y$ を再利用する |
| `asin`、`atanh` | $1/\sqrt{(1 - x)(1 + x)}$、$1/((1 - x)(1 + x))$ | $1 - x$ は $x$ が 1 に近いと厳密に計算でき、$1 - x^2$ の打ち消しを避ける |
| $a / b$ | $(1/b,\ -q/b)$、$q = a/b$ | 商 $q$ を再利用する |
| `powf` | $(\operatorname{azmul}(b, a^{b-1}),\ \operatorname{azmul}(a^b, \ln a))$ | $a = 0$ で $0 \cdot (-\infty)$ を NaN にしない |
| `logaddexp` | $(\sigma(a - b),\ \sigma(b - a))$ | $a - b$ が非有限なら大きい側に 1、他方に 0 |

$\sigma(t) = 1/(1 + e^{-t})$ はロジスティック関数である。
`azmul` は、どちらかの因子が厳密に 0 なら相手が無限大や NaN でも $+0$ を返す積（絶対零の積）である。
IEEE 754 の通常の積（以下 IEEE 積）では、$0 \cdot \infty$ は NaN になる。
`powf` の指数側の偏導関数 $a^b \ln a$ は、$a = 0$、$b > 0$ では値 $a^b = 0$ と $\ln a = -\infty$ の積になり、IEEE 積では NaN だが、`azmul` では極限値の 0 になる。
テープでは、指数が受動的（入力に依存しない定数）なら、この偏導関数を計算しない。

`Dual` と `MultiDual` は、`×`、スカラー倍、`to_degrees`、`to_radians`、`fract`、`exp`、`exp2`、`exp_m1`、`sin`、`cos`、`sinh`、`cosh`、`tanh`、`atan`、`asinh` の偏導関数を IEEE 積で接ベクトルに掛け、ほかのすべての偏導関数を `azmul` で掛ける。
テープの走査はすべての更新に `azmul` を使う。
連鎖律の積は乗算と加算を分けて行い（`mul_add` を使わない）、結果は FMA の有無によらない。
`azmul` が導関数を変える例と、IEEE 積との違いは[折れ点と非有限値の扱い](../nonsmooth-and-nonfinite-policies/)で確かめる。

## 領域による式の切り替え

1 つの式では引数の全域で精度を保てない関数がある。
$\tanh' x = 1 - \tanh^2 x$ は、$|x|$ が大きいと $\tanh^2 x$ が 1 に近づいて打ち消しを起こす。
$|x|$ が約 19.06 を超えると $\tanh x$ が 1 に丸められ、この式は 0 を返す。
真の値 $\operatorname{sech}^2 x \approx 4e^{-2|x|}$ は $|x| = 354$ 付近まで正規化数で表せる。
$\operatorname{arsinh}' x = 1/\sqrt{x^2 + 1}$ は、$|x| > 2^{512} \approx 1.34 \times 10^{154}$ で $x^2$ が無限大にあふれて 0 を返す。

`scioxide-ad` は次の 6 つの関数で、領域ごとに別の式を使う。

| 関数 | 既定の式 | 切り替える条件と式 |
|---|---|---|
| `atan` | $1/(1 + x^2)$ | $\lvert x\rvert > 1$ で $r^2/(1 + r^2)$、$r = 1/x$ |
| `tanh` | $1 - y^2$ | $\lvert x\rvert > 1$ で $s^2$、$s = 2e/(1 + e^2)$、$e = e^{-\lvert x\rvert}$ |
| `asinh` | $1/\sqrt{x^2 + 1}$ | $\lvert x\rvert > 1$ で $1/\operatorname{hypot}(x, 1)$ |
| `acosh` | $1/\sqrt{(x - 1)(x + 1)}$ | $x > 2$ で $1/(\sqrt{x - 1}\,\sqrt{x + 1})$ |
| `hypot(a, b)` | $(u/n,\ v/n)$、$u = a/m$、$v = b/m$、$n = \operatorname{hypot}(u, v)$ | $m$ が 0 か無限大なら $(a/h,\ b/h)$、$h = \operatorname{hypot}(a, b)$。原点で $(0, 0)$ |
| `atan2(a, b)` | $(v,\ -u)/((u^2 + v^2)\,m)$、$u = a/m$、$v = b/m$ | 原点と、片方だけが無限大の点で $(0, 0)$ |

ここで $m = \max(|a|, |b|)$ である。
`tanh` の $s = 2e/(1 + e^2)$ は $\operatorname{sech}|x|$ に等しく、$e = e^{-|x|} \le 1$ なので打ち消しもあふれも起こさない。
`hypot` と `atan2` は引数を最大の大きさ $m$ で割ってから偏導関数を作るので、$a^2 + b^2$ があふれる範囲でも有限の値を返す。

切り替えは分岐ではなく、両方の式を評価し、base の値（最も内側の `f64` などの値）の比較から作ったマスクで `select` によって選ぶ。
選ばなかった式が無限大や NaN になっても、`select` は成分を選ぶだけで掛け算をしないので、結果には入らない。
`Lanes` ではレーン（lane、SIMD の 1 要素）ごとに選ぶので、同じ演算の中で lane ごとに別の式を使える。
比較は base の値で行うので、入れ子の型の外側の微分は選んだ式だけを微分し、切り替えの条件は微分しない。
`select` と比較は折れ点に当たらないので、テープは切り替えを数えない。
計算コストは両方の式の評価の和になる。

次のセルは `tanh`、`asinh`、`acosh` の導関数を `Dual::variable(x)` で求め、1 つの式（$1 - \tanh^2 x$、$1/\sqrt{x^2 + 1}$、$1/\sqrt{(x - 1)(x + 1)}$）と比べる。
入力は `tanh` の評価点 $x$（無次元）と、`asinh` と `acosh` の評価点 $x = 10^p$ の指数 $p$ である。
参照値は打ち消しもあふれも起こさない別の閉形式 $\operatorname{sech}^2 x = 4e^{-2|x|}/(1 + e^{-2|x|})^2$、$r/\sqrt{1 + r^2}$、$r/\sqrt{1 - r^2}$（$r = 1/x$）を、f64 の固有メソッドで評価した値である。
表は SciOxide の導関数の誤差を参照値の位置の ulp（隣り合う浮動小数点数の間隔）で、1 つの式の誤差を相対誤差で示す。
グラフは $x = 0.5, 1, \ldots, 40$ での $\tanh'$ の相対誤差を対数軸で描き、誤差が厳密に 0 の点は除いて、その数を 2 つ目の表に示す。

```rust
//| id: ad-regime-switch-derivatives
//| ref: ad-regime-switch-derivatives
//| title: 領域で式を切り替える導関数と 1 つの式の比較
//| run: reactive
//| crates: [scioxide-ad, scioxide-core]
//| inputs:
//|   tanh_x: {"type":"range","label":"tanh の評価点 x","description":"x が大きいほど 1 − tanh²x の打ち消しが強くなる（無次元）。","min":0.5,"max":40,"step":0.5,"value":20}
//|   exponent: {"type":"range","label":"asinh と acosh の評価点の指数 p（x = 10^p）","description":"p > 154 では x² が f64 の範囲を超える。","min":1,"max":300,"step":1,"value":200}
//| cases:
//|   - {"id":"moderate","label":"x = 2、p = 10","description":"どちらの式も正しい値を返す。","inputs":{"tanh_x":2,"exponent":10}}
//|   - {"id":"cancellation-onset","label":"x = 10、p = 150","description":"1 − tanh²x の相対誤差が 10⁻⁸ 程度に増え、x² はまだ有限。","inputs":{"tanh_x":10,"exponent":150}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"derivatives","path":"/rows/0/2","approx":{"value":1.6993417021166355e-17,"rtol":1e-14}}
//|       - {"artifact":"derivatives","path":"/rows/0/5","range":{"max":4}}
//|       - {"artifact":"derivatives","path":"/rows/0/6","approx":{"value":1,"atol":1e-15}}
//|       - {"artifact":"derivatives","path":"/rows/1/2","approx":{"value":1e-200,"rtol":1e-14}}
//|       - {"artifact":"derivatives","path":"/rows/1/6","approx":{"value":1,"atol":1e-15}}
//|       - {"artifact":"derivatives","path":"/rows/2/5","range":{"max":4}}
//|       - {"artifact":"excluded","path":"/rows/0/0","range":{"min":20}}
//|   - case: moderate
//|     expect:
//|       - {"artifact":"derivatives","path":"/rows/0/5","range":{"max":4}}
//|       - {"artifact":"derivatives","path":"/rows/0/6","range":{"max":1e-15}}
//|       - {"artifact":"derivatives","path":"/rows/1/6","range":{"max":1e-15}}
//|   - case: cancellation-onset
//|     expect:
//|       - {"artifact":"derivatives","path":"/rows/0/5","range":{"max":4}}
//|       - {"artifact":"derivatives","path":"/rows/0/6","range":{"min":1e-10,"max":1e-6}}
//|       - {"artifact":"derivatives","path":"/rows/1/6","range":{"max":1e-15}}
use scioxide_ad::{Dual, Real};
use scioxide_core::RealScalar;

// SciOxide の導関数: 接ベクトル 1 の二重数を通す。
let derivative = |f: fn(Dual<f64>) -> Dual<f64>, x: f64| f(Dual::variable(x)).derivative();
// 参照値 r の位置での ulp。
let ulp = |r: f64| RealScalar::next_after(r.abs(), f64::INFINITY) - r.abs();
// 参照値（f64 の固有メソッド）: sech²x = 4e^{−2|x|}/(1 + e^{−2|x|})²。
let sech2 = |x: f64| {
    let e = (-2.0 * x.abs()).exp();
    4.0 * e / ((1.0 + e) * (1.0 + e))
};
// 1 つの式（SciOxide の初等関数 RealScalar で評価する）。
let one_minus_tanh2 = |x: f64| 1.0 - RealScalar::tanh(x) * RealScalar::tanh(x);

let big = format!("1e{}", exponent as i32)
    .parse::<f64>()
    .map_err(|e| e.to_string())?;
let r = 1.0 / big;
let cases: [(&str, f64, f64, f64, f64); 3] = [
    (
        "tanh",
        tanh_x,
        derivative(|v| v.tanh(), tanh_x),
        one_minus_tanh2(tanh_x),
        sech2(tanh_x),

        derivative(|v| v.acosh(), big),

    .iter()
    .map(|&(name, x, ad, single, reference)| {

        let single_relative = (single - reference).abs() / reference;
        (name, x, ad, single, reference, ad_ulps, single_relative)
    })
    .collect();

let columns = serde_json::json!([
    { "key": "0", "label": "関数" },
    { "key": "1", "label": "評価点 x [-]", "type": "number", "format": sci3 },
    { "key": "2", "label": "SciOxide（Dual）[-]", "type": "number", "format": digits },
    { "key": "3", "label": "1 つの式 [-]", "type": "number", "format": digits },
    { "key": "4", "label": "参照値 [-]", "type": "number", "format": digits },
    { "key": "5", "label": "SciOxide の誤差 [ulp]", "type": "number", "format": fixed1 },

// x = 0.5, 1, …, 40 での tanh′ の相対誤差。誤差 0 の点は対数軸に描けないので数える。
let (mut scioxide, mut single, mut zeros) = (Vec::new(), Vec::new(), (0_u32, 0_u32));
for step in 1..=80 {
    let x = 0.5 * f64::from(step);
    let reference = sech2(x);
    let errors = [
        (derivative(|v| v.tanh(), x) - reference).abs() / reference,
        (one_minus_tanh2(x) - reference).abs() / reference,
```

既定の $x = 20$ では、$\tanh x$ が 1 に丸められるので、1 つの式 $1 - \tanh^2 x$ は 0 を返し、相対誤差は 1 になる。
SciOxide の導関数は切り替えた後の式 $s^2$ で計算され、参照値 $1.6993417021166355 \times 10^{-17}$ と一致する（0 ulp）。
$p = 200$ の `asinh` と `acosh` では、1 つの式は $x^2$ が無限大にあふれて 0 を返し、SciOxide は参照値どおり $10^{-200}$ を返す。

グラフでは、1 つの式の相対誤差が $x = 5$ で $3.0 \times 10^{-13}$、$x = 10$ で $1.1 \times 10^{-8}$、$x = 15$ で $1.7 \times 10^{-4}$ と増え、$x \ge 19.5$ では 1 に達する。
$1 - \tanh^2 x$ の絶対誤差は $\varepsilon$ 程度のまま、真の値 $\approx 4e^{-2x}$ が小さくなるので、相対誤差は $\varepsilon e^{2x}/4$ 程度に増える。
SciOxide の相対誤差は全域で $5 \times 10^{-16}$ 以下で、80 点のうち 37 点では厳密に 0 である。
$x = 1$ の切り替えの前後でも誤差は増えない。

$x = 2$、$p = 10$ の場合はどちらの式も正しく、SciOxide の `tanh` の誤差は 2 ulp、1 つの式の相対誤差は $3.9 \times 10^{-16}$ である。
$x = 10$、$p = 150$ の場合は、1 つの式の $\tanh'$ の相対誤差が $1.1 \times 10^{-8}$ に増えるが、$x^2 = 10^{300}$ はまだ有限なので、`asinh` と `acosh` の 1 つの式は正しい値を返す。

## 安定変換の導関数

`softplus` から `tan_degrees` までの 14 個の安定変換（定義は[初等関数と安定変換](../../../scioxide-core/algorithms/stable-transforms/)）は、値と 2 階までの導関数を組 $[f(x), f'(x), f''(x)]$ として与える規則で実装されている。
値は `scioxide_core` の安定変換のカーネルから取り、カーネルがエラーを返す点（非有限な引数や定義域の外）では NaN になる。
数値型の演算はエラーを返さないので、`scioxide_core` の関数が `Result` で返す失敗を NaN で表す。
1 階と 2 階の導関数は変換ごとに用意した式を `f64` で評価し、出力の型に 1 回だけ丸める。

導関数の式も打ち消しとあふれを避けて選ばれている。
$\sigma'(x) = e^{-|x|}/(1 + e^{-|x|})^2$ は $x$ の符号によらずあふれない。
$\sigma''(x) = \sigma'(x)(1 - 2\sigma(x))$ は $1 - 2\sigma(x) = -\tanh(x/2)$ と書き換えて、0 の近くの打ち消しを避ける。
`exprel` の導関数は $|x| < 2$ で級数 $\sum_k x^k/(k!\,(k + 2))$ と $\sum_k x^k/(k!\,(k + 3))$ を $k = 24$ まで足し、`sinc` と `sincpi` の導関数は $|x| \ge 1$（`sincpi` は $|\pi x| \ge 1$）で二倍長の補正付きの演算を使い、積の丸めの残差を明示的な融合積和で求める。
融合積和はハードウェアの FMA の有無によらず同じ値を返すので、この導関数も FMA の有無によらない。

組 $[f, f', f'']$ を受け取る規則は[スカラー関数の微分規則](../custom-primitives/)の `map_scalar` と同じ仕組みなので、`Dual`、`MultiDual`、`Var`、`Var<Dual>`、`Dual<Var>`、`Dual<Dual>` で総次数（入れ子の各段で微分した階数の和）2 まで正確である。
`Jet` は残りの 11 個の変換を Taylor 係数の漸化式で計算し、`exprel`、`sinc`、`sincpi` だけは $c_2$ より上の係数が NaN になる（[Taylor ジェットと高階の係数](../taylor-jets/)）。

二項の安定変換 `logaddexp`、`xlogy`、`xlog1py`、`powm1` も値を `scioxide_core` のカーネルから取り、エラーの点では NaN になる。
そのため IEEE の演算なら極限を返す点でも NaN になる（`powm1(0, y < 0)`、`powm1(∞, 0)`、`logaddexp(∞, ∞)`）。
偏導関数は上の表の局所規則として `Primal` の演算で評価する。
`xlogy` と `xlog1py` は $x = 0$ の直線上で 0 なので、$x = 0$ かつ $y = 0$（`xlog1py` では $y = -1$）の $y$ についての偏導関数を $0/0$ ではなく 0 にする。
`powf` の底についての偏導関数は $y\,x^{y-1}$ を $y\,(x^y/x)$ として計算し、$y - 1$ の丸めが $\lvert\ln x\rvert$ 倍に広がるのを避ける。
`logaddexp` の偏導関数は $x - y$ の丸め誤差を TwoSum で求めて補正する。

## 導関数の精度

`scioxide-ad` の精度の保証は次のとおりである。
「$N$ ulp 以内」は、高い精度で計算した参照値との差が $N$ ulp 以下であることを試験で確かめた仕様で、個々の計算の誤差の証明ではない。

| 対象 | 仕様 |
|---|---|
| 値 | `scioxide_core` の初等関数の精度を保つ。lane の 8 つのカーネル（`exp`、`exp_m1`、`ln`、`ln_1p`、`sin`、`cos`、`tanh`、`powf`）は 4 ulp 以内でスカラーの関数と最後の桁が違いうる |
| 単項関数の 1 階の偏導関数 | 64 ulp 以内。境界付近の点の `log10` と `tanh` は 6 ulp、定数倍の `log2`、`log10`、`exp2` は 2 ulp |
| 安定変換の 1 階と 2 階の導関数 | 64 ulp 以内 |
| 二項関数の 1 階の偏導関数 | 64 ulp 以内 |
| 二項関数の 2 階の偏導関数（入れ子による） | 256 ulp 以内 |

二項関数の仕様は、引数、値、偏導関数がどれも 0 か、大きさが $[\sqrt{\text{MIN\_POSITIVE}}, \sqrt{\text{MAX}}]$（`f64` で約 $[1.5 \times 10^{-154}, 1.3 \times 10^{154}]$）にある点に限られる。
その外では、偏導関数の式を IEEE の演算でそのまま評価するので、途中の値があふれたりアンダーフローしたりすることがある。
`hypot` と `atan2` の偏導関数のような個別の式を除き、数値型は範囲の調整（スケーリング）をせずに評価する。
値の精度の保証の一般論は[初等関数と安定変換](../../../scioxide-core/algorithms/stable-transforms/)、lane のカーネルは[数値型・lane・汎用コード](../number-types-and-lanes/)で扱う。

## まとめ

初等関数の偏導関数は値 $y$ や商 $q$ を再利用し、打ち消しとあふれを避ける式で評価され、ラッパー型の値は包まない型で同じ関数を評価した値とビットで一致する。
`atan`、`tanh`、`asinh`、`acosh`、`hypot`、`atan2` は 2 つの式を評価して `select` で選ぶので、1 つの式が打ち消しやあふれで 0 を返す領域でも相対精度を保ち、計算コストは 2 つの式の評価の和になる。
14 個の安定変換は値と 2 階までの導関数の組を与える規則で実装され、`Dual`、`MultiDual`、`Var`、`Var<Dual>`、`Dual<Var>`、`Dual<Dual>` で総次数 2 まで正確である。
1 階の偏導関数は 64 ulp、二項関数の入れ子による 2 階の偏導関数は 256 ulp の仕様を持つが、二項関数の仕様は引数・値・偏導関数が $[\sqrt{\text{MIN\_POSITIVE}}, \sqrt{\text{MAX}}]$ に収まる点に限られるので、極端な尺度の入力は事前に無次元化する。
