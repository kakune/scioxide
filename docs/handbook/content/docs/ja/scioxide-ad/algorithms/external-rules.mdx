自動微分は関数を `Real` の演算で書けることを前提にしている。
固有値の解法のように、成分が `f64` などの浮動小数点数の型の行列だけを受け付ける計算は、`Dual` や `Var` を通せないので、そのままでは微分できない。
反復で解を求める計算では、反復の過程を記録して微分するより、解が満たす条件から導いた導関数を使いたいこともある。
`ExternalRule` は、このようなベクトル関数の値と、ヤコビ行列とベクトルの積を呼び出し側が与える規則で、`Var::external` がそれをテープの 1 つの文（statement、テープの 1 記録）として記録する。
この文を呼び出し文（call statement）と呼ぶ。
このページは規則のメソッドの約束、呼び出し文の記録と作業領域の確保、各変換がどのメソッドを使うかを説明し、対称行列の最小固有値を例に確かめる。
すべての数値型で使えるスカラー関数の規則 `map_scalar`・`combine` と、方法の選び方は[スカラー関数の微分規則](../custom-primitives/)、テープの記録と走査は[逆モードとテープ](../reverse-mode-and-replay/)で扱う。

## ExternalRule の 3 つのメソッド

`ExternalRule<V>` は、ベクトル関数 $y = f(x)$（$x \in \mathbb{R}^n$、$y \in \mathbb{R}^m$）をテープの 1 つの呼び出し文として扱うための規則である。
ヤコビ行列を $J = \partial f/\partial x \in \mathbb{R}^{m \times n}$ とすると、規則は次の 3 つのメソッドを持つ。

| メソッド | 計算 | 書き方 |
|---|---|---|
| `evaluate(inputs, outputs)` | $y = f(x)$ | `outputs` に書く |
| `pullback(inputs, outputs, output_adjoints, input_adjoints)` | $\bar x \mathrel{+}= J^{\mathsf T} \bar y$ | `input_adjoints` に足す |
| `pushforward(inputs, outputs, input_tangents, output_tangents)` | $\dot y = J \dot x$ | `output_tangents` に書く。既定は `CapabilityUnavailable` を返す |

`pullback` が計算する $J^{\mathsf T} \bar y$ を引き戻し（pullback）、`pushforward` が計算する $J \dot x$ を押し出し（pushforward）と呼ぶ。
$\bar y$ は出力の随伴（最終の出力の $y$ についての偏導関数）、$\bar x$ は入力の随伴、$\dot x$ は入力の接ベクトル（入力を動かす方向）、$\dot y$ は出力の接ベクトルである。

規則は入力の純粋な関数でなければならない。
テープは規則の `Arc` と、呼び出しの入力と出力の値を保存し、積を計算するたびにそれを規則に渡す。
規則は呼び出しごとの状態を持たないので、引き戻しに必要な中間量は渡された入力と出力から計算し直すか、出力に含める。
`V` について汎用に書いた規則（`impl<V: TapeValue> ExternalRule<V> for …`）は、`Tape<Dual<S>>` でも使え、引き戻しを二重数で評価してヘッセ行列・ベクトル積を与える。
`f64` の関数しか呼べない規則は `ExternalRule<f64>` だけを実装し、`Tape<f64>` で使う。

## Var::external による記録

`Var::external(&rule, inputs, outputs)` は、`rule: &Arc<dyn ExternalRule<V>>` を入力に適用し、結果を `outputs` に書く。
入力がすべて受動的（テープに記録されていない定数）なら、評価だけを行い（評価用の作業領域は呼び出しごとに確保する）、出力は受動的になる。
そうでなければ、1 つの呼び出し文を記録し、入力と出力の値を保存する。
テープは文を 64 ビットのワード（statement word）の列で表し、呼び出し文は見出しのワード、入力ごとのワード、見出しの写し、出力ごとのワードからなる。
同じ関数を記録したことのあるテープでは、記録で領域を確保しない。
`evaluate` のエラーはそのまま返し、最初の記録で評価用の作業領域を確保できなければ `AllocationFailure` を返す。
2 つの記録の値を混ぜると、出力は NaN になり、変換は `InvalidInput`（`Inconsistent`）で失敗する。
規則の中の計算は記録されないので、その中で起きた折れ点は数えられない。

## 引き戻しと押し出しを使う積

逆走査（記録を末尾から先頭へたどり、随伴を足す走査）は呼び出し文で `pullback` を呼ぶので、`gradient_into`、`vjp_into`、逆走査の `jacobian_into`、`JacobianOperator` の `apply_adjoint_into` は引き戻しだけで動く。
接ベクトルの走査（記録を先頭から末尾へたどり、接ベクトルを伝える走査）は `pushforward` を呼ぶので、`jvp_into`、接ベクトルの走査を使う `jacobian_into`（`JacobianMode::Forward`、または出力が入力以上の数の `Auto`）、`sparse_jacobian_into`、`JacobianOperator` の `apply_into` には押し出しが要る。
押し出しのない規則でこれらを呼ぶと、`CapabilityUnavailable` を返す。

## 対称行列の最小固有値

$2 \times 2$ の実対称行列

$$
S = \begin{pmatrix} a & b \\ b & c \end{pmatrix}, \qquad
\lambda(a, b, c) = \frac{a + c}{2} - \sqrt{\Bigl(\frac{a - c}{2}\Bigr)^2 + b^2}
$$

の最小固有値 $\lambda$ を、scioxide-linalg の `HermitianEigenDecomposition`（[固有値問題と Schur 分解](../../../scioxide-linalg/algorithms/eigenproblems/)）で計算し、`ExternalRule` でラップする。
この解法は成分が `f64` などの `NumericScalar` の行列だけを受け付け、`Dual` や `Var` を通せないので、汎用関数では書けない。
scioxide-linalg の型を直接使うので、自分のコードでは scioxide-linalg も `Cargo.toml` に加える。
最小固有値が単純（重複しない）なら、単位固有ベクトルを $v$ として、Hellmann–Feynman の定理から

$$
\mathrm{d}\lambda = v^{\mathsf T}\,\mathrm{d}S\,v, \qquad
\Bigl(\frac{\partial\lambda}{\partial a}, \frac{\partial\lambda}{\partial b}, \frac{\partial\lambda}{\partial c}\Bigr) = (v_0^2,\ 2 v_0 v_1,\ v_1^2)
$$

が成り立つ。
$b$ は $S$ の 2 つの非対角成分に現れるので、偏導関数に係数 2 が付く。
引き戻しは $\bar x \mathrel{+}= \bar y\,(v_0^2, 2v_0v_1, v_1^2)$、押し出しは $\dot y = v_0^2 \dot a + 2v_0v_1 \dot b + v_1^2 \dot c$ である。
規則は呼び出しごとの状態を持たないので、どちらも入力から固有ベクトルを計算し直す。
$v_0^2 + v_1^2 = 1$ なので、$\partial\lambda/\partial a + \partial\lambda/\partial c = 1$ はどの点でも成り立つ（$\lambda(S + tI) = \lambda(S) + t$）。

次のブロックは、続く 2 つのセルが使う定義である。
`lowest` は scioxide-linalg で $S$ の固有値と固有ベクトルを求め、$\lambda$ と偏導関数 $(v_0^2, 2v_0v_1, v_1^2)$ を返す。
`Lowest` は引き戻しだけを持つ規則、`LowestWithTangent` は押し出しも持つ規則である。
`closed_form` は上の閉形式を数値型 `R` の演算で書いた検算用の関数である。

```rust
//| id: ad-eigenvalue-rules
//| kind: definitions
//| title: 最小固有値の外部の規則と閉形式
//| crates: [scioxide-ad, scioxide-core, scioxide-linalg]
use scioxide_ad::{ExternalRule, Real};
use scioxide_core::SciOxideError;
use scioxide_linalg::{HermitianEigenDecomposition, HermitianInput, Matrix};

/// S = [[a, b], [b, c]] の最小固有値 λ と、単位固有ベクトル v から作る
/// ∂λ/∂(a, b, c) = (v₀², 2v₀v₁, v₁²)（Hellmann–Feynman の定理）。固有値は scioxide-linalg で求める。
pub(crate) fn lowest(s: &[f64]) -> Result<(f64, [f64; 3]), SciOxideError> {
    let matrix = Matrix::from_vec(2, 2, vec![s[0], s[1], s[1], s[2]])?;
    let eigen = HermitianEigenDecomposition::decompose(&matrix, HermitianInput::Exact)?;
    let vectors = eigen.eigenvectors().view();
    let v = [vectors.get(0, 0)?, vectors.get(1, 0)?];
    Ok((
        eigen.eigenvalues()[0],
        [v[0] * v[0], 2.0 * v[0] * v[1], v[1] * v[1]],
    ))
}

/// y = λ(S)。引き戻しだけを持つ規則。
pub(crate) struct Lowest;

impl ExternalRule<f64> for Lowest {
    fn evaluate(&self, s: &[f64], y: &mut [f64]) -> Result<(), SciOxideError> {
        y[0] = lowest(s)?.0;
        Ok(())
    }
    fn pullback(&self, s: &[f64], _: &[f64], w: &[f64], g: &mut [f64]) -> Result<(), SciOxideError> {
        // 随伴には足し込む: x̄ += Jᵀ ȳ。
        for (target, d) in g.iter_mut().zip(lowest(s)?.1) {
            *target += w[0] * d;
        }
        Ok(())
    }
}

/// 同じ規則に押し出し ẏ = J ẋ = vᵀ Ṡ v を加えたもの。
pub(crate) struct LowestWithTangent;

impl ExternalRule<f64> for LowestWithTangent {
    fn evaluate(&self, s: &[f64], y: &mut [f64]) -> Result<(), SciOxideError> {
        Lowest.evaluate(s, y)
    }
    fn pullback(&self, s: &[f64], y: &[f64], w: &[f64], g: &mut [f64]) -> Result<(), SciOxideError> {
        Lowest.pullback(s, y, w, g)
    }
    fn pushforward(
        &self,
        s: &[f64],
        _: &[f64],
        t: &[f64],
        out: &mut [f64],
    ) -> Result<(), SciOxideError> {
        // 出力の接ベクトルは上書きする。
        out[0] = lowest(s)?.1.iter().zip(t).map(|(d, t)| d * t).sum();
        Ok(())
    }
}

/// 閉形式 λ = (a + c)/2 − hypot((a − c)/2, b)。数値型 R について書く。
pub(crate) fn closed_form<R: Real>(s: &[R]) -> R {
    (s[0] + s[2]) * 0.5 - ((s[0] - s[2]) * 0.5).hypot(s[1])
}
```

次のセルは引き戻しだけを持つ規則 `Lowest` で包んだ $\lambda$ の値と勾配を、閉形式をテープで微分した値と比べる。
入力は $a$、$b$、$c$（無次元）である。
勾配はどちらも `Tape::gradient_into` で求める。
1 つ目の表は $\lambda$、勾配の 3 成分、$\partial\lambda/\partial a + \partial\lambda/\partial c$ を示し、2 つ目の表は各記録で数えた折れ点の数を `TapeReport::kinks()` で示す。

```rust
//| id: ad-external-eigenvalue
//| ref: ad-external-eigenvalue
//| title: ExternalRule で包んだ対称行列の最小固有値の勾配
//| run: reactive
//| crates: [scioxide-ad, scioxide-core]
//| uses: [ad-eigenvalue-rules]
//| inputs:
//|   a: {"type":"range","label":"対角成分 a","min":-2,"max":2,"step":0.25,"value":1}
//|   b: {"type":"range","label":"非対角成分 b","min":-1,"max":1,"step":0.25,"value":0.5}
//|   c: {"type":"range","label":"対角成分 c","min":-2,"max":2,"step":0.25,"value":-0.5}
//| cases:
//|   - {"id":"degenerate","label":"a = c = 0.5、b = 0","description":"最小固有値が重複し、λ は微分できない点。","inputs":{"a":0.5,"b":0,"c":0.5}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"gradients","path":"/rows/0/1","approx":{"value":-0.6513878188659973,"rtol":1e-14}}
//|       - {"artifact":"gradients","path":"/rows/1/3","range":{"max":1e-14}}
//|       - {"artifact":"gradients","path":"/rows/2/3","range":{"max":1e-14}}
//|       - {"artifact":"gradients","path":"/rows/3/3","range":{"max":1e-14}}
//|       - {"artifact":"kinks","path":"/rows/0/1","equals":0}
//|       - {"artifact":"kinks","path":"/rows/1/1","equals":0}
//|   - case: degenerate
//|     expect:
//|       - {"artifact":"gradients","path":"/rows/1/1","approx":{"value":1,"atol":1e-15}}
//|       - {"artifact":"gradients","path":"/rows/1/2","approx":{"value":0.5,"atol":1e-15}}
//|       - {"artifact":"gradients","path":"/rows/3/2","approx":{"value":0.5,"atol":1e-15}}
//|       - {"artifact":"gradients","path":"/rows/4/1","approx":{"value":1,"atol":1e-14}}
//|       - {"artifact":"gradients","path":"/rows/4/2","approx":{"value":1,"atol":1e-14}}
//|       - {"artifact":"kinks","path":"/rows/0/1","equals":0}
//|       - {"artifact":"kinks","path":"/rows/1/1","equals":1}
use scioxide_ad::{ExternalRule, Real, Tape, TapeOptions, Var};
use scioxide_core::ExecutionContext;
use std::sync::Arc;

let cx = ExecutionContext::sequential();
let rule: Arc<dyn ExternalRule<f64>> = Arc::new(Lowest);
let point = [a, b, c];
// 外部の規則の勾配と、その記録の折れ点の数。
let mut external = [0.0; 3];
let mut tape = Tape::<f64>::new(TapeOptions::new());
tape.gradient_into(
    |s| {
        let mut y = [Var::constant(0.0)];
        Var::external(&rule, s, &mut y)?;
        Ok(y[0])
    },
    &point,
    &mut external,
    cx,
)
.map_err(|e| e.to_string())?;
let external_kinks = tape.report().kinks();
// 検算: 閉形式をテープで微分した勾配。
let mut direct = [0.0; 3];
let mut closed_tape = Tape::<f64>::new(TapeOptions::new());
closed_tape
    .gradient_into(|s| Ok(closed_form(s)), &point, &mut direct, cx)
    .map_err(|e| e.to_string())?;
let closed_kinks = closed_tape.report().kinks();

let (value, _) = lowest(&point).map_err(|e| e.to_string())?;
let (e, d) = (external, direct);
let gradients: Vec<_> = [
    ("λ", value, closed_form(&point)),
    ("∂λ/∂a", e[0], d[0]),
    ("∂λ/∂b", e[1], d[1]),
    ("∂λ/∂c", e[2], d[2]),
    ("∂λ/∂a + ∂λ/∂c", e[0] + e[2], d[0] + d[2]),
]
.iter()
.map(|&(name, rule_value, closed)| (name, rule_value, closed, (rule_value - closed).abs()))
.collect();

let digits = serde_json::json!({ "significantDigits": 16 });
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let gradient_columns = serde_json::json!([
    { "key": "0", "label": "量" },
    { "key": "1", "label": "外部の規則 [-]", "type": "number", "format": digits },
    { "key": "2", "label": "閉形式をテープで微分 [-]", "type": "number", "format": digits },
    { "key": "3", "label": "差 [-]", "type": "number", "format": sci2 }
]);
emit_table_with_columns!(
    gradient_columns,
    gradients,
    metadata = serde_json::json!({ "id": "gradients" })
);
emit_table_with_columns!(
    ["記録", "折れ点の数 [回]"],
    vec![("外部の規則", external_kinks), ("閉形式", closed_kinks)],
    metadata = serde_json::json!({ "id": "kinks" })
);
```

既定の $(a, b, c) = (1, 0.5, -0.5)$ では、外部の規則の $\lambda = -0.6513878188659973$ は閉形式と一致し、勾配の差は $3.3 \times 10^{-16}$ 以下である。
$\partial\lambda/\partial a + \partial\lambda/\partial c$ も、どちらの方法でも丸めの範囲で 1 になる。
どちらの記録も折れ点を数えない。

$a = c = 0.5$、$b = 0$ では最小固有値が重複し、$\lambda$ はこの点で微分できない。
閉形式は `hypot` の原点の折れ点で偏導関数 $(0, 0)$ を使い、勾配 $(0.5, 0, 0.5)$ を返す。
外部の規則は、解法が返した固有ベクトル $v = (1, 0)$ から $(1, 0, 0)$ を返す。
$\lambda$ は $S$ について局所 Lipschitz で、この点での Clarke の一般化勾配は $\operatorname{conv}\{(v_0^2, 2v_0v_1, v_1^2) : \|v\| = 1\}$ なので、2 つの値はどちらもその元だが、互いに異なる。
テープは閉形式の `hypot` の折れ点を 1 回数えるが、外部の規則の中の固有値の重複は数えない。

次のセルは `Tape::linearize` で記録した 1 つの線形化で、引き戻しを使う積（`vjp_into`、`JacobianMode::Auto` の `jacobian_into`）と押し出しを使う積（`jvp_into`）を呼ぶ。
点は既定の $(a, b, c) = (1, 0.5, -0.5)$ に固定し、入力は押し出しを実装した規則 `LowestWithTangent` を使うかどうかである。
`jvp_into` の方向は $(\dot a, \dot b, \dot c) = (1, 0, 1)$ で、上の恒等式から結果は 1 になるはずである。
2 つ目の表は記録のワード数と、受動的な入力で `Var::external` を呼んだときの出力が能動的（テープに記録された値）かどうかを示す。

```rust
//| id: ad-external-products
//| ref: ad-external-products
//| title: 押し出しのない外部の規則と線形化の積
//| run: reactive
//| crates: [scioxide-ad, scioxide-core]
//| uses: [ad-eigenvalue-rules]
//| inputs:
//|   tangent: {"type":"checkbox","label":"押し出し（pushforward）を実装した規則を使う","description":"使わない規則では jvp_into が CapabilityUnavailable になる。","value":false}
//| cases:
//|   - {"id":"with-pushforward","label":"押し出しあり","description":"jvp_into も成功し、恒等式どおり 1 を返す。","inputs":{"tangent":true}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"products","path":"/rows/0/2","equals":"成功"}
//|       - {"artifact":"products","path":"/rows/0/1","approx":{"value":0.08397485283107817,"rtol":1e-13}}
//|       - {"artifact":"products","path":"/rows/1/1","approx":{"value":-0.5547001962252293,"rtol":1e-13}}
//|       - {"artifact":"products","path":"/rows/2/1","equals":null}
//|       - {"artifact":"products","path":"/rows/2/2","equals":"CapabilityUnavailable（external rule pushforward）"}
//|       - {"artifact":"recording","path":"/rows/0/0","equals":10}
//|       - {"artifact":"recording","path":"/rows/0/1","equals":"受動的"}
//|   - case: with-pushforward
//|     expect:
//|       - {"artifact":"products","path":"/rows/2/1","approx":{"value":1,"atol":1e-14}}
//|       - {"artifact":"products","path":"/rows/2/2","equals":"成功"}
use scioxide_ad::{ExternalRule, Real, Tape, TapeOptions, Var};
use scioxide_core::{Capability, ExecutionContext, SciOxideErrorKind, SciOxideErrorView};
use std::sync::Arc;

let rule: Arc<dyn ExternalRule<f64>> = if tangent {
    Arc::new(LowestWithTangent)
} else {
    Arc::new(Lowest)
};
// 点は既定の (a, b, c) = (1, 0.5, −0.5)。
let point = [1.0, 0.5, -0.5];
// 1 つの線形化で、引き戻しを使う積と押し出しを使う積を呼ぶ。
let cx = ExecutionContext::sequential();
let mut tape = Tape::<f64>::new(TapeOptions::new());
let mut linear = tape
    .linearize(
        |s, y| {
            let mut out = [Var::constant(0.0)];
            Var::external(&rule, s, &mut out)?;
            y.push(out[0]);
            Ok(())
        },
        &point,
        cx,
    )
    .map_err(|e| e.to_string())?;
let mut reverse = [0.0; 3];
let vjp = linear
    .vjp_into(&[1.0], &mut reverse, cx)
    .map(|()| reverse[0]);
let mut jacobian = [0.0; 3];
let full = linear
    .jacobian_into(&mut jacobian, cx)
    .map(|()| jacobian[1]);
let mut forward = [0.0];
let jvp = linear
    .jvp_into(&[1.0, 0.0, 1.0], &mut forward, cx)
    .map(|()| forward[0]);
let products: Vec<_> = [
    ("vjp_into(ȳ = 1) の ∂λ/∂a", vjp),
    ("jacobian_into（Auto、逆走査）の ∂λ/∂b", full),
    ("jvp_into(ẋ = (1, 0, 1))", jvp),
]
.into_iter()
.map(|(product, result)| match result {
    Ok(value) => (product, Some(value), "成功".to_string()),
    // エラーは kind() と view() で分類する。
    Err(error) => match (error.kind(), error.view()) {
        (
            SciOxideErrorKind::CapabilityUnavailable,
            SciOxideErrorView::CapabilityUnavailable {
                capability: Capability::Operation(operation),
            },
        ) => (
            product,
            None,
            format!("CapabilityUnavailable（{operation}）"),
        ),
        _ => (product, None, error.to_string()),
    },
})
.collect();
let words = tape.report().words();

// 受動的な入力では評価だけを行い、出力は受動的になる。
let constants = point.map(|v| Var::constant(v));
let mut passive = [Var::constant(0.0)];
Var::external(&rule, &constants, &mut passive).map_err(|e| e.to_string())?;
let activity = if passive[0].is_active() {
    "能動的"
} else {
    "受動的"
};

let digits = serde_json::json!({ "significantDigits": 16 });
let product_columns = serde_json::json!([
    { "key": "0", "label": "積" },
    { "key": "1", "label": "結果 [-]", "type": "number", "format": digits, "nullText": "—" },
    { "key": "2", "label": "状態" }
]);
emit_table_with_columns!(
    product_columns,
    products,
    metadata = serde_json::json!({ "id": "products" })
);
emit_table_with_columns!(
    ["記録のワード数 [ワード]", "受動的な入力での出力"],
    vec![(words, activity)],
    metadata = serde_json::json!({ "id": "recording" })
);
```

引き戻しだけの規則では、`vjp_into` と `jacobian_into` が成功する。
出力が 1 個で入力の 3 個より少ないので、`JacobianMode::Auto` は逆走査を選ぶ。
`jvp_into` は `CapabilityUnavailable`（`external rule pushforward`）を返す。
押し出しを実装した規則では `jvp_into` も成功し、恒等式どおり $1.0000000000000002$（1 と 1 ulp の差）を返す。
記録のワード数 10 は、定数の枠 1、入力 3、呼び出し文 5（見出し、引数 3、見出しの写し）、出力 1 の和で、`Var::external` が 1 つの呼び出し文として記録されたことを示す。
受動的な入力で呼んだ `Var::external` の出力は受動的である。

## まとめ

`Real` の演算で書けない外部の計算は、値・引き戻し・必要なら押し出しを持つ `ExternalRule` で包み、`Var::external` でテープの 1 つの呼び出し文として記録する。
規則は入力の純粋な関数として書き、引き戻しは入力の随伴に足し込み、押し出しは出力の接ベクトルを上書きする。
押し出しのない規則でも勾配、VJP、逆走査のヤコビ行列は求まるが、`jvp_into` などの接ベクトルの走査を使う積は `CapabilityUnavailable` を返す。
規則の中の計算は記録されないので、規則の中の折れ点や固有値の重複のような微分できない点はテープの折れ点の数に現れず、規則の導関数は閉形式や別の方法と比べて確かめる。
`V` について汎用に書いた規則は `Tape<Dual<S>>` でも使え、引き戻しを二重数で評価してヘッセ行列・ベクトル積を与える。
