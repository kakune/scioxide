非線形方程式 $F(y, p) = 0$ の解 $y$ は、パラメータ $p$ の関数として間接的に定まる。
解は Newton 法などの反復で求めることが多い。
反復の演算をそのまま微分すると、テープの記録は反復の回数に比例して伸び、導関数は反復をどこで打ち切ったかに依存する。
解が満たす方程式そのものを微分すれば、解の点での $F$ の偏導関数から、線形方程式を 1 つ解いて導関数が求まる。

このページは陰関数定理による解の微分と、それを数値型の階層ごとに適用する `implicit_solution_into`、近似解を受け入れたときの導関数の誤差を扱う。
途中で解く線形方程式の微分と `solve_into` のアルゴリズムは[線形系の解と分解の微分](../linear-solutions/)で説明する。
数値型の階層（`Real::LEVEL`）、1 つ下の階層の型 `Primal`、base の値は[数値型・lane・汎用コード](../number-types-and-lanes/)で定義している。
偏導関数から値を組み立てる `combine` は[スカラー関数の微分規則](../custom-primitives/)で説明する。

## 陰関数定理による解の微分

$F: \mathbb{R}^n \times \mathbb{R}^q \to \mathbb{R}^n$ が $(y^*, p)$ の近傍で連続微分可能で、$F(y^*, p) = 0$、$F_y = \partial F / \partial y$ が $(y^*, p)$ で正則なら、陰関数定理により $p$ の近傍で $F(y(p), p) = 0$ を満たす連続微分可能な解 $y(p)$ があり

$$
\frac{\partial y}{\partial p} = -F_y^{-1} F_p
$$

である。
接ベクトルは $F_y \dot y = -F_p \dot p$ を、余接は $F_y^\top \lambda = \bar y$ を解いて $\bar p = -F_p^\top \lambda$ とする。
どちらも $F_y$ かその転置の線形方程式を 1 つ解くだけで、$y^*$ をどの解法で求めたかに依存しない。
線形方程式 $AX = B$ は $F(X; A, B) = AX - B$、$F_y = A$ の場合で、このとき接ベクトルの式は線形系の解の微分 $\dot X = A^{-1}(\dot B - \dot A X)$ に一致する（[線形系の解と分解の微分](../linear-solutions/)）。
$F$ が 2 回連続微分可能なら、恒等式 $F(y(p), p) = 0$ をもう一度微分して、2 階の導関数も $F$ の 2 階の導関数と $F_y$ の線形方程式で表せる。

## `implicit_solution_into` と `Residual`

`Residual<S>` は残差 $F(y, p)$ を、`Mask = bool`（比較の結果が `bool` になる型）のすべての数値型に対して一度だけ書くトレイトである。
`residual<R: Real<S, Mask = bool>>(&self, solution, parameters, out)` は $n$ 個の値 $F(y, p)$ を `out` に書き、エラーはそのまま返す。

`implicit_solution_into(residual, solution, parameters, tolerance, out)` は、base の値で求めた解 `solution`（$n$ 個の `S`）と、導関数を持つパラメータ `parameters`（$q$ 個の `R`）から、導関数つきの解 $y(p)$ を `out` に書く。
解そのものは呼び出し側が Newton 法などで求めて渡し、この関数は $F = 0$ を解かない。
`out` の値は `solution` に等しく、導関数は渡した解の点で評価される。

導関数は数値型の階層ごとに、陰関数定理を再帰的に適用して作る。
`R` の階層（`Real::LEVEL`、`f64` は 0、`Var<f64>` と `Dual<f64>` は 1、`Var<Dual<f64>>` は 2）を $L$ とする。

1. $L = 0$ では、残差を 1 回評価し、$\|F(y, p)\|_2 \le \text{atol} + \text{rtol}\,\|y\|_2$（`ResidualTolerance`）を確かめて、`solution` をそのまま書く。
2. $L \ge 1$ では、パラメータの 1 つ下の階層（`R::Primal`）で同じ関数を呼び、1 つ下の階層の解を求める。
3. その解とパラメータに単位の接ベクトルを持たせた `Dual<R::Primal>` で残差を $n + q$ 回評価し、$F_y$ と $F_p$ の列を作る。
4. `solve_into` で $M = F_y^{-1} F_p$ を `R::Primal` の算術で解き、各成分を `R::combine` で値 $y_k$ と偏微分 $-M_{k,\cdot}$ から組み立てる。

手順 4 の `solve_into` は $F_y$ の base の値を部分ピボット選択つきの LU 分解で一度だけ分解し、その因子を $F_p$ の $q$ 列と、`R::Primal` が持つ導関数のすべての成分に使う。

`combine` は偏微分を 1 つ下の階層の算術で受け取るので、結果は入れ子の次数まで正確である。
そのため `Var<Dual<f64>>` による `hvp` と `hessian`、`Dual<Dual<f64>>` による 2 階の導関数も陰的な解を通して求まる。
テープ（`Var`）では、残差の評価はテープの外の `Dual` で行い、出力ごとに `combine` の文を 1 つだけ記録する。
`Jet` も使えるが、`combine` で組み立てるので $c_2$ 以降の係数は NaN になる（[Taylor ジェットと高階の係数](../taylor-jets/)）。
`Lanes` を含む型は `Mask = bool` を満たさないので使えない。

計算コストは階層ごとに、`Dual` での残差の評価 $n + q$ 回、$n \times n$ の $F_y$ の分解 1 回（約 $\tfrac{2}{3}n^3$ 回の浮動小数点演算）と $q$ 列の代入、$O(n(n + q))$ 個の値の確保である。
ほかに階層 0 で、許容誤差の検査のための残差の評価が 1 回ある。

エラーは次のとおりである。

- `out` の長さが `solution` と違えば `DimensionMismatch` を返す。
- 階層 0 で残差が許容誤差を満たさないか、残差か `solution` が有限でなければ、`InvalidInput`（引数 `solution`、`OutOfRange`）を返す。
  2 つのノルムは `hypot` で足すので、$10^{200}$ のような大きな解でもあふれない。
- 微分の階層で、$F_y$ の base の値の LU 分解のあるピボット（その列の残りの成分の絶対値の最大）が 0 か非有限なら、`Singular` を返す。
  階層 0 の普通の数の呼び出しは $F_y$ を作らないので、`Singular` を返さない。
  条件数は推定しないので、$F_y$ が特異に近いだけならエラーにならず、大きな導関数を返す。
- 微分の階層で $F_y$ や $F_p$ の大きさが `usize` に収まらなければ、残差を呼ぶ前に `SizeOverflow` を返す。
- 作業領域を確保できなければ `AllocationFailure` を返す。
- 残差のエラーはそのまま返る。

## 近似解を受け入れたときの誤差

許容誤差の中に入った近似解 $\tilde y$ は受け入れられ、導関数は $y^*$ ではなく $\tilde y$ で評価される。
$\tilde y - y^* \approx F_y^{-1} F(\tilde y, p)$ なので $\|\tilde y - y^*\| \lesssim \|F_y^{-1}\|\,\|F(\tilde y, p)\|$ である。
解の導関数 $D(y) = -F_y^{-1}F_p$ の $y$ についての Lipschitz 定数を $L_D$ とすると、導関数の誤差は一次の近似で

$$
\bigl\| D(\tilde y) - D(y^*) \bigr\| \lesssim L_D\,\|F_y^{-1}\|\,\|F(\tilde y, p)\|
$$

となる。
既定の `ResidualTolerance`（atol と rtol がどちらも $\sqrt{\varepsilon} \approx 1.5 \times 10^{-8}$）では、残差が $10^{-8}$ 程度の解も受け入れられ、導関数の誤差は $L_D\,\|F_y^{-1}\| \times 10^{-8}$ 程度になりうる（[許容誤差と残差の尺度化理論](../../../concepts/tolerances-and-residuals/)）。
導関数を丸めの水準で求めたいときは、残差が丸めの水準に下がるまで解き、許容誤差もその水準にする。

## Kepler 方程式の解の感度

楕円軌道の離心近点角 $E$ は平均近点角 $M$ と離心率 $e$ から Kepler 方程式 $F(E; M, e) = E - e \sin E - M = 0$ の解として定まる。
$E(M, e)$ の 1 階と 2 階の導関数を `implicit_solution_into` で求め、閉形式と比べる（[Kepler 方程式と離心率](../../../scioxide-rootfind/examples/kepler-equation/)と同じ $e = 0.6$、$M = 1.2$ rad が既定）。
$F_E = 1 - e\cos E \ge 1 - e > 0$ なので、解はただ 1 つで、陰関数定理がどこでも使える。

呼び出し側の解法は $F$ と $F_E$ を同じ `Residual` の `Dual` で評価する Newton 法 $E \leftarrow E - F/F_E$ で、$E_0 = \pi$ から $K$ 回反復する。
許容誤差は絶対値 atol だけ（rtol = 0）とし、`grad` と `hessian` の中で `implicit_solution_into` を呼ぶ。
`hessian` は `Var<Dual<f64>>` の上で方向ごとにヘッセ行列・ベクトル積を求める。

独立な検算として、二分法を 100 回行った参照解 $E^*$ で、$D = 1 - e \cos E^*$ による閉形式

$$
\frac{\partial E}{\partial M} = \frac{1}{D}, \quad
\frac{\partial E}{\partial e} = \frac{\sin E^*}{D}, \quad
\frac{\partial^2 E}{\partial M^2} = -\frac{e \sin E^*}{D^3}, \quad
\frac{\partial^2 E}{\partial M \partial e} = \frac{\cos E^* - e}{D^3}, \quad
\frac{\partial^2 E}{\partial e^2} = \frac{2 \sin E^* \cos E^*\, D - e \sin^3 E^*}{D^3}
$$

を並べる。
次のセルの入力は $e$、$M$、反復回数 $K$、atol である。
1 つ目の表は呼び出し側の解と残差、検査の結果を、2 つ目の表は導関数を示す。

```rust

//| ref: ad-implicit-solution
//| title: Kepler 方程式の解の感度を陰関数定理で求める
//| run: reactive
//| crates: [scioxide-ad, scioxide-core]
//| inputs:

//|   mean_anomaly: {"type":"range","label":"平均近点角 M [rad]","description":"0 から 2π の範囲。","min":0.1,"max":6.2,"step":0.1,"value":1.2}
//|   iterations: {"type":"range","label":"Newton 法の反復回数 K","description":"呼び出し側が E₀ = π から E を求める反復の回数。","min":0,"max":8,"step":1,"value":6}

//|   - {"id":"early","label":"K = 3","description":"残差が許容誤差を満たさず、InvalidInput になる。","inputs":{"iterations":3}}

//|   - case: default
//|     expect:
//|       - {"artifact":"solution","path":"/rows/0/4","equals":"受理"}
//|       - {"artifact":"derivatives","path":"/rows/0/1","approx":{"value":0.8863591446259845,"rtol":1e-14}}
//|       - {"artifact":"derivatives","path":"/rows/0/3","range":{"max":1e-13}}
//|       - {"artifact":"derivatives","path":"/rows/2/3","range":{"max":1e-13}}
//|       - {"artifact":"derivatives","path":"/rows/4/3","range":{"max":1e-13}}
//|   - case: early
//|     expect:
//|       - {"artifact":"solution","path":"/rows/0/4","equals":"InvalidInput（引数 solution、OutOfRange）"}
//|       - {"artifact":"derivatives","path":"/rows/0/1","equals":null}
//|   - case: loose
//|     expect:
//|       - {"artifact":"solution","path":"/rows/0/4","equals":"受理"}
//|       - {"artifact":"derivatives","path":"/rows/0/3","range":{"min":1e-7,"max":1e-4}}
//|   - case: eccentric
//|     expect:
//|       - {"artifact":"derivatives","path":"/rows/0/1","approx":{"value":1.5726167673887486,"rtol":1e-13}}
//|       - {"artifact":"derivatives","path":"/rows/2/3","range":{"max":1e-13}}
use scioxide_ad::{Dual, Real, Residual, grad, hessian, implicit_solution_into};
use scioxide_core::{
    SciOxideError, SciOxideErrorKind, SciOxideErrorView, InvalidInputReason, ResidualTolerance,
};

/// F(E; M, e) = E − e sin E − M。解は [E]、パラメータは [M, e]。
struct Kepler;
impl Residual for Kepler {
    fn residual<R: Real<f64, Mask = bool>>(
        &self,
        y: &[R],
        p: &[R],
        out: &mut [R],
    ) -> Result<(), SciOxideError> {
        out[0] = y[0] - p[1] * y[0].sin() - p[0];
        Ok(())
    }
}

let (m, e) = (mean_anomaly, eccentricity);
// 呼び出し側の解法: F と F_E を Dual で評価する Newton 法。
let mut estimate = core::f64::consts::PI;
for _ in 0..iterations as usize {
    let mut f = [Dual::constant(0.0)];
    let parameters = [Dual::constant(m), Dual::constant(e)];
    Kepler
        .residual(&[Dual::variable(estimate)], &parameters, &mut f)
        .map_err(|e| e.to_string())?;
    estimate -= f[0].value() / f[0].derivative();
}
let mut f = [0.0];
Kepler
    .residual(&[estimate], &[m, e], &mut f)
    .map_err(|e| e.to_string())?;
let atol: f64 = tolerance
    .parse()
    .map_err(|_| "許容誤差を読めない".to_string())?;
let tol = ResidualTolerance::new(atol, 0.0).map_err(|e| e.to_string())?;

// 陰関数の微分: 勾配（Var<f64>）とヘッセ行列（Var<Dual<f64>>）。
let point = [m, e];
let gradient = grad(
    |p| {
        let mut y = [p[0]];
        implicit_solution_into(&Kepler, &[estimate], p, tol, &mut y)?;
        Ok(y[0])
    },
    &point,
);
let curvature = hessian(
    |p| {
        let mut y = [p[0]];
        implicit_solution_into(&Kepler, &[estimate], p, tol, &mut y)?;
        Ok(y[0])
    },
    &point,
);
let verdict = match &gradient {
    Ok(_) => "受理".to_string(),
    Err(error) => match (error.kind(), error.view()) {
        (
            SciOxideErrorKind::InvalidInput,
            SciOxideErrorView::InvalidInput {
                argument,
                reason: InvalidInputReason::OutOfRange,
                ..
            },

        _ => error.to_string(),
    },
};

for _ in 0..100 {
    let middle = 0.5 * (low + high);
    if middle - e * middle.sin() - m < 0.0 {
        low = middle;
    } else {
        high = middle;
    }
}
let star = 0.5 * (low + high);
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let digits = serde_json::json!({ "significantDigits": 16 });
let columns = serde_json::json!([
    { "key": "0", "label": "反復回数 K", "type": "integer" },
    { "key": "1", "label": "E_K [rad]", "type": "number", "format": digits },
    { "key": "2", "label": "|F(E_K)| [rad]", "type": "number", "format": sci3 },
    { "key": "3", "label": "|E_K − E*| [rad]", "type": "number", "format": sci3 },
    { "key": "4", "label": "残差の検査" }
]);
let solution = vec![(
    iterations as u32,
    estimate,
    f[0].abs(),
    (estimate - star).abs(),
    verdict,
)];
emit_table_with_columns!(
    columns,
    solution,
    metadata = serde_json::json!({ "id": "solution" })
);

// 閉形式（独立検算）: D = 1 − e cos E*。
let (s, c) = (star.sin(), star.cos());
let d = 1.0 - e * c;
let exact = [
    1.0 / d,
    s / d,
    -e * s / d.powi(3),
    (c - e) / d.powi(3),
    (2.0 * s * c * d - e * s.powi(3)) / d.powi(3),
];
let computed: [Option<f64>; 5] = match (&gradient, &curvature) {
    (Ok(g), Ok(h)) => {
        let (g, h) = (g.as_slice(), h.as_slice());
        [Some(g[0]), Some(g[1]), Some(h[0]), Some(h[1]), Some(h[3])]
    }
    _ => [None; 5],
};
let names = [
    "∂E/∂M [-]",
    "∂E/∂e [rad]",
    "∂²E/∂M² [1/rad]",
    "∂²E/∂M∂e [-]",
    "∂²E/∂e² [rad]",
];
let rows: Vec<_> = names
    .iter()
    .zip(computed.iter().zip(&exact))
    .map(|(name, (value, &reference))| {
        let gap = value.map(|v| ((v - reference) / reference).abs());
        (*name, *value, reference, gap)
    })
    .collect();
let derivative_columns = serde_json::json!([
    { "key": "0", "label": "量" },
    { "key": "1", "label": "陰関数の微分", "type": "number", "format": digits, "nullText": "拒否された" },
    { "key": "2", "label": "閉形式（E* で評価）", "type": "number", "format": digits },
    { "key": "3", "label": "相対差 [-]", "type": "number", "format": sci3, "nullText": "拒否された" }
]);
emit_table_with_columns!(
    derivative_columns,
    rows,
    metadata = serde_json::json!({ "id": "derivatives" })
);
```

既定の $K = 6$ では $E_6 = 1.786141603274313$ rad で、残差 $2.2 \times 10^{-16}$ が atol $= 10^{-12}$ を満たすので、検査を通る。
参照解との差は 0 である。
5 つの導関数は閉形式と相対差 $3 \times 10^{-16}$ 以内で一致し、`Var<Dual<f64>>` による 2 階の導関数も丸めの水準で求まっている。

$K = 3$ では残差 $6.6 \times 10^{-6}$ が atol $= 10^{-12}$ を超えるので、`InvalidInput`（引数 `solution`、`OutOfRange`）になり、導関数は返らない。
同じ $K = 3$ で atol $= 10^{-4}$ にすると近似解 $E_3$ が受理され、$|E_3 - E^*| = 5.9 \times 10^{-6}$ に応じて導関数の相対差が $1.8 \times 10^{-6}$ から $1.0 \times 10^{-5}$ になる。
$\partial E/\partial M = 1/D$ の $E$ についての導関数は $-e \sin E/D^2 \approx -0.46$ なので、$0.46 \times 5.9 \times 10^{-6} / 0.886 \approx 3.0 \times 10^{-6}$ の見積りが、観測した $3.0 \times 10^{-6}$ と合う。

$e = 0.95$、$M = 0.3$ では $F_E = 0.636$ と小さくなり、$\partial^2 E / \partial M^2 = -3.41$ と既定の 8 倍以上の大きさになるが、最大相対差は $4.0 \times 10^{-16}$ である。

## まとめ

非線形方程式の解は呼び出し側が Newton 法などで求め、`Residual` を実装した残差と一緒に `implicit_solution_into` に渡す。
`implicit_solution_into` は `ResidualTolerance` で残差を確かめたうえで、勾配からヘッセ行列・ベクトル積まで陰関数定理で導関数を作り、テープには反復の過程ではなく出力ごとに `combine` の文を 1 つだけ残す。
導関数は渡した解の点で評価されるので、許容誤差を緩めると、受け入れた近似解の残差に応じて導関数の誤差も大きくなりうる。
丸めの水準の導関数が要るなら、残差を丸めの水準まで下げてから渡す。
$F_y$ の LU 分解のピボットが 0 か非有限なら `Singular` になるが、特異に近いだけならエラーにならないので、$F_y$ の条件数は呼び出し側が確かめる。
`Jet` では $c_2$ 以降の係数が NaN になり、`Lanes` を含む型は使えない。
