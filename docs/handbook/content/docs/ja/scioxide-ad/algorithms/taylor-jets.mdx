常微分方程式の Taylor 法、曲線に沿った高階の変化率、多変数の混合偏微分では、1 つの方向に沿った $K$ 階までの微分や、$\partial^{a+b} f/\partial x^a \partial y^b$ のような混合偏微分が要る。
1 階の前進モードを入れ子にして $K$ 階を求めると、段ごとに成分が 2 倍になり、$2^K$ 個の成分を保持する。
切り捨てた冪級数を値として保持する Taylor 算術なら、$K$ 階までを 1 回の評価と、演算あたり $O(K^2)$ の係数の演算で求められる。
このページは `scioxide-ad` の Taylor ジェット `Jet` が使う漸化式、型と関数、混合係数、特別な規約、精度を扱う。
1 階の前進モードと二重数は[前進モードと二重数](../forward-mode/)で説明する。

導出では、関数が評価点の近くで必要な階数まで連続微分可能であることを仮定する。

## 正規化 Taylor 係数

1 変数 $t$ の関数 $x(t)$ を $t = 0$ のまわりで

$$
x(t) = \sum_{k=0}^{N-1} c_k\, t^k + O(t^N), \qquad c_k = \frac{1}{k!} \left.\frac{d^k x}{dt^k}\right|_{t=0}
$$

と展開したときの $c_k$ を正規化 Taylor 係数と呼ぶ。
$k$ 階の導関数は $k!\,c_k$ である。
入力を直線 $x(t) = p + t\,d$ にとると、$f(x(t))$ の係数は $c_k = \frac{1}{k!} D^k f(p)[d, \dots, d]$ で、1 変数なら $c_k = f^{(k)}(p)\,d^k/k!$ である。

導関数そのものではなく $f^{(k)}/k!$ を保持する理由は 2 つある。
1 つは積の Leibniz 則 $(uv)^{(k)} = \sum_j \binom{k}{j} u^{(j)} v^{(k-j)}$ の二項係数が消え、次の節の Cauchy 積になることである。
もう 1 つは大きさで、$t$ についての収束半径を $R$ とすると $|c_k|$ は $R^{-k}$ 程度にとどまるが、$f^{(k)}$ は $k!/R^k$ 程度に増える。
倍精度では $171! > 1.8 \times 10^{308}$ なので、$k = 171$ で $k!$ だけでもあふれる。
`Jet` は階乗を作らないので、たとえば $1/(1 + t)$ の係数 $(-1)^k$ は $k \ge 171$ でも正確に求まる。

## 係数の漸化式

各演算は入力の級数を出力の級数へ写す。
合成関数の規則を書く必要はなく、演算を順に適用すれば $f(g(x(t)))$ の級数が得られる。
$c_0$ は係数の型 `V` での同じ演算の値そのもので、$c_1$ は 1 階の規則の偏導関数を入力の $c_1$ に掛けた値である。
$k \ge 2$ の係数は、関数が満たす微分方程式の両辺の係数を比べて求める。

例として $w = e^u$ を考える。
$t$ についての微分を $'$ で表すと $w' = w\,u'$ で、両辺に $t$ を掛けると $t w' = w \cdot t u'$ になる。
$t\,w'$ の $k$ 次の係数は $k\,w_k$ なので、$t^k$ の係数を比べて

$$
w_k = \frac{1}{k} \sum_{j=1}^{k} j\, u_j\, w_{k-j}
$$

を得る。
各項に整数 $j$ を掛けて和を 1 回だけ $k$ で割るので、階乗は現れない。
ほかの演算も同じ比較から次の漸化式になる（$k \ge 2$）。

| 演算 | 関係式 | 係数 |
|---|---|---|
| 和・差・符号反転・定数倍 | 線形 | 係数ごとに同じ演算。定数の加減は $c_0$ だけを変える |
| 積 $w = uv$ | Cauchy 積 | $w_k = \sum_{j=0}^{k} u_j v_{k-j}$ |
| 商 $w = u/v$ | $vw = u$ | $w_k = \bigl(u_k - \sum_{j=1}^{k} v_j w_{k-j}\bigr)/v_0$ |
| 逆数 $w = 1/u$ | $uw = 1$ | $w_k = -\sum_{j=1}^{k} u_j w_{k-j}/u_0$ |
| 平方根 $w = \sqrt u$ | $w^2 = u$ | $w_k = \bigl(u_k - \sum_{j=1}^{k-1} w_j w_{k-j}\bigr)/(2w_0)$ |
| 指数 $w = e^u$ | $w' = w u'$ | $w_k = \frac1k \sum_{j=1}^{k} j\,u_j w_{k-j}$ |
| 対数 $w = \ln u$ | $u w' = u'$ | $w_k = \bigl(u_k - \frac1k \sum_{j=1}^{k-1} j\,w_j u_{k-j}\bigr)/u_0$ |
| 定数の冪 $w = u^p$（Miller の漸化式） | $u w' = p\,w u'$ | $w_k = \frac{1}{k\,u_0} \sum_{j=1}^{k} \bigl(p j - (k - j)\bigr)\, u_j w_{k-j}$ |
| 正弦と余弦 $s = \sin u$、$c = \cos u$ | $s' = c u'$、$c' = -s u'$ | $s_k = \frac1k \sum_{j=1}^{k} j\,u_j c_{k-j}$、$c_k = -\frac1k \sum_{j=1}^{k} j\,u_j s_{k-j}$ |
| 正接 $y = \tan u$ | $y' = w u'$、$w = 1 + y^2$ | $y_k = \frac1k \sum_{j=1}^{k} j\,u_j w_{k-j}$、$w_k = \sum_{j=0}^{k} y_j y_{k-j}$ |
| 逆関数 $y = \operatorname{asin} u$ など | $q\,y' = \pm u'$ | $y_k = \bigl(\pm u_k - \frac1k \sum_{j=1}^{k-1} j\,y_j q_{k-j}\bigr)/q_0$ |

正弦と余弦は 2 つの級数を同時に進める連立の漸化式で、`sinh` と `cosh` は符号を変えた同じ形である。
`tan` は補助の級数 $w = 1 + y^2$ を、`tanh` は $w = 1 - y^2$ を一緒に保持する。
`sigmoid` $\sigma(v)$ は $\sigma' = D v'$、$D' = (1 - 2\sigma)\,\sigma'$ を運び、$1 - 2\sigma$ の初期値を $-\tanh(v_0/2)$ から作るので、飽和した $\sigma$ の丸めた値を 1 から引く項がない。
逆関数の $q$ は `asin`・`acos` で $\sqrt{1 - u^2}$、`atan` で $1 + u^2$、`asinh` で $\sqrt{1 + u^2}$、`acosh` で $\sqrt{u^2 - 1}$、`atanh` で $1 - u^2$ である。
$q$ の級数は $m = \max(|u_0|, 1)$（`atan` と `atanh` では $m^2$）で割ってから作り、2 乗があふれないようにする。
`powi` は 0 でない底では Miller の漸化式を、底が 0 の点では級数の 2 進の冪乗（繰り返しの Cauchy 積）を使い、0 での割り算を避ける。
`cbrt` は $p = 1/3$ の Miller の漸化式、`hypot` は方向余弦 $(x/h, y/h)$ の級数を保持する極形式の漸化式である。
`hypot` の漸化式は、$h^2 = x^2 + y^2$ の係数を比べる方法が $(x', y')$ のほぼ動径方向で起こす桁落ちを避ける。

計算コストは非線形の演算 1 つが `V` の演算 $O(N^2)$ 回、線形の演算が $O(N)$ 回である。
漸化式の積は IEEE の積で、掛け算と足し算を別々に行い（`mul_add` を使わない）、和は添字の順に足すので、結果は FMA の有無によらない。

## Jet 型

`Jet<V, N>` は、正規化係数 $c_0, \dots, c_{N-1}$ を `V` の値として `N` 個持つ `Copy` の型である。
`V` は `Real` を実装する任意の数値型で、`Jet<Lanes<f64, 8>, N>` は 8 個の lane を同時に展開する。
`Jet` 自身も `Real` を実装するので、`R: Real` に対して一度書いた関数をそのまま Taylor 算術で評価できる。
大小の比較は $c_0$ で行う。

- `Jet::new(coefficients)` は係数の配列から作る。
  `N ≥ 1` はコンパイル時に検査され、`Jet<f64, 0>` を作るコードはコンパイルできない。
- `Jet::variable(x0)` は独立変数 $x_0 + t$（$c_0 = x_0$、$c_1 = 1$、それより上は 0）を作る。
- `coefficients()` は配列 `[V; N]` を、`coefficient(k)` は $c_k$ を `Option` で返し、$k \ge N$ なら `None` である。
- `Jet<V, 3>` は値、1 階微分、2 階微分（$2c_2$）を保持する。

$c_0$ は `V` での同じ演算の値とビット単位で一致する。
$c_1$ は同じ偏導関数から作るので `Dual` の導関数と一致するが、2 つの点で違う。
1 つはゼロの符号である。
もう 1 つは非有限の偏導関数と正確に 0 の係数が出会う場合で、`Jet` は IEEE の積を使うので NaN になるが、`Dual` は多くの規則で絶対零の積 `azmul` を使って $+0$ を返す。
たとえば $v < 0$ での `sqrt(max(v, 0))` は、`Dual` の導関数が $+0$、`Jet` の $c_1$ が NaN である。

## 直線に沿う係数 jet

ワンショット呼び出しの `jet(function, point, direction)` は、各入力を `Jet` の $[p_i, d_i, 0, \dots]$ にして関数を評価し、$f(p + t\,d)$ の正規化係数を `[S; N]` で返す。
$c_0$ は値、$c_1$ は方向微分 $\nabla f \cdot d$、$2c_2$ は曲率 $d^{\mathsf T} \nabla^2 f\, d$ で、一般に $k!\,c_k = D^k f(p)[d, \dots, d]$ である。
`function` の引数は `&[Jet<S, N>]` で、戻り値の型 `[f64; N]` を書いて `N` を決める。
`direction` の長さが `point` と違えば `DimensionMismatch`、入力の配列を確保できなければ `AllocationFailure` を返し、関数のエラーはそのまま返す。
出力が複数ある関数や、方向が複数ある計算では、`Jet` で汎用関数を直接評価する。

## 丸め誤差と精度の限界

漸化式が与えるのは切り捨てた級数の正確な係数なので、打ち切り誤差はなく、誤差は丸め誤差だけである。
各段は丸めた低次の係数を使うので、誤差は次数とともに蓄積する。

`scioxide-ad` が高精度の参照値との試験で確かめている `Jet` の精度の保証は、次の上限である。
引数と係数が 0 か、大きさが $[\sqrt{\mathrm{MIN\_POSITIVE}}, \sqrt{\mathrm{MAX}}]$ に入る点で、係数 $c_k$ の絶対誤差は

$$
64\,\varepsilon\,(k + 1)\, g + (\text{最小の非正規数})
$$

以下である。
$\varepsilon$ は機械イプシロン、$g$ は正確な合成の各項の絶対値の和である。
この上限は `f32` と `f64` で 8 次まで、混合係数では全次数 8 までについて述べられており、それより高い次数の上限は定めていない。
範囲の外では、IEEE の算術がそのままあふれたりアンダーフローしたりする。
浮動小数点の誤差の一般論は[浮動小数点数と条件数](../../../concepts/floating-point-and-conditioning/)にある。

$g$ は $|c_k|$ 以上で、すべての項が同じ符号なら $|c_k|$ に等しい。
打ち消しのある合成では $g \gg |c_k|$ になり、小さい係数の相対誤差は大きくなりうる。
商、逆数、対数、平方根、逆関数の漸化式は $u_0$ や $w_0$ で割るので、分母が 0 に近い点では係数と $g$ が $(1/u_0)^k$ のように増える。
導関数 $k!\,c_k$ に戻しても相対誤差は掛け算の丸め 1 回の分しか変わらないが、値は $k!$ 倍になる。

次のセルは閉形式の分かる 3 つの級数の係数を $t = 0$ のまわりで 30 次まで求め、誤差を $\varepsilon\,(k + 1)\,g_k$ で割った値（以下、誤差比）を示す。
$k \le 8$ での誤差比の上限は 64 である。

- $\tan t$：$c_k = E_k/k!$（$k$ が奇数）、偶数次は 0。
  $E_k$ は正接数で、セルの中で Seidel の三角形（整数の足し算だけ）から求める。
  漸化式の項はすべて非負なので $g_k = |c_k|$ である。
- $e^t$：$c_k = 1/k!$、$g_k = c_k$。
- $e^t \cdot e^{-t}$：$k \ge 1$ の正しい係数は 0 で、Cauchy 積の項の絶対値の和は $g_k = \sum_j \frac{1}{j!\,(k-j)!} = 2^k/k!$ である。

参照値は整数で正確に作った分数を 64 ビットの長除法で求めてから `f64` に丸めた独立な値である。
グラフは誤差が 0 でない係数を対数軸に描き（0 の係数は表で数える）、誤差比の上限 64 を注記の線、上限が述べられた $k \le 8$ を範囲で示す。

```rust
//| id: ad-taylor-exp-series
//| ref: ad-taylor-exp-series
//| title: 既知の級数の正規化 Taylor 係数と誤差の上限
//| run: reactive
//| crates: [scioxide-ad]
//| inputs:
//|   function: {"type":"select","label":"関数","options":["tan t","exp t","e^t · e^(−t)"],"value":"tan t"}
//| cases:
//|   - {"id":"exp","label":"exp t","description":"係数 1/k! が 30 次で 10⁻³³ まで下がる。","inputs":{"function":"exp t"}}
//|   - {"id":"cancellation","label":"e^t · e^(−t)","description":"正しい係数は 0 で、誤差の規模は g_k = 2ᵏ/k! で決まる。","inputs":{"function":"e^t · e^(−t)"}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"coefficients","path":"/rows/2/1","approx":{"value":0.3333333333333333,"rtol":1e-15}}
//|       - {"artifact":"coefficients","path":"/rows/1/1","equals":0}
//|       - {"artifact":"summary","path":"/rows/0/1","range":{"max":64}}
//|       - {"artifact":"summary","path":"/rows/0/2","range":{"max":64}}
//|   - case: exp
//|     expect:
//|       - {"artifact":"coefficients","path":"/rows/6/1","approx":{"value":3.769987628815906e-33,"rtol":1e-14}}
//|       - {"artifact":"summary","path":"/rows/0/1","range":{"max":64}}
//|   - case: cancellation
//|     expect:
//|       - {"artifact":"coefficients","path":"/rows/0/2","equals":0}
//|       - {"artifact":"summary","path":"/rows/0/1","range":{"max":64}}
//|       - {"artifact":"summary","path":"/rows/0/2","range":{"max":64}}
use scioxide_ad::{Jet, Real};

const N: usize = 31;
let t = Jet::<f64, N>::variable(0.0);
let series = match function.as_str() {
    "tan t" => t.tan(),
    "exp t" => t.exp(),
    _ => t.exp() * (-t).exp(),
};
let c = series.coefficients();

// 参照値（独立検算）: 整数の分数 p/q を 64 ビットの長除法で求め、f64 に 1 回だけ丸める。
let ratio = |p: u128, q: u128| -> f64 {
    if p == 0 {
        return 0.0;
    }
    let (mut p, mut q, mut scale) = (p, q, 0_i32);
    while p / 2 >= q {
        q <<= 1;
        scale += 1;
    }
    while p < q {
        p <<= 1;
        scale -= 1;
    }
    let mut bits = 0_u64;
    for _ in 0..64 {
        bits <<= 1;
        if p >= q {
            p -= q;
            bits |= 1;
        }
        p <<= 1;
    }
    // 2 の冪を掛けるだけなので正確（参照値の計算）。
    bits as f64 * 2.0_f64.powi(scale - 63)
};
// 正接数 E_k を Seidel の三角形で求める。
let mut zigzag = vec![1_u128; N];
let mut row = vec![1_u128];
for k in 1..N {
    let mut next = vec![0_u128; k + 1];
    for j in 1..=k {
        next[j] = next[j - 1] + row[k - j];
    }
    zigzag[k] = next[k];
    row = next;
}
let eps = f64::EPSILON;
let (mut factorial, mut zeros) = (1_u128, 0_usize);
let (mut points, mut rows) = (Vec::new(), Vec::new());
let (mut worst_low, mut worst_high) = (0.0_f64, 0.0_f64);
for k in 0..N {
    if k > 0 {
        factorial *= k as u128;
    }
    // (参照値 c*_k, 項の絶対値の和 g_k)
    let (exact, growth) = match function.as_str() {
        "tan t" if k % 2 == 1 => (ratio(zigzag[k], factorial), ratio(zigzag[k], factorial)),
        "tan t" => (0.0, 0.0),
        "exp t" => (ratio(1, factorial), ratio(1, factorial)),
        _ => (if k == 0 { 1.0 } else { 0.0 }, ratio(1 << k, factorial)),
    };
    let error = (c[k] - exact).abs();
    let scaled = (growth > 0.0).then(|| error / (eps * (k as f64 + 1.0) * growth));
    if error == 0.0 {
        zeros += 1;
    } else if let Some(value) = scaled {
        points.push([k as f64, value]);
    }
    let worst = if k <= 8 {
        &mut worst_low
    } else {
        &mut worst_high
    };
    *worst = worst.max(scaled.unwrap_or(0.0));
    if [1, 2, 3, 5, 8, 15, 30].contains(&k) {
        rows.push((k, c[k], exact, growth, error, scaled));
    }
}
emit_scatter_chart!(
    &vec![serde_json::json!({ "name": "誤差比", "points": points })],
    options = &serde_json::json!({
        "xLabel": "次数 k [-]",
        "yLabel": "誤差比 |c_k − c*_k| / (ε(k + 1)g_k) [-]",
        "yType": "log",
        "xMin": 0.0,
        "xMax": 30.0,
        "annotations": [
            { "kind": "line", "axis": "y", "value": 64.0, "label": "上限 64" },
            { "kind": "range", "axis": "x", "from": 0.0, "to": 8.0, "label": "上限が述べられた範囲" }
        ]
    })
);
let sci4 = serde_json::json!({ "notation": "scientific", "significantDigits": 4 });
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let columns = serde_json::json!([
    { "key": "0", "label": "次数 k", "type": "integer" },
    { "key": "1", "label": "Jet の c_k [-]", "type": "number", "format": sci4 },
    { "key": "2", "label": "参照値 c*_k [-]", "type": "number", "format": sci4 },
    { "key": "3", "label": "g_k [-]", "type": "number", "format": sci4 },
    { "key": "4", "label": "|c_k − c*_k| [-]", "type": "number", "format": sci2 },
    { "key": "5", "label": "誤差比 [-]", "type": "number", "format": sci2, "nullText": "g_k = 0" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "coefficients" })
);
let summary_columns = serde_json::json!([
    { "key": "0", "label": "誤差が 0 の係数の数（31 個のうち）", "type": "integer" },
    { "key": "1", "label": "最大の誤差比、k ≤ 8 [-]", "type": "number", "format": sci2 },
    { "key": "2", "label": "最大の誤差比、9 ≤ k ≤ 30 [-]", "type": "number", "format": sci2 }
]);
emit_table_with_columns!(
    summary_columns,
    vec![(zeros, worst_low, worst_high)],
    metadata = serde_json::json!({ "id": "summary" })
);
```

既定の $\tan t$ では、31 個の係数のうち 23 個が参照値とビット単位で一致し、偶数次の 0 はすべて正確に 0 になる。
誤差が 0 でない係数でも誤差比は 0.074 以下で、上限の 64 より約 3 桁小さい。
$k \le 8$ と $9 \le k \le 30$ で比は同じ水準で、次数とともに増える傾向はない。

$e^t$ では係数が 30 次の $3.8 \times 10^{-33}$ まで 32 桁あまり下がるが、31 個のうち 18 個が正確に一致し、残りの誤差比も 0.079 以下である。
すべての項が同じ符号の合成では $g_k = |c_k|$ なので、係数の大きさが何桁変わっても相対誤差は $\varepsilon$ の程度にとどまる。

$e^t \cdot e^{-t}$ では $k \ge 3$ の係数が 0 にならず、30 次でも $1.2 \times 10^{-41}$ が残る。
正しい係数が 0 なので相対誤差は定義できないが、残った値の誤差比は 0.024 以下である。
誤差の規模を決めるのは $|c_k|$ ではなく項の絶対値の和 $g_k$ であり、上限が $g$ を使って書かれている理由がここにある。
3 つの例のどれでも誤差比は 0.08 以下で、上限の 64 より約 3 桁小さい。

## 入れ子の Jet による混合係数

`Jet<Jet<V, M>, N>` は 2 変数の級数を保持する。
外側の変数を $s$、内側の変数を $t$ とすると、外側の係数 $i$ の内側の係数 $j$ は

$$
c_{ij} = \frac{1}{i!\,j!} \left.\frac{\partial^{i+j} x}{\partial s^i\, \partial t^j}\right|_{s = t = 0}
$$

で、`f.coefficients()[i].coefficients()[j]` で読む。
$x = x_0 + s$ は `Jet::variable(Jet::constant(x0))`、$y = y_0 + t$ は `Jet::lift(Jet::variable(y0))` で作る。
外側の演算は内側の `Jet` を係数とする同じ漸化式で、外側の積や重み $j/k$ の掛け算が内側の Taylor 算術になるだけなので、ここでも階乗は現れない。

メモリ領域は `V` の値 $N \cdot M$ 個で、$i < N$、$j < M$ の長方形のすべての係数を持つ。
非線形の演算 1 つは外側で $O(N^2)$ 回の内側の演算を行い、その 1 つが $O(M^2)$ 回なので、`V` の演算は $O(N^2 M^2)$ 回である。
必要な係数が全次数の低い一部だけでも、長方形全体を計算する。

次のセルは $f(x, y) = e^{xy}$ を `Jet<Jet<f64, 6>, 6>` で評価し、$c_{pq}$ を閉形式と比べる。
$(x_0 + s)(y_0 + t) = x_0 y_0 + y_0 s + x_0 t + st$ を指数関数の級数に入れて展開すると

$$
c_{pq} = e^{x_0 y_0} \sum_{m=0}^{\min(p, q)} \frac{y_0^{\,p-m}\, x_0^{\,q-m}}{(p-m)!\,(q-m)!\,m!}
$$

で、これを `f64` で独立に計算する。
入力は評価点 $(x_0, y_0)$ である。
1 つ目の表は選んだ $(p, q)$ の係数、閉形式、相対差、偏導関数 $\partial^{p+q} f/\partial x^p \partial y^q = p!\,q!\,c_{pq}$ を示す。
2 つ目の表は 36 個すべての係数の相対差の最大値を $\varepsilon$ を単位にして示す（閉形式が 0 の係数は除く）。

```rust
//| id: ad-mixed-jet
//| ref: ad-mixed-jet
//| title: e^{xy} の混合 Taylor 係数と閉形式
//| run: reactive
//| crates: [scioxide-ad]
//| inputs:
//|   x0: {"type":"range","label":"評価点 x₀","min":-1,"max":1,"step":0.1,"value":0.6}
//|   y0: {"type":"range","label":"評価点 y₀","min":-1,"max":1,"step":0.1,"value":-0.4}
//| cases:
//|   - {"id":"same-sign","label":"(x₀, y₀) = (0.6, 0.4)","description":"閉形式の項がすべて正になる。","inputs":{"y0":0.4}}
//|   - {"id":"origin-x","label":"(x₀, y₀) = (0, −1)","description":"q > p の係数が 0 になる。","inputs":{"x0":0,"y0":-1}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"mixed","path":"/rows/0/2","approx":{"value":0.7866278610665535,"rtol":1e-15}}
//|       - {"artifact":"mixed","path":"/rows/3/2","approx":{"value":0.5978371744105806,"rtol":1e-14}}
//|       - {"artifact":"box","path":"/rows/0/0","range":{"max":64}}
//|   - case: same-sign
//|     expect:
//|       - {"artifact":"box","path":"/rows/0/0","range":{"max":64}}
//|   - case: origin-x
//|     expect:
//|       - {"artifact":"mixed","path":"/rows/5/2","equals":0}
//|       - {"artifact":"box","path":"/rows/0/0","range":{"max":64}}
use scioxide_ad::{Jet, Real};

// x = x₀ + s（外側の変数）、y = y₀ + t（内側の変数）。
let x = Jet::<Jet<f64, 6>, 6>::variable(Jet::constant(x0));
let y = Jet::<Jet<f64, 6>, 6>::lift(Jet::variable(y0));
let c = (x * y).exp().coefficients().map(|row| row.coefficients());

// 閉形式（独立検算、f64 の標準関数による参照値）。
let factorial = |n: usize| (1..=n).map(|i| i as f64).product::<f64>();
let closed = |p: usize, q: usize| {
    let sum: f64 = (0..=p.min(q))
        .map(|m| {
            y0.powi((p - m) as i32) * x0.powi((q - m) as i32)
                / (factorial(p - m) * factorial(q - m) * factorial(m))
        })
        .sum();
    (x0 * y0).exp() * sum
};
let relative = |p: usize, q: usize| {
    let exact = closed(p, q);
    (exact != 0.0).then(|| ((c[p][q] - exact) / exact).abs())
};
let picks = [
    (0, 0),
    (1, 0),
    (0, 1),
    (1, 1),
    (2, 1),
    (1, 2),
    (3, 2),
    (5, 5),
];
let rows: Vec<_> = picks
    .iter()
    .map(|&(p, q)| {
        let derivative = factorial(p) * factorial(q) * c[p][q];
        (p, q, c[p][q], closed(p, q), relative(p, q), derivative)
    })
    .collect();
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let sig10 = serde_json::json!({ "significantDigits": 10 });
let columns = serde_json::json!([
    { "key": "0", "label": "s の次数 p", "type": "integer" },
    { "key": "1", "label": "t の次数 q", "type": "integer" },
    { "key": "2", "label": "Jet の c_pq [-]", "type": "number", "format": sig10 },
    { "key": "3", "label": "閉形式 [-]", "type": "number", "format": sig10 },
    { "key": "4", "label": "相対差 [-]", "type": "number", "format": sci2, "nullText": "閉形式が 0" },
    { "key": "5", "label": "p! q! c_pq [-]", "type": "number", "format": sig10 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "mixed" })
);
let mut worst = (0.0_f64, 0, 0);
for p in 0..6 {
    for q in 0..6 {
        let value = relative(p, q).unwrap_or(0.0) / f64::EPSILON;
        if value > worst.0 {
            worst = (value, p, q);
        }
    }
}
let box_columns = serde_json::json!([
    { "key": "0", "label": "最大の相対差 / ε [-]", "type": "number", "format": sci2 },
    { "key": "1", "label": "そのときの p", "type": "integer" },
    { "key": "2", "label": "そのときの q", "type": "integer" }
]);
emit_table_with_columns!(
    box_columns,
    vec![worst],
    metadata = serde_json::json!({ "id": "box" })
);
```

既定の $(x_0, y_0) = (0.6, -0.4)$ では、選んだ 8 つの係数がすべて閉形式とビット単位で一致し、36 個の係数の相対差の最大値は $(p, q) = (5, 1)$ の $1.8\varepsilon$ である。
$c_{21} = -0.27689$ から得る $\partial^3 f/\partial x^2 \partial y = 2!\,1!\,c_{21} = -0.55379$ は、直接の微分 $e^{xy}(2y + xy^2)$ の値と一致する。
$y_0 < 0$ では閉形式の和の項の符号が交互になるので、参照値自身も丸めを含み、差は両方の誤差を合わせたものである。
同じ $y_0 = -0.4$ で $x_0 = 1$ にすると、最大値は $(p, q) = (3, 3)$ の約 $20\varepsilon$ に増える。

$y_0 = 0.4$ にすると閉形式の項がすべて正になり、相対差の最大値は $(p, q) = (5, 3)$ の $1.5\varepsilon$ である。
$(x_0, y_0) = (0, -1)$ では $x_0 t$ の項が消え、$t$ を含むのは $st$ の項だけなので、$q > p$ の係数は 0 になる。
`Jet` もこれらの係数を正確に 0 にし、残りの係数もすべて閉形式と一致する。

## 折れ点と係数を作らない演算

`Jet` はすべての数値型に共通の 1 階の折れ点の規約（片側導関数の中点）を係数ごとに適用する（[折れ点と非有限値の扱い](../nonsmooth-and-nonfinite-policies/)）。
`abs`、`min`、`max`、`clamp`、`%` の規則は偏導関数を絶対零の積 `azmul` で係数に掛けるので、偏導関数が 0 の側（選ばれなかった側や、$x_0 = 0$ での `abs`）の係数が NaN や無限大でも結果に入らない。

- `abs` は $c_1$ 以上のすべての係数に $\operatorname{sign} x_0$ を掛け、$x_0 = 0$ では 0 を掛ける。
- `min`、`max`、`clamp` は選ばれた側の係数をとり、$c_0$ が等しいときは両側の係数の平均をとる。
- `floor`、`ceil`、`round`、`trunc`、`signum` は $c_1$ 以上がすべて 0 である。
- `fract` と `%` は定義 $x - \operatorname{trunc}(x)$、$a - \operatorname{trunc}(a_0/b_0)\,b$ に従う。
- `hypot` は原点で $c_1$ に偏導関数 $(0, 0)$ を使い、$c_2$ から NaN になる。

`powf` の規則は指数の級数で分かれる。

- 指数の $c_1$ 以上がすべて 0（定数の指数 $y_0$）のときは Miller の漸化式を使うので、$(-2 + t)^3$ のように負の底で値が有限なら係数が求まる。
- 定数の指数で底が 0 のとき、$y_0$ が 0 以上の整数なら `powi` と同じ係数になる。
  そうでなければ、$k \ge 2$ の係数は $k < y_0$ で 0、$k \ge y_0$ で NaN になる。
  たとえば $t^{2.5}$ は $c_0 = c_1 = c_2 = 0$、$c_3$ から NaN で、$t^{2.5}$ の 3 階微分が $t = 0$ で発散することと合う。
- 指数が変わるときは $e^{y \ln x}$ の漸化式を使うので、底が 0 なら $c_2$ から、底が負なら $c_1$ から NaN になる。

いくつかの演算は高い係数を作らず、その係数を NaN にする。

- `atan2` と `Real::combine` は 1 階まで正確で、$c_2$ から NaN である。
- `exprel`、`sinc`、`sincpi` と、呼び出し側が値と 1 階・2 階の導関数を与える `Real::map_scalar`（`try_map_scalar` も同じ）は 2 階まで正確で、$c_3$ から NaN である。

0 ではなく NaN を入れるので、計算しなかった係数がそれに依存するすべての結果に伝わり、誤った有限の値として残らない。
これらの演算の高い係数が要るときは、同じ関数を係数の漸化式を持つ演算で書き直す。
たとえば `sinc` は `sin(x) / x` で書けば（$x_0 \ne 0$ の点で）すべての係数が求まる。

次のセルは、これらの規約が当てはまる点で `Jet<f64, 4>` の係数を求め、`Dual` の導関数と並べる。
入力はない。
NaN の係数は表で「NaN」と示す。

```rust
//| id: ad-jet-special-points
//| ref: ad-jet-special-points
//| title: 折れ点と高い係数を作らない演算での Jet の係数
//| run: reactive
//| crates: [scioxide-ad, scioxide-core]
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"rules","path":"/rows/0/2","equals":0}
//|       - {"artifact":"rules","path":"/rows/2/2","equals":3}
//|       - {"artifact":"rules","path":"/rows/2/3","equals":1}
//|       - {"artifact":"rules","path":"/rows/4/3","equals":0}
//|       - {"artifact":"rules","path":"/rows/4/4","equals":null}
//|       - {"artifact":"rules","path":"/rows/5/4","equals":1}
//|       - {"artifact":"rules","path":"/rows/6/1","equals":-8}
//|       - {"artifact":"rules","path":"/rows/6/3","approx":{"value":-6,"atol":1e-14}}
//|       - {"artifact":"rules","path":"/rows/7/2","approx":{"value":0.8,"rtol":1e-15}}
//|       - {"artifact":"rules","path":"/rows/7/3","equals":null}
//|       - {"artifact":"rules","path":"/rows/8/4","equals":null}
//|       - {"artifact":"rules","path":"/rows/10/2","equals":null}
//|       - {"artifact":"rules","path":"/rows/10/5","equals":0}
use scioxide_ad::{Dual, Jet, Real};
use scioxide_core::RealScalar;

// x(t) = x₀ + t の Jet と、同じ点の Dual。
let jet = |x0: f64| Jet::<f64, 4>::variable(x0);
let dual = |x0: f64| Dual::variable(x0);
// NaN は JSON に入らないので None にして「NaN」と表示する。
let finite = |v: f64| v.is_finite().then_some(v);
let row = |name: &str, j: Jet<f64, 4>, d: Dual<f64>| {
    let [c0, c1, c2, c3] = j.coefficients().map(finite);
    (name.to_string(), c0, c1, c2, c3, finite(d.derivative()))
};
let sin_rule = |v: f64| [RealScalar::sin(v), RealScalar::cos(v), -RealScalar::sin(v)];
let (a, b) = (
    Jet::new([1.0, 2.0, 3.0, 0.0]),
    Jet::new([1.0, 4.0, -1.0, 0.0]),
);
let rows = vec![
    row("|t|（x₀ = 0）", jet(0.0).abs(), dual(0.0).abs()),
    row("|x|（x₀ = −1）", jet(-1.0).abs(), dual(-1.0).abs()),
    row(
        "max(1 + 2t + 3t², 1 + 4t − t²)",
        a.max(b),
        Dual::new(1.0, 2.0).max(Dual::new(1.0, 4.0)),
    ),
    row("floor(2.5 + t)", jet(2.5).floor(), dual(2.5).floor()),
    row(
        "t^2.5（定数の指数）",
        jet(0.0).powf(Jet::constant(2.5)),
        dual(0.0).powf(Dual::constant(2.5)),
    ),
    row(
        "t^3（定数の指数）",
        jet(0.0).powf(Jet::constant(3.0)),
        dual(0.0).powf(Dual::constant(3.0)),
    ),
    row(
        "(−2 + t)^3（定数の指数）",
        jet(-2.0).powf(Jet::constant(3.0)),
        dual(-2.0).powf(Dual::constant(3.0)),
    ),
    row(
        "atan2(0.5 + t, 1)",
        jet(0.5).atan2(Jet::constant(1.0)),
        dual(0.5).atan2(Dual::constant(1.0)),
    ),
    row("sinc(0.5 + t)", jet(0.5).sinc(), dual(0.5).sinc()),
    row(
        "map_scalar で与えた sin（x₀ = 0.5）",
        jet(0.5).map_scalar(sin_rule),
        dual(0.5).map_scalar(sin_rule),
    ),
    row(
        "sqrt(max(−1 + t, 0))",
        jet(-1.0).max(Jet::constant(0.0)).sqrt(),
        dual(-1.0).max(Dual::constant(0.0)).sqrt(),
    ),
];
let sig6 = serde_json::json!({ "significantDigits": 6 });
let columns = serde_json::json!([
    { "key": "0", "label": "式" },
    { "key": "1", "label": "c₀ [-]", "type": "number", "format": sig6, "nullText": "NaN" },
    { "key": "2", "label": "c₁ [-]", "type": "number", "format": sig6, "nullText": "NaN" },
    { "key": "3", "label": "c₂ [-]", "type": "number", "format": sig6, "nullText": "NaN" },
    { "key": "4", "label": "c₃ [-]", "type": "number", "format": sig6, "nullText": "NaN" },
    { "key": "5", "label": "Dual の導関数 [-]", "type": "number", "format": sig6, "nullText": "NaN" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "rules" })
);
```

$|t|$ の行では $x_0 = 0$ で $\operatorname{sign} x_0 = 0$ を掛けるので、$c_1$ 以上がすべて 0 になり、`Dual` の導関数も片側導関数 $\pm 1$ の中点の 0 である。
`max` の行は $c_0$ が等しい点で、2 つの級数の係数の平均 $(2 + 4)/2 = 3$、$(3 - 1)/2 = 1$ をとる。
$t^{2.5}$ は $c_3$ から NaN で、$t^3$ と $(-2 + t)^3$ は多項式 $(-2 + t)^3 = -8 + 12t - 6t^2 + t^3$ の係数を返す。
`atan2` は $c_2$ から、`sinc` と `map_scalar` は $c_3$ から NaN である。
最後の行を除くどの行でも、$c_1$ は `Dual` の導関数と一致する。

最後の行では、`max` が定数 0 の側を選ぶので `sqrt` に渡る級数の $c_1$ 以上はすべて 0 になり、`sqrt` の偏導関数 $+\infty$ と係数 0 の IEEE の積が NaN を作る。
`Dual` はここで絶対零の積を使うので導関数が $+0$ になり、`Jet` の $c_1$ と `Dual` の導関数が違う例になる。
$\sqrt{\max(v, 0)}$ のように偏導関数が無限大になる点を定数の側で避ける式を `Jet` で評価するときは、$c_1$ 以上が NaN になることを前提に扱う。

## まとめ

方向 $d$ に沿った $N - 1$ 階までの微分は、`jet` で正規化係数 $c_k = D^k f(p)[d, \dots, d]/k!$ として求まり、計算コストは非線形の演算あたり $O(N^2)$ である。
2 変数の混合偏微分は `Jet<Jet<f64, M>, N>` の $c_{ij}$ に $i!\,j!$ を掛けて求め、外側の変数が $s$、内側が $t$ であることに注意する。
誤差の上限は 8 次までの $64\,\varepsilon\,(k + 1)\,g$ で、$g$ は合成の項の絶対値の和なので、打ち消しや 0 に近い分母のある関数では $|c_k|$ に対する相対誤差を別に確かめる。
`atan2`、`combine`、`exprel`、`sinc`、`sincpi`、`map_scalar` の高い係数は NaN になるので、必要なら係数の漸化式を持つ演算で同じ関数を書き直す。
導関数 $k!\,c_k$ に戻すと値が $k!$ 倍になるので、高い次数では係数のまま扱う。
