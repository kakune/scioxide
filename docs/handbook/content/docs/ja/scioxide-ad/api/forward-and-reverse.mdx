この表は関数を書くための数値型と、1 階の導関数を求める前進モードと逆モードの項目をまとめる。
数値型の演算はエラーを返さず、IEEE 754 に従って NaN と無限大をそのまま伝える。
エラーを返すのは点を受け取って結果を書く変換で、失敗したときは呼び出し側の出力を書き換えない。
ワンショット関数は新しいテープを作って結果を確保し、`Tape` のメソッドは呼び出し側の出力に書き、同じ関数を記録したテープでは確保しない。
表の項目名のリンクは、docs.rs の 0.1.0 の API リファレンスを指す。

## まとめ

関数は `R: Real` について一度だけ書き、値は `f64` か `Lanes`、1 方向の導関数は `Dual`、数方向は `MultiDual`、勾配は `Var` を記録する `Tape` で求める。
一度だけ微分するなら `grad`・`value_and_grad`・`vjp`・`jacobian`・`jvp` のワンショット呼び出しで足りる。
同じ関数を多くの点で微分するなら、`Tape` を 1 本作って `gradient_into` か `linearize` を繰り返し、`TapeReport` で記録の大きさと再記録の有無を確かめる。
テープに渡すクロージャは呼び出しの位置に書き、関数は決定論的にする。
