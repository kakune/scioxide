この表は2 階以上の導関数と、行列を作らずに導関数を掛ける作用素の項目をまとめる。
ヘッセ行列・ベクトル積は逆モードの勾配の計算を二重数の算術で行う方法（forward over reverse。
`Tape<Dual<f64>>` に記録する）で、勾配の小さな定数倍の計算コストで求まる。
疎なヘッセ行列と疎なヤコビ行列の復元は `Tape` と `Linearization` のメソッド（`hessian_pattern`、`sparse_hessian_into`、`sparse_jacobian_into`）で、表の `Tape` と `Linearization` の行と[構造パターンと疎な微分の復元](../../algorithms/sparse-derivatives/)にある。
表の項目名のリンクは、docs.rs の 0.1.0 の API リファレンスを指す。

## Taylor 係数

| 項目 | 種別 | 役割 | 仕様の要点 | 解説節 | 実行例 |
|---|---|---|---|---|---|
| [`Jet`](https://docs.rs/scioxide-ad/0.1.0/scioxide_ad/struct.Jet.html) | 構造体 | 正規化 Taylor 係数 $c_k = \frac{1}{k!}\frac{d^k x}{dt^k}$ の組 | `new`、`variable`、`coefficients`、`coefficient`（`k ≥ N` は `None`）。`N ≥ 1` はコンパイル時に検査する。非線形の演算は $O(N^2)$、線形の演算は $O(N)$ の演算。$c_0$ は `V` の演算とビットで一致する。精度は制限した点で $64\varepsilon(k+1)g$ に最小の非正規化数を足した値以内（8 次まで）。`atan2` と `combine`（`implicit_solution_into` を含む）は 1 階、`exprel`・`sinc`・`sincpi`・`map_scalar` は 2 階まで正確で、それより高い係数は NaN。入れ子の `Jet<Jet<V, M>, N>` は混合係数を持つ | [Jet 型](oxref:ad-jet-type)、[入れ子の Jet による混合係数](oxref:ad-nested-jets) | [既知の級数の正規化 Taylor 係数と誤差の上限](oxref:ad-taylor-exp-series)、[絶対零の積と IEEE 積による導関数の違い](oxref:ad-azmul-products)、[map_scalar と combine で与えた Φ の各数値型での導関数](oxref:ad-normal-cdf-rules) |

## まとめ

ヘッセ行列の作用 $Hv$ は `hvp` か `Tape<Dual<f64>>::hvp_into` で、勾配の小さな定数倍の計算コストで求まる。
密なヘッセ行列 `hessian` は方向ごとに 1 回記録するので、次元が大きければ作用か疎構造の彩色を使う。
反復解法には `HessianOperator` と `JacobianOperator` を渡し、適用ごとの確保をなくす。
1 本の直線に沿う高階の係数は `Jet` と `jet` で、総次数 2 を超える係数は `map_scalar` などを通ると NaN になることに注意する。
