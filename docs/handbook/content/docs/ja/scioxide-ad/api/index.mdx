`scioxide-ad` は、関数を数値型 `R: Real` について一度だけ書き、数値型と変換を選んで導関数を求めるクレートである。
公開されている 62 項目（トレイト 10、構造体 21、列挙型 7、関数 24）は、用途別の 4 つの表にまとめてある。
表の項目名のリンクは、docs.rs の 0.1.0 の API リファレンスを指す。
アルゴリズムと誤差の説明は[自動微分のアルゴリズム体系](../algorithms/)の各ページにあり、表の「解説節」と「実行例」の列から引ける。

## 目的別の API

| したいこと | API となる項目 | 表 |
|---|---|---|
| 関数を一度だけ書いて数値型を選ぶ | `Real`、`BaseReal`、`Mask` | [数値型・前進モード・逆モード](forward-and-reverse/) |
| 多数の点の値を SIMD でまとめて評価する | `Lanes`、`LaneMask` | [数値型・前進モード・逆モード](forward-and-reverse/) |
| 1 方向か数方向の導関数を求める | `Dual`、`MultiDual`、`jvp` | [数値型・前進モード・逆モード](forward-and-reverse/) |
| スカラー関数の勾配、VJP、ヤコビ行列を一度だけ求める | `grad`、`value_and_grad`、`vjp`、`jacobian` | [数値型・前進モード・逆モード](forward-and-reverse/) |
| 同じ関数を多くの点で微分する | `Tape`、`TapeOptions`、`Linearization`、`TapeReport` | [数値型・前進モード・逆モード](forward-and-reverse/) |
| ヘッセ行列か、その作用を求める | `hvp`、`hessian`、`HessianOperator` | [高階微分・Taylor 係数・作用素](higher-order-and-jets/) |
| ヤコビ行列を反復解法に渡す | `JacobianOperator` | [高階微分・Taylor 係数・作用素](higher-order-and-jets/) |
| 高階の Taylor 係数を求める | `Jet`、`jet` | [高階微分・Taylor 係数・作用素](higher-order-and-jets/) |
| 行列積、softmax、線形系の解を微分する | `gemm_into`、`softmax_into`、`solve_into` など | [構造化演算・ループ・独自規則](structures-and-control/) |
| 方程式の解の感度を求める | `implicit_solution_into`、`Residual` | [構造化演算・ループ・独自規則](structures-and-control/) |
| 長いループを少ないメモリで逆にたどる | `checkpointed_loop`、`LoopBody`、`CheckpointSchedule` | [構造化演算・ループ・独自規則](structures-and-control/) |
| `Real` で書けない部分に導関数を与える | `ExternalRule`（と `Real::map_scalar`、`Real::combine`） | [構造化演算・ループ・独自規則](structures-and-control/) |
| 複素数の関数を微分する | `ComplexElementary` | [構造化演算・ループ・独自規則](structures-and-control/) |

疎なヤコビ行列とヘッセ行列の構造パターンは scioxide-core の `StructuralPattern`、その彩色は scioxide-sparse の `derivative_coloring` が提供する。
複素数の型 `Complex` は scioxide-core にある。
関数の値しか得られない場合の差分による微分は scioxide-differentiate が提供する。

## 型の関係

- `Real` は数値型の sealed トレイトで、`f32`、`f64`、`Lanes`、`Dual`、`MultiDual`、`Jet`、`Var` が実装する。
  関連型 `Base` は最も内側の値（`f32`、`f64`、`Lanes`、トレイト `BaseReal`）、`Primal` は 1 段下の値、`Mask` は比較の結果（`bool` か `LaneMask`、トレイト `Mask`）である。
- `Dual`、`MultiDual`、`Jet` は任意の `Real` を包み、入れ子にできる。
  `Var<'t, V>` は `Tape<V>` に記録される値で、`V` はトレイト `TapeValue` を実装する型（スカラー、`Lanes` と、それらをラップする `Dual`、`MultiDual`、`Jet`）である。
  `Var` をラップする型はない。
- `Tape` は呼び出し側が所有し、`TapeOptions` で方針を選ぶ。
  `gradient_into` は勾配を、`linearize` は 1 点の記録 `Linearization` を返し、`Linearization` から積、構造パターン、`JacobianOperator` を得る。
  `Tape<Dual<S>>` は `hvp_into`、`sparse_hessian_into`、`HessianOperator` を持つ。
  `TapeRequirements` は記録の大きさ、`TapeReport` は直前の変換の事実である。
- ワンショット関数（`grad`、`value_and_grad`、`vjp`、`jacobian`、`hvp`、`hessian`）は新しいテープを作って結果を確保する。
  `jvp` と `jet` はテープを使わない前進モードのワンショット呼び出しである。
- `BatchPlan` は `BatchFunction` を `BatchData` の項目について足し、`BatchOutputs` に書き、`BatchEstimate` を返す。
  メモリは `BatchWorkspace` で、その大きさは `BatchRequirements` である。
  方式は `BatchOptions` の `DerivativeMode` で選び、使った方式が `BatchMode` で返る。
- 構造化演算（`dot` から `checkpointed_loop` まで）は自由関数で、すべての数値型で動く。
  呼び出し側の規則はトレイト `ExternalRule`、`Residual`、`LoopBody` で与える。

## 最小の実行例

同じ勾配を三つの形で求める。
ワンショット呼び出しの `value_and_grad`、呼び出し側が所有するテープの `Tape::gradient_into`、前進モードの `MultiDual<f64, 3>` である。
関数は 3 変数の拡張 Rosenbrock 関数

$$
f(x) = \sum_{i=0}^{1} \Bigl[(1 - x_i)^2 + 10\,(x_{i+1} - x_i^2)^2\Bigr]
$$

で、入力は第 1 成分 $x_0$（$-1.5$ から $1.5$、無次元）である。
残りの成分は $x_1 = 0.8$、$x_2 = 0.5$ に固定する。
表は形ごとの勾配の 3 成分、閉形式の勾配との差の最大値、テープを広げるために関数を 2 回記録したかを示す。
テープの形は同じテープで 2 回呼び、1 回目と 2 回目を別の行にする。

```rust
//| id: ad-api-gradient-forms
//| ref: ad-api-gradient-forms
//| title: 同じ勾配をワンショット呼び出し・テープ・前進モードで求める
//| run: reactive
//| crates: [scioxide-ad, scioxide-core]
//| inputs:
//|   first: {"type":"range","label":"第 1 成分 x₀","description":"勾配を求める点の第 1 成分（無次元）。x₁ = 0.8、x₂ = 0.5 は固定。","min":-1.5,"max":1.5,"step":0.1,"value":0.3}
//| cases:
//|   - {"id":"negative-start","label":"x₀ = −1.2","description":"勾配が大きい点でも三つの形の勾配は一致する。","inputs":{"first":-1.2}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"forms","path":"/rows/0/1","approx":{"value":-9.92,"rtol":1e-13}}
//|       - {"artifact":"forms","path":"/rows/0/4","range":{"max":1e-13}}
//|       - {"artifact":"forms","path":"/rows/1/4","range":{"max":1e-13}}
//|       - {"artifact":"forms","path":"/rows/2/4","range":{"max":1e-13}}
//|       - {"artifact":"forms","path":"/rows/3/4","range":{"max":1e-13}}
//|       - {"artifact":"forms","path":"/rows/1/5","equals":"あり"}
//|       - {"artifact":"forms","path":"/rows/2/5","equals":"なし"}
//|   - case: negative-start
//|     expect:
//|       - {"artifact":"forms","path":"/rows/0/4","range":{"max":1e-12}}
//|       - {"artifact":"forms","path":"/rows/3/4","range":{"max":1e-12}}
use scioxide_ad::{MultiDual, Real, Tape, TapeOptions, value_and_grad};
use scioxide_core::ExecutionContext;

// 拡張 Rosenbrock 関数を数値型 R について一度だけ書く。
fn rosenbrock<R: Real>(x: &[R]) -> R {
    x.windows(2)
        .map(|w| (-w[0] + 1.0).powi(2) + (w[1] - w[0] * w[0]).powi(2) * 10.0)
        .sum()
}

let point = [first, 0.8, 0.5];
// 独立な検算: 閉形式の勾配（f64 の算術）。
let exact = [
    -2.0 * (1.0 - point[0]) - 40.0 * point[0] * (point[1] - point[0] * point[0]),
    20.0 * (point[1] - point[0] * point[0])
        - 2.0 * (1.0 - point[1])
        - 40.0 * point[1] * (point[2] - point[1] * point[1]),
    20.0 * (point[2] - point[1] * point[1]),
];
let cx = ExecutionContext::sequential();
let mut rows = Vec::new();
let mut push = |name: &str, g: [f64; 3], twice: Option<bool>| {
    let error = (0..3).map(|i| (g[i] - exact[i]).abs()).fold(0.0, f64::max);
    let recorded = twice.map(|t| if t { "あり" } else { "なし" });
    rows.push((name.to_string(), g[0], g[1], g[2], error, recorded));
};

// ワンショット呼び出し: 新しいテープを作り、結果の Vector を確保する。
let (_, gradient) = value_and_grad(|x| Ok(rosenbrock(x)), &point).map_err(|e| e.to_string())?;
let g = gradient.as_slice();
push("value_and_grad（ワンショット呼び出し）", [g[0], g[1], g[2]], None);

// 呼び出し側のテープ: 1 回目は広げるために 2 回記録し、2 回目は確保しない。
let mut tape = Tape::<f64>::new(TapeOptions::new());
let mut g = [0.0; 3];
for name in [
    "Tape::gradient_into（1 回目）",
    "Tape::gradient_into（2 回目）",
] {
    tape.gradient_into(|x| Ok(rosenbrock(x)), &point, &mut g, cx)
        .map_err(|e| e.to_string())?;
    push(name, g, Some(tape.report().recorded_twice()));
}

// 前進モード: 3 方向の接ベクトルを 1 回の評価で保持する。
let mut x = [MultiDual::<f64, 3>::constant(0.0); 3];
for (i, xi) in x.iter_mut().enumerate() {
    *xi = MultiDual::variable(point[i], i).map_err(|e| e.to_string())?;
}
push(
    "MultiDual<f64, 3>（前進モード）",
    rosenbrock(&x).gradient(),
    None,
);

let value = serde_json::json!({ "significantDigits": 15 });
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let columns = serde_json::json!([
    { "key": "0", "label": "形" },
    { "key": "1", "label": "∂f/∂x₀ [-]", "type": "number", "format": value },
    { "key": "2", "label": "∂f/∂x₁ [-]", "type": "number", "format": value },
    { "key": "3", "label": "∂f/∂x₂ [-]", "type": "number", "format": value },
    { "key": "4", "label": "閉形式との差の最大 [-]", "type": "number", "format": sci3 },
    { "key": "5", "label": "2 回記録したか", "nullText": "テープを再利用しない" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "forms" })
);
```

既定の $x_0 = 0.3$ では、四つの行の勾配はどれも $(-9.92, 18.28, -2.8)$ で、閉形式との差は $2 \times 10^{-15}$ 以下である。
テープの 1 回目は空のテープに入りきらない文を数えてから広げ、関数をもう一度記録したので「あり」になる。
2 回目は同じ関数を同じ大きさで記録するので 1 回で済み、確保もしない。
ワンショット呼び出しの `value_and_grad` は呼ぶたびに新しいテープを作り、そのたびに関数を 2 回実行するので、繰り返し呼ぶ用途ではテープの形を選ぶ。
`MultiDual<f64, 3>` は 1 回の評価で 3 成分を求め、テープを使わない。

## 結果・エラー・診断の読み方

- 数値型の演算はエラーを返さない。
  定義域の外では IEEE 754 の結果（NaN か無限大）になり、それが導関数にも伝わる。
  検出したいときは `TapeOptions::with_non_finite_policy(NonFinitePolicy::Error)` を選ぶと、変換の境界で `NonFinite` になる。
- 変換と構造化演算の失敗は `SciOxideError` で返る。
  `kind()` で分類し（`DimensionMismatch`、`NonFinite`、`DomainError`、`Singular`、`InvalidInput`、`ResourceLimit`、`AllocationFailure`、`ExecutionStopped`、`CapabilityUnavailable` など）、`view()` で引数と理由を読む。
  関数や規則が返したエラーは、種類を変えずにそのまま返る。
- 変換が失敗したとき、呼び出し側の出力の領域は書き換えられない。
  一括の評価も、すべてのブロックが成功してから出力を書く。
- `TapeReport` は直前の変換の文の数、確保したバイト数、折れ点に当たった回数、再記録の有無を示す。
  `BatchEstimate` は値、標準誤差、方向微分、項目とブロックの数、使った方式、折れ点に当たった回数を示す。
- 自動微分の変換は反復を持たないので、終了状態や収束の判定はない。
  陰関数の微分は、呼び出し側が求めた解の残差を許容誤差で確かめ、満たさなければ `InvalidInput` を返す。

## まとめ

関数は `R: Real` について一度だけ書き、求める導関数に合わせて数値型と変換を選ぶ。
一度だけ微分するならワンショット関数、同じ関数を何度も微分するならテープと出力の領域を再利用する形を使う。
失敗は `SciOxideError` の `kind()` で分類でき、失敗したときは出力が書き換えられない。
項目の仕様の詳細は用途別の表、アルゴリズムと誤差は表の「解説節」の列から引く。
