この表は変換の境界で効く方針と、多数の独立な項目の和と平均を評価する一括の項目をまとめる。
方針は `TapeOptions` と `BatchOptions` で選び、数値型の演算そのものはつねに IEEE 754 に従う。
`BatchPlan` は勾配を求めるかどうかで値・前進・逆モードを選び、どの方式でも値は同じビットになる。
wasm ではスレッドを使えないので、本書のセルは逐次の実行だけを示す。
表の項目名のリンクは、docs.rs の 0.1.0 の API リファレンスを指す。

## まとめ

非有限値を早く検出したいときは `NonFinitePolicy::Error`、折れ点を通る点を拒みたいときは `KinkPolicy::Error` を選ぶ。
多数の項目の和や平均は `BatchPlan` に `BatchFunction` を渡して評価し、勾配は `BatchOutputs` で求める。
`Mean` では標準誤差が返り、勾配の標準誤差は 2 ブロック以上のブロック平均から推定される。
作業領域は `workspace` で一度作り、同じ Plan で繰り返し使う。
