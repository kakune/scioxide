この表の関数はすべての数値型で動き、`f64` でも `Dual` でも `Var` でも同じ呼び出しで使える。
行列は行優先の平らなスライスで渡し、出力は呼び出し側が用意する（名前が `_into` で終わる関数）。
テープの上では、`dot` と `gemv_into`・`gemm_into` の各内積が 1 文、`solve_into`・`checkpointed_loop`・`Var::external` が呼び出しの文 1 つになり、`cholesky_into`・`qr_into`・`least_squares_into` はアルゴリズムの演算をそのまま記録する。
表の項目名のリンクは、docs.rs の 0.1.0 の API リファレンスを指す。

## まとめ

行列積と内積は `dot`・`gemv_into`・`gemm_into` で書くと、テープの文が内積ごとに 1 つで済む。
線形系の解は `solve_into` で、消去を微分せずに因子を導関数の成分に適用する。
方程式の解の感度は解を別に求めてから `implicit_solution_into` に渡す。
長いループの勾配でメモリが足りないときは `checkpointed_loop` と `CheckpointSchedule` を使い、`Real` で書けない部分は `map_scalar` か `ExternalRule` で導関数を与える。
