オプションの価格が市場の変数にどう反応するかを表す偏微分を、グリークス（Greeks）と呼ぶ。
原資産価格についての 1 階微分 Δ と 2 階微分 Γ は、ヘッジに必要な原資産の量とその変わりやすさを表す。
ボラティリティ・期間・金利についての微分 ν、Θ、ρ は、それぞれの変数に対する価格の感度を表す。

この例題ではヨーロピアン・コールの Black–Scholes 価格を `R: Real` の汎用関数として一度だけ書き、前進モードの `MultiDual` で 1 階、`hessian` で 2 階の指標を求めて、閉形式とプット・コール・パリティで確かめる。
価格に現れる標準正規分布の累積分布関数（CDF）$\Phi$ は、scioxide-special の値と、利用者が与える微分の規則で組み込む。
同じ価格を Monte Carlo 法の経路ごとに微分して推定する方法は [経路ごとの微分による Monte Carlo のグリークス](../black-scholes-monte-carlo/) で扱い、そこではこのページの閉形式を検算に使う。

## Black–Scholes 式

原資産価格が一定のボラティリティ $\sigma$ の幾何 Brown 運動に従い、無リスク金利 $r$ が一定で配当がなく、満期にだけ行使できる（ヨーロピアン）と仮定する。
行使価格 $K$、満期までの期間 $T$ のコールとプットの価格は次の式で与えられる。

$$
C = S\,\Phi(d_1) - K e^{-rT}\Phi(d_2),\quad
P = K e^{-rT}\Phi(-d_2) - S\,\Phi(-d_1),\quad
d_1 = \frac{\ln(S/K) + (r + \sigma^2/2)\,T}{\sigma\sqrt T},\quad d_2 = d_1 - \sigma\sqrt T
$$

単位は、$S, K, C, P$ が通貨、$T$ が年、$r$ が連続複利の年率（1/年）、$\sigma$ が年率のボラティリティ（1/√年。
$\sigma^2 T$ が無次元）である。

プット・コール・パリティ $C - P = S - K e^{-rT}$ は裁定の議論からモデルによらず成り立ち、上の式では $\Phi(x) + \Phi(-x) = 1$ から確かめられる。

## グリークスと Θ の符号

入力 $z = [S, \sigma, T, r]$ についての偏微分として、グリークスとコールの閉形式は次のとおりである（$\varphi$ は標準正規分布の密度）。

| 指標 | 定義 | コールの閉形式 |
|---|---|---|
| Δ | $\partial C/\partial S$ | $\Phi(d_1)$ |
| Γ | $\partial^2 C/\partial S^2$ | $\varphi(d_1)/(S\sigma\sqrt T)$ |
| ν | $\partial C/\partial\sigma$ | $S\varphi(d_1)\sqrt T$ |
| Θ | $-\partial C/\partial T$ | $-S\varphi(d_1)\sigma/(2\sqrt T) - rKe^{-rT}\Phi(d_2)$ |
| ρ | $\partial C/\partial r$ | $KTe^{-rT}\Phi(d_2)$ |
| vanna | $\partial^2 C/\partial S\,\partial\sigma$ | $-\varphi(d_1)\,d_2/\sigma$ |
| volga | $\partial^2 C/\partial\sigma^2$ | $S\varphi(d_1)\sqrt T\,d_1 d_2/\sigma$ |

1 階の閉形式が簡単になるのは、$S\varphi(d_1) = K e^{-rT}\varphi(d_2)$ によって $d_1, d_2$ の微分を含む項が打ち消し合うからである。
たとえば $\partial C/\partial S = \Phi(d_1) + S\varphi(d_1)\,\partial_S d_1 - K e^{-rT}\varphi(d_2)\,\partial_S d_2$ で、$\partial_S d_1 = \partial_S d_2$ なので後の 2 項が消える。

Θ の符号には規約がある。
Θ は暦の上の時刻 $t$ についての変化率 $\partial V/\partial t$ で、満期日 $T_{\mathrm{exp}}$ を固定すると残りの期間は $T = T_{\mathrm{exp}} - t$ なので $\Theta = -\partial V/\partial T$ になる。
AD に渡す入力は残りの期間 $T$ なので、勾配の第 3 成分 $\partial C/\partial T$ の符号を反転して Θ とする。
ここでの Θ は 1 年あたりの値で、1 日あたりにするには 365（または年間の取引日数）で割る。
同様に ν と ρ は $\sigma$、$r$ が 1（100 % ポイント）変わったときの変化率で、1 % ポイントあたりの値は 100 で割る。

## Φ を `try_map_scalar` で組み込む

`Real` の初等関数は指数・対数・三角関数・双曲線関数・softplus・sigmoid などを持つが、誤差関数と正規分布の CDF は持たない。
そこで `Real::try_map_scalar` を使い、スカラーの関数を値と 1 階・2 階の微分の組 $[f(x), f'(x), f''(x)]$ として与える。
$\Phi$ では $[\Phi(x), \varphi(x), -x\varphi(x)]$ を返す。
`Dual`、`MultiDual`、`Var`、`Var<Dual>`、`Dual<Dual>` は、この組から合計 2 階までの微分を正しく組み立てる。
それより深い成分（`Jet` の 3 次以上の係数など）は NaN になるので、この関数で 3 階の微分は求められない。
規則はレーン（lane、`Lanes` の SIMD の 1 要素）ごとに 1 回呼ばれ、決定論的でなければならない。
`try_map_scalar` は規則が返した最初のエラーをそのまま返す（[スカラー関数の微分規則](../../algorithms/custom-primitives/)）。

値は scioxide-special の `normal_cdf` が返す。
この関数は $\Phi(x) = \tfrac12\operatorname{erfc}(-x/\sqrt2)$ の各裾を直接計算し、`f64` では $-38 \le x \le 38$ で誤差 8 ulp 以内という精度の保証を持つ。
非有限の引数には `NonFinite` を返し、そのエラーが価格の関数から呼び出し側へ伝わる。
$\varphi$ は `scioxide_core` の `RealScalar::exp` で計算する。

AD はこの規則と ln、√、exp、積を連鎖律でつなぎ、閉形式の約分を使わずにグリークスを組み立てる。
閉形式の検算は同じ `normal_cdf` で $\Phi(d_1)$、$\Phi(d_2)$ を求めて表の公式に代入するので、両者は $\Phi$ の値を共有する。
したがって比較で確かめられるのは連鎖律による組み立てと微分の規則で、$\Phi$ そのものの精度ではない。

## 前進モードの `MultiDual` とヘッセ行列

1 階の指標は前進モード（forward mode）の `MultiDual<f64, 4>` で求める。
`MultiDual<V, N>` は値 $v$ と $N$ 本の方向微分 $(\dot v_0, \dots, \dot v_{N-1})$ を持つ数である。
入力の配列 $z = [S, \sigma, T, r]$ を `MultiDual::<f64, 4>::variables(z)` に渡すと、要素 $k$ が値 $z_k$ で $k$ 番目の接ベクトルだけが 1 の独立変数になり、関数を 1 回評価すると `gradient()` が 4 つの偏微分を返す。
`variables` は配列の長さが $N$ に決まっているので失敗せず、一部の方向だけにシードを置くときの `MultiDual::variable(z_k, k)` は方向の番号が $N$ 以上なら `OutOfBounds` を返す。
各成分は `Dual` で 1 方向ずつ 4 回評価した結果とビットまで一致し、値の計算は 1 回で済む。
入力が数個なら前進モードが安く、4 個程度を超えると逆モードのほうが安くなる（[前進モードと二重数](../../algorithms/forward-mode/)）。

2 階の指標は `hessian` で求める。
`hessian` は関数を `Var<Dual<f64>>` の上に単位方向ごとに 1 回ずつ記録し、行優先の $4\times 4$ 行列を返す（[二階微分とヘッセ行列の作用素](../../algorithms/second-order-derivatives/)）。
新しいテープでは最初の方向で文の数を数えるためにもう 1 回実行するので、関数の実行は 5 回である。
Γ、vanna、volga はその $(S,S)$、$(S,\sigma)$、$(\sigma,\sigma)$ 成分である。
価格の関数は `Result` を返すので、クロージャは `|x| price(x, strike, 1.0)` とそのまま渡せる。

次のブロックは 2 つのセルが共有する定義である。
`normal_pdf` が $\varphi$、`normal_cdf` が規則付きの $\Phi$、`price` が符号 $s$ 付きの価格 $V = s\,[S\Phi(s d_1) - Ke^{-rT}\Phi(s d_2)]$（$s = 1$ でコール、$s = -1$ でプット）に対応する。

```rust
//| id: ad-bs-model
//| kind: definitions
//| title: Black–Scholes 価格と正規分布の CDF
//| crates: [scioxide-ad, scioxide-core, scioxide-special]
use scioxide_ad::Real;
use scioxide_core::{SciOxideError, RealScalar};

/// 標準正規分布の密度 φ(x) = exp(−x²/2)/√(2π)。
pub(crate) fn normal_pdf(x: f64) -> f64 {
    RealScalar::exp(-0.5 * x * x) / RealScalar::sqrt(2.0 * core::f64::consts::PI)
}

/// Φ(x)。値は scioxide-special の normal_cdf、微分の規則は Φ′ = φ、Φ″ = −xφ。
pub(crate) fn normal_cdf<R: Real>(x: R) -> Result<R, SciOxideError> {
    x.try_map_scalar(|v| {
        let density = normal_pdf(v);
        Ok([scioxide_special::normal_cdf(v)?, density, -v * density])
    })
}

/// V = s·[S Φ(s d₁) − K e^{−rT} Φ(s d₂)]（s = 1 でコール、s = −1 でプット）。z = [S, σ, T, r]。
pub(crate) fn price<R: Real>(z: &[R], strike: f64, sign: f64) -> Result<R, SciOxideError> {
    let (spot, vol, maturity, rate) = (z[0], z[1], z[2], z[3]);
    let vol_sqrt_t = vol * maturity.sqrt();
    let d1 = ((spot / strike).ln() + (rate + vol * vol * 0.5) * maturity) / vol_sqrt_t;
    let d2 = d1 - vol_sqrt_t;
    let discounted_strike = (-(rate * maturity)).exp() * strike;
    let value = spot * normal_cdf(d1 * sign)? - discounted_strike * normal_cdf(d2 * sign)?;
    Ok(value * sign)
}
```

## グリークスの照合

次のセルは $S$、$K$（50〜150 通貨）、$\sigma$（0.05〜0.8 /√年）、$T$（0.05〜3 年）、$r$（0〜0.1 /年）を入力に、コールの価格と 7 つの指標を AD と閉形式で求めて比べる。
相対差は $|\mathrm{AD} - \text{閉形式}|/|\text{閉形式}|$ で、閉形式が 0 のときは「定義なし」と表示する。
閉形式の ln、exp、√ は `f64` の標準関数で計算した参照値である。
このセルは入力と、コールの AD の値（価格と 5 つの指標）を次のセルに渡す。

```rust
//| id: ad-bs-greeks
//| ref: ad-bs-greeks
//| title: コールの価格を MultiDual と hessian で微分してグリークスを閉形式と比べる
//| run: reactive
//| uses: [ad-bs-model]
//| crates: [scioxide-ad, scioxide-core, scioxide-special]
//| exports: [market, call]
//| inputs:
//|   spot: {"type":"range","label":"原資産価格 S [通貨]","min":50,"max":150,"step":1,"value":100}
//|   strike: {"type":"range","label":"行使価格 K [通貨]","min":50,"max":150,"step":1,"value":100}
//|   vol: {"type":"range","label":"ボラティリティ σ [1/√年]","description":"年率の対数収益率の標準偏差。","min":0.05,"max":0.8,"step":0.01,"value":0.2}
//|   maturity: {"type":"range","label":"満期までの期間 T [年]","min":0.05,"max":3,"step":0.05,"value":1}
//|   rate: {"type":"range","label":"金利 r [1/年]","description":"連続複利の無リスク金利。","min":0,"max":0.1,"step":0.005,"value":0.05}
//| cases:
//|   - {"id":"deep-in","label":"S = 130, K = 90, σ = 0.35, T = 0.25, r = 0.03","description":"深いイン・ザ・マネーでは Δ が 1 に近づく。","inputs":{"spot":130,"strike":90,"vol":0.35,"maturity":0.25,"rate":0.03}}
//|   - {"id":"forward-like","label":"S = 150, K = 50, σ = 0.05, T = 0.05","description":"d₁ が大きく、Γ と ν が 0 に丸められる。","inputs":{"spot":150,"strike":50,"vol":0.05,"maturity":0.05}}
//|   - {"id":"long-volatile","label":"σ = 0.8, T = 3, r = 0","description":"d₁ と d₂ の符号が分かれ、volga が負になる。","inputs":{"vol":0.8,"maturity":3,"rate":0}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"greeks","path":"/rows/0/2","approx":{"value":10.450583572185565,"rtol":1e-13}}
//|       - {"artifact":"greeks","path":"/rows/1/2","approx":{"value":0.6368306511756191,"rtol":1e-13}}
//|       - {"artifact":"greeks","path":"/rows/2/4","range":{"max":1e-14}}
//|       - {"artifact":"greeks","path":"/rows/3/4","range":{"max":1e-14}}
//|       - {"artifact":"greeks","path":"/rows/4/4","range":{"max":1e-14}}
//|       - {"artifact":"greeks","path":"/rows/5/4","range":{"max":1e-14}}
//|       - {"artifact":"greeks","path":"/rows/7/4","range":{"max":1e-14}}
//|   - case: deep-in
//|     expect:
//|       - {"artifact":"greeks","path":"/rows/1/2","approx":{"value":0.9871806700826756,"rtol":1e-13}}
//|       - {"artifact":"greeks","path":"/rows/2/4","range":{"max":1e-13}}
//|   - case: forward-like
//|     expect:
//|       - {"artifact":"greeks","path":"/rows/2/4","equals":null}
//|       - {"artifact":"greeks","path":"/rows/4/2","approx":{"value":-2.49375780599365,"rtol":1e-13}}
//|       - {"artifact":"greeks","path":"/rows/5/2","approx":{"value":2.49375780599365,"rtol":1e-13}}
//|   - case: long-volatile
//|     expect:
//|       - {"artifact":"greeks","path":"/rows/6/2","approx":{"value":0.2717753238096447,"rtol":1e-12}}
//|       - {"artifact":"greeks","path":"/rows/7/2","approx":{"value":-32.61303885715736,"rtol":1e-12}}
use scioxide_ad::{MultiDual, hessian};

let z = [spot, vol, maturity, rate];
// 前進モード: 4 入力に単位の接ベクトルを持たせ、1 回の評価で勾配を得る。
let point = MultiDual::<f64, 4>::variables(z);
let call = price(&point, strike, 1.0).map_err(|e| e.to_string())?;
let [delta, vega, dc_dt, rho] = call.gradient();
// 2 階: 行優先の 4×4 ヘッセ行列（単位方向ごとに 1 回の記録）。
let h = hessian(|x| price(x, strike, 1.0), &z).map_err(|e| e.to_string())?;
let h = h.as_slice();

// 独立な検算: グリークスの閉形式（Φ は scioxide-special、ln・exp・√ は f64 の参照値）。
let n = |x: f64| scioxide_special::normal_cdf(x).map_err(|e| e.to_string());

let d1 = ((spot / strike).ln() + (rate + 0.5 * vol * vol) * maturity) / (vol * st);
let d2 = d1 - vol * st;
let disc = (-rate * maturity).exp();
let pdf = normal_pdf(d1);
let closed = [
    spot * n(d1)? - strike * disc * n(d2)?,
    n(d1)?,
    pdf / (spot * vol * st),
    spot * pdf * st,
    -spot * pdf * vol / (2.0 * st) - rate * strike * disc * n(d2)?,
    strike * maturity * disc * n(d2)?,
    -pdf * d2 / vol,
    spot * pdf * st * d1 * d2 / vol,
];
// Θ = −∂C/∂T（残りの期間 T についての微分の符号を反転する）。
let ad = [call.value(), delta, h[0], vega, -dc_dt, rho, h[1], h[5]];
let names = [
    ("価格 C", "通貨"),
    ("Δ = ∂C/∂S", "1"),
    ("Γ = ∂²C/∂S²", "1/通貨"),
    ("ν = ∂C/∂σ", "通貨·√年"),
    ("Θ = −∂C/∂T", "通貨/年"),
    ("ρ = ∂C/∂r", "通貨·年"),
    ("vanna = ∂²C/∂S∂σ", "√年"),
    ("volga = ∂²C/∂σ²", "通貨·年"),
];
let rows: Vec<(&str, &str, f64, f64, Option<f64>)> = names
    .iter()
    .zip(ad.iter().zip(&closed))
    .map(|(&(name, unit), (&a, &c))| {
        let relative = (c != 0.0).then(|| (a - c).abs() / c.abs());
        (name, unit, a, c, relative)
    })
    .collect();
let digits = serde_json::json!({ "significantDigits": 10 });
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let columns = serde_json::json!([
    { "key": "0", "label": "指標" },
    { "key": "1", "label": "単位" },
    { "key": "2", "label": "AD", "type": "number", "format": digits },
    { "key": "3", "label": "閉形式", "type": "number", "format": digits },
    { "key": "4", "label": "相対差", "type": "number", "format": sci2, "nullText": "定義なし" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "greeks" })
);
export!(market, &[spot, strike, vol, maturity, rate]);
export!(call, &ad[..6].to_vec());
```

既定の入力（$S = K = 100$、$\sigma = 0.2$、$T = 1$、$r = 0.05$）では $C = 10.4506$、$\Delta = 0.63683$、$\Gamma = 0.018762$、$\nu = 37.524$、$\Theta = -6.4140$ /年、$\rho = 53.232$ で、相対差はすべて $5.4\times 10^{-16}$ 以下である。
Θ を 365 で割ると 1 日あたり $-0.0176$ 通貨で、他の変数が動かなくても時間の経過だけでコールの価値が減ることを表す。

$S = 130$、$K = 90$、$\sigma = 0.35$、$T = 0.25$、$r = 0.03$ の深いイン・ザ・マネーでは $\Delta = 0.98718$ となり、Γ の相対差は $7.2\times 10^{-15}$ に増える。
AD は $S\varphi(d_1) = Ke^{-rT}\varphi(d_2)$ による約分を使わずに、打ち消し合う項を別々に計算して足す。
それらの項が結果より 1 桁ほど大きいと、丸め誤差の相対値もその分大きくなる。
それでも差は丸めの水準で、差分近似のような刻みに依存する打ち切り誤差は含まない。

$S = 150$、$K = 50$、$\sigma = 0.05$、$T = 0.05$ では $d_1$ が約 98 になり、$\Phi(d_1) = 1$、$\varphi(d_1) = 0$ に丸められて $\Delta = 1$、$\Gamma = \nu = 0$ になり、vanna と volga とともに相対差は「定義なし」と表示される。
残る $\Theta = -rKe^{-rT} = -2.4938$ /年と $\rho = KTe^{-rT} = 2.4938$ は、コールが受渡価格 $K$ の先渡し仕様と同じように振る舞うことを示す。
$\sigma = 0.8$、$T = 3$、$r = 0$ では $d_1 = 0.693$、$d_2 = -0.693$ と符号が分かれるので、volga $= -32.61$ が負、vanna $= 0.2718$ が正になる。

## プット・コール・パリティの微分

パリティ $C - P = S - Ke^{-rT}$ を $z$ の各成分で微分すると、$\Delta_C - \Delta_P = 1$、$\Gamma_C = \Gamma_P$、$\nu_C = \nu_P$、$\Theta_C - \Theta_P = -rKe^{-rT}$、$\rho_C - \rho_P = KTe^{-rT}$ が得られる。
右辺は $\Phi$ を含まないので、コールとプットをそれぞれ AD で微分した結果の差と比べれば、グリークスの閉形式を使わない検算になる。

次のセルは前のセルの入力とコールの値（前進モード）を受け取り、プットを逆モードで微分する。
価格の関数の符号を $s = -1$ にして、`value_and_grad` で価格と 1 階の指標を、`hessian` で Γ を求める。
`value_and_grad` は新しいテープに関数を記録し、余接 1 で 1 回逆走査して値と勾配を返す（[逆モードとテープ](../../algorithms/reverse-mode-and-replay/)）。
新しいテープなので、関数は文を数える実行と記録する実行の 2 回呼ばれる。
コールとプットを別の方式で微分するので、この検算は前進モードと逆モードの一致も確かめる。

```rust
//| id: ad-bs-parity
//| ref: ad-bs-parity
//| title: プット・コール・パリティの微分を前進モードのコールと逆モードのプットで確かめる
//| run: reactive
//| uses: [ad-bs-model]
//| crates: [scioxide-ad, scioxide-core, scioxide-special]
//| dependsOn:
//|   greeks: ad-bs-greeks
//| tests:
//|   - case: default
```

前のセルの入力を $S = 130$、$K = 90$、$\sigma = 0.35$、$T = 0.25$、$r = 0.03$ にすると、Θ の関係の差が $-1.3\times 10^{-15}$、ν の関係の差が $8.9\times 10^{-16}$ で、ほかの差は 0 である。
$S = 60$、$K = 140$、$\sigma = 0.05$、$T = 0.05$ の深いアウト・オブ・ザ・マネーでは、コールの価格と指標はすべて 0 に丸められるが、パリティの関係はプット側の値（$\Delta_P = -1$ など）で差 0 のまま保たれる。

## まとめ

`Real` にない関数は `try_map_scalar` で値と 1 階・2 階の微分の組を与えれば、価格の関数の中で他の演算と同じように微分でき、2 階までの微分は正しく組み立てられる。
入力が 4 個の価格では、`MultiDual<f64, 4>` の 1 回の評価で Δ、ν、Θ、ρ を、`hessian` で Γ、vanna、volga を得られ、閉形式との相対差は丸めの水準（試した入力では $1.1\times 10^{-14}$ 以下）にとどまる。
AD の入力は残りの期間 $T$ なので、暦の上の時刻についての Θ は勾配の第 3 成分の符号を反転して得る。
閉形式と比べる検算は $\Phi$ の値を共有するので、$\Phi$ の精度ではなく連鎖律による組み立てを確かめるものとして読み、プット・コール・パリティのように $\Phi$ を含まない関係で補う。
