Lagrange 形式の力学では、一般化座標 $\theta$ と一般化速度 $\dot\theta$ の関数としてラグランジアン $L(\theta, \dot\theta) = T - V$ を書けば、運動方程式は Euler–Lagrange 方程式から決まる。
運動方程式に現れるのは $L$ の 1 階と 2 階の偏微分で、自由度が増えると三角関数の積を手で微分して整理する作業が長くなり、誤りも入りやすい。
自動微分（automatic differentiation、AD）を使うと、$L$ を計算する関数を一つ書くだけで、それらの偏微分が差分の打ち切り誤差なしに得られる（丸め誤差は残る）。

この例題では二重振り子の運動方程式の各項を `grad`、`hessian`、`hvp` で求めて手で導いた閉形式と比べる。
続いて、同じラグランジアンを再利用するテープで微分して運動方程式を組み立て、陽的 Runge–Kutta 法で積分して全エネルギーの保存を確かめる。

## 二重振り子のモデル

固定点から長さ $l_1$ の質量のない棒で質点 $m_1$ を吊り、その質点から長さ $l_2$ の棒で質点 $m_2$ を吊る。
各棒が鉛直下向きとなす角を $\theta_1, \theta_2$（反時計回りを正）とすると、質点の位置は $x_1 = l_1\sin\theta_1$、$y_1 = -l_1\cos\theta_1$、$x_2 = x_1 + l_2\sin\theta_2$、$y_2 = y_1 - l_2\cos\theta_2$ である。
これを時間で微分して速度の 2 乗を足すと、運動エネルギー $T$ と、固定点の高さを基準とする位置エネルギー $V$ は次の式になる。

$$
T = \tfrac12\,\dot\theta^{\mathsf T} M(\theta)\,\dot\theta,\quad
M(\theta) = \begin{bmatrix} (m_1+m_2)\,l_1^2 & m_2 l_1 l_2\cos(\theta_1-\theta_2) \\ m_2 l_1 l_2\cos(\theta_1-\theta_2) & m_2 l_2^2 \end{bmatrix},\quad
V = -(m_1+m_2)\,g\,l_1\cos\theta_1 - m_2\,g\,l_2\cos\theta_2
$$

$M(\theta)$ は質量行列で、$\det M = m_2 l_1^2 l_2^2\,\bigl(m_1 + m_2\sin^2(\theta_1-\theta_2)\bigr) > 0$ なので、どの $\theta$ でも正定値である。

数値例では $m_1 = 1$ kg、$l_1 = 1$ m、$g = 9.80665$ m/s² に固定し、質量比 $\mu = m_2/m_1$ と長さの比 $\lambda = l_2/l_1$ を操作入力にする。
エネルギーの単位は J、$\partial L/\partial\theta$ のような一般化力の単位は N·m、質量行列の単位は kg·m² である。

## ラグランジアンの微分としての運動方程式

Euler–Lagrange 方程式 $\frac{d}{dt}\frac{\partial L}{\partial\dot\theta} - \frac{\partial L}{\partial\theta} = 0$ の第 1 項は、$\partial L/\partial\dot\theta$ が $\theta$ と $\dot\theta$ の関数なので、連鎖律で $\frac{\partial^2 L}{\partial\dot\theta^2}\ddot\theta + \frac{\partial^2 L}{\partial\dot\theta\,\partial\theta}\dot\theta$ と展開できる。
ここで $\partial^2 L/\partial\dot\theta\,\partial\theta$ は $(i, k)$ 成分が $\partial^2 L/\partial\dot\theta_i\partial\theta_k$ の行列である。
$T$ は $\dot\theta$ の 2 次形式で $V$ は $\dot\theta$ によらないので、$\partial^2 L/\partial\dot\theta^2 = M(\theta)$ が成り立つ。
さらに $\partial L/\partial\dot\theta = M(\theta)\dot\theta$ から $\bigl(\partial^2 L/\partial\dot\theta\,\partial\theta\bigr)\dot\theta = \sum_k (\partial M/\partial\theta_k)\,\dot\theta_k\,\dot\theta = \dot M\dot\theta$ となり、運動方程式は

$$
M(\theta)\,\ddot\theta = \frac{\partial L}{\partial\theta} - \dot M\dot\theta
$$

と書ける。
左辺の $M$ と右辺の各項はどれも $L$ の 1 階・2 階の偏微分で、$M$ が正定値なので、この連立 1 次方程式は $\ddot\theta$ について一意に解ける。

独立な検算のため、各項を手で導いておく。
$\Delta = \theta_1 - \theta_2$、$k = m_2 l_1 l_2$ とすると

$$
\frac{\partial L}{\partial\theta} = \begin{bmatrix} -k\,\dot\theta_1\dot\theta_2\sin\Delta - (m_1+m_2)\,g\,l_1\sin\theta_1 \\ k\,\dot\theta_1\dot\theta_2\sin\Delta - m_2\,g\,l_2\sin\theta_2 \end{bmatrix},\qquad
\dot M\dot\theta = -k\sin\Delta\,(\dot\theta_1-\dot\theta_2)\begin{bmatrix} \dot\theta_2 \\ \dot\theta_1 \end{bmatrix}
$$

である。
角加速度はこれらを代入して $M$ の逆行列を掛け、分母を $l_i(2m_1 + m_2 - m_2\cos 2\Delta)$ にそろえた閉形式と比べる。

## 微分の API の分担と計算コスト

入力を $z = [\theta_1, \theta_2, \dot\theta_1, \dot\theta_2]$ の 4 成分とし、スカラー $L(z)$ を返す関数を `R: Real` について一度だけ書く。
`Real` は `f64`、前進モードの `Dual`、逆モードの `Var` などの数値型が共通に満たすトレイトで、同じ関数が呼び出し側の選んだ数値型で評価され、微分される（[数値型・lane・汎用コード](../../algorithms/number-types-and-lanes/)）。
運動方程式の各項はこの関数に次のワンショット関数を適用して取り出す。

| 運動方程式の項 | API | 返り値のうち使う部分 |
|---|---|---|
| $\partial L/\partial\theta$ | `grad` | $\nabla_z L$ の前半 2 成分 |
| $M(\theta) = \partial^2 L/\partial\dot\theta^2$ | `hessian` | 行優先の $4\times 4$ 行列 $H = \nabla_z^2 L$ の右下の $2\times 2$ ブロック |
| $\dot M\dot\theta = (\partial^2 L/\partial\dot\theta\,\partial\theta)\,\dot\theta$ | `hvp`（方向 $u = [\dot\theta; 0]$） | $Hu$ の後半 2 成分 |

`grad` は新しいテープ（tape、演算を記録する列）に $L$ の評価を記録し、出力の随伴（adjoint）$\bar L = 1$ から逆向きに 1 回走査して勾配を返す。
スカラー出力の勾配の計算コストは $L$ の評価の定数倍で、入力の次元によらない（[逆モードとテープ](../../algorithms/reverse-mode-and-replay/)）。

`hvp` はヘッセ行列・ベクトル積（Hessian-vector product、HVP）$Hu$ を返す。
入力を $\mathrm{Dual}(z_i, u_i)$ として `Var<Dual<f64>>` の上に記録し、逆走査を 1 回行うと、随伴の値の部分が勾配、微分の部分が $Hu$ になる（forward-over-reverse）。
`hessian` は 1 本のテープで単位方向ごとにこの記録と走査を繰り返すので、$n$ 入力の密なヘッセ行列は $n$ 回の記録を使う（[二階微分とヘッセ行列の作用素](../../algorithms/second-order-derivatives/)）。
新しいテープでの最初の記録は文の数を数えるために関数を 1 回余分に実行するので、関数の実行は $n + 1$ 回になる。
$M$ は $\dot\theta$ 方向の $2\times 2$ 成分がすべて要るのでヘッセ行列の列を並べ、$\dot M\dot\theta$ は 1 本のベクトルなので HVP 1 本で足りる。

3 つの関数はどれも呼び出しごとに新しいテープを作り、結果を `scioxide_linalg` の `Vector` または `Matrix` として確保して返す。
時間積分のように多数の点で同じ $L$ を微分するときは、テープを一度作って使い回す（[一つの走査で勾配と 3 本の HVP を得る](#一つの走査で勾配と-3-本の-hvp-を得る)）。

次のブロックは 2 つのセルが共有する定義である。
`Pendulum` が質量と長さ、`lagrangian` が $L(z) = T - V$ に対応する。
係数の `f64` は演算子の右に置き、同じ式が `f64`、`Var<f64>`、`Var<Dual<f64>>`、2 つ目のセルの `Var<MultiDual<f64, 3>>` のどれでも評価できるようにしている。

```rust
//| id: ad-pendulum-model
//| kind: definitions
//| title: 二重振り子のラグランジアン
//| crates: [scioxide-ad]
use scioxide_ad::Real;

/// 標準重力加速度 g [m/s²]。
pub(crate) const G: f64 = 9.80665;

/// 質量 m₁、m₂ [kg] と棒の長さ l₁、l₂ [m]。
#[derive(Clone, Copy)]
pub(crate) struct Pendulum {
    pub(crate) m1: f64,
    pub(crate) m2: f64,
    pub(crate) l1: f64,
    pub(crate) l2: f64,
}

/// L(z) = T − V。z = [θ₁, θ₂, θ̇₁, θ̇₂]（rad、rad/s）、値の単位は J。
pub(crate) fn lagrangian<R: Real>(z: &[R], p: &Pendulum) -> R {
    let (t1, t2, w1, w2) = (z[0], z[1], z[2], z[3]);
    let coupling = p.m2 * p.l1 * p.l2;
    // T = ½(m₁ + m₂)l₁²θ̇₁² + ½m₂l₂²θ̇₂² + m₂l₁l₂ cos(θ₁ − θ₂) θ̇₁θ̇₂
    let kinetic = w1 * w1 * (0.5 * (p.m1 + p.m2) * p.l1 * p.l1)
        + w2 * w2 * (0.5 * p.m2 * p.l2 * p.l2)
        + w1 * w2 * (t1 - t2).cos() * coupling;
    // −V = (m₁ + m₂) g l₁ cos θ₁ + m₂ g l₂ cos θ₂
    let minus_potential = t1.cos() * ((p.m1 + p.m2) * G * p.l1) + t2.cos() * (p.m2 * G * p.l2);
    kinetic + minus_potential
}
```

## 運動方程式の各項の照合

次のセルは質量比 $\mu$、長さの比 $\lambda$、角度 $\theta_1, \theta_2$（$-180°$ から $180°$）を入力に、上の 3 つの API で $M$、$\partial L/\partial\theta$、$\dot M\dot\theta$ を求め、$M\ddot\theta = \partial L/\partial\theta - \dot M\dot\theta$ を Cramer の公式で解いて $\ddot\theta$ を得る。
$\dot\theta = 0$ だと $\partial T/\partial\theta$ と $\dot M\dot\theta$ が消えて速度に依存する項を検証できないので、角速度は $\dot\theta = (1, -1)$ rad/s に固定する。

表は各成分の AD の値、上で導いた閉形式、その差を示す。
閉形式はセルの中で `f64` の三角関数を使って別に計算した独立な検算で、AD の記録を通らない。

```rust
//| id: ad-pendulum-eom-terms
//| ref: ad-pendulum-eom-terms
//| title: ラグランジアンの勾配・ヘッセ行列・HVP から運動方程式の項を求める
//| run: reactive
//| uses: [ad-pendulum-model]
//| crates: [scioxide-ad, scioxide-core]
//| inputs:
//|   mass_ratio: {"type":"range","label":"質量比 m₂/m₁","description":"m₁ = 1 kg に対する先端の質点の質量の比。","min":0.1,"max":5,"step":0.1,"value":1}
//|   length_ratio: {"type":"range","label":"長さの比 l₂/l₁","description":"l₁ = 1 m に対する下の棒の長さの比。","min":0.2,"max":3,"step":0.1,"value":1}
//|   theta1_deg: {"type":"range","label":"角度 θ₁ [deg]","description":"上の棒の鉛直下向きから測った角度。","min":-180,"max":180,"step":5,"value":120}
//|   theta2_deg: {"type":"range","label":"角度 θ₂ [deg]","description":"下の棒の鉛直下向きから測った角度。","min":-180,"max":180,"step":5,"value":-30}
//| cases:
//|   - {"id":"heavy-short","label":"μ = 3.5, λ = 0.5, θ = (45°, 170°)","description":"重く短い下の振り子で、M₁₂ が負になる。","inputs":{"mass_ratio":3.5,"length_ratio":0.5,"theta1_deg":45,"theta2_deg":170}}
//|   - {"id":"aligned","label":"θ₁ = θ₂ = 30°","description":"sin Δ = 0 で Ṁθ̇ が消え、M₁₂ が最大になる。","inputs":{"theta1_deg":30,"theta2_deg":30}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"terms","path":"/rows/1/2","approx":{"value":-0.8660254037844386,"atol":1e-14}}
//|       - {"artifact":"terms","path":"/rows/7/2","approx":{"value":-10.24497,"atol":1e-4}}
//|       - {"artifact":"terms","path":"/rows/8/2","approx":{"value":-3.46914,"atol":1e-4}}
//|       - {"artifact":"terms","path":"/rows/7/4","range":{"min":-1e-13,"max":1e-13}}
//|       - {"artifact":"terms","path":"/rows/8/4","range":{"min":-1e-13,"max":1e-13}}
//|   - case: heavy-short
//|     expect:
//|       - {"artifact":"terms","path":"/rows/1/2","approx":{"value":-1.0037587636,"atol":1e-9}}
//|       - {"artifact":"terms","path":"/rows/7/4","range":{"min":-1e-13,"max":1e-13}}
//|       - {"artifact":"terms","path":"/rows/8/4","range":{"min":-1e-13,"max":1e-13}}
//|   - case: aligned
//|     expect:
//|       - {"artifact":"terms","path":"/rows/1/2","approx":{"value":1.0,"atol":1e-14}}
//|       - {"artifact":"terms","path":"/rows/5/2","approx":{"value":0.0,"atol":1e-14}}
//|       - {"artifact":"terms","path":"/rows/6/2","approx":{"value":0.0,"atol":1e-14}}
use scioxide_ad::{grad, hessian, hvp};
use scioxide_core::RealScalar;

let p = Pendulum {
    m1: 1.0,
    m2: mass_ratio,
    l1: 1.0,
    l2: length_ratio,
};
// 速度に依存する項を 0 にしないための角速度 θ̇ = (1, −1) rad/s。
let (w1, w2) = (1.0, -1.0);
let (t1, t2) = (
    RealScalar::to_radians(theta1_deg),
    RealScalar::to_radians(theta2_deg),
);
let z = [t1, t2, w1, w2];
let g = grad(|x| Ok(lagrangian(x, &p)), &z).map_err(|e| e.to_string())?;
let h = hessian(|x| Ok(lagrangian(x, &p)), &z).map_err(|e| e.to_string())?;
let u = [w1, w2, 0.0, 0.0];
let hu = hvp(|x| Ok(lagrangian(x, &p)), &z, &u).map_err(|e| e.to_string())?;
let (g, h, hu) = (g.as_slice(), h.as_slice(), hu.as_slice());
// M は 4×4 の H（行優先）の右下のブロック、Ṁθ̇ は H·[θ̇; 0] の後半 2 成分。
let mass = [h[10], h[11], h[15]];
let mdot = [hu[2], hu[3]];
let force = [g[0] - mdot[0], g[1] - mdot[1]];
// M θ̈ = ∂L/∂θ − Ṁθ̇ を Cramer の公式で解く（M は正定値）。
let det = mass[0] * mass[2] - mass[1] * mass[1];
let acc = [
    (mass[2] * force[0] - mass[1] * force[1]) / det,
    (mass[0] * force[1] - mass[1] * force[0]) / det,
];

// 独立な検算: 手で導いた閉形式（f64 の sin・cos は参照値の計算だけに使う）。
let (s, c) = ((t1 - t2).sin(), (t1 - t2).cos());
let (m1, m2, l1, l2) = (p.m1, p.m2, p.l1, p.l2);
let k = m2 * l1 * l2;
let den = 2.0 * m1 + m2 - m2 * (2.0 * (t1 - t2)).cos();
let closed = [
    (m1 + m2) * l1 * l1,
    k * c,
    m2 * l2 * l2,
    -k * w1 * w2 * s - (m1 + m2) * G * l1 * t1.sin(),
    k * w1 * w2 * s - m2 * G * l2 * t2.sin(),
    -k * s * (w1 - w2) * w2,
    -k * s * (w1 - w2) * w1,
    (-G * (2.0 * m1 + m2) * t1.sin()
        - m2 * G * (t1 - 2.0 * t2).sin()
        - 2.0 * s * m2 * (w2 * w2 * l2 + w1 * w1 * l1 * c))
        / (l1 * den),
    2.0 * s * (w1 * w1 * l1 * (m1 + m2) + G * (m1 + m2) * t1.cos() + w2 * w2 * l2 * m2 * c)
        / (l2 * den),
];
let ad = [
    mass[0], mass[1], mass[2], g[0], g[1], mdot[0], mdot[1], acc[0], acc[1],
];
let names = [
    ("M₁₁", "kg·m²"),
    ("M₁₂", "kg·m²"),
    ("M₂₂", "kg·m²"),
    ("∂L/∂θ₁", "N·m"),
    ("∂L/∂θ₂", "N·m"),
    ("(Ṁθ̇)₁", "N·m"),
    ("(Ṁθ̇)₂", "N·m"),
    ("θ̈₁", "rad/s²"),
    ("θ̈₂", "rad/s²"),
];
let rows: Vec<(&str, &str, f64, f64, f64)> = names
    .iter()
    .zip(ad.iter().zip(&closed))
    .map(|(&(name, unit), (&a, &b))| (name, unit, a, b, a - b))
    .collect();
let digits = serde_json::json!({ "significantDigits": 12 });
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let columns = serde_json::json!([
    { "key": "0", "label": "成分" },
    { "key": "1", "label": "単位" },
    { "key": "2", "label": "AD", "type": "number", "format": digits },
    { "key": "3", "label": "閉形式", "type": "number", "format": digits },
    { "key": "4", "label": "差（AD − 閉形式）", "type": "number", "format": sci2 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "terms" })
);
```

既定の入力（$\mu = \lambda = 1$、$\theta = (120°, -30°)$）では、$M$、$\partial L/\partial\theta$、$\dot M\dot\theta$ の 7 成分の差がすべて 0 で、AD の値と閉形式はビットまで一致した。
$\ddot\theta = (-10.2450, -3.4691)$ rad/s² の差は $1.8\times 10^{-15}$ と $2.2\times 10^{-15}$ rad/s² である。
この差は、AD 側の $2\times 2$ の連立方程式の解と閉形式とで演算の順序が違うことによる丸めの差で、値の大きさに倍精度の単位丸め（約 $1.1\times 10^{-16}$）を掛けた数倍にとどまる。

$\mu = 3.5$、$\lambda = 0.5$、$\theta = (45°, 170°)$ では $M_{12} = -1.00376$ kg·m² が負になり、$\ddot\theta = (-10.4028, -16.9777)$ rad/s² の差は $7.1\times 10^{-15}$ rad/s² 以下である。
$\theta_1 = \theta_2 = 30°$ では $\sin\Delta = 0$ なので $\dot M\dot\theta$ が 0 になり、$M_{12}$ は最大値 $k = m_2 l_1 l_2 = 1$ kg·m² をとる。
試した入力では、差は $\ddot\theta$ の大きさの $10^{-15}$ 倍程度以下で、差分近似のように刻みに依存する打ち切り誤差は含まない。

## 全エネルギーの保存による検算

$L$ が時刻を陽に含まないので、正しい運動方程式の解では全エネルギー $E = T + V$ が保存される。
そこで、AD で組み立てた右辺 $f(y) = [\dot\theta, \ddot\theta]$（$y = [\theta, \dot\theta]$）を陽的 Runge–Kutta 法で積分し、$E(t) - E(0)$ を手で書いた $T$ と $V$ の閉形式で測る。

積分法の次数 $p$ とエネルギーのずれの関係は次のとおりである。
$p$ 次の方法の 1 ステップの局所誤差は $O(h^{p+1})$ で、固定した区間 $[0, t_{\mathrm{end}}]$ での大域誤差は $O(h^p)$ である。
係数は $t_{\mathrm{end}}$ とともに増え、カオス的な運動では指数的に増えうる。
$E$ は状態の滑らかな関数なので、$|E(y_n) - E(0)| = |E(y_n) - E(y(t_n))|$ も $O(h^p)$ で抑えられる。
$h$ を半分にするとずれはおよそ $2^{-p}$ 倍になるので、$\log_2\bigl(\max|E - E_0|_{h} / \max|E - E_0|_{h/2}\bigr)$ を観測された次数とする。

振幅の小さい調和振動に近い運動では、誤差の主な部分が位相のずれになり、エネルギーのずれは 1 次速く $O(h^{p+1})$ で減ることがある。
$y' = i\omega y$ に対する $p = 2, 4$ の方法の増幅率は $|R(i\omega h)|^2 = 1 + O((\omega h)^{p+2})$ で、1 ステップのエネルギーの変化が $O(h^{p+2})$、$t_{\mathrm{end}}/h$ ステップで $O(h^{p+1})$ になるからである。

運動方程式の項が誤っていれば、誤った微分方程式の厳密解は一般にエネルギーを保存しないので、$h \to 0$ でもずれは 0 に近づかない。
この違いを見るため、セルには $\dot M\dot\theta$ の項を落として積分する切り替えを置く。

### 一つの走査で勾配と 3 本の HVP を得る

右辺の 1 回の評価には $\partial L/\partial\theta$、$M$ の 2 列、$\dot M\dot\theta$ の 4 つが要る。
前の節のように `grad`、`hessian`、`hvp` を呼ぶと、評価ごとに新しいテープを 3 本作り、記録と逆走査を 6 回（`grad` と `hvp` で 1 回ずつ、`hessian` で 4 方向の 4 回）行う。
3 本のテープはどれも新しいので最初の記録で関数を 2 回実行し、関数の実行は合わせて 9 回（`grad` と `hvp` で 2 回ずつ、`hessian` で 5 回）になる。

このセルではテープの値の型を `MultiDual<f64, 3>`（値と 3 本の接ベクトルを持つ数）にした `Tape<MultiDual<f64, 3>>` を一度だけ作り、`Tape::gradient_into` を各点で呼ぶ。
入力 $z_i$ に 3 方向のシード $(e_3)_i$、$(e_4)_i$、$u_i$（$u = [\dot\theta; 0]$）を持たせて記録すると、1 回の逆走査で各入力の随伴の値が $\partial L/\partial z_i$、3 本の接ベクトルの部分が $(He_3)_i$、$(He_4)_i$、$(Hu)_i$ になる。
`hvp` が `Var<Dual<f64>>` で 1 方向を保持するのと同じ forward-over-reverse を、3 方向まとめて行うことになる。
各文の値は 4 個の `f64` を持ち（`Var<Dual<f64>>` では 2 個）、記録と走査は 1 回で済む。

記録が収まらないと、`gradient_into` は文の数を数え、その大きさまでテープを広げて関数をもう一度実行する。
したがって最初の呼び出しだけ関数が 2 回走り、同じ関数を記録したことのあるテープでの以後の呼び出しは確保を行わない（[テープのライフサイクルと再利用](../../algorithms/tape-lifecycle/)）。
ワンショット関数は毎回新しいテープを作るので、呼び出しごとにこの 2 回の実行と確保が起こる。
関数は決定論的でなければならない。

次のセルは静止状態から $\theta_1(0) = \theta_2(0) = \theta_0$ で放した二重振り子を $t_{\mathrm{end}} = 5$ s まで、Heun 法（$p = 2$）と古典的 Runge–Kutta 法（$p = 4$）で刻み $h$ と $h/2$ の 2 通りに積分する。
入力は質量比、長さの比、初期角 $\theta_0$（5° から 175°）、刻み $h$ [s]（区間 5 s を等分するように丸め、実際の値を表に示す）、$\dot M\dot\theta$ を落とすかどうかである。

出力は方法ごとの $\max|E - E_0|$、その比、観測された次数の表と、$|E(t) - E(0)|$ の時間変化の片対数グラフ（実線が $h$、破線が $h/2$）である。
ずれがちょうど 0 になった時刻は対数軸に描けないので除き、その数を表に示す。

```rust
//| id: ad-pendulum-energy
//| ref: ad-pendulum-energy
//| title: 再利用するテープで運動方程式を組み立てて積分し、エネルギーのずれを測る
//| run: button
//| uses: [ad-pendulum-model]
//| crates: [scioxide-ad, scioxide-core]
//| inputs:
//|   mass_ratio: {"type":"range","label":"質量比 m₂/m₁","description":"m₁ = 1 kg に対する先端の質点の質量の比。","min":0.1,"max":5,"step":0.1,"value":1}
//|   length_ratio: {"type":"range","label":"長さの比 l₂/l₁","description":"l₁ = 1 m に対する下の棒の長さの比。","min":0.2,"max":3,"step":0.1,"value":1}
//|   theta0_deg: {"type":"range","label":"初期角 θ₁(0) = θ₂(0) [deg]","description":"静止状態から放す角度。","min":5,"max":175,"step":5,"value":120}
//|   step: {"type":"range","label":"時間刻み h [s]","description":"粗いほうの刻み。h/2 でも積分して比べる。","min":0.0025,"max":0.05,"step":0.0025,"value":0.005}
//|   drop_mdot: {"type":"checkbox","label":"Ṁθ̇ の項を落とす","description":"誤った運動方程式で積分したときのエネルギーのずれを見る。","value":false}
//| cases:
//|   - {"id":"small-swing","label":"θ₀ = 10°, h = 0.01 s","description":"小さい振幅では、エネルギーのずれが p + 1 次で減る。","inputs":{"theta0_deg":10,"step":0.01}}
//|   - {"id":"missing-term","label":"Ṁθ̇ を落とす","description":"運動方程式が誤っていると、刻みを細かくしてもずれは減らない。","inputs":{"drop_mdot":true}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"orders","path":"/rows/0/6","approx":{"value":1.94,"atol":0.05}}
//|       - {"artifact":"orders","path":"/rows/1/6","approx":{"value":3.91,"atol":0.05}}
//|       - {"artifact":"orders","path":"/rows/1/4","range":{"max":1e-7}}
//|   - case: small-swing
//|     expect:
//|       - {"artifact":"orders","path":"/rows/0/6","approx":{"value":3.0,"atol":0.1}}
//|       - {"artifact":"orders","path":"/rows/1/6","approx":{"value":5.0,"atol":0.1}}
//|   - case: missing-term
//|     expect:
//|       - {"artifact":"orders","path":"/rows/1/4","range":{"min":10}}
//|       - {"artifact":"orders","path":"/rows/1/6","approx":{"value":0.0,"atol":0.05}}
use scioxide_ad::{MultiDual, Tape, TapeOptions, Var};
use scioxide_core::{ExecutionContext, SciOxideError, RealScalar};

let p = Pendulum {
    m1: 1.0,
    m2: mass_ratio,
    l1: 1.0,
    l2: length_ratio,
};
let mut tape = Tape::<MultiDual<f64, 3>>::new(TapeOptions::new());
let cx = ExecutionContext::sequential();
// y = [θ, θ̇] → [θ̇, θ̈]。シードの 3 方向は e₃、e₄（M の 2 列）と u = [θ̇; 0]（Ṁθ̇）。
let mut rhs = |y: &[f64; 4]| -> Result<[f64; 4], SciOxideError> {
    let seeds = |k: usize| {
        [
            f64::from(k == 2),
            f64::from(k == 3),
            if k < 2 { y[k + 2] } else { 0.0 },
        ]
    };
    let point: [MultiDual<f64, 3>; 4] =
        core::array::from_fn(|k| MultiDual::new(y[k], seeds(k)));
    let mut adjoint = [MultiDual::new(0.0, [0.0; 3]); 4];
    tape.gradient_into(
        |z: &[Var<'_, MultiDual<f64, 3>>]| Ok(lagrangian(z, &p)),
        &point,
        &mut adjoint,
        cx,
    )?;
    // adjoint[i] = (∂L/∂zᵢ, [(H e₃)ᵢ, (H e₄)ᵢ, (H u)ᵢ])
    let (row1, row2) = (adjoint[2].gradient(), adjoint[3].gradient());
    let mass = [row1[0], row1[1], row2[1]];
    let mdot = if drop_mdot {
        [0.0; 2]
    } else {
        [row1[2], row2[2]]
    };
    let force = [adjoint[0].value() - mdot[0], adjoint[1].value() - mdot[1]];
    let det = mass[0] * mass[2] - mass[1] * mass[1];
    Ok([
        y[2],
        y[3],
        (mass[2] * force[0] - mass[1] * force[1]) / det,
        (mass[0] * force[1] - mass[1] * force[0]) / det,
    ])
};
// 独立な検算: 全エネルギー E = T + V の閉形式（AD を通らない。f64 の cos は参照値用）。
let energy = |y: &[f64; 4]| {
    0.5 * (p.m1 + p.m2) * p.l1 * p.l1 * y[2] * y[2]
        + 0.5 * p.m2 * p.l2 * p.l2 * y[3] * y[3]
        + p.m2 * p.l1 * p.l2 * y[2] * y[3] * (y[0] - y[1]).cos()
        - (p.m1 + p.m2) * G * p.l1 * y[0].cos()
        - p.m2 * G * p.l2 * y[1].cos()
};
// 陽的 Runge–Kutta 法の Butcher 表（a は下三角部分、b は重み）。
let heun: (&[&[f64]], &[f64]) = (&[&[], &[1.0]], &[0.5, 0.5]);
let rk4: (&[&[f64]], &[f64]) = (
    &[&[], &[0.5], &[0.0, 0.5], &[0.0, 0.0, 1.0]],
    &[1.0 / 6.0, 1.0 / 3.0, 1.0 / 3.0, 1.0 / 6.0],
);
let t_end = 5.0;
let n0 = (t_end / step).round() as usize;
let theta0 = RealScalar::to_radians(theta0_deg);
let y0 = [theta0, theta0, 0.0, 0.0];
let e0 = energy(&y0);
let (mut rows, mut series) = (Vec::new(), Vec::new());
for (name, order, (a, b)) in [("Heun 法", 2, heun), ("古典的 Runge–Kutta 法", 4, rk4)] {
    let mut worst = [0.0_f64; 2];
    let mut zeros = 0;
    for (level, n) in [n0, 2 * n0].into_iter().enumerate() {
        let h = t_end / n as f64;
        let (mut y, mut points) = (y0, Vec::new());
        for i in 1..=n {
            let mut k = [[0.0; 4]; 4];
            for (s, row) in a.iter().enumerate() {
                let mut stage = y;
                for (&aij, kj) in row.iter().zip(&k) {
                    for c in 0..4 {
                        stage[c] += h * aij * kj[c];
                    }
                }
                k[s] = rhs(&stage).map_err(|e| e.to_string())?;
            }
            for (&bi, ki) in b.iter().zip(&k) {
                for c in 0..4 {
                    y[c] += h * bi * ki[c];
                }
            }
            let drift = (energy(&y) - e0).abs();
            worst[level] = worst[level].max(drift);
            if drift == 0.0 {
                zeros += 1;
            } else if i % (n / 250).max(1) == 0 {
                points.push([i as f64 * h, drift]);
            }
        }
        let style = if level == 0 { "solid" } else { "dashed" };
        series.push(serde_json::json!({
            "name": format!("{name}（h = {h:.5} s）"),
            "points": points,
            "style": { "lineType": style, "showSymbol": false }
        }));
    }
    let ratio = worst[0] / worst[1];
    rows.push((
        name,
        order,
        t_end / n0 as f64,
        worst[0],
        worst[1],
        ratio,
        RealScalar::log2(ratio),
        zeros,
    ));
}
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let fixed2 = serde_json::json!({ "fractionDigits": 2 });
let columns = serde_json::json!([
    { "key": "0", "label": "方法" },
    { "key": "1", "label": "次数 p", "type": "integer" },
    { "key": "2", "label": "h [s]", "type": "number", "format": { "significantDigits": 4 } },
    { "key": "3", "label": "max|E − E₀|（h）[J]", "type": "number", "format": sci3 },
    { "key": "4", "label": "max|E − E₀|（h/2）[J]", "type": "number", "format": sci3 },
    { "key": "5", "label": "比 [-]", "type": "number", "format": fixed2 },
    { "key": "6", "label": "観測された次数 [-]", "type": "number", "format": fixed2 },
    { "key": "7", "label": "ずれが 0 の時刻の数", "type": "integer" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "orders" })
);
emit_chart!(
    serde_json::json!({
        "kind": "line",
        "xLabel": "時刻 t [s]",
        "yLabel": "エネルギーのずれ |E(t) − E(0)| [J]",
        "yType": "log",
        "dataZoom": true,
        "tooltip": true,
        "series": series
    }),
    metadata = serde_json::json!({ "id": "drift" })
);
```

既定の入力（$\theta_0 = 120°$、$h = 0.005$ s）では、Heun 法の $\max|E - E_0|$ が $9.80\times 10^{-4}$ J から $2.55\times 10^{-4}$ J に下がって観測された次数は 1.94 である。
古典的 Runge–Kutta 法は $4.44\times 10^{-7}$ J から $2.96\times 10^{-8}$ J に下がって次数は 3.91 である。
どちらも理論の次数 2 と 4 に近く、AD で組み立てた運動方程式の解のエネルギーのずれは、刻みを細かくすると 0 に向かう。
グラフのずれは単調には増えず、大きく増減しながら最初の約 1 s で最大値に近い大きさに達し、その後も同じ桁にとどまる。
局所誤差は解の高階導関数に比例するので、運動が急に変わる区間でずれが大きく動く。

$\dot M\dot\theta$ の項を落とすと、$\max|E - E_0|$ は両方の方法、両方の刻みで約 $2.2\times 10^2$ J になり、比は 1.00、観測された次数はほぼ 0（$-0.001$）になる。
初期状態の $E_0 = 14.71$ J に比べて大きなエネルギーが注入されており、このずれは積分法の誤差ではなく運動方程式の誤りから来ている。
$t = 0.02$ s でのずれは正しい場合とほぼ同じ $2.2\times 10^{-7}$ J（Heun 法）である。
動き始めは $\dot\theta$ の 2 次の項である $\dot M\dot\theta$ が小さいので、欠落はすぐには現れない。

## パラメータを変えたときの振る舞い

$h = 0.02$ s では観測された次数が Heun 法 3.16、古典的 Runge–Kutta 法 5.02 となり、理論の次数から離れる。
この刻みでは主要項以外の誤差がまだ大きく、観測された次数は $h$ と $h/2$ の両方で主要項が支配的なときにだけ理論の次数を表す（$h = 0.0025$ s では 1.97 と 3.92）。

初期角を $\theta_0 = 10°$、刻みを $h = 0.01$ s にすると、次数は 3.00 と 5.01 になり、$p + 1$ に一致する。
小さい振幅では運動がほぼ 2 つの基準振動の重ね合わせになり、上で述べた位相誤差が主の場合に当たる。
刻みを既定の $h = 0.005$ s に戻して $\theta_0 = 5°$ にすると、古典的 Runge–Kutta 法の $h/2$ での $\max|E - E_0|$ は $9.4\times 10^{-13}$ J まで小さくなり、ずれがちょうど 0 になる時刻が 4 つ現れる。
$\theta_0$ が $120°$ や $170°$ のように大きいと運動はカオス的になり、次数は $p$ に近づく。

質量比を $\mu = 5$ にすると、同じ $h = 0.005$ s でも Heun 法のずれは $0.749$ J、古典的 Runge–Kutta 法は $9.77\times 10^{-3}$ J に増え、後者の次数は 4.83 で漸近範囲の手前にある。
長さの比を $\lambda = 0.5$ にしたときも、下の振り子の固有角振動数 $\sqrt{g/l_2}$ が大きくなるので、ずれは Heun 法で 0.125 J、古典的 Runge–Kutta 法で $2.29\times 10^{-4}$ J に増える。
どちらの場合も、最初のセルの AD と閉形式の差は $\ddot\theta$ の大きさの $10^{-15}$ 倍程度のままで、運動方程式の項の精度と積分の難しさは別の問題である。

## まとめ

運動方程式に現れる $M(\theta)$、$\partial L/\partial\theta$、$\dot M\dot\theta$ は、$L$ を `R: Real` の汎用関数として一つ書けば `hessian`、`grad`、`hvp` で取り出せ、閉形式との差は丸めの水準にとどまる。
$M$ のように全成分が要る量はヘッセ行列の列を並べ、$\dot M\dot\theta$ のように 1 本のベクトルで済む量は HVP 1 本で求める。
同じ $L$ を多数の点で微分するときは、`Tape<MultiDual<f64, 3>>` のようにテープを一度作り、`gradient_into` の 1 回の記録と走査で勾配と複数の HVP をまとめて得る。
運動方程式の正しさは刻みを半分にしたときのエネルギーのずれの比から観測された次数を求めて確かめられ、項が欠けるとずれは $h$ によらず 0 に近づかない。
