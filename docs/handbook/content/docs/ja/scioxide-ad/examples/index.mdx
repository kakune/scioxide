例題は物理・化学・工学・金融・機械学習の具体的な題材で、導関数を求めてから閉形式や別の方法で検算するまでを通して示す。
どの例題も関数を `R: Real` について一度だけ書き、数値型と変換を選ぶ形をとる。
表の「独立な検算」は自動微分とは別の手段で確かめる量である。

| 例題 | 題材 | 主な API | 独立な検算 |
|---|---|---|---|
| [Rosenbrock 関数の勾配と曲率](rosenbrock-sensitivity/) | 最適化の試験関数の谷 | `value_and_grad`、`hessian`、`Dual`、`Tape::gradient_into` | 閉形式の勾配とヘッセ行列、谷に沿う曲率 |
| [JVP と VJP の双対性](jvp-vjp-duality/) | ベクトル値の写像のヤコビ行列 | `jvp`、`Tape::linearize`、`Linearization` の積、`JacobianMode` | $\langle Jv, w\rangle = \langle v, J^\mathsf{T}w\rangle$ の残差、走査の回数 |
| [ヘッセ行列とヘッセ行列・ベクトル積](hessian-vector-product/) | Newton–CG の 1 ステップ | `hvp`、`Tape<Dual<f64>>::hvp_into`、`HessianOperator` | 密なヘッセ行列、差分 |
| [疎なヘッセ行列の彩色による復元](sparse-hessian-chain/) | 鎖状の相互作用のエネルギー | `hessian_pattern`、`derivative_coloring`、`sparse_hessian_into` | 密なヘッセ行列との一致、色数と次元 |
| [L1 正則化の折れ点と微分の規約](nonsmooth-l1-policy/) | LASSO の目的関数 | `abs` の中点規約、`KinkPolicy`、`TapeReport::kinks` | 劣微分の区間、片側導関数 |
| [二重振り子のラグランジアンから運動方程式を組み立てる](double-pendulum-lagrangian/) | 解析力学 | `grad`、`hessian`、`hvp`、`Tape::gradient_into`（`MultiDual` の値） | 質量行列と一般化力の閉形式、エネルギー保存と積分の観測次数 |
| [1 層ニューラルネットの逆伝播と勾配検査](neural-network-backprop/) | 回帰の学習 | `value_and_grad`、`BatchPlan`、scioxide-differentiate の `FiniteDifference` | 中心差分の相対誤差（刻みに対する U 字）、テープと一括の一致 |
| [Black–Scholes 式のグリークス](black-scholes-greeks/) | オプションの価格と感度 | `try_map_scalar`、`MultiDual`、`hessian`、`value_and_grad` | 閉形式の指標、プット・コール・パリティ |
| [経路ごとの微分による Monte Carlo のグリークス](black-scholes-monte-carlo/) | 幾何 Brown 運動の経路の平均 | `BatchPlan` の `evaluate_into`・`hvp_into`、scioxide-random の正規乱数 | 閉形式の指標との差を標準誤差で測る、Γ の偏り |
| [Lennard-Jones クラスタの力と基準振動](lennard-jones-normal-modes/) | 分子の振動 | `grad`、`hvp`、`value_and_grad`、`hessian`、scioxide-rootfind の Newton 法、scioxide-linalg の対称固有値分解 | 2 量体の平衡距離と振動数、零モードの数、閉形式の固有値 |
| [van der Waals 状態方程式の陰的感度](van-der-waals-implicit/) | 実在気体の体積の感度 | `implicit_solution_into`、`Residual`、`value_and_grad`、`hessian`、scioxide-rootfind の多項式の根 | 陰関数定理の閉形式、等温圧縮率、臨界点に近づくときの漸近形 |
| [Taylor ジェットによる ODE のべき級数解と収束半径](taylor-series-ode/) | 常微分方程式の級数解 | `Jet` の係数の再帰 | 厳密な係数、係数の比による収束半径 |

例題を読む前に、[自動微分の選び方](../choosing/)で数値型と変換の選び方を確かめておくと、各例題がなぜその API を使うかが分かる。
アルゴリズムの導出は[自動微分のアルゴリズム体系](../algorithms/)の各ページにある。

## まとめ

例題は 1 階の導関数（Rosenbrock、JVP と VJP）、2 階の導関数（ヘッセ行列の作用、疎なヘッセ行列、二重振り子、Lennard-Jones）、折れ点（L1 正則化）、陰的な解（van der Waals）、高階の係数（ODE の級数解）、多数の項目の和（ニューラルネット、Monte Carlo のグリークス）を扱う。
どの例題も閉形式、保存量、別の方法のどれかで結果を検算する。
自分の問題に近い題材から読み、使う API と検算の組み立てを写すとよい。
