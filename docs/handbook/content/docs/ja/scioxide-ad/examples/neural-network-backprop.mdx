ニューラルネットの学習では、重み $\theta \in \mathbb{R}^P$ に対する損失 $L(\theta)$ の勾配を繰り返し求める。
誤差逆伝播法（backpropagation）は、この勾配を逆モードの自動微分で求める計算である。
勾配の実装は差分近似と比べる勾配検査（gradient check）で確かめることが多いが、差分の誤差は刻みに依存し、比べられる精度には下限がある。

この例題では tanh の中間層を 1 層持つ回帰ネットの勾配を、テープに記録する `value_and_grad` と、標本を項目として平均する `BatchPlan` の二通りで求めて比べる。
続いて scioxide-differentiate の中心差分と比べ、相対誤差が刻みに対して U 字を描き、一致を確かめられる精度に下限があることを示す。

## 回帰ネットと損失

入力 $x$ と出力 $\hat y$ はどちらも無次元のスカラーで、中間層の幅を $m$ とする。

$$
\hat y(x; \theta) = \sum_{j=1}^{m} a_j \tanh(w_j x + b_j) + c,\qquad
L(\theta) = \frac{1}{N}\sum_{k=1}^{N} \ell_k(\theta),\qquad
\ell_k(\theta) = \tfrac12\bigl(\hat y(x_k; \theta) - y_k\bigr)^2
$$

重みは $\theta = [w_1, \dots, w_m, b_1, \dots, b_m, a_1, \dots, a_m, c]$ の順に並べ、その数は $P = 3m + 1$ である（幅 17 から 166 で $P$ は 52 から 499）。
学習データは $N = 24$ 点で、$x_k$ は $[-1, 1]$ の等間隔点、目標は $y_k = \sin(\pi x_k)$ である。

重みは学習前の乱数の値で、$w_j, b_j$ を $[-2, 2)$、$a_j$ を $[-1, 1)/\sqrt m$ の一様分布から引き、$c = 0$ とする。
乱数は scioxide-random の SplitMix64 からシードを指定して作るので、同じシードなら同じ重みになる（[scioxide-random の章](../../../scioxide-random/)）。

## 逆伝播は余接 1 の逆走査

予測の写像 $F(\theta) = [\hat y(x_1;\theta), \dots, \hat y(x_N;\theta)]$ のヤコビ行列を $J = \partial F/\partial\theta$（$N\times P$）、残差を $r = F(\theta) - y$ とすると、$\nabla L = J^{\mathsf T} r / N$ である。
逆モード（reverse mode）は評価をテープに記録し、出力の随伴 $\bar L = 1$ から逆向きに走査して $\bar\theta = \nabla L$ を集める。
計算コストは $L$ の評価の定数倍で、重みの数 $P$ によらない。
同じ勾配を前進モードで求めると、単位方向の方向微分を $P$ 回計算することになる。

`value_and_grad` は新しいテープに関数を記録し、余接 1 で 1 回逆走査して、値と勾配（`scioxide_linalg::Vector`）を返す。
新しいテープは容量を持たないので、関数は記録の大きさを数える 1 回目と、広げたテープに記録する 2 回目の 2 回実行される（[テープのライフサイクルと再利用](../../algorithms/tape-lifecycle/)）。
渡すクロージャは `|t| Ok(loss(t, &data))` の形で、汎用関数 `loss` を逆モードの数値型 `Var<f64>` で評価する。
テープは演算を 1 つずつ文（statement）として記録するので、記録の長さは $N m$ に比例する（[逆モードとテープ](../../algorithms/reverse-mode-and-replay/)）。

## 標本の平均を一括で微分する

$L$ は標本ごとの損失 $\ell_k$ の平均で、各 $\ell_k$ は同じ重み $\theta$ と標本 $(x_k, y_k)$ だけで決まる。
`BatchPlan` はこの形の和 $\sum_k f(\theta, a_k, d_k)$ またはその平均を、多数の独立な項目について求める。
$\theta$ はすべての項目が共有するパラメータ、$a_k$ は項目ごとの微分対象の入力、$d_k$ は項目ごとの微分対象外のデータである。
ここでは項目を標本、パラメータを $P$ 個の重み、微分対象の入力を 0 個、データを $(x_k, y_k)$ の 2 個とし、`BatchReduction::Mean` で平均する。
データは項目 × 2 の行優先の表（`&[f64]` のスライス）で渡し、微分対象の入力がないことは空のスライスで表す。

関数は `BatchFunction` で書く。
`prepare` はパラメータから項目によらない状態を作るメソッドで、ブロック（既定で 256 項目）ごとに 1 回呼ばれる。
`item` は 1 項目の値を返し、`R` がレーン（lane、SIMD の 1 要素）を持つ型なら $W$ 個の連続する項目を 1 回で評価する。
データは `R::Base` の値として渡るので、`R::passive` で微分しない値として演算に入れる。

既定の `DerivativeMode::Auto` で勾配を求めると、`BatchPlan` は数値型を自動で選ぶ。
パラメータと入力の数の和が 4 以下なら前進モードの `MultiDual<Lanes<f64, W>, N>`、それより多ければ逆モードの `Var<Lanes<f64, W>>` を使う。
この例は $P \ge 52$ なので逆モードで、ワーカーごとに 1 本のテープに `prepare` の部分をブロックごとに一度記録し、$W = 8$ 標本ずつの項目をその後ろに記録しては走査する。
24 標本は 1 つのブロックに収まり、8 lane の組 3 つで評価される。
ブロックの結果はブロックの番号順に対ごとに足すので、推定値と勾配は実行方針とワーカーの数によらず同じビットになる（[多数の項目の一括評価](../../algorithms/batches/)）。
このページのセルは逐次に実行する。

テープの勾配と一括の勾配は丸めの水準では一致するが、ビットまで一致するとは限らない。
一括の `tanh` は lane の演算カーネルで計算され、スカラーの関数と最後の数 ulp が違いうる（演算カーネルの誤差は 4 ulp 以内）。
また、勾配への標本ごとの寄与を足す順序が違う。
テープは文を逆順にたどって随伴に寄与を足し、一括は lane ごとの随伴をブロックの最後に lane の順に足す。

次のブロックは 2 つのセルが共有する定義である。
`samples` が学習データ、`initial_weights` が初期の重み、`predict` が $\hat y$、`loss` が $L$ に対応する。

```rust
//| id: ad-nn-model
//| kind: definitions
//| title: 回帰ネットと平均二乗誤差
//| crates: [scioxide-ad, scioxide-core, scioxide-random]
use scioxide_ad::Real;
use scioxide_core::{SciOxideError, RealScalar};
use scioxide_random::{Rng, SeedableRng, SplitMix64};

/// 学習データ (x_k, y_k)：[−1, 1] の等間隔の 24 点と y_k = sin(πx_k)。
pub(crate) fn samples() -> Vec<[f64; 2]> {
    let n = 24;
    (0..n)
        .map(|k| {
            let x = -1.0 + 2.0 * k as f64 / (n - 1) as f64;
            [x, Real::sin_pi(x)]
        })
        .collect()
}

/// 初期の重み θ = [w (m 個), b (m 個), a (m 個), c]：w, b は U(−2, 2)、a は U(−1, 1)/√m、c = 0。
pub(crate) fn initial_weights(width: usize, seed: u64) -> Result<Vec<f64>, SciOxideError> {
    let mut rng = SplitMix64::from_seed(seed);
    let mut theta = vec![0.0; 3 * width + 1];
    for (i, t) in theta.iter_mut().take(3 * width).enumerate() {
        let u: f64 = rng.next_float()?;
        *t = if i < 2 * width {
            4.0 * u - 2.0
        } else {
            (2.0 * u - 1.0) / RealScalar::sqrt(width as f64)
        };
    }
    Ok(theta)
}

/// ŷ(x; θ) = Σⱼ aⱼ tanh(wⱼ x + bⱼ) + c。
pub(crate) fn predict<R: Real>(theta: &[R], x: R) -> R {
    let m = (theta.len() - 1) / 3;
    let (w, rest) = theta.split_at(m);
    let (b, rest) = rest.split_at(m);
    let (a, c) = rest.split_at(m);
    let hidden: R = w
        .iter()
        .zip(b)
        .zip(a)
        .map(|((&w, &b), &a)| a * (w * x + b).tanh())
        .sum();
    hidden + c[0]
}

/// L(θ) = (1/N) Σ_k ½(ŷ(x_k; θ) − y_k)²。
pub(crate) fn loss<R: Real>(theta: &[R], data: &[[f64; 2]]) -> R {
    let total: R = data
        .iter()
        .map(|&[x, y]| {
            let r = predict(theta, R::constant(x)) - y;
            r * r * 0.5
        })
        .sum();
    total / data.len() as f64
}
```

次のセルは幅 $m$ と重みのシードを入力に、同じ重みで二通りの勾配を求めて比べる。
`Regression` が標本 1 個の損失 $\ell_k$ を返す `BatchFunction` で、`prepare` は重みを複製して共有の状態にする。
表の 1 行目はテープの結果、2 行目は一括の結果と、テープに対する損失と勾配の相対差 $\|g_{\mathrm{batch}} - g_{\mathrm{tape}}\|_2 / \|g_{\mathrm{tape}}\|_2$ である。
2 行目の数値型の列は、一括が実際に使った方式（`BatchEstimate::mode`）を示す。
このセルは重み、テープの勾配、損失を次のセルに渡す。

```rust
//|   - {"id":"wide","label":"m = 166, シード 123","description":"重みの数 P = 499 でも、二つの勾配は丸めの水準で一致する。","inputs":{"width":166,"seed":123}}

//| tests:
//|   - case: default

//|       - {"artifact":"gradients","path":"/rows/0/2","approx":{"value":0.402049784259763,"rtol":1e-13}}
//|       - {"artifact":"gradients","path":"/rows/0/3","approx":{"value":2.374398919533063,"rtol":1e-13}}
//|       - {"artifact":"gradients","path":"/rows/1/1","equals":"逆モード"}
//|       - {"artifact":"gradients","path":"/rows/1/4","range":{"max":1e-15}}
//|       - {"artifact":"gradients","path":"/rows/1/5","range":{"max":1e-14}}
//|   - case: wide
//|     expect:
//|       - {"artifact":"gradients","path":"/rows/0/3","approx":{"value":5.716510097729216,"rtol":1e-13}}
//|       - {"artifact":"gradients","path":"/rows/1/5","range":{"max":1e-14}}
//|   - case: narrow
//|     expect:
//|       - {"artifact":"gradients","path":"/rows/0/3","approx":{"value":1.0617748143601429,"rtol":1e-13}}
//|       - {"artifact":"gradients","path":"/rows/1/5","range":{"max":1e-14}}
use scioxide_ad::{
    BatchFunction, BatchMode, BatchOptions, BatchOutputs, BatchPlan, BatchReduction, Real,
    value_and_grad,
};
use scioxide_core::{ExecutionContext, SciOxideError, RealScalar};

/// 標本 1 個の損失 ½(ŷ(x; θ) − y)²。data = [x, y]。
struct Regression;
impl BatchFunction for Regression {
    type Shared<R: Real> = Vec<R>;
    fn prepare<R: Real>(&self, theta: &[R]) -> Result<Vec<R>, SciOxideError> {
        Ok(theta.to_vec())
    }
    fn item<R: Real>(
        &self,
        theta: &Vec<R>,
        _: &[R],
        data: &[R::Base],
    ) -> Result<R, SciOxideError> {
        let r = predict(theta, R::passive(data[0])) - R::passive(data[1]);
        Ok(r * r * 0.5)
    }

let theta = initial_weights(width as usize, seed as u64).map_err(|e| e.to_string())?;
// テープの逆伝播: 損失を 1 回記録し、余接 1 から逆走査する。
let (tape_loss, tape_gradient) =
    value_and_grad(|t| Ok(loss(t, &data)), &theta).map_err(|e| e.to_string())?;
let tape_gradient = tape_gradient.as_slice();
// 一括: 標本を項目、重みをパラメータとし、8 標本ずつ lane に詰めて平均する。
let table: Vec<f64> = data.iter().flatten().copied().collect();
let plan = BatchPlan::<8>::new(
    data.len(),
    theta.len(),
    0,
    2,
    BatchReduction::Mean,
    BatchOptions::new(),

.map_err(|e| e.to_string())?;

    .evaluate_into(
        &Regression,
        &theta,
        &[],
        &table[..],
        BatchOutputs::new().with_parameter_gradient(&mut batch_gradient),
        &mut workspace,
        ExecutionContext::sequential(),
    )
    .map_err(|e| e.to_string())?;

    BatchMode::Value => "値",
    BatchMode::Forward { .. } => "前進モード",
    BatchMode::Reverse => "逆モード",

let norm = |v: &[f64]| RealScalar::sqrt(v.iter().map(|x| x * x).sum::<f64>());
let difference: Vec<f64> = batch_gradient
    .iter()
    .zip(tape_gradient)
    .map(|(a, b)| a - b)
    .collect();
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let digits = serde_json::json!({ "significantDigits": 15 });
let columns = serde_json::json!([
    { "key": "0", "label": "方式" },
    { "key": "1", "label": "数値型" },
    { "key": "2", "label": "損失 L [-]", "type": "number", "format": digits },
    { "key": "3", "label": "‖∇L‖₂ [-]", "type": "number", "format": digits },
    { "key": "4", "label": "損失の相対差 [-]", "type": "number", "format": sci3, "nullText": "基準" },
    { "key": "5", "label": "勾配の相対差 [-]", "type": "number", "format": sci3, "nullText": "基準" }
]);
let rows = vec![

        "value_and_grad",
        "Var<f64>",
        tape_loss,

        None,
    ),

    rows,
```

既定の入力（$m = 32$、$P = 97$、シード 7）では、損失は $L = 0.402050$、勾配のノルムは $\|\nabla L\|_2 = 2.374399$ で、一括は逆モードを選んだ。
一括の損失はテープの損失とビットまで一致し（`tanh` の lane の演算カーネルがスカラーの関数と違う環境では最後の数 ulp が違いうる）、勾配の相対差は $1.9\times 10^{-16}$ である。
$m = 166$、シード 123（$P = 499$）では $\|\nabla L\|_2 = 5.716510$ で相対差は $2.3\times 10^{-16}$、$m = 17$、シード 4242（$P = 52$）では $\|\nabla L\|_2 = 1.061775$ で相対差は $2.2\times 10^{-16}$ である。
どの場合も相対差は倍精度の単位丸め（約 $1.1\times 10^{-16}$）の数倍で、二つの方式は同じ勾配を丸めの範囲で与える。
ただし、これは同じ微分の規則を別の順序で適用した結果どうしの比較で、微分の規則そのものの検算ではない。
規則に依存しない検算として、次に差分と比べる。

## 中心差分による勾配検査

中心差分は $\partial L/\partial\theta_i \approx [L(\theta + h e_i) - L(\theta - h e_i)]/(2h)$ で勾配を近似する。
打ち切り誤差は Taylor 展開から $\frac{h^2}{6}\,\partial^3 L/\partial\theta_i^3$ 程度、$L$ の値の丸め誤差（相対で機械イプシロン $\varepsilon \approx 2.2\times 10^{-16}$ 程度）から来る誤差は $\varepsilon|L|/h$ 程度で、和は $h \sim \varepsilon^{1/3}$ で最小になる。
この導出と刻みの選び方は[丸め誤差・ノイズと最適な刻み幅](../../../scioxide-differentiate/algorithms/roundoff-and-noisy-functions/)にあり、ここでは繰り返さない。

勾配全体の相対誤差 $e(h) = \|g_{\mathrm{FD}} - \nabla L\|_2 / \|\nabla L\|_2$ については、$P$ 個の成分の丸め誤差が独立に足し合わされると見て、丸め誤差の目安を $c_1/h$（$c_1 = \varepsilon|L|\sqrt P/\|\nabla L\|_2$）とする。
打ち切り誤差は $c_2 h^2$ と書き、$c_1/h + c_2 h^2$ を最小にする刻みは $(c_1/2c_2)^{1/3}$ である。

差分には scioxide-differentiate の `FiniteDifference` を使う。
`FiniteDifference::default().with_step(DifferenceStep::absolute(h)?)` で全成分に共通の刻み $h$ を指定し、`gradient` で $P$ 入力 1 出力の関数の勾配を得る。
既定の刻みは中心差分の 1 階微分で $\varepsilon^{1/3}\max(1, |\theta_i|)$ である。
中心差分は各座標の前後 2 点で評価し、基準点 $\theta$ でも 1 回評価するので、勾配 1 回の評価回数は $2P + 1$ になる（既知の値 $L(\theta)$ を `base` に渡すと基準点の評価は省かれる）。
固定刻みの差分の終了状態 `Completed` はステンシルを評価したことを示すだけで、精度は主張しない。

差分のコールバックは同じ汎用関数 `loss` を `f64` で評価する。
微分の規則を使わないので、AD の勾配の独立な検算になる。

次のセルは前のセルの重み $\theta$、テープの勾配、損失を受け取り、$h = 10^{-1}$ から $10^{-13}$ まで $10^{1/2}$ 倍ずつ変えた 25 通りの中心差分の勾配と、表に示す刻み $h = 10^x$ の勾配、既定の刻みの勾配を求める。
グラフは $e(h)$ の観測値（記号）と、二つの誤差の傾きを示す破線の両対数図で、縦線は選んだ $h$ と $\varepsilon^{1/3}$ の位置である。
打ち切り誤差の線は傾き 2 だけを理論から取り、係数 $c_2$ を $h = 10^{-3}$ の観測値に合わせる。
丸め誤差の線は上の目安 $c_1/h$ そのもので、観測値には合わせていない。
$m = 166$ では差分の勾配 1 回に損失を 999 回評価し、合わせて 27 回の勾配を求めるので、wasm では数秒かかる。

```rust
//|       - {"artifact":"summary","path":"/rows/0/5","approx":{"value":2.38e-5,"rtol":0.02}}
//|       - {"artifact":"summary","path":"/rows/0/6","equals":195}
//|       - {"artifact":"errors","path":"/spec/series/0/points/0/1","approx":{"value":1.3679e-4,"rtol":1e-3}}
//|   - case: tiny-step
//|     expect:
//|       - {"artifact":"summary","path":"/rows/0/1","approx":{"value":2.35e-7,"rtol":0.1}}
//|   - case: coarse-step
//|     expect:
//|       - {"artifact":"summary","path":"/rows/0/1","approx":{"value":1.3679e-4,"rtol":1e-3}}
use scioxide_core::{SciOxideError, RealScalar};
use scioxide_differentiate::{DifferenceStep, FiniteDifference};

let theta: Vec<f64> =
    serde_json::from_value(reference["theta"].clone()).map_err(|e| e.to_string())?;
let exact: Vec<f64> =
    serde_json::from_value(reference["gradient"].clone()).map_err(|e| e.to_string())?;
let value = reference["loss"].as_f64().ok_or("損失がない")?;
let data = samples();
let norm = |v: &[f64]| RealScalar::sqrt(v.iter().map(|x| x * x).sum::<f64>());
// 中心差分のコールバック: 同じ汎用関数を f64 で評価する（微分を使わない）。
let callback = |t: &[f64], out: &mut [f64]| -> Result<(), SciOxideError> {
    out[0] = loss(t, &data);
    Ok(())
};
// scioxide-differentiate の中心差分で勾配を求め、AD の勾配との相対誤差と評価回数を返す。
let relative_error = |step: DifferenceStep<f64>| -> Result<(f64, usize), String> {
    let result = FiniteDifference::default()
        .with_step(step)
        .gradient(callback, &theta, None, None)
        .map_err(|e| e.to_string())?;
    let approx = result.values().ok_or("差分の出力がない")?;
    let difference: Vec<f64> = approx.iter().zip(&exact).map(|(a, b)| a - b).collect();
    Ok((
        norm(&difference) / norm(&exact),
        result.report().evaluations(),
    ))
};
let absolute = |h: f64| DifferenceStep::absolute(h).map_err(|e| e.to_string());
let points = (0..=24)
    .map(|i| {
        let h = RealScalar::powf(10.0, -1.0 - 0.5 * f64::from(i));
        Ok([h, relative_error(absolute(h)?)?.0])
    })
    .collect::<Result<Vec<[f64; 2]>, String>>()?;
let chosen = RealScalar::powf(10.0, log_step);
let (chosen_error, evaluations) = relative_error(absolute(chosen)?)?;
let (default_error, _) = relative_error(DifferenceStep::default())?;
let best = points
    .iter()
    .copied()
    .fold([0.0, f64::INFINITY], |b, p| if p[1] < b[1] { p } else { b });
// 打ち切り誤差 c₂h²: 傾きは理論、係数は h = 10⁻³ の観測値に合わせる。
let c2 = points[4][1] / 1e-6;
// 丸め誤差の目安 c₁/h: c₁ = ε|L|√P/‖∇L‖₂（観測値には合わせない）。
let c1 = f64::EPSILON * value.abs() * (theta.len() as f64).sqrt() / norm(&exact);
let guide = |f: &dyn Fn(f64) -> f64| -> Vec<[f64; 2]> {
    points.iter().map(|p| [p[0], f(p[0])]).collect()
};
emit_chart!(
    serde_json::json!({
        "kind": "line",
        "xLabel": "刻み h [-]",
        "yLabel": "相対誤差 ‖g_FD − g_AD‖₂ / ‖g_AD‖₂ [-]",
        "xType": "log",
        "yType": "log",
        "dataZoom": true,
        "tooltip": true,
        "series": [
            { "name": "中心差分（観測）", "points": points, "style": { "showSymbol": true } },
            {
                "name": "打ち切り誤差 c₂h²",
                "points": guide(&|h| c2 * h * h),
                "style": { "lineType": "dashed" }
            },
            {
                "name": "丸め誤差の目安 c₁/h",
                "points": guide(&|h| c1 / h),
                "style": { "lineType": "dashed" }
            }
        ],
        "annotations": [
            { "kind": "line", "axis": "x", "value": chosen, "label": "選んだ h" },
            { "kind": "line", "axis": "x", "value": RealScalar::cbrt(f64::EPSILON), "label": "ε^(1/3)" }
        ]
    }),
    metadata = serde_json::json!({ "id": "errors" })
);
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let columns = serde_json::json!([
    { "key": "0", "label": "選んだ刻み h [-]", "type": "number", "format": sci2 },
    { "key": "1", "label": "相対誤差（選んだ h）[-]", "type": "number", "format": sci2 },
    { "key": "2", "label": "相対誤差（既定の刻み）[-]", "type": "number", "format": sci2 },
    { "key": "3", "label": "最小の相対誤差 [-]", "type": "number", "format": sci2 },
    { "key": "4", "label": "最小を与えた h [-]", "type": "number", "format": sci2 },
    { "key": "5", "label": "(c₁/2c₂)^(1/3) [-]", "type": "number", "format": sci2 },
    { "key": "6", "label": "差分 1 回の評価回数", "type": "integer" }
]);
emit_table_with_columns!(
    columns,
    vec![(
        chosen,
        chosen_error,
        default_error,
        best[1],
        best[0],
        RealScalar::cbrt(c1 / (2.0 * c2)),
        evaluations,
    )],
    metadata = serde_json::json!({ "id": "summary" })
);
```

既定の重み（$m = 32$、シード 7）では、$h = 10^{-1}$ で $e = 1.37\times 10^{-4}$、$h = 10^{-4}$ で $1.37\times 10^{-10}$ と、$h$ が 1 桁小さくなるごとに誤差が 2 桁下がり、打ち切り誤差の破線に重なる。
誤差は $h = 3.2\times 10^{-5}$ で最小の $1.5\times 10^{-11}$ になり、それより小さい $h$ では 1 桁ごとに 1 桁ずつ増えて、$h = 10^{-13}$ では $2.2\times 10^{-3}$ になる。

丸め誤差の目安は $h = 10^{-11}$ で $3.7\times 10^{-5}$ になり、観測値 $2.4\times 10^{-5}$ の約 1.5 倍で桁が合う。
二つの線から求めた刻み $2.4\times 10^{-5}$ は観測された最小の位置と合い、既定の刻みでの誤差は $3.8\times 10^{-11}$ である。
選んだ刻み $h = 10^{-5}$ での誤差は $2.6\times 10^{-11}$ で、差分 1 回の評価回数は $2P + 1 = 195$ 回である。

表の刻みを $h = 10^{-9}$ にすると誤差は $2.3\times 10^{-7}$ で丸め誤差の側にあり、$h = 10^{-1}$ では $1.37\times 10^{-4}$ で打ち切り誤差の側にある。
この勾配検査で言えるのは、AD の勾配と差分が相対 $10^{-11}$ 程度まで一致することで、それより小さい差は差分の側の誤差に隠れる。

## パラメータを変えたときの振る舞い

前のセルで幅を $m = 166$（$P = 499$）、シードを 123 にすると、勾配のノルムは 5.7 に増えるが、相対誤差の曲線はほとんど動かない。
最小は $h = 3.2\times 10^{-5}$ で $1.0\times 10^{-11}$、二つの線から求めた刻みは $2.7\times 10^{-5}$ で、$h = 10^{-9}$ では $1.7\times 10^{-7}$ である。
丸め誤差の目安 $c_1$ の中で $\sqrt P$ と $\|\nabla L\|_2$ がほぼ同じ割合で増え、この例では $P$ の影響が打ち消し合う。
一方、差分の評価回数は $2P + 1 = 999$ 回に増え、差分による勾配の計算コストは $P$ に比例する。
テープの勾配の計算コストは損失の評価の定数倍のままである。

$m = 17$、シード 4242（$P = 52$）では、$h = 10^{-1}$ の誤差が $3.3\times 10^{-4}$ に増え、最小は $h = 10^{-5}$ の $2.6\times 10^{-11}$ で、評価回数は 105 回である。
既定の刻みのように $\varepsilon^{1/3}$ 付近を選べば、試した 3 通りの重みでは誤差が $2\times 10^{-11}$ から $4\times 10^{-11}$ に収まった。
それより桁違いに大きい不一致は、刻みではなく実装の誤りを疑う手がかりになる。

## まとめ

`value_and_grad` は損失の値と勾配を 1 回の逆走査で返し、計算コストは重みの数 $P$ によらず、損失を評価する計算コストの定数倍である。
損失が標本ごとの項の平均なら、同じ汎用関数を `BatchFunction` の `item` に使い、`BatchPlan` で標本を lane に詰めて微分できる。
パラメータと入力の数が 4 を超えると逆モードが選ばれ、テープの勾配と相対 $10^{-16}$ 程度で一致する。
中心差分との勾配検査では、相対誤差が $h^2$ の打ち切り誤差と $\varepsilon/h$ の丸め誤差の和として U 字を描き、この例では $h \approx 3\times 10^{-5}$ での $10^{-11}$ 程度の一致が下限になる。
刻みを固定して勾配検査をするなら $\varepsilon^{1/3}$ 付近を選び、それより大きい刻みや小さい刻みでの不一致を AD の誤差と取り違えない。
