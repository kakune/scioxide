Lasso 回帰や圧縮センシングで使う L1 正則化は、不要な係数をちょうど 0 にする。
その理由はペナルティの項 $|w|$ が原点で折れていて、古典的な導関数を持たないことにある。
自動微分がこの点で何を返すかは規約で決まり、規約を知らずに勾配を使うと、最適解を最適でないと判定することがある。
この例題では `scioxide-ad` の規約（片側導関数の中点）を劣微分と比べ、テープが折れ点を数える規則と、Lasso の解の判定への影響を確かめる。

## 劣微分と最適性条件

設計行列 $A \in \mathbb{R}^{m \times n}$ と観測 $\boldsymbol{b} \in \mathbb{R}^m$ に対する Lasso の目的関数は

$$
F(\boldsymbol{w}) = g(\boldsymbol{w}) + \lambda \lVert \boldsymbol{w} \rVert_1, \qquad
g(\boldsymbol{w}) = \frac{1}{2} \lVert A\boldsymbol{w} - \boldsymbol{b} \rVert_2^2, \qquad
\lVert \boldsymbol{w} \rVert_1 = \sum_{j} |w_j|
$$

である（$\lambda > 0$ は正則化の係数）。
$g$ は滑らかな凸関数で、勾配は $\nabla g(\boldsymbol{w}) = A^\mathsf{T}(A\boldsymbol{w} - \boldsymbol{b})$ である。

凸関数 $f$ の点 $\boldsymbol{w}$ での劣微分 $\partial f(\boldsymbol{w})$ は、すべての $\boldsymbol{v}$ で $f(\boldsymbol{v}) \ge f(\boldsymbol{w}) + \boldsymbol{\xi}^\mathsf{T}(\boldsymbol{v} - \boldsymbol{w})$ を満たす傾き $\boldsymbol{\xi}$ の集合である。
$|w|$ の劣微分は $w < 0$ で $\{-1\}$、$w = 0$ で区間 $[-1, 1]$、$w > 0$ で $\{1\}$ になる。
凸関数が $\boldsymbol{w}^*$ で最小になる必要十分条件は $\boldsymbol{0} \in \partial F(\boldsymbol{w}^*)$ で、Lasso では成分ごとに

$$
\frac{\partial g}{\partial w_j}(\boldsymbol{w}^*) = -\lambda \operatorname{sgn}(w^*_j) \quad (w^*_j \ne 0), \qquad
\left| \frac{\partial g}{\partial w_j}(\boldsymbol{w}^*) \right| \le \lambda \quad (w^*_j = 0)
$$

となる。
係数がちょうど 0 になるのは、その成分の劣微分の区間 $\partial_j g + \lambda[-1, 1]$ が 0 を含むからで、ある 1 つの傾きの値が 0 だからではない。

$m = n = 1$、$A = 1$、$b = y$ の場合は 1 変数の問題 $L(w) = \tfrac{1}{2}(w - y)^2 + \lambda|w|$ で、$\partial L(0) = [-y - \lambda,\ -y + \lambda]$ である。
条件 $0 \in \partial L(w^*)$ を場合分けして解くと

$$
w^* = S_\lambda(y) = \operatorname{sgn}(y) \max(|y| - \lambda,\ 0)
$$

を得る。
$S_\lambda$ を軟判定しきい値（soft thresholding）と呼ぶ。

凸とは限らない局所 Lipschitz 関数には、Clarke 一般化勾配 $\partial_C f(w)$ を使う。
これは $w$ に近づく微分可能な点の列での勾配の極限を集めた凸包で、凸関数では劣微分に一致する。
1 変数の区分的に滑らかな関数では、片側導関数

$$
f'_{\pm}(w) = \lim_{h \to 0\pm} \frac{f(w + h) - f(w)}{h}
$$

を使って $\partial_C f(w) = [\min(f'_-, f'_+),\ \max(f'_-, f'_+)]$ と書ける。
$|w|$ の原点では $f'_- = -1$、$f'_+ = 1$ で、$\partial L(0)$ の両端は $L'_{\pm}(0) = -y \pm \lambda$ である。

## scioxide-ad の折れ点の規約

`scioxide-ad` のすべての数値型（`Dual`、`MultiDual`、`Jet`、テープの `Var`）は、折れ点で片側導関数の中点を使う。
主な関数の規則は次のとおりで、全体の表は[折れ点と非有限値の扱い](../../algorithms/nonsmooth-and-nonfinite-policies/)にある。

| 関数 | 導関数 | 折れ点 |
|---|---|---|
| `abs` | $\operatorname{sgn} x$、0 で 0 | $x = 0$ |
| `min`、`max` | 返した被演算子に 1、同点では各 $\tfrac{1}{2}$ | $a = b$ |
| `floor`、`ceil`、`round`、`trunc`、`signum` | 0 | 跳びの点 |

1 つの折れ点では、中点 $\tfrac{1}{2}(f'_- + f'_+)$ は区間 $\partial_C f$ の中央の点である。
$|w|$ の原点では 0、$L$ の原点では $-y$ になり、どちらも劣微分の元である。
合成した関数では、各演算の中点を連鎖律でつなぐので、結果が合成関数の片側導関数の中点になるとは限らない。

`select` と比較は折れ点ではない。
`R::select(mask, a, b)` の導関数は選ばれた被演算子の導関数なので、同じ ReLU でも `max(w, 0)` と書けば原点で $\tfrac{1}{2}$、`select(w > 0, w, 0)` と書けば偽の枝の 0 になる。

テープは能動的な（微分の対象につながる）引数が折れ点にある演算を、演算とレーン（lane、SIMD の 1 要素）ごとに 1 回数える。
定数だけを引数とする演算は記録されないので数えない。
折れ点の判定は最も内側の値（`base`）の厳密な比較で、$w = 10^{-300}$ のように折れ点のごく近くの点は数えない。
途中の値が区間で一定になり、その値が後の演算の折れ点に当たると、その区間のすべての点で数える。
`max(max(w, 0), 0)` では、$w < 0$ で内側の `max` が 0 を返し、外側の `max` の被演算子が 0 どうしの同点になるので、$w < 0$ のすべての点で 1 回数える。
数は最後の記録について `TapeReport::kinks()`（`Tape::report()` が返す）で読める。
前進モードの型は規約を適用するだけで、数を持たない。

テープの方針は `TapeOptions::with_kink_policy` で選ぶ。
`KinkPolicy::Midpoint`（既定）は中点を使って数を返す。
`KinkPolicy::Error` は数が 0 でなければ変換の境界で `DomainError`（引数 `point`、理由 `Undefined`）を返す。
このとき勾配などの出力は書き換えられない。
`Error` は関数を折れ点で評価したことを見落とさないための検査であり、折れ点での別の値を選ぶ方針ではない。
上の `max(max(w, 0), 0)` のように途中の値が一定になる区間では、`Error` はその区間全体を拒む。

次のブロックは三つのセルが共有する定義である。
`misfit` が $g(\boldsymbol{w})$、`lasso` が $F(\boldsymbol{w})$ で、設計行列 `design` は行優先の $m \times n$、観測 `data` は長さ $m$ の配列である。
どちらも数値型 `R: Real` について一度だけ書き、`f64`、`Dual`、テープの `Var` で同じ式を評価する。

```rust
//| id: ad-l1-lasso-model
//| kind: definitions
//| title: Lasso の当てはめの項と目的関数
//| crates: [scioxide-ad]
use scioxide_ad::Real;

/// 当てはめの項 g(w) = ½‖Aw − b‖²。design は行優先の m × n。
pub(crate) fn misfit<R: Real>(w: &[R], design: &[f64], data: &[f64]) -> R {
    let n = w.len();
    data.iter()
        .enumerate()
        .map(|(i, &b)| {
            let row = &design[i * n..(i + 1) * n];
            let residual = w
                .iter()
                .zip(row)
                .fold(R::constant(-b), |sum, (&wj, &aij)| sum + wj * aij);
            residual * residual * 0.5
        })
        .sum()
}

/// 目的関数 F(w) = g(w) + λ‖w‖₁。
pub(crate) fn lasso<R: Real>(w: &[R], design: &[f64], data: &[f64], penalty: f64) -> R {
    misfit(w, design, data) + w.iter().map(|&wj| wj.abs()).sum::<R>() * penalty
}
```

## 原点での値と片側導関数

次のセルは観測値 $y$ と正則化の係数 $\lambda$（どちらも無次元）を選び、原点 $w = 0$ で五つの関数の導関数を求める。
関数は $|w|$、`max(w, 0)`、`select(w > 0, w, 0)`、`max(max(w, 0), 0)`、$L(w) = \tfrac{1}{2}(w - y)^2 + \lambda|w|$（`lasso` の $m = n = 1$ の場合）である。
導関数は `Dual::variable(0.0)` と、既定の方針のテープの `gradient_into` で求め、テープが数えた折れ点の数を読む。
比べるために、原点から離れた $w = -0.5$ でも同じテープで記録し、折れ点の数を読む。
独立な検算として、同じ関数を `f64` で評価した片側の差分商 $(f(0) - f(-h))/h$ と $(f(h) - f(0))/h$（$h = 2^{-26}$）を求め、その中点と比べる。
グラフは `Dual` で求めた $L'(w)$ を $w < 0$ と $w > 0$ の 2 本の枝に描き、原点の中点の値、区間 $\partial L(0)$（網掛け）、軟判定しきい値の解 $w^* = S_\lambda(y)$（縦線）を重ねる。

既定値（$y = 1.2$、$\lambda = 0.8$）では、$|w|$ の `Dual` の導関数とテープの勾配はどちらも 0 で、片側の差分商 $-1$ と $1$ の中点に一致した。
`max(w, 0)` は片側の値 0 と 1 の中点 $\tfrac{1}{2}$ を返し、テープは 1 回の折れ点を数えた。
同じ ReLU を `select` で書くと、原点では偽の枝が選ばれて導関数は 0 になり、折れ点は数えられない。
片側の差分商は 0 と 1 で、中点の規約が適用されていないことが分かる。
`max(max(w, 0), 0)` は ReLU を 2 回重ねたもので関数としては ReLU と同じだが、中点 $\tfrac{1}{2}$ を 2 回掛けて $\tfrac{1}{4}$ を返し、テープは 2 回の折れ点を数えた。
連鎖律でつないだ中点は合成関数の片側導関数の中点（ここでは $\tfrac{1}{2}$）と一致しない。
$w = -0.5$ ではほかの 4 つの関数は折れ点を数えないが、`max(max(w, 0), 0)` は外側の `max` の同点を 1 回数える。
この関数は $w < 0$ で 0 と一定なのに、テープは $w < 0$ のすべての点を折れ点の上として数え、`KinkPolicy::Error` ではこの区間全体がエラーになる。
$L$ の導関数は $-y = -1.2$ で、片側の差分商 $-2$ と $-0.4$（閉形式 $-y \mp \lambda$ との差は $10^{-8}$ 以下）の中点、つまり区間 $\partial L(0)$ の中央にある。
グラフでは 2 本の枝が原点で $-2$ から $-0.4$ へ跳び、菱形の点がその中央にある。
区間は 0 を含まないので、解は原点の外の $w^* = 0.4$ にある。

$\lambda = 2$ にすると区間は $[-3.2, 0.8]$ で 0 を含み、解は $w^* = 0$ になる。
このとき原点の中点の値は $-1.2$ のままで 0 ではないが、原点は最小点である。
1 つの傾きの値では最適性を判定できず、区間全体が 0 を含むかを見る必要がある。
$y = -1.2$ では区間が $[0.4, 2]$、解が $w^* = -0.4$ になり、表とグラフは原点について反転する。

## 近接勾配法と停止の判定

$F$ は係数が 0 の点で微分できないので、中点の勾配をそのまま勾配法に使うと、係数は 0 のまわりを振動し、ちょうど 0 に止まることはまれである。
近接勾配法（ISTA、iterative shrinkage-thresholding algorithm）は滑らかな $g$ にだけ勾配の 1 歩を使い、$\lambda\lVert \cdot \rVert_1$ は近接写像で扱う。

$$
\boldsymbol{w}_{k+1} = S_{t\lambda}\bigl(\boldsymbol{w}_k - t\,\nabla g(\boldsymbol{w}_k)\bigr)
$$

ここで $S_{t\lambda}$ は成分ごとの軟判定しきい値で、$t\lambda\lVert \cdot \rVert_1$ の近接写像 $\arg\min_{\boldsymbol{u}} \bigl\{ t\lambda\lVert \boldsymbol{u} \rVert_1 + \tfrac{1}{2}\lVert \boldsymbol{u} - \boldsymbol{v} \rVert_2^2 \bigr\}$ に等しい。
刻み $t$ は $\nabla g$ の Lipschitz 定数 $L_g$（$A^\mathsf{T}A$ の最大固有値）について $0 < t \le 1/L_g$ に選ぶ。
このとき $F(\boldsymbol{w}_k)$ は単調に減り、$F(\boldsymbol{w}_k) - F^* \le \lVert \boldsymbol{w}_0 - \boldsymbol{w}^* \rVert_2^2 / (2tk)$ が成り立つ。
$A^\mathsf{T}A$ が正定値で最小固有値が $\mu > 0$ なら、$t = 1/L_g$ で $\lVert \boldsymbol{w}_k - \boldsymbol{w}^* \rVert_2$ は毎回 $1 - \mu/L_g$ 倍以下に縮む。
固有値を求めない代わりに、Gershgorin の定理による上界 $\bar{L} = \max_j \sum_l |(A^\mathsf{T}A)_{jl}| \ge L_g$ を使い、$t = 1/\bar{L}$ とする。
このとき縮む割合は $1 - \mu/\bar{L}$ 倍以下になる。

しきい値は $|v_j| \le t\lambda$ の成分をちょうど 0 にする。
解で $|\partial_j g(\boldsymbol{w}^*)| < \lambda$（狭義の相補性）が 0 の成分すべてで成り立てば、有限回の反復の後、$\boldsymbol{w}_k$ の 0 の成分の集合は $\boldsymbol{w}^*$ のものと一致し、以後変わらない。
したがってテープが $F$ の評価で数える折れ点の数も、有限回で一定になる。

停止は勾配の大きさではなく $\boldsymbol{0}$ と $\partial F(\boldsymbol{w})$ の距離で判定する。
これは劣微分の中で長さが最小の元 $\boldsymbol{r}(\boldsymbol{w})$ の長さで、成分は

$$
r_j = \partial_j g + \lambda \operatorname{sgn}(w_j) \quad (w_j \ne 0), \qquad
r_j = \operatorname{sgn}(\partial_j g)\,\max\bigl(|\partial_j g| - \lambda,\ 0\bigr) \quad (w_j = 0)
$$

である。
$\lVert \boldsymbol{r}(\boldsymbol{w}) \rVert_2 = 0$ は最適性条件 $\boldsymbol{0} \in \partial F(\boldsymbol{w})$ と同値である。
一方、テープで $F$ を微分すると、$w_j = 0$ の成分は中点の規約で $\partial_j g + \lambda \cdot 0 = \partial_j g$ になる。
解では $|\partial_j g| \le \lambda$ のどの値でもありうるので、この「勾配」の長さは解でも一般に 0 にならない。
中点の勾配の大きさで停止を判定すると、解に着いても止まらない。

## 吸収スペクトルの線の選択

題材は気体の吸収スペクトルの解析である。
波数のずれ $\nu_i = 2i$ cm⁻¹（$i = 0, \dots, 39$、$m = 40$ 点）で吸光度 $b_i$ を測り、データベースにある $n = 8$ 本の候補の吸収線の重ね合わせで説明する。
線 $j$（$j = 0, \dots, 7$）の中心は $c_j = 5 + 10j$ cm⁻¹ で、形は標準偏差 $\sigma = 5$ cm⁻¹ の Gauss 形とし、

$$
A_{ij} = \exp\!\left( -\frac{(\nu_i - c_j)^2}{2\sigma^2} \right)
$$

とおく。
係数 $w_j$ は線 $j$ の中心での吸光度（無次元）で、試料に含まれない成分の線は 0 である。
観測は、線 1、4、5 だけが吸光度 0.8、0.5、0.3 を持つ真の係数による吸光度に、モデルにない一定のベースライン 0.02 を足したものとする。
L1 正則化はベースラインを余分な線で説明することを $\lambda$ に応じて抑える。
$\boldsymbol{w} = \boldsymbol{0}$ では $\nabla g(\boldsymbol{0}) = -A^\mathsf{T}\boldsymbol{b}$ なので、$\lambda \ge \lambda_{\max} = \lVert A^\mathsf{T}\boldsymbol{b} \rVert_\infty$ なら解は $\boldsymbol{w}^* = \boldsymbol{0}$ である。

次のブロックは二つのセルが共有する問題の定義である。
`spectrum` は設計行列 $A$（行優先の $m \times n$）と観測 $\boldsymbol{b}$ を返し、`TRUTH` は真の係数、`line_center` は線の中心 $c_j$ [cm⁻¹] である。

```rust
//| id: ad-l1-spectrum
//| kind: definitions
//| title: 吸収スペクトルの設計行列と観測
//| crates: [scioxide-core]
use scioxide_core::RealScalar;

/// 候補の線の数 n と、測定点の数 m。
pub(crate) const LINES: usize = 8;
pub(crate) const SAMPLES: usize = 40;
/// 真の係数（線の中心での吸光度）。
pub(crate) const TRUTH: [f64; LINES] = [0.0, 0.8, 0.0, 0.0, 0.5, 0.3, 0.0, 0.0];

/// 線 j の中心 c_j = 5 + 10j [cm⁻¹]。
pub(crate) fn line_center(j: usize) -> f64 {
    5.0 + 10.0 * j as f64
}

/// 設計行列 A_ij = exp(−(ν_i − c_j)²/(2σ²))（ν_i = 2i cm⁻¹、σ = 5 cm⁻¹）と、
/// ベースライン 0.02 を含む観測 b。
pub(crate) fn spectrum() -> (Vec<f64>, Vec<f64>) {
    let design: Vec<f64> = (0..SAMPLES * LINES)
        .map(|e| {
            let offset = 2.0 * (e / LINES) as f64 - line_center(e % LINES);
            RealScalar::exp(-offset * offset / 50.0)
        })
        .collect();
    let data = (0..SAMPLES)
        .map(|i| {
            (0..LINES)
                .map(|j| design[i * LINES + j] * TRUTH[j])
                .sum::<f64>()
                + 0.02
        })
        .collect();
    (design, data)
}
```

次のセルは $\lambda$ を選び、$\boldsymbol{w}_0 = \boldsymbol{0}$ から ISTA を反復する。
各反復で、既定の方針のテープの `gradient_into` で $\nabla g$ を求めて 1 歩を進め、同じテープで $F$ の中点の勾配と折れ点の数も求める。
$\lVert \boldsymbol{r} \rVert_2 \le 10^{-12}$ で止め、反復の上限は 5000 回とする。
表は反復回数、0 の成分の数、最後の記録でテープが数えた折れ点の数、$\lVert \boldsymbol{r} \rVert_2$、中点の勾配の長さを示す。
上のグラフは反復ごとの $\lVert \boldsymbol{r}(\boldsymbol{w}_k) \rVert_2$ と中点の勾配の長さを対数軸で、下のグラフは $F$ の記録で数えた折れ点の数を示し、横軸の反復回数は二つのグラフで連動する。
$\lVert \boldsymbol{r} \rVert_2$ がちょうど 0 の点は対数軸に描けないので除き、その数を表に示す。
このセルは $\lambda$、解、$\nabla g$、中点の勾配を次のセルに渡す。

```rust
//| id: ad-l1-lasso-ista
//| ref: ad-l1-lasso-ista
//| title: 近接勾配法で Lasso を解き、中点の勾配と劣微分の最適性条件を比べる
//| run: reactive
//| uses: [ad-l1-lasso-model, ad-l1-spectrum]
//| crates: [scioxide-ad, scioxide-core]
//| exports: [penalty, solution, misfit_gradient, midpoint_gradient]
//| inputs:
//|   penalty: {"type":"range","label":"正則化の係数 λ [-]","description":"大きいほど 0 の係数が増える。λ ≥ λ_max ではすべて 0 になる。","min":0.005,"max":4,"step":0.005,"value":0.3}
//| cases:
//|   - {"id":"weak-penalty","label":"λ = 0.01","description":"ベースラインを説明するために、含まれない線にも小さな係数が付く。0 の成分がなく、中点の勾配も 0 に近づく。","inputs":{"penalty":0.01}}
//|   - {"id":"strong-penalty","label":"λ = 2","description":"最も弱い線 5 も 0 になり、0 の成分が 6 個になる。","inputs":{"penalty":2}}
//|   - {"id":"above-lambda-max","label":"λ = 3.7","description":"λ ≥ λ_max なので原点が解で、反復は 0 回で止まる。","inputs":{"penalty":3.7}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"iterations","path":"/rows/0/0","range":{"min":50,"max":80}}
//|       - {"artifact":"iterations","path":"/rows/0/1","equals":5}
//|       - {"artifact":"iterations","path":"/rows/0/2","equals":5}
//|       - {"artifact":"iterations","path":"/rows/0/3","range":{"max":1e-12}}
//|       - {"artifact":"iterations","path":"/rows/0/4","approx":{"value":0.3740103139083049,"rtol":1e-9}}
//|   - case: weak-penalty
//|     expect:
//|       - {"artifact":"iterations","path":"/rows/0/1","equals":0}
//|       - {"artifact":"iterations","path":"/rows/0/2","equals":0}
//|       - {"artifact":"iterations","path":"/rows/0/4","range":{"max":1e-12}}
//|   - case: strong-penalty
//|     expect:
//|       - {"artifact":"iterations","path":"/rows/0/1","equals":6}
//|       - {"artifact":"iterations","path":"/rows/0/2","equals":6}
//|   - case: above-lambda-max
//|     expect:
//|       - {"artifact":"iterations","path":"/rows/0/0","equals":0}
//|       - {"artifact":"iterations","path":"/rows/0/2","equals":8}
//|       - {"artifact":"iterations","path":"/rows/0/4","approx":{"value":5.683309372964972,"rtol":1e-12}}
//|       - {"artifact":"iterations","path":"/rows/0/5","equals":1}
use scioxide_ad::{Tape, TapeOptions};
use scioxide_core::ExecutionContext;

let (design, data) = spectrum();
let (m, n, lambda) = (SAMPLES, LINES, penalty);
// Gershgorin の上界 L̄ ≥ L_g（AᵀA の最大固有値）から刻み t = 1/L̄ を決める。
let gram = |j: usize, l: usize| {
    (0..m)
        .map(|i| design[i * n + j] * design[i * n + l])
        .sum::<f64>()
};
let bound = (0..n)
    .map(|j| (0..n).map(|l| gram(j, l).abs()).sum::<f64>())
    .fold(0.0, f64::max);
let step = 1.0 / bound;
// 軟判定しきい値 S_τ(v)。0 にする成分は厳密に +0 にする。
let soft = |v: f64, tau: f64| {
    if v.abs() <= tau {
        0.0
    } else {
        v - tau * v.signum()
    }
};
// 0 と ∂F(w) の距離 ‖r(w)‖₂（最小ノルムの劣勾配の長さ）。
let distance = |w: &[f64], g: &[f64]| {
    (0..n)
        .map(|j| {
            if w[j] != 0.0 {
                g[j] + lambda * w[j].signum()
            } else {
                (g[j].abs() - lambda).max(0.0)
            }
        })
        .map(|r| r * r)
        .sum::<f64>()
        .sqrt()
};
let norm = |v: &[f64]| v.iter().map(|x| x * x).sum::<f64>().sqrt();

let cx = ExecutionContext::sequential();
let mut tape = Tape::<f64>::new(TapeOptions::new());
let (mut w, mut grad_g, mut grad_f) = (vec![0.0; n], vec![0.0; n], vec![0.0; n]);
let (mut distances, mut midpoints, mut counts, mut skipped) = (vec![], vec![], vec![], 0);
let mut iterations = 0;
loop {
    tape.gradient_into(|x| Ok(misfit(x, &design, &data)), &w, &mut grad_g, cx)
        .map_err(|e| e.to_string())?;
    // F の中点の勾配と、その記録で数えた折れ点。
    tape.gradient_into(
        |x| Ok(lasso(x, &design, &data, lambda)),
        &w,
        &mut grad_f,
        cx,
    )
    .map_err(|e| e.to_string())?;
    let (k, residual) = (iterations as f64, distance(&w, &grad_g));
    if residual > 0.0 {
        distances.push([k, residual]);
    } else {
        skipped += 1;
    }
    midpoints.push([k, norm(&grad_f)]);
    counts.push([k, tape.report().kinks() as f64]);
    if residual <= 1e-12 || iterations == 5000 {
        break;
    }
    w = (0..n)
        .map(|j| soft(w[j] - step * grad_g[j], step * lambda))
        .collect();
    iterations += 1;
}
let zeros = w.iter().filter(|&&x| x == 0.0).count();
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let columns = serde_json::json!([
    { "key": "0", "label": "反復回数", "type": "integer" },
    { "key": "1", "label": "0 の成分の数", "type": "integer" },
    { "key": "2", "label": "折れ点の数 kinks()", "type": "integer" },
    { "key": "3", "label": "‖r(w)‖₂ [-]", "type": "number", "format": sci3 },
    { "key": "4", "label": "中点の勾配の長さ [-]", "type": "number", "format": sci3 },
    { "key": "5", "label": "‖r‖₂ = 0 で除いた点", "type": "integer" }
]);
emit_table_with_columns!(
    columns,
    vec![(
        iterations,
        zeros,
        tape.report().kinks(),
        distance(&w, &grad_g),
        norm(&grad_f),
        skipped
    )],
    metadata = serde_json::json!({ "id": "iterations" })
);
emit_line_chart!(
    &vec![
        serde_json::json!({ "name": "‖r(w_k)‖₂（0 と ∂F の距離）", "points": distances }),
        serde_json::json!({
            "name": "中点の勾配の長さ",
            "points": midpoints,
            "style": { "lineType": "dashed" }
        })
    ],
    options = &serde_json::json!({
        "link": { "group": "lasso-iteration" },
        "xLabel": "反復回数 k",
        "yLabel": "長さ [-]",
        "yType": "log",
        "annotations": [{ "kind": "line", "axis": "y", "value": 1e-12, "label": "停止の閾値" }]
    })
);
emit_line_chart!(
    &vec![serde_json::json!({
        "name": "F の記録の折れ点の数",
        "points": counts,
        "style": { "step": "end" }
    })],
    options = &serde_json::json!({
        "link": { "group": "lasso-iteration" },
        "xLabel": "反復回数 k",
        "yLabel": "折れ点の数 [個]",
        "yMin": 0,
        "yMax": 8
    })
);
export!(penalty, lambda);
export!(solution, w);
export!(misfit_gradient, grad_g);
export!(midpoint_gradient, grad_f);
```

既定値の $\lambda = 0.3$ では、ISTA は 62 回の反復で $\lVert \boldsymbol{r} \rVert_2 = 6.8 \times 10^{-13}$ に達し、8 成分のうち 5 成分がちょうど 0 になった。
上のグラフでは $\lVert \boldsymbol{r} \rVert_2$ が後半にほぼ一定の比（1 回あたり約 0.64 倍）で減るのに対し、破線の中点の勾配の長さは 0.374 で水平になる。
中点の勾配の長さで停止を判定すると、この問題は止まらない。
下のグラフでは、折れ点の数が $\boldsymbol{w}_0 = \boldsymbol{0}$ の 8 から最初の 1 歩で 1、$k = 3$ で 3、$k = 7$ で 5 になり、以後は変わらない。
有限回で 0 の成分の集合が定まる性質が、テープの数として現れている。

$\lambda = 0.01$ では 0 の成分がなく、折れ点は数えられず、中点の勾配の長さも $\lVert \boldsymbol{r} \rVert_2$ と同じく $8 \times 10^{-13}$ まで下がる。
$\lambda = 2$ では最も弱い線 5 も 0 になり、0 の成分と折れ点の数はどちらも 6 になる。
$\lambda = 3.7 \ge \lambda_{\max}$ では原点で $\lVert \boldsymbol{r} \rVert_2 = 0$ になり、反復は 0 回で止まって、その点は対数軸から除かれる。
このとき中点の勾配は $-A^\mathsf{T}\boldsymbol{b}$ で、その長さは 5.68 である。

## 解の検算と厳密な方針

次のセルは前のセルの $\lambda$、解、$\nabla g$、中点の勾配を受け取り、三つを確かめる。
一つ目は解そのもので、座標降下法（各成分を $w_j \leftarrow S_\lambda(\boldsymbol{a}_j^\mathsf{T}\boldsymbol{\rho}_j)/\lVert \boldsymbol{a}_j \rVert_2^2$ で順に更新する方法、$\boldsymbol{a}_j$ は $A$ の列 $j$、$\boldsymbol{\rho}_j$ は列 $j$ の寄与を除いた残差）で同じ問題を解いて比べる。
二つ目はテープの $\nabla g$ で、手で書いた $A^\mathsf{T}(A\boldsymbol{w} - \boldsymbol{b})$ と比べる。
どちらも自動微分を使わない独立な計算である。
三つ目は `KinkPolicy::Error` のテープで解の $F$ を微分し、勾配の配列に前もって入れた 7 が失敗の後も残るかを確かめる。

1 つ目の表は成分ごとに、真の係数、ISTA の解、座標降下法との差、$\partial_j g$、中点の勾配 $\partial_j F$、最小ノルムの劣勾配 $r_j$、最適性条件の判定を示す。
判定は $w_j \ne 0$ なら $|r_j| \le 10^{-9}$、$w_j = 0$ なら $|\partial_j g| \le \lambda$ を確かめる。
2 つ目の表は $\lambda_{\max}$、勾配の検算の差と、厳密な方針の結果（`kind()`、`view()` の引数と理由、呼び出し後の勾配の配列の最大値）を示す。

```rust
//| id: ad-l1-lasso-check
//| ref: ad-l1-lasso-check
//| title: Lasso の解を座標降下法と最適性条件で確かめ、厳密な方針のエラーを読む
//| run: reactive
//| uses: [ad-l1-lasso-model, ad-l1-spectrum]
//| crates: [scioxide-ad, scioxide-core]
//| dependsOn:
//|   ista: ad-l1-lasso-ista
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"coefficients","path":"/rows/1/2","approx":{"value":0.7605669454984567,"rtol":1e-9}}
//|       - {"artifact":"coefficients","path":"/rows/1/3","range":{"max":1e-11}}
//|       - {"artifact":"coefficients","path":"/rows/4/3","range":{"max":1e-11}}
//|       - {"artifact":"coefficients","path":"/rows/0/2","equals":0}
//|       - {"artifact":"coefficients","path":"/rows/0/5","approx":{"value":-0.17533447761511534,"rtol":1e-9}}
//|       - {"artifact":"coefficients","path":"/rows/0/7","equals":"満たす"}
//|       - {"artifact":"coefficients","path":"/rows/5/7","equals":"満たす"}
//|       - {"artifact":"checks","path":"/rows/0/0","approx":{"value":3.670424650674448,"rtol":1e-12}}
//|       - {"artifact":"checks","path":"/rows/0/1","range":{"max":1e-14}}
//|       - {"artifact":"checks","path":"/rows/0/2","equals":"DomainError"}
//|       - {"artifact":"checks","path":"/rows/0/3","equals":"point"}
//|       - {"artifact":"checks","path":"/rows/0/4","equals":"Undefined"}
//|       - {"artifact":"checks","path":"/rows/0/5","equals":7}
use scioxide_ad::{KinkPolicy, Tape, TapeOptions};
use scioxide_core::{DomainReason, ExecutionContext, SciOxideErrorKind, SciOxideErrorView};

let read = |name: &str| -> Result<Vec<f64>, String> {
    let values = ista[name].as_array().ok_or("配列がない")?;
    values
        .iter()
        .map(|v| v.as_f64().ok_or_else(|| "数でない".to_string()))
        .collect()
};
let lambda = ista["penalty"].as_f64().ok_or("λ がない")?;
let (w, grad_g, grad_f) = (
    read("solution")?,
    read("misfit_gradient")?,
    read("midpoint_gradient")?,
);
let (design, data) = spectrum();
let (m, n) = (SAMPLES, LINES);
let column_dot = |j: usize, v: &[f64]| (0..m).map(|i| design[i * n + j] * v[i]).sum::<f64>();
let soft = |v: f64, tau: f64| (v.abs() - tau).max(0.0) * v.signum();

// 独立な検算 1: 座標降下法（f64 の手計算）。rest は残差 b − Av。
let mut v = vec![0.0; n];
let mut rest = data.clone();
for _ in 0..10_000 {
    let mut change = 0.0_f64;
    for j in 0..n {
        let norm2: f64 = (0..m).map(|i| design[i * n + j].powi(2)).sum();
        let next = soft(column_dot(j, &rest) + norm2 * v[j], lambda) / norm2;
        (0..m).for_each(|i| rest[i] -= design[i * n + j] * (next - v[j]));
        change = change.max((next - v[j]).abs());
        v[j] = next;
    }
    if change == 0.0 {
        break;
    }
}
// 独立な検算 2: 手で書いた ∇g = Aᵀ(Aw − b) とテープの ∇g の差。
let fitted: Vec<f64> = (0..m)
    .map(|i| (0..n).map(|j| design[i * n + j] * w[j]).sum::<f64>() - data[i])
    .collect();
let gradient_check = (0..n)
    .map(|j| (column_dot(j, &fitted) - grad_g[j]).abs())
    .fold(0.0, f64::max);
let rows: Vec<_> = (0..n)
    .map(|j| {
        // 最小ノルムの劣勾配 r_j と、成分ごとの最適性条件。
        let (r, optimal) = if w[j] != 0.0 {
            let r = grad_g[j] + lambda * w[j].signum();
            (r, r.abs() <= 1e-9)
        } else {
            let r = (grad_g[j].abs() - lambda).max(0.0) * grad_g[j].signum();
            (r, grad_g[j].abs() <= lambda)
        };
        let verdict = if optimal {
            "満たす"
        } else {
            "満たさない"
        };
        let gap = (w[j] - v[j]).abs();
        (
            line_center(j),
            TRUTH[j],
            w[j],
            gap,
            grad_g[j],
            grad_f[j],
            r + 0.0,
            verdict,
        )
    })
    .collect();

// KinkPolicy::Error のテープで解の F を微分する。勾配の配列には 7 を入れておく。
let options = TapeOptions::new().with_kink_policy(KinkPolicy::Error);
let mut strict = Tape::<f64>::new(options);
let mut gradient = vec![7.0; n];
let outcome = strict.gradient_into(
    |x| Ok(lasso(x, &design, &data, lambda)),
    &w,
    &mut gradient,
    ExecutionContext::sequential(),
);
let (kind, argument, reason) = match &outcome {
    Ok(_) => ("成功", "-", "-"),
    Err(error) => {
        let kind = match error.kind() {
            SciOxideErrorKind::DomainError => "DomainError",
            _ => "その他",
        };
        match error.view() {
            SciOxideErrorView::DomainError {
                argument,
                reason: DomainReason::Undefined,
                ..
            } => (kind, argument.as_str(), "Undefined"),
            _ => (kind, "-", "-"),
        }
    }
};
let largest = gradient.iter().fold(f64::NEG_INFINITY, |a, &b| a.max(b));
let lambda_max = (0..n)
    .map(|j| column_dot(j, &data).abs())
    .fold(0.0, f64::max);
```

## まとめ

`scioxide-ad` は折れ点で片側導関数の中点を返し、$|w|$ の原点では 0、Lasso の 1 変数の目的関数では劣微分の区間の中央 $-y$ になる。
中点の値は区間の 1 点にすぎないので、解でも 0 になるとは限らず、勾配の大きさで最適性や停止を判定してはいけない。
L1 正則化の問題は近接勾配法のようにペナルティを近接写像で扱い、停止は $\boldsymbol{0}$ と劣微分の距離 $\lVert \boldsymbol{r} \rVert_2$ で判定する。
テープの `TapeReport::kinks()` は能動的な引数が折れ点にちょうど乗った演算の数で、Lasso の解では 0 の係数の数に等しく、`max(max(w, 0), 0)` の $w < 0$ のように途中の値が一定になる区間ではそのすべての点で正になる。
`select` で書いた分岐は折れ点として数えられないので、数を検査に使うなら折れ点は `abs`・`max`・`min` などの関数で書く。
`KinkPolicy::Error` は数が正になる評価を `DomainError`（引数 `point`、理由 `Undefined`）で拒み、出力を書き換えないので、折れ点を通らないはずの計算の検査に使う。
