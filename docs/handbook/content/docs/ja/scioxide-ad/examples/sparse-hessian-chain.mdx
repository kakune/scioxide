格子振動、離散化した場のエネルギー、分子の力場では、各変数が近くの変数とだけ相互作用する。
このときヘッセ行列の大半の成分は評価点によらず 0 で、非零は変数の数 $n$ に比例する個数しかない。
非零の位置（構造）が分かれば、同じ行に非零を持たない列をまとめた少数の方向のヘッセ行列・ベクトル積（HVP）から、非零をすべて読み出せる。
この例題では非線形の原子鎖を題材に、`scioxide-ad` のテープから構造を求め、列彩色で方向をまとめてヘッセ行列を復元し、密な計算と比べる。

## 原子鎖のエネルギーとヘッセ行列

$n$ 個の原子が直線上に並び、平衡位置からの変位を $x_0, \dots, x_{n-1}$ [m] とする。
距離 $d$（$d = 1, \dots, r$）だけ離れた原子の組はばねでつながり、伸び $s$ [m] のばねのエネルギーを

$$
V_d(s) = \frac{k_d}{2} s^2 + \frac{\beta_d}{4} s^4, \qquad k_d = \frac{k}{d^2}, \quad \beta_d = \frac{\beta}{d^2}
$$

とする。
$k$ [N/m] は線形のばね定数、$\beta$ [N/m³] は 4 次の非線形性の係数で、$r = 1$ は Fermi–Pasta–Ulam–Tsingou の β モデルにあたる。
鎖の外側の原子は動かないとし、$j < 0$ と $j \ge n$ では $x_j = 0$ とおく。
全エネルギー [J] は

$$
E(\boldsymbol{x}) = \sum_{d=1}^{r} \sum_{i=-d}^{n-1} V_d(x_{i+d} - x_i)
$$

である。

ばね $(p, q)$（$q = p + d$）の伸びを $s = x_q - x_p$ とすると、その曲率は $\kappa = V_d''(s) = k_d + 3\beta_d s^2$ である。
ばねはヘッセ行列に $\kappa\,(\boldsymbol{e}_q - \boldsymbol{e}_p)(\boldsymbol{e}_q - \boldsymbol{e}_p)^\mathsf{T}$ を足すので、鎖の内側の添字について

$$
H_{pp} \mathrel{+}= \kappa, \qquad H_{qq} \mathrel{+}= \kappa, \qquad H_{pq} = H_{qp} = -\kappa
$$

となる（$\boldsymbol{e}_j$ は第 $j$ 単位ベクトル）。
$|i - j| > r$ の成分は評価点によらず 0 で、ヘッセ行列は半帯幅 $r$ の帯行列になる。
構造上の非零の数は

$$
\mathrm{nnz} = n + 2\sum_{d=1}^{r} (n - d) = (2r + 1)\,n - r(r + 1)
$$

で（$n \ge r$ のとき）、$n$ が $r$ より十分大きければ $n^2$ に比べて小さい。
非零の値のうち評価点に依存するのは $3\beta_d s^2$ の部分だけで、$\beta = 0$ ではヘッセ行列は定数になる。

## 構造的に直交する列と彩色

二つの列が同じ行に非零を持たないとき、二つの列は構造的に直交するという。
列を色 $0, \dots, p - 1$ に分け、同じ色の列が互いに構造的に直交するようにする。
色 $c$ の列の単位ベクトルの和を $\boldsymbol{d}_c = \sum_{\mathrm{color}(j) = c} \boldsymbol{e}_j$ とすると、行 $i$ に非零を持つ色 $c$ の列は高々 1 つなので、その列を $j$ として

$$
(H \boldsymbol{d}_c)_i = H_{ij}
$$

が成り立つ。
したがって色ごとに 1 本の HVP $H\boldsymbol{d}_c$ を求めれば、各非零 $H_{ij}$ は列 $j$ の色の HVP の第 $i$ 成分からそのまま読める。
連立方程式を解かないので、この読み出しを直接復元（direct recovery）と呼ぶ。
この彩色は Curtis–Powell–Reid の列圧縮と同じで、ヤコビ行列の列彩色の数学は[疎構造と列彩色](../../../scioxide-core/algorithms/sparse-structure-and-coloring/)で扱う。

1 つの行の非零はすべて異なる色を必要とするので、色数は 1 行の非零の最大数を下回らない。
$n \ge 2r + 1$ の半帯幅 $r$ の帯では、行 $r, \dots, n - 1 - r$ が $2r + 1$ 個の非零を持つので、下界は $2r + 1$ 色である。
列 $j$ と列 $l$ は $|j - l| \le 2r$ のとき同じ行に非零を持つ。
`scioxide_sparse::derivative_coloring` は列を添字の小さい順に見て、すでに色の付いた衝突する列が使っていない最小の色を割り当てる貪欲法である。
帯行列ではこの方法がちょうど $\mathrm{color}(j) = j \bmod (2r + 1)$ を与え、下界に一致する。
一般の構造では、貪欲法は最小の色数を保証せず、色数は列の順序にもよる。
この復元はヘッセ行列の対称性 $H_{ij} = H_{ji}$ を使わない。
対称性を使う星彩色（star coloring）などの方式は一般の構造で色数を減らせるが、`scioxide-ad` の疎ヘッセ行列はその方式を提供しない。

各 HVP は二重数 `Dual<f64>` をテープに載せる forward-over-reverse で求める。
変数を $\mathrm{Dual}(x_i, (\boldsymbol{d}_c)_i)$ として関数を記録し、1 回の逆走査で、値の成分に勾配 $\nabla E$、接ベクトルの成分に $H\boldsymbol{d}_c$ を得る（[二階微分とヘッセ行列の作用素](../../algorithms/second-order-derivatives/)）。
密なヘッセ行列は単位ベクトルの方向ごとに 1 回、計 $n$ 回記録するが、彩色した復元は色ごとに 1 回、計 $2r + 1$ 回で済み、記録の回数が $n$ によらない。

## scioxide-ad での手順

復元は三つの段階からなる。

1. `Tape::<f64>::linearize` で関数を 1 回記録し、`Linearization::hessian_pattern` で構造を求める。
   構造は記録した文から決まり、評価点の値によらない。
   各値が依存する入力の集合を前から伝え、非線形な文の引数の集合どうしの組をヘッセ行列の非零とする（Walther の非線形相互作用の領域）。
   $x + y$ や $c\,x$ のような線形の文は相互作用を作らず、積 $x \cdot y$ は二つの引数の集合の組だけを、`exp` のような非線形の 1 引数関数は引数の集合のすべての組を作る。
   構造は同じ分岐をたどる評価点で有効で、出力がちょうど 1 つでなければ `DimensionMismatch` になる。
2. `scioxide_sparse::derivative_coloring` に構造のビュー（`pattern.view()`）を渡し、列彩色 `ColoringSchedule` を得る。
   スケジュールは構造の複製を持ち、色ごとの列（`groups()`）、列ごとの色（`colors()`）、色数（`color_count()`）を返す。
3. `Tape::<Dual<f64>>::sparse_hessian_into(function, point, &coloring, &mut values, cx)` で非零の値を求める。
   `values` は構造の非零の数だけの長さを持ち、値は構造の CSR の順に並ぶ。
   関数は色ごとに 1 回記録される。
   構造が $n \times n$ でないか、`values` の長さが非零の数と違えば `DimensionMismatch` になり、記録の失敗は `Tape::gradient_into` と同じエラーになる。
   失敗したときは `values` を書き換えない。

新しいテープは容量を持たないので、最初の実行は文を数えるだけで、記録は保存されない。
変換はテープを数えた大きさに広げて関数をもう一度実行するので、最初の呼び出しでは関数が色数より 1 回多く実行され、関数は決定論的でなければならない（[テープのライフサイクルと再利用](../../algorithms/tape-lifecycle/)）。
同じ関数を記録して容量が足りているテープでは、2 回目以降の呼び出しは記録を色数の回数だけ行い、メモリを確保しない。
比較に使うワンショット呼び出しの `hessian` は、呼ぶたびに新しいテープを作り、単位方向ごとに記録して密な行列を確保して返す。

次のブロックは二つのセルが共有する定義である。
`chain_energy` が $E(\boldsymbol{x})$ を数値型 `R: Real` について一度だけ書いたもので、`range` が $r$、`stiffness` が $k$、`quartic` が $\beta$ である。
鎖の外側の変位 $x_j = 0$ は受動的な定数 `R::zero()` で表す。
`chain_hessian` はばねごとに曲率 $\kappa$ を足す閉形式のヘッセ行列（行優先の $n \times n$）で、自動微分を使わない独立な検算である。

```rust
//| id: ad-sparse-hessian-chain-model
//| kind: definitions
//| title: 第 r 近接まで結合した非線形の原子鎖のエネルギーと閉形式のヘッセ行列
//| crates: [scioxide-ad]
use scioxide_ad::Real;

/// 鎖のエネルギー E(x) [J]。鎖の外側（j < 0、j ≥ n）の変位は 0 とする。
pub(crate) fn chain_energy<R: Real>(x: &[R], range: usize, stiffness: f64, quartic: f64) -> R {
    let n = x.len() as isize;
    let at = |j: isize| {
        if (0..n).contains(&j) {
            x[j as usize]
        } else {
            R::zero()
        }
    };
    let mut energy = R::zero();
    for d in 1..=range as isize {
        let scale = 1.0 / (d * d) as f64;
        for i in -d..n {
            // ばね (i, i + d) の伸び s と V_d(s) = k_d s²/2 + β_d s⁴/4。
            let s = at(i + d) - at(i);
            let s2 = s * s;
            energy += s2 * (0.5 * stiffness * scale) + s2 * s2 * (0.25 * quartic * scale);
        }
    }
    energy
}

/// 閉形式のヘッセ行列 [N/m]（行優先 n × n）。ばねごとに曲率 κ = k_d + 3β_d s² を足す。
pub(crate) fn chain_hessian(x: &[f64], range: usize, stiffness: f64, quartic: f64) -> Vec<f64> {
    let n = x.len() as isize;
    let inside = |j: isize| (0..n).contains(&j);
    let at = |j: isize| if inside(j) { x[j as usize] } else { 0.0 };
    let mut hessian = vec![0.0; x.len() * x.len()];
    for d in 1..=range as isize {
        let scale = 1.0 / (d * d) as f64;
        for p in -d..n {
            let q = p + d;
            let s = at(q) - at(p);
            let curvature = (stiffness + 3.0 * quartic * s * s) * scale;
            for (row, column, sign) in [(p, p, 1.0), (q, q, 1.0), (p, q, -1.0), (q, p, -1.0)] {
                if inside(row) && inside(column) {
                    hessian[(row * n + column) as usize] += sign * curvature;
                }
            }
        }
    }
    hessian
}
```

## 構造と色数の次元依存

次のセルは結合の範囲 $r$（1 から 3 の整数）を選び、$n = 8, 16, \dots, 256$ の鎖をそれぞれ `Tape::<f64>::linearize` で 1 回記録して、`hessian_pattern` の構造と `derivative_coloring` の色数を求める。
構造は値によらないので、ここでは $k = 1$ N/m、$\beta = 1$ N/m³、変位 $x_i = \sin(\pi (i + 1)/(n + 1))$ m の 1 点だけで記録する。
1 つのテープを $n$ の小さい順に使い回し、$n$ が増えるたびに記録の大きさまで広げ直す（広げ直したテープは、その大きさの新しいテープと同じ領域を持つ。
[テープのライフサイクルと再利用](../../algorithms/tape-lifecycle/)）。
表は構造の非零の数を閉形式 $(2r + 1)n - r(r + 1)$ と比べ、各行の列が $|i - j| \le r$ の帯とちょうど一致するか、色数と下界 $2r + 1$、色が $j \bmod (2r + 1)$ と一致するかを示す。
グラフは HVP の本数（関数を記録する回数）を、彩色した復元の色数と、密なヘッセ行列の $n$ 本で比べる。

```rust
//| id: ad-sparse-hessian-pattern
//| ref: ad-sparse-hessian-pattern
//| title: テープの構造解析で帯構造を求め、色数が鎖の長さによらないことを確かめる
//| run: reactive
//| uses: [ad-sparse-hessian-chain-model]
//| crates: [scioxide-ad, scioxide-core, scioxide-sparse]
//| inputs:
//|   range: {"type":"range","label":"結合の範囲 r","description":"第 r 近接まで結合する。帯の半幅と色数の下界 2r + 1 を決める。","min":1,"max":3,"step":1,"value":1}
//| cases:
//|   - {"id":"third-neighbours","label":"r = 3","description":"帯が 7 本になり、色数も 7 になる。n を 32 倍にしても変わらない。","inputs":{"range":3}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"structure","path":"/rows/0/1","equals":22}
//|       - {"artifact":"structure","path":"/rows/0/2","equals":22}
//|       - {"artifact":"structure","path":"/rows/5/1","equals":766}
//|       - {"artifact":"structure","path":"/rows/5/3","equals":"一致"}
//|       - {"artifact":"structure","path":"/rows/0/4","equals":3}
//|       - {"artifact":"structure","path":"/rows/5/4","equals":3}
//|       - {"artifact":"structure","path":"/rows/5/6","equals":"一致"}
//|   - case: third-neighbours
//|     expect:
//|       - {"artifact":"structure","path":"/rows/0/1","equals":44}
//|       - {"artifact":"structure","path":"/rows/5/2","equals":1780}
//|       - {"artifact":"structure","path":"/rows/5/1","equals":1780}
//|       - {"artifact":"structure","path":"/rows/0/4","equals":7}
//|       - {"artifact":"structure","path":"/rows/5/4","equals":7}
//|       - {"artifact":"structure","path":"/rows/5/6","equals":"一致"}
use scioxide_ad::Tape;
use scioxide_core::{ExecutionContext, RealScalar};
use scioxide_sparse::derivative_coloring;

let r = range as usize;
let bound = 2 * r + 1;
let cx = ExecutionContext::sequential();
let mut rows = Vec::new();
let (mut colored, mut unit) = (Vec::new(), Vec::new());
// 1 つのテープを使い回し、n が増えるたびに記録の大きさまで広げ直す。
let mut tape = Tape::<f64>::default();
for n in [8_usize, 16, 32, 64, 128, 256] {
    let point: Vec<f64> = (0..n)
        .map(|i| RealScalar::sin(std::f64::consts::PI * (i + 1) as f64 / (n + 1) as f64))
        .collect();
    let linear = tape
        .linearize(
            |x, y| {
                y.push(chain_energy(x, r, 1.0, 1.0));
                Ok(())
            },
            &point,
            cx,
        )
        .map_err(|e| e.to_string())?;
    let pattern = linear.hessian_pattern().map_err(|e| e.to_string())?;
    let view = pattern.view();
    // 独立な検算: 行 i の列が帯 max(0, i − r) ..= min(n − 1, i + r) とちょうど一致するか。
    let banded = (0..n).all(|i| {
        let columns = &view.col_indices()[view.row_ptr()[i]..view.row_ptr()[i + 1]];
        columns
            .iter()
            .copied()
            .eq(i.saturating_sub(r)..=(i + r).min(n - 1))
    });
    let coloring = derivative_coloring(view).map_err(|e| e.to_string())?;
    let periodic = (0..n).all(|j| coloring.colors()[j] == j % bound);
    let label = |ok: bool| if ok { "一致" } else { "不一致" };
    rows.push((
        n,
        view.col_indices().len(),
        bound * n - r * (r + 1),
        label(banded),
        coloring.color_count(),
        bound,
        label(periodic),
    ));
    colored.push([n as f64, coloring.color_count() as f64]);
    unit.push([n as f64, n as f64]);
}
let columns = serde_json::json!([
    { "key": "0", "label": "原子の数 n", "type": "integer" },
    { "key": "1", "label": "構造の非零の数", "type": "integer" },
    { "key": "2", "label": "閉形式 (2r + 1)n − r(r + 1)", "type": "integer" },
    { "key": "3", "label": "帯 |i − j| ≤ r との一致" },
    { "key": "4", "label": "色数", "type": "integer" },
    { "key": "5", "label": "下界 2r + 1", "type": "integer" },
    { "key": "6", "label": "色 = j mod (2r + 1)" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "structure" })
);
emit_line_chart!(
    &vec![
        serde_json::json!({
            "name": "彩色した方向（色数）",
            "points": colored,
            "style": { "symbol": "circle", "showSymbol": true }
        }),
        serde_json::json!({
            "name": "単位方向（n 本）",
            "points": unit,
            "style": { "lineType": "dashed" }
        })
    ],
    options = &serde_json::json!({
        "xLabel": "原子の数 n",
        "yLabel": "HVP の本数（記録の回数）[本]",
        "xType": "log",
        "yType": "log"
    })
);
```

$r = 1$ では、構造の非零の数は $n = 8$ の 22 個から $n = 256$ の 766 個まで閉形式 $3n - 2$ と一致し、各行の列は三重対角の帯とちょうど一致した。
`hessian_pattern` は値を見ずに文の種類だけから構造を決めるが、この鎖では余分な位置も欠けた位置もない。
色数はすべての $n$ で下界と同じ 3 で、色は $j \bmod 3$ の順に並ぶ。
グラフの破線（密なヘッセ行列の $n$ 本）は $n$ に比例して増えるが、彩色した方向の本数は水平のままである。

$r = 3$ にすると帯は 7 本になり、非零の数は $7n - 12$（$n = 256$ で 1780 個）、色数は 7 になる。
色数は帯の幅だけで決まり、$n$ を 32 倍にしても変わらない。
$n = 256$ の密なヘッセ行列は 65536 成分を持ち 256 回の記録を要するが、彩色した復元は 1780 個の非零を 7 回の記録で求める。

## 値の復元と記録の回数

次のセルは原子の数 $n$、結合の範囲 $r$、4 次の係数 $\beta$、変位の振幅 $A$ を選び、$k = 1$ N/m として、評価点 $x_i = A \sin(\pi (i + 1)/(n + 1))$ [m] でヘッセ行列を復元する。
この変位は最近接だけで結合した両端固定の線形の鎖（$r = 1$、$\beta = 0$）の最も低い基準振動の形である。
手順は前の節の三つの段階のとおりで、`sparse_hessian_into` に渡すクロージャは呼ばれた回数を `Cell` で数える。
続けて同じテープと同じ彩色のまま、評価点を $\boldsymbol{x} = \boldsymbol{0}$ に替えてもう一度復元する。
$\boldsymbol{x} = \boldsymbol{0}$ のヘッセ行列は線形の鎖の剛性行列で、4 次の項の寄与が消える。
比較としてワンショット呼び出しの `hessian` で密なヘッセ行列を求め、こちらも関数の実行回数を数える。

1 つ目の表は非零の数、色数、関数の実行回数（新しいテープでの 1 回目、同じテープでの 2 回目、密な計算）を示す。
2 つ目の表は二つの評価点で、復元した非零と閉形式 `chain_hessian` の最大差、評価点での密なヘッセ行列との最大差、密なヘッセ行列の帯の外の成分の最大の絶対値を示す。
ヒートマップは評価点で復元したヘッセ行列で、帯の外は 0 として描く。

```rust
//| id: ad-sparse-hessian-chain
//| ref: ad-sparse-hessian-chain
//| title: 彩色した方向の HVP で鎖のヘッセ行列を復元し、密な計算と閉形式に照らす
//| run: reactive
//| uses: [ad-sparse-hessian-chain-model]
//| crates: [scioxide-ad, scioxide-core, scioxide-sparse]
//| inputs:
//|   particles: {"type":"range","label":"原子の数 n","description":"自由度。密なヘッセ行列の記録の回数は n に比例する。","min":4,"max":64,"step":1,"value":24}
//|   range: {"type":"range","label":"結合の範囲 r","description":"第 r 近接まで結合する。n ≥ 2r + 1 なら色数は 2r + 1 になる。","min":1,"max":3,"step":1,"value":1}
//|   quartic: {"type":"range","label":"4 次の係数 β [N/m³]","description":"0 ではヘッセ行列が評価点によらない。","min":0,"max":4,"step":0.1,"value":2}
//|   amplitude: {"type":"range","label":"変位の振幅 A [m]","description":"評価点 x_i = A sin(π(i + 1)/(n + 1))。","min":0,"max":1.5,"step":0.05,"value":0.6}
//| cases:

use scioxide_core::{ExecutionContext, RealScalar};
use scioxide_sparse::derivative_coloring;
use std::cell::Cell;

let (n, r, k) = (particles as usize, range as usize, 1.0);
let cx = ExecutionContext::sequential();
let point: Vec<f64> = (0..n)
    .map(|i| {
        amplitude * RealScalar::sin(std::f64::consts::PI * (i + 1) as f64 / (n + 1) as f64)
    })
    .collect();
// 1. 構造: f64 のテープに 1 回記録する。
let mut tape = Tape::<f64>::new(TapeOptions::new());
let linear = tape
    .linearize(
        |x, y| {
            y.push(chain_energy(x, r, k, quartic));
            Ok(())
        },
        &point,
        cx,
    )
    .map_err(|e| e.to_string())?;

// 2. 列彩色。

// 3. 復元: 色ごとに Dual(x_i, (d_c)_i) で 1 回記録する。runs は関数の実行回数。

let mut second = Tape::<Dual<f64>>::new(TapeOptions::new());

        .sparse_hessian_into(
            |x: &[Var<'_, Dual<f64>>]| {
                runs.set(runs.get() + 1);
                Ok(chain_energy(x, r, k, quartic))
            },
            at,
            &coloring,
            &mut values,
            cx,
        )
        .map_err(|e| e.to_string())?;

        max_diff(&full_origin, &chain_hessian(&origin, r, k, quartic)),
        None,
        None,
        largest(&full_origin),
```

既定値（$n = 24$、$r = 1$、$\beta = 2$ N/m³、$A = 0.6$ m）では、576 成分のうち構造上の非零は 70 個で、色数は 3 である。
新しいテープでの最初の復元は関数を 4 回実行した。
3 回は色ごとの記録で、1 回は文を数えるだけの最初の実行である。
同じテープで $\boldsymbol{x} = \boldsymbol{0}$ を復元した 2 回目は、色数と同じ 3 回だった。
密な `hessian` は 24 の単位方向に文を数える 1 回を加えた 25 回実行した。

復元した非零と閉形式の最大差は $4.4 \times 10^{-16}$ N/m で、成分の最大値 2.067 N/m の 1 ulp 程度である。
復元した値は密なヘッセ行列とビットまで一致し、密なヘッセ行列の帯の外の成分はすべて 0 だった。
同じ色の列は $2r + 1$ 以上離れているので、ある行に接ベクトルの成分を保持するのは、その行の帯に入る同じ色の 1 列だけである。
ほかの列の寄与は接ベクトルの成分 0 との積で厳密に 0 になり、和の値を変えない。
ヒートマップでは対角と両隣の帯だけが色を持つ。
対角は中央で約 2 N/m、両端で約 2.07 N/m で、伸びの大きい両端のばねほど $3\beta_d s^2$ の分だけ硬い。
$\boldsymbol{x} = \boldsymbol{0}$ では 4 次の項が消え、閉形式（対角 $2k$、隣 $-k$）と厳密に一致した。

$n = 64$ にすると非零は 4096 成分のうち 190 個で、復元の関数の実行は 4 回と 3 回のまま、密な計算は 65 回に増える。
$r = 3$ にすると非零は 156 個、色数は 7 で、実行回数は 8 回と 7 回になる。
閉形式との最大差は $8.9 \times 10^{-16}$ N/m で、帯の幅が広がっても丸め誤差の水準にとどまる。
$\beta = 0$ N/m³ ではヘッセ行列が評価点によらず、二つの点の成分の最大値はどちらも $2k = 2$ N/m になる。
構造と色数は値ではなく記録した文から決まるので、$\beta$ や $A$ を変えても変わらない。

## まとめ

近くの変数とだけ相互作用する関数のヘッセ行列は、`Tape::linearize` の 1 回の記録から `hessian_pattern` で構造を求め、`scioxide_sparse::derivative_coloring` で列を彩色すれば、色数と同じ本数の HVP で復元できる。
半帯幅 $r$ の帯では色数は下界 $2r + 1$ に等しく、原子の数 $n$ によらないので、記録の回数は密なヘッセ行列の $n$ 回から $2r + 1$ 回に減る。
`Tape::<Dual<f64>>::sparse_hessian_into` は値を構造の CSR の順に書き、新しいテープでは関数を 1 回余分に実行するので、関数は決定論的でなければならない。
評価点を変えて繰り返すときは、構造、彩色、テープ、値の配列を使い回し、`sparse_hessian_into` だけを呼ぶ。
構造は同じ分岐をたどる評価点でだけ有効なので、分岐を含む関数では分岐ごとに構造を求め直す。
