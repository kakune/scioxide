常微分方程式（ODE）の解を $t = 0$ のまわりでべき級数に展開できれば、係数から解の値だけでなく、級数が使える範囲も分かる。
べき級数が収束する最大の半径を収束半径と呼ぶ。
収束半径は複素平面で展開の中心に最も近い解の特異点までの距離に等しい。
Taylor 級数法の ODE 解法は各刻みで解の係数を求め、刻みを収束半径より十分小さく選んで進む。
この例題では係数を `scioxide-ad` の Taylor ジェット `Jet` の算術で 1 次ずつ求め、厳密な係数と、係数から推定した収束半径を確かめる。

## 三つの初期値問題と厳密な係数

解を $y(t) = \sum_{n \ge 0} a_n t^n$、$a_n = y^{(n)}(0)/n!$（正規化 Taylor 係数）と書く。
次の三つの自励系 $y' = f(y)$ を扱う。

- $y' = y^2$、$y(0) = 1$ の解は $y = 1/(1 - t)$ で、係数はすべて $a_n = 1$ である。
  $t = 1$ に極があるので、収束半径は $R = 1$ である。
- $y' = 1 + y^2$、$y(0) = 0$ の解は $y = \tan t$ で、極 $t = \pm\pi/2$ から $R = \pi/2$ である。
- $y' = 1 - y^2$、$y(0) = 0$ の解は $y = \tanh t$ である。
  $\tanh t$ は実軸の上では有界で滑らかだが、虚軸上の極 $t = \pm i\pi/2$ のため、収束半径はやはり $R = \pi/2$ である。

$\tan t$ と $\tanh t$ は奇関数なので偶数次の係数は 0 で、奇数次の係数は

$$
a_{2m-1}^{\tan} = \frac{T_{2m-1}}{(2m-1)!}, \qquad
a_{2m-1}^{\tanh} = (-1)^{m-1}\,\frac{T_{2m-1}}{(2m-1)!}, \qquad
a_1^{\tan}, a_3^{\tan}, a_5^{\tan}, a_7^{\tan}, \ldots = 1, \tfrac{1}{3}, \tfrac{2}{15}, \tfrac{17}{315}, \ldots
$$

である。
$T_{2m-1} = 1, 2, 16, 272, 7936, \ldots$ は正接数で、Bernoulli 数 $B_{2m}$ を使えば $T_{2m-1} = (-1)^{m-1} 2^{2m}(2^{2m} - 1) B_{2m}/(2m)$ と書ける。
正接数は Knuth と Buckholtz の整数の漸化式で求まり、ODE とは独立な検算に使える。
この漸化式は非負の係数による和と積だけからなるので、`f64` で計算しても相対誤差は演算回数に比例する丸めの大きさにとどまる。

$\tan t$ の部分分数展開 $\tan t = \sum_{k \ge 1} 8t / \bigl((2k - 1)^2\pi^2 - 4t^2\bigr)$ を $t$ について展開すると

$$
|a_{2m-1}| = 2 \left( \frac{2}{\pi} \right)^{2m} \lambda(2m), \qquad
\lambda(s) = \sum_{k = 1, 3, 5, \ldots} k^{-s} = 1 + 3^{-s} + 5^{-s} + \cdots
$$

を得る。
$\lambda(s) \to 1$ なので、奇数次の係数は $|a_n| \approx (4/\pi) R^{-n}$ のように等比数列に近い形で減る。

## 係数を 1 次ずつ決める再帰

$y' = f(y)$ の両辺の $t^k$ の係数を比べると

$$
(k + 1)\,a_{k+1} = [f(y)]_k
$$

になる。
ここで $[u]_k$ は級数 $u(t)$ の $k$ 次の係数である。
Taylor 係数の積は Cauchy 積 $[uv]_k = \sum_{j=0}^{k} u_j v_{k-j}$ で、和と定数倍も次数ごとなので、$[f(y)]_k$ は $a_0, \ldots, a_k$ だけで決まる。
したがって、既知の $a_0, \ldots, a_k$ とそれより上の 0 を並べた級数を $f$ に通すと、$k$ 次の係数は正しく、そこから $a_{k+1}$ が求まる。
これを $k = 0, 1, \ldots, K - 1$ と繰り返せば $a_1, \ldots, a_K$ が得られる。

`Jet<V, N>` は 1 変数の関数の正規化 Taylor 係数 $c_0, \ldots, c_{N-1}$ を持つ数値型で、`Real` の演算は合成した級数の係数を $N - 1$ 次まで返す（[Taylor ジェットと高階の係数](../../algorithms/taylor-jets/)）。
`Jet::new(coefficients)` は係数の配列から級数を作り、`coefficients()` は係数の配列を返す。
右辺 $f$ を `R: Real` について一度だけ書き、`Jet::<f64, N>::new(a)` を渡せば、$[f(y)]_0, \ldots, [f(y)]_{N-1}$ が得られる。
`Jet` の $N$ は型の定数（const ジェネリクス）なので、実行時の入力の次数 $K$ で型を変えることはできない。
ここでは入力の上限 $K = 40$ に合わせて $N = 41$ に固定し、$K$ はループの回数だけを変える。
$k$ より上の係数は 0 の置き場所で、$[f(y)]_k$ には影響しない。

1 回の非線形な演算は $O(N^2)$ の演算を要するので、$K$ 回の再帰は $O(KN^2)$ になる。
$y^2$ のような特定の $f$ なら漸化式 $(k + 1)a_{k+1} = \sum_j a_j a_{k-j}$ を手で書いて全体を $O(K^2)$ にできるが、ジェットを使えば `Real` の演算で書ける任意の $f$ に同じ手順が使える。
`Jet` の精度の保証は 8 次までで、引数と係数が 0 か大きさ `[√MIN_POSITIVE, √MAX]` の範囲にある点では、係数 $c_k$ の絶対誤差は $64\varepsilon(k + 1)g$ に最小の非正規化数を加えた値以下である（$g$ は厳密な合成の項の絶対値の和）。
それより高い次数には上界を与えない。
この例題の 9 次以上の係数は厳密な係数との比較で確かめる。
`scioxide-ad` は Taylor 級数法の ODE 解法そのものを提供しないので、刻みの制御を含む積分には [scioxide-ode](../../../scioxide-ode/) の解法を使う。

次のブロックは三つのセルが共有する定義である。
`Equation` が三つの初期値問題を表し、`rhs` が右辺 $f$、`initial` が $y(0)$、`radius` が収束半径 $R$、`solution` が厳密解、`exact_coefficients` が正接数による厳密な係数である。
`solution` は `f64` の標準関数で参照値を計算し、`exact_coefficients` は自動微分を使わずに係数を求める。

```rust
//| id: ad-taylor-ode-model
//| kind: definitions
//| title: 三つの初期値問題の右辺、厳密解と厳密な係数
//| crates: [scioxide-ad]
use scioxide_ad::Real;

/// 初期値問題 y′ = f(y)、y(0) = y₀。
#[derive(Clone, Copy, PartialEq, Eq)]
pub(crate) enum Equation {
    /// y′ = y²、y(0) = 1。解は 1/(1 − t)。
    Pole,
    /// y′ = 1 + y²、y(0) = 0。解は tan t。
    Tangent,
    /// y′ = 1 − y²、y(0) = 0。解は tanh t。
    Tanh,
}

impl Equation {
    pub(crate) fn from_label(label: &str) -> Result<Self, String> {
        match label {
            "y′ = y²、y(0) = 1" => Ok(Self::Pole),
            "y′ = 1 + y²、y(0) = 0" => Ok(Self::Tangent),
            "y′ = 1 − y²、y(0) = 0" => Ok(Self::Tanh),
            _ => Err(format!("未知の初期値問題: {label}")),
        }
    }

    pub(crate) fn label(self) -> &'static str {
        match self {
            Self::Pole => "y′ = y²、y(0) = 1",
            Self::Tangent => "y′ = 1 + y²、y(0) = 0",
            Self::Tanh => "y′ = 1 − y²、y(0) = 0",
        }
    }

    /// 右辺 f(y)。数値型 R について一度だけ書く。
    pub(crate) fn rhs<R: Real>(self, y: R) -> R {
        match self {
            Self::Pole => y * y,
            Self::Tangent => y * y + 1.0,
            Self::Tanh => -(y * y) + 1.0,
        }
    }

    pub(crate) fn initial(self) -> f64 {
        if self == Self::Pole { 1.0 } else { 0.0 }
    }

    /// 収束半径 R（最も近い特異点までの距離）。
    pub(crate) fn radius(self) -> f64 {
        if self == Self::Pole {
            1.0
        } else {
            std::f64::consts::FRAC_PI_2
        }
    }

    /// 厳密解 y(t)。参照値（f64 の標準関数）。
    pub(crate) fn solution(self, t: f64) -> f64 {
        match self {
            Self::Pole => 1.0 / (1.0 - t),
            Self::Tangent => t.tan(),
            Self::Tanh => t.tanh(),
        }
    }

    /// 厳密な係数 a_0, …, a_order。正接数 T_{2m−1} を Knuth–Buckholtz の漸化式で求める。
    pub(crate) fn exact_coefficients(self, order: usize) -> Vec<f64> {
        if self == Self::Pole {
            return vec![1.0; order + 1];
        }
        let count = order / 2 + 1;
        let mut tangent = vec![0.0_f64; count + 1];
        tangent[1] = 1.0;
        for k in 2..=count {
            tangent[k] = (k - 1) as f64 * tangent[k - 1];
        }
        for k in 2..=count {
            for j in k..=count {
                tangent[j] = (j - k) as f64 * tangent[j - 1] + (j - k + 2) as f64 * tangent[j];
            }
        }
        let mut coefficients = vec![0.0; order + 1];
        let mut factorial = 1.0;
        for n in 1..=order {
            factorial *= n as f64;
            if n % 2 == 1 {
                let m = (n + 1) / 2;
                let sign = if self == Self::Tanh && m % 2 == 0 {
                    -1.0
                } else {
                    1.0
                };
                coefficients[n] = sign * tangent[m] / factorial;
            }
        }
        coefficients
    }
}
```

## 係数と厳密な値

次のセルは初期値問題と次数 $K$（4 から 40 の整数）を選び、`Jet<f64, 41>` の算術による再帰で $a_1, \ldots, a_K$ を求める。
表は各次数の係数、厳密な係数、絶対誤差と相対誤差を示す。
厳密な係数が 0 の次数では相対誤差を定義しない。
グラフは $|a_n|$ を対数軸で描き、$R^{-n}$ を破線で重ねる。
係数が 0 の次数は対数軸に描けないので除く（表ではその行の係数が 0 になる）。
このセルは初期値問題と係数を後の二つのセルに渡す。

```rust

//| ref: ad-taylor-ode-coefficients
//| title: Jet の算術で ODE の級数係数を 1 次ずつ求め、正接数による厳密な係数と比べる
//| run: reactive
//| uses: [ad-taylor-ode-model]
//| crates: [scioxide-ad]
//| exports: [equation, coefficients]
//| inputs:
//|   equation: {"type":"select","label":"初期値問題","description":"右辺 f(y) と初期値。","options":["y′ = 1 + y²、y(0) = 0","y′ = 1 − y²、y(0) = 0","y′ = y²、y(0) = 1"],"value":"y′ = 1 + y²、y(0) = 0"}
//|   order: {"type":"range","label":"次数 K","description":"求める係数の最高次数。","min":4,"max":40,"step":1,"value":25}
//| cases:
//|   - {"id":"tanh","label":"y′ = 1 − y²","description":"係数の符号が交互に変わるが、大きさは tan と同じで、収束半径も π/2 になる。","inputs":{"equation":"y′ = 1 − y²、y(0) = 0"}}
//|   - {"id":"pole-order-40","label":"y′ = y²、K = 40","description":"係数はすべてちょうど 1 で、40 次まで誤差は 0 である。","inputs":{"equation":"y′ = y²、y(0) = 1","order":40}}

//|   - case: default

//|       - {"artifact":"coefficients","path":"/rows/2/1","equals":0}
//|       - {"artifact":"coefficients","path":"/rows/3/1","approx":{"value":0.3333333333333333,"rtol":1e-15}}
//|       - {"artifact":"coefficients","path":"/rows/7/1","approx":{"value":0.05396825396825397,"rtol":1e-14}}
//|       - {"artifact":"coefficients","path":"/rows/25/4","range":{"max":1e-14}}
//|       - {"artifact":"coefficients","path":"/rows/24/4","equals":null}
//|   - case: tanh
//|     expect:
//|       - {"artifact":"coefficients","path":"/rows/3/1","approx":{"value":-0.3333333333333333,"rtol":1e-15}}
//|       - {"artifact":"coefficients","path":"/rows/5/1","approx":{"value":0.13333333333333333,"rtol":1e-14}}
//|       - {"artifact":"coefficients","path":"/rows/25/4","range":{"max":1e-14}}
//|   - case: pole-order-40
//|     expect:
//|       - {"artifact":"coefficients","path":"/rows/40/1","equals":1}
//|       - {"artifact":"coefficients","path":"/rows/40/3","equals":0}

// 係数の数 N は型の定数なので、入力の上限 K = 40 に合わせて 41 に固定する。
const N: usize = 41;
let problem = Equation::from_label(&equation)?;
let k_max = order as usize;
let mut a = [0.0_f64; N];
a[0] = problem.initial();
for k in 0..k_max {
    // c_0..c_k に既知の係数、それより上に 0 を置いた級数を右辺に通す。
    // (k + 1) a_{k+1} = [f(y)]_k は a_0..a_k だけで決まる。
    let f = problem.rhs(Jet::<f64, N>::new(a)).coefficients();
    a[k + 1] = f[k] / (k + 1) as f64;

        (n, a[n] + 0.0, exact[n], error, relative)
    })
    .collect();

    { "key": "2", "label": "厳密な係数 [-]", "type": "number", "format": digits },

        "key": "4",
        "label": "相対誤差 [-]",

    }

    metadata = serde_json::json!({ "id": "coefficients" })

// |a_n| と R^{−n}。R^{−n} は R で割り続けて作る。
let radius = problem.radius();
let magnitudes: Vec<[f64; 2]> = (1..=k_max)
    .filter(|&n| a[n] != 0.0)
    .map(|n| [n as f64, a[n].abs()])
    .collect();

        scale /= radius;

            "style": { "symbol": "circle", "showSymbol": true }

        serde_json::json!({ "name": "R⁻ⁿ", "points": geometric, "style": { "lineType": "dashed" } })

    options = &serde_json::json!({
        "link": { "group": "taylor-order" },
        "xLabel": "次数 n",
        "yLabel": "係数の大きさ |a_n| [-]",
        "yType": "log"
    })

```

既定値（$y' = 1 + y^2$、$K = 25$）では、偶数次の係数はちょうど 0 になり、奇数次の係数は正接数による厳密な係数と相対誤差 $2.3 \times 10^{-16}$ 以下で一致した。
$K = 40$ に上げても相対差は $6.0 \times 10^{-16}$ 以下で、`Jet` の精度の保証が及ばない 9 次以上でも、誤差は次数とともにほとんど増えない。
$\tan t$ の右辺の Cauchy 積 $\sum_j a_j a_{k-j}$ は同じ符号の項の和なので、桁落ちが起きない。
グラフの $|a_n|$ は破線 $R^{-n}$ とほぼ平行に、$(2/\pi)^n$ の割合で減る。
$|a_n|$ と破線の比はほぼ一定の $4/\pi \approx 1.27$ で、等比数列に近い減り方の公比が $1/R$ を表している。

$y' = 1 - y^2$ に切り替えると、係数の符号は $+, -, +, \ldots$ と交互に変わるが、大きさは $\tan t$ と同じで、相対誤差も同じ値になる。
積 $a_j a_{k-j}$ の符号は $k$ だけで決まるので、この場合も同じ符号の項の和である。
$y' = y^2$、$K = 40$ では係数はすべてちょうど 1 で、誤差は 0 である。
$[y^2]_k = k + 1$ の和が整数の和として正確に計算されるためで、グラフの点は破線 $R^{-n} = 1$ の上に並ぶ。

## 収束半径の推定

Cauchy–Hadamard の公式 $1/R = \limsup_{n \to \infty} |a_n|^{1/n}$ から、根による推定 $\hat{R}_{\mathrm{root}} = |a_n|^{-1/n}$ は $R$ に近づく。
隣り合う非零係数 $a_p$、$a_n$（$p < n$）の比による推定 $\hat{R}_{\mathrm{ratio}} = |a_p/a_n|^{1/(n-p)}$ も使える。
$1/(1 - t)$ ではどちらの推定も最初から $R = 1$ を返す。

$\tan t$ と $\tanh t$ では、前の節の式から

$$
\hat{R}_{\mathrm{root}} = \frac{\pi}{2} \left( \frac{\pi}{4\lambda(n + 1)} \right)^{1/n}, \qquad
\hat{R}_{\mathrm{ratio}} = \frac{\pi}{2} \sqrt{\frac{\lambda(n - 1)}{\lambda(n + 1)}}
$$

である（$n$ は奇数、$p = n - 2$）。
根による推定は $\lambda \to 1$ でも因子 $(\pi/4)^{1/n}$ が残るので、相対誤差は約 $\ln(4/\pi)/n \approx 0.24/n$ で、$n$ に反比例してしか減らない。
比による推定は $\lambda(s) - 1 \approx 3^{-s}$ から相対誤差が約 $\tfrac{4}{9} \cdot 3^{-(n-1)}$ で、次数が 2 上がるごとに 9 分の 1 になる。

比による推定の誤差が次数について等比数列のように減るのは、最も近い特異点が単純な極か、$\tan t$ の $\pm\pi/2$ のように係数の符号をそろえる単純な極の対で、ほかの特異点がそれより遠いときである。
$\tan t$ では、次に近い極 $\pm 3\pi/2$ との距離の比 $1/3$ が誤差の因子 $3^{-(n-1)}$ に現れている。
最も近い特異点が実軸から離れた複素共役の対 $t = \rho e^{\pm i\theta}$（$0 < \theta < \pi/2$）のときは、係数に $\cos(n\theta)$ のような振動が乗り、隣り合う係数の比は収束しない。
その場合も $|a_n|^{1/n}$ の上極限は $1/R$ を与えるので、遅いが根による推定のほうがロバストである。

次のセルは前のセルの初期値問題と係数を受け取り、二つの推定を各次数で求めて、真の $R$ との相対誤差を対数軸で描く。
比による推定は直前の非零係数との比で作るので、$\tan t$ と $\tanh t$ では $p = n - 2$、$1/(1 - t)$ では $p = n - 1$ になる。
表は最後の非零係数の次数での二つの推定と相対誤差を示す。
相対誤差がちょうど 0 になる点は対数軸に描けないので除き、その数を表に示す。
グラフの横軸の次数 $n$ は前のセルの係数の図と連動する。

```rust
//| id: ad-taylor-ode-radius
//| ref: ad-taylor-ode-radius
//| title: 係数の根と比から収束半径を推定し、真の値と比べる
//| run: reactive
//| uses: [ad-taylor-ode-model]
//| crates: [scioxide-ad, scioxide-core]

// 根 |a_n|^(−1/n) と、直前の非零係数 a_p との比 |a_p/a_n|^(1/(n−p)) による推定。
let (mut roots, mut ratios, mut excluded) = (Vec::new(), Vec::new(), 0);
let (mut previous, mut last) = (None, (0, f64::NAN, None));
for n in 1..a.len() {
    if a[n] == 0.0 {
        continue;
    }
    let root = RealScalar::powf(a[n].abs(), -1.0 / n as f64);
    let ratio =
        previous.map(|p: usize| RealScalar::powf((a[p] / a[n]).abs(), 1.0 / (n - p) as f64));
    for (points, estimate) in [(&mut roots, Some(root)), (&mut ratios, ratio)] {
        match estimate.map(relative) {
            Some(error) if error > 0.0 => points.push([n as f64, error]),
            Some(_) => excluded += 1,
            None => {}
        }
    }
    previous = Some(n);
    last = (n, root, ratio);
}
let (n_last, root, ratio) = last;
```

既定値の $\tan t$、$K = 25$ では、根による推定は $1.5557$ で、$\pi/2 = 1.5708$ に約 1 % 足りない。
相対誤差 $9.6 \times 10^{-3}$ は $\ln(4/\pi)/25 = 9.7 \times 10^{-3}$ とほぼ一致する。
比による推定の相対誤差は $1.6 \times 10^{-12}$ で、$\tfrac{4}{9} \cdot 3^{-24} = 1.57 \times 10^{-12}$ と一致する。
グラフでは、丸印（根）が $1/n$ の割合でゆっくり下がり、菱形（比）は片対数の図でほぼ直線に並んで、次数 2 ごとに 9 分の 1 ずつ下がる。
$\tanh t$ を選んでも係数の大きさが同じなので、二つの推定は $\tan t$ と同じ値になる。
$1/(1 - t)$ では係数がすべて 1 なので、どちらの推定もちょうど $R = 1$ になり、すべての点が対数軸から除かれる（$K = 25$ で 49 点）。

## 部分和の誤差と刻み

収束半径は部分和 $S_n(h) = \sum_{j \le n} a_j h^j$ の誤差の減り方に現れる。
$|a_n| \approx C R^{-n}$ なら項の大きさは $C(h/R)^n$ で、$h < R$ では誤差も $(h/R)^n$ の割合で減り、$h \ge R$ では項が減らないので部分和は収束しない。
$\tanh t$ は $h \ge \pi/2$ でも有限の値を持つが、べき級数は複素平面の極 $\pm i\pi/2$ のために発散する。
$1/(1 - t)$ では誤差が閉形式 $y(h) - S_K(h) = h^{K+1}/(1 - h)$ で与えられ、検算に使える。

次のセルは前のセルの初期値問題と係数を受け取り、刻みと収束半径の比 $h/R$（0.2 から 1.2）を選んで、$h = (h/R) \cdot R$ での部分和を求める。
グラフは部分和の誤差 $|S_n(h) - y(h)|$、項の大きさ $|a_n| h^n$、破線 $(h/R)^n$ を対数軸で描き、横軸の次数 $n$ は前の二つの図と連動する。
参照値 $y(h)$ は `f64` の標準関数による厳密解で、$h \ge R$ では部分和と比べない。
表は $S_K(h)$、$y(h)$、誤差、$(h/R)^{K+1}$、最後の非零の項の大きさと、誤差がちょうど 0 で対数軸から除いた点の数を示す。
横線は $y(h)$ の丸めの大きさ $\varepsilon |y(h)|$ で、部分和の誤差はこの水準まで下がると、それより先は丸めで決まる。

既定値の $\tan t$、$K = 25$、$h/R = 0.8$（$h = 0.4\pi \approx 1.2566$）では、$S_{25}(h) = 3.0691$ と $\tan h = 3.0777$ の差は $8.6 \times 10^{-3}$ だった。
グラフの誤差は破線 $(h/R)^n$ と同じ傾きで下がる。
奇数次の項はすべて正なので、誤差は省いた項の和で、最後の項 $4.8 \times 10^{-3}$ に公比 $(h/R)^2 = 0.64$ の等比級数の因子 $0.64/(1 - 0.64)$ を掛けた値とほぼ等しい。
$h/R = 0.5$ では誤差は $1.3 \times 10^{-8}$ まで下がり、$(h/R)^{26} = 1.5 \times 10^{-8}$ と同じ桁になる。
丸めの水準 $\varepsilon|y(h)|$ に届くには、$h/R = 0.5$ でもおよそ 50 次が要る。
$h/R = 1.1$ では項の大きさが次数とともに増え（最後の項は 13.8）、$S_{25}(h) = 73.2$ は発散する部分和の途中の値にすぎない。

$\tanh t$ を選ぶと、$h/R = 0.8$ での誤差は $1.9 \times 10^{-3}$ で、$\tan t$ より小さい。
項の符号が交互に変わる交代級数なので、誤差は最初に省いた項の大きさ（$3.1 \times 10^{-3}$）以下になる。
$1/(1 - t)$ では $h/R = 0.8$ の誤差が $0.0151$ で、閉形式 $h^{26}/(1 - h) = 5 \times 0.8^{26}$ と一致する。
$h$ を $R$ で測れば、三つの問題で項の大きさは同じ $(h/R)^n$ の割合で減り、刻みの選び方を決めるのは $h/R$ である。

## まとめ

ODE $y' = f(y)$ の級数係数は、右辺を `R: Real` について書き、既知の係数を並べた `Jet::new(a)` を右辺に通して $(k + 1)a_{k+1} = [f(y)]_k$ から 1 次ずつ求められる。
`Jet` の長さ $N$ は型の定数なので、必要な最大次数で型を決め、まだ求めていない係数を 0 にしておけばよく、計算コストは $O(KN^2)$ である。
`Jet` の精度の保証は 8 次までなので、それより高い次数は厳密な係数や別の方法で確かめ、この例題では 40 次まで相対差 $6 \times 10^{-16}$ 以下だった。
収束半径は隣り合う非零係数の比で推定すると速く収束し、$|a_n|^{-1/n}$ による推定は $1/n$ でしか近づかないが、係数が振動する場合にも使える。
部分和の誤差は $(h/R)^n$ の割合で減り、$\tanh t$ のように実軸上で滑らかな解でも、複素平面の特異点のために $h \ge R$ では級数が発散する。
Taylor 級数法の刻みは推定した $R$ に対して $h/R$ が 1 より十分小さくなるように選び、求めたい精度と次数の兼ね合いで決める。
