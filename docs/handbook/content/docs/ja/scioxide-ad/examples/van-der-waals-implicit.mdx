状態方程式は圧力 $p$、温度 $T$、モル体積 $V$ を結ぶ関係で、van der Waals 式は $V$ について 3 次式になる。
圧力と温度を与えて体積を求めるには 3 次式の根を選ぶ必要があり、その根の求め方と、気液共存の圧力を Maxwell の等面積則で決める問題は [scioxide-rootfind の van der Waals 気体と Maxwell の等面積則](../../../scioxide-rootfind/examples/van-der-waals-maxwell/) が主に扱う。

この例題が扱うのは、求めた体積の感度 $\partial V/\partial p$、$\partial V/\partial T$ と 2 階の $\partial^2 V/\partial p^2$ である。
根を求める反復を微分しなくても、陰関数定理を使えば根での残差の微分だけで感度が決まる。
scioxide-ad では残差を `Residual` として一度だけ書き、`implicit_solution_into` が呼び出し側の渡した根に陰関数定理の微分を付ける。
同じ状態方程式の $\partial p/\partial V$ を差分で求めたときの刻みと誤差の問題は [van der Waals 状態方程式の導関数と推定誤差](../../../scioxide-differentiate/examples/van-der-waals-adaptive/) で扱い、このページはその逆数にあたる感度を差分の誤差なしに求める。

## 換算形の状態方程式

臨界点の値 $T_c$、$p_c$、$V_c$ で割った換算変数 $T_r = T/T_c$、$p_r = p/p_c$、$V_r = V/V_c$ を使うと、van der Waals 式は物質によらない形

$$
p_r = \frac{8T_r}{3V_r - 1} - \frac{3}{V_r^2}, \qquad V_r > \frac{1}{3}
$$

になる。
以下では添字 $r$ を省き、$p$、$T$、$V$ はすべて換算量を表す。

CO2 の臨界値は rootfind と differentiate の例題とそろえて $T_c = 304.13$ K、$p_c = 7.3773$ MPa とし、$V_c$ には van der Waals 式の関係 $V_c = 3RT_c/(8p_c) \approx 0.12854$ L/mol（$R = 8.314462618$ J/(mol·K)）を使う。
この値は実測の臨界体積（約 0.094 L/mol）より大きく、van der Waals 式は定性的なモデルである。

残差を

$$
F(V; p, T) = p - \frac{8T}{3V - 1} + \frac{3}{V^2}
$$

とおき、$V^2(3V - 1)$ を掛けると 3 次式 $3pV^3 - (p + 8T)V^2 + 9V - 3 = 0$ になる。
$T \ge 1$ では等温線が $V$ について単調に減るので、どの $p > 0$ に対しても実根は 1 個しかない（$T = p = 1$ では 3 重根 $V = 1$）。
$T < 1$ では等温線の極小と極大（スピノーダル）の圧力の間で実根が 3 個あり、たとえば $T = 0.9$ では $0.420 < p < 0.724$ である。

最小の根が液相の枝、最大の根が気相の枝で、中間の根は $\partial p/\partial V > 0$ の力学的に不安定な状態である。
液相と気相のどちらが安定でどちらが準安定かは飽和圧力（$T = 0.9$ で $p_{\mathrm{sat}} \approx 0.647$）との大小で決まり、その計算は rootfind の例題に任せる。

## 陰関数定理による感度

$F_V \ne 0$ の根では、$F(V(p, T); p, T) = 0$ を $p$ と $T$ で微分して

$$
\frac{\partial V}{\partial p} = -\frac{F_p}{F_V} = -\frac{1}{F_V}, \qquad
\frac{\partial V}{\partial T} = -\frac{F_T}{F_V} = \frac{8}{(3V - 1)F_V}, \qquad
F_V = \frac{24T}{(3V - 1)^2} - \frac{6}{V^3} = -\left(\frac{\partial p}{\partial V}\right)_T
$$

を得る。
$F$ は $p$ について 1 次（$F_p = 1$、$F_{Vp} = 0$）なので、$\partial V/\partial p$ をもう一度 $p$ で微分すると

$$
\frac{\partial^2 V}{\partial p^2} = \frac{F_{VV}}{F_V^2}\,\frac{\partial V}{\partial p} = -\frac{F_{VV}}{F_V^3}, \qquad
F_{VV} = \frac{18}{V^4} - \frac{144T}{(3V - 1)^3}
$$

になる。

等温圧縮率と熱膨張率は $\kappa_T = -(1/V)(\partial V/\partial p)_T$、$\alpha_p = (1/V)(\partial V/\partial T)_p$ で、換算変数からは $\kappa_T = -(\partial V_r/\partial p_r)/(p_c V_r)$、$\alpha_p = (\partial V_r/\partial T_r)/(T_c V_r)$ と求まる。
理想気体なら $\kappa_T = 1/p$、$\alpha_p = 1/T$ で、体積の比 $V/V_{\mathrm{ideal}} = pV/(RT)$ は圧縮因子 $Z$ である。

臨界点 $(V, T, p) = (1, 1, 1)$ では $F_V = 0$ かつ $F_{VV} = 0$ で、感度は発散する。
$t = T - 1$、$v = V - 1$ で展開すると $p - 1 \approx 4t - 6tv - \tfrac{3}{2}v^3$ である。

臨界等温線（$t = 0$）では $v \approx -(2(p - 1)/3)^{1/3}$、$\partial V/\partial p \approx -\tfrac{2}{9}v^{-2}$ なので、$\delta = \lvert p - 1 \rvert$ について $\lvert \partial V/\partial p \rvert \approx \tfrac{2}{9}(3/(2\delta))^{2/3} \approx 0.2912\,\delta^{-2/3}$ になる。
臨界等容線（$V = 1$、$p = 1 + 4t$、$t > 0$）では $F_V = 6t$ なので、$\delta = t$ について $\partial V/\partial p = -1/(6\delta)$ がちょうど成り立つ。
発散の指数 $2/3$ と $1$ は臨界点への近づき方で変わり、どちらも平均場の指数で、実在の流体で測られる臨界指数とは異なる。

## 陰関数の解と `Residual`

`Residual` は、$n$ 個の未知数 $y$ と $q$ 個のパラメータ $\theta$ をとる残差 $F(y, \theta)$ を、スカラーのマスクを持つすべての数値型 `R: Real<S, Mask = bool>` に対して一度だけ書くトレイトである。
この例題では $n = 1$、$q = 2$ で、$y = (V)$、$\theta = (p, T)$ である。

`implicit_solution_into(residual, solution, parameters, tolerance, out)` は、パラメータの微分を除いた最も内側の値（base）で $F = 0$ を満たす解 `solution`（`&[S]`）を受け取り、`out` に $y(\theta)$ を微分付きで書く。
関数は $F = 0$ を解かず、渡された解を検査する。
最も内側の段では $F$ を `solution` で評価し、$\lVert F \rVert_2 \le \mathrm{atol} + \mathrm{rtol}\,\lVert y \rVert_2$ を `tolerance`（`ResidualTolerance`）で確かめ、満たさなければ `InvalidInput`（引数 `solution`、`OutOfRange`）を返す。

微分の段が 1 つ上がるごとに、1 つ下の段の解を同じ関数で求め、$F_y$ と $F_\theta$ の列を `Dual` の単位接ベクトルで $n + q$ 回の残差評価から作る。
$F_y$ は base の値を部分ピボット付き LU 分解で 1 回だけ分解し（`solve_into`）、$\partial y/\partial \theta = -F_y^{-1}F_\theta$ を `Real::combine` で値と偏微分の組にする。
テープの上では出力 1 個ごとに `combine` の 1 文として記録される。
段ごとに繰り返すので、`hessian` が渡す `Var<'t, Dual<f64>>` では 2 階の感度も入れ子の次数まで正確になる。

段ごとの計算コストは残差評価 $n + q$ 回、$n \times n$ の分解 1 回、$O(n(n + q))$ の確保した作業領域で、この確保はテープを使い回しても残る。
エラーは、`out` の長さが `solution` と違えば `DimensionMismatch`、$F_y$ の LU 分解のピボットが 0 か非有限になれば `Singular`、残差のエラーはそのまま返る。
`Singular` はピボットがちょうど 0 か非有限のときだけで、$F_y$ が 0 に近いだけなら感度は大きな有限の値になる（[陰関数の微分](../../algorithms/implicit-functions/)）。

解そのものは微分しない値として渡すので、根を求めた計算（ここでは伴行列の固有値と Aberth–Ehrlich 反復による精度改善）は記録されない。
感度の正しさは、渡した根が $F = 0$ の根であることと、$F_V$ の精度だけで決まる。

次のブロックは 2 つのセルが共有する定義である。
`VanDerWaals` が残差 $F$ で、`R` の演算はすべて `Real` のメソッドなので、`f64`、`Dual`、`Var` のどれでも同じ式を評価する。
`volume_roots` は scioxide-rootfind の `polynomial_roots_with_options`（既定の設定で、方法は `Auto`）で 3 次式の全根を求め、実根を昇順に返す。
係数は rootfind の例題と同じ昇べきの順 $[-3,\,9,\,-(p + 8T),\,3p]$ である。
`residual_partials` は検算用の閉形式 $F_V$、$F_{VV}$ で、`f64` の四則演算で計算する。

```rust
//| id: ad-vdw-model
//| kind: definitions
//| title: 換算形の van der Waals 式の残差と体積の根
//| crates: [scioxide-ad, scioxide-core, scioxide-rootfind]
use scioxide_ad::{Real, Residual};
use scioxide_core::SciOxideError;
use scioxide_rootfind::{PolynomialRootOptions, PolynomialRootReport, polynomial_roots_with_options};

/// 残差 F(V; p, T) = p − 8T/(3V − 1) + 3/V²。未知数は [V]、パラメータは [p, T]（換算量）。
pub(crate) struct VanDerWaals;

impl Residual for VanDerWaals {
    fn residual<R: Real<f64, Mask = bool>>(
        &self,
        solution: &[R],
        parameters: &[R],
        out: &mut [R],
    ) -> Result<(), SciOxideError> {
        let v = solution[0];
        let (p, t) = (parameters[0], parameters[1]);
        out[0] = p - t * 8.0 / (v * 3.0 - 1.0) + (v * v).recip() * 3.0;
        Ok(())
    }
}

/// 3pV³ − (p + 8T)V² + 9V − 3 = 0 の実根（昇順）と全根計算のレポート。
pub(crate) fn volume_roots(
    p: f64,
    t: f64,
) -> Result<(Vec<f64>, PolynomialRootReport<f64>), SciOxideError> {
    let coefficients = [-3.0, 9.0, -(p + 8.0 * t), 3.0 * p];
    let roots = polynomial_roots_with_options(&coefficients, &PolynomialRootOptions::default())?;
    // 実係数の多項式では、全根計算は検査を通る限り実軸に近い根を虚部が厳密に 0 の値にして返す。
    let mut real: Vec<f64> = roots
        .roots()
        .iter()
        .filter(|z| z.im == 0.0)
        .map(|z| z.re)
        .collect();
    real.sort_by(f64::total_cmp);
    Ok((real, roots.report()))
}

/// 検算用の閉形式 F_V = 24T/(3V − 1)² − 6/V³ と F_VV = 18/V⁴ − 144T/(3V − 1)³（f64 の四則演算）。
pub(crate) fn residual_partials(v: f64, t: f64) -> (f64, f64) {
    let d = 3.0 * v - 1.0;
    let f_v = 24.0 * t / (d * d) - 6.0 / (v * v * v);
    let f_vv = 18.0 / (v * v * v * v) - 144.0 * t / (d * d * d);
    (f_v, f_vv)
}
```

## 選んだ状態の感度

次のセルは $(T, p)$ で 3 次式の実根を `volume_roots` で求め、選んだ根を `implicit_solution_into` に渡す。
`value_and_grad` は $V$ と $(\partial V/\partial p, \partial V/\partial T)$ を逆走査 1 回で、`hessian` は $2 \times 2$ のヘッセ行列を方向ごとの forward-over-reverse で返す。
許容値は残差の単位（換算圧力）で $\mathrm{atol} = 10^{-12}$、$\mathrm{rtol} = 0$ とする。
渡す根の残差は丸めの大きさなので、この検査は根の取り違えや未収束の値を拒むためのものである。

入力は換算温度、換算圧力、根の選び方（実根が 1 個なら選び方によらずその根を使う）である。
出力は 3 つの感度と閉形式の相対差の表、モル体積・$\kappa_T$・$\alpha_p$ を理想気体と比べる表、実根の一覧である。
最後に、全根計算の `PolynomialRootReport` の終了状態を計算の判定（outcome）として示す。
`Complete` はすべての根が後退誤差の検査を通ったことを表し、根の前進誤差はおよそ条件数の推定と後退誤差の積になる。

```rust
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });

let (tc, pc) = (304.13, 7.3773); // [K]、[MPa]

            root * vc,
            -f_v,
            if k == index { "選んだ根" } else { "" },
        )
    })
    .collect();
let digits8 = serde_json::json!({ "significantDigits": 8 });
let columns = serde_json::json!([
    { "key": "0", "label": "実根", "type": "integer" },
    { "key": "1", "label": "V/V_c [-]", "type": "number", "format": digits8 },
    { "key": "2", "label": "V [L/mol]", "type": "number", "format": digits5 },
    { "key": "3", "label": "(∂p_r/∂V_r)_T [-]", "type": "number", "format": sci3 },
    { "key": "4", "label": "選択" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "volumes" })
);

// PolynomialRootReport の終了状態: Complete は成功、上限での停止は最後の候補を返す partial、他は failed。
let termination = report.termination();
let outcome = match termination {
    t if t.is_success() => {
        Outcome::satisfied("体積の 3 次式の全根を後退誤差の検査付きで求めた")
    }
    RootTermination::IterationLimit | RootTermination::WorkLimit(_) => {
        Outcome::partial("全根計算が上限で止まり、根は最後の候補である")
    }
    _ => Outcome::failed("体積の 3 次式の根が後退誤差の検査を通らなかった"),
};
let mut outcome = outcome.status(termination.to_string());
outcome = outcome.diagnostic("実根の数", volumes.len() as f64, None);
if let Some(error) = report.backward_error() {
    outcome = outcome.diagnostic("最大の後退誤差", error, None);
}
if let Some(condition) = report.max_root_condition().value() {
    outcome = outcome.diagnostic("最大の条件数の推定", condition, None);
}
emit_outcome!(outcome);
```

既定の $T = 0.90$、$p = 0.55$ では実根が 3 個（$0.6246$、$0.9248$、$3.1475$）あり、気相の根 $V_r = 3.1475$（$V \approx 0.4046$ L/mol）を使う。
3 つの感度は閉形式と相対差 $2 \times 10^{-15}$ 以下で一致し、$\partial^2 V/\partial p^2 = 23.614$ も入れ子の微分で正しく求まる。
全根計算は `Complete` で、最大の後退誤差は $4.5 \times 10^{-17}$、最大の条件数の推定は $17.5$ である。

圧縮因子は $Z = 0.721$ で、分子間の引力によって体積が理想気体より小さい。
等温圧縮率 $0.389$ MPa⁻¹ は理想気体の $1/p = 0.246$ MPa⁻¹ の 1.58 倍で、同じ引力のため気体が圧縮されやすい。
熱膨張率 $8.95 \times 10^{-3}$ K⁻¹ も理想気体の $1/T$ の 2.45 倍である。

液相の根に切り替えると $V \approx 0.0803$ L/mol、$\kappa_T = 0.0592$ MPa⁻¹ で、気相の約 7 分の 1 になる。
中間の根では $\partial V_r/\partial p_r = 1.378 > 0$、すなわち $\kappa_T = -0.202$ MPa⁻¹ と負になり、実根の表の $(\partial p_r/\partial V_r)_T = 0.725 > 0$ と合わせて力学的に不安定な状態であることが分かる。
陰関数定理は $F_V \ne 0$ であれば根の安定性を問わないので、不安定な根にも同じ精度で感度を付ける。

$T = 1.00$、$p = 1.01$ では実根は 1 個（$V_r = 0.8458$）で、$\kappa_T = 0.674$ MPa⁻¹ は理想気体の 5.0 倍、$\partial^2 V/\partial p^2 = 331.7$ と既定の値より 1 桁以上大きい。

臨界点そのもの $T = 1.00$、$p = 1.00$ を選ぶと、3 次式は 3 重根 $V = 1$ を持つ。
全根計算は 3 つの実根 $0.999995$、$0.9999996$、$1.0000015$ を返し、後退誤差の検査は通るので終了状態は `Complete` のままである。
しかし最大の条件数の推定は $2.0 \times 10^{13}$ で、根は $10^{-6}$ 程度しか正しくない。
渡した根では $F_V \approx 10^{-11}$ が 0 でないので `Singular` にはならず、感度は $\partial V/\partial p \approx -1.0 \times 10^{11}$ という有限だが意味のない値になる。
閉形式も同じ根で評価するので、両者の相対差 $9 \times 10^{-5}$ は $F_V$ を求める引き算の桁落ちを表すだけで、根の誤差は検出しない。
感度を使う前に、条件数の推定と $\lvert F_V \rvert$ の大きさを確かめる。

## 臨界点に近づくときの発散

次のセルは陰関数の解に $\ln V$ を続けて記録し、`grad` で $\partial \ln V/\partial p$ を逆走査 1 回で求める。
陰関数の解は普通の演算と合成でき、$\kappa_T = -(\partial \ln V_r/\partial p_r)/p_c$ を直接得られる。
臨界点からの距離 $\delta$ を $10^{-6}$ から $10^{-1}$ まで対数で等間隔に 21 点とり、各点で全根計算の根を渡す。

入力は近づき方で、臨界等温線（$T = 1$、$p = 1 \pm \delta$）と臨界等容線（$V = 1$、$T = 1 + \delta$、$p = 1 + 4\delta$）から選ぶ。
グラフは両対数で $\kappa_T$ と漸近形（破線）を描き、表は最小の 2 点の傾きを平均場の指数と比べる。
最後の表は臨界点 $(1, 1)$ に厳密な根 $V = 1$ を渡したときの `implicit_solution_into` のエラーの分類である。

```rust
//| id: ad-vdw-critical-divergence
//| ref: ad-vdw-critical-divergence
//| title: 臨界点に近づくときの等温圧縮率の発散
//| run: reactive
//| uses: [ad-vdw-model]
//| crates: [scioxide-ad, scioxide-core, scioxide-rootfind]
//| inputs:
//|   path: {"type":"select","label":"近づき方","options":["臨界等温線 T = 1","臨界等容線 V = 1"],"value":"臨界等温線 T = 1"}
//| cases:
//|   - {"id":"isochore","label":"臨界等容線 V = 1","description":"点が 1/(6δp_c) の破線に全域で重なり、傾きは −1 になる。","inputs":{"path":"臨界等容線 V = 1"}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"slopes","path":"/rows/0/1","approx":{"value":390.163,"rtol":1e-5}}
//|       - {"artifact":"slopes","path":"/rows/0/3","approx":{"value":-0.6709,"atol":5e-4}}
//|       - {"artifact":"slopes","path":"/rows/1/3","approx":{"value":-0.6623,"atol":5e-4}}
//|       - {"artifact":"critical","path":"/rows/0/0","equals":"Singular"}
//|       - {"artifact":"critical","path":"/rows/0/1","equals":0}
//|   - case: isochore
//|     expect:
//|       - {"artifact":"slopes","path":"/rows/0/3","approx":{"value":-1,"atol":1e-6}}
//|       - {"artifact":"slopes","path":"/rows/0/1","approx":{"value":22591.82447,"rtol":1e-6}}
//|       - {"artifact":"slopes","path":"/rows/0/2","approx":{"value":22591.82447,"rtol":1e-6}}
use scioxide_ad::{Real, grad, implicit_solution_into};
use scioxide_core::{SciOxideErrorKind, SciOxideErrorView, RealScalar, ResidualTolerance};

let pc = 7.3773; // CO2 の臨界圧力 [MPa]
let tolerance = ResidualTolerance::new(1e-12, 0.0).map_err(|e| e.to_string())?;
let isotherm = path == "臨界等温線 T = 1";
// κ_T = −(∂ln V_r/∂p_r)/p_c。ln V を陰関数の解に続けて記録し、逆モード 1 回で微分する。
let compressibility = |p: f64, t: f64, v: f64| -> Result<f64, String> {
    let g = grad(
        |x| {
            let mut y = [x[0]];
            implicit_solution_into(&VanDerWaals, &[v], x, tolerance, &mut y)?;
            Ok(y[0].ln())
        },
        &[p, t],
    )
    .map_err(|e| e.to_string())?;
    Ok(-g.as_slice()[0] / pc)
};
let deltas: Vec<f64> = (0..=20)
    .map(|i| RealScalar::powf(10.0, -6.0 + 0.25 * f64::from(i)))
    .collect();
let sides: &[f64] = if isotherm { &[1.0, -1.0] } else { &[1.0] };
let mut series = Vec::new();
let mut slopes = Vec::new();
for &side in sides {
    let mut points = Vec::new();
    for &delta in &deltas {
        let (p, t) = if isotherm {
            (1.0 + side * delta, 1.0)
        } else {
            (1.0 + 4.0 * delta, 1.0 + delta)
        };
        // T ≥ 1 では実根は 1 個。全根計算が検査を通らなければ止める。
        let (volumes, report) = volume_roots(p, t).map_err(|e| e.to_string())?;
        if !report.is_success() || volumes.len() != 1 {
            return Err(format!(
                "δ = {delta:e} で体積の根が定まらない: {}",
                report.termination()
            ));
        }
        points.push([delta, compressibility(p, t, volumes[0])?]);
    }
    // 最小の δ での値を漸近形と比べ、小さい方の 2 点で両対数の傾きを測る。
    let [d0, k0] = points[0];
    let [d1, k1] = points[1];
    let slope = RealScalar::ln(k1 / k0) / RealScalar::ln(d1 / d0);
    let label = match (isotherm, side > 0.0) {
        (false, _) => "T > 1",
        (true, true) => "p > 1",
        (true, false) => "p < 1",
    };
    let (asymptote, exponent) = if isotherm {
        (
            2.0 / 9.0 * RealScalar::powf(1.5 / d0, 2.0 / 3.0) / pc,
            -2.0 / 3.0,
        )
    } else {
        (1.0 / (6.0 * d0 * pc), -1.0)
    };
    slopes.push((label, k0, asymptote, slope, exponent));
    series.push(serde_json::json!({
        "name": format!("AD（{label}）"),
        "points": points,
        "style": { "symbol": "circle", "showSymbol": true }
    }));
}
// 独立な検算: 漸近形。等温線は (2/9)(3/(2δ))^(2/3)/p_c（V ≈ 1）、等容線は 1/(6δp_c)（V = 1 でちょうど）。
let asymptote: Vec<[f64; 2]> = deltas
    .iter()
    .map(|&d| {
        let value = if isotherm {
            2.0 / 9.0 * RealScalar::powf(1.5 / d, 2.0 / 3.0)
        } else {
            1.0 / (6.0 * d)
        };
        [d, value / pc]
    })
    .collect();
series.push(serde_json::json!({
    "name": "漸近形",
    "points": asymptote,
    "style": { "lineType": "dashed", "showSymbol": false }
}));
emit_line_chart!(
    &series,
    options = &serde_json::json!({
        "xLabel": "臨界点からの換算距離 δ [-]",
        "yLabel": "等温圧縮率 κ_T [1/MPa]",
        "xType": "log",
        "yType": "log",
        "xMin": 1e-6,
        "xMax": 0.1,
        "yMin": 0.01,
        "yMax": 1e5
    })
);
let fixed4 = serde_json::json!({ "fractionDigits": 4 });
let digits5 = serde_json::json!({ "significantDigits": 5 });
let columns = serde_json::json!([
    { "key": "0", "label": "枝" },
    { "key": "1", "label": "δ = 10⁻⁶ での κ_T [1/MPa]", "type": "number", "format": digits5 },
    { "key": "2", "label": "漸近形 [1/MPa]", "type": "number", "format": digits5 },
    { "key": "3", "label": "最小の 2 点の傾き d ln κ_T / d ln δ [-]", "type": "number", "format": fixed4 },

]);

let critical = grad(
    |x| {
        let mut y = [x[0]];
        implicit_solution_into(&VanDerWaals, &[1.0], x, tolerance, &mut y)?;
        Ok(y[0])
    },
    &[1.0, 1.0],

let columns = serde_json::json!([
```

臨界等温線では、$\delta = 10^{-6}$ で $\kappa_T$ が $p > 1$ で 390.2 MPa⁻¹、$p < 1$ で 399.4 MPa⁻¹ になり、点は傾き $-2/3$ の破線に沿う。
漸近形 394.7 MPa⁻¹ との差は約 1.2% で、$v \approx \mp 0.0087$ の 1 次の補正の大きさである。
最小の 2 点の傾きは $p > 1$ で $-0.6709$、$p < 1$ で $-0.6623$ で、$-2/3$ からのずれは展開の次の項（$p - 1 = -\tfrac{3}{2}v^3(1 - \tfrac{7}{2}v + \cdots)$）と $\kappa_T$ の因子 $1/V$ による $v$ の 1 次の補正である。
$\delta$ が大きくなると $V$ が 1 から離れ、点は漸近形からさらにずれる。

臨界等容線に切り替えると $V = 1$ がちょうど根になり、点は $1/(6\delta p_c)$ の破線に全域で重なり、傾きは $-1.0000$、$\delta = 10^{-6}$ での値は約 $2.26 \times 10^{4}$ MPa⁻¹ になる。
同じ臨界点でも近づき方で発散の速さが違うので、臨界点付近の感度を比べるときは経路をそろえる。

臨界点に厳密な根 $V = 1$ を渡すと、$F_V = 24/4 - 6 = 0$ がちょうど 0 になり、`implicit_solution_into` は `Singular`（ピボット 0）を返す。
前のセルで見たとおり、根に丸めが入ると同じ点でもエラーにはならないので、`Singular` が返らないことは臨界点から離れていることを意味しない。

## 解の精度と感度の精度

陰関数定理の感度は渡した根 $V$ での $F_V$ と $F_\theta$ から決まる。
根の誤差 $\Delta V$ は $F_V$ を $F_{VV}\,\Delta V$ だけ変えるので、感度の相対誤差はおよそ $\lvert F_{VV}\,\Delta V / F_V \rvert$ である。
臨界点の近くでは $F_V$ が小さく、根の条件数も大きいので、両方の効果で感度の精度が落ちる。

検査を通る根の残差を $\rho$ とすると、根の誤差は $\Delta V \approx \rho/\lvert F_V \rvert$ で、感度の相対誤差は上の式から $\lvert F_{VV} \rvert \rho / F_V^2$ 程度になる。
許容値を緩めるとこの誤差の上限が大きくなるので、許容値は根を求めた方法の精度に合わせて選ぶ。

$T < 1$ で $p$ をスピノーダルの圧力に近づけると、2 つの根が重なって $F_V \to 0$ になり、その枝の感度も発散する。
スピノーダルの圧力を越えると 2 根は共役な複素根になって実根の数が 3 から 1 に変わり、選び方の入力にかかわらず残った根が使われる。

## まとめ

根を求める反復を微分しなくても、残差 $F$ を `Residual` として一度だけ書けば、`implicit_solution_into` は渡した根に陰関数定理の微分を付け、`value_and_grad` で 1 階、`hessian` で 2 階の感度を返す。
感度は閉形式 $-1/F_V$、$8/((3V - 1)F_V)$、$-F_{VV}/F_V^3$ と丸めの範囲で一致し、$\kappa_T$ や $\alpha_p$ は換算値と臨界値から求まる。
陰関数の解は $\ln V$ のような後続の演算と合成でき、臨界点への発散の指数は近づき方で $-2/3$ と $-1$ に分かれる。
`implicit_solution_into` は根の残差を許容値で検査するが、根の前進誤差や $F_V$ の小ささは検査しないので、全根計算の条件数の推定と $\lvert F_V \rvert$ を確かめてから感度を使う。
`Singular` は $F_y$ のピボットがちょうど 0 のときだけ返り、臨界点に近いことの検出には使えない。
