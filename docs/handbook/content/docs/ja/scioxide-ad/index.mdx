`scioxide-ad` は、`f32` と `f64` で書いた計算の導関数を、各演算の局所的な導関数に連鎖律を適用して求めるクレートである。
この方法を自動微分（automatic differentiation）と呼ぶ。
導関数の式を組み立てる記号微分と違い、評価点での導関数の値を計算する。
差分のように刻み幅を選ぶ必要がなく、差分の打ち切り誤差を持たない。
ただし primal 値（primal、関数そのものの値）と同じく、各演算の丸め誤差は持つ。

`scioxide-ad` では、関数を数値型 `R: Real` について一度だけ書き、実行するときに数値型を選ぶ。
`f64` を渡せば普通の評価、`Dual` を渡せば前進モード（forward mode）の 1 方向の導関数、`Jet` を渡せば Taylor 係数、`Tape` に記録する `Var` を渡せば逆モード（reverse mode）の勾配になる。
`Lanes` を渡すと、独立な値をまとめて SIMD で評価する。
ラッパー型は入れ子にでき、`Dual<Dual<f64>>` は 2 階微分、`Var<Dual<f64>>` はヘッセ行列・ベクトル積を与える。
多数の独立な項目（Monte Carlo の経路や標本ごとの損失）の和は `BatchPlan` が lane に詰めて評価する。

関数を `Real` の演算で書けない場合（外部のプログラムや計測値）は、差分による数値微分（[scioxide-differentiate](../scioxide-differentiate/)）を使う。
二つの方法の使い分けと差分の誤差は[数値微分の選び方](../scioxide-differentiate/choosing/)で扱う。

## 最初の計算

関数とその導関数

$$
f(x) = \frac{e^x}{1 + x^2}, \qquad f'(x) = \frac{e^x (x - 1)^2}{(1 + x^2)^2}, \qquad
f''(x) = \frac{e^x (x - 1)\bigl(x^3 - 3x^2 + 5x + 1\bigr)}{(1 + x^2)^3}
$$

を、評価点 $x$ で四つの方法で求める。
`Dual::variable(x)` を渡す前進モード、`value_and_grad` によるテープの逆モード、`Jet::<_, 3>::variable(x)` による Taylor 係数（$f' = c_1$、$f'' = 2c_2$）、scioxide-differentiate の `FiniteDifference::derivative` による中心差分である。
最初の三つは同じ汎用関数 `model` を数値型を変えて実行し、中心差分は `model` を `f64` か `f32` のまま評価する。

入力は評価点 $x$（0.5 から 3.5 の無次元の数）と、計算に使う浮動小数点の型（`f64` か `f32`）である。
表は各方法の $f'(x)$ の値、閉形式との絶対誤差、その誤差を型の単位丸め $u$（`f64` で $2^{-53}$、`f32` で $2^{-24}$）で割った値と、計算に要した評価または走査の回数を示す。
最後の行は `Jet` の $2c_2$ と閉形式の $f''(x)$ の比較である。
閉形式は f64 の固有メソッドで計算した独立の参照値で、`f32` を選んだときは f32 に丸めた評価点で計算する。

```rust
//| id: ad-diff-vs-ad-comparison
//| ref: ad-diff-vs-ad-comparison
//| title: 二重数・テープ・ジェット・中心差分による導関数の比較
//| run: reactive
//| crates: [scioxide-ad, scioxide-core, scioxide-differentiate]
//| inputs:
//|   eval_x: {"type":"range","label":"評価点 x","description":"導関数を比べる位置（無次元）。x = 1 では f′(1) = 0。","min":0.5,"max":3.5,"step":0.1,"value":1.5}
//|   precision: {"type":"select","label":"浮動小数点の型","description":"四つの方法の計算に使う型。","options":["f64","f32"],"value":"f64"}
//| cases:
//|   - {"id":"single-precision","label":"f32","description":"単位丸めが 2^−24 に大きくなる。自動微分の誤差は u の数倍のままで、中心差分の誤差は 10^−6 程度に広がる。","inputs":{"precision":"f32"}}
//|   - {"id":"stationary-point","label":"x = 1","description":"f′(1) = f″(1) = 0 の点。自動微分の三つの方法は 0 を返す。","inputs":{"eval_x":1.0}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"derivatives","path":"/rows/0/1","approx":{"value":0.10607548095474706,"rtol":1e-14}}
//|       - {"artifact":"derivatives","path":"/rows/0/3","range":{"max":8}}
//|       - {"artifact":"derivatives","path":"/rows/1/3","range":{"max":8}}
//|       - {"artifact":"derivatives","path":"/rows/2/3","range":{"max":8}}
//|       - {"artifact":"derivatives","path":"/rows/3/2","range":{"min":1e-12,"max":1e-9}}
//|       - {"artifact":"derivatives","path":"/rows/4/1","approx":{"value":0.33454574762651,"rtol":1e-13}}
//|       - {"artifact":"derivatives","path":"/rows/4/3","range":{"max":32}}
//|   - case: single-precision
//|     expect:
//|       - {"artifact":"derivatives","path":"/rows/0/3","range":{"max":8}}
//|       - {"artifact":"derivatives","path":"/rows/3/2","range":{"min":1e-7,"max":1e-4}}
//|   - case: stationary-point
//|     expect:
//|       - {"artifact":"derivatives","path":"/rows/0/2","range":{"max":1e-15}}
//|       - {"artifact":"derivatives","path":"/rows/1/2","range":{"max":1e-15}}
//|       - {"artifact":"derivatives","path":"/rows/4/2","range":{"max":1e-15}}
use scioxide_ad::{Dual, Jet, Real, value_and_grad};
use scioxide_core::RealScalar;
use scioxide_differentiate::FiniteDifference;

// f(x) = eˣ/(1 + x²) を数値型 R について一度だけ書く。
fn model<S: RealScalar, R: Real<S>>(x: R) -> R {
    x.exp() / (x * x + S::ONE)
}

// 型 S で四つの方法を実行し、(f′ の 4 つの値, 2c₂, 差分の評価回数) を返す。
fn derivatives<S: RealScalar>(x: S) -> Result<([f64; 4], f64, usize), String> {
    // 前進モード: 接ベクトル 1 の二重数を渡す。
    let forward = model::<S, Dual<S>>(Dual::variable(x)).derivative();
    // 逆モード: 新しいテープに記録し、1 回の逆走査で勾配を得る。
    let (_, gradient) =
        value_and_grad(|v| Ok(model::<S, _>(v[0])), &[x]).map_err(|e| e.to_string())?;
    // Taylor 係数: c₁ = f′、2c₂ = f″。
    let c = model::<S, Jet<S, 3>>(Jet::variable(x)).coefficients();
    // 中心差分: 型の精度から決まる刻み幅で model を f64 か f32 のまま評価する。
    let difference = FiniteDifference::default()
        .derivative(|t| Ok(model::<S, S>(t)), x)
        .map_err(|e| e.to_string())?;
    let central = difference
        .values()
        .ok_or("中心差分の値が出力に反映されていない")?[0];
    let values = [
        forward.into_f64(),
        gradient.as_slice()[0].into_f64(),
        c[1].into_f64(),
        central.into_f64(),
    ];
    let curvature = (c[2] + c[2]).into_f64();
    Ok((values, curvature, difference.report().evaluations()))
}

let (x, (values, curvature, evaluations), unit) = if precision == "f32" {
    let x = eval_x as f32;
    (f64::from(x), derivatives(x)?, f64::from(f32::EPSILON) / 2.0)
} else {
    (eval_x, derivatives(eval_x)?, f64::EPSILON / 2.0)
};
// 独立の参照値: 閉形式 f′(x) と f″(x) を f64 の固有メソッドで計算する。
let q = 1.0 + x * x;
let first = x.exp() * (x - 1.0).powi(2) / (q * q);
let second = x.exp() * (x - 1.0) * (x.powi(3) - 3.0 * x * x + 5.0 * x + 1.0) / q.powi(3);
let names = [
    "前進モード Dual",
    "逆モード value_and_grad",
    "Taylor 係数 Jet の c₁",
    "中心差分 FiniteDifference::derivative",
];
let work = [
    "評価 1 回（primal 値と同時）".to_string(),
    "関数の実行 2 回（数えて広げ、記録する）、逆走査 1 回".to_string(),
    "評価 1 回（係数 3 個）".to_string(),
    format!("f の評価 {evaluations} 回"),
];
let mut rows: Vec<(String, f64, f64, f64, String)> = names
    .iter()
    .zip(values)
    .zip(work)
    .map(|((name, value), work)| {
        let error = (value - first).abs();
        (name.to_string(), value, error, error / unit, work)
    })
    .collect();
let error = (curvature - second).abs();
rows.push((
    "Taylor 係数 Jet の 2c₂（f″）".to_string(),
    curvature,
    error,
    error / unit,
    "上と同じ評価".to_string(),
));
let value = serde_json::json!({ "significantDigits": 15 });
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let fixed2 = serde_json::json!({ "fractionDigits": 2 });
let columns = serde_json::json!([
    { "key": "0", "label": "方法" },
    { "key": "1", "label": "導関数の値 [-]", "type": "number", "format": value },
    { "key": "2", "label": "閉形式との差 [-]", "type": "number", "format": sci3 },
    { "key": "3", "label": "差 / u [-]", "type": "number", "format": fixed2 },
    { "key": "4", "label": "要した計算" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "derivatives" })
);
```

## 結果の読み方

既定の $x = 1.5$、`f64` では、前進モード・逆モード・ジェットの $c_1$ は同じ値を返し、閉形式との差は $2.8 \times 10^{-17}$（$0.25u$）である。
ジェットの $2c_2$ も $f''$ と $0.5u$ の差で一致する。
中心差分の誤差は $1.3 \times 10^{-11}$ で、$u$ の約 11 万倍である。
自動微分の誤差は各演算の局所的な導関数（$e^x$ や $1/(1 + x^2)$ の微分）を浮動小数点で評価したときの丸めから来る。
中心差分の誤差は刻み幅 $h$ に比例する打ち切り誤差と $u/h$ に比例する丸め誤差の和で、二つを釣り合わせた刻み幅でも約 $u^{2/3}$ の大きさが残る。
`f32` を選ぶと $u$ が $2^{-24}$ に大きくなり、自動微分の誤差は $u$ の 1〜2 倍のまま、中心差分の誤差は約 $7 \times 10^{-6}$ になる。

$x = 1$ では $f'(1) = 0$ かつ $f''(1) = 0$ である。
自動微分の三つの方法はちょうど 0 を返し、中心差分は $1.8 \times 10^{-11}$ を返す。
真の値が 0 では相対誤差が意味を持たないので、表は絶対誤差を示す。

要した計算の列は、1 つの導関数を得るための評価または走査の回数である。
前進モードは primal 値と導関数を 1 回の評価で同時に計算する。
逆モードは関数を一度テープに記録し、記録を逆順に 1 回たどる。
`value_and_grad` は空のテープから始めるので、関数を 1 回実行して文の数を数え、テープを広げてからもう 1 回実行して記録する。
同じテープを使い回せば、2 回目からは記録 1 回で済む。
入力が $n$ 個のとき、前進モードで勾配を得るには $n$ 回の評価が要るが、逆モードは入力の数によらず記録 1 回と逆走査 1 回で済む。
この違いが、[自動微分の選び方](choosing/)で前進モードと逆モードを選ぶときの中心になる。

## 汎用関数の書き方

上のセルの `model` は数値型 `R: Real<S>` について一度だけ書いた関数である。
`f64` でも `Dual<f64>` でも `Var` でも同じ演算列を実行し、値は数値型によらずビットで一致する。
汎用関数を書くときの約束は次のとおりである。

- スカラーの定数は演算子の右に置く（`x * 2.0`、`-x + 1.0`、`x * x + S::ONE`）。
  具体的な型（`Dual<f64>` など）では左に置いてもよい。
- 乱数や測定値のように微分しない base の値は、`R::passive(z)` で数値型に入れる。
- 値で `if` 分岐するには、境界を `R: Real<Mask = bool>` にする。
  lane を持つ型も受け付けるなら、`R::select(mask, a, b)` で lane ごとに選ぶ。
- 逆モードの関数（`value_and_grad`、`Tape::gradient_into` など）に渡すクロージャは、呼び出しの引数の位置にその場で書く。
  クロージャは記録ごとのライフタイムについて汎用でなければならず、`let` で束縛すると型推論が失敗する。

数値型の仕様と lane は[数値型・lane・汎用コード](algorithms/number-types-and-lanes/)で、前進モードと逆モードのアルゴリズムはそれぞれ[前進モードと二重数](algorithms/forward-mode/)と[逆モードとテープ](algorithms/reverse-mode-and-replay/)で説明する。

## エラーと出力

数値型の演算はエラーを返さない。
IEEE 754 に従って評価し、引数を検査せず、NaN と無限大はそのまま伝わる。
エラーを返すのは、点を受け取って結果を書く変換（`grad`、`Tape::gradient_into`、`BatchPlan::evaluate_into` など）と構造化演算（`solve_into` など）で、`Result<_, SciOxideError>` を返す。
主な種類は次のとおりである。

| 種類 | 起こる場面 |
|---|---|
| `DimensionMismatch` | 点・方向・出力の長さが合わない |
| `NonFinite` | `NonFinitePolicy::Error` のもとで、点か結果に NaN か無限大がある |
| `DomainError` | `KinkPolicy::Error` のもとで能動的な引数が折れ点に当たった、分解のピボットが正でない |
| `Singular` | 線形系の解や陰関数の微分で行列が特異 |
| `InvalidInput` | 2 つの記録を混ぜた、2 回目の記録が 1 回目より大きくなった（関数が決定論的でない）、陰関数の解が許容誤差を満たさない |
| `ResourceLimit`、`AllocationFailure` | テープや作業領域を広げられない |

関数が返したエラーは、種類を変えずにそのまま返る。
変換が失敗したとき、呼び出し側の出力の領域は書き換えられない。
エラーの分類は `e.kind()` と `e.view()` で読む。
方針の詳細は[折れ点と非有限値の扱い](algorithms/nonsmooth-and-nonfinite-policies/)、テープの容量と再利用のエラーは[テープのライフサイクルと再利用](algorithms/tape-lifecycle/)で扱う。

## まとめ

`scioxide-ad` では関数を `R: Real` について一度だけ書き、`Dual`・`Jet`・`Var`・`Lanes` などの数値型を選んで、前進モード、Taylor 係数、逆モード、SIMD の評価を切り替える。
自動微分の誤差は各演算の丸めから来るので単位丸めの数倍にとどまり、刻み幅の選択も要らない。
入力が少なければ前進モード、スカラー関数の勾配のように入力が多く出力が少なければ逆モードが計算コストが小さい。
変換は `Result` を返し、失敗したときは出力を書き換えないので、エラーを `kind()` で分類して処理できる。
次は[自動微分の選び方](choosing/)で、問題の形から数値型と変換を選ぶ手順を確かめる。
アルゴリズムの仕組みと誤差から入るなら[自動微分のアルゴリズム体系](algorithms/)へ進む。
