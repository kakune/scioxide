分配関数、尤度、ソフトマックスのように、正の量を対数で保持して和を取る計算は多い。
倍精度では $\exp(x)$ が $x > 709.78$ でオーバーフローし、$x < -745.13$ で 0 になる。
`scioxide-core` の対数和は指数を作る前に最大値で移動し、和の誤差を段階的に確かめてから結果を返す。
このページは 1 本のベクトルの対数和、ソフトマックス、重み付きの和を扱う。
配列の軸に沿って同じ計算をする関数は[軸に沿った正規化と対数和](../axis-reductions/)で扱う。

## 最大値シフトによる対数和

実数のベクトル $\mathbf{x} = (x_1, \dots, x_n)$ の対数和（log-sum-exp）を $y = \operatorname{LSE}(\mathbf{x}) = \ln \sum_{i} e^{x_i}$ と書く。
入力 $x_i$ は足し合わせる正の項 $e^{x_i}$ の対数であり、以下では単に「対数」と呼ぶ。
$c = \max_i x_i$ とおいて各項を $e^{x_i} = e^{c}\, e^{x_i - c}$ と分けると

$$
y = c + \ln S, \qquad S = \sum_{i=1}^{n} e^{x_i - c}
$$

と書き直せる。
$x_i - c \le 0$ なので指数はオーバーフローせず、最大の項が $e^0 = 1$ なので $1 \le S \le n$、すなわち $c \le y \le c + \ln n$ である。

最大の項が突出していると $S = 1 + \delta$（$\delta \ll 1$）となり、丸めた $S$ の対数を取ると $\delta$ の情報が失われる。
そこで最大の項を除いた和 $\delta = S - 1$ を保持し、$\ln S = \ln(1 + \delta)$ を `ln_1p` で評価する。

$y$ を $x_i$ で偏微分すると $p_i = e^{x_i - y}$（ソフトマックスの確率）になり、$\sum_i p_i = 1$ である。
したがって入力の摂動 $\Delta x_i$ に対して $|\Delta y| \le \max_i |\Delta x_i|$ が一次で成り立ち、絶対誤差の意味では対数和は良条件である。

`logsumexp(values)` は実数と複素数の対数を受け付ける。

- $-\infty$ の実数の対数はマスクとして扱い、厳密に 0 の項として寄与する。
  空の入力やすべてがマスクの入力には $-\infty$ を返す。
- NaN と $+\infty$ は `NonFinite` として拒否する。
  結果が有限の範囲に収まらなければ `NumericalInstability` になる。
- 複素数の対数では、$-\infty$ にできるのは実部だけで、虚部はマスクの項でも有限でなければならない。
  結果は主値の対数で、空の入力やすべてがマスクの入力には $(-\infty, +0)$ を返し、有効な項が厳密に打ち消し合う場合は `DomainError` になる。
- `logsumexp_value` は同じ和を `LogValue` で返し、空の和や厳密に打ち消し合った和を、無限大の対数ではなく 0 という独立した状態で表す。
- 2 つの値の対数和は `logaddexp(x, y)` で計算する。

### シフトした計算の誤差の見積り

標準モデル（各演算と `exp`、`ln_1p` の相対誤差が単位丸め $u$ 以内）を仮定し、$u$ の二次以上を無視する。
$d_i = x_i - c$ の計算の丸めは指数に $u|d_i|$ の誤差を入れるので、$e^{d_i}$ の相対誤差は $u(1 + |d_i|)$ 以内である。
$n - 1$ 個の正の項を順に足して $\delta$ を作るときの誤差は $(n-2)u\,\delta$ 以内で、$\ln(1 + \delta)$ は $\delta \ge 0$ で傾きが $1/S$ 以下である。
以上をまとめ、$t\,e^{-t} \le e^{-1}$（$t \ge 0$）を使うと、$\ln S$ の絶対誤差 $E$ は

$$
E \le u \Bigl[ \ln S + (n - 1)(1 - p_{\max}) + \sum_{i} p_i\, |x_i - c| \Bigr]
\le u \bigl[ \ln n + (1 + e^{-1})(n - 1) \bigr]
$$

となる。
ここで $p_{\max} = 1/S$ は最大の項の確率である。
最後に $c + \ln S$ の加算で 1 回丸めるので、$y \ne 0$ なら相対誤差は $|\hat{y} - y| / |y| \le u + E/|y|$ で抑えられる。

$E$ は入力の大きさによらず $O(nu)$ なので、$|y|$ が 1 程度以上なら結果は相対的に正確である。
一方、$c < 0$ で $c + \ln S$ が打ち消し合い $|y|$ が小さくなると、第 2 項 $E/|y|$ が大きくなる。
例えば $x_1 = x_2 = -\ln 2$（倍精度に丸めた値）では真の $y$ は約 $2.3 \times 10^{-17}$ だが、$c + \ln 2$ を倍精度で計算すると 0 になる。
この例では $y$ の相対条件数 $\sum_i p_i |x_i| / |y|$ が約 $3 \times 10^{16}$ あり、入力の相対誤差 $u$ だけで $y$ が自身と同程度に動く。

`scioxide-core` はこの事前の見積りに頼らず、次節のように計算した結果ごとに誤差の上界を確かめ、足りなければ精度を上げて計算し直す。
上の例でも `logsumexp` は約 $2.3 \times 10^{-17}$ を返す。

## 正の和の誤差と段階的な評価

正の和（実数の対数の `logsumexp` と `logaddexp`、および非負の重みの `weighted_logsumexp`）の結果は、結果自身の ULP で 16 ULP 以内である。
これは試験で確かめた精度の保証で、0 に近い結果や非正規化数の結果も対象に含む。

この仕様を満たすため、計算は次の順に精度を上げ、誤差の上界が仕様に収まると確かめられた段階で終える。

1. 倍精度の指数と補償和。
2. 倍精度 2 つの組（double-double）の指数。
3. 指数の成分の厳密な累積。

2 段目と 3 段目は項を厳密な累積器で足すので、加算の丸め誤差が入力長に比例して増えない。
最初の段は、$c + \ln S$ が強く打ち消し合って 0 に近くなる結果と非正規化数の結果を受理せず、後の段に回す。
どの段で終えても結果は仕様の内側にある。
実数の対数和の計算量は $O(n)$ で、どの段もヒープを確保しない。

## ソフトマックスと対数ソフトマックス

確率 $p_i = e^{x_i - y}$ をソフトマックス、その対数 $\ln p_i = (x_i - c) - \ln S$ を対数ソフトマックスと呼ぶ。
対数確率は確率を作らずに $(x_i - c) - \ln S$ として計算するので、$p_i$ が倍精度で 0 に丸められる項でも $\ln p_i$ は有限に表せる。

1 次元のスライスには次の 4 つの関数がある。

| 関数 | 結果 | メモリ領域 |
|---|---|---|
| `softmax(input)` | 確率の `Vec` | 結果の `Vec` を 1 回だけ確保する |
| `log_softmax(input)` | 対数確率の `Vec` | 同上 |
| `softmax_into(input, output, scratch)` | `output` に確率を書き込む | 確保しない。`scratch` は入力以上の長さ |
| `log_softmax_into(input, output, scratch)` | `output` に対数確率を書き込む | 同上 |

どの関数も計算量は $O(n)$ である。
出力先を指定する API は結果をまず `scratch` に作り、すべての項の計算が成功してから `output` に写すので、失敗したときは `output` を変えない。
`output` の長さが入力と違う場合と `scratch` が入力より短い場合は `DimensionMismatch` になる。
所有値を返す API は結果を確保できなければ `AllocationFailure` になる。

マスク（$-\infty$）の確率は厳密な $+0$、対数確率は $-\infty$ である。
空の入力やすべてがマスクの入力は、正規化する和が 0 なので `DomainError` になる。
NaN と $+\infty$ は `NonFinite` として拒否する。

次のセルは 2 つの対数 $c$ と $c + d$（必要なら 3 番目にマスク $-\infty$）の対数和、確率、対数確率を計算する。
入力は共通の移動 $c$、対数の差 $d$（どちらも無次元）、マスクを加えるかどうかである。
1 つ目の表は各量を解析値 $y = c + \ln(1 + e^{d})$、$p_0 = 1/(1 + e^{d})$、$\ln p_0 = -\ln(1 + e^{d})$、$\ln p_1 = -\ln(1 + e^{-d})$ などと比べ、誤差を $|\text{計算値} - \text{解析値}| / (\varepsilon |\text{解析値}|)$ で示す。
解析値は `f64` の固有メソッドで計算した参照値で、それ自身も数 $\varepsilon$ の丸め誤差を持つ。
2 つ目の表は指数をそのまま足して対数を取った値と、マスクの項の出力を示す。

```rust
//| id: core-stable-logsumexp-shift
//| ref: core-stable-logsumexp-shift
//| title: 共通の移動に対する対数和と確率
//| run: reactive
//| crates: [scioxide-core]
//| inputs:
//|   common_shift: {"type":"range","label":"共通の移動 c [-]","description":"c ≥ 710 では e^c がオーバーフローする。","min":-1000,"max":1000,"step":100,"value":800}
//|   logit_gap: {"type":"range","label":"対数の差 d [-]","description":"2 つ目の対数を c + d とする。","min":-8,"max":8,"step":0.5,"value":2}
//|   include_mask: {"type":"checkbox","label":"マスク -∞ を 3 番目に加える","description":"-∞ は厳密に 0 の項として扱われる。","value":false}
//| cases:
//|   - {"id":"no-shift","label":"c = 0","description":"指数をそのまま足しても有限で、対数和と一致する。","inputs":{"common_shift":0}}
//|   - {"id":"underflow","label":"c = −1000, d = 8","description":"指数がすべて 0 に丸められ、そのままの和の対数は −∞ になる。","inputs":{"common_shift":-1000,"logit_gap":8}}
//|   - {"id":"masked","label":"マスクあり","description":"マスクの確率は厳密な +0、対数確率は −∞ になり、他の値は変わらない。","inputs":{"include_mask":true}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"values","path":"/rows/0/1","approx":{"value":802.1269280110429,"rtol":1e-14}}
//|       - {"artifact":"values","path":"/rows/1/1","approx":{"value":0.11920292202211755,"rtol":1e-13}}

use scioxide_core::{RealScalar, log_softmax_into, logsumexp, softmax_into};

let mut logits = vec![common_shift, common_shift + logit_gap];

    logits.push(f64::NEG_INFINITY);

    { "key": "0", "label": "量" },
    { "key": "1", "label": "SciOxide [-]", "type": "number", "format": digits },
    { "key": "2", "label": "解析値 [-]", "type": "number", "format": digits },
    { "key": "3", "label": "相対誤差 / ε [-]", "type": "number", "format": fixed2 }
]);

    value_columns,
    rows,
    metadata = serde_json::json!({ "id": "values" })
);

// 比較用: 指数をそのまま足す（f64 の固有メソッド）。有限でなければ None。
let direct: f64 = logits.iter().map(|x| x.exp()).sum::<f64>().ln();

// マスクの確率は +0、対数確率は −∞。マスクがなければ None。
let mask_probability = include_mask.then(|| probabilities[2]);
let mask_log = match log_probabilities.get(2) {
    Some(&value) if value == f64::NEG_INFINITY => "はい",
    Some(_) => "いいえ",
    None => "マスクなし",
};
let direct_columns = serde_json::json!([
    {
        "key": "0",
        "label": "指数をそのまま足した ln Σ e^x [-]",
        "type": "number",
        "format": digits,
        "nullText": "有限でない"
    },
    { "key": "1", "label": "マスクの確率 p₂ [-]", "type": "number", "nullText": "マスクなし" },
    { "key": "2", "label": "マスクの対数確率が −∞ か" }
]);

    direct_columns,
    vec![(direct, mask_probability, mask_log)],
    metadata = serde_json::json!({ "id": "direct" })
);
```

既定値（$c = 800$、$d = 2$）では、指数をそのまま足した値は有限でなくなり、`logsumexp` は解析値 $802.1269\ldots$ と表示の桁まで一致する。
$c = 0$ ではそのままの和も有限で、対数和と同じ値 $2.1269\ldots$ になる。
$c = -1000$、$d = 8$ では指数がすべて 0 に丸められてそのままの和の対数は $-\infty$ になるが、対数和は $-991.9997$ で、$\ln p_0 \approx -8.0003$ は確率の対数を取らずに得られる。
マスクを加えても和と $p_0$、$p_1$ は変わらず、マスクの確率は厳密な $+0$、対数確率は $-\infty$ になる。

## 符号付き・複素重みの和と条件数

重み付きの和 $Z = \sum_i w_i e^{x_i}$ で重みが負や複素数の場合、項どうしが打ち消し合う。
打ち消しの強さは条件数

$$
\kappa = \frac{\sum_i |w_i| e^{x_i}}{\left| \sum_i w_i e^{x_i} \right|}
$$

で表され、重みがすべて非負なら $\kappa = 1$ である。
各項の相対誤差が $\theta_i$ のとき、和の相対誤差は $\sum_i |w_i| e^{x_i} \theta_i / |Z| \le \kappa \max_i \theta_i$ まで広がりうるので、$\ln |Z|$ の絶対誤差も $\kappa$ に比例する。

`weighted_logsumexp(values, weights)` は実数の対数と実数・複素数の重みを受け取り、結果を `LogValue`（符号または位相と $\ln |Z|$）で返す。
マスクの項と重み 0 の項は和に寄与しない。
空の入力、寄与する項のない入力、厳密に打ち消し合った和は 0 の状態になり、`log_magnitude()` は `None` を返す。
重みは、マスクされた項や重み 0 の項も含めて、すべて有限でなければならない。
有限でない重みと、NaN や $+\infty$ の対数は `NonFinite` になる。
対数と重みの長さが違えば `DimensionMismatch` になる。

非負の重みでは $\ln |Z|$ は 16 ULP 以内である。
符号付き・複素の重みの誤差は条件数に依存する。
寄与する項の対数を大きい順に見て、最大の対数から下へ幅 1200 の区間を取り、そこに入らない対数のうち最大のものから次の区間を取る。
これを繰り返してできる区間の数を $k$（$k \le n$）とすると、$32 k \varepsilon \kappa < 1/2$ の範囲で

$$
\bigl| \widehat{\ln |Z|} - \ln |Z| \bigr| \le 64\, k\, \varepsilon\, \kappa\, (1 + |\ln |Z||) + 8\eta
$$

が成り立つ（$\varepsilon$ は機械イプシロン、$\eta$ は最小の非正規化数）。
この範囲を超える条件数では前進誤差の上界はない。
複素数の対数の `logsumexp` も、項を $t_i = e^{x_i}$、区間を対数の実部で数えた同じ限界に従う。
計算量は多くの場合 $O(n)$ で、最大でも $O(nk)$（$k = n$ なら $O(n^2)$）である。
メモリ領域は固定長で、ヒープを確保しない。

次のセルは $w_1 = 1$、$w_2 = -(1 - \delta)$、$x_1 = x_2 = 100$ の和 $Z = \delta\, e^{100}$ を計算する。
入力は打ち消しの残り $\delta = 10^{q}$ の指数 $q$ である。
$1 - \delta$ は倍精度に丸められるが、$\delta_{\mathrm{eff}} = 1 + w_2$ は Sterbenz の補題により厳密に計算できるので、参照値を $100 + \ln \delta_{\mathrm{eff}}$ とする。
1 つ目の表は計算値と参照値の差を、2 つ目の表は条件数 $\kappa = (2 - \delta_{\mathrm{eff}})/\delta_{\mathrm{eff}}$ と、上式で $k = 1$ とした誤差限界を示す。

```rust
//|   - case: unresolved
//|     expect:
//|       - {"artifact":"sum","path":"/rows/0/3","equals":1}
//|       - {"artifact":"bound","path":"/rows/0/2","range":{"min":0.5}}
//|       - {"artifact":"bound","path":"/rows/0/4","equals":"いいえ"}
use scioxide_core::{RealScalar, weighted_logsumexp};

let delta = RealScalar::powi(10.0_f64, delta_exponent as i32);
let values = [100.0, 100.0];
let weights = [1.0, -(1.0 - delta)];
let sum = weighted_logsumexp(&values, &weights).map_err(|e| e.to_string())?;
let log_magnitude = sum.log_magnitude().ok_or("和が厳密に 0 になった")?;

// 1 + w₂ は Sterbenz の補題により厳密（w₂ ∈ [-1, -1/2]）。
let delta_eff = 1.0 + weights[1];
// 参照値（f64 の固有メソッド）。
let reference = 100.0 + delta_eff.ln();
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let digits = serde_json::json!({ "significantDigits": 14 });
let sum_columns = serde_json::json!([
    { "key": "0", "label": "ln |Z|（weighted_logsumexp）[-]", "type": "number", "format": digits },
    { "key": "1", "label": "参照値 100 + ln δ_eff [-]", "type": "number", "format": digits },
    { "key": "2", "label": "差の絶対値 [-]", "type": "number", "format": sci3 },
    { "key": "3", "label": "符号 [-]", "type": "integer" }
]);
emit_table_with_columns!(
    sum_columns,
    vec![(
        log_magnitude,
        reference,
        (log_magnitude - reference).abs(),
        sum.sign() as i32,
    )],
    metadata = serde_json::json!({ "id": "sum" })
);

// κ = Σ|wᵢ|e^{xᵢ} / |Σ wᵢ e^{xᵢ}| = (1 + |w₂|) / δ_eff。
let kappa = (1.0 + weights[1].abs()) / delta_eff;
// 上界が成り立つ条件 32 k ε κ < 1/2 と、k = 1 の誤差限界（8η は無視できる）。
let regime = 32.0 * f64::EPSILON * kappa;
let bound = 64.0 * f64::EPSILON * kappa * (1.0 + reference.abs());
let resolved = if regime < 0.5 { "はい" } else { "いいえ" };
let bound_columns = serde_json::json!([
    { "key": "0", "label": "δ_eff = 1 + w₂ [-]", "type": "number", "format": sci3 },
    { "key": "1", "label": "条件数 κ [-]", "type": "number", "format": sci3 },
    { "key": "2", "label": "32 ε κ [-]", "type": "number", "format": sci3 },
    { "key": "3", "label": "誤差限界 64 ε κ (1 + |ln|Z||) [-]", "type": "number", "format": sci3 },
    { "key": "4", "label": "上界が成り立つ範囲か（32 ε κ < 1/2）" }
]);
emit_table_with_columns!(
    bound_columns,
    vec![(delta_eff, kappa, regime, bound, resolved)],
    metadata = serde_json::json!({ "id": "bound" })
);
```

既定値（$\delta = 10^{-8}$）では $\kappa \approx 2 \times 10^{8}$ で、誤差限界は $2 \times 10^{-4}$ 程度まで広がる。
実際の差は限界よりはるかに小さいが、限界は打ち消しの強さに比例して広がる。
$\delta = 10^{-1}$ では $\kappa \approx 19$ で、誤差限界は $10^{-11}$ 程度に収まる。
$\delta = 10^{-15}$ では $\kappa$ が約 $2 \times 10^{15}$ となり、$32 \varepsilon \kappa$ が $1/2$ を超えるので上界が成り立たない範囲に入る。
この場合も符号は $+1$ で返るが、$\ln |Z|$ の誤差を上の式で見積もることはできない。

## まとめ

指数の和は `logsumexp`、2 つの値なら `logaddexp` で計算し、正の和の結果は 16 ULP 以内である。
最大値シフトの事前の見積りでは $|y|$ が小さいと相対誤差が大きくなりうるが、SciOxide は結果ごとに上界を確かめて精度を上げるので、この場合も 16 ULP の仕様が保たれる。
$-\infty$ はマスクとして厳密に 0 の項になるので、無効な項を除くために配列を作り直す必要はない。
符号付きや複素数の重みの和は `weighted_logsumexp` で `LogValue` として受け取り、誤差は条件数 $\kappa$ に比例して広がることを前提に結果を読む。
