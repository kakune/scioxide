この表は途中の値の範囲や丸めを管理する算術と縮約の項目をまとめる。
`checked_*` 関数は有限な入力だけを受け付ける。
非有限な入力は `NonFinite`、0 による除算は `DomainError`、表せない最終結果は `NumericalInstability`（`Overflow`）で返す。
「一回の丸め」は数学的な値を最近接偶数丸めした結果（誤差 0 ULP）を意味する。
記号は $u = \varepsilon/2$、$\gamma_k = ku/(1-ku)$ で、$\eta$ は最小の正の非正規化数である。
結果の `Vec` を返す所有値を返す API（`softmax`、`log_softmax`、`softmax_axis`、`log_softmax_axis`、`logsumexp_axis`、`weighted_logsumexp_axis`）を除き、これらの関数はヒープを確保しない。

## 安定変換と一括変換

`log1mexp` を除く実数版の精度の保証は 16 ULP である（`sincpi` は正しく丸めた値かその隣）。
複素数版の誤差は結果の成分ごとに $32\varepsilon\, m\, g + 8\eta$ 以下である。
ここで $m$ は厳密な値の実部と虚部の絶対値の大きい方で、$g$ は表の各行に示す係数である（示していない関数は $g = 1$）。
`log1mexp` 以外はすべて実数と複素数を受け付け、非有限な入力を `NonFinite` で拒否する。
引数は `f64` で評価し、結果を出力の型へ一回丸める。

## まとめ

`checked_*` 関数は有限な入力から一回の丸めの結果か、行に書いた誤差限界の内側の結果を返す。
和や積和を分けて足すときは `RangeAccumulator` か `ProductSum` に蓄積し、最後に `finish` で丸める。
打ち消しが起きる式は安定変換の関数で計算し、配列には `transform_into` を使う。
対数和と正規化は、1 本のベクトルなら `logsumexp` と `softmax` の系統、配列の軸ごとなら `_axis` の系統を選ぶ。
反復の内側では `_into` の形を選び、出力と作業領域を呼び出し側で用意する。
