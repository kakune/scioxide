この表は計算を始める前に呼び出し側が決める三つの値、すなわち変数の範囲、受理のしきい値、リソースの上限の型をまとめる。
しきい値は多くの型で、尺度 $s \ge 0$ に対して $\tau(s) = \tau_{\mathrm{abs}} + \tau_{\mathrm{rel}} s$ である。
`IntegralityTolerance` は絶対値だけ、`RelativeTolerance` は相対値だけを持つ。
上限は許容誤差とは別の型 `Budget`（正の整数）で表す。

## まとめ

範囲は、端点が有限なら `Interval`、無限の端点を含むなら `ExtendedInterval`、変数ごとの上下限なら `Bounds` で表す。
受理のしきい値は判定する量の役割に合う許容誤差の型で渡す。
反復や評価の上限は `Budget` で表し、定数なら `budget!`、実行時の値なら `Budget::try_from` で作る。
許容誤差の判定はしきい値を満たさないことを `Ok(false)` で返すので、`Err` は入力の誤りとして扱う。
