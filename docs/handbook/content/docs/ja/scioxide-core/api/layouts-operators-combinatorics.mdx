この表は配列の配置、作用素のプロトコルと適用のコンテキスト、疎構造・三角格納と彩色、整数の組合せの項目をまとめる。
配置とビューは形、ストライド、要素のスライスを借用し、要素を所有しない（`row_major` で作った配置だけは、ストライドを配置の中に持つ）。
作用素は必要な作業領域の長さを事前に返し、呼び出し側のメモリ領域に書く。

## まとめ

配列はパディングのない行優先なら `row_major`、それ以外は `StridedLayout::new` で配置を作り、`NdView` か `NdViewMut` で渡す。
作用素はトレイトを実装した型か `ClosureOperator` で渡し、作業領域は `apply_workspace_len` などが返す長さで用意する。
疎構造は `StructuralPatternView` で検査し、彩色は `ColoringSchedule::new` で検証してから使う。
組合せの関数は、結果が整数型に収まらないときに `SizeOverflow` を返し、折り返した値を返さない。
