この表は計算の対象となる値の型と、その境界を定めるトレイトをまとめる。
`RealScalar` と `NumericScalar` は外部からの実装を許可していないため、SciOxide が定める型だけが実装する。
`RealScalar` は `f32` と `f64`、`NumericScalar` はそれに `Complex<f32>` と `Complex<f64>` を加えた 4 つの型である。
拡張範囲値の表現と IEEE 型への射影規則は[拡張範囲値と対数・射影表現](../../algorithms/extended-range-values/)で説明する。
スカラー型の階層は[初等関数と安定変換](oxref:core-scalar-hierarchy)で説明する。

## スカラーの境界と複素数

|---|---|---|---|---|---|
| [`AlgebraicScalar`](https://docs.rs/scioxide-core/0.1.0/scioxide_core/trait.AlgebraicScalar.html) | トレイト | 体の演算（四則）と 0、1 を持つ値の境界 | `ZERO`、`ONE`、四則演算、符号反転、`is_zero` を要求する。他のクレートも実装できる（自動微分の双対数など）。IEEE 754 の分類や初等関数は要求しない | [スカラー型の階層と精度の区分](oxref:core-scalar-hierarchy) | - |

| [`FloatDecomposition`](https://docs.rs/scioxide-core/0.1.0/scioxide_core/enum.FloatDecomposition.html) | 列挙型 | IEEE 値の符号・整数の仮数・二進指数への厳密な分解 | `Finite { significand, exponent, negative }`、`Infinite { negative }`、`Nan`。`RealScalar::decompose` が返す。ゼロの符号と非正規化数を保つ。NaN の符号とペイロードは返しない | [スカラー型の階層と精度の区分](oxref:core-scalar-hierarchy) | - |
| [`Complex`](https://docs.rs/scioxide-core/0.1.0/scioxide_core/struct.Complex.html) | 構造体 | 実部 `re` と虚部 `im` の組 | 初等関数の各成分の誤差は、厳密な結果 $w$ に対して $16\varepsilon\max(\lvert \operatorname{Re} w \rvert, \lvert \operatorname{Im} w \rvert)\,g$ 以内（$g \ge 1$ は関数ごとの増大因子）。除算の誤差は、厳密な商 $q$ に対して $8\varepsilon \lvert q \rvert + 4\eta$ 以内（$\eta$ は最小の正の非正規化数）。算術は IEEE 754 に従い、NaN や無限大を検査しない。`try_new` は非有限な成分を `NonFinite` で拒否する | [複素数での誤差の増大因子](oxref:core-complex-growth-factors) | - |

## 拡張範囲値

| 項目 | 種別 | 役割 | 仕様の要点 | 解説節 | 実行例 |
|---|---|---|---|---|---|
| [`Scaled`](https://docs.rs/scioxide-core/0.1.0/scioxide_core/struct.Scaled.html) | 構造体 | $m \cdot 2^{e}$（$1 \le \lvert m \rvert < 2$、$e$ は `i64`）で表す実数 | 加減乗除、平方根、積の差は、厳密な結果を仮数の精度へ一回丸める。確保しない。指数が `i64` の範囲を出ると `ExponentOutOfRange`。IEEE 型へは、段階的アンダーフローを許す `round` か、非零の値が 0 に丸まる場合を `Underflow` で拒否する `try_value` で戻す。どちらも無限大に丸まる場合は `Overflow` | [二進正規化数 Scaled](oxref:core-scaled) | [n! を拡張範囲で計算して Stirling 級数と比べる](oxref:core-scaled-factorial)、[大きな項に埋もれた 1 を補償和で取り戻す](oxref:core-scaled-accumulator-vs-exact) |
| [`ScaledValue`](https://docs.rs/scioxide-core/0.1.0/scioxide_core/struct.ScaledValue.html) | 構造体 | 成分ごとに尺度を持つ実数・複素数 | 有限な IEEE 値をビットを保って変換する。加減算と積の差は成分ごとに一回丸める。複素数の商は、IEEE 型へ戻す前の各成分の相対誤差が $\gamma_3 = 3u/(1 - 3u)$ 以内（$u = \varepsilon/2$）。`try_projective` で共有指数の座標へ変換する | [成分ごとの尺度 ScaledValue と共有指数 ProjectiveValue](oxref:core-scaled-and-projective-values) | [成分の尺度差と共有指数への変換](oxref:core-projective-frame) |
| [`ScaledAccumulator`](https://docs.rs/scioxide-core/0.1.0/scioxide_core/struct.ScaledAccumulator.html) | 構造体 | `Scaled` の補償和（Neumaier） | 走行和と補正項を `i64` の指数付きで持つ。失敗した更新は和を変えない。積は丸めてから加える。正しく丸めた和も、符号の正しさも保証しない（必要なら `RangeAccumulator` を使う）。`absorbs(exponent)` が `true` なら、指数がそれ以下の値を加えても和と補正項は変わらない。`false` は、値を加えると和が変わることを意味しない | [補償付きの和 ScaledAccumulator](oxref:core-scaled-accumulator) | [大きな項に埋もれた 1 を補償和で取り戻す](oxref:core-scaled-accumulator-vs-exact)、[単精度の調和級数を四通りに足す](oxref:core-harmonic-series-summation) |
| [`ProjectiveValue`](https://docs.rs/scioxide-core/0.1.0/scioxide_core/struct.ProjectiveValue.html) | 構造体 | 全成分が一つの二進指数を共有する座標 | 非零の最大成分の大きさは $[1, 2)$ にあり、符号付きゼロの成分を保つ。`ScaledValue::try_projective` で作る。非零の成分が 0 になる場合は `Underflow`、仮数のビットが落ちる場合は `LossOfSignificance` で失敗する。算術は定義しない | [成分ごとの尺度 ScaledValue と共有指数 ProjectiveValue](oxref:core-scaled-and-projective-values) | - |
| [`LogValue`](https://docs.rs/scioxide-core/0.1.0/scioxide_core/struct.LogValue.html) | 構造体 | 大きさ 1 の位相 $p$ と有限な自然対数 $\ell$ で $p\,e^{\ell}$ を表す値 | 0 は対数を持たない別の状態（`ZERO`）で表す。`from_log` は、実数の位相が $\pm 1$ でない場合と、複素数の位相が $\lvert \lvert p \rvert - 1 \rvert > 16\varepsilon$ となる場合を `InvalidInput` で拒否する。`from_value` は対数を丸める。`round` は段階的アンダーフローを許し、`try_value` は非零の成分が 0 に丸まる場合を `Underflow` で拒否する。確保しない | [対数表現 LogValue](oxref:core-log-value) | [軸に沿った対数和と重み付き対数和](oxref:core-axis-logsumexp) |
| [`ValueAndDerivative`](https://docs.rs/scioxide-core/0.1.0/scioxide_core/struct.ValueAndDerivative.html) | 構造体 | 一回の評価で得た値と導関数の組 | `new`、`value()`、`derivative()`、`into_parts()`。値の検証は行わない | [値と導関数の組 ValueAndDerivative](oxref:core-value-and-derivative) | - |

## まとめ

実数の計算は `RealScalar`、複素数も受け付ける計算は `NumericScalar` を境界にする。
途中の値が指数の範囲を出るなら `Scaled` か `ScaledValue`、対数で持つなら `LogValue` を選ぶ。
IEEE 型へ戻すときは `try_value` などの射影を使い、範囲外や桁の損失をエラーで受け取る。
アフィン値は `AffineValue` で成分を借用し、線形結合は `affine_combination_into` で一回の丸めにする。
