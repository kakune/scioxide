この表は反復解法のライフタイムと回数の集計、および実行の方針と基盤の機能の型をまとめる。
求解の状態は所有型 `SolveState` に置き、一回の求解の間だけ借用する `SolveContext` を通してリソースの許可と計数を行う。
実行の意図 `ExecutionPolicy` と、エグゼキューターやクロックを持つ `ExecutionContext` は別々に渡す。
コンテキストの引数を持たない関数は `ExecutionContext::sequential_native()` で動く。
名前が `_scoped` で終わる関数は、呼び出し側のスコープかコンテキストを最後の引数に取り、その取り消し・期限・上限のもとで動く。

## まとめ

反復解法は状態を `SolveState` に持ち、`SolveContext` でリソースの許可を受けてから評価や反復を数える。
入れ子の求解は `SolveScope` を `_scoped` 関数に渡し、共有の上限に数える。
並列化の意図は `ExecutionPolicy`、エグゼキューター・取り消し・クロックは `ExecutionContext` で渡す。
wasm32 のようにエグゼキューターやクロックがない環境では、逐次のコンテキストを使い、時間上限はクロックを自分で注入したときだけ設定できる。
