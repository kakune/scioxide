難溶性塩を溶かす水に、その塩と同じイオンを含む塩をあらかじめ溶かしておくと、溶解平衡が沈殿の側に移り、溶解度が下がる。
これを共通イオン効果と呼ぶ。
溶解度は二次方程式の正の根で、共通イオンが多いほど小さくなる。
解の公式をそのまま使うと、この小さな根で大きさの近い数の引き算が起き、有効数字が失われる。
この例題では `checked_quadratic_roots` で根を求め、その残差の仕様を `Tolerance` で判定する。

## 溶解平衡と二次方程式

1:1 型の難溶性塩 MX の溶解平衡

$$
\mathrm{MX(s)} \rightleftharpoons \mathrm{M^+(aq)} + \mathrm{X^-(aq)}
$$

では、飽和溶液のイオン濃度の積が溶解度積 $K_{\mathrm{sp}} = [\mathrm{M^+}][\mathrm{X^-}]$ に等しい。
共通イオン $\mathrm{X^-}$ を濃度 $c$ [mol/L] 含む溶液に MX を飽和させ、溶解度を $s$ [mol/L] とすると、$[\mathrm{M^+}] = s$、$[\mathrm{X^-}] = s + c$ なので

$$
s(s + c) = K_{\mathrm{sp}} \quad \Longleftrightarrow \quad s^2 + c\,s - K_{\mathrm{sp}} = 0
$$

となる。
活量係数を 1 とし、錯イオン（例えば $\mathrm{AgI_2^-}$）の生成やイオン対は無視する。
実際の溶液でこれらを無視できない濃度では、副反応の平衡を連立させる必要がある。

| 塩 | $K_{\mathrm{sp}}$（25 °C）[mol²/L²] | 純水中の溶解度 $\sqrt{K_{\mathrm{sp}}}$ [mol/L] |
|---|---|---|
| AgCl | $1.77 \times 10^{-10}$ | $1.33 \times 10^{-5}$ |
| AgBr | $5.35 \times 10^{-13}$ | $7.31 \times 10^{-7}$ |
| AgI | $8.52 \times 10^{-17}$ | $9.23 \times 10^{-9}$ |
| BaSO₄ | $1.08 \times 10^{-10}$ | $1.04 \times 10^{-5}$ |

表の $K_{\mathrm{sp}}$ は 25 °C の代表値で、文献によって値は少し異なる。

## 解の公式での打ち消し

正の根を解の公式で書くと

$$
s = \frac{-c + \sqrt{c^2 + 4K_{\mathrm{sp}}}}{2}
$$

である。
$c = 1$ mol/L の溶液に AgI を溶かすと $c^2 + 4K_{\mathrm{sp}} = 1 + 3.408 \times 10^{-16}$ で、1 との差は 1 の近くの倍精度数の間隔 $\varepsilon \approx 2.22 \times 10^{-16}$ と同じ程度しかない。
これは $1 + 2\varepsilon$ に丸められ、平方根は $1 + \varepsilon$、結果は $\varepsilon / 2 \approx 1.11 \times 10^{-16}$ になる。
正しい溶解度は約 $K_{\mathrm{sp}} / c = 8.52 \times 10^{-17}$ mol/L（1 L あたり約 $5 \times 10^{7}$ 個の銀イオン）なので、約 30 % の誤差である。
$4K_{\mathrm{sp}}$ が $c^2$ の近くの間隔の半分より小さくなると、$c^2 + 4K_{\mathrm{sp}}$ は $c^2$ に丸められ、結果は 0 になる。

分子を有理化した

$$
s = \frac{2K_{\mathrm{sp}}}{c + \sqrt{c^2 + 4K_{\mathrm{sp}}}}
$$

は正の数の足し算だけで打ち消しがなく、この例題では独立な参照値として使う。
加算、平方根、除算の丸めは合わせて数回なので、参照値の相対誤差は $\varepsilon$ の数倍以内である。
$4K_{\mathrm{sp}} \ll c^2$ では $s = K_{\mathrm{sp}}/c - K_{\mathrm{sp}}^2/c^3 + 2K_{\mathrm{sp}}^3/c^5 - \cdots$ と展開でき、$s \approx K_{\mathrm{sp}}/c$ である。

次のブロックは二つのセルが共有する定義である。
`solubility_product` は上の表の $K_{\mathrm{sp}}$ を返し、`formula_root` は解の公式、`rationalized_root` は有理化した式に対応する。
後の二つは比較と検算のための式で、`f64` の演算と標準関数で計算する。

```rust
//| id: core-common-ion-model
//| kind: definitions
//| title: 溶解度積と比較用の二つの式
//| crates: [scioxide-core]
/// 25 °C の溶解度積 K_sp [mol²/L²]。
pub(crate) fn solubility_product(salt: &str) -> f64 {
    match salt {
        "AgCl" => 1.77e-10,
        "AgBr" => 5.35e-13,
        "BaSO4" => 1.08e-10,
        _ => 8.52e-17,
    }
}

/// 解の公式 s = (−c + √(c² + 4K))/2。比較用（f64 の固有メソッド）。
pub(crate) fn formula_root(c: f64, k_sp: f64) -> f64 {
    (-c + (c * c + 4.0 * k_sp).sqrt()) / 2.0
}

/// 有理化した式 s = 2K/(c + √(c² + 4K))。独立な参照値（f64 の固有メソッド）。
pub(crate) fn rationalized_root(c: f64, k_sp: f64) -> f64 {
    2.0 * k_sp / (c + (c * c + 4.0 * k_sp).sqrt())
}
```

## 根の残差の仕様

`checked_quadratic_roots(a, b, c)` は、二つの実根のうち絶対値の大きい方を打ち消しの起きない式 $q/a$ で求め、もう一方を $c/q$ から得る（詳細は[厳密累積と範囲安全な算術](oxref:core-quadratic-roots)）。
戻り値は配列 `[Complex<S>; 2]` で、実根は小さい順に並ぶ。
この問題では二根の積が $-K_{\mathrm{sp}} < 0$ なので、1 番目が負の根、2 番目が正の溶解度である。

重根に近い問題では根の条件数

$$
\kappa(x) = \frac{|a| x^2 + |b|\,|x| + |c|}{|x|\,|2ax + b|}
$$

が非常に大きくなるので、前進誤差は ULP で保証されず、代わりに残差が保証される。
根 $x$（実数）について $T = |a| x^2 + |b| |x| + |c|$ とすると、

$$
|a x^2 + b x + c| \le 32\,\varepsilon\, T + (2|a||x| + |b|)\,\eta + |a|\,\eta^2
$$

である。
$\eta \approx 4.9 \times 10^{-324}$ は最小の正の非正規化数である。
この例題の大きさでは $\eta$ の項は無視できるので、`Tolerance::new(0, 32ε)` を作り、`is_residual_ok(残差, T)` で $|f(s)| \le 32\varepsilon T$ を判定する。
残差は `checked_sum_of_products` で厳密に計算して一度だけ丸める。

この問題の正の根では $2s + c > 0$ で、$\kappa(s) = (s^2 + cs + K_{\mathrm{sp}})/(s(2s + c)) \le 2$ である。
$s^2 + cs = K_{\mathrm{sp}}$ を分子に使うと $\kappa(s) = 2(s + c)/(2s + c)$ となるからである。
良条件なので、残差の限界から、$s$ の相対誤差も一次の見積りで $32\varepsilon\,\kappa(s) \le 64\varepsilon$ 以下になる。

## 溶解度の計算

次のセルは選んだ塩と共通イオン濃度 $c$ について、解の公式、`checked_quadratic_roots`、有理化した式の三つで $s$ を求め、残差の仕様を判定する。
入力は塩の種類と $\log_{10}(c / (\mathrm{mol/L}))$（$-8$ から 0、0.5 刻み）である。
1 つ目の表は三つの方法の溶解度と、有理化した式に対する相対差を示す。
2 つ目の表は負の根、正の根の残差、限界 $32\varepsilon T$、`is_residual_ok` の判定を示す。

```rust
//| id: core-common-ion-solubility
//| ref: core-common-ion-solubility
//| title: 共通イオンを含む溶液での溶解度
//| run: reactive
//| crates: [scioxide-core]
//| uses: [core-common-ion-model]
//| inputs:
//|   salt: {"type":"select","label":"難溶性塩","options":["AgCl","AgBr","AgI","BaSO4"],"value":"AgI"}
//|   log_c: {"type":"range","label":"共通イオン濃度 log₁₀(c / (mol/L)) [-]","description":"−8 は 10 nmol/L、0 は 1 mol/L。","min":-8,"max":0,"step":0.5,"value":0}
//| cases:
//|   - {"id":"no-common-ion","label":"AgCl、c = 10 nmol/L","description":"共通イオンの効果がなく、溶解度は純水中の値に近い。","inputs":{"salt":"AgCl","log_c":-8}}
//|   - {"id":"barium-sulfate","label":"BaSO₄、c = 10 mmol/L","description":"共通イオンで溶解度が 3 桁下がる。","inputs":{"salt":"BaSO4","log_c":-2}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"solubility","path":"/rows/0/1","approx":{"value":8.52e-17,"rtol":1e-12}}
//|       - {"artifact":"solubility","path":"/rows/1/2","approx":{"value":0.303,"atol":0.005}}
//|       - {"artifact":"solubility","path":"/rows/2/2","range":{"min":0,"max":1e-15}}
//|       - {"artifact":"residual","path":"/rows/0/3","equals":"範囲内"}
//|   - case: no-common-ion
//|     expect:
//|       - {"artifact":"solubility","path":"/rows/2/1","approx":{"value":1.3299e-5,"rtol":1e-3}}
//|       - {"artifact":"solubility","path":"/rows/2/2","range":{"min":0,"max":1e-15}}
//|       - {"artifact":"residual","path":"/rows/0/3","equals":"範囲内"}
//|   - case: barium-sulfate
//|     expect:
//|       - {"artifact":"solubility","path":"/rows/2/1","approx":{"value":1.08e-8,"rtol":1e-5}}
//|       - {"artifact":"solubility","path":"/rows/2/2","range":{"min":0,"max":1e-15}}
//|       - {"artifact":"residual","path":"/rows/0/3","equals":"範囲内"}
use scioxide_core::{RealScalar, Tolerance, checked_quadratic_roots, checked_sum_of_products};

let k_sp = solubility_product(salt.as_str());
let c = RealScalar::powf(10.0_f64, log_c);
let naive = formula_root(c, k_sp);
let reference = rationalized_root(c, k_sp);

// s² + c s − K_sp = 0 の根。実根は小さい順に並ぶので、2 番目が正の溶解度である。
let [negative, positive] = checked_quadratic_roots(1.0, c, -k_sp).map_err(|e| e.to_string())?;
let s = positive.re;
let relative = |value: f64| (value - reference).abs() / reference;
let digits = serde_json::json!({ "notation": "scientific", "significantDigits": 11 });
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let solubility_columns = serde_json::json!([
    { "key": "0", "label": "方法" },
    { "key": "1", "label": "溶解度 s [mol/L]", "type": "number", "format": digits },
    {
        "key": "2",
        "label": "参照値との相対差 [-]",
        "type": "number",
        "format": sci3,
        "nullText": "基準"
    }
]);
emit_table_with_columns!(
    solubility_columns,
    vec![
        ("有理化した式（参照値）", reference, None),
        ("解の公式", naive, Some(relative(naive))),
        ("checked_quadratic_roots", s, Some(relative(s))),
    ],
    metadata = serde_json::json!({ "id": "solubility" })
);

// 残差 s² + c s − K_sp を厳密に計算し、仕様 |f(s)| ≤ 32 ε T を判定する。
let residual =
    checked_sum_of_products(&[s, s, -k_sp], &[s, c, 1.0]).map_err(|e| e.to_string())?;
let scale = s * s + c * s + k_sp;
let contract = Tolerance::new(0.0, 32.0 * f64::EPSILON).map_err(|e| e.to_string())?;
let within = contract
    .is_residual_ok(residual.abs(), scale)
    .map_err(|e| e.to_string())?;
let residual_columns = serde_json::json!([
    { "key": "0", "label": "負の根 [mol/L]", "type": "number", "format": digits },
    { "key": "1", "label": "残差 s² + c s − K_sp [mol²/L²]", "type": "number", "format": sci3 },
    { "key": "2", "label": "限界 32 ε T [mol²/L²]", "type": "number", "format": sci3 },
    { "key": "3", "label": "is_residual_ok(|残差|, T)" }
]);
emit_table_with_columns!(
    residual_columns,
    vec![(
        negative.re,
        residual,
        32.0 * f64::EPSILON * scale,
        if within { "範囲内" } else { "範囲外" },
    )],
    metadata = serde_json::json!({ "id": "residual" })
);
```

既定の AgI、$c = 1$ mol/L では、解の公式は $1.11 \times 10^{-16}$ mol/L で参照値から 30 % ずれる。
`checked_quadratic_roots` の正の根は $8.52 \times 10^{-17}$ mol/L で、参照値との相対差は 0 である。
残差 $7.3 \times 10^{-33}$ は限界 $1.2 \times 10^{-30}$ の内側にあり、`is_residual_ok` は範囲内と判定する。
負の根は $-1$ mol/L で、濃度としての意味を持たない。

AgCl で $c$ を $10^{-8}$ mol/L まで下げると共通イオンの効果がなくなり、溶解度は $1.3299 \times 10^{-5}$ mol/L で、純水中の $\sqrt{K_{\mathrm{sp}}} = 1.3304 \times 10^{-5}$ mol/L に近い。
この濃度では二つの根の絶対値がほぼ等しく、解の公式にも打ち消しはない。
BaSO₄ で $c = 10^{-2}$ mol/L にすると、溶解度は純水中の $1.04 \times 10^{-5}$ mol/L から $1.08 \times 10^{-8}$ mol/L へ 3 桁下がり、解の公式の相対差は $9 \times 10^{-12}$ になる。

## 共通イオン濃度による誤差の変化

次のセルは $c$ を $10^{-8}$ から $1$ mol/L まで対数等間隔の 65 点で動かし、解の公式と `checked_quadratic_roots` の参照値からの相対誤差を両対数軸に描く。
入力は塩の種類だけである。
横線は機械イプシロン $\varepsilon$ を示す。
相対誤差が厳密に 0 の点は対数軸に描けないので系列から除き、その数と、65 点での相対誤差の最大値を表に示す。

```rust
//| id: core-common-ion-error-sweep
//| ref: core-common-ion-error-sweep
//| title: 共通イオン濃度と溶解度の相対誤差
//| run: reactive
//| crates: [scioxide-core]
//| uses: [core-common-ion-model]
//| inputs:
//|   salt: {"type":"select","label":"難溶性塩","options":["AgCl","AgBr","AgI","BaSO4"],"value":"AgI"}
//| cases:
//|   - {"id":"silver-chloride","label":"AgCl","description":"K_sp が大きく、解の公式の誤差は 10⁻⁷ 程度までしか増えない。","inputs":{"salt":"AgCl"}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"errors","path":"/rows/0/2","range":{"min":0.1,"max":1}}
//|       - {"artifact":"errors","path":"/rows/1/2","range":{"min":0,"max":1e-15}}
//|   - case: silver-chloride
//|     expect:
//|       - {"artifact":"errors","path":"/rows/0/2","range":{"min":1e-8,"max":1e-5}}
//|       - {"artifact":"errors","path":"/rows/1/2","range":{"min":0,"max":1e-15}}
use scioxide_core::{RealScalar, checked_quadratic_roots};

let k_sp = solubility_product(salt.as_str());
let mut curves = [Vec::new(), Vec::new()];
let mut zeros = [0_u32; 2];
let mut worst = [0.0_f64; 2];
for step in 0..=64 {
    let c = RealScalar::powf(10.0_f64, -8.0 + 8.0 * step as f64 / 64.0);
    let reference = rationalized_root(c, k_sp);
    let [_, positive] = checked_quadratic_roots(1.0, c, -k_sp).map_err(|e| e.to_string())?;
    // 0 番目が解の公式、1 番目が checked_quadratic_roots。
    for (method, value) in [formula_root(c, k_sp), positive.re].into_iter().enumerate() {
        let error = (value - reference).abs() / reference;
        worst[method] = RealScalar::max(worst[method], error);
        if error > 0.0 {
            curves[method].push([c, error]);
        } else {
            zeros[method] += 1;
        }
    }
}
emit_line_chart!(
    &vec![
        serde_json::json!({ "name": "解の公式", "points": curves[0] }),
        serde_json::json!({ "name": "checked_quadratic_roots", "points": curves[1] }),
    ],
    options = &serde_json::json!({
        "xLabel": "共通イオン濃度 c [mol/L]",
        "yLabel": "参照値からの相対誤差 [-]",
        "xType": "log",
        "yType": "log",
        "annotations": [{ "kind": "line", "axis": "y", "value": f64::EPSILON, "label": "ε" }]
    })
);
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let columns = serde_json::json!([
    { "key": "0", "label": "方法" },
    { "key": "1", "label": "相対誤差が 0 の点（65 点中）[個]", "type": "integer" },
    { "key": "2", "label": "相対誤差の最大値 [-]", "type": "number", "format": sci3 }
]);
emit_table_with_columns!(
    columns,
    vec![
        ("解の公式", zeros[0], worst[0]),
        ("checked_quadratic_roots", zeros[1], worst[1]),
    ],
    metadata = serde_json::json!({ "id": "errors" })
);
```

AgI では、解の公式の相対誤差は $c$ とともにおよそ $\varepsilon\, c^2 / K_{\mathrm{sp}}$ に比例して増え、$c = 1$ mol/L で最大の 0.30 に達する。
これは、$c \approx \sqrt{K_{\mathrm{sp}}/\varepsilon} \approx 0.6$ mol/L のあたりで誤差が 1 の桁になるという見積りと合う。
`checked_quadratic_roots` は 65 点のうち 63 点で参照値と同じ値を返し（相対誤差 0 の点は系列に現れない）、残りの 2 点の相対誤差は $2.1 \times 10^{-16}$ 以下で $\varepsilon$ より小さい。
他の塩でも 63 点以上が一致し、相対誤差の最大値は $3 \times 10^{-16}$ 以下である。
一致する点の数は、$c$ の格子を作る `powf` の丸めが実行環境によって最後の桁で違いうるので、1 点ほど変わる。
参照値の有理化した式自身も丸め誤差を数回含むので、$10^{-16}$ 程度の差はどちらが正しいかを決めるものではない。

AgCl に替えると $K_{\mathrm{sp}}$ が 6 桁大きく、解の公式の誤差は $c = 1$ mol/L でも $1.7 \times 10^{-7}$ にとどまる。
打ち消しによる誤差は $c^2/K_{\mathrm{sp}}$ で決まるので、塩が難溶であるほど、共通イオンが濃いほど大きくなる。

## まとめ

共通イオンを含む溶液での溶解度は二次方程式の小さい根であり、解の公式では共通イオンの濃度が高いほど有効数字を失う。
`checked_quadratic_roots` は打ち消しのない式で根を求め、実根を小さい順に並べた配列で返すので、正の溶解度は 2 番目の要素として取り出せる。
根の精度は残差 $|f(s)| \le 32\varepsilon T$（と非正規化数の項）で保証されるので、`Tolerance::new(0, 32ε)` と `is_residual_ok` で判定できる。
前進誤差は有理化した式などの独立な値と照合して確かめる。
