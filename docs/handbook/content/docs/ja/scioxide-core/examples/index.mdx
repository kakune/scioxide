`scioxide-core` の例題は、途中の値の範囲、丸めで失われる小さな項、打ち消し、求解の回数の集計のように、最終結果だけを見ても気づきにくい問題を扱う。
どの例題も SciOxide の API で計算した値を、解析解、展開、別の方法など独立に求めた値と照合する。

| 例題 | 題材 | 主に使う API | 独立な検算 |
|---|---|---|---|
| [最終値より先に中間値を守る](range-safe-arithmetic/) | 大きな項に挟まれた和、成分の二乗が範囲を出るノルム、二項分布の確率 | `checked_sum`、`checked_scaled_norm`、`checked_float_product_factors` | 一回の乗算で丸めた $N s$、$\sqrt{n}\,x$、対数の厳密和 |
| [二原子分子の回転分配関数とボルツマン分布](rotational-partition-function/) | CO、HCl、HF の剛体回転子、解離極限を基準にしたエネルギー | `weighted_logsumexp`、`logsumexp`、`softmax_into`、`checked_sum_of_products` | Mulholland の高温展開、低温の 3 項の和、最頻の準位の連続近似 |
| [共通イオン効果と難溶性塩の溶解度](common-ion-solubility/) | AgCl、AgBr、AgI、BaSO₄ の溶解平衡 | `checked_quadratic_roots`、`Tolerance::is_residual_ok`、`checked_sum_of_products` | 有理化した解の公式、残差の仕様 |
| [単精度の調和級数と総和法](harmonic-series-summation/) | `f32` で足した調和級数が止まる現象 | `RangeAccumulator`、`ScaledAccumulator` | Euler–Maclaurin 展開 |
| [波動関数の裾のノルム](wavefunction-tail-norms/) | 調和振動子の減衰解と増大解の標本 | `checked_scaled_norm`、`ScaledNorm::merge`、`logsumexp` | 成分の対数からの対数和 |
| [スピン系の縮退度と常磁性](ising-paramagnet/) | 外部磁場中の独立なスピン | `checked_binomial`、`weighted_logsumexp`、`CombinationEnumerator`、`combination_rank` | 厳密解 $(2\cosh \beta h)^N$、全微視状態の列挙 |
| [Kepler 方程式と求解の回数の集計](kepler-solve-accounting/) | 不動点反復と入れ子の Newton 法 | `SolveState`、`SolveScope`、`invoke_provider`、`ResidualTolerance` | 二分法による参照値 |

数値の結果を読むときは、各例題の本文が示す誤差の大きさ（ulp、相対差、残差）と、その値がどの仕様や近似から期待されるものかを合わせて確かめる。
仕様の定義は[共通基盤の数理](../algorithms/)にまとめてある。

## まとめ

算術を扱う例題は、そのまま計算すると 0、`inf`、`NaN` になるか、気づかないうちに有効数字を失う入力を既定値に選んである。
和や積の途中の値が範囲を出る問題は最初の例題、指数の和や確率を扱う問題は分配関数とスピン系の例題、桁の大きく異なる多数の項の和は調和級数の例題で、素朴な計算との差を確かめられる。
小さい根の打ち消しは溶解度の例題、二乗が範囲を出るノルムは波動関数の例題、反復と評価の数え方は Kepler 方程式の例題が扱う。
自分の問題に当てはめるときは、表の誤差の列が本文の示す仕様や近似の大きさに収まっていることを確かめてから結果を使う。
