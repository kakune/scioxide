統計力学では、同じエネルギーを持つ微視状態の数（縮退度）が分配関数の重みになる。
縮退度は系の大きさとともに組合せ的に増え、スピンが 35 個になると 32 ビットの整数に収まらなくなる。
この例題では外部磁場中の相互作用のないスピン系（理想常磁性体）を取り上げ、縮退度を `checked_binomial` で、分配関数を `weighted_logsumexp` で求める。
この系には厳密解があるので、計算の誤差を直接測れる。

## 外部磁場中の独立なスピン

$N$ 個のスピン $s_i \in \{+1, -1\}$ が一様な磁束密度 $B$ の中にあり、互いに相互作用しないとする。
g 因子が 2 のスピン 1/2（常磁性塩の不対電子など）では磁気モーメントがボーア磁子 $\mu_B$ に等しく、1 つのスピンのエネルギーの大きさは $h = \mu_B B$ である。
ハミルトニアンは

$$
\mathcal{H} = -h \sum_{i=1}^{N} s_i
$$

である。
下向きのスピンが $k$ 個のとき、全磁化（$\mu_B$ を単位とする）は $M_k = N - 2k$、エネルギーは $E_k = -h M_k$ で、このエネルギーを持つ微視状態は $g(N, k) = C(N, k)$ 個ある。
逆温度を $\beta = 1/k_B T$ とすると、分配関数は

$$
Z = \sum_{k=0}^{N} C(N, k)\, e^{\beta h (N - 2k)}
$$

で、各スピンが独立なので $Z = (e^{\beta h} + e^{-\beta h})^N = (2\cosh \beta h)^N$ と因数分解できる。
準位 $k$ の確率と平均磁化は

$$
P(k) = \frac{C(N, k)\, e^{\beta h (N - 2k)}}{Z}, \qquad \langle M \rangle = \sum_k P(k)(N - 2k) = N \tanh \beta h
$$

である。
$P(k)$ は 1 つのスピンが下向きになる確率 $p_{\downarrow} = 1/(1 + e^{2\beta h})$ の二項分布で、平均は $\langle k \rangle = N p_{\downarrow}$ である。

計算に入るのは無次元の積 $\beta h = \mu_B B / k_B T$ だけである。
$\mu_B / k_B = 0.671714$ K/T なので、$B = 1$ T、$T = 1$ K では $\beta h \approx 0.672$ になる。
$\beta h \ll 1$ では $\langle M \rangle \approx N \beta h$ で、磁化は $B/T$ に比例する（キュリーの法則）。
$\beta h \gg 1$ では $\langle M \rangle \to N$ で、磁化は飽和する。

## 縮退度の厳密な計算

縮退度 $C(N, k)$ は $k = N/2$ の近くで最大になり、`usize` に収まる上限は次のとおりである。

| `usize` の幅 | 収まる最大の $\max_k C(N, k)$ | 扱える $N$ |
|---|---|---|
| 32 ビット（wasm32） | $C(34, 17) = 2{,}333{,}606{,}220$ | $N \le 34$（$C(35, 17) = 4{,}537{,}567{,}650 > 2^{32}$ で `SizeOverflow`） |
| 64 ビット | $C(67, 33) \approx 1.42 \times 10^{19}$ | $N \le 67$（$C(68, 34) \approx 2.85 \times 10^{19} > 2^{64}$） |

`checked_binomial(n, k)` は対称性で $k$ を $\min(k, n - k)$ に置き換え、$i = 1, 2, \ldots, k$ の順に $C(n - k + i, i) = C(n - k + i - 1, i - 1) \cdot (n - k + i) / i$ を整数で更新する。
各段では $d = \gcd(n - k + i,\ i)$ で分子と分母を先に割る。
前の段の値と $n - k + i$ の積は $i \cdot C(n - k + i, i)$ なので $i$ で割り切れ、$(n - k + i)/d$ と $i/d$ は互いに素だから、前の段の値が $i/d$ で割り切れる。
そのため割り算は厳密で、掛け算の結果はちょうど次の段の値 $C(n - k + i, i)$ になる。
この値は $i$ について単調に増え、最後の段で $C(n, k)$ になる。
途中のどの値も最終結果を超えないので、`SizeOverflow` を返すのは最終結果が `usize` に収まらないときだけである。

分配関数の計算ではこの整数を `f64` に変換して重みに使う。
$C(N, \lfloor N/2 \rfloor) < 2^{53}$ を満たす $N \le 56$ では、どの $C(N, k)$ も `f64` で厳密に表せるので、変換で誤差は入らない。

`scioxide-core` は二項係数の対数を返す関数を提供しない。
`usize` に収まらない大きな $N$ で縮退度を扱うには、`scioxide-special` の `ln_binomial` を使うか、漸化式 $\ln C(N, k+1) = \ln C(N, k) + \ln\bigl((N - k)/(k + 1)\bigr)$ を `RealScalar::ln` で累積する。
後者の丸め誤差は $k$ の段数に比例して増える。
このモデルのようにスピンが独立なら、縮退度を経由せずに因数分解した $\ln Z = N \ln(2\cosh\beta h)$ を使えばよい。

## 対数のままの分配関数と確率

項 $C(N, k)\, e^{\beta h(N-2k)}$ の最大は $e^{|\beta h| N}$ 程度で、$|\beta h| N > 709.78$ では `f64` の範囲を出る。
例えば $B = 10$ T、$T = 0.2$ K、$N = 34$ では $\beta h N \approx 1142$ である。
`weighted_logsumexp(v, w)` に指数 $v_k = \beta h (N - 2k)$ と重み $w_k = C(N, k)$ を別々に渡すと、$e^{v_k}$ や積 $w_k e^{v_k}$ を `f64` で作らずに $\ln Z$ を求められる。
重みがすべて正のとき、結果の誤差は結果自身の ULP で 16 ULP 以内である（試験で確かめた精度の保証、[対数和・重み付き和・正規化](../../algorithms/logarithmic-reductions/)）。
$\ln Z \approx 10$ なら、これは絶対誤差で約 $3 \times 10^{-14}$ にあたる。

確率 $P(k)$ は $\ln C(N, k) + \beta h (N - 2k)$ を `softmax_into` で正規化して求める。
$\ln C(N, k)$ は `RealScalar::ln` で計算する。
$\langle M \rangle$ は `checked_sum_of_products` で計算し、積の和を 1 回だけ丸める。
そのため $\langle M \rangle$ の誤差は、ほぼ $P(k)$ の丸め誤差だけで決まる。

厳密解の $\ln Z = N \ln(2\cosh \beta h)$ は、$\cosh$ のオーバーフローを避けて $N(|\beta h| + \ln(1 + e^{-2|\beta h|}))$ と書き、`f64` の固有メソッド `exp`・`ln_1p`・`tanh` で計算して参照値にする。
これらは SciOxide の関数を通らない独立な計算で、それぞれ自身の丸め誤差を持つ。

次のセルは $\ln Z$ と $\langle M \rangle$ を厳密解と比べる。
入力はスピン数 $N$、磁束密度 $B$ [T]、温度 $T$ [K] である。
1 つ目の表は $\ln Z$、$\langle M \rangle$ [$\mu_B$]、および比較のために項を `f64` で作って足した直接の和を、厳密解との絶対差と相対差とともに示す。
2 つ目の表は、$\beta h$、この環境の `usize` で `checked_binomial(35, 17)` が収まるか、$P(k)$ が 0 にアンダーフローした準位の数を示す。
グラフは $P(k)$ を対数軸に描き、厳密な平均 $\langle k \rangle$ を縦線で示す。
0 になった $P(k)$ は対数軸に描けないので、グラフから除く。

```rust
//| id: core-ising-paramagnet
//| ref: core-ising-paramagnet
//| title: 縮退度の重み付き対数和で分配関数を求める
//| run: reactive
//| crates: [scioxide-core]
//| inputs:
//|   n_spins: {"type":"range","label":"スピン数 N","description":"wasm32 では N ≤ 34 で縮退度が usize に収まる。","min":2,"max":34,"step":1,"value":16}
//|   field_tesla: {"type":"range","label":"磁束密度 B [T]","description":"負の B では下向きのスピンが有利になる。","min":-10,"max":10,"step":0.5,"value":1}
//|   temperature: {"type":"range","label":"温度 T [K]","description":"βh = 0.671714 B/T。低温・強磁場ほど βh が大きい。","min":0.1,"max":10,"step":0.1,"value":1}
//| cases:
//|   - {"id":"cold-strong-field","label":"N = 34、10 T、0.2 K","description":"βhN ≈ 1142 で、項を f64 で作る直接の和はオーバーフローする。","inputs":{"n_spins":34,"field_tesla":10,"temperature":0.2}}
//|   - {"id":"reversed-field","label":"B = −1 T","description":"磁化の符号が反転し、確率の山が k の大きい側に移る。","inputs":{"field_tesla":-1}}
//|   - {"id":"zero-field","label":"B = 0 T","description":"Z = 2^N、⟨M⟩ = 0 になる。","inputs":{"field_tesla":0}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"partition","path":"/rows/0/1","approx":{"value":14.457265385799,"rtol":1e-12}}
//|       - {"artifact":"partition","path":"/rows/0/3","range":{"min":0,"max":5e-14}}
//|       - {"artifact":"partition","path":"/rows/1/1","approx":{"value":9.377699506276,"rtol":1e-12}}
//|       - {"artifact":"partition","path":"/rows/1/3","range":{"min":0,"max":5e-14}}
//|       - {"artifact":"environment","path":"/rows/0/4","equals":0}
//|   - case: cold-strong-field
//|     expect:
//|       - {"artifact":"partition","path":"/rows/0/1","approx":{"value":1141.9138,"rtol":1e-8}}
//|       - {"artifact":"partition","path":"/rows/0/3","range":{"min":0,"max":1e-11}}
//|       - {"artifact":"partition","path":"/rows/2/1","equals":null}
//|       - {"artifact":"environment","path":"/rows/0/4","range":{"min":20,"max":26}}
//|   - case: reversed-field
//|     expect:
//|       - {"artifact":"partition","path":"/rows/0/1","approx":{"value":14.457265385799,"rtol":1e-12}}
//|       - {"artifact":"partition","path":"/rows/1/1","approx":{"value":-9.377699506276,"rtol":1e-12}}
//|   - case: zero-field
//|     expect:
//|       - {"artifact":"partition","path":"/rows/0/1","approx":{"value":11.090354888959125,"rtol":1e-14}}
//|       - {"artifact":"partition","path":"/rows/1/1","approx":{"value":0,"atol":1e-14}}
//|       - {"artifact":"partition","path":"/rows/1/4","equals":null}
use scioxide_core::{
    SciOxideErrorKind, RealScalar, checked_binomial, checked_sum_of_products, softmax_into,
    weighted_logsumexp,
};

let n = n_spins as usize;
// βh = μ_B B / (k_B T)。μ_B / k_B = 0.671714 K/T（g = 2 のスピン 1/2）。
let x = 0.671_714 * field_tesla / temperature;
// 縮退度 C(N, k)。N ≤ 56 では 2^53 未満なので f64 への変換は厳密。
let mut degeneracy = Vec::with_capacity(n + 1);
for k in 0..=n {
    degeneracy.push(checked_binomial(n, k).map_err(|e| e.to_string())? as f64);
}
// 全磁化 M_k = N − 2k [μ_B] と指数 βh M_k。
let magnetization: Vec<f64> = (0..=n).map(|k| n as f64 - 2.0 * k as f64).collect();
let exponents: Vec<f64> = magnetization.iter().map(|m| x * m).collect();

// ln Z: 重み C(N, k) と指数 βh M_k を分けて渡し、e^{βh M_k} を作らない。
let ln_z = weighted_logsumexp(&exponents, &degeneracy)
    .map_err(|e| e.to_string())?
    .log_magnitude()
    .ok_or("分配関数が 0 になった")?;
// P(k): ln C(N, k) + βh M_k を正規化する。⟨M⟩ は積の和を 1 回だけ丸める。
let logits: Vec<f64> = degeneracy
    .iter()
    .zip(&exponents)
    .map(|(&g, &e)| RealScalar::ln(g) + e)
    .collect();
let mut probability = vec![0.0; n + 1];
let mut scratch = vec![0.0; n + 1];
softmax_into(&logits, &mut probability, &mut scratch).map_err(|e| e.to_string())?;
let mean_m =
    checked_sum_of_products(&probability, &magnetization).map_err(|e| e.to_string())?;

// 比較用: 項 C(N, k) e^{βh M_k} を f64 の固有メソッドで作って足す。有限でなければ None。
let direct: f64 = degeneracy
    .iter()
    .zip(&exponents)
    .map(|(g, e)| g * e.exp())
    .sum::<f64>()
    .ln();
let direct = RealScalar::is_finite(direct).then_some(direct);
// 厳密解（参照値、f64 の固有メソッド）: ln Z = N(|βh| + ln(1 + e^{-2|βh|}))、⟨M⟩ = N tanh βh。
let exact_ln_z = n as f64 * (x.abs() + (-2.0 * x.abs()).exp().ln_1p());
let exact_m = n as f64 * x.tanh();
let row = |name: &'static str, value: Option<f64>, exact: f64| {
    let difference = value.map(|v| (v - exact).abs());
    // 厳密解が 0 のとき、相対差は定義しない。
    let relative = difference.filter(|_| exact != 0.0).map(|d| d / exact.abs());
    (name, value, exact, difference, relative)
};
let digits = serde_json::json!({ "significantDigits": 14 });
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let lost = "有限でない";
let columns = serde_json::json!([
    { "key": "0", "label": "量" },
    { "key": "1", "label": "計算値", "type": "number", "format": digits, "nullText": lost },
    { "key": "2", "label": "厳密解", "type": "number", "format": digits },
    { "key": "3", "label": "絶対差", "type": "number", "format": sci2, "nullText": "—" },
    { "key": "4", "label": "相対差 [-]", "type": "number", "format": sci2, "nullText": "—" }
]);
emit_table_with_columns!(
    columns,
    vec![
        row("ln Z [-]", Some(ln_z), exact_ln_z),
        row("⟨M⟩ [μ_B]", Some(mean_m), exact_m),
        row("ln Z（項を f64 で作る直接の和）[-]", direct, exact_ln_z),
    ],
    metadata = serde_json::json!({ "id": "partition" })
);

// この環境の usize で C(35, 17) = 4537567650 が収まるかを、エラーの分類で示す。
let (boundary_status, boundary) = match checked_binomial(35, 17) {
    Ok(value) => ("Ok", Some(value as f64)),
    Err(error) if error.kind() == SciOxideErrorKind::SizeOverflow => ("SizeOverflow", None),
    Err(error) => return Err(error.to_string()),
};
let underflow = probability.iter().filter(|&&p| p == 0.0).count();
let fixed4 = serde_json::json!({ "fractionDigits": 4 });
let environment_columns = serde_json::json!([
    { "key": "0", "label": "βh = μ_B B / k_B T [-]", "type": "number", "format": fixed4 },
    { "key": "1", "label": "usize の幅 [ビット]", "type": "integer" },
    { "key": "2", "label": "checked_binomial(35, 17) の結果" },
    { "key": "3", "label": "C(35, 17)", "type": "integer", "nullText": "usize に収まらない" },
    { "key": "4", "label": "P(k) が 0 になった準位 [個]", "type": "integer" },
    { "key": "5", "label": "準位の数 N + 1 [個]", "type": "integer" }
]);
emit_table_with_columns!(
    environment_columns,
    vec![(x, usize::BITS, boundary_status, boundary, underflow, n + 1,)],
    metadata = serde_json::json!({ "id": "environment" })
);

// 基準線: 厳密な平均 ⟨k⟩ = N / (1 + e^{2βh})（参照値、f64 の固有メソッド）。
let mean_k = n as f64 / (1.0 + (2.0 * x).exp());
let points: Vec<[f64; 2]> = probability
    .iter()
    .enumerate()
    .filter(|&(_, &p)| p > 0.0)
    .map(|(k, &p)| [k as f64, p])
    .collect();
emit_line_chart!(
    &vec![serde_json::json!({ "name": format!("N = {n}, βh = {x:.3}"), "points": points })],
    options = &serde_json::json!({
        "xLabel": "下向きのスピン数 k [個]",
        "yLabel": "準位の確率 P(k) [-]",
        "yType": "log",
        "xMin": 0.0,
        "xMax": n as f64,
        "annotations": [{ "kind": "line", "axis": "x", "value": mean_k, "label": "厳密な平均 ⟨k⟩" }]
    })
);
```

既定値（$N = 16$、$B = 1$ T、$T = 1$ K、$\beta h = 0.672$）では、$\ln Z = 14.457265385799$ と $\langle M \rangle = 9.377699506276\,\mu_B$ がどちらも厳密解と表示の桁まで一致する。
この条件では項が `f64` の範囲に収まるので、直接の和も同じ値を与える。
入力の範囲から選んだ 200 通り（$N$ が 2、9、16、25、34、$B$ が $\pm 10$、$\pm 3$、$\pm 0.5$、1、4 T、$T$ が 0.1、0.5、1、3、10 K）をネイティブ環境で実行すると、$\ln Z$ の相対差は $2.2 \times 10^{-16}$ 以下（1 ULP 程度）、$\langle M \rangle$ の相対差は $1.2 \times 10^{-15}$ 以下だった。
この大きさは参照値自身の丸め誤差と区別できず、$\ln Z$ については 16 ULP の仕様の内側にある。

$N = 34$、$B = 10$ T、$T = 0.2$ K にすると $\beta h N \approx 1142$ で、直接の和は有限でなくなるが、`weighted_logsumexp` の $\ln Z = 1141.9138$ は厳密解と一致する。
磁化は飽和して $\langle M \rangle = 34\,\mu_B$ になる。
このとき 35 準位のうち 23 準位の $P(k)$ が 0 にアンダーフローし、グラフから除かれる。

グラフは $P(k)$ の二項分布で、山は厳密な平均 $\langle k \rangle = N/(1 + e^{2\beta h})$ の縦線の近くにある。
$B = -1$ T では $\langle M \rangle$ の符号が反転し、山が $k$ の大きい側に移る。
$B = 0$ では $\ln Z = N \ln 2$、$\langle M \rangle = 0$ で、山は $k = N/2$ を中心に左右対称になる。
2 つ目の表の `checked_binomial(35, 17)` は、ブラウザ（wasm32）では `SizeOverflow` になり、64 ビットのネイティブ環境では 4537567650 を返す。

## 全微視状態の列挙による確認

小さな系では$2^N$ 個の微視状態をすべて列挙して和を取れる。
縮退度でまとめないので、二項係数と重み付き対数和の両方から独立な検算になる。
次のセルは $k = 0, \ldots, N$ ごとに `CombinationEnumerator` で下向きのスピンの位置の組を辞書式に列挙し、次の 3 つを確かめる。
入力はスピン数 $N$ と無次元の $\beta h$ である。

- 列挙した個数が `checked_binomial(N, k)` に等しいこと。
- 各組の `combination_rank` が列挙の順番に等しいこと。
- 各状態の磁化を個々のスピンから数えて作った全状態の指数 $\beta h M$ の `logsumexp` が、厳密な $\ln Z$ に一致すること。

1 つ目の表は個数と順位の照合の結果を、2 つ目の表は $\ln Z$ と厳密解の差を示す。

```rust
//| id: core-ising-microstates
//| ref: core-ising-microstates
//| title: 全微視状態を列挙して分配関数を確かめる

//| inputs:
//|   n_spins: {"type":"range","label":"スピン数 N","description":"2^N 個の状態をすべて列挙する。","min":2,"max":14,"step":1,"value":10}
//|   beta_h: {"type":"range","label":"βh = μ_B B / k_B T [-]","description":"B = 1 T、T = 1 K で約 0.67。","min":-3,"max":3,"step":0.1,"value":0.7}

//|   - {"id":"largest","label":"N = 14、βh = −2.5","description":"16384 個の状態を足しても、厳密解と 1 ULP 程度で一致する。","inputs":{"n_spins":14,"beta_h":-2.5}}
//|   - {"id":"zero-field","label":"βh = 0","description":"全状態の指数が 0 で、ln Z = N ln 2 になる。","inputs":{"beta_h":0}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"counts","path":"/rows/0/0","equals":1024}

//|       - {"artifact":"counts","path":"/rows/0/3","equals":0}
//|       - {"artifact":"partition","path":"/rows/0/0","approx":{"value":9.20417409918451,"rtol":1e-13}}
//|       - {"artifact":"partition","path":"/rows/0/2","range":{"min":0,"max":3e-14}}
//|   - case: largest
//|     expect:
//|       - {"artifact":"counts","path":"/rows/0/0","equals":16384}
//|       - {"artifact":"counts","path":"/rows/0/2","equals":0}
//|       - {"artifact":"counts","path":"/rows/0/3","equals":0}
//|       - {"artifact":"partition","path":"/rows/0/2","range":{"min":0,"max":1e-13}}
//|   - case: zero-field
//|     expect:
//|       - {"artifact":"partition","path":"/rows/0/0","approx":{"value":6.931471805599453,"rtol":1e-14}}
//|       - {"artifact":"partition","path":"/rows/0/2","range":{"min":0,"max":2e-14}}
use scioxide_core::{CombinationEnumerator, checked_binomial, combination_rank, logsumexp};

let n = n_spins as usize;
let mut exponents = Vec::new();
let (mut count_mismatch, mut rank_mismatch) = (0_u32, 0_u32);
for k in 0..=n {
    let mut storage = vec![0; k];
    let mut states =
        CombinationEnumerator::first_into(n, &mut storage[..]).map_err(|e| e.to_string())?;
    let mut position = 0;
    loop {
        let down = states.indices();
        if combination_rank(n, down).map_err(|e| e.to_string())? != position {
            rank_mismatch += 1;
        }
        // 各スピンの向きから磁化を数える（下向きの位置に −1、他は +1）。
        let m: i32 = (0..n).map(|i| if down.contains(&i) { -1 } else { 1 }).sum();
        exponents.push(beta_h * f64::from(m));
        position += 1;
        if !states.advance() {
            break;
        }
    }
    if position != checked_binomial(n, k).map_err(|e| e.to_string())? {
        count_mismatch += 1;
    }
}
let count_columns = serde_json::json!([
    { "key": "0", "label": "列挙した状態 [個]", "type": "integer" },
    { "key": "1", "label": "2^N [個]", "type": "integer" },
    { "key": "2", "label": "個数が C(N, k) と異なった k [個]", "type": "integer" },
    { "key": "3", "label": "順位が列挙の順番と異なった状態 [個]", "type": "integer" }
]);
emit_table_with_columns!(
    count_columns,
    vec![(exponents.len(), 1_usize << n, count_mismatch, rank_mismatch)],
    metadata = serde_json::json!({ "id": "counts" })
);

let ln_z = logsumexp(&exponents).map_err(|e| e.to_string())?;
// 厳密解（参照値、f64 の固有メソッド）。
let exact = n as f64 * (beta_h.abs() + (-2.0 * beta_h.abs()).exp().ln_1p());
let digits = serde_json::json!({ "significantDigits": 14 });
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let partition_columns = serde_json::json!([
    { "key": "0", "label": "ln Z（全状態の logsumexp）[-]", "type": "number", "format": digits },
    { "key": "1", "label": "ln Z（厳密解）[-]", "type": "number", "format": digits },
    { "key": "2", "label": "絶対差 [-]", "type": "number", "format": sci2 }
]);
emit_table_with_columns!(
    partition_columns,
    vec![(ln_z, exact, (ln_z - exact).abs())],
    metadata = serde_json::json!({ "id": "partition" })
);
```

既定値（$N = 10$、$\beta h = 0.7$）では状態の数は $2^{10} = 1024$ で、個数と順位の不一致は 0 になる。
全状態の `logsumexp` は、縮退度でまとめずに 1024 項を足しても、厳密解 $\ln Z = 9.2042$ と表示の桁まで一致する。
$N = 14$、$\beta h = -2.5$（16384 項）では絶対差が $7.1 \times 10^{-15}$ で、これは $\ln Z \approx 35.1$ の 1 ULP にあたる。
$\beta h = 0$ では全状態の指数が 0 で、$\ln Z = 10 \ln 2 = 6.9315$ になる。

## 適用範囲と限界

この例題の計算は、指数 $\beta h (N - 2k)$ が有限である限り $\ln Z$ と $\langle M \rangle$ の計算で桁あふれしない。
ただし次の制約は残る。

- 縮退度は `usize` の範囲（wasm32 で $N \le 34$、64 ビットで $N \le 67$）に限られる。
- `f64` で表せない小さな $P(k)$ は 0 または非正規化数になる。
  平均と分散への寄与は無視できるが、裾の確率そのものが必要なら `log_softmax_into` で対数のまま持つ。
- スピン間の相互作用がある Ising モデルでは $Z$ が因数分解できず、縮退度もエネルギー準位ごとに数え直す必要がある。
  厳密解との照合はこの例題の独立な系に限られる。

## まとめ

縮退度は `checked_binomial` で計算すると、途中の値がどれも最終結果以下なので、`SizeOverflow` は結果自体が `usize` に収まらないときだけ返る。
`scioxide-core` は二項係数の対数を提供しないので、$N \ge 35$（wasm32）では `scioxide-special` の `ln_binomial` を使うか、対数の漸化式を自分で累積する。
分配関数は重みと指数を分けたまま `weighted_logsumexp` に渡し、確率は `softmax_into`、期待値は `checked_sum_of_products` で求めると、項を作る直接の和が `inf` になる低温・強磁場でも有限の結果が得られる。
既定の条件では $\ln Z$ も $\langle M \rangle$ も厳密解と表示の桁まで一致し、試した 200 通りの入力でも相対差は $1.2 \times 10^{-15}$ 以下にとどまり、全微視状態の列挙とも 1 ULP 程度で一致する。
