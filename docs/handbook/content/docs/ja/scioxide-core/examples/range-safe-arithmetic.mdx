最終的な答えが倍精度で表せる大きさでも、途中の値が範囲を出たり、小さな項が丸めで消えたりすると、結果は 0、`inf`、`NaN` になる。
この例題では、そうした失敗が起きる三つの計算を、`scioxide-core` の範囲安全な算術で計算し直し、それぞれ独立に求めた値と照合する。
各関数の誤差の保証は[厳密累積と範囲安全な算術](../../algorithms/range-safe-arithmetic/)にまとめてある。

## 大きな項に挟まれた小さな項の和

$A$、$s$ が $N$ 個、$-A$ の順に並んだ $N + 2$ 項の和を考える。
数学的な和は $N s$ である。
$A$ の近くの倍精度数の間隔が $2s$ を超えると、左から足すたびに $s$ が丸めで失われる。
間隔がちょうど $2s$ のときは $A + s$ が隣り合う二数の中点になり、偶数丸めで $A$ に戻るか隣の数に上がるかは $A$ の仮数の最下位ビットで決まる。
絶対値の小さい順に並べ替えてから足すと、先に $N s$ が作られるが、その後に $A$ を足したときの丸め誤差は残る。

`checked_sum` は厳密な和を一度だけ丸めた値を返すので、結果は項の順序によらない。
参照値は $N \times s$ を倍精度の乗算一回で求めた値である。
$N$ は倍精度で厳密に表せるので、この積は入力の $s$（$10^p$ を丸めた倍精度数）の $N$ 倍を正しく丸めた値で、`checked_sum` の結果とビットまで一致するはずである。

次のセルの入力は大きな項の指数 $\log_{10} A$（12 から 20）、小さな項の指数 $\log_{10} s$（$-2$ から 2）、小さな項の数 $N$（1 から 1000）である。
表は三つの方法の和と、参照値 $N s$ との差を示す。

```rust
//| id: core-range-safe-sum
//| ref: core-range-safe-sum
//| title: 大きな項に挟まれた N 個の小さな項
//| run: reactive
//| crates: [scioxide-core]
//| inputs:
//|   large_exp: {"type":"range","label":"大きな項の指数 log₁₀ A [-]","description":"A と −A で挟む。","min":12,"max":20,"step":1,"value":16}
//|   small_exp: {"type":"range","label":"小さな項の指数 log₁₀ s [-]","description":"s = 10^p を N 個並べる。","min":-2,"max":2,"step":1,"value":0}
//|   count: {"type":"range","label":"小さな項の数 N [個]","description":"和の参照値は N s。","min":1,"max":1000,"step":1,"value":999}
//| cases:
//|   - {"id":"even-count","label":"N = 1000","description":"A + N s が倍精度で表せ、小さい順の和のずれが消える。","inputs":{"count":1000}}
//|   - {"id":"huge-term","label":"A = 10²⁰","description":"小さい順に足しても N s が A に吸収される。","inputs":{"large_exp":20}}
//|   - {"id":"inexact-term","label":"A = 10¹², s = 0.01","description":"s が二進で表せず、足すたびに丸めが起きる。","inputs":{"large_exp":12,"small_exp":-2,"count":1000}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"sums","path":"/rows/0/1","equals":0}
//|       - {"artifact":"sums","path":"/rows/1/1","equals":1000}
//|       - {"artifact":"sums","path":"/rows/2/1","equals":999}
//|       - {"artifact":"sums","path":"/rows/2/2","equals":0}
//|   - case: even-count
//|     expect:
//|       - {"artifact":"sums","path":"/rows/1/2","equals":0}
//|       - {"artifact":"sums","path":"/rows/2/2","equals":0}
//|   - case: huge-term
//|     expect:
//|       - {"artifact":"sums","path":"/rows/1/1","equals":0}
//|       - {"artifact":"sums","path":"/rows/2/1","equals":999}
//|   - case: inexact-term
//|     expect:
//|       - {"artifact":"sums","path":"/rows/2/1","approx":{"value":10,"rtol":1e-15}}
//|       - {"artifact":"sums","path":"/rows/2/2","equals":0}
use scioxide_core::{RealScalar, checked_sum};

let a = RealScalar::powi(10.0_f64, large_exp as i32);
let s = RealScalar::powi(10.0_f64, small_exp as i32);
let n = count as usize;
let mut terms = vec![a];
terms.extend(std::iter::repeat_n(s, n));
terms.push(-a);

// 比較用: 左から足す和と、絶対値の小さい順に並べてから足す和。
let left_to_right: f64 = terms.iter().sum();
let mut sorted = terms.clone();
sorted.sort_by(|x, y| x.abs().total_cmp(&y.abs()));
let ascending: f64 = sorted.iter().sum();
let exact = checked_sum(&terms).map_err(|e| e.to_string())?;
// 参照値: N s を一回の乗算で正しく丸めた値。
let reference = n as f64 * s;
let digits = serde_json::json!({ "significantDigits": 12 });
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let columns = serde_json::json!([
    { "key": "0", "label": "方法" },
    { "key": "1", "label": "和 [-]", "type": "number", "format": digits },
    { "key": "2", "label": "和 − N s [-]", "type": "number", "format": sci3 }
]);
emit_table_with_columns!(
    columns,
    vec![
        ("左から足す", left_to_right, left_to_right - reference),
        ("小さい順に足す", ascending, ascending - reference),
        ("checked_sum", exact, exact - reference),
    ],
    metadata = serde_json::json!({ "id": "sums" })
);
```

既定の $A = 10^{16}$、$s = 1$、$N = 999$ では、$A$ の近くの間隔は 2 で、$A + 1$ は中点にあたる。
$10^{16}$ の仮数は偶数なので、左から足すと毎回 $A$ に戻り、1 がすべて失われて 0 になる。
小さい順に足すと 999 が作られるが、$10^{16} + 999$ が偶数丸めで $10^{16} + 1000$ になり、結果は 1 だけずれて 1000 になる。
$N = 1000$ にするとこのずれは消え、$A = 10^{20}$（間隔 16384）では小さい順の和も 0 になる。
$A = 10^{12}$、$s = 0.01$、$N = 1000$ では、$A$ の近くの間隔 $1.2 \times 10^{-4}$ での丸めが積もり、左からの和は 10.0098 になる。
`checked_sum` はどの設定でも参照値との差が 0 である。

## オーバーフローやアンダーフローする成分のノルム

$n$ 個の成分がすべて $x = 10^{q}$ のベクトルのノルムは $\sqrt{n}\, 10^{q}$ である。
$\sqrt{\sum_i x_i^2}$ をそのまま計算すると、$q \ge 155$ では $x^2$ が倍精度の最大値を超えて `inf` になり、$q \le -162$ では $x^2$ が 0 に丸められて結果が 0 になる。
$-161 \le q \le -154$ では $x^2$ が非正規化数になり、0 にはならないが仮数の桁を失う。
このセルの入力の範囲では、ノルム自体は倍精度の正規化数に収まっている。

`checked_scaled_norm` は成分を最大値で割った比の二乗を足すので、どちらも起きない。
参照値は $\sqrt{n}$ と $x$ を倍精度で掛けた値で、相対誤差は $\varepsilon$ 程度である。
`checked_scaled_norm` の誤差限界は、0 でない成分の数 $m = n$ を使って $\gamma_{8n+8}\,\lVert \mathbf{x} \rVert + \eta/2$ である（$\gamma_k = ku/(1 - ku)$、$u = \varepsilon/2$、$\eta$ は最小の正の非正規化数）。

次のセルの入力は成分の指数 $q$（$-200$ から 300、5 刻み）と成分の数 $n$（2 から 64）である。
表はそのままの計算、`checked_scaled_norm`、参照値、後の二つの差、誤差限界を示す。
そのままの計算が `inf` になった場合は、値のない欄になる。

```rust
//| id: core-range-safe-norm
//| ref: core-range-safe-norm
//| title: 成分の二乗が範囲を出るベクトルのノルム
//| run: reactive
//| crates: [scioxide-core]
//| inputs:
//|   norm_exponent: {"type":"range","label":"成分の指数 q [-]","description":"x = 10^q。q ≥ 155 で二乗がオーバーフローし、q ≤ −162 で二乗が 0 になる。","min":-200,"max":300,"step":5,"value":200}
//|   length: {"type":"range","label":"成分の数 n [個]","description":"ノルムは √n · 10^q。","min":2,"max":64,"step":1,"value":8}
//| cases:
//|   - {"id":"underflow","label":"q = −180","description":"二乗が 0 に丸められる。","inputs":{"norm_exponent":-180}}
//|   - {"id":"subnormal-squares","label":"q = −160","description":"二乗が非正規化数になり、そのままの計算は桁を失う。","inputs":{"norm_exponent":-160}}
//|   - {"id":"ordinary","label":"q = 0, n = 64","description":"範囲の問題がなく、三つの値が一致する。","inputs":{"norm_exponent":0,"length":64}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"norms","path":"/rows/0/0","equals":null}
//|       - {"artifact":"norms","path":"/rows/0/1","approx":{"value":2.8284271247461903e200,"rtol":1e-14}}
//|       - {"artifact":"norms","path":"/rows/0/3","range":{"min":0,"max":2.3e186}}
//|   - case: underflow
//|     expect:
//|       - {"artifact":"norms","path":"/rows/0/0","equals":0}
//|       - {"artifact":"norms","path":"/rows/0/1","approx":{"value":2.8284271247461903e-180,"rtol":1e-14}}
//|   - case: subnormal-squares
//|     expect:
//|       - {"artifact":"norms","path":"/rows/0/1","approx":{"value":2.8284271247461903e-160,"rtol":1e-14}}
//|   - case: ordinary
//|     expect:
//|       - {"artifact":"norms","path":"/rows/0/0","equals":8}
//|       - {"artifact":"norms","path":"/rows/0/1","equals":8}
use scioxide_core::{RealScalar, checked_scaled_norm};

let x = RealScalar::powi(10.0_f64, norm_exponent as i32);
let n = length as usize;
let values = vec![x; n];
// 比較用: 二乗の和の平方根をそのまま計算する（inf は None にして表に出す）。
let naive = RealScalar::sqrt(values.iter().map(|v| v * v).sum::<f64>());
let naive = naive.is_finite().then_some(naive);
let scaled = checked_scaled_norm(&values).map_err(|e| e.to_string())?;
// 参照値: √n · x（丸めは平方根と積の 2 回）。
let reference = RealScalar::sqrt(n as f64) * x;
// 誤差限界 γ_k‖x‖ + η/2（k = 8n + 8、u = ε/2）。
let k = (8 * n + 8) as f64;
let u = f64::EPSILON / 2.0;
let bound = k * u / (1.0 - k * u) * reference + f64::from_bits(1) / 2.0;
let digits = serde_json::json!({ "notation": "scientific", "significantDigits": 15 });
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let columns = serde_json::json!([
    { "key": "0", "label": "√(Σ x²) [-]", "type": "number", "format": digits, "nullText": "inf" },
    { "key": "1", "label": "checked_scaled_norm [-]", "type": "number", "format": digits },
    { "key": "2", "label": "参照値 √n · x [-]", "type": "number", "format": digits },
    { "key": "3", "label": "|checked − 参照値| [-]", "type": "number", "format": sci3 },
    { "key": "4", "label": "誤差限界 [-]", "type": "number", "format": sci3 }
]);
emit_table_with_columns!(
    columns,
    vec![(naive, scaled, reference, (scaled - reference).abs(), bound)],
    metadata = serde_json::json!({ "id": "norms" })
);
```

既定の $q = 200$ ではそのままの計算は `inf` になり、$q = -180$ では 0 になる。
$q = -160$ では $x^2 = 10^{-320}$ が非正規化数で、そのままの計算は $2.82841 \times 10^{-160}$ になり、6 桁目から先を失う。
`checked_scaled_norm` はこれらのどの入力でも参照値 $\sqrt{8} \times 10^{q}$ との差が 0 で、誤差限界（参照値の約 $8 \times 10^{-15}$ 倍）の内側にある。
$q = 0$、$n = 64$ では範囲の問題がなく、三つの値がすべて 8 になる。

## 二項分布の確率

表の出る確率 $p$ の硬貨を $n$ 回投げて、表がちょうど $k$ 回出る確率は

$$
P(k) = C(n, k)\, p^{k} (1 - p)^{n - k}
$$

である。
$n = 2000$、$k = 1000$、$p = 1/2$ では $P \approx 0.0178$ だが、$C(2000, 1000) \approx 2 \times 10^{600}$ は倍精度で `inf` になり、その後にべき $2^{-1000} \approx 9 \times 10^{-302}$ を掛けても `inf` のままである。
逆にべき $p^k (1-p)^{n-k} = 2^{-2000}$ を先にまとめると 0 になる。

`checked_float_product_factors` は因子を仮数と指数に分け、指数を別に足してから最後に一度だけ戻すので、途中の積が範囲を出ない。
因子は $C(n, k)$ を $\prod_{i=0}^{k-1} (n - i)/(i + 1)$ に分けたものと、$p$ を $k$ 個、$1 - p$ を $n - k$ 個並べたもので、合計 $n + k$ 個になる。
渡した因子の積に対する相対誤差は $\gamma_{n+k-1} \approx (n + k)\,u$ 以下である。
各因子 $(n - i)/(i + 1)$ を作る除算の丸めは、これとは別に因子ごとに $u$ 以下の相対誤差を加える。

独立な参照値は対数 $\ln P = \sum \ln(\text{因子})$ を `RangeAccumulator` で足し合わせてから指数を取った値である。
対数の和は範囲の問題を起こさないが、各対数の丸め誤差が和に残り、指数を取ると相対誤差になる。
したがって二つの値の差は、どちらの誤差も含む。

次のセルの入力は試行回数 $n$（100 から 3000、100 刻み）と表の確率 $p$（10 % から 90 %、5 % 刻み）で、$k$ は $np$ に最も近い整数とする。
表は $k$、倍精度のままの二項係数と確率、`checked_float_product_factors` の値、参照値、後の二つの相対差を示す。
倍精度のままの計算が有限でない場合は、値のない欄になる。

```rust
//| id: core-range-safe-binomial
//| ref: core-range-safe-binomial
//| title: 途中の値が範囲を出る二項分布の確率
//| run: reactive
//| crates: [scioxide-core]
//| inputs:
//|   trials: {"type":"range","label":"試行回数 n [回]","description":"n が大きいほど C(n, k) と p^k が範囲を出る。","min":100,"max":3000,"step":100,"value":2000}
//|   success_percent: {"type":"range","label":"表の確率 p [%]","description":"k は n p に最も近い整数とする。","min":10,"max":90,"step":5,"value":50}
//| cases:
//|   - {"id":"small-n","label":"n = 100","description":"倍精度のままの計算も有限になる。","inputs":{"trials":100}}
//|   - {"id":"skewed","label":"n = 3000, p = 10 %","description":"分布の山が k = 300 にある。","inputs":{"trials":3000,"success_percent":10}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"binomial","path":"/rows/0/0","equals":1000}
//|       - {"artifact":"binomial","path":"/rows/0/1","equals":null}
//|       - {"artifact":"binomial","path":"/rows/0/3","approx":{"value":0.01783901114585432,"rtol":1e-12}}
//|       - {"artifact":"binomial","path":"/rows/0/5","range":{"min":0,"max":1e-11}}
//|   - case: small-n
//|     expect:
//|       - {"artifact":"binomial","path":"/rows/0/2","approx":{"value":0.07958923738717877,"rtol":1e-10}}
//|       - {"artifact":"binomial","path":"/rows/0/3","approx":{"value":0.07958923738717877,"rtol":1e-12}}
//|   - case: skewed
//|     expect:
//|       - {"artifact":"binomial","path":"/rows/0/0","equals":300}
//|       - {"artifact":"binomial","path":"/rows/0/3","approx":{"value":0.02427,"rtol":1e-3}}
//|       - {"artifact":"binomial","path":"/rows/0/5","range":{"min":0,"max":1e-11}}
use scioxide_core::{RangeAccumulator, RealScalar, checked_float_product_factors};

let n = trials as usize;
let p = success_percent / 100.0;
let k = RealScalar::round(n as f64 * p) as usize;
// 因子: (n − i)/(i + 1) を k 個、p を k 個、1 − p を n − k 個。
let mut factors: Vec<f64> = (0..k).map(|i| (n - i) as f64 / (i + 1) as f64).collect();
factors.extend(std::iter::repeat_n(p, k));
factors.extend(std::iter::repeat_n(1.0 - p, n - k));

let probability = checked_float_product_factors(&factors).map_err(|e| e.to_string())?;
// 比較用: 二項係数とべきを別々に倍精度で計算して掛ける（非有限の値は None にする）。
let binomial: f64 = factors[..k].iter().product();
let powers = RealScalar::powi(p, k as i32) * RealScalar::powi(1.0 - p, (n - k) as i32);
let naive = binomial * powers;
// 独立な参照値: 対数の和を厳密に累積してから指数を取る。
let mut log_sum = RangeAccumulator::new();
for &factor in &factors {
    log_sum
        .add(RealScalar::ln(factor))
        .map_err(|e| e.to_string())?;
}
let reference = RealScalar::exp(log_sum.finish().map_err(|e| e.to_string())?);
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let digits = serde_json::json!({ "notation": "scientific", "significantDigits": 13 });
let columns = serde_json::json!([
    { "key": "0", "label": "k [回]", "type": "integer" },
    {
        "key": "1",
        "label": "C(n, k)（倍精度の積）[-]",
        "type": "number",
        "format": sci3,
        "nullText": "inf"
    },
    {
        "key": "2",
        "label": "倍精度のままの確率 [-]",
        "type": "number",
        "format": digits,
        "nullText": "非有限"
    },
    {
        "key": "3",
        "label": "checked_float_product_factors [-]",
        "type": "number",
        "format": digits
    },
    { "key": "4", "label": "参照値 exp(Σ ln 因子) [-]", "type": "number", "format": digits },
    { "key": "5", "label": "相対差 [-]", "type": "number", "format": sci3 }
]);
emit_table_with_columns!(
    columns,
    vec![(
        k as u32,
        binomial.is_finite().then_some(binomial),
        naive.is_finite().then_some(naive),
        probability,
        reference,
        (probability - reference).abs() / reference,
    )],
    metadata = serde_json::json!({ "id": "binomial" })
);
```

既定の $n = 2000$、$p = 0.5$ では、倍精度の二項係数もそのままの確率も有限にならず、`checked_float_product_factors` は $P = 1.78390111459 \times 10^{-2}$ を返す。
この値は整数演算で求めた $C(2000, 1000)/2^{2000} = 1.78390111459 \times 10^{-2}$ と表示した桁で一致する。
参照値との相対差は $4 \times 10^{-14}$ 程度で、因子数と単位丸めの積 $(n + k)\,u \approx 3.3 \times 10^{-13}$ より小さい。
$n = 100$ に下げるとそのままの計算も有限になり、三つの値が $7.9589237387 \times 10^{-2}$ まで一致する。
$n = 3000$、$p = 10\,\%$ では $k = 300$ で、二項係数は再び `inf` になるが、`checked_float_product_factors` は $2.4272 \times 10^{-2}$ を返し、参照値との相対差は同じく $4 \times 10^{-14}$ 程度である。

## まとめ

途中の値の範囲や丸めで失われる小さな項は、最終結果を見ただけでは気づきにくい。
大きさの異なる項の和は `checked_sum`、成分の大きさが極端なベクトルのノルムは `checked_scaled_norm`、範囲を出る因子の積は `checked_float_product_factors` で計算すれば、最終結果が表せる限り途中で失敗しない。
和は一回の丸め、ノルムは $\gamma_{8m+8}$、積は $\gamma_{n-1}$ の誤差限界を持つので、成分や因子の数から、必要な精度に足りるかを計算の前に見積もれる。
並べ替えや手作業の尺度調整は改善にはなるが、どの入力でも正しい結果を保証するものではない。
