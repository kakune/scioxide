分配関数は気体の熱容量や自由エネルギー、化学平衡定数を求めるための基本量である。
二原子分子の回転では、準位の縮退度 $2J + 1$ とボルツマン因子 $e^{-E_J / k_B T}$ の積を足し合わせる。
化学平衡の計算でエネルギーの基準を解離極限に取ると、全準位のエネルギーが解離エネルギー $D_0$ だけ下がり、指数がそのまま計算できないほど大きくなる。
この例題では重み付き対数和 `weighted_logsumexp` と正規化 `softmax_into` を使い、この移動に影響されずに分配関数と占有確率を求める。

## 剛体回転子のモデル

異核二原子分子（CO、HCl、HF など）を剛体回転子とみなすと、回転準位のエネルギーは回転量子数 $J = 0, 1, 2, \ldots$ について

$$
E_J = h c B\, J(J+1) = k_B \theta_{\mathrm{rot}}\, J(J+1), \qquad \theta_{\mathrm{rot}} = \frac{h c B}{k_B}
$$

である。
$B$ は回転定数 [cm⁻¹]（下の表では平衡値 $B_e$）、$\theta_{\mathrm{rot}}$ は回転特性温度 [K] で、$hc/k_B \approx 1.4388$ cm·K である。
各準位は磁気量子数 $M_J = -J, \ldots, J$ により $g_J = 2J + 1$ 重に縮退している。
同核二原子分子では核スピン統計による重みが加わるので、ここでは扱わない。

回転分配関数、準位 $J$ の占有確率、回転の内部エネルギーは

$$
q(T) = \sum_{J=0}^{\infty} (2J+1)\, e^{-\theta_{\mathrm{rot}} J(J+1)/T}, \qquad
p_J = \frac{(2J+1)\, e^{-\theta_{\mathrm{rot}} J(J+1)/T}}{q(T)}, \qquad
\frac{U}{k_B T} = \sum_J p_J\, \frac{\theta_{\mathrm{rot}} J(J+1)}{T}
$$

である。

| 分子 | $B$ [cm⁻¹] | $\theta_{\mathrm{rot}}$ [K] | $D_0$ [eV] |
|---|---|---|---|
| CO | 1.931 | 2.78 | 11.09 |
| HCl | 10.59 | 15.2 | 4.43 |
| HF | 20.96 | 30.2 | 5.87 |

## 解離極限を基準にしたときの桁あふれ

エネルギーの基準を解離した原子に取ると、$J = 0$ の準位は $-D_0$ になり、指数は

$$
v_J = -\frac{E_J - D_0}{k_B T} = \frac{D_0}{k_B T} - \frac{\theta_{\mathrm{rot}} J(J+1)}{T}
$$

となる。
CO の $D_0 = 11.09$ eV、$k_B = 8.617333 \times 10^{-5}$ eV/K では、$T = 100$ K で $D_0 / k_B T \approx 1287$ である。
$e^{709.78}$ が倍精度の最大値なので、$e^{1287}$ は表せず、和をそのまま計算すると `inf` になる。

対数和では、移動 $C = D_0 / k_B T$ は $\ln q' = C + \ln q$ として結果に足されるだけで、確率 $p_J$ は変わらない。
`weighted_logsumexp(v, g)` は重み $g_J = 2J + 1$ と指数 $v_J$ から $\ln q'$ を `LogValue` として返し、`softmax_into` は $v_J + \ln g_J$ を正規化して $p_J$ を返す。

## 独立な検算

$T \gg \theta_{\mathrm{rot}}$ では、Euler–Maclaurin の和公式から得られる Mulholland の展開

$$
q(T) = \frac{T}{\theta_{\mathrm{rot}}} \left( 1 + \frac{x}{3} + \frac{x^2}{15} + \frac{4 x^3}{315} + O(x^4) \right), \qquad x = \frac{\theta_{\mathrm{rot}}}{T}
$$

が使える。
$U / k_B T = d \ln q / d \ln T$ をこの展開から計算すると

$$
\frac{U}{k_B T} = 1 - \frac{x}{3} - \frac{x^2}{45} + O(x^3)
$$

となり、$x \to 0$ で古典的な等分配則の値 1（回転の自由度 2 つ分）に近づく。
$T \lesssim \theta_{\mathrm{rot}}$ では最初の 3 項 $q \approx 1 + 3 e^{-2x} + 5 e^{-6x}$ が良い近似になる。
また、$J$ を連続変数とみなして $p_J$ を最大にすると $(2J + 1)^2 = 2T/\theta_{\mathrm{rot}}$、すなわち最頻の準位は $J \approx \sqrt{T / 2\theta_{\mathrm{rot}}} - 1/2$ の近くにある。

和は $\theta_{\mathrm{rot}} J(J+1)/T > 60$（ボルツマン因子が $e^{-60} \approx 10^{-26}$ 未満）になるか $J = 400$ に達したところで打ち切る。
この例題の温度の範囲（$T \le 3162$ K）では、打ち切りは常に前者の条件で決まる。

2 つのセルは次の定義を共有する。
`molecule_constants` は上の表の $\theta_{\mathrm{rot}}$ と $D_0$ を返し、`reduced_energies` は換算エネルギー $\epsilon_J = \theta_{\mathrm{rot}} J(J+1)/T$ を打ち切りの準位まで並べ、`degeneracies` は縮退度 $g_J = 2J + 1$ を返す。

```rust
//| id: core-rotational-model
//| kind: definitions
//| title: 剛体回転子の定数と換算エネルギー
//| crates: [scioxide-core]
/// 回転特性温度 θ_rot [K] と解離エネルギー D₀ [eV]。
pub(crate) fn molecule_constants(molecule: &str) -> (f64, f64) {
    match molecule {
        "HCl" => (15.2, 4.43),
        "HF" => (30.2, 5.87),
        _ => (2.78, 11.09),
    }
}

/// 換算エネルギー ε_J = θ_rot J(J+1)/T [-]。ε_J > 60 になる準位か J = 400 まで並べる。
pub(crate) fn reduced_energies(theta: f64, temperature: f64) -> Vec<f64> {
    let energy = |j: u32| theta * f64::from(j * (j + 1)) / temperature;
    let last = (0..=400).find(|&j| energy(j) > 60.0).unwrap_or(400);
    (0..=last).map(energy).collect()
}

/// 縮退度 g_J = 2J + 1（J = 0, …, levels − 1）。
pub(crate) fn degeneracies(levels: usize) -> Vec<f64> {
    (0..levels).map(|j| 2.0 * j as f64 + 1.0).collect()
}
```

## 分配関数の対数

次のセルは $\ln q'$ を `weighted_logsumexp` で計算し、指数と縮退度の対数をまとめた $v_J + \ln g_J$ の `logsumexp` と比べる。
入力は分子、温度 $T$ [K] の常用対数、解離極限を基準にするかどうかである。
「解離極限を基準にする」を選ぶと、すべての指数に $D_0 / k_B T$ が加わる。

1 つ目の表は 2 つの方法の $\ln q'$ と、指数をそのまま足して対数を取った値を示す。
2 つ目の表は移動を引いた $\ln q = \ln q' - D_0/k_B T$ を独立な参照値と比べる。
参照値は $T > \theta_{\mathrm{rot}}$ で Mulholland の展開、それ以下で 3 項の和で、`f64` の固有メソッドで計算する。
どちらも近似なので、切り替わる $T \approx \theta_{\mathrm{rot}}$ の近くでは、展開の側で $3 \times 10^{-3}$ 程度、3 項の和の側で $10^{-5}$ 程度の差が残る。

```rust
//| id: core-rotational-partition-function
//| ref: core-rotational-partition-function
//| title: 回転分配関数の対数
//| run: reactive
//| uses: [core-rotational-model]
//| crates: [scioxide-core]
//| inputs:
//|   molecule: {"type":"select","label":"分子","options":["CO","HCl","HF"],"value":"CO"}
//|   log_t: {"type":"range","label":"温度 log₁₀(T / K)","description":"0 は 1 K、2 は 100 K、3.5 は約 3162 K。","min":0,"max":3.5,"step":0.1,"value":2}
//|   include_d0: {"type":"checkbox","label":"解離極限を基準にする","description":"全準位の指数に D₀ / k_B T を加える。","value":true}
//| cases:
//|   - {"id":"hf-cold","label":"HF、10 K","description":"T < θ_rot なので、参照値は 3 項の和に切り替わる。","inputs":{"molecule":"HF","log_t":1}}
//|   - {"id":"ground-reference","label":"CO、100 K、基底準位を基準","description":"移動がなければ、指数をそのまま足しても有限になる。","inputs":{"include_d0":false}}
//|   - {"id":"hcl-hot","label":"HCl、1000 K","description":"高温では多くの準位が寄与し、Mulholland の展開と一致する。","inputs":{"molecule":"HCl","log_t":3}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"sums","path":"/rows/0/3","approx":{"value":1290.5330934028543,"rtol":1e-12}}
//|       - {"artifact":"sums","path":"/rows/0/5","equals":null}
//|       - {"artifact":"check","path":"/rows/0/1","approx":{"value":3.59199457,"atol":1e-7}}
//|       - {"artifact":"check","path":"/rows/0/3","range":{"min":-1e-8,"max":1e-8}}
//|   - case: hf-cold
//|     expect:
//|       - {"artifact":"check","path":"/rows/0/0","equals":"3 項の和"}
//|       - {"artifact":"check","path":"/rows/0/3","range":{"min":-1e-11,"max":1e-11}}
//|       - {"artifact":"sums","path":"/rows/0/5","equals":null}
//|   - case: ground-reference
//|     expect:
//|       - {"artifact":"sums","path":"/rows/0/2","equals":0}
//|       - {"artifact":"sums","path":"/rows/0/5","approx":{"value":3.5919945733209,"rtol":1e-12}}
//|       - {"artifact":"check","path":"/rows/0/3","range":{"min":-1e-8,"max":1e-8}}
//|   - case: hcl-hot
//|     expect:
//|       - {"artifact":"check","path":"/rows/0/0","equals":"Mulholland の展開"}
//|       - {"artifact":"check","path":"/rows/0/3","range":{"min":-1e-8,"max":1e-8}}
use scioxide_core::{RealScalar, logsumexp, weighted_logsumexp};

let (theta, d0_ev) = molecule_constants(&molecule);
let t = RealScalar::powf(10.0_f64, log_t);
// 解離極限を基準にすると、全準位の指数に D₀ / k_B T が加わる（k_B = 8.617333e-5 eV/K）。
let shift = if include_d0 {
    d0_ev / (8.617333e-5 * t)
} else {
    0.0
};
let energy = reduced_energies(theta, t);
let degeneracy = degeneracies(energy.len());
// 指数 v_J = D₀ / k_B T − θ J(J+1)/T。
let logits: Vec<f64> = energy.iter().map(|e| shift - e).collect();

// 重み g_J と指数 v_J を分けて渡す。
let ln_q = weighted_logsumexp(&logits, &degeneracy)
    .map_err(|e| e.to_string())?
    .log_magnitude()
    .ok_or("和が 0 になった")?;
// 重みを対数にして指数にまとめる。
let combined: Vec<f64> = logits
    .iter()
    .zip(&degeneracy)
    .map(|(&v, &g)| v + RealScalar::ln(g))
    .collect();
let ln_q_combined = logsumexp(&combined).map_err(|e| e.to_string())?;
// 比較用: 指数をそのまま足す（f64 の固有メソッド）。有限でなければ None。
let direct: f64 = logits
    .iter()
    .zip(&degeneracy)
    .map(|(v, g)| g * v.exp())
    .sum::<f64>()
    .ln();
let direct = RealScalar::is_finite(direct).then_some(direct);

let fixed4 = serde_json::json!({ "fractionDigits": 4 });
let digits = serde_json::json!({ "significantDigits": 15 });
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let lost = "有限でない";
let sum_columns = serde_json::json!([
    { "key": "0", "label": "温度 T [K]", "type": "number", "format": fixed1 },
    { "key": "1", "label": "打ち切りの準位 J [-]", "type": "integer" },
    { "key": "2", "label": "移動 D₀ / k_B T [-]", "type": "number", "format": fixed4 },
    { "key": "3", "label": "ln q'（weighted_logsumexp）[-]", "type": "number", "format": digits },
    { "key": "4", "label": "ln q'（v + ln g の logsumexp）[-]", "type": "number", "format": digits },
    { "key": "5", "label": "そのまま足した ln q' [-]", "type": "number", "format": digits, "nullText": lost }
]);
emit_table_with_columns!(
    sum_columns,
    vec![(t, energy.len() - 1, shift, ln_q, ln_q_combined, direct)],
    metadata = serde_json::json!({ "id": "sums" })
);

// 独立な参照値（f64 の固有メソッド）。x = θ_rot / T。
let x = theta / t;
let (name, reference) = if t > theta {
    let series = 1.0 + x / 3.0 + x * x / 15.0 + 4.0 * x.powi(3) / 315.0;
    ("Mulholland の展開", (series / x).ln())
} else {
    let terms = 1.0 + 3.0 * (-2.0 * x).exp() + 5.0 * (-6.0 * x).exp();
    ("3 項の和", terms.ln())
};
let check_columns = serde_json::json!([
    { "key": "0", "label": "参照値の種類" },
    { "key": "1", "label": "ln q = ln q' − D₀ / k_B T [-]", "type": "number", "format": digits },
    { "key": "2", "label": "参照値 [-]", "type": "number", "format": digits },
    { "key": "3", "label": "差 [-]", "type": "number", "format": sci3 }
]);
emit_table_with_columns!(
    check_columns,
    vec![(name, ln_q - shift, reference, (ln_q - shift) - reference)],
    metadata = serde_json::json!({ "id": "check" })
);
```

既定値（CO、$T = 100$ K、解離極限を基準）では、$\ln q' \approx 1290.533$ で、指数をそのまま足した値は有限でなくなる。
`weighted_logsumexp` と `logsumexp` の値は表示の桁まで一致する。
移動を除いた $\ln q \approx 3.59199$ は Mulholland の展開と $1.9 \times 10^{-9}$ の差で一致し、この差は展開の次の項 $x^4/315 \approx 1.9 \times 10^{-9}$（$x = 0.0278$）にあたる。
基底準位を基準にすると移動は 0 で、そのままの和も同じ $\ln q$ を与える。

HF を $T = 10$ K（$\log_{10} T = 1$）にすると $T < \theta_{\mathrm{rot}}$ となり、参照値は 3 項の和に切り替わる。
この温度では $J \ge 3$ の寄与が $10^{-15}$ 程度しかないので、3 項の和はほぼ厳密である。
解離極限を基準にしたときの差は $4 \times 10^{-13}$ 程度で、$\ln q' \approx 6812$ の隣接する倍精度数の間隔（約 $9 \times 10^{-13}$）の範囲にある。
この差は、$\ln q'$ の丸めが移動を引いたあとの小さな $\ln q \approx 0.0071$ に残ったものである。
HCl の $T = 1000$ K では移動が約 51 と小さいので、そのままの和も有限で、対数和と一致する。

## 占有確率と内部エネルギー

次のセルは $v_J + \ln g_J$ を `softmax_into` で正規化して $p_J$ を求め、`checked_sum` で $\sum_J p_J$ を、`checked_sum_of_products` で $U / k_B T = \sum_J p_J\, \theta_{\mathrm{rot}} J(J+1)/T$ を計算する。
入力は分子と温度 $T$ [K] の常用対数である。
解離極限の移動 $D_0 / k_B T$ を加えても $p_J$ は変わらないので、このセルでは加えない。

1 つ目の表は確率の和と、$U / k_B T$ を参照値と比べた差を示す。
参照値は $T > \theta_{\mathrm{rot}}$ で展開 $1 - x/3 - x^2/45$、それ以下で $J \le 2$ の 3 準位だけの和である。
2 つ目の表は最頻の準位と、連続近似の予測 $\max(0, \sqrt{T/2\theta_{\mathrm{rot}}} - 1/2)$ を比べる。
グラフは $J = 0$ から 40 までの $p_J$ を描き、連続近似による最頻の準位を縦線で示す。

```rust
//| id: core-rotational-populations
//| ref: core-rotational-populations
//| title: 回転準位の占有確率と内部エネルギー
//| run: reactive
//| uses: [core-rotational-model]
//| crates: [scioxide-core]
//| inputs:
//|   molecule: {"type":"select","label":"分子","options":["CO","HCl","HF"],"value":"CO"}
//|   log_t: {"type":"range","label":"温度 log₁₀(T / K)","description":"0 は 1 K、2 は 100 K、3.5 は約 3162 K。","min":0,"max":3.5,"step":0.1,"value":2}

//|   - {"id":"hf-cold","label":"HF、10 K","description":"ほぼ全分子が J = 0 にあり、回転の励起が凍結している。","inputs":{"molecule":"HF","log_t":1}}

//|       - {"artifact":"energy","path":"/rows/0/0","approx":{"value":1,"atol":5e-16}}

//|       - {"artifact":"mode","path":"/rows/0/0","equals":0}

    { "key": "0", "label": "最頻の準位 J [-]", "type": "integer" },
    { "key": "1", "label": "その確率 p_J [-]", "type": "number", "format": digits4 },
    { "key": "2", "label": "連続近似の最頻 J* [-]", "type": "number", "format": fixed2 }
]);
emit_table_with_columns!(
    mode_columns,
    vec![(mode, p_mode, j_star)],
    metadata = serde_json::json!({ "id": "mode" })

let points: Vec<[f64; 2]> = population
    .iter()
    .take(41)
    .enumerate()
    .map(|(j, &p)| [j as f64, p])

emit_line_chart!(

    options = &serde_json::json!({
        "xLabel": "回転量子数 J [-]",
        "yLabel": "占有確率 p_J [-]",
        "annotations": [{ "kind": "line", "axis": "x", "value": j_star, "label": "連続近似の最頻 J*" }]
```

既定値（CO、$T = 100$ K）では $x \approx 0.028$ で、$U / k_B T \approx 0.99072$ が展開 $1 - x/3 - x^2/45$ と $2 \times 10^{-7}$ の差で一致する。
確率の和は `f64` の 1 に等しい。
最頻の準位は $J = 4$（$p_4 \approx 0.142$）で、連続近似の $3.74$ に最も近い整数である。

CO を $T = 1000$ K にすると最頻の準位は $J = 13$（連続近似は $12.91$）に上がり、$U / k_B T \approx 0.99907$ は等分配則の値 1 に近づく。
HF の $T = 10$ K では分子の $99.3\,\%$ が $J = 0$ にあり、$U / k_B T \approx 0.043$ まで下がる（回転の励起が凍結される）。
切り替わる $T \approx \theta_{\mathrm{rot}}$ の近くでは参照値の側の誤差が大きく、展開の側で $2 \times 10^{-2}$ 程度、3 項の和の側で $10^{-4}$ 程度の差が残る。

## まとめ

エネルギーの基準を移すと指数の値は大きく変わるが、対数和と正規化では移動は $\ln q$ に足されるだけで、占有確率は変わらない。
重みのある和は `weighted_logsumexp`、確率は `softmax_into` で求め、確率の和や期待値は `checked_sum` と `checked_sum_of_products` で一度の丸めで評価できる。
分配関数と内部エネルギーは高温では Mulholland の展開と、低温では最初の数項の和と照合でき、最頻の準位は連続近似と照合できる。
