量子力学では、ポテンシャルの外側に染み出す波動関数の裾がトンネル効果を決める。
裾の値そのものは倍精度で表せる大きさでも、ノルムを計算するために二乗すると 0 に丸められることがある。
逆に、打ち込み法（shooting method）で現れる増大解では、二乗がオーバーフローする。
この例題では標本化した波動関数のノルムを `checked_scaled_norm` で求め、二つに分けて累積した `ScaledNorm` のマージと、対数和による参照値で確かめる。

## 調和振動子の裾と増大解

質量 $m$、角振動数 $\omega$ の調和振動子で、長さの単位 $x_0 = \sqrt{\hbar/(m\omega)}$ による無次元座標 $\xi = x/x_0$ を使うと、基底状態は

$$
\psi_0(\xi) = \pi^{-1/4}\, e^{-\xi^2/2}
$$

である。
古典的な転回点 $\xi = 1$ より外側では、波動関数はガウス関数として減衰する。
大きな $\xi$ では、シュレーディンガー方程式の解は近似的に

$$
\psi(\xi) \approx c_1\, e^{-\xi^2/2} + c_2\, e^{+\xi^2/2}
$$

と書け、打ち込み法で固有値を探す途中の解には増大する成分 $e^{+\xi^2/2}$ が含まれる。
以下では定数倍を除いた $\psi = e^{\mp \xi^2/2}$ を区間 $[a, a+2]$ で $N$ 点標本化し、ベクトル $\boldsymbol{\psi}$ のノルム $\lVert \boldsymbol{\psi} \rVert_2 = \sqrt{\sum_k \psi_k^2}$ を求める。
$\xi$ と $\psi$ はどちらも無次元である。

## そのまま計算したときの失敗

`f64` の正規化数の最大は約 $1.8 \times 10^{308} \approx e^{709.8}$、最小の非正規化数は $4.9 \times 10^{-324} \approx e^{-744.4}$ である。
二乗の和 $\sum_k \psi_k^2$ をそのまま計算すると、次の三つの場合に失敗する。

減衰解では、$\xi = 28$ で $\psi = e^{-392} \approx 6 \times 10^{-171}$ は正規化数として表せるが、$\psi^2 = e^{-784}$ は最小の非正規化数より小さく 0 になる。
$\xi > 27.3$ の標本だけからなるウインドウでは、$\sum_k \psi_k^2$ とともにノルムも 0 に落ちる。

増大解では、$\xi = 27$ で $\psi = e^{364.5} \approx 2 \times 10^{158}$ は表せるが、$\psi^2 \approx 4 \times 10^{316}$ は最大値を超えて `inf` に達する。

$\xi > 37.7$ では、成分 $e^{\mp\xi^2/2}$ そのものが倍精度の正規化数の範囲を出る。
増大解は `inf` になり、減衰解は非正規化数になって有効桁を失い、$\xi > 38.6$ で 0 になる。
この先は値を対数で持つ必要があるので、以下ではウインドウを $a \le 35$（$\xi \le 37$）に限る。

## 尺度化ノルムと参照値

`checked_scaled_norm` は尺度 $s$（それまでの最大の絶対値）と、各成分を $s$ で割った比の二乗和 $q$ を保持し、$\lVert \boldsymbol{\psi} \rVert_2 = s\sqrt{q}$ とする。
比は 1 以下なので、二乗がオーバーフローすることはない。
最大成分に比べて小さい成分の比の二乗はアンダーフローしうるが、$q \ge 1$ に対して無視できる大きさである。
0 でない成分の数を $m$、$k = 8m + 8$、$u = \varepsilon/2$ とすると、$ku < 1$ のもとで絶対誤差は $\gamma_k \lVert \boldsymbol{\psi} \rVert_2 + \eta/2$ 以下である（$\gamma_k = ku/(1 - ku)$、$\eta$ は最小の非正規化数）。
ノルムが正規化数の範囲にあれば、これは相対誤差 $\gamma_k$ 以下ということで、$m = 64$ では $\gamma_{520} \approx 5.8 \times 10^{-14}$ になる（[厳密累積と範囲安全な算術](../../algorithms/range-safe-arithmetic/)）。

`ScaledNorm` は同じ状態を逐次に作る型で、二つの状態 $(s_1, q_1)$、$(s_2, q_2)$ を `merge` でマージできる。
マージは $s = \max(s_1, s_2)$ として $q = q_1 (s_1/s)^2 + q_2 (s_2/s)^2$ を計算するのと同じ意味である。
マージも誤差限界の $m$ に一回として数える。

成分が表せてもノルムが倍精度の範囲を超える場合、`finish()` は `NumericalInstability`（`Overflow`）を返す。
そのときは `scale()` と `sum_squares()` を取り出し、拡張範囲値 `Scaled` の積 $s \cdot \sqrt{q}$ を作って `ln_abs()` で $\ln \lVert \boldsymbol{\psi} \rVert_2$ を得られる。
この例題のウインドウではノルムは範囲内に収まる。

独立な参照値は、成分の対数 $e_k = \mp \xi_k^2/2$ が分かっていることを使って

$$
\ln \lVert \boldsymbol{\psi} \rVert_2 = \frac{1}{2} \ln \sum_k e^{2 e_k} = \frac{1}{2} \operatorname{LSE}(2e_1, \ldots, 2e_N)
$$

を `logsumexp` で求める。
指数を一度も作らないので、倍精度の範囲に関係なく計算でき、結果は LSE の値の 16 ULP 以内である。
$\ln \lVert \boldsymbol{\psi} \rVert_2$ の差は、ノルムの相対差に近似的に等しい。

2 つのセルは次の定義を共有する。
`tail_exponents` は選んだ解の成分の対数 $e_k = \mp \xi_k^2/2$ を区間 $[a, a+2]$ の等間隔の点で返し、`naive_norm` は二乗の和の平方根をそのまま計算し、`gamma` は誤差限界 $\gamma_{8m+8}$ を返す。

```rust
//| id: core-wavefunction-tail-model
//| kind: definitions
//| title: 裾の標本と誤差限界
//| crates: [scioxide-core]
/// 成分の対数 e_k = ∓ξ_k²/2。ξ_k は区間 [start, start + 2] の等間隔の count 点（count ≥ 2）。
pub(crate) fn tail_exponents(mode: &str, start: f64, count: usize) -> Vec<f64> {
    let sign = if mode.starts_with("減衰") {
        -1.0
    } else {
        1.0
    };
    (0..count)
        .map(|k| {
            let xi = start + 2.0 * k as f64 / (count - 1) as f64;
            sign * 0.5 * xi * xi
        })
        .collect()
}

/// 比較用: 二乗の和の平方根を f64 の演算と固有メソッドでそのまま計算する。
pub(crate) fn naive_norm(psi: &[f64]) -> f64 {
    psi.iter().map(|v| v * v).sum::<f64>().sqrt()
}

/// 誤差限界 γ_k = ku/(1 − ku)、k = 8m + 8、u = ε/2（m は 0 でない成分とマージの数）。
pub(crate) fn gamma(m: usize) -> f64 {
    let ku = (8 * m + 8) as f64 * f64::EPSILON / 2.0;
    ku / (1.0 - ku)
}
```

## 一つのウインドウでのノルム

次のセルは選んだウインドウで、そのままの計算、`checked_scaled_norm`、前半と後半に分けて累積して `merge` した `ScaledNorm` の三つで $\ln \lVert \boldsymbol{\psi} \rVert_2$ を求め、参照値と比べる。
入力はウインドウの開始位置 $a$、解の種類、標本点の数 $N$ である。
成分 $\psi_k$ と対数は `RealScalar::exp`、`RealScalar::ln` で計算し、そのままの計算だけを `f64` の演算と固有メソッドで行う。
表は方法ごとのノルム、その対数、参照値 $\operatorname{LSE}(2e)/2$ との差、相対誤差の限界 $\gamma_k$ を示す。
0 や無限大の対数のように有限でない値は「有限でない」と表示する。

```rust
//| id: core-wavefunction-tail-norms
//| ref: core-wavefunction-tail-norms
//| title: 波動関数の裾を標本化したベクトルのノルム
//| run: reactive
//| uses: [core-wavefunction-tail-model]
//| crates: [scioxide-core]
//| inputs:
//|   window_start: {"type":"range","label":"ウインドウの開始位置 a（ξ）[-]","description":"区間 [a, a + 2] で標本化する。","min":0,"max":35,"step":1,"value":28}
//|   mode: {"type":"select","label":"解","options":["減衰解 exp(-ξ²/2)","増大解 exp(+ξ²/2)"],"value":"減衰解 exp(-ξ²/2)"}
//|   sample_count: {"type":"range","label":"標本点の数 N","description":"区間内の等間隔の点数。","min":16,"max":256,"step":16,"value":64}
//| cases:
//|   - {"id":"growing","label":"増大解、a = 27","description":"二乗がオーバーフローし、そのままの計算は有限でなくなる。","inputs":{"window_start":27,"mode":"増大解 exp(+ξ²/2)"}}
//|   - {"id":"subnormal","label":"減衰解、a = 27","description":"二乗が非正規化数になり、そのままの計算は有効桁を失う。","inputs":{"window_start":27}}
//|   - {"id":"in-range","label":"減衰解、a = 10、N = 256","description":"二乗が範囲に収まり、3 つの方法が一致する。","inputs":{"window_start":10,"sample_count":256}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"norms","path":"/rows/0/1","equals":0}
//|       - {"artifact":"norms","path":"/rows/0/2","equals":null}
//|       - {"artifact":"norms","path":"/rows/1/2","approx":{"value":-391.9075731605,"rtol":1e-12}}
//|       - {"artifact":"norms","path":"/rows/1/4","range":{"min":-1.2e-13,"max":1.2e-13}}
//|       - {"artifact":"norms","path":"/rows/2/4","range":{"min":-1.2e-13,"max":1.2e-13}}
//|       - {"artifact":"norms","path":"/rows/1/5","approx":{"value":5.77e-14,"rtol":1e-2}}
//|   - case: growing
//|     expect:
//|       - {"artifact":"norms","path":"/rows/0/1","equals":null}
//|       - {"artifact":"norms","path":"/rows/1/2","approx":{"value":420.5864845297,"rtol":1e-12}}
//|       - {"artifact":"norms","path":"/rows/2/4","range":{"min":-1.2e-13,"max":1.2e-13}}
//|   - case: subnormal
//|     expect:
//|       - {"artifact":"norms","path":"/rows/0/4","range":{"min":-1e-6,"max":-1e-9}}
//|       - {"artifact":"norms","path":"/rows/1/4","range":{"min":-1.2e-13,"max":1.2e-13}}
//|   - case: in-range
//|     expect:
//|       - {"artifact":"norms","path":"/rows/0/4","range":{"min":-1e-13,"max":1e-13}}
//|       - {"artifact":"norms","path":"/rows/1/4","range":{"min":-1e-13,"max":1e-13}}
use scioxide_core::{RealScalar, ScaledNorm, checked_scaled_norm, logsumexp};

let n = sample_count as usize;
let exponents = tail_exponents(&mode, window_start, n);
let psi: Vec<f64> = exponents.iter().map(|&e| RealScalar::exp(e)).collect();

// 参照値: ln‖ψ‖ = LSE(2 e_k) / 2。指数を作らない。
let doubled: Vec<f64> = exponents.iter().map(|e| 2.0 * e).collect();
let reference = 0.5 * logsumexp(&doubled).map_err(|e| e.to_string())?;

let naive = naive_norm(&psi);
let checked = checked_scaled_norm(&psi).map_err(|e| e.to_string())?;
// 前半と後半を別々に累積してマージしる。
let (mut first, mut second) = (ScaledNorm::new(), ScaledNorm::new());
for &v in &psi[..n / 2] {
    first.add(v).map_err(|e| e.to_string())?;
}
for &v in &psi[n / 2..] {
    second.add(v).map_err(|e| e.to_string())?;
}
first.merge(second).map_err(|e| e.to_string())?;
let merged = first.finish().map_err(|e| e.to_string())?;

// m は 0 でない成分の数。マージは m に 1 を足す。
let m = psi.iter().filter(|&&v| v != 0.0).count();
let finite = |v: f64| RealScalar::is_finite(v).then_some(v);
let row = |name: &'static str, norm: f64, bound: Option<f64>| {
    let log = finite(RealScalar::ln(norm));
    let difference = log.map(|value| value - reference);
    (name, finite(norm), log, reference, difference, bound)
};
let sci6 = serde_json::json!({ "notation": "scientific", "significantDigits": 6 });
let digits = serde_json::json!({ "significantDigits": 13 });
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let lost = "有限でない";
let columns = serde_json::json!([
    { "key": "0", "label": "方法" },
    { "key": "1", "label": "‖ψ‖₂ [-]", "type": "number", "format": sci6, "nullText": lost },
    { "key": "2", "label": "ln ‖ψ‖₂ [-]", "type": "number", "format": digits, "nullText": lost },
    { "key": "3", "label": "参照値 LSE(2e)/2 [-]", "type": "number", "format": digits },
    { "key": "4", "label": "参照値との差 [-]", "type": "number", "format": sci2, "nullText": lost },
    { "key": "5", "label": "相対誤差の限界 γ_k [-]", "type": "number", "format": sci2, "nullText": "なし" }
]);
emit_table_with_columns!(
    columns,
    vec![
        row("そのまま", naive, None),
        row("checked_scaled_norm", checked, Some(gamma(m))),
        row("ScaledNorm を merge", merged, Some(gamma(m + 1))),
    ],
    metadata = serde_json::json!({ "id": "norms" })
);
```

既定値（減衰解、$a = 28$、$N = 64$）ではそのままの計算が 0（対数は $-\infty$）になる。
`checked_scaled_norm` と `merge` した結果は $\ln \lVert \boldsymbol{\psi} \rVert_2 = -391.9075731605$ で、参照値と表示の桁まで一致する。
増大解で $a = 27$ にすると、そのままの計算は無限大になり、尺度化した 2 つの結果は参照値 $420.5864845297$ と表示の桁まで一致する。
減衰解の $a = 27$ では、そのままの計算は 0 にならないが、二乗が非正規化数になって有効桁を失い、対数が $4.5 \times 10^{-8}$ だけ小さくなる。
減衰解の $a = 10$、$N = 256$ のように二乗が範囲に収まるウインドウでは、そのままの計算も尺度化した結果と丸めの範囲で一致する。

`f64` で表した対数 $\ln \lVert \boldsymbol{\psi} \rVert_2 \approx -392$ の 1 ULP は $5.7 \times 10^{-14}$ なので、対数の差が 1 ULP 以内であることは、ノルムの相対差がこの程度以下であることを意味する。
これは相対誤差の限界 $\gamma_{520} \approx 5.8 \times 10^{-14}$ と同じ大きさで、表の差からそれ以上細かく誤差を読み取ることはできない。

## ウインドウの位置による変化

次のセルは $a = 0, 1, \ldots, 35$ の 36 個のウインドウについて、32 点で標本化した $\lVert \boldsymbol{\psi} \rVert_2$ をそのままの計算と `checked_scaled_norm` で求め、対数軸に描く。
入力は解の種類である。
そのままの計算が 0 や無限大になったウインドウは対数軸に描けないので系列から除き、その数を表に示す。
表には各ウインドウの `checked_scaled_norm` と参照値 $\exp(\operatorname{LSE}(2e)/2)$ の相対差の最大と、32 点のウインドウの限界 $\gamma_{264}$ も示す。

```rust
//| id: core-wavefunction-tail-sweep
//| ref: core-wavefunction-tail-sweep
//| title: ウインドウの位置とノルム
//| run: reactive
//| uses: [core-wavefunction-tail-model]
//| crates: [scioxide-core]
//| inputs:
//|   mode: {"type":"select","label":"解","options":["減衰解 exp(-ξ²/2)","増大解 exp(+ξ²/2)"],"value":"増大解 exp(+ξ²/2)"}
//| cases:
//|   - {"id":"decaying","label":"減衰解","description":"そのままの計算は a = 27 を最後に 0 になり、8 個のウインドウが除かれる。","inputs":{"mode":"減衰解 exp(-ξ²/2)"}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"summary","path":"/rows/0/0","equals":11}
//|       - {"artifact":"summary","path":"/rows/0/1","equals":36}
//|       - {"artifact":"summary","path":"/rows/0/2","range":{"min":0,"max":1.5e-13}}
//|       - {"artifact":"summary","path":"/rows/0/3","approx":{"value":2.93e-14,"rtol":1e-2}}
//|   - case: decaying
//|     expect:
//|       - {"artifact":"summary","path":"/rows/0/0","equals":8}
//|       - {"artifact":"summary","path":"/rows/0/2","range":{"min":0,"max":1.5e-13}}
use scioxide_core::{RealScalar, checked_scaled_norm, logsumexp};

let (mut naive_curve, mut scaled_curve) = (Vec::new(), Vec::new());
let (mut naive_lost, mut worst) = (0_u32, 0.0_f64);
for a in 0..=35 {
    let start = f64::from(a);
    let exponents = tail_exponents(&mode, start, 32);
    let psi: Vec<f64> = exponents.iter().map(|&e| RealScalar::exp(e)).collect();
    let naive = naive_norm(&psi);
    if naive > 0.0 && RealScalar::is_finite(naive) {
        naive_curve.push([start, naive]);
    } else {
        naive_lost += 1;
    }
    let scaled = checked_scaled_norm(&psi).map_err(|e| e.to_string())?;
    scaled_curve.push([start, scaled]);
    // 参照値 exp(LSE(2e)/2)。この範囲ではノルムは f64 で表せる。
    let doubled: Vec<f64> = exponents.iter().map(|e| 2.0 * e).collect();
    let reference = RealScalar::exp(0.5 * logsumexp(&doubled).map_err(|e| e.to_string())?);
    worst = worst.max(((scaled - reference) / reference).abs());
}
emit_line_chart!(
    &vec![
        serde_json::json!({ "name": "そのまま計算", "points": naive_curve }),
        serde_json::json!({ "name": "checked_scaled_norm", "points": scaled_curve }),
    ],
    options = &serde_json::json!({
        "xLabel": "ウインドウの開始位置 a（ξ）[-]",
        "yLabel": "ノルム ‖ψ‖₂ [-]",
        "yType": "log",
        "xMin": 0.0,
        "xMax": 35.0
    })
);
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let columns = serde_json::json!([
    { "key": "0", "label": "そのままの計算が 0 または無限大になったウインドウ [個]", "type": "integer" },
    { "key": "1", "label": "ウインドウの数 [個]", "type": "integer" },
    { "key": "2", "label": "参照値との相対差の最大 [-]", "type": "number", "format": sci2 },
    { "key": "3", "label": "限界 γ₂₆₄ [-]", "type": "number", "format": sci2 }
]);
emit_table_with_columns!(
    columns,
    vec![(naive_lost, 36_u32, worst, gamma(32))],
    metadata = serde_json::json!({ "id": "summary" })
);
```

ノルムは増大解で約 17 から $1.9 \times 10^{297}$ まで、減衰解で約 3.8 から $9.9 \times 10^{-267}$ までにわたり、対数はほぼ放物線に沿い、増大解では $\ln \lVert \boldsymbol{\psi} \rVert_2 \approx (a + 2)^2/2$、減衰解では $\approx -a^2/2$ である（どちらもウインドウの中で絶対値が最大になる端の成分の対数）。
増大解では、そのままの計算の系列が $a = 24$ を最後に途切れ、36 個中 11 個のウインドウが除かれる。
減衰解では $a = 27$ を最後に途切れ、8 個のウインドウが除かれる。
`checked_scaled_norm` の系列はどちらの解でも $a = 35$ まで続く。

参照値との相対差の最大は増大解で $5.1 \times 10^{-14}$、減衰解で $5.3 \times 10^{-14}$ である。
32 点のウインドウの限界 $\gamma_{264} \approx 2.9 \times 10^{-14}$ より大きいが、この差には参照値の誤差も入っている。
参照値 $\exp(\operatorname{LSE}/2)$ では、引数 $\operatorname{LSE}/2$ の絶対誤差がそのまま相対誤差になる。
$|\operatorname{LSE}/2| \approx 600$ のウインドウでは、引数を `f64` に丸めるだけで最大 $5.7 \times 10^{-14}$ の相対誤差が入るので、$5 \times 10^{-14}$ 程度の差はどちらの誤差かを決めない。

## まとめ

成分が倍精度で表せても、ノルムを計算するための二乗は範囲を出ることがあり、そのままの計算は 0 や `inf` を返す。
`checked_scaled_norm` と `ScaledNorm` は尺度と比の二乗和で計算するので、ノルムが表せる限り二乗の範囲に影響されず、分けて累積した状態も `merge` でマージできる。
ノルムが正規化数の範囲にあれば相対誤差は $\gamma_{8m+8}$ 以下である。
1 つのウインドウの表では対数の差がこの限界の内側にあり、ウインドウを動かした表の相対差（約 $5 \times 10^{-14}$）は参照値の丸め誤差と区別できない大きさである。
ノルム自体が範囲外なら `NumericalInstability` を受け取り、`scale()` と `sum_squares()` から `Scaled` を作って対数を得る。
成分そのものが 0 に丸められる領域では、値を対数で持つ設計（`LogValue` や対数の配列）が必要になる。
