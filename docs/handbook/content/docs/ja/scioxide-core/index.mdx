`scioxide-core` は方程式を解くクレートではなく、他のすべてのクレートが同じ前提で計算するための型と規則を定める最下層のクレートである。
許容誤差をどう判定するか、変数の範囲をどう表すか、途中の値の桁あふれをどう避けるか、反復や評価をどう数えて制限するか、並列化や停止をどう指定するかを、ここで一度だけ定義する。
数値微分は [scioxide-differentiate](../scioxide-differentiate/algorithms/)、自動微分は [scioxide-ad](../scioxide-ad/)、行列の分解と反復解法は [scioxide-linalg](../scioxide-linalg/) と [scioxide-sparse](../scioxide-sparse/) が提供し、いずれもこの章の型を使う。

## 最初の計算：許容誤差の判定

反復をいつ止めるか、結果をいつ受理するかを決める基本の型が `Tolerance` である。
`Tolerance` は絶対許容誤差 $\tau_{\mathrm{abs}}$ と相対許容誤差 $\tau_{\mathrm{rel}}$ の組で、大きさ $m \ge 0$ の量を代表スケール $s \ge 0$ のもとで

$$
m \le \tau(s) = \tau_{\mathrm{abs}} + \tau_{\mathrm{rel}}\, s
$$

のとき受理する。
$\tau_{\mathrm{abs}}$ は判定する量と同じ単位を持ち、$\tau_{\mathrm{rel}}$ は無次元である。
二つの項が等しくなる $s_\times = \tau_{\mathrm{abs}} / \tau_{\mathrm{rel}}$ より小さい $s$ では絶対項が、大きい $s$ では相対項がしきい値の大半を占める。

`Tolerance::new(absolute, relative)` は負の値を `InvalidInput`、NaN と無限大を `NonFinite` として拒否する。
`threshold(scale)` は $\tau(s)$ を返す。
`is_residual_ok(residual_norm, problem_scale)` は残差 $r$ が $r \le \tau(s)$ を満たすかを返し、満たさない場合はエラーではなく `Ok(false)` を返す。

次のセルは $\tau_{\mathrm{abs}}$、$\tau_{\mathrm{rel}}$、代表スケール $s$、残差 $r$ を入力とし、しきい値、交点スケール $s_\times$、余裕 $\tau(s) - r$、判定を 1 行の表にする。
四つの入力はどれも無次元の例として扱い、$s$ と $r$ は 0 以上、二つの許容誤差は正の範囲で動かす。
確かめるのは、`threshold` の値が式 $\tau_{\mathrm{abs}} + \tau_{\mathrm{rel}} s$ と一致することと、判定が余裕の符号と一致することである。

```rust
//| id: core-first-contract
//| ref: core-first-contract
//| title: 許容誤差のしきい値と残差の判定
//| run: reactive
//| crates: [scioxide-core]
//| inputs:
//|   abs_tol: {"type":"range","label":"絶対許容誤差 τ_abs [-]","description":"判定する量と同じ単位。","min":0.001,"max":0.05,"step":0.001,"value":0.01}
//|   rel_tol: {"type":"range","label":"相対許容誤差 τ_rel [-]","description":"無次元。","min":0.001,"max":0.05,"step":0.001,"value":0.02}
//|   scale: {"type":"range","label":"代表スケール s [-]","description":"0 以上。","min":0,"max":10,"step":0.5,"value":2}
//|   residual: {"type":"range","label":"残差 r [-]","description":"0 以上。","min":0,"max":0.15,"step":0.005,"value":0.04}
//| cases:
//|   - {"id":"rejected","label":"r = 0.06","description":"残差がしきい値 0.05 を超え、判定は false になる。","inputs":{"residual":0.06}}
//|   - {"id":"zero-scale","label":"s = 0","description":"相対項が消え、しきい値は τ_abs だけになる。","inputs":{"scale":0}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"decision","path":"/rows/0/0","approx":{"value":0.05,"rtol":1e-12}}
//|       - {"artifact":"decision","path":"/rows/0/1","approx":{"value":0.5,"rtol":1e-12}}
//|       - {"artifact":"decision","path":"/rows/0/3","approx":{"value":0.01,"atol":1e-12}}
//|       - {"artifact":"decision","path":"/rows/0/4","equals":"true"}
//|   - case: rejected
//|     expect:
//|       - {"artifact":"decision","path":"/rows/0/3","approx":{"value":-0.01,"atol":1e-12}}
//|       - {"artifact":"decision","path":"/rows/0/4","equals":"false"}
//|   - case: zero-scale
//|     expect:
//|       - {"artifact":"decision","path":"/rows/0/0","approx":{"value":0.01,"rtol":1e-12}}
//|       - {"artifact":"decision","path":"/rows/0/4","equals":"false"}
use scioxide_core::Tolerance;

let tolerance = Tolerance::new(abs_tol, rel_tol).map_err(|e| e.to_string())?;
let threshold = tolerance.threshold(scale).map_err(|e| e.to_string())?;
let accepted = tolerance
    .is_residual_ok(residual, scale)
    .map_err(|e| e.to_string())?;

let fixed4 = serde_json::json!({ "fractionDigits": 4 });
let columns = serde_json::json!([
    { "key": "0", "label": "しきい値 τ(s) [-]", "type": "number", "format": fixed4 },
    { "key": "1", "label": "交点スケール s× [-]", "type": "number", "format": fixed4 },
    { "key": "2", "label": "残差 r [-]", "type": "number", "format": fixed4 },
    { "key": "3", "label": "余裕 τ(s) − r [-]", "type": "number", "format": fixed4 },
    { "key": "4", "label": "is_residual_ok(r, s)" }
]);
emit_table_with_columns!(
    columns,
    vec![(
        threshold,
        abs_tol / rel_tol,
        residual,
        threshold - residual,
        accepted.to_string(),
    )],
    metadata = serde_json::json!({ "id": "decision" })
);
```

既定値では $\tau(2) = 0.01 + 0.02 \times 2 = 0.05$ で、残差 $0.04$ は余裕 $0.01$ で受理される。
交点スケールは $s_\times = 0.01 / 0.02 = 0.5$ なので、$s = 2$ ではしきい値の 8 割を相対項が占める。
残差を $0.06$ に上げると余裕が $-0.01$ になり、判定は `false` に変わる。
このとき `is_residual_ok` は `Ok(false)` を返し、セルはエラーにならない。
残差を $0.06$ にしたままスケールを $2.5$ 以上にすると、しきい値が $0.06$ 以上になって再び受理される。
$s = 0$ では相対項が消えてしきい値が $\tau_{\mathrm{abs}} = 0.01$ になり、残差 $0.04$ は受理されない。

## 結果の読み方

`scioxide-core` の関数は入力の誤りと数値的な失敗を `Result` のエラーとして返し、正当な入力に対する「満たさない」を `Ok(false)` などの値として返す。
エラーの型 `SciOxideError` は内部の表現を出力に反映しない。
分類（`InvalidInput`、`NonFinite`、`DomainError`、`NumericalInstability` など 20 種類）は `kind()` で、引数・数量・理由などの詳細は `view()` で読む。
分類ごとの詳細の読み方は[エラーの分類と詳細ビュー](algorithms/errors-and-diagnostic-views/)で扱う。

数値の精度は関数ごとに「一回の丸め」「$N$ ULP」「残差の限界」などの形で示される。
これらの種類の違いは[共通基盤の数理](algorithms/)にまとめてある。

## まとめ

`scioxide-core` は、許容誤差・定義域・上限・算術・実行の五つについて、他のクレートが共有する型と規則を定める。
しきい値は $\tau_{\mathrm{abs}} + \tau_{\mathrm{rel}} s$ で、しきい値を満たさないことは `Ok(false)`、入力の誤りは `Err` として区別される。
`Err` を受け取ったら、`kind()` で分類を確かめ、`view()` で引数や理由を読む。
途中の値の範囲や丸めが問題になる計算は、範囲安全な算術・拡張範囲値・対数和のどれかで書き直せる。
