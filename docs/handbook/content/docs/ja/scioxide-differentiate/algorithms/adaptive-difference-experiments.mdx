[Richardson 外挿と Ridders の方法](../richardson-and-ridders/) は、適応差分 `AdaptiveDifference` が Neville 型の表から推定誤差を作り、どの規則で止まるかを導出する。
このページは、その規則が実際の関数でどう働くかを 2 つの実験で確かめる。
1 つ目の実験は最大準位数と許容誤差を変え、`Ridders` と `Richardson` の終了理由、評価回数、推定誤差を参照値との差（実際の誤差）と比べる。
2 つ目の実験は関数にノイズを足し、適応差分が `RoundoffLimit` で止まる場合と、推定誤差が実際の誤差を下回る場合を示す。
推定誤差と丸めの下限の作り方は [推定誤差と丸めの下限](oxref:differentiate-error-estimate)、閾値と終了理由の規則は [刻みと停止の規則](oxref:differentiate-stopping-rules) にある。
記号は [アルゴリズムの共通仕様と構成](oxref:differentiate-notation) に従い、$\varepsilon = 2^{-52}$ は倍精度の計算機イプシロンである。

次のブロックは、このページの 2 つの実験のセルが使う定義である。
`smooth` が被微分関数 $f(x) = e^{\sin x}$、`smooth_derivative` が導関数の参照値 $f'(x) = \cos x \, e^{\sin x}$ である。
参照値は f64 の固有メソッドで計算し、被微分関数は SciOxide の `RealScalar` の関数で計算する。

```rust
//| id: differentiate-adaptive-experiment-model
//| kind: definitions
//| title: 被微分関数 e^{sin x} と導関数の参照値
//| crates: [scioxide-core]
use scioxide_core::{SciOxideError, RealScalar};

/// 被微分関数 f(x) = e^{sin x}。
pub(crate) fn smooth(t: f64) -> Result<f64, SciOxideError> {
    Ok(RealScalar::exp(RealScalar::sin(t)))
}

/// 参照値 f'(x) = cos x · e^{sin x}（f64 の固有メソッド）。
pub(crate) fn smooth_derivative(x: f64) -> f64 {
    x.cos() * x.sin().exp()
}
```

## 準位数と推定誤差の実測

次のセルは $f(x) = e^{\sin x}$ の一階導関数を、最大準位数 $L$ を 3 から 12 まで変えて 2 つの方法で計算する。
$L$ ごとに `with_max_levels` で設定を変えて一から計算し、終了理由、評価回数、推定誤差、参照値との差（実際の誤差）を記録する。
許容誤差 $\tau$ は絶対・相対の両方に使い、図の横線は評価点での閾値 $\tau (1 + \lvert f'(x_0) \rvert)$ である。
許容誤差を小さくすると収束せず、刻みを縮め続けたときの推定誤差と実際の誤差の振る舞いが見える。
表の行ごとに終了理由が違うので、終了理由は表の列で示す。

```rust
//| id: differentiate-extrapolation-levels
//| ref: differentiate-extrapolation-levels
//| title: 最大準位数による Ridders と Richardson の推定誤差と実際の誤差
//| run: reactive
//| uses: [differentiate-adaptive-experiment-model]
//| crates: [scioxide-core, scioxide-differentiate]
//| inputs:
//|   tolerance: {"type":"select","label":"許容誤差 τ（絶対・相対）","options":["√ε（既定）","1e-12","1e-15"],"value":"1e-12"}
//|   x0: {"type":"range","label":"評価点 x₀","min":-2.0,"max":2.0,"step":0.5,"value":0.5}
//| cases:
//|   - {"id":"library-default","label":"τ = √ε（ライブラリの既定）","description":"閾値が大きいので、どちらの方法も少ない準位で Converged になる。","inputs":{"tolerance":"√ε（既定）"}}
//|   - {"id":"unreachable","label":"τ = 10⁻¹⁵","description":"閾値が丸めの下限より小さく、Converged に達しない。","inputs":{"tolerance":"1e-15"}}
//|   - {"id":"estimate-below","label":"x₀ = −2","description":"Ridders の L = 5, 6 で、推定誤差が実際の誤差を下回る。","inputs":{"x0":-2.0}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"levels","path":"/rows/0/3","equals":7}
//|       - {"artifact":"levels","path":"/rows/5/2","equals":"Converged"}
//|       - {"artifact":"levels","path":"/rows/5/5","range":{"max":1e-12}}
//|       - {"artifact":"levels","path":"/rows/17/2","equals":"Converged"}
//|       - {"artifact":"levels","path":"/rows/17/3","equals":21}
//|   - case: library-default
//|     expect:
//|       - {"artifact":"levels","path":"/rows/9/2","equals":"Converged"}
//|       - {"artifact":"levels","path":"/rows/9/5","range":{"max":1.5e-8}}
//|   - case: unreachable
//|     expect:
//|       - {"artifact":"levels","path":"/rows/9/2","equals":"RoundoffLimit"}
//|       - {"artifact":"levels","path":"/rows/9/5","range":{"max":1e-13}}
//|   - case: estimate-below
//|     expect:
//|       - {"artifact":"levels","path":"/rows/2/4","approx":{"value":5.0006e-9,"rtol":1e-3}}
//|       - {"artifact":"levels","path":"/rows/2/5","approx":{"value":2.8392e-8,"rtol":1e-3}}
//|       - {"artifact":"levels","path":"/rows/5/2","equals":"Converged"}
use scioxide_core::{ErrorTolerance, NormSelection};
use scioxide_differentiate::{AdaptiveDifference, AdaptiveDifferenceMethod};

let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let tau = match tolerance.as_str() {
    "√ε（既定）" => f64::EPSILON.sqrt(),
    text => text.parse().map_err(|_| "許容誤差を読めない")?,
};
let base = AdaptiveDifference::default().with_tolerance(
    ErrorTolerance::scalar(tau, tau, NormSelection::Infinity).map_err(|e| e.to_string())?,
);
let exact = smooth_derivative(x0);
let mut rows = Vec::new();
let mut series = Vec::new();
let mut dropped = 0;
for (name, method) in [
    ("Ridders", AdaptiveDifferenceMethod::Ridders),
    ("Richardson", AdaptiveDifferenceMethod::Richardson),
] {
    let (mut estimated, mut actual) = (Vec::new(), Vec::new());
    for levels in 3..=12_usize {
        let adaptive = base.clone().with_method(method).with_max_levels(levels);
        let result = adaptive.derivative(smooth, x0).map_err(|e| e.to_string())?;
        let report = result.report();
        let value = result.values().ok_or("導関数が公開されない")?[0];
        let estimate = result.errors().ok_or("推定誤差が出力に反映されない")?[0];
        let error = (value - exact).abs();
        estimated.push([levels as f64, estimate]);
        // 実際の誤差が 0 の点は対数軸に描けないので数える。
        if error > 0.0 {
            actual.push([levels as f64, error]);
        } else {
            dropped += 1;
        }
        let termination = report.termination().to_string();
        rows.push((
            name,
            levels,
            termination,
            report.evaluations(),
            estimate,
            error,
        ));
    }
    let diamond = serde_json::json!({ "symbol": "diamond", "showSymbol": true });
    series
        .push(serde_json::json!({ "name": format!("{name} の推定誤差"), "points": estimated }));
    series.push(serde_json::json!({
        "name": format!("{name} の実際の誤差"),
        "points": actual,
        "style": diamond
    }));
}
let threshold = tau * (1.0 + exact.abs());
emit_line_chart!(
    &series,
    options = &serde_json::json!({
        "xLabel": "最大準位数 L [-]",
        "yLabel": "導関数の誤差 [-]",
        "yType": "log",
        "annotations": [{ "kind": "line", "axis": "y", "value": threshold, "label": "閾値" }]
    })
);
let columns = serde_json::json!([
    { "key": "0", "label": "方法" },
    { "key": "1", "label": "最大準位数 L", "type": "integer" },
    { "key": "2", "label": "終了理由" },
    { "key": "3", "label": "評価回数 [回]", "type": "integer" },
    { "key": "4", "label": "推定誤差 [-]", "type": "number", "format": sci3 },
    { "key": "5", "label": "実際の誤差 [-]", "type": "number", "format": sci3 }
]);
let caption = format!("実際の誤差が 0 の {dropped} 点は図から除いた。");
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "levels", "caption": caption })
);
```

既定の入力（許容誤差 $10^{-12}$、$x_0 = 0.5$、閾値 $2.4 \times 10^{-12}$）では、$L$ が小さいうちは `RefinementLimit` で止まり、推定誤差と実際の誤差が $L$ とともに下がる。
`Ridders` は 7 準位目で推定誤差 $8.5 \times 10^{-13}$ が初めて閾値を下回り、続く 8 準位目で `Converged` になる（評価 $1 + 2 \times 8 = 17$ 回）。
$L$ をそれ以上増やしても、8 準位目で止まるので結果は同じである。
`Richardson` は列 1 だけを使うので誤差の次数は 4 のままで、誤差は準位ごとに $r^4 = 16$ 分の 1 程度にしか下がらず、`Converged` には 10 準位（21 回）を要する。

`Ridders` の推定誤差は実際の誤差より 1〜3 桁大きく、`Richardson` の推定誤差は 8 準位までは実際の誤差とほぼ同じ大きさになる。
ただし推定は上界ではない。
$x_0 = -2$ の `Ridders` の $L = 5, 6$ では、推定誤差 $5.0 \times 10^{-9}$ が実際の誤差 $2.8 \times 10^{-8}$ を下回る。

許容誤差を $10^{-15}$ にすると閾値は丸めの下限より小さくなり、どちらの方法も `Converged` に達しない。
`Ridders` は 8 準位目の推定誤差 $2.2 \times 10^{-13}$ のあと 3 準位続けて改善しないので、$L \ge 11$ では 11 準位目に `RoundoffLimit` で止まり（23 回）、そのときも値と推定誤差は出力に反映される。
ライブラリの既定の許容誤差 $\sqrt{\varepsilon}$ でも、最初の刻み $0.5$ が大きいので、どちらの方法も収束に 7 準位（15 回）かかる。

## 丸めが勝つ関数と二階導関数

次のセルは $f(x) = e^x + \sigma \eta(x)$ の一階導関数と二階導関数を、既定の `AdaptiveDifference` の `derivative` と `second_derivative` で $x_0 = 1$ において計算する。
$\eta$ は [丸め誤差・ノイズと最適な刻み幅](oxref:differentiate-noisy-functions) と同じ $[-1, 1)$ の擬似乱数のノイズで、点とシードだけで決まる。
ノイズの大きさ $\sigma$ を 0 から $10^{-4}$ まで変え、終了理由、出力への反映の有無、評価回数、推定誤差、実際の誤差を表に出す。
導関数はどの階数も $e$ なので、閾値は一階と二階で同じ $\sqrt{\varepsilon}(1 + e) \approx 5.5 \times 10^{-8}$ である。
表の行と閾値は、次のセルが図と結論に使う。

```rust
//| id: differentiate-adaptive-roundoff
//| ref: differentiate-adaptive-roundoff
//| title: ノイズの大きさによる適応差分の終了理由と推定誤差
//| run: reactive
//| uses: [differentiate-adaptive-experiment-model]
//| crates: [scioxide-core, scioxide-differentiate]
//| exports: [rows, success, threshold]
//| inputs:
//|   seed: {"type":"range","label":"乱数のシード","min":1,"max":20,"step":1,"value":3}
//| cases:
//|   - {"id":"other-seed","label":"シード = 11","description":"ノイズの実現値を変えても、σ = 10⁻⁶ では RoundoffLimit で止まり、一階でも推定誤差が実際の誤差を下回る。","inputs":{"seed":11}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"sweep","path":"/rows/0/2","equals":"Converged"}
//|       - {"artifact":"sweep","path":"/rows/0/4","equals":13}
//|       - {"artifact":"sweep","path":"/rows/0/6","range":{"max":1e-12}}
//|       - {"artifact":"sweep","path":"/rows/10/2","equals":"RoundoffLimit"}
//|       - {"artifact":"sweep","path":"/rows/10/3","equals":"あり"}
//|       - {"artifact":"sweep","path":"/rows/10/6","range":{"max":1e-4}}
//|   - case: other-seed
//|     expect:
//|       - {"artifact":"sweep","path":"/rows/10/2","equals":"RoundoffLimit"}
//|       - {"artifact":"sweep","path":"/rows/10/5","range":{"max":1e-5}}
//|       - {"artifact":"sweep","path":"/rows/10/6","range":{"min":1e-5,"max":1e-4}}
use scioxide_core::{SciOxideError, RealScalar};
use scioxide_differentiate::AdaptiveDifference;

let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let seed = seed as u64;
// ノイズのモデル: 点のビット列とシードを splitmix64 で混ぜ、[-1, 1) の値にする。
let noise = |t: f64| {
    let mut z = t.to_bits() ^ seed.wrapping_mul(0x9E37_79B9_7F4A_7C15);
    z = (z ^ (z >> 30)).wrapping_mul(0xBF58_476D_1CE4_E5B9);
    z = (z ^ (z >> 27)).wrapping_mul(0x94D0_49BB_1331_11EB);
    z ^= z >> 31;
    (z >> 11) as f64 / (1_u64 << 53) as f64 * 2.0 - 1.0
};
let x0 = 1.0_f64;
// 参照値: e^x の導関数はすべて e（f64 の固有メソッド）。
let exact = x0.exp();
let adaptive = AdaptiveDifference::default();
let mut rows = Vec::new();
let mut success = Vec::new();
for amplitude in [0.0, 1e-14, 1e-12, 1e-10, 1e-8, 1e-6, 1e-4] {
    let f = |t: f64| Ok::<f64, SciOxideError>(RealScalar::exp(t) + amplitude * noise(t));
    let first = adaptive.derivative(f, x0).map_err(|e| e.to_string())?;
    let second = adaptive
        .second_derivative(f, x0)
        .map_err(|e| e.to_string())?;
    for (order, result) in [("一階", &first), ("二階", &second)] {
        let report = result.report();
        let published = if report.output_available() {
            "あり"
        } else {
            "なし"
        };
        rows.push((
            amplitude,
            order,
            report.termination().to_string(),
            published,
            report.evaluations(),
            result.errors().map(|e| e[0]),
            result.values().map(|v| (v[0] - exact).abs()),
        ));
        success.push(report.is_success());
    }
}
let columns = serde_json::json!([
    { "key": "0", "label": "ノイズの大きさ σ [-]", "type": "number", "format": sci3 },
    { "key": "1", "label": "階数" },
    { "key": "2", "label": "終了理由" },
    { "key": "3", "label": "出力への反映" },
    { "key": "4", "label": "評価回数 [回]", "type": "integer" },
    { "key": "5", "label": "推定誤差 [-]", "type": "number", "format": sci3, "nullText": "なし" },
    { "key": "6", "label": "実際の誤差 [-]", "type": "number", "format": sci3, "nullText": "なし" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "sweep" })
);
export!(rows, rows);
export!(success, success);
// 閾値 τ_abs + τ_rel |f′| = √ε (1 + e)（既定の許容誤差、導関数はどの階数も e）。
export!(threshold, f64::EPSILON.sqrt() * (1.0 + exact));
```

ノイズがなければ（$\sigma = 0$）一階も二階も 6 準位（13 回）で `Converged` になり、一階の推定誤差は $2.5 \times 10^{-13}$、実際の誤差は $1.8 \times 10^{-15}$ である。
$\sigma \le 10^{-10}$ では収束するが、推定誤差はノイズとともに大きくなる。
$\sigma = 10^{-8}$ 以上では、刻みを縮めるとノイズの寄与 $\sigma / h$（二階では $\sigma / h^2$）が増えて最良の推定誤差が改善しなくなり、一階も二階も `RoundoffLimit` で止まる。
このときも「出力への反映」の列のとおり値と推定誤差は出力に反映される。
シードを 11 にしても、$\sigma = 10^{-8}$ 以上では `RoundoffLimit` で止まる。

次のセルは上のセルの表の推定誤差と実際の誤差をノイズの大きさ $\sigma$ に対して描き、選んだ $\sigma$ の一階導関数の終了理由をセルの結論として最後に示す。
横線は閾値 $\sqrt{\varepsilon}(1 + e)$、縦線は選んだ $\sigma$ である。
$\sigma = 0$ の行は横軸が対数なので図にない。
outcome は、終了理由が `Converged` なら satisfied、それ以外なら partial である。

```rust
//| id: differentiate-adaptive-noise-chart
//| ref: differentiate-adaptive-noise-chart
//| title: ノイズの大きさに対する推定誤差と実際の誤差、選んだ σ の終了理由
//| run: reactive
//| crates: [scioxide-core]
//| dependsOn:
//|   sweep: differentiate-adaptive-roundoff
//| inputs:
//|   sigma: {"type":"select","label":"結論を示すノイズの大きさ σ","options":["0","1e-12","1e-8","1e-6","1e-4"],"value":"1e-6"}
//| cases:
//|   - {"id":"noiseless","label":"σ = 0","description":"ノイズがなければ、一階導関数は Converged で止まり、outcome は satisfied になる。","inputs":{"sigma":"0"}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"path":"/outputs/1/state","equals":"partial"}
//|       - {"path":"/outputs/1/status","equals":"RoundoffLimit"}
//|   - case: noiseless
//|     expect:
//|       - {"path":"/outputs/1/state","equals":"satisfied"}
//|       - {"path":"/outputs/1/status","equals":"Converged"}
// 表の行: (σ, 階数, 終了理由, 出力への反映, 評価回数, 推定誤差, 実際の誤差)。
type Row = (f64, String, String, String, usize, Option<f64>, Option<f64>);
let rows: Vec<Row> =
    serde_json::from_value(sweep["rows"].clone()).map_err(|e| e.to_string())?;
let success: Vec<bool> =
    serde_json::from_value(sweep["success"].clone()).map_err(|e| e.to_string())?;
let threshold = sweep["threshold"].as_f64().ok_or("閾値がない")?;
let selected: f64 = sigma.parse().map_err(|_| "σ を読めない")?;
// 曲線: 一階の推定誤差と実際の誤差、二階の推定誤差と実際の誤差。σ = 0 は対数軸に描けない。
let mut curves: Vec<Vec<[f64; 2]>> = vec![Vec::new(); 4];
let mut chosen = None;
for (row, &converged) in rows.iter().zip(&success) {
    let (amplitude, order, termination, _, evaluations, estimate, error) = row;
    let lane = if order == "一階" { 0 } else { 2 };
    if let (true, Some(estimate), Some(error)) = (*amplitude > 0.0, estimate, error) {
        curves[lane].push([*amplitude, *estimate]);
        if *error > 0.0 {
            curves[lane + 1].push([*amplitude, *error]);
        }
    }
    if lane == 0 && *amplitude == selected {
        chosen = Some((converged, termination, *evaluations, *estimate, *error));
    }
}
let names = [
    "一階の推定誤差",
    "一階の実際の誤差",
    "二階の推定誤差",
    "二階の実際の誤差",
];
let series: Vec<_> = names
    .iter()
    .zip(&curves)
    .map(|(name, points)| serde_json::json!({ "name": name, "points": points }))
    .collect();
let mut annotations = vec![serde_json::json!({
    "kind": "line",
    "axis": "y",
    "value": threshold,
    "label": "閾値 √ε(1 + e)"
})];
if selected > 0.0 {
    annotations.push(serde_json::json!({
        "kind": "line",
        "axis": "x",
        "value": selected,
        "label": "選んだ σ"
    }));
}
emit_line_chart!(
    &series,
    options = &serde_json::json!({
        "xLabel": "ノイズの大きさ σ [-]",
        "yLabel": "導関数の誤差 [-]",
        "xType": "log",
        "yType": "log",
        "annotations": annotations
    })
);
let (converged, termination, evaluations, estimate, error) =
    chosen.ok_or("選んだ σ が走査の値にない")?;
let outcome = if converged {
    Outcome::satisfied("一階導関数の推定誤差が許容誤差を満たした")
} else {
    Outcome::partial("一階導関数の外挿が許容誤差を満たす前に止まった")
        .explanation("出力に反映された値は最良の推定である。推定誤差を見て、使うかどうかを判断する。")
};
let mut outcome = outcome.status(termination.clone());
outcome = outcome.diagnostic("評価回数", evaluations as f64, None);
if let (Some(estimate), Some(error)) = (estimate, error) {
    outcome = outcome.diagnostic("推定誤差", estimate, None);
    outcome = outcome.diagnostic("実際の誤差", error, None);
}
emit_outcome!(outcome);
```

既定の $\sigma = 10^{-6}$（シード 3）では、一階導関数は 7 準位（15 回）で `RoundoffLimit` になり、値と推定誤差は出力に反映されるが outcome は partial になる。

ノイズのある関数では、推定誤差は実際の誤差を大きく下回ることがある。
シード 3 では $\sigma \ge 10^{-8}$ の一階と $\sigma \ge 10^{-12}$ の二階で、実際の誤差の点が推定誤差の線より上にある。
$\sigma = 10^{-12}$ と $10^{-10}$ の二階は `Converged` でも、実際の誤差は推定誤差の 2〜12 倍である。
$\sigma = 10^{-6}$ の二階導関数では推定誤差 $7.7 \times 10^{-7}$ に対して実際の誤差は $9.5 \times 10^{-5}$ で、シードを 11 にすると一階でも推定誤差 $2.7 \times 10^{-6}$ に対して実際の誤差は $4.5 \times 10^{-5}$ になる。
ノイズは滑らかでないので、外挿が前提とする展開が成り立たず、表の要素の差が偶然小さくなることがあるからである。
終了理由が `RoundoffLimit` のときは推定誤差を信頼せず、ノイズの大きさから刻みを選ぶ方法（[ノイズのある関数](oxref:differentiate-noisy-functions)）か、独立な検算で値を確かめる。

## まとめ

$f(x) = e^{\sin x}$ と許容誤差 $10^{-12}$ では、`Ridders` は 8 準位（17 回）で `Converged` になり、列 1 だけを使う `Richardson` は 10 準位（21 回）を要するので、同じ許容誤差では既定の `Ridders` の方が評価回数が少ない。
`Ridders` の推定誤差は $x_0 = 0.5$ では実際の誤差より 1〜3 桁大きいが、$x_0 = -2$ では実際の誤差を下回る準位があり、上界としては使えない。
許容誤差を丸めの下限より小さくすると `Converged` には達せず `RoundoffLimit` で止まるので、許容誤差は導関数の大きさと丸めの下限を見て選ぶ。
ノイズのある関数では $\sigma \ge 10^{-8}$ で `RoundoffLimit` になり、$\sigma = 10^{-12}$ と $10^{-10}$ の二階導関数は `Converged` でも実際の誤差が推定誤差の 2〜12 倍になる。
`RoundoffLimit` でも値と推定誤差は出力に反映されるので、その推定誤差は信頼せず、ノイズの大きさから刻みを選ぶか独立な方法で値を検算する。
