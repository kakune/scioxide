濃度や確率のように負にならない量、$\sqrt{x}$ や $\ln x$ のように定義域の限られた関数、上下限を持つ最適化の変数では、差分の節点が定義域の外に出てはならない。
`scioxide-differentiate` は座標ごとの下限と上限を評価の引数として受け取り、関数を区間の外で評価しない。
固定刻みの差分は、境界までの余地が刻みに足りない向きに節点を置かず、余地の大きい向きの片側の節点に切り替える。
適応差分も準位ごとに同じ規則で節点を選び、節点を指定する差分は区間の外の節点を拒む。
このページではそれぞれの規則と、規則によって打ち切り誤差と丸め誤差がどう変わるかを導く。
境界の扱いが約束するのは標本が区間に入ることで、精度は関数が節点の範囲で滑らかなときに内部の点と同じ大きさになる。

## 境界の指定

区間の制約は scioxide-core の [`Bounds`](https://docs.rs/scioxide-core/0.1.0/scioxide_core/struct.Bounds.html) で表す。
`Bounds::new(vec![(Some(0.0), None), (Some(-1.0), Some(1.0))])` のように、座標ごとに下限と上限を `Option` で与え、`None` はその側に制約がないことを表す。
区間は閉区間で、座標が 1 つもなければ `InvalidInput`（`Empty`）、下限が上限を超えると `InvalidInput`（`Inconsistent`）、有限でない境界は `NonFinite` になる。
一部の座標だけに制約があるときは、`Bounds::from_indexed(n, vec![(i, lower, upper)])` で座標の番号を付けて与えられる。

`bounds` は手法オブジェクトや Plan ではなく評価の引数なので、同じ手法オブジェクトを異なる区間で使える。
スカラー関数の `derivative` と `second_derivative` は `FiniteDifference` でも `AdaptiveDifference` でも区間を受け取らない。
一変数で区間を渡すときは、一階なら `FiniteDifference::derivative_into`（区間は `ExtendedInterval`）、どちらの方法でも 1 座標の `gradient` と `hessian` を使う。
評価点が区間の外にあれば `InvalidInput`（`x`、`OutOfRange`）、区間の座標の数が評価点と合わなければ `DimensionMismatch` になる。
以下では評価点 $x$ から下限までの距離を $a = x - x_{\min}$ と書き、公称の刻みを $h$ と書く。
固定刻みの既定の $h$ は [Taylor 展開と刻み幅の選択](../taylor-and-step-size/) で導く値で、一階の中心差分では $h = \varepsilon^{1/3} \max(1, \lvert x \rvert)$、二階では $h = \varepsilon^{1/4} \max(1, \lvert x \rvert)$ である。

## 固定刻みの中心差分が選ぶ節点

`FiniteDifference` の中心差分は各座標の節点を次の順に決める。

1. 正の向きの余地 $x_{\max} - x$ と負の向きの余地 $a = x - x_{\min}$ を求める。
   制約のない側の余地は浮動小数点数の最大値までの距離である。
2. 両方の余地が公称の刻み $h$ 以上なら、3 点 $\{-h, 0, h\}$ を使う。
3. どちらかの余地が $h$ に満たなければ、余地の大きい向き（等しければ正の向き）に片側の節点を置く。
   一階では 3 点 $\{0, h', 2h'\}$、二階では 4 点 $\{0, h', 2h', 3h'\}$ を使い、刻みは進む向きの余地に収まるように $h' = \min(h, \text{余地}/2)$（二階は $\min(h, \text{余地}/3)$）に縮める。
   その向きで節点が区間を出るか丸めで重なれば、逆の向きを試す。
4. どちらの向きにも片側の節点を置けず、両側に余地があるとき（区間の幅が刻みに比べて非常に狭いとき）は、刻みを $h$ と両側の余地のうち最も小さいものに縮めた対称な 3 点を試す。
5. どれも置けなければ、関数を呼ぶ前に `InvalidInput`（`UnsupportedConfiguration`）を返す。
   引数は、その座標に制約があれば `bounds`、なければ `x` である。

2 の場合に一方の変位が丸めで消えるとき（区間がなく、$h$ が $\mathrm{ulp}(x)$ の半分より小さいときなど）は、片側の節点に切り替えずに 5 のエラーになる（[刻み幅の走査による誤差の U 字曲線](oxref:differentiate-step-u-curve)）。
重みはどの場合も丸めたあとの変位から作り、3 点以上の節点では Fornberg の漸化式（[差分ステンシルの重みと任意の節点](oxref:differentiate-fornberg)）を使う。
境界が近い点でも、節点の形は境界からの距離 $a$ によらず、対称な 3 点か、内側へ向かう等間隔の片側の節点のどちらかになる。

### 非対称な節点を避ける理由

$0 < a < h$ のとき、負の向きの変位だけを $a$ に縮めた非対称な 3 点 $\{-a, 0, h\}$ でも、区間の外を評価せずに一階導関数を作れる。
その公式は次のようになる。

$$
D f(x) = -\frac{h}{a (a + h)} f(x - a) + \frac{h - a}{a h} f(x) + \frac{a}{h (a + h)} f(x + h).
$$

三次のモーメント $\sum_j w_j \Delta_j^3 = a h$ を $3!$ で割ると、打ち切り誤差の主項は $(a h/6) f'''(x)$ になり、$a$ が小さいほど小さくなる。
その代わりに、$a \ll h$ では負の向きと中央の重みがどちらも約 $1/a$ になり、重みの絶対値の和は約 $2/a$ になる。
関数値の相対誤差を $\varepsilon_f$ とすると、丸め誤差は約 $2 \varepsilon_f \lvert f \rvert / a$ で、境界に近づくほど際限なく増える。
二階導関数では同じ 3 点の三次のモーメントが $2(h - a)$ になり、誤差の主項 $(h - a) f'''(x)/3$ は一次に下がり、丸め誤差は約 $4 \varepsilon_f \lvert f \rvert / (a h)$ に増える。
そのため `FiniteDifference` は余地が刻みに足りない向きに節点を置かず、内側へ向かう片側の節点を使う。

### 片側の公式の誤差

片側 3 点の一階の公式は Taylor 展開から二次の精度を持つ。

$$
\frac{-3 f(x) + 4 f(x + h) - f(x + 2h)}{2h} = f'(x) - \frac{h^2}{3} f'''(x) + O(h^3).
$$

片側 4 点の二階の公式も、三次のモーメントが $(-5 + 32 - 27) h^3 = 0$ になるので二次の精度を持つ。

$$
\frac{2 f(x) - 5 f(x + h) + 4 f(x + 2h) - f(x + 3h)}{h^2} = f''(x) - \frac{11}{12} h^2 f^{(4)}(x) + O(h^3).
$$

片側の公式の主項の係数は中心差分（一階 $h^2/6$、二階 $h^2/12$）より大きい。
重みの絶対値の和も一階で $4/h$（中心差分は $1/h$）、二階で $12/h^2$（中心差分は $4/h^2$）と大きいので、同じ $h$ でも誤差は中心差分の数倍になる。
ただし、どちらも境界からの距離 $a$ によらないので、境界のすぐ内側でも誤差は内部の点と同じ大きさにとどまる。

前進差分の一階は、正の向きの余地が $h$ 以上なら $\{0, h\}$、そうでなく負の向きの余地が $h$ 以上なら $\{0, -h\}$ を使う。
どちらの向きの余地も $h$ に満たなければ、余地の大きい向き（等しければ正の向き）に刻みを余地まで縮めて置く。
前進差分の二階は $\{0, h, 2h\}$ を使い、余地を $2h$ と比べて同じ規則で向きを選ぶ。

## 境界からの距離と誤差の実測

次のセルは下限 0 を持つ区間で $f(x) = e^x$ を、境界からの距離 $a$ を変えた点 $x = a$ で、既定の中心差分により微分する。
区間を渡すので、一階は 1 座標の `gradient`、二階は 1 座標の `hessian` で求める。
関数を呼ぶたびに点を記録し、実際に使われた節点の最小と最大の変位を公称の刻み $h$ を単位として表に示す。
打ち切り誤差の主項は上の式で予測する。
丸めの目安 $u \sum_j \lvert w_j \rvert \lvert f \rvert$（$u = \varepsilon/2$ は丸めの単位）は、記録した節点から `FiniteDifferenceStencil` を作り、`weights()` が返す物理単位の重みで求める。
比較のために、使われなかった非対称な 3 点 $\{-a, 0, h\}$ の誤差も、`FiniteDifferenceStencil::apply` で同じ関数値に重みを掛けて求め、最後の列に示す（$a = 0$ と $a \ge h$ では定義しない）。
厳密値と主項は f64 の参照値である。
図は $a$ を $10^{-12}$ から $10^{-1}$ まで細かく変えた誤差の絶対値で、$a = 0$ は対数軸に描けないので表だけに示す。

```rust
//| id: differentiate-bounded-stencil
//| ref: differentiate-bounded-stencil
//| title: 下限からの距離による中心差分の節点と誤差
//| run: reactive
//| crates: [scioxide-core, scioxide-differentiate]

//| cases:
//|   - {"id":"second","label":"二階","description":"h が大きいので a ≤ 10⁻⁴ の行が片側の 4 点になり、非対称な 3 点の誤差は一次の主項と 1/(ah) の丸めで大きくなる。","inputs":{"order":"二階"}}

//|   - case: default
//|     expect:

//|       - {"artifact":"nodes","path":"/rows/4/2","approx":{"value":-1,"rtol":1e-9}}
//|       - {"artifact":"nodes","path":"/rows/6/4","range":{"min":-3e-11,"max":3e-11}}

use scioxide_differentiate::{FiniteDifference, FiniteDifferenceStencil};

// 既定の刻みは h = c·max(1, |x|) で、ここでは x < 1 なので h = c。
let (m, h) = match order.as_str() {
    "一階" => (1, f64::EPSILON.cbrt()),
    _ => (2, f64::EPSILON.sqrt().sqrt()),
};
let method = FiniteDifference::default();
let bounds = Bounds::new(vec![(Some(0.0), None)]).map_err(|e| e.to_string())?;
// 点 x = a で微分し、(節点, 実測の誤差, 主項, 丸めの目安, 非対称な 3 点の誤差) を返す。
let probe = |a: f64| {
    let mut seen = Vec::new();
    let f = |p: &[f64], y: &mut [f64]| {
        seen.push(p[0]);
        y[0] = RealScalar::exp(p[0]);
        Ok::<(), SciOxideError>(())
    };
    let result = if m == 1 {
        method.gradient(f, &[a], Some(&bounds), None)
    } else {
        method.hessian(f, &[a], Some(&bounds), None)
    }
    .map_err(|e| e.to_string())?;
    let value = result.values().ok_or("導関数が公開されない")?[0];
    seen.sort_by(f64::total_cmp);
    // 参照値: e^x のすべての導関数は e^a（f64 の固有メソッド）。
    let g = a.exp();
    let (lo, hi) = (a - seen[0], seen[seen.len() - 1] - a);
    // 対称な 3 点は h²/6（二階 h²/12）、片側は −h²/3（二階 −11h²/12）の主項。
    let predicted = match (m, lo > 0.0) {
        (1, true) => lo * hi / 6.0 * g,
        (1, false) => -(hi / 2.0).powi(2) / 3.0 * g,
        (_, true) => lo * hi / 12.0 * g,
        _ => -11.0 / 12.0 * (hi / 3.0).powi(2) * g,
    };
    let stencil = FiniteDifferenceStencil::new(a, &seen, m).map_err(|e| e.to_string())?;
    let weights = stencil.weights().map_err(|e| e.to_string())?;
    let spread: f64 = weights.iter().map(|w| w.abs()).sum();
    // 比較: 負の向きだけを a に縮めた非対称な 3 点 {−a, 0, h} の誤差。
    let asymmetric = if a > 0.0 && a < h {
        let nodes = [0.0, a, a + h];
        let values = nodes.map(RealScalar::exp);
        let stencil = FiniteDifferenceStencil::new(a, &nodes, m).map_err(|e| e.to_string())?;
        Some(stencil.apply(&values).map_err(|e| e.to_string())? - g)
    } else {
        None
    };
    let rounding = f64::EPSILON / 2.0 * spread * g;
    Ok::<_, String>((seen, value - g, predicted, rounding, asymmetric))
};
let mut rows = Vec::new();
for a in [0.0, 1e-10, 1e-8, 1e-6, 1e-5, 1e-4, 1e-2] {
    let (seen, error, predicted, rounding, asymmetric) = probe(a)?;
    let (low, high) = ((seen[0] - a) / h, (seen[seen.len() - 1] - a) / h);
    rows.push((
        a,
        seen.len(),
        low,
        high,
        error,
        predicted,
        rounding,
        asymmetric,
    ));
}
let (sci2, sci3, fixed3) = (
    serde_json::json!({ "notation": "scientific", "significantDigits": 2 }),
    serde_json::json!({ "notation": "scientific", "significantDigits": 3 }),
    serde_json::json!({ "fractionDigits": 3 }),
);

    { "key": "0", "label": "距離 a [-]", "type": "number", "format": sci2 },
    { "key": "1", "label": "節点の数 [個]", "type": "integer" },
    { "key": "2", "label": "最小の変位 ÷ h [-]", "type": "number", "format": fixed3 },
    { "key": "3", "label": "最大の変位 ÷ h [-]", "type": "number", "format": fixed3 },
    { "key": "4", "label": "実測の誤差 [-]", "type": "number", "format": sci3 },
    { "key": "5", "label": "打ち切りの主項 [-]", "type": "number", "format": sci3 },
    { "key": "6", "label": "丸めの目安 [-]", "type": "number", "format": sci3 },
    { "key": "7", "label": "非対称な 3 点の誤差 [-]", "type": "number", "format": sci3, "nullText": "—" }

emit_table_with_columns!(

    rows,
    metadata = serde_json::json!({ "id": "nodes" })

let (mut measured, mut skewed, mut rounding) = (Vec::new(), Vec::new(), Vec::new());
for k in 0..=44 {
    let a = 10.0_f64.powf(-12.0 + 0.25 * k as f64);
    let (_, error, _, guide, asymmetric) = probe(a)?;
    if error != 0.0 {
        measured.push([a, error.abs()]);
    }
    if let Some(e) = asymmetric.filter(|e| *e != 0.0) {
        skewed.push([a, e.abs()]);

        serde_json::json!({ "name": "非対称な 3 点の誤差", "points": skewed, "style": { "showSymbol": true } }),
        serde_json::json!({ "name": "丸めの目安", "points": rounding, "style": dashed })
    ],
    options = &serde_json::json!({
        "xLabel": "下限からの距離 a [-]",
        "yLabel": "導関数の誤差の絶対値 [-]",
        "xType": "log",
```

一階の既定では $h = \varepsilon^{1/3} \approx 6.06 \times 10^{-6}$ で、$a \ge 10^{-5}$ の 3 行では節点は対称な $\{-h, 0, h\}$ になる。
誤差は $1.3 \times 10^{-11}$ 以下で、主項 $h^2/6 \approx 6.1 \times 10^{-12}$ と丸めの目安 $1.8 \times 10^{-11}$ の範囲に収まる。
$a \le 10^{-6}$ の 4 行では、$a$ によらず片側の $\{0, h, 2h\}$ になり、主項 $-h^2/3 = -1.2 \times 10^{-11}$、丸めの目安 $7.3 \times 10^{-11}$ も行ごとに変わらない。
実測の誤差は $5.2 \times 10^{-12}$ から $-4.0 \times 10^{-11}$ で、丸めの目安を超えない。
比較の非対称な 3 点では、誤差が $a = 10^{-6}$ の $-3.2 \times 10^{-11}$ から、$10^{-8}$ で $-1.1 \times 10^{-8}$、$10^{-10}$ で $8.3 \times 10^{-8}$ に増える。
図でも、実測の誤差は $a$ によらず $7.4 \times 10^{-11}$ 以下にとどまり、非対称な 3 点の誤差は $a < 10^{-8}$ の範囲で丸めの $2u \lvert f \rvert / a$ と同じ大きさで増え、$a = 10^{-12}$ で $8.9 \times 10^{-5}$ に達する。

二階（ケース second）では $h = \varepsilon^{1/4} \approx 1.22 \times 10^{-4}$ で、$a = 10^{-2}$ だけが対称な節点を使い、$a \le 10^{-4}$ の 6 行は片側の 4 点 $\{0, h, 2h, 3h\}$ になる。
片側の主項は $-1.4 \times 10^{-8}$、丸めの目安は $8.9 \times 10^{-8}$ で、実測の誤差は最大でも $a = 10^{-8}$ の $-7.0 \times 10^{-8}$ で丸めの目安を超えない。
非対称な 3 点では、$a = 10^{-4}$、$10^{-5}$、$10^{-6}$ の誤差 $7.35 \times 10^{-6}$、$3.75 \times 10^{-5}$、$4.10 \times 10^{-5}$ が一次の主項 $(h - a)/3$ に沿い、$a = 10^{-8}$ 以下では丸めの $4u \lvert f \rvert/(a h)$ が加わって $2.2 \times 10^{-4}$、$-1.3 \times 10^{-3}$ に増える。
図の範囲では、実測の誤差は $7.6 \times 10^{-8}$ 以下、非対称な 3 点の誤差は $a = 10^{-12}$ で $1.5$ になる。
片側の節点を使うことで、境界から刻みより近い点でも、誤差は境界から離れた点の数倍の大きさにとどまる。

## 適応差分・方向微分・節点差分の境界

適応差分 `AdaptiveDifference`（[Richardson 外挿と Ridders の方法](../richardson-and-ridders/)）は、各準位の刻み $h_\ell$ について、固定刻みの中心差分と同じ規則で節点を選ぶ。
両方の向きの余地が $h_\ell$ 以上なら対称な $\{-h_\ell, 0, h_\ell\}$、そうでなければ余地の大きい向きの片側の節点（一階 $\{0, h', 2h'\}$、二階 $\{0, h', 2h', 3h'\}$）を使う。
最初の刻み $0.5 \max(1, \lvert x \rvert)$ は大きいので、境界から $a$ の点では、刻みが $a$ を超える初めの準位は片側の節点になり、刻みが $a$ を下回った準位から対称な節点に変わる。
片側の差分の誤差は $h$ のすべての冪を含み、対称な差分の誤差は偶数冪だけを含むので、外挿は節点の形ごとに別の展開を仮定する。
節点の形が変わった準位では、外挿の表を列 0 からやり直し、停滞の履歴も初期化する。
それまでの最良推定は代替として保持するが、新しい配置での改善はその配置の履歴と比べる。
どちらの形でも刻みは境界までの距離 $a$ に縮められないので、境界のすぐ内側でも丸め誤差は内部の点と同じ大きさにとどまる。

一階の準位はどちらの形でも評価が 2 回である。
二階導関数の片側の準位は 4 点を使うので、準位あたりの評価が中心の 2 回より 1 回多い 3 回になる。
刻みを縮めると節点が表現できなくなるか、縮めても前の準位と同じ節点になるときは、レポートの終了理由が `StepSizeLimit` になる。
`AdaptiveDifference` には `FixedCoordinatePolicy` にあたる設定はないので、下限と上限が一致する座標でも `StepSizeLimit` で止まる。

方向微分（[方向微分（ヤコビ行列とベクトルの積）](oxref:differentiate-jvp-step)）は、方向 $\mathbf{v}$ に沿った直線 $\mathbf{x} + \alpha \mathbf{v}$ が区間を出るまでの $\alpha$ の余地を、正と負の向きで別々に求める。
そのうえで、一変数の固定刻みの差分と同じ規則で、対称な節点、余地の大きい向きの片側の節点、縮めた対称な節点の順に試す。
方向が境界を向いている座標がすでにその境界上にあれば、その向きには進めない。
丸めたあとの点がすべて区間の中にあり、互いに異なることも確かめ、通らなければ中心差分では刻みを縮めた対称な節点を試す。
固定刻みの `FiniteDifference::jvp` は節点を置けなければレポートではなくエラー `DifferentiationFailure`（原因は `ConvergenceFailure` の `StepSizeLimit`）を返す。
適応差分の `AdaptiveDifference::jvp` も準位ごとに同じ規則で節点を置き、節点を置けなければレポートの終了理由 `StepSizeLimit` で止まる。

節点を指定する差分（[節点を指定する差分の Plan と手法オブジェクト](oxref:differentiate-node-checks)）は、境界に合わせて節点を動かさない。
区間の外の節点は関数を呼ぶ前に `InvalidInput`（`UnsupportedConfiguration`）で拒む。
引数は評価点を固定する `PhysicalDifferencePlan` では `bounds`、変位を持つ `RelativeDifference` では `x` である。

複素ステップ法（[複素ステップ微分と解析的拡張](../complex-step/)）の一階の摂動は虚部だけを動かし、実部は評価点のままなので、区間を出ない。
手法オブジェクト `ComplexStep` の演算は区間を受け取らない。
実数の節点で二階導関数を作る `ComplexStepPlan` と `RelativeComplexStep` は区間を受け取り、節点を指定する差分と同じように、区間の外の実数の節点を `InvalidInput`（`UnsupportedConfiguration`）で拒む（[実数の節点を指定する差分法オブジェクトと Plan](oxref:differentiate-complex-node-plans)）。

次のセルは下限 0 を持つ区間で $f(x) = e^x$ の一階と二階の導関数を `AdaptiveDifference` で求め、境界からの距離 $a$ ごとに終了理由、準位の数、片側の節点を使った準位の数、評価回数、推定誤差、実際の誤差を表に示す。
対称な準位は評価点より小さい点を 1 つだけ評価し、片側の準位はそのような点を評価しないので、関数を呼ぶたびに点を記録し、$a$ より小さい点の数を対称な準位の数として数える。
最初の刻みは $0.5$ で、Ridders の方法では準位ごとに $1.4$ で割るので、$a = 0.05$ と $0.1$ では途中の準位で節点の形が変わる。
厳密値 $e^a$ は f64 の参照値である。

```rust
//| id: differentiate-bounded-adaptive
//| ref: differentiate-bounded-adaptive
//| title: 下限からの距離による適応差分の節点の形と誤差
//| run: reactive
//| crates: [scioxide-core, scioxide-differentiate]
//| inputs:
//|   order: {"type":"select","label":"微分の階数","options":["一階","二階"],"value":"一階"}
//| cases:
//|   - {"id":"second","label":"二階","description":"片側の準位が 3 回ずつ評価するので、境界の近くの評価回数は内部の点より多い。誤差は境界からの距離によらない。","inputs":{"order":"二階"}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"adaptive","path":"/rows/0/1","equals":"Converged"}
//|       - {"artifact":"adaptive","path":"/rows/0/3","equals":8}
//|       - {"artifact":"adaptive","path":"/rows/0/4","equals":17}
//|       - {"artifact":"adaptive","path":"/rows/0/6","range":{"max":1e-11}}
//|       - {"artifact":"adaptive","path":"/rows/1/1","equals":"Converged"}
//|       - {"artifact":"adaptive","path":"/rows/1/6","range":{"max":1e-11}}
//|       - {"artifact":"adaptive","path":"/rows/5/1","equals":"Converged"}
//|       - {"artifact":"adaptive","path":"/rows/5/2","equals":11}
//|       - {"artifact":"adaptive","path":"/rows/5/3","equals":7}
//|       - {"artifact":"adaptive","path":"/rows/5/4","equals":23}
//|       - {"artifact":"adaptive","path":"/rows/5/6","range":{"max":1e-11}}
//|       - {"artifact":"adaptive","path":"/rows/7/3","equals":0}
//|       - {"artifact":"adaptive","path":"/rows/7/6","range":{"max":1e-11}}
//|   - case: second
//|     expect:
//|       - {"artifact":"adaptive","path":"/rows/0/1","equals":"Converged"}
//|       - {"artifact":"adaptive","path":"/rows/0/4","equals":28}
//|       - {"artifact":"adaptive","path":"/rows/1/6","range":{"max":1e-11}}
//|       - {"artifact":"adaptive","path":"/rows/5/1","equals":"Converged"}
//|       - {"artifact":"adaptive","path":"/rows/7/4","equals":13}
//|       - {"artifact":"adaptive","path":"/rows/7/6","range":{"max":1e-11}}
use scioxide_core::{Bounds, SciOxideError, RealScalar};
use scioxide_differentiate::AdaptiveDifference;

let second = order == "二階";
let method = AdaptiveDifference::default();
let bounds = Bounds::new(vec![(Some(0.0), None)]).map_err(|e| e.to_string())?;
let mut rows = Vec::new();
for a in [0.0, 1e-12, 1e-8, 1e-4, 1e-2, 0.05, 0.1, 1.0] {
    // 評価点 a より小さい点を数える。対称な準位だけがそのような点を 1 つ評価する。
    let mut below = 0_usize;
    let f = |p: &[f64], y: &mut [f64]| {
        below += usize::from(p[0] < a);
        y[0] = RealScalar::exp(p[0]);
        Ok::<(), SciOxideError>(())
    };
    let result = if second {
        method.hessian(f, &[a], Some(&bounds))
    } else {
        method.gradient(f, &[a], Some(&bounds))
    }
    .map_err(|e| e.to_string())?;
    let report = result.report();
    // 上限による停止なら値は出力に反映されないので、None で示す。
    let estimate = result.errors().map(|e| e[0]);
    // 参照値: e^x の導関数は e^a（f64 の固有メソッド）。
    let actual = result.values().map(|v| (v[0] - a.exp()).abs());
    rows.push((
        a,
        report.termination().to_string(),
        report.iterations(),
        report.iterations() - below,
        report.evaluations(),
        estimate,
        actual,
    ));
}
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let columns = serde_json::json!([
    { "key": "0", "label": "距離 a [-]", "type": "number", "format": sci3 },
    { "key": "1", "label": "終了理由" },
    { "key": "2", "label": "準位の数 [段]", "type": "integer" },
    { "key": "3", "label": "片側の準位 [段]", "type": "integer" },
    { "key": "4", "label": "評価回数 [回]", "type": "integer" },
    { "key": "5", "label": "推定誤差 [-]", "type": "number", "format": sci3, "nullText": "なし" },
    { "key": "6", "label": "実際の誤差 [-]", "type": "number", "format": sci3, "nullText": "なし" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "adaptive" })
);
```

一階の既定では、$a \le 10^{-2}$ の 5 行はどれも 8 準位すべてで片側の節点を使い、17 回の評価で `Converged` になる。
実際の誤差は $8.3 \times 10^{-13}$ から $9.1 \times 10^{-13}$、推定誤差は $1.4 \times 10^{-10}$ で、境界上の点と境界から $10^{-12}$ の点の結果はほとんど変わらない。
$a = 0.1$ では 5 準位の片側の差分のあと対称な節点に変わり、表をやり直して 10 準位、21 回の評価で `Converged` になり、誤差は $9.1 \times 10^{-15}$ である。
$a = 0.05$ では 7 準位の片側の差分のあとで節点の形が変わり、外挿と停滞の履歴をやり直す。
対称な節点の 4 準位を加えた 11 準位、23 回の評価で `Converged` になり、実際の誤差は $1.1 \times 10^{-14}$、推定誤差は $6.1 \times 10^{-13}$ である。
境界から離れた $a = 1$ では 6 準位すべてが対称で、13 回の評価で誤差は $1.8 \times 10^{-15}$ である。

二階（ケース second）では、片側の準位が 3 回ずつ評価するので、$a \le 10^{-2}$ の 5 行は 9 準位で $1 + 3 \times 9 = 28$ 回を使い、どれも `Converged` で、誤差は $4.3 \times 10^{-13}$ から $1.3 \times 10^{-11}$ である。
$a = 0.05$ は片側 7 準位と対称 4 準位の $1 + 3 \times 7 + 2 \times 4 = 30$ 回、$a = 0.1$ は片側 5 準位と対称 5 準位の 26 回で、どちらも `Converged` になる。
境界のすぐ内側でも、片側の節点を使う限り刻みは $a$ まで縮まず、誤差は境界上の点と同じ大きさになる。
節点の形が変わる距離では外挿の表と停滞の履歴をやり直すため、評価回数が増えることがある。
同じ配置での改善が続かない場合は `RoundoffLimit` もあり得るので、終了理由と推定誤差を確かめてから値を使う。


## 下限と上限が一致する座標

上下限のある最適化の途中では、下限と上限が一致して値が固定された座標が現れる。
その座標には正にも負にも余地がないので、差分の節点を置けない。
`FiniteDifference` はその扱いを、`with_fixed_coordinates` に渡す [`FixedCoordinatePolicy`](https://docs.rs/scioxide-differentiate/0.1.0/scioxide_differentiate/enum.FixedCoordinatePolicy.html) で選ぶ。

| 値 | 動作 |
|---|---|
| `RequireStencil`（既定） | その座標の節点が作れないので、関数を呼ぶ前に `InvalidInput`（`bounds`、`UnsupportedConfiguration`）を返す |
| `FeasibleZero` | その座標の偏微分を 0 とし、その座標の標本を評価しない |

`FeasibleZero` を受け付けるのは勾配（`gradient`、`gradient_into`）とスカラーの一階導関数（`derivative`、`derivative_into`）だけである。
ほかの演算（二階導関数、ヘッセ行列、ヤコビ行列、方向微分）に指定すると、呼び出したときに `InvalidInput`（`self`、`Inconsistent`）になる。
勾配の評価で `bounds` を渡さなければ、`InvalidInput`（`bounds`、`Inconsistent`）になる。
スカラーの `derivative` は区間を受け取らないので、この方針は区間を渡す `derivative_into` でだけ働く。
0 にした成分も完了した成分と 1 回の反復として数えられる。
返る勾配は固定された座標を動かさない方向だけで見た勾配で、元の関数のその座標の偏微分ではない。

ほかの方法には `FixedCoordinatePolicy` にあたる設定がない。
`AdaptiveDifference` は固定された座標で節点を置けないので、その成分の準位を始められずに終了理由 `StepSizeLimit` で止まる。
方向微分は、方向が固定された座標を動かすなら、どちらの向きにも余地がないので節点を置けない。
節点を指定する差分は固定された座標の 0 でない変位を区間の外の節点として拒む。

次の二つのセルは $f(\mathbf{x}) = x_0^2 + x_0 x_1 + x_2^3$ の勾配を $\mathbf{x} = (1, 2, 0.5)$ で、選んだ座標の下限と上限をその値に一致させて求める。
元の関数の勾配は $(2 x_0 + x_1, x_0, 3 x_2^2) = (4, 1, 0.75)$ である。
次のブロックは二つのセルが共有する定義で、`polynomial` が $f$、`pinned_bounds` が選んだ座標だけを固定した区間、`row` が結果かエラーを表の 1 行にする関数である。
`row` はエラーの分類を `e.kind()`、引数と理由を `e.view()` で読み、`DifferentiationFailure` では原因のエラーの理由を読む。

```rust
//| id: differentiate-fixed-coordinate-model
//| kind: definitions
//| title: 固定した座標を持つ区間と結果の表の行
//| crates: [scioxide-core, scioxide-differentiate]
use scioxide_core::{Bounds, SciOxideError, SciOxideErrorView};
use scioxide_differentiate::DifferentiationResult;

/// 評価点 x = (1, 2, 0.5)。
pub(crate) const POINT: [f64; 3] = [1.0, 2.0, 0.5];

/// f(x) = x₀² + x₀x₁ + x₂³ を y[0] に書く。
pub(crate) fn polynomial(p: &[f64], y: &mut [f64]) -> Result<(), SciOxideError> {
    y[0] = p[0] * p[0] + p[0] * p[1] + p[2] * p[2] * p[2];
    Ok(())
}

/// 座標 fixed だけ下限と上限を評価点の値に一致させ、ほかの座標は制約しない区間。
pub(crate) fn pinned_bounds(fixed: usize) -> Result<Bounds<f64>, SciOxideError> {
    let value = POINT[fixed];
    Bounds::from_indexed(3, vec![(fixed, Some(value), Some(value))])
}

/// 表の 1 行: (計算, 終了理由かエラーの分類, 引数, 理由, 評価回数, 勾配の 3 成分)。
pub(crate) type Row = (
    &'static str,
    String,
    Option<String>,
    Option<String>,
    Option<usize>,
    Option<f64>,
    Option<f64>,
    Option<f64>,
);

/// 結果かエラーを表の 1 行にする。DifferentiationFailure は原因のエラーの理由を読む。
pub(crate) fn row(
    name: &'static str,
    outcome: Result<DifferentiationResult<f64>, SciOxideError>,
) -> Row {
    match outcome {
        Ok(result) => {
            let report = result.report();
            let g = |i: usize| result.values().and_then(|v| v.get(i).copied());
            let termination = report.termination().to_string();
            let evaluations = Some(report.evaluations());
            (name, termination, None, None, evaluations, g(0), g(1), g(2))
        }
        Err(e) => {
            let (argument, reason) = match e.view() {
                SciOxideErrorView::InvalidInput {
                    argument, reason, ..
                } => (Some(argument.to_string()), Some(format!("{reason:?}"))),
                SciOxideErrorView::DifferentiationFailure { cause, .. } => match cause.view() {
                    SciOxideErrorView::ConvergenceFailure { reason, .. } => {
                        (None, Some(format!("{reason:?}")))
                    }
                    _ => (None, Some(format!("{:?}", cause.kind()))),
                },
                _ => (None, None),
            };
            let kind = format!("{:?}", e.kind());
            (name, kind, argument, reason, None, None, None, None)
        }
    }
}
```

### FiniteDifference の二つの方針

次のセルは `FiniteDifference` の勾配を二つの方針で求め、評価回数と値を比べる。
あわせて、`FeasibleZero` を区間なしの勾配とヘッセ行列に指定した場合のエラーを示す。
最後の行は手で微分した元の関数の勾配である。

```rust
));
let fixed6 = serde_json::json!({ "fractionDigits": 6 });

    { "key": "2", "label": "引数", "nullText": "-" },
    { "key": "3", "label": "理由", "nullText": "-" },
    { "key": "4", "label": "評価回数 [回]", "type": "integer", "nullText": "-" },
    { "key": "5", "label": "∂f/∂x₀ [-]", "type": "number", "format": fixed6, "nullText": "-" },
    { "key": "6", "label": "∂f/∂x₁ [-]", "type": "number", "format": fixed6, "nullText": "-" },

```

既定で座標 1 を固定すると、`RequireStencil` はエラー `InvalidInput`（`bounds`、`UnsupportedConfiguration`）を返す。
`FeasibleZero` は $(4, 0, 0.75)$ の勾配を 5 回の評価で返す。
基準点の 1 回と、自由な 2 座標の中心差分の $2 \times 2 = 4$ 回で、固定した座標の標本は評価しない。
2 番目の成分は元の勾配の $x_0 = 1$ ではなく 0 である。
区間なしの `FeasibleZero` は `InvalidInput`（`bounds`、`Inconsistent`）、ヘッセ行列は `InvalidInput`（`self`、`Inconsistent`）で拒まれる。
固定する座標を 2 に変えると（ケース fixed-last）、0 になる成分が 3 番目に移る。

### 方向微分・適応差分・節点差分の振る舞い

次のセルは同じ区間で、固定した座標の向きの方向微分を `FiniteDifference::jvp` で、勾配を `AdaptiveDifference` と変位 $\{-10^{-3}, 0, 10^{-3}\}$ の `RelativeDifference` で求める。

```rust

//| ref: differentiate-fixed-coordinate-methods

//|   - case: default
```

`AdaptiveDifference` の勾配は座標を番号の順に求め、固定した座標 1 の最初の準位で節点を置けず、終了理由 `StepSizeLimit` で止まる。
それまでに座標 0 の 3 準位で $1 + 2 \times 3 = 7$ 回を評価しているが、推定値のない成分があるので、ほかの成分も含めて値は出力に反映されない。

`RelativeDifference` は固定した座標の節点 $x_1 \pm 10^{-3}$ が区間の外に出るので、関数を呼ぶ前に `InvalidInput`（`x`、`UnsupportedConfiguration`）を返す。

## まとめ

`Bounds` を渡すと、どの方法も関数を区間の外で評価しない。
固定刻みの中心差分は、境界までの余地が刻みに足りなければ、余地の大きい向きの片側の $\{0, h, 2h\}$（二階は $\{0, h, 2h, 3h\}$）に切り替え、精度は二次のまま主項の係数と丸めの目安が中心差分の数倍になる。
節点の形も誤差も境界からの距離によらないので、境界のすぐ内側でも誤差は内部の点と同じ大きさで、刻みを距離に縮める非対称な節点のように $1/a$ で増えることはない。
適応差分は準位ごとに同じ規則で節点を選び、境界の近くでも内部と同じ精度で収束するが、刻みが境界までの距離を横切る準位で表をやり直すので、終了理由と推定誤差を確かめる。
方向微分は直線に沿った余地で同じ規則を使い、節点差分は区間の外の節点を拒む。
下限と上限が一致する座標は既定ではエラーになり、`FiniteDifference` の勾配と一階導関数に限って `FeasibleZero` で 0 として扱え、ほかの方法では節点を置けずに止まる。
