[数値微分のアルゴリズムの共通仕様と構成](oxref:differentiate-call-forms-terms) では、ワンショット関数、所有値を返す API、出力先を指定する API の三つの呼び出しの形と、評価回数と反復回数の数え方を定めた。
このページでは同じ関数の勾配をそれぞれの形と種類で求め、その定めを実測で確かめる。
確かめるのは次の四つである。

- 三つの形が同じ値を返し、評価回数の上限で止まった出力先を指定する API は値を出力に反映しないこと。
- レポートの評価回数が、関数を実際に呼んだ回数に一致すること。
- 評価回数と反復回数が、種類ごとの式に従うこと。
- 九つのワンショット関数が既定の設定で、方法ごとの精度の目安に合う値を返すこと。

上限、取り消し、期限で止まった評価が何を返し何を出力に反映するかは、[評価回数の上限・レポート・結果の出力への反映](../budgets-reports-and-publication/) で扱う。

## 巡回和の関数

実験には $n$ 変数の関数

$$
f(\mathbf{x}) = \sum_{i=0}^{n-1} e^{x_i} \sin x_{i+1} \quad (x_n = x_0)
$$

を使う。
評価点は $x_i = 0.3 + 0.2\,i$ とする。
次のブロックは二つのセルが共有する関数の定義で、`cyclic` が $f$、`cyclic_complex` が複素ステップ法に渡す同じ式の複素数版である。
$e^{z}$ と $\sin z$ は正則で実軸の上では実数の値をとるので、`cyclic_complex` は $f$ の解析的拡張になる。

```rust
//| id: differentiate-cyclic-model
//| kind: definitions
//| title: 巡回和の関数とその複素数版
//| crates: [scioxide-core]
use scioxide_core::{Complex, RealScalar};

/// f(x) = Σᵢ e^{xᵢ} sin x_{i+1}（添字は巡回）。
pub(crate) fn cyclic(p: &[f64]) -> f64 {
    (0..p.len())
        .map(|i| RealScalar::exp(p[i]) * RealScalar::sin(p[(i + 1) % p.len()]))
        .sum()
}

/// 同じ式を複素数で評価する解析的拡張。
pub(crate) fn cyclic_complex(z: &[Complex<f64>]) -> Complex<f64> {
    (0..z.len()).fold(Complex::new(0.0, 0.0), |s, i| {
        s + z[i].exp() * z[(i + 1) % z.len()].sin()
    })
}
```

## 三つの形と評価回数の上限

最初のセルは $n = 3$ の勾配を、固定刻みの中心差分の三つの形で求める。
ワンショット関数 `gradient` は値だけを返し、所有値を返す API `FiniteDifference::gradient` はレポートと値を返す。
出力先を指定する API `gradient_into` には評価回数の上限 $B$ を与え、入力で $B$ を変える。
出力先を指定する API に渡す配列は初めに 7 で埋めておき、評価のあとに値が変わった成分の数を数える。
表は形ごとに、終了理由、関数の中で数えた呼び出し回数、レポートの評価回数と反復回数、出力への反映の有無、ワンショット関数の値との差の最大、出力先を指定する API で値が変わった出力の成分の数を示す。

```rust
//| id: differentiate-call-forms
//| ref: differentiate-call-forms
//| title: ワンショット呼び出し・所有値を返す API・出力先を指定する API と評価回数の上限
//| run: reactive
//| uses: [differentiate-cyclic-model]
//| crates: [scioxide-core, scioxide-differentiate]
//| inputs:
//|   limit: {"type":"range","label":"評価回数の上限 B","description":"出力先を指定する API の中心差分に与える評価回数の上限。","min":1,"max":10,"step":1,"value":5}
//| cases:
//|   - {"id":"enough-budget","label":"B = 7","description":"上限が中心差分の 2n + 1 = 7 回に足りるので、出力先を指定する API も完了してワンショット関数と同じ値を出力に反映する。","inputs":{"limit":7}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"forms","path":"/rows/0/2","equals":7}
//|       - {"artifact":"forms","path":"/rows/1/1","equals":"Completed"}
//|       - {"artifact":"forms","path":"/rows/1/3","equals":7}
//|       - {"artifact":"forms","path":"/rows/1/6","equals":0}
//|       - {"artifact":"forms","path":"/rows/2/1","equals":"EvaluationLimit"}
//|       - {"artifact":"forms","path":"/rows/2/2","equals":5}
//|       - {"artifact":"forms","path":"/rows/2/3","equals":5}
//|       - {"artifact":"forms","path":"/rows/2/5","equals":"しない"}
//|       - {"artifact":"forms","path":"/rows/2/6","equals":null}
//|       - {"artifact":"forms","path":"/rows/2/7","equals":0}
//|   - case: enough-budget
//|     expect:
//|       - {"artifact":"forms","path":"/rows/2/1","equals":"Completed"}
//|       - {"artifact":"forms","path":"/rows/2/3","equals":7}
//|       - {"artifact":"forms","path":"/rows/2/6","equals":0}
//|       - {"artifact":"forms","path":"/rows/2/7","equals":3}
use core::cell::Cell;
use scioxide_core::{Budget, BudgetKind, ExecutionContext, SciOxideError, SolveBudgets};
use scioxide_differentiate::{
    DerivativeRequest, DerivativeShape, FiniteDifference, FiniteDifferenceWorkspace, gradient,
};

let n = 3;
let x: Vec<f64> = (0..n).map(|i| 0.3 + 0.2 * i as f64).collect();
// 関数を呼んだ回数を、レポートとは別に数える。
let calls = Cell::new(0_usize);
let f = |p: &[f64], y: &mut [f64]| {
    calls.set(calls.get() + 1);
    y[0] = cyclic(p);
    Ok::<(), SciOxideError>(())
};
let one_shot = |p: &[f64]| {
    calls.set(calls.get() + 1);
    Ok(cyclic(p))
};
// ワンショット関数: 値だけが返る。
let reference = gradient(one_shot, &x).map_err(|e| e.to_string())?;
let one_shot_calls = calls.replace(0);
let gap = |v: &[f64]| {
    v.iter()
        .zip(&reference)
        .fold(0.0_f64, |m, (a, b)| m.max((a - b).abs()))
};
// 所有値を返す API: 結果にレポート、値、推定誤差（固定刻みにはない）が入る。
let method = FiniteDifference::default();
let owned = method
    .gradient(&f, &x, None, None)
    .map_err(|e| e.to_string())?;
let owned_calls = calls.replace(0);
// 出力先を指定する API: 作業領域を事前確保し、評価回数の上限 B を付けて呼ぶ。出力は 7 で埋めておく。
let budget = Budget::try_from(limit as usize).map_err(|e| e.to_string())?;
let limited =
    method.with_budgets(SolveBudgets::unbounded().with_limit(BudgetKind::Evaluation, budget));
let request = DerivativeRequest::new(&limited, DerivativeShape::gradient(n));
let mut workspace = FiniteDifferenceWorkspace::workspace(request).map_err(|e| e.to_string())?;
let mut out = vec![7.0; n];
let context = ExecutionContext::sequential();
let report = limited
    .gradient_into(&f, &x, None, None, &mut out, &mut workspace, context)
    .map_err(|e| e.to_string())?;
let borrowed_calls = calls.replace(0);
let changed = out.iter().filter(|&&v| v != 7.0).count();
let written = report.output_available().then_some(&out[..]);
let shown = |available: bool| if available { "する" } else { "しない" };
let reports = [
    (owned.report(), owned_calls, owned.values(), None),
    (&report, borrowed_calls, written, Some(changed)),
];
// (形, 終了理由, 数えた呼び出し, 評価回数, 反復回数, 出力への反映, ワンショット呼び出しとの差, 変わった成分)
let mut rows = vec![(
    "ワンショット関数",
    None,
    one_shot_calls,
    None,
    None,
    "する",
    Some(0.0),
    None,
)];
let forms = ["所有値を返す API", "出力先を指定する API"];
for (form, (r, counted, values, touched)) in forms.into_iter().zip(reports) {
    rows.push((
        form,
        Some(r.termination().to_string()),
        counted,
        Some(r.evaluations()),
        Some(r.iterations()),
        shown(r.output_available()),
        values.map(&gap),
        touched,
    ));
}
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let columns = serde_json::json!([
    { "key": "0", "label": "形" },
    { "key": "1", "label": "終了理由", "nullText": "レポートなし" },
    { "key": "2", "label": "数えた呼び出し [回]", "type": "integer" },
    { "key": "3", "label": "評価回数 [回]", "type": "integer", "nullText": "レポートなし" },
    { "key": "4", "label": "反復回数 [回]", "type": "integer", "nullText": "レポートなし" },
    { "key": "5", "label": "出力への反映" },
    { "key": "6", "label": "gradient との差 [-]", "type": "number", "format": sci3, "nullText": "値なし" },
    { "key": "7", "label": "値が変わった出力の成分 [個]", "type": "integer", "nullText": "配列なし" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "forms" })
);
```

既定の $B = 5$ では、ワンショット関数と所有値を返す API はどちらも $2n + 1 = 7$ 回評価し、同じ値を返す（差は 0）。
関数の中で数えた呼び出し回数はレポートの評価回数に一致し、所有値を返す API の反復回数は座標の数 3 である。
出力先を指定する API は基準点と座標 0、1 の 5 回を評価し、座標 2 の反復に入ったところで 6 回目の評価を拒まれて `EvaluationLimit` で止まる。
反復回数が 3 なのは、座標 2 の反復を数えたあとで評価が拒まれたからである。
このとき値は出力に反映されず、出力の配列は 3 成分とも初めの 7 のままである。
$B = 7$ にすると出力先を指定する API も完了し、所有値を返す API とワンショット関数と同じ値を出力に反映して、出力の 3 成分を書き換える。
$B$ を 6 以下のどの値にしても出力先を指定する API は `EvaluationLimit` で止まり、値を出力に反映しない。

## 種類ごとの評価回数と反復回数

2 つ目のセルは変数の数 $n$ を入力として、四つの種類の所有値を返す API で同じ勾配を求める。
節点を指定する差分法オブジェクト `RelativeDifference` には各座標に変位 $(-0.01, 0, 0.01)$ を与える。
表の「評価回数の式」は前進差分で $n + 1$、中心差分で $2n + 1$、複素ステップ法で $n + 1$、`RelativeDifference` で $3n$、適応差分で $1 + 2 \times (\text{反復回数})$ である。
適応差分の式は $f(\mathbf{x})$ の 1 回の評価と、座標ごとの各準位での中心差分の 2 点の評価を足したものである。

```rust
//| id: differentiate-evaluation-counts
//| ref: differentiate-evaluation-counts
//| title: 種類ごとの評価回数と反復回数
//| run: reactive
//| uses: [differentiate-cyclic-model]
//| crates: [scioxide-core, scioxide-differentiate]
//| inputs:
//|   n: {"type":"range","label":"変数の数 n","description":"評価点の長さ。","min":1,"max":8,"step":1,"value":3}
//| cases:
//|   - {"id":"eight-variables","label":"n = 8","description":"固定刻み、複素ステップ法、節点の差分の評価回数は n の一次式で増え、反復回数は n に等しい。","inputs":{"n":8}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"counts","path":"/rows/0/2","equals":4}
//|       - {"artifact":"counts","path":"/rows/0/4","equals":3}
//|       - {"artifact":"counts","path":"/rows/1/2","equals":7}
//|       - {"artifact":"counts","path":"/rows/2/2","equals":35}
//|       - {"artifact":"counts","path":"/rows/2/4","equals":17}
//|       - {"artifact":"counts","path":"/rows/2/5","equals":35}
//|       - {"artifact":"counts","path":"/rows/3/2","equals":4}
//|       - {"artifact":"counts","path":"/rows/4/2","equals":9}
//|   - case: eight-variables
//|     expect:
//|       - {"artifact":"counts","path":"/rows/0/2","equals":9}
//|       - {"artifact":"counts","path":"/rows/1/2","equals":17}
//|       - {"artifact":"counts","path":"/rows/1/4","equals":8}
//|       - {"artifact":"counts","path":"/rows/3/2","equals":9}
//|       - {"artifact":"counts","path":"/rows/4/2","equals":24}
use core::cell::Cell;
use scioxide_core::{Complex, SciOxideError};
use scioxide_differentiate::{
    AdaptiveDifference, ComplexStep, DerivativeOperation, DifferenceScheme,
    DifferentiationResult, FiniteDifference, NodeDifferenceOptions, RelativeDifference,
};

let n = n as usize;
let x: Vec<f64> = (0..n).map(|i| 0.3 + 0.2 * i as f64).collect();
// 関数を呼んだ回数を、レポートとは別に数える。
let calls = Cell::new(0_usize);
let f = |p: &[f64], y: &mut [f64]| {
    calls.set(calls.get() + 1);
    y[0] = cyclic(p);
    Ok::<(), SciOxideError>(())
};
let g = |z: &[Complex<f64>], y: &mut [Complex<f64>]| {
    calls.set(calls.get() + 1);
    y[0] = cyclic_complex(z);
    Ok::<(), SciOxideError>(())
};
let forward = FiniteDifference::default().with_scheme(DifferenceScheme::Forward);
let offsets = [-0.01, 0.0, 0.01];
let lists = vec![&offsets[..]; n];
let options = NodeDifferenceOptions::default();
let relative = RelativeDifference::new(DerivativeOperation::Gradient, &lists, 1, options)
    .map_err(|e| e.to_string())?;
let mut rows = Vec::new();
let mut record =
    |name, result: Result<DifferentiationResult<f64>, _>, formula: Option<usize>| {
        let result = result.map_err(|e: scioxide_core::SciOxideError| e.to_string())?;
        let r = result.report();
        // 適応差分の勾配は f(x) を 1 回、各準位で座標ごとに 2 回評価する。
        let formula = formula.unwrap_or(1 + 2 * r.iterations());
        let termination = r.termination().to_string();
        let counted = calls.replace(0);
        rows.push((
            name,
            termination,
            counted,
            r.evaluations(),
            r.iterations(),
            formula,
        ));
        Ok::<(), String>(())
    };
record(
    "前進差分",
    forward.gradient(&f, &x, None, None),
    Some(n + 1),
)?;
let central = FiniteDifference::default();
record(
    "中心差分",
    central.gradient(&f, &x, None, None),
    Some(2 * n + 1),
)?;
let adaptive = AdaptiveDifference::default();
record("適応差分", adaptive.gradient(&f, &x, None), None)?;
record(
    "複素ステップ法",
    ComplexStep::default().gradient(&g, &x),
    Some(n + 1),
)?;
record(
    "RelativeDifference",
    relative.evaluate(&f, &x, None),
    Some(3 * n),
)?;
let columns = serde_json::json!([
    { "key": "0", "label": "方法" },
    { "key": "1", "label": "終了理由" },
    { "key": "2", "label": "数えた呼び出し [回]", "type": "integer" },
    { "key": "3", "label": "評価回数 [回]", "type": "integer" },
    { "key": "4", "label": "反復回数 [回]", "type": "integer" },
    { "key": "5", "label": "評価回数の式 [回]", "type": "integer" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "counts" })
);
```

既定の $n = 3$ では、関数の中で数えた呼び出し回数とレポートの評価回数はどの行でも一致し、式の値とも一致する。
前進差分は $n + 1 = 4$ 回、中心差分は $2n + 1 = 7$ 回、複素ステップ法は $n + 1 = 4$ 回で、反復回数はどれも座標の数 3 である。
複素ステップ法の $n + 1$ 回のうち 1 回は基準点の評価で、値が実数であることの検査に使う。
`RelativeDifference` は変位 0 の節点を評価点そのものとして評価するので、評価点を別に評価せず、$3n = 9$ 回になる。
適応差分は 17 回の反復（3 座標で使った準位の数の和）で 35 回評価し、評価回数は $1 + 2 \times 17$ に一致する。
適応差分の終了理由は `Converged` で、ほかの種類の `Completed` と違い、推定誤差が許容誤差を満たしたことを表す。
$n = 8$ にすると、固定刻み、複素ステップ法、`RelativeDifference` の評価回数は式どおり $9$、$17$、$9$、$24$ 回になり、反復回数は 8 になる。
適応差分は 47 回の反復で 95 回評価し、座標あたりの準位の数は $n$ によってほとんど変わらない。

## 九つのワンショット関数

ワンショット関数は既定の設定を持つ手法オブジェクトを一度だけ実行し、導関数の値だけを返して、成功でない終了をエラーにする。
次のセルは九つの関数を、導関数を手で書ける小さな関数に一度ずつ適用し、厳密値との最大誤差を表にする。
スカラーの関数には $f(x) = \sin x$、多変数の関数には $f(\mathbf{x}) = e^{x_0} \sin x_1$ と $\mathbf{F}(\mathbf{x}) = (x_0 x_1, \sin x_0)$ を使い、評価点は $(x_0, 0.7)$、方向は $\mathbf{v} = (1, -1)$ とする。
`physical_difference_derivative` には間隔 $0.01$ の 4 節点 $x_0 \pm 0.01$、$x_0 \pm 0.02$ を渡し、`sparse_jacobian` には対角のヤコビ行列を持つ $(x_0^2, x_1^2)$ と、二つの列に同じ色を付けた彩色を渡す。
厳密値は f64 の固有メソッドで計算した参照値である。

```rust
//| id: differentiate-one-shot-functions
//| ref: differentiate-one-shot-functions
//| title: 九つのワンショット関数と厳密値との誤差
//| run: reactive
//| crates: [scioxide-core, scioxide-differentiate]
//| inputs:
//|   x0: {"type":"range","label":"評価点 x0","description":"スカラーの関数の評価点と、多変数の関数の最初の座標。","min":-3.0,"max":3.0,"step":0.25,"value":1.0}
//| cases:
//|   - {"id":"large-point","label":"x0 = 3","description":"既定の刻みは max(1, |x0|) に比例するので、|x0| が大きいと固定刻みの誤差の大きさが変わるが、どの関数も成功する。","inputs":{"x0":3.0}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"one-shots","path":"/rows/0/3","range":{"max":1e-9}}
//|       - {"artifact":"one-shots","path":"/rows/1/3","range":{"max":1e-6}}
//|       - {"artifact":"one-shots","path":"/rows/2/3","range":{"max":1e-15}}
//|       - {"artifact":"one-shots","path":"/rows/3/3","range":{"max":1e-8}}
//|       - {"artifact":"one-shots","path":"/rows/4/3","range":{"max":1e-9}}
//|       - {"artifact":"one-shots","path":"/rows/5/3","range":{"max":1e-6}}
//|       - {"artifact":"one-shots","path":"/rows/6/3","range":{"max":1e-9}}
//|       - {"artifact":"one-shots","path":"/rows/7/3","range":{"max":1e-9}}
//|       - {"artifact":"one-shots","path":"/rows/8/3","range":{"max":1e-8}}
//|       - {"artifact":"one-shots","path":"/rows/5/2","equals":4}
//|   - case: large-point
//|     expect:
//|       - {"artifact":"one-shots","path":"/rows/0/3","range":{"max":1e-9}}
//|       - {"artifact":"one-shots","path":"/rows/2/3","range":{"max":1e-15}}
//|       - {"artifact":"one-shots","path":"/rows/8/3","range":{"max":1e-8}}
use scioxide_core::{
    ColoringKind, ColoringSchedule, Complex, SciOxideError, RealScalar, StructuralPattern,
};
use scioxide_differentiate::{
    complex_step_derivative, derivative, gradient, hessian, jacobian, jvp,
    physical_difference_derivative, second_derivative, sparse_jacobian,

let sine = |t: f64| Ok::<f64, SciOxideError>(RealScalar::sin(t));
let surface = |p: &[f64]| Ok::<f64, SciOxideError>(RealScalar::exp(p[0]) * RealScalar::sin(p[1]));
let map = |p: &[f64], y: &mut [f64]| {
    y[0] = p[0] * p[1];
    y[1] = RealScalar::sin(p[0]);
    Ok::<(), SciOxideError>(())
};
let x = [x0, 0.7];
let v = [1.0, -1.0];
// 参照値（f64 の固有メソッド）。
let (e, s, c) = (x0.exp(), x[1].sin(), x[1].cos());
let jacobian_exact = [x[1], x0, x0.cos(), 0.0];
let max_error = |values: &[f64], exact: &[f64]| {
    values
        .iter()
        .zip(exact)
        .map(|(a, b)| (a - b).abs())
        .fold(0.0, f64::max)
};
let nodes = [x0 - 0.02, x0 - 0.01, x0 + 0.01, x0 + 0.02];
let pattern =
    StructuralPattern::new(2, 2, vec![0, 1, 2], vec![0, 1]).map_err(|e| e.to_string())?;
let schedule = ColoringSchedule::new(pattern, ColoringKind::DerivativeColumns, vec![0, 0])
    .map_err(|e| e.to_string())?;
let squares = |p: &[f64], y: &mut [f64]| {
    y[0] = p[0] * p[0];
    y[1] = p[1] * p[1];
    Ok::<(), SciOxideError>(())
};
let values: Vec<(&str, &str, Vec<f64>, Vec<f64>)> = vec![
    (
        "derivative",
        "中心差分",
        vec![derivative(sine, x0).map_err(|e| e.to_string())?],
        vec![x0.cos()],
    ),
    (
        "second_derivative",
        "中心差分",
        vec![second_derivative(sine, x0).map_err(|e| e.to_string())?],
        vec![-x0.sin()],
    ),
    (
        "complex_step_derivative",
        "複素ステップ法",
        vec![
            complex_step_derivative(|z: Complex<f64>| Ok(z.sin()), x0)
                .map_err(|e| e.to_string())?,
        ],
        vec![x0.cos()],
    ),
    (
        "physical_difference_derivative",
        "4 節点の重み",
        vec![physical_difference_derivative(sine, x0, &nodes).map_err(|e| e.to_string())?],
        vec![x0.cos()],
    ),
    (
        "gradient",
        "中心差分",
        gradient(surface, &x).map_err(|e| e.to_string())?,
        vec![e * s, e * c],
    ),
    (
        "hessian",
        "中心差分",
        hessian(surface, &x).map_err(|e| e.to_string())?,
        vec![e * s, e * c, e * c, -e * s],
    ),
    (
        "jacobian",
        "中心差分",
        jacobian(map, &x, 2).map_err(|e| e.to_string())?,
        jacobian_exact.to_vec(),
    ),
    (
        "jvp",
        "中心差分",
        jvp(map, &x, &v, 2).map_err(|e| e.to_string())?,
        vec![x[1] - x0, x0.cos()],
    ),
    (
        "sparse_jacobian",
        "彩色と適応差分",
        sparse_jacobian(squares, &x, &schedule).map_err(|e| e.to_string())?,
        vec![2.0 * x0, 2.0 * x[1]],
    ),
];
let rows: Vec<(&str, &str, usize, f64)> = values
    .iter()
    .map(|(name, method, got, exact)| (*name, *method, got.len(), max_error(got, exact)))
    .collect();
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let columns = serde_json::json!([
    { "key": "0", "label": "ワンショット関数" },
    { "key": "1", "label": "内部の方法" },
    { "key": "2", "label": "成分の数", "type": "integer" },
    { "key": "3", "label": "厳密値との最大誤差 [-]", "type": "number", "format": sci2 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "one-shots" })
);
```

既定の $x_0 = 1$ では、九つの関数がどれも成功し、一階の固定刻みの差分（`derivative`、`gradient`、`jacobian`、`jvp`）の誤差は $10^{-12}$ から $10^{-11}$ の大きさで、中心差分の目安 $\varepsilon^{2/3} \approx 3.7 \times 10^{-11}$ 以下である。
二階の差分を使う `second_derivative` と `hessian` の誤差は $1.8 \times 10^{-9}$ と $5.1 \times 10^{-8}$ で、二階の中心差分の目安 $\sqrt{\varepsilon} \approx 1.5 \times 10^{-8}$ の前後にある。
`complex_step_derivative` は引き算を使わないので、誤差は 0 である。
`physical_difference_derivative` の 4 節点の公式は 4 次の精度を持ち、誤差 $1.8 \times 10^{-10}$ は主項 $h^4 \lvert f^{(5)}(x_0) \rvert / 30 = 10^{-8} \cos 1 / 30$ と一致する。
`sparse_jacobian` の関数は各成分が二次式なので中心差分に打ち切り誤差がなく、誤差は丸めの大きさ $4.4 \times 10^{-16}$ にとどまる。
$x_0 = 3$ にすると、既定の刻みが $\max(1, \lvert x_0 \rvert)$ に比例して 3 倍になり、`gradient` の誤差は $7.4 \times 10^{-10}$、`hessian` の誤差は $3.1 \times 10^{-7}$ に増える。
どの関数も推定誤差と終了理由を返さないので、精度を確かめたいときや失敗の理由を読みたいときは、同じ計算を所有値を返す API で呼ぶ。

## まとめ

三つの呼び出しの形は同じ設定なら同じ値を返し、違いはレポートを読めるか、作業領域と実行コンテキストを渡せるかにある。
評価回数の上限に達した出力先を指定する API は `EvaluationLimit` を返し、出力の配列を書き換えないので、終了理由を読んでから値を使うかどうかを決められる。
レポートの評価回数は関数を実際に呼んだ回数に一致するので、関数を呼ぶ計算コストを見積もるのにそのまま使える。
勾配の評価回数は固定刻みで $n + 1$ か $2n + 1$、複素ステップ法で $n + 1$、節点の差分で節点の総数、適応差分で $1 + 2 \times (\text{反復回数})$ になり、適応差分の計算コストだけが関数の性質で変わる。
ワンショット関数は既定の設定で方法ごとの精度の目安に合う値を返すが、推定誤差も終了理由も返さないので、精度を確かめるときは所有値を返す API を使う。
