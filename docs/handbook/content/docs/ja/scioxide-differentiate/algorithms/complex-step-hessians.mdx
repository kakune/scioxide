[複素ステップ微分と解析的拡張](../complex-step/) の公式 $\operatorname{Im} f(x + ih)/h$ は、引き算をせずに一階導関数を求める。
このページでは同じ考え方を二階導関数、ヘッセ行列、方向微分に広げる。
二階導関数とヘッセ行列は、複素ステップ法の一階導関数に実数の節点での差分を重ねて求めるので、精度は一階より落ちる。
方向微分は一階の量なので、方向に沿った 1 回の複素評価で一階と同じように求まる。
関数が実関数の解析的拡張であるという前提と基準点の検査は、一階と同じである（[解析的拡張の宣言](oxref:differentiate-analytic-extension)）。
記号は [アルゴリズムの共通仕様と構成](oxref:differentiate-notation) に従い、$\varepsilon = 2^{-52}$ は倍精度の計算機イプシロンである。

## 二階導関数とヘッセ行列

実部を使う二階の公式 $f''(x) \approx 2(f(x) - \operatorname{Re} f(x + ih))/h^2$ は引き算を含み、桁落ちの問題が戻る。
`scioxide-differentiate` は、複素ステップ法の一階導関数 $g(t) = \operatorname{Im} f(t + i h)/h$ に、実数の節点での一階導関数の差分公式を当てて二階導関数を作る。

$$
f''(x) \approx \sum_a w_a \, g(x + \Delta_a) = \sum_a w_a \, \frac{\operatorname{Im} f(x + \Delta_a + i h)}{h}.
$$

ここで $\Delta_a$ は実数の節点の変位、$w_a$ はその節点での一階導関数の差分の重みである。
3 点の中心の変位 $\{-\Delta, 0, \Delta\}$ では重みは $\{-1/(2\Delta), 0, 1/(2\Delta)\}$ で、$g$ の中心差分の展開から打ち切り誤差は $\Delta^2 f^{(4)}(x)/6 + \Delta^4 f^{(6)}(x)/120 + \cdots$ になる。
$g$ の値は $\varepsilon \lvert f' \rvert$ 程度の丸め誤差を持つので、総誤差は次の式で見積もれる。

$$
E(\Delta) \approx \frac{\Delta^2}{6} \lvert f^{(4)}(x) \rvert + \frac{\varepsilon \lvert f'(x) \rvert}{\Delta}.
$$

見積もりは $\Delta_* = (3 \varepsilon \lvert f' \rvert / \lvert f^{(4)} \rvert)^{1/3}$、つまり $\varepsilon^{1/3}$ 程度で最小になり、最小値は $\varepsilon^{2/3}$ 程度である。
実数の 3 点の二階差分の見積もりは $\Delta^2 \lvert f^{(4)} \rvert / 12 + 4 \varepsilon \lvert f \rvert / \Delta^2$ で、$\Delta = (48 \varepsilon \lvert f \rvert / \lvert f^{(4)} \rvert)^{1/4}$、つまり $\varepsilon^{1/4}$ 程度で最小になり、最小値は $\varepsilon^{1/2}$ 程度である。
複素ステップ法と実数の節点の組み合わせはそれより良いが、一階のような $\varepsilon$ 程度の精度には届かない。

多変数ではヘッセ行列の要素 $(i, j)$ を、座標 $i$ の虚数方向の摂動による一階導関数 $\partial f / \partial x_i$ に、座標 $j$ の実数の節点のステンシルを当てて作る。
$i = j$ では 2 つの摂動が同じ座標に掛かり、上の一変数の式になる。

## 実数の節点を指定する差分法オブジェクトと Plan

ライブラリは実数の節点を選ばないので、呼び出し側が明示する。
[`RelativeComplexStep`](https://docs.rs/scioxide-differentiate/0.1.0/scioxide_differentiate/struct.RelativeComplexStep.html)`::new(&[&offsets, …], method)` は、評価のたびに $x_j + \Delta$ に置く変位を座標ごとに持つ節点を指定する差分法オブジェクトで、`evaluate(f, x, bounds)` で評価する。
[`ComplexStepPlan`](https://docs.rs/scioxide-differentiate/0.1.0/scioxide_differentiate/struct.ComplexStepPlan.html)`::new(point, &[&nodes, …], method)` は、評価点と節点の位置を作成時に固定する Plan で、`evaluate(f, bounds)` で評価する。
`method` は虚数の刻みと実行の設定を与える `ComplexStep` で、刻みと方向が 0 のときの扱いは作成時に検査する。
どちらも軸ごとに 2 個以上の異なる節点を要求し、足りなければ `InvalidInput`（`OutOfRange`）、重なった節点は `InvalidInput`（`Inconsistent`）になる。
重みは作成時に Fornberg の方法で計算し、`RelativeComplexStep` は丸めたあとの変位から評価のたびに計算し直す。
どちらもヘッセ行列を計算し、スカラー関数の二階導関数は $1 \times 1$ のヘッセ行列として求める。
`bounds` を渡すと、評価点とすべての節点が区間の中にあることを関数を呼ぶ前に検査し、外にあれば `InvalidInput` を返す。
`RelativeComplexStep` は、評価点に変位を足した節点が有限でないときや、丸めで別の節点に重なるときも、関数を呼ぶ前に `InvalidInput`（`x`、`UnsupportedConfiguration`）を返す。
出力先を指定する API `evaluate_into` と作業領域はほかの Plan と同じように使う（[Plan・要件・作業領域の再利用](../plans-workspaces-and-reports/)）。
推定誤差は返さず、上限で止まらなければ終了理由は `Completed` で、精度を主張しない。

どちらもすべての順序対 $(i, j)$ を計算し、混合項は $(i, j)$ と $(j, i)$ の平均をとって対称にする。
固定刻みの差分が上三角を計算して鏡映するのとは異なる。
節点が評価点に一致する標本 $\partial f / \partial x_i (\mathbf{x})$ は座標 $i$ ごとに 1 回だけ評価する。
各軸の節点が評価点を含み、軸 $j$ が $k_j$ 点を持つとき、評価回数は基準点の検査の 1 回を含めて $1 + n\bigl(\sum_j k_j - (n - 1)\bigr)$ 回である。
評価点を含まない軸があると、評価回数はこれより多く、最大で $1 + n \sum_j k_j$ 回になる。
スカラー関数の二階導関数を 1 軸 $k$ 点の `RelativeComplexStep` で求めると、評価回数は $1 + k$ 回である。

## 二階導関数の誤差の実測

次のセルは $f(x) = e^x \sin x$ の二階導関数を、1 軸の `RelativeComplexStep` の 3 点の変位 $\{-\Delta, 0, \Delta\}$ で、$\Delta$ を $10^{-1}$ から $10^{-10}$ まで変えて計算する。
比較として、同じ $\Delta$ の実数の 3 点の二階差分を `FiniteDifference::second_derivative` で計算する。
参照値は $f^{(n)}(x) = 2^{n/2} e^x \sin(x + n\pi/4)$ を f64 で計算した値である。
表は各方法の評価回数、最小の誤差とそれを与えた $\Delta$、上の見積もりの最小点 $\Delta_*$ を示す。
誤差の曲線と見積もりは、次のセルが図に描く。

```rust
//| id: differentiate-complex-second-derivative
//| ref: differentiate-complex-second-derivative
//| title: 複素ステップ法と実節点による二階導関数と実数の二階差分の誤差
//| run: reactive
//| crates: [scioxide-core, scioxide-differentiate]
//| exports: [curves]
//| inputs:
//|   x0: {"type":"range","label":"評価点 x₀","min":-1.0,"max":1.0,"step":0.25,"value":0.5}
//| cases:
//|   - {"id":"vanishing-fourth","label":"x₀ = 0","description":"f⁽⁴⁾(0) = 0 で打ち切り誤差の主項が消え、Δ⁴ の項が残る。","inputs":{"x0":0.0}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"second","path":"/rows/0/1","equals":4}
//|       - {"artifact":"second","path":"/rows/0/2","range":{"max":1e-9}}
//|       - {"artifact":"second","path":"/rows/1/1","equals":3}
//|       - {"artifact":"second","path":"/rows/1/2","range":{"min":1e-11,"max":1e-6}}
//|       - {"artifact":"second","path":"/rows/0/4","approx":{"value":7.7825e-6,"rtol":1e-3}}
//|   - case: vanishing-fourth
//|     expect:
//|       - {"artifact":"second","path":"/rows/0/4","equals":null}
//|       - {"artifact":"second","path":"/rows/1/4","equals":null}
//|       - {"artifact":"second","path":"/rows/0/2","range":{"max":1e-10}}
use scioxide_core::{Complex, SciOxideError, RealScalar};
use scioxide_differentiate::{
    ComplexStep, DifferenceScheme, DifferenceStep, FiniteDifference, RelativeComplexStep,
};

let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
// 参照値: f^{(n)}(x) = 2^{n/2} e^x sin(x + nπ/4) を n ごとに展開した式（f64 の固有メソッド）。
let derivative = |n: i32, x: f64| {
    let (s, c) = x.sin_cos();
    x.exp()
        * match n {
            0 => s,
            1 => s + c,
            2 => 2.0 * c,
            4 => -4.0 * s,
            _ => -8.0 * c,
        }
};
let exact = derivative(2, x0);
let complex = |z: &[Complex<f64>], y: &mut [Complex<f64>]| {
    y[0] = z[0].exp() * z[0].sin();
    Ok::<(), SciOxideError>(())
};
let real = |t: f64| Ok::<f64, SciOxideError>(RealScalar::exp(t) * RealScalar::sin(t));
let method = ComplexStep::default();
// 曲線: 複素ステップ法と実節点、実数の二階差分、それぞれの誤差の見積もり。
let mut curves: Vec<Vec<[f64; 2]>> = vec![Vec::new(); 4];
let mut best = [(f64::INFINITY, 0.0, 0_usize); 2];
for k in 2..=20 {
    let delta = 10.0_f64.powf(-0.5 * f64::from(k));
    let offsets = [-delta, 0.0, delta];
    let second = RelativeComplexStep::new(&[&offsets], method).map_err(|e| e.to_string())?;
    let r = second
        .evaluate(complex, &[x0], None)
        .map_err(|e| e.to_string())?;
    let fd = FiniteDifference::default()
        .with_scheme(DifferenceScheme::Central)
        .with_step(DifferenceStep::absolute(delta).map_err(|e| e.to_string())?);
    let q = fd.second_derivative(real, x0).map_err(|e| e.to_string())?;
    let observed = [
        r.values().ok_or("二階導関数が公開されない")?[0],
        q.values().ok_or("二階差分が出力に反映されない")?[0],
    ];
    let evaluations = [r.report().evaluations(), q.report().evaluations()];
    // 見積もりの丸めの項は節点での |f′| と |f| の最大値で測る。
    let nodes = [x0 - delta, x0, x0 + delta];
    let slope = nodes
        .iter()
        .map(|&t| derivative(1, t).abs())
        .fold(0.0, f64::max);
    let size = nodes
        .iter()
        .map(|&t| derivative(0, t).abs())
        .fold(0.0, f64::max);
    let (d2, d4) = (delta * delta, delta.powi(4));
    let models = [
        (d2 * derivative(4, x0) / 6.0 + d4 * derivative(6, x0) / 120.0).abs()
            + f64::EPSILON * slope / delta,
        (d2 * derivative(4, x0) / 12.0 + d4 * derivative(6, x0) / 360.0).abs()
            + 4.0 * f64::EPSILON * size / d2,
    ];
    for lane in 0..2 {
        let error = (observed[lane] - exact).abs();
        if error > 0.0 {
            curves[lane].push([delta, error]);
        }
        curves[lane + 2].push([delta, models[lane]]);
        if error < best[lane].0 {
            best[lane] = (error, delta, evaluations[lane]);
        }
    }
}
// 見積もりの最小点（打ち切り誤差の主項だけで計算。f⁽⁴⁾ = 0 なら定義されない）。
let fourth = derivative(4, x0).abs();
let optimum = [
    (fourth > 0.0).then(|| (3.0 * f64::EPSILON * derivative(1, x0).abs() / fourth).cbrt()),
    (fourth > 0.0).then(|| (48.0 * f64::EPSILON * derivative(0, x0).abs() / fourth).powf(0.25)),
];
let names = ["複素ステップ法と実節点", "実数の二階差分"];
let rows: Vec<_> = names
    .iter()
    .zip(best)
    .zip(optimum)
    .map(|((name, (error, delta, evaluations)), star)| (*name, evaluations, error, delta, star))
    .collect();
let columns = serde_json::json!([
    { "key": "0", "label": "方法" },
    { "key": "1", "label": "評価回数 [回]", "type": "integer" },
    { "key": "2", "label": "最小の誤差 [-]", "type": "number", "format": sci3 },
    { "key": "3", "label": "その Δ [-]", "type": "number", "format": sci3 },
    { "key": "4", "label": "見積もりの最小点 Δ* [-]", "type": "number", "format": sci3, "nullText": "なし" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "second" })
);
export!(curves, curves);
```

既定の $x_0 = 0.5$ では、複素ステップ法と実節点の組み合わせ（評価 $1 + 3 = 4$ 回）は $\Delta = 10^{-5}$ で最小の誤差 $6.5 \times 10^{-11}$ になり、見積もりの最小点 $\Delta_* = 7.8 \times 10^{-6}$ と合う。
実数の二階差分（3 回）で最小になった誤差 $4.5 \times 10^{-10}$（$\Delta = 10^{-4}$）は、打ち切り誤差と丸め誤差の符号が打ち消し合った点の値で、同じ $\Delta$ の見積もり $7.3 \times 10^{-8}$ よりずっと小さい。
$x_0 = 0$ では $f^{(4)}(0) = 0$ なので打ち切り誤差の主項が消えて $\Delta^4$ の項が残り、表の $\Delta_*$ は定義されない。
このとき $f(0) = 0$ で実数の二階差分の丸めの項も小さく、どちらの方法も $\Delta = 10^{-3}$ で $10^{-13}$ 程度以下の誤差になる。

次のセルは、上のセルが計算した誤差を変位 $\Delta$ に対して両対数で描く。
記号つきの線が実際の誤差、破線が上の 2 つの見積もり（打ち切り誤差は $\Delta^4$ の項まで）である。
誤差がちょうど 0 になった点は対数軸に描けないので除く。

```rust
//| id: differentiate-complex-second-chart
//| ref: differentiate-complex-second-chart
//| title: 実節点の変位による二階導関数の誤差と見積もり
//| run: reactive
//| crates: [scioxide-core]
//| dependsOn:
//|   sweep: differentiate-complex-second-derivative
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"errors","path":"/spec/series/0/points/0/1","approx":{"value":5.28e-3,"rtol":1e-2}}
//|       - {"artifact":"errors","path":"/spec/series/1/points/0/1","approx":{"value":2.64e-3,"rtol":1e-2}}

    serde_json::from_value(sweep["curves"].clone()).map_err(|e| e.to_string())?;

    "複素ステップ法と実節点",
    "実数の二階差分",
    "見積もり（複素）",
    "見積もり（実数）",
];
let dashed = serde_json::json!({ "lineType": "dashed", "showSymbol": false });
let series: Vec<_> = names
    .iter()
    .zip(&curves)
    .enumerate()
    .map(|(i, (name, points))| {
        let style = if i < 2 {
            serde_json::json!({ "showSymbol": true })
        } else {
            dashed.clone()
        };
        serde_json::json!({ "name": name, "points": points, "style": style })
    })
    .collect();
emit_chart!(
    serde_json::json!({
        "kind": "line",
        "dataZoom": true,
        "tooltip": true,
        "series": series,
        "xLabel": "実節点の変位 Δ [-]",
        "yLabel": "二階導関数の絶対誤差 [-]",
        "xType": "log",
        "yType": "log"
    }),
    metadata = serde_json::json!({ "id": "errors" })
);
```

どちらの方法も $\Delta \ge 10^{-3}$ では打ち切り誤差が支配し、破線の見積もりと重なる。
$\Delta = 10^{-1}$ の誤差 $5.3 \times 10^{-3}$ と $2.6 \times 10^{-3}$ は、打ち切り誤差の主項 $\Delta^2 \lvert f^{(4)} \rvert / 6$ と $\Delta^2 \lvert f^{(4)} \rvert / 12$ の比 2 を示す。
複素ステップ法と実節点の誤差は、$\Delta$ を $3 \times 10^{-7}$ から $3 \times 10^{-5}$ まで変えても $10^{-9}$ を下回り、変位の選び方に対して鈍い。
実数の二階差分は、$\Delta$ が見積もりの最小点 $2.3 \times 10^{-4}$ から離れると誤差が急に増え、$\Delta = 10^{-6}$ で $1.2 \times 10^{-4}$ になる。
複素ステップ法と実節点の丸めの項は $1/\Delta$、実数の二階差分の丸めの項は $1/\Delta^2$ で増えるので、小さい $\Delta$ ほど差が開く。

## ヘッセ行列の評価回数

次のセルは $g(x, y) = e^x \sin y$ のヘッセ行列を点 $(0.5, 1.5)$ で、2 軸の `RelativeComplexStep` と、同じ節点を固定した `ComplexStepPlan` で計算する。
各軸の節点は評価点を含む 3 点（変位 $\pm 10^{-5}$）か 5 点（変位 $\pm 10^{-3}$、$\pm 2 \times 10^{-3}$）である。
表は評価回数を上の公式と比べ、手で求めたヘッセ行列との最大絶対誤差と、対称性の差 $\lvert H_{12} - H_{21} \rvert$ を示す。

```rust
//| id: differentiate-complex-hessian-jvp
//| ref: differentiate-complex-hessian-jvp
//| title: 複素ステップ法のヘッセ行列の評価回数と対称性
//| run: reactive
//| crates: [scioxide-core, scioxide-differentiate]
//| inputs:
//|   stencil: {"type":"select","label":"各軸の実節点","options":["3 点、Δ = 1e-5","5 点、Δ = 1e-3"],"value":"3 点、Δ = 1e-5"}
//| cases:
//|   - {"id":"five-point","label":"5 点、Δ = 10⁻³","description":"節点を増やすと評価回数は増え、打ち切り誤差の次数が上がって誤差が下がる。","inputs":{"stencil":"5 点、Δ = 1e-3"}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"counts","path":"/rows/0/1","equals":11}
//|       - {"artifact":"counts","path":"/rows/0/2","equals":11}
//|       - {"artifact":"counts","path":"/rows/0/3","range":{"max":1e-9}}
//|       - {"artifact":"counts","path":"/rows/0/4","equals":0}
//|       - {"artifact":"counts","path":"/rows/1/1","equals":11}
//|       - {"artifact":"counts","path":"/rows/1/4","equals":0}
//|   - case: five-point
//|     expect:
//|       - {"artifact":"counts","path":"/rows/0/1","equals":19}
//|       - {"artifact":"counts","path":"/rows/1/1","equals":19}
//|       - {"artifact":"counts","path":"/rows/0/3","range":{"max":1e-11}}
use scioxide_core::{Complex, SciOxideError};
use scioxide_differentiate::{ComplexStep, ComplexStepPlan, RelativeComplexStep};

let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let offsets: Vec<f64> = match stencil.as_str() {
    "5 点、Δ = 1e-3" => vec![-2e-3, -1e-3, 0.0, 1e-3, 2e-3],
    _ => vec![-1e-5, 0.0, 1e-5],
};
let p = [0.5_f64, 1.5];
let method = ComplexStep::default();
// 参照値: g = e^x sin y のヘッセ行列（f64 の固有メソッド）。
let (e, (s, c)) = (p[0].exp(), p[1].sin_cos());
let exact = [e * s, e * c, e * c, -e * s];
let g = |z: &[Complex<f64>], y: &mut [Complex<f64>]| {
    y[0] = z[0].exp() * z[1].sin();
    Ok::<(), SciOxideError>(())
};
// 評価回数の公式 1 + n(Σ k_j − (n − 1))、n = 2、各軸 k 点。
let k = offsets.len();
let formula = 1 + 2 * (2 * k - 1);
let relative = RelativeComplexStep::new(&[offsets.as_slice(), offsets.as_slice()], method)
    .map_err(|e| e.to_string())?;
let nodes: Vec<Vec<f64>> = p
    .iter()
    .map(|&x| offsets.iter().map(|o| x + o).collect())
    .collect();
let plan = ComplexStepPlan::new(&p, &[nodes[0].as_slice(), nodes[1].as_slice()], method)
    .map_err(|e| e.to_string())?;
let hessians = [
    ("RelativeComplexStep", relative.evaluate(g, &p, None)),
    ("ComplexStepPlan", plan.evaluate(g, None)),
];
let mut rows = Vec::new();
for (name, result) in hessians {
    let r = result.map_err(|e| e.to_string())?;
    let h = r.values().ok_or("ヘッセ行列が出力に反映されない")?;
    let error = h
        .iter()
        .zip(exact)
        .map(|(a, b)| (a - b).abs())
        .fold(0.0, f64::max);
    rows.push((
        name,
        r.report().evaluations(),
        formula,
        error,
        (h[1] - h[2]).abs(),
    ));
}
let columns = serde_json::json!([
    { "key": "0", "label": "方法" },
    { "key": "1", "label": "評価回数 [回]", "type": "integer" },
    { "key": "2", "label": "公式の評価回数 [回]", "type": "integer" },
    { "key": "3", "label": "最大絶対誤差 [-]", "type": "number", "format": sci3 },
    { "key": "4", "label": "対称性の差 [-]", "type": "number", "format": sci3 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "counts" })
);
```

既定の 3 点の節点では、評価回数は `RelativeComplexStep` と `ComplexStepPlan` のどちらも公式どおり $1 + 2 \times (6 - 1) = 11$ 回で、誤差も同じ $2.7 \times 10^{-11}$ になる。
混合項は 2 つの順序の平均をとるので、対称性の差はちょうど 0 になる。
5 点の節点（$\Delta = 10^{-3}$）にすると、評価回数は $1 + 2 \times (10 - 1) = 19$ 回に増え、打ち切り誤差の次数が 2 から 4 に上がって誤差は $2.8 \times 10^{-13}$ に下がる。

## 方向微分

ベクトル値関数 $\mathbf{F}$ の方向 $\mathbf{v}$ の方向微分 $\mathbf{J}\mathbf{v}$ は、一変数の関数 $\boldsymbol{\varphi}(t) = \mathbf{F}(\mathbf{x} + t \mathbf{v})$ の $t = 0$ での導関数である。
$\boldsymbol{\varphi}$ に一階の公式を当てると、方向に沿った虚数の摂動による 1 回の複素評価から求まる。

$$
\mathbf{J}(\mathbf{x}) \mathbf{v} = \frac{\operatorname{Im} \mathbf{F}(\mathbf{x} + i h \mathbf{v})}{h} + \frac{h^2}{6} \boldsymbol{\varphi}'''(0) + O(h^4).
$$

引き算がないので、一階導関数と同じく刻みを小さくしても桁落ちは起きない。

`ComplexStep` の `jvp(f, x, v, m)` と出力先を指定する API `jvp_into` は方向を評価の引数として受け取る。
刻みは `ComplexStep` の刻み $h$（既定は $\varepsilon$）をそのまま使い、座標 $i$ の虚部の摂動は $h v_i$ になる。
実数の差分による方向微分（[方向微分の差分公式](oxref:differentiate-jvp-formula)）と違い、刻みを方向の大きさで割らない。
評価回数は基準点の検査の 1 回と摂動の 1 回の 2 回である。
0 でない成分 $v_i$ について $h v_i$ が 0 にアンダーフローするか有限でなくなるときは、関数を呼ぶ前に `InvalidInput`（`direction`、`UnsupportedConfiguration`）で拒む。
$h v_i$ が非正規化数になる方向は受け付けて関数を評価するが、返った虚部 $\operatorname{Im} \mathbf{F}$ の 0 でない成分が非正規化数になれば、一階導関数と同じく値を出力に反映せずに `NumericalInstability`（`Underflow`）を返す（[虚数方向の摂動](oxref:differentiate-complex-perturbation)）。

方向がちょうど 0 のときの扱いは `with_zero_direction` に渡す `ZeroDirectionPolicy` で選ぶ（[方向が 0 のとき](oxref:differentiate-zero-direction)）。
`MathematicalZero`（既定）は関数を呼ばずに 0 を返し、`ValidateBase` は基準点を 1 回評価して値が実数であることを検査してから 0 を返す。
`ZeroDirectionPolicy` を既定以外にした `ComplexStep` を方向微分以外の演算に使うと、`InvalidInput`（`Inconsistent`）になる。

次のセルは $\mathbf{F}(x, y) = (e^{x} y^2, \sin(x y))$ の方向微分を、点 $(0.5, 1.5)$ で `ComplexStep::jvp` によって求め、手で求めた $\mathbf{J}\mathbf{v}$ と比べる。
方向は $(1, -2)$ を入力で選んだ倍率だけ縮めたものと、2 つの `ZeroDirectionPolicy` での 0 の方向である。
関数を呼んだ回数をセルの中で数え、レポートの評価回数と並べる。
相対誤差は成分ごとの誤差の最大値を、参照値の各成分の絶対値のうち最大のもので割った値である（方向が 0 なら絶対誤差）。

```rust
//| id: differentiate-complex-jvp
//| ref: differentiate-complex-jvp
//| title: 複素ステップ法の方向微分と方向の大きさ、方向が 0 のときの評価回数
//| run: reactive
//| crates: [scioxide-core, scioxide-differentiate]
//| inputs:
//|   direction: {"type":"select","label":"方向 v","options":["(1, −2)","(1, −2) × 10⁻³⁰⁰","(1, −2) × 10⁻³¹⁰"],"value":"(1, −2)"}
//| cases:
//|   - {"id":"subnormal","label":"v = (1, −2) × 10⁻³⁰⁰","description":"虚部の摂動 hv が非正規化数になり、関数は 2 回呼ばれるが、虚部の応答も非正規化数になるので Underflow のエラーになる。","inputs":{"direction":"(1, −2) × 10⁻³⁰⁰"}}
//|   - {"id":"underflow","label":"v = (1, −2) × 10⁻³¹⁰","description":"hv が 0 にアンダーフローするので、関数を呼ぶ前に拒まれる。","inputs":{"direction":"(1, −2) × 10⁻³¹⁰"}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"jvp","path":"/rows/0/1","equals":2}
//|       - {"artifact":"jvp","path":"/rows/0/2","equals":2}
//|       - {"artifact":"jvp","path":"/rows/0/3","range":{"max":1e-15}}
//|       - {"artifact":"jvp","path":"/rows/1/2","equals":0}
//|       - {"artifact":"jvp","path":"/rows/2/2","equals":1}
//|   - case: subnormal
//|     expect:
//|       - {"artifact":"jvp","path":"/rows/0/1","equals":null}
//|       - {"artifact":"jvp","path":"/rows/0/2","equals":2}
//|       - {"artifact":"jvp","path":"/rows/0/4","equals":"NumericalInstability（Underflow）"}
//|   - case: underflow
//|     expect:
//|       - {"artifact":"jvp","path":"/rows/0/2","equals":0}
//|       - {"artifact":"jvp","path":"/rows/0/4","equals":"InvalidInput（direction、UnsupportedConfiguration）"}
use scioxide_core::{Complex, SciOxideError, SciOxideErrorView};
use scioxide_differentiate::{ComplexStep, ZeroDirectionPolicy};

let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let scale = match direction.as_str() {
    "(1, −2) × 10⁻³⁰⁰" => 1e-300,
    "(1, −2) × 10⁻³¹⁰" => 1e-310,
    _ => 1.0,
};
let p = [0.5_f64, 1.5];
let calls = std::cell::Cell::new(0_usize);
// F(x, y) = (e^x y², sin(xy))。呼んだ回数を数える。
let field = |z: &[Complex<f64>], y: &mut [Complex<f64>]| {
    calls.set(calls.get() + 1);
    y[0] = z[0].exp() * z[1] * z[1];
    y[1] = (z[0] * z[1]).sin();
    Ok::<(), SciOxideError>(())
};
let v = [scale, -2.0 * scale];
// 参照値: J v = (e^x y² v₀ + 2 e^x y v₁, cos(xy)(y v₀ + x v₁))（f64 の固有メソッド）。
let (e, cxy) = (p[0].exp(), (p[0] * p[1]).cos());
let exact = [
    e * p[1] * p[1] * v[0] + 2.0 * e * p[1] * v[1],
    cxy * (p[1] * v[0] + p[0] * v[1]),
];
let directions = [
    ("方向 v", v, ZeroDirectionPolicy::MathematicalZero, exact),
    (
        "方向 0（MathematicalZero）",
        [0.0; 2],
        ZeroDirectionPolicy::MathematicalZero,
        [0.0; 2],
    ),
    (
        "方向 0（ValidateBase）",
        [0.0; 2],
        ZeroDirectionPolicy::ValidateBase,
        [0.0; 2],
    ),
];
let mut rows = Vec::new();
for (name, direction, policy, reference) in directions {
    calls.set(0);
    let method = ComplexStep::default().with_zero_direction(policy);
    let (evaluations, error, failure) = match method.jvp(field, &p, &direction, 2) {
        Ok(r) => {
            let jv = r.values().ok_or("方向微分が出力に反映されない")?;
            let size = reference[0].abs().max(reference[1].abs());
            let gap = (jv[0] - reference[0])
                .abs()
                .max((jv[1] - reference[1]).abs());
            let error = if size > 0.0 { gap / size } else { gap };
            (Some(r.report().evaluations()), Some(error), None)
        }
        // 方向の検査による拒否と虚部のアンダーフローだけを表に残し、ほかのエラーはセルのエラーにする。
        Err(e) => match e.view() {
            SciOxideErrorView::InvalidInput {
                argument, reason, ..
            } => {
                let detail = format!("InvalidInput（{}、{reason:?}）", argument.as_str());
                (None, None, Some(detail))
            }
            SciOxideErrorView::NumericalInstability { issue, .. } => (
                None,
                None,
                Some(format!("NumericalInstability（{issue:?}）")),
            ),
            _ => return Err(e.to_string()),
        },
    };
    rows.push((name, evaluations, calls.get(), error, failure));
}
let columns = serde_json::json!([
    { "key": "0", "label": "計算" },
    { "key": "1", "label": "レポートの評価回数 [回]", "type": "integer", "nullText": "—" },
    { "key": "2", "label": "関数を呼んだ回数 [回]", "type": "integer" },
    { "key": "3", "label": "相対誤差 [-]", "type": "number", "format": sci3, "nullText": "—" },
    { "key": "4", "label": "エラー", "nullText": "なし" }
]);
emit_table_with_columns!(columns, rows, metadata = serde_json::json!({ "id": "jvp" }));
```

既定の方向 $(1, -2)$ では、レポートの評価回数と関数を呼んだ回数はどちらも 2 回で、相対誤差は $1.4 \times 10^{-16}$ と丸め誤差の程度である。
方向を $10^{-300}$ 倍すると、虚部の摂動 $h v_i$ は $2 \times 10^{-316}$ 程度の非正規化数になる。
関数は 2 回呼ばれるが、返った虚部も非正規化数で有効数字が失われているので、値を出力に反映せずに `NumericalInstability`（`Underflow`）を返す。
$10^{-310}$ 倍では $h v_i$ が 0 にアンダーフローするので、関数を一度も呼ばずに `InvalidInput`（`direction`、`UnsupportedConfiguration`）で拒まれる。
方向が 0 のとき、`MathematicalZero` は関数を呼ばず、`ValidateBase` は基準点の検査の 1 回だけを評価する。

## まとめ

複素ステップ法で引き算なしに求まるのは一階の量で、二階導関数とヘッセ行列は複素ステップ法の一階導関数に実数の節点の一階ステンシルを当てて求める。
3 点の節点では誤差の見積もりが $\Delta^2 \lvert f^{(4)} \rvert / 6 + \varepsilon \lvert f' \rvert / \Delta$ になり、精度は $\varepsilon^{2/3}$ 程度にとどまるので、節点の変位は $\varepsilon^{1/3}$ 程度を目安に呼び出し側が選ぶ。
実数の二階差分より丸めの項の増え方が緩く、変位の選び方に対して鈍いので、関数を複素数で書けるなら二階導関数でも実数の二階差分より有利なことが多い。
評価点が動くなら `RelativeComplexStep`、評価点と節点を固定して繰り返すなら `ComplexStepPlan` を使い、どちらも評価回数は $1 + n\bigl(\sum_j k_j - (n - 1)\bigr)$ 回で、混合項は対称になる。
方向微分は `ComplexStep::jvp` で 2 回の評価で求まり、虚部の摂動 $h v_i$ と応答が正規化数に収まる大きさの方向を渡す。
