実数の差分では、刻みを小さくすると近い 2 数の引き算で有効数字が失われ、誤差には下限がある。
関数を複素数の引数でも計算でき、その複素関数が実軸の近くで解析的なら、刻みを虚数方向にとって、引き算をせずに一階導関数を求められる。
これが複素ステップ法（Lyness と Moler 1967、Squire と Trapp 1998）である。
このページでは複素ステップ法の導出と誤差、前提と `scioxide-differentiate` による検査、一階導関数を求める API、前提を破る関数で起こることを説明する。
二階導関数、ヘッセ行列、方向微分への拡張は [複素ステップ法による二階導関数・ヘッセ行列・方向微分](../complex-step-hessians/) で扱う。
記号は [アルゴリズムの共通仕様と構成](oxref:differentiate-notation) に従い、$\varepsilon = 2^{-52}$ は倍精度の計算機イプシロンである。

## 虚数方向の摂動

$f$ が実軸上で実数値をとり、実軸の近くで解析的（複素微分可能）だとする。
虚数方向の刻み $h > 0$ で Taylor 展開すると、偶数次の項は実部に、奇数次の項は虚部に分かれる。

$$
f(x + i h) = f(x) + i h f'(x) - \frac{h^2}{2} f''(x) - i \frac{h^3}{6} f'''(x) + \frac{h^4}{24} f^{(4)}(x) + \cdots .
$$

虚部を取り出して $h$ で割ると、一階導関数の近似が得られる。

$$
\frac{\operatorname{Im} f(x + i h)}{h} = f'(x) - \frac{h^2}{6} f'''(x) + O(h^4).
$$

打ち切り誤差は $O(h^2)$ で、その主項を相対誤差で表すと $(h^2/6) \lvert f'''(x)/f'(x) \rvert$ である。
この式には引き算がないので、$h$ を小さくしても桁落ちは起きない。
実数の差分では打ち切り誤差と丸め誤差の釣り合いで刻みを選ぶが、複素ステップ法では打ち切り誤差を丸めに埋もれさせるまで $h$ を小さくすればよい。
既定の刻み $h = \varepsilon$ では相対的な打ち切り誤差は $8.2 \times 10^{-33} \lvert f'''/f' \rvert$ で、$\lvert f'''/f' \rvert \le 2 \times 10^{16}$ なら $\varepsilon$ より小さい。

到達する精度は、複素数の演算と初等関数が虚部をどれだけ正確に計算するかで決まる。
$h$ が十分小さいと、虚部の計算は自動微分の前進モードと同じ演算になる（Martins ら 2003）。
多くの関数では相対誤差が $\varepsilon$ の数倍になるが、それを保証するものではない。

$h$ の下限は、$\operatorname{Im} f(x + ih) \approx h f'(x)$ が正規化数の範囲に収まること、つまり $\lvert h f'(x) \rvert$ が最小の正規化数 `MIN_POSITIVE`（f64 で $2.2 \times 10^{-308}$）以上であることで決まる。
非正規化数の虚部は有効数字の一部を失っているので、`scioxide-differentiate` は 0 でない虚部が非正規化数になるか、$\operatorname{Im} f / h$ が 0 に丸められたとき、値を出力に反映せずに `NumericalInstability`（`Underflow`）を返す。
虚部がちょうど 0 のときはエラーにせず、導関数 0 を返す。
導関数が本当に 0 の関数と、関数の中で虚部が 0 に丸められた関数は、返った値からは区別できないからである。
刻み $h$ そのものも `MIN_POSITIVE` 以上でなければならず、非正規化数の刻みは関数を呼ぶ前に `InvalidInput`（`OutOfRange`）で拒まれる。
既定の $h = \varepsilon$ なら、$\lvert f'(x) \rvert$ が `MIN_POSITIVE` の $1/\varepsilon$ 倍（約 $10^{-292}$）以上のとき虚部が正規化数に収まる。

複素ステップ法が引き算なしで求めるのは一階の導関数（勾配、ヤコビ行列、方向微分を含む）で、二階導関数には実数の節点との組み合わせが要る（[二階導関数とヘッセ行列](oxref:differentiate-complex-second)）。
関数を複素数で評価するので、1 回の評価コストは実数の評価の数倍になる。

## 解析的拡張の宣言

複素ステップ法の前提は、渡した複素関数が実関数の解析的拡張になっていることである。
解析的拡張とは実軸の近くで解析的で、実軸上で元の実関数に一致する複素関数をいう。
`scioxide-differentiate` では、複素数の点を受け取る関数を [`ComplexStep`](https://docs.rs/scioxide-differentiate/0.1.0/scioxide_differentiate/struct.ComplexStep.html) などに渡すことで、呼び出し側がこの前提を宣言する（関数をラップする型はない）。
宣言は検査も証明もされない。
次の操作は一般に前提を破り、エラーにならずに誤った導関数を返しうる。

- 共役 $\bar z$、絶対値 $\lvert z \rvert$、実部や虚部だけを取り出す演算。
- 虚部に依存する条件分岐。
- 実数専用の関数を実部に適用すること（摂動の虚部が失われる）。

実部に依存する条件分岐は、各分岐が解析的なら前提を保つ。
たとえば $\lvert x \rvert$ は「実部が負なら $-z$、そうでなければ $z$」と書けば、$x \ne 0$ で正しい導関数を返す。

検査されるのは、前提から導ける安価な性質の 1 つ、実軸上の点で関数値が実数になることだけである。
基準点 $x$ で $f(x)$ を評価し、虚部がちょうど 0 でなければ `InvalidInput`（`function`、`UnsupportedConfiguration`）を返す。
この評価の値は一階の公式には使わないので、勾配の評価回数は基準点の 1 回と座標ごとの 1 回の合計 $n + 1$ 回になる。

## ComplexStep

[`ComplexStep`](https://docs.rs/scioxide-differentiate/0.1.0/scioxide_differentiate/struct.ComplexStep.html) は複素ステップ法の手法オブジェクトで、すべての座標に共通の虚数の刻み $h$ を持つ。
既定の刻みは $h = \varepsilon$ で、`with_step(h)` で変える。
`ComplexStep` は刻みを評価のたびに検査し、有限でない刻みは `NonFinite`（原因 `Input`）、`MIN_POSITIVE` より小さい刻み（0 以下と非正規化数）は `InvalidInput`（`self`、`OutOfRange`）になる。
演算はメソッドで選び、一階の `derivative(f, x)`、`gradient(f, x)`、`jacobian(f, x, m)`、`jvp(f, x, v, m)` を持つ。
勾配、ヤコビ行列、方向微分には出力先を指定する API `gradient_into`、`jacobian_into`、`jvp_into` もあり、`derivative` には出力先を指定する API がない。
一階の摂動は虚部だけを動かし、実部の評価点は $x$ のままなので、区間 `bounds` は受け取らない。
実行の方針、評価回数の上限、作業領域の上限は `with_execution`、`with_budgets`、`with_max_workspace_bytes` で指定する。

`derivative` の `f` は複素数を受け取って複素数を返し、ほかの演算の `f` は複素数の点の配列を受け取って複素数の値を書き込む。
返る導関数は実数で、推定誤差は返さず、評価回数や反復回数の上限で止まらなければ終了理由は `Completed` になる。
`Completed` は予定した評価を終えたことだけを表し、精度を主張しない。
方向微分 `jvp` の評価回数は基準点の検査と方向に沿った虚数の摂動の 2 回である（[方向微分](oxref:differentiate-complex-directional)）。
スカラー関数の一階導関数にはワンショット関数 [`complex_step_derivative`](https://docs.rs/scioxide-differentiate/0.1.0/scioxide_differentiate/fn.complex_step_derivative.html)`(f, x)` があり、刻み $h = \varepsilon$ で 2 回評価して値だけを返す。

## 実数の差分との比較

次のセルは Squire と Trapp の例 $f(x) = e^x / \sqrt{\sin^3 x + \cos^3 x}$ の一階導関数を、刻み $h$ を $10^{-1}$ から $10^{-300}$ まで変えて、実数の差分と複素ステップ法で計算する。
実数の差分は刻みを固定した `FiniteDifference`、複素ステップ法は刻みを変えた `ComplexStep` の `derivative` で計算し、複素関数は scioxide-core の `Complex` の演算で書く。
参照値は導関数の式を f64 で計算した値で、縦軸はそれとの相対誤差である。
相対誤差がちょうど 0 になった点と、節点が丸めで一致して差分を作れない刻みは対数軸に描けないので、その数を表に示す。
表の $h = 10^{-300}$ の列の「—」は、節点が一致して差分を作れないことを表す。

```rust
//| id: differentiate-complex-step-sweep
//| ref: differentiate-complex-step-sweep
//| title: 刻み幅による実数の差分と複素ステップ法の相対誤差
//| run: reactive
//| crates: [scioxide-core, scioxide-differentiate]
//| inputs:
//|   x0: {"type":"range","label":"評価点 x₀","min":0.5,"max":1.5,"step":0.25,"value":1.5}
//|   scheme: {"type":"select","label":"実数の差分の公式","options":["中心差分","前進差分"],"value":"中心差分"}
//| cases:
//|   - {"id":"forward","label":"前進差分","description":"打ち切り誤差が O(h) なので、実数の差分の最良の誤差は √ε 程度にとどまる。","inputs":{"scheme":"前進差分"}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"best","path":"/rows/0/1","range":{"min":1e-13,"max":1e-10}}
//|       - {"artifact":"best","path":"/rows/0/3","equals":null}
//|       - {"artifact":"best","path":"/rows/1/1","range":{"max":5e-16}}
//|       - {"artifact":"best","path":"/rows/1/3","range":{"max":5e-16}}
//|   - case: forward
//|     expect:
//|       - {"artifact":"best","path":"/rows/0/1","range":{"min":1e-10,"max":1e-7}}
//|       - {"artifact":"best","path":"/rows/1/1","range":{"max":5e-16}}
use scioxide_core::{Complex, SciOxideError, SciOxideErrorKind, RealScalar};
use scioxide_differentiate::{ComplexStep, DifferenceScheme, DifferenceStep, FiniteDifference};

let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let (label, formula) = match scheme.as_str() {
    "前進差分" => ("前進差分", DifferenceScheme::Forward),
    _ => ("中心差分", DifferenceScheme::Central),
};
// 参照値: f' = e^x (d − 1.5 (s²c − c²s)/d) / d²、d = (s³ + c³)^{1/2}（f64 の固有メソッド）。
let (s, c) = x0.sin_cos();
let d = (s.powi(3) + c.powi(3)).sqrt();
let exact = x0.exp() * (d - 1.5 * (s * s * c - c * c * s) / d) / (d * d);
let real = |t: f64| {
    let (s, c) = (RealScalar::sin(t), RealScalar::cos(t));
    Ok::<f64, SciOxideError>(RealScalar::exp(t) / RealScalar::sqrt(s * s * s + c * c * c))
};
let complex = |z: Complex<f64>| {
    let (s, c) = (z.sin(), z.cos());
    Ok::<_, SciOxideError>(z.exp() / (s * s * s + c * c * c).sqrt())
};
// 刻みの指数: 10⁻¹ から 10⁻¹⁶ までは 0.5 刻み、その先は複素ステップ法だけが意味を持つ。
let mut exponents: Vec<f64> = (2..=32).map(|k| 0.5 * k as f64).collect();
exponents.extend([20.0, 30.0, 50.0, 100.0, 150.0, 200.0, 250.0, 300.0]);
// 各方法の (点, 0 になった点の数, h = 10⁻³⁰⁰ での相対誤差)。
let mut curves: [(Vec<[f64; 2]>, usize, Option<f64>); 2] = Default::default();
let mut collided = 0;
for p in exponents {
    let h = 10.0_f64.powf(-p);
    let method = FiniteDifference::default()
        .with_scheme(formula)
        .with_step(DifferenceStep::absolute(h).map_err(|e| e.to_string())?);
    let real_value = match method.derivative(real, x0) {
        Ok(result) => Some(result.values().ok_or("導関数が公開されない")?[0]),
        // 節点が丸めで一致した刻みだけを除く。
        Err(e) if e.kind() == SciOxideErrorKind::InvalidInput => None,
        Err(e) => return Err(e.to_string()),
    };
    let result = ComplexStep::default()
        .with_step(h)
        .derivative(complex, x0)
        .map_err(|e| e.to_string())?;
    let complex_value = Some(result.values().ok_or("導関数が公開されない")?[0]);
    for (curve, value) in curves.iter_mut().zip([real_value, complex_value]) {
        let Some(value) = value else {
            collided += 1;
            continue;
        };
        let error = ((value - exact) / exact).abs();
        if p == 300.0 {
            curve.2 = Some(error);
        }
        if error > 0.0 {
            curve.0.push([h, error]);
        } else {
            curve.1 += 1;
        }
    }
}
let mut rows = Vec::new();
for (name, (points, zeros, smallest)) in [label, "複素ステップ法"].into_iter().zip(&curves)
{
    let best = points
        .iter()
        .copied()
        .fold([0.0, f64::INFINITY], |a, b| if b[1] < a[1] { b } else { a });
    let skipped = (name == label).then_some(collided);
    rows.push((name, best[1], best[0], *smallest, *zeros, skipped));
}
let series: Vec<_> = rows
    .iter()
    .zip(&curves)
    .map(|(row, curve)| serde_json::json!({ "name": row.0, "points": curve.0 }))
    .collect();
emit_line_chart!(
    &series,
    options = &serde_json::json!({
        "xLabel": "刻み幅 h [-]",
        "yLabel": "導関数の相対誤差 [-]",
        "xType": "log",
        "yType": "log",
        "annotations": [{ "kind": "line", "axis": "y", "value": f64::EPSILON, "label": "ε" }]
    })
);
let columns = serde_json::json!([
    { "key": "0", "label": "方法" },
    { "key": "1", "label": "最良の相対誤差（0 を除く） [-]", "type": "number", "format": sci3 },
    { "key": "2", "label": "その刻み h [-]", "type": "number", "format": sci3 },
    { "key": "3", "label": "h = 10⁻³⁰⁰ の相対誤差 [-]", "type": "number", "format": sci3, "nullText": "—" },
    { "key": "4", "label": "相対誤差が 0 の点 [点]", "type": "integer" },
    { "key": "5", "label": "節点が一致した点 [点]", "type": "integer", "nullText": "—" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "best" })
);
```

既定の入力（$x_0 = 1.5$、中心差分）では、$h \ge 10^{-5}$ の範囲で両方の誤差が打ち切り誤差の $h^2$ に沿って重なる。
中心差分の誤差はそこから丸め誤差で増え始め、$h \le 3 \times 10^{-12}$ では $10^{-5}$ を超え、$h \le 10^{-16}$ の 9 点では節点が丸めで一致して差分を作れない。
表の最良の相対誤差 $4.8 \times 10^{-12}$（$h = 3.2 \times 10^{-6}$）は丸め誤差のばらつきで小さくなった点で、隣の刻みでは $5.7 \times 10^{-11}$ と $1.3 \times 10^{-10}$ である。
複素ステップ法の誤差は $h = 3.2 \times 10^{-8}$ まで $h^2$ で下がり、$h \le 10^{-8}$ では $\varepsilon$ 以下になって、$h = 10^{-300}$ まで変わらない。
39 点のうち 19 点では参照値とビットまで一致し、相対誤差がちょうど 0 になる。
前進差分を選ぶと打ち切り誤差が $O(h)$ になるので、実数の差分で得られる最良の相対誤差は $7.0 \times 10^{-9}$ にとどまる。

## 前提が破られたときの振る舞い

次のセルはいくつかの複素関数を既定の `ComplexStep` の `derivative` に渡し、結果を実関数の導関数と比べる。
$z^2$ と $\sqrt{z}$（$x_0 > 0$）は解析的拡張で、正しい導関数を返す。
$z \bar z = \lvert z \rvert^2$ と $\lvert z \rvert$ は実軸上で $x^2$ と $\lvert x \rvert$ に一致するが、解析的ではない。
実部に $\sin$ を適用して実数を返す関数も、実軸上では $\sin x$ に一致するが、摂動の虚部を捨てる。
これらは $f(x + ih)$ の虚部が 0 になるので、導関数 0 を返し、エラーにはならない。
実部の符号で $z$ と $-z$ を選ぶ関数は、$x_0 \ne 0$ では解析的拡張なので、$\lvert x \rvert$ の導関数 $\operatorname{sign} x_0$ を正しく返す。
$(1 + i) z$ と $x_0 < 0$ での $\sqrt{z}$（主値）は実軸上で値が実数にならないので、基準点の検査で拒まれる。

```rust
//| id: differentiate-analytic-contract
//| ref: differentiate-analytic-contract
//| title: 解析的拡張でない複素関数の複素ステップ法の結果
//| run: reactive
//| crates: [scioxide-core, scioxide-differentiate]
//| inputs:
//|   point: {"type":"select","label":"評価点 x₀","options":["1.5","0.5","-0.5","-1.5"],"value":"1.5"}
//| cases:
//|   - {"id":"negative","label":"x₀ = −1.5","description":"√z の主値は負の実軸上で虚数になるので、基準点の検査で拒まれる。","inputs":{"point":"-1.5"}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"contract","path":"/rows/0/3","approx":{"value":3.0,"rtol":1e-15}}
//|       - {"artifact":"contract","path":"/rows/1/3","approx":{"value":0.408248290463863,"rtol":1e-15}}
//|       - {"artifact":"contract","path":"/rows/2/3","equals":0}
//|       - {"artifact":"contract","path":"/rows/3/3","equals":0}
//|       - {"artifact":"contract","path":"/rows/4/3","equals":0}
//|       - {"artifact":"contract","path":"/rows/5/3","approx":{"value":1.0,"rtol":1e-15}}
//|       - {"artifact":"contract","path":"/rows/6/3","equals":null}
//|       - {"artifact":"contract","path":"/rows/6/4","equals":"InvalidInput（function、UnsupportedConfiguration）"}
//|   - case: negative
//|     expect:
//|       - {"artifact":"contract","path":"/rows/1/4","equals":"InvalidInput（function、UnsupportedConfiguration）"}
//|       - {"artifact":"contract","path":"/rows/5/3","approx":{"value":-1.0,"rtol":1e-15}}
use scioxide_core::{Complex, SciOxideError, SciOxideErrorView, RealScalar};
use scioxide_differentiate::ComplexStep;

let fixed6 = serde_json::json!({ "fractionDigits": 6 });
let x0: f64 = point.parse().map_err(|_| "評価点を読めない")?;
let root_extension = if x0 > 0.0 { "はい" } else { "いいえ" };
type Case = (
    &'static str,
    &'static str,
    fn(Complex<f64>) -> Complex<f64>,
    Option<f64>,
);
// (関数, 実関数の解析的拡張か, 複素関数, 実関数の導関数)。導関数は手で求めた参照値。
let cases: [Case; 7] = [
    ("z²", "はい", |z| z * z, Some(2.0 * x0)),
    (
        "√z（主値）",
        root_extension,
        |z| z.sqrt(),
        (x0 > 0.0).then(|| 0.5 / x0.sqrt()),
    ),
    ("z · conj(z)", "いいえ", |z| z * z.conj(), Some(2.0 * x0)),
    (
        "|z|（norm）",
        "いいえ",
        |z| Complex::new(z.norm(), 0.0),
        Some(x0.signum()),
    ),
    (
        "sin(Re z)",
        "いいえ",
        |z| Complex::new(RealScalar::sin(z.re), 0.0),
        Some(x0.cos()),
    ),
    (
        "Re z < 0 なら −z、他は z",
        "はい",
        |z| if z.re < 0.0 { -z } else { z },
        Some(x0.signum()),
    ),
    ("(1 + i) z", "いいえ", |z| Complex::new(1.0, 1.0) * z, None),
];
let method = ComplexStep::default();
let mut rows = Vec::new();
for (name, analytic, function, reference) in cases {
    let (value, failure) = match method.derivative(|z| Ok::<_, SciOxideError>(function(z)), x0) {
        Ok(r) => (Some(r.values().ok_or("導関数が公開されない")?[0]), None),
        // 基準点の検査による拒否だけを表に残し、ほかのエラーはセルのエラーにする。
        Err(e) => match e.view() {
            SciOxideErrorView::InvalidInput {
                argument, reason, ..
            } => {
                let detail = format!("InvalidInput（{}、{reason:?}）", argument.as_str());
                (None, Some(detail))
            }
            _ => return Err(e.to_string()),
        },
    };
    rows.push((name, analytic, reference, value, failure));
}
let columns = serde_json::json!([
    { "key": "0", "label": "複素関数" },
    { "key": "1", "label": "実関数の解析的拡張" },
    { "key": "2", "label": "実関数の導関数", "type": "number", "format": fixed6, "nullText": "なし" },
    { "key": "3", "label": "複素ステップ法の結果", "type": "number", "format": fixed6, "nullText": "—" },
    { "key": "4", "label": "エラー", "nullText": "なし" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "contract" })
);
```

既定の $x_0 = 1.5$ では、$z^2$、$\sqrt{z}$、実部の符号で分ける関数は実関数の導関数と一致する。
$z \bar z$、$\lvert z \rvert$、$\sin(\operatorname{Re} z)$ はどれも 0 を返し、実関数の導関数 3、1、$\cos 1.5 = 0.0707$ とは違うが、エラーにはならない。
$(1 + i) z$ は基準点で虚部が 0 でないので `InvalidInput`（`function`、`UnsupportedConfiguration`）で拒まれる。
$x_0$ を負にすると、$\sqrt{z}$ も基準点の値 $\sqrt{x_0} = i \sqrt{\lvert x_0 \rvert}$ が実数でないので拒まれ、実部の符号で分ける関数は $-1$ を返す。
基準点の検査が捕まえるのは実軸上で値が実数にならない場合だけで、$z \bar z$ のように実軸上で実数を返す非解析的な関数は捕まえられない。
複素ステップ法の結果が 0 になったときは、関数の書き方が前提を破っていないかを疑い、実数の差分の値と比べる。

## まとめ

複素ステップ法は $\operatorname{Im} f(x + ih)/h$ で一階導関数を求め、引き算がないので刻みを小さくしても桁落ちが起きず、多くの関数で相対誤差が $\varepsilon$ の数倍になる。
前提は関数が実関数の解析的拡張であることで、検査されるのは基準点の値が実数になることだけなので、共役、絶対値、実部だけの演算を含む関数はエラーにならずに誤った 0 を返しうる。
結果が 0 になったときは関数の書き方を疑い、実数の差分の値と比べる。
`ComplexStep` の既定の刻みは $\varepsilon$ で、勾配とヤコビ行列は $n + 1$ 回の評価で求まり、推定誤差は返さず、終了理由 `Completed` は精度を主張しない。
関数を複素数で書けないときや推定誤差が要るときは、実数の差分か適応差分を使う。
