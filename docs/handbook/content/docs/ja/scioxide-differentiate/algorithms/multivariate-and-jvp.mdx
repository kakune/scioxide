多変数の関数では、導関数は勾配、ヤコビ行列、ヘッセ行列という配列になり、差分で求める計算コストは変数の数とともに増える。
このページでは `scioxide-differentiate` で多変数の導関数を求める演算と出力の配置、差分公式と誤差の次数、評価回数の内訳を説明する。
一変数の差分公式と既定刻みは [Taylor 展開と刻み幅の選択](../taylor-and-step-size/) を前提にする。
ヤコビ行列とベクトルの積 $\mathbf{J}\mathbf{v}$ だけが要るときは、行列を作らずに方向微分で求められる（[方向微分（ヤコビ行列とベクトルの積）](../directional-derivatives/)）。

## 演算と出力の配置

入力の次元を $n$、出力の次元を $m$ とし、関数を $\mathbf{F}: \mathbb{R}^n \to \mathbb{R}^m$（$m = 1$ のときは $f$）と書く。
手法オブジェクト `FiniteDifference`、`AdaptiveDifference`、`ComplexStep` では計算する導関数の形をメソッドで選び、節点を指定する差分法オブジェクト `RelativeDifference` と Plan `PhysicalDifferencePlan` では作成時に [`DerivativeOperation`](https://docs.rs/scioxide-differentiate/0.1.0/scioxide_differentiate/enum.DerivativeOperation.html) で指定する。

| メソッド（`DerivativeOperation`） | 入力と出力 | 出力の配列 | 持つ手法オブジェクト |
|---|---|---|---|
| `derivative`（`First`） | $n = m = 1$ | $f'(x)$ の 1 要素 | 3 つすべて |
| `second_derivative`（`Second`） | $n = m = 1$ | $f''(x)$ の 1 要素 | `FiniteDifference`、`AdaptiveDifference` |
| `gradient`（`Gradient`） | $m = 1$ | $\nabla f$ の $n$ 要素 | 3 つすべて |
| `jacobian`（`Jacobian`） | 任意 | $m \times n$ の行優先、要素 $(i, j) = \partial F_i / \partial x_j$ は位置 $i n + j$ | 3 つすべて |
| `hessian`（`Hessian`） | $m = 1$ | $n \times n$ の行優先の対称行列、要素 $(i, j)$ は位置 $i n + j$ | `FiniteDifference`、`AdaptiveDifference` |
| `jvp`（なし） | 任意 | $\mathbf{J}\mathbf{v}$ の $m$ 要素 | 3 つすべて |

手法オブジェクトは $n$ を評価点の長さから、$m$ を `jacobian` と `jvp` の引数 `outputs` から取る。
出力の配列や既知の基準値 `base` の長さが合わなければ `DimensionMismatch` になる。
節点を指定する差分法オブジェクトと Plan では、次元が演算と合わなければ作成時に `InvalidInput`（`UnsupportedConfiguration`、引数 `operation`）になる。
`ComplexStep` は二階の導関数のメソッドを持たず、二階の導関数とヘッセ行列は Plan `ComplexStepPlan` と節点を指定する差分法オブジェクト `RelativeComplexStep` で求める（[複素ステップ法による二階導関数・ヘッセ行列・方向微分](oxref:differentiate-complex-second)）。
節点を指定する差分法オブジェクトと Plan には方向微分の演算がない（[方向微分（ヤコビ行列とベクトルの積）](../directional-derivatives/)）。

既定の中心差分で値だけが要るなら、ワンショット関数 `gradient(f, x)`、`hessian(f, x)`、`jacobian(f, x, m)`、`jvp(f, x, v, m)` が `FiniteDifference::default()` で求めた値を返す。
`gradient` と `hessian` はスカラーを返す関数 `Fn(&[S]) -> Result<S, SciOxideError>` を、`jacobian` と `jvp` は出力の配列に書く関数 `Fn(&[S], &mut [S]) -> Result<(), SciOxideError>` を受け取る。
手法オブジェクトの `gradient` と `hessian` は、出力が 1 つでも出力の配列に書く形の関数を受け取る。
疎なヤコビ行列は、彩色の Plan `ColoredJacobianPlan` が構造の格納順に出力する（[疎ヤコビ行列の彩色による圧縮](../sparse-coloring/)）。

## 勾配とヤコビ行列の差分

座標 $j$ の単位ベクトルを $\mathbf{e}_j$、刻みを $h_j$ とする。
`FiniteDifference` は座標ごとに一変数の差分を作り、ヤコビ行列の第 $j$ 列を 1 本のステンシルで求める。

$$
\frac{\mathbf{F}(\mathbf{x} + h_j \mathbf{e}_j) - \mathbf{F}(\mathbf{x})}{h_j} = \frac{\partial \mathbf{F}}{\partial x_j} + \frac{h_j}{2} \frac{\partial^2 \mathbf{F}}{\partial x_j^2} + O(h_j^2),
\qquad
\frac{\mathbf{F}(\mathbf{x} + h_j \mathbf{e}_j) - \mathbf{F}(\mathbf{x} - h_j \mathbf{e}_j)}{2 h_j} = \frac{\partial \mathbf{F}}{\partial x_j} + \frac{h_j^2}{6} \frac{\partial^3 \mathbf{F}}{\partial x_j^3} + O(h_j^4).
$$

左が前進差分、右が中心差分である。
1 回の評価で $m$ 個の出力がすべて得られるので、ヤコビ行列の計算コストは勾配と同じく列の数 $n$ で決まり、$m$ にはよらない。
既定の刻みは座標ごとに $h_j = c \max(1, \lvert x_j \rvert)$ で、係数 $c$ は前進差分で $\varepsilon^{1/2}$、中心差分で $\varepsilon^{1/3}$ である（[SciOxide の既定刻み](oxref:differentiate-default-steps)）。
このとき誤差の大きさは、関数が滑らかで大きさが 1 程度なら、前進差分で $\varepsilon^{1/2} \approx 1.5 \times 10^{-8}$、中心差分で $\varepsilon^{2/3} \approx 3.7 \times 10^{-11}$ 程度になる。

列ごとに求めた値は行優先の位置 $i n + j$ に書く。
基準点での値 $\mathbf{F}(\mathbf{x})$ は全座標で共有し、中心差分でも 1 回評価する（[基準値の差し引きと既知の基準値 `base`](oxref:differentiate-base-argument)）。

## ヘッセ行列の差分と誤差の次数

ヘッセ行列 $\mathbf{H}$ の対角 $H_{ii} = \partial^2 f / \partial x_i^2$ は一変数の二階差分で求める。
$f_{ii}$、$f_{iii}$ などは偏導関数を表す。

$$
\frac{f(\mathbf{x} + h_i \mathbf{e}_i) - 2 f(\mathbf{x}) + f(\mathbf{x} - h_i \mathbf{e}_i)}{h_i^2} = f_{ii} + \frac{h_i^2}{12} f_{iiii} + O(h_i^4),
\qquad
\frac{f(\mathbf{x} + 2 h_i \mathbf{e}_i) - 2 f(\mathbf{x} + h_i \mathbf{e}_i) + f(\mathbf{x})}{h_i^2} = f_{ii} + h_i f_{iii} + O(h_i^2).
$$

左が中心差分、右が前進差分である。
混合項 $H_{ij}$（$i \ne j$）は、座標 $i$ と $j$ の一階差分を重ねたテンソル積で求める。
中心差分の一階差分の作用素を $D_i$ とすると、$D_i g = g_i + \tfrac{h_i^2}{6} g_{iii} + O(h_i^4)$ を二つの座標に順に当てて次を得る。

$$
D_i D_j f = \frac{f(\mathbf{x}{+}h_i\mathbf{e}_i{+}h_j\mathbf{e}_j) - f(\mathbf{x}{+}h_i\mathbf{e}_i{-}h_j\mathbf{e}_j) - f(\mathbf{x}{-}h_i\mathbf{e}_i{+}h_j\mathbf{e}_j) + f(\mathbf{x}{-}h_i\mathbf{e}_i{-}h_j\mathbf{e}_j)}{4 h_i h_j} = f_{ij} + \frac{h_i^2}{6} f_{iiij} + \frac{h_j^2}{6} f_{ijjj} + O(h^4).
$$

前進差分の混合項は $\mathbf{x}$、$\mathbf{x} + h_i \mathbf{e}_i$、$\mathbf{x} + h_j \mathbf{e}_j$、$\mathbf{x} + h_i \mathbf{e}_i + h_j \mathbf{e}_j$ の 4 点を使い、誤差の主項は $\tfrac{h_i}{2} f_{iij} + \tfrac{h_j}{2} f_{ijj}$ である。
打ち切り誤差は中心差分で $O(h^2)$、前進差分で $O(h)$ になる。

丸め誤差は、関数の値の誤差 $\varepsilon \lvert f \rvert$ が分母の $h^2$（混合項では $h_i h_j$）で割られて増え、どの公式でもおよそ $\varepsilon \lvert f \rvert / h^2$ に比例する。
打ち切り誤差 $C h^p$ と丸め誤差 $\varepsilon \lvert f \rvert / h^2$ の和を最小にする刻みは $h \propto \varepsilon^{1/(p+2)}$ で、そのときの誤差は $\varepsilon^{p/(p+2)}$ に比例する。

| 公式 | 打ち切り誤差の次数 $p$ | 最適な刻み | 誤差の大きさ | 倍精度での値 |
|---|---|---|---|---|
| 中心差分 | 2 | $\varepsilon^{1/4}$ | $\varepsilon^{1/2}$ | $1.5 \times 10^{-8}$ |
| 前進差分 | 1 | $\varepsilon^{1/3}$ | $\varepsilon^{1/3}$ | $6.1 \times 10^{-6}$ |

`FiniteDifference` はヘッセ行列の対角と混合項の両方に、二階の導関数の既定刻み（中心差分で $\varepsilon^{1/4} \max(1, \lvert x_i \rvert)$、前進差分で $\varepsilon^{1/3} \max(1, \lvert x_i \rvert)$）を使う。
混合項は一階差分の組み合わせだが、丸め誤差が $1/(h_i h_j)$ で増えるので、一階の刻みでは丸め誤差が大きくなりすぎる。
係数 $C$ と $\lvert f \rvert$ は関数ごとに違うので、表の値は大きさの目安である。

ヘッセ行列は上三角 $j \ge i$ だけを計算して下三角に写すので、結果はビット単位で対称になる。
1 回の `hessian` の呼び出しの中では、浮動小数点数としてビットが同一の点（符号付きゼロも区別する）で関数を一度だけ呼び、値を再利用する。
対角の二階差分と混合項が共有する座標軸上の点がこれにあたり、呼び出しをまたいで値を持ち越すことはない。
対角と混合項は同じ刻みを使うので、境界がなければ軸上の点はちょうど一致する。

## ヘッセ行列の刻みと誤差の実測

この節の二つのセルは $f(x, y) = e^{xy}$ の点 $(x, y) = (1, 0.5)$ でのヘッセ行列を `FiniteDifference::hessian` で求め、厳密値と比べる。
厳密値は $f_{xx} = y^2 e^{xy}$、$f_{xy} = (1 + xy) e^{xy}$ で、上の展開に現れる主項の係数も閉じた形で書ける。

$$
f_{xxx} = y^3 e^{xy}, \quad f_{xxxx} = y^4 e^{xy}, \quad f_{xxy} = y(2 + xy) e^{xy}, \quad f_{xyy} = x(2 + xy) e^{xy}, \quad f_{xxxy} = y^2(3 + xy) e^{xy}, \quad f_{xyyy} = x^2 (3 + xy) e^{xy}.
$$

次のブロックは二つのセルが共有する定義である。
`hessian_errors` は相対刻み $r$（`DifferenceStep::relative`、刻み $h_i = r \max(1, \lvert x_i \rvert)$）か既定の刻みでヘッセ行列を求め、$H_{00} = f_{xx}$ と $H_{01} = f_{xy}$ の絶対誤差と、下三角との差 $\lvert H_{01} - H_{10} \rvert$ を返す。
型 `f32` と `f64` は入力の文字列で選ぶ。
厳密値は f64 の標準関数による参照値である。

```rust
//| id: differentiate-hessian-exp-model
//| kind: definitions
//| title: e^(xy) のヘッセ行列の誤差
//| crates: [scioxide-core, scioxide-differentiate]
use scioxide_core::{SciOxideError, RealScalar};
use scioxide_differentiate::{DifferenceScheme, DifferenceStep, FiniteDifference};

/// f(x, y) = exp(xy) の (1, 0.5) でのヘッセ行列から [|H00 誤差|, |H01 誤差|, |H01 − H10|] を返す。
/// relative が None なら既定の刻みを使う。
fn errors_in<S: RealScalar>(
    scheme: DifferenceScheme,
    relative: Option<f64>,
) -> Result<[f64; 3], SciOxideError> {
    let x = [S::try_from_f64_lossy(1.0)?, S::try_from_f64_lossy(0.5)?];
    let mut method = FiniteDifference::default().with_scheme(scheme);
    if let Some(r) = relative {
        method = method.with_step(DifferenceStep::relative(S::try_from_f64_lossy(r)?)?);
    }
    let f = |p: &[S], y: &mut [S]| {
        y[0] = RealScalar::exp(p[0] * p[1]);
        Ok::<(), SciOxideError>(())
    };
    let h = method.hessian(f, &x, None, None)?.into_values()?;
    // 参照値: f_xx = y² e^{xy}、f_xy = (1 + xy) e^{xy}（f64 の標準関数による）。
    let e = 0.5_f64.exp();
    let (h00, h01, h10) = (h[0].into_f64(), h[1].into_f64(), h[2].into_f64());
    Ok([
        (h00 - 0.25 * e).abs(),
        (h01 - 1.5 * e).abs(),
        (h01 - h10).abs(),
    ])
}

/// 型を "f32" か "f64" で選んで errors_in を呼ぶ。
pub(crate) fn hessian_errors(
    precision: &str,
    scheme: DifferenceScheme,
    relative: Option<f64>,
) -> Result<[f64; 3], SciOxideError> {
    match precision {
        "f32" => errors_in::<f32>(scheme, relative),
        _ => errors_in::<f64>(scheme, relative),
    }
}

/// 型の計算機イプシロン ε。
pub(crate) fn machine_epsilon(precision: &str) -> f64 {
    match precision {
        "f32" => f64::from(f32::EPSILON),
        _ => f64::EPSILON,
    }
}
```

### 誤差と相対刻み

次のセルは相対刻み $r$ を $10^{-1}$ から 1 桁に 4 点ずつ、`f64` では $10^{-9}$、`f32` では $10^{-5}$ まで小さくして、二つの公式の誤差を走査する。
上の図は対角 $H_{00}$、下の図は混合項 $H_{01}$ の絶対誤差で、横軸の刻みは二つの図で連動する。
破線は打ち切り誤差の主項、縦の点線は二つの公式が既定で使う相対刻み $\varepsilon^{1/3}$（前進差分）と $\varepsilon^{1/4}$（中心差分）である。
表は、走査した刻みの中で誤差が最小になる刻みとその誤差を、既定の相対刻みと並べて示す。
型を `f32` にすると $\varepsilon$ が $1.19 \times 10^{-7}$ に変わり、最適な刻みと誤差の目安が同じ冪の規則で動く。

```rust
//| id: differentiate-hessian-step-error
//| ref: differentiate-hessian-step-error
//| title: ヘッセ行列の対角と混合項の誤差と相対刻み
//| run: reactive
//| uses: [differentiate-hessian-exp-model]
//| crates: [scioxide-core, scioxide-differentiate]
//| inputs:
//|   precision: {"type":"select","label":"浮動小数点数の型","description":"計算機イプシロン ε を変える。","options":["f64","f32"],"value":"f64"}
//| cases:
//|   - {"id":"single","label":"f32","description":"ε が大きくなり、最適な刻みが大きく、誤差の下限が高くなる。","inputs":{"precision":"f32"}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"optimum","path":"/rows/0/3","range":{"min":6e-7,"max":6e-5}}
//|       - {"artifact":"optimum","path":"/rows/1/3","range":{"min":6e-7,"max":6e-5}}
//|       - {"artifact":"optimum","path":"/rows/2/3","range":{"min":1.2e-5,"max":1.2e-3}}
//|       - {"artifact":"optimum","path":"/rows/3/3","range":{"min":1.2e-5,"max":1.2e-3}}
//|       - {"artifact":"optimum","path":"/rows/0/4","range":{"min":1e-8,"max":6e-5}}
//|       - {"artifact":"optimum","path":"/rows/2/4","range":{"min":1e-12,"max":1.5e-8}}
//|       - {"artifact":"optimum","path":"/rows/3/4","range":{"min":1e-12,"max":1.5e-8}}
//|   - case: single
//|     expect:
//|       - {"artifact":"optimum","path":"/rows/0/3","range":{"min":4.9e-4,"max":4.9e-2}}
//|       - {"artifact":"optimum","path":"/rows/2/3","range":{"min":1.8e-3,"max":0.18}}
//|       - {"artifact":"optimum","path":"/rows/2/4","range":{"min":1e-6,"max":3.5e-4}}
use scioxide_differentiate::DifferenceScheme;

let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let epsilon = machine_epsilon(&precision);
// 相対刻みは 10⁻¹ から 4 点/桁で、f64 は 9 桁、f32 は 5 桁走査する。
let last = if precision == "f32" { 16 } else { 32 };
let steps: Vec<f64> = (0..=last)
    .map(|k| 10.0_f64.powf(-1.0 - f64::from(k) / 4.0))
    .collect();
// 打ち切り誤差の主項（x = 1, y = 0.5 で max(1, |xᵢ|) = 1 なので h = r）:
// [前進 H00, 前進 H01, 中心 H00, 中心 H01]。
let e = 0.5_f64.exp();
let leading = |k: usize, h: f64| match k {
    0 => h * 0.125 * e,
    1 => 0.5 * h * (1.25 + 2.5) * e,
    2 => h * h / 12.0 * 0.0625 * e,
    _ => h * h / 6.0 * (0.875 + 3.5) * e,
};
let schemes = [
    ("前進差分", DifferenceScheme::Forward, epsilon.cbrt()),
    ("中心差分", DifferenceScheme::Central, epsilon.sqrt().sqrt()),
];
let (mut charts, mut rows, mut dropped) = ([Vec::new(), Vec::new()], Vec::new(), 0);
for (s, &(name, scheme, default_step)) in schemes.iter().enumerate() {
    let sweep: Vec<[f64; 3]> = steps
        .iter()
        .map(|&r| hessian_errors(&precision, scheme, Some(r)))
        .collect::<Result<_, _>>()
        .map_err(|e| e.to_string())?;
    for (entry, label) in ["H₀₀", "H₀₁"].iter().enumerate() {
        // 誤差がちょうど 0 の点は両対数の図に描けないので除いて数える。
        let points: Vec<[f64; 2]> = steps
            .iter()
            .zip(&sweep)
            .map(|(&r, v)| [r, v[entry]])
            .filter(|p| p[1] > 0.0)
            .collect();
        dropped += steps.len() - points.len();
        let theory: Vec<[f64; 2]> = steps
            .iter()
            .map(|&r| [r, leading(2 * s + entry, r)])
            .collect();
        let best = points.iter().copied().min_by(|a, b| a[1].total_cmp(&b[1]));
        let reference = format!("{name}の主項");
        charts[entry].push(serde_json::json!({
            "name": name,
            "points": points,
            "style": { "showSymbol": true }
        }));
        charts[entry].push(serde_json::json!({
            "name": reference,
            "points": theory,
            "style": { "lineType": "dashed" }
        }));
        rows.push((
            name,
            *label,
            default_step,
            best.map(|p| p[0]),
            best.map(|p| p[1]),
        ));
    }
}
let columns = serde_json::json!([
    { "key": "0", "label": "公式" },
    { "key": "1", "label": "要素" },
    { "key": "2", "label": "既定の相対刻み [-]", "type": "number", "format": sci3 },
    { "key": "3", "label": "誤差が最小の刻み [-]", "type": "number", "format": sci3, "nullText": "なし" },
    { "key": "4", "label": "最小の誤差 [-]", "type": "number", "format": sci3, "nullText": "なし" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "optimum" })
);
let defaults = [
    ("ε^(1/3)", epsilon.cbrt()),
    ("ε^(1/4)", epsilon.sqrt().sqrt()),
];
let annotations: Vec<_> = defaults
    .iter()
    .map(|&(label, value)| {
        serde_json::json!({
            "kind": "line",
            "axis": "x",
            "value": value,
            "label": label,
            "style": { "lineType": "dotted" }
        })
    })
    .collect();
for (series, y_label) in charts
    .iter()
    .zip(["H₀₀ の絶対誤差 [-]", "H₀₁ の絶対誤差 [-]"])
{
    emit_line_chart!(
        series,
        options = &serde_json::json!({
            "link": { "group": "hessian-step" },
            "xLabel": "相対刻み r [-]",
            "yLabel": y_label,
            "xType": "log",
            "yType": "log",
            "annotations": annotations
        })
    );
}
emit_text!(format!("誤差がちょうど 0 で図から除いた点: {dropped} 個"));
```

図では、刻みが大きい側で誤差が破線の主項に沿って傾き 1（前進差分）か 2（中心差分）で減り、刻みが小さい側では丸め誤差が $r^{-2}$ に比例して増えるので、誤差の曲線は V 字になる。
既定の `f64` で誤差が最小になる相対刻みは、前進差分の $H_{00}$ と $H_{01}$ で $1.0 \times 10^{-5}$ と $3.2 \times 10^{-6}$、中心差分で $3.2 \times 10^{-4}$ と $3.2 \times 10^{-5}$ である。
どれも既定の相対刻み（前進差分で $6.1 \times 10^{-6}$、中心差分で $1.2 \times 10^{-4}$）の 4 倍以内にある。
最小の誤差は前進差分で $6.9 \times 10^{-7}$ と $6.5 \times 10^{-6}$、中心差分で $1.7 \times 10^{-10}$ と $1.3 \times 10^{-10}$ である。

`f32`（ケース single）では、既定の相対刻みが $\varepsilon^{1/3} \approx 4.9 \times 10^{-3}$ と $\varepsilon^{1/4} \approx 1.9 \times 10^{-2}$ に大きくなり、V 字の谷も右に動く。
誤差が最小になる相対刻みは前進差分で $10^{-2}$ と $3.2 \times 10^{-3}$、中心差分で $5.6 \times 10^{-2}$ と $5.6 \times 10^{-3}$ で、ここでも既定の刻みの 4 倍以内にある。

### 既定の刻みでの誤差と対称性

次のセルは既定の刻みで二つの公式のヘッセ行列を求め、誤差を上の表の目安（中心差分で $\varepsilon^{1/2}$、前進差分で $\varepsilon^{1/3}$）と比べる。
最後の列は下三角との差 $\lvert H_{01} - H_{10} \rvert$ で、上三角を写す実装なら 0 になる。

```rust
//| id: differentiate-hessian-default-step
//| ref: differentiate-hessian-default-step
//| title: 既定の刻みでのヘッセ行列の誤差と対称性
//| run: reactive
//| uses: [differentiate-hessian-exp-model]
//| crates: [scioxide-core, scioxide-differentiate]
//| inputs:
//|   precision: {"type":"select","label":"浮動小数点数の型","description":"計算機イプシロン ε を変える。","options":["f64","f32"],"value":"f64"}
//| cases:
//|   - {"id":"single","label":"f32","description":"既定の刻みも誤差の目安も ε の同じ冪で大きくなる。","inputs":{"precision":"f32"}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"default-step","path":"/rows/0/1","approx":{"value":6.0555e-6,"rtol":1e-4}}
//|       - {"artifact":"default-step","path":"/rows/0/3","range":{"min":6e-8,"max":6e-5}}
//|       - {"artifact":"default-step","path":"/rows/0/4","range":{"min":6e-8,"max":6e-5}}
//|       - {"artifact":"default-step","path":"/rows/1/1","approx":{"value":1.2207e-4,"rtol":1e-4}}
//|       - {"artifact":"default-step","path":"/rows/1/3","range":{"max":1.5e-7}}
//|       - {"artifact":"default-step","path":"/rows/1/4","range":{"max":1.5e-7}}
//|       - {"artifact":"default-step","path":"/rows/0/5","equals":0}
//|       - {"artifact":"default-step","path":"/rows/1/5","equals":0}
//|   - case: single
//|     expect:
//|       - {"artifact":"default-step","path":"/rows/1/1","approx":{"value":1.8581e-2,"rtol":1e-3}}
//|       - {"artifact":"default-step","path":"/rows/0/3","range":{"min":4.9e-5,"max":4.9e-2}}
//|       - {"artifact":"default-step","path":"/rows/1/3","range":{"max":3.5e-3}}
//|       - {"artifact":"default-step","path":"/rows/1/4","range":{"max":3.5e-3}}
//|       - {"artifact":"default-step","path":"/rows/1/5","equals":0}
use scioxide_differentiate::DifferenceScheme;

let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let epsilon = machine_epsilon(&precision);
// (公式, 差分公式, 既定の相対刻み, 誤差の目安)
let schemes = [
    (
        "前進差分",
        DifferenceScheme::Forward,
        epsilon.cbrt(),
        epsilon.cbrt(),
    ),
    (
        "中心差分",
        DifferenceScheme::Central,
        epsilon.sqrt().sqrt(),
        epsilon.sqrt(),
    ),
];
let mut rows = Vec::new();
for (name, scheme, step, magnitude) in schemes {
    let [h00, h01, asymmetry] =
        hessian_errors(&precision, scheme, None).map_err(|e| e.to_string())?;
    rows.push((name, step, magnitude, h00, h01, asymmetry));
}
let columns = serde_json::json!([
    { "key": "0", "label": "公式" },
    { "key": "1", "label": "既定の相対刻み [-]", "type": "number", "format": sci3 },
    { "key": "2", "label": "誤差の目安 [-]", "type": "number", "format": sci3 },
    { "key": "3", "label": "H₀₀ の誤差 [-]", "type": "number", "format": sci3 },
    { "key": "4", "label": "H₀₁ の誤差 [-]", "type": "number", "format": sci3 },
    { "key": "5", "label": "|H₀₁ − H₁₀| [-]", "type": "number", "format": sci3 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "default-step" })
);
```

既定の `f64` では、前進差分の誤差は対角で $2.6 \times 10^{-6}$、混合項で $2.0 \times 10^{-5}$ で、目安の $\varepsilon^{1/3} \approx 6.1 \times 10^{-6}$ の 4 倍以内にある。
中心差分の誤差は対角で $1.8 \times 10^{-9}$ と目安の $\varepsilon^{1/2} \approx 1.5 \times 10^{-8}$ より 1 桁小さく、混合項で $1.8 \times 10^{-8}$ と目安と同じ桁である。
上のセルの最小の誤差と比べると、既定の刻みでの誤差は前進差分で 3〜4 倍、中心差分で 10〜140 倍大きい。
最小の誤差は厳密値を知っていて刻みを走査したから選べる値で、既定の刻みは関数を知らずに誤差の桁を合わせる規則である。
$\lvert H_{01} - H_{10} \rvert$ はどの行も 0 になり、上三角を写す実装のとおり行列は対称になる。

`f32`（ケース single）では、中心差分の誤差は対角と混合項でどちらも $4.1 \times 10^{-4}$ で、目安の $\varepsilon^{1/2} \approx 3.5 \times 10^{-4}$ に近い。
前進差分の誤差は $1.2 \times 10^{-3}$ と $7.4 \times 10^{-3}$ で、目安の $\varepsilon^{1/3} \approx 4.9 \times 10^{-3}$ に近く、二つの精度で同じ冪の規則が成り立つ。

## 固定刻みの評価回数

勾配とヤコビ行列は、前進差分なら座標ごとに 1 点、中心差分なら 2 点を評価し、基準点 $\mathbf{x}$ の 1 回を全座標で共有する。
ヘッセ行列の中心差分は対角に軸上の 2 点、混合項に $\mathbf{x} \pm h_i \mathbf{e}_i \pm h_j \mathbf{e}_j$ の 4 点を使い、前進差分は対角に軸上の 2 点、混合項に新しい 1 点 $\mathbf{x} + h_i \mathbf{e}_i + h_j \mathbf{e}_j$ を使う。
前進差分の混合項のほかの 3 点は基準点と対角の差分の点を再利用する。

境界がなく節点が丸めで潰れない場合の評価回数は次のとおりである。
既知の基準値 `base` に $f(\mathbf{x})$ を渡すと、基準点の 1 回を省ける（[基準値の差し引きと既知の基準値 `base`](oxref:differentiate-base-argument)）。

| 演算 | 前進差分 | 前進差分、`base` あり | 中心差分 | 中心差分、`base` あり | 反復回数 `iterations()` |
|---|---|---|---|---|---|
| 勾配・ヤコビ行列 | $n + 1$ | $n$ | $2n + 1$ | $2n$ | $n$ |
| ヘッセ行列 | $1 + 2n + n(n-1)/2$ | $2n + n(n-1)/2$ | $1 + 2n^2$ | $2n^2$ | $n + n(n-1)/2$ |

中心差分のヘッセ行列は対角の $n$ 個に $2n$ 回、上三角の混合項 $n(n-1)/2$ 個に $4 \cdot n(n-1)/2$ 回を使うので、基準点と合わせて $1 + 2n + 2n(n-1) = 1 + 2n^2$ 回になる。
レポートの反復回数 `iterations()` は計算した導関数の単位の数（座標、または上三角の要素）である。
方向微分は $n$ によらず 2 回か 3 回で済む（[方向微分の評価回数](oxref:differentiate-jvp-costs)）。

境界の近くでは、前進差分は刻みの分の余地がある向きの節点を使い、どちらの向きの余地も足りなければ余地の大きい向きで刻みを縮める。
中心差分は、境界までの余地が刻みに足りなければ、余地の大きい向きの同じ次数の片側の節点に切り替わる（[定義域の境界と片側差分](oxref:differentiate-bounded-fixed-nodes)）。
どちらの場合も勾配とヤコビ行列の評価回数は変わらない。
中心差分のヘッセ行列では、片側に切り替わった座標ごとに対角の二階差分の点が 1 つ増え、対角と混合項の軸上の点も一致しなくなるので、評価回数は同じ点の再利用の前で高々 $1 + 3n + 4n(n-1)$ 回になる。
`FixedCoordinatePolicy::FeasibleZero` で 0 とした座標は評価しない（勾配で使える。
[下限と上限が一致する座標](oxref:differentiate-equal-bounds)）。

ヘッセ行列の評価回数は $n^2$ に比例するので、変数が多いと計算コストが大きい。
勾配が手に入るなら、勾配のヤコビ行列としてヘッセ行列を求めれば評価は $n$ に比例し、ヘッセ行列とベクトルの積だけなら勾配の方向微分で足りる。
自動微分（scioxide-ad）が使えるなら、そちらのほうが正確で速いことが多い（[数値微分の選び方](../../choosing/)）。

## 適応差分と複素ステップの評価回数

`AdaptiveDifference` は刻みを準位ごとに縮めて外挿し、各成分が収束するまで準位を重ねる（[Richardson 外挿と Ridders の方法](../richardson-and-ridders/)）。
境界から離れた点では、1 準位あたりの評価は、勾配とヤコビ行列の座標ごと、ヘッセ行列の対角ごとに 2 回、ヘッセ行列の混合項ごとに 4 回で、ほかに基準点の 1 回を使う。
境界の近くで片側の節点を使う準位では、ヘッセ行列の対角が 3 回、混合項が最大 8 回になり、勾配とヤコビ行列は 2 回のままである。
座標 $j$ の準位数を $L_j$ とすると、勾配とヤコビ行列は $1 + 2\sum_j L_j$ 回になる。
収束には推定誤差が 2 準位続けて許容誤差を満たす必要があり、推定誤差は 2 準位目から得られるので、最少は 3 準位で、勾配では $1 + 6n$ 回である。
既定の最大 16 準位を使い切ると、勾配は $1 + 32n$ 回になる。
レポートの `iterations()` は準位の数の和である。

`ComplexStep` は勾配とヤコビ行列を $n + 1$ 回（基準点の 1 回と座標ごとに 1 回）で求める。
基準点の 1 回は、$f(\mathbf{x})$ が実数であることを確かめるために使う（[複素ステップ微分と解析的拡張](../complex-step/)）。

## 変数の数と評価回数の実測

次のセルは変数の数 $n$ を 2 から最大値まで 2 ずつ変え、$f(\mathbf{x}) = \sum_i \sin(x_i)\, x_{i+1}$（$x_{n+1} = x_1$）の勾配とヘッセ行列を `FiniteDifference` の前進差分と中心差分で求める。
評価点は $x_i = 0.1 i$（$i = 1, \dots, n$）である。
各演算を `base` なしと、`base` に $f(\mathbf{x})$ を渡した場合で 1 回ずつ行い、レポートの評価回数と反復回数を上の表の式と比べる。
表は最大の $n$ での値と、走査したすべての $n$ で照合した値の数を示し、図は `base` なしの評価回数を両対数で示す。

```rust
//| id: differentiate-evaluation-scaling
//| ref: differentiate-evaluation-scaling
//| title: 変数の数による勾配とヘッセ行列の評価回数
//| run: reactive
//| crates: [scioxide-core, scioxide-differentiate]
//| inputs:
//|   n_max: {"type":"range","label":"最大の変数の数","description":"表に載せる n。図は 2 からこの値まで描く。","min":4,"max":16,"step":2,"value":16}
//| cases:
//|   - {"id":"small","label":"n = 4","description":"変数が少ないと、中心差分のヘッセ行列 33 回と勾配 9 回の差は小さい。","inputs":{"n_max":4}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"counts","path":"/rows/0/2","equals":17}
//|       - {"artifact":"counts","path":"/rows/1/2","equals":33}
//|       - {"artifact":"counts","path":"/rows/1/4","equals":32}
//|       - {"artifact":"counts","path":"/rows/2/2","equals":153}
//|       - {"artifact":"counts","path":"/rows/3/2","equals":513}
//|       - {"artifact":"counts","path":"/rows/3/4","equals":512}
//|       - {"artifact":"counts","path":"/rows/3/6","equals":136}
//|       - {"artifact":"mismatch","path":"/rows/0/0","equals":96}
//|       - {"artifact":"mismatch","path":"/rows/0/1","equals":0}
//|   - case: small
//|     expect:
//|       - {"artifact":"counts","path":"/rows/0/2","equals":5}
//|       - {"artifact":"counts","path":"/rows/2/2","equals":15}
//|       - {"artifact":"counts","path":"/rows/3/2","equals":33}
//|       - {"artifact":"mismatch","path":"/rows/0/0","equals":24}
//|       - {"artifact":"mismatch","path":"/rows/0/1","equals":0}
use scioxide_core::{SciOxideError, RealScalar};
use scioxide_differentiate::{DifferenceScheme, FiniteDifference};

let n_max = n_max as usize;
let f = |p: &[f64], y: &mut [f64]| {
    let n = p.len();
    y[0] = (0..n).map(|i| RealScalar::sin(p[i]) * p[(i + 1) % n]).sum();
    Ok::<(), SciOxideError>(())
};
// 上の表の評価回数（base なし）と反復回数。hessian が偽なら勾配。
let evaluations = |hessian: bool, central: bool, n: usize| match (hessian, central) {
    (false, false) => n + 1,
    (false, true) => 2 * n + 1,
    (true, false) => 1 + 2 * n + n * (n - 1) / 2,
    (true, true) => 1 + 2 * n * n,
};
let iterations = |hessian: bool, n: usize| if hessian { n + n * (n - 1) / 2 } else { n };
let (mut rows, mut series, mut checked, mut mismatches) = (Vec::new(), Vec::new(), 0, 0);
for (hessian, label) in [(false, "勾配"), (true, "ヘッセ行列")] {
    for (central, scheme_name) in [(false, "前進"), (true, "中心")] {
        let scheme = if central {
            DifferenceScheme::Central
        } else {
            DifferenceScheme::Forward
        };
        let method = FiniteDifference::default().with_scheme(scheme);
        let mut points = Vec::new();
        for n in (2..=n_max).step_by(2) {
            let x: Vec<f64> = (1..=n).map(|i| 0.1 * i as f64).collect();
            let mut value = [0.0];
            f(&x, &mut value).map_err(|e| e.to_string())?;
            let run = |known: Option<f64>| {
                let result = if hessian {
                    method.hessian(f, &x, None, known)
                } else {
                    method.gradient(f, &x, None, known)
                };
                result.map(|r| *r.report()).map_err(|e| e.to_string())
            };
            let (plain, known) = (run(None)?, run(Some(value[0]))?);
            let expected = evaluations(hessian, central, n);
            let measured = [plain.evaluations(), known.evaluations(), plain.iterations()];
            let theory = [expected, expected - 1, iterations(hessian, n)];
            checked += 3;
            mismatches += measured.iter().zip(&theory).filter(|(a, b)| a != b).count();
            points.push([n as f64, plain.evaluations() as f64]);
            if n == n_max {
                rows.push((
                    label,
                    scheme_name,
                    measured[0],
                    theory[0],
                    measured[1],
                    theory[1],
                    measured[2],
                    theory[2],
                ));
            }
        }
        let name = format!("{label}・{scheme_name}");
        series.push(serde_json::json!({
            "name": name,
            "points": points,
            "style": { "showSymbol": true }
        }));
    }
}
let columns = serde_json::json!([
    { "key": "0", "label": "演算" },
    { "key": "1", "label": "公式" },
    { "key": "2", "label": "評価回数 [回]", "type": "integer" },
    { "key": "3", "label": "理論値 [回]", "type": "integer" },
    { "key": "4", "label": "base ありの評価回数 [回]", "type": "integer" },
    { "key": "5", "label": "理論値 [回]", "type": "integer" },
    { "key": "6", "label": "反復回数 [回]", "type": "integer" },
    { "key": "7", "label": "理論値 [回]", "type": "integer" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "counts" })
);
emit_table_with_columns!(
    serde_json::json!([
        { "key": "0", "label": "照合した値 [件]", "type": "integer" },
        { "key": "1", "label": "理論値と異なる値 [件]", "type": "integer" }
    ]),
    vec![(checked, mismatches)],
    metadata = serde_json::json!({ "id": "mismatch" })
);
emit_line_chart!(
    &series,
    options = &serde_json::json!({
        "xLabel": "変数の数 n [-]",
        "yLabel": "評価回数 [回]",
        "xType": "log",
        "yType": "log"
    })
);
```

$n = 16$ では、勾配は前進差分で 17 回、中心差分で 33 回、ヘッセ行列は前進差分で 153 回、中心差分で 513 回で、`base` を渡すとどれも 1 回減る。
反復回数は勾配で 16、ヘッセ行列で上三角の要素の数 136 である。
$n = 2, 4, \dots, 16$ で照合した 96 個の値はすべて理論値と一致する。
両対数の図では、勾配は傾き 1、ヘッセ行列は傾き 2 に近づく直線になり、増え方の次数の違いが傾きとして見える。
中心差分のヘッセ行列は $2n^2$、前進差分は $n^2/2$ で増えるので、$n$ が大きいと計算コストの比は 4 に近づく。
$n = 4$（ケース small）では、中心差分のヘッセ行列は 33 回で勾配の 9 回の 4 倍に満たないが、$n = 16$ では 513 回と 33 回で 15 倍を超える。

## まとめ

手法オブジェクトのメソッド（節点を指定する差分法オブジェクトと Plan では `DerivativeOperation`）で一階、二階、勾配、行優先のヤコビ行列、行優先の対称なヘッセ行列、方向微分を選び、入力の次元は評価点の長さで決まる。
固定刻みの勾配とヤコビ行列は中心差分で $2n + 1$ 回、ヘッセ行列は $1 + 2n^2$ 回の評価を使い、既知の基準値 `base` を渡すとそれぞれ 1 回減るので、変数が多いときは勾配やヤコビ行列からヘッセ行列を作るほうが少ない評価で済む。
ヘッセ行列は対角と混合項に二階の既定刻みを使い、誤差は中心差分で $\varepsilon^{1/2}$、前進差分で $\varepsilon^{1/3}$ 程度になり、上三角を計算して写すのでビット単位で対称になる。
既定の刻みは誤差が最小になる刻みから数倍以内にあり、最適な刻みを探すには厳密値が要るので、ふつうは既定の刻みのまま使う。
適応差分は座標ごとに少なくとも 3 準位を使うので、勾配に $1 + 6n$ 回以上の評価が要り、その代わりに推定誤差を返す。
