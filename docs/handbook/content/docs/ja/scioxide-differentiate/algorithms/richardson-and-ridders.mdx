固定刻みの差分は刻みを 1 つ選んで一度だけ計算するので、結果の誤差の大きさは分からない。
刻みを縮めながら差分を何度か計算すると、値の変わり方から打ち切り誤差の大きさを推定でき、誤差の主項を消して次数を上げることもできる。
この操作が Richardson 外挿で、外挿を表の形で繰り返し、推定誤差が最小の要素を採るのが Ridders の方法である。
このページでは外挿の導出、表の更新と丸め誤差の増幅、推定誤差の作り方、`scioxide-differentiate` の適応差分 `AdaptiveDifference` が止まる規則を説明し、手で組んだ表と適応差分が返す値を照合する。
最大準位数、許容誤差、ノイズの大きさによって終了理由と推定誤差がどう変わるかは、[適応差分の推定誤差と終了理由の実測](../adaptive-difference-experiments/) で実測する。
記号は [アルゴリズムの共通仕様と構成](oxref:differentiate-notation) に従い、$\varepsilon = 2^{-52}$ は倍精度の計算機イプシロンである。

## Richardson 外挿

$f$ が $x$ の近くで十分に滑らかなら、中心差分 $A(h)$ は Taylor 展開により $h$ の偶数冪の級数になる。

$$
A(h) = \frac{f(x + h) - f(x - h)}{2h} = f'(x) + c_1 h^2 + c_2 h^4 + \cdots, \qquad c_k = \frac{f^{(2k+1)}(x)}{(2k+1)!}.
$$

係数 $c_k$ の値は分からないが、$h$ には依らない。
刻みを $r > 1$ で割った $A(h/r)$ では $h^2$ の項が $c_1 h^2 / r^2$ になるので、$r^2 A(h/r) - A(h)$ で $c_1$ の項が消える。

$$
A_1(h) = \frac{r^2 A(h/r) - A(h)}{r^2 - 1} = A(h/r) + \frac{A(h/r) - A(h)}{r^2 - 1} = f'(x) - \frac{c_2 h^4}{r^2} + O(h^6).
$$

2 つの差分の組み合わせで、打ち切り誤差の次数が 2 から 4 に上がる。
$A_1$ も $h$ の偶数冪で展開できるので、同じ操作で $h^4$ の項を消せ、これを繰り返せる。

消せる冪は差分公式の展開で決まる。
中心の二階差分も偶数冪だけを持つ。

$$
\frac{f(x + h) - 2 f(x) + f(x - h)}{h^2} = f''(x) + \frac{h^2}{12} f^{(4)}(x) + \frac{h^4}{360} f^{(6)}(x) + \cdots .
$$

片側 3 点の差分は奇数冪も持ち、展開の冪が $h^2, h^3, h^4, \dots$ と 1 つずつ進む。

$$
\frac{-3 f(x) + 4 f(x + h) - f(x + 2h)}{2h} = f'(x) - \frac{h^2}{3} f'''(x) - \frac{h^3}{4} f^{(4)}(x) + \cdots .
$$

外挿はこの冪の列を前提にしているので、$f$ が評価点の近くで滑らかでないと、項を消したつもりの値が誤差を減らさない。

## Neville 型の表

刻みを $h_i = h_0 / r^i$（$i = 0, 1, 2, \dots$）と縮めた差分を $A_{i,0} = A(h_i)$ とし、次の漸化式で表を作る。

$$
A_{i,k} = A_{i,k-1} + \frac{A_{i,k-1} - A_{i-1,k-1}}{r^{p_k} - 1}, \qquad p_k = 2 + \iota (k - 1), \qquad 1 \le k \le i.
$$

$\iota$ は展開の冪の増え方で、偶数冪だけの展開（対称な節点）では 2、すべての冪を持つ展開（片側の節点）では 1 である。
求める導関数を $D$ とし、列 $k-1$ の要素が $A_{i,k-1} = D + c\,h_i^{p_k} + \cdots$ の形だとする。
$A_{i-1,k-1}$ の刻みは $r h_i$ なので $A_{i-1,k-1} = D + c\,r^{p_k} h_i^{p_k} + \cdots$ で、差は $A_{i,k-1} - A_{i-1,k-1} = -c\,(r^{p_k} - 1) h_i^{p_k} + \cdots$ になる。
これを $r^{p_k} - 1$ で割って $A_{i,k-1}$ に足すと $h_i^{p_k}$ の項が消える。
したがって列 $k$ の要素は $h^{p_k}$ までの項を消しており、打ち切り誤差の次数は $p_{k+1}$ である。
対称な節点（$p_k = 2k$）では、この漸化式は $(h_i^2, A_{i,0})$ を通る $h^2$ の多項式の $h = 0$ での値を求める Neville のアルゴリズムと同じになる。
表は準位ごとに 1 行ずつ伸びる。

```text
A₀,₀
A₁,₀  A₁,₁
A₂,₀  A₂,₁  A₂,₂
A₃,₀  A₃,₁  A₃,₂  A₃,₃
```

行 $i$ は新しい差分 $A_{i,0}$ と 1 行上の要素から左から順に計算できるので、メモリは 1 行分で足りる。
表の右下ほど打ち切り誤差の次数が高い。

丸め誤差は列を進むごとに増える。
$A_{i,k-1}$ と $A_{i-1,k-1}$ の誤差が絶対値 $\delta$ 以下なら、漸化式の値の誤差は最大で $\delta (r^{p_k} + 1)/(r^{p_k} - 1)$ になる。
この増幅率は $r = 1.4$ では列 1 で 3.08、列 2 で 1.70、$r = 2$ では 1.67 と 1.13 で、縮小比が小さいほど大きい。
差分 $A_{i,0}$ 自体の丸め誤差も [丸め誤差・ノイズと最適な刻み幅](../roundoff-and-noisy-functions/) のとおり $\varepsilon \lvert f \rvert / h_i$ 程度で、刻みを縮めるほど大きくなる。
したがって次数を上げても精度は限りなくは上がらず、どこかで打ち切り誤差の減少より丸め誤差の増加が勝つ。

次のブロックは、このページの 2 つのセルが共有する定義である。
`smooth` が被微分関数 $f(x) = e^{\sin x}$、`smooth_derivative` が導関数の参照値 $f'(x) = \cos x \, e^{\sin x}$ である。
参照値は f64 の固有メソッドで計算し、被微分関数は SciOxide の `RealScalar` の関数で計算する。

```rust
//| id: differentiate-extrapolation-model
//| kind: definitions
//| title: 被微分関数 e^{sin x} と導関数の参照値
//| crates: [scioxide-core]
use scioxide_core::{SciOxideError, RealScalar};

/// 被微分関数 f(x) = e^{sin x}。
pub(crate) fn smooth(t: f64) -> Result<f64, SciOxideError> {
    Ok(RealScalar::exp(RealScalar::sin(t)))
}

/// 参照値 f'(x) = cos x · e^{sin x}（f64 の固有メソッド）。
pub(crate) fn smooth_derivative(x: f64) -> f64 {
    x.cos() * x.sin().exp()
}
```

## Neville 型の表の各列の誤差

次のセルは $f(x) = e^{\sin x}$ の $x_0 = 0.5$ での一階導関数について、Neville 型の表の各列の要素と参照値との差を刻み $h_i$ に対して描く。
差分 $A_{i,0}$ は刻みを $h_i = 0.5 / r^i$（$i = 0, 1, 2, \dots$）に固定した `FiniteDifference` の中心差分で求め、列 1 以降は本文の漸化式を手で適用して計算する。
破線は列 0 の打ち切り誤差の主項 $h^2 \lvert f'''(x_0) \rvert / 6$ と、差分の丸め誤差の目安 $\varepsilon \lvert f(x_0) \rvert / h$ である。
両対数の図では、列 $k$ の誤差は傾き $p_{k+1} = 2k + 2$ の直線で下がり、刻みが小さい側では丸め誤差で上がる。
表は列 0 から 4 の最小の誤差と、それを与えた準位 $i$ と刻みを示す。
手で組んだ表と縮小比は、[手で組んだ表と適応差分の値の照合](#手で組んだ表と適応差分の値の照合) のセルが使う。

```rust
//| id: differentiate-neville-tableau
//| ref: differentiate-neville-tableau
//| title: Neville 型の表の列ごとの誤差
//| run: reactive
//| uses: [differentiate-extrapolation-model]
//| crates: [scioxide-core, scioxide-differentiate]
//| exports: [table, ratio]
//| inputs:
//|   ratio: {"type":"select","label":"縮小比 r","description":"1.4 は Ridders、2 は Richardson の縮小比。","options":["1.4","2"],"value":"1.4"}
//| cases:
//|   - {"id":"halving","label":"r = 2","description":"刻みが速く縮み、少ない準位で丸めの領域に達する。","inputs":{"ratio":"2"}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"columns","path":"/rows/0/2","range":{"min":1e-14,"max":1e-9}}
//|       - {"artifact":"columns","path":"/rows/3/2","range":{"max":1e-13}}
//|   - case: halving
//|     expect:
//|       - {"artifact":"columns","path":"/rows/0/2","range":{"min":1e-14,"max":1e-9}}
//|       - {"artifact":"columns","path":"/rows/3/2","range":{"max":1e-13}}
use scioxide_differentiate::{DifferenceScheme, DifferenceStep, FiniteDifference};

let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let r: f64 = ratio.parse().map_err(|_| "縮小比を読めない")?;
let x0 = 0.5_f64;
let exact = smooth_derivative(x0);
// 参照値: f‴(x) = cos x (cos²x − 3 sin x − 1) e^{sin x}、f(x) = e^{sin x}（f64 の固有メソッド）。
let (s, c) = x0.sin_cos();
let third = c * (c * c - 3.0 * s - 1.0) * s.exp();
let value = s.exp();
// 刻みを h_0 = 0.5 から 10⁻⁷ 付近まで縮め、丸め誤差が勝つ領域まで見る。
let levels = ((0.5 / 1e-7_f64).ln() / r.ln()).ceil() as usize;
let width = 5;
let mut table: Vec<Vec<f64>> = Vec::new();
let mut curves: Vec<Vec<[f64; 2]>> = vec![Vec::new(); width];
let mut best = vec![(f64::INFINITY, 0_usize, 0.0_f64); width];
let mut reference = (Vec::new(), Vec::new());
for i in 0..levels {
    let h = 0.5 / r.powi(i as i32);
    let method = FiniteDifference::default()
        .with_scheme(DifferenceScheme::Central)
        .with_step(DifferenceStep::absolute(h).map_err(|e| e.to_string())?);
    let result = method.derivative(smooth, x0).map_err(|e| e.to_string())?;
    let mut row = vec![result.values().ok_or("差分が出力に反映されない")?[0]];
    // 独立な検算: A_{i,k} = A_{i,k−1} + (A_{i,k−1} − A_{i−1,k−1}) / (r^{p_k} − 1) を手で適用する（p_k = 2k）。
    for k in 1..=i {
        let factor = r.powi(2 * k as i32);
        row.push(row[k - 1] + (row[k - 1] - table[i - 1][k - 1]) / (factor - 1.0));
    }
    for (k, entry) in row.iter().enumerate().take(width) {
        let error = (entry - exact).abs();
        if error > 0.0 {
            curves[k].push([h, error]);
        }
        if error < best[k].0 {
            best[k] = (error, i, h);
        }
    }
    reference.0.push([h, h * h * third.abs() / 6.0]);
    reference.1.push([h, f64::EPSILON * value / h]);
    table.push(row);
}
let mut series: Vec<serde_json::Value> = curves
    .iter()
    .enumerate()
    .map(|(k, points)| serde_json::json!({ "name": format!("列 {k}"), "points": points }))
    .collect();
let dashed = serde_json::json!({ "lineType": "dashed", "showSymbol": false });
series.push(serde_json::json!({ "name": "h²|f‴|/6", "points": reference.0, "style": dashed }));
series.push(serde_json::json!({ "name": "ε|f|/h", "points": reference.1, "style": dashed }));
emit_line_chart!(
    &series,
    options = &serde_json::json!({
        "xLabel": "刻み h [-]",
        "yLabel": "要素の誤差 |A_{i,k} − f′(x₀)| [-]",
        "xType": "log",
        "yType": "log"
    })
);
let rows: Vec<_> = best
    .iter()
    .enumerate()
    .map(|(k, &(error, level, step))| (k, 2 * k + 2, error, level, step))
    .collect();
let columns = serde_json::json!([
    { "key": "0", "label": "列 k", "type": "integer" },
    { "key": "1", "label": "誤差の次数 p_{k+1}", "type": "integer" },
    { "key": "2", "label": "最小の誤差 [-]", "type": "number", "format": sci3 },
    { "key": "3", "label": "その準位 i", "type": "integer" },
    { "key": "4", "label": "その刻み h_i [-]", "type": "number", "format": sci3 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "columns" })
);
// 手で組んだ表と縮小比を、適応差分と照合するセルに渡す。
export!(table, table);
export!(ratio, r);
```

既定の $r = 1.4$ では、列 0 の誤差は破線 $h^2 \lvert f'''(x_0) \rvert / 6$ に沿って傾き 2 で下がる。
$h \approx 5 \times 10^{-6}$ より小さい刻みでは丸め誤差が勝ち、誤差は破線 $\varepsilon \lvert f \rvert / h$ を目安にばらつきながら増える。
列 1 と 2 は傾き 4 と 6 で下がり、列 1 は $h \approx 1.2 \times 10^{-3}$、列 2 は $3.2 \times 10^{-3}$ で $10^{-14}$ 程度の誤差の底に達する。
列 3 と 4 は $8.8 \times 10^{-3}$ という大きな刻みで、誤差が $10^{-15}$ を下回る。
次数の高い列は大きな刻みで打ち切り誤差を消せるので、差分の丸め誤差が小さいうちに精度が出る。
表の列 0 の最小の誤差 $2.1 \times 10^{-12}$（$h = 7.1 \times 10^{-7}$）と列 1 の $9.8 \times 10^{-15}$（$h = 7.9 \times 10^{-5}$）は、丸め誤差のばらつきでたまたま小さくなった点の値である。
たとえば列 0 のその点の誤差は同じ刻みの丸めの目安 $5 \times 10^{-10}$ よりずっと小さい。
$r = 2$ では列 1 以降の丸めの増幅率が 1.67 以下に下がるが、刻みの並びが粗く誤差の底の近くの準位が少ないので、表の各列の最小の誤差は $r = 1.4$ より小さくならない。

## 推定誤差と丸めの下限

外挿の表は値と同時に誤差の推定も与える。
`scioxide-differentiate` の適応差分には [`AdaptiveDifferenceMethod`](https://docs.rs/scioxide-differentiate/0.1.0/scioxide_differentiate/enum.AdaptiveDifferenceMethod.html) の 2 つの方法があり、縮小比、使う列、打ち切り誤差の推定 $T_{i,k}$ の式が違う。

| 方法 | 縮小比 $r$ | 使う列 | 打ち切り誤差の推定 $T_{i,k}$ |
|---|---|---|---|
| `Ridders`（既定） | 1.4 | すべての列（$1 \le k \le i$） | $\max(\lvert A_{i,k} - A_{i,k-1} \rvert, \lvert A_{i,k} - A_{i-1,k-1} \rvert)$ |
| `Richardson` | 2 | 列 1 だけ | $i \ge 2$ で $\lvert A_{i,1} - A_{i-1,1} \rvert / (r^{2 + \iota} - 1)$、$i = 1$ では `Ridders` と同じ式 |

`Ridders` は Ridders（1982）の方法で、表のすべての要素で誤差を推定する。
推定は最後の消去で値がどれだけ動いたかを誤差の大きさとみなすもので、展開から導いた式ではない。
`Richardson` は 1 回の外挿 $A_{i,1}$ を刻みを半分にしながら繰り返し、その誤差を展開から推定する。
$q = 2 + \iota$ とすると、$A_{i,1} = D + c\,h_i^{q} + \cdots$ と $A_{i-1,1} = D + c\,r^{q} h_i^{q} + \cdots$ の差は $-c\,(r^{q} - 1) h_i^{q}$ なので、差を $r^{q} - 1$ で割ると $A_{i,1}$ の誤差の主項 $\lvert c \rvert h_i^{q}$ になる。
1 準位あたりの評価回数はどちらも同じで、`Richardson` は刻みの縮小が速いぶん、同じ準位数で丸めの領域に早く達する。

推定誤差 $E_{i,k}$ は打ち切りの推定 $T_{i,k}$ に、伝播した丸め誤差の見積もり $\rho_{i,k}$ を足したものである。
$\rho_{i,k}$ は推定誤差がそれより小さくならない下限として働くので、ここでは丸めの下限と呼ぶ。
列 0 の下限は差分の重みと関数の値から次の式で見積もる。

$$
\rho_{i,0} = \frac{4 \varepsilon}{s_i^{m}} \sum_j \lvert w_j \rvert \bigl(\lvert \operatorname{Re} f_j \rvert + \lvert \operatorname{Im} f_j \rvert\bigr).
$$

ここで $s_i$ は準位 $i$ で評価点から最も遠い節点までの距離、$w_j$ は変位を $s_i$ で割った節点での差分の重み、$f_j$ は節点 $j$ での関数の値、$m$ は微分の階数である。
外挿した要素の下限は漸化式と同じ一次結合で伝え、結果の丸め $\varepsilon \lvert A_{i,k} \rvert$ を足す。

$$
\rho_{i,k} = \frac{r^{p_k} \rho_{i,k-1} + \rho_{i-1,k-1}}{r^{p_k} - 1} + \varepsilon \lvert A_{i,k} \rvert, \qquad E_{i,k} = T_{i,k} + \rho_{i,k}.
$$

下限を足すのは、表の要素の差が丸め誤差より小さくなっても、丸め誤差より小さな精度を主張しないためである。
各準位で、それまでに外挿した要素（列 1 以降）のうち $E_{i,k}$ が最小のものを最良の推定とし、その値と推定誤差を返す。
推定誤差は誤差の上界ではなく、外挿の展開が成り立つことを前提にした見積もりである。
$f$ が評価点の近くで滑らかでないと展開の前提が崩れ、推定は実際の誤差より小さくなりうる。

## 刻みと停止の規則

[`AdaptiveDifference`](https://docs.rs/scioxide-differentiate/0.1.0/scioxide_differentiate/struct.AdaptiveDifference.html) は、各準位で中心差分の節点 $\{x_i - h, x_i, x_i + h\}$ を作り、その準位の差分を表に加える。
最初の刻みは $0.5 \max(1, \lvert x_i \rvert)$ で、準位ごとに $r$ で割る。
境界がある場合は、その準位の刻みが境界までの余地に収まれば対称な節点を使い、収まらなければ余地の大きい向きの片側の節点 $\{x_i, x_i + h, x_i + 2h\}$（二階では $x_i + 3h$ まで）を使う（[定義域の境界と片側差分](oxref:differentiate-bounded-other-methods)）。
刻みは境界までの距離に縮めないので、境界の近くでは初めの準位が片側の節点になり、刻みが距離を下回った準位から対称な節点に変わる。
節点は丸めた座標に置くので、漸化式には名目の $r$ ではなく、丸めたあとの節点から求めた実際の縮小比を使う。
節点の形が変わったり、実際の縮小比が 1 以下になったりすると、それまでの列は同じ展開を共有しないので、表を列 0 からやり直す。

各成分の閾値は [`ErrorTolerance`](https://docs.rs/scioxide-core/0.1.0/scioxide_core/struct.ErrorTolerance.html) の絶対許容誤差 $\tau_{\mathrm{abs},i}$ と相対許容誤差 $\tau_{\mathrm{rel}}$ から $\tau_{\mathrm{abs},i} + \tau_{\mathrm{rel}} \lvert A \rvert$ と決める（$A$ は判定する要素の値）。
ノルムは最大ノルム `NormSelection::Infinity` だけを受け付け、成分ごとに判定する。
ヘッセ行列の混合項は $(i, j)$ と $(j, i)$ の両方に出力に反映されるので、2 つの閾値の小さい方を使う。
ある準位で、すべての出力について、その準位のいずれかの要素の $E_{i,k}$ と、最良の推定が持つ推定誤差がどちらも閾値以下なら、その準位は閾値を満たしたとする。

1 つの成分の外挿は次の終了理由のどれかで止まる（[`DifferentiationTermination`](https://docs.rs/scioxide-differentiate/0.1.0/scioxide_differentiate/enum.DifferentiationTermination.html)）。

| 終了理由 | 起こる条件 | 値と推定誤差の出力への反映 |
|---|---|---|
| `Converged` | 続く 2 つの準位で閾値を満たした（表をやり直すと数え直す） | する |
| `RoundoffLimit` | 推定が得られたあと、3 準位続けてどの出力の最良の推定誤差も小さくならなかった | すべての成分に推定があればする |
| `RefinementLimit` | 準位数の上限 $L$ を使い切った | すべての成分に推定があればする |
| `StepSizeLimit` | 縮めた刻みで、区間の中に異なる有限の節点を置けない（刻みが 0 になる、節点が丸めで評価点に重なる、前の準位と同じ節点になる） | すべての成分に推定があればする |
| `EvaluationLimit`、`IterationLimit` | 評価回数の上限か反復回数（準位の数）の上限に達した | しない |
| `Cancelled`、`DeadlineReached` | 外部からの取り消しか期限 | しない |

`Converged` には少なくとも 3 準位が要る。
1 準位目の差分だけでは推定がなく、偶然の一致を受け入れないように 2 準位続けて閾値を満たすことを求めるからである。
`RoundoffLimit` は、刻みを縮めても推定誤差が下がらないことから丸め誤差が勝ったと判断して止まる規則で、丸め誤差を直接検出するものではない。
勾配やヤコビ行列では座標ごとに表を作り直し、レポートの終了理由は最初に `Converged` 以外で止まった成分のものになる。
ただし評価回数や反復回数の上限、取り消し、期限による停止はそれより前の成分の終了理由より優先される。
推定が 1 つもないまま止まった成分があると、残りの成分を計算せずに止まる。

結果を出力に反映したかどうかは [`DifferentiationReport::output_available`](https://docs.rs/scioxide-differentiate/0.1.0/scioxide_differentiate/struct.DifferentiationReport.html#method.output_available) で分かる。
上の表のとおり、終了理由が `RoundoffLimit`、`RefinementLimit`、`StepSizeLimit` でも、すべての成分に推定があれば値と推定誤差を出力に反映する。
したがって、値を使う前に終了理由と推定誤差の両方を確かめる。
適応差分のレポートで `is_success()` が真になるのは `Converged` だけで、`require_success()` はそれ以外の終了理由を `ConvergenceFailure`（`RoundoffLimit` は `Stagnation`、`RefinementLimit` は `TruncationLimit`）などのエラーに変える。

## 選択肢と評価回数

[`AdaptiveDifference`](https://docs.rs/scioxide-differentiate/0.1.0/scioxide_differentiate/struct.AdaptiveDifference.html) の既定は、`Ridders`、許容誤差 $\tau_{\mathrm{abs}} = \tau_{\mathrm{rel}} = \sqrt{\varepsilon} \approx 1.5 \times 10^{-8}$（最大ノルム）、最大 16 準位、最初の刻み $0.5 \max(1, \lvert x_i \rvert)$、逐次実行、上限なしである。
`with_method`、`with_tolerance`、`with_max_levels`、`with_step`、`with_execution`、`with_max_workspace_bytes`、`with_budgets` で変える。
準位数は 3 から 64 まで、ノルムは最大ノルムだけで、範囲の外は評価のときに `InvalidInput`（`self`、`OutOfRange`）になる。
変数の大きさが 1 よりずっと小さいときや、評価点の近くに極や定義域の端があるときは、最初の刻みを `with_step` で明示する（[van der Waals 状態方程式の導関数と推定誤差](../../examples/van-der-waals-adaptive/)）。
絶対許容誤差は導関数の単位で測るので、導関数の大きさが 1 から大きく外れるときは `with_tolerance` で合わせる。
既定の $\sqrt{\varepsilon}$ のままだと、導関数が $10^{-30}$ のように小さな量では、推定誤差が導関数よりずっと大きくても $\sqrt{\varepsilon}$ より小さければ閾値を満たし、誤った値で `Converged` になる（[Arrhenius 式の温度感度を複素ステップで求める](../../examples/arrhenius-complex-step/)）。

`AdaptiveDifference` は演算をメソッドで選び、`derivative(f, x)`、`second_derivative(f, x)`、`gradient(f, x, bounds)`、`jacobian(f, x, m, bounds)`、`hessian(f, x, bounds)`、`jvp(f, x, v, m, bounds)` を持つ。
勾配、ヤコビ行列、ヘッセ行列、方向微分には出力先を指定する API `_into` もある。
固定刻みの `FiniteDifference` と違って既知の基準値 `base` は受け取らず、スカラー関数の `derivative` と `second_derivative` は区間を取らない。
返り値の [`DifferentiationResult`](https://docs.rs/scioxide-differentiate/0.1.0/scioxide_differentiate/struct.DifferentiationResult.html) は、`values()` に導関数、`errors()` に成分ごとの推定誤差を持つ。
座標は実数で、関数の値は実数でも複素数でもよく、導関数は実座標についてとる。

評価回数は基準点の 1 回に 1 準位ごとの次の回数を足したものである。

- 勾配とヤコビ行列は座標ごとに 2 回、方向微分は 2 回、二階導関数とヘッセ行列の対角は 2 回（片側の節点を使う準位では 3 回）。
- ヘッセ行列の混合項は両軸の一階の節点の組で最大 8 点を使い、ビットが同じ点を再利用するので、両軸が対称な節点なら 4 回になる。

スカラー関数の一階導関数が 3 準位で収束すれば 7 回、16 準位を使い切れば 33 回になる。
推定誤差を返すワンショット関数はない。
既定の設定でスカラー関数の一階と二階の導関数と推定誤差を求めるときは、`AdaptiveDifference::default()` の `derivative(f, x)` と `second_derivative(f, x)` を呼ぶ。

## 手で組んだ表と適応差分の値の照合

`AdaptiveDifference` は最初の刻み $0.5 \max(1, \lvert x_0 \rvert)$ と縮小比 $r$ で、[Neville 型の表の各列の誤差](#neville-型の表の各列の誤差) のセルと同じ表を内部で作り、推定誤差が最小の要素を返すが、表そのものは出力に反映しない。
次のセルは、そのセルが手で組んだ表を独立な検算として使い、`AdaptiveDifference` が返す値が表のどの要素と一致するかを確かめる。
方法はそのセルの縮小比に合わせ、$r = 1.4$ なら `Ridders`、$r = 2$ なら `Richardson` を使い、許容誤差 $\tau$ は絶対・相対の両方に使う。
表は終了理由、準位数、評価回数、実際の誤差と、`AdaptiveDifference` が使った準位までの外挿した要素のうち値が最も近いもの（`Richardson` では列 1 だけから探す）を示す。

```rust
//| id: differentiate-neville-adaptive-check
//| ref: differentiate-neville-adaptive-check
//| title: 適応差分の値と手で組んだ Neville 型の表の要素の照合
//| run: reactive
//| uses: [differentiate-extrapolation-model]
//| crates: [scioxide-core, scioxide-differentiate]
//| dependsOn:
//|   tableau: differentiate-neville-tableau
//| inputs:
//|   tolerance: {"type":"select","label":"許容誤差 τ（絶対・相対）","options":["√ε（既定）","1e-12"],"value":"√ε（既定）"}
//| cases:
//|   - {"id":"tight","label":"τ = 10⁻¹²","description":"準位を重ねて表のより下の行の要素を返すが、値はやはり表の要素と一致する。","inputs":{"tolerance":"1e-12"}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"adaptive","path":"/rows/0/1","equals":"Converged"}
//|       - {"artifact":"adaptive","path":"/rows/0/3","equals":15}
//|       - {"artifact":"adaptive","path":"/rows/0/7","range":{"max":1e-13}}
//|   - case: tight
//|     expect:
//|       - {"artifact":"adaptive","path":"/rows/0/3","equals":17}
//|       - {"artifact":"adaptive","path":"/rows/0/7","range":{"max":1e-13}}
use scioxide_core::{ErrorTolerance, NormSelection};
use scioxide_differentiate::{AdaptiveDifference, AdaptiveDifferenceMethod};

let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let table: Vec<Vec<f64>> =
    serde_json::from_value(tableau["table"].clone()).map_err(|e| e.to_string())?;
let r = tableau["ratio"].as_f64().ok_or("縮小比がない")?;
// 縮小比 2 は Richardson、1.4 は Ridders の縮小比。最初の刻みはどちらも 0.5 max(1, |x₀|) = 0.5。
let (method, name) = if r == 2.0 {
    (AdaptiveDifferenceMethod::Richardson, "Richardson")
} else {
    (AdaptiveDifferenceMethod::Ridders, "Ridders")
};
let tau = match tolerance.as_str() {
    "√ε（既定）" => f64::EPSILON.sqrt(),
    text => text.parse().map_err(|_| "許容誤差を読めない")?,
};
let x0 = 0.5_f64;
let adaptive = AdaptiveDifference::default()
    .with_method(method)
    .with_tolerance(
        ErrorTolerance::scalar(tau, tau, NormSelection::Infinity).map_err(|e| e.to_string())?,
    )
    .derivative(smooth, x0)
    .map_err(|e| e.to_string())?;
let report = adaptive.report();
let derivative = adaptive.values().ok_or("導関数が公開されない")?[0];
// 使った準位までの外挿した要素から、適応差分の値に最も近いものを探す（Richardson は列 1 だけ）。
let last_column = if method == AdaptiveDifferenceMethod::Richardson {
    1
} else {
    report.iterations()
};
let mut nearest = (f64::INFINITY, 0_usize, 0_usize);
for (i, row) in table.iter().enumerate().take(report.iterations()) {
    for (k, entry) in row.iter().enumerate().take(last_column + 1).skip(1) {
        if (entry - derivative).abs() < nearest.0 {
            nearest = ((entry - derivative).abs(), i, k);
        }
    }
}
let check = [(
    name,
    report.termination().to_string(),
    report.iterations(),
    report.evaluations(),
    (derivative - smooth_derivative(x0)).abs(),
    nearest.1,
    nearest.2,
    nearest.0,
)];
let columns = serde_json::json!([
    { "key": "0", "label": "方法" },
    { "key": "1", "label": "終了理由" },
    { "key": "2", "label": "準位数", "type": "integer" },
    { "key": "3", "label": "評価回数 [回]", "type": "integer" },
    { "key": "4", "label": "実際の誤差 [-]", "type": "number", "format": sci3 },
    { "key": "5", "label": "最も近い要素の準位 i", "type": "integer" },
    { "key": "6", "label": "その列 k", "type": "integer" },
    { "key": "7", "label": "その要素との差 [-]", "type": "number", "format": sci3 }
]);
emit_table_with_columns!(
    columns,
    check,
    metadata = serde_json::json!({ "id": "adaptive" })
);
```

既定の許容誤差 $\sqrt{\varepsilon}$ では、`Ridders` は 7 準位（$i = 0$ から 6、評価 $1 + 2 \times 7 = 15$ 回）で `Converged` になり、返した値は手で組んだ表の準位 6、列 6 の要素とビットまで一致する。
その実際の誤差は $1.1 \times 10^{-15}$ である。
$\tau = 10^{-12}$ にすると 8 準位（17 回）まで進み、返した値は準位 7、列 5 の要素と一致する。
推定誤差が最小の要素は表の右下の端とは限らず、ここでは列 5 の要素の推定誤差がほかのどの要素よりも小さかった。
表を組むセルで $r = 2$ を選ぶと、`Richardson` も既定の許容誤差で 7 準位で `Converged` になり、値は準位 6、列 1 の要素と一致する。
`Richardson` は列 1 だけを使い、許容誤差を満たした時点で止まるので、実際の誤差は $1.5 \times 10^{-10}$ である。
この照合は適応差分が本文の漸化式と同じ表から値を選ぶことを確かめるもので、値の精度を確かめるものではない。

## まとめ

Richardson 外挿は刻みを $r$ で縮めた差分を組み合わせて誤差の主項 $h^{p}$ を消し、Neville 型の表で次数を順に上げるが、列を進むごとに丸め誤差も増幅する。
`AdaptiveDifference` の `Ridders`（既定、$r = 1.4$）は表のすべての要素で誤差を推定して最小のものを採り、`Richardson`（$r = 2$）は 1 回の外挿を繰り返して連続する値の差から誤差を推定する。
推定誤差は打ち切りの推定に丸めの下限を足した見積もりで、上界ではないので、重要な値は独立な方法で検算する。
2 準位続けて閾値を満たせば `Converged`、同じ差分点の配置で外挿した 3 準位続けて改善しなければ `RoundoffLimit` で止まる。
境界によって点の配置が変わると、外挿表と停滞の履歴を初期化し、それまでの最良推定は代替として保持する。
どちらの終了でも全成分に推定があれば値と推定誤差を出力に反映するので、終了理由と推定誤差の両方を見て値を使う。
最初の刻みは $0.5 \max(1, \lvert x \rvert)$ なので、変数が 1 よりずっと小さいときや評価点の近くに極があるときは `with_step` で最初の刻みを、導関数の大きさが 1 から外れるときは `with_tolerance` で絶対許容誤差を合わせる。
