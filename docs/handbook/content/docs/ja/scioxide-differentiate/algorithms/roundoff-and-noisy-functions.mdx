[Taylor 展開と刻み幅の選択](../taylor-and-step-size/) では、刻み幅 $h$ を小さくすると打ち切り誤差が $h^p$ で減ることを見た。
ところが実際に $h$ を小さくしていくと、ある所から誤差は逆に増え始める。
関数値は丸め誤差やノイズを含み、差分はその誤差を $1/h$（二階差分では $1/h^2$）倍に拡大するからである。
このページではこの増え方を見積もり、打ち切り誤差との釣り合いから最適な刻み幅と到達できる誤差を導いて、実測と比べる。
続いて、関数値に丸めより大きなノイズがある場合と、関数が表の値としてしか与えられない場合の刻みの選び方を説明する。
浮動小数点数と桁落ちの一般的な説明は [浮動小数点数と条件数](../../../concepts/floating-point-and-conditioning/) にある。

## 関数値の丸めと 1/h 則

計算された関数値 $\hat f$ が、真の値に対して相対誤差 $\varepsilon_f$ 以下の誤差を持つとする。

$$
\hat f(t) = f(t)(1 + \theta_t), \qquad \lvert \theta_t \rvert \le \varepsilon_f .
$$

倍精度の丸めの単位を $u = 2^{-53} \approx 1.11 \times 10^{-16}$ と書く。
$u$ は計算機イプシロン $\varepsilon = 2^{-52}$（1 と次の浮動小数点数の差）の半分である。
正しく丸めた関数値なら $\varepsilon_f = u$、誤差が 1 ulp 以内の関数値なら $\varepsilon_f \le \varepsilon$ になる。
長い計算の結果として得られる関数値や、引数の丸めが結果に拡大されて入る関数値では、$\varepsilon_f$ はもっと大きい。
たとえば $\sin(\omega t)$ では、$\omega t$ を丸めた誤差によって、最大で約 $u \lvert \omega t \cos(\omega t) \rvert$ の誤差が関数値に加わる。

中心差分の分子 $\hat f(x + h) - \hat f(x - h)$ の誤差は、$t \approx x$ で $\lvert f(t) \rvert \approx \lvert f(x) \rvert$ とみなすと、最大で $2 \varepsilon_f \lvert f(x) \rvert$ になる。
分母 $2h$ で割ると、導関数の丸め誤差は次の大きさで抑えられる。

$$
E_{\mathrm{round}}^{0}(h) \le \frac{\varepsilon_f \lvert f(x) \rvert}{h}.
$$

同じ考え方で、前進差分の丸め誤差は $2 \varepsilon_f \lvert f \rvert / h$ で抑えられる。
二階差分は前進でも中心でも重みが $(1, -2, 1)/h^2$ で、重みの絶対値の和が $4/h^2$ なので、丸め誤差は $4 \varepsilon_f \lvert f \rvert / h^2$ で抑えられる。
差分の分子は近い 2 数の引き算なので、$h$ が小さいほど関数値の有効数字が多く失われる（桁落ち）。
両対数の図では、この上界は傾き $-1$（二階差分では $-2$）の直線になる。
実際の丸め誤差は符号のそろわない誤差の和なので、上界より小さく、刻みごとに不規則にばらつく。
SciOxide は [丸めたあとの変位で重みを作る](oxref:differentiate-rounded-displacements) ので、節点の位置そのものの丸めは誤差に入らない。

## 総誤差と最適な刻み幅

打ち切り誤差 $C_t h^p$ と丸め誤差 $C_r \varepsilon_f \lvert f \rvert / h^m$（$p$ は公式の次数、$m$ は微分の階数）を足すと、総誤差の見積もりになる。

$$
E(h) \approx C_t h^p + \frac{C_r \varepsilon_f \lvert f(x) \rvert}{h^m}.
$$

第 1 項は $h$ とともに増え、第 2 項は減るので、$E(h)$ は両対数の図で U 字の曲線になる。
$E'(h) = p C_t h^{p-1} - m C_r \varepsilon_f \lvert f \rvert h^{-m-1} = 0$ を解くと、最適な刻み $h^\ast$ が得られる。

$$
h^\ast = \left( \frac{m C_r \varepsilon_f \lvert f \rvert}{p C_t} \right)^{1/(p + m)} .
$$

$h^\ast$ では丸めの項が打ち切りの項の $p/m$ 倍になるので、到達できる誤差は次のようになる。

$$
E(h^\ast) = \left( 1 + \frac{p}{m} \right) C_t \, (h^\ast)^p \propto \varepsilon_f^{\,p/(p + m)} .
$$

[前のページ](oxref:differentiate-second-differences) の主項 $C_t$ と上の $C_r$ を入れると、4 つの公式について次の表になる。

| 公式 | $p$、$m$ | 総誤差の見積もり $E(h)$ | 最適な刻み $h^\ast$ | 到達できる誤差 $E(h^\ast)$ |
|---|---|---|---|---|
| 一階・前進 | 1、1 | $\tfrac{1}{2}\lvert f'' \rvert h + 2 \varepsilon_f \lvert f \rvert / h$ | $2 (\varepsilon_f \lvert f \rvert / \lvert f'' \rvert)^{1/2}$ | $2 (\varepsilon_f \lvert f \rvert \lvert f'' \rvert)^{1/2}$ |
| 一階・中心 | 2、1 | $\tfrac{1}{6}\lvert f''' \rvert h^2 + \varepsilon_f \lvert f \rvert / h$ | $(3 \varepsilon_f \lvert f \rvert / \lvert f''' \rvert)^{1/3}$ | $\tfrac{3}{2} (\varepsilon_f \lvert f \rvert)^{2/3} (\lvert f''' \rvert / 3)^{1/3}$ |
| 二階・中心 | 2、2 | $\tfrac{1}{12}\lvert f^{(4)} \rvert h^2 + 4 \varepsilon_f \lvert f \rvert / h^2$ | $(48 \varepsilon_f \lvert f \rvert / \lvert f^{(4)} \rvert)^{1/4}$ | $\tfrac{2}{\sqrt{3}} (\varepsilon_f \lvert f \rvert \lvert f^{(4)} \rvert)^{1/2}$ |
| 二階・前進 | 1、2 | $\lvert f''' \rvert h + 4 \varepsilon_f \lvert f \rvert / h^2$ | $(8 \varepsilon_f \lvert f \rvert / \lvert f''' \rvert)^{1/3}$ | $3 (\varepsilon_f \lvert f \rvert)^{1/3} \lvert f''' \rvert^{2/3}$ |

$\lvert f \rvert$ と導関数がどれも 1 程度で $\varepsilon_f = u$ なら、到達できる誤差の目安は一階前進で $10^{-8}$、一階中心で $10^{-11}$、二階中心で $10^{-8}$、二階前進で $10^{-5}$ である。
階数 $m$ が同じなら、次数 $p$ が高いほど同じ $\varepsilon_f$ から小さな誤差に届く。

`FiniteDifference` の [既定刻み](oxref:differentiate-default-steps) $c \cdot \max(1, \lvert x \rvert)$ の係数 $c$ は、この表の $h^\ast$ の冪 $\varepsilon_f^{1/(p + m)}$ で $\varepsilon_f$ を $\varepsilon$ に置き換え、定数と比 $\lvert f \rvert / \lvert f^{(k)} \rvert$ を 1 とみなしたものである。
一階前進は $\varepsilon^{1/2}$、一階中心と二階前進は $\varepsilon^{1/3}$、二階中心は $\varepsilon^{1/4}$ になる。
したがって、$f$ が中程度の大きさで滑らかなら、既定刻みでの誤差は $\varepsilon^{p/(p + m)}$ の大きさで、倍精度の一階前進で $\sqrt{\varepsilon} \approx 1.5 \times 10^{-8}$、一階中心で $\varepsilon^{2/3} \approx 3.7 \times 10^{-11}$ になる。
既定刻みは $f$ の導関数の大きさを知らずに使える目安で、比 $\lvert f \rvert / \lvert f^{(k)} \rvert$ が 1 から大きく外れると最適値から離れる。

## U 字曲線の実測

次のセルは $f(x) = \sin(\omega x)$ の一階導関数を、刻み $h = 10^{-16}$ から $1$ まで変えて前進差分と中心差分で計算し、厳密値 $\omega \cos(\omega x_0)$ との誤差を両対数で描く。
$\omega$ は 2 の冪に限るので、$\omega t$ は丸めなしに計算でき、関数値の誤差は $\sin$ の丸めだけになる。
破線は上の表の見積もり $E(h)$ で、$\varepsilon_f = u$ とした。
縦線は `FiniteDifference` の既定刻みの位置である。
表には見積もりの $h^\ast$ と $E(h^\ast)$、$h^\ast$ と既定刻みで計算した誤差、図から除いた点の数を並べる。

刻みが $\mathrm{ulp}(x_0)$ の半分より小さいと、$x_0 \pm h$ が丸めで $x_0$ に戻る。
片方の向きだけが戻る刻みでは、前進差分は戻らない向きの節点に切り替える。
このとき関数値の差はほとんど丸めだけになるので、誤差は $10^{-2}$ から $10^{-1}$ の大きさになり、図の左端に現れる。
中心差分は片側の節点に切り替えず、どちらかの向きが戻る刻みでは `InvalidInput`（`UnsupportedConfiguration`）を返す（[固定刻みの中心差分が選ぶ節点](oxref:differentiate-bounded-fixed-nodes)）。
前進差分でもどちらの向きにも節点を置けない刻みでは同じエラーになるので、エラーになった刻みは図から除いて表の「除いた点」に数える。
誤差がちょうど 0 になった点も、対数軸に描けないので除いて数える。
厳密値と見積もりは f64 の固有メソッドで作った参照値である。

        if let Some(h) = step {
            method = method.with_step(DifferenceStep::absolute(h).map_err(|e| e.to_string())?);

2 つの線が交わる付近が谷になる。
既定の $\omega = 2$、$x_0 = 1$ では、$h^\ast$ での誤差は前進差分で $2.39 \times 10^{-8}$、中心差分で $6.43 \times 10^{-12}$ で、見積もり $E(h^\ast)$（$3.83 \times 10^{-8}$ と $3.37 \times 10^{-11}$）を下回る。
見積もりは丸め誤差がすべて同じ向きにそろった場合の値なので、実際の誤差はそれより小さいことが多い。
谷の底には $E(h^\ast)$ よりさらに小さい点（中心差分で $8.3 \times 10^{-13}$）もあるが、これは丸め誤差が偶然打ち消し合った刻みで、刻みを少し変えると再現しない。
既定刻み（$1.49 \times 10^{-8}$ と $6.06 \times 10^{-6}$）は $h^\ast$ と同じ桁にあり、既定刻みでの誤差（$3.11 \times 10^{-8}$ と $2.75 \times 10^{-11}$）も見積もり $E(h^\ast)$ 以下である。
図の左端の $h = 10^{-16}$ では $x_0 + h$ だけが 1 に戻るので、前進差分は負の向きに切り替えて誤差 $0.17$ の点を描き、中心差分はこの刻みを除く（除いた点 1）。

$\omega = 8$ にすると $\lvert f''' \rvert / \lvert f \rvert$ が大きくなり、中心差分の $h^\ast$ は $1.64 \times 10^{-6}$ に縮む。
既定刻みは $\omega$ を知らないので $6.06 \times 10^{-6}$ のままで、中心差分の誤差は $4.55 \times 10^{-10}$ と $E(h^\ast) = 1.00 \times 10^{-10}$ の 4.5 倍になる。
$x_0 = 3$ では、既定刻みが $\max(1, \lvert x_0 \rvert)$ に比例して 3 倍の $1.82 \times 10^{-5}$ になる。
一方、この点では $\lvert f \rvert = \lvert \sin 6 \rvert = 0.28$ が小さく $\lvert f''' \rvert$ が大きいので、中心差分の $h^\ast$ は $2.30 \times 10^{-6}$ に縮み、既定刻みでの誤差 $4.23 \times 10^{-10}$ は $E(h^\ast)$ の 21 倍になる。
$\mathrm{ulp}(3) \approx 4.4 \times 10^{-16}$ なので、最も小さい 2 つの刻み（$10^{-16}$ と $1.8 \times 10^{-16}$）ではどちらの向きにも節点を置けず、各公式で 2 点を除く。

## ノイズのある関数

関数値が反復計算の打ち切り、確率的な模擬、測定に由来するときは、関数値の誤差は丸めよりずっと大きい。
関数値の誤差の大きさ（絶対値の上限）を $\sigma$ とすると、上の見積もりの $\varepsilon_f \lvert f \rvert$ を $\sigma$ に置き換えればよい。
中心差分なら、最適な刻みと到達できる誤差は次のようになる。

$$
h^\ast = \left( \frac{3 \sigma}{\lvert f''' \rvert} \right)^{1/3}, \qquad E(h^\ast) = \frac{3}{2} \left( \frac{\lvert f''' \rvert}{3} \right)^{1/3} \sigma^{2/3} .
$$

既定刻みは $\sigma \approx \varepsilon \lvert f \rvert$ を前提にしているので、ノイズが大きい関数には小さすぎ、誤差は $\sigma / h$ の項に支配される。
ノイズの大きさと $\lvert f''' \rvert$ の目安が分かっていれば、$h^\ast$ を `DifferenceStep::absolute` で指定する。
ノイズの大きさが分からないときは、刻みを変えた計算を比べる適応差分（[Richardson 外挿と Ridders の方法](../richardson-and-ridders/)）が手がかりになる。
適応差分は、最良の推定誤差が 3 準位続けて改善しないと `RoundoffLimit` で止まり、そこまでの最良の値と推定誤差を出力に反映する。

次のセルは $f(x) = e^x + \sigma \eta(x)$ を $x_0 = 1$ で中心差分により微分し、刻み $h = 10^{-12}$ から $1$ までの誤差を描く。
$\eta(x) \in [-1, 1)$ は、$x$ のビット列とシードから作る擬似乱数で、同じ点では同じ値、異なる点では独立な値をとるノイズのモデルである。
乱数のクレートはこの章より後にあるので、セルの中で splitmix64 の混合関数を使って作る。
$\lvert \eta \rvert < 1$ なので、ノイズによる関数値の誤差は $\sigma$ 未満である（$e^x$ の丸め $u e \approx 3 \times 10^{-16}$ は $\sigma$ に比べて無視できる）。
$f'(1) = f'''(1) = e$ なので、破線の見積もりは $E(h) = e h^2/6 + \sigma/h$ になる。
表は既定刻みと $h^\ast$ で計算した誤差を、同じ刻みでの見積もり $E(h)$ と並べる。

```rust
//| id: differentiate-noisy-step
//| ref: differentiate-noisy-step
//| title: ノイズのある関数の中心差分とノイズの大きさから決めた刻み
//| run: reactive
//| crates: [scioxide-core, scioxide-differentiate]
//| inputs:
//|   sigma: {"type":"select","label":"ノイズの大きさ σ [-]","options":["1e-12","1e-9","1e-6","1e-3"],"value":"1e-6"}
//|   seed: {"type":"range","label":"乱数のシード","min":1,"max":20,"step":1,"value":1}
//| cases:
//|   - {"id":"large-noise","label":"σ = 10⁻³","description":"谷が右へ移り、h* は 0.1 に近づく。到達できる誤差は σ^(2/3) に比例して大きくなる。","inputs":{"sigma":"1e-3"}}
//|   - {"id":"small-noise","label":"σ = 10⁻¹²","description":"谷が左へ移り、h* は既定刻みに近づくが、まだ 17 倍大きい。","inputs":{"sigma":"1e-12"}}
//|   - {"id":"other-seed","label":"シード = 7","description":"個々の点の誤差は変わるが、谷の位置と深さは変わらない。","inputs":{"seed":7}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"noisy","path":"/rows/0/2","range":{"min":1e-2,"max":0.1652}}
//|       - {"artifact":"noisy","path":"/rows/1/1","approx":{"value":1.0334e-2,"rtol":1e-3}}
//|       - {"artifact":"noisy","path":"/rows/1/2","range":{"max":1.4515e-4}}
//|       - {"artifact":"noisy","path":"/rows/1/3","approx":{"value":1.4515e-4,"rtol":1e-3}}
//|   - case: large-noise
//|     expect:
//|       - {"artifact":"noisy","path":"/rows/1/2","range":{"max":1.6e-2}}
//|       - {"artifact":"noisy","path":"/rows/1/3","approx":{"value":1.4515e-2,"rtol":1e-3}}
//|   - case: small-noise
//|     expect:
//|       - {"artifact":"noisy","path":"/rows/0/2","range":{"max":1.652e-7}}
//|       - {"artifact":"noisy","path":"/rows/1/2","range":{"max":1.4515e-8}}
//|       - {"artifact":"noisy","path":"/rows/1/3","approx":{"value":1.4515e-8,"rtol":1e-3}}
//|   - case: other-seed
//|     expect:
//|       - {"artifact":"noisy","path":"/rows/0/2","range":{"max":0.1652}}
//|       - {"artifact":"noisy","path":"/rows/1/2","range":{"max":1.4515e-4}}
use scioxide_core::{SciOxideError, RealScalar};
use scioxide_differentiate::{DifferenceScheme, DifferenceStep, FiniteDifference};

let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let sigma: f64 = sigma.parse().map_err(|_| "σ を読めない")?;
let seed = seed as u64;
// ノイズのモデル: 点のビット列とシードを splitmix64 で混ぜ、[-1, 1) の値にする。
let noise = |t: f64| {
    let mut z = t.to_bits() ^ seed.wrapping_mul(0x9E37_79B9_7F4A_7C15);
    z = (z ^ (z >> 30)).wrapping_mul(0xBF58_476D_1CE4_E5B9);
    z = (z ^ (z >> 27)).wrapping_mul(0x94D0_49BB_1331_11EB);
    z ^= z >> 31;
    (z >> 11) as f64 / (1_u64 << 53) as f64 * 2.0 - 1.0
};
let x0 = 1.0_f64;
// 参照値: f′(1) = f‴(1) = e（f64 の固有メソッド）。
let e = x0.exp();
let model = |h: f64| e * h * h / 6.0 + sigma / h;
// 刻み step（None は既定刻み）での中心差分の誤差。
let error_at = |step: Option<f64>| -> Result<f64, String> {
    let mut method = FiniteDifference::default().with_scheme(DifferenceScheme::Central);
    if let Some(h) = step {
        method = method.with_step(DifferenceStep::absolute(h).map_err(|e| e.to_string())?);
    }
    let result = method
        .derivative(
            |t: f64| Ok::<f64, SciOxideError>(RealScalar::exp(t) + sigma * noise(t)),
            x0,
        )
        .map_err(|e| e.to_string())?;
    Ok((result.values().ok_or("導関数が公開されない")?[0] - e).abs())
};
let mut observed = Vec::new();
let mut theory = Vec::new();
for k in 0..=48 {
    let h = 10.0_f64.powf(-12.0 + 0.25 * k as f64);
    observed.push([h, error_at(Some(h))?]);
    theory.push([h, model(h)]);
}
let optimum = (3.0 * sigma / e).cbrt();
let default_h = f64::EPSILON.cbrt();
let rows = vec![
    (
        "既定刻み ε^(1/3)",
        default_h,
        error_at(None)?,
        model(default_h),
    ),
    (
        "見積もりの h*",
        optimum,
        error_at(Some(optimum))?,
        model(optimum),
    ),
];
let columns = serde_json::json!([
    { "key": "0", "label": "刻みの決め方" },
    { "key": "1", "label": "刻み h [-]", "type": "number", "format": sci3 },
    { "key": "2", "label": "導関数の絶対誤差 [-]", "type": "number", "format": sci3 },
    { "key": "3", "label": "見積もり E(h) = e h²/6 + σ/h [-]", "type": "number", "format": sci3 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "noisy" })
);
let series = vec![
    serde_json::json!({
        "name": "中心差分の誤差",
        "points": observed,
        "style": { "showSymbol": true }
    }),
    serde_json::json!({
        "name": "見積もり e h²/6 + σ/h",
        "points": theory,
        "style": { "lineType": "dashed", "showSymbol": false }
    }),
];
emit_line_chart!(
    &series,
    options = &serde_json::json!({
        "link": { "group": "differentiate-step" },
        "xLabel": "刻み h [-]",
        "yLabel": "導関数の絶対誤差 [-]",
        "xType": "log",
        "yType": "log",
        "annotations": [
            { "kind": "line", "axis": "x", "value": default_h, "label": "既定刻み" },
            { "kind": "line", "axis": "x", "value": optimum, "label": "h*" }
        ]
    })
);
```

既定の $\sigma = 10^{-6}$ では、既定刻み $6.06 \times 10^{-6}$ での誤差は $6.42 \times 10^{-2}$ で、同じ刻みでの見積もり $0.165$ のほとんどを $\sigma/h$ の項が占める。
ノイズの大きさから決めた $h^\ast = 1.03 \times 10^{-2}$ では、誤差は $1.33 \times 10^{-5}$ に下がり、見積もりの最小値 $E(h^\ast) = 1.45 \times 10^{-4}$ を下回る。
見積もりはノイズが最悪の向きにそろった場合の値なので、実際の誤差はそれより小さいことが多い。
$\sigma = 10^{-3}$ にすると谷は右へ移って $h^\ast = 0.103$、$E(h^\ast) = 1.45 \times 10^{-2}$ になる。
$\sigma = 10^{-12}$ にすると谷は左へ移って $h^\ast = 1.03 \times 10^{-4}$、$E(h^\ast) = 1.45 \times 10^{-8}$ になる。
$\sigma$ が $10^9$ 倍変わると $E(h^\ast)$ は $10^6$ 倍変わり、谷の誤差が $\sigma^{2/3}$ に比例することと合う。
$\sigma = 10^{-12}$ でもノイズは丸め（$u e \approx 3 \times 10^{-16}$）より大きいので、既定刻みでの誤差 $6.42 \times 10^{-8}$ は $h^\ast$ での誤差 $5.74 \times 10^{-9}$ の 11 倍になる。
シードを 7 にすると個々の点の誤差は変わる（$h^\ast$ での誤差は $1.14 \times 10^{-4}$）が、谷の位置と深さは変わらない。

## 表の値の微分

関数を呼べず、決まった点の値の表しかないときは、刻みを自由に選べない。
選べるのは、どの表の点を節点に使うかである。
[`FiniteDifferenceStencil`](https://docs.rs/scioxide-differentiate/0.1.0/scioxide_differentiate/struct.FiniteDifferenceStencil.html)`::new(c, nodes, order)` は、呼び出し側が選んだ節点 `nodes` で点 `c` の `order` 階の導関数を近似する重みを作り、`apply(values)` は節点の順に並べた値から物理単位の導関数を返す。
重みの作り方と、重みの絶対値の和が値の誤差を拡大する仕組みは [差分ステンシルの重みと任意の節点](oxref:differentiate-noise-amplification) で説明する。

表の値が $\pm \sigma$ 以内の誤差を持つとき、$m$ 階の導関数の誤差のうち値の誤差による部分は $\sigma A_w / s^m$ 以下になる。
ここで $A_w$ は正規化した変位 $(x_j - c)/s$ に対する重みの絶対値の和で `weight_amplification()` が返し、$s = \max_j \lvert x_j - c \rvert$ は `scale()` が返す変位の尺度である。
節点の間隔を広げると重みは小さくなるが、打ち切り誤差は増える。
したがって、表の値の誤差が大きいほど、間隔の広い節点を選ぶほうがよい。

等間隔 $h$ の対称な節点では、一階導関数の公式と誤差の主項は次のとおりである。

| 節点 | 公式 | $A_w / s$ | 打ち切り誤差の主項 |
|---|---|---|---|
| 3 点 $c, c \pm h$ | $\dfrac{f(c + h) - f(c - h)}{2h}$ | $1/h$ | $\tfrac{1}{6} h^2 \lvert f''' \rvert$ |
| 5 点 $c, c \pm h, c \pm 2h$ | $\dfrac{f(c - 2h) - 8 f(c - h) + 8 f(c + h) - f(c + 2h)}{12 h}$ | $3/(2h)$ | $\tfrac{1}{30} h^4 \lvert f^{(5)} \rvert$ |

次のセルは間隔 $\Delta = 0.001$ で $\sin x$ を表にし、値を小数点以下 $d$ 桁に丸めたデータから、$x_0 = 0.5$ での導関数を計算する。
節点は $x_0, x_0 \pm r \Delta$ の 3 点と、$x_0, x_0 \pm r \Delta, x_0 \pm 2 r \Delta$ の 5 点で、$r$ を 1 から 64 まで倍にして間隔 $h = r\Delta$ を広げる。
丸めの誤差は $\sigma = 0.5 \times 10^{-d}$ 以下で、「値の誤差の上界」は $\sigma A_w / s$ である。
$0 < x < \pi/2$ では $\lvert f''' \rvert = \lvert f^{(5)} \rvert = \cos x$ なので、主項は $x_0$ での値で見積もる。
図の破線は上界と主項の和で、誤差の見積もりになる。
厳密値 $\cos 0.5$ と表の値は f64 の固有メソッドで作る。

```rust
//| id: differentiate-tabulated-values
//| ref: differentiate-tabulated-values
//| title: 丸めた表の値から作る導関数と節点の間隔の選び方
//| run: reactive
//| crates: [scioxide-core, scioxide-differentiate]
//| inputs:
//|   digits: {"type":"select","label":"表の小数点以下の桁数 d","options":["4","6","8"],"value":"6"}
//| cases:
//|   - {"id":"coarse-table","label":"d = 4","description":"値の誤差が大きいので、誤差が最小になる間隔は広い側へ移る。","inputs":{"digits":"4"}}
//|   - {"id":"fine-table","label":"d = 8","description":"値の誤差が小さいので、誤差が最小になる間隔は狭い側へ移り、5 点の公式は広い間隔で打ち切り誤差の主項どおりになる。","inputs":{"digits":"8"}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"spacing","path":"/rows/0/2","approx":{"value":5e-4,"rtol":1e-9}}
//|       - {"artifact":"spacing","path":"/rows/0/5","approx":{"value":7.5e-4,"rtol":1e-9}}
//|       - {"artifact":"spacing","path":"/rows/3/1","range":{"max":7.19e-5}}
//|       - {"artifact":"spacing","path":"/rows/6/1","range":{"min":5.912e-4,"max":6.069e-4}}
//|       - {"artifact":"spacing","path":"/rows/6/4","range":{"max":1.222e-5}}
//|   - case: coarse-table
//|     expect:
//|       - {"artifact":"spacing","path":"/rows/0/1","range":{"max":5.0001e-2}}
//|       - {"artifact":"spacing","path":"/rows/6/1","range":{"max":1.381e-3}}
//|   - case: fine-table
//|     expect:
//|       - {"artifact":"spacing","path":"/rows/0/1","range":{"max":5.15e-6}}
//|       - {"artifact":"spacing","path":"/rows/6/4","range":{"min":3.73e-7,"max":6.08e-7}}
use scioxide_differentiate::FiniteDifferenceStencil;

let fixed3 = serde_json::json!({ "fractionDigits": 3 });
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let digits: i32 = digits.parse().map_err(|_| "桁数を読めない")?;
let (x0, delta) = (0.5_f64, 0.001_f64);
let sigma = 0.5 * 10.0_f64.powi(-digits);
// 表の値: sin を小数点以下 d 桁に丸めたデータ（f64 の固有メソッドで作る）。
let table = |x: f64| (x.sin() * 10.0_f64.powi(digits)).round() / 10.0_f64.powi(digits);
// 参照値: f′(x0) = cos x0、|f‴| = |f⁽⁵⁾| = cos x0。
let exact = x0.cos();
let mut rows = Vec::new();
let mut observed = [Vec::new(), Vec::new()];
let mut estimated = [Vec::new(), Vec::new()];
for r in [1, 2, 4, 8, 16, 32, 64] {
    let h = r as f64 * delta;
    let three = [x0 - h, x0, x0 + h];
    let five = [x0 - 2.0 * h, x0 - h, x0, x0 + h, x0 + 2.0 * h];
    // 打ち切り誤差の主項 h²|f‴|/6 と h⁴|f⁽⁵⁾|/30。
    let leading = [h * h * exact / 6.0, h.powi(4) * exact / 30.0];
    let mut row = [0.0; 6];
    for (index, nodes) in [&three[..], &five[..]].into_iter().enumerate() {
        let stencil = FiniteDifferenceStencil::new(x0, nodes, 1).map_err(|e| e.to_string())?;
        let values: Vec<f64> = nodes.iter().map(|&x| table(x)).collect();
        let derivative = stencil.apply(&values).map_err(|e| e.to_string())?;
        // 値の誤差の上界 σ A_w / s（一階なので s で 1 回割る）。
        let bound = sigma * stencil.weight_amplification() / stencil.scale();
        let error = (derivative - exact).abs();
        row[3 * index..3 * index + 3].copy_from_slice(&[error, bound, leading[index]]);
        observed[index].push([h, error]);
        estimated[index].push([h, bound + leading[index]]);
    }
    rows.push((h, row[0], row[1], row[2], row[3], row[4], row[5]));
}
let columns = serde_json::json!([
    { "key": "0", "label": "間隔 h = rΔ [-]", "type": "number", "format": fixed3 },
    { "key": "1", "label": "3 点の誤差 [-]", "type": "number", "format": sci3 },
    { "key": "2", "label": "3 点の値の誤差の上界 [-]", "type": "number", "format": sci3 },
    { "key": "3", "label": "3 点の主項 [-]", "type": "number", "format": sci3 },
    { "key": "4", "label": "5 点の誤差 [-]", "type": "number", "format": sci3 },
    { "key": "5", "label": "5 点の値の誤差の上界 [-]", "type": "number", "format": sci3 },
    { "key": "6", "label": "5 点の主項 [-]", "type": "number", "format": sci3 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "spacing" })
);
let [observed3, observed5] = observed;
let [estimated3, estimated5] = estimated;
let series = vec![
    serde_json::json!({ "name": "3 点の誤差", "points": observed3, "style": { "showSymbol": true } }),
    serde_json::json!({ "name": "5 点の誤差", "points": observed5, "style": { "showSymbol": true } }),
    serde_json::json!({
        "name": "3 点の見積もり（上界 + 主項）",
        "points": estimated3,
        "style": { "lineType": "dashed", "showSymbol": false }
    }),
    serde_json::json!({
        "name": "5 点の見積もり（上界 + 主項）",
        "points": estimated5,
        "style": { "lineType": "dashed", "showSymbol": false }
    }),
];
emit_line_chart!(
    &series,
    options = &serde_json::json!({
        "xLabel": "節点の間隔 h [-]",
        "yLabel": "導関数の絶対誤差 [-]",
        "xType": "log",
        "yType": "log"
    })
);
```

既定の $d = 6$ では、3 点の誤差は間隔 0.008 と 0.016 で最小（$2.01 \times 10^{-5}$）になる。
それより狭いと値の誤差が、広いと打ち切り誤差が増え、間隔 0.064 での誤差 $5.98 \times 10^{-4}$ は主項 $5.99 \times 10^{-4}$ とほぼ一致する。
5 点の公式は打ち切り誤差が $O(h^4)$ なので広い間隔でも誤差が小さく、間隔 0.064 で $5.31 \times 10^{-7}$ まで下がる。
$d = 8$ では 3 点の誤差が最小になる間隔は 0.004 以下に移り、5 点の公式は間隔 0.064 で主項 $4.91 \times 10^{-7}$ に近い誤差になる。
$d = 4$ では 3 点の誤差は表の範囲で最も広い 0.064 で最小（$2.39 \times 10^{-4}$）になる。
選べる 3 つの桁数のどれでも、誤差は破線の見積もり（値の誤差の上界と主項の和）を超えない。
丸めによる値の誤差は点ごとに決まった値で、互いに独立な乱数ではないので、誤差は間隔に対して滑らかには変わらず、偶然に打ち消し合う間隔もある。
表の値を微分するときは、データの誤差の大きさから節点の間隔を決め、間隔を変えた結果が安定しているかを確かめる。

## まとめ

関数値の誤差が $\varepsilon_f \lvert f \rvert$ のとき、差分の丸め誤差は一階で $1/h$、二階で $1/h^2$ に比例して増え、打ち切り誤差との和は U 字の曲線になる。
最適な刻みは $\varepsilon_f^{1/(p + m)}$ に比例し、そこで到達できる誤差は $\varepsilon_f^{p/(p + m)}$ の大きさになる。
`FiniteDifference` の既定刻みはこの冪で $\varepsilon_f$ を $\varepsilon$ に置き換えた目安なので、$\lvert f \rvert / \lvert f^{(k)} \rvert$ が 1 から大きく外れる関数では、$h^\ast$ を見積もって `DifferenceStep` で指定すると誤差が下がる。
関数値に $\sigma$ のノイズがあるときは $\varepsilon_f \lvert f \rvert$ を $\sigma$ に置き換えて刻みを決め、ノイズの大きさが分からなければ適応差分の推定誤差と終了理由を見る。
表の値しかないときは、`FiniteDifferenceStencil` で節点を選び、重みの絶対値の和から値の誤差の拡大を見積もって、打ち切り誤差との釣り合いで間隔を決める。
