偏微分方程式の離散化や化学反応網のヤコビ行列は、各方程式が少数の変数にしか依存しないので、ほとんどの要素が 0 の疎行列になる。
密なヤコビ行列として差分で求めると、変数の数 $n$ に比例する回数だけ関数を評価するが、疎性を使えば評価回数を色の数に比例する回数まで減らせる。
このページでは Curtis、Powell、Reid（1974）の方法の原理と、`scioxide-differentiate` の彩色ヤコビ行列の Plan の評価回数、出力の順序、使い方の注意を説明する。
列を彩色するアルゴリズムとその色の数は scioxide-sparse の [並べ替えと彩色](../../../scioxide-sparse/algorithms/orderings-and-coloring/#導関数の列の彩色) で扱い、このページは彩色を受け取ってからの差分による復元を扱う。

## 構造的に直交する列

ヤコビ行列 $\mathbf{J} \in \mathbb{R}^{m \times n}$ で 0 でありうる要素の位置の集合を、疎構造（パターン）$\mathcal{S}$ とする。
$(i, j) \notin \mathcal{S}$ は、$F_i$ が $x_j$ に依存しないことを意味する。
列 $j$ と $k$ がどの行でも同時に $\mathcal{S}$ に入らないとき、二つの列は構造的に直交するという。

互いに構造的に直交する列の集まり $C$ を一つの色とし、色に属する列を同時に、それぞれの刻み $h_j$ で摂動する。

$$
\mathbf{x}_C^{\pm} = \mathbf{x} \pm \sum_{j \in C} h_j \mathbf{e}_j .
$$

行 $i$ には $C$ の列のうち高々一つ $j$ しか $\mathcal{S}$ に入らないので、$F_i(\mathbf{x}_C^{\pm}) = F_i(\mathbf{x} \pm h_j \mathbf{e}_j)$ が成り立つ。
したがって、色ごとの中心差分は行 $i$ ごとに列 $j$ だけを摂動した差分と同じ値になる。

$$
\frac{F_i(\mathbf{x}_C^{+}) - F_i(\mathbf{x}_C^{-})}{2 h_j} = \frac{F_i(\mathbf{x} + h_j \mathbf{e}_j) - F_i(\mathbf{x} - h_j \mathbf{e}_j)}{2 h_j} = J_{ij} + \frac{h_j^2}{6} \frac{\partial^3 F_i}{\partial x_j^3} + O(h_j^4) \qquad ((i, j) \in \mathcal{S},\ j \in C).
$$

打ち切り誤差と丸め誤差は密な差分の列 $j$ と同じで、評価の回数だけが列の数 $n$ から色の数 $c$ に比例する回数に減る。
この等式は、$F_i$ が $\mathcal{S}$ の外の変数に本当に依存しないことを前提にしている。

一つの行の $\mathcal{S}$ の列はすべて異なる色でなければならないので、色の数 $c$ は行ごとの要素の数の最大以上である。

$$
c \ge \max_i \bigl\lvert \{ j : (i, j) \in \mathcal{S} \} \bigr\rvert .
$$

下の帯幅 $p_l$、上の帯幅 $p_u$ の帯行列（$-p_l \le j - i \le p_u$ だけが非零）では、行の要素は最大 $p_l + p_u + 1$ 個で、列番号を $p_l + p_u + 1$ で割った余りによる彩色がちょうどこの数で足りるので、色の数は $n$ によらない。
最小の色の数を求める問題は一般に NP 困難で、実用では貪欲な彩色を使う。
列を番号の順に見て、同じ行を共有する前の列が使っていない最小の色を割り当てる貪欲法では、色の数は、ある列と行を共有する他の列の数の最大値に 1 を足した値以下である。
色の数の評価と帯行列での実測は [導関数の列の彩色](../../../scioxide-sparse/algorithms/orderings-and-coloring/#導関数の列の彩色) にある。

## 構造の指定と彩色

非零の位置は scioxide-core の [`StructuralPattern`](https://docs.rs/scioxide-core/0.1.0/scioxide_core/struct.StructuralPattern.html)`::new(rows, cols, row_ptr, col_indices)` で、CSR 形式（各行の列番号が狭義の昇順）で与える。
`row_ptr` は $m + 1$ 個の行の先頭位置、`col_indices` は格納した要素の列番号で、形式が崩れていれば `InvalidInput`（`Malformed`）になる。
パターンは 0 でありうる要素の位置をすべて含まなければならない。
偶然 0 になる要素を含めるのは構わないが、実際には非零の要素を落とすと、その値は同じ色の別の列の要素に混ざり、エラーにならずに誤ったヤコビ行列が返る（下の [パターンから非零が漏れたとき](#パターンから非零が漏れたとき)）。

彩色は scioxide-sparse の [`derivative_coloring`](https://docs.rs/scioxide-sparse/0.1.0/scioxide_sparse/fn.derivative_coloring.html)`(pattern.view())` が上の貪欲法で作る。
結果は scioxide-core の [`ColoringSchedule`](https://docs.rs/scioxide-core/0.1.0/scioxide_core/struct.ColoringSchedule.html)（種類 `ColoringKind::DerivativeColumns`）で、パターンの複製を持ち、`color_count()`、`colors()`、`groups()` で色の数、列ごとの色、色ごとの列（昇順）を読める。
自分で色を決めるときは `ColoringSchedule::new(pattern, ColoringKind::DerivativeColumns, colors)` に渡すと、同じ行を共有する列が同じ色でないことを検査してから受け取り、衝突があれば `InvalidInput`（`Malformed`、引数 `colors`）になる。
色が保証するのは宣言したパターンの上で衝突がないことだけで、関数が本当に依存する変数とパターンが一致するかは検査しない。
scioxide-differentiate は scioxide-sparse に依存しないので、彩色を作るには呼び出し側で scioxide-sparse を使う。

## ColoredJacobianPlan

[`ColoredJacobianPlan`](https://docs.rs/scioxide-differentiate/0.1.0/scioxide_differentiate/struct.ColoredJacobianPlan.html)`::new(&schedule, method)` は、彩色を借り、適応差分の設定 `AdaptiveDifference` で疎なヤコビ行列を求める Plan を作る。
作成時に、列ごとにその列の要素を持つ行、出力の位置、絶対許容誤差を前計算する（$n$ 列と格納した要素の数 $\mathrm{nnz}$ に対して $O(n + \mathrm{nnz})$ の時間とメモリ使用量）。
彩色の種類が `DerivativeColumns` でなければ `InvalidInput`（引数 `schedule`、`UnsupportedConfiguration`）、準位数が 3〜64 の外か許容誤差のノルムが最大ノルムでなければ `InvalidInput`（引数 `method`、`OutOfRange`）、`ZeroDirectionPolicy` が既定でなければ `InvalidInput`（引数 `method`、`Inconsistent`）になる。
評価は所有値を返す API の `evaluate(f, x, bounds)` か、出力・推定誤差・作業領域・実行コンテキストを受け取る出力先を指定する API の `evaluate_into` で行う。
関数は $m$ 行すべての値を書き、値は実数でも複素数でもよい。

### 列ごとの外挿

各列はその列の要素を持つ行だけを出力とする一変数の適応差分として扱われ、列ごとに自分の刻み、外挿の表、終了理由を持つ（[Richardson 外挿と Ridders の方法](../richardson-and-ridders/)）。
最初の刻みは $h_j = 0.5 \max(1, \lvert x_j \rvert)$（`with_step` の指定があればその値）で、準位ごとに縮小比で割る。
同じ色の列は準位ごとに摂動した点を共有し、標本点 $s$ では各列が自分の $s$ 番目の変位を使う。
収束した列は評価点に留まり、残りの列だけが摂動される。
許容誤差は格納した要素 $k$ ごとに $\tau_{\mathrm{abs},k} + \tau_{\mathrm{rel}} \lvert J_k \rvert$（$\tau_{\mathrm{abs},k}$ は絶対許容誤差、$\tau_{\mathrm{rel}}$ は相対許容誤差、$J_k$ は格納順で $k$ 番目の要素）で判定し、絶対許容誤差をベクトルで与えるときは格納順に要素の数だけ並べる。

出力の値と推定誤差はパターンの格納順（CSR の順、行ごと）に並び、長さは格納した要素の数 `output_len()` である。
レポートの終了理由は、外部からの停止や上限による停止がなければ、列の番号順に見て最初に収束しなかった列の終了理由になる。
すべての列に推定があれば、`Converged` でなくても値と推定誤差を出力に反映する（[レポートと出力への反映の規則](oxref:differentiate-report-rules)）。

### 評価回数

1 準位の標本は、境界がなければ $\mathbf{x}_C^{\pm}$ の 2 点である。
区間を渡すと、各列はその準位の刻みで、適応差分と同じ規則で対称な節点 $\{-h, 0, h\}$ か内側へ向かう片側の節点 $\{0, h, 2h\}$ を選ぶ（[適応差分・方向微分・節点差分の境界](oxref:differentiate-bounded-other-methods)）。
どちらの節点も評価点のほかに 2 点を持つので、1 つ目の標本点には各列の 1 番目の変位（$-h$ か $h$）、2 つ目には 2 番目の変位（$h$ か $2h$）を入れる。
同じ色の列は行を共有しないので、節点の形の違う列が同じ色に混じっても、1 準位の標本は 2 点のままである。
色 $C$ の準位数 $L_C$ はその色で最も遅く止まった列の準位数で、評価回数は基準点の 1 回とこれらの和である。

$$
N_{\mathrm{eval}} = 1 + 2 \sum_{C} L_C .
$$

和はすべての色 $C$ にわたり、全列が同じ準位数 $L$ で止まれば $1 + 2cL$ になる。
区間の有無によらず、評価回数は高々 $1 + 2cL_{\max}$（$L_{\max}$ は準位数の上限）である。
密な適応差分のヤコビ行列は $1 + 2\sum_j L_j$ 回なので、比はおよそ $c / n$ である。
レポートの反復回数 `iterations()` は列ごとの準位数の和 $\sum_j L_j$ である。
評価回数の 1 回は関数全体の呼び出し 1 回で、そのほかに、色の準位ごとに摂動した点を組み立てる $O(n + m)$ の計算と、格納した要素ごとの外挿の表の更新がかかる。
表の更新は Ridders の方法では 1 準位で表の列の数だけ計算するので要素ごとに準位数の 2 乗に比例し、Richardson 外挿では準位数に比例する。

### ワンショット関数と作業領域

既定の設定で値だけが要るなら、ワンショット呼び出しの [`sparse_jacobian`](https://docs.rs/scioxide-differentiate/0.1.0/scioxide_differentiate/fn.sparse_jacobian.html)`(f, x, &schedule)` が `AdaptiveDifference::default()` と境界なしで同じ計算をする。
既定の許容誤差は格納した要素ごとに $\sqrt{\varepsilon}(1 + \lvert J_{ij} \rvert)$、最大準位数は 16 で、評価回数は $1 + 32c$ 以下である。
終了理由が `Converged` でなければ、値を返さずに `into_values()` と同じ規則でエラー（`RoundoffLimit`、`RefinementLimit`、`StepSizeLimit` では `ConvergenceFailure`）を返す。

作業領域は [`ColoredJacobianWorkspace`](https://docs.rs/scioxide-differentiate/0.1.0/scioxide_differentiate/struct.ColoredJacobianWorkspace.html) で、要件は Plan を借りる [`ColoredJacobianRequirements`](https://docs.rs/scioxide-differentiate/0.1.0/scioxide_differentiate/struct.ColoredJacobianRequirements.html) が表す（[Plan・要件・作業領域の再利用](../plans-workspaces-and-reports/)）。
大きさは $m$ 行、$L$ 準位に対して $O(n + m + \mathrm{nnz} \cdot L)$ 個の要素で、Plan の `workspace(())` で作れば `evaluate_into` は確保をしない。
摂動した点と関数の値は同時に 2 組しか持たないので、色の数によらない。

## 帯行列での評価回数の実測

次のセルは Broyden の帯の関数（Moré、Garbow、Hillstrom の試験問題）のヤコビ行列を、密な適応差分 `AdaptiveDifference::jacobian` と彩色ヤコビ行列で求めて比べる。

$$
F_i(\mathbf{x}) = x_i (2 + 5 x_i^2) + 1 - \sum_{j \in J_i} x_j (1 + x_j), \qquad J_i = \{ j \ne i : i - p_l \le j \le i + 1,\ 0 \le j < n \}.
$$

元の試験問題は下の帯幅 $p_l = 5$、上の帯幅 1 で、セルでは $p_l$ を 1 から 5 まで変えられる。
行の要素は最大 $p_l + 2$ 個なので、色の数は $p_l + 2$ 以上になる。
解析的なヤコビ行列は $\partial F_i / \partial x_i = 2 + 15 x_i^2$、$\partial F_i / \partial x_j = -(1 + 2 x_j)$（$j \in J_i$）である。
評価点は $x_i = -1 + 0.5\, i / n$ で、$n$ を 8 から 64 まで変えて評価回数と最大誤差を記録する。

次のブロックは、このページの二つのセルが共有する補助関数の定義である。
`csr_pattern` は行ごとの列番号の並びから CSR 形式の `StructuralPattern` を作り、`stored_max_error` は格納順に並んだ値と参照値 $J_{ij}$ との差の絶対値の最大を返す。

```rust
//| id: differentiate-coloring-helpers
//| kind: definitions
//| title: 行ごとの列番号から作る CSR の構造と格納した要素の誤差
//| crates: [scioxide-core]
use scioxide_core::{SciOxideError, StructuralPattern};

/// 行 i の列番号 columns(i)（狭義の昇順）から n × n の CSR の構造を作る。
pub(crate) fn csr_pattern<I: IntoIterator<Item = usize>>(
    n: usize,
    columns: impl Fn(usize) -> I,
) -> Result<StructuralPattern, SciOxideError> {
    let (mut row_ptr, mut col_indices) = (vec![0], Vec::new());
    for i in 0..n {
        col_indices.extend(columns(i));
        row_ptr.push(col_indices.len());
    }
    StructuralPattern::new(n, n, row_ptr, col_indices)
}

/// 格納順（CSR の順）の値 values と参照値 reference(i, j) の差の絶対値の最大。
pub(crate) fn stored_max_error(
    pattern: &StructuralPattern,
    values: &[f64],
    reference: impl Fn(usize, usize) -> f64,
) -> f64 {
    let view = pattern.view();
    let mut largest = 0.0_f64;
    for (i, span) in view.row_ptr().windows(2).enumerate() {
        for k in span[0]..span[1] {
            largest = largest.max((values[k] - reference(i, view.col_indices()[k])).abs());
        }
    }
    largest
}
```

表の $\bar{L}$ は彩色の反復回数を $n$ で割った列あたりの準位数、予測は $1 + 2c\bar{L}$ である。
彩色の最大誤差は格納した要素での解析解との差、密と彩色の差は格納した要素での二つの結果の差の最大で、終了理由は彩色ヤコビ行列のレポートのものである。
図は二つの方法の評価回数を両対数で示す。

//|     expect:

    "Richardson" => AdaptiveDifferenceMethod::Richardson,
    _ => AdaptiveDifferenceMethod::Ridders,

            .map(|j| x[j] * (1.0 + x[j]))

    { "key": "0", "label": "n", "type": "integer" },
    { "key": "1", "label": "色の数 c", "type": "integer" },
    { "key": "2", "label": "密な評価回数 [回]", "type": "integer" },
    { "key": "3", "label": "彩色の評価回数 [回]", "type": "integer" },
    { "key": "4", "label": "列あたりの準位数 L̄", "type": "number", "format": fixed2 },
    { "key": "5", "label": "予測 1 + 2cL̄ [回]", "type": "number", "format": fixed1 },
    { "key": "6", "label": "彩色の最大誤差 [-]", "type": "number", "format": sci3 },
    { "key": "7", "label": "密と彩色の差 [-]", "type": "number", "format": sci3 },
    { "key": "8", "label": "終了理由" }

emit_table_with_columns!(

    metadata = serde_json::json!({ "id": "comparison" })

$p_l = 5$ では、色の数はどの $n$ でも下界と同じ 7 で、彩色の評価回数は $n$ によらず $1 + 2 \cdot 7 \cdot 4 = 57$ 回である。
密な適応差分の評価回数は $1 + 8n$ 回で $n$ に比例し、$n = 64$ では 513 回と彩色の 9 倍になる。
$n = 8$ では色の数 7 が $n$ に近いので、65 回と 57 回の差は小さい。

どの列も 4 準位で収束する。
$F_i$ は各変数の 3 次式なので、中心差分の誤差は $h^2$ の項だけで、外挿の 1 列目で打ち切り誤差が消える。
それでも 2 準位目では収束しない。
Ridders の方法の推定誤差は新しい値と表の二つの親との差の大きい方で、2 準位目の親は外挿する前の差分なので、推定誤差に $h^2$ の項が残るからである。
推定誤差が丸めの大きさまで下がるのは親がどちらも外挿した値になる 3 準位目からで、許容誤差を 2 準位続けて満たした 4 準位目で収束する（[刻みと停止の規則](oxref:differentiate-stopping-rules)）。

彩色の最大誤差は $1.3 \times 10^{-14}$ 以下で、格納した要素での密と彩色の差はちょうど 0 である。
$F_i$ は同じ色の他の列の変数を読まず、密な適応差分も同じ最初の刻みと縮小比を使う。
そのため、色の摂動は行ごとに列だけの摂動とビット単位で同じ値を与え、外挿も同じ値をたどる。

$p_l = 1$（ケース narrow-band）にすると色は 3 つに減り、彩色の評価回数は $1 + 2 \cdot 3 \cdot 4 = 25$ 回になる。
Richardson 外挿（ケース richardson）でも同じ理由で 4 準位で収束して評価回数は変わらず、この関数と評価点では誤差がちょうど 0 になる。

## パターンから非零が漏れたとき

パターンが実際の非零 $(i, k)$ を落とすと、列 $k$ と、行 $i$ に要素を持つ列 $j$ が同じ色になりうる。
そのとき色の摂動 $\mathbf{x}_C^{\pm}$ は $x_j$ と $x_k$ を同時に動かし、行 $i$ の差分は列 $k$ の変化を含む。

$$
\frac{F_i(\mathbf{x}_C^{+}) - F_i(\mathbf{x}_C^{-})}{2 h_j} = J_{ij} + \frac{h_k}{h_j} J_{ik} + O(h^2).
$$

列ごとの刻みは準位ごとに同じ比で縮むので、比 $h_k / h_j$ は準位によらず一定で、外挿はこの誤った値に収束する。
推定誤差は準位の間の変化から作るので、混入は推定誤差に現れず、終了理由も `Converged` になる。
`ColoredJacobianPlan` は関数をパターンと照合しないので、この誤りをエラーとしても返しない。

検出には、パターンとは独立な計算が要る。
たとえば一度だけ密な差分 `FiniteDifference::jacobian` でヤコビ行列を求め、パターンの外の要素が 0 であることを確かめればよい。
$F_i$ が $x_k$ を読まなければ、差分の 2 点で $F_i$ の値はビット単位で同じなので、パターンの外の差分はちょうど 0 になる。
パターンを関数のコードから機械的に作るには、scioxide-ad の記録から `jacobian_pattern()` で構造パターンを求める方法もある（[記録から求める構造パターン](../../../scioxide-ad/algorithms/sparse-derivatives/#記録から求める構造パターン)）。

次のセルは 4 変数の関数のヤコビ行列を、正しいパターンと、要素 $(0, 2)$ を落としたパターンで計算する。

$$
\mathbf{F} = \bigl( x_0^2 + \gamma x_2, \; x_0 + x_1^2, \; x_1 + x_2^2, \; x_2 + x_3^2 \bigr), \qquad \mathbf{x} = (1, 0.5, x_2, 2).
$$

正しいパターンでは列 0 と列 2 が行 0 で衝突するので別の色になるが、$(0, 2)$ を落とすと同じ色になる。
すると行 0 の差分は $J_{00} = 2 x_0 = 2$ ではなく $2 x_0 + \gamma h_2 / h_0$ になり、最初の刻み $h_j = 0.5 \max(1, \lvert x_j \rvert)$ から予測できる。
結合の強さ $\gamma$ を 0 にすると、$(0, 2)$ は実際にも 0 なので、落としても結果は正しい。
表の「パターン外の最大値」は密な固定刻みのヤコビ行列でパターンの外にある要素の絶対値の最大をとった独立な検査である。

```rust
//| id: differentiate-missing-pattern
//| ref: differentiate-missing-pattern
//| title: パターンから非零を落としたときの色の併合と値の混入
//| run: reactive
//| uses: [differentiate-coloring-helpers]
//| crates: [scioxide-core, scioxide-differentiate, scioxide-sparse]
//| inputs:
//|   coupling: {"type":"select","label":"結合の強さ γ","description":"F₀ が x₂ に依存する強さ。0 なら (0, 2) は実際に 0 になる。","options":["0.5","0.01","0"],"value":"0.5"}
//|   x2: {"type":"select","label":"評価点の x₂","description":"列 2 の最初の刻み h₂ = 0.5 max(1, |x₂|) を変える。","options":["-0.5","-4"],"value":"-0.5"}
//| cases:
//|   - {"id":"weak-coupling","label":"γ = 0.01","description":"混入は小さくなるが、推定誤差には現れない。","inputs":{"coupling":"0.01"}}
//|   - {"id":"no-coupling","label":"γ = 0","description":"落とした要素が実際に 0 なので、2 色でも正しい値になる。","inputs":{"coupling":"0"}}
//|   - {"id":"large-step","label":"x₂ = −4","description":"刻みの比 h₂/h₀ が 4 になり、混入も 4 倍になる。","inputs":{"x2":"-4"}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"patterns","path":"/rows/0/1","equals":3}
//|       - {"artifact":"patterns","path":"/rows/0/5","range":{"max":1e-9}}
//|       - {"artifact":"patterns","path":"/rows/0/7","equals":0}
//|       - {"artifact":"patterns","path":"/rows/1/1","equals":2}
//|       - {"artifact":"patterns","path":"/rows/1/3","approx":{"value":2.5,"rtol":1e-9}}
//|       - {"artifact":"patterns","path":"/rows/1/4","approx":{"value":2.5,"rtol":1e-12}}
//|       - {"artifact":"patterns","path":"/rows/1/6","range":{"max":1e-8}}
//|       - {"artifact":"patterns","path":"/rows/1/7","approx":{"value":0.5,"rtol":1e-8}}
//|       - {"artifact":"patterns","path":"/rows/1/8","equals":"Converged"}
//|   - case: weak-coupling
//|     expect:
//|       - {"artifact":"patterns","path":"/rows/1/3","approx":{"value":2.01,"rtol":1e-9}}
//|       - {"artifact":"patterns","path":"/rows/1/6","range":{"max":1e-8}}
//|       - {"artifact":"patterns","path":"/rows/1/7","approx":{"value":0.01,"rtol":1e-6}}
//|   - case: no-coupling
//|     expect:
//|       - {"artifact":"patterns","path":"/rows/1/1","equals":2}
//|       - {"artifact":"patterns","path":"/rows/1/5","range":{"max":1e-9}}
//|       - {"artifact":"patterns","path":"/rows/1/7","equals":0}
//|   - case: large-step
//|     expect:
//|       - {"artifact":"patterns","path":"/rows/0/5","range":{"max":1e-9}}
//|       - {"artifact":"patterns","path":"/rows/1/3","approx":{"value":4,"rtol":1e-9}}
//|       - {"artifact":"patterns","path":"/rows/1/4","approx":{"value":4,"rtol":1e-12}}
use scioxide_core::SciOxideError;
use scioxide_differentiate::{AdaptiveDifference, ColoredJacobianPlan, FiniteDifference};
use scioxide_sparse::derivative_coloring;

let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let digits10 = serde_json::json!({ "significantDigits": 10 });
let gamma: f64 = coupling.parse().map_err(|_| "γ を読めない")?;
let x2: f64 = x2.parse().map_err(|_| "x₂ を読めない")?;
let x = [1.0_f64, 0.5, x2, 2.0];
let f = |p: &[f64], y: &mut [f64]| {
    y[0] = p[0] * p[0] + gamma * p[2];
    y[1] = p[0] + p[1] * p[1];
    y[2] = p[1] + p[2] * p[2];
    y[3] = p[2] + p[3] * p[3];
    Ok::<(), SciOxideError>(())
};
// 参照値: 解析的なヤコビ行列 J(i, j)。
let exact = |i: usize, j: usize| match (i, j) {
    (0, 2) => gamma,
    (i, j) if j == i => 2.0 * x[i],
    (i, j) if j + 1 == i => 1.0,
    _ => 0.0,
};
// 独立な検査: 密な固定刻みのヤコビ行列（行優先）。パターンの外の要素は 0 のはずである。
let dense = FiniteDifference::default()
    .jacobian(f, &x, 4, None, None)
    .map_err(|e| e.to_string())?
    .into_values()
    .map_err(|e| e.to_string())?;
// 列 j の最初の刻み h_j = 0.5 max(1, |x_j|)。比 h₂/h₀ は準位によらない。
let step = |v: f64| 0.5 * v.abs().max(1.0);
let mut rows = Vec::new();
for (name, row0) in [
    ("正しいパターン", vec![0, 2]),
    ("(0, 2) を落としたパターン", vec![0]),
] {
    let dropped = row0.len() == 1;
    // 行 0 は row0、行 i ≥ 1 は列 i − 1 と i。
    let pattern = csr_pattern(4, |i| if i == 0 { row0.clone() } else { vec![i - 1, i] })
        .map_err(|e| e.to_string())?;
    let schedule = derivative_coloring(pattern.view()).map_err(|e| e.to_string())?;
    let plan = ColoredJacobianPlan::new(&schedule, AdaptiveDifference::default())
        .map_err(|e| e.to_string())?;
    let result = plan.evaluate(f, &x, None).map_err(|e| e.to_string())?;
    let values = result.values().ok_or("ヤコビ行列が出力に反映されない")?;
    let estimates = result.errors().ok_or("推定誤差が出力に反映されない")?;
    let mixed = if dropped {
        gamma * step(x[2]) / step(x[0])
    } else {
        0.0
    };
    let view = pattern.view();
    let in_pattern = |i: usize, j: usize| {
        view.col_indices()[view.row_ptr()[i]..view.row_ptr()[i + 1]].contains(&j)
    };
    let largest_estimate = estimates.iter().copied().fold(0.0, f64::max);
    let outside = (0..16)
        .filter(|&k| !in_pattern(k / 4, k % 4))
        .map(|k| dense[k].abs())
        .fold(0.0, f64::max);
    let colors: Vec<String> = schedule.colors().iter().map(|c| c.to_string()).collect();
    rows.push((
        name,
        schedule.color_count(),
        colors.join(", "),
        values[0],
        2.0 * x[0] + mixed,
        stored_max_error(&pattern, values, exact),
        largest_estimate,
        outside,
        result.report().termination().to_string(),
    ));
}
let columns = serde_json::json!([
    { "key": "0", "label": "パターン" },
    { "key": "1", "label": "色の数", "type": "integer" },
    { "key": "2", "label": "列 0〜3 の色" },
    { "key": "3", "label": "J₀₀（真値 2）[-]", "type": "number", "format": digits10 },
    { "key": "4", "label": "予測 2x₀ + γh₂/h₀ [-]", "type": "number", "format": digits10 },
    { "key": "5", "label": "格納した要素の最大誤差 [-]", "type": "number", "format": sci3 },
    { "key": "6", "label": "最大の推定誤差 [-]", "type": "number", "format": sci3 },
    { "key": "7", "label": "パターン外の最大値 [-]", "type": "number", "format": sci3 },
    { "key": "8", "label": "終了理由" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "patterns" })
);
```

既定の $\gamma = 0.5$、$x_2 = -0.5$ では、正しいパターンは 3 色で、格納したすべての要素が解析解と一致する。
$(0, 2)$ を落としたパターンは 2 色（列の色 0, 1, 0, 1）になり、$J_{00}$ は真値 2 ではなく予測どおり $2 + 0.5 \cdot h_2 / h_0 = 2.5$ になる。
それでも推定誤差は $2.4 \times 10^{-14}$ のままで、終了理由は `Converged` で、エラーは出ない。
パターン外の最大値は正しいパターンでちょうど 0、落としたパターンで $\lvert J_{02} \rvert = 0.5$ になり、この独立な検査だけが漏れを見つける。

$\gamma = 0.01$ では $J_{00} = 2.01$ と混入は小さくなるが、推定誤差は変わらない。
$\gamma = 0$ では落とした要素が実際に 0 なので、2 色でも正しい値が得られ、パターン外の最大値も 0 になる。
$x_2 = -4$ にすると $h_2 / h_0 = 2 / 0.5 = 4$ になり、$J_{00}$ は $2 + 0.5 \cdot 4 = 4$ と混入が 4 倍になる。
混入の大きさは $J_{02}$ だけでなく刻みの比で決まるので、変数の尺度が違うと誤差はさらに大きくなりうる。

## まとめ

疎なヤコビ行列では構造的に直交する列を一つの色にまとめて同時に摂動でき、評価回数は列の数ではなく色の数に比例する。
色の数は行あたりの要素の最大数以上で、帯行列では帯幅だけで決まり、`derivative_coloring` が列の番号順の貪欲法で彩色を作る。
`ColoredJacobianPlan` は列ごとに適応差分の表を持ち、同じ色の列で摂動した点を共有し、値と推定誤差を CSR の格納順に返す。
評価回数は区間の有無によらず $1 + 2\sum_C L_C$ で、色ごとの最も遅い列の準位数で決まり、関数が同じ色の他の列の変数を読まなければ、値は密な適応差分の同じ列と一致する。
`StructuralPattern` が実際の非零を落とすと、値は同じ色の別の列に混ざり、エラーも推定誤差の増加もなく `Converged` で誤った結果が返るので、パターンは一度だけ密な差分や自動微分で確かめてから使う。
