前進差分や中心差分は、等間隔の 2 点や 3 点を使う特別な場合である。
不等間隔の表の値、境界の近くの片側の節点、5 点や 7 点の高次の公式では、節点の位置から重みを計算する必要がある。
このページでは、重みが満たすべきモーメント条件を導き、それを安定に解く Fornberg の漸化式と、節点を増やしたときのノイズの拡大を説明する。
`scioxide-differentiate` では、呼び出し側が持つ値に掛ける重みを `FiniteDifferenceStencil` が作る。
関数を呼べるときに節点を指定して導関数を求める Plan と手法オブジェクトは、[節点を指定する差分の Plan と手法オブジェクト](../node-difference-plans/) で扱う。

## モーメント条件

評価点 $x_0$ と相異なる $N$ 個の節点 $x_1, \dots, x_N$ をとり、$m$ 階導関数を関数値の一次結合で近似する。

$$
f^{(m)}(x_0) \approx \sum_{j=1}^{N} w_j f(x_j).
$$

係数 $w_j$ を差分の重みといい、節点と重みの組をステンシルという。
$f$ は $x_0$ の近くで十分に滑らかとする。
変位を $\Delta_j = x_j - x_0$ と書き、$f(x_j)$ を $x_0$ のまわりで Taylor 展開すると、近似は次のように書ける。

$$
\sum_{j=1}^{N} w_j f(x_j) = \sum_{k \ge 0} \frac{f^{(k)}(x_0)}{k!} \sum_{j=1}^{N} w_j \Delta_j^{\,k} .
$$

右辺が $f^{(m)}(x_0)$ と一致するには、$k = m$ の係数が 1 で、ほかの $k$ の係数が 0 でなければならない。
未知数は $N$ 個なので、$k = 0, \dots, N - 1$ の $N$ 個の条件を課す。

$$
\sum_{j=1}^{N} w_j \Delta_j^{\,k} = k! \, \delta_{km} \qquad (k = 0, 1, \dots, N - 1).
$$

これをモーメント条件という。
係数行列は $(\Delta_j^{\,k})$ で、転置した Vandermonde 行列になる。
節点が相異なれば行列は正則なので、$m < N$ である限り重みは一意に決まる。
こうして作った公式は $N - 1$ 次以下の多項式を正確に微分する。

誤差は条件を課さなかった最初の $k = N$ の項から始まる。
節点の広がりを $s = \max_j \lvert \Delta_j \rvert$ とすると、$\Delta_j^{\,k} = O(s^k)$、重みは $O(s^{-m})$ なので、打ち切り誤差は $O(s^{N - m})$ になる。

$$
\sum_{j} w_j f(x_j) - f^{(m)}(x_0) = \frac{f^{(N)}(x_0)}{N!} \sum_{j} w_j \Delta_j^{\,N} + O(s^{N + 1 - m}).
$$

節点が $x_0$ について対称なら、重みは $m$ が奇数のとき奇関数、偶数のとき偶関数になる。
すると $k - m$ が奇数の項 $\sum_j w_j \Delta_j^{\,k}$ は打ち消し合って 0 になる。
$N - m$ が奇数なら $k = N$ の項が消え、次数は 1 つ上がって $N + 1 - m$ になる。
$N - m$ が偶数なら $k = N$ の項は消えず、次数は $N - m$ のままである。
3 点の中心差分は一階（$N - m = 2$）でも二階（$N - m = 1$）でも二次になる。
5 点の中心差分は一階でも二階でも四次になる。

## Vandermonde 系を直接解かない理由

節点が実数なら、転置 Vandermonde 行列の条件数は節点数とともに指数関数的に大きくなる。
一般の Gauss 消去で解くと $O(N^3)$ の演算がかかり、節点が多いほど重みの有効数字が失われる。
Vandermonde 構造を使うアルゴリズム（Björck–Pereyra の方法や、次に述べる Fornberg の方法）は、多くの場合、条件数から予想されるより正確に重みを求める。
Fornberg の方法は $0$ から $m$ 階までの重みを $O(N^2 (m + 1))$ の演算で同時に作るので、`scioxide-differentiate` はこれを使う。

## Fornberg の漸化式

Fornberg（1988）の方法は、Lagrange 補間多項式の導関数を、節点を 1 つずつ加えながら更新する。
評価点を原点にとり、節点を $\alpha_0, \alpha_1, \dots$（評価点からの変位）と並べる。
節点 $\alpha_0, \dots, \alpha_n$ の $n + 1$ 個を使う $m$ 階の重みのうち、節点 $\alpha_\nu$ に掛かるものを $\delta^{m}_{n,\nu}$ と書く。
初期値は $\delta^{0}_{0,0} = 1$ とする。
$c_0 = 1$、$c_n = \prod_{\nu < n} (\alpha_n - \alpha_\nu)$ とおくと、節点 $\alpha_n$ を加えたときに既存の節点の重みは次のように更新される。

$$
\delta^{m}_{n,\nu} = \frac{\alpha_n \, \delta^{m}_{n-1,\nu} - m \, \delta^{m-1}_{n-1,\nu}}{\alpha_n - \alpha_\nu} \qquad (\nu < n).
$$

新しく加えた節点の重みは、一つ前の段の最後の重みから作る。

$$
\delta^{m}_{n,n} = \frac{c_{n-1}}{c_n} \left( m \, \delta^{m-1}_{n-1,n-1} - \alpha_{n-1} \, \delta^{m}_{n-1,n-1} \right).
$$

$m$ が負になる項と、$m > n$ の重みは 0 とみなす。
すべての節点を加えたあとの $\delta^{m}_{N-1,\nu}$ が求める重みで、同時に $0$ から $m$ 階までの重みが得られる。
節点 1 つを加える段の演算は既存の節点の数と階数の数 $m + 1$ の積に比例するので、全体は $O(N^2 (m + 1))$ である。

## SciOxide の実装

[`FiniteDifferenceStencil`](https://docs.rs/scioxide-differentiate/0.1.0/scioxide_differentiate/struct.FiniteDifferenceStencil.html)`::new(c, nodes, order)` は、点 `c` で `order` 階の導関数を近似する重みを、呼び出し側が選んだ節点 `nodes` について作る。
節点は等間隔でなくてよく、`c` の片側にあってもよい。
節点の並びは保たれ、`apply(values)` は同じ並びの値に重みを掛けて、物理単位の導関数を返す。
値は実数でも複素数でもよい。
`order = 0` は補間になる。
重みを作る計算では次の三つの処理をする。

まず、変位の最大の絶対値 $s = \max_j \lvert x_j - c \rvert$ で変位を割り、$[-1, 1]$ の正規化した変位で漸化式を回す。
漸化式の積 $c_n$ は節点の数とともに幾何級数的に増減するので、変位の大きさをそろえて桁あふれを防ぐ。
物理単位の重みは正規化した重みを $s^m$ で割ったものである。

次に、評価点に近い節点から順に漸化式に加える。
節点が一部に集まった格子では、遠い節点から加えると途中の値の桁が大きく動くからである。

最後に、正規化した変位の集合が符号の反転で閉じている（どの節点にも鏡像の節点がある）とき、重みの偶奇を強制する。
奇数階の重みは反対称、偶数階の重みは対称になるはずなので、対になる二つの重みを符号を合わせて平均した値で置き換え、丸めによる偶奇の崩れを除く。

`apply` は、$m \ge 1$ のとき、評価点に最も近い節点の値と、その鏡像の位置の節点の値の中点を全標本から引いてから重みを掛ける。
鏡像の節点がなければ、最も近い節点の値だけを引く。
重みの和は数学的には 0 なので結果は変わらず、定数のデータは丸めの残っている重みでも正確に 0 になる。
積和は各積を丸めずに足し込む累積器（`scioxide_core::RangeAccumulator`）で計算し、最後に一度だけ丸める。
準備の計算量は $O(N^2 (m + 1))$ で、`apply` は 1 回の呼び出しが $O(N)$ の演算で、確保はしない。

重みと補助の量は次のメソッドで読む。

| メソッド | 返す値 |
|---|---|
| `normalized_weights()` | 正規化した変位 $(x_j - c)/s$ に対する重み $w_j$ |
| `weights()`、`weights_into(out)` | 物理単位の重み $w_j / s^m$（`weights` は確保した配列、`weights_into` は呼び出し側の配列） |
| `scale()` | 変位の尺度 $s$ |
| `weight_amplification()` | 正規化した重みの絶対値の和 $A_w = \sum_j \lvert w_j \rvert$ |
| `coordinate()`、`nodes()`、`derivative_order()` | 評価点 $c$、節点、階数 $m$ |

`weights` は各重みを $s^m$ で一度だけ割り、$s^m$ を途中で丸めない。
対称性で 0 になる重み（3 点の中心差分の中央の重みなど）は正確に 0 になる。
`weights_into` はすべての重みを計算してから書き込むので、エラーのときは `out` を変えない。
重みと値の積和には、基準値を引いて丸めのない累積で計算する `apply` を使う。

`new` は、有限でない評価点や節点を `NonFinite`、空の節点と $m \ge N$ を `InvalidInput`（`nodes`、`OutOfRange`）、重複した節点を `InvalidInput`（`nodes`、`Inconsistent`）で拒む。
正規化のあとで節点が区別できなくなるか、漸化式があふれると `NumericalInstability` になる。
`apply` は値の数が節点の数と違えば `DimensionMismatch`、有限でない値があれば `NonFinite`、結果があふれるか 0 でない値が 0 にアンダーフローすれば `NumericalInstability` を返す。
`weights` と `weights_into` は、物理単位の重みがあふれるか 0 にアンダーフローすると `NumericalInstability` を返し、`weights_into` は `out` の長さが違えば `DimensionMismatch` を返す。

## 重みの絶対値の和とノイズの拡大

関数値が誤差 $e_j$（$\lvert e_j \rvert \le \sigma$）を含むとき、導関数の誤差のうち値の誤差による部分は次のように抑えられる。

$$
\Bigl\lvert \sum_j w_j e_j \Bigr\rvert \le \sigma \sum_j \lvert w_j \rvert .
$$

$e_j$ が平均 0、分散 $\sigma^2$ の独立な誤差なら、標準偏差は $\sigma \sqrt{\sum_j w_j^2}$ になる。
`weight_amplification()` は正規化した重みの絶対値の和 $A_w$ を返し、物理単位の和は $A_w / s^m$ である。
これは値の誤差の拡大の目安で、打ち切り誤差を含む導関数の誤差全体の上界ではない。

等間隔の中心差分の一階の公式では、$A_w$ は 3 点で 1、5 点で 3、7 点で 5.5 と穏やかに増える。
節点の間隔を $h$ とすると $s = (N - 1) h / 2$ なので、物理単位では $1/h$、$1.5/h$、$1.83/h$ で、節点を増やしてもノイズの拡大はあまり変わらない。
片側の一階の公式では、物理単位の和が 3 点で $4/h$、5 点で $10.7/h$、7 点で $27.7/h$ と急速に増え（$A_w$ は 8、42.7、166）、高次にしてもノイズの多いデータでは結果が悪くなる。
高次の公式が有利かどうかは、打ち切り誤差の減り方と、この拡大の釣り合いで決まる。

## モーメント条件と誤差の主項の実測

次のセルは節点の配置と数と階数を選んで `FiniteDifferenceStencil` を作り、正規化した変位 $\xi_j$ と重みでモーメントの残差 $\sum_j w_j \xi_j^{\,k} / k! - \delta_{km}$ を計算する。
$k < N$ では残差は丸めの大きさになり、$k \ge N$ の最初の 0 でないモーメント $\mu_{k^\ast}$ が誤差の主項 $f^{(k^\ast)}(x_0) s^{k^\ast - m} \mu_{k^\ast}$ を決める。
被微分関数は $f(x) = e^x$、評価点は $x_0 = 0.3$、節点の基本の間隔は $0.1$ である。
不等間隔の配置は等間隔の位置 $t_j$ を $t_j (1 + 0.15 t_j)$ に動かして作る。
主計算は `FiniteDifferenceStencil::apply` で、厳密値と主項の予測は f64 の参照値、モーメントの残差は重みからの後処理である。
間隔を半分にした節点でも導関数を計算し、誤差の比の $\log_2$ を観測次数として、主項の次数と比べる。
丸めの目安 $u \sum_j \lvert w_j \rvert \lvert f \rvert$ は、`weights()` が返す物理単位の重みから求める。

```rust
//| id: differentiate-stencil-moments
//| ref: differentiate-stencil-moments
//| title: 任意の節点の重みのモーメント条件と誤差の主項
//| run: reactive
//| crates: [scioxide-core, scioxide-differentiate]
//| inputs:
//|   layout: {"type":"select","label":"節点の配置","description":"評価点 x₀ に対する節点の並べ方。","options":["中心・等間隔","中心・不等間隔","片側・等間隔"],"value":"中心・不等間隔"}
//|   count: {"type":"range","label":"節点の数 N","min":3,"max":7,"step":1,"value":5}
//|   order: {"type":"select","label":"微分の階数 m","options":["1","2"],"value":"1"}
//| cases:
//|   - {"id":"central-second","label":"中心・等間隔、N = 5、m = 2","description":"k = 5 のモーメントが対称性で消え、次数は N − m = 3 より 1 つ高い 4 になる。","inputs":{"layout":"中心・等間隔","order":"2"}}
//|   - {"id":"one-sided-three","label":"片側・等間隔、N = 3、m = 1","description":"片側 3 点の公式は A_w = 8 で、二次の主項 −h²f‴/3 を持つ。","inputs":{"layout":"片側・等間隔","count":3}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"moments","path":"/rows/0/1","range":{"min":-1e-14,"max":1e-14}}
//|       - {"artifact":"moments","path":"/rows/4/1","range":{"min":-1e-14,"max":1e-14}}
//|       - {"artifact":"summary","path":"/rows/0/2","equals":4}
//|       - {"artifact":"summary","path":"/rows/0/3","approx":{"value":-4.0e-6,"rtol":0.05}}
//|       - {"artifact":"summary","path":"/rows/0/6","approx":{"value":4,"atol":0.2}}
//|   - case: central-second
//|     expect:
//|       - {"artifact":"moments","path":"/rows/5/1","range":{"min":-1e-14,"max":1e-14}}
//|       - {"artifact":"summary","path":"/rows/0/1","approx":{"value":21.333333333333332,"rtol":1e-12}}
//|       - {"artifact":"summary","path":"/rows/0/2","equals":4}
//|       - {"artifact":"summary","path":"/rows/0/3","approx":{"value":-1.49984e-6,"rtol":0.02}}
//|       - {"artifact":"summary","path":"/rows/0/6","approx":{"value":4,"atol":0.1}}
//|   - case: one-sided-three
//|     expect:
//|       - {"artifact":"summary","path":"/rows/0/1","approx":{"value":8,"rtol":1e-12}}
//|       - {"artifact":"summary","path":"/rows/0/4","approx":{"value":-4.4995293586e-3,"rtol":1e-9}}
//|       - {"artifact":"summary","path":"/rows/0/6","approx":{"value":2,"atol":0.15}}
use scioxide_core::{SciOxideError, RealScalar};
use scioxide_differentiate::FiniteDifferenceStencil;

let (x0, spacing) = (0.3_f64, 0.1_f64);
let count = count as usize;
let order: usize = order.parse().map_err(|_| "階数を読めない")?;
// 評価点からの変位を、基本の間隔の倍数 t_j で与える。
let offsets: Vec<f64> = (0..count)
    .map(|j| {
        let t = j as f64 - (count - 1) as f64 / 2.0;
        match layout.as_str() {
            "片側・等間隔" => j as f64,
            "中心・等間隔" => t,
            _ => t * (1.0 + 0.15 * t),
        }
    })
    .collect();
// 主計算: 間隔 d の節点で e^x の m 階導関数を求め、ステンシルとともに返す。
let solve = |d: f64| {
    let nodes: Vec<f64> = offsets.iter().map(|t| x0 + d * t).collect();
    let stencil = FiniteDifferenceStencil::new(x0, &nodes, order)?;
    let values: Vec<f64> = nodes.iter().map(|&x| RealScalar::exp(x)).collect();
    Ok::<_, SciOxideError>((stencil.apply(&values)?, stencil))
};
let (derivative, stencil) = solve(spacing).map_err(|e| e.to_string())?;
let (halved, _) = solve(spacing / 2.0).map_err(|e| e.to_string())?;
// 参照値: e^x の導関数はすべて e^{x0}（f64 の固有メソッド）。
let exact = x0.exp();
// 後処理: 正規化した変位 ξ_j でモーメント Σ w_j ξ_j^k / k! を計算する。
let s = stencil.scale();
let xi: Vec<f64> = stencil.nodes().iter().map(|x| (x - x0) / s).collect();
let moment = |k: usize| {
    let factorial: f64 = (1..=k).map(|i| i as f64).product();
    let sum: f64 = stencil
        .normalized_weights()
        .iter()
        .zip(&xi)
        .map(|(w, x)| w * x.powi(k as i32))
        .sum();
    sum / factorial
};
let mut rows = Vec::new();
let mut leading = None;
for k in 0..count + 2 {
    let residual = moment(k) - if k == order { 1.0 } else { 0.0 };
    if k >= count && leading.is_none() && residual.abs() > 1e-12 {
        leading = Some((k, residual));
    }
    rows.push((k, residual, if k < count { "条件" } else { "誤差の項" }));
}
let (fixed2, fixed3) = (
    serde_json::json!({ "fractionDigits": 2 }),
    serde_json::json!({ "fractionDigits": 3 }),
);
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let columns = serde_json::json!([
    { "key": "0", "label": "k", "type": "integer" },
    { "key": "1", "label": "Σ w_j ξ_j^k / k! − δ_km [-]", "type": "number", "format": sci3 },
    { "key": "2", "label": "種類" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "moments" })
);
let (k_star, mu) = leading.ok_or("先頭のモーメントが見つからない")?;
// 主項の予測 f^(k*)(x0) s^(k*−m) μ_k*（参照値 e^{x0} を使う）。
let predicted = exact * s.powi((k_star - order) as i32) * mu;
// 丸めの目安 u Σ|w_j| |f|。物理単位の重み w_j / s^m を weights() で読む。
let weights = stencil.weights().map_err(|e| e.to_string())?;
let spread: f64 = weights.iter().map(|w| w.abs()).sum();
// 観測次数: 間隔を半分にしたときの誤差の比の log₂。
let observed = ((derivative - exact) / (halved - exact)).abs().log2();
let summary = vec![(
    s,
    stencil.weight_amplification(),
    k_star - order,
    derivative - exact,
    predicted,
    f64::EPSILON / 2.0 * spread * exact,
    observed,
)];
let columns = serde_json::json!([
    { "key": "0", "label": "尺度 s [-]", "type": "number", "format": fixed3 },
    { "key": "1", "label": "A_w [-]", "type": "number", "format": fixed3 },
    { "key": "2", "label": "主項の次数 k* − m", "type": "integer" },
    { "key": "3", "label": "実測の誤差 [-]", "type": "number", "format": sci3 },
    { "key": "4", "label": "主項の予測 [-]", "type": "number", "format": sci3 },
    { "key": "5", "label": "丸めの目安 [-]", "type": "number", "format": sci3 },
    { "key": "6", "label": "観測次数 [-]", "type": "number", "format": fixed2 }
]);
emit_table_with_columns!(
    columns,
    summary,
    metadata = serde_json::json!({ "id": "summary" })
);
```

既定の中心・不等間隔の 5 点、一階では、$k = 0$ から 4 までの残差は $3 \times 10^{-16}$ 以下で、条件は丸めの範囲で満たされている。
節点が非対称なので $k = 5$ のモーメント（$-6.5 \times 10^{-4}$）が 0 にならず、主項の次数は $N - m = 4$ になる。
実測の誤差 $-4.11 \times 10^{-6}$ と主項の予測 $-4.00 \times 10^{-6}$ の差は 3 % で、差は次の $k = 6$ の項から来る。
間隔を半分にしたときの観測次数は 4.02 で、丸めの目安 $4.0 \times 10^{-15}$ は誤差より 9 桁小さい。

中心・等間隔の 5 点で $m = 1$ にすると、$k = 5$ のモーメントは残り、次数は $N - m = 4$ のままである。
同じ節点で $m = 2$ にすると（ケース central-second）、$k - m$ が奇数の $k = 5$ のモーメントは $2 \times 10^{-18}$ まで消え、主項は $k = 6$ に移る。
次数は $N - m = 3$ より 1 つ高い 4 になり、観測次数も 4.00 になる。
主項の予測 $-1.500 \times 10^{-6}$ は Taylor 展開から求めた $-h^4 f^{(6)}(x_0) / 90$ に一致する。
$A_w = 21.33$ は重み $(-1, 16, -30, 16, -1)/(12 h^2)$ に $s^2 = 4h^2$ を掛けた絶対値の和 $64/3$ に一致する。

片側・等間隔の 3 点（ケース one-sided-three）では $A_w = 8$ になる。
物理単位の和は $8/s = 4/h$ で、3 点の中心差分の $1/h$ の 4 倍である。
主項の予測は $-h^2 f'''(x_0)/3 = -4.50 \times 10^{-3}$、観測次数は 2.05 になる。
実測の誤差 $-4.85 \times 10^{-3}$ が予測より 8 % 大きいのは、片側の公式では $k = 4$ の項 $-h^3 f^{(4)}(x_0)/4$ も消えないからである。

## 節点数とノイズの拡大の実測

次のセルは等間隔の中心差分の一階の公式を 3、5、7 点で作り、ノイズを含む関数 $f(x) = e^x + \sigma \eta(x)$ の $x_0 = 0.5$ での導関数の誤差を、間隔 $h$ に対して描く。
$\eta$ は [丸め誤差・ノイズと最適な刻み幅](oxref:differentiate-noisy-functions) と同じ、点のビット列とシードから作る $[-1, 1)$ の擬似乱数である。
節点の値は `apply` に渡し、重みは `FiniteDifferenceStencil` が作る。

誤差を読むために、上界のモデルを置く。
$N$ 点の公式の主項は $c_N h^{N-1} f^{(N)}(x_0)$ で、ノイズによる誤差は $\sigma \sum_j \lvert w_j \rvert = \sigma B_N / h$（$B_N = h \sum_j \lvert w_j \rvert$ は間隔によらない）以下である。

$$
E_N(h) = c_N h^{p} e^{x_0} + \frac{\sigma B_N}{h}, \qquad p = N - 1 .
$$

$E_N$ を最小にする間隔と最小値は次のとおりである。

$$
h^\ast = \left( \frac{\sigma B_N}{p \, c_N e^{x_0}} \right)^{1/(p+1)}, \qquad E_N(h^\ast) = \frac{\sigma B_N}{h^\ast} \left( 1 + \frac{1}{p} \right).
$$

セルは間隔 1 の節点の重みを `weights()` で読み、$B_N$ と $c_N = \lvert \sum_j w_j t_j^{\,N} \rvert / N!$ を求める。
Taylor 展開から求めた値は $c_3 = 1/6$、$c_5 = 1/30$、$c_7 = 1/140$ である。
図の破線はモデル $E_N(h)$、記号は実測の誤差で、誤差が正確に 0 になった点は対数軸に描けないので除き、その数を表に示す。

```rust
//| id: differentiate-stencil-noise
//| ref: differentiate-stencil-noise
//| title: 節点数の異なる中心差分のノイズの拡大と打ち切り誤差
//| run: reactive
//| crates: [scioxide-core, scioxide-differentiate]
//| inputs:
//|   sigma: {"type":"select","label":"ノイズの大きさ σ","options":["1e-12","1e-8","1e-4"],"value":"1e-8"}
//|   seed: {"type":"range","label":"乱数のシード","min":1,"max":20,"step":1,"value":1}
//| cases:
//|   - {"id":"large-noise","label":"σ = 10⁻⁴","description":"モデルの最適な間隔は 7 点で 0.4 を超え、点数を増やしたときの改善が小さくなる。","inputs":{"sigma":"1e-4"}}
//|   - {"id":"other-seed","label":"シード 20","description":"ノイズの並びを変えると、実測で最良の誤差の順位が入れ替わる。","inputs":{"seed":20}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"noise","path":"/rows/0/1","approx":{"value":1,"rtol":1e-12}}
//|       - {"artifact":"noise","path":"/rows/1/1","approx":{"value":3,"rtol":1e-12}}
//|       - {"artifact":"noise","path":"/rows/2/1","approx":{"value":5.5,"rtol":1e-12}}
//|       - {"artifact":"noise","path":"/rows/2/2","approx":{"value":1.8333333333333333,"rtol":1e-12}}
//|       - {"artifact":"noise","path":"/rows/0/3","approx":{"value":0.16666666666666666,"rtol":1e-12}}
//|       - {"artifact":"noise","path":"/rows/1/3","approx":{"value":0.03333333333333333,"rtol":1e-12}}
//|       - {"artifact":"noise","path":"/rows/2/3","approx":{"value":0.007142857142857143,"rtol":1e-12}}
//|       - {"artifact":"noise","path":"/rows/0/7","range":{"max":5.8e-6}}
//|       - {"artifact":"noise","path":"/rows/2/5","approx":{"value":1.8665e-7,"rtol":1e-3}}
//|   - case: large-noise
//|     expect:
//|       - {"artifact":"noise","path":"/rows/2/4","range":{"min":0.4,"max":0.45}}
//|       - {"artifact":"noise","path":"/rows/0/7","range":{"max":2.7e-3}}
//|   - case: other-seed
//|     expect:
//|       - {"artifact":"noise","path":"/rows/1/7","range":{"max":6e-7}}
use scioxide_core::RealScalar;
use scioxide_differentiate::FiniteDifferenceStencil;

let sigma: f64 = sigma.parse().map_err(|_| "σ を読めない")?;
let seed = seed as u64;
// ノイズのモデル: 点のビット列とシードを splitmix64 で混ぜ、[-1, 1) の値にする。
let noise = |t: f64| {
    let mut z = t.to_bits() ^ seed.wrapping_mul(0x9E37_79B9_7F4A_7C15);
    z = (z ^ (z >> 30)).wrapping_mul(0xBF58_476D_1CE4_E5B9);
    z = (z ^ (z >> 27)).wrapping_mul(0x94D0_49BB_1331_11EB);
    z ^= z >> 31;
    (z >> 11) as f64 / (1_u64 << 53) as f64 * 2.0 - 1.0
};
let x0 = 0.5_f64;
// 参照値: f の導関数はすべて e^{x0}（f64 の固有メソッド）。
let exact = x0.exp();
let mut series = Vec::new();
let mut rows = Vec::new();
for count in [3_usize, 5, 7] {
    // 間隔 1 の節点 t_j の重みから B_N = h Σ|w_j| と c_N = |Σ w_j t_j^N| / N! を求める。
    let unit: Vec<f64> = (0..count).map(|j| j as f64 - (count / 2) as f64).collect();
    let reference = FiniteDifferenceStencil::new(0.0, &unit, 1).map_err(|e| e.to_string())?;
    let weights = reference.weights().map_err(|e| e.to_string())?;
    let spread: f64 = weights.iter().map(|w| w.abs()).sum();
    let factorial: f64 = (1..=count).map(|i| i as f64).product();
    let moment: f64 = weights
        .iter()
        .zip(&unit)
        .map(|(w, t)| w * t.powi(count as i32))
        .sum();
    let leading = moment.abs() / factorial;
    let p = (count - 1) as f64;
    let h_star = (sigma * spread / (p * leading * exact)).powf(1.0 / (p + 1.0));
    let e_star = sigma * spread / h_star * (1.0 + 1.0 / p);
    let (mut measured, mut model, mut dropped) = (Vec::new(), Vec::new(), 0_usize);
    let mut best = (f64::INFINITY, 0.0);
    for k in 0..=40 {
        let h = 10.0_f64.powf(-8.0 + 0.2 * k as f64);
        let nodes: Vec<f64> = unit.iter().map(|t| x0 + h * t).collect();
        let stencil = FiniteDifferenceStencil::new(x0, &nodes, 1).map_err(|e| e.to_string())?;
        let values: Vec<f64> = nodes
            .iter()
            .map(|&x| RealScalar::exp(x) + sigma * noise(x))
            .collect();
        let error = (stencil.apply(&values).map_err(|e| e.to_string())? - exact).abs();
        model.push([h, leading * h.powf(p) * exact + sigma * spread / h]);
        if error > 0.0 {
            measured.push([h, error]);
        } else {
            dropped += 1;
        }
        if error < best.0 {
            best = (error, h);
        }
    }
    let amplification = reference.weight_amplification();
    rows.push((
        count,
        amplification,
        spread,
        leading,
        h_star,
        e_star,
        best.1,
        best.0,
        dropped,
    ));
    let dashed = serde_json::json!({ "lineType": "dashed" });
    let marked = serde_json::json!({ "showSymbol": true, "symbol": "circle" });
    series.push(serde_json::json!({
        "name": format!("{count} 点（実測）"),
        "points": measured,
        "style": marked
    }));
    series.push(serde_json::json!({
        "name": format!("{count} 点（モデル E_N）"),
        "points": model,
        "style": dashed
    }));
}
let (fixed3, sci3) = (
    serde_json::json!({ "fractionDigits": 3 }),
    serde_json::json!({ "notation": "scientific", "significantDigits": 3 }),
);
let columns = serde_json::json!([
    { "key": "0", "label": "節点の数 N", "type": "integer" },
    { "key": "1", "label": "A_w [-]", "type": "number", "format": fixed3 },
    { "key": "2", "label": "B_N = h Σ|w_j| [-]", "type": "number", "format": fixed3 },
    { "key": "3", "label": "主項の係数 c_N [-]", "type": "number", "format": sci3 },
    { "key": "4", "label": "モデルの最適な h* [-]", "type": "number", "format": sci3 },
    { "key": "5", "label": "モデルの最小誤差 E_N(h*) [-]", "type": "number", "format": sci3 },
    { "key": "6", "label": "実測で最良の h [-]", "type": "number", "format": sci3 },
    { "key": "7", "label": "実測の最良の誤差 [-]", "type": "number", "format": sci3 },
    { "key": "8", "label": "除いた誤差 0 の点 [個]", "type": "integer" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "noise" })
);
emit_line_chart!(
    &series,
    options = &serde_json::json!({
        "xLabel": "節点の間隔 h [-]",
        "yLabel": "導関数の絶対誤差 [-]",
        "xType": "log",
        "yType": "log"
    })
);
```

表の $A_w$ と $B_N$ は前節の値（1、3、5.5 と 1、1.5、1.83）に一致し、重みから求めた $c_N$ は Taylor 展開の値 $1/6$、$1/30$、$1/140$ に一致する。
既定の $\sigma = 10^{-8}$ では、モデルの最小誤差は 3 点で $5.7 \times 10^{-6}$、5 点で $5.1 \times 10^{-7}$、7 点で $1.9 \times 10^{-7}$ と下がる。
最適な間隔は $2.6 \times 10^{-3}$、$3.7 \times 10^{-2}$、$0.11$ と大きくなる。
ノイズの拡大 $B_N$ がほとんど増えない一方で、打ち切り誤差は $h^2$、$h^4$、$h^6$ と速く下がるからである。

図の実測の誤差は、ノイズの項 $\sigma B_N / h$ が支配する小さい $h$ では破線の下で揺れ、打ち切りの項が支配する大きい $h$ では破線に沿う。
モデルのノイズの項はノイズが最悪の向きにそろった場合の上界なので、実測の誤差はふつうそれより小さい。
実測で最良の誤差（3 点で $1.2 \times 10^{-6}$）は $h = 4.0 \times 10^{-4}$ で得られ、その $h$ でのノイズの上界 $2.5 \times 10^{-5}$ より 1 桁以上小さい。
その $h$ で 2 つの節点のノイズがたまたま近い値をとったためである。
シードを 20 に変えると（ケース other-seed）、最良の誤差は 3 点で $1.5 \times 10^{-8}$、7 点で $2.2 \times 10^{-8}$ になり、公式の順位が入れ替わる。
1 つの実現の最良の値は偶然に左右されるので、公式を選ぶときはモデルの最小誤差で比べる。

$\sigma = 10^{-4}$（ケース large-noise）では、最適な間隔が 3 点で 0.057、7 点で 0.43 まで大きくなる。
モデルの最小誤差は $2.6 \times 10^{-3}$、$8.1 \times 10^{-4}$、$5.0 \times 10^{-4}$ で、点数を増やしたときの改善は小さくなる。
7 点の最適な間隔では節点が $x_0 \pm 1.3$ まで広がり、主項だけのモデルは粗い近似になる。
等間隔の中心差分では、節点を増やすことはノイズの拡大をほとんど増やさずに打ち切り誤差を減らすが、その利点はノイズが大きいほど小さい。

## まとめ

$N$ 個の節点で $m$ 階導関数を近似する重みは、モーメント条件 $\sum_j w_j \Delta_j^{\,k} = k!\,\delta_{km}$（$k < N$）で一意に決まり、打ち切り誤差は $O(s^{N - m})$、対称な節点で $N - m$ が奇数なら $O(s^{N + 1 - m})$ になる。
主項は最初に残るモーメントから予測でき、間隔を半分にしたときの誤差の比で次数を確かめられる。
`FiniteDifferenceStencil` は Fornberg の漸化式を正規化した変位で回し、物理単位の重みを `weights` で、ノイズの拡大の目安 $A_w$ を `weight_amplification` で返す。
等間隔の中心差分では節点を増やしてもノイズの拡大はほとんど増えないが、片側の公式では急速に増えるので、ノイズのある値には上界のモデル $E_N(h)$ で節点の数と間隔を選ぶ。
値の表しかないときは `FiniteDifferenceStencil` の `apply` で導関数を求め、関数を呼べるときは節点を指定する Plan か節点を指定する差分法オブジェクトに節点を渡す。
