関数 $f$ を評価できるが導関数の式がないとき、有限差分は点 $x$ の近くの数点で $f$ を評価し、その値の一次結合で導関数を近似する。
評価する点を節点、節点と $x$ の差を変位、変位の大きさの目安を刻み幅（刻み）$h$ と呼ぶ（記号の一覧は [数値微分のアルゴリズムの共通仕様と構成](oxref:differentiate-notation) にある）。
近似の誤差は 2 つに分かれる。
1 つは Taylor 展開を有限の項で打ち切ったことによる打ち切り誤差で、$h$ を小さくすると減る。
もう 1 つは関数値と引き算の丸め誤差で、$h$ を小さくすると増える。
このページでは打ち切り誤差を導いて次数を実測し、固定刻みの差分 `FiniteDifference` が刻みをどう決め、節点をどう置き、重みをどう作るかを説明する。
丸め誤差とノイズ、2 つの誤差の釣り合いで決まる最適な刻みは [丸め誤差・ノイズと最適な刻み幅](../roundoff-and-noisy-functions/) で扱う。

## 前進差分と中心差分

$f$ が $x$ の近くで十分に滑らかなとき、$x \pm h$ での値は次のように展開できる。

$$
\begin{aligned}
f(x + h) &= f(x) + h f'(x) + \frac{h^2}{2} f''(x) + \frac{h^3}{6} f'''(x) + \frac{h^4}{24} f^{(4)}(x) + O(h^5), \\
f(x - h) &= f(x) - h f'(x) + \frac{h^2}{2} f''(x) - \frac{h^3}{6} f'''(x) + \frac{h^4}{24} f^{(4)}(x) + O(h^5).
\end{aligned}
$$

第 1 式から $f(x)$ を引いて $h$ で割ると、前進差分が得られる。
$f$ が $C^2$ 級なら、Taylor の定理の Lagrange 型の剰余項から、ある $\xi \in (x, x + h)$ について次が成り立つ。

$$
D_h^{+} f(x) = \frac{f(x + h) - f(x)}{h} = f'(x) + \frac{h}{2} f''(\xi).
$$

誤差が $h^p$ に比例して減るとき、その公式は $p$ 次の精度を持つという。
前進差分の誤差は $h$ に比例するので、前進差分の精度は 1 次である。

第 1 式から第 2 式を引くと、$f(x)$ と偶数次の項が消える。
$f$ が $C^3$ 級なら、2 つの剰余項 $f'''(\xi_\pm)$ の平均を中間値の定理で 1 つの $f'''(\xi)$ にまとめられ、ある $\xi \in (x - h, x + h)$ について次が成り立つ。

$$
D_h^{0} f(x) = \frac{f(x + h) - f(x - h)}{2h} = f'(x) + \frac{h^2}{6} f'''(\xi).
$$

中心差分は 2 次の精度を持ち、$h$ が小さければ前進差分より誤差が小さい。
節点 $x - h, x, x + h$ に対する重みは $(-\tfrac{1}{2}, 0, \tfrac{1}{2})/h$ で、$f(x)$ の重みは 0 である。
これらの次数は $f$ の滑らかさを仮定したもので、節点の範囲で $f'''$ が存在しなければ次数は下がる（片側差分で次数が下がる例は [濃度の非負制約下で反応速度の感度を求める](oxref:differentiate-boundary-order-loss)）。

## 二階差分

2 つの展開を足すと奇数次の項が消え、3 点の中心二階差分が得られる。
$f$ が $C^4$ 級なら、ある $\xi \in (x - h, x + h)$ について次が成り立つ。

$$
D_h^{2,0} f(x) = \frac{f(x + h) - 2 f(x) + f(x - h)}{h^2} = f''(x) + \frac{h^2}{12} f^{(4)}(\xi).
$$

片側の 3 点 $x, x + h, x + 2h$ だけを使う前進の二階差分は、$f(x + 2h)$ も展開して $h^2$ の係数をそろえると次のようになる。

$$
D_h^{2,+} f(x) = \frac{f(x + 2h) - 2 f(x + h) + f(x)}{h^2} = f''(x) + h f'''(x) + \frac{7 h^2}{12} f^{(4)}(x) + O(h^3).
$$

前進の二階差分は 1 次の精度にとどまる。
どちらの二階差分も 3 点を使い、$f(x)$ の重みは $1/h^2$ の定数倍で 0 ではない。
分母が $h^2$ なので、[次のページ](oxref:differentiate-roundoff-rule) で見るように、丸め誤差は一階差分より速く増える。

| 公式 | 節点 | 打ち切り誤差の主項 | 次数 |
|---|---|---|---|
| 一階・前進 $D_h^{+}$ | $x, x + h$ | $\tfrac{1}{2} h f''$ | 1 |
| 一階・中心 $D_h^{0}$ | $x - h, x, x + h$ | $\tfrac{1}{6} h^2 f'''$ | 2 |
| 二階・中心 $D_h^{2,0}$ | $x - h, x, x + h$ | $\tfrac{1}{12} h^2 f^{(4)}$ | 2 |
| 二階・前進 $D_h^{2,+}$ | $x, x + h, x + 2h$ | $h f'''$ | 1 |

## 打ち切り誤差の次数の実測

次のセルは $f(x) = e^{a x}$ の一階と二階の導関数を、前進差分と中心差分で刻み $h = 10^{-1}$ から $10^{-3}$ まで計算する。
この範囲では丸め誤差は打ち切り誤差より十分に小さいので、誤差は主項 $C h^p$ に従うはずである。
主項の係数 $C$ は上の表から、一階前進で $a^2 e^{a x_0}/2$、一階中心で $a^3 e^{a x_0}/6$、二階中心で $a^4 e^{a x_0}/12$、二階前進で $a^3 e^{a x_0}$ になる。
主計算は `FiniteDifference` の `derivative` と `second_derivative` で行い、刻みは `DifferenceStep::absolute(h)` で与え、被微分関数は `RealScalar::exp` で評価する。
厳密値と主項は f64 の固有メソッドで作った参照値である。
観測次数は両端の刻み $h_1 = 10^{-1}$、$h_2 = 10^{-3}$ での誤差 $e_1$、$e_2$ から $\ln(e_1 / e_2) / \ln(h_1 / h_2)$ で求める。
表の最後の列は最小の刻みでの誤差と主項の比で、1 に近ければ誤差の大きさまで式どおりである。

```rust
//| id: differentiate-truncation-order
//| ref: differentiate-truncation-order
//| title: 前進差分と中心差分の打ち切り誤差の次数
//| run: reactive
//| crates: [scioxide-core, scioxide-differentiate]
//| inputs:
//|   a: {"type":"range","label":"指数の係数 a [1/x の単位]","description":"導関数の大きさ a^k e^{ax} を変える。","min":0.5,"max":3.0,"step":0.5,"value":1.0}
//|   x0: {"type":"range","label":"評価点 x0 [x の単位]","min":-1.0,"max":1.0,"step":0.5,"value":0.5}
//| cases:
//|   - {"id":"steep","label":"a = 3","description":"導関数が大きくなり誤差は増えるが、両対数の傾き（次数）は変わらない。大きな h では高次の項が効いて主項から離れる。","inputs":{"a":3.0}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"orders","path":"/rows/0/2","approx":{"value":1.0,"atol":0.02}}
//|       - {"artifact":"orders","path":"/rows/1/2","approx":{"value":2.0,"atol":0.01}}
//|       - {"artifact":"orders","path":"/rows/2/2","approx":{"value":2.0,"atol":0.01}}
//|       - {"artifact":"orders","path":"/rows/3/2","approx":{"value":1.0,"atol":0.02}}
//|       - {"artifact":"orders","path":"/rows/0/5","approx":{"value":1.0,"atol":0.002}}
//|       - {"artifact":"orders","path":"/rows/1/5","approx":{"value":1.0,"atol":0.002}}
//|       - {"artifact":"orders","path":"/rows/2/5","approx":{"value":1.0,"atol":0.005}}
//|       - {"artifact":"orders","path":"/rows/3/5","approx":{"value":1.0,"atol":0.002}}
//|   - case: steep
//|     expect:
//|       - {"artifact":"orders","path":"/rows/0/2","approx":{"value":1.0,"atol":0.06}}
//|       - {"artifact":"orders","path":"/rows/1/2","approx":{"value":2.0,"atol":0.03}}
//|       - {"artifact":"orders","path":"/rows/2/2","approx":{"value":2.0,"atol":0.03}}
//|       - {"artifact":"orders","path":"/rows/3/2","approx":{"value":1.0,"atol":0.06}}
//|       - {"artifact":"orders","path":"/rows/0/5","approx":{"value":1.0,"atol":0.005}}
//|       - {"artifact":"orders","path":"/rows/3/5","approx":{"value":1.0,"atol":0.01}}
use scioxide_core::{SciOxideError, RealScalar};
use scioxide_differentiate::{
    DerivativeOperation as Op, DifferenceScheme as Scheme, DifferenceStep, FiniteDifference,
};

let fixed3 = serde_json::json!({ "fractionDigits": 3 });
let fixed4 = serde_json::json!({ "fractionDigits": 4 });
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
// 参照値: 誤差の主項の係数と厳密な導関数（f64 の固有メソッドで計算する）。
let g = (a * x0).exp();
let cases = [
    (Op::First, Scheme::Forward, "一階・前進"),
    (Op::First, Scheme::Central, "一階・中心"),
    (Op::Second, Scheme::Central, "二階・中心"),
    (Op::Second, Scheme::Forward, "二階・前進"),
];
// h = 10^{-1}, 10^{-1.25}, …, 10^{-3} の 9 点。
let steps: Vec<f64> = (0..=8)
    .map(|k| 10.0_f64.powf(-1.0 - 0.25 * k as f64))
    .collect();
let mut series = Vec::new();
let mut rows = Vec::new();
for (operation, scheme, name) in cases {
    // 理論次数 p と主項 C h^p の係数 C（主項の表に f⁽ᵏ⁾ = aᵏ e^{ax} を入れたもの）。
    let (order, leading) = match (operation, scheme) {
        (Op::First, Scheme::Forward) => (1, a.powi(2) * g / 2.0),
        (Op::First, _) => (2, a.powi(3) * g / 6.0),
        (_, Scheme::Central) => (2, a.powi(4) * g / 12.0),
        _ => (1, a.powi(3) * g),
    };
    let exact = match operation {
        Op::First => a * g,
        _ => a * a * g,
    };
    let f = |t: f64| Ok::<f64, SciOxideError>(RealScalar::exp(a * t));
    let mut observed = Vec::new();
    let mut theory = Vec::new();
    for &h in &steps {
        let method = FiniteDifference::default()
            .with_scheme(scheme)
            .with_step(DifferenceStep::absolute(h).map_err(|e| e.to_string())?);
        let result = match operation {
            Op::First => method.derivative(f, x0),
            _ => method.second_derivative(f, x0),
        }
        .map_err(|e| e.to_string())?;
        let value = result.values().ok_or("導関数が公開されない")?[0];
        observed.push([h, (value - exact).abs()]);
        theory.push([h, leading * h.powi(order)]);
    }
    // 後処理: 両端の刻みでの観測次数と、最小の刻みでの主項との比。
    let (first, last) = (observed[0], observed[observed.len() - 1]);
    let slope = (first[1] / last[1]).ln() / (first[0] / last[0]).ln();
    let predicted = theory[theory.len() - 1][1];
    rows.push((name, order, slope, last[1], predicted, last[1] / predicted));
    series.push(serde_json::json!({
        "name": name,
        "points": observed,
        "style": { "showSymbol": true }
    }));
    series.push(serde_json::json!({
        "name": format!("{name} の主項"),
        "points": theory,
        "style": { "lineType": "dashed", "showSymbol": false }
    }));
}
let columns = serde_json::json!([
    { "key": "0", "label": "公式" },
    { "key": "1", "label": "理論次数 p [-]", "type": "integer" },
    { "key": "2", "label": "観測次数 [-]", "type": "number", "format": fixed3 },
    { "key": "3", "label": "h = 10⁻³ での誤差 [-]", "type": "number", "format": sci3 },
    { "key": "4", "label": "主項 C h^p [-]", "type": "number", "format": sci3 },
    { "key": "5", "label": "誤差 ÷ 主項 [-]", "type": "number", "format": fixed4 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "orders" })
);
emit_line_chart!(
    &series,
    options = &serde_json::json!({
        "xLabel": "刻み h [x の単位]",
        "yLabel": "導関数の絶対誤差 [-]",
        "xType": "log",
        "yType": "log"
    })
);
```

既定の $a = 1$、$x_0 = 0.5$ では、観測次数は前進差分で 1.007 と 1.013、中心差分で 2.000 になる。
最小の刻みでの誤差と主項の比は 0.998 から 1.001 で、誤差は大きさまで主項に一致する。
図では、記号で描いた観測点が破線の主項に $h$ が小さいほど近づき、両対数の傾きが次数を表す。
大きな $h$ で主項から離れるのは、高次の項 $O(h^{p+1})$ が効くためである。
$a = 3$ にすると導関数が大きくなるので誤差はどの公式でも大きくなるが、傾きは変わらない。

## SciOxide の既定刻み

刻みを小さくすると打ち切り誤差は減るが、丸め誤差は $1/h$（二階差分では $1/h^2$）に比例して増える。
2 つを釣り合わせると、最適な刻みは計算機イプシロン $\varepsilon$ の冪になる（導出は [丸め誤差・ノイズと最適な刻み幅](oxref:differentiate-optimal-step)）。
ここで $\varepsilon$ は 1 と次の浮動小数点数の差で、倍精度では $2^{-52} \approx 2.22 \times 10^{-16}$ である。
[`FiniteDifference`](https://docs.rs/scioxide-differentiate/0.1.0/scioxide_differentiate/struct.FiniteDifference.html) は、刻みを指定しなければ座標 $x_i$ ごとに次の刻みを使う。

$$
h_i = c \cdot \max(1, \lvert x_i \rvert).
$$

| 公式 | 微分の階数 | 係数 $c$ | 倍精度での $c$ |
|---|---|---|---|
| 前進差分 `Forward` | 一階（`derivative`、`gradient`、`jacobian`、`jvp`） | $\varepsilon^{1/2}$ | $1.49 \times 10^{-8}$ |
| 中心差分 `Central` | 一階 | $\varepsilon^{1/3}$ | $6.06 \times 10^{-6}$ |
| 前進差分 `Forward` | 二階（`second_derivative`、`hessian`） | $\varepsilon^{1/3}$ | $6.06 \times 10^{-6}$ |
| 中心差分 `Central` | 二階 | $\varepsilon^{1/4}$ | $1.22 \times 10^{-4}$ |

$\lvert x_i \rvert \ge 1$ では刻みは $\lvert x_i \rvert$ に比例する相対刻みになり、$\lvert x_i \rvert < 1$ では $x_i$ の単位で測った絶対刻み $c$ になる。
$x_i = 0$ の近くでも刻みが 0 に縮まないのはこのためである。
この規則は、$f$ とその導関数が $\max(1, \lvert x \rvert)$ 程度の幅で変化することを仮定している（Nocedal と Wright、*Numerical Optimization* 第 2 版、§8.1）。
変数の自然な大きさが 1 から大きく外れる場合（モル体積 $10^{-4}\,\mathrm{m^3/mol}$ や、桁の大きい物理量）は、変数を無次元化するか、刻みを明示する（[van der Waals 状態方程式の導関数と推定誤差](../../examples/van-der-waals-adaptive/)）。

ヘッセ行列の混合項 $\partial^2 f / \partial x_i \partial x_j$ は一階差分の節点のテンソル積で計算するが、2 つの刻みの積で割るので、刻みには二階の規則を使う。
方向微分 `jvp` は方向 $\mathbf{v}$ に沿った 1 本の差分で、点 $\mathbf{x} + \alpha \mathbf{v}$ の刻み $\alpha$ は、一階の係数 $c$ を使って $\alpha = c / \max_i (\lvert v_i \rvert / \max(1, \lvert x_i \rvert))$ とする。
この $\alpha$ ではどの座標の変位 $\alpha \lvert v_i \rvert$ もその座標の既定刻みを超えない。
刻みを明示したときは、$v_i \ne 0$ の座標の刻み $h_i$ について $\alpha = \min_i h_i / \lvert v_i \rvert$ とする。
適応差分 `AdaptiveDifference` は別の規則で、大きな刻み $0.5 \cdot \max(1, \lvert x_i \rvert)$ から縮めていく（[Richardson 外挿と Ridders の方法](../richardson-and-ridders/)）。

## `DifferenceStep` による刻みの指定

刻みは [`DifferenceStep`](https://docs.rs/scioxide-differentiate/0.1.0/scioxide_differentiate/struct.DifferenceStep.html) で指定し、`FiniteDifference::with_step` に渡す（適応差分では `AdaptiveDifference::with_step` で初期刻みになる）。
指定の方法は次の 4 つで、互いに排他的である。

| 構築関数 | 刻み $h_i$ |
|---|---|
| `DifferenceStep::absolute(h)` | すべての座標に同じ $h$（$x$ の単位） |
| `DifferenceStep::relative(r)` | $r \cdot \max(1, \lvert x_i \rvert)$ |
| `DifferenceStep::absolute_coordinates(&[h_1, h_2, …])` | 座標ごとの絶対刻み（座標ごとに単位が違うとき） |
| `DifferenceStep::relative_coordinates(&[r_1, r_2, …])` | 座標ごとの相対刻み $r_i \cdot \max(1, \lvert x_i \rvert)$ |

どの構築関数も有限でない値と 0 以下の値を `InvalidInput`（`OutOfRange`）で拒む。
座標ごとの指定は値を複製し、複製できなければ `SizeOverflow` か `AllocationFailure` を返す。
座標ごとの指定で配列の長さが入力の次元と違えば、評価のときに `DimensionMismatch` になる。
刻みは大きさだけを表し、向きは差分公式と境界への適応（[定義域の境界と片側差分](../bounds-and-one-sided/)）で決まる。
刻みを明示すると、一階と二階の既定の規則がどちらもその刻みに置き換わる。

ワンショット関数 [`derivative`](https://docs.rs/scioxide-differentiate/0.1.0/scioxide_differentiate/fn.derivative.html)`(f, x)` は既定の中心差分と既定刻みでスカラー関数の一階導関数を計算し、値だけを返す。
$f(x)$ を含めて $f$ を 3 回評価し、メモリを確保しない。
刻みや公式を選ぶときは、`FiniteDifference` の設定を変えてそのメソッド `derivative` などを呼ぶ。

## 丸めで表現された変位

浮動小数点数では、$x + h$ は表現できる数に丸められる。
実際に評価される点を $x_+ = \mathrm{fl}(x + h)$、$x_- = \mathrm{fl}(x - h)$ と書くと、実際の変位の大きさ $\delta_+ = x_+ - x$ と $\delta_- = x - x_-$ は公称の $h$ と一致しない。
ここで $\mathrm{ulp}(x)$ は $x$ の近くで隣り合う浮動小数点数の間隔である。
最近接の丸めでは、$\delta_\pm$ と $h$ の差は $\mathrm{ulp}(x)$ の半分以下になる。
$h$ が $\mathrm{ulp}(x)$ に比べて十分に大きければ差は無視できるが、$\lvert x \rvert$ が大きく $h$ が小さいときに公称の $h$ で割ると、差がそのまま導関数の相対誤差になる。
中心差分を公称の $h$ で割ったときの値は、打ち切り誤差と関数値の丸めを除けば次のようになる。

$$
\frac{f(x_+) - f(x_-)}{2h} \approx \frac{\delta_+ + \delta_-}{2h} \, f'(x).
$$

`FiniteDifference` は、加算のあとに実際の変位 $\delta_\pm$ を計算し直し、その変位に対する重みを Fornberg の方法（[差分ステンシルの重みと任意の節点](../stencil-weights/)）で作る。
$\delta_+ \ne \delta_-$ のときは非対称な 3 点の重みになり、$f(x)$ の重みも 0 でなくなる。
公称の $h$ は節点を置く位置を決めるだけである。
区間がなくても、浮動小数点数の最大値までの距離をその向きの余地とみなし、余地が $h$ に足りない向きには節点を置かない。
そのとき中心差分は、余地の大きい向きに一階導関数では 3 点 $x$、$x \pm h$、$x \pm 2h$、二階導関数では 4 点 $x$、$x \pm h$、$x \pm 2h$、$x \pm 3h$ の片側の公式を使い、どちらも 2 次の精度を保つ（区間の境界での節点の選び方は [定義域の境界と片側差分](oxref:differentiate-bounded-fixed-nodes)）。
一方、余地があるのに丸めで一方の向きの変位が 0 になるときは、前進差分は逆の向きの節点を使うが、中心差分は片側の節点に切り替えずに `InvalidInput`（`UnsupportedConfiguration`）を返す。
どの向きにも区別できる節点が置けないときも同じエラーになる。

次のセルでこの効果を確かめる。
$X = 10^8$ の近くの点 $x = X + \xi$ で、$f(t) = \sin(t - X)$ を中心差分で微分する。
$t$ と $X$ が近いとき（$X/2 \le t \le 2X$）、$t - X$ は丸めなしに計算できる（Sterbenz の補題）ので、関数値の誤差は $\sin$ の評価の丸めだけになる。
$2^{26} \le x < 2^{27}$ では $\mathrm{ulp}(x) = 2^{-26} \approx 1.49 \times 10^{-8}$ で、刻みには ulp の整数倍でない値（ulp の 1.3 倍から 100.7 倍）を使う。
比較のために、公称の $h$ で割る手計算の中心差分と、その相対誤差の予測 $\lvert (\delta_+ + \delta_-)/(2h) - 1 \rvert$ も並べる。
最後の列は、関数値が 1 ulp 以内の誤差（相対誤差 $\varepsilon$ 以下）で求まるとしたときの丸め誤差の見積もり $\varepsilon \lvert f(x) \rvert / (\bar\delta \lvert f'(x) \rvert)$ で、$\bar\delta = (\delta_+ + \delta_-)/2$ である（導出は [次のページ](oxref:differentiate-roundoff-rule)）。
厳密値 $\cos \xi$ は f64 の参照値である。

```rust
//| id: differentiate-rounded-displacement
//| ref: differentiate-rounded-displacement
//| title: 丸めで表現された変位と公称刻みによる中心差分の比較
//| run: reactive
//| crates: [scioxide-core, scioxide-differentiate]
//| inputs:
//|   offset: {"type":"range","label":"中心からのずれ ξ = x − 10⁸ [-]","min":0.1,"max":0.9,"step":0.1,"value":0.3}
//| cases:
//|   - {"id":"far-offset","label":"ξ = 0.9","description":"|f(x)| / |f′(x)| = tan ξ が大きくなり、丸め誤差の見積もりも大きくなる。公称の h で割る誤差は ξ によらない。","inputs":{"offset":0.9}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"displacements","path":"/rows/0/1","equals":1.0}
//|       - {"artifact":"displacements","path":"/rows/0/3","approx":{"value":0.230769,"rtol":1e-4}}
//|       - {"artifact":"displacements","path":"/rows/0/4","approx":{"value":0.230769,"rtol":1e-4}}
//|       - {"artifact":"displacements","path":"/rows/0/5","range":{"max":4.6e-9}}
//|       - {"artifact":"displacements","path":"/rows/2/3","approx":{"value":0.0909091,"rtol":1e-4}}
//|       - {"artifact":"displacements","path":"/rows/5/5","range":{"max":4.6e-11}}
//|   - case: far-offset
//|     expect:
//|       - {"artifact":"displacements","path":"/rows/0/3","approx":{"value":0.230769,"rtol":1e-4}}
//|       - {"artifact":"displacements","path":"/rows/0/5","range":{"max":1.88e-8}}
//|       - {"artifact":"displacements","path":"/rows/5/5","range":{"max":1.88e-10}}
use scioxide_core::{SciOxideError, RealScalar};
use scioxide_differentiate::{DifferenceScheme, DifferenceStep, FiniteDifference};

let fixed1 = serde_json::json!({ "fractionDigits": 1 });
let fixed2 = serde_json::json!({ "fractionDigits": 2 });
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let center = 1.0e8_f64;
let x = center + offset;
// x − center は丸めなしに求まるので、表現された ξ で厳密値を作る（f64 の参照値）。
let xi = x - center;
let exact = xi.cos();
let ulp = x.next_up() - x;
let f = |t: f64| RealScalar::sin(t - center);
let mut rows = Vec::new();
for multiple in [1.3, 2.7, 5.5, 10.4, 50.2, 100.7] {
    let h = multiple * ulp;
    // 実際の変位の大きさ δ₊ = fl(x + h) − x、δ₋ = x − fl(x − h)（引き算は丸めなし）。
    let (plus, minus) = ((x + h) - x, x - (x - h));
    // 比較用の手計算: 実際の変位ではなく公称の h で割る。
    let nominal = (f(x + h) - f(x - h)) / (2.0 * h);
    let predicted = ((plus + minus) / (2.0 * h) - 1.0).abs();
    let method = FiniteDifference::default()
        .with_scheme(DifferenceScheme::Central)
        .with_step(DifferenceStep::absolute(h).map_err(|e| e.to_string())?);
    let result = method
        .derivative(|t: f64| Ok::<f64, SciOxideError>(f(t)), x)
        .map_err(|e| e.to_string())?;
    let value = result.values().ok_or("導関数が公開されない")?[0];
    // 丸め誤差の見積もり ε|f| / (δ̄ |f′|)（相対誤差。f64 の参照値）。
    let rounding = f64::EPSILON * xi.sin().abs() / (0.5 * (plus + minus) * exact.abs());
    rows.push((
        multiple,
        plus / ulp,
        minus / ulp,
        ((nominal - exact) / exact).abs(),
        predicted,
        ((value - exact) / exact).abs(),
        rounding,
    ));
}
let columns = serde_json::json!([
    { "key": "0", "label": "公称 h ÷ ulp [-]", "type": "number", "format": fixed1 },
    { "key": "1", "label": "δ₊ ÷ ulp [-]", "type": "number", "format": fixed2 },
    { "key": "2", "label": "δ₋ ÷ ulp [-]", "type": "number", "format": fixed2 },
    { "key": "3", "label": "公称 h で割った相対誤差 [-]", "type": "number", "format": sci3 },
    { "key": "4", "label": "その予測 |(δ₊ + δ₋)/(2h) − 1| [-]", "type": "number", "format": sci3 },
    { "key": "5", "label": "FiniteDifference の相対誤差 [-]", "type": "number", "format": sci3 },
    { "key": "6", "label": "丸め誤差の見積もり [-]", "type": "number", "format": sci3 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "displacements" })
);
```

$\delta_\pm / \mathrm{ulp}$ は整数になり、公称の $h / \mathrm{ulp}$ とずれる。
公称の $h$ で割る手計算の相対誤差は予測 $\lvert (\delta_+ + \delta_-)/(2h) - 1 \rvert$ と 4 桁以上一致し、$h$ が ulp の 1.3 倍から 10.4 倍のときは $3.85 \times 10^{-2}$ から $0.231$ になる。
この誤差は $h$ を ulp の 100 倍にしても $3 \times 10^{-3}$ 残る。
`FiniteDifference` の相対誤差は既定の $\xi = 0.3$ で $6.1 \times 10^{-12}$ から $6.7 \times 10^{-10}$ で、どの行でも丸め誤差の見積もりより小さい。
$\xi = 0.9$ では $\lvert f \rvert / \lvert f' \rvert = \tan \xi$ が大きくなるので見積もりは 4 倍ほど大きくなるが、公称の $h$ で割る誤差は変わらない。
この例は変位の扱いだけを見るために刻みを極端に小さくしたもので、実用の刻みは既定刻みのように ulp よりずっと大きい。

## 基準値の差し引きと既知の基準値 `base`

導関数の重み $w_j$ は定数関数の微分が 0 になるように作るので、$\sum_j w_j = 0$ を満たす。
したがって、各標本から基準値 $f(x)$ を引いても結果は変わらない。

$$
\sum_j w_j f(x_j) = \sum_j w_j \bigl( f(x_j) - f(x) \bigr) + f(x) \sum_j w_j .
$$

ところが、非対称な節点で作った重みは丸めを含むので、計算された重みの和はちょうど 0 にならない。
すると最後の項 $f(x) \sum_j w_j$ が残り、$\lvert f(x) \rvert$ が大きいほど結果がずれる。
`FiniteDifference` は差 $f(x_j) - f(x)$ に重みを掛けてこの項を除く。
除ける誤差は関数値の丸め誤差と同じ程度の大きさなので、改善は定数倍にとどまり、差が出るのは $\lvert f(x) \rvert$ が導関数に比べて大きいときである。
差がオーバーフローするときは、生の標本に重みを掛ける計算に戻る。
対称な中心差分の正規化した重み $(-\tfrac{1}{2}, 0, \tfrac{1}{2})$ は正確に表現でき、和もちょうど 0 になる。

固定刻みの差分は $f(x)$ を基準値の差し引きと非対称な重みに使うので、中心差分でも $f(x)$ を評価する。
呼び出し側が $f(x)$ をすでに知っていれば、`FiniteDifference` の `gradient`、`hessian`、`jacobian`、`jvp` とその `_into` 形、`derivative_into` の引数 `base` に渡して、その 1 回の評価を省ける。
ワンショット関数と、`FiniteDifference` の `derivative` と `second_derivative` には `base` がない（二階導関数で `base` を使うときは、1 変数の `hessian` を呼ぶ）。
適応差分、節点を指定する差分、複素ステップ法にも同じ引数はない。
`base` は勾配とヘッセ行列ではスカラー、ヤコビ行列と方向微分では長さが出力の数の配列である。
有限でない値は `NonFinite`、長さの違いは `DimensionMismatch` になるが、本当に $f(x)$ かどうかは確かめない。
`base` は $x$ での標本としても、差し引く基準値としても使われる。

$n$ 変数の勾配とヘッセ行列の評価回数は次のとおりで、`base` を渡すとどれも 1 回減る。
ヘッセ行列では、ビット列が同じ点を 1 回だけ評価する。

| 演算 | 前進差分 | 中心差分 |
|---|---|---|
| `derivative`、`gradient`、`jacobian` | $n + 1$ | $2n + 1$ |
| `second_derivative`、`hessian` | $1 + 2n + n(n - 1)/2$ | $1 + 2n^2$ |
| `jvp` | 2 | 3 |

1 変数（$n = 1$）の二階導関数は、前進差分（節点 $x, x + h, x + 2h$）でも中心差分でも 3 回である。

`base` が $\delta_b$ だけずれると、導関数は $f(x)$ の重み $w_x$ を掛けた $w_x \delta_b$ だけずれる。
$w_x$ は一階前進差分で $-1/h$、一階中心差分で 0、二階前進差分で $1/h^2$、二階中心差分で $-2/h^2$ である。
したがって、一階の中心差分だけはずれの影響をほとんど受けず、二階差分は中心差分でも $2 \delta_b / h^2$ の誤差を受ける。

次のセルは $n$ 変数の関数 $f(\mathbf{x}) = \sum_i e^{x_i}$ の勾配とヘッセ行列を、`base` なしと、わざと $\delta_b$ だけずらした `base` で計算する。
評価点は $x_i = 0.1(i + 1)$ で、$\lvert x_i \rvert < 1$ なので既定刻みは係数 $c$ そのものになる。
示された評価回数を上の表の理論値と比べ、厳密値（勾配と対角は $e^{x_i}$、混合項は 0）との最大誤差を、ずれの寄与の見積もり $\lvert w_x \rvert \delta_b$ と比べる。
厳密値は f64 の固有メソッドで作った参照値である。

```rust
//| id: differentiate-known-base
//| ref: differentiate-known-base
//| title: 既知の基準値による評価回数の削減と誤った基準値の影響
//| run: reactive
//| crates: [scioxide-core, scioxide-differentiate]
//| inputs:
//|   n: {"type":"range","label":"変数の数 n","min":1,"max":8,"step":1,"value":3}
//|   shift: {"type":"select","label":"base のずれ δ_b [-]","options":["0","1e-12","1e-9"],"value":"1e-12"}
//| cases:
//|   - {"id":"one-variable","label":"n = 1","description":"1 変数の二階導関数は前進差分でも中心差分でも 3 回の評価で、base を渡すと 2 回になる。","inputs":{"n":1}}
//|   - {"id":"exact-base","label":"δ_b = 0","description":"正しい f(x) を渡すと、評価が 1 回減るだけで誤差は base なしと同じ大きさになる。","inputs":{"shift":"0"}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"base","path":"/rows/0/4","equals":4}
//|       - {"artifact":"base","path":"/rows/1/4","equals":3}
//|       - {"artifact":"base","path":"/rows/2/4","equals":7}
//|       - {"artifact":"base","path":"/rows/3/4","equals":6}
//|       - {"artifact":"base","path":"/rows/4/4","equals":10}
//|       - {"artifact":"base","path":"/rows/5/4","equals":9}
//|       - {"artifact":"base","path":"/rows/6/4","equals":19}
//|       - {"artifact":"base","path":"/rows/7/4","equals":18}
//|       - {"artifact":"base","path":"/rows/1/5","approx":{"value":6.7109e-5,"rtol":0.01}}
//|       - {"artifact":"base","path":"/rows/3/5","range":{"max":1e-9}}
//|       - {"artifact":"base","path":"/rows/5/5","approx":{"value":2.7271e-2,"rtol":0.01}}
//|       - {"artifact":"base","path":"/rows/7/5","approx":{"value":1.3422e-4,"rtol":0.01}}
//|   - case: one-variable
//|     expect:
//|       - {"artifact":"base","path":"/rows/4/4","equals":3}
//|       - {"artifact":"base","path":"/rows/5/4","equals":2}
//|       - {"artifact":"base","path":"/rows/6/4","equals":3}
//|       - {"artifact":"base","path":"/rows/7/4","equals":2}
//|   - case: exact-base
//|     expect:
//|       - {"artifact":"base","path":"/rows/1/5","range":{"max":1e-7}}
//|       - {"artifact":"base","path":"/rows/5/5","range":{"max":1e-4}}
//|       - {"artifact":"base","path":"/rows/7/5","range":{"max":1e-6}}
use scioxide_core::{SciOxideError, RealScalar};
use scioxide_differentiate::DifferenceScheme::{Central, Forward};
use scioxide_differentiate::FiniteDifference;

let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let n = n as usize;
let delta_b: f64 = shift.parse().map_err(|_| "ずれを読めない")?;
let x: Vec<f64> = (0..n).map(|i| 0.1 * (i as f64 + 1.0)).collect();
let f = |p: &[f64], y: &mut [f64]| {
    y[0] = p.iter().map(|&v| RealScalar::exp(v)).sum();
    Ok::<(), SciOxideError>(())
};
// 参照値: ∂f/∂xᵢ = ∂²f/∂xᵢ² = e^{xᵢ}、混合項は 0、f(x) = Σ e^{xᵢ}（f64 の固有メソッド）。
let exact: Vec<f64> = x.iter().map(|v| v.exp()).collect();
let fx: f64 = exact.iter().sum();
let max_error = |values: &[f64], hessian: bool| {
    let reference = |k: usize| match (hessian, k / n == k % n) {
        (false, _) => exact[k],
        (true, true) => exact[k % n],
        (true, false) => 0.0,
    };
    let errors = values
        .iter()
        .enumerate()
        .map(|(k, v)| (v - reference(k)).abs());
    errors.fold(0.0, f64::max)
};
let eps = f64::EPSILON;
let mut rows = Vec::new();
for (operation, hessian) in [("勾配", false), ("ヘッセ行列", true)] {
    for (name, scheme) in [("前進", Forward), ("中心", Central)] {
        // 理論の評価回数（base なし）と f(x) の重みの大きさ |w_x|。|xᵢ| < 1 なので h = c。
        let (calls, weight) = match (hessian, scheme) {
            (false, Forward) => (n + 1, 1.0 / eps.sqrt()),
            (false, Central) => (2 * n + 1, 0.0),
            (true, Forward) => (1 + 2 * n + n * (n - 1) / 2, eps.powf(-2.0 / 3.0)),
            (true, Central) => (1 + 2 * n * n, 2.0 / eps.sqrt()),
        };
        let method = FiniteDifference::default().with_scheme(scheme);
        for base in [None, Some(fx + delta_b)] {
            let result = if hessian {
                method.hessian(f, &x, None, base)
            } else {
                method.gradient(f, &x, None, base)
            }
            .map_err(|e| e.to_string())?;
            let values = result.values().ok_or("導関数が公開されない")?;
            let (label, expected, estimate) = match base {
                None => ("なし", calls, None),
                Some(_) => ("f(x) + δ_b", calls - 1, Some(weight * delta_b)),
            };
            rows.push((
                operation,
                name,
                label,
                expected,
                result.report().evaluations(),
                max_error(values, hessian),
                estimate,
            ));
        }
    }
}
// 行の順: 勾配の前進・中心、ヘッセ行列の前進・中心（それぞれ base なし、あり）。
let columns = serde_json::json!([
    { "key": "0", "label": "演算" },
    { "key": "1", "label": "公式" },
    { "key": "2", "label": "base" },
    { "key": "3", "label": "理論の評価回数 [回]", "type": "integer" },
    { "key": "4", "label": "評価回数 [回]", "type": "integer" },
    { "key": "5", "label": "最大誤差 [-]", "type": "number", "format": sci3 },
    { "key": "6", "label": "ずれの寄与 |w_x| δ_b [-]", "type": "number", "format": sci3, "nullText": "—" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "base" })
);
```

既定の $n = 3$、$\delta_b = 10^{-12}$ では、評価回数はどの行も理論値と一致し、`base` を渡すと 1 回減る（勾配の前進差分で 4 回と 3 回、ヘッセ行列の中心差分で 19 回と 18 回）。
ずれた `base` による最大誤差は勾配の前進差分で $6.71 \times 10^{-5}$、ヘッセ行列の前進差分で $2.73 \times 10^{-2}$、ヘッセ行列の中心差分で $1.34 \times 10^{-4}$ で、それぞれ見積もり $\lvert w_x \rvert \delta_b$ と 0.1 % 以内で一致する。
中心差分で求めた勾配の誤差は `base` なしと同じ $1.30 \times 10^{-11}$ で、$f(x)$ の重みが 0 であることと合う。
$\delta_b = 10^{-9}$ にすると、勾配の前進差分の誤差は $6.71 \times 10^{-2}$、ヘッセ行列の前進差分の誤差は 27.3 になり、導関数として使えない値になる。
$\delta_b = 0$ にすると、`base` ありの行の誤差は `base` なしの行と同じ値になる。
$n = 1$ にすると、二階導関数は前進差分でも中心差分でも 3 回、`base` ありで 2 回の評価になる。
`base` は評価を 1 回省く代わりに、渡した値が正しいことに呼び出し側が責任を持つ引数である。

## まとめ

前進差分は 1 次、中心差分は 2 次、中心の二階差分は 2 次、前進の二階差分は 1 次の精度を持ち、次数は両対数の図の傾きとして実測できる。
`FiniteDifference` は刻みを指定しなければ $c \cdot \max(1, \lvert x_i \rvert)$ を使い、係数 $c$ は公式と階数に応じて $\varepsilon^{1/2}$、$\varepsilon^{1/3}$、$\varepsilon^{1/4}$ になる。
変数の大きさが 1 から大きく外れるときは、`DifferenceStep` で絶対刻みか相対刻みを明示する。
重みは丸めたあとの実際の変位から作るので、公称の刻みと表現された変位のずれは結果に入らない。
$f(x)$ が既知なら `base` で評価を 1 回省けるが、値の正しさは呼び出し側が保証し、二階差分では中心差分でもずれが $2\delta_b/h^2$ で効く。
