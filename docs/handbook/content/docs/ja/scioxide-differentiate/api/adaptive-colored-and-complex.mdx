この表は刻みを縮めて外挿する適応差分、疎なヤコビ行列の彩色、複素ステップ法の項目をまとめる。
推定誤差を返すのは適応差分と彩色だけで、その推定誤差は外挿の表と丸めの見積もりから作る推定であり、上界ではない。
複素ステップ法は推定誤差を返さず、前提の解析的拡張は呼び出し側が保証する。
ライブラリが検査するのは、基準点で関数の値が実数であることだけである。
どの評価も、エラーのときと結果を出力に反映しないときは借用した出力を変えず、十分な作業領域を渡した出力先を指定する API は数値計算のための確保をしない。

| [`AdaptiveDifference`](https://docs.rs/scioxide-differentiate/0.1.0/scioxide_differentiate/struct.AdaptiveDifference.html) | 構造体 | 外挿による推定誤差つきの適応差分の手法オブジェクト | 設定だけを持つ値で、既定は `Ridders`、最大 16 準位、最初の刻み $0.5 \max(1, \lvert x_i \rvert)$、許容誤差 $\tau_{\mathrm{abs}} = \tau_{\mathrm{rel}} = \sqrt{\varepsilon}$（最大ノルム）、逐次実行、上限のない `SolveBudgets`、作業領域の上限なし、`MathematicalZero`。`with_method`、`with_tolerance`、`with_max_levels`、`with_step`、`with_execution`、`with_max_workspace_bytes`、`with_budgets`、`with_zero_direction`、`step()`。要素 $D$ は、連続する 2 つの準位で推定誤差が $\tau_{\mathrm{abs}} + \tau_{\mathrm{rel}} \lvert D \rvert$ 以下になり、そのとき採る最良の推定値もこの許容誤差を満たすと収束し、少なくとも 3 準位を使う（絶対許容誤差は導関数の単位）。設定は演算のたびに検査し、準位数が 3 から 64 の外か最大ノルム以外のノルムは `InvalidInput`（`self`、`OutOfRange`）、成分ごとの絶対許容誤差の長さが出力の長さと違えば `DimensionMismatch`。所有値を返す API `derivative(f, x)`、`second_derivative(f, x)`、`gradient(f, x, bounds)`、`hessian(f, x, bounds)`、`jacobian(f, x, m, bounds)`、`jvp(f, x, v, m, bounds)` と、推定誤差の配列も受け取る出力先を指定する API `gradient_into(f, x, bounds, out, errors, workspace, scope)`、`hessian_into`、`jacobian_into`、`jvp_into`。`base` はない。関数の値は実数・複素数。各準位は二次の中心差分で、その準位の刻みが両側の余地に収まらなければ、刻みを区間の端までの距離に縮めずに、余地の大きい向きの同じ次数の片側の節点を使う。節点の形が変わった準位では外挿の表をやり直す。方向微分も直線に沿って同じ規則で節点を選ぶ。評価回数は基準点の 1 回と、要素ごとに 1 準位あたり 2 回（片側の節点の二階の項は 3 回、ヘッセ行列の混合項は両軸が対称なら 4 回、片側を含むと最大 8 回）。方向微分の最初の刻みは $\min_i h_i / \lvert v_i \rvert$（$h_i$ は座標 $i$ の最初の刻み）。終了理由は `Converged`、`RoundoffLimit`、`RefinementLimit`、`StepSizeLimit`、上限、外部停止で、全要素に推定があり、上限と外部停止で止まっていなければ、`Converged` 以外でも値と推定誤差を出力に反映する。推定誤差は上界ではない。ヘッセ行列は上三角を求めて鏡映する | [刻みと停止の規則](oxref:differentiate-stopping-rules)、[選択肢と評価回数](oxref:differentiate-adaptive-options) | [中心差分・適応差分・複素ステップ法による最初の導関数](oxref:differentiate-first-derivatives)、[最大準位数による Ridders と Richardson の推定誤差と実際の誤差](oxref:differentiate-extrapolation-levels)、[van der Waals 式の体積微分の三つの設定による適応差分](oxref:differentiate-vdw-isotherm) |

| [`ColoredJacobianPlan`](https://docs.rs/scioxide-differentiate/0.1.0/scioxide_differentiate/struct.ColoredJacobianPlan.html) | 構造体 | 彩色による疎なヤコビ行列の Plan | `new(&schedule, method)` は彩色を借用し、`AdaptiveDifference` の設定で、列ごとに保存された要素の行、出力の位置、絶対許容誤差を前計算する（$n$ 列、保存された要素 $\mathrm{nnz}$ 個で $O(n + \mathrm{nnz})$）。彩色が `ColoringKind::DerivativeColumns` でなければ `InvalidInput`（`schedule`、`UnsupportedConfiguration`）、準位数かノルムの誤りは `InvalidInput`（`method`、`OutOfRange`）、既定以外の `ZeroDirectionPolicy` は `InvalidInput`（`method`、`Inconsistent`）、座標ごとの刻みや成分ごとの絶対許容誤差（保存された要素ごと）の長さの違いは `DimensionMismatch`。列ごとに適応差分の表を持ち、同じ色の列は摂動した点を共有する。`evaluate(f, x, bounds)`、`evaluate_into(f, x, bounds, out, errors, workspace, scope)`。値と推定誤差は保存された要素の行ごとの順（CSR の格納順）で、`output_len()` は保存された要素の数。関数はすべての行を書き、値は実数・複素数。評価回数は色の数 $c$、準位数の上限 $L$ で高々 $1 + 2cL$ で、区間を渡して片側の節点を使う列が同じ色に混じっても 1 準位 2 回（各列の 1 番目と 2 番目の変位をまとめて評価する）。終了理由は、上限と外部停止がなければ、列の番号順で最初に収束しなかった列の理由。パターンが実際の非零を落とすと、エラーなしに別の列の値が混ざる。`schedule()`、`workspace_requirements::<T>(())`、`workspace::<T>(())` | [ColoredJacobianPlan](oxref:differentiate-colored-plan)、[構造的に直交する列](oxref:differentiate-orthogonal-columns) | [Broyden の帯の関数のヤコビ行列を密な差分と彩色で求める](oxref:differentiate-banded-coloring)、[パターンから非零を落としたときの色の併合と値の混入](oxref:differentiate-missing-pattern)、[Brusselator 系の彩色ヤコビ行列と解析解との比較](oxref:differentiate-brusselator-coloring) |

## 複素ステップ

| 項目 | 種別 | 役割 | 仕様の要点 | 解説節 | 実行例 |

| [`ComplexStep`](https://docs.rs/scioxide-differentiate/0.1.0/scioxide_differentiate/struct.ComplexStep.html) | 構造体 | 複素ステップ法 $\operatorname{Im} f(x + ih\mathbf{e}_i)/h$ の手法オブジェクト | 関数は実関数の解析的拡張 $f: \mathbb{C}^n \to \mathbb{C}^m$ で、基準点 $x$ で値の虚部がちょうど 0 であることだけを検査する（違反は `InvalidInput`（`function`、`UnsupportedConfiguration`））。共役、絶対値、実部の取り出し、虚部による分岐は前提を破り、誤った値をエラーなしに返しうる。既定は刻み $h = \varepsilon$、逐次実行、上限のない `SolveBudgets`、作業領域の上限なし、`MathematicalZero`。`with_step`、`with_execution`、`with_budgets`、`with_max_workspace_bytes`、`with_zero_direction`。刻みは演算のたびに検査し、有限でなければ `NonFinite`、最小の正規化数 `MIN_POSITIVE` より小さければ `InvalidInput`（`self`、`OutOfRange`）。演算は一階だけで、所有値を返す API `derivative(f, x)`、`gradient(f, x)`、`jacobian(f, x, m)`、`jvp(f, x, v, m)` と出力先を指定する API `gradient_into`、`jacobian_into`、`jvp_into`。区間は取らない。値は実数で、推定誤差は返さず、上限や外部停止で止まらなければ `Completed` で終わる。評価回数は一階 2、勾配・ヤコビ行列 $n + 1$、方向微分 $\operatorname{Im} f(x + ih\mathbf{v})/h$ で 2。$h v_i$ があふれるか 0 に丸められれば `InvalidInput`（`direction`、`UnsupportedConfiguration`）、0 でない虚部が非正規化数になるか、$h$ で割った商が 0 に丸められれば、値を出力に反映せずに `NumericalInstability`（`Underflow`）。虚部がちょうど 0 なら、真の 0 と区別できないので導関数 0 を返す | [虚数方向の摂動](oxref:differentiate-complex-perturbation)、[ComplexStep](oxref:differentiate-complex-step-api) | [刻み幅による実数の差分と複素ステップ法の相対誤差](oxref:differentiate-complex-step-sweep)、[解析的拡張でない複素関数の複素ステップ法の結果](oxref:differentiate-analytic-contract)、[修正 Arrhenius 式の見かけの活性化エネルギーを四つの計算で求める](oxref:differentiate-arrhenius-sensitivity) |
| [`ComplexStepPlan`](https://docs.rs/scioxide-differentiate/0.1.0/scioxide_differentiate/struct.ComplexStepPlan.html) | 構造体 | 固定した点のヘッセ行列を、実数の節点のステンシルと複素ステップの勾配から求める Plan | `new(point, nodes, method)` は座標ごとの節点の一階のステンシルの Fornberg の重みを作成時に計算する（節点 $k$ 個で $O(k^2)$）。刻みと `ZeroDirectionPolicy` の誤りは `ComplexStep` と同じで引数名は `method`、節点の並びの数の違いは `DimensionMismatch`、節点が 2 個未満なら `InvalidInput`（`nodes`、`OutOfRange`）、重複は `InvalidInput`（`nodes`、`Inconsistent`）。要素 $(i, j)$ は軸 $j$ の節点での $\partial f / \partial x_i$ の複素ステップ値に軸 $j$ のステンシルを当てたもので、混合項は二つの順序の平均なので結果はちょうど対称。評価は高々 $1 + n\sum_j k_j$ 回。精度は実数のステンシルの打ち切り誤差と丸めで決まり、`ComplexStep` の精度ではない。二階導関数は $n = 1$ の場合。`evaluate(f, bounds)`、`evaluate_into(f, bounds, out, workspace, scope)` は評価点を受け取らず、区間の外の点や節点は `InvalidInput`（`bounds`）。`output_len()` は $n^2$ | [実数の節点を指定する差分法オブジェクトと Plan](oxref:differentiate-complex-node-plans)、[二階導関数とヘッセ行列](oxref:differentiate-complex-second) | [複素ステップ法のヘッセ行列の評価回数と対称性](oxref:differentiate-complex-hessian-jvp) |
| [`RelativeComplexStep`](https://docs.rs/scioxide-differentiate/0.1.0/scioxide_differentiate/struct.RelativeComplexStep.html) | 構造体 | 評価のたびに変位から節点を置き直す複素ステップのヘッセ行列の節点を指定する差分法オブジェクト | `new(offsets, method)` は座標ごとの変位を持ち、評価のたびに節点 $x_i + \Delta$ を作って、丸めたあとの変位から確保なしで重みを作り直す。変位が 2 個未満なら `InvalidInput`（`offsets`、`OutOfRange`）、重複は `InvalidInput`（`offsets`、`Inconsistent`）。区間の外の $x$ は `InvalidInput`（`x`、`OutOfRange`）、有限でない節点、区間の外の節点、別の節点に丸められた節点は `InvalidInput`（`x`、`UnsupportedConfiguration`）。精度、評価回数、関数の前提は `ComplexStepPlan` と同じで、1 軸 $k$ 点の二階導関数は高々 $1 + k$ 回。`evaluate(f, x, bounds)`、`evaluate_into(f, x, bounds, out, workspace, scope)`、`output_len()` は $n^2$ | [実数の節点を指定する差分法オブジェクトと Plan](oxref:differentiate-complex-node-plans)、[二階導関数とヘッセ行列](oxref:differentiate-complex-second) | [複素ステップ法と実節点による二階導関数と実数の二階差分の誤差](oxref:differentiate-complex-second-derivative)、[複素ステップ法のヘッセ行列の評価回数と対称性](oxref:differentiate-complex-hessian-jvp) |

| [`ComplexStepWorkspace`](https://docs.rs/scioxide-differentiate/0.1.0/scioxide_differentiate/struct.ComplexStepWorkspace.html) | 構造体 | `ComplexStep`、`ComplexStepPlan`、`RelativeComplexStep` の作業領域 | 関連関数 `workspace_requirements(request)` と `workspace(request)`、Plan と手法オブジェクトの `workspace(())`、`Default`、`check(&r)`、`try_reserve(&r)`。一つの作業領域を、要件を満たすすべての評価に使い回せる。評価中に増えず、容量が足りなければ `DimensionMismatch`。`retained_bytes()` は前の大きな要件の分も含めて保持している容量のバイト数を確保なしに返す。 | [Plan・要件・作業領域](oxref:differentiate-plans-requirements) | [種類ごとの要件と作業領域の事前確保](oxref:differentiate-workspace-reuse) |
