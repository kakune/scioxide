この表は導関数の種類・差分公式・刻みを指定する型、固定刻みの差分の手法オブジェクト、呼び出し側が節点を選ぶ差分の項目をまとめる。
固定刻みの `FiniteDifference` は関数の値を実数に限り、推定誤差を返さない。
その終了理由 `Completed` は予定の評価を終えたことだけを表す。
節点の差分は実数と複素数の値を扱い、区間の外の節点はエラーにして、区間に合わせて節点を動かさない。
どの評価も、エラーのときと結果を出力に反映しないときは借用した出力を変えず、十分な作業領域を渡した出力先を指定する API は数値計算のための確保をしない。
