この表はワンショット関数、作業領域の大きさを決める型、関数を渡す形、評価の結果とレポート、導関数のプロバイダーの方針の項目をまとめる。
ワンショット関数は既定の設定で導関数の値だけを返し、成功でない終了をエラーにする。
`derivative` 以外は呼び出しのたびに作業領域と結果を確保するので、反復の中で繰り返すときは手法オブジェクトと作業領域を使い回す。
出力を使ってよいかは `output_available()` だけで決まり、終了理由 `Completed` は精度を主張せず、推定誤差は上界ではない。

| [`jvp`](https://docs.rs/scioxide-differentiate/0.1.0/scioxide_differentiate/fn.jvp.html) | 関数 | ヤコビ行列とベクトルの積を既定の中心差分で求める | `jvp(f, x, v, m)`、`f` は `jacobian` と同じ。$\mathbf{v}$ に沿った 1 本の中心差分で、刻みは $\varepsilon^{1/3} / \max_i(\lvert v_i \rvert / \max(1, \lvert x_i \rvert))$。$n$ によらず評価 3 回で、$\mathbf{v} = \mathbf{0}$ なら関数を呼ばずに $\mathbf{0}$。長さの違いは `DimensionMismatch`、有限でない $x$ や $\mathbf{v}$ は `NonFinite`、区別できる点を置けなければ `DifferentiationFailure`（原因は `ConvergenceFailure` の `StepSizeLimit`） | [呼び出しの形](oxref:differentiate-call-forms-terms)、[九つのワンショット関数](oxref:differentiate-one-shot-catalog) | [九つのワンショット関数と厳密値との誤差](oxref:differentiate-one-shot-functions) |
| [`sparse_jacobian`](https://docs.rs/scioxide-differentiate/0.1.0/scioxide_differentiate/fn.sparse_jacobian.html) | 関数 | 彩色による疎なヤコビ行列を既定の適応差分で求める | `sparse_jacobian(f, x, &schedule)`、`f: Fn(&[S], &mut [T]) -> Result<(), SciOxideError>` はすべての行を書き、値は実数・複素数。`DerivativeColumns` の彩色（scioxide-sparse の `derivative_coloring` など）の保存された要素を行ごとの順で返す。`AdaptiveDifference` の既定で、各要素の推定誤差が $\sqrt{\varepsilon}(1 + \lvert J_{ij} \rvert)$ 以下の準位が 2 回続き、最良の推定値も満たすまで（少なくとも 3 準位）外挿し、評価は色の数 $c$ で高々 $1 + 32c$ 回。最初の刻み $0.5\max(1, \lvert x_j \rvert)$ は関数の定義域に収まる必要がある。彩色が `DerivativeColumns` でなければ `InvalidInput`（`schedule`、`UnsupportedConfiguration`）、$x$ の長さが列の数と違えば `DimensionMismatch`、許容誤差を満たさない要素があれば `ConvergenceFailure`。区間や推定誤差が要るなら `ColoredJacobianPlan` を使う | [ワンショット関数と作業領域](oxref:differentiate-sparse-one-shot)、[九つのワンショット関数](oxref:differentiate-one-shot-catalog) | [九つのワンショット関数と厳密値との誤差](oxref:differentiate-one-shot-functions) |
| [`complex_step_derivative`](https://docs.rs/scioxide-differentiate/0.1.0/scioxide_differentiate/fn.complex_step_derivative.html) | 関数 | 実関数の一階導関数を刻み $\varepsilon$ の複素ステップ法で求める | `complex_step_derivative(f, x)`、`f: Fn(Complex<S>) -> Result<Complex<S>, SciOxideError>` は解析的拡張。$\operatorname{Im} f(x + i\varepsilon)/\varepsilon$ で評価 2 回（$f(x)$ は実数でなければならない）、精度は $f$ の評価の丸め誤差（$\varepsilon \lvert f'(x) \rvert$ 程度）。$f(x)$ の虚部が 0 でなければ `InvalidInput`（`function`、`UnsupportedConfiguration`）、0 でない虚部が非正規化数になるか商が 0 に丸められれば `NumericalInstability`（`Underflow`）。刻みを変えるとき、勾配やヤコビ行列を求めるときは `ComplexStep` を使う | [ComplexStep](oxref:differentiate-complex-step-api)、[九つのワンショット関数](oxref:differentiate-one-shot-catalog) | [九つのワンショット関数と厳密値との誤差](oxref:differentiate-one-shot-functions) |
| [`physical_difference_derivative`](https://docs.rs/scioxide-differentiate/0.1.0/scioxide_differentiate/fn.physical_difference_derivative.html) | 関数 | 選んだ節点の値から一階導関数を求める | `physical_difference_derivative(f, x, nodes)`、`f: Fn(S) -> Result<T, SciOxideError>` で値は実数・複素数。Fornberg の重みで $\sum_k w_k f(x_k)$ を作り、節点の数より低い次数の多項式で厳密。節点は等間隔でなくてよく、$x$ を含まなくてよい。評価は節点ごとに 1 回。$x$ や節点が有限でなければ `NonFinite`、節点が 2 個未満なら `InvalidInput`（`nodes`、`OutOfRange`）、重複は `InvalidInput`（`nodes`、`Inconsistent`） | [スカラー関数のワンショット関数](oxref:differentiate-physical-one-shot)、[九つのワンショット関数](oxref:differentiate-one-shot-catalog) | [ワンショット関数と変位の節点によるスカラーの導関数と評価回数](oxref:differentiate-node-scalar-derivative)、[九つのワンショット関数と厳密値との誤差](oxref:differentiate-one-shot-functions) |
