反応速度定数 $k(T)$ の温度感度は、見かけの活性化エネルギーとして実験とモデルを比べるときに使われる。
速度定数は温度とともに数十桁変わるので、$k$ そのものではなく、その対数の微分が意味を持つ量になる。
この例題では速度定数を計算する手続きを中身の分からない関数として扱い、その導関数を複素ステップ法、中心差分、適応差分の三つで求める。
温度に依存する前指数因子を持つ修正 Arrhenius 式を使うので、見かけの活性化エネルギーは温度とともに変わり、解析式で独立に検算できる。

## 修正 Arrhenius 式と見かけの活性化エネルギー

修正 Arrhenius 式は前指数因子に温度の冪 $T^n$ を含む。

$$
k(T) = A \, T^n \exp\!\left( -\frac{E_a}{R T} \right).
$$

ここで $A$ は前指数因子、$n$ は温度の冪、$E_a$ は活性化エネルギー（J/mol）、$R$ は気体定数である。
この例題では仮想的な一次反応を考え、$A = 10^{10}\,\mathrm{s^{-1}\,K^{-n}}$、$R = 8.314462618\,\mathrm{J/(mol \cdot K)}$（SI で定義される $N_A k_B$ の上位 10 桁）とし、$E_a$ と $n$ を入力で変える。
温度 250–1500 K で、$k$ は $E_a = 200\,\mathrm{kJ/mol}$、$n = 0$ のとき $1.6 \times 10^{-32}$ から $1.1 \times 10^{3}\,\mathrm{s^{-1}}$ まで、約 35 桁変わる。

見かけの活性化エネルギーは Arrhenius プロット（$\ln k$ を $1/T$ に対して描いた図）の傾きから定義される（IUPAC Gold Book、activation energy）。

$$
E_{a,\mathrm{app}}(T) = -R \frac{\mathrm{d} \ln k}{\mathrm{d}(1/T)} = R T^2 \frac{\mathrm{d} \ln k}{\mathrm{d}T} = R T^2 \frac{k'(T)}{k(T)}.
$$

修正 Arrhenius 式では、$\ln k = \ln A + n \ln T - E_a/(R T)$ を微分して次の解析式が得られる。

$$
E_{a,\mathrm{app}}(T) = E_a + n R T.
$$

$n \ne 0$ なら見かけの活性化エネルギーは温度とともに直線的に変わり、入力の $E_a$ とは一致しない。
この式は数値微分とは独立に導いたものなので、検算に使える。
$k$ を厳密に計算すれば、$E_{a,\mathrm{app}}$ の相対誤差は $k'$ の相対誤差に等しい。

## 三つの方法と誤差の見積もり

複素ステップ法では $k$ を計算する手続きを複素数でも計算できるように書き、$k'(T) = \operatorname{Im} k(T + ih)/h$ を求める（[複素ステップ微分と解析的拡張](../../algorithms/complex-step/)）。
$k$ は冪と指数関数の積なので、正の実軸の近くで正則であり、`ComplexStep` に渡す関数の前提（実関数の解析的拡張であること）を満たす。
`ComplexStep::default()` の刻みは $h = \varepsilon$（倍精度の計算機イプシロン $2.2 \times 10^{-16}$）で、引き算がないので桁落ちは起きない。
打ち切り誤差の相対的な大きさは $(h^2/6) \lvert k'''/k' \rvert$ で、この例題では $10^{-30}$ 以下になり、誤差は $k$ の評価の丸め誤差で決まる。
評価は $k(T)$ と $k(T + ih)$ の 2 回である。

中心差分は `FiniteDifference::default()` の `derivative` で、既定の刻み $h = \varepsilon^{1/3} \max(1, T) = \varepsilon^{1/3} T$ を使い、評価は 3 回である。
$g = \ln k$ とおくと $k''' / k' = g'^2 + 3 g'' + g'''/g'$ なので、中心差分の相対誤差の主項は次のようになる。

$$
\frac{h^2}{6} \left\lvert \frac{k'''}{k'} \right\rvert = \frac{h^2}{6} \left\lvert g'^2 + 3 g'' + \frac{g'''}{g'} \right\rvert, \qquad g' = \frac{n}{T} + \frac{E_a}{R T^2} .
$$

$E_a/(RT)$ が大きいときは $g'^2$ の項が支配し、相対誤差は $\varepsilon^{2/3} (E_a/(RT) + n)^2 / 6$ にほぼ等しい。
$E_a$ が大きく $T$ が低いほど打ち切り誤差は大きい。
丸めによる相対誤差は $\varepsilon/(h g')$ 程度で、既定の入力では打ち切り誤差より 2 桁以上小さい。

適応差分は Ridders の方法で、刻みを $0.5 \max(1, T)$ から 1.4 分の 1 ずつ縮め、各準位の中心差分を外挿する（[Richardson 外挿と Ridders の方法](oxref:differentiate-stopping-rules)）。
推定誤差が閾値 $\tau_{\mathrm{abs}} + \tau_{\mathrm{rel}} \lvert D \rvert$（$D$ は導関数の推定値）以下になる準位が 2 回続くと `Converged` で止まり、最短では 3 準位で止まる。
評価回数は $k(T)$ の 1 回と 1 準位あたり 2 回で、3 準位なら 7 回である。
`AdaptiveDifference::default()` の許容誤差は $\tau_{\mathrm{abs}} = \tau_{\mathrm{rel}} = \sqrt{\varepsilon} \approx 1.5 \times 10^{-8}$ で、絶対許容誤差の単位は導関数 $k'$ の単位（$\mathrm{s^{-1}\,K^{-1}}$）である。
低温の $k'$ は $10^{-29}$ 程度なので、絶対許容誤差はそれより 20 桁以上大きく、推定誤差が $k'$ よりずっと大きくても閾値を下回る。

次のブロックは二つのセルが共有する定義で、上の式を Rust の関数にしたものである。
`rate` が $k(T)$、`rate_complex` がその解析的拡張、`log_rate` が $\ln k$、`apparent_energy` が解析式 $E_a + nRT$、`rate_slope` が検算用の $k'(T) = k \, E_{a,\mathrm{app}}/(R T^2)$、`central_truncation` が中心差分の相対誤差の主項に対応する。
被微分関数は SciOxide の `RealScalar::exp`、`RealScalar::powf`、`RealScalar::ln` と `Complex` の演算で書き、検算用の `central_truncation` は f64 の演算で書く。

```rust
//| id: differentiate-arrhenius-model
//| kind: definitions
//| title: 修正 Arrhenius 式の速度定数と見かけの活性化エネルギー
//| crates: [scioxide-core]
use scioxide_core::{Complex, SciOxideError, RealScalar};

/// 前指数因子 A [s⁻¹ K⁻ⁿ]。
pub(crate) const PREFACTOR: f64 = 1.0e10;
/// 気体定数 R [J/(mol·K)]。
pub(crate) const GAS_CONSTANT: f64 = 8.314462618;

/// 速度定数 k(T) = A Tⁿ exp(−Ea/(RT)) [s⁻¹]。Ea は J/mol、T は K。
pub(crate) fn rate(ea: f64, n: f64, t: f64) -> f64 {
    PREFACTOR * RealScalar::powf(t, n) * RealScalar::exp(-ea / (GAS_CONSTANT * t))
}

/// k の解析的拡張。主枝の zⁿ と exp(−Ea/(Rz)) は正の実軸の近くで正則で、実軸上で実数になる。
pub(crate) fn rate_complex(ea: f64, n: f64, z: Complex<f64>) -> Result<Complex<f64>, SciOxideError> {
    let boltzmann = (Complex::new(-ea / GAS_CONSTANT, 0.0) / z).exp();
    Ok(z.powf(n) * boltzmann * PREFACTOR)
}

/// ln k(T) = ln A + n ln T − Ea/(RT)（無次元）。
pub(crate) fn log_rate(ea: f64, n: f64, t: f64) -> f64 {
    RealScalar::ln(PREFACTOR) + n * RealScalar::ln(t) - ea / (GAS_CONSTANT * t)
}

/// 解析式 Ea,app = Ea + nRT [J/mol]（検算用）。
pub(crate) fn apparent_energy(ea: f64, n: f64, t: f64) -> f64 {
    ea + n * GAS_CONSTANT * t
}

/// 検算用の k′(T) = k Ea,app/(RT²) [s⁻¹ K⁻¹]。
pub(crate) fn rate_slope(ea: f64, n: f64, t: f64) -> f64 {
    rate(ea, n, t) * apparent_energy(ea, n, t) / (GAS_CONSTANT * t * t)
}

/// 中心差分の相対誤差の主項 (h²/6)|g′² + 3g″ + g‴/g′|。h = ε^(1/3) T、g = ln k。
pub(crate) fn central_truncation(ea: f64, n: f64, t: f64) -> f64 {
    let h = f64::EPSILON.cbrt() * t;
    let g1 = n / t + ea / (GAS_CONSTANT * t * t);
    let g2 = -n / (t * t) - 2.0 * ea / (GAS_CONSTANT * t.powi(3));
    let g3 = 2.0 * n / t.powi(3) + 6.0 * ea / (GAS_CONSTANT * t.powi(4));
    h * h / 6.0 * (g1 * g1 + 3.0 * g2 + g3 / g1).abs()
}
```

## 温度の範囲での相対誤差

次のセルは 250 K から 1500 K まで 50 K ごとに、四つの計算で $E_{a,\mathrm{app}} = R T^2 k'/k$ を求め、解析式 $E_a + nRT$ との相対誤差を計算する。
四つの計算は複素ステップ法、中心差分、既定の許容誤差による適応差分、`with_tolerance` に `ErrorTolerance::scalar(0.0, √ε, NormSelection::Infinity)` を渡して絶対許容誤差を 0 にした適応差分である。
$k'/k$ の $k$ は `rate` で計算する。
表は計算ごとの最大の相対誤差、1 点あたりの評価回数の範囲、終了理由、相対誤差がちょうど 0 になった点の数を示す。
最後の行は、中心差分の相対誤差の主項 $(h^2/6) \lvert k'''/k' \rvert$ を上の式で計算した値の最大である。
このセルは温度ごとの相対誤差と主項を次のセルに渡し、$E_a$ と $n$ をその次のセルにも渡す。

```rust
//| id: differentiate-arrhenius-sensitivity
//| ref: differentiate-arrhenius-sensitivity
//| title: 修正 Arrhenius 式の見かけの活性化エネルギーを四つの計算で求める
//| run: reactive
//| uses: [differentiate-arrhenius-model]
//| crates: [scioxide-core, scioxide-differentiate]
//| exports: [ea_kj, n, temperatures, errors, theory]
//| inputs:
//|   ea_kj: {"type":"range","label":"活性化エネルギー Ea [kJ/mol]","min":50,"max":250,"step":25,"value":200}
//|   n: {"type":"range","label":"温度の冪 n","min":-1.0,"max":2.0,"step":0.5,"value":1.5}
//| cases:
//|   - {"id":"low-barrier","label":"Ea = 50 kJ/mol, n = −1","description":"低温の k′ が 10⁻⁴ s⁻¹ K⁻¹ 程度まで大きくなり、既定の許容誤差による適応差分も正しい値を返す。","inputs":{"ea_kj":50,"n":-1.0}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"summary","path":"/rows/0/1","range":{"max":1e-13}}
//|       - {"artifact":"summary","path":"/rows/1/1","approx":{"value":5.484e-8,"rtol":0.02}}
//|       - {"artifact":"summary","path":"/rows/2/1","range":{"min":1}}
//|       - {"artifact":"summary","path":"/rows/2/4","equals":"Converged"}
//|       - {"artifact":"summary","path":"/rows/3/1","range":{"max":1e-11}}
//|       - {"artifact":"summary","path":"/rows/4/1","approx":{"value":5.484e-8,"rtol":1e-3}}
//|   - case: low-barrier
//|     expect:
//|       - {"artifact":"summary","path":"/rows/0/1","range":{"max":1e-13}}
//|       - {"artifact":"summary","path":"/rows/2/1","range":{"max":1e-6}}
//|       - {"artifact":"summary","path":"/rows/2/4","equals":"Converged"}
use scioxide_core::{ErrorTolerance, SciOxideError, NormSelection};
use scioxide_differentiate::{AdaptiveDifference, ComplexStep, FiniteDifference};

let ea = ea_kj * 1000.0;
// 絶対許容誤差を 0 にして、相対許容誤差 √ε だけで判定させる。
let relative_only = ErrorTolerance::scalar(0.0, f64::EPSILON.sqrt(), NormSelection::Infinity)
    .map_err(|e| e.to_string())?;
let adaptive = AdaptiveDifference::default();
let relative = AdaptiveDifference::default().with_tolerance(relative_only);
let temperatures: Vec<f64> = (0..=25).map(|k| 250.0 + 50.0 * f64::from(k)).collect();
let mut errors: [Vec<f64>; 4] = Default::default();
let mut counts = [(usize::MAX, 0_usize); 4];
let mut terminations: [Vec<String>; 4] = Default::default();
for &t in &temperatures {
    let real = |s: f64| Ok::<_, SciOxideError>(rate(ea, n, s));
    let results = [
        ComplexStep::default().derivative(|z| rate_complex(ea, n, z), t),
        FiniteDifference::default().derivative(real, t),
        adaptive.derivative(real, t),
        relative.derivative(real, t),
    ];
    let exact = apparent_energy(ea, n, t);
    for (i, result) in results.into_iter().enumerate() {
        let result = result.map_err(|e| e.to_string())?;
        let slope = result.values().ok_or("導関数が公開されない")?[0];
        // Ea,app = R T² k′/k の解析式 Ea + nRT に対する相対誤差。
        let apparent = GAS_CONSTANT * t * t * slope / rate(ea, n, t);
        errors[i].push(((apparent - exact) / exact).abs());
        let evaluations = result.report().evaluations();
        counts[i] = (counts[i].0.min(evaluations), counts[i].1.max(evaluations));
        let name = result.report().termination().to_string();
        if !terminations[i].contains(&name) {
            terminations[i].push(name);
        }
    }
}
// 中心差分の相対誤差の主項（理論値）。
let theory: Vec<f64> = temperatures
    .iter()
    .map(|&t| central_truncation(ea, n, t))
    .collect();
let largest = |values: &[f64]| values.iter().fold(0.0_f64, |m, v| m.max(*v));
let labels = [
    "複素ステップ法",
    "中心差分",
    "適応差分（既定の許容誤差）",
    "適応差分（絶対許容誤差 0）",
];
// (計算, 最大の相対誤差, 評価回数の最小, 最大, 終了理由, 誤差 0 の点の数)
let mut rows: Vec<_> = (0..4)
    .map(|i| {
        (
            labels[i],
            largest(&errors[i]),
            Some(counts[i].0),
            Some(counts[i].1),
            Some(terminations[i].join(", ")),
            Some(errors[i].iter().filter(|e| **e == 0.0).count()),
        )
    })
    .collect();
rows.push((
    "中心差分の打ち切り誤差の主項（理論）",
    largest(&theory),
    None,
    None,
    None,
    None,
));
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let columns = serde_json::json!([
    { "key": "0", "label": "計算" },
    { "key": "1", "label": "最大の相対誤差 [-]", "type": "number", "format": sci3 },
    { "key": "2", "label": "1 点の評価回数の最小 [回]", "type": "integer", "nullText": "—" },
    { "key": "3", "label": "1 点の評価回数の最大 [回]", "type": "integer", "nullText": "—" },
    { "key": "4", "label": "終了理由", "nullText": "—" },
    { "key": "5", "label": "相対誤差が 0 の点 [点]", "type": "integer", "nullText": "—" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "summary" })
);
export!(ea_kj, &ea_kj);
export!(n, &n);
export!(temperatures, &temperatures);
export!(errors, &errors);
export!(theory, &theory);
```

既定の $E_a = 200\,\mathrm{kJ/mol}$、$n = 1.5$ では、見かけの活性化エネルギーは 250 K の 203.118 kJ/mol から 1500 K の 218.708 kJ/mol まで変わる。
複素ステップ法の相対誤差は全温度で $1.5 \times 10^{-14}$ 以下で、1 点あたり 2 回の評価で済み、26 点のうち 3 点では相対誤差がちょうど 0 になる。
中心差分は 3 回の評価で、相対誤差は 250 K の $5.5 \times 10^{-8}$ が最大であり、主項の最大 $5.5 \times 10^{-8}$ と一致する。
既定の許容誤差による適応差分は、450 K 以下の 5 点で相対誤差が 1 を超え、250 K では $10^{9}$ の大きさに達するのに、どの温度でも `Converged` を返す。
絶対許容誤差を 0 にした適応差分は、19〜31 回の評価で相対誤差を $1.1 \times 10^{-13}$ 以下にする。

$E_a = 50\,\mathrm{kJ/mol}$、$n = -1$ にすると、250 K の $k'$ は $10^{-4}\,\mathrm{s^{-1}\,K^{-1}}$ 程度まで大きくなり、既定の許容誤差による適応差分でも相対誤差は $10^{-8}$ の大きさにとどまる。
既定の許容誤差で問題が起きるかどうかは、導関数の大きさと絶対許容誤差の比で決まる。

次のセルは前のセルが渡す温度ごとの相対誤差を、求め直さずに温度に対して描く。
入力の縦軸で、四つの計算の相対誤差と、中心差分の相対誤差を主項で割った比を切り替える。
相対誤差の図は対数軸で、破線が主項、横線が計算機イプシロン $\varepsilon$ である。
相対誤差がちょうど 0 の点は対数軸に描けないので除き、その数は前の表にある。
比の図では、横線の 1 が観測と主項の一致を表す。

```rust
//| id: differentiate-arrhenius-error-curves
//| ref: differentiate-arrhenius-error-curves
//| title: 見かけの活性化エネルギーの相対誤差と中心差分の主項
//| run: reactive
//| crates: [scioxide-core]
//| dependsOn:
//|   sweep: differentiate-arrhenius-sensitivity
//| inputs:
//|   view: {"type":"select","label":"縦軸","options":["相対誤差","中心差分の誤差 ÷ 主項"],"value":"相対誤差"}
//| cases:
//|   - {"id":"ratio","label":"誤差 ÷ 主項","description":"中心差分の相対誤差を主項で割った比は、全温度で 1 との差が 1 % 未満になる。","inputs":{"view":"中心差分の誤差 ÷ 主項"}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"curves","path":"/spec/series/1/points/0/1","approx":{"value":5.484e-8,"rtol":0.02}}
//|       - {"artifact":"curves","path":"/spec/series/4/points/0/1","approx":{"value":5.484e-8,"rtol":1e-3}}
//|   - case: ratio
//|     expect:
//|       - {"artifact":"curves","path":"/spec/series/0/points/0/1","approx":{"value":1.0,"rtol":0.01}}
//|       - {"artifact":"curves","path":"/spec/series/0/points/25/1","approx":{"value":1.0,"rtol":0.01}}
let read = |name: &str| serde_json::from_value::<Vec<f64>>(sweep[name].clone());
let temperatures = read("temperatures").map_err(|e| e.to_string())?;
let theory = read("theory").map_err(|e| e.to_string())?;
let errors = serde_json::from_value::<Vec<Vec<f64>>>(sweep["errors"].clone())
    .map_err(|e| e.to_string())?;
let curve = |values: &[f64]| -> Vec<[f64; 2]> {
    // 0 の点は対数軸に描けないので除く。
    temperatures
        .iter()
        .zip(values)
        .filter(|(_, v)| **v > 0.0)
        .map(|(t, v)| [*t, *v])
        .collect()
};
let (series, y_type, label, reference) = if view == "相対誤差" {
    let names = [
        "複素ステップ法",
        "中心差分",
        "適応差分（既定）",
        "適応差分（atol = 0）",
    ];
    let mut series: Vec<_> = (0..4)
        .map(|i| {
            serde_json::json!({
                "name": names[i],
                "points": curve(&errors[i]),
                "style": { "showSymbol": true }
            })
        })
        .collect();
    series.push(serde_json::json!({
        "name": "中心差分の主項",
        "points": curve(&theory),
        "style": { "lineType": "dashed", "showSymbol": false }
    }));
    (series, "log", "Ea,app の相対誤差 [-]", (f64::EPSILON, "ε"))
} else {
    // 中心差分の観測した相対誤差 ÷ 主項 (h²/6)|k‴/k′|。主項が 0 の温度は除く。
    let ratios: Vec<[f64; 2]> = temperatures
        .iter()
        .zip(errors[1].iter().zip(&theory))
        .filter(|(_, (_, p))| **p > 0.0)
        .map(|(t, (e, p))| [*t, e / p])
        .collect();
    let series = vec![serde_json::json!({ "name": "観測 ÷ 主項", "points": ratios })];
    (series, "value", "中心差分の相対誤差 ÷ 主項 [-]", (1.0, "1"))
};
let line = serde_json::json!({
    "kind": "line",
    "axis": "y",
    "value": reference.0,
    "label": reference.1
});
emit_chart!(
    serde_json::json!({
        "kind": "line",
        "series": series,
        "xLabel": "温度 T [K]",
        "yLabel": label,
        "yType": y_type,
        "dataZoom": true,
        "tooltip": true,
        "annotations": [line]
    }),
```

相対誤差の図では、中心差分の観測した誤差が破線の主項とほぼ重なり、誤差が打ち切り誤差の主項で決まっていることが分かる。
比の図にすると、比は全温度で 0.995 から 1.005 の間にあり、主項との差は 0.5 % 以内である。
既定の許容誤差による適応差分の誤差は 450 K 以下で 1 を超え、500–700 K でも $10^{-11}$ から $10^{-8}$ の大きさで、750 K 以上で絶対許容誤差 0 の適応差分と同じ値になる。

## 絶対許容誤差と推定誤差

既定の許容誤差による適応差分が誤った値で `Converged` になる理由を、1 つの温度で推定誤差と閾値を並べて確かめる。
次のセルは温度の範囲を計算した最初のセルの $E_a$ と $n$ を受け取り、選んだ温度 $T$ で三つの適応差分を比べる。
1 行目と 2 行目は $k(T)$ を既定の許容誤差と絶対許容誤差 0 で微分する。
3 行目は無次元の $\ln k(T)$ を既定の許容誤差で微分し、$E_{a,\mathrm{app}} = R T^2 \, \mathrm{d} \ln k / \mathrm{d}T$ を直接求める。
$\mathrm{d} \ln k / \mathrm{d}T$ は 250 K で 0.39 K⁻¹、1500 K で 0.012 K⁻¹ なので、絶対許容誤差 $\sqrt{\varepsilon}$ は温度の範囲のどこでも導関数の大きさに比べて十分小さい。
表は導関数の推定値 $D$、推定誤差、閾値 $\tau_{\mathrm{abs}} + \tau_{\mathrm{rel}} \lvert D \rvert$、解析値との実際の誤差、$E_{a,\mathrm{app}}$ とその相対誤差、評価回数、終了理由を示す。
$D$ の単位は、1 行目と 2 行目が $\mathrm{s^{-1}\,K^{-1}}$、3 行目が $\mathrm{K^{-1}}$ である。

```rust
//| id: differentiate-arrhenius-tolerance
//| ref: differentiate-arrhenius-tolerance
//| title: 適応差分の絶対許容誤差と推定誤差
//| run: reactive
//| uses: [differentiate-arrhenius-model]
//| crates: [scioxide-core, scioxide-differentiate]
//| dependsOn:
//|   model: differentiate-arrhenius-sensitivity
//| inputs:
//|   temperature: {"type":"range","label":"温度 T [K]","description":"導関数を求める温度。低温ほど k′ が小さい。","min":250,"max":1500,"step":50,"value":250}
//| cases:
//|   - {"id":"high-temperature","label":"T = 1500 K","description":"k′ が 10⁵ s⁻¹ K⁻¹ を超え、既定の許容誤差でも正しい値になる。","inputs":{"temperature":1500}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"estimates","path":"/rows/0/8","equals":"Converged"}
//|       - {"artifact":"estimates","path":"/rows/0/2","range":{"max":1.5e-8}}
//|       - {"artifact":"estimates","path":"/rows/0/6","range":{"min":1}}
//|       - {"artifact":"estimates","path":"/rows/1/6","range":{"max":1e-11}}
//|       - {"artifact":"estimates","path":"/rows/2/5","approx":{"value":203.118,"atol":1e-3}}
//|       - {"artifact":"estimates","path":"/rows/2/6","range":{"max":1e-8}}
//|   - case: high-temperature
//|     expect:
//|       - {"artifact":"estimates","path":"/rows/0/5","approx":{"value":218.708,"atol":1e-3}}
//|       - {"artifact":"estimates","path":"/rows/0/6","range":{"max":1e-8}}
use scioxide_core::{ErrorTolerance, SciOxideError, NormSelection};
use scioxide_differentiate::AdaptiveDifference;

let ea = model["ea_kj"].as_f64().ok_or("活性化エネルギーがない")? * 1000.0;
let n = model["n"].as_f64().ok_or("温度の冪がない")?;
let t = temperature;
let root_eps = f64::EPSILON.sqrt();
let relative_only = ErrorTolerance::scalar(0.0, root_eps, NormSelection::Infinity)
    .map_err(|e| e.to_string())?;
let exact = apparent_energy(ea, n, t);
let mut rows = Vec::new();
for (name, logarithm, atol) in [
    ("k(T)、既定の許容誤差", false, root_eps),
    ("k(T)、絶対許容誤差 0", false, 0.0),
    ("ln k(T)、既定の許容誤差", true, root_eps),
] {
    let method = if atol > 0.0 {
        AdaptiveDifference::default()
    } else {
        AdaptiveDifference::default().with_tolerance(relative_only.clone())
    };
    let result = if logarithm {
        method.derivative(|s: f64| Ok::<_, SciOxideError>(log_rate(ea, n, s)), t)
    } else {
        method.derivative(|s: f64| Ok::<_, SciOxideError>(rate(ea, n, s)), t)
    }
    .map_err(|e| e.to_string())?;
    let value = result.values().ok_or("導関数が公開されない")?[0];
    let estimate = result.errors().ok_or("推定誤差が出力に反映されない")?[0];
    // 解析値: d ln k/dT = Ea,app/(RT²)、k′ = k Ea,app/(RT²)。
    let (reference, apparent) = if logarithm {
        (exact / (GAS_CONSTANT * t * t), GAS_CONSTANT * t * t * value)
    } else {
        (
            rate_slope(ea, n, t),
            GAS_CONSTANT * t * t * value / rate(ea, n, t),
        )
    };
    rows.push((
        name,
        value,
        estimate,
        atol + root_eps * value.abs(),
        (value - reference).abs(),
        apparent / 1000.0,
        ((apparent - exact) / exact).abs(),
        result.report().evaluations(),
        result.report().termination().to_string(),
    ));
}
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let digits7 = serde_json::json!({ "significantDigits": 7 });
let columns = serde_json::json!([
    { "key": "0", "label": "微分する量と許容誤差" },
    { "key": "1", "label": "推定値 D", "type": "number", "format": sci3 },
    { "key": "2", "label": "推定誤差", "type": "number", "format": sci3 },
    { "key": "3", "label": "閾値 τabs + τrel|D|", "type": "number", "format": sci3 },
    { "key": "4", "label": "実際の誤差", "type": "number", "format": sci3 },
    { "key": "5", "label": "Ea,app [kJ/mol]", "type": "number", "format": digits7 },
    { "key": "6", "label": "Ea,app の相対誤差 [-]", "type": "number", "format": sci3 },
    { "key": "7", "label": "評価回数 [回]", "type": "integer" },
    { "key": "8", "label": "終了理由" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "estimates" })
);
```

既定の 250 K では、解析的な $k'$ は $2.52 \times 10^{-29}\,\mathrm{s^{-1}\,K^{-1}}$ である。
既定の許容誤差による適応差分は 7 回の評価で $D = -5.9 \times 10^{-20}$ を返し、符号まで誤った値で `Converged` になる。
推定誤差 $1.2 \times 10^{-19}$ は実際の誤差 $5.9 \times 10^{-20}$ の約 2 倍で、誤差の大きさを正しく示している。
それでも閾値 $\sqrt{\varepsilon} \approx 1.5 \times 10^{-8}$ よりはるかに小さいので、2 準位続けて閾値を満たしたと判定される。
原因は推定誤差ではなく、閾値の絶対許容誤差が導関数の大きさに合っていないことにある。
絶対許容誤差を 0 にすると閾値は $\sqrt{\varepsilon} \lvert D \rvert$ に縮み、適応差分は 31 回の評価まで準位を重ねて、相対誤差 $10^{-13}$ の値に達する。
$\ln k$ を微分すると、既定の許容誤差のまま 17 回の評価で $E_{a,\mathrm{app}} = 203.118\,\mathrm{kJ/mol}$ が求まる。
1500 K では $k'$ が $7.4 \times 10^{5}\,\mathrm{s^{-1}\,K^{-1}}$ と大きく、絶対許容誤差は閾値にほとんど効かないので、三つの設定のどれでも正しい値になる。

## まとめ

修正 Arrhenius 式の見かけの活性化エネルギー $R T^2 \, \mathrm{d}\ln k / \mathrm{d}T$ は $E_a + nRT$ となり、温度とともに変わるので、数値微分の検算に使える。
速度定数を計算する手続きを複素数で書けば、複素ステップ法は 2 回の評価で、相対誤差 $10^{-14}$ 程度の導関数を返す。
実数の中心差分の相対誤差は打ち切り誤差の主項 $(h^2/6) \lvert k'''/k' \rvert$ でよく予測でき、$E_a/(RT)$ が大きいほど増える。
適応差分の既定の絶対許容誤差 $\sqrt{\varepsilon}$ は導関数の単位で測られるので、$10^{-29}$ のように小さな量では閾値として働かず、誤った値でも `Converged` になる。
桁の大きく変わる量を適応差分で微分するときは、対数のような大きさ 1 程度の量を微分するか、絶対許容誤差を量の大きさに合わせるか 0 にし、結果を推定誤差とは独立な検算で確かめる。
