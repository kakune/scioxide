この章の例題は熱力学、化学反応、分子モデル、反応拡散、放射、状態方程式、天体力学の具体的なモデルの導関数を `scioxide-differentiate` で求める。
どの例題にも解析的な導関数、保存則や恒等式、別の方法のいずれかによる独立な検算を置いている。
操作入力を既定の値から変えると、刻みや節点の選び方、変数の大きさ、境界からの距離、ノイズによって結果がどう変わるかを確かめられる。

## 他の章と共有する題材

二つの例題は他の章と同じモデルを別の角度から扱い、パラメータの値をそろえている。
van der Waals 式の例題は CO2 の臨界値 $T_c = 304.13\,\mathrm{K}$、$p_c = 7.3773\,\mathrm{MPa}$ を使う。
液相と気相の共存は求根の章の [van der Waals 気体と Maxwell の等面積則](../../scioxide-rootfind/examples/van-der-waals-maxwell/) が主に扱い、根の陰的な感度は自動微分の章の [van der Waals 状態方程式の陰的感度](../../scioxide-ad/examples/van-der-waals-implicit/) が扱う。
軌道計算の例題は長半径 $a = 1$、焦点を原点に置いた楕円軌道と既定の離心率 $e = 0.6$ を、Kepler 方程式を六つの求根法で解く [Kepler 方程式と離心率](../../scioxide-rootfind/examples/kepler-equation/) とそろえている。

## まとめ

例題は表の値の微分、複素ステップ法、多変数の勾配とヘッセ行列、疎なヤコビ行列、境界、プロバイダーの選択、適応差分、作業領域の使い回しを、それぞれ一つのモデルで扱う。
検算には解析式や保存則のように数値微分と独立に分かる量を使い、適応差分の推定誤差や小さな残差だけで結果を受け入れない。
いくつかの例題では、変数の大きさに合わない既定の刻みや許容誤差が、誤った結果を `Converged` や `RoundoffLimit` とともに返すことを確かめている。
刻みと許容誤差は、量の大きさと、座標の原点をどこに取るかに合わせて選ぶ。
