分子のモデルでは、ポテンシャルエネルギー $U(\mathbf{x})$ の負の勾配が原子に働く力、ヘッセ行列が振動の剛性行列になる。
解析的な微分を書くのが手間なモデルや、エネルギーだけを返す外部の計算では、これらを差分で求めることになる。
この例題では Morse ポテンシャルで結合した一次元の原子鎖を使い、力を勾配の差分から、曲率をヘッセ行列と方向微分から求める。
解析的な力と剛性行列のほか、孤立した系の力の和が 0 になること（作用・反作用の法則）と、一様な平行移動でエネルギーが変わらないこと（並進不変性）を検算に使う。

## Morse ポテンシャルの原子鎖

$N$ 個の原子が直線上の位置 $x_1 < x_2 < \dots < x_N$（Å）にあり、隣どうしが Morse ポテンシャルで結合している。

$$
U(\mathbf{x}) = \sum_{i=1}^{N-1} V(x_{i+1} - x_i), \qquad V(r) = D_e \bigl[ 1 - e^{-a (r - r_e)} \bigr]^2 .
$$

$D_e$ は井戸の深さ（eV）、$a$ は井戸の幅の逆数（Å⁻¹）、$r_e$ は平衡結合長（Å）である。
値は炭素–炭素の単結合を想定して $D_e = 3.6\,\mathrm{eV}$、$a = 2.0\,\mathrm{\text{Å}^{-1}}$、$r_e = 1.54\,\mathrm{\text{Å}}$ とする。
$D_e$ は C–C 単結合の平均結合エンタルピー約 348 kJ/mol（1 結合あたり 3.6 eV）に合わせ、$r_e$ はエタンやダイヤモンドの C–C 結合長とした。
$a = 2.0\,\mathrm{\text{Å}^{-1}}$ のとき、平衡での力の定数は $V''(r_e) = 2 D_e a^2 = 28.8\,\mathrm{eV/\text{Å}^2} \approx 461\,\mathrm{N/m}$ である。
$\rho = r - r_e$、$u = e^{-a\rho}$ とおくと、結合の導関数は次の式になる。

$$
V'(r) = 2 D_e a \, u (1 - u), \qquad V''(r) = 2 D_e a^2 \, u (2 u - 1), \qquad V'''(r) = -2 D_e a^3 \, u (4 u - 1).
$$

$V''$ は $u = 1/2$、すなわち $\rho = \ln 2 / a = 0.347\,\mathrm{\text{Å}}$ で符号を変え、それより伸びた結合の曲率は負になる。

すべての結合を同じ $\Delta r$ だけ伸ばした配置 $x_i = (i - 1)(r_e + \Delta r)$ では、内部の原子に左右から働く結合の力は打ち消し合う。
力が残るのは両端の原子だけで、$r = r_e + \Delta r$ として $F_1 = V'(r)$、$F_N = -V'(r)$ になる。
これらはどちらも鎖の中の結合による内力なので、和は 0 になる。
ヘッセ行列は三重対角で、$H_{ii} = V''(r_{i-1,i}) + V''(r_{i,i+1})$（端では片方だけ）、$H_{i,i+1} = H_{i+1,i} = -V''(r_{i,i+1})$ である。
並進不変性 $U(\mathbf{x} + c\mathbf{1}) = U(\mathbf{x})$ から、ヘッセ行列の各行の和は 0、すなわち $\mathbf{H}\mathbf{1} = \mathbf{0}$ になる。

次のブロックは二つのセルが共有する定義である。
`chain` が一様に伸ばした配置、`energy` が $U(\mathbf{x})$、`gradient` が解析的な $\nabla U$、`bond_force`・`bond_curvature`・`bond_third` が $V'$・$V''$・$V'''$ に対応する。
指数関数は SciOxide の `RealScalar::exp` で計算する。

```rust
//| id: differentiate-morse-model
//| kind: definitions
//| title: Morse 原子鎖のエネルギーと解析的な導関数
//| crates: [scioxide-core]
use scioxide_core::RealScalar;

/// 井戸の深さ De [eV]。
pub(crate) const DEPTH: f64 = 3.6;
/// 井戸の幅の逆数 a [Å⁻¹]。
pub(crate) const WIDTH: f64 = 2.0;
/// 平衡結合長 re [Å]。
pub(crate) const BOND_LENGTH: f64 = 1.54;

/// すべての結合を Δr だけ伸ばした配置 xᵢ = (i − 1)(re + Δr) [Å]。
pub(crate) fn chain(atoms: usize, stretch: f64) -> Vec<f64> {
    (0..atoms)
        .map(|i| i as f64 * (BOND_LENGTH + stretch))
        .collect()
}

/// u = e^{−a(r − re)}。
fn decay(r: f64) -> f64 {
    RealScalar::exp(-WIDTH * (r - BOND_LENGTH))
}

/// V′(r) = 2 De a u(1 − u) [eV/Å]。
pub(crate) fn bond_force(r: f64) -> f64 {
    let u = decay(r);
    2.0 * DEPTH * WIDTH * u * (1.0 - u)
}

/// V″(r) = 2 De a² u(2u − 1) [eV/Å²]。
pub(crate) fn bond_curvature(r: f64) -> f64 {
    let u = decay(r);
    2.0 * DEPTH * WIDTH * WIDTH * u * (2.0 * u - 1.0)
}

/// V‴(r) = −2 De a³ u(4u − 1) [eV/Å³]。
pub(crate) fn bond_third(r: f64) -> f64 {
    let u = decay(r);
    -2.0 * DEPTH * WIDTH.powi(3) * u * (4.0 * u - 1.0)
}

/// U(x) = Σ De (1 − u)² [eV]。
pub(crate) fn energy(x: &[f64]) -> f64 {
    x.windows(2)
        .map(|w| DEPTH * (1.0 - decay(w[1] - w[0])).powi(2))
        .sum()
}

/// 解析的な勾配 ∇U [eV/Å]。結合 i の V′ は原子 i に −V′、原子 i + 1 に +V′ で入る。
pub(crate) fn gradient(x: &[f64], out: &mut [f64]) {
    out.fill(0.0);
    for i in 0..x.len() - 1 {
        let force = bond_force(x[i + 1] - x[i]);
        out[i] -= force;
        out[i + 1] += force;
    }
}
```

## 力と力の和

`FiniteDifference::default()` の `gradient` は座標ごとに中心差分をとり、$x$ での値と合わせて $2N + 1$ 回のエネルギーの評価で $\nabla U$ を返す。
力は $\mathbf{F} = -\nabla U$ である。
既定の刻みは原子ごとに $h_i = \varepsilon^{1/3} \max(1, \lvert x_i \rvert)$ で、座標の大きい原子ほど刻みが大きい（[SciOxide の既定刻み](oxref:differentiate-default-steps)）。

中心差分の打ち切り誤差は $h_i^2 \, \partial^3 U / \partial x_i^3 / 6$ である。
原子 1 では $U$ が $x_1$ に $V(x_2 - x_1)$ だけを通して依存するので $\partial^3 U / \partial x_1^3 = -V'''(r)$、原子 $N$ では $\partial^3 U / \partial x_N^3 = V'''(r)$ になる。
一様に伸ばした鎖の内部の原子では、左右の結合からの寄与が打ち消し合って 0 になる。
したがって差分の力は $F_1 \approx V' + h_1^2 V'''/6$、$F_N \approx -V' - h_N^2 V'''/6$ で、力の和は次のように予測できる。

$$
\sum_i F_i \approx \frac{(h_1^2 - h_N^2) \, V'''(r)}{6} .
$$

既定の刻みでは $h_1 \ne h_N$ なので、両端の打ち切り誤差は打ち消し合わず、力の和が 0 から離れる。
すべての原子に同じ絶対刻みを使うと $h_1 = h_N$ になり、予測は 0 になる。

次のセルは原子の数 $N$、結合の伸び $\Delta r$、刻みの決め方を選び、差分の力を解析的な力と比べる。
1 つ目の表は原子ごとの位置、要求した刻み、差分の力、解析的な力、誤差を示す。
2 つ目の表は差分の力の和、上の式による予測、評価回数と理論値 $2N + 1$ を示す。
絶対刻みの値 $6 \times 10^{-6}\,\mathrm{\text{Å}}$ は、原子 1 の既定の刻み $\varepsilon^{1/3} = 6.06 \times 10^{-6}$ とほぼ同じにしてある。

```rust
//| id: differentiate-morse-forces
//| ref: differentiate-morse-forces
//| title: Morse 原子鎖の差分による力と力の和
//| run: reactive
//| uses: [differentiate-morse-model]
//| crates: [scioxide-core, scioxide-differentiate]
//| inputs:
//|   atoms: {"type":"range","label":"原子の数 N","min":3,"max":10,"step":1,"value":5}
//|   stretch: {"type":"range","label":"結合の伸び Δr [Å]","description":"負の値は結合を縮める。","min":-0.2,"max":0.4,"step":0.05,"value":0.1}
//|   step_rule: {"type":"select","label":"刻みの決め方","options":["既定（座標に比例）","絶対刻み 6e-6 Å"],"value":"既定（座標に比例）"}
//| cases:
//|   - {"id":"absolute-step","label":"絶対刻み 6e-6 Å","description":"両端の刻みがそろい、打ち切り誤差が打ち消し合って力の和が丸めの大きさになる。","inputs":{"step_rule":"絶対刻み 6e-6 Å"}}
//|   - {"id":"compressed","label":"Δr = −0.2 Å","description":"結合を縮めると両端の力の向きが逆になり、鎖は外へ押し広げられる。","inputs":{"stretch":-0.2}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"forces","path":"/rows/0/3","approx":{"value":2.1371141814,"atol":1e-8}}
//|       - {"artifact":"forces","path":"/rows/0/5","range":{"max":1e-9}}
//|       - {"artifact":"forces","path":"/rows/4/5","approx":{"value":2.82e-8,"rtol":0.05}}
//|       - {"artifact":"total","path":"/rows/0/0","approx":{"value":2.76e-8,"rtol":0.05}}
//|       - {"artifact":"total","path":"/rows/0/1","approx":{"value":2.76e-8,"rtol":0.02}}
//|       - {"artifact":"total","path":"/rows/0/2","equals":11}
//|   - case: absolute-step
//|     expect:
//|       - {"artifact":"total","path":"/rows/0/0","range":{"min":-1e-10,"max":1e-10}}
//|       - {"artifact":"total","path":"/rows/0/1","equals":0}
//|   - case: compressed
//|     expect:
//|       - {"artifact":"forces","path":"/rows/0/3","range":{"max":-1}}
//|       - {"artifact":"forces","path":"/rows/0/5","range":{"max":1e-8}}
use scioxide_core::SciOxideError;
use scioxide_differentiate::{DifferenceStep, FiniteDifference};

let n = atoms as usize;
let x = chain(n, stretch);
let absolute = step_rule.starts_with("絶対");
let mut method = FiniteDifference::default();
if absolute {
    method = method.with_step(DifferenceStep::absolute(6e-6).map_err(|e| e.to_string())?);
}
let objective = |p: &[f64], y: &mut [f64]| {
    y[0] = energy(p);
    Ok::<(), SciOxideError>(())
};
let result = method
    .gradient(objective, &x, None, None)
    .map_err(|e| e.to_string())?;
let derivative = result.values().ok_or("勾配が出力に反映されない")?;
// 要求した刻み: 既定は ε^(1/3) max(1, |xᵢ|)。
let steps: Vec<f64> = x
    .iter()
    .map(|xi| {
        if absolute {
            6e-6
        } else {
            f64::EPSILON.cbrt() * xi.abs().max(1.0)
        }
    })
    .collect();
// 参照値: 一様な伸びでは両端だけに ±V′(r) が働く。
let r = BOND_LENGTH + stretch;
let rows: Vec<(usize, f64, f64, f64, f64, f64)> = (0..n)
    .map(|i| {
        let exact = match i {
            0 => bond_force(r),
            i if i == n - 1 => -bond_force(r),
            _ => 0.0,
        };
        (
            i + 1,
            x[i],
            steps[i],
            -derivative[i],
            exact,
            (-derivative[i] - exact).abs(),
        )
    })
    .collect();
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let fixed10 = serde_json::json!({ "fractionDigits": 10 });
let columns = serde_json::json!([
    { "key": "0", "label": "原子 i", "type": "integer" },
    { "key": "1", "label": "位置 x_i [Å]", "type": "number", "format": { "fractionDigits": 2 } },
    { "key": "2", "label": "要求した刻み h_i [Å]", "type": "number", "format": sci3 },
    { "key": "3", "label": "差分の力 [eV/Å]", "type": "number", "format": fixed10 },
    { "key": "4", "label": "解析的な力 [eV/Å]", "type": "number", "format": fixed10 },
    { "key": "5", "label": "誤差 [eV/Å]", "type": "number", "format": sci3 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "forces" })
);
let total: f64 = derivative.iter().map(|g| -g).sum();
// 打ち切り誤差の主項による予測 (h₁² − h_N²) V‴(r)/6。+ 0.0 で −0 を 0 にそろえる。
let predicted = (steps[0].powi(2) - steps[n - 1].powi(2)) * bond_third(r) / 6.0 + 0.0;
let total_columns = serde_json::json!([
    { "key": "0", "label": "力の和 Σ F_i [eV/Å]", "type": "number", "format": sci3 },
    { "key": "1", "label": "主項による予測 [eV/Å]", "type": "number", "format": sci3 },
    { "key": "2", "label": "評価回数 [回]", "type": "integer" },
    { "key": "3", "label": "2N + 1 [回]", "type": "integer" }
]);
emit_table_with_columns!(
    total_columns,
    vec![(total, predicted, result.report().evaluations(), 2 * n + 1)],
    metadata = serde_json::json!({ "id": "total" })
);
```

既定の $N = 5$、$\Delta r = 0.1\,\mathrm{\text{Å}}$ では、両端の力は解析値 $\pm V'(r) = \pm 2.1371141814\,\mathrm{eV/\text{Å}}$ と一致し、内部の原子の力は丸めの大きさになる。
原子 1（$x_1 = 0$）の刻みは $\varepsilon^{1/3}$、原子 5（$x_5 = 6.56\,\mathrm{\text{Å}}$）の刻みはその 6.56 倍なので、両端の誤差は $6.8 \times 10^{-10}$ と $2.8 \times 10^{-8}\,\mathrm{eV/\text{Å}}$ で、比は刻みの比の 2 乗 $6.56^2 = 43$ に近い。
力の和は $2.8 \times 10^{-8}\,\mathrm{eV/\text{Å}}$ 残り、打ち切り誤差の主項による予測とほぼ一致する。
絶対刻みにすると、両端の打ち切り誤差がそろって打ち消し合い、力の和は $4 \times 10^{-12}\,\mathrm{eV/\text{Å}}$ と丸めの大きさまで小さくなる。
ただし原子 $N$ の誤差そのものは原子 1 と同じ $6.5 \times 10^{-10}$ 程度に減るだけで、0 にはならない。
力の和が 0 に近いことは差分の誤差の目安にはなるが、打ち消し合う誤差は和に現れないので、個々の力の精度は示さない。
$\Delta r$ を負にして結合を縮めると、両端の力の向きが逆になる。
評価回数はどの入力でも $2N + 1$ である。

## ヘッセ行列と方向微分

振動の解析には剛性行列 $\mathbf{H}$ が要るが、反復法で固有値を求めるときなどは、ベクトルとの積 $\mathbf{H}\mathbf{v}$ だけで足りる。
`FiniteDifference::default()` の `hessian` は対角成分を二階の中心差分で、非対角成分を座標 $i$ と $j$ の一階の中心差分を重ねた 4 点の公式で求め、上三角だけを評価する。
評価回数は対角の $N$ 成分に 2 回ずつ、非対角の $N(N-1)/2$ 成分に 4 回ずつ、$x$ での 1 回を加えて $1 + 2N^2$ 回である。
二階差分の既定の刻みは $\varepsilon^{1/4} \max(1, \lvert x_i \rvert)$ で、誤差は $O(\sqrt{\varepsilon})$ の大きさになり、座標の大きい原子ほど刻みと誤差が大きい。

一方、勾配 $\nabla U$ を計算できれば、$\mathbf{H}\mathbf{v}$ は勾配の方向微分 $\mathrm{d}\nabla U(\mathbf{x} + \alpha \mathbf{v})/\mathrm{d}\alpha$ として `FiniteDifference::jvp` で求まる（[方向微分](oxref:differentiate-jvp-formula)）。
中心差分の方向微分は $\mathbf{x}$ と $\mathbf{x} \pm \alpha \mathbf{v}$ の 3 回の勾配の評価で済み、刻みは $\alpha = \varepsilon^{1/3} / \max_i (\lvert v_i \rvert / \max(1, \lvert x_i \rvert))$ である。
このセルでは勾配として定義の `gradient`（解析的な $\nabla U$）を使う。
エネルギーしかない場合に差分の勾配の方向微分をとると、1 回の勾配に $2N + 1$ 回のエネルギーの評価が要り、合計は $3(2N + 1)$ 回になる。

次のセルはヘッセ行列の差分を解析的な三重対角の剛性行列と比べ、並進ベクトル $\mathbf{1}$ または交互のベクトル $(1, -1, 1, \dots)$ との積を、ヘッセ行列から計算したものと方向微分で求めたもので比べる。
1 つ目の表は計算ごとの評価回数と理論値、剛性行列の最大誤差、$\mathbf{H}\mathbf{v}$ の最大誤差を示す。
2 つ目の表は解析的な結合の曲率 $V''(r)$ と $\lVert \mathbf{H}\mathbf{v} \rVert$ を示す。

```rust
//| id: differentiate-morse-curvature
//| ref: differentiate-morse-curvature
//| title: Morse 原子鎖の剛性行列とヘッセ行列とベクトルの積
//| run: reactive
//| uses: [differentiate-morse-model]
//| crates: [scioxide-core, scioxide-differentiate]
//| inputs:
//|   atoms: {"type":"range","label":"原子の数 N","min":3,"max":10,"step":1,"value":6}
//|   stretch: {"type":"range","label":"結合の伸び Δr [Å]","description":"0.35 Å を超えると結合の曲率 V″ が負になる。","min":-0.2,"max":0.4,"step":0.05,"value":0.1}
//|   vector: {"type":"select","label":"ベクトル v","options":["並進 (1, …, 1)","交互 (1, −1, …)"],"value":"並進 (1, …, 1)"}
//| cases:
//|   - {"id":"alternating","label":"交互のベクトル","description":"H v が 0 でなくなり、二つの計算が解析値と一致することを確かめる。","inputs":{"vector":"交互 (1, −1, …)"}}
//|   - {"id":"beyond-inflection","label":"Δr = 0.4 Å","description":"変曲点より伸びた結合では V″ が負になり、剛性行列の符号が逆になる。","inputs":{"stretch":0.4}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"methods","path":"/rows/0/1","equals":73}
//|       - {"artifact":"methods","path":"/rows/0/3","range":{"max":1e-3}}
//|       - {"artifact":"methods","path":"/rows/1/1","equals":3}
//|       - {"artifact":"methods","path":"/rows/1/4","range":{"max":1e-8}}
//|       - {"artifact":"reference","path":"/rows/0/0","approx":{"value":15.030989,"rtol":1e-6}}
//|       - {"artifact":"reference","path":"/rows/0/1","equals":0}
//|   - case: alternating
//|     expect:
//|       - {"artifact":"methods","path":"/rows/0/4","range":{"max":1e-2}}
//|       - {"artifact":"methods","path":"/rows/1/4","range":{"max":1e-7}}
//|   - case: beyond-inflection
//|     expect:
//|       - {"artifact":"reference","path":"/rows/0/0","range":{"max":0}}
//|       - {"artifact":"methods","path":"/rows/1/4","range":{"max":1e-8}}
use scioxide_core::SciOxideError;
use scioxide_differentiate::FiniteDifference;

let n = atoms as usize;
let x = chain(n, stretch);
let v: Vec<f64> = (0..n)
    .map(|i| {
        if vector.starts_with("並進") || i % 2 == 0 {
            1.0
        } else {
            -1.0
        }
    })
    .collect();
let objective = |p: &[f64], y: &mut [f64]| {
    y[0] = energy(p);
    Ok::<(), SciOxideError>(())
};
let method = FiniteDifference::default();
let result = method
    .hessian(objective, &x, None, None)
    .map_err(|e| e.to_string())?;
let hessian = result.values().ok_or("ヘッセ行列が出力に反映されない")?;
// 方向微分の対象は解析的な勾配 ∇U（出力は N 成分）。
let analytic_gradient = |p: &[f64], y: &mut [f64]| {
    gradient(p, y);
    Ok::<(), SciOxideError>(())
};
let directional = method
    .jvp(analytic_gradient, &x, &v, n, None, None)
    .map_err(|e| e.to_string())?;
let jv = directional.values().ok_or("方向微分が出力に反映されない")?;
// 参照値: 一様な伸びでの V″ と三重対角の剛性行列。
let curvature = bond_curvature(BOND_LENGTH + stretch);
let exact = |i: usize, j: usize| match i.abs_diff(j) {
    0 if i == 0 || i == n - 1 => curvature,
    0 => 2.0 * curvature,
    1 => -curvature,
    _ => 0.0,
};
let h_error = (0..n * n)
    .map(|k| (hessian[k] - exact(k / n, k % n)).abs())
    .fold(0.0, f64::max);
let product = |entry: &dyn Fn(usize, usize) -> f64| -> Vec<f64> {
    (0..n)
        .map(|i| (0..n).map(|j| entry(i, j) * v[j]).sum())
        .collect()
};
let hv = product(&|i, j| hessian[i * n + j]);
let exact_hv = product(&exact);
let max_error = |values: &[f64]| {
    values
        .iter()
        .zip(&exact_hv)
        .map(|(u, w)| (u - w).abs())
        .fold(0.0, f64::max)
};
let rows: Vec<(&str, usize, usize, Option<f64>, f64)> = vec![
```

既定の $N = 6$、$\Delta r = 0.1\,\mathrm{\text{Å}}$ では、結合の曲率は $V''(r) = 15.03\,\mathrm{eV/\text{Å}^2}$ である。
ヘッセ行列は $1 + 2 \times 36 = 73$ 回の評価で、剛性行列と $1.4 \times 10^{-4}\,\mathrm{eV/\text{Å}^2}$（$V''$ に対する相対誤差 $10^{-5}$ 程度）まで一致する。
並進ベクトルとの積は解析的には 0 で、ヘッセ行列から計算した積には $1.8 \times 10^{-4}$ の大きさの残りが出るが、方向微分の結果は $5 \times 10^{-10}$ の大きさで 0 に近い。
方向微分は勾配を 3 回評価するだけで、一階の差分なので誤差もヘッセ行列から計算した積より小さい。
交互のベクトルでは $\lVert \mathbf{H}\mathbf{v} \rVert = 128\,\mathrm{eV/\text{Å}^2}$ になり、最大誤差はヘッセ行列から計算した積で $2.9 \times 10^{-4}$、方向微分で $5.3 \times 10^{-8}\,\mathrm{eV/\text{Å}^2}$ である。
$\Delta r = 0.4\,\mathrm{\text{Å}}$ では $\rho$ が変曲点 $0.347\,\mathrm{\text{Å}}$ を超えるので $V'' < 0$ になり、剛性行列の対角成分も負になる。
剛性行列は $V''$ と半正定値の三重対角行列（鎖のグラフのラプラシアン行列）の積なので、並進以外のすべての方向で曲率が負になる。

## まとめ

エネルギーの勾配の差分から求めた力は、`FiniteDifference::gradient` の $2N + 1$ 回の評価で、解析的な力と $7 \times 10^{-10}$ から $3 \times 10^{-8}\,\mathrm{eV/\text{Å}}$ の誤差で一致する。
孤立した系の力の和は厳密には 0 だが、既定の刻みは原子の座標に比例するので両端の打ち切り誤差が打ち消し合わず、和には主項 $(h_1^2 - h_N^2) V'''/6$ の大きさの残りが出る。
同じ絶対刻みを使えば和は丸めの大きさになるが、和が小さいことは個々の力の精度を示さない。
ヘッセ行列は $1 + 2N^2$ 回の評価が要り、二階差分の誤差は $\sqrt{\varepsilon}$ の大きさにとどまる。
勾配を計算できるなら、$\mathbf{H}\mathbf{v}$ は `FiniteDifference::jvp` による勾配の方向微分で、3 回の勾配の評価とより小さい誤差で求まる。
