反応拡散方程式を空間で離散化して陰的な方法で時間積分すると、各段の Newton 法でヤコビ行列が要る。
各格子点の式は自分と隣の格子点の未知数にしか依存しないので、ヤコビ行列は疎になる。
構造的に直交する列をまとめて摂動する彩色（[疎ヤコビ行列の彩色による圧縮](../../algorithms/sparse-coloring/)）を使えば、関数の評価回数は格子点の数ではなく色の数で決まる。
この例題では拡散のある Brusselator 系を題材に、`ColoredJacobianPlan` で疎なヤコビ行列を求める。
色の数を理論上の下界と上界と比べ、評価回数を密な差分と比べ、値を解析的なヤコビ行列で確かめる。

## 拡散のある Brusselator 系

Brusselator は Prigogine と Lefever（1968）が提案した自己触媒反応のモデルで、二つの中間体の濃度 $u$、$v$ が振動しうる。
反応の項に拡散を加えた系は、Hairer と Wanner の教科書 *Solving Ordinary Differential Equations II* で硬い方程式の試験問題として使われている。
区間 $x \in [0, 1]$ で、無次元の濃度 $u(x, t)$、$v(x, t)$ は次の式に従う。

$$
\frac{\partial u}{\partial t} = 1 + u^2 v - 4 u + \alpha \frac{\partial^2 u}{\partial x^2},
\qquad
\frac{\partial v}{\partial t} = 3 u - u^2 v + \alpha \frac{\partial^2 v}{\partial x^2}.
$$

これは一般形 $A + u^2 v - (B + 1) u$、$B u - u^2 v$ で $A = 1$、$B = 3$ とした場合で、反応だけの定常解は $(u, v) = (A, B/A) = (1, 3)$ である。
拡散係数は Hairer と Wanner と同じ $\alpha = 0.02$ とし、両端の境界は定常解の値 $u = 1$、$v = 3$ に固定する。

## 空間の離散化とヤコビ行列

内部の $N$ 個の格子点 $x_i = i\,\Delta x$（$i = 1, \dots, N$、$\Delta x = 1/(N + 1)$）で、二階微分を中心差分 $(w_{i-1} - 2 w_i + w_{i+1})/\Delta x^2$ に置き換える。
$w_0$ と $w_{N+1}$ には境界の値を入れる。
すると $2N$ 個の未知数の常微分方程式系 $\dot{\mathbf{w}} = \mathbf{F}(\mathbf{w})$ になる。
$D = \alpha/\Delta x^2 = \alpha (N + 1)^2$ とおくと、格子点 $i$ の二つの式は

$$
F_{u,i} = 1 + u_i^2 v_i - 4 u_i + D (u_{i-1} - 2 u_i + u_{i+1}),
\qquad
F_{v,i} = 3 u_i - u_i^2 v_i + D (v_{i-1} - 2 v_i + v_{i+1})
$$

で、0 でない偏微分は次のとおりである。

$$
\frac{\partial F_{u,i}}{\partial u_i} = 2 u_i v_i - 4 - 2D, \quad \frac{\partial F_{u,i}}{\partial v_i} = u_i^2, \quad \frac{\partial F_{u,i}}{\partial u_{i \pm 1}} = D,
$$

$$
\frac{\partial F_{v,i}}{\partial u_i} = 3 - 2 u_i v_i, \quad \frac{\partial F_{v,i}}{\partial v_i} = -u_i^2 - 2D, \quad \frac{\partial F_{v,i}}{\partial v_{i \pm 1}} = D.
$$

拡散は同じ成分の隣の格子点としか結合しないので、どの行も非零は高々 4 個である。
両端の格子点の行は隣が一つ欠けるので 3 個で、非零の総数は $4 \cdot 2N - 4 = 8N - 4$ になる。

評価点は、境界の値とつながる滑らかな状態 $u_i = 1 + 0.5 \sin(\pi x_i)$、$v_i = 3 - 0.5 \sin(\pi x_i)$ とする。
定常解 $(1, 3)$ から離すのは、ヤコビ行列の対角の要素が格子点ごとに違う値をとるようにするためである。

次のブロックは、このページの二つのセルが共有する定義である。
`Brusselator` の `rhs` が $\mathbf{F}$、`coupling` が $D$、`state` が評価点、`exact` が上の偏微分の式、`pattern` が非零の位置に対応する。
`interleaved` は未知数の並べ方（次の節）を選ぶ。

```rust
//| id: differentiate-brusselator-model
//| kind: definitions
//| title: 拡散のある Brusselator 系の右辺、評価点、解析的なヤコビ行列と構造
//| crates: [scioxide-core]
use scioxide_core::{SciOxideError, RealScalar, StructuralPattern};

/// 内部の格子点 cells 個、拡散係数 alpha の離散化。
/// interleaved が真なら未知数を (u₁, v₁, u₂, v₂, …)、偽なら (u₁, …, u_N, v₁, …, v_N) と並べる。
#[derive(Debug, Clone, Copy)]
pub(crate) struct Brusselator {
    pub(crate) cells: usize,
    pub(crate) alpha: f64,
    pub(crate) interleaved: bool,
}

impl Brusselator {
    /// 未知数の数 2N。
    pub(crate) fn unknowns(&self) -> usize {
        2 * self.cells
    }

    /// 成分 s（0 は u、1 は v）と格子点 i（0 始まり）の未知数の番号。
    pub(crate) fn index(&self, s: usize, i: usize) -> usize {
        if self.interleaved {
            2 * i + s
        } else {
            s * self.cells + i
        }
    }

    /// 未知数の番号 k の (成分, 格子点)。
    pub(crate) fn split(&self, k: usize) -> (usize, usize) {
        if self.interleaved {
            (k % 2, k / 2)
        } else {
            (k / self.cells, k % self.cells)
        }
    }

    /// 拡散の結合 D = α/Δx² = α (N + 1)²。
    pub(crate) fn coupling(&self) -> f64 {
        let intervals = (self.cells + 1) as f64;
        self.alpha * intervals * intervals
    }

    /// 右辺 F(w)。範囲の外の隣は境界の値 u = 1、v = 3。
    pub(crate) fn rhs(&self, w: &[f64], y: &mut [f64]) -> Result<(), SciOxideError> {
        let (n, d) = (self.cells, self.coupling());
        let neighbor = |s: usize, i: Option<usize>| match i {
            Some(i) if i < n => w[self.index(s, i)],
            _ => [1.0, 3.0][s],
        };
        for i in 0..n {
            let (u, v) = (w[self.index(0, i)], w[self.index(1, i)]);
            let lap_u = neighbor(0, i.checked_sub(1)) - 2.0 * u + neighbor(0, Some(i + 1));
            let lap_v = neighbor(1, i.checked_sub(1)) - 2.0 * v + neighbor(1, Some(i + 1));
            y[self.index(0, i)] = 1.0 + u * u * v - 4.0 * u + d * lap_u;
            y[self.index(1, i)] = 3.0 * u - u * u * v + d * lap_v;
        }
        Ok(())
    }

    /// 評価点 u_i = 1 + 0.5 sin(πx_i)、v_i = 3 − 0.5 sin(πx_i)、x_i = i/(N + 1)。
    pub(crate) fn state(&self) -> Vec<f64> {
        let mut w = vec![0.0; self.unknowns()];
        for i in 0..self.cells {
            let x = (i + 1) as f64 / (self.cells + 1) as f64;
            let bump = 0.5 * RealScalar::sin(std::f64::consts::PI * x);
            w[self.index(0, i)] = 1.0 + bump;
            w[self.index(1, i)] = 3.0 - bump;
        }
        w
    }

    /// 参照値: 解析的なヤコビ行列の要素 ∂F_row/∂w_col（上の偏微分の式）。
    pub(crate) fn exact(&self, w: &[f64], row: usize, col: usize) -> f64 {
        let ((s, i), (t, j)) = (self.split(row), self.split(col));
        let (u, v, d) = (w[self.index(0, i)], w[self.index(1, i)], self.coupling());
        match (s, t, i.abs_diff(j)) {
            (0, 0, 0) => 2.0 * u * v - 4.0 - 2.0 * d,
            (0, 1, 0) => u * u,
            (1, 0, 0) => 3.0 - 2.0 * u * v,
            (1, 1, 0) => -u * u - 2.0 * d,
            (s, t, 1) if s == t => d,
            _ => 0.0,
        }
    }

    /// 非零の位置: 行 (s, i) は u_i、v_i と、同じ成分 s の隣の格子点に依存する。
    pub(crate) fn pattern(&self) -> Result<StructuralPattern, SciOxideError> {
        let (mut row_ptr, mut col_indices) = (vec![0], Vec::new());
        for row in 0..self.unknowns() {
            let (s, i) = self.split(row);
            let mut cols = vec![self.index(0, i), self.index(1, i)];
            cols.extend(i.checked_sub(1).map(|k| self.index(s, k)));
            cols.extend((i + 1 < self.cells).then(|| self.index(s, i + 1)));
            // StructuralPattern は各行の列番号を昇順で受け取る。
            cols.sort_unstable();
            col_indices.extend(cols);
            row_ptr.push(col_indices.len());
        }
        StructuralPattern::new(self.unknowns(), self.unknowns(), row_ptr, col_indices)
    }

    /// 疎な値（パターンの格納順）の各要素と解析解との差の絶対値。
    pub(crate) fn entry_errors(
        &self,
        w: &[f64],
        pattern: &StructuralPattern,
        values: &[f64],
    ) -> Vec<f64> {
        let view = pattern.view();
        let (row_ptr, col_indices) = (view.row_ptr(), view.col_indices());
        (0..self.unknowns())
            .flat_map(|row| (row_ptr[row]..row_ptr[row + 1]).map(move |k| (row, k)))
            .map(|(row, k)| (values[k] - self.exact(w, row, col_indices[k])).abs())
            .collect()
    }

    /// 密な値（行優先、要素 row·2N + col）と解析解との最大誤差。
    pub(crate) fn dense_error(&self, w: &[f64], values: &[f64]) -> f64 {
        let n = self.unknowns();
        (0..n * n)
            .map(|k| (values[k] - self.exact(w, k / n, k % n)).abs())
            .fold(0.0, f64::max)
    }
}
```

## 色の数の下界と上界

同じ行に非零を持つ二つの列は同じ色にできないので、一つの行の非零の列はすべて違う色になる。
したがって色の数 $p$ は行の非零の最大数 $\rho_{\max}$ 以上である。
この系では $\rho_{\max} = 4$ で、たとえば行 $F_{u,i+1}$ を共有する列 $u_i$、$u_{i+1}$、$v_{i+1}$、$u_{i+2}$ は互いに違う色を要する。

上界は帯幅から得られる。
$J_{ij} \ne 0$ が $\lvert i - j \rvert \le \beta$ のときだけ起こるなら、同じ行に非零を持つ二つの列の番号の差は $2\beta$ 以下である。
そこで列 $j$ を $j \bmod (2\beta + 1)$ で塗れば衝突がなく、$p \le 2\beta + 1$ になる（[並べ替えと彩色](../../../scioxide-sparse/algorithms/orderings-and-coloring/#帯行列の色の数)）。
上下の帯がすべて埋まった帯行列ではこの上界が最小の色の数に一致するが、帯の中に 0 がある行列ではもっと少ない色で足りることがある。

帯幅と貪欲な彩色の結果は、未知数の並べ方で変わる。

- **交互の並べ方** $(u_1, v_1, u_2, v_2, \dots)$ では、$u_i$ と $u_{i+1}$ の番号の差が 2 なので帯幅は $\beta = 2$ で、上界は 5 色である。
- **成分ごとの並べ方** $(u_1, \dots, u_N, v_1, \dots, v_N)$ では、$u_i$ と $v_i$ の番号の差が $N$ なので $\beta = N$ で、帯幅の上界は役に立たない。

並べ替えは行列の行と列を同じ置換で入れ替えるだけなので、列の交差グラフの形も $\rho_{\max}$ も変わらない。
しかし scioxide-sparse の `derivative_coloring` は列を番号の小さい順に見て、使える最小の色を割り当てる貪欲法なので、列を見る順が変わると色の数が変わりうる。
成分ごとの並べ方では、貪欲法はまず $u$ の列だけを見る。
$u_j$ は $u_{j \pm 1}$、$u_{j \pm 2}$ と衝突するので、$u$ の列は 3 色を周期的に使う。
両端以外の $v_j$ は $u_{j-1}$、$u_j$、$u_{j+1}$ の 3 色すべてと衝突し、$v$ どうしも番号の差が 2 以下なら衝突するので、新しい 3 色が要り、合計 6 色になる。
両端の $v_1$ と $v_N$ は隣の $u$ が 2 個しかないので、残る $u$ の色を使う。

## 構造と彩色

次のセルは選んだ $N$ と並べ方で構造を作り、`derivative_coloring` で列を彩色する。
表は構造から求めた下界 $\rho_{\max}$、帯幅 $\beta$ と上界 $\min(2\beta + 1, 2N)$ と、彩色が使った色の数である。
図は非零の位置を列の色の番号で塗ったもので、横軸が列（摂動する未知数）、縦軸が行（式）である。
同じ色の列が同じ行に現れないことが、図の各行で色が重ならないことで読み取れる。
このセルは $N$、並べ方、列の色を次のセルに渡す。

```rust
//| id: differentiate-brusselator-pattern
//| ref: differentiate-brusselator-pattern
//| title: Brusselator 系のヤコビ行列の構造と列の彩色
//| run: reactive
//| uses: [differentiate-brusselator-model]
//| crates: [scioxide-core, scioxide-sparse]
//| exports: [cells, interleaved, colors]
//| inputs:
//|   cells: {"type":"range","label":"内部の格子点の数 N","description":"未知数の数は 2N になる。","min":5,"max":40,"step":5,"value":20}
//|   layout: {"type":"select","label":"未知数の並べ方","description":"列を見る順が変わり、貪欲な彩色の色の数が変わる。","options":["交互 (u₁, v₁, u₂, …)","成分ごと (u₁, …, u_N, v₁, …)"],"value":"交互 (u₁, v₁, u₂, …)"}
//| cases:
//|   - {"id":"componentwise","label":"成分ごとの並べ方","description":"下界は 4 のままだが、帯幅が N に広がり、貪欲法は 6 色を使う。","inputs":{"layout":"成分ごと (u₁, …, u_N, v₁, …)"}}
//|   - {"id":"fine-grid","label":"N = 40","description":"未知数を 80 に増やしても、色の数は 4 のままである。","inputs":{"cells":40}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"structure","path":"/rows/0/1","equals":156}
//|       - {"artifact":"structure","path":"/rows/0/2","equals":4}
//|       - {"artifact":"structure","path":"/rows/0/3","equals":2}
//|       - {"artifact":"structure","path":"/rows/0/4","equals":5}
//|       - {"artifact":"structure","path":"/rows/0/5","equals":4}
//|   - case: componentwise
//|     expect:
//|       - {"artifact":"structure","path":"/rows/0/2","equals":4}
//|       - {"artifact":"structure","path":"/rows/0/3","equals":20}
//|       - {"artifact":"structure","path":"/rows/0/5","equals":6}
//|   - case: fine-grid
//|     expect:
//|       - {"artifact":"structure","path":"/rows/0/1","equals":316}
//|       - {"artifact":"structure","path":"/rows/0/5","equals":4}
use scioxide_sparse::derivative_coloring;

let model = Brusselator {
    cells: cells as usize,
    alpha: 0.02,
    interleaved: layout.starts_with("交互"),
};
let n = model.unknowns();
let pattern = model.pattern().map_err(|e| e.to_string())?;
let schedule = derivative_coloring(pattern.view()).map_err(|e| e.to_string())?;
let view = pattern.view();
let (row_ptr, col_indices) = (view.row_ptr(), view.col_indices());
// 下界 ρ_max（行の非零の最大数）と帯幅 β = max |row − col|。
let lower = row_ptr.windows(2).map(|r| r[1] - r[0]).max().unwrap_or(0);
let beta = (0..n)
    .flat_map(|row| {
        col_indices[row_ptr[row]..row_ptr[row + 1]]
            .iter()
            .map(move |&col| row.abs_diff(col))
    })
    .max()
    .unwrap_or(0);
let structure = vec![(
    n,
    col_indices.len(),
    lower,
    beta,
    (2 * beta + 1).min(n),
    schedule.color_count(),
)];
let columns = serde_json::json!([
    { "key": "0", "label": "未知数 2N", "type": "integer" },
    { "key": "1", "label": "非零", "type": "integer" },
    { "key": "2", "label": "下界 ρ_max", "type": "integer" },
    { "key": "3", "label": "帯幅 β", "type": "integer" },
    { "key": "4", "label": "上界 min(2β + 1, 2N)", "type": "integer" },
    { "key": "5", "label": "色の数", "type": "integer" }
]);
emit_table_with_columns!(
    columns,
    structure,
    metadata = serde_json::json!({ "id": "structure" })
);
// 非零 (列, 行) を列の色の番号で塗る。縦軸は 1 行目が上に来るように逆順に並べる。
let names: Vec<String> = (0..n)
    .map(|k| {
        let (s, i) = model.split(k);
        format!("{}{}", ["u", "v"][s], i + 1)
    })
    .collect();
let mut data = Vec::new();
for row in 0..n {
    for &col in &col_indices[row_ptr[row]..row_ptr[row + 1]] {
        data.push(serde_json::json!([
            col,
            n - 1 - row,
            schedule.colors()[col]
        ]));
    }
}
let rows_top_down: Vec<&String> = names.iter().rev().collect();
emit_chart!(
    serde_json::json!({
        "kind": "heatmap",
        "data": data,
        "xCategories": names,
        "yCategories": rows_top_down,
        "xLabel": "列（摂動する未知数）",
        "yLabel": "行（式）",
        "colorMin": 0.0,
        "colorMax": 5.0,
        "tooltip": true,
        "style": { "animation": false }
    }),
    metadata = serde_json::json!({
        "id": "coloring",
        "title": "ヤコビ行列の非零と列の色の番号（0 から 5）"
    })
);
export!(cells, model.cells);
export!(interleaved, model.interleaved);
export!(colors, schedule.colors().to_vec());
```

既定の $N = 20$ と交互の並べ方では未知数 40、非零 156 で、帯幅は $\beta = 2$、上界は 5 色である。
貪欲法は下界と同じ 4 色を使う。
図では $u$ の列が色 0、2、1、3、$v$ の列が色 1、3、0、2 を周期 4 で繰り返している。
成分ごとの並べ方にすると下界は 4 のままだが、帯幅は $\beta = 20$ に広がり、上の節の説明どおり貪欲法は 6 色を使う。
図では $v_1$ と $v_{20}$ が $u$ の色 2 を使っている。
$N = 40$ にすると未知数は 80、非零は 316 に増えるが、色の数は 4 のままである。

## 彩色ヤコビ行列と解析解

次のセルは前のセルから $N$、並べ方、列の色を受け取り、`ColoringSchedule::new` で彩色を作り直してから、`ColoredJacobianPlan` と既定の `AdaptiveDifference` でヤコビ行列を計算する。
`ColoringSchedule::new` は、同じ行に同じ色の列が二つないことを検査してから受け取るので、受け取った色が構造に合っていることの検算にもなる。
表は評価回数、終了理由と、解析的なヤコビ行列との最大誤差、最大の推定誤差、実際の誤差が推定誤差を超えた要素の数である。
解析解との比較は Plan とは独立な検算で、手で微分した式（定義の `exact`）を使う。
このセルは前のセルの入力に従い、自分の入力を持たない。

```rust
//| id: differentiate-brusselator-coloring
//| ref: differentiate-brusselator-coloring
//| title: Brusselator 系の彩色ヤコビ行列と解析解との比較
//| run: reactive
//| uses: [differentiate-brusselator-model]
//| crates: [scioxide-core, scioxide-differentiate]
//| dependsOn:
//|   coloring: differentiate-brusselator-pattern
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"accuracy","path":"/rows/0/0","equals":25}
//|       - {"artifact":"accuracy","path":"/rows/0/1","equals":"Converged"}
//|       - {"artifact":"accuracy","path":"/rows/0/2","range":{"max":1e-12}}
//|       - {"artifact":"accuracy","path":"/rows/0/3","range":{"max":1e-12}}
//|       - {"artifact":"accuracy","path":"/rows/0/4","equals":0}
use scioxide_core::{ColoringKind, ColoringSchedule};
use scioxide_differentiate::{AdaptiveDifference, ColoredJacobianPlan};

let cells = coloring["cells"].as_u64().ok_or("格子点の数がない")? as usize;
let interleaved = coloring["interleaved"].as_bool().ok_or("並べ方がない")?;
let colors: Vec<usize> =
    serde_json::from_value(coloring["colors"].clone()).map_err(|e| e.to_string())?;
let model = Brusselator {
    cells,
    alpha: 0.02,
    interleaved,
};
let w = model.state();
let pattern = model.pattern().map_err(|e| e.to_string())?;
let schedule = ColoringSchedule::new(pattern.clone(), ColoringKind::DerivativeColumns, colors)
    .map_err(|e| e.to_string())?;
let plan = ColoredJacobianPlan::new(&schedule, AdaptiveDifference::default())
    .map_err(|e| e.to_string())?;
let result = plan
    .evaluate(|x: &[f64], y: &mut [f64]| model.rhs(x, y), &w, None)
    .map_err(|e| e.to_string())?;
let values = result.values().ok_or("疎なヤコビ行列が出力に反映されない")?;
let estimates = result.errors().ok_or("推定誤差が出力に反映されない")?;
// 独立な検算: 値と推定誤差は格納順（行ごと）に並ぶので、要素ごとに解析解と比べる。
let errors = model.entry_errors(&w, &pattern, values);
let worst = errors.iter().fold(0.0_f64, |a, &b| a.max(b));
let largest_estimate = estimates.iter().fold(0.0_f64, |a, &b| a.max(b));
let exceeded = errors.iter().zip(estimates).filter(|(e, s)| e > s).count();
let report = result.report();
let accuracy = vec![(
    report.evaluations(),
    report.termination().to_string(),
    worst,
    largest_estimate,
    exceeded,
)];
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let columns = serde_json::json!([
    { "key": "0", "label": "評価回数 [回]", "type": "integer" },
    { "key": "1", "label": "終了理由" },
    { "key": "2", "label": "解析解との最大誤差 [-]", "type": "number", "format": sci2 },
    { "key": "3", "label": "最大の推定誤差 [-]", "type": "number", "format": sci2 },
    { "key": "4", "label": "誤差 > 推定誤差の要素", "type": "integer" }
]);
emit_table_with_columns!(
    columns,
    accuracy,
    metadata = serde_json::json!({ "id": "accuracy" })
);
```

既定の 4 色では評価回数は 25 回で、終了理由は `Converged` である。
解析的なヤコビ行列との最大誤差は $7.1 \times 10^{-15}$ で、最大の推定誤差 $6.6 \times 10^{-14}$ より小さく、推定誤差を超えた要素はない。
前のセルで成分ごとの並べ方を選ぶと 6 色になり、評価回数は 37 回に増えるが、誤差は変わらない。
$N = 40$ にしても評価回数は 25 回のままで、最大誤差は $2.8 \times 10^{-14}$、最大の推定誤差は $2.3 \times 10^{-13}$ になる。

## 評価回数の内訳

`ColoredJacobianPlan` は基準点 $\mathbf{F}(\mathbf{w})$ を 1 回評価し、色ごとに、その色の列をまとめて摂動した点を準位ごとに評価する。
各準位は摂動した 2 点なので、色 $c$ の準位数を $L_c$ とすると、評価回数は $1 + 2 \sum_c L_c$ である。
準位数の上限は既定で $L = 16$ なので、評価回数は高々 $1 + 32p$ になる。
区間を渡して片側の節点を使う列があっても、1 準位の標本は 2 点のままで、この上限は変わらない（[疎ヤコビ行列の彩色による圧縮](../../algorithms/sparse-coloring/)）。

列はその準位の推定誤差と、それまでで最良の推定値の推定誤差がどちらも閾値 $\sqrt{\varepsilon}(1 + \lvert J_{ij} \rvert)$ 以下になる準位が 2 回続くと収束する（[刻みと停止の規則](oxref:differentiate-stopping-rules)）。
推定誤差は 2 準位目から得られるので、どの列も少なくとも 3 準位を使う。
この系では最小の 3 準位で収束する。
同じ色の列は行を共有しないので、各行の値は一つの未知数だけを動かしたときの変化になる。
$\mathbf{F}$ の各成分はどの一つの未知数についても高々 2 次式（$u_i^2 v_i$ は $u_i$ の 2 次式、$v_i$ の 1 次式）なので、中心差分の打ち切り誤差は 0 になり、外挿の表はすぐに一致する。
したがって評価回数は $1 + 2 \cdot 3 \cdot p$ で、4 色なら 25 回、6 色なら 37 回である。

密な適応差分 `AdaptiveDifference::jacobian` は列を一つずつ摂動するので、同じ 3 準位で $1 + 6 \cdot 2N = 12N + 1$ 回を要する。
密な固定刻みの中心差分 `FiniteDifference::jacobian` は $2 \cdot 2N + 1 = 4N + 1$ 回で済むが、推定誤差を返さない。

## 格子点の数と評価回数

次のセルは $N$ を 5 から 80 まで変えて、彩色ヤコビ行列、密な適応差分、密な固定刻みの中心差分の評価回数と、解析的なヤコビ行列との最大誤差を比べる。
未知数の並べ方は交互とし、拡散係数 $\alpha$ を入力にする。
図は評価回数を両対数で描いたものである。

```rust
//| id: differentiate-brusselator-scaling
//| ref: differentiate-brusselator-scaling
//| title: 格子点の数による彩色と密な差分の評価回数と誤差
//| run: reactive
//| uses: [differentiate-brusselator-model]
//| crates: [scioxide-core, scioxide-differentiate, scioxide-sparse]
//| inputs:
//|   alpha: {"type":"select","label":"拡散係数 α","description":"拡散の結合 D = α(N + 1)² の大きさを変える。","options":["0.002","0.02","0.2"],"value":"0.02"}
//| cases:
//|   - {"id":"strong-diffusion","label":"α = 0.2","description":"D が 10 倍になっても評価回数は変わらない。彩色の誤差は D とともに増えるが、対角の大きさ 2D に比べれば丸め誤差の程度にとどまる。","inputs":{"alpha":"0.2"}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"counts","path":"/rows/0/3","equals":25}
//|       - {"artifact":"counts","path":"/rows/0/5","equals":21}
//|       - {"artifact":"counts","path":"/rows/4/1","approx":{"value":131.22,"rtol":1e-12}}
//|       - {"artifact":"counts","path":"/rows/4/2","equals":4}
//|       - {"artifact":"counts","path":"/rows/4/3","equals":25}
//|       - {"artifact":"counts","path":"/rows/4/4","equals":961}
//|       - {"artifact":"counts","path":"/rows/4/5","equals":321}
//|       - {"artifact":"counts","path":"/rows/4/6","range":{"max":1e-11}}
//|       - {"artifact":"counts","path":"/rows/4/7","range":{"max":1e-11}}
//|       - {"artifact":"counts","path":"/rows/4/8","range":{"min":1e-11,"max":1e-9}}
//|   - case: strong-diffusion
//|     expect:
//|       - {"artifact":"counts","path":"/rows/4/1","approx":{"value":1312.2,"rtol":1e-12}}
//|       - {"artifact":"counts","path":"/rows/4/3","equals":25}
//|       - {"artifact":"counts","path":"/rows/4/4","equals":961}
//|       - {"artifact":"counts","path":"/rows/4/6","range":{"max":1e-11}}
//|       - {"artifact":"counts","path":"/rows/4/8","range":{"min":1e-11,"max":1e-9}}
use scioxide_differentiate::{AdaptiveDifference, ColoredJacobianPlan, FiniteDifference};
use scioxide_sparse::derivative_coloring;

let alpha: f64 = alpha.parse().map_err(|_| "拡散係数を読めない")?;
let (mut rows, mut points) = (Vec::new(), [Vec::new(), Vec::new(), Vec::new()]);
for cells in [5_usize, 10, 20, 40, 80] {
    let model = Brusselator {
        cells,
        alpha,
        interleaved: true,
    };
    let (n, w) = (model.unknowns(), model.state());
    let f = |x: &[f64], y: &mut [f64]| model.rhs(x, y);
    let pattern = model.pattern().map_err(|e| e.to_string())?;
    let schedule = derivative_coloring(pattern.view()).map_err(|e| e.to_string())?;
    let adaptive = AdaptiveDifference::default();
    let colored = ColoredJacobianPlan::new(&schedule, adaptive.clone())
        .and_then(|plan| plan.evaluate(f, &w, None))
        .map_err(|e| e.to_string())?;
    let dense = adaptive
        .jacobian(f, &w, n, None)
        .map_err(|e| e.to_string())?;
    let central = FiniteDifference::default()
        .jacobian(f, &w, n, None, None)
        .map_err(|e| e.to_string())?;
    // 独立な検算: 解析解との最大誤差。疎な値は格納順、密な値は行優先。
    let sparse = colored.values().ok_or("疎なヤコビ行列が出力に反映されない")?;
    let sparse_error = model
        .entry_errors(&w, &pattern, sparse)
        .into_iter()
        .fold(0.0_f64, f64::max);
    let dense_values = dense.values().ok_or("密なヤコビ行列が出力に反映されない")?;
    let central_values = central
        .values()
        .ok_or("中心差分のヤコビ行列が出力に反映されない")?;
    let counts = [
        colored.report().evaluations(),
        dense.report().evaluations(),
        central.report().evaluations(),
    ];
    for (series, count) in points.iter_mut().zip(counts) {
        series.push([cells as f64, count as f64]);
    }
    rows.push((
        cells,
        model.coupling(),
        schedule.color_count(),
        counts[0],
        counts[1],
        counts[2],
        sparse_error,
        model.dense_error(&w, dense_values),
        model.dense_error(&w, central_values),
    ));
}

    { "key": "6", "label": "彩色の誤差 [-]", "type": "number", "format": sci2 },
    { "key": "7", "label": "密な適応差分の誤差 [-]", "type": "number", "format": sci2 },

]);
emit_table_with_columns!(

    rows,

);

    .map(|(name, points)| {
```

色の数はどの $N$ でも 4 で、彩色ヤコビ行列の評価回数は 25 回で一定である。
密な適応差分（$12N + 1$ 回）と密な中心差分（$4N + 1$ 回）の評価回数は $N$ に比例して増え、両対数の図では傾き 1 の直線になる。
$N = 5$ では未知数が 10 しかないので、彩色の 25 回は密な中心差分の 21 回より多い。
評価回数で彩色が有利になるのは $1 + 6p < 4N + 1$、つまり 4 色なら $N > 6$ のときである。
1 回の評価の計算量は $N$ に比例するので、ヤコビ行列 1 個の計算量は彩色で $O(N)$、密な差分で $O(N^2)$ になる。

彩色と密な適応差分の誤差は同じ値で、$N = 80$ でも $1.7 \times 10^{-13}$ である。
どちらも同じ列ごとの外挿を、同じ刻みで行うからである。
密な中心差分の誤差は $5 \times 10^{-11}$ から $9 \times 10^{-11}$ で、2 桁以上大きい。
この系では打ち切り誤差がないので、どちらの誤差も丸め誤差で決まる。
固定刻みの中心差分は刻み $h = \varepsilon^{1/3} \max(1, \lvert w_j \rvert)$ を使い、関数値の丸め誤差を $h$ で割った $\varepsilon^{2/3} \approx 3.7 \times 10^{-11}$ の程度の誤差が残る（[丸め誤差・ノイズと最適な刻み幅](oxref:differentiate-optimal-step)）。
適応差分は大きな刻み $0.5 \max(1, \lvert w_j \rvert)$ から始め、2 次式では大きな刻みでも打ち切り誤差が生じないので、丸め誤差だけが小さくなる。

$\alpha = 0.2$ にすると $D$ は 10 倍になるが、どの方法の評価回数も変わらない。
彩色の誤差は $N = 80$ で $1.8 \times 10^{-12}$ に増えるが、対角の要素の大きさ $2D \approx 2.6 \times 10^{3}$ に対しては $10^{-15}$ の程度で、相対的には丸め誤差の程度にとどまる。
密な中心差分の誤差は $D$ によらずほぼ同じである。

## まとめ

Brusselator 系の離散化のヤコビ行列は各行の非零が高々 4 個の疎行列なので、色の数の下界は $\rho_{\max} = 4$ で、交互の並べ方では帯幅 $\beta = 2$ から上界 5 も得られる。
`derivative_coloring` は交互の並べ方で下界どおりの 4 色、成分ごとの並べ方で 6 色を使うので、貪欲な彩色を使うときは帯幅が小さくなる並べ方を選ぶとよい。
`ColoredJacobianPlan` の評価回数は $1 + 2\sum_c L_c$ で、この系では格子点の数によらず 25 回になり、値は解析的なヤコビ行列と丸め誤差の程度で一致する。
未知数が少ないうちは密な固定刻みの中心差分のほうが評価回数が少なく、この系では $1 + 6p$ と $4N + 1$ を比べて彩色を使うかどうかを決められる。
推定誤差が要らず値だけが要るときは、同じ計算をワンショット関数 `sparse_jacobian` でも行え、`Converged` 以外の終了理由はエラーになる。
