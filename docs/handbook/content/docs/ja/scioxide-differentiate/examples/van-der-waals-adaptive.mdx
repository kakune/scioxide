状態方程式の圧力の体積微分 $(\partial p / \partial V)_T$ は、等温圧縮率 $\kappa_T = -1/(V (\partial p / \partial V)_T)$ や音速の計算に使い、臨界点では 0 になる。
van der Waals 式は解析的に微分できるので、数値微分の値と推定誤差を独立に検算できる。
この例題では CO2 の van der Waals 式を適応差分 `AdaptiveDifference` で微分し、変数の大きさと既定の刻みの関係、臨界点に近づくときの相対誤差、推定誤差と終了理由がどこまで信頼できるかを確かめる。
推定誤差は適応差分が成分ごとに返す誤差の見積もりで、上界ではない（[Richardson 外挿と Ridders の方法](../../algorithms/richardson-and-ridders/)）。

同じモデルの液相と気相の共存は求根の章の [van der Waals 気体と Maxwell の等面積則](../../../scioxide-rootfind/examples/van-der-waals-maxwell/) が主に扱い、根の陰的な感度は [van der Waals 状態方程式の陰的感度](../../../scioxide-ad/examples/van-der-waals-implicit/) で扱う。
CO2 の臨界値はこれらのページとそろえる。

## モデルと臨界点

1 mol あたりの体積 $V$ [m³/mol]、温度 $T$ [K] での圧力 $p$ [Pa] は次の式で表される。

$$
p(V, T) = \frac{R T}{V - b} - \frac{a}{V^2}, \qquad V > b.
$$

$a$ [Pa·m⁶/mol²] は分子間の引力、$b$ [m³/mol] は分子の排除体積を表す定数で、$R = 8.314462618\,\mathrm{J/(mol \cdot K)}$ は気体定数である。
体積についての一階と二階の導関数は次のとおりである。

$$
\left( \frac{\partial p}{\partial V} \right)_T = -\frac{R T}{(V - b)^2} + \frac{2a}{V^3},
\qquad
\left( \frac{\partial^2 p}{\partial V^2} \right)_T = \frac{2 R T}{(V - b)^3} - \frac{6a}{V^4}.
$$

臨界点は等温線が水平な変曲点になる点で、二つの導関数が同時に 0 になる。
二つの条件 $RT/(V - b)^2 = 2a/V^3$ と $2RT/(V - b)^3 = 6a/V^4$ の比をとると $(V - b)/2 = V/3$ となり、臨界値が決まる。

$$
V_c = 3b, \qquad T_c = \frac{8a}{27 R b}, \qquad p_c = \frac{a}{27 b^2}.
$$

逆に解くと $a = 27 R^2 T_c^2 / (64 p_c)$、$b = R T_c / (8 p_c)$ である。
CO2 の臨界値 $T_c = 304.13\,\mathrm{K}$、$p_c = 7.3773\,\mathrm{MPa}$ から、$a = 0.36566\,\mathrm{Pa \cdot m^6/mol^2}$、$b = 4.2846 \times 10^{-5}\,\mathrm{m^3/mol}$、$V_c = 1.2854 \times 10^{-4}\,\mathrm{m^3/mol}$ になる。

換算変数 $V_r = V/V_c$、$T_r = T/T_c$、$p_r = p/p_c$ を使うと、式は物質によらない形になる。

$$
p_r = \frac{8 T_r}{3 V_r - 1} - \frac{3}{V_r^2},
\qquad
\frac{\partial p_r}{\partial V_r} = -\frac{24 T_r}{(3 V_r - 1)^2} + \frac{6}{V_r^3}.
$$

物理単位の導関数には $\partial p / \partial V = (p_c / V_c)\, \partial p_r / \partial V_r$、$\partial^2 p / \partial V^2 = (p_c / V_c^2)\, \partial^2 p_r / \partial V_r^2$ で戻す。
臨界体積 $V_r = 1$ では、臨界温度からのずれ $\tau = T_r - 1$ を使って

$$
\frac{\partial p_r}{\partial V_r} = -6\tau,
\qquad
\frac{\partial^2 p_r}{\partial V_r^2} = 18\tau,
\qquad
\frac{\partial^3 p_r}{\partial V_r^3} = -9 - 81\tau
$$

となる。
一階導関数は $\tau$ に比例して 0 に近づき、等温圧縮率 $\kappa_T = 1/(6 \tau p_c)$ は $1/\tau$ で発散する。

次のブロックは三つのセルが共有するモデルである。
`pressure` が $p(V, T)$、`reduced_pressure` が $p_r(V_r, T_r)$、`exact_derivatives` が解析的な一階と二階の導関数で、解析式は検算だけに使う。

```rust
//| id: differentiate-vdw-model
//| kind: definitions
//| title: CO2 の van der Waals 式と解析的な導関数
//| crates: [scioxide-core]
/// 気体定数 R [J/(mol·K)]、CO2 の臨界温度 T_c [K] と臨界圧力 p_c [Pa]。
pub(crate) const GAS_CONSTANT: f64 = 8.314462618;
pub(crate) const CRITICAL_TEMPERATURE: f64 = 304.13;
pub(crate) const CRITICAL_PRESSURE: f64 = 7.3773e6;

/// 臨界値から決めた (a [Pa·m⁶/mol²], b [m³/mol])。
pub(crate) fn coefficients() -> (f64, f64) {
    let (r, tc, pc) = (GAS_CONSTANT, CRITICAL_TEMPERATURE, CRITICAL_PRESSURE);
    (27.0 * r * r * tc * tc / (64.0 * pc), r * tc / (8.0 * pc))
}

/// 圧力 p(V, T) = RT/(V − b) − a/V² [Pa]。
pub(crate) fn pressure(temp: f64, volume: f64) -> f64 {
    let (a, b) = coefficients();
    GAS_CONSTANT * temp / (volume - b) - a / (volume * volume)
}

/// 換算圧力 p_r = 8T_r/(3V_r − 1) − 3/V_r²。
pub(crate) fn reduced_pressure(reduced_temp: f64, reduced_volume: f64) -> f64 {
    8.0 * reduced_temp / (3.0 * reduced_volume - 1.0) - 3.0 / (reduced_volume * reduced_volume)
}

/// 参照値: 解析的な ∂p/∂V [Pa·mol/m³] と ∂²p/∂V² [Pa·mol²/m⁶]。
pub(crate) fn exact_derivatives(temp: f64, volume: f64) -> [f64; 2] {
    let (a, b) = coefficients();
    let rt = GAS_CONSTANT * temp;
    [
        -rt / (volume - b).powi(2) + 2.0 * a / volume.powi(3),
        2.0 * rt / (volume - b).powi(3) - 6.0 * a / volume.powi(4),
    ]
}
```

## 物理単位での既定の刻み

`AdaptiveDifference` は刻みを $h_0, h_0/1.4, h_0/1.4^2, \ldots$ と縮めながら中心差分を計算し、Ridders の方法で刻み 0 へ外挿する。
1 準位ごとに評価が 2 回増え、最初に $f(x)$ を 1 回評価する。
その準位の推定誤差と、それまでで最良の推定値の推定誤差がどちらも閾値 $\mathrm{atol} + \mathrm{rtol} \lvert D \rvert$ 以下になる準位が 2 回続くと `Converged`、最良の推定誤差が 3 準位続けて改善しないと `RoundoffLimit`、準位の上限（既定 16）に達すると `RefinementLimit` で止まる。
最初の刻みの既定は $h_0 = 0.5 \max(1, \lvert x \rvert)$ である（[刻みと停止の規則](oxref:differentiate-stopping-rules)）。

物理単位の $V \approx 10^{-4}\,\mathrm{m^3/mol}$ では、$h_0$ は $0.5\,\mathrm{m^3/mol}$ になる。
これは極 $V = b$ までの距離 $V - b \approx 10^{-4}$ より 3 桁以上大きく、節点は極 $V = b$ と $V = 0$ をまたぐ。
直し方として、ここでは二つを比べる。
一つは `with_step(DifferenceStep::absolute(h0))` で、最初の刻みを極までの距離より小さく明示する方法で、ここでは $h_0 = 0.1 (V - b)$ とする。
もう一つは換算変数で計算して変数の大きさを 1 程度にし、既定の刻みを使う方法である。
換算変数では極は $V_r = 1/3$ にあり、$V_r = 1.4$ での既定の $h_0 = 0.7$ は極までの距離 $1.07$ の 0.66 倍になる。

次のセルは選んだ温度と体積で、三つの設定の適応差分で一階と二階の導関数を求め、解析値と比べる。
表の「$h_0$ ÷ 極までの距離」は、最初の刻みを極までの距離（$V - b$、換算変数では $V_r - 1/3$）で割った値である。
相対誤差は解析値に対するもので、推定誤差も解析値の大きさで割って並べる。

```rust
//| id: differentiate-vdw-isotherm
//| ref: differentiate-vdw-isotherm
//| title: van der Waals 式の体積微分の三つの設定による適応差分
//| run: reactive
//| uses: [differentiate-vdw-model]
//| crates: [scioxide-core, scioxide-differentiate]
//| inputs:
//|   temp: {"type":"range","label":"温度 T [K]","min":280,"max":340,"step":5,"value":310}
//|   volume_r: {"type":"range","label":"換算体積 V/V_c [-]","min":0.6,"max":3.0,"step":0.2,"value":1.4}
//| cases:
//|   - {"id":"dilute","label":"V/V_c = 3.0","description":"極から遠く、換算変数の一階も Converged になるが、物理単位の既定の刻みは失敗したままである。","inputs":{"volume_r":3.0}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"isotherm","path":"/rows/0/2","equals":"RoundoffLimit"}
//|       - {"artifact":"isotherm","path":"/rows/0/5","range":{"min":0.5}}
//|       - {"artifact":"isotherm","path":"/rows/0/6","range":{"max":1e-3}}
//|       - {"artifact":"isotherm","path":"/rows/2/2","equals":"Converged"}
//|       - {"artifact":"isotherm","path":"/rows/2/5","range":{"max":1e-11}}
//|       - {"artifact":"isotherm","path":"/rows/3/2","equals":"Converged"}
//|       - {"artifact":"isotherm","path":"/rows/3/5","range":{"max":1e-9}}
//|       - {"artifact":"isotherm","path":"/rows/4/2","equals":"RoundoffLimit"}
//|       - {"artifact":"isotherm","path":"/rows/4/5","range":{"min":1e-3}}
//|       - {"artifact":"isotherm","path":"/rows/5/2","equals":"Converged"}
//|       - {"artifact":"isotherm","path":"/rows/5/5","range":{"max":1e-9}}
//|   - case: dilute
//|     expect:
//|       - {"artifact":"isotherm","path":"/rows/0/2","equals":"RoundoffLimit"}
//|       - {"artifact":"isotherm","path":"/rows/4/2","equals":"Converged"}
//|       - {"artifact":"isotherm","path":"/rows/4/5","range":{"max":1e-9}}
use scioxide_differentiate::{AdaptiveDifference, DifferenceStep};

let (_, b) = coefficients();
let vc = 3.0 * b;
let volume = volume_r * vc;
let reduced_temp = temp / CRITICAL_TEMPERATURE;
let exact = exact_derivatives(temp, volume);
let explicit = DifferenceStep::absolute(0.1 * (volume - b)).map_err(|e| e.to_string())?;
// (設定の名前, 手法オブジェクト, 換算変数か, 最初の刻み ÷ 極までの距離)
let configs = [
    (
        "物理単位・既定の刻み",
        AdaptiveDifference::default(),
        false,
        0.5 / (volume - b),
    ),
    (
        "物理単位・刻み 0.1 (V − b)",
        AdaptiveDifference::default().with_step(explicit),
        false,
        0.1,
    ),
    (
        "換算変数・既定の刻み",
        AdaptiveDifference::default(),
        true,
        0.5 * volume_r.max(1.0) / (volume_r - 1.0 / 3.0),
    ),
];
let mut rows = Vec::new();
for (name, method, reduced, step_ratio) in configs {
    for (k, label) in ["∂p/∂V", "∂²p/∂V²"].into_iter().enumerate() {
        // 換算変数では V_r で微分し、p_c / V_c^(k+1) を掛けて物理単位に戻す。
        let (point, scale) = if reduced {
            (volume_r, CRITICAL_PRESSURE / vc.powi(k as i32 + 1))
        } else {
            (volume, 1.0)
        };
        let f = |v: f64| {
            Ok(if reduced {
                reduced_pressure(reduced_temp, v)
            } else {
                pressure(temp, v)
            })
        };
        let result = if k == 0 {
            method.derivative(f, point)
        } else {
            method.second_derivative(f, point)
        }
        .map_err(|e| e.to_string())?;
        let value = scale * result.values().ok_or("導関数が公開されない")?[0];
        let estimate = scale * result.errors().ok_or("推定誤差が出力に反映されない")?[0];
        rows.push((
            name,
            label,
            result.report().termination().to_string(),
            result.report().evaluations(),
            step_ratio,
            ((value - exact[k]) / exact[k]).abs(),
            estimate / exact[k].abs(),
        ));
    }
}
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let columns = serde_json::json!([
    { "key": "0", "label": "設定" },
    { "key": "1", "label": "導関数" },
    { "key": "2", "label": "終了理由" },
    { "key": "3", "label": "評価回数 [回]", "type": "integer" },
    { "key": "4", "label": "h₀ ÷ 極までの距離 [-]", "type": "number", "format": sci3 },
    { "key": "5", "label": "相対誤差 [-]", "type": "number", "format": sci3 },
    { "key": "6", "label": "推定誤差 ÷ |解析値| [-]", "type": "number", "format": sci3 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "isotherm" })
);
```

既定の $T = 310\,\mathrm{K}$、$V = 1.4 V_c$ では、物理単位の既定の刻みの結果は相対誤差が 1 で、値はまったく使えない。
それでも推定誤差は解析値の $10^{-6}$ 倍しかなく、実際の誤差を 6 桁下回る。
推定誤差は外挿の表の値どうしの差から作るので、表の値がどれも極をまたいだ意味のない値なら、推定も意味を持たない。
このとき異常を示すのは終了理由の `RoundoffLimit` だけで、評価 11 回（5 準位）で止まっている。

刻みを $0.1(V - b)$ と明示すると、一階も二階も `Converged` になり、相対誤差は一階で $10^{-13}$、二階で $10^{-11}$ の大きさで、推定誤差は実際の誤差より大きい。
換算変数で既定の刻みを使うと、二階は収束するが、一階は評価 13 回（6 準位）で `RoundoffLimit` で止まる。
最初の刻み $0.7$ は極までの距離の 0.66 倍で、最初の数準位の差分は打ち切り誤差が大きく、外挿の表はまだ $h \to 0$ の漸近的な振る舞いに入っていない。
その間に最小になった推定誤差が続く 3 準位で改善しなかったので、丸め誤差が支配していないのに `RoundoffLimit` と判定された。
このときの相対誤差は $6.6 \times 10^{-2}$ で、推定誤差 $1.8 \times 10^{-4}$ を大きく上回る。
この停止は点に依存し、同じ $V/V_c = 1.4$ でも 280 K や 340 K では評価 19 回で収束する。
$V/V_c = 3$ でも換算変数の一階は評価 15 回で収束し（$h_0$ ÷ 極までの距離は 0.56）、物理単位の既定の刻みは、入力の範囲のどの点でも $h_0 = 0.5\,\mathrm{m^3/mol}$ が極をまたぐので失敗する。
変数の大きさを 1 程度にそろえるだけでは十分でない場合があるので、最初の刻みは最も近い特異点までの距離より十分小さく選び、終了理由が `Converged` であることを確かめる。

## 臨界点への接近

臨界点では $\partial p / \partial V = 0$ になるので、絶対誤差が一定でも相対誤差は $1/\tau$ で増える。
次のセルは $V = V_c$ で温度を $T_c (1 + \tau)$、$\tau = 10^{-1}$ から $10^{-7}$ と臨界温度に近づけ、換算変数で $\partial p_r / \partial V_r$ を求める。
図は実際の相対誤差と推定誤差の相対値を描き、破線は収束の判定に使う閾値 $\mathrm{atol} + \mathrm{rtol} \lvert D \rvert$ を $\lvert D \rvert = 6\tau$ で割った値である。
入力で許容誤差を既定の $\mathrm{atol} = \mathrm{rtol} = \sqrt{\varepsilon}$ と、相対だけの $\mathrm{atol} = 0$、$\mathrm{rtol} = \sqrt{\varepsilon}$ から選ぶ。
表は 1 桁ごとの値と、等温圧縮率の解析値 $\kappa_T = 1/(6 \tau p_c)$ である。

```rust
//| id: differentiate-vdw-critical
//| ref: differentiate-vdw-critical
//| title: 臨界点への接近による適応差分の相対誤差と推定誤差
//| run: reactive
//| uses: [differentiate-vdw-model]
//| crates: [scioxide-core, scioxide-differentiate]
//| inputs:
//|   tolerance: {"type":"select","label":"許容誤差","options":["atol = rtol = √ε","atol = 0, rtol = √ε"],"value":"atol = rtol = √ε"}
//| cases:
//|   - {"id":"relative","label":"atol = 0","description":"相対誤差 √ε を要求すると、臨界点の近くでは収束せず RoundoffLimit で止まる。","inputs":{"tolerance":"atol = 0, rtol = √ε"}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"critical","path":"/rows/0/1","equals":"Converged"}
//|       - {"artifact":"critical","path":"/rows/0/3","range":{"max":1e-11}}
//|       - {"artifact":"critical","path":"/rows/6/1","equals":"Converged"}
//|       - {"artifact":"critical","path":"/rows/6/3","range":{"max":1e-6}}
//|       - {"artifact":"critical","path":"/rows/6/5","approx":{"value":2.25920e-1,"rtol":1e-4}}
//|   - case: relative
//|     expect:
//|       - {"artifact":"critical","path":"/rows/0/1","equals":"Converged"}
//|       - {"artifact":"critical","path":"/rows/4/1","equals":"Converged"}
//|       - {"artifact":"critical","path":"/rows/5/1","equals":"RoundoffLimit"}
//|       - {"artifact":"critical","path":"/rows/6/1","equals":"RoundoffLimit"}
//|       - {"artifact":"critical","path":"/rows/6/3","range":{"max":1e-6}}
use scioxide_core::{ErrorTolerance, NormSelection, RealScalar};
use scioxide_differentiate::AdaptiveDifference;

let root = <f64 as RealScalar>::SQRT_EPSILON;
let absolute = if tolerance.starts_with("atol = 0") {
    0.0
} else {
    root
};
let tolerance = ErrorTolerance::scalar(absolute, root, NormSelection::Infinity)
    .map_err(|e| e.to_string())?;
let method = AdaptiveDifference::default().with_tolerance(tolerance);
let (mut actual, mut estimated, mut threshold, mut rows) =
    (Vec::new(), Vec::new(), Vec::new(), Vec::new());
for k in 0..=12 {
    let tau = 10.0_f64.powf(-1.0 - 0.5 * f64::from(k));
    let result = method
        .derivative(|v: f64| Ok(reduced_pressure(1.0 + tau, v)), 1.0)
        .map_err(|e| e.to_string())?;
    // 参照値: V_r = 1 での ∂p_r/∂V_r = −6τ。
    let exact = -6.0 * tau;
    let value = result.values().ok_or("導関数が公開されない")?[0];
    let estimate = result.errors().ok_or("推定誤差が出力に反映されない")?[0] / exact.abs();
    let error = ((value - exact) / exact).abs();
    // 誤差 0 の点は対数軸に描けないので除く。
    if error > 0.0 {
        actual.push([tau, error]);
    }
    estimated.push([tau, estimate]);
    threshold.push([tau, (absolute + root * exact.abs()) / exact.abs()]);
    if k % 2 == 0 {
        let termination = result.report().termination().to_string();
        let compressibility = 1.0 / (6.0 * tau * CRITICAL_PRESSURE);
        let evaluations = result.report().evaluations();
        rows.push((
            tau,
            termination,
            evaluations,
            error,
            estimate,
            compressibility,
        ));
    }
}

        "tooltip": true,

            { "name": "実際の相対誤差", "points": actual, "style": { "showSymbol": true } },
            { "name": "推定誤差 ÷ |解析値|", "points": estimated, "style": { "symbol": "triangle" } },

    { "key": "2", "label": "評価回数 [回]", "type": "integer" },
    { "key": "3", "label": "相対誤差 [-]", "type": "number", "format": sci3 },
    { "key": "4", "label": "推定誤差 ÷ |解析値| [-]", "type": "number", "format": sci3 },
    { "key": "5", "label": "κ_T の解析値 [1/Pa]", "type": "number", "format": sci3 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "critical" })
);
```

既定の許容誤差では、表の 7 点はどれも評価 21 回で `Converged` になる。
絶対誤差は $\tau$ によらず $8 \times 10^{-14}$ 以下にとどまるので、相対誤差は $\tau = 10^{-1}$ の $1.3 \times 10^{-13}$ から $\tau = 10^{-7}$ の $5.5 \times 10^{-8}$ まで、ばらつきながらほぼ $1/\tau$ に比例して増える。
推定誤差は全範囲で実際の誤差の 54 倍から 5000 倍と大きめで、その相対値は $7.1 \times 10^{-12}$ から $6.2 \times 10^{-6}$ までほぼ $1/\tau$ に比例して増える。

推定誤差の相対値が $\sqrt{\varepsilon} = 1.5 \times 10^{-8}$ を超えても `Converged` になるのは、絶対的な推定誤差が閾値 $\sqrt{\varepsilon}(1 + 6\tau)$ を下回るからである。
閾値は $\tau \to 0$ で $\sqrt{\varepsilon}$ に近づくので、相対値で見ると破線は $1/\tau$ で増え、既定の許容誤差は相対精度を保証しない。

$\mathrm{atol} = 0$ にすると閾値は $\sqrt{\varepsilon} \cdot 6\tau$ になり、相対値では水平な破線になる。
表の $\tau = 10^{-2}$ から $10^{-5}$ の点では評価を 2 回から 4 回増やして `Converged` になるが、$\tau \le 10^{-6}$ では閾値が丸め誤差を下回って満たせなくなり、評価 29 回で `RoundoffLimit` で止まる。
このとき出力に反映される最良の推定値の相対誤差は $10^{-8}$ から $10^{-7}$ で、既定の許容誤差で `Converged` になったときと同じ程度か、それより大きい。
許容誤差を厳しくしても丸め誤差より小さな誤差は得られないので、`RoundoffLimit` は求めた相対精度に届かないことの印として扱う。
相対誤差が必要な量では、既定の許容誤差の結果でも推定誤差の相対値を確かめる必要がある。

## ノイズのある圧力

圧力が測定値や反復計算の打ち切りを含むときは、関数値に丸め誤差よりずっと大きい誤差が乗る。
次のセルは換算圧力に大きさ $\sigma / p_c$ のノイズを加えて $V_r = 1$ で $\partial p_r / \partial V_r$ を一度求め、その終了理由をセルの結論として示す。
ノイズは点のビット列とシードから作る $[-1, 1)$ の擬似乱数で、同じ点では同じ値、異なる点では独立な値をとる（[ノイズのある関数](oxref:differentiate-noisy-functions)）。
ノイズの大きさ $\delta$ の関数に中心差分を使うとき、到達できる誤差の目安は $E^\ast = \tfrac{3}{2} (\lvert f''' \rvert / 3)^{1/3} \delta^{2/3}$ である。
ここでは $\delta = \sigma / p_c$、$f''' = \partial^3 p_r / \partial V_r^3 = -9 - 81\tau$ で、表には $E^\ast$ も解析値の大きさで割って並べる。
outcome は、`is_success()` が真なら satisfied、それ以外の終了理由なら最良の推定値を出力に反映した partial にする。

```rust
//| id: differentiate-vdw-noise
//| ref: differentiate-vdw-noise
//| title: ノイズのある圧力の体積微分と適応差分の終了理由
//| run: reactive
//| uses: [differentiate-vdw-model]
//| crates: [scioxide-core, scioxide-differentiate]
//| inputs:
//|   noise: {"type":"select","label":"圧力のノイズの大きさ σ [Pa]","options":["0","10","1000"],"value":"10"}
//|   tau: {"type":"select","label":"臨界温度からのずれ τ [-]","options":["1e-1","1e-3"],"value":"1e-1"}
//|   seed: {"type":"range","label":"ノイズのシード","min":0,"max":15,"step":1,"value":7}
//| cases:
//|   - {"id":"smooth","label":"σ = 0","description":"ノイズがなければ Converged になり、推定誤差は実際の誤差より大きい。","inputs":{"noise":"0"}}
//|   - {"id":"loud","label":"σ = 1000 Pa","description":"シード 7 では準位の上限で止まり、推定誤差は実際の誤差の 1/100 しかない。","inputs":{"noise":"1000"}}
//|   - {"id":"near-critical","label":"τ = 10⁻³","description":"導関数が小さくなり、同じノイズでも相対誤差は 100 倍になる。","inputs":{"tau":"1e-3"}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"noise","path":"/rows/0/0","equals":"RoundoffLimit"}
//|       - {"artifact":"noise","path":"/rows/0/2","range":{"max":5.47e-4}}
//|       - {"artifact":"noise","path":"/rows/0/4","approx":{"value":5.46974e-4,"rtol":1e-5}}
//|       - {"path":"/outputs/1/state","equals":"partial"}
//|   - case: smooth
//|     expect:
//|       - {"artifact":"noise","path":"/rows/0/0","equals":"Converged"}
//|       - {"artifact":"noise","path":"/rows/0/2","range":{"max":1e-11}}
//|       - {"path":"/outputs/1/state","equals":"satisfied"}
//|   - case: loud
//|     expect:
//|       - {"artifact":"noise","path":"/rows/0/0","equals":"RefinementLimit"}
//|       - {"artifact":"noise","path":"/rows/0/1","equals":33}
//|       - {"artifact":"noise","path":"/rows/0/2","range":{"min":1e-3}}
//|       - {"artifact":"noise","path":"/rows/0/3","range":{"max":1e-3}}
//|       - {"path":"/outputs/1/state","equals":"partial"}
//|   - case: near-critical
//|     expect:
//|       - {"artifact":"noise","path":"/rows/0/2","range":{"min":1e-4,"max":4.43e-2}}
//|       - {"artifact":"noise","path":"/rows/0/4","approx":{"value":4.42941e-2,"rtol":1e-5}}
//|       - {"path":"/outputs/1/state","equals":"partial"}
use scioxide_differentiate::AdaptiveDifference;

let sigma: f64 = noise.parse().map_err(|_| "ノイズの大きさを読めない")?;
let tau: f64 = tau.parse().map_err(|_| "τ を読めない")?;
let delta = sigma / CRITICAL_PRESSURE;
// ノイズのモデル: 点のビット列をシードと混ぜて splitmix64 で攪拌し、[-1, 1) の値にする。
let eta = |v: f64| {
    let mut z = v.to_bits() ^ (seed as u64).wrapping_mul(0x9E37_79B9_7F4A_7C15);
    z = (z ^ (z >> 30)).wrapping_mul(0xBF58_476D_1CE4_E5B9);
    z = (z ^ (z >> 27)).wrapping_mul(0x94D0_49BB_1331_11EB);
    z ^= z >> 31;
    (z >> 11) as f64 / (1_u64 << 53) as f64 * 2.0 - 1.0
};
let result = AdaptiveDifference::default()
    .derivative(
        |v: f64| Ok(reduced_pressure(1.0 + tau, v) + delta * eta(v)),
        1.0,
    )
    .map_err(|e| e.to_string())?;
let report = *result.report();
// 参照値: V_r = 1 での ∂p_r/∂V_r = −6τ と、ノイズ δ のもとでの中心差分の誤差の目安 E*。
let exact = -6.0 * tau;
let best = 1.5 * ((9.0 + 81.0 * tau) / 3.0).cbrt() * delta.powf(2.0 / 3.0);
let value = result.values().ok_or("導関数が公開されない")?[0];
let error = ((value - exact) / exact).abs();
let estimate = result.errors().ok_or("推定誤差が出力に反映されない")?[0] / exact.abs();
let termination = report.termination().to_string();
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let columns = serde_json::json!([
    { "key": "0", "label": "終了理由" },
    { "key": "1", "label": "評価回数 [回]", "type": "integer" },
    { "key": "2", "label": "相対誤差 [-]", "type": "number", "format": sci3 },
    { "key": "3", "label": "推定誤差 ÷ |解析値| [-]", "type": "number", "format": sci3 },
    { "key": "4", "label": "E* ÷ |解析値| [-]", "type": "number", "format": sci3 }
]);
let rows = vec![(
    termination.clone(),
    report.evaluations(),
    error,
    estimate,
    best / exact.abs(),
)];
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "noise" })
);
let outcome = if report.is_success() {
    Outcome::satisfied("推定誤差が許容誤差を満たした")
} else {
    Outcome::partial("外挿が許容誤差を満たす前に止まった")
        .explanation("値と推定誤差は最良の推定として出力に反映される。推定誤差は上界ではないので、ノイズの大きさから見積もった誤差と比べて読む。")
};
emit_outcome!(
    outcome
        .status(termination)
        .diagnostic("評価回数", report.evaluations() as f64, None)
        .diagnostic("相対誤差", error, None)
        .diagnostic("推定誤差 ÷ |解析値|", estimate, None)
);
```

既定の $\sigma = 10\,\mathrm{Pa}$、$\tau = 10^{-1}$ では、刻みを縮めるとノイズの寄与 $\delta / h$ が増えて推定誤差が改善しなくなり、評価 21 回で `RoundoffLimit` で止まる。
ノイズがなければ同じ点で `Converged` になるので、この終了理由はノイズの印として読める。
相対誤差は $8.4 \times 10^{-6}$、推定誤差の相対値は $2.2 \times 10^{-5}$ で、どちらも $E^\ast$ の相対値 $5.5 \times 10^{-4}$ より小さい。
外挿は打ち切り誤差の次数 $p$ を上げるので、最適な刻みが大きくなり、到達できる誤差は $\delta^{p/(p + 1)}$ の大きさまで下がる（[総誤差と最適な刻み幅](oxref:differentiate-optimal-step)）。
$E^\ast$ は一つの刻みの中心差分の目安で、適応差分の誤差の上界ではない。

推定誤差と実際の誤差の比はノイズの値によって変わる。
同じ $\sigma$ と $\tau$ でシードを 0、3、7、11、15 と変えると、終了理由はどれも `RoundoffLimit` だが、推定誤差は実際の誤差の 0.06 倍から 2.6 倍に散らばる。
ノイズのある関数では、推定誤差が実際の誤差を 1 桁以上下回ることがある。

$\sigma = 1000\,\mathrm{Pa}$ ではシード 7 で準位の上限 16 に達して評価 33 回で `RefinementLimit` になる。
相対誤差は $1.9 \times 10^{-2}$ で $E^\ast$ の相対値 $1.2 \times 10^{-2}$ と同じ大きさだが、推定誤差の相対値は $1.9 \times 10^{-4}$ で、実際の誤差の 1/100 しかない。
$\tau = 10^{-3}$ では導関数 $-6\tau$ が 100 倍小さくなるので、$\sigma = 10\,\mathrm{Pa}$ でも相対誤差は $10^{-3}$ の大きさになる。
臨界点に近づくとノイズのある圧力から求めた導関数は相対的な精度を失い、$\kappa_T$ の発散の様子は数値微分では追えなくなる。

## まとめ

物理単位の体積 $10^{-4}\,\mathrm{m^3/mol}$ に対して、適応差分の既定の最初の刻み $0.5\,\mathrm{m^3/mol}$ は極をまたぎ、結果は意味を持たず、推定誤差も実際の誤差を大きく下回る。
最初の刻みを極までの距離より小さく明示すると、相対誤差 $10^{-11}$ 以下の導関数と、それより大きな推定誤差が得られる。
換算変数で変数の大きさを 1 程度にそろえても、最初の刻みが特異点までの距離に近いと、早すぎる `RoundoffLimit` で止まることがある。
臨界点では導関数が 0 に近づくので相対誤差は $1/\tau$ で増え、既定の許容誤差は絶対誤差 $\sqrt{\varepsilon}$ を下限とするので相対精度を保証しない。
圧力にノイズがあると適応差分は `RoundoffLimit` か `RefinementLimit` で止まり、推定誤差は上界ではないので、終了理由が `Converged` でない結果はノイズの大きさから見積もった誤差と比べて使う。
