`scioxide-differentiate` は、関数の値だけから導関数を求めるクレートである。
スカラー関数の一階と二階の導関数、多変数の勾配、ヤコビ行列、ヘッセ行列、ヤコビ行列とベクトルの積（方向微分）を、固定刻みの差分、刻みを縮めて外挿する適応差分、呼び出し側が選んだ節点の差分、複素ステップ法で計算する。
疎なヤコビ行列は同じ行に非零を持たない列をまとめて動かす彩色で、少ない評価回数で求める。
このページでは差分の誤差の考え方と最初の計算を示し、結果の読み方、章の構成、ほかのクレートとの関係を説明する。

## 関数の値による導関数の近似

解析的な導関数を書くのが難しいモデル、ソースを書き換えられない外部の計算、表の値しかないデータでは、導関数を関数の値から推定するしかない。
コードを書き換えられる関数なら、自動微分（scioxide-ad）のほうが打ち切り誤差を持たず、一般に正確である（[数値微分の選び方](choosing/)）。

差分は近い点での関数の値の線形結合で導関数を近似する。
たとえば中心差分 $(f(x + h) - f(x - h)) / (2h)$ は、$f(x \pm h)$ を $x$ のまわりで Taylor 展開すると $f'(x) + h^2 f'''(x)/6 + O(h^4)$ に等しい。
差分の誤差は主に二つの原因から生じる。

| 原因 | 大きさ | 刻み $h$ を小さくすると |
|---|---|---|
| 打ち切り誤差（Taylor 展開の高次の項を捨てたこと） | 公式の次数 $p$ について $O(h^p)$（中心差分では $p = 2$） | 減る |
| 丸め誤差と関数のノイズ（近い値どうしの引き算で拡大される） | 一階の導関数で $\varepsilon_f \lvert f \rvert / h$ 程度 | 増える |

$\varepsilon_f$ は関数値の相対誤差の大きさである。
初等関数を数回組み合わせた式なら計算機イプシロン $\varepsilon = 2^{-52} \approx 2.2 \times 10^{-16}$ の数倍で、反復計算や測定の値ならもっと大きい。
二つの和は刻みに対して U 字の曲線になり、谷の位置が最適な刻みである。
中心差分では谷が $h \sim \varepsilon^{1/3}$ にあり、そこでの誤差は $\varepsilon^{2/3} \approx 3.7 \times 10^{-11}$ の大きさになる（[丸め誤差・ノイズと最適な刻み幅](algorithms/roundoff-and-noisy-functions/)）。
複素ステップ法は引き算を使わないので、一階導関数では丸め誤差が拡大されない。
適応差分は刻みを縮めた差分の変化から誤差を推定する。

偏微分方程式の空間の離散化も差分を使うが、それは領域全体の微分作用素を行列として組み立てて方程式を解くもので、scioxide-pde が扱う。
このクレートは与えられた関数の指定した点での導関数を求める。

## 最初の計算

次のセルは $f(x) = e^x \sin x$ の導関数 $f'(x) = e^x(\sin x + \cos x)$ を、三つの手法オブジェクトの `derivative(f, x)` で計算する。
手法オブジェクトは設定だけを持つ型で、演算はメソッドで選ぶ（[呼び出しの形](oxref:differentiate-call-forms-terms)）。

- `FiniteDifference::default()` は既定の刻み $h = \varepsilon^{1/3} \max(1, \lvert x \rvert)$ の中心差分で、$f(x)$ を含めて 3 回評価する。
- `AdaptiveDifference::default()` は Ridders の方法で刻みを縮めながら外挿し、推定誤差を返す。
- `ComplexStep::default()` は既定の刻み $h = \varepsilon$ で $\operatorname{Im} f(x + ih)/h$ を引き算なしに求め、$f(x)$ と $f(x + ih)$ の 2 回評価する。

ワンショット関数 `derivative(f, x)` と `complex_step_derivative(g, x)` も中心差分と複素ステップ法で同じ値を返すが、値しか返さないので、終了理由と評価回数を表に出すこのセルでは手法オブジェクトを使う。
被微分関数は `RealScalar` と scioxide-core の `Complex` の演算で書き、厳密値は f64 の固有メソッドで計算した参照値である。
入力は評価点 $x_0$ である。
表は $x_0$ での値、厳密値との誤差、推定誤差（適応差分だけ）、終了理由、評価回数を示す。
図は $x \in [-3, 3]$ の 121 点での三つの方法の誤差を対数軸で描く。
誤差がちょうど 0 になった点は対数軸に描けないので除き、その数を 2 つ目の表に出す。

```rust
//| id: differentiate-first-derivatives
//| ref: differentiate-first-derivatives
//| title: 中心差分・適応差分・複素ステップ法による最初の導関数
//| run: reactive
//| crates: [scioxide-core, scioxide-differentiate]
//| inputs:
//|   x0: {"type":"range","label":"評価点 x0","description":"表の値を求める点。図では縦線で示す。","min":-3.0,"max":3.0,"step":0.25,"value":1.0}
//| cases:
//|   - {"id":"large-x","label":"x0 = 3","description":"e^x と既定の刻みがともに大きく、中心差分の誤差が 10^-9 の大きさに増える。","inputs":{"x0":3.0}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"methods","path":"/rows/0/1","approx":{"value":3.756049227094728,"rtol":1e-9}}
//|       - {"artifact":"methods","path":"/rows/0/2","range":{"min":1e-12,"max":1e-10}}
//|       - {"artifact":"methods","path":"/rows/0/4","equals":"Completed"}
//|       - {"artifact":"methods","path":"/rows/0/5","equals":3}
//|       - {"artifact":"methods","path":"/rows/1/1","approx":{"value":3.756049227094728,"rtol":1e-14}}
//|       - {"artifact":"methods","path":"/rows/1/3","range":{"min":1e-14,"max":1e-10}}
//|       - {"artifact":"methods","path":"/rows/1/4","equals":"Converged"}
//|       - {"artifact":"methods","path":"/rows/2/1","approx":{"value":3.756049227094728,"rtol":1e-15}}
//|       - {"artifact":"methods","path":"/rows/2/3","equals":null}
//|       - {"artifact":"methods","path":"/rows/2/5","equals":2}
//|   - case: large-x
//|     expect:
//|       - {"artifact":"methods","path":"/rows/0/2","range":{"min":1e-10,"max":1e-8}}
//|       - {"artifact":"methods","path":"/rows/1/1","approx":{"value":-17.050059711659983,"rtol":1e-14}}
//|       - {"artifact":"methods","path":"/rows/2/1","approx":{"value":-17.050059711659983,"rtol":1e-15}}
use scioxide_core::{Complex, SciOxideError, RealScalar};
use scioxide_differentiate::{
    AdaptiveDifference, ComplexStep, DifferentiationResult, FiniteDifference,
};

// f(x) = e^x sin x を SciOxide の関数で書き、複素ステップ法には複素数版を渡す。
let f = |t: f64| Ok::<f64, SciOxideError>(RealScalar::exp(t) * RealScalar::sin(t));
let g = |z: Complex<f64>| Ok::<_, SciOxideError>(z.exp() * z.sin());
// 参照値: f'(x) = e^x (sin x + cos x)（f64 の固有メソッドによる独立な計算）。
let exact = |x: f64| x.exp() * (x.sin() + x.cos());
let run = |x: f64| -> Result<[DifferentiationResult<f64>; 3], String> {
    Ok([
        FiniteDifference::default()
            .derivative(f, x)
            .map_err(|e| e.to_string())?,
        AdaptiveDifference::default()
            .derivative(f, x)
            .map_err(|e| e.to_string())?,
        ComplexStep::default()
            .derivative(g, x)
            .map_err(|e| e.to_string())?,
    ])
};
let names = ["中心差分", "適応差分（Ridders）", "複素ステップ法"];
let mut rows = Vec::new();
for (name, result) in names.iter().zip(run(x0)?) {
    let report = result.report();
    let value = result.values().ok_or("導関数が公開されない")?[0];
    rows.push((
        *name,
        value,
        (value - exact(x0)).abs(),
        result.errors().map(|e| e[0]),
        report.termination().to_string(),
        report.evaluations(),
    ));
}
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let digits16 = serde_json::json!({ "significantDigits": 16 });
let columns = serde_json::json!([
    { "key": "0", "label": "方法" },
    { "key": "1", "label": "f′(x0) [-]", "type": "number", "format": digits16 },
    { "key": "2", "label": "厳密値との誤差 [-]", "type": "number", "format": sci3 },
    { "key": "3", "label": "推定誤差 [-]", "type": "number", "format": sci3, "nullText": "なし" },
    { "key": "4", "label": "終了理由" },
    { "key": "5", "label": "評価回数 [回]", "type": "integer" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "methods" })
);
// x ∈ [-3, 3] の 121 点の誤差。ちょうど 0 の誤差は対数軸に描けないので数えて除く。
let mut points: [Vec<[f64; 2]>; 3] = Default::default();
let mut zeros = [0_usize; 3];
for k in 0..=120 {
    let x = -3.0 + 0.05 * k as f64;
    for (i, result) in run(x)?.iter().enumerate() {
        let error = (result.values().ok_or("導関数が公開されない")?[0] - exact(x)).abs();
        if error > 0.0 {
            points[i].push([x, error]);
        } else {
            zeros[i] += 1;
        }
    }
}
let dropped: Vec<_> = (0..3).map(|i| (names[i], zeros[i])).collect();
let columns = serde_json::json!([
    { "key": "0", "label": "方法" },
    { "key": "1", "label": "誤差が 0 で図から除いた点 [個]", "type": "integer" }
]);
emit_table_with_columns!(
    columns,
    dropped,
    metadata = serde_json::json!({ "id": "dropped" })
);
let series: Vec<_> = (0..3)
    .map(|i| {
        serde_json::json!({
            "name": names[i],
            "points": points[i],
            "style": { "showSymbol": true }
        })
    })
    .collect();
emit_line_chart!(
    &series,
    options = &serde_json::json!({
        "xLabel": "評価点 x [-]",
        "yLabel": "導関数の絶対誤差 [-]",
        "yType": "log",
        "annotations": [{ "kind": "line", "axis": "x", "value": x0, "label": "x0" }]
    })
);
```

既定の $x_0 = 1$ では、中心差分の誤差は $2.3 \times 10^{-11}$ で、3 回の評価で求まる。
適応差分は 13 回の評価で誤差を $8.9 \times 10^{-16}$ まで下げ、推定誤差 $9.4 \times 10^{-13}$ は実際の誤差より大きい。
複素ステップ法は 2 回の評価で、誤差はこの点ではちょうど 0 になる。

図では、中心差分の誤差は $e^x$ と刻み $\varepsilon^{1/3} \max(1, \lvert x \rvert)$ がともに大きい正の側で増え、$x \in [2, 3]$ で $4 \times 10^{-10}$ から $2.5 \times 10^{-9}$ になる。
打ち切り誤差の主項 $h^2 f'''(x)/6$ が消える点、つまり $f'''(x) = 2e^x(\cos x - \sin x) = 0$ となる $x = \pi/4$ と $x = -3\pi/4$ の近くでは、中心差分の誤差が小さくなる。
適応差分と複素ステップ法の誤差は全範囲で $3 \times 10^{-14}$ 以下にとどまり、複素ステップ法では 121 点のうち 48 点で誤差がちょうど 0 になる。
$x_0 = 3$ にすると、中心差分の誤差は $2.5 \times 10^{-9}$ に増えるが、適応差分（17 回の評価）と複素ステップ法の誤差は $10^{-14}$ 程度のままである。

## 結果の読み方

手法オブジェクトの所有値を返す API（`derivative`、`gradient` など）と、Plan と節点を指定する差分法オブジェクトが持つ所有値を返す API `evaluate` は [`DifferentiationResult`](https://docs.rs/scioxide-differentiate/0.1.0/scioxide_differentiate/struct.DifferentiationResult.html) を返す。
`values()` は導関数の配列（ヤコビ行列とヘッセ行列は行優先）で、出力が出力に反映されたときだけ `Some` になる。
`errors()` は要素ごとの推定誤差で、適応差分と彩色が結果を出力に反映したときだけ `Some` を返す。
推定誤差は外挿の表の差と伝播した丸め誤差から作った見積もりで、上界ではない。
`into_values()` は成功した評価の値を取り出し、成功でない終了理由をエラーにする。
適応差分が途中で止まったときの最良の推定値を使うには、`values()` か `into_parts()` で読む。
ワンショット関数 `derivative`、`gradient`、`jacobian` などは値だけを返し、成功でない終了理由を `into_values()` と同じエラーとして返す。

`report()` が返す [`DifferentiationReport`](https://docs.rs/scioxide-differentiate/0.1.0/scioxide_differentiate/struct.DifferentiationReport.html) は、値を作った方法 `source()`、終了理由 `termination()`、関数の評価回数 `evaluations()`、反復回数 `iterations()`、推定が求まった要素の数 `completed_entries()`、出力への反映の有無 `output_available()` を持つ。
評価回数と反復回数の数え方は [呼び出しの形](oxref:differentiate-call-forms-terms) にある。
終了理由は [`DifferentiationTermination`](https://docs.rs/scioxide-differentiate/0.1.0/scioxide_differentiate/enum.DifferentiationTermination.html) の次のどれかである。

| 終了理由 | 意味 | 値の出力への反映 | `into_values()` のエラー |
|---|---|---|---|
| `Completed` | 固定刻み・節点・複素ステップ法の差分公式をすべて評価した（精度の主張はない） | する | なし |
| `Converged` | 適応差分と彩色で、すべての要素の推定誤差が 2 準位続けて許容誤差を満たし、最良の推定値の推定誤差も許容誤差以内にある | する | なし |
| `RoundoffLimit` | 最良の推定誤差が 3 準位続けて改善しなかった（多くは丸め誤差が打ち切り誤差を上回ったため） | すべての要素に推定があればする | `ConvergenceFailure`（`Stagnation`） |
| `RefinementLimit` | 準位の数の上限に達した | すべての要素に推定があればする | `ConvergenceFailure`（`TruncationLimit`） |
| `StepSizeLimit` | 区間の中で異なる有限の標本点を与える、より小さい刻みがない | すべての要素に推定があればする | `ConvergenceFailure`（`StepSizeLimit`） |
| `EvaluationLimit`、`IterationLimit` | 評価回数か反復回数の上限に達した | しない | `ConvergenceFailure`（同じ名前の理由） |
| `Cancelled`、`DeadlineReached` | 実行コンテキストの取り消しか期限 | しない | `ExecutionStopped` |

`is_success()` は `Completed` と `Converged` のときだけ真になる。
適応差分と彩色では、終了理由が `Converged` でなくても値が出力に反映されることがあるので、終了理由と推定誤差の両方を見てから値を使う。
入力の誤りや関数のエラーはレポートではなく `Err` で返り、分類は `e.kind()` で読む（[数値微分のアルゴリズムの共通仕様と構成](oxref:differentiate-input-checks)）。

## ほかのクレートとの関係

`scioxide-differentiate` が依存するのは scioxide-core だけである。
区間 `Bounds` と `ExtendedInterval`、評価回数と反復回数の上限 `SolveBudgets`・`BudgetKind`・`Budget`、許容誤差 `ErrorTolerance`、実行コンテキスト `ExecutionContext`・`SolveContext`・`SolveScope` と実行の方針 `ExecutionPolicy`、複素数 `Complex`、疎行列の構造 `StructuralPattern` と彩色 `ColoringSchedule` は scioxide-core の型である。
疎なヤコビ行列の列の彩色は scioxide-sparse の `derivative_coloring` で作れるが、このクレートは scioxide-sparse に依存せず、`ColoringSchedule` だけを受け取る。
自動微分は scioxide-ad が提供し、導関数のプロバイダーの方針 `DerivativeStrategy` には候補の一つとして名前だけが現れる。
scioxide-rootfind、scioxide-optimize、scioxide-ode のソルバーは、ヤコビ行列や勾配のプロバイダーを `DerivativeStrategy` で受け取る。

## まとめ

`scioxide-differentiate` は、関数の値から一階と二階の導関数、勾配、ヤコビ行列、ヘッセ行列、方向微分を、固定刻みの差分、適応差分、節点の差分、複素ステップ法、彩色で求める。
差分の誤差は打ち切り誤差と丸め誤差の和で、刻みに対して U 字の曲線になり、既定の刻みはその谷の目安である。
解析的に複素数へ拡張できる関数の一階導関数は複素ステップ法で丸めの大きさの誤差で求まり、推定誤差が要るときは適応差分を使う。
値は `output_available()` が真のときだけ出力に反映され、`Completed` は精度を主張せず、推定誤差は上界ではないので、値を使う前に終了理由と推定誤差を確かめる。
