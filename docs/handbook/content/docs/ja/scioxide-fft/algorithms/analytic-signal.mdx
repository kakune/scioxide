振幅変調波の包絡線や瞬時位相は、実信号から負の周波数の成分を除いた複素信号（解析信号）から読む。
`scioxide-fft` は Hilbert 変換と解析信号の関数を提供しない。
これらは `scioxide-signal` の `hilbert` と `envelope` が提供する。
このページは同じ計算を `scioxide-fft` の `rfft` と `ifft` から組み立て、離散の周波数の重みを導き、`hilbert` と照合する。

## 解析信号の定義

実信号 $x(t)$ の Hilbert 変換 $\mathcal{H}\{x\}$ は、Fourier 変換 $X(f)$ を使って

$$
\mathcal{F}\{\mathcal{H}\{x\}\}(f) = -i\,\mathrm{sgn}(f)\,X(f)
$$

と定義する。
正の周波数の位相を $\pi/2$ 遅らせ、負の周波数の位相を $\pi/2$ 進める演算である。
解析信号 $z = x + i\,\mathcal{H}\{x\}$ のスペクトルは、正の周波数で $2X(f)$、負の周波数で 0、$f = 0$ で $X(0)$ になる。
$\lvert z\rvert$ を瞬時振幅、$\arg z$ を瞬時位相と呼ぶ。

$\lvert z\rvert$ を変調の包絡線と読めるのは、包絡線のスペクトルが搬送波の周波数より低い帯域に収まるときである（Bedrosian の定理）。
例えば包絡線 $a(t)\ge0$ の帯域が $\lvert f\rvert<f_c$ に収まれば、$a(t)\cos 2\pi f_ct$ の Hilbert 変換は $a(t)\sin 2\pi f_ct$ になり、$\lvert z\rvert=a$ となる。

## 離散の解析信号の重み

長さ $N$ の標本を 1 周期とみなす離散の解析信号は、DFT $X_k$ に重み

$$
w_k = \begin{cases} 1 & k = 0,\ \text{または } N \text{ が偶数で } k = N/2 \\ 2 & 0 < k < N/2 \\ 0 & N/2 < k < N \end{cases}
$$

を掛けて逆変換した列 $z_n$ である（S. L. Marple, "Computing the discrete-time analytic signal via FFT", *IEEE Trans. Signal Process.* 47(9), 1999）。
奇数長では Nyquist のビンがないので、$0 < k \le \lfloor N/2\rfloor$ のすべてが 2 倍になる。
実数の列では $X_{N-k}=\overline{X_k}$ で、$X_0$ と偶数長の $X_{N/2}$ は実数である。
重みは $w_k+w_{N-k}=2$（$0<k<N$）と $w_0=1$ を満たすので、$\operatorname{Re} z_n = x_n$ が成り立つ。
`scioxide_signal::hilbert` も同じ重みを使う。

`scioxide-fft` で組み立てる手順は次のとおりである。

1. `rfft` で $X_0, \dots, X_{\lfloor N/2\rfloor}$ を求める。
2. 長さ $N$ の複素列を作り、$w_k X_k$ を $k \le \lfloor N/2\rfloor$ に入れ、残り（負の周波数）を 0 にする。
3. `ifft` で逆変換して $z_n$ を得る。
   演算量は $O(N \log N)$ である。

離散の解析信号は標本を周期列とみなすので、信号がウインドウの中で整数周期にならないと、両端の不連続が全帯域に広がり、端の近くの包絡線が乱れる。

### 振幅変調波の包絡線

次のセルは振幅変調波 $x_n = (1 + 0.5\cos 2\theta_n)\cos c\,\theta_n$、$\theta_n = 2\pi n/N$ の解析信号を上の手順で求める。
入力は標本数 $N$ と、ウインドウの中の搬送波の周期数 $c$ である。
$c$ が整数で $c + 2 < N/2$ なら、$x$ は 3 本の正の周波数の和で、真の包絡線 $1 + 0.5\cos 2\theta_n$ が丸め誤差を除いて得られる。
出力は包絡線の図と、$\operatorname{Re} z - x$、`scioxide_signal::hilbert` との差、真の包絡線との差の最大を示す表である。

```rust
//| id: fft-analytic-signal-weights
//| ref: fft-analytic-signal-weights
//| title: rfft と ifft で組み立てた解析信号を signal の hilbert と照合する
//| run: reactive
//| crates: [scioxide-core, scioxide-fft, scioxide-signal]
//| inputs:
//|   samples: {"type":"integer","label":"標本数 N","description":"奇数長では Nyquist のビンがない。","min":32,"max":64,"value":48}
//|   carrier_cycles: {"type":"range","label":"ウインドウ内の搬送波の周期数 c [-]","description":"整数でないとウインドウの両端で信号が不連続になる。","min":6,"max":12,"step":0.25,"value":10}
//| cases:
//|   - {"id":"odd-length","label":"N = 45","description":"奇数長でも重みは同じ形で、包絡線は厳密に得られる。","inputs":{"samples":45}}
//|   - {"id":"fractional-carrier","label":"c = 9.5","description":"周期がウインドウに合わず、端の近くで包絡線が乱れる。","inputs":{"carrier_cycles":9.5}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"errors","path":"/rows/0/1","range":{"max":1e-14}}
//|       - {"artifact":"errors","path":"/rows/1/1","range":{"max":1e-14}}
//|       - {"artifact":"errors","path":"/rows/2/1","range":{"max":1e-13}}
//|   - case: odd-length
//|     expect:
//|       - {"artifact":"errors","path":"/rows/1/1","range":{"max":1e-14}}
//|       - {"artifact":"errors","path":"/rows/2/1","range":{"max":1e-13}}
//|   - case: fractional-carrier
//|     expect:
//|       - {"artifact":"errors","path":"/rows/1/1","range":{"max":1e-14}}
//|       - {"artifact":"errors","path":"/rows/2/1","range":{"min":0.05}}
use scioxide_core::Complex;
use scioxide_fft::{Normalization, ifft, rfft};

// 振幅変調波 x_n（f64 の cos は入力と真の包絡線の生成だけに使う）
let count = samples as usize;
let theta = |k: usize| 2.0 * std::f64::consts::PI * k as f64 / count as f64;
let truth: Vec<f64> = (0..count)
    .map(|k| 1.0 + 0.5 * (2.0 * theta(k)).cos())
    .collect();
let x: Vec<f64> = (0..count)
    .map(|k| truth[k] * (carrier_cycles * theta(k)).cos())
    .collect();

// 1. rfft で X_0, …, X_⌊N/2⌋ を求める
let bins = rfft(&x, Normalization::Inverse).map_err(|e| e.to_string())?;
// 2. 重み w_k: DC と偶数長の Nyquist は 1、0 < k < N/2 は 2、負の周波数は 0
let mut weighted = vec![Complex::new(0.0, 0.0); count];
for (k, &value) in bins.bins().iter().enumerate() {
    let edge = k == 0 || 2 * k == count;
    weighted[k] = if edge { value } else { value * 2.0 };
}
// 3. ifft で解析信号 z_n に戻す
let z = ifft(&weighted, Normalization::Inverse).map_err(|e| e.to_string())?;

// 参照計算: signal の hilbert（同じ重みの解析信号）
let reference = scioxide_signal::hilbert(&x).map_err(|e| e.to_string())?;
let real_error = z
    .iter()
    .zip(&x)
    .map(|(zn, xn)| (zn.re - xn).abs())
    .fold(0.0_f64, f64::max);
let signal_error = z
    .iter()
    .zip(&reference)
    .map(|(p, q)| (*p - *q).norm())
    .fold(0.0_f64, f64::max);
let envelope_error = z
    .iter()
    .zip(&truth)
    .map(|(zn, e)| (zn.norm() - e).abs())
    .fold(0.0_f64, f64::max);

let series = |values: Vec<f64>| -> Vec<[f64; 2]> {
    values
        .into_iter()
        .enumerate()
        .map(|(k, v)| [k as f64, v])
        .collect()
};
emit_line_chart!(
    &vec![
        serde_json::json!({ "name": "信号 x", "points": series(x.clone()) }),
        serde_json::json!({ "name": "瞬時振幅 |z|", "points": series(z.iter().map(|v| v.norm()).collect()) }),
        serde_json::json!({
            "name": "真の包絡線",
            "points": series(truth.clone()),
            "style": { "lineType": "dashed" }
        }),
    ],
    options = &serde_json::json!({
        "xLabel": "標本の番号 n [-]",
        "yLabel": "振幅 [-]",
        "xMin": 0.0,
        "xMax": 64.0,
        "yMin": -1.6,
        "yMax": 1.8
    })
);
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let columns = serde_json::json!([
    { "key": "0", "label": "量" },
    { "key": "1", "label": "最大値 [-]", "type": "number", "format": sci2 }
]);
emit_table_with_columns!(
    columns,
    vec![
        ("max |Re z − x|", real_error),
        ("max |z − hilbert(x)|", signal_error),
        ("max ||z| − 真の包絡線|", envelope_error),
    ],
    metadata = serde_json::json!({ "id": "errors" })
);
```

既定の $N = 48$、$c = 10$ では、$\operatorname{Re} z$ と $x$ の差は $4.4\times10^{-16}$、`hilbert` との差は $5.6\times10^{-16}$、真の包絡線との差は $6.4\times10^{-15}$ で、どれも丸め誤差の大きさである。
$N = 45$ の奇数長でも同じ大きさにとどまる。
$c = 9.5$ では信号がウインドウの両端でつながらず、包絡線との差の最大が 0.99 になる。
図では、差がウインドウの両端の近くに集まる。
この差は重みの誤りではなく、周期を仮定した離散 Hilbert 変換の性質で、`hilbert` との差は丸め誤差の大きさのままである。

## まとめ

離散の解析信号は `rfft` の結果に DC と偶数長の Nyquist のビンで 1、正の周波数で 2 の重みを掛け、負の周波数を 0 にして `ifft` で戻せば得られる。
この重みで実部は入力に一致し、`scioxide_signal::hilbert` と丸め誤差の範囲で一致する。
$\lvert z_n\rvert$ を包絡線と読めるのは、包絡線の帯域が搬送波より低く、信号がウインドウの中で整数周期になるときである。
繰り返し計算するときや多次元の配列では、`scioxide-signal` の `AnalyticSignalNdPlan` を使う。
