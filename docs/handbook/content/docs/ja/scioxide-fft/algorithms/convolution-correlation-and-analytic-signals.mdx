線形時不変（LTI）系の応答、反響の合成、遅延の検出は、どれも Fourier 変換の畳み込み定理に基づく。
`scioxide-fft` は畳み込みと相関の関数を提供しない。
これらは `scioxide-signal` の `convolve`、`convolve_circular`、`correlate` が提供し、直接和と FFT のうち演算の少ない方を選ぶ。
このページでは同じ演算を `scioxide-fft` の `rfft`、`irfft`、`fft`、`ifft` と `next_fast_len` から組み立て、必要なゼロパディングの長さとラグの並びを導く。
各セルは直接和か `scioxide-signal` の結果と照合する。
同じく周期の仮定に基づく解析信号は[解析信号と離散 Hilbert 変換](../analytic-signal/)で扱う。

## 線形畳み込みと巡回畳み込み

入力 $x_n$（長さ $N_x$）とインパルス応答 $h_n$（長さ $N_h$）の線形畳み込みは、区間外を 0 とみなして

$$
y_n = \sum_{m} x_m\, h_{n-m}, \qquad n = 0, \dots, N_x + N_h - 2
$$

と定義する。
出力の長さは $N_y = N_x + N_h - 1$、直接和の演算量は $O(N_x N_h)$ である。

長さ $L$ の DFT $\mathcal{F}_L$ では、スペクトルの要素ごとの積が周期 $L$ の巡回畳み込みに対応する。

$$
\mathcal{F}_L^{-1}\left\{\mathcal{F}_L\{x\}\cdot\mathcal{F}_L\{h\}\right\}_n = \sum_{m=0}^{L-1} x_m\, h_{(n-m) \bmod L}
$$

ここで $x$ と $h$ は長さ $L$ の列とし、足りない分は 0 で埋める。
DFT は列を周期 $L$ で繰り返したものとして扱うので、添字が $L$ を超える出力は法 $L$ で先頭へ回り込んで足される。
これを巡回の折り返し（循環エイリアシング）と呼ぶ。

### ゼロパディングの長さ

折り返しが起きないのは、線形畳み込みの全出力が 1 周期に収まるとき、すなわち

$$
L \ge N_x + N_h - 1
$$

のときである。
`scioxide-fft` の変換は渡した配列の長さで変換し、ゼロパディングを暗黙には行わないので、詰めるのは呼び出し側である。
$L$ には `next_fast_len(N_x + N_h - 1)`（それ以上で最小の 2・3・5・7 の積）を選ぶと、混合基数の FFT だけで計算でき、素数長の Rader 法や Bluestein 法を避けられる。

実数の列では、`rfft` が $\lfloor L/2\rfloor + 1$ 個のビンを返す。
要素ごとの積を `HermitianSpectrum::from_vec(L, …)` で論理長 $L$ と組にして `irfft` に渡すと、長さ $L$ の実数列に戻る。
両方の変換で `Normalization::Inverse` を使えば、往復の係数 $1/L$ は逆変換の側で 1 回だけ掛かる。

FFT による畳み込みの演算量は、長さ $L$ の実数 FFT 3 回分の $O(L \log L)$ である。
FFT の丸め誤差の解析から、各出力成分の絶対誤差の上界は定数倍を除いて $\varepsilon \log_2 L\,\lVert x\rVert_2\lVert h\rVert_2$（$\varepsilon=2^{-52}$ は機械イプシロン）になる。
この上界は出力成分の大きさによらず全成分に共通なので、ピークの裾のように小さい出力値の相対誤差は、直接和より大きくなり得る。
`scioxide-signal` の `convolve` は直接和と FFT の演算回数を比べて方法を選ぶ。

次のセルはガウス形のパルス（64 標本、中心 24、幅 4 標本）と、直接波と遅延 $d$ の反響からなる応答 $h = \delta_0 + 0.55\,\delta_d$ をこの手順で畳み込む。
入力は反響の遅延 $d$ [標本] と、ゼロパディングの有無である。
ゼロパディングを外すと $L = 64$ のまま変換し、64 標本を超える出力が先頭へ回り込む。
出力は応答の図と、$O(N_x N_h)$ の直接和（独立な検算）との差の最大を示す表である。

```rust
//| id: fft-convolution-delay
//| ref: fft-convolution-delay
//| title: ゼロパディングの有無で FFT 畳み込みと直接和を比べる
//| run: reactive
//| crates: [scioxide-core, scioxide-fft]
//| inputs:
//|   echo_delay: {"type":"range","label":"反響遅延 d [標本]","description":"直接波から反響までの標本数を変える。","min":4,"max":40,"step":1,"value":18}
//|   linear_padding: {"type":"checkbox","label":"線形畳み込みの長さまで零を詰める","description":"外すと入力長 64 のまま変換し、巡回畳み込みになる。","value":true}
//| cases:
//|   - {"id":"circular-short","label":"ゼロパディングなし、d = 18","description":"反響の裾だけが 64 標本を超え、折り返しの差は小さい。","inputs":{"linear_padding":false}}
//|   - {"id":"circular-late","label":"ゼロパディングなし、d = 40","description":"反響の中心が 64 標本に来て、裾の半分が先頭に足される。","inputs":{"echo_delay":40,"linear_padding":false}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"summary","path":"/rows/0/0","equals":82}
//|       - {"artifact":"summary","path":"/rows/0/1","equals":84}
//|       - {"artifact":"summary","path":"/rows/0/3","range":{"max":1e-14}}
//|   - case: circular-short
//|     expect:
//|       - {"artifact":"summary","path":"/rows/0/1","equals":64}
//|       - {"artifact":"summary","path":"/rows/0/3","approx":{"value":1.5e-7,"rtol":0.1}}
//|   - case: circular-late
//|     expect:
//|       - {"artifact":"summary","path":"/rows/0/1","equals":64}
//|       - {"artifact":"summary","path":"/rows/0/3","approx":{"value":0.55,"rtol":0.01}}
use scioxide_core::Complex;
use scioxide_fft::{HermitianSpectrum, Normalization, irfft, next_fast_len, rfft};

// ガウス形のパルス x（f64 の exp は入力の生成だけに使う）と応答 h = δ0 + 0.55 δd
let delay = echo_delay.round() as usize;
let input: Vec<f64> = (0..64)
    .map(|i| {
        let z = (i as f64 - 24.0) / 4.0;
        (-0.5 * z * z).exp()
    })
    .collect();
let mut kernel = vec![0.0_f64; delay + 1];
kernel[0] = 1.0;
kernel[delay] = 0.55;
let needed = input.len() + kernel.len() - 1;

// 変換長 L: 線形畳み込みなら next_fast_len(Nx + Nh − 1)、そうでなければ入力長のまま
let length = if linear_padding {
    next_fast_len(needed).map_err(|e| e.to_string())?
} else {
    input.len()
};
let padded = |values: &[f64]| {
    let mut v = vec![0.0; length];
    v[..values.len()].copy_from_slice(values);
    v
};
let x_bins = rfft(&padded(&input), Normalization::Inverse).map_err(|e| e.to_string())?;
let h_bins = rfft(&padded(&kernel), Normalization::Inverse).map_err(|e| e.to_string())?;
// 要素ごとの積を論理長 L のパックしたスペクトルにして逆変換する（1/L は逆変換で掛かる）
let product: Vec<Complex<f64>> = x_bins
    .bins()
    .iter()
    .zip(h_bins.bins())
    .map(|(a, b)| *a * *b)
    .collect();
let spectrum = HermitianSpectrum::from_vec(length, product).map_err(|e| e.to_string())?;
let output = irfft(&spectrum, Normalization::Inverse).map_err(|e| e.to_string())?;

// 独立な検算: 線形畳み込みの直接和 O(Nx Nh)
let direct: Vec<f64> = (0..needed)
    .map(|n| {
        (0..kernel.len())
            .filter(|&m| m <= n && n - m < input.len())
            .map(|m| kernel[m] * input[n - m])
            .sum()
    })
    .collect();
let compared = needed.min(length);
let difference = (0..compared)
    .map(|n| (output[n] - direct[n]).abs())
    .fold(0.0_f64, f64::max);

let fft_curve: Vec<[f64; 2]> = output
    .iter()
    .take(needed)
    .enumerate()
    .map(|(n, &v)| [n as f64, v])
    .collect();
let direct_curve: Vec<[f64; 2]> = direct
    .iter()
    .enumerate()
    .map(|(n, &v)| [n as f64, v])
    .collect();
// 横軸は最長の出力（64 + 40 標本）に固定し、遅延を変えても目盛を保つ
emit_line_chart!(
    &vec![
        serde_json::json!({ "name": "FFT による畳み込み", "points": fft_curve }),
        serde_json::json!({
            "name": "直接和（線形畳み込み）",
            "points": direct_curve,
            "style": { "lineType": "dashed" }
        }),
    ],
    options = &serde_json::json!({
        "xLabel": "時間 [標本]",
        "yLabel": "応答の振幅 [-]",
        "xMin": 0.0,
        "xMax": 103.0,
        "annotations": [
            { "kind": "line", "axis": "x", "value": delay as f64 + 24.0, "label": "反響の中心" }
        ]
    })
);
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let columns = serde_json::json!([
    { "key": "0", "label": "線形畳み込みの長さ Nx+Nh−1", "type": "integer" },
    { "key": "1", "label": "変換長 L", "type": "integer" },
    { "key": "2", "label": "比べた標本数", "type": "integer" },
    { "key": "3", "label": "直接和との差の最大 [-]", "type": "number", "format": sci2 }
]);
emit_table_with_columns!(
    columns,
    vec![(needed, length, compared, difference)],
    metadata = serde_json::json!({ "id": "summary" })
);
```

既定の遅延 18 標本では、必要な長さ 82 に対して `next_fast_len` が $L = 84 = 2^2\cdot 3\cdot 7$ を選び、直接和との差の最大は $4.4\times10^{-16}$ である。
この入力では $\lVert x\rVert_2\approx2.66$、$\lVert h\rVert_2\approx1.14$ で、上界の目安 $\varepsilon\log_2L\,\lVert x\rVert_2\lVert h\rVert_2\approx4.3\times10^{-15}$ より 1 桁小さい。
ゼロパディングを外すと $L = 64$ になる。
遅延 18 では反響のパルス（中心 42 標本）の裾がわずかに 64 標本を超えるだけで、差の最大は $1.5\times10^{-7}$ にとどまる。
遅延 40 では反響の中心が 64 標本に来て裾の半分が先頭に足され、差の最大は 0.55 になる。
折り返しの大きさは 64 標本を超える出力の大きさで決まり、丸め誤差とは桁が違う。

## 相互相関とラグの並び

長さ $N$ の列 $a$ と長さ $M$ の列 $b$ の相互相関を、`scioxide_signal::correlate` と同じ規約で

$$
r[\ell] = \sum_{k} a[k]\, \overline{b[k - \ell]}, \qquad \ell = -(M-1), \dots, N-1
$$

と定義する。
和は $0 \le k < N$ かつ $0 \le k - \ell < M$ の範囲を取り、区間外は 0 とみなす。
実数の列では共役は効かない。
`correlate` はこの $N + M - 1$ 個の値をラグの昇順に並べて返すので、配列の添字 $j$ とラグの関係は $\ell = j - (M-1)$、ラグ 0 は添字 $M-1$ である。
$r[\ell]$ が $\ell = d > 0$ で最大なら、$a$ の中で $b$ に似た波形が $d$ 標本だけ後ろにある。

この定義は $r = a * \tilde b$（$\tilde b[m] = \overline{b[-m]}$ は $b$ の時間反転の共役）と書ける。
時間反転と共役は Fourier 領域での複素共役に当たるので、長さ $L$ の DFT では

$$
\mathcal{F}_L\{r\}_k = A_k\, \overline{B_k}
$$

になる。
自己相関 $a = b$ では右辺がパワースペクトル $\lvert A_k\rvert^2$ になり、これが Wiener–Khinchin の定理の離散版である。

折り返しを防ぐ条件は線形畳み込みと同じ $L \ge N + M - 1$ である。
逆変換した長さ $L$ の列 $c$ では、ラグ $\ell \ge 0$ が添字 $\ell$ に、負のラグ $\ell$ が末尾の添字 $L + \ell$ に入る。
`correlate` の並びを得るには、ラグ $\ell = -(M-1), \dots, N-1$ ごとに $c[\ell \bmod L]$ を取り出す。
`fftshift` は長さ $L$ の列の前半と後半を入れ替えるだけなので、先頭はラグ $-\lfloor L/2\rfloor$ になり、ゼロパディングで増やした分の零が負のラグの前か正のラグの後ろに残る。
ラグを定義から取り出せば、$N$、$M$、$L$ によらず `correlate` と同じ並びになる。
ラグと時間差の換算や、相関係数への正規化は signal 章の [相関のラグの並び](oxref:signal-correlation-lags)にある。

次のセルは長さ $M = 16$ の複素の線形チャープ $b[m] = e^{i\pi m^2/(2M)}$ を、長さ $N = 64$ の受信列 $a$ の位置 $d$ に置き、さらに振幅 0.5 の反響を位置 $d + 20$ に足す。
レーダーの整合フィルタと同じ配置で、相関の最大はラグ $d$ に現れる。
主計算は `fft` によるスペクトルの積 $A_k\overline{B_k}$ で、`scioxide_signal::correlate` と定義の直接和を独立な参照計算として使う。
チェックボックスを外すと共役を取らずに $A_k B_k$ を逆変換し、相関ではなく畳み込みを計算したときの食い違いを示す。

```rust
//| id: fft-correlation-lag-order
//| ref: fft-correlation-lag-order
//| title: FFT による相互相関を signal の correlate と照合する
//| run: reactive
//| crates: [scioxide-core, scioxide-fft, scioxide-signal]
//| inputs:
//|   delay: {"type":"integer","label":"チャープの位置 d [標本]","description":"受信列 a の中で長さ 16 のチャープが始まる位置。","min":0,"max":40,"value":12}
//|   conjugate: {"type":"checkbox","label":"B の共役を取る","description":"外すと A·B を逆変換し、相関ではなく畳み込みになる。","value":true}
//| cases:
//|   - {"id":"zero-lag","label":"d = 0","description":"最大がラグ 0、すなわち添字 M − 1 = 15 に来る。","inputs":{"delay":0}}
//|   - {"id":"no-conjugate","label":"共役なし","description":"A·B は相関と一致せず、ラグ d の鋭い最大が消える。","inputs":{"conjugate":false}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"lags","path":"/rows/0/0","equals":80}
//|       - {"artifact":"lags","path":"/rows/0/1","equals":12}
//|       - {"artifact":"lags","path":"/rows/0/2","equals":12}
//|       - {"artifact":"lags","path":"/rows/0/3","range":{"max":1e-13}}
//|       - {"artifact":"lags","path":"/rows/0/4","range":{"max":1e-13}}
//|   - case: zero-lag
//|     expect:
//|       - {"artifact":"lags","path":"/rows/0/1","equals":0}
//|       - {"artifact":"lags","path":"/rows/0/2","equals":0}
//|       - {"artifact":"lags","path":"/rows/0/3","range":{"max":1e-13}}
//|   - case: no-conjugate
//|     expect:
//|       - {"artifact":"lags","path":"/rows/0/2","equals":12}
//|       - {"artifact":"lags","path":"/rows/0/3","range":{"min":1}}
use scioxide_core::Complex;
use scioxide_fft::{Normalization, fft, ifft, next_fast_len};

// 線形チャープ b[m] = exp(iπ m²/(2M))（f64 の sin/cos は入力の生成だけに使う）
let (n, m) = (64_usize, 16_usize);
let delay = delay as usize;
let b: Vec<Complex<f64>> = (0..m)
    .map(|k| Complex::from_polar(1.0, std::f64::consts::PI * (k * k) as f64 / (2 * m) as f64))
    .collect();
// 受信列 a: 位置 d のチャープと、位置 d + 20 の振幅 0.5 の反響（区間外は切り捨てる）
let mut a = vec![Complex::new(0.0, 0.0); n];
for (shift, gain) in [(delay, 1.0), (delay + 20, 0.5)] {
    for (k, &value) in b.iter().enumerate() {
        if shift + k < n {
            a[shift + k] += value * gain;
        }
    }
}

// L ≥ N + M − 1 まで零を詰め、A_k conj(B_k) を逆変換する
let length = next_fast_len(n + m - 1).map_err(|e| e.to_string())?;
let padded = |values: &[Complex<f64>]| {
    let mut v = vec![Complex::new(0.0, 0.0); length];
    v[..values.len()].copy_from_slice(values);
    v
};
let fa = fft(&padded(&a), Normalization::Inverse).map_err(|e| e.to_string())?;
let fb = fft(&padded(&b), Normalization::Inverse).map_err(|e| e.to_string())?;
let product: Vec<Complex<f64>> = fa
    .iter()
    .zip(&fb)
    .map(|(&x, &y)| if conjugate { x * y.conj() } else { x * y })
    .collect();
let circular = ifft(&product, Normalization::Inverse).map_err(|e| e.to_string())?;

// 参照計算: signal の correlate（ラグ −(M−1), …, N−1 の昇順）
let signal = scioxide_signal::correlate(&a, &b).map_err(|e| e.to_string())?;
let lags: Vec<i64> = (-(m as i64 - 1)..n as i64).collect();
// ラグ ℓ は巡回列の添字 ℓ mod L に入る
let from_fft: Vec<Complex<f64>> = lags
    .iter()
    .map(|&lag| circular[lag.rem_euclid(length as i64) as usize])
    .collect();
// 独立な検算: 定義の直接和 r[ℓ] = Σ_k a[k] conj(b[k − ℓ])
let direct: Vec<Complex<f64>> = lags
    .iter()
    .map(|&lag| {
        (0..n as i64)
            .filter(|&k| (0..m as i64).contains(&(k - lag)))
            .map(|k| a[k as usize] * b[(k - lag) as usize].conj())
            .sum()
    })
    .collect();
let max_diff = |x: &[Complex<f64>], y: &[Complex<f64>]| {
    x.iter()
        .zip(y)
        .map(|(p, q)| (*p - *q).norm())
        .fold(0.0_f64, f64::max)
};
let argmax = |values: &[Complex<f64>]| {
    let best = (0..values.len())
        .max_by(|&i, &j| values[i].norm().total_cmp(&values[j].norm()))
        .unwrap_or(0);
    lags[best]
};

let curve = |values: &[Complex<f64>]| -> Vec<[f64; 2]> {
    lags.iter()
        .zip(values)
        .map(|(&lag, value)| [lag as f64, value.norm()])
        .collect()
};
emit_line_chart!(
    &vec![
        serde_json::json!({ "name": "FFT のスペクトル積", "points": curve(&from_fft) }),
        serde_json::json!({
            "name": "scioxide_signal::correlate",
            "points": curve(&signal),
            "style": { "lineType": "dashed" }
        }),
    ],
    options = &serde_json::json!({
        "xLabel": "ラグ ℓ [標本]",
        "yLabel": "相関の絶対値 |r[ℓ]| [-]",
        "xMin": -15.0,
        "xMax": 63.0,
        "yMin": 0.0,
        "yMax": 17.0
    })
);
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let columns = serde_json::json!([
    { "key": "0", "label": "変換長 L", "type": "integer" },
    { "key": "1", "label": "最大のラグ（FFT） [標本]", "type": "integer" },
    { "key": "2", "label": "最大のラグ（signal） [標本]", "type": "integer" },
    { "key": "3", "label": "signal との差の最大 [-]", "type": "number", "format": sci2 },
    { "key": "4", "label": "直接和との差の最大 [-]", "type": "number", "format": sci2 }
]);
let row = (
    length,
    argmax(&from_fft),
    argmax(&signal),
    max_diff(&from_fft, &signal),
    max_diff(&from_fft, &direct),
);
emit_table_with_columns!(
    columns,
    vec![row],
    metadata = serde_json::json!({ "id": "lags" })
);
```

既定の $d = 12$ では、$N + M - 1 = 79$ に対して $L = 80$ になり、FFT とスペクトル積の相関は `correlate` と $2.2\times10^{-15}$、直接和と $1.9\times10^{-15}$ の差で一致する。
最大はラグ 12 に、反響による 2 番目の山はラグ 32 に現れる。
$d = 0$ では最大がラグ 0、すなわち `correlate` の結果の添字 15 に来る。
共役を外すと、FFT の側は $a$ と $b$ の畳み込みを計算するので `correlate` との差が 15 になり、最大の位置もラグ 38 に移る。
複素の列では共役の有無が結果を変えるので、実数の列で確かめた規約を複素の列に当てはめるときは、共役の位置まで定義と照合する。

## まとめ

FFT で線形畳み込みを計算するには、両方の列を $L \ge N_x + N_h - 1$ まで零で伸ばしてから変換し、$L$ は `next_fast_len` で選ぶ。
ゼロパディングが足りないと、出力の尾が先頭へ回り込んだ巡回畳み込みになり、その差は丸め誤差ではなく折り返した出力の大きさになる。
相互相関は $A_k\overline{B_k}$ の逆変換から、ラグ $\ell = -(M-1), \dots, N-1$ ごとに添字 $\ell \bmod L$ を取り出すと、`scioxide_signal::correlate` と同じ並びと共役の規約になる。
同じ演算を繰り返すときや直接和との自動選択が必要なときは、`scioxide-signal` の関数と Plan を使う。
