離散 Fourier 変換（DFT）は、長さ $N$ の数列を $N$ 個の複素正弦波の重ね合わせとして表す。
このページでは `scioxide-fft` の DFT の定義と符号の規約を確かめ、`Normalization` が倍率 $1/N$ をどちらの方向に置くかと、それに応じた Parseval の等式を導く。
最後に、ビンの値を元の正弦波の振幅に直す係数を示す。
連続信号の標本化、折り返し、周波数軸は [標本化・折り返し・周波数軸](../sampling-and-frequency-axis/) で扱う。

## DFT の定義と逆変換

長さ $N$ の複素数列 $x_0,\dots,x_{N-1}$ に対し、`scioxide-fft` の順変換と逆変換は、正規化の前には次の和である。

$$
X_k = \sum_{j=0}^{N-1} x_j\, e^{-2\pi i jk/N}, \qquad
x_j = \sum_{k=0}^{N-1} X_k\, e^{+2\pi i jk/N}
\qquad (j, k = 0,\dots,N-1)
$$

順変換（`FftDirection::Forward`）の指数の符号は $-$、逆変換（`FftDirection::Inverse`）は $+$ である。
$\omega = e^{-2\pi i/N}$ とおき、行列 $F_{kj} = \omega^{jk}$ を作ると、順変換は $X = Fx$、無尺度の逆変換は $x \mapsto F^{\mathsf H}x$ と書ける。
列どうしの内積は $\sum_k \omega^{-jk}\omega^{j'k} = N\delta_{jj'}$ なので $F^{\mathsf H}F = NI$ が成り立つ。
したがって、無尺度の順変換と逆変換を続けて適用すると数列は $N$ 倍になる。
この $N$ をどこで割るかを決めるのが次節の正規化である。

$X_k$ は $k$ について周期 $N$ を持ち、ビン $k \ge N/2$ は負の周波数 $(k-N)/N$ [周期/標本] を表す。
実数列のスペクトルは $X_{N-k} = \overline{X_k}$（Hermite 対称）を満たすので、`rfft` はビン $0,\dots,\lfloor N/2\rfloor$ だけを返す。
ビンと物理的な周波数の対応は [周波数軸とビンの並び](oxref:fft-frequency-axis)、パックしたスペクトルは [実数 FFT と Hermite 対称性](../real-and-hermitian-transforms/) で扱う。

## 正規化と Parseval の等式

`Normalization` は、往復で生じる倍率 $N$ を順変換と逆変換のどちらで割るかを選ぶ。
順変換の倍率を $s$ とすると、正規化した順変換は $X = sFx$ で、$F^{\mathsf H}F = NI$ から

$$
\sum_{k=0}^{N-1} \lvert X_k\rvert^2 = s^2\, x^{\mathsf H}F^{\mathsf H}F\,x = s^2 N \sum_{j=0}^{N-1} \lvert x_j\rvert^2
$$

が成り立つ（Parseval の等式）。
4 つの列挙子の倍率とエネルギーの比は次のとおりである。

| `Normalization` | 順変換の倍率 $s$ | 逆変換の倍率 | 往復の倍率 | $\sum_k\lvert X_k\rvert^2/\sum_j\lvert x_j\rvert^2$ |
|---|---|---|---|---|
| `Inverse` | $1$ | $1/N$ | $1$ | $N$ |
| `Forward` | $1/N$ | $1$ | $1$ | $1/N$ |
| `Orthonormal` | $1/\sqrt N$ | $1/\sqrt N$ | $1$ | $1$ |
| `Unscaled` | $1$ | $1$ | $N$ | $N$ |

往復で元に戻すには、両方向に同じ値を渡す（`Unscaled` を除く）。
`Orthonormal` では $F/\sqrt N$ がユニタリなので、変換は 2 ノルムを保つ。
多次元変換では選んだ軸の長さの積を $N$ とする。
`rfft` のようなパックした実数の配置でも倍率は変わらない。
ただしパックしたビンで和をとるときは、DC と偶数長の Nyquist 以外のビンを 2 回数える。
DCT・DST、チャープ Z 変換、非一様 Fourier 変換での $N$ の数え方は [正規化](oxref:fft-normalization) にまとめてある。

次のセルは長さ $N$ の決定論的な複素数列を 4 通りの正規化で変換し、上の表の倍率と Parseval の比を測る。
順変換の倍率は $X_0/\sum_j x_j$、エネルギーの比は $\sum_k\lvert X_k\rvert^2/\sum_j\lvert x_j\rvert^2$、往復の倍率は $\lVert\mathrm{ifft}(\mathrm{fft}(x))\rVert_2/\lVert x\rVert_2$ である。
表の「（表）」「（式）」の列は上の表から書き写した値で、測った値と並べて比べる。
入力の生成には f64 の `cos`・`sin` を使う。

```rust
//| id: fft-normalization-parseval
//| ref: fft-normalization-parseval
//| title: 4 通りの正規化の倍率と Parseval の比を測る
//| run: reactive
//| crates: [scioxide-core, scioxide-fft]
//| inputs:
//|   length: {"type":"range","label":"変換長 N","description":"倍率 1/N と 1/√N の違いが N とともに広がる。","min":1,"max":256,"step":1,"value":8}
//| cases:
//|   - {"id":"single-sample","label":"N = 1","description":"どの正規化でも倍率とエネルギーの比が 1 になる。","inputs":{"length":1}}
//|   - {"id":"prime-length","label":"N = 97","description":"素数長でも同じ倍率になり、往復の誤差は丸めの大きさにとどまる。","inputs":{"length":97}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"normalization","path":"/rows/0/1","approx":{"value":1,"rtol":1e-13}}
//|       - {"artifact":"normalization","path":"/rows/1/1","approx":{"value":0.125,"rtol":1e-13}}
//|       - {"artifact":"normalization","path":"/rows/2/3","approx":{"value":1,"rtol":1e-13}}
//|       - {"artifact":"normalization","path":"/rows/3/3","approx":{"value":8,"rtol":1e-13}}
//|       - {"artifact":"normalization","path":"/rows/3/5","approx":{"value":8,"rtol":1e-13}}
//|       - {"artifact":"normalization","path":"/rows/2/6","range":{"max":1e-14}}
//|   - case: single-sample
//|     expect:
//|       - {"artifact":"normalization","path":"/rows/3/5","approx":{"value":1,"rtol":1e-15}}
//|   - case: prime-length
//|     expect:
//|       - {"artifact":"normalization","path":"/rows/1/3","approx":{"value":0.010309278350515464,"rtol":1e-12}}
//|       - {"artifact":"normalization","path":"/rows/3/5","approx":{"value":97,"rtol":1e-12}}
//|       - {"artifact":"normalization","path":"/rows/0/6","range":{"max":1e-14}}
use scioxide_core::Complex;
use scioxide_fft::{Normalization, fft, ifft};

let n = length.round() as usize;
// 決定論的な入力 x_j = 1 + cos(0.7 j) + i sin(1.3 j²/N)（生成は f64 の関数）
let x: Vec<Complex<f64>> = (0..n)
    .map(|j| {
        let t = j as f64;
        Complex::new(1.0 + (0.7 * t).cos(), (1.3 * t * t / n as f64).sin())
    })
    .collect();
let sum = x.iter().fold(Complex::new(0.0, 0.0), |acc, v| acc + *v);
let energy: f64 = x.iter().map(|v| v.norm_sqr()).sum();
let nf = n as f64;
let variants = [
    ("Inverse", Normalization::Inverse, 1.0, nf, 1.0),
    ("Forward", Normalization::Forward, 1.0 / nf, 1.0 / nf, 1.0),
    (
        "Orthonormal",
        Normalization::Orthonormal,
        1.0 / nf.sqrt(),
        1.0,
        1.0,
    ),
    ("Unscaled", Normalization::Unscaled, 1.0, nf, nf),
];
let mut rows = Vec::new();
for (name, norm, forward_scale, energy_ratio, round_trip) in variants {
    let spectrum = fft(&x, norm).map_err(|e| e.to_string())?;
    let back = ifft(&spectrum, norm).map_err(|e| e.to_string())?;
    let spectral_energy: f64 = spectrum.iter().map(|v| v.norm_sqr()).sum();
    // 往復の誤差は、表の倍率で割り戻した列と元の列の相対 L2 差
    let error: f64 = back
        .iter()
        .zip(&x)
        .map(|(b, a)| (*b / round_trip - *a).norm_sqr())
        .sum();
    let back_energy: f64 = back.iter().map(|v| v.norm_sqr()).sum();
    rows.push((
        name,
        (spectrum[0] / sum).re,
        forward_scale,
        spectral_energy / energy,
        energy_ratio,
        (back_energy / energy).sqrt(),
        (error / energy).sqrt(),
    ));
}
let digits = serde_json::json!({ "significantDigits": 6 });
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let columns = serde_json::json!([
    { "key": "0", "label": "Normalization" },
    { "key": "1", "label": "X₀/Σx [-]", "type": "number", "format": digits },
    { "key": "2", "label": "順変換の倍率（表） [-]", "type": "number", "format": digits },
    { "key": "3", "label": "Σ|X|²/Σ|x|² [-]", "type": "number", "format": digits },
    { "key": "4", "label": "Parseval の比（式） [-]", "type": "number", "format": digits },
    { "key": "5", "label": "往復の倍率 [-]", "type": "number", "format": digits },
    { "key": "6", "label": "往復の相対誤差 [-]", "type": "number", "format": sci2 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "normalization" })
);
```

既定の $N = 8$ では、`Forward` の $X_0/\sum x$ が $0.125$、`Orthonormal` が $1/\sqrt 8 \approx 0.354$ になり、エネルギーの比は `Orthonormal` だけが 1 になる。
`Unscaled` の往復の倍率は $N = 8$ で、他の 3 つは 1 である。
往復の相対誤差は $2\times10^{-16}$ 程度（$N = 97$ では $6$〜$8\times10^{-16}$）で、倍率で割り戻した列が元の列と丸め誤差の範囲で一致する。
$N = 97$ のような素数長でも倍率は変わらない（素数長のアルゴリズムは [FFT のアルゴリズムと任意長変換](../planner-and-arbitrary-lengths/) で扱う）。

## 物理振幅への換算

DC・Nyquist 以外のビン中心に一致する振幅 $A$ の実数の正弦波は、正と負の周波数に $AN/2$ ずつ分かれて現れる（`Unscaled` または `Inverse` の順変換）。
片側の振幅に戻すには、DC と偶数長の Nyquist 以外のビンの絶対値を $2/N$ 倍し、DC と Nyquist は $1/N$ 倍する。

$$
A_k = \begin{cases}
\lvert X_0\rvert/N & (k = 0) \\
2\lvert X_k\rvert/N & (0 < k < N/2) \\
\lvert X_{N/2}\rvert/N & (k = N/2,\ N \text{ が偶数})
\end{cases}
$$

`Forward` で変換したときは $N$ で割る操作が済んでいるので、係数は $2$ と $1$ になる。
`Orthonormal` では $2/\sqrt N$ と $1/\sqrt N$ になる。
この換算はビン中心に一致する正弦波に限って振幅を正しく返し、ビンの間の周波数では漏れのために小さく出る。
振幅を読む実験は [二つの正弦波の周波数と振幅を rfft で読む](oxref:fft-first-spectrum) と [折り返しと漏れの観測](oxref:fft-aliasing-experiment) にある。

## まとめ

`scioxide-fft` の順変換は指数の符号 $-$、逆変換は $+$ で、無尺度の往復は数列を $N$ 倍する。
`Normalization` はこの $N$ を逆変換（`Inverse`）、順変換（`Forward`）、両方向の $\sqrt N$（`Orthonormal`）に配るか、配らない（`Unscaled`）かを選ぶ。
順変換の倍率 $s$ から Parseval の比 $s^2N$ が決まり、二乗和を保つのは `Orthonormal` だけである。
片側の振幅は `Inverse` と `Unscaled` ではビンの絶対値の $2/N$ 倍（DC と Nyquist は $1/N$ 倍）で読み、使った `Normalization` を結果と一緒に記録する。
