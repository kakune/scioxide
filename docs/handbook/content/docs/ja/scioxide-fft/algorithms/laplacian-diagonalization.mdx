[DCT・DST と境界条件](oxref:fft-dct-boundary-symmetry)の表は、8 つの型の核を、両端で偶・奇に延長した列として分類した。
このページは、その延長が 2 階差分の境界条件そのものであり、各型の核が対応する差分行列の固有ベクトルになることを導く。
固有値が分かれば、差分の Poisson 方程式は変換、対角成分での割り算、逆変換の $O(n\log n)$ で解ける。
最初のセルで 8 つの型すべての閉じ方を数値で確かめ、2 番目のセルで格子の間隔 $h$ を入れた固有値を連続の Laplace 作用素の固有値と比べる。

## 境界条件で閉じた 2 階差分

長さ $n$ の列 $u_0,\ldots,u_{n-1}$ に 2 階差分

$$
(\mathbf D\mathbf u)_j=u_{j-1}-2u_j+u_{j+1},\qquad j=0,\ldots,n-1
$$

を作用させるには、列の外側の値 $u_{-1}$ と $u_n$ を決める必要がある。
対称の中心と偶奇を選ぶと、外側の値は次のように内側の値で決まる。

| 左端の対称 | $u_{-1}$ | 右端の対称 | $u_n$ |
|---|---|---|---|
| 格子点 0 で偶 | $u_1$ | 格子点 $n-1$ で偶 | $u_{n-2}$ |
| 半格子点 $-\tfrac12$ で偶 | $u_0$ | 半格子点 $n-\tfrac12$ で偶 | $u_{n-1}$ |
| 格子点 $-1$ で奇 | $0$ | 格子点 $n$ で奇 | $0$ |
| 半格子点 $-\tfrac12$ で奇 | $-u_0$ | 半格子点 $n-\tfrac12$ で奇 | $-u_{n-1}$ |

格子点で奇に延長すると中心の値が 0 になり、これは格子点に置いた Dirichlet 条件である。
半格子点で偶に延長すると $u_{-1}=u_0$ となり、セルの境界をはさむ差分 $u_0-u_{-1}$ が 0 になる。
これはセル中心の格子で流束 0 を課す Neumann 条件である。

$c_j=\cos(\omega j+\varphi)$ の形の列には、加法定理 $\cos(a-b)+\cos(a+b)=2\cos a\cos b$ から

$$
(\mathbf D\mathbf c)_j=(2\cos\omega-2)\,c_j=-4\sin^2\frac{\omega}{2}\,c_j
$$

が内部の $j$ で成り立つ。
端でも成り立つのは、外側の値の決め方が $c_j$ を延長した値 $c_{-1}$、$c_n$ と一致するときである。
各型の核は $j$ について $\cos(\omega_k j+\varphi)$ の形をしており、その延長の対称は[表](oxref:fft-dct-boundary-symmetry)のとおりなので、核は表の境界条件で閉じた $\mathbf D$ の固有ベクトルになる（G. Strang, "The discrete cosine transform", *SIAM Review* 41(1), 1999, 135–147）。
固有値は $\lambda_k=-4\sin^2(\omega_k/2)$ で、核の $j$ に関する角周波数 $\omega_k$ は型ごとに次の値である。

| 型 | $\omega_k$ | 型 | $\omega_k$ |
|---|---|---|---|
| DCT-I | $\pi k/(n-1)$ | DST-I | $\pi(k+1)/(n+1)$ |
| DCT-II | $\pi k/n$ | DST-II | $\pi(k+1)/n$ |
| DCT-III | $\pi(k+\tfrac12)/n$ | DST-III | $\pi(k+\tfrac12)/n$ |
| DCT-IV | $\pi(k+\tfrac12)/n$ | DST-IV | $\pi(k+\tfrac12)/n$ |

格子点で偶に閉じる端（DCT-I の両端、DCT-III の左端、DST-III の右端）では $\mathbf D$ の端の行に係数 2 が現れ（左端なら $(-2,\,2,\,0,\ldots)$）、$\mathbf D$ は対称行列でない。
このとき固有ベクトルは通常の内積では直交せず、端点の重みを $\tfrac12$ にした内積で直交する。
`Orthonormal` が端点に $\sqrt2$ の重みを付けるのはこのためである。

### 8 つの型の閉じ方の確認

次のセルは型ごとに核の列 $c_k[j]$（$j=0,\ldots,n-1$）を `scioxide-fft` で作り、上の表の外側の値で閉じた $\mathbf D$ を掛けて固有ベクトルかどうかを測る。
型 $T$ の核を $j$ の関数として取り出すには、$T$ の行列の転置を単位ベクトル $\mathbf e_k$ に作用させればよい。
DCT・DST の転置は端点の重みを除いて双対の型（I と IV は自分自身、II と III は互い）であり、逆方向の Plan は順変換の型 $T$ を受け取って双対を計算する。
そこで、型 $T$ の逆方向の `Unscaled` の Plan に $\mathbf e_k$ を渡した出力を $c_k$ とする（端点の重みは $c_k$ の定数倍にしかならない）。
差分 $\mathbf D c_k$ は外側の値の表から直接計算する独立な検算で、表には Rayleigh 商 $\langle\mathbf Dc_k,c_k\rangle/\langle c_k,c_k\rangle$ と固有値の式 $\lambda_k$ の差の最大と、残差 $\max_j\lvert(\mathbf Dc_k)_j-\lambda_kc_{k,j}\rvert/\max_j\lvert c_{k,j}\rvert$ の $k$ についての最大を示す。
外側の値を「両端とも 0」に切り替えると、すべての型を格子点の Dirichlet 条件で閉じ、表の閉じ方を使わないと固有ベクトルにならないことが分かる。

```rust
//| id: fft-dct-dst-difference-eigenvectors
//| ref: fft-dct-dst-difference-eigenvectors
//| title: 8 つの型の核が境界条件で閉じた 2 階差分の固有ベクトルになるかを測る
//| run: reactive
//| crates: [scioxide-core, scioxide-fft]
//| inputs:
//|   length: {"type":"range","label":"長さ n","description":"差分を作用させる列の長さ。DCT-I に合わせて 2 以上。","min":2,"max":24,"step":1,"value":8}
//|   closure: {"type":"select","label":"外側の値","description":"差分を閉じる u₋₁ と uₙ の決め方。","options":["表の閉じ方","両端とも 0"],"value":"表の閉じ方"}
//| cases:
//|   - {"id":"odd","label":"n = 7","description":"奇数長でも 8 つの型の残差は丸め誤差の大きさにとどまる。","inputs":{"length":7}}
//|   - {"id":"zero-ghost","label":"両端とも 0","description":"DST-I だけが固有ベクトルのまま残り、ほかの型の残差が O(1) になる。","inputs":{"closure":"両端とも 0"}}
//|   - {"id":"shortest","label":"n = 2","description":"DCT-I が受け付ける最小の長さでも閉じ方は成り立つ。","inputs":{"length":2}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"closures","path":"/rows/0/4","range":{"max":1e-14}}
//|       - {"artifact":"closures","path":"/rows/2/4","range":{"max":1e-14}}
//|       - {"artifact":"closures","path":"/rows/3/3","range":{"max":1e-14}}
//|       - {"artifact":"closures","path":"/rows/6/4","range":{"max":1e-14}}
//|       - {"artifact":"closures","path":"/rows/7/4","range":{"max":1e-14}}
//|   - case: odd
//|     expect:
//|       - {"artifact":"closures","path":"/rows/2/4","range":{"max":1e-14}}
//|       - {"artifact":"closures","path":"/rows/6/4","range":{"max":1e-14}}
//|   - case: zero-ghost
//|     expect:
//|       - {"artifact":"closures","path":"/rows/4/4","range":{"max":1e-14}}
//|       - {"artifact":"closures","path":"/rows/1/4","range":{"min":0.5}}
//|       - {"artifact":"closures","path":"/rows/6/4","range":{"min":0.5}}
//|   - case: shortest
//|     expect:
//|       - {"artifact":"closures","path":"/rows/0/4","range":{"max":1e-14}}
//|       - {"artifact":"closures","path":"/rows/6/4","range":{"max":1e-14}}
use scioxide_core::ExecutionContext;
use scioxide_fft::RealTransformKind::{self, Dct, Dst};
use scioxide_fft::{DctType, DstType, FftDirection, Normalization};
use scioxide_fft::{RealTransformPlan, RealTransformPlanSpec};

// 外側の値の決め方。Node は格子点で偶、Half は半格子点で偶、
// HalfOdd は半格子点で奇、Zero は格子点で奇に延長する。
#[derive(Clone, Copy)]
enum Ghost {
    Node,
    Half,
    HalfOdd,
    Zero,
}
let n = length.round() as usize;
let nf = n as f64;
let use_table = closure == "表の閉じ方";
let pi = std::f64::consts::PI;
let kinds: [RealTransformKind; 8] = [
    Dct(DctType::I),
    Dct(DctType::II),
    Dct(DctType::III),
    Dct(DctType::IV),
    Dst(DstType::I),
    Dst(DstType::II),
    Dst(DstType::III),
    Dst(DstType::IV),
];
// 型ごとの (名前, 左端, 右端, a, b)。核の角周波数は ω_k = π(k + a)/(n + b)
let model = |kind: RealTransformKind| match kind {
    Dct(DctType::I) => ("DCT-I", Ghost::Node, Ghost::Node, 0.0, -1.0),
    Dct(DctType::II) => ("DCT-II", Ghost::Half, Ghost::Half, 0.0, 0.0),
    Dct(DctType::III) => ("DCT-III", Ghost::Node, Ghost::Zero, 0.5, 0.0),
    Dct(DctType::IV) => ("DCT-IV", Ghost::Half, Ghost::HalfOdd, 0.5, 0.0),
    Dst(DstType::I) => ("DST-I", Ghost::Zero, Ghost::Zero, 1.0, 1.0),
    Dst(DstType::II) => ("DST-II", Ghost::HalfOdd, Ghost::HalfOdd, 1.0, 0.0),
    Dst(DstType::III) => ("DST-III", Ghost::Zero, Ghost::Node, 0.5, 0.0),
    Dst(DstType::IV) => ("DST-IV", Ghost::HalfOdd, Ghost::Half, 0.5, 0.0),
};
// 外側の値 u₋₁（left）と uₙ（right）。Node の内側の点は端から 1 つ内側。
let outside = |ghost: Ghost, u: &[f64], left: bool| {
    let (edge, inner) = if left {
        (u[0], u[1])
    } else {
        (u[n - 1], u[n - 2])
    };
    match ghost {
        Ghost::Node => inner,
        Ghost::Half => edge,
        Ghost::HalfOdd => -edge,
        Ghost::Zero => 0.0,
    }
};
let label = |ghost: Ghost, left: bool| match (ghost, left) {
    (Ghost::Node, true) => "u₋₁ = u₁",
    (Ghost::Half, true) => "u₋₁ = u₀",
    (Ghost::HalfOdd, true) => "u₋₁ = −u₀",
    (Ghost::Zero, true) => "u₋₁ = 0",
    (Ghost::Node, false) => "uₙ = uₙ₋₂",
    (Ghost::Half, false) => "uₙ = uₙ₋₁",
    (Ghost::HalfOdd, false) => "uₙ = −uₙ₋₁",
    (Ghost::Zero, false) => "uₙ = 0",
};
let mut rows = Vec::new();
for kind in kinds {
    let (name, table_left, table_right, a, b) = model(kind);
    let (left, right) = if use_table {
        (table_left, table_right)
    } else {
        (Ghost::Zero, Ghost::Zero)
    };
    // 逆方向の Plan は双対（転置）を計算するので、e_k を渡すと核の列 c_k[j] が出る
    let spec =
        RealTransformPlanSpec::new(n, kind, FftDirection::Inverse, Normalization::Unscaled);
    let plan = RealTransformPlan::<f64>::new(spec).map_err(|e| e.to_string())?;
    let mut workspace = plan.workspace(()).map_err(|e| e.to_string())?;
    let (mut eigen_gap, mut residual) = (0.0_f64, 0.0_f64);
    for k in 0..n {
        let mut unit = vec![0.0; n];
        unit[k] = 1.0;
        let mut c = vec![0.0; n];
        plan.execute_into(
            &unit,
            &mut c,
            &mut workspace,
            ExecutionContext::sequential(),
        )
        .map_err(|e| e.to_string())?;
        // 独立検算: 外側の値で閉じた 2 階差分 D c と、固有値の式 −4 sin²(ω_k/2)
        let ghost_left = outside(left, &c, true);
        let ghost_right = outside(right, &c, false);
        let dc: Vec<f64> = (0..n)
            .map(|j| {
                let prev = if j == 0 { ghost_left } else { c[j - 1] };
                let next = if j + 1 == n { ghost_right } else { c[j + 1] };
                prev - 2.0 * c[j] + next
            })
            .collect();
        let omega = pi * (k as f64 + a) / (nf + b);
        let lambda = -4.0 * (omega / 2.0).sin().powi(2);
        let dot = |p: &[f64], q: &[f64]| p.iter().zip(q).map(|(x, y)| x * y).sum::<f64>();
        let rayleigh = dot(&dc, &c) / dot(&c, &c);
        let scale = c.iter().fold(0.0_f64, |m, v| m.max(v.abs()));
        let worst = dc
            .iter()
            .zip(&c)
            .fold(0.0_f64, |m, (d, v)| m.max((d - lambda * v).abs()));
        eigen_gap = eigen_gap.max((rayleigh - lambda).abs());
        residual = residual.max(worst / scale);
    }
    rows.push((
        name,
        label(left, true),
        label(right, false),
        eigen_gap,
        residual,
    ));
}

let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let columns = serde_json::json!([
    { "key": "0", "label": "型" },
    { "key": "1", "label": "左の外側の値" },
    { "key": "2", "label": "右の外側の値" },
    { "key": "3", "label": "Rayleigh 商と λₖ の差の最大 [-]", "type": "number", "format": sci2 },
    { "key": "4", "label": "残差 ‖Dc − λc‖∞/‖c‖∞ の最大 [-]", "type": "number", "format": sci2 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "closures" })
);
```

既定の $n=8$ では、8 つの型のどれも残差が $1.4\times10^{-15}$ 以下で、Rayleigh 商と式の $\lambda_k$ の差も $1.4\times10^{-15}$ 以下である。
表の外側の値で閉じれば、どの型の核も丸め誤差の範囲で 2 階差分の固有ベクトルであり、境界条件の表と固有値の式が 8 つの型すべてで成り立つ。
$n=7$ と $n=2$ でも残差は $9\times10^{-16}$ 以下にとどまる。
外側の値を両端とも 0 にすると、DST-I の残差は $9.0\times10^{-16}$ のままだが、ほかの 7 つの型の残差は $0.98$ から $1.0$ になり、核は固有ベクトルでなくなる。

## 格子の間隔と固有値

区間 $[0,1]$ を $N$ 等分し、$h=1/N$ とする。
Dirichlet 条件 $u(0)=u(1)=0$ では、未知数は内部の格子点 $x_j=jh$（$j=1,\ldots,N-1$）の $N-1$ 個で、2 階中心差分は

$$
(\mathbf L\mathbf u)_j=\frac{u_{j-1}-2u_j+u_{j+1}}{h^2},\qquad u_0=u_N=0
$$

の $(N-1)\times(N-1)$ の対称三重対角行列になる。
これは長さ $n=N-1$ の $\mathbf D$ を $h^2$ で割ったもので、外側の値は格子点の Dirichlet 条件（DST-I の閉じ方）である。
上の DST-I の行から、$\mathbf v_k=[\sin(jk\pi/N)]_{j=1}^{N-1}$ は

$$
\mathbf L\mathbf v_k=\lambda_k\mathbf v_k,\qquad
\lambda_k=-\frac{4}{h^2}\sin^2\frac{k\pi}{2N},\qquad k=1,\ldots,N-1
$$

を満たす。

Neumann 条件 $u'(0)=u'(1)=0$ をセル中心 $x_j=(j+\tfrac12)h$（$j=0,\ldots,N-1$）の格子で離散化すると、外側の値は鏡映 $u_{-1}=u_0$、$u_N=u_{N-1}$ になる。
これは DCT-II の閉じ方で、固有ベクトルは $\cos(\pi(j+\tfrac12)k/N)$、固有値は同じ式の $\lambda_k$（$k=0,\ldots,N-1$）である。
$k=0$ の定数ベクトルは固有値 0 を持ち、Neumann 問題の解が定数の差を除いてしか決まらないことに対応する。

連続の固有値 $-(k\pi)^2$（Dirichlet の固有関数 $\sin k\pi x$、Neumann の $\cos k\pi x$）との比は

$$
\frac{\lambda_k}{-(k\pi)^2}=\left(\frac{\sin(k\pi h/2)}{k\pi h/2}\right)^2=1-\frac{(k\pi h)^2}{12}+O(h^4)
$$

なので、$kh$ が小さいモードほど連続の値に近く、相対差は $h^2$ に比例して減る。
$k$ が $N$ に近いモードでは $\lvert\lambda_k\rvert$ が $4/h^2$ で頭打ちになり、連続の値から大きく離れる。

### 固有値の測定

次のセルは各モード $k$ について $\mathbf v_k$ と $\mathbf L\mathbf v_k$ を差分の式で独立に作り、Dirichlet では DST-I、Neumann では DCT-II（どちらも `Orthonormal`）で変換する。
$\mathbf L\mathbf v_k$ の係数のうち $k$ 番目のモードに当たる係数と、$\mathbf v_k$ の同じ係数の比を、測った固有値とする。
それ以外の係数の最大と $k$ 番目の係数の比は、変換が行列を対角化しているかの目安である。
基底ベクトルは `f64` の `sin` と `cos` で作った参照値である。
グラフは $\lvert\lambda\rvert$ を対数軸で描き、Neumann の $k=0$（固有値 0）は描かない。

```rust
//| id: fft-boundary-bases
//| ref: fft-boundary-bases
//| title: DST-I と DCT-II で差分ラプラシアンの固有値を測る
//| run: reactive
//| crates: [scioxide-fft]
//| inputs:
//|   grid_intervals: {"type":"range","label":"区間の分割数 N","description":"Dirichlet では内部の N−1 点、Neumann ではセル中心の N 点が未知数になる。","min":24,"max":128,"step":8,"value":32}
//|   mode: {"type":"range","label":"表に出すモード k","description":"固有値を表で比べるモード次数。","min":1,"max":20,"step":1,"value":3}
//|   boundary: {"type":"select","label":"境界条件","description":"変換の型と格子が変わる。","options":["Dirichlet（格子点、DST-I）","Neumann（セル中心、DCT-II）"],"value":"Dirichlet（格子点、DST-I）"}
//| cases:
//|   - {"id":"neumann","label":"Neumann","description":"DCT-II が対角化し、同じ k では固有値が Dirichlet と同じ値になる。","inputs":{"boundary":"Neumann（セル中心、DCT-II）"}}
//|   - {"id":"fine-grid","label":"N = 128","description":"h が 1/4 になり、連続との相対差が約 1/16 に減る。","inputs":{"grid_intervals":128}}
//|   - {"id":"high-mode","label":"N = 24, k = 20","description":"k が N に近く、差分の固有値が連続の値から大きく離れる。","inputs":{"grid_intervals":24,"mode":20}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"eigen","path":"/rows/0/0","equals":3}
//|       - {"artifact":"eigen","path":"/rows/0/3","range":{"max":1e-12}}
//|       - {"artifact":"eigen","path":"/rows/0/5","approx":{"value":0.0072,"rtol":0.02}}
//|       - {"artifact":"eigen","path":"/rows/0/6","range":{"max":1e-12}}
//|   - case: neumann
//|     expect:
//|       - {"artifact":"eigen","path":"/rows/0/3","range":{"max":1e-12}}
//|       - {"artifact":"eigen","path":"/rows/0/5","approx":{"value":0.0072,"rtol":0.02}}
//|       - {"artifact":"eigen","path":"/rows/0/6","range":{"max":1e-12}}
//|   - case: fine-grid
//|     expect:
//|       - {"artifact":"eigen","path":"/rows/0/3","range":{"max":1e-11}}
//|       - {"artifact":"eigen","path":"/rows/0/5","approx":{"value":4.5e-4,"rtol":0.02}}
//|   - case: high-mode
//|     expect:
//|       - {"artifact":"eigen","path":"/rows/0/0","equals":20}
//|       - {"artifact":"eigen","path":"/rows/0/3","range":{"max":1e-12}}
//|       - {"artifact":"eigen","path":"/rows/0/5","range":{"min":0.4}}
use scioxide_fft::{DctType, DstType, Normalization, dct, dst};

let intervals = grid_intervals.round() as usize;
let selected = mode.round() as usize;
let dirichlet = boundary.starts_with("Dirichlet");
let h = 1.0 / intervals as f64;
let pi = std::f64::consts::PI;
// Dirichlet: 内部の格子点 N−1 個、モード k = 1..N−1 は係数 k−1。
// Neumann: セル中心 N 個、モード k = 0..N−1 は係数 k。
let (size, first) = if dirichlet {
    (intervals - 1, 1)
} else {
    (intervals, 0)
};
let transform = |values: &[f64]| {
    if dirichlet {
        dst(values, DstType::I, Normalization::Orthonormal)
    } else {
        dct(values, DctType::II, Normalization::Orthonormal)
    }
};
let (mut measured, mut discrete, mut continuous) = (Vec::new(), Vec::new(), Vec::new());
let mut row = None;
for k in first..first + size {
    let kf = k as f64;
    // 基底ベクトル（参照値として f64 の sin と cos で作る）。
    let v: Vec<f64> = (0..size)
        .map(|j| {
            if dirichlet {
                ((j + 1) as f64 * kf * pi * h).sin()
            } else {
                ((j as f64 + 0.5) * kf * pi * h).cos()
            }
        })
        .collect();
    // 独立に差分の式で L v を作る。外側の値は Dirichlet では 0、Neumann では鏡映。
    let outside = |inner: f64| if dirichlet { 0.0 } else { inner };
    let lv: Vec<f64> = (0..size)
        .map(|i| {
            let left = if i > 0 { v[i - 1] } else { outside(v[0]) };
            let right = if i + 1 < size {
                v[i + 1]
            } else {
                outside(v[size - 1])
            };
            (left - 2.0 * v[i] + right) / (h * h)
        })
        .collect();
    let coefficients_v = transform(&v).map_err(|e| e.to_string())?;
    let coefficients_lv = transform(&lv).map_err(|e| e.to_string())?;
    let index = k - first;
    let eigenvalue = coefficients_lv[index] / coefficients_v[index];
    let formula = -4.0 / (h * h) * (kf * pi * h / 2.0).sin().powi(2);
    let exact = -(kf * pi).powi(2);
    if k > 0 {
        measured.push([kf, -eigenvalue]);
        discrete.push([kf, -formula]);
        continuous.push([kf, -exact]);
    }
    if k == selected {
        // k 番目以外の係数の最大と k 番目の比（対角化の目安）。
        let off = coefficients_lv
            .iter()
            .enumerate()
            .filter(|(i, _)| *i != index)
            .fold(0.0_f64, |m, (_, c)| m.max(c.abs()))
            / coefficients_lv[index].abs();
        row = Some((
            k,
            eigenvalue,
            formula,
            ((eigenvalue - formula) / formula).abs(),
            exact,
            ((formula - exact) / exact).abs(),
            off,
        ));
    }
}

let series = vec![
    serde_json::json!({
        "name": "変換で測った |λₖ|",
        "points": measured,
        "style": { "showSymbol": true, "lineType": "dotted" }
    }),
    serde_json::json!({
        "name": "差分の式 (4/h²) sin²(kπh/2)",
        "points": discrete,
        "style": { "lineType": "dashed" }
    }),
    serde_json::json!({

        "points": continuous,

    }),
];
emit_line_chart!(

            { "kind": "line", "axis": "x", "value": selected as f64, "label": "表のモード" }
        ]

);
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let digits10 = serde_json::json!({ "significantDigits": 10 });
let columns = serde_json::json!([

    { "key": "1", "label": "測った λₖ [-]", "type": "number", "format": digits10 },
```

既定の Dirichlet、$N=32$、$k=3$ では、測った固有値 $-88.18619242043626$ と差分の式 $-88.18619242043624$ の相対差は $1.6\times10^{-16}$ で、他の係数は $k$ 番目の $4.2\times10^{-15}$ 倍にとどまる。
差分と連続の相対差は $0.0072$ で、$(k\pi h)^2/12=0.00723$ と合う。
Neumann に切り替えても同じ $k$ の固有値は同じ値になり、変わるのは固有ベクトルと $k$ の範囲（0 から始まる）である。
$N=128$ では差分と連続の相対差が $4.5\times10^{-4}$ に下がり、$h$ を 1/4 にして誤差が 1/16 になる $h^2$ の速さと合う。
$N=24$、$k=20$ では相対差が $0.46$ に達し、グラフの右端のように差分の固有値が $4/h^2$ に向かって頭打ちになる。

## 高速 Poisson 解法

Dirichlet 条件の差分方程式 $\mathbf L\mathbf u=\mathbf f$ は、$\mathbf L$ が DST-I で対角化されることから次の 3 段で解ける。

1. `dst(f, DstType::I, Normalization::Orthonormal)` で $\hat f_k$ を求める。
2. 各 $k$ で $\hat u_k=\hat f_k/\lambda_k$ とする。
3. `idst(…, DstType::I, Normalization::Orthonormal)` で $\mathbf u$ に戻す。

`Orthonormal` の DST-I は対称な直交行列なので、3 段目は 1 段目と同じ変換である。
演算量は FFT 2 回と割り算 $N-1$ 回の $O(N\log N)$ である。
1 次元では三重対角の LU 分解が $O(N)$ で解くので、この解法の利点は 2 次元以上で現れる。
$N\times N$ の格子の 5 点差分では、`dstn` で両軸に DST-I を掛けると固有値が $\lambda_k+\lambda_l$ の対角行列になり、$O(N^2\log N)$ で解ける。
Neumann 条件では DCT-II を使い、固有値 0 の $k=0$ の成分は右辺の平均が 0 であること（可解条件）を確かめてから任意の定数に決める。
周期境界の同じ解法は [周期境界の Poisson 方程式をスペクトル法で解く](../../examples/spectral-poisson/)が `rfftn` で扱う。

## まとめ

DCT と DST の核は表の外側の値で閉じた 2 階差分の固有ベクトルで、固有値は $-4\sin^2(\omega_k/2)$ である。
外側の値を型に合わない閉じ方にすると固有ベクトルではなくなるので、境界条件から型を選ぶ。
格子点の Dirichlet 条件には DST-I、セル中心の Neumann 条件には DCT-II が対応し、差分の固有値は低いモードで連続の $-(k\pi)^2$ に $h^2$ の速さで近づく。
差分の Poisson 方程式は対角化する変換、固有値での割り算、逆変換で $O(N\log N)$ で解ける。
