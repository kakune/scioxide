[非一様 Fourier 変換](../nonuniform-fft/)の 3 つの型は、指数和を直接に足さず、核で等間隔の格子へ移して FFT で計算する。
近似の誤差は核の幅と格子の細かさで決まり、Plan の準備は要求精度に合う最小の核の幅を選ぶ。
このページでは核と格子の作り方、要求精度の意味、準備が使う誤差の推定、演算量とメモリ使用量を説明し、不規則な観測時刻の型 3 で推定と実際の誤差を比べる。

## Kaiser–Bessel 核と過標本格子

型 1 は各点の値を幅 $w$ 格子点の核で等間隔の過標本格子へ広げ（拡散）、格子を FFT で変換し、核の Fourier 変換で割ってモードの値を戻す（逆畳み込み）。
型 2 は逆の順に、係数を核の Fourier 変換で割ってから FFT で格子に戻し、各点の値を格子から核で補間する。
型 3 は点を拡大縮小して格子に広げ、FFT のあとに周波数の位置で補間するので、拡散と補間の両方を行う（Barnett, Magland & af Klinteberg 2019）。

核は Kaiser–Bessel 関数 $I_0\bigl(\beta\sqrt{1-(2u/w)^2}\bigr)/I_0(\beta)$ で、$u$（$\lvert u\rvert\le w/2$）は格子点を単位とする距離、$I_0$ は第 1 種変形 Bessel 関数である。
形状の母数は

$$
\beta = \pi\sqrt{\bigl(w(1-1/(2\sigma_o))\bigr)^2-0.8}
$$

である（Beatty, Nishimura & Pauly 2005）。
$\sigma_o\ge2$ は過標本率の下限で、`NufftPlanSpec::with_oversampling` で変える（既定 2）。
$N_a>1$ の軸の格子は $\max(\lceil\sigma_oN_a\rceil, w+2)$ 以上で最小の 2 のべきの点数を持つので、実際の過標本率は $\sigma_o$ 以上になる。
核の形状 $\beta$ と次の節の推定 $E_a$ には、実際の格子の比ではなく指定した $\sigma_o$ が使われる。
型 3 では、点の箱の半幅 $X_a$ と周波数の箱の半幅 $S_a$ から、基底の点数を $2\lceil X_aS_a\sigma_o/\pi\rceil+w+1$ とし、同じ規則で格子を決める。
型 3 の格子の大きさは点の数ではなく、空間と周波数の広がりの積 $X_aS_a$ で決まる。

1 点の拡散か補間は $w^d$ 個の格子点を訪れ、型 3 は点と周波数の両方で訪れる。
格子点数を $G$ とすると、1 回の変換の演算量は $O(Mw^d+G\log G)$（型 3 では $M$ を点と周波数の数の和とする）である。
Plan は FFT の表のほかに $O(Md+\sum_aN_a+dw)$ の値を保持し、作業領域の大部分は過標本格子 2 つ分である。
点やモードが少ないと、準備を含めた計算コストが直接和を上回ることがある。

## 要求精度と誤差の推定

要求精度 $\varepsilon_r$（$0<\varepsilon_r<1$）は、出力の最大誤差を入力の 1 ノルムに対する比で指定する。

$$
\max_\ell\bigl\lvert \hat f_\ell-f_\ell\bigr\rvert \lesssim \varepsilon_r\,\lvert s\rvert\sum_j\lvert c_j\rvert
$$

$\hat f_\ell$ は計算値、$f_\ell$ は厳密な和、$s$ は正規化の係数である。
型 2 では右辺の和がモードの係数の 1 ノルム $\sum_{\mathbf k}\lvert f_{\mathbf k}\rvert$ になる。
出力の大きさではなく入力の大きさを基準にするので、打ち消しで小さくなった出力の相対誤差は要求の対象外である。

準備は、折り返し誤差の推定 $E_a$ と丸め誤差の推定 $E_r$ の和が $\varepsilon_r$ 以下になる最小の $w\ge4$ を探す。

$$
E_a=(1+a)^r-1,\qquad a=3\exp\bigl(-\pi(w-1)\sqrt{1-1/\sigma_o}\bigr)
$$

$$
E_r=\varepsilon\,(4+C+\log_2\max(2,G))+\varepsilon_{64}\,(2P+8d)
$$

$r$ は型 1・2 で $d$、2 段の格子を通る型 3 で $2d$ である。
$\varepsilon$ はスカラー型の、$\varepsilon_{64}$ は `f64` の機械イプシロンを表す。
$C$ は 3 次元の拡散で点を局所的な区画にまとめるとき `f64` で 64、`f32` で 4 をとり、まとめないときは 0 をとる。
$P$ は型 1・2 で、座標の絶対値が $\pi$ を超える点を持つ軸についての $N_a$ の和で、全座標が $[-\pi,\pi]$ にあれば 0 になる。
$a$ の減衰率は Kaiser–Bessel 核の理論から来るが、係数 3 は直接和との比較で決めた経験値である。
どちらも上界ではなく推定で、打ち消しのために実際の誤差がずっと小さくなることもある。

$E_r\ge\varepsilon_r$ なら、核を広げても要求に届かないので、準備は `NumericalInstability` を返す。
`f64` の $E_r$ は小さい 1 次元の問題でも $4\times10^{-15}$ 程度あり、格子の大きさ、座標の範囲、次元とともに増える。
$\sigma_o$ を大きくすると $a$ が速く減るので狭い核で済むが、格子が大きくなる。

## 不規則な観測時刻での型 3

型 3 は時刻も周波数も等間隔でない和を直接扱う。
次のセルは signal 章の [変光星の周期推定](../../../scioxide-signal/examples/variable-star-period/)と同じ観測時刻と光度曲線（周期 $P=0.567$ 日、40 夜・一晩 6 点の 240 点）を、ノイズを加えずに使う。
平均を引いた光度 $c_j$ [等] と時刻 $t_j$ [日] から、周波数 0.2〜4 日⁻¹ の 1901 点で $F(\nu)=\sum_jc_je^{-2\pi i\nu t_j}$ を求める。
型 3 には時刻 [日] と角周波数 $\omega=2\pi\nu$ [rad/日] を渡す。
入力は要求精度の指数と過標本率の下限 $\sigma_o$ である。
独立な検算として、全 1901 点の直接和（`f64` の固有メソッド）との差の最大を、入力の 1 ノルムで割って示す。
周期の推定や誤警報確率は signal 章で、型 1 による同じ和の要求精度ごとの比較は例題で扱い、ここでは型 3 の推定と格子の大きさを見る。

```rust
//| id: fft-nufft-direct-sum
//| ref: fft-nufft-direct-sum
//| title: 不規則な観測時刻の Fourier 和を型 3 で求め、直接和と比べる
//| run: reactive
//| crates: [scioxide-core, scioxide-fft]
//| inputs:
//|   accuracy_exponent: {"type":"integer","label":"要求精度の指数 p（ε_r = 10^p）","description":"入力の 1 ノルムに対する最大誤差の要求。","min":-12,"max":-3,"value":-6}
//|   oversampling: {"type":"range","label":"過標本率の下限 σ_o [-]","description":"大きいほど核は狭く、格子は大きくなる。","min":2,"max":4,"step":0.5,"value":2}
//| cases:
//|   - {"id":"strict","label":"ε_r = 10⁻¹²","description":"核が広がり、拡散の訪問数が増える。","inputs":{"accuracy_exponent":-12}}
//|   - {"id":"oversampled","label":"σ_o = 3","description":"核が狭まる代わりに格子が大きくなる。","inputs":{"oversampling":3}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"accuracy","path":"/rows/0/1","range":{"max":1e-6}}
//|       - {"artifact":"accuracy","path":"/rows/0/4","approx":{"value":9,"atol":0.5}}
//|   - case: strict
//|     expect:
//|       - {"artifact":"accuracy","path":"/rows/0/1","range":{"max":1e-12}}
//|       - {"artifact":"accuracy","path":"/rows/0/4","range":{"min":15}}
//|   - case: oversampled
//|     expect:
//|       - {"artifact":"accuracy","path":"/rows/0/1","range":{"max":1e-6}}
//|       - {"artifact":"accuracy","path":"/rows/0/4","range":{"max":8.5}}
use scioxide_core::{Complex, ExecutionContext, NdView, StridedLayout};
use scioxide_fft::{FftDirection, Normalization, NufftPlan, NufftPlanSpec, NufftTransform};

let tau = 2.0 * std::f64::consts::PI;
let period = 0.567_f64; // 周期 [日]
// 40 夜 × 6 回の観測時刻 [日] と光度 [等]（f64 の sin は入力の生成だけに使う）
let times: Vec<f64> = (0..240)
    .map(|j| (j / 6) as f64 + 0.05 + 0.25 * (j as f64 * 0.618_033_988_749_894_9).fract())
    .collect();
let light: Vec<f64> = times
    .iter()
    .map(|&t| {
        let phase = tau * t / period;
        0.3 * phase.sin() + 0.1 * (2.0 * phase + 0.7).sin()
    })
    .collect();
let mean = light.iter().sum::<f64>() / light.len() as f64;
let c: Vec<Complex<f64>> = light.iter().map(|&y| Complex::new(y - mean, 0.0)).collect();
// 周波数 ν = 0.2〜4 日⁻¹（1901 点）を角周波数 ω = 2πν [rad/日] で渡す
let nu: Vec<f64> = (0..1901).map(|k| 0.2 + 0.002 * k as f64).collect();
let omegas: Vec<f64> = nu.iter().map(|v| tau * v).collect();

let (point_shape, target_shape) = ([times.len(), 1], [omegas.len(), 1]);
let point_layout = StridedLayout::new(&point_shape, &[1, 1]).map_err(|e| e.to_string())?;
let target_layout = StridedLayout::new(&target_shape, &[1, 1]).map_err(|e| e.to_string())?;
let transform = NufftTransform::Type3 {
    points: NdView::new(&times, point_layout).map_err(|e| e.to_string())?,
    frequencies: NdView::new(&omegas, target_layout).map_err(|e| e.to_string())?,
};
let accuracy = 10f64.powi(accuracy_exponent);
let spec = NufftPlanSpec::new(FftDirection::Forward, Normalization::Unscaled, accuracy)
    .with_oversampling(oversampling);
let plan = NufftPlan::new(transform, spec).map_err(|e| e.to_string())?;
let mut workspace = plan.workspace(()).map_err(|e| e.to_string())?;
let mut output = vec![Complex::new(0.0, 0.0); omegas.len()];
plan.execute_into(
    &c[..],
    &mut output[..],
    &mut workspace,
    ExecutionContext::sequential(),
)
.map_err(|e| e.to_string())?;

// 独立な検算: 全周波数での直接和 Σ_j c_j exp(−i ω t_j)
let l1: f64 = c.iter().map(|v| v.norm()).sum();
let mut worst = 0.0_f64;
for (value, &omega) in output.iter().zip(&omegas) {
    let direct: Complex<f64> = c
        .iter()
        .zip(&times)
        .map(|(cj, &t)| *cj * Complex::from_polar(1.0, -omega * t))
        .sum();
    worst = worst.max((*value - direct).norm() / l1);
}

let curve: Vec<[f64; 2]> = nu
    .iter()
    .zip(&output)
    .map(|(&v, z)| [v, z.norm()])
    .collect();
emit_line_chart!(
    &vec![serde_json::json!({ "name": "|F(ν)|（型 3）", "points": curve })],
    options = &serde_json::json!({
        "xLabel": "周波数 ν [日⁻¹]",
        "yLabel": "Fourier 和の絶対値 |F| [等]",
        "xMin": 0.2,
        "xMax": 4.0,
        "annotations": [
            { "kind": "line", "axis": "x", "value": 1.0 / period, "label": "基本周波数" },
            { "kind": "line", "axis": "x", "value": 2.0 / period, "label": "第 2 高調波" }
        ]
    })
);
let d = plan.diagnostics();
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let columns = serde_json::json!([
    { "key": "0", "label": "要求精度 ε_r [-]", "type": "number", "format": sci2 },
    { "key": "1", "label": "実測誤差 / Σ|c_j| [-]", "type": "number", "format": sci2 },
    { "key": "2", "label": "推定 E_a [-]", "type": "number", "format": sci2 },
    { "key": "3", "label": "推定 E_r [-]", "type": "number", "format": sci2 },
    { "key": "4", "label": "核の幅 w", "type": "integer" },
    { "key": "5", "label": "格子点数 G", "type": "integer" },
    { "key": "6", "label": "格子点の延べ訪問数", "type": "integer" },
    { "key": "7", "label": "直接和の項数 MK", "type": "integer" }
]);
let row = (
    accuracy,
    worst,
    d.approximation_error,
    d.roundoff_error,
    d.kernel_support,
    d.grid_points,
    d.stencil_visits,
    times.len() * omegas.len(),
);
emit_table_with_columns!(
    columns,
    vec![row],
    metadata = serde_json::json!({ "id": "accuracy" })
);
```

図の最大の山は基本周波数 $1/(0.567\ \text{日})\approx1.764$ 日⁻¹ にあり、その 2 倍に第 2 高調波の山、両側に 1 日⁻¹ 間隔の日周エイリアスが並ぶ。
既定の $\varepsilon_r=10^{-6}$、$\sigma_o=2$ では、核の幅 9、格子 1024 点で、直接和との差は入力の 1 ノルムの $3.2\times10^{-9}$ 倍である。
格子点数は時刻の半幅（約 20 日）と角周波数の半幅（約 11.9 rad/日）の積で決まり、観測数 240 には比例しない。
$\varepsilon_r=10^{-12}$ では核の幅が 15 に広がり、延べ訪問数も 19269 から 32115 に増えるが、格子はこの例では変わらない。
$\sigma_o=3$ では核の幅が 8 に狭まり、格子が 2048 点に大きくなる。
どの場合も実測誤差は推定 $E_a+E_r$ と要求を下回るが、これはこの配置と係数での結果で、推定は上界ではない。

## まとめ

NUFFT は Kaiser–Bessel 核で過標本格子へ拡散するか格子から補間し、FFT と核の Fourier 変換による補正を組み合わせて指数和を近似する。
要求精度は入力の 1 ノルムに対する最大誤差の比で、準備は推定 $E_a+E_r$ が要求を下回る最小の核の幅を選び、$E_r$ が要求以上なら `NumericalInstability` を返す。
過標本率 $\sigma_o$ を上げると核は狭くなるが格子は大きくなり、型 3 の格子は点と周波数の広がりの積で決まる。
推定は上界ではないので、重要な計算では一部の出力を直接和と比べる。
