実数列の離散 Fourier 変換（DFT）は、負の周波数のビンが正の周波数のビンの共役になる。
`rfft` はこの性質を使って非負周波数のビンだけを返し、`irfft` はそのビンから元の実数列を復元する。
時間側の列が共役対称で周波数側が実数になる逆向きの問題には、`hfft` と `ihfft` を使う。
このページは対称性の導出、計アルゴリズムと計算コスト、パックした格納の型、逆変換が入力に課す対称性の検査を説明する。
DFT の符号と正規化の規約は [DFT の定義と正規化](../dft-sampling-and-normalization/) にある。

## 実数列のスペクトルと Hermite 対称性

長さ $N$ の列 $x_j$ の DFT を $X_k=\sum_{j=0}^{N-1}x_j\,e^{-2\pi i jk/N}$ とする。
$x_j$ がすべて実数なら、共役を取ると指数の符号だけが反転するので

$$
\overline{X_k}=\sum_{j=0}^{N-1}x_j\,e^{2\pi i jk/N}=X_{(N-k)\bmod N}
$$

が成り立つ。
この性質を Hermite 対称性（共役対称性）と呼ぶ。
$X_{N-k}$ は $X_k$ から決まるので、$k=0,\ldots,\lfloor N/2\rfloor$ の $\lfloor N/2\rfloor+1$ 個のビンを持てば全体が分かる。

$k=N-k$ となるビンは自分自身の共役なので実数である。
DC 成分 $X_0=\sum_j x_j$ は常にそうであり、偶数長では Nyquist 成分 $X_{N/2}=\sum_j(-1)^jx_j$ も実数になる。
奇数長には周波数がちょうど $1/2$ 周期毎標本のビンがなく、最後に持つビン $X_{(N-1)/2}$ は一般に複素数である。
したがって奇数長では、最後のビンの虚部を 0 にしてはならない。

パックしたビン $k$ の周波数は $k/(Nd)$（$d$ は標本間隔）で、`rfftfreq(n, d)` がこの $\lfloor N/2\rfloor+1$ 個の値を返す。

## rfft と irfft の計アルゴリズム

$N=2m$ が偶数なら、偶数番目と奇数番目の標本を 1 つの複素数 $z_j=x_{2j}+i\,x_{2j+1}$（$j=0,\ldots,m-1$）にまとめ、長さ $m$ の複素 FFT $Z_k$ を 1 回求める。
偶数番目の列と奇数番目の列の DFT は

$$
E_k=\tfrac12\bigl(Z_k+\overline{Z_{m-k}}\bigr),\qquad
O_k=-\tfrac{i}{2}\bigl(Z_k-\overline{Z_{m-k}}\bigr)
$$

で取り出せ（添字は $\bmod m$）、$X_k=E_k+e^{-2\pi i k/N}O_k$ が $k=0,\ldots,m$ のビンになる。
計算コストは長さ $m$ の複素 FFT 1 回と $O(N)$ の後処理で、長さ $N$ の複素 FFT のおよそ半分である。
`irfft` は同じ手順を逆にたどる。

奇数長で 3・5・7 のいずれかの真の倍数（$N=pm$、$p\in\{3,5,7\}$、$N>p$）なら、標本を $p$ 本の間引き列 $x_{pt+r}$（$r=0,\ldots,p-1$）に分ける。
$r=1,\ldots,p-1$ の列は 2 本ずつ 1 つの複素列にまとめて長さ $m$ の複素 FFT にかけ、$r=0$ の列は長さ $m$ の実数 FFT で再帰的に変換する。
最後に $p$ 点のバタフライで各列のスペクトルを合わせるので、計算コストはこの場合も複素 FFT のおよそ半分である。
それ以外の奇数長（3・5・7 そのもの、11・13 などの素数、$11^2$ など）では、実数列を虚部 0 の複素列として長さ $N$ の複素 FFT にかけるので、計算コストは半分にならない。
どの経路でも計算量は $O(N\log N)$ である。

格納するビンの数は全体のおよそ半分になるが、実行時間と作業領域がどれだけ減るかは長さの因数分解と経路で決まる。
順変換の誤差の上限は複素 FFT と同じく相対 $L^2$ 誤差で $2\varepsilon\max(1,\log_2N)$（$\varepsilon$ はスカラー型の機械イプシロン）である。
これはネイティブの計算カーネルについて、高精度の DFT と比べる試験で確かめた上限で、ノルムで測った値である。
最大のビンよりずっと小さいビンの相対誤差は大きくなりうる。

## HermitianSpectrum と論理長

長さ 6 の実数列と長さ 7 の実数列は、どちらも 4 個のビンに詰まる。
ビンの数だけでは元の長さが決まらないので、`HermitianSpectrum<S>` はビンの `Vec` と論理長 $N$ を一緒に所有する。

- `logical_len()` は論理長 $N$、`len()` はビンの数 $\lfloor N/2\rfloor+1$ を返す。
- `bins()` は共有借用、`bins_mut()` は可変借用でビンを返し、`into_vec()` は論理長を捨ててビンの `Vec` を取り出す。
- `from_vec(logical_len, bins)` は論理長が 0 なら `InvalidInput`（`Empty`）、ビンの数が $\lfloor N/2\rfloor+1$ と違えば `DimensionMismatch` を返す。
- `zeros(logical_len)` は値が 0 のスペクトルを確保する。

構築時には長さだけを調べ、値の有限性と対称性は調べない。
`bins_mut()` でビンを書き換えたあとも、対称性は逆変換を実行するときに検査される（[Hermite 対称性の検査](#hermite-対称性の検査)）。

## Plan での格納形式

同じ長さを繰り返し変換するときは、`FftPlanSpec::new(n, direction, normalization, layout)` から `FftPlan` を準備する。
`FftLayout` は入出力の格納形式を選ぶ。

| `FftLayout` | 順方向の入力 → 出力 | 逆方向の入力 → 出力 | 一括関数 |
|---|---|---|---|
| `Complex` | 長さ $N$ の複素数 → 長さ $N$ の複素数 | 同左 | `fft`、`ifft` |
| `Real` | 実数の標本 → パックしたビン | パックしたビン → 実数の標本 | `rfft`、`irfft` |
| `Hermitian` | パックした共役対称の標本 → 実数のスペクトル | 実数のスペクトル → パックした標本 | `hfft`、`ihfft` |

`execute_into` の入力は `FftInput`、出力は `FftOutput` で受け取る。
実数のスライスや配列は `Real`、複素数のスライスは `Complex` の列挙子に変換され、`&HermitianSpectrum` と `&mut HermitianSpectrum` は論理長付きの `Hermitian` になる。
連続でない格納は `VectorView` で渡し、パックしたビンを借用で渡すときは `FftInput::hermitian(logical_len, &bins)` か列挙子 `FftInput::Hermitian { logical_len, bins }` で論理長を添える。
列挙子が Plan の格納形式と方向に合わなければ `InvalidInput`（`UnsupportedConfiguration`）、論理長やビンの数が Plan と違えば `DimensionMismatch` になる。
Plan は方向と正規化を固定するので、往復には逆方向の Plan をもう 1 つ準備する。
Plan と作業領域の再利用は [Plan の準備と所有](oxref:fft-plan-preparation) にある。

## Hermite 対称性の検査

`irfft`、`hfft`、`irfftn`、`hfftn` と、パックした入力を受け取る Plan は、入力が丸め誤差の範囲で Hermite 対称であることを検査する。
独立なスペクトルごとに、パックしたビンの実部と虚部の絶対値の最大を $M$、スカラー型の機械イプシロンを $\varepsilon$、最小の正の非正規化数を $\eta$ として、許容値を

$$
\tau=\max(8\varepsilon M,\ \eta)
$$

とする。
1 次元では DC と、偶数長の Nyquist のビンが $|\operatorname{Im}X|\le\tau$ を満たす必要がある。
多次元の変換では、パックした軸の DC と Nyquist の面に共役の対が両方とも格納されるので、対 $(X,Y)$ について

$$
|\operatorname{Re}X-\operatorname{Re}Y|\le2\tau,\qquad
|\operatorname{Im}X+\operatorname{Im}Y|\le2\tau
$$

を調べる（[HermitianSpectrumNd と逆変換](oxref:fft-real-nd-spectrum)）。

許容値を超えると `InvalidInput`（`OutOfRange`）を返し、黙って射影はしない。
非有限の成分は `NonFinite` になる。
許容値以内のずれは作業領域の中で正確な Hermite 対称に射影し、呼び出し側の入力は書き換えない。
自己共役なビンでは虚部を 0 にし、対では両者の平均で置き換える。
この射影が正規化前の変換結果を動かす量は $\sqrt2\,N(\tau+\varepsilon M+\eta)$ 以下である。

$8\varepsilon$ は単位丸め誤差 $u=\varepsilon/2$ の 16 倍で、$\tau$ は入力の摂動として認める量である。
変換全体の精度を保証する値ではない。
これとは別に、パックした入力から実数を返す変換は、実数データ用の分解を持たない奇数長の場合と、多次元の DC・Nyquist の面で、実数になるはずの途中結果の虚部を丸め誤差の上限と比べる。
上限を超えると `NumericalInstability`（`Breakdown`）を返す。
どのエラーでも出力は書き換えられない。

### 往復誤差と許容値の実験

次のセルは $x_j=\cos(2\pi\cdot3j/N)+0.5$ を `rfft` と `irfft` で往復し、最大絶対誤差を求める。
続いて、比 $\delta/\tau$ を入力で選んだ $\delta$ を DC ビンの虚部に加えて `irfft` に渡し、受理されるか、受理されたとき出力がどれだけ変わるかを見る。
$\tau$ はセルの中で式どおりに独立に計算する。
入力の余弦は `f64` の `cos` で作った参照値である。

```rust
//| id: fft-real-hermitian-invariants
//| ref: fft-real-hermitian-invariants
//| title: 実数 FFT の往復誤差と Hermite 対称性の許容値
//| run: reactive
//| crates: [scioxide-core, scioxide-fft]
//| inputs:
//|   length: {"type":"range","label":"標本長 N","description":"偶数長では Nyquist ビンが実数になり、奇数長では最後のビンが複素数になる。","min":8,"max":64,"step":1,"value":16}
//|   perturbation_ratio: {"type":"range","label":"DC 虚部の摂動 δ/τ","description":"1 以下なら受理されて射影され、1 を超えると拒否される。","min":0,"max":2.5,"step":0.1,"value":0.8}
//| cases:
//|   - {"id":"reject","label":"δ/τ = 1.5","description":"許容値を超え、irfft が InvalidInput を返す。","inputs":{"perturbation_ratio":1.5}}
//|   - {"id":"odd-prime","label":"N = 13","description":"実数データ用の分解がない奇数長。ビンは 7 個で最後のビンは複素数。","inputs":{"length":13}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"roundtrip","path":"/rows/0/0","equals":16}
//|       - {"artifact":"roundtrip","path":"/rows/0/1","equals":9}
//|       - {"artifact":"roundtrip","path":"/rows/0/2","range":{"max":1e-14}}
//|       - {"artifact":"roundtrip","path":"/rows/0/3","approx":{"value":8,"rtol":1e-12}}
//|       - {"artifact":"roundtrip","path":"/rows/0/4","approx":{"value":1.4210854715202004e-14,"rtol":1e-9}}
//|       - {"artifact":"check","path":"/rows/0/2","equals":"受理"}
//|       - {"artifact":"check","path":"/rows/0/3","range":{"max":0}}
//|   - case: reject
//|     expect:
//|       - {"artifact":"check","path":"/rows/0/0","approx":{"value":1.5,"atol":1e-12}}
//|       - {"artifact":"check","path":"/rows/0/2","equals":"拒否（InvalidInput）"}
//|       - {"artifact":"check","path":"/rows/0/3","equals":null}
//|   - case: odd-prime
//|     expect:
//|       - {"artifact":"roundtrip","path":"/rows/0/1","equals":7}
//|       - {"artifact":"roundtrip","path":"/rows/0/2","range":{"max":1e-14}}
//|       - {"artifact":"roundtrip","path":"/rows/0/3","approx":{"value":6.5,"rtol":1e-12}}
//|       - {"artifact":"check","path":"/rows/0/2","equals":"受理"}
use scioxide_core::Complex;
use scioxide_fft::{HermitianSpectrum, Normalization, irfft, rfft};

let n = length.round() as usize;
let pi = std::f64::consts::PI;
// 入力 x_j = cos(2π·3j/N) + 0.5（参照値として f64 の cos で作る）。
let input: Vec<f64> = (0..n)
    .map(|j| (2.0 * pi * 3.0 * j as f64 / n as f64).cos() + 0.5)
    .collect();
// Inverse は順変換を無尺度にし、逆変換で 1/N を掛ける。
let spectrum = rfft(&input, Normalization::Inverse).map_err(|e| e.to_string())?;
let roundtrip = irfft(&spectrum, Normalization::Inverse).map_err(|e| e.to_string())?;
let max_gap = |a: &[f64], b: &[f64]| {
    a.iter()
        .zip(b)
        .map(|(p, q)| (p - q).abs())
        .fold(0.0_f64, f64::max)
};
let roundtrip_error = max_gap(&input, &roundtrip);
// 独立検算: τ = max(8εM, η)。M はパックしたビンの実部と虚部の絶対値の最大。
let maximum = spectrum
    .bins()
    .iter()
    .map(|z| z.re.abs().max(z.im.abs()))
    .fold(0.0_f64, f64::max);
let tau = (8.0 * f64::EPSILON * maximum).max(f64::from_bits(1));
// DC ビンの虚部に δ を加える。from_vec は長さだけを調べる。
let delta = perturbation_ratio * tau;
let mut bins = spectrum.clone().into_vec();
bins[0] = Complex::new(bins[0].re, delta);
let perturbed = HermitianSpectrum::from_vec(n, bins).map_err(|e| e.to_string())?;
let (verdict, change) = match irfft(&perturbed, Normalization::Inverse) {
    // 射影は DC の虚部を 0 にするだけなので、無摂動の往復と比べる。
    Ok(values) => ("受理".to_string(), Some(max_gap(&values, &roundtrip))),
    Err(e) => (format!("拒否（{:?}）", e.kind()), None),
};

let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let fixed2 = serde_json::json!({ "fractionDigits": 2 });
let digits6 = serde_json::json!({ "significantDigits": 6 });
let roundtrip_columns = serde_json::json!([
    { "key": "0", "label": "論理長 N", "type": "integer" },
    { "key": "1", "label": "ビン数 ⌊N/2⌋+1", "type": "integer" },
    { "key": "2", "label": "往復の最大絶対誤差 [-]", "type": "number", "format": sci3 },
    { "key": "3", "label": "最大成分 M [-]", "type": "number", "format": digits6 },
    { "key": "4", "label": "許容値 τ [-]", "type": "number", "format": sci3 }
]);
emit_table_with_columns!(
    roundtrip_columns,
    vec![(n, spectrum.len(), roundtrip_error, maximum, tau)],
    metadata = serde_json::json!({ "id": "roundtrip" })
);
let check_columns = serde_json::json!([
    { "key": "0", "label": "δ/τ [-]", "type": "number", "format": fixed2 },
    { "key": "1", "label": "摂動 δ [-]", "type": "number", "format": sci3 },
    { "key": "2", "label": "irfft の判定" },
    {
        "key": "3",
        "label": "無摂動の出力との最大差 [-]",
        "type": "number",
        "format": sci3,
        "nullText": "出力なし"
    }
]);
emit_table_with_columns!(
    check_columns,
    vec![(perturbation_ratio, delta, verdict, change)],
    metadata = serde_json::json!({ "id": "check" })
);
```

既定の $N=16$ では、DC と $k=3$ のビンがともにほぼ 8 なので $M\approx8$、$\tau=8\varepsilon M\approx1.42\times10^{-14}$ である。
往復の最大絶対誤差は $3.3\times10^{-16}$（$1.5\varepsilon$）である。
$\delta/\tau\le1$ では検査に通り、出力は無摂動の往復と 1 ビットも違わない。
射影が DC の虚部を 0 に戻し、変換に渡る値が無摂動のときと同じになるからである。
$\delta/\tau$ を 1.1 以上にすると `InvalidInput` で拒否され、出力は作られない。
判定は格納された浮動小数点数で行うので、$\delta/\tau$ がちょうど 1 の付近では $\delta$ の丸めで結果が変わりうる。

$N=13$ では $M\approx6.5$ で、ビンは 7 個になる。
13 は素数なので、この長さの実数 FFT は長さ 13 の複素 FFT で計算される。
往復の誤差は $4.4\times10^{-16}$ で偶数長と同じ程度であり、検査の振る舞いも変わらない。

検査に通ることは、スペクトルが意図したものであることを意味しない。
DC の実部を変えれば信号の平均が変わるように、対称性を保つ編集でも結果は変わる。
振幅や単位は別に検算する。

## hfft と ihfft

時間側の列 $h_j$ が $h_{N-j}=\overline{h_j}$ を満たすなら、その DFT は実数である。
`hfft` はこの共役対称な列の先頭 $h_0,\ldots,h_{\lfloor N/2\rfloor}$ を `HermitianSpectrum` で受け取り、順方向の DFT

$$
y_k=\sum_{j=0}^{N-1}h_j\,e^{-2\pi i jk/N}
$$

を長さ $N$ の実数列で返す。
`ihfft` は実数列 $y$ の逆 DFT $h_j=\sum_k y_k e^{2\pi i jk/N}$ を計算し、共役対称な結果の先頭 $\lfloor N/2\rfloor+1$ 個を論理長と一緒に返す。
`hfft` は `ihfft` の逆で、どちらも `Normalization` の規約に従う。
Plan では `FftLayout::Hermitian` を選ぶ。

`rfft` と `hfft` は同じ型を使うが、向きが違う。
`rfft` の出力の `HermitianSpectrum` は周波数側のビン、`hfft` の入力は時間側の標本である。
`hfft` も入力の $h_0$ と、偶数長の $h_{N/2}$ の虚部を上の許容値で検査する。

次のセルは、パックした表現が全長の変換の先頭と一致することを確かめる。
$x_j=1/(1+j)+0.25\,(j\bmod3)$ という非対称な実数列について、`rfft` のビンを複素 `fft` の先頭と、`ihfft` の結果を複素 `ifft` の先頭と比べる。
`fft` の結果そのものが $X_{N-k}=\overline{X_k}$ を満たすことと、`hfft` が `ihfft` を元に戻すことも測る。

```rust
//| id: fft-hermitian-duality
//| ref: fft-hermitian-duality
//| title: パックした変換と全長の複素変換の一致
//| run: reactive
//| crates: [scioxide-core, scioxide-fft]
//| inputs:
//|   length: {"type":"range","label":"長さ N","description":"奇数長と偶数長でビン数 ⌊N/2⌋+1 の数え方を確かめる。","min":1,"max":40,"step":1,"value":16}
//| cases:
//|   - {"id":"odd","label":"N = 15","description":"奇数長。ビンは 8 個で、Nyquist ビンはない。","inputs":{"length":15}}
//|   - {"id":"single","label":"N = 1","description":"ビンは DC の 1 個だけになる。","inputs":{"length":1}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"sizes","path":"/rows/0/1","equals":9}
//|       - {"artifact":"gaps","path":"/rows/0/1","range":{"max":1e-14}}
//|       - {"artifact":"gaps","path":"/rows/1/1","range":{"max":1e-14}}
//|       - {"artifact":"gaps","path":"/rows/2/1","range":{"max":1e-15}}
//|       - {"artifact":"gaps","path":"/rows/3/1","range":{"max":1e-14}}
//|   - case: odd
//|     expect:
//|       - {"artifact":"sizes","path":"/rows/0/1","equals":8}
//|       - {"artifact":"gaps","path":"/rows/0/1","range":{"max":1e-14}}
//|       - {"artifact":"gaps","path":"/rows/3/1","range":{"max":1e-14}}
//|   - case: single
//|     expect:
//|       - {"artifact":"sizes","path":"/rows/0/1","equals":1}
//|       - {"artifact":"gaps","path":"/rows/3/1","range":{"max":0}}
use scioxide_core::Complex;
use scioxide_fft::{Normalization, fft, hfft, ifft, ihfft, rfft};

let n = length.round() as usize;
let norm = Normalization::Inverse;
// 非対称な実数列（四則演算だけで作る）。
let x: Vec<f64> = (0..n)
    .map(|j| 1.0 / (1.0 + j as f64) + 0.25 * (j % 3) as f64)
    .collect();
let as_complex: Vec<Complex<f64>> = x.iter().map(|&v| Complex::new(v, 0.0)).collect();
// zip は短いほうで止まるので、パックした列と全長の列の先頭を比べられる。
let max_gap = |a: &[Complex<f64>], b: &[Complex<f64>]| {
    a.iter()
        .zip(b)
        .map(|(p, q)| (*p - *q).norm())
        .fold(0.0_f64, f64::max)
};
let packed = rfft(&x, norm).map_err(|e| e.to_string())?;
let full = fft(&as_complex, norm).map_err(|e| e.to_string())?;
let rfft_gap = max_gap(packed.bins(), &full);
// 全長の結果が X[N−k] = conj(X[k]) を満たすか。
let symmetry_gap = (1..n)
    .map(|k| (full[n - k] - full[k].conj()).norm())
    .fold(0.0_f64, f64::max);
let half = ihfft(&x, norm).map_err(|e| e.to_string())?;
let inverse = ifft(&as_complex, norm).map_err(|e| e.to_string())?;
let ihfft_gap = max_gap(half.bins(), &inverse);
let back = hfft(&half, norm).map_err(|e| e.to_string())?;
let hfft_gap = x
    .iter()
    .zip(&back)
    .map(|(a, b)| (a - b).abs())
    .fold(0.0_f64, f64::max);

let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let size_columns = serde_json::json!([
    { "key": "0", "label": "論理長 N", "type": "integer" },
    { "key": "1", "label": "rfft のビン数", "type": "integer" },
    { "key": "2", "label": "ihfft のパックした長さ", "type": "integer" }
]);
emit_table_with_columns!(
    size_columns,
    vec![(packed.logical_len(), packed.len(), half.len())],
    metadata = serde_json::json!({ "id": "sizes" })
);
let gap_columns = serde_json::json!([
    { "key": "0", "label": "比較" },
    { "key": "1", "label": "最大絶対差 [-]", "type": "number", "format": sci3 }
]);
emit_table_with_columns!(
    gap_columns,
    vec![
        ("rfft と fft の先頭 ⌊N/2⌋+1 ビン", rfft_gap),
        ("ihfft と ifft の先頭 ⌊N/2⌋+1 個", ihfft_gap),
        ("fft の結果の X[N−k] と conj(X[k])", symmetry_gap),
        ("hfft(ihfft(x)) と x", hfft_gap),
    ],
    metadata = serde_json::json!({ "id": "gaps" })
);
```

既定の $N=16$ ではどの行も差が $2.2\times10^{-16}$ 以下で、パックした変換は全長の変換の先頭の値を返している。
$N=15$ では `rfft` と `fft` の差が $1.3\times10^{-15}$ に広がる。
15 は 3 の倍数なので `rfft` は間引きの経路を通り、全長の複素 FFT とは演算の順序が違うからである。
3 行目は `rfft` を使わない検算で、複素 FFT の結果がその丸め誤差の範囲で Hermite 対称であることを示す。
$N=1$ ではビンは DC の 1 個だけで、`hfft` と `ihfft` の往復は入力をそのまま返す。

## まとめ

実数列のスペクトルは $X_{N-k}=\overline{X_k}$ を満たすので、`rfft` は $\lfloor N/2\rfloor+1$ 個のビンだけを返し、`HermitianSpectrum` が論理長 $N$ を一緒に保つ。
偶数長と 3・5・7 の真の倍数の奇数長では、計算コストは長さ $N$ の複素 FFT のおよそ半分で済み、それ以外の奇数長では長さ $N$ の複素 FFT になる。
奇数長の最後のビンは複素数なので、実数に制限しない。
逆変換は DC と Nyquist の虚部を $\tau=\max(8\varepsilon M,\eta)$ と比べ、許容値以内なら作業領域で射影し、超えれば `InvalidInput` を返す。
時間側が共役対称で周波数側が実数の問題には `hfft` と `ihfft` を使う。
