実数の画像や体積データの DFT は、1 次元の実数列と同じく共役の対称性を持つ。
`rfftn` はこれを使って 1 本の軸だけを半分に詰め、`irfftn` はパックしたビンから実数配列を復元する。
このページは詰める軸の選び方とパックした形状、パックしたスペクトルの型と逆変換の検査、全長のスペクトルを表示のために並べ替える `fftshift_nd` を説明する。
軸ごとの分離と一括の軸は[多次元 Fourier 変換](../multidimensional-transforms/)、1 次元のパックした格納と許容値 $\tau$ は[実数 FFT と Hermite 対称性](../real-and-hermitian-transforms/)にある。

## 実数配列の詰め方

形状 $(N_0,\ldots,N_{D-1})$ の実数配列の DFT は、変換したすべての軸の波数を同時に反転すると共役になる。

$$
X_{-\mathbf k}=\overline{X_{\mathbf k}}\qquad(\text{添字は各軸で }\bmod N_d)
$$

1 本の軸を半分にすれば残りは対称性から決まるので、`rfftn(input, shape, axes, normalization)` は `axes` の最後の軸だけを $\lfloor N/2\rfloor+1$ 個に詰め、ほかの選んだ軸は全長のまま残す。
詰める軸は配列の最後の軸とは限らない。
`axes` が空なら `InvalidInput`（`Empty`）になり、その他のエラーは `fftn` と同じである。
形状 `[24, 32]` で `axes = [0, 1]` ならパックした形状は `[24, 17]`、`axes = [1, 0]` なら `[13, 32]` になる。

順変換では詰める軸を先に実数 FFT で変換し、残りの軸をパックした形状の上で複素 FFT で変換する。
逆変換は逆の順で、複素の軸を先に戻し、最後にパックした軸を実数の逆変換で戻す。
詰める軸の長さが偶数か、3・5・7 の真の倍数の奇数なら、その軸の実数 FFT は同じ長さの複素 FFT のおよそ半分の計算コストで済む。
残りの軸はパックした形状の上で変換するので、変換する列の数もおよそ半分になる。

`FftNdPlan` で `FftLayout::Real` か `Hermitian` を選んだ Plan では、パックした側を複素のビューとして `packed_shape()` の形状で渡す。
`packed_shape()` は最後に選んだ軸を $\lfloor N/2\rfloor+1$ にした形状を返す。

## HermitianSpectrumNd と逆変換

`HermitianSpectrumNd<S>` はパックしたビンの `Vec` と、実数配列の形状、変換した軸の列を一緒に所有する。

- `shape()` は実数配列の論理形状、`axes()` は変換した軸の列（最後がパックした軸）を返す。
- `bins()` と `bins_mut()` はパックした形状の行優先の順でビンを借用し、`into_vec()` は形状と軸を捨ててビンを取り出す。
- `from_vec(shape, axes, bins)` は軸の範囲（`OutOfBounds`）、空の軸の列と長さ 0 の軸（`InvalidInput`、`Empty`）、軸の重複（`InvalidInput`、`Inconsistent`）、ビンの数（`DimensionMismatch`）を調べる。
  有限性と対称性は調べない。

`irfftn` と `hfftn` は `HermitianSpectrumNd` が持つ形状と軸を使うので、軸を別の引数で渡さない。
パックした軸の座標が 0 の面（DC の面）と、偶数長での $N/2$ の面（Nyquist の面）では、パックした軸以外の選んだ軸の波数を反転した位置のビンが共役の対になる。
選ばなかった軸の添字は反転しないので、対はバッチの中で決まる。
面の中のビンがすべて実数である必要はない。
逆変換はこの対を、バッチごとの最大成分 $M$ から決めた[許容値](oxref:fft-hermitian-check) $\tau=\max(8\varepsilon M,\eta)$ で調べる。
対 $(X,Y)$ の実部の差と虚部の和が $2\tau$ を超えれば `InvalidInput`（`OutOfRange`）を返し、以内なら作業領域の中で両者の平均に射影する。
選んだ軸が 1 本だけなら、各列は 1 次元の `irfft` と同じく DC と Nyquist のビンの虚部だけを調べる。
複素の軸を戻したあと、DC と Nyquist の面に丸め誤差の上限を超える虚部が残れば `NumericalInstability`（`Breakdown`）になる。

`hfftn` と `ihfftn` は、時間側の配列が共役対称で周波数側が実数になる場合の変換で、`hfft` と `ihfft` の多次元版である。
詰め方は `rfftn` と同じである。

## fftshift と ifftshift

全長のスペクトルは零周波数を先頭に置き、正の周波数、負の周波数の順に並ぶ。
`fftshift` は 1 次元の列、`fftshift_nd(input, shape, axes)` は行優先の配列の選んだ軸を回転させ、零周波数を各軸の添字 $\lfloor N/2\rfloor$ に移す。
`ifftshift` と `ifftshift_nd` はその逆である。
値を計算し直したり位相を補正したりはせず、要素を並べ替えるだけである。

長さ $N$ の軸で、`fftshift` は $\lceil N/2\rceil$、`ifftshift` は $\lfloor N/2\rfloor$ だけ左に回転させる。
偶数長では同じ回転になるが、奇数長では違う。
長さ 5 の `[0, 1, 2, 3, 4]` は `fftshift` で `[3, 4, 0, 1, 2]` になり、もう一度 `fftshift` をかけても元に戻らず、`ifftshift` で戻る。
パックしたスペクトルは負の周波数を持たないので、`rfft` や `rfftn` の出力を並べ替えても全長のスペクトルにはならない。
`fftshift_nd` と `ifftshift_nd` は長さ 0 の軸も受け付け、軸の重複は `InvalidInput`（`Inconsistent`）、範囲外の軸は `OutOfBounds` になる。
要素の型は問わないので、添字の配列を並べ替えれば各要素の移動先が分かる。

## パックした形状と並べ替えの実験

次のセルは非対称な実数配列 $x$ を `rfftn` で変換し、パックした形状と、全長の複素 `fftn` の対応するビンとの差を調べる。
DC と Nyquist の面の共役の対のずれを、逆変換が使う許容値 $\tau=\max(8\varepsilon M,\eta)$ と比べる。
ずれと $\tau$ はセルの中で式どおりに計算した独立な値である。
`irfftn` と、`ihfftn` の後の `hfftn` で元の配列に戻ることも測る。
`rfftn` が返す `HermitianSpectrumNd` の `shape()` と `axes()` を読み、論理形状がパックした形状ではなく元の形状であることを確かめる。
`bins()` の写しを `from_vec` で同じ形状と軸に組み直して `irfftn` にかけ、元のスペクトルからの逆変換と一致しない要素の数も数える。
最後に全長のスペクトルを `fftshift_nd` で並べ替え、零周波数が移った位置と、`ifftshift_nd` で戻した配列が元と一致しない要素の数を数える。

```rust
//| id: fft-rfftn-packing
//| ref: fft-rfftn-packing
//| title: 実数配列のパックした形状と周波数の並べ替え
//| run: reactive
//| crates: [scioxide-core, scioxide-fft]
//| inputs:
//|   rows_count: {"type":"range","label":"行数 M","description":"軸 0 の長さ。","min":2,"max":12,"step":1,"value":6}
//|   cols_count: {"type":"range","label":"列数 N","description":"軸 1 の長さ。","min":2,"max":12,"step":1,"value":8}
//|   axis_order: {"type":"select","label":"変換する軸の順 axes","description":"最後の軸が詰められる。","options":["[0, 1]","[1, 0]"],"value":"[0, 1]"}
//| cases:
//|   - {"id":"odd-sizes","label":"M = 5, N = 7","description":"奇数長。Nyquist の面がなく、DC の面だけを検査する。","inputs":{"rows_count":5,"cols_count":7}}
//|   - {"id":"reversed-axes","label":"axes = [1, 0]","description":"軸 0 が詰められ、パックした形状は [4, 8] になる。","inputs":{"axis_order":"[1, 0]"}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"layout","path":"/rows/0/2","equals":1}
//|       - {"artifact":"layout","path":"/rows/0/3","equals":6}
//|       - {"artifact":"layout","path":"/rows/0/4","equals":5}
//|       - {"artifact":"layout","path":"/rows/0/5","equals":30}
//|       - {"artifact":"checks","path":"/rows/0/1","range":{"max":1e-13}}
//|       - {"artifact":"checks","path":"/rows/2/1","range":{"max":1e-13}}
//|       - {"artifact":"checks","path":"/rows/3/1","range":{"max":1e-14}}
//|       - {"artifact":"checks","path":"/rows/4/1","range":{"max":1e-14}}
//|       - {"artifact":"shift","path":"/rows/0/0","equals":3}
//|       - {"artifact":"shift","path":"/rows/0/1","equals":4}
//|       - {"artifact":"shift","path":"/rows/0/2","equals":0}
//|       - {"artifact":"spectrum","path":"/rows/0/0","equals":6}
//|       - {"artifact":"spectrum","path":"/rows/0/1","equals":8}
//|       - {"artifact":"spectrum","path":"/rows/0/3","equals":1}
//|       - {"artifact":"spectrum","path":"/rows/0/4","equals":0}
//|   - case: odd-sizes
//|     expect:
//|       - {"artifact":"layout","path":"/rows/0/4","equals":4}
//|       - {"artifact":"layout","path":"/rows/0/5","equals":20}
//|       - {"artifact":"checks","path":"/rows/3/1","range":{"max":1e-14}}
//|       - {"artifact":"shift","path":"/rows/0/0","equals":2}
//|       - {"artifact":"shift","path":"/rows/0/1","equals":3}
//|       - {"artifact":"spectrum","path":"/rows/0/0","equals":5}
//|       - {"artifact":"spectrum","path":"/rows/0/1","equals":7}
//|   - case: reversed-axes
//|     expect:
//|       - {"artifact":"layout","path":"/rows/0/2","equals":0}
//|       - {"artifact":"layout","path":"/rows/0/3","equals":4}
//|       - {"artifact":"layout","path":"/rows/0/4","equals":8}
//|       - {"artifact":"layout","path":"/rows/0/5","equals":32}
//|       - {"artifact":"checks","path":"/rows/0/1","range":{"max":1e-13}}
//|       - {"artifact":"checks","path":"/rows/3/1","range":{"max":1e-14}}
//|       - {"artifact":"spectrum","path":"/rows/0/2","equals":1}
//|       - {"artifact":"spectrum","path":"/rows/0/3","equals":0}
//|       - {"artifact":"spectrum","path":"/rows/0/4","equals":0}
use scioxide_core::Complex;
use scioxide_fft::{
    HermitianSpectrumNd, Normalization, fftn, fftshift_nd, hfftn, ifftshift_nd, ihfftn, irfftn,
    rfftn,
};

let (m, n) = (rows_count.round() as usize, cols_count.round() as usize);
let shape = [m, n];
let axes = if axis_order == "[1, 0]" {
    [1, 0]
} else {
    [0, 1]
};
let (other_axis, packed_axis) = (axes[0], axes[1]);
let norm = Normalization::Inverse;
// 非対称な実数配列（四則演算だけで作る）。
let x: Vec<f64> = (0..m * n)
    .map(|i| 1.0 / (1.0 + i as f64) + 0.5 * ((i * 7) % 5) as f64)
    .collect();
// パックしたビンは実数配列の論理形状と軸の列と一緒に HermitianSpectrumNd に入る。
let spectrum: HermitianSpectrumNd<f64> =
    rfftn(&x, &shape, &axes, norm).map_err(|e| e.to_string())?;
let mut packed_shape = shape;
packed_shape[packed_axis] = shape[packed_axis] / 2 + 1;
let packed_cols = packed_shape[1];
// 全長の複素変換と、パックした座標 (r, c) ごとに比べる。
let complex: Vec<Complex<f64>> = x.iter().map(|&v| Complex::new(v, 0.0)).collect();
let full = fftn(&complex, &shape, &[0, 1], norm).map_err(|e| e.to_string())?;
let packed_gap = spectrum
    .bins()
    .iter()
    .enumerate()
    .map(|(i, z)| (*z - full[(i / packed_cols) * n + i % packed_cols]).norm())
    .fold(0.0_f64, f64::max);
// DC と Nyquist の面で、他の軸の座標 c と (−c) mod N の対のずれを SciOxide の検査と同じ形で測る。
let bin = |packed: usize, other: usize| {
    let mut coordinate = [0, 0];
    coordinate[packed_axis] = packed;
    coordinate[other_axis] = other;
    spectrum.bins()[coordinate[0] * packed_cols + coordinate[1]]
};
let mut endpoints = vec![0];
if shape[packed_axis] % 2 == 0 {
    endpoints.push(shape[packed_axis] / 2);
}
let length = shape[other_axis];
let mut mismatch = 0.0_f64;
for &plane in &endpoints {
    for c in 0..length {
        let (p, q) = (bin(plane, c), bin(plane, (length - c) % length));
        let gap = if 2 * c % length == 0 {
            p.im.abs()
        } else {
            0.5 * (p.re - q.re).abs().max((p.im + q.im).abs())
        };
        mismatch = mismatch.max(gap);
    }
}
let maximum = spectrum
    .bins()
    .iter()
    .map(|z| z.re.abs().max(z.im.abs()))
    .fold(0.0_f64, f64::max);
let tau = (8.0 * f64::EPSILON * maximum).max(f64::from_bits(1));
let real_gap = |a: &[f64]| {
    a.iter()
        .zip(&x)
        .map(|(p, q)| (p - q).abs())
        .fold(0.0_f64, f64::max)
};
let recovered = irfftn(&spectrum, norm).map_err(|e| e.to_string())?;
// ビンだけを取り出し、同じ形状と軸で組み直してから逆変換した結果と比べる。
let rebuilt =
    HermitianSpectrumNd::from_vec(spectrum.shape(), spectrum.axes(), spectrum.bins().to_vec())
        .map_err(|e| e.to_string())?;
let rebuilt_back = irfftn(&rebuilt, norm).map_err(|e| e.to_string())?;
let rebuilt_mismatched = rebuilt_back
    .iter()
    .zip(&recovered)
    .filter(|(a, b)| a != b)
    .count();
let dual = ihfftn(&x, &shape, &axes, norm).map_err(|e| e.to_string())?;
let dual_back = hfftn(&dual, norm).map_err(|e| e.to_string())?;
// 並べ替え: 零周波数の移動先と、往復で一致しない要素の数。
let shifted = fftshift_nd(&full, &shape, &[0, 1]).map_err(|e| e.to_string())?;
// 添字の配列を同じく並べ替え、元の添字 0（零周波数）の移動先を値の一致に頼らずに求める。
let indices: Vec<usize> = (0..m * n).collect();
let moved_indices = fftshift_nd(&indices, &shape, &[0, 1]).map_err(|e| e.to_string())?;
let dc_index = moved_indices
    .iter()
    .position(|&i| i == 0)
    .ok_or("零周波数の要素が見つからない")?;
let restored = ifftshift_nd(&shifted, &shape, &[0, 1]).map_err(|e| e.to_string())?;
let mismatched = restored.iter().zip(&full).filter(|(a, b)| a != b).count();

let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let layout_columns = serde_json::json!([
    { "key": "0", "label": "行数 M", "type": "integer" },
    { "key": "1", "label": "列数 N", "type": "integer" },
    { "key": "2", "label": "パックした軸", "type": "integer" },
    { "key": "3", "label": "パックした形状の軸 0", "type": "integer" },
    { "key": "4", "label": "パックした形状の軸 1", "type": "integer" },
    { "key": "5", "label": "ビン数", "type": "integer" }
]);
emit_table_with_columns!(
    layout_columns,
    vec![(
        m,
        n,
        packed_axis,
        packed_shape[0],
        packed_shape[1],
        spectrum.bins().len()
    )],
    metadata = serde_json::json!({ "id": "layout" })
);
let spectrum_columns = serde_json::json!([
    { "key": "0", "label": "shape() の軸 0", "type": "integer" },
    { "key": "1", "label": "shape() の軸 1", "type": "integer" },
    { "key": "2", "label": "axes() の最初", "type": "integer" },
    { "key": "3", "label": "axes() の最後（パックした軸）", "type": "integer" },
    { "key": "4", "label": "from_vec で組み直した逆変換と一致しない要素数", "type": "integer" }
]);
emit_table_with_columns!(
    spectrum_columns,
    vec![(
        spectrum.shape()[0],
        spectrum.shape()[1],
        spectrum.axes()[0],
        spectrum.axes()[1],
        rebuilt_mismatched
    )],
    metadata = serde_json::json!({ "id": "spectrum" })
);
let check_columns = serde_json::json!([
    { "key": "0", "label": "量" },
    { "key": "1", "label": "値 [-]", "type": "number", "format": sci3 }
]);
emit_table_with_columns!(
    check_columns,
    vec![
        ("rfftn と fftn の対応するビンの最大差", packed_gap),
        ("DC・Nyquist 面の共役の対のずれ", mismatch),
        ("許容値 τ = max(8εM, η)", tau),
        ("irfftn(rfftn(x)) と x の最大差", real_gap(&recovered)),
        ("hfftn(ihfftn(x)) と x の最大差", real_gap(&dual_back)),
    ],
    metadata = serde_json::json!({ "id": "checks" })
);
let shift_columns = serde_json::json!([
    { "key": "0", "label": "零周波数の移動先の行", "type": "integer" },
    { "key": "1", "label": "零周波数の移動先の列", "type": "integer" },
    { "key": "2", "label": "往復で一致しない要素数", "type": "integer" }
]);
emit_table_with_columns!(
    shift_columns,
    vec![(dc_index / n, dc_index % n, mismatched)],
    metadata = serde_json::json!({ "id": "shift" })
);
```

既定の 6×8 で `axes = [0, 1]` なら、詰めるのは軸 1 で、パックした形状は `[6, 5]`、ビンは 30 個になる。
`axes = [1, 0]` に変えると軸 0 が詰められ、形状は `[4, 8]`、ビンは 32 個になる。
パックしたビンと全長の `fftn` の差は $4.4\times10^{-15}$ で、同じビンを別の経路で求めたときの丸めの違いである。
DC と Nyquist の面の共役の対のずれは $4.4\times10^{-16}$ で、許容値 $\tau=9.3\times10^{-14}$ の 200 分の 1 程度なので、`rfftn` の出力はそのまま逆変換に渡せる。
`irfftn` と、`ihfftn` の後の `hfftn` の往復の誤差はどちらも $8.9\times10^{-16}$ である。
5×7 の奇数長では Nyquist の面がなく、DC の面の対のずれはちょうど 0 になった。
`HermitianSpectrumNd` の `shape()` はパックした形状ではなく元の `[6, 8]` を返し、`axes()` は渡した軸の列をそのまま返す（`axes = [1, 0]` なら最後が軸 0）。
`from_vec` で組み直したスペクトルの逆変換は、元のスペクトルからの逆変換とすべての要素で一致する。
`fftshift_nd` は零周波数を $(\lfloor M/2\rfloor,\lfloor N/2\rfloor)$、既定では $(3,4)$、5×7 では $(2,3)$ に移し、`ifftshift_nd` で戻した配列は元とすべての要素で一致する。

## まとめ

実数配列の DFT は全軸の波数の反転で共役になるので、`rfftn` は `axes` の最後の軸だけを $\lfloor N/2\rfloor+1$ 個に詰め、パックした形状は軸の順で変わる。
`HermitianSpectrumNd` はパックしたビンと論理形状と軸を一緒に持ち、`irfftn` と `hfftn` はそれを使って元の形状を決める。
逆変換は DC と Nyquist の面の共役の対を許容値 $2\tau$ で調べ、範囲内なら射影し、超えれば `InvalidInput` を返す。
`fftshift_nd` と `ifftshift_nd` は全長のスペクトルの並べ替えだけを行い、奇数長では互いに違う回転になる。
