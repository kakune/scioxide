連続時間の信号を等間隔に標本化して DFT にかけると、結果には折り返し（エイリアシング）とスペクトル漏れが現れる。
このページでは二つの現象を導き、ビンの番号を物理的な周波数に対応させる関数を示す。
DFT の定義、符号、正規化と、ビンの値を振幅に直す係数は [DFT の定義と正規化](../dft-sampling-and-normalization/) で扱う。
ここでは長さを $N$、標本の間隔を $\Delta t$ と書く。

## 標本化定理と折り返し

連続信号 $x(t)$ を間隔 $\Delta t$（標本化周波数 $f_s = 1/\Delta t$）で標本化する操作は、Dirac の櫛 $p(t) = \sum_{n=-\infty}^{\infty}\delta(t - n\Delta t)$ との積 $x_p(t) = x(t)p(t)$ と書ける。
Poisson の和公式により、櫛の Fourier 変換は周波数領域の櫛になる。

$$
\mathcal{F}\{p\}(f) = \frac{1}{\Delta t}\sum_{m=-\infty}^{\infty}\delta(f - m f_s)
$$

畳み込み定理から、標本化した信号のスペクトルは元のスペクトル $X(f)$ を $f_s$ ごとに複製して重ねたものになる。

$$
X_p(f) = \frac{1}{\Delta t}\sum_{m=-\infty}^{\infty} X(f - m f_s)
$$

$x(t)$ が Nyquist 周波数 $f_{\mathrm{Nyq}} = f_s/2$ 以上の成分を含むと、隣の複製が区間 $[-f_s/2, f_s/2]$ に入り込んで重なる。
逆に、$x(t)$ の成分がすべて $\lvert f\rvert < f_s/2$ にあれば複製は重ならず、標本から元の信号を復元できる（標本化定理）。
格子点の上では

$$
e^{2\pi i (f + m f_s) n\Delta t} = e^{2\pi i f n\Delta t}\, e^{2\pi i mn} = e^{2\pi i f n\Delta t} \qquad (m, n \in \mathbb{Z})
$$

なので、周波数 $f$ と $f + m f_s$ の正弦波は同じ標本値をとり、標本だけからは区別できない。
実信号では、周波数 $f_0$ の成分は $\lvert f_0 - m f_s\rvert$（$m$ は $f_0/f_s$ に最も近い整数）の位置に現れる。

## 有限の観測区間とスペクトル漏れ

長さ $N$ の区間を切り出すことは、矩形ウインドウ $w_n = 1$（$0 \le n < N$）を掛けることと同じである。
観測区間に $\alpha$ 周期を含む複素正弦波 $x_n = e^{2\pi i\alpha n/N}$ の DFT は、等比数列の和から

$$
X_k = \sum_{n=0}^{N-1} e^{2\pi i(\alpha - k)n/N}
= e^{i\pi(\alpha - k)(N-1)/N}\,\frac{\sin(\pi(\alpha - k))}{\sin(\pi(\alpha - k)/N)}
$$

となる。
この核を Dirichlet 核（離散 sinc 関数）と呼ぶ。

1. $\alpha$ が整数のときは、$k=\alpha\bmod N$ のビンだけが $N$ になり、他の整数ビンでは分子 $\sin(\pi\cdot\text{整数})$ が 0 になる。
2. $\alpha$ が整数でないときは、どの整数ビンでも分子が 0 にならず、エネルギーが周りのビンへ広がる。
   これをスペクトル漏れと呼ぶ。
   ビンの中間（$\alpha - k = 1/2$）では、最も近いビンの絶対値が $\lvert 1/\sin(\pi/(2N))\rvert \approx 2N/\pi$ に下がる。
   漏れを窓関数で抑える実験は [非整数周期とスペクトル漏れ](../../examples/spectral-leakage/) にある。

## 周波数軸とビンの並び

$X_k$ は $k$ について周期 $N$ を持つので、ビン $k \ge N/2$ は負の周波数のビン $k - N$ と同じものである。
標本間隔を $d = \Delta t$ とすると、ビン $k$ の物理的な周波数は $k < N/2$ なら $k/(Nd)$、$k \ge N/2$ なら $(k-N)/(Nd)$ で、ビンの間隔は $\Delta f = 1/(Nd) = f_s/N$ である。
ゼロパディングしない場合、この間隔は観測時間 $T = Nd$ で決まる。
観測した $N$ 点を長さ $L>N$ にゼロパディングすると、評価の格子は $f_s/L$ に細かくなるが、観測時間とウインドウの主ローブの幅は変わらない。

周波数軸は次の 4 つの関数で作る。
周波数の単位は $d$ の単位の逆数で、$d$ を秒で与えれば Hz になる。

| 関数 | 返す列 | 長さ |
|---|---|---|
| `fftfreq(n, d)` | $[0, 1, \dots, \lceil n/2\rceil - 1, -\lfloor n/2\rfloor, \dots, -1]/(nd)$ | $n$ |
| `rfftfreq(n, d)` | $[0, 1, \dots, \lfloor n/2\rfloor]/(nd)$ | $\lfloor n/2\rfloor + 1$ |
| `fftshift(x)` | `x` を左へ $\lceil n/2\rceil$ 個回転した列。ビン 0 は添字 $\lfloor n/2\rfloor$ に移る | $n$ |
| `ifftshift(x)` | `x` を左へ $\lfloor n/2\rfloor$ 個回転した列。`fftshift` の逆 | $n$ |

偶数の $n$ では、Nyquist のビン $n/2$ を `fftfreq` は負の周波数 $-1/(2d)$ として、`rfftfreq` は正の周波数 $+1/(2d)$ として返す。
奇数の $n$ では二つの回転の量が異なるので、`fftshift` を戻すには必ず `ifftshift` を使う。
$d < 0$ を与えると符号がすべて反転する。
各値は整数 $k$ から $(k/n)/d$ として 1 回で計算するので、格子に丸め誤差が累積しない。

$n = 0$ と $d = 0$ は `InvalidInput`、NaN や無限大の $d$ は `NonFinite` になる。
$1/(nd)$ か周波数が有限の範囲を外れるか 0 に丸められると `NumericalInstability` になる。
$n$ や添字がスカラー型で正確に表せないとき、隣り合う周波数をスカラー型が区別できないときは `ScalarConversion` になる。
`fftshift` と `ifftshift` は任意の `Clone` な要素の列を受け取り、空の列には空の列を返す。
多次元配列の軸ごとの移動（`fftshift_nd`、`ifftshift_nd`）は [fftshift と ifftshift](oxref:fft-frequency-shift) で扱う。

次のセルは長さ $n$ と標本間隔 $d$ から 4 つの関数の出力を並べる。
最後の列は上の表の式を手で書いた独立な検算である。
$n$ を偶数と奇数で切り替え、Nyquist のビンの符号と回転の量の違いを確かめる。

```rust
//| id: fft-frequency-order
//| ref: fft-frequency-order
//| title: fftfreq・rfftfreq・fftshift・ifftshift の並びを長さの偶奇で比べる
//| run: reactive
//| crates: [scioxide-fft]
//| inputs:
//|   length: {"type":"range","label":"長さ n","description":"偶数では Nyquist のビンが現れ、奇数では fftshift と ifftshift の回転の量が異なる。","min":1,"max":12,"step":1,"value":6}
//|   spacing: {"type":"range","label":"標本間隔 d [s]","description":"周波数はすべて 1/(n d) [Hz] の整数倍になる。","min":0.25,"max":2,"step":0.25,"value":0.5}
//| cases:
//|   - {"id":"odd-length","label":"n = 5","description":"Nyquist のビンがなく、fftshift は 3 個、ifftshift は 2 個回転する。","inputs":{"length":5}}
//|   - {"id":"single-sample","label":"n = 1","description":"どの関数も 0 だけを返す。","inputs":{"length":1}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"frequency-order","path":"/rows/3/1","approx":{"value":-1,"atol":1e-15}}
//|       - {"artifact":"frequency-order","path":"/rows/0/2","approx":{"value":-1,"atol":1e-15}}
//|       - {"artifact":"frequency-order","path":"/rows/3/4","approx":{"value":1,"atol":1e-15}}
//|       - {"artifact":"frequency-order","path":"/rows/1/5","approx":{"value":0.3333333333333333,"atol":1e-15}}
//|   - case: odd-length
//|     expect:
//|       - {"artifact":"frequency-order","path":"/rows/0/2","approx":{"value":-0.8,"atol":1e-15}}
//|       - {"artifact":"frequency-order","path":"/rows/2/2","approx":{"value":0,"atol":1e-15}}
//|       - {"artifact":"frequency-order","path":"/rows/3/4","equals":null}
//|   - case: single-sample
//|     expect:
//|       - {"artifact":"frequency-order","path":"/rows/0/1","range":{"min":0,"max":0}}
use scioxide_fft::{fftfreq, fftshift, ifftshift, rfftfreq};

let n = length.round() as usize;
let d = spacing;
let full = fftfreq(n, d).map_err(|e| e.to_string())?;
let packed = rfftfreq(n, d).map_err(|e| e.to_string())?;
let centered = fftshift(&full).map_err(|e| e.to_string())?;
let restored = ifftshift(&centered).map_err(|e| e.to_string())?;
// 独立検算: k < ⌈n/2⌉ なら k/(n d)、それ以外は (k − n)/(n d)
let by_hand = |k: usize| {
    let signed = if k < n.div_ceil(2) {
        k as f64
    } else {
        k as f64 - n as f64
    };
    signed / (n as f64 * d)
};
let rows: Vec<(usize, f64, f64, f64, Option<f64>, f64)> = (0..n)
    .map(|k| {
        (
            k,
            full[k],
            centered[k],
            restored[k],
            packed.get(k).copied(),
            by_hand(k),
        )
    })
    .collect();
let fixed4 = serde_json::json!({ "fractionDigits": 4 });
let columns = serde_json::json!([
    { "key": "0", "label": "添字 k", "type": "integer" },
    { "key": "1", "label": "fftfreq [Hz]", "type": "number", "format": fixed4 },
    { "key": "2", "label": "fftshift 後 [Hz]", "type": "number", "format": fixed4 },
    { "key": "3", "label": "ifftshift で戻した値 [Hz]", "type": "number", "format": fixed4 },
    { "key": "4", "label": "rfftfreq [Hz]", "type": "number", "format": fixed4, "nullText": "-" },
    { "key": "5", "label": "検算 (k または k − n)/(n d) [Hz]", "type": "number", "format": fixed4 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "frequency-order" })
);
```

既定の $n = 6$、$d = 0.5$ s では、`fftfreq` の添字 3 が $-1$ Hz（Nyquist のビン）になり、`rfftfreq` の添字 3 は $+1$ Hz になる。
`fftshift` 後の列は $-1$ Hz から昇順に並び、`ifftshift` で元の並びに戻る。
$n = 5$ では Nyquist のビンがなく、`fftshift` 後の先頭は $-2/(5 \cdot 0.5) = -0.8$ Hz、ビン 0 は添字 $\lfloor 5/2\rfloor = 2$ に来る。

## 折り返しと漏れの観測

次のセルは標本化周波数 64 Hz で 64 点（観測時間 1 s、ビンの間隔 1 Hz）を標本化した正弦波を `rfft` で変換し、片側の振幅を `rfftfreq` の周波数軸に描く。
片側の振幅は無尺度のビンの絶対値に $2/N$（DC と Nyquist のビンは $1/N$）を掛けた値である（[物理振幅への換算](oxref:fft-physical-amplitude)）。
信号周波数を Nyquist 周波数 32 Hz より上の整数値に動かすと、最大のビンが予測した折り返しの周波数 $\lvert f_0 - m f_s\rvert$ に現れる。
整数でない周波数では、ピークの両側に漏れが現れる。
入力の生成には f64 の `sin` を使い、予測する折り返しの周波数は手計算の独立な検算である。

```rust
//| id: fft-sampling-alias
//| ref: fft-sampling-alias
//| title: 信号周波数を Nyquist 周波数の前後へ動かす
//| run: reactive
//| crates: [scioxide-fft]
//| inputs:
//|   signal_frequency_hz: {"type":"range","label":"信号周波数 [Hz]","description":"標本化周波数 64 Hz の正弦波の周波数を変える。","min":1,"max":55,"step":0.5,"value":12}
//| cases:
//|   - {"id":"alias-40hz","label":"40 Hz","description":"Nyquist 周波数を超え、24 Hz のビンに振幅 1 で現れる。","inputs":{"signal_frequency_hz":40}}
//|   - {"id":"half-bin","label":"12.5 Hz","description":"ビンの中間にあり、最大のビンの振幅が 2/π の近くまで下がる。","inputs":{"signal_frequency_hz":12.5}}
//|   - {"id":"nyquist","label":"32 Hz","description":"すべての標本が sin(πn) = 0 になり、信号を観測できない。","inputs":{"signal_frequency_hz":32}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"alias","path":"/rows/0/1","approx":{"value":12,"atol":1e-12}}
//|       - {"artifact":"alias","path":"/rows/0/2","approx":{"value":12,"atol":1e-12}}
//|       - {"artifact":"alias","path":"/rows/0/3","approx":{"value":1,"atol":1e-12}}
//|   - case: alias-40hz
//|     expect:
//|       - {"artifact":"alias","path":"/rows/0/1","approx":{"value":24,"atol":1e-12}}
//|       - {"artifact":"alias","path":"/rows/0/2","approx":{"value":24,"atol":1e-12}}
//|       - {"artifact":"alias","path":"/rows/0/3","approx":{"value":1,"atol":1e-12}}
//|   - case: half-bin
//|     expect:
//|       - {"artifact":"alias","path":"/rows/0/3","approx":{"value":0.6425,"atol":1e-3}}
//|   - case: nyquist
//|     expect:
//|       - {"artifact":"alias","path":"/rows/0/3","range":{"max":1e-12}}
use scioxide_fft::{Normalization, rfft, rfftfreq};

// 標本化周波数 64 Hz、64 点（観測時間 1 s、ビンの間隔 1 Hz）
let sample_rate = 64.0_f64;
let count = 64_usize;
// 入力の生成には f64 の sin を使う
let samples: Vec<f64> = (0..count)
    .map(|n| (2.0 * std::f64::consts::PI * signal_frequency_hz * n as f64 / sample_rate).sin())
    .collect();

// 無尺度で変換し、片側の振幅には 2/N（DC と Nyquist は 1/N）を掛ける
let spectrum = rfft(&samples, Normalization::Unscaled).map_err(|e| e.to_string())?;
// ビン k の周波数 k/(N Δt) [Hz]
let frequencies = rfftfreq(count, 1.0 / sample_rate).map_err(|e| e.to_string())?;
let curve: Vec<[f64; 2]> = spectrum
    .bins()
    .iter()
    .zip(&frequencies)
    .enumerate()
    .map(|(k, (value, &f))| {
        let scale = if k == 0 || 2 * k == count { 1.0 } else { 2.0 };
        [f, scale * value.norm() / count as f64]
    })
    .collect();

// 片側の振幅が最大のビン（等しければ高い周波数を残す）
let peak = curve
    .iter()
    .fold(curve[0], |best, &p| if p[1] >= best[1] { p } else { best });
// 独立検算: 予測する折り返しの周波数 |f0 − m fs|（m は f0/fs に最も近い整数）
let expected_alias =
    (signal_frequency_hz - (signal_frequency_hz / sample_rate).round() * sample_rate).abs();

emit_line_chart!(
    &vec![serde_json::json!({ "name": "片側振幅", "points": curve })],
    options = &serde_json::json!({
        "xLabel": "周波数 [Hz]",
        "yLabel": "片側振幅 [-]",
        "xMin": 0.0,
        "xMax": 32.0,
        "yMin": 0.0,
        "yMax": 1.05,
        "annotations": [
            { "kind": "line", "axis": "x", "value": sample_rate / 2.0, "label": "Nyquist 周波数" },
            { "kind": "line", "axis": "x", "value": expected_alias, "label": "予測する折り返し" }
        ]
    })
);
let fixed1 = serde_json::json!({ "fractionDigits": 1 });
let fixed4 = serde_json::json!({ "fractionDigits": 4 });
let columns = serde_json::json!([
    { "key": "0", "label": "信号周波数 [Hz]", "type": "number", "format": fixed1 },
    { "key": "1", "label": "予測する折り返し [Hz]", "type": "number", "format": fixed1 },
    { "key": "2", "label": "最大のビン [Hz]", "type": "number", "format": fixed1 },
    { "key": "3", "label": "その片側振幅 [-]", "type": "number", "format": fixed4 },
    { "key": "4", "label": "ビンの間隔 [Hz]", "type": "number", "format": fixed1 }
]);
emit_table_with_columns!(
    columns,
    vec![(
        signal_frequency_hz,
        expected_alias,
        peak[0],
        peak[1],
        frequencies[1] - frequencies[0],
    )],
    metadata = serde_json::json!({ "id": "alias" })
);
```

既定の 12 Hz では 12 Hz のビンだけが振幅 1 になる。
40 Hz を入れると $\lvert 40 - 64\rvert = 24$ Hz のビンに振幅 1 が現れる。
この標本列は符号を反転した 24 Hz の正弦波と一致するので、片側振幅だけでは両者を区別できない。
12.5 Hz のような半整数では、最大のビン（12 Hz）の振幅が 0.6425 に下がり、周りのビンに漏れが広がる。
複素正弦波 1 本の Dirichlet 核から見積もった値 $2/\pi \approx 0.637$ に近く、残りの差は負の周波数の成分からの漏れである。
32 Hz ちょうどでは $\sin(\pi n)$ がすべての標本で 0 に近くなり、信号そのものを観測できない。
このときの最大のビンは丸め誤差の大きさ（$4\times10^{-15}$ 程度）しか持たない。

## まとめ

標本化はスペクトルを $f_s$ ごとに複製し、Nyquist 周波数を超える成分は $\lvert f_0 - m f_s\rvert$ に折り返すので、標本化の前に帯域を $f_s/2$ 未満に制限する。
観測区間に整数周期が入らない正弦波は Dirichlet 核に従って周りのビンへ漏れ、ビンの中間では最大のビンの振幅が約 $2/\pi$ 倍に下がる。
ビンの間隔 $f_s/N$ は観測時間で決まり、ゼロパディングは評価の格子を細かくするだけで分解能を上げない。
周波数軸は `fftfreq` と `rfftfreq` で作り、偶数長の Nyquist のビンの符号と、奇数長での `fftshift` と `ifftshift` の回転の量の違いに注意する。
