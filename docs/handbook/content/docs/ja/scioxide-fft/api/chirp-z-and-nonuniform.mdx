## チャープ Z と周波数帯の拡大

| [`CztPlanSpec`](https://docs.rs/scioxide-fft/0.1.0/scioxide_fft/struct.CztPlanSpec.html) | 構造体 | チャープ Z 変換の Plan の仕様 | `new(n, m, contour, normalization)`、`with_limits`、`with_execution_policy`、`with_backend_strategy`。$n$ と $m$ の検査は準備のときに行う | [Plan、作業領域、リソースの上限](oxref:fft-czt-plan) | [関数 czt と Plan、軸に沿った実行、バイト数の上限](oxref:fft-czt-function-axis-limits)、[輪郭の半径を変えて減衰振動の山の幅を測る](oxref:fft-czt-damped-mode)、[輪郭と大きさによるアルゴリズムの選択と誤差](oxref:fft-czt-algorithm-choice) |

## 非一様 Fourier 変換

| 項目 | 種別 | 役割 | 仕様の要点 | 解説節 | 実行例 |
|---|---|---|---|---|---|
| [`nufft_type1`](https://docs.rs/scioxide-fft/0.1.0/scioxide_fft/fn.nufft_type1.html) | 関数 | 非一様な点から整数モードへの和を一度だけ計算する | 引数は `(points, input, modes, direction, normalization, accuracy)` で、入力は実数か複素数。点は形 `[点の数, 次元]` のビュー、モードは各軸で $-\lfloor N/2\rfloor$ から昇順の行優先。`Forward` は指数の符号 $-1$。過標本化率は 2 で、リソースの上限を課さない。パックした入力は `InvalidInput`（`UnsupportedConfiguration`）、範囲外の `accuracy` は `InvalidInput`（`OutOfRange`）、モード数 0 は `InvalidInput`、形の不一致は `DimensionMismatch`、非有限値は `NonFinite`、丸めの推定より小さい `accuracy` は `NumericalInstability` | [3 つの型と符号・尺度](oxref:fft-nufft-types)、[Plan、診断、リソースの上限](oxref:fft-nufft-plan)、[型 3 とリソースの上限の確認](oxref:fft-nufft-type3-check) | [型 3 の直接和との比較、関数と Plan の一致、診断値と上限](oxref:fft-nufft-type3-limits)、[型 1 のモードの並びと直接和、型 2 との随伴の恒等式](oxref:fft-nufft-type1-type2-adjoint) |
| [`nufft_type2`](https://docs.rs/scioxide-fft/0.1.0/scioxide_fft/fn.nufft_type2.html) | 関数 | 整数モードから非一様な点への和を一度だけ計算する | 引数の順とエラーは `nufft_type1` と同じで、入力はモードの係数。Fourier 和の評価であり、型 1 の逆問題は解かない | [3 つの型と符号・尺度](oxref:fft-nufft-types)、[直接和と随伴の恒等式による確認](oxref:fft-nufft-adjoint-check) | [型 1 のモードの並びと直接和、型 2 との随伴の恒等式](oxref:fft-nufft-type1-type2-adjoint) |
| [`nufft_type3`](https://docs.rs/scioxide-fft/0.1.0/scioxide_fft/fn.nufft_type3.html) | 関数 | 非一様な点から任意の角周波数への和を一度だけ計算する | 引数は `(points, input, frequencies, direction, normalization, accuracy)` で、入力は実数か複素数。点と周波数は同じ次元の二階のビューで、周波数は座標の単位あたりのラジアン。エラーは `nufft_type1` と同じ（モード数の検査はない） | [型 3 とリソースの上限の確認](oxref:fft-nufft-type3-check)、[3 つの型と符号・尺度](oxref:fft-nufft-types) | [型 3 の直接和との比較、関数と Plan の一致、診断値と上限](oxref:fft-nufft-type3-limits) |
| [`NufftTransform`](https://docs.rs/scioxide-fft/0.1.0/scioxide_fft/enum.NufftTransform.html) | 列挙型 | 和の型と幾何 | `Type1 { points, modes }`、`Type2 { points, modes }`、`Type3 { points, frequencies }`。ビューとモード数を借用する | [3 つの型と符号・尺度](oxref:fft-nufft-types) | [型 1 のモードの並びと直接和、型 2 との随伴の恒等式](oxref:fft-nufft-type1-type2-adjoint)、[型 3 の直接和との比較、関数と Plan の一致、診断値と上限](oxref:fft-nufft-type3-limits)、[不規則な観測時刻の Fourier 和を型 3 で求め、直接和と比べる](oxref:fft-nufft-direct-sum)、[型 1 NUFFT による不規則観測の Fourier 和と直接和の比較](oxref:fft-nonuniform-periodogram) |
| [`NufftPlanSpec`](https://docs.rs/scioxide-fft/0.1.0/scioxide_fft/struct.NufftPlanSpec.html) | 構造体 | 非一様 Fourier 変換の仕様 | `new(direction, normalization, accuracy)`、`with_limits`、`with_oversampling`（既定 2）、`with_execution_policy`、`with_backend_strategy`。`accuracy` は入力の 1 ノルムに対する出力の最大誤差の要求で、準備のときに $0 < \epsilon < 1$ と過標本化率 2 以上を検査する（非有限値は `NonFinite`、範囲外は `InvalidInput`） | [3 つの型と符号・尺度](oxref:fft-nufft-types)、[Plan、診断、リソースの上限](oxref:fft-nufft-plan)、[Kaiser–Bessel 核と過標本格子](oxref:fft-nufft-kernel) | [型 1 のモードの並びと直接和、型 2 との随伴の恒等式](oxref:fft-nufft-type1-type2-adjoint)、[型 3 の直接和との比較、関数と Plan の一致、診断値と上限](oxref:fft-nufft-type3-limits)、[不規則な観測時刻の Fourier 和を型 3 で求め、直接和と比べる](oxref:fft-nufft-direct-sum)、[型 1 NUFFT による不規則観測の Fourier 和と直接和の比較](oxref:fft-nonuniform-periodogram) |
| [`NufftPlan`](https://docs.rs/scioxide-fft/0.1.0/scioxide_fft/struct.NufftPlan.html) | 構造体 | 非一様 Fourier 変換の Plan | `new(transform, spec)`。丸めの推定 $E_r$ より小さい要求は `NumericalInstability`、`NufftLimits` を超えると `ResourceLimit`。`execute_into(input, output, &mut workspace, scope)` は作用素の評価を 1 回数え、出力が複素数でなければ `InvalidInput`（`UnsupportedConfiguration`）。`execute_axis_into` は列が一つ以上あるとき 1 回数える。失敗時は出力を変えない。随伴は `AdjointOperator` で作用させる | [Plan、診断、リソースの上限](oxref:fft-nufft-plan)、[3 つの型と符号・尺度](oxref:fft-nufft-types) | [型 1 のモードの並びと直接和、型 2 との随伴の恒等式](oxref:fft-nufft-type1-type2-adjoint)、[型 3 の直接和との比較、関数と Plan の一致、診断値と上限](oxref:fft-nufft-type3-limits)、[不規則な観測時刻の Fourier 和を型 3 で求め、直接和と比べる](oxref:fft-nufft-direct-sum)、[型 1 NUFFT による不規則観測の Fourier 和と直接和の比較](oxref:fft-nonuniform-periodogram) |
| [`NufftLimits`](https://docs.rs/scioxide-fft/0.1.0/scioxide_fft/struct.NufftLimits.html) | 構造体 | 準備・作業領域・格子・拡散・核の幅の上限 | `preparation_bytes`、`workspace_bytes`、`grid_points`、`stencil_visits`、`kernel_support`（既定は `usize::MAX`）。準備は確保の前にすべてを検査して超えれば `ResourceLimit` を返し、上限を緩めない | [Plan、診断、リソースの上限](oxref:fft-nufft-plan)、[型 3 とリソースの上限の確認](oxref:fft-nufft-type3-check) | [型 3 の直接和との比較、関数と Plan の一致、診断値と上限](oxref:fft-nufft-type3-limits) |
