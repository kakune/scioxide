| [`RealTransformPlan`](https://docs.rs/scioxide-fft/0.1.0/scioxide_fft/struct.RealTransformPlan.html) | 構造体 | 一次元の DCT・DST の Plan | 8 種類の定義の和、往復係数、`Orthonormal` の端点の重みを rustdoc に持つ。DCT-I と DST-I は長さ $2(n-1)$ と $2(n+1)$ の実数 FFT、II・III・IV は偶数長で長さ $n/2$ の複素 FFT、奇数長で長さ $n$ の実数 FFT を使い、$O(n\log n)$。準備は長さ 0 と長さ 1 の DCT-I を `InvalidInput` とする。`execute_into(input, output, scratch, context)` は実数のスライスを受け取り、確保しない | [計アルゴリズムと API](oxref:fft-dct-api) | [8 つの型の定義の和・往復の係数・直交性の照合](oxref:fft-dct-dst-conventions)、[8 つの型の核が境界条件で閉じた 2 階差分の固有ベクトルになるかを測る](oxref:fft-dct-dst-difference-eigenvectors) |

## 多次元 DCT・DST

| 項目 | 種別 | 役割 | 仕様の要点 | 解説節 | 実行例 |
|---|---|---|---|---|---|
| [`dctn`](https://docs.rs/scioxide-fft/0.1.0/scioxide_fft/fn.dctn.html) | 関数 | 選んだ軸ごとに型を指定する DCT | 行優先にパックしたスライス、形状、軸、型を受け取る。`types[i]` が `axes[i]` の順変換の型で、選ばない軸は独立なバッチ。形状の要素数の桁あふれは `SizeOverflow`、スライスの長さが要素数と違うか型と軸の数が違えば `DimensionMismatch`、範囲外の軸は `OutOfBounds`、重複・長さ 0 の選んだ軸・長さ 1 の DCT-I の軸は `InvalidInput` | [一括関数と Plan](oxref:fft-real-transform-nd-workspace)、[DCT と DST を混ぜた Plan と作業領域の照合](oxref:fft-real-transform-nd-check)、[計アルゴリズムと API](oxref:fft-dct-api) | [軸ごとに DCT と DST を混ぜる Plan と作業領域の要件](oxref:fft-nd-mixed-real-transforms)、[DCT 係数の打切りと画像の復元](oxref:fft-dct-image-compression) |
| [`idctn`](https://docs.rs/scioxide-fft/0.1.0/scioxide_fft/fn.idctn.html) | 関数 | `dctn` の逆 | 順変換の型を渡す。往復を元の尺度にするには `Unscaled` 以外の同じ正規化を使う | [計アルゴリズムと API](oxref:fft-dct-api)、[一括関数と Plan](oxref:fft-real-transform-nd-workspace) | [DCT 係数の打切りと画像の復元](oxref:fft-dct-image-compression) |
| [`dstn`](https://docs.rs/scioxide-fft/0.1.0/scioxide_fft/fn.dstn.html) | 関数 | 選んだ軸ごとに型を指定する DST | 引数とエラーは `dctn` と同じ（長さ 1 の軸も受け付ける） | [DCT と DST を混ぜた Plan と作業領域の照合](oxref:fft-real-transform-nd-check)、[一括関数と Plan](oxref:fft-real-transform-nd-workspace)、[計アルゴリズムと API](oxref:fft-dct-api) | [軸ごとに DCT と DST を混ぜる Plan と作業領域の要件](oxref:fft-nd-mixed-real-transforms) |
| [`idstn`](https://docs.rs/scioxide-fft/0.1.0/scioxide_fft/fn.idstn.html) | 関数 | `dstn` の逆 | 順変換の型を渡す。往復を元の尺度にするには `Unscaled` 以外の同じ正規化を使う | [DCT と DST を混ぜた Plan と作業領域の照合](oxref:fft-real-transform-nd-check)、[計アルゴリズムと API](oxref:fft-dct-api)、[一括関数と Plan](oxref:fft-real-transform-nd-workspace) | [軸ごとに DCT と DST を混ぜる Plan と作業領域の要件](oxref:fft-nd-mixed-real-transforms) |
| [`RealTransformNdPlanSpec`](https://docs.rs/scioxide-fft/0.1.0/scioxide_fft/struct.RealTransformNdPlanSpec.html) | 構造体 | 多次元の DCT・DST の Plan の仕様 | `new(shape, axes, types, direction, normalization)` は引数を複製し、確保の失敗だけを返す。軸ごとに `RealTransformKind` を選べる。検査は準備のときに行う | [一括関数と Plan](oxref:fft-real-transform-nd-workspace) | [軸ごとに DCT と DST を混ぜる Plan と作業領域の要件](oxref:fft-nd-mixed-real-transforms) |
| [`RealTransformNdPlan`](https://docs.rs/scioxide-fft/0.1.0/scioxide_fft/struct.RealTransformNdPlan.html) | 構造体 | 多次元の DCT・DST の Plan | 選んだ軸ごとに一次元の DCT・DST を順に作用させる。演算量は $O(V\sum_i\log n_i)$。`RealTransformNdWorkspace` を使い、実数の `NdView`・`NdViewMut` を受け取る。結果を作業領域で作ってから書くので、失敗したときは出力を変えない。`execute_in_place` も持つ | [一括関数と Plan](oxref:fft-real-transform-nd-workspace)、[計アルゴリズムと API](oxref:fft-dct-api)、[DCT と DST を混ぜた Plan と作業領域の照合](oxref:fft-real-transform-nd-check) | [軸ごとに DCT と DST を混ぜる Plan と作業領域の要件](oxref:fft-nd-mixed-real-transforms) |
