## 複素 Fourier 変換

| 項目 | 種別 | 役割 | 仕様の要点 | 解説節 | 実行例 |
|---|---|---|---|---|---|
| [`fft`](https://docs.rs/scioxide-fft/0.1.0/scioxide_fft/fn.fft.html) | 関数 | 複素数の列の順変換 | 出力は入力と同じ長さで、`fftfreq` の順に並ぶ。長さの素因数が 2・3・5・7 だけなら混合基数の Cooley–Tukey、それ以外は Rader か Bluestein の Plan を内部で準備し、どの長さも $O(n\log n)$。空の入力は `InvalidInput`（`Empty`）、非有限値は `NonFinite`、表現できない出力は `NumericalInstability`（`Overflow`）、確保の失敗は `AllocationFailure` | [DFT の定義と逆変換](oxref:fft-dft-definition)、[アルゴリズムの選択規則](oxref:fft-algorithm-selection)、[Plan の準備と所有](oxref:fft-plan-preparation) | [FFT による相互相関を signal の correlate と照合する](oxref:fft-correlation-lag-order)、[4 通りの正規化の倍率と Parseval の比を測る](oxref:fft-normalization-parseval)、[2 次元 FFT と軸ごとの 1 次元 FFT の照合](oxref:fft-2d-separable)、[パックした変換と全長の複素変換の一致](oxref:fft-hermitian-duality) |
| [`ifft`](https://docs.rs/scioxide-fft/0.1.0/scioxide_fft/fn.ifft.html) | 関数 | 複素数の列の逆変換 | 指数の符号が正の和を計算し、`Normalization` の逆方向の係数を掛ける。`Unscaled` 以外の同じ正規化なら `ifft(fft(x))` は丸め誤差の範囲で `x` に戻る。エラーは `fft` と同じ | [DFT の定義と逆変換](oxref:fft-dft-definition)、[正規化と Parseval の等式](oxref:fft-normalization-conventions)、[離散の解析信号の重み](oxref:fft-analytic-signal-discrete) | [rfft と ifft で組み立てた解析信号を signal の hilbert と照合する](oxref:fft-analytic-signal-weights)、[FFT による相互相関を signal の correlate と照合する](oxref:fft-correlation-lag-order)、[4 通りの正規化の倍率と Parseval の比を測る](oxref:fft-normalization-parseval)、[パックした変換と全長の複素変換の一致](oxref:fft-hermitian-duality) |

## 実数 Fourier 変換

|---|---|---|---|---|---|
| [`rfft`](https://docs.rs/scioxide-fft/0.1.0/scioxide_fft/fn.rfft.html) | 関数 | 実数の列から非負の周波数のパックしたビンへ | $\lfloor n/2\rfloor + 1$ 個のビンと論理長 $n$ を `HermitianSpectrum` で返す。詰めても正規化の係数は変わらない。空の入力は `InvalidInput`（`Empty`）、非有限値は `NonFinite`、表現できない出力は `NumericalInstability`（`Overflow`） | [実数列のスペクトルと Hermite 対称性](oxref:fft-hermitian-symmetry)、[rfft と irfft の計アルゴリズム](oxref:fft-real-transforms)、[ゼロパディングの長さ](oxref:fft-zero-padding) | [rfft と ifft で組み立てた解析信号を signal の hilbert と照合する](oxref:fft-analytic-signal-weights)、[ゼロパディングの有無で FFT 畳み込みと直接和を比べる](oxref:fft-convolution-delay)、[実数 FFT の往復誤差と Hermite 対称性の許容値](oxref:fft-real-hermitian-invariants)、[パックした変換と全長の複素変換の一致](oxref:fft-hermitian-duality) |
| [`irfft`](https://docs.rs/scioxide-fft/0.1.0/scioxide_fft/fn.irfft.html) | 関数 | パックしたビンから論理長の実数列へ | DC と偶数長の Nyquist のビンの虚部が許容 $\max(8\varepsilon M, \eta)$ を超えると `InvalidInput`。許容内の虚部は作業領域の写しで 0 にし、入力は変えない。非有限値は `NonFinite`、桁あふれは `NumericalInstability`（`Overflow`）。奇数長の一部では内部の丸めの検査の失敗が `NumericalInstability`（`Breakdown`）になる | [rfft と irfft の計アルゴリズム](oxref:fft-real-transforms)、[Hermite 対称性の検査](oxref:fft-hermitian-check)、[ゼロパディングの長さ](oxref:fft-zero-padding) | [ゼロパディングの有無で FFT 畳み込みと直接和を比べる](oxref:fft-convolution-delay)、[実数 FFT の往復誤差と Hermite 対称性の許容値](oxref:fft-real-hermitian-invariants)、[基数と桁数を変えた FFT 乗算の係数誤差](oxref:fft-integer-multiplication)、[実数 FFT の往復と DC のビンの対称性の検査](oxref:fft-api-real-roundtrip) |
| [`hfft`](https://docs.rs/scioxide-fft/0.1.0/scioxide_fft/fn.hfft.html) | 関数 | Hermite 対称な標本のパックした半分から実数のスペクトルへ | 論理長を `HermitianSpectrum` から読み、指数の符号が負の和を計算する。対称性の検査とエラーは `irfft` と同じ。`ihfft` が逆変換 | [hfft と ihfft](oxref:fft-hfft-ihfft)、[Hermite 対称性の検査](oxref:fft-hermitian-check)、[Plan での格納形式](oxref:fft-real-plan-layout) | [パックした変換と全長の複素変換の一致](oxref:fft-hermitian-duality) |
| [`ihfft`](https://docs.rs/scioxide-fft/0.1.0/scioxide_fft/fn.ihfft.html) | 関数 | 実数のスペクトルから Hermite 対称な標本のパックした半分へ | 指数の符号が正の和の $h_0, \dots, h_{\lfloor n/2\rfloor}$ と論理長 $n$（奇偶を含む）を `HermitianSpectrum` で返す。空の入力は `InvalidInput`（`Empty`）、非有限値は `NonFinite`、表現できない結果は `NumericalInstability`（`Overflow`） | [hfft と ihfft](oxref:fft-hfft-ihfft)、[Plan での格納形式](oxref:fft-real-plan-layout)、[HermitianSpectrumNd と逆変換](oxref:fft-real-nd-spectrum) | [パックした変換と全長の複素変換の一致](oxref:fft-hermitian-duality) |
| [`HermitianSpectrum`](https://docs.rs/scioxide-fft/0.1.0/scioxide_fft/struct.HermitianSpectrum.html) | 構造体 | 論理長つきの所有するパックしたビン | `from_vec(logical_len, bins)` は論理長 0 を `InvalidInput`（`Empty`）、ビンの数が $\lfloor n/2\rfloor + 1$ でないと `DimensionMismatch` とし、対称性は逆変換のときに検査する。`zeros` は確保の失敗を `AllocationFailure` で返す。`bins`、`bins_mut`、`into_vec`、`logical_len`、`len`。スライスへの参照外しは持たない。`&HermitianSpectrum` は `FftInput` に、`&mut HermitianSpectrum` は `FftOutput` に変換され、一次元の Plan の `execute_into` に直接渡せる | [HermitianSpectrum と論理長](oxref:fft-hermitian-spectrum)、[実数入力とパックしたスペクトル](oxref:fft-packed-spectrum) | [ゼロパディングの有無で FFT 畳み込みと直接和を比べる](oxref:fft-convolution-delay)、[外部実装の方針と上限で準備の結果がどう変わるかを確かめる](oxref:fft-provider-fallback)、[実数 FFT の往復誤差と Hermite 対称性の許容値](oxref:fft-real-hermitian-invariants)、[基数と桁数を変えた FFT 乗算の係数誤差](oxref:fft-integer-multiplication) |

## 周波数軸と変換長

| 項目 | 種別 | 役割 | 仕様の要点 | 解説節 | 実行例 |
|---|---|---|---|---|---|
| [`fftfreq`](https://docs.rs/scioxide-fft/0.1.0/scioxide_fft/fn.fftfreq.html) | 関数 | 全スペクトルのビンの周波数 | $[0, \dots, \lceil n/2\rceil - 1, -\lfloor n/2\rfloor, \dots, -1]/(nd)$ を、各項 $(k/n)/d$ として整数 $k$ から直接計算する。$n = 0$ や $d = 0$ は `InvalidInput`、非有限の $d$ は `NonFinite`、長さや添字が正確に表せないか隣り合う周波数を区別できないときは `ScalarConversion`、$1/(nd)$ や周波数の桁あふれ・0 への丸めは `NumericalInstability` | [周波数軸とビンの並び](oxref:fft-frequency-axis)、[離散 Fourier 変換の記法](oxref:fft-notation) | [fftfreq・rfftfreq・fftshift・ifftshift の並びを長さの偶奇で比べる](oxref:fft-frequency-order)、[単一モードと多モードの製造解による周期 Poisson 求解](oxref:fft-spectral-poisson) |
| [`rfftfreq`](https://docs.rs/scioxide-fft/0.1.0/scioxide_fft/fn.rfftfreq.html) | 関数 | `rfft` のビンの周波数 | $[0, \dots, \lfloor n/2\rfloor]/(nd)$。偶数長の最後のビンは正の Nyquist 周波数 $1/(2d)$。エラーは `fftfreq` と同じ | [周波数軸とビンの並び](oxref:fft-frequency-axis)、[実数列のスペクトルと Hermite 対称性](oxref:fft-hermitian-symmetry)、[折り返しと漏れの観測](oxref:fft-aliasing-experiment) | [fftfreq・rfftfreq・fftshift・ifftshift の並びを長さの偶奇で比べる](oxref:fft-frequency-order)、[信号周波数を Nyquist 周波数の前後へ動かす](oxref:fft-sampling-alias)、[周期数とウインドウを変えてスペクトル漏れを測る](oxref:fft-leakage-windows)、[単一モードと多モードの製造解による周期 Poisson 求解](oxref:fft-spectral-poisson) |
| [`fftshift`](https://docs.rs/scioxide-fft/0.1.0/scioxide_fft/fn.fftshift.html) | 関数 | 零周波数を中央へ並べ替える | $\lceil n/2\rceil$ だけ左に回転し、零周波数を位置 $\lfloor n/2\rfloor$ に置く。空の入力は空の結果。確保の失敗（`AllocationFailure`）だけがエラー | [周波数軸とビンの並び](oxref:fft-frequency-axis)、[fftshift と ifftshift](oxref:fft-frequency-shift)、[相互相関とラグの並び](oxref:fft-correlation) | [fftfreq・rfftfreq・fftshift・ifftshift の並びを長さの偶奇で比べる](oxref:fft-frequency-order) |
| [`ifftshift`](https://docs.rs/scioxide-fft/0.1.0/scioxide_fft/fn.ifftshift.html) | 関数 | `fftshift` の逆の並べ替え | $\lfloor n/2\rfloor$ だけ左に回転する。奇数長では `fftshift` と異なる。確保の失敗だけがエラー | [周波数軸とビンの並び](oxref:fft-frequency-axis)、[fftshift と ifftshift](oxref:fft-frequency-shift) | [fftfreq・rfftfreq・fftshift・ifftshift の並びを長さの偶奇で比べる](oxref:fft-frequency-order) |
| [`next_fast_len`](https://docs.rs/scioxide-fft/0.1.0/scioxide_fft/fn.next_fast_len.html) | 関数 | $n$ 以上で最小の 2・3・5・7 の積 | ゼロパディングの長さを選ぶ補助関数で、他の長さも変換できる。確保も浮動小数点の計算もしない。$n = 0$ は `InvalidInput`（`OutOfRange`）、`usize` に収まる該当の長さがなければ `SizeOverflow`。 | [速い長さの選択](oxref:fft-fast-lengths)、[ゼロパディングの長さ](oxref:fft-zero-padding)、[Bluestein の恒等式](oxref:fft-bluestein-czt) | [ゼロパディングの有無で FFT 畳み込みと直接和を比べる](oxref:fft-convolution-delay)、[FFT による相互相関を signal の correlate と照合する](oxref:fft-correlation-lag-order)、[変換長ごとのアルゴリズムの選択と f32 の誤差を Plan の診断で確かめる](oxref:fft-planner-algorithm-choice)、[基数と桁数を変えた FFT 乗算の係数誤差](oxref:fft-integer-multiplication) |
| [`prev_fast_len`](https://docs.rs/scioxide-fft/0.1.0/scioxide_fft/fn.prev_fast_len.html) | 関数 | $n$ 以下で最大の 2・3・5・7 の積 | $n = 0$ は `InvalidInput`（`OutOfRange`）。確保しない | [速い長さの選択](oxref:fft-fast-lengths) | [変換長ごとのアルゴリズムの選択と f32 の誤差を Plan の診断で確かめる](oxref:fft-planner-algorithm-choice) |
