## 離散 Hankel 変換と FFTLog

| [`dht`](https://docs.rs/scioxide-fft/0.1.0/scioxide_fft/fn.dht.html) | 関数 | Bessel 零点の格子の離散 Hankel 変換を一度だけ計算する | 実数の標本、零点、次数 `order`、範囲 `extent` を受け取り、$\int_0^R f(r)J_\nu(kr)\,r\,dr$ を零点の格子の求積で近似する。零点が 2 個未満なら `InvalidInput`（`Empty`）、標本数が零点の数 − 1 でないと `DimensionMismatch`、非有限値は `NonFinite`、$\nu \le -1/2$・$R \le 0$・既定の許容を満たさない零点は `InvalidInput`（`OutOfRange`）。準備と適用はどちらも $O(n^2)$ | [Plan と簡易 API](oxref:fft-hankel-api) | [dht・idht と Plan の一致、HankelLimits の各欄](oxref:fft-hankel-function-limits) |

| [`DiscreteHankelPlan`](https://docs.rs/scioxide-fft/0.1.0/scioxide_fft/struct.DiscreteHankelPlan.html) | 構造体 | 離散 Hankel 変換の Plan | `new(zeros, spec)` は 2 個未満の零点や、正・増加・許容内・連続の条件を満たさない零点を `InvalidInput`（引数 `zeros`）で拒む。準備と実行は $O(n^2)$。成分ごとの丸めの範囲は $8\varepsilon(n+2)\sum_j\lvert m_{ij}\rvert\lvert x_j\rvert$。`execute_into` は複素数のスライスを受け取り、作用素の評価 1 回と $n$ 回の反復を数える。`nodes`、`frequencies`、`diagnostics`、`execute_axis_into`、`LinearOperator` と `AdjointOperator` | [Plan と簡易 API](oxref:fft-hankel-api) | [dht・idht と Plan の一致、HankelLimits の各欄](oxref:fft-hankel-function-limits)、[Bessel 零点の格子で 3 次元 Gauss 関数の動径変換を求める](oxref:fft-hankel-gaussian) |
| [`DiscreteHankelDiagnostics`](https://docs.rs/scioxide-fft/0.1.0/scioxide_fft/struct.DiscreteHankelDiagnostics.html) | 構造体 | 零点の検査と準備の計算量 | `maximum_zero_residual`（$\lvert J_\nu(z_m)\rvert$ の最大）、`maximum_zero_correction`（Newton 法の補正量の最大）、`preparation_work` | [Plan と簡易 API](oxref:fft-hankel-api) | [dht・idht と Plan の一致、HankelLimits の各欄](oxref:fft-hankel-function-limits) |
| [`HankelLimits`](https://docs.rs/scioxide-fft/0.1.0/scioxide_fft/struct.HankelLimits.html) | 構造体 | 離散 Hankel 変換の上限 | `preparation_bytes`、`workspace_bytes`（超えると `ResourceLimit`）と `preparation_work`（使い切ると `ConvergenceFailure`）。既定は無制限 | [Plan と簡易 API](oxref:fft-hankel-api) | [dht・idht と Plan の一致、HankelLimits の各欄](oxref:fft-hankel-function-limits) |

| [`fht`](https://docs.rs/scioxide-fft/0.1.0/scioxide_fft/fn.fht.html) | 関数 | 実数の入力の FFTLog | 入力の中心の半径は 1。入力は $\ln r$ について周期的として扱い、ゼロパディングはしない。空の入力と正でない `dln` は `InvalidInput`、非有限値は `NonFinite`、順方向の乗数の極は `Singular`、0 でない乗数の 0 への丸めや乗数・重み・結果の桁あふれは `NumericalInstability` | [Plan と簡易 API](oxref:fft-fftlog-api) | [fht・ifht と Plan の一致、FftLogLimits の各欄](oxref:fft-fftlog-function-limits) |

| [`FftLogPlan`](https://docs.rs/scioxide-fft/0.1.0/scioxide_fft/struct.FftLogPlan.html) | 構造体 | FFTLog の Plan | 準備は $n$ 個の乗数を計算する。長さ 0 と正でない刻みは `InvalidInput`、非有限値は `NonFinite`、0 でない乗数の 0 への丸めは `NumericalInstability`（`Underflow`）、重みや二進指数の範囲外は `NumericalInstability`（`Overflow`）。実行は FFT 2 回と $O(n)$。バイアス後の入力を $\ln r$ について周期延長し、暗黙のゼロパディングはしない。乗数に零や極があっても準備は成功し、方向に応じて実行が `Singular` を返す。`execute_into` は複素数のスライスを受け取り、作用素の評価 1 回と $n$ 回の反復を数える。`log_radius`、`log_frequency`、`diagnostics`、`execute_axis_into`、`LinearOperator` と `AdjointOperator` | [Plan と簡易 API](oxref:fft-fftlog-api) | [fht・ifht と Plan の一致、FftLogLimits の各欄](oxref:fft-fftlog-function-limits)、[FFTLog で Gauss 型の関数の Hankel 変換を対数格子で求める](oxref:fft-fftlog-gaussian)、[音響スケールを模した山を FFTLog と閉形式で比べる](oxref:fft-fftlog-correlation-function)、[べき乗則の閉形式でバイアスと換算係数を確かめる](oxref:fft-fftlog-power-law) |
