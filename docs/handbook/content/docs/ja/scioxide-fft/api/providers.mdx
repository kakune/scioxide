## 外部の FFT 実装と準備のコンテキスト

| 項目 | 種別 | 役割 | 仕様の要点 | 解説節 | 実行例 |
|---|---|---|---|---|---|
| [`FftPlanningContext`](https://docs.rs/scioxide-fft/0.1.0/scioxide_fft/struct.FftPlanningContext.html) | 構造体 | 準備に渡す借用の機能 | `ExecutionContext` から変換でき、そのとき外部の実装は使わない。`Default` は `ExecutionContext::sequential_native`。`with_provider(execution, provider, policy)`、`with_provider_limits`（上限は下げることしかできない）、`execution()`。Plan はコンテキストを保持しない | [外部 FFT 実装の注入](oxref:fft-providers)、[CPU の命令セットと実行方針](oxref:fft-execution-environment)、[Plan の準備と所有](oxref:fft-plan-preparation) | [外部実装の方針と上限で準備の結果がどう変わるかを確かめる](oxref:fft-provider-fallback) |
| [`FftProvider`](https://docs.rs/scioxide-fft/0.1.0/scioxide_fft/trait.FftProvider.html) | トレイト | 外部の FFT Plan の準備 | `prepare` は長さごとに両方向の尺度なしの変換を準備する。`Ok(None)` は長さを断る意味で、`FftProviderPolicy` が CPU の実装に戻すかを決める。エラーはそのまま呼び出し側に返り、CPU の実装には戻らない | [外部 FFT 実装の注入](oxref:fft-providers)、[Plan と作業領域](oxref:fft-plans-and-workspaces) | [外部実装の方針と上限で準備の結果がどう変わるかを確かめる](oxref:fft-provider-fallback) |
| [`FftProviderPlan`](https://docs.rs/scioxide-fft/0.1.0/scioxide_fft/trait.FftProviderPlan.html) | トレイト | 準備した外部の変換 | 尺度なしの複素 DFT を、返した長さの一時領域でその場で計算する。正規化、2 のべきの尺度の調整、出力の NaN・無限大の検査は SciOxide が行う。実装は実行中に確保や状態の変更をしてはならない。`preparation_bytes` が `plan_bytes` より小さいと準備は `InvalidInput`。`workspace_len`、`plan_bytes`、`preparation_bytes`、`diagnostics`、`execute` | [外部 FFT 実装の注入](oxref:fft-providers)、[SciOxide が確かめることと実装者の責任](oxref:fft-provider-contract) | [外部実装の方針と上限で準備の結果がどう変わるかを確かめる](oxref:fft-provider-fallback) |
| [`FftProviderPolicy`](https://docs.rs/scioxide-fft/0.1.0/scioxide_fft/enum.FftProviderPolicy.html) | 列挙型 | 外部の実装の使い方 | `Preferred`（断られた長さは CPU の実装を使う）と `Required`（断られた長さは準備が `InvalidInput`（`UnsupportedConfiguration`）） | [外部 FFT 実装の注入](oxref:fft-providers)、[SciOxide が確かめることと実装者の責任](oxref:fft-provider-contract) | [外部実装の方針と上限で準備の結果がどう変わるかを確かめる](oxref:fft-provider-fallback) |
| [`FftProviderLimits`](https://docs.rs/scioxide-fft/0.1.0/scioxide_fft/struct.FftProviderLimits.html) | 構造体 | 外部の実装の準備と作業領域のバイト数の上限 | `preparation_bytes` と `workspace_bytes`（既定は `usize::MAX`）。プロバイダーは確保の前に上限を守り、SciOxide は準備のあとで示された大きさを調べて超えれば `ResourceLimit` を返す | [リソースの上限](oxref:fft-provider-limits) | [外部実装の方針と上限で準備の結果がどう変わるかを確かめる](oxref:fft-provider-fallback) |
| [`FftBackend`](https://docs.rs/scioxide-fft/0.1.0/scioxide_fft/enum.FftBackend.html) | 列挙型 | 実際に使われた FFT の実装 | `Cpu(KernelBackend)` と `Provider`。各 Plan の `resolved_backends()` が含む複素 FFT ごとに返す | [CPU の命令セットと実行方針](oxref:fft-execution-environment)、[Plan の診断](oxref:fft-plan-diagnostics)、[外部 FFT 実装の注入](oxref:fft-providers) | [外部実装の方針と上限で準備の結果がどう変わるかを確かめる](oxref:fft-provider-fallback) |
