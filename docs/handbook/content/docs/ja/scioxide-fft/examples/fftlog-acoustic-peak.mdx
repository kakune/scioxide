宇宙論の 2 点相関関数 $\xi(r)$ は、パワースペクトル $P(k)$ の 3 次元 Fourier 変換である。
[FFTLog でパワースペクトルから相関関数を求める](../fftlog-correlation-function/)では、この変換を次数 $\mu = 1/2$ の FFTLog に換算し、べき乗則の閉形式で換算係数を確かめた。
このページでは同じ換算を、バリオン音響振動（BAO）を模した合成スペクトルに使う。
閉形式と比べて、波数の範囲と点数が相関関数の誤差と山の位置をどう変えるかを調べる。

## 換算の関数

波数 $k$ の単位は $h\,\mathrm{Mpc}^{-1}$（図と表では h/Mpc）、距離 $r$ の単位は $h^{-1}\mathrm{Mpc}$（Mpc/h）、$P$ の単位は $(h^{-1}\mathrm{Mpc})^3$ とする。
換算は[球 Bessel 変換から FFTLog への換算](oxref:fft-fftlog-correlation-mapping)のとおりで、$a(k) = k^{3/2}P(k)$ を次数 $1/2$ の FFTLog で変換した $A(r)$ から $\xi(r) = A(r)/((2\pi)^{3/2} r^{3/2})$ を得る。
API の入力の格子 `log_radius(j)` を $\ln k_j$、出力の格子 `log_frequency(j)` を $\ln r_j$ と読み替える。

次の定義は換算を 1 つの関数にまとめる（前のページの定義と同じ内容である）。
`correlation_function` は $[k_{\min}, k_{\max}]$ の $n$ 点の対数格子で $P(k)$ を標本化し、FFTLog の出力格子の $r$ と $\xi(r)$ を返す。
offset は `fftlog_low_ringing_offset` で 0 の近くから選ぶので、$r$ の範囲はおよそ $[1/k_{\max}, 1/k_{\min}]$ になる。

```rust
//| id: fft-fftlog-acoustic-transform
//| kind: definitions
//| title: P(k) から ξ(r) を次数 1/2 の FFTLog で求める関数
//| crates: [scioxide-core, scioxide-fft]
use scioxide_core::{Complex, ExecutionContext};
use scioxide_fft::{FftDirection, FftLogPlan, FftLogPlanSpec, fftlog_low_ringing_offset};

/// FFTLog の出力格子の距離 r [Mpc/h]、相関関数 ξ(r) [-]、乗数の条件数の対数。
pub(crate) struct Correlation {
    pub(crate) radii: Vec<f64>,
    pub(crate) values: Vec<f64>,
    pub(crate) log_condition: f64,
}

/// k ∈ [k_min, k_max] [h/Mpc] の n 点の対数格子で P(k) [(Mpc/h)³] を標本化し、
/// ξ(r) = (2π)^{−3/2} r^{−3/2} A(r)、A(r) = ∫ k^{3/2} P(k) J_{1/2}(kr) r dk を返す。
pub(crate) fn correlation_function(
    power: impl Fn(f64) -> f64,
    k_min: f64,
    k_max: f64,
    n: usize,
    bias: f64,
) -> Result<Correlation, String> {
    let log_step = (k_max / k_min).ln() / (n - 1) as f64;
    let offset = fftlog_low_ringing_offset(log_step, 0.5, 0.0, bias).map_err(|e| e.to_string())?;
    let spec = FftLogPlanSpec::new(
        n,
        log_step,
        0.5,
        offset,
        Complex::new(bias, 0.0),
        FftDirection::Forward,
    )
    .with_log_radius_center(0.5 * (k_min * k_max).ln());
    let plan = FftLogPlan::new(spec).map_err(|e| e.to_string())?;
    // API の入力の格子（log_radius）を波数 k として使う
    let mut input = Vec::with_capacity(n);
    for j in 0..n {
        let k = plan.log_radius(j).map_err(|e| e.to_string())?.exp();
        input.push(Complex::new(k.powf(1.5) * power(k), 0.0));
    }
    let mut output = vec![Complex::new(0.0, 0.0); n];
    let mut workspace = plan.workspace(()).map_err(|e| e.to_string())?;
    plan.execute_into(
        &input,
        &mut output,
        &mut workspace,
        ExecutionContext::sequential(),
    )
    .map_err(|e| e.to_string())?;
    // 出力の格子（log_frequency）を距離 r として読み、ξ = A / ((2π)^{3/2} r^{3/2}) に直す
    let norm = (2.0 * std::f64::consts::PI).powf(1.5);
    let mut radii = Vec::with_capacity(n);
    let mut values = Vec::with_capacity(n);
    for (j, a) in output.iter().enumerate() {
        let r = plan.log_frequency(j).map_err(|e| e.to_string())?.exp();
        radii.push(r);
        values.push(a.re / (norm * r.powf(1.5)));
    }
    let log_condition = plan.diagnostics().log_multiplier_condition;
    Ok(Correlation {
        radii,
        values,
        log_condition,
    })
}
```

## 音響スケールを模したスペクトル

初期宇宙のバリオンと光子の音波は、物質の分布に音響スケール $r_s \approx 105\,h^{-1}\mathrm{Mpc}$（共動距離）の特徴を残す。
パワースペクトルでは $k$ の振動、相関関数では $r \approx r_s$ の山として現れる。
この対応を、次の合成モデルで確かめる。

$$
P(k) = P_0\, e^{-\sigma^2 k^2/2}\left[1 + \alpha\, j_0(k r_s)\right], \qquad
P_0 = 1\,(h^{-1}\mathrm{Mpc})^3,\quad \sigma = 8\,h^{-1}\mathrm{Mpc},\quad \alpha = 0.2
$$

これは実測の物質パワースペクトルではなく、閉形式を持つように作ったモデルである。
Gauss 型の部分と振動の部分の相関関数は、それぞれ

$$
\xi_G(r) = \frac{P_0\, e^{-r^2/(2\sigma^2)}}{(2\pi)^{3/2}\sigma^3}, \qquad
\xi_{\mathrm{osc}}(r) = \frac{\alpha P_0 \left[e^{-(r-r_s)^2/(2\sigma^2)} - e^{-(r+r_s)^2/(2\sigma^2)}\right]}{2\,(2\pi)^{3/2}\,\sigma\, r\, r_s}
$$

である。
第 2 式は $\sin(kr)\sin(kr_s)$ を積和の公式で余弦の差に直し、Gauss 関数の余弦積分 $\int_0^\infty e^{-\sigma^2k^2/2}\cos(ck)\,dk = \sqrt{\pi/2}\,e^{-c^2/(2\sigma^2)}/\sigma$ を使って得る。
$\xi_{\mathrm{osc}}$ は $r = r_s$ を中心とする幅 $\sigma$ の山で、相関関数の慣例どおり $r^2\xi(r)$ を描くと山が見やすい。
ただし $1/r$ の因子と $r^2$ の重みがあるので、$r^2\xi$ の極大は $r_s$ からわずかにずれる。

## 波数の範囲と山の位置

次のセルは $k_{\min} = 10^{-5}\,h\,\mathrm{Mpc}^{-1}$ に固定し、上端 $k_{\max}$ と点数 $n$ と $r_s$ を入力にする。
$P$ は $k = 0.5\,h\,\mathrm{Mpc}^{-1}$ で $e^{-8} \approx 3\times 10^{-4}$ まで減るので、$k_{\max}$ がそれより小さいと Gauss 関数の裾を打ち切る。
誤差は $2 \le r \le 150\,h^{-1}\mathrm{Mpc}$ で、閉形式との差を $\xi_G(0)$ で割って測る（裾で小さい参照値で割ることを避ける）。
山の位置は FFTLog の格子点の $r^2\xi$ の極大を $\ln r$ の放物線で補間して求め、閉形式を $0.01\,h^{-1}\mathrm{Mpc}$ 刻みで評価した極大と比べる。
1 つめの図は $r^2\xi(r)$、2 つめの図は閉形式との差の絶対値で、$r$ の軸を連動させる。

```rust
//| id: fft-fftlog-correlation-function
//| ref: fft-fftlog-correlation-function
//| title: 音響スケールを模した山を FFTLog と閉形式で比べる
//| run: reactive
//| crates: [scioxide-core, scioxide-fft]
//| uses: [fft-fftlog-acoustic-transform]
//| inputs:
//|   bao_scale: {"type":"range","label":"音響スケール r_s [Mpc/h]","description":"P(k) の振動の周期 2π/r_s と ξ(r) の山の位置を動かす。","min":90,"max":120,"step":5,"value":105}
//|   k_max: {"type":"range","label":"波数の上端 k_max [h/Mpc]","description":"格子の上端。0.5 より小さいと P の Gauss 関数の裾を打ち切る。","min":0.25,"max":2,"step":0.25,"value":1}
//|   sample_count: {"type":"range","label":"対数格子の点数 n","description":"範囲を変えずに刻み Δ を変える。","min":256,"max":1024,"step":256,"value":512}
//| cases:
//|   - {"id":"truncated","label":"k_max = 0.25","description":"P(0.25) = 0.14 の裾を打ち切り、差の最大が ξ_G(0) の 0.19 倍になって山も動く。","inputs":{"k_max":0.25}}
//|   - {"id":"small-scale","label":"r_s = 90","description":"山が 90 Mpc/h の近くへ移る。","inputs":{"bao_scale":90}}
//|   - {"id":"coarse","label":"n = 256","description":"刻みが粗くなっても範囲が同じなら誤差は変わらない。","inputs":{"sample_count":256}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"summary","path":"/rows/0/1","approx":{"value":1.264e-14,"rtol":0.01}}
//|       - {"artifact":"summary","path":"/rows/0/2","approx":{"value":3.29e-6,"rtol":0.02}}
//|       - {"artifact":"summary","path":"/rows/0/3","approx":{"value":105.59,"atol":0.02}}
//|       - {"artifact":"summary","path":"/rows/0/4","approx":{"value":105.61,"atol":0.005}}
//|   - case: truncated
//|     expect:
//|       - {"artifact":"summary","path":"/rows/0/2","approx":{"value":0.1905,"rtol":0.01}}
//|       - {"artifact":"summary","path":"/rows/0/3","approx":{"value":111.95,"atol":0.05}}
//|   - case: small-scale
//|     expect:
//|       - {"artifact":"summary","path":"/rows/0/3","approx":{"value":90.68,"atol":0.02}}
//|       - {"artifact":"summary","path":"/rows/0/4","approx":{"value":90.71,"atol":0.005}}
//|   - case: coarse
//|     expect:
//|       - {"artifact":"summary","path":"/rows/0/2","approx":{"value":3.17e-6,"rtol":0.02}}
//|       - {"artifact":"summary","path":"/rows/0/3","approx":{"value":105.46,"atol":0.02}}
let (rs, sigma, alpha) = (bao_scale, 8.0_f64, 0.2_f64);
let (k_min, n) = (1e-5_f64, sample_count as usize);
// P(k) = e^{−σ²k²/2} [1 + α j₀(k r_s)] [(Mpc/h)³]（入力の生成は f64 の関数）
let model = |k: f64| {
    let x = k * rs;
    (-0.5 * sigma * sigma * k * k).exp() * (1.0 + alpha * x.sin() / x)
};
let xi = correlation_function(model, k_min, k_max, n, 0.0)?;

// 独立検算: ξ_G と ξ_osc の閉形式
let norm = (2.0 * std::f64::consts::PI).powf(1.5);
let gauss = |r: f64| (-0.5 * (r / sigma).powi(2)).exp();
let closed = |r: f64| {
    let peak = gauss(r - rs) - gauss(r + rs);
    gauss(r) / (norm * sigma.powi(3)) + alpha * peak / (2.0 * norm * sigma * r * rs)
};
let scale = 1.0 / (norm * sigma.powi(3)); // ξ_G(0)
let (mut weighted, mut reference, mut errors) = (Vec::new(), Vec::new(), Vec::new());
let mut largest = 0.0_f64;
let mut best: Option<usize> = None;
for (j, (&r, &value)) in xi.radii.iter().zip(&xi.values).enumerate() {
    let error = (value - closed(r)).abs();
    if (2.0..=150.0).contains(&r) {
        largest = largest.max(error / scale);
    }
    if (1.0..=300.0).contains(&r) {
        weighted.push([r, r * r * value]);
        reference.push([r, r * r * closed(r)]);
        if error > 0.0 {
            errors.push([r, error]);
        }
    }
    // r_s ± 30 Mpc/h の範囲で、格子点の r² ξ の極大を探す
    let inside = (rs - 30.0..=rs + 30.0).contains(&r);
    if inside && best.is_none_or(|b| r * r * value > xi.radii[b].powi(2) * xi.values[b]) {
        best = Some(j);
    }
}
// 格子点の極大を ln r の放物線で補間する（両隣の点を使う）
// r_s ± 30 は入力の範囲で常に出力の格子の内側にあり、両隣の点もある
let j = best.ok_or("山を探す範囲に格子点がない")?;
let y = |i: usize| xi.radii[i].powi(2) * xi.values[i];
let (left, mid, right) = (y(j - 1), y(j), y(j + 1));
let shift = 0.5 * (left - right) / (left - 2.0 * mid + right);
let step = (xi.radii[j + 1] / xi.radii[j]).ln();
let peak = xi.radii[j] * (shift * step).exp();
// 独立検算: 閉形式の r² ξ を 0.01 Mpc/h 刻みで評価した極大
let exact_peak = (0..=6000)
    .map(|i| rs - 30.0 + 0.01 * i as f64)
    .fold((0.0_f64, f64::MIN), |(at, high), r| {
        let value = r * r * closed(r);
        if value > high { (r, value) } else { (at, high) }
    })
    .0;

emit_line_chart!(
    &vec![
        serde_json::json!({
            "name": "FFTLog",
            "points": weighted,
            "style": { "showSymbol": true }
        }),
        serde_json::json!({
            "name": "閉形式",
            "points": reference,
            "style": { "lineType": "dashed" }
        }),
    ],
    options = &serde_json::json!({
        "xLabel": "距離 r [Mpc/h]",
        "yLabel": "r² ξ(r) [(Mpc/h)²]",
        "xType": "log",
        "xMin": 1.0,
        "xMax": 300.0,
        "annotations": [{ "kind": "line", "axis": "x", "value": rs, "label": "r_s" }],
        "link": { "group": "acoustic-r" }
    })
);
emit_line_chart!(
    &vec![serde_json::json!({ "name": "閉形式との差の絶対値", "points": errors })],
    options = &serde_json::json!({
        "xLabel": "距離 r [Mpc/h]",
        "yLabel": "|ξ − 閉形式| [-]",
        "xType": "log",
        "yType": "log",
        "xMin": 1.0,
        "xMax": 300.0,
        "yMin": 1e-20,
        "yMax": 1e-3,
        "link": { "group": "acoustic-r" }
    })
);
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let fixed2 = serde_json::json!({ "fractionDigits": 2 });
let fixed4 = serde_json::json!({ "fractionDigits": 4 });
let columns = serde_json::json!([
    { "key": "0", "label": "刻み Δ [-]", "type": "number", "format": fixed4 },
    { "key": "1", "label": "P の裾 P(k_max) [(Mpc/h)³]", "type": "number", "format": sci2 },
    { "key": "2", "label": "差の最大 / ξ_G(0)（2 ≤ r ≤ 150）[-]", "type": "number", "format": sci2 },
    { "key": "3", "label": "山の位置 FFTLog [Mpc/h]", "type": "number", "format": fixed2 },
    { "key": "4", "label": "山の位置 閉形式 [Mpc/h]", "type": "number", "format": fixed2 }
]);
let log_step = (k_max / k_min).ln() / (n - 1) as f64;
emit_table_with_columns!(
    columns,
    vec![(log_step, model(k_max), largest, peak, exact_peak)],
    metadata = serde_json::json!({ "id": "summary" })
);
```

既定の $r_s = 105$、$k_{\max} = 1$、$n = 512$ では、$P$ の裾は $P(1) = 1.3\times 10^{-14}$ で、差の最大は $\xi_G(0)$ の $3.3\times 10^{-6}$ 倍である。
差は出力の格子の左端 $r \approx 1\,h^{-1}\mathrm{Mpc}$ の近くで最も大きい。
そこでは $A(r) = (2\pi)^{3/2} r^{3/2}\xi(r)$ が 0 まで減らず、周期化した出力に段差ができるためである。
$r_s$ の近くの差は $4\times 10^{-12}$ の程度で、$\xi_{\mathrm{osc}}$ の山の高さ $7\times 10^{-8}$ の $10^{-4}$ 倍より小さい。
山の位置は FFTLog の補間で $105.59$、閉形式で $105.61\,h^{-1}\mathrm{Mpc}$ で、どちらも $r_s$ より 0.6 だけ外にある。
$r_s = 90$ では $90.68$ と $90.71$ になり、山は $r_s$ に従って動く。

$k_{\max} = 0.25$ では $P(0.25) = 0.14$ の裾を打ち切るので、差の最大が $\xi_G(0)$ の 0.19 倍に増え、$r^2\xi$ の山が $111.9\,h^{-1}\mathrm{Mpc}$ に動いて高さも約 2.8 倍になる。
$k_{\max} = 2$ では出力の左端が $r \approx 0.5$ に伸びて、差の最大が $1.3\times 10^{-6}$ 倍に下がる。
$n = 256$ にしても範囲は同じなので、差の最大は $3.2\times 10^{-6}$ 倍でほとんど変わらず、格子が粗くなった分だけ補間した山の位置が $105.46$ にずれる。
このモデルの誤差を減らすには、点数ではなく波数の範囲を見直す。

## まとめ

$r^2\xi$ の山は $r_s$ の近くに出るが、$1/r$ の因子と $r^2$ の重みのために $r_s$ と一致するとは限らないので、閉形式か範囲を広げた計算と比べて読む。
このモデルでは、波数の上端 $k_{\max}$ で $P$ の裾を打ち切ると誤差が増え、山の位置と高さも変わる。
範囲を変えずに点数を増やしても誤差はほとんど変わらず、点数は山の位置の補間の細かさにだけ効く。
誤差は出力の格子の左端 $r \approx 1/k_{\max}$ の近くで最も大きく、山の近くの差は山の高さに比べて十分小さい。
