この節の例題は振動、画像、整数演算、偏微分方程式、天文観測、宇宙論の題材で FFT の API を使う。
どの例題も主な計算を `scioxide-fft` で行い、定義の和、整数演算、製造解、閉形式のような独立な方法で結果を確かめる。
入力の単位と正規化は各ページで指定する。

| 例題 | 題材と調べること | 主な API | 独立な検算 |
|---|---|---|---|
| [非整数周期とスペクトル漏れ](spectral-leakage/) | ウインドウの主ローブ、遠くの漏れ、振幅の補正 | `rfft`、`rfftfreq` | Dirichlet 核による閉形式 |
| [DCT による画像ブロック圧縮](dct-image-compression/) | $8\times8$ ブロックの低周波の係数の保持と段差の復元 | `dctn`、`idctn` | DCT-II の定義の和、Parseval の等式による二乗誤差 |
| [多倍長整数の畳み込み乗算](fft-integer-multiplication/) | 基数と桁数に対する係数の丸め誤差と整数への復元 | `rfft`、`irfft`、`HermitianSpectrum`、`next_fast_len` | 整数だけで計算した係数の二重和と桁上がり |
| [2 次元周期 Poisson 方程式](spectral-poisson/) | 指数収束と丸め誤差による精度の限界、右辺の平均 0 の条件 | `rfftn`、`irfftn`、`fftfreq`、`rfftfreq` | 製造解（既知解）との差、右辺と解の標本平均 |
| [zoom FFT の分解能](zoom-fft-tone-resolution/) | 観測時間で決まる分解能と周波数格子の細かさ | `zoom_fft`、`fft` | DTFT の定義和、ゼロパディング FFT |
| [不規則観測時刻の NUFFT](nonuniform-periodogram/) | 変光星の光度曲線の Fourier 和、要求精度と核幅・格子・演算量 | `NufftPlan`、`NufftPlanSpec`、`NufftDiagnostics` | 位相を正確に縮約した直接和（入力の 1 ノルムで正規化） |
| [FFTLog による相関関数](fftlog-correlation-function/) | パワースペクトルから相関関数への球 Bessel 変換の換算とバイアスの選び方 | `FftLogPlan`、`FftLogPlanSpec`、`fftlog_low_ringing_offset` | べき乗則の閉形式 |
| [FFTLog で音響スケールの山を調べる](fftlog-acoustic-peak/) | 音響振動を模したスペクトルで、波数の範囲と点数が誤差と $r^2\xi$ の山の位置に与える影響 | `FftLogPlan`、`FftLogPlanSpec`、`fftlog_low_ringing_offset` | Gauss 型と振動の部分の閉形式、閉形式の $r^2\xi$ の極大 |

信号処理の水準の二つの例題は scioxide-signal の章にある。
[インパルス応答と音響反射の線形畳み込み合成](../../scioxide-signal/examples/echo-convolution/)は FFT による畳み込みを、[Hilbert 変換による解析信号生成と瞬時包絡線復元](../../scioxide-signal/examples/hilbert-envelope/)は解析信号を扱う。
FFT の側の作り方は[畳み込みと相関](../algorithms/convolution-correlation-and-analytic-signals/)と[解析信号と離散 Hilbert 変換](../algorithms/analytic-signal/)で説明する。

## まとめ

例題を読むときは、入力の変更が変換する問題そのものを変えるのか、評価する格子だけを変えるのかを区別する。
往復が一致することと、連続の積分や既知の解に近いことは別の確認で、後者には製造解や定義の和のような独立な検算が要る。
表の誤差は絶対誤差か、何で割った値か（入力の 1 ノルム、標本数 $N$、参照値の最大）を確かめてから比べる。
整数乗算のように結果を整数へ丸める問題では、最近接整数との距離ではなく、整数だけの検算と比べた真の誤差で判断する。
