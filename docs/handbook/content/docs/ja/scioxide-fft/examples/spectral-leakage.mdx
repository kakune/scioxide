無限に続く正弦波 $x(t) = A\sin(2\pi f_0 t)$ の両側スペクトルは、$\pm f_0$ だけに線を持つ。
計算機で扱えるのは、有限の時間 $[0, T)$ で切り出した標本列だけである。
切り出しは窓関数を掛けることで、周波数領域ではウインドウのスペクトルとの畳み込みになる。
観測区間に整数個の周期が収まらないと、エネルギーが周りの周波数ビンへ広がる。
これをスペクトル漏れと呼ぶ。

このページでは振動計の 1 秒の記録（標本化周波数 128 Hz、$N = 128$ 標本、ビンの間隔 1 Hz）を題材に、矩形ウインドウと Hann ウインドウの漏れと振幅の補正を測る。
加速度の振幅は $A = 1\,\mathrm{m/s^2}$ とする。

## 漏れと Dirichlet 核

観測時間 $T = N\Delta t$ に $\alpha = f_0 T$ 周期を含む正弦波の標本 $x_n = \sin(2\pi\alpha n/N)$（$n = 0, \dots, N-1$）を考える。
DFT $X_k = \sum_n x_n e^{-2\pi i kn/N}$ は、[複素正弦波 1 つの DFT](oxref:fft-spectral-leakage) を正の周波数と負の周波数の 2 つについて組み合わせて

$$
X_k = \frac{1}{2i}\left[D_N(\alpha - k) - D_N(-\alpha - k)\right], \qquad
D_N(u) = e^{i\pi u (N-1)/N}\,\frac{\sin(\pi u)}{\sin(\pi u/N)}
$$

と書ける。
$D_N$ を Dirichlet 核と呼び、$D_N(0) = N$ である。
この式は整数でない $k$ でも成り立ち、標本列の離散時間 Fourier 変換をビン単位の周波数 $k$ で表す。
DFT のビンはこの連続な曲線を整数の $k$ で標本化したものである。

1. 整数周期（$\alpha \in \mathbb{Z}$、$0 < \alpha < N/2$）では、$k = \alpha$ と負の周波数に当たる $k = N - \alpha$ のビンだけが残り、他の整数のビンでは分子の $\sin(\pi(\pm\alpha - k))$ が 0 になる。
   `rfft` が返す $0 \le k \le N/2$ の範囲では、$k = \alpha$ のビンだけが残る。
2. 非整数周期（$\alpha \notin \mathbb{Z}$）では、どの整数のビンでも分子が 0 にならない。
   半整数 $\alpha = k_0 + 1/2$ では分子が $\pm 1$ になり、ピークから離れたビンでも $1/\lvert\alpha - k\rvert$ の割合でしか減らない。
   矩形ウインドウの最大の側帯（サイドローブ）は、主ローブより約 13.3 dB（振幅で 0.22 倍）低いだけである。

## Hann ウインドウと振幅の補正

窓関数を掛けて区間の両端を滑らかに 0 へ近づけると、遠くのビンへの漏れが減る。
DFT の解析では周期版の Hann ウインドウ

$$
w_n = \frac{1}{2}\left[1 - \cos\left(\frac{2\pi n}{N}\right)\right], \qquad 0 \le n < N
$$

を使う。
$\cos(2\pi n/N)$ を掛けることは周波数を $\pm 1$ ビンずらすことなので、ウインドウを掛けたスペクトルは矩形ウインドウのスペクトルの 3 項の和

$$
X_k^{\mathrm{Hann}} = -\frac{1}{4}X_{k-1} + \frac{1}{2}X_k - \frac{1}{4}X_{k+1}
$$

になる。
遠くでは 3 項が打ち消し合い、側帯は $\lvert k - \alpha\rvert^{-3}$（1 オクターブあたり 18 dB）で減って、最大の側帯は約 31.5 dB 低い。
代わりに主ローブの幅は矩形ウインドウの 2 倍になり、近い 2 つの周波数を分ける機能は下がる。
分母を $N-1$ とする対称版の Hann ウインドウは、両端の値がどちらも 0 になるフィルタ設計向けの形で、上の 3 項の式は近似になる。

ウインドウを掛けると信号の大きさが減るので、そのままではピークの振幅を小さく見積もる。
ウインドウの平均

$$
\mathrm{CG} = \frac{1}{N}\sum_{n=0}^{N-1} w_n
$$

をコヒーレント利得と呼ぶ。
[物理振幅への換算](oxref:fft-physical-amplitude)の片側の振幅をウインドウに合わせて $2\lvert X_k\rvert/(N\,\mathrm{CG})$ とすると、ビンの中心にある正弦波の振幅 $A$ が戻る（負の周波数の項の寄与は無視する）。
周期版の Hann ウインドウでは $\mathrm{CG} = 1/2$ である。
ビンの間にある正弦波では、主ローブの形によってピークの振幅がさらに下がる。
この低下をスカロッピング損失と呼び、半整数のずれで矩形ウインドウは $2/\pi \approx 0.64$ 倍（3.9 dB）、Hann ウインドウは約 0.85 倍（1.4 dB）になる。

## 漏れを測る実験

次のセルは周期数 $\alpha$（信号の周波数 $f_0 = \alpha$ Hz）の正弦波にウインドウを掛け、`rfft` で片側のビンを求める。
`rfft` は $N/2 + 1$ 個のビンを `HermitianSpectrum` に入れて返すので、値は `bins()` で読む。
周波数の軸は `rfftfreq(N, Δt)` で求める。
片側の振幅は直流と Nyquist 以外のビンを 2 倍し、コヒーレント利得で割る。
遠くの漏れは $\lvert k - \alpha\rvert > 3$ のビンに出たパワーの割合で、パワーも片側化の重みを付けて数える。

独立検算として、上の Dirichlet 核の式（Hann ウインドウでは 3 項の和）でビンの値を計算し、`rfft` との差を求める。
同じ閉形式を 1/16 ビンの刻みで評価した連続な曲線を破線で重ね、ビンがその曲線の標本であることを示す。
ウインドウの係数、信号、閉形式の三角関数は f64 の固有メソッドで計算する。

```rust
//| id: fft-leakage-windows
//| ref: fft-leakage-windows
//| title: 周期数とウインドウを変えてスペクトル漏れを測る
//| run: reactive
//| crates: [scioxide-core, scioxide-fft]
//| inputs:
//|   cycles: {"type":"range","label":"観測区間内の周期数 α（= f₀ [Hz]）","description":"整数なら漏れがなく、半整数で漏れとピークの低下が最大になる。","min":4,"max":8,"step":0.25,"value":5.5}
//|   window: {"type":"select","label":"窓関数","options":["矩形ウインドウ","Hann ウインドウ（周期版）"],"value":"矩形ウインドウ"}
//| cases:
//|   - {"id":"hann","label":"Hann ウインドウ","description":"遠くの漏れが 400 分の 1 に減り、主ローブが 2 倍に広がる。","inputs":{"window":"Hann ウインドウ（周期版）"}}
//|   - {"id":"integer-cycles","label":"α = 6","description":"整数周期では矩形ウインドウでも漏れがなく、振幅 1 がそのまま出る。","inputs":{"cycles":6}}
//|   - {"id":"quarter-hann","label":"α = 5.25、Hann ウインドウ","description":"ビンの間の 1/4 の位置で、スカロッピング損失が半整数より小さい。","inputs":{"cycles":5.25,"window":"Hann ウインドウ（周期版）"}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"leakage","path":"/rows/0/1","approx":{"value":1,"atol":1e-15}}
//|       - {"artifact":"leakage","path":"/rows/0/2","approx":{"value":5,"atol":0.5}}
//|       - {"artifact":"leakage","path":"/rows/0/3","approx":{"value":0.6662289344268328,"rtol":1e-10}}
//|       - {"artifact":"leakage","path":"/rows/0/4","approx":{"value":0.0514735844984633,"rtol":1e-8}}
//|       - {"artifact":"leakage","path":"/rows/0/5","range":{"max":1e-14}}
//|   - case: hann
//|     expect:
//|       - {"artifact":"leakage","path":"/rows/0/1","approx":{"value":0.5,"atol":1e-15}}
//|       - {"artifact":"leakage","path":"/rows/0/3","approx":{"value":0.8490371647027412,"rtol":1e-10}}
//|       - {"artifact":"leakage","path":"/rows/0/4","approx":{"value":1.2819648927252093e-4,"rtol":1e-8}}
//|       - {"artifact":"leakage","path":"/rows/0/5","range":{"max":1e-14}}
//|   - case: integer-cycles
//|     expect:
//|       - {"artifact":"leakage","path":"/rows/0/2","approx":{"value":6,"atol":0.5}}
//|       - {"artifact":"leakage","path":"/rows/0/3","approx":{"value":1,"atol":1e-13}}
//|       - {"artifact":"leakage","path":"/rows/0/4","range":{"max":1e-26}}
//|   - case: quarter-hann
//|     expect:
//|       - {"artifact":"leakage","path":"/rows/0/3","approx":{"value":0.9603374284333767,"rtol":1e-10}}
//|       - {"artifact":"leakage","path":"/rows/0/5","range":{"max":1e-14}}
use scioxide_core::Complex;
use scioxide_fft::{Normalization, rfft, rfftfreq};

// 128 標本、標本化周波数 128 Hz（観測時間 1 s、ビンの間隔 1 Hz）、振幅 A = 1 m/s²
let n = 128_usize;
let size = n as f64;
let dt = 1.0 / 128.0;
let pi = std::f64::consts::PI;
let hann = window != "矩形ウインドウ";
// 周期版の Hann ウインドウ w_n = (1 − cos(2πn/N)) / 2（係数は f64 の cos で生成）
let weights: Vec<f64> = (0..n)
    .map(|j| {
        if hann {
            0.5 * (1.0 - (2.0 * pi * j as f64 / size).cos())
        } else {
            1.0
        }
    })
    .collect();
let signal: Vec<f64> = weights
    .iter()
    .enumerate()
    .map(|(j, w)| w * (2.0 * pi * cycles * j as f64 / size).sin())
    .collect();
let coherent_gain = weights.iter().sum::<f64>() / size;

// 主計算: 無尺度の rfft と周波数の軸
let spectrum = rfft(&signal, Normalization::Unscaled).map_err(|e| e.to_string())?;
let frequencies = rfftfreq(n, dt).map_err(|e| e.to_string())?;
// 片側化の重み: 直流と Nyquist は 1、他は 2
let side = |k: usize| if k == 0 || 2 * k == n { 1.0 } else { 2.0 };

// 独立検算: Dirichlet 核 D_N(u) による閉形式（Hann ウインドウは 3 項の和）。ν はビン単位の周波数
let kernel = |u: f64| {
    let ratio = if u == 0.0 {
        size
    } else {
        (pi * u).sin() / (pi * u / size).sin()
    };
    let phase = pi * u * (size - 1.0) / size;
    Complex::new(ratio * phase.cos(), ratio * phase.sin())
};
let rectangle = |nu: f64| {
    let d = kernel(cycles - nu) - kernel(-cycles - nu);
    Complex::new(d.im / 2.0, -d.re / 2.0) // d / (2i)
};
let closed = |nu: f64| {
    if hann {
        rectangle(nu) * 0.5 - (rectangle(nu - 1.0) + rectangle(nu + 1.0)) * 0.25
    } else {
        rectangle(nu)
    }
};

let amplitude = |k: usize, z: Complex<f64>| side(k) * z.norm() / (size * coherent_gain);
let mut bins = Vec::new();
let (mut peak, mut total, mut far, mut mismatch) = ((0.0_f64, 0.0_f64), 0.0, 0.0, 0.0_f64);
for (k, &z) in spectrum.bins().iter().enumerate() {
    let value = amplitude(k, z);
    if value > peak.1 {
        peak = (frequencies[k], value);
    }
    total += side(k) * z.norm_sqr();
    if (k as f64 - cycles).abs() > 3.0 {
        far += side(k) * z.norm_sqr();
    }
    mismatch = mismatch.max((z - closed(k as f64)).norm() / size);
    bins.push([frequencies[k], value]);
}
// 振幅がちょうど 0 のビンは対数軸に描けないので除いて数える
let plotted: Vec<[f64; 2]> = bins.iter().copied().filter(|b| b[1] > 0.0).collect();
let dropped = bins.len() - plotted.len();
// 閉形式の連続な曲線（1/16 ビン刻み、直流と Nyquist も 2 倍して滑らかに描く）
let curve: Vec<[f64; 2]> = (0..=64 * 16)
    .map(|i| i as f64 / 16.0)
    .map(|nu| [nu, 2.0 * closed(nu).norm() / (size * coherent_gain)])
    .filter(|p| p[1] > 0.0)
    .collect();

emit_line_chart!(
    &vec![
        serde_json::json!({
            "name": "rfft のビン",
            "points": plotted,
            "style": { "showSymbol": true, "lineType": "dotted" }
        }),
        serde_json::json!({
            "name": "閉形式（連続）",
            "points": curve,
            "style": { "lineType": "dashed" }
        }),
    ],
    options = &serde_json::json!({
        "xLabel": "周波数 [Hz]",
        "yLabel": "片側の振幅 [m/s²]",
        "yType": "log",
        "xMin": 0.0,
        "xMax": 64.0,
        "yMin": 1e-17,
        "yMax": 2.0,
        "annotations": [{ "kind": "line", "axis": "x", "value": cycles, "label": "信号の周波数 f₀" }]
    })
);
let fixed4 = serde_json::json!({ "fractionDigits": 4 });
let fixed0 = serde_json::json!({ "fractionDigits": 0 });
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let columns = serde_json::json!([
    { "key": "0", "label": "ウインドウ" },
    { "key": "1", "label": "コヒーレント利得 [-]", "type": "number", "format": fixed4 },
    { "key": "2", "label": "最大のビン [Hz]", "type": "number", "format": fixed0 },
    { "key": "3", "label": "ピークの振幅 [m/s²]", "type": "number", "format": fixed4 },
    { "key": "4", "label": "遠くの漏れの割合 [-]", "type": "number", "format": sci2 },
    { "key": "5", "label": "閉形式との差の最大 / N [-]", "type": "number", "format": sci2 },
    { "key": "6", "label": "描かなかった振幅 0 のビン [個]", "type": "integer" }
]);
let row = (
    window.clone(),
    coherent_gain,
    peak.0,
    peak.1,
    far / total,
    mismatch,
    dropped,
);
emit_table_with_columns!(
    columns,
    vec![row],
    metadata = serde_json::json!({ "id": "leakage" })
);
```

既定の $\alpha = 5.5$（半整数）と矩形ウインドウでは、ピークは 5 Hz のビンにあり、振幅は 0.666 m/s² に下がる。
$2/\pi = 0.637$ より少し大きいのは、負の周波数の項がこのビンにも寄与するためである。
$\alpha$ から 3 ビンより離れたビンには、全パワーの $5.1\times 10^{-2}$ が漏れる。
同じ $\alpha$ で Hann ウインドウにすると、コヒーレント利得は 0.5、ピークの振幅は 0.849 m/s² で、遠くの漏れは $1.3\times 10^{-4}$ と約 400 分の 1 になる。
図では、Hann ウインドウの側帯が矩形ウインドウより速く下がり、主ローブがピークの両側の 2 ビンずつに広がることが分かる。
$\alpha = 5.25$ の Hann ウインドウでは、ビンからのずれが 1/4 なので、ピークの振幅は 0.960 m/s² になる。

$\alpha = 6$ のような整数では、矩形ウインドウでもピークの振幅は 1 m/s² で、遠くの漏れは $10^{-30}$ の程度（丸め誤差の二乗）しかない。
図の他のビンも $10^{-16}$ の程度で、破線の連続な曲線の零点に乗っている。
どの場合も `rfft` と閉形式の差の最大は $N$ で割って $10^{-15}$ 以下で、正規化と片側化が式どおりであることを確かめられる。

## まとめ

観測区間に整数個の周期が収まらない正弦波は、Dirichlet 核の形で周りのビンへ漏れ、矩形ウインドウの漏れは周波数の差に反比例してしか減らない。
周期版の Hann ウインドウは矩形ウインドウのスペクトルの 3 項の和で、遠くの漏れを大きく減らす代わりに、主ローブを 2 倍に広げる。
振幅はコヒーレント利得で割って読み、ビンの間にある周波数ではスカロッピング損失（矩形ウインドウで最大約 0.64 倍、Hann ウインドウで約 0.85 倍）が残ることを考える。
`rfft` のビンは `HermitianSpectrum::bins()`、周波数は `rfftfreq` で得られ、整数周期の信号か Dirichlet 核の閉形式で正規化と片側化を確かめられる。
