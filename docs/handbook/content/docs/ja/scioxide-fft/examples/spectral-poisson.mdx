周期領域の Poisson 方程式は Fourier 基底で展開すると波数ごとの除算に変わる。
行列を組み立てずに $N\times N$ 格子で $O(N^2\log N)$ の演算で解けるが、右辺の平均と解の定数成分を呼び出し側で決める必要がある。

この例題では $[0,2\pi)^2$ 上で $-\Delta u=f$ を `rfftn` と `irfftn` で解く。
解を先に決めて右辺を計算する製造解を使い、数値解と既知解の差を測る。
有限個の Fourier モードで表せる解と無限個のモードを含む解を比べ、格子を細かくしたときの指数収束と丸め誤差による精度の限界を読み分ける。
座標 $x,y$、解 $u$、右辺 $f$ はすべて無次元とする。

scioxide-sparse の [2 次元 Poisson 行列の並べ替えとフィル](../../../scioxide-sparse/examples/poisson-reordering-fill/)は同じ 2 次元の方程式を差分行列の直接法で扱う。
scioxide-pde の [Poisson 問題を保存則から格子収束まで追う](../../../scioxide-pde/examples/poisson-grid/)は 1 次元の Poisson 方程式で、差分・有限要素・有限体積の収束次数を調べる。
このページは周期境界とスペクトル法に限る。

## Fourier 基底による対角化

周期 $2\pi$ の基底 $e^{i(k_xx+k_yy)}$（$k_x,k_y$ は整数）に対して、$-\Delta$ の固有値は $k_x^2+k_y^2$ である。
Fourier 級数の係数を

$$
\widehat f_{k_x,k_y}=\frac{1}{(2\pi)^2}
\int_0^{2\pi}\int_0^{2\pi}f(x,y)e^{-i(k_xx+k_yy)}\,dx\,dy
$$

と定めると、零でない波数では

$$
\widehat u_{k_x,k_y}=\frac{\widehat f_{k_x,k_y}}{k_x^2+k_y^2}
$$

となる。
格子点 $x_i=2\pi i/N$、$y_j=2\pi j/N$ の標本の DFT は、$N/2$ 未満の波数について Fourier 係数の $N^2$ 倍に、折り返した高い波数の係数を足したものである。
DFT のビンに同じ $1/(k_x^2+k_y^2)$ を掛けて逆変換すれば、格子で表せる波数の範囲で同じ除算になる。
正変換を `Normalization::Unscaled`、逆変換を `Normalization::Inverse` にすると、往復の倍率 $N^2$ が逆変換で除かれる。

## 平均 0 の条件と解の定数成分

零波数では固有値が 0 なので、周期解が存在する条件は

$$
\widehat f_{0,0}=\frac{1}{(2\pi)^2}\int_0^{2\pi}\int_0^{2\pi}f\,dx\,dy=0
$$

すなわち右辺の平均が 0 であることである。
解には任意の定数を加えられるので、ここでは $\widehat u_{0,0}=0$ として平均 0 の解を選ぶ。

離散化した方程式では、条件は右辺の標本平均が 0 であることになる。
零波数のビンを 0 にする操作は、右辺から標本平均 $\bar f$ を引いた方程式 $-\Delta u=f-\bar f$ を解くことにあたる。
$\bar f\ne0$ でも計算は失敗せず、元の方程式を満たさない解が黙って返る。
したがって、右辺の平均を確かめるのは呼び出し側の責任である。
次の実験では右辺に定数 $c$ を加える入力を用意し、この挙動を確かめる。

## 実数スペクトルの格納と波数

形状 $[N,N]$（行優先、軸 0 が $x$、軸 1 が $y$）の実数配列を `axes = &[0, 1]` で変換すると、最後に選んだ軸 1 が詰められる。
返る `HermitianSpectrumNd` はパックした形状 $[N,\lfloor N/2\rfloor+1]$ のビン列と、論理形状 $[N,N]$、軸の組を所有する。
軸 0 には正負の波数がそろって残り、軸 1 には非負の波数だけが残る。
ビンは `bins_mut` でその場で書き換え、同じ値を `irfftn` に借用で渡すと、論理形状の実数配列が新しい `Vec` で返る。

波数は `fftfreq` と `rfftfreq` に標本間隔 $1/N$ を渡して得る。
これは周期を 1 とした正規化座標 $x/(2\pi)$ の間隔なので、返る値がそのまま整数の波数になる。
物理座標の間隔 $2\pi/N$ を渡すと単位長さあたりの周期数 $k/(2\pi)$ が返るので、$2\pi$ を掛けて角波数に戻す必要がある。

乗数 $1/(k_x^2+k_y^2)$ は実数で、波数の符号を反転しても変わらないので、Hermite 対称性 $\widehat u_{-k}=\overline{\widehat u_k}$ を保つ。
`irfftn` はパックした軸の零周波数と Nyquist の平面が Hermite 対称性を満たすかを丸めの許容内で検査し、満たさなければ `InvalidInput` を返す。
対称性を壊す乗数（たとえば波数の符号で変わる係数）を掛けると、この検査で失敗しうる。

## 製造解

一つ目の解 $u_1=\sin(mx)\cos(ny)$ は単一のモードで、右辺は $f_1=(m^2+n^2)u_1$ である。
$m,n<N/2$ なら解は格子で正確に表せるので、誤差は関数評価と FFT の丸めだけから来る。
$m=N/2$ のときは格子点で $\sin(mx_i)=0$ となり、標本も既知解も 0 になる。
格子点での誤差は小さいままだが、格子点の間の値は表せないので、格子点だけで測る誤差には現れない。

二つ目の解は

$$
u_2=e^{a\cos(mx)}\cos(ny)
$$

で、母関数 $e^{a\cos\theta}=I_0(a)+2\sum_{k\ge1}I_k(a)\cos(k\theta)$ により $x$ 方向に波数 $km$ の無限個のモードを含む。
ここで $I_k$ は第 1 種変形 Bessel 関数で、$k$ が大きいとき $I_k(a)\approx(a/2)^k/k!$ と階乗より速く減る。
解析的に微分すると

$$
f_2=e^{a\cos(mx)}
\left[n^2+a m^2\cos(mx)-a^2m^2\sin^2(mx)\right]\cos(ny)
$$

となる。
格子が表せない波数 $km\ge N/2$ の係数が打切り・折り返しの誤差になるので、誤差は $N$ に対して指数関数より速く減り、丸め誤差による精度の限界 $10^{-15}$ 程度で止まると期待できる。
$a$ を大きくすると係数の減り方が遅くなり、誤差の下限に達するために必要な $N$ が増える。

$f_1$ も $f_2$ も平均は 0 である（$\cos(ny)$ の $y$ 方向の平均が 0 のため）。

## 格子細分化の実験

次のセルは各軸の点数を $N=8,12,16,\ldots$ と上限まで増やし、両方の製造解について最大絶対誤差と RMS 誤差を求める。
製造解と右辺の値は、FFT と独立な参照計算として `f64` の三角関数と指数関数で求める。
表は $N$ が 2 のべきと上限の行だけを示し、右辺と数値解の標本平均も並べる。
グラフは $N$ に対する最大絶対誤差を対数の縦軸で描き、誤差が 0 の点は除いてその数を示す。
ヒートマップは最も細かい格子での $u_2$ の数値解を、0 を中心とする発散型の色で描く。

```rust
//| id: fft-spectral-poisson
//| ref: fft-spectral-poisson
//| title: 単一モードと多モードの製造解による周期 Poisson 求解
//| run: reactive
//| crates: [scioxide-core, scioxide-fft]
//| inputs:
//|   grid_size: {"type":"range","label":"各軸の点数の上限 N","min":16,"max":96,"step":16,"value":64}
//|   wave_m: {"type":"range","label":"x 方向の基本波数 m","description":"m = N/2 では単一モードが格子から消える。","min":1,"max":4,"step":1,"value":2}
//|   wave_n: {"type":"range","label":"y 方向の波数 n","min":1,"max":4,"step":1,"value":3}
//|   amplitude: {"type":"range","label":"多モード解の振幅 a","description":"大きいほど高い波数の係数が残り、収束が遅い。","min":0.5,"max":4,"step":0.5,"value":2}
//|   rhs_offset: {"type":"range","label":"右辺に加える定数 c","description":"0 以外では平均 0 の条件が破れる。","min":0,"max":0.5,"step":0.1,"value":0}
//| cases:
//|   - {"id":"steep","label":"a = 4","description":"係数の減衰が遅く、N = 64 でも丸め誤差による精度の限界に届かない。","inputs":{"amplitude":4}}
//|   - {"id":"high-harmonics","label":"m = 4","description":"高調波の波数が 2 倍になり、N = 64 でも誤差が丸め誤差による精度の限界に届かない。","inputs":{"wave_m":4}}
//|   - {"id":"offset","label":"c = 0.3","description":"右辺の平均が 0.3 になっても、誤差と解の平均は変わらない。","inputs":{"rhs_offset":0.3}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"errors","path":"/rows/6/0","equals":64}
//|       - {"artifact":"errors","path":"/rows/6/2","range":{"max":1e-13}}
//|       - {"artifact":"errors","path":"/rows/7/2","range":{"max":1e-13}}
//|       - {"artifact":"errors","path":"/rows/1/2","range":{"min":1e-4}}
//|       - {"artifact":"errors","path":"/rows/7/5","approx":{"value":0,"atol":1e-14}}
//|   - case: steep
//|     expect:
//|       - {"artifact":"errors","path":"/rows/7/2","range":{"min":1e-12}}
//|   - case: high-harmonics
//|     expect:
//|       - {"artifact":"errors","path":"/rows/7/2","range":{"min":1e-7}}
//|       - {"artifact":"errors","path":"/rows/6/2","range":{"max":1e-13}}
//|   - case: offset
//|     expect:
//|       - {"artifact":"errors","path":"/rows/7/4","approx":{"value":0.3,"atol":1e-12}}
//|       - {"artifact":"errors","path":"/rows/7/2","range":{"max":1e-13}}
//|       - {"artifact":"errors","path":"/rows/7/5","approx":{"value":0,"atol":1e-14}}
use scioxide_core::Complex;
use scioxide_fft::{Normalization, fftfreq, irfftn, rfftfreq, rfftn};

let (limit, m, q, a, c) = (grid_size as usize, wave_m, wave_n, amplitude, rhs_offset);
let tau = 2.0 * std::f64::consts::PI;
let names = ["単一モード", "多モード"];
let mut rows = Vec::new();
let mut curves = [Vec::new(), Vec::new()];
let (mut zero_points, mut heat) = (0_usize, Vec::new());
for n in (8..=limit).step_by(4) {
    for model in 0..2 {
        // 参照値: 製造解 u と右辺 f を f64 の固有メソッドで評価する（行優先 [x, y]）。
        let (mut f, mut exact) = (Vec::with_capacity(n * n), Vec::with_capacity(n * n));
        for i in 0..n {
            let x = tau * i as f64 / n as f64;
            let (s, cx) = ((m * x).sin(), (m * x).cos());
            for j in 0..n {
                let cy = (q * (tau * j as f64 / n as f64)).cos();
                let (u, rhs) = if model == 0 {
                    (s * cy, (m * m + q * q) * s * cy)
                } else {
                    let u = (a * cx).exp() * cy;
                    (u, (q * q + a * m * m * cx - a * a * m * m * s * s) * u)
                };
                exact.push(u);
                f.push(rhs + c);
            }
        }
        let mut spectrum =
            rfftn(&f, &[n, n], &[0, 1], Normalization::Unscaled).map_err(|e| e.to_string())?;
        // 正規化座標の間隔 1/N を渡すと、整数の波数が返る。
        let kx = fftfreq(n, 1.0 / n as f64).map_err(|e| e.to_string())?;
        let ky = rfftfreq(n, 1.0 / n as f64).map_err(|e| e.to_string())?;
        let width = ky.len();
        for (row, &x) in spectrum.bins_mut().chunks_mut(width).zip(&kx) {
            for (bin, &y) in row.iter_mut().zip(&ky) {
                let k2 = x * x + y * y;
                // 零波数は û = 0（平均 0 の解）とし、他は f̂ / |k|² にする。
                *bin = if k2 == 0.0 {
                    Complex::new(0.0, 0.0)
                } else {
                    *bin / k2
                };
            }
        }
        let solution = irfftn(&spectrum, Normalization::Inverse).map_err(|e| e.to_string())?;
        let (mut max_error, mut sum_sq) = (0.0_f64, 0.0_f64);
        for (&u, &v) in solution.iter().zip(&exact) {
            max_error = max_error.max((u - v).abs());
            sum_sq += (u - v) * (u - v);
        }
        let points = (n * n) as f64;
        if n.is_power_of_two() || n == limit {
            rows.push((
                n,
                names[model],
                max_error,
                (sum_sq / points).sqrt(),
                f.iter().sum::<f64>() / points,
                solution.iter().sum::<f64>() / points,
            ));
        }
        if max_error > 0.0 {
            curves[model].push([n as f64, max_error]);
        } else {
            zero_points += 1;
        }
        if n == limit && model == 1 {
            heat = (0..n * n)
                .map(|k| {
                    let (x, y) = (
                        tau * (k / n) as f64 / n as f64,
                        tau * (k % n) as f64 / n as f64,
                    );
                    serde_json::json!([x, y, solution[k]])
                })
                .collect();
        }
    }
}
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let columns = serde_json::json!([
    { "key": "0", "label": "各軸の点数 N", "type": "integer" },
    { "key": "1", "label": "製造解" },
    { "key": "2", "label": "最大絶対誤差 [-]", "type": "number", "format": sci3 },
    { "key": "3", "label": "RMS 誤差 [-]", "type": "number", "format": sci3 },
    { "key": "4", "label": "右辺の標本平均 [-]", "type": "number", "format": sci3 },
    { "key": "5", "label": "解の標本平均 [-]", "type": "number", "format": sci3 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "errors" })
);
emit_text!(format!("誤差が 0 でグラフから除いた点: {zero_points} 個"));
emit_line_chart!(
    &vec![
        serde_json::json!({
            "name": names[0],
            "points": curves[0],
            "style": { "symbol": "circle", "showSymbol": true }
        }),
        serde_json::json!({
            "name": names[1],
            "points": curves[1],
            "style": { "symbol": "diamond", "showSymbol": true }
        })
    ],
    options = &serde_json::json!({
        "xLabel": "各軸の点数 N [点]",
        "yLabel": "最大絶対誤差 [-]",
        "yType": "log",
        "xMin": 8.0,
        "xMax": 96.0
    })
);
// 色の範囲を ±e^a に固定し、0 を中間色にする。
let bound = a.exp();
emit_chart!(serde_json::json!({
    "kind": "heatmap",
    "title": "多モード解 u₂ の数値解（最も細かい格子）",
    "data": heat,
    "xLabel": "x [-]",
    "yLabel": "y [-]",
    "colorScale": "diverging",
    "center": 0.0,
    "colorMin": -bound,
    "colorMax": bound,
    "tooltip": true
}));
```

既定の $m=2$、$n=3$、$a=2$ では、単一モードの最大絶対誤差はすべての $N$ で $2\times10^{-15}$ 前後にとどまる。
多モード解の誤差は $N=8,16,32,64$ で 1.94、$5.27\times10^{-2}$、$5.04\times10^{-6}$、$1.87\times10^{-14}$ と下がり、$N=64$ で単一モードと同じ丸め誤差による精度の限界に届く。
$N$ を 2 倍にするごとに誤差は 1.6 桁、4.0 桁、8.4 桁と下がり、下がる桁数そのものが増えていく（最後の値は丸め誤差による精度の限界で止まった結果）。
差分法の誤差が $N^{-2}$ のように代数的に減るのと対照的である。
$N=64$ から 96 に増やしても誤差は $1.9\times10^{-14}$ のままで、それ以上の細分は精度を上げない。

$a=4$ では $N=64$ でも誤差が $3.4\times10^{-10}$ 残り、$a=0.5$ では $N=32$ で $1.4\times10^{-11}$ まで下がる。
$m=4$ では $x$ 方向の高調波の波数が 2 倍になるので、同じ $N$ で表せる高調波の数が半分になり、$N=64$ の誤差は $5.2\times10^{-6}$ である。
誤差の曲線が下がり続けている範囲では打切り・折り返しの誤差が、平らになった範囲では丸めの誤差が支配している。

右辺の標本平均は $c=0$ で $10^{-14}$ 以下、数値解の標本平均は $10^{-16}$ 以下で、平均 0 の条件と解の選び方の両方が満たされている。
$c=0.3$ にすると右辺の平均は 0.3 になるが、誤差は $c=0$ と丸めの水準でしか変わらず、解の平均も 0 のままである。
零波数のビンを 0 にしたことで、計算された解は $-\Delta u=f-0.3$ の解になり、元の方程式 $-\Delta u=f$ の残差は至る所で 0.3 になる。
誤差が小さいことだけでは、この取り違えに気づけない。

ヒートマップでは、$x$ 方向に因子 $e^{a\cos(mx)}$ の $m$ 個の山が並び、$\cos(mx)=1$ の列で絶対値が最大 $e^a$ になる。
$y$ 方向には $\cos(ny)$ に従って符号が $n$ 周期で交互に変わり、製造解と同じ形である。

## まとめ

周期 Poisson 方程式は実数 FFT で零でない波数ごとの除算 $\widehat u=\widehat f/\lvert k\rvert^2$ に変わり、$N\times N$ 格子で $O(N^2\log N)$ の演算で解ける。
右辺の平均 0 が可解性の条件で、零波数のビンを 0 にする実装は平均を引いた問題を黙って解くので、右辺の平均は呼び出し側で確かめる。
格子で表せる単一モードの誤差は丸めの水準にとどまり、無限個のモードを含む解析的な解の誤差は格子の細分で指数関数より速く減って丸め誤差による精度の限界で止まる。
波数の除算は Hermite 対称性を保つので、`rfftn` のパックしたビンをその場で書き換えて `irfftn` に渡せる。
