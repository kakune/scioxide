振動や音響の測定では、狭い帯域にある近接した周波数成分を調べたいことがある。
`zoom_fft` は、有限個の標本の離散時間 Fourier 変換（DTFT）を、指定した帯域の等間隔の周波数点で評価する。
周波数点を増やす操作と観測時間を延ばす操作は、スペクトルに別々の効果を及ぼす。

この例題では 120 Hz とその近くの正弦波を合成し、観測時間、周波数差、評価点の細かさを変える。
zoom FFT の値は DTFT の直接和とゼロパディング FFT で検算する。
分解能はおよそ観測時間の逆数 $1/T$ で決まり、zoom FFT は周波数の格子を細かくするだけであることを確かめる。

## 観測時間と分解能

標本化周波数 $f_s$ で $N$ 個の標本を取ると、観測時間は $T=N/f_s$ で、通常の DFT のビンの間隔は $f_s/N=1/T$ である。
この間隔は DFT が評価する点の間隔であり、DTFT を評価できる最小の間隔ではない。

有限時間の観測は無限に続く信号に長さ $T$ の矩形ウインドウを掛けることにあたる。
単一の正弦波のスペクトルもウインドウの Fourier 変換の形に広がり、主ローブの中心から最初の零点までの間隔は $1/T$ である。
二つの成分の周波数差 $\Delta f$ がこの幅より小さいと、二つの主ローブが重なって一つの山に見える。
$\Delta f\approx1/T$ が分離の目安になる。

ただし、$\Delta f\ge1/T$ だけで山が二つに見えるかどうかは決まらない。
ウインドウの形、相対振幅、位相、ノイズ、分離の判定方法にも依存し、既知のモデルを当てはめる推定法なら $1/T$ より近い成分も推定できる。
ここでは同じ振幅、同じ初期位相の二つの余弦波の振幅スペクトルを、矩形ウインドウのまま調べる。

ゼロパディング FFT と zoom FFT は同じ有限列の DTFT を細かい点で評価する。
山の形を詳しく描けるが、観測値も観測時間も増えないので、主ローブの幅は変わらない。
観測時間を延ばすと主ローブ自体が狭くなる。

## zoom FFT の呼び出し

`zoom_fft(input, start, end, m, sample_rate, endpoint, normalization)` は、単位円上の周波数 $f_k=\mathrm{start}+k\Delta$（$0\le k<m$）で

$$
X(f_k)=\sum_{j=0}^{N-1}x_j\,e^{-2\pi i jf_k/f_s}
$$

を返す。
`endpoint` が真なら刻みは $\Delta=(\mathrm{end}-\mathrm{start})/(m-1)$ で、終点を含む。
内部ではチャープ Z 変換（CZT）を [Bluestein の恒等式](oxref:fft-bluestein-czt)でチャープ列との畳み込みに直し、長さ $L=$ `next_fast_len`$(N+m-1)$ の FFT で計算する。
1 回の呼び出しは核の変換を含めて長さ $L$ の FFT 3 回と $O(N+m)$ の演算で済む。
入力は借用され、結果は長さ $m$ の新しい `Vec` で返る。
同じ長さの入力を何度も変換するなら、`CztPlan` を一度作って作業領域を再利用すれば、1 回あたり FFT 2 回になる。

単位円上の輪郭の誤差の上界は各出力の絶対誤差を入力の成分の絶対値の和に比例する形で与える（[誤差の上界](oxref:fft-czt-error)）。
零に近い出力では相対誤差が大きくなりうるので、以下では共通の尺度 $N$ で割った絶対差で比べる。

## 正規化と比較の尺度

以下ではすべて無尺度の順変換を使い、グラフには $|X(f)|/N$ を描く。
振幅 1 の余弦波は $f$ の山で $|X|/N\approx1/2$ になり、片側振幅への換算の係数 2 は掛けない。
ゼロパディング FFT でも、比較の分母には元の標本数 $N$ を使う。
ゼロパディング後の長さで割ると、同じ信号の振幅がゼロパディングの量によって変わってしまう。

## 三つの計アルゴリズムの比較

以下では $f_s=1000$ Hz、$f_1=120$ Hz とし、評価帯域を 115〜128 Hz とする。
zoom FFT は帯域を $26s+1$ 点で評価し、刻みは $0.5/s$ Hz である。
ゼロパディング FFT は長さを 20000、刻みを 0.05 Hz に固定し、zoom FFT の点と周波数が一致する点だけで差を測る。
直接和は 0.5 Hz ごとの 27 点で評価し、FFT と独立な参照値にする。
合成波と直接和の三角関数には `f64` の固有メソッドを使う。

表の「谷と山の比」は、$f_1\le f\le f_2$ の評価点での $|X|/N$ の最小値を帯域全体の最大値で割った値である。
二つの山が分かれていれば小さく、一つの山に見えれば 1 に近い。

```rust
//| id: fft-zoom-tone-resolution
//| ref: fft-zoom-tone-resolution
//| title: 観測時間と評価点数を変える狭帯域スペクトル
//| run: reactive
//| crates: [scioxide-core, scioxide-fft]
//| inputs:
//|   sample_points: {"type":"range","label":"標本数 N（T = N/1000 s）","description":"観測時間を変え、主ローブの幅 1/T を変える。","min":256,"max":1024,"step":256,"value":256}
//|   tone_f2: {"type":"range","label":"第 2 成分の周波数 f₂ [Hz]","description":"第 1 成分は 120 Hz に固定する。","min":121,"max":126,"step":0.5,"value":122.5}
//|   zoom_factor: {"type":"range","label":"0.5 Hz 格子の細分数 s","description":"zoom FFT の刻みは 0.5/s Hz になる。","min":1,"max":10,"step":1,"value":10}
//| cases:
//|   - {"id":"long-record","label":"N = 1024","description":"T = 1.024 s で 1/T ≈ 0.98 Hz < Δf となり、二つの山の間に深い谷ができる。","inputs":{"sample_points":1024}}
//|   - {"id":"wide-separation","label":"f₂ = 126 Hz","description":"T = 0.256 s のままでも Δf = 6 Hz > 1/T で谷ができる。","inputs":{"tone_f2":126}}
//|   - {"id":"coarse-grid","label":"s = 1","description":"刻み 0.5 Hz の粗い格子。谷の深さはほとんど変わらない。","inputs":{"zoom_factor":1}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"summary","path":"/rows/0/2","approx":{"value":3.90625,"rtol":1e-12}}
//|       - {"artifact":"summary","path":"/rows/0/3","approx":{"value":0.05,"rtol":1e-9}}
//|       - {"artifact":"summary","path":"/rows/0/4","range":{"min":0.8}}
//|       - {"artifact":"summary","path":"/rows/0/5","range":{"max":1e-12}}
//|       - {"artifact":"summary","path":"/rows/0/6","range":{"max":1e-12}}
//|       - {"artifact":"summary","path":"/rows/0/7","equals":261}
//|   - case: long-record
//|     expect:
//|       - {"artifact":"summary","path":"/rows/0/4","range":{"max":0.3}}
//|       - {"artifact":"summary","path":"/rows/0/5","range":{"max":1e-12}}
//|   - case: wide-separation
//|     expect:
//|       - {"artifact":"summary","path":"/rows/0/4","range":{"max":0.5}}
//|   - case: coarse-grid
//|     expect:
//|       - {"artifact":"summary","path":"/rows/0/3","approx":{"value":0.5,"rtol":1e-9}}
//|       - {"artifact":"summary","path":"/rows/0/4","range":{"min":0.8}}
//|       - {"artifact":"summary","path":"/rows/0/7","equals":27}
use scioxide_core::Complex;
use scioxide_fft::{Normalization, fft, zoom_fft};

let (fs, n, f1, f2) = (1000.0_f64, sample_points as usize, 120.0_f64, tone_f2);
let tau = 2.0 * std::f64::consts::PI;
// 入力の生成: 振幅 1、初期位相 0 の二つの余弦波（f64 の固有メソッド）。
let input: Vec<Complex<f64>> = (0..n)
    .map(|j| {
        let t = j as f64 / fs;
        Complex::new((tau * f1 * t).cos() + (tau * f2 * t).cos(), 0.0)
    })
    .collect();
// 115〜128 Hz を端点を含めて 26 s + 1 点で評価する（刻み 0.5/s Hz）。
let (start, end, subdivisions) = (115.0_f64, 128.0_f64, zoom_factor as usize);
let m = 26 * subdivisions + 1;
let df = (end - start) / (m - 1) as f64;
let zoomed = zoom_fft(&input, start, end, m, fs, true, Normalization::Unscaled)
    .map_err(|e| e.to_string())?;
// 比較: 長さ 20000 まで零をパックした FFT（刻み 0.05 Hz）。
let padded_len = 20_000_usize;
let mut padded = vec![Complex::new(0.0, 0.0); padded_len];
padded[..n].copy_from_slice(&input);
let full = fft(&padded, Normalization::Unscaled).map_err(|e| e.to_string())?;
let (mut direct_error, mut padded_error, mut common) = (0.0_f64, 0.0_f64, 0_usize);
let (mut zoom_curve, mut reference) = (Vec::new(), Vec::new());
let (mut peak, mut valley) = (0.0_f64, f64::INFINITY);
for (k, &value) in zoomed.iter().enumerate() {
    let f = start + k as f64 * df;
    let amplitude = value.norm() / n as f64;
    zoom_curve.push([f, amplitude]);
    peak = peak.max(amplitude);
    if (f1..=f2).contains(&f) {
        valley = valley.min(amplitude);
    }
    if k % subdivisions == 0 {
        // 独立検算: DTFT の定義和 Σ x_j exp(−2πi f j / f_s)。
        let direct: Complex<f64> = input
            .iter()
            .enumerate()
            .map(|(j, &x)| {
                let phase = -tau * f * j as f64 / fs;
                x * Complex::new(phase.cos(), phase.sin())
            })
            .sum();
        direct_error = direct_error.max((value - direct).norm() / n as f64);
        reference.push([f, direct.norm() / n as f64]);
    }
    // ゼロパディング FFT の格子と一致する点だけを比べる（最近傍の点で代用しない）。
    let bin = f * padded_len as f64 / fs;
    if (bin - bin.round()).abs() < 1e-8 {
        padded_error = padded_error.max((value - full[bin.round() as usize]).norm() / n as f64);
        common += 1;
    }
}
let first_bin = (start * padded_len as f64 / fs) as usize;
let last_bin = (end * padded_len as f64 / fs) as usize;
let padded_curve: Vec<[f64; 2]> = (first_bin..=last_bin)
    .map(|k| [k as f64 * fs / padded_len as f64, full[k].norm() / n as f64])
    .collect();
emit_line_chart!(
    &vec![
        serde_json::json!({ "name": "zoom FFT", "points": zoom_curve }),
        serde_json::json!({
            "name": "ゼロパディング FFT（L = 20000）",
            "points": padded_curve,
            "style": { "lineType": "dashed", "showSymbol": false }
        }),
        serde_json::json!({
            "name": "DTFT の直接和",
            "points": reference,
            "style": { "symbol": "circle", "showSymbol": true, "lineType": "dotted" }
        })
    ],
    options = &serde_json::json!({
        "xLabel": "周波数 f [Hz]",
        "yLabel": "振幅 |X(f)|/N [-]",
        "xMin": 115.0,
        "xMax": 128.0,
        "yMin": 0.0,
        "yMax": 1.1,
        "annotations": [
            { "kind": "line", "axis": "x", "value": f1, "label": "f₁" },
            { "kind": "line", "axis": "x", "value": f2, "label": "f₂" }
        ]
    })
);
let sig3 = serde_json::json!({ "significantDigits": 3 });
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let columns = serde_json::json!([
    { "key": "0", "label": "観測時間 T [s]", "type": "number", "format": sig3 },
    { "key": "1", "label": "周波数差 Δf [Hz]", "type": "number", "format": sig3 },
    { "key": "2", "label": "主ローブの目安 1/T [Hz]", "type": "number", "format": sig3 },
    { "key": "3", "label": "zoom の刻み [Hz]", "type": "number", "format": sig3 },
    { "key": "4", "label": "谷と山の比 [-]", "type": "number", "format": sig3 },
    { "key": "5", "label": "直接和との差 / N [-]", "type": "number", "format": sci2 },
    { "key": "6", "label": "ゼロパディング FFT との差 / N [-]", "type": "number", "format": sci2 },
    { "key": "7", "label": "ゼロパディングと共通の点 [個]", "type": "integer" }
]);
let row = (
    n as f64 / fs,
    f2 - f1,
    fs / n as f64,
    df,
    valley / peak,
    direct_error,
    padded_error,
    common,
);
emit_table_with_columns!(
    columns,
    vec![row],
    metadata = serde_json::json!({ "id": "summary" })
);
```

既定の $N=256$（$T=0.256$ s、$1/T=3.91$ Hz）と $\Delta f=2.5$ Hz では、谷と山の比は 0.995 で、二つの成分は一つの山に見える。
細分数を 1 にして刻みを 0.5 Hz に粗くしても比は 0.996 で、ほとんど変わらない。
評価点を 10 倍に増やしても、山が二つに分かれることはない。

$N=1024$（$T=1.024$ s、$1/T=0.98$ Hz）では、同じ $\Delta f=2.5$ Hz で比が 0.20 に下がり、二つの山の間に深い谷ができる。
$N=256$ のまま $f_2=126$ Hz（$\Delta f=6$ Hz）にしても比は 0.40 になる。
$f_2=121$ Hz（$\Delta f=1$ Hz）では比は 0.97 で、$N=256$ では分かれない。
分かれるかどうかを決めるのは $\Delta f$ と $1/T$ の比で、格子の刻みではない。

直接和との差 $/N$ は既定で $3.5\times10^{-15}$、$N=1024$ で $2.7\times10^{-14}$、ゼロパディング FFT との差は $10^{-15}$ の桁である。
ゼロパディング FFT の曲線と重なることは、両者が同じ有限列の DTFT を評価していることの確認になる。
`zoom_fft` とゼロパディング FFT は FFT の部品を共有するので、それとは別に定義和との差を測っている。
二つの入力周波数は縦線で示したが、二つの山が重なるときは振幅の極大がその位置に来るとは限らない。

計算量は、zoom FFT が長さ $L=$ `next_fast_len`$(N+m-1)$ の FFT 3 回、ゼロパディング FFT が長さ 20000 の FFT 1 回、直接和が $Nm$ 回の複素指数関数の評価である。
既定では $N+m-1=516$ で、$L$ はそれ以上で素因数が 2、3、5、7 だけの最小の長さ 525 になる。
狭い帯域だけを細かく見るなら、zoom FFT は全帯域のゼロパディングより短い変換で済む。

## まとめ

zoom FFT は有限列の DTFT を指定した帯域の等間隔の点で評価し、長さ $N+m-1$ 程度の FFT 数回で済む。
評価点を増やすと曲線は詳しく見えるが、観測時間は変わらないので、近接した二つの成分を分ける力は変わらない。
分離の目安は矩形ウインドウの主ローブの幅 $1/T$ で、$1/T$ を $\Delta f$ より小さくするには観測時間を延ばすしかない。
直接和とゼロパディング FFT の両方に照らすと、評価点の違いと計算誤差を区別できる。
