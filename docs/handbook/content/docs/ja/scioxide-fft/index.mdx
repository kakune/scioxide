Fourier 変換は時間や空間で観測した信号や場を、正弦波（複素指数関数）の重ね合わせとして周波数の側から表す変換である。
長さ $N$ の標本列を周波数成分に変える離散 Fourier 変換（DFT）は、定義どおりに計算すると $N^2$ 回の複素乗算を要する。
Cooley と Tukey が広めた高速 Fourier 変換（FFT）は、$N$ の因数分解を使って同じ値を $O(N\log N)$ 回の演算で求める。

## 提供する変換

`scioxide-fft` の変換はスカラー型 `f32` と `f64`（およびその複素数 `Complex<f32>`、`Complex<f64>`）で動く。
公開項目は 93 個で、どれも crate の直下にある。

- 一次元の FFT は任意の長さを受け付ける（`fft`、`ifft`、実数列の `rfft`、`irfft`、Hermite 対称な列の `hfft`、`ihfft`）。
  長さの素因数から、混合基数の Cooley–Tukey、Rader、Bluestein のどれかを Plan が選ぶ。
- 多次元の FFT は行優先にパックしたスライスと形状を受け取り、選んだ軸に沿って変換する（`fftn`、`rfftn` など）。
  ストライド付きの配列は Plan `FftNdPlan` に渡す。
- 離散コサイン変換（DCT）と離散サイン変換（DST）は I〜IV の型を持つ（`dct`、`dst`、多次元の `dctn`、`dstn` と各逆変換）。
- チャープ Z 変換は複素平面の螺旋や単位円の一部の上で $z$ 変換を評価する（`czt`、`zoom_fft`、`CztPlan`）。
- 非一様 Fourier 変換（NUFFT）は、不規則な位置の Fourier 和を要求精度まで近似する（型 1・2・3 の `nufft_type1`、`nufft_type2`、`nufft_type3` と `NufftPlan`）。
- 動径方向の変換として、Bessel 関数の零点の格子による離散 Hankel 変換（`dht`、`idht`）と、対数格子の FFTLog（`fht`、`ifht`）がある。
- 周波数軸と長さを扱う関数として、`fftfreq`、`rfftfreq`、`fftshift`、`ifftshift`、`next_fast_len`、`prev_fast_len` などがある。
- 繰り返しの計算のために、Plan（`FftPlan` など）、呼び出し側が持つ作業領域（`FftWorkspace`）、上限付きの LRU キャッシュ（`FftPlanCache`）がある。
  `FftPlanningContext` は、使う CPU 命令セットの選択と、外部の FFT 実装（`FftProvider`）の注入を受け持つ。

Fourier 変換、DCT・DST、チャープ Z 変換、NUFFT の関数と Plan は、正規化（`Normalization`）を引数に取る。
離散 Hankel 変換と FFTLog は固有の積分の規約を持ち、`Normalization` を取らない。
どの変換も入力の長さをそのまま使い、ゼロパディングや切り詰めを暗黙には行わない。
ゼロパディングが必要なら、呼び出し側が配列を伸ばす。

関数（`fft`、`rfft` など）は、呼び出しのたびに Plan を作り、結果を新しい `Vec` などに入れて返す。
同じ形の変換を繰り返すときは、Plan と作業領域を一度だけ用意し、呼び出し側の出力に書く `execute_into` を使う。
`execute_into` は、`workspace_requirements` を満たす作業領域と正しい長さの出力を渡せば、ヒープを確保しない。
Plan と作業領域の準備は確保を伴い、並列のエグゼキューターが処理を配るための確保と、注入した外部実装の内部の確保は、それぞれの仕様に従う。

## 二つの正弦波の周波数

標本化周波数 $f_s = 64$ Hz で 1 秒間（$N = 64$ 点）観測した信号

$$
x(t) = \sin(2\pi\cdot 5t) + 0.5\sin(2\pi f_2 t)
$$

を `rfft` で変換する。
`rfft` は非負の周波数の $\lfloor N/2\rfloor + 1 = 33$ 個のビン $X_k$ を `HermitianSpectrum` に入れて返し、`rfftfreq(N, Δt)` はビンの周波数 $k f_s/N$ を返す。
正規化 `Normalization::Inverse` の順変換は係数を掛けないので、片側の振幅は $w_k\lvert X_k\rvert/N$ で読む。
ここで片側化の重み $w_k$ は DC（$k = 0$）と Nyquist（$2k = N$）のビンで 1、他のビンで 2 である。

セルは振幅が $10^{-9}$ を超えるビンを表 `peaks` に、ビンの数と Parseval の等式

$$
\sum_{n=0}^{N-1} x_n^2 = \frac{1}{N}\sum_{k=0}^{N/2} w_k\lvert X_k\rvert^2
$$

の両辺を表 `energy` に出す。
左辺は時間領域の標本から直接足した独立な検算で、右辺は FFT の出力から求める。
入力 $f_2$ は二つ目の正弦波の周波数 [Hz] で、32 Hz（Nyquist 周波数）を超える値では折り返しが起こる。

```rust
//| id: fft-first-spectrum
//| ref: fft-first-spectrum
//| title: 二つの正弦波の周波数と振幅を rfft で読む
//| run: reactive
//| crates: [scioxide-fft]
//| inputs:
//|   second_hz: {"type":"range","label":"二つ目の正弦波の周波数 f₂ [Hz]","description":"5 Hz の正弦波に重ねる振幅 0.5 の正弦波の周波数。32 Hz を超えると 64 − f₂ のビンへ折り返す。","min":1,"max":60,"step":1,"value":12}
//| cases:
//|   - {"id":"same-bin","label":"f₂ = 5 Hz","description":"二つの正弦波が同じビンに入り、振幅が 1.5 になる。","inputs":{"second_hz":5}}
//|   - {"id":"nyquist","label":"f₂ = 32 Hz","description":"標本がすべて sin(πn) ≈ 0 になり、二つ目の成分が消える。","inputs":{"second_hz":32}}
//|   - {"id":"aliased","label":"f₂ = 52 Hz","description":"64 − 52 = 12 Hz のビンへ折り返し、位相が +90 度になる。","inputs":{"second_hz":52}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"peaks","path":"/rows/0/0","equals":5}
//|       - {"artifact":"peaks","path":"/rows/0/2","approx":{"value":1,"atol":1e-12}}
//|       - {"artifact":"peaks","path":"/rows/1/1","approx":{"value":12,"atol":1e-12}}
//|       - {"artifact":"peaks","path":"/rows/1/2","approx":{"value":0.5,"atol":1e-12}}
//|       - {"artifact":"peaks","path":"/rows/1/3","approx":{"value":-90,"atol":1e-9}}
//|       - {"artifact":"energy","path":"/rows/0/2","equals":2}
//|       - {"artifact":"energy","path":"/rows/0/3","approx":{"value":40,"rtol":1e-12}}
//|       - {"artifact":"energy","path":"/rows/0/5","range":{"max":1e-13}}
//|   - case: same-bin
//|     expect:
//|       - {"artifact":"peaks","path":"/rows/0/2","approx":{"value":1.5,"atol":1e-12}}
//|       - {"artifact":"energy","path":"/rows/0/2","equals":1}
//|       - {"artifact":"energy","path":"/rows/0/3","approx":{"value":72,"rtol":1e-12}}
//|   - case: nyquist
//|     expect:
//|       - {"artifact":"peaks","path":"/rows/0/0","equals":5}
//|       - {"artifact":"energy","path":"/rows/0/2","equals":1}
//|       - {"artifact":"energy","path":"/rows/0/3","approx":{"value":32,"rtol":1e-12}}
//|   - case: aliased
//|     expect:
//|       - {"artifact":"peaks","path":"/rows/1/0","equals":12}
//|       - {"artifact":"peaks","path":"/rows/1/2","approx":{"value":0.5,"atol":1e-12}}
//|       - {"artifact":"peaks","path":"/rows/1/3","approx":{"value":90,"atol":1e-9}}
//|       - {"artifact":"energy","path":"/rows/0/5","range":{"max":1e-13}}
use scioxide_fft::{Normalization, rfft, rfftfreq};

// 標本化周波数 64 Hz、64 点（観測時間 1 s、ビンの間隔 1 Hz）。入力は f64 の sin で作る。
let (count, sample_rate) = (64_usize, 64.0_f64);
let pi = std::f64::consts::PI;
let samples: Vec<f64> = (0..count)
    .map(|n| {
        let t = n as f64 / sample_rate;
        (2.0 * pi * 5.0 * t).sin() + 0.5 * (2.0 * pi * second_hz * t).sin()
    })
    .collect();

// 非負周波数の 33 個のビン X_k と、その周波数 [Hz]。
let spectrum = rfft(&samples, Normalization::Inverse).map_err(|e| e.to_string())?;
let frequencies = rfftfreq(count, 1.0 / sample_rate).map_err(|e| e.to_string())?;
// 片側化の重み w_k: DC と Nyquist は 1、他は 2。
let weight = |k: usize| if k == 0 || 2 * k == count { 1.0 } else { 2.0 };
let peaks: Vec<(usize, f64, f64, f64)> = spectrum
    .bins()
    .iter()
    .enumerate()
    .map(|(k, z)| {
        let amplitude = weight(k) * z.norm() / count as f64;
        (k, frequencies[k], amplitude, z.arg() * 180.0 / pi)
    })
    .filter(|row| row.2 > 1e-9)
    .collect();

// 独立検算: 左辺 Σ x² は標本から直接足し、右辺 (1/N) Σ w_k |X_k|² は FFT の出力から求める。
let time_energy: f64 = samples.iter().map(|x| x * x).sum();
let frequency_energy = spectrum
    .bins()
    .iter()
    .enumerate()
    .map(|(k, z)| weight(k) * z.norm_sqr())
    .sum::<f64>()
    / count as f64;
let relative = ((frequency_energy - time_energy) / time_energy).abs();

let fixed1 = serde_json::json!({ "fractionDigits": 1 });
let fixed6 = serde_json::json!({ "fractionDigits": 6 });
let digits10 = serde_json::json!({ "significantDigits": 10 });
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let peak_columns = serde_json::json!([
    { "key": "0", "label": "ビン k", "type": "integer" },
    { "key": "1", "label": "周波数 [Hz]", "type": "number", "format": fixed1 },
    { "key": "2", "label": "片側の振幅 [-]", "type": "number", "format": fixed6 },
    { "key": "3", "label": "位相 [度]", "type": "number", "format": fixed1 }
]);
emit_table_with_columns!(
    peak_columns,
    peaks.clone(),
    metadata = serde_json::json!({ "id": "peaks" })
);
let energy_columns = serde_json::json!([
    { "key": "0", "label": "論理長 N", "type": "integer" },
    { "key": "1", "label": "ビンの数", "type": "integer" },
    { "key": "2", "label": "振幅が 10⁻⁹ を超えるビン", "type": "integer" },
    { "key": "3", "label": "Σ x² [-]", "type": "number", "format": digits10 },
    { "key": "4", "label": "(1/N) Σ w|X|² [-]", "type": "number", "format": digits10 },
    { "key": "5", "label": "相対差 [-]", "type": "number", "format": sci2 }
]);
emit_table_with_columns!(
    energy_columns,
    vec![(
        spectrum.logical_len(),
        spectrum.bins().len(),
        peaks.len(),
        time_energy,
        frequency_energy,
        relative,
    )],
    metadata = serde_json::json!({ "id": "energy" })
);
```

既定の $f_2 = 12$ Hz では表 `peaks` にビン 5（5 Hz、振幅 1.000000）とビン 12（12 Hz、振幅 0.500000）だけが現れ、位相はどちらも $-90$ 度である。
残り 31 個のビンの振幅は $10^{-9}$ 以下である。
表 `energy` の $\sum x_n^2$ は $64\times(1/2 + 0.5^2/2) = 40$ で、FFT の出力から求めた右辺との相対差は丸め誤差の大きさになる。

ケースを選ぶと、次の現象が見える。

- $f_2 = 5$ Hz では二つの正弦波が同じビンに入り、ビン 5 の振幅が $1 + 0.5 = 1.5$、$\sum x_n^2$ が 72 になる。
- $f_2 = 32$ Hz では二つ目の成分の標本が $\sin(\pi n) = 0$ となり（入力の生成では丸め誤差の大きさ）、この成分は標本に残らない。
  表には 5 Hz のビンだけが現れ、$\sum x_n^2 = 32$ になる。
- $f_2 = 52$ Hz の正弦波は $\sin(2\pi\cdot 52 n/64) = -\sin(2\pi\cdot 12 n/64)$ により 12 Hz のビンへ折り返し、位相が $+90$ 度になる。
  標本だけからは、符号が反対の 12 Hz の正弦波と区別できない。

## 結果の読み方

ビン $k$ の周波数は $k f_s/N$ で、間隔 $f_s/N = 1$ Hz は観測時間 1 秒で決まる。
整数 Hz の正弦波はちょうど一つのビンに入り、他のビンの値は丸め誤差の大きさになる。
周波数がビンの間に来るときの広がり（スペクトル漏れ）は [非整数周期とスペクトル漏れ](examples/spectral-leakage/) で測る。

片側の振幅は正規化の係数 $1/N$ と片側化の重み $w_k$ を掛けて読む。
$\sin(2\pi f t)$ は $\cos(2\pi f t - \pi/2)$ なので、位相は $-90$ 度になる。
正規化の選び方で振幅の係数が変わるので、`Normalization` の値を結果と一緒に記録する。

Parseval の等式の相対差は、変換が二乗和を保っているかを、FFT とは独立な時間領域の和で確かめる。
ただし、この検算は周波数の位置の誤り（周波数軸の取り違え）を見つけない。
周波数軸は `rfftfreq` と既知の入力周波数で別に確かめる。

`HermitianSpectrum` はビンと一緒に論理長 64 を持ち、`irfft` はこの長さの実数列を復元する。
33 個のビンは長さ 64 と 65 のどちらの実数列からも生じるので、論理長がないと逆変換の長さが決まらない。
32 Hz（Nyquist 周波数）を超える成分は、上のケースのように低い周波数のビンへ折り返す。
標本化と折り返しの導出は [標本化・折り返し・周波数軸](algorithms/sampling-and-frequency-axis/) にある。

このセルは関数 `rfft` を一回呼ぶ。
同じ長さの変換を何度も行うなら、`FftPlan` と `FftWorkspace` を一度だけ用意して `execute_into` を繰り返す（[FFT の Plan・作業領域・キャッシュ](algorithms/plans-workspaces-and-providers/)）。

## まとめ

`scioxide-fft` は、複素・実数・多次元の FFT、DCT・DST、チャープ Z 変換、非一様 Fourier 変換、動径方向の変換を、`f32` と `f64` の関数と Plan として提供する。
`rfft` の結果は論理長を持つ `HermitianSpectrum` で、ビンの周波数は `rfftfreq` で求め、片側の振幅は $w_k\lvert X_k\rvert/N$（正規化 `Inverse` のとき）で読む。
Nyquist 周波数を超える成分は折り返し、標本だけからは低い周波数の成分と区別できない。
ゼロパディングは暗黙には行われず、繰り返す計算では Plan と作業領域を用意すれば、`execute_into` はヒープを確保しない。
