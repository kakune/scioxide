一様な標本による Monte Carlo 積分の標準誤差は $\sigma/\sqrt N$ で、$\sigma$ は観測値 $V f(\boldsymbol X)$ の標準偏差である。
被積分関数が狭い領域に集中すると $\sigma$ が大きくなり、標本の大半は値がほぼ 0 の場所に費やされる。
適応 Monte Carlo 法は少数の学習標本で被積分関数の形を調べ、評価用の標本の置き方を変えて分散を下げる。
このページは重点標本化の提案分布を学習する VEGAS と、領域の層別化を学習する MISER を扱う。
どちらも学習に使った標本は評価の推定量に含めず、評価には新しい乱数系列を使う。

重点標本化では、単位立方体上の密度 $q$ に従う点 $\boldsymbol Y$ を直方体へ写した点 $\boldsymbol X$ について観測値 $V f(\boldsymbol X)/q(\boldsymbol Y)$ の平均をとり、この推定量は $q$ によらず不偏で、$q \propto |f|$ のとき分散が最小になる。
提案分布の条件と有効標本数の読み方は[重点標本化の提案分布と有効標本数](../importance-sampling-proposals/)、一様 Monte Carlo 法の推定量、標準誤差、区間、`VarianceBasis` は[Monte Carlo 積分の推定量と統計](../monte-carlo-integration/)で扱う。

## VEGAS による分離型の重点写像の学習

VEGAS（Lepage）は $q$ を各軸の 1 次元密度の積 $q(\boldsymbol y)=\prod_k q_k(y_k)$ に制限し、各 $q_k$ を確率 $1/K$ ずつの $K$ 個の区間（bin）を持つ区分定数の密度で表す。
軸 $k$ の境界を $0 = e_0 < e_1 < \dots < e_K = 1$ とすると、一様乱数 $u$ は区間 $j = \lfloor Ku \rfloor$ に入り、$[e_j, e_{j+1})$ へ線形に写される。
点の密度は

$$
q(\boldsymbol y) = \prod_k \frac{1}{K\,\Delta_k(\boldsymbol y)}
$$

で、$\Delta_k(\boldsymbol y)$ は $y_k$ を含む区間の幅である。
幅が狭い区間ほど密度が高い。
学習した写像 `VegasMap` は `MonteCarloProposal` を実装し、`boundaries()` は軸ごとに $K+1$ 個の境界を軸の順に並べて返す。
写像は単位立方体上で定義され、学習した直方体と組にして使う。

`VegasTrainer::train` は一様な写像から始め、決められた回数だけ反復する。
1 回の反復では、現在の写像から $N$ 個の点を引いて $f$ を評価し、各軸 $k$ について点 $y_k$ を含む区間に $(\|f\|/q)^2$ を足す。
$\|f\|$ は実数の被積分関数では絶対値、複数の実数成分では成分の Euclid ノルムで、一つの写像をすべての成分に使う。
各軸では区間の境界を次の手順で引き直す。

1. 区間の和を最大値で割り、隣の区間と平均し、合計で割って $\sum_j r_j = 1$ の $r_j$ を得る。
2. 減衰指数 $\alpha$ で $w_j = \bigl((1 - r_j)/\ln(1/r_j)\bigr)^\alpha$ と圧縮する（$r_j$ は機械イプシロンで下から抑える）。
3. 各区間の $w$ の合計が等しくなるように、現在の区間の中を線形に補間して新しい境界を置く。
4. 新しい境界を現在の境界と平均する。

ある軸に正の和がないか、新しい境界が狭義に増加しなければ、その軸は境界を変えない。
圧縮と平均は、1 回の反復の標本の揺らぎで写像が極端に動き、区間がつぶれることを防ぐ。
$\alpha$ が小さいほど写像はゆっくり変わる。

`VegasOptions::default()` は軸あたり 50 区間、反復 5 回 × 2048 標本、減衰指数 $\alpha = 1.5$、逐次実行で、`with_bins`（2 以上）、`with_iterations`、`with_samples_per_iteration`、`with_damping`（有限で正）、`with_execution_policy` で変える。
1 回の反復の計算量は $d$ 軸、$C$ 成分、$K$ 区間で $O(N(d + C) + dK)$ に $f$ の $N$ 回の評価を加えたものである。
積の形の密度は、軸に沿った構造には適応できるが、斜めの尾根や複数のピークでは、周辺分布の積が実在しない位置にも密度を置く。

## MISER による最良優先の再帰的層別化

領域を互いに重ならない部分領域（層）$\Omega_c$（体積 $V_c$）に分け、各層で独立に $n_c$ 点の一様標本の平均 $\bar f_c$ をとる層別推定量 $\hat I=\sum_c V_c\bar f_c$ の分散は $\sum_c V_c^2\sigma_c^2/n_c$ である（$\sigma_c$ は層の中での $f$ の標準偏差）。
総標本数 $n$ を固定すると、$n_c \propto V_c\sigma_c$（Neyman 配分）で分散が最小になる。
MISER（Press–Farrar）は、層の分け方と配分を試行標本で学習する。

`MiserTrainer::train` は、直方体全体を $n$ 個の評価標本を持つ一つの層として始め、次を繰り返す。

1. まだ調べていない層のうち、深さが上限より小さく、標本が 4 個以上のものから、分散への寄与の見積もり $(V_c\sigma_c)^2/n_c$ が最大の層を選ぶ。
   $\sigma_c$ は親の層の試行標本のうち、その半分に入った標本の標準偏差である。
   最初は直方体全体を選び、同点なら先に作られた層を選ぶ。
2. 選んだ層に $p$ 個の一様な試行標本を引く。
   各軸について、中点で二分した左右の半分の標本標準偏差 $\sigma_a$、$\sigma_b$ を求める（複数の成分では成分の標準偏差の Euclid ノルム）。
3. $\sigma_a + \sigma_b$ が最小の軸で層を二分し（同点なら番号の小さい軸）、下側の半分に $n_a = \lfloor n_c\sigma_a/(\sigma_a+\sigma_b) \rfloor$ を $[2, n_c - 2]$ に収めた数、上側に残りの標本を配る。
   二つの半分は体積が等しいので、これは Neyman 配分である。
   $\sigma_a + \sigma_b = 0$ なら半分ずつ配る。
   各半分に試行標本が 2 個以上入る軸がなければ、その層は分けない。

層の数が上限に達するか、選べる層がなくなると終わる。
分割は最大で（層の上限 − 1）回、評価は調べた層ごとに最大 $p$ 回である。
各層には評価標本が 2 個以上あり、合計は評価の標本数 $n$ に等しい。
この選び方は分散への寄与が大きい層から深く分ける最良優先の探索で、Press–Farrar の元の方法のように全体を深さ優先で再帰するのとは違う。

`MiserOptions::default()` は評価の設定が `MonteCarloOptions::default()`（4096 標本）、層あたり 256 個の試行標本、層の数 16 個、深さ 8 までで、`with_evaluation`、`with_pilot_samples`（4 以上）、`with_max_leaves`、`with_max_depth` で変える。
評価の設定では独立反復数を 1 にしなければならない。
学習した `MiserStrata` は、層の直方体（`strata()`）、層ごとの評価標本数（`samples()`）、層の数（`len()`）、評価の設定（`options()`）を持つ。

`MonteCarloIntegrator::stratified(strata)` は、層 $c$ に $n_c$ 個の一様な観測を割り当てて評価する。
推定値は層ごとの推定値の和、分散は層の分散の和で、統計の基準は `VarianceBasis::Strata`、自由度は Welch–Satterthwaite の有効自由度

$$
\nu = \frac{\bigl(\sum_c v_c\bigr)^2}{\sum_c v_c^2/(n_c - 1)}
$$

である（$v_c$ は層 $c$ の推定値の分散）。
`estimator_variance()` は指数範囲を広げた `Scaled` 値で返す。
この区間は学習で選ばれた層を固定したときの条件付きの区間である。
試行標本が狭いピークを一度も捉えなければ、その層のばらつきは小さく見積もられ、標準誤差も小さく出る。

## 学習と評価の分離

学習と評価は別の段階である。

1. `VegasTrainer::new(&bounds, VegasOptions)` か `MiserTrainer::new(&bounds, MiserOptions)` で学習器を作る。
2. `train(f, streams)` で写像か層と `TrainingReport` を得る（値の成分数は被積分関数の値の型から決まる）。
3. `MonteCarloIntegrator::importance(&bounds, map, options)` か `MonteCarloIntegrator::stratified(strata)` で評価の積分器を作る。
4. 別の乱数系列で `integrate_into` を呼び、作業領域の `statistics()` を読む。

学習の標本は推定量に入らないので、評価の推定値は学習した写像や層を固定したうえで不偏である。
学習と評価はどちらも乱数のブロック 0 から引くので、同じ `RandomStreams` の `stream` 番号を使うと、評価が学習と同じ一様乱数を再利用し、写像と標本が独立でなくなる。
評価には学習と異なる `stream` 番号を渡す。

`TrainingReport` は学習の終わり方を示す。
`is_success()` は所定の学習を最後まで終えたとき真で、`termination()` はそのとき `SampleBudgetCompleted` である。
`evaluations()` は学習での被積分関数の呼び出し回数、`updates()` は完了した VEGAS の反復または MISER の分割の回数である。
評価コストを比べるときは、学習の評価回数も含める。
評価回数の上限、取り消し、期限で学習が止まった場合、1 回以上の更新の後なら最後に完了した更新の写像や層を `Ok` で返し、停止を `TrainingReport` の終了状態に記録する。
最初の更新の前に止まると、`ConvergenceFailure` か `ExecutionStopped` のエラーになる。
途中まで学習した写像も有効な提案分布なので評価に使えるが、所定の学習を終えたものとは区別する。

`train` は作業領域を内部で作る簡易形である。
同じ学習器で繰り返し学習するときは、`VegasTrainer::workspace(ExecutionContext)` が返す `VegasWorkspace` と `uniform_map()` の写像を出力にして `train_into` を呼ぶ。
MISER は `MiserTrainer::workspace(components, ExecutionContext)` の `MiserWorkspace` と `initial_strata()` を使う。
どちらの作業領域も `last_attempt()` で直前の学習の記録を返す。
学習の結果は実行方針やワーカーの数によらない。

一様乱数の源 `UniformSource` は、学習では `RandomStreams` だけを受け付ける。
評価には `RandomStreams` のほか、学習した `VegasMap` を提案分布にした Plan へ `&QmcReplicatePlan` を渡し、乱択 QMC と重点標本化を組み合わせることもできる（[疎格子と乱択準 Monte Carlo](oxref:integrate-qmc-through-monte-carlo-plan)）。

## 箱の中の局在した熱源

一辺 1 m の立方体の中の点 $\boldsymbol c=(0.37,0.52,0.61)$ m に中心を持つ Gauss 型の熱源 $q_{\mathrm{h}}(\boldsymbol x)=\exp(-|\boldsymbol x-\boldsymbol c|^2/(2s^2))$ W/m³ の全出力 [W] を、一様 Monte Carlo、VEGAS、MISER で、同じ評価標本数 $2^{14}$ のもとで推定する。
VEGAS は既定の 50 区間・5 反復 × 2048 標本で写像を学習し、MISER は層 64 個・深さ 8 までの層を試行標本で学習する。
学習と三つの評価には別々の `stream` 番号を使う。
厳密値は各軸の $\sqrt{\pi/2}\,s\,[\operatorname{erf}((1-c_j)/(\sqrt2 s))+\operatorname{erf}(c_j/(\sqrt2 s))]$ の積で、`scioxide_special::erf` で求める。

次の定義のブロックは、三つのセルが使う熱源の強さ `heat_source` と、各軸の 1 次元積分 `axis_mass` を置く。
厳密値は `axis_mass` の 3 軸の積である。
あわせて、Plan を 1 本の乱数系列で実行して推定値・レポート・統計を返す `evaluate` と、表の行を作る `method_row`、`statistics_row` を置く。

```rust
//| id: integrate-localized-heat-source
//| kind: definitions
//| title: 立方体の中の Gauss 型熱源、軸ごとの厳密な積分と評価の補助関数
//| crates: [scioxide-core, scioxide-integrate, scioxide-random, scioxide-special]
use scioxide_core::{ExecutionContext, SciOxideError, RealScalar};
use scioxide_integrate::{
    IntegrationReport, MonteCarloIntegrator, MonteCarloProposal, MonteCarloStatistics,
    RandomStreams, TrainingReport,
};
use scioxide_random::Philox4x64;
use scioxide_special::erf;

// 熱源の中心 c [m]（一辺 1 m の立方体の中）。
pub(crate) const SOURCE_CENTER: [f64; 3] = [0.37, 0.52, 0.61];

// 熱源の強さ q(x) = exp(−|x − c|²/(2s²)) [W/m³]（s は熱源の幅 [m]）。
pub(crate) fn heat_source(x: &[f64], s: f64) -> f64 {
    let r2: f64 = x
        .iter()
        .zip(SOURCE_CENTER)
        .map(|(x, c)| (x - c) * (x - c))
        .sum();
    RealScalar::exp(-r2 / (2.0 * s * s))
}

// 軸 j の 1 次元積分 √(π/2) s [erf((1 − c_j)/(√2 s)) + erf(c_j/(√2 s))]（SciOxide の erf）。
pub(crate) fn axis_mass(j: usize, s: f64) -> Result<f64, String> {
    let (c, width) = (SOURCE_CENTER[j], std::f64::consts::SQRT_2 * s);
    let sum = erf((1.0 - c) / width).map_err(|e| e.to_string())?
        + erf(c / width).map_err(|e| e.to_string())?;
    Ok(RealScalar::sqrt(std::f64::consts::PI / 2.0) * s * sum)
}

// Plan を 1 本の乱数系列で実行し、推定値、レポート、作業領域の統計を返す。
pub(crate) type Evaluation = (f64, IntegrationReport<f64>, MonteCarloStatistics<f64>);
pub(crate) fn evaluate<P: MonteCarloProposal<f64> + Sync>(
    plan: &MonteCarloIntegrator<f64, P>,
    f: &(dyn Fn(&[f64]) -> Result<f64, SciOxideError> + Sync),
    streams: RandomStreams<'_, Philox4x64>,
) -> Result<Evaluation, String> {
    let context = ExecutionContext::sequential();
    let mut workspace = plan.workspace(1, context).map_err(|e| e.to_string())?;
    let mut estimate = 0.0_f64;
    let report = plan
        .integrate_into(f, streams, &mut estimate, &mut workspace, context)
        .map_err(|e| e.to_string())?;
    let statistics = workspace.statistics()[0].clone().ok_or("統計がない")?;
    Ok((estimate, report, statistics))
}

// 方法の表の 1 行: 学習と評価の評価回数、推定値、差、標準誤差、差/標準誤差、終了状態。
pub(crate) type MethodRow = (
    String,
    usize,
    usize,
    f64,
    f64,
    f64,
    f64,
    String,
    Option<String>,
);
pub(crate) fn method_row(
    name: &str,
    (estimate, report, statistics): &Evaluation,
    training: Option<&TrainingReport>,
    exact: f64,
) -> MethodRow {
    let (se, error) = (statistics.standard_error(), estimate - exact);
    let learned = training.map_or(0, |t| t.evaluations());
    let learning = training.map(|t| t.termination().to_string());
    let status = report.termination().to_string();
    let n = report.evaluations();
    (
        name.into(),
        learned,
        n,
        *estimate,
        error,
        se,
        error / se,
        status,
        learning,
    )
}

// 統計の表の 1 行: 分散の基準、独立な単位の数、自由度、有効標本数。
pub(crate) fn statistics_row(
    name: &str,
    statistics: &MonteCarloStatistics<f64>,
) -> (String, String, usize, Option<f64>, Option<f64>) {
    let basis = format!("{:?}", statistics.basis());
    let (units, dof) = (statistics.units(), statistics.degrees_of_freedom());
    (
        name.into(),
        basis,
        units,
        dof,
        statistics.effective_sample_size(),
    )
}
```

最初のセルは VEGAS の写像を学習し、一様 MC と VEGAS で評価する。
表は学習と評価の評価回数、推定値、厳密値との差、標準誤差、差と標準誤差の比、終了状態を示し、2 つ目の表は統計の基準、独立な単位の数、自由度、有効標本数を示す。
outcome は学習と評価が所定の標本を使い切ったかを示し、どちらも精度の主張を持たない成功（`SampleBudgetCompleted`）である。
このセルは熱源の幅、乱数のシード、二つの推定値と標準誤差、VEGAS が学習した区間の境界を後のセルへ渡す。

let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });

    .map(|j| axis_mass(j, s))
    .product::<Result<f64, String>>()?;

    (plain.0, plain.2.standard_error()),
    (learned.0, learned.2.standard_error()),
];
export!(source_width, s);
export!(seed, seed);
export!(vegas_bins, bins);
export!(vegas_boundaries, boundaries);
export!(results, results);

        .diagnostic("VEGAS の標準誤差", results[1].1, Some("W"))

既定値（$s=0.06$ m、シード 11）では、一様 MC の標準誤差 $2.8\times10^{-4}$ W に対し、VEGAS は $1.7\times10^{-5}$ W で約 16 分の 1 になる。
同じ標準誤差を一様 MC で得るには、標本数を約 270 倍にする必要がある。
VEGAS は学習に 10240 回の評価を使い、評価はどちらも 16384 回である。

熱源の幅を 0.3 m にすると、一様 MC の標準誤差は推定値の 0.6 % まで下がり、VEGAS の改善は約 6 倍にとどまる。

既定値（試行標本 128）では、MISER は 47 層を約 5900 回の評価で学習し、標準誤差は $4.9\times10^{-5}$ W で一様 MC の約 6 分の 1、同じ標準誤差を一様 MC で得るのに要る標本数は約 32 倍である。
差と標準誤差の比は 0.83 で、標準誤差の範囲で厳密値と合う。
MISER の自由度は Welch–Satterthwaite の値で約 31 である。
$\nu$ は層の数ではなく層ごとの分散 $v_c$ と標本数 $n_c$ で決まり、$\sum_c (n_c - 1)$ を超えない。
16384 点に対して約 31 にとどまるのは、推定量の分散への寄与に比べて標本の少ない層があるためである。
熱源の幅を 0.3 m にすると、MISER の改善は約 2 倍にとどまる。

試行標本を 16 個にすると、MISER の推定値は厳密値から標準誤差の 16 倍離れる。
少ない試行標本では熱源のある層のばらつきが小さく見積もられ、その層に少ない標本しか配られないうえ、標準誤差も小さく出るためである。
標準誤差だけではこの失敗は分からず、学習量を変えた比較や厳密値との比較が必要になる。
試行標本が 128 個でも、最初のセルのシードを 50 にすると MISER の差は標準誤差の約 5.5 倍、熱源の幅を 0.02 m にすると約 27 倍になる。
MISER の区間は学習で固定した層のもとでの条件付きの区間なので、狭い特徴を持つ被積分関数では、実際の誤差を大きく下回る標準誤差が出うる。

2 つ目のセルは、VEGAS が学習した各軸の密度 $q_k$（実線の階段）と、理想の分離型密度 $q_k^* \propto \exp(-(x - c_k)^2/(2s^2))$（破線）を描く。

```rust
//| id: integrate-vegas-learned-density
//| ref: integrate-vegas-learned-density
//| title: VEGAS が学習した各軸の密度を理想の分離型密度と比べる
//| run: button
//| uses: [integrate-localized-heat-source]
//| crates: [scioxide-core, scioxide-special]
//| dependsOn:
//|   source: integrate-adaptive-monte-carlo-source
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"density","path":"/spec/series/0/points/0/0","equals":0}
//|       - {"artifact":"density","path":"/spec/series/1/points/200/0","equals":1}
use scioxide_core::RealScalar;

let s = source["source_width"].as_f64().ok_or("熱源の幅がない")?;
let bins = source["vegas_bins"].as_u64().ok_or("区間の数がない")? as usize;
let boundaries: Vec<f64> =
    serde_json::from_value(source["vegas_boundaries"].clone()).map_err(|e| e.to_string())?;
// 学習した密度 q_k = 1/(K Δ) を階段で描き、理想の分離型密度 g_k/∫g_k を破線で重ねる。
let mut series = Vec::new();
for k in 0..3 {
    let edges = &boundaries[k * (bins + 1)..(k + 1) * (bins + 1)];
    let mut steps = Vec::new();
    for pair in edges.windows(2) {
        let height = 1.0 / (bins as f64 * (pair[1] - pair[0]));
        steps.extend([[pair[0], height], [pair[1], height]]);
    }
    let (c, mass) = (SOURCE_CENTER[k], axis_mass(k, s)?);
    let ideal: Vec<[f64; 2]> = (0..=200)
        .map(|i| i as f64 / 200.0)
        .map(|x| {
            [
                x,
                RealScalar::exp(-(x - c) * (x - c) / (2.0 * s * s)) / mass,
            ]
        })
        .collect();
    series.push(
        serde_json::json!({ "name": format!("学習した q（軸 {}）", k + 1), "points": steps }),
    );
    series.push(serde_json::json!({
        "name": format!("理想の密度（軸 {}）", k + 1),
        "points": ideal,
        "style": { "lineType": "dashed" }
    }));
}
emit_chart!(
    serde_json::json!({
        "kind": "line",
        "dataZoom": true,
        "tooltip": true,
        "series": series,
        "xLabel": "軸の座標 x_k [m]",
        "yLabel": "単位区間あたりの確率密度 q_k [1/m]",
        "xMin": 0.0,
        "xMax": 1.0
    }),
    metadata = serde_json::json!({ "id": "density" })
);
```

VEGAS の学習した密度は、各軸で熱源の中心 $c_k$ に山を持ち、理想の密度より低く広い。
減衰と境界の平均による慎重な更新のため、5 回の反復では理想の形に届かない。
VEGAS の有効標本数は 16384 点のうち約 10 点しかない。
これは提案分布が一様分布から大きく離れていることを示すだけで、この被積分関数に対する精度は標準誤差が示す（[有効標本数](oxref:integrate-effective-sample-size)）。

## まとめ

狭い領域に集中した被積分関数では、学習した重点写像（VEGAS）や層（MISER）が、同じ評価標本数で標準誤差を大きく下げうる。
VEGAS は各軸の区間に $(\|f\|/q)^2$ を集めて境界を引き直す分離型の写像、MISER は分散への寄与 $(V\sigma)^2/n$ が大きい層から二分して Neyman 配分する最良優先の層別化で、どちらも学習の標本を推定量に入れない。
評価には学習と異なる `stream` 番号を使い、学習の評価回数も計算コストに含めて比べる。
標準誤差と区間は学習で固定した写像や層のもとでの統計量で、学習が特徴を見落とすと小さく出るので、シードや学習量を変えた比較、厳密値や別の方法で確かめる。
