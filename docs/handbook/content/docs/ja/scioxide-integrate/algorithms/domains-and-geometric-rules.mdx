[テンソル積則と Genz–Malik 適応 cubature](../multidimensional-and-monte-carlo/)の `ProductRule` と `CubaturePlan` は直方体 $[a_1,b_1]\times\cdots\times[a_d,b_d]$ を前提とする。
円板や三角形のような領域を直方体に埋め込み、指示関数を掛けて積分すると、境界で被積分関数が不連続になり、求積の収束が遅くなる。
このページは領域の形を求積則の側へ渡す二つの方法、すなわち外側の座標に依存する端点の反復積分と座標写像を扱う。
あわせて、直方体の中で位置の分かっている特徴を初期領域の境界に置く `CubaturePlan::with_breakpoints` と、反復積分と cubature の終了状態の読み方を扱う。
三角形・四面体・球面上の固定則は[単体と球面の求積則](../simplex-and-sphere-rules/)で扱う。

## 可変端点の反復積分

Fubini の定理により、外側の座標に依存する端点を持つ領域上の積分は

$$
\int_\Omega f\,dV = \int_{a_0}^{b_0}\int_{a_1(t_0)}^{b_1(t_0)}\cdots\int_{a_{d-1}(t_0,\dots,t_{d-2})}^{b_{d-1}(t_0,\dots,t_{d-2})} f(t_0,\dots,t_{d-1})\,dt_{d-1}\cdots dt_0
$$

と書ける。
`IteratedDomainPlan::new(d, IteratedOptions)` は軸 0 を最も外側とし、端点の関数 `bounds(outer)` に外側の $k$ 個の座標 $t_0, \dots, t_{k-1}$ を渡して軸 $k$ の区間を受け取る。
軸の番号は渡したスライスの長さ $k$ で分かる。
次元は 0 から 32 までである。
既定の設定で一度だけ積分するワンショット関数 `integrate_iterated` は、[ワンショット呼び出しの integrate_iterated](#ワンショット呼び出しの-integrate_iterated)で扱う。
各軸は G7K15 の大域適応求積で積分し、外側の則の各節点は、それ自体が内側の積分である。
内側の積分値は推定値なので、外側の積分は内側の誤差推定を伝播する。

内側の積分 $F(t_0)=\int_{a_1(t_0)}^{b_1(t_0)}f\,dt_1$ は、端点の関数の滑らかさを受け継ぐ。
半径 $R$ の円板を $t_1\in[-\sqrt{R^2-t_0^2},\sqrt{R^2-t_0^2}]$ と書くと、$F$ は $t_0=\pm R$ で $\sqrt{R-|t_0|}$ 型の特異性を持ち、外側の適応求積は端点の近くを深く細分する。
端点の関数は領域の幾何を与える関数で、被積分関数の評価回数には数えない。
端点は有限で、下端が上端以下でなければならない（幅 0 は許される）。

### 許容誤差の内側への配分

`IteratedOptions::new(SubdivisionOptions)` の許容誤差は最も外側の積分に対するもので、分割回数と評価回数の上限はすべての軸を通して数える。
`with_max_iterations` は、外側の軸も含めた G7K15 の適用回数の上限を与える。
外側の各領域は、自分の許容誤差のうち初めは半分を内側の積分に割り当て、軸の区間全体に一様に配る。
外側の推定値がそろうまでは相対許容誤差を内側の値に当て、その後は外側の推定値で決まる $\varepsilon_{\mathrm{abs}} + \varepsilon_{\mathrm{rel}}|Q|$ を絶対量として配る。
こうすると、打ち消し合って小さくなる内側の積分にも、その値の大きさによらない目標が付く。
内側の不確かさが領域の誤差を支配すると、その領域は割合を半分にして内側の積分を計算し直す。

内側の積分が停滞（たとえば丸め誤差による精度の限界に達した場合）や細分の上限で止まっても、その推定値と誤差を外側の則へ渡す。
内側の丸め誤差による精度の限界は外側の丸めの成分に入り、残りの $\max(\text{離散化}-\text{丸め},0)+\text{内側}$ は外側の `IntegrationErrorComponents::inner` に入る。
誤差が丸め誤差による精度の限界の 2 倍以内の領域と、目標に届かず止まった内側の積分が誤差を支配する領域は、それ以上細分しない。
細分できる領域がなくなると `Stagnation` で終わる。
内側の積分で評価回数や適用回数の上限、取り消し、期限に達すると、呼び出し全体がエラーで終わる。
最も外側の区間の幅が 0 なら、結果は 0 で終了状態は `DegenerateDomain` である。

計算量は少なくとも $15^d$ 回の評価で、次元について指数的に増える。
`with_breakpoints(axis, fractions)` は各軸の現在の区間に対する比率 $(0,1)$ の分割点を与え、境界層や内部の折れ目を初期分割の端点に置く。
`plan.workspace(components)` の `IteratedWorkspace` は軸ごとの領域の一覧を $O(d\,r\,c)$ のメモリに持ち（$r$ は 1 軸の領域数）、`integrate_into` は確保を行わない。

## 座標写像と Jacobian

`CoordinateMap` は積分座標 $\boldsymbol t$ から物理座標 $\boldsymbol x=\varphi(\boldsymbol t)$ を書き込み、値 $J(\boldsymbol t)$ を返すトレイトである。
`plan.integrate_into(f, bounds, &map, &mut out, &mut workspace, scope)` は

$$
\int f(\varphi(\boldsymbol t))\,J(\boldsymbol t)\,d\boldsymbol t
$$

を計算する。
変数変換の公式に合わせるには $J = |\det D\varphi|$ を返す。
Plan は $J$ を絶対値をとらずにそのまま掛けるので、向きを反転する写像の符号付き行列式 $\det D\varphi < 0$ を返すと、積分の符号が反転する。
`Fn(&[f64], &mut [f64]) -> Result<f64, SciOxideError>` のクロージャはこのトレイトを実装し、`IdentityMap` は $\varphi(\boldsymbol t)=\boldsymbol t$、$J = 1$ の恒等写像である。
`plan.integrate(f, bounds)` は恒等写像を使う簡易形である。

極座標 $(r,\theta)\mapsto(r\cos\theta,r\sin\theta)$、$J = r$ を使えば円板は長方形 $[0,R]\times[0,2\pi]$ になり、被積分関数が滑らかなら端点の特異性は消える。
写像と $J$ の正しさは利用者の責任で、求積の誤差推定は写像の誤差を含まない。

## 円板の慣性モーメント

半径 $R=1$ m、面密度 $\rho(r)=\rho_0(1+\alpha r^2/R^2)$、$\rho_0=1$ kg/m² の円板の、中心を通り面に垂直な軸まわりの慣性モーメント

$$
I = \int_{x^2+y^2\le R^2}\rho(r)\,r^2\,dA = 2\pi\rho_0\left(\frac{R^4}{4}+\frac{\alpha R^4}{6}\right)
$$

を、直交座標の可変端点と極座標写像の二通りで計算する。
右辺の解析解を独立な参照値にする。

次の定義のブロックは、二つのセルが使う被積分関数 `inertia_density`（物理座標 $(x, y)$ での $\rho(r)\,r^2$）、直交座標の端点の関数 `disk`、極座標の長方形 `rectangle`、解析解 `exact_inertia` を置く。

```rust
//| id: integrate-disk-inertia-model
//| kind: definitions
//| title: 円板の面密度、二通りの端点の関数と慣性モーメントの解析解
//| crates: [scioxide-core]
use scioxide_core::{SciOxideError, Interval, RealScalar};
use std::f64::consts::PI;

// 円板の半径 R [m]。ρ₀ = 1 kg/m²。
pub(crate) const RADIUS: f64 = 1.0;

// 被積分関数 ρ(r) r² = (1 + α r²/R²) r²（p は物理座標 (x, y)）。
pub(crate) fn inertia_density(p: &[f64], alpha: f64) -> f64 {
    let r2 = p[0] * p[0] + p[1] * p[1];
    (1.0 + alpha * r2 / (RADIUS * RADIUS)) * r2
}

// 直交座標: 外側 x ∈ [−R, R]、内側 y ∈ [−√(R² − x²), √(R² − x²)]。
pub(crate) fn disk(outer: &[f64]) -> Result<Interval<f64>, SciOxideError> {
    match outer {
        [] => Interval::new(-RADIUS, RADIUS),
        [x, ..] => {
            let h = RealScalar::sqrt((RADIUS * RADIUS - x * x).max(0.0));
            Interval::new(-h, h)
        }
    }
}

// 極座標: (r, θ) ∈ [0, R] × [0, 2π]。
pub(crate) fn rectangle(outer: &[f64]) -> Result<Interval<f64>, SciOxideError> {
    Interval::new(0.0, if outer.is_empty() { RADIUS } else { 2.0 * PI })
}

// 解析解 I = 2π ρ₀ (R⁴/4 + α R⁴/6) [kg·m²]。
pub(crate) fn exact_inertia(alpha: f64) -> f64 {
    let r4 = RADIUS * RADIUS * RADIUS * RADIUS;
    2.0 * PI * (r4 / 4.0 + alpha * r4 / 6.0)
}
```

最初のセルは三通りの計算を同じ `IteratedDomainPlan` と作業領域で行い、評価回数、内側の積分の推定誤差、終了状態を比べる。
3 行目は方位角を逆向きに $\theta = -s$ と写し、符号付きの行列式 $-r$ を返した場合で、値が $-I$ になることを確かめる。
表の期待値の列はこの符号を含めた値である。

```rust
//| id: integrate-iterated-disk-inertia
//| ref: integrate-iterated-disk-inertia
//| title: 密度勾配と許容誤差を動かして直交座標と極座標写像の評価回数を比べる
//| run: reactive
//| uses: [integrate-disk-inertia-model]
//| crates: [scioxide-core, scioxide-integrate]
//| inputs:
//|   density_gradient: {"type":"range","label":"密度勾配 α [-]","description":"面密度 ρ(r) = ρ₀(1 + α r²/R²) の外周での増え方。","min":0,"max":4,"step":0.5,"value":1}
//|   tolerance_exponent: {"type":"range","label":"許容誤差の指数 q [-]","description":"絶対・相対許容誤差を 10^q とする。","min":-12,"max":-6,"step":1,"value":-10}
//| cases:
//|   - {"id":"loose-tolerance","label":"許容誤差 10⁻⁶","description":"直交座標でも評価回数が減るが、極座標写像は 225 回のままである。","inputs":{"tolerance_exponent":-6}}
//|   - {"id":"steep-density","label":"α = 4","description":"外周が重い円板でも、極座標では被積分関数が r の多項式なので評価回数は変わらない。","inputs":{"density_gradient":4}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"methods","path":"/rows/0/1","approx":{"value":2.6179938779914944,"rtol":1e-9}}
//|       - {"artifact":"methods","path":"/rows/1/1","approx":{"value":2.6179938779914944,"rtol":1e-12}}
//|       - {"artifact":"methods","path":"/rows/2/1","approx":{"value":-2.6179938779914944,"rtol":1e-12}}
//|       - {"artifact":"methods","path":"/rows/1/6","equals":225}
//|       - {"path":"/outputs/1/state","equals":"satisfied"}
//|   - case: loose-tolerance
//|     expect:
//|       - {"artifact":"methods","path":"/rows/0/3","range":{"min":0,"max":1e-6}}
//|       - {"artifact":"methods","path":"/rows/1/6","equals":225}
//|   - case: steep-density
//|     expect:
//|       - {"artifact":"methods","path":"/rows/1/1","approx":{"value":5.759586531581287,"rtol":1e-12}}
use scioxide_core::{Budget, ErrorTolerance, ExecutionContext, NormSelection, RealScalar};
use scioxide_integrate::{
    IntegrationReport, IteratedDomainPlan, IteratedOptions, SubdivisionOptions,
};

let sig15 = serde_json::json!({ "significantDigits": 15 });
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let alpha = density_gradient;
let tol = 10.0_f64.powf(tolerance_exponent);
let tolerance =
    ErrorTolerance::scalar(tol, tol, NormSelection::Infinity).map_err(|e| e.to_string())?;
let limit = Budget::try_from(2000).map_err(|e| e.to_string())?;
let options = SubdivisionOptions::default()
    .with_tolerance(tolerance)
    .with_max_subdivisions(limit);
let plan =
    IteratedDomainPlan::new(2, IteratedOptions::new(options)).map_err(|e| e.to_string())?;
let inertia = |p: &[f64]| Ok(inertia_density(p, alpha));
let exact = exact_inertia(alpha);
// 方法 1: 直交座標の可変端点（内側の積分は x = ±R で平方根の特異性を持つ）。
let (cartesian, report) = plan.integrate(&inertia, disk).map_err(|e| e.to_string())?;
let mut results = vec![("直交座標・可変端点", cartesian, exact, report)];
// 方法 2 と 3: (r, θ) を物理座標へ写す。σ = −1 は θ = −s と逆向きに写し、−r をそのまま返す。
let mut ws = plan.workspace(1).map_err(|e| e.to_string())?;
let context = ExecutionContext::sequential();
for (name, sign) in [
    ("極座標写像（J = r）", 1.0_f64),
    ("逆向きの写像（J = −r）", -1.0),
] {
    let map = |t: &[f64], x: &mut [f64]| {
        x[0] = t[0] * RealScalar::cos(sign * t[1]);
        x[1] = t[0] * RealScalar::sin(sign * t[1]);
        Ok(sign * t[0])
    };
    let mut value = 0.0_f64;
    let report = plan
        .integrate_into(&inertia, rectangle, &map, &mut value, &mut ws, context)
        .map_err(|e| e.to_string())?;
    results.push((name, value, sign * exact, report));
}
// 内側の積分の誤差は、外側の誤差推定の成分 inner に入る。
let row =
    |(name, value, expected, report): &(&'static str, f64, f64, IntegrationReport<f64>)| {
        let inner = report.error_components().and_then(|e| e.inner());
        let (estimate, n) = (report.error_estimate(), report.evaluations());
        let status = report.termination().to_string();
        let error = (value - expected).abs();
        let inner = inner.map(|e| e.magnitude());
        (*name, *value, *expected, error, estimate, inner, n, status)
    };
let rows: Vec<_> = results.iter().map(row).collect();
let columns = serde_json::json!([
    { "key": "0", "label": "方法" },
    { "key": "1", "label": "I [kg·m²]", "type": "number", "format": sig15 },
    { "key": "2", "label": "期待値 [kg·m²]", "type": "number", "format": sig15 },
    { "key": "3", "label": "期待値との差 [kg·m²]", "type": "number", "format": sci2 },
    { "key": "4", "label": "誤差推定 [kg·m²]", "type": "number", "format": sci2, "nullText": "なし" },
    { "key": "5", "label": "うち内側の積分 [kg·m²]", "type": "number", "format": sci2, "nullText": "なし" },
    { "key": "6", "label": "評価回数 [回]", "type": "integer" },
    { "key": "7", "label": "終了状態" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "methods" })
);
let outcome = if results.iter().all(|r| r.3.is_success()) {
    Outcome::satisfied("三つの計算がすべて許容誤差に達した")
} else {
    Outcome::partial("許容誤差に達する前に止まった計算がある")
        .explanation("表の終了状態の列で、どの計算が止まったかを確かめる。")
};
let (cartesian, polar) = (&results[0].3, &results[1].3);
emit_outcome!(
    outcome
        .status(cartesian.termination().to_string())
        .diagnostic("直交座標の評価回数", cartesian.evaluations() as f64, None)
        .diagnostic("極座標写像の評価回数", polar.evaluations() as f64, None)
);
```

既定値（$\alpha=1$、許容誤差 $10^{-10}$）では、直交座標の可変端点は約 19000 回の評価で期待値との差 $1.4\times10^{-13}$、誤差推定 $2.4\times10^{-10}$ だった。
極座標写像は 225 回（両軸とも G7K15 を 1 回ずつ、$15\times15$ 点）で差 $4\times10^{-16}$ である。
三つとも `ToleranceReached` で終わる。
直交座標の評価回数は許容誤差 $10^{-6}$ で約 11000 回、$10^{-12}$ で約 23000 回と増える。
被積分関数は内側の変数 $y$ の 4 次の多項式なので、内側の積分は G7K15 で厳密になり、内側の成分は 0 と示される。
評価回数を増やしているのは、外側から見た $F(x)$ の $x = \pm R$ での平方根の特異性である。
極座標では被積分関数 $\rho r^3$ が $r$ の多項式で $\theta$ によらないので、最初の G7K15 で受理される。
逆向きの写像は $J = -r$ をそのまま掛けた結果として $-I$ を返し、写像の向きの扱いが利用者に任されていることを示す。

### ワンショット呼び出しの integrate_iterated

ワンショット関数 `integrate_iterated(f, bounds, d)` は、既定の `IteratedOptions` の `IteratedDomainPlan` と恒等写像で積分する。
既定は絶対・相対とも $\sqrt\varepsilon \approx 1.5\times10^{-8}$ の許容誤差、すべての軸を通して分割 50 回まで、G7K15 の適用回数の上限なしで、作業領域を内部で確保して `ExecutionContext::sequential_native()` で逐次に実行する。
戻り値は値と、内側の誤差を含めた誤差推定を持つ `Integral` で、レポートは返さない。
成功しなかった終了はエラーに変わる。
`CoordinateMap` を受け取らないので、座標写像を使うときは $J$ を被積分関数に掛けて渡すか、`IteratedDomainPlan::integrate_into` を使う。
ほかのワンショット関数との対応は[ワンショット関数と設定した Plan](oxref:integrate-choosing-one-shot)にまとめてある。

次のセルは直交座標の可変端点と、$J = r$ を掛けた極座標の被積分関数を `integrate_iterated` で積分し、同じ既定値の Plan が返す評価回数と終了状態と並べる。

```rust
//| id: integrate-iterated-one-shot
//| ref: integrate-iterated-one-shot
//| title: ワンショット呼び出しの integrate_iterated を直交座標と極座標で使い、既定の Plan と比べる
//| run: reactive
//| uses: [integrate-disk-inertia-model]
//| crates: [scioxide-core, scioxide-integrate]
//| inputs:
//|   density_gradient: {"type":"range","label":"密度勾配 α [-]","description":"面密度 ρ(r) = ρ₀(1 + α r²/R²) の外周での増え方。","min":0,"max":4,"step":0.5,"value":1}
//| cases:
//|   - {"id":"uniform-disk","label":"α = 0","description":"一様な円板でも、直交座標の端点の特異性は残る。","inputs":{"density_gradient":0}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"one-shot","path":"/rows/1/2","range":{"min":0,"max":1e-12}}
//|       - {"artifact":"one-shot","path":"/rows/2/4","equals":14175}
//|       - {"path":"/outputs/1/state","equals":"satisfied"}
//|   - case: uniform-disk
//|     expect:
//|       - {"artifact":"one-shot","path":"/rows/1/1","approx":{"value":1.5707963267948966,"rtol":1e-12}}
use scioxide_core::{SciOxideError, RealScalar};
use scioxide_integrate::{Integral, IteratedDomainPlan, IteratedOptions, integrate_iterated};

let sig15 = serde_json::json!({ "significantDigits": 15 });
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let alpha = density_gradient;
let exact = exact_inertia(alpha);
let inertia = |p: &[f64]| Ok(inertia_density(p, alpha));
// ワンショット呼び出しは写像を受け取らないので、極座標では J = r を被積分関数に掛ける。
let polar = |t: &[f64]| {
    let x = [t[0] * RealScalar::cos(t[1]), t[0] * RealScalar::sin(t[1])];
    Ok(inertia_density(&x, alpha) * t[0])
};
let one_shot = |name: &str, result: Result<Integral<f64>, SciOxideError>| match result {
    Ok(r) => {
        let error = Some((r.value() - exact).abs());
        (
            name.to_owned(),
            Some(r.value()),
            error,
            Some(r.error_estimate()),
            None,
            "成功".into(),
        )
    }
    Err(e) => (
        name.to_owned(),
        None,
        None,
        None,
        None,
        format!("{:?}", e.kind()),
    ),
};
let mut rows = vec![
    one_shot(
        "integrate_iterated（直交座標）",
        integrate_iterated(&inertia, disk, 2),
    ),
    one_shot(
        "integrate_iterated（極座標、J を掛ける）",
        integrate_iterated(&polar, rectangle, 2),
    ),
];
// 同じ既定値の Plan は、止まっても推定値とレポートを返す。
let plan = IteratedDomainPlan::new(2, IteratedOptions::default()).map_err(|e| e.to_string())?;
let name = "IteratedDomainPlan（既定、直交座標）".to_owned();
rows.push(match plan.integrate(&inertia, disk) {
    Ok((value, report)) => {
        let (estimate, status) = (report.error_estimate(), report.termination().to_string());
        let error = Some((value - exact).abs());
        (
            name,
            Some(value),
            error,
            estimate,
            Some(report.evaluations()),
            status,
        )
    }
    Err(e) => (name, None, None, None, None, format!("{:?}", e.kind())),
});
let columns = serde_json::json!([
    { "key": "0", "label": "呼び出し" },
    { "key": "1", "label": "I [kg·m²]", "type": "number", "format": sig15, "nullText": "なし" },
    { "key": "2", "label": "解析解との差 [kg·m²]", "type": "number", "format": sci2, "nullText": "なし" },
    { "key": "3", "label": "誤差推定 [kg·m²]", "type": "number", "format": sci2, "nullText": "なし" },
    { "key": "4", "label": "評価回数 [回]", "type": "integer", "nullText": "レポートなし" },
    { "key": "5", "label": "終了状態またはエラー" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "one-shot" })
);
// 二つのワンショット呼び出しの成否を結論にし、同じ既定値の Plan の終了状態を添える。
let (status, evaluations) = (rows[2].5.clone(), rows[2].4.unwrap_or(0) as f64);
let outcome = if rows[0].1.is_some() && rows[1].1.is_some() {
    Outcome::satisfied("二つの integrate_iterated が既定の設定で成功した")
} else {
    Outcome::failed("推定値を返さなかったワンショット呼び出しがある")
};
emit_outcome!(
    outcome
        .status(status)
        .diagnostic("既定の Plan の評価回数", evaluations, None)
);
```

既定値（$\alpha = 1$）では、二つの `integrate_iterated` がどちらも成功する。
直交座標は解析解との差 $2.6\times10^{-11}$、誤差推定 $4.3\times10^{-8}$ で、同じ既定値の Plan は同じ値を 14175 回の評価と `ToleranceReached` で返す。
極座標は差 $4\times10^{-16}$ で、写像を渡した Plan と同じく 225 回で済む。
この円板では既定の許容誤差 $\sqrt\varepsilon$ と分割 50 回で足りるので、ワンショット呼び出しで十分である。
評価回数を知りたいとき、許容誤差や上限を変えたいとき、上限で止まった推定値も使いたいとき、作業領域を再利用したいときは `IteratedDomainPlan` を使う。

## 直方体内の特徴位置の事前分割

直方体上の被積分関数でも、折れ目や不連続の位置が分かっていれば、その位置を初期領域の境界に置ける。
`CubaturePlan::new(&bounds, options)` で直方体と許容誤差・上限を準備し、`with_breakpoints(axis, fractions)` で軸ごとの分割点を与える。
分割点 $s \in (0,1)$ は軸 $[a,b]$ を $a + s(b-a)$ で切り、$k$ 個の分割点を持つ軸は $k+1$ 個に分かれる。
初期領域はすべての軸の区間の直積で、一つの領域の一覧と優先度キューを共有する。
細分の規則は分割点のない Plan と同じで、$d = 1$ では G7K15、$d \ge 2$ では Genz–Malik 7/5 次則である。

幅が初期の節点間隔より狭いピークや、節点の間を通る不連続は、埋め込み対の差に現れずに見落とされることがある（[埋め込み対と大域適応求積](../adaptive-quadrature/)）。
位置の分かっている特徴を分割点で区切ると、その特徴が領域の内部ではなく境界に来るので、各領域の被積分関数は滑らかになり、埋め込み対の差が誤差を正しく反映するようになる。
分割点は準備のときに検査され（有限で $(0,1)$ の中、狭義に増加）、`workspace(components)` が返す `CubatureWorkspace` は初期領域の数を含めた大きさで確保される。
分割点を増やした Plan には、`workspace.check(&plan.workspace_requirements(c)?)` と `try_reserve` で既存の作業領域を広げて使える。

## 反復積分と cubature の終了の読み方

`IteratedDomainPlan` は G7K15 の差に基づく誤差推定を使い、許容誤差に達すると `ToleranceReached` を返す。
内側の積分から来る誤差は、`inner` 成分として外側の誤差推定に足される。
細分できる領域がなくなった `Stagnation` は、主に丸め誤差による精度の限界に達したか、内側の積分が目標に届かなかったことを示す。

`CubaturePlan` は、$d = 1$ では G7K15 の推定で `ToleranceReached` を返す。
$d \ge 2$ の Genz–Malik 則の誤差推定は 7 次と 5 次の差の 4 倍による経験的な推定で、`ErrorReliability::Heuristic` が付き、許容誤差の到達は `HeuristicToleranceReached` となる（[Genz–Malik 適応 cubature](oxref:integrate-genz-malik-cubature)）。
誤差推定は推定値の大きさの $50\varepsilon\sum|w_7|$ 倍を下回らないので、許容誤差がこの下限より小さいと、分割が推定値を変えなくなった時点で `Stagnation` で止まる。
標本がすべて 0 のままでは領域全体の収束を示せず、本当に 0 の関数でも上限や幾何の限界まで細分が進みうる。

## まとめ

直方体でない領域では、領域の形を指示関数ではなく求積則の側に渡す。
可変端点の `IteratedDomainPlan` は一般の領域を扱えるが、計算量は $15^d$ 回以上で、端点の関数の特異性が外側の細分を増やす。
滑らかにする `CoordinateMap` があれば使い、そのとき返す値は $|\det D\varphi|$ にする（符号付きの行列式は積分の符号を反転させる）。
内側の積分の誤差は `inner` 成分として外側の誤差推定に入るので、`IntegrationErrorComponents` でどこに誤差が残っているかを読める。
既定の許容誤差と上限で足りるならワンショット呼び出しの `integrate_iterated` で済み、座標写像を使うときは $J$ を被積分関数に掛けて渡す。
直方体の中の既知の特徴は `CubaturePlan::with_breakpoints` で初期領域の境界に置く。
