強く振動する被積分関数は、正負の波が打ち消し合うので、積分値が個々の波の面積よりずっと小さくなる。
このページは、位相が位置について線形な振動因子 $\cos(\omega x)$、$\sin(\omega x)$ を重みとして解析的に扱う方法と、その方法を周期ごとに繰り返して半直線の Fourier 積分を外挿する方法を説明する。

| 問題 | Plan | 方法 |
|---|---|---|
| 有限区間の $\cos(\omega x)$、$\sin(\omega x)$ 重み | `WeightedQuadraturePlan::fourier` | 修正 Chebyshev モーメントによる Clenshaw–Curtis 則 |
| 半直線・全実数直線の Fourier 積分 | `FourierTailPlan` | 周期ごとの積分と Wynn ε による外挿 |

位相が非線形な振動は[非線形位相の振動積分（Levin・Filon）](../phase-aware-oscillatory/)、振動しない端点特異性と無限区間は[広義積分と端点特異性の二重指数変換](../improper-singular-and-oscillatory/)で扱う。

## 振動積分の相殺

高い周波数で振動する積分

$$
I = \int_a^b A(x)\cos(\omega x + \varphi)\,dx \qquad (\omega \gg 1)
$$

では、正と負の波の面積はそれぞれ大きいが、それらが打ち消し合って積分値は $O(\omega^{-1})$ まで小さくなる。
部分積分で確かめると、主要項は端点での値 $A(b)\sin(\omega b + \varphi)/\omega - A(a)\sin(\omega a + \varphi)/\omega$ である。

一様な格子や通常の Gauss 求積は、1 波長あたりの節点数が足りないと振動を取り違える（エイリアシング）。
最短の波長に合わせて一様に細かくすると、振幅 $A(x)$ が滑らかな領域でも評価回数が振動の回数に比例して増える。
また、大きな正負の寄与の相殺は問題の条件の悪さであり、どのアルゴリズムを使っても丸め誤差は大きな寄与の絶対値に比例して残る。

## Fourier 重みと修正モーメント

振動因子を重み $w(x) = \cos(\omega x)$ または $\sin(\omega x)$ として分け、滑らかな振幅だけを補間すれば、振動を標本で追う必要がなくなる。
各領域を標準座標 $t \in [-1, 1]$ へ写し、振幅を 25 個の Chebyshev 極値点で補間する。
補間多項式の Chebyshev 係数と、修正 Chebyshev モーメント $\int_{-1}^{1} T_k(t)\,w(x(t))\,dt$ の内積が領域の積分値になる。
これを修正 Clenshaw–Curtis 則と呼ぶ。
入れ子の 13 点の則との差が離散化誤差の推定になる。

`WeightedQuadraturePlan::fourier(interval, points, omega, FourierWeight, options)` は角周波数と重みを準備し、`integrate` には振幅だけを渡す。
ワンショット関数 `integrate_fourier(f, a, b, omega, weight)` は分割点なしと既定の `WeightedQuadratureOptions`（許容誤差 $\sqrt{\varepsilon}$、二分 50 回、モーメントの深さ 16）で同じ計算をする。
成功したときだけ値と誤差の推定を `Integral` で返し、評価回数と終了状態は返さない。
許容誤差や上限を変える場合と、上限で止まったときの推定値を受け取りたい場合は Plan を使う。
この方法は位相が $\omega x$ のように位置について線形な場合に限られる。
半幅 $h$ の領域で $|\omega| h > 2$ ならモーメントの則、そうでなければ積 $A(x)w(x)$ に G7K15 を使う。
モーメントは $|\omega| h$ だけで決まり、$h$ は二分のたびに半分になるので、初期区分ごとに強く振動する深さの分だけ準備する（1 つの深さあたり高々 69 個のスカラー）。
`WeightedQuadratureOptions::with_moment_levels` はモーメントを使う二分の深さの上限で、既定は 16 である。
必要な深さだけを準備するので、大きな値を与えてもメモリは増えない。
上限の深さでなお $|\omega| h > 2$ の領域は二分されず、許容誤差を満たさなければ `RefinementLimit` で終わる。

大きな $|\omega| h$ では、入れ子の 2 つの則の差は振幅の端点付近の値でほぼ決まり、振幅の内部の跳び・折れ・尖りを見ない。
そこで各モーメント領域は振幅を補間した多項式の最高次の 2 つの Chebyshev 係数 $c_{23}, c_{24}$ から、周波数によらない目安 $2(|c_{23}| + |c_{24}|)\,L$（$L$ は領域の幅）も計算し、入れ子の差との大きい方を離散化誤差とする。
各領域は離散化の推定、丸め誤差による精度の限界、モーメントの誤差の伝播を別々に持つ。
`component_errors()` はそれぞれを全領域で足した値を `discretization`、`roundoff`、`moments` として返す。
`error_estimate()` は `total()` で、離散化と丸め誤差による精度の限界を足すのではなく大きい方をとり、それにモーメントの誤差（外挿を使えばその誤差も）を足す。
どの領域を二分するかも領域ごとの $\max(\text{離散化}, \text{丸め}) + \text{モーメント}$ で決める。

## 減衰振動の Fourier 重み付き求積

減衰する余弦 $f(x) = e^{-a x}\cos(\omega x)$ を $[0, 20]$ m で積分する。
$x$ は位置 [m]、$\omega$ は角周波数 [rad/m]、$a$ は減衰率 [1/m] で、被積分関数は無次元なので積分値の単位は m である。
`WeightedQuadraturePlan::fourier` には振幅 $e^{-ax}$ だけを渡し、振幅は `RealScalar::exp` で評価する。

検算は原始関数

$$
F(x) = \frac{e^{-ax}\bigl(-a\cos\omega x + \omega\sin\omega x\bigr)}{a^2 + \omega^2}
$$

による $F(20) - F(0)$ で、f64 の標準関数で計算する。
表の 1 行目は許容誤差 $10^{-10}$、二分 4096 回、モーメントの深さ 32 の Plan、2 行目は同じ積分を既定値で計算する `integrate_fourier` である。
ワンショット呼び出しの行は評価回数、細分回数、終了状態を返さないので空欄にする。
outcome は Plan の終了状態を示す。
図は $0$ から $x$ までの累積積分 $F(x) - F(0)$ で、正負の波が打ち消し合って小さな全区間の値（横線）に近づく様子を示す。

```rust
//| id: integrate-oscillatory-cancellation
//| ref: integrate-oscillatory-cancellation
//| title: 減衰率と周波数を動かして振動積分の累積相殺を見る
//| run: reactive
//| crates: [scioxide-core, scioxide-integrate]
//| inputs:
//|   angular_frequency: {"type":"range","label":"角周波数 ω [rad/m]","description":"振動重み cos(ωx) の周波数を変える。","min":2,"max":30,"step":1,"value":14}
//|   decay_rate: {"type":"range","label":"減衰率 a [1/m]","description":"振幅 e^(−ax) の減り方を変える。","min":0.02,"max":0.5,"step":0.02,"value":0.12}
//| cases:
//|   - {"id":"fast-decay","label":"a = 0.5 /m","description":"振幅の変化が大きく、評価回数が増える。","inputs":{"decay_rate":0.5}}
//|   - {"id":"low-frequency","label":"ω = 2 rad/m","description":"振動が遅いと全区間の値が大きくなる。","inputs":{"angular_frequency":2}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"summary","path":"/rows/0/3","range":{"min":0,"max":1e-14}}
//|       - {"artifact":"summary","path":"/rows/0/6","equals":"ToleranceReached"}
//|       - {"artifact":"summary","path":"/rows/1/3","range":{"min":0,"max":1e-9}}
//|       - {"path":"/outputs/2/state","equals":"satisfied"}
//|   - case: fast-decay
//|     expect:
//|       - {"artifact":"summary","path":"/rows/0/3","range":{"min":0,"max":1e-13}}
//|       - {"artifact":"summary","path":"/rows/0/5","range":{"min":1,"max":10}}
//|       - {"path":"/outputs/2/state","equals":"satisfied"}
//|   - case: low-frequency
//|     expect:
//|       - {"artifact":"summary","path":"/rows/0/3","range":{"min":0,"max":1e-13}}
//|       - {"artifact":"summary","path":"/rows/1/3","range":{"min":0,"max":1e-9}}
//|       - {"path":"/outputs/2/state","equals":"satisfied"}
use scioxide_core::{Budget, ErrorTolerance, Interval, NormSelection, RealScalar};
use scioxide_integrate::{
    FourierWeight, SubdivisionOptions, WeightedQuadratureOptions, WeightedQuadraturePlan,
    integrate_fourier,
};

let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let sci12 = serde_json::json!({ "notation": "scientific", "significantDigits": 12 });
let omega = angular_frequency;
let decay = decay_rate;
let end = 20.0_f64;
// 振幅 e^(−ax) だけを渡し、cos(ωx) は Plan の重みが受け持つ。
let amplitude = |x: f64| Ok(RealScalar::exp(-decay * x));

// 許容誤差 10⁻¹⁰、二分 4096 回、モーメントの深さ 32 の Plan。
let options = SubdivisionOptions::default()
    .with_tolerance(
        ErrorTolerance::scalar(1.0e-10_f64, 1.0e-10, NormSelection::Infinity)
            .map_err(|e| e.to_string())?,
    )
    .with_max_subdivisions(Budget::try_from(4096).map_err(|e| e.to_string())?);
let plan = WeightedQuadraturePlan::fourier(
    Interval::new(0.0_f64, end).map_err(|e| e.to_string())?,
    &[],
    omega,
    FourierWeight::Cosine,
    WeightedQuadratureOptions::new(options)
        .with_moment_levels(Budget::try_from(32).map_err(|e| e.to_string())?),
)
.map_err(|e| e.to_string())?;
let (value, report) = plan.integrate(&amplitude).map_err(|e| e.to_string())?;
// ワンショット呼び出し: 許容誤差 √ε、二分 50 回、モーメントの深さ 16 の既定値で 1 回だけ積分する。
let one_shot = integrate_fourier(amplitude, 0.0, end, omega, FourierWeight::Cosine)
    .map_err(|e| e.to_string())?;

// 参照値: 原始関数 F(x) による F(20) − F(0)（f64 の標準関数）。
let primitive = |x: f64| {
    (-decay * x).exp() * (-decay * (omega * x).cos() + omega * (omega * x).sin())
        / (decay * decay + omega * omega)
};
let reference = primitive(end) - primitive(0.0);
let cumulative: Vec<[f64; 2]> = (0..=240)
    .map(|index| {
        let x = end * index as f64 / 240.0;
        [x, primitive(x) - primitive(0.0)]
    })
    .collect();
emit_line_chart!(
    &vec![serde_json::json!({"name": "累積積分 F(x) − F(0)", "points": cumulative})],
    options = &serde_json::json!({
        "xLabel": "上端の位置 x [m]",
        "yLabel": "0 から x までの累積積分 [m]",
        "annotations": [
            {"kind": "line", "axis": "y", "value": reference, "label": "全区間の厳密値"}
        ]
    })
);

let rows = vec![
    (
        "Plan（許容誤差 10⁻¹⁰）",
        value,
        report.error_estimate(),
        (value - reference).abs(),
        Some(report.evaluations()),
        Some(report.subdivisions()),
        Some(report.termination().to_string()),
    ),
    (
        "integrate_fourier（既定値）",
        one_shot.value(),
        Some(one_shot.error_estimate()),
        (one_shot.value() - reference).abs(),
        None,
        None,
        None,
    ),
];
let columns = serde_json::json!([
    { "key": "0", "label": "方法" },
    { "key": "1", "label": "積分値 [m]", "type": "number", "format": sci12 },
    { "key": "2", "label": "誤差推定 [m]", "type": "number", "format": sci2, "nullText": "推定なし" },
    { "key": "3", "label": "実誤差 [m]", "type": "number", "format": sci2 },
    { "key": "4", "label": "評価回数 [回]", "type": "integer", "nullText": "返さない" },
    { "key": "5", "label": "細分回数 [回]", "type": "integer", "nullText": "返さない" },
    { "key": "6", "label": "終了状態", "nullText": "返さない" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "summary" })
);

// 結論は許容誤差 10⁻¹⁰ の Plan の終了状態で決める。
let outcome = if report.is_success() {
    Outcome::satisfied("Plan が許容誤差 10⁻¹⁰ を満たした")
} else {
    Outcome::partial("Plan が許容誤差を満たす前に止まった")
};
emit_outcome!(
    outcome
        .status(report.termination().to_string())
        .diagnostic(
            "区間内の半周期の数",
            end * omega / std::f64::consts::PI,
            None
        )
        .diagnostic("厳密値", reference, Some("m"))
        .diagnostic("評価回数", report.evaluations() as f64, None)
);
```

既定値（$\omega = 14$ rad/m、$a = 0.12$ /m）では 25 回の評価で `ToleranceReached` となり、厳密値 $-1.85 \times 10^{-3}$ m との差は $2 \times 10^{-18}$ m だった。
区間は約 89 個の半周期を含むが、振動をモーメントで積分するので、評価回数は半周期の数に比例しない。
`integrate_fourier` も同じ値と同じ誤差推定 $4.6 \times 10^{-13}$ m を返した。
$a = 0.5$ /m では振幅の変化が大きく、Plan は区間を 2 回分けて 125 回の評価を使った。
このとき `integrate_fourier` の誤差推定は $1.3 \times 10^{-10}$ m で Plan より大きいが、厳密値との差は $3 \times 10^{-17}$ m だった。

## 無限区間の Fourier 積分

半直線の Fourier 積分

$$
I = \int_a^{\infty} f(x)\cos(\omega x)\,dx \quad\text{または}\quad \int_a^{\infty} f(x)\sin(\omega x)\,dx
$$

で $f$ が $1/x$ のようにゆっくり 0 に近づくと、被積分関数は絶対可積分でないことがある。
このとき積分は正負の波の打ち消し合いによって条件収束する。
有限区間で打ち切ると誤差は $f(R)/\omega$ 程度しか減らず、[二重指数（DE）変換](../improper-singular-and-oscillatory/)の節点は遠方の振動を追えない。

### 周期ごとの積分と外挿

`FourierTailPlan` は Longman の方法に従い、半直線 $[x_0, \infty)$ を長さ

$$
L = \frac{(2\lfloor|\omega|\rfloor + 1)\,\pi}{|\omega|}
$$

の周期（cycle）に分ける。
$L$ は半周期の奇数倍なので、振幅がゆっくり変わる場合、隣り合う周期の積分は符号が交互に変わる。
$|\omega| \ge 1$ では $L$ は $3\pi/2$ より長く $3\pi$ 以下で、$\lfloor|\omega|\rfloor$ の項が周期に含む半周期の数を周波数とともに増やすので、高い周波数でも周期は $2\pi$ 程度の長さを保つ。
$|\omega| < 1$ では $L = \pi/|\omega|$ で、周期は半周期 1 つになる。

周期 $k$ の積分 $c_k$ は `WeightedQuadraturePlan::fourier` と同じ則で計算し、許容誤差の配分を $0.05 \times 0.9^k$ とする。
この配分の和は 0.5 なので、周期ごとの局所誤差に許容誤差の半分を使い、残りを外挿と尾部に残す。
部分和 $S_K = \sum_{k<K} c_k$ の列は交代級数のように振る舞うので、Wynn ε アルゴリズムで極限を外挿する（[無限級数の加速（Levin u・Wynn ε）](../series-acceleration/)）。
最初の周期は有限の端点から $\min(2/|\omega|, L/4)$ の位置で分け、端点にある可積分な特異性を Gauss–Kronrod の節点で解像する。

### 減衰を確認する指標

外挿だけでは収束を確かめられない。
周期の寄与が 0 でない極限 $\ell$ に近づく場合、交代する部分和は $\ell$ 程度振動し続けるが、Wynn ε はその Abel 平均を小さな誤差推定とともに返してしまう。
また余弦の周期積分は振幅の定数部分を 0 にするので、振幅が 0 に近づかないことは振幅そのものからしか分からない。

そこで Plan は周期の寄与の大きさ $m_k = |c_k|$ と、周期内で標本にした振幅の最大値 $v_k$ の両方を記録する。
どちらの列についても、減少 $d_k = v_{k-1} - v_k$ が次の 3 条件を満たすときだけ、その周期を減衰を確認する指標に数える。

1. $d_k$ が 2 つの値の不確かさ（$m_k$ はその誤差推定、$v_k$ は丸め）の和を超える。
2. 原点から周期の中心までの距離を $x_k$ として $L\,v_k \le 5\,|x_k|\,d_k$ が成り立つ。
   これは $|x|^{-p}$、$p \ge 1/5$ の代数的な減衰と矛盾しないことを意味する。
3. 直前の周期も数えられていれば、曲がり方が平行移動したべき乗則 $(x - x_0)^{-p}$、$p \ge 2/7$ 以下である。
   式では $v_{k-1}(d_{k-1} - d_k - u) \le \frac{9}{2}\,d_{k-1}\,d_k$ で、$u$ は曲率の不確かさである。

連続する 3 周期が数えられ、かつ 6 周期以上を積分したときに減衰が確立したとみなす。
幾何級数、べき乗則、$\ln x/\sqrt{x}$ はこの検査を通る。
0 でない極限に近づく列は 2 つの比が際限なく大きくなるので、検査を通らない。
ただし $|x|^{-2/7}$ より遅く減衰する振幅や、数周期の間に値の分解能より小さくなる極限（$10^{-6} + 1/(1+x)$ など）は、減衰と区別できない。

減衰が確立すると、尾部の推定を最後の寄与 $m_K / (1 - \rho)$ とする。
$\rho$ は直近 3 周期で隣り合う寄与の比のうち最大のものである。
外挿値の誤差推定がこの尾部より小さければ外挿値を採用し、そうでなければ部分和を採用する。
誤差の内訳は離散化、丸め、モーメント、外挿（外挿値を採用したとき）、尾部（`ErrorReliability::Heuristic`）である。

### 終了状態と尾部の診断

各半直線について、合計の誤差推定が許容誤差を満たした周期で打ち切り、尾部の状態を `HeuristicallyTruncated` にする。
すべての半直線を打ち切った後、合計の値と誤差で許容誤差を確かめ直し、満たせば `HeuristicToleranceReached`、満たさなければ `Stagnation` で終わる。
打ち切れないまま `max_cycles` 周期に達すると `RefinementLimit` で終わり、尾部の状態は `Open` のままである。
このとき値は最後の部分和または外挿値で、推定値として扱う。
周期の求積が許容誤差を満たさずに止まった場合（評価回数の上限など）は、その終了状態を返す。
ただし、丸めとモーメントの誤差の下限に達しただけの `Stagnation` は、その周期の最良の値とみなして続ける。

`FourierTailWorkspace::component_errors()` の `tail_diagnostics()` は Fourier 積分では次の意味を持つ。

- `extent()` は有限の端点から積分した長さ（周期数 × $L$）で、単位は $x$ と同じである。
  DE 積分の変換座標 $t$ とは異なる。
- `shells()` は積分した周期の数である。
- `status()` は `Open` か `HeuristicallyTruncated` だけをとる。
  `Saturated` と `Stagnated` は DE 積分（有限区間の tanh–sinh を含む）の尾部だけが返す。

`FourierDomain` は積分範囲を選ぶ。
`Upper { lower }` は $[\text{lower}, \infty)$、`Lower { upper }` は $(-\infty, \text{upper}]$ で、後者は $x \to -x$ で上側の半直線に写す（正弦重みは符号が変わる）。
`RealLine` は $(-\infty, 0]$ と $[0, \infty)$ の積分の和で、両方がそれぞれ収束しなければならない。
対称な主値 $\lim_{R\to\infty}\int_{-R}^{R}$ ではない。
`RealLine` では許容誤差を 2 つの半直線で分け合い、診断は `extent()` が大きい方、`shells()` が和、`status()` は打ち切れなかった側の状態になる。

`FourierTailOptions::new(SubdivisionOptions)` の許容誤差と上限は呼び出し全体に適用する。
`with_max_cycles` は半直線あたりの周期数の上限で、既定は 128、6 未満は `FourierTailPlan::new` が `InvalidInput` で拒む。
`with_moment_levels` は各周期のモーメントの深さ、`with_quadrature_options` は各周期を積分する設定全体を置き換える。
$\omega = 0$ も `InvalidInput` である。
`workspace(components)` で作った `FourierTailWorkspace` は 1 周期の領域、外挿の表、成分ごとの周期の履歴を持ち、`integrate_into` に繰り返し渡せる。

### 代数的に減衰する振幅の Fourier 積分

積分

$$
I(\omega) = \int_0^{\infty} \frac{\cos(\omega x)}{1 + x^2}\,dx = \frac{\pi}{2}\,e^{-\omega}
$$

を `FourierTailPlan` で計算し、閉じた形と比べる。
$x$ と $\omega$ は無次元で、振幅 $1/(1+x^2)$ は $x^{-2}$ で減衰する。
比較として、同じ被積分関数 $\cos(\omega x)/(1+x^2)$ を exp–sinh 変換の `DoubleExponentialIntegrator` で積分する。
比較の DE は段数を 10（最も細かい刻み $2^{-9}$）に抑え、評価回数を数千回以内にした。
入力は角周波数 $\omega$ と周期数の上限で、許容誤差は絶対・相対とも $10^{-10}$ とした。
DE の行の余弦は SciOxide の `RealScalar::cos` で評価し、参照値の指数関数は f64 の標準関数を使う。

表の「尾部の到達」は Fourier の行では $x$ の長さ、DE の行では変換座標 $|t|$ である。
outcome は `FourierTailPlan` の終了状態を示す。

```rust
//| id: integrate-fourier-tail
//| ref: integrate-fourier-tail
//| title: 周期数の上限を動かして半直線の Fourier 積分を外挿する
//| run: reactive
//| crates: [scioxide-core, scioxide-integrate]
//| inputs:
//|   angular_frequency: {"type":"range","label":"角周波数 ω [-]","description":"cos(ωx) の周波数を変える。","min":0.5,"max":6,"step":0.5,"value":2}
//|   max_cycles: {"type":"range","label":"周期数の上限 [周期]","description":"FourierTailOptions::with_max_cycles に渡す。","min":6,"max":128,"step":2,"value":128}
//| cases:
//|   - {"id":"few-cycles","label":"上限 6 周期","description":"減衰を確認する指標がそろう前に上限に達し、RefinementLimit の推定値になる。","inputs":{"max_cycles":6}}
//|   - {"id":"high-frequency","label":"ω = 6","description":"積分値が小さくなり、周期は短くなる。","inputs":{"angular_frequency":6}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"methods","path":"/rows/0/2","range":{"min":0,"max":1e-9}}
//|       - {"artifact":"methods","path":"/rows/0/7","equals":"HeuristicToleranceReached"}
//|       - {"path":"/outputs/1/state","equals":"satisfied"}
//|   - case: few-cycles
//|     expect:
//|       - {"artifact":"methods","path":"/rows/0/7","equals":"RefinementLimit"}
//|       - {"path":"/outputs/1/state","equals":"partial"}
//|   - case: high-frequency
//|     expect:
//|       - {"artifact":"methods","path":"/rows/0/2","range":{"min":0,"max":1e-9}}
//|       - {"path":"/outputs/1/state","equals":"satisfied"}
use scioxide_core::{Budget, ErrorTolerance, ExecutionContext, NormSelection, RealScalar};
use scioxide_integrate::{
    DoubleExponentialDomain, DoubleExponentialIntegrator, DoubleExponentialPoint,
    FourierDomain, FourierTailOptions, FourierTailPlan, FourierWeight, IntegrationReport,
    LevelOptions, SubdivisionOptions, TailDiagnostics,
};

let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let digits12 = serde_json::json!({ "significantDigits": 12 });
let digits4 = serde_json::json!({ "significantDigits": 4 });
let omega = angular_frequency;
let tolerance = ErrorTolerance::scalar(1.0e-10_f64, 1.0e-10, NormSelection::Infinity)
    .map_err(|e| e.to_string())?;
// 参照値: (π/2) e^(−ω)（f64 の標準関数）。
let exact = std::f64::consts::FRAC_PI_2 * (-omega).exp();

// 半直線 [0, ∞) の Fourier 積分。コールバックは振幅 1/(1 + x²) だけを返す。
let options =
    FourierTailOptions::new(SubdivisionOptions::default().with_tolerance(tolerance.clone()))
        .with_max_cycles(Budget::try_from(max_cycles as usize).map_err(|e| e.to_string())?);
let plan = FourierTailPlan::new(
    FourierDomain::Upper { lower: 0.0 },
    omega,
    FourierWeight::Cosine,
    options,
)
.map_err(|e| e.to_string())?;
let mut tail_workspace = plan.workspace(1).map_err(|e| e.to_string())?;
let mut fourier_value = 0.0_f64;
let fourier = plan
    .integrate_into(
        |x: f64| Ok(1.0 / (1.0 + x * x)),
        &mut fourier_value,
        &mut tail_workspace,
        ExecutionContext::sequential(),
    )
    .map_err(|e| e.to_string())?;
let fourier_tail = tail_workspace
    .component_errors()
    .and_then(|errors| errors[0].tail_diagnostics());

// 比較: 振動因子を含めた被積分関数を exp–sinh 変換で積分する。
let de = DoubleExponentialIntegrator::new(
    DoubleExponentialDomain::HalfLine { lower: 0.0 },
    // 比較用なので段数を 10 に抑え、評価回数を数千回以内にする。
    LevelOptions::default()
        .with_tolerance(tolerance)
        .with_max_levels(Budget::try_from(10).map_err(|e| e.to_string())?),
)
.map_err(|e| e.to_string())?;
let mut de_workspace = de.workspace(1).map_err(|e| e.to_string())?;
let mut de_value = 0.0_f64;
let oscillating = |point: DoubleExponentialPoint<f64>| {
    let x = point.coordinate();
    Ok(RealScalar::cos(omega * x) / (1.0 + x * x))
};
let de_report = de
    .integrate_into(
        &oscillating,
        &mut de_value,
        &mut de_workspace,
        ExecutionContext::sequential(),
    )
    .map_err(|e| e.to_string())?;
let de_tail = de_workspace
    .component_errors()
    .and_then(|errors| errors[0].tail_diagnostics());

let row = |name: &str,
           value: f64,
           report: &IntegrationReport<f64>,
           tail: Option<TailDiagnostics<f64>>| {
    (
        name.to_string(),
        value,
        (value - exact).abs(),
        report.error_estimate(),
        tail.map(|t| t.extent()),
        tail.map(|t| t.shells()),
        tail.map_or("なし".to_string(), |t| format!("{:?}", t.status())),
        report.termination().to_string(),
        report.evaluations(),
    )
};
let columns = serde_json::json!([
    { "key": "0", "label": "方法" },
    { "key": "1", "label": "積分値 [-]", "type": "number", "format": digits12 },
    { "key": "2", "label": "(π/2)e^(−ω) との差 [-]", "type": "number", "format": sci2 },
    { "key": "3", "label": "誤差推定 [-]", "type": "number", "format": sci2, "nullText": "推定なし" },
    { "key": "4", "label": "尾部の到達 [-]", "type": "number", "format": digits4, "nullText": "なし" },
    { "key": "5", "label": "周期・追加区間の数 [-]", "type": "integer", "nullText": "なし" },
    { "key": "6", "label": "尾部の状態" },
    { "key": "7", "label": "終了状態" },
    { "key": "8", "label": "評価回数 [回]", "type": "integer" }
]);
emit_table_with_columns!(
    columns,
    vec![
        row("FourierTailPlan", fourier_value, &fourier, fourier_tail),
        row("DE（exp–sinh）", de_value, &de_report, de_tail),
    ],
    metadata = serde_json::json!({ "id": "methods" })
);

let outcome = if fourier.is_success() {
    Outcome::satisfied("尾部を打ち切り、許容誤差を満たした")
        .explanation("尾部の推定は観測した減衰に基づく経験的な値で、上界ではない。")
} else {
    Outcome::partial("許容誤差を満たす前に止まった")
        .explanation("表の積分値は最後の部分和または外挿値で、推定値として扱う。")
};
let outcome = outcome
    .status(fourier.termination().to_string())
    .diagnostic("評価回数", fourier.evaluations() as f64, None)
    .diagnostic("閉じた形との差", (fourier_value - exact).abs(), None);
emit_outcome!(match fourier.error_estimate() {
    Some(estimate) => outcome.diagnostic("誤差推定", estimate, None),
    None => outcome,
});
```

既定値（$\omega = 2$）では、周期の長さは $L = 5\pi/2$ で、`FourierTailPlan` は 13 周期（$x \approx 102$ まで）を 530 回の評価で積分して `HeuristicToleranceReached` となった。
閉じた形との差は $2 \times 10^{-13}$、誤差推定は $6 \times 10^{-11}$ で、尾部の状態は `HeuristicallyTruncated` である。
振幅 $1/(1+x^2)$ は $x = 102$ でもまだ $10^{-4}$ 程度あるが、交代する部分和の外挿がその先の寄与を見込んでいる。

同じ被積分関数を exp–sinh 変換で積分すると、2057 回の評価の後に `Stagnation` で止まり、差は $7 \times 10^{-4}$ だった。
DE の尾部は $|t| = 5$ で打ち切られているが、遠方では節点の間隔が振動の周期より大きくなり、段を進めても段間の差が十分に縮まらない。
$\omega = 6$ では DE は 10 段を使い切って `RefinementLimit`（4105 回の評価、差 $8 \times 10^{-4}$）になり、`FourierTailPlan` は 12 周期・515 回で成功した。
段数の上限を既定の 15 に戻しても、DE は約 13 万回の評価で差 $9 \times 10^{-6}$ にとどまる。

周期数の上限を 6 にすると、減衰を確認する指標がそろう前に上限に達し、`RefinementLimit` と尾部の状態 `Open` で終わる。
値は最後の部分和または外挿値で、閉じた形との差は $7 \times 10^{-8}$、誤差推定は $2 \times 10^{-5}$ だった。
outcome は `partial` で、この値は許容誤差を満たしていない推定値として扱う。

## まとめ

振動積分では正負の寄与が打ち消し合い、どのアルゴリズムでも丸め誤差は大きな寄与の絶対値に比例して残るので、絶対許容誤差も指定する。
線形位相の振動は振幅だけを `WeightedQuadraturePlan::fourier` に渡し、修正モーメントの則で振動を追わずに積分する。
既定の許容誤差 $\sqrt{\varepsilon}$ でよい有限区間の積分は `integrate_fourier` で足り、成功しなければエラーになる。
半直線の Fourier 積分は `FourierTailPlan` で周期ごとに積分して外挿し、成功は振幅と周期の寄与がともに減衰する証拠を前提とする。
`max_cycles` に達した結果は `RefinementLimit` の推定値として読み、尾部の状態 `Open` と誤差推定を確かめる。
DE 変換の半直線は、振動しながらゆっくり減衰する被積分関数では停滞しやすい。
