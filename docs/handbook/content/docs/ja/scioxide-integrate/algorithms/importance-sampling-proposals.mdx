一様な標本の Monte Carlo 積分では、被積分関数の値が小さい場所にも大きい場所にも同じ密度で標本を置く。
重点標本化は値の大きい場所に多く標本を置く密度（提案分布）から点を引き、密度で割って偏りを打ち消す。
このページは重点標本化の推定量と分散、`MonteCarloIntegrator::importance` に渡す提案分布の仕様、重みの偏りを表す有効標本数を扱い、自作の提案分布で尺度と標準誤差の関係を確かめる。
提案分布を学習で作る VEGAS は[適応 Monte Carlo（VEGAS・MISER）](../adaptive-monte-carlo/)、一様 Monte Carlo 法の標準誤差と区間は[Monte Carlo 積分の推定量と統計](../monte-carlo-integration/)で扱う。

## 重点標本化の推定量と分散

単位立方体 $[0,1)^d$ 上の確率密度 $q > 0$ に従う点 $\boldsymbol Y_i$ を直方体 $B$（体積 $V$）へアフィンに写した点を $\boldsymbol X_i$ とし、観測値を

$$
Y_i = \frac{V f(\boldsymbol X_i)}{q(\boldsymbol Y_i)}
$$

とする。
$\mathbb E_q[V f/q] = \int V f\,d\boldsymbol y = I$ なので、標本平均は $q$ によらず不偏である。
分散は $\operatorname{Var}_q(Y) = \int (Vf)^2/q\,d\boldsymbol y - I^2$ で、$q \propto |f|$ のとき最小になる（$f$ の符号が一定なら 0）。
$q$ が $f$ の大きい場所を薄くしか覆わないと $f/q$ が大きな値をとり、分散はかえって増える。

## 提案分布の仕様

`MonteCarloIntegrator::importance(&bounds, proposal, options)` は、`MonteCarloProposal` トレイトを実装する提案分布 `proposal` で重点標本化を行う。
トレイトは `dimension()`（点の次元 $d$）、`uniform_count()`（1 点に使う一様乱数の個数 $m$）、`sample(uniforms, point)` を持つ。
`sample` は $[0,1)$ の一様乱数 $m$ 個を受け取って単位立方体の点を書き、その点の密度 $q$ を返す。
一様乱数は `ProposalUniforms` で渡され、構築のときに有限で $[0,1)$ にあることが検査済みである（`ProposalUniforms::new` で自分で作ることもできる）。
推定値が不偏であるには、$q$ が立方体上で積分して 1 になり、$f \ne 0$ の場所で正でなければならないが、Plan は標本からこれを確かめられない。
Plan が検査するのは、返された密度が有限で正であること、点が $[0,1)$ の中にあることだけである。
密度か座標が条件を外れると `InvalidInput`、座標が NaN か無限大なら `NonFinite` のエラーになる。
重み $1/q$ は自己正規化しない。
`sample` は一様乱数の決定論的な関数でなければならず、棄却法や適応的な標本化、Markov 連鎖による標本化は使えない。
`MonteCarloIntegrator::new` は一様な提案分布 `UniformProposal::new(d)`（$q = 1$、一様乱数をそのまま点にする）を使う。

## 有効標本数

重みの偏りの診断には Kish の有効標本数 $n_{\mathrm{eff}} = (\sum_i w_i)^2/\sum_i w_i^2$（$w_i = 1/q(\boldsymbol Y_i)$）を使う。
`MonteCarloStatistics::effective_sample_size()` と `MonteCarloChild::effective_sample_size()` が返し、一様な提案分布では $n$ に等しい。
重み $1/q$ が一部の標本に集中するほど $n_{\mathrm{eff}}$ は小さくなる。
$n_{\mathrm{eff}}$ は重みだけから決まり、被積分関数を含まないので、提案分布が一様分布からどれだけ離れているかを表す。
同じ標本を別の被積分関数に使うと、推定値が少数の標本に左右されることの警告になるが、提案分布を合わせた被積分関数に対する精度は標準誤差で判断する。
これは提案分布の診断量で、区間の自由度ではない。

## 自作の提案分布と有効標本数

[適応 Monte Carlo（VEGAS・MISER）](../adaptive-monte-carlo/)の実験と同じ、一辺 1 m の立方体の中の点 $\boldsymbol c=(0.37,0.52,0.61)$ m に中心を持つ Gauss 型の熱源 $\exp(-|\boldsymbol x-\boldsymbol c|^2/(2s^2))$ W/m³ の全出力 [W] を考える。
厳密値は各軸の $\sqrt{\pi/2}\,s\,[\operatorname{erf}((1-c_j)/(\sqrt2 s))+\operatorname{erf}(c_j/(\sqrt2 s))]$ の積で、`scioxide_special::erf` で求める。
`MonteCarloProposal` を自分で実装すると、被積分関数の形の知識を提案分布に入れられる。
この熱源に対し、各軸で中心 $c_k$、尺度 $b$ の Laplace 分布を $[0,1)$ に切り詰めた密度

$$
q_k(y) = \frac{e^{-|y - c_k|/b}}{Z_k}, \qquad Z_k = b\bigl(2 - e^{-c_k/b} - e^{-(1-c_k)/b}\bigr)
$$

の積を提案分布にする。
累積分布関数は閉じた形で逆に解けるので、一様乱数 1 個から各座標を作れる（`uniform_count()` は 3）。
次の定義のブロックはこの提案分布を `MonteCarloProposal` として実装する。
各軸の一様乱数 $u$ を $t = u(A + B)$（$A = 1 - e^{-c_k/b}$、$B = 1 - e^{-(1-c_k)/b}$、$Z_k = b(A + B)$）に写す。
$t < A$ なら左側の逆関数 $y = c_k + b\ln(t + e^{-c_k/b})$、そうでなければ右側の逆関数 $y = c_k - b\ln(1 - (t - A))$ で座標を作り、3 軸の $q_k(y)$ の積を密度として返す。

```rust
//| id: integrate-laplace-proposal
//| kind: definitions
//| title: 切り詰めた Laplace 分布の積による提案分布
//| crates: [scioxide-core, scioxide-integrate]
use scioxide_core::{SciOxideError, RealScalar};
use scioxide_integrate::{MonteCarloProposal, ProposalUniforms};

// 各軸で中心 c_k、尺度 b の Laplace 分布を [0, 1) に切り詰めた密度の積。
pub(crate) struct LaplaceProposal {
    pub(crate) center: [f64; 3],
    pub(crate) scale: f64,
}
impl MonteCarloProposal<f64> for LaplaceProposal {
    fn dimension(&self) -> usize {
        3
    }
    fn uniform_count(&self) -> usize {
        3
    }
    fn sample(
        &self,
        uniforms: ProposalUniforms<'_, f64>,
        point: &mut [f64],
    ) -> Result<f64, SciOxideError> {
        let b = self.scale;
        let mut density = 1.0;
        for (k, &u) in uniforms.as_slice().iter().enumerate() {
            let c = self.center[k];
            // 中心より左と右の質量（b を除いたもの）と正規化定数 Z = b (A + B)。
            let left = 1.0 - RealScalar::exp(-c / b);
            let right = 1.0 - RealScalar::exp(-(1.0 - c) / b);
            let t = u * (left + right);
            // 累積分布関数の逆関数: 左側は c + b ln(t + e^{−c/b})、右側は c − b ln(1 − (t − A))。
            let y = if t < left {
                c + b * RealScalar::ln(t + RealScalar::exp(-c / b))
            } else {
                c - b * RealScalar::ln(1.0 - (t - left))
            };
            point[k] = y;
            density *= RealScalar::exp(-(y - c).abs() / b) / (b * (left + right));
        }
        Ok(density)
    }
}
```

尺度 $b$ を $0.02$ から $2$ m まで動かし、標本 $2^{14}$ 個での標準誤差と、有効標本数の割合 $n_{\mathrm{eff}}/n$ を描く。
二つの図は同じ横軸 $b$ を持つので連動させ、片方を拡大するともう片方も同じ範囲になる。
破線の水平線は一様 Monte Carlo の標準誤差、縦線は熱源の幅 $s$ である。

```rust
//| id: integrate-custom-laplace-proposal
//| ref: integrate-custom-laplace-proposal
//| title: 提案分布の尺度を動かして標準誤差と有効標本数の関係を見る
//| run: button
//| uses: [integrate-laplace-proposal]
//| crates: [scioxide-core, scioxide-integrate, scioxide-random, scioxide-special]
//| timeoutMs: 120000
//| inputs:
//|   source_width: {"type":"range","label":"熱源の幅 s [m]","description":"立方体の中の Gauss 型熱源の広がり。","min":0.02,"max":0.3,"step":0.02,"value":0.06}
//|   seed: {"type":"range","label":"乱数のシード [-]","description":"評価の乱数系列の派生元のシード。","min":1,"max":50,"step":1,"value":11}
//| cases:
//|   - {"id":"wide-source","label":"s = 0.2 m","description":"熱源が広いと標準誤差が最小になる尺度も大きくなり、狭すぎる提案分布では標準誤差が信用できなくなる。","inputs":{"source_width":0.2}}
//|   - {"id":"other-seed","label":"シード 29","description":"別の乱数でも、標準誤差と有効標本数の傾向は同じである。","inputs":{"seed":29}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"scales","path":"/rows/0/1","range":{"min":0,"max":0.2}}
//|       - {"artifact":"scales","path":"/rows/9/1","range":{"min":0.8,"max":1}}
//|       - {"artifact":"scales","path":"/rows/4/4","range":{"min":-4,"max":4}}
//|   - case: wide-source
//|     expect:
//|       - {"artifact":"scales","path":"/rows/7/4","range":{"min":-4,"max":4}}
//|       - {"artifact":"scales","path":"/rows/0/4","range":{"max":-5}}
//|   - case: other-seed
//|     expect:
//|       - {"artifact":"scales","path":"/rows/4/4","range":{"min":-4,"max":4}}
use scioxide_core::{Budget, ExecutionContext, Interval, RealScalar};
use scioxide_integrate::{MonteCarloIntegrator, MonteCarloOptions, RandomStreams};
use scioxide_random::{Philox4x64, SeedableRng};
use scioxide_special::erf;

let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let (s, c) = (source_width, [0.37_f64, 0.52, 0.61]);
let f = |x: &[f64]| {
    let r2: f64 = (0..3).map(|j| (x[j] - c[j]) * (x[j] - c[j])).sum();
    Ok(RealScalar::exp(-r2 / (2.0 * s * s)))
};
// 参照値: 各軸の √(π/2) s [erf((1 − c)/(√2 s)) + erf(c/(√2 s))] の積（SciOxide の erf）。
let width = std::f64::consts::SQRT_2 * s;
let mut exact = 1.0_f64;
for &cj in &c {
    let sum = erf((1.0 - cj) / width).map_err(|e| e.to_string())?
        + erf(cj / width).map_err(|e| e.to_string())?;
    exact *= RealScalar::sqrt(std::f64::consts::PI / 2.0) * s * sum;
}
let bounds = [Interval::new(0.0_f64, 1.0).map_err(|e| e.to_string())?; 3];
let (root, context) = (
    Philox4x64::from_seed(seed as u64),
    ExecutionContext::sequential(),
);
let n = 1_usize << 14;
let options =
    MonteCarloOptions::default().with_samples(Budget::try_from(n).map_err(|e| e.to_string())?);
// 比べるための一様 Monte Carlo の標準誤差。
let uniform = MonteCarloIntegrator::new(&bounds, options).map_err(|e| e.to_string())?;
let mut workspace = uniform.workspace(1, context).map_err(|e| e.to_string())?;
let mut value = 0.0_f64;
let streams = RandomStreams::new(&root, 0);
// 標本数を固定した実行は SampleBudgetCompleted で終わるので、レポートではなく統計を読む。
let _ = uniform
    .integrate_into(&f, streams, &mut value, &mut workspace, context)
    .map_err(|e| e.to_string())?;
let uniform_se = workspace.statistics()[0]
    .as_ref()
    .ok_or("統計がない")?
    .standard_error();
let (mut se_curve, mut ess_curve, mut rows) = (Vec::new(), Vec::new(), Vec::new());
for b in [0.02_f64, 0.03, 0.05, 0.08, 0.12, 0.2, 0.3, 0.5, 1.0, 2.0] {
    let proposal = LaplaceProposal {
        center: c,
        scale: b,
    };
    let plan = MonteCarloIntegrator::importance(&bounds, proposal, options)
        .map_err(|e| e.to_string())?;
    let (streams, mut estimate) = (RandomStreams::new(&root, 1), 0.0_f64);
    let _ = plan
        .integrate_into(&f, streams, &mut estimate, &mut workspace, context)
        .map_err(|e| e.to_string())?;
    let statistics = workspace.statistics()[0].as_ref().ok_or("統計がない")?;
    let se = statistics.standard_error();
    let ess = statistics
        .effective_sample_size()
        .ok_or("有効標本数がない")?;
    se_curve.push([b, se]);
    ess_curve.push([b, ess / n as f64]);
    rows.push((b, ess / n as f64, estimate, se, (estimate - exact) / se));
}
let marker =
    serde_json::json!({ "kind": "line", "axis": "x", "value": s, "label": "熱源の幅 s" });
emit_line_chart!(
    &vec![serde_json::json!({
        "name": "Laplace 提案分布の標準誤差",
        "points": se_curve,
        "style": { "showSymbol": true }
    })],
    options = &serde_json::json!({
        "link": { "group": "proposal-scale" },
        "xLabel": "提案分布の尺度 b [m]",
        "yLabel": "標準誤差 [W]",
        "xType": "log",
        "yType": "log",
        "annotations": [
            marker.clone(),
            { "kind": "line", "axis": "y", "value": uniform_se, "label": "一様 MC の標準誤差" }
        ]
    })
);
emit_line_chart!(
    &vec![serde_json::json!({
        "name": "有効標本数の割合",
        "points": ess_curve,
        "style": { "showSymbol": true }
    })],
    options = &serde_json::json!({
        "link": { "group": "proposal-scale" },
        "xLabel": "提案分布の尺度 b [m]",
        "yLabel": "有効標本数の割合 n_eff/n [-]",
        "xType": "log",
        "yMin": 0.0,
        "yMax": 1.0,
        "annotations": [marker]
    })
);
let columns = serde_json::json!([
    { "key": "0", "label": "尺度 b [m]", "type": "number", "format": { "significantDigits": 2 } },
    { "key": "1", "label": "n_eff/n [-]", "type": "number", "format": { "fractionDigits": 3 } },
    { "key": "2", "label": "推定値 [W]", "type": "number", "format": { "significantDigits": 6 } },
    { "key": "3", "label": "標準誤差 [W]", "type": "number", "format": sci3 },
    { "key": "4", "label": "差/標準誤差 [-]", "type": "number", "format": { "fractionDigits": 2 } }

```

既定値（$s = 0.06$ m）では、標準誤差は $b = 0.05$ m で最小の $1.4\times10^{-5}$ W となり、一様 MC の $2.8\times10^{-4}$ W の約 20 分の 1 で、学習なしで、学習した VEGAS の写像（同じ標本数で $1.7\times10^{-5}$ W）と同程度まで下がる。
$b$ を熱源の幅より小さい 0.02 m にすると、標準誤差は最小値の約 10 倍に増える。
提案分布の裾が被積分関数の裾より速く減ると、まれに裾で引いた点の $f/q$ が非常に大きくなるからである。
$b$ を大きくすると提案分布は一様分布に近づき、標準誤差は一様 MC の値に戻る。

有効標本数の割合は $b \le 0.05$ m で 0.002 未満、$b$ が 0.1 m を超えると増え、$b = 2$ m で 0.98 になる。
標準誤差が最小の $b$ で有効標本数の割合はほぼ最小で、有効標本数が被積分関数ごとの精度の尺度ではないことが分かる。
熱源の幅を 0.2 m にすると、$b = 0.02$ m の推定値は厳密値から標準誤差の約 20 倍離れる。
提案分布が狭すぎると $f/q$ の分布の裾が重くなり、標本から求めた標準誤差そのものが信用できなくなる。

## まとめ

重点標本化の推定量 $V f/q$ の平均は、$q$ が立方体上で積分して 1 になり $f \ne 0$ の場所で正なら不偏で、分散は $q \propto |f|$ に近いほど小さい。
`MonteCarloProposal` は一様乱数から点と密度を決定論的に作る仕様で、Plan は密度の正値性と点の範囲だけを検査し、正規化は確かめられない。
提案分布が被積分関数より狭すぎると $f/q$ の裾が重くなり、標準誤差が増えるうえ、標本から求めた標準誤差そのものが信用できなくなる。
有効標本数は重み $1/q$ だけから決まる、提案分布と一様分布の隔たりの診断量で、特定の被積分関数に対する精度は標準誤差と厳密値との比較で判断する。
