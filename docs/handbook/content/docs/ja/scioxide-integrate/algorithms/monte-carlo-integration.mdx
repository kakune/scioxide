次元が高い積分や、不連続で決定論的な規則の収束が遅い積分では、乱数で点を置く Monte Carlo 法を使う。
その誤差は推定値に付く統計的な不確かさとして示され、[テンソル積則と Genz–Malik 適応 cubature](../multidimensional-and-monte-carlo/)の誤差推定とは性質が違う。
このページは一様 Monte Carlo 法の推定量と標準誤差、区間、複製、`MonteCarloIntegrator` の作業領域から読む統計、標本ブロックによる再現性を扱い、最後に高次元の球の体積で希少事象の難しさを確かめる。
重点標本化は[重点標本化の提案分布と有効標本数](../importance-sampling-proposals/)、学習による分散の低減は[適応 Monte Carlo（VEGAS・MISER）](../adaptive-monte-carlo/)、乱択準 Monte Carlo は[疎格子と乱択準 Monte Carlo](../sparse-grids-and-qmc/)で扱う。

## 一様 Monte Carlo 法の推定量

`MonteCarloIntegrator::new(&bounds, MonteCarloOptions)` の一様標本化では、直方体 $B$（体積 $V = \prod_k (b_k - a_k)$）上の一様分布から独立に $n$ 点 $\boldsymbol X_1, \dots, \boldsymbol X_n$ を引き、観測値 $Y_i = V f(\boldsymbol X_i)$ の標本平均

$$
\hat I_n = \frac1n \sum_{i=1}^n Y_i = \frac{V}{n} \sum_{i=1}^n f(\boldsymbol X_i)
$$

を推定値とする。

### 不偏性と標準誤差

$\boldsymbol X$ の密度は $1/V$ なので $\mathbb E[Y] = V \int_B f(\boldsymbol x)\,d\boldsymbol x / V = I$ であり、期待値の線形性から $\mathbb E[\hat I_n] = I$ となる。
すなわち $\hat I_n$ は不偏推定量である。
観測値の分散 $\sigma^2 = \operatorname{Var}(Y)$ が有限なら、独立性から推定量の分散と標準誤差（standard error、SE）は

$$
\operatorname{Var}(\hat I_n) = \frac{\sigma^2}{n}, \qquad \operatorname{SE} = \frac{\sigma}{\sqrt n}
$$

である。
指数 $-1/2$ は次元によらない。
誤差を 1/10 にするには標本を 100 倍にする必要があり、この関係は次元が増えても $\sigma$ が同じなら変わらない。
ただし $\sigma$ は被積分関数のばらつきで決まり、次元とともに大きくなる関数も多い。

$\sigma$ は未知なので、標本分散 $s^2 = \frac{1}{n-1}\sum_i (Y_i - \hat I_n)^2$ で置き換え、$\widehat{\operatorname{SE}} = s/\sqrt n$ を返す。
中心極限定理により $(\hat I_n - I)/\widehat{\operatorname{SE}}$ は $n$ が大きいと標準正規分布に近づく。
`MonteCarloIntegrator` は既定で自由度 $n - 1$ の Student-t 分布を使った両側の信頼区間

$$
\hat I_n \pm t_{(1+p)/2,\,n-1}\,\widehat{\operatorname{SE}}
$$

を返す（$p$ は信頼確率で既定 0.95）。
`MonteCarloOptions::with_interval_method(MeanIntervalMethod::NormalAsymptotic)` で正規分布の分位点に替えられる。
この区間の被覆確率は近似的な名目値である。
標本が一度も届かなかった領域の寄与は $s^2$ に現れないので、区間はそれを捉えられない。
示される標準誤差と区間は統計的な不確かさであり、誤差の上界ではない。

### 複製と分散の基準

`with_replicates(R)` で $R \ge 2$ にすると、それぞれ $n$ 点の独立な複製 $\hat I_1, \dots, \hat I_R$ を作り、その平均 $\bar I$ を推定値にする。
標準誤差は複製のばらつき

$$
s_R^2 = \frac{1}{R-1} \sum_{r=1}^R (\hat I_r - \bar I)^2, \qquad \widehat{\operatorname{SE}} = \frac{s_R}{\sqrt R}
$$

から求め、区間の自由度は $R - 1$ になる。
複製は、点の間に相関がある乱択準 Monte Carlo（[疎格子と乱択準 Monte Carlo](../sparse-grids-and-qmc/)）で正しい標準誤差を得るための方法で、独立な標本でも推定値の分布を直接見る手段になる。

`MonteCarloStatistics::basis()` は分散を何から計算したかを `VarianceBasis` で示す。

| `VarianceBasis` | 推定値 | 推定量の分散 | 自由度 |
|---|---|---|---|
| `Observations` | 1 回の実行の $n$ 個の観測値の平均 | $s^2/n$ | $n - 1$ |
| `Replicates` | $R$ 個の複製の平均 | $s_R^2/R$ | $R - 1$ |
| `Strata` | 層ごとの推定値の和 | 層の分散の和 | Welch–Satterthwaite の有効自由度 |

層別の場合は[適応 Monte Carlo（VEGAS・MISER）](../adaptive-monte-carlo/)で扱う。
重点標本化で観測値に重み $w_i = 1/q(\boldsymbol y_i)$ が付くときは、Kish の有効標本数 $(\sum_i w_i)^2 / \sum_i w_i^2$ を `effective_sample_size()` が返す。
一様標本化では $n$ に等しく、重みが不揃いなほど小さくなる。
これは提案分布の診断量で、自由度ではない。
`Observations` 以外の基準では `None` である。
読み方は[重点標本化の提案分布と有効標本数](../importance-sampling-proposals/)で扱う。

### 再現できる標本ブロック

標本は `SAMPLE_BLOCK` $= 1024$ 個ずつのブロックに分けて引く。
子（1 回の実行、各複製、各層）$c$ の $n_c$ 個の観測は $\lceil n_c/1024 \rceil$ 個のブロックを使い、ブロックには子 $0, \dots, c-1$ の後から通し番号を振る。
乱数のブロック $b$ は `RandomStreams::new(&root, stream)` のルート生成器 `root` から `root.substream(stream, b)` で取り出した部分系列から一様乱数を引く。
各ブロックは順に要約され、要約はブロックの順、子は番号の順に合成される。
そのため同じ根・`stream`・Plan・被積分関数なら、実行方針やワーカー数によらず推定値、統計、評価回数がビット単位で同じになる。
根は読むだけで進めない。
別の計算には別の `stream` 番号を渡す。

一様乱数の源は `UniformSource` で、外部から実装できない（sealed）トレイトである。
実装は独立な擬似乱数を引く `RandomStreams` と、乱択した準乱数列の複製を供給する `&scioxide_random::QmcReplicatePlan` の二つだけである。

### API と途中停止

`MonteCarloOptions::default()` は 1 複製あたり 4096 標本、1 複製、95 % の Student-t 区間、逐次実行である。
`with_samples`、`with_replicates`、`with_confidence_probability`、`with_interval_method`、`with_execution_policy` で変え、Plan の構築時に検査する（標本 2 未満と複製 0 は `InvalidInput`）。
`plan.workspace(components, ExecutionContext)` が `MonteCarloWorkspace` を作る。
実行方針が許すワーカーの数に合わせてメモリを確保するので、実行コンテキストを渡す。
`plan.integrate_into(f, source, &mut out, &mut workspace, scope)` が推定値を `out` に書き、統計を作業領域に残す。
統計は作業領域に置かれるので、`MonteCarloIntegrator` には作業領域を内部で作って捨てる `integrate` の簡易形はない。
スカラー値の積分を既定の設定で一度だけ推定するワンショット関数 `integrate_monte_carlo` は、[ワンショット呼び出しの integrate_monte_carlo](#ワンショット呼び出しの-integrate_monte_carlo)で扱う。

`workspace.statistics()` は実数成分ごとの `Option<MonteCarloStatistics>` を返す。
`MonteCarloStatistics` は `estimate()`、`standard_error()`、`estimator_variance()`（指数範囲を広げた `Scaled` 値）、`degrees_of_freedom()`、`units()`（独立な単位の数）、`samples()`（観測の総数）、`effective_sample_size()` を持つ。
`estimator_variance()` は推定量の分散で、観測値と複製では標本分散を単位の数で割った値（$s^2/n$ または $s_R^2/R$）、層では層の分散の和である。
この分散は `standard_error()` とは別に保持され、標準誤差が 0 に丸められるほど小さくても失われない。
区間はこの分散の平方根から計算する。
区間の分位点は最初の `confidence_interval()` か `interval_report()` の呼び出しで計算して値に保存するので、これらは `&mut self` をとる。
作業領域から読んだ統計は `clone()` してから呼ぶ。
`workspace.children()` は子ごとの `MonteCarloChild` を番号順に返し、`report()`、`values()`、`statistics()`、`effective_sample_size()` で各複製や各層の結果を読める。

標本の上限（評価回数、標本数）、取り消し、期限で止まった場合の扱いは子の構成で異なる。
1 回の実行は、1 個以上の観測の後に止まると、それまでの平均を `BudgetLimit` か `ExecutionStopped` の終了状態とともに `Ok` で返す。
複製と層は、すべての子が完了したときだけ推定値を出力に反映し、1 つでも止まると `ConvergenceFailure` か `ExecutionStopped` のエラーになる。
その場合も `children()` で各子がどこまで進んだかを読める。
所定の標本を使い切った正常な終了は `SampleBudgetCompleted` である。
解の回数の集計では、各観測は 1 回の被積分関数の呼び出しと、使った一様乱数の個数を合わせた評価として数える。
レポートの `evaluations()` は被積分関数の呼び出し回数である。

## 高次元の球と希少事象

Monte Carlo 法の収束の指数は次元によらないが、これは高次元の積分が常に易しいことを意味しない。
$d$ 次元単位球 $B_d = \{\boldsymbol x : \|\boldsymbol x\|_2 \le 1\}$ の体積は

$$
V_d = \frac{\pi^{d/2}}{\Gamma(d/2 + 1)}
$$

である。
外接する立方体 $[-1, 1]^d$（体積 $2^d$）から一様に引いた点が球に入る確率 $p_d = V_d / 2^d$ は、$d = 2$ で $\pi/4 \approx 0.785$、$d = 6$ で $0.0807$、$d = 10$ で $2.49\times10^{-3}$、$d = 16$ で $3.6\times10^{-6}$ と急に小さくなる。

指示関数 $\mathbf 1_{B_d}$ を立方体上で積分して球の体積を求めると、$Y_i$ は確率 $p$ で $2^d$、それ以外で 0 をとる。
推定値の相対標準誤差は

$$
\frac{\operatorname{SE}}{V_d} = \sqrt{\frac{1 - p}{N p}} \approx \frac{1}{\sqrt{N p}} \quad (p \ll 1)
$$

である（$N$ は観測の総数）。
期待される的中数 $Np$ が小さいと、相対誤差は 1 を超える。
標本が一度も球に入らなければ、推定値も標本分散も 0 になり、区間は幅 0 の $[0, 0]$ になる。
このとき示される標準誤差 0 は精度の高さではなく、情報の欠如を示す。
この問題は重点標本化（[重点標本化の提案分布と有効標本数](../importance-sampling-proposals/)）や、極座標のような領域に合った座標（[座標写像](oxref:integrate-coordinate-maps)）で避ける。

## 球の体積と複製の統計

単位球の体積を立方体上の指示関数の一様 Monte Carlo 積分で推定する。
次の定義のブロックは、三つのセルが使う指示関数 `ball_indicator` と、厳密な体積 `ball_volume` を置く。
厳密値は SciOxide の `gamma` と f64 の `powf` による参照値である。

```rust
//| id: integrate-ball-volume-model
//| kind: definitions
//| title: 単位球の指示関数と d 次元単位球の体積
//| crates: [scioxide-core, scioxide-special]
use scioxide_core::SciOxideError;
use scioxide_special::gamma;

// 単位球の指示関数。立方体 [−1, 1]^d 上の積分が球の体積になる。
pub(crate) fn ball_indicator(x: &[f64]) -> Result<f64, SciOxideError> {
    Ok(if x.iter().map(|v| v * v).sum::<f64>() <= 1.0 {
        1.0
    } else {
        0.0
    })
}

// V_d = π^(d/2) / Γ(d/2 + 1)（SciOxide の gamma と f64 の powf による参照値）。
pub(crate) fn ball_volume(d: usize) -> Result<f64, String> {
    let half = d as f64 / 2.0;
    Ok(std::f64::consts::PI.powf(half) / gamma(half + 1.0).map_err(|e| e.to_string())?)
}
```

表は推定値、厳密値、差、示された標準誤差、差と標準誤差の比、95 % 区間、自由度、分散の基準、有効標本数を示す。
グラフは `children()` で読んだ各複製の推定値と、その複製の中の観測値から求めた ±1 標準誤差である。

```rust
for (index, child) in workspace.children().enumerate() {

    let child_statistics = child.statistics()[0].as_ref().ok_or("子の統計がない")?;
    let (x, half) = (index as f64 + 1.0, child_statistics.standard_error());
    bars.push([x, value, value - half, value + half]);
}
emit_chart!(serde_json::json!({
    "kind": "errorbar",
    "xLabel": "複製の番号 r [-]",
    "yLabel": "複製の推定体積 ± 1 標準誤差 [-]",
    "series": [{ "name": "複製の推定値", "points": bars }],
    "annotations": [{ "kind": "line", "axis": "y", "value": exact, "label": "厳密体積" }]
}));
// 観測した相対標準誤差は、推定値と標準誤差が正のときだけ定義される（未定義は null）。
export!(dimension, d);
export!(total_samples, samples);
export!(observed_relative_error, (se > 0.0).then_some(se / estimate));
```

既定値（$d = 6$、1 複製 $2^{12}$ 点、$R = 4$、シード 4）では、推定体積は 5.21、厳密体積は 5.168 で、差 0.043 は示された標準誤差 0.070 の 0.6 倍である。
自由度は $R - 1 = 3$ なので、95 % 区間の半幅は $t_{0.975,3} \approx 3.18$ を掛けた 0.22 になる。
4 個の複製から求めた標準誤差は、総標本数 16384 点での理論値 $5.168 \times 0.0264 \approx 0.136$ の約半分である。
自由度 3 の標本標準偏差はそれ自体が 4 割程度ばらつくので、この程度のずれは珍しくない。
複製の数が少ないと区間の幅を決める $t$ 分位点も大きくなる。

$R = 1$ にすると、4096 個の観測値から標準誤差 0.273 が求まり、理論値 0.272 とよく合う。
このとき自由度は 4095、有効標本数は観測数と同じ 4096 になる。
$d = 12$、$2^8$ 点では期待される的中数が $Np \approx 0.08$ しかなく、標本が一度も球に入らないので、推定値・標準誤差・区間がすべて 0 になる。
この 0 の標準誤差は精度の証拠にならない。
差/標準誤差の列は未定義として表示される。

2 つ目のセルは最初のセルの次元と総標本数 $N = R\,2^q$ を受け取り、$d$ に対する的中確率 $p_d$ と相対標準誤差の理論値 $\sqrt{(1-p)/(Np)}$ を片対数で描く。
選んだ $d$ で観測した相対標準誤差を点で示す。

既定値では、$d = 6$ で観測した相対標準誤差 0.013 が理論値 0.026 の約半分にあり、上の表で見たずれと同じである。
総標本数 16384 点のままでは、相対標準誤差の理論値は $d = 12$ で 0.43、$d = 16$ で 4.1 になり、期待される的中数 $Np$ が 1 を下回る次元では推定値の桁も信用できない。

### ワンショット呼び出しの integrate_monte_carlo

ワンショット関数 `integrate_monte_carlo(f, &lower, &upper, &rng)` は、スカラー値の積分を `MonteCarloOptions::default()` の設定（4096 標本、1 複製、95 % の Student-t 区間）で一度だけ推定し、`MonteCarloStatistics` を返す。
生成器 `rng` を根として系列 0 から一様標本を引き、根を進めないので、同じ根を渡すと同じ統計になる。
作業領域と `children()` は返らないので、複製、層、重点標本化、標本数の変更が要るときは `MonteCarloIntegrator` を使う。
次元 0、幅 0 の軸、角の座標の長さの違いは評価の前に拒み、成功でない終了はエラーにする。
[ワンショット関数と設定した Plan](oxref:integrate-choosing-one-shot)にあるほかの関数と違い、戻り値は `Integral` ではなく統計そのもので、標準誤差と区間を直接読める。

次のセルは `integrate_monte_carlo` と、同じ既定値の `MonteCarloIntegrator` を同じ根の系列 0 と系列 1 で実行した結果を並べる。

```rust
//| id: integrate-monte-carlo-one-shot
//| ref: integrate-monte-carlo-one-shot
//| title: ワンショット呼び出しの integrate_monte_carlo と同じ既定値の Plan を同じ根で比べる
//| run: reactive
//| uses: [integrate-ball-volume-model]
//| crates: [scioxide-core, scioxide-integrate, scioxide-random]
//| inputs:
//|   dimension: {"type":"range","label":"空間次元 d [-]","description":"体積を推定する単位球の次元。","min":2,"max":8,"step":1,"value":4}
//|   seed: {"type":"range","label":"乱数のシード [-]","description":"根の擬似乱数生成器のシード。","min":1,"max":100,"step":1,"value":4}
//| cases:
//|   - {"id":"other-seed","label":"シード 37","description":"根を変えると三つの推定値がすべて変わり、ワンショット呼び出しと系列 0 の Plan は一致したままである。","inputs":{"seed":37}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"one-shot","path":"/rows/0/1","equals":4096}
//|       - {"artifact":"one-shot","path":"/rows/0/7","equals":4095}
//|       - {"artifact":"one-shot","path":"/rows/1/2","range":{"min":4.5,"max":5.4}}
use scioxide_core::{ExecutionContext, Interval};
use scioxide_integrate::{
    MonteCarloIntegrator, MonteCarloOptions, RandomStreams, integrate_monte_carlo,
};
use scioxide_random::{Philox4x64, SeedableRng};

let sig6 = serde_json::json!({ "significantDigits": 6 });
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let d = dimension.round() as usize;
let (root, exact) = (Philox4x64::from_seed(seed as u64), ball_volume(d)?);
let (lower, upper) = (vec![-1.0_f64; d], vec![1.0_f64; d]);
// ワンショット呼び出し: 既定の設定で根 root の系列 0 から引く。
let one_shot = integrate_monte_carlo(ball_indicator, &lower, &upper, &root);
let mut results = vec![(
    "integrate_monte_carlo",
    one_shot.map_err(|e| e.to_string())?,
)];
// 同じ既定値の Plan を、系列 0 と系列 1 で実行する。
let bounds = vec![Interval::new(-1.0_f64, 1.0).map_err(|e| e.to_string())?; d];
let plan = MonteCarloIntegrator::new(&bounds, MonteCarloOptions::default())
    .map_err(|e| e.to_string())?;
let context = ExecutionContext::sequential();
for (name, stream) in [
    ("MonteCarloIntegrator（系列 0）", 0),
    ("MonteCarloIntegrator（系列 1）", 1),
] {
    let mut workspace = plan.workspace(1, context).map_err(|e| e.to_string())?;
    let (streams, mut value) = (RandomStreams::new(&root, stream), 0.0_f64);
    let _ = plan
        .integrate_into(ball_indicator, streams, &mut value, &mut workspace, context)
        .map_err(|e| e.to_string())?;
    results.push((name, workspace.statistics()[0].clone().ok_or("統計がない")?));
}
let mut rows = Vec::new();
for (name, mut stats) in results {
    let interval = stats.confidence_interval().map_err(|e| e.to_string())?;
    let (value, se) = (stats.estimate(), stats.standard_error());
    let dof = stats.degrees_of_freedom().map(|v| v.round() as u64);
    let (low, high) = (interval.lower(), interval.upper());
    rows.push((
        name,
        stats.samples(),
        value,
        value - exact,
        se,
        low,
        high,
        dof,
    ));
}
let columns = serde_json::json!([
    { "key": "0", "label": "呼び出し" },
    { "key": "1", "label": "標本数 [点]", "type": "integer" },
    { "key": "2", "label": "推定体積 [-]", "type": "number", "format": sig6 },
    { "key": "3", "label": "厳密値との差 [-]", "type": "number", "format": sci3 },
    { "key": "4", "label": "標準誤差 [-]", "type": "number", "format": sci3 },
    { "key": "5", "label": "95 % 区間の下端 [-]", "type": "number", "format": sig6 },
    { "key": "6", "label": "95 % 区間の上端 [-]", "type": "number", "format": sig6 },
    { "key": "7", "label": "自由度 [-]", "type": "integer", "nullText": "未定義" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "one-shot" })
);
```

既定値（$d = 4$、シード 4）では、`integrate_monte_carlo` と系列 0 の Plan が同じ推定値 5.0391、標準誤差 0.116、区間 $[4.811, 5.267]$ を返し、表示したすべての桁で一致する。
系列 1 の Plan は推定値 4.7969 で、同じ根から独立な別の推定が得られる。
既定の 4096 標本で足りる精度ならワンショット呼び出しで済むが、標本数や独立反復数を変えるとき、子ごとの結果を読むとき、ベクトル値や重点標本化を使うときは `MonteCarloIntegrator` を使う。

## まとめ

一様 Monte Carlo 法の推定量は不偏で、標準誤差は次元によらず $N^{-1/2}$ で減るが、比例定数は被積分関数のばらつきで決まり、的中確率が小さいと相対誤差が大きくなる。
`MonteCarloIntegrator` は推定値を出力に書き、標準誤差・区間・自由度を `MonteCarloWorkspace::statistics()` に、複製や層ごとの結果を `children()` に残す。
`VarianceBasis` は分散を観測値・複製・層のどれから求めたかを示し、自由度と区間の読み方を決める。
示される標準誤差と区間は統計的な不確かさで、標本の届かない領域の寄与は表さないので、シードを変えた反復や厳密値で確かめる。
標本ブロックと `RandomStreams` の設計により、同じ根と `stream` 番号なら結果は実行方針によらず再現できる。
既定の 4096 標本で足りるスカラー値の積分はワンショット呼び出しの `integrate_monte_carlo` で推定でき、同じ根を渡すと系列 0 の Plan と同じ統計になる。
