一定の間隔で記録したデータ（流量、電力、加速度など）の積算や、被積分関数の性質が分からないときの最初の近似には、等間隔の節点を使う Newton–Cotes 公式が使われる。
その重みは等間隔の節点を通る補間多項式を積分して決まる。
このページでは重みの導出、Peano 核による誤差の表示、高次の型で現れる負の重み、複合則の収束次数を示し、`NewtonCotes` の使い方をまとめる。
台形則の誤差展開と、それを外挿で消す Romberg 法は[Euler–Maclaurin 展開と Romberg 外挿](../romberg-extrapolation/)で扱う。

## 記号と刻みの約束

このページでは隣り合う節点の間隔（格子間隔）を $h$ と書く。
$n$ 点の型（stencil）が占める 1 つの区画の幅は $Wh$ で、閉じた型（区画の両端を節点に含む）では $W=n-1$、開いた型（両端を含まない）では $W=n+1$ である。
区間 $[a,b]$ を $P$ 個の区画に分けた複合則では $h=(b-a)/(PW)$ になる。
`NewtonCotes::new(nodes, endpoints, panels)` の `panels` はこの区画数 $P$ で、格子の小区間の数ではない。
たとえば Simpson 則（$n=3$、閉）を `panels` $=P$ で作ると、小区間は $2P$ 個、評価回数は $2P+1$ 回になる。

## Lagrange 補間による重みの導出

節点 $x_j=a+jh$（$j=0,\dots,W$）での値 $f(x_j)$ を通る補間多項式は

$$
p(x) = \sum_{j=0}^{W} f(x_j)\,\ell_j(x), \qquad \ell_j(x) = \prod_{k\ne j}\frac{x-x_k}{x_j-x_k}
$$

である。
これを区画で積分すると閉じた Newton–Cotes 公式が得られる。

$$
\int_{x_0}^{x_W} p(x)\,dx = \sum_{j=0}^{W} w_j\,f(x_j), \qquad w_j = \int_{x_0}^{x_W}\ell_j(x)\,dx .
$$

変数 $t=(x-x_0)/h$ を入れると、重みは $h$ と無次元の係数の積になる。

$$
w_j = h\,C_j, \qquad C_j = \int_0^{W}\prod_{k\ne j}\frac{t-k}{j-k}\,dt .
$$

$n$ 点の補間は次数 $n-1$ までの多項式を再現するので、厳密次数は少なくとも $n-1$ である。
節点が区画の中心に関して対称で $n$ が奇数のときは、奇関数 $(x-c)^n$ の積分も 0 として正しく出るので、厳密次数は $n$ に上がる。
主な型は次のとおりである。
誤差は $E=\int f\,dx - Q = C\,h^{m+1}f^{(m)}(\xi)$ の形で、$\xi$ は区画内のある点、$m$ は厳密次数 $+1$ である。

| 則 | 節点数 $n$ | 型 | 区画の幅 | 重み（$h$ 単位） | 厳密次数 | 1 区画の誤差 $E$ |
|---|---:|---|---:|---|---:|---|
| 中点則 | 1 | 開 | $2h$ | $2$ | 1 | $\frac{1}{3}h^3 f''(\xi)$ |
| 台形則 | 2 | 閉 | $h$ | $\frac12,\ \frac12$ | 1 | $-\frac{1}{12}h^3 f''(\xi)$ |
| Simpson 則 | 3 | 閉 | $2h$ | $\frac13,\ \frac43,\ \frac13$ | 3 | $-\frac{1}{90}h^5 f^{(4)}(\xi)$ |
| Simpson の 3/8 則 | 4 | 閉 | $3h$ | $\frac38,\ \frac98,\ \frac98,\ \frac38$ | 3 | $-\frac{3}{80}h^5 f^{(4)}(\xi)$ |
| Boole 則 | 5 | 閉 | $4h$ | $\frac{14}{45},\ \frac{64}{45},\ \frac{24}{45},\ \frac{64}{45},\ \frac{14}{45}$ | 5 | $-\frac{8}{945}h^7 f^{(6)}(\xi)$ |

誤差の式は $f$ が $C^m$ 級（$m$ 階まで連続微分可能）の場合に成り立つ。

## Peano 核による中点則と台形則の誤差

この節だけは 1 つの区間 $[a,b]$ の幅を $H=b-a$、中点を $c=(a+b)/2$ と書く。
台形則では $H=h$、中点則と Simpson 則では $H=2h$ である。
中点則 $M=Hf(c)$ と台形則 $T=\frac H2\bigl(f(a)+f(b)\bigr)$ はどちらも 1 次式を厳密に積分する。
1 次式を厳密に積分する則の誤差は、$f\in C^2[a,b]$ なら 2 階導関数 $f''$ の重み付き積分で表せる（Peano 核定理）。

$$
E[f] = \int_a^b K(t)\,f''(t)\,dt .
$$

核 $K$ は則ごとに決まり、

$$
K_M(t)=\begin{cases}\frac12(t-a)^2 & (a\le t<c)\\ \frac12(b-t)^2 & (c\le t\le b)\end{cases},
\qquad
K_T(t) = -\frac12(t-a)(b-t)
$$

である。
どちらの核も区間で符号が一定（$K_M\ge0$、$K_T\le0$）なので、積分の平均値の定理から

$$
E_M = \frac{H^3}{24}f''(\xi_M), \qquad E_T = -\frac{H^3}{12}f''(\xi_T)
$$

が得られる。
$f''$ がほぼ一定なら、台形則の誤差は中点則の誤差の約 $-2$ 倍である。
下に凸な関数（$f''>0$）では、台形則は真値を過大に、中点則は過小に見積もる。

## Simpson 則と次数の上昇

2 つの誤差の主要部が打ち消すように組み合わせると

$$
S = \frac{2M+T}{3} = \frac H6\bigl(f(a)+4f(c)+f(b)\bigr)
$$

となり、これは Simpson 則である。
$f''$ を一定とみなすと誤差は $\frac13\bigl(2\cdot\frac{H^3}{24}-\frac{H^3}{12}\bigr)f''=0$ になり、$H^3$ の項が消える。
節点が中心 $c$ に関して対称なので、$(x-c)^3$ の積分も正しく 0 になり、厳密次数は 3 になる。
4 階導関数まで Peano 核を進めると、$f\in C^4[a,b]$ に対して

$$
E_S = -\frac{H^5}{2880}f^{(4)}(\xi) = -\frac{h^5}{90}f^{(4)}(\xi)
$$

が得られる（$H=2h$）。

## 高次の型と重みの符号

点数を増やすと厳密次数は上がるが、ある点数から重みに負の値が現れる。
重みの絶対値和が大きいと、関数値の誤差 $\delta$ が和で $\sum_j|w_j|\,\delta$ まで増幅される。
`NewtonCotes` は 1〜11 点の開いた型と 2〜11 点の閉じた型を提供し、それより大きい型は重みが大きく交互の符号を持つので提供しない。
重みは有理数として厳密に計算し、区間に写した重みを 1 回だけ丸める。

次のセルは 1 区画の則（`panels` $=1$）について、型ごとの性質を表にする。
`exactness_degree()` は厳密次数、`error_order()` は誤差項の導関数の階数 $m$、`error_coefficient()` は上の誤差の式の係数 $C$、`weight_amplification()` は $\sum_j|w_j|/W$（単位間隔の重みの絶対値和を区画の幅で割った値）を返す。
`weights()` は単位間隔 $h=1$ での重みで、その負の値の数も数える。
確かめる点は表の係数（台形則 $-1/12$、Simpson 則 $-1/90$、Boole 則 $-8/945$、中点則 $1/3$）との一致と、増幅率が 1 を超える型である。

```rust
//| id: integrate-newton-cotes-stencils
//| ref: integrate-newton-cotes-stencils
//| title: Newton–Cotes の型ごとの厳密次数・誤差係数・重みの増幅率
//| run: reactive
//| crates: [scioxide-core, scioxide-integrate]
//| inputs:
//|   endpoint_kind: {"type":"select","label":"端点の扱い","description":"閉じた型は区画の両端を節点に含め、開いた型は含めない。","options":["Closed","Open"],"value":"Closed"}
//| cases:
//|   - {"id":"open","label":"開いた型","description":"開いた型は 1 点（中点則）から始まり、増幅率が閉じた型より早く 1 を超える。","inputs":{"endpoint_kind":"Open"}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"stencils","path":"/rows/1/4","approx":{"value":-0.011111111111111112,"rtol":1e-12}}
//|       - {"artifact":"stencils","path":"/rows/6/5","approx":{"value":1.0,"atol":1e-12}}
//|       - {"artifact":"stencils","path":"/rows/7/3","equals":3}
//|       - {"artifact":"stencils","path":"/rows/9/5","range":{"min":1.5,"max":10}}
//|   - case: open
//|     expect:
//|       - {"artifact":"stencils","path":"/rows/0/4","approx":{"value":0.3333333333333333,"rtol":1e-12}}
use scioxide_core::Budget;
use scioxide_integrate::{NewtonCotes, NewtonCotesEndpoints};

let (endpoints, smallest) = match endpoint_kind.as_str() {
    "Open" => (NewtonCotesEndpoints::Open, 1),
    _ => (NewtonCotesEndpoints::Closed, 2),
};
// 1 区画だけの則で、型の性質（厳密次数、誤差項、重み）を読む。
let mut rows = Vec::new();
for nodes in smallest..=11 {
    let rule =
        NewtonCotes::<f64>::new(nodes, endpoints, Budget::ONE).map_err(|e| e.to_string())?;
    let negative = rule
        .weights()
        .iter()
        .filter(|&&weight| weight < 0.0)
        .count();
    rows.push((
        nodes,
        rule.exactness_degree(),
        rule.error_order(),
        negative,
        rule.error_coefficient(),
        rule.weight_amplification(),
    ));
}
let sci4 = serde_json::json!({ "notation": "scientific", "significantDigits": 4 });
let sig4 = serde_json::json!({ "significantDigits": 4 });
let columns = serde_json::json!([
    { "key": "0", "label": "節点数 n [点]", "type": "integer" },
    { "key": "1", "label": "厳密次数 [-]", "type": "integer" },
    { "key": "2", "label": "誤差項の導関数の階数 m [-]", "type": "integer" },
    { "key": "3", "label": "負の重みの数 [個]", "type": "integer" },
    { "key": "4", "label": "誤差係数 C [-]", "type": "number", "format": sci4 },
    { "key": "5", "label": "重みの増幅率 Σ|w_j|/W [-]", "type": "number", "format": sig4 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "stencils" })
);
```


閉じた型では 2〜8 点と 10 点の重みはすべて正で、増幅率は 1 だった。
9 点の型は 3 個の負の重みを持って増幅率 $1.45$、11 点の型は増幅率 $3.06$ になった。
開いた型では 3 点ですでに負の重みが現れ（増幅率 $1.67$）、11 点では増幅率が $96$ に達した。
誤差係数は表の値（台形則 $-0.08333$、Simpson 則 $-0.01111$、3/8 則 $-0.0375$、Boole 則 $-0.008466$、中点則 $0.3333$）と一致した。
高い精度が必要なときは、点数を増やすより、低次の型を多くの区画に並べる複合則か、節点を自由に選ぶ [Gauss 型の則](../gaussian-and-clenshaw-curtis/)を使う。

## 複合則と大域的な収束次数

$[a,b]$ を $P$ 個の区画に分け、各区画に同じ型を当てて足した則を複合則と呼ぶ。
閉じた型では隣の区画と共有する端点を 1 回だけ評価するので、評価回数は $P(n-1)+1$ である。
複合台形則は

$$
T(h) = h\Bigl[\frac{f(a)+f(b)}{2}+\sum_{k=1}^{P-1}f(a+kh)\Bigr], \qquad h=\frac{b-a}{P}
$$

である。
1 区画の誤差 $C h^{m+1}f^{(m)}(\xi_p)$ を $P=(b-a)/(Wh)$ 個の区画で足すと、$f^{(m)}$ が連続なら中間値の定理から

$$
E = \sum_{p=1}^{P} C\,h^{m+1}f^{(m)}(\xi_p) = \frac{C}{W}(b-a)\,h^m f^{(m)}(\eta)
$$

となる。
台形則では $-\frac{b-a}{12}h^2f''(\eta)$、Simpson 則では $-\frac{b-a}{180}h^4f^{(4)}(\eta)$ で、大域誤差は $O(h^m)$ になる。
$h\to0$ では区画ごとの和が積分に近づくので、主誤差項は

$$
E \approx \frac{C}{W}\,h^m\bigl[f^{(m-1)}(b)-f^{(m-1)}(a)\bigr]
$$

とも書ける。

次のセルは $f(x)=e^{\lambda x}$ を $[0,1]$ で積分し、厳密値 $(e^\lambda-1)/\lambda$ との差を評価回数 $N$ に対して描く。
入力は増加率 $\lambda$ である。
実線は複合台形・Simpson・Boole 則の実際の誤差、破線は `error_coefficient()` と上の主誤差項の式による予測で、$f^{(m-1)}(1)-f^{(m-1)}(0)=\lambda^{m-1}(e^\lambda-1)$ を使う。
両対数軸で、傾きはそれぞれ $-2$、$-4$、$-6$ になるはずである。
表は区画数 16 から 32 への誤差比による観測次数、区画数 32 での誤差と主誤差項の比を示す。
最後の列は同じ格子の標本を `integrate_samples_into` に渡した値と `integrate` の値の差で、保存した等間隔標本にも同じ則を使えることを確かめる。
$10^{-14}$ 以下の誤差は丸めの水準なので図から除き、除いた点の数を表の最後の列に示す。

```rust
//| id: integrate-composite-orders
//| ref: integrate-composite-orders
//| title: 複合台形・Simpson・Boole 則の誤差を評価回数と誤差項の予測で比べる
//| run: reactive
//| crates: [scioxide-core, scioxide-integrate]
//| inputs:
//|   growth_rate: {"type":"range","label":"指数の増加率 λ [-]","description":"e^(λx) の高階導関数の大きさ λ^m e^λ を変える。","min":0.5,"max":8,"step":0.5,"value":2}
//| cases:
//|   - {"id":"steep","label":"λ = 8","description":"高階導関数が大きく、同じ評価回数での誤差が増えるが、傾きは変わらない。","inputs":{"growth_rate":8}}
//|   - {"id":"gentle","label":"λ = 0.5","description":"Boole 則の誤差が区画数 32 で 0 になり、観測次数を定義しない。","inputs":{"growth_rate":0.5}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"orders","path":"/rows/0/1","approx":{"value":2.0,"atol":0.02}}
//|       - {"artifact":"orders","path":"/rows/1/1","approx":{"value":4.0,"atol":0.05}}
//|       - {"artifact":"orders","path":"/rows/2/1","approx":{"value":6.0,"atol":0.1}}
//|       - {"artifact":"orders","path":"/rows/1/2","approx":{"value":1.0,"atol":0.02}}
//|       - {"artifact":"orders","path":"/rows/1/3","range":{"min":0,"max":1e-13}}
//|       - {"artifact":"orders","path":"/rows/0/4","equals":0}
//|       - {"artifact":"orders","path":"/rows/2/4","range":{"min":1,"max":6}}
//|   - case: steep
//|     expect:
//|       - {"artifact":"orders","path":"/rows/1/1","approx":{"value":4.0,"atol":0.1}}
//|   - case: gentle
//|     expect:
//|       - {"artifact":"orders","path":"/rows/0/1","approx":{"value":2.0,"atol":0.01}}
//|       - {"artifact":"orders","path":"/rows/2/1","equals":null}
use scioxide_core::{Budget, Interval, RealScalar};
use scioxide_integrate::{FixedRule, FixedRuleNode, NewtonCotes, NewtonCotesEndpoints};

let lambda = growth_rate;
let interval = Interval::new(0.0, 1.0).map_err(|e| e.to_string())?;
// 参照値（f64 の標準関数による閉形式）: ∫₀¹ e^{λx} dx = (e^λ − 1)/λ。
let exact = lambda.exp_m1() / lambda;
let integrand = |x: f64| Ok(RealScalar::exp(lambda * x));

let mut series = Vec::new();
let mut rows = Vec::new();
for (name, nodes) in [("台形則", 2_usize), ("Simpson 則", 3), ("Boole 則", 5)] {
    let (mut observed, mut predicted, mut errors) = (Vec::new(), Vec::new(), Vec::new());
    let mut sample_gap = 0.0;
    let mut dropped = 0_usize;
    for level in 0..=9_u32 {
        let panels = Budget::try_from(1_usize << level).map_err(|e| e.to_string())?;
        let rule = NewtonCotes::new(nodes, NewtonCotesEndpoints::Closed, panels)
            .map_err(|e| e.to_string())?;
        let (value, _) = rule
            .integrate(&integrand, interval)
            .map_err(|e| e.to_string())?;
        // 主誤差項の予測（f64 の標準関数）: (C/W) h^m λ^(m−1) (e^λ − 1)、W = n − 1。
        let width = (nodes - 1) as f64;
        let spacing = 1.0 / ((1_usize << level) as f64 * width);
        let m = rule.error_order() as i32;
        let leading = rule.error_coefficient() / width
            * spacing.powi(m)
            * lambda.powi(m - 1)
            * lambda.exp_m1();
        let error = exact - value;
        let evaluations = rule.node_count() as f64;
        // 丸めの水準に達した点と誤差 0 の点は対数軸に描かず、その数を表に示す。
        if error.abs() > 1e-14 {
            observed.push([evaluations, error.abs()]);
        } else {
            dropped += 1;
        }
        predicted.push([evaluations, leading.abs()]);
        errors.push((error, leading));
        if level == 5 {
            // 同じ格子の標本を integrate_samples_into に渡した値と比べる。
            let mut grid = vec![FixedRuleNode::new(0.0, 0.0, None); rule.node_count()];
            rule.map_nodes_into(interval, &mut grid)
                .map_err(|e| e.to_string())?;
            let samples: Vec<f64> = grid
                .iter()
                .map(|node| RealScalar::exp(lambda * node.point()))
                .collect();
            let mut from_samples = 0.0;
            rule.integrate_samples_into(&samples, spacing, &mut from_samples, &mut [0.0])
                .map_err(|e| e.to_string())?;
            sample_gap = (from_samples - value).abs();
        }
    }
    // 区画数 16 → 32 の誤差比から観測次数を求め、区画数 32 で主誤差項と比べる。
    // 誤差が丸めで 0 になった場合は次数を定義しない。
    let (coarse, _) = errors[4];
    let (fine, leading) = errors[5];
    let order = (coarse != 0.0 && fine != 0.0).then(|| RealScalar::log2((coarse / fine).abs()));
    rows.push((
        name,
        order,
        fine / leading,
        sample_gap,
        dropped,
    ));
    series.push(serde_json::json!({ "name": name, "points": observed }));
    series.push(serde_json::json!({
        "name": format!("{name}（主誤差項）"),
        "points": predicted,
        "style": { "lineType": "dashed" }
    }));
}
emit_line_chart!(
    &series,
    options = &serde_json::json!({
        "xLabel": "評価回数 N [回]",
        "yLabel": "絶対誤差 |I − Q| [-]",
        "xType": "log",
        "yType": "log",
        "xMin": 2.0,
        "xMax": 2100.0
    })
);
let fixed3 = serde_json::json!({ "fractionDigits": 3 });
let fixed4 = serde_json::json!({ "fractionDigits": 4 });
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let columns = serde_json::json!([
    { "key": "0", "label": "複合則" },
    { "key": "1", "label": "観測した次数 [-]", "type": "number", "format": fixed3, "nullText": "未定義" },
    { "key": "2", "label": "誤差 / 主誤差項 [-]", "type": "number", "format": fixed4 },
    { "key": "3", "label": "標本からの値との差 [-]", "type": "number", "format": sci3 },
    { "key": "4", "label": "図から除いた点 [点]", "type": "integer" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "orders" })
);
```

既定値 $\lambda=2$ では、観測次数は $2.000$、$3.999$、$6.003$ で、誤差と主誤差項の比は台形則と Simpson 則で $0.9999$、Boole 則で $0.998$ だった。
破線と実線は評価回数が数十を超えると重なり、Boole 則の誤差は数百回の評価で丸めの水準に達する。
既定値では Boole 則の 4 点がこの水準に入り、図から除かれた。
$\lambda=8$ では同じ評価回数での誤差が数桁大きくなるが、観測次数は $1.996$、$3.992$、$5.991$ で、傾きは変わらない。
逆に $\lambda=0.5$ では Boole 則の誤差が区画数 32 で丸めの水準を下回って 0 になるので、観測次数を定義しない。
`integrate_samples_into` の値は `integrate` と $10^{-13}$ 以下の差で一致した。

## まとめ

Newton–Cotes 公式の重みは等間隔節点の補間多項式の積分で決まり、Peano 核から誤差の次数と符号が分かる。
`NewtonCotes::new(nodes, endpoints, panels)` の `panels` は区画数で、格子間隔は $h=(b-a)/(PW)$ になり、複合則の誤差は $O(h^m)$ で減る。
`error_coefficient()` と `error_order()` から主誤差項を予測でき、実際の誤差とよく一致する。
9 点以上の閉じた型と 3 点以上の開いた型の多くは負の重みを持ち、`weight_amplification()` が 1 を超えるので、精度は点数より区画数で上げる。
`NewtonCotes` は誤差推定を返さないので、区画数を変えた比較で確かめる。
