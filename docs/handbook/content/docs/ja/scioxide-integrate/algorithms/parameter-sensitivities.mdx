最適化、パラメータの同定、不確かさの伝播では、積分の値だけでなく、積分がパラメータにどう依存するかが必要になる。
このページはパラメータ $p \in \mathbb{R}^P$ に依存する 1 次元の積分

$$
I(p) = \int_{a(p)}^{b(p)} f(x, p)\,dx \in \mathbb{R}^m
$$

の微分を扱う。
$f$ は $m$ 個の実数成分を持ち、端点 $a$、$b$ もパラメータに依存してよい。
`QuadratureSensitivityPlan` は、積分と同時にその微分を、方向微分（JVP）または随伴の積（VJP）の形で計算する。

---

## 積分の微分と Leibniz 則

$f$ と $\partial_p f$ が積分区間を含む領域で連続で、端点 $a(p)$、$b(p)$ が微分可能なら、微分と積分を交換でき、方向 $v \in \mathbb{R}^P$ への微分は

$$
DI(p)\,v = \int_{a}^{b} J(x, p)\,v\,dx + f(b, p)\,\bigl(\nabla b \cdot v\bigr) - f(a, p)\,\bigl(\nabla a \cdot v\bigr)
$$

となる。
これを Leibniz の積分則と呼ぶ。
$J(x, p) = \partial f / \partial p$ は $x$ を固定したパラメータについての $m \times P$ の Jacobian である。
右辺の第 1 項は被積分関数の変化、残りの 2 項は端点が動くことによる寄与である。
複素数の値やパラメータは実部と虚部の 2 つの実数成分として数える。

$f$ が積分区間の内部で $p$ とともに動く不連続点を持つと、その点での跳びの寄与が加わり、上の式は成り立たない。
Plan はこの寄与を補正しないので、そのような点は区間の端点にして積分を分ける。

## 前進型（JVP）と逆向き（VJP）

Jacobian $\partial I / \partial p$（$m \times P$）を作らずに、2 種類の積を計算する。

- JVP（Jacobian–vector product）は方向 $v \in \mathbb{R}^P$ に対する $(\partial I/\partial p)\,v \in \mathbb{R}^m$ である。
- VJP（vector–Jacobian product）は余接ベクトル $w \in \mathbb{R}^m$ に対する $w^{\mathsf T}(\partial I/\partial p) \in \mathbb{R}^P$ である。

VJP の Leibniz 則は、端点の勾配 $\nabla a$、$\nabla b$ を使って

$$
w^{\mathsf T}\frac{\partial I}{\partial p} = \int_a^b J(x, p)^{\mathsf T} w\,dx + \bigl(w \cdot f(b, p)\bigr)\nabla b - \bigl(w \cdot f(a, p)\bigr)\nabla a
$$

と書ける。
2 つの積は双対性 $w \cdot \bigl((\partial I/\partial p)\,v\bigr) = \bigl(w^{\mathsf T}\partial I/\partial p\bigr) \cdot v$ で結ばれ、これは実装の検算に使える。

Jacobian 全体が必要なら、$P$ 回の JVP（パラメータの各方向）か、$m$ 回の VJP（出力の各成分）で組み立てる。
1 回の呼び出しの計算コストは節点ごとの被積分関数の評価 1 回と Jacobian の作用 1 回で、動く端点ごとに値だけの評価が 1 回加わる。
パラメータが少なければ JVP、出力が少なければ（スカラーの損失関数など）VJP が計算コストが小さい。

## 離散化してから微分する理由

求積で積分を近似した値 $Q(p) = \sum_i w_i\,f(x_i, p)$ の微分には、2 つの考え方がある。

1. 微分してから離散化する。
   $\int J\,v\,dx$ を、$Q$ とは別の求積で近似する。
2. 離散化してから微分する。
   計算した $Q(p)$ そのものを $p$ で微分する。

節点 $x_i$ と重み $w_i$ が $p$ に依存しなければ、$\partial_p Q = \sum_i w_i\,J(x_i, p)$ となり、2 つは一致する。
`QuadratureSensitivityPlan` は積分と Jacobian の積分を同じ Gauss–Kronrod 則と同じ節点で近似するので、端点が固定なら、計算した積分の値の厳密な微分を丸め誤差の範囲で返す。
この性質は勾配法の最適化や有限差分による検算で、値と微分が食い違わないために役立つ。

適応求積では事情が異なる。
細分の判定は誤差推定の比較で決まるので、$p$ を少し変えると分割が不連続に切り替わり、計算した $Q(p)$ は $p$ について区分的にしか滑らかでない。
切り替わる点では $Q$ の微分は存在せず、有限差分は分割の変化による跳びを拾う。
Plan は細分の判定を微分しない。
そのため、適応的に決めた分割を固定（Frozen）し、近くのパラメータでは同じ分割で値と微分を計算する方式を用意する。

端点が $p$ とともに動く場合、分割は物理的な区間 $[a, b]$ の上に定義されている。
Plan は現在のパラメータでの区間を保持するので、$a(p)$、$b(p)$ が変わったら新しい区間で Plan を準備し直す。
端点の項 $f(b)\,(\nabla b \cdot v)$ は値の標本 1 回で厳密に加える。

## 離散化の 3 つの方式

`SensitivityDiscretization` は Plan が積分する分割を表し、`discretization()` で読める。

| 方式 | 構築 | 分割 | 終了状態 |
|---|---|---|---|
| `Fixed` | `QuadratureSensitivityPlan::fixed(&integrand, interval, rule, options)` | 区間全体に 1 つの Gauss–Kronrod 則（`GaussKronrodRule`） | `FixedRuleCompleted` |
| `Adaptive` | `QuadratureSensitivityPlan::adaptive(&integrand, interval, options)` | G7K15 の適応二分 | 収束すれば `ToleranceReached` |
| `Frozen` | `QuadratureSensitivityPlan::frozen(&integrand, &partition, options)` | 前の呼び出しで得た分割を細分せずに再利用 | `FixedRuleCompleted` |

`Fixed` は許容誤差を判定せずに 1 回だけ則を適用し、幅 0 の区間では `DegenerateDomain` になる。
レポートは誤差推定が許容誤差を満たしたかどうかを別に示す。
区間が短すぎて則の節点が区別できない場合は `InvalidInput`（`OutOfRange`）である。

`Adaptive` は、積分の誤差推定と微分の誤差推定のそれぞれを許容誤差で正規化し、悪い方が許容誤差を満たすまで区間を二分する。
`with_max_subdivisions` などの上限に達すると、その時点の推定値を成功でない終了状態とともに返す。

`plan.partition(&workspace)` は直前の成功した呼び出しの分割を `SensitivityPartition` として取り出し、`intervals()` は和をとる順の小区間を返す。
分割は微分の方式（JVP か VJP か）に依存しないので、JVP の Plan で得た分割を VJP の `frozen` Plan に使える。
直前の呼び出しが失敗していれば `InvalidInput` である。

微分の方式 `SensitivityMode::{Jvp, Vjp}` は `SensitivityOptions::with_mode` で準備のときに決まり、`mode()` で読める。
JVP 用の Plan に VJP の問い合わせを渡すとエラーになり、準備の時点で被積分関数が `supports(mode)` で偽を返しても `InvalidInput` になる。

## 被積分関数の実装

利用者は `SensitivityIntegrand` を実装する。

- `type Workspace` は被積分関数の一時領域（自動微分のテープなど）で、呼び出しごとにワーカーの数だけ渡す。
- `parameter_dimension()` は $P$、`value_dimension()` は $m$ を返す。
- `supports(mode)` は JVP と VJP のどちらを計算できるかを返す。
- `evaluate(x, parameters, &mut sample, &mut workspace, execution)` は 1 つの節点の値と微分を計算する。

`evaluate` では、まず `sample.value_mut()` に $f(x, p)$ のすべての成分を書き、次に Jacobian $J(x, p)$ を 1 回だけ作用させる。
JVP だけに対応する被積分関数は `sample.apply_forward(&operator, scratch)` に scioxide-core の `LinearOperator` を渡し、両方に対応する被積分関数は `sample.apply(&operator, scratch)` に `AdjointOperator` を渡す。
`apply` は JVP の要求なら $Jv$、VJP の要求なら $J^{\mathsf T}w$ を計算する。
動く端点の標本では値だけが必要で、`sample.mode()` が `None` を返し、どちらの作用も何もしない。
作用を省いた、または 2 回作用させた呼び出しは `InvalidInput` になる。
`scratch` は演算子の作業長以上の長さが必要である。

scioxide-core の `ClosureOperator::new` が返す演算子は `LinearOperator` だけを実装するので、そのままでは JVP にしか使えない。
VJP には、`with_adjoint` で $J^{\mathsf T}w$ のクロージャを加えた `ClosureOperator` か、`LinearOperator` と `AdjointOperator` の両方を実装する小さな構造体を用意する。
自動微分で作った Jacobian の演算子も同じ形で渡せる。
複素数の値では、$J$ は実部と虚部の実数 Jacobian で、その転置は内積 $\langle u, v\rangle = \mathrm{Re}(\bar u v)$ についての随伴である。

## オプション・レポート・誤差推定

`SensitivityOptions::new(SubdivisionOptions)` は、積分（primal）の許容誤差、細分と評価回数の上限、実行方針を `SubdivisionOptions` から受け取る。
既定の微分の方式は JVP、微分の許容誤差は絶対・相対とも $\sqrt{\varepsilon}$ の二乗平均ノルムである。
`with_primal_tolerance` と `with_derivative_tolerance` は 2 つの許容誤差を別々に設定し、後者は端点の項を含む。
JVP の微分の許容誤差の成分数は $m$、VJP では $P$ である。
`with_max_evaluations` の上限は端点の評価を含む。

`jvp_into(&integrand, JvpQuery, (&mut value, &mut jvp), (&mut workspace, &mut pool), scope)` は積分と JVP を書く。
`JvpQuery::new(&parameters, &direction)` に、端点が動くときは `with_endpoint_tangent(Some([da, db]))` で $[\nabla a \cdot v, \nabla b \cdot v]$ を渡す。
`vjp_into` は `VjpQuery::new(&parameters, &cotangent)` と `with_endpoint_gradients(Some((&grad_a, &grad_b)))` を受け取り、積分と長さ $P$ の VJP を書く。
0 の接ベクトルや勾配は被積分関数の評価を増やさない。
パラメータ、方向・余接、端点の接ベクトル・勾配が NaN や無限大なら、積分を始める前に `NonFinite`（発生元 `Input`）で拒む。
被積分関数が返した値や積が非有限なら、`NonFinite`（発生元 `Callback`）である。
`pool` は被積分関数の作業領域の列で、並列の実行方針では 1 つのワーカーが 1 つを使う。

`SensitivityReport` は `termination()`、端点の評価と失敗した呼び出しを含む `function_evaluations()`、Jacobian の作用の回数 `derivative_evaluations()`、`subdivisions()`、`primal_tolerance_met()`、`derivative_tolerance_met()` を返す。
`is_success()` は持たないので、`report.termination().is_success()` を使う。
終了状態が成功でなくても、2 つの出力は全体の推定値を持つ。

`QuadratureSensitivityWorkspace` は `workspace()` で作り、呼び出しのたびに再割り当てしない。
`value_errors()` は積分の成分ごとの `IntegrationErrorComponents`、`derivative_errors()` は微分の成分ごとの `SensitivityErrorComponents` を返す。
`SensitivityErrorComponents` の `quadrature()` は $\int J$ の求積の誤差推定、`boundary_roundoff()` は端点の項の丸め誤差（端点が固定なら 0）、`total()` はその和である。
これらは被積分関数の Jacobian の積が正確だと仮定した推定で、上界ではない。
呼び出しが失敗すると、誤差推定と分割は次の成功まで使えない。
`workspace_requirements()` が返す `SensitivityRequirements` は区間、方式、則の大きさ、次元、小区間の最大数を記録し、`check` と `try_reserve` がこれと照合する。
`last_attempt()` は直前の呼び出しの記録を返す。

Plan の対象は有限区間の 1 次元の通常の積分である。
重み付き、広義、複素経路、多次元の積分の感度は提供しない。
それらには、Leibniz 則の各項を利用者が組み立て、$\partial_p f$ を値に加えたベクトル値の被積分関数を対応する Plan で積分する。

## 減衰振動の積分の JVP と VJP

減衰率 $k$ [1/s] の振動 $e^{-kt}(\sin t, \cos t)$ を時刻 0 から $b$ [s] まで積分した量

$$
I(k, b) = \int_0^b e^{-kt}\begin{pmatrix}\sin t\\ \cos t\end{pmatrix}dt
$$

の、パラメータ $p = (k, b)$ についての微分を計算する。
角周波数は 1 rad/s で、$I$ の単位は s である。
成分は $m = 2$、パラメータは $P = 2$ で、$b$ は被積分関数には現れず、上端としてだけ動く（$\nabla a = 0$、$\nabla b = (0, 1)$）。
Jacobian は $J(t, p) = \begin{pmatrix} -t f_1 & 0 \\ -t f_2 & 0 \end{pmatrix}$ で、$f_1, f_2$ は 2 つの成分である。

閉じた形は $z = k - i$ として $I_2 + iI_1 = (1 - e^{-zb})/z$ で、その微分は

$$
\frac{\partial (I_2 + iI_1)}{\partial k} = \frac{b\,e^{-zb} - (I_2 + iI_1)}{z}, \qquad \frac{\partial I}{\partial b} = e^{-kb}\begin{pmatrix}\sin b\\ \cos b\end{pmatrix}
$$

である。
上端についての微分は被積分関数の上端での値 $e^{-zb} = e^{-kb}(\cos b + i\sin b)$ に等しい。

次の定義のブロックはモデルを 3 つの Rust の項目にし、セル間で受け渡す 2 つの型を加える。
`Jacobian` は節点 $t$ での $J$ を表し、`LinearOperator` で $Jv$、`AdjointOperator` で $J^{\mathsf T}w$ を計算する。
`DampedOscillation` は `SensitivityIntegrand` を実装し、値 $f(t, p)$ を書いてから `sample.apply` で `Jacobian` を 1 回作用させる。
`exact_jacobian` は scioxide-core の `Complex` で閉じた形の $2 \times 2$ の Jacobian $\partial I/\partial p$ を返し、2 つのセルの検算に使う。
`PlanSummary` は 1 つの Plan のレポート、`Solve` は最初のセルが渡す値（パラメータ、方向、JVP、2 つの Plan のレポート）で、後の 2 つのセルはこれを型として受け取る。

```rust
//| id: integrate-sensitivity-model
//| kind: definitions
//| title: 減衰振動の被積分関数・Jacobian・閉じた形
//| crates: [scioxide-core, scioxide-integrate]
use scioxide_core::{
    AdjointOperator, Complex, ExecutionContext, SciOxideError, LinearOperator, RealScalar,
};
use scioxide_integrate::{SensitivityIntegrand, SensitivityMode, SensitivitySample};

// J(t, p) = [[−t f₁, 0], [−t f₂, 0]]。p = (k, b) で、b は被積分関数に現れない。
pub(crate) struct Jacobian {
    pub(crate) t: f64,
    pub(crate) values: [f64; 2],
}
impl LinearOperator<f64> for Jacobian {
    fn rows(&self) -> usize {
        2
    }
    fn cols(&self) -> usize {
        2
    }
    fn apply_workspace_len(&self) -> Result<usize, SciOxideError> {
        Ok(0)
    }
    fn apply_into(&self, v: &[f64], y: &mut [f64], _: &mut [f64]) -> Result<(), SciOxideError> {
        y[0] = -self.t * self.values[0] * v[0];
        y[1] = -self.t * self.values[1] * v[0];
        Ok(())
    }
}
impl AdjointOperator<f64> for Jacobian {
    fn apply_adjoint_workspace_len(&self) -> Result<usize, SciOxideError> {
        Ok(0)
    }
    fn apply_adjoint_into(
        &self,
        w: &[f64],
        y: &mut [f64],
        _: &mut [f64],
    ) -> Result<(), SciOxideError> {
        y[0] = -self.t * (self.values[0] * w[0] + self.values[1] * w[1]);
        y[1] = 0.0;
        Ok(())
    }
}

// f(t, p) = e^(−kt) (sin t, cos t)。値を書いてから Jacobian を 1 回作用させる。
pub(crate) struct DampedOscillation;
impl SensitivityIntegrand<f64> for DampedOscillation {
    type Workspace = ();
    fn parameter_dimension(&self) -> usize {
        2
    }
    fn value_dimension(&self) -> usize {
        2
    }
    fn supports(&self, _: SensitivityMode) -> bool {
        true
    }
    fn evaluate(
        &self,
        t: f64,
        p: &[f64],
        sample: &mut SensitivitySample<'_, f64>,
        _: &mut (),
        _: ExecutionContext<'_>,
    ) -> Result<(), SciOxideError> {
        let decay = RealScalar::exp(-p[0] * t);
        let values = [decay * RealScalar::sin(t), decay * RealScalar::cos(t)];
        sample.value_mut().copy_from_slice(&values);
        sample.apply(&Jacobian { t, values }, &mut [])
    }
}

// 閉じた形の ∂I/∂p。行は成分 (sin, cos)、列はパラメータ (k, b)。
pub(crate) fn exact_jacobian(k: f64, b: f64) -> [[f64; 2]; 2] {
    let z = Complex::new(k, -1.0);
    let e = (-(z * b)).exp();
    let integral = (Complex::new(1.0, 0.0) - e) / z;
    let d_k = (e * b - integral) / z;
    [[d_k.im, e.im], [d_k.re, e.re]]
}
/// 最初のセルが渡す Plan のレポート。
#[derive(serde::Serialize, serde::Deserialize)]
pub(crate) struct PlanSummary {
    pub(crate) name: String,
    pub(crate) status: String,
    pub(crate) success: bool,
    pub(crate) evaluations: usize,
    pub(crate) actions: usize,
    pub(crate) subdivisions: usize,
    pub(crate) primal_met: bool,
    pub(crate) derivative_met: bool,
    pub(crate) derivative_error: Option<f64>,
}

/// 最初のセルの exports（パラメータ、方向、JVP、2 つの Plan のレポート）。
#[derive(serde::Deserialize)]
pub(crate) struct Solve {
    pub(crate) parameters: [f64; 2],
    pub(crate) direction: [f64; 2],
    pub(crate) jvp: [f64; 2],
    pub(crate) plans: Vec<PlanSummary>,
}
```

最初のセルは適応 JVP の Plan で方向 $v = (\cos\theta, \sin\theta)$ の JVP を求め、その分割を固定して VJP の Plan を準備し、余接 $w = (1, 0.5)$ の VJP を求める。
表は各積と閉じた形の差、双対性 $w \cdot (Jv) - (J^{\mathsf T}w) \cdot v$ である。
感度の Plan の許容誤差は積分と微分とも絶対・相対 $10^{-12}$ とした。
入力は $k$、$b$、方向の角度 $\theta$ で、パラメータ、方向、JVP の値と 2 つの Plan のレポートを後の 2 つのセルに渡す。
このセルは求解だけを担い、Plan の終了状態と判定（outcome）は 3 つ目のセルで示す。

```rust
//|   - case: default
//|     expect:
//|       - {"artifact":"sensitivities","path":"/rows/0/3","range":{"min":0,"max":1e-11}}
//|       - {"artifact":"sensitivities","path":"/rows/2/3","range":{"min":0,"max":1e-11}}
//|       - {"artifact":"sensitivities","path":"/rows/4/3","range":{"min":0,"max":1e-12}}
//|   - case: long-horizon
//|     expect:
//|       - {"artifact":"sensitivities","path":"/rows/0/3","range":{"min":0,"max":1e-11}}
//|   - case: endpoint-direction
//|     expect:
//|       - {"artifact":"sensitivities","path":"/rows/0/3","range":{"min":0,"max":1e-12}}
//|       - {"artifact":"sensitivities","path":"/rows/4/3","range":{"min":0,"max":1e-12}}
use scioxide_core::{ErrorTolerance, ExecutionContext, Interval, NormSelection, RealScalar};
use scioxide_integrate::{
    JvpQuery, QuadratureSensitivityPlan, QuadratureSensitivityWorkspace, SensitivityMode,
    SensitivityOptions, SensitivityReport, SubdivisionOptions, VjpQuery,
};

let sci6 = serde_json::json!({ "notation": "scientific", "significantDigits": 6 });
let p = [decay_rate, end_time];
let angle = direction_angle.to_radians();
let v = [RealScalar::cos(angle), RealScalar::sin(angle)];
let w = [1.0, 0.5];
let tolerance = ErrorTolerance::scalar(1.0e-12_f64, 1.0e-12, NormSelection::Infinity)
    .map_err(|e| e.to_string())?;
let options =
    SensitivityOptions::new(SubdivisionOptions::default().with_tolerance(tolerance.clone()))
        .with_derivative_tolerance(tolerance);
let interval = Interval::new(0.0, end_time).map_err(|e| e.to_string())?;

// 適応 JVP。上端の接ベクトルは ∇b·v = v₂、下端は固定。
let forward = QuadratureSensitivityPlan::adaptive(
    &DampedOscillation,
    interval,
    options.clone().with_mode(SensitivityMode::Jvp),
)
.map_err(|e| e.to_string())?;
let mut forward_ws = forward.workspace().map_err(|e| e.to_string())?;
let (mut value, mut jvp) = ([0.0_f64; 2], [0.0_f64; 2]);
let forward_report = forward
    .jvp_into(
        &DampedOscillation,
        JvpQuery::new(&p, &v).with_endpoint_tangent(Some([0.0, v[1]])),
        (&mut value, &mut jvp),
        (&mut forward_ws, &mut [()]),
        ExecutionContext::sequential(),
    )
    .map_err(|e| e.to_string())?;

// 同じ分割を固定した VJP。∇a = 0、∇b = (0, 1)。
let partition = forward.partition(&forward_ws).map_err(|e| e.to_string())?;
let reverse = QuadratureSensitivityPlan::frozen(
    &DampedOscillation,
    &partition,
    options.with_mode(SensitivityMode::Vjp),
)
.map_err(|e| e.to_string())?;
let mut reverse_ws = reverse.workspace().map_err(|e| e.to_string())?;
let (mut reverse_value, mut vjp) = ([0.0_f64; 2], [0.0_f64; 2]);
let reverse_report = reverse
    .vjp_into(
        &DampedOscillation,
        VjpQuery::new(&p, &w).with_endpoint_gradients(Some((&[0.0, 0.0], &[0.0, 1.0]))),
        (&mut reverse_value, &mut vjp),
        (&mut reverse_ws, &mut [()]),
        ExecutionContext::sequential(),
    )
    .map_err(|e| e.to_string())?;

// 閉じた形の Jv と Jᵀw、双対性 w·(Jv) − (Jᵀw)·v。
let j = exact_jacobian(decay_rate, end_time);
let exact_jvp = [
    j[0][0] * v[0] + j[0][1] * v[1],
    j[1][0] * v[0] + j[1][1] * v[1],
];
let exact_vjp = [
    w[0] * j[0][0] + w[1] * j[1][0],
    w[0] * j[0][1] + w[1] * j[1][1],
];
let duality = (w[0] * jvp[0] + w[1] * jvp[1]) - (vjp[0] * v[0] + vjp[1] * v[1]);
let row = |name, computed: f64, exact: f64| (name, computed, exact, (computed - exact).abs());
let rows = vec![
    row("(Jv)₁", jvp[0], exact_jvp[0]),
    row("(Jv)₂", jvp[1], exact_jvp[1]),
    row("(Jᵀw)_k", vjp[0], exact_vjp[0]),
    row("(Jᵀw)_b", vjp[1], exact_vjp[1]),
    row("w·(Jv) − (Jᵀw)·v", duality, 0.0),
];
let columns = serde_json::json!([
    { "key": "0", "label": "量" },
    { "key": "1", "label": "計算値 [s]", "type": "number", "format": sci6 },
    { "key": "2", "label": "閉じた形 [s]", "type": "number", "format": sci6 },
    { "key": "3", "label": "差 [s]", "type": "number", "format": sci6 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "sensitivities" })
);

// 次のセルに渡すレポート: 終了状態、評価回数、許容誤差の判定、微分の誤差推定の最大。
let summary =
    |name: &str, report: &SensitivityReport, ws: &QuadratureSensitivityWorkspace<f64>| {
        let errors = ws.derivative_errors();
        let worst = errors.and_then(|e| {
            e.iter()
                .try_fold(0.0_f64, |acc, e| e.total().map(|t| acc.max(t)))
        });
        PlanSummary {
            name: name.to_string(),
            status: report.termination().to_string(),
            success: report.termination().is_success(),
            evaluations: report.function_evaluations(),
            actions: report.derivative_evaluations(),
            subdivisions: report.subdivisions(),
            primal_met: report.primal_tolerance_met(),
            derivative_met: report.derivative_tolerance_met(),
            derivative_error: worst,
        }
    };
let plans = vec![
    summary("適応 JVP", &forward_report, &forward_ws),
    summary("固定した分割の VJP", &reverse_report, &reverse_ws),
];
export!(parameters, &p);
export!(direction, &v);
export!(jvp, &jvp);
export!(plans, &plans);
```

既定値（$k = 0.5$ /s、$b = 6$ s、$\theta = 30°$）では、JVP と VJP の各成分は閉じた形と $10^{-15}$ 以下で一致し、双対性の差も丸めの程度だった。
$\theta = 90°$ では方向が上端だけを動かすので、JVP はほぼ端点の項 $e^{-kb}(\sin b, \cos b)$ だけになる。

2 つ目のセルは最初のセルの結果を受け取り、JVP を感度の Plan とは独立な方法で検算する。
積分の値を適応 G7K15（`AdaptiveIntegrator`、許容誤差 $10^{-13}$）で $p \pm hv$ について計算し、中心差分 $(I(p + hv) - I(p - hv))/(2h)$ を作る。
刻みは $h = 10^{-1}, \dots, 10^{-10}$ とし、JVP との差を両対数軸に描く。
中心差分の打ち切り誤差は $O(h^2)$ で、積分値の丸めと求積の誤差は $h$ で割られて $O(1/h)$ で効くので、差は中間の $h$ で最も小さくなる。
最初のセルの値は定義のブロックの型 `Solve` として受け取る。

```rust
//| id: integrate-sensitivity-checks
//| ref: integrate-sensitivity-checks
//| title: JVP を中心差分と照合する
//| run: reactive
//| uses: [integrate-sensitivity-model]
//| crates: [scioxide-core, scioxide-integrate]
//| dependsOn:
//|   solve: {cell: integrate-sensitivity-jvp-vjp, type: Solve}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"steps","path":"/rows/5/1","range":{"min":0,"max":1e-8}}
//|       - {"artifact":"steps","path":"/rows/0/1","range":{"min":1e-3,"max":1e-1}}
use scioxide_core::{ErrorTolerance, Interval, NormSelection, RealScalar};
use scioxide_integrate::{AdaptiveIntegrator, AdaptiveRule, SubdivisionOptions};

let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let (p, v, jvp) = (solve.parameters, solve.direction, solve.jvp);

// 独立な検算: 適応 G7K15 で求めた積分値の中心差分 (I(p + hv) − I(p − hv)) / (2h)。
let tolerance = ErrorTolerance::scalar(1.0e-13, 1.0e-13, NormSelection::Infinity)
    .map_err(|e| e.to_string())?;
let options = SubdivisionOptions::default().with_tolerance(tolerance);
let plan =
    AdaptiveIntegrator::new(AdaptiveRule::GaussKronrod, options).map_err(|e| e.to_string())?;
let primal = |q: [f64; 2]| -> Result<[f64; 2], String> {
    let f = |t: f64| {
        let decay = RealScalar::exp(-q[0] * t);
        Ok([decay * RealScalar::sin(t), decay * RealScalar::cos(t)])
    };
    let interval = Interval::new(0.0, q[1]).map_err(|e| e.to_string())?;
    Ok(plan.integrate(&f, interval).map_err(|e| e.to_string())?.0)
};
let j = exact_jacobian(p[0], p[1]);
let exact = [
    j[0][0] * v[0] + j[0][1] * v[1],
    j[1][0] * v[0] + j[1][1] * v[1],
];
// 2 成分の差の最大。
let gap = |a: [f64; 2], b: [f64; 2]| (a[0] - b[0]).abs().max((a[1] - b[1]).abs());
let (mut rows, mut curve) = (Vec::new(), Vec::new());
for exponent in 1..=10 {
    let h = RealScalar::powi(10.0_f64, -exponent);
    let plus = primal([p[0] + h * v[0], p[1] + h * v[1]])?;
    let minus = primal([p[0] - h * v[0], p[1] - h * v[1]])?;
    let central = [
        (plus[0] - minus[0]) / (2.0 * h),
        (plus[1] - minus[1]) / (2.0 * h),
    ];
    let to_jvp = gap(central, jvp);
    rows.push((h, to_jvp, gap(central, exact)));
    // 差が厳密に 0 の刻みは対数軸に描けないので除く。
    if to_jvp > 0.0 {
        curve.push([h, to_jvp]);
    }
}
let style = serde_json::json!({ "showSymbol": true });
emit_line_chart!(
    &vec![
        serde_json::json!({ "name": "max|中心差分 − JVP|", "points": curve, "style": style })
    ],
    options = &serde_json::json!({
        "xLabel": "刻み h [-]",
        "yLabel": "差の最大成分 [s]",
        "xType": "log",
        "yType": "log"
    })
);
let columns = serde_json::json!([
    { "key": "0", "label": "刻み h [-]", "type": "number", "format": sci3 },
    { "key": "1", "label": "JVP との差 [s]", "type": "number", "format": sci3 },
    { "key": "2", "label": "閉じた形との差 [s]", "type": "number", "format": sci3 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "steps" })
);
```

既定値では、中心差分と JVP の差は $h = 10^{-1}$ から $10^{-5}$ まで $h^2$ に比例して $1.5 \times 10^{-2}$ から $1.5 \times 10^{-10}$ に減り、$h = 10^{-6}$ で最小の $4 \times 10^{-11}$ になった。
それより小さい $h$ では差が $1/h$ に比例して増え、$h = 10^{-10}$ では $10^{-7}$ の桁になる。
この範囲の差は丸め誤差なので、値は実行環境によって数倍変わる。
最小の差は JVP と閉じた形の差（$10^{-16}$ 程度）よりずっと大きく、中心差分は JVP の精度を確かめる手段としては粗い。

3 つ目のセルは最初のセルのレポートを表にし、2 つの Plan の終了状態、評価回数、許容誤差の判定、微分の誤差推定の最大を示す。
outcome は 2 つの Plan がともに成功し、微分の許容誤差を満たしたかを示す。
レポートは最初のセルの入力に従うので、このセルは入力を持たない。

```rust
//| id: integrate-sensitivity-reports
//| ref: integrate-sensitivity-reports
//| title: 2 つの Plan のレポートを読む
//| run: reactive
//| uses: [integrate-sensitivity-model]
//| crates: [scioxide-core, scioxide-integrate]
//| dependsOn:
//|   solve: {cell: integrate-sensitivity-jvp-vjp, type: Solve}
//| tests:
//|   - case: default
//|     expect:

//|       - {"artifact":"plans","path":"/rows/1/2","equals":31}

    } else {

    }

    .iter()

            counts.0,
            counts.1,
            counts.2,
            flags.0,
            flags.1,

        )
    })
    .collect();
let columns = serde_json::json!([
    { "key": "0", "label": "Plan" },
    { "key": "1", "label": "終了状態" },
    { "key": "2", "label": "関数の評価 [回]", "type": "integer" },
    { "key": "3", "label": "Jacobian の作用 [回]", "type": "integer" },
    { "key": "4", "label": "細分 [回]", "type": "integer" },
    { "key": "5", "label": "積分の許容誤差" },
    { "key": "6", "label": "微分の許容誤差" },
    { "key": "7", "label": "微分の誤差推定の最大 [s]", "type": "number", "format": sci3, "nullText": "推定なし" }
]);

    rows,
    metadata = serde_json::json!({ "id": "plans" })
);

// 判定: 2 つの Plan がともに成功し、微分の許容誤差を満たしたか。
let (forward, reverse) = (&solve.plans[0], &solve.plans[1]);
let outcome = if solve
    .plans
    .iter()
    .all(|plan| plan.success && plan.derivative_met)
{
    Outcome::satisfied("JVP と VJP が微分の許容誤差を満たした")
        .explanation("誤差推定は Jacobian の積が正確だと仮定した推定で、上界ではない。")
} else {
    Outcome::partial("微分の許容誤差を満たす前に止まった")
        .explanation("最初のセルの積は最後の分割での推定値として扱う。")
};
let mut outcome = outcome
    .status(forward.status.clone())
    .diagnostic("JVP の関数の評価", forward.evaluations as f64, None)
    .diagnostic("VJP の関数の評価", reverse.evaluations as f64, None);
if let Some(error) = forward.derivative_error {
    outcome = outcome.diagnostic("JVP の微分の誤差推定", error, Some("s"));
}
emit_outcome!(outcome);
```

適応 JVP の Plan は 1 回の二分で 2 つの小区間に分け、`ToleranceReached` で終わった。
評価は 46 回で、Jacobian の作用 45 回（G7K15 の 15 点と二分の 30 点）に、上端の値だけの評価 1 回が加わる。
同じ分割を固定した VJP は 31 回の評価（30 節点と上端 1 回）で `FixedRuleCompleted` となった。
$\theta = 0°$ では上端の接ベクトルが 0 なので、端点の評価が省かれて JVP の評価は 45 回になる。
$b = 20$ s では分割が 8 つの小区間になり、JVP は 226 回、VJP は 121 回の評価を要した。
どの入力でも、2 つの Plan の微分の誤差推定は許容誤差 $10^{-12}$ を満たした。

## まとめ

パラメータに依存する積分の微分は、$x$ を固定した Jacobian の積分と、動く端点の Leibniz の項の和である。
`QuadratureSensitivityPlan` は積分と Jacobian の積分を同じ節点で近似するので、固定した分割では計算した値の微分を丸め誤差の範囲で返す。
適応分割は $p$ について滑らかでないので、`partition()` で分割を取り出して `frozen` で再利用し、端点が動いたら Plan を準備し直す。
パラメータが少なければ JVP、出力が少なければ VJP を選び、VJP には `AdjointOperator` を実装した演算子を渡す。
レポートの `primal_tolerance_met()` と `derivative_tolerance_met()` は別々に読み、小さい積分の誤差から微分の精度を推測しない。
