複合台形則は最も単純な求積則だが、その誤差は被積分関数が十分に滑らかなら、刻み $h$ の偶数べきの規則正しい展開を持つ。
この展開が分かれば、刻みを半分にした値を組み合わせて誤差の主要な項を順に消せる。
これが Richardson 外挿で、台形則に繰り返し適用したものが Romberg 法である。
このページでは誤差展開の条件、展開が崩れる場合と周期関数の特別な振る舞い、外挿の三角表、SciOxide の `Romberg` の誤差推定と停止の規則を扱う。
記号は[Newton–Cotes 公式と複合則](../newton-cotes-and-romberg/)にそろえ、$h$ は格子間隔、$T(h)$ は格子間隔 $h$ の複合台形則とする。
同じ公式を無限級数の和に使う方法は[Euler–Maclaurin 和と条件付きの上界](../euler-maclaurin-summation/)で扱う。

## 台形則の Euler–Maclaurin 展開

$f\in C^{2k+2}[a,b]$ なら、複合台形則の誤差は Euler–Maclaurin の公式で

$$
T(h) - \int_a^b f\,dx = \sum_{j=1}^{k}\frac{B_{2j}}{(2j)!}h^{2j}\bigl[f^{(2j-1)}(b)-f^{(2j-1)}(a)\bigr] + O(h^{2k+2})
$$

と展開できる。
$B_{2j}$ は Bernoulli 数（$B_2=1/6$、$B_4=-1/30$、$B_6=1/42$）である。
この式から 2 つのことが分かる。

1. 十分に滑らかな $f$ では、誤差は $h^2,h^4,h^6,\dots$ の偶数べきだけの漸近展開を持つ。
   これが Romberg 外挿の根拠である。
   $f$ が端点で滑らかでないと展開に他のべきが現れる。
   たとえば $\sqrt{x}$ では $h^{3/2}$ の項が現れ、刻みを半分にしたときの誤差比は 4 ではなく $2^{3/2}\approx2.83$ に近づく。
2. $f$ が周期 $b-a$ の周期関数で滑らかなら、右辺の有限項はすべて 0 になる。
   $f$ が $C^\infty$ 級なら、誤差は $h$ のどのべきよりも速く 0 に近づく。
   さらに $f$ が帯 $|\mathrm{Im}\,x|<d$ で解析的なら、誤差は $O(e^{-2\pi d/h})$ で幾何級数的に減る。
   たとえば $f(x)=1/(2+\cos2\pi x)$ は $\cos2\pi x=-2$ の点に極を持ち、$d=\ln(2+\sqrt3)/(2\pi)$ なので、$N=1/h$ 点の台形則の誤差は $(2-\sqrt3)^N\approx0.268^N$ に比例して減る。

## Romberg 外挿

刻みを半分にしていく列 $h_j=(b-a)/2^j$ の台形則を $R_{j,0}=T(h_j)$ とおく。
偶数べきの展開から

$$
\begin{aligned}
R_{j,0} &= I + c_2h_j^2 + c_4h_j^4 + c_6h_j^6 + \cdots,\\
R_{j-1,0} &= I + 4c_2h_j^2 + 16c_4h_j^4 + 64c_6h_j^6 + \cdots
\end{aligned}
$$

である。
$h_j^2$ の項を消すと

$$
R_{j,1} = \frac{4R_{j,0}-R_{j-1,0}}{3} = I - 4c_4h_j^4 - 20c_6h_j^6 + \cdots
$$

となり、これは格子間隔 $h_j$ の複合 Simpson 則に等しい。
この消去を繰り返すと、Richardson 外挿の三角表

$$
R_{j,k} = R_{j,k-1} + \frac{R_{j,k-1}-R_{j-1,k-1}}{4^k-1}, \qquad 1\le k\le j
$$

が得られる。
第 $k$ 列は $h^2,\dots,h^{2k}$ の項を消しており、誤差は $O(h_j^{2k+2})$ である。
$R_{j,2}$ は複合 Boole 則に等しい。
三角表の並びは次のとおりである。

$$
\begin{array}{llll}
R_{0,0} & & & \\
R_{1,0} & R_{1,1} & & \\
R_{2,0} & R_{2,1} & R_{2,2} & \\
R_{3,0} & R_{3,1} & R_{3,2} & R_{3,3}
\end{array}
$$

行 $j$ で新たに評価するのは、前の格子の小区間の中点 $2^{j-1}$ 個だけで、既存の値はすべて再利用する。

## SciOxide の `Romberg`

`Romberg::new(LevelOptions)` は段数 6〜30 を受け付け、既定は 15 段である。
$L$ 段で最も細かい格子は $2^{L-1}+1$ 点で、既定の 15 段では格子外の検査点を合わせて最大 16 386 回評価する。
両端を評価するので、端点で発散する関数には[二重指数変換](../improper-singular-and-oscillatory/)を使う。

二進の格子点 $a+k(b-a)/2^j$ だけを標本にすると、$\sin^2(2^m\pi x)$ のように格子と共鳴する関数は、ある段まですべての標本で 0 に見える。
そこで 4 段目を終えた後に、区間の $(\sqrt5-1)/2$ の位置（どの二進格子にも含まれない）で 1 回だけ評価する。
この値と、近くの格子点 8 個から作る 7 次の補間値との差が、7 次と 5 次の補間値の差の 4 倍を超えれば、誤差推定をその差の 4 倍に $b-a$ を掛けた値以上に引き上げる。

各成分の誤差推定は次の 3 つの最大値である。

- 最高の 2 つの外挿次数で、直前の段からの変化をそれぞれ 4 倍した値
- 上の検査点による誤差
- 丸め誤差による精度の限界 $50\,\varepsilon A$（$A$ は台形則による $\int_a^b|f|\,dx$ の推定）

`ToleranceReached` は 5 段目以降（検査点を含めて 34 回以上の評価）で、推定が許容誤差を満たし、0 でない標本があり、推定が $A/4$ 以下のときに限る。
推定が丸め誤差による精度の限界に達しても許容誤差を満たさなければ `Stagnation`、全段を使い切れば `RefinementLimit` になる。
成功しなかった場合は、完了した段のうち誤差推定が最小の段の値を返す（4 段目を終えた後は 4 段目以降から選ぶ）。
推定は上界ではない。
入れ子の格子と 1 個の検査点で見えない構造は見落としうる。
`RombergWorkspace` は評価点のブロックの大きさだけを持ち、段数によらない。
`component_errors()` で成分ごとの推定を読める。

次のセルは 4 つの被積分関数について、台形則の列 $T(h_j)$ の誤差と誤差比、および `Romberg` の結果を示す。
被積分関数は $e^x$（滑らか、厳密値 $e-1$）、$\sqrt{x}$（端点で滑らかでない、$2/3$）、$1/(2+\cos2\pi x)$（周期的、$1/\sqrt3$）、$\sin^2(16\pi x)$（二進格子と共鳴、$1/2$）である。
入力は被積分関数と、`LevelOptions` の絶対・相対許容誤差の指数 $q$ である。
誤差が 0 になる段では誤差比を定義しない。

```rust
//| id: integrate-romberg-integrands
//| ref: integrate-romberg-integrands
//| title: 被積分関数の滑らかさと周期性で台形則の列と Romberg 外挿の振る舞いを比べる
//| run: reactive
//| crates: [scioxide-core, scioxide-integrate]
//| inputs:
//|   integrand_kind: {"type":"select","label":"被積分関数","description":"滑らか、端点で平方根、周期的、二進格子と共鳴する関数から選ぶ。","options":["exp","sqrt","periodic","resonant"],"value":"exp"}
//|   tolerance_exponent: {"type":"range","label":"許容誤差の指数 q [-]","description":"絶対・相対許容誤差をともに 10^q とする。","min":-14,"max":-4,"step":1,"value":-10}
//| cases:
//|   - {"id":"sqrt","label":"√x","description":"端点で滑らかでないと誤差比が 4 でなくなり、外挿の効果が落ちる。","inputs":{"integrand_kind":"sqrt"}}
//|   - {"id":"periodic","label":"周期関数","description":"台形則そのものが幾何級数的に収束する。","inputs":{"integrand_kind":"periodic"}}
//|   - {"id":"resonant","label":"sin²(16πx)","description":"4 段目までの格子点ではすべて 0 になるが、格子外の点の検査で細分を続ける。","inputs":{"integrand_kind":"resonant"}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"trapezoid","path":"/rows/3/3","approx":{"value":4.0,"atol":0.01}}
//|       - {"artifact":"romberg","path":"/rows/0/1","range":{"min":0,"max":1e-10}}
//|       - {"path":"/outputs/2/state","equals":"satisfied"}
//|   - case: sqrt
//|     expect:
//|       - {"artifact":"trapezoid","path":"/rows/8/3","approx":{"value":2.81,"atol":0.03}}
//|       - {"path":"/outputs/2/state","equals":"partial"}
//|   - case: periodic
//|     expect:
//|       - {"artifact":"trapezoid","path":"/rows/4/2","range":{"min":5e-10,"max":1.2e-9}}
//|       - {"artifact":"trapezoid","path":"/rows/6/2","range":{"min":0,"max":1e-14}}
//|   - case: resonant
//|     expect:
//|       - {"artifact":"trapezoid","path":"/rows/4/2","approx":{"value":0.5,"atol":1e-12}}
//|       - {"artifact":"romberg","path":"/rows/0/1","range":{"min":0,"max":1e-10}}
//|       - {"path":"/outputs/2/state","equals":"satisfied"}
use scioxide_core::{Budget, ErrorTolerance, Interval, NormSelection, RealScalar};
use scioxide_integrate::{FixedRule, LevelOptions, NewtonCotes, NewtonCotesEndpoints, Romberg};

let pi = std::f64::consts::PI;
// 被積分関数と [0, 1] での厳密値。
let (integrand, exact): (Box<dyn Fn(f64) -> f64 + Sync>, f64) = match integrand_kind.as_str() {
    "sqrt" => (Box::new(|x| RealScalar::sqrt(x)), 2.0 / 3.0),
    "periodic" => (
        Box::new(move |x| 1.0 / (2.0 + RealScalar::cos(2.0 * pi * x))),
        1.0 / RealScalar::sqrt(3.0),
    ),
    "resonant" => (
        Box::new(move |x| RealScalar::powi(RealScalar::sin(16.0 * pi * x), 2)),
        0.5,
    ),
    _ => (Box::new(|x| RealScalar::exp(x)), RealScalar::exp_m1(1.0)),
};
let f = |x: f64| Ok(integrand(x));
let interval = Interval::new(0.0, 1.0).map_err(|e| e.to_string())?;

// 刻み h_j = 2^(−j) の複合台形則 T(h_j) の列。
let mut rows = Vec::new();
let mut previous: Option<f64> = None;
for level in 0..=10_u32 {
    let panels = Budget::try_from(1_usize << level).map_err(|e| e.to_string())?;
    let rule =
        NewtonCotes::new(2, NewtonCotesEndpoints::Closed, panels).map_err(|e| e.to_string())?;
    let (value, _) = rule.integrate(&f, interval).map_err(|e| e.to_string())?;
    let error = (value - exact).abs();
    // 誤差比 e_{j−1}/e_j。どちらかが 0 なら定義しない。
    let ratio = previous
        .filter(|&p| p > 0.0 && error > 0.0)
        .map(|p| p / error);
    rows.push((level, rule.node_count(), error, ratio));
    previous = Some(error);
}
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let sig4 = serde_json::json!({ "significantDigits": 4 });
let sig15 = serde_json::json!({ "significantDigits": 15 });
let trapezoid_columns = serde_json::json!([
    { "key": "0", "label": "段 j [-]", "type": "integer" },
    { "key": "1", "label": "評価回数 [回]", "type": "integer" },
    { "key": "2", "label": "台形則の誤差 |T(h_j) − I| [-]", "type": "number", "format": sci3 },
    {
        "key": "3",
        "label": "誤差比 e_{j−1}/e_j [-]",
        "type": "number",
        "format": sig4,
        "nullText": "未定義"
    }
]);
emit_table_with_columns!(
    trapezoid_columns,
    rows,
    metadata = serde_json::json!({ "id": "trapezoid" })
);

// 同じ関数を Romberg 外挿で、許容誤差 10^q まで計算する。
let requested = 10.0_f64.powf(tolerance_exponent);
let options = LevelOptions::default().with_tolerance(
    ErrorTolerance::scalar(requested, requested, NormSelection::Infinity)
        .map_err(|e| e.to_string())?,
);
let romberg = Romberg::new(options).map_err(|e| e.to_string())?;
let (value, report) = romberg.integrate(&f, interval).map_err(|e| e.to_string())?;
let romberg_columns = serde_json::json!([
    { "key": "0", "label": "Romberg の値 [-]", "type": "number", "format": sig15 },
    { "key": "1", "label": "実際の誤差 [-]", "type": "number", "format": sci3 },
    { "key": "2", "label": "誤差推定 [-]", "type": "number", "format": sci3, "nullText": "未推定" },
    { "key": "3", "label": "評価回数 [回]", "type": "integer" },
    { "key": "4", "label": "終了理由" }
]);
emit_table_with_columns!(
    romberg_columns,
    vec![(
        value,
        (value - exact).abs(),
        report.error_estimate(),
        report.evaluations(),
        report.termination().to_string(),
    )],
    metadata = serde_json::json!({ "id": "romberg" })
);

let termination = report.termination();
let outcome = if termination.is_success() {
    Outcome::satisfied("Romberg 外挿の誤差推定が許容誤差を満たした")
} else {
    Outcome::partial("Romberg 外挿が許容誤差を満たす前に止まった")
        .explanation("表の値は最小の誤差推定を持つ段の値で、推定値として扱う。")
};
let mut outcome = outcome
    .status(termination.to_string())
    .diagnostic("評価回数", report.evaluations() as f64, None)
    .diagnostic("実際の誤差", (value - exact).abs(), None);
if let Some(estimate) = report.error_estimate() {
    outcome = outcome.diagnostic("誤差推定", estimate, None);
}
emit_outcome!(outcome);
```

$e^x$ では誤差比が 4 に近づき、`Romberg` は最少の 34 回の評価で `ToleranceReached` になった（誤差推定 $5\times10^{-12}$、実際の誤差は丸めの範囲）。
$\sqrt{x}$ では誤差比が $2.82$ に近づき、偶数べきの展開が成り立たないので外挿の効果が落ちる。
`Romberg` は 15 段を使い切って 16 386 回の評価で `RefinementLimit` になり、実際の誤差は $3.3\times10^{-8}$、推定は $2.4\times10^{-7}$ だった。
周期関数では誤差比が $2+\sqrt3$ のべきで増え、17 点で誤差が $8\times10^{-10}$、33 点で丸めの水準に達した。
共鳴する関数では 17 点までの台形則がすべて 0 を返して誤差 $0.5$ になるが、`Romberg` は検査点で共鳴を検出して細分を続け、2050 回の評価で $1/2$ に収束した（`ToleranceReached`）。

## まとめ

十分に滑らかな関数では、複合台形則の誤差は Euler–Maclaurin の公式により $h$ の偶数べきに展開でき、Romberg 外挿はその項を順に消す。
端点で滑らかでない関数では展開に別のべきが現れて外挿の効果が落ちるので、[二重指数変換](../improper-singular-and-oscillatory/)などを使う。
滑らかな周期関数を 1 周期積分するなら、台形則だけで幾何級数的に収束する。
`Romberg` の誤差推定は外挿の変化、格子外の検査点、丸め誤差による精度の限界の最大で、上界ではない。
成功には 5 段目以降で推定が許容誤差と $A/4$ の両方を満たすことが要り、段数を使い切ると `RefinementLimit` になる。
