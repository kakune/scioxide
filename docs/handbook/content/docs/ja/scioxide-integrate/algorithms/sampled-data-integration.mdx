測定値やシミュレーションの出力のように、被積分関数が固定の点の値としてだけ与えられることがある。
このとき適応求積のように新しい点で関数を評価し直すことはできず、与えられた標本だけから積分を近似する。
このページは非一様な格子の台形則と Simpson 則、等間隔の標本の Romberg 積分、累積積分、多次元配列の軸ごとの積分を扱う。

被積分関数を任意の点で評価できるなら、[埋め込み対と大域適応求積](../adaptive-quadrature/)の適応求積や[端点重み・主値・複素経路の重み付き求積](../weighted-rules-and-sensitivities/)を使う。

## 標本の Plan と誤差推定

座標 $x_i$ での標本を $y_i = f(x_i)$ と書く。
`SampledTrapezoidPlan`、`SampledSimpsonPlan`、`SampledRombergPlan` は、座標を一度だけ準備し、その座標の標本列を何度でも積分する Plan である。
レポート（`IntegrationReport`）も誤差推定も返さない。
誤差を知りたいときは、異なる次数の則の差や、標本を間引いた積分との差で利用者が見積もる。

同じ座標で一度だけ積分するなら、ワンショット関数 `trapezoid(&samples, &coordinates)`、`simpson(&samples, &coordinates)`、`cumulative_trapezoid(&samples, &coordinates)` で足りる。
これらは対応する Plan と作業領域をその場で作り、全区間の値、または累積積分の標本ごとの値の `Vec` を返す。
設定する選択肢はなく、結果は Plan で求めた値と同じである。
他のワンショット関数と違って `Integral` ではなく値そのものを返し、誤差推定は持たない。
標本と座標の数が違えば `DimensionMismatch` で、座標の条件とエラーは Plan と同じである。
同じ座標で何度も積分するとき、累積積分の作業領域を使い回すとき、Simpson 則の累積積分や Romberg 積分、配列の軸に沿った積分が要るときは Plan を使う。

## 非一様格子の台形則

座標 $x_0, \dots, x_{n-1}$ が狭義単調（増加または減少）なら、台形則は

$$
\int f\,dx \approx \sum_{i=0}^{n-2} \frac{h_i\,(y_i + y_{i+1})}{2}, \qquad h_i = x_{i+1} - x_i
$$

である。
各区間の誤差は $-h_i^3 f''(\xi_i)/12$ なので、全体の誤差は $-\frac{1}{12}\sum_i h_i^3 f''(\xi_i)$ となり、最大の間隔を $h$ として $O(h^2)$ で減る。
1 次式に対して厳密で、減少する座標では $x_0$ から $x_{n-1}$ へ向かう積分（符号が逆）になる。
標本が 2 個未満なら結果は 0 である。

`SampledTrapezoidPlan::new(&coordinates)` は丸めた重み $h_i/2$ を保持し、等間隔なら 1 つの重みだけを保持する。
結果は重みと標本の積の厳密な和を 1 回だけ丸めた値である。
準備の計算コストは $O(n)$、適用の計算コストは実数成分の数を $d$ として $O(nd)$ である。

## 非一様格子の Simpson 則

`SampledSimpsonPlan` は区間の組 $[x_{2k}, x_{2k+2}]$ ごとに、3 つの標本を通る 2 次式を積分する。
間隔を $h_1 = x_1 - x_0$、$h_2 = x_2 - x_1$、$h = h_1 + h_2$ とすると、Lagrange 基底の積分から組の重みは

$$
w_0 = \frac{h\,(2h_1 - h_2)}{6h_1}, \qquad w_1 = \frac{h^3}{6h_1h_2}, \qquad w_2 = \frac{h\,(2h_2 - h_1)}{6h_2}
$$

となり、$h_1 = h_2$ で通常の Simpson 則 $\frac{h}{6}(1, 4, 1)$ に戻る。
補間誤差 $f'''(\xi)(x-x_0)(x-x_1)(x-x_2)/6$ を積分すると

$$
\int_{x_0}^{x_2}(x-x_0)(x-x_1)(x-x_2)\,dx = \frac{h^3(h_1 - h_2)}{12}
$$

なので、組の誤差の主要項は $f'''\,h^3(h_1-h_2)/72$ で、その次が $O(h^5 f^{(4)})$ である。
等間隔では第 1 項が消えて 3 次式まで厳密になり、全体の誤差は $O(h^4)$ になる。
間隔が滑らかに変わる格子（$h_2 - h_1 = O(h^2)$）でも $O(h^4)$ が保たれるが、任意の非一様格子では $O(h^3)$ に落ちる。
非一様な Simpson 則は 2 次式に対して厳密である。

区間の数が奇数のときは、最後の区間を最後の 3 標本を通る 2 次式で積分する。
標本が 2 個なら台形則、2 個未満なら 0 である。
累積積分が組の内部の標本で終わるときは、その組の 2 次式をその標本まで積分する。
間隔の比が極端に大きいと重みが大きくなり、標本の誤差を増幅する。
Plan は重みが有限であることだけを要求する。

各重みは座標の差の厳密な積から作り、分子と分母を 1 回ずつ、商をもう 1 回丸めるので、厳密な値から 2 ulp 以内に入る。
等間隔の組では左右の重みがビット単位で一致する。
間隔そのものを計算しないので、$[-10^{308}, 0, 10^{308}]$ のように幅が桁あふれする座標も準備できる。
有限の範囲に入らない重みだけが `NumericalInstability` になり、重複・向きの反転は `InvalidInput`、非有限の座標は `NonFinite` である。

## 等間隔の標本の Romberg 積分

`SampledRombergPlan::new(samples, spacing)` は $2^k + 1$ 個の等間隔の標本を、符号つきの間隔 `spacing` で積分する。
刻み $2^k h, \dots, 2h, h$ の台形和 $T_0, \dots, T_k$ に Richardson 外挿

$$
R_{j,m} = R_{j,m-1} + \frac{R_{j,m-1} - R_{j-1,m-1}}{4^m - 1}, \qquad R_{j,0} = T_j
$$

を施し、$R_{k,k}$ を結果とする。
$R_{k,k}$ は $2k+1$ 次までの多項式に対して厳密で、外挿は標本ごとの 1 つの重みにまとめて準備する。
理論は[Euler–Maclaurin 展開と Romberg 外挿](../romberg-extrapolation/)にある。
非一様な座標は受け付けず、標本数が $2^k + 1$ でなければ、または間隔が 0 なら `InvalidInput` である。

## 累積積分と軸ごとの積分

台形則と Simpson 則の `cumulative_into` は $x_0$ から各 $x_i$ までの積分を標本ごとに書き、最初は 0、最後は `integrate_into` の結果に等しい。
Romberg の累積積分は添字 $1, 2, 4, \dots, 2^k$ で終わる前置区間の Romberg 値で、その添字は `cumulative_indices()` が返す。
各前置区間はその区間の標本だけを使う。

結果を一時的に保持する `SampledWorkspace` は Plan から作る。
`plan.workspace(components)` は `integrate_into` 用で、結果 1 個分の領域を持つ。
`plan.cumulative_workspace(components)` は `cumulative_into` 用で、台形則と Simpson 則では標本ごと、Romberg では `cumulative_indices()` の添字ごとに 1 個分の領域を持ち、`integrate_into` にも使える。
`components` は値 1 個の実数成分の数で、実数なら 1、複素数なら 2 である。
呼び出しは作業領域の成分数と容量だけを照合するので、容量が足りれば別の Plan にも渡せる（次の実験では台形則の累積積分の作業領域を Simpson 則にも使う）。
結果をすべて計算してから書くので、エラー時は出力を書き換えない。

多次元配列の 1 つの軸に沿った積分には `axis_into(&samples, axis, &mut output, &mut workspace)` を使う。
`samples` は scioxide-core の `NdView`（スライスと `StridedLayout` の組）で、`axis` に沿った各レーンを `integrate_into` と同じく積分する。
`output` は `NdViewMut` で、形は `samples` から `axis` を除いたものである。
`cumulative_axis_into` は各レーンの累積積分を書き、`output` の `axis` の長さは累積の結果の数になる。
軸ごとの積分の作業領域 `SampledAxisWorkspace` は `plan.axis_workspace(shape, axis, components)` と `plan.cumulative_axis_workspace(shape, axis, components)` で、配列の形 `Shape` から作る。
形と軸は、後の呼び出しと一致させる。
`axis` が階数以上なら `OutOfBounds`、形の不一致は `DimensionMismatch`、非有限の標本は `NonFinite`、結果の桁あふれは `NumericalInstability`（`NumericalIssue::Overflow`）である。

## 非一様格子の累積積分

$[0, \pi]$ 上の $f(x) = \sin x$ を、$x_i = \pi (i/n)^p$（$i = 0, \dots, n$）の格子で標本にする。
$p = 1$ は等間隔で、$p > 1$ では原点の近くに点が集まる。
累積積分 $\int_0^{x_i}\sin x\,dx = 1 - \cos x_i$ を台形則と Simpson 則の Plan で計算し、各標本点での誤差を図に描く。
表は全区間の誤差と、区間を 2 倍にした格子での誤差から求めた観測次数 $\log_2(e_n/e_{2n})$ を示す。
比較として、同じ区間の $2^k + 1 \ge n + 1$ 個の等間隔の標本を `SampledRombergPlan` で積分する。
参照値の $\cos$ は f64 の標準関数で計算し、標本の $\sin x_i$ は SciOxide の `RealScalar::sin` で作る。

区間を 2 倍にした格子の全区間の積分は、ワンショット関数 `trapezoid` と `simpson` で求める。
同じ座標で一度だけ積分するなら、Plan と作業領域を書かずに済む。
表の最後の列はワンショット呼び出しの `cumulative_trapezoid` と `simpson` の結果と、Plan の結果との差である。
ワンショット関数は同じ Plan をその場で作るだけなので、この差は 0 になる。

入力は区間の数 $n$ と格子を伸ばす指数 $p$ である。
誤差が厳密に 0 の点は対数軸に描けないので除き、その数を表に示す。
座標と標本は次の実験に渡す。

```rust
//| id: integrate-sampled-cumulative
//| ref: integrate-sampled-cumulative
//| title: 非一様格子の累積積分を閉じた形と比べる
//| run: reactive
//| crates: [scioxide-core, scioxide-integrate]
//| exports: [coordinates, samples]
//| inputs:
//|   intervals: {"type":"range","label":"区間の数 n [-]","description":"標本数は n + 1。奇数なら Simpson 則の最後の区間は 3 標本の 2 次式で積分する。","min":4,"max":64,"step":1,"value":16}
//|   stretch: {"type":"range","label":"格子を伸ばす指数 p [-]","description":"x_i = π (i/n)^p。p = 1 は等間隔。","min":1,"max":3,"step":0.25,"value":2}
//| cases:
//|   - {"id":"uniform","label":"p = 1","description":"等間隔では Simpson 則の誤差が O(h⁴) で小さい。","inputs":{"stretch":1}}
//|   - {"id":"odd-intervals","label":"n = 15","description":"区間の数が奇数のとき、最後の区間は最後の 3 標本の 2 次式で積分する。","inputs":{"intervals":15}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"methods","path":"/rows/0/4","range":{"min":1.9,"max":2.1}}
//|       - {"artifact":"methods","path":"/rows/1/4","range":{"min":3.8,"max":4.2}}
//|       - {"artifact":"methods","path":"/rows/2/2","range":{"min":0,"max":1e-8}}
//|       - {"artifact":"methods","path":"/rows/0/6","equals":0}
//|       - {"artifact":"methods","path":"/rows/1/6","equals":0}
//|   - case: uniform
//|     expect:
//|       - {"artifact":"methods","path":"/rows/1/2","range":{"min":0,"max":1e-4}}
//|       - {"artifact":"methods","path":"/rows/1/4","range":{"min":3.8,"max":4.2}}
//|   - case: odd-intervals
//|     expect:
//|       - {"artifact":"methods","path":"/rows/1/2","range":{"min":1e-4,"max":1e-2}}
use scioxide_core::RealScalar;
use scioxide_integrate::{
    SampledRombergPlan, SampledSimpsonPlan, SampledTrapezoidPlan, cumulative_trapezoid,
    simpson, trapezoid,
};

let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let fixed2 = serde_json::json!({ "fractionDigits": 2 });
let pi = std::f64::consts::PI;
// m 区間の格子 x_i = π (i/m)^p と標本 sin x_i。
let grid = |m: usize| -> (Vec<f64>, Vec<f64>) {
    let x: Vec<f64> = (0..=m)
        .map(|i| pi * RealScalar::powf(i as f64 / m as f64, stretch))
        .collect();
    let y = x.iter().map(|&t| RealScalar::sin(t)).collect();
    (x, y)
};
let n = intervals as usize;
let (coordinates, samples) = grid(n);

// 累積積分 ∫₀^{x_i} sin x dx を台形則と Simpson 則で求める。
let trapezoid_plan = SampledTrapezoidPlan::new(&coordinates).map_err(|e| e.to_string())?;
let simpson_plan = SampledSimpsonPlan::new(&coordinates).map_err(|e| e.to_string())?;
// 累積積分の作業領域は台形則の Plan から作り、標本数が同じ Simpson 則にも使う。
let mut workspace = trapezoid_plan
    .cumulative_workspace(1)
    .map_err(|e| e.to_string())?;
let mut cumulative = [vec![0.0_f64; n + 1], vec![0.0_f64; n + 1]];
trapezoid_plan
    .cumulative_into(&samples, &mut cumulative[0], &mut workspace)
    .map_err(|e| e.to_string())?;
simpson_plan
    .cumulative_into(&samples, &mut cumulative[1], &mut workspace)
    .map_err(|e| e.to_string())?;

// ワンショット関数は同じ Plan をその場で作るので、Plan の結果と一致するはずである。
let one_shot = cumulative_trapezoid(&samples, &coordinates).map_err(|e| e.to_string())?;
let one_shot_total = simpson(&samples, &coordinates).map_err(|e| e.to_string())?;
let one_shot_gap = [
    one_shot
        .iter()
        .zip(&cumulative[0])
        .map(|(a, b)| (a - b).abs())
        .fold(0.0, f64::max),
    (one_shot_total - cumulative[1][n]).abs(),
];

// 参照値 1 − cos x（f64 の標準関数）との差。0 の点は対数軸に描けないので数える。
let mut curves = [Vec::new(), Vec::new()];
let mut zeros = [0_usize; 2];
for (i, &x) in coordinates.iter().enumerate().skip(1) {
    let exact = 1.0 - x.cos();
    for c in 0..2 {
        let error = (cumulative[c][i] - exact).abs();
        if error > 0.0 {
            curves[c].push([x, error]);
        } else {
            zeros[c] += 1;
        }
    }
}
let series = |name: &str, points: &Vec<[f64; 2]>| {
    let style = serde_json::json!({ "showSymbol": true });
    serde_json::json!({ "name": name, "points": points, "style": style })
};
emit_line_chart!(
    &vec![
        series("台形則", &curves[0]),
        series("Simpson 則", &curves[1])
    ],
    options = &serde_json::json!({
        "xLabel": "上端の位置 x_i [-]",
        "yLabel": "累積積分の誤差 [-]",
        "yType": "log",
        "xMin": 0.0,
        "xMax": pi
    })
);

// 区間を 2 倍にした格子での全区間の積分（ワンショット呼び出し）。観測次数は log₂(e_n / e_2n)。
let (refined, refined_samples) = grid(2 * n);
let refined_errors = [
    (trapezoid(&refined_samples, &refined).map_err(|e| e.to_string())? - 2.0).abs(),
    (simpson(&refined_samples, &refined).map_err(|e| e.to_string())? - 2.0).abs(),
];

// 比較: 同じ区間の 2^k + 1 ≥ n + 1 個の等間隔の標本を Romberg で積分する。
let count = n.next_power_of_two() + 1;
let spacing = pi / (count - 1) as f64;
let uniform: Vec<f64> = (0..count)
    .map(|i| RealScalar::sin(i as f64 * spacing))
    .collect();
let romberg = SampledRombergPlan::new(count, spacing).map_err(|e| e.to_string())?;
let mut romberg_workspace = romberg.workspace(1).map_err(|e| e.to_string())?;
let mut romberg_total = 0.0_f64;
romberg
    .integrate_into(&uniform, &mut romberg_total, &mut romberg_workspace)
    .map_err(|e| e.to_string())?;

// 全区間の厳密値は 2。観測次数は両方の誤差が正のときだけ定義する。
let order =
    |coarse: f64, fine: f64| (coarse > 0.0 && fine > 0.0).then(|| (coarse / fine).log2());
let mut rows = Vec::new();
for (c, name) in ["台形則", "Simpson 則"].into_iter().enumerate() {
    // e と f は n 区間と 2n 区間の誤差、z は図で除いた点、g はワンショット呼び出しとの差。
    let (e, f) = ((cumulative[c][n] - 2.0).abs(), refined_errors[c]);
    let (z, g) = (Some(zeros[c]), Some(one_shot_gap[c]));
    rows.push((name, n + 1, e, Some(f), order(e, f), z, g));
}
let romberg_error = (romberg_total - 2.0).abs();
rows.push((
    "Romberg（等間隔）",
    count,
    romberg_error,
    None,
    None,
    None,
    None,
));
let columns = serde_json::json!([
    { "key": "0", "label": "方法" },
    { "key": "1", "label": "標本数 [個]", "type": "integer" },
    { "key": "2", "label": "全区間の誤差 [-]", "type": "number", "format": sci2 },
    { "key": "3", "label": "2n 区間での誤差 [-]", "type": "number", "format": sci2, "nullText": "計算せず" },
    { "key": "4", "label": "観測次数 [-]", "type": "number", "format": fixed2, "nullText": "未定義" },
    { "key": "5", "label": "図で除いた点 [個]", "type": "integer", "nullText": "図なし" },
    { "key": "6", "label": "ワンショット呼び出しとの差 [-]", "type": "number", "format": sci2, "nullText": "対象外" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "methods" })
);
export!(coordinates, &coordinates);
export!(samples, &samples);
```

既定値（$n = 16$、$p = 2$）では、全区間の誤差は台形則で $1.3 \times 10^{-2}$、Simpson 則で $2.1 \times 10^{-4}$ だった。
区間を 2 倍にしたときの観測次数は台形則で 2.00、Simpson 則で 4.00 で、滑らかに伸びた格子でも Simpson 則の $O(h^4)$ が保たれる。
同じ 17 個の標本数の等間隔の Romberg は誤差 $5 \times 10^{-9}$ で、標本の位置を選べるなら等間隔の格子と外挿が有利である。
$p = 2$ の格子は $\pi$ の近くで間隔が等間隔の約 2 倍になるので、等間隔（$p = 1$）より誤差が大きい。

$n = 15$ では最後の区間を最後の 3 標本の 2 次式で積分するので、Simpson 則の誤差は $1.2 \times 10^{-3}$ に増える。
このとき $n$ と $2n$ で区間の数の偶奇が異なるので、観測次数は 6 程度になり、収束の次数としては読めない。

## 配列の軸に沿った積分

前の実験の座標と標本から 2 次元の配列 $F_{ji} = e^{-y_j}\sin x_i$（$y_j = 0, 1, 2$）を作り、$x$ の軸（軸 1）に沿って Simpson 則で積分する。
配列は行優先で、形は $3 \times (n+1)$ である。
各行の厳密値は $2e^{-y_j}$ で、参照値の $e^{-y}$ は f64 の標準関数で計算する。
同じ配列に `cumulative_axis_into` も適用し、各行の累積積分の最後の値が `axis_into` の結果と一致することを確かめる。
入力は持たず、前の実験の $n$ と $p$ に従う。

```rust
//| id: integrate-sampled-axis
//| ref: integrate-sampled-axis
//| title: 2 次元配列の軸に沿った積分と累積積分
//| run: reactive
//| crates: [scioxide-core, scioxide-integrate]
//| dependsOn:
//|   grid: integrate-sampled-cumulative
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"axis","path":"/rows/0/2","range":{"min":0,"max":1e-3}}
//|       - {"artifact":"axis","path":"/rows/2/1","approx":{"value":0.27064,"rtol":1e-3}}
//|       - {"artifact":"axis","path":"/rows/1/3","equals":0}
use scioxide_core::{NdView, NdViewMut, RealScalar, Shape, StridedLayout};
use scioxide_integrate::SampledSimpsonPlan;

let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let digits10 = serde_json::json!({ "significantDigits": 10 });
let read = |key: &str| -> Result<Vec<f64>, String> {
    serde_json::from_value(grid[key].clone()).map_err(|e| e.to_string())
};
let (coordinates, samples) = (read("coordinates")?, read("samples")?);
let m = coordinates.len();

// 2 次元の配列 F[j][i] = e^(−y_j) sin x_i（行優先、形 3 × m）。
let heights = [0.0_f64, 1.0, 2.0];
let mut values = Vec::with_capacity(3 * m);
for &y in &heights {
    values.extend(samples.iter().map(|&s| RealScalar::exp(-y) * s));
}
let (shape, strides) = ([3, m], [m, 1]);
let layout = StridedLayout::new(&shape, &strides).map_err(|e| e.to_string())?;
let view = NdView::new(&values, layout).map_err(|e| e.to_string())?;
let plan = SampledSimpsonPlan::new(&coordinates).map_err(|e| e.to_string())?;

// 軸 1（x）に沿った積分。出力の形は軸 1 を除いた [3]。
let mut totals = [0.0_f64; 3];
let total_layout = StridedLayout::new(&[3], &[1]).map_err(|e| e.to_string())?;
let mut total_view = NdViewMut::new(&mut totals, total_layout).map_err(|e| e.to_string())?;
let mut workspace = plan
    .axis_workspace(Shape::new(&shape).map_err(|e| e.to_string())?, 1, 1)
    .map_err(|e| e.to_string())?;
plan.axis_into(&view, 1, &mut total_view, &mut workspace)
    .map_err(|e| e.to_string())?;

// 軸 1 に沿った累積積分。出力の形は入力と同じ [3, m] で、各行の最後が上の積分に等しい。
let mut prefixes = vec![0.0_f64; 3 * m];
let prefix_layout = StridedLayout::new(&shape, &strides).map_err(|e| e.to_string())?;
let mut prefix_view =
    NdViewMut::new(&mut prefixes, prefix_layout).map_err(|e| e.to_string())?;
let mut cumulative_workspace = plan
    .cumulative_axis_workspace(Shape::new(&shape).map_err(|e| e.to_string())?, 1, 1)
    .map_err(|e| e.to_string())?;
plan.cumulative_axis_into(&view, 1, &mut prefix_view, &mut cumulative_workspace)
    .map_err(|e| e.to_string())?;

let mut rows = Vec::new();
for (j, &y) in heights.iter().enumerate() {
    // 参照値 2 e^(−y)（f64 の標準関数）。
    let exact = 2.0 * (-y).exp();
    let last = prefixes[j * m + m - 1];
    rows.push((
        y,
        totals[j],
        (totals[j] - exact).abs(),
        (last - totals[j]).abs(),
    ));
}
let columns = serde_json::json!([
    { "key": "0", "label": "y_j [-]", "type": "number", "format": { "fractionDigits": 0 } },
    { "key": "1", "label": "軸 1 に沿った積分 [-]", "type": "number", "format": digits10 },
    { "key": "2", "label": "2e^(−y_j) との差 [-]", "type": "number", "format": sci2 },
    { "key": "3", "label": "累積積分の最後との差 [-]", "type": "number", "format": sci2 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "axis" })
);
```

既定値では、各行の値は 1 次元の Simpson 則の結果に $e^{-y_j}$ を掛けたものに一致し、誤差も同じ比で小さくなる。
累積積分の最後の値は軸に沿った積分とビット単位で一致する。

---

## まとめ

固定の標本は `SampledTrapezoidPlan`、`SampledSimpsonPlan`、`SampledRombergPlan` で積分し、座標は Plan として一度だけ準備する。
同じ座標で一度だけ積分するなら、ワンショット呼び出しの `trapezoid`、`simpson`、`cumulative_trapezoid` で足り、結果は Plan と同じになる。
非一様な格子では台形則が $O(h^2)$、Simpson 則が滑らかに変わる格子で $O(h^4)$、任意の格子では $O(h^3)$ の誤差になる。
標本の位置を選べるなら、等間隔の $2^k+1$ 標本と Romberg 外挿が少ない標本で高い精度を出す。
標本の積分は誤差推定を返さないので、異なる則の差や、区間を 2 倍にした格子との差で精度と観測次数を見積もる。
累積積分は `cumulative_into`、多次元配列の 1 つの軸に沿った積分は `axis_into` と `SampledAxisWorkspace` で行い、エラー時は出力を書き換えない。
