三角形・四面体の要素や球面のように、決まった形の領域には、その形に合わせて作った固定則を直接使える。
固定則は節点と重みが決まっているので、評価回数が事前に分かり、要素ごとの積分を有限要素法のような計算に組み込みやすい。
このページは単体上の正の重みの則と Grundmann–Möller 則、メッシュの要素の積分と向き、球面の積則と Lebedev 則を扱う。
外側の座標に依存する端点や座標写像で一般の領域を扱う方法は[可変端点の反復積分と座標写像](../domains-and-geometric-rules/)にある。

## 単体上の求積則

三角形・四面体などの $d$ 単体（$d+1$ 個の頂点の凸包）には、直方体を経由せずに固定則を使える。
`SimplexRule` は則を基準単体 $T = \{\boldsymbol x : x_i \ge 0,\ \sum_i x_i \le 1\}$（体積 $1/d!$）上に持ち、節点を重心座標 $(\lambda_0, \dots, \lambda_d)$ で保持する。
頂点 $\boldsymbol v_0, \dots, \boldsymbol v_d$ の単体へは節点 $j$ を $\boldsymbol x_j = \sum_k \lambda_{jk} \boldsymbol v_k$ に写し、

$$
\int_S f\,d\boldsymbol x \approx |\det J| \sum_j w_j f(\boldsymbol x_j), \qquad J = [\boldsymbol v_1 - \boldsymbol v_0, \dots, \boldsymbol v_d - \boldsymbol v_0]
$$

を計算する。
則は全次数が `exactness_degree()` 以下の多項式を、丸めを除いて厳密に積分する。
誤差推定はなく、終了状態は `FixedRuleCompleted` である。

二つの族がある。

- `SimplexRule::positive(d, minimum_degree, options)` は、次元 1〜3、要求次数 0〜7 で、重みが正、節点が単体の内部にある則を作る。
  線分には最少の点数の Gauss–Legendre 則、三角形・四面体には Xiao–Gimbutas の表の則を使う。
  三角形の要求次数 3 には 6 点の 4 次則を使うので、実際の次数と点数は `exactness_degree()` と `node_count()` で確かめる。
- `SimplexRule::new(d, s, options)` は、任意の次元で使える指数 $s$ の Grundmann–Möller 則で、全次数 $2s+1$ を厳密に積分し、$\binom{d+s+1}{s}$ 個の節点を持つ。
  重みの符号は交互に変わる。

重みの和はどちらも基準単体の体積 $1/d!$ である。
負の重みを持つ則では、重みの絶対値の和 $\Lambda = \sum_j |w_j|$ が体積を上回り、関数値の丸め誤差が $\Lambda/\text{体積}$ 倍に拡大される。
Grundmann–Möller 則では $s$ とともにこの比が急に大きくなるので、高い次数を一度に使うより、単体を細分して低い次数を使うほうが安定である。
正の重みの則は $\Lambda$ が体積に等しく、係数が各節点で正なら離散化した質量や拡散係数の正性も保つ。
ただし、高い次数を指定しても、標本化していない点での係数の正性や積分の誤差を証明するわけではない。

### 写像・向き・メッシュの要素

`rule.map_nodes_into(&vertices, &mut points, &mut weights, &mut workspace)` は、物理座標の節点と重み $|\det J|\,w_j$ を呼び出し側の配列に書き、`SimplexMeasure` を返す。
`SimplexMeasure` の `measure` は体積 $|\det J|/d!$、`orientation` は $\det(\boldsymbol v_1 - \boldsymbol v_0, \dots, \boldsymbol v_d - \boldsymbol v_0)$ の符号（`PredicateSign`）である。
符号は頂点の座標から厳密な幾何述語で求め、丸めた行列式の符号には頼らない。
積分は $|\det J|$ を使うので、頂点の順序を入れ替えて向きが反転しても値は変わらない。
向きは境界の法線の向きを決めたり要素の並び方を検査したりするための情報として別に返される。
厳密な判定に必要な項数は $(d+1)!$ で、`GeometricOptions::with_predicate_terms` の既定 4096 は $d \le 5$ まで足りる。
頂点が厳密に同一の超平面上にある平らな単体は、評価なしで厳密な 0 と `DegenerateDomain` を返す。
辺ベクトル、写した節点、体積、重みが桁あふれするか、0 でない体積や重みが 0 にアンダーフローすると、`NumericalInstability` のエラーになる。
重み付きの和 $\sum_j w_j f(\boldsymbol x_j)$ は Neumaier の補償和で求め、途中の積や和が浮動小数点数の範囲を外れると指数範囲を広げた表現に切り替える。

自分で計算した節点の値を積分するには、`map_nodes_into` で節点の位置を得てから、節点ごとの値を `rule.integrate_values_into(&vertices, &values, &mut out, &mut workspace, scope)` に渡す。
値は `barycentric_nodes()` と同じ順に、1 節点あたり $c$ 成分を並べる。
この呼び出しは被積分関数を評価しない。

三角形と四面体のメッシュは `scioxide_spatial::SimplexMesh`（`TriangleMesh`、`TetrahedronMesh`）で表す。
メッシュは構築のときにすべての要素が正の向きであることを厳密な述語で検査する（[単体メッシュの向きと境界タグ](oxref:spatial-simplex-mesh-orientation-tags)）。
`rule.integrate_mesh_cell_into(f, &mesh, cell, &mut out, &mut workspace, scope)` と `rule.map_mesh_cell_into(&mesh, cell, ..)` は、メッシュを所有せずに要素 `cell` の頂点を読み、頂点を渡した場合と同じ計算をする。
メッシュの次元が則の次元と違うか、2 と 3 以外ならエラーになる。

### 選択肢と作業領域

`GeometricOptions` は単体と球面の則に共通の設定で、既定は節点数の上限 $10^6$、厳密な向きの判定の項数 4096、評価回数の上限なし、逐次実行である。
節点数が上限を超える則は準備のときに拒まれ、評価回数の上限より節点の多い則の呼び出しは評価の前に `ConvergenceFailure` で失敗する。
`rule.workspace(components)` が返す `GeometricWorkspace` は、写した節点と重み、関数値を $O(n(d+c)+d^2)$ のメモリに持ち、単体では厳密な判定のメモリと $d\times d$ の LU 分解も持つ。
`node_capacity()` 以下の節点数で、次元と成分数が同じ則なら同じ作業領域を使える。
`mapped_points()` と `mapped_weights()` は最後に成功した写像の節点と重みを返し、積分の呼び出しも写像を行うので、その節点も読める。

## 三角形メッシュ上の板の質量

一辺 1 m の正方形の板を $n\times n$ の正方形に分け、それぞれを 2 個の正の向きの三角形に分けた `TriangleMesh` を作る。
面密度 $\rho(x,y) = 1/(1+x+y)$ kg/m² の板の質量

$$
M = \int_0^1\!\!\int_0^1 \frac{dx\,dy}{1+x+y} = 3\ln 3 - 4\ln 2 \ \text{kg}
$$

を、要素ごとの `integrate_mesh_cell_into` の和で求める。
次の定義のブロックは、二つのセルが使う面密度 `plate_density` と、正方形の板の質量の厳密値 `exact_plate_mass` を置く。
厳密値は SciOxide の `ln` で求める。

```rust
//| id: integrate-plate-density
//| kind: definitions
//| title: 板の面密度 1/(1 + x + y) と正方形の板の質量の厳密値
//| crates: [scioxide-core]
use scioxide_core::RealScalar;

// 面密度 ρ(x, y) = 1/(1 + x + y) [kg/m²]（x は物理座標 (x, y) [m]）。
pub(crate) fn plate_density(x: &[f64]) -> f64 {
    1.0 / (1.0 + x[0] + x[1])
}

// 一辺 1 m の正方形の板の質量 3 ln 3 − 4 ln 2 [kg]。
pub(crate) fn exact_plate_mass() -> f64 {
    3.0 * RealScalar::ln(3.0) - 4.0 * RealScalar::ln(2.0)
}
```

最初のセルは正の重みの則（要求次数 0〜7）と Grundmann–Möller 則（$s = 0, \dots, 5$、次数 1〜11）について、1 要素の節点数、重みの絶対値の和と体積の比 $\Lambda/(1/2)$、質量の誤差を表とグラフに示す。

```rust
//| id: integrate-simplex-mesh-mass
//| ref: integrate-simplex-mesh-mass
//| title: メッシュの細かさを動かして単体則の次数と質量の誤差を比べる
//| run: reactive
//| uses: [integrate-plate-density]
//| crates: [scioxide-core, scioxide-integrate, scioxide-spatial]
//| inputs:
//|   cells_per_side: {"type":"range","label":"1 辺の分割数 n [-]","description":"正方形を n×n に分け、要素数は 2n²。","min":1,"max":8,"step":1,"value":2}
//| cases:
//|   - {"id":"fine-mesh","label":"n = 8","description":"要素を細かくすると、同じ次数でも誤差が要素の大きさのべきで下がる。","inputs":{"cells_per_side":8}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"rules","path":"/rows/7/3","equals":15}
//|       - {"artifact":"rules","path":"/rows/7/5","range":{"min":1e-9,"max":1e-7}}
//|       - {"artifact":"rules","path":"/rows/13/4","range":{"min":30,"max":50}}
//|   - case: fine-mesh
//|     expect:
//|       - {"artifact":"rules","path":"/rows/7/5","range":{"min":1e-14,"max":1e-11}}
use scioxide_core::ExecutionContext;
use scioxide_integrate::{GeometricOptions, SimplexRule};
use scioxide_spatial::{Point, TriangleMesh};

let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let n = cells_per_side.round() as usize;
let h = 1.0 / n as f64;
// 格子点 (i, j) の番号は j (n + 1) + i。各正方形を反時計回りの 2 個の三角形に分ける。
let mut points = Vec::new();
for j in 0..=n {
    for i in 0..=n {
        points.push(Point::new([i as f64 * h, j as f64 * h]).map_err(|e| e.to_string())?);
    }
}
let id = |i: usize, j: usize| j * (n + 1) + i;
let mut cells = Vec::new();
for j in 0..n {
    for i in 0..n {
        cells.push([id(i, j), id(i + 1, j), id(i + 1, j + 1)]);
        cells.push([id(i, j), id(i + 1, j + 1), id(i, j + 1)]);
    }
}
let mesh = TriangleMesh::new(points, cells).map_err(|e| e.to_string())?;
let density = |x: &[f64]| Ok(plate_density(x));
let (exact, context) = (exact_plate_mass(), ExecutionContext::sequential());
let options = GeometricOptions::default();
let positive = (0..=7).map(|p| ("正の重み", p, SimplexRule::positive(2, p, options)));
let signed = (0..=5).map(|s| ("Grundmann–Möller", s, SimplexRule::new(2, s, options)));
let (mut rows, mut curves) = (Vec::new(), [Vec::new(), Vec::new()]);
for (family, request, rule) in positive.chain(signed) {
    let rule: SimplexRule<f64> = rule.map_err(|e| e.to_string())?;
    let mut workspace = rule.workspace(1).map_err(|e| e.to_string())?;
    let (mut mass, mut evaluations) = (0.0_f64, 0);
    for cell in 0..mesh.cell_count() {
        let mut part = 0.0_f64;
        let report = rule
            .integrate_mesh_cell_into(&density, &mesh, cell, &mut part, &mut workspace, context)
            .map_err(|e| e.to_string())?;
        mass += part;
        evaluations += report.evaluations();
    }
    // Λ/体積: 重みの絶対値の和を基準三角形の面積 1/2 で割る（正の重みなら 1）。
    let lambda = rule.weights().iter().map(|w| w.abs()).sum::<f64>() / rule.reference_measure();
    let error = (mass - exact).abs();
    let curve = &mut curves[usize::from(family != "正の重み")];
    curve.extend(Some([evaluations as f64, error]).filter(|_| error > 0.0));
    let (degree, nodes) = (rule.exactness_degree(), rule.node_count());
    rows.push((family, request, degree, nodes, lambda, error));
}
let [positive, signed] = curves;
let symbols = serde_json::json!({ "showSymbol": true });
let series = vec![
    serde_json::json!({ "name": "正の重みの則", "points": positive, "style": symbols }),
    serde_json::json!({ "name": "Grundmann–Möller 則", "points": signed, "style": symbols }),
];
emit_line_chart!(
    &series,
    options = &serde_json::json!({
        "xLabel": "被積分関数の評価回数 [回]",
        "yLabel": "質量の誤差 [kg]",
        "xType": "log",
        "yType": "log"
    })
);
let columns = serde_json::json!([
    { "key": "0", "label": "則" },
    { "key": "1", "label": "要求次数または指数 s", "type": "integer" },
    { "key": "2", "label": "厳密な次数", "type": "integer" },
    { "key": "3", "label": "1 要素の節点数 [点]", "type": "integer" },
    { "key": "4", "label": "Λ/体積 [-]", "type": "number", "format": { "significantDigits": 4 } },
    { "key": "5", "label": "質量の誤差 [kg]", "type": "number", "format": sci2 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "rules" })
);
```

既定値（$n = 2$、8 要素）では、次数 7 の正の重みの則（15 点、120 回）の誤差は $2.7\times10^{-8}$ kg、同じ次数 7 の Grundmann–Möller 則（20 点、160 回）は $1.1\times10^{-7}$ kg で、同じ次数なら正の重みの則のほうが少ない評価で正確である。
Grundmann–Möller 則の $\Lambda/\text{体積}$ は $s = 1$ で 2.1、$s = 5$（次数 11）で 38 と急に大きくなり、関数値の丸め誤差がその倍率で拡大されうる。
正の重みの則の要求次数 0 と 1、3 と 4 は同じ則になり、表の厳密な次数と節点数で確かめられる。
$n = 8$（128 要素）にすると、次数 7 の正の重みの則の誤差は $7\times10^{-13}$ kg に下がる。
要素の大きさ $h$ を 1/4 にして誤差が約 $4\times10^4$ 分の 1 になったことは、次数 $p$ の則の誤差の目安 $O(h^{p+1}) = O(h^8)$（$4^8 \approx 6.6\times10^4$）に近い。

2 つ目のセルは 1 個の三角形（頂点 $(0,0)$、$(0.5,0)$、$(0.5,0.5)$ m、面積 $1/8$ m²）を、反時計回りと時計回りの頂点の順序で `map_nodes_into` に渡す。
写した節点で面密度を自分で評価し、`integrate_values_into` で質量を求め、測度、向き、写した重みの和と比べる。
質量の参照値はこの三角形での厳密な積分 $\ln 2 - \tfrac32\ln\tfrac32$ kg である。

```rust
//| id: integrate-simplex-orientation
//| ref: integrate-simplex-orientation
//| title: 頂点の順序を入れ替えて単体の向き、測度、写した重みと質量を比べる
//| run: reactive
//| uses: [integrate-plate-density]
//| crates: [scioxide-core, scioxide-integrate]
//| inputs:
//|   degree: {"type":"range","label":"正の重みの則の要求次数 [-]","description":"写す則の要求次数。節点数と質量の精度が変わる。","min":0,"max":7,"step":1,"value":4}
//| cases:
//|   - {"id":"degree-zero","label":"次数 0","description":"重心 1 点の則でも、測度と重みの和は体積に等しい。","inputs":{"degree":0}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"orientation","path":"/rows/0/1","equals":"Positive"}
//|       - {"artifact":"orientation","path":"/rows/1/1","equals":"Negative"}
//|       - {"artifact":"orientation","path":"/rows/1/2","approx":{"value":0.125,"rtol":1e-14}}
//|       - {"artifact":"orientation","path":"/rows/1/3","approx":{"value":0.125,"rtol":1e-14}}
//|       - {"artifact":"orientation","path":"/rows/1/6","equals":0}
//|   - case: degree-zero
//|     expect:
//|       - {"artifact":"orientation","path":"/rows/1/3","approx":{"value":0.125,"rtol":1e-14}}
use scioxide_core::{ExecutionContext, RealScalar};
use scioxide_integrate::{GeometricOptions, SimplexRule};

let sig6 = serde_json::json!({ "significantDigits": 6 });
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let degree = degree.round() as usize;
let rule =
    SimplexRule::positive(2, degree, GeometricOptions::default()).map_err(|e| e.to_string())?;
let mut workspace = rule.workspace(1).map_err(|e| e.to_string())?;
// 同じ三角形（面積 1/8 m²）を反時計回りと時計回りの頂点の順序で渡す。
let (a, b, c): (&[f64], &[f64], &[f64]) = (&[0.0, 0.0], &[0.5, 0.0], &[0.5, 0.5]);
// 参照値: この三角形での ∫ρ dA = ln 2 − (3/2) ln (3/2) [kg]（SciOxide の ln）。
let exact = RealScalar::ln(2.0) - 1.5 * RealScalar::ln(1.5);
let mut rows = Vec::new();
for (name, vertices) in [("反時計回り", [a, b, c]), ("時計回り", [a, c, b])] {
    let mut nodes = vec![0.0; 2 * rule.node_count()];
    let mut weights = vec![0.0; rule.node_count()];
    let measure = rule
        .map_nodes_into(&vertices, &mut nodes, &mut weights, &mut workspace)
        .map_err(|e| e.to_string())?;
    let mapped_sum: f64 = workspace.mapped_weights().ok_or("写像がない")?.iter().sum();
    // 節点の値を自分で計算し、評価なしで積分する。
    let values: Vec<f64> = nodes.chunks(2).map(plate_density).collect();
    let mut mass = 0.0_f64;
    let context = ExecutionContext::sequential();
    let report = rule
        .integrate_values_into(&vertices, &values, &mut mass, &mut workspace, context)
        .map_err(|e| e.to_string())?;
    let orientation = format!("{:?}", measure.orientation);
    let (error, evaluations) = ((mass - exact).abs(), report.evaluations());
    rows.push((
        name,
        orientation,
        measure.measure,
        mapped_sum,
        mass,
        error,
        evaluations,
    ));
}
let columns = serde_json::json!([
    { "key": "0", "label": "頂点の順序" },
    { "key": "1", "label": "向き" },
    { "key": "2", "label": "測度 [m²]", "type": "number", "format": sig6 },
    { "key": "3", "label": "写した重みの和 [m²]", "type": "number", "format": sig6 },
    { "key": "4", "label": "質量 [kg]", "type": "number", "format": { "significantDigits": 10 } },
    { "key": "5", "label": "厳密値との差 [kg]", "type": "number", "format": sci2 },
    { "key": "6", "label": "被積分関数の評価回数 [回]", "type": "integer" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "orientation" })
);
```

既定値（要求次数 4、6 点の則）では、頂点の順序を時計回りにすると向きは `Negative` になるが、測度と写した重みの和はどちらも $0.125$ m²、質量は $0.0849491$ kg で変わらない。
厳密値との差は $4.3\times10^{-7}$ kg で、要求次数 7 では $1.2\times10^{-8}$ kg、次数 0（重心 1 点）では $1.6\times10^{-3}$ kg になる。
`integrate_values_into` は被積分関数を評価しないので、レポートの評価回数は 0 である。

## 球面上の求積則

単位球面 $S^2$ 上の積分では、次数 $p$ 以下の球面調和関数 $Y_\ell^m$（$\ell\le p$）をすべて厳密に積分する則を次数 $p$ の則と呼ぶ。
次数 $p$ 以下の球面調和関数は $(p+1)^2$ 次元の空間をなすので、どんな則にもおよそ $(p+1)^2/3$ 個以上の節点が要ると見積もられる（各節点が位置の 2 自由度と重みの 1 自由度を持つため）。

`SphereProductRule::new(polar_nodes, azimuth_nodes, options)` は、$\cos\theta$ 方向の $n_\theta$ 点の Gauss–Legendre 則と、方位角の $n_\varphi$ 点の等間隔則（台形則）の積で、節点と重みは

$$
\boldsymbol u_{jk} = (\sin\theta_j\cos\varphi_k,\ \sin\theta_j\sin\varphi_k,\ \cos\theta_j), \qquad w_{jk} = \frac{2\pi a_j}{n_\varphi}
$$

である（$\cos\theta_j$、$a_j$ は $[-1,1]$ の Gauss–Legendre の節点と重み、$\varphi_k = 2\pi k/n_\varphi$）。
厳密な次数は $\min(2n_\theta - 1,\ n_\varphi - 1)$ で、次数 $p$ には $n_\theta = (p+1)/2$、$n_\varphi = p+1$ の約 $(p+1)^2/2$ 点を使う。
節点は極の近くに密集する。

`LebedevRule::new(degree, options)` は、正八面体の 48 個の回転・鏡映で不変な Lebedev–Laikov の表の則で、次数 3 から 131 までの 32 通り（3〜31 の奇数と、35〜131 の 6 おき、`LebedevRule::supported_degrees()`）を持つ。
節点数は約 $(p+1)^2/3$ で、下限の見積もりに近く、たとえば次数 25 で 230 点、41 で 590 点、131 で 5810 点である。
節点は球面上にほぼ一様に散らばり、特別な方向を持たない。

どちらの則も重みの和は $4\pi$ で、誤差推定はなく、終了状態は `FixedRuleCompleted` である。
`rule.integrate(f, &center, radius)` は中心 $\boldsymbol c$、半径 $r$ の球面へ写して $\oint f\,dS \approx r^2\sum_j w_j f(\boldsymbol c + r\boldsymbol u_j)$ を計算する。
`integrate_into` は `GeometricWorkspace` を使って確保なしで実行し、`map_nodes_into(&center, radius, &mut points, &mut weights, &mut workspace)` は節点と重み $r^2 w_j$ を書いて面積 $4\pi r^2$ を返す。
中心か半径が NaN か無限大なら `NonFinite`、$r \le 0$ なら `InvalidInput`、節点、面積、重みが桁あふれするか 0 でない面積や重みが 0 にアンダーフローすると `NumericalInstability` のエラーになる。
`nodes()` と `weights()` は単位球面上の節点（1 節点 3 座標）と重みを返す。

不規則な観測から場を近似して全球平均を求める例は、[球面の気温](../../../scioxide-interp/examples/spherical-temperature/)にあり、補間の誤差と求積の誤差を分けて比べられる。

## 球面の求積則の節点効率

方向 $\boldsymbol n$ に集中した分布 $e^{\kappa\,\boldsymbol n\cdot\boldsymbol x}$（正規化していない von Mises–Fisher 分布の密度）の球面積分

$$
\int_{S^2}e^{\kappa\,\boldsymbol n\cdot\boldsymbol x}\,d\Omega = \frac{4\pi\sinh\kappa}{\kappa}
$$

を、同じ次数 $p$ の Lebedev 則と積則で計算する。
$\boldsymbol n$ を座標軸から傾け、積則が方位の対称性を利用できないようにする。
集中度 $\kappa$ を上げるほど、高い次数の球面調和成分が必要になる。
参照値は f64 の `sinh` による。
グラフは節点数に対する相対誤差、表は次数ごとの節点数と相対誤差を示す。

```rust
//| id: integrate-sphere-rules-efficiency
//| ref: integrate-sphere-rules-efficiency
//| title: 集中度を動かして Lebedev 則と球面の積則の誤差を節点数で比べる
//| run: reactive
//| crates: [scioxide-core, scioxide-integrate]
//| inputs:
//|   concentration: {"type":"range","label":"集中度 κ [-]","description":"被積分関数 exp(κ n·x) の方向の偏り。","min":1,"max":30,"step":1,"value":8}
//| cases:
//|   - {"id":"sharp","label":"κ = 30","description":"集中した分布では、相対誤差 10⁻¹² に達する次数が 41 まで上がる。","inputs":{"concentration":30}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"rules","path":"/rows/11/1","equals":230}
//|       - {"artifact":"rules","path":"/rows/11/3","equals":338}
//|       - {"artifact":"rules","path":"/rows/11/2","range":{"min":0,"max":1e-13}}
//|   - case: sharp
//|     expect:
//|       - {"artifact":"rules","path":"/rows/16/2","range":{"min":0,"max":1e-12}}
//|       - {"artifact":"rules","path":"/rows/11/2","range":{"min":1e-6,"max":1}}
use scioxide_core::{Budget, RealScalar};
use scioxide_integrate::{GeometricOptions, LebedevRule, SphereProductRule};

let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
// 単位球面上の ∫ exp(κ n·x) dΩ = 4π sinh κ / κ（向き n によらない）。n は軸から傾けて対称性を使わせない。
let kappa = concentration;
let (polar, azimuth) = (0.6_f64, 0.3_f64);
let n = [
    RealScalar::sin(polar) * RealScalar::cos(azimuth),
    RealScalar::sin(polar) * RealScalar::sin(azimuth),
    RealScalar::cos(polar),
];
let exact = 4.0 * std::f64::consts::PI * kappa.sinh() / kappa; // 参照値（f64 の sinh）
let f = |p: &[f64]| {
    Ok(RealScalar::exp(
        kappa * (n[0] * p[0] + n[1] * p[1] + n[2] * p[2]),
    ))
};
let max_nodes = Budget::try_from(6000).map_err(|e| e.to_string())?;
let options = GeometricOptions::default().with_max_nodes(max_nodes);
let (mut lebedev_curve, mut product_curve, mut rows) = (Vec::new(), Vec::new(), Vec::new());
for &degree in LebedevRule::<f64>::supported_degrees()
    .iter()
    .filter(|&&p| p <= 59)
{
    let lebedev = LebedevRule::<f64>::new(degree, options).map_err(|e| e.to_string())?;
    // 同じ次数 p を持つ積則: 極方向 (p + 1)/2 点、方位方向 p + 1 点。
    let product = SphereProductRule::<f64>::new((degree + 1) / 2, degree + 1, options)
        .map_err(|e| e.to_string())?;
    let (value, _) = lebedev
        .integrate(&f, &[0.0; 3], 1.0)
        .map_err(|e| e.to_string())?;
    let (product_value, _) = product
        .integrate(&f, &[0.0; 3], 1.0)
        .map_err(|e| e.to_string())?;
    let error = (value - exact).abs() / exact;
    let product_error = (product_value - exact).abs() / exact;
    // 両対数のグラフには正の誤差だけを描く（0 になった点は表で読める）。
    let (lebedev_nodes, product_nodes) = (lebedev.node_count(), product.node_count());
    lebedev_curve.extend(Some([lebedev_nodes as f64, error]).filter(|_| error > 0.0));
    product_curve
        .extend(Some([product_nodes as f64, product_error]).filter(|_| product_error > 0.0));
    rows.push((degree, lebedev_nodes, error, product_nodes, product_error));
}
let symbols = serde_json::json!({ "showSymbol": true });
let product_name = "Gauss–Legendre × 等間隔方位の積則";
let series = vec![
    serde_json::json!({ "name": "Lebedev 則", "points": lebedev_curve, "style": symbols }),
    serde_json::json!({ "name": product_name, "points": product_curve, "style": symbols }),
];
emit_line_chart!(
    &series,
    options = &serde_json::json!({
        "xLabel": "節点数 [点]",
        "yLabel": "相対誤差 [-]",
        "xType": "log",
        "yType": "log"
    })
);
let columns = serde_json::json!([
    { "key": "0", "label": "球面調和の次数 p", "type": "integer" },
    { "key": "1", "label": "Lebedev の節点数 [点]", "type": "integer" },
    { "key": "2", "label": "Lebedev の相対誤差 [-]", "type": "number", "format": sci2 },
    { "key": "3", "label": "積則の節点数 [点]", "type": "integer" },
    { "key": "4", "label": "積則の相対誤差 [-]", "type": "number", "format": sci2 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "rules" })
);
```

既定値 $\kappa=8$ では、次数 25 で Lebedev 則が 230 点・相対誤差 $6.0\times10^{-15}$、積則が 338 点・$2.7\times10^{-14}$ に達した。
同じ次数での誤差は同程度で、節点数は Lebedev 則が積則の約 2/3 である。
$\kappa=30$ では相対誤差 $10^{-12}$ を下回るのに次数 41（Lebedev 590 点・$8.0\times10^{-14}$、積則 882 点・$3.0\times10^{-12}$）が要る。
丸めの水準に達した次数では誤差がちょうど 0 になることがあり、その点は両対数のグラフから除き、表に 0 として残す。
固定則は誤差推定を返しないので、次数を上げた二つの結果の差や既知の積分で確かめる。

次のセルは、選んだ次数の二つの則を `map_nodes_into` で中心が原点、半径 1 m の球面へ写し、節点を 3 次元の図に描く。
表は則ごとの節点数、写した重みの和、`map_nodes_into` が返す面積 $4\pi r^2$ を示す。
凡例で則を切り替え、極に集まる積則の節点と、一様に散らばる Lebedev 則の節点を見比べられる。

```rust
//| id: integrate-sphere-nodes-scene
//| ref: integrate-sphere-nodes-scene
//| title: 次数を選んで Lebedev 則と球面の積則の節点を球面に描く
//| run: reactive
//| crates: [scioxide-core, scioxide-integrate]
//| inputs:
//|   draw_degree: {"type":"select","label":"図に描く次数 p","description":"3 次元の図に節点を描く二つの則の次数。","options":["11","17","25"],"value":"17"}
//| cases:
//|   - {"id":"degree-25","label":"p = 25 を描く","description":"Lebedev 則 230 点と積則 338 点の配置を比べる。","inputs":{"draw_degree":"25"}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"sphere-nodes","path":"/points/0/position/2","range":{"min":-1,"max":1}}
//|       - {"artifact":"mapped","path":"/rows/0/1","equals":110}
//|       - {"artifact":"mapped","path":"/rows/0/2","approx":{"value":12.566370614359172,"rtol":1e-13}}
//|       - {"artifact":"mapped","path":"/rows/1/3","approx":{"value":12.566370614359172,"rtol":1e-15}}
//|   - case: degree-25
//|     expect:
//|       - {"artifact":"sphere-nodes","path":"/points/229/group","equals":"lebedev"}
//|       - {"artifact":"mapped","path":"/rows/1/1","equals":338}
use scioxide_integrate::{GeometricOptions, LebedevRule, SphereProductRule};

let sig15 = serde_json::json!({ "significantDigits": 15 });
let degree: usize = draw_degree.parse().map_err(|_| "図の次数が整数でない")?;
let options = GeometricOptions::default();
let lebedev = LebedevRule::<f64>::new(degree, options).map_err(|e| e.to_string())?;
let product = SphereProductRule::<f64>::new((degree + 1) / 2, degree + 1, options)
    .map_err(|e| e.to_string())?;
let (center, radius) = ([0.0_f64; 3], 1.0_f64);
// 二つの則を同じ球面へ写す。写した点は c + r uⱼ、重みは r² wⱼ で、面積 4π r² が返る。
let mut lebedev_ws = lebedev.workspace(1).map_err(|e| e.to_string())?;
let mut lebedev_nodes = vec![0.0; 3 * lebedev.node_count()];
let mut lebedev_weights = vec![0.0; lebedev.node_count()];
let lebedev_area = lebedev
    .map_nodes_into(
        &center,
        radius,
        &mut lebedev_nodes,
        &mut lebedev_weights,
        &mut lebedev_ws,
    )
    .map_err(|e| e.to_string())?;
let mut product_ws = product.workspace(1).map_err(|e| e.to_string())?;
let mut product_nodes = vec![0.0; 3 * product.node_count()];
let mut product_weights = vec![0.0; product.node_count()];
let product_area = product
    .map_nodes_into(
        &center,
        radius,
        &mut product_nodes,
        &mut product_weights,
        &mut product_ws,
    )
    .map_err(|e| e.to_string())?;
let mapped = [
    (
        "lebedev",
        "Lebedev 則",
        lebedev_nodes,
        lebedev_weights,
        lebedev_area,
    ),
    (
        "product",
        "積則",
        product_nodes,
        product_weights,
        product_area,
    ),
];
let (mut points, mut rows) = (Vec::new(), Vec::new());
for (group, label, nodes, weights, area) in mapped {
    for (i, x) in nodes.chunks(3).enumerate() {
        let id = format!("{group}-{i}");
        points.push(serde_json::json!({ "id": id, "position": x, "group": group }));
    }
    rows.push((label, weights.len(), weights.iter().sum::<f64>(), area));
}
let columns = serde_json::json!([
    { "key": "0", "label": "則" },
    { "key": "1", "label": "節点数 [点]", "type": "integer" },
    { "key": "2", "label": "写した重みの和 [m²]", "type": "number", "format": sig15 },
    { "key": "3", "label": "返された面積 [m²]", "type": "number", "format": sig15 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "mapped" })
);
let groups = [
    serde_json::json!({ "id": "lebedev", "label": "Lebedev 則" }),
    serde_json::json!({ "id": "product", "label": "積則" }),
];
let axis = |label: &str| serde_json::json!({ "label": label, "unit": "m" });
let axes = serde_json::json!({ "x": axis("x"), "y": axis("y"), "z": axis("z") });
let scene = serde_json::json!({ "points": points, "groups": groups, "axes": axes });
emit_scene3d!(
    scene,
    metadata = serde_json::json!({ "id": "sphere-nodes", "title": "半径 1 m の球面上の節点" })
);
```

3 次元の図では、積則の節点が極の近くの緯線に密集し、Lebedev 則の節点が球面全体にほぼ一様に広がることを確かめられる。
2 つの節点を選ぶと距離が表示され、Lebedev 則の隣り合う節点の間隔がほぼそろっていることも読める。

## 誤差の確かめ方

単体と球面の固定則は誤差推定を持たず、終了状態は `FixedRuleCompleted` である（平らな単体は `DegenerateDomain`）。
誤差は次数を上げた二つの結果の差、要素を細分した結果との差、既知の積分で確かめる。
次数を上げても差が減らないときは、被積分関数が要素の中で滑らかでないか、重みの絶対値の和が大きく丸めの影響が大きいことを疑う。

## まとめ

三角形・四面体は `SimplexRule` で積分し、正の重みの則は重みの絶対値の和が体積に等しく丸めに強い。
Grundmann–Möller 則は任意の次元と奇数の次数を持つが、指数 $s$ とともに重みの絶対値の和が大きくなるので、高い次数より要素の細分を選ぶ。
積分は $|\det J|$ を使うので頂点の順序によらず、向きは `SimplexMeasure::orientation` として別に返され、`SimplexMesh` の要素は `integrate_mesh_cell_into` で直接積分できる。
球面は `LebedevRule` か `SphereProductRule` で、同じ次数なら Lebedev 則の節点は積則の約 2/3 で、節点は球面全体にほぼ一様に散らばる。
どの固定則も誤差推定を持たないので、次数や要素を変えた比較で確かめる。
