[テンソル積則と Genz–Malik 適応 cubature](../multidimensional-and-monte-carlo/)ではテンソル積則の評価回数が $n^d$ で増えることを、[Monte Carlo 積分の推定量と統計](../monte-carlo-integration/)では Monte Carlo 法の誤差が次元によらず $N^{-1/2}$ でしか減らないことを見た。
被積分関数が滑らかで、変数どうしの相互作用が弱い場合には、その中間の方法が使える。
このページは決定論的に節点を選ぶ疎格子（sparse grid）と、低食い違い点列を乱択化した準 Monte Carlo（quasi-Monte Carlo、QMC）を扱う。
疎格子は節点の組み合わせ方で次元の呪いを和らげ、乱択 QMC は点の並べ方で分散を下げつつ、統計的な標準誤差を残す。

## 入れ子の Clenshaw–Curtis 則

疎格子の材料は段 $l = 0, 1, 2, \dots$ の 1 次元の則の列 $Q_0, Q_1, \dots$ である。
`SparseGridPlan` は $Q_0$ を中点 1 点の則、$Q_l$（$l\ge1$）を $2^l+1$ 点の [Clenshaw–Curtis 則](oxref:integrate-clenshaw-curtis)とする。
Clenshaw–Curtis 則の節点は $\cos(\pi i/2^l)$（$i = 0, \dots, 2^l$）を区間へ写したもので、段 $l$ の節点はすべて段 $l+1$ の節点に含まれる。
中点も段 1 の節点に含まれるので、列全体が入れ子になる。
入れ子なら、段を上げるときに前の段の関数値をすべて再利用できる。
段 $l \ge 1$ の則は次数 $2^l+1$ 以下の多項式を厳密に積分し、中点則は次数 1 以下を厳密に積分する。

## Smolyak の差分則

差分則 $\Delta_l = Q_l - Q_{l-1}$（$Q_{-1}=0$）を使うと、段 $L$ の 1 次元則は望遠鏡和 $Q_L = \sum_{l=0}^{L}\Delta_l$ と書ける。
$d$ 次元では多重添字 $\boldsymbol k=(k_1,\dots,k_d)$ ごとに差分則のテンソル積をとった余剰（surplus）

$$
\Delta_{\boldsymbol k} f = (\Delta_{k_1}\otimes\cdots\otimes\Delta_{k_d})f
$$

を定め、添字の集合 $\mathcal I$ について

$$
A_{\mathcal I}[f] = \sum_{\boldsymbol k\in\mathcal I}\Delta_{\boldsymbol k} f
$$

を推定値とする。
$\mathcal I$ をすべての軸で段 $L$ 以下の添字（直方体の形）にとると、$A_{\mathcal I}$ は段 $L$ のテンソル積則に一致する。
$\mathcal I = \{\boldsymbol k : |\boldsymbol k|_1 \le q\}$（単体の形）にとったものが古典的な Smolyak 則である。
$\Delta_{\boldsymbol k} f$ は各軸の段を一つずつ上げたときの増分の積で、混合偏導関数が有界な滑らかな関数では、$|\boldsymbol k|_1$ が大きいほど急に小さくなる。
そのため段の和が大きい添字を省いても誤差は小さい。

節点数 $N$ に対し、各変数について $r$ 階までの混合偏導関数が有界な関数では、古典的な Smolyak 則の誤差は $O(N^{-r}(\log N)^{(d-1)(r+1)})$ 程度である。
テンソル積則の $O(N^{-r/d})$ と比べ、次元の影響は対数の因子に下がる。
添字の集合は下に閉じている（$\boldsymbol k \in \mathcal I$ で $k_j > 0$ なら $\boldsymbol k - \boldsymbol e_j \in \mathcal I$）必要があり、このとき望遠鏡和が正しく打ち消し合う。

## 次元適応の細分

変数ごとの重要度が違うと、単体の形をした添字の集合は重要でない軸にも節点を使う。
`SparseGridPlan` は Gerstner–Griebel の次元適応の方法で、$\mathcal I$ を被積分関数に合わせて育てる。

1. 添字を受理済み（old）と候補（active）に分ける。
   初めは $\boldsymbol 0$ だけを評価する。
2. 候補のうち、余剰の大きさを許容誤差で正規化した値が最大の添字を受理する。
3. 受理した添字の前方にある近傍 $\boldsymbol k + \boldsymbol e_j$ のうち、後方の近傍がすべて受理済みのもの（集合が下に閉じたままになるもの）を候補に加え、その余剰を計算する。
4. 推定値は受理済みの添字の余剰の和 $\sum_{\boldsymbol k \in \text{old}} \Delta_{\boldsymbol k} f$ とする。

新しい候補の節点のうち、まだ評価していない節点だけを評価する。
一つの呼び出しの中では同じ節点を二度評価しない。
新しい節点は一つのまとまりとして評価回数の上限に照らして許可され、拒まれた候補は評価せずに取り消されて、その方向は未探索のまま残る。

### 誤差推定と終了

候補と、前方の近傍がまだ解決していない受理済みの添字について、余剰の大きさを足して 4 倍した値

$$
\eta = 4 \sum_{\boldsymbol k \in \text{active} \,\cup\, \text{未解決の old}} |\Delta_{\boldsymbol k} f|
$$

を誤差推定とする。
$\eta$ が許容誤差以下で、かつ各軸の段 1 の添字 $\boldsymbol e_j$ がすべて受理済みのとき、`HeuristicToleranceReached` で止まる。
段 1 の受理を求めるのは、対称性などで偶然小さい余剰が未探索の方向を隠すのを防ぐためである。
未探索の添字の余剰が小さい保証はないので、この推定は `ErrorReliability::Heuristic` として示され、誤差の上界ではない。
Gauss–Kronrod 則などと違い、余剰による推定は丸め誤差の下限を別に含まない。
`is_success()` は真になるが、許容誤差を変えた比較や既知の値で確かめる。

`SparseGridOptions` は、許容誤差、1 軸あたりの最大の段（52 以下）、受理済みと候補を合わせた添字の数の上限、異なる節点での評価回数の上限、実行方針を持つ。
既定は絶対・相対とも $\sqrt\varepsilon$ の二乗平均平方根ノルムの許容誤差、最大の段 4、添字 64 個、評価 4096 回、逐次実行で、`SparseGridOptions::default()` から `with_tolerance`、`with_max_level`、`with_max_indices`、`with_max_evaluations`、`with_execution_policy` で変える。
最大の段の 1 次元則の節点数 $2^{L}+1$ が評価回数の上限を超える設定は、準備のときに `InvalidInput` で拒まれる。
最初の推定値の後に評価回数の上限に達すると `BudgetLimit(Evaluation)`、添字の上限に達するか最大の段の下で候補が尽きると `RefinementLimit` で、どちらもその時点の推定値と、同じ方法で計算し直した誤差推定を返す。
最初の推定値の前に止まると `ConvergenceFailure` か `ExecutionStopped` のエラーになる。
直方体の軸が狭く、最初の中点が軸の内部に表せないと `NumericalInstability`（`Breakdown`）のエラーになる。
その後の細分で写した節点が丸めで重なると、最後に完成した推定値と誤差推定を `GeometryFailure` の終了状態とともに返す。

### Plan と作業領域

`SparseGridPlan::new(d, options)` は最大の段までの差分則を準備し、任意の直方体と被積分関数に使える。
`plan.workspace(components)` が返す `SparseGridWorkspace` は、添字の集合と評価した節点の値を $O(I(d+c)+E(d+c))$ のメモリに持つ（$I$ は添字の上限、$E$ は評価回数の上限）。
上限が同じかそれ以下の Plan なら同じ作業領域を使え、`plan.integrate_into(f, &bounds, &mut out, &mut workspace, scope)` は確保を行わない。
次元が違うか、添字や評価回数の容量が Plan の上限に足りない作業領域は `InvalidInput`（`Inconsistent`）で拒まれる。
節点の値は呼び出しの中だけで再利用し、次の呼び出しには持ち越さない。
`plan.integrate(f, &bounds)` は作業領域を内部で作る簡易形である。

作業領域は直前の呼び出しの診断を返す。
`cached_nodes()` は評価した異なる節点の数、`component_errors()` は成分ごとの誤差推定である。
`directional_indicators()` は軸 $j$ ごとに、誤差推定に含まれる添字のうち $k_j > 0$ のものについて $4\max_c|\Delta_{\boldsymbol k} f|$ を足した値で、誤差推定がどの軸の方向に残っているかの目安になる。
ある軸の値が 0 でも、その軸に沿って省いた誤差が 0 とは限らない。

## 乱択準 Monte Carlo

準 Monte Carlo 法は乱数の代わりに単位立方体を一様に埋める低食い違い点列（Sobol 点列など）で標本平均をとる。
Koksma–Hlawka の不等式 $|I-Q_N|\le V_{\mathrm{HK}}(f)\,D_N^*$ により、誤差は被積分関数の変動 $V_{\mathrm{HK}}$ と点のスター・ディスクレパンシー $D_N^*=O((\log N)^d/N)$ で抑えられる。
しかし、どちらも実用上は計算できないので、この不等式から誤差を見積もることはできない。

そこで、点列を独立に乱択化した $R$ 個の複製を使う。
`scioxide_random::QmcReplicatePlan::new(&QmcPlan::sobol(d)?, &root, QmcReplicateOptions)` は、Sobol 点列に線形行列スクランブルとデジタルシフトを施した $R$ 個の複製を、それぞれ独立な乱数系列から作る（$R \ge 2$、点数は 2 のべき）。
乱択化した点は 1 点ずつ見ると $[0,1)^d$ 上の一様分布に従うので、各複製の推定値 $\hat I_r$ は不偏である。
点の間の構造は保たれるので、滑らかな被積分関数では $\hat I_r$ の分散が通常の Monte Carlo 法の $\sigma^2/N$ より速く減る。
最終の推定値は複製の平均 $\bar I$ で、不確かさは複製のばらつきから

$$
\widehat{\operatorname{SE}} = \frac{s_R}{\sqrt R},\qquad s_R^2 = \frac{1}{R-1}\sum_{r=1}^R(\hat I_r-\bar I)^2
$$

で求め、自由度 $R-1$ の Student-t 区間を返す。
1 本の点列の中の点ごとの分散は、点が独立でないので QMC の不確かさにならない。
乱択化の詳細と、反復による誤差の推定の振る舞いは [scioxide-random のランダム化と反復による誤差の推定](oxref:random-qmc-replicate-error)と、[Monte Carlo とランダム化した Sobol の比較](../../../scioxide-random/examples/monte-carlo-vs-sobol/)にある。

### MonteCarloIntegrator での実行

乱択 QMC も `MonteCarloIntegrator::integrate_into` で実行し、一様乱数の源（`UniformSource`）として `&QmcReplicatePlan` を渡す。
Plan の `MonteCarloOptions` の独立反復数は QMC の独立反復数に、標本数は各複製の点数に一致させる。
一致しなければ `InvalidInput`、点の次元が提案分布の一様乱数の個数と違えば `DimensionMismatch` である。
`workspace.statistics()` の基準は `VarianceBasis::Replicates` で、自由度は $R - 1$ になる。
`workspace.children()` は各複製の推定値を返すが、複製の中の点は独立でないので、子の統計は `None` である。
擬似乱数の `RandomStreams` と同じ Plan・作業領域を使えるので、二つの源を同じ評価回数で比べられる。

## 多層透過率の期待値

光が $d$ 枚の層を通るとき、第 $j$ 層の光学的厚さが $[0,\tau_j]$ で一様に不確かなら、期待透過率は

$$
\mathbb E\left[e^{-\sum_j\tau_j u_j}\right] = \int_{[0,1]^d}e^{-\sum_j\tau_j u_j}\,d\boldsymbol u = \prod_{j=1}^d\frac{1-e^{-\tau_j}}{\tau_j}
$$

である。
$\tau_j=\tau_1/j$ と後の層ほど不確かさを小さくし、軸ごとの重要度に差をつける。
次の定義のブロックは、二つのセルが使う透過率 `transmission` と、右辺の積を SciOxide の `exp_m1` で求めた独立な参照値 `exact_transmission` を置く。

```rust
//| id: integrate-transmission-model
//| kind: definitions
//| title: 多層透過率の被積分関数と期待透過率の厳密値
//| crates: [scioxide-core]
use scioxide_core::RealScalar;

// 透過率 exp(−Σ τ_j u_j)（u は単位立方体の点、tau は各層の最大光学的厚さ）。
pub(crate) fn transmission(u: &[f64], tau: &[f64]) -> f64 {
    RealScalar::exp(-u.iter().zip(tau).map(|(x, t)| x * t).sum::<f64>())
}

// 期待透過率 Π (1 − e^{−τ_j}) / τ_j。1 − e^{−τ} は exp_m1 で桁落ちなく求める。
pub(crate) fn exact_transmission(tau: &[f64]) -> f64 {
    tau.iter().map(|&t| -RealScalar::exp_m1(-t) / t).product()
}
```

最初のセルは疎格子で、絶対許容誤差を $10^{-2}$ から $10^{-9}$ まで下げ、最大の段 10、添字 4096 個、評価 $2^{16}$ 回を上限にする。
表は許容誤差ごとの評価回数、厳密値との差、誤差推定、終了状態を示す。
2 つ目の表は最も厳しい許容誤差について、軸ごとの $\tau_j$ と `directional_indicators()` の値を示す。
outcome は最も厳しい許容誤差での終了状態である。
このセルは光学的厚さと、グラフに使う疎格子の差と誤差推定を次のセルへ渡す。

```rust
//| id: integrate-sparse-grid-qmc-transmission
//| ref: integrate-sparse-grid-qmc-transmission
//| title: 層の数と光学的厚さを動かして疎格子の誤差推定と方向の指標を見る
//| run: button
//| cache: inputs
//| uses: [integrate-transmission-model]
//| crates: [scioxide-core, scioxide-integrate]
//| timeoutMs: 120000
//| exports: [optical_depths, sparse_errors, sparse_estimates]
//| inputs:
//|   layer_count: {"type":"range","label":"層の数 d [層]","description":"不確かな光学的厚さの個数（積分の次元）。","min":2,"max":8,"step":1,"value":5}
//|   optical_depth: {"type":"range","label":"第 1 層の最大光学的厚さ τ₁ [-]","description":"第 j 層は τ₁/j まで一様に不確かとする。","min":0.5,"max":4,"step":0.5,"value":2}
//| cases:
//|   - {"id":"eight-layers","label":"d = 8","description":"疎格子は最も厳しい二つの許容誤差で評価回数の上限 2¹⁶ に達し、方向の指標が重要な軸に偏る。","inputs":{"layer_count":8}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"sparse","path":"/rows/7/1","range":{"min":500,"max":20000}}
//|       - {"artifact":"sparse","path":"/rows/7/2","range":{"min":0,"max":1e-8}}
//|       - {"artifact":"sparse","path":"/rows/7/4","equals":"HeuristicToleranceReached"}
//|       - {"artifact":"axes","path":"/rows/0/2","range":{"min":1e-12,"max":1}}
//|       - {"path":"/outputs/2/state","equals":"satisfied"}
//|   - case: eight-layers
//|     expect:
//|       - {"artifact":"sparse","path":"/rows/5/4","equals":"HeuristicToleranceReached"}
//|       - {"artifact":"sparse","path":"/rows/7/4","equals":"BudgetLimit(Evaluation)"}
//|       - {"artifact":"sparse","path":"/rows/7/2","range":{"min":0,"max":1e-10}}
//|       - {"path":"/outputs/2/state","equals":"partial"}
use scioxide_core::{Budget, ErrorTolerance, ExecutionContext, Interval, NormSelection};
use scioxide_integrate::{SparseGridOptions, SparseGridPlan};

let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
// 期待透過率 E[exp(−Σ τ_j u_j)], u_j ~ U(0, 1), τ_j = τ₁/j。
let d = layer_count.round() as usize;
let tau: Vec<f64> = (1..=d).map(|j| optical_depth / j as f64).collect();
let exact = exact_transmission(&tau);
let f = |u: &[f64]| Ok(transmission(u, &tau));
let bounds = vec![Interval::new(0.0_f64, 1.0).map_err(|e| e.to_string())?; d];
let max_indices = Budget::try_from(4096).map_err(|e| e.to_string())?;
let max_evaluations = Budget::try_from(1 << 16).map_err(|e| e.to_string())?;
let (mut rows, mut errors, mut estimates) = (Vec::new(), Vec::new(), Vec::new());
let (mut indicators, mut last) = (Vec::new(), None);
// 絶対許容誤差を下げながら解き直す。到達は HeuristicToleranceReached（推定に基づく成功）。
for q in 2..=9 {
    let tol = 10.0_f64.powi(-q);
    let tolerance =
        ErrorTolerance::scalar(tol, 0.0, NormSelection::Infinity).map_err(|e| e.to_string())?;
    let options = SparseGridOptions::default()
        .with_tolerance(tolerance)
        .with_max_level(10)
        .with_max_indices(max_indices)
        .with_max_evaluations(max_evaluations);
    let plan = SparseGridPlan::new(d, options).map_err(|e| e.to_string())?;
    let mut workspace = plan.workspace(1).map_err(|e| e.to_string())?;
    let (mut value, context) = (0.0_f64, ExecutionContext::sequential());
    let report = plan
        .integrate_into(&f, &bounds, &mut value, &mut workspace, context)
        .map_err(|e| e.to_string())?;
    let (n, error, estimate) = (
        report.evaluations(),
        (value - exact).abs(),
        report.error_estimate(),
    );
    // 差がちょうど 0 の点は対数軸に描けないので除き、表に残す。
    errors.extend(Some([n as f64, error]).filter(|_| error > 0.0));
    estimates.extend(estimate.map(|e| [n as f64, e]));
    rows.push((tol, n, error, estimate, report.termination().to_string()));
    indicators = workspace.directional_indicators().to_vec();
    last = Some(report);
}
let columns = serde_json::json!([
    { "key": "0", "label": "絶対許容誤差 [-]", "type": "number", "format": sci3 },
    { "key": "1", "label": "評価回数 [回]", "type": "integer" },
    { "key": "2", "label": "厳密値との差 [-]", "type": "number", "format": sci3 },
    { "key": "3", "label": "誤差推定 [-]", "type": "number", "format": sci3, "nullText": "なし" },
    { "key": "4", "label": "終了状態" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "sparse" })
);
// 最も厳しい許容誤差での方向の指標を、軸ごとの τ_j と並べる。
let axes: Vec<_> = indicators
    .iter()
    .enumerate()
    .map(|(j, &v)| (j + 1, tau[j], v))
    .collect();
let axis_columns = serde_json::json!([
    { "key": "0", "label": "軸 j", "type": "integer" },
    { "key": "1", "label": "最大光学的厚さ τ_j [-]", "type": "number", "format": { "fractionDigits": 3 } },
    { "key": "2", "label": "方向の指標 [-]", "type": "number", "format": sci3 }
]);
emit_table_with_columns!(
    axis_columns,
    axes,
    metadata = serde_json::json!({ "id": "axes" })
);
export!(optical_depths, &tau);
export!(sparse_errors, &errors);
export!(sparse_estimates, &estimates);
let report = last.ok_or("許容誤差の列が空である")?;
let outcome = if report.is_success() {
    Outcome::satisfied("最も厳しい許容誤差に推定上で到達した")
        .explanation("誤差推定は未探索の添字の余剰を含まない経験的な推定で、上界ではない。")
} else {
    Outcome::partial("最も厳しい許容誤差に達する前に止まった")
        .explanation("表の最後の行は、止まった時点の推定値と誤差推定である。")
};
let evaluations = report.evaluations() as f64;
let outcome =
    outcome
        .status(report.termination().to_string())
        .diagnostic("評価回数", evaluations, None);
emit_outcome!(match report.error_estimate() {
    Some(estimate) => outcome.diagnostic("誤差推定", estimate, None),
    None => outcome,
});
```

既定値（$d=5$、$\tau_1=2$）では、疎格子は 61 回の評価で差 $2.0\times10^{-4}$、637 回で $6.5\times10^{-9}$、3673 回で $4.5\times10^{-12}$ に達し、すべて `HeuristicToleranceReached` で終わる。
誤差推定は実際の差より 2〜7 桁大きく、許容誤差を満たすことは確かめられるが、実際の誤差の大きさは表さない。
`directional_indicators()` の値は 5 軸とも同じ桁にそろう。
次元適応の細分が、残りの余剰が大きい方向から順に段を上げて、どの方向にも同程度の誤差しか残さないためである。
重要な軸（$\tau_j$ の大きい軸）は、そこに至るまでに多くの段を使っている。

層の数を 8 にすると、疎格子は許容誤差 $10^{-7}$ まで 25009 回で達するが、最も厳しい二つの許容誤差では評価回数の上限 $2^{16}$ に達して `BudgetLimit(Evaluation)` で止まり、outcome は partial になる。
このときも推定値と誤差推定は出力に反映され、差は $1.8\times10^{-13}$ である。
方向の指標は $\tau_j$ の大きい軸 1 と 2 で他の軸の 4〜12 倍になり、上限で止まったときに残った誤差がどの方向にあるかを示す。
層の数を 2 にすると、疎格子の差がちょうど 0 になる行があり、その点はグラフから除かれる。
$d = 8$ の計算は Wasm で 30 秒近くかかる。

2 つ目のセルは同じ被積分関数を乱択 QMC と通常の Monte Carlo で積分する。
乱択 QMC は $R=8$ 複製・各 $2^m$ 点（$m = 5, 7, \dots, 13$）、通常の Monte Carlo は 1 回の実行で $8\cdot 2^m$ 点とし、評価回数をそろえる。
グラフは評価回数に対する厳密値との差を両対数で描き、疎格子の誤差推定と統計的な方法の標準誤差を破線で重ねる。
差がちょうど 0 になった点は対数軸に描けないので除き、表に残す。
表は統計的な方法の評価回数、厳密値との差、標準誤差、差と標準誤差の比、終了状態を示す。

//| ref: integrate-qmc-mc-transmission
//| title: 乱数のシードを動かして乱択 QMC と Monte Carlo の誤差と標準誤差を疎格子と比べる

//| uses: [integrate-transmission-model]
//| crates: [scioxide-core, scioxide-integrate, scioxide-random]
//| timeoutMs: 120000

//|   sparse: integrate-sparse-grid-qmc-transmission

//| cases:
//|   - {"id":"other-seed","label":"シード 23","description":"別の乱数でも、統計的な方法の差は標準誤差の数倍以内に収まる。","inputs":{"seed":23}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"statistical","path":"/rows/8/2","range":{"min":0,"max":1e-5}}
//|       - {"artifact":"statistical","path":"/rows/8/4","range":{"min":-6,"max":6}}
//|       - {"artifact":"statistical","path":"/rows/8/1","equals":65536}
//|       - {"path":"/outputs/2/state","equals":"satisfied"}
//|   - case: other-seed
//|     expect:
//|       - {"artifact":"statistical","path":"/rows/9/4","range":{"min":-5,"max":5}}
use scioxide_core::{Budget, ExecutionContext, Interval};
use scioxide_integrate::{MonteCarloIntegrator, MonteCarloOptions, RandomStreams};
use scioxide_random::{Philox4x64, QmcPlan, QmcReplicateOptions, QmcReplicatePlan, SeedableRng};

let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
// 疎格子のセルから光学的厚さ τ_j と、疎格子の差と誤差推定の点列を受け取る。
let read = |key: &str| serde_json::from_value::<Vec<[f64; 2]>>(sparse[key].clone());
let sparse_errors = read("sparse_errors").map_err(|e| e.to_string())?;
let sparse_estimates = read("sparse_estimates").map_err(|e| e.to_string())?;
let tau: Vec<f64> =
    serde_json::from_value(sparse["optical_depths"].clone()).map_err(|e| e.to_string())?;
let exact = exact_transmission(&tau);
let f = |u: &[f64]| Ok(transmission(u, &tau));
let bounds = vec![Interval::new(0.0_f64, 1.0).map_err(|e| e.to_string())?; tau.len()];
let (context, replicates) = (ExecutionContext::sequential(), 8);
let sobol = QmcPlan::sobol(tau.len()).map_err(|e| e.to_string())?;
let (qmc_root, mc_root) = (
    Philox4x64::from_key([seed as u64, 0]),
    Philox4x64::from_seed(seed as u64),
);
let (mut curves, mut rows) = ([(); 4].map(|_| Vec::new()), Vec::new());
let mut completed = true;
// 乱択 QMC（R = 8 複製、各 2^m 点）と Monte Carlo（1 回の実行、8·2^m 点）を同じ評価回数で比べる。
for m in [5_u32, 7, 9, 11, 13] {
    let points = 1_usize << m;
    let qmc_options = QmcReplicateOptions::default()
        .with_replicates(replicates)
        .with_points_per_replicate(points);
    let qmc =
        QmcReplicatePlan::new(&sobol, &qmc_root, qmc_options).map_err(|e| e.to_string())?;
    let methods = [
        ("乱択 QMC（R = 8）", points, replicates),
        ("Monte Carlo", points * replicates, 1),
    ];
    for (k, (name, samples, copies)) in methods.into_iter().enumerate() {
        let budget = Budget::try_from(samples).map_err(|e| e.to_string())?;
        let options = MonteCarloOptions::default()
            .with_samples(budget)
            .with_replicates(copies);
        let plan = MonteCarloIntegrator::new(&bounds, options).map_err(|e| e.to_string())?;
        let mut ws = plan.workspace(1, context).map_err(|e| e.to_string())?;
        let mut value = 0.0_f64;
        let streams = RandomStreams::new(&mc_root, 0);
        let report = match k {
            0 => plan.integrate_into(&f, &qmc, &mut value, &mut ws, context),
            _ => plan.integrate_into(&f, streams, &mut value, &mut ws, context),
        }
        .map_err(|e| e.to_string())?;
        let se = ws.statistics()[0]
            .as_ref()
            .ok_or("統計がない")?
            .standard_error();

        curves[2 * k].extend(Some([n as f64, error]).filter(|_| error > 0.0));
        curves[2 * k + 1].push([n as f64, se]);
        let z = (value - exact) / se;
        completed &= report.is_success();
        rows.push((name, n, error, se, z, report.termination().to_string()));
    }
}

];

        "xLabel": "被積分関数の評価回数 [回]",
        "yLabel": "期待透過率の誤差 [-]",

    { "key": "0", "label": "方法" },
    { "key": "1", "label": "評価回数 [回]", "type": "integer" },
    { "key": "2", "label": "厳密値との差 [-]", "type": "number", "format": sci3 },
    { "key": "3", "label": "標準誤差 [-]", "type": "number", "format": sci3 },
    { "key": "4", "label": "差/標準誤差 [-]", "type": "number", "format": { "fractionDigits": 2 } },

} else {

};
emit_outcome!(

        .status(last.5.clone())

        .diagnostic("Monte Carlo の標準誤差", last.3, None)

既定値（シード 7）では、乱択 QMC は 256 回で差 $3.9\times10^{-4}$（標準誤差 $5.6\times10^{-4}$）、65536 回で差 $2.5\times10^{-7}$（標準誤差 $2.6\times10^{-7}$）となった。
評価回数を 256 倍にして標準誤差は約 2100 分の 1 になり、$N^{-1/2}$ より速い $N^{-1.4}$ 程度の減り方を示す。
通常の Monte Carlo 法は同じ 65536 回で差 $5.2\times10^{-4}$（標準誤差 $3.6\times10^{-4}$）で、標準誤差は 256 回から約 18 分の 1、すなわち $N^{-1/2}$ の割合で減る。
既定のシードでは、差と標準誤差の比はすべての行で $\pm 1.5$ 以内に収まる。
シードを 23 にすると、Monte Carlo の 256 回の行で比が $-3.3$ になる。
標準誤差は誤差の大きさの統計的な目安で、外れる確率は小さいが 0 ではない。
乱択 QMC の標準誤差は自由度 7 の複製のばらつきから求めるので、標準誤差の推定値自体が相対標準偏差で 3 割程度揺らぐ。

この滑らかな被積分関数では、疎格子が最も少ない評価で最も小さい誤差に達する。
乱択 QMC は疎格子より遅いが、誤差推定の代わりに統計的な標準誤差を持ち、被積分関数の滑らかさが失われても不偏性を保つ。

## まとめ

疎格子は入れ子の Clenshaw–Curtis 則の差分のテンソル積を足し合わせ、混合偏導関数が有界な滑らかな関数で、テンソル積則の次元の呪いを対数の因子まで和らげる。
`SparseGridPlan` は余剰の大きい方向へ添字を増やす次元適応の方法で、重要な軸に節点を集め、`directional_indicators()` でその偏りを確かめられる。
その成功は `HeuristicToleranceReached` で、誤差推定は経験的な推定なので、許容誤差を変えた比較や既知の値で確かめる。
乱択 QMC は `QmcReplicatePlan` の独立な複製を `MonteCarloIntegrator` に渡し、複製のばらつきから自由度 $R-1$ の標準誤差と区間を返すので、通常の Monte Carlo 法と同じ形の統計的な不確かさを、より少ない評価で得られる。
不連続や局在したピークを持つ被積分関数では両方とも効率が落ちるので、[適応 Monte Carlo（VEGAS・MISER）](../adaptive-monte-carlo/)や領域の分割を検討する。
