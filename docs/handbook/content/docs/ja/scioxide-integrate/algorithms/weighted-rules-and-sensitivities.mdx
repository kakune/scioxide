被積分関数の難しい部分が式で分かっているときは、積分を $\int_a^b w(x)\,g(x)\,dx$ と分け、既知の重み $w$ を解析的に扱い、滑らかな振幅 $g$ だけを標本にする。
このページは端点の代数的・対数的な重み、Cauchy 主値、複素経路の積分を扱う。

`WeightedQuadraturePlan` の Fourier 重みは[振動積分の相殺と Fourier 積分の尾部](../fourier-integrals-and-tails/)、分割点は[広義積分と端点特異性の二重指数変換](../improper-singular-and-oscillatory/)で扱う。
固定の標本として与えられた被積分関数は[標本データの積分](../sampled-data-integration/)、パラメータについての積分の微分は[パラメータ感度と積分の JVP・VJP](../parameter-sensitivities/)で扱う。

## 重みを分ける考え方

積分 $I = \int_a^b w(x)\,g(x)\,dx$ で、$g$ を多項式 $p_n$ で補間すると

$$
\left| I - \int_a^b w(x)\,p_n(x)\,dx \right| \le \max_{[a,b]}|g - p_n| \int_a^b |w(x)|\,dx
$$

が成り立つ。
右辺は $g$ の滑らかさだけで決まり、$w$ の特異性や振動は $\int|w|$ を通してしか入らない。
これを積の求積（product integration）と呼ぶ。

区間を $x(t) = \frac{a+b}{2} + \frac{b-a}{2}t$ で $t \in [-1, 1]$ に写し、$p_n = \sum_k c_k T_k(t)$ を Chebyshev 多項式 $T_k$ の和で表すと

$$
\int_a^b w\,p_n\,dx = \frac{b-a}{2}\sum_{k=0}^{n} c_k\,\mu_k, \qquad \mu_k = \int_{-1}^{1} T_k(t)\,w(x(t))\,dt
$$

となる。
$\mu_k$ を修正 Chebyshev モーメントと呼ぶ。
係数 $c_k$ は 25 個の Chebyshev 極値点 $t_j = \cos(j\pi/24)$ での $g$ の値から離散コサイン変換で求まり、これを修正 Clenshaw–Curtis 則と呼ぶ。
入れ子の 13 点の則（次数 12）との差が離散化誤差の推定になる。

基本の仕様は、コールバックが振幅 $g(x)$ だけを返し、重み $w$ を重ねて掛けないことである。
値は実数、複素数、ベクトルのどれでもよく、scioxide-core の `AffineValue` トレイトを通して実数成分ごとに積分する。

## 代数的・対数的な端点重み

`EndpointWeight::new(alpha, beta, left_log, right_log)` は重み

$$
w(x) = (x - a)^{\alpha}\,(b - x)^{\beta}\,[\ln(x - a)]\,[\ln(b - x)]
$$

を表す。
角括弧の対数因子は `left_log`、`right_log` で選んだときだけ掛かる。
$\alpha > -1$ かつ $\beta > -1$ なら $w$ は $[a, b]$ で可積分で、$\alpha \le -1$ や $\beta \le -1$ は `InvalidInput`、NaN や無限大は `NonFinite` になる。

`WeightedQuadraturePlan::endpoint(interval, points, weight, options)` は端点特異性の重み付き求積を行う。
内部の分割点を与えない場合、Plan は区間を中点で 2 つに分け、両方の特異な端点を含む領域ができないようにする。
特異な端点（指数が 0 でないか対数因子がある端点）に接する領域だけがモーメントの則を使い、他の領域は積 $g\,w$ に 15 点の Gauss–Kronrod 則（G7K15）を使う。
モーメント領域では、もう一方の端点に由来する因子が滑らかなので、標本側の因子として $g$ に掛ける。
モーメントの則は Chebyshev 極値点の両端を使うので、$g$ は $a$ と $b$ でも評価される。
$g$ は端点を含めて有限で滑らかでなければならない。

### モーメントの尺度変換

左端 $a$ に接する幅 $L$ の領域で $x = a + Ls$、$s = (1+t)/2$ と置くと、$(x-a)^\alpha = L^\alpha s^\alpha$、$dx = L\,ds$ である。
したがって、$dx = L\,ds$ を含めた領域の積分は、幅 1 の正準区間のモーメント

$$
\nu_k = \int_0^1 s^{\alpha}\,T_k(2s - 1)\,ds, \qquad \lambda_k = \int_0^1 s^{\alpha}\ln s\;T_k(2s - 1)\,ds
$$

に $L^{\alpha+1}$ を掛けたもので表せる。
対数因子は $\ln(x - a) = \ln L + \ln s$ と分かれるので、$\ln L \cdot \nu_k + \lambda_k$ の形になる。
最初のモーメントは $\nu_0 = 1/(\alpha+1)$、$\lambda_0 = -1/(\alpha+1)^2$ で、高次のモーメントは $T_k$ の三項漸化式と部分積分から導く漸化式（Piessens–Branders）で求める。

Plan は正準モーメントを端点ごとに一度だけ準備する。
実装は $T_k(t) - T_k(-1)$ の積分を漸化式で求め、共通の $1/(\alpha+1)$ の特異性を丸めの前に取り除く。
どのモーメントも $O(1/(\alpha+1))$ の大きさで、2 のべきを途中で作らないので、大きな指数でも桁あふれしない。
$L^{\alpha+1}$ の尺度は拡張指数範囲で掛けるので、$\alpha = 1022$ のような指数や、端点から $10^{-100}$ の位置にある分割点でも途中で桁あふれや下位桁あふれを起こさない。
領域の値そのものが表せないほど大きいときだけ、積分は `NumericalInstability` で失敗する。
値が下位桁あふれする領域は丸めた値を加え、失った精度を丸め誤差による精度の限界に加える。

各領域は入れ子の差による離散化の推定、丸め誤差による精度の限界、モーメントの誤差の伝播を別々に持つ。
`component_errors()` はそれぞれを全領域で足した値を `discretization`、`roundoff`、`moments` として返す。
`error_estimate()` は `total()` で、離散化と丸め誤差による精度の限界を足すのではなく大きい方をとり、それにモーメントの誤差（外挿を使えばその誤差も）を足す。
どの領域を二分するかも領域ごとの $\max(\text{離散化}, \text{丸め}) + \text{モーメント}$ で決める。
どれも上界ではない。

## Cauchy 主値

極 $c \in (a, b)$ を持つ積分の Cauchy 主値は、極の左右を対称に除いた極限

$$
\mathrm{PV}\int_a^b \frac{f(x)}{x - c}\,dx = \lim_{\epsilon \to 0^+}\left[\int_a^{c-\epsilon} + \int_{c+\epsilon}^{b}\right]\frac{f(x)}{x - c}\,dx
$$

である。
発散する 2 つの通常積分を別々に計算して足すものではない。
$f(c)$ を引いて足すと

$$
\mathrm{PV}\int_a^b \frac{f(x)}{x - c}\,dx = \int_a^b \frac{f(x) - f(c)}{x - c}\,dx + f(c)\ln\frac{b - c}{c - a}
$$

となり、右辺の第 1 項は $f$ が $c$ の近くで滑らかなら通常の積分である。

`WeightedQuadraturePlan::principal_value(interval, pole, options)` は Cauchy 主値積分を求める。
コールバックは $f$ だけを返し、Plan は極の近くで $x - c$ で割らない。
極を含む領域と、中心から半幅の 1.1 倍以内に極がある領域は、$1/(t - \hat c)$ のモーメント（$\hat c$ は標準座標の極）を使う修正 Clenshaw–Curtis 則で積分する。
他の領域は $f(x)/(x - c)$ に G7K15 を使う。

モーメントは $m_0 = \ln\bigl((1 - \hat c)/(1 + \hat c)\bigr)$ から始まり、$T_k = 2tT_{k-1} - T_{k-2}$ と $t = (t - \hat c) + \hat c$ から

$$
m_k = 2\hat c\,m_{k-1} - m_{k-2} + 2\int_{-1}^{1} T_{k-1}(t)\,dt
$$

の漸化式で求める。
$m_0$ は、標準座標の $\hat c$ を経由せずに、物理的な距離の比 $|b - c|/|c - a|$ の対数として計算する。
2 つの距離は拡張指数範囲で求めるので、区間の端点が大きく距離が桁あふれする場合も扱える。
2 つの距離がほぼ等しく比が 1 に近いときは、距離の差を先に正確に足し合わせ、$\ln(1+x)$ の形で対数をとる。
このため、極が中点の近くにある場合も、端点から丸め 1 回分しか離れていない場合も、対数の値を失わない。
内部かどうかも物理的な位置で判定する。
領域の外の極では漸化式の最小解を使うことになり、丸め誤差は 1 段ごとに $|\hat c| + \sqrt{\hat c^2 - 1}$ 倍に増えるので、誤差のモデルにこの増幅を含める。
極が区間の外にあれば通常の積分になり、極が $a$ または $b$ に等しい場合は `InvalidInput` である。

## 複素経路の積分

`ContourPlan::new(parameter_interval, breakpoints, SubdivisionOptions)` は、径路 $C$ をパラメータ $t \in [a, b]$ で表した複素積分

$$
\int_C f(z)\,dz = \int_a^b f(z(t))\,z'(t)\,dt
$$

を計算する。
`integrate(f, map)` の `map` は $t$ から $(z(t), z'(t))$ を返し、`f` は $f(z)$ を返す。
向きは `map` が決め、閉じた径路や逆向きの径路に特別な扱いはいらない。
$z'$ の孤立した零点は許される。
Plan は多価関数の枝を選ばないので、$f$ は $C$ に沿って連続でなければならない。

実部と虚部を分割点つきの適応 G7K15 で積分し、各節点で `map` と `f` を 1 回ずつ呼ぶ。
両方の呼び出しが評価回数の上限に数えられ、レポートの評価回数は `f` の呼び出しの数である。
誤差推定は $z'$ の誤差を含まない。
`workspace()` は `WeightedQuadratureWorkspace` を返し、`component_errors()` の成分は `[実部, 虚部]` の順である。

## Plan・作業領域・終了状態

`WeightedQuadratureOptions::new(SubdivisionOptions)` の `SubdivisionOptions` は許容誤差、細分と評価回数の上限、実行方針を決める。
既定の許容誤差は絶対・相対とも $\sqrt{\varepsilon}$ で、判定は $E \le \varepsilon_{\mathrm{abs}} + \varepsilon_{\mathrm{rel}}|Q|$ である。
`with_moment_levels` は Fourier 重みだけが使い、他の重みは無視する。

`workspace(components)` は実数成分の数に合わせた `WeightedQuadratureWorkspace` を作り、`integrate_into(f, out, &mut workspace, scope)` に繰り返し渡せる。
`component_errors()` は直前に呼び出したときの成分ごとの `IntegrationErrorComponents` を返し、呼び出しが失敗したときや誤差を推定しなかったときは `None` である。
幅 0 の区間では値が厳密に 0、終了状態が `DegenerateDomain` で、$f$ は呼ばれない。
収束したときの終了状態は `ToleranceReached` で、上限で止まると `BudgetLimit` や `RefinementLimit` とともにその時点の推定値を返す。
エラー時は出力を書き換えない。

## 端点重みと Beta 関数

重み $w(x) = x^{\alpha}(1-x)^{\beta}$（対数因子を選べば $\ln x$ も掛ける）と振幅のベクトル $(1, x, e^x)$ を `WeightedQuadraturePlan::endpoint` で積分する。
対数因子がなければ、参照値は

$$
\int_0^1 x^{\alpha}(1-x)^{\beta}\,dx = B(\alpha+1, \beta+1), \qquad \int_0^1 x^{\alpha+1}(1-x)^{\beta}\,dx = B(\alpha+2, \beta+1),
$$

$$
\int_0^1 x^{\alpha}(1-x)^{\beta}e^{x}\,dx = B(\alpha+1, \beta+1)\,M(\alpha+1;\, \alpha+\beta+2;\, 1)
$$

である。
$M$ は Kummer の合流型超幾何関数で、最後の式は DLMF 13.4.1 の積分表示による。
対数因子があると、$\partial_\alpha B(\alpha+1, \beta+1) = B(\alpha+1,\beta+1)\bigl(\psi(\alpha+1) - \psi(\alpha+\beta+2)\bigr)$ から、最初の 2 成分の参照値は digamma 関数 $\psi$ で表せる。
$e^x$ の成分には対数因子つきの閉じた形を使わず、参照値なしとして表に示す。
参照値は `scioxide_special` の `beta`、`digamma`、`hyp1f1` で求める。

最初の 2 成分は振幅が多項式なので、Chebyshev 補間は厳密であり、モーメントそのものの精度を確かめる。
$e^x$ の成分は補間の誤差も含めて確かめる。
入力は 2 つの指数と対数因子の有無で、$x$ と積分値は無次元である。
3 成分の振幅を 1 回の呼び出しで積分し、成分ごとの誤差推定を作業領域から読む。
比較として、第 1 成分と同じ積分を[広義積分と端点特異性の二重指数変換](../improper-singular-and-oscillatory/)の tanh–sinh 変換でも計算する。
DE の被積分関数は `nearest_endpoint()` の距離で特異因子を評価する。
表は方法と振幅ごとに 1 行で、outcome は端点重みの Plan の終了状態を示す。

```rust
//| id: integrate-endpoint-weight
//| ref: integrate-endpoint-weight
//| title: 端点重みの指数を動かして Beta 関数と照合する
//| run: reactive
//| crates: [scioxide-core, scioxide-integrate, scioxide-special]
//| inputs:
//|   alpha: {"type":"range","label":"左端の指数 α [-]","description":"重み x^α の指数。−1 より大きい。","min":-0.95,"max":2,"step":0.05,"value":-0.5}
//|   beta_exponent: {"type":"range","label":"右端の指数 β [-]","description":"重み (1 − x)^β の指数。−1 より大きい。","min":-0.95,"max":2,"step":0.05,"value":0.25}
//|   left_log: {"type":"checkbox","label":"左端の対数因子 ln x","value":false}
//| cases:
//|   - {"id":"strong-left","label":"α = −0.95","description":"強い端点特異性でも端点重みは数十回の評価で成功し、DE は停滞する。","inputs":{"alpha":-0.95}}
//|   - {"id":"with-log","label":"対数因子あり","description":"ln x を掛けた重みを digamma 関数の参照値と照合する。","inputs":{"left_log":true}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"methods","path":"/rows/0/4","range":{"min":0,"max":1e-13}}
//|       - {"artifact":"methods","path":"/rows/2/4","range":{"min":0,"max":1e-13}}
//|       - {"artifact":"methods","path":"/rows/0/7","equals":"ToleranceReached"}
//|       - {"artifact":"methods","path":"/rows/3/7","equals":"HeuristicToleranceReached"}
//|       - {"path":"/outputs/1/state","equals":"satisfied"}
//|   - case: strong-left
//|     expect:
//|       - {"artifact":"methods","path":"/rows/0/4","range":{"min":0,"max":1e-12}}
//|       - {"artifact":"methods","path":"/rows/2/4","range":{"min":0,"max":1e-12}}
//|       - {"artifact":"methods","path":"/rows/0/7","equals":"ToleranceReached"}
//|       - {"artifact":"methods","path":"/rows/3/7","equals":"Stagnation"}
//|       - {"path":"/outputs/1/state","equals":"satisfied"}
//|   - case: with-log
//|     expect:
//|       - {"artifact":"methods","path":"/rows/0/4","range":{"min":0,"max":1e-12}}
//|       - {"artifact":"methods","path":"/rows/1/4","range":{"min":0,"max":1e-12}}
//|       - {"artifact":"methods","path":"/rows/2/4","equals":null}
//|       - {"path":"/outputs/1/state","equals":"satisfied"}
use scioxide_core::{ExecutionContext, Interval, RealScalar};
use scioxide_integrate::{
    DoubleExponentialDomain, DoubleExponentialIntegrator, DoubleExponentialPoint,
    EndpointWeight, LevelOptions, WeightedQuadratureOptions, WeightedQuadraturePlan,
};
use scioxide_special::{beta, digamma, hyp1f1};

let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let digits15 = serde_json::json!({ "significantDigits": 15 });
let interval = Interval::new(0.0_f64, 1.0).map_err(|e| e.to_string())?;
let weight =
    EndpointWeight::new(alpha, beta_exponent, left_log, false).map_err(|e| e.to_string())?;
let plan = WeightedQuadraturePlan::endpoint(
    interval,
    &[],
    weight,
    WeightedQuadratureOptions::default(),
)
.map_err(|e| e.to_string())?;
// 振幅は (1, x, eˣ) の 3 成分。重み x^α (1 − x)^β [ln x] は Plan が受け持つ。
let mut workspace = plan.workspace(3).map_err(|e| e.to_string())?;
let mut value = [0.0_f64; 3];
let report = plan
    .integrate_into(
        |x: f64| Ok([1.0, x, RealScalar::exp(x)]),
        &mut value,
        &mut workspace,
        ExecutionContext::sequential(),
    )
    .map_err(|e| e.to_string())?;
let errors = workspace
    .component_errors()
    .ok_or("成分ごとの誤差推定がない")?;

// 参照値: B(α+1, β+1) と B(α+2, β+1)。対数因子では ψ の差を掛ける。
let moment = |a: f64| -> Result<f64, String> {
    let b = beta(a, beta_exponent + 1.0).map_err(|e| e.to_string())?;
    if left_log {
        let psi = digamma(a).map_err(|e| e.to_string())?
            - digamma(a + beta_exponent + 1.0).map_err(|e| e.to_string())?;
        Ok(b * psi)
    } else {
        Ok(b)
    }
};
// eˣ の成分は B(α+1, β+1) M(α+1; α+β+2; 1)。対数因子つきの閉じた形は使わない。
let kummer = if left_log {
    None
} else {
    let m = hyp1f1(alpha + 1.0, alpha + beta_exponent + 2.0, 1.0).map_err(|e| e.to_string())?;
    Some(moment(alpha + 1.0)? * m)
};
let exact = [
    Some(moment(alpha + 1.0)?),
    Some(moment(alpha + 2.0)?),
    kummer,
];

// 比較: 第 1 成分を tanh–sinh 変換で積分する。特異因子は端点距離で評価する。
let de = DoubleExponentialIntegrator::new(
    DoubleExponentialDomain::Finite {
        interval,
        singular_points: &[],
    },
    LevelOptions::default(),
)
.map_err(|e| e.to_string())?;
let singular = |point: DoubleExponentialPoint<f64>| {
    let x = point.coordinate();
    let (left, right) = match point.nearest_endpoint() {
        Some((0.0, distance)) => (distance, 1.0 - x),
        Some((_, distance)) => (x, distance),
        None => (x, 1.0 - x),
    };
    let logarithm = if left_log { RealScalar::ln(left) } else { 1.0 };
    Ok(RealScalar::powf(left, alpha) * RealScalar::powf(right, beta_exponent) * logarithm)
};
let (de_value, de_report) = de.integrate(&singular).map_err(|e| e.to_string())?;

let columns = serde_json::json!([
    { "key": "0", "label": "方法" },
    { "key": "1", "label": "振幅" },
    { "key": "2", "label": "積分値 [-]", "type": "number", "format": digits15 },
    { "key": "3", "label": "参照値 [-]", "type": "number", "format": digits15, "nullText": "参照なし" },
    { "key": "4", "label": "実誤差 [-]", "type": "number", "format": sci2, "nullText": "参照なし" },
    { "key": "5", "label": "誤差推定 [-]", "type": "number", "format": sci2, "nullText": "推定なし" },
    { "key": "6", "label": "評価回数 [回]", "type": "integer" },
    { "key": "7", "label": "終了状態" }
]);
let mut rows = Vec::new();
for (component, name) in ["1", "x", "eˣ"].into_iter().enumerate() {
    rows.push((
        "端点重み".to_string(),
        name.to_string(),
        value[component],
        exact[component],
        exact[component].map(|e| (value[component] - e).abs()),
        errors[component].total(),
        report.evaluations(),
        report.termination().to_string(),
    ));
}
rows.push((
    "DE（tanh–sinh）".to_string(),
    "1".to_string(),
    de_value,
    exact[0],
    exact[0].map(|e| (de_value - e).abs()),
    de_report.error_estimate(),
    de_report.evaluations(),
    de_report.termination().to_string(),
));
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "methods" })
);

// 結論は端点重みの Plan の終了状態で決める。DE の行は比較用。
let outcome = if report.is_success() {
    Outcome::satisfied("端点重みの Plan が 3 成分の許容誤差を満たした")
} else {
    Outcome::partial("端点重みの Plan が許容誤差を満たす前に止まった")
};
let outcome = outcome.status(report.termination().to_string()).diagnostic(
    "評価回数",
    report.evaluations() as f64,
    None,
);
emit_outcome!(match report.error_estimate() {
    Some(estimate) => outcome.diagnostic("誤差推定", estimate, None),
    None => outcome,
});
```

既定値（$\alpha = -0.5$、$\beta = 0.25$）では、端点重みは中点で分けた 2 つの領域にそれぞれ 25 点の則を使い、50 回の評価で `ToleranceReached` となった。
3 成分とも参照値との差は丸めの程度で、成分ごとの誤差推定は $10^{-13}$ 程度である。
DE は 81 回の評価で `HeuristicToleranceReached` となり、差は同じく丸めの程度だった。

$\alpha = -0.95$ でも端点重みの評価回数は 50 回のままで、差は $10^{-14}$ 以下である。
特異性はモーメントが受け持ち、振幅 $(1, x, e^x)$ の滑らかさは変わらないからである。
一方、DE は 97 回の評価で `Stagnation` となり、値は正しいが誤差推定は $8 \times 10^{-5}$ にとどまった。
対数因子を加えても端点重みは 50 回で収束し、digamma 関数による参照値との差は $10^{-16}$ 程度だった。

## まとめ

既知の端点特異性と主値は、重みとして `WeightedQuadraturePlan::endpoint` と `principal_value` に持たせ、コールバックには滑らかな振幅だけを渡す。
誤差は振幅の滑らかさだけで決まるので、特異指数が $-1$ に近くても評価回数は増えない。
修正モーメントは幅 1 の正準区間で一度だけ準備され、拡張指数範囲の尺度変換で大きな指数や小さな領域を扱う。
複素経路の積分は `ContourPlan` に $(z, z')$ を返す写像を渡し、誤差推定は $z'$ の誤差を含まないことに注意する。
繰り返し積分するときは `WeightedQuadratureWorkspace` を作り、`component_errors()` で成分ごとの誤差の内訳を読む。
