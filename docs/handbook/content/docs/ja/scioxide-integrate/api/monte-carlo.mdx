このページの表は標本を確率的に選ぶ積分の型をまとめる。
標準誤差と信頼区間は標本化による統計的な不確かさを表し、偏りの上界ではなく、標本の届かない領域の寄与も検出しない。
区間は既定で Student-t 分布に基づく。
区間は実成分ごとに求めるので、成分の間で同時には成り立たない。
`RandomStreams` から引く標本は根と系列番号で決まり、取り消しや期限で止まらない限り、実行方針やワーカーの数によらず同じ推定値、統計、評価回数になる。
VEGAS と MISER の学習に使った標本は評価の推定量に入らない。
共通の結果型は [API ガイドの最初のページ](../)にある。
