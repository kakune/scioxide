このページの表は標本を確率的に選ばない多次元の求積をまとめる。
直方体ではテンソル積則、Genz–Malik の適応 cubature、疎格子を使い、端点が外側の座標に依存する領域は反復積分と座標写像、三角形・四面体・球面は固定則で扱う。
被積分関数は点 `&[S]` を受け取り、実数・複素数・固定長ベクトルの値を `Result` で返す。
適応法の誤差は推定値で、節点の間に隠れた局所的な特徴は見落とされうる。
作業領域は 1 つの次元と成分数に対応し、十分な大きさの作業領域を渡した `integrate_into` は確保しない。
共通の結果型と `SubdivisionOptions` は [API ガイドの最初のページ](../)にある。

## 適応 cubature

| 項目 | 種別 | 役割 | 仕様の要点 | 解説節 | 実行例 |
