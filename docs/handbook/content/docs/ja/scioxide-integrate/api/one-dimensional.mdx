この表は有界区間と無限区間の 1 次元積分の型をまとめる。
区間は scioxide-core の `Interval` で渡し、非有限や逆順の端点は `Interval` の構築で拒まれる。
幅 0 の区間は評価なしで厳密な 0 と `DegenerateDomain` を返す。
固定則は節点と重みを一度適用して `FixedRuleCompleted` で終わり、精度を主張しない。
適応則と段を重ねる則は許容誤差を満たすと `ToleranceReached`（二重指数変換は `HeuristicToleranceReached`）で終わり、上限で止まると領域全体の推定値を成功でない終了理由とともに返す。
共通の結果型と `SubdivisionOptions` は [API ガイドの最初のページ](../)にある。

## 固定則の共通仕様

`FixedRule` を実装する則は同じ方法で節点を写し、実数・複素数・ベクトルの値を積分する。

## 標本データの積分

標本の Plan は座標を一度だけ準備し、その座標の標本列を何度でも積分する。
作業領域は Plan の `workspace(components)`、`cumulative_workspace(components)`、`axis_workspace(shape, axis, components)`、`cumulative_axis_workspace(shape, axis, components)` で作る。
一度だけ積分するならワンショット関数 `trapezoid`、`simpson`、`cumulative_trapezoid` を使う。
レポートも誤差推定も返さず、結果をすべて計算してから書くので、エラー時は出力を変えない。
結果の桁あふれは `NumericalInstability`、非有限の標本は `NonFinite` である。
