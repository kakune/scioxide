この表は積分に近い二つの計算をまとめる。
一つは無限級数の和で、Levin u と Wynn ε の停止は経験的な推定、Euler–Maclaurin 和の上界は利用者が与える尾部の情報が正しい場合に限る条件付きの上界である。
もう一つは有限区間の 1 次元積分のパラメータ微分で、$x$ を固定した被積分関数の微分の積分と動く端点の Leibniz 項を合わせ、離散化した積分の導関数を同じ節点で求める。
適応的な分割の選び方は微分しない。
