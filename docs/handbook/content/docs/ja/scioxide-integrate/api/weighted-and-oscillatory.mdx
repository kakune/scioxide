この表は既知の難しい因子（端点の特異性、極、振動因子）を Plan に重みとして持たせ、コールバックには滑らかな振幅だけを渡す積分の型をまとめる。
コールバックに同じ重みを重ねて掛けてはならない。
準備した Plan は不変で、作業領域を渡した `integrate_into` は確保しない。
レポートの誤差は離散化、丸め誤差による精度の限界、モーメント、外挿、尾部の成分に分かれ、合計は $\max(\text{離散化},\text{丸め})$ に他の成分を足した推定値で、上界ではない。
共通の結果型と `SubdivisionOptions` は [API ガイドの最初のページ](../)にある。

## 重み付き求積

`WeightedQuadraturePlan` は分割点・端点特異性・Cauchy 主値・Fourier 重みに対応する 4 つのコンストラクターを持つ。
重みが特異か強く振動する領域では、振幅を 25 個の Chebyshev 点で補間して修正 Chebyshev モーメントと組み合わせ（修正 Clenshaw–Curtis 則）、入れ子の 13 点の則との差を誤差推定にする。
他の領域は積 $f\,w$ に G7K15 を使う。
