光学系の開口を通る光束、放射面からの熱流束、流路の断面を通る流量は、面の上の強度を積分した 2 重積分で表される。
強度が多項式に近ければ各軸の Gauss 則の積で少ない点数で積分できるが、座標軸に沿わない細い構造が加わると、積型則の誤差は点数を増やしても単調には減らない。
この例題では回転した細い遮蔽帯を持つ開口の透過量を、Gauss–Legendre の積型則と適応 Genz–Malik 求積で求め、閉形式と点数を増やした積型則で照合する。

## 開口の強度と透過量

開口面の強度を $I(x, y)$ [W/m²]、座標を [m] とすると、透過量

$$
P = \iint_\Omega I(x, y)\,dx\,dy
$$

は [W] の単位を持つ。
以下では開口を正方形 $\Omega = [-1, 1]^2$ とし、座標を開口の半幅で、強度を中心の強度で割った無次元の量で書く。
透過量も無次元で、中心の強度と半幅の 2 乗の積を単位とする。

遮蔽のない開口の強度を、縁で滑らかに 0 になる

$$
B(x, y) = (1 - x^2)(1 - y^2)
$$

とする。
$B$ は $x$ の関数と $y$ の関数の積なので、Fubini の定理から

$$
P_0 = \left(\int_{-1}^{1}(1 - x^2)\,dx\right)^2 = \left(\frac{4}{3}\right)^2 = \frac{16}{9}
$$

である。
$B$ は各変数について 2 次なので、各軸 $n$ 点の Gauss–Legendre 則（$2n - 1$ 次まで厳密）は $n \ge 2$ で $P_0$ を丸め誤差の範囲で再現する。

## 回転した遮蔽帯

開口に、角度 $\theta$ だけ回転した細い遮蔽帯を置く。
帯に沿う座標 $u$ と帯を横切る座標 $v$ を

$$
u = x\cos\theta + y\sin\theta, \qquad v = -x\sin\theta + y\cos\theta
$$

とし、横切る方向の半幅を $w$、沿う方向の尺度を $\ell = 0.65$、中心での遮蔽の深さを $d \in [0, 1)$ とする。
透過率と強度は

$$
T(x, y) = 1 - d\exp\left[-\left(\frac{v}{w}\right)^2 - \left(\frac{u}{\ell}\right)^2\right], \qquad I(x, y) = B(x, y)\,T(x, y)
$$

である。
$0 < \theta < 90^\circ$ では指数の中に $xy$ の交差項が現れ、$I$ は変数分離できず、多項式でもない。

$\theta = 0$ では $u = x$、$v = y$ となり、遮蔽の項も $x$ と $y$ の関数の積になる。
$J(s) = \int_{-1}^{1}(1 - x^2)e^{-x^2/s^2}\,dx$ は

$$
J(s) = s\sqrt{\pi}\,\operatorname{erf}(1/s)\left(1 - \frac{s^2}{2}\right) + s^2 e^{-1/s^2}
$$

と誤差関数で書けるので、透過量は

$$
P(\theta = 0) = \frac{16}{9} - d\,J(\ell)\,J(w)
$$

の閉形式を持つ。
$\theta = 90^\circ$ では $\ell$ と $w$ の役割が入れ替わるだけで、$B$ の対称性から $P$ は $\theta = 0$ と同じ値になる。
回転した場合の参照値には各軸 96 点（9216 点）の積型則を使う。
これも推定値なので、$\theta = 0$ では閉形式と、回転した場合は適応求積の値と比べてその精度を確かめる。

## 積型則と適応 Genz–Malik 求積

`ProductRule` は 1 次元の固定則を各軸に適用した直積で、各軸 $n$ 点なら $n^2$ 個の格子点で評価する。
`GaussianRulePlan` で作る Gauss–Legendre 則は埋め込みの則を持たないので、積型則は誤差推定を返さず、終了状態は `FixedRuleCompleted` になる。
格子点の位置は被積分関数の形と無関係に決まり、$n$ を変えるとすべての点が動く。
細い帯の中に格子点がいくつ入るかが $n$ ごとに変わるので、誤差は $n$ について単調に減るとは限らない。

`CubaturePlan` は 2 次元以上で、7 次の Genz–Malik 則と、それに埋め込んだ 5 次の則を使う適応求積である。
2 次元では 1 領域あたり 17 点で評価し、二つの則の差の 4 倍を領域の誤差推定とする。
誤差推定の和が許容誤差を満たすまで、誤差推定が最大の領域を、4 階差分が最大の軸に沿って二分する。
この誤差推定は経験的なもの（`ErrorReliability::Heuristic`）で、上界ではない。
許容誤差を満たして止まった場合の終了状態は `HeuristicToleranceReached` である。

次のブロックは三つのセルが共有する定義である。
`Aperture` が遮蔽のパラメータ $(d, w, \theta)$ を持ち、`baseline` が $B$、`intensity` が $I = BT$ を返す。
`product_gauss` は各軸 $n$ 点の Gauss–Legendre 則の積で積分し、`axis_aligned_power` は $\theta = 0$ の閉形式を `scioxide-special` の `erf` で計算する。

```rust
//| id: integrate-aperture-model
//| kind: definitions
//| title: 開口の強度分布と Gauss–Legendre の積型則
//| crates: [scioxide-core, scioxide-integrate, scioxide-special]
use scioxide_core::{SciOxideError, Interval, RealScalar};
use scioxide_integrate::{GaussianRulePlan, IntegrationReport, ProductRule};

/// 遮蔽帯に沿う方向の尺度 ℓ [-]。
pub(crate) const LONG_SCALE: f64 = 0.65;

/// 遮蔽の深さ d、横切る方向の半幅 w、角度 θ [rad]。
#[derive(Clone, Copy)]
pub(crate) struct Aperture {
    pub(crate) depth: f64,
    pub(crate) width: f64,
    pub(crate) angle: f64,
}

impl Aperture {
    /// 遮蔽のない強度 B(x, y) = (1 − x²)(1 − y²)。
    pub(crate) fn baseline(x: f64, y: f64) -> f64 {
        (1.0 - x * x) * (1.0 - y * y)
    }

    /// 強度 I(x, y) = B(x, y) T(x, y)、T = 1 − d exp(−(v/w)² − (u/ℓ)²)。
    pub(crate) fn intensity(&self, x: f64, y: f64) -> f64 {
        let (sine, cosine) = RealScalar::sin_cos(self.angle);
        let (u, v) = (cosine * x + sine * y, -sine * x + cosine * y);
        let exponent = RealScalar::powi(v / self.width, 2) + RealScalar::powi(u / LONG_SCALE, 2);
        Self::baseline(x, y) * (1.0 - self.depth * RealScalar::exp(-exponent))
    }

    /// θ = 0 の閉形式 16/9 − d J(ℓ) J(w)。
    pub(crate) fn axis_aligned_power(&self) -> Result<f64, SciOxideError> {
        Ok(16.0 / 9.0 - self.depth * moment(LONG_SCALE)? * moment(self.width)?)
    }
}

/// J(s) = ∫₋₁¹ (1 − x²) exp(−x²/s²) dx = s√π erf(1/s)(1 − s²/2) + s² exp(−1/s²)。
fn moment(s: f64) -> Result<f64, SciOxideError> {
    let root_pi = RealScalar::sqrt(core::f64::consts::PI);
    let error_function = scioxide_special::erf(1.0 / s)?;
    Ok(
        s * root_pi * error_function * (1.0 - 0.5 * s * s)
            + s * s * RealScalar::exp(-1.0 / (s * s)),
    )
}

/// 正方形 [−1, 1]²。
pub(crate) fn square() -> Result<[Interval<f64>; 2], SciOxideError> {
    let side = Interval::new(-1.0, 1.0)?;
    Ok([side, side])
}

/// 各軸 n 点の Gauss–Legendre 則の積で f を積分する。誤差推定は返らない。
pub(crate) fn product_gauss(
    n: usize,
    f: &(dyn Fn(&[f64]) -> Result<f64, SciOxideError> + Sync),
) -> Result<(f64, IntegrationReport<f64>), SciOxideError> {
    let rule = GaussianRulePlan::gauss_legendre(n)?;
    ProductRule::new(&rule, Default::default()).integrate(f, &square()?)
}
```

## 強度分布と参照値

遮蔽のパラメータと参照値は、後の二つのセルに渡す。

既定値（$d = 0.65$、$w = 0.12$、$\theta = 35^\circ$）では、参照値は $P = 1.648549$ で、遮蔽のない場の 92.7 % が透過する。
$\theta = 0$ にすると、参照値は閉形式 $1.6513021756587$ と $2.2 \times 10^{-16}$ の差で一致する。
回転した帯には閉形式がないので、参照値は次のセルで、別の方法である適応求積の値と比べて確かめる。
細く深い帯（$w = 0.04$、$d = 0.9$）では遮る面積が小さくなり、透過率は 96.6 % に上がる。

## 適応求積と積型則の比較

次のセルは前のセルの遮蔽と参照値を受け取り、積型則の各軸の点数 $n$ と、適応 Genz–Malik 求積の許容誤差 $\varepsilon$（絶対・相対とも）を選ぶ。
二分の上限は 4096 回に固定する。
表は二つの方法の透過量を、参照値との差、誤差推定、評価回数、終了状態とともに示す。
判定は適応 Genz–Malik 求積の終了状態を示す。

```rust
//| id: integrate-aperture-cubature
//| ref: integrate-aperture-cubature
//| title: 回転した遮蔽帯の透過量を積型則と適応求積で求める
//| run: reactive
//| uses: [integrate-aperture-model]
//| crates: [scioxide-core, scioxide-integrate, scioxide-special]
//| dependsOn:
//|   field: integrate-aperture-reference
//| inputs:
//|   product_order: {"type":"range","label":"積型則の各軸の点数 n","description":"積型則の評価回数 n² を変える。","min":2,"max":16,"step":1,"value":6}
//|   tolerance_exponent: {"type":"range","label":"適応求積の許容誤差の指数 p（ε = 10^p）","description":"絶対・相対許容誤差をそろえて変える。","min":-9,"max":-5,"step":1,"value":-7}
//| cases:
//|   - {"id":"tight","label":"ε = 10^-9","description":"許容誤差を厳しくすると、二分の上限 4096 回で止まり、判定は partial になる。","inputs":{"tolerance_exponent":-9}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"methods","path":"/rows/0/2","approx":{"value":2.9619e-2,"rtol":1e-3}}
//|       - {"artifact":"methods","path":"/rows/0/3","equals":null}
//|       - {"artifact":"methods","path":"/rows/1/2","range":{"max":1e-9}}
//|       - {"artifact":"methods","path":"/rows/1/5","equals":"HeuristicToleranceReached"}
//|       - {"path":"/outputs/1/state","equals":"satisfied"}
//|   - case: tight
//|     expect:
//|       - {"artifact":"methods","path":"/rows/1/5","equals":"BudgetLimit(Subdivision)"}
//|       - {"path":"/outputs/1/state","equals":"partial"}
use scioxide_core::{Budget, ErrorTolerance, NormSelection, RealScalar};
use scioxide_integrate::{CubaturePlan, SubdivisionOptions};

let number = |key: &str| field[key].as_f64().ok_or(format!("{key} がない"));
let aperture = Aperture {
    depth: number("depth")?,
    width: number("width")?,
    angle: RealScalar::to_radians(number("angle")?),
};
let reference = number("reference")?;
let intensity = |p: &[f64]| Ok(aperture.intensity(p[0], p[1]));
let product = product_gauss(product_order as usize, &intensity).map_err(|e| e.to_string())?;
let epsilon = RealScalar::exp10(tolerance_exponent);
let tolerance = ErrorTolerance::scalar(epsilon, epsilon, NormSelection::Infinity)
    .map_err(|e| e.to_string())?;
let options = SubdivisionOptions::default()
    .with_tolerance(tolerance)
    .with_max_subdivisions(Budget::try_from(4096).map_err(|e| e.to_string())?);
let bounds = square().map_err(|e| e.to_string())?;
let adaptive = CubaturePlan::new(&bounds, options)
    .map_err(|e| e.to_string())?
    .integrate(&intensity)
    .map_err(|e| e.to_string())?;

let rows: Vec<_> = [
    ("積型 Gauss–Legendre（各軸 n 点）", &product),
    ("適応 Genz–Malik", &adaptive),
]
.into_iter()
.map(|(name, (value, report))| {
    (
        name,
        *value,
        (value - reference).abs(),
        report.error_estimate(),
        report.evaluations(),
        report.termination().to_string(),
    )
})
.collect();
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let columns = serde_json::json!([
    { "key": "0", "label": "方法" },
    { "key": "1", "label": "透過量 P [-]", "type": "number", "format": { "significantDigits": 12 } },
    { "key": "2", "label": "参照値との差 [-]", "type": "number", "format": sci3 },
    { "key": "3", "label": "誤差推定 [-]", "type": "number", "format": sci3, "nullText": "なし（固定則）" },
    { "key": "4", "label": "評価回数 [回]", "type": "integer" },
    { "key": "5", "label": "終了状態" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "methods" })
);

let (value, report) = &adaptive;
let termination = report.termination();
let outcome = if termination.is_success() {
    Outcome::satisfied("適応求積の経験的な誤差推定が許容誤差を満たした")
} else {
    Outcome::partial("適応求積が許容誤差を満たす前に止まった")
        .explanation("返された値は推定値として読み、二分の上限か許容誤差を見直す。")
};
let mut outcome = outcome
    .status(termination.to_string())
    .diagnostic("評価回数", report.evaluations() as f64, None)
    .diagnostic("参照値との差", (value - reference).abs(), None);
if let Some(estimate) = report.error_estimate() {
    outcome = outcome.diagnostic("誤差推定", estimate, None);
}
emit_outcome!(outcome);
```

既定値（$n = 6$、$\varepsilon = 10^{-7}$）では、各軸 6 点（36 点）の積型則は参照値と $3.0 \times 10^{-2}$ ずれる。
終了状態は `FixedRuleCompleted` で誤差推定もないので、参照値がなければこの差に気づけない。
適応 Genz–Malik 求積は 31739 回の評価で `HeuristicToleranceReached` となり、参照値との差は $4 \times 10^{-11}$ だった。
節点の置き方が異なる二つの方法がこの差で一致するので、参照値の誤差もこの程度以下と見込める。
誤差推定は $2.6 \times 10^{-7}$ で、許容誤差 $\varepsilon(1 + |P|)$ をわずかに下回ったところで止まっている。
実際の差は推定より 4 桁小さく、この経験的な推定は実際の差より大きい側にある。

前のセルで $\theta = 0$ にすると、帯が格子の軸に沿い、各軸 6 点の積型則の差は $0.12$ に増える。
帯の中心線 $y = 0$ の上に節点がなく、帯の谷を挟む節点だけで積分するためである。
このとき適応求積は 7225 回の評価で済む。
帯が座標軸に沿うと、軸に沿った二分だけで帯を少ない領域に収められるためと考えられる。
前のセルで細く深い帯（$w = 0.04$、$d = 0.9$）にすると、適応求積の評価回数は 73695 回に増え、参照値との差は $9 \times 10^{-12}$ である。
$\varepsilon = 10^{-9}$ にすると、適応求積は二分の上限 4096 回に 139281 回の評価で達して `BudgetLimit(Subdivision)` で止まり、判定は partial になる。
このときも参照値との差は $6 \times 10^{-14}$ と小さいが、計算は精度を主張できない。

$\theta = 0$ では、各軸 96 点の積型則（9216 点）は閉形式と $2.2 \times 10^{-16}$ で一致し、7225 回評価した適応求積（差 $6.6 \times 10^{-11}$）より正確である。
被積分関数が解析的なので、Gauss 則の誤差は点数が十分に多いと速く減る。
適応求積の利点は必要な点数を前もって知らなくても細分を進め、誤差推定と終了状態を返すことにある。

## 積型則の点数と誤差

次のセルは最初のセルの遮蔽のパラメータと参照値を受け取り、各軸の点数 $n = 1, \ldots, 16$ の積型則で、遮蔽を含む場 $I$ と遮蔽のない場 $B$ を積分する。
$I$ の誤差は参照値との差、$B$ の誤差は $16/9$ との差である。
誤差が厳密に 0 の点は対数軸に描けないので除き、表には残す。

```rust
//| id: integrate-aperture-order-study
//| ref: integrate-aperture-order-study
//| title: 積型 Gauss–Legendre 則の点数と誤差
//| run: reactive
//| uses: [integrate-aperture-model]
//| crates: [scioxide-core, scioxide-integrate, scioxide-special]
//| dependsOn:
//|   field: integrate-aperture-reference
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"orders","path":"/rows/1/3","range":{"max":1e-13}}
//|       - {"artifact":"orders","path":"/rows/2/2","approx":{"value":0.3847,"atol":1e-3}}
//|       - {"artifact":"orders","path":"/rows/15/2","approx":{"value":1.0009e-5,"rtol":1e-3}}
use scioxide_core::RealScalar;

let number = |key: &str| field[key].as_f64().ok_or(format!("{key} がない"));
let aperture = Aperture {
    depth: number("depth")?,
    width: number("width")?,
    angle: RealScalar::to_radians(number("angle")?),
};
let reference = number("reference")?;
let intensity = |p: &[f64]| Ok(aperture.intensity(p[0], p[1]));
let baseline = |p: &[f64]| Ok(Aperture::baseline(p[0], p[1]));

let (mut obstructed, mut polynomial, mut rows) = (Vec::new(), Vec::new(), Vec::new());
for n in 1_usize..=16 {
    let obstructed_error =
        (product_gauss(n, &intensity).map_err(|e| e.to_string())?.0 - reference).abs();
    let polynomial_error =
        (product_gauss(n, &baseline).map_err(|e| e.to_string())?.0 - 16.0 / 9.0).abs();
    if obstructed_error > 0.0 {
        obstructed.push([n as f64, obstructed_error]);
    }
    if polynomial_error > 0.0 {
        polynomial.push([n as f64, polynomial_error]);
    }
    rows.push((n, n * n, obstructed_error, polynomial_error));
}
emit_line_chart!(
    &vec![
        serde_json::json!({ "name": "遮蔽を含む場 I", "points": obstructed }),
        serde_json::json!({ "name": "遮蔽のない場 B", "points": polynomial }),
    ],
    options = &serde_json::json!({
        "xLabel": "各軸の点数 n",
        "yLabel": "誤差 [-]",
        "yType": "log",
        "xMin": 1.0,
        "xMax": 16.0
    })
);
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let columns = serde_json::json!([
    { "key": "0", "label": "各軸の点数 n", "type": "integer" },
    { "key": "1", "label": "評価回数 n² [回]", "type": "integer" },
    { "key": "2", "label": "I の参照値との差 [-]", "type": "number", "format": sci3 },
    { "key": "3", "label": "B の 16/9 との差 [-]", "type": "number", "format": sci3 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "orders" })
);
```

既定値の場では、遮蔽のない場 $B$ の誤差は $n = 2$（4 点）で $10^{-15}$ の丸め誤差の水準に下がり、以後もその水準にとどまる。
遮蔽を含む場 $I$ の誤差は、$n = 1$ から 6 まで $0.25$、$0.098$、$0.38$、$0.028$、$0.094$、$0.030$ と上下する。
$n$ を変えるとすべての節点が動き、帯の谷に落ちる節点の数が変わるためである。
$n = 7$（49 点）の $0.024$ から先は単調に減り、$n = 16$（256 点）で $1.0 \times 10^{-5}$ になる。
減り方はほぼ等比的である。
Gauss 則の誤差は被積分関数を多項式で近似する誤差で決まり、帯の半幅 $w$ が小さいほど近似に高い次数が要るので、$w$ を狭めると減り方が遅くなる。
$n = 16$ での誤差は、最初のセルで $w = 0.24$ にすると $4.3 \times 10^{-12}$ まで下がり、$w = 0.04$ にすると $7.8 \times 10^{-4}$ にとどまる。
低い次数で 2 つの $n$ の結果が近くても、それを収束の証拠にしない。

## まとめ

変数分離できる多項式の場は、各軸の Gauss 則の厳密次数が足りれば数点で丸め誤差の水準まで積分できる。
座標軸に沿わない細い構造を含む場では、積型則の誤差は低い次数で単調に減らず、誤差推定もないので、各軸 96 点のように点数を増やした参照値で確かめる。
適応 `CubaturePlan` は局所的な変化に合わせて領域を細分し、経験的な誤差推定と `HeuristicToleranceReached` を返すが、解析的な被積分関数では高次の積型則の方が少ない評価で正確になることがある。
二分の上限で止まった `BudgetLimit(Subdivision)` は partial として扱い、許容誤差か上限を見直す。
遮蔽が軸に沿う場合の閉形式や、節点の置き方が異なる適応求積との一致のように、参照値そのものを独立に確かめる手段を一つは用意する。
