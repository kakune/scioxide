温度 $T$ の黒体が放射するエネルギーは、波長について積分すると $\sigma T^4$（Stefan–Boltzmann の法則）になる。
係数 $\sigma$ は Planck 分布の半無限区間の積分で決まり、波長 $\lambda$ より短い帯域に出る割合（帯域率）も同じ被積分関数の積分で表せる。
この例題ではその積分を三つの方法で求めて比べ、物理定数から $\sigma$ を再現する。
放射が最大になる波長（Wien の変位則）は[Lambert W による Wien の変位則とダイオード方程式](../../../scioxide-special/examples/lambert-w-wien-and-diode/)が扱い、ここでは帯域率の目安として値だけを使う。

## Planck 分布と無次元の積分

黒体の分光放射輝度は

$$
B_\lambda(\lambda, T) = \frac{2hc^2}{\lambda^5}\,\frac{1}{e^{hc/(\lambda k T)} - 1}
$$

である。
$h = 6.62607015 \times 10^{-34}$ J s は Planck 定数、$k = 1.380649 \times 10^{-23}$ J/K は Boltzmann 定数、$c = 299792458$ m/s は光速で、どれも SI の定義値である。
半球に出る放射の発散度を $M = \int_0^\infty \pi B_\lambda\,d\lambda$ とする。
$x = C_2/(\lambda T)$、$C_2 = hc/k$ と置換すると、

$$
M = \frac{2\pi k^4 T^4}{h^3 c^2}\,I, \qquad I = \int_0^\infty \frac{x^3}{e^x - 1}\,dx = \frac{\pi^4}{15}
$$

を得る。
第二放射定数は $C_2 = hc/k = 14387.77\ \mu\mathrm{m\,K}$ で、$\sigma = 2\pi k^4 I/(h^3c^2) = 2\pi^5 k^4/(15 h^3 c^2)$ は $5.670374419 \times 10^{-8}$ W m⁻² K⁻⁴ になる（CODATA 2018 の値）。

波長 $0$ から $\lambda$ までの帯域に出る割合は、$\lambda < \lambda_0$ が $x > x_0$ に対応するので

$$
F(0 \to \lambda T) = \frac{15}{\pi^4}\int_{x_0}^\infty \frac{x^3}{e^x - 1}\,dx, \qquad x_0 = \frac{C_2}{\lambda T}
$$

である。
$F$ は $\lambda$ と $T$ の積 $\lambda T$ だけの関数で、放射温度計の帯域の設計や、ウインドウガラスを通る太陽放射の割合の見積もりに使う。
Wien の変位則による最大の波長 $\lambda_{\max} T = 2897.77\ \mu\mathrm{m\,K}$ では $F \approx 0.25$ で、放射の 4 分の 1 がピークより短い波長に出る。

## 三つの求め方

**二重指数変換。**
半無限区間 $[x_0, \infty)$ に exp–sinh 変換 $x = x_0 + \exp(\tfrac{\pi}{2}\sinh t)$ を使う（`DoubleExponentialDomain::HalfLine`）。
変換の変数 $t$ を 1 増やすごとに $x$ は二重指数的に大きくなり、尾部の追加区間を数個延ばすだけで節点は $x = 10^3$ を大きく超える。
$e^x$ は $x > 709$ で倍精度の範囲を超えるので、直接計算するとあふれる。
$x^3/(e^x - 1) = x^2 e^{-x}/\operatorname{exprel}(-x)$ と書く。
$\operatorname{exprel}(y) = (e^y - 1)/y$ は scioxide-core の `exprel` で、$\operatorname{exprel}(-x) = (1 - e^{-x})/x$ は $x = 0$ でも $x \to \infty$ でも有限の値を返す。

**一般化 Laguerre 重みの Gauss 則。**
全区間の積分では重み $x^{\alpha}e^{-x}$ を則に持たせ、残りの因子を多項式で近似する。

$$
\frac{x^3}{e^x - 1} = x^2 e^{-x}\cdot\frac{x}{1 - e^{-x}}
$$

と分けると、$x/(1 - e^{-x}) = 1/\operatorname{exprel}(-x)$ は $x = 0$ で 1 に近づく滑らかな関数で、$\alpha = 2$ の一般化 Laguerre 則がそのまま使える。
$x^3e^{-x}\cdot 1/(1 - e^{-x})$ と分けて $\alpha = 3$ にすると、残りの因子は $x = 0$ で $1/x$ のように発散し、多項式で近似できない。
帯域率の積分 $[x_0, \infty)$ では $x = x_0 + y$ と置き、

$$
\int_{x_0}^\infty \frac{x^3}{e^x - 1}\,dx = \int_0^\infty e^{-y}\,\frac{(x_0 + y)^2 e^{-x_0}}{\operatorname{exprel}\bigl(-(x_0 + y)\bigr)}\,dy
$$

と書く。
右辺の重みは $\alpha = 0$ の Laguerre 重み $e^{-y}$ で、`GaussianSupport::HalfLine(x₀)` が節点を $x_0$ だけずらす。
$x_0 > 0$ では被積分関数が下端で $x_0^3/(e^{x_0} - 1) \ne 0$ なので、$y^2$ を重みに含める $\alpha = 2$ の分け方は使えない。

**級数。**
$x > 0$ では $1/(e^x - 1) = \sum_{n \ge 1} e^{-nx}$ なので、項ごとに積分すると（項は正なので和と積分を交換できる）

$$
\int_{x_0}^\infty \frac{x^3}{e^x - 1}\,dx = \sum_{n=1}^\infty J_3(n), \qquad
J_m(t) = \int_{x_0}^\infty x^m e^{-tx}\,dx = e^{-t x_0}\sum_{j=0}^{m}\frac{m!}{(m - j)!}\,\frac{x_0^{m-j}}{t^{j+1}}
$$

となる。
$J_3(n) = e^{-nx_0}\bigl(x_0^3/n + 3x_0^2/n^2 + 6x_0/n^3 + 6/n^4\bigr)$ で、$x_0 = 0$ では $\sum 6/n^4 = 6\zeta(4) = \pi^4/15$ になる。
$x_0$ が小さい（$\lambda T$ が大きい）と項は $6/n^4$ のようにしか減らないので、和を加速する必要がある。

`SeriesSummation` の `EulerMaclaurin` は尾部 $\sum_{k \ge n} f(k)$ を積分と端点の奇数階導関数の補正で近似し、剰余の上界 $(|B_{2p}|/(2p)!)\int_n^\infty |f^{(2p)}|$ を返す（[Euler–Maclaurin 和と条件付きの上界](../../algorithms/euler-maclaurin-summation/)）。
$f(t) = J_3(t)$ は $t$ について滑らかで、導関数も同じ形の積分になる。

$$
f^{(k)}(t) = (-1)^k J_{3+k}(t), \qquad \int_n^\infty f(t)\,dt = J_2(n), \qquad \int_n^\infty \bigl|f^{(2p)}(t)\bigr|\,dt = J_{2+2p}(n)
$$

偶数階の導関数は正なので、絶対値の積分も閉形式になる。
プロバイダーがこれらを正しく返すという条件のもとで、上界が許容誤差を下回れば `BoundedTailReached`（成功）で止まる。
比較に使う Levin の u 変換は項だけから外挿し、連続する推定値の一致で止まるので、成功の終了状態は `HeuristicToleranceReached` で、上界は付かない。

次の定義のブロックはモデルを表し、三つのセルで共有する。
`planck(x)` が被積分関数 $x^2e^{-x}/\operatorname{exprel}(-x)$、`moment(m, t, x₀)` が $J_m(t)$ で、`BandSeries` は項 $J_3(n)$ と Euler–Maclaurin の尾部の情報を返すプロバイダーである。
プロバイダーが提示する誤差は、正の項の和に対する丸めの尺度 $64\varepsilon|\text{値}|$ とする。

```rust
//| id: integrate-blackbody-model
//| kind: definitions
//| title: Planck の被積分関数と Euler–Maclaurin のプロバイダー
//| crates: [scioxide-core, scioxide-integrate]
use scioxide_core::{SciOxideError, RealScalar, exprel};
use scioxide_integrate::{EulerMaclaurinProvider, SeriesTerms};

/// SI の定義値: Planck 定数 [J s]、Boltzmann 定数 [J/K]、光速 [m/s]。
pub(crate) const PLANCK: f64 = 6.626_070_15e-34;
pub(crate) const BOLTZMANN: f64 = 1.380_649e-23;
pub(crate) const LIGHT: f64 = 299_792_458.0;

/// x³/(eˣ − 1) = x² e^(−x) / exprel(−x)。大きな x でもあふれない。
pub(crate) fn planck(x: f64) -> Result<f64, SciOxideError> {
    Ok(x * x * RealScalar::exp(-x) / exprel(-x)?)
}

/// J_m(t) = ∫_{x₀}^∞ x^m e^(−tx) dx = e^(−t x₀) Σ_j m!/(m−j)! x₀^(m−j) / t^(j+1)。
pub(crate) fn moment(m: usize, t: f64, x0: f64) -> f64 {
    let (mut sum, mut falling) = (0.0, 1.0);
    for j in 0..=m {
        sum += falling * RealScalar::powi(x0, (m - j) as i32) / RealScalar::powi(t, j as i32 + 1);
        falling *= (m - j) as f64;
    }
    RealScalar::exp(-t * x0) * sum
}

/// 項 J₃(n) と、f(t) = J₃(t) の尾部の積分・奇数階導関数・偶数階導関数の L¹ ノルム。
pub(crate) struct BandSeries(pub(crate) f64);

impl SeriesTerms<f64> for BandSeries {
    fn term(&self, n: usize, out: &mut [f64]) -> Result<(), SciOxideError> {
        out[0] = moment(3, n as f64, self.0);
        Ok(())
    }
}

impl EulerMaclaurinProvider<f64> for BandSeries {
    fn tail_integral(
        &self,
        at: usize,
        value: &mut [f64],
        error: &mut [f64],
    ) -> Result<(), SciOxideError> {
        value[0] = moment(2, at as f64, self.0);
        error[0] = 64.0 * f64::EPSILON * value[0];
        Ok(())
    }
    fn odd_derivative(
        &self,
        at: usize,
        order: usize,
        value: &mut [f64],
        error: &mut [f64],
    ) -> Result<(), SciOxideError> {
        value[0] = -moment(3 + order, at as f64, self.0);
        error[0] = 64.0 * f64::EPSILON * value[0].abs();
        Ok(())
    }
    fn even_derivative_l1_bound(
        &self,
        at: usize,
        order: usize,
        bound: &mut [f64],
    ) -> Result<(), SciOxideError> {
        bound[0] = moment(2 + order, at as f64, self.0) * (1.0 + 64.0 * f64::EPSILON);
        Ok(())
    }
}

```

次の定義のブロックは同じ積分を求める方法を名前で呼べるようにまとめる。
`half_line` は下端 0 の exp–sinh 変換を一度だけ準備し、`by_double_exponential` は $\int_{x_0}^\infty f(x)\,dx = \int_0^\infty f(x_0 + y)\,dy$ としてそれを使う。
節点の表の準備は $x_0$ によらないので、$x_0$ を変える計算でも Plan を作り直さない。
`by_laguerre` はずらした Laguerre 則、`by_series` は級数で求める。
どれも値、誤差の見積もり、評価回数、終了状態を `Estimate` にまとめる。
`BandRoutes` は帯域率の二つのセルが使う六つの方法を名前で選ぶ。

```rust
//| id: integrate-blackbody-routes
//| kind: definitions
//| title: 半無限区間の積分を求める方法
//| uses: [integrate-blackbody-model]
//| crates: [scioxide-core, scioxide-integrate, scioxide-poly]
use scioxide_core::{ErrorTolerance, SciOxideError, NormSelection, RealScalar, exprel};
use scioxide_integrate::{
    DoubleExponentialDomain, DoubleExponentialIntegrator, DoubleExponentialPoint,
    GaussianRulePlan, GaussianSupport, IntegrationReport, LevelOptions, SeriesMethod,
    SeriesOptions, SeriesProblem, SeriesSummation,
};
use scioxide_poly::OrthogonalFamily;

/// 値、誤差の見積もり（ない場合は None）、評価回数、終了状態。
pub(crate) struct Estimate {
    pub(crate) value: f64,
    pub(crate) error: Option<f64>,
    pub(crate) evaluations: usize,
    pub(crate) status: String,
}

impl Estimate {
    /// 求積の値とレポートをまとめる。
    pub(crate) fn integral(value: f64, report: &IntegrationReport<f64>) -> Self {
        Estimate {
            value,
            error: report.error_estimate(),
            evaluations: report.evaluations(),
            status: report.termination().to_string(),
        }
    }
}

/// 下端 0 の半無限区間の exp–sinh 変換を一度だけ準備する（節点の表は x₀ によらない）。
pub(crate) fn half_line(
    options: LevelOptions<f64>,
) -> Result<DoubleExponentialIntegrator<f64>, SciOxideError> {
    DoubleExponentialIntegrator::new(DoubleExponentialDomain::HalfLine { lower: 0.0 }, options)
}

/// ∫_{x₀}^∞ x³/(eˣ − 1) dx = ∫₀^∞ f(x₀ + y) dy を準備済みの exp–sinh 変換で求める。
pub(crate) fn by_double_exponential(
    de: &DoubleExponentialIntegrator<f64>,
    x0: f64,
) -> Result<Estimate, SciOxideError> {
    let (value, report) =
        de.integrate(|p: DoubleExponentialPoint<f64>| planck(x0 + p.coordinate()))?;
    Ok(Estimate::integral(value, &report))
}

/// 同じ積分を x = x₀ + y でずらした n 点 Laguerre 則（α = 0）で求める。
/// 重み e^(−y) を除いた因子は x² e^(−x₀)/exprel(−x)。
pub(crate) fn by_laguerre(x0: f64, nodes: usize) -> Result<Estimate, SciOxideError> {
    let rule = GaussianRulePlan::<f64>::new(OrthogonalFamily::Laguerre, nodes)?;
    let factor = |x: f64| Ok(x * x * RealScalar::exp(-x0) / exprel(-x)?);
    let (value, report) = rule.integrate_weighted(&factor, GaussianSupport::HalfLine(x0))?;
    Ok(Estimate::integral(value, &report))
}

/// 同じ積分を級数 Σ J₃(n) の和として求める。
pub(crate) fn by_series(
    x0: f64,
    method: SeriesMethod,
    tolerance: ErrorTolerance<f64>,
) -> Result<Estimate, SciOxideError> {
    let plan = SeriesSummation::<f64>::new(
        method,
        1,
        SeriesOptions::default().with_tolerance(tolerance),
    )?;
    let provider = BandSeries(x0);
    let problem = match method {
        SeriesMethod::EulerMaclaurin => SeriesProblem::EulerMaclaurin(&provider),
        _ => SeriesProblem::Terms(&provider),
    };
    let result = plan.sum(problem)?;
    // 判定に使う誤差: Euler–Maclaurin は提示内容誤差 + 剰余の上界 + 丸め、加速法は max(外挿の変化, 丸め)。
    let e = result.error();
    let error = e
        .provider()
        .zip(e.tail_bound())
        .map(|(p, t)| p + t + e.roundoff())
        .or(e.acceleration().map(|a| a.max(e.roundoff())));
    let report = result.report();
    let status = report.termination().to_string();
    Ok(Estimate {
        value: result.value(),
        error,
        evaluations: report.provider_calls(),
        status,
    })
}

/// 帯域率の方法を名前で選ぶ。二つの exp–sinh 変換は一度だけ準備し、全部の x₀ で使い回す。
pub(crate) struct BandRoutes {
    de_default: DoubleExponentialIntegrator<f64>,
    de_relative: DoubleExponentialIntegrator<f64>,
    relative: ErrorTolerance<f64>,
    tight: ErrorTolerance<f64>,
}

impl BandRoutes {
    /// 相対許容誤差 10⁻¹²（基準の Euler–Maclaurin 和だけ 10⁻¹³）と既定の許容誤差を準備する。
    pub(crate) fn new() -> Result<Self, SciOxideError> {
        let relative = ErrorTolerance::scalar(0.0, 1e-12, NormSelection::Infinity)?;
        Ok(BandRoutes {
            de_default: half_line(LevelOptions::default())?,
            de_relative: half_line(LevelOptions::default().with_tolerance(relative.clone()))?,
            relative,
            tight: ErrorTolerance::scalar(0.0, 1e-13, NormSelection::Infinity)?,
        })
    }

    /// route は "de-default"、"de-relative"、"laguerre-8"、"laguerre-32"、"levin"、
    /// "euler-maclaurin"（基準）。
    pub(crate) fn estimate(&self, route: &str, x0: f64) -> Result<Estimate, SciOxideError> {
        match route {
            "de-default" => by_double_exponential(&self.de_default, x0),
            "de-relative" => by_double_exponential(&self.de_relative, x0),
            "laguerre-8" => by_laguerre(x0, 8),
            "laguerre-32" => by_laguerre(x0, 32),
            "levin" => by_series(x0, SeriesMethod::LevinU, self.relative.clone()),
            _ => by_series(x0, SeriesMethod::EulerMaclaurin, self.tight.clone()),
        }
    }
}

/// 第二放射定数 C₂ = hc/k [μm K]。
pub(crate) fn second_radiation_constant() -> f64 {
    PLANCK * LIGHT / BOLTZMANN * 1e6
}
```

## 全放射と Stefan–Boltzmann 定数

次のセルは $I = \int_0^\infty x^3/(e^x - 1)\,dx$ を五つの方法で求め、$\pi^4/15$ と比べる。
二重指数変換、$\alpha = 2$ と $\alpha = 3$ の一般化 Laguerre 則（$n$ 点）、Euler–Maclaurin 和、Levin の u 変換である。
入力は Laguerre 則の点数 $n$ と、二重指数変換と級数の相対許容誤差 $10^q$ で、絶対許容誤差は 0 にする。
Euler–Maclaurin 和の推定誤差の列は、プロバイダーの提示内容どおりなら成り立つ上界である。
ほかの方法の推定誤差は上界ではなく、Gauss 則は推定誤差を持たない。

二つ目の表は閉形式 $2\pi^5k^4/(15h^3c^2)$ と、二重指数変換で求めた $I$ を使う $2\pi k^4 I/(h^3c^2)$ を、CODATA 2018 の値 $5.670374419 \times 10^{-8}$ と比べる。
CODATA の値は定義値の定数から決まる量を 10 桁に丸めたものなので、相対差は $10^{-10}$ 程度までしか意味を持たない。

既定の入力（$n = 16$、$q = -12$）では、二重指数変換は 173 回の評価で `HeuristicToleranceReached` となり、$\pi^4/15$ との相対誤差は $2.2 \times 10^{-16}$ だった。
$\alpha = 2$ の Laguerre 則は 16 点で $1.0 \times 10^{-10}$、64 点で丸めの水準に達する。
$\alpha = 3$ では 16 点で $3.2 \times 10^{-4}$、64 点でも $6.4 \times 10^{-6}$ で、点数を 4 倍にしても誤差は 50 分の 1 程度にしかならない。
重みの指数を 1 つ変えただけで、残りの因子が $x = 0$ で滑らかかどうかが変わり、収束の型が指数的から代数的に変わる。

Euler–Maclaurin 和は 66 回のプロバイダー呼出しで `BoundedTailReached` となり、実際の相対誤差 $1.1 \times 10^{-13}$ は示された上界 $5.6 \times 10^{-13}$ の内側にある。
$q = -6$ に緩めると、33 回の呼出しで止まり、誤差 $1.4 \times 10^{-7}$ が上界 $2.9 \times 10^{-7}$ の内側にある。
Levin の u 変換は 15 回の呼出しで相対誤差 $3.0 \times 10^{-14}$ に達し、`HeuristicToleranceReached`（成功）で止まるが、上界は付かない。
値が合っていても、Levin の推定誤差は連続する外挿値の変化から作った目安で、上界ではない。
$q = -14$ に締めると、要求が丸めの水準に近すぎてどの適応的な方法も成功しない。
二重指数変換は 327 回の評価で `Stagnation`、Euler–Maclaurin 和と Levin の u 変換は項数の上限で `TermLimit` になる。
値そのものは $\pi^4/15$ と $3 \times 10^{-15}$ 以内で一致するが、終了状態は許容誤差に達したことを示さない。

$\sigma$ の閉形式は $5.6703744191844 \times 10^{-8}$ W m⁻² K⁻⁴ で、CODATA の 10 桁の値との相対差 $3.3 \times 10^{-11}$ は CODATA の値の丸めの幅に収まる。
二重指数変換の $I$ を使う値は閉形式と 15 桁で一致する。

## 帯域率と λT

帯域率 $F(0 \to \lambda T)$ を二つのセルで調べる。
基準はどちらも Euler–Maclaurin 和（相対許容誤差 $10^{-13}$）で、`BoundedTailReached` で止まった値にはプロバイダーの提示内容のもとで成り立つ上界が付く。
比べる方法は五つある。
既定の許容誤差（絶対・相対とも $\sqrt\varepsilon \approx 1.5 \times 10^{-8}$）の二重指数変換、相対許容誤差 $10^{-12}$ だけの二重指数変換、8 点と 32 点のずらした Laguerre 則、Levin の u 変換である。

### λT の全範囲での相対差

次のセルは $\lambda T = 300$ から $10^5\ \mu\mathrm{m\,K}$ までの 61 点で、基準による $F$ と、選んだ手法オブジェクトと基準との相対差を描く。
一つ目のグラフの破線は Wien の変位則の $\lambda_{\max}T = 2897.77\ \mu\mathrm{m\,K}$ である。
二つのグラフは横軸の拡大と移動が連動する。
相対差がちょうど 0 の点は対数軸に描けないので除き、その数と、基準が `BoundedTailReached` で止まらなかった点の数を表に示す。

既定の許容誤差の二重指数変換は、$\lambda T$ が小さい側で相対差が急に増え、$\lambda T = 316\ \mu\mathrm{m\,K}$ では $2.1 \times 10^{-3}$ になる。
$F$ が小さい側では積分そのものが既定の絶対許容誤差 $1.5 \times 10^{-8}$ より小さくなり、絶対誤差の条件だけで停止の判定を満たしてしまうからである（次の節で数値を示す）。
相対許容誤差 $10^{-12}$ だけの二重指数変換と 32 点の Laguerre 則は、全範囲で相対差が $5 \times 10^{-14}$ 以下になる。
$\lambda T \gtrsim 1500\ \mu\mathrm{m\,K}$ でそれらの相対差が $10^{-15}$ から $3 \times 10^{-14}$ に並ぶのは、基準の Euler–Maclaurin 和の側の誤差である。

8 点の Laguerre 則は逆に $\lambda T$ が大きい側で悪くなり、$\lambda T = 10^5\ \mu\mathrm{m\,K}$ では相対差が $5.5 \times 10^{-7}$ になる。
$x_0$ が大きいと $1/(1 - e^{-x})$ はほぼ 1 で、重み $e^{-y}$ を除いた因子 $x^3e^{-x_0}/(1 - e^{-x})$ は $y$ のほぼ 3 次の多項式なので、少ない点数で正確になる。
$x_0$ が小さいと、この因子が $x = 0$ の近くで 1 から離れ、$x = \pm 2\pi i$ の極が近いので多項式近似の収束が遅くなる。
Levin の u 変換も $\lambda T$ が大きい側で相対差が増え、$\lambda T = 10^5\ \mu\mathrm{m\,K}$ では $2.2 \times 10^{-13}$ になる。
項が $6/n^4$ のように代数的にしか減らない側では、外挿の精度が下がる。

### 選んだ λT での比較

```rust
let quantities = vec![("λT [μm K]", lambda_t), ("x₀ = C₂/(λT) [-]", x0), ("C₂ [μm K]", c2)];
emit_table_with_columns!(
    columns,
    quantities,
    metadata = serde_json::json!({ "id": "quantities" })
);
```

既定の入力（$\lambda T = 2897\ \mu\mathrm{m\,K}$、Wien のピークの位置）では $F = 0.249957$ で、放射の 4 分の 1 がピークより短い波長に出る。
二重指数変換（両方の許容誤差）、32 点の Laguerre 則、Levin の u 変換、Debye 関数による値は互いに $10^{-15}$ 程度で一致し、基準の Euler–Maclaurin 和とは $1.3 \times 10^{-14}$ から $1.4 \times 10^{-14}$ 異なる。
この差は基準の側の誤差で、Euler–Maclaurin 和が返した上界 $4.5 \times 10^{-14}$ の内側にある。

$\lambda T = 500\ \mu\mathrm{m\,K}$ では $F = 1.30 \times 10^{-9}$ で、既定の許容誤差で求めた二重指数変換の値は基準と相対 $1.9 \times 10^{-3}$ 違う。
積分そのもの（$F$ の $\pi^4/15$ 倍で $8.4 \times 10^{-9}$）が絶対許容誤差 $1.5 \times 10^{-8}$ より小さいので、37 回の評価で停止の判定を満たす。
示された推定誤差を値で割ると $7.5 \times 10^{-2}$ で、相対精度が足りないことはレポートからも読み取れる。
絶対許容誤差を 0 にした二重指数変換は同じ点で相対差 $2.2 \times 10^{-16}$ になる。
小さな量を相対精度で求めるときは、絶対許容誤差を量の大きさに合わせるか 0 にする。

$\lambda T = 3 \times 10^4\ \mu\mathrm{m\,K}$ では 8 点の Laguerre 則の相対差が $3.8 \times 10^{-7}$ になり、32 点では $5 \times 10^{-15}$ である。
Debye 関数による値は、$F$ が 1 に近い側では基準と $10^{-15}$ 程度で一致するが、$\lambda T = 500\ \mu\mathrm{m\,K}$ では $1 - (1 \text{ に近い数})$ の桁落ちで相対差が $1.2 \times 10^{-7}$ に増える。
$\lambda T = 316\ \mu\mathrm{m\,K}$ では $F = 2.7 \times 10^{-16}$ が 1 に近い項の丸め誤差と同じ程度になり、この式は 0 を返す。

## まとめ

Stefan–Boltzmann 定数は $\int_0^\infty x^3/(e^x - 1)\,dx = \pi^4/15$ で決まり、SI の定義値の定数から CODATA の値を 10 桁まで再現できる。
被積分関数は $x^2e^{-x}/\operatorname{exprel}(-x)$ と書くと、二重指数変換の遠方の節点でもあふれない。
Laguerre 型の Gauss 則では、重みに含める $x^\alpha$ を残りの因子が滑らかになるように選ぶ必要があり、全区間では $\alpha = 2$、帯域率の $[x_0, \infty)$ ではずらした $\alpha = 0$ の重みを使う。
級数 $\sum J_3(n)$ は Euler–Maclaurin 和で `BoundedTailReached` まで進めるとプロバイダーの前提のもとでの上界が付き、Levin の u 変換は値が合っても `HeuristicToleranceReached` で止まり、上界は付かない。
帯域率のように $\lambda T$ によって $10^{-16}$ から 1 まで変わる量では、既定の絶対許容誤差が相対精度を損なうので、許容誤差を量の大きさに合わせる。
