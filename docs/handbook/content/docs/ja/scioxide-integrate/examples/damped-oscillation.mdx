減衰振動はRLC 回路の過渡電流、構造物の自由振動、核磁気共鳴の自由誘導減衰など、多くの系の応答に現れる。
信号の時間積分は回路を流れた正味の電荷や、応答の Laplace 変換の値にあたる。
高周波の減衰振動では正の山と負の谷がほぼ打ち消し合うので、積分値は信号の大きさに比べてずっと小さく、誤差の基準の選び方が結果を左右する。
この例題では振動を重みとして扱う求積で有限時刻までの積分を求め、無限区間の積分を周期ごとの和の外挿で求めて、どちらも閉形式と照合する。

## 減衰振動と積分の閉形式

減衰率 $a > 0$ [s⁻¹]、角周波数 $\omega > 0$ [rad/s] の無次元の信号

$$
f(t) = e^{-a t}\cos(\omega t)
$$

を考える。
時定数は $\tau = 1/a$、周期は $P = 2\pi/\omega$ で、1 時定数の間に $\omega/(2\pi a)$ 回振動する。
たとえば振幅 $I_0$ の電流 $I_0 f(t)$ なら、$I_0 \int f\,dt$ が流れた電荷になる。
以下では $f$ を無次元とし、積分の単位を s とする。

部分積分を 2 回使うと、原始関数は

$$
F(t) = \frac{e^{-at}\left[-a\cos(\omega t) + \omega\sin(\omega t)\right]}{a^2 + \omega^2}
$$

である。
したがって時刻 $T$ までの積分と無限区間の積分は

$$
I(T) = \int_0^T f(t)\,dt = F(T) - F(0), \qquad
I_\infty = \int_0^\infty f(t)\,dt = \frac{a}{a^2 + \omega^2}
$$

となる。
$I_\infty$ は Laplace 変換 $\mathcal{L}\{f\}(s) = (s + a)/[(s + a)^2 + \omega^2]$ の $s = 0$ での値でもある。
$\omega \gg a$ では $I_\infty \approx a/\omega^2$ で、信号の大きさ 1 に比べて $\omega^{-2}$ の桁まで小さくなる。

## 正負の相殺と誤差の基準

相殺の大きさは絶対値の積分 $A(T) = \int_0^T |f(t)|\,dt$ との比

$$
C(T) = \frac{|I(T)|}{A(T)}
$$

で表せる。
$A(T)$ は $\cos(\omega t)$ の零点 $t_k = (k + \tfrac{1}{2})\pi/\omega$ で区間を区切り、各半周期の積分 $F(t_{k+1}) - F(t_k)$ の絶対値を足せば閉形式から求まる。
$C(T) \ll 1$ のとき、積分値は大きさがほぼ等しい正負の寄与の差で決まる。

この場合、相対許容誤差 $\varepsilon_{\mathrm{rel}}|Q|$ は小さな $|Q|$ に比例して厳しくなり、積分値が 0 を横切る $T$ の近くでは意味を失う。
信号の大きさの尺度は $A(T)$ なので、物理的に意味のある絶対許容誤差 $\varepsilon_{\mathrm{abs}}$ を与えて停止を制御する。

## 振動を重みとして扱う求積

`WeightedQuadraturePlan::fourier` は $\int_a^b g(t)\cos(\omega t)\,dt$ の形の積分を扱い、コールバックは滑らかな振幅 $g(t) = e^{-at}$ だけを返す。
$\cos(\omega t)$ を掛けた値を返すと、重みと二重に掛かって別の積分になる。

各領域の半幅を $h$ とすると、$|\omega| h > 2$ の領域では、$g$ の Chebyshev 補間に $\cos(\omega t)$ の修正モーメントを掛けて積分する修正 Clenshaw–Curtis 則を使う。
振動は重みが厳密に受け持つので、評価の回数は $g$ の滑らかさで決まり、区間に含まれる半周期の数には比例しない。
$|\omega| h \le 2$ の領域では、積 $g(t)\cos(\omega t)$ に Gauss–Kronrod 則を使う。
誤差推定は入れ子になった二つの則の差から作り、修正モーメントの領域では Chebyshev 係数の上位 2 項による推定と比べて大きい方をとる。
修正モーメントを用意する二分の深さは `WeightedQuadratureOptions::with_moment_levels` で決まり、既定は 16 段である。
この深さに達しても $|\omega| h > 2$ の領域はそれ以上二分せず、許容誤差を満たさなければ `RefinementLimit` で止まる。
これは Fourier 重み付き求積である（[振動積分の相殺と Fourier 積分の尾部](oxref:integrate-fourier-weight-moments)）。

## 無限区間の積分と周期ごとの和

無限区間の $I_\infty$ は時刻 $T$ で打ち切らずに `FourierTailPlan` で直接求められる。
`FourierDomain::Upper { lower: 0.0 }` は半直線 $[0, \infty)$ を表す。
Plan は半直線を長さ

$$
L = \frac{(2\lfloor|\omega|\rfloor + 1)\pi}{|\omega|}
$$

の区間（奇数個の半周期）に分け、各区間の積分を上の Fourier 型の求積で求める。
奇数個の半周期をまとめるので、続く区間の積分は符号が交互に変わり、部分和は交代級数になる。
部分和の列を Wynn の ε アルゴリズムで外挿し、外挿値の変化から裾の寄与を推定する。

この裾の推定は経験的である。
Plan は少なくとも 6 区間を積分し、区間の積分の大きさと標本化した $|g|$ の最大値がどちらも 3 区間続けて $|t|^{-1/5}$ 以上の速さで減ることを確かめてから、推定を受け入れる。
推定が許容誤差を満たすと、終了状態は `HeuristicToleranceReached` になる。
これは成功の状態だが、誤差推定は観測した減衰に基づくもので、上界ではない。
減衰が確かめられないあいだは区間を足し続け、区間数の上限 `FourierTailOptions::with_max_cycles`（既定 128）に達すると `RefinementLimit` で止まる。
すべての裾を受け入れた後に合計の誤差推定が許容誤差を満たさない場合は `Stagnation` で止まる。
作業領域の `component_errors` が返す `TailDiagnostics` には、積分した区間の数（`shells`）と裾の状態（`status`）が入り、受け入れた場合の状態は `HeuristicallyTruncated` になる。

## 打ち切り誤差の上界

有限の $T$ で打ち切った $I(T)$ を $I_\infty$ の代わりに使うと、求積がどれほど正確でも、モデルの打ち切り誤差

$$
R(T) = I_\infty - I(T) = \frac{e^{-aT}\left[a\cos(\omega T) - \omega\sin(\omega T)\right]}{a^2 + \omega^2}
$$

が残る。
Cauchy–Schwarz の不等式 $|a\cos\theta - \omega\sin\theta| \le \sqrt{a^2 + \omega^2}$ から、位相によらない上界

$$
|R(T)| \le \frac{e^{-aT}}{\sqrt{a^2 + \omega^2}}
$$

が得られる。
$\omega T$ が適当な位相になると等号が成り立つので、この上界は改善できない。
有限区間の求積の許容誤差をこの打ち切り誤差より小さくしても、$I_\infty$ の近似としての精度は打ち切り誤差で頭打ちになる。

次のブロックは二つのセルが共有する定義である。
`amplitude` が求積に渡す振幅 $e^{-at}$、`primitive` が原始関数 $F$、`finite_integral` と `infinite_integral` が $I(T)$ と $I_\infty$、`tail_bound` が打ち切り誤差の上界に対応する。
閉形式の関数は検算用で、`f64` の標準関数で計算する。

```rust
//| id: integrate-damped-oscillation-model
//| kind: definitions
//| title: 減衰振動の振幅と積分の閉形式
//| crates: [scioxide-core]
use scioxide_core::{SciOxideError, RealScalar};

/// 求積に渡す振幅 g(t) = e^{−at}。cos(ωt) は求積の重みが受け持つ。
pub(crate) fn amplitude(decay_rate: f64, time: f64) -> Result<f64, SciOxideError> {
    Ok(RealScalar::exp(-decay_rate * time))
}

/// 原始関数 F(t) = e^{−at}(−a cos ωt + ω sin ωt)/(a² + ω²)。参照値（f64 の標準関数）。
pub(crate) fn primitive(a: f64, omega: f64, time: f64) -> f64 {
    let phase = omega * time;
    (-a * time).exp() * (-a * phase.cos() + omega * phase.sin()) / (a * a + omega * omega)
}

/// I(T) = F(T) − F(0)。
pub(crate) fn finite_integral(a: f64, omega: f64, end: f64) -> f64 {
    primitive(a, omega, end) - primitive(a, omega, 0.0)
}

/// I∞ = a/(a² + ω²)。
pub(crate) fn infinite_integral(a: f64, omega: f64) -> f64 {
    a / (a * a + omega * omega)
}

/// 打ち切り誤差の上界 e^{−aT}/√(a² + ω²)。参照値（f64 の標準関数）。
pub(crate) fn tail_bound(a: f64, omega: f64, end: f64) -> f64 {
    (-a * end).exp() / (a * a + omega * omega).sqrt()
}
```

## 有限時刻までの積分

次のセルは減衰率 $a$、角周波数 $\omega$、終端 $T$、許容誤差 $\varepsilon$（絶対・相対とも）を選び、$I(T)$ を `WeightedQuadraturePlan::fourier` で求める。
上のグラフは信号 $f(t)$、下のグラフは閉形式の累積積分 $I(t)$（破線）と、求積値 $Q(T)$ の点で、横軸の時刻は二つのグラフで連動する。
$I_\infty$ は横線で示す。
表は求積値、閉形式との差、誤差推定、評価回数、終了状態と、相殺の比 $C(T)$、区間に含まれる半周期の数 $\omega T/\pi$ を示す。
このセルの $a$ と $\omega$ は、次のセルの無限区間の積分にも渡す。

```rust
//| id: integrate-damped-oscillation
//| ref: integrate-damped-oscillation
//| title: 減衰振動の有限時刻までの積分
//| run: reactive
//| uses: [integrate-damped-oscillation-model]
//| crates: [scioxide-core, scioxide-integrate]
//| exports: [decay_rate, angular_frequency, tolerance]
//| inputs:
//|   decay_rate: {"type":"range","label":"減衰率 a [s⁻¹]","description":"包絡線 e^(−at) の減り方を変える。","min":0.03,"max":0.8,"step":0.01,"value":0.12}
//|   angular_frequency: {"type":"range","label":"角周波数 ω [rad/s]","description":"1 秒あたりに進む位相を変える。","min":2,"max":40,"step":0.5,"value":15.5}
//|   integration_end: {"type":"range","label":"終端 T [s]","description":"積分を打ち切る時刻。","min":2,"max":30,"step":0.5,"value":20}
//|   tolerance_exponent: {"type":"range","label":"許容誤差の指数 p（ε = 10^p）","description":"絶対・相対許容誤差をそろえて変える。","min":-12,"max":-6,"step":1,"value":-10}
//| cases:
//|   - {"id":"slow-decay","label":"a = 0.03 s⁻¹, ω = 40 rad/s","description":"半周期の数が約 255 に増えても、評価回数は変わらない。","inputs":{"decay_rate":0.03,"angular_frequency":40}}
//|   - {"id":"short-window","label":"T = 2 s","description":"終端が短いと、I(T) は I∞ から大きくずれ、符号も変わる。","inputs":{"integration_end":2}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"summary","path":"/rows/0/0","approx":{"value":5.503005248430788e-3,"rtol":1e-10}}
//|       - {"artifact":"summary","path":"/rows/0/1","range":{"max":1e-15}}
//|       - {"artifact":"summary","path":"/rows/0/3","range":{"max":100}}
//|       - {"artifact":"summary","path":"/rows/0/5","approx":{"value":1.141e-3,"rtol":1e-3}}
//|       - {"path":"/outputs/3/state","equals":"satisfied"}
//|   - case: slow-decay
//|     expect:
//|       - {"artifact":"summary","path":"/rows/0/3","range":{"max":100}}
//|       - {"artifact":"summary","path":"/rows/0/6","approx":{"value":254.65,"atol":0.01}}
//|       - {"path":"/outputs/3/state","equals":"satisfied"}
//|   - case: short-window
//|     expect:
//|       - {"artifact":"summary","path":"/rows/0/0","approx":{"value":-2.036369135106895e-2,"rtol":1e-10}}
//|       - {"path":"/outputs/3/state","equals":"satisfied"}
use scioxide_core::{ErrorTolerance, Interval, NormSelection};
use scioxide_integrate::{
    FourierWeight, SubdivisionOptions, WeightedQuadratureOptions, WeightedQuadraturePlan,
};

let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let digits12 = serde_json::json!({ "significantDigits": 12 });
let (a, omega, end) = (decay_rate, angular_frequency, integration_end);
let epsilon = 10.0_f64.powf(tolerance_exponent);
let tolerance = ErrorTolerance::scalar(epsilon, epsilon, NormSelection::Infinity)
    .map_err(|e| e.to_string())?;
let options =
    WeightedQuadratureOptions::new(SubdivisionOptions::default().with_tolerance(tolerance));
let interval = Interval::new(0.0_f64, end).map_err(|e| e.to_string())?;
let plan =
    WeightedQuadraturePlan::fourier(interval, &[], omega, FourierWeight::Cosine, options)
        .map_err(|e| e.to_string())?;
// コールバックは振幅 e^{−at} だけを返す。
let (value, report) = plan
    .integrate(|t: f64| amplitude(a, t))
    .map_err(|e| e.to_string())?;
let exact = finite_integral(a, omega, end);

// 相殺のない面積 A(T): 零点 (k + 1/2)π/ω で区切った半周期の積分の絶対値の和（閉形式）。
let half_period = std::f64::consts::PI / omega;
let mut cuts = vec![0.0];
cuts.extend(
    (0..)
        .map(|k| (f64::from(k) + 0.5) * half_period)
        .take_while(|&t| t < end),
);
cuts.push(end);
let absolute_area: f64 = cuts
    .windows(2)
    .map(|w| (primitive(a, omega, w[1]) - primitive(a, omega, w[0])).abs())
    .sum();

// 1 周期あたり 16 点以上で信号と累積積分を描く（表示用の値。f64 の標準関数による）。
let samples = ((16.0 * end / (2.0 * half_period)).ceil() as usize).max(800);
let times: Vec<f64> = (0..=samples)
    .map(|i| end * i as f64 / samples as f64)
    .collect();
let signal: Vec<[f64; 2]> = times
    .iter()
    .map(|&t| [t, (-a * t).exp() * (omega * t).cos()])
    .collect();
let cumulative: Vec<[f64; 2]> = times
    .iter()
    .map(|&t| [t, finite_integral(a, omega, t)])
    .collect();
emit_line_chart!(
    &vec![serde_json::json!({ "name": "f(t)", "points": signal })],
    options = &serde_json::json!({
        "link": { "group": "damped-time" },
        "xLabel": "時刻 t [s]",
        "yLabel": "信号 f(t) [-]",
        "yMin": -1.0,
        "yMax": 1.0
    })
);
emit_chart!(serde_json::json!({
    "kind": "xy",
    "link": { "group": "damped-time" },
    "xLabel": "時刻 t [s]",
    "yLabel": "累積積分 I(t) [s]",
    "layers": [
        {
            "id": "closed-form",
            "kind": "line",
            "name": "I(t)（閉形式）",
            "points": cumulative,
            "style": { "lineType": "dashed", "showSymbol": false }
        },
        {
            "id": "quadrature",
            "kind": "scatter",
            "name": "求積値 Q(T)",
            "points": [[end, value]],
            "style": { "symbol": "diamond" }
        }
    ],
    "annotations": [{
        "kind": "line",
        "axis": "y",
        "value": infinite_integral(a, omega),
        "label": "I∞（閉形式）",
        "style": { "lineType": "dotted" }
    }]
}));

let columns = serde_json::json!([
    { "key": "0", "label": "求積値 Q(T) [s]", "type": "number", "format": digits12 },
    { "key": "1", "label": "閉形式との差 [s]", "type": "number", "format": sci3 },
    { "key": "2", "label": "誤差推定 [s]", "type": "number", "format": sci3, "nullText": "なし" },
    { "key": "3", "label": "評価回数 [回]", "type": "integer" },
    { "key": "4", "label": "終了状態" },
    { "key": "5", "label": "相殺の比 C(T) [-]", "type": "number", "format": sci3 },
    { "key": "6", "label": "半周期の数 ωT/π [-]", "type": "number", "format": { "fractionDigits": 1 } }
]);
emit_table_with_columns!(
    columns,
    vec![(
        value,
        (value - exact).abs(),
        report.error_estimate(),
        report.evaluations(),
        report.termination().to_string(),
        exact.abs() / absolute_area,
        end / half_period,
    )],
    metadata = serde_json::json!({ "id": "summary" })
);
export!(decay_rate, a);
export!(angular_frequency, omega);
export!(tolerance, epsilon);

let termination = report.termination();
let outcome = if termination.is_success() {
    Outcome::satisfied("I(T) の誤差推定が許容誤差を満たした")
} else {
    Outcome::partial("I(T) の求積が許容誤差を満たす前に止まった")
        .explanation("返された値は推定値として読み、修正モーメントの段数か許容誤差を見直す。")
};
let mut outcome = outcome
    .status(termination.to_string())
    .diagnostic("評価回数", report.evaluations() as f64, None)
    .diagnostic("閉形式との差", (value - exact).abs(), Some("s"));
if let Some(estimate) = report.error_estimate() {
    outcome = outcome.diagnostic("誤差推定", estimate, Some("s"));
}
emit_outcome!(outcome);
```

既定値（$a = 0.12$ s⁻¹、$\omega = 15.5$ rad/s、$T = 20$ s、$\varepsilon = 10^{-10}$）では、区間は約 99 個の半周期を含む。
求積は 25 回の評価で `ToleranceReached` となり、$Q(T) = 5.503 \times 10^{-3}$ s は閉形式と $10^{-17}$ 程度の差で一致した。
誤差推定は $4.9 \times 10^{-13}$ s で、実際の差より大きい側にあるが、上界ではない。
相殺のない面積 $A(T)$ は約 4.82 s で、相殺の比は $C(T) = 1.1 \times 10^{-3}$ である。
積分値は信号の大きさの尺度の 1000 分の 1 程度しかないので、相対許容誤差だけで止めると、要求される絶対誤差もそれだけ小さくなる。

$a = 0.03$ s⁻¹、$\omega = 40$ rad/s では半周期の数が約 255 に増えるが、評価回数は 25 回のままである。
振幅 $e^{-at}$ は区間全体で滑らかなので、1 つの領域の修正 Clenshaw–Curtis 則で許容誤差に達する。
$T = 2$ s では $Q(T) = -2.036 \times 10^{-2}$ s で、$I_\infty = 4.99 \times 10^{-4}$ s とは符号まで異なる。
下のグラフで、累積積分が振動しながら $I_\infty$ の横線へ近づく様子と、終端の求積値が破線の上にあることを確かめられる。

## 無限区間の積分と打ち切り誤差

次のセルは前のセルの $a$、$\omega$、$\varepsilon$ を受け取り、始点 $T_0$ から先の裾の積分

$$
\int_{T_0}^{\infty} f(t)\,dt = I_\infty - I(T_0) = R(T_0)
$$

を `FourierTailPlan` で求める。
$T_0 = 0$ なら $I_\infty$ そのもので、$T_0 > 0$ なら $T_0$ で打ち切ったときの打ち切り誤差 $R(T_0)$ を直接求めることになる。
入力は $T_0$ を時定数 $1/a$ の倍数 $k_0$ で選ぶ。
1 つ目の表は求積値を閉形式 $R(T_0)$ と比べ、誤差推定、評価回数、積分した区間の数、裾の状態、終了状態を示す。
グラフは $T \in [0, 8/a]$ での $I(T)$ と、帯 $I_\infty \pm e^{-aT}/\sqrt{a^2 + \omega^2}$ である。
$T_0 = 0$ のときの求積値 $I_\infty$ を破線、選んだ $T_0$ を縦線で示す。
曲線は最大 6000 点で描くので、周期の数が多いと振動の形は描き切れないが、各点は $I(T)$ の値で、帯の内側にある。
2 つ目の表は $T = k/a$（$k = 1, \ldots, 8$）での実際の打ち切り誤差 $|R(T)|$ と上界を閉形式で比べる。

```rust
//| id: integrate-damped-tail
//| ref: integrate-damped-tail
//| title: 半直線の積分と打ち切り誤差の上界
//| run: reactive
//| uses: [integrate-damped-oscillation-model]
//| crates: [scioxide-core, scioxide-integrate]
//| dependsOn:
//|   solve: integrate-damped-oscillation
//| inputs:
//|   tail_start: {"type":"range","label":"裾の始点 k₀（T₀ = k₀/a）","description":"0 なら I∞、正なら打ち切り誤差 R(T₀) を求める。","min":0,"max":8,"step":1,"value":0}
//| cases:
//|   - {"id":"four-time-constants","label":"T₀ = 4/a","description":"打ち切り誤差 R(T₀) を求積で直接求め、上界との比が 1 に近い位相であることを確かめる。","inputs":{"tail_start":4}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"tail","path":"/rows/0/0","approx":{"value":4.994497728323631e-4,"rtol":1e-10}}
//|       - {"artifact":"tail","path":"/rows/0/1","range":{"max":1e-13}}
//|       - {"artifact":"tail","path":"/rows/0/7","equals":"HeuristicToleranceReached"}
//|       - {"artifact":"bounds","path":"/rows/3/3","approx":{"value":1.0089,"atol":1e-3}}
//|       - {"path":"/outputs/3/state","equals":"satisfied"}
//|   - case: four-time-constants
//|     expect:
//|       - {"artifact":"tail","path":"/rows/0/0","approx":{"value":-1.1711728373716e-3,"rtol":1e-9}}
//|       - {"artifact":"tail","path":"/rows/0/2","approx":{"value":1.1816187107e-3,"rtol":1e-9}}
//|       - {"path":"/outputs/3/state","equals":"satisfied"}
use scioxide_core::{ErrorTolerance, ExecutionContext, NormSelection};
use scioxide_integrate::{
    FourierDomain, FourierTailOptions, FourierTailPlan, FourierWeight, SubdivisionOptions,
};

let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let digits12 = serde_json::json!({ "significantDigits": 12 });
let a = solve["decay_rate"].as_f64().ok_or("減衰率がない")?;
let omega = solve["angular_frequency"]
    .as_f64()
    .ok_or("角周波数がない")?;
let epsilon = solve["tolerance"].as_f64().ok_or("許容誤差がない")?;
let tolerance = ErrorTolerance::scalar(epsilon, epsilon, NormSelection::Infinity)
    .map_err(|e| e.to_string())?;
let infinite = infinite_integral(a, omega);

// 半直線 [T₀, ∞) の積分。コールバックは振幅 e^{−at} だけを返す。
let start = tail_start / a;
let options = FourierTailOptions::new(SubdivisionOptions::default().with_tolerance(tolerance));
let domain = FourierDomain::Upper { lower: start };
let plan = FourierTailPlan::new(domain, omega, FourierWeight::Cosine, options)
    .map_err(|e| e.to_string())?;
let mut workspace = plan.workspace(1).map_err(|e| e.to_string())?;
let mut value = 0.0_f64;
let report = plan
    .integrate_into(
        |t: f64| amplitude(a, t),
        &mut value,
        &mut workspace,
        ExecutionContext::sequential(),
    )
    .map_err(|e| e.to_string())?;
let exact = infinite - finite_integral(a, omega, start);
let diagnostics = workspace
    .component_errors()
    .and_then(|errors| errors[0].tail_diagnostics());
let columns = serde_json::json!([
    { "key": "0", "label": "裾の積分の求積値 [s]", "type": "number", "format": digits12 },
    { "key": "1", "label": "閉形式との差 [s]", "type": "number", "format": sci3 },
    { "key": "2", "label": "上界 e^(−aT₀)/√(a²+ω²) [s]", "type": "number", "format": sci3 },
    { "key": "3", "label": "誤差推定 [s]", "type": "number", "format": sci3, "nullText": "なし" },
    { "key": "4", "label": "評価回数 [回]", "type": "integer" },
    { "key": "5", "label": "積分した区間の数", "type": "integer", "nullText": "なし" },
    { "key": "6", "label": "裾の状態" },
    { "key": "7", "label": "終了状態" }
]);
emit_table_with_columns!(
    columns,
    vec![(
        value,
        (value - exact).abs(),
        tail_bound(a, omega, start),
        report.error_estimate(),
        report.evaluations(),
        diagnostics.map(|d| d.shells()),
        diagnostics.map_or("なし".to_string(), |d| format!("{:?}", d.status())),
        report.termination().to_string(),
    )],
    metadata = serde_json::json!({ "id": "tail" })
);

// I(T) と帯 I∞ ± e^{−aT}/√(a² + ω²)（閉形式）を T ∈ [0, 8/a] で描く。
let horizon = 8.0 / a;
let samples =
    ((16.0 * omega * horizon / (2.0 * std::f64::consts::PI)).ceil() as usize).clamp(800, 6000);
let times = (0..=samples).map(|i| horizon * i as f64 / samples as f64);
let band: Vec<[f64; 4]> = times
    .clone()
    .map(|t| {
        let bound = tail_bound(a, omega, t);
        [t, infinite, infinite - bound, infinite + bound]
    })
    .collect();
let curve: Vec<[f64; 2]> = times.map(|t| [t, finite_integral(a, omega, t)]).collect();
emit_chart!(serde_json::json!({
    "kind": "xy",
    "xLabel": "終端 T [s]",
    "yLabel": "積分 [s]",
    "xMin": 0.0,
    "xMax": horizon,
    "layers": [
        { "id": "bound", "kind": "band", "name": "I∞ ± 上界（閉形式）", "points": band },
        { "id": "finite", "kind": "line", "name": "I(T)（閉形式）", "points": curve }
    ],
    "annotations": [
        {
            "kind": "line",
            "axis": "y",
            "value": infinite,
            "label": "I∞",
            "style": { "lineType": "dashed" }
        },
        { "kind": "line", "axis": "x", "value": start, "label": "T₀" }
    ]
}));

// T = k/a での実際の打ち切り誤差と上界（閉形式）。
let rows: Vec<(f64, f64, f64, Option<f64>)> = (1..=8)
    .map(|k| {
        let end = f64::from(k) / a;
        let actual = (infinite - finite_integral(a, omega, end)).abs();
        let bound = tail_bound(a, omega, end);
        (end, actual, bound, (actual > 0.0).then(|| bound / actual))
    })
    .collect();
let digits3 = serde_json::json!({ "significantDigits": 3 });
let truncation_columns = serde_json::json!([
    { "key": "0", "label": "終端 T [s]", "type": "number", "format": { "fractionDigits": 2 } },
    { "key": "1", "label": "打ち切り誤差 |R(T)| [s]", "type": "number", "format": sci3 },
    { "key": "2", "label": "上界 [s]", "type": "number", "format": sci3 },
    { "key": "3", "label": "上界/|R(T)| [-]", "type": "number", "format": digits3, "nullText": "未定義" }
]);
emit_table_with_columns!(
    truncation_columns,
    rows,
    metadata = serde_json::json!({ "id": "bounds" })
);

let termination = report.termination();
let outcome = if termination.is_success() {
    Outcome::satisfied("裾の積分の経験的な誤差推定が許容誤差を満たした")
        .explanation("裾の推定は観測した減衰に基づくもので、上界ではない。")
} else {
    Outcome::partial("裾の積分が許容誤差を満たす前に止まった")
        .explanation("返された値は推定値として読み、区間数の上限か許容誤差を見直す。")
};
let mut outcome = outcome
    .status(termination.to_string())
    .diagnostic("評価回数", report.evaluations() as f64, None)
    .diagnostic("閉形式との差", (value - exact).abs(), Some("s"));
if let Some(estimate) = report.error_estimate() {
    outcome = outcome.diagnostic("誤差推定", estimate, Some("s"));
}
emit_outcome!(outcome);
```

既定値の $T_0 = 0$ では、`FourierTailPlan` は 6 区間を積分した時点で裾を受け入れ、165 回の評価で `HeuristicToleranceReached` となった。
求積値 $4.9945 \times 10^{-4}$ s は閉形式 $a/(a^2 + \omega^2)$ と $1.2 \times 10^{-15}$ s の差で一致し、誤差推定は $3.3 \times 10^{-13}$ s である。
裾の状態は `HeuristicallyTruncated` で、観測した減衰から裾を打ち切ったことを示す。
区間の積分は交互に符号を変えて等比的に小さくなるので、Wynn の ε アルゴリズムは少ない区間で極限に達する。

$T_0 = 4/a \approx 33.3$ s にすると、求積値は $R(T_0) = -1.171 \times 10^{-3}$ s で、閉形式と $10^{-17}$ 程度の差で一致する。
この $T_0$ では上界 $1.182 \times 10^{-3}$ s との比が 1.009 で、上界がほぼ等号で成り立つ位相にある。
2 つ目の表では、上界と $|R(T)|$ の比は位相によって $T = 4/a$ の 1.009 から $T = 8/a$ の 3.9 まで変わるが、常に 1 以上である。
帯の幅は $e^{-aT}$ で縮み、$I(T)$ の曲線はその内側で振動する。
有限区間の結果を $I_\infty$ の近似として使うなら、$T$ を上界が要求精度を下回るまで延ばすか、`FourierTailPlan` で半直線を直接積分する。

## まとめ

減衰振動の積分では振動因子を `FourierWeight::Cosine` として Plan に持たせ、コールバックは滑らかな振幅 $e^{-at}$ だけを返す。
修正モーメントで振動を厳密に扱うので、評価回数は振幅の滑らかさで決まり、区間の半周期の数には比例しない。
正負の相殺で積分値が絶対値の積分 $A(T)$ よりずっと小さいとき（既定値では約 1000 分の 1）は、相対許容誤差ではなく絶対許容誤差で停止を制御する。
無限区間の値は `FourierTailPlan` で直接求められ、成功の状態 `HeuristicToleranceReached` は観測した減衰に基づく推定であって上界ではない。
有限の $T$ で打ち切るなら、求積の誤差推定とモデルの打ち切り誤差を分け、後者を上界 $e^{-aT}/\sqrt{a^2 + \omega^2}$ で見積もる。
