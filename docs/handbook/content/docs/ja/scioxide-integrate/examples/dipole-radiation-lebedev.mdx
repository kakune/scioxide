アンテナが放射する全電力は、遠方の球面を通る電力の流れを全方向について積分して求める。
この例題では中央から給電する細いダイポールアンテナの放射電力を、単位球面上の積分として `LebedevRule` と `SphereProductRule` で計算する。
長さによって変わる放射電力、放射抵抗、指向性を閉形式と照合し、アンテナの軸を傾けたときにそれぞれの則の精度がどう変わるかを確かめる。

二つの則の構成、厳密な次数、節点数の見積もりは [単体と球面の求積則](oxref:integrate-sphere-rules)にある。

## 放射強度と放射電力

全長 $\ell$ の細い導線を中央で給電し、波数 $k = 2\pi/\lambda$（$\lambda$ は波長）の正弦波の電流

$$
I(z) = I_0 \sin\!\left(k\left(\frac{\ell}{2} - |z|\right)\right), \qquad |z| \le \frac{\ell}{2}
$$

が流れるとする。
$I_0$ は正弦波の定在波電流の振幅で、以下では $I_0 = 1$ A とする。
$\ell \ge \lambda/2$ なら $I_0$ は導線上の電流の最大値に等しいが、$\ell < \lambda/2$ では最大値は給電点の $I_0\sin(k\ell/2)$ で、$I_0$ より小さい。
導線の太さを無視し、電流分布をこの形に固定するのが細いダイポールの近似である。
アンテナの軸と観測方向のなす角を $\theta$ とすると、遠方の単位立体角あたりの放射電力（放射強度）は

$$
U(\theta) = \frac{\eta I_0^2}{8\pi^2}\,F(\theta)^2, \qquad F(\theta) = \frac{\cos\!\left(\frac{k\ell}{2}\cos\theta\right) - \cos\frac{k\ell}{2}}{\sin\theta}
$$

で、単位は W/sr である。
$\eta = 376.73\ \Omega$ は自由空間の波動インピーダンスである。
放射電力 $P$、指向性 $D$、放射抵抗 $R$ は

$$
P = \oint_{S^2} U\,d\Omega, \qquad D = \frac{4\pi\,U_{\max}}{P}, \qquad R = \frac{2P}{I_0^2}
$$

で定める。
$D$ は等方的に放射した場合に比べて最も強い方向の強度が何倍かを表し、$10\log_{10}D$ を dBi で書く。
$R$ は振幅 $I_0$ を基準にした値で、$\ell = \lambda/2$ では給電点の電流がちょうど $I_0$ になる。

極 $\theta = 0, \pi$ では $F$ の分子と分母がどちらも 0 になる。
$c = \cos\theta$ と書き、$\cos(ac) - \cos a = 2\sin\frac{a(1 + c)}{2}\sin\frac{a(1 - c)}{2}$（$a = k\ell/2$）と $\sin^2\theta = (1 - c)(1 + c)$ を使うと

$$
F^2 = 4\,(1 - c)(1 + c)\,S(1 - c)^2\,S(1 + c)^2, \qquad S(t) = \frac{\sin(at/2)}{t}
$$

となる。
$S$ は $t = 0$ で $a/2$ に連続につながるので、$F^2$ は $c$ の整関数で、極での値は 0 である。
Lebedev 則は正八面体の頂点、つまり極 $(0, 0, \pm1)$ を節点に含むので、この形で計算しないと 0/0 になる。
$F^2$ は多項式ではないので、どちらの則も有限の次数で正確にはならず、誤差は次数とともに速く減る。

## 閉形式

$P$ は $\theta$ についての 1 次元の積分で、正弦積分 $\mathrm{Si}$ と余弦積分 $\mathrm{Ci}$ で閉じた形に書ける。
$\mathrm{Cin}(x) = \gamma + \ln x - \mathrm{Ci}(x)$（$\gamma$ は Euler の定数）と $x = k\ell$ を使うと

$$
P = \frac{\eta I_0^2}{4\pi}\left[\mathrm{Cin}(x) + \frac{\sin x}{2}\bigl(\mathrm{Si}(2x) - 2\,\mathrm{Si}(x)\bigr) + \frac{\cos x}{2}\bigl(2\,\mathrm{Cin}(x) - \mathrm{Cin}(2x)\bigr)\right]
$$

である（C. A. Balanis, *Antenna Theory: Analysis and Design*, 4th ed., Wiley, 2016, §4.5 の式を $\mathrm{Cin}$ でまとめたもの）。
半波長ダイポール $\ell = \lambda/2$ では $x = \pi$、$\sin x = 0$、$\cos x = -1$ なので

$$
P = \frac{\eta I_0^2}{8\pi}\,\mathrm{Cin}(2\pi), \qquad R = \frac{\eta}{4\pi}\,\mathrm{Cin}(2\pi) \approx 73.08\ \Omega, \qquad D = \frac{4}{\mathrm{Cin}(2\pi)} \approx 1.641
$$

となる（同 §4.6）。
$\mathrm{Cin}(2\pi) = 2.43765$ で、$D$ は 2.15 dBi にあたる。
最大の強度は $\theta = \pi/2$ の方向で $F = 1$ である。
scioxide-special は `si` と `ci` を提供し、$\mathrm{Cin}$ は提供しないので、上の定義で `ci` から作る。
$x$ が小さいと $\gamma + \ln x$ と $\mathrm{Ci}(x)$ の引き算で桁が失われるが、この例題の範囲（$\ell/\lambda \ge 0.1$）では失われる桁は 2 桁以下である。

指向性に要る $U_{\max}$ は、$\ell \le \lambda$ では $\theta = \pi/2$ の値だが、長いアンテナでは主ビームが斜めに分かれる。
以下のセルは $c = \cos\theta$ を 4001 点で走査した最大値を参照値として使う。

次の定義のブロックは三つのセルで共有する。
`pattern(a, c)` が $F^2$、`intensity` が観測方向の単位ベクトルとアンテナの軸から求めた $U$、`max_intensity` が走査による $U_{\max}$、`closed_form_power` が $P$ の閉形式、`tilted_axis` が $z$ 軸から $x$ 軸の向きに傾けた軸である。

```rust
//| id: integrate-dipole-model
//| kind: definitions
//| title: ダイポールの放射強度と放射電力の閉形式
//| crates: [scioxide-core, scioxide-special]
use scioxide_core::{SciOxideError, RealScalar};

/// 自由空間の波動インピーダンス η [Ω]。
pub(crate) const IMPEDANCE: f64 = 376.730_313_668;

/// Euler の定数 γ。
const EULER_GAMMA: f64 = 0.577_215_664_901_532_9;

/// S(t) = sin(a t / 2) / t。t = 0 では極限 a / 2。
fn half_sine_ratio(a: f64, t: f64) -> f64 {
    if t == 0.0 {
        0.5 * a
    } else {
        RealScalar::sin(0.5 * a * t) / t
    }
}

/// F² = 4 (1 − c)(1 + c) S(1 − c)² S(1 + c)²。c は軸との角の余弦、a = kℓ/2。
pub(crate) fn pattern(a: f64, c: f64) -> f64 {
    // 単位ベクトルの内積は丸めで ±1 をわずかに超えることがある。
    let c = RealScalar::clamp(c, -1.0, 1.0);
    let (minus, plus) = (1.0 - c, 1.0 + c);
    let s = half_sine_ratio(a, minus) * half_sine_ratio(a, plus);
    4.0 * minus * plus * s * s
}

/// 放射強度 U = η I₀² F² / (8π²) [W/sr]（I₀ = 1 A、length = ℓ/λ）。
pub(crate) fn intensity(length: f64, axis: &[f64; 3], direction: &[f64]) -> f64 {
    let pi = <f64 as RealScalar>::PI;
    let c = axis[0] * direction[0] + axis[1] * direction[1] + axis[2] * direction[2];
    IMPEDANCE / (8.0 * pi * pi) * pattern(pi * length, c)
}

/// U_max の参照値: c = cos θ を 4001 点で走査した最大値。
pub(crate) fn max_intensity(length: f64) -> f64 {
    (0..=4000)
        .map(|i| {
            let c = -1.0 + f64::from(i) / 2000.0;
            let s = RealScalar::sqrt(1.0 - c * c);
            intensity(length, &[0.0, 0.0, 1.0], &[s, 0.0, c])
        })
        .fold(0.0, |a, b| RealScalar::max(a, b))
}

/// Cin(x) = γ + ln x − Ci(x)。
fn cin(x: f64) -> Result<f64, SciOxideError> {
    Ok(EULER_GAMMA + RealScalar::ln(x) - scioxide_special::ci(x)?)
}

/// 放射電力 P [W] の閉形式（I₀ = 1 A、length = ℓ/λ）。
pub(crate) fn closed_form_power(length: f64) -> Result<f64, SciOxideError> {
    let x = <f64 as RealScalar>::TAU * length;
    let (sine, cosine) = RealScalar::sin_cos(x);
    let si_terms = scioxide_special::si(2.0 * x)? - 2.0 * scioxide_special::si(x)?;
    let cin_terms = 2.0 * cin(x)? - cin(2.0 * x)?;
    let bracket = cin(x)? + 0.5 * sine * si_terms + 0.5 * cosine * cin_terms;
    Ok(IMPEDANCE / (4.0 * <f64 as RealScalar>::PI) * bracket)
}

/// z 軸から x 軸の向きに tilt [°] だけ傾けた単位ベクトル。
pub(crate) fn tilted_axis(tilt: f64) -> [f64; 3] {
    let (sine, cosine) = RealScalar::sin_cos(RealScalar::to_radians(tilt));
    [sine, 0.0, cosine]
}
```

## 長さを変えたときの放射電力と放射抵抗

次のセルはアンテナの長さ $\ell/\lambda$ と Lebedev 則の次数 $L$ を選び、軸を $z$ 軸にそろえたアンテナの $P$ を `LebedevRule` と `SphereProductRule` で求める。
積則は同じ厳密な次数になるように、$\cos\theta$ 方向に $p = (L + 1)/2$ 点、方位角に $m = L + 1$ 点をとる。
被積分関数は単位球面上の点 $\boldsymbol u$（3 成分のスライス）を受け取り、`integrate(&f, &[0.0; 3], 1.0)` で中心が原点、半径 1 の球面に適用する。
立体角で積分するので、半径は 1 にする。
半径 $r$ の球面では重みが $r^2$ 倍になる。
中心や半径が有限でなければ `NonFinite`、$r \le 0$ なら `InvalidInput` を返し、節点、面積、重みが浮動小数点数の範囲を超えるか、0 でない面積や重みが 0 に丸められると `NumericalInstability` を返す。
表は $P$、$R$、$D$ と閉形式との相対誤差を並べる。

```rust
//| id: integrate-dipole-power
//| ref: integrate-dipole-power
//| title: アンテナの長さと則の次数を動かして放射電力・放射抵抗・指向性を求める
//| run: reactive
//| uses: [integrate-dipole-model]
//| crates: [scioxide-core, scioxide-integrate, scioxide-special]
//| inputs:
//|   power_length: {"type":"range","label":"アンテナの長さ ℓ/λ [-]","description":"波長で測った全長。0.5 が半波長ダイポール。","min":0.1,"max":3,"step":0.05,"value":0.5}
//|   power_degree: {"type":"select","label":"Lebedev 則の次数 L","description":"積則は p = (L + 1)/2、m = L + 1 で同じ厳密な次数にそろえる。","options":["11","17","23","29","41","59"],"value":"11"}
//| cases:
//|   - {"id":"full-wave","label":"ℓ = λ","description":"全波長では R = 199 Ω、指向性は 2.41 に上がる。","inputs":{"power_length":1}}
//|   - {"id":"long-coarse","label":"ℓ = 3λ, L = 11","description":"長いアンテナでは次数 11 の則の誤差が 10⁻¹ 程度になる。","inputs":{"power_length":3}}
//|   - {"id":"long-fine","label":"ℓ = 3λ, L = 59","description":"次数を上げると長いアンテナでも閉形式と丸めの水準で一致する。","inputs":{"power_length":3,"power_degree":"59"}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"methods","path":"/rows/0/3","approx":{"value":73.0790102856714,"rtol":1e-12}}
//|       - {"artifact":"methods","path":"/rows/0/4","approx":{"value":1.640922376984585,"rtol":1e-9}}
//|       - {"artifact":"methods","path":"/rows/0/5","approx":{"value":2.150880374549228,"rtol":1e-9}}
//|       - {"artifact":"methods","path":"/rows/1/6","range":{"min":0,"max":1e-7}}
//|       - {"artifact":"methods","path":"/rows/2/6","range":{"min":0,"max":1e-5}}
//|   - case: full-wave
//|     expect:
//|       - {"artifact":"methods","path":"/rows/0/3","approx":{"value":198.949980540224,"rtol":1e-12}}

//|     expect:
//|       - {"artifact":"methods","path":"/rows/1/6","range":{"min":1e-3,"max":1}}

//|       - {"artifact":"methods","path":"/rows/1/6","range":{"min":0,"max":1e-13}}
//|       - {"artifact":"methods","path":"/rows/2/6","range":{"min":0,"max":1e-9}}

use scioxide_integrate::{GeometricOptions, LebedevRule, SphereProductRule};

let length = power_length;

let product =
    SphereProductRule::new((degree + 1) / 2, degree + 1, options).map_err(|e| e.to_string())?;
let (lebedev_power, _): (f64, _) = lebedev
    .integrate(&radiation, &[0.0; 3], 1.0)
    .map_err(|e| e.to_string())?;
let (product_power, _): (f64, _) = product
    .integrate(&radiation, &[0.0; 3], 1.0)
    .map_err(|e| e.to_string())?;
// 参照値: Si・Ci による閉形式と、走査による U_max。

        name.to_string(),

    { "key": "1", "label": "節点数 [点]", "type": "integer", "nullText": "—" },

    { "key": "3", "label": "放射抵抗 R [Ω]", "type": "number", "format": digits(10) },
    { "key": "4", "label": "指向性 D [-]", "type": "number", "format": digits(6) },
    { "key": "5", "label": "指向性 [dBi]", "type": "number", "format": digits(4) },
    { "key": "6", "label": "P の相対誤差 [-]", "type": "number", "format": sci3, "nullText": "—" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "methods" })
);
```

既定値（半波長、$L = 11$）では、閉形式から $R = 73.079\ \Omega$、$D = 1.6409$（2.151 dBi）が得られ、前節の値と一致する。
50 点の Lebedev 則の相対誤差は $4\times10^{-9}$、同じ次数の 72 点の積則は $3\times10^{-8}$ である。
$D$ は $P$ で割るので、$D$ の相対誤差も $P$ と同じ大きさになる。

`full-wave` の場合（$\ell = \lambda$）は $R = 198.95\ \Omega$、$D = 2.411$ になる。
この $R$ は電流の最大値を基準にした値で、全波長のダイポールでは給電点の電流が 0 になるので、給電点から見た抵抗とは異なる。
`long-coarse` の場合（$\ell = 3\lambda$）は放射パターンに細かいローブが増え、次数 11 の則では相対誤差が $10^{-1}$ 程度になる。
`long-fine` で次数を 59（1202 点）に上げると、相対誤差は丸めの水準まで下がる。
長いアンテナほど、$F^2$ に高い次数の球面調和成分が含まれるからである。

## 軸を傾けたときの精度

次数 $L$ 以下の球面上の多項式は座標を回転しても次数 $L$ 以下の多項式のままである。
そのため次数 $L$ の則はアンテナの軸をどの向きに傾けても、$F^2$ のうち次数 $L$ 以下の部分を正確に積分する。
傾きで変わるのは、残りの高い次数の部分から来る誤差だけである。

積則には、これとは別の性質がある。
方位角の等間隔則は方位角によらない関数を $m$ によらず正確に積分する。
軸を $z$ 軸にそろえたアンテナの $U$ は $\cos\theta$ だけの関数なので、積則の誤差は $\cos\theta$ 方向の Gauss–Legendre 則の誤差だけになり、方位角は $m = 1$ でも足りる。
軸を傾けると $U$ は方位角にも依存し、方位角の点数が少ない積則は、その点数で決まる誤差に張り付く。

次のセルはアンテナの長さ $\ell/\lambda$ と軸の傾き $\alpha$（$z$ 軸から $x$ 軸の向き）を選び、次の 4 通りで $P$ の相対誤差を節点数に対して描く。

- Lebedev 則（傾き $\alpha$）：表のすべての次数 3〜131。
- 積則 $m = 2p$（傾き $\alpha$）：$p = 2, 3, \dots, 54$。
  厳密な次数は $2p - 1$ である。
- 積則 $m = 4$（傾き 0）と積則 $m = 4$（傾き $\alpha$）：方位角を 4 点に固定した、軸対称な被積分関数向けの則。

表は、それぞれの則で相対誤差が初めて $10^{-10}$ 以下になった節点数と、最大の節点数での相対誤差を示す。

```rust
//| id: integrate-dipole-tilt-convergence
//| ref: integrate-dipole-tilt-convergence
//| title: 軸の傾きを動かして Lebedev 則と積則の誤差を節点数で比べる
//| run: reactive
//| uses: [integrate-dipole-model]
//| crates: [scioxide-core, scioxide-integrate, scioxide-special]
//| inputs:
//|   tilt_length: {"type":"range","label":"アンテナの長さ ℓ/λ [-]","description":"長いほど高い次数の成分が要る。","min":0.1,"max":3,"step":0.05,"value":1.5}
//|   tilt_angle: {"type":"range","label":"軸の傾き α [°]","description":"z 軸から x 軸の向きに傾ける。","min":0,"max":90,"step":5,"value":30}
//| cases:
//|   - {"id":"aligned","label":"α = 0°","description":"軸をそろえると、方位 4 点の積則も m = 2p の積則と同じ誤差になる。","inputs":{"tilt_angle":0}}
//|   - {"id":"half-wave","label":"ℓ = λ/2","description":"半波長では 74 点の Lebedev 則で 10⁻¹⁰ に届き、方位 4 点の積則は 2.7 × 10⁻³ に張り付く。","inputs":{"tilt_length":0.5}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"rules","path":"/rows/0/1","range":{"min":200,"max":600}}
//|       - {"artifact":"rules","path":"/rows/1/1","range":{"min":200,"max":400}}
//|       - {"artifact":"rules","path":"/rows/3/1","equals":null}
//|       - {"artifact":"rules","path":"/rows/3/2","range":{"min":1e-6,"max":1}}
//|   - case: aligned
//|     expect:
//|       - {"artifact":"rules","path":"/rows/3/1","range":{"min":10,"max":200}}
//|   - case: half-wave
//|     expect:
//|       - {"artifact":"rules","path":"/rows/0/2","range":{"min":0,"max":1e-14}}
use scioxide_integrate::{GeometricOptions, LebedevRule, SphereProductRule};

let length = tilt_length;
let exact = closed_form_power(length).map_err(|e| e.to_string())?;
let options = GeometricOptions::default();
let (tilted, aligned) = (tilted_axis(tilt_angle), tilted_axis(0.0));
// 各系列は (節点数, 相対誤差) の列。
let mut curves: Vec<Vec<[f64; 2]>> = vec![Vec::new(); 4];
for &degree in LebedevRule::<f64>::supported_degrees() {
    let rule = LebedevRule::new(degree, options).map_err(|e| e.to_string())?;
    let f = |u: &[f64]| Ok(intensity(length, &tilted, u));
    let (value, _): (f64, _) = rule
        .integrate(&f, &[0.0; 3], 1.0)
        .map_err(|e| e.to_string())?;
    curves[0].push([rule.node_count() as f64, (value - exact).abs() / exact]);
}
for polar in 2..=54 {
    let cases = [(1, 2 * polar, &tilted), (2, 4, &aligned), (3, 4, &tilted)];
    for (series, azimuth, axis) in cases {
        let rule =
            SphereProductRule::new(polar, azimuth, options).map_err(|e| e.to_string())?;
        let f = |u: &[f64]| Ok(intensity(length, axis, u));
        let (value, _): (f64, _) = rule
            .integrate(&f, &[0.0; 3], 1.0)
            .map_err(|e| e.to_string())?;
        curves[series].push([rule.node_count() as f64, (value - exact).abs() / exact]);
    }
}
let names = [
    "Lebedev 則（傾き α）",
    "積則 m = 2p（傾き α）",
    "積則 m = 4（傾き 0）",
    "積則 m = 4（傾き α）",
];
let mut rows = Vec::new();
let mut excluded = 0_usize;
let mut series = Vec::new();
for (name, curve) in names.iter().zip(&curves) {
    // 相対誤差が初めて 1e-10 以下になった節点数（届かなければ None）と最大の節点数での相対誤差。
    let reached = curve.iter().find(|p| p[1] <= 1e-10).map(|p| p[0] as usize);
    let last = curve[curve.len() - 1][1];
    rows.push((name.to_string(), reached, last));
    // 誤差が 0 の点は対数軸に描けないので除き、数を数える。
    let points: Vec<[f64; 2]> = curve.iter().copied().filter(|p| p[1] > 0.0).collect();
    excluded += curve.len() - points.len();
    let line = if name.contains("傾き 0") {
        "dashed"
    } else {
        "solid"
    };
    series.push(serde_json::json!({
        "name": name,
        "points": points,
        "style": { "showSymbol": true, "lineType": line }
    }));
}
emit_line_chart!(
    &series,
    options = &serde_json::json!({
        "xLabel": "節点数 [点]",
        "yLabel": "放射電力の相対誤差 [-]",
        "xType": "log",
        "yType": "log",
        "xMin": 6.0,
        "xMax": 6000.0,
        "annotations": [{ "kind": "line", "axis": "y", "value": 1e-10, "label": "10⁻¹⁰" }]
    })
);
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let columns = serde_json::json!([
    { "key": "0", "label": "則" },
    { "key": "1", "label": "相対誤差 10⁻¹⁰ 以下に届いた節点数 [点]", "type": "integer", "nullText": "届かない" },
    { "key": "2", "label": "最大の節点数での相対誤差 [-]", "type": "number", "format": sci3 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "rules" })
);
emit_text!(format!("相対誤差が 0 でグラフから除いた点: {excluded} 点"));
```

既定の入力（$\ell = 1.5\lambda$、$\alpha = 30°$）では、相対誤差 $10^{-10}$ に届く節点数は Lebedev 則が 230 点、$m = 2p$ の積則が 242 点である。
軸の向きに特別な扱いのない二つの則は、どちらも節点数とともに誤差が速く下がる。
方位 4 点の積則は軸をそろえると 52 点で $10^{-10}$ に届くが、$30°$ 傾けると相対誤差が $3.4\times10^{-2}$ に張り付き、$p$ を増やしても下がらない。
$m$ 点の等間隔則は $e^{ij\varphi}$ を $j$ が $m$ の倍数でないときに正確に 0 と積分し、$j$ が $m$ の倍数の成分を 0 次の成分と取り違えるので、傾けた $U$ の $j = 4, 8, \dots$ の成分が誤差として残るからである。

`aligned` の場合（$\alpha = 0°$）は、方位 4 点の積則と $m = 2p$ の積則の誤差が同じ $p$ で一致し、方位角の点数が結果に効かないことが分かる。
`half-wave` の場合は 74 点の Lebedev 則で $10^{-10}$ に届き、傾けた方位 4 点の積則は $2.7\times10^{-3}$ に張り付く。
被積分関数が対称軸を持ち、その軸が座標軸にそろっているときは、積則を軸対称向けに小さくできる。
軸の向きが入力で変わる問題では、どの向きにも同じ次数の精度を持つ Lebedev 則か、$m \ge 2p$ の積則を使う。

## Lebedev 則の節点と負の重み

Lebedev–Laikov の表には、一部の重みが負になる則がある。
この実装の表では次数 13（74 点）、25（230 点）、27（266 点）がそうである。
負の重みがあると $\sum_j |w_j| > 4\pi$ になり、被積分関数の値の丸め誤差が重みの和 $4\pi$ より大きい係数で積み上がる。
この例題の大きさでは影響は丸めの水準にとどまるが、正の重みの則が使える次数では、それを選ぶ理由になる。

次のセルは選んだ次数の Lebedev 則の節点を単位球面上に描く。
節点は負の重み、正の重みで半電力ビームの中（$U \ge U_{\max}/2$）、正の重みでビームの外の 3 つのグループに分ける。
アンテナの軸も 2 点と辺で描く。
3 軸の単位はどれも球の半径である。
2 つの節点を選ぶと、その間の直線距離が出る。
表は節点数、負の重みの数、重みの和と $4\pi$ の差、$\sum_j |w_j|/(4\pi)$、ビームの中の節点数、その則による $P$ の相対誤差を示す。

```rust
//| id: integrate-dipole-lebedev-nodes
//| ref: integrate-dipole-lebedev-nodes
//| title: Lebedev 則の節点と負の重み、半電力ビームの位置を球面上に描く
//| run: reactive
//| uses: [integrate-dipole-model]
//| crates: [scioxide-core, scioxide-integrate, scioxide-special]
//| inputs:
//|   scene_degree: {"type":"select","label":"Lebedev 則の次数 L","description":"13・25・27 は負の重みを持つ。","options":["11","13","17","25","27","41"],"value":"25"}
//|   scene_length: {"type":"range","label":"アンテナの長さ ℓ/λ [-]","description":"半電力ビームの形を変える。","min":0.1,"max":3,"step":0.05,"value":0.5}
//|   scene_tilt: {"type":"range","label":"軸の傾き α [°]","description":"z 軸から x 軸の向きに傾ける。","min":0,"max":90,"step":5,"value":30}
//| cases:
//|   - {"id":"positive-weights","label":"L = 41","description":"590 点の則で、すべての重みが正になる。","inputs":{"scene_degree":"41"}}
//|   - {"id":"long-tilted","label":"ℓ = 1.5λ, α = 60°","description":"主ビームが斜めの円錐に分かれ、ビームの中の節点が軸の両側に移る。","inputs":{"scene_length":1.5,"scene_tilt":60}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"nodes","path":"/rows/0/1","equals":230}
//|       - {"artifact":"nodes","path":"/rows/0/2","equals":6}
//|       - {"artifact":"nodes","path":"/rows/0/3","range":{"min":-1e-12,"max":1e-12}}
//|       - {"artifact":"nodes","path":"/rows/0/4","range":{"min":1.0001,"max":2}}
//|       - {"artifact":"nodes","path":"/rows/0/6","range":{"min":0,"max":1e-13}}
//|   - case: positive-weights
//|     expect:
//|       - {"artifact":"nodes","path":"/rows/0/2","equals":0}
//|       - {"artifact":"nodes","path":"/rows/0/4","approx":{"value":1,"atol":1e-12}}
//|   - case: long-tilted
//|     expect:
//|       - {"artifact":"nodes","path":"/rows/0/5","range":{"min":10,"max":230}}
use scioxide_core::RealScalar;
use scioxide_integrate::{GeometricOptions, LebedevRule};

let degree: usize = scene_degree.parse().map_err(|_| "次数が整数でない")?;
let rule =
    LebedevRule::<f64>::new(degree, GeometricOptions::default()).map_err(|e| e.to_string())?;
let axis = tilted_axis(scene_tilt);
let half_power = 0.5 * max_intensity(scene_length);
let four_pi = 2.0 * <f64 as RealScalar>::TAU;
let (mut points, mut negative, mut in_beam) = (Vec::new(), 0_usize, 0_usize);
for (index, (u, &w)) in rule.nodes().chunks_exact(3).zip(rule.weights()).enumerate() {
    let group = if w < 0.0 {
        negative += 1;
        "negative"
    } else if intensity(scene_length, &axis, u) >= half_power {
        in_beam += 1;
        "beam"
    } else {
        "other"
    };
    points.push(serde_json::json!({
        "id": format!("node-{index}"),
        "position": [u[0], u[1], u[2]],
        "label": format!("w = {w:.4e}"),
        "group": group
    }));
}
// アンテナの軸を半径 1.3 の 2 点と辺で示す。
for (id, sign) in [("axis-plus", 1.3), ("axis-minus", -1.3)] {
    points.push(serde_json::json!({
        "id": id,
        "position": [sign * axis[0], sign * axis[1], sign * axis[2]],
        "group": "axis"
    }));
}

emit_scene3d!(
    serde_json::json!({
        "points": points,
        "edges": [{ "from": "axis-plus", "to": "axis-minus" }],
        "groups": [
            { "id": "negative", "label": "負の重み" },
            { "id": "beam", "label": "正の重み・半電力ビームの中" },
            { "id": "other", "label": "正の重み・ビームの外" },
            { "id": "axis", "label": "アンテナの軸" }

        "axes": { "x": unit("x"), "y": unit("y"), "z": unit("z") }
    }),

);

let absolute_sum: f64 = rule.weights().iter().map(|w| w.abs()).sum();
let f = |u: &[f64]| Ok(intensity(scene_length, &axis, u));
let (power, _): (f64, _) = rule
    .integrate(&f, &[0.0; 3], 1.0)
    .map_err(|e| e.to_string())?;
let exact = closed_form_power(scene_length).map_err(|e| e.to_string())?;
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let sig6 = serde_json::json!({ "significantDigits": 6 });
let columns = serde_json::json!([
    { "key": "0", "label": "次数 L", "type": "integer" },
    { "key": "1", "label": "節点数 [点]", "type": "integer" },
    { "key": "2", "label": "負の重みの数 [個]", "type": "integer" },
    { "key": "3", "label": "Σw − 4π [-]", "type": "number", "format": sci3 },
    { "key": "4", "label": "Σ|w| / 4π [-]", "type": "number", "format": sig6 },

]);

    degree,
    rule.node_count(),
    negative,
    weight_sum - four_pi,
    absolute_sum / four_pi,
    in_beam,
    (power - exact).abs() / exact,
);
emit_table_with_columns!(
    columns,
    vec![row],
    metadata = serde_json::json!({ "id": "nodes" })
);
```

既定の次数 25（230 点）では、正八面体の 6 頂点の重みが $-0.694$ で負になり、$\sum_j|w_j|/(4\pi) = 1.66$ である。
重みの和と $4\pi$ の差は $10^{-14}$ 程度で、半波長ダイポールの $P$ は丸めの水準で閉形式と一致する。
次数 13（74 点）では立方体の 8 頂点が負で $\sum_j|w_j|/(4\pi) = 1.47$、次数 27（266 点）では 18 点が負で 1.08 になる。
`positive-weights` の次数 41（590 点）ではすべての重みが正で、比は 1 である。
被積分関数の値の誤差が $\delta$ 以下のとき、積分値の誤差の上界は $\delta\sum_j|w_j|$ なので、この比は上界が正の重みの則の何倍になるかを表す。
被積分関数が測定値や別の数値計算の結果で、$\delta$ が丸めより大きい場合に、この差が効く。

半電力ビームの中の節点は、半波長ダイポールでは軸に垂直な太い帯に並び、230 点のうち 142 点を占める。
`long-tilted` の場合（$\ell = 1.5\lambda$、$\alpha = 60°$）は、主ビームが軸から斜めの 2 つの円錐に分かれ、ビームの中の節点は 92 点に減る。

## まとめ

細いダイポールの放射電力は放射強度 $U$ の単位球面上の積分で、`LebedevRule` と `SphereProductRule` の `integrate(&f, &[0.0; 3], 1.0)` で立体角について求められる。
$F^2$ を $(1 - c)(1 + c)$ と $\sin(at/2)/t$ の積に書き直すと、Lebedev 則が節点に含む極でも 0/0 を作らずに評価できる。
半波長ダイポールでは閉形式の $R = \eta\,\mathrm{Cin}(2\pi)/(4\pi) = 73.08\ \Omega$、$D = 1.641$ と、数十点の則で $10^{-8}$ 程度まで一致し、長いアンテナほど高い次数が要る。
どちらの則も次数 $L$ 以下の部分は軸の向きによらず正確に積分するが、方位角の点数を減らした積則は軸対称で軸がそろった場合にしか使えない。
負の重みを持つ Lebedev 則（次数 13、25、27）は $\sum_j|w_j|$ が $4\pi$ を超えるので、値に誤差を含む被積分関数では正の重みの次数を選ぶ。
