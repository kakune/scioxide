Fresnel 積分

$$
C(t) = \int_0^t \cos\Bigl(\frac{\pi s^2}{2}\Bigr)\,ds, \qquad S(t) = \int_0^t \sin\Bigl(\frac{\pi s^2}{2}\Bigr)\,ds
$$

は、光が物体の縁で回り込む Fresnel 回折の振幅に現れる。
点 $(C(t), S(t))$ を平面に描いた曲線をコルニュ螺旋（Euler 螺旋、クロソイドとも呼ぶ）という。
この例題では `OscillatoryQuadraturePlan` で $C$ と $S$ を求めて螺旋を描き、大きな $t$ での評価回数を適応 Gauss–Kronrod 則と比べ、直線の縁による回折の強度分布を計算する。
参照値は scioxide-special の `fresnel_c`、`fresnel_s` である。
Levin 法と Filon 法の仕組みと、角周波数を上げたときの評価回数の変化は[非線形位相の振動積分（Levin・Filon）](../../algorithms/phase-aware-oscillatory/)で扱う。

## 螺旋の幾何と漸近形

$(C'(t), S'(t)) = (\cos(\pi t^2/2), \sin(\pi t^2/2))$ は長さ 1 のベクトルなので、$t$ は螺旋に沿った弧長である。
接線の角度は $\pi t^2/2$ で、曲率は $\pi t$ になる。
曲率が弧長に比例して増えるので、螺旋は $t \to \pm\infty$ で極限点 $(\pm\tfrac12, \pm\tfrac12)$ のまわりを小さく巻いていく。
$C$ と $S$ は奇関数で、$t < 0$ の枝は原点について点対称である。

大きな $t$ では、部分積分により

$$
C(t) \approx \frac12 + \frac{\sin(\pi t^2/2)}{\pi t}, \qquad S(t) \approx \frac12 - \frac{\cos(\pi t^2/2)}{\pi t}
$$

が成り立つ。
これは中心 $(\tfrac12, \tfrac12)$、半径 $1/(\pi t)$ の円の上の点で、次の項は $1/(\pi^2t^3)$ の大きさである。

## 停留点の宣言と区間の分け方

$C$ と $S$ は位相 $g(s) = s^2$、角周波数 $\omega = \pi/2$、振幅 $f = 1$ の振動積分 $\int_0^t f\cos(\omega g)\,ds$ と $\int_0^t f\sin(\omega g)\,ds$ である。
$g'(s) = 2s$ は $s = 0$ で零になるので、$s = 0$ は停留点である。
`OscillatoryRegion` で区間を分け、各領域で $g'$ が取る値の範囲を宣言する。

- $[0, \min(t, 1)]$ は停留点を含むので `OscillatoryRegion::stationary` とし、$g' \in [0, 2\min(t, 1)]$ を宣言する。
  停留領域は、位相の変化が 1 区画あたり 2 rad 以下になる数の等分区画に G7K15 を当てる通常の求積で測る。
- $t > 1$ の残りは $[1, 2], [2, 4], \dots$ と 2 倍ずつの区間に分け、$[a, b]$ では $g' \in [2a, 2b]$ を `OscillatoryRegion::nonstationary` で宣言する。

$|g'|$ の範囲を区間ごとに狭く取ると、Levin 法の選点系と Filon 法の位相座標の補間がよく働く。
Levin 法は領域の幅 $L$ と $|g'|$ の下限 $m$ が $|\omega|Lm > 64$ を満たす領域だけで選点を使い、それ以外は通常の求積に切り替える。
$[a, 2a]$ では $|\omega|Lm = \pi a^2$ なので、選点を使うのは $a \ge 8$ の区間である。
Filon 法の切り替えの閾値は 2 で、$a \ge 1$ の区間から位相座標の則を使う。
Filon 法には位相の逆関数 $s = \sqrt\varphi$ も渡す。

比較に使う適応 Gauss–Kronrod 則は、値 $[\cos(\pi s^2/2), \sin(\pi s^2/2)]$ を 2 成分の値として一度に積分する。
被積分関数は scioxide-core の `cos_pi`、`sin_pi` で $\cos(\pi x)$、$\sin(\pi x)$ を評価する。
$\pi x$ を先に丸めないので、$\pi$ を掛けた積の丸めによる誤差は入らない。
ただし $x = s^2/2$ 自体の丸めは残り、位相には $\pi\varepsilon s^2/2$ 程度の絶対誤差が生じる。

次の定義のブロックは三つのセルで共有する。
`regions(t)` が上の領域の列を作り、`fresnel(method, t, tolerance)` は `"levin"`、`"filon"`、`"adaptive"` のどれかで $C(t)$ と $S(t)$ を求める。
振動積分の Plan は重みが余弦か正弦かで別の Plan になるので、$C$ と $S$ に一つずつ Plan を作り、評価回数は二つの合計にする。
許容誤差は絶対許容誤差だけで与える。
結果の `success` は、二つの積分がどちらも成功の終了状態で止まったかを示す。
`reference(t)` は scioxide-special の `fresnel_c`、`fresnel_s` による参照値、`asymptote(t)` は螺旋の幾何の節で示した漸近形である。

```rust
//| id: integrate-fresnel-model
//| kind: definitions
//| title: 停留点を宣言した Fresnel 積分の計算
//| crates: [scioxide-core, scioxide-integrate, scioxide-special]
use scioxide_core::{
    Budget, ErrorTolerance, SciOxideError, Interval, NormSelection, RealScalar, cos_pi, sin_pi,
};
use scioxide_integrate::{
    AdaptiveIntegrator, AdaptiveRule, FourierWeight, IntegrationReport, OscillatoryGeometry,
    OscillatoryMethod, OscillatoryOptions, OscillatoryQuadraturePlan, OscillatoryRegion,
    SubdivisionOptions,
};
use scioxide_special::{fresnel_c, fresnel_s};

/// scioxide-special による参照値 (C(t), S(t))。
pub(crate) fn reference(t: f64) -> Result<(f64, f64), SciOxideError> {
    Ok((fresnel_c(t)?, fresnel_s(t)?))
}

/// 漸近形 C ≈ 1/2 + sin(πt²/2)/(πt)、S ≈ 1/2 − cos(πt²/2)/(πt)。
pub(crate) fn asymptote(t: f64) -> Result<(f64, f64), SciOxideError> {
    let radius = 1.0 / (<f64 as RealScalar>::PI * t);
    let phase = 0.5 * t * t;
    Ok((0.5 + radius * sin_pi(phase)?, 0.5 - radius * cos_pi(phase)?))
}

/// C(t)、S(t)、二つの積分の評価回数の合計、終了状態、両方が成功したか。
pub(crate) struct Fresnel {
    pub(crate) c: f64,
    pub(crate) s: f64,
    pub(crate) evaluations: usize,
    pub(crate) status: String,
    pub(crate) success: bool,
}

/// [0, min(t, 1)] は停留領域、その先は [a, 2a] ごとに g' ∈ [2a, 2b] の非停留領域。
fn regions(t: f64) -> Result<Vec<OscillatoryRegion<f64>>, SciOxideError> {
    let first = t.min(1.0);
    let stationary = OscillatoryRegion::stationary(
        Interval::new(0.0, first)?,
        Interval::new(0.0, 2.0 * first)?,
    )?;
    let mut list = vec![stationary];
    let mut a = first;
    while a < t {
        let b = (2.0 * a).min(t);
        list.push(OscillatoryRegion::nonstationary(
            Interval::new(a, b)?,
            Interval::new(2.0 * a, 2.0 * b)?,
        )?);
        a = b;
    }
    Ok(list)
}

fn summary(c: f64, s: f64, reports: &[&IntegrationReport<f64>]) -> Fresnel {
    let evaluations = reports.iter().map(|r| r.evaluations()).sum();
    let success = reports.iter().all(|r| r.is_success());
    // 成功しなかった積分があれば、その終了状態を示す。
    let worst = reports
        .iter()
        .find(|r| !r.is_success())
        .unwrap_or(&reports[0]);
    Fresnel {
        c,
        s,
        evaluations,
        status: worst.termination().to_string(),
        success,
    }
}

/// method は "levin"、"filon"、"adaptive"。tolerance は絶対許容誤差。
pub(crate) fn fresnel(method: &str, t: f64, tolerance: f64) -> Result<Fresnel, SciOxideError> {
    let tolerance = ErrorTolerance::scalar(tolerance, 0.0, NormSelection::Infinity)?;
    let options = SubdivisionOptions::default()
        .with_tolerance(tolerance)
        .with_max_subdivisions(Budget::try_from(1000)?);
    let interval = Interval::new(0.0, t)?;
    if method == "adaptive" {
        let plan = AdaptiveIntegrator::new(AdaptiveRule::GaussKronrod, options)?;
        let integrand = |x: f64| Ok([cos_pi(0.5 * x * x)?, sin_pi(0.5 * x * x)?]);
        let ([c, s], report) = plan.integrate(&integrand, interval)?;
        return Ok(summary(c, s, &[&report]));
    }
    let method = if method == "filon" {
        OscillatoryMethod::Filon
    } else {
        OscillatoryMethod::Levin
    };
    let geometry = OscillatoryGeometry::new(interval, 0.5 * <f64 as RealScalar>::PI, &regions(t)?)?;
    // 位相 g(s) = s² と g'(s) = 2s。Filon 法の逆関数は s = √φ。
    let phase = (
        |x: f64| Ok((x * x, 2.0 * x)),
        |_: Interval<f64>, p: f64| Ok(RealScalar::sqrt(p)),
    );
    let solve = |weight| {
        let plan = OscillatoryQuadraturePlan::new(
            method,
            geometry.clone(),
            weight,
            OscillatoryOptions::new(options.clone()),
        )?;
        plan.integrate(|_: f64| Ok(1.0), &phase)
    };
    let (c, cosine) = solve(FourierWeight::Cosine)?;
    let (s, sine) = solve(FourierWeight::Sine)?;
    Ok(summary(c, s, &[&cosine, &sine]))
}
```

## コルニュ螺旋

次のセルは $t = \pm T_s k/150$（$k = 1, \dots, 150$）で $C(t)$、$S(t)$ を選んだ方法で求め、螺旋を描く。
$t < 0$ の点は奇関数であることを使って $t > 0$ の値から作る。
破線は $|t| \ge 1$ での漸近形で、四角の記号は極限点 $(\pm\tfrac12, \pm\tfrac12)$ である。
縦軸と横軸は同じ範囲 $[-0.8, 0.8]$ に固定するが、表示の縦横比は画面の幅で変わる。
許容誤差は絶対 $10^{-10}$ である。

表は全点での `fresnel_c`、`fresnel_s` との差の最大値、評価回数の合計、成功しなかった点の数を示す。
全点で成功したかどうかをセルの結論として最後に示す。

```rust
//| id: integrate-fresnel-cornu-spiral
//| ref: integrate-fresnel-cornu-spiral
//| title: 方法を選んでコルニュ螺旋を描く
//| run: reactive
//| uses: [integrate-fresnel-model]
//| crates: [scioxide-core, scioxide-integrate, scioxide-special]
//| inputs:
//|   spiral_extent: {"type":"range","label":"弧長の範囲 T_s [-]","description":"t ∈ [−T_s, T_s] を描く。大きいほど極限点のまわりを多く巻く。","min":1,"max":8,"step":0.5,"value":4}
//|   spiral_method: {"type":"select","label":"方法","options":[{"label":"Levin 法","value":"levin"},{"label":"Filon 法","value":"filon"},{"label":"適応 Gauss–Kronrod 則","value":"adaptive"}],"value":"filon"}
//| cases:
//|   - {"id":"levin","label":"Levin 法","description":"同じ螺旋を Levin 法で描く。|t| ≤ 4 では全区間が通常の求積に切り替わる。","inputs":{"spiral_method":"levin"}}
//|   - {"id":"adaptive-long","label":"適応 Gauss–Kronrod 則、T_s = 8","description":"弧長を 8 まで延ばすと、適応 Gauss–Kronrod 則の評価回数が増える。","inputs":{"spiral_method":"adaptive","spiral_extent":8}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"quantities","path":"/rows/0/0","range":{"min":0,"max":1e-13}}
//|       - {"artifact":"quantities","path":"/rows/0/1","range":{"min":20000,"max":40000}}
//|       - {"artifact":"quantities","path":"/rows/0/2","equals":0}
//|       - {"path":"/outputs/2/state","equals":"satisfied"}
//|   - case: levin
//|     expect:
//|       - {"artifact":"quantities","path":"/rows/0/0","range":{"min":0,"max":1e-13}}
//|       - {"path":"/outputs/2/state","equals":"satisfied"}
//|   - case: adaptive-long
//|     expect:
//|       - {"artifact":"quantities","path":"/rows/0/0","range":{"min":0,"max":1e-13}}
//|       - {"artifact":"quantities","path":"/rows/0/1","range":{"min":30000,"max":60000}}
//|       - {"path":"/outputs/2/state","equals":"satisfied"}
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let (mut positive, mut asymptotic) = (Vec::new(), Vec::new());
let (mut worst, mut evaluations, mut failed) = (0.0_f64, 0_usize, 0_usize);
let mut status = String::new();
for k in 1..=150 {
    let t = spiral_extent * k as f64 / 150.0;
    let point = fresnel(spiral_method.as_str(), t, 1e-10).map_err(|e| e.to_string())?;
    let (c, s) = reference(t).map_err(|e| e.to_string())?;
    worst = worst.max((point.c - c).abs()).max((point.s - s).abs());
    evaluations += point.evaluations;
    // 最初に成功しなかった点の終了状態を残す。全点が成功なら最後の点の終了状態になる。
    if failed == 0 {
        status = point.status.clone();
    }
    failed += usize::from(!point.success);
    positive.push([point.c, point.s]);
    if t >= 1.0 {
        let (c, s) = asymptote(t).map_err(|e| e.to_string())?;
        asymptotic.push([c, s]);
    }
}
// C と S は奇関数なので、t < 0 の枝は原点について点対称である。負の枝を逆順に並べ、原点でつなぐ。
let mirror = |points: &[[f64; 2]]| points.iter().map(|[c, s]| [-c, -s]).collect::<Vec<_>>();
let mut curve: Vec<[f64; 2]> = mirror(&positive).into_iter().rev().collect();
curve.push([0.0, 0.0]);
curve.extend_from_slice(&positive);
let (plus, minus) = (&asymptotic, mirror(&asymptotic));
let limits = [[-0.5, -0.5], [0.5, 0.5]];
let (dashed, square) = (
    serde_json::json!({ "lineType": "dashed" }),
    serde_json::json!({ "symbol": "rect" }),
);
emit_chart!(serde_json::json!({
    "kind": "xy",
    "xLabel": "C(t) [-]",
    "yLabel": "S(t) [-]",
    "xMin": -0.8,
    "xMax": 0.8,
    "yMin": -0.8,
    "yMax": 0.8,
    "layers": [
        { "id": "spiral", "kind": "line", "name": "(C(t), S(t))", "points": curve },
        { "id": "plus", "kind": "line", "name": "t ≥ 1 の漸近形", "points": plus, "style": dashed },
        { "id": "minus", "kind": "line", "name": "t ≤ −1 の漸近形", "points": minus, "style": dashed },
        { "id": "limits", "kind": "scatter", "name": "極限点", "points": limits, "style": square }
    ]
}));
let columns = serde_json::json!([
    { "key": "0", "label": "special との差の最大値 [-]", "type": "number", "format": sci3 },
    { "key": "1", "label": "評価回数の合計 [回]", "type": "integer" },
    { "key": "2", "label": "成功しなかった点の数 [点]", "type": "integer" }
]);
emit_table_with_columns!(
    columns,
    vec![(worst, evaluations, failed)],
    metadata = serde_json::json!({ "id": "quantities" })
);
let outcome = if failed == 0 {
    Outcome::satisfied("全点で C と S の積分が成功した")
} else {
    Outcome::partial("成功しなかった点がある")
        .explanation("その点の値は推定値として描いている。")
};
emit_outcome!(
    outcome
        .status(status)
        .diagnostic("special との差の最大値", worst, None)
        .diagnostic("評価回数の合計", evaluations as f64, None)
);
```

既定の入力（$T_s = 4$、Filon 法）では、150 点のどれも $C$ と $S$ の積分が `ToleranceReached` で止まり、`fresnel_c`、`fresnel_s` との差の最大値は $5.6 \times 10^{-16}$ だった。
螺旋は原点を通って二つの極限点のまわりを巻き、$|t| \ge 1$ の破線の円とは $|t|$ が大きいほどよく重なる。
評価回数の合計は Filon 法が 29290 回、Levin 法が 36900 回、適応 Gauss–Kronrod 則が 13620 回である。
$|t| \le 4$ では振動が数回しかなく、Levin 法は全区間を通常の求積に切り替えるので、適応 Gauss–Kronrod 則がいちばん少ない評価回数で済む。
$T_s = 8$ でも適応 Gauss–Kronrod 則は全点で成功し、評価回数は 44400 回で、Filon 法の約 5.3 万回、Levin 法の約 14 万回より少ない。
振動を追跡しない方法の利点は、次の節のように $t$ がさらに大きいときに現れる。

## 大きな t での評価回数と漸近形

次のセルは $t = 10^{-1}, 10^{-0.75}, \dots, 10^{2}$ の 13 点で、三つの方法が $C$ と $S$ を求めるのに使った評価回数を両対数で描く。
成功しなかった結果は描かず、その数を表に示す。
二つ目のグラフは漸近形と `fresnel_c`、`fresnel_s` との差を $t \ge 1$ で描き、次の項の大きさ $1/(\pi^2t^3)$ を破線で重ねる。
二つのグラフは横軸の拡大と移動が連動する。

表は選んだ $t$ での各手法オブジェクト、参照値との差、評価回数、終了状態である。
入力は $t$ と絶対許容誤差 $10^q$ である。

        let result = fresnel(key, t, tolerance).map_err(|e| e.to_string())?;
        if result.success {
            costs[index].push([t, result.evaluations as f64]);
        } else {
            failures[index] += 1;
        }
    }
    if t >= 1.0 {
        // 漸近形の誤差（参照は scioxide-special）と、次の項の大きさ 1/(π²t³)。
        let (c, s) = asymptote(t).map_err(|e| e.to_string())?;
        let (c_ref, s_ref) = reference(t).map_err(|e| e.to_string())?;
        asymptotic_errors.push([t, (c - c_ref).abs().max((s - s_ref).abs())]);
        let radius = 1.0 / (<f64 as RealScalar>::PI * t);
        next_term.push([t, radius * radius / t]);
    }
}
let chosen = RealScalar::powf(10.0_f64, log_t);
let marker =
    serde_json::json!([{ "kind": "line", "axis": "x", "value": chosen, "label": "選んだ t" }]);
let series: Vec<_> = methods
    .iter()
    .zip(&costs)
    .map(|((_, name), points)| {

    })

既定の許容誤差 $10^{-10}$ では、$t \le 10$ の評価回数は三つの方法とも $t$ とともに増える。
$t = 10$ で Filon 法は 680 回、適応 Gauss–Kronrod 則は 1245 回、Levin 法は 3540 回である。
Levin 法が多いのは、選点を使う条件 $a \ge 8$ を満たさない区間で、位相を解像する等分区画の通常の求積を使うからである。
$t \ge 17.8$ では Levin 法と Filon 法の評価回数はほとんど増えず、$t = 100$ でも Levin 法は 2780 回で成功する。

適応 Gauss–Kronrod 則は $t = 17.8$ まで成功するが（4125 回）、$t \ge 31.6$ では `Stagnation` で止まる。
選んだ $t \approx 31.6$ での値は $C = -0.077$ で、参照値 $0.4999968$ とまったく合わない。
振動の数（約 $t^2/4$）に比べて初めの区画が粗すぎ、二分を続けても誤差の推定が十分に減らないので、改善が止まったと判定して打ち切る。
終了状態が成功でないので、この値は採用しない。
Filon 法は $t = 100$ で `Stagnation` で止まり、値は参照値と $2.3 \times 10^{-15}$ 以内で一致するが、終了状態は成功ではない。
許容誤差を $10^{-6}$ に緩めると、Filon 法は 13 点すべてで成功し、$t = 31.6$ では 310 回の評価で済む。
許容誤差を $10^{-12}$ に締めると、Levin 法でも 13 点のうち 2 点が成功しない。

漸近形の誤差は $t \gtrsim 3$ で破線 $1/(\pi^2t^3)$ とほぼ重なり、$t = 31.6$ では $3.2 \times 10^{-6}$ である。
$t = 0.1$ のような小さな $t$ では、漸近形は $C$ と $S$ のどちらとも合わない。
漸近形は大きな $t$ での目安や検算には使えるが、$10^{-10}$ の精度を得るには $t \approx 1000$ 以上が要る。

## 直線の縁による回折

波長 $\lambda$ の平面波が直線の縁（ナイフエッジ）に垂直に入射し、縁から距離 $z$ のスクリーンで強度を測る。
スクリーン上の位置 $x$ を幾何光学の影の境界から測り、明るい側を $x > 0$ とする。
Fresnel 近似のもとで、強度は遮らないときの強度 $I_0$ に対して

$$
\frac{I}{I_0} = \frac12\Bigl[\Bigl(C(w) + \frac12\Bigr)^2 + \Bigl(S(w) + \frac12\Bigr)^2\Bigr], \qquad w = x\sqrt{\frac{2}{\lambda z}}
$$

になる。
$w$ を Fresnel パラメータと呼ぶ。
右辺は螺旋上の点 $(C(w), S(w))$ と極限点 $(-\tfrac12, -\tfrac12)$ の距離の二乗の半分である。
$w \to \infty$ では距離が $\sqrt2$ になって $I = I_0$、影の境界 $w = 0$ では距離が $1/\sqrt2$ で $I = I_0/4$ になる。
明るい側では点が極限点 $(\tfrac12, \tfrac12)$ のまわりを回るので強度が振動し（干渉縞）、影の側 $w < 0$ では点が $(-\tfrac12, -\tfrac12)$ に近づいて強度が単調に減る。

次のセルは He–Ne レーザーの $\lambda = 633$ nm、$z = 1$ m を既定として、$x \in [-1.5, 3]$ mm の 600 点で強度を求める。
$w < 0$ の点は $C(-w) = -C(w)$、$S(-w) = -S(w)$ を使う。
Fresnel 積分は Filon 法で求める。
表は最初の極大（$w_1 = 1.2172$）、最初の極小（$w = 1.8725$）、影の側（$w = -2$）での強度を、`fresnel_c`、`fresnel_s` による値と、影の側では漸近形 $I/I_0 \approx 1/(2\pi^2w^2)$ と比べる。

## まとめ

Fresnel 積分 $C(t)$、$S(t)$ は位相 $s^2$ の振動積分で、`OscillatoryQuadraturePlan` には停留点 $s = 0$ を含む区間を `OscillatoryRegion::stationary`、その先を $|g'|$ の範囲が狭い非停留領域として宣言する。
許容誤差 $10^{-10}$ では、$T_s = 4$ と $8$ の螺旋の全点を適応 Gauss–Kronrod 則がいちばん少ない評価回数で描いた。
ただし 1 点ごとに見ると、$t = 10$ では Filon 法（680 回）が適応 Gauss–Kronrod 則（1245 回）より少ない。
$t$ が 30 程度を超えると、適応 Gauss–Kronrod 則は `Stagnation` で止まって誤った値を返すのに対し、Levin 法と Filon 法は評価回数をほとんど増やさずに、参照値と $10^{-14}$ 以内で一致する値を返す。
Filon 法も $t = 100$ では値が正確なまま `Stagnation` で終わるので、既定の許容誤差で全点が成功したのは Levin 法だけである。
どの方法でも `is_success()` と参照値で結果を確かめ、成功でない終了の値は採用しない。
直線の縁による回折の強度は、螺旋上の点と極限点 $(-\tfrac12, -\tfrac12)$ の距離で決まり、縞の間隔は $\sqrt{\lambda z}$ に比例する。
