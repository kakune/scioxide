多次元の積分法は、問題ごとに得意と不得意が分かれる。
Genz は閉形式で積分できて、振動の速さや局在の鋭さを係数で調節できる試験関数の族を作り、積分法を同じ条件で比べる方法を示した（A. Genz, "Testing multidimensional integration routines", *Tools, Methods and Languages for Scientific and Engineering Computation*, North-Holland, 1984, 81–94）。
この例題ではその中の 3 つの族を $[0, 1]^d$ で積分し、次元適応の疎格子（`SparseGridPlan`）、Genz–Malik の適応 cubature（`CubaturePlan`）、Monte Carlo 法（`MonteCarloIntegrator` と `RandomStreams`）、乱択準 Monte Carlo 法（`MonteCarloIntegrator` と `QmcReplicatePlan`）の誤差を、評価回数に対して比べる。
確率的な二つの方法については、示された標準誤差（SE）が実際の誤差の尺度として使えるかを、シードを変えた反復で確かめる。

各方法のアルゴリズムは [疎格子と乱択準 Monte Carlo](../../algorithms/sparse-grids-and-qmc/)、[テンソル積則と Genz–Malik 適応 cubature](../../algorithms/multidimensional-and-monte-carlo/)、[Monte Carlo 積分の推定量と統計](../../algorithms/monte-carlo-integration/) にある。

## 3 つの試験関数と閉形式

係数 $a_i > 0$、位置 $w_i \in [0, 1)$、位相 $u_1 \in [0, 1)$ を使い、次の 3 つの族を考える。

$$
\begin{aligned}
f_{\mathrm{osc}}(\boldsymbol x) &= \cos\Bigl(2\pi u_1 + \sum_{i=1}^d a_i x_i\Bigr) &&\text{（振動型）}\\
f_{\mathrm{peak}}(\boldsymbol x) &= \prod_{i=1}^d \frac{1}{a_i^{-2} + (x_i - w_i)^2} &&\text{（積ピーク型）}\\
f_{\mathrm{gauss}}(\boldsymbol x) &= \exp\Bigl(-\sum_{i=1}^d a_i^2 (x_i - w_i)^2\Bigr) &&\text{（Gauss 型）}
\end{aligned}
$$

振動型は全体に広がった波で、$a_i$ が大きいほど $x_i$ 方向に速く振動する。
積ピーク型と Gauss 型は点 $\boldsymbol w$ に山を持ち、$a_i$ が大きいほど $x_i$ 方向の幅（約 $1/a_i$）が狭い。
どれも実解析的である。
Genz の 6 つの族のうち、角ピーク型と、導関数が不連続な連続型、関数が不連続な不連続型は扱わない。

積ピーク型と Gauss 型は座標ごとの積なので、積分は 1 次元の積分の積になる。

$$
\int_0^1 \frac{dx}{a^{-2} + (x - w)^2} = a\bigl[\arctan(a(1 - w)) + \arctan(aw)\bigr],
\qquad
\int_0^1 e^{-a^2(x - w)^2}\,dx = \frac{\sqrt\pi}{2a}\bigl[\operatorname{erf}(a(1 - w)) + \operatorname{erf}(aw)\bigr]
$$

振動型は $\cos\theta = \operatorname{Re} e^{i\theta}$ と書くと指数関数の積になり、

$$
\int_{[0,1]^d} f_{\mathrm{osc}}\,d\boldsymbol x = \operatorname{Re}\Bigl[e^{2\pi i u_1}\prod_{i=1}^d \frac{e^{ia_i} - 1}{ia_i}\Bigr],
\qquad
\frac{e^{ia} - 1}{ia} = \frac{\sin a}{a} + i\,\frac{2\sin^2(a/2)}{a}
$$

となる。
虚部を $1 - \cos a$ ではなく $2\sin^2(a/2)$ で計算すると、$a$ が小さいときの打ち消しを避けられる。
誤差関数は scioxide-special の `erf`、逆正接と三角関数は `RealScalar::atan` などで計算する。

## 難しさの正規化

Genz にならい、$a_i$ は $(0, 1)$ の一様乱数 $\tilde a_i$ を引いて

$$
a_i = h\,\frac{\tilde a_i}{\sum_j \tilde a_j}, \qquad \sum_{i=1}^d a_i = h
$$

と正規化する。
$h$ を難しさと呼び、$h$ を固定して $d$ を変えると、1 軸あたりの $a_i$ は $h/d$ 程度に小さくなる。
次元の増加による難しさと、1 軸あたりの振動や鋭さによる難しさを分けて比べるためである。
$w_i$ と $u_1$ も同じ生成器から引くので、問題は族、$d$、$h$、問題のシードで決まる。
生成器は scioxide-random の `Philox4x64` で、$\tilde a_i$ は 0 を含まない `next_open_float` で引く。

積ピーク型の積分値は $d$ とともに桁が大きく変わる（$a_i$ が小さいと各因子が $a_i^2$ 程度になる）。
そこで以下では閉形式 $I$ との相対誤差 $|Q - I|/|I|$ と、SE を $|I|$ で割った相対 SE を使う。
振動型では問題のシードによっては $I$ が 0 に近くなり、相対誤差が大きく見える。

次の定義のブロックは三つのセルで共有する。
`Family` が族、`Genz::new` が上の正規化による係数の生成、`value` が $f(\boldsymbol x)$、`exact` が閉形式である。
`from_problem` は最初のセルが渡す族・次元・難しさ・問題のシードから同じ試験関数を作り直し、`sample_estimate` は後の節で使う Monte Carlo と乱択 QMC の 1 回の推定を行う。

```rust
//| id: integrate-genz-model
//| kind: definitions
//| title: Genz の試験関数と閉形式
//| crates: [scioxide-core, scioxide-integrate, scioxide-random, scioxide-special]
use scioxide_core::{Budget, ExecutionContext, SciOxideError, Interval, RealScalar};
use scioxide_integrate::{
    IntegrationReport, MonteCarloIntegrator, MonteCarloOptions, MonteCarloStatistics, RandomStreams,
};
use scioxide_random::{
    Philox4x64, QmcPlan, QmcReplicateOptions, QmcReplicatePlan, Rng, SeedableRng,
};

/// Genz の試験関数の族。
#[derive(Clone, Copy, PartialEq)]
pub(crate) enum Family {
    Oscillatory,
    ProductPeak,
    Gaussian,
}

impl Family {
    /// 入力の選択肢の文字列から族を選ぶ。
    pub(crate) fn parse(name: &str) -> Result<Self, String> {
        match name {
            "振動型" => Ok(Self::Oscillatory),
            "積ピーク型" => Ok(Self::ProductPeak),
            "Gauss 型" => Ok(Self::Gaussian),
            _ => Err(format!("未知の族: {name}")),
        }
    }
}

/// 試験関数 f(x) と、その係数 a_i（Σ a_i = h）、位置 w_i、位相 u₁。
pub(crate) struct Genz {
    pub(crate) family: Family,
    pub(crate) a: Vec<f64>,
    pub(crate) w: Vec<f64>,
    pub(crate) u: f64,
}

impl Genz {
    /// シード seed の生成器から a_i を (0, 1) の一様乱数で引いて Σ a_i = h に正規化し、
    /// 続けて w_i ∈ [0, 1) と u₁ ∈ [0, 1) を引く。
    pub(crate) fn new(family: Family, d: usize, h: f64, seed: u64) -> Result<Self, SciOxideError> {
        let mut rng = Philox4x64::from_seed(seed);
        let raw = (0..d)
            .map(|_| rng.next_open_float())
            .collect::<Result<Vec<f64>, _>>()?;
        let total: f64 = raw.iter().sum();
        let a = raw.iter().map(|r| h * r / total).collect();
        let w = (0..d)
            .map(|_| rng.next_float())
            .collect::<Result<Vec<f64>, _>>()?;
        let u = rng.next_float()?;
        Ok(Self { family, a, w, u })
    }

    /// 最初のセルが export した族・次元・難しさ・問題のシードから、同じ試験関数を作り直す。
    pub(crate) fn from_problem(problem: &serde_json::Value) -> Result<Self, String> {
        let number = |key: &str| problem[key].as_f64().ok_or(format!("{key} がない"));
        let family = Family::parse(problem["family"].as_str().ok_or("族がない")?)?;
        let d = number("dimension")? as usize;
        let seed = number("problem_seed")? as u64;
        Self::new(family, d, number("difficulty")?, seed).map_err(|e| e.to_string())
    }

    /// 被積分関数 f(x)、x ∈ [0, 1]^d。
    pub(crate) fn value(&self, x: &[f64]) -> f64 {
        let terms = self.a.iter().zip(&self.w).zip(x);
        match self.family {
            Family::Oscillatory => {
                let phase: f64 = self.a.iter().zip(x).map(|(a, x)| a * x).sum();
                RealScalar::cos(<f64 as RealScalar>::TAU * self.u + phase)
            }
            Family::ProductPeak => terms
                .map(|((a, w), x)| 1.0 / (1.0 / (a * a) + (x - w) * (x - w)))
                .product(),
            Family::Gaussian => {
                let sum: f64 = terms.map(|((a, w), x)| a * a * (x - w) * (x - w)).sum();
                RealScalar::exp(-sum)
            }
        }
    }

    /// 閉形式（1 次元の積分の積）。
    pub(crate) fn exact(&self) -> Result<f64, SciOxideError> {
        let pairs = self.a.iter().zip(&self.w);
        match self.family {
            Family::Oscillatory => {
                // Re[e^{2πi u₁} Π (e^{i a} − 1)/(i a)]。
                // (e^{ia} − 1)/(ia) = sin a / a + i·2 sin²(a/2) / a。
                let (sine, cosine) = RealScalar::sin_cos(<f64 as RealScalar>::TAU * self.u);
                let (mut re, mut im) = (cosine, sine);
                for &a in &self.a {
                    let half = RealScalar::sin(0.5 * a);
                    let (fr, fi) = (RealScalar::sin(a) / a, 2.0 * half * half / a);
                    (re, im) = (re * fr - im * fi, re * fi + im * fr);
                }
                Ok(re)
            }
            Family::ProductPeak => Ok(pairs
                .map(|(&a, &w)| a * (RealScalar::atan(a * (1.0 - w)) + RealScalar::atan(a * w)))
                .product()),
            Family::Gaussian => {
                let root_pi = RealScalar::sqrt(<f64 as RealScalar>::PI);
                let mut product = 1.0;
                for (&a, &w) in pairs {
                    let mass = scioxide_special::erf(a * (1.0 - w))? + scioxide_special::erf(a * w)?;
                    product *= root_pi / (2.0 * a) * mass;
                }
                Ok(product)
            }
        }
    }
}

/// 評価回数 n の Monte Carlo（replicates = 1）か乱択 QMC（n/R 点の Sobol 点列を R 回乱択化）。
/// シード seed から Monte Carlo の乱数の根と、QMC の乱択化の鍵を作る。
pub(crate) fn sample_estimate(
    model: &Genz,
    n: usize,
    replicates: usize,
    seed: u64,
) -> Result<(f64, Option<MonteCarloStatistics<f64>>, IntegrationReport<f64>), SciOxideError> {
    let d = model.a.len();
    let bounds = vec![Interval::new(0.0, 1.0)?; d];
    // MonteCarloOptions の標本数と独立反復数は、QMC の 1 複製の点数と独立反復数に一致させる。
    let options = MonteCarloOptions::default()
        .with_samples(Budget::try_from(n / replicates)?)
        .with_replicates(replicates);
    let plan = MonteCarloIntegrator::new(&bounds, options)?;
    let cx = ExecutionContext::sequential();
    let mut workspace = plan.workspace(1, cx)?;
    let f = |x: &[f64]| Ok(model.value(x));
    let mut value = 0.0;
    let report = if replicates == 1 {
        let root = Philox4x64::from_seed(seed);
        plan.integrate_into(&f, RandomStreams::new(&root, 0), &mut value, &mut workspace, cx)?
    } else {
        let sobol = QmcPlan::sobol(d)?;
        let key = Philox4x64::from_key([seed, 0]);
        let options = QmcReplicateOptions::default()
            .with_replicates(replicates)
            .with_points_per_replicate(n / replicates);
        let qmc = QmcReplicatePlan::new(&sobol, &key, options)?;
        plan.integrate_into(&f, &qmc, &mut value, &mut workspace, cx)?
    };
    Ok((value, workspace.statistics()[0].clone(), report))
}
```

## 決定論的な方法の誤差と誤差推定

4 つの方法に、同じ評価回数の上限 $N = 2^k$（$k = 6, 7, \dots, m$）を与えて比べる。
まず決定論的な二つの方法を扱う。

- 疎格子：入れ子の Clenshaw–Curtis 則による次元適応の Smolyak 求積で、`SparseGridOptions` の評価回数の上限（`with_max_evaluations`）と添字の数の上限を $N$、最高の水準（`with_max_level`）を $k - 1$（1 次元の則の点数 $2^{k-1} + 1 \le N$）にする。
- Genz–Malik：次数 7 と 5 の埋め込み対による適応 cubature で、1 領域に $2^d + 2d^2 + 2d + 1$ 回（$d = 5$ では 93 回）の評価を使う。
  $d$ とともに評価回数が $2^d$ で増えるので、$d \le 5$ だけで計算し、1 領域の評価回数より小さい上限は飛ばす。

どちらにも届かない許容誤差 $10^{-13}$ を与え、評価回数の上限で止める。
したがって終了状態は `BudgetLimit(Evaluation)` で、返る値は推定値である。
この比較の目的は、同じ評価回数でどこまで誤差が下がるかを見ることで、許容誤差に届いたかどうかではない。
疎格子の誤差は、$r$ 階までの混合偏導関数が有界な関数で $O\bigl(N^{-r}(\log N)^{(r + 1)(d - 1)}\bigr)$ で減り、実解析的な関数ではさらに速い。
ただし、その対数の因子と、1 軸あたりの振動や鋭さが、実用的な $N$ での誤差を決める。
両方の方法は誤差推定を返すが、どちらも隣り合う則の差から作る経験的な量（`ErrorReliability::Heuristic`）である。

次のセルは入力として族、次元 $d$、難しさ $h$、評価回数の上限の指数 $m$、問題のシードを受け取り、各上限での相対誤差と、$|I|$ で割った誤差推定を表にする。
最後の列は誤差推定と実際の誤差の比で、1 より大きければ推定が安全側に外れている。
このセルは問題の設定と結果を、次の二つのセルに渡す。

```rust
let d = dimension as usize;
let model = Genz::new(Family::parse(&family)?, d, difficulty, problem_seed as u64)
    .map_err(|e| e.to_string())?;
let exact = model.exact().map_err(|e| e.to_string())?;
let f = |x: &[f64]| Ok(model.value(x));
let bounds = vec![Interval::new(0.0, 1.0).map_err(|e| e.to_string())?; d];

let region = (1 << d) + 2 * d * d + 2 * d + 1;

let mut curves: [Vec<[f64; 2]>; 2] = [Vec::new(), Vec::new()];

let (mut rows, mut final_rows) = ([Vec::new(), Vec::new()], Vec::new());

    let n = 1_usize << k;
    let budget = Budget::try_from(n).map_err(|e| e.to_string())?;
    // 疎格子: 最高の水準は 2^level + 1 ≤ N を満たす k − 1。
    let options = SparseGridOptions::default()
        .with_tolerance(tolerance.clone())
        .with_max_level(k as usize - 1)
        .with_max_indices(budget)
        .with_max_evaluations(budget);
    let plan = SparseGridPlan::new(d, options).map_err(|e| e.to_string())?;
    let mut results = vec![(
        "疎格子",
        plan.integrate(&f, &bounds).map_err(|e| e.to_string())?,
    )];
    if d <= 5 && n >= region {
        let options = SubdivisionOptions::default()
            .with_tolerance(tolerance.clone())
            .with_max_subdivisions(budget)
            .with_max_evaluations(Some(budget));
        let plan = CubaturePlan::new(&bounds, options).map_err(|e| e.to_string())?;
        results.push(("Genz–Malik", plan.integrate(&f).map_err(|e| e.to_string())?));
    }
    for (index, (name, (value, report))) in results.into_iter().enumerate() {
        // 相対誤差と |I| で割った誤差推定。族ごとに大きさの違う積分を同じ尺度で比べる。
        let error = (value - exact).abs() / exact.abs();
        let estimate = report.error_estimate().map(|e| e / exact.abs());
        let ratio = estimate.map(|e| e / error);
        let status = report.termination().to_string();
        let evaluations = report.evaluations();
        curves[index].push([evaluations as f64, error]);
        rows[index].push((name, n, evaluations, error, estimate, ratio, status.clone()));
        if k == budget_exponent as u32 {
            final_rows.push((name, evaluations, value, error, estimate, status));
        }
    }
}

        { "key": "1", "label": "値 [-]", "type": "number", "format": { "significantDigits": 12 } }
    ]),
    vec![("閉形式 I", exact)],
    metadata = serde_json::json!({ "id": "quantities" })
);
```

既定の入力（Gauss 型、$d = 5$、$h = 6$、$N \le 2^{12}$）では、閉形式は $I = 0.2546027$ である。
疎格子の相対誤差は $N = 64$ の $6\times10^{-3}$ から $N = 4096$ の $3\times10^{-10}$ まで下がり、Genz–Malik は $N = 4096$ で $4\times10^{-7}$ である。
疎格子の誤差推定（$|I|$ で割って $6\times10^{-5}$）は実際の誤差より 5 桁大きく、Genz–Malik の推定（$4\times10^{-4}$）も 3 桁大きい。
どちらの推定も経験的なもので、ここでは安全側に外れているが、上界ではない。
Genz–Malik は上限 64 回では 1 領域（93 回）も評価できないので行がなく、上限 128 回と 256 回では分割 1 回（186 回）が収まらず 93 回で止まる。
疎格子の誤差は単調には減らず、$N = 128$ の $9\times10^{-5}$ から $N = 256$ では $4\times10^{-4}$ に増える。
隣り合う上限の結果が近いことだけで収束を判断しない。

`oscillatory-10d` の場合（振動型、$d = 10$）は、Genz–Malik を計算しない（1 領域に $2^{10} + 221 = 1245$ 回の評価が要る）。
疎格子の相対誤差は $4096$ 回で $4\times10^{-6}$ になる。
係数を $\sum a_i = h$ で正規化したので、$d$ が増えると 1 軸あたりの振動が遅くなり、各軸に要る細かさが下がる。
`sharp-gauss` の場合（Gauss 型、$h = 20$）は、山の幅が $1/a_i \approx 1/4$ 程度に狭まり、$N \approx 4000$ での相対誤差は疎格子が $9\times10^{-5}$、Genz–Malik が $4\times10^{-4}$ になる。
疎格子の誤差推定は相対値で 7 で、実際の誤差より 5 桁大きい。

## 確率的な方法との比較

確率的な二つの方法は次のとおりである。

- Monte Carlo：独立な一様乱数の $N$ 点の平均で、SE は標本分散から求める。
- 乱択 QMC：$N/8$ 点の Sobol 点列を `QmcReplicatePlan` で 8 回独立に乱択化（線形スクランブルとデジタルシフト）し、8 個の推定の平均とばらつきから推定値と SE を求める。
  `MonteCarloOptions` の標本数（`with_samples`）と独立反復数（`with_replicates`）を、`QmcReplicatePlan` の 1 複製の点数と独立反復数に一致させる必要がある。
  一致しないと `integrate_into` は `InvalidInput` を返す。

Monte Carlo の誤差は $\sigma_f/\sqrt N$（$\sigma_f$ は $f$ の標準偏差）で、次元によらず $N^{-1/2}$ で減る。
Sobol 点列をスクランブルで乱択化した QMC は、$f$ が滑らかなら RMSE が $N^{-1}$ より速く減ることがある（Owen の理論では $O(N^{-3/2}(\log N)^{(d-1)/2})$）が、漸近に入るまでの $N$ は $d$ とともに大きくなる。

次のセルは前のセルの問題を受け取り、標本のシードを選んで、同じ上限 $N = 2^k$ の Monte Carlo と乱択 QMC を実行する。
グラフは 4 つの方法の相対誤差（記号）と、確率的な方法の相対 SE（破線）を評価回数に対して両対数で描く。
表は $N = 2^m$ での 4 つの方法の結果で、確率的な方法には誤差と SE の比を示す。

```rust
//|   - {"id":"other-seed","label":"標本のシード 2","description":"シードを変えると確率的な方法の誤差の曲線が変わるが、相対 SE の傾きはほとんど変わらない。","inputs":{"sample_seed":2}}

    serde_json::from_value(problem["curves"].clone()).map_err(|e| e.to_string())?;

    serde_json::from_value(problem["final_rows"].clone()).map_err(|e| e.to_string())?;

    .into_iter()

        (name, n, value, error, estimate, None, status)
    })
    .collect();

        "yType": "log"

);

let sig3 = serde_json::json!({ "significantDigits": 3 });
let columns = serde_json::json!([

    { "key": "1", "label": "評価回数 [回]", "type": "integer" },
    { "key": "2", "label": "推定値 [-]", "type": "number", "format": { "significantDigits": 10 } },
    { "key": "3", "label": "相対誤差 [-]", "type": "number", "format": sci3 },
    { "key": "4", "label": "誤差推定・SE / |I| [-]", "type": "number", "format": sci3, "nullText": "—" },

]);
```

既定の入力では、$N \approx 4000$ での相対誤差は、疎格子が $3\times10^{-10}$、Genz–Malik が $4\times10^{-7}$、乱択 QMC が $3\times10^{-4}$、Monte Carlo が $3\times10^{-3}$ で、滑らかな被積分関数では決定論的な二つの方法が桁違いに小さい。
Monte Carlo の相対 SE は $N = 64$ の $0.108$ から $N = 4096$ の $0.0138$ まで、両対数の傾き約 $-0.49$ で $N^{-1/2}$ に沿って下がる。
乱択 QMC の相対 SE は $0.061$ から $3.3\times10^{-4}$ まで傾き約 $-1.26$ で下がり、$N^{-1}$ より速い。
二つの方法の相対誤差（記号）は、それぞれの破線のまわりを上下する。
1 回の実行での誤差と SE の比は 0.2 や 2.5 にもなり、この 1 本の曲線だけでは SE が誤差の尺度として正しいかを判断できない。
それを確かめるのが次のセルである。

前のセルの `oscillatory-10d` に合わせて実行すると、乱択 QMC（$3\times10^{-4}$）と Monte Carlo（$7\times10^{-4}$）はどちらも疎格子（$4\times10^{-6}$）より大きい誤差になる。
`sharp-gauss` に合わせると、Monte Carlo が $6\times10^{-3}$、乱択 QMC が $4\times10^{-2}$ になり、このシードでは乱択 QMC のほうが大きい。
局在した山では確率的な方法どうしの順位も標本の偶然に左右される。

## 示された標準誤差の検証

確率的な方法の推定値はシードごとに異なる確率変数である。
示された SE が誤差の正しい尺度なら、シードを変えて推定を繰り返したときの実際の RMSE（閉形式との差の二乗平均の平方根）は SE の平均に近く、95 % 信頼区間は約 95 % の割合で閉形式を含む。
Monte Carlo の区間は自由度 $N - 1$、乱択 QMC の区間は複製の数 8 から自由度 7 の Student の $t$ 分布で作る（`MonteCarloOptions` の既定）。
区間の半幅は $t$ 分布の分位点と SE の積で、SE は `estimator_variance()` が返す推定量の分散から求める。
推定量の分散は、Monte Carlo では標本分散 $s^2$ を $N$ で割った $s^2/N$、乱択 QMC では 8 個の推定値の標本分散を 8 で割った値である。
乱択 QMC の SE は 8 個の値のばらつきから求めるので、1 回ごとの SE の値自体が大きくばらつき、区間の幅もそれに応じて広くなる。

次のセルは最初のセルの問題（族、$d$、$h$、問題のシード）を受け取り、標本のシードを $s_0 + 1, s_0 + 2, \dots$ と変えて、評価回数 $N = 2^k$ の Monte Carlo と乱択 QMC を繰り返す。
シードのずらし $s_0$ も入力で、変えると別の反復の組で同じ検証をやり直せる。
グラフは反復ごとの推定値と 95 % 信頼区間をエラーバーで描き、横線が閉形式である。
表は区間が閉形式を含んだ割合、示された SE の平均、実際の RMSE、その比を示す。
反復が 20 回なら、含んだ割合には $\sqrt{0.95\times0.05/20} \approx 0.05$ 程度、RMSE の推定には約 16 %（$1/\sqrt{2\times20}$）のばらつきがある。

## まとめ

Genz の試験関数は閉形式を持ち、振動の速さや山の鋭さを $\sum a_i = h$ で調節できるので、多次元の積分法を同じ評価回数で比べるのに使える。
既定の Gauss 型と `oscillatory-10d` では、同じ評価回数での誤差は疎格子が最も小さく、Monte Carlo が最も大きく、$d = 10$ でも疎格子が有利だった。
鋭い山の `sharp-gauss` では、このシードで乱択 QMC の誤差が Monte Carlo より大きくなった。
決定論的な二つの方法の誤差推定は経験的で、実際の誤差より何桁も大きいことがあり、`BudgetLimit(Evaluation)` で止まった値は推定値として扱う。
乱択 QMC は `QmcReplicatePlan` の独立反復数と点数を `MonteCarloOptions` の `with_replicates` と `with_samples` に一致させて使い、その SE はシードを変えた反復で実際の RMSE と一致した。
被積分関数が局在した山を持つ、あるいは不連続な場合は、どの方法の優位も入れ替わりうるので、評価回数を変えた比較と、確率的な方法の SE による誤差の見積もりを組み合わせる。
