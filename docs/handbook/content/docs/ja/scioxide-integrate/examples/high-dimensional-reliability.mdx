製品の信頼性評価や構造物の安全率の解析では、多数の不確かな要素をまとめた性能が基準を超える確率を求めることが多い。
要素の数を次元とする積分になるので、次元が上がると格子による求積は評価回数が指数的に増えて使えなくなる。
この例題では、独立な部品性能の平均が閾値を超える確率を Monte Carlo 積分で求め、Irwin–Hall 分布による厳密な確率と、標準誤差・信頼区間・独立な複製で照合する。

## 超過確率と指示関数の積分

$d$ 個の部品の性能 $U_1, \ldots, U_d$ が独立に区間 $[0, 1]$ の一様分布に従うとする。
性能は規格の範囲を 0 から 1 に写した無次元の量で、確率も無次元である。
平均性能 $\bar{U} = \frac{1}{d}\sum_j U_j$ が閾値 $q$ 以上になる確率は、同時密度が単位超立方体の上で 1 なので

$$
p = \Pr(\bar{U} \ge q) = \int_{[0, 1]^d} \mathbf{1}\left\{\sum_{j=1}^{d} u_j \ge d q\right\} du_1 \cdots du_d
$$

という指示関数の積分になる。
被積分関数は超平面 $\sum_j u_j = dq$ で 0 から 1 に跳ぶので、滑らかさを前提にする高次の求積則は効かない。

## Irwin–Hall 分布による厳密な確率

和 $S_d = \sum_j U_j$ の分布は Irwin–Hall 分布で、その分布関数は包除原理から

$$
F_d(s) = \Pr(S_d \le s) = \frac{1}{d!}\sum_{k=0}^{\lfloor s \rfloor} (-1)^k \binom{d}{k} (s - k)^d \qquad (0 \le s \le d)
$$

である。
$q > 1/2$ で $1 - F_d(dq)$ をそのまま計算すると、1 に近い数どうしの引き算で桁が落ちる。
$1 - U_j$ も $[0, 1]$ の一様分布に従うことを使うと

$$
p = \Pr\left(\sum_j U_j \ge dq\right) = \Pr\left(\sum_j (1 - U_j) \le d(1 - q)\right) = F_d\bigl(d(1 - q)\bigr)
$$

となり、下側の裾の和を直接計算できる。
$d \le 10$ では二項係数と階乗は整数として厳密に表せ、和の項は算術演算だけで求まる。

## Monte Carlo 推定量と標準誤差

$N$ 個の一様な点 $\boldsymbol{u}_i$ での指示関数の値 $Y_i \in \{0, 1\}$ の平均 $\hat{p} = \frac{1}{N}\sum_i Y_i$ は $p$ の不偏推定量で、

$$
\operatorname{SE}(\hat{p}) = \sqrt{\frac{p(1 - p)}{N}}, \qquad \frac{\operatorname{SE}(\hat{p})}{p} = \sqrt{\frac{1 - p}{Np}} \approx \frac{1}{\sqrt{Np}} \quad (p \ll 1)
$$

である。
$Np$ は $N$ 個の点のうち事象に入る点の数の期待値で、相対的な精度はこの数だけで決まり、次元 $d$ には直接よらない。
ただし $d$ が増えると、中心極限定理により $\bar{U}$ は $1/2$ の周りに分散 $1/(12d)$ で集中するので、$q > 1/2$ の $p$ は急に小さくなり、同じ $N$ でも $Np$ が減る。

`MonteCarloIntegrator` は観測値の標本分散 $s^2$ から推定量の分散 $s^2/N$ を求める。
`MonteCarloStatistics` はこの分散を `estimator_variance()` で返し、その平方根を標準誤差として、自由度 $N - 1$ の Student-t 分布による 95 % 信頼区間（既定）を作る。
これらは統計的な主張で、有限の分散を仮定する。
事象が一度も観測されないと（$K = \sum_i Y_i = 0$）、推定値も標本分散も 0 になり、区間は幅を持たない。
これは確率が 0 であることを意味せず、標本数が事象の希少さに対して足りないことを示す。
そのときは $p \lesssim 3/N$（95 % の片側上限、3 の法則）や Clopper–Pearson 区間のような二項分布に基づく区間を使う。

## 乱数の流れと複製

`RandomStreams::new(&root, stream)` は、分割可能な生成器 `root` の番号 `stream` の流れから一様乱数を取り出す。
標本は 1024 個ずつのブロックに分かれ、ブロック $b$ は `root` の部分流 $(\text{stream}, b)$ から乱数を取るので、結果は実行の並列度によらない。
`MonteCarloOptions::with_replicates(R)` を指定すると、1 回の呼び出しで $R$ 個の独立な複製をそれぞれ $N$ 点で計算する。
複製は重ならないブロックを使い、作業領域の `children` が各複製の推定値と、その複製の観測値からの統計量を返す。
全体の推定値は $R$ 個の推定値の平均で、全体の `statistics` は複製のばらつきから標準誤差を作る（`VarianceBasis::Replicates`、自由度 $R - 1$）。

次のブロックは三つのセルが共有する定義である。
`exceedance` が厳密な確率 $F_d(d(1 - q))$、`estimate_exceedance` が指示関数を `MonteCarloIntegrator` で積分する手順に対応する。
乱数のシードと標本数、複製の数は各セルの入力にする。

```rust
//| id: integrate-reliability-model
//| kind: definitions
//| title: Irwin–Hall 分布の厳密な確率と Monte Carlo の手順
//| crates: [scioxide-core, scioxide-integrate, scioxide-random]
use scioxide_core::{
    ExecutionContext, SciOxideError, Interval, RealScalar, checked_binomial, checked_factorial,
};
use scioxide_integrate::{
    IntegrationReport, MonteCarloIntegrator, MonteCarloOptions, MonteCarloWorkspace, RandomStreams,
};
use scioxide_random::Philox4x64;

/// p = Pr(Σ U_j ≥ dq) = F_d(d(1 − q))（包除原理、算術演算だけで計算する）。
pub(crate) fn exceedance(d: usize, q: f64) -> Result<f64, SciOxideError> {
    let s = d as f64 * (1.0 - q);
    let mut sum = 0.0;
    for k in 0..=(RealScalar::floor(s) as usize).min(d) {
        let term = checked_binomial(d, k)? as f64 * RealScalar::powi(s - k as f64, d as i32);
        sum += if k % 2 == 0 { term } else { -term };
    }
    Ok(sum / checked_factorial(d)? as f64)
}

/// 指示関数 1{Σ u_j ≥ dq} を [0, 1]^d で積分する。root の流れ 0 を使う。
pub(crate) fn estimate_exceedance(
    d: usize,
    q: f64,
    options: MonteCarloOptions,
    root: &Philox4x64,
) -> Result<(f64, IntegrationReport<f64>, MonteCarloWorkspace<f64>), SciOxideError> {
    let bounds = vec![Interval::new(0.0, 1.0)?; d];
    let plan = MonteCarloIntegrator::new(&bounds, options)?;
    let mut workspace = plan.workspace(1, ExecutionContext::sequential())?;
    let threshold = d as f64 * q;
    let event = |u: &[f64]| {
        Ok(if u.iter().sum::<f64>() >= threshold {
            1.0
        } else {
            0.0
        })
    };
    let mut value = 0.0;
    let report = plan.integrate_into(
        &event,
        RandomStreams::new(root, 0),
        &mut value,
        &mut workspace,
        ExecutionContext::sequential(),
    )?;
    Ok((value, report, workspace))
}
```

## 1 回の推定と理論値

次のセルは部品の数 $d$、標本数 $N = 2^m$、閾値 $q$、乱数のシードを選び、超過確率を 1 回推定する。
表は推定値、厳密値、示された標準誤差と理論値、95 % 信頼区間、推定値と厳密値の差を示された標準誤差で割った $z$、事象に入った点の数 $K$ と期待値 $Np$ を示す。
判定は事象が観測されて標準誤差が定義できたかを示す。
$d$、$N$、$q$ は次のセルに渡す。

$z = 1.44$ で、差は標準誤差の 1.4 倍にあたり、95 % 区間 $[0.0438, 0.0531]$ は厳密値を含む。

推定値はシードごとに標準誤差の程度でばらつき、$|z|$ が 2 を超えるシードも 20 回に 1 回程度はある。

$q = 0.86$、$N = 2^8$ では $Np = 0.12$ で、このシードでは事象が一度も観測されない。
推定値、標準誤差、区間はすべて 0 になり、判定は failed になる。
このとき 3 の法則による上限 $3/N = 0.012$ は厳密値 $4.9 \times 10^{-4}$ を含むが、推定としては粗い。

## 独立な複製と区間の被覆率

1 回の推定で区間が厳密値を含むかどうかは偶然に左右されるので、区間の意味は複製を重ねて確かめる。
次のセルは同じ $d$、$N$、$q$ で $R$ 個の複製を 1 回の呼び出しで計算する。
グラフは各複製の推定値と、その複製の観測値から作った 95 % 区間をエラーバーで示し、厳密値を横線、厳密値 $\pm 2$ 標準誤差（理論値）を帯で示す。
表は複製の平均と、その標準誤差（複製のばらつきから作る）、平均と厳密値の差を標準誤差で割った $z$、複製の推定値の標準偏差と理論値 $\sqrt{p(1 - p)/N}$、区間が厳密値を含んだ割合（被覆率）を示す。
被覆率そのものにも、二項分布による標準誤差 $\sqrt{0.95 \times 0.05/R}$ のばらつきがある。

//|   - {"id":"more-replicates","label":"R = 40","description":"複製を増やすと、被覆率の標準誤差が小さくなる。","inputs":{"replicate_count":40}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"replicates","path":"/rows/0/2","approx":{"value":0.0645255118506666,"rtol":1e-12}}
//|       - {"artifact":"replicates","path":"/rows/0/4","range":{"min":-4,"max":4}}
//|       - {"artifact":"replicates","path":"/rows/0/5","range":{"min":0.0027,"max":0.0082}}
//|       - {"artifact":"replicates","path":"/rows/0/7","range":{"min":0.75,"max":1}}
//|   - case: rare
//|     expect:
//|       - {"artifact":"replicates","path":"/rows/0/9","range":{"min":1}}
//|       - {"artifact":"replicates","path":"/rows/0/4","range":{"min":-4,"max":4}}
//|   - case: more-replicates
//|     expect:
//|       - {"artifact":"replicates","path":"/rows/0/8","approx":{"value":0.03446,"atol":1e-4}}
//|       - {"artifact":"replicates","path":"/rows/0/7","range":{"min":0.8,"max":1}}
use scioxide_core::{Budget, RealScalar};
use scioxide_integrate::MonteCarloOptions;
use scioxide_random::{Philox4x64, SeedableRng};

let d = replicate_components as usize;
let samples = 1_usize << (replicate_sample_exponent as u32);
let replicates = replicate_count as usize;
let q = replicate_threshold;
let exact = exceedance(d, q).map_err(|e| e.to_string())?;
let predicted = RealScalar::sqrt(exact * (1.0 - exact) / samples as f64);
let root = Philox4x64::from_seed(replicate_seed as u64);
let options = MonteCarloOptions::default()
    .with_samples(Budget::try_from(samples).map_err(|e| e.to_string())?)
    .with_replicates(replicates);
let (mean, _, workspace) =
    estimate_exceedance(d, q, options, &root).map_err(|e| e.to_string())?;

// 各複製の推定値と、その複製の観測値から作った 95 % 区間。
let (mut bars, mut estimates) = (Vec::new(), Vec::new());
let (mut covered, mut empty) = (0_usize, 0_usize);
for (r, child) in workspace.children().enumerate() {
    let value = child.values().ok_or("複製の推定値がない")?[0];
    let mut statistics = child.statistics()[0].clone().ok_or("複製の統計量がない")?;
    let interval = statistics
        .confidence_interval()
        .map_err(|e| e.to_string())?;
    covered += usize::from(interval.lower() <= exact && exact <= interval.upper());
    empty += usize::from(value == 0.0);
    bars.push([r as f64 + 1.0, value, interval.lower(), interval.upper()]);
    estimates.push(value);
}
let squares: f64 = estimates.iter().map(|e| (e - mean) * (e - mean)).sum();
let spread = RealScalar::sqrt(squares / (replicates - 1) as f64);
let aggregate = workspace.statistics()[0]
    .clone()
    .ok_or("複製全体の統計量がない")?;
let standard_error = aggregate.standard_error();

emit_chart!(serde_json::json!({
    "kind": "errorbar",
    "xLabel": "複製の番号",
    "yLabel": "超過確率の推定値 [-]",
    "series": [{ "name": "推定値と 95 % 区間", "points": bars }],
    "annotations": [
        { "kind": "line", "axis": "y", "value": exact, "label": "厳密値 p" },
        {
            "kind": "range",

            "from": exact - 2.0 * predicted,
            "to": exact + 2.0 * predicted,

        }

}));

let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let fixed2 = serde_json::json!({ "fractionDigits": 2 });
let fixed3 = serde_json::json!({ "fractionDigits": 3 });
let columns = serde_json::json!([
    { "key": "0", "label": "期待値 Np", "type": "number", "format": { "fractionDigits": 1 } },
    { "key": "1", "label": "複製の平均 [-]", "type": "number", "format": sig4 },
    { "key": "2", "label": "厳密値 p [-]", "type": "number", "format": sig4 },
    { "key": "3", "label": "平均の標準誤差 [-]", "type": "number", "format": sci3 },
    { "key": "4", "label": "平均の z [-]", "type": "number", "format": fixed2, "nullText": "未定義" },
    { "key": "5", "label": "複製の標準偏差 [-]", "type": "number", "format": sci3 },
    { "key": "6", "label": "標準偏差の理論値 [-]", "type": "number", "format": sci3 },
    { "key": "7", "label": "被覆率 [-]", "type": "number", "format": fixed3 },
    { "key": "8", "label": "被覆率の標準誤差 [-]", "type": "number", "format": fixed3 },

]);
emit_table_with_columns!(
    columns,
    vec![(
        samples as f64 * exact,
        mean,
        exact,
        standard_error,
        (standard_error > 0.0).then(|| (mean - exact) / standard_error),
        spread,
        predicted,
        covered as f64 / replicates as f64,
        RealScalar::sqrt(0.95 * 0.05 / replicates as f64),
        empty,
    )],
    metadata = serde_json::json!({ "id": "replicates" })
);

既定値（$d = 6$、$N = 2^{11}$、$q = 0.68$、$R = 20$、シード 1）では、厳密値 $p = 0.06453$、$Np = 132$ である。
20 個の複製の平均は $0.06387$ で、複製のばらつきから作った標準誤差 $1.01 \times 10^{-3}$ に対して $z = -0.65$ となる。
複製の標準偏差 $4.5 \times 10^{-3}$ は理論値 $5.4 \times 10^{-3}$ より 17 % 小さいが、20 個から求めた標準偏差の相対的なばらつき $1/\sqrt{2(R - 1)} \approx 0.16$ と同じ程度である。
被覆率は 1.0 で、名目の 0.95 との差は被覆率の標準誤差 0.049 と同じ程度である。
$R = 40$ では被覆率は 0.95、平均の $z$ は $-1.31$ になる。

$q = 0.84$ にすると $Np \approx 2.2$ で、20 個のうち 3 個の複製で事象が観測されない。
その複製の区間は幅を持たない $[0, 0]$ で、厳密値を含まない。
被覆率は 0.85 で、名目の 0.95 から被覆率の標準誤差の 2 倍ほど下がる。
観測値の分散から作る区間は、事象の数が少ないと正規近似が成り立たず、名目の確率で厳密値を含まなくなる。
希少事象では二項分布に基づく区間を使うか、事象の起きやすい領域に標本を集める重点標本化（[適応 Monte Carlo（VEGAS・MISER）](../../algorithms/adaptive-monte-carlo/)）を使う。

## まとめ

部品性能の平均の超過確率は単位超立方体の上の指示関数の積分で、Irwin–Hall 分布の厳密な確率と照合できる。
Monte Carlo 推定量の標準誤差は $\sqrt{p(1 - p)/N}$ で、相対的な精度は事象の数の期待値 $Np$ で決まる。
推定値と厳密値の差は示された標準誤差で割った $z$ で読み、区間の意味は `with_replicates` で作った独立な複製の被覆率で確かめる。
事象が観測されないと標準誤差も区間も 0 になるので、その結果は失敗として扱い、二項分布に基づく上限や標本数の増加、重点標本化に切り替える。
シードは入力として固定し、別のシードでの結果と合わせて統計的なばらつきを読む。
