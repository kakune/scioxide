数値積分の難しさは、被積分関数の大きさよりも、狭い領域への集中、正負の相殺、端点の特異性、座標軸に沿わない構造、次元の高さといった形で決まる。
各例題は具体的な問題で SciOxide の求積を使い、閉形式、既知の値、別の手法、精度改善のいずれかで結果を独立に確かめる。
手法そのものの導出と小さな実験は[数値積分の数理とアルゴリズム体系](../algorithms/)の各ページにある。

| 例題 | 題材 | 主な API | 独立な検算 |
| :--- | :--- | :--- | :--- |
| [幅の狭いピーク](narrow-peak/) | Lorentz 型のスペクトル線の面積 | `AdaptiveIntegrator`、`CubaturePlan::with_breakpoints`、`GaussianRulePlan` | $\arctan$ による面積の閉形式、局所座標への変数変換 |
| [減衰する高周波信号を積分する](damped-oscillation/) | 指数的に減衰する余弦波の積分 | `WeightedQuadraturePlan::fourier`、`FourierTailPlan` | 原始関数と Laplace 変換による閉形式、打ち切り誤差の上界 |
| [二次元開口の透過量を求める](aperture-cubature/) | 回転した細い遮蔽帯を持つ正方形開口 | `ProductRule`、`GaussianRulePlan`、`CubaturePlan` | 遮蔽のない場と軸に沿う遮蔽の閉形式、点数を増やした積型則 |
| [高次元の信頼度を Monte Carlo 積分で求める](high-dimensional-reliability/) | 独立な部品性能の平均の超過確率 | `MonteCarloIntegrator`、`MonteCarloOptions::with_replicates`、`RandomStreams` | Irwin–Hall 分布の厳密な確率、標準誤差と複製の被覆率 |
| [動く積分端点の感度を検算する](moving-boundary-sensitivity/) | コンクリートへの塩化物の浸透量と前線 | `QuadratureSensitivityPlan`、`SensitivityIntegrand`、`JvpQuery`、`VjpQuery` | Leibniz 則による閉形式、JVP と VJP の双対性 |
| [振り子の周期を特異な積分として求める](pendulum-singular-quadrature/) | 振幅の大きい単振り子の周期 | `DoubleExponentialIntegrator`（`nearest_endpoint`）、`WeightedQuadraturePlan::endpoint`（$\beta = -\tfrac{1}{2}$）、`GaussianRulePlan`、`AdaptiveIntegrator` | `scioxide-special` の `elliptic_k` による $K(m)$ |
| [黒体放射の Stefan–Boltzmann 定数と帯域率](blackbody-radiation/) | Planck 分布の積分と波長帯の放射の割合 | `DoubleExponentialIntegrator`（半直線）、一般化 Laguerre の `GaussianRulePlan`、`SeriesSummation` | $\pi^4/15$ と Stefan–Boltzmann 定数 $\sigma$ |

| [ダイポールアンテナの放射電力と Lebedev 則](dipole-radiation-lebedev/) | 線状アンテナの放射パターンと放射電力 | `LebedevRule`、`SphereProductRule` | `ci` による $\operatorname{Cin}(2\pi)$ の閉形式、軸の回転に対する不変性 |

## 結果を採用するまでの確認

求積の結果を設計や判断に使う前に、次の順で確かめる。

1. 終了状態を読む。
   `IntegrationTermination::is_success` は `FixedRuleCompleted`、`ToleranceReached`、`HeuristicToleranceReached`、`SampleBudgetCompleted`、`DegenerateDomain` で真になり、計算が設定どおりに終わったことを表す。
   `FixedRuleCompleted` は決めた節点の和を計算し終えたことだけを表し、精度を主張しない。
   `ToleranceReached` は二つの則の差による誤差推定が許容誤差を満たしたこと、`HeuristicToleranceReached` は観測した減衰のような経験的な推定が許容誤差を満たしたことを表す。
   どちらも節点の間に隠れた細い構造がないことの証明ではない。
   `BudgetLimit(Evaluation)`・`BudgetLimit(Subdivision)`・`RefinementLimit`・`Stagnation` などは成功を表さない。
   返された値は推定値として扱い、上限の拡大、事前分割、変数変換を検討する。
2. 誤差の基準を選ぶ。
   積分値が 0 に近い問題（相殺の大きい振動積分など）では相対許容誤差 $\varepsilon_{\mathrm{rel}}|Q|$ が働かないので、物理的に意味のある絶対許容誤差 $\varepsilon_{\mathrm{abs}}$ を設定する。
   逆に、$\varepsilon_{\mathrm{abs}}$ が積分値と同じ程度以上だと、積分をほとんど求めなくても許容誤差を満たしうる。
3. モデルの打ち切りと数値誤差を分ける。
   無限区間を有限の区間で打ち切るときは、モデルの打ち切り誤差と有限区間の求積の誤差を分けて見積もる。
4. 独立に検算する。
   変数変換、別の手法、閉形式や漸近形、点数や標本数を変えた比較で値を確かめる。
   統計的な推定ではシードを変えた反復や独立な複製で、標準誤差と区間の意味を確かめる。
   包含が保証された区間が必要なら、`scioxide-validated` の検証付き求積を使う。
