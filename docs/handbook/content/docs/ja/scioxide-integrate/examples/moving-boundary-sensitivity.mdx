積分の上端そのものがパラメータとともに動く量は、拡散や相変化の問題によく現れる。
たとえばコンクリートの中を塩化物が拡散すると、鉄筋の腐食を始める臨界濃度に達した深さ（前線）が時間とともに奥へ進み、前線より手前に入った塩化物の量も増える。
その量をパラメータで微分するには、被積分関数の変化と端点の移動の両方を数える必要がある。
この例題では `QuadratureSensitivityPlan` で浸透量とその感度を JVP と VJP の両方で求め、閉形式と双対性で照合する。

## 拡散による浸透と臨界濃度の前線

厚い部材の表面から塩化物が拡散で入るとし、表面の濃度 $c_s$ を一定、初期濃度を 0 とする。
深さ $x$ [mm]、材齢 $t$ [a]、見かけの拡散係数 $D$ [mm²/a] の Fick の第 2 法則の解は

$$
\frac{c(x, t)}{c_s} = \operatorname{erfc}\left(\frac{x}{2\sqrt{Dt}}\right)
$$

である。
$D = 30$ mm²/a はおよそ $10^{-12}$ m²/s にあたる。

腐食が始まる臨界濃度を $c_{\mathrm{crit}} = r\,c_s$（$0 < r < 1$）とすると、濃度が臨界値に等しい深さは

$$
s(t, D) = 2\lambda\sqrt{Dt}, \qquad \lambda = \operatorname{erfc}^{-1}(r)
$$

で、前線は $\sqrt{t}$ に比例して進む。
前線より手前に入った塩化物の量を $c_s$ で割った量

$$
M(t, D) = \int_0^{s(t, D)} \operatorname{erfc}\left(\frac{x}{2\sqrt{Dt}}\right) dx \quad [\mathrm{mm}]
$$

を浸透量と呼ぶ。
$M$ は単位面積あたりの塩化物の量を表面の濃度で割った値で、長さの単位を持つ。

$z = x/(2\sqrt{Dt})$ と置くと積分は $z \in [0, \lambda]$ に移り、$\int_0^\lambda \operatorname{erfc} z\,dz = \lambda\operatorname{erfc}\lambda + (1 - e^{-\lambda^2})/\sqrt{\pi}$ から

$$
M = 2\sqrt{Dt}\,G(\lambda), \qquad G(\lambda) = \lambda\operatorname{erfc}\lambda + \frac{1 - e^{-\lambda^2}}{\sqrt{\pi}}
$$

となる。
$M$ は $Dt$ だけを通じて $\sqrt{Dt}$ に比例するので、

$$
\frac{\partial M}{\partial t} = \frac{M}{2t}, \qquad \frac{\partial M}{\partial D} = \frac{M}{2D}
$$

が成り立つ。
以下の検算にはこの閉形式を使い、$\operatorname{erfc}$ と $\operatorname{erfc}^{-1}$ は `scioxide-special` で計算する。

## Leibniz の積分則と端点の項

パラメータを $\boldsymbol{p} = (t, D)$ とまとめ、被積分関数を $f(x; \boldsymbol{p}) = c/c_s$、積分区間を $[a(\boldsymbol{p}), b(\boldsymbol{p})]$ とすると、Leibniz の積分則は

$$
dM = \int_a^b \frac{\partial f}{\partial \boldsymbol{p}}\,d\boldsymbol{p}\,dx + f(b)\,db - f(a)\,da
$$

となる。
偏微分 $\partial f/\partial \boldsymbol{p}$ は $x$ を固定してとり、$db = \nabla b \cdot d\boldsymbol{p}$ は端点の移動量を表す。
この問題では $a = 0$ は動かず、$b = s$ で $f(s) = r$、$\nabla s = (s/(2t),\ s/(2D))$ である。

被積分関数の偏微分は、$\operatorname{erfc}'(z) = -2e^{-z^2}/\sqrt{\pi}$ と $\partial z/\partial t = -z/(2t)$、$\partial z/\partial D = -z/(2D)$ から

$$
\frac{\partial f}{\partial t} = \frac{z\,e^{-z^2}}{\sqrt{\pi}\,t}, \qquad \frac{\partial f}{\partial D} = \frac{z\,e^{-z^2}}{\sqrt{\pi}\,D}
$$

である。
$t$ についての内側の積分は $\sqrt{D/(\pi t)}\,(1 - e^{-\lambda^2})$、端点の項は $r\lambda\sqrt{D/t}$ で、和は $\sqrt{D/t}\,G(\lambda) = M/(2t)$ に一致する。
端点の項を落とすと、感度を $r\lambda\sqrt{D/t}$ だけ小さく見積もる。

## JVP と VJP

値の成分数を $m$、パラメータの数を $P$ とすると、感度は $m \times P$ の Jacobian 行列 $J = \partial M/\partial \boldsymbol{p}$ である。
JVP（Jacobian–vector product）は方向 $\boldsymbol{v}$ に対する $J\boldsymbol{v}$（$m$ 成分）を、VJP（vector–Jacobian product）は余接ベクトル $\boldsymbol{w}$ に対する $\boldsymbol{w}^{\mathsf T} J$（$P$ 成分）を求める。
この例題では $m = 1$、$P = 2$ なので、JVP は 1 回で 1 つの方向微分を、VJP は $w = 1$ で勾配 $(\partial M/\partial t, \partial M/\partial D)$ 全体を 1 回で求める。
勾配を JVP で求めるには、方向を変えて 2 回計算する必要がある。

厳密な感度については、任意の $\boldsymbol{v}$ と $\boldsymbol{w}$ で

$$
\boldsymbol{w}^{\mathsf T}(J\boldsymbol{v}) = (\boldsymbol{w}^{\mathsf T}J)\,\boldsymbol{v}
$$

という双対性が成り立つ。
同じ節点と重みで求めた JVP と VJP は、同じ離散的な Jacobian の積なので、この等式が丸め誤差の範囲で成り立つ。
双対性は二つの実装が整合していることを確かめるもので、離散化誤差を測るものではない。

## Plan・被積分関数・端点の指定

`QuadratureSensitivityPlan` は、$M$ と感度を同じ Gauss–Kronrod 則の同じ節点で近似する。
分割の作り方は `SensitivityDiscretization` の 3 通りである。

- `fixed`：1 つの Gauss–Kronrod 則を区間全体に 1 回使う。
  終了状態は `FixedRuleCompleted` で、許容誤差を満たすまで細分はしないが、レポートは誤差推定が許容誤差を満たしたかを示す。
- `adaptive`：G7K15 で二分を続け、主積分と導関数の両方の誤差推定が許容誤差を満たすと `ToleranceReached` で止まる。
- `frozen`：以前の呼び出しの分割（`partition` で取り出す）を、細分せずに使う。
  分割は JVP と VJP で共通に使える。

どの場合も、Plan が微分するのはその分割の上での積分で、適応的な分割の選び方は微分しない。
`fixed` と `frozen` では節点が $\boldsymbol{p}$ によらないので、計算した $M$ は $\boldsymbol{p}$ の滑らかな関数になる。
区間 $[0, s(\boldsymbol{p})]$ は Plan に固定されるので、$\boldsymbol{p}$ を変えて $s$ が変わるたびに Plan を作り直す。

被積分関数は `SensitivityIntegrand` を実装し、`evaluate` で値を `sample.value_mut()` に書いてから、Jacobian を 1 回だけ適用する。
JVP だけなら `LinearOperator` を `apply_forward` に渡せばよいが、VJP には転置の作用が要るので、`LinearOperator` と `AdjointOperator` の両方を実装した型を `apply` に渡す。
scioxide-core の `ClosureOperator::new` が返す演算子は `LinearOperator` だけを実装するので、VJP に使うときは `with_adjoint` で転置の作用のクロージャを加えて `AdjointOperator` にする。
端点での評価は値だけが要求され、`sample.mode()` が `None` になり、`apply` は何もしない。
動く端点は JVP では `JvpQuery::with_endpoint_tangent(Some([da, db]))`、VJP では `VjpQuery::with_endpoint_gradients(Some((&grad_a, &grad_b)))` で渡す。
節点 1 つにつき被積分関数の評価と Jacobian の適用が 1 回ずつ、動く端点 1 つにつき値だけの評価が 1 回加わる。
パラメータ、方向、端点の接ベクトルや勾配に NaN や無限大があると、計算を始める前に起点 `Input` の `NonFinite` を返す。
被積分関数が返した値や積が有限でなければ、起点 `Callback` の `NonFinite` を返す。

`SensitivityReport` は終了状態、被積分関数の評価回数、Jacobian の適用回数、二分の回数と、主積分・導関数の誤差推定がそれぞれ許容誤差を満たしたかを返す。
作業領域の `derivative_errors` は導関数の誤差推定の成分を返し、`total()` は求積の誤差推定と端点の項の丸め誤差の推定の和である。
どちらも上界ではない。
また、Jacobian の作用そのものの誤差は含まない。

次のブロックは二つのセルが共有する定義である。
`Ingress` が被積分関数 $f(x; t, D)$ と、その Jacobian $(\partial f/\partial t, \partial f/\partial D)$ を適用する部分、`front` が前線の深さ $s$、`amount` が閉形式の $M$ に対応する。
`sensitivity_options` は、主積分と導関数に共通の許容誤差 $10^{-10}$（絶対・相対とも）と、JVP か VJP かの方式を設定する。
Jacobian は $1 \times 2$ の行列で、`ClosureOperator::new` に渡すクロージャが $J\boldsymbol{v}$ を、`with_adjoint` に渡すクロージャが $J^{\mathsf T}w$ を書く。
`ClosureOperator` は結果をいったん作業領域に書き、有限性を確かめてから出力に写す。
その作業領域は JVP では行数（1）、VJP では列数（2）の長さが要るので、`apply` には長さ 2 の配列を渡す。
`prepare_plan` は選んだ離散化（`fixed` の規則か `adaptive`）で Plan を作り、`jvp` と `vjp` は 1 回の計算の値・積・誤差推定・レポートを `Run` にまとめて返す。
`jvp` の `tangent` は上端の移動量 $\nabla s \cdot \boldsymbol{v}$ で、`None` を渡すと端点の項を入れない。
```rust
//| id: integrate-moving-boundary-model
//| kind: definitions
//| title: 塩化物の浸透の被積分関数・Jacobian・閉形式
//| crates: [scioxide-core, scioxide-integrate, scioxide-special]
use scioxide_core::{
    ClosureOperator, ErrorTolerance, ExecutionContext, SciOxideError, Interval, NormSelection,
    RealScalar,
};
use scioxide_integrate::{
    GaussKronrodRule, JvpQuery, QuadratureSensitivityPlan, QuadratureSensitivityWorkspace,
    SensitivityIntegrand, SensitivityMode, SensitivityOptions, SensitivityReport,
    SensitivitySample, SubdivisionOptions, VjpQuery,
};

/// f(x; t, D) = erfc(x / (2√(Dt)))。パラメータは p = [t, D]。
pub(crate) struct Ingress;

impl SensitivityIntegrand<f64> for Ingress {
    type Workspace = ();
    fn parameter_dimension(&self) -> usize {
        2
    }
    fn value_dimension(&self) -> usize {
        1
    }
    fn supports(&self, _: SensitivityMode) -> bool {
        true
    }
    fn evaluate(
        &self,
        x: f64,
        p: &[f64],
        sample: &mut SensitivitySample<'_, f64>,
        _: &mut (),
        _: ExecutionContext<'_>,
    ) -> Result<(), SciOxideError> {
        let (t, d) = (p[0], p[1]);
        let z = x / (2.0 * RealScalar::sqrt(d * t));
        sample.value_mut()[0] = scioxide_special::erfc(z)?;
        // ∂f/∂t = z e^{−z²}/(√π t)、∂f/∂D = z e^{−z²}/(√π D)。
        let common = z * RealScalar::exp(-z * z) / RealScalar::sqrt(core::f64::consts::PI);
        let (by_age, by_diffusivity) = (common / t, common / d);
        // 1 × 2 の Jacobian J。J v と Jᵀ w を書くクロージャ。端点では apply は何もしない。
        let jacobian = ClosureOperator::new(1, 2, |v: &[f64], out: &mut [f64]| {
            out[0] = by_age * v[0] + by_diffusivity * v[1];
            Ok(())
        })
        .with_adjoint(|w: &[f64], out: &mut [f64]| {
            out[0] = by_age * w[0];
            out[1] = by_diffusivity * w[0];
            Ok(())
        });
        // 作業領域は J v に行数 1、Jᵀ w に列数 2 の長さが要る。
        sample.apply(&jacobian, &mut [0.0; 2])
    }
}

/// 主積分と導関数に共通の許容誤差 10⁻¹⁰（絶対・相対、無限大ノルム）と方式。
pub(crate) fn sensitivity_options(
    mode: SensitivityMode,
) -> Result<SensitivityOptions<f64>, SciOxideError> {
    let tolerance = ErrorTolerance::scalar(1e-10, 1e-10, NormSelection::Infinity)?;
    Ok(
        SensitivityOptions::new(
            SubdivisionOptions::default().with_tolerance(tolerance.clone()),
        )
        .with_derivative_tolerance(tolerance)
        .with_mode(mode),
    )
}

/// 選択肢の名前（"fixed G7K15" … "fixed G25K51"、"adaptive G7K15"）から Plan を作る。
pub(crate) fn prepare_plan(
    discretization: &str,
    interval: Interval<f64>,
    mode: SensitivityMode,
) -> Result<QuadratureSensitivityPlan<f64>, SciOxideError> {
    let options = sensitivity_options(mode)?;
    let rule = match discretization {
        "adaptive G7K15" => {
            return QuadratureSensitivityPlan::adaptive(&Ingress, interval, options);
        }
        "fixed G10K21" => GaussKronrodRule::G10K21,
        "fixed G15K31" => GaussKronrodRule::G15K31,
        "fixed G20K41" => GaussKronrodRule::G20K41,
        "fixed G25K51" => GaussKronrodRule::G25K51,
        _ => GaussKronrodRule::G7K15,
    };
    QuadratureSensitivityPlan::fixed(&Ingress, interval, rule, options)
}

/// 1 回の JVP または VJP の結果: 値、積（JVP は 1 成分、VJP は 2 成分）、
/// それぞれの誤差推定（求積の推定と端点の項の丸め誤差の和）、レポート。
pub(crate) struct Run {
    pub(crate) value: f64,
    pub(crate) products: Vec<f64>,
    pub(crate) value_error: Option<f64>,
    pub(crate) product_errors: Vec<Option<f64>>,
    pub(crate) report: SensitivityReport,
}

impl Run {
    fn read(
        value: f64,
        products: Vec<f64>,
        report: SensitivityReport,
        workspace: &QuadratureSensitivityWorkspace<f64>,
    ) -> Self {
        let value_error = workspace.value_errors().and_then(|e| e[0].total());
        let product_errors = workspace
            .derivative_errors()
            .map_or_else(Vec::new, |e| e.iter().map(|c| c.total()).collect());
        Self {
            value,
            products,
            value_error,
            product_errors,
            report,
        }
    }
}

/// p での J v。tangent は上端の移動量 db = ∇s·v（None なら端点の項を入れない）。
pub(crate) fn jvp(
    plan: &QuadratureSensitivityPlan<f64>,
    workspace: &mut QuadratureSensitivityWorkspace<f64>,
    p: &[f64],
    v: &[f64],
    tangent: Option<f64>,
) -> Result<Run, SciOxideError> {
    let (mut value, mut product) = (0.0, 0.0);
    // 端点の接ベクトル [da, db] = [0, ∇s·v]（下端 a = 0 は動かない）。
    let query = JvpQuery::new(p, v).with_endpoint_tangent(tangent.map(|db| [0.0, db]));
    let cx = ExecutionContext::sequential();
    let outputs = (&mut value, &mut product);
    let report = plan.jvp_into(&Ingress, query, outputs, (&mut *workspace, &mut [()]), cx)?;
    Ok(Run::read(value, vec![product], report, workspace))
}

/// p での wᵀ J（w = 1）。端点の勾配は ∇a = 0、∇b = grad_b。
pub(crate) fn vjp(
    plan: &QuadratureSensitivityPlan<f64>,
    workspace: &mut QuadratureSensitivityWorkspace<f64>,
    p: &[f64],
    grad_b: &[f64; 2],
) -> Result<Run, SciOxideError> {
    let (mut value, mut product) = (0.0, [0.0; 2]);
    let grad_a = [0.0; 2];
    let query = VjpQuery::new(p, &[1.0]).with_endpoint_gradients(Some((&grad_a, grad_b)));
    let cx = ExecutionContext::sequential();
    let outputs = (&mut value, &mut product);
    let report = plan.vjp_into(&Ingress, query, outputs, (&mut *workspace, &mut [()]), cx)?;
    Ok(Run::read(value, product.to_vec(), report, workspace))
}

/// 前線の深さ s = 2λ√(Dt) [mm]。
pub(crate) fn front(lambda: f64, t: f64, d: f64) -> f64 {
    2.0 * lambda * RealScalar::sqrt(d * t)
}

/// 閉形式 M = 2√(Dt) G(λ)、G(λ) = λ erfc λ + (1 − e^{−λ²})/√π [mm]。
pub(crate) fn amount(lambda: f64, t: f64, d: f64) -> Result<f64, SciOxideError> {
    let root_pi = RealScalar::sqrt(core::f64::consts::PI);
    let g = lambda * scioxide_special::erfc(lambda)?
        + (1.0 - RealScalar::exp(-lambda * lambda)) / root_pi;
    Ok(2.0 * RealScalar::sqrt(d * t) * g)
}
```

## 一つのパラメータ点での JVP と VJP

次のセルは材齢 $t$、拡散係数 $D$、臨界濃度比 $r = 10^{k}$ を選び、浸透量 $M$ と感度を求める。
計算の方法は Gauss–Kronrod 則を 1 回使う `fixed` か、許容誤差 $10^{-10}$（絶対・相対とも、主積分と導関数で共通）の `adaptive` から選ぶ。
JVP の方向は $\boldsymbol{v} = (1\ \mathrm{a}, 0)$（$t$ 方向）か $(0, 1\ \mathrm{mm^2/a})$（$D$ 方向）で、VJP の余接は $w = 1$ とする。
JVP の計算の分割を `partition` で取り出し、その分割を使う `frozen` の Plan で VJP を同じ節点の上で計算して、双対性 $w(J\boldsymbol{v}) = (J^{\mathsf T}w)\cdot\boldsymbol{v}$ を確かめる。
1 つ目の表は値と感度を閉形式と比べ、それぞれの誤差推定も示す。
2 つ目の表は各計算の評価回数、許容誤差の判定、双対性の差、終了状態を示す。
判定は JVP の終了状態と、主積分と導関数の誤差推定がどちらも許容誤差を満たしたかを示す。

```rust
//|       - {"artifact":"quantities","path":"/rows/1/4","range":{"max":1e-14}}
//|       - {"path":"/outputs/2/state","equals":"satisfied"}
//|   - case: d-direction
//|     expect:
//|       - {"artifact":"quantities","path":"/rows/1/2","approx":{"value":0.30867597832362015,"rtol":1e-12}}
//|       - {"artifact":"runs","path":"/rows/2/6","range":{"max":1e-15}}
//|       - {"path":"/outputs/2/state","equals":"satisfied"}
use scioxide_core::{Interval, RealScalar};
use scioxide_integrate::{QuadratureSensitivityPlan, SensitivityMode};

let (t, d) = (age, diffusivity);
let r = RealScalar::exp10(threshold_exponent);
let lambda = scioxide_special::erfcinv(r).map_err(|e| e.to_string())?;
let s = front(lambda, t, d);
let interval = Interval::new(0.0, s).map_err(|e| e.to_string())?;
let p = [t, d];
let v = if direction.starts_with("t") {
    [1.0, 0.0]
} else {
    [0.0, 1.0]
};
// 上端の勾配 ∇s = (s/(2t), s/(2D)) と、方向 v への移動量 ∇s·v。
let grad_b = [s / (2.0 * t), s / (2.0 * d)];
let tangent = grad_b[0] * v[0] + grad_b[1] * v[1];
// 閉形式: M、∂M/∂t = M/(2t)、∂M/∂D = M/(2D)。
let exact = amount(lambda, t, d).map_err(|e| e.to_string())?;
let gradient = [exact / (2.0 * t), exact / (2.0 * d)];
let exact_jvp = gradient[0] * v[0] + gradient[1] * v[1];
// 値と感度の表の行 (量, 単位, 計算値, 閉形式, 相対差, 誤差推定)。
let row = |name: &'static str, unit: &'static str, value: f64, exact: f64, estimate| {
    (name, unit, value, exact, ((value - exact) / exact).abs(), estimate)
};

// JVP（端点の項あり・なし）と、その分割を frozen で再利用する VJP。
let plan = prepare_plan(&discretization, interval, SensitivityMode::Jvp)
    .map_err(|e| e.to_string())?;
let mut ws = plan.workspace().map_err(|e| e.to_string())?;
let full = jvp(&plan, &mut ws, &p, &v, Some(tangent)).map_err(|e| e.to_string())?;
let partition = plan.partition(&ws).map_err(|e| e.to_string())?;
// 比較: 端点の項を落とした JVP。閉形式は J v − r ∇s·v。
let interior = jvp(&plan, &mut ws, &p, &v, None).map_err(|e| e.to_string())?;
let options = sensitivity_options(SensitivityMode::Vjp).map_err(|e| e.to_string())?;
let frozen =
    QuadratureSensitivityPlan::frozen(&Ingress, &partition, options).map_err(|e| e.to_string())?;
let mut frozen_ws = frozen.workspace().map_err(|e| e.to_string())?;
let back = vjp(&frozen, &mut frozen_ws, &p, &grad_b).map_err(|e| e.to_string())?;
// 双対性 w(J v) = (Jᵀ w)·v（w = 1）。
let dual = back.products[0] * v[0] + back.products[1] * v[1];
let duality = (full.products[0] - dual).abs();

let interior_exact = exact_jvp - r * tangent;
let values = vec![
    row("M", "mm", full.value, exact, full.value_error),
    row("J v", "mm", full.products[0], exact_jvp, full.product_errors[0]),
    row("J v（端点の項なし）", "mm", interior.products[0], interior_exact, interior.product_errors[0]),
    row("∂M/∂t（VJP）", "mm/a", back.products[0], gradient[0], back.product_errors[0]),
    row("∂M/∂D（VJP）", "a/mm", back.products[1], gradient[1], back.product_errors[1]),
];
let runs = [
    ("JVP", &full.report, None),
    ("JVP（端点の項なし）", &interior.report, None),
    ("VJP（frozen）", &back.report, Some(duality)),
];
let sig12 = serde_json::json!({ "significantDigits": 12 });
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let value_columns = serde_json::json!([
    { "key": "0", "label": "量" },
    { "key": "1", "label": "単位" },
    { "key": "2", "label": "計算値", "type": "number", "format": sig12 },
    { "key": "3", "label": "閉形式", "type": "number", "format": sig12 },
    { "key": "4", "label": "相対差 [-]", "type": "number", "format": sci3 },
    { "key": "5", "label": "誤差推定（量の単位）", "type": "number", "format": sci3, "nullText": "なし" }
]);
emit_table_with_columns!(
    value_columns,
    values,
    metadata = serde_json::json!({ "id": "quantities" })
);
let run_rows: Vec<_> = runs
    .iter()
    .map(|&(name, report, duality)| {
        (
            name,
            report.function_evaluations(),
            report.derivative_evaluations(),
            report.subdivisions(),
            report.primal_tolerance_met(),
            report.derivative_tolerance_met(),
            duality,
            report.termination().to_string(),
        )
    })
    .collect();
let run_columns = serde_json::json!([
    { "key": "0", "label": "計算" },
    { "key": "1", "label": "被積分関数の評価 [回]", "type": "integer" },
    { "key": "2", "label": "Jacobian の適用 [回]", "type": "integer" },
    { "key": "3", "label": "二分 [回]", "type": "integer" },
    { "key": "4", "label": "主積分の許容誤差を満たす", "type": "boolean" },
    { "key": "5", "label": "導関数の許容誤差を満たす", "type": "boolean" },
    { "key": "6", "label": "双対性の差 [mm]", "type": "number", "format": sci3, "nullText": "対象外" },
    { "key": "7", "label": "終了状態" }
]);
emit_table_with_columns!(
    run_columns,
    run_rows,
    metadata = serde_json::json!({ "id": "runs" })
);
export!(diffusivity, d);
export!(lambda, lambda);

let report = &full.report;
let termination = report.termination();
let met = report.primal_tolerance_met() && report.derivative_tolerance_met();
let outcome = if termination.is_success() && met {
    Outcome::satisfied("値と感度の誤差推定が許容誤差を満たした")
} else {
    Outcome::partial("誤差推定が許容誤差を満たさないか、上限で止まった")
        .explanation("値と感度は推定値として読み、規則の点数を増やすか adaptive を使う。")
};
let evaluations = report.function_evaluations() as f64;
let applications = report.derivative_evaluations() as f64;
emit_outcome!(
    outcome
        .status(termination.to_string())
        .diagnostic("被積分関数の評価", evaluations, None)
        .diagnostic("Jacobian の適用", applications, None)
);
```

既定値（$t = 10$ a、$D = 30$ mm²/a、$r = 0.1$、`fixed G7K15`、$t$ 方向）では、$\lambda = 1.163$、前線の深さは $s = 40.3$ mm で、浸透量は $M = 18.52$ mm である。
JVP の $J\boldsymbol{v} = \partial M/\partial t = 0.926$ mm/a と、VJP の勾配 $(0.926\ \mathrm{mm/a},\ 0.309\ \mathrm{a/mm})$ は、閉形式 $M/(2t)$、$M/(2D)$ と $10^{-16}$ 程度の相対差で一致する。
双対性の差は 0 で、同じ節点の JVP と VJP が同じ離散的な Jacobian を使ったことを示す。
端点の項を落とした JVP は $0.725$ mm/a で、感度を 22 % 小さく見積もる。
差 $0.201$ mm/a は端点の項 $r\lambda\sqrt{D/t}$ に等しい。

評価回数は、JVP と VJP が 15 節点に端点の 1 回を加えた 16 回、端点の項を落とした JVP が 15 回である。
VJP は 1 回の計算で勾配の 2 成分を返し、JVP で同じ勾配を得るには方向を変えた 2 回の計算が要る。
JVP の方向を $D$ 方向にすると、$J\boldsymbol{v}$ は VJP の 2 成分目と同じ $0.309$ になり、双対性の差はこの方向でも 0 である。
Gauss–Kronrod 則の点数を上げても、この滑らかな被積分関数では差はすでに丸め誤差の水準にあり、評価回数だけが増える。

$r = 10^{-6}$ にすると $\lambda = 3.459$ で、前線は $s = 119.8$ mm まで深くなる。
`fixed G7K15` の結果は閉形式と $3.5 \times 10^{-12}$ の相対差で一致するが、誤差推定は導関数で $6.1 \times 10^{-4}$、主積分で $4.6 \times 10^{-4}$ で、どちらも許容誤差を満たさず、判定は partial になる。
この誤差推定は二つの則の差に基づくもので、実際の差よりはるかに大きい。
`adaptive G7K15` では 2 回の二分（76 回の評価）で両方の許容誤差を満たし、取り出した 3 つの部分区間の分割を使う `frozen` の VJP は二分なしの 46 回で同じ勾配を返す。
臨界濃度比が小さいと前線の位置での濃度 $r$ も小さいので、端点の項は $J\boldsymbol{v}$ の $6 \times 10^{-6}$ 程度しかない。

## 材齢に対する浸透量と感度

次のセルは前のセルの $D$ と $\lambda$ を受け取り、材齢 $t = 1, 2, \ldots, 50$ a で $M$ と $\partial M/\partial t$ を JVP で求める。
区間 $[0, s(t)]$ が $t$ とともに変わるので、各 $t$ で `fixed G15K31` の Plan を作り直す。
上のグラフは浸透量、下のグラフは感度で、閉形式を破線、求積の値を点で示し、横軸の材齢は二つのグラフで連動する。
表は 50 点での閉形式との相対差の最大を示す。

```rust
//| id: integrate-moving-boundary-age
//| ref: integrate-moving-boundary-age
//| title: 材齢に対する浸透量と感度の曲線
//| run: reactive
//| uses: [integrate-moving-boundary-model]
//| crates: [scioxide-core, scioxide-integrate, scioxide-special]
//| dependsOn:
//|   solve: integrate-moving-boundary-jvp
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"deviations","path":"/rows/0/1","range":{"max":1e-13}}
//|       - {"artifact":"deviations","path":"/rows/1/1","range":{"max":1e-13}}

use scioxide_integrate::SensitivityMode;

let d = solve["diffusivity"].as_f64().ok_or("拡散係数がない")?;
let lambda = solve["lambda"].as_f64().ok_or("λ がない")?;

for k in 1..=50 {
    let t = f64::from(k);
    let s = front(lambda, t, d);
    let interval = Interval::new(0.0, s).map_err(|e| e.to_string())?;
    let plan = prepare_plan("fixed G15K31", interval, SensitivityMode::Jvp)
        .map_err(|e| e.to_string())?;
    let mut ws = plan.workspace().map_err(|e| e.to_string())?;
    // 方向 v = (1 a, 0)、上端の移動量 ∂s/∂t = s/(2t)。
    let run = jvp(&plan, &mut ws, &[t, d], &[1.0, 0.0], Some(s / (2.0 * t)))
        .map_err(|e| e.to_string())?;
    let (value, rate) = (run.value, run.products[0]);
    let exact = amount(lambda, t, d).map_err(|e| e.to_string())?;
    let exact_rate = exact / (2.0 * t);
    worst_amount = RealScalar::max(worst_amount, ((value - exact) / exact).abs());
    worst_rate = RealScalar::max(worst_rate, ((rate - exact_rate) / exact_rate).abs());
    amounts.push([t, value]);
    rates.push([t, rate]);
    exact_amounts.push([t, exact]);
    exact_rates.push([t, exact_rate]);

        "xMin": 0.0,
        "xMax": 50.0
    })
);

    ],
    options = &serde_json::json!({
        "link": { "group": "age" },

        "yLabel": "感度 ∂M/∂t [mm/a]",

        "xMax": 50.0,
        "yType": "log"
    })
);
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
emit_table_with_columns!(

        { "key": "1", "label": "閉形式との相対差の最大 [-]", "type": "number", "format": sci3 }
```

$M$ は $\sqrt{t}$ に比例して増え、$t = 1$ a の 5.86 mm から $t = 50$ a の 41.4 mm になる。
感度 $\partial M/\partial t = M/(2t)$ は $1/\sqrt{t}$ に比例して減り、対数軸の上では 2.93 mm/a から 0.414 mm/a まで傾き $-1/2$ の直線に沿う。
50 点のすべてで、求積の値と JVP は閉形式と $10^{-15}$ 以下の相対差で一致する。
節点が $t$ に依存しない `fixed` の Plan では、計算した $M(t)$ は $t$ の滑らかな関数になり、JVP はその導関数になる。

## まとめ

積分の端点がパラメータで動くとき、感度は被積分関数の偏微分の積分と、端点の値と移動量の積である Leibniz の項の和になる。
`QuadratureSensitivityPlan` では、端点の移動を JVP では `with_endpoint_tangent`、VJP では `with_endpoint_gradients` で渡し、渡し忘れると端点の項がそのまま抜ける。
値の成分が少なくパラメータが多い場合は、VJP が 1 回の計算で勾配全体を返す。
JVP の分割を `partition` で取り出して `frozen` の VJP に使うと、同じ節点の上で双対性 $\boldsymbol{w}^{\mathsf T}(J\boldsymbol{v}) = (\boldsymbol{w}^{\mathsf T}J)\boldsymbol{v}$ を丸め誤差の範囲で確かめられる。
`fixed` の終了状態 `FixedRuleCompleted` は許容誤差を主張しないので、レポートの `derivative_tolerance_met` と誤差推定を合わせて読み、満たさなければ規則を上げるか `adaptive` を使う。
区間が変わるたびに Plan を作り直し、閉形式や双対性との照合で感度を確かめる。
