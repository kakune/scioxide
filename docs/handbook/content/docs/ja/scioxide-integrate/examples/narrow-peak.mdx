分光測定の吸収線や共鳴散乱の断面積は、中心の近くだけに値が集中する Lorentz 型の線形で表される。
線の強度は線形の面積で決まるので、幅の狭い線の面積を数値積分で求める場面は多い。
この例題では、幅を狭めると固定の求積則がピークを見落とすこと、適応求積がピークの周りを細分して面積を求めること、ピークの位置と幅を求積に渡すと評価回数や見落としがどう変わるかを、面積の閉形式と照合して確かめる。

## Lorentz 型の線形と面積の閉形式

測定ウインドウを無次元の座標 $x \in [-1, 1]$ で表す。
たとえば周波数 $\nu$ のウインドウの中心を $\nu_0$、半幅を $\Delta$ として $x = (\nu - \nu_0)/\Delta$ とする。
中心 $c$、半値半幅 $w > 0$ の Lorentz 型の線形を、最大値が 1 になるように

$$
f(x) = \frac{1}{1 + \left(\dfrac{x - c}{w}\right)^2}
$$

と書く。
$f(c \pm w) = 1/2$ なので、半値全幅は $2w$ である。
$x$ と $f$ はどちらも無次元で、面積も無次元である。

$u = (x - c)/w$ と置くと $dx = w\,du$ で、原始関数は $w \arctan u$ になる。
したがってウインドウの上の面積は

$$
I(c, w) = \int_{-1}^{1} f(x)\,dx = w\left[\arctan\frac{1 - c}{w} - \arctan\frac{-1 - c}{w}\right]
$$

である。
$c$ がウインドウの端から十分に離れ、$w \ll 1 - |c|$ なら、両方の $\arctan$ が $\pm\pi/2$ に近づき、$I \approx \pi w$ となる。
$c$ が端に近づくと片側の裾がウインドウの外に出るので、面積は $\pi w$ より小さくなる。
以下の検算にはこの閉形式を `f64` の標準関数 `atan` で計算した値を使う。

## 固定の求積則が見落とすもの

$n$ 点の Gauss–Legendre 則は、次数 $2n - 1$ 以下の多項式を厳密に積分する（[Gauss 型求積と Clenshaw–Curtis 則](../../algorithms/gaussian-and-clenshaw-curtis/)）。
$f$ は多項式でないので、多項式による近似の良さは、$f$ が複素平面のどこまで解析的に延びるかで決まる。
$f$ は $x = c \pm i w$ に極を持つので、$w$ が小さいと極が実軸に近づき、多項式近似が急に悪くなる。

節点の間隔がピークの幅 $w$ より広いと、ピークの中に節点がほとんど入らない。
節点がすべて平坦な裾に落ちると、求積値は面積 $\pi w$ と無関係な値になる。
固定則の終了状態 `FixedRuleCompleted` は決めた節点の和を計算し終えたことだけを表し、この誤りを知らせない。

## 適応 Gauss–Kronrod 求積の細分

`AdaptiveIntegrator` に `AdaptiveRule::GaussKronrod` を渡すと、7 点 Gauss 則と、その節点を含む 15 点 Kronrod 則の組（G7K15）を使う。
各領域の誤差推定は二つの則の差 $|K - G|$ から作り、尺度補正をかける。
全領域の誤差推定の和が許容誤差 $\varepsilon_{\mathrm{abs}} + \varepsilon_{\mathrm{rel}}|Q|$ 以下になるまで、誤差推定が最大の領域を二分する。
最初の領域で 15 回、二分 1 回ごとに 2 つの子領域で 30 回の評価を使う。

狭いピークでは、ピークを含む領域の誤差推定が大きく残るので、二分はピークの周りに集中する。
ピークの幅まで領域を縮めるのに必要な二分の段数は、おおよそ $\log_2(1/w)$ に比例する。
したがって評価回数は、$w$ を 10 分の 1 にするごとにほぼ一定数ずつ増える。

終了状態は次のように読む。

- `ToleranceReached`：誤差推定が許容誤差を満たした。
  推定は上界ではない。
- `BudgetLimit(Subdivision)`：二分の回数の上限で止まった。
  全区間の推定値は返るが、許容誤差を満たしたとはいえない。
- `Stagnation`：丸め誤差の水準が誤差推定を支配したか、二分が値を変えなくなった。

どの状態でも、節点の間に隠れた細い構造がないことは証明されない。
最初の 15 点がどれもピークに触れないほど $w$ が小さいと、$K$ と $G$ がそろって裾の小さな値だけを積分し、誤差推定も小さいまま `ToleranceReached` で終わる。
ピークの位置が分からないまま幅の狭い構造を適応求積にかけると、この見落としを終了状態から区別できない。

## ピークの位置と幅を使う二つの方法

ピークの中心 $c$ と幅 $w$ が分かっている場合は、それを求積に渡せる。

一つ目は事前分割である。
`CubaturePlan` は 1 次元では `AdaptiveIntegrator` と同じ G7K15 の細分を行い、`with_breakpoints` で区間を初めから分けておける。
$x = c \pm w$ で分けると、最初の領域の一つが半値全幅に重なり、ピークの中心部が必ず標本化される。
ただし、外側の領域でも $f$ は分割点からの距離に比例する尺度で変わるので、そこでの二分は残る。
外側の領域は、端にピークの裾が寄った別の狭い構造になっている。

二つ目は局所座標への変数変換である。

$$
x = c + w \sinh t, \qquad dx = w \cosh t\,dt
$$

と置くと、$c$ の近くでは刻みが $w$ で、遠くでは指数的に広がる座標になる。
積分は

$$
I = \int_{t_-}^{t_+} f(c + w \sinh t)\, w \cosh t\,dt, \qquad t_\pm = \operatorname{arsinh}\frac{\pm 1 - c}{w}
$$

となり、Lorentz 型では被積分関数が $w/\cosh t$ という幅 1 程度の滑らかな関数になる。
区間の長さは $2\ln(2/w)$ 程度でしか伸びないので、評価回数は $w$ にほとんど依存しない。
被積分関数のコードは $f(c + w\sinh t)\,w\cosh t$ のまま書けばよく、$1/\cosh t$ への簡約は要らない。
この変換は代数的に減衰する裾を持つ幅 $w$ のピークに一般に使える。

## 許容誤差の尺度

面積は $I \approx \pi w$ なので、幅を狭めると積分値そのものが小さくなる。
相対許容誤差だけを与えると、要求される絶対誤差 $\varepsilon_{\mathrm{rel}}|I|$ も $w$ に比例して小さくなり、細分が深くなる。
逆に、絶対許容誤差 $\varepsilon_{\mathrm{abs}}$ が面積 $\pi w$ と同じ程度以上だと、面積をまったく求めなくても許容誤差を満たしうる。
面積として意味のある最小の大きさが分かっているなら、$\varepsilon_{\mathrm{abs}}$ をそれより十分に小さく設定する。
以下のセルは $\varepsilon_{\mathrm{abs}} = \varepsilon_{\mathrm{rel}} = \varepsilon$ とするので、判定の基準は $\varepsilon(1 + |Q|)$ になる。

次のブロックは二つのセルが共有する定義である。
`lorentz` が線形 $f$、`exact_area` が面積の閉形式、`subdivision_options` が許容誤差と二分の上限、`split_at_peak` が $x = c \pm w$ での事前分割、`stretched` が $x = c + w\sinh t$ での積分に対応する。

```rust
//| id: integrate-narrow-peak-model
//| kind: definitions
//| title: Lorentz 型の線形と三つの求積の設定
//| crates: [scioxide-core, scioxide-integrate]
use scioxide_core::{Budget, ErrorTolerance, SciOxideError, Interval, NormSelection, RealScalar};
use scioxide_integrate::{
    AdaptiveIntegrator, AdaptiveRule, CubaturePlan, IntegrationReport, SubdivisionOptions,
};

/// 線形 f(x) = 1 / (1 + ((x − c)/w)²)。
pub(crate) fn lorentz(x: f64, center: f64, width: f64) -> f64 {
    let u = (x - center) / width;
    1.0 / (1.0 + u * u)
}

/// 面積の閉形式 w [atan((1 − c)/w) − atan((−1 − c)/w)]。参照値（f64 の標準関数）。
pub(crate) fn exact_area(center: f64, width: f64) -> f64 {
    width * (((1.0 - center) / width).atan() - ((-1.0 - center) / width).atan())
}

/// 絶対・相対許容誤差 ε（無限大ノルム）と二分の回数の上限。
pub(crate) fn subdivision_options(
    tolerance: f64,
    max_subdivisions: usize,
) -> Result<SubdivisionOptions<f64>, SciOxideError> {
    let tolerance = ErrorTolerance::scalar(tolerance, tolerance, NormSelection::Infinity)?;
    Ok(SubdivisionOptions::default()
        .with_tolerance(tolerance)
        .with_max_subdivisions(Budget::try_from(max_subdivisions)?))
}

/// x = c ± w で区間を分けてから G7K15 で細分する（1 次元の CubaturePlan）。
pub(crate) fn split_at_peak(
    center: f64,
    width: f64,
    options: SubdivisionOptions<f64>,
) -> Result<(f64, IntegrationReport<f64>), SciOxideError> {
    // 分割点は区間 [−1, 1] の割合 (x + 1)/2 で渡し、(0, 1) の外に出たものは除く。
    let fractions: Vec<f64> = [center - width, center + width]
        .iter()
        .map(|x| 0.5 * (x + 1.0))
        .filter(|&t| t > 0.0 && t < 1.0)
        .collect();
    let domain = [Interval::new(-1.0, 1.0)?];
    CubaturePlan::new(&domain, options)?
        .with_breakpoints(0, &fractions)?
        .integrate(|x: &[f64]| Ok(lorentz(x[0], center, width)))
}

/// x = c + w sinh t で書き直した積分 ∫ f(c + w sinh t) w cosh t dt を G7K15 で求める。
pub(crate) fn stretched(
    center: f64,
    width: f64,
    options: SubdivisionOptions<f64>,
) -> Result<(f64, IntegrationReport<f64>), SciOxideError> {
    let lower = RealScalar::asinh((-1.0 - center) / width);
    let upper = RealScalar::asinh((1.0 - center) / width);
    let integrand = |t: f64| {
        let x = center + width * RealScalar::sinh(t);
        Ok(lorentz(x, center, width) * width * RealScalar::cosh(t))
    };
    AdaptiveIntegrator::new(AdaptiveRule::GaussKronrod, options)?
        .integrate(&integrand, Interval::new(lower, upper)?)
}
```

## 一つの線での比較

次のセルは選んだ $c$、$w$、$\varepsilon$、二分の上限で面積を 4 通りに求め、閉形式との差を表にする。
15 点 Gauss–Legendre 則は全区間に 1 回だけ使う固定則で、比較のために置く。
全区間から始める適応求積については、評価した点 $(x, f(x))$ をすべて記録し、線形の曲線に重ねて描く。
曲線はピークの近くで密にとった点で描くので、$w$ が小さくても線の形が崩れない。
二分の上限は全区間からの適応求積と事前分割に効き、sinh 座標の積分は上限に達しない程度の二分で終わる。
最後の判定は全区間から始める適応求積の終了状態を示す。

既定値（$w = 10^{-2}$、$c = 0.15$、$\varepsilon = 10^{-9}$）では、面積の閉形式は $3.1211 \times 10^{-2}$ で、裾がウインドウの外に出る分だけ $\pi w$ より約 0.65 % 小さい。
15 点 Gauss–Legendre 則の値は $8.97 \times 10^{-3}$ で、面積の 3 割にも満たないが、終了状態は `FixedRuleCompleted` である。
全区間からの適応求積は 405 回（$15 + 30 \times 13$）の評価で `ToleranceReached` となり、閉形式との差は $10^{-16}$ 程度だった。
示された誤差推定は $2.7 \times 10^{-11}$ で、実際の差より 5 桁大きい。
グラフの評価点は $x = c$ の周りに集まり、405 点のうち 211 点がウインドウの 1 割の幅にあたる $|x - c| < 0.1$ にある。
事前分割は 375 回、sinh 座標は 165 回の評価で、どちらも閉形式と $10^{-15}$ 以下の差で一致する。

幅を $w = 10^{-3.5}$ にすると、固定則の値は面積の約 1 % になる。
全区間からの適応求積は 525 回に増え、事前分割は 675 回と、かえって多くなる。
sinh 座標は 135 回で済む。

二分の上限を 8 回にすると、全区間からの適応求積は 255 回（$15 + 30 \times 8$）の評価で `BudgetLimit(Subdivision)` となり、判定は partial になる。
このときも閉形式との差は $7.5 \times 10^{-13}$ と小さいが、誤差推定は $1.1 \times 10^{-6}$ で許容誤差を満たさず、計算は精度を主張できない。
事前分割も同じ上限で止まる一方、sinh 座標の積分は上限の内側で `ToleranceReached` に達する。

$c = 0.8$、$w = 10^{-0.5}$ では、面積は $0.62007$ で、$\pi w = 0.9935$ よりはっきり小さい。
ピークが広いので、15 点の固定則でも閉形式との差は $2.0 \times 10^{-6}$ にとどまる。

## 幅を変えたときの評価回数と見落とし

次のセルは $w = 10^{-6}$ から $1$ まで $10^{0.25}$ 倍ずつ 25 通りの幅について、三つの適応求積の評価回数と閉形式との相対差を求める。
二分の上限は 1024 回に固定する。
上のグラフが評価回数、下のグラフが相対差で、横軸の $w$ は二つのグラフで連動する。
相対差が厳密に 0 の点は対数軸に描けないので除き、その数を最後の表に示す。

```rust
//| id: integrate-narrow-peak-width-sweep
//| ref: integrate-narrow-peak-width-sweep
//| title: ピークの幅と評価回数・相対差
//| run: reactive
//| uses: [integrate-narrow-peak-model]
//| crates: [scioxide-core, scioxide-integrate]
//| inputs:
//|   sweep_center: {"type":"range","label":"中心 c [-]","description":"ウインドウの中でのピークの位置を変える。","min":-0.8,"max":0.8,"step":0.05,"value":0.15}
//|   sweep_tolerance_exponent: {"type":"range","label":"許容誤差の指数 p（ε = 10^p）","description":"絶対・相対許容誤差をそろえて変える。","min":-12,"max":-5,"step":1,"value":-9}
//| cases:
//|   - {"id":"centered","label":"c = 0","description":"中心が最初の Kronrod 節点 x = 0 に一致し、全区間からの適応求積も最も狭いピークを見つける。","inputs":{"sweep_center":0}}
//|   - {"id":"loose","label":"ε = 10^-6","description":"許容誤差を緩めると、見落とす幅が広がり、事前分割は面積の半分だけを返す幅が現れる。","inputs":{"sweep_tolerance_exponent":-6}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"widths","path":"/rows/0/1","equals":15}
//|       - {"artifact":"widths","path":"/rows/0/4","range":{"min":0.99}}
//|       - {"artifact":"widths","path":"/rows/0/7","equals":"ToleranceReached"}
//|       - {"artifact":"widths","path":"/rows/0/6","range":{"max":1e-8}}
//|       - {"artifact":"widths","path":"/rows/16/1","range":{"min":300,"max":500}}
//|       - {"artifact":"widths","path":"/rows/16/4","range":{"max":1e-13}}
//|   - case: centered
//|     expect:
//|       - {"artifact":"widths","path":"/rows/0/4","range":{"max":1e-10}}
//|       - {"artifact":"widths","path":"/rows/0/1","range":{"min":1000}}
//|   - case: loose
//|     expect:
//|       - {"artifact":"widths","path":"/rows/7/4","range":{"min":0.99}}
//|       - {"artifact":"widths","path":"/rows/5/5","range":{"min":0.45,"max":0.55}}
//|       - {"artifact":"widths","path":"/rows/0/6","range":{"max":1e-5}}
use scioxide_core::Interval;
use scioxide_integrate::{AdaptiveIntegrator, AdaptiveRule};

let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let center = sweep_center;
let tolerance = 10.0_f64.powf(sweep_tolerance_exponent);
let domain = Interval::new(-1.0_f64, 1.0).map_err(|e| e.to_string())?;
let (mut rows, mut counts) = (Vec::new(), [Vec::new(), Vec::new(), Vec::new()]);
let mut differences = [Vec::new(), Vec::new(), Vec::new()];
let mut exact_zero = 0_usize;
// w = 10^q、q = −6, −5.75, …, 0。
for k in 0..=24 {
    let width = 10.0_f64.powf(-6.0 + 0.25 * f64::from(k));
    let reference = exact_area(center, width);
    let options = subdivision_options(tolerance, 1024).map_err(|e| e.to_string())?;
    let plain = AdaptiveIntegrator::new(AdaptiveRule::GaussKronrod, options.clone())
        .map_err(|e| e.to_string())?
        .integrate(|x: f64| Ok(lorentz(x, center, width)), domain)
        .map_err(|e| e.to_string())?;
    let split = split_at_peak(center, width, options.clone()).map_err(|e| e.to_string())?;
    let local = stretched(center, width, options).map_err(|e| e.to_string())?;
    let mut relative = [0.0; 3];
    for (m, (value, report)) in [&plain, &split, &local].into_iter().enumerate() {
        relative[m] = (value - reference).abs() / reference;
        counts[m].push([width, report.evaluations() as f64]);
        // 差が 0 の点は対数軸に描けないので除き、数を表に示す。
        if relative[m] > 0.0 {
            differences[m].push([width, relative[m]]);
        } else {
            exact_zero += 1;
        }
    }
    rows.push((
        width,
        plain.1.evaluations(),
        split.1.evaluations(),
        local.1.evaluations(),
        relative[0],
        relative[1],
        relative[2],
        plain.1.termination().to_string(),
    ));
}

let series = |data: &[Vec<[f64; 2]>; 3]| -> Vec<serde_json::Value> {
    names
        .iter()
        .zip(data)
        .map(|(name, points)| serde_json::json!({ "name": name, "points": points }))
        .collect()
};

    options = &serde_json::json!({

        "xLabel": "半値半幅 w [-]",
        "yLabel": "評価回数 [回]",
        "xType": "log",
        "yMin": 0.0
    })
);
emit_line_chart!(
    &series(&differences),
    options = &serde_json::json!({
        "link": { "group": "peak-width" },
        "xLabel": "半値半幅 w [-]",
        "yLabel": "閉形式との相対差 [-]",
        "xType": "log",
        "yType": "log"
    })
);
let w_format = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let columns = serde_json::json!([
    { "key": "0", "label": "w [-]", "type": "number", "format": w_format },
    { "key": "1", "label": "評価回数（全区間から）[回]", "type": "integer" },
    { "key": "2", "label": "評価回数（事前分割）[回]", "type": "integer" },
    { "key": "3", "label": "評価回数（sinh 座標）[回]", "type": "integer" },

    { "key": "6", "label": "相対差（sinh 座標）[-]", "type": "number", "format": sci2 },

emit_table_with_columns!(
```

既定値（$c = 0.15$、$\varepsilon = 10^{-9}$）では、全区間からの適応求積の評価回数は $w = 1$ の 45 回から $w = 10^{-5}$ の 585 回まで、$\log w$ にほぼ比例して増える。
ところが $w \le 1.8 \times 10^{-6}$ では評価は 15 回だけで、終了状態は `ToleranceReached` のまま、相対差はほぼ 1 になる。
最初の 15 点がどれもピークに触れず、面積を見落としたまま許容誤差を満たしたと判定された。
事前分割はどの幅でもピークを見つけるが、$w \le 3.2 \times 10^{-3}$ では全区間からの求積より評価回数が多く、最大で 1065 回になる。
sinh 座標の評価回数はどの幅でも 45〜165 回で、相対差は $1.5 \times 10^{-9}$ 以下である。

$c = 0$ にすると、ピークの中心が最初の Kronrod 節点 $x = 0$ に一致する。
このときは全区間からの適応求積も $w = 10^{-6}$ でピークを見つけ、1185 回の評価で収束する。
見落とすかどうかはピークの位置と節点の位置関係で決まり、幅だけでは決まらない。

$\varepsilon = 10^{-6}$ に緩めると、全区間からの適応求積は $w \le 5.6 \times 10^{-5}$ でピークを見落とす。
事前分割は $w \le 1.8 \times 10^{-5}$ で相対差がほぼ 0.5 になる。
中央の領域 $[c - w, c + w]$ はちょうど面積の半分（$\int_{-1}^{1} du/(1 + u^2) = \pi/2$）を持ち、外側の二つの領域では分割点の近くに寄った裾を最初の 15 点が捉えられないためである。
sinh 座標の相対差は $1.7 \times 10^{-6}$ 以下にとどまる。

## まとめ

狭いピークの面積は、適応 Gauss–Kronrod 求積がピークの周りを二分し続けることで求まり、評価回数は幅の対数にほぼ比例して増える。
最初の節点がピークに触れないほど幅が狭いと、適応求積も面積を見落としたまま `ToleranceReached` を返すので、終了状態だけで結果を採用しない。
ピークの位置と幅が分かっているなら、$x = c + w\sinh t$ のような局所座標に書き直すと、評価回数がほぼ幅によらなくなる。
位置での事前分割はピークの中心を確実に標本化するが、外側の裾の細分が残るので、評価回数は減るとは限らない。
二分の上限で止まった `BudgetLimit(Subdivision)` は partial として扱い、上限を増やすか座標を変える。
面積が小さい問題では、絶対許容誤差を面積の大きさより十分に小さくとる。
