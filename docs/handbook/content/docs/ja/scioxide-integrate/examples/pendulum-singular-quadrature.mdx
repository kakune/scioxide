単振り子の周期は、振れ角について積分すると上端で被積分関数が無限大になる積分で表せる。
この例題ではその特異性を求積でどう扱うかを比べる。
周期を第一種完全楕円積分 $K(m)$ で表す導出、小角の展開、Jacobi 楕円関数による軌道は[大振幅振り子の周期を求める](../../../scioxide-special/examples/pendulum-period/)が主に扱う。
ここでは $K(m)$ を scioxide-special の `elliptic_k` で求め、求積の結果を検算する参照値にだけ使う。
振り子の長さ $L = 1.2$ m と標準重力加速度 $g = 9.80665$ m/s² は、そのページの例題と同じ値にする。

## 周期の二つの積分形

長さ $L$ の振り子が最大の振れ角 $\theta_0 \in (0, \pi)$ で振動するとき、エネルギーの保存から角速度は $\dot\theta = \sqrt{2g/L}\,\sqrt{\cos\theta - \cos\theta_0}$ である。
最下点から $\theta_0$ までの時間は周期の 4 分の 1 なので、

$$
T = 2\sqrt2\,\sqrt{\frac{L}{g}}\int_0^{\theta_0}\frac{d\theta}{\sqrt{\cos\theta - \cos\theta_0}}
$$

となる。
これを形式 A と呼ぶ。
小角の周期 $T_0 = 2\pi\sqrt{L/g}$ で割ると $T/T_0 = (\sqrt2/\pi)\,I_A$ で、$I_A$ は上の積分である。

$\sin(\theta/2) = \sin(\theta_0/2)\sin\varphi$ と置換すると（Legendre の置換）、

$$
T = 4\sqrt{\frac{L}{g}}\int_0^{\pi/2}\frac{d\varphi}{\sqrt{1 - m\sin^2\varphi}} = 4\sqrt{\frac{L}{g}}\,K(m), \qquad m = \sin^2\frac{\theta_0}{2}
$$

になる。
これを形式 B と呼ぶ。
$T/T_0 = (2/\pi)\,I_B = (2/\pi)\,K(m)$ が参照値で、`elliptic_k` には法 $k = \sin(\theta_0/2)$ ではなく母数 $m = k^2$ を渡す。

## 上端の逆平方根特異性

形式 A の被積分関数は $\theta \to \theta_0$ で発散する。
$\cos\theta - \cos\theta_0 \approx \sin\theta_0\,(\theta_0 - \theta)$ なので、上端の近くでは $(\sin\theta_0)^{-1/2}(\theta_0 - \theta)^{-1/2}$ のように振る舞う。
指数が $-1/2 > -1$ なので積分は有限だが、多項式で近似する求積則はこの特異性をよく近似できない。
節点を内部に置く $n$ 点 Gauss–Legendre 則を端点に $(1 - t)^{\alpha}$ の特異性を持つ関数に当てると、誤差は $O(n^{-2-2\alpha})$ でしか減らず、$\alpha = -1/2$ では $O(n^{-1})$ である。

被積分関数の評価にも注意が要る。
上端の近くで $\cos\theta - \cos\theta_0$ をそのまま計算すると、ほぼ等しい二数の引き算で相対的な桁が失われる。
距離 $d = \theta_0 - \theta$ を使って積和の公式で

$$
\cos\theta - \cos\theta_0 = 2\sin\Bigl(\theta_0 - \frac{d}{2}\Bigr)\sin\frac{d}{2}
$$

と書けば、引き算は現れない。
ただし、$d$ を座標 $\theta$ から $\theta_0 - \theta$ で作ると、$\theta$ を丸めた時点で $d$ の桁が失われる。

### 二重指数変換と端点の距離

二重指数変換（tanh–sinh 変換）は、区間を $t \in (-\infty, \infty)$ に写し、端点の近くに二重指数的に密集する節点で台形則を使う（[広義積分と端点特異性の二重指数変換](../../algorithms/improper-singular-and-oscillatory/)）。
変換後の被積分関数は $|t| \to \infty$ で二重指数的に減るので、端点の代数的な特異性があっても誤差は点数とともに速く減る。
節点は端点から浮動小数点の間隔よりはるかに小さい距離まで近づくので、座標 $\theta$ は $\theta_0$ に丸められる。
`DoubleExponentialPoint::nearest_endpoint()` は、最も近い端点とそこまでの距離を、丸めた座標から引き算せずに返す。
上端が最も近い点ではこの距離を $d$ として上の積和の式に渡し、それ以外の点では $d = \theta_0 - \theta$ を使う。

### 端点重みと滑らかな因子

特異性を重み関数として分けると、残りは滑らかな関数になる。

$$
\frac{1}{\sqrt{\cos\theta - \cos\theta_0}} = (\theta_0 - \theta)^{-1/2}\,g(\theta), \qquad
g(\theta) = \frac{1}{\sqrt{\sin(\theta_0 - d/2)\,\operatorname{sinc}(d/2)}}
$$

である。
ここで $\operatorname{sinc}x = \sin x / x$ で、$\operatorname{sinc}0 = 1$ である。
$g$ は $\theta = \theta_0$ で $0/0$ の形になるが、極限は $g(\theta_0) = (\sin\theta_0)^{-1/2}$ で、sinc を使う式はこの点でもそのまま値を返す。
`WeightedQuadraturePlan::endpoint` は重み $(\theta - a)^{\alpha}(b - \theta)^{\beta}$ の修正 Chebyshev モーメントを Plan の準備で一度だけ求め、$g$ だけを Chebyshev 補間する修正 Clenshaw–Curtis 則で積分する。
コールバックが返すのは $g$ である。
この則は端点 $a$、$b$ でも $g$ を評価するので、端点で有限の値を返す式が必要になる。
ここでは $\alpha = 0$、$\beta = -1/2$ とする。

同じ分け方を固定の点数で行うのが Gauss–Jacobi 則である。
重み $(1 - t)^{-1/2}$ の Jacobi 族（$\alpha = -1/2$、$\beta = 0$）を区間 $[0, \theta_0]$ に写すと、$1 - t = (\theta_0 - \theta)/h$、$h = \theta_0/2$ である。
$[-1, 1]$ の基準の節点 $t_i$ と重み $w_i$ で書けば、$\int_0^{\theta_0} g(\theta)(\theta_0 - \theta)^{-1/2}\,d\theta = \sqrt h\sum_i w_i\,g(\theta_i)$ となる。
`integrate_weighted` に `GaussianSupport::Interval` で $[0, \theta_0]$ を渡すと重みに $h$ が掛かった $h\sum_i w_i\,g(\theta_i)$ が返るので、求める積分はその値を $\sqrt h$ で割ったものである。

形式 B の被積分関数は $[0, \pi/2]$ で滑らかなので、通常の Gauss–Legendre 則と適応 Gauss–Kronrod 則がそのまま使える。
ただし $\theta_0 \to \pi$ では $m \to 1$ となり、$1 - m\sin^2\varphi$ の零点 $\varphi = \pi/2 + iy$（$\cosh y = 1/\sin(\theta_0/2)$）が端点 $\varphi = \pi/2$ に虚軸方向から近づく。
その距離はおよそ $(\pi - \theta_0)/2$ で、収束はこの距離が小さいほど遅くなる。

次の定義のブロックは二つのセルで共有する。
`form_a(θ₀, d)` は形式 A の被積分関数を上端からの距離 $d$ で評価し、`form_a_smooth(θ₀, d)` は滑らかな因子 $g$、`form_b(m, φ)` は形式 B の被積分関数である。
`reference_ratio(θ₀)` は参照値 $(2/\pi)K(m)$ を返し、$m$ は `sin_degrees` で度から直接求める。

```rust
//| id: integrate-pendulum-model
//| kind: definitions
//| title: 振り子の周期の二つの積分形と K(m) による参照値
//| crates: [scioxide-core, scioxide-special]
use scioxide_core::{SciOxideError, RealScalar, sin_degrees, sinc};
use scioxide_special::elliptic_k;

/// 振り子の長さ L [m] と標準重力加速度 g [m/s²]（special の例題と同じ値）。
pub(crate) const LENGTH: f64 = 1.2;
pub(crate) const GRAVITY: f64 = 9.80665;

/// 母数 m = sin²(θ₀/2)。θ₀ は度で受け取り、sin_degrees で直接評価する。
pub(crate) fn parameter(theta0_deg: f64) -> Result<f64, SciOxideError> {
    Ok(RealScalar::powi(sin_degrees(0.5 * theta0_deg)?, 2))
}

/// 参照値 T/T₀ = (2/π) K(m)。
pub(crate) fn reference_ratio(theta0_deg: f64) -> Result<f64, SciOxideError> {
    Ok(2.0 / <f64 as RealScalar>::PI * elliptic_k(parameter(theta0_deg)?)?)
}

/// 形式 A の被積分関数 1/√(cos θ − cos θ₀) を上端からの距離 d = θ₀ − θ で評価する。
/// cos θ − cos θ₀ = 2 sin(θ₀ − d/2) sin(d/2) なので、引き算による桁落ちがない。
pub(crate) fn form_a(theta0: f64, d: f64) -> f64 {
    let gap = 2.0 * RealScalar::sin(theta0 - 0.5 * d) * RealScalar::sin(0.5 * d);
    1.0 / RealScalar::sqrt(gap)
}

/// 形式 A の滑らかな因子 g = 1/√(sin(θ₀ − d/2) sinc(d/2))。d = 0 では 1/√(sin θ₀)。
pub(crate) fn form_a_smooth(theta0: f64, d: f64) -> Result<f64, SciOxideError> {
    let product = RealScalar::sin(theta0 - 0.5 * d) * sinc(0.5 * d)?;
    Ok(1.0 / RealScalar::sqrt(product))
}

/// 形式 B の被積分関数 1/√(1 − m sin²φ)。
pub(crate) fn form_b(m: f64, phi: f64) -> f64 {
    1.0 / RealScalar::sqrt(1.0 - m * RealScalar::powi(RealScalar::sin(phi), 2))
}
```

## 五つの求め方の比較

次のセルは振幅 $\theta_0$ を選び、周期の比 $T/T_0$ を五つの方法で求めて参照値 $(2/\pi)K(m)$ と比べる。
形式 A には端点距離を使う二重指数変換、座標から差を作る二重指数変換、端点重み $\beta = -1/2$ の重み付き求積を使う。
形式 B には $n$ 点の Gauss–Legendre 則と適応 Gauss–Kronrod 則（G7K15）を使う。
適応的な方法の許容誤差は絶対許容誤差 0、相対許容誤差 $10^{-12}$ にそろえる。
入力は振幅、Gauss–Legendre 則の点数 $n$、二重指数変換の段数の上限 $L$ である。
段数 $L$ では最も細かい刻みが $2^{-(L-1)}$ になる。

表の「推定誤差（相対）」は示された誤差推定を $T/T_0$ の相対値に直したもので、上界ではない。
Gauss–Legendre 則は固定則なので推定誤差を持たず、終了状態は `FixedRuleCompleted` になる。
計算がエラーで終わった方法は、値を「—」にしてエラーの分類を終了状態の列に示す。

use scioxide_integrate::{

// T/T₀ = (√2/π) I_A = (2/π) I_B。
let (scale_a, scale_b) = (RealScalar::sqrt(2.0_f64) / pi, 2.0 / pi);
let tolerance =

                r.error_estimate().map(|e| scale * e / reference),
                Some(r.evaluations()),
                r.termination().to_string(),

            // エラーで終わった方法は値を出さず、分類だけを示す。

            row.0,

        .with_max_levels(levels),

    Some((end, d)) if end == theta0 => Ok(form_a(theta0, d)),

    Ok(1.0 / RealScalar::sqrt(RealScalar::cos(p.coordinate()) - RealScalar::cos(theta0)))

    SubdivisionOptions::default().with_tolerance(tolerance.clone()),
);

    .map_err(|e| e.to_string())?;

record("A 端点重み β = −1/2", scale_a, endpoint.integrate(&smooth));

    .map_err(|e| e.to_string())?;
let elliptic = |phi: f64| Ok(form_b(m, phi));
record(
    "B Gauss–Legendre",
    scale_b,
    legendre.integrate(&elliptic, quarter),
);
let options = SubdivisionOptions::default().with_tolerance(tolerance);

    AdaptiveIntegrator::new(AdaptiveRule::GaussKronrod, options).map_err(|e| e.to_string())?;
record(
    "B 適応 Gauss–Kronrod",
    scale_b,
    adaptive.integrate(&elliptic, quarter),

既定の $\theta_0 = 150^\circ$ では参照値は $T/T_0 = 1.76220$、$T = 3.8732$ s である。
端点距離を使う二重指数変換は 137 回の評価で `HeuristicToleranceReached` となり、参照値との相対誤差は $2.2 \times 10^{-16}$ だった。
幅 0 の区間で返る `DegenerateDomain` を除くと、二重指数変換が成功する状態はこれだけで、`ToleranceReached` にはならない。
尾部の打ち切りの見積もりが観測した減衰に基づく経験的なものだからである。
端点重みの Plan は 40 回、形式 B の適応 Gauss–Kronrod 則は 105 回の評価で `ToleranceReached` となり、どちらも誤差は丸めの水準だった。
8 点の Gauss–Legendre 則は形式 B でも誤差 $1.3 \times 10^{-5}$ が残る。

座標の差で $\cos\theta - \cos\theta_0$ を作った二重指数変換は、どの振幅でも `NonFinite` のエラーで止まる。
上端に密集した節点では座標が $\theta_0$ に丸められて差が 0 になり、$1/\sqrt{0}$ が無限大になるか、丸めで差が負になって平方根が NaN になるからである。
同じ節点でも、端点距離 $d$ を受け取って積和の式で評価すれば、$d$ が $\theta_0$ の浮動小数点の間隔より小さくても有限の値が得られる。
この比較は、二重指数変換が上端の特異性を扱えるかどうかが変換そのものではなく、被積分関数の評価の仕方で決まることを示す。

$\theta_0 = 30^\circ$ では $m = 0.067$ と小さく、8 点の Gauss–Legendre 則でも相対誤差は $1.5 \times 10^{-13}$ になる。
$\theta_0 = 179.9^\circ$ では同じ 8 点の誤差が 0.33 に増える。
適応的な方法はどれも許容誤差に達するが、評価回数は二重指数変換が 265 回、端点重みが 400 回、適応 Gauss–Kronrod 則が 345 回に増える。
段数の上限を $L = 4$ にすると（$\theta_0 = 179^\circ$）、二重指数変換は 73 回の評価で `RefinementLimit` となり、最後の値は推定値として返る。
このとき実際の相対誤差は $1.9 \times 10^{-13}$ だが、示された推定誤差は $2.8 \times 10^{-6}$ で、段数が足りないことを正しく示している。

## 節点数と誤差の減り方

次のセルは固定の点数の則で点数 $n = 1, 2, \dots, 128$ を動かし、$T/T_0$ の相対誤差を両対数で描く。
系列は三つある。
形式 A の被積分関数にそのまま当てた Gauss–Legendre 則、形式 A の滑らかな因子 $g$ に当てた Gauss–Jacobi 則（重み $(1 - t)^{-1/2}$）、形式 B に当てた Gauss–Legendre 則である。
誤差がちょうど 0 になった点は対数軸に描けないので除き、その数を表に示す。
破線の横線は倍精度の機械イプシロン $\varepsilon \approx 2.2 \times 10^{-16}$ である。

```rust
//| id: integrate-pendulum-node-convergence
//| ref: integrate-pendulum-node-convergence
//| title: 節点数を増やしたときの三つの固定則の誤差
//| run: reactive
//| uses: [integrate-pendulum-model]
//| crates: [scioxide-core, scioxide-integrate, scioxide-poly, scioxide-special]
//| inputs:
//|   sweep_amplitude_deg: {"type":"range","label":"最大の振れ角 θ₀ [deg]","description":"形式 B の収束の速さを変える。","min":1,"max":179.9,"step":0.1,"value":150}
//| cases:
//|   - {"id":"small-amplitude","label":"θ₀ = 30°","description":"形式 B の Gauss–Legendre 則は 10 点前後で丸めの水準に達する。","inputs":{"sweep_amplitude_deg":30}}
//|   - {"id":"near-inverted","label":"θ₀ = 179.9°","description":"形式 B の収束が遅れ、128 点でも 10⁻⁵ 程度の誤差が残る。","inputs":{"sweep_amplitude_deg":179.9}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"nodes","path":"/rows/0/1","approx":{"value":0.11406532681625392,"rtol":1e-8}}
//|       - {"artifact":"nodes","path":"/rows/3/1","approx":{"value":3.9607e-3,"rtol":1e-4}}
//|       - {"artifact":"nodes","path":"/rows/1/2","range":{"min":0,"max":1e-14}}
//|       - {"artifact":"nodes","path":"/rows/1/3","range":{"min":5e-11,"max":3e-10}}
//|       - {"artifact":"nodes","path":"/rows/3/3","range":{"min":0,"max":1e-14}}
//|   - case: small-amplitude
//|     expect:
//|       - {"artifact":"nodes","path":"/rows/1/2","range":{"min":0,"max":1e-14}}
//|       - {"artifact":"nodes","path":"/rows/1/3","range":{"min":0,"max":1e-14}}
//|   - case: near-inverted
//|     expect:
//|       - {"artifact":"nodes","path":"/rows/3/1","approx":{"value":2.4186e-2,"rtol":1e-3}}
//|       - {"artifact":"nodes","path":"/rows/3/2","range":{"min":1e-9,"max":2e-8}}
//|       - {"artifact":"nodes","path":"/rows/3/3","approx":{"value":2.1123e-5,"rtol":1e-2}}
//|       - {"artifact":"quantities","path":"/rows/0/1","equals":0}
use scioxide_core::{Interval, RealScalar};
use scioxide_integrate::{FixedRule, GaussianRulePlan, GaussianSupport};
use scioxide_poly::OrthogonalFamily;

let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let pi = <f64 as RealScalar>::PI;
let theta0 = sweep_amplitude_deg * pi / 180.0;
let m = parameter(sweep_amplitude_deg).map_err(|e| e.to_string())?;
let reference = reference_ratio(sweep_amplitude_deg).map_err(|e| e.to_string())?;
let (scale_a, scale_b) = (RealScalar::sqrt(2.0_f64) / pi, 2.0 / pi);
let interval_a = Interval::new(0.0, theta0).map_err(|e| e.to_string())?;
let quarter = Interval::new(0.0, 0.5 * pi).map_err(|e| e.to_string())?;
// Jacobi の重み (1 − t)^(−1/2) は区間 [0, θ₀] で √h (θ₀ − θ)^(−1/2)、h = θ₀/2 になる。
let jacobi_scale = scale_a / RealScalar::sqrt(0.5 * theta0);
let mut curves = [Vec::new(), Vec::new(), Vec::new()];
let (mut rows, mut dropped) = (Vec::new(), 0_usize);
for n in 1..=128_usize {
    let rule = |family| GaussianRulePlan::<f64>::new(family, n);
    let legendre = rule(OrthogonalFamily::Legendre).map_err(|e| e.to_string())?;
    let jacobi = rule(OrthogonalFamily::Jacobi {
        alpha: -0.5,
        beta: 0.0,
    })
    .map_err(|e| e.to_string())?;
    let (direct, _) = legendre
        .integrate(|theta: f64| Ok(form_a(theta0, theta0 - theta)), interval_a)
        .map_err(|e| e.to_string())?;
    let (weighted, _): (f64, _) = jacobi
        .integrate_weighted(
            |theta: f64| form_a_smooth(theta0, theta0 - theta),
            GaussianSupport::Interval(interval_a),
        )
        .map_err(|e| e.to_string())?;
    let (smooth, _) = legendre
        .integrate(|phi: f64| Ok(form_b(m, phi)), quarter)
        .map_err(|e| e.to_string())?;
    let errors = [scale_a * direct, jacobi_scale * weighted, scale_b * smooth]
        .map(|ratio| (ratio / reference - 1.0).abs());
    for (error, curve) in errors.iter().zip(curves.iter_mut()) {
        // 誤差が 0 の点は対数軸に描けないので除き、数を数える。
        if *error > 0.0 {
            curve.push([n as f64, *error]);
        } else {
            dropped += 1;
        }
    }
    if [4, 16, 64, 128].contains(&n) {
        rows.push((n, errors[0], errors[1], errors[2]));
    }
}
let names = [
    "A に Gauss–Legendre",
    "A の g に Gauss–Jacobi",
    "B に Gauss–Legendre",
];
let symbols = ["circle", "triangle", "rect"];
let dashed = serde_json::json!({ "lineType": "dashed" });
let series: Vec<_> = names
    .iter()
    .zip(symbols)
    .zip(&curves)
    .map(|((name, symbol), points)| {
        serde_json::json!({
            "name": name,
            "points": points,
            "style": { "symbol": symbol }
        })
    })
    .collect();
emit_line_chart!(
    &series,
    options = &serde_json::json!({
        "xLabel": "節点数 n [点]",
        "yLabel": "T/T₀ の相対誤差 [-]",
        "xType": "log",
        "yType": "log",
        "xMin": 1.0,
        "xMax": 128.0,
        "yMin": 1e-17,
        "yMax": 1.0,
        "annotations": [
            { "kind": "line", "axis": "y", "value": f64::EPSILON, "label": "ε", "style": dashed }
        ]
    })
);
let columns = serde_json::json!([
    { "key": "0", "label": "節点数 n [点]", "type": "integer" },
    { "key": "1", "label": "A に Gauss–Legendre [-]", "type": "number", "format": sci3 },
    { "key": "2", "label": "A の g に Gauss–Jacobi [-]", "type": "number", "format": sci3 },
    { "key": "3", "label": "B に Gauss–Legendre [-]", "type": "number", "format": sci3 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "nodes" })
);
emit_table_with_columns!(
    serde_json::json!([
        { "key": "0", "label": "量" },
        { "key": "1", "label": "値", "type": "integer" }
    ]),
    vec![("グラフから除いた誤差 0 の点の数", dropped)],
    metadata = serde_json::json!({ "id": "quantities" })
);
```

形式 A にそのまま当てた Gauss–Legendre 則（丸）は、点数を 2 倍にするごとに誤差がほぼ半分になり、傾き $-1$ の直線に並ぶ。
これは端点の特異性 $(\theta_0 - \theta)^{-1/2}$ による $O(n^{-1})$ の収束で、既定の $\theta_0 = 150^\circ$ では 128 点でも誤差は $4.0 \times 10^{-3}$ である。
同じ特異性を重み $(1 - t)^{-1/2}$ として則に持たせた Gauss–Jacobi 則（三角）は、$g$ が滑らかなので誤差が指数的に減り、16 点で丸めの水準（$3.3 \times 10^{-16}$）に達する。
形式 B の Gauss–Legendre 則（四角）も指数的に減るが、16 点の誤差は $1.1 \times 10^{-10}$ で、Gauss–Jacobi 則より遅い。

$\theta_0 = 179.9^\circ$ では、指数的に減る二つの系列も遅くなる。
形式 B では前節の分岐点が端点から約 $8.7 \times 10^{-4}$ の距離にあり、128 点でも誤差は $2.1 \times 10^{-5}$ である。
形式 A の因子 $g$ も $\sin(\theta_0 - d/2) = 0$ となる点が区間の外 $\theta = 2\pi - \theta_0$ に近づくので、Gauss–Jacobi 則は 128 点で $5.3 \times 10^{-9}$ にとどまる。
振幅を倒立に近づけると、端点の特異性とは別に、周期の対数発散に対応するほぼ特異な構造が現れる。
固定の点数の則はこれを解像できず、前節の適応的な方法は評価回数を増やして対応する。

## 倒立に近い振幅での参照値

$\theta_0 = 179.9^\circ$ では、形式 A の二つの適応的な方法（二重指数変換と端点重み）の値は互いに相対 $10^{-14}$ 以下で一致するが、参照値との差は $2.4 \times 10^{-13}$ ある。
この差の多くは参照値の側にある。
$m = \sin^2(\theta_0/2)$ を倍精度に丸めると $1 - m \approx 7.6 \times 10^{-7}$ に相対 $\varepsilon/(1 - m)$ 程度の誤差が入り、$K(m) \approx \ln\bigl(4/\sqrt{1 - m}\bigr)$ では $K$ の相対誤差はおよそ $\varepsilon/\bigl(2(1 - m)K\bigr)$、つまり $10^{-11}$ 程度まで増えうる。
形式 A は $\theta_0$ を直接使うので、この丸めを通らない。
$\sqrt{1 - m} = \cos(\theta_0/2)$ から計算する算術幾何平均による参照値は[大振幅振り子の周期を求める](../../../scioxide-special/examples/pendulum-period/)にあり、この影響を受けない。
参照値と比べるときは、比較する量の条件数も含めて誤差を読む。

## まとめ

振り子の周期を振れ角の積分で書くと、上端に逆平方根の特異性を持つ積分になる。
二重指数変換で求めるときは、`nearest_endpoint()` が返す端点からの距離で被積分関数を評価し、$\cos\theta - \cos\theta_0$ を積和の式で計算する。
座標の差で計算すると、丸めで差が 0 や負になり `NonFinite` のエラーで止まる。
特異性 $(\theta_0 - \theta)^{-1/2}$ を重みとして分けると、`WeightedQuadraturePlan::endpoint` や Gauss–Jacobi 則が滑らかな因子だけを扱い、少ない評価回数で丸めの水準に達する。
特異性を残したまま Gauss–Legendre 則を当てると誤差は $O(n^{-1})$ でしか減らず、Legendre の置換で滑らかにした形式 B も振幅が $180^\circ$ に近いと収束が遅れる。
