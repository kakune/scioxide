量子調和振動子の固有状態は確率密度に Gauss 関数 $e^{-\xi^2}$ を持つ。
位置のべき乗の期待値はこの重みに多項式を掛けた積分になるので、重み $e^{-\xi^2}$ の Gauss 則（Gauss–Hermite 則）で有限個の点から正確に求められる。
この例題ではどの点数から正確になるかを導き、`GaussianRulePlan` の結果で確かめる。
多項式でない期待値 $\langle\cos q\xi\rangle$ では誤差が点数とともに速く減ることと、同じ積分を二重指数変換で求めた場合の評価回数も比べる。
最後に、四次の非調和項によるエネルギー準位のずれを一次の摂動で求める。

Gauss–Hermite 則の節点が Hermite 多項式の零点であることと、零点の計算は [Gauss 節点と Hermite 多項式の零点](../../../scioxide-poly/examples/gauss-nodes-as-zeros/)で扱う。

## 固有状態と期待値の閉形式

質量 $m$、角振動数 $\omega$ の調和振動子で、長さの単位 $\sqrt{\hbar/(m\omega)}$ による無次元の位置 $\xi = x/\sqrt{\hbar/(m\omega)}$ を使う。
ハミルトニアンは $H_0 = \hbar\omega\,(-\tfrac12\,d^2/d\xi^2 + \tfrac12\xi^2)$、エネルギー準位は $E_n^{(0)} = \hbar\omega\,(n + \tfrac12)$ で、規格化した固有関数は

$$
\psi_n(\xi) = \bigl(2^n n!\sqrt\pi\bigr)^{-1/2} H_n(\xi)\,e^{-\xi^2/2}
$$

である。
$H_n$ は物理学者の規約の Hermite 多項式（$H_0 = 1$、$H_1 = 2\xi$）である。
以下ではエネルギーを $\hbar\omega$ 単位で書く。

期待値 $\langle A\rangle_n = \int A(\xi)\,\psi_n(\xi)^2\,d\xi$ の閉形式は梯子演算子で求められる。
消滅演算子 $a$ と生成演算子 $a^\dagger$ は $a\,|n\rangle = \sqrt n\,|n - 1\rangle$、$a^\dagger|n\rangle = \sqrt{n + 1}\,|n + 1\rangle$ を満たし、位置は $\xi = (a + a^\dagger)/\sqrt2$ と書ける。
$\xi^k|n\rangle$ を基底 $|m\rangle$ で展開して係数の二乗和を取れば $\langle\xi^{2k}\rangle_n = \lVert\xi^k|n\rangle\rVert^2$ になり、

$$
\langle\xi^2\rangle_n = n + \tfrac12, \qquad \langle\xi^4\rangle_n = \tfrac34\,(2n^2 + 2n + 1)
$$

を得る。
$\langle\xi^2\rangle_n = n + \tfrac12$ は、ポテンシャルエネルギーの期待値が全エネルギーの半分になるというビリアル定理とも一致する。

位置の余弦の期待値は、$e^{iq\xi}$ が変位演算子 $D(\alpha)$（$\alpha = iq/\sqrt2$）であることから

$$
\langle\cos q\xi\rangle_n = e^{-q^2/4}\,L_n\!\left(\frac{q^2}{2}\right)
$$

となる。
$L_n$ は Laguerre 多項式で、$q$ は無次元の波数である。
この量は振動子に運動量を与える散乱や光の吸収のうち、振動の状態が変わらない過程の振幅に現れ、その熱平均が Debye–Waller 因子になる。

## Gauss–Hermite 則が正確になる点数

$h_n(\xi) = (2^n n!\sqrt\pi)^{-1/2}H_n(\xi)$ と書くと、$\psi_n^2 = h_n^2\,e^{-\xi^2}$ なので

$$
\langle\xi^{2k}\rangle_n = \int_{-\infty}^{\infty} h_n(\xi)^2\,\xi^{2k}\,e^{-\xi^2}\,d\xi
$$

である。
重み $e^{-\xi^2}$ を則に持たせると、コールバックが返すのは多項式 $f(\xi) = h_n(\xi)^2\xi^{2k}$ で、その次数は $2n + 2k$ である。
$N$ 点の Gauss 則は次数 $2N - 1$ 以下の多項式を厳密に積分する（[Gauss 型求積と Clenshaw–Curtis 則](../../algorithms/gaussian-and-clenshaw-curtis/)）。
したがって

$$
2n + 2k \le 2N - 1 \iff N \ge n + k + 1
$$

のとき、求積は丸め誤差を除いて正確になる。

一つ手前の $N = n + k$ では、$f$ の次数がちょうど $2N$ である。
$N$ 次のモニックな Hermite 多項式を $\pi_N = 2^{-N}H_N$ とし、次数 $2N$ の $f$ を $\pi_N^2$ で割ると、商は定数 $c$、余りは次数 $2N - 1$ 以下で、$f = c\,\pi_N^2 + (\text{次数 } 2N - 1 \text{ 以下})$ となる。
$c$ は $f$ の最高次の係数 $2^n/(n!\sqrt\pi)$ である。
節点では $\pi_N = 0$ なので、$c\,\pi_N^2$ の項は求積値に寄与せず、誤差はちょうど

$$
\langle\xi^{2k}\rangle_n - Q_N = c\int \pi_N^2\,e^{-\xi^2}\,d\xi = \frac{2^n}{n!\sqrt\pi}\cdot\frac{\sqrt\pi\,N!}{2^N} = \frac{(n + k)!}{n!\,2^k}
$$

になる。
誤差は正なので、求積値は真の値より小さい。
たとえば $n = 4$、$k = 2$ では、$\langle\xi^4\rangle_4 = 30.75$ に対して $N = 6$ の求積値は $30.75 - 7.5 = 23.25$ である。
誤差は点数を 1 つ増やしただけで、この大きさから丸めの水準まで落ちる。

$\cos q\xi$ は多項式ではないので、$h_n^2\cos q\xi$ を正確に積分する有限の点数はない。
ただし $\cos q\xi$ は複素平面全体で解析的（整関数）なので、誤差は点数のどのべき乗よりも速く減る（スペクトル収束）。
誤差が減り始めるのは、$h_n^2\cos q\xi$ を次数 $2N - 1$ の多項式でよく近似できる点数に達してからで、それまでは誤差が $10^{-2}$ から $10^{-1}$ 程度のまま上下する。
その点数は $h_n^2$ の次数 $2n$ と、$\cos q\xi$ の振動の速さ $q$ の両方とともに増える。

## 正規化した Hermite 多項式の漸化式

$h_n$ を $H_n$ から $(2^n n!\sqrt\pi)^{-1/2}$ を掛けて作ると、$n$ が大きいときに途中の値が倍精度の範囲を外れる。
たとえば $2^n n!$ は $n = 151$ で倍精度の最大値（約 $1.8\times10^{308}$）を超える。
scioxide-poly の `OrthogonalFamily::HermiteH.evaluate(n, ξ)` は途中の値のあふれを避けて $H_n(\xi)$ そのものを返すが、その値が表せない大きさになると `NumericalInstability` のエラーを返す（[直交多項式族の理論と数値計算](../../../scioxide-poly/algorithms/orthogonal-families/)）。
そこで正規化したまま進む三項漸化式

$$
h_0 = \pi^{-1/4}, \quad h_1 = \sqrt2\,\xi\,h_0, \quad
h_{j+1} = \sqrt{\frac{2}{j + 1}}\;\xi\,h_j - \sqrt{\frac{j}{j + 1}}\;h_{j-1}
$$

を使う。
初期値を $\pi^{-1/4}e^{-\xi^2/2}$ に替えると、同じ漸化式が固有関数 $\psi_j(\xi)$ を直接与える。
重みを持たない求積（二重指数変換）ではこちらを使う。

次の定義のブロックは二つのセルで共有する。
`hermite_recurrence(n, ξ, start)` が上の漸化式で、`start` に $h_0$ を渡すと $h_n(\xi)$、$\psi_0(\xi)$ を渡すと $\psi_n(\xi)$ を返す。
`ladder_state(n, k)` は $\xi^k|n\rangle$ の展開係数を梯子演算子の規則だけで計算し、`ladder_moment(n, k)` はその二乗和 $\langle\xi^{2k}\rangle_n$ を返す。
求積とは独立な参照値として、どちらのセルもこれを使う。

```rust
//| id: integrate-oscillator-model
//| kind: definitions
//| title: 正規化した Hermite 多項式の漸化式と梯子演算子による参照値
//| crates: [scioxide-core]
use scioxide_core::RealScalar;

/// h_{j+1} = √(2/(j+1)) ξ h_j − √(j/(j+1)) h_{j−1} を start = h_0 から n 回進める。
pub(crate) fn hermite_recurrence(n: usize, xi: f64, start: f64) -> f64 {
    let (mut previous, mut current) = (0.0, start);
    for j in 0..n {
        let next = RealScalar::sqrt(2.0 / (j + 1) as f64) * xi * current
            - RealScalar::sqrt(j as f64 / (j + 1) as f64) * previous;
        previous = current;
        current = next;
    }
    current
}

/// ξ^k |n⟩ の展開係数。ξ|m⟩ = (√m |m−1⟩ + √(m+1) |m+1⟩)/√2 を k 回使う。
pub(crate) fn ladder_state(n: usize, k: usize) -> Vec<f64> {
    let mut state = vec![0.0; n + k + 1];
    state[n] = 1.0;
    let half = RealScalar::sqrt(0.5_f64);
    for _ in 0..k {
        let mut next = vec![0.0; n + k + 1];
        for (m, &c) in state.iter().enumerate().filter(|(_, c)| **c != 0.0) {
            // 係数が 0 でない添字は n + k − 1 以下なので、m + 1 は範囲内にある。
            if m > 0 {
                next[m - 1] += c * RealScalar::sqrt(m as f64) * half;
            }
            next[m + 1] += c * RealScalar::sqrt((m + 1) as f64) * half;
        }
        state = next;
    }
    state
}

/// ⟨ξ^{2k}⟩_n = ‖ξ^k |n⟩‖²。
pub(crate) fn ladder_moment(n: usize, k: usize) -> f64 {
    ladder_state(n, k).iter().map(|c| c * c).sum()
}
```

## 点数と誤差の関係

次のセルは量子数 $n$、モーメントの次数 $k$、波数 $q$ を選び、点数 $N = 1, 2, \dots, 40$ の Gauss–Hermite 則で $\langle\xi^{2k}\rangle_n$ と $\langle\cos q\xi\rangle_n$ を求める。
二つの被積分関数は 2 成分の値 `[h_n² ξ^{2k}, h_n² cos qξ]` として 1 回の呼び出しで渡し、`GaussianSupport::RealLine` で実軸全体に適用する。
成分ごとに $\int f_i(\xi)\,e^{-\xi^2}\,d\xi$ が返る。
参照値は梯子演算子による $\langle\xi^{2k}\rangle_n$ と、scioxide-poly の `OrthogonalFamily::Laguerre.evaluate` で計算した $e^{-q^2/4}L_n(q^2/2)$ である。

グラフは $\langle\xi^{2k}\rangle_n$ の相対誤差と $\langle\cos q\xi\rangle_n$ の絶対誤差を、点数に対して対数軸で描く。
縦の線が $N = n + k + 1$ である。
表は正確になる一つ手前の点数 $N = n + k$、正確になる点数 $N = n + k + 1$、最大の点数 $N = 40$ の結果と参照値を並べる。
$N = n + k$ の行には前節で導いた不足分 $(n + k)!/(n!\,2^k)$ を相対誤差に直した値を示す。
このセルは入力と誤差の曲線を次のセルに渡す。

```rust
//| id: integrate-oscillator-hermite-exactness
//| ref: integrate-oscillator-hermite-exactness
//| title: 点数を動かして Gauss–Hermite 則の厳密次数とスペクトル収束を見る
//| run: reactive
//| uses: [integrate-oscillator-model]
//| crates: [scioxide-core, scioxide-integrate, scioxide-poly]
//| exports: [level, power, wavenumber, moment_curve, cosine_curve]
//| inputs:
//|   level: {"type":"range","label":"量子数 n [-]","description":"固有状態を選ぶ。h_n² の次数 2n が変わる。","min":0,"max":20,"step":1,"value":4}
//|   power: {"type":"range","label":"モーメントの次数 k [-]","description":"⟨ξ^{2k}⟩ の k。被積分多項式の次数は 2n + 2k。","min":0,"max":4,"step":1,"value":2}
//|   wavenumber: {"type":"range","label":"波数 q [-]","description":"⟨cos qξ⟩ の q。大きいほど多くの点が要る。","min":0.5,"max":8,"step":0.5,"value":3}
//| cases:
//|   - {"id":"high-level","label":"n = 15, k = 1","description":"N = 17 で ⟨ξ²⟩ = 15.5 が正確になり、N = 16 では不足分 8 のため 7.5 になる。","inputs":{"level":15,"power":1}}
//|   - {"id":"short-wave","label":"q = 8","description":"⟨cos qξ⟩ の誤差は N = 25 付近まで 10⁻¹ 程度に残り、N = 40 でも 4×10⁻⁸ 程度である。","inputs":{"wavenumber":8}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"nodes","path":"/rows/0/1","approx":{"value":23.25,"rtol":1e-12}}
//|       - {"artifact":"nodes","path":"/rows/0/2","approx":{"value":0.24390243902439024,"rtol":1e-12}}
//|       - {"artifact":"nodes","path":"/rows/0/3","approx":{"value":0.24390243902439024,"rtol":1e-12}}
//|       - {"artifact":"nodes","path":"/rows/1/2","range":{"min":0,"max":1e-13}}
//|       - {"artifact":"nodes","path":"/rows/2/5","range":{"min":0,"max":1e-13}}
//|       - {"artifact":"nodes","path":"/rows/3/1","approx":{"value":30.75,"rtol":1e-14}}
//|       - {"artifact":"quantities","path":"/rows/0/1","equals":2}
//|   - case: high-level
//|     expect:
//|       - {"artifact":"nodes","path":"/rows/0/1","approx":{"value":7.5,"rtol":1e-11}}
//|       - {"artifact":"nodes","path":"/rows/1/2","range":{"min":0,"max":1e-12}}
//|   - case: short-wave
//|     expect:
//|       - {"artifact":"nodes","path":"/rows/0/5","range":{"min":1e-3,"max":10}}
//|       - {"artifact":"nodes","path":"/rows/2/5","range":{"min":1e-9,"max":1e-6}}
use scioxide_core::RealScalar;
use scioxide_integrate::{GaussianRulePlan, GaussianSupport};
use scioxide_poly::OrthogonalFamily;

let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let digits15 = serde_json::json!({ "significantDigits": 15 });
let (n, k, q) = (level as usize, power as usize, wavenumber);
// 参照値: 梯子演算子による ⟨ξ^{2k}⟩_n と e^{−q²/4} L_n(q²/2)。
let moment = ladder_moment(n, k);
let laguerre = OrthogonalFamily::Laguerre
    .evaluate(n, q * q / 2.0)
    .map_err(|e| e.to_string())?;
let cosine = RealScalar::exp(-q * q / 4.0) * laguerre;
// 重み e^{−ξ²} を除いた被積分関数 [h_n² ξ^{2k}, h_n² cos qξ]。
let h0 = 1.0 / RealScalar::sqrt(RealScalar::sqrt(<f64 as RealScalar>::PI));
let polynomial = |xi: f64| {
    let h = hermite_recurrence(n, xi, h0);
    Ok([
        h * h * RealScalar::powi(xi, 2 * k as i32),
        h * h * RealScalar::cos(q * xi),
    ])
};
let threshold = n + k + 1;
let (mut moment_curve, mut cosine_curve, mut rows) = (Vec::new(), Vec::new(), Vec::new());
let mut exact_zero = 0_usize;
for nodes in 1..=40 {
    let plan =
        GaussianRulePlan::new(OrthogonalFamily::HermiteH, nodes).map_err(|e| e.to_string())?;
    let (value, report): ([f64; 2], _) = plan
        .integrate_weighted(&polynomial, GaussianSupport::RealLine)
        .map_err(|e| e.to_string())?;
    let errors = [
        (value[0] - moment).abs() / moment,
        (value[1] - cosine).abs(),
    ];
    for (error, curve) in errors
        .into_iter()
        .zip([&mut moment_curve, &mut cosine_curve])
    {
        // 誤差が 0 の点は対数軸に描けないので除き、数を数える。
        if error > 0.0 {
            curve.push([nodes as f64, error]);
        } else {
            exact_zero += 1;
        }
    }
    if [threshold - 1, threshold, 40].contains(&nodes) {
        // N = n + k の不足分 (n + k)!/(n! 2^k) を相対誤差に直す。
        let shortfall = (nodes + 1 == threshold)
            .then(|| (n + 1..=n + k).map(|j| j as f64 / 2.0).product::<f64>() / moment);
        rows.push((
            Some(nodes),
            value[0],
            Some(errors[0]),
            shortfall,
            value[1],
            Some(errors[1]),
            Some(report.termination().to_string()),
        ));
    }
}
// 最後の行は参照値（点数・誤差・終了状態なし）。
rows.push((None, moment, None, None, cosine, None, None));
export!(level, &n);
export!(power, &k);
export!(wavenumber, &q);
export!(moment_curve, &moment_curve);
export!(cosine_curve, &cosine_curve);
emit_line_chart!(
    &vec![
        serde_json::json!({
            "name": "⟨ξ^{2k}⟩ の相対誤差",
            "points": moment_curve,
            "style": { "symbol": "circle" }
        }),
        serde_json::json!({
            "name": "⟨cos qξ⟩ の絶対誤差",
            "points": cosine_curve,
            "style": { "symbol": "triangle" }
        }),
    ],
    options = &serde_json::json!({
        "xLabel": "Gauss–Hermite の点数 N [点]",
        "yLabel": "誤差 [-]",
        "yType": "log",
        "xMin": 0.0,
        "xMax": 40.0,
        "annotations": [
            { "kind": "line", "axis": "x", "value": threshold as f64, "label": "N = n + k + 1" }
        ]
    })
);
let columns = serde_json::json!([
    { "key": "0", "label": "点数 N [点]", "type": "integer", "nullText": "参照値" },
    { "key": "1", "label": "⟨ξ^{2k}⟩ [-]", "type": "number", "format": digits15 },
    { "key": "2", "label": "相対誤差 [-]", "type": "number", "format": sci3, "nullText": "—" },
    { "key": "3", "label": "理論の不足分 [-]", "type": "number", "format": sci3, "nullText": "—" },
    { "key": "4", "label": "⟨cos qξ⟩ [-]", "type": "number", "format": digits15 },
    { "key": "5", "label": "絶対誤差 [-]", "type": "number", "format": sci3, "nullText": "—" },
    { "key": "6", "label": "終了状態", "nullText": "—" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "nodes" })
);
let columns = serde_json::json!([
    { "key": "0", "label": "量" },
    { "key": "1", "label": "点の数 [点]", "type": "integer" }
]);
emit_table_with_columns!(
    columns,
    vec![("誤差が 0 でグラフから除いた点", exact_zero)],
    metadata = serde_json::json!({ "id": "quantities" })
);
```

既定値（$n = 4$、$k = 2$、$q = 3$）では、$N = 6$ の求積値は 23.25 で、相対誤差 0.244 は理論の不足分 $7.5/30.75$ と一致する。
$N = 7$ では相対誤差が $10^{-15}$ 程度に落ち、それより多い点数でも丸めの水準のまま変わらない。
グラフの $\langle\xi^{2k}\rangle$ の記号が $N = 7$ の縦線で十数桁を一度に落ちるのが、厳密次数の効果である。
$\langle\cos 3\xi\rangle_4$ の絶対誤差は $N = 11$ までは $0.009$ から $0.37$ の間で上下し、そこから 1 点ごとにおよそ 1 桁ずつ下がって、$N = 25$ 付近で丸めの水準に届く。

`high-level` の場合（$n = 15$、$k = 1$）は、$N = 16$ の求積値が 7.5 で、$\langle\xi^2\rangle_{15} = 15.5$ との差 8 は不足分 $(n + k)!/(n!\,2^k) = 16/2$ に一致する。
$N = 17$ で相対誤差は $10^{-14}$ 程度になる。
$n$ が大きいと $\langle\cos q\xi\rangle$ の誤差が減り始める点数も増え、$q = 3$ でも $N = 27$ 付近まで $10^{-2}$ を下回らない。
`short-wave` の場合（$q = 8$）は、$N = 40$ でも誤差が $4\times10^{-8}$ 程度残る。
厳密次数のない被積分関数では、点数を変えた差か別の方法との比較で誤差を見積もる。

$k = 0$ にすると、$N = n$ の行の求積値は規格化 $\langle 1\rangle_n = 1$ ではなく 0（丸めの水準）になる。
$n$ 点の節点は $H_n$ の零点なので、すべての節点で $h_n^2 = 0$ になるからである。
不足分の式も $(n + 0)!/(n!\,2^0) = 1$ を与え、相対誤差 1 と一致する。

## 二重指数変換との評価回数の比較

重みを則に組み込まない方法として、実軸全体の二重指数変換 $\xi = \sinh(\tfrac{\pi}{2}\sinh t)$（sinh–sinh 変換）がある。
`DoubleExponentialIntegrator` に `DoubleExponentialDomain::RealLine` を渡すと、$\psi_n(\xi)^2$ を含む被積分関数全体を台形則で積分し、刻みを半分にしながら差 $|Q_h - Q_{2h}|$ と裾の打ち切りの推定から誤差を見積もる（[広義積分と端点特異性の二重指数変換](../../algorithms/improper-singular-and-oscillatory/)）。
誤差推定は観測した減衰に基づくので、収束しても終了状態は `HeuristicToleranceReached` である。

次のセルは前のセルの $n$、$k$、$q$ を受け取り、許容誤差（絶対・相対とも同じ値）を $10^{-4}$ から $10^{-14}$ まで変えて同じ 2 成分を二重指数変換で積分する。
被積分関数は $\psi_n$ の漸化式で作り、遠方で $\psi_0 = \pi^{-1/4}e^{-\xi^2/2}$ が 0 に落ちたらそのまま 0 を返す。
グラフは評価回数と誤差の関係を、前のセルの Gauss–Hermite 則の曲線と同じ対数軸に重ねる。

```rust
//| id: integrate-oscillator-double-exponential
//| ref: integrate-oscillator-double-exponential
//| title: 同じ期待値を二重指数変換で求め、評価回数と誤差を比べる
//| run: reactive
//| uses: [integrate-oscillator-model]
//| crates: [scioxide-core, scioxide-integrate, scioxide-poly]
//| dependsOn:
//|   solve: integrate-oscillator-hermite-exactness
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"tolerances","path":"/rows/4/2","range":{"min":0,"max":1e-12}}
//|       - {"artifact":"tolerances","path":"/rows/4/3","range":{"min":0,"max":1e-12}}
//|       - {"artifact":"tolerances","path":"/rows/4/5","equals":"HeuristicToleranceReached"}
use scioxide_core::{ErrorTolerance, NormSelection, RealScalar};
use scioxide_integrate::{
    DoubleExponentialDomain, DoubleExponentialIntegrator, DoubleExponentialPoint, LevelOptions,
};
use scioxide_poly::OrthogonalFamily;

let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let read = |name: &str| solve[name].as_f64().ok_or(format!("{name} がない"));
let (n, k, q) = (
    read("level")? as usize,
    read("power")? as usize,
    read("wavenumber")?,
);
let curve = |name: &str| -> Result<Vec<[f64; 2]>, String> {
    serde_json::from_value(solve[name].clone()).map_err(|e| e.to_string())
};
let moment = ladder_moment(n, k);
let laguerre = OrthogonalFamily::Laguerre
    .evaluate(n, q * q / 2.0)
    .map_err(|e| e.to_string())?;
let cosine = RealScalar::exp(-q * q / 4.0) * laguerre;
let h0 = 1.0 / RealScalar::sqrt(RealScalar::sqrt(<f64 as RealScalar>::PI));
// 重みを含む被積分関数 [ψ_n² ξ^{2k}, ψ_n² cos qξ]。
let state = |point: DoubleExponentialPoint<f64>| {
    let xi = point.coordinate();
    let psi = hermite_recurrence(n, xi, h0 * RealScalar::exp(-xi * xi / 2.0));
    // 遠方で ψ_0 が 0 に落ちたら被積分関数も 0 とし、ξ^{2k} のあふれを避ける。
    if psi == 0.0 {
        return Ok([0.0; 2]);
    }
    Ok([
        psi * psi * RealScalar::powi(xi, 2 * k as i32),
        psi * psi * RealScalar::cos(q * xi),
    ])
};
let (mut moment_points, mut cosine_points, mut rows) = (Vec::new(), Vec::new(), Vec::new());
for exponent in [4, 6, 8, 10, 12, 14] {
    let tolerance = 10.0_f64.powi(-exponent);
    let tolerance = ErrorTolerance::scalar(tolerance, tolerance, NormSelection::Infinity)
        .map_err(|e| e.to_string())?;
    let options = LevelOptions::default().with_tolerance(tolerance);
    let de = DoubleExponentialIntegrator::new(DoubleExponentialDomain::RealLine, options)
        .map_err(|e| e.to_string())?;
    let (value, report): ([f64; 2], _) = de.integrate(&state).map_err(|e| e.to_string())?;
    let evaluations = report.evaluations() as f64;
    let errors = [
        (value[0] - moment).abs() / moment,
        (value[1] - cosine).abs(),
    ];
    // 誤差が 0 の点は対数軸に描けないので除く（表には残す）。
    if errors[0] > 0.0 {
        moment_points.push([evaluations, errors[0]]);
    }
    if errors[1] > 0.0 {
        cosine_points.push([evaluations, errors[1]]);
    }
    let status = report.termination().to_string();
    rows.push((
        exponent,
        report.evaluations(),
        errors[0],
        errors[1],
        report.error_estimate(),
        status,
    ));
}
let series = |name: &str, points: Vec<[f64; 2]>, symbol: &str, dashed: bool| {
    let line = if dashed { "dashed" } else { "solid" };
    serde_json::json!({
        "name": name,
        "points": points,
        "style": { "symbol": symbol, "lineType": line }
    })
};
emit_line_chart!(
    &vec![
        series(
            "Gauss–Hermite ⟨ξ^{2k}⟩",
            curve("moment_curve")?,
            "circle",
            false
        ),
        series(
            "Gauss–Hermite ⟨cos qξ⟩",
            curve("cosine_curve")?,
            "triangle",
            false
        ),
        series("二重指数変換 ⟨ξ^{2k}⟩", moment_points, "circle", true),
        series("二重指数変換 ⟨cos qξ⟩", cosine_points, "triangle", true),
    ],
    options = &serde_json::json!({
        "xLabel": "評価回数 [回]",
        "yLabel": "誤差（⟨ξ^{2k}⟩ は相対、⟨cos qξ⟩ は絶対）[-]",
        "xType": "log",
        "yType": "log"
    })
);
let columns = serde_json::json!([
    { "key": "0", "label": "許容誤差の指数 p（10⁻ᵖ）", "type": "integer" },
    { "key": "1", "label": "評価回数 [回]", "type": "integer" },
    { "key": "2", "label": "⟨ξ^{2k}⟩ の相対誤差 [-]", "type": "number", "format": sci3 },
    { "key": "3", "label": "⟨cos qξ⟩ の絶対誤差 [-]", "type": "number", "format": sci3 },
    { "key": "4", "label": "誤差推定 [-]", "type": "number", "format": sci3, "nullText": "なし" },
    { "key": "5", "label": "終了状態" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "tolerances" })
);
```

既定の入力（$n = 4$、$k = 2$、$q = 3$）では、許容誤差 $10^{-4}$ の 131 回の評価で、両方の成分の誤差がすでに $2\times10^{-13}$ 以下になる。
誤差推定は $6\times10^{-5}$ で、実際の誤差より 8 桁大きい。
二重指数変換の誤差推定は前の段との差に基づくので、収束が速いほど、一段前の粗い和の誤差を返すことになる。
許容誤差 $10^{-6}$ から $10^{-12}$ では 259 回で止まり、$\langle\xi^{2k}\rangle$ の誤差は 0 になる（対数軸には描かず、表に残す）。
$10^{-14}$ を要求すると、`Stagnation` で止まり、515 回を使う。
誤差推定の丸めの下限 $50\varepsilon A$（$A$ は $|f|$ の和で、ここでは約 30.75）は $3.4\times10^{-13}$ で、要求 $10^{-14}(1 + |Q|) \approx 3.2\times10^{-13}$ を上回るからである。
この結果は成功ではないが、返された値は前の段と同じ精度を持つ。

同じ精度に Gauss–Hermite 則が使う評価回数は、$\langle\xi^{2k}\rangle$ では $n + k + 1 = 7$ 回、$\langle\cos 3\xi\rangle$ では約 25 回である。
重み $e^{-\xi^2}$ が既知で、残りの因子が多項式か整関数であるときは、重みを則に組み込むほうが少ない評価で済み、評価回数は多項式のモーメントで約 20 分の 1（7 回と 131 回）、$\langle\cos 3\xi\rangle$ で約 5 分の 1（約 25 回と 131 回）になる。
一方、二重指数変換は誤差推定を返し、重みの形を知らなくても使える。
被積分関数の形が分からないときや、Gauss–Hermite 則の結果を独立に確かめたいときに使い分ける。

## 四次の非調和項による準位のずれ

実際の分子の振動では、ポテンシャルが放物線からずれる。
無次元の位置で四次の項を加えたハミルトニアン

$$
H = H_0 + \lambda\,\hbar\omega\,\xi^4
$$

を考える（$\lambda$ は無次元の結合定数）。
Rayleigh–Schrödinger 摂動論の一次では、準位のずれは摂動の期待値

$$
E_n^{(1)} = \lambda\,\langle\xi^4\rangle_n = \tfrac34\,\lambda\,(2n^2 + 2n + 1)
$$

である（$\hbar\omega$ 単位）。
二次の補正は $\xi^4$ が $|n\rangle$ を $|n \pm 2\rangle$、$|n \pm 4\rangle$ に移す行列要素 $c_m = \langle m|\xi^4|n\rangle$ から

$$
E_n^{(2)} = \sum_{m \ne n} \frac{\lambda^2 c_m^2}{E_n^{(0)} - E_m^{(0)}} = -\lambda^2\sum_{m \ne n}\frac{c_m^2}{m - n} = -\frac{\lambda^2}{8}\,(34n^3 + 51n^2 + 59n + 21)
$$

となる。
一次の補正は $n^2$、二次の補正は $n^3$ で増えるので、比 $|E_n^{(2)}/E_n^{(1)}|$ はおよそ $\lambda n$ に比例して大きくなる。
この比が 1 に近づく準位では、摂動級数の最初の数項で準位を表せない。

次のセルは $n = 0, 1, \dots, n_{\max}$ について、$N = n + 3$ 点の Gauss–Hermite 則で $\langle\xi^2\rangle_n$ と $\langle\xi^4\rangle_n$ を求める。
被積分多項式 $h_n^2\xi^4$ の次数は $2n + 4$ なので、$N = n + 3$ は前節の条件 $N \ge n + k + 1$ をちょうど満たす最小の点数である。
求積値は閉形式 $n + \tfrac12$ と $\tfrac34(2n^2 + 2n + 1)$ と照合する。
二次の補正は定義のブロックの `ladder_state(n, 4)` で $c_m$ を作り、上の和から直接計算する。
グラフは非摂動の準位、一次まで、二次までの準位を $n$ に対して描き、表は各準位の値と比 $|E^{(2)}/E^{(1)}|$ を示す。

```rust
//| id: integrate-oscillator-anharmonic-shift
//| ref: integrate-oscillator-anharmonic-shift
//| title: 四次の非調和項による準位の一次補正を Gauss–Hermite 則で求める
//| run: reactive
//| uses: [integrate-oscillator-model]
//| crates: [scioxide-core, scioxide-integrate, scioxide-poly]
//| inputs:
//|   coupling: {"type":"range","label":"結合定数 λ [-]","description":"四次の項 λ ħω ξ⁴ の強さ。","min":0.001,"max":0.2,"step":0.001,"value":0.01}
//|   top_level: {"type":"range","label":"最大の量子数 n_max [-]","description":"表とグラフに並べる準位の数を変える。","min":1,"max":15,"step":1,"value":6}
//| cases:
//|   - {"id":"strong","label":"λ = 0.1","description":"n = 0 でも比が 0.35 になり、n ≥ 3 では二次の補正が一次を上回る。","inputs":{"coupling":0.1}}
//|   - {"id":"many-levels","label":"n_max = 15","description":"λ = 0.01 でも、比は n とともに増えて n = 15 で 0.44 になる。","inputs":{"top_level":15}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"levels","path":"/rows/0/3","approx":{"value":0.75,"rtol":1e-13}}
//|       - {"artifact":"levels","path":"/rows/6/3","approx":{"value":63.75,"rtol":1e-13}}
//|       - {"artifact":"levels","path":"/rows/0/5","approx":{"value":0.5072375,"rtol":1e-12}}
//|       - {"artifact":"levels","path":"/rows/0/6","approx":{"value":0.035,"rtol":1e-10}}
//|       - {"artifact":"check","path":"/rows/0/1","range":{"min":0,"max":1e-13}}
//|   - case: strong
//|     expect:
//|       - {"artifact":"levels","path":"/rows/0/4","approx":{"value":0.575,"rtol":1e-12}}
//|       - {"artifact":"levels","path":"/rows/0/5","approx":{"value":0.54875,"rtol":1e-12}}
//|       - {"artifact":"levels","path":"/rows/3/6","range":{"min":1,"max":1.1}}
//|   - case: many-levels
//|     expect:
//|       - {"artifact":"levels","path":"/rows/15/6","range":{"min":0.43,"max":0.45}}
use scioxide_core::RealScalar;
use scioxide_integrate::{GaussianRulePlan, GaussianSupport};
use scioxide_poly::OrthogonalFamily;

let digits15 = serde_json::json!({ "significantDigits": 15 });
let digits8 = serde_json::json!({ "significantDigits": 8 });
let digits3 = serde_json::json!({ "significantDigits": 3 });
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let (lambda, n_max) = (coupling, top_level as usize);
let h0 = 1.0 / RealScalar::sqrt(RealScalar::sqrt(<f64 as RealScalar>::PI));
let (mut rows, mut unperturbed, mut first, mut second) =
    (Vec::new(), Vec::new(), Vec::new(), Vec::new());
let mut moment_error = 0.0_f64;
for n in 0..=n_max {
    // 次数 2n + 4 の多項式 h_n² ξ⁴ を正確に積分する最小の点数 N = n + 3。
    let plan =
        GaussianRulePlan::new(OrthogonalFamily::HermiteH, n + 3).map_err(|e| e.to_string())?;
    let integrand = |xi: f64| {
        let h = hermite_recurrence(n, xi, h0);
        Ok([h * h * xi * xi, h * h * RealScalar::powi(xi, 4)])
    };
    let (moments, _): ([f64; 2], _) = plan
        .integrate_weighted(&integrand, GaussianSupport::RealLine)
        .map_err(|e| e.to_string())?;
    // 閉形式との相対差（独立検算）。
    let level = n as f64;
    let closed = [
        level + 0.5,
        0.75 * (2.0 * level * level + 2.0 * level + 1.0),
    ];
    for (value, exact) in moments.iter().zip(closed) {
        moment_error = moment_error.max((value - exact).abs() / exact);
    }
    // 二次の補正: c_m = ⟨m|ξ⁴|n⟩ から −λ² Σ_{m≠n} c_m² / (m − n)。
    let couplings = ladder_state(n, 4);
    let sum: f64 = couplings
        .iter()
        .enumerate()
        .filter(|&(m, _)| m != n)
        .map(|(m, c)| c * c / (m as f64 - level))
        .sum();
    let (e0, e1, e2) = (level + 0.5, lambda * moments[1], -lambda * lambda * sum);
    unperturbed.push([level, e0]);
    first.push([level, e0 + e1]);
    second.push([level, e0 + e1 + e2]);
    rows.push((
        n,
        n + 3,
        moments[0],
        moments[1],
        e0 + e1,
        e0 + e1 + e2,
        (e2 / e1).abs(),
    ));
}
emit_line_chart!(
    &vec![
        serde_json::json!({
            "name": "非摂動 n + 1/2",
            "points": unperturbed,
            "style": { "lineType": "dashed" }
        }),
        serde_json::json!({
            "name": "一次まで（Gauss–Hermite）",
            "points": first,
            "style": { "symbol": "circle" }
        }),
        serde_json::json!({ "name": "二次まで", "points": second, "style": { "symbol": "triangle" } }),
    ],
    options = &serde_json::json!({
        "xLabel": "量子数 n [-]",
        "yLabel": "エネルギー E_n [ħω]"
    })
);
let columns = serde_json::json!([
    { "key": "0", "label": "n [-]", "type": "integer" },
    { "key": "1", "label": "点数 N [点]", "type": "integer" },
    { "key": "2", "label": "⟨ξ²⟩ [-]", "type": "number", "format": digits15 },
    { "key": "3", "label": "⟨ξ⁴⟩ [-]", "type": "number", "format": digits15 },
    { "key": "4", "label": "一次まで E [ħω]", "type": "number", "format": digits8 },
    { "key": "5", "label": "二次まで E [ħω]", "type": "number", "format": digits8 },
    { "key": "6", "label": "|E⁽²⁾/E⁽¹⁾| [-]", "type": "number", "format": digits3 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "levels" })
);
let columns = serde_json::json!([
    { "key": "0", "label": "量" },
    { "key": "1", "label": "値 [-]", "type": "number", "format": sci3 }
]);
emit_table_with_columns!(
    columns,
    vec![("⟨ξ²⟩・⟨ξ⁴⟩ と閉形式の最大相対差", moment_error)],
    metadata = serde_json::json!({ "id": "check" })
);
```

既定値（$\lambda = 0.01$）では、$N = n + 3$ 点の求積値は $\langle\xi^2\rangle_n = n + \tfrac12$ と $\langle\xi^4\rangle_n$ の閉形式に相対差 $10^{-14}$ 程度で一致する。
基底状態の準位は一次まで $0.5075\,\hbar\omega$、二次まで $0.5072375\,\hbar\omega$ で、比 $|E^{(2)}/E^{(1)}|$ は 0.035 である。
行列の対角化で求めた固有値は $0.5072562\,\hbar\omega$ なので、二次までの値の誤差は $2\times10^{-5}$ 程度である。
比は $n$ とともに増え、`many-levels` の場合の $n = 15$ では 0.44 になる。

`strong` の場合（$\lambda = 0.1$）は、基底状態でも一次まで 0.575、二次まで 0.54875 と大きく食い違う。
対角化した固有値は 0.559146 で、どちらの近似とも $10^{-2}$ 程度ずれる。
$n \ge 3$ では比が 1 を超え、二次まで足した準位は $n = 5$ から $n$ とともに下がる。
これは摂動級数の打ち切りが破綻した兆候で、期待値の求積の誤差ではない。
期待値そのものはどの $\lambda$ でも閉形式と丸めの水準で一致している。

## まとめ

調和振動子の固有状態の期待値 $\langle\xi^{2k}\rangle_n$ は、重み $e^{-\xi^2}$ を除くと次数 $2n + 2k$ の多項式の積分になる。
`GaussianRulePlan` に `OrthogonalFamily::HermiteH` を渡し、`integrate_weighted` を `GaussianSupport::RealLine` で呼ぶと、$N \ge n + k + 1$ 点で丸めの水準まで正確になり、$N = n + k$ では不足分 $(n + k)!/(n!\,2^k)$ だけ小さくなる。
Gauss 則の終了状態 `FixedRuleCompleted` は精度を主張しないので、厳密次数が使えない $\langle\cos q\xi\rangle$ のような被積分関数では、点数を増やした差や閉形式、二重指数変換との比較で誤差を確かめる。
被積分関数の $h_n$ は正規化したままの三項漸化式で計算すると、$2^n n!$ のような途中の大きな値を経由しない。
非調和項の一次補正は $\lambda\langle\xi^4\rangle_n$ で、比 $|E^{(2)}/E^{(1)}|$ が 1 に近づく準位では摂動の打ち切りそのものが成り立たない。
