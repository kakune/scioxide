AAA は標本から支持点と重みを選ぶ当てはめで、どこに極ができるかは結果を見るまで分からない。
有理関数を使う方法には分母の形を先に決めて極の位置を制御するものもある。
このページは実軸上の節点から極のない有理補間を作る Floater–Hormann 補間と、一点での Taylor 係数から作る Padé 近似を扱う。
二つは受け取る情報が異なり、前者は標本値、後者は級数の係数を使う。
重心形式の有理関数と極の診断は[有理近似と極の診断](../rational-approximation/)で説明した。

## Floater–Hormann の混合補間

[`FloaterHormannInterpolator`](https://docs.rs/scioxide-interp/0.1.0/scioxide_interp/struct.FloaterHormannInterpolator.html) は、狭義単調増加の実数節点 $x_0 < \dots < x_n$ で標本を補間する有理関数である。
次数 $d$ を選び、連続する $d+1$ 点を通る $d$ 次以下の局所多項式 $p_i$（$i = 0, \dots, n-d$）を次の重みで混ぜ合わせる。

$$
r(x) = \frac{\sum_{i=0}^{n-d} \lambda_i(x)\, p_i(x)}{\sum_{i=0}^{n-d} \lambda_i(x)},
\qquad
\lambda_i(x) = \frac{(-1)^i}{(x - x_i)(x - x_{i+1}) \cdots (x - x_{i+d})}
$$

$x$ が節点 $x_k$ に近づくと、$x_k$ を含む局所多項式の重みだけが発散し、それらの $p_i$ はすべて $x_k$ で $y_k$ をとるので、$r(x_k) = y_k$ となって標本を補間する。
各 $p_i$ が $d$ 次以下の多項式 $f$ を再現するので、$r$ も $d$ 次以下の多項式を再現する。
$d = n$ では局所多項式が一つだけになり、全域多項式補間に一致する。

Floater と Hormann（2007）は、重み $\lambda_i$ の符号が交互に変わることを使って、分母 $\sum_i \lambda_i(x)$ が実軸上で 0 にならず、したがって $r$ が任意の $d$ で実軸上に極を持たないことを示した。
さらに、$d \ge 1$ で $f \in C^{d+2}[x_0, x_n]$ なら、最大節点間隔 $h$ に対して

$$
\max_{x \in [x_0, x_n]} |f(x) - r(x)| = O(h^{d+1})
$$

が成り立つ。
定数は区間の長さと $f^{(d+1)}$、$f^{(d+2)}$ の最大値で決まり、節点の配置には依らない。
$d = 0$ は Berrut の補間で、隣り合う節点間隔の比が有界な場合に誤差は $O(h)$ である。
全域多項式補間と違って、収束の速さは節点の総数ではなく局所多項式の次数 $d$ で決まる。

この有理関数は第二種の重心公式で書け、重みは

$$
w_k = (-1)^{k-d} \sum_{i \in J_k} \prod_{j=i,\, j \ne k}^{i+d} \frac{1}{|x_k - x_j|},
\qquad J_k = \{ i : \max(0, k-d) \le i \le \min(k, n-d) \}
$$

である。
$J_k$ は $x_k$ を含む局所多項式の番号の集合である。
等間隔節点では、Lebesgue 定数が $n$ について対数的にしか増えない一方、$d$ について指数的に増える（Bos ら, 2012）。
$d$ を上げると収束次数は上がるが、標本値の誤差の拡大も大きくなるので、$d$ は小さく保つ。

`FloaterHormannInterpolator::new(nodes, values, degree)` は、節点数を $N = n + 1$ として $0 \le d < N$ を要求し、範囲外の次数は `InvalidInput`（`OutOfRange`）になる。
次数は結果を決める量で中立な既定値がないので、標本と並んで構築関数の引数になる。
節点の分離の判定を変えるときは `with_options(nodes, values, degree, options)` に `SampleOptions` を渡す。
重みは対数の和で桁あふれを避けて $O(Nd^2)$ の処理と $O(N)$ のメモリで作り、最大の絶対値が 1 になるように正規化して `weights()` で返す。
重みが下位桁あふれで 0 になる場合や、節点の間隔が表せない場合は `NumericalInstability` になる。
値は多項式の補間器と同じくアフィン値で渡し、評価は `BarycentricInterpolator` と同じ核で、次数によらず成分ごとに $O(N)$ である。
導関数と積分は提供しない。
実軸上に極がないという性質は複素平面の極を除くものではなく、丸め誤差による悪条件も防がない。

### 等間隔節点での収束次数

次のセルは Runge の関数 $f(x) = 1/(1 + 25x^2)$ を $[-1, 1]$ の等間隔節点で補間し、節点数 $N = 11, 21, \dots, 641$（最大節点間隔 $h = 2/(N-1)$）での最大誤差を測る。
入力は Floater–Hormann の次数 $d$（0〜6）である。
$f$ は実軸上で滑らかだが、複素平面の $\pm i/5$ に極を持ち、等間隔節点の全域多項式補間は節点を増やすと発散する（Runge 現象）。
比較のため、$N \le 41$ では同じ節点の全域多項式補間（`BarycentricInterpolator`）の誤差も示す。
誤差は節点の各区間の中点で、閉形式の $f$ との差の最大として測る。
隣り合う $N$ の誤差の比から観測次数 $\log_2(e_{h}/e_{h/2})$ を求め、理論の $d + 1$ と比べる。
グラフの破線は $N = 161$ の誤差を通る傾き $d + 1$ の参照線である。

```rust
//| id: interp-floater-hormann-convergence
//| ref: interp-floater-hormann-convergence
//| title: 等間隔節点で Floater–Hormann 補間の収束次数を測る
//| run: reactive
//| crates: [scioxide-core, scioxide-interp]
//| inputs:
//|   degree: {"type":"range","label":"Floater–Hormann の次数 d","description":"混ぜ合わせる局所多項式の次数。","min":0,"max":6,"step":1,"value":3}
//| cases:
//|   - {"id":"berrut","label":"d = 0（Berrut）","description":"観測次数が 1 に近づく。","inputs":{"degree":0}}
//|   - {"id":"degree-six","label":"d = 6","description":"観測次数が 7 に近づいたあと、誤差が丸め誤差の水準に達して次数が下がる。","inputs":{"degree":6}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"orders","path":"/rows/6/0","equals":641}
//|       - {"artifact":"orders","path":"/rows/6/2","approx":{"value":1.0147160889317774e-11,"rtol":1e-4}}
//|       - {"artifact":"orders","path":"/rows/6/3","approx":{"value":4.0,"atol":0.1}}
//|       - {"artifact":"orders","path":"/rows/2/4","range":{"min":1e4}}
//|       - {"artifact":"orders","path":"/rows/3/4","equals":null}
//|   - case: berrut
//|     expect:
//|       - {"artifact":"orders","path":"/rows/6/3","approx":{"value":1.0,"atol":0.05}}
//|       - {"artifact":"orders","path":"/rows/6/2","approx":{"value":9.537558412703318e-5,"rtol":1e-6}}
//|   - case: degree-six
//|     expect:
//|       - {"artifact":"orders","path":"/rows/5/3","approx":{"value":7.0,"atol":0.3}}
//|       - {"artifact":"orders","path":"/rows/5/2","range":{"max":1e-14}}
use scioxide_core::RealScalar;
use scioxide_interp::{BarycentricInterpolator, FloaterHormannInterpolator, Univariate};

// Runge の関数 f(x) = 1/(1 + 25x²)。誤差は閉形式との差で測る
let runge = |x: f64| 1.0 / (1.0 + 25.0 * x * x);
let d = degree as usize;
let mut rows = Vec::new();
let (mut fh_curve, mut poly_curve) = (Vec::new(), Vec::new());
let mut previous: Option<f64> = None;
for level in 0..7 {
    let intervals = 10_usize << level;
    let h = 2.0 / intervals as f64;
    let x: Vec<f64> = (0..=intervals)
        .map(|i| -1.0 + 2.0 * i as f64 / intervals as f64)
        .collect();
    let y: Vec<f64> = x.iter().map(|&v| runge(v)).collect();
    // 誤差は各区間の中点で測る
    let probes: Vec<f64> = x.windows(2).map(|w| 0.5 * (w[0] + w[1])).collect();
    let fh =
        FloaterHormannInterpolator::new(x.clone(), y.clone(), d).map_err(|e| e.to_string())?;
    let mut fh_error = 0.0_f64;
    for &t in &probes {
        fh_error = fh_error.max((fh.value_at(t).map_err(|e| e.to_string())? - runge(t)).abs());
    }
    // 全域多項式補間は Runge 現象で発散するので、節点数 41 までに限る
    let poly_error = if x.len() <= 41 {
        let poly = BarycentricInterpolator::new(x.clone(), y).map_err(|e| e.to_string())?;
        let mut error = 0.0_f64;
        for &t in &probes {
            error = error.max((poly.value_at(t).map_err(|e| e.to_string())? - runge(t)).abs());
        }
        poly_curve.push([h, error]);
        Some(error)
    } else {
        None
    };
    // 観測次数 log₂(e_h / e_{h/2})
    let order = previous.map(|coarse| RealScalar::ln(coarse / fh_error) / RealScalar::ln(2.0));
    previous = Some(fh_error);
    fh_curve.push([h, fh_error]);
    rows.push((x.len(), h, fh_error, order, poly_error));
}
// N = 161 の誤差を通る傾き d + 1 の参照線
let [anchor_h, anchor_error] = fh_curve[4];
let reference: Vec<[f64; 2]> = fh_curve
    .iter()
    .map(|&[h, _]| {
        [
            h,
            anchor_error * RealScalar::powi(h / anchor_h, d as i32 + 1),
        ]
    })
    .collect();
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let fixed2 = serde_json::json!({ "fractionDigits": 2 });
let columns = serde_json::json!([
    { "key": "0", "label": "節点数 N", "type": "integer" },
    { "key": "1", "label": "節点間隔 h [-]", "type": "number", "format": sci3 },
    { "key": "2", "label": "Floater–Hormann の最大誤差 [-]", "type": "number", "format": sci3 },
    { "key": "3", "label": "観測次数 [-]", "type": "number", "format": fixed2, "nullText": "—" },
    {
        "key": "4",
        "label": "全域多項式の最大誤差 [-]",
        "type": "number",
        "format": sci3,
        "nullText": "計算しない"
    }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "orders" })
);
emit_line_chart!(
    &vec![
        serde_json::json!({
            "name": format!("Floater–Hormann（d = {d}）"),
            "points": fh_curve,
            "style": {"showSymbol": true}
        }),
        serde_json::json!({
            "name": format!("傾き {} の参照線", d + 1),
            "points": reference,
            "style": {"lineType": "dashed"}
        }),
        serde_json::json!({
            "name": "全域多項式補間",
            "points": poly_curve,
            "style": {"showSymbol": true}
        }),
    ],
    options = &serde_json::json!({
        "xLabel": "最大節点間隔 h [-]",
        "yLabel": "最大誤差 [-]",
        "xType": "log",
        "yType": "log"
    })
);
```

既定の $d = 3$ では、Floater–Hormann の最大誤差は $N = 11$ の $6.42 \times 10^{-2}$ から $N = 641$ の $1.01 \times 10^{-11}$ まで減り、最後の観測次数は 4.02 で理論の 4 に近い。
$N = 21$ から $81$ までの観測次数は 4.6、9.4、6.4 と 4 から外れる。
$h$ が $f$ の変化の幅 $1/5$ と同程度の粗い格子では、誤差がまだ $O(h^{d+1})$ の漸近域に入っていないためである。
同じ節点の全域多項式補間の誤差は $N = 11, 21, 41$ で 1.53、40.0、$5.74 \times 10^{4}$ と増え、等間隔節点で次数を上げると発散する。
$d = 0$ では観測次数が 0.96、0.98、0.99、1.00 と 1 に近づく。
$d = 6$ では $N = 161 \to 321$ の観測次数が 7.19 で理論の 7 に近いが、$N = 641$ では誤差が丸め誤差の水準 $2.2 \times 10^{-16}$ に達し、観測次数は 4.53 に下がる。
観測次数は、打ち切り誤差が丸め誤差より十分大きい範囲でだけ理論と比べられる。

## Taylor 係数からの Padé 近似

[`PadeApproximant`](https://docs.rs/scioxide-interp/0.1.0/scioxide_interp/struct.PadeApproximant.html) は標本値ではなく中心 $z_0$ での Taylor 係数 $c_k$ を昇べき順に受け取る。
$(m, n)$ 型の Padé 近似 $P/Q$ は、$\deg P \le m$、$\deg Q \le n$、$Q(0) = 1$（局所座標 $u = z - z_0$ で）として

$$
Q(u) f(u) - P(u) = O\bigl(u^{m+n+1}\bigr)
$$

を満たす。
未知数は $P$ の $m+1$ 個と $Q$ の $n$ 個（$q_0 = 1$）で、条件は $u^0, \dots, u^{m+n}$ の係数の $m+n+1$ 個なので、数は合う。
$u^k$ の係数を比べると、$k = m+1, \dots, m+n$ の行が $Q$ の係数 $q_1, \dots, q_n$ の $n \times n$ の Toeplitz 系

$$
\sum_{j=1}^{n} q_j\, c_{k-j} = -c_k \qquad (k = m+1, \dots, m+n)
$$

を与え（$k - j < 0$ の係数は 0 とする）、$k = 0, \dots, m$ の行から $P$ の係数 $p_k = \sum_{j=0}^{\min(k,n)} q_j c_{k-j}$ が決まる。
scioxide-interp は係数を最大絶対値で割って尺度をそろえ、この系を SVD で解く。
数値ランクが不足する場合は、打ち切った SVD による最小ノルムの解を使う。
ランクが不足しても系が両立していれば受理し、ランクを返して $P$ と $Q$ の共通因子を残す。
両立しない場合は、使わなかった $n$ 本の条件の残差が `PolynomialApproximationPolicy` の許容誤差を超えるので、`NumericalInstability`（`Breakdown`）になる。
これは、その型の Padé 近似が一致条件をすべては満たせない退化した場合にあたる。

`PadeApproximant::new(coefficients, m, n, center, domain)` は $m + n + 1$ 個以上の係数を要求し、それより後の係数は使わない。
ランクの判定と係数の残差の許容誤差は `PolynomialApproximationPolicy::default()`（ランクは `DimensionScaledEpsilon`、許容誤差は絶対・相対とも $\sqrt{\varepsilon}$）で、別の方針は `with_options(coefficients, m, n, center, domain, policy)` に渡す。
係数が足りなければ `DimensionMismatch`、係数が NaN か無限大なら `NonFinite`、中心が近似域の外なら `DomainError`、$m + n + 1$ が `usize` で表せなければ `SizeOverflow` になる。
構築は $O(n^3 + mn)$ の処理と $O(n^2 + m)$ のメモリを要し、評価は Horner 法で $O(m + n)$ で、確保を行わない。
`coefficient_residual()` は一致条件 $Qf - P$ の $u^{m+n}$ までの係数の最大残差、`denominator_rank()` は分母の系の数値ランク、`rational()` は局所座標の有理関数 $P/Q$ である。
`fit_report()` は常に `Converged` と反復数 1 を返し、特異値比は分母の系のもの（$n = 0$ なら 1）である。
`build(.., policy, scope)` は実行スコープの中で一回の反復を承認してから計算し、承認されなければ `ConvergenceFailure`（`IterationLimit`）になる。
評価は `BarycentricRational` と同じ 1 座標・2 座標の形で行う。
分母が 0 になる点や、分母の計算値の誤差の推定が分母の絶対値以上になる点（計算した分母が 0 でありうる点）は極とみなし、`DomainError` を返す。
中心付近の級数の一致は遠方での近似精度を意味しない。
$e^x$ の Padé 近似の極の位置は[指数関数の Padé 近似](../../../scioxide-poly/examples/pade-exponential-poles/)で、共鳴の極を AAA と閉形式で比べる例は[共鳴の極](../../examples/aaa-resonance-poles/)で扱う。

## 標本と Taylor 係数の使い分けの実験

次のセルは $e^x$ を、5 つの不等間隔の標本 $x = -1, -0.7, -0.1, 0.4, 1$ を使う次数 $d$ の Floater–Hormann 補間と、中心 0 の Taylor 係数を使う $(2,2)$ 型の Padé 近似で表す。
入力は評価位置 $x$ と Floater–Hormann の次数 $d$（0〜4）で、$d = 4$ は全域多項式補間に一致する。
出力は評価位置での各近似の値と `RealScalar::exp` による参照値との差、Padé の係数の診断、$[-1, 1]$ の 201 点での誤差の曲線である。
Padé の閉形式 $(1 + x/2 + x^2/12)/(1 - x/2 + x^2/12)$ を独立な検算として併記する。
どちらも標準形式 `new` で作り、近似域 $[-1, 1]$ の中を `value_at` で評価する。
二つの方法は受け取る情報が異なるので、同じ係数の数での優劣を測る実験ではない。

```rust
//| id: interp-floater-hormann-pade
//| ref: interp-floater-hormann-pade
//| title: 標本からの補間と級数からの近似を比較する
//| run: reactive
//| crates: [scioxide-core, scioxide-interp]
//| inputs:
//|   position: {"type":"range","label":"評価位置 x [-]","min":-1,"max":1,"step":0.05,"value":0.5}
//|   degree: {"type":"range","label":"Floater–Hormann の次数 d","min":0,"max":4,"step":1,"value":2}
//| cases:
//|   - {"id":"berrut","label":"d = 0","description":"Berrut の補間は誤差が大きく、次数 0 の混合の限界が見える。","inputs":{"degree":0}}
//|   - {"id":"near-polynomial","label":"d = 3","description":"5 点で d = 3 の混合は全域多項式補間と一致する。","inputs":{"degree":3}}
//|   - {"id":"endpoint","label":"x = 1","description":"端点は節点なので Floater–Hormann の誤差は 0 になり、Padé の誤差は最大になる。","inputs":{"position":1}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"values","path":"/rows/0/2","approx":{"value":4.649480459325783e-3,"rtol":1e-9}}
//|       - {"artifact":"values","path":"/rows/1/1","approx":{"value":1.6486486486486487,"rtol":1e-14}}
//|       - {"artifact":"values","path":"/rows/1/2","approx":{"value":7.262205147950951e-5,"rtol":1e-9}}
//|       - {"artifact":"values","path":"/rows/1/3","approx":{"value":3.996114173331122e-3,"rtol":1e-9}}
//|       - {"artifact":"pade","path":"/rows/0/0","range":{"max":1e-15}}
//|       - {"artifact":"pade","path":"/rows/0/1","equals":2}
//|       - {"artifact":"pade","path":"/rows/0/2","range":{"max":1e-15}}
//|   - case: berrut
//|     expect:
//|       - {"artifact":"values","path":"/rows/0/3","approx":{"value":0.339452127644821,"rtol":1e-9}}
//|   - case: near-polynomial
//|     expect:
//|       - {"artifact":"values","path":"/rows/0/1","approx":{"value":1.6491947871863581,"rtol":1e-14}}
//|       - {"artifact":"values","path":"/rows/0/3","approx":{"value":1.7995764959852778e-3,"rtol":1e-9}}
//|   - case: endpoint
//|     expect:
//|       - {"artifact":"values","path":"/rows/0/2","range":{"max":1e-15}}
//|       - {"artifact":"values","path":"/rows/1/2","approx":{"value":3.996114173331122e-3,"rtol":1e-9}}
use scioxide_core::{Interval, RealScalar};
use scioxide_interp::{FloaterHormannInterpolator, PadeApproximant, RationalDomain, Univariate};

let nodes = vec![-1.0_f64, -0.7, -0.1, 0.4, 1.0];
let values: Vec<f64> = nodes.iter().map(|&x| RealScalar::exp(x)).collect();
let fh = FloaterHormannInterpolator::new(nodes, values, degree as usize)
    .map_err(|e| e.to_string())?;
let domain = RationalDomain::Real(Interval::new(-1.0, 1.0).map_err(|e| e.to_string())?);
// e^x の Taylor 係数 1, 1, 1/2, 1/6, 1/24 から (2, 2) 型を作る
let pade = PadeApproximant::new(
    &[1.0_f64, 1.0, 0.5, 1.0 / 6.0, 1.0 / 24.0],
    2,
    2,
    0.0,
    domain,
)
.map_err(|e| e.to_string())?;
let first = fh.value_at(position).map_err(|e| e.to_string())?;
let second = pade.value_at(position).map_err(|e| e.to_string())?;
let exact = RealScalar::exp(position);
// 独立な検算: (2, 2) 型 Padé 近似の閉形式を手で代入する
let closed = (1.0 + position / 2.0 + position * position / 12.0)
    / (1.0 - position / 2.0 + position * position / 12.0);
let (mut fh_curve, mut pade_curve, mut omitted) = (Vec::new(), Vec::new(), 0_usize);
let (mut fh_maximum, mut pade_maximum) = (0.0_f64, 0.0_f64);
for i in 0..=200 {
    let x = -1.0 + i as f64 / 100.0;
    let reference = RealScalar::exp(x);
    let errors = [
        (fh.value_at(x).map_err(|e| e.to_string())? - reference).abs(),
        (pade.value_at(x).map_err(|e| e.to_string())? - reference).abs(),
    ];
    fh_maximum = fh_maximum.max(errors[0]);
    pade_maximum = pade_maximum.max(errors[1]);
    // 誤差が 0 の点（節点や中心）は対数軸に描けないので除いて数える
    for (curve, error) in [&mut fh_curve, &mut pade_curve].into_iter().zip(errors) {
        if error > 0.0 {
            curve.push([x, error]);
        } else {
            omitted += 1;
        }
    }
}
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let value_format = serde_json::json!({ "significantDigits": 10 });
let columns = serde_json::json!([
    { "key": "0", "label": "方法" },
    { "key": "1", "label": "値 [-]", "type": "number", "format": value_format },
    { "key": "2", "label": "exp との差 [-]", "type": "number", "format": sci3 },
    { "key": "3", "label": "[−1, 1] の最大誤差 [-]", "type": "number", "format": sci3 }
]);
let rows = vec![
    ("Floater–Hormann", first, (first - exact).abs(), fh_maximum),
    ("Padé (2, 2)", second, (second - exact).abs(), pade_maximum),
];
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "values" })
);
let check_columns = serde_json::json!([
    { "key": "0", "label": "Padé と閉形式の差 [-]", "type": "number", "format": sci3 },
    { "key": "1", "label": "分母の数値ランク", "type": "integer" },
    { "key": "2", "label": "係数の残差 [-]", "type": "number", "format": sci3 },
    { "key": "3", "label": "対数軸から除いた点数", "type": "integer" }
]);
let check = (
    (second - closed).abs(),
    pade.denominator_rank(),
    pade.coefficient_residual(),
    omitted,
);
emit_table_with_columns!(
    check_columns,
    vec![check],
    metadata = serde_json::json!({ "id": "pade" })
);
emit_line_chart!(
    &vec![
        serde_json::json!({"name": format!("Floater–Hormann（d = {degree}）"), "points": fh_curve}),
        serde_json::json!({"name": "Padé (2, 2)", "points": pade_curve}),
    ],
    options = &serde_json::json!({
        "xLabel": "位置 x [-]",
        "yLabel": "e^x に対する絶対誤差 [-]",
        "yType": "log",
        "annotations": [{"kind": "line", "axis": "x", "value": position, "label": "評価位置"}]
    })
);
```

既定の $x = 0.5$、$d = 2$ では、Floater–Hormann の誤差は $4.65 \times 10^{-3}$、Padé の誤差は $7.26 \times 10^{-5}$ である。
Padé と閉形式の差は $2.2 \times 10^{-16}$、分母の数値ランクは 2、係数の残差は $2.1 \times 10^{-17}$ で、構築した近似が閉形式どおりであることを確かめられる。
$[-1, 1]$ 全体での最大誤差は、Floater–Hormann が節点 0.4 と 1 の間の $x = 0.78$ で $1.53 \times 10^{-2}$、Padé が端点 $x = 1$ で $4.00 \times 10^{-3}$ である。
Floater–Hormann の誤差は節点で 0 になって節点の間で山を作り、Padé の誤差は中心 $x = 0$ で 0 になって中心から離れるほど増える。
二つの近似が受け取る情報の違いが、この誤差の形の違いに表れる。
評価位置を $x = 1$ にすると、そこは標本の節点なので Floater–Hormann の差は 0 になり、Padé の差は最大誤差と同じ $4.00 \times 10^{-3}$ になる。

$d$ を 0 から 4 まで上げると、Floater–Hormann の最大誤差は 0.339、$3.01 \times 10^{-2}$、$1.53 \times 10^{-2}$、$1.80 \times 10^{-3}$、$1.80 \times 10^{-3}$ と減る。
$d = 3$ と $d = 4$ の結果が丸め誤差の範囲で一致するのは偶然ではない。
5 点で $d = 3$ のとき、二つの 3 次の局所多項式の重みの比は $\lambda_0 : \lambda_1 = (x - x_4) : -(x - x_0)$ となり、その混合 $[(x - x_4) p_0 - (x - x_0) p_1]/(x_0 - x_4)$ は Neville の漸化式そのものなので、全域多項式補間（$d = 4$）に一致する。
一般に、$N$ 点で $d = N - 2$ の Floater–Hormann 補間は全域多項式補間と一致する。

## まとめ

Floater–Hormann 補間は連続する $d+1$ 点の局所多項式を混ぜ合わせ、任意の $d$ で実軸上に極を持たない補間を作る。
誤差は $d \ge 1$ で $O(h^{d+1})$ で減り、等間隔節点でも全域多項式補間のような発散を起こさないので、等間隔の標本を高精度に補間するときの第一候補になる。
等間隔節点の Lebesgue 定数は $d$ について指数的に増えるので、$d$ は小さな値から選び、次数を変えて結果が安定するかを確かめる。
Padé 近似は中心での Taylor 係数だけから決まり、中心の近くでは高い精度を持つが、遠方の精度は保証しない。
`PadeApproximant` を使うときは `coefficient_residual` と `denominator_rank` で一致条件と分母の系のランクを確かめる。
導関数や積分が必要なら、どちらも提供しないので、区分多項式やスプラインを使う。
