全域補間ではすべての標本を一つの関数で通す。
相異なる $n+1$ 個の節点を通る $n$ 次以下の多項式は一意に定まるが、その多項式をどの形で保存して評価するかによって、準備・更新・評価の計算量と丸め誤差の振る舞いが変わる。
このページは scioxide-interp の全域補間器の構築と使い分けを扱う。
重心公式の導出、補間誤差の剰余項の証明、Lebesgue 定数と Runge 現象は[多項式補間・差商・Chebyshev 節点](../../../scioxide-poly/algorithms/interpolation-and-chebyshev/)で説明しており、ここではその結果を使う。

## 全域補間と節点の選択

節点 $x_0 < x_1 < \dots < x_n$ と標本値 $y_i = f(x_i)$ から、$p_n(x_i) = y_i$ を満たす $n$ 次以下の多項式 $p_n$ を作る。
$f$ が $n+1$ 回連続微分可能なら、誤差は剰余項

$$
f(x) - p_n(x) = \frac{f^{(n+1)}(\xi)}{(n+1)!}\,\omega(x),
\qquad \omega(x) = \prod_{j=0}^{n}(x - x_j)
$$

で表される。
$\xi$ は $x$ と全節点を含む最小の区間の内部の点で、$x$ に依存する。
誤差の大きさは $f$ の高階導関数と、節点の配置だけで決まる節点多項式 $\omega$ の積で決まる。

各標本値を絶対値 $\eta$ 以内で動かすと、補間値は区間の上で最大 $\Lambda_n \eta$ まで動く。
$\Lambda_n$ を Lebesgue 定数と呼び、標本値の誤差が補間で拡大される倍率を表す。
$\Lambda_n$ は等間隔節点では $n$ について指数的に、Chebyshev 節点では対数的に増える。
したがって、次数を上げる前に節点の族を選ぶ。

### 重心補間器の構築

`BarycentricInterpolator::new(x, y)` は、第二種の重心公式

$$
p_n(x) = \frac{\sum_{j=0}^{n} \dfrac{w_j}{x - x_j}\, y_j}{\sum_{j=0}^{n} \dfrac{w_j}{x - x_j}},
\qquad w_j = \frac{1}{\prod_{k \ne j}(x_j - x_k)}
$$

で評価する補間器を作る。
節点 `x` は狭義単調増加でなければならず、並べ替えは呼び出し側が行う。
近すぎる節点も拒否するときは、`with_options(x, y, options)` に `SampleOptions` で節点の分離を渡す。
重み $w_j$ は一般の節点から $O(n^2)$ で計算し、共通の因子で割って保存する。
第二種の重心公式では重みの共通因子が分子と分母で約分されるので、この正規化は値を変えずに桁あふれを避ける。

節点の族が決まっている場合は、値の配列と区間の両端 `lower`、`upper` から、節点と重みを閉形式により $O(n)$ で作る構築関数を使う。

| 構築関数 | 節点（2 点以上） | 端点 | 重み（共通因子を除く） |
|---|---|---|---|
| `from_equispaced(values, lower, upper)` | 等間隔 | 含む | $(-1)^j \binom{n}{j}$ |
| `from_chebyshev_roots(values, lower, upper)` | Chebyshev 多項式 $T_{n+1}$ の零点 | 含まない | $(-1)^j \sin\frac{(2j+1)\pi}{2n+2}$ |
| `from_chebyshev_lobatto(values, lower, upper)` | $T_n$ の極値点（Chebyshev–Lobatto 点） | 含む | $(-1)^j \delta_j$（両端で $\delta_j = 1/2$、他は 1） |

重みの式は区間 $[-1, 1]$ の節点を $\cos$ の順に並べたときのもので（Berrut–Trefethen, 2004）、昇順に並べ替えても符号の共通因子が変わるだけである。
区間 $[\mathrm{lower}, \mathrm{upper}]$ への 1 次変換も重みに共通因子を掛けるだけなので、値は変わらない。

節点は昇順に生成されるので、値もその順に並べる。
値が一つなら、どの族でも区間の中点を節点にする。
値が空の場合、`lower > upper` の場合、2 点以上で区間が一点に縮退して節点が狭義単調増加にならない場合は `InvalidInput` を返す。
端が有限でなければ `NonFinite`、生成した節点や正規化した重みが表せない場合（下位桁あふれで 0 になる場合を含む）は `NumericalInstability` を返す。
等間隔の構築関数は重みの準備を速くするだけで、等間隔の高次補間の悪条件は改善しない。

補間器の評価域は節点の最小値から最大値までである。
Chebyshev 零点の族は指定区間の端点を節点に含まないので、端点まで評価するには `MethodDefined` などの外挿方針を明示する。
`SampleOptions` の節点の分離 `NodeSeparation` は、既定の `Exact` では等しい隣接節点を拒否し、`Tolerant(tol)` では隣接節点の間隔が $\tau_{\mathrm{abs}} + \tau_{\mathrm{rel}}\max(|x_i|,|x_{i+1}|)$ 以下の場合も拒否する。
同じ分離の範囲で節点に一致する問い合わせには、その節点の標本値を返す。
近すぎる節点を拒否するのは悪条件な入力を避けるための検査であり、受理した入力での精度を保証するものではない。

値は実数、複素数、配列、ベクトルのような同じ形の `AffineValue` で渡す。
節点ごとに成分を並べて保存し、どの実数成分も同じ核で評価するので、各成分の結果はその成分だけのスカラー補間と一致する。
一点の評価は成分数を $d$ として $O(nd)$ で、確保を行わない。
評価では問い合わせ点に最も近い節点の項を基準にして和を取り、その節点の標本値を先に引いておくので、節点の近くでも精度を保つ。
和は補償和で計算し、項が桁あふれか下位桁あふれを起こす場合は、指数の範囲を広げた計算で和全体を計算し直す。
`evaluate_with_derivative` は値と 1 階導関数を一度の走査で計算して組で返し、`evaluate_with_derivative_into` は同じ計算を呼び出し側の出力と作業領域へ書く。
`Differentiable::gradient` と `derivative_at` は導関数だけを返す。
`Clamp` で領域の外を問い合わせた場合、その軸の導関数は 0 になる。
全域多項式の補間器は一回ごとの積分 `Integrable` を実装しない。
定積分には `prepare_antiderivative()` で原始関数を一度準備し（$O(n^2 d)$ の処理と $O(nd)$ のメモリ）、その問い合わせを $O(nd)$ で繰り返す。

## Newton 差商形式と節点の逐次追加

測定やシミュレーションの進行に合わせて標本点を足していく場合は、Newton 形式が便利である。

$$
p_n(x) = c_0 + c_1 (x - x_0) + c_2 (x - x_0)(x - x_1) + \dots + c_n \prod_{j=0}^{n-1} (x - x_j)
$$

係数 $c_k$ は次の漸化式で定める差商（divided difference）$f[x_0, \dots, x_k]$ に一致する。

$$
f[x_i] = y_i, \quad f[x_i, \dots, x_{i+k}] = \frac{f[x_{i+1}, \dots, x_{i+k}] - f[x_i, \dots, x_{i+k-1}]}{x_{i+k} - x_i}
$$

差商は平均値の性質 $f[x_0,\dots,x_k] = f^{(k)}(\eta)/k!$（$\eta$ は節点を含む最小の区間の点）を持つので、係数の大きさから高階導関数の大きさの目安が得られる。
`NewtonInterpolator::new(x, y)` は狭義単調増加の節点から差商の表を $O(n^2 d)$ で作り、`coefficients()` は節点ごとに成分を並べた差商を返す。
評価は入れ子の積に Horner 法を当てて $O(nd)$ で行い、値だけの問い合わせでは導関数を計算しない。
途中の値が桁あふれか下位桁あふれを起こす場合は、指数の範囲を広げた計算に切り替える。

新しい節点 $x_{n+1}$ を加えても、既存の係数 $c_0, \dots, c_n$ は変わらない。
新しい係数 $c_{n+1} = f[x_0, \dots, x_{n+1}]$ は、$v = y_{n+1}$ から始めて $v \leftarrow (v - c_k)/(x_{n+1} - x_k)$ を $k = 0, \dots, n$ の順に繰り返すと求まる。
`NewtonInterpolator::insert_point(x, y)` は節点を右端に加えた新しいモデルを返し、元のモデルを変更しない。
加える節点は現在の最後の節点より大きく、構築時の節点の分離（`SampleOptions` の `NodeSeparation`）で最後の節点から分離していなければならない。
新しい係数の計算と既存の状態のコピーは、ともに $O(nd)$ の処理とメモリを要する。
渡した値を新しいモデルの形のひな型として消費するので、値の型に `Clone` は要求しない。
確保の失敗も含めて、すべての失敗は `Result` で返る。
左端や途中に節点を加える操作は提供しないので、その場合は `new` で作り直す。

## Hermite 接触補間

軌道の位置と速度のように、各節点で関数値 $y_i = f(x_i)$ と 1 階導関数 $y_i' = f'(x_i)$ の両方が分かっている場合がある。
Hermite 接触補間は、全 $n+1$ 個の節点で

$$
p(x_i) = y_i, \quad p'(x_i) = y_i' \quad (i = 0, \dots, n)
$$

の $2n + 2$ 個の条件を満たす $2n + 1$ 次以下の多項式を作る。
条件の数と係数の数は等しい。
同次の条件 $p(x_i) = p'(x_i) = 0$ を満たす $2n+1$ 次以下の多項式は重複度 2 の零点を $n+1$ 個、合わせて $2n+2$ 個持つので 0 に限られ、したがって解は一意に存在する。

各節点を二回並べた列 $z = (x_0, x_0, x_1, x_1, \dots)$ に差商の漸化式を当てると、同じ節点どうしの 1 階差商は $0/0$ の形になる。
その極限は $f[x_i, x_i] = \lim_{h \to 0} f[x_i, x_i + h] = f'(x_i)$ なので、そこに導関数の標本 $y_i'$ を入れれば、残りは通常の差商で埋まる。
この差商を合流差商（confluent divided difference）と呼ぶ。
$f$ が $2n+2$ 回連続微分可能なら、誤差は次の式で表される。

$$
f(x) - p(x) = \frac{f^{(2n+2)}(\xi)}{(2n+2)!} \prod_{i=0}^{n} (x - x_i)^2
$$

節点多項式が 2 乗になるので、誤差は節点の上で 0 になるだけでなく、そこで傾きも 0 になる。

[`HermiteInterpolator::new(x, y, dy)`](https://docs.rs/scioxide-interp/0.1.0/scioxide_interp/struct.HermiteInterpolator.html#method.new) はこの二重節点の差商を $O(n^2 d)$ で作り、Newton 形式として $O(nd)$ で評価する。
`dy` は `y` と同じ形の値で、座標についての導関数 $dy/dx$ を物理単位のまま渡す。
温度と熱流束を標本にする場合は、Fourier の法則 $q = -k\,dT/dx$ から $dT/dx = -q/k$ に換算してから渡す。
受け取るのは値と 1 階導関数だけで、2 階以上の導関数の標本は受け取らない。
`Differentiable` を実装し、定積分は `prepare_antiderivative()` で準備する。

### 導関数の標本の効果と点の追加

次のセルは $f(x) = \sin x$ を区間 $[0, \pi]$ の $n$ 個の等間隔節点で補間し、三つの補間を比べる。
このセルでは節点の数を $n$ と書き、上の式の $n+1$ にあたる。
したがって Hermite 補間は $2n$ 個の条件を満たす $2n-1$ 次以下の多項式である。
一つ目は値だけを使う $n$ 点の補間で、1 点の `NewtonInterpolator` から `insert_point` で右端に 1 点ずつ加えて作る。
二つ目は値と導関数 $\cos x_i$ を使う `HermiteInterpolator` である。
三つ目は同じ $2n$ 個の条件を値だけで与える $2n$ 点の等間隔補間で、`from_equispaced` で作る。
入力は節点数 $n$ で、出力は $[0, \pi]$ の 401 点での誤差の最大と剰余項による上界の表、加えた点の検算の表、誤差の曲線である。
$\sin x$ のどの階の導関数も絶対値が 1 以下なので、各方法の誤差は剰余項の節点多項式の最大値を階乗で割った値以下になる。
検算として、`insert_point` で伸ばしたモデルの差商を `new` で一度に作った差商と比べ、Hermite 補間の導関数を節点で $\cos x_i$ と比べる。
標本値と参照値は `RealScalar::sin` と `RealScalar::cos` で計算する。

```rust
//| title: 導関数の標本を使う Hermite 補間と点の追加を確かめる
//| run: reactive
//| crates: [scioxide-core, scioxide-interp]

//|   node_count: {"type":"range","label":"節点数 n","description":"[0, π] の等間隔節点の数。Hermite 補間は 2n 個の条件を使う。","min":2,"max":7,"step":1,"value":3}

//|     expect:
//|       - {"artifact":"errors","path":"/rows/0/2","approx":{"value":1.0,"atol":1e-12}}

let n = node_count as usize;

    (0..count)
        .map(|i| PI * i as f64 / (count - 1) as f64)
        .collect()
};
let x = grid(n);
let y: Vec<f64> = x.iter().map(|&v| RealScalar::sin(v)).collect();
let dy: Vec<f64> = x.iter().map(|&v| RealScalar::cos(v)).collect();
// 1. 値だけの n 点補間を、1 点のモデルから右端に 1 点ずつ加えて作る
let mut grown = NewtonInterpolator::new(vec![x[0]], vec![y[0]]).map_err(|e| e.to_string())?;
for i in 1..n {
    grown = grown.insert_point(x[i], y[i]).map_err(|e| e.to_string())?;
}
// 2. 値と導関数の 2n 個の条件を満たす 2n − 1 次の Hermite 補間
let hermite =
    HermiteInterpolator::new(x.clone(), y.clone(), dy.clone()).map_err(|e| e.to_string())?;
// 3. 同じ 2n 個の条件を値だけで与える 2n 点の等間隔補間
let wide: Vec<f64> = grid(2 * n).iter().map(|&v| RealScalar::sin(v)).collect();
let lagrange =
    BarycentricInterpolator::from_equispaced(wide, 0.0, PI).map_err(|e| e.to_string())?;

// 独立な検算: 剰余項 |f^(k)| ≤ 1 による上界 max|ω|/k! の節点多項式 ω

        (lagrange.value_at(t).map_err(|e| e.to_string())? - exact).abs(),

        maxima[k] = maxima[k].max(errors[k]);

        // 節点では誤差が 0 になり対数軸に描けないので、正の値だけを描く

            curves[k].push([t, errors[k]]);
        }
    }
}

let direct = NewtonInterpolator::new(x.clone(), y).map_err(|e| e.to_string())?;
let mut coefficient_gap = 0.0_f64;
for (a, b) in grown.coefficients().iter().zip(direct.coefficients()) {
    coefficient_gap = coefficient_gap.max((a - b).abs());
}

for (&node, &slope) in x.iter().zip(&dy) {

}

emit_table_with_columns!(
    check_columns,
    vec![(coefficient_gap, slope_gap)],
    metadata = serde_json::json!({ "id": "checks" })
);
let [newton_curve, hermite_curve, lagrange_curve] = curves;
emit_line_chart!(
    &vec![
        serde_json::json!({ "name": "値だけの n 点", "points": newton_curve }),
        serde_json::json!({ "name": "Hermite（2n 条件）", "points": hermite_curve }),
        serde_json::json!({ "name": "値だけの 2n 点", "points": lagrange_curve }),
    ],
    options = &serde_json::json!({
        "xLabel": "位置 x [rad]",
        "yLabel": "sin x に対する絶対誤差 [-]",
        "yType": "log"
    })
);
```

既定の $n = 3$（節点 $0, \pi/2, \pi$）では、値だけの 3 点補間の誤差の最大は $5.60 \times 10^{-2}$、Hermite 補間は $2.79 \times 10^{-3}$、6 点の等間隔補間は $1.31 \times 10^{-3}$ で、どれも剰余項の上界の内側にある。
Hermite 補間の上界は $3.09 \times 10^{-3}$ で、実際の誤差に近い。
Hermite 補間と 6 点補間は同じ数の条件を使うので誤差の桁はそろうが、誤差の曲線の形が違う。
Hermite 補間の誤差は節点の近くで小さく（$x = \pi/2 - 0.2$ で $2.9 \times 10^{-4}$）、節点の間の中央で大きい（$x = \pi/4$ で $2.7 \times 10^{-3}$）。
これは剰余項の節点多項式が $\prod (x - x_i)^2$ で、節点の近くで 2 乗で小さくなるためである。
6 点補間は条件が区間に等間隔に広がるので、$x = \pi/4$ では $3.4 \times 10^{-4}$ と小さいが、最大は端の近くにある。
`insert_point` で伸ばした差商は `new` の差商と $5.6 \times 10^{-17}$ 以内で一致し、Hermite 補間の節点での傾きは $\cos x_i$ と $2.2 \times 10^{-16}$ 以内で一致する。

$n = 2$ では両端の値と傾きだけを使う 3 次 Hermite 補間になり、誤差の最大は $x = \pi/2$ で $0.215$ である。
これは区分 3 次 Hermite 補間（[PCHIP・三次スプライン・Akima](../pchip-and-splines/)）の一区間と同じ形である。
値だけの 2 点補間は直線 $p = 0$ なので、$x = \pi/2$ での誤差は 1 になる。
$n = 7$ では Hermite 補間の誤差は $1.18 \times 10^{-11}$、14 点補間は $1.71 \times 10^{-11}$ まで下がる。
等間隔の 14 点補間は区間の端の近くで誤差が大きくなり、最大誤差では Hermite 補間のほうが小さくなる。

## 近接した節点と重心重み

次のセルは 3 つの節点 $\{0, \delta, 1\}$ で $f(x) = e^x$ を `BarycentricInterpolator` で 2 次補間し、$\delta$ を 0.001 から 0.5 まで動かす。
入力は無次元の節点間隔 $\delta$ で、出力は $[0,1]$ の 241 点での誤差の最大、剰余項による下界と上界、重心重みの絶対値の最大と最小の比、誤差の曲線である。
3 点の重みは $w_0 = 1/\delta$、$w_1 = -1/(\delta(1-\delta))$、$w_2 = 1/(1-\delta)$ なので、絶対値の比はちょうど $1/\delta$ になる。
検算は二つある。
一つは同じ 3 点の差商から手で作った Newton 形式との差で、評価の丸め誤差の大きさを見る。
もう一つは剰余項で、$f''' = e^x$ は $[0,1]$ で $1 \le f'''(\xi) \le e$ を満たすので、誤差は各点で $|\omega(x)|/6$ と $e\,|\omega(x)|/6$ の間に入る。
標本値と参照値は `RealScalar::exp` で計算する。


既定の $\delta = 0.1$ では、$e^x$ との誤差の最大は $3.35 \times 10^{-2}$ で、剰余項の下界 $2.10 \times 10^{-2}$ と上界 $5.72 \times 10^{-2}$ の間にある。
手で作った Newton 形式との差は $1.1 \times 10^{-15}$ で、重心重みの比は $1/\delta = 10$ である。
$\delta = 0.001$ では重みの比が $10^{3}$ に広がり、二つの形式の差も $9.8 \times 10^{-14}$ に増えるが、補間誤差 $3.82 \times 10^{-2}$ に比べれば無視できる。
等間隔の $\delta = 0.5$ では、重みの比は 2、誤差の最大は $1.44 \times 10^{-2}$ である。
入力できるどの $\delta$ でも、誤差の最大は二つの界の間に入る。
誤差の曲線は破線の二つの界の間を通り、その大きさは $|\omega(x)|$ の形、つまり節点の配置で決まる。
近接した節点は重みの比を広げて丸め誤差を増やすが、この例の誤差の大部分は補間そのものの打ち切り誤差である。

## Neville の再帰アルゴリズム

一点 $x$ での補間値だけが必要なら、係数を求めずに Neville のアルゴリズムを使える。
節点の部分集合 $\{x_i, \dots, x_j\}$ を通る $j - i$ 次の補間多項式の $x$ での値を $P_{i, j}$ とすると、次の漸化式が成り立つ。

$$
P_{i, j} = \frac{(x_j - x) P_{i, j-1} + (x - x_i) P_{i+1, j}}{x_j - x_i}, \qquad P_{i,i} = y_i
$$

右辺の二つの多項式は共通の節点 $x_{i+1}, \dots, x_{j-1}$ で一致し、重みが $x = x_i$ と $x = x_j$ でそれぞれ一方だけを残すので、左辺は $x_i, \dots, x_j$ のすべてを通る。
$P_{i,j}$ を $j - i$ の順に並べた三角形の表を Neville の表と呼ぶ。

scioxide-interp は Stoer–Bulirsch と Numerical Recipes の形に従い、表の値の代わりに隣り合う次数の差

$$
C_{m,i} = P_{i,i+m} - P_{i,i+m-1}, \qquad D_{m,i} = P_{i,i+m} - P_{i+1,i+m}
$$

を更新する。
$w = C_{m-1,i+1} - D_{m-1,i}$ とおくと、$C_{m,i} = (x_i - x)\,w/(x_i - x_{i+m})$、$D_{m,i} = (x_{i+m} - x)\,w/(x_i - x_{i+m})$ である。
ある節点の標本から出発し、次数を一つ上げるたびに $C$ か $D$ を一つ足すと、表の中を一本の経路でたどって最後に全節点の補間値に着く。
$C$ を足すと経路の右端に節点が加わり、$D$ を足すと左端に節点が加わる。

出発点は問い合わせ点に最も近い節点である。
節点は昇順なので、二分探索で問い合わせ点を挟む二つの節点を求め、近いほうを選ぶ（距離が等しければ左の節点）。
評価域の外の問い合わせでは近い側の端の節点から出発する。
比べるのはこの二つの節点の距離だけで、座標が極端に大きく一方の距離が桁あふれしても、順位は正しく決まる。
経路は表の中央を通るように選ぶ。
各次数で、経路の左に残る未使用の節点が右に残る節点より少なければ $C$ を足して右に伸ばし、そうでなければ $D$ を足して左に伸ばす。
厳密な算術ではどの出発点と経路でも同じ値になるが、近い節点から中央を通ると足し込む補正量が小さく保たれ、丸め誤差が小さくなる。

`NevilleInterpolator::new(nodes, values)` は検査した標本を保持するだけで、表は問い合わせのたびに作る。
一点の評価は $O(n^2 d)$ の処理を要し、作業領域の二つの $O(n)$ の表を使う。
作業領域を渡す `evaluate_into` と `evaluate_with_error_into` は確保を行わない。
問い合わせ点が `NodeSeparation` の意味で節点に一致すれば、表を作らずにその標本値をそのまま返す。
導関数と積分は提供しないので、それらが必要なら重心形式か Newton 形式を使う。
同じ標本で多数の点を評価するなら、一点 $O(nd)$ の `BarycentricInterpolator` のほうが速い。

## Neville の誤差推定と有理外挿

`evaluate_with_error(point, policy)` は、補間値と、各成分の最後の補正量の絶対値を組で返す。
この形は出力と作業領域を呼び出しごとに確保する。
`evaluate_with_error_into(point, policy, value_out, error_out, workspace)` は同じ二つを呼び出し側の出力へ書き、確保を行わない。
最後の補正量は全 $n+1$ 点の補間値と、端の 1 点を除いた $n$ 点の補間値との差である。
除かれるのは、経路が最後に加えた側の端の節点である。
この差は本来 $n-1$ 次の補間の誤差の推定であり、全次数の補間の誤差の推定として使うのは、次数を上げると誤差が速く減るという仮定に基づく。
したがって、推定は誤差の上界ではない。
節点の上と、標本が一つの場合は 0 を返す。
外挿や、近くに特異点がある場合には、推定が実際の誤差を大きく下回ることがある（次のセルで確かめる）。

[`BulirschStoerInterpolator`](https://docs.rs/scioxide-interp/0.1.0/scioxide_interp/struct.BulirschStoerInterpolator.html) は、同じ形の表と同じ出発点・経路で、多項式の代わりに対角有理関数を補間する。
$N$ 個の標本からは、分子と分母の次数の差が 1 以下の有理関数、つまり分子が $\lfloor (N-1)/2 \rfloor$ 次、分母が $\lceil (N-1)/2 \rceil$ 次の有理関数が作られる。
次数は標本数で決まるので、構築関数は分子・分母の次数を引数に取らない。
表の更新は Stoer–Bulirsch の有理補間の漸化式で、$r = (x - x_i)/(x - x_{i+m})$、$t = r\,D_{m-1,i}$ とおくと

$$
\phi = \frac{C_{m-1,i+1} - D_{m-1,i}}{t - C_{m-1,i+1}}, \qquad
D_{m,i} = C_{m-1,i+1}\,\phi, \qquad C_{m,i} = t\,\phi
$$

である。
有理関数は分母の零点として極を表せるので、極や漸近線に近い関数を多項式より少ない標本で近似できることがある。
Bulirsch と Stoer は刻み幅 $h$ に対する数値解の列を $h \to 0$ へ外挿するためにこの有理補間を使った。
同じ使い方をする場合、$h = 0$ は節点の範囲の外なので、`MethodDefined` か `BoundedContinue` を明示して外挿する。

表の更新は標本に対して非線形で、各実数成分が独自の表を持つ。
一点の評価は $O(n^2 d)$ で、作業領域を渡せば確保を行わない。
導関数と積分は提供しない。
更新の分母 $t - C_{m-1,i+1}$ が 0 になる場合（問い合わせ点が有理補間の極に当たる場合や、その次数の有理補間が存在しない場合）は、`NumericalInstability`（`Breakdown`）のエラーになる。
節点の分離が既定の `Exact` なら厳密に 0 の場合だけを、`Tolerant` なら引き算する二つの量の大きい方の絶対値を尺度とした許容誤差以下の場合を 0 とみなす。
二つの入力 $C_{m-1,i+1}$ と $D_{m-1,i}$ がともに 0（局所的に定数の標本）の場合は、$0/0$ を避けて新しい補正量を 0 とする。
例えば $(0,1), (1,-1), (2,1)$ を通る $(1,1)$ 型の有理関数 $(a + bx)/(1 + cx)$ を求めると、$x = 0$ と $x = 2$ の条件から $a = 1$、$b = c$ となり、$r$ は定数 1 になる。
$b = c = -1$ としても $(1-x)/(1-x)$ に退化するだけで、$x = 1$ で値 $-1$ をとれない。
この有理補間は存在しないので、$x = 0.5$ での評価は 1 次の段で分母が 0 になり、このエラーになる。
有理関数だからといって外挿が安全になるわけではなく、区間の中に極が入れば連続性も失われる。
標本から極の位置と留数を推定する目的には、[有理近似](../rational-approximation/)の `aaa` と診断を使う。

## Neville の推定と有理補間の比較

次のセルは $f(x) = \tan x$ を区間 $[0, 1.4]$ の $n$ 個の等間隔節点（$n = 2, \dots, 16$）で補間し、問い合わせ点 $x$ での三つの量を比べる。
一つは `NevilleInterpolator` の実際の誤差、一つは `evaluate_with_error` が返す推定、一つは `BulirschStoerInterpolator` の実際の誤差である。
$\tan x$ は $x = \pi/2 \approx 1.571$ に極を持ち、区間の右端から 0.17 しか離れていない。

```rust
    BulirschStoerInterpolator, ExtrapolationPolicy, Interpolant, NevilleInterpolator,

// 1.4 を超える問い合わせは多項式・有理関数の表現をそのまま延長する
let policy = ExtrapolationPolicy::MethodDefined;
let exact = RealScalar::tan(query);
let (mut actual, mut estimated, mut rational) = (Vec::new(), Vec::new(), Vec::new());
let mut rows = Vec::new();
let mut omitted = 0_usize;
for n in 2..=16_usize {
    let x: Vec<f64> = (0..n).map(|i| 1.4 * i as f64 / (n - 1) as f64).collect();
    let y: Vec<f64> = x.iter().map(|&v| RealScalar::tan(v)).collect();
    let neville = NevilleInterpolator::new(x.clone(), y.clone()).map_err(|e| e.to_string())?;
    // 値と誤差の推定を一度の表の計算で受け取る
    let (value, estimate) = neville
        .evaluate_with_error([query], policy)
        .map_err(|e| e.to_string())?;
    let ratio = BulirschStoerInterpolator::new(x, y)
        .map_err(|e| e.to_string())?
        .evaluate([query], policy)
        .map_err(|e| e.to_string())?;
    let (error, rational_error) = ((value - exact).abs(), (ratio - exact).abs());
    for (series, quantity) in [
        (&mut actual, error),
        (&mut estimated, estimate),
        (&mut rational, rational_error),
    ] {
        if quantity > 0.0 {
            series.push([n as f64, quantity]);
        } else {
            omitted += 1;
        }
    }
    if n % 4 == 0 {
        rows.push((n, error, estimate, rational_error));
    }
}
```

既定の $x = 1.3$ では、$n = 8$ で Neville の実際の誤差が $7.32 \times 10^{-2}$、推定が $1.52 \times 10^{-2}$ で、推定は実際の誤差の 5 分の 1 ほどである。
$n = 12$ では実際の誤差 $3.20 \times 10^{-3}$ に対して推定は $8.66 \times 10^{-3}$ で、今度は大きめになる。
同じ点で Bulirsch–Stoer の誤差は $n = 8$ で $1.42 \times 10^{-6}$、$n = 12$ で $2.17 \times 10^{-12}$ と速く減り、極を分母で表せる有理関数の利点が表れる。
$x = 1.5$ の外挿では、$n = 16$ でも Neville の実際の誤差が 1.61 あるのに推定は $7.60 \times 10^{-2}$ にとどまり、推定は実際の誤差の 20 分の 1 より小さい。
Bulirsch–Stoer の外挿誤差は $n = 16$ で $4.62 \times 10^{-12}$ だが、これは区間の近くにある $\tan$ の極が一つだけで、低次の分母で表しやすいためであり、外挿の精度を一般に保証するものではない。
極から離れた $x = 0.7$ では、$n = 8$ で Neville の実際の誤差 $1.86 \times 10^{-3}$ に対して推定は $2.31 \times 10^{-3}$ で、推定は実際の誤差の 1.24 倍とよく合う。
この点では極までの距離が節点の間隔に比べて大きく、次数を上げるたびに誤差がほぼ一定の割合で減るので、推定の前提が成り立つ。
$x = 0$ は全節点に共通の節点なので、すべての誤差が 0 になり、グラフには何も描かれない。

## まとめ

全域補間では次数を上げる前に節点の族を選び、Chebyshev 節点なら `from_chebyshev_roots` か `from_chebyshev_lobatto` で重みを $O(n)$ で作る。
一般の節点は狭義単調増加に並べて `BarycentricInterpolator::new` に渡し、値と導関数を同時に読むなら `evaluate_with_derivative`（確保しないなら `evaluate_with_derivative_into`）、定積分を繰り返すなら `prepare_antiderivative` を使う。
右端に標本を足していくなら `NewtonInterpolator::insert_point`、導関数の標本があるなら `HermiteInterpolator` を選び、Hermite の誤差は節点の近くで 2 乗で小さくなることを踏まえて節点を置く。
Neville の推定は誤差の上界ではなく、外挿や特異点の近くでは実際の誤差を大きく下回りうるので、独立な点での検算と併せて読む。
極に近い関数の補間や刻み幅の外挿には `BulirschStoerInterpolator` が使えるが、極に当たると `Breakdown` のエラーになる。
