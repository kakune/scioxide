2 次元の標本から曲面を作る方法は、標本の配置で大きく分かれる。
標本が直交する格子の上に並んでいれば、格子の各セルで閉じた局所的な補間を使える。
観測点のように座標が散らばっていれば、距離だけで決まる核を重ねる放射基底関数（RBF）か、[Delaunay 分割に基づく補間](../scattered-tessellations/)を使う。
このページでは双線形補間、双3次のパッチ、RBF の核行列と条件数を順に扱う。

## 長方形格子と双線形補間

$x$ 軸の節点 $x_0<x_1<\dots<x_{n_x-1}$ と $y$ 軸の節点 $y_0<\dots<y_{n_y-1}$ の直積格子に値があるとする。
節点の間隔は等しくなくてよい。
問い合わせ点 $(x,y)$ を含むセル $[x_i,x_{i+1}]\times[y_j,y_{j+1}]$ は、各軸の二分探索で $O(\log n_x+\log n_y)$ の手間で見つかる。

セル内の局所座標

$$
u=\frac{x-x_i}{x_{i+1}-x_i},\qquad v=\frac{y-y_j}{y_{j+1}-y_j}\qquad(0\le u,v\le1)
$$

を使うと、双線形補間は四隅の値 $z_{00},z_{10},z_{01},z_{11}$（添字の1つ目が $x$、2つ目が $y$ の向きのずれ）の

$$
z(u,v)=(1-u)(1-v)z_{00}+u(1-v)z_{10}+(1-u)vz_{01}+uvz_{11}
$$

である。
四つの重みは非負で和が 1 なので、セル内の値は四隅の値の凸結合になり、四隅の最小値と最大値の範囲を出ない。
曲面はセルの境界で連続（$C^0$ 級）だが、境界をまたぐと1階偏導関数が一般に跳ぶ。
各セルの曲面は $uv$ の項を持つので、平面ではなく双曲放物面になる。
滑らかな関数を間隔 $h$ の格子で標本化すると、誤差は $O(h^2)$ である。

`BilinearInterpolator` は `Interpolant` だけを実装し、`Differentiable` を実装しない。
セルの内部では式を形式的に微分できるが、セルの境界で勾配が定まらないからである。

## 双3次 Hermite パッチ

セルの境界をまたいで勾配まで連続にするには、各セルの曲面を双3次の多項式

$$
z(u,v)=\sum_{a=0}^3\sum_{b=0}^3c_{ab}u^av^b=\boldsymbol u^\mathsf T C\boldsymbol v,\qquad
\boldsymbol u=[1,u,u^2,u^3]^\mathsf T,\ \boldsymbol v=[1,v,v^2,v^3]^\mathsf T
$$

で表す。
16 個の係数 $c_{ab}$ は四隅での値 $z$、局所座標の偏導関数 $z_u$ と $z_v$、交差偏導関数 $z_{uv}$ の16個の条件で一意に決まる。
1 次元の3次 Hermite 補間で、$[p(0),p(1),p'(0),p'(1)]$ から係数 $[a_0,a_1,a_2,a_3]$ を作る行列を

$$
B=\begin{bmatrix}
1&0&0&0\\
0&0&1&0\\
-3&3&-2&-1\\
2&-2&1&1
\end{bmatrix}
$$

とすると、係数行列は $C=BMB^\mathsf T$ である。
ここで $M$ は $4\times4$ 行列で、行を $u$ 方向の $[\,\cdot(0),\cdot(1),\partial_u\cdot(0),\partial_u\cdot(1)]$、列を $v$ 方向の同じ並びとして四隅の $z,z_u,z_v,z_{uv}$ を並べる。
局所座標の導関数は物理座標の導関数にセル幅 $h_x=x_{i+1}-x_i$、$h_y=y_{j+1}-y_j$ を掛けたもので、$z_u=h_x\,\partial z/\partial x$、$z_v=h_y\,\partial z/\partial y$、$z_{uv}=h_xh_y\,\partial^2z/\partial x\partial y$ となる。
隣り合うセルは共有する辺で値と、辺に沿う導関数と、辺を横切る導関数を共有する。
節点の物理座標での導関数はどのセルから見ても同じ値なので、曲面は $C^1$ 級になる。

格子には節点の導関数がないので、`BicubicInterpolator::new` は各軸の連続する3節点を通る2次式の導関数でこれを推定する。
内部の節点ではその節点を中心とする3節点、端の節点では内側へずらした3節点を使うので、不等間隔でも2次式の導関数は正確に出る。
節点が2個しかない軸では割線の傾きを使う。
交差偏導関数は二つの軸の推定を組み合わせたテンソル積で作る。
このため、各軸の節点が3個以上なら、各軸について2次以下の多項式（$x^2y^2$ を含む双2次の多項式）が丸め誤差の範囲で再現される。
2階導関数はセルの境界で一般に跳ぶので、曲面は全体として $C^2$ 級ではない。
間隔が極端に不揃いだと、推定した導関数が標本の誤差を増幅しうるので、構築の成功は精度の保証ではない。

名前付きの構築関数 `BicubicInterpolator::monotone(x, y, z)` は各軸に沿って単調な格子値から、各軸で単調な $C^1$ 級の曲面を作る。
各実数成分は、各軸に沿う向き（増加・減少）が格子全体で一つに決まっていなければならず、向きが変わる軸があれば `InvalidInput` になる。
値が一定の区間は許され、どこでも一定の軸は増加として扱う。
節点の1階偏導関数は PCHIP の傾きを Bernstein 係数の十分条件で縮めたもので、交差偏導関数は 0 にする。
単調性は境界を含む各セルの全体で丸め誤差の範囲で成り立ち、四隅の値を超える行き過ぎは起こらない。
平面は再現するが、一般の2次式や双線形の関数 $xy$ は再現せず、必要以上に平らな曲面になることがある。
単調性は外挿には及ばない。
節点の分離は常に `NodeSeparation::Exact` で判定し、設定を受け取る形はない。

準備は値の成分ごとに $O(n_xn_y)$ の処理とメモリ（セルあたり16係数）を使う。
問い合わせは $O(\log n_x+\log n_y)$ で、`evaluate_into` などの事前確保済みの形は確保しない。
`BicubicInterpolator` は `Differentiable` と `TwiceDifferentiable` を実装し、勾配と Hessian を物理座標で返す。
Hessian はセルの内部の多項式の2階導関数であり、セルの境界で連続するとは限らない。
`Clamp` で外側に出た軸の導関数は 0 になり、`BoundedContinue` と `MethodDefined` では最も外側のセルの多項式を延長する。

## 格子の値の並び

`BilinearInterpolator::new(x, y, z)` と `BicubicInterpolator::new(x, y, z)` は、二つの座標軸と平坦化した値を受け取る。
節点の分離の判定を変えるときは、それぞれの `with_options(x, y, z, options)` に `SampleOptions` を渡す。
値は $n_y\times n_x$ の行優先で、`z[j * nx + i]` が $(x_i,y_j)$ の値である。
つまり $x$ の添字が先に変わる。
各軸は2個以上の狭義に増加する節点を持たなければならず、満たさなければ `InvalidInput` になる。
値の個数が $n_xn_y$ でなければ `DimensionMismatch` になる。
値は実数・複素数・配列のどれでもよく、各実数成分を同じ規則で補間する。
2 変数のテンソル積 B スプラインの制御値は、最後の軸が最も速く変わる行優先で、`(x, y)` の順の軸なら $y$ の添字が先に変わる。
格子補間とは添字の役割が逆になるので、格子の大きさと成分数を確かめてから渡す。

## 不等間隔格子での再現と導関数

次のセルは各軸に $n$ 個の節点を持つ格子に $f(x,y)=x+2y+x^2y^2$ の値を与え、双線形・双3次・単調双3次の三つの曲面を比べる。
$f$ は各軸に2次で、$[0,1]^2$ の両軸で増加するので、単調な構築も受け付ける。
$x$ 軸の節点は $t_i=i/(n-1)$ に対して $x_i=(1-w)t_i+wt_i^2$ で、$w$ が大きいほど原点の近くに集まる。
$y$ 軸は等間隔である。
$f$ の $x$ と $y$ の役割は対称でないので、値の並びを取り違えると誤差が大きくなる。
出力は $41\times41$ の点での値の最大誤差と、点 $(0.3,0.7)$ での勾配と Hessian の誤差である。
独立な検算として、解析的な勾配 $(1+2xy^2,\ 2+2x^2y)$ と Hessian $\begin{bmatrix}2y^2&4xy\\4xy&2x^2\end{bmatrix}$ を使う。
双3次は双2次の多項式を再現するので、$n\ge3$ のどの格子でも誤差は丸め誤差の程度になるはずである。

```rust
//| id: interp-grid-biquadratic
//| ref: interp-grid-biquadratic
//| title: 不等間隔格子で双線形・双3次・単調双3次の誤差を比べる
//| run: reactive
//| crates: [scioxide-interp]
//| inputs:
//|   nodes: {"type":"range","label":"各軸の節点数 n","min":3,"max":12,"step":1,"value":5}
//|   grading: {"type":"range","label":"x 軸の節点の偏り w [-]","description":"0 で等間隔、1 で xᵢ = tᵢ²。","min":0,"max":1,"step":0.05,"value":0.5}
//| cases:
//|   - {"id":"three-uniform","label":"n = 3、等間隔","description":"各軸 3 節点でも双3次は双2次の多項式を再現し、双線形の誤差は大きい。","inputs":{"nodes":3,"grading":0}}
//|   - {"id":"fine-graded","label":"n = 12、w = 1","description":"節点を増やすと双線形と単調双3次の誤差は減るが、双3次の誤差は丸め誤差のまま変わらない。","inputs":{"nodes":12,"grading":1}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"errors","path":"/rows/0/1","approx":{"value":0.03481406250000019,"rtol":1e-6}}
//|       - {"artifact":"errors","path":"/rows/0/2","equals":null}
//|       - {"artifact":"errors","path":"/rows/1/1","range":{"max":1e-14}}
//|       - {"artifact":"errors","path":"/rows/1/3","range":{"max":1e-12}}
//|       - {"artifact":"errors","path":"/rows/2/1","approx":{"value":0.004335392891359202,"rtol":1e-6}}
//|   - case: three-uniform
//|     expect:
//|       - {"artifact":"errors","path":"/rows/0/1","approx":{"value":0.0806558593750002,"rtol":1e-6}}
//|       - {"artifact":"errors","path":"/rows/1/1","range":{"max":1e-14}}
//|   - case: fine-graded
//|     expect:
//|       - {"artifact":"errors","path":"/rows/1/1","range":{"max":1e-14}}
//|       - {"artifact":"errors","path":"/rows/2/1","approx":{"value":0.0006365129048719886,"rtol":1e-6}}
use scioxide_interp::{
    BicubicInterpolator, BilinearInterpolator, Differentiable, ExtrapolationPolicy,
    Interpolant, TwiceDifferentiable,
};

// f(x, y) = x + 2y + x²y²。各軸に 2 次で、[0, 1]² の両軸で増加する
let f = |x: f64, y: f64| x + 2.0 * y + x * x * y * y;
let n = nodes as usize;
let t = |i: usize| i as f64 / (n - 1) as f64;
// x 軸は tᵢ と tᵢ² を w で混ぜた不等間隔、y 軸は等間隔
let x: Vec<f64> = (0..n)
    .map(|i| (1.0 - grading) * t(i) + grading * t(i) * t(i))
    .collect();
let y: Vec<f64> = (0..n).map(t).collect();
// 値は行優先: z[j * nx + i] = f(x[i], y[j])。x の添字が先に変わる
let z: Vec<f64> = y
    .iter()
    .flat_map(|&yj| x.iter().map(move |&xi| f(xi, yj)))
    .collect();
let bilinear =
    BilinearInterpolator::new(x.clone(), y.clone(), z.clone()).map_err(|e| e.to_string())?;
let bicubic =
    BicubicInterpolator::new(x.clone(), y.clone(), z.clone()).map_err(|e| e.to_string())?;
let monotone = BicubicInterpolator::monotone(x, y, z).map_err(|e| e.to_string())?;
let policy = ExtrapolationPolicy::Reject;
let mut errors = [0.0_f64; 3];
for i in 0..=40 {
    for j in 0..=40 {
        let point = [i as f64 / 40.0, j as f64 / 40.0];
        let exact = f(point[0], point[1]);
        let values = [
            bilinear
                .evaluate(point, policy)
                .map_err(|e| e.to_string())?,
            bicubic.evaluate(point, policy).map_err(|e| e.to_string())?,
            monotone
                .evaluate(point, policy)
                .map_err(|e| e.to_string())?,
        ];
        for (error, value) in errors.iter_mut().zip(values) {
            *error = error.max((value - exact).abs());
        }
    }
}
// 独立な検算: (0.3, 0.7) での解析的な勾配と Hessian（行優先）
let (px, py) = (0.3, 0.7);
let gradient = [1.0 + 2.0 * px * py * py, 2.0 + 2.0 * px * px * py];
let hessian = [2.0 * py * py, 4.0 * px * py, 4.0 * px * py, 2.0 * px * px];
let derivative_errors = |model: &BicubicInterpolator<f64>| -> Result<(f64, f64), String> {
    let g = model
        .gradient([px, py], policy)
        .map_err(|e| e.to_string())?;
    let h = model.hessian([px, py], policy).map_err(|e| e.to_string())?;
    let largest = |m: f64, (a, b): (&f64, f64)| m.max((a - b).abs());
    let gradient_error = g.iter().zip(gradient).fold(0.0, largest);
    Ok((
        gradient_error,
        h.as_flattened().iter().zip(hessian).fold(0.0, largest),
    ))
};
let (cubic_gradient, cubic_hessian) = derivative_errors(&bicubic)?;
let (monotone_gradient, monotone_hessian) = derivative_errors(&monotone)?;
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let columns = serde_json::json!([
    { "key": "0", "label": "方式" },
    { "key": "1", "label": "値の最大誤差 [-]", "type": "number", "format": sci3 },
    {
        "key": "2",
        "label": "勾配の誤差 [-]",
        "type": "number",
        "format": sci3,
        "nullText": "Differentiable なし"
    },
    {
        "key": "3",
        "label": "Hessian の誤差 [-]",
        "type": "number",
        "format": sci3,
        "nullText": "TwiceDifferentiable なし"
    }
]);
let rows = vec![
    ("双線形", errors[0], None, None),
    (
        "双3次",
        errors[1],
        Some(cubic_gradient),
        Some(cubic_hessian),
    ),
    (
        "単調双3次",
        errors[2],
        Some(monotone_gradient),
        Some(monotone_hessian),
    ),
];
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "errors" })
);
```

既定の $n=5$、$w=0.5$ では、双3次の値の最大誤差は $4.4\times10^{-16}$ で、勾配と Hessian の誤差も丸め誤差の程度である。
双線形の値の最大誤差は $3.5\times10^{-2}$、単調双3次は $4.3\times10^{-3}$ である。
単調双3次の Hessian の誤差は 0.37 で、値や勾配の誤差よりずっと大きい。
交差偏導関数を 0 にして傾きを縮める構築は、行き過ぎを防ぐためのもので、2階導関数を合わせることは目的にしていない。
各軸3節点の等間隔格子（`three-uniform`）でも、双3次の誤差は $8.9\times10^{-16}$ のままで、双線形の誤差は $8.1\times10^{-2}$ に増える。
$n=12$、$w=1$（`fine-graded`）では、双線形の誤差は $8.4\times10^{-3}$、単調双3次は $6.4\times10^{-4}$ まで減り、双3次の Hessian の誤差は $1.2\times10^{-14}$ である。
双3次の誤差が節点の数や偏りによらず丸め誤差の程度にとどまることは、$f$ が双2次の多項式の空間に入っていることの帰結であり、一般の関数での精度を示すものではない。

## 放射基底関数による散在点の補間

標本点 $\boldsymbol x_1,\dots,\boldsymbol x_N\in\mathbb R^2$ と値 $y_i$ が格子の構造を持たないとき、補間関数を各標本点を中心とする核 $\phi(r)$ の線形結合

$$
s(\boldsymbol x)=\sum_{j=1}^Nw_j\,\phi(\|\boldsymbol x-\boldsymbol x_j\|_2)
$$

で作る。
補間条件 $s(\boldsymbol x_i)=y_i$ を課すと、重み $\boldsymbol w$ は

$$
K\boldsymbol w=\boldsymbol y,\qquad K_{ij}=\phi(\|\boldsymbol x_i-\boldsymbol x_j\|_2)
$$

の解になる。
$K$ は対称な $N\times N$ の密行列である。

### 核と行列の正則性

`RbfKernel` の核と、核行列 $K$ の性質は次のとおりである。
$r\ge0$ は2点の Euclid 距離で、形状係数 $c$ は有限で正でなければならない。

| 核 | $\phi(r)$ | $K$ の性質（相異なる点） |
| :--- | :--- | :--- |
| `Gaussian(c)` | $\exp(-c^2r^2)$ | 正定値。$C^\infty$ 級で、遠方で速く減衰する |
| `InverseMultiquadric(c)` | $1/\sqrt{1+(cr)^2}$ | 正定値。遠方で $1/(cr)$ のようにゆっくり減衰する |
| `Multiquadric(c)` | $\sqrt{1+(cr)^2}$ | 正則だが不定値（$N\ge2$ で正の固有値が1個、負が $N-1$ 個） |
| `ThinPlateSpline` | $r^2\ln r$（$r=0$ で 0） | 2 次の条件付き正定値。多項式の項がなければ特異になりうる |

正定値の核では、相異なる点に対して $K$ が常に正則である。
Multiquadric の行列も、相異なる点に対して正則であることが知られている（Micchelli, 1986）。
薄板スプラインは1次多項式の項と、重みがその多項式に直交するという条件を加えた系で、標本点が一直線上にないときに初めて解が一意になる。
そのとき解は曲げエネルギー $\int_{\mathbb R^2}(s_{xx}^2+2s_{xy}^2+s_{yy}^2)\,dx\,dy$ を最小にする補間になる。
多項式の項がなければ、例えば互いの距離がすべて 1 の3点では $\ln1=0$ から $K$ が零行列になる。
`RbfInterpolator` は多項式の項を加えず、核行列だけを解く。
したがって薄板スプラインでも1次関数を正確には再現せず、変分の性質も持たない。
多項式の項を加えた RBF が必要なら、近傍ごとに多項式を加える[局所 RBF](oxref:interp-local-samples)を使う。

### 形状係数と条件数

Gaussian と逆 Multiquadric では、形状係数 $c$ が基底の広がり（およそ $1/c$）を決める。
$c$ が大きいと各基底は急に減衰し、$K$ は単位行列に近づいて条件数は 1 に近い。
その代わり、標本点の間で値が 0 へ落ち込み、補間の精度が下がる。
$c$ が小さい（平坦な極限に近い）と、滑らかな関数では多項式補間に近い高い精度が得られることがある。
しかし $K$ の列が互いに似てくるので、条件数は急に大きくなる。
精度と条件数のこの逆向きの関係は、不確定性原理（trade-off principle）と呼ばれる（Schaback, 1995）。
Multiquadric では $c$ を大きくしても $K$ は単位行列に近づかないので、この見方はそのまま当てはまらない。

## RBF の構築と診断

核は結果を決める量なので、設定ではなく標本と並ぶ引数として渡す。
`RbfInterpolator::new(points, values, kernel)` は座標と値を所有し、既定の設定で $K\boldsymbol w=\boldsymbol y$ を解く。
`RbfInterpolator::with_options(points, values, kernel, options)` は `RbfOptions` の設定で、正則化を指定すれば $(K+\lambda I)\boldsymbol w=\boldsymbol y$ を解く。
`build(points, values, kernel, options, scope)` は同じ準備を呼び出し側の実行スコープの中で行い、提案1回として数える。
`new` と `with_options` は呼び出したスレッドで逐次に準備する。

`RbfOptions::new()`（`Default` と同じ）の既定は、正則化なし、`NodeSeparation::Exact`、数値ランクの閾値 `RankThreshold` の絶対・相対とも $\varepsilon$（f64 では $2.2\times10^{-16}$）、逆条件数の下限 0、実行方針 `Auto`、メモリの上限なしである。
各値は失敗しない設定関数で変え、値の検査は構築の最初に行う。
`with_regularization` は `RbfRegularization::None` か、対角に $\lambda$ を加える `Diagonal(lambda)` を受け取り、$\lambda$ は有限で正でなければならない。
`with_node_separation` は点の重複の判定、`with_rank_threshold` は数値ランクの閾値を与える。
`with_minimum_rcond` は受け入れる逆条件数の下限を $[0,1]$ の値で、`with_maximum_bytes` は準備のメモリの見積もりの上限を、`with_execution_policy` は分解に使うワーカーの数を与える。

構築のエラーは次のとおりである。
形状係数、$\lambda$、逆条件数の下限が範囲の外なら `InvalidInput`、非有限なら `NonFinite` になる。
点が空のとき、分離の方針で区別できない点の組があるときは `InvalidInput`、点と値の個数や値の形が合わないときは `DimensionMismatch` になる。
同じ点が二つあると $K$ の二つの行が等しくなって必ず特異になるので、重複は分解の前に入力の誤りとして拒否する。
メモリの見積もりが上限を超えると `ResourceLimit` になり、作業は始まらない。

Gaussian と逆 Multiquadric では Cholesky 分解、Multiquadric と薄板スプラインでは部分ピボット付き LU 分解を使う。
分解が破綻するか、数値ランクと逆条件数の受け入れの判定に通らなければ、特異値分解（SVD）で分解し直す。
SVD では最大特異値 $\sigma_{\max}$ に対して `abs_tol + rel_tol * σ_max` 以下の特異値をランク不足とみなす。
それでもランクが $N$ に満たないか、逆条件数が下限を下回ると `Singular` のエラーになり、打ち切った解は返さない。
準備は $O(N^2)$ のメモリと $O(N^3)$ の処理を使い、値の一回の問い合わせは成分ごとに $O(N)$ で、事前確保済みの形は確保しない。

`conditioning()` が返す `RbfConditioning` は、`matrix_size()`、`numerical_rank()`、`rank_threshold()`、`factorization()`（`FitFactorization`）、`used_fallback()`、`condition_norm()`（`FitConditionNorm`）、`reciprocal_condition_number()` を持つ。
逆条件数は正則化を含めて解いた行列について、採用した因子のノルムで読む。
Cholesky と LU の経路では1ノルムの推定値、SVD の経路では最小特異値と最大特異値の比（2ノルム）であり、1ノルムの値は上界ではない。
$\lambda$ を加えると条件は良くなるが、標本点での一致は緩む。
これは補間ではなく平滑化であり、$\lambda$ は核の値と同じ単位を持つ。

`RbfInterpolator` は `Interpolant<S, 2>` だけを実装し、勾配や積分のトレイトは提供しない。
外挿の判定に使う領域は標本点を囲む座標軸に平行な長方形で、凸包ではない。
長方形の内側でも、標本点から遠い所の値は核の減衰や増大で決まり、精度の保証はない。
核の値は、中間の積が浮動小数点数の範囲を外れても指数の範囲を広げた算術で計算するので、表現できる最終値は非正規化数も含めて返す。

## 形状係数による核行列の変化

次のセルは $x$ 軸上の5点 $\{0,0.2,0.5,0.75,1\}$（$y=0$）で Gaussian 核の行列を作り、形状係数 $c$ による変化を見る。
入力は形状係数 $c$ [1/m] で、座標の単位を m とする。
表の1列目は `RbfKernel::evaluate` と f64 の `exp` で直接計算した参照値 $e^{-(cr)^2}$ との差の最大で、核の実装の独立な検算である。
続く列は値 $\sin(\pi x)$ の補間の構築結果である。
成功すれば数値ランク、因子、逆条件数とそのノルムを示し、`Singular` で失敗すればランクと逆条件数の欄を空にする。
補間はオプション付き形式 `with_options` で作り、`with_rank_threshold` で数値ランクの閾値を相対 $10^{-14}$（絶対 0）にする。
最後の列は標本に使わない4点（各区間の中点）での $\sin(\pi x)$ との最大誤差である。
図は核行列の要素を色で示し、色の範囲は $[0,1]$ に固定する。

```rust
//| ref: interp-rbf-shape-matrix
//| title: Gaussian RBF の形状係数で補間行列を動かす
//| run: reactive
//| crates: [scioxide-core, scioxide-interp]
//| inputs:
//|   shape_parameter: {"type":"range","label":"形状係数 c [1/m]","description":"基底の距離方向の幅を変える。","min":0.01,"max":8,"step":0.01,"value":1.5}
//| cases:
//|   - {"id":"flat","label":"c = 0.5 /m","description":"平坦に近い核では中点の誤差が小さくなる一方、逆条件数は 10⁻⁸ 程度まで下がる。","inputs":{"shape_parameter":0.5}}
//|   - {"id":"fallback","label":"c = 0.07 /m","description":"Cholesky 分解の受け入れの判定に通らず、SVD で分解し直してランク 5 で構築する。","inputs":{"shape_parameter":0.07}}
//|   - {"id":"singular","label":"c = 0.05 /m","description":"数値ランクが 5 を下回り、構築が Singular で止まる。","inputs":{"shape_parameter":0.05}}
//|   - {"id":"narrow","label":"c = 8 /m","description":"行列は単位行列に近いが、標本点の間で値が 0 へ落ち込む。","inputs":{"shape_parameter":8}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"construction","path":"/rows/0/0","range":{"max":1e-15}}
//|       - {"artifact":"construction","path":"/rows/0/1","equals":"成功"}
//|       - {"artifact":"construction","path":"/rows/0/2","equals":5}
//|       - {"artifact":"construction","path":"/rows/0/3","equals":"Cholesky"}
//|       - {"artifact":"construction","path":"/rows/0/4","approx":{"value":4.276266906633815e-4,"rtol":1e-6}}
//|       - {"artifact":"construction","path":"/rows/0/6","approx":{"value":2.111164088090256e-3,"rtol":1e-6}}
//|   - case: flat
//|     expect:
//|       - {"artifact":"construction","path":"/rows/0/4","approx":{"value":6.447990555305157e-8,"rtol":1e-3}}
//|       - {"artifact":"construction","path":"/rows/0/6","approx":{"value":5.077625752578085e-4,"rtol":1e-3}}
//|   - case: fallback
//|     expect:
//|       - {"artifact":"construction","path":"/rows/0/3","equals":"Svd"}
//|       - {"artifact":"construction","path":"/rows/0/5","equals":"Two"}
//|       - {"artifact":"construction","path":"/rows/0/6","approx":{"value":1.0306003338398928e-3,"rtol":1e-3}}
//|   - case: singular
//|     expect:
//|       - {"artifact":"construction","path":"/rows/0/1","equals":"Singular"}
//|       - {"artifact":"construction","path":"/rows/0/4","equals":null}
//|   - case: narrow
//|     expect:
//|       - {"artifact":"construction","path":"/rows/0/4","approx":{"value":0.8514407041576785,"rtol":1e-6}}
//|       - {"artifact":"construction","path":"/rows/0/6","approx":{"value":0.5181426536359379,"rtol":1e-6}}
use scioxide_core::{SciOxideErrorKind, RankThreshold, RealScalar};
use scioxide_interp::{ExtrapolationPolicy, Interpolant, RbfInterpolator, RbfKernel, RbfOptions};

// x 軸上の 5 点（y = 0）。単位は m
let xs = [0.0_f64, 0.2, 0.5, 0.75, 1.0];
let pi = std::f64::consts::PI;
let kernel = RbfKernel::Gaussian(shape_parameter);
let mut matrix = Vec::new();
let mut kernel_gap = 0.0_f64;
for (row, &a) in xs.iter().enumerate() {
    for (column, &b) in xs.iter().enumerate() {
        let value = kernel.evaluate((a - b).abs()).map_err(|e| e.to_string())?;
        // 独立な検算: f64 の exp による参照値 exp(-(c r)^2) と比べる
        let reference = (-(shape_parameter * (a - b)).powi(2)).exp();
        kernel_gap = kernel_gap.max((value - reference).abs());
        matrix.push([column as f64, row as f64, value]);
    }
}
let points: Vec<[f64; 2]> = xs.iter().map(|&x| [x, 0.0]).collect();
let values: Vec<f64> = xs.iter().map(|&x| RealScalar::sin(pi * x)).collect();
// 正則化はせず、相対 1e-14 以下の特異値をランク不足とみなす
let threshold = RankThreshold::new(0.0_f64, 1.0e-14).map_err(|e| e.to_string())?;
let options = RbfOptions::new().with_rank_threshold(threshold);
// 小さい c ではランク不足で Singular になるので、その場合も結果として表に示す
let row = match RbfInterpolator::with_options(points, values, kernel, options) {
    Ok(rbf) => {
        let c = rbf.conditioning();
        let mut error = 0.0_f64;
        for pair in xs.windows(2) {
            let x = 0.5 * (pair[0] + pair[1]);
            let value = rbf
                .evaluate([x, 0.0], ExtrapolationPolicy::Reject)
                .map_err(|e| e.to_string())?;
            error = error.max((value - RealScalar::sin(pi * x)).abs());
        }
        (
            kernel_gap,
            "成功".to_string(),
            Some(c.numerical_rank()),
            Some(format!("{:?}", c.factorization())),
            Some(c.reciprocal_condition_number()),
            Some(format!("{:?}", c.condition_norm())),
            Some(error),
        )
    }
    Err(e) if e.kind() == SciOxideErrorKind::Singular => (
        kernel_gap,
        "Singular".to_string(),
        None,
        None,
        None,
        None,
        None,
    ),
    Err(e) => return Err(e.to_string()),
};

    { "key": "1", "label": "構築" },
    { "key": "2", "label": "数値ランク", "type": "integer", "nullText": "—" },
    { "key": "3", "label": "因子", "nullText": "—" },
    { "key": "4", "label": "逆条件数 [-]", "type": "number", "format": sci3, "nullText": "—" },
    { "key": "5", "label": "ノルム", "nullText": "—" },
    { "key": "6", "label": "中点の最大誤差 [-]", "type": "number", "format": sci3, "nullText": "—" }

    metadata = serde_json::json!({ "id": "construction" })

emit_chart!(

        "kind": "heatmap",
        "data": matrix,
        "xLabel": "基底の中心の添字 j [-]",
        "yLabel": "評価点の添字 i [-]",

        "colorMax": 1.0,
        "tooltip": true,
        "style": {"animation": false}

    })

```

既定の $c=1.5$ では、核の実装と参照値の差は 0 で、補間はランク 5 の Cholesky 分解で構築でき、1ノルムの逆条件数の推定は $4.3\times10^{-4}$ である。
区間の中点での最大誤差は $2.1\times10^{-3}$ になる。
$c=0.5$（`flat`）では図の非対角の要素が 1 に近づき、逆条件数は $6.4\times10^{-8}$ まで下がる一方、中点の誤差は $5.1\times10^{-4}$ に減る。
$c=0.07$（`fallback`）では Cholesky 分解の受け入れの判定に通らず、SVD で分解し直してランク 5 で構築する。
このときの逆条件数は2ノルムの $1.3\times10^{-14}$ で、中点の誤差は $1.0\times10^{-3}$ に戻り、丸め誤差の増幅が平坦な核の利点を打ち消し始める。
$c=0.05$（`singular`）以下では、数値ランクが 5 を下回って構築が `Singular` で止まる。
$c=8$（`narrow`）では行列が単位行列に近づいて逆条件数は 0.85 になるが、中点では核がほぼ 0 まで減衰するので補間値も 0 に近づき、誤差は 0.52 になる。
条件の良さと補間の精度が逆向きに動くことを、逆条件数の列と誤差の列から読み取れる。

## まとめ

双線形補間はセル内の値を四隅の凸結合にして新しい極値を作らないが、勾配は連続でなく `Differentiable` も実装しない。
双3次補間は推定した節点の偏導関数と交差偏導関数から16係数を決め、各軸の2次式を再現する $C^1$ 級の曲面を作る。
単調性が必要なら `BicubicInterpolator::monotone` を使うが、2次式の再現は失われる。
格子の値は `z[j * nx + i]` の行優先で渡し、$x$ と $y$ で役割の違う関数で並びを確かめる。
散在点の RBF は密な核行列を解くので、形状係数で条件数が大きく変わり、`RbfConditioning` の数値ランクと逆条件数で確かめる。
条件が悪いときは形状係数を大きくするか `RbfRegularization::Diagonal` で正則化するが、どちらも精度か標本への一致と引き換えになる。
