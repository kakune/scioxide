計測データ、物性値の表、軌道のモデルでは、標本点の間を区分多項式でつなぎ、大域多項式の Runge 現象を避ける。
区分 3 次式では 2 階導関数の連続（$C^2$）と、データの形（単調性や非負性）の保存とが両立しないことがある。
このページは区分 3 次 Hermite 基底から出発し、単調性を保つ PCHIP（Fritsch–Carlson 条件）、3 次スプラインの三重対角系、局所的な傾きを使う Akima の方法を導く。

## 区分 3 次 Hermite 補間の基底

区間 $[x_i, x_{i+1}]$（幅 $h_i = x_{i+1} - x_i$）の 3 次式 $S_i(x)$ は、無次元座標 $t = (x - x_i)/h_i \in [0, 1]$ を使うと、両端の値 $y_i, y_{i+1}$ と 1 階導関数 $d_i, d_{i+1}$ から一意に決まる。

$$
S_i(x) = h_{00}(t) y_i + h_{10}(t) h_i d_i + h_{01}(t) y_{i+1} + h_{11}(t) h_i d_{i+1}
$$

4 つの 3 次 Hermite 基底多項式は次のとおりである。

$$
\begin{aligned}
h_{00}(t) &= 2t^3 - 3t^2 + 1 = (1 + 2t)(1 - t)^2 \\
h_{10}(t) &= t^3 - 2t^2 + t = t(1 - t)^2 \\
h_{01}(t) &= -2t^3 + 3t^2 = t^2(3 - 2t) \\
h_{11}(t) &= t^3 - t^2 = t^2(t - 1)
\end{aligned}
$$

各基底は $t = 0, 1$ での値と導関数のうち一つだけが 1 で、残りが 0 になる（$h_{00}(0) = 1$、$h_{10}'(0) = 1$ など）。
そのため $S_i$ は両端で値 $y_i, y_{i+1}$ と傾き $d_i, d_{i+1}$ を正確にとる。
隣の区間と節点の値と傾きを共有するので、傾き $d_i$ をどう選んでも曲線全体は $C^1$ になる。
2 階導関数は一般に節点で跳ぶ。
区分 3 次の補間法の違いは節点の傾き $d_i$ の決め方だけである。

scioxide-interp の `PchipInterpolator`、`AkimaInterpolator`、`CubicSpline` は、どれも節点の傾きを準備で計算し、この Hermite 形の区間を共有して評価する。
どれも `new(x, y)` に標本だけを渡して作り、節点の分離の判定を変えるときは `with_options` に `SampleOptions` を渡す。
節点は狭義単調増加で 2 個以上必要で、`slopes()` は節点ごとに成分を並べた物理単位の傾きを返す。
一点の値と導関数は、区間を二分探索で見つけるので $O(\log n)$ の処理を要する。
作業領域を渡す `evaluate_into` などの形は確保を行わず、所有した値を返す `evaluate` や `value_at` は呼び出しごとに作業領域を作る（[準備済みの評価と一括評価](../prepared-evaluation-and-batches/)）。
3 つとも `Differentiable` と `Integrable` を実装し、定義域の中の値・傾き・定積分は `value_at`・`derivative_at`・`integrate` でも求められる。
一回ごとの積分は二分探索に加えて、積分範囲が横切る区間の数に比例する処理を要する。
`CubicSpline` は、定積分を繰り返すための `prepare_antiderivative()` も持つ。
値は複素数・配列・ベクトルでもよく、傾きは実数成分ごとに独立に計算するので、各成分の結果はその成分だけのスカラー補間と一致する。

## PCHIP と Fritsch–Carlson の単調性必要十分条件

データが単調増加（$y_0 \le y_1 \le \dots \le y_n$）のとき、区間の割線の傾きを $\Delta_i = (y_{i+1} - y_i)/h_i \ge 0$ とする。
$\Delta_i = 0$ の区間では、$d_i = d_{i+1} = 0$ のときに限り $S_i$ が単調（定数）になる。
$\Delta_i > 0$ の区間で端の傾きを割線で正規化し、

$$
\alpha_i = \frac{d_i}{\Delta_i}, \qquad \beta_i = \frac{d_{i+1}}{\Delta_i}
$$

とおく。
上の基底を微分すると、正規化した導関数は $t$ の 2 次式

$$
g(t) = \frac{S_i'(x)}{\Delta_i} = 3(\alpha_i + \beta_i - 2)\,t^2 - 2(2\alpha_i + \beta_i - 3)\,t + \alpha_i
$$

になり、$g(0) = \alpha_i$、$g(1) = \beta_i$ である。
したがって単調であるためには $\alpha_i \ge 0$、$\beta_i \ge 0$ が必要である。
そのうえで $g \ge 0$ が $[0, 1]$ で成り立つのは、次のどれかが成り立つときに限る（Fritsch と Carlson, 1980）。

1. $\alpha_i + \beta_i - 2 \le 0$ のとき、$g$ は上に凸か 1 次式なので、最小は端点でとる。
2. $2\alpha_i + \beta_i - 3 \le 0$ または $\alpha_i + 2\beta_i - 3 \le 0$ のとき、$g$ は下に凸だが、頂点 $t^* = (2\alpha_i + \beta_i - 3)/(3(\alpha_i + \beta_i - 2))$ が $[0, 1]$ の外にある。
3. $\phi(\alpha_i, \beta_i) = \alpha_i - \dfrac{(2\alpha_i + \beta_i - 3)^2}{3(\alpha_i + \beta_i - 2)} \ge 0$ のとき、頂点での最小値 $g(t^*) = \phi$ が非負である。

この単調性の領域に含まれる実用的な十分条件として、正方形 $0 \le \alpha_i, \beta_i \le 3$ や、それに含まれる四分円 $\alpha_i^2 + \beta_i^2 \le 9$ がよく使われる。
正方形の角 $\alpha_i = \beta_i = 3$ では $t^* = 1/2$、$\phi = 0$ となり、条件 3 の境界に当たる。

### 単調性の限界の検証

正方形の角を越えると単調性がどう破れるかを、1 区間で確かめる。
次のセルは区間 $[0, 1]$（$y_0 = 0$、$y_1 = 1$、$h = 1$、割線の傾き $\Delta = 1$）で、両端に同じ正規化傾き $s = \alpha = \beta$ を与えた 3 次 Hermite 補間

$$
p(t) = h_{10}(t)\, s + h_{01}(t) + h_{11}(t)\, s
$$

を `HermiteInterpolator::new(x, y, dy)` で作って描く。
$\alpha = \beta = s$ のとき $g(t) = 6(s - 1)t^2 - 6(s - 1)t + s$ で、$s > 1$ なら頂点 $t^* = 1/2$ で最小値 $g(1/2) = (3 - s)/2$ をとり、$s \le 1$ なら端点で最小値 $s$ をとる。
したがって $p'$ の最小値は $\min(s, (3 - s)/2)$ で、$s > 3$ のとき区間の中央で傾きが負になる。
入力は無次元の傾き $s$（0〜6）で、表は $t = 1/2$ での傾き $p'(1/2)$、121 点の格子での $p'$ の最小値、その閉じた形、$p$ の最小と最大、隣り合う格子点の間で値が減った区間の数を示す。
閉じた形は `HermiteInterpolator` を通さない独立な検算である。

```rust

既定の $s = 1$ では曲線は直線 $p(t) = t$ になり、$p'$ は区間全体で 1 である。
$s = 0$ では中央の傾きが 1.5 の S 字形で、$p'$ の最小値は端点の 0 なので単調である。
$s = 3$ は正方形の角で、中央の傾きがちょうど 0 になり、値はまだ減らない。
$s = 6$ では中央の傾きが $-1.5$ と負になり、区間の中で値が上がり、下がり、また上がる。
このとき $p$ は $t = (1 - 1/\sqrt{5})/2 \approx 0.28$ で極大 $0.72$、$t \approx 0.72$ で極小 $0.28$ をとり、120 の格子区間のうち間の 54 区間で値が減る。
それでも値はデータの範囲 $[0, 1]$ に収まるので、範囲からのはみ出しだけを見ても単調性の破れはわからない。
次に述べる PCHIP は内部の傾きを割線の 3 倍以下に抑えるので、このような破れが起きない。

### PCHIP の節点の傾き

[`PchipInterpolator`](https://docs.rs/scioxide-interp/0.1.0/scioxide_interp/struct.PchipInterpolator.html) は、隣り合う割線だけから節点の傾き $d_i$ を決める。

1. 極値と平坦部 隣り合う割線の符号が異なるか、どちらかが 0（$\Delta_{i-1} \Delta_i \le 0$）なら、$x_i$ はデータの極値か平坦部の端なので $d_i = 0$ とする。
2. 重み付き調和平均（Fritsch–Butland の式） 同じ符号（$\Delta_{i-1} \Delta_i > 0$）なら、区間幅で重みを付けた調和平均を使う。

   $$
   d_i = \frac{w_1 + w_2}{\dfrac{w_1}{\Delta_{i-1}} + \dfrac{w_2}{\Delta_i}}, \qquad w_1 = 2h_i + h_{i-1}, \quad w_2 = h_i + 2h_{i-1}
   $$

   左の割線 $\Delta_{i-1}$ には右の区間を 2 倍に数えた重み $w_1$ が付き、右の割線には左の区間を 2 倍に数えた重み $w_2$ が付く。
   分母の一方の項を落とすと $d_i \le (w_1 + w_2)\Delta_{i-1}/w_1 \le 3\Delta_{i-1}$ となり、同様に $d_i \le 3\Delta_i$ なので、$0 < d_i \le 3 \min(\Delta_{i-1}, \Delta_i)$ が成り立つ。
3. 端点 端の 2 区間の割線から、片側 3 点の式 $d_0 = \Delta_0 + \frac{h_0}{h_0 + h_1}(\Delta_0 - \Delta_1)$ を作る。
   その符号が $\Delta_0$ と異なるか $\Delta_0 = 0$ なら $d_0 = 0$ とし、割線の符号が変わる場合（$\Delta_0 \Delta_1 < 0$）は $|d_0| \le 3|\Delta_0|$ に制限する。
   右端も同じ式を $h_{n-1}, h_{n-2}, \Delta_{n-1}, \Delta_{n-2}$ で使う。

2 によって内部の各区間の $\alpha_i, \beta_i$ は 0 以上 3 以下になり、上の正方形に入る。
端点の式も、割線の符号が同じなら $0 \le d_0 < 2\Delta_0$（$\Delta_0 > 0$ のとき）で、符号が変わる場合は制限によって正方形に入る。
したがって、単調な実数データでは各区間で補間も単調になる。
ベクトル値では成分ごとに判定するので、単調な成分ごとに単調性が保たれる。
節点が 2 個なら直線になる。

重みは隣り合う 2 区間の幅の比だけで決まるので、座標を一斉に $c$ 倍すると傾きは $1/c$ 倍になり、正規化した $\alpha_i, \beta_i$ は変わらない。
節点、幅、割線の大きさがおよそ $10^{-152}$ から $10^{152}$ の範囲にあれば、上の式をそのまま計算する。
その外の極端な値では隣り合う 2 つの幅だけを大きい方で割ってから重みを作る。
遠くの節点の大きさで幅を割ると、局所の 2 つの幅がともにアンダーフローして重みの比が失われるからである。

傾きの精度は等間隔の節点で極値から離れた滑らかな単調データなら $O(h^2)$ で、補間の誤差は $O(h^3)$ になる。
割線を $\Delta_{i-1} = f' - h_{i-1} f''/2 + O(h^2)$、$\Delta_i = f' + h_i f''/2 + O(h^2)$ と展開して重み付き調和平均に代入すると、$d_i - f'(x_i) = f''(x_i)(h_i - h_{i-1})/6 + O(h^2)$ を得る。
等間隔なら 1 次の項が消えて $O(h^2)$ が残り、隣の幅の比が 1 から大きく離れる節点では 1 次の項が残る。
極値では傾きを 0 にするので、なめらかなデータでも極値の近くでは曲線が平たくなり、局所的な精度が落ちる。
隣り合う 2 つの割線だけから傾きを決めるので、精度は 3 次スプラインの $O(h^4)$ より一つ低い。

### PCHIP の傾きの検算

次のセルは極大と平坦部を含む 7 点の標本で `PchipInterpolator::slopes()` を上の式の f64 による直接計算と比べる。
標本は $x = (0, 2, 3, 3.5, 5, 6, 8)$、$y = (0, 4, -1, -1, 0.5, 2, 2.4)$ で、上の 3 つの規則のすべての分岐を通る。
$x_1$ は極大なので $d_1 = 0$、$x_2, x_3$ は平坦部の端なので $d_2 = d_3 = 0$、$x_4, x_5$ は重み付き調和平均になる。
左端では割線の符号が変わり（$\Delta_0 = 2$、$\Delta_1 = -5$）、片側 3 点の式の値 $6.67$ が $3\Delta_0 = 6$ に制限される。
右端では式の値が $-0.67$ と $\Delta_5 = 0.2$ の逆符号になるので 0 になる。
入力 $k$ は座標を一斉に $10^k$ 倍し、極端な座標でも傾きの比が保たれることを確かめる。
表の傾きは $10^k$ を掛けて $k = 0$ の座標の単位に戻した値である。
1 つ目の表は節点ごとの傾きと直接計算との差、2 つ目の表は区間ごとの $\alpha_i, \beta_i$ で、平坦な区間（$\Delta_i = 0$）では定義しない。

//|   scale_exponent: {"type":"range","label":"座標の倍率の指数 k（x を 10^k 倍）","description":"節点の座標を一斉に 10^k 倍する。値 y は変えない。","min":-300,"max":300,"step":50,"value":0}

//|       - {"artifact":"slopes","path":"/rows/6/3","equals":0}
//|       - {"artifact":"slopes","path":"/rows/5/5","range":{"max":1e-15}}

//|   - case: huge-coordinates
//|     expect:
//|       - {"artifact":"slopes","path":"/rows/4/3","approx":{"value":1.2162162162162162,"rtol":1e-13}}
//|       - {"artifact":"slopes","path":"/rows/5/3","approx":{"value":0.38571428571428573,"rtol":1e-13}}
//|   - case: tiny-coordinates
//|     expect:
//|       - {"artifact":"slopes","path":"/rows/4/3","approx":{"value":1.2162162162162162,"rtol":1e-13}}
//|       - {"artifact":"slopes","path":"/rows/0/3","approx":{"value":6,"rtol":1e-13}}

use scioxide_interp::PchipInterpolator;

// 極大 (x = 2)、平坦部 [3, 3.5]、増加部を含む標本（k = 0 の座標）
let x0 = [0.0_f64, 2.0, 3.0, 3.5, 5.0, 6.0, 8.0];
let y = [0.0_f64, 4.0, -1.0, -1.0, 0.5, 2.0, 2.4];
let scale = RealScalar::powi(10.0_f64, scale_exponent as i32);
let x: Vec<f64> = x0.iter().map(|&v| v * scale).collect();
let pchip = PchipInterpolator::new(x, y.to_vec()).map_err(|e| e.to_string())?;
// 10^k 倍した座標での傾きに 10^k を掛け、k = 0 の座標の単位に戻す
let slopes: Vec<f64> = pchip.slopes().iter().map(|&d| d * scale).collect();

// 独立な検算: k = 0 の座標で本文の式を f64 で直接計算する
let n = x0.len();
let h: Vec<f64> = x0.windows(2).map(|w| w[1] - w[0]).collect();
let delta: Vec<f64> = (0..n - 1).map(|i| (y[i + 1] - y[i]) / h[i]).collect();
let end_slope = |h1: f64, h2: f64, d1: f64, d2: f64| {
    let d = d1 + h1 / (h1 + h2) * (d1 - d2);
    if d1 == 0.0 || (d > 0.0) != (d1 > 0.0) {
        0.0
    } else if (d1 > 0.0) != (d2 > 0.0) && d.abs() > 3.0 * d1.abs() {
        3.0 * d1
    } else {
        d
    }
};
let mut reference = vec![0.0; n];
for i in 1..n - 1 {
    if delta[i - 1] * delta[i] > 0.0 {
        let w1 = 2.0 * h[i] + h[i - 1];
        let w2 = h[i] + 2.0 * h[i - 1];
        reference[i] = (w1 + w2) / (w1 / delta[i - 1] + w2 / delta[i]);
    }
}
reference[0] = end_slope(h[0], h[1], delta[0], delta[1]);
reference[n - 1] = end_slope(h[n - 2], h[n - 3], delta[n - 2], delta[n - 3]);

let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let fixed4 = serde_json::json!({ "fractionDigits": 4 });
let rows: Vec<(f64, Option<f64>, Option<f64>, f64, f64, f64)> = (0..n)
    .map(|i| {
        let left = (i > 0).then(|| delta[i - 1]);
        let right = (i + 1 < n).then(|| delta[i]);
        let difference = (slopes[i] - reference[i]).abs();
        (x0[i], left, right, slopes[i], reference[i], difference)
    })
    .collect();
let columns = serde_json::json!([
    { "key": "0", "label": "節点 x_i（k = 0） [-]", "type": "number", "format": { "fractionDigits": 1 } },
    { "key": "1", "label": "左の割線 Δ_{i−1} [-]", "type": "number", "format": fixed4, "nullText": "なし" },
    { "key": "2", "label": "右の割線 Δ_i [-]", "type": "number", "format": fixed4, "nullText": "なし" },
    { "key": "3", "label": "slopes() × 10^k [-]", "type": "number", "format": fixed4 },
    { "key": "4", "label": "式による d_i [-]", "type": "number", "format": fixed4 },
    { "key": "5", "label": "差 [-]", "type": "number", "format": sci3 }
]);
emit_table_with_columns!(columns, rows, metadata = serde_json::json!({ "id": "slopes" }));

// 区間ごとの正規化傾き α_i = d_i/Δ_i、β_i = d_{i+1}/Δ_i（Δ_i = 0 では定義しない）
let intervals: Vec<(f64, f64, Option<f64>, Option<f64>)> = (0..n - 1)
    .map(|i| {
        let defined = delta[i] != 0.0;
        let alpha = defined.then(|| slopes[i] / delta[i]);
        let beta = defined.then(|| slopes[i + 1] / delta[i]);
        (x0[i], delta[i], alpha, beta)
    })
    .collect();
let interval_columns = serde_json::json!([
    { "key": "0", "label": "区間の左端 x_i [-]", "type": "number", "format": { "fractionDigits": 1 } },
    { "key": "1", "label": "割線 Δ_i [-]", "type": "number", "format": fixed4 },
    { "key": "2", "label": "α_i [-]", "type": "number", "format": fixed4, "nullText": "平坦" },
    { "key": "3", "label": "β_i [-]", "type": "number", "format": fixed4, "nullText": "平坦" }
]);
emit_table_with_columns!(
    interval_columns,
    intervals,
    metadata = serde_json::json!({ "id": "intervals" })
);
```

既定の $k = 0$ では、7 個の傾きはすべて直接計算と丸め誤差の範囲で一致する。
左端の傾きは制限された $6 = 3\Delta_0$ で、最初の区間の $\alpha_0$ は正方形の辺 $\alpha = 3$ 上にある。
$x_4 = 5$ の傾きは $w_1 = 3.5$、$w_2 = 4$ の調和平均 $7.5/(3.5/1 + 4/1.5) = 1.2162$ である。
どの区間でも $\alpha_i, \beta_i$ は 0 以上 3 以下に入り、各区間の単調性が保たれる。
$k = \pm 300$ にすると幅は $10^{\pm 300}$ 程度になるが、$10^k$ を掛けた傾きと直接計算との差は $9 \times 10^{-16}$ 以下で、$k = 0$ と丸め誤差の範囲で一致する。
傾きは幅の比だけで決まり、極端な座標でも重みの比が失われないことがわかる。

## 3 次スプラインの三重対角方程式と境界条件

3 次スプラインは 2 階導関数まで連続（$C^2$）な区分 3 次式で標本を補間する。
$n$ 区間の 3 次式は $4n$ 個の係数を持ち、各区間の両端での補間が $2n$ 本、内部の $n - 1$ 個の節点での $S'$ と $S''$ の連続が $2(n-1)$ 本の条件を与える。
残る 2 本を両端の境界条件で与える。

節点での 2 階導関数 $M_j = S''(x_j)$ を未知数にとる。
各区間で $S''$ は 1 次式なので

$$
S''_j(x) = M_j \frac{x_{j+1} - x}{h_j} + M_{j+1} \frac{x - x_j}{h_j}
$$

と書ける。
これを 2 回積分して $S_j(x_j) = y_j$、$S_j(x_{j+1}) = y_{j+1}$ から積分定数を決め、内部の節点で $S'_{j-1}(x_j) = S'_j(x_j)$ を課すと、次の三重対角系を得る。

$$
\frac{h_{j-1}}{6} M_{j-1} + \frac{h_{j-1} + h_j}{3} M_j + \frac{h_j}{6} M_{j+1} = \frac{y_{j+1} - y_j}{h_j} - \frac{y_j - y_{j-1}}{h_{j-1}} \quad (j = 1, \dots, n-1)
$$

対角成分 $(h_{j-1} + h_j)/3$ は非対角成分の和 $(h_{j-1} + h_j)/6$ の 2 倍なので、この行は狭義対角優位である。

[`CubicSpline::new(x, y)`](https://docs.rs/scioxide-interp/0.1.0/scioxide_interp/struct.CubicSpline.html#method.new) は not-a-knot の端で 3 次スプラインを作る。
ほかの境界条件は `CubicSpline::with_boundary(x, y, boundary)` に [`SplineBoundary`](https://docs.rs/scioxide-interp/0.1.0/scioxide_interp/enum.SplineBoundary.html) で渡し、節点の分離も変えるときは `with_options(x, y, boundary, options)` を使う。
座標を定義域の半幅で正規化してから系を組むので、節点の絶対値が大きくても系は座標の大きさによらない。
係数行列は節点だけで決まるので一度だけ分解し、値の実数成分ごとに右辺を変えて解く。
分解と各成分の求解は $O(n)$ で、準備の処理は節点数と値の成分数の積に比例する。
解いた $M_j$ を節点の傾きに変換し、上の Hermite 形の区間として保存する。
系が特異なら `Singular`、両端の値が合わない周期データや節点が 2 個未満なら `InvalidInput` になる。

### 境界条件の選び方と誤差

1. `Natural`（自然スプライン）は $M_0 = M_n = 0$ とする。
   梁の両端に曲げモーメントがかからない状態に当たる。
   標本を通り 2 階導関数が 2 乗可積分なすべての関数のうちで、$\int_{x_0}^{x_n} (S''(x))^2 \,dx$ を最小にする（Holladay の定理）。
   ただし、真の関数の端の 2 階導関数が 0 でないと、端の近くの誤差は $O(h^2)$ にとどまる。
2. `Clamped(v0, vn)`（固定端スプライン）は $S'(x_0) = v_0$、$S'(x_n) = v_n$ とする。
   傾きは値と同じ型で、座標あたりの物理単位で渡す。
   熱流束から傾きを決める場合は、熱伝導率で温度勾配に換算する。
   正しい端の傾きを与え $f \in C^4$ なら、$h = \max_j h_j$ に対して $\|f - S\|_\infty \le \frac{5}{384} h^4 \|f^{(4)}\|_\infty$ が成り立つ（Hall と Meyer, 1976）。
3. `NotAKnot` は $x_1$ と $x_{n-1}$ で 3 階導関数も連続にする。
   最初と最後の 2 区間がそれぞれ一つの 3 次式になり、端の情報がない場合に $O(h^4)$ の精度を保つためによく使われる。
   端の未知数を消去すると、系は一般に対角優位でなくなる。
   scioxide-interp は周期以外の境界条件で、隣の行との交換を伴う三重対角 LU 分解（部分ピボット選択）を使う。
4. `Periodic` は始点と終点で値、1 階導関数、2 階導関数を一致させる。
   未知数 $M_0 = M_n$ が両端でつながる巡回三重対角系を解く。
   各成分の両端の値の差が $\sqrt{\varepsilon}\max(|y_0|, |y_n|, 1)$ 以内なら受理し、終端の値を始端の値にそろえてから構築する。
   それより大きく異なれば `InvalidInput`（`OutOfRange`）になる。

どの境界条件も 2 点から使える。
not-a-knot は 2 点で直線、3 点で 3 点を通る放物線になり、周期条件は 2 点で定数になる。
周期条件の 3 点の場合は、2 行の巡回系の解を閉形式で求める。

## Akima の方法と局所的な傾き

Akima（1970）の方法は節点 $x_i$ の周りの 4 つの割線 $m_{i-2}, m_{i-1}, m_i, m_{i+1}$（$m_j$ は区間 $[x_j, x_{j+1}]$ の割線）から傾きを決める。

$$
d_i = \frac{|m_{i+1} - m_i|\, m_{i-1} + |m_{i-1} - m_{i-2}|\, m_i}{|m_{i+1} - m_i| + |m_{i-1} - m_{i-2}|}
$$

左の割線 $m_{i-1}$ の重みは右側の割線の差、右の割線 $m_i$ の重みは左側の割線の差である。
そのため、片側が直線に近いほど、傾きはその側の割線に近づく。
急な変化の影響は近くの節点にとどまり、離れた平坦部に及びにくい。

[`AkimaInterpolator::new(x, y)`](https://docs.rs/scioxide-interp/0.1.0/scioxide_interp/struct.AkimaInterpolator.html#method.new) は上の式そのもの（`AkimaMethod::Akima`）で傾きを決める。
`AkimaInterpolator::with_method(x, y, method)` は `AkimaMethod` で重みを選ぶ。
`AkimaMethod::Makima`（Moler と Ionita による修正 Akima 法）は、重みを

$$
w_1 = |m_{i+1} - m_i| + \frac{|m_{i+1} + m_i|}{2}, \qquad
w_2 = |m_{i-1} - m_{i-2}| + \frac{|m_{i-1} + m_{i-2}|}{2}
$$

とし、$d_i = (w_1 m_{i-1} + w_2 m_i)/(w_1 + w_2)$ とする。
足した項は、同じ傾きの割線が続いて元の重みが両方 0 になる場合にも重みを決め、平坦部の近くでの行き過ぎを抑える。
重みの和が 0 になる場合は隣り合う二つの割線の平均を、隣り合う割線が等しい場合はその値を傾きにする。
両端では割線の列を $m = 2a - b$（$a$ は隣の割線、$b$ はその内側の割線）で 2 つずつ延長してから同じ式を使う。
節点が 2 個なら直線になる。
どちらの方法も一般の単調データで単調性を保証しないので、単調性が必要なら PCHIP を使う。

## 急変するデータでの行き過ぎ

次のセルは 0 が続いたあとに 1 が続く段差の標本（$x = 0, 1, \dots, 7$）を、自然スプライン、not-a-knot スプライン、Akima、Makima、PCHIP で補間する。
not-a-knot スプライン、Akima、PCHIP は `new` で、自然スプラインは `with_boundary` で、Makima は `with_method` で作る。
入力は段差の位置（値が 1 に変わる最初の節点、2〜5）で、出力は各曲線、標本の範囲 $[0, 1]$ を超えた最大量、隣り合う検証点の間で値が減った区間の数である。
検証点は 561 点で、細かい有限個の点で減少が見つからなくても全区間での単調性の証明にはならない。

```rust
//| id: interp-overshoot-comparison
//| ref: interp-overshoot-comparison
//| title: 五つの区分三次補間の行き過ぎを比較する
//| run: reactive
//| crates: [scioxide-interp]
//| inputs:
//|   step: {"type":"range","label":"段差の位置（値が 1 になる最初の節点）","min":2.0,"max":5.0,"step":1.0,"value":3.0}
//| cases:
//|   - {"id":"short-left-plateau","label":"位置 2","description":"左の平坦部が 2 点だけになり、Akima と Makima も行き過ぎる。","inputs":{"step":2}}
//|   - {"id":"mirrored","label":"位置 5","description":"左右に反転すると位置 3 と同じ標本になり、同じ値が出る。","inputs":{"step":5}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"overshoot","path":"/rows/0/1","approx":{"value":0.10938216235292858,"rtol":1e-9}}
//|       - {"artifact":"overshoot","path":"/rows/1/1","approx":{"value":0.13075231758373204,"rtol":1e-9}}
//|       - {"artifact":"overshoot","path":"/rows/2/1","equals":0}
//|       - {"artifact":"overshoot","path":"/rows/4/1","equals":0}
//|       - {"artifact":"overshoot","path":"/rows/4/2","equals":0}
//|   - case: short-left-plateau
//|     expect:
//|       - {"artifact":"overshoot","path":"/rows/2/1","approx":{"value":0.125,"rtol":1e-9}}
//|       - {"artifact":"overshoot","path":"/rows/3/1","approx":{"value":0.10992504882812498,"rtol":1e-9}}
//|       - {"artifact":"overshoot","path":"/rows/4/1","equals":0}
//|       - {"artifact":"overshoot","path":"/rows/4/2","equals":0}
//|   - case: mirrored
//|     expect:
//|       - {"artifact":"overshoot","path":"/rows/0/1","approx":{"value":0.10938216235292858,"rtol":1e-9}}
//|       - {"artifact":"overshoot","path":"/rows/4/2","equals":0}
use scioxide_interp::{
    AkimaInterpolator, AkimaMethod, CubicSpline, PchipInterpolator, SplineBoundary, Univariate,
};

let step = step as usize;
let x: Vec<_> = (0..8).map(f64::from).collect();
let y: Vec<_> = (0..8).map(|i| if i < step { 0.0 } else { 1.0 }).collect();
let natural = CubicSpline::with_boundary(x.clone(), y.clone(), SplineBoundary::Natural)
    .map_err(|e| e.to_string())?;
// new は not-a-knot の端を使う
let nak = CubicSpline::new(x.clone(), y.clone()).map_err(|e| e.to_string())?;
// new は Akima の元の重みを使う
let akima = AkimaInterpolator::new(x.clone(), y.clone()).map_err(|e| e.to_string())?;
let makima = AkimaInterpolator::with_method(x.clone(), y.clone(), AkimaMethod::Makima)
    .map_err(|e| e.to_string())?;
let pchip = PchipInterpolator::new(x, y).map_err(|e| e.to_string())?;
let mut curves = [Vec::new(), Vec::new(), Vec::new(), Vec::new(), Vec::new()];
for i in 0..=560 {
    let t = f64::from(i) / 80.0;
    let values = [
        natural.value_at(t),
        nak.value_at(t),
        akima.value_at(t),
        makima.value_at(t),
        pchip.value_at(t),
    ];
    for (curve, value) in curves.iter_mut().zip(values) {
        curve.push([t, value.map_err(|e| e.to_string())?]);
    }

    .iter()
    .zip(&curves)
    .map(|(name, curve)| {
        let outside = curve
            .iter()
            .map(|v| (-v[1]).max(v[1] - 1.0).max(0.0))
            .fold(0.0_f64, f64::max);
        let decreases = curve
            .windows(2)
            .filter(|w| w[1][1] < w[0][1] - 1e-12)
            .count();
        (*name, outside, decreases)
    })
    .collect();
let columns = serde_json::json!([
    { "key": "0", "label": "方法" },
    {
        "key": "1",
        "label": "範囲 [0, 1] からの最大のはみ出し [-]",
        "type": "number",
        "format": { "significantDigits": 3 }
    },
    { "key": "2", "label": "減少した検証区間の数", "type": "integer" }
]);
emit_table_with_columns!(columns, rows, metadata = serde_json::json!({ "id": "overshoot" }));

    .iter()
    .zip(&curves)
    .map(|(name, curve)| serde_json::json!({ "name": name, "points": curve }))
    .collect();

    &series,
    options = &serde_json::json!({
        "xLabel": "座標 x [-]",
        "yLabel": "補間値 [-]",
        "annotations": [

        ]
    })
);
```

既定の段差の位置 3 では、自然スプラインが範囲から最大 0.109、not-a-knot が 0.131 はみ出し、560 の検証区間のうちそれぞれ 246 と 265 で値が減る。
$C^2$ の条件は段差の影響を全区間へ伝えるので、段差から離れた平坦部でも曲線が波打つ。
Akima、Makima、PCHIP ははみ出しも減少もない。
段差の位置を 2 にすると、左の平坦部が 2 点だけになり、Akima が 0.125、Makima が 0.110 はみ出して、それぞれ 40 と 43 の区間で値が減る。
左端で延長した割線 $m_{-1} = 2m_0 - m_1 = -1$、$m_{-2} = -2$ が平坦部を直線と見なさないので、Akima の傾きは $d_0 = -0.5$、$d_1 = 0.5$ になり、区間 $[0, 1]$ の曲線が $-0.125$ まで下がる。
PCHIP だけがどの位置でもはみ出しと減少を示さない。
位置 5 の標本を左右に反転すると、位置 3 の標本の 0 と 1 を入れ替えたものになり、はみ出しと減少の数は位置 3 と同じになる。

スプラインの $C^2$ は 2 階導関数までの連続を意味し、3 階導関数の連続は一般に意味しない。
軌道で躍度の連続も必要なら、次数とノットの多重度を別に設計する（[B スプライン・テンソル積・NURBS](../b-splines-tensor-and-nurbs/)）。

## まとめ

区分 3 次補間の違いは節点の傾きの決め方にあり、どれも値と導関数の問い合わせは $O(\log n)$ で、作業領域を渡す形は確保を行わない。
物性値の表や累積分布のように単調性が必要なデータには PCHIP を選ぶ。
内部の傾きが割線の 3 倍以下に抑えられ、各区間の $(\alpha_i, \beta_i)$ が Fritsch–Carlson の正方形に入るので、各区間の単調性が保たれる。
PCHIP の補間誤差は等間隔で $O(h^3)$ と 3 次スプラインより一つ低く、極値の近くでは傾きを 0 にするので精度が落ちる。
2 階導関数の連続が必要なら `CubicSpline` を使い、端の傾きがわからなければ `new` の `NotAKnot`、わかるなら `with_boundary` の `Clamped`、周期データなら `Periodic` を選ぶ。
自然スプラインは曲げエネルギーを最小にするが、端の 2 階導関数が 0 でない関数では端の精度が落ちる。
Akima と Makima は急変の影響を局所にとどめるが、単調性は保証しないので、行き過ぎを検証点で確かめる。
