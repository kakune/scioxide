共鳴や近くの特異点を持つ関数は、多項式の次数を上げるより、分母を持つ有理関数のほうが少ない係数で表せることがある。
多項式は極を持てないので、極の近くの急な変化を高次の項で追うしかないが、有理関数は分母の零点として極そのものを表せるからである。
一方で、標本での近似がよくても、標本の間に不要な極が現れることがある。
そのため、近似の残差、分母の条件、極の推定を別々に調べる。
このページは標本から当てはめる AAA と AAA–Lawson、推定した極と留数の診断を扱う。
実軸上に極を作らない Floater–Hormann 補間と、Taylor 係数から作る Padé 近似は[Floater–Hormann 補間と Padé 近似](../floater-hormann-and-pade/)で扱う。

## 重心形式と支持点

有理関数を支持点 $z_j$ と二組の係数 $a_j$、$b_j$（$j = 1, \dots, m$）で次のように表す。

$$
r(z) = \frac{n(z)}{d(z)}, \qquad
n(z) = \sum_{j=1}^m \frac{a_j}{z - z_j}, \qquad
d(z) = \sum_{j=1}^m \frac{b_j}{z - z_j}
$$

$\ell(z) = \prod_{k}(z - z_k)$ を分子と分母に掛けると $\ell n$ と $\ell d$ は $m-1$ 次以下の多項式になるので、$r$ は $(m-1, m-1)$ 型の有理関数である。
支持点 $z_j$ では各項が発散するが、$b_j \ne 0$ なら $r(z_j) = a_j / b_j$ という極限値を持つ。
したがって、式の項が発散することと、有理関数が極を持つことは別である。
極は $\ell d$ の零点のうち $\ell n$ と打ち消し合わないものである。
AAA は $a_j = b_j f_j$ と選ぶので、支持点で標本値 $f_j$ を補間する。
分子と分母を同じ非零定数倍にしても関数は変わらない。
多項式の係数で $(m-1, m-1)$ 型を表すより、この形のほうが支持点の配置に応じて条件がよく、係数から直接評価できる。

[`BarycentricRational`](https://docs.rs/scioxide-interp/0.1.0/scioxide_interp/struct.BarycentricRational.html) は、支持点 `support_points()`、分子の係数 `numerator_weights()`、分母の係数 `weights()` を別々に保持する。
そのため、標本を補間しない Lawson 反復の結果も同じ型で表せる。
`BarycentricRational::new(nodes, numerator, denominator, domain)` は、支持点が有限で互いに異なり近似域の中にあること、係数が有限で分母の係数がすべては 0 でないことを検査する。
評価の処理は支持点数 $m$ に対して $O(m)$ である。
作業領域の型は `()` で、評価は確保を行わない。
評価では問い合わせ点に最も近い支持点の項を基準にして和を取り、項が桁あふれか下位桁あふれを起こす場合は指数の範囲を広げて計算し直す。
評価点が極に当たって分母が 0 になると、`NumericalInstability`（`Breakdown`）のエラーになる。
`denominator_condition(z, policy)` は分母の相殺の目安 $\sum_j |b_j/(z - z_j)| \big/ |\sum_j b_j/(z - z_j)|$ を返す。
この値は 1 以上で、支持点の上や項の符号がそろう点では 1 になり、値が大きいほど分母の和で桁落ちが起きている。
これは条件の目安であり、近似誤差の推定ではない。

近似域 `RationalDomain` には二つの列挙子がある。
`Real(interval)` は実数の閉区間、`Complex { real, imaginary }` は実部と虚部の閉区間の積で作る長方形である。
支持点と標本は近似域の中になければならず、外にあれば `DomainError` になる。
`Real` の近似域では、虚部が 0 でない支持点と標本を `InvalidInput` で拒否する。
近似域は評価できる座標と外挿方針の基準を決めるだけで、その中に極がないことも、近似精度も保証しない。

評価は `Interpolant` を通す。
実数・複素数のどちらのモデルも `Real` の近似域では 1 座標の形 `[x]`（`Interpolant<_, 1>`）で評価でき、この形ではスカラー形 `value_at(x)` も使える。
複素数のモデルはさらに `[re, im]` の 2 座標の形（`Interpolant<_, 2>`）を持つ。
`Complex` の近似域は 2 座標の形でだけ評価でき、1 座標の問い合わせは `InvalidInput` になる。
`Real` の近似域を 2 座標の形で使うと、長方形 $[a, b] \times [0, 0]$ として扱われる。
複素数のモデルは二つの実装を持つので、座標を渡さない呼び出しでは `Interpolant::<f64, 2>::domains(&model)` のように次元を明示する。

## AAA の貪欲選択と線形化

AAA（adaptive Antoulas–Anderson）法は、標本 $(Z_i, F_i)$（$i = 1, \dots, N$）から支持点を一つずつ選びながら有理関数を当てはめる。
scioxide-interp の手順は次のとおりである。

1. 標本平均を定数の近似として受理し、全標本での最大残差を計算する。
2. 最大残差が閾値 $\tau_{\mathrm{abs}} + \tau_{\mathrm{rel}} \max_i |F_i|$ 以下なら `Converged` で終える。
3. まだ支持点に選んでいない標本のうち、残差が最大のもの（同じ値なら入力順で先のもの）を次の支持点に加える。
4. 重み $b$ を線形化した最小二乗問題で決め、$a_j = b_j f_j$ とおく。
5. 全標本での残差を計算し直して 2 に戻る。
   支持点数が `max_terms` に達した後は 2 の判定だけを行い、満たさなければ `SupportLimit` で終える。

4 の線形化では支持点以外の標本 $Z_i$ で $F_i d(Z_i) - n(Z_i)$ を小さくする。
$r(Z_i) = n(Z_i)/d(Z_i)$ の誤差 $F_i - r(Z_i)$ を直接小さくする問題は $b$ について非線形なので、分母を掛けて線形にする。
$a_j = b_j f_j$ を代入すると、この量は

$$
F_i d(Z_i) - n(Z_i) = \sum_j \frac{F_i - f_j}{Z_i - z_j}\, b_j = (L b)_i
$$

となる。
$L$ を Loewner 行列と呼び、$\|b\|_2 = 1$ のもとで $\|L b\|_2$ を最小にする $b$ は、$L$ の最小特異値に対応する右特異ベクトルである。
数値ランクが不足して最小化の解が一意でない場合、scioxide-interp は零空間の正規直交基底の和を正規化した単位ベクトルを使い、結果を決定論的にする。
線形化した残差の各成分 $(Lb)_i = d(Z_i)\,(F_i - r(Z_i))$ は真の誤差に $d(Z_i)$ を掛けたものなので、3 と 5 では有理関数そのものの残差を評価し直す。
最小化するのは 2 乗和で、閾値と比べるのは最大値なので、支持点を一つ加えても最大残差が増える段がある。
原論文は [Nakatsukasa・Sète・Trefethen](https://arxiv.org/abs/1612.00337) である。

支持点が $k$ 個の段階で $L$ はおよそ $N \times k$ の行列で、密な薄い SVD は $N \ge k$ なら $O(Nk^2)$ の処理を要する。
$m$ 個まで支持点を増やすと、SVD の合計は $O(Nm^3)$ になる。
分解の前に、値を標本の最大絶対値で割り、各成分に標本と支持点の最小距離を掛けて尺度をそろえる。
どちらも共通因子なので、重みは変わらない。

AAA には前計算して使い回す量がないので Plan はなく、次の三つの形で当てはめる。

- ワンショット関数 `aaa(nodes, values)` は既定の設定で当てはめ、近似の `BarycentricRational` だけを返す。
  支持点の上限は $\min(100, N)$、許容誤差は絶対・相対とも $\sqrt{\varepsilon}$（f64 で約 $1.5 \times 10^{-8}$）で、近似域は節点を囲む区間（節点がすべて実数のとき）か長方形である。
  閾値に届かずに止まると `ConvergenceFailure`（支持点の上限なら `TruncationLimit`）を返し、近似は返さない。
- オプション付き形式 `aaa_with_options(nodes, values, domain, options)` は近似域と `AaaOptions` を受け取り、逐次実行で作業領域と出力を確保して、所有する `RationalFit` を返す。
  `SupportLimit` のような未収束の終了でも `Ok` で、その時点で受理した近似が `fit.approximant()` に入る。
- 出力先を指定する API `aaa_into(nodes, values, domain, options, out, workspace, scope)` は、事前確保した出力と作業領域に書き、実行スコープを受け取る。

`AaaOptions::new()`（`Default` と同じ）は、支持点 100 個まで、許容誤差 $\sqrt{\varepsilon}$、Lawson 反復なし、逐次実行、既定の SVD 設定、反復の上限なしを既定にする。
`with_max_terms` で支持点の上限、`with_tolerance` で残差の許容誤差を変える。
`max_terms` が 0 なら `InvalidInput` になる。
標本の節点が重複すればどの形でも `InvalidInput` になり、節点か値が NaN か無限大なら `NonFinite` になる。
オプション付き形式と出力先を指定する API では、標本数が `max_terms` より少ない場合も `InvalidInput` になり、標本が近似域の外なら `DomainError` になる。
[`RationalReport`](https://docs.rs/scioxide-interp/0.1.0/scioxide_interp/struct.RationalReport.html) は `fit.report()` で読む。
`termination()` が返す `RationalTermination` が終了状態の唯一の根拠であり、`is_success()` が真になるのは `Converged` だけである。
`Converged` 以外の状態でも、使える近似が出力に反映され、その最大残差が閾値を上回っている。
`iterations()` は支持点を加えた段の数と試行した Lawson の段の数の和で、受理しなかった Lawson の段も数える。
`max_residual()` は標本での最大残差、`singular_ratio()` は保持した近似を生んだ系の最小特異値と最大特異値の比である。
この比は $\min_{\|b\|=1}\|Lb\|_2 / \|L\|_2$ に等しく、線形化した当てはめの相対的な大きさを表すが、誤差の保証ではない。

事前確保した領域で繰り返し解くには、標本数と設定を `RationalRequest::new(samples, options)` にまとめる。
`RationalWorkspace::workspace_requirements(request)` で `RationalRequirements` を求め、`RationalWorkspace::workspace(request)` で作業領域を、`RationalFit::new()` と `try_reserve` で出力を用意してから、同じ設定で `aaa_into` を呼ぶ。
要求量は SVD の行列の行数・列数（AAA では列数が支持点の上限、Lawson では 2 倍、行数は標本数と列数の大きい方）と残差履歴の長さを含み、事前確保後の求解は確保を行わない。
`RationalFit::new()` の直後は、まだ何も出力に反映していないので `approximant()` と `report()` が `None` を返す。
求解が失敗した場合、前に出力に反映した近似とレポートはそのまま残る。
`RationalWorkspace::residual_history()` は、最初の定数近似から受理した各近似までの標本最大残差の列である。
`AaaOptions::with_budgets` で反復回数の上限を与え、定数近似のあとで計算回数の上限に達すると、受理済みの近似を `BudgetExhausted` で出力に反映する。

## Lawson 反復と二重項

`AaaOptions::with_lawson_iterations(l)` で $l > 0$ を指定すると、AAA が収束せずに終わった場合（回数上限への到達の場合を除く）に、支持点を固定したまま重み付き最小二乗を最大 $l$ 回繰り返す（AAA–Lawson）。
各段では分子と分母の係数を並べた単位ベクトル $[a; b]$ について

$$
\sum_i \lambda_i \bigl| n(Z_i) - F_i\, d(Z_i) \bigr|^2
$$

を最小にし、標本ごとの重みを $\lambda_i \leftarrow \lambda_i |e_i| / \max_k |e_k|$（$e_i$ はその段の残差）で更新して、最大が 1 になるように正規化する。
誤差の大きい標本ほど重みが増えるので、反復は最大残差を均す方向に進む。
支持点の標本では行を $a_j - f_j b_j$ に置き換える。
$a$ と $b$ が独立なので、結果は支持点でも標本を補間するとは限らない。
最大残差が真に減った段だけを受理するので、出力に反映する最大残差は増えない。
この反復の不動点は最良一様近似（最大誤差を最小にする近似）の条件に対応するが、scioxide-interp は最良一様近似に収束することを保証しない。
終了状態は、閾値に達すれば `Converged`、上限に達すれば `IterationLimit`、試行した近似が標本で評価できない（標本の上に極ができた）場合や重みがすべて 0 になった場合は `Stagnation` である。
Lawson の段は分子と分母の係数を合わせて $2k$ 列の行列の SVD を解く。

標本の誤差だけを小さくしすぎるとノイズまで近似し、近接した不要な極と零点の対が現れることがある。
この対を Froissart 二重項と呼ぶ。
二重項の極は留数が小さく、近くの零点とほぼ打ち消し合うので、標本での残差にはほとんど表れない。
ノイズのない標本でも、閾値を丸め誤差の水準まで下げると同じことが起こる。

`BarycentricRational::diagnostics(policy, doublet, eigen_options)` は、分子と分母に $\ell(z)$ を掛けて局所座標 $u = (z - c)/s$ の多項式に変換し、コンパニオン行列の固有値として零点と極を求める。
ここで $c$ は最初の支持点、$s$ は $c$ から最も遠い支持点までの距離で、すべての支持点が単位円板に入る。
極 $\zeta$ の留数は $p(\zeta)/q'(\zeta)$ に座標の尺度 $s$ を掛けて元の座標に戻したもので、$q'(\zeta) = 0$ なら単純極の留数として定まらないので `RationalPole::residue()` は `None` を返す。
返る [`RationalDiagnostics`](https://docs.rs/scioxide-interp/0.1.0/scioxide_interp/struct.RationalDiagnostics.html) は、分子の零点 `roots()`、極の一覧 `poles()`、分子と分母の根の診断、許容誤差で除いた最高次側の係数の数、局所座標の中心と尺度を持つ。
`RationalPole` は位置、留数、最も近い零点までの距離、二重項の疑いを持つ。
二重項の疑いは、最も近い零点までの距離が $\tau(\max(|\zeta|, s))$ 以下で、かつ留数の絶対値が $\tau(v s)$ 以下のときに立つ。
ここで $\tau(x) = \tau_{\mathrm{abs}} + \tau_{\mathrm{rel}} x$ は引数 `doublet` の許容誤差、$v = \max_j|a_j| / \max_j|b_j|$ は値の大きさの目安である。
片方だけなら本物の極にも当てはまるので、両方を要求する。
多項式への変換と固有値計算は $O(m^3)$ の確保を伴う別の経路で、評価には使わない。
`policy` の許容誤差以下の最高次の係数は根を求める前に除く。
許容誤差を超える小さな最高次の係数が残ると、無限遠に近い極が大きな絶対値で現れ、その位置は不確かである。
`policy` が分母の係数をすべて除いてしまう場合は `NumericalInstability`（`Breakdown`）になる。
診断は数値的な推定であり、極の存在の証明ではない。

`cleanup_doublets(nodes, values, policy, doublet, eigen_options)` は、二重項と判定した極ごとに最も近い支持点を除き、残りの支持点で補間的な重みを Loewner 行列の SVD から一度だけ計算し直す。
支持点を新たに選ぶ貪欲な段は行わない。
元の標本（すべての支持点を含む）を渡す必要があり、支持点がすべて除かれる場合は `NumericalInstability`（`Breakdown`）になる。
返る `RationalCleanup` は新しい近似 `approximant()`、除いた支持点の数 `removed_supports()`、除去前後の標本での最大残差 `before_residual()` と `after_residual()` を持ち、元のモデルは変更しない。
除去で真の小さな留数の極を失うこともあるので、標本以外の点でも検算してから採用を決める。

## tan の近似と残差履歴

次の二つのセルは $[-4, 4]$ の標本から $\tan x$ を AAA で近似する。
標本は刻み 0.05 の点のうち $|\cos x| > 0.08$ の 153 点で、極 $\pm\pi/2$ のごく近くは除く。
標本値には標準偏差 $\sigma$ の正規ノイズを加えられ、既定はノイズなしである。
許容誤差は絶対・相対とも $10^{-10}$ で、ノイズのない標本の最大絶対値 8.24 から閾値は $9.2 \times 10^{-10}$ になる。
誤差は標本と重ならない刻み 0.025 の点（同じく極の近くを除く）で、ノイズのない $\tan x$ に対して測る。
極の近くを除くので、この最大誤差は区間全体の一様誤差ではない。

次のブロックは二つのセルが共有する定義である。
`tan_samples` が節点とノイズを加えた標本値を、`nearest_tan_pole` が $x$ に最も近い真の極 $\pi/2 + k\pi$ を返す。
ノイズは `scioxide-random` の SplitMix64 と正規分布で作り、シードを変えると別のノイズになる。

```rust
//| id: interp-aaa-tan-samples
//| kind: definitions
//| title: tan の標本と真の極
//| crates: [scioxide-core, scioxide-random]
use scioxide_core::{SciOxideError, RealScalar};
use scioxide_random::{Distribution, Normal, SeedableRng, SplitMix64};
use std::f64::consts::{FRAC_PI_2, PI};

/// 近似域 [−4, 4] の半幅。
pub(crate) const HALF_WIDTH: f64 = 4.0;

/// 極 ±π/2 のごく近くを除く判定 |cos x| > 0.08。
pub(crate) fn away_from_poles(x: f64) -> bool {
    RealScalar::cos(x).abs() > 0.08
}

/// 刻み 0.05 の節点と、tan x に標準偏差 noise の正規ノイズを加えた標本値。
pub(crate) fn tan_samples(noise: f64, seed: u64) -> Result<(Vec<f64>, Vec<f64>), SciOxideError> {
    let nodes: Vec<f64> = (0..161)
        .map(|i| -HALF_WIDTH + i as f64 / 20.0)
        .filter(|&x| away_from_poles(x))
        .collect();
    let mut rng = SplitMix64::from_seed(seed);
    let normal = Normal::new(0.0_f64, 1.0)?;
    let mut values = Vec::with_capacity(nodes.len());
    for &x in &nodes {
        values.push(RealScalar::tan(x) + noise * normal.sample(&mut rng)?);
    }
    Ok((nodes, values))
}

/// x に最も近い tan の真の極 π/2 + kπ（検算用の参照値）。
pub(crate) fn nearest_tan_pole(x: f64) -> f64 {
    FRAC_PI_2 + RealScalar::round((x - FRAC_PI_2) / PI) * PI
}
```

最初のセルの入力は支持点の上限、Lawson 反復の上限、ノイズの標準偏差 $\sigma$、ノイズのシードである。
`aaa_into` に事前確保した作業領域と出力を渡し、終了状態、反復数、支持点数、標本での最大残差、標本の間の最大誤差、特異値比、閾値の表と、作業領域に残る残差履歴を出力する。
残差履歴のグラフには閾値を横線で示す。
最後に終了状態を判定として示し、求めた近似の支持点と係数を次のセルに渡す。

```rust
//| id: interp-aaa-tan
//| ref: interp-aaa-tan
//| title: AAA の終了状態と残差履歴を Lawson 反復と比べる
//| run: reactive
//| uses: [interp-aaa-tan-samples]
//| crates: [scioxide-core, scioxide-interp]
//| exports: [support, numerator, denominator, noise, seed]
//| inputs:

//|       - {"artifact":"fit","path":"/rows/0/1","equals":10}

//|       - {"path":"/outputs/2/state","equals":"partial"}
//|   - case: lawson
//|     expect:
//|       - {"artifact":"fit","path":"/rows/0/0","equals":"IterationLimit"}
//|       - {"artifact":"fit","path":"/rows/0/1","equals":36}
//|       - {"artifact":"fit","path":"/rows/0/3","approx":{"value":9.130927013263346e-4,"rtol":1e-6}}
//|       - {"artifact":"fit","path":"/rows/0/4","approx":{"value":2.678151754855307e-3,"rtol":1e-4}}

//|   - case: noisy
//|     expect:
//|       - {"artifact":"fit","path":"/rows/0/0","equals":"SupportLimit"}
//|       - {"artifact":"fit","path":"/rows/0/2","equals":20}
//|       - {"artifact":"fit","path":"/rows/0/4","range":{"min":1e-6,"max":1e-5}}
//|       - {"path":"/outputs/2/state","equals":"partial"}
use scioxide_core::{ExecutionContext, Interval, RealScalar, Tolerance};
use scioxide_interp::{
    AaaOptions, RationalDomain, RationalFit, RationalRequest, RationalWorkspace, Univariate,
    aaa_into,
};

let sigma: f64 = noise
    .parse()
    .map_err(|_| format!("ノイズ {noise} を数として読めない"))?;
let (nodes, values) = tan_samples(sigma, seed as u64).map_err(|e| e.to_string())?;
let tolerance = Tolerance::new(1e-10, 1e-10).map_err(|e| e.to_string())?;
let options = AaaOptions::new()
    .with_max_terms(terms as usize)
    .with_tolerance(tolerance)
    .with_lawson_iterations(lawson as usize);
let domain =
    RationalDomain::Real(Interval::new(-HALF_WIDTH, HALF_WIDTH).map_err(|e| e.to_string())?);
// 標本数と設定から要求量を求め、作業領域と出力を事前確保してから解く
let request = RationalRequest::new(nodes.len(), options);
let requirements =
    RationalWorkspace::<f64>::workspace_requirements(request).map_err(|e| e.to_string())?;
let mut workspace = RationalWorkspace::workspace(request).map_err(|e| e.to_string())?;
let mut fit = RationalFit::new();
fit.try_reserve(&requirements).map_err(|e| e.to_string())?;
aaa_into(
    &nodes,
    &values,
    domain,
    options,
    &mut fit,
    &mut workspace,
    ExecutionContext::sequential_native(),
)
.map_err(|e| e.to_string())?;
let report = fit.report().ok_or("求解のレポートがない")?;
let model = fit.approximant().ok_or("近似がない")?;

let mut error = 0.0_f64;
for i in 0..320 {
    let x = -HALF_WIDTH + (i as f64 + 0.5) / 40.0;
    if away_from_poles(x) {
        let value = model.value_at(x).map_err(|e| e.to_string())?;
        error = error.max((value - RealScalar::tan(x)).abs());
    }
}
// 停止の閾値 τ_abs + τ_rel max|F_i|
let scale = values.iter().fold(0.0_f64, |m, v| m.max(v.abs()));
let threshold = tolerance.threshold(scale).map_err(|e| e.to_string())?;
let termination = report.termination();
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let columns = serde_json::json!([
    { "key": "0", "label": "終了状態" },
    { "key": "1", "label": "反復数", "type": "integer" },
    { "key": "2", "label": "支持点数", "type": "integer" },
    { "key": "3", "label": "標本の最大残差 [-]", "type": "number", "format": sci3 },
    { "key": "4", "label": "標本の間の最大誤差 [-]", "type": "number", "format": sci3 },
    { "key": "5", "label": "特異値比 [-]", "type": "number", "format": sci3 },
    { "key": "6", "label": "閾値 [-]", "type": "number", "format": sci3 }
]);
let row = (
    format!("{termination:?}"),
    report.iterations(),
    model.support_points().len(),
    report.max_residual(),
    error,
    report.singular_ratio(),
    threshold,
);
emit_table_with_columns!(
    columns,
    vec![row],
    metadata = serde_json::json!({ "id": "fit" })
);
let history: Vec<[f64; 2]> = workspace
    .residual_history()
    .iter()
    .enumerate()
    .map(|(k, &r)| [k as f64, r])
    .collect();
emit_line_chart!(
    &vec![serde_json::json!({
        "name": "受理した近似の標本最大残差",
        "points": history,
        "style": {"showSymbol": true}
    })],
    options = &serde_json::json!({
        "xLabel": "受理した近似の番号 [-]",
        "yLabel": "標本での最大残差 [-]",
        "yType": "log",
        "annotations": [{"kind": "line", "axis": "y", "value": threshold, "label": "閾値"}]
    })
);
// 支持点は標本の番号で渡す。JSON の受け渡しでは浮動小数点数の最下位桁が変わりうるので、
// 後のセルは同じ標本を作り直し、番号から支持点を正確に取り出す
let mut support = Vec::new();
for point in model.support_points() {
    support.push(
        nodes
            .iter()
            .position(|node| node == point)
            .ok_or("支持点が標本にない")?,
    );
}
export!(support, support);
export!(numerator, model.numerator_weights());
export!(denominator, model.weights());
export!(noise, sigma);
export!(seed, seed);

let outcome = if termination.is_success() {
    Outcome::satisfied("標本での最大残差が閾値以下になった")
        .explanation("残差は標本でだけ測った値で、標本の間の誤差は別に確かめる。")
} else {
    Outcome::partial("閾値に届く前に上限で止まった")
        .explanation("出力に反映した近似は上限に達した時点のもので、最大残差は閾値を上回る。")
};
emit_outcome!(
    outcome
        .status(format!("{termination:?}"))
        .diagnostic("反復数", report.iterations() as f64, None)
        .diagnostic("標本の最大残差", report.max_residual(), None)
        .diagnostic("標本の間の最大誤差", error, None)
);
```

既定の上限 12 では、10 回の支持点の追加で `Converged` になり、標本の最大残差は $5.20 \times 10^{-10}$、標本の間の最大誤差もほぼ同じ $5.20 \times 10^{-10}$ である。
残差履歴は定数近似を含めて 11 個の値を持つ。
最初の 2 段では最大残差が 8.2 から 21.6 まで増え、3 段目から急に減る。
AAA が小さくするのは線形化した残差の 2 乗和であって最大残差ではないので、支持点が少ない段では最大残差が増えることがある。
上限を 6 にすると `SupportLimit` で終わり、標本の最大残差は $1.72 \times 10^{-3}$、標本の間の最大誤差は $1.73 \times 10^{-3}$ で、判定は `partial` になる。
ここで Lawson 反復の上限を 30 にすると、終了状態は `IterationLimit`、反復数は支持点の 6 段と Lawson の 30 段を合わせた 36 になる。
標本の最大残差は $9.13 \times 10^{-4}$ に下がる一方、標本の間の最大誤差は $2.68 \times 10^{-3}$ に増える。
残差履歴には受理した 12 段だけが加わり、最大残差を下げなかった段は記録されない。
Lawson 反復は標本での最大残差を下げるが、標本の間の誤差まで下げるとは限らないので、検証点での誤差を別に確かめる。
支持点の上限が 10 以上なら AAA が先に収束するので、Lawson 反復は実行されない。

ノイズ $\sigma = 10^{-8}$ を加えて上限を 20 にすると、閾値 $9.2 \times 10^{-10}$ はノイズより 1 桁小さいので届かず、20 個の支持点を使い切って `SupportLimit` で終わる。
残差履歴では、支持点 9 個の段で最大残差が $4.8 \times 10^{-8}$ まで下がるが、そのあとはノイズを追って増減し、20 個目の段では $1.84 \times 10^{-5}$ になる。
ノイズのない $\tan x$ との誤差は標本の間で $3.75 \times 10^{-6}$ で、ノイズの大きさを大きく上回る。
支持点を増やしても近似はよくならず、次のセルで見るように近似域の中に二重項が並ぶ。
ノイズのある標本では閾値をノイズの水準より小さくしない。

### 推定した極と留数の検算

$\tan x$ の極は $\pi/2 + k\pi$ にあり、留数はすべて $-1$ なので、推定した極の位置と留数を独立に検算できる。
次のセルは、前のセルから受け取ったノイズの設定で同じ標本を作り直し、受け取った支持点の番号と係数から `BarycentricRational::new` で同じ有理関数を組み立て直して、`diagnostics` で極と留数を推定する。
AAA を解き直さないので、前のセルの入力を変えると、このセルはその近似の極を調べる。
入力は二重項の判定に使う許容誤差 $\tau$（相対・絶対とも同じ値）で、既定は $10^{-7}$ である。

1 つ目の表は推定した極を実部の順に並べ、最も近い真の極までの距離、留数の絶対値、最も近い零点までの距離、二重項の疑いを示す。
二重項の判定に使う二つの量（留数と零点までの距離）を並べるので、判定の理由を表から読める。
2 つ目の表は真の極 $\pi/2 + k\pi$（$k = -3, \dots, 2$）ごとに、二重項の疑いのない推定極のうち最も近いものを照合する。
3 つ目の表は `cleanup_doublets` の結果で、二重項の疑いの数、除いた支持点の数、除去前後の標本の最大残差を示す。

```rust
//| id: interp-aaa-tan-poles
//| ref: interp-aaa-tan-poles
//| title: AAA で推定した tan の極と留数を検算する
//| run: reactive
//| uses: [interp-aaa-tan-samples]
//| crates: [scioxide-core, scioxide-interp, scioxide-poly]
//| dependsOn:
//|   fit: interp-aaa-tan
//| inputs:
//|   doublet_exponent: {"type":"range","label":"二重項の許容誤差の指数 p（τ = 10^p）","description":"二重項と判定する留数と零点までの距離の大きさを変える。","min":-12,"max":-3,"step":1,"value":-7}
//| cases:
//|   - {"id":"loose","label":"τ = 1e-3","description":"許容誤差を緩めても、ノイズのない近似の極は二重項と判定されない。","inputs":{"doublet_exponent":-3}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"matches","path":"/rows/2/2","approx":{"value":-1.5707963267948966,"atol":1e-11}}
//|       - {"artifact":"matches","path":"/rows/3/2","approx":{"value":1.5707963267948966,"atol":1e-11}}
//|       - {"artifact":"matches","path":"/rows/2/4","range":{"max":1e-10}}
//|       - {"artifact":"matches","path":"/rows/3/4","range":{"max":1e-10}}
//|       - {"artifact":"matches","path":"/rows/1/2","approx":{"value":-4.71238898038469,"atol":1e-6}}
//|       - {"artifact":"matches","path":"/rows/4/2","approx":{"value":4.71238898038469,"atol":1e-6}}
//|       - {"artifact":"cleanup","path":"/rows/0/0","equals":0}
//|       - {"artifact":"cleanup","path":"/rows/0/1","equals":0}
//|   - case: loose
//|     expect:
//|       - {"artifact":"cleanup","path":"/rows/0/0","equals":0}
//|       - {"artifact":"poles","path":"/rows/3/5","equals":"なし"}
//|       - {"artifact":"matches","path":"/rows/3/3","range":{"max":1e-11}}
use scioxide_core::{Interval, RealScalar, Tolerance};
use scioxide_interp::{BarycentricRational, RationalDomain};
use scioxide_poly::PolynomialApproximationPolicy;
use std::f64::consts::{FRAC_PI_2, PI};

// 前のセルと同じ標本を作り直し、支持点を標本の番号から取り出す
let noise = fit["noise"].as_f64().ok_or("ノイズの値がない")?;
let seed = fit["seed"].as_f64().ok_or("ノイズのシードがない")?;
let (nodes, values) = tan_samples(noise, seed as u64).map_err(|e| e.to_string())?;
let indices: Vec<usize> =
    serde_json::from_value(fit["support"].clone()).map_err(|e| e.to_string())?;
let support: Vec<f64> = indices.iter().map(|&i| nodes[i]).collect();
let read = |key: &str| -> Result<Vec<f64>, String> {
    serde_json::from_value(fit[key].clone()).map_err(|e| e.to_string())
};
let domain =
    RationalDomain::Real(Interval::new(-HALF_WIDTH, HALF_WIDTH).map_err(|e| e.to_string())?);
// 前のセルの支持点と係数から同じ有理関数を組み立てる
let model = BarycentricRational::new(support, read("numerator")?, read("denominator")?, domain)
    .map_err(|e| e.to_string())?;
let tau = 10.0_f64.powi(doublet_exponent as i32);
let doublet = Tolerance::new(tau, tau).map_err(|e| e.to_string())?;
let policy = PolynomialApproximationPolicy::default();
let diagnostic = model
    .diagnostics(policy, doublet, &Default::default())
    .map_err(|e| e.to_string())?;
let mut poles: Vec<_> = diagnostic.poles().iter().collect();
poles.sort_by(|a, b| a.location().re.total_cmp(&b.location().re));
// 独立な検算: 最も近い真の極 π/2 + kπ との距離と、真の留数 −1 との差
let residue_gap = |pole: &scioxide_interp::RationalPole<f64>| {
    pole.residue().map(|r| RealScalar::hypot(r.re + 1.0, r.im))
};
let label = |pole: &scioxide_interp::RationalPole<f64>| {
    if pole.suspected_doublet() {
        "あり"
    } else {
        "なし"
    }
};
let rows: Vec<_> = poles
    .iter()
    .map(|pole| {
        let p = pole.location();
        let distance = RealScalar::hypot(p.re - nearest_tan_pole(p.re), p.im);
        let residue = pole.residue().map(|r| RealScalar::hypot(r.re, r.im));
        let zero = pole.nearest_zero_distance();
        (p.re, p.im, distance, residue, zero, label(pole))
    })
    .collect();
let fixed6 = serde_json::json!({ "fractionDigits": 6 });
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let pole_columns = serde_json::json!([
    { "key": "0", "label": "極の実部 [rad]", "type": "number", "format": fixed6 },
    { "key": "1", "label": "極の虚部 [rad]", "type": "number", "format": sci2 },
    { "key": "2", "label": "最も近い真の極との距離 [rad]", "type": "number", "format": sci3 },
    {
        "key": "3",
        "label": "|留数| [-]",
        "type": "number",
        "format": sci3,
        "nullText": "定まらない"
    },
    {
        "key": "4",
        "label": "最も近い零点との距離 [rad]",
        "type": "number",
        "format": sci3,
        "nullText": "零点なし"
    },
    { "key": "5", "label": "二重項の疑い" }
]);
emit_table_with_columns!(
    pole_columns,
    rows,
    metadata = serde_json::json!({ "id": "poles" })
);

// 真の極ごとに、二重項の疑いのない推定極のうち最も近いものを照合する
let genuine: Vec<_> = poles
    .iter()
    .filter(|pole| !pole.suspected_doublet())
    .collect();
let mut matches = Vec::new();
for k in -3..=2 {
    let exact = FRAC_PI_2 + f64::from(k) * PI;
    let nearest = genuine.iter().min_by(|a, b| {
        let da = RealScalar::hypot(a.location().re - exact, a.location().im);
        let db = RealScalar::hypot(b.location().re - exact, b.location().im);
        da.total_cmp(&db)
    });
    let location = nearest.map(|pole| pole.location().re);
    let distance =
        nearest.map(|pole| RealScalar::hypot(pole.location().re - exact, pole.location().im));
    let gap = nearest.and_then(|pole| residue_gap(pole));
    matches.push((k, exact, location, distance, gap));
}
let match_columns = serde_json::json!([
    { "key": "0", "label": "k", "type": "integer" },
    { "key": "1", "label": "真の極 π/2 + kπ [rad]", "type": "number", "format": fixed6 },
    {
        "key": "2",
        "label": "推定した極の実部 [rad]",
        "type": "number",
        "format": fixed6,
        "nullText": "なし"
    },
    { "key": "3", "label": "距離 [rad]", "type": "number", "format": sci3, "nullText": "なし" },
    {
        "key": "4",
        "label": "|留数 + 1| [-]",
        "type": "number",
        "format": sci3,
        "nullText": "定まらない"
    }
]);
emit_table_with_columns!(
    match_columns,
    matches,
    metadata = serde_json::json!({ "id": "matches" })
);

// 二重項の極に最も近い支持点を除き、残りの支持点で重みを計算し直す
let cleanup = model
    .cleanup_doublets(&nodes, &values, policy, doublet, &Default::default())
    .map_err(|e| e.to_string())?;
let suspected = poles.iter().filter(|pole| pole.suspected_doublet()).count();
let cleanup_columns = serde_json::json!([
    { "key": "0", "label": "二重項の疑いの数", "type": "integer" },
    { "key": "1", "label": "除いた支持点の数", "type": "integer" },
    { "key": "2", "label": "除去前の標本の最大残差 [-]", "type": "number", "format": sci3 },
    { "key": "3", "label": "除去後の標本の最大残差 [-]", "type": "number", "format": sci3 }
]);
let cleanup_row = (
    suspected,
    cleanup.removed_supports(),
    cleanup.before_residual(),
    cleanup.after_residual(),
);
emit_table_with_columns!(
    cleanup_columns,
    vec![cleanup_row],
    metadata = serde_json::json!({ "id": "cleanup" })
);
```

既定の入力（前のセルの上限 12、ノイズなし）では、近似域の中の極 $\pm\pi/2$ が $3 \times 10^{-12}$ 以下の距離で求まり、留数と $-1$ の差も $10^{-11}$ 以下である。
近似域の外の $\pm 3\pi/2 \approx \pm 4.71$ も $6.6 \times 10^{-7}$ 以下の距離で求まるが、遠い極ほど誤差が大きい。
$\pm 5\pi/2$ に対応する極は 0.05 ずれ、留数も $-1$ から 0.09 離れる。
実部が約 4854 の極は、最高次の係数が小さいために現れた無限遠に近い極で、真の極には対応しない。
二重項の疑いは立たないので、`cleanup_doublets` は支持点を除かず、除去前後の残差は等しい。
許容誤差を $10^{-3}$ に緩めても、どの極も二重項とは判定されない。
真の極は留数の絶対値が 1 程度で最も近い零点まで 1.5 以上離れており、どちらの条件も満たさないからである。

前のセルの上限を 4 にすると、$\pm\pi/2$ の推定は $3.6 \times 10^{-4}$ と $6.5 \times 10^{-3}$ までずれる。
前のセルでノイズ $\sigma = 10^{-8}$、上限 20 にすると、19 個の推定極のうち 9 個に二重項の疑いが立ち、すべて近似域 $[-4, 4]$ の中にある。
それらの留数の絶対値は $2.5 \times 10^{-11}$ から $4.1 \times 10^{-8}$、最も近い零点までの距離は $1.4 \times 10^{-10}$ から $1.1 \times 10^{-7}$ で、極と零点がほぼ打ち消し合っている。
二重項の疑いのない極では、$\pm\pi/2$ は $2.2 \times 10^{-10}$ と $1.7 \times 10^{-9}$ の距離で求まり、ノイズがあっても本物の極の推定は保たれる。
`cleanup_doublets` は 9 個の支持点を除き、標本の最大残差は $1.84 \times 10^{-5}$ から $1.41 \times 10^{-7}$ に下がる。
この場合は、除去で残差も下がり、除いた支持点がノイズを追っていたことが分かる。
許容誤差を $10^{-3}$ に緩めると、留数 $3 \times 10^{-7}$ 程度、零点までの距離 $6 \times 10^{-6}$ 程度の 2 個の極も二重項と判定され、11 個の支持点が除かれる。
近似域から遠い推定極まで真の極のよい推定になるわけではないので、極の位置は近似域の近くで、終了状態と残差を併せて読む。

## まとめ

標本から有理関数を当てはめるには、既定の設定なら `aaa`、上限や許容誤差を選ぶなら `aaa_with_options` を使う。
`aaa` は未収束をエラーにし、`aaa_with_options` では `report().termination()` が `Converged` であることを確かめ、どちらでも標本の間の点での誤差を別に確かめる。
極の位置と留数は `diagnostics` で推定するが、近似域から遠い極や最高次の係数が小さいときの極は信頼しない。
ノイズのある標本で閾値をノイズより小さくすると二重項が現れるので、閾値はノイズの水準に合わせ、疑いがあれば `cleanup_doublets` の前後の残差と標本以外の点での誤差を比べて採用を決める。
最大誤差を下げたい場合は `with_lawson_iterations` を試し、結果が補間的でなくなることを踏まえて検証点の誤差を読む。
