測定ノイズを含む値をすべて通る曲線は、微分するとノイズを強く増幅することがある。
平滑化では標本との一致を緩め、関数の粗さにも制限を加える。
どの程度の不一致を許すかは、測定誤差と下流の用途から決める。
このページでは固定した基底でのペナルティ付き最小二乗、残差目標に合わせてノットとペナルティを選ぶ適応的な当てはめ、曲線の媒介変数と曲率を順に扱う。

## 係数差分によるペナルティ

B スプライン基底 $B_j$（[B スプライン・テンソル積・NURBS](../b-splines-tensor-and-nurbs/)）の基底行列を $B_{ij}=B_j(x_i)$、対角の重み行列を $W$ とする。
係数 $c$ は

$$
J(c)=\|W^{1/2}(Bc-y)\|_2^2+\lambda\|D_qc\|_2^2
$$

が最小になるように求める。
第1項をデータ適合度、第2項をペナルティ項と呼ぶ。
$D_q$ は係数列の $q$ 階前進差分を並べた $(n-q)\times n$ 行列で、$n$ は制御値（係数）の数である。
各行には $(-1)^{q-k}\binom qk$（$k=0,\dots,q$）が並び、`difference_coefficients(q)` はこの列を返す。
例えば $q=2$ の列は $[1,-2,1]$ となる。
この形は Eilers と Marx の P スプラインである。

`SplinePenalty::new(lambda, q)` は $\lambda$ が有限で非負であること、$q$ が正であることを検査し、違反は `InvalidInput` になる。
$q$ は制御値の数より小さくなければならず、この条件は Plan の準備で検査する。

停留条件は

$$
(B^TWB+\lambda D_q^TD_q)c=B^TWy
$$

である。
基底は局所台を持つので、次数 $p$ のとき左辺の行列は半帯幅 $\max(p,q)$ の対称な帯行列になる（$\lambda=0$ なら半帯幅 $p$）。
SciOxide はこの行列を局所的な基底の行から直接組み立て、帯の Cholesky 分解で一度だけ分解する。
標本数 $m$、制御値数 $n$、実効半帯幅 $k$ に対して、組み立てと分解の計算量は $O(m(p^2+\log n)+nk^2)$、メモリは $O(m+n(k+1))$ 個のスカラーである。
$\log n$ は各標本の基底を求めるノット区間の二分探索、$nk^2$ は帯の Cholesky 分解の処理である。
分解した Plan での当てはめでは、右辺の組み立てに $O(m(p^2+\log n))$、帯の前進・後退代入に値の実数成分ごとに $O(nk)$ の処理を要する。

以下では左辺の行列を $A$、右辺を $b$ と書く。
正規方程式を直接作るので、$\lambda=0$ では設計行列 $W^{1/2}B$ の条件数が $A$ で二乗される。
$A$ が正定値でなければ、最小解は一意に決まらない。
$\lambda=0$ では $W^{1/2}B$ の列が一次従属のとき、例えば標本のない区間にだけ台を持つ基底があるときにそうなる。
$\lambda>0$ では、$W^{1/2}B$ と $D_q$ の零空間に共通の非零ベクトルがあるときに限られる。
正のペナルティは標本のない区間の係数を隣の係数と結び付けて決めるが、標本が少なく、$D_q$ の零空間に属する係数列（下の段落）のうち全標本で値が零になるものがあれば、それでも決まらない。
SciOxide はこの場合に対角へ小さな値（jitter）を足して続けることはせず、準備を `DomainError` で止める。

このペナルティは係数の差分であり、一般の非一様ノットでは $\int(s^{(q)})^2dx$ と同じではない。
等間隔ノットではおおむね比例するが、ノットの密度、座標の単位、重みの一括した倍率を変えると、同じ $\lambda$ の意味も変わる。
$\lambda\to\infty$ では係数が $D_q$ の零空間、すなわち添字 $j$ について $q-1$ 次以下の多項式である係数列へ近づく。
これが物理座標の $q-1$ 次以下の多項式に対応するのは、Greville 点 $\xi_j=(t_{j+1}+\dots+t_{j+p})/p$ が添字について等間隔なとき（端を重ねない一様ノットなど）に限られる。
端で重ねたノットや非一様ノットでは、極限の曲線は一般に多項式にならない。

## 固定した Plan の再利用と診断

`PenalizedSplinePlan::new(basis, samples, weights, penalty)` は基底、標本位置、重み、ペナルティを固定して正規行列を分解する。
標本位置は整列していなくても重複していてもよいが、基底の定義域の中になければ `DomainError` になる。
重みを `None` にすると全標本の重みは 1 になる。
重みを与える場合は有限・非負で、少なくとも一つが正でなければならない。
`build` は同じ準備を呼び出し側の `SolveScope` の中で行う。
帯の Cholesky 分解は列ごとに 1 反復を子のスコープで数えるので、親の反復上限で分解を打ち切れる（打ち切られると `ConvergenceFailure`、取り消しや期限では `ExecutionStopped`）。
`preparation_bytes` は準備に要するヒープ量の上界を、確保せずに返す。

`fit(&values)` は `PenalizedSplineFit` を返し、その `spline()` は当てはめた `BSpline` である。
値は実数・複素数・配列のどれでもよく、実数成分ごとに同じ分解で一本ずつ解く。
`fit_into` の作業領域 `PenalizedSplineWorkspace` は成分数に合わせて準備する。
`workspace_requirements(m)` が返す `PenalizedSplineRequirements` を `check` に渡すと足りるかどうかを `Capacity` で返し、`try_reserve` に渡すとその場で広げる。
成功した `fit_into` のあとで、作業領域の `diagnostics()` は成分ごとの診断を返す。
`fit_into` では係数の出力も呼び出し側が用意し、同じ Plan で値だけを変えて解ける。
`fit_into` は失敗したとき出力を変えない。

`SplineFitReport` は全成分についての合計（後退誤差は最大）を、`SplineFitDiagnostics` は成分ごとの値を保持する。
`data_fidelity` は重み付きの残差平方和 $\sum_iw_i(s(x_i)-y_i)^2$、`penalty` は強度を掛けたペナルティ項 $\lambda\|D_qc\|^2$ である。
`normal_residual` は正規方程式の成分ごとの後退誤差

$$
\max_r\frac{|(Ac-b)_r|}{|b_r|+\sum_j|A_{rj}||c_j|}
$$

で、後退安定な求解なら機械イプシロン程度になる。
これは求解の後退誤差を評価する指標であり、真の関数との誤差でも、条件数で増幅された係数の誤差でもない。
`PenalizedSplinePlan::diagonal_ratio` は正規行列の対角成分の絶対値の最小と最大の比で、安価な警告にすぎず、条件数の推定ではない。

## 適合度と粗さの関係

次のセルは $y_i=\sin(2\pi x_i)\pm0.08$ の41点を、31個の内部ノットを等間隔に置いた3次の基底（制御値35個）と2階差分のペナルティで平滑化する。
制御値を標本数に近いほど多く取り、滑らかさをペナルティだけで決めるのが P スプラインの考え方である。
擾乱の符号は標本ごとに交互に変わる。
確率的な測定ノイズではなく、微分で増幅されやすい成分を固定した検証用の信号である。
入力は基準のペナルティの強度 $\lambda_0$ で、セルは $\lambda_0$ の $10^{-3}$ 倍から $10^3$ 倍までの7通りで当てはめる。
出力は各強度のデータ適合度、係数差分の平方和（レポートのペナルティ項を $\lambda$ で割って復元する）、正規方程式の後退誤差、真の関数 $\sin(2\pi x)$ との最大誤差である。
最後の列は人工データだから計算できる独立な検算で、401点の格子で測る。

```rust
//| id: interp-penalized-tradeoff
//| ref: interp-penalized-tradeoff
//| title: ペナルティを増やしたときの残差と係数差分を測る
//| run: reactive
//| crates: [scioxide-core, scioxide-interp]
//| inputs:
//|   strength: {"type":"range","label":"基準のペナルティの強度 λ₀ [-]","description":"7 通りの強度 λ = 10^j λ₀（j = −3, …, 3）の基準を変える。","min":0.01,"max":1.0,"step":0.01,"value":0.1}
//| cases:
//|   - {"id":"weak-range","label":"λ₀ = 0.01","description":"λ = 10⁻⁵ から 10 まで。最も弱いペナルティでは曲線が擾乱を追う。","inputs":{"strength":0.01}}
//|   - {"id":"strong-range","label":"λ₀ = 1","description":"λ = 10⁻³ から 1000 まで。最も強いペナルティでは曲線が直線に近づき、山を削る。","inputs":{"strength":1}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"tradeoff","path":"/rows/0/1","approx":{"value":0.19074583908301296,"rtol":1e-8}}
//|       - {"artifact":"tradeoff","path":"/rows/4/4","approx":{"value":0.07224028864695035,"rtol":1e-6}}
//|       - {"artifact":"tradeoff","path":"/rows/6/1","approx":{"value":0.6157657333812614,"rtol":1e-8}}
//|       - {"artifact":"tradeoff","path":"/rows/3/3","range":{"max":1e-14}}
//|   - case: weak-range
//|     expect:
//|       - {"artifact":"tradeoff","path":"/rows/0/4","approx":{"value":0.41266104489709615,"rtol":1e-6}}
//|   - case: strong-range
//|     expect:
//|       - {"artifact":"tradeoff","path":"/rows/6/1","approx":{"value":4.7400328484665195,"rtol":1e-8}}
//|       - {"artifact":"tradeoff","path":"/rows/6/4","approx":{"value":0.6404006205089303,"rtol":1e-6}}
use scioxide_core::RealScalar;
use scioxide_interp::{BSplineBasis, PenalizedSplinePlan, SplinePenalty, Univariate};

let tau = std::f64::consts::TAU;
let x: Vec<_> = (0..=40).map(|i| i as f64 / 40.0).collect();
// 交互符号の擾乱 ±0.08 を加えた人工データ
let y: Vec<_> = x
    .iter()
    .enumerate()
    .map(|(i, &t)| RealScalar::sin(tau * t) + if i % 2 == 0 { 0.08 } else { -0.08 })
    .collect();
// 端で 4 重、内部に 31 個の等間隔ノットを持つ 3 次の基底（制御値 35 個）
let mut knots = vec![0.0; 4];
knots.extend((1..32).map(|i| i as f64 / 32.0));
knots.extend([1.0; 4]);
let basis = BSplineBasis::new(knots, 3).map_err(|e| e.to_string())?;
let mut rows = Vec::new();
for factor in [1e-3, 1e-2, 0.1, 1.0, 10.0, 100.0, 1e3] {
    let lambda = factor * strength;
    // ペナルティは Plan に固定されるので、強度ごとに Plan を作り直す
    let penalty = SplinePenalty::new(lambda, 2).map_err(|e| e.to_string())?;
    let plan = PenalizedSplinePlan::new(basis.clone(), x.clone(), None, penalty)
        .map_err(|e| e.to_string())?;
    let fit = plan.fit(&y).map_err(|e| e.to_string())?;
    let d = &fit.diagnostics()[0];
    // 独立な検算: 真の関数 sin(2πx) との最大誤差を 401 点で測る
    let mut truth_error = 0.0_f64;
    for j in 0..=400 {
        let t = j as f64 / 400.0;
        let value = fit.spline().value_at(t).map_err(|e| e.to_string())?;
        truth_error = truth_error.max((value - RealScalar::sin(tau * t)).abs());
    }
    rows.push((
        lambda,
        d.data_fidelity(),
        d.penalty() / lambda,
        d.normal_residual(),
        truth_error,
    ));
}
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let digits4 = serde_json::json!({ "significantDigits": 4 });
let columns = serde_json::json!([
    { "key": "0", "label": "ペナルティの強度 λ [-]", "type": "number", "format": sci3 },
    { "key": "1", "label": "データ適合度 [-]", "type": "number", "format": digits4 },
    { "key": "2", "label": "係数差分の平方和 [-]", "type": "number", "format": digits4 },
    { "key": "3", "label": "正規方程式の後退誤差 [-]", "type": "number", "format": sci3 },
    { "key": "4", "label": "sin(2πx) との最大誤差 [-]", "type": "number", "format": digits4 }
]);
emit_table_with_columns!(columns, rows, metadata = serde_json::json!({ "id": "tradeoff" }));
```

同じ基底とデータに対する厳密な最小解なら、強度を増やすと係数差分の平方和は増えず、データ適合度は減らない。
表の2列目と3列目はこの単調な関係に従う。
比較の基準は擾乱そのものの平方和 $41\times0.08^2=0.2624$ である。
既定の $\lambda_0=0.1$ で最も弱い $\lambda=10^{-4}$ では、データ適合度が約 0.19 とこの値より小さく、曲線が擾乱の一部を追っている。
そのため係数差分の平方和が大きく、真の関数との誤差も約 0.39 に達する。
$\lambda$ が 0.1 から 10 の範囲では真の関数との誤差が約 0.07 と最も小さく、データ適合度は 0.24 から 0.27 で擾乱の平方和に近い。
$\lambda=100$ ではデータ適合度が 0.62 と擾乱の平方和を大きく超え、曲線が $\sin(2\pi x)$ の山を削るので誤差がまた増える。
$\lambda_0 = 1$ にして $\lambda = 1000$ まで強めると、データ適合度は 4.74、真の関数との誤差は 0.64 に達し、係数列は $D_2$ の零空間（添字について 1 次の列）に近づく。
$\lambda_0 = 0.01$ の最も弱い $\lambda = 10^{-5}$ では、誤差は 0.41 で $\lambda = 10^{-4}$ とほとんど変わらず、曲線はすでに擾乱を追い切っている。
真の関数との誤差を最小にする強度は、実データでは真の関数が分からないので直接は求められない。
正規方程式の後退誤差は強度によらず $10^{-16}$ 程度で、求解の後退誤差は十分小さい。

## 適応的な残差目標と終了状態

固定した基底とペナルティを選ぶ代わりに、許容する残差から当てはめを決めることもできる。
`AdaptiveSplineOptions` の目標 `SplineFitTarget` は二つある。
`Penalty(λ)` は初期の基底で指定したペナルティの問題を一度だけ解き、ノットを挿入しない。
`Residual(s)` は重み付き残差平方和 $R$ が上界 $s + \tau$（$\tau$ は残差の許容誤差）以下になるまでノットを挿入し、そのあとで上界を保つ最大のペナルティを探す。
既定の目標は `Residual(0)` で、残差の許容誤差は絶対・相対ともに機械イプシロンなので、ほぼ補間を求めることになる。
許容誤差の絶対部分は値の二乗の単位を持つから、値の大きさが1から大きく離れるときは目標と許容誤差を値の尺度に合わせて与える。
曲線ではオプション付き形式 `fit_parametric_spline_with_options(points, parameterization, weights, options)`、球面では `fit_spherical_spline_with_options(samples, values, weights, options)` がこの API で、どちらもモデルをレポートとともに返す。
ワンショット関数 `fit_parametric_spline(points, residual, tolerance)` と `fit_spherical_spline(points, values, residual, tolerance)` は、弦長の媒介変数（球面では散在点）、単位の重み、既定の上限で目標 `Residual(residual)` を解き、目標に達したモデルだけを返す。
探索が目標の前に止まると `ConvergenceFailure` を返し、その理由はノットや挿入の上限なら `TruncationLimit`、挿入できる区間がなければ `Stagnation`、ペナルティの試行の上限なら `IterationLimit` である。
許容誤差 $(\tau_{\mathrm{abs}}, \tau_{\mathrm{rel}})$ は $\tau = \tau_{\mathrm{abs}} + \tau_{\mathrm{rel}} s$ として使われる。
$\varepsilon$ に近い許容誤差では、ペナルティの探索が 32 回の試行で $|R - s| \le \tau$ のウインドウを見つけられないことがあるので、平滑化（$s > 0$）には $\tau_{\mathrm{rel}} = 10^{-5}$ 程度を与える。
曲線のペナルティは2階差分に固定されている。

残差は値の全実数成分（複素数なら絶対値の二乗）と全標本について合計した重み付き平方和であり、最大絶対誤差ではない。
独立なノイズの分散 $\sigma^2$ が分かっていれば、$m$ 個の標本に対して $s\approx m\sigma^2$ とするのが一つの目安になる（Reinsch の考え方）。
ペナルティを交差検証や一般化交差検証（GCV）で自動的に選ぶ機能は提供しない。
必要ならペナルティごとに `PenalizedSplinePlan` を作り、利用側で検証用の標本の誤差を比べる。

曲線の当てはめは両端の媒介変数だけを分点とする1区間の3次多項式（制御値4個）から始める。
したがって `Penalty(λ)` の目標では、全標本に一本の3次多項式をペナルティ付きの最小二乗（$\lambda=0$ なら通常の最小二乗）で当てはめることになる。
残差目標では標本ごとの重み付き二乗残差を分点の区間ごとに合計し、合計が最大で内部に標本を持つ区間に、内部標本の最小と最大の中点を新しい分点として加える。
内部に標本を持つ区間がなくなるか、挿入回数かノット数の上限に達すると挿入は止まる。

ペナルティの探索は $\lambda=1$ から始め、上界を満たす限り $\lambda$ を16倍ずつ増やす。
上界を破る値が見つかったら、満たす値との間を二分する。
各段で上界を満たす最後の当てはめを保持し、残差が目標から許容誤差以内に入るか、二分しても浮動小数点の値が動かなくなれば止まる。
残差はペナルティについて単調に増えるので、この探索は上界を満たす範囲の端を狭めていく。
目標が $s = 0$ のときはペナルティの探索を行わず、$\lambda = 0$ の当てはめで終える。

`SplineFitLimits` はノット数（既定128）、挿入回数（64）、ペナルティの試行回数（32）、作業メモリの上限（64 MiB）を与える。
メモリの上限を超える試行は `ResourceLimit` のエラーになるが、ノット数・挿入回数・ペナルティの試行回数の上限は、次の終了状態で探索を終える。
`AdaptiveSplineOptions::with_budgets` の反復回数の上限は当てはめの試行1回を1反復として数える。
最初の試行が計算回数の上限で拒否されたときは、モデルがないので `ConvergenceFailure` になる。
途中の試行で正規行列が正定値でなくなると（曲線では `DomainError`）、または設計行列が数値的にランク落ちすると（球面では `NumericalInstability`）、探索は終了状態を返さずにエラーで止まる。
目標をノイズの平方和より大きく下回る値にすると、ノットの挿入が続いてこの状態に近づく。

`AdaptiveSplineReport::termination` が唯一の状態で、オプション付き形式はどの終了状態でも最後に受理したモデルを返す。
`FixedPenalty` は指定したペナルティでの完了、`ResidualSatisfied` は残差の上界を満たしペナルティの探索も終えた状態で、この二つだけが `is_success()` を満たす。
`PenaltySearchLimit` は残差の上界を満たしているが、ペナルティの試行が尽きて目標の近くまで届かなかった状態である。
`RefinementLimit` と `NoAdmissibleKnot` は、ノットの上限か挿入できる区間の不足で、上界を満たす前に止まった状態である。
`BudgetExhausted` は反復回数の上限に達した状態で、挿入の途中で尽きれば上界を満たしておらず、ペナルティの探索の途中で尽きれば上界は満たしている。
返された曲線を使うかどうかは、終了状態と `residual()`、`penalty()`、`refinements()`、`penalty_iterations()`、`fit_trials()` を見て利用側で決める。
`reciprocal_condition()` は最後の求解の条件を表す安価な指標で、小さい値は悪条件の警告になるが、条件数の上界ではない。
`fit_parametric_spline_scoped` はオプション付き形式と同じ当てはめを、呼び出し側の `SolveScope` の中の入れ子の求解として行い、呼び出し側の取り消しと期限に従う（試行の反復は `options` の計算回数の上限で数える）。

## 媒介変数と曲率

平面や空間の曲線は標本を順に結ぶ媒介変数 $u$ を決め、各座標を $u$ の関数として同じノットで当てはめる。
オプション付き形式が返す `ParametricSplineFit` は、共有するノットの曲線 `spline()`、実際に使った媒介変数 `parameters()`、レポート `report()` を保持する。
`CurveParameterization::ChordLength` は隣り合う標本の距離（値の全実数成分についての Euclid ノルム）を累積して $[0,1]$ に正規化する。
連続する一致点は距離が零で媒介変数が増えないので、`InvalidInput` で拒否される。
`Supplied` は利用側の有限・狭義増加する媒介変数を、その単位のまま使う。
一様な媒介変数や求心法（距離の平方根を累積する方法）は SciOxide の選択肢にないので、利用側で計算して `Supplied` に渡す。
標本は少なくとも4点が必要である。

媒介変数の選び方は曲線の形を変える。
一様な媒介変数は、標本の間隔が大きく違うと短い区間で曲線をねじり、行き過ぎやループを作りやすい。
弦長はその間隔を反映するので、多くの曲線で形が安定する。

平面曲線 $r(u)=(x(u),y(u))$ の符号付き曲率は

$$
\kappa(u)=\frac{x'(u)y''(u)-y'(u)x''(u)}
{(x'(u)^2+y'(u)^2)^{3/2}}
$$

である。
微分は媒介変数に関するものだが、この値は向きを保つ正則な媒介変数の変更で変わらない。
速度 $(x',y')$ が零の点では定義できない。
当てはめた曲線の導関数は媒介変数の単位で返るので、2階導関数 $d^2r/du^2$ だけを曲率と読んではいけない。

## 円弧の平滑化と曲率の検算

次のセルは半径 $r = 2$ m の半円上に角度を等分して置いた 41 点に、半径方向の擾乱 $\pm\delta$（$\delta = 0.02$ m、標本ごとに符号が交互）を加えた点列を平滑化する。
真の曲線は半円なので、曲率は至るところ $1/r = 0.5$ m⁻¹ で、当てはめた曲線の位置と曲率を独立に検算できる。
平滑化は `fit_parametric_spline_with_options` に弦長の媒介変数と目標 `Residual(s)` を渡し、目標は擾乱の平方和 $m\delta^2$（$m = 41$）の $c$ 倍 $s = c\,m\delta^2$ にする。
残差の許容誤差は $\tau_{\mathrm{abs}} = 0$、$\tau_{\mathrm{rel}} = 10^{-5}$ である。
比較のため、既定の目標 `Residual(0)` でほぼ補間する曲線も同じ点列で求める。

入力は倍率 $c$ と、平滑化の側のノット挿入の上限（`SplineFitLimits::with_max_refinements`）である。
上限を小さくすると、残差の上界を満たす前に挿入が止まり、終了状態が `RefinementLimit` になる。
表は二つの当てはめの終了状態、残差 $R$ [m²]、選ばれたペナルティ $\lambda$、挿入したノットの数、ペナルティの試行回数、当てはめの試行回数と、201 点で測った半径の最大誤差 $\max|\,|r(u)| - r\,|$ と曲率の最大誤差 $\max|\kappa(u) - 1/r|$ を示す。
図は媒介変数 $u$ に対する曲率の誤差 $|\kappa(u) - 1/r|$ を対数軸で示す。
outcome は平滑化の側の終了状態を `is_success()` で判定する。

```rust
//| id: interp-parametric-arc-smoothing
//| ref: interp-parametric-arc-smoothing
//| title: 擾乱を含む円弧を残差目標で平滑化し、曲率を比べる
//| run: reactive
//| crates: [scioxide-core, scioxide-interp]
//| inputs:
//|   residual_factor: {"type":"range","label":"残差目標の倍率 c（s = c·mδ²）","description":"擾乱の平方和 mδ² に対する残差目標の比。","min":0.25,"max":4,"step":0.25,"value":1}
//|   max_refinements: {"type":"range","label":"ノット挿入の上限 [回]","description":"平滑化の側の SplineFitLimits::with_max_refinements に渡す。","min":1,"max":64,"step":1,"value":64}
//| cases:
//|   - {"id":"loose-target","label":"c = 4","description":"残差目標を擾乱の 4 倍にすると、ペナルティが強くなり曲線が円から離れる。","inputs":{"residual_factor":4}}
//|   - {"id":"tight-target","label":"c = 0.25","description":"残差目標を擾乱より小さくすると、ノットが増えて曲線が擾乱を追い、曲率の誤差が補間と同じ桁になる。","inputs":{"residual_factor":0.25}}
//|   - {"id":"refinement-limit","label":"挿入の上限 1 回","description":"残差の上界を満たす前に挿入が止まり、終了状態が RefinementLimit になる。","inputs":{"max_refinements":1}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"fits","path":"/rows/0/1","equals":"ResidualSatisfied"}
//|       - {"artifact":"fits","path":"/rows/0/2","approx":{"value":0.0164,"rtol":1e-4}}
//|       - {"artifact":"fits","path":"/rows/0/7","range":{"max":0.01}}
//|       - {"artifact":"fits","path":"/rows/0/8","range":{"max":0.05}}
//|       - {"artifact":"fits","path":"/rows/1/2","range":{"max":1e-20}}
//|       - {"artifact":"fits","path":"/rows/1/8","range":{"min":10}}
//|       - {"path":"/outputs/2/state","equals":"satisfied"}
//|   - case: loose-target
//|     expect:
//|       - {"artifact":"fits","path":"/rows/0/2","approx":{"value":0.0656,"rtol":1e-4}}
//|       - {"artifact":"fits","path":"/rows/0/7","range":{"min":0.03}}
//|       - {"path":"/outputs/2/state","equals":"satisfied"}
//|   - case: tight-target
//|     expect:
//|       - {"artifact":"fits","path":"/rows/0/4","range":{"min":20}}
//|       - {"artifact":"fits","path":"/rows/0/8","range":{"min":10}}
//|       - {"path":"/outputs/2/state","equals":"satisfied"}
//|   - case: refinement-limit
//|     expect:
//|       - {"artifact":"fits","path":"/rows/0/1","equals":"RefinementLimit"}
//|       - {"artifact":"fits","path":"/rows/0/2","range":{"min":0.0165}}
//|       - {"path":"/outputs/2/state","equals":"partial"}
use scioxide_core::{RealScalar, Tolerance};
use scioxide_interp::{
    AdaptiveSplineOptions, CurveParameterization, Differentiable, ExtrapolationPolicy,
    Interpolant, ParametricSplineFit, SplineFitLimits, SplineFitTarget, TwiceDifferentiable,
    fit_parametric_spline_with_options,
};

let (radius, perturbation, count) = (2.0_f64, 0.02_f64, 41_u32);
// 半径 2 m の半円上の 41 点に、交互符号の半径方向の擾乱 ±δ を加える
let points: Vec<[f64; 2]> = (0..count)
    .map(|i| {
        let angle = std::f64::consts::PI * f64::from(i) / f64::from(count - 1);
        let r = radius + if i % 2 == 0 { perturbation } else { -perturbation };
        [r * RealScalar::cos(angle), r * RealScalar::sin(angle)]
    })
    .collect();
let target = residual_factor * f64::from(count) * perturbation * perturbation;
let smoothing = AdaptiveSplineOptions::new()
    .with_target(SplineFitTarget::Residual(target))
    .with_residual_tolerance(Tolerance::new(0.0, 1e-5).map_err(|e| e.to_string())?)
    .with_limits(SplineFitLimits::new().with_max_refinements(max_refinements as usize));
let chord = CurveParameterization::ChordLength;
let smooth = fit_parametric_spline_with_options(&points, chord, None, smoothing)
    .map_err(|e| e.to_string())?;
// 比較: 既定の目標 Residual(0) でほぼ補間する
let interpolating =
    fit_parametric_spline_with_options(&points, chord, None, AdaptiveSplineOptions::new())
        .map_err(|e| e.to_string())?;

// 独立な検算: 201 点で半径と符号付き曲率 κ = (x'y'' − y'x'')/|r'|³ を真の円と比べる
let policy = ExtrapolationPolicy::Reject;
let profile = |fit: &ParametricSplineFit<f64, [f64; 2]>| -> Result<_, String> {
    let (mut curve, mut radial, mut curvature) = (Vec::new(), 0.0_f64, 0.0_f64);
    for j in 0..=200 {
        let u = f64::from(j) / 200.0;
        let [x, y] = fit.spline().evaluate([u], policy).map_err(|e| e.to_string())?;
        let [[dx, dy]] = fit.spline().gradient([u], policy).map_err(|e| e.to_string())?;
        let [[[ddx, ddy]]] = fit.spline().hessian([u], policy).map_err(|e| e.to_string())?;
        let speed = RealScalar::hypot(dx, dy);
        let kappa = (dx * ddy - dy * ddx) / (speed * speed * speed);
        radial = radial.max((RealScalar::hypot(x, y) - radius).abs());
        let error = (kappa - 1.0 / radius).abs();
        curvature = curvature.max(error);
        if error > 0.0 {
            curve.push([u, error]);
        }
    }
    Ok((curve, radial, curvature))
};
let fits = [("平滑化", &smooth), ("補間（Residual(0)）", &interpolating)];
let mut rows = Vec::new();
let mut series = Vec::new();
for (name, fit) in fits {
    let (curve, radial, curvature) = profile(fit)?;
    let report = fit.report();
    rows.push((
        name,
        format!("{:?}", report.termination()),
        report.residual(),
        report.penalty(),
        report.refinements(),
        report.penalty_iterations(),
        report.fit_trials(),
        radial,
        curvature,
    ));
    series.push(serde_json::json!({ "name": name, "points": curve }));
}
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let columns = serde_json::json!([
    { "key": "0", "label": "当てはめ" },
    { "key": "1", "label": "終了状態" },
    { "key": "2", "label": "残差 R [m²]", "type": "number", "format": sci3 },
    { "key": "3", "label": "ペナルティ λ [-]", "type": "number", "format": sci3 },
    { "key": "4", "label": "挿入したノット [個]", "type": "integer" },
    { "key": "5", "label": "ペナルティの試行 [回]", "type": "integer" },
    { "key": "6", "label": "当てはめの試行 [回]", "type": "integer" },
    { "key": "7", "label": "半径の最大誤差 [m]", "type": "number", "format": sci3 },
    { "key": "8", "label": "曲率の最大誤差 [1/m]", "type": "number", "format": sci3 }
]);
emit_table_with_columns!(columns, rows, metadata = serde_json::json!({ "id": "fits" }));
// 曲率の誤差は桁が広がるので対数軸で描く（誤差が 0 の点は描かない）
emit_line_chart!(
    &series,
    options = &serde_json::json!({
        "xLabel": "弦長の媒介変数 u [-]",
        "yLabel": "曲率の誤差 |κ(u) − 1/r| [1/m]",
        "yType": "log",
        "yMin": 1e-5,
        "yMax": 1e2
    })
);

let report = smooth.report();
let termination = report.termination();
let outcome = if termination.is_success() {
    Outcome::satisfied("平滑化の当てはめが残差目標を満たし、ペナルティの探索を終えた")
} else {
    Outcome::partial("平滑化の当てはめが残差目標を満たす前に止まった").explanation(
        "返された曲線は最後に受理した当てはめで、残差は目標を超えうる。上限か目標を見直す。",
    )
};
emit_outcome!(
    outcome
        .status(format!("{termination:?}"))
        .diagnostic("残差 R", report.residual(), Some("m²"))
        .diagnostic("残差目標 s", target, Some("m²"))
        .diagnostic("当てはめの試行", report.fit_trials() as f64, None)
);
```

既定の $c = 1$ では目標は $s = 41 \times 0.02^2 = 0.0164$ m² で、平滑化はノットを 3 個挿入した時点で残差の上界を満たした。
続く 18 回のペナルティの試行で $\lambda = 0.0041$ を選び、22 回の試行で `ResidualSatisfied` になった。
残差は $R = 0.01640$ m² で、目標との差は許容誤差 $10^{-5} s$ に収まる。
半径の最大誤差は 0.0074 m と擾乱 $\delta = 0.02$ m の半分より小さく、曲率の最大誤差は 0.031 m⁻¹（真の曲率の約 6%）である。
一方、ほぼ補間する曲線は 37 個のノットで残差を $10^{-29}$ m² まで下げるが、擾乱を追って標本の間で振動し、半径の誤差は 0.054 m、曲率の誤差は 38 m⁻¹ に達する。
残差を小さくすることと曲線の形を正しく求めることは別で、2 階導関数を使う量では補間の誤差が大きく増幅される。

$c = 4$ にするとノット 1 個と $\lambda = 0.016$ で目標を満たし、曲線は円より平らになって半径の誤差が 0.040 m に増える。
$c = 0.25$ では 36 個のノットを挿入し、曲線が擾乱の一部を追うので、曲率の誤差が 28 m⁻¹ と補間と同じ桁になる。
挿入の上限を 1 回にすると、残差 $0.0193$ m² が上界 $0.0164$ m² を超えたまま挿入が止まり、終了状態は `RefinementLimit`、outcome は partial になる。
このとき返される曲線は最後に受理した当てはめ（$\lambda = 0$）で、目標を満たしていないことは終了状態で判断する。
残差目標をノイズの平方和 $m\sigma^2$ の近くに置くと、ノイズを追わず、真の形も削りすぎない曲線が得られることがわかる。

## まとめ

ペナルティ付きの当てはめではデータ適合項と係数の粗さの釣り合いを強度 $\lambda$ で決め、強度を上げると残差平方和は増え、粗さは減る。
ノット、重み、座標の単位を変えると同じ $\lambda$ でも効果が変わるので、強度は検証用の標本か既知のノイズの大きさから選ぶ。
ノイズの分散が分かっているなら、`SplineFitTarget::Residual` に $m\sigma^2$ 程度を与え、ノットとペナルティを自動で選ばせる方法もある。
適応的な当てはめで成功を表す終了状態は `FixedPenalty` と `ResidualSatisfied` の二つだけなので、それ以外では残差と試行回数を見てから曲線を使う。
曲線の形は媒介変数の選び方で変わり、曲率は1階と2階の導関数を組み合わせて計算する。
擾乱を含む点列をほぼ補間すると曲率の誤差が擾乱より桁違いに大きくなるので、曲率を使う用途では残差目標をノイズの平方和に合わせて平滑化する。
