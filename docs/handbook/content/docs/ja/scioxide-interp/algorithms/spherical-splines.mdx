地球上の場を経度・緯度の長方形として補間すると、経度の継ぎ目と両極での座標の縮退が問題になる。
経度の異なる北極の点はすべて同じ場所である。
球面のモデルはこの同一性と経度の周期性を、基底の段階で満たすように構成する必要がある。
このページでは SciOxide の球面スプラインの座標、基底、当てはめ、導関数と積分を順に説明する。

## 角度と球面積

`SphericalSamples` と `SphericalSpline` の座標は `[余緯度 θ, 経度 φ]` の順で、単位は rad である。
余緯度は北極からの角度で $0\le\theta\le\pi$、地理緯度は $\pi/2-\theta$ となる。
経度は任意の有限な角を受け取り、$[0,2\pi)$ へ折り返す。
標本の配置は散在点の `Scattered` か、格子の `Rectangular { theta, longitude }` で指定する。
格子では値を経度が最も速く変わる順（余緯度の行ごと）に並べ、各軸は有限で狭義に増加していなければならない。
余緯度 0 や $\pi$ の行（経度の数だけ同じ点を含む）と、継ぎ目を閉じる経度の列（$0$ と $2\pi$ の両方）を含めてよい。
極の点と継ぎ目の重複は重みを合計した一つの標本へ統合される。

単位球面の面積要素は $dA=\sin\theta\,d\theta\,d\phi$ である。
経度・緯度の地図上で一様に平均すると、面積の小さい極付近を面積に比べて重く数えてしまう。
全球平均は $\overline T=(4\pi)^{-1}\int T\,dA$ から求める。
半径 $R$ の球面の面積積分は $R^2$ 倍になるが、平均は変わらない。

## 極と周期境界を含む基底

球面上の散在点の補間には再生核を使う方法と、球面調和関数で展開する方法もよく知られている。
再生核を使う球面スプライン（Wahba, 1981）は、球面上の Sobolev 空間の再生核 $K$ を使って $s(\xi) = d + \sum_i c_i K(\xi_i \cdot \xi)$ と表し、標本ごとに一つの基底を置いて、標本数と同じ大きさの密な連立方程式を解く。
scioxide-interp はこの再生核の方法も球面調和関数の展開も提供しない。
SciOxide の球面モデルは分点で決まる固定した数の基底を使う回帰スプラインで、基底の数は標本数ではなく分点の数で決まる。
余緯度の3次 B スプラインと、経度の周期的な3次 B スプラインのテンソル積を内部に置き、両極の近くを六つの極モードで表す。
余緯度の正規化座標 $u=\theta/\pi$ と、3次 Hermite 基底 $h_{00},h_{01},h_{10},h_{11}$（区間の両端での値と傾きを一つずつ持つ基底）を使うと、極モードは

$$
h_{00}(u),\quad h_{01}(u),\quad
\pi h_{10}(u)\cos\phi,\quad \pi h_{10}(u)\sin\phi,\quad
\pi h_{11}(u)\cos\phi,\quad \pi h_{11}(u)\sin\phi
$$

である。
$h_{00}$ は北極で 1、$h_{01}$ は南極で 1 になり、どちらも経度に依存しないので、極の値は一つに決まる。
$h_{10}$ と $h_{11}$ は両極で値が 0 で、それぞれ北極と南極で傾きを持つ。
極の近くで $\theta\cos\phi$ と $\theta\sin\phi$ は極の接平面の直交座標にあたるから、残りの四つのモードは極で接平面の一次関数を表す。

内部のテンソル積からは余緯度の両端の二つずつの制御値に対応する基底を除く。
除いた基底だけが極で値か傾きを持つので、残りの内部の基底は両極で値と余緯度方向の傾きがともに 0 になる。
このため内部の項は極の値と接平面の勾配に影響せず、極で $C^1$ 級の曲面になる。
極での $C^1$ と、球面全体で任意の次数まで滑らかであることを混同しない。
内部では3次スプラインなので、一般に $C^2$ 級である。

`SphericalSplinePlan` は余緯度の分点（$0$ から $\pi$ まで）と経度の分点（$0$ から $2\pi$ まで）を受け取る。
経度には少なくとも四つの区間が必要である。
モードの数は、余緯度の分点が $N_\theta+1$ 個、経度の区間が $N_\phi$ 個のとき $6+(N_\theta-1)N_\phi$ で、`mode_count()` で確かめられる。
正のペナルティを与えると、内部の係数の経度方向（周期的）と余緯度方向の2階差分の平方和を加え、極モードにはペナルティを課さない。

設計行列は統合後の標本の行とペナルティの行からなる。
行の数が列の数以上なら列ピボット付き QR で最小二乗解を、列より少なければ全行ランクを仮定した LQ で最小ノルムの補間を求める。
数値的にランクが不足した設計は `NumericalInstability` のエラーになり、jitter を足して続けることはしない。
統合後の標本とペナルティの行の総数を $r$、モード数を $c$ とすると、設計と因子のメモリは $O(rc)$、分解は $O(rc\min(r,c))$ である。
任意の散在点と大域的な極モードを含むので、軸ごとの細い帯行列にはならない。
`SplineFitLimits` のメモリの上限は確保の前に検査され、超えると `ResourceLimit` になる。
Wasm のようなメモリの限られた環境では小さい分点から始める。

## 当てはめと再利用

固定した分点とペナルティでは `SphericalSplinePlan::new(theta_breaks, longitude_breaks, samples, weights, penalty, limits)` で分解を準備し、`fit` で `SphericalSplineFit` を得る。
その `spline()` は不変の `SphericalSpline`、`report()` は `AdaptiveSplineReport` で、固定 Plan の終了状態は `FixedPenalty` である。
値は実数・複素数・配列のどれでもよく、各実数成分はその成分だけを当てはめた結果とビット単位で一致する。
`SphericalSplineFitRequirements` は成分数に応じた係数と求解の要求量を表す。
`SphericalSplineFitWorkspace` を事前確保し、`fit_into` の係数の出力も用意すると、同じ Plan で標本値だけを替えて解ける。
成功した `fit_into` のあとで、作業領域の `residuals()` は標本ごとの重み付き二乗残差を返す。
問い合わせには補間器の `workspace()` から得る別の `SphericalSplineWorkspace` を使う。

`fit_spherical_spline_with_options(samples, values, weights, options)` は残差の目標に合わせて分点を選ぶ API で、曲面とレポートを `SphericalSplineFit` で返す。
ワンショット関数 `fit_spherical_spline(points, values, residual, tolerance)` は散在点と単位の重みで目標 `Residual(residual)` を解き、目標に達した `SphericalSpline` だけを返して、それ以外は `ConvergenceFailure` にする。
極モードだけの基底（余緯度の分点が両極だけ）と経度の四つの区間から始め、残差の大きい区間に分点を一つずつ加える。
分点は余緯度と経度へ交互に加え、内部の余緯度の行ができるまでは余緯度を優先する。
目標、上限、終了状態の意味は[平滑化と媒介変数スプライン](oxref:interp-adaptive-termination)と同じである。
`fit_spherical_spline_scoped` はオプション付き形式と同じ当てはめを、呼び出し側のスコープの中の入れ子の求解として行い、呼び出し側の取り消しと期限に従う（試行の反復は `options` の計算回数の上限で数える）。
適応的な細分やペナルティの探索では、返されたモデルが目標を満たしたかを終了状態で確かめる。

## 再現と近似の区別

定数は $h_{00}+h_{01}=1$ として基底に含まれるので、十分なランクがあれば丸め誤差の範囲で再現できる。
$\cos\theta$ は極で値 $\pm1$、傾き 0 を持つので、$h_{00}-h_{01}$ と内部の項の和で近似できるが、有限個の3次の基底には一般に含まれない。
次のセルは定数と $\cos\theta$ を二つの成分として同時に当てはめ、標本に使わなかった点での誤差を比べる。
標本は余緯度 25 行（両極を含む）と経度 12 列の格子で、統合後は 278 点になる。
経度の分点は四つの区間に固定し、ペナルティは 0 とする。
入力は余緯度の区間数 $N_\theta$ である。

当てはめは 2 回行う。
1 回目は `fit` で曲面を作り、誤差の測定に使う。
2 回目は同じ Plan に対して、1 成分用に作った作業領域を 2 成分の要求量まで `try_reserve` で広げ、`fit_into` で係数だけを書く。
`fit_into` の係数が `fit` の係数とビット単位で一致することを確かめ、作業領域の `residuals()` から標本ごとの重み付き二乗残差の最大を読む。
表はモード数、定数の再現誤差、$\cos\theta$ の最大誤差、標本の残差平方和、標本ごとの重み付き二乗残差の最大、北極での $\cos\theta$ 成分の誤差、2 回の当てはめの係数の差である。
最大誤差は経度 0.37 rad の子午線上で、標本の行の間にある 41 点で測る。

```rust
//| id: interp-spherical-harmonic-recovery
//| ref: interp-spherical-harmonic-recovery
//| title: 球面基底の定数再現と調和関数の近似を区別する
//| run: reactive
//| crates: [scioxide-core, scioxide-interp]
//| inputs:
//|   divisions: {"type":"range","label":"余緯度の区間数 N_θ","description":"余緯度の分点を [0, π] に等間隔で N_θ + 1 個置く。","min":2.0,"max":8.0,"step":1.0,"value":4.0}
//| cases:
//|   - {"id":"coarse","label":"N_θ = 2","description":"内部の余緯度の行が 1 つだけで、cos θ の誤差は 10⁻² に達する。","inputs":{"divisions":2}}
//|   - {"id":"fine","label":"N_θ = 8","description":"区間幅を半分ずつにすると、cos θ の誤差は 10⁻⁵ の桁まで下がる。","inputs":{"divisions":8}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"recovery","path":"/rows/0/1","equals":18}
//|       - {"artifact":"recovery","path":"/rows/0/2","range":{"max":1e-13}}
//|       - {"artifact":"recovery","path":"/rows/0/3","approx":{"value":5.5728e-4,"rtol":1e-3}}
//|       - {"artifact":"recovery","path":"/rows/0/7","equals":0}
//|   - case: coarse
//|     expect:
//|       - {"artifact":"recovery","path":"/rows/0/1","equals":10}
//|       - {"artifact":"recovery","path":"/rows/0/3","approx":{"value":1.3210e-2,"rtol":1e-3}}
//|   - case: fine
//|     expect:
//|       - {"artifact":"recovery","path":"/rows/0/1","equals":34}
//|       - {"artifact":"recovery","path":"/rows/0/3","approx":{"value":3.5016e-5,"rtol":1e-3}}
//|       - {"artifact":"recovery","path":"/rows/0/7","equals":0}
use scioxide_core::{ExecutionContext, RealScalar};
use scioxide_interp::{
    ExtrapolationPolicy, Interpolant, SphericalSamples, SphericalSplinePlan, SplineFitLimits,
};

let divisions = divisions as usize;
let pi = std::f64::consts::PI;
// 余緯度 25 行（両極を含む）と経度 12 列の格子。値は経度が最も速く変わる順に並べる
let theta: Vec<_> = (0..=24).map(|i| pi * f64::from(i) / 24.0).collect();
let longitude: Vec<_> = (0..12).map(|j| pi * f64::from(j) / 6.0).collect();
let values: Vec<_> = theta
    .iter()
    .flat_map(|&t| longitude.iter().map(move |_| [1.0, RealScalar::cos(t)]))
    .collect();
let breaks: Vec<_> = (0..=divisions)
    .map(|i| pi * i as f64 / divisions as f64)
    .collect();
let plan = SphericalSplinePlan::new(
    &breaks,
    &[0.0, pi / 2.0, pi, 1.5 * pi, 2.0 * pi],
    SphericalSamples::Rectangular {
        theta: &theta,
        longitude: &longitude,
    },
    None,
    0.0,
    SplineFitLimits::new(),
)
.map_err(|e| e.to_string())?;
let fit = plan.fit(&values).map_err(|e| e.to_string())?;

// 同じ Plan での 2 回目の当てはめ: 1 成分用の作業領域を 2 成分の要求量まで広げる
let requirements = plan.workspace_requirements(2).map_err(|e| e.to_string())?;
let mut workspace = plan.workspace(1).map_err(|e| e.to_string())?;
workspace
    .try_reserve(&requirements)
    .map_err(|e| e.to_string())?;
let mut coefficients = vec![0.0; requirements.coefficients()];
let report = plan
    .fit_into(
        &values,
        coefficients.as_mut_slice(),
        &mut workspace,
        ExecutionContext::sequential_native(),
    )
    .map_err(|e| e.to_string())?;
let coefficient_change = coefficients
    .iter()
    .zip(fit.spline().coefficients())
    .map(|(a, b)| (a - b).abs())
    .fold(0.0_f64, f64::max);
let largest_residual = workspace.residuals().iter().copied().fold(0.0_f64, f64::max);

// 標本の行の間にある 41 点で、定数と cos θ の誤差を測る
let policy = ExtrapolationPolicy::Reject;
let mut errors = [0.0_f64; 2];
for i in 0..41 {
    let t = pi * (f64::from(i) + 0.5) / 41.0;
    let [constant, harmonic] = fit
        .spline()
        .evaluate([t, 0.37], policy)
        .map_err(|e| e.to_string())?;
    errors[0] = errors[0].max((constant - 1.0).abs());
    errors[1] = errors[1].max((harmonic - RealScalar::cos(t)).abs());
}
// 北極の値は経度によらないはずなので、経度 2 rad で問い合わせる
let [_, north] = fit
    .spline()
    .evaluate([0.0, 2.0], policy)
    .map_err(|e| e.to_string())?;
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let columns = serde_json::json!([
    { "key": "0", "label": "N_θ", "type": "integer" },
    { "key": "1", "label": "モード数", "type": "integer" },
    { "key": "2", "label": "定数の最大誤差 [-]", "type": "number", "format": sci3 },
    { "key": "3", "label": "cos θ の最大誤差 [-]", "type": "number", "format": sci3 },
    { "key": "4", "label": "残差平方和（fit_into のレポート） [-]", "type": "number", "format": sci3 },
    { "key": "5", "label": "標本ごとの残差の最大 [-]", "type": "number", "format": sci3 },
    { "key": "6", "label": "北極の cos θ 成分の誤差 [-]", "type": "number", "format": sci3 },
    { "key": "7", "label": "fit と fit_into の係数の差 [-]", "type": "number", "format": sci3 }
]);
emit_table_with_columns!(
    columns,
    vec![(
        divisions,
        plan.mode_count(),
        errors[0],
        errors[1],
        report.residual(),
        largest_residual,
        (north - 1.0).abs(),
        coefficient_change
    )],
    metadata = serde_json::json!({ "id": "recovery" })
);
```

定数の誤差は区間数によらず $10^{-14}$ 程度で、基底に含まれる関数は丸め誤差の範囲で再現される。
$\cos\theta$ の最大誤差は $N_\theta=2$ で $1.32\times10^{-2}$、$N_\theta=4$ で $5.57\times10^{-4}$、$N_\theta=8$ で $3.50\times10^{-5}$ である。
区間幅を半分にするたびに誤差は 16 倍から 24 倍小さくなり、滑らかな関数を3次スプラインで近似したときの $O(h^4)$ の誤差に合う。
標本の残差平方和は全 278 点・2成分の合計であり、未使用点での最大誤差とは別の量である。
標本ごとの重み付き二乗残差の最大は、既定の $N_\theta = 4$ で $3.1\times10^{-7}$ で、どの標本でも残差は小さい。
北極の値は経度によらず一つに決まるが、その値も最小二乗で決まるので、北極での誤差は近似誤差と同じ程度になる。
`fit_into` の係数は `fit` の係数と差 0 で一致し、作業領域を使った当てはめが同じ計算であることを確かめられる。

## 微分と面積積分

`gradient` と `hessian` は角度 $(\theta,\phi)$ に関する座標の導関数であり、接平面上の物理的な勾配ではない。
`derivative(point, orders, policy)` は各軸で2階までの偏導関数を返し、3階以上の指定は `InvalidInput` になる。
半径 $R$ の球面上の物理的な勾配の成分は、極以外で $R^{-1}\partial_\theta T$ と $(R\sin\theta)^{-1}\partial_\phi T$ に換算する。
極ではこの式の $\sin\theta$ が 0 になるので、そのまま割らない。
極の勾配は上の極モードの係数が表す接平面の一次関数から読む。
余緯度は外挿方針に従い、`Clamp` では $[0,\pi]$ の外で余緯度方向の導関数が 0 になる。
どの方針でも、余緯度を $[0,\pi]$ の外へ延長することはできない。

`integral(lower, upper, policy)` は角度の箱 $[\theta_0,\theta_1]\times[\phi_0,\phi_1]$ で、面積要素 $\sin\theta$ を含めた積分を返す。
上下限は有限で、各軸で下限が上限を超えないことを先に検査する。
余緯度の上下限は方針に従い、`Clamp` では球面の範囲に切り詰める。
経度の上下限は折り返さずにそのまま使うので、$2\pi$ を超える幅を与えると一周を超える分も積分される。
全球の積分は `integral([0.0, 0.0], [PI, 2.0 * PI], policy)` で、定数 1 なら $4\pi$ になる。
積分の計算コストはモード数と成分数に比例する。

## 適応的な当てはめと終了状態

次のセルは単位球面上の滑らかな場

$$
f(\theta, \phi) = \cos\theta + \tfrac{1}{2}\sin^2\theta\cos 2\phi
$$

に擾乱を加えた標本を、`fit_spherical_spline_with_options` に残差目標を渡して平滑化する。
$f$ は直交座標で $z + (x^2 - y^2)/2$ と書けるので、極でも滑らかで、全球の積分は 0 になる。
標本は極を含まない余緯度 12 行（$\theta_i = (i + 1/2)\pi/12$）と経度 16 列の格子の 192 点で、値に格子の市松模様の符号の擾乱 $\pm\delta$（$\delta = 0.02$）を加える。
目標は擾乱の平方和 $m\delta^2$（$m = 192$）の $c$ 倍 $s = c\,m\delta^2$ で、残差の許容誤差は $\tau_{\mathrm{abs}} = 0$、$\tau_{\mathrm{rel}} = 10^{-5}$ である。
入力は倍率 $c$ とノット挿入の上限である。

表は終了状態、残差 $R$、選ばれたペナルティ $\lambda$、挿入した分点の数、ペナルティの試行回数、当てはめの試行回数、軸ごとのノット列の長さ、極での連続の階数を示す。
2 つ目の表は独立な検算で、標本に使わなかった Fibonacci 格子の 400 点での $f$ との最大誤差と、`integral` で求めた全球の積分（厳密値 0）である。
outcome は終了状態を `is_success()` で判定する。

```rust
//| inputs:
//|   residual_factor: {"type":"range","label":"残差目標の倍率 c（s = c·mδ²）","description":"擾乱の平方和 mδ² に対する残差目標の比。1 未満では設計行列が数値的にランク落ちする。","min":1,"max":4,"step":0.25,"value":1}
//|   max_refinements: {"type":"range","label":"分点の挿入の上限 [回]","description":"SplineFitLimits::with_max_refinements に渡す。","min":1,"max":64,"step":1,"value":64}
//| cases:
//|   - {"id":"loose-target","label":"c = 2","description":"残差目標を擾乱の 2 倍にすると、分点 1 個で上界を満たし、ペナルティの強い曲面になって f との誤差が δ を超える。","inputs":{"residual_factor":2}}
//|   - {"id":"refinement-limit","label":"挿入の上限 1 回","description":"残差の上界を満たす前に挿入が止まり、終了状態が RefinementLimit になる。","inputs":{"max_refinements":1}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"report","path":"/rows/0/0","equals":"ResidualSatisfied"}
//|       - {"artifact":"report","path":"/rows/0/1","approx":{"value":0.0768,"rtol":1e-4}}
//|       - {"artifact":"report","path":"/rows/0/8","equals":1}
//|       - {"artifact":"check","path":"/rows/0/0","range":{"max":0.01}}
//|       - {"artifact":"check","path":"/rows/0/2","range":{"min":-1e-4,"max":1e-4}}
//|       - {"path":"/outputs/2/state","equals":"satisfied"}
//|   - case: loose-target
//|     expect:
//|       - {"artifact":"report","path":"/rows/0/3","equals":1}
//|       - {"artifact":"check","path":"/rows/0/0","range":{"min":0.02}}
//|       - {"path":"/outputs/2/state","equals":"satisfied"}
//|   - case: refinement-limit
//|     expect:
//|       - {"artifact":"report","path":"/rows/0/0","equals":"RefinementLimit"}
//|       - {"artifact":"report","path":"/rows/0/1","range":{"min":0.0769}}
//|       - {"path":"/outputs/2/state","equals":"partial"}
use scioxide_core::{RealScalar, Tolerance};
use scioxide_interp::{
    AdaptiveSplineOptions, ExtrapolationPolicy, Integrable, Interpolant, SphericalSamples,
    SplineFitLimits, SplineFitTarget, fit_spherical_spline_with_options,
};

let pi = std::f64::consts::PI;
let field = |t: f64, p: f64| {
    let s = RealScalar::sin(t);
    RealScalar::cos(t) + 0.5 * s * s * RealScalar::cos(2.0 * p)
};
let delta = 0.02_f64;
// 極を含まない 12 × 16 の格子。値は経度が最も速く変わる順で、擾乱は市松模様の符号
let theta: Vec<f64> = (0..12).map(|i| (f64::from(i) + 0.5) * pi / 12.0).collect();
let longitude: Vec<f64> = (0..16).map(|j| f64::from(j) * pi / 8.0).collect();
let mut values = Vec::new();
for (i, &t) in theta.iter().enumerate() {
    for (j, &p) in longitude.iter().enumerate() {
        let sign = if (i + j) % 2 == 0 { 1.0 } else { -1.0 };
        values.push(field(t, p) + sign * delta);
    }
}
let target = residual_factor * values.len() as f64 * delta * delta;
let options = AdaptiveSplineOptions::new()
    .with_target(SplineFitTarget::Residual(target))
    .with_residual_tolerance(Tolerance::new(0.0, 1e-5).map_err(|e| e.to_string())?)
    .with_limits(SplineFitLimits::new().with_max_refinements(max_refinements as usize));
let grid = SphericalSamples::Rectangular {
    theta: &theta,
    longitude: &longitude,
};
let fit = fit_spherical_spline_with_options(grid, &values, None, options)
    .map_err(|e| e.to_string())?;
let report = fit.report();
let termination = report.termination();
let [theta_knots, longitude_knots] = report.knot_counts();
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let columns = serde_json::json!([
    { "key": "0", "label": "終了状態" },
    { "key": "1", "label": "残差 R [-]", "type": "number", "format": sci3 },
    { "key": "2", "label": "ペナルティ λ [-]", "type": "number", "format": sci3 },
    { "key": "3", "label": "挿入した分点 [個]", "type": "integer" },
    { "key": "4", "label": "ペナルティの試行 [回]", "type": "integer" },
    { "key": "5", "label": "当てはめの試行 [回]", "type": "integer" },
    { "key": "6", "label": "余緯度のノット数", "type": "integer" },
    { "key": "7", "label": "経度のノット数", "type": "integer" },
    { "key": "8", "label": "極での連続の階数", "type": "integer", "nullText": "なし" }
]);
emit_table_with_columns!(
    columns,
    vec![(
        format!("{termination:?}"),
        report.residual(),
        report.penalty(),
        report.refinements(),
        report.penalty_iterations(),
        report.fit_trials(),
        theta_knots,
        longitude_knots,
        report.pole_continuity()
    )],
    metadata = serde_json::json!({ "id": "report" })
);

// 独立な検算: 標本に使わない Fibonacci 格子の 400 点での誤差と、全球の積分（厳密値 0）
let policy = ExtrapolationPolicy::Reject;
let golden = pi * (3.0 - RealScalar::sqrt(5.0_f64));
let mut largest = 0.0_f64;
for k in 0..400 {
    let z = 1.0 - (2.0 * f64::from(k) + 1.0) / 400.0;
    let (t, p) = (RealScalar::acos(z), golden * f64::from(k));
    let value = fit.spline().evaluate([t, p], policy).map_err(|e| e.to_string())?;
    largest = largest.max((value - field(t, p)).abs());
}
let integral = fit
    .spline()
    .integral([0.0, 0.0], [pi, 2.0 * pi], policy)
    .map_err(|e| e.to_string())?;
let check_columns = serde_json::json!([
    { "key": "0", "label": "未使用 400 点での f との最大誤差 [-]", "type": "number", "format": sci3 },
    { "key": "1", "label": "擾乱の大きさ δ [-]", "type": "number", "format": sci3 },
    { "key": "2", "label": "全球の積分 ∫ s dA [-]", "type": "number", "format": sci3 }
]);
emit_table_with_columns!(
    check_columns,
    vec![(largest, delta, integral)],
    metadata = serde_json::json!({ "id": "check" })
);

let outcome = if termination.is_success() {
    Outcome::satisfied("球面の当てはめが残差目標を満たし、ペナルティの探索を終えた")
} else {
    Outcome::partial("球面の当てはめが残差目標を満たす前に止まった").explanation(
        "返された曲面は最後に受理した当てはめで、残差は目標を超えうる。上限か目標を見直す。",
    )
};
emit_outcome!(
    outcome
        .status(format!("{termination:?}"))
        .diagnostic("残差 R", report.residual(), None)
        .diagnostic("残差目標 s", target, None)
        .diagnostic("当てはめの試行", report.fit_trials() as f64, None)
);
```

既定の $c = 1$ では目標は $s = 192 \times 0.02^2 = 0.0768$ で、当てはめは分点を 17 個挿入して残差の上界を満たし、14 回のペナルティの試行で $\lambda = 0.0013$ を選んで `ResidualSatisfied` になった。
最後のノット列の長さは余緯度 17、経度 19 で、極での連続の階数は 1（$C^1$）である。
未使用の 400 点での $f$ との最大誤差は 0.0075 で、擾乱 $\delta = 0.02$ より小さく、平滑化が擾乱の大部分を取り除いたことがわかる。
全球の積分は $-1.1\times10^{-5}$ で、厳密値 0 との差は誤差 0.0075 に比べて小さい。

$c = 2$ にすると、分点を 1 個挿入しただけで残差が上界を下回り、ペナルティの探索が $\lambda$ を大きくするので、曲面は平らになって $f$ との誤差が 0.044 と $\delta$ を超える。
挿入の上限を 1 回にすると、残差 0.0943 が上界 0.0768 を超えたまま `RefinementLimit` で止まり、outcome は partial になる。
入力の下限を $c = 1$ にしているのは、この格子ではそれより小さい目標で分点の挿入が続き、途中の試行の設計行列が数値的にランク落ちして `NumericalInstability`（`IllConditioned`）のエラーになるからである。
適応的な探索はランク落ちした試行から後戻りしないので、目標はノイズの平方和の見積もり $m\sigma^2$ より小さくしない。
既定の入力では 32 回の試行で密な QR 分解を繰り返すので、wasm で数秒かかる。

## まとめ

球面の座標は `[余緯度 θ, 経度 φ]` の rad で、地理緯度は $\pi/2-\theta$ に換算してから渡す。
極の値の一意性と接平面での $C^1$ 級の接続は六つの極モードが受け持ち、内部の周期的な3次テンソル積は極の値と勾配を変えない。
基底に含まれる定数は丸め誤差の範囲で再現されるが、$\cos\theta$ のような一般の関数は区間幅の4乗程度の誤差で近似されるので、未使用点で誤差を確かめる。
当てはめの作業領域と問い合わせの作業領域は別の型であり、固定 Plan では分解を再利用して値だけを替えられる。
勾配は角度の導関数なので、物理的な勾配には $R$ と $\sin\theta$ で換算し、極では極モードから読む。
適応的な当てはめでは残差目標をノイズの平方和の見積もりに合わせ、終了状態が `ResidualSatisfied` でなければ返された曲面を目標に届かない推定値として扱う。
