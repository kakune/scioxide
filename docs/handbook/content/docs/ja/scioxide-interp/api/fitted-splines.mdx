この表は多次元の B スプライン、標本を通るとは限らない当てはめ（平滑化）、有理スプライン、球面スプラインをまとめる。
共通の部品は検査済みの 1 次元の基底 `BSplineBasis` で、テンソル積のモデルは軸ごとに一つずつ持つ。
B スプラインの係数は制御点順（多重添字の行優先で、最後の軸が最速）に並び、各制御点の値の実数成分を続けて並べる。
球面スプラインの係数はモード順（極の 6 モードが先）に並ぶ。

API は目的で分かれる。
テンソル格子の標本を not-a-knot の基底で一度だけ補間するならワンショット呼び出しの `BSpline::interpolate`、基底を選ぶか同じ格子で値を取り替えて何度も解くなら `TensorSplineInterpolationPlan` を使う。
固定したノットとペナルティでノイズのある 1 次元の標本を平滑化するなら `PenalizedSplinePlan` を使う。
ノットとペナルティを残差の目標から自動で選ぶなら、曲線は `fit_parametric_spline`、球面は `fit_spherical_spline` を使い、目標に達したモデルだけを受け取る。
媒介変数・標本の配置・重み・上限を選び、レポートも読むときはオプション付き形式 `fit_parametric_spline_with_options`・`fit_spherical_spline_with_options` を使う。
分点とペナルティを固定した球面の当てはめは `SphericalSplinePlan`、正の重みを持つ有理の曲線・曲面は `Nurbs` で扱う。

Plan（`*Plan`）は分解を一度だけ行い、`fit` でモデル（ペナルティ付きと球面ではレポートと一組の `PenalizedSplineFit`・`SphericalSplineFit`）を返すか、`fit_into` で事前確保済みの作業領域を使って係数を呼び出し側へ書く。
作業領域は `workspace_requirements(dimension)` の要件を `check` で確かめ、`try_reserve` で伸ばす。
`fit_into` は事前確保後に確保せず、失敗時は出力を変えない。
当てはめたモデルは `BSpline` か `SphericalSpline` で、評価は共通のトレイトを通る。

当てはめの結果はレポートで読む。
`SplineFitReport` と `SplineFitDiagnostics` は元の目的関数での観測値であり、前進誤差の保証ではない。
適応的な当てはめのオプション付き形式とスコープ付き API は目標に届かなくてもモデルを `Ok` で返すので、`AdaptiveSplineReport::termination()` の `is_success()` で成功を判定する。
これらでは最初の試行の前に計算回数の上限に達したときだけ `ConvergenceFailure` になり、ワンショット関数は目標に届かなければ `ConvergenceFailure` を返す。
正規行列が正定値でないときは `DomainError`、球面の設計のランク不足は `NumericalInstability`、メモリ使用量の上限の超過は `ResourceLimit` になる。

## まとめ

格子の標本を通すなら `TensorSplineInterpolationPlan`、ノイズを平滑化するなら `PenalizedSplinePlan` を使い、どちらも軸ごとの `BSplineBasis` を先に作る。
`PenalizedSplinePlan` ではノットと $\lambda$ を呼び出し側が選ぶので、`SplineFitReport` のデータ適合項とペナルティ項を見比べて選ぶ。
ノットとペナルティを自動で選ぶ曲線・球面の当てはめでは、目標に達したモデルだけが要るならワンショット関数を使い、オプション付き形式では `SplineFitLimits` で上限を決めて `AdaptiveSplineReport::termination()` が成功かを確かめてからモデルを使う。
同じ設計で値だけを取り替えて何度も当てはめるときは、Plan と作業領域を一度だけ準備して `fit_into` を繰り返す。
