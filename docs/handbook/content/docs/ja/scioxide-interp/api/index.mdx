`scioxide-interp` は 1 次元の多項式・有理・区分補間、テンソル・平滑化・NURBS・球面のスプライン、2 次元の格子補間、散在点の RBF と Delaunay 分割に基づく補間、局所多項式・局所 RBF・Gauss 過程を出力に反映する。
このガイドは目的から API となる項目を示し、公開されている 115 項目を用途別の五つの表にまとめる。
表の項目名のリンクは、docs.rs の 0.1.0 の API リファレンスを指す。

## 目的別の API

| したいこと | API となる項目 | 規約と注意 | 表 |
|---|---|---|---|
| 標本点を通る多項式で補間する | `BarycentricInterpolator`、`NewtonInterpolator` | 節点の配置が誤差を決める。Chebyshev 節点の重心形式は $O(n)$ で構成できる | [1 次元補間](one-dimensional/) |
| 値と導関数を合わせる | `HermiteInterpolator` | $n$ 節点で次数 $2n-1$ 以下 | [1 次元補間](one-dimensional/) |
| 一点の値と誤差の推定 | `NevilleInterpolator::evaluate_with_error` | 誤差は最終段の修正量による推定で、上界ではない | [1 次元補間](one-dimensional/) |
| 単調性を保つ | `PchipInterpolator` | 各成分の標本が単調な範囲で単調な $C^1$ 曲線 | [1 次元補間](one-dimensional/) |
| 曲率の連続な曲線 | `CubicSpline::new`、`CubicSpline::with_boundary`、`SplineBoundary` | `new` の端は not-a-knot で、ほかの境界条件は `with_boundary` で渡す。周期条件は両端の値がそろっていることを検査する | [1 次元補間](one-dimensional/) |
| ノットで連続性を調整する | `BSpline`、`KnotSide` | ノットでの片側の導関数を明示できる | [1 次元補間](one-dimensional/) |
| 定積分を繰り返す | `prepare_antiderivative`、`PreparedSplineAntiderivative`、`PreparedPolynomialAntiderivative` | 準備後の `integral_into` は確保しない | [1 次元補間](one-dimensional/) |
| 有理関数で近似・補間する | `aaa`、`aaa_with_options`、`FloaterHormannInterpolator`、`PadeApproximant` | `aaa` は未収束をエラーにする。オプション付き形式では終了状態を、どちらでも極の診断を確かめる | [有理補間](rational/) |
| ノイズのある標本を平滑化する | `PenalizedSplinePlan`、`fit_parametric_spline` | `PenalizedSplinePlan` はノットとペナルティを呼び出し側が決め、`fit_parametric_spline` は残差の目標から選ぶ | [テンソル・平滑化・球面スプライン](fitted-splines/) |
| テンソル格子・球面のデータ | `BSpline::interpolate`、`TensorSplineInterpolationPlan`、`SphericalSplinePlan` | テンソルは軸ごとの帯の分解、球面は密な設計の分解で、計算コストが異なる | [テンソル・平滑化・球面スプライン](fitted-splines/) |
| 長方形格子の 2 次元補間 | `BilinearInterpolator`、`BicubicInterpolator` | 値は `ny × nx` の行優先 | [2 次元・散在点・局所モデル](multidimensional/) |
| 散在点の補間 | `RbfInterpolator::new`、`interpolate_scattered`、`SimplexLinearInterpolator`、`CloughTocherInterpolator` | RBF は核を引数に取り、条件のレポートを確かめ、外挿の定義域は外接長方形。Delaunay に基づく補間の定義域は凸包 | [2 次元・散在点・局所モデル](multidimensional/) |
| 局所モデルと Kriging | `LocalModelPlan`、`GaussianProcessModel` | 予測の分散は統計的な不確かさ | [2 次元・散在点・局所モデル](multidimensional/) |
| 1 変数の補間器を点で評価する | `Univariate`（`value_at`・`values_at`・`derivative_at`・`integrate`） | 定義域の外は `DomainError`。延長には方針を取る形を使う | [共通の仕様とバッチ評価](contracts-and-batches/) |
| 多数の点を評価する | `Interpolant::evaluate_many`、`BatchEvaluator::evaluate_into`、`BatchWorkspace` | 失敗したバッチは出力を変えない | [共通の仕様とバッチ評価](contracts-and-batches/) |

## 型の関係

- 対応機能を表すトレイト: `Interpolant<S, D>`（値）、`Differentiable`（勾配）、`TwiceDifferentiable`（Hessian）、`Integrable`（箱領域の定積分）を使う。
  座標は `[S; D]` で渡し、補間器は実際に持つ対応機能を表すトレイトだけを実装する。
  重心形式・Newton・Hermite の定積分は `Integrable` ではなく、`prepare_antiderivative` で準備した原始関数で求める。
- 構築: `new(data)` は標本だけを受け取り、設定を既定値に固定する。
  `with_options(data, options)` は `Default` を実装する設定を値で受け取り、1 次元と格子の補間器の設定は節点の分離を持つ `SampleOptions` である。
  `CubicSpline::with_boundary` のような名前付きの構築関数は別の種類の準備を選ぶ。
  `aaa`、`fit_parametric_spline`、`fit_spherical_spline`、`CloughTocherInterpolator::new` は反復が目標に届かなければ `ConvergenceFailure` を返し、オプション付き形式はモデルをレポートとともに返す。
- 外挿の方針: `ExtrapolationPolicy` は方針を取る評価ごとに必須で、既定値はない。
  1 変数のスカラー形 `Univariate` は方針を取らず、`Reject` と同じく定義域の外を拒否する。
  `report(point, policy, workspace)` は求めたときだけ座標のレポートを作る。
- 準備と作業領域: `workspace()` でモデルに合う作業領域を作り、`evaluate_into` などへ渡す。
  この形は事前確保後に確保せず、失敗時は出力を変えない。
  所有値を返す API の `evaluate`・`gradient`・`evaluate_many` と `Univariate` のスカラー形は出力や作業領域を確保しうる。
  当てはめの Plan と AAA の作業領域（`RationalRequest` で大きさを決める）は、`workspace_requirements` の要件を `check` で確かめ、`try_reserve` で作業領域を伸ばす。
- 値の型: 実数成分ごとに同じ計算を当てる補間器は、アフィン値（実数・複素数・配列・ベクトル）を直接扱う。
  AAA・Padé・`BarycentricRational` は体の演算が必要なので `NumericScalar` を値の型にする。

## 最小の実行例

3 点 $(0, 0)$、$(1, 1)$、$(2, 4)$ を通る 2 次以下の補間多項式は一つに決まり、$p(x) = x^2$ である。
したがって $p(0.5) = 0.25$、$\int_0^2 p(x)\,dx = 8/3$ が解析値になる。
次のセルは `NewtonInterpolator::new(x, y)` で補間を作り、定義域 $[0, 2]$ の中の値を `value_at` で、定積分を `prepare_antiderivative` で準備した原始関数で求め、この解析値と比べる（表 `checks`）。
続いて定義域の外の $x = 2.5$ を、スカラー形 `value_at` と、外挿の方針を取る `Interpolant::evaluate` で評価する（表 `outside`）。
値の列が空の行はエラーで、その分類 `e.kind()` を最後の列に示す。

```rust
//| id: interp-api-quadratic-calculus
//| ref: interp-api-quadratic-calculus
//| title: 三点の Newton 補間を値と面積で検算する
//| run: reactive
//| crates: [scioxide-core, scioxide-interp]
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"checks","path":"/rows/0/1","approx":{"value":0.25,"atol":1e-15}}
//|       - {"artifact":"checks","path":"/rows/1/1","approx":{"value":2.6666666666666665,"rtol":1e-14}}
//|       - {"artifact":"checks","path":"/rows/1/3","range":{"max":1e-14}}
//|       - {"artifact":"outside","path":"/rows/0/3","equals":"DomainError"}
//|       - {"artifact":"outside","path":"/rows/1/3","equals":"DomainError"}
//|       - {"artifact":"outside","path":"/rows/2/2","approx":{"value":4,"atol":1e-14}}
//|       - {"artifact":"outside","path":"/rows/3/3","equals":"DomainError"}
//|       - {"artifact":"outside","path":"/rows/4/2","approx":{"value":6.25,"rtol":1e-14}}
//|       - {"artifact":"outside","path":"/rows/5/2","approx":{"value":6.25,"rtol":1e-14}}
use scioxide_core::SciOxideError;
use scioxide_interp::{ExtrapolationPolicy, Interpolant, NewtonInterpolator, Univariate};

// 標本 (0, 0)、(1, 1)、(2, 4) を通る Newton 形式の 2 次多項式。定義域は [0, 2]
let curve = NewtonInterpolator::new(vec![0.0_f64, 1.0, 2.0], vec![0.0, 1.0, 4.0])
    .map_err(|e| e.to_string())?;
let value = curve.value_at(0.5).map_err(|e| e.to_string())?;
let primitive = curve.prepare_antiderivative().map_err(|e| e.to_string())?;
let integral = primitive
    .integral(0.0, 2.0, ExtrapolationPolicy::Reject)
    .map_err(|e| e.to_string())?;

// 独立検算: 解析値 p(0.5) = 0.25、∫₀² x² dx = 8/3 との差
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let digits = serde_json::json!({ "significantDigits": 17 });
let check_columns = serde_json::json!([
    { "key": "0", "label": "量" },
    { "key": "1", "label": "SciOxide の値 [-]", "type": "number", "format": digits },
    { "key": "2", "label": "解析値 [-]", "type": "number", "format": digits },
    { "key": "3", "label": "絶対誤差 [-]", "type": "number", "format": sci3 }
]);
emit_table_with_columns!(
    check_columns,
    vec![
        ("p(0.5)", value, 0.25, (value - 0.25).abs()),
        (
            "∫₀² p(x) dx",
            integral,
            8.0 / 3.0,
            (integral - 8.0 / 3.0).abs()
        ),
    ],
    metadata = serde_json::json!({ "id": "checks" })
);

// 定義域の外の x = 2.5。値かエラーの分類のどちらか一方を表に入れる
let split = |result: Result<f64, SciOxideError>| match result {
    Ok(v) => (Some(v), None),
    Err(e) => (None, Some(format!("{:?}", e.kind()))),
};
let x = 2.5;
let attempts = [
    ("value_at(x)", "なし（Reject と同じ）", curve.value_at(x)),
    (
        "evaluate",
        "Reject",
        curve.evaluate([x], ExtrapolationPolicy::Reject),
    ),
    (
        "evaluate",
        "Clamp",
        curve.evaluate([x], ExtrapolationPolicy::Clamp),
    ),
    (
        "evaluate",
        "BoundedContinue（0.25）",
        curve.evaluate(
            [x],
            ExtrapolationPolicy::BoundedContinue { max_distance: 0.25 },
        ),
    ),
    (
        "evaluate",
        "BoundedContinue（1）",
        curve.evaluate(
            [x],
            ExtrapolationPolicy::BoundedContinue { max_distance: 1.0 },
        ),
    ),
    (
        "evaluate",
        "MethodDefined",
        curve.evaluate([x], ExtrapolationPolicy::MethodDefined),
    ),
];
let rows: Vec<_> = attempts
    .into_iter()
    .map(|(call, policy, result)| {
        let (v, kind) = split(result);
        (call, policy, v, kind)
    })
    .collect();
let outside_columns = serde_json::json!([
    { "key": "0", "label": "呼び出し" },
    { "key": "1", "label": "外挿の方針" },
    { "key": "2", "label": "返った値 [-]", "type": "number", "format": digits, "nullText": "—" },
    { "key": "3", "label": "エラーの分類", "nullText": "—" }
]);
emit_table_with_columns!(
    outside_columns,
    rows,
    metadata = serde_json::json!({ "id": "outside" })
);
```

値と積分は解析値と一致し、差は丸めの程度（値で 0、積分で $4.4 \times 10^{-16}$）である。
定義域の外の $x = 2.5$ は `value_at` と `Reject` では `DomainError` になり、延長した値を返さない。
`Clamp` は境界 $x = 2$ へ射影して $p(2) = 4$ を返す。
`BoundedContinue` は定義域からの距離 $0.5$ が上限以下のときだけ多項式を延長し、上限 $0.25$ では `DomainError`、上限 $1$ では $2.5^2 = 6.25$ を返す。
`MethodDefined` は距離の上限なしに多項式を延長し、同じ $6.25$ を返す。
延長した値が必要なときは、このように方針を呼び出しごとに明示する。

## 結果・エラー・診断の読み方

失敗は `SciOxideError` で返り、分類は `e.kind()`（`SciOxideErrorKind`）、詳細は `e.view()` で読む。
この章でよく現れる分類は次のとおりである。

| 分類 | 主な原因 |
|---|---|
| `InvalidInput` | 空の標本、手法の必要数より少ない標本、増加していない節点、`NodeSeparation` で重複とみなした節点・散在点、範囲外のパラメータ（負のペナルティ、不正な次数、正でない重み・長さの尺度、負・非有限の `max_distance`）、積分の下端が上端より大きい、AAA の標本数が支持点数の上限より少ない |
| `DimensionMismatch` | 節点と値の長さや値の形の不一致、出力や作業領域の不足 |
| `DomainError` | `Reject` と 1 変数のスカラー形での定義域の外の問い合わせ、自然近傍の凸包の外での `Clamp` 以外の方針、ノットや凸包の外の切り替わりで定義されない導関数（`Undefined`）、Padé の極での評価、ペナルティ付き・媒介変数のスプラインの正規行列や Gauss 過程の共分散が正定値でない |
| `ResourceLimit` | 問い合わせ・準備・当てはめのメモリ使用量が設定した上限を超えた |
| `Singular` | RBF・局所多項式・局所 RBF・Gauss 過程の系のランク不足や最小の逆条件数の未達、3 次スプラインやテンソル格子の選点系の特異、ペナルティ付きスプラインの求解の失敗、Clough–Tocher の頂点の系の退化、Gauss 過程の一つ抜きの精度が正でない |
| `NonFinite` | 非有限の入力（`Input`）、非有限の中間結果（`Intermediate`）、表せない結果（`Output`） |
| `NumericalInstability` | 有理関数の極での評価（Bulirsch–Stoer と `BarycentricRational` の `Breakdown`）、Padé の係数残差の超過、球面の設計の数値的なランク不足、退化に近い単体での評価 |
| `ConvergenceFailure`、`ExecutionStopped` | `aaa`・`fit_parametric_spline`・`fit_spherical_spline`・`CloughTocherInterpolator::new` の反復が目標に届かなかった、受理した状態がないうちに回数制限によって試行が拒否された、取り消し・期限による停止 |

入力検査の分類は全体で共通である。
必須の集合が空なら `InvalidInput`（`Empty`）、要素数の不足は `OutOfRange`、対応する長さの不一致は `DimensionMismatch` になる。
非有限な入力は `NonFinite`（`Input`）、減少・重複した節点や散在点は `InvalidInput`（`Inconsistent`）、負の重みは `OutOfRange` である。
重みがすべて 0 のときは `Inconsistent` になる。

オプション付き形式が `Ok` で返っても、当てはめの結果はレポートで確かめる。
`RationalFit::report()` の `termination()`、`AdaptiveSplineReport::termination()`、`CloughTocherReport::termination()` が終了状態の唯一の根拠で、オプション付き形式は目標に届かなくても受理したモデルを返す。
`RbfConditioning`、`LocalFitReport`、`SplineFitDiagnostics`、`RationalDiagnostics` は推定値や観測値であり、誤差の保証ではない。

## まとめ

API の表で目的に合う補間器を選び、その補間器が値・勾配・Hessian・定積分のどのトレイトを実装するかを各表で確かめる。
定義域の中の 1 変数の評価には `value_at` などのスカラー形を使い、外を評価するときは外挿の方針を明示して、延長した値を座標のレポートで定義域の外の距離とともに読む。
積分や評価を繰り返すときは原始関数や作業領域を一度だけ準備し、多数の点は `evaluate_many` か `BatchEvaluator` で一度に処理する。
エラーは `kind()` で分類し、当てはめの結果は終了状態とレポートを読んでから使う。
