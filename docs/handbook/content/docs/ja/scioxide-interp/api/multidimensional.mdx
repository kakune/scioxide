この表は長方形格子の 2 次元補間、散在点の補間、局所モデルをまとめる。
格子の補間（`BilinearInterpolator`、`BicubicInterpolator`）は、軸の座標 `x`（長さ $n_x$）・`y`（長さ $n_y$）と、`ny × nx` の行優先の値を受け取る。
値の `z[j·nx + i]` が点 $(x_i, y_j)$ の値である。

散在点の補間は二つの系統に分かれる。
`RbfInterpolator` は 2 次元の点の全体で一つの密な系を解き、外挿の定義域は点の外接長方形である。
Delaunay 分割に基づく補間（最近傍・単体線形・Clough–Tocher・自然近傍）は、`scioxide-spatial` の分割 `Delaunay` を借用して共有し、値は分割の `MeshToken` に結び付いた `ScatteredValues` で渡す。
どれも標準形式 `new(&mesh, &values)` で作り、設定はオプション付き形式 `with_options` に渡す。
一組の問い合わせだけなら、ワンショット関数 `interpolate_scattered` が分割の構築から単体線形の評価までを行う。
こちらの定義域は凸包で、最近傍と単体線形は任意の次元、Clough–Tocher と自然近傍は平面だけを扱う。

局所モデルは中心のまわりの近傍だけを使う。
`LocalSamples` か借用した表から `LocalModelPlan` で KD 木を作り、中心ごとに `LocalPolynomialModel` か `LocalRbfModel` を準備する。
`GaussianProcessModel` は全標本の密な共分散から Gauss 過程（kriging）の予測を作り、評価は `prediction` が返す `GaussianPrediction` で行う。
局所モデルと Gauss 過程は正の次元 `D` の座標を扱い、所有値を返す API の評価は実数成分を並べた `Vec` を返す（Gauss 過程の予測は分散の 2 成分を末尾に加える）。

密な系を解く補間器（RBF、局所モデル、Gauss 過程）は、使った因子分解と条件を `RbfConditioning` や `LocalFitReport` で返す。
逆条件数は直接の分解では 1 ノルムでの推定、SVD では 2 ノルムの特異値の比で、どちらのノルムかを `FitConditionNorm` が示す。
どちらも誤差の上界ではない。
ランク不足や設定した最小の逆条件数の未達は `Singular`（Gauss 過程の共分散が正定値でないときは `DomainError`）、準備のメモリ使用量や問い合わせの作業領域の上限の超過は `ResourceLimit` になる。
問い合わせの作業領域の上限は補間器を作るときに検査する。
Clough–Tocher の頂点の勾配は反復で推定し、標準形式 `new` は収束しなければ `ConvergenceFailure` を返す。
未収束の補間器も受け取るオプション付き形式 `with_options` と `build` では、終了状態を `CloughTocherReport::termination()` で確かめる。
Gauss 過程の予測の分散は統計的な不確かさであって、数値誤差の保証ではない。

## まとめ

長方形格子のデータは双線形か双 3 次で補間し、勾配や Hessian が要るなら `Differentiable` を実装する双 3 次を使う。
散在点では、RBF は核と正則化を明示して `conditioning()` の逆条件数を読み、Delaunay 分割に基づく補間は同じ分割と `ScatteredValues` を共有して凸包の中で使う。
Clough–Tocher は標準形式なら勾配の推定が収束したときだけ返り、オプション付き形式では `gradient_report().termination()` が `Converged` かを確かめる。
局所モデルは近傍と次数の範囲を指定して中心ごとに準備し、`fit_report` の次数・逆条件数・残差を読み、Gauss 過程は共分散と平均の仮定を明示して予測の分散を統計量として解釈する。
