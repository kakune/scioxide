この表は 1 次元の補間器と、その原始関数の準備をまとめる。
補間器は大域多項式（重心形式・Newton・Hermite・Neville）、対角有理補間（Bulirsch–Stoer）、区分 3 次補間（Akima・PCHIP・3 次スプライン）、B スプラインの 4 群に分かれる。
Floater–Hormann の有理補間は[有理補間の API](../rational/)で扱う。

節点を受け取る補間器は標準形式 `new(x, y)` で作り、設定を rustdoc に書かれた既定値に固定する。
Hermite は導関数 `dy` も標本として受け取る。
節点は有限で狭義に増加する必要があり、近すぎる節点も重複とみなすときは、オプション付き形式 `with_options` に `SampleOptions`（`NodeSeparation` の `Exact` か許容誤差付きの `Tolerant`）を渡す。
名前付きの構築関数は別の種類の準備を選ぶ。
`CubicSpline::with_boundary` は `SplineBoundary`、`AkimaInterpolator::with_method` は `AkimaMethod` を受け取り、重心形式の `from_equispaced`・`from_chebyshev_roots`・`from_chebyshev_lobatto` は値と区間の両端から節点の族を作る。
値は同じ形のアフィン値（実数・複素数・配列・ベクトル）で、実数成分ごとに同じスカラーの計算を当てる。
そのため、ベクトル値の結果は成分ごとのスカラー補間と一致する。
B スプラインは節点の代わりにノット列 `BSplineBasis` と制御点の値から作り、標本を通る区分線形曲線は `BSpline::linear` で作る。

評価は共通のトレイトを通り、点は `[x]` で渡し、外挿の方針は呼び出しごとに指定する。
定義域の中では、どの補間器でも `Univariate` のスカラー形 `value_at(x)`・`values_at(xs)` を使え、実装するトレイトに応じて `derivative_at(x)`・`integrate(a, b)` も使える。
重心形式・Newton・Hermite は `Interpolant` と `Differentiable` を実装し、定積分は `prepare_antiderivative` が返す `PreparedPolynomialAntiderivative` で求める。
Akima・PCHIP・3 次スプラインは `Interpolant`・`Differentiable`・`Integrable` を実装し、B スプラインはこの三つに加えて `TwiceDifferentiable` も実装する。
Neville と Bulirsch–Stoer は値だけを返す。
3 次スプラインと 1 次元 B スプラインの定積分を繰り返すときは、`prepare_antiderivative` で `PreparedSplineAntiderivative` を作る。

構成の失敗は `Err` で返る。
節点が空か手法の必要数より少ないとき、または増加していないときは `InvalidInput`、節点と値の長さや形の不一致は `DimensionMismatch`、非有限の入力は `NonFinite` である。
`evaluate_into` などの `*_into` は補間器の `workspace()` で作った作業領域を使い、確保しない。
失敗した呼び出しは出力を変えない。
所有値を返す API の `evaluate`・`gradient`・`evaluate_many` とスカラー形は出力や作業領域を確保しうる。
評価が成功しても精度は保証されず、Neville の修正量も誤差の推定にとどまる。

## まとめ

標本が少なく滑らかな関数なら大域多項式を使い、節点を Chebyshev 点に置ける場合は重心形式の `from_chebyshev_lobatto` などで $O(n)$ で構成する。
一点の値と誤差の目安が欲しいときは Neville の `evaluate_with_error` を使い、修正量は推定として解釈する。
区分補間では、単調性を保つなら PCHIP、近傍の割線だけで傾きを決めたいなら Akima・Makima（単調性は保証しない）、$C^2$ が要るなら 3 次スプラインを選び、ノットで連続性を調整するなら B スプラインを使う。
2 階導関数が要るときは `TwiceDifferentiable` を実装する B スプラインを選び、定積分を繰り返すときは `prepare_antiderivative` で原始関数を一度だけ準備する。
