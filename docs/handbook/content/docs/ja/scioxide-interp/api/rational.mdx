この表は有理関数による補間と近似をまとめる。
API は三つある。
標本から当てはめる AAA と AAA–Lawson は関数 `aaa`・`aaa_with_options`・`aaa_into`、実数の節点で極のない補間をする Floater–Hormann は `FloaterHormannInterpolator`、Taylor 係数から近似する Padé は `PadeApproximant` である。

AAA の当てはめと二重項の除去の結果は、重心形式 $r(z) = \sum_j a_j/(z - z_j) \big/ \sum_j b_j/(z - z_j)$ の `BarycentricRational` で返る。
Lawson 反復は分子の係数 $a_j$ と分母の係数 $b_j$ を別々に更新するので、その結果は支持点で標本を補間するとは限らない。
Floater–Hormann は実数の節点とアフィン値を持つ別の型で、重心形式の多項式補間と同じ評価の計算を使う。
Padé は展開の中心のまわりの分子・分母の多項式として結果を持つ。
AAA・`BarycentricRational`・`PadeApproximant` は体の演算を使うので値の型を `NumericScalar`（実数か複素数）とし、近似の閉領域を `RationalDomain` で明示する。
近似の評価は `Interpolant` を通り、実数の点は `[x]`、複素数の点は `[re, im]` で渡し、実数の近似域では 1 変数のスカラー形 `value_at(x)` も使える。
この表の補間器と近似はどれも値だけを返し、勾配のトレイトは実装しない。

AAA には前計算する Plan がない。
ワンショット関数 `aaa(nodes, values)` は既定の設定で当てはめ、閾値に届かなければ `ConvergenceFailure` を返す。
オプション付き形式 `aaa_with_options(nodes, values, domain, options)` は所有する `RationalFit` を返し、出力先を指定する API `aaa_into` は `RationalRequest` で大きさを決めて事前確保した `RationalFit` と `RationalWorkspace` へ書く。
この二つは支持点数や反復の上限、計算回数の上限に達しても、受理した近似を `Ok` で返す。
そのため、結果の状態は `RationalFit::report()` の `termination()` で読み、`Converged` だけを成功とみなす。
標本での残差は与えた標本での値であり、標本の間の誤差の保証ではない。
有理関数は極を持ちうるので、評価が極に当たると `BarycentricRational` では `NumericalInstability`（`Breakdown`）、Padé では `DomainError` になる。
極・零点・留数は `BarycentricRational::diagnostics` で別に推定し、推定値として扱う。

## まとめ

標本から有理関数を当てはめるには、既定の設定で足りれば `aaa`、上限・許容誤差・Lawson 反復を選ぶなら `aaa_with_options` を使い、同じ大きさの当てはめを確保なしで繰り返すなら `RationalRequest` で事前確保して `aaa_into` を使う。
オプション付き形式では `RationalFit::report()` の `termination()` が `Converged` かどうかと、標本での最大残差 `max_residual()` を確かめる。
`SupportLimit` や `BudgetExhausted` でも近似は返るので、その近似を使うかは残差を見て決める。
結果の `BarycentricRational` は極を持ちうるので、`diagnostics` で極・留数・二重項を推定し、疑わしい二重項があれば `cleanup_doublets` の前後の残差を比べてから新しい表現を採用する。
実軸上に極のない補間が必要なら Floater–Hormann、Taylor 係数しかないなら Padé を使い、Padé では `coefficient_residual` と `denominator_rank` を確かめる。
