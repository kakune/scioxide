赤外光に対する極性結晶の応答には、格子振動による共鳴が現れる。
実軸上の標本から誘電関数を有理関数で近似し、その極を複素平面で読むと、共鳴の位置と減衰幅を分けて推定できる。
ただし、実軸でよく近似できても、複素平面への解析接続は摂動に敏感な問題である。
ここでは極が閉形式で分かるモデルを使い、AAA の結果をその値と照合する。

## Lorentz モデルと 6H-SiC の定数

時間依存を $e^{-i\omega t}$ とし、誘電関数を

$$
\epsilon(\omega)=\epsilon_\infty+
\frac{\Delta\epsilon\,\omega_T^2}{\omega_T^2-\omega^2-i\gamma\omega}
$$

と定める。
$\epsilon_\infty$ は格子振動より十分高い周波数での誘電率（電子の寄与）、$\Delta\epsilon$ は振動子の強さ、$\omega_T$ は横光学（TO）フォノンの角周波数、$\gamma>0$ は減衰幅である。
この時間依存の約束では、因果的な応答は上半平面で正則であり、極は下半平面にある。
以下では角周波数を共通の $2\pi c$ で割った分光波数 $\nu$（単位 cm⁻¹）を使う。
分母の各項に同じ換算が掛かるので、式の形は変わらない。

静的な誘電率は $\epsilon_s=\epsilon(0)=\epsilon_\infty+\Delta\epsilon$ である。
縦光学（LO）フォノンの波数 $\nu_L$ は、減衰を無視したときの $\epsilon$ の零点で、Lyddane–Sachs–Teller の関係

$$
\frac{\epsilon_s}{\epsilon_\infty}=\left(\frac{\nu_L}{\nu_T}\right)^2
$$

を満たす。
$\nu_T<\nu<\nu_L$ では $\mathrm{Re}\,\epsilon<0$ となり、光がほぼ全反射される（残留線帯）。

定数は [Spitzer, Kleinman, Walsh, Phys. Rev. 113, 127（1959）](https://doi.org/10.1103/PhysRev.113.127)が 6H-SiC の反射スペクトルに当てはめた、電場が c 軸に垂直な成分（常光線）の値を使う。
$\nu_T=793.9\ \mathrm{cm}^{-1}$、$\gamma=4.8\ \mathrm{cm}^{-1}$、$\Delta\epsilon=3.30$、$\epsilon_s=10.0$ であり、$\epsilon_\infty=\epsilon_s-\Delta\epsilon=6.7$ となる。
Lyddane–Sachs–Teller の関係からは $\nu_L=\nu_T\sqrt{\epsilon_s/\epsilon_\infty}\approx969.9\ \mathrm{cm}^{-1}$ が得られ、SiC の LO フォノンの波数としてよく引かれる約 970 cm⁻¹ と合う。
減衰が小さいとき $\mathrm{Im}\,\epsilon$ の吸収の山の半値全幅はほぼ $\gamma$ に等しく、$\gamma/\nu_T\approx0.006$ の鋭い共鳴である。
c 軸方向の成分、自由キャリアの Drude 項、多フォノン吸収、実測スペクトルのノイズは含めない。
このモデルは SiC の誘電関数を完全には表さず、ここでは有理近似の検証に使う。

## 極と留数の閉形式

分母 $\nu_T^2-\nu^2-i\gamma\nu$ を零とする極は

$$
p_\pm=-\frac{i\gamma}{2}\pm\sqrt{\nu_T^2-\frac{\gamma^2}{4}}
$$

である。
減衰が $\gamma<2\nu_T$ を満たす限り、二つの極は虚部 $-\gamma/2$ を共有し、虚軸に対して左右対称に並ぶ（$p_-=-\overline{p_+}$）。
この対称性は、実の時間応答の Fourier 変換が $\epsilon(-\nu)=\overline{\epsilon(\nu)}$ を満たすことの表れである。
極の虚部は共鳴の減衰を表し、$\hat\gamma=-2\,\mathrm{Im}\,p_+$ で減衰幅を読み取れる。
分母の導関数は $-2\nu-i\gamma$ なので、単純極の留数は

$$
\rho_\pm=\frac{\Delta\epsilon\,\nu_T^2}{-2p_\pm-i\gamma}
$$

となる。
$\epsilon$ は $\nu$ について分子・分母とも 2 次の有理関数であり、無限遠での値は $\epsilon_\infty$ である。

近似は無次元の座標 $z=\nu/\nu_T$ で行う。
$z$ 座標では $\epsilon=\epsilon_\infty+\Delta\epsilon/(1-z^2-igz)$（$g=\gamma/\nu_T$）であり、極の座標と留数は $\nu_T$ 倍すると $\nu$ 座標の値に戻る。
AAA の残差の判定は値に対するもので、座標を定数倍しても近似は丸めの範囲で変わらない。
ここでは座標の大きさを 1 程度にそろえるために $z$ を使う。

## AAA の考え方と停止条件

AAA は標本 $(z_i,f_i)$ を近似する有理関数を重心形式

$$
r(z)=\frac{\sum_{j=1}^m a_j/(z-z_j)}{\sum_{j=1}^m b_j/(z-z_j)},\qquad a_j=b_jf_j
$$

で表す。
$z_j$ は標本点から選んだ支持点で、$a_j=b_jf_j$ なら $r$ は支持点で標本値に一致する。
各段で、残差 $|r(z_i)-f_i|$ が最大の標本を新しい支持点に加え、残りの標本での誤差を最小にする重み $b$ を Loewner 行列 $A_{ij}=(f_i-f_j)/(z_i-z_j)$ の最小特異値に対応する右特異ベクトルとして求める。
支持点が $m$ 個なら、近似は分子・分母とも次数 $m-1$ 以下の有理関数である。
上のモデルは 2 次の有理関数なので、厳密な演算なら支持点 3 個で再現できる。
アルゴリズムの詳細は[有理近似](../../algorithms/rational-approximation/)にある。

当てはめにはオプション付き形式 `aaa_with_options(nodes, values, domain, options)` を使う。
`AaaOptions::new().with_max_terms(8)` で支持点の上限を 8 にし、`with_tolerance` で残差の許容誤差を与える（既定は上限 100 個、許容誤差 $\sqrt\varepsilon\approx1.5\times10^{-8}$）。
停止の判定は、標本での残差の最大値が $\tau_{\mathrm{abs}}+\tau_{\mathrm{rel}}\max_i|f_i|$ 以下になったかどうかで行う。
判定を満たすと `RationalTermination::Converged`、先に支持点の上限に達すると `SupportLimit` を返し、どちらの場合も最後に受理した近似を返す。
`is_success()` が真になるのは `Converged` だけである。
ワンショット関数 `aaa` は支持点の上限と許容誤差を選べず、判定を満たさないと `ConvergenceFailure` のエラーにするので、ここでは使わない。
支持点が $k$ 個の段は $N\times k$ の行列の特異値分解を解くので、$K$ 個まで進めると計算量は $O(NK^3)$ である。

極と留数は `BarycentricRational::diagnostics` が求める。
重心形式に $\prod_j(z-z_j)$ を掛けて多項式の比 $p/q$ に変換し、同伴行列の固有値として分子と分母の根を求める。
この変換は評価とは別にメモリ領域を確保する $O(m^3)$ の診断であり、得られる根は数値的な推定値で、包含が保証された区間ではない。
単純極 $\zeta$ の留数は $p(\zeta)/q'(\zeta)$ で求め、$q'(\zeta)=0$ なら `None` を返す。

標本は $z\in[-1.4,1.4]$ の等間隔な $N$ 点で、負の波数も含める。
既定の $N=81$ では標本の間隔が約 28 cm⁻¹ となり、減衰幅 $\gamma=4.8\ \mathrm{cm}^{-1}$ よりはるかに粗い。
共鳴の幅は標本の間に隠れているが、モデルが厳密に有理関数なので、ノイズなしなら AAA は極を回復できる。
近似の定義域は実部 $[-1.4,1.4]$、虚部 $[-0.2,0.2]$ の長方形とし、評価は実軸上だけで行う。

次のブロックは、ページの三つのセルが共有するモデルと補助関数である。
`permittivity` が $z$ 座標の $\epsilon$、`exact_pole` が極と留数の閉形式、`sample_nodes` と `fit_domain` が標本点と定義域、`generator` が乱数のシードから作る乱数生成器、`noisy_samples` がノイズを加えた標本、`unused_error` が標本と重ならない点での誤差に対応する。

```rust
//| id: interp-aaa-resonance-model
//| kind: definitions
//| title: Lorentz モデルと標本・検算の補助関数
//| crates: [scioxide-core, scioxide-interp, scioxide-random]
use scioxide_core::{Complex, SciOxideError, Interval, RealScalar};
use scioxide_interp::{
    BarycentricRational, ExtrapolationPolicy, Interpolant, RationalDomain, RationalPole,
};
use scioxide_random::{Distribution, Normal, SeedableRng, SplitMix64};

/// 6H-SiC の常光線（Spitzer ら 1959）: ν_T [cm⁻¹]、ε∞、Δε。
pub(crate) const TRANSVERSE: f64 = 793.9;
pub(crate) const EPSILON_INF: f64 = 6.7;
pub(crate) const STRENGTH: f64 = 3.3;

/// ε(z) = ε∞ + Δε/(1 − z² − i g z)、z = ν/ν_T、g = γ/ν_T。
pub(crate) fn permittivity(z: Complex<f64>, g: f64) -> Complex<f64> {
    let denominator = Complex::new(1.0, 0.0) - z * z - Complex::new(0.0, g) * z;
    Complex::new(EPSILON_INF, 0.0) + Complex::new(STRENGTH, 0.0) / denominator
}

/// 閉形式の極 p = ±√(1 − g²/4) − i g/2 と留数 Δε/(−2p − i g)（z 座標）。
pub(crate) fn exact_pole(sign: f64, g: f64) -> (Complex<f64>, Complex<f64>) {
    let pole = Complex::new(sign * RealScalar::sqrt(1.0 - g * g / 4.0), -g / 2.0);
    let residue = Complex::new(STRENGTH, 0.0) / (pole * (-2.0) - Complex::new(0.0, g));
    (pole, residue)
}

/// 推定した極のうち、target に最も近いもの。
pub(crate) fn nearest_pole(
    poles: &[RationalPole<f64>],
    target: Complex<f64>,
) -> Option<&RationalPole<f64>> {
    poles.iter().min_by(|a, b| {
        let da = (a.location() - target).norm();
        da.total_cmp(&(b.location() - target).norm())
    })
}

/// z ∈ [−1.4, 1.4] の等間隔な count 点（実軸上）。
pub(crate) fn sample_nodes(count: usize) -> Vec<Complex<f64>> {
    let last = (count - 1) as f64;
    (0..count)
        .map(|i| Complex::new(-1.4 + 2.8 * i as f64 / last, 0.0))
        .collect()
}

/// 極を含む長方形 [−1.4, 1.4] × [−0.2, 0.2] i。
pub(crate) fn fit_domain() -> Result<RationalDomain<f64>, SciOxideError> {
    Ok(RationalDomain::Complex {
        real: Interval::new(-1.4, 1.4)?,
        imaginary: Interval::new(-0.2, 0.2)?,
    })
}

/// 各点の実部と虚部に独立な N(0, σ²) のノイズを加えた標本。
pub(crate) fn noisy_samples(
    nodes: &[Complex<f64>],
    g: f64,
    noise: f64,
    rng: &mut SplitMix64,
) -> Result<Vec<Complex<f64>>, SciOxideError> {
    let normal = Normal::new(0.0_f64, 1.0)?;
    let mut values = Vec::with_capacity(nodes.len());
    for &z in nodes {
        let re = normal.sample(rng)?;
        let im = normal.sample(rng)?;
        values.push(permittivity(z, g) + Complex::new(noise * re, noise * im));
    }
    Ok(values)
}

/// 標本と重ならない 240 点（区間の中点）での |r − ε| の最大値。
pub(crate) fn unused_error(
    model: &BarycentricRational<Complex<f64>>,
    g: f64,
) -> Result<f64, SciOxideError> {
    let mut largest = 0.0_f64;
    for i in 0..240 {
        let x = -1.4 + 2.8 * (i as f64 + 0.5) / 240.0;
        let value = model.evaluate([x, 0.0], ExtrapolationPolicy::Reject)?;
        largest = largest.max((value - permittivity(Complex::new(x, 0.0), g)).norm());
    }
    Ok(largest)
}

/// 乱数のシードから作った SplitMix64。
pub(crate) fn generator(seed: f64) -> SplitMix64 {
    SplitMix64::from_seed(seed as u64)
}
```

## ノイズなしの標本からの極

次のセルはノイズなしの標本に AAA を当てはめる。
入力は減衰幅 $\gamma$、標本数 $N$、残差の許容誤差 $\tau_{\mathrm{abs}}=\tau_{\mathrm{rel}}=\tau$ の指数である。
1 つ目の表は終了状態、支持点数、極の数、標本残差の最大値と判定値 $\tau(1+\max_i|f_i|)$、標本と重ならない 240 点での最大誤差、標本値の最大 $|f_i|$ を示す。
2 つ目の表は二つの真の極それぞれについて、最も近い推定極との距離、推定した減衰幅 $-2\,\mathrm{Im}\,p$、留数の閉形式との差を示す。
主計算は `aaa_with_options` とその診断で行い、モデルの値と極・留数の公式は独立検算にだけ使う。
このセルの $\gamma$ と $N$ は、次の二つのセルにも渡す。

```rust
//|     expect:
//|       - {"artifact":"summary","path":"/rows/0/0","equals":"SupportLimit"}
//|       - {"artifact":"summary","path":"/rows/0/2","equals":7}

```

既定値では、AAA は 3 個の支持点で `Converged` に達し、極は二つだけ見つかる。
二つの極の位置は閉形式と $3\times10^{-13}$ cm⁻¹ 以下、留数（大きさ約 1310 cm⁻¹）は $2\times10^{-11}$ cm⁻¹ 以下の差で一致し、推定した減衰幅は 4.8 cm⁻¹ を相対 $10^{-13}$ の水準で再現する。
未使用点の誤差は $3.5\times10^{-11}$ で、標本値の最大 $|f_i|\approx100$ に対して丸めの水準である。
減衰幅を 1〜8 cm⁻¹、標本数を 41〜121 点の両端に変えても、支持点 3 個で収束する結果は変わらない。
$\gamma=1$ cm⁻¹、$N=41$ では標本の間隔が減衰幅の約 56 倍あるが、極は同じ精度で回復する。

既定の $\tau=10^{-9}$ では判定値は $1.0\times10^{-7}$ であり、3 個の支持点での残差 $4.2\times10^{-12}$ はそれを十分に下回る。
$\tau=10^{-14}$ にすると判定値 $1.0\times10^{-12}$ が 3 個の支持点での残差を下回るので、AAA は支持点を 4 個に増やし、物理的な極のほかに余分な極を一つ作る。
$\tau=10^{-16}$ では判定値を満たせないまま支持点の上限 8 に達し、`SupportLimit` で止まって極が 7 個になる。
このとき $p_+$ の位置の誤差は $4.9\times10^{-12}$ cm⁻¹ と既定の約 18 倍に増える。
一方、未使用点の誤差はむしろ $3.2\times10^{-12}$ に下がるので、実軸上の精度だけでは余分な極を見分けられない。
表の留数が「計算できない」となる行は分母の導関数が極で 0 になったことを意味し、留数が 0 という意味ではない。

## ノイズのある標本と二重項

ノイズを含む標本に小さい許容誤差を課すと、AAA はノイズまで再現しようとして支持点を増やし、物理的な共鳴に対応しない極を作る。
その多くは、近くに零点があって留数の小さい極と零点の組になる。
この組を Froissart 二重項と呼ぶ。
極と零点がほぼ打ち消し合うので、実軸上の値にはほとんど影響しないが、極を共鳴として解釈すると誤る。

`diagnostics` は、極 $\zeta$ について次の二つがともに二重項の許容誤差 $(\tau_{\mathrm{abs}},\tau_{\mathrm{rel}})$ の範囲にあるとき、二重項の疑いとする。
一つは最も近い零点までの距離で、尺度は $\max(|\zeta|,h)$ である。
もう一つは留数の絶対値で、尺度は $h\max_j|a_j|/\max_j|b_j|$（関数値の大きさの目安に座標の尺度 $h$ を掛けたもの）である。
$h$ は支持点を単位円板に収めるための座標の尺度を表す。
どちらか一方だけなら本物の極にも当てはまるので、両方を要求する。
`cleanup_doublets` は疑いのある極に最も近い支持点を除き、残りの支持点で重みを一度だけ当てはめ直す。
元の近似は変更せず、新しい近似と除去前後の標本残差を返すので、採用するかどうかは呼び出し側が決める。

次のセルは前のセルの $\gamma$ と $N$ を受け取り、ノイズを加えた標本に AAA を当てはめて、見つかったすべての極を診断する。
ノイズは標準正規標本を実部と虚部に独立に生成し、入力の標準偏差 $\sigma$ を掛けて加える。
入力は $\sigma$、残差の許容誤差の指数、二重項の許容誤差 $\tau_{\mathrm{abs}}=\tau_{\mathrm{rel}}$ の指数、乱数のシードである。
1 つ目の表は除去前後の支持点数、標本残差の最大値、未使用点の最大誤差を、2 つ目の表は各極の位置・留数の絶対値・最も近い零点までの距離・二重項の判定を示す。
散布図には推定した極を描き、真の極の実部と虚部を基準線で示す。

余分な 5 個の極は、留数の絶対値が 0.04〜1.6 cm⁻¹ と 3 桁以上小さく、最も近い零点までの距離も 0.005〜0.32 cm⁻¹ と、物理的な極の 80〜120 cm⁻¹ よりずっと短い。

既定の二重項の許容誤差 $10^{-7}$ では、どの極も二重項の疑いにならない。
指数を $-3$ にすると余分な 5 個が疑いとして除かれ、支持点は 3 個に減る。
この標本では、標本残差の最大値が 0.0122 から 0.0112 に、未使用点の誤差が 0.203 から 0.180 に下がり、除去後の近似のほうがよい。
指数を $-1$ にすると物理的な極まで疑いになり、支持点が 1 個に減って標本残差は 189 に増え、除去後の近似は使えなくなる。
残差の許容誤差の指数を $-2$ にすると、判定値 $10^{-2}(1+\max_i|f_i|)\approx1$ はノイズよりかなり大きく、AAA は支持点 3 個で `Converged` に達して余分な極は現れない。
$\sigma=0$ にすると、前のセルと同じノイズなしの当てはめになる。

## ノイズと許容誤差の反復実験

前のセルの結果は一つの乱数系列に対するものであり、偶然の差と区別できない。
そこでノイズを独立に何度も生成し、二つの許容誤差の設定を統計量で比べる。
一つは前のセルの既定と同じ $\tau_{\mathrm{abs}}=\tau_{\mathrm{rel}}=10^{-9}$、もう一つはノイズの水準に合わせた $\tau_{\mathrm{abs}}=k\sigma$、$\tau_{\mathrm{rel}}=0$ である。
支持点以外の標本での残差はおよそノイズの絶対値 $|\eta_i|$ になり、実部と虚部が独立な $N(0,\sigma^2)$ なら $|\eta_i|$ は尺度 $\sigma$ の Rayleigh 分布に従う。
その分布関数は $1-e^{-x^2/(2\sigma^2)}$ なので、$N$ 個の最大値の中央値は $\sigma\sqrt{2\ln(N/\ln2)}$ で、$N=81$ では約 $3.1\sigma$ である。
$k$ はそれより大きい 5 を既定にする。

次のセルは前のセルの $\gamma$、$N$、$\sigma$、乱数のシードを受け取る。
同じシードから始めるので、1 回目の反復の標本は前のセルの標本と同じである。
入力は係数 $k$ と反復回数 $R$ で、各反復の同じノイズの標本に両方の設定を当てはめる。
出力は設定ごとの収束した割合、平均の支持点数、物理的な二つの極以外の極の平均数である。
さらに、$p_+$ に最も近い推定極から求めた減衰幅 $\hat\gamma=-2\,\mathrm{Im}\,\hat p$ について、平均、95% 信頼区間の半幅 1.96 SE、平均と真値の差を出す。
SE は $R$ 回の推定値の標本標準偏差を $\sqrt R$ で割った標準誤差である。
各設定の終了状態は収束した割合の列で示し、セル全体の判定は出さない。

```rust
//| id: interp-aaa-resonance-noise
//| ref: interp-aaa-resonance-noise
//| title: ノイズと許容誤差による減衰幅の推定を反復で比べる
//| run: button
//| uses: [interp-aaa-resonance-model]
//| crates: [scioxide-core, scioxide-interp, scioxide-poly, scioxide-random]

//|   noisy: interp-aaa-resonance-doublets

//|   - case: default
//|     expect:
//|       - {"artifact":"settings","path":"/rows/0/1","equals":0}
//|       - {"artifact":"settings","path":"/rows/0/2","equals":8}
//|       - {"artifact":"settings","path":"/rows/1/1","approx":{"value":0.925,"atol":1e-9}}
//|       - {"artifact":"settings","path":"/rows/1/2","approx":{"value":3.95,"atol":1e-9}}
//|       - {"artifact":"settings","path":"/rows/0/4","approx":{"value":4.8,"atol":1e-3}}

//|   - case: below-noise-maximum

//|       - {"artifact":"settings","path":"/rows/0/5","approx":{"value":1.4697e-4,"rtol":1e-3}}
use scioxide_core::{RealScalar, Tolerance};
use scioxide_interp::{AaaOptions, aaa_with_options};
use scioxide_poly::PolynomialApproximationPolicy;

let number = |key: &str| noisy[key].as_f64().ok_or(format!("{key} がない"));

];

    for (tolerance, record) in tolerances.iter().zip(&mut records) {

            .with_max_terms(8)
            .with_tolerance(*tolerance);

            1.0

// 標本平均と 95% 区間の半幅 1.96 SE（SE = 標本標準偏差 / √R）
let mean_and_half_width = |i: usize, k: usize| {
    let x: Vec<f64> = records[i].iter().map(|r| r[k]).collect();
    let n = x.len() as f64;
    let mean = x.iter().sum::<f64>() / n;
    let variance = x.iter().map(|v| (v - mean) * (v - mean)).sum::<f64>() / (n - 1.0);
    (mean, 1.96 * RealScalar::sqrt(variance / n))
};
let names = ["τ = 10⁻⁹（ノイズより小さい）", "τ = kσ（ノイズの水準）"];
let mut rows = Vec::new();
let mut bars = Vec::new();
for (i, name) in names.into_iter().enumerate() {
    let (width, half) = mean_and_half_width(i, 3);
    let means = [0, 1, 2].map(|k| mean_and_half_width(i, k).0);
    rows.push((
        name,
        means[0],
        means[1],
        means[2],
        width,
        half,
        width - gamma,
    ));
    bars.push([(i + 1) as f64, width, width - half, width + half]);
}
let fixed2 = serde_json::json!({ "fractionDigits": 2 });
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let columns = serde_json::json!([
    { "key": "0", "label": "設定" },
    { "key": "1", "label": "収束した割合 [-]", "type": "number", "format": fixed2 },
    { "key": "2", "label": "平均の支持点数 [-]", "type": "number", "format": fixed2 },
    { "key": "3", "label": "物理的な極以外の極の平均数 [-]", "type": "number", "format": fixed2 },
    { "key": "4", "label": "減衰幅の平均 [cm⁻¹]", "type": "number", "format": { "fractionDigits": 5 } },
    { "key": "5", "label": "減衰幅の 1.96 SE [cm⁻¹]", "type": "number", "format": sci3 },
    { "key": "6", "label": "平均と真値 γ の差 [cm⁻¹]", "type": "number", "format": sci3 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "settings" })
);
emit_chart!(serde_json::json!({
    "kind": "errorbar",
    "xLabel": "設定（1: τ = 10⁻⁹、2: τ = kσ）[-]",
    "yLabel": "推定した減衰幅 γ̂ [cm⁻¹]",
    "xMin": 0.5,
    "xMax": 2.5,
    "series": [{ "name": "平均 ±1.96 SE", "points": bars }],
    "annotations": [{ "kind": "line", "axis": "y", "value": gamma, "label": "真値 γ" }]
}));
```

既定（$\sigma=0.002$、$k=5$、$R=40$、シード 7）では、$\tau=10^{-9}$ の当てはめは一度も収束せず、毎回 8 個の支持点を使って物理的な極のほかに 5 個の極を作る。
$\tau=5\sigma$ では 40 回中 37 回が収束し、平均の支持点数は 3.95、余分な極は平均 0.95 個である。
減衰幅の推定は $4.8000\pm0.0002$ と $4.7999\pm0.0002\ \mathrm{cm}^{-1}$（平均 ±1.96 SE）で、真値との差 $2.0\times10^{-5}$ と $-6.8\times10^{-5}$ cm⁻¹ は区間の半幅より小さい。
この条件では、許容誤差をノイズに合わせる効果は余分な極を減らすことにあり、物理的な極の減衰幅の推定精度はほとんど変わらない。
$k=2$ では $\tau$ がノイズの最大値の目安 $3.1\sigma$ を下回り、40 回すべてが支持点の上限に達して、一つ目の設定と同じ結果になる。
$k=10$ では 40 回すべてが収束し、平均の支持点数は 3.03 になる。

$R=100$ では半幅が $1.47\times10^{-4}$ と $1.44\times10^{-4}$ cm⁻¹ に縮み、平均と真値の差 $-2.1\times10^{-4}$ と $-1.6\times10^{-4}$ cm⁻¹ が半幅をわずかに上回る。
相対 $4\times10^{-5}$ 程度の偏りがある可能性を示すが、偏りがあると結論するにはさらに反復を増やして確かめる。
前のセルで $\sigma$ を 0.001、0.002、0.004 と変えると、$\tau=10^{-9}$ の設定の半幅は $1.07\times10^{-4}$、$2.13\times10^{-4}$、$4.26\times10^{-4}$ cm⁻¹ と $\sigma$ に比例する。
同じシードでは標準正規標本の系列が同じでノイズが $\sigma$ 倍されるだけなので、推定値の誤差がノイズに対して線形に応答する範囲では、半幅も $\sigma$ に比例する。

## 結果を読む順序

最初に終了状態と標本残差を読み、近似が許容誤差を満たしたか、支持点の上限で止まったかを確かめる。
次に、未使用点での誤差と、極の位置・留数を調べる。
二重項を除いた近似は支持点が減るので、標本残差が増えることも、未使用点の誤差が悪化することもある。
除去前後の標本残差だけで採否を決めず、未使用点での誤差も比べる。
実測値だけで真の極が分からない場合は、標本の密度と範囲、ノイズ、許容誤差を変えたときに極の位置が安定しているかを確かめる。
下半平面にない極や、留数が小さく近くに零点がある極は、物理的な共鳴とみなす前に疑う。

## まとめ

Lorentz モデルの誘電関数は 2 次の有理関数であり、極 $p_\pm=-i\gamma/2\pm\sqrt{\nu_T^2-\gamma^2/4}$ と留数を閉形式で持つ。
ノイズなしの標本なら、AAA は標本の間隔より狭い減衰幅を 3 個の支持点で回復し、極と留数が閉形式と丸めの水準で一致する。
許容誤差を丸めの水準より小さくすると、実軸上の誤差はかえって下がっても余分な極が生じるので、実軸上の精度だけで極を信用しない。
ノイズがあるときは、許容誤差をノイズの最大値より大きく取ると余分な極が減るが、物理的な極の推定精度はこの条件ではほとんど変わらない。
`cleanup_doublets` は新しい近似を返すだけなので、除去後の標本残差と未使用点の誤差を比べてから採用を決める。
推定値の比較は一回の乱数系列ではなく、反復の平均と標準誤差で行う。
