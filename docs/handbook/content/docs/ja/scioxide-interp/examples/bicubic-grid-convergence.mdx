[規則格子の温度場を双線形と双 3 次で復元する](../bicubic-temperature-field/)では、決めた格子での誤差の大きさと分布を比べた。
このページでは格子を細かくしたときに誤差がどう減るかを測り、理論の収束次数と比べる。
温度場は同じ単位正方形 $[0,1]^2$ [m] の上の

$$
T(x, y) = 20 + A \sin(m \pi x) \cos(m \pi y) + 0.8 x y\quad[{}^\circ\mathrm C]
$$

で、$A=4$ °C、$m$ は各軸の半波長の数である。
勾配は

$$
\frac{\partial T}{\partial x} = A m \pi \cos(m \pi x) \cos(m \pi y) + 0.8 y, \qquad \frac{\partial T}{\partial y} = -A m \pi \sin(m \pi x) \sin(m \pi y) + 0.8 x\quad[{}^\circ\mathrm C/\mathrm m]
$$

である。

## 理論の収束次数

双線形補間の値の誤差は格子間隔 $h$ について $O(h^2)$ である。
各軸の 1 次補間の誤差 $\tfrac12 s(1-s)h^2 T_{xx}$ が足し合わさるからである。

双 3 次 Hermite 補間は、格子点の値と正確な導関数を与えれば値の誤差が $O(h^4)$、勾配の誤差が $O(h^3)$ になる。
`BicubicInterpolator::new` は導関数を 3 節点の 2 次式で推定し、その誤差は $O(h^2)$ である（等間隔の内側では中心差分で $h^2T_{xxx}/6$）。
局所座標の傾き $hT_x$ の誤差は $O(h^3)$ になり、セルの中の値の誤差に $h^3$ の項を加える。
1 次元で書くと、傾きの誤差 $e$ が両端でほぼ等しいとき、この項は

$$
h\,e\,t(1-t)(1-2t),\qquad t=\frac{x-x_i}{h}\in[0,1]
$$

で、$|t(1-t)(1-2t)|$ の最大は約 0.096 である。
したがって値の誤差は $O(h^3)$、勾配の誤差は $O(h^2)$ と見込まれる。
等間隔の格子の内側では、この構成は Keys（1981）の 3 次たたみ込み補間（$a=-1/2$）のテンソル積と同じで、Keys も値の誤差が $O(h^3)$ であることを示している。
$h^3$ の項の係数は $T_{xxx}$ に、正確な Hermite 補間の $h^4$ の項の係数は $T_{xxxx}$ に比例するので、二つの比はおよそ $m\pi h$ に比例する。
粗い格子では $h^4$ の項の割合が大きく、観測次数は 3 と 4 の間に出ることがある。

次のブロックはこのページの二つのセルが共有する定義である。
`temperature` と `temperature_gradient` が解析場 $T$ と $\nabla T$、`grid_models` が $n\times n$ の等間隔格子の値から作る二つの補間、`validation_points` が検証点に対応する。
解析場の正弦と余弦は `RealScalar::sin`、`RealScalar::cos` で計算する。

```rust
//| id: interp-bicubic-convergence-model
//| kind: definitions
//| title: 解析的な温度場と格子の二つの補間
//| crates: [scioxide-core, scioxide-interp]
use scioxide_core::{SciOxideError, RealScalar};
use scioxide_interp::{BicubicInterpolator, BilinearInterpolator};

/// 振動の振幅 A [°C]。
pub(crate) const AMPLITUDE: f64 = 4.0;

/// T(x, y) = 20 + A sin(mπx) cos(mπy) + 0.8xy [°C]。
pub(crate) fn temperature(m: f64, x: f64, y: f64) -> f64 {
    let w = m * std::f64::consts::PI;
    20.0 + AMPLITUDE * RealScalar::sin(w * x) * RealScalar::cos(w * y) + 0.8 * x * y
}

/// ∇T = (∂T/∂x, ∂T/∂y) [°C/m]。
pub(crate) fn temperature_gradient(m: f64, x: f64, y: f64) -> [f64; 2] {
    let w = m * std::f64::consts::PI;
    [
        AMPLITUDE * w * RealScalar::cos(w * x) * RealScalar::cos(w * y) + 0.8 * y,
        -AMPLITUDE * w * RealScalar::sin(w * x) * RealScalar::sin(w * y) + 0.8 * x,
    ]
}

/// 一軸 n 点の等間隔格子の値（行優先 z[j·n + i] = T(x_i, y_j)）から作る二つの補間。
pub(crate) fn grid_models(
    n: usize,
    m: f64,
) -> Result<(BilinearInterpolator<f64>, BicubicInterpolator<f64>), SciOxideError> {
    let nodes: Vec<f64> = (0..n).map(|i| i as f64 / (n - 1) as f64).collect();
    let values: Vec<f64> = nodes
        .iter()
        .flat_map(|&y| nodes.iter().map(move |&x| temperature(m, x, y)))
        .collect();
    let bilinear = BilinearInterpolator::new(nodes.clone(), nodes.clone(), values.clone())?;
    let bicubic = BicubicInterpolator::new(nodes.clone(), nodes, values)?;
    Ok((bilinear, bicubic))
}

/// 底 base の基数逆関数（van der Corput 列の k 番目の点）。
fn radical_inverse(mut k: usize, base: usize) -> f64 {
    let (mut value, mut scale) = (0.0, 1.0 / base as f64);
    while k > 0 {
        value += (k % base) as f64 * scale;
        k /= base;
        scale /= base as f64;
    }
    value
}

/// 検証点: 底 2 と 3 の Halton 点列の 2000 点 [x, y]。
pub(crate) fn validation_points() -> Vec<[f64; 2]> {
    (1..=2000)
        .map(|k| [radical_inverse(k, 2), radical_inverse(k, 3)])
        .collect()
}
```

## 値の誤差の収束

固定した格子の比較だけでは、誤差が格子の細かさとともにどう減るかはわからない。
次のセルは $m$ を固定し、一軸の節点数を 4 から 55 まで変えて、検証点での値の RMSE を格子間隔 $h = 1/(n-1)$ [m] の関数として測る。
検証点には、底 2 と 3 の Halton 点列（低ディスクレパンシーの点列）の 2000 点を使う。
等間隔の検証格子を使うと、その間隔と補間の格子の間隔の比によっては、セルの中の限られた位置だけを測ることになり、RMSE の推定が格子ごとに偏る。
$h^3$ の誤差はセルの中の位置 $t$ によって符号を変える $t(1-t)(1-2t)$ の形なので、この偏りは観測次数を大きく乱す。
Halton 点列はセルの中の位置を一様に覆うので、この偏りを避けられる。
同じ格子の双 3 次補間で勾配の誤差も測り、次のセルに渡す。
表の観測次数は隣り合う行の $\log(e_1/e_2)/\log(h_1/h_2)$ である。
格子点で与えた値を再現しているかも、格子点での最大の差として確かめる。
グラフは両対数で、点が観測した RMSE、破線が最も細かい格子を通る次数 2 と 3 の傾きの線である。

```rust
//| id: interp-bicubic-value-convergence
//| ref: interp-bicubic-value-convergence
//| title: 格子を細かくしたときの値の誤差の収束次数を測る
//| run: reactive
//| uses: [interp-bicubic-convergence-model]
//| crates: [scioxide-core, scioxide-interp]
//| exports: [spatial_cycles, refinement]
//| inputs:
//|   spatial_cycles: {"type":"range","label":"半波長の数 m [-]","description":"格子が表すべき温度の振動の細かさを変える。","min":1,"max":4,"step":1,"value":2}
//| cases:
//|   - {"id":"fine-oscillation","label":"m = 4","description":"粗い格子で折り返しが起き、観測次数が乱れる。","inputs":{"spatial_cycles":4}}
//|   - {"id":"slow-oscillation","label":"m = 1","description":"振動が緩やかで、粗い格子から理論の次数に近い。","inputs":{"spatial_cycles":1}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"values","path":"/rows/0/3","equals":null}
//|       - {"artifact":"values","path":"/rows/8/3","approx":{"value":2.01,"atol":0.02}}
//|       - {"artifact":"values","path":"/rows/8/5","range":{"min":3.1,"max":3.3}}
//|       - {"artifact":"values","path":"/rows/4/5","range":{"min":3.3,"max":3.5}}
//|       - {"artifact":"values","path":"/rows/8/6","range":{"max":1e-13}}
//|   - case: fine-oscillation
//|     expect:
//|       - {"artifact":"values","path":"/rows/1/2","approx":{"value":1.9987,"atol":1e-3}}
//|       - {"artifact":"values","path":"/rows/1/3","range":{"max":1}}
//|   - case: slow-oscillation
//|     expect:
//|       - {"artifact":"values","path":"/rows/8/5","range":{"min":3.1,"max":3.3}}
use scioxide_core::RealScalar;
use scioxide_interp::{Differentiable, ExtrapolationPolicy, Interpolant};

let m = spatial_cycles.round();
let reject = ExtrapolationPolicy::Reject;
let grid = validation_points();
// refinement の各行: [h, 双線形の RMSE, 双 3 次の RMSE, 勾配誤差の RMS, 勾配誤差の最大]
let (mut rows, mut refinement) = (Vec::new(), Vec::new());
let mut previous: Option<[f64; 3]> = None;
for n in [4_usize, 5, 7, 10, 14, 20, 28, 40, 55] {
    let (bilinear, bicubic) = grid_models(n, m).map_err(|e| e.to_string())?;
    let (mut squared, mut gradient_squared, mut gradient_worst) = ([0.0_f64; 2], 0.0_f64, 0.0_f64);
    for &p in &grid {
        let exact = temperature(m, p[0], p[1]);
        let linear = bilinear.evaluate(p, reject).map_err(|e| e.to_string())?;
        let cubic = bicubic.evaluate(p, reject).map_err(|e| e.to_string())?;
        squared[0] += (linear - exact) * (linear - exact);
        squared[1] += (cubic - exact) * (cubic - exact);
        // 独立な検算に使う解析的な勾配との差のノルム
        let [gx, gy] = bicubic.gradient(p, reject).map_err(|e| e.to_string())?;
        let [ex, ey] = temperature_gradient(m, p[0], p[1]);
        let error = RealScalar::hypot(gx - ex, gy - ey);
        gradient_squared += error * error;
        gradient_worst = gradient_worst.max(error);
    }
    let count = grid.len() as f64;
    let rmse = squared.map(|s| RealScalar::sqrt(s / count));
    // 格子点では与えた値を再現するはず
    let mut node_error = 0.0_f64;
    for j in 0..n {
        for i in 0..n {
            let point = [i as f64 / (n - 1) as f64, j as f64 / (n - 1) as f64];
            let value = bicubic.evaluate(point, reject).map_err(|e| e.to_string())?;
            node_error = node_error.max((value - temperature(m, point[0], point[1])).abs());
        }
    }
    let h = 1.0 / (n - 1) as f64;
    // 最初の行には比べる前の行がないので、観測次数は空欄にする
    let order =
        |now: f64, before: f64, h0: f64| RealScalar::ln(before / now) / RealScalar::ln(h0 / h);
    let orders = previous.map(|[h0, b, c]| (order(rmse[0], b, h0), order(rmse[1], c, h0)));
    previous = Some([h, rmse[0], rmse[1]]);
    let gradient_rms = RealScalar::sqrt(gradient_squared / count);
    refinement.push([h, rmse[0], rmse[1], gradient_rms, gradient_worst]);
    rows.push((n, h, rmse[0], orders.map(|o| o.0), rmse[1], orders.map(|o| o.1), node_error));
}
// 最も細かい格子を通る次数 p の傾きの線（双線形は 2、双 3 次は 3）
let last = refinement[refinement.len() - 1];
let guide = |column: usize, power: f64| -> Vec<[f64; 2]> {
    refinement
        .iter()
        .map(|r| [r[0], last[column] * RealScalar::powf(r[0] / last[0], power)])
        .collect()
};
let points = |column: usize| -> Vec<[f64; 2]> {
    refinement.iter().map(|r| [r[0], r[column]]).collect()
};
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let fixed2 = serde_json::json!({ "fractionDigits": 2 });
let columns = serde_json::json!([
    { "key": "0", "label": "一軸の節点数 n", "type": "integer" },
    {
        "key": "1",
        "label": "格子間隔 h [m]",
        "type": "number",
        "format": { "significantDigits": 4 }
    },
    { "key": "2", "label": "双線形の RMSE [°C]", "type": "number", "format": sci3 },
    {
        "key": "3",
        "label": "双線形の観測次数",
        "type": "number",
        "format": fixed2,
        "nullText": "—"
    },
    { "key": "4", "label": "双 3 次の RMSE [°C]", "type": "number", "format": sci3 },
    {
        "key": "5",
        "label": "双 3 次の観測次数",
        "type": "number",
        "format": fixed2,
        "nullText": "—"
    },
    { "key": "6", "label": "格子点の再現誤差 [°C]", "type": "number", "format": sci3 }
]);
emit_table_with_columns!(columns, rows, metadata = serde_json::json!({ "id": "values" }));
let dashed = serde_json::json!({ "lineType": "dashed", "showSymbol": false });
let marked = serde_json::json!({ "showSymbol": true });
emit_line_chart!(
    &vec![
        serde_json::json!({ "name": "双線形", "points": points(1), "style": marked }),
        serde_json::json!({ "name": "双 3 次", "points": points(2), "style": marked }),
        serde_json::json!({ "name": "次数 2 の傾き", "points": guide(1, 2.0), "style": dashed }),
        serde_json::json!({ "name": "次数 3 の傾き", "points": guide(2, 3.0), "style": dashed }),
    ],
    options = &serde_json::json!({
        "link": { "group": "grid-spacing" },
        "xLabel": "格子間隔 h [m]",
        "yLabel": "値の RMSE [°C]",
        "xType": "log",
        "yType": "log"
    })
);
export!(spatial_cycles, m);
export!(refinement, &refinement);
```

$m=2$ の双線形の観測次数は 1.53 から 2.01 へ上がり、理論の 2 に近づく。
双 3 次の観測次数は粗い格子の 3.05 から $n=14$ の 3.40 まで上がり、そこから細かい格子で 3.20 へ下がる。
上がる部分は、半波長あたり 1.5 間隔以下の粗い格子で、誤差がまだ漸近の形になっていないことによる。
下がる部分は、$h^4$ の項の割合が $m\pi h$ に比例して小さくなり、観測次数が漸近の 3 へ近づく過程である。
観測次数が 3 を上回っても、それは $h^4$ の項が残っていることを示すだけで、漸近の次数が 4 であることを意味しない。
格子点の再現誤差はどの格子でも 0 で、双 3 次補間は格子点の値を正確に通る。

$m=1$ でも双 3 次の観測次数は 3.16 から 3.39 まで上がってから 3.19 へ下がり、同じ形になる。
$m=4$ では粗い格子で次数が乱れ、$n=4$ から 5 への双線形の観測次数は 0.31 になる。
$n=5$ では節点 $x_i=i/4$ のすべてで $\sin(4\pi x_i)=0$ となる折り返しが起き、二つの RMSE はどちらも 1.999 °C で、振動の大きさ $A/2$ で止まる。
半波長あたり 2 間隔を超える $n=10$ 以上で、双 3 次の観測次数は 3 を超える。

## 勾配の誤差の収束

熱流束 $\mathbf q=-k\nabla T$ には勾配の精度が要る。
次のセルは、上のセルが同じ格子と同じ検証点で測った双 3 次補間の `gradient` の誤差を受け取り、解析的な勾配との差のノルム $|\nabla C-\nabla T|$ の二乗平均平方根（RMS）と最大値を、格子間隔の関数として示す。
勾配の単位は °C/m で、熱伝導率 $k$ [W/(m·K)] を掛けると熱流束の誤差 [W/m²] になる。
理論の見込みは 2 次である。
最大値は片側の差分を使う板の縁の近くで大きくなりやすい。
グラフの横軸は上のグラフと連動し、破線は最も細かい格子を通る次数 2 の傾きの線である。

```rust
//| id: interp-bicubic-gradient-convergence
//| ref: interp-bicubic-gradient-convergence
//| title: 格子を細かくしたときの誤差と勾配の収束を見る
//| run: reactive
//| crates: [scioxide-core]
//| dependsOn:
//|   values: interp-bicubic-value-convergence
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"gradients","path":"/rows/0/2","approx":{"value":9.79,"atol":0.01}}
//|       - {"artifact":"gradients","path":"/rows/0/3","equals":null}
//|       - {"artifact":"gradients","path":"/rows/8/3","approx":{"value":2.08,"atol":0.05}}
use scioxide_core::RealScalar;

let m = values["spatial_cycles"]
    .as_f64()
    .ok_or("半波長の数がない")?;
let refinement: Vec<[f64; 5]> =
    serde_json::from_value(values["refinement"].clone()).map_err(|e| e.to_string())?;
// 勾配の振動の大きさ A m π [°C/m]（A = 4 °C）
let scale = 4.0 * m * std::f64::consts::PI;
let mut rows = Vec::new();
for (k, r) in refinement.iter().enumerate() {
    // 最初の行には比べる前の行がないので、観測次数は空欄にする
    let order = (k > 0).then(|| {
        let before = refinement[k - 1];
        RealScalar::ln(before[3] / r[3]) / RealScalar::ln(before[0] / r[0])
    });
    let nodes = (1.0 / r[0]).round() as usize + 1;
    rows.push((nodes, r[0], r[3], order, r[4], r[3] / scale, r[2]));
}
let last = refinement[refinement.len() - 1];
let guide: Vec<[f64; 2]> = refinement
    .iter()
    .map(|r| [r[0], last[3] * RealScalar::powf(r[0] / last[0], 2.0)])
    .collect();
let curve: Vec<[f64; 2]> = refinement.iter().map(|r| [r[0], r[3]]).collect();
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let columns = serde_json::json!([
    { "key": "0", "label": "一軸の節点数 n", "type": "integer" },
    {
        "key": "1",
        "label": "格子間隔 h [m]",
        "type": "number",
        "format": { "significantDigits": 4 }
    },
    { "key": "2", "label": "勾配誤差の RMS [°C/m]", "type": "number", "format": sci3 },
    {
        "key": "3",
        "label": "観測次数",
        "type": "number",
        "format": { "fractionDigits": 2 },
        "nullText": "—"
    },
    { "key": "4", "label": "勾配誤差の最大 [°C/m]", "type": "number", "format": sci3 },
    { "key": "5", "label": "RMS / Amπ [-]", "type": "number", "format": sci3 },
    { "key": "6", "label": "値の RMSE（双 3 次）[°C]", "type": "number", "format": sci3 }
]);
emit_table_with_columns!(columns, rows, metadata = serde_json::json!({ "id": "gradients" }));
emit_line_chart!(
    &vec![
        serde_json::json!({
            "name": "双 3 次の勾配誤差の RMS",
            "points": curve,
            "style": { "showSymbol": true }
        }),
        serde_json::json!({
            "name": "次数 2 の傾き",
            "points": guide,
            "style": { "lineType": "dashed", "showSymbol": false }
        }),
    ],
    options = &serde_json::json!({
        "link": { "group": "grid-spacing" },
        "xLabel": "格子間隔 h [m]",
        "yLabel": "勾配誤差の RMS [°C/m]",
        "xType": "log",
        "yType": "log"
    })
);
```

$m=2$ の勾配誤差の RMS は $n=4$ の 9.79 °C/m から $n=55$ の 0.0186 °C/m まで下がり、観測次数は 2.20 から 2.08 へ下がって見込みの 2 に近づく。
この場の勾配の振動の大きさは $Am\pi\approx25.1$ °C/m なので、$n=7$ の RMS 2.09 °C/m はその 8% にあたる。
$n=55$ でも最大誤差は 0.093 °C/m で、RMS の 5 倍ある。
上のセルで $m=4$ にすると、$n=7$ では RMS が 17.3 °C/m、最大誤差が 48.7 °C/m で、振動の大きさ $Am\pi\approx50.3$ °C/m と同じ程度になり、勾配の向きさえ信用できない。
そのときの値の RMSE は 0.80 °C で、振幅 4 °C に比べて小さく見えても、勾配は大きく外れうる。
熱流束を評価するときは、勾配の誤差を格子の細分化で確かめる。

## まとめ

収束次数は格子を細かくしたときの誤差の比から $\log(e_1/e_2)/\log(h_1/h_2)$ として測る。
この温度場では、双線形の値の誤差は 2 次、導関数を推定した双 3 次の値の誤差は 3 次、勾配の誤差は 2 次で減り、理論の見込みと合う。
粗い格子の双 3 次の観測次数が 3 を上回るのは $h^4$ の項がまだ無視できないためで、漸近の次数は細かい格子での次数の動きから読む。
等間隔の検証格子は補間の格子と干渉して RMSE を偏らせることがあるので、検証点には Halton 点列のような一様に散らばった点を使う。
半波長あたりの格子間隔が少ない粗い格子では次数が乱れ、折り返しの格子では誤差が振動の大きさで止まる。
値の誤差が小さくても勾配の誤差は振動の大きさと同じ程度になりうるので、熱流束が必要なら勾配の誤差を別に確かめる。
