伝熱の数値計算や気象の格子データでは、長方形の格子点に温度 $T(x,y)$ が並んでいる。
格子点の間の温度や、熱流束 $\mathbf q=-k\nabla T$ に必要な勾配 $\nabla T = (\partial T/\partial x, \partial T/\partial y)$ を求めるには、格子の値を補間する。
この例題では 1 m 四方の板の座標 $x,y$ [m] の上に解析的な温度場を置き、格子点の値だけから値と勾配を復元して、解析解と比べる。
格子の細かさと温度場の振動の細かさを変え、誤差の大きさ、分布、折り返しを確かめる。

## 格子と値の並び

格子の座標は $x_0 < x_1 < \dots < x_{n_x-1}$、$y_0 < y_1 < \dots < y_{n_y-1}$ で、間隔は等しくなくてもよい。
`BilinearInterpolator::new(x, y, z)` と `BicubicInterpolator::new(x, y, z)` は、二つの座標軸と行優先に平坦化した値 `z` を受け取る。
`z[j * nx + i]` が $(x_i, y_j)$ の値で、$x$ の添字が先に変わる。
問い合わせ点を含むセル $[x_i, x_{i+1}] \times [y_j, y_{j+1}]$ は各軸の二分探索で $O(\log n_x+\log n_y)$ で見つかり、セルの中の計算は定数の手間で終わる。
大域的な連立方程式は解かない。

## 双線形補間と凸結合

セルの幅を $h_{x,i} = x_{i+1} - x_i$、$h_{y,j} = y_{j+1} - y_j$ とし、セルの中の局所座標

$$
s = \frac{x - x_i}{h_{x,i}}, \qquad t = \frac{y - y_j}{h_{y,j}} \qquad (0 \le s,t \le 1)
$$

を使う。
双線形補間はセルの四隅の値 $z_{00}, z_{10}, z_{01}, z_{11}$（添字は $(s,t)$ の隅）から

$$
B(s, t) = (1 - s)(1 - t) z_{00} + s(1 - t) z_{10} + (1 - s)t z_{01} + st z_{11}
$$

を作る。
重みはどれも非負で和は 1 なので、$B$ は四隅の値の凸結合である。
したがって値は四隅の最小値と最大値の間に収まり、行き過ぎは起こらない。
誤差は滑らかな場に対して格子間隔 $h$ の 2 乗に比例する（$O(h^2)$）。

$B$ はセルの境界で連続（$C^0$ 級）だが、境界に垂直な方向の偏導関数は境界を越えると跳ぶ。
`BilinearInterpolator` は `Differentiable` を実装せず、勾配を返さない。
熱流束のように勾配そのものが必要な量には、次の双 3 次補間を使う。

## 双 3 次 Hermite 補間

双 3 次補間は各セルを 2 変数の 3 次多項式

$$
C(s, t) = \sum_{p=0}^3 \sum_{q=0}^3 a_{pq} s^p t^q
$$

で表す。
16 個の係数はセルの四隅で次の 4 種類の量を指定すると一つに決まる。

1. 値 $T$
2. $x$ 方向の偏導関数を局所座標に直した $T_s = h_{x,i}\,\partial T/\partial x$
3. $y$ 方向の偏導関数を局所座標に直した $T_t = h_{y,j}\,\partial T/\partial y$
4. 交差偏導関数を局所座標に直した $T_{st} = h_{x,i} h_{y,j}\,\partial^2 T/\partial x \partial y$

1 次元の 3 次 Hermite 補間を各軸に掛け合わせると、

$$
C(s, t) = \begin{bmatrix} 1 & s & s^2 & s^3 \end{bmatrix} M \begin{bmatrix}
T_{00} & T_{01} & T_{t,00} & T_{t,01} \\
T_{10} & T_{11} & T_{t,10} & T_{t,11} \\
T_{s,00} & T_{s,01} & T_{st,00} & T_{st,01} \\
T_{s,10} & T_{s,11} & T_{st,10} & T_{st,11}
\end{bmatrix} M^\mathsf{T} \begin{bmatrix} 1 \\ t \\ t^2 \\ t^3 \end{bmatrix},
\qquad
M = \begin{bmatrix}
1 & 0 & 0 & 0 \\
0 & 0 & 1 & 0 \\
-3 & 3 & -2 & -1 \\
2 & -2 & 1 & 1
\end{bmatrix}
$$

と書ける。
$M$ は端点の値と傾き $(p_0,p_1,d_0,d_1)$ を 3 次式の係数に変える行列である。
隣り合うセルは共有する辺の上で同じ値と同じ導関数を使うので、曲面は全体で値と 1 階偏導関数が連続（$C^1$ 級）になる。
2 階偏導関数はセルの境界で跳ぶことがある。

### 格子点の導関数の推定

`BicubicInterpolator::new` には格子点の値だけを渡し、導関数は与えない。
各軸の偏導関数は隣り合う 3 節点を通る 2 次式の導関数で推定する。
内側の節点 $x_i$ では

$$
T_x(x_i, y_j) \approx \frac{h_+}{h_- + h_+} \frac{T(x_i, y_j) - T(x_{i-1}, y_j)}{h_-} + \frac{h_-}{h_- + h_+} \frac{T(x_{i+1}, y_j) - T(x_i, y_j)}{h_+}
$$

となる。
ここで $h_- = x_i - x_{i-1}$、$h_+ = x_{i+1} - x_i$ である。
端の節点では内側の 3 節点を通る片側の 2 次式を使い、節点が 2 個しかない軸では 1 次の差分を使う。
交差偏導関数 $T_{xy}$ は二つの軸の同じ差分を順に掛けたテンソル積で推定する。

この推定は 2 次式までを正確に再現し、滑らかな場では誤差が $O(h^2)$ である。
等間隔の内側の節点では中心差分 $\bigl(T(x_{i+1})-T(x_{i-1})\bigr)/(2h)$ になり、誤差の主要項は $h^2 T_{xxx}/6$ である。
局所座標の傾き $T_s=h\,T_x$ の誤差は $O(h^3)$ になり、Hermite 補間そのものの $O(h^4)$ の誤差より大きい。
そのため、導関数を推定した双 3 次補間の値の誤差は $O(h^3)$、勾配の誤差は $O(h^2)$ と見込まれる。
等間隔の格子の内側のセルでは、この構成は Keys（1981）の 3 次たたみ込み補間（Catmull–Rom 型、$a=-1/2$）のテンソル積と同じで、Keys も値の誤差が $O(h^3)$ であることを示している。
`BicubicInterpolator` は `Differentiable` と `TwiceDifferentiable` を実装し、勾配と Hessian を物理座標で返す。

## 解析的な温度場と標本化

単位正方形 $[0, 1]^2$ [m] の上に、解析的な温度場

$$
T(x, y) = 20 + A \sin(m \pi x) \cos(m \pi y) + 0.8 x y\quad[{}^\circ\mathrm C]
$$

を置く。
$A=4$ °C は振動の振幅、$m$ は各軸の半波長の数で、半波長は $1/m$ m である。
勾配は

$$
\frac{\partial T}{\partial x} = A m \pi \cos(m \pi x) \cos(m \pi y) + 0.8 y, \qquad \frac{\partial T}{\partial y} = -A m \pi \sin(m \pi x) \sin(m \pi y) + 0.8 x\quad[{}^\circ\mathrm C/\mathrm m]
$$

で、振動の部分は $m$ に比例して大きくなる。
定数 20 と $0.8xy$ は双線形補間でも双 3 次補間でも正確に再現されるので、どちらの誤差も振動の部分だけから生じ、$A$ に比例する。

一軸の節点数を $n$ とすると、半波長あたりの格子間隔の数は $(n - 1)/m$ である。
この値が 1 以下になると、格子は振動を表せない。
例えば $m=4$、$n=5$ では節点 $x_i=i/4$ のすべてで $\sin(4\pi x_i)=0$ となり、格子点の値には振動が現れない。
これを折り返し（エイリアシング）と呼び、補間法を変えても失われた振動は戻らない。
標本化定理の条件 $(n-1)/m>1$ は必要条件にすぎず、局所多項式の補間で値や勾配を精度よく求めるには、半波長あたりにさらに多くの間隔が要る。
必要な格子の細かさは格子を細かくしたときの誤差の減り方で確かめる。

次のブロックはこのページの二つのセルが共有する定義である。
`temperature` と `temperature_gradient` が解析場 $T$ と $\nabla T$、`grid_models` が $n\times n$ の等間隔格子の値から作る双線形補間と双 3 次補間、`validation_grid` が $41\times41$ の検証格子に対応する。
解析場の正弦と余弦は `RealScalar::sin`、`RealScalar::cos` で計算する。

```rust
//| id: interp-bicubic-field-model
//| kind: definitions
//| title: 解析的な温度場と格子の二つの補間
//| crates: [scioxide-core, scioxide-interp]
use scioxide_core::{SciOxideError, RealScalar};
use scioxide_interp::{BicubicInterpolator, BilinearInterpolator};

/// 振動の振幅 A [°C]。
pub(crate) const AMPLITUDE: f64 = 4.0;

/// T(x, y) = 20 + A sin(mπx) cos(mπy) + 0.8xy [°C]。
pub(crate) fn temperature(m: f64, x: f64, y: f64) -> f64 {
    let w = m * std::f64::consts::PI;
    20.0 + AMPLITUDE * RealScalar::sin(w * x) * RealScalar::cos(w * y) + 0.8 * x * y
}

/// ∇T = (∂T/∂x, ∂T/∂y) [°C/m]。
pub(crate) fn temperature_gradient(m: f64, x: f64, y: f64) -> [f64; 2] {
    let w = m * std::f64::consts::PI;
    [
        AMPLITUDE * w * RealScalar::cos(w * x) * RealScalar::cos(w * y) + 0.8 * y,
        -AMPLITUDE * w * RealScalar::sin(w * x) * RealScalar::sin(w * y) + 0.8 * x,
    ]
}

/// 一軸 n 点の等間隔格子の値（行優先 z[j·n + i] = T(x_i, y_j)）から作る二つの補間。
pub(crate) fn grid_models(
    n: usize,
    m: f64,
) -> Result<(BilinearInterpolator<f64>, BicubicInterpolator<f64>), SciOxideError> {
    let nodes: Vec<f64> = (0..n).map(|i| i as f64 / (n - 1) as f64).collect();
    let values: Vec<f64> = nodes
        .iter()
        .flat_map(|&y| nodes.iter().map(move |&x| temperature(m, x, y)))
        .collect();
    let bilinear = BilinearInterpolator::new(nodes.clone(), nodes.clone(), values.clone())?;
    let bicubic = BicubicInterpolator::new(nodes.clone(), nodes, values)?;
    Ok((bilinear, bicubic))
}

/// 41×41 の検証格子 [x, y]（x が先に変わる）。
pub(crate) fn validation_grid() -> Vec<[f64; 2]> {
    (0..41 * 41)
        .map(|k| [(k % 41) as f64 / 40.0, (k / 41) as f64 / 40.0])
        .collect()
}
```

## 断面と誤差の大きさの実験

次のセルの入力は一軸の節点数 $n$、半波長の数 $m$、断面の位置 $y^*$ [m] である。
1 つ目の表は $41\times41$ の検証格子での RMSE と最大誤差、2 つ目の表は半波長あたりの間隔の数と RMSE の比、3 つ目の表は断面 $y=y^*$ の 201 点での温度と $\partial T/\partial x$ の最大誤差である。
解析場の値が独立検算で、検証格子は補間の格子点と一致しない点も含む。
上のグラフは $y=y^*$ での温度の断面、下のグラフは同じ断面の $\partial T/\partial x$ で、横軸の位置は二つのグラフで連動する。
双線形補間は勾配を返さないので、下のグラフは双 3 次補間の `gradient` だけを解析的な勾配（破線）と比べる。
このセルは検証格子の符号付きの誤差を、次のセルの誤差の分布の図に渡す。

```rust
//| id: interp-bicubic-temperature-field
//| ref: interp-bicubic-temperature-field
//| title: 格子温度場の解像度と振動数を動かして二手法を比較する
//| run: reactive
//| uses: [interp-bicubic-field-model]
//| crates: [scioxide-core, scioxide-interp]
//| exports: [error_maps]
//| inputs:
//|   grid_node_count: {"type":"range","label":"一軸の節点数 n [点]","description":"格子の間隔 1/(n − 1) を変える。","min":4,"max":14,"step":1,"value":7}
//|   spatial_cycles: {"type":"range","label":"半波長の数 m [-]","description":"格子が表すべき温度の振動の細かさを変える。","min":1,"max":4,"step":1,"value":2}
//|   temperature_section_y: {"type":"range","label":"断面の位置 y* [m]","description":"比較する断面を動かす。","min":0,"max":1,"step":0.05,"value":0.35}
//| cases:
//|   - {"id":"fine-grid","label":"n = 14","description":"格子を細かくすると、双 3 次の利点が大きくなる。","inputs":{"grid_node_count":14}}
//|   - {"id":"aliased","label":"n = 5、m = 4","description":"格子点で振動が 0 になる折り返しで、二つの RMSE が A/2 = 2 °C に近い値で一致する。","inputs":{"grid_node_count":5,"spatial_cycles":4}}
//|   - {"id":"under-resolved","label":"n = 4、m = 4","description":"半波長あたり 0.75 間隔で、双 3 次の RMSE が双線形を上回る。","inputs":{"grid_node_count":4,"spatial_cycles":4}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"errors","path":"/rows/0/1","approx":{"value":0.348,"atol":1e-3}}
//|       - {"artifact":"errors","path":"/rows/1/1","approx":{"value":0.097,"atol":1e-3}}
//|       - {"artifact":"resolution","path":"/rows/0/0","approx":{"value":3,"atol":1e-12}}
//|       - {"artifact":"section","path":"/rows/0/2","approx":{"value":3.146,"atol":0.01}}
//|   - case: fine-grid
//|     expect:
//|       - {"artifact":"errors","path":"/rows/1/1","approx":{"value":0.0071,"atol":1e-4}}
//|   - case: aliased
//|     expect:
//|       - {"artifact":"errors","path":"/rows/0/1","approx":{"value":1.999,"atol":1e-3}}
//|       - {"artifact":"errors","path":"/rows/1/1","approx":{"value":1.999,"atol":1e-3}}
//|   - case: under-resolved
//|     expect:
//|       - {"artifact":"resolution","path":"/rows/0/1","range":{"min":1}}
use scioxide_core::RealScalar;
use scioxide_interp::{Differentiable, ExtrapolationPolicy, Interpolant};

let n = grid_node_count.round() as usize;
let m = spatial_cycles.round();
let (bilinear, bicubic) = grid_models(n, m).map_err(|e| e.to_string())?;
let reject = ExtrapolationPolicy::Reject;

// 独立な検算: 検証格子で解析場との符号付きの誤差 [x, y, 補間値 − 解析値] を測る
let mut maps = [Vec::new(), Vec::new()];
for p in validation_grid() {
    let exact = temperature(m, p[0], p[1]);
    let linear = bilinear.evaluate(p, reject).map_err(|e| e.to_string())?;
    let cubic = bicubic.evaluate(p, reject).map_err(|e| e.to_string())?;
    maps[0].push([p[0], p[1], linear - exact]);
    maps[1].push([p[0], p[1], cubic - exact]);
}
let rmse = maps.each_ref().map(|map| {
    RealScalar::sqrt(map.iter().map(|e| e[2] * e[2]).sum::<f64>() / map.len() as f64)
});
let maximum = maps
    .each_ref()
    .map(|map| map.iter().fold(0.0_f64, |a, e| a.max(e[2].abs())));
let sig3 = serde_json::json!({ "significantDigits": 3 });
emit_table_with_columns!(
    serde_json::json!([
        { "key": "0", "label": "方法" },
        { "key": "1", "label": "RMSE [°C]", "type": "number", "format": sig3 },
        { "key": "2", "label": "最大誤差 [°C]", "type": "number", "format": sig3 }
    ]),
    vec![("双線形", rmse[0], maximum[0]), ("双 3 次", rmse[1], maximum[1])],
    metadata = serde_json::json!({ "id": "errors" })
);
emit_table_with_columns!(
    serde_json::json!([
        {
            "key": "0",
            "label": "半波長あたりの格子間隔の数 (n − 1)/m [-]",
            "type": "number",
            "format": sig3
        },
        {
            "key": "1",
            "label": "RMSE の比（双 3 次 / 双線形）[-]",
            "type": "number",
            "format": sig3
        }
    ]),
    vec![((n - 1) as f64 / m, rmse[1] / rmse[0])],
    metadata = serde_json::json!({ "id": "resolution" })
);

// 断面 y = y* の温度と ∂T/∂x
let y = temperature_section_y;
let (mut exact, mut linear, mut cubic) = (Vec::new(), Vec::new(), Vec::new());
let (mut exact_slope, mut cubic_slope) = (Vec::new(), Vec::new());
for i in 0..=200 {
    let x = f64::from(i) / 200.0;
    exact.push([x, temperature(m, x, y)]);
    linear.push([x, bilinear.evaluate([x, y], reject).map_err(|e| e.to_string())?]);
    cubic.push([x, bicubic.evaluate([x, y], reject).map_err(|e| e.to_string())?]);
    exact_slope.push([x, temperature_gradient(m, x, y)[0]]);
    cubic_slope.push([x, bicubic.gradient([x, y], reject).map_err(|e| e.to_string())?[0]]);
}
// 断面での最大誤差: 温度（二つの方法）と ∂T/∂x（双 3 次）
let worst = |curve: &[[f64; 2]], reference: &[[f64; 2]]| {
    curve
        .iter()
        .zip(reference)
        .fold(0.0_f64, |w, (c, r)| w.max((c[1] - r[1]).abs()))
};
emit_table_with_columns!(
    serde_json::json!([
        { "key": "0", "label": "双線形の温度の最大誤差 [°C]", "type": "number", "format": sig3 },
        { "key": "1", "label": "双 3 次の温度の最大誤差 [°C]", "type": "number", "format": sig3 },
        {
            "key": "2",
            "label": "双 3 次の ∂T/∂x の最大誤差 [°C/m]",
            "type": "number",
            "format": sig3
        }
    ]),
    vec![(worst(&linear, &exact), worst(&cubic, &exact), worst(&cubic_slope, &exact_slope))],
    metadata = serde_json::json!({ "id": "section" })
);
let dashed = serde_json::json!({ "lineType": "dashed", "showSymbol": false });
emit_line_chart!(
    &vec![
        serde_json::json!({ "name": "解析場", "points": exact, "style": dashed }),
        serde_json::json!({ "name": "双線形", "points": linear }),
        serde_json::json!({ "name": "双 3 次", "points": cubic }),
    ],
    options = &serde_json::json!({
        "link": { "group": "plate-x" },
        "xLabel": "位置 x [m]",
        "yLabel": "温度 T(x, y*) [°C]"
    })
);
emit_line_chart!(
    &vec![
        serde_json::json!({ "name": "解析的な ∂T/∂x", "points": exact_slope, "style": dashed }),
        serde_json::json!({ "name": "双 3 次の ∂C/∂x", "points": cubic_slope }),
    ],
    options = &serde_json::json!({
        "link": { "group": "plate-x" },
        "xLabel": "位置 x [m]",
        "yLabel": "勾配 ∂T/∂x(x, y*) [°C/m]"
    })
);
export!(error_maps, &maps);
```

既定の $n=7$、$m=2$（半波長あたり 3 間隔）では、RMSE は双線形が 0.348 °C、双 3 次が 0.0966 °C で、比は 0.28 である。
最大誤差は双線形が 0.88 °C、双 3 次が 0.30 °C である。
$n=14$（6.5 間隔）では RMSE は 0.0789 °C と 0.0071 °C になり、比は 0.090 まで下がる。
格子を細かくするほど双 3 次の利点が大きくなるのは、二つの方法の収束次数が 2 と 3 で違うためである。
断面 $y^*=0.35$ m では、双 3 次の $\partial T/\partial x$ の最大誤差は 3.15 °C/m で、この断面の振動の振幅 $Am\pi|\cos(m\pi y^*)|\approx14.8$ °C/m の約 2 割になる。
温度の最大誤差 0.11 °C が振幅 4 °C の 3% 程度であるのに比べて、勾配の相対誤差はずっと大きい。
$n=14$ では勾配の最大誤差は 1.05 °C/m まで下がる。
縁の断面 $y^*=0$ では、片側の差分の影響で 6.04 °C/m に増える。

半波長あたり 1.5 間隔の $n=7$、$m=4$ では比は 0.71、$n=4$、$m=2$ では 0.78 まで上がり、双 3 次の利点はほとんど失われる。
$n=4$、$m=4$（0.75 間隔）では双 3 次の RMSE 2.42 °C が双線形の 2.18 °C を上回る。
$n=5$、$m=4$ では二つの RMSE がどちらも 1.999 °C で一致する。
格子点で振動が 0 になる折り返しの例で、どちらの補間も $20+0.8xy$ を正確に再現し、誤差は振動の全体 $-A\sin(4\pi x)\cos(4\pi y)$ になる。
その RMSE は連続な正方形の上では $A/2=2$ °C で、表の値はこの既知値と一致する。
断面の位置 $y^*$ はグラフと 3 つ目の表だけを変え、上の二つの表の値は変えない。

## 誤差の分布の実験

誤差がどこに集まるかを見るため、次のセルは上のセルが渡す検証格子の符号付きの誤差（補間値 − 解析値）を二つの heatmap に描く。
上のセルの入力を変えると、この図も同じ条件で描き直される。
二つの図は同じ対称な色の範囲を使い、0 を中間色にする。
格子点の位置は、誤差が 0 に戻る点として見える。
表は各方法の最大誤差の値と位置である。

```rust
//| id: interp-bicubic-error-maps
//| ref: interp-bicubic-error-maps
//| title: 双線形と双 3 次の誤差の分布を heatmap で比べる
//| run: reactive
//| crates: []
//| dependsOn:
//|   field: interp-bicubic-temperature-field
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"worst","path":"/rows/0/2","approx":{"value":0.25,"atol":1e-9}}
//|       - {"artifact":"worst","path":"/rows/1/3","approx":{"value":0.075,"atol":1e-9}}
let maps: [Vec<[f64; 3]>; 2] =
    serde_json::from_value(field["error_maps"].clone()).map_err(|e| e.to_string())?;
// 二つの図で同じ対称な色の範囲を使う
let limit = maps
    .iter()
    .flatten()
    .fold(f64::MIN_POSITIVE, |acc, p| acc.max(p[2].abs()));
let names = ["双線形", "双 3 次"];
let rows: Vec<(&str, f64, f64, f64)> = names
    .iter()
    .zip(&maps)
    .map(|(&name, map)| {
        let worst = map
            .iter()
            .fold([0.0_f64, 0.0, 0.0], |w, &e| if e[2].abs() > w[2].abs() { e } else { w });
        (name, worst[2], worst[0], worst[1])
    })
    .collect();
let fixed3 = serde_json::json!({ "fractionDigits": 3 });
emit_table_with_columns!(
    serde_json::json!([
        { "key": "0", "label": "方法" },
        {
            "key": "1",
            "label": "最大の誤差 [°C]",
            "type": "number",
            "format": { "significantDigits": 3 }
        },
        { "key": "2", "label": "その x [m]", "type": "number", "format": fixed3 },
        { "key": "3", "label": "その y [m]", "type": "number", "format": fixed3 }
    ]),
    rows,
    metadata = serde_json::json!({ "id": "worst" })
);
for (map, name) in maps.iter().zip(names) {
    emit_chart!(
        serde_json::json!({
            "kind": "heatmap",
            "data": map,
            "xLabel": "位置 x [m]",
            "yLabel": "位置 y [m]",
            "colorScale": "diverging",
            "center": 0.0,
            "colorMin": -limit,
            "colorMax": limit,
            "tooltip": true,
            "style": { "animation": false }
        }),
        metadata = serde_json::json!({ "title": format!("{name}の誤差 [°C]") })
    );
}
```

既定の $n=7$、$m=2$ では、どちらの最大誤差も振動の山 $(0.25,0)$ に近い $(0.25,0.075)$ にあり、符号は負である。
補間は格子点の間で山の頂を低く見積もり、曲率の大きい山と谷の付近に誤差が集まる。
上のセルで $n=14$ にすると、双 3 次の最大誤差 0.025 °C は縁の $(0.025,0)$ に移る。
縁の格子点では片側の 2 次式で導関数を推定するので、内側の中心差分より誤差が大きい。
双線形の最大誤差 0.22 °C は内側の $(0.275,0.5)$ に残る。
$n=5$、$m=4$ では二つの図が同じになり、振動の全体がそのまま誤差として現れ、最大誤差は $(0.125,0)$ での $-4$ °C $=-A$ である。

## まとめ

格子補間では値の誤差と勾配の誤差を別々に測る。
双線形補間は四隅の値の範囲を出ないが、勾配を返さない。
双 3 次補間は勾配と Hessian を返すが、格子点の導関数を 3 節点の 2 次式で推定するので、誤差は縁の近くで大きくなりやすい。
半波長あたりの格子間隔が 1 以下の振動は格子点の値から失われ、どの補間でも戻らない。
必要な格子の細かさは解析解か格子の細分化で誤差の減り方を確かめて決める。
