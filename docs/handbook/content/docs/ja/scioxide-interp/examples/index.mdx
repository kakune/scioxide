補間では、標本の間で何を推定したいかによって必要な性質が変わる。
各例題は入力の単位とモデルを固定し、補間器の出力を解析解・既知値・別の計算と比べる。
図の滑らかさだけで精度を判断せず、表の誤差と終了状態も読む。

## 例題と検算

| 題材 | 使う API | 独立検算 |
|---|---|---|
| [単調な校正表](./monotone-calibration/) | `PchipInterpolator`（`slopes`、`derivative_at`）、`CubicSpline::with_boundary`（`Natural`） | Fritsch–Butland の規則による節点の傾きの手計算、二分法による逆校正と `derivative_at` の感度による 1 次の予測 |
| [日射強度の積算](./solar-energy/) | `CubicSpline::with_boundary`（`Natural`）、`PchipInterpolator`、`integrate`、`prepare_antiderivative` | 節点の傾きから作る台形則との差の式、非負性、準備した原始関数と `integrate` の一致（微積分の基本定理） |
| [日射モデルの積算の収束次数](./solar-sine-convergence/) | `CubicSpline::with_boundary`（`Natural`、`NotAKnot`）、`integrate` | 太陽高度のモデルの日積算 $19200/\pi$ Wh/m² と、Euler–Maclaurin の主要項から見込んだ次数と観測次数の比較 |
| [散在センサーの地形](./rbf-terrain/) | `RbfInterpolator::with_options`、`RbfOptions`、`RbfKernel::Gaussian`、`RbfRegularization`、`conditioning` | 既知の地形との検証格子の誤差とその分布、形状係数の走査での標本点の残差と検証誤差 |
| [格子の温度場](./bicubic-temperature-field/) | `BilinearInterpolator`、`BicubicInterpolator`（`gradient`） | 解析場の値と勾配、誤差の分布、折り返しでの RMSE $\approx A/2$ |
| [格子の温度場の収束次数](./bicubic-grid-convergence/) | `BilinearInterpolator`、`BicubicInterpolator`（`gradient`） | 格子の細分化による値と勾配の誤差の観測次数と、理論の次数（双線形の値 2、双 3 次の値 3、勾配 2） |
| [誘電関数の共鳴の極](./aaa-resonance-poles/) | `aaa_with_options`、`AaaOptions`、`BarycentricRational`（`poles`、`diagnostics`）、`RationalTermination` | 6H-SiC の Lorentz モデルの極と留数の閉形式、標本と重ならない点の誤差、ノイズの反復による減衰幅の平均と 1.96 SE |
| [ノイズのある位置からの微分](./noisy-velocity-smoothing/) | `CubicSpline`、`PenalizedSplinePlan`、`fit_parametric_spline_with_options`、`SplineFitTarget` | 自由落下の解析的な速度と加速度、補間の加速度誤差の理論 RMS、反復による重力加速度の平均と SE |
| [球面の気温と全球平均](./spherical-temperature/) | `fit_spherical_spline_with_options`、`SphericalSamples`、`SphericalSplinePlan`、`integral` | 除いた観測点の RMSE と SE、合成場の厳密な全球平均、Lebedev 則（scioxide-integrate） |
| [Franke 関数の交差検証](./station-cross-validation/) | `RbfInterpolator`（`conditioning`）、`CloughTocherInterpolator::with_options`、`ScatteredValues` | 内部点の一つ抜き誤差と独立格子の誤差の Spearman 順位相関、RBF と Clough–Tocher の二乗誤差の差の平均と 1.96 SE |
| [緩和曲線の曲率](./track-curvature/) | `fit_parametric_spline_with_options`、`CurveParameterization`、`PchipInterpolator`、`physical_difference_derivative`（scioxide-differentiate） | Fresnel 積分（scioxide-special）で作るクロソイドの解析的な曲率 $s/A^2$、つなぎ目の両側の曲率差 |

## 操作入力と比較

最初に既定値で結果の大きさを確認する。
次に一つの入力を変え、どの誤差や制約が変わるかを比べる。
乱数を使う例題ではシードを変えたときのばらつきを見て、反復の標準誤差（SE）と比べる。
標本数や格子の細かさを増やすときは、誤差の減り方（観測次数）と、行列の条件や計算量の変化を併せて確かめる。

真値が分かる人工の場やモデルは、実測値では得られない真の誤差を測るために使う。
そこで確かめた精度を、ほかの点配置やノイズにそのまま一般化しない。
定義域外の値や未収束の部分結果は、それぞれの例題が示した条件の下でだけ読む。

## まとめ

例題ごとに、値・導関数・積分・極・曲率のどれを求めるかを先に決める。
入力を変えたときは、独立検算の値がどう変わるかを比べる。
標本での一致だけで判断せず、未使用点の誤差や、単調性・非負性のような保つべき性質を確かめる。
