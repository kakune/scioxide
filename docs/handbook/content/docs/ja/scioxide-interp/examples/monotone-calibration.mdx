校正表は既知の入力濃度とそのときのセンサー出力を対応させる表である。
対象の範囲で応答が単調増加すると仮定し、

$$
x_0<x_1<\cdots<x_n,\qquad y_0\le y_1\le\cdots\le y_n
$$

を満たす標本を扱う。
補間曲線も各区間で単調なら、標本にない極大・極小は現れない。
逆校正で一つの出力から濃度を一意に戻すには、対象範囲で補間曲線が狭義に単調でなければならない。
平坦な区間では同じ出力に複数の濃度が対応しうるので、広義の単調性だけでは一意性は得られない。
この例題では、同じ校正表を自然 3 次スプラインと PCHIP で補間し、値の単調性、節点の傾き、逆校正の一意性と感度を順に比べる。

## 校正表と記号

この例の校正表は説明のために作った値で、出典のある実測値ではない。
入力濃度 $x$ の単位は mmol/L、センサー出力 $y$ の単位は mV とし、5 点の節点を等間隔に置く。

| 節点 $i$ | 0 | 1 | 2 | 3 | 4 |
|---|---|---|---|---|---|
| 濃度 $x_i$ [mmol/L] | 0 | 1 | 2 | 3 | 4 |
| 出力 $y_i$ [mV] | 0 | 0.8 | $0.8+\Delta_2$ | 2.7 | $2.7+\Delta_4$ |

$\Delta_2=y_2-y_1$ を中央の増分、$\Delta_4=y_4-y_3$ を終端の増分と呼ぶ。
$\Delta_2$ を小さくすると、急な区間の間に平坦に近い区間ができる。
区間 $[x_i,x_{i+1}]$ の幅を $h_i=x_{i+1}-x_i$、割線の傾きを

$$
\delta_i = \frac{y_{i+1} - y_i}{h_i}
$$

と書く。
この表では $h_i=1$ mmol/L なので、$\delta_i$ [mV/(mmol/L)] の数値は各区間の増分 [mV] に等しい。

次のブロックはこのページの三つのセルが共有する定義である。
`CONCENTRATIONS` が節点の濃度 $x_i$、`calibration_outputs` が出力 $y_i$、`calibration_models` が同じ表から作る PCHIP と自然 3 次スプラインに対応する。

```rust
//| id: interp-monotone-model
//| kind: definitions
//| title: 校正表と二つの補間
//| crates: [scioxide-core, scioxide-interp]
use scioxide_core::SciOxideError;
use scioxide_interp::{CubicSpline, PchipInterpolator, SplineBoundary};

/// 節点の濃度 x_i [mmol/L]。等間隔で h_i = 1。
pub(crate) const CONCENTRATIONS: [f64; 5] = [0.0, 1.0, 2.0, 3.0, 4.0];

/// センサー出力 y_i [mV]（説明用の値）。Δ₂ = y₂ − y₁、Δ₄ = y₄ − y₃。
pub(crate) fn calibration_outputs(central: f64, terminal: f64) -> Vec<f64> {
    vec![0.0, 0.8, 0.8 + central, 2.7, 2.7 + terminal]
}

/// 同じ校正表の PCHIP と自然 3 次スプライン（両端で S″ = 0）。
pub(crate) fn calibration_models(
    central: f64,
    terminal: f64,
) -> Result<(PchipInterpolator<f64>, CubicSpline<f64>), SciOxideError> {
    let nodes = CONCENTRATIONS.to_vec();
    let outputs = calibration_outputs(central, terminal);
    let pchip = PchipInterpolator::new(nodes.clone(), outputs.clone())?;
    let natural = CubicSpline::with_boundary(nodes, outputs, SplineBoundary::Natural)?;
    Ok((pchip, natural))
}
```

## 自然 3 次スプラインの行き過ぎ

自然 3 次スプラインは節点の間を 3 次多項式で結び、全域で 2 階導関数まで連続（$C^2$ 級）にする。
両端では 2 階導関数を 0 とする。
2 階導関数が二乗可積分で標本を通る関数のうち、

$$
J(S) = \int_{x_0}^{x_n} S''(x)^2\,dx
$$

を最小にするのが自然 3 次スプラインである（Holladay の定理、de Boor の第 V 章）。
この意味で曲がり方の少ない補間であるが、値の範囲や傾きの符号を保つ条件は含まない。

節点の 2 階導関数は全節点を結ぶ三重対角方程式で決まるので、ある区間の急な変化が離れた区間の形にも影響する。
割線の傾きが急な区間から平坦な区間へ大きく変わると、平坦な区間の近くで $S'(x)<0$ となり、標本にない極大・極小が現れることがある。
これを行き過ぎ（overshoot）と呼ぶ。
標本値が単調でも、スプラインの値は標本値の範囲を出ることがある。

## PCHIP の傾きと Fritsch–Carlson の条件

区分 3 次 Hermite 補間（PCHIP）は、節点で値と 1 階導関数だけを連続にする $C^1$ 級の区分 3 次曲線である。
2 階導関数の連続性を求めない代わりに、各節点の傾きを近くの標本だけから決め、単調性を保つ。

区間 $[x_i,x_{i+1}]$ で $t=(x-x_i)/h_i\in[0,1]$ とおく。
端点の値 $y_i,y_{i+1}$ と端点の傾き $d_i,d_{i+1}$ を与えると、3 次 Hermite 多項式は

$$
p_i(t) = (2t^3 - 3t^2 + 1) y_i + (t^3 - 2t^2 + t) h_i d_i + (-2t^3 + 3t^2) y_{i+1} + (t^3 - t^2) h_i d_{i+1}
$$

と書ける。
$\delta_i>0$ の区間で、端の傾きを割線で割った $\alpha_i=d_i/\delta_i$、$\beta_i=d_{i+1}/\delta_i$ を使うと、$p_i'(x)/\delta_i$ は $\alpha_i,\beta_i$ だけで決まる $t$ の 2 次式になる。
Fritsch と Carlson（1980）は、この 2 次式が $[0,1]$ で非負になる $(\alpha_i,\beta_i)$ の領域を求めた。
$\alpha_i\ge0$、$\beta_i\ge0$ は必要条件で、正方形 $0\le\alpha_i,\beta_i\le3$ はこの領域に含まれる十分条件である。
$\delta_i=0$ の平坦な区間では、両端の傾きを 0 にすれば区間の中で値が一定になる。
領域の全体と導出は[PCHIP・三次スプライン・Akima](../../algorithms/pchip-and-splines/)にある。

### 節点の傾きの決め方

`PchipInterpolator` は各成分について、節点の傾きを次の規則で決める。

1. 内側の節点で $\delta_{i-1}\delta_i\le0$ のとき、$x_i$ はデータの極値か平坦部の端なので $d_i=0$ とする。
2. 内側の節点で $\delta_{i-1}\delta_i>0$ のとき、区間幅で重みを付けた調和平均（Fritsch–Butland の式、Brodlie の重み）を使う。
   $$
   d_i = \frac{w_1 + w_2}{\dfrac{w_1}{\delta_{i-1}} + \dfrac{w_2}{\delta_i}}, \qquad w_1 = 2h_i + h_{i-1}, \quad w_2 = h_i + 2h_{i-1}
   $$
3. 左端では、最初の 3 節点を通る 2 次式の $x_0$ での傾き

   $$
   d_0=\frac{(2h_0+h_1)\delta_0-h_0\delta_1}{h_0+h_1}=\delta_0+\frac{h_0}{h_0+h_1}(\delta_0-\delta_1)
   $$

   を作る。
   その符号が $\delta_0$ と異なれば $d_0=0$ にし、$\delta_0$ と $\delta_1$ の符号が異なり $|d_0|>3|\delta_0|$ なら $d_0=3\delta_0$ に制限する。
   右端は $\delta_{n-1},\delta_{n-2}$ と $h_{n-1},h_{n-2}$ で同じ規則を使う。

調和平均は小さい方の割線に引き寄せられ、$0<d_i\le3\min(\delta_{i-1},\delta_i)$ を満たす。
したがって内側の区間の $(\alpha_i,\beta_i)$ は上の正方形に入り、急な区間の傾きが平坦な区間へ持ち込まれない。
端の式は、割線の符号が同じなら $|d_0|<2|\delta_0|$ で、符号が変わる場合は制限によって正方形に入る。
準備の計算量は節点数 $n$ に対して $O(n)$、値と導関数の評価は区間の二分探索を含めて $O(\log n)$ である。
求めた傾きは `slopes()` で読める。

## 値の単調性を比べる実験

次のセルは中央の増分 $\Delta_2$ と終端の増分 $\Delta_4$ を入力として、PCHIP と自然 3 次スプラインを $[0,4]$ の 241 点で評価する。
`value_at` は `ExtrapolationPolicy::Reject` で評価するので、校正域の外の点はエラーになる。
表は、隣り合う評価点で値が下がる組の数、校正値の範囲 $[y_0,y_4]$ を出る評価点の数、評価点での最小値と最大値である。
グラフの網掛けは校正値の範囲で、単調な補間の曲線はこの範囲を出ない。
このセルの $\Delta_2$ と $\Delta_4$ は、下の二つのセルにも渡す。

```rust
//| id: interp-monotone-calibration
//| ref: interp-monotone-calibration
//| title: 単調校正表の増分を動かして PCHIP と自然 spline を比較する
//| run: reactive
//| uses: [interp-monotone-model]
//| crates: [scioxide-interp]
//| exports: [central_increment, terminal_increment]
//| inputs:
//|   central_increment: {"type":"range","label":"中央の増分 Δ₂ = y₂ − y₁ [mV]","description":"急な区間に挟まれた区間の傾きを変える。","min":0.05,"max":1.6,"step":0.05,"value":0.1}
//|   terminal_increment: {"type":"range","label":"終端の増分 Δ₄ = y₄ − y₃ [mV]","description":"最後の区間の傾きと右端の傾きを変える。","min":0.05,"max":1.2,"step":0.05,"value":0.3}
//| cases:
//|   - {"id":"flat-middle","label":"Δ₂ = 0.05 mV","description":"中央の区間がさらに平坦になり、スプラインの値の下がる組が増える。","inputs":{"central_increment":0.05}}
//|   - {"id":"steep-end","label":"Δ₄ = 1.2 mV","description":"右端の区間が急になり、スプラインの範囲外の点はなくなるが、値の下がる組は残る。","inputs":{"terminal_increment":1.2}}
//|   - {"id":"gentle-middle","label":"Δ₂ = 1.6 mV","description":"割線の変化が小さくなり、スプラインも単調になる。","inputs":{"central_increment":1.6}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"monotonicity","path":"/rows/0/1","equals":0}
//|       - {"artifact":"monotonicity","path":"/rows/0/2","equals":0}
//|       - {"artifact":"monotonicity","path":"/rows/1/1","equals":56}
//|       - {"artifact":"monotonicity","path":"/rows/1/2","equals":39}
//|       - {"artifact":"monotonicity","path":"/rows/1/4","approx":{"value":3.0600,"atol":5e-4}}
//|   - case: flat-middle
//|     expect:
//|       - {"artifact":"monotonicity","path":"/rows/0/1","equals":0}
//|       - {"artifact":"monotonicity","path":"/rows/1/1","equals":60}
//|   - case: steep-end
//|     expect:
//|       - {"artifact":"monotonicity","path":"/rows/1/1","equals":31}
//|       - {"artifact":"monotonicity","path":"/rows/1/2","equals":0}
//|   - case: gentle-middle
//|     expect:
//|       - {"artifact":"monotonicity","path":"/rows/1/1","equals":0}
//|       - {"artifact":"monotonicity","path":"/rows/0/1","equals":0}
use scioxide_interp::Univariate;

let (pchip, natural) =
    calibration_models(central_increment, terminal_increment).map_err(|e| e.to_string())?;
let outputs = calibration_outputs(central_increment, terminal_increment);
let (lowest, highest) = (outputs[0], outputs[4]);

// 校正域 [0, 4] mmol/L の 241 点で値を評価する
let (mut pchip_curve, mut natural_curve) = (Vec::new(), Vec::new());
for i in 0..=240 {
    let x = 4.0 * f64::from(i) / 240.0;
    pchip_curve.push([x, pchip.value_at(x).map_err(|e| e.to_string())?]);
    natural_curve.push([x, natural.value_at(x).map_err(|e| e.to_string())?]);
}
// 隣り合う評価点での減少、校正値の範囲 [y₀, y₄] を出る点、評価点での最小値と最大値
let summary = |name: &str, curve: &[[f64; 2]]| {
    let decreases = curve.windows(2).filter(|p| p[1][1] < p[0][1]).count();
    let outside = curve
        .iter()
        .filter(|p| p[1] < lowest || p[1] > highest)
        .count();
    let minimum = curve.iter().map(|p| p[1]).fold(f64::INFINITY, f64::min);
    let maximum = curve.iter().map(|p| p[1]).fold(f64::NEG_INFINITY, f64::max);
    (name.to_string(), decreases, outside, minimum, maximum)
};
let fixed3 = serde_json::json!({ "fractionDigits": 3 });
let columns = serde_json::json!([
    { "key": "0", "label": "方法" },
    { "key": "1", "label": "値が下がる隣接点の組 [組]", "type": "integer" },
    { "key": "2", "label": "範囲外の評価点 [点]", "type": "integer" },
    { "key": "3", "label": "最小値 [mV]", "type": "number", "format": fixed3 },
    { "key": "4", "label": "最大値 [mV]", "type": "number", "format": fixed3 }
]);
emit_table_with_columns!(
    columns,
    vec![
        summary("PCHIP", &pchip_curve),
        summary("自然 3 次スプライン", &natural_curve),
    ],
    metadata = serde_json::json!({ "id": "monotonicity" })
);

let samples: Vec<[f64; 2]> = CONCENTRATIONS
    .iter()
    .zip(&outputs)
    .map(|(&x, &y)| [x, y])
    .collect();
emit_line_chart!(
    &vec![
        serde_json::json!({ "name": "PCHIP", "points": pchip_curve }),
        serde_json::json!({ "name": "自然 3 次スプライン", "points": natural_curve }),
        serde_json::json!({
            "name": "校正節点",
            "points": samples,
            "style": { "lineType": "dotted", "showSymbol": true, "symbol": "diamond" }
        }),
    ],
    options = &serde_json::json!({
        "link": { "group": "calibration-concentration" },
        "xLabel": "入力濃度 x [mmol/L]",
        "yLabel": "センサー出力 y [mV]",
        "annotations": [
            { "kind": "range", "axis": "y", "from": lowest, "to": highest, "label": "校正値の範囲" }
        ]
    })
);
export!(central_increment, central_increment);
export!(terminal_increment, terminal_increment);
```

既定の $\Delta_2=0.1$ mV、$\Delta_4=0.3$ mV では、自然 3 次スプラインは 56 組の隣接点で値が下がり、39 点で校正値の範囲を出る。
値が下がるのは区間 $[1,2]$ の前半（$1.08\le x\le1.62$）と右端の手前（$x\ge3.63$）で、範囲外の点はすべて $3.35\le x\le3.98$ にあり、最大 3.060 mV まで $y_4=3.0$ mV を超える。
$\Delta_2=0.05$ mV では値の下がる組が 60 に、$\Delta_4=0.05$ mV では 66 に増える。
$\Delta_4=1.2$ mV では範囲外の点はなくなるが、31 組で値が下がる。
$\Delta_2=1.6$ mV にすると割線の傾きの変化が小さくなり、スプラインも単調になる。
PCHIP はどの入力でも、値の下がる組も範囲外の点も 0 である。
評価点の間隔は 1/60 mmol/L なので、この表はそれより狭い範囲の減少を数えない。
減少の有無を連続な $x$ で確かめるには、次のセルの導関数の符号を見る。

## 節点の傾きと感度の検算

次のセルは上のセルの $\Delta_2$ と $\Delta_4$ を受け取り、PCHIP の節点の傾き `slopes()` と、二つの補間の導関数 $dy/dx$ を `derivative_at` で読む。
導関数は濃度あたりの出力の変化で、センサーの局所感度 [mV/(mmol/L)] にあたる。
1 つ目の表は独立検算で、上の傾きの規則を区間幅 $h_i$ を含む一般の形のまま f64 の四則演算で計算し、`slopes()` との差を示す。
2 つ目の表は各区間の割線 $\delta_i$ と比 $\alpha_i=d_i/\delta_i$、$\beta_i=d_{i+1}/\delta_i$ で、どの区間でも正方形 $[0,3]^2$ に入ることを確かめる。
3 つ目の表は 241 点で評価した感度の最小値とその濃度である。
グラフの横軸は上のセルのグラフと連動し、0 の線より下ではその補間の値が濃度とともに減る。

```rust
//| id: interp-monotone-slopes
//| ref: interp-monotone-slopes
//| title: PCHIP の節点の傾きを手計算と比べ、局所感度を描く
//| run: reactive
//| uses: [interp-monotone-model]
//| crates: [scioxide-interp]
//| dependsOn:
//|   table: interp-monotone-calibration
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"slopes","path":"/rows/0/2","approx":{"value":1.15,"atol":1e-12}}
//|       - {"artifact":"slopes","path":"/rows/1/2","approx":{"value":0.17777777777777778,"atol":1e-12}}
//|       - {"artifact":"slopes","path":"/rows/4/2","equals":0}
//|       - {"artifact":"slopes","path":"/rows/3/4","range":{"min":-1e-15,"max":1e-15}}
//|       - {"artifact":"ratios","path":"/rows/1/3","approx":{"value":1.8947368421052628,"atol":1e-12}}
//|       - {"artifact":"sensitivity","path":"/rows/0/1","approx":{"value":0,"atol":1e-12}}
//|       - {"artifact":"sensitivity","path":"/rows/1/1","approx":{"value":-0.236,"atol":1e-3}}
use scioxide_interp::Univariate;

let central = table["central_increment"]
    .as_f64()
    .ok_or("中央の増分がない")?;
let terminal = table["terminal_increment"]
    .as_f64()
    .ok_or("終端の増分がない")?;
let (pchip, natural) = calibration_models(central, terminal).map_err(|e| e.to_string())?;
let x = CONCENTRATIONS;
let y = calibration_outputs(central, terminal);
let h: Vec<f64> = x.windows(2).map(|p| p[1] - p[0]).collect();
let delta: Vec<f64> = (0..4).map(|i| (y[i + 1] - y[i]) / h[i]).collect();

// 独立検算: 片側 3 点の 2 次式の傾きを、符号と大きさで制限する
let end_slope = |d1: f64, d2: f64, h1: f64, h2: f64| {
    let proposal = d1 + h1 / (h1 + h2) * (d1 - d2);
    if proposal * d1 <= 0.0 {
        0.0
    } else if d1 * d2 < 0.0 && proposal.abs() > 3.0 * d1.abs() {
        3.0 * d1
    } else {
        proposal
    }
};
let mut expected = vec![end_slope(delta[0], delta[1], h[0], h[1])];
for i in 1..4 {
    // 同符号なら重み付き調和平均、それ以外は 0
    let (w1, w2) = (2.0 * h[i] + h[i - 1], h[i] + 2.0 * h[i - 1]);
    expected.push(if delta[i - 1] * delta[i] > 0.0 {
        (w1 + w2) / (w1 / delta[i - 1] + w2 / delta[i])
    } else {
        0.0
    });
}
expected.push(end_slope(delta[3], delta[2], h[3], h[2]));
let slopes = pchip.slopes();
let node_rows: Vec<(usize, f64, f64, f64, f64)> = (0..5)
    .map(|i| (i, x[i], slopes[i], expected[i], slopes[i] - expected[i]))
    .collect();
// 区間ごとの α = d_i/δ_i と β = d_{i+1}/δ_i。平坦な区間（δ_i = 0）では定義しない。
let ratio_rows: Vec<(usize, f64, Option<f64>, Option<f64>)> = (0..4)
    .map(|i| {
        let ratio = |d: f64| (delta[i] != 0.0).then(|| d / delta[i]);
        (i, delta[i], ratio(slopes[i]), ratio(slopes[i + 1]))
    })
    .collect();

// 241 点で局所感度 dy/dx を評価する
let (mut pchip_slope, mut natural_slope) = (Vec::new(), Vec::new());
for i in 0..=240 {
    let at = 4.0 * f64::from(i) / 240.0;
    pchip_slope.push([at, pchip.derivative_at(at).map_err(|e| e.to_string())?]);
    natural_slope.push([at, natural.derivative_at(at).map_err(|e| e.to_string())?]);
}
let lowest = |name: &str, curve: &[[f64; 2]]| {
    let p = curve
        .iter()
        .fold([0.0, f64::INFINITY], |m, &p| if p[1] < m[1] { p } else { m });
    (name.to_string(), p[1], p[0])
};
```

## 逆校正の感度

測定した出力 $y^*$ から濃度 $x^*$ を推定する逆校正は、方程式 $p(x)=y^*$ を解く問題である。
$p$ が狭義単調増加なら、校正域 $[y_0,y_n]$ の中の $y^*$ に対して根は一つに決まる。
$p$ が単調でなければ、同じ $y^*$ に複数の濃度が対応することがある。

$p$ が狭義単調で $p'(x^*)>0$ なら、逆関数 $x(y)$ は $y^*$ の近くで滑らかで、$x'(y)=1/p'(x)$ である。
出力に誤差 $e_y$ があると、1 次の Taylor 展開から、濃度の推定の誤差 $e_x$ は

$$
e_x \approx \frac{e_y}{p'(x^*)}
$$

となる（記号 $\delta_i$ の割線と区別するため、誤差は $e$ で書く）。
出力の誤差に対する濃度の誤差の増幅率は $1/|p'(x^*)|$ であり、これが逆校正の絶対条件数である。
感度 $p'(x)$ の大きい範囲では濃度の推定が出力の誤差に鈍く、良条件である。
$p'(x)\approx0$ の平坦な範囲では、小さい出力の誤差でも濃度の推定が大きく動き、悪条件になる。
この悪条件は、センサーの応答そのものが平坦であることから来るもので、補間法を変えても解消しない。

出力の幅 $y^*\pm u_y$ に対応する濃度の半幅

$$
w = \frac{x(y^*+u_y)-x(y^*-u_y)}{2} = \frac{u_y}{p'(x^*)} + \frac{x'''(y^*)}{6}u_y^3 + O(u_y^5)
$$

では、$x''$ の項が両側で打ち消し合う。
したがって $y^*\pm u_y$ が一つの 3 次片の中にあれば、1 次の予測 $u_y/p'(x^*)$ と実際の半幅の相対差は $u_y^2$ に比例して小さくなる。
PCHIP の 2 階導関数は節点で跳ぶので、幅が節点の出力をまたぐと、この打ち消しは成り立たない。

`scioxide-interp` は逆関数を求める API を提供しない。
次のセルでは $[0,4]$ を 400 区間に分けて $p(x)-y^*$ の符号の変化を探し、変化のあった区間を二分法で 60 回半分にして根を求める。
二分法は値の評価だけを使うので、`derivative_at` で得た感度による 1 次の予測とは独立な検算になる。
一般の求根法とその比較は [scioxide-rootfind の章](../../../scioxide-rootfind/)で扱う。

## 逆校正の実験

次のセルは上のセルの $\Delta_2$ と $\Delta_4$ を受け取り、測定した出力 $y^*$ [mV] と出力の誤差の幅 $u_y$ [mV] を入力とする。
$y^*\pm u_y$ は校正値の範囲 $[y_0,y_4]$ の内側にとり、外にあるとセルはエラーを返す。
1 つ目の表は二つの補間による $y^*$ の逆像（小さい順）と、各逆像での感度である。
2 つ目の表は PCHIP の感度 $p'(x^*)$、1 次の予測 $u_y/p'(x^*)$、二分法による半幅 $w$ とその相対差である。
走査は幅 0.01 mmol/L の区間ごとに符号を調べるので、それより近い二つの根は見落としうる。

```rust
// p(x) = target の根: 400 区間で符号の変化を探し、各区間を二分法で 60 回半分にする
fn crossings<M: Interpolant<f64, 1, Value = f64>>(
    model: &M,
    target: f64,
) -> Result<Vec<f64>, String> {
    let f = |x: f64| {
        model
            .value_at(x)
            .map(|v| v - target)
            .map_err(|e| e.to_string())
    };
    let mut roots = Vec::new();
    let (mut a0, mut f0) = (0.0, f(0.0)?);
    for k in 1..=400 {
        let b0 = 4.0 * f64::from(k) / 400.0;
        let g0 = f(b0)?;
        if (f0 <= 0.0 && g0 > 0.0) || (f0 >= 0.0 && g0 < 0.0) {
            let (mut a, mut b, mut fa) = (a0, b0, f0);
            for _ in 0..60 {
                let mid = 0.5 * (a + b);
                let fm = f(mid)?;
                if (fm > 0.0) == (fa > 0.0) {
                    (a, fa) = (mid, fm);
                } else {
                    b = mid;
                }
            }
            roots.push(0.5 * (a + b));
        }
        (a0, f0) = (b0, g0);
    }
    Ok(roots)
}
```

真ん中の逆像では感度が負で、出力が増えると濃度の推定が減る向きに動く。
PCHIP の逆像は 0.8641 mmol/L の一つだけである。

最初のセルで $\Delta_2=1.6$ mV にすると、どちらの補間でも逆像は一つになり、感度は 1.06 まで上がる。

## まとめ

単調な校正表には各区間の単調性を保つ PCHIP を使える。
自然 3 次スプラインの $C^2$ の滑らかさは、値の範囲も傾きの符号も保たず、逆校正の一意性を壊すことがある。
PCHIP の傾きは `slopes()` で読め、内側の重み付き調和平均と端の片側の式から手で再計算でき、比 $\alpha_i,\beta_i$ が $[0,3]$ に入ることで単調性を確かめられる。
逆校正では $1/|p'(x^*)|$ が出力の誤差の増幅率になり、平坦な範囲ではどの補間でも悪条件である。
出力の誤差が大きいときや幅が節点をまたぐときは、1 次の予測を二分法などによる実際の逆算と比べて確かめる。
