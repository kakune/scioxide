位置の誤差が小さくても、そこから速度や加速度を正確に求められるとは限らない。
差分の刻みを $h$ とすると、独立な位置ノイズの標準偏差 $\sigma$ は 1 階差分 $(y_{i+1}-y_i)/h$ で $\sqrt2\,\sigma/h$、2 階差分 $(y_{i+1}-2y_i+y_{i-1})/h^2$ で $\sqrt6\,\sigma/h^2$ に増幅される。
微分は高い周波数の成分ほど大きく増幅する操作なので、ノイズを含むデータの数値微分は不適切問題の典型である。
ここでは軌道が解析的に分かる自由落下を使い、測定点を通す補間と、ノイズを平滑化する当てはめの速度・加速度を比べる。

## モデルと検算値

高さ $y$ [m] は上向きを正に取り、空気抵抗を無視する。

$$
y(t)=20+2t-\frac12gt^2,\qquad
v(t)=2-gt,\qquad y''(t)=-g.
$$

$g=9.80665\ \mathrm{m/s^2}$ は標準重力加速度であり、ここでは検証用の定数として使う。
場所ごとの実際の重力を推定する実験ではない。
$0\le t\le1\ \mathrm s$ に等間隔の標本を $N$ 個取り、独立な平均 0・標準偏差 $\sigma$ の正規ノイズを加える。
速度と加速度は区間内部の $[0.1,0.9]\ \mathrm s$ の 81 点で比べる。
端の近くでは、どの方法も片側の標本しか使えないため微分の誤差が大きくなりやすい。

## 補間スプラインによるノイズの増幅

測定値を通す 3 次スプラインの 2 階導関数は、節点での値 $M_i=s''(t_i)$ を節点の間で線形につないだものである。
等間隔 $h$ の内部の節点では、$M_i$ は三重対角方程式

$$
\frac{M_{i-1}+4M_i+M_{i+1}}{6}=\frac{y_{i+1}-2y_i+y_{i-1}}{h^2}
$$

を満たす。
軌道は 2 次式なので、ノイズがなければ $M_i=-g$ が厳密に成り立つ。
ノイズの寄与は線形なので、端から離れた節点では離散 Fourier 変換で解ける。
角周波数 $\theta$ の成分は $6(2\cos\theta-2)/[(4+2\cos\theta)h^2]$ 倍されるので、

$$
\operatorname{Var}M_i=\frac{36\sigma^2}{h^4}\cdot\frac1{2\pi}\int_{-\pi}^{\pi}\left(\frac{1-\cos\theta}{2+\cos\theta}\right)^2d\theta=\frac{36\sigma^2}{h^4}
$$

となる。
積分は $(1-\cos\theta)/(2+\cos\theta)=3/(2+\cos\theta)-1$ と書き直し、$\frac1{2\pi}\int d\theta/(2+\cos\theta)=1/\sqrt3$ と $\frac1{2\pi}\int d\theta/(2+\cos\theta)^2=2/(3\sqrt3)$ を使うと 1 になる。
同じ計算で、隣り合う節点の相関係数は $\rho=3\sqrt3-6\approx-0.804$ となる。
区間の内部の点 $t=t_i+sh$（$0\le s\le1$）では $s''=(1-s)M_i+sM_{i+1}$ なので、加速度の誤差の分散は

$$
\frac{36\sigma^2}{h^4}\left[(1-s)^2+s^2+2s(1-s)\rho\right]
$$

であり、$s$ について平均した二乗平均平方根（RMS）は $(6\sigma/h^2)\sqrt{\sqrt3-4/3}\approx3.79\,\sigma/h^2$ となる。
既定の $\sigma=0.02\ \mathrm m$、$N=31$（$h=1/30\ \mathrm s$）では約 $68\ \mathrm{m/s^2}$ であり、$g$ の 7 倍に当たる。
補間の加速度はノイズにほぼ支配され、$h$ を小さくする（標本を増やす）ほど悪化する。

## 三つの曲線

not-a-knot の補間スプライン（`CubicSpline::new`）は測定値を通す。
not-a-knot は、両端から 2 番目の節点で 3 階導関数が連続になる（端の 2 区間が同じ 3 次式になる）境界条件である。

ペナルティ付きスプライン（`PenalizedSplinePlan`）は、$[0,1]$ を 8 等分した単純ノットの 3 次 B スプライン基底 $N_j$ を固定し、

$$
\sum_i\bigl(y_i-f(t_i)\bigr)^2+\lambda\,\|\Delta^2c\|^2,\qquad f(t)=\sum_jc_jN_j(t)
$$

を最小にする係数 $c$ を求める（Eilers–Marx の P スプライン）。
$\Delta^2c$ は係数の 2 階差分であり、$\lambda$ は無次元の入力である。
最小化は正規方程式 $(B^\top B+\lambda D_2^\top D_2)c=B^\top y$（$B_{ij}=N_j(t_i)$、$D_2$ は 2 階差分の行列）を帯 Cholesky 分解で解く。
正規行列は標本の時刻とペナルティだけで決まるので、Plan を一度準備すれば、ノイズの異なる測定値に `fit` で何度でも使える。
1 次式の係数は $\Delta^2c=0$ を満たすが 2 次式の係数は満たさないので、2 次の軌道もペナルティを受け、$\lambda>0$ ではノイズがなくても偏りが残る。

適応的な当てはめはスカラーの位置値をオプション付き形式 `fit_parametric_spline_with_options` に渡し、時刻を `CurveParameterization::Supplied` で与える。
値がスカラーなら、この関数は時刻に対する位置の関数を当てはめる。
ワンショット関数 `fit_parametric_spline` は弦長の媒介変数しか使えず、目標に届かないとエラーを返して終了状態のレポートを返さないので、ここではオプション付き形式を使う。
当てはめは 1 つの 3 次の多項式片から始まり、目標 `SplineFitTarget::Residual(S)` では、残差平方和が $S$（と許容誤差）以下になるまで、残差の和が最大の区間を二分するノットを挿入する。
その後、$\lambda=1$ から 16 倍ずつ増やして条件を満たさなくなる値を見つけ、二分法で条件を満たす最大のペナルティを探す。
$S=N\sigma^2$ は残差平方和をノイズの平方和の期待値にそろえる選び方（Morozov の食い違い原理）である。
ノイズが 0 のときは $S=10^{-16}\ \mathrm{m^2}$ を下限にし、残差の判定には絶対 $10^{-14}\ \mathrm{m^2}$・相対 $10^{-5}$ の許容誤差を使う。
この選び方はノイズの分散を既知とした目安であり、平滑化の強さが統計的に最適になるとは限らない。
終了状態 `AdaptiveSplineTermination` は、目標を満たしてペナルティの探索も終えた `ResidualSatisfied` のときに `is_success()` が真になる。

`CubicSpline` は 2 階導関数を返すトレイト `TwiceDifferentiable` を実装しない。
そこで補間の加速度は `scioxide-differentiate` の `physical_difference_derivative` で勾配 `derivative_at` を中心差分して求める。
3 次スプラインの勾配は各区間で 2 次式なので、刻みを区間幅の $10^{-5}$ 倍にした中心差分は丸めを除いて厳密になる。
スプラインは $C^2$ なので、差分点が節点をまたいでも結果は変わらない。
二つの B スプラインは `hessian` で 2 階導関数を直接評価できる。

次のブロックは、ページの二つのセルが共有するモデルと三つの曲線の当てはめである。
`height` と `velocity` が $y(t)$ と $v(t)$、`generator` と `noisy_heights` が乱数のシードからのノイズ入りの標本、`penalized_plan` が 8 等分の基底とペナルティの Plan、`adaptive_options` が残差目標 $S=\max(N\sigma^2,10^{-16})$ の設定、`Curves::fit` が三つの曲線の当てはめ、`Curves::derivatives` が各曲線の速度と加速度に対応する。

```rust
//| id: interp-noisy-velocity-model
//| kind: definitions
//| title: 自由落下のモデルと三つの曲線
//| crates: [scioxide-core, scioxide-differentiate, scioxide-interp, scioxide-random]
use scioxide_core::{SciOxideError, Tolerance};
use scioxide_differentiate::physical_difference_derivative;
use scioxide_interp::{
    AdaptiveSplineOptions, BSpline, BSplineBasis, CubicSpline, CurveParameterization,
    ExtrapolationPolicy, ParametricSplineFit, PenalizedSplinePlan, SplineFitTarget, SplinePenalty,
    TwiceDifferentiable, Univariate, fit_parametric_spline_with_options,
};
use scioxide_random::{Distribution, Normal, SeedableRng, SplitMix64};

/// 標準重力加速度 g [m/s²]。
pub(crate) const GRAVITY: f64 = 9.80665;

/// 高さ y(t) = 20 + 2t − g t²/2 [m] と速度 v(t) = 2 − g t [m/s]。
pub(crate) fn height(t: f64) -> f64 {
    20.0 + 2.0 * t - 0.5 * GRAVITY * t * t
}
pub(crate) fn velocity(t: f64) -> f64 {
    2.0 - GRAVITY * t
}

/// [0, 1] s の等間隔な count 点と、比較に使う [0.1, 0.9] s の 81 点。
pub(crate) fn sample_times(count: usize) -> Vec<f64> {
    (0..count).map(|i| i as f64 / (count - 1) as f64).collect()
}
pub(crate) fn evaluation_times() -> Vec<f64> {
    (0..81).map(|i| 0.1 + 0.8 * i as f64 / 80.0).collect()
}

/// シードから作った乱数で、各時刻の高さに N(0, σ²) のノイズを加える。
pub(crate) fn generator(seed: f64) -> SplitMix64 {
    SplitMix64::from_seed(seed as u64)
}
pub(crate) fn noisy_heights(
    times: &[f64],
    noise: f64,
    rng: &mut SplitMix64,
) -> Result<Vec<f64>, SciOxideError> {
    let normal = Normal::new(0.0_f64, 1.0)?;
    let mut heights = Vec::with_capacity(times.len());
    for &t in times {
        heights.push(height(t) + noise * normal.sample(rng)?);
    }
    Ok(heights)
}

/// [0, 1] を 8 等分した 3 次 B スプライン基底とペナルティ λ‖Δ²c‖² の Plan。
pub(crate) fn penalized_plan(
    times: &[f64],
    strength: f64,
) -> Result<PenalizedSplinePlan<f64>, SciOxideError> {
    let mut knots = vec![0.0; 4];
    knots.extend((1..8).map(|i| i as f64 / 8.0));
    knots.extend([1.0; 4]);
    let basis = BSplineBasis::new(knots, 3)?;
    PenalizedSplinePlan::new(
        basis,
        times.to_vec(),
        None,
        SplinePenalty::new(strength, 2)?,
    )
}

/// 残差平方和の目標 S = max(Nσ², 10⁻¹⁶) m² と、その許容誤差（絶対 10⁻¹⁴、相対 10⁻⁵）。
pub(crate) fn adaptive_options(
    count: usize,
    noise: f64,
) -> Result<AdaptiveSplineOptions<f64>, SciOxideError> {
    let target = (count as f64 * noise * noise).max(1e-16);
    Ok(AdaptiveSplineOptions::new()
        .with_target(SplineFitTarget::Residual(target))
        .with_residual_tolerance(Tolerance::new(1e-14, 1e-5)?))
}

/// 同じ標本に当てはめた補間・固定ペナルティ・適応的な残差目標の三つの曲線。
pub(crate) struct Curves {
    pub(crate) interpolation: CubicSpline<f64>,
    pub(crate) penalized: BSpline<f64>,
    pub(crate) adaptive: ParametricSplineFit<f64>,
    step: f64,
}

impl Curves {
    pub(crate) fn fit(
        times: &[f64],
        heights: &[f64],
        plan: &PenalizedSplinePlan<f64>,
        options: AdaptiveSplineOptions<f64>,
    ) -> Result<Self, SciOxideError> {
        let supplied = CurveParameterization::Supplied(times);
        Ok(Self {
            interpolation: CubicSpline::new(times.to_vec(), heights.to_vec())?,
            penalized: plan.fit(heights)?.into_spline(),
            adaptive: fit_parametric_spline_with_options(heights, supplied, None, options)?,
            step: 1e-5 * (times[1] - times[0]),
        })
    }

    /// 各曲線の [速度, 加速度]。補間の加速度は勾配の中心差分、B スプラインは Hessian。
    pub(crate) fn derivatives(&self, t: f64) -> Result<[[f64; 2]; 3], SciOxideError> {
        let policy = ExtrapolationPolicy::Reject;
        let h = self.step;
        let difference = physical_difference_derivative(
            |q| self.interpolation.derivative_at(q),
            t,
            &[t - h, t + h],
        )?;
        let adaptive = self.adaptive.spline();
        Ok([
            [self.interpolation.derivative_at(t)?, difference],
            [
                self.penalized.derivative_at(t)?,
                self.penalized.hessian([t], policy)?[0][0],
            ],
            [
                adaptive.derivative_at(t)?,
                adaptive.hessian([t], policy)?[0][0],
            ],
        ])
    }
}
```

## 1 回の測定での速度と加速度

次のセルは一組のノイズ入りの標本から三つの曲線を作り、速度と加速度を比べる。
入力はノイズの標準偏差 $\sigma$ [m]、標本数 $N$、固定ペナルティの強さ $\lambda$、乱数のシードである。
1 つ目の表は各方法の速度と加速度の RMS 誤差、2 つ目の表は適応的な当てはめの終了状態、残差平方和と目標、挿入したノット、ペナルティを示す。
上のグラフは速度、下のグラフは加速度で、横軸の時刻は二つのグラフで連動する。
理論値 $v(t)=2-gt$ と $y''=-g$ は破線で描く。
このセルの 4 つの入力は次の反復実験にも渡す。

```rust

//| ref: interp-noisy-velocity-smoothing
//| title: 補間と平滑化の速度を比べる
//| run: reactive
//| uses: [interp-noisy-velocity-model]
//| crates: [scioxide-core, scioxide-differentiate, scioxide-interp, scioxide-random]
//| exports: [noise, samples, strength, seed]
//| inputs:
//|   noise: {"type":"range","label":"位置ノイズの標準偏差 σ [m]","min":0.0,"max":0.1,"step":0.005,"value":0.02}
//|   samples: {"type":"range","label":"標本数 N [-]","min":21.0,"max":61.0,"step":10.0,"value":31.0}

//|   - {"id":"dense-samples","label":"N = 61","description":"標本を増やすと補間の加速度の誤差は h⁻² で増える。","inputs":{"samples":61}}

let count = samples as usize;

let heights = noisy_heights(&times, noise, &mut rng).map_err(|e| e.to_string())?;

let options = adaptive_options(count, noise).map_err(|e| e.to_string())?;
let curves = Curves::fit(&times, &heights, &plan, options).map_err(|e| e.to_string())?;

// 81 点で速度と加速度を評価し、理論値との RMS 誤差を求める
let mut velocity_lines = [Vec::new(), Vec::new(), Vec::new(), Vec::new()];
let mut acceleration_lines = [Vec::new(), Vec::new(), Vec::new(), Vec::new()];
let mut squares = [[0.0; 2]; 3];
for t in evaluation_times() {
    let methods = curves.derivatives(t).map_err(|e| e.to_string())?;
    for (j, [v, a]) in methods.into_iter().enumerate() {
        velocity_lines[j].push([t, v]);
        acceleration_lines[j].push([t, a]);
        squares[j][0] += (v - velocity(t)) * (v - velocity(t)) / 81.0;
        squares[j][1] += (a + GRAVITY) * (a + GRAVITY) / 81.0;
    }
    velocity_lines[3].push([t, velocity(t)]);
    acceleration_lines[3].push([t, -GRAVITY]);
}

let rows: Vec<_> = (0..3)
    .map(|j| {

        (names[j], RealScalar::sqrt(v), RealScalar::sqrt(a))
    })
    .collect();

    { "key": "2", "label": "加速度の RMS 誤差 [m/s²]", "type": "number", "format": sci3 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "errors" })
);

let report = curves.adaptive.report();
let target = (count as f64 * noise * noise).max(1e-16);
let report_columns = serde_json::json!([
    { "key": "0", "label": "終了状態" },
    { "key": "1", "label": "残差平方和 [m²]", "type": "number", "format": sci3 },
    { "key": "2", "label": "目標 S [m²]", "type": "number", "format": sci3 },
    { "key": "3", "label": "挿入したノット [-]", "type": "integer" },

]);
let report_rows = vec![(
    format!("{:?}", report.termination()),
    report.residual(),
    target,
    report.refinements(),
    report.penalty(),
)];
emit_table_with_columns!(
    report_columns,
    report_rows,
    metadata = serde_json::json!({ "id": "adaptive" })
);

let series = |lines: &[Vec<[f64; 2]>; 4], theory: &str| {
    let mut list: Vec<_> = (0..3)
        .map(|j| serde_json::json!({ "name": names[j], "points": lines[j] }))

emit_line_chart!(

    options = &serde_json::json!({
        "link": { "group": "fall-time" },
        "xLabel": "時刻 t [s]",

);

export!(noise, noise);
export!(samples, samples);
export!(strength, strength);
export!(seed, seed);

let outcome = if termination.is_success() {
    Outcome::satisfied("適応的な当てはめが残差平方和の目標を満たした")
} else {

};
emit_outcome!(
    outcome
        .status(format!("{termination:?}"))
        .diagnostic("残差平方和", report.residual(), Some("m²"))
        .diagnostic("目標", target, Some("m²"))

```

既定値（$\sigma=0.02\ \mathrm m$、$N=31$、$\lambda=0.1$、シード 7）では、補間の速度の RMS 誤差は 1.27 m/s、加速度の RMS 誤差は 86.8 m/s² で、加速度は $g$ の約 9 倍のノイズに埋もれる。
固定ペナルティと適応的な残差目標の速度誤差は 0.140 と 0.135 m/s で補間の約 1/9 になり、加速度の誤差も 2.1 と 2.5 m/s² に下がる。
適応的な当てはめは 4 個のノットを挿入し、ペナルティ $\lambda\approx4.7\times10^{-3}$ で残差平方和を目標 0.0124 m² に合わせて `ResidualSatisfied` で終わる。
下のグラフでは、補間の加速度が $-g$ の破線のまわりで大きく振れ、二つの平滑化がその近くにとどまる様子を、上の速度のグラフと同じ時刻で比べられる。

$\sigma=0$ では、補間スプラインは 2 次の軌道を丸めの水準（速度誤差 $6\times10^{-14}$ m/s）で、適応的な当てはめは速度誤差 $8\times10^{-8}$ m/s で再現する。
固定ペナルティではノイズがなくても速度の RMS 誤差が 0.096 m/s、加速度の誤差が 1.34 m/s² 残り、ペナルティによる偏りを示す。
$N=61$ にすると、補間の加速度の誤差は 282 m/s² に増える。
理論の RMS $3.79\,\sigma/h^2$ は $h$ が半分になると 4 倍（68 から 273 m/s²）になり、1 回の測定の値はそのまわりでばらつく。
ペナルティの強さやシードを変えると、平滑化の二つの方法の順位は入れ替わる（シード 1 では固定ペナルティの速度誤差 0.086 m/s が適応的な当てはめの 0.095 m/s より小さい）。
一回の測定での比較はノイズの系列に左右されるので、次の節で反復して比べる。

## 反復による重力加速度の推定

各方法の 2 階導関数を $[0.1,0.9]\ \mathrm s$ の 81 点で平均し、符号を反転したものを重力加速度の推定値 $\hat g$ とする。
一回の測定の $\hat g$ はノイズに依存する確率変数なので、独立な測定を $R$ 回繰り返し、平均と標準誤差（SE）で真値と比べる。
SE は $R$ 個の推定値の標本標準偏差を $\sqrt R$ で割った値であり、平均 ±1.96 SE を 95% 信頼区間の近似とする。
加速度の RMS 誤差は各回の二乗平均誤差を $R$ 回で平均してから平方根を取る。
補間スプラインについては前の節で導いた分散の式を同じ 81 点で平均した理論値も出す。
推定値の平均と $g$ の差は偏り、SE は分散の大きさを表し、二乗平均誤差はその両方を含む。

次のセルは前のセルの $\sigma$、$N$、$\lambda$、乱数のシードを受け取り、反復回数 $R$ だけを入力にする。
同じシードから始めるので、1 回目の反復の標本は前のセルの標本と同じである。
ペナルティ付きスプラインの Plan は標本の時刻とペナルティだけで決まるので、一度準備して各回の `fit` に再利用する。
表は各方法の $\hat g$ の平均・1.96 SE・平均と $g$ の差、加速度の RMS 誤差、補間の理論値、適応的な当てはめが目標を満たした割合を示し、グラフは $\hat g$ の平均と 95% 区間を示す。

```rust
//| id: interp-noisy-velocity-gravity
//| ref: interp-noisy-velocity-gravity
//| title: 重力加速度の推定とノイズの増幅を反復で検算する
//| run: button
//| uses: [interp-noisy-velocity-model]
//| crates: [scioxide-core, scioxide-differentiate, scioxide-interp, scioxide-random]
//| dependsOn:
//|   single: interp-noisy-velocity-smoothing
//| inputs:
//|   replicates: {"type":"range","label":"反復回数 R [-]","min":10.0,"max":100.0,"step":10.0,"value":40.0}
//| cases:
//|   - {"id":"many-replicates","label":"R = 100","description":"反復を増やすと 1.96 SE が 1/√R で縮み、偏りがよりはっきりする。","inputs":{"replicates":100}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"gravity","path":"/rows/0/4","approx":{"value":69.513,"rtol":1e-3}}
//|       - {"artifact":"gravity","path":"/rows/0/5","approx":{"value":69.329,"rtol":1e-4}}
//|       - {"artifact":"gravity","path":"/rows/0/2","approx":{"value":0.4695,"rtol":1e-3}}
//|       - {"artifact":"gravity","path":"/rows/1/1","approx":{"value":9.4785,"rtol":1e-4}}
//|       - {"artifact":"gravity","path":"/rows/1/3","approx":{"value":-0.32815,"atol":1e-3}}
//|       - {"artifact":"gravity","path":"/rows/2/6","equals":1}
//|   - case: many-replicates
//|     expect:
//|       - {"artifact":"gravity","path":"/rows/1/2","approx":{"value":0.03964,"rtol":1e-3}}
//|       - {"artifact":"gravity","path":"/rows/0/4","approx":{"value":69.505,"rtol":1e-3}}
use scioxide_core::RealScalar;

let number = |key: &str| single[key].as_f64().ok_or(format!("{key} がない"));
let (noise, strength) = (number("noise")?, number("strength")?);
let count = number("samples")? as usize;
let times = sample_times(count);
let h = times[1] - times[0];
// Plan は標本の時刻とペナルティだけで決まるので、反復の間で再利用する
let plan = penalized_plan(&times, strength).map_err(|e| e.to_string())?;
let options = adaptive_options(count, noise).map_err(|e| e.to_string())?;
let evaluation = evaluation_times();
let mut rng = generator(number("seed")?);
// 方法ごとの各回の [ĝ, 加速度の二乗平均誤差]、適応的な当てはめの成功回数
let mut records = [Vec::new(), Vec::new(), Vec::new()];
let mut satisfied = 0;
for _ in 0..replicates as usize {
    let heights = noisy_heights(&times, noise, &mut rng).map_err(|e| e.to_string())?;
    let curves = Curves::fit(&times, &heights, &plan, options).map_err(|e| e.to_string())?;
    if curves.adaptive.report().termination().is_success() {
        satisfied += 1;
    }
    let mut sums = [[0.0; 2]; 3];
    for &t in &evaluation {
        let methods = curves.derivatives(t).map_err(|e| e.to_string())?;
        for (sum, [_, a]) in sums.iter_mut().zip(methods) {
            sum[0] -= a / 81.0;
            sum[1] += (a + GRAVITY) * (a + GRAVITY) / 81.0;
        }
    }
    for (record, sum) in records.iter_mut().zip(sums) {
        record.push(sum);
    }
}
// 独立検算: 補間の加速度誤差の理論 RMS（端から離れた節点の近似、ρ = 3√3 − 6）
let rho = 3.0 * RealScalar::sqrt(3.0) - 6.0;
let mut shape = 0.0;
for &t in &evaluation {
    let s = RealScalar::fract(t / h);
    shape += ((1.0 - s) * (1.0 - s) + s * s + 2.0 * s * (1.0 - s) * rho) / 81.0;
}
let predicted = 6.0 * noise / (h * h) * RealScalar::sqrt(shape);
let r = replicates;
let names = ["補間", "固定ペナルティ", "適応的な残差目標"];
let mut rows = Vec::new();
let mut bars = Vec::new();
for (i, record) in records.iter().enumerate() {
    let mean = record.iter().map(|x| x[0]).sum::<f64>() / r;
    let deviations = record.iter().map(|x| (x[0] - mean) * (x[0] - mean));
    let half = 1.96 * RealScalar::sqrt(deviations.sum::<f64>() / (r - 1.0) / r);
    let rms = RealScalar::sqrt(record.iter().map(|x| x[1]).sum::<f64>() / r);
    let theory = (i == 0).then_some(predicted);
    let success = (i == 2).then_some(satisfied as f64 / r);
    rows.push((names[i], mean, half, mean - GRAVITY, rms, theory, success));
    bars.push([(i + 1) as f64, mean, mean - half, mean + half]);
}
let fixed2 = serde_json::json!({ "fractionDigits": 2 });
let fixed3 = serde_json::json!({ "fractionDigits": 3 });
let sig3 = serde_json::json!({ "significantDigits": 3 });
let columns = serde_json::json!([
    { "key": "0", "label": "方法" },
    { "key": "1", "label": "ĝ の平均 [m/s²]", "type": "number", "format": fixed3 },
    { "key": "2", "label": "1.96 SE [m/s²]", "type": "number", "format": fixed3 },
    { "key": "3", "label": "平均 − g [m/s²]", "type": "number", "format": fixed3 },
    { "key": "4", "label": "加速度の RMS 誤差 [m/s²]", "type": "number", "format": sig3 },
    { "key": "5", "label": "補間の理論 RMS [m/s²]", "type": "number", "format": sig3, "nullText": "—" },
    { "key": "6", "label": "目標を満たした割合 [-]", "type": "number", "format": fixed2, "nullText": "—" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "gravity" })
);
emit_chart!(serde_json::json!({
    "kind": "errorbar",
    "xLabel": "方法（1: 補間、2: 固定ペナルティ、3: 適応的な残差目標）[-]",
    "yLabel": "重力加速度の推定 ĝ [m/s²]",
    "xMin": 0.5,
    "xMax": 3.5,
    "series": [{ "name": "平均 ±1.96 SE", "points": bars }],
    "annotations": [{ "kind": "line", "axis": "y", "value": GRAVITY, "label": "標準重力加速度 g" }]
}));
```

既定値（$\sigma=0.02\ \mathrm m$、$N=31$、$\lambda=0.1$、$R=40$、シード 7）では、補間の加速度の RMS 誤差は 69.5 m/s² で、理論値 69.3 m/s² と 0.3% の差で一致する。
前のセルで $N=21$ と $N=61$ にすると、観測値と理論値は 31.8 と 31.5 m/s²、285.7 と 283.2 m/s² で差は 1% 以内であり、誤差が $\sigma/h^2$ に比例して増えることを確かめられる。
補間の $\hat g$ は $9.77\pm0.47\ \mathrm{m/s^2}$（平均 ±1.96 SE）で、区間は $g$ を含むが、幅は平滑化の 5 倍以上ある。
1 回の測定の $\hat g$ の標準偏差は SE $\times\sqrt R\approx1.5\ \mathrm{m/s^2}$ で、一点の加速度の誤差よりはるかに小さい。
隣り合う節点の $M_i$ が負の相関（$\rho\approx-0.80$）を持ち、81 点で平均すると正負が打ち消し合うからである。

固定ペナルティの $\hat g$ は $9.48\pm0.06\ \mathrm{m/s^2}$ で、区間が $g$ を含まない。
差 $-0.33\ \mathrm{m/s^2}$ はペナルティ $\lambda\|\Delta^2c\|^2$ が曲率を小さくする向きの偏りである。
前のセルで $\sigma=0$ にしても差は $-0.328\ \mathrm{m/s^2}$ のまま変わらないので、この偏りはノイズではなくペナルティから生じる。
$\lambda=0$ にすると $9.87\pm0.18$ となって区間が $g$ を含む。
適応的な残差目標の $\hat g$ も $9.65\pm0.08$ で $g$ より有意に小さく、40 回すべてで目標を満たしている。
その加速度の RMS 誤差 6.45 m/s² は固定ペナルティの 1.86 m/s² より大きく、偏りの小さい方法が二乗平均誤差でも小さいとは限らない。
$R=100$ にすると 1.96 SE は $1/\sqrt{2.5}\approx0.63$ 倍に縮む（補間 0.47 から 0.32、固定ペナルティ 0.064 から 0.040 m/s²）。
平滑化は分散を減らす代わりに偏りを生むので、平均と SE の両方を見ないと、どちらの誤差が支配的かを判断できない。

## まとめ

位置のノイズは 1 階微分で $1/h$、2 階微分で $1/h^2$ の割合で増幅され、等間隔の補間スプラインの加速度誤差の RMS は $3.79\,\sigma/h^2$ になる。
補間スプラインは測定値を通すので偏りはないが、加速度はノイズに支配され、標本を増やすとむしろ悪化する。
ペナルティ付きスプラインと残差目標の当てはめは分散を大きく減らすが、ペナルティが 2 次の軌道にも偏りを与えるので、重力加速度の推定は真値より小さくなる。
平滑化の強さを選ぶときは、既知の軌道で偏りと SE を同時に確かめ、残差平方和だけで判断しない。
適応的な当てはめでは終了状態、残差平方和と目標、挿入したノットとペナルティをレポートで確かめる。
