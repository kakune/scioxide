気象観測や太陽光発電の見積もりでは、離散的な時刻 $t_i$ [h] に記録した水平面の全天日射強度 $G_i$ [W/m²] から、1 日の日射量

$$
E = \int_0^{24} G(t)\,dt\quad[\mathrm{Wh/m^2}]
$$

を求める。
時刻を時間 [h] で測るので、W/m² の強度を積分すると Wh/m² になる。
標本 $(t_i,G_i)$ だけでは標本の間の $G(t)$ は決まらない。
日射量を求めるには標本の間をつなぐモデルを選び、そのモデルを積分する。
補間の積分は選んだモデルの積分であり、真の日射の積分ではない。
この例題では、同じ観測表を自然 3 次スプライン、PCHIP、折れ線（台形則）の三つのモデルで積分し、差の出どころを式で確かめる。

## 観測表と単位

この例の観測表は夏の晴れた日の水平面日射を模した説明用の値で、出典のある実測値ではない。
夜間は 4 時間おき、日中は 2 時間おきに記録する。

| 時刻 $t_i$ [h] | 0 | 4 | 6 | 8 | 10 | 12 | 14 | 16 | 18 | 20 | 24 |
|---|---|---|---|---|---|---|---|---|---|---|---|
| 晴天の強度 [W/m²] | 0 | 0 | 35 | 260 | 610 | 850 | 790 | 510 | 135 | 0 | 0 |

午後の雲の影響として、14 時以降の値に $1-f\,\min\bigl(1,(t-14)/6\bigr)$ を掛ける。
$f$ は 20 時での減衰率で、14 時の 0 から 20 時の $f$ まで直線的に増える。
全体の倍率 $s$ はすべての値に掛ける。

次のブロックはこのページの三つのセルが共有する定義である。
`HOURS` と `CLEAR_SKY` が上の表、`irradiance` が倍率 $s$ と減衰率 $f$ を掛けた標本 $G_i$、`solar_models` が同じ標本から作る自然 3 次スプラインと PCHIP に対応する。

```rust
//| id: interp-solar-model
//| kind: definitions
//| title: 日射の観測表と二つの補間
//| crates: [scioxide-core, scioxide-interp]
use scioxide_core::SciOxideError;
use scioxide_interp::{CubicSpline, PchipInterpolator, SplineBoundary};

/// 観測時刻 t_i [h]。
pub(crate) const HOURS: [f64; 11] = [
    0.0, 4.0, 6.0, 8.0, 10.0, 12.0, 14.0, 16.0, 18.0, 20.0, 24.0,
];

/// 晴天時の水平面日射強度 [W/m²]（説明用の値）。
pub(crate) const CLEAR_SKY: [f64; 11] = [
    0.0, 0.0, 35.0, 260.0, 610.0, 850.0, 790.0, 510.0, 135.0, 0.0, 0.0,
];

/// G_i = s · G_clear · (1 − f · min(1, max(0, (t − 14)/6))) [W/m²]。
pub(crate) fn irradiance(scale: f64, cloud: f64) -> Vec<f64> {
    HOURS
        .iter()
        .zip(CLEAR_SKY)
        .map(|(&t, g)| scale * g * (1.0 - cloud * ((t - 14.0) / 6.0).clamp(0.0, 1.0)))
        .collect()
}

/// 同じ標本の自然 3 次スプライン（両端で S″ = 0）と PCHIP。
pub(crate) fn solar_models(
    scale: f64,
    cloud: f64,
) -> Result<(CubicSpline<f64>, PchipInterpolator<f64>), SciOxideError> {
    let samples = irradiance(scale, cloud);
    let spline =
        CubicSpline::with_boundary(HOURS.to_vec(), samples.clone(), SplineBoundary::Natural)?;
    let pchip = PchipInterpolator::new(HOURS.to_vec(), samples)?;
    Ok((spline, pchip))
}
```

## 補間の積分と台形則

最も簡単な日積算は、標本を折れ線で結んだ区分線形補間の積分、すなわち合成台形則

$$
E_{\text{trap}} = \sum_{i=0}^{n-1} \frac{h_i}{2} (G_i + G_{i+1}), \qquad h_i = t_{i+1} - t_i
$$

である。
3 次スプラインや PCHIP は、各区間を節点の値 $G_i,G_{i+1}$ と傾き $d_i,d_{i+1}$ で決まる 3 次 Hermite 多項式で表す。
局所座標 $u=(t-t_i)/h_i$ の Hermite 基底を $[0,1]$ で積分すると、値の基底はどちらも $1/2$、傾きの基底は $h_i/12$ と $-h_i/12$ になる。
したがって各区間の積分は

$$
\int_{t_i}^{t_{i+1}} p_i(t)\,dt = \frac{h_i}{2}(G_i+G_{i+1}) + \frac{h_i^2}{12}(d_i-d_{i+1})
$$

となり、3 次の補間と台形則の日積算の差は

$$
E_{\text{cubic}} - E_{\text{trap}} = \sum_{i=0}^{n-1}\frac{h_i^2}{12}(d_i-d_{i+1})
$$

で、節点の傾きだけで決まる。
この差は丸め誤差でも汎用の求積の離散化誤差でもなく、標本の間を直線とみるか 3 次式とみるかというモデルの違いである。
どちらが現実に近いかは、標本の外の知識（より細かい観測や日射の物理モデル）がなければ決まらない。

間隔がすべて等しい区間の並びでは、和 $\sum(d_i-d_{i+1})$ が打ち消し合って $h^2(d_{\text{first}}-d_{\text{last}})/12$ だけが残る。
この表は夜間の 2 区間（幅 4 h）と日中の 8 区間（幅 2 h）からなるので、差は 0、4、20、24 時の傾きだけで決まる。

台形則とスプラインの日積算は標本値 $G_i$ に線形である。
PCHIP の傾きは調和平均を含むので線形ではないが、すべての標本値を同じ正の倍率で変えると、傾きも日積算も同じ倍率で変わる。

`CubicSpline` と `PchipInterpolator` の定積分（`Integrable::integral` と、そのスカラー形 `integrate`）は、この Hermite 片の積分を区間ごとに足して計算する。
計算量は積分範囲に含まれる区間の数に比例する。
同じスプラインを何度も積分するなら、`CubicSpline::prepare_antiderivative` で区間ごとの原始関数と累積和を一度作り、各問い合わせを $O(\log n)$ にできる。
`PchipInterpolator` にはこの準備の API はない。

## 日積算の実験

次のセルは全体の倍率 $s$ と午後の減衰率 $f$ を入力として、自然 3 次スプライン（`CubicSpline::with_boundary` に `Natural` を渡す）と PCHIP の 24 時間の積分を `integrate` で求め、台形則と比べる。
独立検算として、各補間の節点の傾き `slopes()` から上の差の式を計算し、台形則にこの差を足した値を `integrate` と比べる。
表の「再構成との差」がこの検算で、丸め誤差の大きさなら差の式が成り立っている。
このセルの $s$ と $f$ は下の二つのセルにも渡す。

```rust
//| id: interp-solar-energy
//| ref: interp-solar-energy
//| title: 日射の倍率と午後の雲を動かして日積算を台形則と比べる
//| run: reactive
//| uses: [interp-solar-model]
//| crates: [scioxide-interp]
//| exports: [irradiance_scale, afternoon_cloud_fraction]
//| inputs:
//|   irradiance_scale: {"type":"range","label":"全体の倍率 s [-]","description":"すべての標本値に掛ける倍率。","min":0.4,"max":1.6,"step":0.05,"value":1}
//|   afternoon_cloud_fraction: {"type":"range","label":"20 時の雲による減衰率 f [-]","description":"14 時から 20 時まで直線的に増える減衰の最終値。","min":0,"max":0.9,"step":0.05,"value":0.35}
//| cases:
//|   - {"id":"bright-day","label":"s = 1.6","description":"日積算はどれも 1.6 倍になり、相対差は変わらない。","inputs":{"irradiance_scale":1.6}}
//|   - {"id":"clear-afternoon","label":"f = 0","description":"雲がないと 18–20 時の減少が急になり、スプラインの差が大きくなる。","inputs":{"afternoon_cloud_fraction":0}}
//|   - {"id":"cloudy-afternoon","label":"f = 0.9","description":"午後の標本が下がり、スプラインと台形則の差の符号が変わる。","inputs":{"afternoon_cloud_fraction":0.9}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"daily","path":"/rows/0/1","approx":{"value":6177.2,"atol":0.1}}
//|       - {"artifact":"daily","path":"/rows/2/1","approx":{"value":6198.0,"atol":0.1}}
//|       - {"artifact":"daily","path":"/rows/0/2","approx":{"value":-3.36e-3,"atol":2e-5}}
//|       - {"artifact":"daily","path":"/rows/0/4","range":{"min":-1e-10,"max":1e-10}}
//|       - {"artifact":"daily","path":"/rows/1/2","range":{"min":-1e-15,"max":1e-15}}
//|       - {"artifact":"daily","path":"/rows/2/3","equals":null}
//|   - case: bright-day
//|     expect:
//|       - {"artifact":"daily","path":"/rows/0/1","approx":{"value":9883.5,"atol":0.2}}
//|       - {"artifact":"daily","path":"/rows/0/2","approx":{"value":-3.36e-3,"atol":2e-5}}
//|   - case: clear-afternoon
//|     expect:
//|       - {"artifact":"daily","path":"/rows/0/2","approx":{"value":-5.5e-3,"atol":1e-4}}
//|   - case: cloudy-afternoon
//|     expect:
//|       - {"artifact":"daily","path":"/rows/0/2","range":{"min":0,"max":1e-3}}
use scioxide_interp::Univariate;

let (spline, pchip) =
    solar_models(irradiance_scale, afternoon_cloud_fraction).map_err(|e| e.to_string())?;
let samples = irradiance(irradiance_scale, afternoon_cloud_fraction);
let spline_total = spline.integrate(0.0, 24.0).map_err(|e| e.to_string())?;
let pchip_total = pchip.integrate(0.0, 24.0).map_err(|e| e.to_string())?;

// 独立な比較: 合成台形則（折れ線の積分）
let trapezoid: f64 = (0..HOURS.len() - 1)
    .map(|i| 0.5 * (HOURS[i + 1] - HOURS[i]) * (samples[i] + samples[i + 1]))
    .sum();
// 独立検算: Hermite 片の積分の差 Σ h_i²(d_i − d_{i+1})/12 を節点の傾きから計算する
let correction = |slopes: &[f64]| -> f64 {
    (0..HOURS.len() - 1)
        .map(|i| {
            let h = HOURS[i + 1] - HOURS[i];
            h * h * (slopes[i] - slopes[i + 1]) / 12.0
        })
        .sum()
};
let row = |name: &str, total: f64, slopes: &[f64]| {
    let difference = correction(slopes);
    (
        name.to_string(),
        total,
        (total - trapezoid) / trapezoid,
        Some(difference),
        Some(trapezoid + difference - total),
    )
};
let rows = vec![
    row("自然 3 次スプライン", spline_total, spline.slopes()),
    row("PCHIP", pchip_total, pchip.slopes()),
    ("台形則".to_string(), trapezoid, 0.0, None, None),
];
let fixed1 = serde_json::json!({ "fractionDigits": 1 });
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let columns = serde_json::json!([
    { "key": "0", "label": "モデル" },
    { "key": "1", "label": "日積算 [Wh/m²]", "type": "number", "format": fixed1 },
    { "key": "2", "label": "台形則との相対差 [-]", "type": "number", "format": sci3 },
    {
        "key": "3",
        "label": "Σh²(d_i − d_{i+1})/12 [Wh/m²]",
        "type": "number",
        "format": sci3,
        "nullText": "—"
    },
    {
        "key": "4",
        "label": "再構成との差 [Wh/m²]",
        "type": "number",
        "format": sci2,
        "nullText": "—"
    }
]);
emit_table_with_columns!(columns, rows, metadata = serde_json::json!({ "id": "daily" }));
export!(irradiance_scale, irradiance_scale);
export!(afternoon_cloud_fraction, afternoon_cloud_fraction);
```

既定の $s=1$、$f=0.35$ では、自然 3 次スプラインの日積算は 6177.2 Wh/m²、台形則は 6198.0 Wh/m² で、相対差は $-0.34\%$ である。
差の式の値 $-20.8$ Wh/m² を台形則に足した値とスプラインの `integrate` の差は、既定で 0、どの入力でも $4\times10^{-12}$ Wh/m² 以下で、丸め誤差の範囲で差の式が成り立つ。
$s=1.6$ にしても相対差は変わらず、三つの日積算がどれも標本値の倍率に比例することがわかる。
$f=0$ では相対差は $-0.55\%$、$f=0.9$ では $+0.03\%$ になり、雲で午後の標本が下がると差の符号まで変わる。

PCHIP の日積算は台形則と一致する。
差の式に残る 0、4、20、24 時の傾きが、PCHIP ではどれも 0 になるからである。
4 時と 20 時では片側の割線が 0 なので内側の規則で 0 になり、0 時と 24 時では最初と最後の区間の割線が 0 なので端の規則で 0 になる。
スプラインでは夜間の節点の傾きが 0 にならず、この端の項が差を生む。

## 非負性と行き過ぎ

自然 3 次スプラインは両端で $S''(0) = S''(24) = 0$ とする。
これは 2 階導関数の二乗積分を最小にする変分問題の自然な境界条件で、「夜間の日射が 0 である」ことや「日の出で強度の傾きが 0 である」ことを表すものではない。

物理的な日射強度は $G(t)\ge0$ を満たすが、$C^2$ の 3 次スプラインはこの制約を知らない。
夜間の 0 が続く区間と日中の急な変化が隣り合う所では、2 階導関数の連続性のために曲線が 0 を下回ることがある。
負の強度は日積算を減らし、累積の日射量 $E(t)$ を一時的に減少させる。

PCHIP は各区間で単調な Hermite 片を作り、データが極値をとる節点では傾きを 0 にする。
そのため各区間の値は両端の標本値の間にとどまり、標本が非負なら曲線も非負になる。
代わりに 2 階導関数は節点で跳ぶ。

次のセルは上のセルの $s$ と $f$ を受け取り、二つの補間を 0.1 h ごとに `value_at` で評価して、最小値とその時刻、負になる評価点の数を表に出す。
グラフの $G=0$ の線より下が、補間が作った負の日射強度である。
横軸の時刻は次のセルの累積日射量のグラフと連動する。

```rust

//| ref: interp-solar-nonnegativity
//| title: 日射強度のスプラインと PCHIP の負の値を比べる
//| run: reactive
//| uses: [interp-solar-model]
//| crates: [scioxide-interp]
//| dependsOn:
//|   day: interp-solar-energy

//|     expect:
//|       - {"artifact":"minimum","path":"/rows/0/1","approx":{"value":-11.2,"atol":0.05}}

    .ok_or("全体の倍率がない")?;

}
let summary = |name: &str, curve: &[[f64; 2]]| {
    let lowest = curve
        .iter()

]);
emit_table_with_columns!(
    columns,
    vec![
        summary("自然 3 次スプライン", &spline_curve),
        summary("PCHIP", &pchip_curve),
    ],
    metadata = serde_json::json!({ "id": "minimum" })
);
let samples: Vec<[f64; 2]> = HOURS
    .iter()
    .zip(irradiance(scale, cloud))
    .map(|(&t, g)| [t, g])
    .collect();
emit_line_chart!(
    &vec![
        serde_json::json!({ "name": "自然 3 次スプライン", "points": spline_curve }),

```

既定の条件では、スプラインは 4.1–4.7 h と 20.1–23.9 h で負になり（241 点のうち 46 点）、最小値は 21.7 h の $-11.2$ W/m² である。
日の入り後の負の値の方が大きいのは、18–20 時の急な減少が夜間の区間へ持ち越されるためである。
最初のセルで $f=0.9$ にすると午後の減少が緩やかになり、最小値は $-0.65$ W/m² まで小さくなるが、0 以上にはならない。
PCHIP の最小値はどの入力でも夜間の標本と同じ 0 で、負になる点はない。
表の PCHIP の時刻 0 h は最小値 0 をとる最初の評価点である。

## 累積日射量と微積分の基本定理

0 時から時刻 $t$ までの累積日射量

$$
E(t) = \int_0^t S(\tau)\,d\tau
$$

は、微積分の基本定理により $E'(t) = S(t)$ を満たす。
累積曲線の傾きはその時刻の補間した強度に等しく、負の強度の範囲では累積曲線が下がる。

この定理は差分でも確かめられる。
幅 $2\tau$ の区間 $[t-\tau,t+\tau]$ での平均 $\bigl(E(t+\tau)-E(t-\tau)\bigr)/(2\tau)$ を中点の強度 $S(t)$ と比べると、Taylor 展開から

$$
\frac{E(t+\tau)-E(t-\tau)}{2\tau} - S(t) = \frac{S''(t)}{6}\tau^2 + O(\tau^3)
$$

となる。
$O(\tau^3)$ の項は、節点で $S'''$ が跳ぶことから来る。
差が $\tau^2$ の大きさにとどまれば、準備した原始関数の値と補間した強度が基本定理で結びついていることを確かめられる。

次のセルは上のセルの $s$ と $f$ を受け取り、時刻 $t^*$ [h] を入力とする。
`prepare_antiderivative` で作った原始関数から 0.1 h ごとの累積曲線を描き、$t^*$ での強度 $S(t^*)$、傾き $S'(t^*)$、累積日射量 $E(t^*)$ を表に出す。
検算として、`integrate` で直接求めた $E(t^*)$ と準備した原始関数の値の差と、$\tau=0.01$ h の区間平均と中点の強度の差、その見込み $S''(t^*)\tau^2/6$ を示す。
$S''$ は両端の `derivative_at` の差分 $\bigl(S'(t+\tau)-S'(t-\tau)\bigr)/(2\tau)$ で求める。
一つの 3 次片の中では $S'$ が 2 次式なので、この差分は中点の $S''$ に等しい。
区間は $[0,24]$ の中に切り詰めるので、$t^*$ が端にあるときは中点がずれ、見込みはずれた中点で計算する。

```rust
//| id: interp-solar-cumulative
//| ref: interp-solar-cumulative
//| title: 準備した原始関数で累積日射量を描き、基本定理を確かめる
//| run: reactive
//| uses: [interp-solar-model]
//| crates: [scioxide-interp]
//| dependsOn:
//|   day: interp-solar-energy
//| inputs:
//|   solar_query_hour: {"type":"range","label":"時刻 t* [h]","description":"強度・傾き・累積日射量を読む時刻。","min":0,"max":24,"step":0.25,"value":12}
//| cases:
//|   - {"id":"after-sunset","label":"t* = 22 h","description":"スプラインの強度が負の時刻で、累積曲線の傾きも負になる。","inputs":{"solar_query_hour":22}}
//|   - {"id":"end-of-day","label":"t* = 24 h","description":"累積値が最初のセルのスプラインの日積算と一致する。","inputs":{"solar_query_hour":24}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"cumulative","path":"/rows/0/1","approx":{"value":2645.6,"atol":0.1}}
//|       - {"artifact":"cumulative","path":"/rows/0/2","range":{"min":-1e-9,"max":1e-9}}
//|       - {"artifact":"cumulative","path":"/rows/0/3","approx":{"value":-1.4e-3,"atol":1e-4}}
//|   - case: after-sunset
//|     expect:
//|       - {"artifact":"strength","path":"/rows/0/0","range":{"max":0}}
//|   - case: end-of-day
//|     expect:
//|       - {"artifact":"cumulative","path":"/rows/0/1","approx":{"value":6177.2,"atol":0.1}}
use scioxide_interp::{ExtrapolationPolicy, Univariate};

let scale = day["irradiance_scale"]
    .as_f64()
    .ok_or("全体の倍率がない")?;
let cloud = day["afternoon_cloud_fraction"]
    .as_f64()
    .ok_or("雲の減衰率がない")?;
let (spline, _) = solar_models(scale, cloud).map_err(|e| e.to_string())?;
// 区間ごとの原始関数と累積和を一度だけ作る
let primitive = spline.prepare_antiderivative().map_err(|e| e.to_string())?;
let reject = ExtrapolationPolicy::Reject;
let energy = |t: f64| {
    primitive
        .integral(0.0, t, reject)
        .map_err(|e| e.to_string())
};

let mut cumulative = Vec::new();
for i in 0..=240 {
    let t = 0.1 * f64::from(i);
    cumulative.push([t, energy(t)?]);
}
let t = solar_query_hour;
let direct = spline.integrate(0.0, t).map_err(|e| e.to_string())?;
let value = spline.value_at(t).map_err(|e| e.to_string())?;
let slope = spline.derivative_at(t).map_err(|e| e.to_string())?;
// 基本定理の検算: 半幅 τ = 0.01 h の区間平均と中点の強度、見込み S″τ²/6
let (a, b) = ((t - 0.01).max(0.0), (t + 0.01).min(24.0));
let middle = 0.5 * (a + b);
let average = (energy(b)? - energy(a)?) / (b - a);
let midpoint = spline.value_at(middle).map_err(|e| e.to_string())?;
// 3 次片の S′ は 2 次式なので、両端の S′ の差分は中点の S″ に等しい
let slope_right = spline.derivative_at(b).map_err(|e| e.to_string())?;
let slope_left = spline.derivative_at(a).map_err(|e| e.to_string())?;
let curvature = (slope_right - slope_left) / (b - a);
let half = 0.5 * (b - a);

let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let fixed1 = serde_json::json!({ "fractionDigits": 1 });
emit_table_with_columns!(
    serde_json::json!([
        {
            "key": "0",
            "label": "S(t*) [W/m²]",
            "type": "number",
            "format": { "fractionDigits": 2 }
        },
        {
            "key": "1",
            "label": "S′(t*) [W/(m²·h)]",
            "type": "number",
            "format": { "fractionDigits": 2 }
        }
    ]),
    vec![(value, slope)],
    metadata = serde_json::json!({ "id": "strength" })
);
emit_table_with_columns!(
    serde_json::json!([
        { "key": "0", "label": "時刻 t* [h]", "type": "number", "format": { "fractionDigits": 2 } },
        {
            "key": "1",
            "label": "E(t*)（準備した原始関数）[Wh/m²]",
            "type": "number",
            "format": fixed1
        },
        { "key": "2", "label": "integrate との差 [Wh/m²]", "type": "number", "format": sci2 },
        { "key": "3", "label": "区間平均 − 中点の強度 [W/m²]", "type": "number", "format": sci2 },
        { "key": "4", "label": "見込み S″τ²/6 [W/m²]", "type": "number", "format": sci2 }
    ]),
    vec![(t, energy(t)?, direct - energy(t)?, average - midpoint, curvature * half * half / 6.0)],
    metadata = serde_json::json!({ "id": "cumulative" })
);
emit_line_chart!(
    &vec![serde_json::json!({ "name": "累積日射量 E(t)", "points": cumulative })],
    options = &serde_json::json!({
        "link": { "group": "solar-time" },
        "xLabel": "時刻 t [h]",
        "yLabel": "累積日射量 E(t) [Wh/m²]",
        "annotations": [{ "kind": "line", "axis": "x", "value": t, "label": "t*" }]
    })
);
```

既定の $t^*=12$ h では $E(t^*)=2645.6$ Wh/m² で、準備した原始関数と `integrate` の差は 0 である。
区間平均と中点の強度の差は $-1.4\times10^{-3}$ W/m² で、見込み $S''\tau^2/6$ とほぼ等しく、基本定理と矛盾しない。
$t^*=0$ や 24 h では区間を片側に切り詰めるが、自然境界条件で端の $S''$ が 0 なので、差は $10^{-7}$ W/m² 以下である。
$t^*=22$ h では $S(t^*)$ が負で、累積曲線もこの時刻で下がっている。
累積曲線は 20 時の 6206.3 Wh/m² から 24 時の 6177.2 Wh/m² まで約 29 Wh/m² 下がり、非負性の実験で見た 20.1–23.9 h の負の強度に対応する。
反対に 0–4 時ではスプラインがわずかに正になり、標本がすべて 0 の夜間に 4.2 Wh/m² が加わる。
24 時の累積値は日積算の実験で求めたスプラインの日積算 6177.2 Wh/m² と一致する。

## まとめ

日射量の積算は標本の間をつなぐモデルの選択に依存する。
3 次の補間と台形則の差は $\sum h_i^2(d_i-d_{i+1})/12$ で、節点の傾きから計算できるモデルの差であり、この表の PCHIP では 0 になる。
自然 3 次スプラインは日の出前や日の入り後に負の強度を作ることがあり、非負性が必要なら PCHIP を使うか夜間を 0 と定義する。
同じ補間を繰り返し積分するときは `prepare_antiderivative` で原始関数を準備し、`integrate` と一致することを確かめる。
この観測表には真の日積算がないので、表で比べた値はモデルどうしの差であり、積分の誤差ではない。
