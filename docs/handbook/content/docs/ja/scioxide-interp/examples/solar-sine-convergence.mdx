[日射強度表を積分する](../solar-energy/)の観測表には真の日積算がないので、そこで比べたのはモデルどうしの差だった。
このページでは解析的に積分できる日射モデルを標本化し、既知の積分との差から積分の誤差そのものを測る。
標本の間隔を半分にしたときの誤差の比から収束の次数を求め、スプラインの端の条件と、日の出・日の入りで傾きが跳ぶ角が次数をどう変えるかを確かめる。

## 太陽高度から作る正弦の日射モデル

太陽高度 $\alpha$ は、緯度 $\varphi$、太陽の赤緯 $\delta$、時角 $\omega=15^\circ\,(t-12)$（$t$ は地方太陽時 [h]）から

$$
\sin\alpha = \sin\varphi\sin\delta + \cos\varphi\cos\delta\cos\omega
$$

で決まる。
春分・秋分（$\delta=0$）では $\sin\alpha=\cos\varphi\cos\omega$ となり、日の出は 6 時、日の入りは 18 時である。
大気による減衰を無視し、水平面の強度を $G=G_n\sin\alpha$（$G_n$ は太陽に正対する面の強度）とおく。
$G_n=1000$ W/m²、$\varphi=36.87^\circ$（$\cos\varphi=0.8$）とすると、

$$
G(t)=800\cos\frac{\pi(t-12)}{12}=800\sin\frac{\pi(t-6)}{12}\ \mathrm{W/m^2}\quad(6\le t\le18),\qquad G(t)=0\quad(\text{それ以外})
$$

となる。
区間 $[a,b]$ での積分は、$a'=\max(a,6)$、$b'=\min(b,18)$ とおくと

$$
E(a,b)=\int_{a'}^{b'}800\sin\frac{\pi(t-6)}{12}\,dt=\frac{9600}{\pi}\left[\cos\frac{\pi(a'-6)}{12}-\cos\frac{\pi(b'-6)}{12}\right]\ \mathrm{Wh/m^2}
$$

である。
昼間の日積算は $E(6,18)=19200/\pi\approx6111.55$ Wh/m² になる。
このモデルは太陽の幾何だけを表し、大気の透過率や散乱光を含まない。

## 誤差の次数の見込み

間隔 $h$ の等間隔の標本で、台形則の誤差は Euler–Maclaurin の公式から

$$
E_{\text{trap}}-E=\frac{h^2}{12}\bigl[G'(b)-G'(a)\bigr]+O(h^4)
$$

となる（被積分関数が $[a,b]$ で滑らかな場合）。
主要項は両端の傾きだけで決まり、台形則の次数は 2 である。

3 次スプラインの積分と台形則の差は、[日射強度表を積分する](oxref:interp-solar-integral-trapezoid)で導いたとおり $\sum h_i^2(d_i-d_{i+1})/12$ で、等間隔なら $h^2(d_0-d_n)/12$ に縮む。
したがってスプラインの積分の誤差は

$$
E_{\text{spline}}-E=\frac{h^2}{12}\Bigl[\bigl(d_0-G'(a)\bigr)-\bigl(d_n-G'(b)\bigr)\Bigr]+O(h^4)
$$

で、端の傾き $d_0,d_n$ の誤差が次数を決める。

- not-a-knot の端（端の 2 区間を一つの 3 次式にする条件）では、滑らかな $G$ に対して端の傾きの誤差が $O(h^3)$ になり（de Boor の第 IV 章）、積分の誤差は $O(h^4)$ である。
- 自然な端（$S''=0$）では、$G''(a)\ne0$ なら端の傾きの誤差が $O(h)$ になり、積分の誤差は $O(h^3)$ に下がる。
  $G''(a)=0$ なら端の条件は真の関数と一致し、積分の誤差は $O(h^4)$ のままである。
- 区間の中に $G'$ が跳ぶ角があり、それが節点にあれば、Euler–Maclaurin の公式は角で区切った各区間に当てはまる。
  $[0,24]$ では夜間の区間で $G'=0$ なので、台形則の主要項は $[6,18]$ と同じ $h^2[G'(18)-G'(6)]/12$ である。
  スプラインは角の左右を一つの $C^2$ 曲線でつなぐので、角の近くで $O(h)$ の誤差を持つ。

このモデルの $G$ は $t=6$、18 h で $G=0$ かつ $G''=0$ を満たす。
$[6,18]$ を標本にすれば自然な端がちょうど成り立ち、$[8,16]$ を標本にすれば端で $G''=-800(\pi/12)^2\sin(\pi/6)\ne0$ となる。

## 次数の測定

次のセルは標本の範囲と端の条件を選び、等間隔の標本数 $N$ を 5 から 129 まで（間隔を半分ずつに）変えて、スプラインの積分と台形則の誤差を $E(a,b)$ と比べる。
$[0,24]$ でも標本数が $2^k+1$ なので、$t=6$、18 h は必ず節点になる。
表の誤差は符号付きの $E_{\text{model}}-E$ で、観測次数は間隔が半分になるごとの誤差の絶対値の比から $\log_2(|e_{N}|/|e_{2N-1}|)$ で求める。
最後の列は台形則の誤差の Euler–Maclaurin の主要項で、$[0,24]$ では $[6,18]$ の端の傾きで計算する。
グラフは両対数で、点が観測した誤差、破線が台形則の主要項と、最も細かい標本を通る理論次数の傾きの線である。
モデルの正弦と余弦は `RealScalar::sin`、`RealScalar::cos` で計算する。

```rust
//| id: interp-solar-sine-convergence
//| ref: interp-solar-sine-convergence
//| title: 解析的な日射モデルの積算誤差を標本数で比較する
//| run: reactive
//| crates: [scioxide-core, scioxide-interp]
//| inputs:
//|   sampling_window: {"type":"select","label":"標本の範囲","options":[{"label":"昼間 [6, 18] h（端で G = G″ = 0）","value":"day"},{"label":"日中の一部 [8, 16] h（端で G″ ≠ 0）","value":"inner"},{"label":"終日 [0, 24] h（6 時と 18 時に角）","value":"full"}],"value":"day"}
//|   spline_ends: {"type":"select","label":"スプラインの端の条件","options":[{"label":"自然（S″ = 0）","value":"natural"},{"label":"not-a-knot","value":"not-a-knot"}],"value":"natural"}
//| cases:
//|   - {"id":"inner-natural","label":"[8, 16] h、自然","description":"端で G″ ≠ 0 なので、自然な端のスプラインの次数が 3 に下がる。","inputs":{"sampling_window":"inner"}}
//|   - {"id":"inner-not-a-knot","label":"[8, 16] h、not-a-knot","description":"端の条件を not-a-knot にすると、次数が 4 に戻る。","inputs":{"sampling_window":"inner","spline_ends":"not-a-knot"}}
//|   - {"id":"full-day","label":"[0, 24] h","description":"日の出と日の入りの角で、スプラインも台形則も次数 2 になる。","inputs":{"sampling_window":"full"}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"orders","path":"/rows/0/2","approx":{"value":-3.9926,"atol":1e-3}}
//|       - {"artifact":"orders","path":"/rows/0/3","equals":null}
//|       - {"artifact":"orders","path":"/rows/5/3","approx":{"value":4,"atol":0.05}}
//|       - {"artifact":"orders","path":"/rows/5/5","approx":{"value":2,"atol":0.01}}
//|       - {"artifact":"orders","path":"/rows/5/6","approx":{"value":-0.30680,"atol":1e-4}}
//|   - case: inner-natural
//|     expect:
//|       - {"artifact":"orders","path":"/rows/5/3","approx":{"value":3,"atol":0.05}}
//|   - case: inner-not-a-knot
//|     expect:
//|       - {"artifact":"orders","path":"/rows/5/3","range":{"min":3.5,"max":4.2}}
//|       - {"artifact":"orders","path":"/rows/5/2","range":{"min":-1e-6,"max":1e-6}}
//|   - case: full-day
//|     expect:
//|       - {"artifact":"orders","path":"/rows/5/3","approx":{"value":2,"atol":0.05}}
//|       - {"artifact":"orders","path":"/rows/5/2","approx":{"value":-1.22723,"atol":1e-4}}
use scioxide_core::RealScalar;
use scioxide_interp::{CubicSpline, SplineBoundary, Univariate};

let pi = std::f64::consts::PI;
// 春分・秋分、cos φ = 0.8、G_n = 1000 W/m² の水平面日射 G(t) [W/m²] と G′(t) [W/(m²·h)]
let model = |t: f64| {
    if (6.0..=18.0).contains(&t) {
        800.0 * RealScalar::sin(pi * (t - 6.0) / 12.0)
    } else {
        0.0
    }
};
let model_slope = |t: f64| 800.0 * pi / 12.0 * RealScalar::cos(pi * (t - 6.0) / 12.0);
let (start, end) = match sampling_window.as_str() {
    "inner" => (8.0, 16.0),
    "full" => (0.0, 24.0),
    _ => (6.0, 18.0),
};
// 日照のある部分 [a′, b′] と、閉形式の E(a, b)（参照値）
let (lit_start, lit_end) = (start.max(6.0), end.min(18.0));
let phase = |t: f64| RealScalar::cos(pi * (t - 6.0) / 12.0);
let exact = 9600.0 / pi * (phase(lit_start) - phase(lit_end));
let natural = spline_ends == "natural";
let boundary = if natural {
    SplineBoundary::Natural
} else {
    SplineBoundary::NotAKnot
};
// 本文の見込みによるスプラインの理論次数
let theory = match (sampling_window.as_str(), natural) {
    ("full", _) => 2.0,
    ("inner", true) => 3.0,
    _ => 4.0,
};

let (mut rows, mut curves) = (Vec::new(), [Vec::new(), Vec::new(), Vec::new()]);
let mut previous: Option<(f64, f64)> = None;
for count in [5_usize, 9, 17, 33, 65, 129] {
    let h = (end - start) / (count - 1) as f64;
    let times: Vec<f64> = (0..count).map(|i| start + h * i as f64).collect();
    let values: Vec<f64> = times.iter().map(|&t| model(t)).collect();
    let trapezoid: f64 = values.windows(2).map(|g| 0.5 * h * (g[0] + g[1])).sum();
    let spline =
        CubicSpline::with_boundary(times, values, boundary).map_err(|e| e.to_string())?;
    let integral = spline.integrate(start, end).map_err(|e| e.to_string())?;
    let errors = (integral - exact, trapezoid - exact);
    // 台形則の誤差の Euler–Maclaurin の主要項 h²[G′(b′) − G′(a′)]/12
    let leading = h * h / 12.0 * (model_slope(lit_end) - model_slope(lit_start));
    // 間隔が半分になったときの誤差の比から観測次数を求める。最初の行は空欄。
    let order = |now: f64, before: f64| RealScalar::log2(before.abs() / now.abs());
    let orders = previous.map(|(s, t)| (order(errors.0, s), order(errors.1, t)));
    previous = Some(errors);
    curves[0].push([h, errors.0.abs()]);
    curves[1].push([h, errors.1.abs()]);
    curves[2].push([h, leading.abs()]);
    rows.push((
        count,
        h,
        errors.0,
        orders.map(|o| o.0),
        errors.1,
        orders.map(|o| o.1),
        leading,
    ));
}
// 最も細かい標本を通る理論次数の傾きの線
let [h_last, e_last] = curves[0][curves[0].len() - 1];
let guide: Vec<[f64; 2]> = curves[0]
    .iter()
    .map(|p| [p[0], e_last * RealScalar::powf(p[0] / h_last, theory)])
    .collect();

let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let fixed2 = serde_json::json!({ "fractionDigits": 2 });
let columns = serde_json::json!([
    { "key": "0", "label": "標本数 N", "type": "integer" },
    { "key": "1", "label": "間隔 h [h]", "type": "number", "format": { "significantDigits": 4 } },
    { "key": "2", "label": "スプラインの誤差 [Wh/m²]", "type": "number", "format": sci3 },
    {
        "key": "3",
        "label": "スプラインの観測次数",
        "type": "number",
        "format": fixed2,
        "nullText": "—"
    },
    { "key": "4", "label": "台形則の誤差 [Wh/m²]", "type": "number", "format": sci3 },
    {
        "key": "5",
        "label": "台形則の観測次数",
        "type": "number",
        "format": fixed2,
        "nullText": "—"
    },
    { "key": "6", "label": "台形則の主要項 [Wh/m²]", "type": "number", "format": sci3 }
]);
emit_table_with_columns!(columns, rows, metadata = serde_json::json!({ "id": "orders" }));
emit_chart!(
    serde_json::json!({
        "kind": "line",
        "dataZoom": true,
        "tooltip": true,
        "series": [
            {
                "name": "スプラインの誤差",
                "points": curves[0],
                "style": { "showSymbol": true, "symbol": "circle" }
            },
            {
                "name": "台形則の誤差",
                "points": curves[1],
                "style": { "showSymbol": true, "symbol": "diamond" }
            },
            {
                "name": "台形則の主要項（Euler–Maclaurin）",
                "points": curves[2],
                "style": { "lineType": "dashed", "showSymbol": false }
            },
            {
                "name": format!("理論次数 {theory} の傾き"),
                "points": guide,
                "style": { "lineType": "dashed", "showSymbol": false }
            }
        ],
        "xLabel": "間隔 h [h]",
        "yLabel": "日積算の誤差の絶対値 [Wh/m²]",
        "xType": "log",
        "yType": "log"
    }),
    metadata = serde_json::json!({ "id": "errors" })
);
```

昼間 $[6,18]$ を自然な端で標本にする既定では、スプラインの誤差は $N=5$ の $-3.99$ Wh/m² から $N=129$ の $-3.1\times10^{-6}$ Wh/m² まで下がり、観測次数は 4.00 に収束する。
台形則の観測次数は 2.00 で、$N=129$ でも $-0.307$ Wh/m² の誤差が残る。
台形則の誤差は Euler–Maclaurin の主要項 $h^2[G'(18)-G'(6)]/12=-(h^2/12)(400\pi/3)$ と、$N=129$ で $3\times10^{-6}$ Wh/m² の差まで一致する。
残りの差は $O(h^4)$ の項である。
ここではモデルの $G''=0$ が自然な端の条件と一致しているので、スプラインは 4 次になる。

$[8,16]$ では端で $G''\ne0$ となり、自然な端のスプラインの観測次数は 3.05 から 3.00 へ収束する。
端の条件を not-a-knot にすると、$N=129$ の誤差は $-4.7\times10^{-7}$ Wh/m² で、自然な端の $-3.2\times10^{-4}$ Wh/m² の約 700 分の 1 である。
ただし not-a-knot の誤差は $N=9$ と 17 の間で符号を変えるので、その前後の観測次数は 10.4 や $-1.21$ のような意味のない値になる。
誤差が 0 を横切る所では比 $|e_N|/|e_{2N-1}|$ が次数を表さないので、次数は符号が定まった細かい標本で読む。
最後の 2 行の観測次数は 3.48 と 3.81 で、4 に近づいている。

夜間を含めた $[0,24]$ では、どちらの観測次数も 2.00 になる。
$N=129$ のスプラインの誤差 $-1.2272$ Wh/m² は、台形則の誤差と $2\times10^{-12}$ Wh/m² の差まで一致する。
上の式でスプラインと台形則の差は $h^2(d_0-d_n)/12$ で、0 時と 24 時の傾き $d_0,d_n$ は、角からの影響が節点ごとにおよそ $2-\sqrt3\approx0.27$ 倍に減衰するので、ほとんど 0 になる。
その結果、スプラインの積分は台形則と同じ $O(h^2)$ の誤差を持ち、主要項も台形則の Euler–Maclaurin の主要項になる。
この結果は、[日射強度表を積分する](../solar-energy/)の観測表のように夜間の 0 を含む標本では、3 次の補間の日積算が台形則より正確だとは限らないことを示す。

## まとめ

解析的に積分できるモデルを使うと、補間の積分の誤差を既知の値との差として測れる。
滑らかな被積分関数では、台形則の誤差は 2 次で、主要項は Euler–Maclaurin の公式 $h^2[G'(b)-G'(a)]/12$ で予測できる。
3 次スプラインの積分の次数は端の傾きの精度で決まり、not-a-knot か、関数の $G''$ が端で 0 のときの自然な端では 4、それ以外の自然な端では 3 になる。
夜間の 0 を含めて標本にすると、日の出と日の入りの傾きの跳びで、スプラインも台形則も次数 2 になる。
観測次数は誤差の符号が定まった細かい標本で読み、実測の表で 3 次の補間を使う前に、角や端の条件が収束の次数を下げていないかを確かめる。
