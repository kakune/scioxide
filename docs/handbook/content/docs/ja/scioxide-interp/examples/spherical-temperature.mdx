全球の気温を地図上で補間するとき、緯度・経度の度数をそのまま平面の距離とみなすと、極付近で歪みが大きくなる。
球面スプラインなら、経度の周期性と極で値が一つに決まることを基底の段階で満たせる。
ここでは全球平均が厳密に分かる人工的な気温場を使い、地図の当てはめ誤差と全球平均の誤差を分けて調べる。

## 合成場と面積平均

単位球上に、余緯度 $\theta$（北極から測った角）と経度 $\phi$ の関数として

$$
T(\theta,\phi)=15+8\cos\theta+3\sin\theta\cos\phi
\quad[{}^\circ\mathrm C]
$$

を置く。
北極側が暖かく、経度 0 の側が暖かい、方向性のある温度差を持つ。
第 2 項と第 3 項は 1 次の球面調和関数 $Y_1^0$ と $Y_1^1$ の実部に比例し、定数項は $Y_0^0=1/\sqrt{4\pi}$ の定数倍である。
球面調和関数は互いに直交するので、1 次の二項の全球積分は 0 になる。
したがって、全球平均 $\overline T=(4\pi)^{-1}\int_0^{2\pi}\!\int_0^\pi T\sin\theta\,d\theta\,d\phi$ は定数項の係数そのものの $15\ {}^\circ\mathrm C$ である。
これは気候の実測モデルではなく、極、経度の継ぎ目、面積平均を検証するための場である。

観測点は $z=\cos\theta$ を $[-1,1]$ から、経度を $[0,2\pi)$ から、それぞれ一様乱数で発生させる。
Archimedes の定理により、球面上の帯の面積は $z$ の幅に比例するので、この点は球面上で面積について一様に分布する。
余緯度 $\theta$ そのものを一様にすると、面積の小さい極付近に点が偏る。
発生させた点のうち 5 個に 1 個を当てはめから除き、除いた点での温度差を検証に使う。
これにより、当てはめに使った標本での残差とは別の誤差を測れる。

## 球面スプラインと残差目標による当てはめ

`SphericalSpline` は、余緯度方向の 3 次 B スプラインと経度方向の周期的な 3 次 B スプラインのテンソル積に、極での値と接平面を決める 6 個の極モードを加えたものである。
極モードを除くテンソル積の基底は両極で値と傾きが 0 になるので、曲面は極を含めて至るところ $C^1$ 級で、極での値は経度によらず一つに決まる。
点の座標は `[余緯度, 経度]`（rad）の順で、経度は周期 $2\pi$ で折り返される。

オプション付き形式 `fit_spherical_spline_with_options` は極モードだけの基底（余緯度の区切り点 $[0,\pi]$、経度 4 区間）から出発する。
目標 `SplineFitTarget::Residual(S)` では、重み付き残差平方和が $S$（と許容誤差）以下になるまで、残差の和が最大の区間を二分する区切り点を、余緯度と経度で交互に（余緯度から）挿入する。
その後、$\lambda=1$ から 16 倍ずつ増やして条件を満たさなくなる値を見つけ、二分法で条件を満たす最大のペナルティ $\lambda$ を探す。
各試行は区切り点を固定した `SphericalSplinePlan` の当てはめ（重み付き残差平方和と、$\lambda$ 倍の係数の 2 階差分のペナルティの和の最小化）である。
ペナルティの試行の上限を既定の 32 回から 64 回に上げ、終了状態をレポートで読むので、ワンショット関数 `fit_spherical_spline` ではなくオプション付き形式を使う。
ペナルティの探索の上限は `SplineFitLimits::with_max_penalty_iterations(64)` で与える。

入力の平滑化尺度 $\tau$ [°C] は許容する残差の RMS の目安であり、当てはめに使う標本数 $n$ から目標を $S=n\tau^2$ とする。
$\tau$ は測定誤差の推定値ではなく、この人工場でどこまで当てはめるかを決める操作量である。
目標を小さくすると、区切り点の追加と小さいペナルティが必要になる。
残差の判定には絶対 $10^{-10}$・相対 $10^{-4}$ の許容誤差を使う。
終了状態 `AdaptiveSplineTermination` が `ResidualSatisfied` なら、目標を満たし、ペナルティの探索も許容誤差の範囲で終わったことを示し、`is_success()` が真になる。

除いた $m$ 点での誤差 $e_j$ から、二乗平均 $\overline{e^2}$ とその標準誤差 $\mathrm{SE}=s_{e^2}/\sqrt m$ を求める。
RMSE $=\sqrt{\overline{e^2}}$ の不確かさは、デルタ法で $\mathrm{SE}/(2\,\mathrm{RMSE})$ と近似する。
除く点が既定で 20 点と少ないので、この不確かさは無視できない。

次のブロックは、ページの二つのセルが共有する合成場と観測点である。
`temperature` が $T(\theta,\phi)$、`observations` が当てはめ用の点と値、検証用に除いた点、`fit_options` が残差目標 $S=n\tau^2$ と探索の上限に対応する。

```rust
//| id: interp-spherical-temperature-model
//| kind: definitions
//| title: 合成気温場と観測点
//| crates: [scioxide-core, scioxide-interp, scioxide-random]
use scioxide_core::{SciOxideError, RealScalar, Tolerance};
use scioxide_interp::{AdaptiveSplineOptions, SplineFitLimits, SplineFitTarget};
use scioxide_random::{Rng, SeedableRng, SplitMix64};

/// T(θ, φ) = 15 + 8 cos θ + 3 sin θ cos φ [°C]（θ は余緯度、φ は経度、rad）。
pub(crate) fn temperature(theta: f64, phi: f64) -> f64 {
    15.0 + 8.0 * RealScalar::cos(theta) + 3.0 * RealScalar::sin(theta) * RealScalar::cos(phi)
}

/// 面積について一様な count 点を発生させ、5 点に 1 点を検証用に除く。
/// 返り値は（当てはめ用の [θ, φ]、その値、除いた [θ, φ]）。
pub(crate) fn observations(
    count: usize,
    seed: f64,
) -> Result<(Vec<[f64; 2]>, Vec<f64>, Vec<[f64; 2]>), SciOxideError> {
    let mut rng = SplitMix64::from_seed(seed as u64);
    let (mut sites, mut values, mut held) = (Vec::new(), Vec::new(), Vec::new());
    for i in 0..count {
        let uniform_z: f64 = rng.next_float()?;
        let uniform_phi: f64 = rng.next_float()?;
        // z = cos θ と経度を一様にする
        let point = [
            RealScalar::acos(2.0 * uniform_z - 1.0),
            std::f64::consts::TAU * uniform_phi,
        ];
        if i % 5 == 0 {
            held.push(point);
        } else {
            sites.push(point);
            values.push(temperature(point[0], point[1]));
        }
    }
    Ok((sites, values, held))
}

/// 残差目標 S = nτ²、許容誤差（絶対 10⁻¹⁰、相対 10⁻⁴）、ペナルティの試行 64 回。
pub(crate) fn fit_options(
    fitted: usize,
    strength: f64,
) -> Result<AdaptiveSplineOptions<f64>, SciOxideError> {
    Ok(AdaptiveSplineOptions::new()
        .with_target(SplineFitTarget::Residual(
            fitted as f64 * strength * strength,
        ))
        .with_limits(SplineFitLimits::new().with_max_penalty_iterations(64))
        .with_residual_tolerance(Tolerance::new(1e-10, 1e-4)?))
}
```

## 当てはめと地図

次のセルの入力は発生させる観測点の数、平滑化尺度 $\tau$、乱数のシードである。
1 つ目の表は当てはめの終了状態、残差平方和と目標、挿入した区切り点、ペナルティを、2 つ目の表は当てはめた点と除いた点の数、除いた点の RMSE と 95% 区間の半幅（1.96 倍の近似 SE）を示す。
地図は地理緯度 $90^\circ-\theta$ と経度 $[-180^\circ,180^\circ)$ の $10^\circ$ 格子の中心で評価する。
地図の座標は `[余緯度, 経度]`（rad）に変換して渡す。
色の範囲は合成場の値域 $[15-\sqrt{73},15+\sqrt{73}]\approx[6.5,23.5]$ °C を含む 6〜24 °C に固定する。
このセルは観測点、区切り点、ペナルティと係数を次のセルに渡す。

```rust
//| id: interp-spherical-temperature
//| ref: interp-spherical-temperature
//| title: 球面の気温場を当てはめ、除いた観測点で検算する
//| run: reactive
//| uses: [interp-spherical-temperature-model]
//| crates: [scioxide-core, scioxide-interp, scioxide-random]
//| exports: [sites, values, theta_breaks, longitude_breaks, penalty, coefficients]
//| inputs:
//|   samples: {"type":"range","label":"発生させる観測点の数 [-]","min":80.0,"max":160.0,"step":20.0,"value":100.0}
//|   strength: {"type":"range","label":"許容する残差の RMS 尺度 τ [°C]","min":0.02,"max":0.08,"step":0.01,"value":0.04}
//|   seed: {"type":"range","label":"乱数のシード","min":1.0,"max":100.0,"step":1.0,"value":7.0}
//| cases:
//|   - {"id":"loose-target","label":"τ = 0.08 °C","description":"目標を緩めると区切り点が減り、ペナルティが大きくなる。","inputs":{"strength":0.08}}
//|   - {"id":"more-stations","label":"160 点","description":"観測点を増やすと除いた点も 32 点に増える。","inputs":{"samples":160}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"fit","path":"/rows/0/0","equals":"ResidualSatisfied"}
//|       - {"artifact":"fit","path":"/rows/0/1","approx":{"value":0.128,"rtol":1e-4}}
//|       - {"artifact":"fit","path":"/rows/0/3","equals":3}
//|       - {"artifact":"holdout","path":"/rows/0/1","equals":20}
//|       - {"artifact":"holdout","path":"/rows/0/2","approx":{"value":0.04237,"rtol":1e-3}}
//|       - {"artifact":"holdout","path":"/rows/0/3","approx":{"value":0.01204,"rtol":1e-3}}
//|       - {"path":"/outputs/3/state","equals":"satisfied"}
//|   - case: loose-target
//|     expect:
//|       - {"artifact":"fit","path":"/rows/0/3","equals":1}
//|       - {"artifact":"holdout","path":"/rows/0/2","approx":{"value":0.09272,"rtol":1e-3}}
//|       - {"path":"/outputs/3/state","equals":"satisfied"}
//|   - case: more-stations
//|     expect:
//|       - {"artifact":"holdout","path":"/rows/0/0","equals":128}
//|       - {"artifact":"holdout","path":"/rows/0/1","equals":32}
//|       - {"artifact":"holdout","path":"/rows/0/2","approx":{"value":0.04933,"rtol":1e-3}}
use scioxide_core::RealScalar;
use scioxide_interp::{
    ExtrapolationPolicy, Interpolant, SphericalSamples, fit_spherical_spline_with_options,
};

let (sites, values, held) = observations(samples as usize, seed).map_err(|e| e.to_string())?;
let options = fit_options(values.len(), strength).map_err(|e| e.to_string())?;
let grid = SphericalSamples::Scattered(&sites);
// 未達の終了状態もレポートで示すため、レポートを返すオプション付き形式を使う
let fit = fit_spherical_spline_with_options(grid, &values, None, options)
    .map_err(|e| e.to_string())?;
let spline = fit.spline();
let policy = ExtrapolationPolicy::Reject;
let mut squares = Vec::new();
for &[t, p] in &held {
    let error = spline.evaluate([t, p], policy).map_err(|e| e.to_string())? - temperature(t, p);
    squares.push(error * error);
}
// 二乗誤差の平均と SE、デルタ法による RMSE の SE
let m = squares.len() as f64;
let mse = squares.iter().sum::<f64>() / m;
let variance = squares.iter().map(|s| (s - mse) * (s - mse)).sum::<f64>() / (m - 1.0);
let rmse = RealScalar::sqrt(mse);
let half = 1.96 * RealScalar::sqrt(variance / m) / (2.0 * rmse);
let mut map = Vec::new();
for i in 0..18 {
    let latitude = -85.0 + 10.0 * i as f64;
    for j in 0..36 {
        let longitude = -175.0 + 10.0 * j as f64;
        let degree = std::f64::consts::PI / 180.0;
        let point = [(90.0 - latitude) * degree, longitude * degree];
        let value = spline.evaluate(point, policy).map_err(|e| e.to_string())?;
        map.push([longitude, latitude, value]);
    }
}
let report = fit.report();
let target = values.len() as f64 * strength * strength;
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let fit_columns = serde_json::json!([
    { "key": "0", "label": "終了状態" },
    { "key": "1", "label": "残差平方和 [°C²]", "type": "number", "format": sci3 },
    { "key": "2", "label": "目標 S [°C²]", "type": "number", "format": sci3 },
    { "key": "3", "label": "挿入した区切り点 [-]", "type": "integer" },
    { "key": "4", "label": "ペナルティ λ [-]", "type": "number", "format": sci3 }
]);
let fit_rows = vec![(
    format!("{:?}", report.termination()),
    report.residual(),
    target,
    report.refinements(),
    report.penalty(),
)];
emit_table_with_columns!(
    fit_columns,
    fit_rows,
    metadata = serde_json::json!({ "id": "fit" })
);
let fixed3 = serde_json::json!({ "fractionDigits": 3 });
let holdout_columns = serde_json::json!([
    { "key": "0", "label": "当てはめた点 [-]", "type": "integer" },
    { "key": "1", "label": "除いた点 [-]", "type": "integer" },
    { "key": "2", "label": "除いた点の RMSE [°C]", "type": "number", "format": fixed3 },
    { "key": "3", "label": "RMSE の 1.96 SE [°C]", "type": "number", "format": fixed3 }
]);
let holdout = vec![(sites.len(), held.len(), rmse, half)];
emit_table_with_columns!(
    holdout_columns,
    holdout,
    metadata = serde_json::json!({ "id": "holdout" })
);
emit_chart!(serde_json::json!({
    "kind": "heatmap",
    "data": map,
    "xLabel": "経度 [°]",
    "yLabel": "地理緯度 [°]",
    "title": "球面スプラインの気温 [°C]",
    "colorMin": 6.0,
    "colorMax": 24.0
}));
// 区切り点: 余緯度は両端が 4 重のノット列、経度は周期のため両端に 3 個ずつ延長したノット列
let [theta_knots, longitude_knots] = spline.knots();
let mut theta_breaks = theta_knots.to_vec();
theta_breaks.dedup();
let longitude_breaks = longitude_knots[3..longitude_knots.len() - 3].to_vec();
export!(sites, sites);
export!(values, values);
export!(theta_breaks, theta_breaks);
export!(longitude_breaks, longitude_breaks);
export!(penalty, report.penalty());
export!(coefficients, spline.coefficients().to_vec());

let termination = report.termination();
let outcome = if termination.is_success() {
    Outcome::satisfied("残差平方和が目標を満たし、ペナルティの探索も終わった")
} else {
    Outcome::partial("当てはめが目標を満たす前に止まった")
        .explanation("返された曲面は最後に受理したもので、目標か試行の上限を見直す。")
};
emit_outcome!(
    outcome
        .status(format!("{termination:?}"))
        .diagnostic("残差平方和", report.residual(), Some("°C²"))
        .diagnostic("目標", target, Some("°C²"))
        .diagnostic("除いた点の RMSE", rmse, Some("°C"))
);
```

既定値（100 点、$\tau=0.04$ °C、シード 7）では、当てはめは区切り点を 3 個挿入し、ペナルティ $\lambda\approx0.049$ で残差平方和を目標 0.128 °C² に合わせて `ResidualSatisfied` で終わる。
除いた 20 点の RMSE は 0.042 °C で、当てはめに使った点の RMS 尺度 $\tau$ と同程度である。
95% 区間の半幅は 0.012 °C で RMSE の 3 割に当たり、シードを 1 と 100 に変えたときの RMSE（0.031 と 0.043 °C）はこの区間の幅でおおむね説明できる。
$\tau$ を 0.02 °C にすると挿入する区切り点は 5 個に増え、除いた点の RMSE は 0.035 °C に下がるが、$\tau$ に比例しては下がらない。
当てはめに使った点の残差と、使っていない点の誤差が同じとは限らないからである。
$\tau=0.08$ °C では区切り点は 1 個で、RMSE は 0.093 °C になる。
地図の長方形の各画素は同じ球面積を表さない（画素の面積は緯度の余弦に比例する）ので、全球平均には画素値の単純平均を使わない。

## 全球平均の検算

スプラインの全球平均は二通りに求められる。
一つは `Integrable::integral` による面積積分である。
`SphericalSpline` の積分は面積要素 $\sin\theta\,d\theta\,d\phi$ に対する積分であり、`[0, 0]` から `[π, 2π]` の範囲で全球の積分になる。
余緯度の各区間で $\theta^n\sin\theta$ の積分を 32 項の Taylor 級数で求め、その打ち切り誤差は `f64` の丸めより小さいので、離散的な求積の誤差を含まない。

もう一つは `scioxide-integrate` の Lebedev 則である。
Lebedev 則は次数 $d$ 以下の球面多項式（$x,y,z$ の $d$ 次以下の多項式の球面への制限、すなわち次数 $d$ 以下の球面調和関数の和）を厳密に積分する八面体対称な求積則で、重みの和は $4\pi$ である。
`LebedevRule::new(d, options)` は 3 から 31 までの奇数と、35 から 131 まで 6 刻みの 32 通りの次数を受け付ける（[球面上の求積則](oxref:integrate-sphere-rules)）。
Lebedev 則は誤差推定を持たない。
被積分関数は直交座標 $(x,y,z)$ を受け取るので、$\theta=\arccos z$、$\phi=\operatorname{atan2}(y,x)$ に変換してスプラインを評価する。
スプラインは $\theta$ と $\phi$ の区分的な 3 次式であり、球面多項式ではないので、次数 $d$ の厳密性はスプラインの積分を厳密にしない。
Lebedev 則とスプラインの面積積分の差は求積の誤差、スプラインの面積積分と 15 °C の差は当てはめの誤差である。

次のセルは前のセルから観測点、区切り点、ペナルティを受け取り、区切り点とペナルティを固定した `SphericalSplinePlan` で同じ曲面を作り直す。
これは 1 回の線形最小二乗の解で、区切り点とペナルティの探索は繰り返さない。
作り直した曲面の係数が前のセルの係数と一致することも確かめる。
入力は Lebedev 則の最大の次数で、5 からその次数までの次数で全球平均を求める。
1 つ目の表は面積積分による全球平均、当てはめの誤差、係数の差を、2 つ目の表は各次数の節点数、全球平均、面積積分との差（求積の誤差）を示す。
グラフは求積の誤差の対数グラフで、当てはめの誤差は次数によらないので基準線として描く。

```rust
//| id: interp-spherical-global-mean
//| ref: interp-spherical-global-mean
//| title: 全球平均を面積積分と Lebedev 則で比べる

//| uses: [interp-spherical-temperature-model]
//| crates: [scioxide-core, scioxide-interp, scioxide-integrate, scioxide-random]

//|   fitted: interp-spherical-temperature
//| inputs:
//|   max_degree: {"type":"select","label":"Lebedev 則の最大の次数 d","options":["17","41","83","131"],"value":"41"}
//| cases:
//|   - {"id":"highest-degree","label":"d ≤ 131","description":"次数 131（5810 節点）でも求積の誤差は 10⁻⁹ °C 程度にとどまる。","inputs":{"max_degree":"131"}}
//| tests:
//|   - case: default

//|       - {"artifact":"lebedev","path":"/rows/0/1","equals":14}

//|       - {"artifact":"lebedev","path":"/rows/2/3","approx":{"value":3.436e-5,"rtol":1e-2}}

use scioxide_core::{SciOxideError, RealScalar};
use scioxide_integrate::{GeometricOptions, LebedevRule};
use scioxide_interp::{
    ExtrapolationPolicy, Integrable, Interpolant, SphericalSamples, SphericalSplinePlan,
    SplineFitLimits,
};

let list = |key: &str| -> Result<Vec<f64>, String> {
    serde_json::from_value(fitted[key].clone()).map_err(|e| e.to_string())
};
let sites: Vec<[f64; 2]> =
    serde_json::from_value(fitted["sites"].clone()).map_err(|e| e.to_string())?;
let (values, previous) = (list("values")?, list("coefficients")?);
let penalty = fitted["penalty"].as_f64().ok_or("ペナルティがない")?;
// 区切り点とペナルティを固定した 1 回の当てはめ（探索はしない）
let limits = SplineFitLimits::new().with_max_penalty_iterations(64);
let plan = SphericalSplinePlan::new(
    &list("theta_breaks")?,
    &list("longitude_breaks")?,
    SphericalSamples::Scattered(&sites),
    None,
    penalty,
    limits,
)
.map_err(|e| e.to_string())?;
let spline = plan.fit(&values).map_err(|e| e.to_string())?.into_spline();
let coefficient_gap = spline
    .coefficients()
    .iter()
    .zip(&previous)
    .map(|(a, b)| (a - b).abs())
    .fold(0.0_f64, f64::max);
let policy = ExtrapolationPolicy::Reject;
let four_pi = 2.0 * std::f64::consts::TAU;
// 面積要素 sin θ dθ dφ による全球の積分。4π で割ると全球平均になる
let area_mean = spline
    .integral(
        [0.0, 0.0],
        [std::f64::consts::PI, std::f64::consts::TAU],
        policy,
    )
    .map_err(|e| e.to_string())?
    / four_pi;
let fit_error = (area_mean - 15.0).abs();
// Lebedev 則の被積分関数: 直交座標を [余緯度, 経度] に変換して評価する
let integrand = |xyz: &[f64]| -> Result<f64, SciOxideError> {
    let t = RealScalar::acos(xyz[2].clamp(-1.0, 1.0));
    spline.evaluate([t, RealScalar::atan2(xyz[1], xyz[0])], policy)
};
let largest: usize = max_degree.parse().map_err(|_| "次数が整数でない")?;
let mut rows = Vec::new();
let mut errors = Vec::new();
for degree in [5, 7, 11, 17, 23, 29, 41, 59, 83, 131] {
    if degree > largest {
        break;
    }
    let rule =
        LebedevRule::new(degree, GeometricOptions::default()).map_err(|e| e.to_string())?;
    let (integral, _) = rule
        .integrate(&integrand, &[0.0; 3], 1.0)
        .map_err(|e| e.to_string())?;
    let quadrature_error = (integral / four_pi - area_mean).abs();
    rows.push((
        degree,
        rule.node_count(),
        integral / four_pi,
        quadrature_error,
    ));
    // 対数軸に描けない 0 の差は除き、表には残す
    if quadrature_error > 0.0 {
        errors.push([degree as f64, quadrature_error]);
    }
}
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let fixed6 = serde_json::json!({ "fractionDigits": 6 });
let global_columns = serde_json::json!([
    { "key": "0", "label": "面積積分による全球平均 [°C]", "type": "number", "format": fixed6 },
    { "key": "1", "label": "当てはめの誤差 |平均 − 15| [°C]", "type": "number", "format": sci2 },
    { "key": "2", "label": "係数の最大の差 [°C]", "type": "number", "format": sci2 }
]);
let global = vec![(area_mean, fit_error, coefficient_gap)];
emit_table_with_columns!(
    global_columns,
    global,
    metadata = serde_json::json!({ "id": "global" })
);
let columns = serde_json::json!([
    { "key": "0", "label": "Lebedev 則の次数 d [-]", "type": "integer" },
    { "key": "1", "label": "節点数 [-]", "type": "integer" },
    { "key": "2", "label": "全球平均 [°C]", "type": "number", "format": fixed6 },
    { "key": "3", "label": "面積積分との差 [°C]", "type": "number", "format": sci2 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "lebedev" })
);
emit_line_chart!(
    &vec![serde_json::json!({ "name": "求積の誤差 |Lebedev − 面積積分|", "points": errors })],
    options = &serde_json::json!({
        "xLabel": "Lebedev 則の次数 d [-]",
        "yLabel": "全球平均の差 [°C]",
        "yType": "log",
        "annotations": [{
            "kind": "line",
            "axis": "y",
            "value": fit_error,
            "label": "当てはめの誤差 |面積積分 − 15|",
            "style": { "lineType": "dashed" }
        }]
    })
);
```

既定値では、スプラインの面積積分による全球平均は 15.0015 °C で、当てはめの誤差は $1.5\times10^{-3}$ °C である。
区切り点とペナルティを固定して作り直した係数は前のセルの係数と $7\times10^{-15}$ 以内で一致し、同じ曲面を積分していることを確かめられる。
当てはめの誤差は除いた点の RMSE 0.042 °C よりはるかに小さく、点ごとの誤差の正負が全球の積分で打ち消し合うことを示す。
求積の誤差は次数 5（14 節点）で $1.1\times10^{-3}$ °C と当てはめの誤差に近いが、次数 11（50 節点）で $3.4\times10^{-5}$ °C、次数 17 以上では $10^{-6}$ °C 程度まで下がる。
減り方は単調でなく、次数 17 の $9.8\times10^{-7}$ °C から次数 23 では $2.5\times10^{-6}$ °C に増える。
次数を 131（5810 節点）まで上げても差は $2\times10^{-9}$ °C 程度にとどまり、丸めの水準までは下がらない。
スプラインは区分的な 3 次式で継ぎ目の高階の導関数が連続でないので、高い次数の厳密性がそのまま誤差の減少につながらない。
この場では次数 11 以上なら求積の誤差は当てはめの誤差の 1/40 以下であり、全球平均の誤差は当てはめで決まる。
前のセルで $\tau=0.08$ °C にすると、当てはめの誤差は $1.0\times10^{-2}$ °C に増えるが、求積の誤差は次数 5 で $2.2\times10^{-5}$ °C とむしろ小さくなる。
挿入した区切り点が 1 個に減り、ペナルティも大きくなって曲面が滑らかになるので、少ない節点でも積分しやすくなる。

## まとめ

球面の場は余緯度・経度の座標で表すが、標本の配置と平均は面積要素 $\sin\theta\,d\theta\,d\phi$ に従って扱う。
$z=\cos\theta$ と経度を一様にすると面積について一様な観測点が得られ、地図の画素の単純平均は全球平均にならない。
当てはめの精度は当てはめに使わなかった観測点の RMSE とその標準誤差で評価し、残差平方和の目標と混同しない。
全球平均では、スプラインの面積積分と厳密値の差が当てはめの誤差、Lebedev 則と面積積分の差が求積の誤差であり、二つを分けて確かめる。
この合成場では次数 11 程度の Lebedev 則で求積の誤差は当てはめの誤差より十分小さくなるが、場の滑らかさが変われば必要な次数も変わる。
