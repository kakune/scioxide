測候所のような散在点から場を推定するとき、補間は標本点で一致し、弱い正則化でも標本での残差はほぼ 0 になるので、その残差では核の形状係数を選べない。
ここでは Gaussian RBF の幅を変え、標本を一つずつ除いたときの誤差で未観測点の精度を見積もる。
真値が分かる Franke 関数を使い、交差検証の誤差が実際の近似誤差をどれだけ反映するかを調べる。

## 試験関数と観測点

$[0,1]^2$ 上で

$$
\begin{aligned}
f(x,y)={}&\tfrac34e^{-[(9x-2)^2+(9y-2)^2]/4}
+\tfrac34e^{-(9x+1)^2/49-(9y+1)/10}\\
&+\tfrac12e^{-[(9x-7)^2+(9y-3)^2]/4}
-\tfrac15e^{-(9x-4)^2-(9y-7)^2}
\end{aligned}
$$

とする。
幅と高さの異なる二つの山、なだらかな斜面、狭い窪みを含むので、一つの尺度の基底では全体を表しにくい。
原典は [Franke, Scattered Data Interpolation: Tests of Some Methods](https://doi.org/10.1090/S0025-5718-1982-0637296-4) である。
観測点は正方形の四隅を必ず含め、残りを一様乱数で発生させる。
四隅を含めると、全点の外接長方形と凸包がどちらも正方形になる。
`RbfInterpolator` の定義域は点の外接長方形、`CloughTocherInterpolator` の定義域は Delaunay 分割の凸包なので、二つを同じ正方形の上で比べられる。

## Gaussian RBF と条件

Gaussian 核は $\varphi(r)=\exp[-(\epsilon r)^2]$ であり、$\epsilon>0$ を形状係数と呼ぶ。
補間は多項式項を持たない $s(\boldsymbol x)=\sum_jw_j\varphi(\|\boldsymbol x-\boldsymbol x_j\|)$ の重み $w$ を、核行列 $K_{ij}=\varphi(\|\boldsymbol x_i-\boldsymbol x_j\|)$ の方程式 $(K+\lambda I)w=y$ から求める。
Gaussian 核の $K$ は相異なる点に対して正定値（Bochner の定理）なので、`RbfInterpolator` は Cholesky 分解を使う。
分解が破綻するか、数値的な階数や条件の検査に失敗すると、特異値分解に切り替える。
特異値分解でも、設定した閾値のもとで数値的に階数が不足すると `Singular` のエラーを返す。
構築は $O(n^3)$ の時間と $O(n^2)$ のメモリ領域を使い、評価は 1 点あたり $O(n)$ である。
$\lambda>0$ は `RbfRegularization::Diagonal(λ)` で与える対角正則化であり、標本での厳密な一致を緩めてデータを平滑化する。
核 `RbfKernel::Gaussian(ε)` は標本と並ぶ引数として渡し、正則化と数値的な階数の閾値（ここでは相対 $10^{-14}$、既定は機械イプシロン）は `RbfOptions` の設定関数で与えて、オプション付き形式 `RbfInterpolator::with_options(points, values, kernel, options)` で作る。

$\epsilon$ が小さいと基底が平坦になり、$K$ の列が互いに近くなって条件数が急に大きくなる（平坦極限）。
一方、正則化があれば $A=K+\lambda I$ の最小固有値は $\lambda$ 以上なので、$\|A^{-1}\|_2\le1/\lambda$ である。
核の値は 1 以下なので $\|A\|_1\le n+\lambda$、また $\|A^{-1}\|_1\le\sqrt n\,\|A^{-1}\|_2$ から、1 ノルムの逆条件数は

$$
\kappa_1^{-1}\ge\frac{\lambda}{\sqrt n\,(n+\lambda)}
$$

を満たす。
`RbfConditioning::reciprocal_condition_number` は、Cholesky や LU の因子からは 1 ノルムの逆条件数の推定値を、特異値分解からは 2 ノルムの特異値比 $\sigma_{\min}/\sigma_{\max}$ を返す。
1 ノルムの推定値は上界でも下界でもない推定値である。
ただし、推定に使う Hager–Higham の方法は厳密な演算では $\|A^{-1}\|_1$ を下から見積もるので、推定値はふつう真の逆条件数以上になる。
2 ノルムの逆条件数 $\lambda_{\min}/\lambda_{\max}\ge\lambda/(n+\lambda)$ も同じ下界を満たす。

次のブロックは、ページの三つのセルが共有する試験関数と観測点、検証の補助関数である。
`franke` が $f$、`stations` が四隅と一様乱数の観測点、`test_grid` が $20\times20$ の格子の中心、`shape_parameter` が $\epsilon=2^{k/2}$、`rbf_options` が正則化と階数の閾値、`without` が 1 点を除いた標本、`mean_and_half_width` が平均と 1.96 SE に対応する。

```rust
//| id: interp-station-franke-model
//| kind: definitions
//| title: Franke 関数、観測点と検証の補助関数
//| crates: [scioxide-core, scioxide-interp, scioxide-random]
use scioxide_core::{SciOxideError, RankThreshold, RealScalar};
use scioxide_interp::{RbfOptions, RbfRegularization};
use scioxide_random::{Rng, SeedableRng, SplitMix64};

/// Franke の試験関数（Franke 1982）。
pub(crate) fn franke(x: f64, y: f64) -> f64 {
    let (u, v) = (9.0 * x, 9.0 * y);
    0.75 * RealScalar::exp(-((u - 2.0) * (u - 2.0) + (v - 2.0) * (v - 2.0)) / 4.0)
        + 0.75 * RealScalar::exp(-(u + 1.0) * (u + 1.0) / 49.0 - (v + 1.0) / 10.0)
        + 0.5 * RealScalar::exp(-((u - 7.0) * (u - 7.0) + (v - 3.0) * (v - 3.0)) / 4.0)
        - 0.2 * RealScalar::exp(-(u - 4.0) * (u - 4.0) - (v - 7.0) * (v - 7.0))
}

/// 正方形の四隅（番号 0〜3）と、[0, 1)² の一様乱数の点を合わせた count 点。
pub(crate) fn stations(count: usize, seed: f64) -> Result<Vec<[f64; 2]>, SciOxideError> {
    let mut sites = vec![[0.0, 0.0], [1.0, 0.0], [1.0, 1.0], [0.0, 1.0]];
    let mut rng = SplitMix64::from_seed(seed as u64);
    while sites.len() < count {
        sites.push([rng.next_float()?, rng.next_float()?]);
    }
    Ok(sites)
}

/// 標本と独立な 20 × 20 の格子の中心。
pub(crate) fn test_grid() -> Vec<[f64; 2]> {
    (0..400)
        .map(|k| {
            [
                ((k / 20) as f64 + 0.5) / 20.0,
                ((k % 20) as f64 + 0.5) / 20.0,
            ]
        })
        .collect()
}

/// 形状係数 ε = 2^(k/2)。
pub(crate) fn shape_parameter(k: i32) -> f64 {
    RealScalar::powf(2.0, f64::from(k) / 2.0)
}

/// 正則化と、数値的な階数の閾値（相対 10⁻¹⁴）。
pub(crate) fn rbf_options(
    regularization: RbfRegularization<f64>,
) -> Result<RbfOptions<f64>, SciOxideError> {
    Ok(RbfOptions::new()
        .with_regularization(regularization)
        .with_rank_threshold(RankThreshold::new(0.0, 1e-14)?))
}

/// 番号 omitted の点を除いた標本。
pub(crate) fn without(
    sites: &[[f64; 2]],
    values: &[f64],
    omitted: usize,
) -> (Vec<[f64; 2]>, Vec<f64>) {
    sites
        .iter()
        .zip(values)
        .enumerate()
        .filter(|(i, _)| *i != omitted)
        .map(|(_, (&p, &v))| (p, v))
        .unzip()
}

/// 標本平均と 95% 区間の半幅 1.96 SE（SE = 標本標準偏差 / √m）。
pub(crate) fn mean_and_half_width(x: &[f64]) -> (f64, f64) {
    let m = x.len() as f64;
    let mean = x.iter().sum::<f64>() / m;
    let variance = x.iter().map(|v| (v - mean) * (v - mean)).sum::<f64>() / (m - 1.0);
    (mean, 1.96 * RealScalar::sqrt(variance / m))
}
```

## 形状係数と正則化による条件

次のセルは全点の RBF を $\epsilon=2^{k/2}$（$k=-4,\dots,8$、0.25 から 16 までの 13 通り）と四つの正則化で作り、逆条件数の推定値を比べる。
入力は点数と乱数のシードである。
条件は値によらないので、値はすべて 1 にそろえる。
グラフは逆条件数の推定値の両対数グラフで、各 $\lambda$ の下界 $\lambda/(\sqrt n(n+\lambda))$ を基準線で示す。
1 つ目の表は各候補の推定値で、作れなかった候補は「作れない」と示し、0 で置き換えない。
2 つ目の表は正則化ごとに、特異値分解に切り替えた候補の数、作れなかった候補の数とエラーの種類を示す。
このセルの点数とシードは、次の二つのセルにも渡す。

```rust

//| ref: interp-station-rbf-conditioning
//| title: 形状係数と正則化による条件推定の変化
//| run: reactive
//| uses: [interp-station-franke-model]
//| crates: [scioxide-core, scioxide-interp, scioxide-random]

//|   count: {"type":"range","label":"点数 n [-]","min":12.0,"max":40.0,"step":4.0,"value":24.0}
//|   seed: {"type":"range","label":"乱数のシード","min":1.0,"max":100.0,"step":1.0,"value":7.0}
//| cases:
//|   - {"id":"many-points","label":"n = 40","description":"点の間隔が縮み、同じ ε でも条件が悪くなる。","inputs":{"count":40}}
//| tests:
//|   - case: default
//|     expect:

//|       - {"artifact":"rcond","path":"/rows/0/3","range":{"min":8.5e-11}}
//|       - {"artifact":"rcond","path":"/rows/0/4","approx":{"value":1.984e-6,"rtol":1e-2}}
//|       - {"artifact":"failures","path":"/rows/0/2","equals":2}
//|       - {"artifact":"failures","path":"/rows/0/3","equals":"Singular"}
//|       - {"artifact":"failures","path":"/rows/1/2","equals":0}
//|   - case: many-points
//|     expect:
//|       - {"artifact":"failures","path":"/rows/0/1","equals":1}
//|       - {"artifact":"failures","path":"/rows/0/2","equals":4}
//|       - {"artifact":"rcond","path":"/rows/12/1","approx":{"value":0.022538,"rtol":1e-3}}

let values = vec![1.0; count];
let lambdas = [None, Some(1e-12), Some(1e-8), Some(1e-4)];
let names = ["正則化なし", "λ = 10⁻¹²", "λ = 10⁻⁸", "λ = 10⁻⁴"];
let mut curves = vec![Vec::new(); lambdas.len()];
let mut rows = Vec::new();
// 正則化ごとの [SVD に切り替えた数, 作れなかった数] と最後のエラーの種類

            lambda.map_or(RbfRegularization::None, RbfRegularization::Diagonal);

        match RbfInterpolator::with_options(sites.clone(), values.clone(), kernel, options) {
            Ok(model) => {
                let conditioning = model.conditioning();
                let value = conditioning.reciprocal_condition_number();

                curves[j].push([epsilon, value]);

                    tally[j][0] += 1;

            Err(e) => {
                tally[j][1] += 1;
                kinds[j] = Some(format!("{:?}", e.kind()));

    }));
}
emit_line_chart!(
    &series,
    options = &serde_json::json!({
        "xLabel": "形状係数 ε [-]",
        "yLabel": "逆条件数の推定 [-]",
        "xType": "log",
        "yType": "log",
        "annotations": annotations
    })
);
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let columns = serde_json::json!([
    { "key": "0", "label": "形状係数 ε [-]", "type": "number", "format": { "significantDigits": 3 } },
    { "key": "1", "label": "正則化なし [-]", "type": "number", "format": sci2, "nullText": "作れない" },
    { "key": "2", "label": "λ = 10⁻¹² [-]", "type": "number", "format": sci2, "nullText": "作れない" },
    { "key": "3", "label": "λ = 10⁻⁸ [-]", "type": "number", "format": sci2, "nullText": "作れない" },
    { "key": "4", "label": "λ = 10⁻⁴ [-]", "type": "number", "format": sci2, "nullText": "作れない" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "rcond" })
);
let failure_rows: Vec<_> = (0..4)
    .map(|j| (names[j], tally[j][0], tally[j][1], kinds[j].clone()))
    .collect();
let failure_columns = serde_json::json!([
    { "key": "0", "label": "正則化" },
    { "key": "1", "label": "SVD に切り替えた候補 [-]", "type": "integer" },
    { "key": "2", "label": "作れなかった候補 [-]", "type": "integer" },
    { "key": "3", "label": "エラーの種類", "nullText": "なし" }
]);

    failure_rows,

);

```

既定の $n=24$ で $\epsilon$ を 16 から小さくすると、正則化なしの逆条件数の推定値は 0.16 から $\epsilon=0.5$ の $5.8\times10^{-14}$ まで下がり、$\epsilon\le0.35$ の 2 候補は `Singular` のエラーで作れない。
作れた候補はどれも特異値分解に切り替わらず、値は Cholesky 分解からの 1 ノルムの推定値である。
正則化を加えると逆条件数は下げ止まり、$\lambda=10^{-8}$ では $2.1\times10^{-10}$〜$3.5\times10^{-8}$、$\lambda=10^{-4}$ では $2.0\times10^{-6}$ 以上になる。
平坦な側の下げ止まりの値は下界 $\lambda/(\sqrt n(n+\lambda))$（$\lambda=10^{-8}$ で $8.5\times10^{-11}$、$10^{-4}$ で $8.5\times10^{-7}$）の 2〜4 倍で、どの候補も下界を下回らない。
$\epsilon\ge4$ では核行列の条件がよく、$\lambda\le10^{-4}$ の正則化は推定値をほとんど変えない。
$n=40$ にすると点の間隔が縮まり、同じ $\epsilon$ でも基底が相対的に平坦になるので、$\epsilon=16$ の推定値は 0.023 に下がり、正則化なしでは 4 候補が作れず、1 候補が特異値分解に切り替わる。
逆条件数が大きいことは方程式を安定に解けることを示すだけで、補間の精度がよいことは示さない。

## 一つ抜き交差検証

標本 $i$ を除いて作ったモデルを $s_{-i}$ とし、除いた点での誤差 $e_i=s_{-i}(\boldsymbol x_i)-y_i$ から

$$
E_{\mathrm{CV}}=\sqrt{\frac1{|I|}\sum_{i\in I}e_i^2}
$$

を求める。
四隅を除くと外接長方形が縮み、除いた点が RBF の定義域の外に出るので、ここでは四隅を常に残し、内部の点 $I$ だけを順に除く。
これは全点の一つ抜き誤差ではなく、境界の値を既知とした内部点の検証である。
`RbfInterpolator` は一つ抜き誤差を閉形式で返す機能を提供しないので、点を除くたびに作り直す。
作り直しの計算コストは 1 回 $O(n^3)$、全体で $O(n^4)$ である。
閉形式の一つ抜き予測が必要なら、Gauss 過程の `GaussianProcessModel::leave_one_out_into` を使う（[局所モデルと kriging の予測分散](../../algorithms/local-models-and-kriging/)）。

$E_{\mathrm{CV}}$ 自体も限られた点から求めた推定値である。
二乗誤差の平均の標準誤差 $\mathrm{SE}=s_{e^2}/\sqrt{|I|}$ をデルタ法で $\mathrm{SE}/(2E_{\mathrm{CV}})$ に換算し、$E_{\mathrm{CV}}$ の 95% 区間の半幅を求める。
比較のため、全点のモデルと真の関数との差の RMS $E_{\mathrm{test}}$ を、標本と独立な $20\times20$ の格子の中心で測る。
形状係数を変えたときに $E_{\mathrm{CV}}$ と $E_{\mathrm{test}}$ の順位がどれだけそろうかを Spearman の順位相関係数 $r_s=1-6\sum d_i^2/[m(m^2-1)]$（$d_i$ は候補 $i$ の二つの順位の差、$m$ は候補の数）で表す。
さらに、$E_{\mathrm{CV}}$ が最小の $\epsilon$ を選んだときの $E_{\mathrm{test}}$ を、$E_{\mathrm{test}}$ の最小値と比べる。

次のセルは前のセルの点数とシードを受け取り、対角正則化の指数 $\log_{10}\lambda$ を入力にする。
形状係数は前のセルと同じ 13 通りである。
1 つ目の表は各候補の $E_{\mathrm{CV}}$ と区間、$E_{\mathrm{test}}$、状態を、2 つ目の表は順位相関と選んだ $\epsilon$ を示す。
作れなかった候補はエラーの種類を状態に示し、誤差 0 で置き換えない。
グラフは $E_{\mathrm{CV}}\pm1.96$ SE の帯と $E_{\mathrm{test}}$ の折れ線を両対数で描く。
このセルの $\lambda$ は次のセルにも渡す。

```rust

    }
}
```

$E_{\mathrm{CV}}$ の最小値だけで $\epsilon$ を決めず、区間の重なりと逆条件数を合わせて読む。

## Clough–Tocher との比較

Clough–Tocher 補間は Delaunay 分割の各三角形を重心で三つに分け、それぞれに 3 次の Bézier 曲面片を置く大域的に $C^1$ 級の補間である。
頂点の勾配は Nielson の最小ノルム網の方法で大域的に推定し、Gauss–Seidel の反復が収束したかを `CloughTocherReport` の終了状態で返す。
勾配の推定が収束しなくても、補間は標本点で値に一致する $C^1$ 級の曲面のままで、頂点の勾配の精度だけが下がる。
標準形式 `CloughTocherInterpolator::new` は収束しなければエラーを返すので、未収束の回数も数えるこの比較では、レポート付きの補間器を返すオプション付き形式 `with_options` を使う。
形状係数のような尺度の入力を持たないので、RBF の形状係数の選択がどれだけ効くかを測る比較の基準になる。

次のセルは前のセルの点数、シード、正則化を受け取り、指定した形状係数の RBF と Clough–Tocher について、内部点の一つ抜き誤差と独立格子の誤差を求める。
Clough–Tocher も点を除くたびに Delaunay 分割から作り直す。
同じ点を除いた二つの誤差は対応があるので、二乗誤差の差 $d_i=e_{\mathrm{RBF},i}^2-e_{\mathrm{CT},i}^2$ の平均と 1.96 SE でも比べる。
入力は形状係数の指数 $k$（$\epsilon=2^{k/2}$）である。
既定の $k=3$（$\epsilon\approx2.83$）は、前のセルの既定値で $E_{\mathrm{CV}}$ が最小になる候補である。
1 つ目の表は二つの方法の $E_{\mathrm{CV}}$、区間、$E_{\mathrm{test}}$ と、勾配推定が収束しなかった回数を示し、2 つ目の表は対応のある差を示す。

```rust
use scioxide_interp::{

};

let count = scan["count"].as_u64().ok_or("点数がない")? as usize;
let seed = scan["seed"].as_f64().ok_or("シードがない")?;
let exponent = scan["exponent"].as_f64().ok_or("正則化の指数がない")?;
let sites = stations(count, seed).map_err(|e| e.to_string())?;
let values: Vec<_> = sites.iter().map(|p| franke(p[0], p[1])).collect();
let grid = test_grid();

let lambda = RealScalar::powi(10.0, exponent as i32);
let options = rbf_options(RbfRegularization::Diagonal(lambda)).map_err(|e| e.to_string())?;
let policy = ExtrapolationPolicy::Reject;
// 与えた点から RBF を作り、問い合わせ点での値を返す
let rbf = |points: &[[f64; 2]], data: &[f64], queries: &[[f64; 2]]| {
    let model = RbfInterpolator::with_options(points.to_vec(), data.to_vec(), kernel, options)?;
    queries
        .iter()
        .map(|&q| model.evaluate(q, policy))
        .collect::<Result<Vec<_>, SciOxideError>>()
};

    let samples = ScatteredValues::from_input_values(&mesh, data.to_vec())?;
    let model =

    let predicted = queries

        .map(|&q| model.evaluate(q, policy))

};
```

最初のセルで $n=12$ にすると、RBF の独立格子の誤差 0.086 は Clough–Tocher の 0.148 より小さいが、一つ抜き誤差は RBF の 0.160 が Clough–Tocher の 0.074 より大きく、二つの順位が一致しない。

形状係数を持たない Clough–Tocher は、RBF の形状係数が適切でないときの比較の基準になるが、どちらが優れるかは点数と配置に依存する。

## まとめ

標本を通す補間では標本での残差がほぼ 0 になるので、形状係数は一つ抜き誤差のように標本の外での誤差で選ぶ。
一つ抜き誤差は点配置と点数に依存する推定値なので、95% 区間を付けて候補を比べ、区間の重なる候補の差を結論にしない。
Gaussian RBF の条件は $\epsilon$ を小さくすると急に悪くなり、対角正則化 $\lambda$ は逆条件数を $\lambda/(\sqrt n(n+\lambda))$ 以上に保つが、標本での一致を緩める。
逆条件数の推定値は方程式を安定に解けるかを示すだけで、精度の指標にはならない。
Clough–Tocher のような尺度の入力を持たない方法と比べると、形状係数の選択がどれだけ精度に効いているかを確かめられる。
