直線から円弧へ直接つなぐと、曲率が 0 から $1/R$ へ飛ぶ。
一定の速さ $v$ で走る車両の横加速度は $v^2\kappa$ なので、曲率の飛びは横加速度の急変になる。
緩和曲線は弧長に対して曲率を徐々に変えてこの急変を避ける。
ここでは線路設計の個別の規格は扱わず、クロソイドの幾何を補間の検証に使う。

## クロソイドと Fresnel 積分

クロソイドは弧長 $s$ に比例する曲率 $\kappa(s)=s/A^2$ を持つ曲線であり、$A$ [m] をクロソイドパラメータと呼ぶ。
接線角は $\psi(s)=\int_0^s\kappa\,du=s^2/(2A^2)$ なので、位置は

$$
x(s)=\int_0^s\cos\frac{u^2}{2A^2}\,du,
\qquad y(s)=\int_0^s\sin\frac{u^2}{2A^2}\,du
$$

となる。
正規化した Fresnel 積分 $C(z)=\int_0^z\cos(\pi t^2/2)\,dt$、$S(z)=\int_0^z\sin(\pi t^2/2)\,dt$（DLMF 7.2.7）を使い、$u=A\sqrt\pi\,t$ と置換すると

$$
x(s)=A\sqrt\pi\,C\!\left(\frac{s}{A\sqrt\pi}\right),
\qquad y(s)=A\sqrt\pi\,S\!\left(\frac{s}{A\sqrt\pi}\right)
$$

を得る。
参照線形の標本は `scioxide-special` の `fresnel_c` と `fresnel_s` で作る。

$A=80\ \mathrm m$、クロソイド長 $L=60\ \mathrm m$ とし、前に 30 m の直線、後ろに 30 m の円弧を置く。
円弧の半径は $R=A^2/L\approx106.7\ \mathrm m$ で、接続点 $s=L$ で位置と接線角 $\psi(L)=L^2/(2A^2)$ を一致させる。
この参照線形の曲率は直線で 0、緩和区間で $s/A^2$、円弧で $L/A^2$ であり、弧長に対して連続だが、$s=0$ と $s=L$ で傾きが変わる。
曲率の最大値は $L/A^2\approx9.4\times10^{-3}\ \mathrm{m^{-1}}$ である。
曲率 $\kappa=\psi'$ が連続で $\kappa'$ が飛ぶので、位置は $C^2$ 級だが $C^3$ 級ではない。

## 媒介変数化と曲率

点列 $\boldsymbol r_0,\dots,\boldsymbol r_{N-1}$ を曲線で結ぶには、各点に媒介変数 $u_i$ を割り当てる。
一様な媒介変数は $u_i=i$、弦長の媒介変数は点間距離の累積 $u_{i+1}=u_i+\|\boldsymbol r_{i+1}-\boldsymbol r_i\|$、求心的な媒介変数は距離の平方根の累積 $u_{i+1}=u_i+\|\boldsymbol r_{i+1}-\boldsymbol r_i\|^{1/2}$ である。
`CurveParameterization::ChordLength` は弦長の累積を全長で割り、$[0,1]$ に正規化する。
一様・求心的な媒介変数は用意されていないので、配列を作って `CurveParameterization::Supplied` に渡す。
どの媒介変数も真の弧長と一致するとは限らない。
弦長は弧長を下から近似し、点の間隔が曲率半径に比べて小さいほど弧長に近い。

曲率は媒介変数の取り方によらない量であり、位置の 1 階・2 階導関数から

$$
\kappa=\frac{x'y''-y'x''}{\|\boldsymbol r'\|^3}
$$

で求める。
$\boldsymbol r'$ と $\boldsymbol r''$ は媒介変数についての導関数で、分母の $\|\boldsymbol r'\|^3$ が媒介変数の尺度を打ち消す。
媒介変数についての 2 階導関数 $y''$ だけを描くと、媒介変数の尺度の違いを曲率と取り違える。

当てはめには二つの方法を使う。
一つはオプション付き形式 `fit_parametric_spline_with_options` による 3 次の B スプライン曲線であり、目標 `SplineFitTarget::Residual(0)` と絶対許容誤差 $10^{-12}\ \mathrm{m^2}$ で、残差平方和が $10^{-12}\ \mathrm{m^2}$ 以下になるまでノットを挿入する。
目標が 0 なのでペナルティの探索はせず、ペナルティは 0 のままである。
媒介変数化を選び、使った媒介変数 `parameters()` とレポートを読むので、ワンショット関数 `fit_parametric_spline` ではなくオプション付き形式を使う。
ノットはすべて単純ノットなので、曲線は $C^2$ 級であり、レポートの `continuity()` も 2 を返す。
速度 $\boldsymbol r'$ が 0 にならない限り、曲率もノットで連続になる。

もう一つは同じ媒介変数での `PchipInterpolator` であり、各成分を Fritsch–Butland の重み付き調和平均の傾きで補間する。
PCHIP は各成分の単調性を保つ $C^1$ 級の 3 次 Hermite 補間なので、2 階導関数と曲率は節点で飛びうる。
`PchipInterpolator` は 2 階導関数を返すトレイト `TwiceDifferentiable` を実装しないので、2 階導関数は `scioxide-differentiate` の `physical_difference_derivative` で勾配を中心差分して求める。
差分の点を同じ多項式片の中に取れば、2 次式の勾配の中心差分は丸めを除いて厳密になる。

## 曲率の誤差の測り方

参照の弧長の標本は $s_i=-30+120\,(i/(N-1))^{1.3}$ [m] とし、間隔を後ろほど広くして媒介変数化の違いを見やすくする。
曲率は各区間の媒介変数の中点で評価する。
当てはめた曲線の点は参照線形の上にないので、比べる解析曲率はその点を参照線形へ射影した弧長 $\tilde s$ で求める。
射影は Newton 法の 1 次の近似 $\tilde s\leftarrow\tilde s+(\boldsymbol r-\boldsymbol p(\tilde s))\cdot\boldsymbol t(\tilde s)$（$\boldsymbol p$ は参照線形の点、$\boldsymbol t$ は単位接線）を、両端の弧長の中点から 3 回繰り返す。
この射影と解析曲率は独立検算のための手計算であり、当てはめと曲率の主計算は `scioxide-interp` で行う。

次のブロックは、ページの二つのセルが共有する参照線形と当てはめの補助関数である。
`Track::point` が弧長 $s$ の点と接線角、`Track::curvature` が解析曲率、`Track::project` が射影、`sample_arcs` が標本の弧長、`fit_curves` が媒介変数化を選んだ二つの方法の当てはめ、`spline_curvature` と `pchip_curvature` が二つの方法の曲率に対応する。

```rust
//| id: interp-track-clothoid-model
//| kind: definitions
//| title: 直線・クロソイド・円弧の参照線形と二つの曲線
//| crates: [scioxide-core, scioxide-differentiate, scioxide-interp, scioxide-special]
use scioxide_core::{SciOxideError, RealScalar, Tolerance};
use scioxide_differentiate::physical_difference_derivative;
use scioxide_interp::{
    AdaptiveSplineOptions, CurveParameterization, Differentiable, ExtrapolationPolicy,
    ParametricSplineFit, PchipInterpolator, SplineFitTarget, TwiceDifferentiable,
    fit_parametric_spline_with_options,
};
use scioxide_special::{fresnel_c, fresnel_s};

/// クロソイドパラメータ A [m] とクロソイド長 L [m]。
pub(crate) const CLOTHOID_A: f64 = 80.0;
pub(crate) const CLOTHOID_LENGTH: f64 = 60.0;

/// 直線（s < 0）、クロソイド（0 ≤ s ≤ L）、円弧（s > L）をつないだ参照線形。
pub(crate) struct Track {
    scale: f64,
    radius: f64,
    angle: f64,
    end: [f64; 2],
}

impl Track {
    pub(crate) fn new() -> Result<Self, SciOxideError> {
        let (a, length) = (CLOTHOID_A, CLOTHOID_LENGTH);
        let scale = a * RealScalar::sqrt(std::f64::consts::PI);
        let end = [
            scale * fresnel_c(length / scale)?,
            scale * fresnel_s(length / scale)?,
        ];
        let (radius, angle) = (a * a / length, length * length / (2.0 * a * a));
        Ok(Self {
            scale,
            radius,
            angle,
            end,
        })
    }

    /// 弧長 s の点 [m] と接線角 ψ(s) [rad]。
    pub(crate) fn point(&self, s: f64) -> Result<([f64; 2], f64), SciOxideError> {
        if s < 0.0 {
            return Ok(([s, 0.0], 0.0));
        }
        if s <= CLOTHOID_LENGTH {
            let p = [
                self.scale * fresnel_c(s / self.scale)?,
                self.scale * fresnel_s(s / self.scale)?,
            ];
            return Ok((p, s * s / (2.0 * CLOTHOID_A * CLOTHOID_A)));
        }
        let psi = self.angle + (s - CLOTHOID_LENGTH) / self.radius;
        let x = self.end[0] + self.radius * (RealScalar::sin(psi) - RealScalar::sin(self.angle));
        let y = self.end[1] - self.radius * (RealScalar::cos(psi) - RealScalar::cos(self.angle));
        Ok(([x, y], psi))
    }

    /// 解析曲率 κ(s) = clamp(s, 0, L)/A² [1/m]。
    pub(crate) fn curvature(s: f64) -> f64 {
        s.clamp(0.0, CLOTHOID_LENGTH) / (CLOTHOID_A * CLOTHOID_A)
    }

    /// 点 r を参照線形へ射影した弧長（s ← s + (r − p(s))·t(s) を 3 回）。
    pub(crate) fn project(&self, r: [f64; 2], guess: f64) -> Result<f64, SciOxideError> {
        let mut arc = guess;
        for _ in 0..3 {
            let (p, psi) = self.point(arc)?;
            arc += (r[0] - p[0]) * RealScalar::cos(psi) + (r[1] - p[1]) * RealScalar::sin(psi);
        }
        Ok(arc)
    }
}

/// 標本の弧長 s_i = −30 + 120 (i/(N − 1))^1.3 [m]。
pub(crate) fn sample_arcs(count: usize) -> Vec<f64> {
    let last = (count - 1) as f64;
    (0..count)
        .map(|i| -30.0 + 120.0 * RealScalar::powf(i as f64 / last, 1.3))
        .collect()
}

/// 媒介変数化（"uniform"、"chord"、"centripetal"）を選び、スプライン曲線と PCHIP を当てはめる。
pub(crate) fn fit_curves(
    points: &[[f64; 2]],
    mode: &str,
) -> Result<
    (
        ParametricSplineFit<f64, [f64; 2]>,
        PchipInterpolator<f64, [f64; 2]>,
    ),
    SciOxideError,
> {
    let mut parameters = vec![0.0];
    for pair in points.windows(2) {
        let distance = RealScalar::hypot(pair[1][0] - pair[0][0], pair[1][1] - pair[0][1]);
        let step = if mode == "uniform" {
            1.0
        } else {
            RealScalar::sqrt(distance)
        };
        parameters.push(parameters[parameters.len() - 1] + step);
    }
    let choice = if mode == "chord" {
        CurveParameterization::ChordLength
    } else {
        CurveParameterization::Supplied(&parameters)
    };
    let options = AdaptiveSplineOptions::new()
        .with_target(SplineFitTarget::Residual(0.0))
        .with_residual_tolerance(Tolerance::new(1e-12, 0.0)?);
    let fit = fit_parametric_spline_with_options(points, choice, None, options)?;
    let pchip = PchipInterpolator::new(fit.parameters().to_vec(), points.to_vec())?;
    Ok((fit, pchip))
}

/// 平面曲線の符号付き曲率 (x'y'' − y'x'')/‖r'‖³。
pub(crate) fn plane_curvature(v: [f64; 2], acc: [f64; 2]) -> f64 {
    (v[0] * acc[1] - v[1] * acc[0]) / RealScalar::powi(RealScalar::hypot(v[0], v[1]), 3)
}

/// スプライン曲線の点と曲率（解析的な Hessian）。
pub(crate) fn spline_curvature(
    fit: &ParametricSplineFit<f64, [f64; 2]>,
    q: f64,
) -> Result<([f64; 2], f64), SciOxideError> {
    let policy = ExtrapolationPolicy::Reject;
    let spline = fit.spline();
    let point = scioxide_interp::Interpolant::evaluate(spline, [q], policy)?;
    let v = spline.gradient([q], policy)?[0];
    Ok((
        point,
        plane_curvature(v, spline.hessian([q], policy)?[0][0]),
    ))
}

/// PCHIP の点と曲率。2 階導関数は q ± step の勾配の中心差分で求める。
pub(crate) fn pchip_curvature(
    pchip: &PchipInterpolator<f64, [f64; 2]>,
    q: f64,
    step: f64,
) -> Result<([f64; 2], f64), SciOxideError> {
    let policy = ExtrapolationPolicy::Reject;
    let mut acc = [0.0; 2];
    for (component, out) in acc.iter_mut().enumerate() {
        *out = physical_difference_derivative(
            |x| Ok(pchip.gradient([x], policy)?[0][component]),
            q,
            &[q - step, q + step],
        )?;
    }
    let point = scioxide_interp::Interpolant::evaluate(pchip, [q], policy)?;
    let v = pchip.gradient([q], policy)?[0];
    Ok((point, plane_curvature(v, acc)))
}
```

## 区間の中点での曲率

```rust
        serde_json::json!({ "name": "PCHIP", "points": gaps[1] })
    ],
    options = &serde_json::json!({
        "link": { "group": "track-arc" },
        "xLabel": "射影した弧長 s̃ [m]",
        "yLabel": "曲率の誤差 |κ − s/A²| [1/m]",
        "yType": "log",
        "annotations": junctions
    })
);
export!(count, count);

let termination = report.termination();
let outcome = if termination.is_success() {
    Outcome::satisfied("スプライン曲線が残差平方和の目標を満たした")
} else {
    Outcome::partial("スプライン曲線が目標を満たす前に止まった")
        .explanation("ノットの上限で止まった曲線は標本を補間していない。")
};
emit_outcome!(
    outcome
        .status(format!("{termination:?}"))
        .diagnostic("残差平方和", report.residual(), Some("m²"))
        .diagnostic("曲率の最大誤差", errors[0][0], Some("1/m"))
);
```

既定の弦長の媒介変数と $N=25$ では、スプライン曲線は 17 個のノットを挿入した時点で残差平方和 $1.0\times10^{-13}\ \mathrm{m^2}$ が目標の $10^{-12}\ \mathrm{m^2}$ を下回り、`ResidualSatisfied` で終わる。
ノット列の長さ 25 は補間に必要な $N+4=29$ より短く、曲線は標本を厳密には通らない（残差の RMS は約 $6\times10^{-8}$ m）。
曲率の最大誤差は $1.5\times10^{-4}\ \mathrm{m^{-1}}$ で、曲率の最大値の約 1.6% に当たる。
誤差は曲率の傾きが変わる $s=0$ と $s=L$ を含む区間に集まり、その区間と隣の区間を除くと $4.9\times10^{-6}\ \mathrm{m^{-1}}$ である。
参照線形は位置の 3 階導関数が接続点で飛ぶので、そこをまたぐ区間では 3 次式で近似しきれない。
PCHIP の最大誤差 $1.4\times10^{-4}\ \mathrm{m^{-1}}$ も同じ程度だが、接続点から離れた区間でも同じ大きさの誤差が残る。
PCHIP は各区間の両端の値と傾きだけで決まる局所的な補間なので、直線区間の 8 区間では曲率がちょうど 0 になり、下の対数軸の図には現れない。
スプライン曲線は全体の当てはめなので、直線区間にも小さな曲率が残る。

$N=41$ にすると、スプラインの最大誤差は $4.2\times10^{-5}$ に下がり、PCHIP の $9.9\times10^{-5}\ \mathrm{m^{-1}}$ より小さくなる。
一様な媒介変数ではスプラインの最大誤差が $2.3\times10^{-4}$、求心的な媒介変数では $1.8\times10^{-4}\ \mathrm{m^{-1}}$ で、この不等間隔の標本では弦長の媒介変数が最も小さい。
一様と求心的な媒介変数ではノットを 21 個挿入してノット列の長さが 29 になり、曲線は標本を補間する。

## 節点とノットでの曲率の連続性

中点での誤差は連続性を直接は示さない。
そこで、各方法の多項式片のつなぎ目の両側で曲率を評価し、その差を測る。
スプライン曲線のつなぎ目は内部のノット、PCHIP のつなぎ目は内部の節点 $u_1,\dots,u_{N-2}$ であり、両者は一致しない。
つなぎ目から $\pm h$ の 2 点で曲率を比べ、$h$ は媒介変数の最小間隔の $10^{p}$ 倍とする。
有限の距離での差なので連続性そのものの証明ではない。
$C^2$ の曲線なら差は曲率の傾き $\times2h$ 程度で $h$ に比例して小さくなり、$C^1$ の曲線なら 2 階導関数の飛びが $h$ によらず残る。

次のセルは前のセルの標本数を受け取り、三つの媒介変数化のそれぞれで両方の方法を当てはめる。
入力は $h$ の指数 $p$ である。
表は媒介変数化と方法ごとのつなぎ目の数、両側の曲率差の最大値と、スプライン曲線の当てはめの終了状態を示す。

```rust
//| id: interp-track-curvature-continuity
//| ref: interp-track-curvature-continuity
//| title: 媒介変数化ごとにつなぎ目の曲率差を比べる
//| run: reactive
//| uses: [interp-track-clothoid-model]
//| crates: [scioxide-core, scioxide-differentiate, scioxide-interp, scioxide-special]
//| dependsOn:
//|   sampled: interp-track-curvature
//| inputs:
//|   offset: {"type":"range","label":"つなぎ目からの距離の指数 p（h = 10^p × 最小間隔）[-]","min":-8.0,"max":-2.0,"step":1.0,"value":-6.0}
//| cases:
//|   - {"id":"wide-offset","label":"p = −2","description":"スプラインの差は h に比例して増え、PCHIP の飛びはほぼ変わらない。","inputs":{"offset":-2}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"jumps","path":"/rows/2/2","equals":17}
//|       - {"artifact":"jumps","path":"/rows/2/3","approx":{"value":6.880e-10,"rtol":1e-2}}
//|       - {"artifact":"jumps","path":"/rows/3/2","equals":23}
//|       - {"artifact":"jumps","path":"/rows/3/3","approx":{"value":3.6926e-3,"rtol":1e-3}}
//|       - {"artifact":"jumps","path":"/rows/0/4","equals":"ResidualSatisfied"}
//|   - case: wide-offset
//|     expect:
//|       - {"artifact":"jumps","path":"/rows/2/3","approx":{"value":6.880e-6,"rtol":1e-3}}
//|       - {"artifact":"jumps","path":"/rows/3/3","approx":{"value":3.670e-3,"rtol":1e-3}}
let count = sampled["count"].as_u64().ok_or("標本数がない")? as usize;
let track = Track::new().map_err(|e| e.to_string())?;
let mut points = Vec::new();
for arc in sample_arcs(count) {
    points.push(track.point(arc).map_err(|e| e.to_string())?.0);
}
let mut rows = Vec::new();
for (name, mode) in [
    ("一様", "uniform"),
    ("弦長", "chord"),
    ("求心", "centripetal"),
] {
    let (fit, pchip) = fit_curves(&points, mode).map_err(|e| e.to_string())?;
    let u = fit.parameters();
    let gap = u
        .windows(2)
        .map(|w| w[1] - w[0])
        .fold(f64::INFINITY, f64::min);
    let h = scioxide_core::RealScalar::powi(10.0, offset as i32) * gap;
    // 開いた 3 次の基底のノット列は両端に 4 重のノットを持つ
    let knots = fit.spline().bases()[0].knots();
    let interior = &knots[4..knots.len() - 4];
    let mut spline_jump = 0.0_f64;
    for &k in interior {
        let left = spline_curvature(&fit, k - h).map_err(|e| e.to_string())?.1;
        let right = spline_curvature(&fit, k + h).map_err(|e| e.to_string())?.1;
        spline_jump = spline_jump.max((right - left).abs());
    }
    // PCHIP は節点の両側の多項式片の中で、刻み h/4 の中心差分を使う
    let mut pchip_jump = 0.0_f64;
    for &node in &u[1..count - 1] {
        let left = pchip_curvature(&pchip, node - h, h / 4.0)
            .map_err(|e| e.to_string())?
            .1;
        let right = pchip_curvature(&pchip, node + h, h / 4.0)
            .map_err(|e| e.to_string())?
            .1;
        pchip_jump = pchip_jump.max((right - left).abs());
    }
    let status = format!("{:?}", fit.report().termination());
    rows.push((
        name,
        "3 次スプライン曲線（ノット）",
        interior.len(),
        spline_jump,
        Some(status),
    ));
    rows.push((name, "PCHIP（節点）", count - 2, pchip_jump, None));
}
let columns = serde_json::json!([
    { "key": "0", "label": "媒介変数化" },
    { "key": "1", "label": "方法（つなぎ目）" },
    { "key": "2", "label": "つなぎ目の数 [-]", "type": "integer" },
    {
        "key": "3",
        "label": "両側の曲率差の最大値 [1/m]",
        "type": "number",
        "format": { "notation": "scientific", "significantDigits": 3 }
    },
    { "key": "4", "label": "当てはめの終了状態", "nullText": "—" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "jumps" })
);
```

既定（$N=25$、$p=-6$）では、どの媒介変数化でもスプライン曲線のノットの両側の曲率差は $7\times10^{-10}$〜$1.9\times10^{-9}\ \mathrm{m^{-1}}$ である。
$p$ を $-8$ と $-2$ にすると、弦長の媒介変数での差は $6.9\times10^{-12}$ と $6.9\times10^{-6}\ \mathrm{m^{-1}}$ になり、$h$ に比例して変わる。
これは、曲率がノットで連続で、両側の差が曲率の傾きと $2h$ の積で決まることと合う。
PCHIP の節点の両側の差は $3.7\times10^{-3}$〜$4.0\times10^{-3}\ \mathrm{m^{-1}}$ で、$p$ によらずほぼ一定であり、曲率の最大値 $9.4\times10^{-3}\ \mathrm{m^{-1}}$ の 4 割に達する。
前のセルで標本数を変えると、PCHIP の差は $N=17$ で $5.3\times10^{-3}$〜$5.7\times10^{-3}$、$N=41$ で $2.4\times10^{-3}$〜$2.6\times10^{-3}\ \mathrm{m^{-1}}$ と小さくなるが、スプラインの差の水準には近づかない。
中点での誤差が同程度でも、PCHIP の曲率は節点ごとに飛ぶので、横加速度の急変を避ける目的には向かない。
PCHIP が保つのは各座標成分の単調性であり、曲率を滑らかにつなぐこととは別の性質である。

## まとめ

クロソイドは曲率が弧長に比例する曲線であり、直線と円弧の間で曲率を連続に変える。
曲率は媒介変数によらない量なので、$\kappa=(x'y''-y'x'')/\|\boldsymbol r'\|^3$ で求め、媒介変数についての 2 階導関数だけで判断しない。
解析曲率と比べるときは、当てはめた点を参照線形へ射影した弧長を使う。
単純ノットの 3 次スプライン曲線は曲率が連続であり、PCHIP は中点の誤差が同程度でも節点で曲率が飛ぶ。
媒介変数化は誤差の大きさを変えるが、この連続性の違いは変えない。
