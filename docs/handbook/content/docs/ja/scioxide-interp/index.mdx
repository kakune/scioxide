`scioxide-interp` は、離散的な点と値から、標本の間でも評価できる関数や曲線を作る。
標本をすべて通す補間と、ノイズを含む標本に必ずしも一致させない平滑化の両方を扱う。
作った関数は値だけでなく、方式が対応していれば導関数と定積分も返す。
このページでは一つの補間を計算し、その結果から何を判断できるかを確かめてから、手法の選び方、外挿、評価の形の要点をまとめる。

## 最初の補間

次のセルは単調な校正表 $(x_i, y_i) = (0, 0), (1, 0.8), (2, 1.0), (3, 1.5)$ を PCHIP（区分 3 次 Hermite 補間の一種）で補間する。
区分 3 次 Hermite 補間は各区間 $[x_i, x_{i+1}]$ で両端の値 $y_i, y_{i+1}$ と節点の傾き $d_i, d_{i+1}$ に一致する 3 次式を使う。
PCHIP は節点の傾きを隣り合う割線 $\delta_i = (y_{i+1} - y_i)/(x_{i+1} - x_i)$ から決め、単調なデータの単調性を保つ。
座標の単位を m、値の単位を V とすれば、傾きの単位は V/m になる。
入力は校正域 $[0, 3]$ の中の座標 $x$ である。
出力は補間値と傾き、節点の傾きから 3 次 Hermite 形を組み立て直した検算値、$x$ を挟む二つの節点の値の表である。
`PchipInterpolator::new(x, y)` は標本だけから補間器を作り、1 変数の問い合わせ `value_at` と `derivative_at`（トレイト `Univariate`）は校正域の中の値と傾きを返す。
標本から真の関数が一つに決まるわけではないので、傾きも選んだモデルの導関数として解釈する。

```rust
//| id: interp-first-calibration
//| ref: interp-first-calibration
//| title: 単調な標本の値と傾きを計算する
//| run: reactive
//| crates: [scioxide-interp]
//| inputs:
//|   position: {"type":"range","label":"座標 x [m]","description":"校正域 [0, 3] の中の評価点。節点 0、1、2、3 では校正値がそのまま返る。","min":0,"max":3,"step":0.05,"value":1.5}
//| cases:
//|   - {"id":"at-node","label":"節点 x = 2","description":"節点では校正値 1.0 V と節点の傾き 2/7 V/m が返る。","inputs":{"position":2}}
//|   - {"id":"last-interval","label":"x = 2.5","description":"最後の区間では右端の傾きを片側の 3 点公式で 0.65 V/m と決め、x = 2.5 の傾きは 0.516 V/m になる。","inputs":{"position":2.5}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"calibration","path":"/rows/0/1","approx":{"value":0.904285714285714,"atol":1e-12}}
//|       - {"artifact":"calibration","path":"/rows/0/2","approx":{"value":0.148571428571429,"atol":1e-12}}
//|       - {"artifact":"calibration","path":"/rows/0/3","approx":{"value":0.904285714285714,"atol":1e-12}}
//|   - case: at-node
//|     expect:
//|       - {"artifact":"calibration","path":"/rows/0/1","approx":{"value":1.0,"atol":1e-14}}
//|       - {"artifact":"calibration","path":"/rows/0/2","approx":{"value":0.285714285714286,"atol":1e-12}}
//|   - case: last-interval
//|     expect:
//|       - {"artifact":"calibration","path":"/rows/0/1","approx":{"value":1.20446428571429,"atol":1e-12}}
//|       - {"artifact":"calibration","path":"/rows/0/2","approx":{"value":0.516071428571429,"atol":1e-12}}
//|       - {"artifact":"calibration","path":"/rows/0/3","approx":{"value":1.20446428571429,"atol":1e-12}}
use scioxide_interp::{PchipInterpolator, Univariate};

let x = vec![0.0_f64, 1.0, 2.0, 3.0];
let y = vec![0.0, 0.8, 1.0, 1.5];
let model = PchipInterpolator::new(x.clone(), y.clone()).map_err(|e| e.to_string())?;
// スカラー形は校正域 [0, 3] の中だけで評価し、外は DomainError で拒否する
let value = model.value_at(position).map_err(|e| e.to_string())?;
let slope = model.derivative_at(position).map_err(|e| e.to_string())?;
// position を含む区間の番号は、position 以下の内部節点の数に等しい
let i = x[1..x.len() - 1]
    .iter()
    .filter(|&&node| node <= position)
    .count();
// 独立検算: 節点の傾き d と 3 次 Hermite 基底から区間 i の値を組み立て直す
let d = model.slopes();
let h = x[i + 1] - x[i];
let t = (position - x[i]) / h;
let hermite = (2.0 * t * t * t - 3.0 * t * t + 1.0) * y[i]
    + (t * t * t - 2.0 * t * t + t) * h * d[i]
    + (-2.0 * t * t * t + 3.0 * t * t) * y[i + 1]
    + (t * t * t - t * t) * h * d[i + 1];
let fixed2 = serde_json::json!({ "fractionDigits": 2 });
let digits6 = serde_json::json!({ "significantDigits": 6 });
let columns = serde_json::json!([
    { "key": "0", "label": "座標 x [m]", "type": "number", "format": fixed2 },
    { "key": "1", "label": "補間値 [V]", "type": "number", "format": digits6 },
    { "key": "2", "label": "傾き [V/m]", "type": "number", "format": digits6 },
    { "key": "3", "label": "Hermite 形の検算 [V]", "type": "number", "format": digits6 },
    { "key": "4", "label": "左の節点の値 [V]", "type": "number", "format": digits6 },
    { "key": "5", "label": "右の節点の値 [V]", "type": "number", "format": digits6 }
]);
emit_table_with_columns!(
    columns,
    vec![(position, value, slope, hermite, y[i], y[i + 1])],
    metadata = serde_json::json!({ "id": "calibration" })
);
```

節点に入力を合わせると、元の校正値がそのまま返る。
既定の $x = 1.5$ では補間値は 0.904286 V で、挟む節点の値 0.8 V と 1.0 V の間にあり、傾きは 0.148571 V/m と正である。
節点の傾きから組み立て直した Hermite 形の値も 0.904286 V で、評価の経路が違っても同じ値になる。

この値は手でも求められる。
割線は $\delta_0 = 0.8$、$\delta_1 = 0.2$、$\delta_2 = 0.5$ V/m で、節点の間隔がすべて 1 m なので、内部の節点の傾きは隣り合う割線の調和平均 $d_i = 2/(1/\delta_{i-1} + 1/\delta_i)$ になる。
$d_1 = 0.32$ V/m、$d_2 = 2/7 \approx 0.285714$ V/m である。
区間の中点では 3 次 Hermite 形が

```text
s(xᵢ + h/2)  = (yᵢ + yᵢ₊₁)/2 + h (dᵢ − dᵢ₊₁)/8
s′(xᵢ + h/2) = 3δᵢ/2 − (dᵢ + dᵢ₊₁)/4
```

になり（$h$ は区間の幅）、$i = 1$ を代入すると 0.904286 V と 0.148571 V/m が出る。
区間の中の傾きの平均は割線に等しいので、両端の傾き 0.32 V/m と 0.285714 V/m が割線 0.2 V/m より大きい分だけ、中点の傾きは割線より小さくなる。
最後の区間（入力の組「x = 2.5」）では、右端の傾きを片側の 3 点公式 $((2h_2 + h_1)\delta_2 - h_2\delta_1)/(h_1 + h_2) = 0.65$ V/m で決めるので、$x = 2.5$ の傾きは 0.516071 V/m、補間値は 1.204464 V になる。

PCHIP は単調なデータの各区間で単調性を保つので、どの $x$ でも補間値は隣の節点の値の間に入り、傾きは負にならない。
その代わり 2 階導関数は節点で跳びうるので、曲率の連続が必要なら 3 次スプラインを選ぶ。
実測のノイズまで通したくない場合は、補間ではなく平滑化を選ぶ。
傾きの規則と単調性の条件の導出は [PCHIP・三次スプライン・Akima](./algorithms/pchip-and-splines/) で扱う。

## 標本から決めること

同じ点を通る関数は無数にある。
補間法はその中からどの関数の空間と形の制約を使うかを決める。
座標の配置、標本値の型、単調性や滑らかさ、必要な微積分を先に整理する。

| 入力と目的 | 主な選択肢 | 確認する性質 |
|---|---|---|
| 1 次元で一つの全域表現 | 重心・Newton・Hermite・Neville・Bulirsch–Stoer | 節点の配置、導関数の標本の有無、極の近さ |
| 実軸の補間・共鳴・Taylor 係数 | Floater–Hormann・AAA・Padé | 次数、極、標本外の誤差 |
| 単調な表・局所的な急変 | PCHIP・Akima・Makima | 単調性と行き過ぎ |
| 滑らかな曲線・幾何設計 | 3 次スプライン・B スプライン・NURBS | 境界条件、ノット、曲率 |
| 空間の点列を通る曲線 | 媒介変数スプライン | 媒介変数の選び方、残差の目標、終了状態 |
| ノイズのある値 | ペナルティ付き・適応的スプライン | 適合度、粗さ、終了状態 |
| 直交格子 | 双線形・双 3 次・テンソルスプライン | 軸順、成分順、微分の連続性 |
| 散在点 | RBF・Delaunay 分割の補間・局所モデル | 凸包、近傍、ランクと条件 |
| 共分散に基づく予測 | Gauss 過程・kriging | 平均の仮定、ノイズ、予測分散 |
| 全球の場 | 球面スプライン | 極、周期性、角度、球面積 |

各手法の連続性、局所性、誤差の次数の比較は[補間の選び方](./choosing/)にまとめてある。

## 外挿と座標のレポート

`value_at` のような 1 変数のスカラー形は定義域の中だけで評価し、外では `DomainError` を返す。
外挿方針を取る問い合わせには `ExtrapolationPolicy` を毎回渡し、暗黙の既定値はない。
定義域は閉じていて、境界上の点は領域の中として扱う。

| 方針 | 領域の外の動作 |
|---|---|
| `Reject` | `DomainError` で拒否する |
| `Clamp` | 領域の最も近い点で評価する。区間・箱では境界の値で一定に延長し、凸包では最も近い凸包上の点への射影と合成する |
| `BoundedContinue { max_distance }` | 各軸で境界からの距離が `max_distance` 以下（等号を含む）なら方式の表現をそのまま延長し、それより遠い点は拒否する |
| `MethodDefined` | 方式の表現（全域の式や最も外側の区間の多項式）で距離の制限なく延長し、極や表せない値はエラーにする |

外挿を許しても精度は保証されない。
`Interpolant::report` が返す `ExtrapolationReport` は、元の座標、方式が実際に使う座標、各軸の領域からの距離を返す幾何の情報であり、精度や安定性の推定ではない。

領域の定義は方式によって異なる。
1 次元と直交格子の補間器では節点が張る区間・箱、`RbfInterpolator` では点を囲む長方形（凸包ではない）、Delaunay 分割に基づく補間器では点の凸包が領域である。
球面スプラインでは経度が折り返すので有限の経度はすべて領域の中にあり、余緯度だけが $[0, \pi]$ に対して方針に従う。
自然近傍補間は凸包の外で `Clamp` だけを受け付け、ほかの方針は `DomainError` になる。

区間や箱を `Clamp` で延長した場合、外側にある軸の導関数は 0 になり、積分には境界の値に外側の長さを掛けた量が加わる。
凸包への射影では射影との合成を微分する。
射影先が切り替わる点で両側の導関数が丸め誤差の範囲で一致しなければ、その問い合わせは `DomainError` になる。

## 評価と結果の読み方

補間器は `new` に標本だけを渡して既定の設定で作り、節点の判定や境界条件などを変えるときは `with_options` や `CubicSpline::with_boundary` のような名前付きの構築関数を使う。
値は実数座標の配列と外挿方針を渡して `Interpolant` の `evaluate` で評価し、多数の点は `evaluate_many` で一度に評価する。
1 変数の補間器は `Univariate` の `value_at`・`values_at`・`derivative_at`・`integrate` でも評価できる。
標本値は実数・複素数・配列・ベクトルでよく、複数の成分は同じ幾何（節点、分割、近傍）を共有する。
導関数と積分は、方式が実装するトレイト `Differentiable`、`TwiceDifferentiable`、`Integrable` で求め、実装しない方式では呼び出せない。
呼び出し側の出力と作業領域を渡す `*_into` の形は、成功すれば完全で有限な結果を書き、エラーなら出力を変更しない。
所有する結果を返す便利な形と、作業領域を事前確保して確保なしで繰り返す形とでは計算コストが異なる。
その区別は[準備済みの評価と一括評価](./algorithms/prepared-evaluation-and-batches/)で扱う。

反復を伴う準備のうち、ワンショット関数 `aaa`・`fit_parametric_spline`・`fit_spherical_spline` と `CloughTocherInterpolator::new` は、目標に届かなければ `ConvergenceFailure` を返す。
未達のモデルもレポートとともに受け取るオプション付き形式（`aaa_with_options`、`fit_*_with_options`、`CloughTocherInterpolator::with_options`）では、終了状態を先に読む。
標本での残差が小さくても、標本の間の誤差、外挿の誤差、真の導関数との誤差は保証されない。
誤差の種類と共通の数値の約束事は[許容誤差と残差](../concepts/tolerances-and-residuals/)にまとめてある。

## まとめ

補間器は標本の配置と必要な性質から選ぶ。
標本への一致、形の保存（単調性）、2 階導関数までの滑らかさ、ノイズの平滑化は別々の要求で、一つの手法がすべてを満たすとは限らない。
PCHIP の値は節点の傾きと 3 次 Hermite 形から手で再現でき、単調なデータでは隣の節点の値の間に入る。
定義域の外を評価するときは外挿方針を明示し、領域が方式ごとに違うことと、必要な微積分を方式が実装しているかを確かめる。
反復を伴う準備では終了状態を読み、標本以外の点で独立に検算する。
