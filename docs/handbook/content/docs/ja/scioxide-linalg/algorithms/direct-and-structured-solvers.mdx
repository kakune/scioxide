直接法は正方行列 $A$ を三角行列の積に分解し、二つの三角系を代入で解く。
分解は $O(n^3)$、代入は $O(n^2)$ の演算なので、同じ $A$ で多くの右辺を解くときは分解を保持して使い回す。
このページは LU・Cholesky・LDL 分解のアルゴリズムと誤差、`scioxide-linalg` が分解の成否と解の受理をどう分けているか、因子から作る逆作用素を説明する。
三重対角・帯・Toeplitz 行列は[構造付き線形方程式の直接解法](../structured-systems/)で扱う。

---

## 部分ピボット付き LU 分解

ガウスの消去法の第 $k$ 段は $k$ 列目の対角より下を、乗数 $\ell_{ik} = a^{(k)}_{ik} / a^{(k)}_{kk}$ を掛けた $k$ 行目で消す。
部分ピボット選択は、各段で $\lvert a^{(k)}_{ik} \rvert$ が最大の行 $p \ge k$ を $k$ 行目と交換し、すべての乗数を $\lvert \ell_{ik} \rvert \le 1$ に保つ。
すべての交換をまとめた置換行列を $P$ とすると、単位下三角の $L$ と上三角の $U$ で

$$
PA = LU
$$

が得られる。
解は $Ly = Pb$ の前進代入と $Ux = y$ の後退代入で求め、演算数は分解が約 $\tfrac{2}{3}n^3$、二つの代入が約 $2n^2$ である。

計算した解 $\hat x$ は、ある $\Delta A$ について $(A + \Delta A)\hat x = b$ の厳密解であり、成分ごとに $\lvert \Delta A \rvert \le \gamma_{3n} \lvert \hat L \rvert \lvert \hat U \rvert$ を満たす（$\gamma_k = ku/(1-ku)$、$u$ は単位丸め、Higham の定理 9.4）。
部分ピボット選択では $\lvert \hat L \rvert$ の成分が 1 以下なので、$\lvert \hat U \rvert$ を成長因子 $\rho_n$ で抑えるとノルムの評価

$$
\frac{\lVert \Delta A \rVert_\infty}{\lVert A \rVert_\infty} \le 2n^2 \gamma_{3n}\, \rho_n \approx 6 n^3 \rho_n\, u, \qquad
\rho_n = \frac{\max_{i,j,k} \lvert a^{(k)}_{ij} \rvert}{\max_{i,j} \lvert a_{ij} \rvert}
$$

を得る（Wilkinson の評価、Higham の定理 9.5）。
$n^3$ の係数は最悪の場合を見積もったもので、実際の後退誤差はこれよりずっと小さいことが多いが、成長因子が大きい行列では次のセルのように後退誤差も大きくなる。
成長因子は部分ピボット選択のもとでも最大 $2^{n-1}$ まで大きくなりうるが、実際の行列ではほとんどの場合小さい。

`LuDecomposition::factor(&a)` は分解の前に、絶対値が最大の成分が $[1, 2)$ に入る 2 の冪で各行を尺度変換し、続けて各列も同じように変換する（平衡化）。
指数は `equilibration()` が返す `EquilibrationMetadata` に記録される。
2 の冪の積は丸め誤差を生まないので、`to_l_matrix()` と `to_u_matrix()` は元の行列 $PA$ の因子を返し、解と診断も元の行列について述べたものになる。
例外は行の最大値の約 $\mu$ 倍（$\mu$ は正の最小の正規数）より小さい成分で、尺度変換した値が非正規化数になって丸められるか 0 になる。
各列のピボットは、絶対値が最大の成分のうち最初のものである。
消去は右視（right-looking）のブロック化で、最大 64 列のパネルを消去して行の交換を残りの列に適用し、残りの部分行列を三角求解（TRSM）と行列積（GEMM）で更新する。
因子は後で残差を測るために元の行列の写しも保持する。
分解が失敗するのは、正方でない入力（`DimensionMismatch`）、非有限な成分（`NonFinite`）、厳密に 0 のピボット（`Singular`）、ピボットの成長で $U$ の成分が浮動小数点の範囲を超える場合（`NumericalInstability`（`Overflow`））で、数値的な理由で失敗するのは後の二つだけである。

次のセルは Wilkinson の行列 $W_n$（対角と最後の列が 1、対角より下が $-1$、他は 0）で、成長因子が上限 $2^{n-1}$ に達することを確かめる。
$W_n$ の成分の最大値は 1 なので、$\rho_n$ は $U$ の成分の最大値である。
右辺は $b = W_n x^{\star}$（$x^{\star}_i = ((i \bmod 7) + 1)/7$）とし、LU の解の前進誤差を、列ピボット付き Householder QR によるワンショット関数 `least_squares` の解と比べる。
LU の解の後退誤差についてはオプション付き形式の `solve_with_options` にレポートさせた値と、$W_n$ に解を代入して手で計算した値を並べる。
最後の行はワンショット関数 `solve(&w, &b)` の解と、因子の標準形式 `lu.solve(&b)` の解の差である。
グラフは $n = 2, \dots, 60$ の前進誤差で、縦線が選んだ $n$ を示す。

```rust
//| id: linalg-lu-growth-factor
//| ref: linalg-lu-growth-factor
//| title: Wilkinson の行列で見る LU の成長因子
//| run: reactive
//| crates: [scioxide-linalg]
//| inputs:
//|   order: {"type":"range","label":"次数 n","description":"Wilkinson の行列 W_n の次数。","min":2,"max":60,"step":1,"value":40}
//| cases:
//|   - {"id":"small-order","label":"n = 8","description":"成長因子 2⁷ = 128 では、LU の前進誤差は QR と同じ程度にとどまる。","inputs":{"order":8}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"growth","path":"/rows/0/1","approx":{"value":549755813888,"rtol":1e-12}}
//|       - {"artifact":"growth","path":"/rows/1/1","approx":{"value":549755813888,"rtol":1e-12}}
//|       - {"artifact":"growth","path":"/rows/4/1","range":{"min":1e-6,"max":1e-4}}
//|       - {"artifact":"growth","path":"/rows/5/1","range":{"max":1e-12}}
//|       - {"artifact":"growth","path":"/rows/6/1","range":{"max":0}}
//|   - case: small-order
//|     expect:
//|       - {"artifact":"growth","path":"/rows/0/1","approx":{"value":128,"rtol":1e-12}}
//|       - {"artifact":"growth","path":"/rows/4/1","range":{"max":1e-13}}
//|       - {"artifact":"growth","path":"/rows/6/1","range":{"max":0}}
use scioxide_linalg::{
    DirectSolveOptions, Estimation, LuDecomposition, Matrix, RankPolicy, least_squares, solve,
};

struct Study {
    growth: f64,
    reported: Option<f64>,
    backward: f64,
    lu_error: f64,
    qr_error: f64,
    one_shot: f64,
}
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
// オプション付き形式の solve に、元の行列 W についての後退誤差をレポートに記録させる。
let with_residual =
    DirectSolveOptions::new(RankPolicy::Exact).with_residual(Estimation::Estimate);
let max_abs = |v: &[f64]| v.iter().fold(0.0_f64, |m, x| m.max(x.abs()));
let max_diff = |p: &[f64], q: &[f64]| {
    p.iter()
        .zip(q)
        .fold(0.0_f64, |m, (a, b)| m.max((a - b).abs()))
};
let study = |n: usize| -> Result<Study, String> {
    let entries = (0..n * n).map(|k| {
        let (i, j) = (k / n, k % n);
        if i == j || j == n - 1 {
            1.0
        } else if i > j {
            -1.0
        } else {
            0.0
        }
    });
    let w = Matrix::from_vec(n, n, entries.collect()).map_err(|e| e.to_string())?;
    // 2 進で割り切れない真の解 x*_i = ((i mod 7) + 1) / 7。
    let x_star: Vec<f64> = (0..n).map(|i| ((i % 7) + 1) as f64 / 7.0).collect();
    let b = w.view().mul_vec(&x_star[..]).map_err(|e| e.to_string())?;
    let lu = LuDecomposition::factor(&w).map_err(|e| e.to_string())?;
    let growth = max_abs(lu.to_u_matrix().map_err(|e| e.to_string())?.as_slice());
    let result = lu
        .solve_with_options(&b, &with_residual)
        .map_err(|e| e.to_string())?;
    let reported = result.report().residual().map(|r| r.scaled_norm());
    // 受理されなかった解は into_accepted がエラーに変える。
    let x = result.into_accepted().map_err(|e| e.to_string())?;
    // 独立な検算: W についての正規化残差を手で計算する（‖W‖∞ = n）。
    let wx = w.view().mul_vec(&x).map_err(|e| e.to_string())?;
    let r = max_diff(wx.as_slice(), b.as_slice());
    let backward = r / (n as f64 * max_abs(x.as_slice()) + max_abs(b.as_slice()));
    let qr = least_squares(&w, &b).map_err(|e| e.to_string())?;
    // ワンショット呼び出しの solve と、因子の標準形式 solve の解を比べる。
    let direct = solve(&w, &b).map_err(|e| e.to_string())?;
    let plain = lu.solve(&b).map_err(|e| e.to_string())?;
    Ok(Study {
        growth,
        reported,
        backward,
        lu_error: max_diff(x.as_slice(), &x_star),
        qr_error: max_diff(qr.as_slice(), &x_star),
        one_shot: max_diff(direct.as_slice(), plain.as_slice()),
    })
};
let n = order.round() as usize;
let s = study(n)?;
let columns = serde_json::json!([
    { "key": "0", "label": "量" },
    { "key": "1", "label": "値 [-]", "type": "number", "format": sci3, "nullText": "なし" }
]);
emit_table_with_columns!(
    columns,
    vec![
        ("成長因子 ρ_n", Some(s.growth)),
        ("上限 2^(n−1)", Some(2.0_f64.powi(n as i32 - 1))),
        ("示された後退誤差", s.reported),
        ("手計算の後退誤差", Some(s.backward)),
        ("LU の前進誤差", Some(s.lu_error)),
        ("least_squares の前進誤差", Some(s.qr_error)),
        ("solve(&w, &b) と lu.solve(&b) の差", Some(s.one_shot)),
    ],
    metadata = serde_json::json!({ "id": "growth" })
);
let (mut lu_points, mut qr_points, mut model) = (Vec::new(), Vec::new(), Vec::new());
for m in 2..=60 {
    let e = study(m)?;
    // 誤差が厳密に 0 の次数は対数軸に描けないので除く。
    if e.lu_error > 0.0 {
        lu_points.push([m as f64, e.lu_error]);
    }
    if e.qr_error > 0.0 {
        qr_points.push([m as f64, e.qr_error]);
    }
    model.push([m as f64, 2.0_f64.powi(m as i32 - 1) * f64::EPSILON / 2.0]);
}
let series = vec![
    serde_json::json!({
        "name": "LU（部分ピボット）",
        "points": lu_points,
        "style": { "showSymbol": true }
    }),
    serde_json::json!({
        "name": "least_squares（列ピボット付き QR）",
        "points": qr_points,
        "style": { "showSymbol": true }
    }),
    serde_json::json!({ "name": "2^(n−1) u", "points": model, "style": { "lineType": "dashed" } }),
];
emit_line_chart!(
    &series,
    options = &serde_json::json!({
        "xLabel": "次数 n [-]",
        "yLabel": "前進誤差 max|xᵢ − x*ᵢ| [-]",
        "yType": "log",
        "annotations": [{ "kind": "line", "axis": "x", "value": n, "label": "選んだ n" }]
    })
);
```

既定の $n = 40$ では、成長因子 $\rho_{40}$ は上限 $2^{39} \approx 5.5 \times 10^{11}$ に一致する。
$W_n$ の消去では最後の列が 1 段ごとに 2 倍になる整数だけが現れて丸めが起きないので、どの $n$ でも $\rho_n = 2^{n-1}$ である。
LU の前進誤差 $1.7 \times 10^{-5}$ は破線の参照線 $2^{n-1} u \approx 6.1 \times 10^{-5}$ と同じ桁で、`least_squares` の $2.0 \times 10^{-14}$ より 9 桁大きい。
オプション付き形式が返した後退誤差は、保持した元の行列 $W_n$ について測った $7.7 \times 10^{-7}$ で、手で計算した値と一致し、単位丸め $u \approx 1.1 \times 10^{-16}$ の約 $7 \times 10^{9}$ 倍である。
レポートは丸めた因子 $\hat L \hat U$ が表す系ではなく元の行列で残差を測るので、成長因子による劣化がその値に現れる。
ワンショット呼び出しの `solve(&w, &b)` は標準形式の `lu.solve(&b)` と同じ計算なので、二つの解の差は 0 である。

グラフでは、LU の誤差が次数とともに参照線とほぼ同じ傾きで増え、$n = 60$ では 2.9 に達して解として意味を持たない。
`least_squares` の誤差はどの $n$ でも $10^{-13}$ を下回る。
誤差が厳密に 0 になった次数（LU の $n = 2, 3$ と QR の $n = 3$）は、対数軸に描けないので除いている。
$n = 8$ にすると成長因子は $2^7 = 128$ で、LU の前進誤差 $5.6 \times 10^{-16}$ は QR の $7.2 \times 10^{-16}$ と同じ程度にとどまる。
成長因子が大きくなる行列は実際にはまれだが、起きた場合も後退誤差のレポートを要求していれば、その値が単位丸めより大きくなることで気づける。

## 分解と解の受理を分ける

`scioxide-linalg` は、分解が成り立つかという構造上の判断と、得られた解を使ってよいかという数値上の判断を分ける。
分解は数値ランクのしきい値を使わず、解を受理するかどうかは求解のときに `DirectSolveOptions` で決める。
受理とは計算した解を結果として出力に反映してよいと判定することである。

`DirectSolveOptions` は次の三つの検査を持つ。

- ランクの方針 `RankPolicy`。
  `DirectSolveOptions::new(policy)` で与え、因子の対角（LU では平衡化した $U$ のピボットの絶対値）から数値ランクを数え、フルランクでなければ `RankDeficient` にする。
- 逆条件数の下限 `ReciprocalConditionThreshold`。
  `with_minimum_reciprocal_condition` で設定したときだけ条件数を推定し、推定値が下限より小さければ `IllConditioned` にする。
- 後退誤差の診断。
  `with_residual(Estimation::Estimate)` を指定したときだけ、受理した解について元の行列での後退誤差 $\lVert b - A\hat x \rVert_\infty / (\lVert A \rVert_\infty \lVert \hat x \rVert_\infty + \lVert b \rVert_\infty)$ を計算する。
  これは診断で、受理の判定には使わない。

`RankPolicy` は三つある。
`Exact` はしきい値 $\tau = 0$ で、厳密に 0 でない値をすべて数える。
`DimensionScaledEpsilon` は $m \times n$ の行列に $\tau = \min(\max(m, n)\,\varepsilon,\ 1/2) \cdot s$（$s$ は分類する値の最大値、$\varepsilon$ は機械イプシロン）を使う。
`Threshold(RankThreshold)` は呼び出し側の絶対・相対しきい値で $\tau = \tau_{\mathrm{abs}} + \tau_{\mathrm{rel}} s$ とする。
`DirectSolveOptions::default()` は `new(RankPolicy::Exact)` と同じで、条件数の検査も後退誤差の診断も行わない。
LU の分解は厳密に 0 のピボットで失敗するので、既定の選択肢のもとで LU の解が拒否されることはない。

求解の形は受理されなかった解の伝え方で分かれる。
形の名前と作業領域の扱いは[呼び出しの形](oxref:linalg-execution-forms)で定義している。

| 呼び出し | 受理の選択肢 | 戻り値 | 拒否されたとき |
|---|---|---|---|
| 標準形式 `lu.solve(&b)` | `DirectSolveOptions::default()` | 解の `Vector` | `require_accepted` が変換したエラー |
| オプション付き形式 `lu.solve_with_options(&b, &options)` | 呼び出し側の値 | `DirectSolveResult`（解と `DirectSolveReport`） | `Ok`。`solution()` が `None` |
| 出力先を指定する API `lu.solve_into(&b, &options, x, &mut ws, cx)` | 呼び出し側の値 | `DirectSolveReport` | `Ok`。出力 `x` は書き換えない |
| ワンショット関数 `solve(&a, &b)` | `DirectSolveOptions::default()` | 解の `Vector` | 分解の `Singular` |

オプション付き形式の結果は解を `solution()`（参照）か `into_solution()`（値）で `Option` として返し、レポートを `report()` で返す。
`into_accepted()` は、受理された解を `Ok` で返し、拒否された結果を標準形式と同じエラーに変える。
`DirectSolveTermination::require_accepted` の対応は、`RankDeficient` が `Singular`、`IllConditioned` と `StabilityRejected` が `NumericalInstability`（`IllConditioned`）、`ResidualRejected` が `NumericalInstability`（`LossOfSignificance`）である。
`ResidualRejected` は Toeplitz 系の解法、Kronecker 積とブロック対角の作用素の求解、[行列方程式](../matrix-equations/)が、`StabilityRejected` は Riccati 方程式が使い、LU の求解の終了理由は `Accepted`、`RankDeficient`、`IllConditioned` のどれかになる。
拒否された場合も、レポートは拒否した候補のランクと条件数の診断を持ち、残差の検査で拒否した場合はその残差も持つ。
`with_residual` で求めた後退誤差はレポートに載るだけで、解の拒否には使わない。

レポート `DirectSolveReport` は終了理由 `termination()`、ランク `rank()`（`RankReport`：ランク、最大ランク、使ったしきい値と尺度）、逆条件数の推定 `condition()`、後退誤差 `residual()` を持つ。
下限を設定していれば条件数はランクの結果によらず推定し、判定はランク、条件数の順に行い、両方を通った解だけを計算する。
`condition()` は下限を設定したときだけ `Some` になり、`residual()` は診断を要求して解を計算したときだけ `Some` になる。

ワンショット関数 `solve(&a, &b)` は `LuDecomposition::factor(&a)?.solve(&b)` と同じ計算である。
既定の選択肢（`RankPolicy::Exact`、条件数の検査なし）を使い、逐次のコンテキスト `ExecutionContext::sequential_native()` で動き、因子と解を内部で確保して因子は捨てる。
失敗は `DimensionMismatch`、`NonFinite`、厳密に 0 のピボットの `Singular`、解のあふれの `NumericalInstability`（`Overflow`）、確保の失敗の `AllocationFailure` である。
複数の右辺を同じ因子で解く場合や、条件数の推定・後退誤差が必要な場合は、`LuDecomposition` を保持してオプション付き形式を使う。

LU の `condition_estimate()` は元の行列の 1 ノルムの逆条件数 $1/(\lVert A \rVert_1 \lVert A^{-1} \rVert_1)$ の推定値 `ConditionEstimate` を返す。
$\lVert A \rVert_1$ は分解のときに正確に計算し、$\lVert A^{-1} \rVert_1$ は $A$ と $A^{\mathsf H}$ による数回の求解（一回あたり $O(n^2)$）から Hager の方法（Higham の改良）で推定する（$n \le 4$ では正確に計算する）。
推定は厳密な算術では $\lVert A^{-1} \rVert_1$ の下界で、多くの場合 10 倍以内に収まるが、保証はなく、信頼度は `EstimateReliability::Heuristic` である。
行列式は仮数と指数の組 `scaled_determinant()`（core の `ScaledValue`）、符号と対数の組 `slogdet()`（`SignLogDeterminant`）、表現できる場合だけ成功する `determinant()` で得られる。

次のセルは $A(\delta) = \begin{bmatrix} 1 & 2 & 3 \\ 4 & 5 & 6 \\ 7 & 8 & 9 + \delta \end{bmatrix}$（$\det A(\delta) = -3\delta$）を $\delta = 1, 10^{-2}, \dots, 10^{-16}$ で分解し、選んだ方針のオプション付き形式 `solve_with_options` で解を受理するかを判定する。
入力はランクの方針と、逆条件数の下限 $10^{t}$ の指数 $t$ である。
真の解は $x^{\star} = (1, 1, 1)$ で、条件数の参照値には SVD で求めた $1/\kappa_2 = \sigma_3 / \sigma_1$ を並べる。
最後の列は同じ結果に `into_accepted()` を適用したときの値で、受理された解か、拒否を変換したエラーの分類を示す。

```rust
//| id: linalg-lu-checked-solve

//| title: ランクと条件数の方針で LU の解を受理する

## Cholesky 分解

Hermitian 正定値行列 $A = A^{\mathsf H}$（すべての $x \ne 0$ で $x^{\mathsf H} A x > 0$）は、対角が正の下三角行列 $L$ で $A = L L^{\mathsf H}$ と一意に分解できる。
成分を比べると、実数の場合

$$
l_{jj} = \sqrt{a_{jj} - \sum_{k<j} l_{jk}^2}, \qquad
l_{ij} = \frac{1}{l_{jj}}\Bigl(a_{ij} - \sum_{k<j} l_{ik} l_{jk}\Bigr) \quad (i > j)
$$

を得る。
$a_{ii} = \sum_{k \le i} l_{ik}^2$ の各項は非負なので $\lvert l_{ik} \rvert \le \sqrt{a_{ii}}$ となり、ピボット選択なしで成分の増大が起きない。
計算した因子は $A + \Delta A$ の厳密な因子で、$\lVert \Delta A \rVert_\infty \le c\, n \varepsilon \lVert \lvert L \rvert \lvert L^{\mathsf H} \rvert \rVert_\infty$ を満たす（$c$ は小さな定数、$\varepsilon$ は機械イプシロン、Higham の 10 章）。
さらに $\lVert \lvert L \rvert \lvert L^{\mathsf H} \rvert \rVert_2 \le n \lVert L \rVert_2^2 = n \lVert A \rVert_2$ なので、この評価は $A$ のノルムだけで閉じ、LU と違って成長因子の項を含まない。
分解が成功しても、$A$ が正定値であることの証明にはならない。

演算数は約 $\tfrac{1}{3} n^3$ で LU の半分である。
`CholeskyDecomposition` は $L$ を $n \times n$ の密行列で持ち、元の行列の写しも保持するので、メモリ使用量は LU と同じである（三角の半分だけを持つ形式は[構造付き線形方程式](../structured-systems/)のパック行列）。
分解は、0 でない対角成分が $[1/2, 2)$ に入るように選んだ 2 の冪の対角行列 $D$ で $DAD$ と対称に平衡化してから（この尺度変換は、$\mu \sqrt{a_{ii} a_{jj}}$ 程度より小さい非対角成分 $a_{ij}$ が非正規化数に丸められるのを除いて厳密である）、最大 64 列のパネルごとに対角ブロックを分解し、その下のパネルを三角求解で、残りの下三角を対称な階数 $k$ 更新（SYRK・HERK）で更新する。

Cholesky 分解と LDL 分解は、入力を Hermitian とみなす方法を `HermitianInput` で明示させ、暗黙の対称化は行わない。
`Exact` は厳密な共役対称を要求し、対角の虚部を含めて $A \ne A^{\mathsf H}$ なら `InvalidInput`（`Inconsistent`）になる。
`Triangle(t)` は指定した三角だけを読み、もう一方は共役対称で補い（読まない側は NaN でもよい）、対角に虚部があれば `InvalidInput`（`OutOfRange`）になる。
`Projected(policy)` は $(A + A^{\mathsf H})/2$ に置き換えて変化量の Frobenius ノルムを `HermitianProjectionReport` に残し、許す変化量は `HermitianProjectionPolicy` の `Always` か `Within(tolerance)` で決め、`Within` の許容量を超えると `InvalidInput`（`OutOfRange`）になる。

`CholeskyDecomposition::factor(&a, input, CholeskyPivoting::None)` は、平方根の中が正でなくなると `DomainError` を返す。
`CholeskyPivoting::Diagonal(policy)` は半正定値行列のための対角ピボット選択で、残りの Schur 補行列の対角が最大の行と列を先頭に移す。
その対角が $\max(\tau, \tau_0)$ まで下がった段で打ち切り、$L$ の残りの列を 0 にする（$\tau$ は方針のしきい値、$\tau_0 = \min(n\varepsilon, 1/2)\,s$、尺度はどちらも $s = \max_i a_{ii}$）。
$\tau_0$ 以下のピボットはそれまでの段の丸め誤差の水準なので、`RankPolicy::Exact` を含むどの方針でも $\tau_0$ で打ち切る（Higham の 10.3 節）。
`DimensionScaledEpsilon` のしきい値は $\tau = \tau_0$ である。
Schur 補行列の対角が $-\delta$（$\delta = \min(8n\varepsilon, 1/2)\,s$）を下回る場合や、ピボットが $\tau_0$ に達したときに残る Schur 補行列に絶対値が $\tau_0 + \delta$ を超える成分がある場合は `DomainError` を返すので、粗いしきい値で不定値な行列を隠すことはない。
`definiteness_report(policy)` が返す `CholeskyDefinitenessReport` は、分解が打ち切ったランク `factor_rank()` と、ピボット $\lvert L_{kk} \rvert^2$ を方針で数えたランク `effective_rank()` を持つ。
求解はこの `effective_rank` で受理を判定するので、打ち切った因子の標準形式 `solve(&b)` は `Singular` で失敗し、オプション付き形式は `RankDeficient` のレポートを返す。

## LDL 分解と慣性

KKT 行列のように正と負の固有値が混在する Hermitian 行列には Cholesky 分解が使えない。
LDL 分解は対称な置換 $P$ を選んで $P^{\mathsf T} A P = L D L^{\mathsf H}$ とし、$L$ を単位下三角、$D$ を実数の $1 \times 1$ と Hermitian な $2 \times 2$ のブロックからなるブロック対角行列にする。
`LdlDecomposition::factor(&a, input)` は有界ルックピボット選択（Ashcraft–Grimes–Lewis、しきい値 $\alpha = (1 + \sqrt{17})/8 \approx 0.64$）でピボットを選ぶ。
$1 \times 1$ のピボットは列の非対角の最大値の $\alpha$ 倍以上の対角だけに使い、$2 \times 2$ のピボットは行と列の両方で最大の非対角を含むので、$L$ の成分は $\max(1/\alpha,\ 1/(1-\alpha)) \approx 2.78$ 以下に抑えられる（Higham の 11.1.3 節）。
計算した因子は $\lVert \Delta A \rVert_\infty \le c\, n \varepsilon \lVert \lvert L \rvert \lvert D \rvert \lvert L^{\mathsf H} \rvert \rVert_\infty$ を満たす $A + \Delta A$ の厳密な因子で（Higham の 11 章）、$L$ が有界なので、評価の大きさは $D$ の成分の増大（成長因子）で決まる。
最大 32 列のパネルでブロック化し、演算数は約 $\tfrac{1}{3} n^3$ である。
成分の実部と虚部の絶対値がすべて 1 未満なら、その最大値を $[1, 2)$ に移す 2 の冪 $2^\sigma$（$\sigma \ge 0$）を掛けた $2^\sigma A$ を消去して、小さな成分や非正規化数の成分の精度を保ち、それ以外の行列は尺度変換しない。
この尺度変換は厳密で、`diagonal()` と `off_diagonal()` は $A$ 自身の $D$ を一度だけ丸めて返す。
正規数の範囲より小さい乗数は非正規化数か 0 に丸めてエラーにせず、成分の増大で $L$ か $D$ の成分があふれた場合だけ `NumericalInstability`（`Overflow`）で失敗する。
積の精度が `Accuracy::Exact` の求解では、代入の各行の内積を厳密に累積して一度だけ丸めるので、結果は計算カーネルによらない。
特異な行列でも分解は失敗せず、厳密に 0 のピボットはそのまま $D$ に残り、ランクは後で呼び出し側の方針で判定する。

Sylvester の慣性法則により、合同変換は正・負・0 の固有値の個数（慣性）を変えない。
したがって、$D$ のブロックの固有値の符号を数えれば、$A$ の固有値を計算せずに慣性が分かる。
`inertia(RankPolicy::Exact)` は $D$ のブロック固有値の符号をそのまま数えた値で、計算した因子が厳密に表す行列（$A$ に丸め誤差を加えた行列）の慣性である。
$A$ やその近くの行列の慣性を証明するものではない。
`inertia(RankPolicy::DimensionScaledEpsilon)` などはブロック固有値の絶対値の最大値を尺度とするしきい値以下を 0 と数える。
これは $D$ に対するしきい値で、$A$ の固有値に対するしきい値ではない。
標準形式の `solve(&b)` は、$D$ に厳密に 0 の固有値があると `Singular` で失敗する。

次のセルは正定値な $H = \operatorname{tridiag}(-1, 4, -1) \in \mathbb{R}^{n \times n}$ と制約行列 $B \in \mathbb{R}^{m \times n}$（$b_{rj} = \cos(0.7 (r+1)(j+1))$）から KKT 行列 $K = \begin{bmatrix} H & B^{\mathsf T} \\ B & 0 \end{bmatrix}$ を作る。
入力は変数の数 $n$、制約の数 $m$（$n$ 以下に切り詰める）と、$B$ の最後の行を最初の行と同じにするかどうかである。
$B$ が行フルランクなら慣性は $(n, m, 0)$ で、行を重複させるとランクが一つ落ちる。
LDL の二つの慣性を、`HermitianEigenvaluesResult` で求めた固有値の符号の数と比べ、同じ $K$ の Cholesky 分解の結果も示す。

        ),
    ],
    metadata = serde_json::json!({ "id": "inertia" })
);
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let columns = serde_json::json!([
    { "key": "0", "label": "K の次数 n + m", "type": "integer" },
    { "key": "1", "label": "|λ| の最小値 [-]", "type": "number", "format": sci2 },
    { "key": "2", "label": "同じ K の Cholesky 分解" }
]);
emit_table_with_columns!(
    columns,
    vec![(size, minimum, cholesky)],
    metadata = serde_json::json!({ "id": "kkt" })
);
```

既定の $n = 6$、$m = 3$ では、三つの方法がそろって $(6, 3, 0)$ を返し、同じ $K$ の Cholesky 分解は `DomainError` になる。
行を重複させると $K$ は特異になり、固有値の一つの絶対値が $6.7 \times 10^{-16}$ まで下がる。
このとき `Exact` の慣性は丸め誤差で 0 にならなかったピボットを正と数えて $(7, 2, 0)$ を返し、`DimensionScaledEpsilon` で数えた慣性は固有値の符号と同じ $(6, 2, 1)$ になる。
$n = m = 12$ では $B$ が正方の正則行列になり、慣性は $(12, 12, 0)$ である。
特異に近い行列では `Exact` の慣性をそのまま使わず、尺度に応じた方針で 0 を判定する。

## 因子から作る逆作用素

三つの分解は逆行列を作らずに $x \mapsto A^{-1}x$ を作用させる値を `inverse_operator()` で返す。
`LuInverseOperator`、`CholeskyInverseOperator`、`LdlInverseOperator` はどれも因子を借用し、core の `LinearOperator`、`AdjointOperator`、`Preconditioner` を実装するので、反復法の作用素や前処理、構造付きの積の因子に使える。
随伴の作用は、LU では $x \mapsto A^{-\mathsf H}x$、Cholesky と LDL では $A^{-1}$ が Hermitian なので同じ写像である。
一回の作用で受け取る作業領域のスカラーの数は、LU と Cholesky が $n$、LDL が $2n$ である。
コンテキストを渡さない作用は呼び出したスレッドで逐次に動く。

打ち切った半正定値の Cholesky 因子と、$D$ に厳密に 0 の固有値がある LDL 因子は、作用させたときに `Singular` を返す。
LDL の逆作用素は一般に不定値なので、正定値な前処理を要求する CG や MINRES の前処理には使えない。
一方、正定値な行列の Cholesky の逆作用素は、[クリロフ部分空間法](../krylov-and-preconditioning/)の前処理にそのまま渡せる。

## まとめ

LU 分解は部分ピボット選択で乗数を 1 以下に保つが、成長因子は Wilkinson の行列のように $2^{n-1}$ まで増えうるので、結果は後退誤差と前進誤差を分けて確かめる。
`scioxide-linalg` の分解は厳密な 0 ピボットのような構造上の破綻だけを拒否し、解を受理するかどうかは `DirectSolveOptions` のランクの方針と逆条件数の下限で決まる。
標準形式の `solve(&b)` とワンショット呼び出しの `solve(&a, &b)` は既定の `RankPolicy::Exact` で解を返して拒否をエラーにし、オプション付き形式の `solve_with_options` は拒否を `Ok` のレポートの終了理由で返す。
LU の条件数推定は 1 ノルムの経験的な推定なので、2 ノルムの条件数そのものが必要なら SVD を使い、後退誤差は `with_residual` で元の行列についてレポートさせる。
Hermitian 行列では入力の解釈を `HermitianInput` で明示し、正定値なら Cholesky 分解、不定値なら LDL 分解を使うと、LDL の慣性から固有値を求めずに正と負の固有値の数が分かる。
