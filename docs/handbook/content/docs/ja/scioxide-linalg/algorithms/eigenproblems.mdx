固有値問題 $Av = \lambda v$ は、振動の固有周波数、Markov 連鎖の定常状態と混合の速さ、線形系の安定性などを決める。
Hermitian 行列とそれ以外の行列とでは、固有値の性質も計アルゴリズムもはっきり異なる。
このページは二つの場合の理論とアルゴリズム、`scioxide-linalg` の型と反復の上限、非正規な行列で固有値が摂動に敏感になる現象を説明する。
一般化固有値問題 $Av = \lambda Bv$ は[次のページ](../generalized-eigenproblems/)で扱う。
呼び出しの形（標準形式、オプション付き形式、出力先を指定する API）は[作業領域・実行コンテキスト・試行記録](oxref:linalg-execution-forms)で定義する。

## Hermitian 行列の固有値

Hermitian 行列 $A = A^{\mathsf H}$ はユニタリ行列で対角化でき（$A = V \Lambda V^{\mathsf H}$）、固有値はすべて実数で、固有ベクトルは正規直交にとれる。
固有値は摂動に対して安定で、昇順に並べた固有値について、Weyl の不等式により任意の Hermitian な $E$ に対して $\lvert \lambda_i(A + E) - \lambda_i(A) \rvert \le \lVert E \rVert_2$ が成り立つ。
固有ベクトルの変化は Davis–Kahan の $\sin\theta$ 定理により $\lVert E \rVert_2 / \mathrm{gap}$（$\mathrm{gap}$ は他の固有値との距離）の程度で抑えられ、近接した固有値の固有ベクトルは個別には決まりにくい。

`HermitianEigenDecomposition::decompose(&a, input)` は固有値と固有ベクトルを、`HermitianEigenvaluesResult::compute(&a, input)` は固有値だけを求める標準形式である。
位置引数 `input`（`HermitianInput`）は、入力をどう Hermitian 行列として解釈するかを明示する。
`Exact` は成分が厳密に共役対称で対角が実数であることを検査し、`Triangle(Triangle::Lower)` など（`Triangle` は scioxide-core の型）は指定した三角だけを読む。
`Projected(policy)` は $(A + A^{\mathsf H})/2$ に置き換え、変化の大きさ $\lVert A - (A + A^{\mathsf H})/2 \rVert_F$ を `projection_report()` に残す。
`policy` が `HermitianProjectionPolicy::Within(tolerance)` なら、その変化が許容誤差を超えたときに `InvalidInput` を返す。
計算は次の手順で行う。

1. $A$ を成分の最大絶対値で割り、Householder の相似変換で実対称三重対角行列に縮約する（次数 64 以下は 1 列ずつ、それより大きい場合は幅 32 のパネルにまとめて行列積で更新する）。
2. 三重対角行列の固有値問題を解く。
   値だけなら平方根を使わない Pal–Walker–Kahan 型の QL/QR 反復、ベクトルも求めるなら次数 32 以下で陰的 QL 法、それより大きい場合は分割統治を使う。
3. `HermitianEigenOptions::with_index_range(EigenIndexRange::new(i, j)?)` で昇順の添字 $i \le k < j$ の固有対を選んだ場合と、`with_eigenvalue_accuracy(EigenvalueAccuracy::Relative)` を指定した場合は、Sturm の二分法と逆反復を使う。
4. 縮約の変換を固有ベクトルに戻す。
   添字の範囲で $k$ 個を選んだ場合は選んだ列だけを戻すので、この段は $O(n^2 k)$ である。

計アルゴリズムは次数とジョブだけで決まり、命令セットには依存しない。
計算量は $O(n^3)$、メモリ領域は $O(n^2)$ である。
選択肢はオプション付き形式 `decompose_with_options(&a, input, &HermitianEigenOptions)` と `compute_with_options` に渡す。
`EigenvalueAccuracy::Absolute`（既定）はスペクトル全体の大きさを基準に止め、`Relative` は各固有値の大きさを基準に止めるので、成分の大きさが段階的に異なる三重対角行列の小さな固有値を保ちやすい。
ただし稠密行列の三重対角化はノルムの意味でだけ後退安定なので、`Relative` を選んでも、任意の稠密行列の小さな固有値の相対精度は得られない。
固有値の順序は `EigenvalueOrder`（既定は昇順）で選ぶ。
各固有ベクトルは 2 ノルムが 1 で、絶対値が最大の成分（同じ大きさなら最後のもの）が正の実数になるよう位相をそろえる。

反復の上限は一回の呼び出しの QL/QR の掃引、永年方程式の反復、二分法、逆反復の合計に掛かり、既定値は次数 $n$ に対して $m = \max(n, 1)$ に比例する。

| ジョブ | 既定の上限 [回] |
|---|---|
| 全スペクトルの値だけ、または $n \le 32$ のベクトル | $30m$ |
| 全スペクトルの $n > 32$ のベクトル（分割統治） | $30m\,(1 + \lceil \log_2 \lceil m/24 \rceil \rceil)$ |
| 添字の範囲、または `Relative` | $m\,(E_{\max} - E_{\min} + p + 32)$。`f64` で $2182m$、`f32` で $332m$ |

最後の行の $E_{\max}, E_{\min}$ は最大の有限数と最小の非正規化数の 2 進指数、$p$ は仮数の桁数で、二分法が浮動小数点数の全範囲をたどったあとに逆反復まで進める大きさである。
上限は `with_execution_options(LinalgExecutionOptions::new().with_iteration_budget(..))` で置き換えられる。
上限に達するか、逆反復が残差の限界に届かなければ `ConvergenceFailure`、逆反復が方向を失うか固有値が元の単位に戻すとオーバーフローすれば `NumericalInstability` になる。
入力の解釈に合わない行列（`Exact` で厳密に Hermitian でない、対角に虚部がある）は `InvalidInput` である。

成功した計算の作業量は `EigenReport` で読む。
`iterations()` はこの計算自身の反復回数、`counts()` は自身の回数 `own()` と、入れ子の計算が使った回数 `nested()` を分けて返す。
分解の型の `report()` は一度も計算していない空の結果に対して `None` を返し、値だけの結果の `report()` は常にレポートを返す。
値だけの結果は `into_parts()` で再利用できる出力 `HermitianEigenvaluesBuffer` とレポートに分けられる（[固有値の出力バッファー](oxref:linalg-eigenvalue-buffers)）。
出力先を指定する API `decompose_into` と `HermitianEigenvaluesBuffer::compute_into` の作業領域は `HermitianEigenWorkspaceRequest::new(n, &options)` から求める。

### 三重対角行列と Golub–Welsch 法

三重対角行列は `HermitianEigenDecomposition::tridiagonal(&diag, &off_diag)` で、稠密な行列を作らずに直接解ける。
`off_diag` は長さ $n - 1$ の副対角で、長さが合わなければ `DimensionMismatch` になる。
固有値だけなら `HermitianEigenvaluesResult::tridiagonal(&diag, &off_diag)` を使う。
全スペクトルは平方根を使わない Pal–Walker–Kahan の QL/QR 反復で $O(n^2)$ の時間で求め、添字の範囲か `Relative` を指定したオプション付き形式 `tridiagonal_with_options` は Sturm の二分法で作業精度いっぱいまで求める。
二分法の前には最大の成分で割らずに 2 の冪だけで厳密に尺度変換し、成分がすべて 1 未満なら $[1, 2)$ に上げ、Gershgorin の範囲や残差があふれうるなら下げる。
そのため成分の大きさが段階的に異なる行列の最も小さな成分も精度を失わない。
どちらもメモリ領域は $O(n)$ である。
メモリ領域を再利用する出力先を指定する API は `HermitianEigenvaluesBuffer::tridiagonal_into` で、作業領域の要件は `HermitianEigenWorkspaceRequest::tridiagonal(n, &options)` から求める。

`HermitianEigenFirstComponents::tridiagonal(&diag, &off_diag)` は、固有値と、各単位固有ベクトルの第 1 成分だけを返す。
陰的 QL 反復の回転を固有ベクトル行列の第 1 行にだけ掛けるので、計算量は $O(n^2)$、メモリ領域は $O(n)$ で、完全な固有分解の $O(n^3)$ と $O(n^2)$ より少ない。
これは Golub–Welsch 法で使う量である。
直交多項式の族の Jacobi 行列（三項漸化式の係数を並べた三重対角行列）では、固有値が Gauss 求積の節点に、第 1 成分の二乗に重みの 0 次のモーメント $\mu_0$ を掛けた値が重みになる。
第 1 成分の符号は定めず、重複した固有値では個々の成分は一意でないが、その固有空間での二乗和は一意である。
`eigenvalues()` と `first_components()` は同じ順に並び、`report()` は最後に成功した計算の `EigenReport` を返す。
オプション付き形式 `tridiagonal_with_options` は順序、収縮の許容誤差（副対角の成分を 0 とみなして問題を分けるしきい値）、反復の上限を受け取るが、添字の範囲と `Relative` は扱わず、指定すると `InvalidInput` になる。
反復の上限は既定で $30\max(n, 1)$ 回の掃引である。
出力先を指定する API `tridiagonal_into` の作業領域は全スペクトルと `Absolute` の `HermitianEigenWorkspaceRequest::tridiagonal` から求める。
Gauss 求積の節点と重みの計算は [Gauss 型求積と Clenshaw–Curtis 則](../../../scioxide-integrate/algorithms/gaussian-and-clenshaw-curtis/)で扱う。

## べき乗法と Rayleigh 商

最も大きさの大きい固有値を一つだけ求めるなら、べき乗法 $x_{k+1} = A x_k / \lVert A x_k \rVert$ が最も単純である。
固有値の大きさの比 $q = \lvert \lambda_2 \rvert / \lvert \lambda_1 \rvert < 1$ に対して、$x_k$ と $v_1$ のなす角の正弦は $O(q^k)$ で減る。
Hermitian 行列では Rayleigh 商 $\rho_k = x_k^{\mathsf H} A x_k$ の誤差は角の正弦の二乗に比例するので、$O(q^{2k})$ で減る。
$q$ が 1 に近いと収束は遅く、シフト反転 $(A - \sigma I)^{-1}$ で $\sigma$ に近い固有値を強調すると速くなる（[大きな作用素の少数の固有対](../partial-spectra/)）。

次のセルは固有値を指定して作った $30 \times 30$ の対称行列 $A = H \Lambda H$ にべき乗法を適用する。
$H = I - 2uu^{\mathsf T}/u^{\mathsf T}u$（$u_i = \sqrt{i}$）は Householder 鏡映、$\Lambda = \operatorname{diag}(1, q, q(1 - 1/n), q(1 - 2/n), \dots)$ なので、$\lambda_1 = 1$、$\lambda_2 = q$、$v_1 = He_1$ が分かっている。
入力は比 $q$（0.5 から 0.99）と反復回数 $K$（10 から 200）である。
積は `mul_vec`、正規化は `norm2`、Rayleigh 商は `dotc_left` の標準形式で計算する。
参照の固有ベクトルは `HermitianEigenDecomposition` で求め、閉じた形 $He_1$ と照合する。
$A$ は丸めのため厳密には対称にならないので、入力の解釈を `HermitianInput::Triangle(Triangle::Lower)` と明示する。
一つ目の表は参照の固有値と固有ベクトルの閉じた形との差、固有値分解の `EigenReport` の反復回数で、二つ目の表は $K$ 回目の誤差と、1 回目の値から $q^{K-1}$、$q^{2(K-1)}$ で減らした参照値である。
グラフは角の正弦と Rayleigh 商の誤差を対数軸で描き、破線はその参照の傾きである。

```rust
//| id: linalg-power-iteration-rayleigh
//| ref: linalg-power-iteration-rayleigh
//| title: べき乗法の方向と Rayleigh 商の収束
//| run: reactive
//| crates: [scioxide-core, scioxide-linalg]
//| inputs:
//|   ratio: {"type":"range","label":"固有値の比 q = λ₂/λ₁","description":"λ₁ = 1、λ₂ = q、残りは q より小さい。","min":0.5,"max":0.99,"step":0.01,"value":0.9}
//|   steps: {"type":"range","label":"反復回数 K","description":"べき乗法の反復回数。","min":10,"max":200,"step":10,"value":100}
//| cases:
//|   - {"id":"fast","label":"q = 0.5","description":"数十回で Rayleigh 商の誤差が丸めの水準に達する。","inputs":{"ratio":0.5}}
//|   - {"id":"slow","label":"q = 0.99","description":"100 回でも角の正弦は 0.1 を超える。","inputs":{"ratio":0.99}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"reference","path":"/rows/0/1","range":{"max":1e-14}}
//|       - {"artifact":"reference","path":"/rows/0/2","range":{"max":1e-14}}
//|       - {"artifact":"final","path":"/rows/0/1","range":{"min":1e-6,"max":3e-5}}
//|       - {"artifact":"final","path":"/rows/0/2","range":{"min":1e-12,"max":1e-9}}
//|   - case: fast
//|     expect:
//|       - {"artifact":"final","path":"/rows/0/1","range":{"max":1e-14}}
//|       - {"artifact":"final","path":"/rows/0/2","range":{"max":1e-14}}
//|   - case: slow
//|     expect:
//|       - {"artifact":"final","path":"/rows/0/1","range":{"min":0.1,"max":0.4}}
//|       - {"artifact":"final","path":"/rows/0/2","range":{"min":1e-4,"max":1e-2}}
use scioxide_core::Triangle;
use scioxide_linalg::{HermitianEigenDecomposition, HermitianInput, Matrix, Vector};

let n = 30_usize;
let steps = steps.round() as usize;
// A = H Λ H（H は Householder 鏡映）、Λ = diag(1, q, q(1 − 1/n), …)。
let u: Vec<f64> = (0..n).map(|i| ((i + 1) as f64).sqrt()).collect();
let uu: f64 = u.iter().map(|x| x * x).sum();
let h = |i: usize, k: usize| (if i == k { 1.0 } else { 0.0 }) - 2.0 * u[i] * u[k] / uu;
let lambda: Vec<f64> = (0..n)
    .map(|k| match k {
        0 => 1.0,
        1 => ratio,
        _ => ratio * (1.0 - (k - 1) as f64 / n as f64),
    })
    .collect();
let entries = (0..n * n)
    .map(|idx| {
        (0..n)
            .map(|k| h(idx / n, k) * lambda[k] * h(k, idx % n))
            .sum()
    })
    .collect();
let a = Matrix::from_vec(n, n, entries).map_err(|e| e.to_string())?;

// 参照: 固有値分解の最大固有値と固有ベクトル（閉じた形は λ₁ = 1、v₁ = H e₁）。
// 積の丸めで A は厳密には対称でないので、下三角だけを読むと明示する。
let eigen =
    HermitianEigenDecomposition::decompose(&a, HermitianInput::Triangle(Triangle::Lower))
        .map_err(|e| e.to_string())?;
let report = eigen.report().ok_or("固有値分解のレポートがない")?;
let lambda1 = eigen.eigenvalues()[n - 1];
let v1: Vec<f64> = (0..n)
    .map(|i| eigen.eigenvectors().as_slice()[i * n + n - 1])
    .collect();
let closed_form_gap = (0..n)
    .map(|i| (v1[i].abs() - h(i, 0).abs()).abs())
    .fold(0.0_f64, f64::max);
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let digits16 = serde_json::json!({ "significantDigits": 16 });
let reference = serde_json::json!([
    { "key": "0", "label": "λ₁（固有値分解） [-]", "type": "number", "format": digits16 },
    { "key": "1", "label": "|λ₁ − 1| [-]", "type": "number", "format": sci2 },
    { "key": "2", "label": "max | |v₁| − |He₁| | [-]", "type": "number", "format": sci2 },
    { "key": "3", "label": "固有値分解の反復 [回]", "type": "integer" }
]);
emit_table_with_columns!(
    reference,
    vec![(
        lambda1,
        (lambda1 - 1.0).abs(),
        closed_form_gap,
        report.iterations()
    )],
    metadata = serde_json::json!({ "id": "reference" })
);

let mut x = Vector::from_vec(vec![1.0_f64; n]);
let (mut angle, mut rayleigh) = (Vec::new(), Vec::new());
let (mut first, mut last) = ((0.0_f64, 0.0_f64), (0.0_f64, 0.0_f64));
for k in 1..=steps {
    let y = a.view().mul_vec(&x).map_err(|e| e.to_string())?;
    let norm = y.view().norm2().map_err(|e| e.to_string())?;
    x = Vector::from_vec(y.as_slice().iter().map(|v| v / norm).collect());
    let ax = a.view().mul_vec(&x).map_err(|e| e.to_string())?;
    let error = (x.view().dotc_left(&ax).map_err(|e| e.to_string())? - lambda1).abs();
    // 正弦は v₁ に直交する成分のノルムで求める（1 − cos² の桁落ちを避ける）。
    let c: f64 = x.as_slice().iter().zip(&v1).map(|(p, q)| p * q).sum();
    let sine = x
        .as_slice()
        .iter()
        .zip(&v1)
        .map(|(p, q)| (p - c * q).powi(2))
        .sum::<f64>()
        .sqrt();
    if k == 1 {
        first = (sine, error);
    }
    last = (sine, error);
    // 0 は対数軸に描けないので除く。
    if sine > 0.0 {
        angle.push([k as f64, sine]);
    }
    if error > 0.0 {
        rayleigh.push([k as f64, error]);
    }
}
// 参照の傾き: 1 回目の値から q^(k−1)、q^(2(k−1)) で減らす。
let model = |k: usize, power: i32| ratio.powi(power * (k as i32 - 1));
let model_angle: Vec<[f64; 2]> = (1..=steps)
    .map(|k| [k as f64, first.0 * model(k, 1)])
    .collect();
let model_rayleigh: Vec<[f64; 2]> = (1..=steps)
    .map(|k| [k as f64, first.1 * model(k, 2)])
    .collect();
let series = vec![
    serde_json::json!({ "name": "sin ∠(x_k, v₁)", "points": angle }),
    serde_json::json!({
        "name": "q^k の傾き",
        "points": model_angle,
        "style": { "lineType": "dashed" }
    }),
    serde_json::json!({ "name": "|ρ_k − λ₁|", "points": rayleigh }),
    serde_json::json!({
        "name": "q^(2k) の傾き",
        "points": model_rayleigh,
        "style": { "lineType": "dashed" }
    }),
];
emit_line_chart!(
    &series,
    options = &serde_json::json!({
        "xLabel": "反復回数 k [回]",
        "yLabel": "誤差 [-]",
        "yType": "log"
    })
);
let final_columns = serde_json::json!([
    { "key": "0", "label": "K [回]", "type": "integer" },
    { "key": "1", "label": "sin ∠(x_K, v₁) [-]", "type": "number", "format": sci2 },
    { "key": "2", "label": "|ρ_K − λ₁| [-]", "type": "number", "format": sci2 },
    { "key": "3", "label": "正弦の参照値 [-]", "type": "number", "format": sci2 },
    { "key": "4", "label": "Rayleigh 商の参照値 [-]", "type": "number", "format": sci2 }
]);
let final_row = (
    steps,
    last.0,
    last.1,
    first.0 * model(steps, 1),
    first.1 * model(steps, 2),
);
emit_table_with_columns!(
    final_columns,
    vec![final_row],
    metadata = serde_json::json!({ "id": "final" })
);
```

固有値分解で求めた $\lambda_1$ は閉じた形の 1 と $4.4 \times 10^{-16}$、固有ベクトルは $He_1$ と $3.1 \times 10^{-16}$ の差で一致する。
`EigenReport` の反復回数は 62 回で、既定の上限 $30m = 900$ 回より十分少ない。
既定の $q = 0.9$ では、角の正弦は一反復あたり約 $\log_{10} 0.9 \approx -0.046$ 桁ずつ、Rayleigh 商の誤差はその約 2 倍の速さで減り、100 回で前者は $1.6 \times 10^{-5}$、後者は $2.7 \times 10^{-11}$ に達する。
1 回目の値から延ばした参照値はそれぞれ $2.8 \times 10^{-5}$ と $4.3 \times 10^{-10}$ で、初めの数回は $\lambda_3$ 以下の成分も減っていくので、実際の誤差は破線より速く減る。

$q = 0.5$ では Rayleigh 商の誤差が 24 回目、角の正弦が 50 回目に $10^{-15}$ を下回り、そこから先は丸め誤差の水準 $10^{-16}$ 付近で止まる。
$q = 0.99$ では 100 回でも角の正弦は 0.22、Rayleigh 商の誤差は $4.8 \times 10^{-4}$ にとどまる。
反復回数を 200 にすると、$q = 0.9$ の角の正弦は $4.3 \times 10^{-10}$ まで減り、Rayleigh 商の誤差は丸め誤差の水準 $2.2 \times 10^{-16}$ に達する。
Rayleigh 商の誤差がちょうど 0 になった反復は対数軸に描けないので図から除いており、$q = 0.5$、$K = 100$ では 7 回ある。

## 一般の行列：Hessenberg 化と Francis の QR 反復

Hermitian でない行列も、ユニタリ行列 $Q$ で上三角行列 $T$ に変換できる（Schur の定理 $A = QTQ^{\mathsf H}$）。
$T$ の対角が固有値で、実行列では複素共役な固有値の組を $2 \times 2$ のブロックで表す実 Schur 形（準上三角）を使う。
計算はまず Householder 変換で Hessenberg 行列（第 1 副対角より下が 0 の行列）に縮約し、QR 反復で準上三角になるまで副対角を消す。
実行列には実数演算のまま複素共役な組を扱う Francis の二重シフト QR 反復を、複素行列には単一シフトの複素 QR 反復を使う。
一般の場合の局所的な収束は 2 次で、Hermitian の三重対角行列での 3 次とは異なる。

`GeneralEigenOptions` の平衡化 `GeneralEigenBalancing` は置換行列 $P$ と 2 の冪を対角に持つ $D$ による相似変換 $D^{-1} P^{\mathsf T} A P D$ である。
`Permute` は分離できる行と列を置換で取り出して対角から読める固有値を切り離し、`Scale` は 2 の冪で各行とその列の 2 ノルムをそろえ、既定の `PermuteAndScale` は両方を順に適用し、`None` は何もしない。
相似変換なので固有値は変わらず、2 の冪の尺度は丸め誤差を加えないので、尺度の大きく異なる行列で誤差を減らす。
尺度の積とその逆数は正規化数の範囲に収め、0 でない成分を 0 にしない。
行列は成分の最大絶対値で割り、平衡化し、QR 反復の前にもう一度尺度を合わせるので、収縮の許容誤差はこの行列に対して決まる。
結果は元の座標に戻され、使った置換と尺度は `GeneralEigenBalanceMetadata`（`balancing()`）の `permutation()` と `scale_factors()` に残る。

`GeneralEigenvaluesResult::compute(&a)` は固有値だけを返す標準形式で、実行列の複素固有値は厳密な共役の組で返る。
`GeneralEigenDecomposition::decompose(&a)` は固有ベクトルも同じ Schur 形から計算し、右の固有ベクトルは後退代入、左の固有ベクトルは前進代入で求める。
どちらを求めるかはオプション付き形式 `decompose_with_options(&a, &options)` に渡す `GeneralEigenOptions::with_eigenvectors(GeneralEigenvectorSelection::{Left, Right, Both})`（既定 `Right`）で選ぶ。
固有ベクトルは実行列でも複素数で、2 ノルムが 1、絶対値が最大の成分（同じ大きさなら最後のもの）が正の実数になるよう位相をそろえる。
`right_residuals()` は各右固有ベクトルの相対残差 $\lVert Ax - \lambda x \rVert_\infty / ((\lVert A \rVert_\infty + \lvert\lambda\rvert) \lVert x \rVert_\infty)$ を尺度を合わせた行列について返し、`left_residuals()` は左固有ベクトル $y$ の $\lVert A^{\mathsf H} y - \bar\lambda y \rVert_\infty / ((\lVert A \rVert_1 + \lvert\lambda\rvert) \lVert y \rVert_\infty)$ を返す（$\lVert A^{\mathsf H} \rVert_\infty = \lVert A \rVert_1$）。
結果は返す前に検査する。
各相対残差が $32\max(n, 1)$ 倍した残差の許容誤差（`with_residual_tolerance`、既定は機械イプシロンから作る）を超えるか、固有ベクトルが平衡化した座標で数値的に一次従属なら、`NumericalInstability`（`DefectiveEigenbasis`）になる。
欠損行列や、固有ベクトルが数値的に一次従属になるほど欠損に近い行列はこの検査を通らないので、固有値だけを求めるか Schur 分解を使う。
`eigenvector_condition_estimates()` は各固有ベクトルについて $\min(1, \mathrm{gap}/\lVert A \rVert_\infty)$ を返す経験的な推定で、$\mathrm{gap}$ は最も近い別の固有値との距離である。
QR 反復の上限は既定で $30\max(n, 1)$ 回で、達すると `ConvergenceFailure` になる。
出力先を指定する API `decompose_into` と `GeneralEigenvaluesBuffer::compute_into` の作業領域は `GeneralEigenWorkspaceRequest::new(n, &options)` から求め、要求した側の固有ベクトルごとに $n \times n$ の行列が加わる。

### Hessenberg 形のシフト付き求解

Hessenberg 形は固有値の計算のほかに、多くのシフト $\sigma$ について $(\sigma I - A)^{-1} B$ を求める計算にも使える。
伝達関数 $C(\sigma I - A)^{-1}B$ を多くの周波数 $\sigma = \mathrm{i}\omega$ で評価する場合がその例で、$A = QHQ^{\mathsf H}$ と一度だけ縮約すれば、各シフトでは $(\sigma I - H) X = Q^{\mathsf H} B$ を解けばよい。
$H$ の副対角は 1 本なので、部分ピボット付きの消去は各段で隣り合う 2 行を比べるだけで済み、右辺が $m$ 列なら一つのシフトの計算量は $O(n^2 + n^2 m)$ で、稠密な LU 分解の $O(n^3)$ を毎回払わずに済む。

この計算の部品は低水準の `backend::hessenberg` にある。
`reduce(a.view(), context)` は有限な正方行列から $A = QHQ^{\mathsf H}$ の $H$ と $Q$ を $O(n^3)$ で作り、形の誤り、非有限値、実行コンテキストの取り消しや期限をエラーで返し、メモリ領域を確保できない場合も `AllocationFailure` を返す。
`HessenbergView::new(h.view())` は $H$ が正方で有限で、第 1 副対角より下が 0 であることを一度だけ検査し、第 1 副対角も 0 なら上三角として記録する。
`solve_shifted(view, shift, columns, &mut rhs, &mut factor)` は行優先の $n \times m$ の右辺 `rhs` を解 $X$ で上書きする。
`factor` は少なくとも $n^2$ 要素の作業配列で、呼び出しのたびに $\sigma I - H$ の写しに使われ、$H$ 自体は変わらない。
上三角の $H$ では消去を省いて後退代入だけで解き、ピボットの選択では複素数の大きさを $\max(\lvert \mathrm{Re}\,z \rvert, \lvert \mathrm{Im}\,z \rvert)$ で比べる。
作業配列が短いか右辺の長さが $n m$ でなければ `DimensionMismatch`、右辺に非有限値があれば `NonFinite`、シフトや途中の値が有限でなければ `NumericalInstability`、ピボットが厳密に 0 なら `Singular` を返す。
`backend` は他の SciOxide クレートが使う低水準の部品で、失敗したときに右辺と作業配列を書き換えたままにすることがあり、ランクの方針、残差や条件数の診断、実行の回数の集計を持たない。

## 非正規な行列の固有値の感度

$A$ が非正規（$A^{\mathsf H} A \ne A A^{\mathsf H}$）だと、固有値は摂動に敏感になりうる。
単純な固有値 $\lambda_i$ の右固有ベクトルを $x_i$、左固有ベクトルを $y_i$ とすると、摂動 $E$ に対して一次近似で

$$
\lvert \Delta\lambda_i \rvert \lesssim \frac{\lVert E \rVert_2}{s_i}, \qquad s_i = \frac{\lvert y_i^{\mathsf H} x_i \rvert}{\lVert x_i \rVert_2 \lVert y_i \rVert_2}
$$

が成り立つ。
Hermitian 行列では $x_i = y_i$ なので $s_i = 1$ であり、$s_i$ が小さいほど固有値は悪条件になる（Wilkinson の $s(\lambda)$）。
`GeneralEigenDecomposition` は、`GeneralEigenvectorSelection::Both` で左右のベクトルの両方を求めた場合に、$s_i$ を `eigenvalue_condition_estimates()` で返す。

次のセルは対角が $1, 2, \dots, n$、上対角が $\alpha$ の上二重対角行列に、成分の大きさ $\delta$ の摂動を加え、固有値の変化を $n\delta / s_i$ と比べる。
符号を決めた摂動 $E$ は $\lVert E \rVert_2 \le \lVert E \rVert_F = n\delta$ を満たす。
固有値は対角の $1, 2, \dots, n$ のままで、$\alpha$ を大きくすると非正規性が強まる。
固有値 $\lambda_j = j + 1$（添字は 0 から）の右固有ベクトルは $x_{j-m} = \alpha^m/m!$、左固有ベクトルは $y_{j+m} = (-\alpha)^m/m!$（$m \ge 0$）で、$y_j^{\mathsf H} x_j = 1$ なので

$$
s_j = \Bigl(\sum_{m=0}^{j} \frac{\alpha^{2m}}{(m!)^2}\Bigr)^{-1/2} \Bigl(\sum_{m=0}^{n-1-j} \frac{\alpha^{2m}}{(m!)^2}\Bigr)^{-1/2}
$$

が閉じた形で分かる。
入力は $\alpha$（0 から 6）、次数 $n$（3 から 12）、摂動の指数 $e$（$\delta = 10^{e}$、$-14$ から $-6$）である。
表は推定した $s_i$ と閉じた形の $s_i$、摂動後の固有値のうち $\lambda_i$ に最も近いものとの距離 $\lvert \Delta\lambda_i \rvert$、一次の評価 $n\delta/s_i$ を並べる。

```rust
//| id: linalg-nonnormal-sensitivity
//| ref: linalg-nonnormal-sensitivity
//| title: 非正規な行列の固有値の摂動と条件数推定
//| run: reactive
//| crates: [scioxide-linalg]
//| inputs:
//|   coupling: {"type":"range","label":"上対角 α","description":"非正規性の強さ。α = 0 で対角行列。","min":0,"max":6,"step":0.5,"value":3}
//|   order: {"type":"range","label":"次数 n","description":"固有値は 1, 2, …, n。","min":3,"max":12,"step":1,"value":8}
//|   perturbation_exponent: {"type":"range","label":"摂動の大きさ 10^e の e","description":"全成分に加える摂動の大きさ。","min":-14,"max":-6,"step":1,"value":-10}
//| cases:
//|   - {"id":"normal","label":"α = 0","description":"対角行列なので s_i = 1 で、固有値の変化は摂動と同じ大きさになる。","inputs":{"coupling":0}}
//|   - {"id":"strong-coupling","label":"α = 6","description":"中央の s_i が 3.6 × 10⁻⁴ まで下がり、固有値が摂動の千倍以上動く。","inputs":{"coupling":6}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"sensitivity","path":"/rows/0/1","approx":{"value":0.12198324317856824,"rtol":1e-8}}
//|       - {"artifact":"sensitivity","path":"/rows/3/1","approx":{"value":0.017887179974519887,"rtol":1e-8}}
//|       - {"artifact":"sensitivity","path":"/rows/2/3","range":{"max":3.6e-8}}
//|   - case: normal
//|     expect:
//|       - {"artifact":"sensitivity","path":"/rows/3/1","approx":{"value":1,"rtol":1e-12}}
//|       - {"artifact":"sensitivity","path":"/rows/3/3","approx":{"value":1e-10,"rtol":1e-3}}
//|   - case: strong-coupling
//|     expect:
//|       - {"artifact":"sensitivity","path":"/rows/3/1","approx":{"value":3.6327720298445846e-4,"rtol":1e-6}}
//|       - {"artifact":"sensitivity","path":"/rows/3/3","range":{"min":1e-8,"max":2.2e-6}}
use scioxide_linalg::{
    GeneralEigenDecomposition, GeneralEigenOptions, GeneralEigenvaluesResult,
    GeneralEigenvectorSelection, Matrix,
};

let n = order.round() as usize;
let delta = 10.0_f64.powf(perturbation_exponent);
let base = |k: usize| {
    let (i, j) = (k / n, k % n);
    if i == j {
        (i + 1) as f64
    } else if j == i + 1 {
        coupling
    } else {
        0.0
    }
};
let a = Matrix::from_vec(n, n, (0..n * n).map(base).collect()).map_err(|e| e.to_string())?;
// 決定論的な符号の摂動 E（成分の大きさ δ、‖E‖₂ ≤ nδ）。
let sign = |k: usize| if (k * 7 + 3) % 5 < 2 { -1.0 } else { 1.0 };
let perturbed = Matrix::from_vec(
    n,
    n,
    (0..n * n).map(|k| base(k) + delta * sign(k)).collect(),
)
.map_err(|e| e.to_string())?;
let options = GeneralEigenOptions::new().with_eigenvectors(GeneralEigenvectorSelection::Both);
let exact = GeneralEigenDecomposition::decompose_with_options(&a, &options)
    .map_err(|e| e.to_string())?;
let moved = GeneralEigenvaluesResult::compute(&perturbed).map_err(|e| e.to_string())?;
let conditions = exact
    .eigenvalue_condition_estimates()
    .ok_or("条件数の推定がない")?;
// 独立な参照: 閉じた形の s_j（ノルムの二乗和 Σ (α^m/m!)²）。
let norm = |count: usize| {
    let (mut term, mut sum) = (1.0_f64, 1.0_f64);
    for m in 1..=count {
        term *= coupling / m as f64;
        sum += term * term;
    }
    sum.sqrt()
};

    let s = cond.reciprocal().value();

    // 摂動後の固有値のうち λ_j に最も近いものとの距離。
    let shift = moved
        .eigenvalues()
        .iter()
        .map(|z| (z.re - lambda.re).hypot(z.im - lambda.im))
        .fold(f64::INFINITY, f64::min);
    rows.push((lambda.re, s, closed, shift, n as f64 * delta / s));
}

let columns = serde_json::json!([
    { "key": "0", "label": "λ_i [-]", "type": "number", "format": { "fractionDigits": 0 } },
    { "key": "1", "label": "s_i（推定） [-]", "type": "number", "format": sci3 },
    { "key": "2", "label": "s_i（閉じた形） [-]", "type": "number", "format": sci3 },
    { "key": "3", "label": "|Δλ_i| [-]", "type": "number", "format": sci3 },
    { "key": "4", "label": "n δ / s_i [-]", "type": "number", "format": sci3 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "sensitivity" })
);
```

推定した $s_i$ は既定値と二つのケース、各入力の両端で、閉じた形の値と相対 $10^{-14}$ 以内で一致する。
$\alpha = 0$ では行列は対角（正規）で $s_i = 1$ となり、固有値の変化は摂動の大きさ $10^{-10}$ とほぼ同じである。
既定の $\alpha = 3$、$n = 8$ では中央の固有値の $s_i$ が $1.8 \times 10^{-2}$ まで下がり、変化は最大 $3.4 \times 10^{-9}$ に増える。
$\alpha = 6$（$n = 8$）では中央の $s_i$ が $3.6 \times 10^{-4}$ まで下がり、摂動 $10^{-10}$ に対して固有値が最大 $1.4 \times 10^{-7}$ 動く。
どの場合も変化は一次の評価 $n\delta / s_i$ を下回り、$s_i$ が小さい固有値ほど大きく動く傾向は評価どおりである。
既定の $\alpha = 3$、$n = 8$ で摂動を $10^{-6}$ に上げると最大の変化は $3.4 \times 10^{-5}$、$10^{-14}$ に下げると $3.1 \times 10^{-13}$ で、どちらも摂動にほぼ比例しており、この範囲では一次の評価が成り立っている。

## Schur 分解と不変部分空間

`SchurDecomposition::decompose(&a)` は $A = QTQ^{\mathsf H}$ の $T$（`t()`）と $Q$（`q()`）、固有値（`eigenvalues()`）、対角ブロックの並び（`blocks()`）を返す標準形式である。
複素行列の $T$ は上三角で、実行列の $T$ は準上三角である。
実行列の複素共役な組は `SchurBlock::RealTwoByTwo` の $2 \times 2$ ブロック $\begin{bmatrix} a & b \\ c & a \end{bmatrix}$（$bc < 0$、固有値 $a \pm \mathrm{i}\sqrt{\lvert b \rvert \lvert c \rvert}$）に標準化して置き、実数や複素数の 1 個の固有値は `SchurBlock::OneByOne` に置く。
固有値は QR 反復が残した順に並び、各 $2 \times 2$ ブロックでは虚部が正のものが先に来る。
平衡化は $Q$ をユニタリでなくするので、Schur 分解では行わない。
オプション付き形式 `decompose_with_options(&a, &SchurOptions)` の `SchurOptions` は収縮の許容誤差と実行の制御だけを持ち、QR 反復の上限は既定で $30\max(n, 1)$ 回である。

$Q$ の先頭 $k$ 列は $T$ の左上 $k \times k$ ブロックの固有値に対応する不変部分空間の正規直交基底で、`invariant_subspace(k)` で借用できる。
$k$ が次数を超えるか実数の $2 \times 2$ ブロックを分ける場合は `InvalidInput` になる。
`reorder(&selection)` は、選んだ固有値を隣り合うブロックの交換で左上へ移した写しとレポート `SchurReorderReport` を返し、複素共役な組は分けない。
交換は小さな Sylvester 方程式から求めたユニタリな相似変換で、弱い後退誤差の検査と強い後退誤差の検査を通るときだけ採用し、安定に交換できなければ `NumericalInstability`（`IllConditioned`）になる。
`reorder` は写しを返すので、失敗しても元の分解は変わらない。
オプション付き形式 `reorder_with_options(&selection, &SchurReorderOptions)` の作業量の上限は既定で 30 000 単位（試みた交換の回数と、条件数を推定するときに Sylvester 作用素を適用した回数の合計）で、達すると `ConvergenceFailure` になる。
同じ分解を書き換える出力先を指定する API は `reorder_in_place` で、作業領域は `SchurWorkspaceRequest::reorder` から求める。

レポートは選んだ固有値の個数 `selected_dimension()`、交換の回数 `swaps()`、使った作業量 `iterations()` を返す。
`SchurReorderOptions::with_condition_estimates(Estimation::Estimate)` を指定すると、選んだ固有値の組の逆条件数 $1/\sqrt{1 + \lVert R \rVert_F^2}$（`cluster_condition()`、$R$ は $T_{11} R - R T_{22} = T_{12}$ の解）と、残りとの分離 $\operatorname{sep}(T_{11}, T_{22}) = 1/\lVert S^{-1} \rVert$ の 1 ノルムによる推定（`separation()`、$S(R) = T_{11}R - RT_{22}$）が加わる。
どちらも推定値で証明された限界ではなく、分離が小さいと不変部分空間は摂動に敏感になる。

## まとめ

Hermitian 行列には `HermitianEigenDecomposition` を使い、入力の対称性を `HermitianInput` で明示し、一部の固有値や小さな固有値の相対精度が要るときだけ添字の範囲や `Relative` を指定する。
Gauss 求積の節点と重みのように固有値と第 1 成分だけが要る三重対角の問題は、`HermitianEigenFirstComponents` で $O(n^2)$ の計算量と $O(n)$ のメモリ領域で解ける。
べき乗法の収束は比 $q = \lvert \lambda_2 \rvert / \lvert \lambda_1 \rvert$ で決まるので、$q$ が 1 に近ければシフト反転か部分スペクトルの手法を選ぶ。
一般の行列で非正規性が疑われるときは、`GeneralEigenvectorSelection::Both` で左右の固有ベクトルを求め、$s_i$ から固有値の感度 $\lVert E \rVert_2 / s_i$ を見積もる。
固有ベクトルの検査に通らない欠損に近い行列や、不変部分空間が要る問題には、`SchurDecomposition` と `reorder` を使う。
反復が上限に達すると `ConvergenceFailure` になるので、`EigenReport` の反復回数で上限との余裕を確かめる。
