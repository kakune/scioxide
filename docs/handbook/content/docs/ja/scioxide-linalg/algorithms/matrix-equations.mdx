行列を未知数とする線形方程式は、制御系の可制御性・可観測性、安定性の判定、モデル低次元化、最適制御の設計に現れる。
このページは Sylvester 方程式と Lyapunov 方程式、非線形の代数 Riccati 方程式の解の存在条件と計アルゴリズム、`scioxide-linalg` のワンショット関数と Plan、解を受理する判定と診断を説明する。
いずれの解法も [Schur 分解](../eigenproblems/)か [QZ 分解](../generalized-eigenproblems/)を使う。

## Sylvester 方程式と Bartels–Stewart 法

$A \in \mathbb{K}^{m \times m}$、$B \in \mathbb{K}^{n \times n}$、$C \in \mathbb{K}^{m \times n}$ と符号 $s = \pm 1$ に対する Sylvester 方程式 $AX + sXB = C$ は、$X$ の成分を並べたベクトルについての線形方程式

$$
(I_n \otimes A + s\, B^{\mathsf T} \otimes I_m)\, \operatorname{vec}(X) = \operatorname{vec}(C)
$$

と同値である。
係数行列の固有値は $\lambda_i(A) + s\,\mu_j(B)$ なので、$\lambda_i + s\,\mu_j = 0$ となる組がないときに限り解は一意である（$s = 1$ では $A$ と $-B$ が共通の固有値を持たないこと）。
$mn \times mn$ の行列を作って解くと $O(m^3 n^3)$ かかるので、Bartels–Stewart 法は $A = Q_A T_A Q_A^{\mathsf H}$、$B = Q_B T_B Q_B^{\mathsf H}$ と Schur 分解し、三角な $T_A Y + s\,Y T_B = Q_A^{\mathsf H} C Q_B$ を代入で解いて $X = Q_A Y Q_B^{\mathsf H}$ に戻す。
計算コストは Schur 分解の $O(m^3 + n^3)$ と、右辺ごとの変換と代入の $O(m^2 n + m n^2)$ である。
`scioxide-linalg` は実行列では $1 \times 1$ と $2 \times 2$ の対角ブロックを持つ実 Schur 形を使い、代入を 32 次以下の区画にまとめて区画の間の更新を行列の積で行う。
$A^{\mathsf T} X + XB = C$ のような別の向きは、係数の転置や随伴のビューを渡して解く。

解の感度は分離 $\operatorname{sep}(A, -sB) = \min_{X \ne 0} \lVert AX + sXB \rVert_F / \lVert X \rVert_F$ で決まる。
係数を $\lVert \Delta A \rVert_F \le \epsilon \lVert A \rVert_F$、$\lVert \Delta B \rVert_F \le \epsilon \lVert B \rVert_F$、$\lVert \Delta C \rVert_F \le \epsilon \lVert C \rVert_F$ だけ摂動すると、摂動した方程式から $A\,\Delta X + s\,\Delta X\,B = \Delta C - \Delta A\,X - s X\,\Delta B + O(\epsilon^2)$ が得られ、Higham（*Accuracy and Stability of Numerical Algorithms*、16 章）の教科書の評価

$$
\frac{\lVert \Delta X \rVert_F}{\lVert X \rVert_F} \le \epsilon\, \frac{(\lVert A \rVert_F + \lVert B \rVert_F) \lVert X \rVert_F + \lVert C \rVert_F}{\operatorname{sep}(A, -sB)\, \lVert X \rVert_F} + O(\epsilon^2) \le 2\epsilon\, \frac{\lVert A \rVert_F + \lVert B \rVert_F}{\operatorname{sep}(A, -sB)} + O(\epsilon^2)
$$

になる（最後の不等式は $\lVert C \rVert_F \le (\lVert A \rVert_F + \lVert B \rVert_F) \lVert X \rVert_F$ による）。
この比 $(\lVert A \rVert_F + \lVert B \rVert_F) / \operatorname{sep}$ は条件数の目安で、三角不等式を重ねた上界なので真の感度を大きく見積もることがある。
$\operatorname{sep}$ は固有値の最小の間隔 $\min_{i,j} \lvert \lambda_i + s\,\mu_j \rvert$ 以下で、$A$ と $B$ が正規なら等しく、非正規な行列ではそれよりずっと小さくなりうる。

呼び出しの形の名前（ワンショット関数・Plan・出力先を指定する API など）は[作業領域・実行コンテキスト・試行記録](oxref:linalg-execution-forms)で定義する。
ワンショット関数 `solve_sylvester(&a, &b, SylvesterSign::Plus, &c)` は $X$ を返し（`Minus` で $AX - XB = C$）、残差の判定で拒否された解は `NumericalInstability`（`LossOfSignificance`）のエラーになる。
同じ係数で右辺を変えて何度も解くなら、Plan `SylvesterPlan::new(&a, &b, sign, options)` が二つの Schur 分解を一度だけ準備し、`solve(&c)` で右辺ごとに解く（`build(..., cx)` は準備の反復をコンテキスト `cx` の入れ子の処理として数える）。
`solve(&c)` は結果 `MatrixEquationResult` を返し、`solution()` は受理された解だけを `Some` で返し、`report()` はレポート `MatrixEquationReport` を、`into_accepted()` は解かエラーを返す。
出力先を指定する API `solve_into(&c, out, &mut ws, cx)` は `plan.workspace(())`（`workspace_requirements(())` で大きさを求める）の `LinalgWorkspace` を使い、拒否したときは `out` を書き換えない。

拒否された候補の解は出力に反映されないが、診断はレポートに残る。
レポートの `termination()` は直接解法と共通の終了理由 `DirectSolveTermination` で、Sylvester と Lyapunov では `Accepted` か `ResidualRejected` であり、受理はこの値だけで判定する。
受理の判定は元の方程式の残差 $R = T_1 + T_2 + T_3$（Sylvester では $T_1 = AX$、$T_2 = sXB$、$T_3 = -C$）について

$$
\lVert R \rVert_F \le \tau_{\mathrm{abs}} + \tau_{\mathrm{rel}} \left( \lVert T_1 \rVert_F + \lVert T_2 \rVert_F + \lVert T_3 \rVert_F \right)
$$

で、`residual()` が $\lVert R \rVert_F$、`backward_error()` が右辺の括弧で割った比（後退誤差）を返す。
`separation()` は Schur 座標での方程式の作用素 $L$（Sylvester では $L(Y) = T_A Y + s\,Y T_B$）の $1/\lVert L^{-1} \rVert_1$ を推定した、分離の 1 ノルム版である。
$\lVert L^{-1} \rVert_1$ を Hager–Higham の方法で下から推定する（未知数が 4 個以下なら厳密）ので、レポートの値は真の 1 ノルムの分離より大きく出ることがあり、感度を保証する値ではない。
`Estimation::Skip` で推定しない場合と空の方程式では `None`、推定が完了しなかった場合は 0 になる。
`work()` は変換・代入・分離の推定・残差の確認に使った作業量である。
設定 `MatrixEquationOptions` の既定は残差の許容誤差 $\tau_{\mathrm{abs}} = \tau_{\mathrm{rel}} = \sqrt{\varepsilon_{\mathrm{mach}}}$（`with_tolerance`）、分離の推定あり（`with_separation(Estimation::Estimate)`）、1 回の求解あたり作業量 100 万単位（`LinalgExecutionOptions::with_iteration_budget` で変える）である。
作業量を超えると `ConvergenceFailure`、可解条件が浮動小数点で破れて対角ブロックの方程式のピボットがちょうど 0 になると `Singular` のエラーになる。
反復の上限を明示すると、Plan の準備で行う Schur 分解の QR 反復もその上限で抑える。
この反復は指定しなければ $30\max(n, 1)$ 回まで許され、通常は固有値ひとつあたり 2 回ほどかかるので、それより小さい上限では Plan の構築が失敗する。

## Lyapunov 方程式とグラミアン

連続時間の Lyapunov 方程式 $AX + XA^{\mathsf H} = Q$ は $B = A^{\mathsf H}$ の Sylvester 方程式で、すべての固有値の組で $\lambda_i + \overline{\lambda_j} \ne 0$ のとき一意に解ける。
$A$ が安定（すべての固有値の実部が負）なら解は

$$
X = -\int_0^{\infty} e^{At}\, Q\, e^{A^{\mathsf H} t}\, dt
$$

である。
$A$ が安定で $Q = -BB^{\mathsf H}$ のときの解 $X = \int_0^\infty e^{At} BB^{\mathsf H} e^{A^{\mathsf H}t}\, dt$ は半正定値の可制御性グラミアンで、正定値であることが系 $(A, B)$ の可制御性と同値になる。
離散時間の方程式 $AXA^{\mathsf H} - X + Q = 0$（Stein 方程式）は、$\lambda_i \overline{\lambda_j} \ne 1$ のとき一意に解け、$A$ の固有値がすべて単位円の内側にあればこれを満たす。

ワンショット関数 `solve_lyapunov(&a, LyapunovKind::Continuous, &q)`（離散時間は `Discrete`）は $X$ を返す。
Plan `LyapunovPlan::new(&a, kind, options)` は $A$ の Schur 分解を一度 $O(n^3)$ で求めて両側で使い回し、`solve(&q)` は右辺ごとに $O(n^3)$ で解く。
$A^{\mathsf H} X + XA = Q$ を解くには、$A$ の随伴のビューを渡す。
$Q$ がちょうど Hermitian なら、計算した解を Hermitian 部分 $(X + X^{\mathsf H})/2$ に置き換えてから残差を確かめ、レポートの `symmetry_defect()` は置き換える前のずれ $\max_{ij} \lvert x_{ij} - \overline{x_{ji}} \rvert$ を返す（Sylvester では `None`）。
受理の判定とレポートは Sylvester 方程式と同じである。

次のブロックはこのページの二つのセルが表と判定に出す終了理由の名前を定める。

```rust
//| id: linalg-matrix-equation-termination
//| kind: definitions
//| title: 直接解法の終了理由の名前
//| crates: [scioxide-linalg]
use scioxide_linalg::DirectSolveTermination;

/// 終了理由の列挙子名（表の列と判定の status に使う）。
pub(crate) fn direct_termination_name(termination: DirectSolveTermination) -> &'static str {
    match termination {
        DirectSolveTermination::Accepted => "Accepted",
        DirectSolveTermination::RankDeficient => "RankDeficient",
        DirectSolveTermination::IllConditioned => "IllConditioned",
        DirectSolveTermination::ResidualRejected => "ResidualRejected",
        DirectSolveTermination::StabilityRejected => "StabilityRejected",
    }
}
```

次のセルは減衰振動子 $A = \begin{bmatrix} -\delta & \omega \\ -\omega & -\delta \end{bmatrix}$ に対する連続時間の方程式（$Q = -I$）と、$A_d = (1 - \delta) R(\omega)$（$R(\omega)$ は角 $\omega$ [rad] の回転）に対する離散時間の方程式（$Q = I$）を `LyapunovPlan` で解く。
どちらも解は単位行列の定数倍で、連続時間は $X = I/(2\delta)$、離散時間は $X = I/(1 - (1-\delta)^2)$ であり、$\delta \to 0$ で安定の境界に近づくと解が発散する。
表は解の $(1,1)$ 成分、閉じた形、全成分の相対差（閉じた形の値で割った最大値）、後退誤差、分離の推定、終了理由を示し、判定は二つとも受理されたかを示す。

```rust
//| id: linalg-lyapunov-stability
//| ref: linalg-lyapunov-stability
//| title: 安定の境界に近づく Lyapunov 方程式の解と分離
//| run: reactive
//| uses: [linalg-matrix-equation-termination]
//| crates: [scioxide-linalg]
//| inputs:
//|   distance_exponent: {"type":"range","label":"安定の境界までの距離 δ = 10^k の k","description":"連続時間は固有値の実部 −δ、離散時間はスペクトル半径 1 − δ。","min":-8,"max":0,"step":1,"value":-3}
//|   omega: {"type":"range","label":"回転 ω [rad]","description":"固有値の虚部（連続）と回転角（離散）。","min":0,"max":3,"step":0.25,"value":1}
//| cases:
//|   - {"id":"near-boundary","label":"δ = 10⁻⁸","description":"解が 5 × 10⁷ に達し、離散時間の解の相対差が条件数に応じて増える。","inputs":{"distance_exponent":-8}}
//|   - {"id":"far-from-boundary","label":"δ = 1","description":"離散時間の係数が 0 になり、解は単位行列になる。","inputs":{"distance_exponent":0}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"lyapunov","path":"/rows/0/1","approx":{"value":500.0,"rtol":1e-12}}
//|       - {"artifact":"lyapunov","path":"/rows/0/3","range":{"max":1e-12}}
//|       - {"artifact":"lyapunov","path":"/rows/1/3","range":{"max":1e-12}}
//|       - {"artifact":"lyapunov","path":"/rows/0/5","approx":{"value":2e-3,"rtol":2e-3}}
//|       - {"artifact":"lyapunov","path":"/rows/1/6","equals":"Accepted"}
//|       - {"path":"/outputs/1/state","equals":"satisfied"}
//|   - case: near-boundary
//|     expect:
//|       - {"artifact":"lyapunov","path":"/rows/0/2","approx":{"value":5e7,"rtol":1e-12}}
//|       - {"artifact":"lyapunov","path":"/rows/1/3","range":{"max":1e-6}}
//|       - {"path":"/outputs/1/state","equals":"satisfied"}
//|   - case: far-from-boundary
//|     expect:
//|       - {"artifact":"lyapunov","path":"/rows/1/1","approx":{"value":1.0,"rtol":1e-14}}
//|       - {"artifact":"lyapunov","path":"/rows/0/3","range":{"max":1e-14}}
use scioxide_linalg::{LyapunovKind, LyapunovPlan, Matrix, MatrixEquationOptions};

let delta = 10.0_f64.powf(distance_exponent);
let (c, s) = (omega.cos(), omega.sin());
let continuous =
    Matrix::from_rows(&[[-delta, omega], [-omega, -delta]]).map_err(|e| e.to_string())?;
let r = 1.0 - delta;
let discrete =
    Matrix::from_rows(&[[r * c, -r * s], [r * s, r * c]]).map_err(|e| e.to_string())?;
let equations = [
    (
        "連続 AX + XAᴴ = −I",
        &continuous,
        LyapunovKind::Continuous,
        -1.0,
        1.0 / (2.0 * delta),
    ),
    (
        "離散 AXAᴴ − X + I = 0",
        &discrete,
        LyapunovKind::Discrete,
        1.0,
        1.0 / (1.0 - r * r),
    ),
];
let (mut rows, mut accepted) = (Vec::new(), true);

        LyapunovPlan::new(a, kind, MatrixEquationOptions::new()).map_err(|e| e.to_string())?;

        name,
        x11,
        exact,
        error,
        report.backward_error(),
        report.separation(),
        termination,

    { "key": "1", "label": "x₁₁ [-]", "type": "number", "format": digits7, "nullText": "拒否" },
    { "key": "2", "label": "閉じた形 [-]", "type": "number", "format": digits7 },
    { "key": "3", "label": "相対差 [-]", "type": "number", "format": sci2, "nullText": "-" },

};
emit_outcome!(
    outcome

            "Accepted"
```

既定の $\delta = 10^{-3}$、$\omega = 1$ では、二つの解が閉じた形と相対差 $2.3 \times 10^{-16}$、$1.9 \times 10^{-15}$ で一致し、後退誤差は $10^{-16}$ 以下で、どちらも `Accepted` になる。
分離の推定は 1 ノルム版なので Frobenius ノルムの分離 $2\delta$ と一致するとは限らないが、ここではどちらの方程式も $2.0 \times 10^{-3}$ で、安定の境界までの距離を表している。
$\delta = 10^{-8}$ では解は $5 \times 10^{7}$ に達し、分離の推定は $2.0 \times 10^{-8}$ に縮み、離散時間の解の相対差は $5.8 \times 10^{-9}$ に増える。
離散時間の方程式で $A$ を摂動したときの $AXA^{\mathsf H}$ の変化は $2\epsilon \lVert A \rVert_2 \lVert A \rVert_F \lVert X \rVert_F$ 以下なので、$\lVert A \rVert_2 \approx 1$ のこの例では前節の目安 $(\lVert A \rVert_F + \lVert A^{\mathsf H} \rVert_F)/\operatorname{sep} \approx 1.4 \times 10^{8}$ がそのまま使える。
これに単位丸め $1.1 \times 10^{-16}$ を掛けた $1.6 \times 10^{-8}$ が相対誤差の目安で、観測した相対差はその範囲にあり、後退誤差は $6.4 \times 10^{-19}$ と小さく、判定は `Accepted` のままである。
小さい後退誤差は、解が係数のわずかな摂動に対する厳密解であることを示すだけで、前進誤差の小ささは分離で決まる。
連続時間の解がこの例で厳密に求まるのは、$X$ が単位行列の定数倍で丸め誤差が打ち消すためで、一般の行列では同じ程度の誤差が現れうる。
$\delta = 1$ では離散時間の係数が 0 になって解は単位行列になり、分離の推定は連続時間が 1.33、離散時間が 1.0 である。

## 代数 Riccati 方程式

最適レギュレータ $\min \int_0^\infty (x^{\mathsf H} Q x + u^{\mathsf H} R u)\, dt$（$\dot x = Ax + Bu$）の解は $u = -Kx$、$K = R^{-1} B^{\mathsf H} X$ で、$X$ は連続時間の代数 Riccati 方程式（CARE）

$$
A^{\mathsf H} X + X A - X B R^{-1} B^{\mathsf H} X + Q = 0
$$

の安定化解（$A - BK$ の固有値がすべて開いた左半平面にある解）である。
$Q \succeq 0$、$R \succ 0$ のとき、安定化解が存在するための必要十分条件は、$(A, B)$ が可安定で $(Q, A)$ が虚軸の上に不可観測な固有値を持たないことである。
安定化解は存在すればただ一つで、半正定値になる。
$(Q, A)$ が可検出なら、安定化解は半正定値な解のうちのただ一つでもある。

$X$ について二次の方程式だが、Hamilton 行列 $H = \begin{bmatrix} A & -BR^{-1}B^{\mathsf H} \\ -Q & -A^{\mathsf H} \end{bmatrix}$ を使うと固有値問題になる。
CARE は $H \begin{bmatrix} I \\ X \end{bmatrix} = \begin{bmatrix} I \\ X \end{bmatrix} (A - BK)$ と同値で、安定化解では $A - BK$ の固有値が $H$ の安定な固有値になる。
$H$ の固有値は $\lambda$ と $-\bar\lambda$ の対で現れるので、虚軸の上に固有値がなければ安定な固有値はちょうど $n$ 個ある。
その不変部分空間を $\operatorname{span}\begin{bmatrix} U_1 \\ U_2 \end{bmatrix}$ と書くと、$U_1$ が正則なら $X = U_2 U_1^{-1}$ が成り立つ。

`RiccatiPlan` は記述子 $E$ と交差項 $S$ を含む一般の形を扱い、`RiccatiKind::Continuous` は $A^{\mathsf H} X E + E^{\mathsf H} X A - (E^{\mathsf H} X B + S) R^{-1} (B^{\mathsf H} X E + S^{\mathsf H}) + Q = 0$ と $K = R^{-1}(B^{\mathsf H} X E + S^{\mathsf H})$、離散時間の `Discrete` は $A^{\mathsf H} X A - E^{\mathsf H} X E - (A^{\mathsf H} X B + S)(R + B^{\mathsf H} X B)^{-1}(B^{\mathsf H} X A + S^{\mathsf H}) + Q = 0$ と $K = (R + B^{\mathsf H} X B)^{-1}(B^{\mathsf H} X A + S^{\mathsf H})$ である。
この一般の形でも、安定化解は閉ループの行列束 $(A - BK, E)$ の固有値が開いた左半平面（離散では開いた単位円板）に入る解をいう。

準備は制御の未知数 $u$ を残した $2n + m$ 次の拡大行列束 $\mathcal{H} - \lambda \mathcal{J}$ を作る。
CARE では次の形で、$(x, \mu, u)$ の第 3 行 $S^{\mathsf H} x + B^{\mathsf H} \mu + R u = 0$ から $u$ を消すと、$E = I$、$S = 0$ のとき上の $H$ の固有値問題 $H \begin{bmatrix} x \\ \mu \end{bmatrix} = \lambda \begin{bmatrix} x \\ \mu \end{bmatrix}$ に戻る（DARE も同じ考え方の行列束を使う）。

$$
\mathcal{H} = \begin{bmatrix} A & 0 & B \\ -Q & -A^{\mathsf H} & -S \\ S^{\mathsf H} & B^{\mathsf H} & R \end{bmatrix}, \qquad
\mathcal{J} = \begin{bmatrix} E & 0 & 0 \\ 0 & E^{\mathsf H} & 0 \\ 0 & 0 & 0 \end{bmatrix}
$$

$u$ を消す代わりに行列束のまま扱うので、悪条件になりうる $R^{-1}$ や $(R + B^{\mathsf H} X B)^{-1}$ を作らない。
任意の平衡化のあと、$[B; -S; R]$ の列ピボット付き QR で最後の $m$ 列を消し、残る $2n \times 2n$ の行列束を QZ 法で一般化 Schur 形にし、$n$ 個の安定な固有値（連続では実部が負、離散では絶対値が 1 未満）を先頭へ並べ替える。
この行列束の固有値は連続では $\lambda$ と $-\bar\lambda$、離散では $\lambda$ と $1/\bar\lambda$ の対で現れる（Hamilton とシンプレクティックの構造）。
右 Schur ベクトルの先頭の $n$ 列 $[U_1; U_2]$ から $X = U_2 (E U_1)^{-1}$ を復元し、準備の計算コストは $O((n + m)^3)$ である。
可安定性と可検出性は呼び出し側の仮定で、Plan はこれを確かめない。
計算したスペクトルが安定性の許容誤差だけ離れて $n$ 個の安定な固有値と $n$ 個の不安定な固有値に分かれない場合（虚軸や単位円の近くに固有値がある、安定な固有値が $n$ 個でない、$0/0$ の固有値がある、部分空間の逆条件数の推定が $\varepsilon_{\mathrm{mach}}$ 以下になる）は、準備の段階で `NumericalInstability`（`IllConditioned`）のエラーになる。
$Q$ か $R$ がちょうど Hermitian でなければ `InvalidInput` になる。

状態 1 個・入力 1 個で $E = 1$、$S = 0$、$Q > 0$、$R > 0$、$B \ne 0$ の場合は、行列束を作らずに二次方程式のただ一つの正の根を求め、同じ安定性の判定を課す。
根は打ち消しの起きない側の解の公式と根の積から選び、係数の積は拡張した指数の範囲で計算する。
この経路は平衡化も部分空間の計算もしないので、状態の尺度 `state_scaling()` は 1、部分空間の逆条件数は 1、対称性のずれは 0 と示される。
それ以外は平衡化した行列束の並べ替えた QZ から解く。
既定の平衡化 `RiccatiBalancing::Scale` は置換を使わない Parlett–Reinsch の反復で $\lvert \mathcal{H} \rvert + \lvert \mathcal{J} \rvert$ の非対角の行和と列和をそろえ、余状態には状態の尺度の逆数を与え、制御の尺度を保つ 2 のべきの相似変換（Benner のシンプレクティックな平衡化）である。
`state_scaling()` は状態の尺度 $x = Dz$ の対角 $d$ を返し、$X$ と $K$ はつねに元の座標で返る。

ワンショット関数 `solve_riccati(problem, kind)` は受理された $(X, K)$ を返す。
この関数は `RiccatiOptions` の既定と違って閉ループの行列束 $(A - BK, E)$ の固有値を QZ でもう一度（$O(n^3)$）求め、残差の判定に加えて、すべての固有値の安定余裕が安定性の許容誤差を超えることを要求する。
Plan `RiccatiPlan::new(problem, kind, options)` に `RiccatiProblem`（$A, B, Q, R$ と任意の $E, S$ のビュー）を渡して準備し、`solve()` が結果 `RiccatiResult` を返す。
出力先を指定する API `solve_into(x, k, &mut ws, cx)` は `workspace(())` の `LinalgWorkspace` を使う。
各求解は $X$ を復元し、Hermitian からのずれが残差の許容誤差に収まることを確かめて $(X + X^{\mathsf H})/2$ に置き換え（収まらなければ `NumericalInstability` のエラー）、$K$ を計算し、元の方程式の残差を確かめる。
残差の判定は四つの項 $T_1 + T_2 + T_3 + T_4$（連続では $A^{\mathsf H} X E$、$E^{\mathsf H} X A$、$-(E^{\mathsf H} X B + S) K$、$Q$）の Frobenius ノルムの和に対する比で、Sylvester 方程式と同じ形である。
`RiccatiOptions` は残差の許容誤差（既定 $\sqrt{\varepsilon_{\mathrm{mach}}}$）、虚軸（単位円）からの距離の許容誤差 `with_stability_tolerance`（既定は $\tau_{\mathrm{abs}} = \tau_{\mathrm{rel}} = \varepsilon_{\mathrm{mach}}$）、平衡化 `with_balancing`（`RiccatiBalancing::{None, Scale}`、既定 `Scale`）、閉ループの固有値を別の QZ（$O(n^3)$）で確かめる `with_closed_loop_verification(Estimation::Estimate)`（既定は確かめない）を選ぶ。
QZ と並べ替えはそれぞれ反復 30 000 回までで、`with_execution_options` で合成する `LinalgExecutionOptions` の反復の上限で変える。

結果の `solution()` と `gain()` は受理されたときだけ `Some` を返し、`report()` がレポート `RiccatiReport` を返す。
レポートの `termination()` は `DirectSolveTermination` の `Accepted`、`ResidualRejected`、`StabilityRejected` のどれかで、両方の検証に不合格なら `StabilityRejected` が優先する。
`into_accepted()` とワンショット関数は拒否を `NumericalInstability` のエラーにし、安定性の拒否は `IllConditioned`、残差の拒否は `LossOfSignificance` である（ワンショット関数はいつも閉ループを確かめるので、どちらの拒否も起こりうる）。
これに残差 `residual()`、後退誤差 `backward_error()`、対称性のずれ `symmetry_defect()`、部分空間の逆条件数 `subspace_reciprocal_condition()`（$E U_1$ の 1 ノルムの逆条件数の推定と $U_1$ の最小特異値の小さい方で、0 から 1 の値）、閉ループを確かめた場合の安定余裕 `stability_margin()` を合わせて解を判定する。
固有値 $\lambda = \alpha/\beta$ の安定余裕は、連続では $-\operatorname{Re}(\alpha) / \max(\lvert\alpha\rvert, \lvert\beta\rvert)$、離散では $(\lvert\beta\rvert - \lvert\alpha\rvert) / \max(\lvert\alpha\rvert, \lvert\beta\rvert)$ で、レポートはその最小値である。
どちらも $-1$ から $1$ の値で、正なら安定であり、無限大の固有値（$\beta = 0$）は $-1$ になる。
作業量 `work()` は、準備を除き、解の復元・残差の検証・任意の閉ループの検証の各段階と、その中の入れ子の反復を数えた値である。

次のセルはスカラーの CARE $2ax - (b^2/r)x^2 + q = 0$（$b = 1$）を閉ループの検証つきの `RiccatiPlan` で解き、安定化解 $x = (r/b^2)\,(a + \sqrt{a^2 + qb^2/r})$、ゲイン $K = bx/r$、閉ループの極 $a - bK = -\sqrt{a^2 + qb^2/r}$ と比べる。
一つ目の表は計算値・閉じた形・相対差（閉じた形が 0 の量では「-」）を、二つ目の表は終了理由と診断を示し、判定は受理されたかを示す。

```rust
//| id: linalg-riccati-scalar
//| ref: linalg-riccati-scalar
//| title: スカラーの代数 Riccati 方程式と閉じた形
//| run: reactive
//| uses: [linalg-matrix-equation-termination]
//| crates: [scioxide-linalg]
//| inputs:
//|   a: {"type":"range","label":"状態の係数 a [-]","description":"a > 0 で開ループは不安定。","min":-5,"max":5,"step":0.5,"value":1}
//|   q: {"type":"range","label":"状態の重み q [-]","description":"q = 0 かつ a > 0 でも安定化解は存在する。","min":0,"max":10,"step":0.5,"value":1}
//|   r: {"type":"range","label":"入力の重み r [-]","description":"大きいほど入力を抑える。","min":0.1,"max":10,"step":0.1,"value":1}
//| cases:
//|   - {"id":"zero-state-cost","label":"q = 0","description":"Q > 0 でないので行列束の QZ から解き、閉ループの極は −a に移る。","inputs":{"q":0}}
//|   - {"id":"unstable-plant","label":"a = 5","description":"強く不安定な系では大きなゲインが要る。","inputs":{"a":5}}
//|   - {"id":"cheap-control","label":"r = 0.1","description":"入力の重みが小さいとゲインが増え、極が左へ移る。","inputs":{"r":0.1}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"riccati","path":"/rows/0/1","approx":{"value":2.414213562373095,"rtol":1e-12}}
//|       - {"artifact":"riccati","path":"/rows/2/1","approx":{"value":-1.4142135623730951,"rtol":1e-12}}
//|       - {"artifact":"diagnostics","path":"/rows/0/0","equals":"Accepted"}
//|       - {"artifact":"diagnostics","path":"/rows/0/2","approx":{"value":1.0,"atol":1e-12}}
//|       - {"path":"/outputs/2/state","equals":"satisfied"}
//|   - case: zero-state-cost
//|     expect:
//|       - {"artifact":"riccati","path":"/rows/0/1","approx":{"value":2.0,"rtol":1e-10}}
//|       - {"artifact":"riccati","path":"/rows/2/1","approx":{"value":-1.0,"rtol":1e-10}}
//|       - {"path":"/outputs/2/state","equals":"satisfied"}
//|   - case: unstable-plant
//|     expect:
//|       - {"artifact":"riccati","path":"/rows/1/1","approx":{"value":10.099019513592784,"rtol":1e-12}}
//|   - case: cheap-control
//|     expect:
//|       - {"artifact":"riccati","path":"/rows/2/1","approx":{"value":-3.3166247903554,"rtol":1e-12}}
use scioxide_linalg::{
    Estimation, Matrix, RiccatiKind, RiccatiOptions, RiccatiPlan, RiccatiProblem,
};

let one = |v: f64| Matrix::from_rows(&[[v]]).map_err(|e| e.to_string());
let (am, bm, qm, rm) = (one(a)?, one(1.0)?, one(q)?, one(r)?);
let problem = RiccatiProblem {
    a: am.view(),
    b: bm.view(),
    q: qm.view(),
    r: rm.view(),
    e: None,
    s: None,
};
let options = RiccatiOptions::new().with_closed_loop_verification(Estimation::Estimate);
let plan =
    RiccatiPlan::new(problem, RiccatiKind::Continuous, options).map_err(|e| e.to_string())?;
let result = plan.solve().map_err(|e| e.to_string())?;
let report = result.report();
// 閉じた形（b = 1）：x = r(a + √(a² + q/r))、K = x/r、極 a − K = −√(a² + q/r)。
let root = (a * a + q / r).sqrt();
let (x_exact, k_exact) = (r * (a + root), a + root);
// 拒否された解とゲインは出力に反映されないので、計算値と相対差は空になる。
let x = result.solution().map(|x| x.as_slice()[0]);
let k = result.gain().map(|k| k.as_slice()[0]);
// 閉じた形が 0 の量（q = 0、a < 0 の x と K）では相対差を定義しない。
let relative = |value: Option<f64>, exact: f64| {
    value
        .filter(|_| exact != 0.0)
        .map(|v| (v - exact).abs() / exact.abs())
};
let pole = k.map(|k| a - k);
let rows = vec![
    ("x", x, x_exact, relative(x, x_exact)),
    ("K", k, k_exact, relative(k, k_exact)),
    ("閉ループの極 a − K", pole, -root, relative(pole, -root)),
];
let digits12 = serde_json::json!({ "significantDigits": 12 });
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let columns = serde_json::json!([
    { "key": "0", "label": "量" },
    {
        "key": "1",

    },
    { "key": "2", "label": "閉じた形 [-]", "type": "number", "format": digits12 },
    { "key": "3", "label": "相対差 [-]", "type": "number", "format": sci2, "nullText": "-" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "riccati" })
);
let termination = report.termination();
let diagnostics = vec![(
    direct_termination_name(termination),
    report.backward_error(),
    report.subspace_reciprocal_condition(),
    report.stability_margin(),
    plan.state_scaling()[0],
)];
let digits3 = serde_json::json!({ "significantDigits": 3 });
let digits4 = serde_json::json!({ "significantDigits": 4 });
let diagnostic_columns = serde_json::json!([
    { "key": "0", "label": "終了理由" },
    { "key": "1", "label": "後退誤差 [-]", "type": "number", "format": sci2 },
    { "key": "2", "label": "部分空間の逆条件数 [-]", "type": "number", "format": digits3 },
    {
        "key": "3",
        "label": "安定余裕 [-]",
        "type": "number",
        "format": digits4,
        "nullText": "なし"
    },
    { "key": "4", "label": "状態の尺度 d [-]", "type": "number", "format": digits4 }
]);

    diagnostic_columns,
    diagnostics,
    metadata = serde_json::json!({ "id": "diagnostics" })
);
let outcome = if termination.is_success() {
    Outcome::satisfied("安定化解が残差と閉ループの検証で受理された")
} else {
    Outcome::failed("解が残差か閉ループの検証で拒否された")
};
let mut outcome = outcome
    .status(direct_termination_name(termination))
    .diagnostic("後退誤差", report.backward_error(), None);
if let Some(margin) = report.stability_margin() {
    outcome = outcome.diagnostic("安定余裕", margin, None);
}
emit_outcome!(outcome);
```

既定の $a = q = r = 1$ では $x = 1 + \sqrt{2}$、$K = 1 + \sqrt{2}$、閉ループの極 $-\sqrt{2}$ が閉じた形と丸め誤差の範囲（相対差 $1.6 \times 10^{-16}$ 以下）で一致し、終了理由は `Accepted` である。
この入力は二次方程式の根の経路を通るので、部分空間の逆条件数は 1、状態の尺度は 1 と示される。
$q = 0$ にすると $Q > 0$ でないので QZ の経路になり、安定化解 $x = 2ar = 2$ が求まって閉ループの極は $-a = -1$ に移り、部分空間の逆条件数の推定は 0.447 になる。
$a = 5$（不安定）では $x = K = 10.099$、極は $-5.099$ で、$a = -5$（安定）では $x = K = 0.099$ と制御はわずかしか働かない。
$r$ を小さくすると入力の計算コストが下がり、ゲインが大きくなって閉ループの極が左へ移る（$r = 0.1$ で $-3.317$、$r = 10$ で $-1.049$）。
これらの入力では後退誤差は 0 と示され、極の絶対値が 1 以上なので安定余裕は 1 になる。
$a = 0$ かつ $q = 0$ では、$(Q, A)$ が虚軸の上の 0 に不可観測な固有値を持つので安定化解は存在しない。
二つの根が $x = 0$ で重なって閉ループの極が 0（虚軸の上）になり、準備の段階で `NumericalInstability`（`IllConditioned`）のエラーになり、セルはエラーの文を表示する。

## まとめ

Sylvester 方程式は $\lambda_i + s\,\mu_j \ne 0$ のときに一意に解け、Bartels–Stewart 法は二つの Schur 分解と三角の代入で、準備 $O(m^3 + n^3)$、右辺ごとに $O(m^2 n + mn^2)$ で解く。
解の感度は分離 $\operatorname{sep}$ で決まり、Lyapunov 方程式では安定の境界に近づくほど分離が小さく解が大きくなるので、レポートにある分離の推定で確かめる。
代数 Riccati 方程式は拡大行列束の並べ替えた QZ から安定な収縮部分空間を取り出して解き、可安定性などの存在条件は Plan が確かめないので呼び出し側の仮定になる。
一度だけ解くならワンショット関数（`solve_sylvester`、`solve_lyapunov`、`solve_riccati`）で足り、拒否はエラーになる。
`solve_riccati` は閉ループの安定性も確かめる。
Plan の `solve` は元の方程式の残差を検証し、拒否した候補の解は出力に反映しないので、`Ok` を受理とみなさず `termination()` と後退誤差・分離・安定余裕で解を判定する。
