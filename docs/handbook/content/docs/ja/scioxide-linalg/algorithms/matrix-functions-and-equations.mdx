線形の常微分方程式 $\dot x = Ax$ の解 $x(t) = e^{tA}x(0)$、量子力学の時間発展 $e^{-iHt}$、制御の離散化、マルコフ連鎖の連続時間の遷移確率は、行列の指数関数で書ける。
対数・平方根・べきなどの行列関数も、行列の補間や回転の平均、方程式の変換に使われる。
このページは行列関数の定義、`scioxide-linalg` が使う計アルゴリズムと呼び出し方、関数の感度を表す Fréchet 微分と条件数、疎行列のべきと関数を説明する。
Sylvester・Lyapunov・Riccati 方程式は[次のページ](../matrix-equations/)で扱う。

## 定義と主値

スカラー関数 $f$ を行列に拡張するには、$f$ が収束円の内側に $A$ の固有値をすべて含むべき級数 $\sum c_k z^k$ で表せるなら $f(A) = \sum c_k A^k$ とし、$A = V \Lambda V^{-1}$ と対角化できるなら $f(A) = V f(\Lambda) V^{-1}$ とする。
両方が使える場合、二つは同じ行列を与える。
対角化できない場合は Jordan 標準形 $A = Z J Z^{-1}$ で $f(A) = Z f(J) Z^{-1}$ と定義し、$2 \times 2$ の $J = \lambda I + \nu N$（$N = \begin{bmatrix} 0 & 1 \\ 0 & 0 \end{bmatrix}$、$N^2 = 0$）では Taylor 展開の 2 次以上の項が消えて

$$
f(J) = f(\lambda) I + \nu f'(\lambda) N
$$

となる。
$V$ の条件数が大きいと $V f(\Lambda) V^{-1}$ の計算は不安定なので、実際のアルゴリズムは固有ベクトルを使わない。

対数・平方根・非整数のべきは多価関数で、`scioxide-linalg` は主値を返す。
主値の対数は固有値の虚部が $(-\pi, \pi)$ に入るもので、$A$ の固有値が閉じた非正の実軸 $(-\infty, 0]$ にあると定義されない。
主値の平方根は固有値の実部が非負のもので、負の実固有値 $\lambda$ にはスカラーの主値 $i\sqrt{\lvert\lambda\rvert}$ を対応させる。
虚部の 0 は $+0$ とみなすので、IEEE の `csqrt` が $-i\sqrt{\lvert x \rvert}$ を返す $x - 0i$ にも $i\sqrt{\lvert x \rvert}$ を対応させる。
実行列の関数値は複素数になりうるので、実数の出力に書く場合は虚部が許容誤差以下のときだけ受け付け、捨てた虚部の大きさを返す。

## 計アルゴリズム

| 関数 | `MatrixFunction` | アルゴリズム |
|---|---|---|
| 指数 | `Exp` | $A$ そのものに次数 3、5、7、9、13 の Padé 近似とスケーリング・二乗（Al-Mohy–Higham 2009 のアルゴリズム 6.1）。Schur 分解を使わない |
| 対数 | `Log` | Schur 形（実行列では実 Schur 形）の上で $\lVert T - I \rVert_1 \le 1/4$ まで平方根をとる逆スケーリング・二乗と、8 点（`f32` では 4 点）の Gauss–Legendre 求積で評価する $\log(I + X)$ の Padé 近似。対角ブロックは固有値から直接求める |
| 平方根 | `Sqrt` | Schur 形の上で上三角の平方根の成分を対角から順に決める漸化式を、$2 \times 2$ ブロックを分けない 32 次の区画でブロック化する。実行列で負の実固有値がなければ実 Schur 形を使う |
| べき | `Power(p)` | 整数の $p$ は Schur 因子の二分累乗（負なら先に逆行列）で、分枝の切れ目を持たない。$\lvert p \rvert \ge 2^{62}$ の整数は $p = m 2^k$（$\lvert m \rvert < 2^{62}$）と分けて $A^m$ を $k$ 回二乗する。それ以外は $\exp(p \log A)$ |
| 符号 | `Sign` | 複素 Schur 形の上の Parlett の漸化式（$\operatorname{sign}(T)^2 = I$ を使う）。虚軸の上の固有値は許さない |
| 三角・双曲線関数 | `Sin`、`Cos`、`Tan`、`Sinh`、`Cosh`、`Tanh` | 複素 Schur 形の上の Schur–Parlett 法（Davies–Higham）と厳密な Taylor 係数。`Tan` と `Tanh` は三角の $\cos(T)$、$\cosh(T)$ の対角に厳密な 0 があると `Singular` |
| 任意の解析関数 | `Analytic(&f)` | Schur–Parlett 法。$f$ は `AnalyticMatrixFunction`（収束半径・Taylor 係数・剰余の上界）を実装した `Sync` な値で与える |

指数のスケーリング・二乗は $e^{z}$ の $[m/m]$ 型の Padé 近似 $r_m$ を $2^{-s}A$ に使い、$e^{A} \approx r_m(2^{-s}A)^{2^s}$ を $s$ 回の二乗で求める。
厳密な計算では、$\log$ が定義される範囲で次が成り立つ。

$$
r_m(2^{-s}A)^{2^s} = e^{A + \Delta A}, \qquad
\Delta A = 2^{s} h_{2m+1}(2^{-s}A), \qquad
h_{2m+1}(X) = \log\bigl(e^{-X} r_m(X)\bigr) = \sum_{k \ge 2m+1} c_k X^k
$$

つまり近似の誤差は $A$ の後退誤差 $\Delta A$ として表せる。
Al-Mohy–Higham のアルゴリズムは、この $\lVert \Delta A \rVert_1 / \lVert A \rVert_1$ の上界が単位丸め $u$（`f64` では $2^{-53}$）以下になるように、次数 $m \in \{3, 5, 7, 9, 13\}$ とスケーリングの回数 $s$ を $d_k = \lVert A^k \rVert_1^{1/k}$ から選ぶ。
非正規な行列では $d_k$ が $\lVert A \rVert_1$ よりずっと小さいことがあり、$\lVert A \rVert_1$ で選ぶ場合の余分なスケーリング（二乗が増えて丸め誤差がたまる）を避けられる。
`scioxide-linalg` は $d_k$ を推定せず、計算した $A$ のべきの 1 ノルムから求める。
この後退誤差は Padé 近似の打ち切りの分で、二乗の段階の丸め誤差は含まない。

上三角の $T$ では $F = f(T)$ も上三角で $FT = TF$ を満たすので、対角 $f_{ii} = f(t_{ii})$ から上の成分を次の Parlett の漸化式で順に決められる。

$$
f_{ij} = t_{ij} \frac{f_{ii} - f_{jj}}{t_{ii} - t_{jj}} + \sum_{k=i+1}^{j-1} \frac{f_{ik} t_{kj} - t_{ik} f_{kj}}{t_{ii} - t_{jj}}, \qquad i < j
$$

近い固有値の組では分母 $t_{ii} - t_{jj}$ が小さく、誤差が大きく拡大される。
そこで Schur–Parlett 法は Schur 形の対角を固有値の距離 0.1 以下でつながるものの塊に分けて並べ替え、各塊では平均の固有値のまわりの Taylor 級数を、塊の間では上の漸化式をブロックにした Sylvester 方程式を解いて $f(T)$ を組み立てる。
組み込みの関数の Taylor 級数は、剰余の上界が現在の値の $\varepsilon_{\mathrm{mach}}$ 倍（1 ノルム）以下になったところで止める。
三角・双曲線関数では、塊 $T_b = cI + D + N$（$D$ は対角、$N$ は狭義上三角、次数 $m$）で $s$ 項までとった剰余の上界を

```text
e^(γ+μ) Σ_{k<m} (νᵏ / k!) μ^((s−k)₊) / ((s−k)₊)!
```

とする（Davies と Higham、2003、2 節）。
ここで $\mu = \max_i \lvert d_i \rvert$、$\nu = \lVert N \rVert_1$、$(x)_+ = \max(x, 0)$ で、$\gamma$ は $\sin$・$\cos$・$\tan$ では $\lvert \operatorname{Im} c \rvert$、双曲線関数では $\lvert \operatorname{Re} c \rvert$ である。
非正規性 $\nu$ は $m$ 未満のべきでしか入らないので、非正規な小さな塊で $\nu$ が大きくても、項はおよそ $m$ 個増えるだけで級数は止まる。
任意の解析関数の係数や剰余の上界は呼び出し側の数学的な仮定で、ソルバーは正則性を検証せず、誤った値を与えると誤った結果になる。

実行列は直交行列 $Q$ で準上三角の実 Schur 形 $Q^{\mathsf T} A Q = T$ に変換でき、$T$ の対角には実固有値の $1 \times 1$ ブロックと、共役な複素固有値の対の $2 \times 2$ ブロックが並ぶ。
主値の対数は実行列 $A$ の固有値が $(-\infty, 0]$ にないとき、主値の平方根は負の実固有値がないときに実行列になるので、表のとおり実 Schur 形の上で実数の演算だけで求める。
ほかの関数は複素 Schur 形 $A = Q T Q^{\mathsf H}$（$Q$ はユニタリ、$T$ は上三角）の上で計算し、実数の出力に書くときは小さな虚部を捨てる。

## ワンショット関数と Plan

呼び出しの形の名前（ワンショット関数・標準形式・出力先を指定する API・Plan など）は[作業領域・実行コンテキスト・試行記録](oxref:linalg-execution-forms)で定義する。
ワンショット関数 `matrix_function(&a, function)` は $f(A)$ を $A$ と同じスカラー型の新しい行列で返す。
内部で下の Plan を既定の設定で作り、`ExecutionContext::sequential_native()` で逐次に評価する。
実行列の $f(A)$ が複素数になる場合（負の実固有値を持つ行列の平方根など）は、引数 `a` の `DomainError` になるので、複素数の行列で呼ぶか、Plan で複素数の出力に書く。
計算量はどの組み込みの関数も $O(n^3)$ である。

Plan `MatrixFunctionPlan::new(&a, function, &options)` は関数を固定して準備を行い、同じ $A$ で値・Fréchet 微分・条件数を繰り返し求めるときに使う（`build(&a, function, &options, cx)` は準備の Schur 分解の反復をコンテキスト `cx` の入れ子の処理として数える）。
指数の Plan は $A$ を保持するだけで固有値の計算をせず、ほかの Plan は前の節の実 Schur 形か複素 Schur 形を一度 $O(n^3)$ で求めて保持する。
分枝の切れ目にスペクトルがある場合（対数と非整数のべきでは $(-\infty, 0]$、符号では虚軸）は、この準備の段階で引数 `self` の `DomainError` になる。
`evaluate_into(out, &mut ws, cx)` は値を $n \times n$ の出力に書き、出力は実数でも複素数でもよい。
作業領域は `plan.workspace(&MatrixFunctionWorkspaceRequest::Evaluate)` などで作る複素数の `LinalgWorkspace` で、評価では $n$ 次、Fréchet 微分と条件数では $2n$ 次の行列およそ 15 個分を持ち、`Condition` 用の作業領域は他の二つ（`Evaluate`、`Frechet`）にも使える。

`MatrixFunctionOptions` は数値の設定 `MatrixFunctionSettings`（`with_function_settings`）と実行の制御 `LinalgExecutionOptions`（`with_execution_options`）を合成した値である。
設定の既定は許容誤差 $\tau_{\mathrm{abs}} = \tau_{\mathrm{rel}} = \sqrt{\varepsilon_{\mathrm{mach}}}$（解析関数の剰余と、実数の出力で捨てる虚部の判定に使う）と Taylor 級数の最大次数 256（`with_series_limit`）である。
作業量の上限は、反復の上限を指定しなければ 1 回の評価あたり 100 万単位で、1 単位は行列の積・三角の求解・平方根の一段・Taylor 級数の 1 項のようなブロック演算 1 回であり、上限に達すると `ConvergenceFailure` になる。
同じ上限は `MatrixFunctionPlan` の準備で行う Schur 分解の QR 反復にも掛かる。
この反復は指定しなければ $30\max(n, 1)$ 回まで許され、通常は固有値ひとつあたり 2 回ほどかかるので、それより小さい上限では準備が失敗する。
レポート `MatrixFunctionReport` は作業量 `work()`、スペクトルから分枝の切れ目までの距離 `branch_distance()`（対数・平方根・非整数のべきでは $(-\infty, 0]$ まで、符号では虚軸まで、それ以外は `None`）、実数の出力で捨てた虚部の最大 `imaginary_defect()`、出力の成分ごとの 1 ノルム `output_norm()`（範囲を超えうるので `Scaled` の数）を返す。

次のセルは $A = \lambda I + \nu N$（$\lambda > 0$）の指数・対数・平方根を Plan の出力先を指定する API で計算し、上の公式 $f(J) = f(\lambda) I + \nu f'(\lambda) N$ と比べる。
公式の $f(\lambda)$ と $f'(\lambda)$ は `f64` の標準関数で計算した参照値である。
表の差は、成分が 0 でなければ相対差、0 の成分では絶対差で、その最大を示す。
二つ目の表はワンショット関数 `matrix_function` で計算した $\log A$ に指数を作用させ、$A$ に戻るかを確かめる。

```rust
//| id: linalg-matrix-log-jordan
//| ref: linalg-matrix-log-jordan
//| title: Jordan ブロックの指数・対数・平方根
//| run: reactive
//| crates: [scioxide-core, scioxide-linalg]
//| inputs:
//|   lambda: {"type":"range","label":"固有値 λ [-]","description":"A = λI + νN の重複固有値。","min":0.1,"max":10,"step":0.1,"value":2}
//|   nu: {"type":"range","label":"上対角 ν [-]","description":"非対角の大きさ。0 なら A は対角。","min":0,"max":10,"step":0.5,"value":1}
//| cases:
//|   - {"id":"near-cut","label":"λ = 0.1","description":"固有値が分枝の切れ目に近く、log A の非対角が ν/λ = 10 に増える。","inputs":{"lambda":0.1}}
//|   - {"id":"diagonal","label":"ν = 0","description":"A が対角になり、非対角の成分は 0 になる。","inputs":{"nu":0}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"jordan","path":"/rows/0/2","approx":{"value":7.38905609893065,"rtol":1e-14}}
//|       - {"artifact":"jordan","path":"/rows/0/3","range":{"max":1e-14}}
//|       - {"artifact":"jordan","path":"/rows/1/3","range":{"max":1e-14}}
//|       - {"artifact":"jordan","path":"/rows/1/5","approx":{"value":2.0,"atol":1e-12}}
//|       - {"artifact":"jordan","path":"/rows/2/3","range":{"max":1e-14}}
//|       - {"artifact":"round-trip","path":"/rows/0/0","range":{"max":1e-14}}
//|   - case: near-cut
//|     expect:
//|       - {"artifact":"jordan","path":"/rows/1/2","approx":{"value":10.0,"rtol":1e-14}}
//|       - {"artifact":"jordan","path":"/rows/1/3","range":{"max":1e-13}}
//|       - {"artifact":"jordan","path":"/rows/1/5","approx":{"value":0.1,"atol":1e-12}}
//|   - case: diagonal
//|     expect:
//|       - {"artifact":"jordan","path":"/rows/0/1","approx":{"value":0.0,"atol":1e-15}}
//|       - {"artifact":"jordan","path":"/rows/2/3","range":{"max":1e-14}}
use scioxide_core::ExecutionContext;
use scioxide_linalg::{
    Matrix, MatrixFunction, MatrixFunctionOptions, MatrixFunctionPlan,
    MatrixFunctionWorkspaceRequest, matrix_function,
};

let a = Matrix::from_rows(&[[lambda, nu], [0.0, lambda]]).map_err(|e| e.to_string())?;
let options = MatrixFunctionOptions::new();
// f(J) = f(λ) I + ν f'(λ) N の f(λ) と f'(λ)（参照値。f64 の標準関数）。
let functions = [
    ("exp", MatrixFunction::Exp, lambda.exp(), lambda.exp()),
    ("log", MatrixFunction::Log, lambda.ln(), 1.0 / lambda),
    (
        "sqrt",
        MatrixFunction::Sqrt,
        lambda.sqrt(),
        0.5 / lambda.sqrt(),
    ),
];
let mut rows = Vec::new();
for (name, function, value, derivative) in functions {
    let plan = MatrixFunctionPlan::new(&a, function, &options).map_err(|e| e.to_string())?;
    let request = MatrixFunctionWorkspaceRequest::Evaluate;
    let mut workspace = plan.workspace(&request).map_err(|e| e.to_string())?;
    let mut out = Matrix::<f64>::zeros(2, 2).map_err(|e| e.to_string())?;
    let context = ExecutionContext::sequential_native();
    let report = plan
        .evaluate_into(out.view_mut(), &mut workspace, context)
        .map_err(|e| e.to_string())?;
    let exact = [value, nu * derivative, 0.0, value];
    // 0 でない成分は相対差、0 の成分は絶対差。
    let error = out
        .as_slice()
        .iter()
        .zip(exact)
        .fold(0.0_f64, |acc, (p, q)| {
            acc.max(if q == 0.0 {
                p.abs()
            } else {
                (p - q).abs() / q.abs()
            })
        });
    let off_diagonal = out.as_slice()[1];
    rows.push((
        name,
        off_diagonal,
        exact[1],
        error,
        report.work(),
        report.branch_distance(),
    ));
}
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let digits12 = serde_json::json!({ "significantDigits": 12 });
let columns = serde_json::json!([
    { "key": "0", "label": "f" },
    { "key": "1", "label": "f(A) の (0,1) 成分 [-]", "type": "number", "format": digits12 },
    { "key": "2", "label": "ν f′(λ)（公式）[-]", "type": "number", "format": digits12 },
    { "key": "3", "label": "成分の差の最大 [-]", "type": "number", "format": sci2 },
    { "key": "4", "label": "作業量 [単位]", "type": "integer" },
    {
        "key": "5",
        "label": "分枝までの距離 [-]",
        "type": "number",
        "format": sci2,
        "nullText": "なし"
    }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "jordan" })
);
// ワンショット関数で exp(log A) を求め、A との差を測る。
let log_a = matrix_function(&a, MatrixFunction::Log).map_err(|e| e.to_string())?;
let back = matrix_function(&log_a, MatrixFunction::Exp).map_err(|e| e.to_string())?;
let round_trip = back
    .as_slice()
    .iter()
    .zip(a.as_slice())
    .fold(0.0_f64, |acc, (p, q)| acc.max((p - q).abs()));
let trip_columns = serde_json::json!([
    { "key": "0", "label": "exp(log A) と A の差の最大 [-]", "type": "number", "format": sci2 }
]);
emit_table_with_columns!(
    trip_columns,
    vec![(round_trip,)],
    metadata = serde_json::json!({ "id": "round-trip" })
);
```

既定の $\lambda = 2$、$\nu = 1$ では、三つの関数とも全成分が公式と $2.4 \times 10^{-16}$ 以下の差で一致し、$\exp(\log A)$ は $A$ に一致する。
$\nu \ne 0$ の $A$ は対角化できないので $V f(\Lambda) V^{-1}$ では計算できないが、固有ベクトルを使わないアルゴリズム（指数は $A$ そのもの、対数と平方根は Schur 形）では問題にならない。
対数と平方根の分枝までの距離は固有値 $\lambda$ そのもので、指数には分枝がないので「なし」になる。
$\lambda = 0.1$ では分枝までの距離が 0.1 に縮み、$\log A$ の非対角が $\nu / \lambda = 10$ に増えるが、差は $2.0 \times 10^{-16}$ の程度のまま変わらない。
$\nu = 10$ でも差は変わらず、$\exp(\log A)$ と $A$ の差は $1.2 \times 10^{-14}$ である。
作業量は関数と $\lVert A \rVert$ によって変わり、指数では $\lVert A \rVert$ が大きいほど Padé 近似の次数とスケーリングの回数が増えるので、$\nu = 1$ のまま $\lambda = 0.1, 2, 10$ とすると 17、37、39 単位と大きくなる。
平方根はどの入力でも 4 単位である。

## Fréchet 微分と条件数

$f(A + E) = f(A) + L_f(A, E) + o(\lVert E \rVert)$ を満たす線形写像 $E \mapsto L_f(A, E)$ を Fréchet 微分といい、$f$ が $A$ の固有値を含む開集合で解析的なら存在する。
指数では $L_{\exp}(A, E) = \int_0^1 e^{sA} E\, e^{(1-s)A}\, ds$ なので、$A$ と $E$ が可換でなければ一般に $L_{\exp}(A, E) \ne e^{A} E$ である。
`frechet_into(&e, out, ws, cx)` は、ブロック行列の恒等式

$$
f\left( \begin{bmatrix} A & E \\ 0 & A \end{bmatrix} \right) = \begin{bmatrix} f(A) & L_f(A, E) \\ 0 & f(A) \end{bmatrix}
$$

の右上のブロックとして $L_f(A, E)$ を求め、計算コストは $f(A)$ の評価のおよそ 8 倍である。
方向 $E$ は $A$ の大きさに合わせて 2 のべきで尺度化してから評価し、結果を戻すので、結果の成分が非正規化数でない限り尺度化は丸め誤差を加えない。
平方根は $(-\infty, 0]$ の固有値で微分できないので、その場合は引数 `self` の `DomainError` になる。

成分ごとの 1 ノルム $\lVert X \rVert = \sum_{ij} \lvert x_{ij} \rvert$ で測った条件数は

$$
\operatorname{cond}_{\mathrm{abs}}(f, A) = \max_{E \ne 0} \frac{\lVert L_f(A, E) \rVert}{\lVert E \rVert}, \qquad
\operatorname{cond}_{\mathrm{rel}}(f, A) = \frac{\operatorname{cond}_{\mathrm{abs}}(f, A) \lVert A \rVert}{\lVert f(A) \rVert}
$$

で、相対条件数は、入力の小さな相対摂動が出力の相対誤差に一次の範囲で最大何倍に拡大されるかを表す。
`condition_into(out, ws, cx)` は $f(A)$ を出力に書き、$n^2 \times n^2$ の微分の行列を作らずに、Fréchet 微分とその随伴を高々 17 回作用させる Hager–Higham の 1 ノルム推定で二つの条件数を推定する。
結果 `MatrixFunctionConditionReport` の `absolute()` は丸め誤差を除いて $\operatorname{cond}_{\mathrm{abs}}$ の下界で、$n \le 2$ では厳密に一致し、`relative()` は $f(A) = 0$ なら `None` である。
下界なので、真の条件数を小さめに見積もることはあっても、証明された上界にはならない。
随伴の微分には実の Taylor 係数が要るので、`condition_into` は組み込みの関数だけを扱い、`Analytic` の関数には `InvalidInput` を返す。

次のセルは非正規な $A = \begin{bmatrix} -1 & \alpha \\ 0 & -2 \end{bmatrix}$ と方向 $E = \begin{bmatrix} 0 & 0 \\ 1 & 0 \end{bmatrix}$ について、`frechet_into` の値を中心差分 $(e^{A + hE} - e^{A - hE}) / (2h)$（$h = 10^{-1}, \dots, 10^{-13}$）と比べる。
中心差分の行列指数はワンショット関数 `matrix_function` で求める。
中心差分の誤差は打ち切りの $O(h^2)$ と丸めの $O(\varepsilon_{\mathrm{mach}} / h)$ の和なので、$h \approx \varepsilon_{\mathrm{mach}}^{1/3} \approx 6 \times 10^{-6}$ の近くで最小になると予想される。
表は $L(A, E)$ の $(1, 0)$ 成分、可換と仮定した誤った式 $e^{A}E$ との差、中心差分の最小誤差とそのときの $h$、条件数の推定を示し、グラフは $h$ ごとの誤差を両対数で描く。

## 疎行列のべきと関数

疎行列 $A$ の $A^k$ や $f(A)$ は一般に疎でなくなる。
`SparsePowerPlan::new(a.view(), k, &options)` は、二分累乗の記号的な積で $A^k$ と途中の行列の非零パターンを準備の段階で決め、値は使わない（`a` のパターンだけを読み、重複した成分は合わせる）。
最初の因子から始めるので、$k > 0$ の積の回数は $\lfloor \log_2 k \rfloor + \operatorname{popcount}(k) - 1$ で、$k = 0$ は単位行列、$k = 1$ は $A$ の写しになる。
負のべきは $A$ を疎 LU 分解して $A^{-1}$ を列ごとに求め、$A^{-k} = (A^{-1})^k$ とする。
$A^{-1}$ は $A$ のグラフの弱連結成分（連結ブロック）の外では 0 だが中では密になりうるので、そのパターンは連結ブロックを全成分で持ち、LU の因子の成分数もこの数で抑える。
設定 `SparsePowerOptions` は成分数の上限 `with_max_entries`（既定は上限なし）と、実行の制御 `with_execution_options` だけを持つ。
`with_execution_options` で決めるバイト数の上限は途中の積と LU を含む作業領域全体を、反復の上限は積と LU の処理を抑える。
疎行列の積の並列度は `Sequential` で 1、`Auto` で最大 64、`Parallel(n)` で $\min(n, 64)$ で、結果は並列度によらない。

`SparseFunctionPlan::new(a.view(), function, &options)` は、$A$ の連結ブロックごとに密行列として関数を計算し、ブロックの外は厳密に 0 とする。
各ブロックのアルゴリズムは密行列の Plan と同じである。
出力パターンは各ブロックを全成分で持ち、数値的に 0 になった値も明示的な 0 として残す。
準備はブロックを見つけて出力パターンを作るだけで、格納する成分数に比例する時間で終わり、次数 $b$ のブロックの評価は $O(b^3)$ なので、ブロックが小さい行列に向く。
設定 `SparseFunctionOptions` は成分数の上限 `with_max_entries`（既定は上限なし）、密行列と同じ数値の設定 `with_function_settings`、誤差の推定 `with_error_estimate`（既定 `Estimation::Skip`）、実行の制御 `with_execution_options` を持つ。
`with_error_estimate(Estimation::Estimate)` は、ブロック $A_b$ ごとの Fréchet 条件数から一次の前進誤差の目安 $\sum_b \operatorname{cond}_{\mathrm{abs}}(f, A_b) \lVert A_b \rVert \varepsilon_{\mathrm{mach}}$（$\lVert A_b \rVert$ は成分の絶対値の和）を返し、証明された上界ではない（`Analytic` の関数には使えない）。
実数の出力では結果が実数でなければならず、負の実固有値を持つ実行列の平方根は複素数の出力を `evaluate_into` で受け取る。

どちらの Plan も、入力・途中の行列・出力の成分数が `with_max_entries` を、作業領域が `LinalgExecutionOptions::with_byte_limit` のバイト数を超える場合は、準備の段階で数値計算の前に `ResourceLimit` で拒否する。
`evaluate(a.view())` は新しい出力と作業領域で値を計算して `SparseMaterialization`（CSR 行列 `value()` とレポート `report()`）を返し、`a` は準備と同じパターンでなければならない。
出力先を指定する API `evaluate_into(a.view(), &mut out, &mut ws, cx)` の出力は `create_output()` で作り、作業領域 `SparseMaterializationWorkspace` は `workspace(())` か、`workspace_requirements(())` が返す `SparseMaterializationRequirements` で事前確保する（作業領域は一つの Plan のパターンにだけ合う）。
レポート `SparseMaterializationReport` は出力パターンの成分数 `structural_fill()`、0 でない値の数 `nonzero_fill()`、途中の最大の成分数 `peak_intermediate_fill()`（入力を含む）、上限と比べた作業領域のバイト数 `admitted_workspace_bytes()`、作業量 `work()`（べきでは疎行列の積の回数で、負のべきでは $2n$ を足し、関数ではブロックの評価の作業単位）、任意の誤差推定 `estimated_error()` を返す。

次のセルは長さ $m$ の棒 $c$ 本の一次元の熱伝導を表す $A = -L$（$L$ は各棒の $\operatorname{tridiag}(-1, 2, -1)$ を対角に並べた $n = cm$ 次の行列）の $k$ 乗と指数 $e^{A}$ を、二つの Plan で求める。
棒どうしはつながっていないので、$A$ の連結ブロックは $c$ 個の $m \times m$ の三重対角行列である。
$A^k$ は各ブロックで半帯幅 $w = \min(k, m - 1)$ の帯行列になるので成分数は $c\,[m(2w + 1) - w(w + 1)]$、$e^{A}$ は各ブロックを埋めるので $c\,m^2$ と予想され、この予想と成分数の上限を比べる。
参照は $A^k$ では密行列の積の繰り返し（成分は整数で厳密）、$e^{A}$ では各ブロックの固有分解 $e^{A_b} = \sum_{l} e^{\mu_l} v_l v_l^{\mathsf T}$（$\mu_l = -2 + 2\cos\theta_l$、$(v_l)_p = \sqrt{2/(m+1)} \sin(p\theta_l)$、$\theta_l = l\pi/(m+1)$）による閉じた形で、`f64` の標準関数で計算する。
準備で拒否された計算は、表の「準備」の列に `ResourceLimit` と示し、レポートの列を空にする。

```rust
//| id: linalg-sparse-power
//| ref: linalg-sparse-power
//| title: 疎行列のべきと指数の充填と上限
//| run: reactive
//| crates: [scioxide-core, scioxide-linalg, scioxide-sparse]
//| inputs:
//|   block_order: {"type":"range","label":"棒の格子点の数 m","description":"連結ブロック 1 個の次数。","min":5,"max":50,"step":5,"value":25}
//|   blocks: {"type":"range","label":"棒の数 c","description":"つながっていない連結ブロックの数。n = cm。","min":1,"max":4,"step":1,"value":2}
//|   exponent: {"type":"range","label":"べき k","description":"A^k を求める。","min":1,"max":10,"step":1,"value":4}
//|   max_entries: {"type":"range","label":"成分数の上限","description":"入力・途中の行列・出力の成分数の上限。","min":100,"max":6000,"step":100,"value":2000}
//| cases:
//|   - {"id":"one-rod","label":"c = 1, m = 50","description":"一本の棒では e^A が 2500 成分の密行列になり、上限 2000 で拒否される。","inputs":{"blocks":1,"block_order":50}}
//|   - {"id":"dense-blocks","label":"m = 5, k = 10","description":"k ≥ m − 1 では A^k も各ブロックを埋める。","inputs":{"block_order":5,"exponent":10}}
//|   - {"id":"tight-limit","label":"上限 300","description":"A^k の予想 410 成分も上限を超え、どちらも準備で拒否される。","inputs":{"max_entries":300}}

//|   - case: default
//|     expect:
//|       - {"artifact":"fill","path":"/rows/0/1","equals":410}

//|       - {"artifact":"fill","path":"/rows/0/5","equals":2}
//|       - {"artifact":"fill","path":"/rows/0/7","range":{"max":0}}
//|       - {"artifact":"fill","path":"/rows/1/3","equals":1250}

//|       - {"artifact":"fill","path":"/rows/0/7","range":{"max":0}}
//|   - case: dense-blocks
//|     expect:
//|       - {"artifact":"fill","path":"/rows/0/3","equals":50}
//|       - {"artifact":"fill","path":"/rows/1/3","equals":50}
//|       - {"artifact":"fill","path":"/rows/1/7","range":{"max":1e-14}}
//|   - case: tight-limit
//|     expect:
//|       - {"artifact":"fill","path":"/rows/0/1","range":{"min":301}}
//|       - {"artifact":"fill","path":"/rows/0/2","equals":"ResourceLimit"}
//|       - {"artifact":"fill","path":"/rows/1/2","equals":"ResourceLimit"}
use scioxide_core::SciOxideErrorKind;
use scioxide_linalg::{
    Estimation, Matrix, MatrixFunction, SparseFunctionOptions, SparseFunctionPlan,
    SparsePowerOptions, SparsePowerPlan,
};
use scioxide_sparse::{ExplicitZeroPolicy, sparse_diagonals};

let (m, c, k) = (
    block_order.round() as usize,
    blocks.round() as usize,
    exponent.round() as usize,
);
let n = c * m;
// A = −L：対角 −2、隣接 1。棒の境目（i が m の倍数）をまたぐ成分は 0 にして落とす。
let off: Vec<f64> = (1..n).map(|i| if i % m == 0 { 0.0 } else { 1.0 }).collect();

    .and_then(|a| a.view().to_csr(ExplicitZeroPolicy::Drop))
    .map_err(|e| e.to_string())?;
let w = k.min(m - 1);

let dense = Matrix::from_csr(&a).map_err(|e| e.to_string())?;
let mut power = dense.clone();
for _ in 1..k {
    power = power.view().mul_mat(&dense).map_err(|e| e.to_string())?;
}

let heat = |i: usize, j: usize| -> f64 {
    if i / m != j / m {
        return 0.0;
    }
    let (p, q) = ((i % m + 1) as f64, (j % m + 1) as f64);
    let terms = (1..=m).map(|l| {
        let mode = (p * theta(l)).sin() * (q * theta(l)).sin();
        mode * (-2.0 + 2.0 * theta(l).cos()).exp()
    });
    2.0 / (m + 1) as f64 * terms.sum::<f64>()
};

    .map_err(|e| e.to_string())?;

    .with_max_entries(limit)
    .with_error_estimate(Estimation::Estimate);

    SparseFunctionPlan::new(a.view(), MatrixFunction::Exp, &function_options)
        .and_then(|p| p.evaluate(a.view())),
];
let names = ["A^k（SparsePowerPlan）", "e^A（SparseFunctionPlan）"];
let references = [&power, &exponential];
let mut rows = Vec::new();
for (index, result) in results.into_iter().enumerate() {
    let (name, expected) = (names[index], predicted[index]);
    match result {
        // 成分数かバイト数の上限を超える計算は、数値計算の前に拒否される。

            rows.push((
                name,
                expected,
                "ResourceLimit",
                None,
                None,
                None,
                None,
                None,
            ));
        }
        Err(e) => return Err(e.to_string()),
        Ok(result) => {
            let report = result.report();
            let computed = Matrix::from_csr(result.value()).map_err(|e| e.to_string())?;
            let gap = computed
                .as_slice()
                .iter()
                .zip(references[index].as_slice())
                .fold(0.0_f64, |acc, (p, q)| acc.max((p - q).abs()));
            let fill = Some(report.structural_fill());
            let peak = Some(report.peak_intermediate_fill());
            let work = Some(report.work());
            rows.push((
                name,
                expected,
                "準備した",
                fill,
                peak,
                work,
                report.estimated_error(),
                Some(gap),
            ));
        }
    }
}
```

既定の $m = 25$、$c = 2$、$k = 4$ では、$A^k$ の出力パターンの成分数が予想の 410 に一致し、密行列の積との差は 0 である（成分はすべて整数）。
積の回数（作業量）は $\lfloor \log_2 4 \rfloor + 1 - 1 = 2$ 回で、$k = 10$ では $3 + 2 - 1 = 4$ 回になる。
$e^{A}$ の出力パターンは二つのブロックを埋めた $2 \times 25^2 = 1250$ 成分で、棒をまたぐ $n^2 - 1250 = 1250$ 成分は格納されない。
閉じた形との差は $4.4 \times 10^{-16}$ で、一次の誤差推定 $4.4 \times 10^{-14}$ は実際の差より大きい側にあるが、上界ではない。
棒を 1 本（$c = 1$、$m = 50$）にすると、$e^{A}$ は $50^2 = 2500$ 成分の密行列になり、上限 2000 のもとで準備の段階で `ResourceLimit` になる。
同じ入力の $A^k$ は 430 成分で受理される。
$m = 5$、$k = 10$ では $k \ge m - 1$ なので $A^k$ も各ブロックを埋め、二つの Plan の出力パターンはどちらも $2 \times 5^2 = 50$ 成分になる。
上限を 300 にすると、$A^k$ の 410 成分も上限を超え、二つとも数値計算の前に拒否される。

## まとめ

行列関数は固有ベクトルを使わずに計算され、指数は打ち切りの後退誤差を単位丸め以下にする Padé 近似とスケーリング・二乗で、対数と平方根は Schur 形の上で、その他の関数は Schur–Parlett 法で求められる。
一度だけ値が要るならワンショット関数 `matrix_function` を、同じ行列で値・Fréchet 微分・条件数を繰り返し求めるなら `MatrixFunctionPlan` を使う。
対数・平方根・べきは主値を返し、実数の出力では捨てた虚部と分枝までの距離をレポートで確かめる。
Fréchet 微分は非可換な方向の変化を正しく与え、その大きさから関数の条件数を推定できるが、推定は下界なので誤差の保証には使えない。
疎行列のべきと関数は非零パターンを準備の段階で決め、関数は連結ブロックを全成分で埋めるので、充填が上限を超えるなら計算の前に `ResourceLimit` で拒否される。
