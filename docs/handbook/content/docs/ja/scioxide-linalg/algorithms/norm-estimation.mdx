連立一次方程式の解の精度を見積もるには、条件数 $\kappa_1(A) = \lVert A \rVert_1 \lVert A^{-1} \rVert_1$ の大きさが要る。
$\lVert A \rVert_1$ は成分から求まるが、$\lVert A^{-1} \rVert_1$ を厳密に求めるには $A^{-1}$ の $n$ 本の列、つまり $n$ 回の求解が要る。
このページは積だけから 1 ノルムを高々 17 回の積で推定する `OneNormEstimator` と、$n$ 回の作用で厳密なノルムを求める `operator_norm` を説明し、両者を逆行列の 1 ノルムで比べる。
条件数の意味と、SVD で求める $\kappa_2$ との関係は[条件数の計算と推定](oxref:linalg-condition-estimation)で扱う。
手法オブジェクト、作業領域の要件、所有値を返す API・スコープ付き API、終了理由 `SpectralTermination` の共通の規約は[行列関数のベクトルへの適用と手法オブジェクト](oxref:linalg-action-conventions)にある。

## Hager–Higham 法による推定

1 ノルムは列の絶対値の和の最大 $\lVert A \rVert_1 = \max_j \sum_i \lvert a_{ij} \rvert$ で、$\lVert x \rVert_1 = 1$ の上での $f(x) = \lVert Ax \rVert_1$ の最大値に等しい。
$f$ は凸関数なので、最大値は 1 ノルムの単位球の頂点 $\pm e_j$ でとられ、$f(e_j)$ は列 $j$ の絶対値の和である。
Hager の方法はこの最大化を、積 $Ax$ と $A^{\mathsf H}x$ だけを使って頂点から頂点へ登る反復で解く。
$y = Ax$ の符号ベクトル $\xi$（$\xi_i = y_i / \lvert y_i \rvert$、$y_i = 0$ なら 1）と $z = A^{\mathsf H}\xi$ をとると、$f(x) = z^{\mathsf H}x$ であり、各 $j$ について $f(e_j) \ge \lvert z_j \rvert$ が成り立つ。
したがって $\lvert z_j \rvert$ が最大の $j$ を選んで $x = e_j$ に移ると、$\lVert z \rVert_\infty > z^{\mathsf H} x$ のとき推定は増える。

`OneNormEstimator` の手順は次のとおりである。

1. $n \le 4$ では $A$ をすべての単位ベクトルに作用させ、厳密な値を返す。
2. それより大きい $n$ では $x = (1, \dots, 1)/n$ から始め、$\lVert Ax \rVert_1$ を推定とする。
   推定が前の段より増えなければ止め、増えれば $z = A^{\mathsf H}\xi$ から $j$ を選んで $x = e_j$ とする。
   選んだ $j$ が前の段と同じでも止める。
   この段は高々 8 回で、各段は前向きの積と随伴の積を 1 回ずつ使う（推定が増えずに止まる段は前向きだけ）。
3. 最後に交代符号のベクトル $x_i = (-1)^i (1 + i/(n-1))$（$i = 0, \dots, n-1$、$\lVert x \rVert_1 = 3n/2$）に 1 回作用させ、$\lVert Ax \rVert_1 / \lVert x \rVert_1$ がそれまでの推定より大きければ置き換える。
   このベクトルは、初めのベクトル $(1, \dots, 1)/n$ が手がかりにならない行列への備えである（Higham、1988）。

積の回数は $n$ によらず高々 $8 \times 2 + 1 = 17$ 回である。
推定値はどれも $\lVert x \rVert_1 = 1$ に正規化したある $x$ に対する $\lVert Ax \rVert_1$ なので、丸めを除けば $\lVert A \rVert_1$ の下界になる。
上界は与えず、下にどれだけ外れうるかの保証もない（Higham、2002、15 章）。
多くの行列で推定は真の値に一致するか 10 倍以内に入るが、後のセルのシード 63 の行列のように半分以下にとどまる例もある。
$A^{-1}$ に当てる場合は 1 回の積が LU 分解による 1 回の求解（$O(n^2)$）なので、推定の計算コストは $O(n^2)$ で、$A^{-1}$ を作る $O(n^3)$ より少ない。

`OneNormEstimator` は設定だけを持つ[手法オブジェクト](oxref:linalg-method-values)で、次数 $n$ は呼び出しごとに作用素から読む。
`OneNormEstimator::new()` の既定は前向きと随伴の作用を合わせて 64 回までで、`with_applications` で変える。
各作用は実行の設定（`with_execution_options`）の反復の上限にも 1 回ずつ数える。
所有値を返す API `estimate(&op)` とスコープ付き API `estimate_scoped(&op, &mut workspace, context)` はレポート `OneNormReport` を返し、推定値 `estimate()`、作用の回数 `applications()`、終了理由 `termination()` を持つ。
終了理由は手順を終えれば `Converged`、作用の上限で止まれば `EvaluationLimit`、取り消しや期限で止まれば `ExecutionStopped` である。
止まった場合の推定値はそれまでに完了した積のうち最大のもので、積が一つも完了していなければ 0 である。
作用素が正方でなければ `DimensionMismatch`、作用素が NaN や無限大を返せば `NonFinite`、推定値が浮動小数点数の範囲を超えれば `NumericalInstability` になる。
要件 `OneNormRequirements` から作業領域 `OneNormWorkspace` を事前確保してスコープ付き API で呼ぶ手順は、[Vandermonde 行列の条件数と 1 ノルムの推定](oxref:linalg-condition-estimates)のセルにある。
`LuDecomposition::condition_estimate` は、分解の時点で厳密に求めた $\lVert A \rVert_1$ と、同じ手順による $\lVert A^{-1} \rVert_1$ の推定から逆条件数 $1/\kappa_1$ を返す。

## 単位ベクトルによる厳密なノルム

厳密な値が要るときは、標準形式 `operator_norm(&op, MatrixNorm::One)` を使う。
作用素を $n$ 本の単位ベクトル $e_j$ に作用させ、列 $Ae_j$ から 1 ノルム、$\infty$ ノルム、Frobenius ノルム（`MatrixNorm::One`、`Infinity`、`Frobenius`）を丸めを除いて厳密に計算する。
随伴の積を使わないので、長方形の作用素にも使える。
計算コストは $n$ 回の作用で、作用素は線形で、同じ入力に同じ値を返さなければならない。
オプション付き形式 `operator_norm_with_options` は実行の設定を受け取り、スコープ付き API `operator_norm_scoped(&op, kind, &options, &mut workspace, context)` は作業領域と実行コンテキストも受け取る。
作業領域の大きさは `OperatorWorkspaceRequest::norm` で求める。
列 1 本が反復の上限を 1 回使い、上限に達すると `ConvergenceFailure`、取り消しで `ExecutionStopped` のエラーになり、推定と違って途中の値は返さない。
密な行列には成分から直接ノルムを計算する `MatrixView::norm(MatrixNorm)` もある。

## 逆行列の 1 ノルムと条件数

次のセルは行列 $A$ の LU 分解の逆作用素 `inverse_operator()` に `OneNormEstimator` を当てて $\lVert A^{-1} \rVert_1$ を推定し、`operator_norm_scoped` による厳密な値（$n$ 回の求解）、`LuDecomposition::condition_estimate`、閉じた形と比べる。
行列は一次元ラプラシアン $T = \operatorname{tridiag}(-1, 2, -1)$ か、成分が独立な標準正規分布の行列で、次数 $n \in [4, 200]$、乱数のシード、作用の回数の上限（64 回か 1 回）を選ぶ。
$T$ の逆行列は離散 Green 関数 $(T^{-1})_{ij} = \min(i, j)(n + 1 - \max(i, j))/(n + 1)$（$i, j = 1, \dots, n$）で、列の和は $j(n + 1 - j)/2$ なので、$\lVert T^{-1} \rVert_1 = \max_j j(n+1-j)/2$ になる。
表は各方法の終了理由、求解の回数、$\lVert A^{-1} \rVert_1$、$\kappa_1(A)$、厳密な値との比を示す。
テストはラプラシアンでは閉じた形と、正規乱数の行列では厳密な値と照合し、outcome は推定の終了理由で決める。

```rust
//| id: linalg-one-norm-estimate
//| ref: linalg-one-norm-estimate
//| title: 逆行列の 1 ノルムを数回の求解で推定する
//| run: reactive
//| crates: [scioxide-core, scioxide-linalg]
//| inputs:
//|   family: {"type":"select","label":"行列","description":"ラプラシアンは閉じた形で、正規乱数の行列は厳密な計算で確かめる。","options":["ラプラシアン","正規乱数"],"value":"ラプラシアン"}
//|   points: {"type":"range","label":"次数 n","description":"正方行列の次数。","min":4,"max":200,"step":2,"value":100}
//|   seed: {"type":"range","label":"乱数のシード","description":"正規乱数の行列のシード。","min":1,"max":100,"step":1,"value":1}
//|   limit: {"type":"select","label":"作用の回数の上限","description":"with_applications に渡す上限（既定 64 回）。","options":["64","1"],"value":"64"}
//| cases:
//|   - {"id":"random","label":"正規乱数（シード 1）","description":"推定が厳密な値に一致する例。","inputs":{"family":"正規乱数"}}
//|   - {"id":"underestimate","label":"正規乱数（シード 63）","description":"推定が厳密な値の半分以下にとどまる例。","inputs":{"family":"正規乱数","seed":63}}
//|   - {"id":"budget","label":"作用の上限 1 回","description":"EvaluationLimit で止まり、最初の積 ‖A⁻¹e/n‖₁（列の和の平均）を返す。","inputs":{"limit":"1"}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"one-norm","path":"/rows/0/1","equals":"Converged"}
//|       - {"artifact":"one-norm","path":"/rows/0/3","approx":{"value":1275,"rtol":1e-10}}
//|       - {"artifact":"one-norm","path":"/rows/1/3","approx":{"value":1275,"rtol":1e-10}}
//|       - {"artifact":"one-norm","path":"/rows/3/3","equals":1275}
//|       - {"path":"/outputs/1/state","equals":"satisfied"}
//|   - case: random
//|     expect:
//|       - {"artifact":"one-norm","path":"/rows/0/5","approx":{"value":1,"atol":1e-10}}
//|       - {"artifact":"one-norm","path":"/rows/3/3","equals":null}
//|   - case: underestimate
//|     expect:
//|       - {"artifact":"one-norm","path":"/rows/0/5","range":{"min":0.3,"max":0.6}}
//|       - {"path":"/outputs/1/state","equals":"satisfied"}
//|   - case: budget
//|     expect:
//|       - {"artifact":"one-norm","path":"/rows/0/1","equals":"EvaluationLimit"}
//|       - {"artifact":"one-norm","path":"/rows/0/2","equals":1}
//|       - {"artifact":"one-norm","path":"/rows/0/3","approx":{"value":858.5,"rtol":1e-10}}
//|       - {"path":"/outputs/1/state","equals":"partial"}
use scioxide_core::{Budget, ExecutionContext};
use scioxide_linalg::{
    LinalgExecutionOptions, LinalgWorkspace, LuDecomposition, Matrix, MatrixNorm,
    OneNormEstimator, SpectralTermination, operator_norm_scoped,
};

let n = points.round() as usize;
let laplacian = family == "ラプラシアン";
// シードから作る標準正規分布の擬似乱数（xorshift64* と Box–Muller 法）。
let mut state = (seed.round() as u64).wrapping_mul(0x9E37_79B9_7F4A_7C15) | 1;
let mut uniform = move || {
    state ^= state >> 12;
    state ^= state << 25;
    state ^= state >> 27;
    ((state.wrapping_mul(0x2545_F491_4F6C_DD1D) >> 11) as f64 + 0.5) / (1u64 << 53) as f64
};
let noise: Vec<f64> = (0..n * n)
    .map(|_| {
        let (u, v) = (uniform(), uniform());
        (-2.0 * u.ln()).sqrt() * (2.0 * std::f64::consts::PI * v).cos()
    })
    .collect();
// T = tridiag(−1, 2, −1) か、成分が独立な標準正規分布の行列。
let mut a = Matrix::zeros(n, n).map_err(|e| e.to_string())?;
for (idx, value) in a.as_mut_slice().iter_mut().enumerate() {
    let (i, j) = (idx / n, idx % n);
    *value = match (laplacian, i.abs_diff(j)) {
        (false, _) => noise[idx],
        (true, 0) => 2.0,
        (true, 1) => -1.0,
        (true, _) => 0.0,
    };
}
let norm = a.view().norm(MatrixNorm::One).map_err(|e| e.to_string())?;
let lu = LuDecomposition::factor(&a).map_err(|e| e.to_string())?;
// 逆作用素 x ↦ A⁻¹x は随伴の積も持ち、1 回の作用が 1 回の求解になる。
let inverse = lu.inverse_operator();
let limit = Budget::try_from(limit.parse::<usize>().map_err(|e| e.to_string())?)
    .map_err(|e| e.to_string())?;
let report = OneNormEstimator::new()
    .with_applications(limit)
    .estimate(&inverse)
    .map_err(|e| e.to_string())?;
// 厳密な値: スコープ付き API で n 本の単位ベクトルに作用させる（n 回の求解）。
let exact = operator_norm_scoped(
    &inverse,
    MatrixNorm::One,
    &LinalgExecutionOptions::new(),
    &mut LinalgWorkspace::new(),
    ExecutionContext::sequential(),
)
.map_err(|e| e.to_string())?;
// ラプラシアンの閉じた形 ‖T⁻¹‖₁ = maxⱼ j(n + 1 − j)/2（検算）。
let closed = laplacian.then(|| {
    (1..=n)
        .map(|j| (j * (n + 1 - j)) as f64 / 2.0)
        .fold(0.0, f64::max)
});
// LU の条件数の推定も同じ Hager–Higham 法で ‖A⁻¹‖₁ を推定する。
let rcond = lu
    .condition_estimate()
    .map_err(|e| e.to_string())?
    .reciprocal()
    .value();
let lu_inverse = 1.0 / (rcond * norm);
let name = match report.termination() {
    SpectralTermination::Converged => "Converged",
    SpectralTermination::EvaluationLimit => "EvaluationLimit",
    SpectralTermination::IterationLimit => "IterationLimit",
    SpectralTermination::InvariantSubspace => "InvariantSubspace",
    SpectralTermination::AccuracyLimit => "AccuracyLimit",
    SpectralTermination::ExecutionStopped(_) => "ExecutionStopped",
};

let sci4 = serde_json::json!({ "notation": "scientific", "significantDigits": 4 });
let fixed4 = serde_json::json!({ "fractionDigits": 4 });
let columns = serde_json::json!([
    { "key": "0", "label": "方法" },
    { "key": "1", "label": "終了理由", "nullText": "—" },
    { "key": "2", "label": "求解の回数 [回]", "type": "integer", "nullText": "—" },
    { "key": "3", "label": "‖A⁻¹‖₁ [-]", "type": "number", "format": sci4, "nullText": "対象外" },
    { "key": "4", "label": "κ₁(A) [-]", "type": "number", "format": sci4, "nullText": "対象外" },
    { "key": "5", "label": "厳密な値との比 [-]", "type": "number", "format": fixed4, "nullText": "対象外" }
]);
let rows = vec![
    (
        "OneNormEstimator::estimate",
        Some(name),
        Some(report.applications()),
        Some(report.estimate()),
        Some(norm * report.estimate()),
        Some(report.estimate() / exact),
    ),
    (
        "operator_norm_scoped（厳密）",
        None,
        Some(n),
        Some(exact),
        Some(norm * exact),
        Some(1.0),
    ),
    (
        "LuDecomposition::condition_estimate",
        None,
        None,
        Some(lu_inverse),
        Some(1.0 / rcond),
        Some(lu_inverse / exact),
    ),
    (
        "閉じた形 maxⱼ j(n + 1 − j)/2",
        None,
        None,
        closed,
        closed.map(|v| norm * v),
        closed.map(|v| v / exact),
    ),
];
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "one-norm" })
);

let outcome = match report.termination() {
    SpectralTermination::Converged => Outcome::satisfied("推定の反復が収束した")
        .explanation("推定値は ‖A⁻¹‖₁ の下からの推定で、上界ではない。"),
    SpectralTermination::AccuracyLimit => Outcome::failed("推定が精度の検査に通らなかった"),
    _ => Outcome::partial("上限で止まり、それまでの最大の推定値を返した"),
};
emit_outcome!(
    outcome
        .status(name)
        .diagnostic("求解の回数", report.applications() as f64, None)
        .diagnostic("厳密な値との比", report.estimate() / exact, None)
);
```

既定のラプラシアン（$n = 100$）では、推定は 5 回の求解で `Converged` になり、$\lVert T^{-1} \rVert_1 = 1275$ は 100 回の求解による厳密な値と、閉じた形 $50 \cdot 51/2 = 1275$ に一致する（$\kappa_1 = 5100$）。
5 回の内訳は$(1, \dots, 1)/n$ への積とその随伴の積、選んだ最大の列 $e_j$ への積とその随伴の積（同じ列が再び選ばれて停止）、交代符号のベクトルへの積である。
$T^{-1}$ の成分はすべて正なので、最初の随伴の積で最大の列がすでに見つかる。
作用の上限を 1 回にすると `EvaluationLimit` で止まり、最初の積の 1 ノルム、つまり列の和の平均 $(n+1)(n+2)/12 = 858.5$ が推定値として返る（厳密な値の 0.67 倍）。
正規乱数の行列（シード 1）では推定が厳密な値 $24.07$ に一致するが、シード 63 では推定 $17.11$ が厳密な値 $38.69$ の 0.44 倍にとどまり、$\kappa_1$ を半分以下に見積もる。
`LuDecomposition::condition_estimate` は同じ手順なので、どの場合も丸めの範囲で同じ値を返す。

## まとめ

$\lVert A^{-1} \rVert_1$ や $\kappa_1(A)$ の桁を知りたいだけなら、LU 分解の `condition_estimate` か、逆作用素に当てた `OneNormEstimator` を使えば、$n$ によらず高々 17 回の求解で済む。
推定値は丸めを除いて下界で、上界の保証はないので、数倍の過小評価がありうる桁の目安として解釈する。
`OneNormEstimator` の結果は終了理由が `Converged` のときに使い、`EvaluationLimit` で止まった値は完了した積の最大にすぎないことに注意する。
厳密な値が要るときや作用素が長方形のときは、$n$ 回の作用で `operator_norm`（作業領域とコンテキストを渡すなら `operator_norm_scoped`）を計算する。
