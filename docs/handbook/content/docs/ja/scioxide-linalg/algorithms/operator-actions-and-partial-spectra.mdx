数万次元の疎行列でも、$e^{tA}$ や固有ベクトルを並べた行列はふつう密になり、$n^2$ 個の成分を作ってメモリするのは現実的でない。
しかし多くの応用で必要なのは、ベクトルへの作用 $e^{tA}v$、少数の固有値、上位の特異値のように、行列全体よりずっと小さな情報である。
`scioxide-linalg` はこれらを、作用素の積 $x \mapsto Ax$（と随伴の積 $x \mapsto A^{\mathsf H}x$）だけを使う七つの手法で求める。
このページは七つの手法に共通する規約と、行列関数のベクトルへの作用を説明する。
少数の固有対は[大きな作用素の少数の固有対](../partial-spectra/)、上位の特異値と低ランク近似は[部分 SVD と乱択低ランク近似](../partial-svd-and-low-rank/)、ノルムの推定は[1 ノルムの推定と作用素の厳密なノルム](../norm-estimation/)で扱う。

## 共通の規約

### 手法オブジェクト

作用素だけを使う手法は設定だけを持つ値として作る。
この値を**手法オブジェクト**と呼ぶ。
手法オブジェクトは作用素の次元も入力の列数も持たず、呼び出しのたびに作用素と入力からそれらを読む。
再利用できる前計算（分解や並べ替え）を持つ Plan（`…Plan`）とは違い、手法オブジェクトは計算の前に何も用意しないので、同じ値を次元の違う作用素にそのまま使える。
設定の検査も呼び出しのときに行い、`workspace_requirements` と実行の関数は計算を始める前に同じエラーを返す。

| 手法オブジェクト | 求めるもの | 作用素 | 呼び出しごとに読む次元 | 所有値を返す API | 出力先を指定する API・スコープ付き API | レポート |
|---|---|---|---|---|---|---|
| `ExponentialAction` | $\varphi_k(tA)B$ | 正方の `AdjointOperator` | $n$、$B$ の列数 | `apply` | `apply_into` | `ExponentialActionReport` |
| `FunctionAction` | $f(A)B$ | 正方の `LinearOperator` | $n$、$B$ の列数 | `apply` | `apply_into` | `FunctionActionReport` |
| `PartialSpectrumSolver` | 少数の固有対 | `SpectrumOperator` | $n$ | `solve` | `solve_into` | `PartialSpectrumReport` |
| `LobpcgSolver` | Hermitian 定値の組の端の固有対 | `LobpcgOperator` | $n$、制約の列数 $c$ | `solve` | `solve_into` | `LobpcgReport` |
| `PartialSvdSolver` | 上位の特異三つ組 | `AdjointOperator` | 行数 $m$、列数 $n$ | `solve` | `solve_into` | `PartialSvdReport` |
| `RandomizedLowRank` | 低ランクの SVD と列補間分解 | `AdjointOperator` | $m$、$n$、スケッチの列数 $w$ | `svd`、`interpolative` | `svd_into`、`interpolative_into` | `LowRankReport` |
| `OneNormEstimator` | $\lVert A \rVert_1$ の推定 | 正方の `AdjointOperator` | $n$ | `estimate` | `estimate_scoped` | `OneNormReport` |

`LinearOperator` と `AdjointOperator` は scioxide-core のトレイトで、後者は随伴の積 $A^{\mathsf H}x$ も提供する。
密行列は `matrix.view().try_finite()?` で、三重対角行列は `matrix.view()` で、どちらも随伴を持つ作用素になる。
既定の設定は `FunctionAction` だけが `FunctionAction::default()` で、ほかは `new` で作る。
`new` の引数は、`ExponentialAction` が 1 ノルムの上界、`PartialSpectrumSolver`・`LobpcgSolver`・`PartialSvdSolver` が求める個数、`RandomizedLowRank` が目標のランクで、`OneNormEstimator::new()` は引数を取らない。

### 作業領域の要件と事前確保

作業領域の大きさは手法オブジェクトと作用素から `method.workspace_requirements(&op, …)` で求める（`…` は列数や制約の数など、表の「呼び出しごとに読む次元」のうち作用素から読めないもの）。
要件と作業領域の型は手法ごとに分かれ（`ExponentialAction` なら `ExponentialActionRequirements` と `ExponentialActionWorkspace`）、別の手法の要件を渡すとコンパイルエラーになる。
要件は新しい作業領域に要るバイト数 `required_bytes()` と、実行オプションのバイト上限 `byte_limit()` を返す。
作業領域は `new()` で空のものを作り、`check(&requirements)` で足りるか（`Capacity::Sufficient`）、増やす必要があるか（`Capacity::NeedsGrowth`）を調べ、`try_reserve(&requirements)` で増やす。
`method.workspace(&op, …)` は空の作業領域を作って事前確保するところまでを一度に行う。
要件のバイト数は入れ子の密な分解（射影した小さな行列の固有値計算など）のメモリ領域も含み、`LinalgExecutionOptions::with_byte_limit` の上限を超える要件は計算の前に `ResourceLimit` で拒否される。

### 所有値を返す API と出力先を指定する API

呼び出しの形の名前（所有値を返す API、出力先を指定する API、スコープ付き API）は[作業領域・実行コンテキスト・試行記録](../workspaces-and-execution/)で定義している。
所有値を返す API（`apply`、`solve`、`svd`、`interpolative`、`estimate`）は、出力と作業領域をその場で確保し、`ExecutionContext::sequential_native()` で逐次に実行して、出力とレポートを返す。
出力先を指定する API（`*_into`）は呼び出し側の出力と事前確保済みの作業領域に書き、最後の引数に渡す実行コンテキストで取り消しと期限を観測する。
事前確保した作業領域を同じ大きさの問題に渡す限り、出力先を指定する API の呼び出しはメモリ領域を確保しない。
値を一つだけ返す `OneNormEstimator` には、出力先を指定する API の代わりにスコープ付き API `estimate_scoped` がある。
作業領域の `last_attempt()` は直近の試行を記録した `AttemptRecord` を返す。
試行は `Converged` で `Succeeded`、ほかの終了理由で `Stopped`、計算中のエラーで `Failed` になり、計算を始める前に引数の検査で拒否された呼び出しは `PreflightRejected` になる。

### 実行の上限と終了理由

どの手法オブジェクトも作用素（と前処理や質量行列）の作用の回数の上限 `with_applications` を持ち、既定は `OneNormEstimator` が 64 回、ほかが 10 万回である。
実行オプションは呼び出しごとではなく、`with_execution_options(LinalgExecutionOptions)` で手法オブジェクトに設定する。
その反復の上限（`with_iteration_budget`）が何を数えるかは手法で異なる。
`ExponentialAction` は Taylor 項と推定の積を、`FunctionAction` は Arnoldi の一歩を、`PartialSpectrumSolver` と `PartialSvdSolver` は再始動の周期を、`LobpcgSolver` は外側の反復を、`RandomizedLowRank` はスケッチの列と部分空間反復の一歩を、`OneNormEstimator` は作用を、それぞれ 1 回と数える。
反復の上限を設定しないとき、再始動の周期と LOBPCG の外側の反復は 100 回までになる。

終了理由 `SpectralTermination` は次の六つの列挙子をとり、成功の判定を持つメソッドはない。

| 列挙子 | 意味 | このハンドブックの判定 |
|---|---|---|
| `Converged` | 求めたすべての結果が残差か精度の検査に通った | satisfied |
| `EvaluationLimit` | 作用の回数の上限か、外側の求解の評価の上限に達した | partial |
| `IterationLimit` | 反復・再始動・Taylor 次数・射影の次元の上限に達した | partial |
| `InvariantSubspace` | すべての対が検査に通る前に、Krylov 部分空間が不変になるか全次元に達した | partial |
| `AccuracyLimit` | 近似は完成したが、精度の検査に通らなかった | failed |
| `ExecutionStopped(reason)` | 取り消しか期限で止まった | partial |

`Converged` 以外の終了理由でも、呼び出しは `Ok` を返し、その時点で受理した部分結果を出力に書く。
部分結果に何が入るかはレポートの型ごとに決まっていて、各手法の節で説明する。
不正な入力と数値的な破綻は `Err` で返る。
次の定義のブロックは終了理由を列挙子の名前に直す関数で、このページの二つのセルが表と outcome に使う。

```rust
//| id: linalg-action-termination-name
//| kind: definitions
//| title: 終了理由の名前
//| crates: [scioxide-linalg]
use scioxide_linalg::SpectralTermination;

/// 終了理由を列挙子の名前にする（取り消しの理由は表に出さない）。
pub(crate) fn termination_name(termination: SpectralTermination) -> &'static str {
    match termination {
        SpectralTermination::Converged => "Converged",
        SpectralTermination::EvaluationLimit => "EvaluationLimit",
        SpectralTermination::IterationLimit => "IterationLimit",
        SpectralTermination::InvariantSubspace => "InvariantSubspace",
        SpectralTermination::AccuracyLimit => "AccuracyLimit",
        SpectralTermination::ExecutionStopped(_) => "ExecutionStopped",
    }
}
```

## 指数・φ 関数と解析関数の作用

### 切断 Taylor 法による指数の作用

`ExponentialAction` は $n \times n$ の作用素 $A$ と $n$ 次のベクトルを $c$ 本並べたブロック $B$ に対して、$\varphi_k(tA)B$ を求める。
$\varphi$ 関数は

```text
φ₀(z) = eᶻ,   φₖ(z) = Σ_{j ≥ 0} zʲ / (j + k)!   (k ≥ 1)
```

で定義され、指数積分法による時間積分に現れる。
たとえば定数の強制項 $g$ を持つ $\dot u = Au + g$ の解は $u(t) = e^{tA}u_0 + t\varphi_1(tA)g$ である。
関数と時刻 $t$ は呼び出しのときに `PhiFunction::exp(t)` か `PhiFunction::phi(k, t)` で渡す。

方法は Al-Mohy と Higham（2011）の切断 Taylor 法である。
シフト $\mu$、次数 $m$ の Taylor 多項式 $T_m(X) = \sum_{j=0}^{m} X^j/j!$、刻みの数 $s$ を使い、

```text
e^{tA} b ≈ e^{tμ} ( T_m( t(A − μI)/s ) )^s b
```

を $s$ 回の多項式の作用、つまり高々 $ms$ 回の積で計算する。
$\theta_m$ は、$\lVert X \rVert_1 \le \theta_m$ なら $T_m(X) = e^{X + \Delta X}$、$\lVert \Delta X \rVert_1 \le u \lVert X \rVert_1$（$u = \varepsilon/2$ は単位丸め）となる最大の値で、倍精度では $\theta_{10} = 0.144$、$\theta_{55} = 9.9$ である。
次数と刻みの数は、$\lVert t(A - \mu I) \rVert_1$ の代わりに使う量 $\alpha$ から

```text
s = ⌈ α / θₘ ⌉,   (m, s) = argmin_{m ≤ m_max} m·s
```

で選ぶ（$m_{\max}$ は Taylor 次数の上限で、既定 55）。
$\alpha$ は呼び出し側の上界から $\lvert t \rvert \times$ 上界とする。
これが $2p_{\max}(p_{\max} + 3)\theta_{m_{\max}}/(m_{\max} c)$（既定では約 $31.7/c$、$c$ は列数）を超えるときは、1 ノルムの推定にかかる積を上回る節約が見込める。
そこで随伴の積を使う推定で $d_p = \lVert (t(A - \mu I))^p \rVert_1^{1/p}$ を $p = 2, \dots, p_{\max} + 1$ について求め、$p(p-1) \le m + 1$ を満たす次数 $m$ に $\alpha = \min(\lvert t \rvert \times \text{上界}, \max(d_p, d_{p+1}))$ を使う（$p_{\max}$ は $p(p-1) \le m_{\max} + 1$ を満たす最大の $p$ で、既定では 8）。
$d_p$ は $\lVert t(A - \mu I) \rVert_1$ 以下で、非正規な行列では大きく下回るので、刻みの数を減らせる。
各刻みは、最後の 2 項の 1 ノルムの和が $(\tau_{\mathrm{abs}} \lVert b \rVert_1 + \tau_{\mathrm{rel}} \lVert y \rVert_1)/s$ 以下になった時点で項を足すのをやめる（$\lVert y \rVert_1$ はその刻みの部分和の 1 ノルムの最大で、部分和の丸め誤差の尺度である）。
指数ではすべての列で一つの $(m, s)$ を使い、$\varphi$ 関数では列ごとに選ぶ。

$k \ge 1$ の $\varphi_k(tA)b$ は、$\hat b = b/\lVert b \rVert_1$ と $k \times k$ の上シフト行列 $J$（$Je_{j+1} = e_j$）で作る次数 $n + k$ の拡大行列

```text
Ã = ⎡ tA   b̂ e₁ᵀ ⎤ ,     φₖ(tA) b̂ = ( e^Ã e_{n+k} ) の先頭 n 成分
    ⎣ 0      J   ⎦
```

から読み取る（Al-Mohy と Higham、2011、定理 2.1）。
$\tilde A$ との積は $A$ との積 1 回と追加の $k$ 成分のずらしで済むので、拡大行列は作らない。
末尾の $k \times k$ のブロックはシフトを除いて冪零なので厳密に進め、Taylor 級数とその停止判定（上の $b$ と $y$ のノルムを含む）は拡大したベクトルの先頭 $n$ 成分だけに使う。
$\varphi$ 関数では $(m, s)$ の選択に拡大行列のノルムの上界 $\max(\lvert t \rvert \times \text{上界}, 1 + \lvert t\mu \rvert)$ を使う。
各刻みは選んだ次数ではなく次数の上限まで項を足して許容誤差を確かめ、満たさなければ `IterationLimit` になる。

上界は必須の設定で、`ExponentialAction::new(bound)` の `bound` は $\lVert A - \mu I \rVert_1$ の上界でなければならない。
方法は上界を検証できず、小さすぎる上界は結果を不正確にしうる。
推定したノルムは $(m, s)$ を選ぶためだけに使い、上界の代わりにはならない。
`with_shift(μ)` は $e^{tA} = e^{t\mu} e^{t(A - \mu I)}$ を使い、$\lVert A - \mu I \rVert_1$ と刻みの数を減らせる。
よく使う $\mu = \operatorname{tr}(A)/n$ は一般の作用素からは計算できないので、呼び出し側が渡す。
因子 $e^{t\mu}$ は拡張した指数の範囲で掛けるので、それ単独では浮動小数点数で表せない大きさでもよい。
$\varphi$ 関数ではシフトは拡大行列全体に掛かり、末尾のブロックは $e^{-t\mu}$ のように減衰する。
大きなシフトでは各刻みの $\varphi$ の級数で打ち消しが起き、$\lVert A - \mu I \rVert_1 = 1$、$t\mu = 100$ から $800$ では、$\varphi_1$ から $\varphi_3$ の相対誤差が倍精度で $2 \times 10^{-13}$ から $4 \times 10^{-11}$ になる。

既定はシフト 0、許容誤差 $\tau_{\mathrm{abs}} = 0$・$\tau_{\mathrm{rel}} = u$、作用の回数 10 万回まで、Taylor 次数 55 まで（`with_terms`、55 を超える値は拒否）、指数だけ（`with_max_phi(0)`）である。
$u$ より小さい $\tau_{\mathrm{rel}}$ を与えると、$\theta_m$ を下げて刻みを増やす。
$\varphi$ 関数を使うときは `with_max_phi(k)`（$k$ は Taylor 次数の上限以下）で拡大行列のメモリ領域を用意し、それより大きい添字は呼び出しのときに `InvalidInput`（`OutOfRange`）になる。
正確な算術と正確なノルムの推定のもとでは、選んだ $(m, s)$ は切断した級数の相対後退誤差を $u$（$\tau_{\mathrm{rel}}$ がそれより小さければ $\tau_{\mathrm{rel}}$）以下に保つ。
上界やシフトが有限でない設定は `NonFinite`、上界が負か、Taylor 次数が 55 を超えるか、`max_phi` が Taylor 次数の上限を超える設定は `InvalidInput`（`OutOfRange`）として、要件を求める段階で拒否される。
$\lvert t \rvert$ と上界の積、$t\mu$、途中の値があふれると `NumericalInstability`（`Overflow`）になり、$\varphi$ 関数の正規化した項が $\lVert b \rVert_1$ を掛け戻す前に下位桁あふれすると `NumericalInstability`（`Underflow`）になる。

レポート `ExponentialActionReport` は全列に共通の終了理由 `termination()` と、ノルムの推定を含む作用の回数 `applications()` を持つ。
列ごとの診断は作業領域の `last_accepted()` が返す `ExponentialActionAccepted` で読む。
`progress()` は完了した刻みが覆う区間 $[0, t]$ の割合 $f$、`estimated_errors()` は完了した刻みの打ち切りの指標の和、`completed()` は全刻みが完了したかを返す。
打ち切りの指標は各刻みの最後の 2 項の 1 ノルムで、打ち切り誤差の推定であって前進誤差の上界ではない。
`last_accepted()` は最初の呼び出しの前、`try_reserve` の後、`Err` を返した呼び出しの後には `None` を返す。
上限か取り消しで止まったとき、各列の出力は完了した刻みまでの結果で、指数では $e^{ftA}b$ になる。
刻みを一つも完了していない列には、指数では $b$、$\varphi$ 関数では 0 が入る。

### 熱方程式の半離散解

熱方程式 $u_t = \kappa u_{xx}$（$\kappa = 1$ m²/s、$x \in [0, 1]$ m、$u(0) = u(1) = 0$）を、格子幅 $h = 1/(n+1)$ の二階差分で半離散化すると $\dot u = Au$、$A = \operatorname{tridiag}(1, -2, 1)/h^2$ になり、解は $u(t) = e^{tA}u_0$ である。
離散ラプラシアンの固有ベクトルは $\sin(k\pi x_i)$、固有値は $\lambda_k = -\tfrac{4}{h^2}\sin^2\tfrac{k\pi h}{2}$ なので、初期値を

```text
u₀ = Σₖ cₖ sin(kπxᵢ),   cₖ = 2h Σᵢ u₀(xᵢ) sin(kπxᵢ)
```

と展開すれば、半離散の厳密解は $\sum_k c_k e^{\lambda_k t}\sin(k\pi x_i)$ になる。
初期温度 $u_0 = 4x(1-x)$（無次元）の連続問題の解は Fourier 級数 $\sum_{k\,\text{奇数}} \tfrac{32}{(k\pi)^3} e^{-(k\pi)^2 t}\sin(k\pi x)$ で、半離散の解との差は空間の離散化誤差 $O(h^2)$ である。
$\lVert A \rVert_1 = 4/h^2$ で、$\mu = \operatorname{tr}(A)/n = -2/h^2$ だけずらすと $\lVert A - \mu I \rVert_1 = 2/h^2$ になる。

次の定義のブロックはこのモデルを二つのセルで共有する。
`heat_matrix(n, scale)` が scale を掛けた $A$（scale = 1 なら $A$、scale = $t$ なら $tA$）、`grid` が格子と初期温度、`semi_discrete` と `continuum` が検算に使う二つの解に対応する。
検算の関数は `f64` の標準関数で計算する。

```rust
//| id: linalg-heat-model
//| kind: definitions
//| title: 半離散の熱方程式と検算用の解
//| crates: [scioxide-core, scioxide-linalg]
use scioxide_core::SciOxideError;
use scioxide_linalg::TridiagonalMatrix;

/// 内点 xᵢ = i h（h = 1/(n + 1)）と初期温度 u₀ = 4x(1 − x)。
pub(crate) fn grid(n: usize) -> (Vec<f64>, Vec<f64>) {
    let h = 1.0 / (n + 1) as f64;
    let x: Vec<f64> = (1..=n).map(|i| i as f64 * h).collect();
    let u0 = x.iter().map(|&xi| 4.0 * xi * (1.0 - xi)).collect();
    (x, u0)
}

/// scale · tridiag(1, −2, 1)/h²。scale = t なら tA になる。
pub(crate) fn heat_matrix(n: usize, scale: f64) -> Result<TridiagonalMatrix<f64>, SciOxideError> {
    let s = scale * ((n + 1) as f64).powi(2);
    TridiagonalMatrix::new(vec![s; n - 1], vec![-2.0 * s; n], vec![s; n - 1])
}

/// 半離散の厳密解 Σₖ cₖ e^{λₖ t} sin(kπxᵢ)（参照値。f64 の標準関数）。
pub(crate) fn semi_discrete(n: usize, t: f64) -> Vec<f64> {
    let (x, u0) = grid(n);
    let h = 1.0 / (n + 1) as f64;
    let pi = std::f64::consts::PI;
    let modes: Vec<(f64, f64)> = (1..=n)
        .map(|k| {
            let w = k as f64 * pi;
            let c: f64 = x
                .iter()
                .zip(&u0)
                .map(|(&xi, &ui)| ui * (w * xi).sin())
                .sum();
            let lambda = -4.0 / (h * h) * (0.5 * w * h).sin().powi(2);
            (w, 2.0 * h * c * (lambda * t).exp())
        })
        .collect();
    x.iter()
        .map(|&xi| modes.iter().map(|&(w, c)| c * (w * xi).sin()).sum())
        .collect()
}

/// 連続問題の解 Σ_{k 奇数} 32/(kπ)³ e^{−(kπ)² t} sin(kπx) を内点で求める（参照値）。
pub(crate) fn continuum(n: usize, t: f64) -> Vec<f64> {
    let (x, _) = grid(n);
    let pi = std::f64::consts::PI;
    x.iter()
        .map(|&xi| {
            (1..400)
                .step_by(2)
                .map(|k| {
                    let w = k as f64 * pi;
                    32.0 / w.powi(3) * (-w * w * t).exp() * (w * xi).sin()
                })
                .sum()
        })
        .collect()
}

/// 最大値ノルムで測った二つのベクトルの差。
pub(crate) fn max_gap(p: &[f64], q: &[f64]) -> f64 {
    p.iter().zip(q).fold(0.0, |m, (u, v)| m.max((u - v).abs()))
}
```

### 再始動 Arnoldi による f(A)b

一般の行列関数の作用 $f(A)b$ は `FunctionAction` が再始動する Arnoldi 過程で求める。
関数は `MatrixFunction` で選び、`Exp`、`Log`、`Sqrt`、`Power(p)`、`Sign` などのほか、呼び出し側が与える解析関数 `Analytic` も渡せる。
各列について、$b/\lVert b \rVert_2$ から長さ $m$（再始動の長さ）の Arnoldi 基底を作り、最後の基底ベクトルから再始動する。
すべての周期の Hessenberg 行列は次数 $p$（射影の次元）までの一つの Hessenberg 行列 $H$ にまとめて保持し、各周期は補正 $\lVert b \rVert_2 V_k (f(H)e_1)_k$ を加える（$V_k$ はその周期の基底、$(\cdot)_k$ は対応する行。
Eiermann と Ernst、2006）。
$f(H)$ は複素 Schur 分解から計算し、1 周期の計算コストは次数 $p$ までの密な計算の $O(p^3)$ である。
メモリ領域は基底の $O(nm)$ と $H$ の $O(p^2)$ で済む。
列は誤差の指標が許容誤差を満たすか、Krylov 部分空間が不変になった時点で止まり、その前に射影の次元が $p$ に達すると `IterationLimit` になる。

既定は再始動の長さ 16（`with_restart`）、射影の次元 64（`with_projection`、再始動の長さ以上でなければ `InvalidInput`（`Inconsistent`））、作用の回数 10 万回まで、許容誤差 $\tau_{\mathrm{abs}} = \tau_{\mathrm{rel}} = \sqrt{\varepsilon}$、射影した行列に $f$ を密に評価するときの設定 `with_function_settings` の既定値である。
停止の判定は、列ごとの誤差の指標が $\tau_{\mathrm{abs}} \lVert b \rVert_2 + \tau_{\mathrm{rel}} \lVert y \rVert_2$ 以下になることである（$y$ はその時点の近似）。
誤差の指標は Arnoldi の漸化式で最後に現れる副対角成分 $\beta$ と $H$ の次数 $l$ による $\lVert b \rVert_2\, \beta\, \lvert e_l^{\mathsf T} f(H) e_1 \rvert$（ただし $\varepsilon \lVert y \rVert_2$ 以上）で、部分空間が不変になれば 0 になる。
この指標は誤差の推定で、上界ではない。
実の作用素から複素数の出力を求めることもできる（負の固有値を持つ行列の平方根など）。
実数の出力には各近似の実部を書き、捨てる虚部（実数の結果では $f(H)$ の複素 Schur 法による評価の誤差）が停止のしきい値と誤差の指標の大きい方を超えると `DomainError` になる。
`MatrixFunction::Analytic` の仮定は $A$ の固有値だけでなく、各周期の射影 $H$ の固有値でも成り立っていなければならない。

作業領域 `FunctionActionWorkspace` は、再始動の長さ $m$、射影の次元 $p$、列数 $c$ に対して $O(nm + p^2 + nc)$ 個のスカラーを持ち、その大きさは要件 `FunctionActionRequirements` で求める。
レポート `FunctionActionReport` は全列に共通の終了理由、作用の回数、全列で完了した再始動の周期の数 `cycles()` を持つ。
列ごとの診断は作業領域の `last_accepted()` が返す `FunctionActionAccepted` で読み、`estimated_errors()` が最後に完了した周期で求めた誤差の指標、`completed()` が停止の判定を満たしたかを返す。
上限か取り消しで止まったとき、各列の出力は完了した周期までの近似で、周期を一つも完了していない列は 0 である。

次のセルは前のセルと同じ熱方程式の $e^{tA}u_0$ を、$B = tA$ に対する $\exp(B)u_0$ として `FunctionAction` の出力先を指定する API で求める。

```rust
    SpectralTermination::Converged => Outcome::satisfied("誤差の指標が許容誤差を満たした"),
    SpectralTermination::AccuracyLimit => Outcome::failed("近似が精度の検査に通らなかった"),
    _ => Outcome::partial("射影の次元の上限で止まり、出力はそこまでの近似")
        .explanation("射影の次元 p を上げるか、ExponentialAction を使う。"),
};
emit_outcome!(
    outcome
        .status(termination_name(report.termination()))
        .diagnostic("作用の回数", report.applications() as f64, None)
        .diagnostic("半離散解との差の 2 ノルム", error, None)
);
```

既定の $t = 0.02$ s、$n = 100$、$p = 64$ では、`FunctionAction` は 4 周期・64 回の作用で射影の次元の上限に達し、`IterationLimit` で止まる。
このときの近似の誤差（2 ノルム）は $8.5 \times 10^{-5}$ で、誤差の指標 $2.1 \times 10^{-3}$ はそれより 25 倍ほど大きい。
止まったときの出力は誤差の指標を目安とする部分結果として読める。
$p = 128$ にすると 8 周期・128 回の作用で誤差は $7.8 \times 10^{-11}$（指標は $5.4 \times 10^{-9}$）まで下がるが、許容誤差 $10^{-13}$ にはまだ届かず、終了理由は `IterationLimit` のままである。
$t = 0.001$ s では 3 周期・48 回の作用で `Converged` になり、同じ時刻の `ExponentialAction`（539 回）より一桁少ない。
このとき指標 $6.3 \times 10^{-15}$ は実際の誤差 $1.7 \times 10^{-14}$ より小さく、どちらも丸め誤差の水準にあり、指標が上界ではないことも分かる。
再始動しない Krylov 部分空間による近似では、固有値が負の実軸上の区間 $[-\lVert tA \rVert_2, 0]$ にあるとき、誤差を十分小さくするのに要る次元は $\lVert tA \rVert_2$ の平方根程度で増える（Hochbruck と Lubich、1997）。
そのため作用の回数は $t\lVert A \rVert_1$ に比例する `ExponentialAction` の回数より少なくて済む。
ただしこの例の $\sqrt{816} \approx 29$ に対して、再始動の長さ 16 の `FunctionAction` は 128 次元でも許容誤差 $10^{-13}$ に届かない。
作用の回数を減らしたいなら `FunctionAction` を、射影の $O(p^3)$ の計算と $O(p^2)$ のメモリ領域を避け、上界から決まる回数の作用で刻みを最後まで進めたいなら `ExponentialAction` を選ぶ。

## まとめ

作用素の積だけを使う七つの手法は設定だけを持つ手法オブジェクトで、作用素と入力の次元を呼び出しのたびに読むので、一つの値を大きさの違う問題に使える。
繰り返し呼ぶときは `workspace_requirements` で要件を求めて `try_reserve` で事前確保し、出力先を指定する API で呼べば同じ大きさの呼び出しでメモリ領域を確保しない。
`SpectralTermination` に成功の判定はなく、`Converged` 以外の終了理由でも部分結果が `Ok` で返るので、結果を使う前に終了理由とレポートの診断を読む。
$e^{tA}b$ は、$\lVert A - \mu I \rVert_1$ の上界が分かるなら `ExponentialAction` で求め、上限で止まったときの出力は時刻 $ft$ の解として使える。
上界がないときや指数以外の関数には `FunctionAction` を使い、作用の回数は少なくて済むが、射影の次元の上限で `IterationLimit` になりうるので誤差の指標を確かめる。
