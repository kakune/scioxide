大きな行列や作用素の特異値分解全体は求められなくても、上位の数個の特異値と特異ベクトルや、低ランクの近似は積だけから求められる。
データ行列の主成分や、行列の数値ランクの見積もりはその例である。
このページは `PartialSvdSolver` と `RandomizedLowRank` の二つの手法オブジェクトを説明する。
ノルムと条件数の推定は[1 ノルムの推定と作用素の厳密なノルム](../norm-estimation/)で扱う。
手法オブジェクト、作業領域の要件、所有値を返す API と出力先を指定する API、終了理由 `SpectralTermination` の共通の規約は[行列関数のベクトルへの適用と手法オブジェクト](oxref:linalg-action-conventions)にある。

## 部分 SVD

### 厚い再始動 Golub–Kahan 二重対角化

`PartialSvdSolver` は $m \times n$ の作用素 $A$ の大きい方から `count` 個の特異三つ組 $(\sigma_j, u_j, v_j)$（$Av_j = \sigma_j u_j$、$A^{\mathsf H}u_j = \sigma_j v_j$）を求める。
$A$ は積 $Ax$ と $A^{\mathsf H}y$ だけで使い、$A^{\mathsf H}A$ は作らない。
右の開始ベクトルから Golub–Kahan 二重対角化を進め、次元 $m_b$ までの正規直交基底 $V$、$U$ と上二重対角行列 $B$ で $AV = UB$ を作る。
新しいベクトルは基底全体に対して古典 Gram–Schmidt 法で直交化し、ノルムが $1/\sqrt 2$ 倍より小さくなったときはもう一度直交化する。
$B$ の SVD が Ritz 三つ組（射影した問題から作る近似の特異三つ組）を与える。
再始動では $\max(\text{count}, d/2)$ 本、ただし $d - 1$ 本以下の Ritz ベクトルを、残差との結合の係数とともに残す（Baglama と Reichel、2005 の拡大再始動）。
許容誤差をすでに満たした三つ組は先頭に残し、後の周期でも検査し直す。

三つ組は、$A$ と $A^{\mathsf H}$ との新しい積で計算した二つの残差がどちらも許容誤差を満たすときだけ受理する。

```text
max(‖A v − σ u‖₂, ‖Aᴴ u − σ v‖₂) ≤ τ_abs + τ_rel σ
```

片方の残差だけなら、悪い三つ組でも小さくなりうるためである。
この検査は最初と最後の周期、基底が不変になったとき、求める三つ組のどれかについて推定 $\beta \lvert e_{m_b}^{\mathsf T} \tilde u \rvert$ が許容誤差を満たした周期に行う（$\tilde u$ は $B$ の左特異ベクトル、$\beta$ は二重対角化を伸ばしたときの最後の係数）。
1 周期の計算コストは約 $2(m_b - \text{残した本数})$ 回の積と、検査する三つ組ごとの 2 回の積である。

### PartialSvdSolver の設定・結果・レポート

`PartialSvdSolver::new(count)` の既定は基底の次元 30（`with_basis`。
`count + 2` 以上か、$\min(m, n)$ 以上）、順と随伴を合わせた作用の回数 10 万回まで（残差の検査を含む）、許容誤差 $\tau_{\mathrm{abs}} = \tau_{\mathrm{rel}} = \sqrt{\varepsilon}$ である。
`count` が $\min(m, n)$ を超える設定は `InvalidInput`（`OutOfRange`）、基底の次元が足りない設定は `InvalidInput`（`Inconsistent`）になる。
実行オプションの反復の上限は再始動の周期を数え（既定 100 周期）、射影した行列の密な SVD は反復の上限なしで解く。

呼び出しは所有値を返す API `solve(&a, &initial)` か、出力先を指定する API `solve_into(&a, &initial, &mut buffer, &mut workspace, cx)` で、開始ベクトル `initial` は長さ $n$ の 0 でないベクトルである。
結果の `PartialSvdBuffer`（出力先を指定する API では `PartialSvdBuffer::new(m, n, count)` で用意する）は、降順の特異値 `singular_values()`、左特異ベクトルを列に持つ $m \times r$ の `left_vectors()`、右特異ベクトルを列に持つ $n \times r$ の `right_vectors()`（$V^{\mathsf H}$ ではなく $V$。
$r$ は返した三つ組の数）、三つ組ごとの二つの残差 `residuals()` を持つ。
求めた数より少ない三つ組しか入らないことがあり、すべてが許容誤差を満たすのは `Converged` のときだけである。
上限や取り消しで止まったときは、二つの残差を計算した直近の三つ組が入り、0 個のこともある。
レポート `PartialSvdReport` は終了理由、作用の回数、返した三つ組を計算した周期の番号 `cycles()`（1 から数え、なければ 0）を持つ。
作業領域 `PartialSvdWorkspace` は $O((m + n) m_b)$ のスカラーと射影した行列の SVD のメモリ領域を持ち、要件 `PartialSvdRequirements` で事前確保する。

### 特異値が既知の試験行列

結果を厳密な値と比べるため、特異値が既知の $m \times n$ 行列（$m = 200$、$n = 120$）を作る。
離散正弦変換の行列 $S^{(N)}_{ij} = \sqrt{2/(N+1)}\,\sin(ij\pi/(N+1))$ は直交行列なので、$U = S^{(m)}$ の先頭 $n$ 列と $V = S^{(n)}$ を使えば

```text
A = U diag(σ₁, …, σₙ) Vᵀ,   σⱼ = j^(−α)
```

の特異値は $\sigma_j$ そのものである。
$\alpha$ が大きいほど特異値は速く減る。
Eckart–Young–Mirsky の定理により、2 ノルムで最良のランク $k$ 近似は打ち切った SVD $A_k$ で、その誤差は $\lVert A - A_k \rVert_2 = \sigma_{k+1}$ である。

次の定義のブロックはこの試験行列を二つのセルで共有する。
`test_matrix` が $A$、`singular_value` が $\sigma_j$、`gaussian` がシードから作る標準正規分布の擬似乱数（xorshift64* と Box–Muller 法）、`truncation_error` が近似 $\tilde A = \sum_j \sigma_j u_j v_j^{\mathsf H}$ の誤差 $\lVert A - \tilde A \rVert_2$ を、差の密な SVD で求める検算に対応する。

```rust
//| id: linalg-low-rank-model
//| kind: definitions
//| title: 特異値が既知の試験行列と検算
//| crates: [scioxide-core, scioxide-linalg]
use scioxide_core::SciOxideError;
use scioxide_linalg::{Matrix, MatrixView, SpectralTermination, SvdValues};

/// 特異値 σⱼ = j^(−α)（参照値）。
pub(crate) fn singular_value(j: usize, alpha: f64) -> f64 {
    (j as f64).powf(-alpha)
}

/// A = U diag(σ) Vᵀ（m ≥ n）。U と V は正規直交な離散正弦変換の先頭 n 列。
pub(crate) fn test_matrix(m: usize, n: usize, alpha: f64) -> Result<Matrix<f64>, SciOxideError> {
    let pi = std::f64::consts::PI;
    let basis = |size: usize, i: usize, j: usize| {
        let scale = (2.0 / (size + 1) as f64).sqrt();
        scale * (pi * ((i + 1) * (j + 1)) as f64 / (size + 1) as f64).sin()
    };
    let mut a = Matrix::zeros(m, n)?;
    for (idx, value) in a.as_mut_slice().iter_mut().enumerate() {
        let (i, l) = (idx / n, idx % n);
        *value = (0..n)
            .map(|j| basis(m, i, j) * singular_value(j + 1, alpha) * basis(n, l, j))
            .sum();
    }
    Ok(a)
}

/// シードから作る標準正規分布の擬似乱数（xorshift64* と Box–Muller 法）。
pub(crate) fn gaussian(seed: u64, len: usize) -> Vec<f64> {
    let mut state = seed.wrapping_mul(0x9E37_79B9_7F4A_7C15) | 1;
    let mut uniform = move || {
        state ^= state >> 12;
        state ^= state << 25;
        state ^= state >> 27;
        ((state.wrapping_mul(0x2545_F491_4F6C_DD1D) >> 11) as f64 + 0.5) / (1u64 << 53) as f64
    };
    (0..len)
        .map(|_| {
            let (u, v) = (uniform(), uniform());
            (-2.0 * u.ln()).sqrt() * (2.0 * std::f64::consts::PI * v).cos()
        })
        .collect()
}

/// ランク r の近似 Ã = Σⱼ σⱼ uⱼ vⱼᴴ の誤差 ‖A − Ã‖₂ を、差の密な SVD の最大特異値として求める
/// （独立な検算）。`v` は列が vⱼ の n × r の行列。
pub(crate) fn truncation_error(
    a: &Matrix<f64>,
    u: MatrixView<'_, f64>,
    sigma: &[f64],
    v: MatrixView<'_, f64>,
) -> Result<f64, SciOxideError> {
    let n = a.cols();
    let mut difference = a.clone();
    for (idx, value) in difference.as_mut_slice().iter_mut().enumerate() {
        let (i, l) = (idx / n, idx % n);
        for (j, &s) in sigma.iter().enumerate() {
            *value -= u.get(i, j)? * s * v.get(l, j)?;
        }
    }
    Ok(SvdValues::compute(&difference)?.singular_values()[0])
}

/// 終了理由を列挙子の名前にする。
pub(crate) fn termination_name(termination: SpectralTermination) -> &'static str {
    match termination {
        SpectralTermination::Converged => "Converged",
        SpectralTermination::EvaluationLimit => "EvaluationLimit",
        SpectralTermination::IterationLimit => "IterationLimit",
        SpectralTermination::InvariantSubspace => "InvariantSubspace",
        SpectralTermination::AccuracyLimit => "AccuracyLimit",
        SpectralTermination::ExecutionStopped(_) => "ExecutionStopped",
    }
}
```

次のセルは上位 $k$ 個の特異三つ組を `PartialSvdSolver` の所有値を返す API で求める。
入力は減衰 $\alpha \in [0.5, 3]$、ランク $k \in [1, 10]$、基底の次元 $m_b \in [12, 40]$ である。
一つ目の表は三つ組ごとの厳密な $\sigma_j$、計算した値、相対誤差、二つの残差で、二つ目の表は終了理由、作用の回数、周期と、三つ組から作ったランク $k$ 近似の誤差 $\lVert A - \tilde A_k \rVert_2$ を最適な値 $\sigma_{k+1}$ と並べる。
$\alpha$ と $k$ と計算した特異値は、次の乱択 SVD のセルに渡す。

同じ $\alpha$ と $k$ でも基底の次元を既定の 30 に戻せば、第 2 周期・130 回で済む。

## 乱択低ランク近似

### 値域を捉えるスケッチ

`RandomizedLowRank` は Halko、Martinsson、Tropp（2011）の方法で、$A$ の値域を少数の試験ベクトルで捉えて低ランク近似を作る。
呼び出し側は $n \times w$ の試験行列 $\Omega$（スケッチ。
通常は成分が独立な標準正規分布）と、構成に使わない検査ベクトルを 1 本以上渡す。
`RandomizedLowRank` は乱数を生成しないので、同じ入力からは同じ結果が出て、スケッチの選び方と再現性は呼び出し側が決める。

方法は次の順で進む。

1. $A\Omega$ の値域の正規直交基底 $Q$ を Gram–Schmidt 法で作る。
   直交化の後のノルムが、直交化の前のノルムからランクの方針 `RankPolicy` で決まるしきい値以下になったベクトルは、従属とみなして捨てる。
2. 部分空間反復を $q$ 回行い、そのたびに $Q$ を $A(A^{\mathsf H}Q)$ の正規直交基底で置き換える。
3. 随伴の積で小さな行列 $Q^{\mathsf H}A$（$w \times n$ 以下）を作る。
4. `svd`/`svd_into` は $Q^{\mathsf H}A = \tilde U \Sigma V^{\mathsf H}$ を求めて $U = Q\tilde U$ とし、`interpolative`/`interpolative_into` は列ピボット付き QR $Q^{\mathsf H}AP = \tilde Q [R_{11}\ R_{12}]$ で $A$ の $r$ 列を選び、$Z = [I,\ R_{11}^{-1}R_{12}]P^{\mathsf T}$ として $A \approx CZ$ を作る（$C$ は選んだ列で、1 列ごとに 1 回の積 $Ae_j$ で計算する）。

計算コストは高々 $w(2q + 2)$ 回の積に、検査ベクトルごとに 1 回と、列補間分解では $r$ 回を加えた回数である。
結果のランク $r$ は目標のランク、$Q$ のランク、小さな分解のランクの方針による数値ランクの最小値である。
各検査ベクトル $g$ は残差 $\lVert Ag - \tilde Ag \rVert_2$ を与え、すべての $g$ で $\lVert Ag - \tilde Ag \rVert_2 \le \tau_{\mathrm{abs}} + \tau_{\mathrm{rel}} \lVert Ag \rVert_2$ なら `Converged`、そうでなければ `AccuracyLimit` になる。
検査ベクトルはスケッチと独立なので、その残差は近似の独立な検査になる。
ただし残差から言えるのは $\lVert (A - \tilde A)g \rVert_2 \le \lVert A - \tilde A \rVert_2 \lVert g \rVert_2$ による誤差の下界だけで、上界は得られない。

### 期待値の上界と部分空間反復

精度はスケッチの列数 $w = k + p$（ランク $k$ と余分の列 $p$）と特異値の減衰で決まる。
$\Omega$ の成分が独立な標準正規分布に従い $p \ge 2$ なら、部分空間反復なしで得た基底 $Q$ について

```text
E ‖A − Q Qᴴ A‖₂ ≤ (1 + √(k/(p − 1))) σₖ₊₁ + (e √(k + p) / p) (Σ_{j>k} σⱼ²)^{1/2}
```

が成り立つ（$e$ は自然対数の底。
Halko、Martinsson、Tropp、2011、定理 10.6）。
さらに $Q^{\mathsf H}A$ の SVD をランク $k$ に切り詰めた近似 $\tilde A_k$ は $\lVert A - \tilde A_k \rVert_2 \le \sigma_{k+1} + \lVert A - QQ^{\mathsf H}A \rVert_2$ を満たす（同、9.3 節）。
右辺の第 2 項は特異値がゆっくり減る行列で大きくなる。
$q$ 回の部分空間反復は $A$ の代わりに $(AA^{\mathsf H})^qA$ の値域を捉えるので、特異値が $\sigma_j^{2q+1}$ に変わって減衰が速まる。
このとき、上の右辺の $\sigma_j$ を $\sigma_j^{2q+1}$ に置き換えた値の $1/(2q+1)$ 乗が $E\lVert A - QQ^{\mathsf H}A \rVert_2$ の上界になる（同、系 10.10）。
これらは期待値の上界で、呼び出し側が正規乱数のスケッチを渡した場合にだけ当てはまり、1 回の結果が上界の内側に入る保証はないので、結果は検査ベクトルの残差で確かめる。

### RandomizedLowRank の設定・結果・レポート

`RandomizedLowRank::new(rank)` の既定はランクの方針 `RankPolicy::Exact`（`with_rank_policy`）、部分空間反復 0 回（`with_power_steps`）、作用の回数 10 万回まで、検査の許容誤差 $\tau_{\mathrm{abs}} = \tau_{\mathrm{rel}} = \sqrt{\varepsilon}$ である。
スケッチの列数 $w$ は呼び出しごとに `sketch.cols()` から読み、目標のランクが $w$ を超えるか、$w$ が $\min(m, n)$ を超えると `InvalidInput`（`OutOfRange`）、検査ベクトルが 0 本なら `InvalidInput`（`OutOfRange`）になる。
作業領域は `workspace(&a, w)` で用意し、`RandomizedLowRankWorkspace` は $O((m + n)w)$ のスカラーと小さな SVD と QR のメモリ領域を持つ（要件は `RandomizedLowRankRequirements`）。
`RandomizedSvdBuffer` は $m \times r$ の `u()`、$r \times n$ の `vt()`（$V^{\mathsf H}$）、降順の `singular_values()` を返し、`InterpolativeBuffer` は選んだ列 `columns()`、$r \times n$ の補間行列 `coefficients()`、列の番号 `column_indices()` を返す。
$Z$ の `column_indices()[j]` 番目の列は単位ベクトル $e_j$ なので、選んだ列は厳密に再現される。
レポート `LowRankReport` は終了理由、ランク `rank()`、検査の残差の最大 `probe_residual()` と相対残差の最大 `relative_probe_residual()`（$Ag = 0$ でない検査がなければ `None`）、残差を計算した検査の本数 `completed_probes()`、作用の回数を持つ。
上限や取り消しで止まったときは、近似の構成が終わっていれば出力に近似が入り、終わっていなければ 0（ランク 0）になる。
そのときの残差は完了した検査だけについての値で、完了した検査が 0 本なら残差の欄は 0 でも精度は分からない。

次のセルは前のセルの $\alpha$ と $k$ を受け取り、同じ試験行列のランク $k$ 近似を乱択 SVD で求める。
入力は余分の列 $p \in [2, 10]$、部分空間反復の回数 $q \in [0, 3]$、検査の相対許容誤差 $\tau_{\mathrm{rel}}$、乱数のシードである。
表は乱択 SVD の終了理由、作用の回数、誤差 $\lVert A - \tilde A_k \rVert_2$、上位 $k$ 個の特異値の相対誤差の最大、検査の相対残差、ランクを、最適な誤差 $\sigma_{k+1}$ と期待値の上界（$\sigma_{k+1}$ と $E\lVert A - QQ^{\mathsf H}A \rVert_2$ の上界の和）と並べる。
図は厳密な特異値（破線）と、部分 SVD と乱択 SVD で求めた特異値を対数軸で示す。

    .svd(&op, sketch.view(), probes.view())

誤差 $\lVert A - \tilde A_5 \rVert_2 = 0.0362$ は最適な $\sigma_6 = 0.0278$ の 1.3 倍で、期待値の上界 $0.163$ の内側にある。
一方、上位の特異値の相対誤差の最大は $0.18$ と大きく、`Converged` は検査の相対残差 $0.14$ が $\tau_{\mathrm{rel}} = 0.2$ を下回ったことだけを意味する。
$q = 2$ にすると作用は 62 回に増えるが、特異値の相対誤差は $4.3 \times 10^{-7}$ に下がり、誤差は $\sigma_6$ と相対 $3 \times 10^{-11}$ の差で並ぶ。
期待値の上界も $0.0642$ に下がり、$q$ を増やすと $2\sigma_6$ に近づく。
このほぼ最適な近似でも検査の相対残差は $0.13$ 残り、これは裾の特異値 $\sigma_6, \sigma_7, \dots$ が $Ag$ に寄与するためである。
そのため $\tau_{\mathrm{rel}} = 10^{-8}$ のように裾より小さい許容誤差を与えると、近似の良し悪しによらず `AccuracyLimit` になる。
シードを 2 にすると、誤差 $0.0281$ は最適な値にさらに近いが、検査の相対残差が $0.28$ に出て `AccuracyLimit` になる。
2 本の検査ベクトルによる判定はその向きに左右されるので、検査の残差は近似の独立な確認として解釈する。

## まとめ

`PartialSvdSolver` は Golub–Kahan 二重対角化で上位の特異三つ組を求め、左右の二つの残差がともに許容誤差を満たした三つ組だけを `Converged` として返す。
`RandomizedLowRank` は呼び出し側が渡すスケッチで値域を捉え、少ない積で低ランク近似を作るが、`Converged` は検査ベクトルの残差が基準を満たしたことだけを意味する。
特異値がゆっくり減る行列では、余分の列 $p$ と部分空間反復の回数 $q$ を増やして近似を最適な誤差 $\sigma_{k+1}$ に近づけ、増える積の回数は $w(2q + 2)$ で見積もる。
検査の許容誤差は特異値の裾の大きさに見合う値にし、2 本程度の検査の判定は検査ベクトルの向きにも左右されることを踏まえて読む。
上位の特異値そのものを正確に求めたいなら部分 SVD を、少ない積で値域を捉えたいなら乱択 SVD を選ぶ。
