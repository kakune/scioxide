二つのデータの向きを比べる、二つの観測行列を同時に対角化する、特異な系を自由度を固定して解く、といった問題では、行列そのものより、行列が張る部分空間とその関係が問題になる。
このページは SVD から作る部分空間の計算と、二つの行列を同時に扱う GSVD・CS 分解、行列を回転と伸縮に分ける極分解、呼び出し側が零空間を宣言した特異な系の解き方を説明する。
ランクの判定と特異値の摂動は[特異値分解・数値ランク・正則化解](../svd-and-rank/)の内容を前提にする。
呼び出しの形（標準形式、オプション付き形式、出力先を指定する API）と作業領域の要求は[作業領域・実行コンテキスト・試行記録](oxref:linalg-execution-forms)で定義する。

## 値域と零空間の基底

$A \in \mathbb{K}^{m \times n}$ の SVD $A = U \Sigma V^{\mathsf H}$ でランクを $r$ と判定すると、$U$ の先頭 $r$ 列が値域 $\mathcal{R}(A)$ の、$V$ の残りの $n - r$ 列が零空間 $\mathcal{N}(A)$ の正規直交基底になる。
`orth(&a, policy)` と `null_space(&a, policy)` はこの基底を `SubspaceBasis` で返し、列に並べた基底を `basis()` で、レポート `SubspaceReport` を `report()` で読む。
レポートは方針で選んだランク `rank()`（`RankReport`）と、しきい値によらない逆条件数 $\sigma_{\min}/\sigma_{\max}$ の `condition()` を持ち、特異値がなければ `condition()` は `None` である。
ランクは `RankPolicy` で決まり、方針を変えても SVD の結果は変わらない。
基底のベクトル自体は一意ではなく、同じ部分空間の別の正規直交基底でもよい。
$\sigma_r$ と $\sigma_{r+1}$ の隙間が小さいと、Wedin の定理により部分空間そのものが摂動に敏感になる。

`null_space` の結果 $Z$（$n \times (n - r)$）は $\lVert AZ \rVert_2 = \sigma_{r+1}$ を満たし、$r = m$ なら丸めの範囲で $AZ = 0$ である。
$m \ge n$ では薄い SVD から、横長の行列（$m < n$）では薄い SVD が省く $n - m$ 本の構造的な補空間を含めるため完全な SVD から求める。
左零空間（$A^{\mathsf H} z = 0$）は `a.adjoint()` を渡して求める。
出力先を指定する API `orth_into` と `null_space_into` は基底を呼び出し側の `Matrix` に書いてレポートを返し、作業領域の要件は `SubspaceBasisWorkspaceRequest::orth`、`null_space` の要求を `LinalgWorkspace::workspace_requirements` に渡して求める。
要求は最大のランクを想定して大きさを決めるので、同じ形のどの入力にも足りる。
入力の NaN や無限大は `NonFinite`、SVD の反復の上限は `ConvergenceFailure`、特異値のオーバーフローは `NumericalInstability` になる。

## 部分空間の主角

$\mathbb{K}^m$ の二つの部分空間 $\mathcal{V}, \mathcal{W}$（次元 $p \ge q$）の主角 $0 \le \theta_1 \le \dots \le \theta_q \le \pi/2$ は、

$$
\cos\theta_k = \max_{x \in \mathcal{V},\, y \in \mathcal{W}} \lvert x^{\mathsf H} y \rvert \quad (\lVert x \rVert_2 = \lVert y \rVert_2 = 1,\ x \perp x_1, \dots, x_{k-1},\ y \perp y_1, \dots, y_{k-1})
$$

で順に定める（$x_k, y_k$ は最大を与えるベクトル）。
正規直交基底 $Q_A, Q_B$ をとれば $x = Q_A a$、$y = Q_B b$ と書けるので、この問題は $Q_A^{\mathsf H} Q_B$ の双線形形式の最大化になり、特異値の min-max 特徴づけから

$$
Q_A^{\mathsf H} Q_B = Y \operatorname{diag}(\cos\theta_1, \dots, \cos\theta_q) Z^{\mathsf H}
$$

が従う（Björck–Golub）。
$p = q$ のとき、最大の主角は二つの部分空間の距離 $\lVert P_{\mathcal{V}} - P_{\mathcal{W}} \rVert_2 = \sin\theta_{\max}$ を与える（$P$ は直交射影）。

小さな角では $\cos\theta \approx 1 - \theta^2/2$ のため、余弦から角を戻すと $\theta \lesssim \sqrt{\varepsilon}$ の情報が丸めで失われる（$\varepsilon$ は機械イプシロン）。
`scioxide-linalg` は、45° より小さい角があるときだけ、補空間への射影 $(I - Q_L Q_L^{\mathsf H}) Q_S$（$Q_L$ は次元の大きい方の基底、$Q_S$ は小さい方）の特異値として正弦も求め、各角を余弦と正弦のうち条件のよい方から戻す（Knyazev–Argentati）。
基底 $Q_A, Q_B$ はそれぞれの列空間を方針で選んだランクで切った SVD から作る。

`subspace_angles(&a, &b, policy)` は、二つの行列の列空間の主角をラジアンで返す `SubspaceAngles` を返す。
角は `angles()` で読み、上の定義とは逆に大きい順に並ぶ。
個数は $\min(\operatorname{rank} A, \operatorname{rank} B)$ で、どちらかのランクが 0 なら空になる。
`report()` が返す `SubspaceAnglesReport` は、二つの入力をどう解釈したかを `first()` と `second()` の `SubspaceReport` で持つ。
角の個数が予想より少ないときは、このレポートでどちらの入力のランクが落ちたかを確かめる。
出力先を指定する API `subspace_angles_into(&a, &b, policy, &options, &mut angles, &mut workspace, context)` は角を呼び出し側の `Vec` に書き、同じ `SubspaceAnglesReport` を返す。
作業領域の要件は `SubspaceAnglesWorkspaceRequest::new(rows, first_cols, second_cols, &options)` から求める。
出力の容量は計算の前に $\min(m, n_A, n_B)$ 個まで確保され、作業領域と出力の容量が足りていれば呼び出しは確保をしない。
SVD は最大 4 回（二つの値域、基底の交差積、必要なときの補空間の残差）行い、各 SVD は反復の上限の子のスコープに数える。
行数の違う入力は `DimensionMismatch`、SVD の上限は `ConvergenceFailure` になり、失敗したときは出力の値を変えない。

## 直交 Procrustes 問題

二組の点の座標 $A, B \in \mathbb{R}^{n \times 3}$ を直交変換で重ね合わせる問題は、$R^{\mathsf H} R = I$ の制約のもとで $\lVert AR - B \rVert_F$ を最小にする直交 Procrustes 問題である。
$\lVert AR - B \rVert_F^2 = \lVert A \rVert_F^2 + \lVert B \rVert_F^2 - 2 \operatorname{Re} \operatorname{tr}(R^{\mathsf H} A^{\mathsf H} B)$ なので、跡を最大にすればよい。
$A^{\mathsf H} B = U \Sigma V^{\mathsf H}$ とすると $\operatorname{tr}(R^{\mathsf H} U \Sigma V^{\mathsf H}) = \operatorname{tr}(W \Sigma)$（$W = V^{\mathsf H} R^{\mathsf H} U$ はユニタリで $\lvert w_{ii} \rvert \le 1$）である。
その実部 $\sum_i \sigma_i \operatorname{Re} w_{ii}$ は $\operatorname{tr} \Sigma$ 以下で、等号は $W = I$、つまり $R = U V^{\mathsf H}$ で成り立つ。
$\Sigma$ が正則なら最小解は一意で、0 の特異値があるとその方向の $W$ の成分が自由になり、解は一意でなくなる。
制約は直交性だけなので、解は回転（$\det R = 1$）とは限らない。
点が一つの平面上にあるときは鏡映を含む解も同じ残差を与えるが、`scioxide-linalg` は Kabsch の方法のように $\det R = 1$ を課すことはしない。

`orthogonal_procrustes(&a, &b, policy)` は `ProcrustesAlignment` を返し、右から掛ける変換を `transformation()` で、レポート `ProcrustesReport` を `report()` で読む。
レポートは $A$、$B$、計算した $R$ から独立に計算した残差 `residual_norm()`、交差積 $A^{\mathsf H} B$ のランクと条件数 `cross_product()`、特異値の和 $\sum_i \sigma_i(A^{\mathsf H} B)$ の `scale()`、一意性 `uniqueness()` を持つ。
`scale()` は目的関数の最大値を表す診断で、結果に掛ける倍率ではない。
一意性の値 `ProcrustesUniqueness` は次の三つで、方針は判定にだけ使い、解を切り詰めない。

- `Unique`：交差積の特異値がどれも 0 でなく、方針もすべてを残す。
- `NumericallyUnresolved`：0 の特異値はないが、方針が少なくとも一つを 0 とみなす。
- `Nonunique`：計算した特異値に厳密な 0 があり、最小解が一意でない。

出力先を指定する API `orthogonal_procrustes_into(&a, &b, policy, &options, &mut r, &mut workspace, context)` は列数 × 列数の変換を呼び出し側の `Matrix` に書き、同じ `ProcrustesReport` を返す。
要件は `ProcrustesWorkspaceRequest::new(rows, cols, &options)` から求め、大きさは $O(\text{cols}^2)$ で、残差は 256 行ずつのブロックで作る。
$A, B$ が $m \times n$ のとき、計算量は積に $O(m n^2)$、SVD（1 回）に $O(n^3)$ である。
形の違う入力は `DimensionMismatch`、NaN や無限大を含む入力は `NonFinite`、交差積かその特異値の和がオーバーフローする入力は `NumericalInstability`、SVD の反復の上限は `ConvergenceFailure` になる。

次のセルは 8 個の点を軸 $(1, 1, 1)/\sqrt{3}$ のまわりに $\theta$ だけ回し、相対 $10^{e}$ のノイズを加えた点群 $B$ から回転を出力先を指定する API で推定する。
同じ作業領域で $A$ と $B$ の列空間の主角も求めるので、二つの要求の要件の大きい方（`LinalgRequirements::max`）で作業領域を一度だけ確保する。
$R$ は正則なので $AR$ の列空間は $A$ の列空間と同じで、主角は回転角によらずノイズだけで決まる。
入力は回転角 $\theta$（0° から 180°）、ノイズの指数 $e$（$-14$ から $-1$）、点を平面 $z = 0$ に置く切り替えである。
一つ目の表は Rodrigues の公式で作った真の回転との差、$\det R$、残差、交差積のランク、一意性を示す。
二つ目の表は `SubspaceAnglesReport` の二つの入力のランクと逆条件数、三つ目の表は主角を大きい順に並べる。

```rust
//| id: linalg-procrustes-registration
//| ref: linalg-procrustes-registration
//| title: 直交 Procrustes 問題による点群の回転の推定
//| run: reactive
//| crates: [scioxide-core, scioxide-linalg]
//| inputs:
//|   angle: {"type":"range","label":"回転角 θ [deg]","description":"軸 (1, 1, 1)/√3 のまわりの回転角。","min":0,"max":180,"step":5,"value":40}
//|   noise_exponent: {"type":"range","label":"ノイズの大きさ 10^e の e","description":"回転後の座標に加えるノイズの相対的な大きさ。","min":-14,"max":-1,"step":1,"value":-6}
//|   planar: {"type":"checkbox","label":"点を平面 z = 0 に置く","description":"交差積のランクが 2 になり、解が一意でなくなる。","value":false}
//| cases:
//|   - {"id":"planar","label":"平面上の点","description":"A と交差積のランクが 2 に落ち、一意性が Nonunique になる。","inputs":{"planar":true}}
//|   - {"id":"large-noise","label":"e = −1","description":"ノイズが大きいと、回転の誤差と主角が 0.1 程度まで増える。","inputs":{"noise_exponent":-1}}
//|   - {"id":"planar-half-turn","label":"平面上の点、θ = 180°、e = −14","description":"残差が丸めの水準のまま、det R = −1 の鏡映が返る。","inputs":{"planar":true,"angle":180,"noise_exponent":-14}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"alignment","path":"/rows/0/0","range":{"max":2e-6}}
//|       - {"artifact":"alignment","path":"/rows/0/1","approx":{"value":1,"rtol":1e-12}}
//|       - {"artifact":"alignment","path":"/rows/0/4","equals":"Unique"}
//|       - {"artifact":"ranks","path":"/rows/0/1","equals":3}
//|       - {"artifact":"angles","path":"/rows/0/1","range":{"max":1e-5}}
//|   - case: planar
//|     expect:
//|       - {"artifact":"alignment","path":"/rows/0/3","equals":2}
//|       - {"artifact":"alignment","path":"/rows/0/4","equals":"Nonunique"}
//|       - {"artifact":"ranks","path":"/rows/0/1","equals":2}
//|       - {"artifact":"ranks","path":"/rows/1/1","equals":3}
//|       - {"artifact":"angles","path":"/rows/1/1","range":{"max":1e-5}}
//|   - case: large-noise
//|     expect:
//|       - {"artifact":"alignment","path":"/rows/0/0","range":{"min":1e-2,"max":0.2}}
//|       - {"artifact":"angles","path":"/rows/0/1","range":{"min":0.05,"max":0.5}}
//|   - case: planar-half-turn
//|     expect:
//|       - {"artifact":"alignment","path":"/rows/0/1","approx":{"value":-1,"rtol":1e-12}}
//|       - {"artifact":"alignment","path":"/rows/0/2","range":{"max":1e-12}}
//|       - {"artifact":"alignment","path":"/rows/0/4","equals":"Nonunique"}
use scioxide_core::ExecutionContext;
use scioxide_linalg::{
    LinalgExecutionOptions, LinalgWorkspace, Matrix, ProcrustesUniqueness,
    ProcrustesWorkspaceRequest, RankPolicy, SubspaceAnglesWorkspaceRequest,
    orthogonal_procrustes_into, subspace_angles_into,
};

let n = 8_usize;
let point = |i: usize| -> [f64; 3] {
    let t = i as f64;
    let z = if planar { 0.0 } else { 0.3 * t - 1.0 };
    [(1.3 * t).cos() + 0.2 * t, (0.7 * t).sin() - 0.5, z]
};
// Rodrigues の公式で作った真の回転（f64 の標準関数は参照値の作成にだけ使う）。
let (c, s) = (angle.to_radians().cos(), angle.to_radians().sin());
let k = [1.0 / 3.0_f64.sqrt(); 3];
let cross = [[0.0, -k[2], k[1]], [k[2], 0.0, -k[0]], [-k[1], k[0], 0.0]];
let r_true: Vec<f64> = (0..9)
    .map(|idx| {
        let (i, j) = (idx / 3, idx % 3);
        (if i == j { c } else { 0.0 }) + (1.0 - c) * k[i] * k[j] + s * cross[i][j]
    })
    .collect();
let a: Vec<f64> = (0..n).flat_map(point).collect();
let noise = 10.0_f64.powf(noise_exponent);
// B = A R_trueᵀ（点は行ベクトル）に決定論的なノイズを加える。
let b: Vec<f64> = (0..n * 3)
    .map(|idx| {
        let (p, j) = (idx / 3, idx % 3);
        let rotated: f64 = (0..3).map(|m| a[p * 3 + m] * r_true[j * 3 + m]).sum();
        rotated + noise * (((idx * 37) % 17) as f64 / 8.0 - 1.0)
    })
    .collect();
let am = Matrix::from_vec(n, 3, a).map_err(|e| e.to_string())?;
let bm = Matrix::from_vec(n, 3, b).map_err(|e| e.to_string())?;
let (options, policy) = (
    LinalgExecutionOptions::new(),
    RankPolicy::DimensionScaledEpsilon,
);
// 出力先を指定する API: 二つの要求の要件の大きい方で作業領域を一度だけ確保する。
let procrustes_request = ProcrustesWorkspaceRequest::new(n, 3, &options);
let angles_request = SubspaceAnglesWorkspaceRequest::new(n, 3, 3, &options);
let requirements = LinalgWorkspace::<f64>::workspace_requirements(&procrustes_request)
    .map_err(|e| e.to_string())?
    .max(
        &LinalgWorkspace::<f64>::workspace_requirements(&angles_request)
            .map_err(|e| e.to_string())?,
    );
let mut workspace = LinalgWorkspace::<f64>::new();
workspace
    .try_reserve(&requirements)
    .map_err(|e| e.to_string())?;
let mut r_hat = Matrix::empty();
let report = orthogonal_procrustes_into(
    &am,
    &bm,
    policy,
    &options,
    &mut r_hat,
    &mut workspace,
    ExecutionContext::sequential_native(),
)
.map_err(|e| e.to_string())?;
let mut angles = Vec::new();
let angle_report = subspace_angles_into(
    &am,
    &bm,
    policy,
    &options,
    &mut angles,
    &mut workspace,
    ExecutionContext::sequential_native(),
)
.map_err(|e| e.to_string())?;

let r = r_hat.as_slice();
// 推定した R は右から掛けるので、真の回転の転置と比べる。
let difference = (0..9)
    .map(|idx| (r[idx] - r_true[(idx % 3) * 3 + idx / 3]).powi(2))
    .sum::<f64>()
    .sqrt();
let det = r[0] * (r[4] * r[8] - r[5] * r[7]) - r[1] * (r[3] * r[8] - r[5] * r[6])
    + r[2] * (r[3] * r[7] - r[4] * r[6]);
let uniqueness = match report.uniqueness() {
    ProcrustesUniqueness::Unique => "Unique",
    ProcrustesUniqueness::NumericallyUnresolved => "NumericallyUnresolved",
    ProcrustesUniqueness::Nonunique => "Nonunique",
};
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let alignment = serde_json::json!([
    { "key": "0", "label": "‖R − R_trueᵀ‖_F [-]", "type": "number", "format": sci2 },
    { "key": "1", "label": "det R [-]", "type": "number", "format": { "fractionDigits": 6 } },
    { "key": "2", "label": "残差 ‖AR − B‖_F [-]", "type": "number", "format": sci2 },
    { "key": "3", "label": "交差積のランク", "type": "integer" },
    { "key": "4", "label": "一意性" }
]);
let rank = report.cross_product().rank().rank();
emit_table_with_columns!(
    alignment,
    vec![(difference, det, report.residual_norm(), rank, uniqueness)],
    metadata = serde_json::json!({ "id": "alignment" })
);
let inputs = serde_json::json!([
    { "key": "0", "label": "入力" },
    { "key": "1", "label": "列空間のランク", "type": "integer" },
    { "key": "2", "label": "σ_min/σ_max [-]", "type": "number", "format": sci2, "nullText": "なし" }
]);
let rows: Vec<(&str, usize, Option<f64>)> =
    [("A", angle_report.first()), ("B", angle_report.second())]
        .into_iter()
        .map(|(name, input)| {
            (
                name,
                input.rank().rank(),
                input.condition().map(|c| c.reciprocal().value()),
            )
        })
        .collect();
emit_table_with_columns!(
    inputs,
    rows,
    metadata = serde_json::json!({ "id": "ranks" })
);
let angle_columns = serde_json::json!([
    { "key": "0", "label": "番号 k", "type": "integer" },
    { "key": "1", "label": "主角 θ_k [rad]", "type": "number", "format": sci2 }
]);
let angle_rows: Vec<(usize, f64)> = angles
    .iter()
    .enumerate()
    .map(|(i, &t)| (i + 1, t))
    .collect();
emit_table_with_columns!(
    angle_columns,
    angle_rows,
    metadata = serde_json::json!({ "id": "angles" })
);
```

既定の $\theta = 40^\circ$、$e = -6$ では、推定した $R$ と真の回転の差は $5.2 \times 10^{-7}$、残差は $2.8 \times 10^{-6}$ で、どちらもノイズの大きさの程度である。
$\det R = 1$ なので推定は回転になっており、交差積のランクが 3 なので一意性は `Unique` である。
主角は $2.1 \times 10^{-6}$、$7.5 \times 10^{-7}$、$1.5 \times 10^{-7}$ で、ノイズがなければ 0 になる角がノイズの大きさで決まっている。
$e = -1$ では差が 0.052、残差が 0.28、最大の主角が 0.20 rad まで増える。

点を平面 $z = 0$ に置くと、$A$ のランクと交差積のランクが 2 に落ちて一意性は `Nonunique` になり、$A$ の逆条件数は 0 になる。
$B$ はノイズのために第 3 方向にも $10^{-6}$ 程度の成分を持ち、ランク 3（逆条件数 $3.6 \times 10^{-7}$）と判定されるので、主角は小さい方のランクの 2 個だけになる。
既定の角ではこのとき返る $R$ も $\det R = 1$ だが、平面に垂直な方向を反転した鏡映も同じ残差を与え、どちらを返すかは問題からは決まらない。
実際、$\theta = 180^\circ$、$e = -14$ では残差 $2.9 \times 10^{-14}$ のまま $\det R = -1$ の鏡映が返り、真の回転との差は 2 になる。
回転だけが意味を持つ問題で一意性が `Unique` でなければ、$\det R$ を確かめる。

## 一般化特異値分解

同じ未知数 $x \in \mathbb{K}^n$ に二つの行列 $A \in \mathbb{K}^{m \times n}$、$B \in \mathbb{K}^{p \times n}$ が作用する問題、たとえば一般化 Tikhonov 正則化 $\min \lVert Ax - b \rVert_2^2 + \lambda \lVert Bx \rVert_2^2$ では、二つを同時に対角化する GSVD（一般化特異値分解）を使う。
`GsvdDecomposition` は、入力を共通の尺度 $s$（`input_scale()`、$A$ と $B$ の成分の最大絶対値、両方 0 なら 1）で正規化したうえで

$$
A / s = U D_1 \begin{bmatrix} 0 & R \end{bmatrix} Q^{\mathsf H}, \qquad B / s = V D_2 \begin{bmatrix} 0 & R \end{bmatrix} Q^{\mathsf H}
$$

を求める（$U, V, Q$ はユニタリ、$R$ は $r \times r$ の正則な上三角、$r$ は $[A; B]/s$ の数値ランク）。
$D_1$（$m \times r$）と $D_2$（$p \times r$）の各列は 0 でない成分を高々一つ持ち、その組 $(\alpha_j, \beta_j)$ は $\alpha_j^2 + \beta_j^2 = 1$ を満たす。
`GeneralizedSingularValue` はこの組を割り算をせずに保持し、`alpha()` と `beta()` で読む。
比 $\alpha_j / \beta_j$（`ratio()`）が一般化特異値で、その二乗は共通零空間（後述）を除いた方向で行列束 $A^{\mathsf H} A - \lambda B^{\mathsf H} B$ の固有値に当たるが、GSVD はこの積を作らずに求める。
$\beta_j = 0$ の方向は無限大の値で `ratio()` は `DomainError` になり、比がオーバーフローすれば `NumericalInstability` になる。
$[A; B]$ のランク落ちに当たる方向は共通零空間 $\mathcal{N}(A) \cap \mathcal{N}(B)$ で、$Q$ の先頭 $n - r$ 列が張り、`common_null_space()` がその基底を返す。
`generalized_values()` は $D_1$、$D_2$ の列の順（$R$ の行の順）に並び、大きさの順ではない。

`GsvdDecomposition::factor(&a, &b)` は $[A; B]/s$ のランクを `RankPolicy::Exact` で選ぶ標準形式で、オプション付き形式 `factor_with_options(&a, &b, &GsvdOptions::new(policy))` が方針と実行の設定を受け取る（`GsvdOptions::default()` は `Exact` を選ぶ）。
アルゴリズムはまず、積み重ねた行列の薄い SVD $[A; B]/s = W \Sigma Z^{\mathsf H}$ で共通の行空間とランク $r$ を決める。
次に $W$ の先頭 $r$ 列を $A$ の行に当たるブロック $W_A$ と $B$ の行に当たるブロック $W_B$ に分け、行の少ない方のブロックの右特異ベクトルで両方の列を回す。
$W_A^{\mathsf H} W_A + W_B^{\mathsf H} W_B = I$ なのでこの回転は二つのブロックの Gram 行列を同時に対角化し、両方の列が丸めの範囲で直交になる。
そのあと二つのブロックにまたがる Jacobi 回転の掃引（通常 1、2 回）で $A$ 側と $B$ 側の列をそれぞれ直交に仕上げ、$U D_1$ と $V D_2$ を得る。
最後に、残った右の因子の RQ 分解で $[0\ R]\, Q^{\mathsf H}$ を作る。
Gram 行列や逆行列は作らず、再構成の残差が捨てた特異値のノルムと丸めの許容量の和以下であることを確かめてから因子を出力に反映し、超えれば `NumericalInstability` になる。
反復の上限には積み重ねた SVD に 1 回分、各掃引に 1 回分を数え、上限を指定しなければ最大 40 回掃引する。
上限は `GsvdOptions::with_execution_options` に渡す `LinalgExecutionOptions::with_iteration_budget` で変えられ、入れ子の二つの SVD の反復はそれぞれ子のスコープに数え、同じ上限で抑える。
レポート `GsvdReport` は積み重ねた行列のランク `rank()`、逆条件数 `condition()`、残した部分の逆条件数 $\sigma_r/\sigma_1$ の `retained_reciprocal_condition()`、捨てた特異値の大きさ $(\sum_{i>r} \sigma_i^2)^{1/2}$ の `discarded_norm()`、$A$ と $B$ の再構成誤差 `residual_a()`、`residual_b()`（正規化した単位の Frobenius ノルム）、掃引の回数 `sweeps()` を持つ。
これらは計算した推定値で、証明された限界ではない。
`report()` は一度も計算していない空の結果では `None` を返す。
出力先を指定する API `factor_into` の作業領域は `GsvdWorkspaceRequest::new(m, p, n, &options)` から求める。

次のセルは有限の比・無限の比・共通零空間をそれぞれ一方向ずつ持つ

$$
A = s \begin{bmatrix} a & 0 & 0 \\ 0 & 1 & 0 \end{bmatrix}, \qquad
B = s \begin{bmatrix} 4 & 0 & 0 \\ 0 & 0 & 0 \end{bmatrix}
$$

の GSVD を、共通の倍率 $s = 10^{k}$ を変えて計算する。
入力は係数 $a$（1 から 5）と倍率の指数 $k$（$-100$ から $100$）で、ランクの方針は `DimensionScaledEpsilon` である。
有限の比は $a/4$、無限の比は第 2 方向、共通零空間は $e_3$ で、一つ目の表は組 $(\alpha, \beta)$ と比を、二つ目の表は共通零空間の基底 $z$ について積で独立に求めた $\max(\lVert Az \rVert_\infty, \lVert Bz \rVert_\infty)/s$ とレポートの値を示す。

## CS 分解と極分解

CS 分解は、$2 \times 2$ のブロックに分けたユニタリ行列 $X$ を

$$
X = \begin{bmatrix} U_1 & \\ & U_2 \end{bmatrix} \begin{bmatrix} C & -S \\ S & C \end{bmatrix} \begin{bmatrix} V_1 & \\ & V_2 \end{bmatrix}^{\mathsf H}, \qquad C = \operatorname{diag}(\cos\theta_i),\ S = \operatorname{diag}(\sin\theta_i)
$$

と分ける（単位行列のブロックを含む一般の形は省略した）。
GSVD の中核にある分解で、角 $\theta_i$ は $X$ の先頭 $q$ 列が張る部分空間と、先頭 $p$ 行の座標部分空間との主角に当たる。
`CsdDecomposition::factor(&x, p, q)` は境界 $p, q$ で分けた $n \times n$ の $X$ を分解する標準形式で、オプション付き形式 `factor_with_options` は `LinalgExecutionOptions` を受け取る。
分解は角 `angles()`（昇順）、余弦 `cosines()`、正弦 `sines()`、四つのユニタリ因子 `u1_matrix()`、`u2_matrix()`、`v1_matrix()`、`v2_matrix()`、中央の行列 `cs_matrix()` を返す。
アルゴリズムは先頭 $q$ 列を、上の $p$ 行と下の $n - p$ 行のうち行の少ない方のブロックの右特異ベクトルで回して、両方のブロックの列を丸めの範囲で直交にする。
この回転がないと、行の少ない方のブロックの行数が $q$ より少ない場合にその Gram 行列が重複した固有値 0 を持ち、Jacobi 法の掃引が一次収束になる。
そのあと片側 Jacobi 法の掃引（通常 1、2 回）で上下のブロックのそれぞれの列が直交するまで仕上げ、ブロックの列ノルムから余弦と正弦を作る（小さな値でも相対精度を保つ）。
$V_2$ は 2 回目の Jacobi 反復を使わずに残りの列から求め、SVD と各掃引の計算量は $O(nq^2)$ である。
入力のユニタリ性は $\lVert X^{\mathsf H} X - I \rVert_F \le 32 n \varepsilon$ で検査し、満たさなければ `InvalidInput` になる。
因子は再構成誤差と各因子の直交性誤差が $128 n \varepsilon$ 以下のときだけ出力に反映し、超えれば `NumericalInstability` になる。
掃引の上限は GSVD と同じく既定で 40 回（準備に 1 回分を数える）で、入れ子の SVD の反復も子のスコープで同じ上限に抑え、どちらかが上限に達すると `ConvergenceFailure` になる。
レポート `CsdReport` は入力のユニタリ性の誤差 `input_unitarity_error()`、再構成誤差 `residual()`、直交性誤差（四つの因子のうち最大）`orthogonality_error()`、掃引の回数 `sweeps()` を、因子から計算し直した推定値として持つ。

極分解は $A = UH$（`PolarSide::Right`）または $A = HU$（`PolarSide::Left`）の形で、$U$ は $m \ge n$ なら正規直交な列、$m < n$ なら正規直交な行を持ち、$H$ は Hermitian 半正定値である。
薄い SVD $A = U_k \Sigma_k V_k^{\mathsf H}$ から $U = U_k V_k^{\mathsf H}$ と、`Right` なら $H = V_k \Sigma_k V_k^{\mathsf H} = (A^{\mathsf H} A)^{1/2}$、`Left` なら $H = U_k \Sigma_k U_k^{\mathsf H} = (A A^{\mathsf H})^{1/2}$ で求まり、$U$ は Frobenius ノルムで $A$ に最も近い正規直交行列になる。
$H$ は一意で、$U$ は $A$ のランクが $k$ のときだけ一意である。
`PolarDecomposition::factor(&a, side)` は `RankPolicy::Exact` で診断する標準形式で、オプション付き形式 `factor_with_options(&a, side, &PolarOptions::new(policy))` が方針を受け取る（`PolarOptions::default()` は `Exact`）。
入力は成分の最大絶対値 $s$（`input_scale()`）で割ってから SVD にかけ、$H$ はあとで $s$ を掛ける。
$H$ は上三角だけを計算して実の対角で写すので、厳密に Hermitian である。
$\tau = 128 \max(m, n)\, \varepsilon$ として、残差が $\tau \lVert A/s \rVert_F$ 以下で $U$ の直交性の誤差が $\tau$ 以下のときだけ因子を出力に反映し、超えれば `NumericalInstability` になる。
`PolarReport` は再構成誤差 `residual()`（$\lVert A - UH \rVert_F / s$）、直交性の誤差 `orthogonality_error()`、ランク `rank()` と逆条件数 `condition()`、方針で選んだランクが $k$ より小さく $U$ の補完が一意でないかどうか（`completion_nonunique()`）を残す。
ランクの方針は診断にだけ使い、因子を切り詰めない。
計算量は薄い SVD と、因子を作って再構成を確かめる $O(mnk + h^2 k + mnh)$ で（`Right` なら $h = n$、`Left` なら $h = m$）、因子は SVD の作業領域のほかに $O(mn + h^2)$ のスカラーを占める。

## 零空間を宣言した特異な系

純 Neumann 境界の Poisson 方程式や浮いた構造物の剛体運動のように、係数行列が特異であることと、その零空間が物理的に分かっている問題がある。
左と右の零空間の正規直交基底 $L, R \in \mathbb{K}^{n \times k}$（$A^{\mathsf H} L = 0$、$A R = 0$）が分かれば、拡大系

$$
\begin{bmatrix} A & L \\ R^{\mathsf H} & 0 \end{bmatrix} \begin{bmatrix} x \\ \mu \end{bmatrix} = \begin{bmatrix} b \\ c \end{bmatrix}
$$

は、$L$ と $R$ が零空間全体を張るなら正則になる。
第 1 式に $L^{\mathsf H}$ を掛けると $L^{\mathsf H} A = 0$ から $\mu = L^{\mathsf H} b$ が従うので、$\mu$ は $b$ のうち値域の外にある成分を表す。
$b$ が適合する（$L^{\mathsf H} b = 0$）なら $\mu = 0$ で、$x$ は $Ax = b$ を満たし、第 2 式 $R^{\mathsf H} x = c$ が解の自由度（ゲージ）を固定する。

`BorderedSystem::new(&operator, left, right, operator_scale, &BorderedSystemOptions::default())` は、作用素と `BlockVectorView`（scioxide-core）で渡した $L, R$ を借りて拡大系を作る。
作成時に、各基底が正規直交であることと、各列で $\lVert A r_j \rVert_2$ と $\lVert A^{\mathsf H} l_j \rVert_2$ が $\mathrm{atol} + \mathrm{rtol} \cdot$ `operator_scale` 以下であることを、検証の許容誤差（`with_validation_tolerance`、既定は $\mathrm{atol} = \mathrm{rtol} = \sqrt{\varepsilon}$）で検査する。
`operator_scale` は呼び出し側が与える $\lVert A \rVert$ の見積もりである。
基底が零空間全体を張るかどうかは検査できず、不完全な基底では拡大系が特異のまま残る。
$k = 0$、$k > n$、負の `operator_scale`、検査に通らない基底は `InvalidInput`、形の不一致は `DimensionMismatch` で、$2k$ 本の列の検査は反復の上限に 1 回ずつ数える。
実行コンテキストを渡す作成は `build` で、コンテキストは拡大系に保持しない。

`augmented()` は拡大系を、行列を作らない作用素 `BorderedSystemOperator`（次数 $n + k$、随伴は $[A^{\mathsf H}\ R;\ L^{\mathsf H}\ 0]$）として返す。
1 回の作用は $A$ か $A^{\mathsf H}$ を 1 回作用させ、縁の部分に $O(nk)$ の計算を加えるので、反復法にそのまま渡せる。
`prepare_rhs(&b, &c, policy)` は長さ $n + k$ の右辺 $[\hat b; c]$ を作る。
`CompatibilityPolicy::RequireCompatible` では $\hat b = b$ のままで、$\lVert L^{\mathsf H} b \rVert_2$ が適合の許容誤差（`with_compatibility_tolerance`、既定は $\sqrt{\varepsilon}$）による $\mathrm{atol} + \mathrm{rtol} \lVert b \rVert_2$ を超えると `DomainError` を返す。
`CompatibilityPolicy::Project` は値域への射影 $\hat b = b - L L^{\mathsf H} b$ で置き換える。
`diagnose(&b, &prepared, &x)` が返す `BorderedSystemDiagnostics` は、渡した基底の列数 $k$（`nullity()`、計算したランクではない）と、元の系について計算し直した $\lVert L^{\mathsf H} b \rVert_2$（`compatibility_defect()`）、$\lVert b - \hat b \rVert_2$（`projection_norm()`）、$\lVert Ax - b \rVert_2$（`original_residual_norm()`）、$\lVert Ax - \hat b \rVert_2$（`projected_residual_norm()`）、$\lVert R^{\mathsf H} x - c \rVert_2$（`gauge_defect()`）を持つ。
出力先を指定する API `prepare_rhs_into` と `diagnose_scoped` の作業領域は `workspace_requirements(BorderedSystemWorkspaceRequest::PrepareRhs)`（$n + 2k$ 個のスカラー）と `Diagnose`（$3n$ 個と作用素の作業量）から求める。

次のセルは支えのない 8 個の質点を剛性 $k_s = 2000$ N/m のばねで直列につないだばね鎖の静的なつり合い $Ku = f$ を解く。
剛性行列 $K = k_s G$（$G$ は 8 頂点の道グラフのラプラシアン行列）は対称で、剛体の並進 $r = (1, \dots, 1)/\sqrt{8}$ が左右の零空間を張るので、$L = R = r$ とおく。
$Ku = f$ が解を持つのは合力が $\sum_i f_i = 0$（$L^{\mathsf T} f = 0$）のときで、そのとき $u$ は並進を除いて決まるので、ゲージ条件 $r^{\mathsf T} u = 0$（重心の変位 0）で固定する。
荷重は両端を $\mp 10$ N で引く力に、節点 3 の追加の力 $\delta$ を加えたもので、入力は $\delta$（$-5$ から $5$ N）と値域の外の成分の扱いである。
拡大系は対称な不定値行列なので MINRES（`MinresSolver`）で解く。
独立な参照は、節点 $0$ から $i$ までの力のつり合いからばね $i$ の張力が $-\sum_{j \le i} \hat f_j$ になることを使い、$u_{i+1} = u_i - \frac{1}{k_s} \sum_{j \le i} \hat f_j$ を順に求めて平均を引いた変位である。
二つの表は変位と `BorderedSystemDiagnostics` の値を示し、MINRES の終了理由をセルの結論にする。
`RequireCompatible` で荷重が拒否された場合は、outcome を failed にする。

```rust
//| id: linalg-bordered-spring-chain
//| ref: linalg-bordered-spring-chain
//| title: 浮いたばね鎖の拡大系とゲージ条件
//| run: reactive
//| crates: [scioxide-core, scioxide-linalg]
//| inputs:
//|   imbalance: {"type":"range","label":"節点 3 の追加の力 δ [N]","description":"0 でなければ合力が 0 にならず、つり合いの条件 Σf = 0 が崩れる。","min":-5,"max":5,"step":0.5,"value":0}
//|   compatibility: {"type":"select","label":"値域の外の成分の扱い","options":["RequireCompatible","Project"],"value":"RequireCompatible"}
//| cases:
//|   - {"id":"project","label":"δ = 2 N、Project","description":"合力の成分を射影で除き、元の系の残差に ‖L Lᵀ f‖₂ が残る。","inputs":{"imbalance":2,"compatibility":"Project"}}
//|   - {"id":"reject","label":"δ = 2 N、RequireCompatible","description":"適合しない荷重を DomainError で拒否する。","inputs":{"imbalance":2}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"displacement","path":"/rows/0/1","approx":{"value":-17.5,"rtol":1e-12}}
//|       - {"artifact":"displacement","path":"/rows/7/1","approx":{"value":17.5,"rtol":1e-12}}
//|       - {"artifact":"diagnostics","path":"/rows/0/4","range":{"max":1e-10}}
//|       - {"artifact":"diagnostics","path":"/rows/0/5","range":{"max":1e-15}}
//|       - {"path":"/outputs/2/state","equals":"satisfied"}
//|   - case: project
//|     expect:
//|       - {"artifact":"displacement","path":"/rows/0/1","approx":{"value":-17.5625,"rtol":1e-12}}
//|       - {"artifact":"diagnostics","path":"/rows/0/1","approx":{"value":0.70710678118654752,"rtol":1e-12}}
//|       - {"artifact":"diagnostics","path":"/rows/0/3","approx":{"value":0.70710678118654752,"rtol":1e-10}}
//|       - {"path":"/outputs/2/state","equals":"satisfied"}
//|   - case: reject
//|     expect:
//|       - {"path":"/outputs/0/state","equals":"failed"}
//|       - {"path":"/outputs/0/status","equals":"DomainError"}
use scioxide_core::{BlockVectorView, Budget, SciOxideErrorKind, ResidualTolerance};
use scioxide_linalg::{
    BorderedSystem, BorderedSystemOptions, CompatibilityPolicy, LinearSolveTermination, Matrix,
    MatrixNorm, MinresSolver, Preconditioning,
};

let (n, spring, pull) = (8_usize, 2.0e3_f64, 10.0_f64);
// 支えのないばね鎖の剛性行列 K = k_s G（G は道グラフのラプラシアン行列）。
let entries = (0..n * n)
    .map(|idx| {
        let (i, j) = (idx / n, idx % n);
        if i == j {
            spring * if i == 0 || i == n - 1 { 1.0 } else { 2.0 }
        } else if i.abs_diff(j) == 1 {
            -spring
        } else {
            0.0
        }
    })
    .collect();
let stiffness = Matrix::from_vec(n, n, entries).map_err(|e| e.to_string())?;
let operator = stiffness.view().try_finite().map_err(|e| e.to_string())?;
// 左右の零空間は剛体の並進 (1, …, 1)/√n。
let mode = vec![1.0 / (n as f64).sqrt(); n];
let basis = BlockVectorView::new(&mode, n, 1).map_err(|e| e.to_string())?;
let scale = stiffness
    .view()
    .norm(MatrixNorm::One)
    .map_err(|e| e.to_string())?;
let options = BorderedSystemOptions::default();
let system =
    BorderedSystem::new(&operator, basis, basis, scale, &options).map_err(|e| e.to_string())?;
// 荷重 [N]: 両端を ∓P で引き、節点 3 に δ を加える。
let mut load = vec![0.0; n];
(load[0], load[n - 1]) = (-pull, pull);
load[3] += imbalance;
let policy = if compatibility == "Project" {
    CompatibilityPolicy::Project
} else {
    CompatibilityPolicy::RequireCompatible
};
// ゲージ条件 rᵀu = c = 0（重心の変位 0）。
let prepared = match system.prepare_rhs(&load[..], &[0.0][..], policy) {
    Ok(rhs) => Some(rhs),
    // RequireCompatible は ‖Lᵀ f‖₂ が許容誤差を超える荷重を DomainError で拒む。
    Err(error) if error.kind() == SciOxideErrorKind::DomainError => None,
    Err(error) => return Err(error.to_string()),
};
let outcome = if let Some(rhs) = prepared {
    let tolerance = ResidualTolerance::new(1e-12, 1e-12).map_err(|e| e.to_string())?;
    let solver = MinresSolver::new(tolerance, Budget::try_from(50).map_err(|e| e.to_string())?);
    let result = solver
        .solve_with_options(&system.augmented(), &rhs, Preconditioning::None, None)
        .map_err(|e| e.to_string())?;
    let (u, multiplier) = (
        &result.solution().as_slice()[..n],
        result.solution().as_slice()[n],
    );
    let diagnostics = system
        .diagnose(&load[..], &rhs, u)
        .map_err(|e| e.to_string())?;
    // 独立な参照: 射影した荷重 f̂ = f − mean(f) の部分和の符号を変えた値が張力になる。
    let mean_load = load.iter().sum::<f64>() / n as f64;
    let (mut exact, mut tension) = (vec![0.0; n], 0.0);
    for i in 0..n - 1 {
        tension += load[i] - mean_load;
        exact[i + 1] = exact[i] - tension / spring;
    }
    let mean = exact.iter().sum::<f64>() / n as f64;
    let rows: Vec<(usize, f64, f64)> = (0..n)
        .map(|i| (i, 1e3 * u[i], 1e3 * (exact[i] - mean)))
        .collect();
    let error = rows
        .iter()
        .map(|row| (row.1 - row.2).abs())
        .fold(0.0_f64, f64::max);
    let mm = serde_json::json!({ "fractionDigits": 4 });
    let displacement = serde_json::json!([
        { "key": "0", "label": "節点 i", "type": "integer" },
        { "key": "1", "label": "u_i（MINRES） [mm]", "type": "number", "format": mm },
        { "key": "2", "label": "u_i（部分和） [mm]", "type": "number", "format": mm }
    ]);
    emit_table_with_columns!(
        displacement,
        rows,
        metadata = serde_json::json!({ "id": "displacement" })
    );
    let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
    let checks = serde_json::json!([
        { "key": "0", "label": "nullity", "type": "integer" },
        { "key": "1", "label": "‖Lᵀf‖₂ [N]", "type": "number", "format": sci2 },
        { "key": "2", "label": "‖f − f̂‖₂ [N]", "type": "number", "format": sci2 },
        { "key": "3", "label": "‖Ku − f‖₂ [N]", "type": "number", "format": sci2 },
        { "key": "4", "label": "‖Ku − f̂‖₂ [N]", "type": "number", "format": sci2 },
        { "key": "5", "label": "‖rᵀu − c‖₂ [m]", "type": "number", "format": sci2 }
    ]);
    let values = (
        diagnostics.nullity(),
        diagnostics.compatibility_defect(),
        diagnostics.projection_norm(),
        diagnostics.original_residual_norm(),
        diagnostics.projected_residual_norm(),
        diagnostics.gauge_defect(),
    );
    emit_table_with_columns!(
        checks,
        vec![values],
        metadata = serde_json::json!({ "id": "diagnostics" })
    );
    let termination = result.report().termination();
    let status = match termination {
        LinearSolveTermination::Converged => "Converged",
        LinearSolveTermination::LeastSquaresConverged => "LeastSquaresConverged",
        LinearSolveTermination::ConditionLimit => "ConditionLimit",
        LinearSolveTermination::IterationLimit => "IterationLimit",
        LinearSolveTermination::EvaluationLimit => "EvaluationLimit",
        LinearSolveTermination::Stagnation => "Stagnation",
        LinearSolveTermination::Breakdown(_) => "Breakdown",
        LinearSolveTermination::ExecutionStopped(_) => "ExecutionStopped",
    };
    let outcome = if termination.is_success() {
        Outcome::satisfied("拡大系を解き、ゲージ条件を満たす変位を得た")
    } else if matches!(termination, LinearSolveTermination::Breakdown(_)) {
        Outcome::failed("MINRES の漸化式が破綻した")
    } else {
        Outcome::partial("MINRES が許容誤差を満たす前に止まった")
    };
    outcome
        .status(status)
        .diagnostic("反復", result.report().iterations() as f64, None)
        .diagnostic("部分和との差の最大", error, Some("mm"))
        .diagnostic("乗数 μ", multiplier, Some("N"))
} else {
    // 独立な値: 合力の成分 ‖Lᵀ f‖₂ = |Σ f_i| / √n。
    let defect = load.iter().sum::<f64>().abs() / (n as f64).sqrt();
    Outcome::failed("合力が 0 でない荷重を RequireCompatible が拒否した")
        .explanation(
            "合力を除いて解くには Project を選ぶ。つり合いが要る問題では荷重を見直す。",
        )
        .status("DomainError")
        .diagnostic("‖Lᵀf‖₂", defect, Some("N"))
};
emit_outcome!(outcome);
```

既定の $\delta = 0$ では合力が 0 なので `RequireCompatible` が荷重を受け入れ、MINRES は 4 回の反復で `Converged` になる。
各ばねの張力は 10 N、伸びは $10/2000$ m = 5 mm で、重心を固定した変位は $\pm 2.5$、$\pm 7.5$、$\pm 12.5$、$\pm 17.5$ mm になり、部分和から求めた値と $1.8 \times 10^{-14}$ mm 以内で一致する。
元の系の残差 $\lVert Ku - f \rVert_2$ は $1.7 \times 10^{-14}$ N、ゲージの欠損は 0 で、乗数 $\mu$ は 0 である。

$\delta = 2$ N で `Project` を選ぶと、合力の成分 $\lVert L^{\mathsf T} f \rVert_2 = 2/\sqrt{8} = 0.707$ N が射影で除かれ、MINRES は 7 回で収束する。
射影した系の残差は $2.4 \times 10^{-14}$ N だが、元の系の残差は除いた成分と同じ 0.707 N のまま残り、`diagnose` はこの二つを区別して返す。
変位は射影した荷重 $\hat f_i = f_i - 0.25$ N に対するつり合いで、$u_0 = -17.5625$ mm となり、部分和の値と一致する。
同じ荷重で `RequireCompatible` のままにすると、`prepare_rhs` が `DomainError` を返し、outcome は failed になる。
合力が 0 でない荷重は、支えのない構造物を剛体として加速させるので、静的なつり合いの解はない。
射影した解は「合力を除いた荷重」に対する変位であり、どちらを選ぶかは問題の物理で決める。

## まとめ

値域・零空間の基底や主角が要るときは `orth`、`null_space`、`subspace_angles` を使い、`RankPolicy` をデータの誤差に合わせて選んで、レポートの `rank` と `condition` で判定を確かめる。
主角の個数が予想より少なければ、`SubspaceAnglesReport` でどちらの入力のランクが落ちたかを見る。
点群の位置合わせには `orthogonal_procrustes` を使い、回転だけが意味を持つ問題で一意性が `Unique` でなければ、$\det R$ で鏡映でないかを確かめる。
二つの行列を同時に扱う問題には GSVD を使い、$\beta = 0$ の無限大の値と共通零空間を比とは別に読む。
零空間が分かっている特異な系は `BorderedSystem` の拡大系にして解き、適合しない右辺を拒否するか射影するかを問題の物理で選び、`diagnose` で元の系の残差とゲージの欠損を確かめる。
