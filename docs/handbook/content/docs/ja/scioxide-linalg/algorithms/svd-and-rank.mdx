特異値分解（SVD）は任意の長方行列を二つのユニタリ行列と非負の対角行列の積に分ける。
ランク、条件数、最小ノルム解、最良の低ランク近似がすべて特異値から読み取れるので、LU や QR の対角では確定できない問いに答える基準になる。
このページは SVD の存在と摂動論、計アルゴリズムと `scioxide-linalg` の三つの SVD の型、数値ランクの判定、条件数の計算と推定、悪条件の問題の正則化、最良の低ランク近似を説明する。
記号は[線形代数の数理と共通の規約](../)に、呼び出しの形（標準形式、オプション付き形式、出力先を指定する API、スコープ付き API）は[作業領域・実行コンテキスト・試行記録](oxref:linalg-execution-forms)に従う。

## 特異値分解の存在

任意の $A \in \mathbb{K}^{m \times n}$ はユニタリ行列 $U \in \mathbb{K}^{m \times m}$、$V \in \mathbb{K}^{n \times n}$ と、対角に $\sigma_1 \ge \dots \ge \sigma_p \ge 0$（$p = \min(m, n)$）を持つ $m \times n$ の $\Sigma$ で

$$
A = U \Sigma V^{\mathsf H} = \sum_{i=1}^{p} \sigma_i\, u_i v_i^{\mathsf H}
$$

と分解できる。
存在は次の帰納法で示せる。
単位球面は有界閉集合なので $\lVert A v \rVert_2$ を最大にする単位ベクトル $v_1$ があり、$\sigma_1 = \lVert A v_1 \rVert_2$、$u_1 = A v_1 / \sigma_1$ とおく（$A = 0$ なら自明）。
$u_1, v_1$ を第 1 列とするユニタリ行列で変換すると $\begin{bmatrix} \sigma_1 & w^{\mathsf H} \\ 0 & B \end{bmatrix}$ の形になる。
この行列をベクトル $(\sigma_1, w)$ に掛けると第 1 成分が $\sigma_1^2 + \lVert w \rVert_2^2$ になるので、行列の 2 ノルムは $(\sigma_1^2 + \lVert w \rVert_2^2)^{1/2}$ 以上である。
ユニタリ変換は 2 ノルムを変えず、その値は $\sigma_1$ なので $w = 0$ が従い、残りの $B$ に同じ議論を繰り返せばよい。
特異値は $A$ だけで決まり、単純な特異値の特異ベクトルは位相（実数では符号）を除いて一意である。
重複した特異値では、対応する特異ベクトルの張る部分空間だけが決まる。

幾何的には、$A$ は単位球を半軸 $\sigma_i$ の楕円体に写し、$v_i$ がその原像の方向、$u_i$ が軸の方向を表す。
$\lVert A \rVert_2 = \sigma_1$、$\lVert A \rVert_F^2 = \sum_i \sigma_i^2$、正則な正方行列では $\kappa_2(A) = \sigma_1 / \sigma_n$ が成り立ち、0 でない特異値の個数がランクを与える。

## 特異値と特異部分空間の摂動

特異値は摂動に対して安定である。
特異値の min-max 特徴づけ $\sigma_i(A) = \max_{\dim S = i} \min_{x \in S,\, \lVert x \rVert_2 = 1} \lVert Ax \rVert_2$ と $\lVert (A + E)x \rVert_2 \le \lVert Ax \rVert_2 + \lVert E \rVert_2$ から、任意の $E$ に対して Weyl の不等式

$$
\lvert \sigma_i(A + E) - \sigma_i(A) \rvert \le \lVert E \rVert_2 \qquad (i = 1, \dots, p)
$$

が仮定なしに成り立つ。
これは絶対誤差の評価で、相対誤差に直すと $\lVert E \rVert_2 / \sigma_i$ になる。
後退安定なアルゴリズムの結果は $\lVert E \rVert_2 \lesssim c(m, n)\, \varepsilon\, \sigma_1$（$c(m, n)$ は次元の低次の多項式、$\varepsilon$ は機械イプシロン）の摂動を加えた行列の厳密な特異値なので、計算した特異値の絶対誤差は $\varepsilon\,\sigma_1$ の程度である。
$\sigma_1$ より何桁も小さい特異値は相対的な精度を失い、$\varepsilon\,\sigma_1$ より小さい特異値は 0 と区別できない。
一般の密な行列では成分を浮動小数点数に丸めるだけでも同じ程度の摂動が入るので、この限界は多くの場合、入力を丸めた時点ですでに生じている。
$\sigma_i^2$ は $A^{\mathsf H} A$ の固有値でもあるが、$A^{\mathsf H} A$ を作ると小さな特異値が $\varepsilon \sigma_1^2$ の誤差に埋もれるので、SVD は $A$ から直接計算する。

特異ベクトルの精度は隣の特異値との隙間で決まる。
先頭 $k$ 個の左右の特異ベクトルが張る部分空間を $\mathcal{U}_k, \mathcal{V}_k$ とし、$\delta = \sigma_k(A) - \sigma_{k+1}(A) - \lVert E \rVert_2 > 0$ を仮定する。
$A + E$ の対応する部分空間との[主角](oxref:linalg-principal-angles)を並べた対角行列を $\Theta$ とすると（$\lVert \sin\Theta \rVert_2$ は最大の主角の正弦）、Wedin の $\sin\Theta$ 定理

$$
\max\bigl(\lVert \sin\Theta(\mathcal{U}_k, \hat{\mathcal{U}}_k) \rVert_2,\ \lVert \sin\Theta(\mathcal{V}_k, \hat{\mathcal{V}}_k) \rVert_2\bigr) \le \frac{\lVert E \rVert_2}{\delta}
$$

が成り立つ。
隙間が摂動に比べて大きければ値域や零空間の基底は安定に決まり、隙間が摂動と同じ程度以下なら個々の特異ベクトルは摂動で大きく回りうる。

## 計アルゴリズム

`scioxide-linalg` の SVD は二段階で計算する。
以下では $k = \min(m, n)$ とする。

1. 入力を 2 の冪で尺度変換し、左右から Householder 鏡映を掛けて $A = U_1 B V_1^{\mathsf H}$（$B$ は実の上二重対角行列）とする（Golub–Kahan の二重対角化）。
   次数 64 までは鏡映を 1 本ずつ掛け、それより大きい場合は幅 32 のパネルにまとめた鏡映を行列積で掛ける。
   横長の行列は随伴の向きで縮約する。
   正方の $U$ と $V$ を求めないジョブでは、$\max(m, n) \ge 2k$ の行列を先にピボットなしの Householder QR で分解し、$k \times k$ の三角因子だけを二重対角化する。
2. 二重対角行列の SVD を求める。
   特異値だけを求めるジョブは dqds（シフト付きの微分 qd 漸化式で、平方根をとらずに二重対角行列の特異値を求める）を使う。
   特異ベクトルも求めるジョブは、$k \le 64$ で陰的シフト付きの二重対角 QR 反復、それより大きい場合は分割統治を使う。
   QR 反復はブロックごとに端の対角成分の大きい方から小さい方へ追い込む向きを選ぶ（Demmel–Kahan）ので、成分の大きさが段階的に変わるブロックはどちらの向きでも収束する。
   分割統治は二重対角行列を小さな部分問題に分け、それらをつなぐ永年方程式の根から全体の特異値を求める方法で、最小の部分問題は次数 32 の QR 反復で解く。

計算量は $O(mnk)$ で、切り替えは行列の形とジョブだけで決まり、CPU の命令セットにはよらない。
二重対角行列の特異値は各成分の小さな相対摂動に対して小さな相対変化しかしない（Demmel–Kahan）ので、二重対角行列そのものの小さな特異値も意味を持つ。
dqds はこの性質を生かして $B$ の特異値を高い相対精度で求める。
しかし稠密行列の Householder 縮約が保証するのはノルムの意味の後退誤差だけなので、$A$ の特異値については上の摂動の議論がそのまま当てはまる。
特異値だけのジョブでは、対角行列のように縮約で丸めが入らない入力の小さな特異値も相対精度を保つ。
例外として、尺度変換の後に非正規化数になる値（$\sigma_1$ と正の最小の正規数の積より小さい値）は、元の値が正規数でも相対精度を失い、0 に丸められることもある。
反復の上限は `LinalgExecutionOptions::with_iteration_budget` で与える。
指定しなければ、dqds が $100k$ 回の変換（棄却したシフトを含む）、二重対角 QR が $30k$ 回の掃引、分割統治が $30k\,(1 + \lceil \log_2 \lceil k/32 \rceil \rceil)$ 回（掃引と、永年方程式を解く反復とを合わせた回数）である。
上限に達すると `ConvergenceFailure`、尺度変換を戻すとオーバーフローする場合は `NumericalInstability`、入力に NaN や無限大があれば `NonFinite` を返す。

| 型 | 結果 | 主な用途 |
|---|---|---|
| `SvdValues` | 特異値だけ | ランク、条件数、ノルム |
| `ThinSvdDecomposition` | $U_k$（$m \times k$）、$\sigma$、$V_k^{\mathsf H}$（$k \times n$）の薄い SVD | 最小二乗、正則化解、擬似逆、低ランク近似 |
| `SvdDecomposition` | 正方の $U$、$\sigma$、正方の $V^{\mathsf H}$ | 値域と零空間の基底をすべて含む |

どれも標準形式の `compute(&a)`、実行の設定 `LinalgExecutionOptions` を最後に受け取るオプション付き形式 `compute_with_options(&a, &options)`、出力・作業領域・実行コンテキストを借りる出力先を指定する API `compute_into` を持つ。
分解に使う作業領域の要求は `SvdWorkspaceRequest::new(m, n, &options)` で、既存の分解からの求解と擬似逆の要求は `SvdWorkspaceRequest::solve` と `pseudoinverse` で作る（`SvdValues` は後の二つを `InvalidInput` で拒む）。
特異値は降順の生の値で出力に反映され、0 は `+0.0` になる。
特異ベクトルは位相を除いて決まるので、$U$ の各列の絶対値が最大の成分（同じ大きさなら最初のもの）を正の実数にし、$V^{\mathsf H}$ の対応する行をそれに合わせる。
`analyze_rank(policy)` がランクのレポート `RankReport` を、`condition_estimate()` が $\sigma_k / \sigma_1$ を `ConditionEstimate` として返す（信頼度は数値モデルに基づく `ModelBased`）。

## 数値ランクの判定

丸め誤差や測定誤差のもとでは、ランクは特異値の大きさと、どこから下を 0 とみなすかのしきい値 $\tau$ で決まる。
Eckart–Young の定理（後述）から、$\lVert A - B \rVert_2 \le \tau$ を満たす行列 $B$ の最小のランクは $\sigma_i > \tau$ となる $i$ の個数に等しい。
これを $\tau$ に対する数値ランクと呼び、`analyze_rank` も $\tau$ を超える特異値を数える。
`RankReport` は数値ランク `rank()`、形から決まる最大のランク `maximum_rank()`、使ったしきい値 `threshold()`、相対しきい値の基準にした最大の特異値 `scale()` を返す。

しきい値の目安は行列にすでに含まれる誤差の大きさで、丸めだけなら前節の $c(m, n)\, \varepsilon\, \sigma_1$ である。
`RankPolicy::DimensionScaledEpsilon` はこの考え方で $\min(\max(m, n)\,\varepsilon, 1/2)\,\sigma_1$ をしきい値にする。
`RankPolicy::Exact` は厳密に 0 でない特異値をすべて数える。
測定データの行列が誤差 $E$（$\lVert E \rVert_2 \approx \eta$）を含むときは、丸めより $\eta$ の方が大きいので、`Threshold(RankThreshold::new(atol, rtol)?)` で $\tau = \mathrm{atol} + \mathrm{rtol}\,\sigma_1$ を $\eta$ 以上に選ぶ。
観測した行列 $A + E$ の特異値が $\sigma_r > \tau + \lVert E \rVert_2$ かつ $\sigma_{r+1} < \tau - \lVert E \rVert_2$ を満たせば、Weyl の不等式から誤差のない $A$ の $\tau$ に対する数値ランクも $r$ である。
特異値の列に大きな隙間があればしきい値の選び方によらずランクがはっきり決まり、隙間がなければ数値ランクはしきい値の選択そのものを反映するにすぎない。

## 条件数の計算と推定

正則な正方行列の条件数は、解の相対誤差が右辺や行列の相対的な摂動の何倍になりうるかを表す。
SVD は 2 ノルムの条件数 $\kappa_2(A) = \sigma_1/\sigma_n$ を与えるが、$O(n^3)$ の計算が要り、$\sigma_n$ の絶対誤差 $\varepsilon\,\sigma_1$ のため相対誤差は $\kappa_2\,\varepsilon$ の程度になる。
連立方程式を解くために LU 分解がすでにあるなら、1 ノルムの条件数 $\kappa_1(A) = \lVert A \rVert_1 \lVert A^{-1} \rVert_1$ を $O(n^2)$ の追加の計算で推定できる。
二つの条件数は $\lVert x \rVert_2 \le \lVert x \rVert_1 \le \sqrt{n}\,\lVert x \rVert_2$ から $\kappa_2(A)/n \le \kappa_1(A) \le n\,\kappa_2(A)$ を満たすので、桁の目安としてはどちらを使ってもよい。

$\lVert A \rVert_1$ は列の絶対値の和の最大なので成分から直接求まるが、$\lVert A^{-1} \rVert_1$ は $A^{-1}$ を作らずに推定する。
Hager–Higham 法は $A^{-1}$ と $A^{-\mathsf H}$ の積（LU 分解ではそれぞれ $O(n^2)$ の求解）を $n$ によらず高々 17 回使い、丸めを除いて $\lVert A^{-1} \rVert_1$ の下界を返す。
手順、積の回数、推定の精度は[Hager–Higham 法による推定](oxref:linalg-hager-higham)で説明する。
`LuDecomposition::condition_estimate()` は、分解の時点で厳密に求めた $\lVert A \rVert_1$ とこの推定から逆条件数 $1/\kappa_1$ を返す。
同じ推定を任意の正方作用素に使うのが[手法オブジェクト](oxref:linalg-method-values) `OneNormEstimator` で、LU 分解の逆作用素 `LuDecomposition::inverse_operator()` を渡せば $\lVert A^{-1} \rVert_1$ が得られる。

次のセルは多項式補間で現れる Vandermonde 行列 $V_{ij} = t_i^{\,j}$（$i, j = 0, \dots, n-1$）の条件数を三つの方法で求める。
入力は次数 $n$（4 から 16）、節点 $t_i \in [0, 1]$ の選び方（等間隔、または Chebyshev 点 $t_i = \tfrac12 - \tfrac12 \cos\frac{(2i+1)\pi}{2n}$）、`OneNormEstimator` の作用の上限（1 から 64）である。
表は `SvdValues` による $\kappa_2$、すべての単位ベクトルに $A^{-1}$ を掛ける `operator_norm` による厳密な $\kappa_1$、`OneNormEstimator` の推定、LU 分解の `condition_estimate()` の逆数を並べ、厳密な $\kappa_1$ を推定の独立な参照にする。
`OneNormEstimator` は、作業領域を先に事前確保してスコープ付き API で呼ぶ。
`workspace_requirements(&op)` は作用素を適用せずに形と作業量だけを読んで要件 `OneNormRequirements` を返し、要件は新しい作業領域に要るバイト数 `required_bytes()` と実行の設定のバイト上限 `byte_limit()` を持つ。
`OneNormWorkspace::try_reserve` がその分だけ作業領域を広げ、`estimate_scoped(&op, &mut workspace, context)` がレポート `OneNormReport` を返す。
推定の終了理由がセルの結論で、`Converged` なら satisfied、作用の上限で止まった `EvaluationLimit` なら partial とし、診断の値に作用の回数、推定と厳密な値の比、`required_bytes()` を示す。

既定の $n = 10$ と等間隔の節点では $\kappa_2 = 1.519 \times 10^{7}$、厳密な $\kappa_1 = 4.241 \times 10^{7}$ で、$\kappa_2/n \le \kappa_1 \le n\,\kappa_2$ の範囲にある。
50 桁の精度で別に求めた $\kappa_2$ と比べると、SVD の $\kappa_2$ の相対誤差は、成分を倍精度に丸めた同じ行列に対して $7.9 \times 10^{-12}$、丸める前の節点 $t_i = i/9$ の行列に対して $2.3 \times 10^{-11}$ である。
どちらも $\sigma_n$ の絶対誤差 $\varepsilon\,\sigma_1$ から見積もる $\kappa_2\,\varepsilon \approx 3.4 \times 10^{-9}$ より小さい。
`OneNormEstimator` は 7 回の作用で `Converged` になり、推定は厳密な値に一致し（比 1）、LU 分解の `condition_estimate()` も同じ値を返す。
厳密な値を求める `operator_norm` は $n = 10$ 回の作用を使うので、この大きさでは差が小さいが、推定に使う作用の回数は $n$ を大きくしても 17 回を超えない。
要件の `required_bytes()` は 560 B である。

Chebyshev 点では $\kappa_2 = 3.980 \times 10^{6}$、$\kappa_1 = 7.916 \times 10^{6}$ で、同じ次数で等間隔に置いた節点より $\kappa_2$ で 3.8 倍、$\kappa_1$ で 5.4 倍小さい。
作用の上限を 1 回にすると、推定は 1 回目の積で止まって `EvaluationLimit` になり、outcome は partial になる。
1 回目の積は $x = (1, \dots, 1)/n$ に $A^{-1}$ を掛ける。
$V$ の第 0 列はすべて 1 なので $A^{-1}(1, \dots, 1)^{\mathsf T} = e_0$ となり、推定値は $1/n$、$\lVert A \rVert_1 = n$ との積は 1 で、厳密な値の $2.4 \times 10^{-8}$ 倍にすぎない。
下界の推定は打ち切ると大きく過小になりうるので、終了理由を確かめてから値を使う。

## 正則化した解

$Ax = b$ の最小ノルム最小二乗解は $x = \sum_i (u_i^{\mathsf H} b / \sigma_i)\, v_i$ だが、小さな $\sigma_i$ では $b$ の誤差が $1/\sigma_i$ 倍に増幅される。
`ThinSvdDecomposition::solve(&b, policy, damping)` は、方針 `policy` のしきい値 $\tau$ を超える $r$ 個の特異値を使い、減衰 $\lambda \ge 0$（`damping`）を加えた

$$
x_{r,\lambda} = \sum_{i=1}^{r} \frac{\sigma_i}{\sigma_i^2 + \lambda}\, (u_i^{\mathsf H} b)\, v_i
$$

を返す。
内積 $u_i^{\mathsf H} b$ と $i$ についての和には補償付きの内積を使う。
$\lambda = 0$ は切断 SVD（TSVD）、$r = p$ で $\lambda > 0$ は Tikhonov 正則化 $\min \lVert Ax - b \rVert_2^2 + \lambda \lVert x \rVert_2^2$ に当たる。
TSVD は $\sigma_i \le \tau$ の成分を捨て、Tikhonov は各成分に係数 $\sigma_i^2/(\sigma_i^2 + \lambda)$ を掛けて $\sigma_i \ll \sqrt{\lambda}$ の成分を滑らかに抑える。
係数 $\lvert u_i^{\mathsf H} b \rvert$ が $\sigma_i$ より速く減る範囲（離散 Picard 条件）でだけ、解の成分は意味を持つ。
`damping` が負なら `InvalidInput`、NaN や無限大なら `NonFinite` で、`RankPolicy::Exact` が残した非正規化数の $\sigma_i$ の逆数のように係数がオーバーフローすると `NumericalInstability` になる。
`pseudoinverse(policy)` は同じ切断で擬似逆 $\sum_{\sigma_i > \tau} \sigma_i^{-1} v_i u_i^{\mathsf H}$（$n \times m$）を作る。
これは切断した行列 $A_r$ の Moore–Penrose 擬似逆で、$\tau$ が 0 でない最小の特異値より小さいときだけ $A^+$ に一致する。
出力先を指定する API `solve_into` は 1 回、`pseudoinverse_into` は出力の列ごとに 1 回を反復の上限に数える。

次のセルは幅 $w = 0.05$ のガウス核による第一種積分方程式 $\int_0^1 K(s, t) f(t)\, dt = g(s)$ を中点則で 64 点に離散化し、$f(t) = \sin \pi t + \tfrac12 \sin 3\pi t$ から作った $g$ に相対 $10^{e}$ のノイズを加えて $f$ を復元する。
入力はノイズの指数 $e$（$-10$ から $-1$）と正則化の強さの指数 $\alpha$（$-12$ から $-1$）である。
しきい値 $10^{\alpha}\sigma_1$ の TSVD と、減衰 $\lambda = (10^{\alpha}\sigma_1)^2$ の Tikhonov 正則化を、正則化なしの解と比べる。
表は使った特異値の数、相対残差 $\lVert Ax - b \rVert_2 / \lVert b \rVert_2$、既知の $f$ との相対誤差を示す。
グラフは特異値と係数 $\lvert u_i^{\mathsf T} b \rvert$ の Picard 図で、横線は TSVD のしきい値である。

```rust
//| id: linalg-tsvd-tikhonov
//| ref: linalg-tsvd-tikhonov
//| title: 切断 SVD と Tikhonov 正則化による逆問題の解
//| run: reactive
//| crates: [scioxide-core, scioxide-linalg]
//| inputs:
//|   noise_exponent: {"type":"range","label":"ノイズの相対的な大きさ 10^e の e","description":"右辺 g に加えるノイズの 2 ノルムの比。","min":-10,"max":-1,"step":1,"value":-4}
//|   regularization_exponent: {"type":"range","label":"正則化の強さ 10^α の α","description":"TSVD のしきい値 10^α σ₁ と Tikhonov の減衰 (10^α σ₁)²。","min":-12,"max":-1,"step":0.5,"value":-2}
//| cases:
//|   - {"id":"weak-regularization","label":"α = −12","description":"しきい値がノイズの水準より低く、TSVD がノイズを増幅する。","inputs":{"regularization_exponent":-12}}
//|   - {"id":"low-noise","label":"e = −10、α = −8","description":"ノイズが小さいと、より多くの特異値を使って誤差を下げられる。","inputs":{"noise_exponent":-10,"regularization_exponent":-8}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"solutions","path":"/rows/0/3","range":{"min":1e6}}
//|       - {"artifact":"solutions","path":"/rows/1/1","equals":20}
//|       - {"artifact":"solutions","path":"/rows/1/2","range":{"min":5e-5,"max":2e-4}}
//|       - {"artifact":"solutions","path":"/rows/1/3","range":{"max":1e-2}}
//|       - {"artifact":"solutions","path":"/rows/2/3","range":{"max":1e-2}}
//|   - case: weak-regularization
//|     expect:
//|       - {"artifact":"solutions","path":"/rows/1/1","equals":51}
//|       - {"artifact":"solutions","path":"/rows/1/3","range":{"min":1e3}}
//|   - case: low-noise
//|     expect:
//|       - {"artifact":"solutions","path":"/rows/1/1","equals":42}
//|       - {"artifact":"solutions","path":"/rows/1/3","range":{"max":5e-3}}
use scioxide_core::RankThreshold;
use scioxide_linalg::{Matrix, RankPolicy, ThinSvdDecomposition};

let n = 64_usize;
let h = 1.0 / n as f64;

let pi = std::f64::consts::PI;
let node = |i: usize| (i as f64 + 0.5) * h;
let kernel = |s: f64, t: f64| {
    (-(s - t).powi(2) / (2.0 * width * width)).exp() / (width * (2.0 * pi).sqrt())
};
let entries = (0..n * n)
    .map(|k| h * kernel(node(k / n), node(k % n)))
    .collect();
let a = Matrix::from_vec(n, n, entries).map_err(|e| e.to_string())?;
let f: Vec<f64> = (0..n)
    .map(|j| (pi * node(j)).sin() + 0.5 * (3.0 * pi * node(j)).sin())
    .collect();
let g = a.view().mul_vec(&f[..]).map_err(|e| e.to_string())?;
// 決定論的な擬似乱数のノイズを、2 ノルムの比が 10^e になるよう尺度変換する。
let z: Vec<f64> = (0..n)
    .map(|i| ((i * 7919 + 17) % 1013) as f64 / 1013.0 - 0.5)
    .collect();
let norm = |v: &[f64]| v.iter().map(|x| x * x).sum::<f64>().sqrt();
let scale = 10.0_f64.powf(noise_exponent) * norm(g.as_slice()) / norm(&z);
let b: Vec<f64> = g
    .as_slice()
    .iter()
    .zip(&z)
    .map(|(p, q)| p + scale * q)
    .collect();

let svd = ThinSvdDecomposition::compute(&a).map_err(|e| e.to_string())?;
let sigma = svd.singular_values();

let threshold = RankThreshold::new(level, 0.0).map_err(|e| e.to_string())?;
let truncation = RankPolicy::Threshold(threshold);
let methods = [
    ("正則化なし", RankPolicy::Exact, 0.0),
    ("TSVD", truncation, 0.0),
    ("Tikhonov", RankPolicy::Exact, level * level),
];

        .solve(&b[..], policy, damping)
        .map_err(|e| e.to_string())?;
    let rank = svd.analyze_rank(policy).map_err(|e| e.to_string())?.rank();
    let ax = a.view().mul_vec(&x).map_err(|e| e.to_string())?;
    let residual: Vec<f64> = ax.as_slice().iter().zip(&b).map(|(p, q)| p - q).collect();
    let error: Vec<f64> = x.as_slice().iter().zip(&f).map(|(p, q)| p - q).collect();
    rows.push((
        name,
        rank,
        norm(&residual) / norm(&b),
        norm(&error) / norm(&f),
    ));
}

let columns = serde_json::json!([
    { "key": "0", "label": "解法" },
    { "key": "1", "label": "使った特異値の数", "type": "integer" },
    { "key": "2", "label": "相対残差 [-]", "type": "number", "format": sci3 },
    { "key": "3", "label": "f との相対誤差 [-]", "type": "number", "format": sci3 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "solutions" })
);

// Picard 図: σ_i と |u_iᵀ b|。0 は対数軸に描けないので除く。
let coefficients = svd
    .u_matrix()
    .view()
    .transpose()
    .mul_vec(&b[..])
    .map_err(|e| e.to_string())?;
let (mut s_points, mut c_points) = (Vec::new(), Vec::new());
for i in 0..n {
    if sigma[i] > 0.0 {
        s_points.push([(i + 1) as f64, sigma[i]]);
    }
    let c = coefficients.as_slice()[i].abs();
    if c > 0.0 {
        c_points.push([(i + 1) as f64, c]);
    }
}
emit_line_chart!(
    &vec![
        serde_json::json!({ "name": "σ_i", "points": s_points }),
        serde_json::json!({ "name": "|u_iᵀ b|", "points": c_points }),
    ],
    options = &serde_json::json!({
        "xLabel": "特異値の番号 i [-]",
        "yLabel": "大きさ [-]",
        "yType": "log",
        "annotations": [{
            "kind": "line",
            "axis": "y",
            "value": level,
            "label": "TSVD のしきい値 10^α σ₁"
        }]
    })
);
```

特異値は $\sigma_1 = 0.989$ から急速に減り、計算した $\sigma_{64}$ は $1.9 \times 10^{-18}$ である。
50 桁の精度で求めると、丸める前の核の行列の $\sigma_{64}$ は $5.2 \times 10^{-21}$、成分を倍精度に丸めた行列の $\sigma_{64}$ は $10^{-18}$ の程度で、成分の丸めだけで最小の特異値が 3 桁動く。
$\varepsilon\,\sigma_1 \approx 2 \times 10^{-16}$ より小さい特異値は、入力の丸めでもアルゴリズムの誤差でもこの程度動くので、0 と区別できず、相対的な精度を持たない。
ノイズのない係数 $u_i^{\mathsf T} g$ は特異値とともに減るが、ノイズの係数は番号によらずほぼ一定なので、Picard 図では $\lvert u_i^{\mathsf T} b \rvert$ がノイズの水準（$10^{e} \lVert g \rVert_2 / \sqrt{n}$ 程度、既定で $10^{-5}$〜$10^{-4}$）で平らになる。
正則化なしの解はこの平らな部分を小さな $\sigma_i$ で割るので、既定の $e = -4$ で $f$ との相対誤差が $7.6 \times 10^{12}$ になる。
既定の $\alpha = -2$ では、TSVD が 20 個の特異値を使って相対誤差 $5.7 \times 10^{-3}$、Tikhonov が $4.1 \times 10^{-3}$ で、相対残差は $1.1 \times 10^{-4}$ と $1.5 \times 10^{-4}$ と、ノイズの大きさ $10^{-4}$ と同じ程度になる。
TSVD が使った特異値の数（この節の 14、20、42、51）は、50 桁の精度で求めた特異値をしきい値と比べた個数と一致する。

$\alpha$ を下げるとノイズを拾い、$\alpha = -12$ では TSVD が 51 個の特異値を使って誤差は $6.9 \times 10^{6}$ になる。
上げると解の成分を削りすぎ、$\alpha = -1$ では TSVD が 14 個を使って誤差は $1.7 \times 10^{-2}$ になる。
残差がノイズの大きさに等しくなるように $\alpha$ を選ぶのが Morozov の食い違い原理である。
TSVD の相対残差は $\alpha = -2$ で $1.1 \times 10^{-4}$、$\alpha = -2.5$ で $9.7 \times 10^{-5}$ なので、この原理が与える $\alpha$ はその間にある。
そこでの TSVD の誤差 $3.2 \times 10^{-3}$〜$5.7 \times 10^{-3}$ は、$\alpha = -3$ の $6.0 \times 10^{-2}$ や $\alpha = -1$ の $1.7 \times 10^{-2}$ より小さい。
ノイズを $e = -10$ に下げて $\alpha = -8$ にすると、TSVD は 42 個の特異値を使い、誤差は $1.3 \times 10^{-3}$、Tikhonov は $7.3 \times 10^{-4}$ まで下がる。

## 最良の低ランク近似

Eckart–Young–Mirsky の定理により、ランク $k$ 以下の行列のうち $A$ に最も近いものは、先頭の $k$ 項を残した $A_k = \sum_{i=1}^{k} \sigma_i u_i v_i^{\mathsf H}$ で、

$$
\lVert A - A_k \rVert_2 = \sigma_{k+1}, \qquad \lVert A - A_k \rVert_F = \Bigl( \sum_{i > k} \sigma_i^2 \Bigr)^{1/2}
$$

である。
2 ノルムの場合の証明は短い。
ランク $k$ 以下の $B$ の零空間は $n - k$ 次元以上なので、$v_1, \dots, v_{k+1}$ の張る空間と単位ベクトル $z$ を共有し、$\lVert (A - B) z \rVert_2 = \lVert A z \rVert_2 \ge \sigma_{k+1}$ となる。

次のセルは $30 \times 20$ のガウス核行列 $a_{st} = \exp(-(s - t)^2/(2w^2))$（$s, t$ は $[0, 1]$ の等間隔点）について、薄い SVD から $A_k$ を作る。
入力は核の幅 $w$（0.05 から 0.5）である。
差 $A - A_k$ の 2 ノルムをその差の行列の `SvdValues` で、Frobenius ノルムを成分の二乗和で別に求め、右辺の $\sigma_{k+1}$ と $(\sum_{i>k} \sigma_i^2)^{1/2}$ と比べる。
表は $k \le 7$ と 4 の倍数の $k$ の行を示し、グラフは $\lVert A - A_k \rVert_2$ の点と、理論値 $\sigma_{k+1}$ の破線を描く。

```rust
//| ref: linalg-eckart-young
//| title: 切り詰めた SVD の近似誤差と特異値
//| run: reactive
//| crates: [scioxide-linalg]
//| inputs:
//|   width: {"type":"range","label":"核の幅 w","description":"小さいほど特異値の減衰が遅い。","min":0.05,"max":0.5,"step":0.05,"value":0.2}
//| cases:
//|   - {"id":"narrow-kernel","label":"w = 0.05","description":"特異値の減衰が遅く、同じ誤差に必要なランクが増える。","inputs":{"width":0.05}}

//|   - case: default

//|   - case: narrow-kernel

//|       - {"artifact":"errors","path":"/rows/8/1","approx":{"value":1.3019538677074704,"rtol":1e-12}}

    .map(|k| {
        let (s, t) = (
            (k / n) as f64 / (m - 1) as f64,
            (k % n) as f64 / (n - 1) as f64,
        );
        (-(s - t).powi(2) / (2.0 * width * width)).exp()

    .collect();

for k in 0..n {
    // A − A_k = Σ_{i≥k} σ_i u_i v_iᵀ を成分ごとに作る（添字は 0 から）。
    let diff: Vec<f64> = (0..m * n)
        .map(|idx| {
            let (r, c) = (idx / n, idx % n);
            (k..n)
                .map(|i| sigma[i] * u[r * n + i] * vt[i * n + c])
                .sum()
        })
        .collect();
    let frobenius = diff.iter().map(|x| x * x).sum::<f64>().sqrt();
    let difference = Matrix::from_vec(m, n, diff).map_err(|e| e.to_string())?;
    let two_norm = SvdValues::compute(&difference)
        .map_err(|e| e.to_string())?
        .singular_values()[0];
    let tail = sigma[k..].iter().map(|s| s * s).sum::<f64>().sqrt();
    // 0 は対数軸に描けないので除く。
    if two_norm > 0.0 {
        points.push([k as f64, two_norm]);
    }
    if sigma[k] > 0.0 {
        theory.push([k as f64, sigma[k]]);
    }
    if k < 8 || k % 4 == 0 {
        rows.push((k, two_norm, sigma[k], frobenius, tail));
    }
}

let columns = serde_json::json!([
    { "key": "0", "label": "k", "type": "integer" },
    { "key": "1", "label": "‖A − A_k‖₂ [-]", "type": "number", "format": sci4 },
    { "key": "2", "label": "σ_(k+1) [-]", "type": "number", "format": sci4 },
    { "key": "3", "label": "‖A − A_k‖_F [-]", "type": "number", "format": sci4 },
    { "key": "4", "label": "(Σ_(i>k) σ_i²)^(1/2) [-]", "type": "number", "format": sci4 }
```

どの $k$ でも、差の 2 ノルムは $\sigma_{k+1}$ と、Frobenius ノルムは残りの特異値の二乗和の平方根と、表示した 4 桁で一致する。
$\sigma_{k+1}$ は 50 桁の精度で別に求めた値とも一致し、既定の $w = 0.2$ の $\sigma_{13}$ では相対差が $7.5 \times 10^{-11}$ である。
既定の $w = 0.2$ では、隣り合う特異値の比 $\sigma_k/\sigma_{k+1}$ が 1.4 から 36 まで次第に大きくなり、$\lVert A - A_k \rVert_2 / \sigma_1 \le 10^{-3}$ の近似にはランク 8 で足りる（$\sigma_9 / \sigma_1 = 2.2 \times 10^{-4}$）。
$w = 0.05$ にすると減衰が遅くなり、ランク 8 でも誤差は $\sigma_9 = 1.30$（$\sigma_1$ の 45 %）にとどまる。
グラフの最後の点 $k = 19$ の誤差 $2.6 \times 10^{-15}$ は、50 桁の精度で求めた $\sigma_{20} = 2.5 \times 10^{-15}$ と約 4 % 違う。
$\sigma_{20}$ は特異値の絶対誤差の水準 $\varepsilon\,\sigma_1 \approx 2.3 \times 10^{-15}$ と同じ大きさなので、相対誤差が数 % になる。

## まとめ

計算した特異値は $\varepsilon\,\sigma_1$ 程度の絶対誤差を持つので、$\varepsilon\,\sigma_1$ に近いか小さい特異値の値は信用せず、0 と区別できないものとして扱う。
数値ランクを決めるときは、しきい値を行列にすでに含まれる誤差以上に選び（丸めだけなら `DimensionScaledEpsilon`、測定誤差があればその大きさを `Threshold` で）、特異値の隙間がしきい値をまたいでいるかを確かめる。
条件数は、SVD があれば $\kappa_2$ を読み、LU 分解しかなければ `condition_estimate()` で $\kappa_1$ の下界の推定を $O(n^2)$ で得て、桁の目安として使う。
悪条件の問題を解くときは、Picard 図で係数がノイズの水準に達する番号を見て、`solve(&b, policy, damping)` の切断か減衰を残差がノイズの大きさになるように選ぶ。
低ランク近似に必要なランクは許す誤差を下回る最初の $\sigma_{k+1}$ から決まる。
