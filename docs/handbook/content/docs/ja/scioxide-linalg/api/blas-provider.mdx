この表の 18 項目は `scioxide-linalg` の `blas` 機能を有効にした場合にだけ出力に反映される。
呼び出し側は CBLAS 互換のライブラリをラップする `BlasProvider` を実装し、`BlasDispatch` を `LinalgExecutionContext::with_blas` でコンテキストに付けると、出力先を指定する API とスコープ付き API の密行列の演算のうち提示内容に合う呼び出しがそのプロバイダーに回る。
SciOxide は初期化済みで範囲を検査したスライスだけを渡し、生ポインタは公開しない。
変更する出力は呼び出し側の入出力とは別の場所に置いてから書き込むので、プロバイダーの失敗は呼び出し側の出力を変えない。
スカラー型は scioxide-core の `ScalarKind`（`F32`、`F64`、`Complex32`、`Complex64`）で区別し、帯・パックの行列が参照する三角は scioxide-core の `Triangle` で表す。
ブラウザで実行する本書のセルは外部ライブラリを使えないので、この機能を使う実行例はない。

## まとめ

外部の BLAS ライブラリを使うには、`blas` 機能を有効にし、ライブラリをラップする `BlasProvider` を実装する。
`BlasCapabilities` には、プロバイダーが受け付ける格納の順・変換・整数の幅・整列と、スカラー型ごとの操作の ULP を提示する。
提示内容に合わない呼び出しを自前実装で続けるか `CapabilityUnavailable` で止めるかは、`BlasFallbackPolicy` で選ぶ。
`Accuracy::Exact` を求める呼び出しは、ULP を 0 と提示した操作だけがプロバイダーに渡る。
`BlasDispatch` を `LinalgExecutionContext::with_blas` でコンテキストに付け、出力先を指定する API とスコープ付き API の呼び出しに渡す。
