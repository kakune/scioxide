この表は他のすべての計算が入力と出力に使う密行列とベクトルの型、BLAS 1〜3 に相当する密行列カーネルの精度と実行の制御、作業領域の型をまとめる。
`Matrix` は行優先（成分 $(i, j)$ は `data[i * cols + j]`）で、ビューは行と列のストライドを別々に持つので、転置やブロックを複製せずに借用できる。
並列化の方針、積の精度、時間とバイト数の上限、反復の許容回数は `LinalgExecutionOptions` 一つにまとめる。
密行列の操作と分解のオプション付き形式（`*_with_options`）、出力先を指定する API（`*_into`）、スコープ付き API（`*_scoped`）はこの値を直接受け取り、設定を取らない標準形式は既定の設定で逐次に実行する。
呼び出しの形の定義は [呼び出しの形](oxref:linalg-api-forms)にある。

## 精度と実行の制御

積の精度は [共通の `Accuracy`](oxref:core-api-accuracy) を `LinalgExecutionOptions::with_accuracy` に渡して選ぶ。
`Accuracy` は `scioxide_core` から読み込む。

## まとめ

行列とベクトルは `Matrix`・`Vector` で所有し、転置やブロックはビューで複製せずに借用して渡す。
積・内積・ノルムを一度だけ求めるなら標準形式を使い、精度 `Accuracy::Exact` やバイト数の上限が要るならオプション付き形式かスコープ付き API に `LinalgExecutionOptions` を渡す。
同じ大きさの計算を繰り返すなら、要求の値から `LinalgWorkspace` の要件を求めて一度だけ事前確保し、出力先を指定する API で呼んで確保を避ける。
反復法や作用素の作用に密行列を渡すときは、`try_finite` で一度だけ検査した `FiniteMatrixView` を作用素として使う。
