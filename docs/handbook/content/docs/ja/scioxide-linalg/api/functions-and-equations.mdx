この表は、行列の関数 $f(A)$ を密行列または疎行列として求める型と、Sylvester・Lyapunov・Riccati の行列方程式を解く型をまとめる。

一度だけ解くときは、ワンショット関数 `matrix_function`、`solve_sylvester`、`solve_lyapunov`、`solve_riccati` を使う。
これらは既定の設定で Plan を作り、`ExecutionContext::sequential_native()` で逐次に実行して、結果の行列を返す。
受理されなかった解はエラーになる。
同じ係数で何度も評価や求解をするときは Plan（`MatrixFunctionPlan`、`SylvesterPlan`、`LyapunovPlan`、`RiccatiPlan`、`SparsePowerPlan`、`SparseFunctionPlan`）を作る。
Plan は入力を検査し、Schur 分解や記号的な積のような準備を一度だけ行う。
呼び出しの形の定義は[呼び出しの形](oxref:linalg-api-forms)にある。

行列方程式の Plan の `solve` は解と元の方程式の診断を返し、直接法と同じ終了理由 `DirectSolveTermination` で受理を判定する。
残差や閉ループの安定性の検査に通らない候補は `Ok` のまま `solution()` が `None` になり、`into_accepted()` がこれを `NumericalInstability` のエラーに変える。
Plan の所有値を返す API（`new` と `solve`、疎行列の Plan の `evaluate`）はクロックのない逐次のコンテキストで実行するので、時間の上限を設定すると `CapabilityUnavailable` になる。
コンテキストを渡すときは `build`、`solve_into`、`evaluate_into` を使う。

## まとめ

行列関数を一度だけ求めるなら `matrix_function`、行列方程式を一度だけ解くなら `solve_sylvester`、`solve_lyapunov`、`solve_riccati` を使い、受理されない解はエラーとして受け取る。
同じ行列で評価を繰り返すとき、Fréchet 微分や条件数が要るとき、実行列から複素数の結果を得たいときは `MatrixFunctionPlan` を作って出力先を指定する API で評価する。
疎行列のべきと関数は、連結ブロックを密に埋めた出力パターンを Plan が先に決めるので、`structural_fill` で充填の大きさを確かめてから評価する。
行列方程式の Plan の `solve` は残差や安定性の検査に通らない候補も `Ok` で返すので、`report().termination()` を確かめるか `into_accepted()` でエラーに変える。
レポートの分離や条件数の欄は推定であり、解の誤差の上界を与えない。
