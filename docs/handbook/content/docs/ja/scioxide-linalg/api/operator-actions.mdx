このページの表は作用素 $A$ を積 $Av$（と随伴の積 $A^{\mathsf H}v$）だけで使い、行列の関数のベクトルへの作用、一部の固有対や特異三つ組、低ランク近似、1 ノルムの推定を求める型をまとめる。
API の型（`ExponentialAction`、`FunctionAction`、`PartialSpectrumSolver`、`LobpcgSolver`、`PartialSvdSolver`、`RandomizedLowRank`、`OneNormEstimator`）は手法オブジェクトである。
手法オブジェクトは許容誤差や作用の回数の上限などの設定だけを持ち、Plan（`…Plan`）と違って準備した数値を持たない。
作用素の次元や列数は呼び出しのたびに作用素と入力から読むので、一つの値を大きさの違う問題に使える。
設定の検査も呼び出しのときに行い、作業領域の要件を求める段階で設定の誤りを `InvalidInput` などで返す。

各族は手法オブジェクトのほか、出力（`…Buffer` または呼び出し側の列）、レポート（`…Report`）、作業領域（`…Workspace`）とその要件（`…Requirements`）からなる。
要件は手法オブジェクトの `workspace_requirements` に作用素（と列数や制約の数などの呼び出しの大きさ）を渡して求め、作業領域の `check` と `try_reserve` で照合する。
呼び出しの形の定義は[呼び出しの形](oxref:linalg-api-forms)にある。
所有値を返す API（`apply`、`solve`、`svd`、`interpolative`、`estimate`）は出力と作業領域を確保し、`ExecutionContext::sequential_native()` で逐次に実行する。
出力先を指定する API（`apply_into`、`solve_into`、`svd_into`、`interpolative_into`）とスコープ付き API の `estimate_scoped` は、呼び出し側の作業領域とコンテキストを使い、事前確保した作業領域では同じ大きさの呼び出しで確保しない。

作用の回数や反復の上限、取り消し、期限で止まると、成功でない終了理由 `SpectralTermination` と受理済みの部分結果を `Ok` で返す。
`Err` のときは出力を変えない。
レポートの誤差の指標は打ち切りや残差に基づく推定で、前進誤差の上界ではない。

## まとめ

行列を作らずに $e^{tA}b$ を求めるなら、$\lVert A - \mu I \rVert_1$ の上界を与えて `ExponentialAction` を使い、上界が分からないときや指数以外の関数には `FunctionAction` を使う。
一部の固有対を求めるときは、一般の作用素なら `PartialSpectrumSolver`、Hermitian な行列束の端の固有値で前処理を使いたいなら `LobpcgSolver` を選び、内部の固有値にはシフト反転の `SpectrumOperator::ShiftInvert` を使う。
特異値には `PartialSvdSolver` を、乱数を自分で管理したい低ランク近似には `RandomizedLowRank` を使い、構成に使わない検査ベクトルの残差で近似を確かめる。
どの手法オブジェクトも設定だけを持つので、一つの値を大きさの違う作用素に使え、作業領域の要件は呼び出しの大きさから求める。
上限や取り消しで止まった結果は `Ok` で返るので、`SpectralTermination` が `Converged` かを確かめる。
