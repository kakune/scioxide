この表は密行列として格納しない行列の格納形式、その分解と求解、構造行列の生成子、行列を組み合わせた作用素、作用素に対する汎用の操作をまとめる。
帯・三重対角・三角の分解と Plan の求解は、解く系 $A$、$A^{\mathsf T}$、$A^{\mathsf H}$ を選ぶ `StructuredOperation`（`Normal`、`Transpose`、`Adjoint`）を最初の引数に取る。
標準形式の `solve(op, rhs)` は解を返して拒否をエラーにし、オプション付き形式の `solve_with_options(op, rhs, &DirectSolveOptions)` は受理しない場合も `Ok` で `DirectSolveResult` を返す。
分解の標準形式 `factor(view)` は既定の設定で逐次に実行し、精度や上限を選ぶときはオプション付き形式 `factor_with_options(view, &options)` を使う。
呼び出しの形の定義は [呼び出しの形](oxref:linalg-api-forms)にある。
作業領域は共有の `LinalgWorkspace` を使い、大きさは一つの `StructuredWorkspaceRequest` で問い合わせる。
帯・Hermitian 帯・パック・三重対角の所有型は作用素を実装せず、`view()` で借用したビューが積と作用素の規約を実装する。

## まとめ

三重対角・帯・パック・三角の行列は専用の格納型で持ち、ビューを作用素として渡すか、対応する分解・Plan で解く（三重対角の分解は $O(n)$、帯幅 $k$ の帯 Cholesky は $O(nk^2)$）。
求解では `StructuredOperation` で $A$、$A^{\mathsf T}$、$A^{\mathsf H}$ を選び、解だけが要るなら標準形式、受理のレポートが要るならオプション付き形式を使う。
Toeplitz・Hankel・巡回行列は一度だけなら `solve_structured`、右辺が多いなら `StructuredSolvePlan` で解き、後退誤差の許容誤差と密な LU への退避を選ぶ。
Kronecker 積やブロック対角の系は、因子の逆作用素を渡して `solve_into` で解き、`CompositeSolveReport` の終了理由で受理を確かめる。
作用素のノルムを厳密に求めるなら `operator_norm` を、密行列なら `MatrixView::norm` を使う。
