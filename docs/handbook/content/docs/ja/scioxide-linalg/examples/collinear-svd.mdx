装置の消費電力 $y$ [W] を、近くに置いた二つの温度センサーの読み $x$、$z$ [°C] から $y = \beta_1 x + \beta_2 z + \varepsilon$ で説明したいとする。
二つのセンサーがほとんど同じ値を示すと、計画行列の二つの列がほぼ平行になり、個々の係数は決まりにくくなる（多重共線性）。
この例題では計画行列の特異値から共線性の程度を測り、最小二乗の係数のどの方向が不安定になるかを確かめる。

---

## 係数の分散と特異値

計画行列 $X = [x, z] \in \mathbb{R}^{n \times 2}$ の SVD を $X = U \Sigma V^{\mathsf T}$ とすると、ノイズ $\varepsilon$ の成分が独立で平均 0、標準偏差 $\sigma_\varepsilon$ のとき、最小二乗推定 $\hat\beta = X^{+} y$ の共分散は

$$
\operatorname{Cov}(\hat\beta) = \sigma_\varepsilon^2 (X^{\mathsf T}X)^{-1} = \sum_{j} \frac{\sigma_\varepsilon^2}{\sigma_j^2}\, v_j v_j^{\mathsf T}
$$

である。
小さい特異値 $\sigma_2$ に対応する方向の組み合わせ $v_2^{\mathsf T}\hat\beta$ の分散は $\sigma_\varepsilon^2/\sigma_2^2$ で、$\sigma_2$ が小さいほど大きくなる。
一方、予測値 $\hat y = X\hat\beta$ の共分散は $\sigma_\varepsilon^2 U U^{\mathsf T}$ で、特異値によらずノイズの程度にとどまる。
共線性は予測の精度を下げるのではなく、個々の係数を分けて決められなくする。

## 特異値と標準誤差の閉じた形

$n = 20$ 回の観測で、$x$ の値を 2 回ずつ同じにとる（$x = 15.0, 15.0, 15.5, 15.5, \dots$ °C）。
もう一つのセンサーは $z_i = x_i + \delta (-1)^i$ とずれるとする。
交互の符号 $s_i = (-1)^i$ は $x$ と直交する（$x^{\mathsf T}s = 0$）ので、$a = x^{\mathsf T}x$、$c = n\delta^2/2$ とおくと

$$
X^{\mathsf T}X = \begin{pmatrix} a & a \\ a & a + 2c \end{pmatrix}, \qquad
\sigma_1^2 = a + c + \sqrt{a^2 + c^2}, \qquad \sigma_2^2 = \frac{2ac}{\sigma_1^2} \approx \frac{n\delta^2}{2}
$$

である（$\sigma_2^2$ は打ち消しを避けるため積 $\sigma_1^2\sigma_2^2 = \det X^{\mathsf T}X = 2ac$ から求める）。
$n = 20$ なら $\sigma_2 \approx 3.16\,\delta$、条件数は $\kappa_2 = \sigma_1/\sigma_2 \approx \sqrt{2a}/(3.16\,\delta)$ で、$\delta$ に反比例して大きくなる。
逆行列 $(X^{\mathsf T}X)^{-1} = \tfrac{1}{2ac}\bigl(\begin{smallmatrix} a + 2c & -a \\ -a & a \end{smallmatrix}\bigr)$ から、係数とその組み合わせの標準誤差は

```text
SE(β₁) = σ_ε √((a + 2c)/(2ac)),   SE(β₂) = σ_ε / √(2c),
SE(β₁ + β₂) = σ_ε / √a,           SE(β₁ − β₂) = σ_ε √((4a + 2c)/(2ac))
```

になる。
$\delta$ が小さいと $\mathrm{SE}(\beta_1 - \beta_2) \approx 2\sigma_\varepsilon/(\delta\sqrt n)$ は大きくなるが、$\mathrm{SE}(\beta_1 + \beta_2) = \sigma_\varepsilon/\sqrt a$ は $\delta$ によらない。

次の定義のブロックはこのモデルを二つのセルで共有する。
`design` が $X$、`observations` が真の係数 $\beta = (2, 1)$ W/°C に正規乱数のノイズを加えた $y$、`fit` が `ThinSvdDecomposition` による特異値・最小二乗解・数値ランク・切断した解、`closed_form` と `standard_errors` が上の閉じた形に対応する。

```rust
//| id: linalg-collinear-model
//| kind: definitions
//| title: 共線な計画行列と閉じた形の特異値・標準誤差
//| crates: [scioxide-core, scioxide-linalg]
use scioxide_core::{SciOxideError, RankThreshold};
use scioxide_linalg::{Matrix, RankPolicy, ThinSvdDecomposition};

pub(crate) const N: usize = 20;

/// 計画行列 X = [x, z]（行ごとに x_i、z_i = x_i + δ(−1)^i を並べる）。
pub(crate) fn design(delta: f64) -> Result<Matrix<f64>, SciOxideError> {
    let data = (0..N)
        .flat_map(|i| {
            let x = 15.0 + 0.5 * (i / 2) as f64;
            [x, x + delta * if i % 2 == 0 { 1.0 } else { -1.0 }]
        })
        .collect();
    Matrix::from_vec(N, 2, data)
}

/// シードから作る標準正規分布の擬似乱数（xorshift64* と Box–Muller 法）。
pub(crate) fn gaussian(seed: u64, len: usize) -> Vec<f64> {
    let mut state = seed.wrapping_mul(0x9E37_79B9_7F4A_7C15) | 1;
    let mut uniform = move || {
        state ^= state >> 12;
        state ^= state << 25;
        state ^= state >> 27;
        ((state.wrapping_mul(0x2545_F491_4F6C_DD1D) >> 11) as f64 + 0.5) / (1u64 << 53) as f64
    };
    (0..len)
        .map(|_| {
            let (u, v) = (uniform(), uniform());
            (-2.0 * u.ln()).sqrt() * (2.0 * std::f64::consts::PI * v).cos()
        })
        .collect()
}

/// SVD による当てはめの結果: 特異値、最小二乗解、数値ランク、10⁻³σ₁ で切断した解。
pub(crate) struct Fit {
    pub(crate) sigma: [f64; 2],
    pub(crate) beta: [f64; 2],
    pub(crate) rank: usize,
    pub(crate) truncated: [f64; 2],
}

/// y = 2x + z + σ_ε g（g は正規乱数）を SVD で当てはめる。
pub(crate) fn fit(delta: f64, noise: f64, seed: u64) -> Result<Fit, SciOxideError> {
    let x = design(delta)?;
    let g = gaussian(seed, N);
    let rows = x.as_slice();
    let y: Vec<f64> = (0..N)
        .map(|i| 2.0 * rows[2 * i] + rows[2 * i + 1] + noise * g[i])
        .collect();
    let svd = ThinSvdDecomposition::compute(&x)?;
    let beta = svd.solve(&y[..], RankPolicy::Exact, 0.0)?;
    let rank = svd.analyze_rank(RankPolicy::DimensionScaledEpsilon)?.rank();
    // σ₂ < 10⁻³ σ₁ なら σ₂ の方向を捨てた最小ノルム解になる。
    let threshold = RankPolicy::Threshold(RankThreshold::new(0.0, 1e-3)?);
    let truncated = svd.solve(&y[..], threshold, 0.0)?;
    let s = svd.singular_values();
    Ok(Fit {
        sigma: [s[0], s[1]],
        beta: [beta.as_slice()[0], beta.as_slice()[1]],
        rank,
        truncated: [truncated.as_slice()[0], truncated.as_slice()[1]],
    })
}

/// 閉じた形の (a, c, σ₁, σ₂)（参照値。f64 の標準関数）。
pub(crate) fn closed_form(delta: f64) -> (f64, f64, f64, f64) {
    let a: f64 = (0..N).map(|i| (15.0 + 0.5 * (i / 2) as f64).powi(2)).sum();
    let c = N as f64 * delta * delta / 2.0;
    let s1 = (a + c + (a * a + c * c).sqrt()).sqrt();
    (a, c, s1, (2.0 * a * c).sqrt() / s1)
}

/// 標準誤差 [SE(β₁), SE(β₂), SE(β₁ + β₂), SE(β₁ − β₂)]（参照値）。
pub(crate) fn standard_errors(delta: f64, noise: f64) -> [f64; 4] {
    let (a, c, _, _) = closed_form(delta);
    [
        noise * ((a + 2.0 * c) / (2.0 * a * c)).sqrt(),
        noise / (2.0 * c).sqrt(),
        noise / a.sqrt(),
        noise * ((4.0 * a + 2.0 * c) / (2.0 * a * c)).sqrt(),
    ]
}
```

次のセルはセンサーのずれ $\delta = 10^p$ °C（$p \in [-10, -1]$）、ノイズ $\sigma_\varepsilon = 10^q$ W（$q \in [-8, -1]$）、乱数のシードを選び、`ThinSvdDecomposition::compute` の特異値を閉じた形と比べる。
`RankPolicy::DimensionScaledEpsilon` による数値ランクと、`RankPolicy::Exact` での最小二乗解、$10^{-3}\sigma_1$ のしきい値で切断した解も求める。
二つ目の表は係数とその和・差の誤差を標準誤差と並べ、誤差と標準誤差の比が $\pm 2$ 程度に収まるかで、誤差がノイズで説明できるかを確かめる。
$\delta$、$\sigma_\varepsilon$、シードは次のセルに渡す。

既定の $\delta = 10^{-6}$ °C、$\sigma_\varepsilon = 10^{-3}$ W、シード 1 では、$\sigma_2 = 3.162 \times 10^{-6}$ が閉じた形と相対 $6.5 \times 10^{-10}$ で一致し、条件数は $3.5 \times 10^{7}$ に達する。
`DimensionScaledEpsilon` のしきい値は $n\varepsilon\sigma_1 \approx 4.9 \times 10^{-13}$ で、$\sigma_2$ はそれより十分大きいので、数値ランクは 2 のままである。
個々の係数では $\beta_1$ の誤差が 422 W/°C に達するが、これは標準誤差 $\mathrm{SE}(\beta_1) = 224$ W/°C の 1.9 倍で、ノイズ $\sigma_\varepsilon$ を $\sigma_2$ で割った程度の大きさとして説明できる。
係数の和 $\beta_1 + \beta_2 = 3.0000123$ は $v_1 \propto (1, 1)$ の方向なので、誤差 $1.2 \times 10^{-5}$ W/°C は標準誤差 $\sigma_\varepsilon/\sqrt a = 1.3 \times 10^{-5}$ W/°C の程度にとどまる。
ノイズが正規分布に従うなら誤差と標準誤差の比は標準正規分布に従い、シードを変えると符号と大きさが変わって、約 95% の確率で $\pm 1.96$ の範囲に入る。
$\delta$ を $10^{-10}$ °C まで小さくしても数値ランクは 2 のままだが、計算した $\sigma_2$ の絶対誤差は $u\sigma_1$ の程度なので、閉じた形との相対差は $5.7 \times 10^{-6}$ に広がる。
$z_i = x_i + \delta(-1)^i$ を浮動小数点数に丸めること自体も、$X$ に同じ程度の摂動を加える。

## δ を変えたときの条件数と誤差

次のセルは前のセルの $\sigma_\varepsilon$ とシードを受け取り、$\delta = 10^{-1}, 10^{-1.5}, \dots, 10^{-10}$ °C の 19 点で同じ当てはめを繰り返す。
上の図は SVD の条件数 $\kappa_2$ と閉じた形（破線）、下の図は係数の誤差の最大 $\max(\lvert\hat\beta_1 - 2\rvert, \lvert\hat\beta_2 - 1\rvert)$ と標準誤差 $\mathrm{SE}(\beta_1)$（破線）で、横軸の $\delta$ は二つの図で連動する。
縦線は前のセルで選んだ $\delta$ である。
どちらの図も対数軸で、誤差が厳密に 0 になった点は描かない。

$\delta$ を 1 桁小さくするごとに条件数も係数の誤差も 1 桁大きくなり、SVD の条件数は閉じた形の破線に重なる（$\delta = 10^{-1}$ °C で $\kappa_2 = 346$、$\delta = 10^{-10}$ °C で $3.5 \times 10^{11}$）。
係数の誤差は $\mathrm{SE}(\beta_1)$ の破線と平行に、その約 1.9 倍の位置を通る。
比が $\delta$ によらないのは、小さい特異値の方向にあるノイズの成分 $u_2^{\mathsf T}\varepsilon$ が、ほぼ $\delta$ によらないためである。
ノイズ $\sigma_\varepsilon$ を変えると誤差の線は $\sigma_\varepsilon$ に比例して上下するが、条件数の線は変わらない。

## 切断による安定化と、その代償

係数の表の最後の 2 行は $10^{-3}\sigma_1$ より小さい特異値を捨てた最小ノルム解である。
既定の $\delta$ では $\sigma_2$ が捨てられ、解は $v_1$ の方向だけを持つ $(1.5, 1.5)$ に近づき、ノイズによらず安定するが、真の値 $(2, 1)$ とは異なる。
切断は「データから決められない成分は 0 とする」という仮定を加えることにあたり、係数の和は保たれるが、差 $\beta_1 - \beta_2$ についての情報は失われる。
$\delta = 10^{-1}$ °C では $\sigma_2/\sigma_1 \approx 3 \times 10^{-3}$ がしきい値より大きいので切断されず、通常の最小二乗解になる。
しきい値は丸めの水準（`DimensionScaledEpsilon`）ではなく、データのノイズの水準 $\sigma_\varepsilon$ と特異値の比で選ぶのが目安である。

---

## まとめ

二つの説明変数がほぼ同じ値を示すと、計画行列の最小の特異値が $\delta\sqrt{n/2}$ まで下がり、条件数が $\delta$ に反比例して大きくなる。
方向 $v_j$ の係数の組み合わせの分散は $\sigma_\varepsilon^2/\sigma_j^2$ なので、小さい特異値の方向（ここでは $\beta_1 - \beta_2$）は決まらないが、大きい特異値の方向（$\beta_1 + \beta_2$）は安定に決まり、どちらの誤差も閉じた形の標準誤差で説明できる。
数値ランクは特異値としきい値の比で決まり、丸めの水準のしきい値ではランクが落ちたと判定されなくても、係数はノイズで大きく動く。
共線性が疑われるときは特異値を調べ、決められる係数の組み合わせだけを使うか、[切断 SVD や Tikhonov 正則化](../../algorithms/svd-and-rank/)で小さい特異値の方向を抑える。
