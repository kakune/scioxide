`scioxide-linalg` の例題は力学、確率過程、量子力学、統計、制御、熱伝導の具体的な問題を、線形方程式、固有値問題、特異値分解、行列関数、行列方程式、反復法のいずれかに帰着させて解く。
どの例題も SciOxide の API で計算した値を、閉じた形の解、別のアルゴリズムによる二つ目の経路、統計的な理論値など独立に求めた値と照合し、残差・前進誤差・条件数の大きさを本文で読む。

例題は上から順に、直接法（三重対角、特異値分解）、固有値問題、行列関数、悪条件と反復改良、構造を使う解法、反復法、行列方程式、実行の制御の順に並べてある。
セルはレポートを読まない計算には標準形式とワンショット関数を、終了理由・残差・ランクを読む計算にはオプション付き形式と Plan を使う。
作業領域や試行記録を読む計算（取り消しの例題と Rabi 振動の作用）と、出力先を指定する API の求解しか持たない構造化の Plan（Yule–Walker）だけが出力先を指定する API を使う（形の区別は[作業領域・実行コンテキスト・試行記録](oxref:linalg-execution-forms)）。
解法の終了理由が結論になるセルは、その結論を計算の判定（outcome）として出力の先頭に示す。
数値を読むときは、各例題の本文が示す誤差の大きさ（相対残差、前進誤差、二経路の差）と、その値が条件数やアルゴリズムの性質から期待される大きさかどうかを合わせて確かめる。
アルゴリズムの導出と結果の受理の規約は[線形代数の数理と共通の規約](../algorithms/)にまとめてある。

## まとめ

連立方程式の誤差と条件数を確かめたいときは Hilbert 行列とばね鎖、ランクの判定は特異値分解、固有値と定常分布は振動系と Markov 連鎖の例題から読む。
行列指数とその作用は Rabi 振動、行列方程式は LQR、前処理の選び方と反復法が止まったときの結果は熱伝導と取り消しの例題で確かめられる。
どの例題も結果を閉じた形の解や二つ目のアルゴリズムの経路と照合しているので、自分の問題でも残差が小さいことだけで解を正確とみなさず、独立な検算を一つ用意する。
結果を使う前には終了理由を確かめ、後退誤差と条件数の推定から前進誤差の大きさを見積もる。
