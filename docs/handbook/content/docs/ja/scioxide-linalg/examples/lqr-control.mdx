線形の状態方程式 $\dot x = Ax + Bu$ で表される機械や回路では、どの方向へ状態を動かしやすいかと、どのような入力で系を安定にするかが制御の基本的な問いになる。
前者は可制御性グラミアンで測り、Lyapunov 方程式を解いて求める。
後者の答えの一つが、状態と入力の二次の計算コストを最小にする最適レギュレータ（LQR）で、代数 Riccati 方程式を解いて求める。
この例題では二つの行列方程式を、それぞれ別の経路の計算と閉じた形で確かめる。
解法とレポートの詳細は[Sylvester・Lyapunov・Riccati 方程式](../../algorithms/matrix-equations/)にある。

## 可制御性グラミアン

$A$ が安定（すべての固有値の実部が負）なら、可制御性グラミアン

$$
W = \int_0^\infty e^{At} B B^{\mathsf T} e^{A^{\mathsf T} t}\, dt
$$

は有限で、被積分関数を $t$ で微分してから積分すると、連続時間の Lyapunov 方程式 $AW + WA^{\mathsf T} = -BB^{\mathsf T}$ を満たすことが分かる。
原点から出発して時間の制限なしに状態 $x_f$ へ到達させる入力のうち、入力エネルギー $\int \lVert u \rVert^2 dt$ が最小のものは $x_f^{\mathsf T} W^{-1} x_f$ を要する。
$W$ の固有値が小さい方向ほど、状態を動かすのに大きなエネルギーが要る。

質量 $m$ [kg]、減衰係数 $c$ [N·s/m]、ばね定数 $k$ [N/m] の振動系 $m\ddot x + c\dot x + kx = u$（力 $u$ [N]）では、状態 $(x, \dot x)$ について

$$
A = \begin{bmatrix} 0 & 1 \\ -k/m & -c/m \end{bmatrix}, \quad B = \begin{bmatrix} 0 \\ 1/m \end{bmatrix}, \qquad W = \begin{bmatrix} 1/(2kc) & 0 \\ 0 & 1/(2mc) \end{bmatrix}
$$

となる（Lyapunov 方程式の成分を書き下して解ける）。
変位 1 m の状態 $x_f = (1, 0)$ に到達する最小エネルギーは $1/W_{11} = 2kc$ [N²·s] で、ばねが硬く減衰が大きいほど大きい。

別の経路として、有限時間のグラミアン $W(T) = \int_0^T e^{At}BB^{\mathsf T}e^{A^{\mathsf T}t}dt$ を Van Loan の方法で求める。
ブロック行列 $C = \begin{bmatrix} -A & BB^{\mathsf T} \\ 0 & A^{\mathsf T} \end{bmatrix}$ の指数を $e^{CT} = \begin{bmatrix} F_{11} & F_{12} \\ 0 & F_{22} \end{bmatrix}$ と書くと $W(T) = F_{22}^{\mathsf T} F_{12}$ で、$T \to \infty$ で $W$ に近づく。
振動が減衰する場合（$c^2 < 4mk$）、被積分関数は $e^{-(c/m)t}$ の速さで減るので、差 $1 - W_{11}(T)/W_{11}$ もおよそこの速さで 0 に近づく。
過減衰（$c^2 > 4mk$）では遅いほうのモードの減衰がこれより遅いので、近づくのにより長い時間がかかる。

Lyapunov 方程式は `LyapunovPlan` で解く。
`LyapunovPlan::new(&a, LyapunovKind::Continuous, options)` は $A$ の Schur 形を一度だけ計算する Plan で、`solve(&q)` が Bartels–Stewart 法で $AX + XA^{\mathsf T} = Q$ を解き、元の方程式の残差を検査する。
右辺は $Q = -BB^{\mathsf T}$ と符号を含めて渡す。
方程式の 3 項 $T_1 = AX$、$T_2 = XA^{\mathsf T}$、$T_3 = -Q$ と残差 $R = T_1 + T_2 + T_3$ について、`MatrixEquationOptions::new()` は $\lVert R \rVert_F \le \mathrm{atol} + \mathrm{rtol}\,(\lVert T_1 \rVert_F + \lVert T_2 \rVert_F + \lVert T_3 \rVert_F)$ のとき解を受理する（$\mathrm{atol} = \mathrm{rtol} = \sqrt{\varepsilon_{\mathrm{mach}}}$）。
後退誤差は $\lVert R \rVert_F$ を項のノルムの和で割った値である。
このページの行列は SI 単位で表した数値で、成分ごとに単位が違うので、残差と後退誤差はその数値の大きさで測った値になる。
`solve` の結果は解とレポート `MatrixEquationReport`（終了理由、残差、後退誤差、分離の推定）を持ち、検査を通らなかった解は `solution()` が `None` になって出力に反映されない。
レポートが要らなければ、ワンショット関数 `solve_lyapunov(&a, LyapunovKind::Continuous, &q)` が解の行列だけを返し、拒否を `NumericalInstability` のエラーにする。
行列指数はワンショット関数 `matrix_function(&c, MatrixFunction::Exp)` で求める（スケーリングと平方と Padé 近似）。

次のセルは質量 $m$（0.5〜5 kg）、減衰係数 $c$（0.1〜3 N·s/m）、ばね定数 $k$（1〜20 N/m）を選ぶ。
1 つ目の表は $W$ の 3 成分を、Lyapunov 方程式の解、閉じた形、$T = 24m/c$（振幅の減衰率 $c/(2m)$ の逆数の 12 倍）での $W(T)$ で比べ、最後の列に Lyapunov 方程式の解と閉じた形の差を $\max(W_{11}, W_{22})$ で割った値を示す。
2 つ目の表は最小エネルギー $1/W_{11}$ と $2kc$、Lyapunov 方程式のレポートの値と終了理由を示す。
グラフは $W_{11}(T)/W_{11}$ を $0 \le T \le 12m/c$ で描き、極限の 1 を横線で示す。
最後の判定は Lyapunov 方程式の終了理由である。

```rust
//| ref: linalg-lqr-gramian
//| title: ばね・質点・ダンパー系の可制御性グラミアン
//| run: reactive
//| crates: [scioxide-core, scioxide-linalg]
//| inputs:
//|   mass: {"type":"range","label":"質量 m [kg]","description":"振動する質点の質量。","min":0.5,"max":5,"step":0.5,"value":2}
//|   damping: {"type":"range","label":"減衰係数 c [N·s/m]","description":"小さいほど振動がゆっくり減衰する。","min":0.1,"max":3,"step":0.1,"value":1}
//|   stiffness: {"type":"range","label":"ばね定数 k [N/m]","description":"大きいほど固有振動数が高い。","min":1,"max":20,"step":1,"value":8}
//| cases:
//|   - {"id":"light-damping","label":"c = 0.1 N·s/m","description":"減衰が小さいと W は 1/c に比例して大きくなり、W(T) が W に近づくまでの時間が 10 倍に延びる。","inputs":{"damping":0.1}}
//|   - {"id":"stiff-spring","label":"k = 20 N/m","description":"ばねが硬いと変位の方向の W₁₁ が小さくなり、変位 1 m に到達する最小エネルギーが増える。","inputs":{"stiffness":20}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"gramian","path":"/rows/0/1","approx":{"value":0.0625,"rtol":1e-12}}
//|       - {"artifact":"gramian","path":"/rows/2/1","approx":{"value":0.25,"rtol":1e-12}}
//|       - {"artifact":"gramian","path":"/rows/0/3","approx":{"value":0.0625,"rtol":1e-9}}
//|       - {"artifact":"gramian","path":"/rows/1/4","range":{"max":1e-14}}
//|       - {"artifact":"energy","path":"/rows/0/1","approx":{"value":16,"rtol":1e-12}}
//|       - {"artifact":"energy","path":"/rows/0/3","range":{"max":1e-14}}
//|       - {"path":"/outputs/3/state","equals":"satisfied"}
//|   - case: light-damping
//|     expect:
//|       - {"artifact":"gramian","path":"/rows/0/1","approx":{"value":0.625,"rtol":1e-11}}
//|       - {"artifact":"gramian","path":"/rows/2/1","approx":{"value":2.5,"rtol":1e-11}}
//|       - {"artifact":"gramian","path":"/rows/2/3","approx":{"value":2.5,"rtol":1e-8}}
//|       - {"path":"/outputs/3/state","equals":"satisfied"}
//|   - case: stiff-spring
//|     expect:
//|       - {"artifact":"gramian","path":"/rows/0/1","approx":{"value":0.025,"rtol":1e-12}}
//|       - {"artifact":"energy","path":"/rows/0/1","approx":{"value":40,"rtol":1e-12}}
//|       - {"path":"/outputs/3/state","equals":"satisfied"}
use scioxide_linalg::{
    DirectSolveTermination, LyapunovKind, LyapunovPlan, Matrix, MatrixEquationOptions,
    MatrixFunction, matrix_function,
};

let (m, c, k) = (mass, damping, stiffness);
// 状態 (x [m], ẋ [m/s])、入力 u [N]。A = [[0, 1], [−k/m, −c/m]]、B = [0, 1/m]ᵀ。
let a = Matrix::from_rows(&[[0.0, 1.0], [-k / m, -c / m]]).map_err(|e| e.to_string())?;
// LyapunovKind::Continuous は A X + X Aᵀ = Q を解く。可制御性グラミアンでは Q = −B Bᵀ。
let rhs = Matrix::from_rows(&[[0.0, 0.0], [0.0, -1.0 / (m * m)]]).map_err(|e| e.to_string())?;
// Plan は A の Schur 形を一度だけ求め、solve は解とレポートを返す。
let plan = LyapunovPlan::new(&a, LyapunovKind::Continuous, MatrixEquationOptions::new())
    .map_err(|e| e.to_string())?;
let result = plan.solve(&rhs).map_err(|e| e.to_string())?;
let report = result.report();
// 受理されなかった解は出力に反映されない（None）。
let w: Option<Vec<f64>> = result.solution().map(|s| s.as_slice().to_vec());
// 閉じた形 W = diag(1/(2kc), 1/(2mc))（行優先の成分）。
let exact = [1.0 / (2.0 * k * c), 0.0, 0.0, 1.0 / (2.0 * m * c)];
let scale = exact[0].max(exact[3]);
// Van Loan: exp([[−A, BBᵀ], [0, Aᵀ]] T) = [[F₁₁, F₁₂], [0, F₂₂]] から W(T) = F₂₂ᵀ F₁₂。
let finite = |t: f64| -> Result<[f64; 4], String> {
    let block = Matrix::from_rows(&[
        [0.0, -t, 0.0, 0.0],
        [k * t / m, c * t / m, 0.0, t / (m * m)],
        [0.0, 0.0, 0.0, -k * t / m],
        [0.0, 0.0, t, -c * t / m],
    ])
    .map_err(|e| e.to_string())?;
    let exp = matrix_function(&block, MatrixFunction::Exp).map_err(|e| e.to_string())?;
    let f = exp.as_slice();
    let mut out = [0.0_f64; 4];
    for i in 0..2 {
        for j in 0..2 {
            out[i * 2 + j] = (0..2)
                .map(|l| f[(l + 2) * 4 + i + 2] * f[l * 4 + j + 2])
                .sum();
        }
    }
    Ok(out)
};
// 振幅の減衰率 c/(2m) の逆数の 12 倍、T = 24m/c。
let horizon = 24.0 * m / c;
let late = finite(horizon)?;
let rows: Vec<_> = [
    (0, "W₁₁ [m²/(N²·s)]"),
    (1, "W₁₂ [m²/(N²·s²)]"),
    (3, "W₂₂ [m²/(N²·s³)]"),
]
.iter()
.map(|&(index, name)| {
    let lyapunov = w.as_ref().map(|w| w[index]);
    let difference = lyapunov.map(|v| (v - exact[index]).abs() / scale);
    (name, lyapunov, exact[index], late[index], difference)
})
.collect();
let sig10 = serde_json::json!({ "significantDigits": 10 });
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let columns = serde_json::json!([
    { "key": "0", "label": "成分" },
    { "key": "1", "label": "Lyapunov", "type": "number", "format": sig10, "nullText": "非公開" },
    { "key": "2", "label": "閉じた形", "type": "number", "format": sig10 },
    { "key": "3", "label": "W(T)、T = 24m/c", "type": "number", "format": sig10 },
    { "key": "4", "label": "差（相対）[-]", "type": "number", "format": sci2, "nullText": "なし" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "gramian" })
);
let termination = report.termination();
// 終了理由は列挙子名で示す。
let name = match termination {
    DirectSolveTermination::Accepted => "Accepted",
    DirectSolveTermination::RankDeficient => "RankDeficient",
    DirectSolveTermination::IllConditioned => "IllConditioned",
    DirectSolveTermination::ResidualRejected => "ResidualRejected",
    DirectSolveTermination::StabilityRejected => "StabilityRejected",
};
let energy_columns = serde_json::json!([
    { "key": "0", "label": "1/W₁₁ [N²·s]", "type": "number", "format": sig10, "nullText": "なし" },
    { "key": "1", "label": "2kc [N²·s]", "type": "number", "format": sig10 },
    { "key": "2", "label": "残差 ‖R‖_F", "type": "number", "format": sci2 },
    { "key": "3", "label": "後退誤差 [-]", "type": "number", "format": sci2 },
    { "key": "4", "label": "分離の推定", "type": "number", "format": sci2, "nullText": "なし" },
    { "key": "5", "label": "終了理由" }
]);
emit_table_with_columns!(
    energy_columns,
    vec![(
        w.as_ref().map(|w| 1.0 / w[0]),
        2.0 * k * c,
        report.residual(),
        report.backward_error(),
        report.separation(),
        name,
    )],
    metadata = serde_json::json!({ "id": "energy" })
);
// W₁₁(T)/W₁₁ を T ∈ [0, T/2] で描く。
let mut points = Vec::new();
for step in 0..=40 {
    let t = 0.5 * horizon * f64::from(step) / 40.0;
    points.push([t, finite(t)?[0] / exact[0]]);
}
emit_line_chart!(
    &vec![serde_json::json!({ "name": "W₁₁(T)/W₁₁", "points": points })],
    options = &serde_json::json!({
        "xLabel": "積分の上限 T [s]",
        "yLabel": "比 W₁₁(T)/W₁₁ [-]",
        "annotations": [
            { "kind": "line", "axis": "y", "value": 1.0, "label": "T → ∞ の極限" }
        ]
    })
);
let outcome = if termination.is_success() {
    Outcome::satisfied("Lyapunov 方程式の解が残差の検査で受理された")
} else {
    Outcome::failed("Lyapunov 方程式の解が受理されなかった")
};
emit_outcome!(
    outcome
        .status(name)
        .diagnostic("残差", report.residual(), None)
        .diagnostic("後退誤差", report.backward_error(), None)
);
```

既定の $m = 2$ kg、$c = 1$ N·s/m、$k = 8$ N/m では、Lyapunov 方程式の解は閉じた形 $W = \operatorname{diag}(0.0625, 0.25)$ と相対 $3 \times 10^{-16}$ 以内で一致し、非対角は $10^{-18}$ の程度である。
変位 1 m に到達する最小エネルギーは $2kc = 16$ N²·s で、残差と後退誤差はどちらも $6 \times 10^{-17}$ である。
Van Loan の方法による $W(T)$ は、$T = 24m/c = 48$ s で $W$ と 10 桁一致する。
グラフの $W_{11}(T)/W_{11}$ は $T = 9.6$ s の点で 0.99 を超え、減衰の速さ $c/m$ が 10 分の 1 の $c = 0.1$ N·s/m では 10 倍の 96 s の点で超える。
このとき $W$ は $1/c$ に比例して 10 倍になり、同じ変位に到達するエネルギーは 10 分の 1 の 1.6 N²·s で済む。
$k = 20$ N/m では $W_{11}$ が 0.025 に下がり、最小エネルギーは 40 N²·s に増える。
過減衰の $m = 0.5$ kg、$c = 3$ N·s/m、$k = 1$ N/m では、遅いほうのモードの固有値が $-0.35$ 1/s なので、$T = 24m/c = 4$ s の $W_{11}(T)$ は $W_{11}$ より 7 % 小さい。

## 倒立振子の最適レギュレータ

長さ $\ell$ [m] の軽い棒の先に質量 $m$ [kg] の質点を付けた振子を、支点のトルク $u$ [N·m] で倒立させる。
角度 $\theta$ [rad] が小さいとき、運動方程式は $m\ell^2\ddot\theta = mg\ell\,\theta + u$（$g = 9.81$ m/s²）で、状態 $(\theta, \dot\theta)$ について

$$
A = \begin{bmatrix} 0 & 1 \\ a & 0 \end{bmatrix}, \quad B = \begin{bmatrix} 0 \\ b \end{bmatrix}, \qquad a = \frac{g}{\ell}, \quad b = \frac{1}{m\ell^2}
$$

となる。
固有値 $\pm\sqrt{a}$ の一方が正なので、入力がなければ振子は倒れる。
計算コスト $J = \int_0^\infty (q_1\theta^2 + q_2\dot\theta^2 + r u^2)\, dt$ を最小にする入力は $u = -Kx$、$K = r^{-1}B^{\mathsf T}X$ で、$X$ は代数 Riccati 方程式

$$
A^{\mathsf T}X + XA - XBr^{-1}B^{\mathsf T}X + Q = 0, \qquad Q = \operatorname{diag}(q_1, q_2)
$$

の安定化解（閉ループ $A - BK$ のすべての固有値の実部を負にする解）である。
$(A, B)$ が可安定で $(Q^{1/2}, A)$ が可検出なら、安定化解は一つだけ存在し、半正定値になる。
この振子では $B$ と $AB = (b, 0)^{\mathsf T}$ が一次独立なので $(A, B)$ は可制御で、$Q$ は正定値なので、この条件を満たす。
$\theta$ を rad、$\dot\theta$ を rad/s、$u$ を N·m で測るとき、重み $q_1$、$q_2 = 1$、$r$ は無次元の数として与える。
成分を書き下すと、$X = \begin{bmatrix} x_1 & x_2 \\ x_2 & x_3 \end{bmatrix}$ は

$$
x_2 = \frac{r}{b^2}\Bigl(a + \sqrt{a^2 + q_1 b^2/r}\Bigr), \quad x_3 = \sqrt{\frac{r}{b^2}(2x_2 + q_2)}, \quad x_1 = \frac{b^2}{r}x_2x_3 - a\,x_3
$$

と閉じた形で解ける。
閉ループの特性方程式は $\lambda^2 + bk_2\lambda + (bk_1 - a) = 0$ で、$bk_1 - a = \sqrt{a^2 + q_1b^2/r} > 0$、$bk_2 = (b^2/r)\,x_3 > 0$ なので閉ループは安定になる。
初期状態 $x_0$ からの最小計算コストは $J^\ast = x_0^{\mathsf T} X x_0$ である。
これを独立に確かめるため、閉ループ $A_K = A - BK$ について Lyapunov 方程式 $A_K^{\mathsf T}P + PA_K = -(Q + K^{\mathsf T}rK)$ を解く。
$P$ は同じ制御則の計算コスト $J = x_0^{\mathsf T}Px_0$ を与えるので、$P = X$ になるはずである。

Riccati 方程式は `RiccatiPlan` で解く。
係数は `RiccatiProblem { a, b, q, r, e, s }` に行列の参照で渡し、`e: None` は $E = I$、`s: None` は交差項 $S = 0$ を表す。
`RiccatiPlan::new(problem, RiccatiKind::Continuous, options)` は次数 $2n + m$ の拡大ペンシルを作り、QZ 法と固有値の並べ替えで安定な収縮部分空間を求める（$n$ 状態、$m$ 入力で $O((n+m)^3)$）。
可安定性や可検出性は確かめず、ペンシルの固有値が虚軸の近くにあるか、安定な固有値の数が $n$ でなければ、準備が `NumericalInstability`（`IllConditioned`）のエラーで失敗する。
`solve()` は部分空間から $X$ と $K$ を取り出し、元の方程式の残差を検査する（既定の許容誤差は $\sqrt{\varepsilon_{\mathrm{mach}}}$）。
`RiccatiOptions::with_closed_loop_verification(Estimation::Estimate)` を指定すると、`solve()` は閉ループのペンシル $(A - BK, E)$ の固有値も QZ 法で計算する。
レポート `stability_margin()` は固有値 $\lambda = \alpha/\beta$ の同次座標による余裕 $-\operatorname{Re}\alpha/\max(\lvert\alpha\rvert, \lvert\beta\rvert)$ の最小値で、$E = I$ で $\beta > 0$ にとれば $-\operatorname{Re}\lambda/\max(\lvert\lambda\rvert, 1)$ になる。
この値が安定性の許容誤差（既定は $\mathrm{atol} = \mathrm{rtol} = \varepsilon_{\mathrm{mach}}$）以下なら、終了理由は `StabilityRejected` になる。
受理されたときだけ `solution()` と `gain()` が $X$ と $K$ を返す。
ワンショット関数 `solve_riccati(problem, RiccatiKind::Continuous)` は、`RiccatiOptions` の既定と違って閉ループの検査を有効にして解き（QZ 法の計算がもう一度 $O(n^3)$ かかる）、受理された $(X, K)$ を返す。
拒否はエラーになり、閉ループの安定余裕が許容誤差以下なら `NumericalInstability`（`IllConditioned`）、残差が許容誤差を超えれば `NumericalInstability`（`LossOfSignificance`）である。
このセルの `RiccatiPlan` も同じ検査を指定するので、二つの経路は同じ計算をする。

次のセルは先端の質量 $m$（0.1〜1 kg）、振子の長さ $\ell$（0.2〜1 m）、角度の重み $q_1$（1〜100）、トルクの重み $r$（0.001〜1）を選ぶ。
1 つ目の表は `RiccatiPlan` のレポートで、終了理由、残差、後退誤差、収縮部分空間から $X$ を取り出す計算の逆条件数（0〜1）、安定余裕を示す。
2 つ目の表はゲイン $K$ と、`RiccatiPlan` の $X$、`solve_riccati` の $X$、Lyapunov 方程式による $P$ のそれぞれと閉じた形との相対差、$x_0 = (0.1\ \mathrm{rad}, 0)$ からの最小計算コスト $J^\ast$ と最初のトルク $u(0) = -Kx_0$ である。
3 つ目の表は閉ループの極で、`GeneralEigenvaluesResult::compute`（Francis の QR 法）による値と、閉じた形の $K$ から作った特性方程式の根を並べる。
最後の判定は Riccati 方程式の終了理由である。
このセルの $a$、$b$ と、受理された場合のゲイン $K$ は次の応答のセルに渡す。

```rust
//| id: linalg-lqr-riccati
//| ref: linalg-lqr-riccati
//| title: 倒立振子の LQR と計算コストの二経路の検算
//| run: reactive
//| crates: [scioxide-core, scioxide-linalg]
//| exports: [a, b, gain]
//| inputs:
//|   pendulum_mass: {"type":"range","label":"先端の質量 m [kg]","description":"振子の先端の質点。","min":0.1,"max":1,"step":0.05,"value":0.2}
//|   pendulum_length: {"type":"range","label":"振子の長さ ℓ [m]","description":"支点から質点まで。","min":0.2,"max":1,"step":0.1,"value":0.5}
//|   q_angle: {"type":"range","label":"角度の重み q₁ [-]","description":"角度のずれへのペナルティ。","min":1,"max":100,"step":1,"value":10}
//|   r_torque: {"type":"range","label":"トルクの重み r [-]","description":"入力の大きさへのペナルティ。","min":0.001,"max":1,"step":0.001,"value":0.1}
//| cases:
//|   - {"id":"aggressive","label":"q₁ = 100、r = 0.001","description":"入力に対するペナルティが小さいと極が左へ移って角度は速く戻るが、最初のトルクが大きくなる。","inputs":{"q_angle":100,"r_torque":0.001}}
//|   - {"id":"gentle","label":"q₁ = 1、r = 1","description":"入力が高いと遅い極が虚軸に近づき、角度の戻りが遅くなる。","inputs":{"q_angle":1,"r_torque":1}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"riccati","path":"/rows/0/0","equals":"Accepted"}
//|       - {"artifact":"riccati","path":"/rows/0/4","approx":{"value":1.0,"atol":1e-12}}
//|       - {"artifact":"checks","path":"/rows/0/0","approx":{"value":11.02900283638495,"rtol":1e-12}}
//|       - {"artifact":"checks","path":"/rows/0/2","range":{"max":1e-13}}
//|       - {"artifact":"checks","path":"/rows/0/4","range":{"max":1e-13}}
//|       - {"artifact":"checks","path":"/rows/0/5","approx":{"value":0.03348096513817534,"rtol":1e-12}}
//|       - {"artifact":"poles","path":"/rows/0/1","approx":{"value":-63.47611341693832,"rtol":1e-10}}
//|       - {"artifact":"poles","path":"/rows/1/1","approx":{"value":-3.1659162149343842,"rtol":1e-10}}
//|       - {"path":"/outputs/3/state","equals":"satisfied"}
//|   - case: aggressive
//|     expect:
//|       - {"artifact":"checks","path":"/rows/0/2","range":{"max":1e-12}}
//|       - {"artifact":"poles","path":"/rows/0/1","approx":{"value":-632.4074824360825,"rtol":1e-9}}
//|       - {"artifact":"checks","path":"/rows/0/6","approx":{"value":-31.721028763952273,"rtol":1e-10}}
//|       - {"path":"/outputs/3/state","equals":"satisfied"}
//|   - case: gentle
//|     expect:
//|       - {"artifact":"checks","path":"/rows/0/2","range":{"max":1e-13}}
//|       - {"artifact":"poles","path":"/rows/1/1","approx":{"value":-1.3395453228404897,"rtol":1e-10}}
//|       - {"path":"/outputs/3/state","equals":"satisfied"}
use scioxide_linalg::{
    DirectSolveTermination, Estimation, GeneralEigenvaluesResult, LyapunovKind, Matrix,
    RiccatiKind, RiccatiOptions, RiccatiPlan, RiccatiProblem, solve_lyapunov, solve_riccati,
};

let (q1, q2, r) = (q_angle, 1.0_f64, r_torque);
// 状態 (θ [rad], θ̇ [rad/s])、入力 u [N·m]。a = g/ℓ [1/s²]、b = 1/(mℓ²) [1/(kg·m²)]。
let (a, b) = (
    9.81 / pendulum_length,
    1.0 / (pendulum_mass * pendulum_length.powi(2)),
);
let am = Matrix::from_rows(&[[0.0, 1.0], [a, 0.0]]).map_err(|e| e.to_string())?;
let bm = Matrix::from_rows(&[[0.0], [b]]).map_err(|e| e.to_string())?;
let qm = Matrix::from_rows(&[[q1, 0.0], [0.0, q2]]).map_err(|e| e.to_string())?;
let rm = Matrix::from_rows(&[[r]]).map_err(|e| e.to_string())?;
let problem = RiccatiProblem {
    a: am.view(),
    b: bm.view(),
    q: qm.view(),
    r: rm.view(),
    e: None,
    s: None,
};
// Plan は拡大ペンシルの QZ 分解で安定な収縮部分空間を求め、solve が X と K を取り出す。
// 閉ループの極の検査（QZ）を有効にすると、レポートに安定余裕が入る。
let options = RiccatiOptions::new().with_closed_loop_verification(Estimation::Estimate);
let plan =
    RiccatiPlan::new(problem, RiccatiKind::Continuous, options).map_err(|e| e.to_string())?;
let result = plan.solve().map_err(|e| e.to_string())?;
let report = result.report();
let termination = report.termination();
let name = match termination {
    DirectSolveTermination::Accepted => "Accepted",
    DirectSolveTermination::RankDeficient => "RankDeficient",
    DirectSolveTermination::IllConditioned => "IllConditioned",
    DirectSolveTermination::ResidualRejected => "ResidualRejected",
    DirectSolveTermination::StabilityRejected => "StabilityRejected",
};
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let sig4 = serde_json::json!({ "significantDigits": 4 });
let columns = serde_json::json!([
    { "key": "0", "label": "終了理由" },
    { "key": "1", "label": "残差 ‖Res‖_F", "type": "number", "format": sci2 },
    { "key": "2", "label": "後退誤差 [-]", "type": "number", "format": sci2 },
    { "key": "3", "label": "収縮部分空間の逆条件数 [-]", "type": "number", "format": sig4 },
    { "key": "4", "label": "安定余裕 [-]", "type": "number", "format": sig4, "nullText": "なし" }
]);
emit_table_with_columns!(
    columns,
    vec![(
        name,
        report.residual(),
        report.backward_error(),
        report.subspace_reciprocal_condition(),
        report.stability_margin(),
    )],
    metadata = serde_json::json!({ "id": "riccati" })
);
// 受理された場合だけ X と K が出力に反映される。
let mut gain_export = None;
if let Some((x, gain)) = result.solution().zip(result.gain()) {
    let (x, k) = (x.as_slice(), gain.as_slice());
    // 閉じた形の X と K（検算用）。
    // x₂ = (r/b²)(a + √(a² + q₁b²/r))、x₃ = √((r/b²)(2x₂ + q₂))、x₁ = (b²/r)x₂x₃ − a x₃。
    let x2 = r / (b * b) * (a + (a * a + q1 * b * b / r).sqrt());
    let x3 = (r / (b * b) * (2.0 * x2 + q2)).sqrt();
    let closed = [b * b / r * x2 * x3 - a * x3, x2, x2, x3];
    let scale = closed.iter().fold(0.0_f64, |s, v| s.max(v.abs()));
    let differ = |u: &[f64]| {
        u.iter()
            .zip(&closed)
            .fold(0.0_f64, |s, (p, q)| s.max((p - q).abs()))
            / scale
    };
    // ワンショット関数も閉ループの極を検査し、受理された X と K だけを返す。
    let (x_one, _) =
        solve_riccati(problem, RiccatiKind::Continuous).map_err(|e| e.to_string())?;
    // 閉ループ A_K = A − BK と、同じ制御則の計算コストの Lyapunov 方程式
    // A_Kᵀ P + P A_K = −(Q + Kᵀ r K)。
    let ak = Matrix::from_rows(&[[0.0, 1.0], [a - b * k[0], -b * k[1]]])
        .map_err(|e| e.to_string())?;
    let weight = Matrix::from_rows(&[
        [-(q1 + r * k[0] * k[0]), -r * k[0] * k[1]],
        [-r * k[0] * k[1], -(q2 + r * k[1] * k[1])],
    ])
    .map_err(|e| e.to_string())?;
    let p = solve_lyapunov(ak.view().transpose(), LyapunovKind::Continuous, &weight)
        .map_err(|e| e.to_string())?;
    let check_columns = serde_json::json!([
        { "key": "0", "label": "k₁ [N·m/rad]", "type": "number", "format": sig4 },
        { "key": "1", "label": "k₂ [N·m·s/rad]", "type": "number", "format": sig4 },
        { "key": "2", "label": "X と閉じた形の差（相対）[-]", "type": "number", "format": sci2 },
        { "key": "3", "label": "solve_riccati の X と閉じた形の差 [-]", "type": "number", "format": sci2 },
        { "key": "4", "label": "P と閉じた形の差（相対）[-]", "type": "number", "format": sci2 },
        { "key": "5", "label": "最小計算コスト J* = x₀ᵀXx₀ [-]", "type": "number", "format": sig4 },
        { "key": "6", "label": "初期トルク u(0) [N·m]", "type": "number", "format": sig4 }
    ]);
    emit_table_with_columns!(
        check_columns,
        vec![(
            k[0],
            k[1],
            differ(x),
            differ(x_one.as_slice()),
            differ(p.as_slice()),
            0.01 * x[0],
            -0.1 * k[0],
        )],
        metadata = serde_json::json!({ "id": "checks" })
    );
    // 閉ループの極: 固有値ソルバーと、閉じた形の K による λ² + bk₂λ + (bk₁ − a) = 0 の根。
    let poles = GeneralEigenvaluesResult::compute(&ak).map_err(|e| e.to_string())?;
    let mut computed: Vec<(f64, f64)> =
        poles.eigenvalues().iter().map(|z| (z.re, z.im)).collect();
    let (damping, stiffness) = (b * b / r * x3, b * b / r * x2 - a);
    let discriminant = damping * damping - 4.0 * stiffness;
    let mut formula = if discriminant >= 0.0 {
        let root = discriminant.sqrt();
        vec![
            (-0.5 * (damping + root), 0.0),
            (-0.5 * (damping - root), 0.0),
        ]
    } else {
        let root = (-discriminant).sqrt();
        vec![(-0.5 * damping, -0.5 * root), (-0.5 * damping, 0.5 * root)]
    };
    computed.sort_by(|p, q| p.partial_cmp(q).unwrap_or(std::cmp::Ordering::Equal));
    formula.sort_by(|p, q| p.partial_cmp(q).unwrap_or(std::cmp::Ordering::Equal));
    let pole_rows: Vec<_> = computed
        .iter()
        .zip(&formula)
        .enumerate()
        .map(|(j, (z, f))| (j + 1, z.0, z.1, f.0, f.1))
        .collect();
    let pole_columns = serde_json::json!([
        { "key": "0", "label": "極", "type": "integer" },
        { "key": "1", "label": "実部 [1/s]", "type": "number", "format": sig4 },
        { "key": "2", "label": "虚部 [1/s]", "type": "number", "format": sig4 },
        { "key": "3", "label": "閉じた形の実部 [1/s]", "type": "number", "format": sig4 },
        { "key": "4", "label": "閉じた形の虚部 [1/s]", "type": "number", "format": sig4 }
    ]);
    emit_table_with_columns!(
        pole_columns,
        pole_rows,
        metadata = serde_json::json!({ "id": "poles" })
    );
    gain_export = Some([k[0], k[1]]);
}
// 応答のセルに係数とゲインを渡す（受理されなければ gain は null）。
export!(a, a);
export!(b, b);
export!(gain, gain_export);
let outcome = if termination.is_success() {
    Outcome::satisfied("Riccati 方程式の解が残差と閉ループの安定性の検査で受理された")
} else {
    Outcome::failed("Riccati 方程式の解が受理されなかった")
};
let mut outcome = outcome
    .status(name)
    .diagnostic("残差", report.residual(), None)
    .diagnostic("後退誤差", report.backward_error(), None);
if let Some(margin) = report.stability_margin() {
    outcome = outcome.diagnostic("安定余裕", margin, None);
}
emit_outcome!(outcome);
```


既定の $m = 0.2$ kg、$\ell = 0.5$ m、$q_1 = 10$、$r = 0.1$ では、`RiccatiPlan` は `Accepted` を返し、残差は $4.0 \times 10^{-14}$、後退誤差は $1.3 \times 10^{-15}$ である。
ゲインは $K = (11.03\ \mathrm{N·m/rad}, 3.332\ \mathrm{N·m·s/rad})$ で、$X$ は閉じた形と相対 $3 \times 10^{-16}$ で一致し、`solve_riccati` の解とも同じ差になる。
Lyapunov 方程式による $P$ も閉じた形と $10^{-17}$ 以下の差で一致し、$X$ が最小計算コストを与えることを別の経路で確かめられる。
開ループの極 $\pm 4.43$ 1/s は、閉ループでは $-63.48$ と $-3.166$ の二つの負の実数に移り、固有値ソルバーと特性方程式の根は 14 桁一致する。
どちらの極も負の実軸上にあって大きさが 1 以上なので、安定余裕は 1 である。
最小計算コストは $J^\ast = 0.03348$、最初のトルクは $-1.103$ N·m である。

$q_1 = 100$、$r = 0.001$ では極が $-632.4$ と $-10.00$ に移り、最初のトルクの大きさは 31.7 N·m に増える。
$q_1 = 1$、$r = 1$ では遅い極が $-1.340$ まで虚軸に近づく。
$m = 1$ kg、$\ell = 1$ m、$q_1 = 100$、$r = 1$ では極が複素共役の対 $-3.487 \pm 1.360\mathrm{i}$ になり、安定余裕は $3.487/\lvert\lambda\rvert = 0.932$ に下がる。

## 閉ループの応答

閉ループ $\dot x = A_Kx$ の解は $x(t) = e^{A_Kt}x_0$ で、初期状態 $x_0 = (\theta_0, 0)$ からの角度は、極 $\lambda_1 \ne \lambda_2$ が実数なら

$$
\theta(t) = \theta_0\,\frac{\lambda_2 e^{\lambda_1 t} - \lambda_1 e^{\lambda_2 t}}{\lambda_2 - \lambda_1}
$$

で、$\lambda = \sigma \pm \mathrm{i}\omega$ の複素共役の対なら $\theta(t) = \theta_0 e^{\sigma t}(\cos\omega t - (\sigma/\omega)\sin\omega t)$ である。
次のセルは前のセルの $a$、$b$、$K$ を受け取り、初期角度 $\theta_0$（0.02〜0.3 rad）を選んで、$e^{A_Kt}$ を `matrix_function` で $t = 0, 0.05, \ldots, 3$ s について求める。
表は 6 つの時刻の角度とトルク $u = -Kx$ と、行列指数による角度と上の閉じた形の差を $\theta_0$ で割った値を示す。
二つのグラフは角度とトルクで、時間軸は連動する。

```rust
//| id: linalg-lqr-response
//| ref: linalg-lqr-response
//| title: 倒立振子の閉ループの応答
//| run: reactive
//| crates: [scioxide-core, scioxide-linalg]
//| dependsOn:
//|   solve: linalg-lqr-riccati
//| inputs:
//|   initial_angle: {"type":"range","label":"初期角度 θ₀ [rad]","description":"初期の角速度は 0。","min":0.02,"max":0.3,"step":0.02,"value":0.1}
//| cases:
//|   - {"id":"large-angle","label":"θ₀ = 0.3 rad","description":"線形の閉ループでは、角度もトルクも θ₀ に比例して 3 倍になる。","inputs":{"initial_angle":0.3}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"response","path":"/rows/2/1","approx":{"value":0.004439,"rtol":1e-3}}
//|       - {"artifact":"response","path":"/rows/2/3","range":{"max":1e-12}}
//|       - {"artifact":"response","path":"/rows/0/2","approx":{"value":-1.102900283638495,"rtol":1e-10}}
//|   - case: large-angle
//|     expect:
//|       - {"artifact":"response","path":"/rows/2/1","approx":{"value":0.013317,"rtol":1e-3}}
//|       - {"artifact":"response","path":"/rows/4/3","range":{"max":1e-12}}
use scioxide_linalg::{Matrix, MatrixFunction, matrix_function};

let a = solve["a"].as_f64().ok_or("a がない")?;
let b = solve["b"].as_f64().ok_or("b がない")?;
let gain = solve["gain"]
    .as_array()
    .ok_or("Riccati 方程式の解が受理されなかった")?;
let k1 = gain[0].as_f64().ok_or("k₁ がない")?;
let k2 = gain[1].as_f64().ok_or("k₂ がない")?;
let ak = Matrix::from_rows(&[[0.0, 1.0], [a - b * k1, -b * k2]]).map_err(|e| e.to_string())?;
// 閉じた形（検算用）: 特性方程式 λ² + bk₂λ + (bk₁ − a) = 0 の根による θ(t)。
let (damping, stiffness) = (b * k2, b * k1 - a);
let discriminant = damping * damping - 4.0 * stiffness;
let modal = |t: f64| {
    if discriminant > 0.0 {
        let root = discriminant.sqrt();
        let (l1, l2) = (-0.5 * (damping + root), -0.5 * (damping - root));
        initial_angle * (l2 * (l1 * t).exp() - l1 * (l2 * t).exp()) / (l2 - l1)
    } else {
        let (sigma, omega) = (-0.5 * damping, 0.5 * (-discriminant).sqrt());
        initial_angle
            * (sigma * t).exp()
            * ((omega * t).cos() - sigma / omega * (omega * t).sin())
    }
};
// 初期状態 x₀ = (θ₀, 0) からの応答 x(t) = exp(A_K t) x₀ とトルク u = −K x。
let (mut angle, mut torque, mut rows) = (Vec::new(), Vec::new(), Vec::new());
for step in 0..=60 {
    let t = 0.05 * f64::from(step);
    let scaled = ak.view().try_scale(t).map_err(|e| e.to_string())?;
    let e = matrix_function(&scaled, MatrixFunction::Exp).map_err(|e| e.to_string())?;
    let (theta, omega) = (
        initial_angle * e.as_slice()[0],
        initial_angle * e.as_slice()[2],
    );
    let u = -(k1 * theta + k2 * omega);
    angle.push([t, theta]);
    torque.push([t, u]);
    if matches!(step, 0 | 10 | 20 | 30 | 40 | 60) {
        rows.push((t, theta, u, (theta - modal(t)).abs() / initial_angle));
    }
}
let sig4 = serde_json::json!({ "significantDigits": 4 });
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let columns = serde_json::json!([
    { "key": "0", "label": "時間 t [s]", "type": "number", "format": { "fractionDigits": 1 } },
    { "key": "1", "label": "角度 θ [rad]", "type": "number", "format": sig4 },
    { "key": "2", "label": "トルク u [N·m]", "type": "number", "format": sig4 },
    { "key": "3", "label": "閉じた形との差 / θ₀ [-]", "type": "number", "format": sci2 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "response" })
);
emit_line_chart!(
    &vec![serde_json::json!({ "name": "角度 θ", "points": angle })],
    options = &serde_json::json!({
        "link": { "group": "lqr-response" },
        "xLabel": "時間 t [s]",
        "yLabel": "角度 θ [rad]"
    })
);
emit_line_chart!(
    &vec![serde_json::json!({ "name": "トルク u", "points": torque })],
    options = &serde_json::json!({
        "link": { "group": "lqr-response" },
        "xLabel": "時間 t [s]",
        "yLabel": "トルク u [N·m]"
    })
);
```

既定の $\theta_0 = 0.1$ rad では、最初に大きさ 1.10 N·m のトルクが加わり、角度は単調に 0 へ戻って 1 s 後に 0.0044 rad になる。
行列指数による角度は閉じた形と $\theta_0$ の $10^{-15}$ 倍以下の差で一致する。
閉ループは線形なので、$\theta_0 = 0.3$ rad では角度もトルクも 3 倍になる。
前のセルを $q_1 = 100$、$r = 0.001$ にすると角度は速く戻るが、トルクは 0.05 s 後に符号が変わる。
$q_1 = 1$、$r = 1$ では遅い極のため、3 s 後にも 0.0019 rad の角度が残る。

## まとめ

可制御性グラミアンは `solve_lyapunov` か `LyapunovPlan` で Lyapunov 方程式を解いて求め、受理と残差を読むときは Plan のレポートを使う。
有限時間のグラミアン $W(T)$ が要るときや検算には Van Loan の方法を使い、振動が減衰する既定の例では、振幅が $e$ 分の 1 になる時間 $2m/c$ の 12 倍を $T$ にとると、無限時間の値と 10 桁一致した。
LQR のゲインは `RiccatiPlan` のレポート（残差、収縮部分空間の逆条件数、`with_closed_loop_verification` による安定余裕）で受理を確かめてから使い、レポートが要らなければ、閉ループの安定性まで確かめる `solve_riccati` で求める。
同じゲインの計算コストを Lyapunov 方程式の解 $P$ で計算し直すと、$P = X$ がゲインの最適性の検算になる。
重み $q_1/r$ を大きくするほど閉ループの極は左へ移って角度は速く戻るが、最初のトルクが大きくなるので、重みは入力の上限と応答の速さの釣り合いで選ぶ。
