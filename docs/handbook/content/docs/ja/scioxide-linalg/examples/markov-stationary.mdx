ウインドウ口に並ぶ客の数、集団の個体数、化学反応の分子数のように、一回の遷移で状態が一つ増えるか減るかする確率過程を出生死滅過程という。
離散時間で状態 $n \in \{0, 1, \dots, K\}$ をとり、一歩ごとに確率 $p$ で $n + 1$ へ、確率 $q$ で $n - 1$ へ移り、残りの確率でとどまるとする（端では外へ出ない）。
時間の単位は遷移 1 回で、「歩」と書く。
この例題では長い時間の後の分布（定常分布）を線形代数の零空間の問題として求め、分布がそこへ近づく速さ（混合時間）を固有値から見積もる。

---

## 定常分布と零空間

遷移行列 $P$ の成分 $P_{ij}$ は状態 $i$ から $j$ へ移る確率で、各行の和は 1 である。
出生死滅型では $P$ は三重対角で、$P_{n,n+1} = p$、$P_{n,n-1} = q$、$P_{nn} = 1 - p - q$（端では $P_{00} = 1 - p$、$P_{KK} = 1 - q$）となる。
確率分布 $x_t$（行ベクトル）は $x_{t+1} = x_t P$ で進むので、定常分布 $\pi$ は

$$
\pi^{\mathsf T} P = \pi^{\mathsf T} \quad\Longleftrightarrow\quad (P^{\mathsf T} - I)\, \pi = 0, \qquad \sum_n \pi_n = 1
$$

を満たす。
連鎖が既約（どの状態からもどの状態へも到達できる）なら、$P^{\mathsf T} - I$ の零空間は 1 次元で、その基底を和が 1 になるよう正規化したものが $\pi$ である。
`null_space(&a, policy)` は SVD の右特異ベクトルから零空間の正規直交基底を返し、どの特異値を 0 とみなすかを `RankPolicy` で決める（[値域と零空間の基底](oxref:linalg-range-null-bases)）。
このページでは最大の特異値の $(K+1)\varepsilon$ 倍以下を 0 とみなす `RankPolicy::DimensionScaledEpsilon` を使う。

## 詳細つり合いと閉じた形

出生死滅過程は可逆で、隣り合う状態の間の確率の流れがつり合う（詳細つり合い）。

$$
\pi_n\, p = \pi_{n+1}\, q \quad\Longrightarrow\quad \pi_n = \frac{1 - \rho}{1 - \rho^{K+1}}\, \rho^{n}, \qquad \rho = \frac{p}{q}
$$

（$\rho = 1$ では一様分布 $1/(K+1)$）。
$\rho < 1$ では状態 0 の近くに、$\rho > 1$ では $K$ の近くに確率が集まる。

詳細つり合いがあると、$D = \operatorname{diag}(\pi)$ による相似変換 $S = D^{1/2} P D^{-1/2}$ が対称な三重対角行列になり、非対角は $\sqrt{pq}$、対角は $P$ と同じになる。
したがって $P$ の固有値はすべて実数で、$S$ の固有値として三重対角の固有値の解法で求められる。
$S$ の正規直交な固有ベクトルを $u$ とすると、$P$ の右固有ベクトルは $x = D^{-1/2}u$、左固有ベクトルは $y = D^{1/2}u$ である。

固有値にも閉じた形がある。
右固有ベクトル $Px = \lambda x$ の差分 $\delta_n = x_{n+1} - x_n$（$n = 0, \dots, K-1$）は、対角 $1 - p - q$、下の副対角 $q$、上の副対角 $p$ の $K$ 次の三重対角 Toeplitz 行列の固有ベクトルになるので、

$$
\lambda_1 = 1, \qquad \lambda_{j+1} = 1 - p - q + 2\sqrt{pq}\,\cos\frac{j\pi}{K+1} \quad (j = 1, \dots, K)
$$

である（$\delta = 0$ の定数ベクトルが $\lambda_1 = 1$ に当たる）。
$p + q \le 1$ では $j = 1$ の値が大きさで 2 番目なので、$\lvert\lambda_2\rvert = 1 - p - q + 2\sqrt{pq}\cos(\pi/(K+1))$ になる。
ギャップ $\gamma = 1 - \lvert\lambda_2\rvert$ は

$$
\gamma = (\sqrt p - \sqrt q)^2 + 2\sqrt{pq}\left(1 - \cos\frac{\pi}{K+1}\right)
$$

で、$p \ne q$ なら $K$ を大きくしても第 1 項が残る。
$p = q$ では第 1 項が消え、$\gamma \approx p\pi^2/(K+1)^2$ と $K^{-2}$ に比例して小さくなる。

次の定義のブロックはこのモデルを二つのセルで共有する。
`entry` が遷移確率 $P_{ij}$、`transition` が遷移行列 $P$、`stationary` が詳細つり合いによる閉じた形の定常分布に対応する（$q = 0.4$ は固定）。

```rust
//| id: linalg-birth-death-model
//| kind: definitions
//| title: 出生死滅型の遷移行列と閉じた形の定常分布
//| crates: [scioxide-core, scioxide-linalg]
use scioxide_core::SciOxideError;
use scioxide_linalg::Matrix;

/// 減る確率 q（固定）。
pub(crate) const Q: f64 = 0.4;

/// 状態 0, …, K の遷移確率 P_ij（増える確率 p、減る確率 q、端では外へ出ない）。
pub(crate) fn entry(k: usize, p: f64, i: usize, j: usize) -> f64 {
    if j == i + 1 {
        p
    } else if j + 1 == i {
        Q
    } else if i == j {
        let leave = if i == 0 {
            p
        } else if i == k {
            Q
        } else {
            p + Q
        };
        1.0 - leave
    } else {
        0.0
    }
}

/// 遷移行列 P（(K + 1) × (K + 1)、行の和が 1）。
pub(crate) fn transition(k: usize, p: f64) -> Result<Matrix<f64>, SciOxideError> {
    let dim = k + 1;
    let data = (0..dim * dim)
        .map(|idx| entry(k, p, idx / dim, idx % dim))
        .collect();
    Matrix::from_vec(dim, dim, data)
}

/// 閉じた形 πₙ = (1 − ρ)ρⁿ/(1 − ρ^{K+1})（ρ = p/q。ρ = 1 では一様分布。参照値）。
pub(crate) fn stationary(k: usize, p: f64) -> Vec<f64> {
    let rho = p / Q;
    let dim = k + 1;
    (0..dim)
        .map(|n| {
            if (rho - 1.0).abs() < 1e-12 {
                1.0 / dim as f64
            } else {
                (1.0 - rho) / (1.0 - rho.powi(dim as i32)) * rho.powi(n as i32)
            }
        })
        .collect()
}
```

次のセルは $q = 0.4$ を固定して、最大の状態 $K \in [5, 60]$ と増える確率 $p \in [0.04, 0.56]$ を選ぶ。
零空間から求めた $\pi$ を閉じた形と比べ、$\lvert\lambda_2\rvert$ を二つの経路で求めて閉じた形と比べる。
三重対角の経路は $S$ を `HermitianEigenDecomposition::tridiagonal(&diag, &off)` に渡し、一般の経路は非対称な $P$ を `GeneralEigenvaluesResult::compute(&p)` に渡す。
`null_space` と二つの固有値の計算はどれも既定の設定で動く所有値を返す API の関数である（[呼び出しの形](oxref:linalg-execution-forms)）。
表は零空間の次元とランク、$\pi$ と閉じた形の差の最大、閉じた形の $\lvert\lambda_2\rvert$ と各経路の誤差、ギャップを示し、図は $\pi$ と閉じた形（破線）を重ねる。
$K$、$p$、三重対角の経路の $\lvert\lambda_2\rvert$ と閉じた形の $\pi$ は次のセルに渡す。

```rust
//| id: linalg-markov-stationary
//| ref: linalg-markov-stationary
//| title: 定常分布を零空間として求め、第 2 固有値を二つの経路で比べる
//| run: reactive
//| uses: [linalg-birth-death-model]
//| crates: [scioxide-core, scioxide-linalg]
//| exports: [states, birth, lambda2, pi]
//| inputs:
//|   states: {"type":"range","label":"最大の状態 K","description":"状態は 0, 1, …, K。","min":5,"max":60,"step":1,"value":20}
//|   birth: {"type":"range","label":"増える確率 p","description":"減る確率 q = 0.4。ρ = p/q。","min":0.04,"max":0.56,"step":0.04,"value":0.32}
//| cases:
//|   - {"id":"strongly-tilted","label":"p = 0.04（ρ = 0.1）","description":"小さな確率の相対精度と、非対称な経路の λ₂ の精度が落ちる。","inputs":{"birth":0.04}}
//|   - {"id":"balanced","label":"p = 0.4（ρ = 1）","description":"一様分布になり、ギャップが最も小さい。","inputs":{"birth":0.4}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"stationary","path":"/rows/0/0","equals":1}
//|       - {"artifact":"stationary","path":"/rows/0/1","equals":20}
//|       - {"artifact":"stationary","path":"/rows/0/2","range":{"max":1e-13}}
//|       - {"artifact":"stationary","path":"/rows/0/4","range":{"max":1e-14}}
//|       - {"artifact":"stationary","path":"/rows/0/5","range":{"max":1e-13}}
//|       - {"artifact":"stationary","path":"/rows/0/6","approx":{"value":0.0124503,"atol":1e-6}}
//|   - case: strongly-tilted
//|     expect:
//|       - {"artifact":"stationary","path":"/rows/0/4","range":{"max":1e-14}}
//|       - {"artifact":"stationary","path":"/rows/0/5","range":{"min":1e-12,"max":1e-6}}
//|   - case: balanced
//|     expect:
//|       - {"artifact":"stationary","path":"/rows/0/6","approx":{"value":0.0089353,"atol":1e-6}}
use scioxide_linalg::{
    GeneralEigenvaluesResult, HermitianEigenDecomposition, Matrix, RankPolicy, null_space,
};

let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let fixed8 = serde_json::json!({ "fractionDigits": 8 });
let fixed6 = serde_json::json!({ "fractionDigits": 6 });
let (k, p) = (states.round() as usize, birth);
let dim = k + 1;
let matrix = transition(k, p).map_err(|e| e.to_string())?;
// (Pᵀ − I) の零空間の基底を求め、和が 1 になるよう正規化する。
let data = (0..dim * dim)
    .map(|idx| {
        let (i, j) = (idx / dim, idx % dim);
        entry(k, p, j, i) - if i == j { 1.0 } else { 0.0 }
    })
    .collect();
let shifted = Matrix::from_vec(dim, dim, data).map_err(|e| e.to_string())?;
let kernel =
    null_space(&shifted, RankPolicy::DimensionScaledEpsilon).map_err(|e| e.to_string())?;
let basis = kernel.basis();
let column: Vec<f64> = (0..dim)
    .map(|i| basis.as_slice()[i * basis.cols()])
    .collect();
let total: f64 = column.iter().sum();
let pi: Vec<f64> = column.iter().map(|v| v / total).collect();
let exact = stationary(k, p);
let pi_error = pi
    .iter()
    .zip(&exact)
    .fold(0.0_f64, |m, (a, b)| m.max((a - b).abs()));
// λ₂: 対称化した三重対角行列 S（対角は P と同じ、非対角 √(pq)）と、非対称な P の一般の固有値。
let diag: Vec<f64> = (0..dim).map(|i| entry(k, p, i, i)).collect();
let off = vec![(p * Q).sqrt(); dim - 1];
let tri = HermitianEigenDecomposition::tridiagonal(&diag, &off).map_err(|e| e.to_string())?;
let mut by_size: Vec<f64> = tri.eigenvalues().iter().map(|v| v.abs()).collect();
by_size.sort_by(|a, b| b.total_cmp(a));
let general = GeneralEigenvaluesResult::compute(&matrix).map_err(|e| e.to_string())?;
let mut general_size: Vec<f64> = general.eigenvalues().iter().map(|z| z.norm()).collect();
general_size.sort_by(|a, b| b.total_cmp(a));
let (lambda2, lambda2_general) = (by_size[1], general_size[1]);
// 検算: 閉じた形 |λ₂| = 1 − p − q + 2√(pq) cos(π/(K+1))（f64 の標準関数による参照値）。
let angle = std::f64::consts::PI / dim as f64;
let closed = 1.0 - p - Q + 2.0 * (p * Q).sqrt() * angle.cos();

let columns = serde_json::json!([
    { "key": "0", "label": "零空間の次元", "type": "integer" },
    { "key": "1", "label": "ランク", "type": "integer" },
    { "key": "2", "label": "max |πₙ − 閉じた形| [-]", "type": "number", "format": sci2 },
    { "key": "3", "label": "|λ₂|（閉じた形）[-]", "type": "number", "format": fixed8 },
    { "key": "4", "label": "三重対角の |λ₂| の誤差 [-]", "type": "number", "format": sci2 },
    { "key": "5", "label": "一般の固有値の |λ₂| の誤差 [-]", "type": "number", "format": sci2 },
    { "key": "6", "label": "ギャップ 1 − |λ₂| [-]", "type": "number", "format": fixed6 }
]);
let row = (
    basis.cols(),
    kernel.report().rank().rank(),
    pi_error,
    closed,
    (lambda2 - closed).abs(),
    (lambda2_general - closed).abs(),
    1.0 - lambda2,
);
emit_table_with_columns!(
    columns,
    vec![row],
    metadata = serde_json::json!({ "id": "stationary" })
);
let points = |values: &[f64]| -> Vec<[f64; 2]> {
    values
        .iter()
        .enumerate()
        .map(|(n, &v)| [n as f64, v])
        .collect()
};
emit_line_chart!(
    &vec![
        serde_json::json!({ "name": "零空間から求めた π", "points": points(&pi) }),
        serde_json::json!({
            "name": "閉じた形",
            "points": points(&exact),
            "style": { "lineType": "dashed" }
        })
    ],
    options = &serde_json::json!({ "xLabel": "状態 n [-]", "yLabel": "定常確率 π_n [-]" })
);
export!(states, k);
export!(birth, p);
export!(lambda2, lambda2);
export!(pi, exact);
```

既定の $K = 20$、$p = 0.32$（$\rho = 0.8$）では、零空間は 1 次元（ランク 20）で、正規化した基底は閉じた形と絶対誤差 $1.3 \times 10^{-15}$ で一致する。
閉じた形の $\lvert\lambda_2\rvert = 0.98754974$ に、三重対角の経路は表示の全桁で一致し、一般の固有値の経路も $2.2 \times 10^{-16}$ の誤差で一致する。
ギャップは 0.0125 である。

$p = 0.04$（$\rho = 0.1$）では状態 20 の確率が $10^{-20}$ 程度まで小さくなる。
零空間の基底の成分の絶対誤差は単位丸めの程度なので、小さな確率の相対誤差は大きくなる。
表が絶対誤差を示すのはこのためで、小さな確率を相対精度よく求めるには詳細つり合いの漸化式 $\pi_{n+1} = \rho\,\pi_n$ のような別の方法を使う。

同じ $p = 0.04$ では、一般の固有値の経路の $\lvert\lambda_2\rvert$ の誤差が $1.7 \times 10^{-9}$ に増え、三重対角の経路の誤差は $2.2 \times 10^{-16}$ にとどまる。
$P$ の右と左の固有ベクトル $x = D^{-1/2}u$、$y = D^{1/2}u$ は成分の大きさが逆向きに大きく偏るので、非対称な $P$ の[固有値の条件数](oxref:linalg-nonnormal-eigen-sensitivity) $\lVert x \rVert_2 \lVert y \rVert_2 / \lvert y^{\mathsf T}x \rvert$ が大きい。
`GeneralEigenOptions` の既定の平衡化（`PermuteAndScale`）を通しても、この行列ではこの拡大が残る。
対称な $S$ の固有値は条件数が 1 なので、三重対角の経路にはこの拡大がない。

$p = 0.4$（$\rho = 1$）では一様分布になり、ギャップは閉じた形 $0.8(1 - \cos(\pi/21)) = 0.0089353$ と一致して、$p$ を 0.04 刻みで変えた中で最も小さい。

## 混合時間

初期分布から定常分布までの距離を全変動距離 $d_{\mathrm{TV}}(t) = \tfrac12 \sum_n \lvert x_t(n) - \pi_n \rvert$ で測る。
$x_t - \pi$ は左固有ベクトル $y_j = D^{1/2}u_j$ で展開でき、各成分は $\lambda_j^t$ で減るので、$t$ が大きいと $d_{\mathrm{TV}}(t)$ は $\lvert\lambda_2\rvert^t$ に比例して減る。
最も悪い初期状態から $d_{\mathrm{TV}} \le 1/4$ になるまでの時間を混合時間 $t_{\mathrm{mix}}$ といい、可逆で既約な連鎖では

$$
t_{\mathrm{mix}} \le \frac{\ln(4/\pi_{\min})}{\gamma}
$$

が成り立つ（Levin、Peres と Wilmer の *Markov Chains and Mixing Times* 第 12 章）。
ここで $\gamma = 1 - \lvert\lambda_2\rvert$ は $1$ 以外の固有値の大きさの最大から測ったギャップ、$\pi_{\min}$ は定常確率の最小値である。

次のセルは前のセルの $K$、$p$、$\lvert\lambda_2\rvert$ と閉じた形の $\pi$ を受け取り、初期状態（0 か $K$）と追跡する時間 $T \in [50, 2000]$ 歩を選ぶ。
確率 1 で初期状態に置いた分布を、転置したビューの積 $x_{t+1}^{\mathsf T} = P^{\mathsf T} x_t^{\mathsf T}$（標準形式の `mul_vec`）で進め、全変動距離を対数軸に描く。
表は $\lvert\lambda_2\rvert$、ギャップ、$d_{\mathrm{TV}} \le 1/4$ に初めて達した時刻、混合時間の上界、時刻 $T$ の全変動距離と、終盤 50 歩の減衰率 $(d_{\mathrm{TV}}(T)/d_{\mathrm{TV}}(T-50))^{1/50}$ を示す。
減衰率は $\lvert\lambda_2\rvert$ と比べる独立な検算で、$d_{\mathrm{TV}}(T)$ が丸め誤差の水準（$10^{-12}$ 以下）に達していれば求めない。
破線の参照線 $\lvert\lambda_2\rvert^t$ は、全変動距離が $10^{-12}$ より大きい最後の時刻を通す。
横線は判定の水準 $d_{\mathrm{TV}} = 1/4$、縦線はそれを初めて下回った時刻である。

```rust
//| id: linalg-markov-mixing
//| ref: linalg-markov-mixing
//| title: 全変動距離の減衰と混合時間の上界
//| run: reactive
//| uses: [linalg-birth-death-model]
//| crates: [scioxide-core, scioxide-linalg]
//| dependsOn:
//|   chain: linalg-markov-stationary
//| inputs:
//|   start: {"type":"select","label":"初期状態","description":"確率 1 で置く状態。","options":["0","K"],"value":"K"}
//|   steps: {"type":"range","label":"時間 T [歩]","description":"追跡する歩数。","min":50,"max":2000,"step":50,"value":400}
//| cases:
//|   - {"id":"from-zero","label":"状態 0 から","description":"定常分布の確率が大きい側から出発し、早く混合する。","inputs":{"start":"0"}}
//|   - {"id":"short","label":"T = 50 歩","description":"追跡する時間内に 1/4 を下回らない。","inputs":{"steps":50}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"mixing","path":"/rows/0/2","equals":152}
//|       - {"artifact":"mixing","path":"/rows/0/3","approx":{"value":598,"atol":1}}
//|       - {"artifact":"mixing","path":"/rows/0/5","approx":{"value":0.98755,"atol":1e-5}}
//|   - case: from-zero
//|     expect:
//|       - {"artifact":"mixing","path":"/rows/0/2","equals":17}
//|       - {"artifact":"mixing","path":"/rows/0/5","approx":{"value":0.98755,"atol":1e-5}}
//|   - case: short
//|     expect:
//|       - {"artifact":"mixing","path":"/rows/0/2","equals":null}
//|       - {"artifact":"mixing","path":"/rows/0/4","range":{"min":0.25}}
let k = chain["states"].as_u64().ok_or("K がない")? as usize;
let p = chain["birth"].as_f64().ok_or("p がない")?;
let lambda2 = chain["lambda2"].as_f64().ok_or("λ₂ がない")?;
let pi: Vec<f64> = serde_json::from_value(chain["pi"].clone()).map_err(|e| e.to_string())?;
let matrix = transition(k, p).map_err(|e| e.to_string())?;
let mut x = vec![0.0_f64; k + 1];
x[if start == "K" { k } else { 0 }] = 1.0;
let mut x = scioxide_linalg::Vector::from_vec(x);
let t_end = steps.round() as usize;
// d_TV(t) = ½ Σ |x_t(n) − πₙ| を t = 0, …, T で記録する。
let mut history = Vec::with_capacity(t_end + 1);
for t in 0..=t_end {
    let tv = 0.5
        * x.as_slice()
            .iter()
            .zip(&pi)
            .map(|(a, b)| (a - b).abs())
            .sum::<f64>();
    history.push(tv);
    if t < t_end {
        // x_{t+1}ᵀ = Pᵀ x_tᵀ を転置したビューの標準形式の積で進める。
        x = matrix
            .view()
            .transpose()
            .mul_vec(&x)
            .map_err(|e| e.to_string())?;
    }
}
let mixing = history.iter().position(|&tv| tv <= 0.25);
let last = history[t_end];
// 検算: 終盤 50 歩の減衰率。丸めの水準（10⁻¹² 以下）の値からは求めない。
let rate = (last > 1e-12).then(|| (last / history[t_end - 50]).powf(1.0 / 50.0));
// 0 は対数軸に描けないので除く。
let points: Vec<[f64; 2]> = history
    .iter()
    .enumerate()
    .filter(|(_, tv)| **tv > 0.0)
    .map(|(t, &tv)| [t as f64, tv])
    .collect();
// 参照線 |λ₂|^t は丸めの水準に達する前の最後の点を通し、d_TV ≤ 1 の範囲だけを描く。
let anchor = history
    .iter()
    .rposition(|&tv| tv > 1e-12)
    .map_or((0.0, 1.0), |t| (t as f64, history[t]));
let reference: Vec<[f64; 2]> = (0..=t_end)
    .step_by(10)
    .map(|t| [t as f64, anchor.1 * lambda2.powf(t as f64 - anchor.0)])
    .filter(|q| q[1] > 0.0 && q[1] <= 1.0)
    .collect();
let pi_min = pi.iter().copied().fold(f64::INFINITY, f64::min);
let fixed8 = serde_json::json!({ "fractionDigits": 8 });
let fixed6 = serde_json::json!({ "fractionDigits": 6 });
let fixed0 = serde_json::json!({ "fractionDigits": 0 });
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let columns = serde_json::json!([
    { "key": "0", "label": "|λ₂| [-]", "type": "number", "format": fixed8 },
    { "key": "1", "label": "ギャップ γ [-]", "type": "number", "format": sci3 },
    { "key": "2", "label": "実測 t(d_TV ≤ 1/4) [歩]", "type": "integer", "nullText": "T 歩では未到達" },
    { "key": "3", "label": "上界 ln(4/π_min)/γ [歩]", "type": "number", "format": fixed0 },
    { "key": "4", "label": "d_TV(T) [-]", "type": "number", "format": sci2 },
    { "key": "5", "label": "終盤 50 歩の減衰率 [-]", "type": "number", "format": fixed6, "nullText": "丸めの水準" }
]);
let row = (
    lambda2,
    1.0 - lambda2,
    mixing,
    (4.0 / pi_min).ln() / (1.0 - lambda2),
    last,
    rate,
);
emit_table_with_columns!(
    columns,
    vec![row],
    metadata = serde_json::json!({ "id": "mixing" })
);
let mut marks = vec![serde_json::json!({
    "kind": "line",
    "axis": "y",
    "value": 0.25,
    "label": "d_TV = 1/4"
})];
if let Some(t) = mixing {
    marks.push(serde_json::json!({
        "kind": "line",
        "axis": "x",
        "value": t as f64,
        "label": "混合時間（実測）"
    }));
}
emit_line_chart!(
    &vec![
        serde_json::json!({ "name": "d_TV(t)", "points": points }),
        serde_json::json!({
            "name": "|λ₂|^t の参照線",
            "points": reference,
            "style": { "lineType": "dashed" }
        })
    ],
    options = &serde_json::json!({
        "xLabel": "時間 t [歩]",
        "yLabel": "全変動距離 d_TV [-]",
        "yType": "log",
        "annotations": marks
    })
);
```

既定の $K = 20$、$p = 0.32$ で状態 $K$ から始めると、全変動距離は 152 歩で $1/4$ を下回り、上界 598 歩の 4 分の 1 ほどである。
400 歩では $1.1 \times 10^{-2}$ まで下がり、終盤 50 歩の減衰率 0.987552 は $\lvert\lambda_2\rvert = 0.987550$ と $2.3 \times 10^{-6}$ の差で一致する。
状態 0 から始めると定常分布の確率が大きい側から出発するので、17 歩で $1/4$ を下回る。
$T = 50$ 歩では $1/4$ に届かず（$d_{\mathrm{TV}}(50) = 0.73$）、時刻の欄は未到達になる。

前のセルで $p = 0.4$（$\rho = 1$）、$K = 60$ にし、このセルで $T = 2000$ 歩にすると、ギャップが $1.06 \times 10^{-3}$ まで小さくなり、混合に 882 歩かかる（上界は 5182 歩）。
前のセルで $p = 0.04$ にすると、最初の数十歩は確率の塊が状態 0 へ流れるだけで距離がほとんど減らず、61 歩で $1/4$ を下回る。
その後は $\lvert\lambda_2\rvert = 0.81$ の速さで減り、$10^{-15}$ 付近の丸め誤差の水準で止まるので、減衰率の欄は「丸めの水準」になる。

## まとめ

既約な Markov 連鎖の定常分布は $P^{\mathsf T} - I$ の 1 次元の零空間なので、`null_space` の基底を和が 1 になるよう正規化して求められる。
零空間の基底は絶対誤差が単位丸めの程度なので、$10^{-15}$ より小さな確率が必要なら詳細つり合いの漸化式を使う。
可逆な連鎖の固有値を求めるには、詳細つり合いで対称化した行列を `HermitianEigenDecomposition::tridiagonal` などの対称な固有値の解法に渡すのがよい。
この例では非対称な $P$ のまま `GeneralEigenvaluesResult` で解くと、確率が強く偏る $\rho = 0.1$ で $\lvert\lambda_2\rvert$ の誤差が $1.7 \times 10^{-9}$ まで増えた。
ギャップ $\gamma = 1 - \lvert\lambda_2\rvert$ から混合時間の上界 $\ln(4/\pi_{\min})/\gamma$ が求まり、全変動距離は終盤に $\lvert\lambda_2\rvert^t$ の速さで減る。
