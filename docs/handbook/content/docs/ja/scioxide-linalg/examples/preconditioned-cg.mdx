断熱材と金属を重ねた壁や、温度によって熱伝導率が大きく変わる材料では、拡散方程式の係数が場所によって何桁も変わる。
このような方程式を離散化した行列は条件数が大きく、共役勾配法（CG）の反復回数が増える。
前処理は $A$ に近く逆の作用 $M^{-1}r$ を安く計算できる対称正定値な行列 $M$ を選び、CG の収束を決める条件数を $A$ のものから $M^{-1/2}AM^{-1/2}$ のものに置き換える。
最も計算コストの小さい前処理は対角成分だけを使う Jacobi 前処理 $M = \operatorname{diag}(A)$ で、行と列の尺度の違いを打ち消す。
この例題では、Jacobi 前処理が条件数を大きく下げる熱伝導率の分布と半分程度にしか下げない分布を、条件数の閉じた形と CG の反復回数の上界で確かめる。

## 定常熱伝導の離散化

長さ $L = 1$ m、断面積 1 m² の棒の熱伝導率を $k(x)$ [W/(m·K)] とし、左端の温度を 0 K、右端の温度を 1 K（基準の温度からの差）に保つ。
内部に熱源がないとき、定常温度 $u(x)$ [K] は

$$
-\frac{d}{dx}\Bigl(k(x) \frac{du}{dx}\Bigr) = 0, \qquad u(0) = 0, \quad u(1) = 1
$$

を満たす。
区間を $N + 1$ 等分して節点 $x_i = ih$（$h = 1/(N+1)$ m）に温度 $u_i$ を置き、隣り合う節点の間の熱コンダクタンスを $c_{i+1/2} = k(x_{i+1/2})/h$ [W/K] とする。
内部の節点 $i$ での熱流 [W] の釣合いは

$$
-c_{i-1/2}\, u_{i-1} + \bigl(c_{i-1/2} + c_{i+1/2}\bigr) u_i - c_{i+1/2}\, u_{i+1} = 0
$$

となる。
境界の値 $u_0 = 0$、$u_{N+1} = 1$ を右辺に移すと、三重対角行列 $A$ [W/K] の方程式 $Au = b$ が得られる。
右辺は $b_N = c_{N+1/2}$ [W] だけが 0 でない。
$A$ は対称で対角が正であり、各行で非対角成分の絶対値を足すと対角以下、両端の行では対角より小さくなる。
Gershgorin の定理から $A$ の固有値は 0 以上である。
非対角が 0 でない三重対角行列は既約なので、狭義の対角優位が一つの行で成り立てば $A$ は正則になり（Taussky の定理）、$A$ は対称正定値である。

### 熱抵抗の直列による厳密解

熱源がないので、各区間を流れる熱流 $q = c_{i+1/2}(u_{i+1} - u_i)$ はすべて等しい。
したがって温度は熱抵抗 $1/c_{i+1/2}$ [K/W] の直列で決まり、離散方程式の厳密解は

$$
u_i = \frac{\sum_{j=0}^{i-1} 1/c_{j+1/2}}{\sum_{j=0}^{N} 1/c_{j+1/2}}
$$

である。
これは離散化誤差を含まない離散方程式そのものの解なので、CG の解の誤差を直接測れる。

### 二つの熱伝導率の分布

熱伝導率の最小値を 1 W/(m·K) にそろえ、最大値との比 $10^d$ の桁数 $d$ を変えて、次の二つの分布を比べる。

- 指数的な変化：$k(x) = 10^{dx}$。
  左端から右端へなめらかに $d$ 桁増える。
- 2 種類の層：棒を厚さ 0.1 m の 10 層に分け、左端から $k = 10^d$ の層と $k = 1$ の層を交互に置く。

次のブロックは、このページの二つのセルが共有する定義である。
`bar` は分布と $d$ からコンダクタンス $c_{j+1/2}$ と $A$ の対角・非対角を作り、`exact` は熱抵抗の直列による厳密解を返す。
`scaled_off_diagonal` は次の節の Jacobi 前処理後の行列の非対角を返す。
`extremes` は対称三重対角行列の最小と最大の固有値を、`condition` はその比の条件数を返す。
両端の固有値は `EigenIndexRange` で 1 個ずつ選び、`EigenvalueAccuracy::Relative` を指定して、Sturm 列の二分法で各固有値の大きさに対する相対精度まで求める。
既定の `EigenvalueAccuracy::Absolute`（QL/QR 法か分割統治法）はスペクトル全体の大きさに対する絶対精度で止まるので、条件数が $10^{12}$ に近い行列では最小固有値の相対誤差が $\varepsilon_{\mathrm{mach}}\kappa$ の程度になりうる。

```rust
//| id: linalg-preconditioned-cg-model
//| kind: definitions
//| title: 熱伝導率が不均一な棒の三重対角行列
//| crates: [scioxide-core, scioxide-linalg]
use scioxide_core::SciOxideError;
use scioxide_linalg::{
    EigenIndexRange, EigenvalueAccuracy, HermitianEigenOptions, HermitianEigenvaluesResult,
};

/// 熱伝導率 k(x) [W/(m·K)] の分布。最小値はどちらも 1 W/(m·K)。
#[derive(Clone, Copy, PartialEq)]
pub(crate) enum Profile {
    /// k(x) = 10^(d x)。
    Exponential,
    /// 厚さ 0.1 m の層に、左端から k = 10^d と k = 1 を交互に置く。
    Layered,
}

/// 内部の節点 N 個の棒の行列 A [W/K]。
pub(crate) struct Bar {
    /// 区間 j（節点 j と j + 1 の間）のコンダクタンス c_{j+1/2} = k/h [W/K]、j = 0, …, N。
    pub(crate) conductance: Vec<f64>,
    /// A の対角 c_{i−1/2} + c_{i+1/2}。
    pub(crate) diagonal: Vec<f64>,
    /// A の非対角 −c_{i+1/2}（長さ N − 1）。
    pub(crate) off_diagonal: Vec<f64>,
}

/// 内部の節点 nodes 個、熱伝導率の変化 decades 桁の棒（h = 1/(N + 1) m）。
pub(crate) fn bar(nodes: usize, decades: f64, profile: Profile) -> Bar {
    let h = 1.0 / (nodes + 1) as f64;
    let conductivity = |x: f64| match profile {
        Profile::Exponential => 10.0_f64.powf(decades * x),
        Profile::Layered if (x * 10.0).floor() as usize % 2 == 0 => 10.0_f64.powf(decades),
        Profile::Layered => 1.0,
    };
    let conductance: Vec<f64> = (0..=nodes)
        .map(|j| conductivity((j as f64 + 0.5) * h) / h)
        .collect();
    let diagonal = (0..nodes)
        .map(|i| conductance[i] + conductance[i + 1])
        .collect();
    let off_diagonal = (1..nodes).map(|i| -conductance[i]).collect();
    Bar {
        conductance,
        diagonal,
        off_diagonal,
    }
}

impl Bar {
    /// 熱抵抗の直列による離散方程式の厳密解 u_i [K]（検算用の参照値）。
    pub(crate) fn exact(&self) -> Vec<f64> {
        let total: f64 = self.conductance.iter().map(|c| 1.0 / c).sum();
        let mut partial = 0.0;
        self.conductance[..self.diagonal.len()]
            .iter()
            .map(|c| {
                partial += 1.0 / c;
                partial / total
            })
            .collect()
    }

    /// Jacobi 前処理後の行列 D^{−1/2} A D^{−1/2} の非対角（対角はすべて 1）。
    pub(crate) fn scaled_off_diagonal(&self) -> Vec<f64> {
        self.off_diagonal
            .iter()
            .enumerate()
            .map(|(i, o)| o / (self.diagonal[i] * self.diagonal[i + 1]).sqrt())
            .collect()
    }
}

/// 対称正定値な三重対角行列の最小と最大の固有値 (λ_min, λ_max)。
/// 両端の固有値だけを Sturm 二分法で、それぞれの大きさに対する相対精度で求める。
pub(crate) fn extremes(diagonal: &[f64], off_diagonal: &[f64]) -> Result<(f64, f64), SciOxideError> {
    let n = diagonal.len();
    let options =
        HermitianEigenOptions::default().with_eigenvalue_accuracy(EigenvalueAccuracy::Relative);
    let eigenvalue = |index: usize| -> Result<f64, SciOxideError> {
        let range = EigenIndexRange::new(index, index + 1)?;
        let values = HermitianEigenvaluesResult::tridiagonal_with_options(
            diagonal,
            off_diagonal,
            &options.with_index_range(range),
        )?;
        Ok(values.eigenvalues()[0])
    };
    Ok((eigenvalue(0)?, eigenvalue(n - 1)?))
}

/// 条件数 κ = λ_max/λ_min。
pub(crate) fn condition(diagonal: &[f64], off_diagonal: &[f64]) -> Result<f64, SciOxideError> {
    let (lowest, highest) = extremes(diagonal, off_diagonal)?;
    Ok(highest / lowest)
}
```

## 条件数と Jacobi 前処理

CG の反復回数は前処理 $M$ による $M^{-1/2}AM^{-1/2}$ の条件数 $\kappa = \lambda_{\max}/\lambda_{\min}$ で決まる（次の節）。
Jacobi 前処理 $M = D = \operatorname{diag}(A)$ では、この行列は対角がすべて 1、非対角が $a_{i,i+1}/\sqrt{a_{ii}a_{i+1,i+1}}$ の三重対角行列になる。
その条件数を $\kappa_J$、前処理のない $A$ の条件数を $\kappa(A)$ と書く。

一様な棒（$d = 0$）では $A = c\,\operatorname{tridiag}(-1, 2, -1)$ の固有値が $2c\,(1 - \cos(j\pi h))$（$j = 1, \ldots, N$）なので、条件数は

$$
\kappa_0 = \cot^2\frac{\pi h}{2} \approx \frac{4}{\pi^2 h^2}
$$

である。
対角が定数 $2c$ なので、Jacobi 前処理は $A$ を定数で割るだけで、$\kappa_J = \kappa(A) = \kappa_0$ となる。

指数的な変化では、隣り合う区間のコンダクタンスの比が $q = c_{i+3/2}/c_{i+1/2} = 10^{dh}$ で一定になる。
このとき前処理後の行列の非対角はすべて $-s$、$s = 1/(\sqrt q + 1/\sqrt q)$ に等しく、行列は Toeplitz 行列 $\operatorname{tridiag}(-s, 1, -s)$ そのものになる。
固有値は $1 - 2s\cos(j\pi h)$ なので、条件数は閉じた形

$$
\kappa_J = \frac{1 + 2s\cos(\pi h)}{1 - 2s\cos(\pi h)}
$$

で書ける。
$q > 1$ では $s < 1/2$ なので、$d$ を大きくするほど対角優位が強まり、$\kappa_J$ は $\kappa_0$ より小さくなる。
一方 $\kappa(A)$ は、対角の大きさが $10^d$ 倍の範囲に広がるので大きくなる。

2 種類の層では層の内部の $k$ が一定なので、前処理後の行列は層の内部で一様な棒と同じ形になり、違いは層の境界だけに現れる。
前処理後の行列と相似な $D^{-1}A$ は各行の対角が 1、非対角の絶対値の和が 1 以下なので、Gershgorin の定理から $\lambda_{\max} \le 2$ で、一様な棒の $1 + \cos(\pi h)$ とほぼ同じである。
最小の固有値に対応するなめらかな温度分布では、$u^{\mathsf T}Au$ は熱抵抗の直列、つまり熱伝導率の調和平均 $\bar k_h$ で決まり、$u^{\mathsf T}Du$ は対角、つまり相加平均 $\bar k_a$ で決まる。
このことから、層の厚さが等しい場合の目安

$$
\kappa_J \approx \kappa_0\,\frac{\bar k_a}{\bar k_h}, \qquad \frac{\bar k_a}{\bar k_h} = \frac{(10^d + 1)^2}{4 \cdot 10^d} \approx \frac{10^d}{4}
$$

が得られる。
これは均質化による見積もりで、上界ではない。
相加平均と調和平均の比は、尺度をそろえる対角の前処理では打ち消せない。

次のセルは内部の節点の数 $N$（50〜400）を選び、$d = 0, 1, \ldots, 8$ について二つの分布の $\kappa(A)$ と $\kappa_J$ を固有値から求め、閉じた形と目安と比べる。
表の列は指数的な変化の $\kappa(A)$、$\kappa_J$、閉じた形と、2 種類の層の $\kappa(A)$、$\kappa_J$、目安である。
グラフは同じ値を対数軸に描き、閉じた形と目安を破線、一様な棒の $\kappa_0$ を横線で示す。
閉じた形は固有値ソルバーと独立に計算した値なので、二つの一致が固有値ソルバーの検算になる。

## 反復回数の上界と前処理付き CG

CG の $k$ 回目の反復解 $x_k$ は、Krylov 部分空間 $x_0 + \mathcal K_k(M^{-1}A, M^{-1}r_0)$ の中で誤差 $e_k = x_k - x^\ast$ の $A$ ノルム $\lVert e_k \rVert_A = \sqrt{e_k^{\mathsf T}Ae_k}$ を最小にする（前処理なしは $M = I$）。
Chebyshev 多項式による評価から、$\rho = (\sqrt\kappa - 1)/(\sqrt\kappa + 1)$ として

$$
\lVert e_k \rVert_A \le 2\rho^k\,\lVert e_0 \rVert_A
$$

が成り立つ（$\kappa$ は $M^{-1/2}AM^{-1/2}$ の条件数）。
一方 `CgSolver` が停止を判定するのは誤差の $A$ ノルムではなく真の残差で、`ResidualTolerance::new(atol, rtol)` に対して $\lVert b - Ax_k \rVert_2 \le \mathrm{atol} + \mathrm{rtol}\,\lVert b \rVert_2$ を満たすと止まる。
このページは $\mathrm{atol} = 0$、$\mathrm{rtol} = \varepsilon = 10^{-10}$ とする。
$\lambda_{\min}(A)\lVert e \rVert_A^2 \le \lVert Ae \rVert_2^2 \le \lambda_{\max}(A)\lVert e \rVert_A^2$ を使って誤差の評価を残差に移すと、$x_0 = 0$（$r_0 = b$）から

$$
\frac{\lVert r_k \rVert_2}{\lVert b \rVert_2} \le 2\sqrt{\kappa(A)}\,\rho^k
$$

となる。
右辺が $\varepsilon$ 以下になる最小の $k$ を反復回数の上界

$$
k_\kappa = \left\lceil \frac{\ln\bigl(2\sqrt{\kappa(A)}/\varepsilon\bigr)}{\ln(1/\rho)} \right\rceil \approx \frac{\sqrt\kappa}{2}\,\ln\frac{2\sqrt{\kappa(A)}}{\varepsilon}
$$

とする。
厳密な算術では CG は $N$ 回以内（$M^{-1}A$ の相異なる固有値の数以内）で厳密解に達するので、反復回数は $\min(k_\kappa, N)$ 以下になる。
浮動小数点の CG では残差と探索方向の直交性が丸め誤差で失われるので、$N$ 回での終了は保証されない。
上界 $k_\kappa$ のほうは、丸め誤差のもとでも目安としてほぼ成り立つことが知られている（Greenbaum, 1989）。
1 次元の問題では $\kappa_0 \approx 0.4N^2$ なので、$k_\kappa$ は $N$ の 10 倍程度になる。
丸め誤差で有限回の終了が崩れなければ、反復回数を決めるのは $N$ のほうである。

### CgSolver の呼び出しと前処理

`CgSolver::new(tolerance, max_iterations)` は許容誤差 `ResidualTolerance` と反復回数の上限 `Budget` を取る手法オブジェクトで、設定だけを持ち、次元は呼び出しごとに読む。
各反復は $A$ との積と $M^{-1}$ の作用を 1 回ずつ行い、作業領域は長さ $N$ のベクトル 6 本である。
漸化式で更新する残差は 50 回ごとに真の残差 $b - Ax$ に置き換え、収束は真の残差を計算し直してから受理する。
`with_history(true)` を付けると、残差のノルムを反復ごとに記録する。
最初の値は初期値の真の残差、最後の値は返した解の真の残差で、その間は 50 回ごとと収束の候補になったときだけが真の残差、ほかは漸化式で更新した残差である。
呼び出し方は次の二つである（呼び出しの形の定義は[作業領域・実行コンテキスト・試行記録](oxref:linalg-execution-forms)）。

- 標準形式 `solver.solve(&a, &b)` は初期値 0、前処理なしで解き、解のベクトルを返す。
  許容誤差に届かずに止まると `ConvergenceFailure` のエラーになる。
- オプション付き形式 `solver.solve_with_options(&a, &b, preconditioning, x0)` は前処理と初期値（`None` なら 0）を取り、`IterativeSolveResult`（解、レポート、残差の履歴）を返す。
  収束しなくても `Ok` で、解は検査点で真の残差を確かめた反復解のうち残差が最小のものである（[取り消し・回数上限による停止と受理済み反復解の読み方](../accepted-state-and-cancellation/)）。

前処理は `Preconditioning` で渡す。
`Preconditioning::None` は $M = I$ で、`Preconditioning::Inverse(&p)` は scioxide-core の `Preconditioner` を実装する値 `p` の作用を使う。
`p` が作用させるのは $M$ ではなく $M^{-1}$ である。
CG は $M^{-1}$ を対称に作用させるので、$M^{-1}$ は対称正定値でなければならない。
ソルバーは $r^{\mathsf T}M^{-1}r \le 0$ を検出すると `Breakdown(Preconditioner)`、探索方向の曲率 $p^{\mathsf T}Ap \le 0$ を検出すると `Breakdown(NonPositiveCurvature)` で止まる。

このページの前処理は scioxide-sparse が提供する。
`JacobiPreconditioner::new(&a)` は CSR 行列の対角から $D^{-1}$ を一度だけ計算し、対角に 0 があれば `Singular` のエラーを返す。
`IncompleteFactor::ic0(&a)` は、$A$ の下三角と同じ非零パターンを持つ不完全 Cholesky 分解 IC(0) を作る（[不完全分解と反復法の前処理](../../../scioxide-sparse/algorithms/incomplete-factorizations/)）。
三重対角行列の Cholesky 分解ではフィルが生じないので、ここでの IC(0) は完全な Cholesky 分解で、$M = A$ になる。
厳密な算術では $\kappa = 1$ で、CG は 1 回で終わる。
行列は `sparse_diagonals` で 3 本の対角から CSR 形式に組み立てる。
`CsrMatrix` は `LinearOperator` を実装するので、そのまま CG に渡せる。

### 丸め誤差による残差の下限

浮動小数点数で表した解 $x$ の残差 $b - Ax$ を計算すると、行列とベクトルの積の丸め誤差だけで $\varepsilon_{\mathrm{mach}}\lVert A \rVert_2\lVert x \rVert_2$ 程度の誤差が残差に入る。
そのため相対残差 $\lVert b - Ax \rVert_2/\lVert b \rVert_2$ は、どの解法でも目安 $\varepsilon_{\mathrm{mach}}\lVert A \rVert_2\lVert x \rVert_2/\lVert b \rVert_2$ を大きく下回るとは期待できない。
この目安が許容誤差 $\varepsilon$ を上回る問題では、後退誤差が $\varepsilon_{\mathrm{mach}}$ の程度の解でも収束と判定されない。
後退誤差 $\eta = \lVert b - Ax \rVert_2/(\lVert A \rVert_2\lVert x \rVert_2 + \lVert b \rVert_2)$ は、計算した解 $x$ を厳密解に持つように $A$ と $b$ を変えるときの、最小の相対的な変化の大きさである。
相対残差と $\eta$ の比は $(\lVert A \rVert_2\lVert x \rVert_2 + \lVert b \rVert_2)/\lVert b \rVert_2$ なので、表の二つの列から $\lVert A \rVert_2\lVert x \rVert_2/\lVert b \rVert_2$ を読み取れる。
`CgSolver` はこの下限を停滞の判定に使う。
検査点の真の残差がそれまでの最小の残差を下回らないとき、ソルバーは最小の残差 $\lVert r_{\mathrm{best}} \rVert_2$ を丸め誤差の下限

$$
16\,\varepsilon_{\mathrm{mach}}\bigl(\lVert b \rVert_2 + \lVert A(s \circ x) \rVert_2\bigr)
$$

と比べ、下限以下なら `Stagnation` で止まる。
$x$ は真の残差を確かめた反復解のうち残差が最小のもので、最新の反復解ではない。
$s$ は成分が $\pm 1$ の固定の符号の列で、$s \circ x$ は $x$ の成分の符号をそれに従って入れ替えたベクトルである。
解の近くでは積 $a_{ij}x_j$ が打ち消し合って $\lVert Ax \rVert_2$ が小さくなるが、$\lVert A(s \circ x) \rVert_2$ はその打ち消しを除いた $\lVert \lvert A \rvert \lvert x \rvert \rVert_2$ の大きさを、$A$ との積 1 回で見積もる。
この積も作用素の評価回数に数えられる。
$\lVert A(s \circ x) \rVert_2 \le \lVert A \rVert_2\lVert x \rVert_2$ なので、$\lVert A \rVert_2\lVert x \rVert_2$ が $\lVert b \rVert_2$ より十分大きい問題では、下限を $\lVert b \rVert_2$ で割った値は目安のおよそ 16 倍以下になる。
残差が下がり続けている検査点では判定しないので、下限の見積もりが大きすぎても、進んでいる求解は止まらない。
下限は許容誤差を変えない。

次のセルは内部の節点の数 $N$（50〜400）、熱伝導率の変化 $d$（0〜8 桁）と分布を選び、前処理なし、Jacobi、IC(0) の三つをオプション付き形式で解く。
反復回数の上限は $20N$ 回である。
表は固有値から求めた条件数 $\kappa$（IC(0) は計算しない）、上界 $k_\kappa$、反復回数、終了理由、真の相対残差、後退誤差 $\eta$（$\lVert A \rVert_2 = \lambda_{\max}(A)$）、厳密解との差の最大と、前処理なしの標準形式 `solve` の戻り値を示す。
グラフは相対残差の履歴を対数軸に描き、許容誤差と、厳密解から求めた丸め誤差の目安 $\varepsilon_{\mathrm{mach}}\lVert A \rVert_2\lVert x \rVert_2/\lVert b \rVert_2$ を横線、$k = N$ を縦線で示す。
最後の判定は Jacobi の行の終了理由で、`Converged` なら満たした、上限か停滞で止まったら途中で止まった、破綻なら失敗と示し、診断値に丸め誤差の目安を含める。

use scioxide_linalg::{CgSolver, LinearSolveTermination, Preconditioning, Vector, VectorView};
use scioxide_sparse::{IncompleteFactor, JacobiPreconditioner, sparse_diagonals};

let n = nodes.round() as usize;
let profile = if profile == "2 種類の層" {
    Profile::Layered
} else {
    Profile::Exponential
};
let model = bar(n, decades, profile);
let a = sparse_diagonals(
    n,
    n,
    &[-1, 0, 1],
    &[&model.off_diagonal, &model.diagonal, &model.off_diagonal],
)
.map_err(|e| e.to_string())?;
// 右端の温度 1 K を右辺に移した b_N = c_{N+1/2} [W]。
let mut rhs = vec![0.0_f64; n];
rhs[n - 1] = model.conductance[n];
let b = Vector::from_vec(rhs);
let exact = model.exact();
// 停止条件 ‖b − Ax‖₂ ≤ ε‖b‖₂（ε = 10⁻¹⁰）。反復の上限は 20N 回。
let epsilon = 1e-10;
let tolerance = ResidualTolerance::new(0.0, epsilon).map_err(|e| e.to_string())?;
let budget = Budget::try_from(20 * n).map_err(|e| e.to_string())?;
let solver = CgSolver::new(tolerance, budget).with_history(true);
// 条件数（固有値）と、‖r_k‖/‖b‖ ≤ 2√κ(A)·ρ^k、ρ = (√κ − 1)/(√κ + 1) から決まる反復回数の上界。
let (lowest, highest) =
    extremes(&model.diagonal, &model.off_diagonal).map_err(|e| e.to_string())?;
let kappa_a = highest / lowest;
let kappa_j =
    condition(&vec![1.0; n], &model.scaled_off_diagonal()).map_err(|e| e.to_string())?;
// 丸め誤差による相対残差の目安 ε_mach‖A‖₂‖x‖₂/‖b‖₂（x は厳密解、‖A‖₂ = λ_max(A)）。
let exact_norm = VectorView::from(exact.as_slice())
    .norm2()
    .map_err(|e| e.to_string())?;
let floor = f64::EPSILON * highest * exact_norm / model.conductance[n];
let bound = |kappa: f64| {
    let rate = (kappa.sqrt() + 1.0) / (kappa.sqrt() - 1.0);
    ((2.0 * kappa_a.sqrt() / epsilon).ln() / rate.ln()).ceil() as u64
};
// scioxide-sparse の前処理。どちらも M⁻¹ を作用させる。
let jacobi = JacobiPreconditioner::new(&a).map_err(|e| e.to_string())?;
let cholesky = IncompleteFactor::ic0(&a).map_err(|e| e.to_string())?;
// 標準形式: 初期値 0、前処理なし。許容誤差に届かなければエラーになる。
let plain = match solver.solve(&a, &b) {
    Ok(_) => "Ok（解）".to_string(),
    Err(e) => format!("Err({:?})", e.kind()),
};

    LinearSolveTermination::Converged => "Converged".to_string(),
    LinearSolveTermination::LeastSquaresConverged => "LeastSquaresConverged".to_string(),
    LinearSolveTermination::ConditionLimit => "ConditionLimit".to_string(),
    LinearSolveTermination::IterationLimit => "IterationLimit".to_string(),
    LinearSolveTermination::EvaluationLimit => "EvaluationLimit".to_string(),
    LinearSolveTermination::Stagnation => "Stagnation".to_string(),
    LinearSolveTermination::Breakdown(cause) => format!("Breakdown({cause:?})"),
    LinearSolveTermination::ExecutionStopped(reason) => format!("ExecutionStopped({reason:?})"),
};

    (
        "前処理なし",
        Preconditioning::None,
        Some(kappa_a),
        Some(plain),
    ),
    (
        "Jacobi",
        Preconditioning::Inverse(&jacobi),
        Some(kappa_j),
        None,
    ),
    ("IC(0)", Preconditioning::Inverse(&cholesky), None, None),
];
let mut rows = Vec::new();
let mut series = Vec::new();
let mut jacobi_report = None;
for (name, preconditioning, kappa, plain) in methods {
    // オプション付き形式: 前処理と初期値（None は 0）を渡し、解とレポートを受け取る。
    let result = solver
        .solve_with_options(&a, &b, preconditioning, None)
        .map_err(|e| e.to_string())?;
    let report = result.report();
    let error = result
        .solution()
        .as_slice()
        .iter()
        .zip(&exact)
        .fold(0.0_f64, |m, (p, q)| m.max((p - q).abs()));
    let residual = report.true_residual().map(|r| r.scaled_norm());
    // 規範的な後退誤差 η = ‖b − Ax‖₂ / (‖A‖₂‖x‖₂ + ‖b‖₂)、‖A‖₂ = λ_max(A)。
    let x_norm = result
        .solution()
        .view()
        .norm2()
        .map_err(|e| e.to_string())?;
    let backward = report
        .true_residual()
        .map(|r| r.raw_norm() / (highest * x_norm + model.conductance[n]));
    rows.push((
        name,
        kappa,
        kappa.map(bound),
        report.iterations(),
        name_of(report.termination()),
        residual,
        backward,
        error,
        plain,
    ));
    // 残差が厳密に 0 の点は対数軸に描けないので除く。
    let points: Vec<[f64; 2]> = result
        .history()
        .unwrap_or(&[])
        .iter()
        .enumerate()
        .filter(|(_, r)| **r > 0.0)
        .map(|(k, r)| [k as f64, r / model.conductance[n]])
        .collect();
    series.push(serde_json::json!({ "name": name, "points": points }));
    if name == "Jacobi" {
        jacobi_report = Some((report, error));
    }
}

);

} else if matches!(termination, LinearSolveTermination::Breakdown(_)) {

} else {
    Outcome::partial("Jacobi 前処理付き CG が許容誤差を満たす前に止まった").explanation(
        "返された解は、検査点で真の残差を確かめた反復解のうち残差が最小のものである。",
    )
};
let mut outcome = outcome
    .status(name_of(termination))
    .diagnostic("反復回数", report.iterations() as f64, None)
    .diagnostic("厳密解との差の最大", error, Some("K"))
    .diagnostic("丸め誤差の目安 ε‖A‖‖x‖/‖b‖", floor, None);
if let Some(residual) = report.true_residual() {
    outcome = outcome.diagnostic("相対残差", residual.scaled_norm(), None);
}
emit_outcome!(outcome);

反復回数は上界より小さいが $N$ の 10 倍を超え、厳密解との差は $1.5 \times 10^{-9}$ K である。
グラフの残差は 300 回目から 1800 回目まで $10^{-3}$〜$10^{-5}$ の範囲で上下しながらゆっくり減り、その後の約 270 回で許容誤差を下回る。
Jacobi 前処理では $\kappa_J = 5.2 \times 10^3$、上界は 1131 回で、反復は $N$ と同じ 200 回で終わる。
残差は 199 回目の $4.9 \times 10^{-6}$ から 200 回目の $2.3 \times 10^{-15}$ へ一度に下がり、厳密な算術での有限回の終了が丸め誤差のもとでも起こっている。
IC(0) は 1 回で `Converged` になり、厳密解との差は Jacobi と同じ $10^{-14}$ K の程度である。
標準形式の `solve` は前処理なしのオプション付き形式と同じ計算をし、ここでは解を返す。

$d = 8$ にすると、前処理なしは $\kappa(A) = 9.6 \times 10^9$ で上限の 4000 回に達し、`IterationLimit` で止まる。
相対残差は $5.8 \times 10^{-7}$ だが、後退誤差は $1.6 \times 10^{-8}$ で丸め誤差の水準より 8 桁大きく、厳密解との差は 0.99 K と解として使えない。
丸め誤差の目安は $9.3 \times 10^{-15}$ なので、この失敗の原因は丸め誤差ではなく反復回数の不足である。
同じ問題で標準形式の `solve` は `Err(ConvergenceFailure)` を返す。
Jacobi 前処理後の条件数は $1.7 \times 10^3$ にさらに下がり、やはり 200 回で収束する。

「2 種類の層」の $d = 4$ では、$\kappa_J = 4.2 \times 10^7$ が $\kappa(A) = 8.2 \times 10^7$ の半分にしかならない。
それでも反復回数は前処理なしの 693 回から Jacobi の 221 回に減り、どちらも収束する。
IC(0) は 1 回で収束するが、厳密解との差は $5.0 \times 10^{-10}$ K で、Jacobi の $1.5 \times 10^{-11}$ K より大きい。
後退誤差はどれも $3 \times 10^{-16}$ 以下で、厳密解との差はどれも前進誤差の上界 $2\kappa(A)\eta\lVert x \rVert_2$（$4 \times 10^{-7}$ K 以下）に収まるので、差の大小は前処理の良し悪しを表さない。
丸め誤差の目安は $6.7 \times 10^{-11}$ で、許容誤差 $10^{-10}$ をわずかに下回る。

「2 種類の層」の $d = 8$ では、三つの方法とも許容誤差に届かない。
前処理なしは 1950 回、Jacobi は 300 回、IC(0) は 14 回で `Stagnation` になり、判定は途中で止まったことを示す。
相対残差は $5.1 \times 10^{-7}$、$4.0 \times 10^{-7}$、$7.9 \times 10^{-8}$ だが、後退誤差はどれも $2 \times 10^{-16}$ 以下で、厳密解との差は $5 \times 10^{-7}$ K 以下である。
相対残差と後退誤差の比から $\lVert A \rVert_2\lVert x \rVert_2/\lVert b \rVert_2 = 3.0 \times 10^9$ が読み取れ、丸め誤差の目安 $6.7 \times 10^{-7}$ は許容誤差を 4 桁近く上回るので、完全な Cholesky 分解でも許容誤差を満たせない。
グラフでは目安の線が許容誤差の線より上にある。
返された解の真の残差は三つとも目安の 0.1〜0.8 倍で、目安より大きく下がるのは、検査点と検査点の間で漸化式が更新した残差だけである。
IC(0) の残差は 1 回目で $8.2 \times 10^{-8}$ に下がる。
2 回目には漸化式の残差が許容誤差を満たして検査点になるが、真の残差は $7.9 \times 10^{-8}$ にとどまる。
検査点で残差を真の値に置き換えた後、漸化式の残差は 13 回目の $1.3 \times 10^{-10}$ まで再び下がり、14 回目にもう一度許容誤差を満たす。
14 回目の真の残差は 2 回目の値を下回らず、最小の残差 $7.9 \times 10^{-8}$ は丸め誤差の下限より小さいので、ソルバーは `Stagnation` で止まる。
返された解は最後の反復解ではなく 2 回目の反復解なので、履歴の最後の点は $7.9 \times 10^{-8}$ に戻る。
前処理なしと Jacobi も、検査点の真の残差が最小の値を下回らなくなったところ（1950 回目と 300 回目）で同じ判定によって止まる。
目安は $d$ とともに 10 倍ずつ増え、$d = 5$ で $6.7 \times 10^{-10}$ と許容誤差を上回ると、前処理なしと Jacobi は `Stagnation` で止まり、IC(0) だけが 3 回目に相対残差 $9.1 \times 10^{-11}$ で収束する。

$N = 50$ では Jacobi 前処理付きが 50 回、前処理なしが 169 回で収束し、$N = 400$ では 400 回と 5684 回になる。
既定の $N = 200$ と合わせた三つの格子で、Jacobi 前処理付きの反復回数はどれも $N$ に等しい。
$d = 0$ では Jacobi 前処理が $A$ を定数で割るだけなので、二つの行の反復回数は 200 回で一致する。

2 次元・3 次元の拡散方程式では IC(0) がフィルを捨てるので $M \ne A$ となり、格子を細かくすると条件数は増え続ける。
係数の飛びと格子の細かさの両方に対応する前処理は、[代数的多重格子による前処理](../../../scioxide-sparse/algorithms/algebraic-multigrid/)にある。

## まとめ

係数がなめらかに変わる拡散問題では Jacobi 前処理だけで条件数が一様な棒の値以下に下がるが、材料の層のように係数が飛ぶ問題では相加平均と調和平均の比（約 $10^d/4$）が残るので、対角以外の情報を使う前処理を選ぶ。
反復回数の上限は条件数による上界 $k_\kappa$ と未知数の数 $N$ の小さいほうを目安にし、前処理がなく条件数が大きい問題では丸め誤差で $N$ を何倍も超えることを見込んで決める。
前処理を渡すときや未収束の解も使うときはオプション付き形式の `solve_with_options` を使い、レポートの終了理由と真の残差を確かめる。
許容誤差を $\lVert b \rVert$ に対する相対値で与えるときは、丸め誤差の目安 $\varepsilon_{\mathrm{mach}}\lVert A \rVert\lVert x \rVert/\lVert b \rVert$ を上回る値にする。
目安を下回る許容誤差では `Stagnation` か `IterationLimit` で止まるので、返された解の質は後退誤差と既知の解との比較で判断する。
