両端を壁に固定した $N$ 個の質点を、ばね定数 $k$ [N/m] の $N + 1$ 本のばねでつなぐ。
質点に力を加えたときの釣合いの変位を求める問題は、構造力学の一次元の剛性方程式であり、二階差分で離散化した弦や棒の問題とも同じ形をしている。
この例題では、剛性行列が三重対角になることを導き、`TridiagonalLuDecomposition` で $O(N)$ の演算で解いて、厳密解と全節点で比べる。

---

## 剛性方程式

質点 $i$ の変位を $u_i$ [m]、質点に加える力を $f_i$ [N]、両端を $u_0 = u_{N+1} = 0$ とすると、質点 $i$ に働く力の釣合いは

$$
k(u_{i-1} - u_i) + k(u_{i+1} - u_i) + f_i = 0
\quad\Longleftrightarrow\quad
-k u_{i-1} + 2k u_i - k u_{i+1} = f_i
$$

である。
全質点についてまとめると、$K = k \operatorname{tridiag}(-1, 2, -1)$ の剛性方程式 $Ku = f$ が得られる。
二次形式は $u^{\mathsf T} K u = k \sum_{i=0}^{N} (u_{i+1} - u_i)^2$ で、両端が固定されていれば $u \ne 0$ のとき正なので、$K$ は対称正定値である。

## 厳密解

質点 $j$ だけに力 $P$ [N] を加える集中荷重では、荷重点の左側と右側に外力がないので、$u_{i-1} - 2u_i + u_{i+1} = 0$ から変位は直線になる。
両端で 0 になり、荷重点での力の不釣合いが $P$ になる直線の組は、離散 Green 関数

$$
u_i = \frac{P}{k} \cdot \frac{\min(i, j)\,\bigl(N + 1 - \max(i, j)\bigr)}{N + 1}
$$

である。
最大の変位は荷重点の $u_j = P\,j(N+1-j)/((N+1)k)$ で、中央（$j = (N+1)/2$）では $P(N+1)/(4k)$ になる。
この値は左右 $j$ 本ずつのばねの直列（ばね定数 $k/j$）を並列につないだ等価ばね定数 $4k/(N+1)$ で $P$ を割った値に一致する。

すべての質点に同じ力 $q$ [N] を加える分布荷重では、$-k(u_{i-1} - 2u_i + u_{i+1}) = q$ を満たす二次式

$$
u_i = \frac{q}{2k}\, i\,(N + 1 - i)
$$

が厳密解になる（二次式の二階差分は厳密に定数になるため）。
最大の変位は中央の $q(N+1)^2/(8k)$ である。

## 連続体との関係

張力 $T$ [N] で張った長さ $L$ [m] の弦に点荷重 $P$ を加えると、たわみ $w(s)$ は $-T w'' = P\,\delta(s - s_0)$、$w(0) = w(L) = 0$ を満たし、解は荷重点を頂点とする折れ線である。
弦を $N+1$ 個の区間に分けて二階差分で離散化すると、$k = T/h$（$h = L/(N+1)$）のばね・質点鎖と同じ方程式になる。
折れ線と放物線は二階差分で厳密に表せるので、点荷重と一様な分布荷重では、離散解が連続解の節点の値に一致し、離散化誤差は生じない。
一般の分布荷重では二階差分の離散化誤差 $O(h^2)$ が加わる（[三重対角・帯・Toeplitz 行列](../../algorithms/structured-systems/)の周期境界の例）。

## 三重対角 LU 分解で解く

`TridiagonalLuDecomposition::factor(&matrix)` は、`TridiagonalMatrix::new(lower, main, upper)` で作った三重対角行列を隣接ピボット付きで LU 分解する（[三重対角・帯・Toeplitz 行列](../../algorithms/structured-systems/)）。
分解も一回の求解も $O(N)$ 回の演算とメモリ領域で済み、密行列の LU 分解の約 $\tfrac23 N^3$ 回と比べると、$N = 101$ でも 3 桁近く少ない。
消去の途中で現れる対角 $d_i = k(i+1)/i$ は常に下の成分 $k$ より大きいので、隣接ピボット選択で行が交換されることはなく、この場合は Thomas 法と同じ計算になる。
同じ鎖に多くの荷重の組を加える場合は、因子を保持して $O(N)$ の求解だけを繰り返せばよい。

求解には二つの形がある（呼び出しの形は[作業領域・実行コンテキスト・試行記録](../../algorithms/workspaces-and-execution/)で定義している）。
標準形式 `factor.solve(StructuredOperation::Normal, &f)` は既定の `DirectSolveOptions`（`RankPolicy::Exact`）で解き、解の `Vector` を返して、拒否をエラー（階数落ちなら `Singular`）にする。
オプション付き形式 `factor.solve_with_options(StructuredOperation::Normal, &f, &options)` は受理の条件を渡し、解とレポートを持つ `DirectSolveResult` を返す。
ここでは `DirectSolveOptions::new(RankPolicy::DimensionScaledEpsilon).with_residual(Estimation::Estimate)` で、次元に比例するしきい値のランクの方針を明示し、正規化した後退誤差

```text
η = ‖Ku − f‖∞ / (‖K‖∞ ‖u‖∞ + ‖f‖∞),   ‖K‖∞ = 4k
```

をレポート `report().residual()` に計算させる。
レポートの終了理由 `DirectSolveTermination` が `Accepted` のときだけ `solution()` が解を返す。

次のセルは荷重点を鎖の中の位置 $j/(N+1)$ で選んだ集中荷重 $P$ をオプション付き形式で、合計が同じ $P$ になる分布荷重 $q = P/N$ を同じ因子の標準形式で解く。
入力は質点の数 $N \in [5, 1001]$、ばね定数 $k \in [20, 400]$ N/m、荷重 $P \in [1, 50]$ N、荷重点の位置 $j/(N+1) \in [0.05, 0.95]$ である。
表は荷重ごとに最大の変位と厳密解、全節点の最大誤差と変位の大きさとの比（相対誤差）、三重対角の積を手で計算した相対残差 $\eta$、レポートの後退誤差、行の交換の回数を示す。
図は二つの荷重の変位と厳密解（破線）である。

```rust
//| id: linalg-spring-chain
//| ref: linalg-spring-chain
//| title: 三重対角 LU でばね鎖の釣合い変位を求める
//| run: reactive
//| crates: [scioxide-linalg]
//| inputs:
//|   nodes: {"type":"range","label":"質点の数 N","description":"両端の壁の間の質点の数。","min":5,"max":1001,"step":2,"value":41}
//|   stiffness: {"type":"range","label":"ばね定数 k [N/m]","description":"すべてのばねで同じ。","min":20,"max":400,"step":5,"value":120}
//|   load: {"type":"range","label":"荷重 P [N]","description":"集中荷重の大きさ。分布荷重は合計が同じ P になる q = P/N。","min":1,"max":50,"step":1,"value":18}
//|   position: {"type":"range","label":"荷重点の位置 j/(N+1)","description":"0.5 で中央。最も近い質点に荷重を加える。","min":0.05,"max":0.95,"step":0.05,"value":0.5}
//| cases:
//|   - {"id":"long-chain","label":"N = 1001","description":"条件数が N² に比例して増え、相対誤差が大きくなる。","inputs":{"nodes":1001}}
//|   - {"id":"off-center","label":"j/(N+1) = 0.1","description":"荷重点が端に寄ると、最大の変位が j(N+1−j) に比例して小さくなる。","inputs":{"position":0.1}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"displacement","path":"/rows/0/2","approx":{"value":1.575,"rtol":1e-12}}
//|       - {"artifact":"displacement","path":"/rows/0/3","approx":{"value":1.575,"rtol":1e-14}}
//|       - {"artifact":"displacement","path":"/rows/0/5","range":{"max":1e-14}}
//|       - {"artifact":"displacement","path":"/rows/1/3","approx":{"value":0.8067073170731708,"rtol":1e-12}}
//|       - {"artifact":"displacement","path":"/rows/1/5","range":{"max":1e-14}}
//|       - {"artifact":"displacement","path":"/rows/0/8","equals":0}
//|       - {"path":"/outputs/2/state","equals":"satisfied"}
//|   - case: long-chain
//|     expect:
//|       - {"artifact":"displacement","path":"/rows/0/5","range":{"min":1e-15,"max":1e-11}}
//|       - {"artifact":"displacement","path":"/rows/0/6","range":{"max":1e-15}}
//|       - {"path":"/outputs/2/state","equals":"satisfied"}
//|   - case: off-center
//|     expect:
//|       - {"artifact":"displacement","path":"/rows/0/3","approx":{"value":0.5428571428571429,"rtol":1e-12}}
//|       - {"artifact":"displacement","path":"/rows/0/5","range":{"max":1e-14}}
use scioxide_linalg::{
    DirectSolveOptions, DirectSolveTermination, Estimation, RankPolicy, StructuredOperation,
    TridiagonalLuDecomposition, TridiagonalMatrix,
};

let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let fixed = serde_json::json!({ "significantDigits": 10 });
let n = nodes.round() as usize;
let k = stiffness;
// 荷重点 j（1 始まり）。
let j = ((position * (n + 1) as f64).round() as usize).clamp(1, n);
let matrix = TridiagonalMatrix::new(vec![-k; n - 1], vec![2.0 * k; n], vec![-k; n - 1])
    .map_err(|e| e.to_string())?;
let factor = TridiagonalLuDecomposition::factor(&matrix).map_err(|e| e.to_string())?;
let swaps = factor
    .pivots()
    .iter()
    .enumerate()
    .filter(|&(i, &p)| p != i)
    .count();

// 集中荷重: オプション付き形式でランクの方針を明示し、レポートに後退誤差も求める。
let mut point = vec![0.0_f64; n];
point[j - 1] = load;
let accept = DirectSolveOptions::new(RankPolicy::DimensionScaledEpsilon)
    .with_residual(Estimation::Estimate);
let result = factor
    .solve_with_options(StructuredOperation::Normal, &point[..], &accept)
    .map_err(|e| e.to_string())?;
let termination = result.report().termination();
let backward = result.report().residual().map(|r| r.scaled_norm());
let u = result
    .solution()
    .ok_or("解が受理されなかった")?
    .as_slice()
    .to_vec();
// 分布荷重: 同じ因子を標準形式の solve で使い回す（拒否はエラーになる）。
let q = load / n as f64;
let uniform = vec![q; n];
let v = factor
    .solve(StructuredOperation::Normal, &uniform[..])
    .map_err(|e| e.to_string())?;
let v = v.as_slice().to_vec();

// 検算: 厳密解との差と、三重対角の積を手で計算した相対残差 η。
let green = |i: usize| load / k * (i.min(j) * (n + 1 - i.max(j))) as f64 / (n + 1) as f64;
let parabola = |i: usize| q / (2.0 * k) * (i * (n + 1 - i)) as f64;
let check = |x: &[f64], f: &[f64], exact: &dyn Fn(usize) -> f64| {
    let (mut peak, mut exact_peak, mut error, mut residual) =
        (0.0_f64, 0.0_f64, 0.0_f64, 0.0_f64);
    for i in 1..=n {
        let left = if i > 1 { x[i - 2] } else { 0.0 };
        let right = if i < n { x[i] } else { 0.0 };
        residual = residual.max((k * (2.0 * x[i - 1] - left - right) - f[i - 1]).abs());
        peak = peak.max(x[i - 1].abs());
        exact_peak = exact_peak.max(exact(i));
        error = error.max((x[i - 1] - exact(i)).abs());
    }
    let f_norm = f.iter().fold(0.0_f64, |m, v| m.max(v.abs()));
    (
        peak,
        exact_peak,
        error,
        error / peak,
        residual / (4.0 * k * peak + f_norm),
    )
};
let (p_peak, p_exact, p_error, p_relative, p_eta) = check(&u, &point, &green);
let (u_peak, u_exact, u_error, u_relative, u_eta) = check(&v, &uniform, &parabola);
let columns = serde_json::json!([
    { "key": "0", "label": "荷重" },
    { "key": "1", "label": "求解の形" },
    { "key": "2", "label": "最大の変位 [m]", "type": "number", "format": fixed },
    { "key": "3", "label": "厳密解の最大 [m]", "type": "number", "format": fixed },
    { "key": "4", "label": "全節点の最大誤差 [m]", "type": "number", "format": sci2 },
    { "key": "5", "label": "相対誤差 [-]", "type": "number", "format": sci2 },
    { "key": "6", "label": "相対残差 η（手計算）[-]", "type": "number", "format": sci2 },
    { "key": "7", "label": "後退誤差（レポート）[-]", "type": "number", "format": sci2, "nullText": "求めない" },
    { "key": "8", "label": "行の交換 [回]", "type": "integer" }
]);
let rows = vec![
    (
        "集中荷重 P",
        "オプション付き形式",
        p_peak,
        p_exact,
        p_error,
        p_relative,
        p_eta,
        backward,
        swaps,
    ),
    (
        "分布荷重 q = P/N",
        "標準形式",
        u_peak,
        u_exact,
        u_error,
        u_relative,
        u_eta,
        None,
        swaps,
    ),
];
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "displacement" })
);
let curve = |values: &[f64]| -> Vec<[f64; 2]> {
    (1..=n)
        .map(|i| [i as f64 / (n + 1) as f64, values[i - 1]])
        .collect()
};
let exact_curve = |exact: &dyn Fn(usize) -> f64| -> Vec<[f64; 2]> {
    (1..=n)
        .map(|i| [i as f64 / (n + 1) as f64, exact(i)])
        .collect()
};
let dashed = serde_json::json!({ "lineType": "dashed" });
let (green_curve, parabola_curve) = (exact_curve(&green), exact_curve(&parabola));
emit_line_chart!(
    &vec![
        serde_json::json!({ "name": "集中荷重の変位", "points": curve(&u) }),
        serde_json::json!({ "name": "離散 Green 関数", "points": green_curve, "style": dashed }),
        serde_json::json!({ "name": "分布荷重の変位", "points": curve(&v) }),
        serde_json::json!({ "name": "二次式の厳密解", "points": parabola_curve, "style": dashed })
    ],
    options = &serde_json::json!({ "xLabel": "位置 i/(N+1) [-]", "yLabel": "変位 u_i [m]" })
);

let status = match termination {
    DirectSolveTermination::Accepted => "Accepted",
    DirectSolveTermination::RankDeficient => "RankDeficient",
    DirectSolveTermination::IllConditioned => "IllConditioned",
    DirectSolveTermination::ResidualRejected => "ResidualRejected",
    DirectSolveTermination::StabilityRejected => "StabilityRejected",
};
let outcome = if termination.is_success() {
    Outcome::satisfied("集中荷重の解が受理された")
} else {
    Outcome::failed("集中荷重の解が受理されなかった")
};
let mut outcome = outcome
    .status(status)
    .diagnostic("相対誤差", p_relative, None)
    .diagnostic("行の交換", swaps as f64, None);
if let Some(eta) = backward {
    outcome = outcome.diagnostic("後退誤差", eta, None);
}
emit_outcome!(outcome);
```

既定の $N = 41$、$k = 120$ N/m、$P = 18$ N の中央荷重では、荷重点の変位は $P(N+1)/(4k) = 1.575$ m で、全節点の相対誤差は $7.8 \times 10^{-16}$、相対残差 $\eta$ は $3.4 \times 10^{-17}$ である。
レポートの後退誤差 $3.7 \times 10^{-17}$ は手計算の $\eta$ と同じ量で、丸めの範囲で一致し、終了理由は `Accepted` である。
同じ因子を標準形式で使い回した分布荷重（$q = 18/41$ N）でも、中央の変位 $q(N+1)^2/(8k) = 0.8067$ m に相対 $9.6 \times 10^{-16}$ で一致する。
変位の図は集中荷重では荷重点を頂点とする折れ線、分布荷重では放物線になり、どちらも破線の厳密解と重なる。
荷重点を $j/(N+1) = 0.1$（$j = 4$）に寄せると頂点も移り、最大の変位は $j(N+1-j)$ に比例して $0.5429$ m に小さくなる。

$N = 1001$ では相対残差は $10^{-16}$ の程度のままだが、相対誤差は $2.4 \times 10^{-13}$ に増える。
$K$ の条件数は $\kappa_2 \approx 4(N+1)^2/\pi^2 \approx 4 \times 10^{5}$ で、後退安定な解の前進誤差は条件数の分だけ大きくなりうるためである。
どの入力でも行の交換は起きない。
変位の絶対値は $N/k$ に比例して大きくなるので、誤差は変位の大きさとの比で読む。

## まとめ

ばね・質点鎖の釣合いは対称正定値な三重対角の剛性方程式になり、`TridiagonalLuDecomposition` で $O(N)$ の演算で解ける。
集中荷重の厳密解は離散 Green 関数、一様な分布荷重の厳密解は二次式で、どちらも二階差分で厳密に表せるので、計算した変位を全節点で厳密解と比べられる。
一つの因子はレポートを読むオプション付き形式 `solve_with_options` と、解だけを返す標準形式 `solve` のどちらにも使い回せる。
相対残差とレポートの後退誤差は単位丸めの程度のままでも、相対誤差は条件数 $O(N^2)$ の分だけ大きくなりうる。
対角優位なこの行列では隣接ピボット選択は行を交換せず、Thomas 法と同じ計算になる。
