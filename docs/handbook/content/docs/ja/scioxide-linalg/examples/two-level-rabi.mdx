原子やイオン、超伝導回路の 2 つのエネルギー準位に共鳴に近い電磁波を当てると、基底状態と励起状態の間を確率が周期的に行き来する（Rabi 振動）。
量子ビットの操作や核磁気共鳴のパルスは、この振動の周期と振幅をもとに設計する。
この例題では時間発展を複素行列の指数関数として計算し、解析的な Rabi の公式と閉じた形の状態と比べる。
さらに、行列を指数に通さずに状態だけを進める作用 $\exp(-\mathrm{i}HT)\psi_0$ を別のアルゴリズムで求め、二つのアルゴリズムの結果を照合する。

## ハミルトニアンと時間発展

基底状態を $\lvert 0 \rangle = (1, 0)$、励起状態を $\lvert 1 \rangle = (0, 1)$ とし、$\hbar = 1$ の単位をとる。
エネルギーは角周波数 [rad/μs] で、時間は μs で測る（$\Omega/2\pi$ が MHz の周波数になる）。
駆動の周波数で回る座標系で回転波近似を使うと、ハミルトニアンは

$$
H = \frac12 \begin{bmatrix} -\Delta & \Omega \\ \Omega & \Delta \end{bmatrix} \quad [\mathrm{rad}/\mu\mathrm{s}]
$$

となる。
$\Omega$ は駆動の強さに比例する Rabi 周波数、$\Delta$ は駆動と遷移の周波数の差（離調）である。
$H$ が時間によらないので、Schrödinger 方程式 $\mathrm{i}\,\dot\psi = H\psi$ の解は $\psi(t) = U(t)\psi(0)$、$U(t) = \exp(-\mathrm{i}Ht)$ で、$U$ はユニタリ（$U^{\mathsf H} U = I$）である。

$H$ はトレースが 0 で $H^2 = (\Omega_R/2)^2 I$ を満たすので、指数の級数は閉じた形にまとまる。

$$
U(t) = \cos\frac{\Omega_R t}{2}\, I - \mathrm{i}\,\frac{2}{\Omega_R} \sin\frac{\Omega_R t}{2}\, H, \qquad \Omega_R = \sqrt{\Omega^2 + \Delta^2}
$$

ここで $\Omega_R$ は一般化 Rabi 周波数である。
$\psi(0) = \lvert 0 \rangle$ から始めると、状態は

$$
\psi(t) = \left( \cos\frac{\Omega_R t}{2} + \mathrm{i}\,\frac{\Delta}{\Omega_R} \sin\frac{\Omega_R t}{2},\; -\mathrm{i}\,\frac{\Omega}{\Omega_R} \sin\frac{\Omega_R t}{2} \right)
$$

で、励起状態にある確率は Rabi の公式

$$
P_e(t) = \lvert \psi_1(t) \rvert^2 = \frac{\Omega^2}{\Omega_R^2} \sin^2\frac{\Omega_R t}{2}
$$

で与えられる。
共鳴（$\Delta = 0$）では振幅が 1 になり、時間 $t_\pi = \pi/\Omega$ の「$\pi$ パルス」で励起状態へ移りきる。
離調があると振幅は $\Omega^2/\Omega_R^2$ に下がり、周期 $2\pi/\Omega_R$ は短くなる。
$P_e$ は励起状態の確率振幅 $\psi_1$ の絶対値しか見ないので、状態の位相が正しいかは上の $\psi(t)$ と比べて確かめる。

## 指数の計算と確かめ方

`matrix_function(&a, MatrixFunction::Exp)` は正方行列 $A$ の指数 $\exp(A)$ を新しい行列として返す[ワンショット関数](oxref:linalg-execution-forms)で、内部で既定の設定で Plan `MatrixFunctionPlan` を作って評価する（[行列関数](../../algorithms/matrix-functions-and-equations/)）。
指数は Al-Mohy と Higham（2009）のスケーリング・二乗法で、$A$ を $2^s$ で割ってから次数 3、5、7、9、13 のいずれかの Padé 近似を当て、結果を $s$ 回二乗する。
次数と $s$ は、厳密な算術での Padé 近似の後退誤差が倍精度の単位丸め $u = 2^{-53}$ を超えないように選ばれ、Schur 分解は使わない。
演算量は $n$ 次の行列で $O(n^3)$ である。
同じ行列で Fréchet 微分や条件数の推定も求めるときは、`MatrixFunctionPlan` を作って再利用する。

Padé 近似は後退誤差を $u$ 以下に抑えるが、ユニタリな行列を返すように作られた近似ではないので、計算した $U$ のユニタリ性は丸め誤差の程度でしか成り立たない。
そこで $U(\Delta t) = \exp(-\mathrm{i}H\Delta t)$ を一度だけ計算し、$\psi_{k+1} = U(\Delta t)\psi_k$ を $N$ 回繰り返して時間発展を追い、次の三つを確かめる。

1. 各時刻の $P_e$ と Rabi の公式の差、状態 $\psi_k$ と閉じた形の $\psi(t_k)$ の差。
2. $U^{\mathsf H} U - I$ の成分の大きさ（ユニタリ性）と、$\lVert \psi_k \rVert_2^2 - 1$（確率の保存）。
3. 終端の状態を、$\exp(-\mathrm{i}HT)$ を一度に計算した値と、行列を指数に通さない作用の値と比べること（次の節）。

次の定義は二つのセルが共有する。
`generator` は生成子 $-\mathrm{i}Ht$ の成分を並べ、`exact_state` は閉じた形の $\psi(t)$ を返す。
閉じた形は検算用なので、`f64` の固有メソッド（`sin_cos`、`hypot`）で計算する。

```rust
//| id: linalg-two-level-rabi-model
//| kind: definitions
//| title: 2 準位系の生成子と閉じた形の状態
//| crates: [scioxide-core, scioxide-linalg]
use scioxide_core::{Complex, SciOxideError};
use scioxide_linalg::Matrix;

/// 生成子 −iHt。H = ½[[−Δ, Ω], [Ω, Δ]]、Ω と Δ は [rad/μs]、t は [μs]。
pub(crate) fn generator(
    rabi: f64,
    detuning: f64,
    t: f64,
) -> Result<Matrix<Complex<f64>>, SciOxideError> {
    let (d, w) = (0.5 * detuning * t, 0.5 * rabi * t);
    Matrix::from_rows(&[
        [Complex::new(0.0, d), Complex::new(0.0, -w)],
        [Complex::new(0.0, -w), Complex::new(0.0, -d)],
    ])
}

/// 閉じた形の ψ(t) = U(t)|0⟩（f64 の固有メソッドによる参照値）。
pub(crate) fn exact_state(rabi: f64, detuning: f64, t: f64) -> [Complex<f64>; 2] {
    let omega_r = rabi.hypot(detuning);
    let (s, c) = (0.5 * omega_r * t).sin_cos();
    [
        Complex::new(c, detuning / omega_r * s),
        Complex::new(0.0, -rabi / omega_r * s),
    ]
}
```

次のセルは Rabi 周波数 $\Omega$（0.5〜20 rad/μs）、離調 $\Delta$（−20〜20 rad/μs）、パルスの時間 $T$（0.5〜10 μs）と刻みの数 $N$（10〜1000）を選び、$U(T/N)$ を $N$ 回掛けて励起確率の時間変化を公式と比べる。
表は一般化 Rabi 周波数、周期、振幅と、上の 1 と 2 の誤差の最大値を示し、グラフは計算した $P_e$ と公式（破線）を重ねる。
このセルの $\Omega$、$\Delta$、$T$、$N$ と終端の状態 $\psi_N$ は、次のセルに渡す。

既定値（$\Omega = 6$ rad/μs、$\Delta = 2$ rad/μs、$T = 3$ μs、$N = 400$）では $\Omega_R = 6.325$ rad/μs、周期 0.9935 μs、振幅 0.9 で、グラフの二本の曲線は重なる。
1 刻みの $U$ のユニタリ性の誤差は $1.1 \times 10^{-16}$ で、単位丸めの程度である。
400 回掛けると、$P_e$ の公式との差は $2.7 \times 10^{-14}$、状態の差は $1.8 \times 10^{-14}$、$\lvert \lVert \psi_k \rVert_2^2 - 1 \rvert$ は $3.6 \times 10^{-14}$ まで増える。

刻みの数を変えると、誤差が時間刻みの近似ではなく丸め誤差の蓄積から来ることが分かる。
$N = 10$ では三つの誤差がどれも $2 \times 10^{-15}$ 以下に下がり、$N = 1000$ では $3 \times 10^{-14}$〜$6 \times 10^{-14}$ に増える。
$U(\Delta t)$ は刻みの大きさによらず丸め誤差の程度で計算されるので、表の誤差は各刻みの $U(\Delta t)$ と積に入る相対 $u$ の程度の丸めが、掛けた回数だけ積み重なったものである。
ただし誤差は掛けた回数だけでは決まらず、同じ $N = 1000$ でも $T = 10$ μs では $2.3 \times 10^{-13}$ になる。

$\Delta = 0$ では振幅が 1 になり、$t_\pi = \pi/6 \approx 0.524$ μs で $P_e = 1$ に達する。
$\Omega = 0.5$ rad/μs、$\Delta = -20$ rad/μs のように離調が大きいと、振幅は $6.2 \times 10^{-4}$ まで下がり、周期 0.314 μs の速く小さい振動になる。
このとき $P_e$ の公式との差は $4.0 \times 10^{-17}$ で、振幅 $6.2 \times 10^{-4}$ に比べて十分小さく、状態の差も $1.4 \times 10^{-14}$ にとどまる。

## 行列を作らない作用との比較

`ExponentialAction` は、行列 $\exp(tA)$ を作らずに、ベクトル $b$ への作用 $\exp(tA)b$ を $A$ との積だけで求める[手法オブジェクト](oxref:linalg-method-values)である。
方法は Al-Mohy と Higham（2011）の切断 Taylor 法で、$[0, t]$ を $s$ 段に分け、各段で次数 $m$ の Taylor 多項式を作用させる（[切断 Taylor 法による指数の作用](oxref:linalg-truncated-taylor)）。
$(m, s)$ は呼び出し側が与える $\lVert A - \mu I \rVert_1$ の上界から選ばれ（シフト $\mu$ は既定 0）、上界が大きいときは $\lVert (t(A - \mu I))^p \rVert_1^{1/p}$ の 1 ノルムの推定も使う。
手法は上界を確かめられず、過小な上界は結果を不正確にしうる。
このセルでは `MatrixView::norm(MatrixNorm::One)` で $\lVert -\mathrm{i}H \rVert_1 = (\lvert \Omega \rvert + \lvert \Delta \rvert)/2$ を推定ではなく定義どおりに計算して渡す。

作用素を適用する回数（1 ノルムの推定に使う随伴作用素との積を含む）が上限に達すると、終了理由は `SpectralTermination::EvaluationLimit` になり、結果は `Ok` で返る。
上限の既定は 100 000 回で、`with_applications` で変える。
上限で止まったとき、出力には完了した段までの値 $\exp(f\,tA)b$ が入る。
$f$ は完了した段が覆う $[0, t]$ の割合で、作業領域の `last_accepted()` が返す `ExponentialActionAccepted::progress()` で読む。
割合を読むために、このセルは出力と作業領域を受け取る[出力先を指定する API](oxref:linalg-execution-forms) `apply_into` を使う（作業領域を見ないなら所有値を返す API の `apply` で足りる）。

次のセルは前のセルの $\Omega$、$\Delta$、$T$、$N$ と $\psi_N$ を受け取り、終端の状態を三つの経路で求めて閉じた形と比べる。
経路は $U(\Delta t)$ の $N$ 回の積、`matrix_function` で一度に計算した $U(T)\psi_0$、`ExponentialAction` による $\exp(-\mathrm{i}HT)\psi_0$ である。
入力は作用素を適用する回数の上限（1〜1000 回）で、表は比べた時刻、閉じた形との差、作用素の適用回数、終了理由を示す。
上限で止まった作用は時刻 $fT$ の閉じた形と比べる。
計算の判定（outcome）は作用の終了理由から決め、`Converged` なら `satisfied`、上限や取り消しで止まれば `partial`、`AccuracyLimit` なら `failed` にする。

```rust
};

let read = |key: &str| evolution[key].as_f64().ok_or(format!("{key} がない"));
let (rabi, detuning, duration) = (read("rabi")?, read("detuning")?, read("duration")?);
let steps = read("steps")?;
let product: Vec<f64> = (0..4)
    .map(|i| evolution["final_state"][i].as_f64().ok_or("ψ_N がない"))
    .collect::<Result<_, _>>()?;
let product = [
    Complex::new(product[0], product[1]),
    Complex::new(product[2], product[3]),
];
// 閉じた形の ψ(t) との差 max|ψ − ψ(t)|。
let error = |state: [Complex<f64>; 2], t: f64| {
    let exact = exact_state(rabi, detuning, t);
    (state[0] - exact[0])
        .norm()
        .max((state[1] - exact[1]).norm())
};

// 経路 2: U(T) = exp(−iHT) を一度に計算し、第 1 列 U(T)|0⟩ を取り出す。
let whole = generator(rabi, detuning, duration).map_err(|e| e.to_string())?;
let total = matrix_function(&whole, MatrixFunction::Exp).map_err(|e| e.to_string())?;
let pade = [total.as_slice()[0], total.as_slice()[2]];

// 経路 3: A = −iH の作用 exp(TA)|0⟩。上界 ‖A‖₁ は厳密に計算して渡す。
let a = generator(rabi, detuning, 1.0).map_err(|e| e.to_string())?;
let bound = a.view().norm(MatrixNorm::One).map_err(|e| e.to_string())?;
let budget = Budget::try_from(applications.round() as usize).map_err(|e| e.to_string())?;
let action = ExponentialAction::new(bound).with_applications(budget);
let operator = a.view().try_finite().map_err(|e| e.to_string())?;
let input = [Complex::new(1.0, 0.0), Complex::new(0.0, 0.0)];
let mut output = [Complex::new(0.0, 0.0); 2];
let mut workspace = action.workspace(&operator, 1).map_err(|e| e.to_string())?;
let report = action
    .apply_into(
        &operator,
        PhiFunction::exp(duration),
        BlockVectorView::new(&input, 2, 1).map_err(|e| e.to_string())?,
        BlockVectorViewMut::new(&mut output, 2, 1).map_err(|e| e.to_string())?,
        &mut workspace,
        ExecutionContext::sequential_native(),
    )
    .map_err(|e| e.to_string())?;
let progress = workspace
    .last_accepted()
    .map_or(0.0, |accepted| accepted.progress()[0]);
let reached = progress * duration;
let termination = report.termination();
let name = match termination {
    SpectralTermination::Converged => "Converged",
    SpectralTermination::EvaluationLimit => "EvaluationLimit",
    SpectralTermination::IterationLimit => "IterationLimit",
    SpectralTermination::InvariantSubspace => "InvariantSubspace",
    SpectralTermination::AccuracyLimit => "AccuracyLimit",
    SpectralTermination::ExecutionStopped(_) => "ExecutionStopped",
};

let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let columns = serde_json::json!([
    { "key": "0", "label": "経路" },
    { "key": "1", "label": "比べた時刻 t [μs]", "type": "number", "format": { "significantDigits": 4 } },
    { "key": "2", "label": "閉じた形との差 max|ψ − ψ(t)| [-]", "type": "number", "format": sci2 },
    { "key": "3", "label": "作用素の適用回数 [回]", "type": "integer", "nullText": "—" },
    { "key": "4", "label": "終了理由", "nullText": "なし" }
]);
let (product_error, pade_error) = (error(product, duration), error(pade, duration));
let (action_error, applied) = (error(output, reached), Some(report.applications()));
let rows: Vec<(&str, f64, f64, Option<usize>, Option<&str>)> = vec![
    (
        "U(Δt) の N 回の積",
        duration,
        product_error,
        Some(steps as usize),
        None,
    ),
    (
        "一度の指数 U(T)ψ₀（Padé）",
        duration,
        pade_error,
        None,
        None,
    ),
    (
        "作用 exp(−iHT)ψ₀（Taylor）",
        reached,
        action_error,
        applied,
        Some(name),
    ),
];
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "routes" })
);

let outcome = match termination {
    SpectralTermination::Converged => Outcome::satisfied("Taylor 法の作用が終端まで収束した")
        .explanation("三つの経路は、表の閉じた形との差で比べる。"),
    SpectralTermination::AccuracyLimit => {
        Outcome::failed("Taylor 法の作用が精度の確認に通らなかった")
    }
    _ => Outcome::partial("Taylor 法の作用が上限で止まった")
        .explanation("出力は完了した段までの exp(fT·(−iH))ψ₀ で、時刻 fT の状態として解釈する。"),
};
emit_outcome!(
    outcome
        .status(name)
        .diagnostic("作用素の適用回数", report.applications() as f64, None)
        .diagnostic("完了した割合 f", progress, None)
        .diagnostic("閉じた形との差", action_error, None)
);
```

既定値では、$N = 400$ 回の積の差が $1.8 \times 10^{-14}$ であるのに対し、一度の指数は $4.5 \times 10^{-16}$、Taylor 法の作用は 70 回の作用素の適用で $2.3 \times 10^{-15}$ の差で閉じた形と一致した。
終端の状態だけが要るなら、刻みの積を重ねるより一度の指数か作用を使うほうが丸め誤差が小さい。
前のセルの入力の範囲で $\lVert A \rVert_1 T$ が最大になる $\Omega = \lvert\Delta\rvert = 20$ rad/μs、$T = 10$ μs でも、作用は 823 回の適用で収束するので、このセルの既定の上限 1000 回で足りる。
そのときの閉じた形との差は $1.8 \times 10^{-12}$ で、一度の指数の $3.6 \times 10^{-15}$ より大きい。

上限を 40 回にすると、作用は `EvaluationLimit` で止まり、outcome は `partial` になる。
既定値の作用は $[0, T]$ を 2 段に分けるので、完了した割合は $f = 0.5$ で、出力は時刻 $fT = 1.5$ μs の状態である。
その出力は閉じた形の $\psi(1.5)$ と $5.0 \times 10^{-16}$ の差で一致するが、$\psi(3)$ ではない。
上限が 34 回以下では 1 段も完了せず、$f = 0$ で出力は初期状態 $\psi_0$ のままである。
止まった作用の出力を終端の結果として使わないために、終了理由と $f$ を確かめる。

## 共鳴曲線とパルス列

離調 $\Delta$ の関数として見た振幅 $\Omega^2/(\Omega^2 + \Delta^2)$ は Lorentz 型で、$\lvert\Delta\rvert = \Omega$ で $1/2$ に下がるので、半値全幅は $2\Omega$ である。
駆動の周波数を掃引して共鳴を探す実験では、この幅が周波数の分解能を決める。
区間ごとに一定のハミルトニアンなら、$\Omega$ や $\Delta$ を区間ごとに変えたパルス列も、区間ごとに指数を計算し直した $U$ を順に掛けて扱える。
時間に連続的に依存するハミルトニアンの細かい変化を追うなら、常微分方程式の解法（[scioxide-ode](../../../scioxide-ode/)）の方が適する。

## まとめ

時間によらないハミルトニアンの時間発展演算子 $U(t) = \exp(-\mathrm{i}Ht)$ は、`matrix_function(&a, MatrixFunction::Exp)` で複素行列の指数として求められる。
スケーリング・二乗法の指数はユニタリ性を構造として保たないので、$U^{\mathsf H}U - I$ と $\lVert\psi\rVert_2^2 - 1$ を確かめる（この例ではどちらも丸め誤差の程度だった）。
刻みの積で追った状態の誤差は刻みを細かくしても減らず、掛けた回数とともに増える丸め誤差なので、終端の状態だけが要るなら一度の指数か作用で求める。
`ExponentialAction` は $A$ との積だけで作用を求め、$\lVert A - \mu I \rVert_1$ の上界は呼び出し側が与える。
その終了理由が `EvaluationLimit` のときは、出力を時刻 $fT$ の状態として読み、$T$ の結果とみなさない。
