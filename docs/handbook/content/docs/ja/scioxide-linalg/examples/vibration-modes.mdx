結晶の格子振動や、ナノメートル規模の機械的共振器では、質点とばねが一列につながった鎖が基本のモデルになる。
鎖の中に一つだけ質量の異なる原子（不純物）があると、振動の周波数の分布が変わる。
特に不純物が軽いと、均一な鎖では存在しない高い周波数のモードが現れ、その振幅は不純物のまわりに指数関数的に局在する。
この例題では振動を一般化固有値問題として解き、均一な鎖の解析解と無限に長い鎖の局在モードの理論で結果を確かめる。

---

## 運動方程式と一般化固有値問題

両端を壁に固定した $N$ 個の質点を、ばね定数 $k$ [N/m] のばねでつなぐ。
質点の質量はすべて $m$ [kg] で、中央の質点 $c = (N+1)/2$（$N$ は奇数）だけを $m_d = r\,m$ とする。
質点 $i$ の変位を $u_i(t)$ とすると運動方程式は $m_i \ddot u_i = k(u_{i-1} - 2u_i + u_{i+1})$ で、$u_i = \phi_i e^{\mathrm{i}\omega t}$ とおくと

$$
K\phi = \omega^2 M\phi, \qquad K = k \operatorname{tridiag}(-1, 2, -1), \quad M = \operatorname{diag}(m_1, \dots, m_N)
$$

となる。
$K$ は対称正定値、$M$ は正の対角行列なので、固有値 $\omega^2$ はすべて正で、固有ベクトルは $M$ について正規直交（$\Phi^{\mathsf T} M \Phi = I$）にとれる。

`GeneralizedHermitianEigenDecomposition::decompose(&k, &m, HermitianInput::Exact, HermitianInput::Exact)` は、この問題の全スペクトルを $O(N^3)$ の演算で求める（[一般化固有値問題と QZ 分解](../../algorithms/generalized-eigenproblems/)）。
$K$ と $M$ をそれぞれ絶対値が最大の成分で割り、$M$ の Cholesky 分解 $M = LL^{\mathsf T}$ で標準の固有値問題 $L^{-1}KL^{-\mathsf T}w = \omega^2 w$ に還元してから、$L^{-1}KL^{-\mathsf T}$ を Householder 変換で三重対角化して解く。
既定の `HermitianEigenOptions` を使う[標準形式](oxref:linalg-execution-forms)で、固有値の選択、順序、精度を変えるときはオプション付き形式 `decompose_with_options` に設定を渡す。
`HermitianInput::Exact` は渡した行列が厳密に対称であることを確かめて使う指定で、対称でなければ `InvalidInput`（`Inconsistent`）になる。

$M$ が対角なので、$\psi = M^{1/2}\phi$ とおけば対称な三重対角行列

$$
\tilde K = M^{-1/2} K M^{-1/2}, \qquad \tilde K_{ii} = \frac{2k}{m_i}, \quad \tilde K_{i,i+1} = -\frac{k}{\sqrt{m_i m_{i+1}}}
$$

の標準固有値問題 $\tilde K \psi = \omega^2 \psi$ にもなる。
この $\tilde K$ を `HermitianEigenDecomposition::tridiagonal` に渡す経路は Cholesky 還元と Householder 変換を通らないので、二つの経路を比べると還元と逆変換で入る誤差が分かる。
三重対角行列の固有値を求める部分（32 次までは陰的 QL 法、それより大きいと分割統治法）は二つの経路で共通なので、アルゴリズム全体の独立な検算には均一な鎖の解析解と無限鎖の理論を使う。

## 均一な鎖の分散関係

$r = 1$ のとき、境界条件を満たす固有ベクトルは $\phi_i = \sin(ij\pi/(N+1))$ で、固有角振動数は

$$
\omega_j = 2\sqrt{k/m}\, \sin\frac{j\pi}{2(N+1)}, \qquad j = 1, \dots, N
$$

である。
固有角振動数はすべて $\omega_{\max} = 2\sqrt{k/m}$ より小さく、この範囲が均一な鎖を伝わる波の帯域である。

次の定義のブロックはこのモデルを二つのセルで共有する。
`masses` が中央に不純物を置いた質量の並び、`chain` が剛性行列 $K$ と質量行列 $M$ を密行列で組み立てる関数に対応する。

```rust
//| id: linalg-chain-model
//| kind: definitions
//| title: 不純物を含むばね・質点鎖の剛性行列と質量行列
//| crates: [scioxide-core, scioxide-linalg]
use scioxide_core::SciOxideError;
use scioxide_linalg::Matrix;

/// 質量の並び。中央の質点 c = (N + 1)/2（0 始まりで N/2）だけを r m にする。
pub(crate) fn masses(n: usize, mass: f64, ratio: f64) -> Vec<f64> {
    (0..n)
        .map(|i| if i == n / 2 { ratio * mass } else { mass })
        .collect()
}

/// 剛性行列 K = k tridiag(−1, 2, −1) と質量行列 M = diag(mᵢ)（どちらも厳密に対称）。
pub(crate) fn chain(
    spring: f64,
    masses: &[f64],
) -> Result<(Matrix<f64>, Matrix<f64>), SciOxideError> {
    let n = masses.len();
    let mut stiff = Matrix::zeros(n, n)?;
    let mut mass = Matrix::zeros(n, n)?;
    for (idx, value) in stiff.as_mut_slice().iter_mut().enumerate() {
        let (i, j) = (idx / n, idx % n);
        *value = match i.abs_diff(j) {
            0 => 2.0 * spring,
            1 => -spring,
            _ => 0.0,
        };
    }
    for (i, &mi) in masses.iter().enumerate() {
        mass.as_mut_slice()[i * n + i] = mi;
    }
    Ok((stiff, mass))
}
```

次のセルは質点の数 $N \in [11, 81]$（奇数）、ばね定数 $k \in [10, 1000]$ N/m、質量 $m \in [0.1, 10]$ kg、不純物の質量比 $r = m_d/m \in [0.2, 3]$ を選び、一般化固有値問題を解いて三重対角の経路と比べる。
一つ目の表は低い方と高い方の 3 個ずつのモードの周波数 $f_j = \omega_j/(2\pi)$ [Hz] を、同じ $N$、$k$、$m$ の均一な鎖（$r = 1$）の解析値と並べる。
$r = 1$ では解析値との一致を確かめ、$r \ne 1$ では不純物による周波数の変化を読む。
二つ目の表は二つの経路で求めた $\omega^2$ の相対差の最大値、$M$ 直交性の誤差 $\max\lvert \Phi^{\mathsf T}M\Phi - I \rvert$、全固有対で最大の残差の指標、帯域の上端 $2\sqrt{k/m}/(2\pi)$ [Hz] を示す。
残差の指標は `residuals()` が返す固有対 $(\lambda, v)$ ごとの $\lVert Kv - \lambda Mv \rVert_\infty / (N(\lVert K \rVert_{\max} + \lvert\lambda\rvert \lVert M \rVert_{\max})\lVert v \rVert_{\max})$ で、$\lVert\cdot\rVert_{\max}$ は絶対値が最大の成分の大きさである。

```rust
//| id: linalg-vibration-modes
//| ref: linalg-vibration-modes
//| title: ばね・質点鎖の固有振動数と二つの経路の比較
//| run: reactive
//| uses: [linalg-chain-model]
//| crates: [scioxide-core, scioxide-linalg]
//| inputs:
//|   nodes: {"type":"range","label":"質点の数 N","description":"奇数。中央の質点が不純物。","min":11,"max":81,"step":2,"value":31}
//|   spring: {"type":"range","label":"ばね定数 k [N/m]","description":"すべてのばねで同じ。","min":10,"max":1000,"step":10,"value":100}
//|   mass: {"type":"range","label":"質量 m [kg]","description":"不純物以外の質点の質量。","min":0.1,"max":10,"step":0.1,"value":1}
//|   ratio: {"type":"range","label":"不純物の質量比 r = m_d/m","description":"r < 1 で軽い不純物、r > 1 で重い不純物。","min":0.2,"max":3,"step":0.1,"value":0.4}
//| cases:
//|   - {"id":"uniform","label":"r = 1","description":"均一な鎖で、すべてのモードが解析値に一致する。","inputs":{"ratio":1}}
//|   - {"id":"heavy","label":"r = 3","description":"重い不純物では奇数番目のモードが下がり、帯域の外にモードは出ない。","inputs":{"ratio":3}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"modes","path":"/rows/1/3","range":{"min":-1e-12,"max":1e-12}}
//|       - {"artifact":"modes","path":"/rows/5/1","approx":{"value":3.98,"atol":0.01}}
//|       - {"artifact":"checks","path":"/rows/0/0","range":{"max":1e-12}}
//|       - {"artifact":"checks","path":"/rows/0/1","range":{"max":1e-13}}
//|   - case: uniform
//|     expect:
//|       - {"artifact":"modes","path":"/rows/0/3","range":{"min":-1e-12,"max":1e-12}}
//|       - {"artifact":"modes","path":"/rows/5/3","range":{"min":-1e-12,"max":1e-12}}
//|   - case: heavy
//|     expect:
//|       - {"artifact":"modes","path":"/rows/5/1","range":{"max":3.1831}}
//|       - {"artifact":"modes","path":"/rows/0/3","range":{"max":0}}
use scioxide_linalg::{
    GeneralizedHermitianEigenDecomposition, HermitianEigenDecomposition, HermitianInput,
};

let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let hz = serde_json::json!({ "fractionDigits": 6 });
let (n, k, m) = (nodes.round() as usize, spring, mass);
let masses = masses(n, m, ratio);
let (stiff, mass_matrix) = chain(k, &masses).map_err(|e| e.to_string())?;
// K と M は厳密に対称に組み立てたので、どちらも Exact として渡す。
let eigen = GeneralizedHermitianEigenDecomposition::decompose(
    &stiff,
    &mass_matrix,
    HermitianInput::Exact,
    HermitianInput::Exact,
)
.map_err(|e| e.to_string())?;
// 別経路: 対称化した三重対角行列 M^{-1/2} K M^{-1/2} の固有値。
let diag: Vec<f64> = masses.iter().map(|&mi| 2.0 * k / mi).collect();
let off: Vec<f64> = (0..n - 1)
    .map(|i| -k / (masses[i] * masses[i + 1]).sqrt())
    .collect();
let tri = HermitianEigenDecomposition::tridiagonal(&diag, &off).map_err(|e| e.to_string())?;
let routes = eigen
    .eigenvalues()
    .iter()
    .zip(tri.eigenvalues())
    .fold(0.0_f64, |d, (p, q)| d.max((p - q).abs() / q));
// M 直交性 ΦᵀMΦ − I を二つの積で求める。
let phi = eigen.eigenvectors();
let m_phi = mass_matrix.view().mul_mat(phi).map_err(|e| e.to_string())?;
let gram = phi
    .view()
    .transpose()
    .mul_mat(&m_phi)
    .map_err(|e| e.to_string())?;
let orthogonality = gram
    .as_slice()
    .iter()
    .enumerate()
    .map(|(idx, &g)| (g - if idx / n == idx % n { 1.0 } else { 0.0 }).abs())
    .fold(0.0_f64, f64::max);
let residual = eigen.residuals().iter().copied().fold(0.0_f64, f64::max);

// 均一な鎖の解析値 f_j = 2√(k/m) sin(jπ/(2(N+1)))/(2π)（f64 の標準関数による参照値）。
let two_pi = 2.0 * std::f64::consts::PI;
let uniform = |j: usize| {
    let angle = j as f64 * std::f64::consts::PI / (2.0 * (n + 1) as f64);
    2.0 * (k / m).sqrt() * angle.sin() / two_pi
};
let rows: Vec<(usize, f64, f64, f64)> = [0, 1, 2, n - 3, n - 2, n - 1]
    .into_iter()
    .map(|idx| {
        let f = eigen.eigenvalues()[idx].sqrt() / two_pi;
        (idx + 1, f, uniform(idx + 1), f / uniform(idx + 1) - 1.0)
    })
    .collect();
let mode_columns = serde_json::json!([
    { "key": "0", "label": "モード j", "type": "integer" },
    { "key": "1", "label": "周波数 f [Hz]", "type": "number", "format": hz },
    { "key": "2", "label": "均一な鎖の解析値 [Hz]", "type": "number", "format": hz },
    { "key": "3", "label": "相対的な違い [-]", "type": "number", "format": sci2 }
]);
emit_table_with_columns!(
    mode_columns,
    rows,
    metadata = serde_json::json!({ "id": "modes" })
);
let check_columns = serde_json::json!([
    { "key": "0", "label": "二経路の ω² の相対差の最大 [-]", "type": "number", "format": sci2 },
    { "key": "1", "label": "max |ΦᵀMΦ − I| [-]", "type": "number", "format": sci2 },
    { "key": "2", "label": "固有対の残差の指標の最大 [-]", "type": "number", "format": sci2 },
    { "key": "3", "label": "帯域の上端 2√(k/m)/(2π) [Hz]", "type": "number", "format": hz }
]);
let band_edge = 2.0 * (k / m).sqrt() / two_pi;
emit_table_with_columns!(
    check_columns,
    vec![(routes, orthogonality, residual, band_edge)],
    metadata = serde_json::json!({ "id": "checks" })
);
```

既定の $N = 31$、$k = 100$ N/m、$m = 1$ kg、$r = 0.4$ では、二つの経路の $\omega^2$ は相対 $5.8 \times 10^{-15}$ で一致し、$M$ 直交性の誤差 $1.6 \times 10^{-15}$ と残差の指標 $7.0 \times 10^{-17}$ は単位丸めの程度である。
偶数番目のモード（$j = 2, 30$）は中央に節があって不純物が動かないので、周波数が均一な鎖と同じになる。
奇数番目のモードは不純物の影響で高くなり、最も高いモードは帯域の上端 3.18 Hz を超えて 3.98 Hz になる。
この値は次の節の無限鎖の理論値 $\omega_L/(2\pi) = 3.979$ Hz と一致する。
$r = 1$ にすると、表のモードはすべて解析値と $10^{-14}$ の程度で一致する。
$r = 3$（重い不純物）では奇数番目のモードが下がり（最低モードで $-5.9\%$）、最も高いモードも帯域の上端より低い 3.168 Hz にとどまる。
二つの経路の差は $r = 3$ で $9.4 \times 10^{-14}$ まで広がるが、相対 $10^{-13}$ 以下である。
$k$ と $m$ は周波数を $\sqrt{k/m}$ 倍にするだけなので、相対的な違いの列と、$M$ 直交性・残差の指標は変わらない。
二つの経路の差は尺度によって少し動き、$k = 10$ N/m では $1.2 \times 10^{-13}$ になる。
$N = 81$ にすると、最も高いモード以外の違いは小さくなり（最低モードで 0.74%）、二つの経路の差は $4.3 \times 10^{-13}$ に広がる。

## 軽い不純物による局在モード

無限に長い鎖で不純物の位置を原点とし、$q = e^{-1/\xi}$ として $u_n \propto (-q)^{\lvert n \rvert}$ の形の解を運動方程式に代入する。
不純物以外の質点の式から $m\omega^2/k = (1+q)^2/q$、不純物の式から $r m \omega^2/k = 2(1+q)$ が出て、二つを連立すると $0 < q < 1$ の解は $r < 1$ のときだけあり

$$
\omega_L = \frac{2\sqrt{k/m}}{\sqrt{r(2-r)}}, \qquad e^{-1/\xi} = \frac{r}{2-r}
$$

となる。
$\omega_L$ は帯域の上端 $2\sqrt{k/m}$ より高く、振幅は隣の質点ごとに $r/(2-r)$ 倍になって符号を変えながら減衰する。
$r \to 1$ では $\xi \to \infty$ で帯域の上端につながり、$r \to 0$ では不純物だけが振動する。

次のセルは $k = 1$ N/m、$m = 1$ kg とし、質点の数 $N$ と質量比 $r \in [0.1, 0.9]$ を選ぶ。
最も高いモードの角振動数を $\omega_L$ と比べ、不純物から 1〜6 個離れた質点の振幅 $\lvert \sqrt{m_i}\,\phi_i \rvert$ の対数の傾きを $-1/\xi$ と比べる。
有限の鎖の結果は、局在長 $\xi$ が鎖の半分の長さより十分短いときに無限鎖の理論に近づく。
図は最も高いモードと最も低いモードの振幅を、不純物からの位置に対して描く。

```rust
//| id: linalg-localized-mode
//| ref: linalg-localized-mode
//| title: 軽い不純物の局在モードの周波数と減衰長
//| run: reactive
//| uses: [linalg-chain-model]
//| crates: [scioxide-core, scioxide-linalg]
//| inputs:
//|   nodes: {"type":"range","label":"質点の数 N","description":"奇数。中央の質点が不純物。","min":11,"max":81,"step":2,"value":41}
//|   ratio: {"type":"range","label":"不純物の質量比 r","description":"1 未満で局在モードが現れる。","min":0.1,"max":0.9,"step":0.05,"value":0.4}
//| cases:
//|   - {"id":"weak-impurity","label":"r = 0.9","description":"局在長が 5 質点に伸び、無限鎖の理論からわずかにずれる。","inputs":{"ratio":0.9}}
//|   - {"id":"short-chain","label":"N = 11, r = 0.9","description":"振幅が両端の壁に届き、傾きが理論から大きくずれる。","inputs":{"nodes":11,"ratio":0.9}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"localized","path":"/rows/0/2","range":{"max":1e-10}}
//|       - {"artifact":"localized","path":"/rows/0/0","approx":{"value":2.5,"rtol":1e-10}}
//|       - {"artifact":"localized","path":"/rows/0/5","approx":{"value":0.7213,"atol":1e-3}}
//|   - case: weak-impurity
//|     expect:
//|       - {"artifact":"localized","path":"/rows/0/2","range":{"min":1e-7,"max":1e-4}}
//|       - {"artifact":"localized","path":"/rows/0/3","approx":{"value":-0.2007,"atol":1e-3}}
//|   - case: short-chain
//|     expect:
//|       - {"artifact":"localized","path":"/rows/0/2","range":{"min":1e-4}}
//|       - {"artifact":"localized","path":"/rows/0/3","range":{"max":-0.3}}
use scioxide_linalg::{GeneralizedHermitianEigenDecomposition, HermitianInput};

// k = 1 N/m、m = 1 kg として、周波数を √(k/m) の単位で表す。
let n = nodes.round() as usize;
let c = n / 2;
let masses = masses(n, 1.0, ratio);
let (stiff, mass_matrix) = chain(1.0, &masses).map_err(|e| e.to_string())?;
let eigen = GeneralizedHermitianEigenDecomposition::decompose(
    &stiff,
    &mass_matrix,
    HermitianInput::Exact,
    HermitianInput::Exact,
)
.map_err(|e| e.to_string())?;
let top = eigen.eigenvalues()[n - 1].sqrt();
// 無限鎖の理論値（f64 の標準関数による参照値）。
let omega_l = 2.0 / (ratio * (2.0 - ratio)).sqrt();
let decay = (ratio / (2.0 - ratio)).ln();
// モード j の質量で重み付けした振幅 √m_i φ_i（φ は列が固有ベクトルの行優先の行列）。
let vectors = eigen.eigenvectors().as_slice();
let weighted = |j: usize| -> Vec<f64> {
    (0..n)
        .map(|i| masses[i].sqrt() * vectors[i * n + j])
        .collect()
};
let amplitude = weighted(n - 1);
// 不純物から 1〜6 個離れた振幅の対数の平均の傾き（左右の平均）。
let reach = 6.min(c);
let side_slope = |side: usize| {
    let at = |d: usize| {
        let index = if side == 0 { c - d } else { c + d };
        amplitude[index].abs().ln()
    };
    (at(reach) - at(1)) / (reach - 1) as f64
};
let slope = (side_slope(0) + side_slope(1)) / 2.0;
let fixed8 = serde_json::json!({ "fractionDigits": 8 });
let fixed6 = serde_json::json!({ "fractionDigits": 6 });
let fixed3 = serde_json::json!({ "fractionDigits": 3 });
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let columns = serde_json::json!([
    { "key": "0", "label": "最高モード ω/√(k/m) [-]", "type": "number", "format": fixed8 },
    { "key": "1", "label": "無限鎖 ω_L/√(k/m) [-]", "type": "number", "format": fixed8 },
    { "key": "2", "label": "相対差 [-]", "type": "number", "format": sci2 },
    { "key": "3", "label": "振幅の対数の傾き [1/質点]", "type": "number", "format": fixed6 },
    { "key": "4", "label": "−1/ξ = ln(r/(2−r)) [1/質点]", "type": "number", "format": fixed6 },
    { "key": "5", "label": "局在長 ξ [質点]", "type": "number", "format": fixed3 }
]);
let row = (
    top,
    omega_l,
    (top - omega_l).abs() / omega_l,
    slope,
    decay,
    -1.0 / decay,
);
emit_table_with_columns!(
    columns,
    vec![row],
    metadata = serde_json::json!({ "id": "localized" })
);
let position = |values: Vec<f64>| -> Vec<[f64; 2]> {
    values
        .into_iter()
        .enumerate()
        .map(|(i, a)| [i as f64 - c as f64, a])
        .collect()
};
emit_line_chart!(
    &vec![
        serde_json::json!({ "name": "最高モード", "points": position(amplitude.clone()) }),
        serde_json::json!({ "name": "最低モード", "points": position(weighted(0)) })
    ],
    options = &serde_json::json!({
        "xLabel": "不純物からの位置 i − c [質点]",
        "yLabel": "質量で重み付けした変位 √m_i φ_i [-]"
    })
);
```

既定の $N = 41$、$r = 0.4$ では局在長は $\xi = 0.72$ 質点と短く、最も高いモードの角振動数と振幅の対数の傾きは無限鎖の理論値に表示の桁まで一致する。
図の最も高いモードは不純物の位置で鋭くとがり、隣ごとに符号を変えながら減衰し、最も低いモードは鎖全体に広がる。
$r = 0.9$ では局在長が 5 質点に伸び、角振動数の相対差は $4.4 \times 10^{-6}$ に増え、傾きは $-0.2010$ と理論の $-0.2007$ よりわずかに急になる。
同じ $r$ で $N = 11$ にすると、振幅が両端の壁に届いて傾きが $-0.42$ と理論から大きくずれ、有限の鎖の境界の影響が見える。
$r = 0.1$ では $\omega_L$ が帯域の上端の 2.3 倍に上がり、振動はほぼ不純物だけに閉じ込められる。

## まとめ

剛性行列 $K$ と正定値な質量行列 $M$ を持つ振動問題は、`GeneralizedHermitianEigenDecomposition::decompose` に二つの行列をそのまま渡して解ける。
結果は $\Phi^{\mathsf T}M\Phi = I$ と `residuals()` で確かめ、$M$ が対角なら $M^{-1/2}KM^{-1/2}$ を `tridiagonal` で解く経路と比べて還元の誤差を測れる。
この例の二つの経路の差は既定値で相対 $5.8 \times 10^{-15}$、$N = 81$ で $4.3 \times 10^{-13}$ で、均一な鎖では分散関係の解析解とも一致した。
軽い不純物（$r < 1$）は帯域の外に局在モードを作り、その周波数と減衰長は無限鎖の理論 $\omega_L = 2\sqrt{k/m}/\sqrt{r(2-r)}$、$e^{-1/\xi} = r/(2-r)$ で見積もれる。
有限の鎖でこの見積もりが使えるのは、局在長が鎖の半分の長さより十分短いときである。
