気温や株価、音声のように時間とともに得られるデータでは、現在の値を過去の値の線形結合で予測する自己回帰（AR）モデルがよく使われる。
AR モデルの係数は自己相関を並べた対称な Toeplitz 行列の方程式（Yule–Walker 方程式）から決まる。
Toeplitz 構造を使う Levinson–Durbin の漸化式は、この方程式を $O(P^2)$ 回の演算で解き、途中ですべての低い次数の解も与える。
この例題では、理論的な自己相関から係数が丸め誤差の範囲で復元されることを確かめ、模擬データから推定した係数の誤差を漸近的な標準誤差と比べる。
時刻は標本の番号で数え、単位は「時点」とする。

## AR(2) 過程と自己相関

AR(2) 過程は、互いに独立で平均 0、分散 $\sigma^2$ のノイズ $\varepsilon_t$ を使って

$$
X_t = \phi_1 X_{t-1} + \phi_2 X_{t-2} + \varepsilon_t
$$

で定まる時系列である。
特性方程式 $z^2 - \phi_1 z - \phi_2 = 0$ の根が単位円の内側にあれば過程は定常で、ここでは根を $r e^{\pm \mathrm{i}\theta}$（$0 < r < 1$）として $\phi_1 = 2r\cos\theta$、$\phi_2 = -r^2$ と置く。
$r$ が 1 に近いほど相関が長く続き、$\theta$ は周期 $2\pi/\theta$ 時点の準周期的な振動を表す。

自己相関 $\rho(k) = \operatorname{Cov}(X_t, X_{t-k}) / \operatorname{Var}(X_t)$ は、両辺に $X_{t-k}$ を掛けて期待値をとると

$$
\rho(0) = 1, \qquad \rho(1) = \frac{\phi_1}{1 - \phi_2}, \qquad \rho(k) = \phi_1 \rho(k-1) + \phi_2 \rho(k-2) \quad (k \ge 2)
$$

を満たす。
両辺に $X_t$ を掛けて期待値をとった式 $\gamma(0) = \phi_1\gamma(1) + \phi_2\gamma(2) + \sigma^2$（$\gamma(k) = \operatorname{Cov}(X_t, X_{t-k})$）に $\rho(1)$、$\rho(2)$ を代入すると、ノイズの分散と過程の分散 $\gamma(0) = \operatorname{Var}(X_t)$ の比は

$$
\frac{\sigma^2}{\gamma(0)} = \frac{(1+\phi_2)\bigl((1-\phi_2)^2 - \phi_1^2\bigr)}{1-\phi_2}
$$

になる。

## Yule–Walker 方程式と偏自己相関

次数 $P$ の AR モデル $X_t = \sum_{j=1}^{P} a_j X_{t-j} + e_t$ の係数を予測誤差の分散が最小になるよう選ぶと、係数は

$$
R_P\, a = (\rho(1), \dots, \rho(P))^{\mathsf T}, \qquad (R_P)_{ij} = \rho(\lvert i - j \rvert)
$$

を満たす（Yule–Walker 方程式）。
$R_P$ は対称正定値な Toeplitz 行列で、最後の係数 $a_P^{(P)}$ を偏自己相関 $\alpha(P)$ という。
正規化した予測誤差の分散は $E_P = 1 - \sum_{j=1}^{P} a_j \rho(j)$ である。
真の過程が AR(2) なら $P \ge 2$ の解は $(\phi_1, \phi_2, 0, \dots, 0)$ で、偏自己相関は $\alpha(1) = \rho(1)$、$\alpha(2) = \phi_2$、$P \ge 3$ で 0 になる（切断）。
このとき $E_P$ は $P \ge 2$ で上の $\sigma^2/\gamma(0)$ に等しい。

Levinson–Durbin の漸化式は、次数 $k-1$ の解から反射係数

$$
\kappa_k = \frac{\rho(k) - \sum_{j=1}^{k-1} a_j^{(k-1)} \rho(k-j)}{E_{k-1}}, \qquad E_k = E_{k-1}(1 - \kappa_k^2), \quad E_0 = 1
$$

を求めて $a^{(k)}_j = a^{(k-1)}_j - \kappa_k a^{(k-1)}_{k-j}$、$a^{(k)}_k = \kappa_k$ と更新する。
反射係数は偏自己相関そのもので、$E_k$ は上の正規化した予測誤差の分散である。
1 次ずつ進むたびに $O(k)$ 回の演算がかかるので、次数 $P$ までの全体は $O(P^2)$ で、密な LU 分解の $O(P^3)$ より小さい。

この方程式は構造を持つ行列の記述 `StructuredMatrixView::toeplitz(&column, &row)` を[Plan](oxref:linalg-execution-forms) `StructuredSolvePlan` に渡して解く（[Toeplitz・Hankel・巡回行列](oxref:linalg-toeplitz-systems)）。
Plan は対称な Toeplitz 行列に保護付きの Levinson–Durbin を使う。
予測誤差が最大の係数に対して $\sqrt{\varepsilon}$ 以下に落ちるか、漸化式が非有限の値や受理されない解を出した列は、ピボット付きの GKO 消去（Gohberg–Kailath–Olshevsky）で解き直す。
どちらも右辺 1 本あたり $O(P^2)$ の演算で、$R_P$ が正定値でなくてもよい。
受理の基準は行ごとの後退誤差

$$
\eta = \max_i \frac{\lvert b - A x \rvert_i}{\lvert b_i \rvert + \lVert x \rVert_\infty \sum_j \lvert a_{ij} \rvert}
$$

で、`StructuredSolveOptions` の許容誤差 $(\mathrm{atol}, \mathrm{rtol})$ に対して $\eta \le \mathrm{atol} + \mathrm{rtol}$ の解を受理する。
既定は $\mathrm{atol} = \mathrm{rtol} = \sqrt{\varepsilon} \approx 1.5 \times 10^{-8}$ なので、$\eta \le 2\sqrt{\varepsilon} \approx 3.0 \times 10^{-8}$ が受理の条件になる。
Plan の求解は出力・作業領域・実行コンテキストを受け取る[出力先を指定する API](oxref:linalg-execution-forms)だけで、右辺 1 本には `solve_into(operation, b, output, workspace, context)`、複数の右辺には `solve_matrix_into` を使う。
レポート `StructuredSolveReport` の `termination()` は `Accepted` か `ResidualRejected` を、`backward_error()` は $\eta$ を、`levinson_solves()` と `gko_solves()` はそれぞれの方法で受理した列の数を返す。
受理されなかった解は `Ok` のまま `ResidualRejected` になり、出力は書かれないので、セルでは終了理由を確かめる。
密な LU 分解への切り替えは作業領域を `StructuredWorkspaceRequest::with_dense_fallback` で事前確保したときだけ使われ、このページでは使わない。
レポートが要らなければ、[ワンショット関数](oxref:linalg-execution-forms) `solve_structured(matrix, &b)` が既定の設定で同じ Plan を作って解き、受理されない解を `NumericalInstability`（`LossOfSignificance`）の誤りとして返す。

次の定義は、このページの三つのセルが共有する AR(2) のモデルである。
`ar2_coefficients` は根 $re^{\pm\mathrm{i}\theta}$ から $(\phi_1, \phi_2)$ を、`autocorrelation` は上の漸化式で $\rho(0), \dots, \rho(P_{\max})$ を、`variance_ratio` は $\sigma^2/\gamma(0)$ を返す。

```rust
//| id: linalg-yule-walker-model
//| kind: definitions
//| title: AR(2) 過程の係数・自己相関・予測誤差の分散
//| crates: [scioxide-core]
use scioxide_core::RealScalar;

/// 根 r e^{±iθ} の AR(2) の係数 (φ₁, φ₂) = (2r cos θ, −r²)。θ は度。
pub(crate) fn ar2_coefficients(radius: f64, angle_degrees: f64) -> (f64, f64) {
    let cosine = RealScalar::cos(angle_degrees.to_radians());
    (2.0 * radius * cosine, -radius * radius)
}

/// 理論的な自己相関 ρ(0), …, ρ(p_max)。ρ(1) = φ₁/(1 − φ₂)、ρ(k) = φ₁ρ(k−1) + φ₂ρ(k−2)。
pub(crate) fn autocorrelation(phi1: f64, phi2: f64, p_max: usize) -> Vec<f64> {
    let mut rho = vec![1.0, phi1 / (1.0 - phi2)];
    for k in 2..=p_max {
        rho.push(phi1 * rho[k - 1] + phi2 * rho[k - 2]);
    }
    rho
}

/// 正規化した予測誤差の分散 σ²/γ(0) = (1 + φ₂)((1 − φ₂)² − φ₁²)/(1 − φ₂)。
pub(crate) fn variance_ratio(phi1: f64, phi2: f64) -> f64 {
    (1.0 + phi2) * ((1.0 - phi2).powi(2) - phi1 * phi1) / (1.0 - phi2)
}
```

次のセルは根の絶対値 $r$（0.1〜0.99）、偏角 $\theta$（0〜180 度）、最大の次数 $P_{\max}$（3〜60）を選び、理論的な自己相関から次数 1〜$P_{\max}$ の方程式を一つずつ `StructuredSolvePlan` で解く。
Plan は与えた次数の解だけを返し、漸化式の途中の低い次数の解は出力に反映しないので、偏自己相関を並べるには次数ごとに解き直す。
作業領域 `LinalgWorkspace` は一つを全次数で使い回し、足りない容量は `solve_into` が確保する。
1 つ目の表は偏自己相関 $\alpha(P)$ を理論値と比べる。
2 つ目の表は $P \ge 2$ の係数の真の値との差の最大、後退誤差の最大、方法ごとの次数の数、受理されなかった次数の数と、$E_{P_{\max}}$ と $\sigma^2/\gamma(0)$ を示す。
outcome は、すべての次数の解が受理されたかを示す。
このセルの $(\phi_1, \phi_2)$ と $P_{\max}$ は、次の節の条件数のセルに渡す。

```rust
//| id: linalg-yule-walker-levinson
//| ref: linalg-yule-walker-levinson
//| title: 理論的な自己相関による Yule–Walker 方程式と偏自己相関の切断
//| run: reactive
//| uses: [linalg-yule-walker-model]
//| crates: [scioxide-core, scioxide-linalg]
//| exports: [phi1, phi2, p_max]
//| inputs:
//|   radius: {"type":"range","label":"根の絶対値 r [-]","description":"1 に近いほど相関が長く続く。","min":0.1,"max":0.99,"step":0.01,"value":0.8}
//|   angle: {"type":"range","label":"根の偏角 θ [度]","description":"準周期は 360/θ 時点。","min":0,"max":180,"step":5,"value":60}
//|   max_order: {"type":"range","label":"最大の次数 P_max [-]","description":"次数 1 から P_max まで解く。","min":3,"max":60,"step":1,"value":12}
//| cases:
//|   - {"id":"near-unit-root","label":"r = 0.99, θ = 5°, P_max = 60","description":"スペクトルに鋭い山ができ、後退誤差は小さいまま係数の差が増える。","inputs":{"radius":0.99,"angle":5,"max_order":60}}
//|   - {"id":"double-root","label":"r = 0.99, θ = 0°, P_max = 60","description":"実数の重根では条件数がさらに大きくなり、係数の差が 10⁻⁹ の程度になる。","inputs":{"radius":0.99,"angle":0,"max_order":60}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"pacf","path":"/rows/0/1","approx":{"value":0.4878048780487805,"rtol":1e-12}}
//|       - {"artifact":"pacf","path":"/rows/1/1","approx":{"value":-0.64,"rtol":1e-12}}
//|       - {"artifact":"pacf","path":"/rows/4/3","range":{"max":1e-14}}
//|       - {"artifact":"solves","path":"/rows/0/0","range":{"max":1e-13}}
//|       - {"artifact":"solves","path":"/rows/0/3","equals":0}
//|       - {"artifact":"solves","path":"/rows/0/5","approx":{"value":0.4499121951219512,"rtol":1e-12}}
//|       - {"artifact":"solves","path":"/rows/0/6","approx":{"value":0.4499121951219512,"rtol":1e-14}}
//|       - {"path":"/outputs/3/state","equals":"satisfied"}
//|   - case: near-unit-root
//|     expect:
//|       - {"artifact":"solves","path":"/rows/0/0","range":{"min":1e-12,"max":1e-8}}
//|       - {"artifact":"solves","path":"/rows/0/5","approx":{"value":3.0326724188416615e-4,"rtol":1e-9}}
//|       - {"path":"/outputs/3/state","equals":"satisfied"}
//|   - case: double-root
//|     expect:
//|       - {"artifact":"solves","path":"/rows/0/0","range":{"min":1e-10,"max":1e-7}}
//|       - {"path":"/outputs/3/state","equals":"satisfied"}
use scioxide_core::ExecutionContext;
use scioxide_linalg::{
    LinalgWorkspace, StructuredMatrixView, StructuredOperation, StructuredSolveOptions,
    StructuredSolvePlan, VectorViewMut,
};

let (phi1, phi2) = ar2_coefficients(radius, angle);
let p_max = max_order.round() as usize;
let rho = autocorrelation(phi1, phi2, p_max);
let options = StructuredSolveOptions::new();
// 作業領域は一つを全次数で使い回し、足りない容量は solve_into が確保する。
let mut workspace = LinalgWorkspace::new();
let (mut rows, mut pacf, mut prediction_error) = (Vec::new(), Vec::new(), None);
let (mut coefficient_error, mut worst_backward) = (0.0_f64, 0.0_f64);
let (mut levinson, mut gko, mut rejected) = (0, 0, 0);
for p in 1..=p_max {
    // R_P の第 1 列と第 1 行はどちらも (ρ(0), …, ρ(P−1))。
    let matrix =
        StructuredMatrixView::toeplitz(&rho[..p], &rho[..p]).map_err(|e| e.to_string())?;
    let plan = StructuredSolvePlan::new(matrix, &options).map_err(|e| e.to_string())?;
    let mut a = vec![0.0_f64; p];
    let report = plan
        .solve_into(
            StructuredOperation::Normal,
            &rho[1..=p],
            VectorViewMut::from_slice(&mut a),
            &mut workspace,
            ExecutionContext::sequential_native(),
        )
        .map_err(|e| e.to_string())?;
    worst_backward = worst_backward.max(report.backward_error());
    // 受理されない解は出力に書かれないので、その次数は数えて飛ばす。
    if !report.termination().is_success() {
        rejected += 1;
        continue;
    }
    levinson += report.levinson_solves();
    gko += report.gko_solves();
    // 真の係数 (φ₁, φ₂, 0, …) との差。P = 1 の正解は ρ(1) なので P ≥ 2 で測る。
    let truth = |j: usize| [phi1, phi2].get(j).copied().unwrap_or(0.0);
    if p >= 2 {
        let worst = a
            .iter()
            .enumerate()
            .fold(0.0_f64, |m, (j, v)| m.max((v - truth(j)).abs()));
        coefficient_error = coefficient_error.max(worst);

    let expected = if p == 1 { rho[1] } else { truth(p - 1) };
    pacf.push([p as f64, a[p - 1]]);
    if p <= 4 || p == p_max {
        rows.push((p, a[p - 1], expected, (a[p - 1] - expected).abs()));
    }
    if p == p_max {
        // E_P = 1 − Σ a_j ρ(j)。
        let explained: f64 = a.iter().zip(&rho[1..=p]).map(|(x, r)| x * r).sum();
        prediction_error = Some(1.0 - explained);
    }
}

    { "key": "3", "label": "差 [-]", "type": "number", "format": sci2 }
]);
emit_table_with_columns!(
    pacf_columns,
    rows,
    metadata = serde_json::json!({ "id": "pacf" })
);
let solve_columns = serde_json::json!([
    { "key": "0", "label": "P ≥ 2 の係数の差の最大 [-]", "type": "number", "format": sci2 },
    { "key": "1", "label": "後退誤差 η の最大 [-]", "type": "number", "format": sci2 },
    { "key": "2", "label": "Levinson–Durbin [次数]", "type": "integer" },
    { "key": "3", "label": "GKO [次数]", "type": "integer" },
    { "key": "4", "label": "受理されない次数 [次数]", "type": "integer" },
    { "key": "5", "label": "E_Pmax [-]", "type": "number", "format": fixed6, "nullText": "受理なし" },
    { "key": "6", "label": "σ²/γ(0)（理論）[-]", "type": "number", "format": fixed6 }
]);
let ratio = variance_ratio(phi1, phi2);
let summary = (
    coefficient_error,
    worst_backward,
    levinson,
    gko,
    rejected,
    prediction_error,
    ratio,
);
emit_table_with_columns!(
    solve_columns,
    vec![summary],
    metadata = serde_json::json!({ "id": "solves" })
);
emit_line_chart!(
    &vec![serde_json::json!({ "name": "偏自己相関 α(P)", "points": pacf })],
    options = &serde_json::json!({
        "xLabel": "次数 P [-]",
        "yLabel": "α(P) [-]",
        "yMin": -1.0,
        "yMax": 1.0
    })
);
export!(phi1, phi1);
export!(phi2, phi2);
export!(p_max, p_max);
let outcome = if rejected == 0 {
    Outcome::satisfied("すべての次数の解が後退誤差の許容誤差 2√ε で受理された")
        .status("Accepted")
} else {
    Outcome::failed("一部の次数の解が受理されなかった").status("ResidualRejected")
};
emit_outcome!(
    outcome
        .diagnostic("後退誤差の最大", worst_backward, None)
        .diagnostic("受理されない次数", rejected as f64, None)
);
```

既定の $r = 0.8$、$\theta = 60^\circ$（$\phi_1 = 0.8$、$\phi_2 = -0.64$）では、偏自己相関は $\alpha(1) = 0.487805$、$\alpha(2) = -0.64$ で、次数 3 以上は 0 になる。
次数 2 以上の係数は真の値と一致し、後退誤差の最大は $3.3 \times 10^{-17}$ で、12 個の次数すべてが Levinson–Durbin で受理されて GKO への切り替えは起きない。
$E_{12}$ は $\sigma^2/\gamma(0) = 0.449912$ と表示した桁まで一致する。

$r = 0.99$、$\theta = 5^\circ$、$P_{\max} = 60$ では、係数の差が $1.2 \times 10^{-11}$ まで増えるが、後退誤差は $2.3 \times 10^{-17}$ のままである。
$\theta = 0^\circ$（実数の重根 0.99）では、係数の差が $9.4 \times 10^{-10}$ になる。
どちらの場合も 60 個の次数がすべて Levinson–Durbin で受理され、outcome は `satisfied` である。
後退誤差が小さいまま前進誤差だけが増える理由は、次の節の条件数で分かる。

## 条件数とスペクトル密度

過程のスペクトル密度は $S(\omega) \propto 1/\lvert A(e^{-\mathrm{i}\omega}) \rvert^2$、$A(z) = 1 - \phi_1 z - \phi_2 z^2$ である。
$R_P$ の固有値は比例定数を適切にそろえた $S$ の最小値と最大値の間にある（Grenander と Szegő が示した Toeplitz 行列の性質）。
したがって次数によらず $\kappa_2(R_P) \le \max S / \min S$ で、$r \to 1$ では $\omega = \theta$ の近くに鋭い山ができて上界が大きくなる。

次のセルは前のセルの $(\phi_1, \phi_2)$ と $P_{\max}$ を受け取り、$P = 1, \dots, P_{\max}$ の $R_P$ を `materialize()` で密な行列にして、`SvdValues::compute` の特異値の比から $\kappa_2(R_P)$ を求める。
上界 $\max S / \min S$ は $\lvert A(e^{-\mathrm{i}\omega}) \rvert^2$ を $[0, \pi]$ の 4001 点で評価して求める（検算用の参照値なので `f64` の固有メソッドで計算する）。
表は $P_{\max}$ での $\kappa_2$ と上界とその比を示し、グラフは $\kappa_2(R_P)$ を対数軸で描いて上界を横線で示す。

```rust
//| id: linalg-yule-walker-conditioning
//| ref: linalg-yule-walker-conditioning
//| title: R_P の条件数とスペクトル密度による上界
//| run: reactive
//| uses: [linalg-yule-walker-model]
//| crates: [scioxide-core, scioxide-linalg]
//| dependsOn:
//|   model: linalg-yule-walker-levinson
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"bound","path":"/rows/0/0","equals":12}
//|       - {"artifact":"bound","path":"/rows/0/1","approx":{"value":40.451,"rtol":1e-4}}
//|       - {"artifact":"bound","path":"/rows/0/2","approx":{"value":61.251,"rtol":1e-4}}
//|       - {"artifact":"bound","path":"/rows/0/3","range":{"max":1.0}}
use scioxide_linalg::{StructuredMatrixView, SvdValues};

let phi1 = model["phi1"].as_f64().ok_or("φ₁ がない")?;
let phi2 = model["phi2"].as_f64().ok_or("φ₂ がない")?;
let p_max = model["p_max"].as_u64().ok_or("P_max がない")? as usize;
let rho = autocorrelation(phi1, phi2, p_max);
// 上界 max S / min S = max |A|² / min |A|²（f64 の固有メソッドによる参照値）。
let gain = |w: f64| {
    let (s1, c1) = w.sin_cos();
    let (s2, c2) = (2.0 * w).sin_cos();
    (1.0 - phi1 * c1 - phi2 * c2).powi(2) + (phi1 * s1 + phi2 * s2).powi(2)
};
let grid: Vec<f64> = (0..=4000)
    .map(|i| gain(std::f64::consts::PI * i as f64 / 4000.0))
    .collect();
let bound = grid.iter().copied().fold(0.0_f64, f64::max)
    / grid.iter().copied().fold(f64::INFINITY, f64::min);
// κ₂(R_P) = σ_max/σ_min を次数ごとに特異値から求める。
let mut kappa = Vec::with_capacity(p_max);
for p in 1..=p_max {
    let dense = StructuredMatrixView::toeplitz(&rho[..p], &rho[..p])
        .and_then(|view| view.materialize())
        .map_err(|e| e.to_string())?;
    let sigma = SvdValues::compute(&dense).map_err(|e| e.to_string())?;
    let values = sigma.singular_values();
    kappa.push([p as f64, values[0] / values[p - 1]]);
}
let last = kappa[p_max - 1][1];
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let columns = serde_json::json!([
    { "key": "0", "label": "次数 P_max [-]", "type": "integer" },
    { "key": "1", "label": "κ₂(R_Pmax)（SVD）[-]", "type": "number", "format": sci3 },
    { "key": "2", "label": "上界 max S / min S [-]", "type": "number", "format": sci3 },
    { "key": "3", "label": "κ₂ / 上界 [-]", "type": "number", "format": { "fractionDigits": 3 } }
]);
emit_table_with_columns!(
    columns,
    vec![(p_max, last, bound, last / bound)],
    metadata = serde_json::json!({ "id": "bound" })
);
emit_line_chart!(
    &vec![serde_json::json!({ "name": "κ₂(R_P)", "points": kappa })],
    options = &serde_json::json!({
        "xLabel": "次数 P [-]",
        "yLabel": "条件数 κ₂(R_P) [-]",
        "yType": "log",
        "annotations": [
            { "kind": "line", "axis": "y", "value": bound, "label": "上界 max S / min S" }
        ]
    })
);
```

既定値では $\kappa_2(R_{12}) = 40$ で、スペクトル密度による上界 61 の 0.66 倍である。
グラフの $\kappa_2(R_P)$ は次数とともに増えて上界に近づくが、上界を超えない。
$R_P$ は $R_{P+1}$ の左上の主小行列なので、固有値の分離定理（Cauchy の interlacing 定理）から、次数を上げても最大固有値は減らず最小固有値は増えない。
したがって $\kappa_2(R_P)$ は $P$ について単調に増える。
Toeplitz 行列の端の固有値は $P \to \infty$ で $S$ の最小値と最大値に近づくので、上界は大きな次数での条件数の極限でもある。

$r = 0.99$、$\theta = 5^\circ$、$P_{\max} = 60$ では上界が $5.2 \times 10^{6}$、$\kappa_2(R_{60}) = 1.5 \times 10^{6}$ になる。
$\theta = 0^\circ$ では上界が $1.6 \times 10^{9}$、$\kappa_2(R_{60}) = 2.3 \times 10^{8}$ になる。
前のセルの係数の差 $1.2 \times 10^{-11}$ と $9.4 \times 10^{-10}$ は、後退誤差の最大に $\kappa_2$ を掛けた目安 $3.5 \times 10^{-11}$ と $8.3 \times 10^{-9}$ を下回る。
後退安定な解の前進誤差は条件数とともに増え、その大きさは後退誤差と条件数の積の程度と見積もれる。

## 模擬データからの推定

実際のデータでは自己相関を標本から推定する。
長さ $T$ の系列 $x_1, \dots, x_T$ の標本自己相関

$$
\hat\rho(k) = \frac{\sum_{t=1}^{T-k} (x_t - \bar x)(x_{t+k} - \bar x)}{\sum_{t=1}^{T} (x_t - \bar x)^2}
$$

は分母を $T$ でそろえた推定量で、これを並べた Toeplitz 行列は常に半正定値になり、Levinson–Durbin の反射係数は $\lvert\kappa_k\rvert \le 1$ に収まる。
$T$ が大きいとき、AR(2) の Yule–Walker 推定量 $(\hat\phi_1, \hat\phi_2)$ の標準誤差はどちらも $\sqrt{(1 - \phi_2^2)/T}$ で、次数 $P \ge 3$ の偏自己相関の推定値はおよそ標準偏差 $1/\sqrt{T}$ で 0 のまわりにばらつく。
したがって、帯 $\pm 1.96/\sqrt{T}$ を超える次数は、真の過程が AR(2) なら平均して 5% 程度である。

次のセルは `scioxide-random` の正規乱数（生成器は `SplitMix64`）でノイズを作って AR(2) 系列を作り、標本自己相関から次数 1〜12 の方程式をワンショット関数 `solve_structured` で解く。
最初の 500 時点は初期値 0 の影響を除くために捨てる。
独立な経路として Levinson–Durbin の漸化式を直接書いて偏自己相関を求め、二つの差を示す。
入力は $r$、$\theta$、系列の長さ $T$（100〜20000 時点）と乱数のシードである。
1 つ目の表は $(\hat\phi_1, \hat\phi_2)$ を真の値と標準誤差で比べ、2 つ目の表は二経路の差、帯を超えた次数の数、$E_{12}$ の推定値と理論値を示す。
グラフは推定した $\alpha(P)$ と帯 $\pm 1.96/\sqrt{T}$ である。

```rust
//| id: linalg-yule-walker-sample
//| ref: linalg-yule-walker-sample
//| title: 模擬 AR(2) 系列の標本自己相関による係数の推定
//| run: reactive
//| uses: [linalg-yule-walker-model]
//| crates: [scioxide-core, scioxide-linalg, scioxide-random]
//| inputs:
//|   radius: {"type":"range","label":"根の絶対値 r [-]","description":"1 に近いほど相関が長く続く。","min":0.1,"max":0.99,"step":0.01,"value":0.8}
//|   angle: {"type":"range","label":"根の偏角 θ [度]","description":"準周期は 360/θ 時点。","min":0,"max":180,"step":5,"value":60}
//|   length: {"type":"range","label":"系列の長さ T [時点]","description":"標本自己相関に使う時点の数。","min":100,"max":20000,"step":100,"value":2000}
//|   seed: {"type":"range","label":"乱数のシード [-]","description":"ノイズの系列を変える。","min":1,"max":50,"step":1,"value":7}
//| cases:
//|   - {"id":"long-series","label":"T = 20000","description":"系列を長くすると、係数の差が 1/√T に比例して縮む。","inputs":{"length":20000}}
//|   - {"id":"near-unit-root","label":"r = 0.99, θ = 5°, T = 20000","description":"根が単位円に近いと、Yule–Walker 推定の偏りが標準誤差を大きく超える。","inputs":{"radius":0.99,"angle":5,"length":20000}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"checks","path":"/rows/0/0","range":{"max":1e-12}}
//|       - {"artifact":"estimates","path":"/rows/0/5","range":{"min":-3.0,"max":3.0}}
//|       - {"artifact":"estimates","path":"/rows/1/5","range":{"min":-3.0,"max":3.0}}
//|       - {"artifact":"checks","path":"/rows/0/4","approx":{"value":0.4499121951219512,"rtol":1e-14}}
//|   - case: long-series
//|     expect:
//|       - {"artifact":"estimates","path":"/rows/0/4","approx":{"value":0.0054,"rtol":0.01}}
//|       - {"artifact":"estimates","path":"/rows/0/5","range":{"min":-3.0,"max":3.0}}
//|   - case: near-unit-root
//|     expect:
//|       - {"artifact":"checks","path":"/rows/0/0","range":{"max":1e-9}}
//|       - {"artifact":"estimates","path":"/rows/0/5","range":{"max":-5.0}}
//|       - {"artifact":"estimates","path":"/rows/1/5","range":{"min":5.0}}
use scioxide_linalg::{StructuredMatrixView, solve_structured};
use scioxide_random::{Distribution, Normal, SeedableRng, SplitMix64};

let (phi1, phi2) = ar2_coefficients(radius, angle);
let t_len = length.round() as usize;
let normal = Normal::new(0.0_f64, 1.0).map_err(|e| e.to_string())?;
let mut rng = SplitMix64::from_seed(seed.round() as u64);
// X_t = φ₁X_{t−1} + φ₂X_{t−2} + ε_t。初期値の影響を除くため最初の 500 時点を捨てる。
let (mut x, mut previous) = (Vec::with_capacity(t_len), [0.0_f64; 2]);
for t in 0..t_len + 500 {
    let noise = normal.sample(&mut rng).map_err(|e| e.to_string())?;
    let next = phi1 * previous[0] + phi2 * previous[1] + noise;
    previous = [next, previous[0]];
    if t >= 500 {
        x.push(next);
    }
}
let mean = x.iter().sum::<f64>() / t_len as f64;
let p_max = 12_usize;
// 標本自己相関 ρ̂(k)。分母は k によらず Σ (x_t − x̄)²。
let lagged = |k: usize| -> f64 {
    (0..t_len - k)
        .map(|t| (x[t] - mean) * (x[t + k] - mean))
        .sum()
};
let gamma: Vec<f64> = (0..=p_max).map(lagged).collect();
let r: Vec<f64> = gamma.iter().map(|g| g / gamma[0]).collect();
// 独立な経路: Levinson–Durbin の漸化式を直接書き、反射係数 κ_k と E_k を求める。
let (mut a, mut e, mut reflection) = (Vec::<f64>::new(), 1.0_f64, Vec::new());
for k in 1..=p_max {
    let kappa = (r[k] - (0..k - 1).map(|j| a[j] * r[k - 1 - j]).sum::<f64>()) / e;
    let previous = a.clone();
    for j in 0..k - 1 {
        a[j] = previous[j] - kappa * previous[k - 2 - j];
    }
    a.push(kappa);
    e *= 1.0 - kappa * kappa;
    reflection.push(kappa);
}
// 主経路: 次数ごとに R̂_P a = (ρ̂(1), …, ρ̂(P)) をワンショット関数で解く。
let (mut pacf, mut route_difference, mut phi_hat) = (Vec::new(), 0.0_f64, [0.0_f64; 2]);
for p in 1..=p_max {
    let matrix = StructuredMatrixView::toeplitz(&r[..p], &r[..p]).map_err(|e| e.to_string())?;
    let coefficients = solve_structured(matrix, &r[1..=p]).map_err(|e| e.to_string())?;
    let c = coefficients.as_slice();
    if p == 2 {
        phi_hat = [c[0], c[1]];
    }
    route_difference = route_difference.max((c[p - 1] - reflection[p - 1]).abs());
    pacf.push([p as f64, c[p - 1]]);
}
let standard_error = ((1.0 - phi2 * phi2) / t_len as f64).sqrt();
let band = 1.96 / (t_len as f64).sqrt();
let outside = pacf[2..].iter().filter(|p| p[1].abs() > band).count();
let estimate_row = |name, estimate: f64, truth: f64| {
    let z = (estimate - truth) / standard_error;
    (name, estimate, truth, estimate - truth, standard_error, z)
};
let fixed4 = serde_json::json!({ "fractionDigits": 4 });
let fixed2 = serde_json::json!({ "fractionDigits": 2 });
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let estimate_columns = serde_json::json!([
    { "key": "0", "label": "係数" },
    { "key": "1", "label": "推定値 [-]", "type": "number", "format": fixed4 },
    { "key": "2", "label": "真の値 [-]", "type": "number", "format": fixed4 },
    { "key": "3", "label": "差 [-]", "type": "number", "format": fixed4 },
    { "key": "4", "label": "標準誤差 √((1−φ₂²)/T) [-]", "type": "number", "format": fixed4 },
    { "key": "5", "label": "差 / 標準誤差 [-]", "type": "number", "format": fixed2 }
]);
emit_table_with_columns!(
    estimate_columns,
    vec![
        estimate_row("φ₁", phi_hat[0], phi1),
        estimate_row("φ₂", phi_hat[1], phi2)
    ],
    metadata = serde_json::json!({ "id": "estimates" })
);
let check_columns = serde_json::json!([
    { "key": "0", "label": "二経路の α(P) の差の最大 [-]", "type": "number", "format": sci2 },
    { "key": "1", "label": "P ≥ 3 で帯を超えた次数 [次数]", "type": "integer" },
    { "key": "2", "label": "P ≥ 3 の次数 [次数]", "type": "integer" },
    { "key": "3", "label": "E_12（推定）[-]", "type": "number", "format": fixed4 },
    { "key": "4", "label": "σ²/γ(0)（理論）[-]", "type": "number", "format": fixed4 }
]);
emit_table_with_columns!(
    check_columns,
    vec![(
        route_difference,
        outside,
        p_max - 2,
        e,
        variance_ratio(phi1, phi2)
    )],
    metadata = serde_json::json!({ "id": "checks" })
);
emit_line_chart!(
    &vec![serde_json::json!({ "name": "推定した α(P)", "points": pacf })],
    options = &serde_json::json!({
        "xLabel": "次数 P [-]",
        "yLabel": "α(P) [-]",
        "yMin": -1.0,
        "yMax": 1.0,
        "annotations": [
            { "kind": "range", "axis": "y", "from": -band, "to": band, "label": "±1.96/√T" }
        ]
    })
);
```

既定の $T = 2000$ 時点、シード 7 では $(\hat\phi_1, \hat\phi_2) = (0.8233, -0.6414)$ で、真の値との差は標準誤差 0.0172 の 1.36 倍と 0.08 倍である。
二つの経路で求めた偏自己相関は $6 \times 10^{-17}$ の差で一致する。
次数 3 以上の推定値は 10 個中 1 個が $\pm 1.96/\sqrt{T}$ の帯を超え、5% の水準で期待される程度の数である。
$E_{12}$ の推定値は 0.438 で、理論値 0.450 に近い。
$T$ を 100、1000、20000 時点と増やすと、標準誤差は 0.077、0.024、0.0054 と $1/\sqrt{T}$ に比例して縮み、$\hat\phi_1$ の差も 0.050、0.033、0.0039 と小さくなる。
シードを変えると推定値は標準誤差の程度で動き、シード 1 と 2 では $\hat\phi_1$ の差が標準誤差の 0.68 倍と −1.20 倍になる。

$r = 0.99$、$\theta = 5^\circ$ では、$T = 20000$ 時点でも係数の差が標準誤差 0.0014 の 15 倍になり、帯を超える次数も 10 個中 3 個に増える。
$E_{12}$ の推定値 $6.1 \times 10^{-4}$ も、理論値 $3.0 \times 10^{-4}$ の 2 倍になる。
これは、標本自己相関の分母を $T$ にそろえると、相関が長く続く過程では大きなラグの値が系統的に小さくなり、条件の悪い $R_P$ がその偏りを拡大するためである。
二経路の差は $1.3 \times 10^{-12}$ に増えるが偏りよりずっと小さいので、この偏りは解法ではなく推定量の性質から来る。
根が単位円に近い過程では、Yule–Walker 推定より条件付き最小二乗推定や Burg 法の偏りが小さいことが知られている（Tjøstheim と Paulsen, 1983）。
SciOxide は AR モデルの推定法として Burg 法を提供しない。
条件付き最小二乗推定は遅れた値 $(x_{t-1}, x_{t-2})$ を行に並べた行列と $x_t$ の列で、ワンショット関数 `least_squares` を解けば求められる。

## まとめ

AR モデルの係数は自己相関の対称正定値な Toeplitz 方程式で決まり、`StructuredSolvePlan` は Levinson–Durbin の漸化式で $O(P^2)$ 回の演算で解く。
レポートの終了理由と後退誤差を読むときは Plan の `solve_into` を、解だけが要るときはワンショット関数 `solve_structured` を使う。
理論的な自己相関を使うと AR(2) の係数は丸め誤差の範囲で復元され、偏自己相関は次数 3 以上で 0 になり、予測誤差の分散 $E_P$ は $\sigma^2/\gamma(0)$ に一致する。
$R_P$ の条件数は次数によらずスペクトル密度の最大と最小の比で抑えられ、根が単位円に近いと大きくなり、後退誤差が小さいままでも係数の前進誤差が増える。
標本自己相関から推定した係数は標準誤差 $\sqrt{(1-\phi_2^2)/T}$ の程度でばらつくが、根が単位円に近い過程では偏りが標準誤差を大きく超えるので、条件付き最小二乗推定を `least_squares` で求めて比べる。
