初期値問題では $y(t_0)$ がすべて与えられ、時間方向に一刻みずつ進める。
2 点境界値問題（boundary value problem, BVP）では条件が区間 $[a, b]$ の両端に分かれ、未知パラメータ $p$ を含むこともある。

$$
y'(x) = f(x, y(x), p), \qquad g\bigl(y(a), y(b), p\bigr) = 0, \qquad a \le x \le b
$$

$y$ は $n$ 成分、$p$ は $k$ 個の未知パラメータで、境界条件 $g$ は $n + k$ 本でなければならない。
$x$ は実数で、状態とパラメータには複素数も使える。
複素数の場合、ヤコビ行列を複素線形として扱うので、$f$ と $g$ は正則でなければならない。

`scioxide-ode` は区間全体を同時に解く選点法（collocation）を `BvpPlan` とワンショット関数 `solve_bvp` で提供する。
左端の未知の初期値を求根で決める射撃法（shooting）は提供しない。
射撃法は解が指数的に増える問題で初期値の誤差を拡大する。
必要なら初期値問題の積分法オブジェクトと scioxide-rootfind を組み合わせて自分で構成する。

## 3 段の Lobatto IIIA 選点方程式

節点 $a = x_0 < x_1 < \dots < x_{m-1} = b$ の値 $y_j$ と未知パラメータ $p$ をまとめた $mn + k$ 個の未知数を考える。
各区間 $[x_j, x_{j+1}]$（幅 $h_j$）では、両端の値 $y_j, y_{j+1}$ と傾き $f_j = f(x_j, y_j, p)$、$f_{j+1}$ を通る 3 次の Hermite 多項式 $u(x)$ を使う。
$u$ は区間の境目で値と 1 階導関数が連続（$C^1$）になる。
$u$ の区間中点の値は

$$
y_{j+1/2} = \frac{y_j + y_{j+1}}{2} - \frac{h_j}{8}\,(f_{j+1} - f_j)
$$

で、ここでの傾きを $f_{j+1/2} = f(x_j + h_j/2,\ y_{j+1/2},\ p)$ とする。
選点方程式は Simpson 則の形

$$
\frac{y_{j+1} - y_j}{h_j} - \frac{f_j + 4 f_{j+1/2} + f_{j+1}}{6} = 0, \qquad j = 0, \dots, m-2
$$

である。
これは両端と中点の 3 点で $u' = f$ を課すことと同じで、3 段の Lobatto IIIA 法にあたる。
$(m-1)n$ 本の選点方程式と $n+k$ 本の境界条件を合わせると、方程式の数は未知数の数 $mn + k$ に等しい。
滑らかな解に対して、節点での誤差は $O(h^4)$（4 次）である。
解は節点の値と傾きの $C^1$ の 3 次 Hermite 補間で、`BvpSolution::evaluate_into(x, &mut y)` が区間 $[a, b]$ の任意の点の値を、`evaluate_with_derivative_into` が値と導関数を返す。
節点では保存した値と傾きをそのまま返し、1 点の評価は $m$ 個の節点に対して $O(\log m + n)$ の手間である。

## Newton 法と線形解法

この $mn + k$ 本の非線形方程式を、直線探索（後戻り）付きの減衰 Newton 法で解く。
内側の Newton 法は scioxide-rootfind の Newton–Krylov 法で、選点方程式の残差を許容誤差の 1/1000 を単位にした尺度で、境界条件の残差を境界の許容誤差の 1/1000 を単位にした尺度で正規化して止める。
制御は `BvpNewtonOptions` で与える。
既定値は scioxide-rootfind の `NewtonKrylovOptions` と同じで、節点の列ごとに Newton 反復 100 回まで、Armijo 定数 $10^{-4}$、最小の相対刻み $\varepsilon^{2/3}$（$\varepsilon$ は機械イプシロン）、非単調な直線探索の重み 0.85、Krylov の補正には Eisenstat–Walker の打ち切り条件を使う。
`with_max_iterations`、`with_backtracking`、`with_nonmonotone`、`with_forcing` で変え、`BvpOptions::with_newton` で渡す。

Newton の補正方程式の線形解法は `BvpBackend` で選ぶ。
選んだ解法だけを使い、別の解法に切り替えることはない。

| `BvpBackend` | 補正方程式の解き方 | メモリと向く場合 |
|---|---|---|
| `Sparse { limits }`（既定） | 組み立てたブロック疎の行列の、ピボット選択付きの疎 LU 分解 | メモリは節点数に比例する。`limits: None` ならフィルとメモリの上限を節点の列ごとに決める |
| `Dense` | 組み立てた密行列の、部分ピボット選択付きの LU 分解 | メモリは $(mn + k)^2$ に比例するので、節点と次元が少ない問題に限る |
| `Krylov { iterations, restart }` | 行列を組み立てない再始動 GMRES | 行列を格納しない。前処理がないので、節点が増えると反復が足りなくなりやすい |

系は `BvpSystem` を実装し、次元 `dimension`、未知パラメータの数 `parameter_dimension`（既定は 0）、右辺 $f(x, y, p)$ を書く `rhs`、$n + k$ 個の境界条件の残差 $g(y(a), y(b), p)$ を書く `boundary` を与える。
ヤコビ行列は `BvpProblem` で選ぶ。
`BvpProblem::analytic(&system)` は `BvpJacobian` の局所ヤコビ行列（右辺の $\partial f/\partial y$、$\partial f/\partial p$ と境界条件の $\partial g/\partial y(a)$、$\partial g/\partial y(b)$、$\partial g/\partial p$。
行優先）を使う。
`BvpProblem::numerical(&system)` は前進差分で近似し、直接法では局所のブロックごとに、`Krylov` では選点方程式全体のヤコビ行列とベクトルの積を差分する。

## 残差による誤差の推定と節点の追加

解いた後、$u$ が微分方程式をどれだけ満たすかを残差 $r(x) = u'(x) - f(x, u(x), p)$ で調べる。
成分 $i$ ごとに $\tilde r_i = r_i / (\varepsilon_{\mathrm{abs}} + \varepsilon_{\mathrm{rel}} |f_i(x, u(x), p)|)$ と正規化し、各区間で

$$
\left( \frac{1}{h_j} \int_{x_j}^{x_{j+1}} \lVert \tilde r(x) \rVert_2^2 \, dx \right)^{1/2} \le 1
$$

を要求する。
積分は 5 点の Lobatto 則で求める。
5 点のうち両端では選点方程式により $u' = f$ なので、右辺を評価するのは中点と中点から $\pm\sqrt{3/7}\,h_j/2$ の 3 点である。
1 回の残差の評価は $m$ 個の節点に対して右辺を $4m - 3$ 回、境界条件を 1 回呼ぶ。
この区間の残差の最大がレポートの `max_residual()` で、境界条件の残差 $\max_i |g_i|$ が `boundary_residual()` である。

次の条件がすべて成り立てば、終了状態は `BvpTermination::Converged` である。

- すべての区間で正規化残差が 1 以下（`max_residual() <= 1`）である。
- 境界条件の残差が境界の許容誤差以下である。
  境界の許容誤差は絶対値だけで与え、相対の部分は 0 でなければならない。
- 特異項を使う場合、$S\,y(a)$ の残差も境界の許容誤差以下である。

満たさない場合は、正規化残差が 1 を超えたすべての区間を二分し、新しい節点の列で現在の解 $u$ から解き直す。
許容誤差の既定は微分方程式で $\varepsilon_{\mathrm{abs}} = \varepsilon_{\mathrm{rel}} = 10^{-3}$、境界で $10^{-3}$、細分化は最大 20 回で、`BvpOptions::with_tolerances` と `with_refinements` で変える。

制御するのは残差で、誤差 $u - y$ ではない。
条件のよい問題では二つは近いが、レポートの残差は誤差の上限ではない。
解析解、保存量、節点を増やした解との比較で確かめる。

## Bratu 問題の二つの解

燃焼の熱暴走（Gelfand 問題）の 1 次元モデルである Bratu 問題

$$
u'' + \lambda e^{u} = 0, \qquad u(0) = u(1) = 0
$$

は、$y = (u, u')$ とおくと $n = 2$ の 1 階系になる。
$\lambda > 0$ は発熱の強さを表す無次元のパラメータで、$u$ は無次元の温度である。
解析解は

$$
u(x) = 2\ln\cosh\frac{\theta}{4} - 2\ln\cosh\frac{(x - 1/2)\,\theta}{2}, \qquad \theta = \sqrt{2\lambda}\,\cosh\frac{\theta}{4}
$$

で、$\theta$ の方程式は $0 < \lambda < \lambda_c \approx 3.513831$ のとき二つの根を持つ。
したがって境界値問題にも、$u$ の小さい下側の解と大きい上側の解の二つがある。
$\lambda = 1$ では $\theta = 1.517165$（$u(1/2) = 0.140539$）と $\theta = 10.938703$（$u(1/2) = 4.091467$）である。
scioxide-rootfind の章は同じ問題の差分近似を[擬弧長継続](oxref:rootfind-bratu-branch)でたどり、同じ $\lambda = 1$ の二つの解を求める（[継続法による解の枝の追跡](../../../scioxide-rootfind/algorithms/continuation-and-deflation/)）。

次のブロックは二つのセルが共有する定義である。
`Bratu { lambda, slope }` は `slope` が `None` なら $\lambda$ を与えた系、`Some(s)` なら $\lambda$ を未知パラメータ $p_0$ にして境界条件 $u'(0) = s$ を加えた系である。
`BvpJacobian` の実装は解析的な局所ヤコビ行列を返す。
`bratu_exact` は解析解、`reference_root` は参照値を求める Brent 法である。

```rust
//| id: ode-bratu-model
//| kind: definitions
//| title: Bratu 問題の系・局所ヤコビ行列・参照値
//| crates: [scioxide-core, scioxide-ode, scioxide-rootfind]
use scioxide_core::{
    SciOxideError, Interval, RealScalar, ResidualTolerance, SolveContext, StepTolerance,
};
use scioxide_linalg::Matrix;
use scioxide_ode::{BvpJacobian, BvpSolution, BvpSystem};
use scioxide_rootfind::{Brent, ScalarFn, ScalarRootOptions, ScalarRootSolver};

/// Bratu 問題 u'' + λeᵘ = 0、u(0) = u(1) = 0 を y = (u, u') の 1 階系にしたもの。
/// slope が Some(s) なら λ を未知パラメータ p[0] とし、3 本目の境界条件 u'(0) = s を加える。
pub(crate) struct Bratu {
    pub(crate) lambda: f64,
    pub(crate) slope: Option<f64>,
}
impl Bratu {
    fn lambda(&self, p: &[f64]) -> f64 {
        if self.slope.is_some() {
            p[0]
        } else {
            self.lambda
        }
    }
}
impl BvpSystem<f64> for Bratu {
    fn dimension(&self) -> usize {
        2
    }
    fn parameter_dimension(&self) -> usize {
        usize::from(self.slope.is_some())
    }
    fn rhs(
        &self,
        _: f64,
        y: &[f64],
        p: &[f64],
        out: &mut [f64],
        _: &mut SolveContext<'_, '_>,
    ) -> Result<(), SciOxideError> {
        out[0] = y[1];
        out[1] = -self.lambda(p) * scioxide_core::RealScalar::exp(y[0]);
        Ok(())
    }
    fn boundary(
        &self,
        a: &[f64],
        b: &[f64],
        _: &[f64],
        out: &mut [f64],
        _: &mut SolveContext<'_, '_>,
    ) -> Result<(), SciOxideError> {
        out[0] = a[0];
        out[1] = b[0];
        if let Some(s) = self.slope {
            out[2] = a[1] - s;
        }
        Ok(())
    }
}
/// 局所ヤコビ行列は行優先。境界条件の行 0 は y(a) の u、行 1 は y(b) の u、行 2 は y(a) の u' に依存する。
impl BvpJacobian<f64> for Bratu {
    fn rhs_jacobian(
        &self,
        _: f64,
        y: &[f64],
        p: &[f64],
        state: &mut [f64],
        parameters: &mut [f64],
        _: &mut SolveContext<'_, '_>,
    ) -> Result<(), SciOxideError> {
        let e = scioxide_core::RealScalar::exp(y[0]);
        state.copy_from_slice(&[0.0, 1.0, -self.lambda(p) * e, 0.0]);
        if self.slope.is_some() {
            parameters.copy_from_slice(&[0.0, -e]);
        }
        Ok(())
    }
    fn boundary_jacobian(
        &self,
        _: &[f64],
        _: &[f64],
        _: &[f64],
        a: &mut [f64],
        b: &mut [f64],
        parameters: &mut [f64],
        _: &mut SolveContext<'_, '_>,
    ) -> Result<(), SciOxideError> {
        let rows = a.len() / 2;
        a.fill(0.0);
        b.fill(0.0);
        parameters.fill(0.0);
        a[0] = 1.0;
        b[2] = 1.0;
        if rows == 3 {
            a[5] = 1.0;
        }
        Ok(())
    }
}
/// 解析解 u(x) = 2 ln cosh(θ/4) − 2 ln cosh((x − 1/2)θ/2)（f64 の固有メソッドによる参照値）。
pub(crate) fn bratu_exact(x: f64, theta: f64) -> f64 {
    2.0 * (theta / 4.0).cosh().ln() - 2.0 * ((x - 0.5) * theta / 2.0).cosh().ln()
}
/// 初期推定 u = A sin(πx), u' = Aπ cos(πx) を、節点ごとに 1 行ずつ並べる。
pub(crate) fn sine_guess(mesh: &[f64], amplitude: f64) -> Result<Matrix<f64>, SciOxideError> {
    let pi = core::f64::consts::PI;
    let values = mesh.iter().flat_map(|&x| {
        let (s, c) = RealScalar::sin_cos(pi * x);
        [amplitude * s, amplitude * pi * c]
    });
    Matrix::from_vec(mesh.len(), 2, values.collect())
}
/// 表の 1 行: (解の枝, θ, u(1/2), max|u − u解析|, 最大正規化残差, 節点数, 細分化, 終了状態)。
pub(crate) type Row = (&'static str, f64, f64, f64, f64, usize, usize, String);
/// 解を 101 点で解析解と比べ、表の行、Converged かどうか、描く点を返す。
pub(crate) fn summarize(
    branch: &'static str,
    theta: f64,
    solution: &BvpSolution<f64>,
) -> Result<(Row, bool, Vec<[f64; 2]>), SciOxideError> {
    let (mut y, mut points, mut worst) = ([0.0; 2], Vec::new(), 0.0_f64);
    for x in (0..=100).map(|i| f64::from(i) / 100.0) {
        solution.evaluate_into(x, &mut y)?;
        worst = worst.max((y[0] - bratu_exact(x, theta)).abs());
        points.push([x, y[0]]);
    }
    solution.evaluate_into(0.5, &mut y)?;
    let report = solution.report().ok_or_else(|| {
        SciOxideError::invalid_input(
            scioxide_core::argument!("solution"),
            scioxide_core::InvalidInputReason::Empty,
            "no report",
        )
    })?;
    let status = format!("{:?}", report.termination());
    let residual = report.max_residual();
    let row = (
        branch,
        theta,
        y[0],
        worst,
        residual,
        report.nodes(),
        report.refinements(),
        status,
    );
    Ok((row, report.is_success(), points))
}
/// 参照値の求根: 区間 [lo, hi] で g の零点を Brent 法で 10⁻¹⁵ まで求める。
pub(crate) fn reference_root(
    g: impl Fn(f64) -> f64,
    lo: f64,
    hi: f64,
) -> Result<f64, SciOxideError> {
    let options = ScalarRootOptions::default()
        .with_residual_tolerance(ResidualTolerance::new(1e-15, 0.0)?)
        .with_step_tolerance(StepTolerance::new(1e-15, 1e-15)?);
    let f = ScalarFn::new(|t: f64| Ok(g(t)));
    let result = Brent.solve(&f, Interval::new(lo, hi)?, &options)?;
    Ok(result.point())
}
```

次のセルは同じ Plan（`BvpPlan`）を初期推定 $u_0 = A \sin \pi x$ の振幅 $A = 0.1$ と $A = 4$ で 2 回使い、解析的なヤコビ行列で二つの解を求める。
節点の上限は 400、作業領域の上限は 64 MiB、線形解法は既定の疎 LU である。
$\theta$ の参照値を Brent 法で求め、計算した解を 101 点で解析解と比べる。
最後の行は下側の解をワンショット関数 `solve_bvp`（既定の許容誤差 $10^{-3}$、差分のヤコビ行列）で求めた結果である。
$\lambda$ を $\lambda_c$ に近づけると二つの解が近づき、Newton 法のヤコビ行列は特異に近づく。

```rust
//| id: ode-bratu-collocation
//| ref: ode-bratu-collocation

//|   tolerance_exponent: {"type":"range","label":"許容誤差 10^q の指数 q","description":"微分方程式の残差の絶対・相対の許容誤差と、境界条件の絶対許容誤差。","min":-9,"max":-3,"step":1,"value":-6}
//| cases:
//|   - {"id":"tight","label":"q = −9","description":"上側の解は節点の上限 400 に達して NodeLimit で止まる。","inputs":{"tolerance_exponent":-9}}
//|   - {"id":"small-lambda","label":"λ = 0.2","description":"振幅 4 の初期推定も下側の解に収束する。","inputs":{"lambda":0.2}}
//|   - {"id":"near-fold","label":"λ = 3.4","description":"二つの解の u(1/2) が近づく。","inputs":{"lambda":3.4}}

//|       - {"artifact":"branches","path":"/rows/1/2","approx":{"value":4.091467,"atol":1e-6}}
//|       - {"artifact":"branches","path":"/rows/0/3","range":{"max":1e-7}}
//|       - {"artifact":"branches","path":"/rows/1/3","range":{"max":1e-7}}
//|       - {"artifact":"branches","path":"/rows/2/3","range":{"max":1e-6}}
//|       - {"path":"/outputs/2/state","equals":"satisfied"}
//|   - case: tight
//|     expect:
//|       - {"artifact":"branches","path":"/rows/1/7","equals":"NodeLimit"}
//|       - {"artifact":"branches","path":"/rows/0/3","range":{"max":1e-11}}
//|       - {"path":"/outputs/2/state","equals":"partial"}
//|   - case: small-lambda
//|     expect:
//|       - {"artifact":"branches","path":"/rows/1/3","range":{"min":1}}
//|   - case: near-fold
//|     expect:
//|       - {"artifact":"branches","path":"/rows/0/2","approx":{"value":0.909143,"atol":1e-5}}
//|       - {"artifact":"branches","path":"/rows/1/2","approx":{"value":1.515097,"atol":1e-5}}
use scioxide_core::{RealScalar, ResidualTolerance};
use scioxide_ode::{BvpOptions, BvpPlan, BvpProblem, BvpSystem, solve_bvp};

// 参照値: θ = √(2λ) cosh(θ/4) の二根を、両辺の差が最大になる θ* で区間を分けて求める。
let g = |t: f64| t - (2.0 * lambda).sqrt() * (t / 4.0).cosh();
let peak = 4.0 * (4.0 / (2.0 * lambda).sqrt()).asinh();
let lower = reference_root(g, 0.0, peak).map_err(|e| e.to_string())?;
let upper = reference_root(g, peak, 40.0).map_err(|e| e.to_string())?;
let tol = 10.0_f64.powf(tolerance_exponent);
let options = BvpOptions::new()
    .with_max_nodes(400)
    .with_max_workspace_bytes(64 << 20)
    .with_tolerances(
        ResidualTolerance::new(tol, tol).map_err(|e| e.to_string())?,
        ResidualTolerance::new(tol, 0.0).map_err(|e| e.to_string())?,
    );
let system = Bratu {
    lambda,
```

## 未知パラメータで折り返し点を越える

$\lambda$ を与えて $u$ を求める限り、$\lambda > \lambda_c$ には解がなく、$\lambda_c$ の近くでは Newton 法のヤコビ行列が特異に近づく。
そこで $\lambda$ を未知パラメータ（$k = 1$）とし、代わりに左端の傾き $u'(0) = s$ を 3 本目の境界条件として与える。
解析解では $s = \theta \tanh(\theta/4)$ が $\theta$ について単調に増えるので、$s$ を決めれば解の枝の上の点がただ一つに決まり、折り返し点でも方程式は特異にならない。
scioxide-rootfind の擬弧長継続が弧長の条件を方程式に加えるのと同じ考え方である。

次のセルは $s$ を最大値まで 16 点で掃引し、`parameter_dimension()` が 1 を返す系を `BvpProblem::numerical`（差分のヤコビ行列）で解く。
Plan は状態の次元と未知パラメータの数だけで決まるので、$s$ の異なる 16 個の系に同じ `BvpPlan` を使う。
未知パラメータの初期推定は常に $\lambda_0 = 1$ とし、求めた $\lambda$（`BvpSolution::parameters()`）を解析解の $\lambda = \theta^2 / (2\cosh^2(\theta/4))$ と比べる。

```rust

//| title: 傾きを与えて未知の λ を求め Bratu 問題の解の枝をたどる
//| run: button

//| inputs:
//|   max_slope: {"type":"range","label":"掃引する傾き s = u'(0) の最大値 [-]","description":"大きいほど上側の解の枝の奥まで進む。","min":4,"max":16,"step":1,"value":10}
//| cases:
//|   - {"id":"fold","label":"最大の傾き 4","description":"最後の点がちょうど折り返し点になる。","inputs":{"max_slope":4}}
//|   - {"id":"deep","label":"最大の傾き 16","description":"上側の解の枝の奥まで進む。","inputs":{"max_slope":16}}

//|   - case: default
//|     expect:

//|     expect:
//|       - {"artifact":"sweep","path":"/rows/15/3","range":{"max":1e-7}}
//|       - {"path":"/outputs/2/state","equals":"satisfied"}

    .with_max_nodes(400)
    .with_max_workspace_bytes(64 << 20)
    .with_tolerances(
        ResidualTolerance::new(1e-6, 1e-6).map_err(|e| e.to_string())?,
        ResidualTolerance::new(1e-6, 0.0).map_err(|e| e.to_string())?,

        .iter()

        .solve(&BvpProblem::numerical(&system), guess.view(), &[1.0])

        .evaluate_into(0.5, &mut y)
        .map_err(|e| e.to_string())?;
    // 参照値: θ tanh(θ/4) = s を解き、λ = θ²/(2 cosh²(θ/4)) とする。

        [
            t * t / (2.0 * (t / 4.0).cosh().powi(2)),

    })
    .collect();

    serde_json::json!({ "name": "解析解の枝", "points": branch, "style": dashed }),
    serde_json::json!({ "name": "選点法（未知の λ）", "points": computed, "kind": "scatter" }),
];

    serde_json::json!({ "kind": "line", "axis": "x", "value": 3.5138307, "label": "λc" });
emit_line_chart!(

    options = &serde_json::json!({
        "xLabel": "パラメータ λ [-]",
        "yLabel": "中点の値 u(1/2) [-]",
        "xMin": 0.0,

    })

} else {

        .explanation("その点の λ は許容誤差を満たしていない推定値である。")
```

## 端点の特異項

円柱や球の動径方向の方程式は、左端 $x = a$ で $1/(x - a)$ の係数を持つ。
`BvpPlan::with_singular(S)` は右辺を

$$
y' = \frac{S\,y}{x - a} + f(x, y, p)
$$

とし、定数の $n \times n$ 行列 $S$ の項を加える。
解が $C^1$ で $S\,y(a) = 0$ を満たし、境界条件がそれと矛盾しないことを仮定する。
$x = a$ での導関数は $y'(a) = (I - S)^{+} f(a, y(a), p)$（$^{+}$ は擬逆行列）とし、各解で $y(a)$ を $S$ の零空間へ射影する。
レポートの `regularity_residual()` は $\max|S\,y(a)|$ である。
`with_singular` は $S$ と $I - S$ の擬逆行列を特異値分解で前計算し、$f(a, y(a), p)$ が $I - S$ の値域にない場合（境界の許容誤差で判定）は解くときに `InvalidInput` を返す。

例として、恒星の構造を表す Lane–Emden 方程式（指数 5）

$$
w'' + \frac{2}{x}\,w' + w^5 = 0, \qquad w'(0) = 0, \qquad w(1) = \frac{\sqrt 3}{2}
$$

を考える（Shampine 2003）。
厳密解は $w = (1 + x^2/3)^{-1/2}$ である。
$y = (w, w')$ とおくと、$S = \begin{bmatrix} 0 & 0 \\ 0 & -2 \end{bmatrix}$、$f = (w', -w^5)$ で、$S\,y(0) = (0, -2w'(0))$ が 0 になる条件は境界条件 $w'(0) = 0$ と一致する。

次のセルは右辺と境界条件をクロージャで与えた `BvpFn` を使い、許容誤差 $10^{-3}$、$10^{-6}$、$10^{-9}$ の 3 つの Plan を同じ `BvpWorkspace` と `BvpSolution` で解く。
`BvpFn::new(dimension, rhs, boundary)` は未知パラメータを持たない系をクロージャから作り、ワンショット関数 `solve_bvp` も内部でこれを使う。
作業領域は `workspace_requirements` の見積もり `BvpRequirements` で `try_reserve` し、細分化で足りなくなった分は `solve_into` が大きくする。
作業領域の上限は 64 MiB、節点の上限は 2000 で、線形解法と細分化の回数の上限を入力で選ぶ。

```rust
//| id: ode-lane-emden-singular
//| ref: ode-lane-emden-singular
//| title: 特異項を持つ Lane–Emden 方程式を三つの線形解法で解く
//| run: button
//| crates: [scioxide-core, scioxide-linalg, scioxide-ode]
//| inputs:
//|   backend: {"type":"select","label":"Newton の補正の線形解法","options":["Sparse","Dense","Krylov"],"value":"Sparse"}
//|   refinements: {"type":"range","label":"細分化の回数の上限 [回]","description":"BvpOptions::with_refinements。","min":2,"max":20,"step":1,"value":20}
//| cases:
//|   - {"id":"dense","label":"Dense","description":"密行列のメモリが上限 64 MiB を超え、MemoryLimit で止まる。","inputs":{"backend":"Dense"}}
//|   - {"id":"krylov","label":"Krylov","description":"前処理のない GMRES が反復の上限で止まり、Newton 法が収束しない。","inputs":{"backend":"Krylov"}}
//|   - {"id":"few-refinements","label":"細分化 2 回","description":"許容誤差 10⁻⁹ は細分化の上限で止まる。","inputs":{"refinements":2}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"emden","path":"/rows/2/1","equals":"Converged"}
//|       - {"artifact":"emden","path":"/rows/2/5","range":{"max":1e-10}}
//|       - {"artifact":"emden","path":"/rows/0/5","range":{"max":1e-5}}
//|       - {"path":"/outputs/1/state","equals":"satisfied"}
//|   - case: dense
//|     expect:
//|       - {"artifact":"emden","path":"/rows/2/1","equals":"MemoryLimit"}
//|       - {"path":"/outputs/1/state","equals":"partial"}
//|   - case: krylov
//|     expect:
//|       - {"artifact":"emden","path":"/rows/0/1","equals":"Converged"}
//|       - {"path":"/outputs/1/state","equals":"failed"}
//|   - case: few-refinements
//|     expect:
//|       - {"artifact":"emden","path":"/rows/2/1","equals":"RefinementLimit"}
//|       - {"path":"/outputs/1/state","equals":"partial"}
use scioxide_core::{Budget, ExecutionContext, ResidualTolerance};
use scioxide_linalg::Matrix;
use scioxide_ode::{
    BvpBackend, BvpFn, BvpOptions, BvpPlan, BvpProblem, BvpSolution, BvpTermination,
    BvpWorkspace,
};

// y = (w, w') として w'' + (2/x)w' + w⁵ = 0。特異項 S y/x の外の部分 f = (w', −w⁵)。
let emden = BvpFn::new(
    2,
    |_x: f64, y: &[f64], dy: &mut [f64]| {
        dy[0] = y[1];
        dy[1] = -scioxide_core::RealScalar::powi(y[0], 5);
        Ok(())
    },
    // 境界条件 w'(0) = 0 と w(1) = √3/2。
    |a: &[f64], b: &[f64], r: &mut [f64]| {
        r[0] = a[1];
        r[1] = b[0] - 0.75_f64.sqrt();
        Ok(())
    },
);
let singular = Matrix::from_rows(&[[0.0, 0.0], [0.0, -2.0]]).map_err(|e| e.to_string())?;
let budget = |n: usize| Budget::try_from(n);
let backend = match backend.as_str() {
    "Dense" => BvpBackend::Dense,
    "Sparse" => BvpBackend::Sparse { limits: None },
    _ => BvpBackend::Krylov {
        iterations: budget(200).map_err(|e| e.to_string())?,
        restart: budget(40).map_err(|e| e.to_string())?,
    },
};
let mesh: Vec<f64> = (0..=10).map(|i| f64::from(i) / 10.0).collect();
let guess = Matrix::from_vec(11, 2, [1.0, 0.0].repeat(11)).map_err(|e| e.to_string())?;
let problem = BvpProblem::numerical(&emden);
// 一つの作業領域と出力を、許容誤差の違う 3 つの Plan で使い回す。
let mut workspace = BvpWorkspace::new();
let mut solution = BvpSolution::new();
let (mut rows, mut last) = (Vec::new(), None);
for tol in [1e-3, 1e-6, 1e-9] {
    let options = BvpOptions::new()
        .with_max_nodes(2000)
        .with_max_workspace_bytes(64 << 20)
        .with_backend(backend)
        .with_refinements(budget(refinements as usize).map_err(|e| e.to_string())?)
        .with_tolerances(
            ResidualTolerance::new(tol, tol).map_err(|e| e.to_string())?,
            ResidualTolerance::new(tol, 0.0).map_err(|e| e.to_string())?,
        );
    let plan = BvpPlan::new(2, 0, &mesh, options)
        .and_then(|plan| plan.with_singular(singular.view()))
        .map_err(|e| e.to_string())?;
    let requirements = plan
        .workspace_requirements(&problem)
        .map_err(|e| e.to_string())?;
    // 初期の節点の列に足りるメモリを確保する。細分化で足りなくなれば solve_into が大きくする。
    workspace
        .try_reserve(&requirements)
        .map_err(|e| e.to_string())?;
    let report = plan
        .solve_into(
            &problem,
            guess.view(),
            &[],
            &mut solution,
            &mut workspace,
            ExecutionContext::sequential(),
        )
        .map_err(|e| e.to_string())?;
    // 独立な検算: 厳密解 w = (1 + x²/3)^(−1/2)（f64 の固有メソッドによる参照値）。
    let mut y = [0.0; 2];
    let mut worst = 0.0_f64;
    for x in (0..=100).map(|i| f64::from(i) / 100.0) {
        solution
            .evaluate_into(x, &mut y)
            .map_err(|e| e.to_string())?;
        worst = worst.max((y[0] - (1.0 + x * x / 3.0).powf(-0.5)).abs());
    }
    last = Some(report.termination());
    let status = format!("{:?}", report.termination());
    let (residual, regularity) = (report.max_residual(), report.regularity_residual());
    let bytes = (requirements.required_bytes(), report.workspace_bytes());
    rows.push((
        tol,
        status,
        report.nodes(),
        residual,
        regularity,
        worst,
        bytes.0,
        bytes.1,
    ));
}
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let columns = serde_json::json!([
    { "key": "0", "label": "許容誤差 [-]", "type": "number", "format": sci2 },
    { "key": "1", "label": "終了状態" },
    { "key": "2", "label": "節点数", "type": "integer" },
    { "key": "3", "label": "最大正規化残差 [-]", "type": "number", "format": sci2 },
    { "key": "4", "label": "max |S y(0)| [-]", "type": "number", "format": sci2 },
    { "key": "5", "label": "max |w − w厳密| [-]", "type": "number", "format": sci2 },
    { "key": "6", "label": "初期の節点での見積もり [B]", "type": "integer" },
    { "key": "7", "label": "終了時の見積もり [B]", "type": "integer" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "emden" })
);
// 最も厳しい許容誤差 10⁻⁹ の終了状態をセルの結論にする。
let termination = last.ok_or("解いていない")?;
let outcome = match termination {
    BvpTermination::Converged => Outcome::satisfied("許容誤差 10⁻⁹ の残差の条件を満たした"),
    BvpTermination::Nonlinear(_) | BvpTermination::BoundaryFailure => {
        Outcome::failed("最後の節点の列で Newton 法が収束しなかった")
            .explanation("返された解は許容誤差を満たさない。別の線形解法を選ぶ。")
    }
    _ => Outcome::partial("上限で細分化が止まった")
        .explanation("返された解は最後の節点の列での推定値である。"),
};
emit_outcome!(outcome.status(format!("{termination:?}")));
```

既定の疎 LU では、3 つの許容誤差がすべて `Converged` で終わり、厳密解との差の最大は $2.5 \times 10^{-7}$（$10^{-3}$、11 節点）、$1.6 \times 10^{-8}$（$10^{-6}$、30 節点）、$1.4 \times 10^{-12}$（$10^{-9}$、302 節点）である。
特異項の条件 $\max|S\,y(0)|$ は射影により 0 になる。
疎 LU のメモリの見積もりは、初期の節点の列でも 33 744 384 B と大きい。
`limits: None` の許容量が作業領域の上限 64 MiB から決まるためで、302 節点でも 38 661 120 B にしか増えない。

- `Dense` では見積もりが未知数の 2 乗で増え、許容誤差 $10^{-9}$ では 161 節点で次の細分化の見積もりが 64 MiB を超えるので、`MemoryLimit` で止まる。
  最大正規化残差は 2.47 で、差の最大は $2.7 \times 10^{-12}$ と小さいが、`Converged` ではない。
- `Krylov` では $10^{-3}$ は収束するが、$10^{-6}$ と $10^{-9}$ では前処理のない GMRES が反復の上限 200 回で止まり、`Nonlinear(LinearFailure(IterationLimit))` で終わる。
  返された解の差は $10^{-8}$ 程度だが、許容誤差を満たした解ではない。
- 細分化の上限を 2 回にすると、$10^{-9}$ は 41 節点で `RefinementLimit` になり、最大正規化残差は 158 である。

## Plan・作業領域・終了状態

`BvpPlan::new(dimension, parameter_dimension, mesh, options)` は系を借用せず、次元、初期の節点の列（2 点以上で狭義単調増加、有限）、設定を検査し、初期の節点の列でメモリの見積もりを上限と比べる。
解くときに問題の `dimension()` と `parameter_dimension()` が Plan と一致するかを確かめ、違えば `InvalidInput` を返す。
Plan は不変で、同じ次元の問題ならどれでも解ける。
初期推定は初期の節点ごとに 1 行、状態の成分ごとに 1 列の `MatrixView` で渡し、未知パラメータの初期推定はスライスで渡す。
解くたびに Plan の初期の節点の列から始める。

`BvpOptions::new()` は節点数と作業領域のバイト数を制限しない設定を返す。
`with_max_nodes` と `with_max_workspace_bytes` で上限を与える。
バイト数は線形解法ごとのメモリの見積もりの上限で、確保した量ではない。
`Dense` の見積もりは未知数 $mn + k$ の 2 乗に比例し、`Sparse { limits: None }` の見積もりには、作業領域の上限から決まる疎 LU の許容量（上限の 1/4 の 2 倍）が入る。
細分化のたびに見積もりを上限と比べ、超える場合は細分化をやめて `MemoryLimit` で止まる。

API は 3 つある。

- `solve_bvp(rhs, boundary, mesh, guess)` はワンショット関数で、クロージャを `BvpFn` にし、既定の設定（許容誤差 $10^{-3}$、疎 LU、差分のヤコビ行列）で解く。
  `Converged` 以外の終了状態はエラー（`ConvergenceFailure`、節点とメモリの上限は `ResourceLimit`）になる。
- `BvpPlan::solve(&problem, guess, &parameters)` は作業領域と出力を新しく確保し、逐次のコンテキストで解いて `BvpSolution` を返す。
  終了状態が `Converged` でなくても解を返すので、`report()` で確かめる。
- `BvpPlan::solve_into(&problem, guess, &parameters, &mut solution, &mut workspace, scope)` は作業領域と出力を再利用する。
  `BvpWorkspace` は `BvpPlan::workspace(&problem)`、または `BvpWorkspace::new()` と `try_reserve(&requirements)` で作り、複数の Plan と問題で使える。
  `check(&requirements)` はメモリが足りるかを答える。
  最後の節点の列ですでに解いた作業領域と十分な容量の出力を渡せば、メモリを確保しない。

`solve_into` は、いずれかの節点の列で解が得られた場合は、終了状態が `Converged` でなくても `Ok` とレポートを返す。
レポート `BvpReport` は終了状態 `termination()`、`is_success()`、細分化の回数 `refinements()`、節点数 `nodes()`、`max_residual()`、`boundary_residual()`、`regularity_residual()`、評価の回数 `counts()` と `accounting()`、終了時のメモリの見積もり `workspace_bytes()` を持ち、`BvpSolution::report()` にも保存される。
エラーのとき出力の解は変わらず、作業領域の `last_attempt()` が失敗した試行の回数を記録する。
評価の上限、取り消し、期限で節点の列の評価の前に止まった場合も、終了状態ではなくエラーになる。
右辺と境界条件は逐次に評価される。

| `BvpTermination` | 意味 | 解の扱い |
|---|---|---|
| `Converged` | 残差、境界条件、特異項の条件をすべて満たした | 使える |
| `NodeLimit` | 次の細分化で節点数が `max_nodes` を超える | 最後の節点の列での推定値 |
| `MemoryLimit` | 次の細分化でメモリの見積もりが `max_workspace_bytes` を超える | 同上 |
| `RefinementLimit` | 細分化の回数の上限に達した | 同上 |
| `ResourceLimit(kind)` | 外側の求解の計算回数の上限が次の細分化を許さない | 同上 |
| `MeshStagnation` | 二分する区間の中点が浮動小数点数で表せない | 同上 |
| `BoundaryFailure` | すべての区間が残差の条件を満たすのに、境界条件の残差が許容誤差を超える。細分化では改善しない | 許容誤差を満たさない |
| `Nonlinear(reason)` | その節点の列で Newton 法が収束しなかった（`reason` は scioxide-rootfind の `RootTermination`） | 許容誤差を満たさない |

`Converged` 以外の解も確かめたうえで次の計算の初期推定に使える。
解の枝がどれかは終了状態からは分からないので、参照値や別の初期推定の解と比べて判断する。

## まとめ

2 点境界値問題は両端の条件と選点方程式を合わせた未知数の方程式として解く。
`BvpPlan` は 3 段の Lobatto IIIA（4 次）の選点方程式を Newton 法で解き、区間ごとの正規化残差が 1 を超えた区間を二分して解き直す。
結果は `termination()` が `Converged` のときだけ許容誤差を満たし、`max_residual()` と `boundary_residual()` は誤差の上限ではなく残差なので、解析解や節点を増やした解と比べて確かめる。
解が複数ある問題では初期推定で収束先が変わり、折り返し点の近くでは $\lambda$ を未知パラメータにして別の量を与えると解の枝を越えて追跡できる。
節点が多い問題では既定の疎 LU を使い、`Dense` はメモリが、前処理のない `Krylov` は反復の上限が先に問題になる。

求根による解の枝の追跡は [scioxide-rootfind の継続法とデフレーション](../../../scioxide-rootfind/algorithms/continuation-and-deflation/)、内側の Newton 法の仕様は [Newton–Krylov 法](../../../scioxide-rootfind/algorithms/matrix-free-newton-krylov/)、解く手順と途中までの結果の一般的な規則は [解く手順と結果の仕様](oxref:ode-termination-and-partial-results)、型の一覧は [API ガイド](../../api/)にある。
