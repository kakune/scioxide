数値積分の結果を評価するときは、誤差の次数と安定性を分けて考える。
誤差の次数は、刻み幅 $h$ を小さくしたときに誤差が減る速さである。
安定性は、刻み幅を固定して長く積分したときに誤差が増えないかを表す。
次数の高い方式でも、刻み幅が安定領域の外にあれば数値解は指数的に発散する。
発散しない方式でも、局所誤差が大きければ真の解から離れる。

このページでは、局所打ち切り誤差が大域誤差へ伝わる仕組み、刻みの半減による次数の測り方、Dahlquist の線形安定性の理論、時定数の離れた成分による剛性を扱う。
記号は次のとおりとする。
初期値問題は $y'(t) = f(t, y(t))$、$y(t_0) = y_0 \in \mathbb{R}^d$ で、$t_n$ は $n$ 番目の刻みの終点、$y_n$ はそこでの数値解、$h = t_{n+1} - t_n$ は刻み幅である。

## 局所打ち切り誤差と大域誤差

### 局所打ち切り誤差

時刻 $t_n$ の真の解 $y(t_n)$ から出発して 1 刻み進めた数値解を $y_{n+1}^*$ とする。
局所打ち切り誤差は 1 刻みで生じる離散化誤差

$$
d_{n+1} = y(t_{n+1}) - y_{n+1}^*
$$

である。
方式の次数が $p$ であるとは、十分に滑らかな $f$ に対して $d_{n+1} = O(h^{p+1})$ となることをいう。
線形多段法では主要項が $C_{p+1} h^{p+1} y^{(p+1)}(t_n)$ の形になる。
Runge–Kutta 法の主要項は、$f$ とその偏導関数を組み合わせた基本微分（elementary differential）の和で、方式の係数で決まる重みが付く。

### 大域誤差の上界

大域誤差を $e_n = y(t_n) - y_n$ とする。
$f$ が $y$ について Lipschitz 定数 $L > 0$ を持つ（$\|f(t, u) - f(t, v)\| \le L \|u - v\|$）とき、1 刻みで $\|e_{n+1}\| \le (1 + hL)\|e_n\| + \|d_{n+1}\|$ が成り立つ（1 段法の場合）。
これを繰り返すと、離散版の Grönwall の不等式から

$$
\|e_n\| \le \frac{\max_k \|d_k\|}{h L} \left( e^{L(t_n - t_0)} - 1 \right) \le \frac{C h^{p+1}}{h L} e^{L (T - t_0)} = O(h^p)
$$

が得られる。
ここで $T$ は積分の終端、$C$ は局所誤差の主要項の係数の上限である。
局所誤差 $O(h^{p+1})$ が $N = (T - t_0)/h$ 回積み重なるので、大域誤差の次数は 1 つ下がって $O(h^p)$ になる。
因子 $e^{L(T - t_0)}$ は、近い 2 つの解が離れる速さの上界である。
カオス的な系や長時間の積分ではこの因子が大きくなり、許容誤差を満たした局所誤差からは終端の精度を判断できない。
保存量を持つ系では[幾何積分法](../geometric-integrators/)のように構造を保つ方式を選ぶ。

`scioxide-ode` の適応刻みの方式は局所誤差だけを制御する。
終端の精度は許容誤差を変えた解どうしの比較や既知の解で確かめる。

## 刻みの半減による観測次数

解析解がない問題でも、刻み幅 $h$、$h/2$、$h/4$ の数値解 $Y_h$、$Y_{h/2}$、$Y_{h/4}$ から次数を測れる。
漸近領域で $Y_h - y(T) \approx C h^p$ と書けるなら

$$
\frac{\|Y_h - Y_{h/2}\|}{\|Y_{h/2} - Y_{h/4}\|} \approx \frac{C h^p (1 - 2^{-p})}{C (h/2)^p (1 - 2^{-p})} = 2^p
$$

なので、観測次数は

$$
p_{\text{obs}} = \log_2 \frac{\|Y_h - Y_{h/2}\|}{\|Y_{h/2} - Y_{h/4}\|}
$$

で求まる。
観測次数が公称の次数に近づくことを確かめると、右辺や係数の書き誤りを見つけられる。
刻みが大きすぎて漸近領域に入らないときと、刻みが小さすぎて丸め誤差が支配するときは、観測次数は公称の次数からずれる。

公称の次数は、$h\lambda$ が小さい漸近領域での値である。
剛性のある問題で $|h\lambda| \gg 1$ のまま刻みを半減すると、陰的な Runge–Kutta 法の観測次数は段の次数（stage order、各段の値 $Y_i$ の近似の次数）まで下がることがある。
これを次数低下（order reduction）という。
次の Prothero–Robinson 問題

$$
y' = \lambda \bigl(y - \cos t\bigr) - \sin t, \qquad y(0) = 1
$$

は、$\lambda$ によらず厳密解 $y = \cos t$ を持ち、$\lambda < 0$ を負に大きくすると剛性が強くなる。

次のブロックは、このページの 2 つのセルが共有する定義である。
`fixed_step_endpoint` は 1 成分の系を固定刻みの方式で $[0, T]$ について解き、終端値 $y_N$ を返す。
陽的な方式は剛性のある問題で発散し、状態が有限でなくなると `NonFinite` のエラーで止まるので、その解は `None` にする。
ほかのエラーと、終端に達しなかったレポートはそのまま失敗として返す。

```rust
//| id: ode-fixed-step-endpoint
//| kind: definitions
//| title: 固定刻みの方式で 1 成分の系を解いて終端値を返す
//| crates: [scioxide-core, scioxide-linalg, scioxide-ode]
use scioxide_core::{ErrorTolerance, ExecutionContext, SciOxideErrorKind};
use scioxide_linalg::Vector;
use scioxide_ode::{OdeMethod, OdeOptions, OdeProblem, OdeState, OdeSystem};

/// y(0) = 1 から刻み `step` で [0, end] を解いた終端値。発散した解は None。
pub(crate) fn fixed_step_endpoint<M: OdeMethod<f64> + Clone, Sys: OdeSystem<f64>>(
    method: &M,
    system: &Sys,
    tolerance: &ErrorTolerance<f64>,
    end: f64,
    step: f64,
) -> Result<Option<f64>, String> {
    let problem = OdeProblem::new(system, end);
    let options = OdeOptions::new()
        .with_error_tolerance(tolerance.clone())
        .with_initial_step(step);
    let mut workspace = method
        .workspace(&problem, &options)
        .map_err(|e| e.to_string())?;
    let mut state = OdeState::new(0.0, Vector::from_vec(vec![1.0]));
    let run = method.advance(
        &problem,
        &options,
        &mut state,
        &mut (),
        &mut workspace,
        ExecutionContext::sequential(),
    );
    match run {
        Ok(report) if report.is_success() => Ok(Some(state.values()[0])),
        Ok(report) => Err(format!("{:?}", report.termination())),
        Err(e) if e.kind() == SciOxideErrorKind::NonFinite => Ok(None),
        Err(e) => Err(e.to_string()),
    }
}
```

次のセルは固定刻みの 7 つの方式でこの問題を $[0, 1]$ で解く。
刻みの数は $N = 10, 20, \dots, 320$ で、入力は剛性の指数 $k$（$\lambda = -10^k$）である。
表には最も粗い刻みと最も細かい刻みの誤差と、最後の 2 つの刻みの誤差の比から求めた観測次数、刻みの半減の式（最後の 3 つの解）から求めた観測次数を並べる。
後者は厳密解を使わないので、厳密解との比較による前者の独立な検算になる。
陽的な方式は剛性のある $\lambda$ で発散するので、誤差が 1 を超えた解と状態が有限でなくなった解は「発散」として表と図から除く。
陰的な方式は $\partial f / \partial y = \lambda$ を解析的に与え、段の方程式を $10^{-10}$ の許容誤差で解く。

既定の $k = 0$（$\lambda = -1$）では、7 つの方式の観測次数はどちらの式でも公称の次数と 0.05 以内で一致する。
たとえば古典 RK4 の $N = 320$ の誤差は $3.2 \times 10^{-13}$ で、観測次数は 4.02（厳密解）と 4.01（刻みの半減）である。

$k = 6$（$\lambda = -10^6$）では $|h\lambda| \ge 3125$ がどの陽的な方式の安定領域にも入らないので、陽的な 3 つの方式はすべての $N$ で発散する。
後退 Euler 法と陰的台形則は公称の次数 1 と 2 を保つ。
SDIRK の観測次数は 1.01 で、公称の 3 から段の次数の 1 まで下がる。
2 段 Gauss 法の観測次数は 2.40（厳密解）と 2.03（刻みの半減）で、段の次数の 2 に近い。
後退 Euler 法と SDIRK の誤差は $|\lambda|$ に反比例して小さくなり、$k = 4$ から $k = 6$ で 100 分の 1 になる。
2 段 Gauss 法の誤差は $\lambda$ によらずほぼ同じ大きさで残り、$N = 10$ では $1.3 \times 10^{-4}$ と、$\lambda = -1$ のときの約 1000 倍である。
$k = 4$ では $N = 320$ で $|h\lambda| \approx 31$ まで下がり、Gauss 法の観測次数は 3.98 に戻る。
次数低下は $|h\lambda|$ が大きい刻みの範囲で起こり、刻みを細かくして $|h\lambda|$ が小さくなると公称の次数に戻る。
剛性のある問題では公称の次数だけで方式を比べず、使う刻みの範囲での観測次数を確かめる。

## Dahlquist の試験方程式と絶対安定性領域

長時間の安定性を調べるために、Dahlquist の線形の試験方程式

$$
y' = \lambda y, \qquad \lambda \in \mathbb{C}, \quad \operatorname{Re}\lambda < 0
$$

を使う。
真の解 $y(t) = y_0 e^{\lambda t}$ は $t \to \infty$ で 0 に減衰する。
Runge–Kutta 法をこの方程式に適用すると、数値解は複素数 $z = h\lambda$ を使って

$$
y_{n+1} = R(z)\, y_n
$$

と書ける。
有理関数（陽的な方式では多項式）$R(z)$ を安定関数という。
係数行列 $A$、重み $b$ の Runge–Kutta 法では $R(z) = 1 + z\, b^{\mathsf{T}} (I - zA)^{-1} \mathbf{1}$ である。
数値解の列 $y_n$ が有界であるための必要十分条件は $|R(z)| \le 1$ で、この条件を満たす集合

$$
\mathcal{S} = \{ z \in \mathbb{C} \mid |R(z)| \le 1 \}
$$

を絶対安定性領域という。
$d$ 次元の線形系 $y' = Ay$ で $A$ が対角化できるなら、固有値 $\lambda_i$ ごとに同じ議論ができ、すべての $h\lambda_i$ が $\mathcal{S}$ に入ることが条件になる。

### 代表的な方式の安定関数

| 方式 | 安定関数 $R(z)$ | 負の実軸の安定な区間 |
|---|---|---|
| 前進 Euler 法 | $1 + z$ | $[-2, 0]$ |
| 古典 RK4 | $1 + z + z^2/2 + z^3/6 + z^4/24$ | $[-2.785, 0]$ |
| 後退 Euler 法 | $1/(1 - z)$ | 負の実軸全体 |
| 陰的台形則 | $(1 + z/2)/(1 - z/2)$ | 負の実軸全体 |
| 2 段 Gauss 法 | $(1 + z/2 + z^2/12)/(1 - z/2 + z^2/12)$ | 負の実軸全体 |
| 3 段 Radau IIA 法 | $(1 + 2z/5 + z^2/20)/(1 - 3z/5 + 3z^2/20 - z^3/60)$ | 負の実軸全体 |

陽的な方式の $R$ は多項式なので、$|z| \to \infty$ で $|R(z)| \to \infty$ となり、安定領域は有界である。
陰的台形則と Gauss 法の $R$ は $e^z$ の対角 Padé 近似で、虚軸上で $|R| = 1$ となる。
Radau IIA 法の $R$ は分母の次数が分子より高い Padé 近似で、$|z| \to \infty$ で 0 に近づく。
3 段 SDIRK（`Sdirk`）の $R$ は分母が $(1 - \gamma z)^3$ の有理関数で、こちらも $|z| \to \infty$ で 0 に近づく。

### 方式が提示する安定な区間

各方式は `OdeMethod::linear_stability` で、安定関数が $|R(z)| \le 1$ を満たす実軸と虚軸の区間を `OdeLinearStability` として返す。
`OdeLinearStability::Axes { real, imaginary }` は、$h\lambda$ が負の実軸の区間 $[-\mathrm{real}, 0]$ か虚軸の区間 $[-i\,\mathrm{imaginary}, i\,\mathrm{imaginary}]$ にあれば数値解が増えないことを表す。
`None` はその半直線または軸全体が安定であることを表し、0 は 0 以外のどの刻みも安定でないことを表す。
有限の値は安定領域の境界を 10 進で切り下げた定数で、前進 Euler 法は 2、古典 RK4 は 2.7852、`DormandPrince5` は 3.3065、`DormandPrince853` は 6.3936 である。
`Rkf45` は 5 次の解で進むので、虚軸の区間は 0 である。
A 安定な陰的な方式と `RosenbrockW` は両方の軸で `None` を返す。
最大次数が 3 以上の `Bdf` は負の実軸全体を提示し、虚軸の区間を 0 とする。
Adams 法のように安定領域を提示しない方式は `Undeclared` を返す。

この提示内容は試験方程式に対する性質である。
method of lines（空間を離散化した半離散系）で陽的な方式の刻み幅の上限を決めるときは、空間の離散化の固有値の範囲と組み合わせて使う。
たとえば固有値が $[-\rho, 0]$ にある拡散の半離散系を `DormandPrince5` で解くなら、$h \le 3.3065/\rho$ が安定の条件になる。
系の側でこのような上限が分かっているときは、`OdeSystem::step_limit` で刻みごとに与えられる（[陽的 Runge–Kutta 法と刻み幅の制御](../explicit-runge-kutta-and-control/)）。

## A 安定性と L 安定性

剛性のある系では、安定領域が負の実軸のどこまでを含むかで刻み幅の上限が決まる。

絶対安定性領域 $\mathcal{S}$ が左半平面 $\mathbb{C}^- = \{ z \mid \operatorname{Re} z \le 0 \}$ を含むとき、方式は A 安定であるという。
A 安定な方式では、線形の系の固有値の実部が負である限り、刻み幅 $h > 0$ をどれだけ大きくしても数値解は発散しない。
後退 Euler 法、陰的台形則、Gauss 法、Radau IIA 法、`Sdirk` は A 安定である。

A 安定な方式でも、$|z|$ が大きいときの減衰の速さは方式によって大きく違う。
陰的台形則では

$$
\lim_{z \to -\infty} R_{\text{TR}}(z) = \lim_{z \to -\infty} \frac{1 + z/2}{1 - z/2} = -1
$$

となる。
真の解では速く減衰する成分（$h\lambda \ll -1$）に対して、数値解の増幅率は $-1$ に近づく。
その成分はほとんど減衰せず、刻みごとに符号が反転する見かけの振動が残る。
A 安定であり、さらに

$$
\lim_{|z| \to \infty} R(z) = 0
$$

を満たす方式を L 安定という。
後退 Euler 法、`Sdirk`、`RadauIia` は L 安定で、刻み幅が速い成分の時定数より十分大きいとき、その成分を 1 刻みでほぼ 0 まで減衰させる。
ただし L 安定性は速い成分を減衰させる性質であり、その減衰の速さ $e^{h\lambda}$ を正しく再現する性質ではない。

次のセルは 6 つの固定刻みの方式で $y' = -y$ を刻み $h = |z|$ の 1 刻みだけ解き、得た $y_1$ を $R(z)$ として描く。
入力は調べる負の実軸の範囲 $|z| \le Z$ で、格子は $Z/80$ 刻みである。
陰的な方式の段の方程式は許容誤差に応じて打ち切られるので、許容誤差を $10^{-13}$ にして安定関数の式と比べる。

## 剛性

$y' = Ay$ の固有値 $\lambda_i$ の実部がすべて負で、その大きさが何桁も離れているとき、系は剛性を持つという。
大きさの比 $\max_i |\operatorname{Re}\lambda_i| / \min_i |\operatorname{Re}\lambda_i|$ を剛性比と呼ぶことがある。
速い成分は $1/|\lambda_{\max}|$ 程度の時間で減衰し、その後の解は遅い成分だけで決まる。
陽的な方式は $h|\lambda_{\max}|$ を安定領域の中に保つ必要があるので、速い成分が消えた後も刻み幅は $1/|\lambda_{\max}|$ 程度に制限される。
刻み幅が精度ではなく安定性で決まる状態が剛性の実用上の定義である。
非線形の系では、Jacobi 行列 $\partial f/\partial y$ の固有値が解に沿って変わるので、剛性も時間とともに変わる。

剛性のある系では陰的な方式（[陰的 Runge–Kutta 法と質量行列](../implicit-runge-kutta-and-mass-matrices/)、[線形多段法](../multistep-methods/)）か Rosenbrock 型の方式（[Rosenbrock 法と剛性の自動切り替え](../rosenbrock-and-stiffness-switching/)）を使う。
これらは刻みごとに $I - h\gamma J$ の形の線形方程式を解くので、1 刻みの計算量は大きいが、刻み幅は精度で決められる。
剛性の有無が分からない問題や途中で変わる問題には、`AutoStiff` と `AdamsBdf` が刻みの履歴から剛性を推定して方式を切り替える。

### 非正規な系の過渡的な増大

$A$ が正規行列（$AA^{\mathsf{H}} = A^{\mathsf{H}}A$）なら、$\|e^{At}\|_2 = \max_i e^{t \operatorname{Re}\lambda_i}$ となり、安定性は固有値だけで決まる。
流体の剪断流や一部の反応網のように $A$ が強い非正規性を持つと、すべての固有値の実部が負でも

$$
\sup_{t \ge 0} \|e^{At}\| \gg 1
$$

となり、短い時間に解のノルムが大きく増える。
これを過渡的な増大（transient growth）という。
数値解でも同じで、$h\lambda_i$ がすべて安定領域に入っていても、$\|R(hA)^n\|$ が途中で大きくなりうる。
この振る舞いは擬スペクトル（pseudospectrum、$\|(zI - A)^{-1}\| > 1/\delta$ となる $z$ の集合）で説明される（Trefethen と Embree）。
非正規な系では固有値だけで安定性を判断せず、$\|e^{At}\|$ や数値解のノルムの推移も確かめる。

## まとめ

次数 $p$ の方式の大域誤差は有限区間で $O(h^p)$ だが、定数には区間の長さと Lipschitz 定数の指数が入るので、長い積分では局所誤差の許容誤差だけで終端の精度を判断できない。
刻みを半減して観測次数を測ると、方式と右辺の実装を確かめられ、剛性のある問題では段の次数への次数低下も見える。
剛性のある系では安定関数が刻み幅を決め、A 安定な方式は発散しないが、速い成分を減衰させるには L 安定な方式が要る。
方式が提示する実軸と虚軸の安定な区間は `OdeMethod::linear_stability` で読み、空間の離散化の固有値の範囲と合わせて陽的な方式の刻み幅を決められる。
非正規な系では固有値だけで安定性を判断せず、過渡的な増大も確かめる。

刻みごとの誤差の推定と刻み幅の制御は[陽的 Runge–Kutta 法と刻み幅の制御](../explicit-runge-kutta-and-control/)で、L 安定な陰的な方式の段の解き方は[陰的 Runge–Kutta 法と質量行列](../implicit-runge-kutta-and-mass-matrices/)で確かめられる。
