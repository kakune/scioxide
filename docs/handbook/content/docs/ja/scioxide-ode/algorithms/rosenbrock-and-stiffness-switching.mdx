剛性のある問題を陰的 Runge–Kutta 法や BDF で解くと、刻みごとに非線形方程式を Newton 法で解く。
Rosenbrock 法は Newton 法の 1 回目の反復だけを方式の式に組み込み、各段で線形方程式を 1 つ解く。
反復の収束判定がないので 1 刻みの手間が読みやすく、中程度の精度では陰的 Runge–Kutta 法より少ない手間で済むことが多い。
このページでは、scioxide-ode の `RosenbrockW` の式と 2 つの係数の組、近似した Jacobian で次数が保たれる理由と、それでも安定性が失われる条件を扱う。
後半では、問題の剛性が途中で変わるときに非剛性の方式と剛性の方式を切り替える `AutoStiff` と `AdamsBdf` の指標と規則を扱う。
記号は[数理と共通の規約](../)にそろえ、$J = \partial f/\partial y$ を右辺の Jacobian 行列、$h$ を刻み幅とする。
剛性と安定関数の基本は[誤差次数・安定性・剛性](../error-order-and-stability/)で確かめられる。

## Rosenbrock-W 法の段の方程式

$s$ 段の Rosenbrock 型の方式は、$y_n$ から $y_{n+1}$ への 1 刻みを次の式で進める。

$$
(I - h\gamma A)\,k_i = h\,f\!\left(t_n + \alpha_i h,\; y_n + \sum_{j<i} a_{ij} k_j\right) + hA\sum_{j<i}\gamma_{ij} k_j + h^2 \gamma_i\, \frac{\partial f}{\partial t}(t_n, y_n),
$$

$$
y_{n+1} = y_n + \sum_{i=1}^{s} b_i k_i, \qquad \hat y_{n+1} = y_n + \sum_{i=1}^{s} \hat b_i k_i .
$$

ここで $k_i$ は段の増分、$a_{ij}$、$\gamma_{ij}$、$b_i$、$\hat b_i$ は方式の係数、$\alpha_i = \sum_{j<i} a_{ij}$、$\gamma_i = \sum_{j\le i}\gamma_{ij}$ で、対角の係数はすべて $\gamma_{ii} = \gamma$ にそろえてある。
$A$ は Jacobian $J(t_n, y_n)$ そのもの、またはその近似である。
$A = J$ を前提に次数条件を満たす方式を Rosenbrock 法、任意の $A$ で次数条件を満たす方式を W 法と呼ぶ。

式の左辺の行列 $I - h\gamma A$ は全段で共通なので、1 刻みに LU 分解は 1 回で済み、各段は前進・後退代入だけで解ける。
右辺は既知の段の値だけで決まるので、段の方程式は線形で、Newton 法の反復はない。
誤差の推定は 2 つの重み $b_i$ と $\hat b_i$ の差 $y_{n+1} - \hat y_{n+1}$ で、刻みの受理と次の刻みは陽的 Runge–Kutta 法と同じ規則で決まる（既定は PI 制御）。

`RosenbrockW` は `RosenbrockMethod` で 2 つの係数の組を選ぶ。

| 係数の組 | 段数 $s$ | 次数 | 埋め込みの次数 | $\gamma$ | 文献 |
|---|---:|---:|---:|---|---|
| `RosenbrockMethod::Ros2` | 2 | 2 | 1 | $1 + 1/\sqrt{2} \approx 1.7071$ | Verwer ほか（1999） |
| `RosenbrockMethod::Ros34Pw2` | 4 | 3 | 2 | $0.435866521508459$ | Rang–Angermann（2005） |

どちらも W 法として作られた係数で、$A = J$ のとき L 安定である。
1 回の試行の手間は $s$ 段の方式で、右辺の評価 $s - 1$ 回、LU 分解 1 回、Jacobian とベクトルの積 $s - 1$ 回である。
$f(t_n, y_n)$ と $\partial f/\partial t(t_n, y_n)$ は受理した刻みごとに 1 回だけ評価し、棄却して刻みを縮めた再試行では使い回す。
連続出力は刻みの両端の値と傾きによる 3 次 Hermite 補間で、受理した刻みの終点の傾きは次の刻みの $f(t_n, y_n)$ になる。
事象の検出と出力時刻の指定は使えるが、質量行列には対応せず、質量行列を持つ系は `InvalidInput`（`UnsupportedConfiguration`）で拒まれる。

Jacobian は受理した刻みが 5 回続いたとき、刻みを棄却したとき、時刻か状態のある成分が $\max(1, |\text{旧}|, |\text{新}|)$ の半分より大きく動いたときに作り直す。
`OdeSystem::jacobian_is_constant` が `true` を返す系では作り直さない。
LU 分解は常にその刻みの $h$ で行う。
段の線形方程式の解き方は `with_backend` で選び、既定は密行列の LU 分解で、疎行列の LU 分解と再始動付き GMRES も選べる。
Jacobian の求め方は `with_derivative_strategy` で選ぶ。
これらの選び方と計算コストは [Jacobian と各ステージの線形方程式の解法](../jacobians-and-linear-stages/)で扱う。

## 近似した Jacobian と次数

Rosenbrock 法の次数条件は Taylor 展開から導くが、$A = J$ を使うと条件の数が減る。
$A$ と $J$ を別の量として展開し、すべての $A$ について条件を満たすようにした係数が W 法である。
W 法では、古い Jacobian、差分で近似した Jacobian、一部の成分だけの Jacobian を使っても、刻みを 0 に近づけたときの次数は変わらない。
`RosenbrockW` が Jacobian を 5 刻みごとにしか作り直さず、既定で差分近似も受け入れるのは、この性質による。

一方で安定性は $A$ に依存する。
試験方程式 $y' = \lambda y$ に $A = \mu$ を使うと、1 刻みの増幅率は $z = h\lambda$ と $w = h\mu$ の 2 変数の関数 $R(z, w)$ になり、$|R(z, z)| \le 1$ が成り立っても $w \ne z$ では成り立たないことがある。
たとえば $A = 0$ にすると、各段の行列は単位行列になり、方式は陽的 Runge–Kutta 法と同じ形になる。
したがって、$|h\lambda|$ が大きい剛性の問題では、近似した Jacobian が速い成分の固有値を捉えていないと、どんな W 法でも発散する。

この節と次の節で使う試験問題は Prothero–Robinson 型の方程式

$$
y' = \lambda(t)\,\bigl(y - \cos t\bigr) - \sin t, \qquad y(0) = 1
$$

である。
厳密解は $\lambda(t)$ によらず $y(t) = \cos t$ で、$\lambda(t) < 0$ の大きさが剛性を決める。
非自律系なので、Rosenbrock-W 法には時間微分

$$
\frac{\partial f}{\partial t} = \lambda'(t)\,(y - \cos t) + \lambda(t)\sin t - \cos t
$$

が要る。
次のブロックは 2 つのセルが使うモデルである。
`peak` は $|\lambda|$ の最大値 $\Lambda$、`varying` が `false` なら $\lambda = -\Lambda$ で一定、`true` なら $\lambda(t) = -\Lambda^{\sin^2(\pi t/10)}$ で、$t = 0$ の $-1$ から $t = 5$ の $-\Lambda$ まで大きくなり、$t = 10$ で $-1$ に戻る。
`jacobian_scale` は Rosenbrock-W 法に渡す Jacobian を $c\lambda$ に変える倍率 $c$ で、$c = 1$ が正しい Jacobian である。
`time_derivative` は上の $\partial f/\partial t$ を返す。

```rust
//| id: ode-prothero-robinson-model
//| kind: definitions
//| title: Prothero–Robinson 型の試験問題
//| crates: [scioxide-core, scioxide-linalg, scioxide-ode]
use scioxide_core::{SciOxideError, RealScalar, SolveContext};
use scioxide_linalg::MatrixViewMut;
use scioxide_ode::OdeSystem;

/// y′ = λ(t)(y − cos t) − sin t。y(0) = 1 の厳密解は y(t) = cos t。
pub(crate) struct ProtheroRobinson {
    /// |λ| の最大値 Λ。
    pub(crate) peak: f64,
    /// true なら λ(t) = −Λ^{sin²(πt/10)}、false なら λ = −Λ。
    pub(crate) varying: bool,
    /// Jacobian として渡す c λ の倍率 c（1 なら正しい Jacobian）。
    pub(crate) jacobian_scale: f64,
}

impl ProtheroRobinson {
    /// λ(t) と λ′(t) を返す。
    pub(crate) fn lambda(&self, t: f64) -> (f64, f64) {
        if !self.varying {
            return (-self.peak, 0.0);
        }
        let phase = std::f64::consts::PI * t / 10.0;
        let log_peak = RealScalar::ln(self.peak);
        let lambda = -RealScalar::exp(log_peak * RealScalar::powi(RealScalar::sin(phase), 2));
        // d/dt sin²(πt/10) = (π/10) sin(πt/5)。
        let slope = lambda * log_peak * std::f64::consts::PI / 10.0 * RealScalar::sin(2.0 * phase);
        (lambda, slope)
    }
}

impl OdeSystem<f64> for ProtheroRobinson {
    fn dimension(&self) -> usize {
        1
    }
    fn rhs(
        &self,
        t: f64,
        y: &[f64],
        dydt: &mut [f64],
        _: &mut SolveContext<'_, '_>,
    ) -> Result<(), SciOxideError> {
        let (lambda, _) = self.lambda(t);
        dydt[0] = lambda * (y[0] - RealScalar::cos(t)) - RealScalar::sin(t);
        Ok(())
    }
    fn jacobian(
        &self,
        t: f64,
        _: &[f64],
        jac: &mut MatrixViewMut<'_, f64>,
        _: &mut SolveContext<'_, '_>,
    ) -> Result<Option<()>, SciOxideError> {
        jac.set(0, 0, self.jacobian_scale * self.lambda(t).0)?;
        Ok(Some(()))
    }
    fn time_derivative(
        &self,
        t: f64,
        y: &[f64],
        output: &mut [f64],
        _: &mut SolveContext<'_, '_>,
    ) -> Result<Option<()>, SciOxideError> {
        let (lambda, slope) = self.lambda(t);
        let (sin, cos) = RealScalar::sin_cos(t);
        output[0] = slope * (y[0] - cos) + lambda * sin - cos;
        Ok(Some(()))
    }
}
```

次のセルは $\lambda = -10^k$ で一定の問題を $[0, 2]$ で解き、Jacobian の倍率 $c = 1, 1/2, 0$ ごとに終端の誤差 $|y_N - \cos 2|$ を刻み $h = 2/N$（$N = 8, 16, \ldots, 512$）に対して求める。
`RosenbrockW` は適応型なので、許容誤差を $10^6$ にして誤差による棄却をなくし、刻みの上限・下限・初期値をすべて $h$ にそろえて固定刻みで進める。
刻みは 2 の負べきで、$N$ 刻みでちょうど $t = 2$ に着く。
表の観測次数は、隣り合う 2 つの刻みの誤差の比 $\log_2(e_{h}/e_{h/2})$ である。
発散して値が浮動小数点数の範囲を超えた組と、刻みを棄却して止まった組は「発散」と表示する。

let peak = 10.0_f64.powf(stiffness_exponent);

    .map_err(|e| e.to_string())?;

既定の ROS34PW2、$\lambda = -1$ では、3 つの倍率のどれでも観測次数は 3 に近づき、最も細かい刻みでは $c = 1, 1/2, 0$ の誤差がそれぞれ $9.5 \times 10^{-10}$、$8.2 \times 10^{-10}$、$5.8 \times 10^{-9}$ である。
$c = 0$ は Jacobian を使わない陽的な方式と同じ計算だが、それでも 3 次の収束を保つ。
誤差定数は $A$ によって変わり、$c = 0$ の誤差は $c = 1$ の約 6 倍になる。

$\lambda = -10^3$ にすると、$c = 1$ は $h = 1/4$ でも誤差 $3.4 \times 10^{-6}$ で安定に解く。
$c = 0$ は $|h\lambda| \ge 3.9$ のすべての刻みで発散し、$c = 1/2$ も $h \ge 1/64$ で発散して、$h = 1/128$ で初めて誤差が $3.0 \times 10^{-3}$ に下がる。
ROS2 では $c = 1/2$ が全刻みで安定だが、観測次数は 1.04〜1.13 に下がる。
$c = 1$ でも、ROS34PW2 の観測次数は 2.0〜2.4 で 3 に届かない。
これは Prothero–Robinson 型の問題で知られる次数低下で、$|h\lambda|$ が大きい間は局所誤差が刻みの低いべきでしか減らない。
次数が保たれるのは $h \to 0$ の極限での話で、$|h\lambda|$ が大きい領域の誤差と安定性は Jacobian の近似の良さで決まる。
剛性のある問題では、正しい Jacobian か、少なくとも速い成分の固有値を正しく捉える近似を渡す。

## 非自律系の時間微分

$f$ が $t$ を陽に含むとき、Rosenbrock 型の方式は $\partial f/\partial t$ の項がないと次数を保てない。
`RosenbrockW` はこの項を `OdeSystem::time_derivative` が値を返せばそれから、返さなければ $t$ の差分から求める。
差分の刻みの尺度は $\max(|t|, 1)$ で、前進差分なら受理した刻みごとに右辺の評価が 1 回増える。
自動微分は $\partial f/\partial t$ には使えない。
`with_derivative_strategy` で選ぶ順序は Jacobian と時間微分の両方に使われる。

自律系 $y' = f(y)$ では、`time_derivative` で 0 を書いて `Ok(Some(()))` を返すと差分の評価がなくなる。
クロージャから作る `OdeFn` は `time_derivative` を持たないので、時間微分はいつも差分になる。
評価を減らしたいときや差分の精度が足りないときは、`OdeSystem` を実装して `time_derivative` を与える。

## 剛性の指標

陽的な方式の安定領域は有界で、負の実軸上では $|h\lambda| \le c$（Dormand–Prince 5(4) では $c \approx 3.3$）の範囲に限られる。
刻み幅が精度ではなくこの条件で決まっているとき、問題はその方式にとって剛性がある。
`AutoStiff` はこの状態を、刻み幅とスペクトル半径の積

$$
\sigma = |h|\,\rho(J)
$$

で判定する。
$\rho(J)$ は Jacobian の固有値の絶対値の最大値で、$\sigma$ がおよそ 1 を超えると、陽的な方式の刻みは精度より安定性で制限されている見込みが高い。

$\rho(J)$ は Jacobian 行列を作らずに冪乗法で推定する。
冪乗法の方向は刻みをまたいで引き継ぎ、最後の 2 回の比 $\|Jv\|/\|v\|$ の幾何平均を推定値にするので、絶対値の等しい $\pm\lambda$ の組や複素共役の組が支配的な場合も収束する。
1 回の反復は積 $Jv$ を 1 回使う。
剛性の方式が現在の Jacobian を持っていればその積は追加の評価なしで求まり、持っていなければ `OdeSystem::jacobian_product` か、$f$ の前進差分（右辺の評価 1 回）で求める。
積は受理した刻みごとに高々 1 回で、推定の間隔は 1 刻みから始めて推定のたびに倍にし、12 刻みで止める。
推定値が切り替えの閾値の 2 倍以内にあり、前の推定値と 4 分の 1 より大きく違うと、間隔は 1 刻みに戻る。
$\sigma$ は推定値で、問題が剛性を持つことの証明ではない。
質量行列を持つ系では指標を計算しない。

## 切り替えの規則

`AutoStiff<S, N, F>` は適応型の非剛性の方式 `N` で積分を始め、`StiffnessSwitchOptions` の規則で剛性の方式 `F` に移り、また戻る。
`N` から `F` へは、受理した刻みで $\sigma$ が閾値 `enter` を超える状態が `enter_steps` 回続いたとき、または棄却が `rejections` 回続いたときに移る。
`F` から `N` へは、`F` で `residence` 回以上受理したあと、$\sigma$ が閾値 `leave` を下回る状態が `leave_steps` 回続いたときに戻る。
`F` で積分している間の $\sigma$ の $h$ には、切り替えてから `F` が使った最大の刻みを使う。
棄却や一時的な刻みの縮小だけで `N` に戻らないようにするためである。

| 設定 | 既定値 | 設定する関数 |
|---|---|---|
| `enter`、`leave` | $1$、$1/4$ | `with_thresholds(enter, leave)` |
| `enter_steps`、`leave_steps` | 2、6 | `with_evidence_steps(enter, leave)` |
| `residence` | 8 | `with_residence(accepted_steps)` |
| `rejections` | 3 | `with_rejections(consecutive)` |

設定関数は値を確かめず、`AutoStiff::new` がまとめて確かめる。
`enter` が正の有限値でないとき、`leave` が $0 \le \text{leave} < \text{enter}$ を満たさないとき、回数のどれかが 0 のときは `InvalidInput` を返す。
`N` と `F` のどちらかが適応型でない（固定刻みの方式や `MultistepOrder::Fixed` の多段法）ときは `InvalidInput`（`UnsupportedConfiguration`）を返す。
`enter` と `leave` を離し、続けて満たす回数を求めるのは、閾値の近くで方式が行き来しないようにするヒステリシスである。

切り替えた方式は、切り替えた時刻から空の履歴で始め、刻み幅の制御もやり直す。
多段法の履歴は引き継がないので、`F` が BDF なら次数 1 から始まる。
質量行列を持つ系では、最初の刻みで `F` に移り（理由は `MassMatrix`）、以後は戻らない。
このため `F` は質量行列に対応している必要があり、`RosenbrockW` を `F` にした組は質量行列を扱えない。
出力時刻と事象には両方の方式の連続出力を使う。

`AdamsBdf` は `AutoStiff<S, AdamsMoulton<S>, Bdf<S>>` の別名で、`AdamsBdf::adams_bdf()` は次数を 5 まで自動で選ぶ Adams 予測子・修正子法（PECE）と BDF の組を既定の規則で作る。
ほかの組、たとえば `DormandPrince5` と `RosenbrockW` は `AutoStiff::new` で組み合わせる。
2 つの方式の数値は[線形多段階法](../multistep-methods/)で扱う。

切り替えの記録は `OdeSolveReport` の `method_switches()`（回数）と `last_method_switch()`（最後の 1 回）に残る。
`OdeMethodSwitch` は、新しい方式が最初の刻みを始める時刻 `time()`、前後の方式の名前 `from()`・`to()`、理由 `reason()`、そのときの $\sigma$ の推定値 `indicator()` を返す。
`indicator()` は推定値がないとき（質量行列を持つ系など）は `None` である。
理由 `OdeSwitchReason` は次の 4 つである。

| `OdeSwitchReason` | 切り替え | 条件 |
|---|---|---|
| `Stiffness` | `N` → `F` | $\sigma >$ `enter` が `enter_steps` 回続いた |
| `Rejections` | `N` → `F` | `N` の棄却が `rejections` 回続いた |
| `Nonstiffness` | `F` → `N` | `residence` 回の受理のあと、$\sigma <$ `leave` が `leave_steps` 回続いた |
| `MassMatrix` | `N` → `F` | 系が質量行列を持つ |

出力の受け取り手（`OdeOutputSink`）には切り替えは送られず、レポートに残るのは最後の 1 回だけである。
すべての切り替えを並べるには、記録された時刻の直前に終端の事象を置いて同じ問題を解き直し、そのレポートの最後の切り替えを読む。
事象は積分を止めるだけで、それより前の刻みを変えないので、解き直した積分は元の積分と同じ刻みをたどる。
次のセルはこの手順を切り替えが残らなくなるまで繰り返す。

次のセルは $\lambda(t) = -\Lambda^{\sin^2(\pi t/10)}$ の問題を $[0, 10]$ で、許容誤差 $\varepsilon_{\mathrm{rel}} = 10^{-6}$、$\varepsilon_{\mathrm{abs}} = 10^{-8}$ で解く。
方式の組は `AdamsBdf` と、`DormandPrince5` と ROS34PW2 の `AutoStiff` から選ぶ。
1 つ目の表は切り替えの一覧で、時刻、前後の方式、理由、$\sigma$ の推定値と、その時刻の $|\lambda(t)|$ を示す。

/// 全区間を解いたレポートと受理した時刻、最後から順にたどった切り替えの一覧を返す。
fn switch_log<M: OdeMethod<f64> + Clone>(
    method: &M,
    system: &ProtheroRobinson,
    options: &OdeOptions<f64>,
    end: f64,
) -> Result<
    (
        OdeSolveReport<f64>,
        f64,
        Vec<f64>,
        Vec<OdeMethodSwitch<f64>>,
    ),
    String,
> {
    let initial = || OdeState::new(0.0, Vector::from_vec(vec![1.0]));
    let accepted = options
        .clone()
        .with_output_schedule(OdeOutputSchedule::AcceptedSteps);
    let full = method
        .solve(&OdeProblem::new(system, end), &accepted, initial())
        .map_err(|e| SciOxideError::from(e).to_string())?;
    let report = *full.report();
    let final_value = full.state().values()[0];
    let mut switches = Vec::new();
    let mut last = report.last_method_switch();
    while let Some(switch) = last {
        switches.push(switch);
        // 記録した切り替えの直前で止める終端の事象。それより前の刻みは元の積分と同じ。
        let stop = switch.time() - 1e-9 * switch.time().abs().max(1.0);
        let event = EventFn::new(move |t: f64, _: &[f64]| Ok(t - stop)).with_terminal(true);
        let events: [&dyn EventFunction<f64>; 1] = [&event];
        let problem = OdeProblem::new(system, end).with_events(&events);
        let earlier = method
            .solve(&problem, options, initial())
            .map_err(|e| SciOxideError::from(e).to_string())?;
        last = earlier.report().last_method_switch();
    }
    switches.reverse();
    Ok((
        report,
        final_value,
        full.trajectory().times().to_vec(),
        switches,
    ))
}

## 方式の選び方

Rosenbrock-W 法は Newton 法の収束判定がなく、1 刻みの手間が段数で決まる。
次元が中程度で、Jacobian を解析的に書けるか差分で安く求められ、許容誤差が $10^{-3}$ から $10^{-6}$ 程度の剛性のある問題に向く。
3 次の ROS34PW2 は厳しい許容誤差では刻みが細かくなるので、その場合は 5 次の `RadauIia` か次数 5 までの `Bdf` のほうが刻みの数が少なくなることが多い。
剛性が区間の一部でだけ現れる問題、または剛性があるかどうか分からない問題では、`AutoStiff` か `AdamsBdf` で切り替える。
`AdamsBdf` は、BDF の刻みが大きくなると指標が下がりにくく、上の例では剛性の方式から戻らなかった。
質量行列 $M y' = f$ を持つ問題では、`RosenbrockW` は使えないので、`Bdf` か `RadauIia` を使う。
選び方の全体は[方式の選び方](../../choosing/)にまとめてある。

## まとめ

`RosenbrockW` は各段で行列 $I - h\gamma A$ の線形方程式を解き、1 刻みに LU 分解を 1 回だけ行う。
ROS2 と ROS34PW2 は W 法なので、近似した Jacobian でも $h \to 0$ での次数は 2 と 3 に保たれ、実験では $A = 0$ でも 3 次で収束した。
ただし $|h\lambda|$ が大きい領域の安定性は近似の良さで決まり、$\lambda = -10^3$ では $A = 0$ と $A = J/2$ が大きい刻みで発散した。
非自律系では `time_derivative` で $\partial f/\partial t$ を与え、自律系では 0 を返すと差分の評価が省ける。
`AutoStiff` と `AdamsBdf` は $|h|\rho(J)$ の推定値と棄却の回数で方式を切り替え、レポートには切り替えの回数と最後の 1 回が残る。
