株価、乱流中の粒子、熱雑音を受ける回路のように、決定論的な変化に不規則な揺らぎが加わる系は確率微分方程式（stochastic differential equation、SDE）で表される。
SDE の解は確率過程で、1 本の経路の値と、多くの経路にわたる期待値とでは、数値解法の誤差の意味が変わる。
このページでは SDE の二つの解釈（Itô と Stratonovich）、`scioxide-ode` の二つの解法、呼び出し側が与える Wiener 増分、強収束と弱収束、アンサンブルによる期待値の推定を説明する。
乱数の生成と Wiener 過程の経路の作り方は scioxide-random の[Brownian 橋過程による確率経路の階層的生成](../../../scioxide-random/examples/brownian-bridge/)で扱う。

## 確率微分方程式と Wiener 過程

`scioxide-ode` の SDE は

$$
dX = a(t, X)\,dt + B(t, X)\,dW
$$

である。
$X(t) \in \mathbb K^n$ は実数か複素数の状態、$a(t, X) \in \mathbb K^n$ はドリフト、$B(t, X)$ は $n \times m$ の拡散行列、$W$ は独立な成分を持つ $m$ 次元の実数の Wiener 過程である。
Wiener 過程は $W(0) = 0$ で、重ならない区間の増分が独立であり、増分 $W(t + h) - W(t)$ は平均 0、分散 $h$ の正規分布に従う。
経路は確率 1 で連続だが、どの点でも微分できず、$[0, T]$ を細かく分けた増分の 2 乗の和（2 次変分）は $T$ に収束する。

`SdeSystem` は状態の次元 $n$（`dimension`）、Wiener 過程の次元 $m$（`noise_dimension`）、ドリフト（`drift`）、拡散と増分の積 $B(t, X)\,\Delta W$（`diffusion_product`）を与える。
拡散は行列そのものではなく増分との積で与えるので、密、疎、行列を作らない形のどれでも書ける。
ただし積は増分について線形でなければならない。
クロージャで書く場合は `SdeFn::new(n, m, drift, diffusion_product)` を使う。
ドリフトの呼び出しは `RightHandSide`、拡散の呼び出しは `LinearOperator` の評価として数える。

## Itô 積分と Stratonovich 積分

$\int_0^T b(X)\,dW$ を区間の分割 $t_0 < t_1 < \dots < t_N$ の和で近似するとき、被積分関数を区間のどこで評価するかで極限が変わる。
Itô 積分は左端 $b(X(t_k))$ で、Stratonovich 積分 $\int b(X) \circ dW$ は区間の両端の平均 $\tfrac12\bigl(b(X(t_k)) + b(X(t_{k+1}))\bigr)$ で評価する。
二つの和の差は $\tfrac12 \sum_k \bigl(b(X(t_{k+1})) - b(X(t_k))\bigr)\Delta W_k$ で、$b(X(t_{k+1})) - b(X(t_k)) \approx b'(X)\,b(X)\,\Delta W_k$ と $\sum_k \Delta W_k^2 \to T$ から、差は 0 に収束しない。
したがって、同じ係数を書いても、Itô の方程式と Stratonovich の方程式は別の解を持つ。

Stratonovich の方程式 $dX = a\,dt + B \circ dW$ は、ドリフトを

$$
a_i^{\mathrm{I}} = a_i + \frac12 \sum_{j=1}^{m} \sum_{k=1}^{n} B_{kj}\,\frac{\partial B_{ij}}{\partial X_k}
$$

に替えた Itô の方程式と同じ解を持つ。
スカラーでは $a^{\mathrm I} = a + \tfrac12 b\,b'$ である。
Itô の方程式を Stratonovich の方程式として解くには、逆にドリフトから同じ項を引く。
$B$ が状態に依存しない加法的なノイズでは補正は 0 になり、二つの解釈は一致する。

Itô の解釈では確率積分の期待値が 0 になり（マルチンゲール）、統計や金融のモデルで自然に使われる。
Stratonovich の解釈では通常の連鎖律がそのまま成り立ち、滑らかなノイズの極限として得られる物理のモデルで自然に使われる。
どちらの解釈を使うかはモデルの一部であり、係数だけからは決まらない。

`SdeInterpretation` は `Ito` と `Stratonovich` の二つの値を持ち、`SdeMethod::interpretation` が解法の解釈を返す。
解法はドリフトを解釈の間で変換しないので、呼び出し側は選んだ解法の解釈に合わせたドリフトを与える。

## Euler–Maruyama 法と確率 Heun 法

刻み $h = t_{k+1} - t_k$ と増分 $\Delta W_k = W(t_{k+1}) - W(t_k)$ に対し、`SdeMethod` の二つの解法は次のとおりである。

$$
\begin{aligned}
&\text{Euler–Maruyama:} && X_{k+1} = X_k + h\,a(t_k, X_k) + B(t_k, X_k)\,\Delta W_k, \\
&\text{確率 Heun:} && \tilde X = X_k + h\,a(t_k, X_k) + B(t_k, X_k)\,\Delta W_k, \\
& && X_{k+1} = X_k + \tfrac{h}{2}\bigl(a(t_k, X_k) + a(t_{k+1}, \tilde X)\bigr) + \tfrac12\bigl(B(t_k, X_k) + B(t_{k+1}, \tilde X)\bigr)\Delta W_k
\end{aligned}
$$

`EulerMaruyama` は拡散を左端で評価するので Itô の方程式を解き、`StochasticHeun` は予測子と修正子で同じ増分を使って両端の平均を取るので Stratonovich の方程式を解く。
どちらも陽的な 1 段の方法で、Euler–Maruyama は 1 刻みあたりドリフトと拡散を 1 回ずつ、確率 Heun は 2 回ずつ評価する。
陽的なので、剛性のあるドリフトでは刻みを小さくしないと不安定になる。

## 強収束と弱収束

SDE の数値解の誤差には二つの尺度がある。
同じ Wiener 経路での解との差の期待値

$$
e_{\mathrm s}(h) = \mathbb E\,\lvert X(T) - X_N \rvert \le C h^{\gamma}
$$

が成り立つとき強次数 $\gamma$、滑らかな関数 $g$ の期待値の差

$$
e_{\mathrm w}(h) = \bigl\lvert \mathbb E\, g(X(T)) - \mathbb E\, g(X_N) \bigr\rvert \le C h^{\beta}
$$

が成り立つとき弱次数 $\beta$ と呼ぶ。
強次数は経路そのものの近さ（同じノイズでの模擬）、弱次数は分布や期待値の近さ（Monte Carlo 法の偏り）を表す。

係数が Lipschitz 連続で線形増大の条件と滑らかさの条件を満たすとき、Euler–Maruyama 法の強次数は 1/2、弱次数は 1 である。
確率 Heun 法の弱次数は 1 で、強次数はノイズがスカラー（$m = 1$）か可換なとき 1、一般には 1/2 である。
ノイズが可換であるとは、拡散行列の列 $b_j$ について $(\partial b_j/\partial X)\, b_l = (\partial b_l/\partial X)\, b_j$ がすべての $j, l$ で成り立つことをいう。
対角な拡散行列でも、各成分が他の成分に依存すれば可換とは限らない。
この条件は係数の性質であり、解法は確かめない。

強次数を測るには、同じ Wiener 経路で刻み幅だけを変えた解を比べる必要がある。
刻み数を変えるたびに新しい増分を作ると、別の経路の解を比べることになり、差には経路の違いが含まれる。
弱次数を測るには、多くの経路の平均で期待値を推定し、偏りと標本誤差を分けて読む。
標本平均の標準誤差は経路数 $M$ について $1/\sqrt M$ でしか減らないので、小さい偏りを見るには多くの経路が要る。

## Wiener 増分の与え方

`SdeProblem::new(system, times, increments)` は、時刻の格子 $t_0 < t_1 < \dots < t_N$ と増分の行列を組にする。
増分の行 $i$ は区間 $[t_i, t_{i+1}]$ の $W(t_{i+1}) - W(t_i)$、列 $j$ は Wiener 過程の成分 $j$ で、行列の形は $N \times m$ である。
ストライドのある `MatrixView` も渡せる。
解法は乱数を生成せず、経路を保存しない。
解法が確かめるのは形と値が有限であることだけで、増分が独立で分散 $t_{i+1} - t_i$ の正規分布に従うかは確かめない。
scioxide-random の `Normal` で $N(0, h)$ の値を作るか、`BrownianBridgePlan` で経路を作って差を取る。

`with_step_boundaries(boundaries)` は格子の番号の列で刻みの境目を指定する。
列は 0 で始まって $N$ で終わり、狭義に増加しなければならない。
隣り合う番号が離れていると、その刻みは間の区間の増分の和を使う。
これにより、細かい格子の 1 本の経路から粗い刻みの解を作り、同じ経路で刻み幅だけを変えた比較ができる。
逆に、粗い経路を細かくするには、両端の値を条件にした Brownian 橋で中間の値を作る。

`SdeOptions::with_refinement(tolerance)` は確率 Heun 法の刻みの細分化を有効にする。
各刻みを 1 刻みと、格子の中点で分けた 2 刻みで解き、二つの結果の正規化した差が 1 を超えれば両半分をさらに分け、1 以下なら 2 刻みの結果を受理する。
分けられない（格子の区間が 1 つしかない）刻みに当たると、積分は `StepSizeLimit` で止まる。
差は局所的な目安で、強誤差や弱誤差の上界ではない。
分けるかどうかをその刻みの増分で決めるので、受理する刻みは経路に依存し、2 次変分の標本化が偏る。
この偏りは Itô の解法の極限を変えるので、Euler–Maruyama 法に細分化を設定すると `InvalidInput` になる。
確率 Heun 法は細分化しても Stratonovich の解に収束する（Gaines and Lyons 1997）。

## Plan・作業領域・レポート

`SdeMethod` の値（`EulerMaruyama`、`StochasticHeun`）は、`workspace(problem, options)`、`advance(problem, options, state, sink, workspace, scope)`、`solve(problem, options, initial)` を持つ。
`advance` の状態 `OdeState` の時刻は格子の最初の時刻でなければならない。
受理した刻みごとに状態を更新して出力の出力先に送り、初期の状態は送らない。
`solve` は作業領域を作って逐次に実行し、`SdeSolution`（最終の状態とレポート）を返す。

`solve_sde(drift, diffusion_product, times, increments, y0)` は Euler–Maruyama 法で解き、初期値を含む全経路の行列（$(N + 1) \times n$）を返すワンショット関数である。
成功でない終了はエラーになり、エラーは `PartialFailure` に進捗の `SdeReport` を持つ。

`SdeOptions` は細分化、作業領域のバイト数の上限（`with_max_workspace_bytes`）、試行した刻みの上限（`with_max_steps`）、ドリフトと拡散の評価回数の上限（`with_max_evaluations`）を持つ。
`SdeMethod::workspace_requirements` が返す `SdeRequirements` は、状態とノイズの次元、作業用のメモリのバイト数（`required_bytes`）、上限（`byte_limit`）を持つ。
`SdeWorkspace` は刻みと細分化のメモリだけを持ち、乱数の状態や経路は持たない。
同じスカラー型の複数の問題で使い回せ、確保した最大の大きさを保つ。
作業領域が十分に大きく、コールバックと出力の出力先が確保しなければ、`advance` はメモリを確保しない。

`SdeTermination` の `ReachedEnd` だけが成功である。
`BudgetLimit` は計算回数の上限への到達、`StepSizeLimit` は細分化に必要な細かい格子がないこと、`ExecutionStopped` は取り消しか期限を表す。
`TerminalEvent` は SDE に事象がないので生じない。
`SdeReport` は終了状態、最後に受理した時刻と格子の番号（`grid_index`）、受理と棄却の刻みの数、評価回数、細分化の最後の判定の差（`last_step_error_estimate`）を持つ。
`trust` は受理した状態の扱いを表し、精度の証明ではない。

## 期待値の推定と二つの解釈

多くの経路の平均で期待値を推定するには、経路ごとに独立な増分を与えて同じ SDE を解く。
`solve_ensemble_into` は経路ごとの計算を一つの解法の下で実行し、経路ごとの終了状態を残す（[前進感度とアンサンブル](../forward-sensitivities-and-ensembles/)）。

例として、平均へ戻るドリフトと比例するノイズを持つ

$$
dX = (\alpha - \beta X)\,dt + \sigma X\,dW, \qquad X(0) = x_0
$$

を考える（金利の Brennan–Schwartz モデルと同じ形）。
Itô の解釈では、期待値 $m(t) = \mathbb E X(t)$ は $m' = \alpha - \beta m$ を満たし、

$$
m_{\mathrm I}(T) = \frac{\alpha}{\beta} + \left(x_0 - \frac{\alpha}{\beta}\right) e^{-\beta T}
$$

である。
Stratonovich の解釈では、ドリフトの補正 $+\tfrac12\sigma^2 X$ で $\kappa = \beta - \sigma^2/2$ に置き換わり、

$$
m_{\mathrm S}(T) = \frac{\alpha}{\kappa} + \left(x_0 - \frac{\alpha}{\kappa}\right) e^{-\kappa T}
$$

になる。
離散化の偏りも閉形式で書ける。
Euler–Maruyama 法では $\mathbb E[\sigma X_k \Delta W_k] = 0$ なので、平均は $m_{k+1} = m_k + h(\alpha - \beta m_k)$ に従う。
確率 Heun 法では $\mathbb E[\tilde X \Delta W_k] = \sigma m_k h$ から、平均は

$$
m_{k+1} = m_k + h\left(1 - \frac{\beta h}{2}\right)(\alpha - \beta m_k) + \frac{\sigma^2 h}{2}\, m_k
$$

に従う。
この離散の平均と連続の期待値の差が弱誤差（偏り）で、標本平均と離散の平均の差が標本誤差である。

次のセルは $\alpha = 1$、$\beta = 1$、$x_0 = 0.5$、$T = 2$ とし、$M$ 本の経路の増分を scioxide-random の `Normal` と `SplitMix64` で一度に作る。
両方の解法に同じ増分と共有のパラメータ $(\alpha, \beta, \sigma)$ を渡し、`solve_ensemble_into` で経路ごとに解く。
メンバーは経路ごとの作業領域と終端の値を持ち、各経路の解法には `run` が受け取る入れ子のコンテキスト `cx` を渡す。
表はアンサンブルのレポート（実行した経路、成功した経路、評価回数）を示し、解法ごとの標本平均と標準誤差（SE）を次のセルに渡す。

```rust
//| run: button
//| cache: inputs

//|   seed: {"type":"range","label":"乱数のシード","min":1,"max":1000,"step":1,"value":42}
//| cases:
//|   - {"id":"additive-limit","label":"σ = 0","description":"ノイズがなく、二つの解法の平均が同じ ODE の解に近づく。","inputs":{"noise":0}}
//|   - {"id":"coarse","label":"N = 4","description":"刻みが粗く、偏りが標準誤差より大きくなる。","inputs":{"steps":4}}
//|   - {"id":"other-seed","label":"シード 7","description":"別の経路の集合の標本平均。","inputs":{"seed":7}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"ensemble","path":"/rows/0/2","equals":2000}
//|       - {"artifact":"ensemble","path":"/rows/1/3","equals":128000}
//|       - {"path":"/outputs/1/state","equals":"satisfied"}

    EvaluationRole, ExecutionContext, ExecutionPolicy, SciOxideError, RealScalar, SolveContext,
};
use scioxide_linalg::MatrixView;
use scioxide_ode::{
    EnsembleParameters, EnsembleWorkspace, OdeState, SdeFn, SdeMethod, SdeOptions, SdeProblem,
    SdeReport, SdeWorkspace, solve_ensemble_into,
};
use scioxide_random::{Distribution, Normal, SeedableRng, SplitMix64};

let (n, m, horizon) = (steps.round() as usize, paths.round() as usize, 2.0_f64);
let h = horizon / n as f64;

let normal = Normal::new(0.0, RealScalar::sqrt(h)).map_err(|e| e.to_string())?;
let mut rng = SplitMix64::from_seed(seed.round() as u64);

    .map(|_| normal.sample(&mut rng))
    .collect::<Result<_, SciOxideError>>()
    .map_err(|e| e.to_string())?;
// 全経路が共有するパラメータ p = (α, β, σ)。dX = (α − βX) dt + σX dW、X(0) = 0.5。

let (mut rows, mut means, mut errors) = (Vec::new(), Vec::new(), Vec::new());
for method in [SdeMethod::EulerMaruyama, SdeMethod::StochasticHeun] {
    let run = |i: usize, p: &[f64], member: &mut Member, cx: &mut SolveContext<'_, '_>| {
        let (a, b, s) = (p[0], p[1], p[2]);
        let drift = move |_: f64, x: &[f64], out: &mut [f64]| {
            out[0] = a - b * x[0];
            Ok(())
        };
        let diffusion = move |_: f64, x: &[f64], dw: &[f64], out: &mut [f64]| {
            out[0] = s * x[0] * dw[0];
            Ok(())
        };
        let system = SdeFn::<f64, _, _>::new(1, 1, drift, diffusion);
        let view = MatrixView::from_slice(n, 1, &increments[i * n..(i + 1) * n])?;
        let problem = SdeProblem::new(&system, &times, view);
        let mut state = OdeState::from_slice(0.0, &[0.5])?;
        let report =
            method.advance(&problem, &options, &mut state, &mut (), &mut member.0, cx)?;
        member.1 = state.values()[0];
        Ok(report)
    };
    let mut members: Vec<Member> = (0..m).map(|_| (SdeWorkspace::new(), 0.0)).collect();
    let mut outcomes: Vec<Option<Result<SdeReport<f64>, SciOxideError>>> =
        (0..m).map(|_| None).collect();
    let mut workspace = EnsembleWorkspace::new();
    let shared = EnsembleParameters::Shared(&parameters);
    let policy = ExecutionPolicy::Sequential;
    let cx = ExecutionContext::sequential();
    let report = solve_ensemble_into(
        shared,
        &run,
        policy,
        &mut members,
        &mut outcomes,
        &mut workspace,
        cx,
    )
    .map_err(|e| e.to_string())?;
    let mean = members.iter().map(|x| x.1).sum::<f64>() / m as f64;
    let variance = members.iter().map(|x| (x.1 - mean).powi(2)).sum::<f64>() / (m - 1) as f64;
    means.push(mean);
    errors.push(RealScalar::sqrt(variance / m as f64));
    let work = report.accounting().nested();
    rows.push((
        format!("{method:?}"),
        report.completed(),
        report.successful(),
        work.provider(EvaluationRole::RightHandSide),
        work.provider(EvaluationRole::LinearOperator),
    ));
}

]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "ensemble" })
);
let (outcome, status) = if successful {
    (Outcome::satisfied("全経路が終端に達した"), "ReachedEnd")
} else {
    (
        Outcome::partial("終端に達しなかった経路がある"),
        "一部が未完了",
    )
};
emit_outcome!(outcome.status(status).diagnostic("経路数", m as f64, None));
```

既定値では二つの解法とも 2000 本の経路がすべて `ReachedEnd` に達する。
Euler–Maruyama 法は 1 刻みあたりドリフトと拡散を 1 回ずつ評価するので、評価は $32 \times 2000 = 64000$ 回ずつ、確率 Heun 法はその 2 倍の 128000 回ずつである。

次のセルは上のセルの標本平均と SE を、連続の期待値と離散の平均の閉形式と比べる。
表は標本平均、SE、離散の平均、連続の期待値、偏り（離散の平均 − 連続の期待値）、標本平均と離散の平均の差を SE で割った $z$ を示す。
増分が正しく作られていれば $z$ は標準正規分布に近い分布に従い、$|z| > 3$ は増分の誤りか経路数の不足を疑う目安になる。
グラフは標本平均の 95% 信頼区間（±1.96 SE）と、二つの解釈の期待値の線である。

```rust
//| id: ode-sde-ensemble-mean
//| ref: ode-sde-ensemble-mean
//| title: 同じ係数の SDE の期待値を二つの解釈の理論値と比べる
//| run: reactive
//| crates: [scioxide-ode]
//| dependsOn:
//|   ensemble: ode-sde-ensemble-run
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"means","path":"/rows/0/5","approx":{"value":0.932332,"atol":1e-6}}
//|       - {"artifact":"means","path":"/rows/1/5","approx":{"value":1.221476,"atol":1e-6}}
//|       - {"artifact":"means","path":"/rows/0/7","range":{"min":-3,"max":3}}
//|       - {"artifact":"means","path":"/rows/1/7","range":{"min":-3,"max":3}}
use scioxide_ode::SdeMethod;

let fixed2 = serde_json::json!({ "fractionDigits": 2 });
let fixed6 = serde_json::json!({ "fractionDigits": 6 });
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let read = |key: &str| serde_json::from_value::<Vec<f64>>(ensemble[key].clone());
let means = read("means").map_err(|e| e.to_string())?;
let errors = read("standard_errors").map_err(|e| e.to_string())?;
let noise = ensemble["noise"].as_f64().ok_or("σ がない")?;
let n = ensemble["steps"].as_u64().ok_or("刻み数がない")? as usize;
let (alpha, beta, start, horizon) = (1.0_f64, 1.0_f64, 0.5_f64, 2.0_f64);
let h = horizon / n as f64;
let kappa = beta - noise * noise / 2.0;
// 連続の期待値（閉形式）: Itô は m' = α − βm、Stratonovich は m' = α − κm。
let mean_of = |rate: f64| alpha / rate + (start - alpha / rate) * (-rate * horizon).exp();
let mut rows = Vec::new();
let mut bars = Vec::new();
for (k, method) in [SdeMethod::EulerMaruyama, SdeMethod::StochasticHeun]
    .into_iter()
    .enumerate()
{
    // 離散の平均の漸化式（1 刻みの平均の閉形式）を N 回たどる。
    let mut scheme = start;
    for _ in 0..n {
        let drift = alpha - beta * scheme;
        scheme += match method {
            SdeMethod::EulerMaruyama => h * drift,
            _ => h * (1.0 - beta * h / 2.0) * drift + noise * noise * h / 2.0 * scheme,
        };
    }
    let theory = mean_of(if k == 0 { beta } else { kappa });
    let (mean, se) = (means[k], errors[k]);
    // σ = 0 では全経路が同じで SE が丸め誤差の水準になり、z は意味を持たない。
    let z = (se > 1e-12).then(|| (mean - scheme) / se);
    rows.push((
        format!("{method:?}"),
        format!("{:?}", method.interpretation()),
        mean,
        se,
        scheme,
        theory,
        scheme - theory,
        z,
    ));
    bars.push([(k + 1) as f64, mean, mean - 1.96 * se, mean + 1.96 * se]);
}
let ito = serde_json::json!({
    "kind": "line",
    "axis": "y",
    "value": mean_of(beta),
    "label": "Itô の E[X(T)]"
});
let stratonovich = serde_json::json!({
    "kind": "line",
    "axis": "y",
    "value": mean_of(kappa),
    "label": "Stratonovich の E[X(T)]",
    "style": { "lineType": "dashed" }
});
emit_chart!(serde_json::json!({
    "kind": "errorbar",
    "xLabel": "解法（1: Euler–Maruyama、2: 確率 Heun）[-]",
    "yLabel": "E[X(T)] の推定 [-]",
    "xMin": 0.5,
    "xMax": 2.5,
    "series": [{ "name": "標本平均 ±1.96 SE", "points": bars }],
    "annotations": [ito, stratonovich]
}));
let columns = serde_json::json!([
    { "key": "0", "label": "解法" },
    { "key": "1", "label": "解釈" },
    { "key": "2", "label": "標本平均 [-]", "type": "number", "format": fixed6 },
    { "key": "3", "label": "SE [-]", "type": "number", "format": sci2 },
    { "key": "4", "label": "離散の平均 [-]", "type": "number", "format": fixed6 },
    { "key": "5", "label": "連続の期待値 [-]", "type": "number", "format": fixed6 },
    { "key": "6", "label": "偏り [-]", "type": "number", "format": sci2 },
    { "key": "7", "label": "z [-]", "type": "number", "format": fixed2, "nullText": "SE = 0" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "means" })
);
```

既定値（$\sigma = 0.8$、$N = 32$、$M = 2000$、シード 42）では、Euler–Maruyama 法の標本平均 $0.913 \pm 0.024$（±1.96 SE）は Itô の期待値 0.9323 を含み、確率 Heun 法の標本平均 $1.196 \pm 0.033$ は Stratonovich の期待値 1.2215 を含む。
二つの期待値の差 0.29 は SE の約 20 倍で、同じ係数でも解釈によって別の方程式になることが標本平均で確かめられる。
偏りは Euler–Maruyama 法で $4.3 \times 10^{-3}$、確率 Heun 法で $7.6 \times 10^{-3}$ で、どちらも SE（0.012 と 0.017）より小さい。
二つの $z$ がどちらも $-1.94$ 付近にあるのは、同じ増分を両方の解法に渡したので、標本誤差が強く相関するためである。
$N = 4$ にすると偏りは 0.036 と 0.050 に増えて SE の 2〜3 倍になり、$N = 128$ では 0.0011 と 0.0019 に減る。
$h$ を 1/32 にすると偏りは 1/34 と 1/26 になり、どちらの解法も弱次数 1 の振る舞いを示す。
$\sigma = 0$ では全経路が同じ ODE の解になり、SE は丸め誤差の水準なので $z$ を表示しない。
このとき確率 Heun 法の偏り $-9.2 \times 10^{-5}$ は Euler–Maruyama 法の $4.3 \times 10^{-3}$ よりずっと小さく、決定論的な Heun 法の 2 次の精度が現れる。

## まとめ

SDE の解は Itô と Stratonovich のどちらの解釈で読むかで変わり、`scioxide-ode` では解法が解釈を決める（`EulerMaruyama` は Itô、`StochasticHeun` は Stratonovich）。
解法はドリフトを変換しないので、解釈を変えるときは $\tfrac12 \sum B\,\partial B$ の補正をドリフトに加えるか引く。
Wiener 増分は呼び出し側が `SdeProblem` に与え、`with_step_boundaries` で同じ経路から粗い刻みの解を作れる。
強次数は同じ経路での刻みの比較で、弱次数は多くの経路の平均で測り、期待値の推定では偏りと標本誤差（SE）を分けて読む。
細分化は確率 Heun 法だけに使え、受理した刻みの差は誤差の上界ではない。
