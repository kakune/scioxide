このページの表は2 点境界値問題 $y' = f(x, y, p)$（$a \le x \le b$）、$g(y(a), y(b), p) = 0$ を選点法で解く型をまとめる。
$y$ は $n$ 成分の状態、$p$ は $k$ 個の未知のパラメータ、$g$ は $n + k$ 成分の境界条件で、区間 $[a, b]$ は Plan の節点の列の範囲である。
各区間で 3 段の Lobatto IIIA（Simpson）の選点方程式を立て、節点の値と $p$ を減衰 Newton 法で解き、解を節点で 4 次の精度の $C^1$ の区分 3 次 Hermite 補間として返す。
区間ごとの残差 $u' - f(x, u, p)$ の大きさで節点を足し、許容誤差を満たすまで解き直す。
許容誤差を満たさずに止まった解も `Ok` で返り、`BvpTermination` が唯一の成否の判定になる。
入力の誤り、数値計算の失敗、外側の solve の上限や取り消しによる停止は `Err` になる。
