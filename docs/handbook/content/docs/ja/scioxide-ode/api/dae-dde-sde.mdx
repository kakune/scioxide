このページの表は`OdeSystem` とは別の問題の型を持つ時間発展の解法をまとめる。
どの解法も、積分法オブジェクトか Plan に問題、設定、呼び出し側が所有する状態、出力の出力先、作業領域を渡して実行する。
試行・評価の上限、取り消し、期限で止まった場合も `Ok` のレポートが返り、レポートの終了状態が唯一の成否の判定になる。
エラーで終わった呼び出しでは、状態に最後に受理した点が残り、作業領域の `last_attempt()` と所有値を返す API の `solve` の `PartialFailure` が進捗を持つ。
