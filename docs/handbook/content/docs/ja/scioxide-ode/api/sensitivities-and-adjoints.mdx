このページの表は解のパラメータと初期値に関する微分と、パラメータを変えた独立な問題の実行をまとめる。
前進感度はパラメータの方向ごとに状態と同じ大きさの方程式を加えた拡大系を、初期値問題の方式で積分する。
随伴法は前進の積分とチェックポイントからの再計算と逆向きの掃引で、スカラーの目的関数の勾配を求める。
随伴法の勾配は成功したときだけ書かれ、失敗では出力を変えない。
