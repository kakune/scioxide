このページの表は初期値問題 $M y' = f(t, y)$、$y(t_0) = y_0$ を解く型をまとめる。
$t$ は実数の時刻、$y$ は $n$ 成分の実数か複素数の状態、$M$ は正則な定数の質量行列（既定は単位行列）である。
`OdeMethod::advance` は `Result<OdeSolveReport, SciOxideError>` を返す。
試行・評価の上限、最小の刻み幅、取り消し、期限で止まった場合も `Ok` のレポートが返り、レポートの終了状態が唯一の成否の判定になる。
エラーで終わった呼び出しは作業領域の `last_attempt()` に最後に受理した点までの進捗を残す。

## 出力・レポート・失敗

連続出力は方式が受理した刻みの中で作り、公開型は持たない。
`OdeOutputSchedule::Times` で時刻を指定すると、出力先は `emit_requested` で時刻の位置とその時刻の値を受け取る。
連続出力のない方式に時刻を指定すると、コールバックを呼ぶ前に `InvalidInput` で拒まれる。
