このページの表は`OdeMethod` を実装する積分法オブジェクトと、陰的な方式の段の方程式を解く部品をまとめる。
積分法オブジェクトは係数と方式に固有の設定だけを持ち、次元に依存するメモリは作業領域に置く。
方式ごとに、局所誤差の推定で刻み幅を変える適応刻みか、与えた刻み幅で進む固定刻みかが決まり、連続出力・事象・質量行列への対応も異なる（[方式の選び方](../../choosing/)）。
固定刻みの方式はすべての刻みを `OdeOptions::with_initial_step` の値（なければ推定した初期刻み）で進め、最後の刻みだけを終端に合わせて短くする。
方式が対応しない機能を設定すると、積分を始める前に `InvalidInput`（`UnsupportedConfiguration`）で拒まれる。
陰的な方式の段の解法の失敗は適応刻みの方式では刻みを半分にしたやり直しになり、固定刻みの方式ではそのままエラーになる。
