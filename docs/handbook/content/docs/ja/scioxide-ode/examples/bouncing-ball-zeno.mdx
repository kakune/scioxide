床で跳ねるボールは、滑らかな運動方程式と、接地の瞬間に速度を不連続に変える規則を組み合わせた系である。
跳ねるたびに速さが一定の割合で減るので、跳ねる間隔は等比数列になり、無限回の接地が有限の時刻に集まる。
このページでは接地を終端の事象にして積分を止め、速度を反転して再開する手順を `DormandPrince5` で繰り返し、接地の時刻を閉形式と比べる。
解が時間の 2 次式なので積分の誤差はなく、時刻の誤差は事象の時刻の許容誤差から来る。
跳ねる間隔がその許容誤差や浮動小数点数の間隔より短くなると、計算は接地を見逃すか、時刻が進まなくなる。

## 自由落下と反発

高さを $y$ [m]、上向きの速度を $v$ [m/s]、重力加速度を $g = 9.81$ m/s² とすると、空中の運動は

$$
y' = v, \qquad v' = -g
$$

である。
高さ $h_0$ から静かに落とすと、最初の接地の時刻と速さは

$$
t_1 = \sqrt{\frac{2 h_0}{g}}, \qquad v_1 = g t_1 = \sqrt{2 g h_0}
$$

である。
接地の直前の速度を $v^-$ とすると、直後の速度は $v^+ = -e v^-$ で、$0 < e < 1$ を反発係数という。
$n$ 回目の接地の後の上向きの速さは $e^n v_1$ で、次の接地までの時間は $2 e^n v_1 / g$ である。
したがって接地の時刻は

$$
t_{n+1} = t_n + \frac{2 e^n v_1}{g}
$$

を満たし、等比級数の和から

$$
t_n = t_1 + \frac{2 e v_1}{g} \cdot \frac{1 - e^{n-1}}{1 - e}, \qquad
t_\infty = \lim_{n \to \infty} t_n = t_1 + \frac{2 e v_1}{g (1 - e)}
$$

となる。
$t_\infty$ より前に接地は無限回起こる。
有限の時刻に無限個の事象が集まることを Zeno 現象という。
実際のボールは $t_\infty$ で床に静止するが、上のモデルは $t_\infty$ から先の運動を定めない。

## 接地での停止と再開

接地は事象関数 $g_{\mathrm{ev}}(t, y, v) = y$ が正から 0 以下へ変わる点である。
`EventFn::new(|_, s| Ok(s[0]))` に `EventDirection::Falling` と `with_terminal(true)` を付けると、積分は接地の時刻で止まる。
止まった時刻と状態は `OdeState` に入り、`OdeSolveReport::termination` は `TerminalEvent` を返す。
状態の $v$ を $-e v$ に替えて `OdeState::reset` で同じ時刻から再開する。
開始時刻で $g_{\mathrm{ev}} = 0$ になる点は事象として数えないので、接地した直後に同じ事象で止まることはない（[連続出力と事象の検出](../../algorithms/dense-output-and-events/)）。
同じ作業領域（`OdeWorkspace`）を、すべての再開で使い回す。

事象の時刻は、受理した刻みの連続出力の上で、Alefeld–Potra–Shi の囲い込み法（TOMS 748）で求める。
`OdeEventOptions::with_localization` は、時刻の許容誤差（`StepTolerance`）と反復の上限を与える。
既定の許容誤差は絶対・相対とも $4\varepsilon$（$\varepsilon$ は `f64` の機械イプシロン）である。

`DormandPrince5` の 1 刻みは、解が時間の 2 次式なら丸め誤差を除いて厳密で、連続出力（4 次の補間）も 2 次式を厳密に再現する。
そのため事象の時刻の誤差は、根を囲む区間の幅、つまり時刻の許容誤差で決まる。
求めた時刻が $\delta t$ ずれると、接地の速度は $g\,\delta t$ ずれ、次の飛行時間 $2e\lvert v \rvert/g$ も $2e\,\delta t$ ずれる。
接地の状態の高さ $y$ も厳密な 0 ではなく、$\lvert v \rvert \delta t$ 程度の値が残る。
次のセルはこの高さを 0 に戻さずにそのまま再開に使う。

## Zeno 現象と計算の破綻

$n$ が大きくなると、飛行時間 $2 e^n v_1/g$ は時刻の許容誤差や $t$ の近くの浮動小数点数の間隔（$t \approx 4$ s で約 $8.9 \times 10^{-16}$ s）に近づく。
そうなると次のどちらかが起こる。

- 接地で残った高さが負なら、再開後のボールは床の下から上がって下がる。
  上向きと下向きの横断が同じ刻みに入ると、刻みの両端の符号が同じなので事象は見つからず、ボールは床を通り抜ける。
- 時刻の許容誤差が飛行時間より大きいと、求めた接地の時刻が進まなくなり、同じ時刻で接地を繰り返す。

どちらもモデルではなく計算の限界から生じる。
実用上は跳ね返りの速さがある値を下回ったら静止した状態のモデルに切り替える。

次のセルは、反発係数 $e$、初期の高さ $h_0$、事象の時刻の許容誤差、接地の回数の上限を選び、上の手順で接地を繰り返す。
許容誤差の選択肢の「既定（4ε）」は `OdeEventOptions::new()` の値を使う。
それ以外の選択肢は時刻の絶対許容誤差を選んだ値にし、相対許容誤差を 0 にする。
各区間の終端は $2 t_\infty$ とし、接地が見つからずに終端に達したら、その時点で止める。
接地の時刻が前の接地の時刻から進まなかったときも止める。

表は見つけた接地の回数、最後の区間の終了状態、求めた時刻と閉形式 $t_n$ の差の最大、$t_\infty$、評価回数の合計を示す。
差がちょうど 0 の接地の数も示す。
このセルは最初の 30 回の飛行の高さ、接地ごとの時刻の差と飛行時間を次のセルに渡す。

```rust
//| id: ode-bouncing-ball
//| ref: ode-bouncing-ball
//| title: 接地で止めて速度を反転し、接地の時刻を閉形式と比べる
//| run: reactive
//| crates: [scioxide-core, scioxide-linalg, scioxide-ode]
//| exports: [height, errors, flights, limit_time, localization_time]
//| inputs:
//|   restitution: {"type":"range","label":"反発係数 e [-]","description":"跳ねる間隔が縮む割合。","min":0.5,"max":0.95,"step":0.05,"value":0.8}
//|   drop_height: {"type":"range","label":"初期の高さ h₀ [m]","min":0.5,"max":10,"step":0.5,"value":1}
//|   localization: {"type":"select","label":"事象の時刻の許容誤差 [s]","description":"既定は絶対・相対とも 4ε。","options":["既定（4ε）","1e-12","1e-9","1e-6","1e-3"],"value":"既定（4ε）"}
//|   max_bounces: {"type":"range","label":"接地の回数の上限","min":10,"max":200,"step":10,"value":60}
//| cases:
//|   - {"id":"loose-localization","label":"許容誤差 10⁻⁶ s","description":"時刻の差が 10⁻⁶ s 程度に増え、跳ねる間隔が縮むと時刻が進まなくなる。","inputs":{"localization":"1e-6","max_bounces":200}}
//|   - {"id":"many-bounces","label":"接地 200 回","description":"既定の許容誤差でも、飛行時間が 10⁻¹¹ s を下回るころに接地を見逃す。","inputs":{"max_bounces":200}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"summary","path":"/rows/0/0","equals":60}
//|       - {"artifact":"summary","path":"/rows/0/2","range":{"max":1e-13}}
//|       - {"path":"/outputs/1/state","equals":"satisfied"}
//|   - case: loose-localization
//|     expect:
//|       - {"artifact":"summary","path":"/rows/0/2","range":{"min":1e-7,"max":1e-4}}
//|       - {"path":"/outputs/1/state","equals":"partial"}
//|   - case: many-bounces
//|     expect:
//|       - {"artifact":"summary","path":"/rows/0/1","equals":"ReachedEnd"}
//|       - {"path":"/outputs/1/state","equals":"partial"}
use scioxide_core::{Budget, EvaluationRole, StepTolerance};
use scioxide_linalg::Vector;
use scioxide_ode::{
    DormandPrince5, EventDirection, EventFn, EventFunction, OdeEventOptions, OdeFn, OdeMethod,
    OdeOptions, OdeOutputSchedule, OdeProblem, OdeState, OdeTermination, OdeTrajectory,
};

let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let digits12 = serde_json::json!({ "significantDigits": 12 });
let (e, gravity) = (restitution, 9.81);
let falling = OdeFn::new(2, move |_: f64, s: &[f64], f: &mut [f64]| {
    f[0] = s[1];
    f[1] = -gravity;
    Ok(())
})
.map_err(|err| err.to_string())?;
let ground = EventFn::new(|_: f64, s: &[f64]| Ok(s[0]))
    .with_direction(EventDirection::Falling)
    .with_terminal(true);
let events: [&dyn EventFunction<f64>; 1] = [&ground];
// 閉形式: t₁ = √(2h₀/g)、v₁ = g t₁、t∞ = t₁ + 2e v₁ / (g(1 − e))。
let t1 = (2.0 * drop_height / gravity).sqrt();
let v1 = gravity * t1;
let t_inf = t1 + 2.0 * e * v1 / (gravity * (1.0 - e));
let (event_options, absolute) = match localization.as_str() {
    "既定（4ε）" => (OdeEventOptions::new(), 4.0 * f64::EPSILON),
    text => {
        let tol: f64 = text.parse().map_err(|_| "許容誤差を読めない")?;
        let step = StepTolerance::new(tol, 0.0).map_err(|err| err.to_string())?;
        let limit = Budget::try_from(64).map_err(|err| err.to_string())?;
        (OdeEventOptions::new().with_localization(step, limit), tol)
    }
};
let problem = OdeProblem::new(&falling, 2.0 * t_inf).with_events(&events);
let method = DormandPrince5::new();
let base = OdeOptions::new().with_event_options(event_options);
let mut workspace = method
    .workspace(&problem, &base)
    .map_err(|err| err.to_string())?;
let mut state = OdeState::new(0.0, Vector::from_vec(vec![drop_height, 0.0]));

let (mut height, mut errors, mut flights) = (Vec::new(), Vec::new(), Vec::new());
let (mut exact, mut previous, mut bounces, mut exact_hits) = (t1, 0.0, 0_usize, 0_usize);
let (mut max_error, mut rhs, mut event_calls) = (0.0_f64, 0, 0);
let mut last = OdeTermination::ReachedEnd;
for n in 1..=max_bounces as usize {
    // 最初の 30 回の飛行は 16 等分した時刻で描く（終端の事象の後の時刻は出力されない）。
    let flight = if n == 1 {
        t1
    } else {
        2.0 * state.values()[1].abs() / gravity
    };
    let schedule = if n <= 30 {
        let start = state.time();
        let times = (1..=16).map(|k| start + flight * f64::from(k) / 16.0);
        OdeOutputSchedule::times(times.filter(|&t| t < 2.0 * t_inf).collect())
    } else {
        OdeOutputSchedule::FinalOnly
    };
    let options = base.clone().with_output_schedule(schedule);
    let mut path = OdeTrajectory::new();
    let report = method
        .advance(
            &problem,
            &options,
            &mut state,
            &mut path,
            &mut workspace,
            scioxide_core::ExecutionContext::sequential(),
        )
        .map_err(|err| err.to_string())?;
    rhs += report.counts().provider(EvaluationRole::RightHandSide);
    event_calls += report.event_search().map_or(0, |s| s.evaluations());
    last = report.termination().ok_or("終了状態がない")?;
    if n <= 30 {
        let points = path.times().iter().zip(path.states());
        height.extend(points.map(|(&t, s)| [t, s.as_slice()[0]]));
    }
    if last != OdeTermination::TerminalEvent || state.time() <= previous {
        break;
    }
    bounces = n;
    previous = state.time();
    // 独立な検算: 閉形式 t_n との差。
    let gap = (state.time() - exact).abs();
    max_error = max_error.max(gap);
    if gap > 0.0 {
        errors.push([n as f64, gap]);
    } else {
        exact_hits += 1;
    }
    flights.push([n as f64, 2.0 * e.powi(n as i32) * v1 / gravity]);
    exact += 2.0 * e.powi(n as i32) * v1 / gravity;
    // 速度を反転し、事象の状態から再開する（高さは 0 に戻さない）。
    let (t, y, v) = (state.time(), state.values()[0], state.values()[1]);
    state
        .reset(t, &[y, -e * v])
        .map_err(|err| err.to_string())?;
}
export!(height, height);
export!(errors, errors);
export!(flights, flights);
export!(limit_time, t_inf);
export!(localization_time, absolute);
let columns = serde_json::json!([
    { "key": "0", "label": "見つけた接地の回数", "type": "integer" },
    { "key": "1", "label": "最後の区間の終了状態" },
    { "key": "2", "label": "時刻の差の最大 [s]", "type": "number", "format": sci2 },
    { "key": "3", "label": "差が 0 の接地", "type": "integer" },
    { "key": "4", "label": "最後の接地の時刻 [s]", "type": "number", "format": digits12 },
    { "key": "5", "label": "t∞ [s]", "type": "number", "format": digits12 },
    { "key": "6", "label": "右辺の評価", "type": "integer" },
    { "key": "7", "label": "事象関数の評価", "type": "integer" }
]);
emit_table_with_columns!(
    columns,
    vec![(
        bounces,
        last.to_string(),
        max_error,
        exact_hits,
        previous,
        t_inf,
        rhs,
        event_calls,
    )],
    metadata = serde_json::json!({ "id": "summary" })
);

let outcome = if bounces == max_bounces as usize {
    Outcome::satisfied(format!("{bounces} 回の接地をすべて見つけた"))
} else if last == OdeTermination::TerminalEvent {
    Outcome::partial(format!("{} 回目の接地で時刻が進まなくなった", bounces + 1))
        .explanation("飛行時間が時刻の許容誤差より短くなった。")
} else {
    Outcome::partial(format!(
        "{} 回目の接地を見つけずに区間の終端に達した",
        bounces + 1
    ))
    .explanation("ボールが床を通り抜けた。最後の区間の値はモデルの解ではない。")
};
emit_outcome!(
    outcome
        .status(last.to_string())
        .diagnostic("時刻の差の最大", max_error, Some("s"))
        .diagnostic("見つけた接地の回数", bounces as f64, None)
);
```

既定値（$e = 0.8$、$h_0 = 1$ m、許容誤差 $4\varepsilon$、上限 60 回）では、$t_1 = 0.4515$ s、$t_\infty = 4.0637128$ s で、60 回の接地をすべて見つけた。
求めた時刻と閉形式の差の最大は $9.8 \times 10^{-15}$ s で、$t \approx 4$ s の浮動小数点数の間隔の約 11 倍である。
差がちょうど 0 の接地が 6 回あり、残りの差は丸め誤差の積み重ねの大きさである。
60 回の接地で右辺の評価は 1074 回、事象関数の評価は 973 回で、1 回の飛行は 2〜7 刻みで済む。

時刻の許容誤差を $10^{-12}$、$10^{-9}$、$10^{-6}$、$10^{-3}$ s にすると、差の最大は $5.4 \times 10^{-13}$、$1.0 \times 10^{-9}$、$2.1 \times 10^{-6}$、$3.4 \times 10^{-3}$ s になり、許容誤差の 0.5〜3.4 倍にとどまる。
積分の誤差はないので、差は事象の局在化から来て、再開のたびに次の飛行に引き継がれる。
許容誤差 $10^{-6}$ s で上限を 200 回にすると、62 回目までは見つかるが、63 回目の接地の時刻は前の接地から進まなくなる。
62 回目の接地の後の飛行時間は約 $9 \times 10^{-7}$ s で、許容誤差 $10^{-6}$ s を下回っている。

既定の許容誤差で上限を 200 回にすると、124 回目までの差は $1.3 \times 10^{-14}$ s 以下だが、125 回目の接地は見つからず、ボールは床を通り抜けて $2 t_\infty$ に達する（`ReachedEnd`）。
124 回目の接地の後の飛行時間は約 $9 \times 10^{-13}$ s で、前の節で述べたように、上向きと下向きの横断が同じ刻みに入って事象が見つからない。
最後の区間の終了状態 `ReachedEnd` は成功の状態だが、この区間の値はモデルの解ではない。
$e = 0.5$ では間隔が速く縮み、40 回目の接地で同じことが起こる。

## 接地の時刻の誤差と飛行時間

次のセルは上のセルの結果を受け取って描く。
上の図は高さ $y(t)$ で、最初の 30 回の飛行を連続出力で描き、$t_\infty$ を縦の破線で示す。
下の図は接地の回数 $n$ ごとに、求めた時刻と閉形式 $t_n$ の差の絶対値（記号）と、次の飛行時間 $2e^n v_1/g$（線）を対数軸で描く。
横の破線は時刻の絶対許容誤差で、差がちょうど 0 の接地は対数軸に描けないので除く。

既定値では、下の図の時刻の差は $1.1 \times 10^{-16}$ s から $9.8 \times 10^{-15}$ s までに散らばり、横の破線 $4\varepsilon \approx 8.9 \times 10^{-16}$ s の上下にある。
既定の許容誤差には相対許容誤差 $4\varepsilon$ も加わり、$t \approx 4$ s では合わせて $4 \times 10^{-15}$ s 程度になる。

許容誤差を $10^{-6}$ s にすると、時刻の差の記号は $10^{-6}$ s の破線の近くまで上がり、飛行時間の線が破線と交わる 62 回目のあたりで計算が止まる。
飛行時間の線が時刻の差の記号に近づくところが、この計算で接地の列を追える限界である。

## まとめ

接地のような状態で決まる時刻は、終端の事象で積分を止め、`OdeState::reset` で状態を書き換えて同じ作業領域で再開すれば、刻みの格子に依らずに求まる。
解が時間の 2 次式なら `DormandPrince5` の積分と連続出力は厳密で、接地の時刻の誤差は `OdeEventOptions::with_localization` の時刻の許容誤差で決まり、既定の $4\varepsilon$ では $10^{-14}$ s 程度になる。
跳ねる間隔が許容誤差や浮動小数点数の間隔に近づくと、事象の時刻が進まなくなるか、事象を見逃して `ReachedEnd` で終わる。
`ReachedEnd` は成功の状態でも、見つけた事象の数と最後の状態をモデルと照らして確かめる。
Zeno 現象のあるモデルでは、跳ね返りの速さが閾値を下回ったら静止のモデルに切り替えるような打ち切りをモデルの側に置く。
