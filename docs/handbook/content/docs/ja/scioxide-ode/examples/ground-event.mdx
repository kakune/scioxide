落下する物体が地面に着く時刻は、前もって決まった時刻ではなく、高さ $h(t) = 0$ という状態の条件で決まる。
一定の間隔 $\Delta t$ の観測で接地を判定すると、最大で $\Delta t$ だけ遅れる。
`scioxide-ode` の事象の検出（`EventFunction`）は、受理した刻みの連続出力の上で事象関数の零点を求めるので、刻み幅を観測に合わせて縮めなくても接地時刻と衝突速度が求まる。
求めた時刻の精度は事象の時刻の許容誤差と軌道の誤差で決まる。
この例題では二乗抗力のある落体の解析解と比べて、この二つの誤差の大きさを確かめる。

## 二乗抗力のある落体

鉛直上向きを正とし、物体を高さ $h(0) = h_0$ [m] から速度 $v(0) = 0$ で静かに落とす。
重力加速度を $g = 9.81\ \mathrm{m/s^2}$、単位質量あたりの二乗抗力係数を $c \ge 0$ [1/m] とすると、運動方程式は

$$
\frac{dh}{dt} = v, \qquad \frac{dv}{dt} = -g - c\,v\,|v|
$$

である。
落下中は $v < 0$ なので、抗力 $-c\,v|v| = c v^2$ は上向きに働いて落下を遅くする。
下向きの速さ $u = -v \ge 0$ は Riccati 型の方程式

$$
\frac{du}{dt} = g - c u^2
$$

に従う。
終端速度 $u_\infty = \sqrt{g/c}$ と速さの時定数の逆数 $a = \sqrt{gc}$ [1/s] を使うと、変数分離で

$$
u(t) = \sqrt{\frac{g}{c}}\,\tanh(a t), \qquad s(t) = h_0 - h(t) = \frac{1}{c}\ln\cosh(a t)
$$

が得られる。
$s$ は落下距離である。
接地の条件 $s(t^*) = h_0$ から、接地時刻と衝突速度は

$$
t^* = \frac{\operatorname{arcosh}\bigl(e^{c h_0}\bigr)}{\sqrt{gc}}, \qquad u(t^*) = \sqrt{\frac{g}{c}}\,\tanh\bigl(\sqrt{gc}\,t^*\bigr)
$$

になる。
$c \to 0$ の極限では自由落下の $t^* = \sqrt{2h_0/g}$ と $u(t^*) = \sqrt{2gh_0}$ に近づく。

次のブロックは二つのセルが共有する定義である。
`FallingBody(c)` が右辺、`Ground` が接地の事象、`ground_contact` が解析的な接地時刻と衝突速度（$c = 0$ では自由落下の式）である。

```rust
//| id: ode-falling-body-model
//| kind: definitions
//| title: 二乗抗力のある落体と接地の事象
//| crates: [scioxide-core, scioxide-ode]
use scioxide_core::{SciOxideError, SolveContext};
use scioxide_ode::{EventDirection, EventFunction, OdeSystem};

/// 重力加速度 g [m/s²]。
pub(crate) const GRAVITY: f64 = 9.81;
/// 状態 (h, v)。h' = v、v' = −g − c v|v|（c は単位質量あたりの二乗抗力係数 [1/m]）。
pub(crate) struct FallingBody(pub(crate) f64);
impl OdeSystem<f64> for FallingBody {
    fn dimension(&self) -> usize {
        2
    }
    fn rhs(
        &self,
        _: f64,
        y: &[f64],
        out: &mut [f64],
        _: &mut SolveContext<'_, '_>,
    ) -> Result<(), SciOxideError> {
        out[0] = y[1];
        out[1] = -GRAVITY - self.0 * y[1] * y[1].abs();
        Ok(())
    }
}
/// 接地の事象 g = h。上から下への通過で積分を止める。
pub(crate) struct Ground;
impl EventFunction<f64> for Ground {
    fn eval(&self, _: f64, y: &[f64]) -> Result<f64, SciOxideError> {
        Ok(y[0])
    }
    fn direction(&self) -> EventDirection {
        EventDirection::Falling
    }
    fn is_terminal(&self) -> bool {
        true
    }
}
/// 解析的な接地時刻 t* = arcosh(e^{c h₀})/√(gc) と衝突速度 √(g/c) tanh(√(gc) t*)。
/// c = 0 は自由落下の √(2h₀/g) と √(2gh₀)。f64 の固有メソッドによる参照値。
pub(crate) fn ground_contact(drag: f64, height: f64) -> (f64, f64) {
    if drag > 0.0 {
        let rate = (GRAVITY * drag).sqrt();
        let time = (drag * height).exp().acosh() / rate;
        (time, (GRAVITY / drag).sqrt() * (rate * time).tanh())
    } else {
        (
            (2.0 * height / GRAVITY).sqrt(),
            (2.0 * GRAVITY * height).sqrt(),
        )
    }
}
```

## 連続出力の上での接地の検出

事象関数を $g_{\mathrm{ev}}(t, h, v) = h$ とし、正から負への通過（`EventDirection::Falling`）で積分を止める（`is_terminal` が `true`）。
符号が変わった受理した刻みの中で、Dormand–Prince 5(4) の 4 次の連続出力の上の Alefeld–Potra–Shi の囲い込み法（TOMS 748）が、符号の変化を挟んだまま時刻の区間を縮める。
区間を止める幅は `OdeEventOptions::with_localization(StepTolerance, iterations)` で与え、既定は絶対・相対とも $4\varepsilon \approx 8.9 \times 10^{-16}$、反復 64 回である。
仕組みは [連続出力と事象](../../algorithms/dense-output-and-events/)で説明している。

次のセルは積分の局所誤差の許容誤差を $10^{-10}$ に固定し、高さ、抗力係数、最大刻み、事象の時刻の許容誤差を変えて、解析解と比べる。
上の図は高さ $h(t)$、下の図は下向きの速さ $u(t)$ で、横軸の時刻は二つの図で連動する。
表の「最後の区間の幅」は、事象の記録 `EventInfo::evidence()` の `EventEvidence::Crossing` が持つ、局所化を止めたときの区間の幅である。
このセルの $h_0$ と $c$ は次のセルにも渡す。

```rust
//| id: ode-ground-event
//| ref: ode-ground-event
//| title: 二乗抗力のある落下の接地を連続出力の上で求める
//| run: reactive
//| uses: [ode-falling-body-model]
//| crates: [scioxide-core, scioxide-linalg, scioxide-ode]
//| exports: [drop_height, quadratic_drag]
//| inputs:
//|   drop_height: {"type":"range","label":"初期の高さ h₀ [m]","description":"落下距離と接地時刻を変える。","min":5,"max":300,"step":5,"value":100}
//|   quadratic_drag: {"type":"range","label":"二乗抗力係数 c [1/m]","description":"終端速度と自由落下からのずれを変える。0 なら自由落下。","min":0,"max":0.08,"step":0.001,"value":0.015}
//|   event_maximum_step: {"type":"range","label":"最大刻み [s]","description":"事象を挟む受理した刻みの最大の幅。","min":0.02,"max":1,"step":0.02,"value":0.3}
//|   localization_exponent: {"type":"range","label":"事象の時刻の許容誤差 10^q [s] の指数 q","description":"TOMS 748 を止める区間の幅（絶対・相対とも同じ値）。","min":-14,"max":-4,"step":1,"value":-8}
//| cases:
//|   - {"id":"free-fall","label":"c = 0","description":"自由落下の √(2h₀/g) と比べる。","inputs":{"quadratic_drag":0}}
//|   - {"id":"loose-localization","label":"q = −4","description":"局所化の幅を緩めると、時刻の誤差がその幅まで広がりうる。","inputs":{"localization_exponent":-4}}
//|   - {"id":"fine-steps","label":"最大刻み 0.02 s","description":"刻みを細かくすると軌道の誤差が減る。","inputs":{"event_maximum_step":0.02}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"contact","path":"/rows/0/2","approx":{"value":5.684185817716974,"rtol":1e-12}}
//|       - {"artifact":"contact","path":"/rows/0/3","range":{"max":1e-10}}
//|       - {"artifact":"contact","path":"/rows/1/3","range":{"max":1e-8}}
//|       - {"path":"/outputs/3/state","equals":"satisfied"}
//|   - case: free-fall
//|     expect:
//|       - {"artifact":"contact","path":"/rows/0/2","approx":{"value":4.515236409857309,"rtol":1e-12}}
//|       - {"artifact":"contact","path":"/rows/0/3","range":{"max":1e-10}}
//|   - case: loose-localization
//|     expect:
//|       - {"artifact":"contact","path":"/rows/0/3","range":{"max":1e-4}}
//|   - case: fine-steps
//|     expect:
//|       - {"artifact":"contact","path":"/rows/0/3","range":{"max":1e-12}}
use scioxide_core::{
    Budget, ErrorTolerance, EvaluationRole, ExecutionContext, NormSelection, StepTolerance,
};
use scioxide_linalg::Vector;
use scioxide_ode::{
    DormandPrince5, EventEvidence, EventFunction, OdeEventOptions, OdeMethod, OdeOptions,
    OdeOutputSchedule, OdeProblem, OdeState, OdeTrajectory,
};

let (c, h0) = (quadratic_drag, drop_height);
let (t_star, u_star) = ground_contact(c, h0);
let end = 1.5 * t_star;
// 積分の局所誤差の許容誤差は 10⁻¹⁰ に固定し、事象の時刻の許容誤差だけを入力で変える。
let tolerance = ErrorTolerance::scalar(1e-10, 1e-10, NormSelection::RootMeanSquare)
    .map_err(|e| e.to_string())?;
let width = 10.0_f64.powf(localization_exponent);
let localization = StepTolerance::new(width, width).map_err(|e| e.to_string())?;
let iterations = Budget::try_from(200).map_err(|e| e.to_string())?;
let options = OdeOptions::new()
    .with_error_tolerance(tolerance)
    .with_initial_step(event_maximum_step.min(0.05))
    .with_maximum_step(event_maximum_step)
    .with_output_schedule(OdeOutputSchedule::times(
        (0..=300).map(|i| end * f64::from(i) / 300.0).collect(),
    ))
    .with_event_options(OdeEventOptions::new().with_localization(localization, iterations));
let system = FallingBody(c);
let events: &[&dyn EventFunction<f64>] = &[&Ground];
let problem = OdeProblem::new(&system, end).with_events(events);
let method = DormandPrince5::new();
let mut workspace = method
    .workspace(&problem, &options)
    .map_err(|e| e.to_string())?;
let mut state = OdeState::new(0.0, Vector::from_vec(vec![h0, 0.0]));
let mut path = OdeTrajectory::new();
let report = method
    .advance(
        &problem,
        &options,
        &mut state,
        &mut path,
        &mut workspace,
        ExecutionContext::sequential(),
    )
    .map_err(|e| e.to_string())?;
// 終端の事象で止まるので、出力は接地の時刻までになる。符号 sign を掛けた成分 k を描く。
let curve = |k: usize, sign: f64| -> Vec<[f64; 2]> {
    let states = path.states().iter().map(|y| sign * y.as_slice()[k]);
    path.times()
        .iter()
        .copied()
        .zip(states)
        .map(|(t, y)| [t, y])
        .collect()
};
let (height, speed) = (curve(0, 1.0), curve(1, -1.0));
let contact =
    serde_json::json!({ "kind": "line", "axis": "x", "value": t_star, "label": "t*" });
emit_line_chart!(
    &vec![serde_json::json!({ "name": "h(t)", "points": height })],
    options = &serde_json::json!({
        "link": { "group": "ground-time" },
        "xLabel": "時刻 t [s]",
        "yLabel": "高さ h [m]",
        "yMin": 0.0,
        "annotations": [contact]
    })
);
// 抗力があれば速さは終端速度 √(g/c) に近づく（c = 0 では横線を描かない）。
let terminal: Vec<_> = (c > 0.0)
    .then(|| (GRAVITY / c).sqrt())
    .map(|u| serde_json::json!({ "kind": "line", "axis": "y", "value": u, "label": "√(g/c)" }))
    .into_iter()
    .collect();
emit_line_chart!(
    &vec![serde_json::json!({ "name": "u(t)", "points": speed })],
    options = &serde_json::json!({
        "link": { "group": "ground-time" },
        "xLabel": "時刻 t [s]",
        "yLabel": "下向きの速さ u [m/s]",
        "annotations": terminal
    })
);
let event = path.events().first().ok_or("接地の事象が見つからない")?;
let (t_hit, y_hit) = (event.time(), event.state());
let bracket = match event.evidence() {
    EventEvidence::Crossing { bracket, .. } | EventEvidence::Contact { bracket, .. } => {
        Some(bracket.width().map_err(|e| e.to_string())?)
    }
    EventEvidence::SampledZero => None,
};
let compare = |name, value: f64, exact: f64| {
    (name, Some(value), Some(exact), Some((value - exact).abs()))
};
let rows = vec![
    compare("接地時刻 [s]", t_hit, t_star),
    compare("衝突速度 [m/s]", -y_hit[1], u_star),
    compare("接地時の高さ [m]", y_hit[0], 0.0),
    ("最後の区間の幅 [s]", bracket, None, None),
];
let digits11 = serde_json::json!({ "significantDigits": 11 });
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let columns = serde_json::json!([
    { "key": "0", "label": "量" },
    { "key": "1", "label": "事象の検出", "type": "number", "format": digits11, "nullText": "-" },
    { "key": "2", "label": "解析解", "type": "number", "format": digits11, "nullText": "-" },
    { "key": "3", "label": "差", "type": "number", "format": sci2, "nullText": "-" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "contact" })
);
let termination = report.termination().ok_or("終了状態がない")?;
let outcome = if termination == scioxide_ode::OdeTermination::TerminalEvent {
    Outcome::satisfied("終端の事象で接地時刻に止まった")
} else {
    Outcome::failed("接地の前に積分が止まった")
};
let counts = report.counts();
let rhs = counts.provider(EvaluationRole::RightHandSide) as f64;
let event_calls = counts.provider(EvaluationRole::Event) as f64;
emit_outcome!(
    outcome
        .status(termination.to_string())
        .diagnostic("受理した刻み", report.accepted_steps() as f64, None)
        .diagnostic("右辺の評価", rhs, None)
        .diagnostic("事象関数の評価", event_calls, None)
);
export!(drop_height, h0);
export!(quadratic_drag, c);
```

既定値（$h_0 = 100$ m、$c = 0.015$ 1/m、最大刻み 0.3 s、事象の時刻の許容誤差 $10^{-8}$ s）では、65 刻みを受理し、右辺を 397 回評価して接地を検出する。
求めた接地時刻と解析値 5.6841858177 s の差は $4.0 \times 10^{-12}$ s、衝突速度の差は $3.5 \times 10^{-10}$ m/s である。
局所化を止めたときの区間の幅は $3.3 \times 10^{-8}$ s で、返した時刻はこの区間の中にあるが、解析値との差は区間の幅よりずっと小さい。
許容誤差を $10^{-14}$ にすると区間の幅は $3.4 \times 10^{-14}$ s まで縮むが、時刻の差は $2.7 \times 10^{-11}$ s で小さくならない。
この範囲では、時刻の誤差は局所化ではなく軌道の誤差で決まる。
許容誤差を $10^{-4}$ に緩めると、区間の幅は $3.4 \times 10^{-4}$ s、時刻の差は $7.8 \times 10^{-6}$ s になり、許容誤差の範囲に収まる。
最大刻みを 0.02 s にすると受理した刻みは 285 に増え、時刻の差は $1.6 \times 10^{-13}$ s まで縮む。
最大刻みを 1 s にしても結果は既定と同じで、既定の 0.3 s は許容誤差で決まる刻みを制限していない。
$c = 0$ では解が時間の 2 次式なので、Dormand–Prince 5(4) と 4 次の連続出力は丸め誤差を除いて厳密になる。
接地時刻の差は 0、衝突速度の差は $1.4 \times 10^{-14}$ m/s で、誤差は局所化と丸めからしか生じない。

## 観測の格子による接地時刻の遅れ

事象を使わずに、間隔 $\Delta t$ の時刻だけで状態を出力し（`OdeOutputSchedule::times`）、最初に $h \le 0$ となった観測を接地とみなすと、遅れは $0$ 以上 $\Delta t$ 未満のどこかになる。
次のセルは前のセルの $h_0$ と $c$ を受け取り、観測の間隔を 24 通りに変えてこの遅れを解析的な接地時刻と比べる。
出力先は最初に $h \le 0$ となった時刻を記録するクロージャ `FnMut(t, y)` で、`OdeOutputSink` を実装している。

```rust
//| id: ode-ground-sampling-bias
//| ref: ode-ground-sampling-bias
//| title: 観測の格子で接地を判定したときの遅れ
//| run: reactive
//| uses: [ode-falling-body-model]
//| crates: [scioxide-core, scioxide-linalg, scioxide-ode]
//| dependsOn:
//|   event: ode-ground-event
//| inputs:
//|   maximum_sampling_interval: {"type":"range","label":"最大の観測の間隔 [s]","description":"調べる観測の間隔 Δt の範囲（24 通り）。","min":0.1,"max":3,"step":0.1,"value":1}
//| cases:
//|   - {"id":"coarse","label":"最大の間隔 3 s","description":"間隔が広いほど遅れの上下が大きくなる。","inputs":{"maximum_sampling_interval":3}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"sampling","path":"/rows/0/2","range":{"min":0,"max":0.25}}
//|       - {"artifact":"sampling","path":"/rows/3/3","range":{"min":0,"max":1}}
//|   - case: coarse
//|     expect:
//|       - {"artifact":"sampling","path":"/rows/3/3","range":{"min":0,"max":1}}
use scioxide_core::{ErrorTolerance, ExecutionContext, NormSelection};
use scioxide_linalg::Vector;
use scioxide_ode::{
    DormandPrince5, OdeMethod, OdeOptions, OdeOutputSchedule, OdeProblem, OdeState,
};

let h0 = event["drop_height"].as_f64().ok_or("初期の高さがない")?;
let c = event["quadratic_drag"].as_f64().ok_or("抗力係数がない")?;
let (t_star, _) = ground_contact(c, h0);
let tolerance = ErrorTolerance::scalar(1e-10, 1e-10, NormSelection::RootMeanSquare)
    .map_err(|e| e.to_string())?;
let system = FallingBody(c);
let method = DormandPrince5::new();
let (mut delay, mut rows) = (Vec::new(), Vec::new());
for k in 1..=24 {
    // 事象を使わず、間隔 Δt の時刻だけで状態を観測する。
    let dt = maximum_sampling_interval * f64::from(k) / 24.0;
    let n = (1.5 * t_star / dt).ceil() as u32;
    let times: Vec<f64> = (0..=n).map(|i| f64::from(i) * dt).collect();
    let options = OdeOptions::new()
        .with_error_tolerance(tolerance.clone())
        .with_output_schedule(OdeOutputSchedule::times(times));
    let problem = OdeProblem::new(&system, f64::from(n) * dt);
    let mut state = OdeState::new(0.0, Vector::from_vec(vec![h0, 0.0]));
    // 観測した時刻のうち、最初に h ≤ 0 となった時刻を接地とみなす。
    let mut sampled = None;
    let mut sink = |t: f64, y: &[f64]| {
        if sampled.is_none() && y[0] <= 0.0 {
            sampled = Some(t);
        }
        Ok::<(), scioxide_core::SciOxideError>(())
    };
    let mut workspace = method
        .workspace(&problem, &options)
        .map_err(|e| e.to_string())?;
    let context = ExecutionContext::sequential();
    let report = method
        .advance(
            &problem,
            &options,
            &mut state,
            &mut sink,
            &mut workspace,
            context,
        )
        .map_err(|e| e.to_string())?;
    if !report.is_success() {
        return Err(format!("積分が途中で止まった: {:?}", report.termination()));
    }
    let sampled = sampled.ok_or("観測に接地がない")?;
    delay.push([dt, sampled - t_star]);
    if k % 6 == 0 {
        rows.push((dt, sampled, sampled - t_star, (sampled - t_star) / dt));
    }
}
// 遅れは 0 以上 Δt 未満に収まる。破線は上界 Δt。
let bound: Vec<_> = delay.iter().map(|p| [p[0], p[0]]).collect();
let dashed = serde_json::json!({ "lineType": "dashed", "showSymbol": false });
emit_line_chart!(
    &vec![
        serde_json::json!({ "name": "観測による接地の遅れ", "points": delay, "kind": "scatter" }),
        serde_json::json!({ "name": "上界 Δt", "points": bound, "style": dashed })
    ],
    options = &serde_json::json!({
        "xLabel": "観測の間隔 Δt [s]",
        "yLabel": "接地の判定の遅れ [s]",
        "yIncludeZero": true
    })
);
let fixed3 = serde_json::json!({ "fractionDigits": 3 });
let columns = serde_json::json!([
    { "key": "0", "label": "観測の間隔 Δt [s]", "type": "number", "format": fixed3 },
    { "key": "1", "label": "観測による接地 [s]", "type": "number", "format": fixed3 },
    { "key": "2", "label": "遅れ [s]", "type": "number", "format": { "fractionDigits": 4 } },
    { "key": "3", "label": "遅れ / Δt [-]", "type": "number", "format": fixed3 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "sampling" })
);
```

既定値では、$\Delta t = 0.25$ s の遅れは 0.066 s である。
$\Delta t = 0.5$〜1 s ではどれも 6.000 s の観測で接地と判定され、0.316 s 遅れる。
遅れと $\Delta t$ の比は 0.26〜0.63 とばらつき、格子と接地時刻の位置関係で決まる。
最大の間隔を 3 s にすると、$\Delta t = 2.25$ s で遅れは 1.07 s になる。
遅れを小さくするには観測の間隔を細かくするしかないが、事象の検出は観測の間隔と関係なく前のセルの精度で時刻を返す。

## まとめ

事象の時刻は連続出力の上で求まるので、観測の間隔による遅れはない。
求めた時刻の誤差は局所化で残る区間の幅（事象の時刻の許容誤差以下で、既定は $4\varepsilon$）と軌道の誤差の大きい方で決まる。
TOMS 748 は区間を許容誤差よりずっと狭くすることが多いので、既定の許容誤差では軌道の誤差が支配する。
より正確な接地時刻が必要なら、積分の許容誤差や最大刻みを厳しくする。
`OdeEventOptions::with_localization` で許容誤差を緩めると、時刻の誤差はその幅まで広がりうる。
観測の格子で判定すると遅れは $\Delta t$ 未満のどこかになり、格子と接地時刻の位置関係で上下する。

事象の探索方針と見逃しの扱いは [連続出力と事象](../../algorithms/dense-output-and-events/)、解く手順と終了状態は [解く手順と結果の仕様](oxref:ode-termination-and-partial-results)で確かめられる。
