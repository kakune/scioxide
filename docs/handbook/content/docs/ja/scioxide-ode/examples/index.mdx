数値解の軌道が滑らかに見えても、正しいとは限らない。
人工的なエネルギーの減衰、濃度の負値、位相のずれ、事象の見逃しは、解析解、保存量、許容誤差や方式を変えた計算と比べて初めて分かる。
この章の例題は、それぞれ独立な検算を一つ以上持つ。

数理のページにも、例題と同じ形の実験がある。
Bratu 問題と Lane–Emden 方程式は[2 点境界値問題の選点法](../algorithms/boundary-value-collocation/)、薬物動態の AUC の勾配は[随伴法による勾配](../algorithms/adjoint-gradients/)、指数 1 の DAE の整合初期値は[指数 1 の DAE](../algorithms/dae-index-one/)、遅延ロジスティック方程式の Hopf 分岐は[遅延方程式](../algorithms/delay-equations/)、複素数の状態を持つ 2 準位系は[解く手順と結果の仕様](../algorithms/solve-lifecycle-and-contracts/)にある。

## まとめ

例題は、解析解・保存量・別の計算のいずれかで数値解を確かめる。
事象の時刻を確かめるなら接地事象、SIR モデル、跳ねるボールへ、不変量のずれを見るなら捕食者–被食者系、振動子、Kepler 問題へ進む。
剛性による方式の違いは可逆反応、Van der Pol 振動子、Robertson 反応系で、確率微分方程式の収束次数は幾何 Brownian 運動と Ornstein–Uhlenbeck 過程で確かめられる。
カオス的な系で何が予測でき何ができないかは、Lorenz 系と Mackey–Glass 方程式で確かめられる。
