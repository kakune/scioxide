惑星や人工衛星の軌道を何百周も積分すると、1 周あたりの誤差は小さくても、方式によってはエネルギーが一方向に増え続け、軌道の大きさや周期が変わってしまう。
この例題では、重力による二体問題（Kepler 問題）を、シンプレクティックな Störmer–Verlet 法（`StormerVerlet`）、同じ固定刻みの古典的 RK4（`ClassicalRk4`）、適応型の Dormand–Prince 8(5,3) 法（`DormandPrince853`）で解き、エネルギーと角運動量の厳密な値と比べる。
軌道上の位置を時刻から求める Kepler 方程式 $M = E - e\sin E$ の求根は別の問題で、[Kepler 方程式と離心率](../../../scioxide-rootfind/examples/kepler-equation/)で扱う。
回転座標系の軌道を適応型の方式で積分し、最近接の時刻を事象として求める応用は[制限三体問題の事象と保存量](../../../applications/orbital-mechanics/)にある。

## 二体問題と保存量

太陽の質量が惑星よりずっと大きいとき、惑星の位置 $q \in \mathbb{R}^2$ は

$$
q'' = -\frac{\mu\, q}{|q|^3}
$$

に従う。
ここで $\mu = GM$ は重力定数と太陽の質量の積である。
長さを軌道長半径 $a$、時間を $\sqrt{a^3/\mu}$ を単位にとると $\mu = 1$、$a = 1$ になり、公転周期は $2\pi$ である（地球なら長さの単位は 1 au、時間の単位は 1 年の $1/(2\pi)$）。
以下はこの無次元量で書く。

運動量 $p = q'$ を使うと、系は分離可能な Hamiltonian

$$
H(q, p) = \frac{|p|^2}{2} - \frac{1}{|q|}
$$

を持ち、$T(p) = |p|^2/2$、$V(q) = -1/|q|$ である。
保存量はエネルギー $H$ と角運動量 $L = q_1 p_2 - q_2 p_1$ で、離心率 $e$ の楕円軌道では

$$
H = -\frac{1}{2a} = -\frac{1}{2}, \qquad L = \sqrt{a(1 - e^2)} = \sqrt{1 - e^2}
$$

である。
近点（太陽に最も近い点）から始めると、初期値は

$$
q_0 = (1 - e,\; 0), \qquad p_0 = \Bigl(0,\; \sqrt{\tfrac{1 + e}{1 - e}}\Bigr)
$$

で、厳密解は周期 $2\pi$ ごとに $q_0$ に戻る。
したがって $N$ 周の後の位置のずれ $|q(2\pi N) - q_0|$ は、軌道上の位相（と軌道の形）の誤差をそのまま表す。

近点では速さが $\sqrt{(1 + e)/(1 - e)}$、距離が $1 - e$ で、軌道の曲率が大きい。
固定刻みの方式はこの部分を細かく解けないと大きな誤差を出すので、離心率が大きいほど 1 周あたりの刻みが多く要る。

## 3 つの方式と計算量

Störmer–Verlet 法は $\nabla T(p) = p$、$\nabla V(q) = q/|q|^3$ を `HamiltonianFn` で与え、刻み $h = 2\pi/m$（1 周 $m$ 刻み）で $Nm$ 刻み進める。
最後の状態だけが要るなら `solve_hamiltonian` で足りるが、ここでは各刻みのエネルギーを見るので、`StormerVerlet::advance` と受け取り手を使う。
1 刻みの評価は $\nabla T$ と $\nabla V$ が 1 回ずつである。
古典的 RK4 は同じ $h$ で $y = (q, p)$ の 4 成分の ODE を解き、1 刻みに右辺を 4 回評価する。
Dormand–Prince 8(5,3) 法は許容誤差 $\varepsilon$（絶対・相対とも）で刻みを選び、1 刻みに右辺を 12 回評価する（棄却した刻みの評価も数える）。

Störmer–Verlet 法はシンプレクティックなので、エネルギーの誤差は $O(h^2)$ の大きさで振動して増え続けない（[修正 Hamiltonian と長時間のエネルギー誤差](oxref:ode-modified-hamiltonian)）。
角運動量は $p^{\mathsf T} D q$ の形の 2 次の保存量なので、Störmer–Verlet 法では丸め誤差の水準で保たれる。
RK4 と Dormand–Prince 法はシンプレクティックでなく、誤差は 1 周ごとにほぼ同じ向きに積み重なる。
Dormand–Prince 法の誤差は許容誤差で小さくできるが、増え続ける性質は変わらない。

## 数百周の積分

次のセルは離心率 $e$、周回の数 $N$、1 周の刻みの数 $m$、Dormand–Prince 法の許容誤差 $\varepsilon = 10^{k}$ を選んで 3 つの方式で $t = 2\pi N$ まで積分する。
上の図は各周回の中での最大の $|H - (-1/2)|$、下の図は各周回の中での最大の $|L - \sqrt{1 - e^2}|$ を、周回の番号に対して両対数で描く（横軸は連動する）。
誤差が 0 の点は対数軸に描けないので除く。
表は全体の最大のエネルギー誤差と角運動量の誤差、$N$ 周の後の位置のずれ $|q_N - q_0|$、受理した刻みと右辺（Störmer–Verlet 法では $\nabla T$ と $\nabla V$）の評価の回数、終了状態を示す。
計算が重いので、ボタンで実行する。

```rust
//| id: ode-kepler-long-time
//| ref: ode-kepler-long-time
//| title: Kepler 問題のエネルギーと角運動量を 3 つの方式で数百周追う
//| run: button
//| crates: [scioxide-core, scioxide-linalg, scioxide-ode]
//| inputs:
//|   eccentricity: {"type":"range","label":"離心率 e","description":"0 は円軌道。大きいほど近点で速く曲がる。","min":0,"max":0.8,"step":0.05,"value":0.5}
//|   orbits: {"type":"range","label":"周回の数 N","description":"積分する公転の回数。","min":10,"max":500,"step":10,"value":500}
//|   steps_per_orbit: {"type":"range","label":"1 周の刻みの数 m","description":"Störmer–Verlet 法と RK4 の固定刻み h = 2π/m を決める。","min":50,"max":500,"step":50,"value":100}
//|   tolerance_exponent: {"type":"range","label":"Dormand–Prince 法の許容誤差の指数 k（ε = 10^k）","description":"絶対・相対許容誤差をそろえて変える。","min":-13,"max":-6,"step":1,"value":-10}
//| cases:
//|   - {"id":"eccentric","label":"e = 0.8","description":"近点が近く、固定刻みの 2 方式の誤差が大きくなる。","inputs":{"eccentricity":0.8}}
//|   - {"id":"circular","label":"e = 0","description":"円軌道では刻みの影響が軌道上で一様になる。","inputs":{"eccentricity":0}}
//|   - {"id":"loose","label":"ε = 10⁻⁶","description":"許容誤差を緩めると Dormand–Prince 法のエネルギーの増え方が速くなる。","inputs":{"tolerance_exponent":-6}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"kepler","path":"/rows/0/1","range":{"max":1e-2}}
//|       - {"artifact":"kepler","path":"/rows/1/1","range":{"min":6e-3}}
//|       - {"artifact":"kepler","path":"/rows/0/2","range":{"max":1e-12}}
//|       - {"artifact":"kepler","path":"/rows/1/2","range":{"min":1e-6}}
//|       - {"artifact":"kepler","path":"/rows/2/1","range":{"max":1e-7}}
//|   - case: eccentric
//|     expect:
//|       - {"artifact":"kepler","path":"/rows/0/2","range":{"max":1e-11}}
use scioxide_core::{
    ErrorTolerance, EvaluationRole, ExecutionContext, SciOxideError, NormSelection, RealScalar,
};
use scioxide_linalg::Vector;
use scioxide_ode::{
    ClassicalRk4, DormandPrince853, HamiltonianFn, MechanicalOptions, OdeFn, OdeMethod,
    OdeOptions, OdeOutputSchedule, OdeProblem, OdeState, PhaseSpace, StormerVerlet,
};

let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let e = eccentricity;
let (n_orbits, m) = (orbits as usize, steps_per_orbit as usize);
let tau = 2.0 * std::f64::consts::PI;
let h = tau / m as f64;
let end = tau * n_orbits as f64;
let q0 = [1.0 - e, 0.0];
let p0 = [0.0, RealScalar::sqrt((1.0 + e) / (1.0 - e))];
// 厳密な保存量 H = −1/2、L = √(1 − e²)（検算用）。
let angular0 = RealScalar::sqrt(1.0 - e * e);
let deviations = move |q: &[f64], p: &[f64]| {
    let energy = 0.5 * (p[0] * p[0] + p[1] * p[1]) - 1.0 / RealScalar::hypot(q[0], q[1]);
    let angular = q[0] * p[1] - q[1] * p[0];
    ((energy + 0.5).abs(), (angular - angular0).abs())
};
// 各周回の中での最大の |ΔH| と |ΔL|。
let record = |table: &mut Vec<[f64; 2]>, orbit: usize, d: (f64, f64)| {
    let row = &mut table[orbit.min(n_orbits - 1)];
    row[0] = row[0].max(d.0);
    row[1] = row[1].max(d.1);
};
let mut per_orbit = vec![vec![[0.0_f64; 2]; n_orbits]; 3];
let mut rows = Vec::new();

// Störmer–Verlet: ∇T(p) = p、∇V(q) = q/|q|³。
let hamiltonian = HamiltonianFn::new(
    2,
    |p: &[f64], velocity: &mut [f64]| {
        velocity.copy_from_slice(p);
        Ok::<(), SciOxideError>(())
    },
    |q: &[f64], gradient: &mut [f64]| {
        let r3 = RealScalar::powi(RealScalar::hypot(q[0], q[1]), 3);
        gradient[0] = q[0] / r3;
        gradient[1] = q[1] / r3;
        Ok::<(), SciOxideError>(())
    },
);
let mut state = PhaseSpace::new(q0.to_vec(), p0.to_vec()).map_err(|e| e.to_string())?;
let mut workspace = StormerVerlet
    .workspace(&hamiltonian)
    .map_err(|e| e.to_string())?;
let report = StormerVerlet
    .advance(
        &hamiltonian,
        h,
        n_orbits * m,
        &MechanicalOptions::new(),
        &mut state,
        &mut |n: usize, q: &[f64], p: &[f64]| {
            record(&mut per_orbit[0], (n - 1) / m, deviations(q, p));
            Ok(())
        },
        &mut workspace,
        ExecutionContext::sequential(),
    )
    .map_err(|e| e.to_string())?;
let counts = report.counts();
rows.push((
    "Störmer–Verlet",
    state.position().to_vec(),
    report.accepted_steps(),
    counts.provider(EvaluationRole::Gradient) + counts.provider(EvaluationRole::RightHandSide),
    report
        .termination()
        .map_or_else(|| "なし".to_string(), |t| format!("{t:?}")),
));

// RK4 と Dormand–Prince 8(5,3): y = (q₁, q₂, p₁, p₂)。
let system = OdeFn::new(4, |_: f64, y: &[f64], dydt: &mut [f64]| {
    let r3 = RealScalar::powi(RealScalar::hypot(y[0], y[1]), 3);
    dydt[0] = y[2];
    dydt[1] = y[3];
    dydt[2] = -y[0] / r3;
    dydt[3] = -y[1] / r3;
    Ok::<(), SciOxideError>(())
})
.map_err(|e| e.to_string())?;
let problem = OdeProblem::new(&system, end);
let epsilon = 10.0_f64.powf(tolerance_exponent);
let adaptive_tolerance =
    ErrorTolerance::scalar(epsilon, epsilon, NormSelection::RootMeanSquare)
        .map_err(|e| e.to_string())?;
for (k, name) in [(1, "古典 RK4"), (2, "Dormand–Prince 8(5,3)")] {
    let mut state = OdeState::new(0.0, Vector::from_vec(vec![q0[0], q0[1], p0[0], p0[1]]));
    let table = &mut per_orbit[k];
    let mut sink = |t: f64, y: &[f64]| {
        // t = 2πN の終点は最後の周回に入れる。
        record(table, (t / tau) as usize, deviations(&y[..2], &y[2..]));
        Ok::<(), SciOxideError>(())
    };
    let report = if k == 1 {
        let options = OdeOptions::new()
            .with_initial_step(h)
            .with_output_schedule(OdeOutputSchedule::AcceptedSteps);
        let method = ClassicalRk4::new();
        let mut workspace = method
            .workspace(&problem, &options)
            .map_err(|e| e.to_string())?;
        method.advance(
            &problem,
            &options,
            &mut state,
            &mut sink,
            &mut workspace,
            ExecutionContext::sequential(),
        )
    } else {
        let options = OdeOptions::new()
            .with_error_tolerance(adaptive_tolerance.clone())
            .with_output_schedule(OdeOutputSchedule::AcceptedSteps);
        let method = DormandPrince853::new();
        let mut workspace = method
            .workspace(&problem, &options)
            .map_err(|e| e.to_string())?;
        method.advance(
            &problem,
            &options,
            &mut state,
            &mut sink,
            &mut workspace,
            ExecutionContext::sequential(),
        )
    }
    .map_err(|e| e.to_string())?;
    rows.push((
        name,
        state.values()[..2].to_vec(),
        report.accepted_steps(),
        report.counts().provider(EvaluationRole::RightHandSide),
        report
            .termination()
            .map_or_else(|| "なし".to_string(), |t| t.to_string()),
    ));
}

let table: Vec<_> = rows
    .into_iter()
    .zip(&per_orbit)
    .map(|((name, q, steps, evaluations, termination), orbit)| {
        let worst = orbit
            .iter()
            .fold([0.0_f64; 2], |w, d| [w[0].max(d[0]), w[1].max(d[1])]);
        let distance = RealScalar::hypot(q[0] - q0[0], q[1] - q0[1]);
        (
            name,
            worst[0],
            worst[1],
            distance,
            steps,
            evaluations,
            termination,
        )
    })
    .collect();
let columns = serde_json::json!([
    { "key": "0", "label": "方式" },
    { "key": "1", "label": "最大の |H + 1/2| [-]", "type": "number", "format": sci3 },
    { "key": "2", "label": "最大の |L − √(1 − e²)| [-]", "type": "number", "format": sci3 },
    { "key": "3", "label": "N 周後の |q_N − q₀| [-]", "type": "number", "format": sci3 },
    { "key": "4", "label": "受理した刻み", "type": "integer" },
    { "key": "5", "label": "評価 [回]", "type": "integer" },
    { "key": "6", "label": "終了状態" }
]);
emit_table_with_columns!(
    columns,
    table,
    metadata = serde_json::json!({ "id": "kepler" })
);

let names = ["Störmer–Verlet", "古典 RK4", "Dormand–Prince 8(5,3)"];
for (k, label) in [
    (0, "周回ごとの最大の |H + 1/2| [-]"),
    (1, "周回ごとの最大の |L − √(1 − e²)| [-]"),
] {
    // 0 の点は対数軸に描けないので除く。
    let series: Vec<_> = (0..3)
.map(|method| {
let points: Vec<[f64; 2]> = per_orbit[method]
    .iter()
    .enumerate()
    .filter(|(_, d)| d[k] > 0.0)
    .map(|(orbit, d)| [(orbit + 1) as f64, d[k]])
    .collect();
serde_json::json!({ "name": names[method], "points": points, "style": { "showSymbol": false } })
})
.collect();
    emit_line_chart!(
        &series,
        options = &serde_json::json!({
            "link": { "group": "kepler-orbits" },
            "xLabel": "周回の番号 [-]",
            "yLabel": label,
            "xType": "log",
            "yType": "log"
        })
    );
}
```

既定の $e = 0.5$、$N = 500$ 周、$m = 100$ では、Störmer–Verlet 法の周回ごとの最大の $|H + 1/2|$ は 1 周目から 500 周目まで $5.42 \times 10^{-3}$ で、4 桁目まで変わらない。
RK4 の誤差は 1 周目の $1.7 \times 10^{-5}$ から周回の数に比例して増え、365 周前後で Störmer–Verlet 法を超え、500 周目には $7.4 \times 10^{-3}$ になる。
両対数の図では、RK4 と Dormand–Prince 法がほぼ傾き 1 の直線、Störmer–Verlet 法が水平な線になる。
Dormand–Prince 法（$\varepsilon = 10^{-10}$）の誤差は 500 周で $1.8 \times 10^{-8}$ と小さいが、やはり周回の数に比例して増える。

角運動量の誤差は、Störmer–Verlet 法では最大 $2.5 \times 10^{-14}$ で丸め誤差の水準にとどまり、RK4 は $2.0 \times 10^{-3}$、Dormand–Prince 法は $1.1 \times 10^{-8}$ まで増える。
500 周後の位置のずれは Störmer–Verlet 法で $0.76$、RK4 で $1.94$、Dormand–Prince 法で $1.4 \times 10^{-4}$ である。
Störmer–Verlet 法は保存量を保つが、位相の誤差は周回ごとに積み重なり、500 周後の位置は軌道の大きさの程度までずれる。

評価の回数は Störmer–Verlet 法が 100001 回、RK4 が 200004 回、Dormand–Prince 法が 329954 回である。
同じ評価の回数なら、Störmer–Verlet 法は RK4 の 2 倍の刻みを使える。
$e = 0.8$ では近点の距離が 0.2 になり、1 周 100 刻みでは固定刻みの 2 方式の誤差が大きくなる。
Störmer–Verlet 法のエネルギー誤差は $0.37$ に増えるが角運動量は $9.7 \times 10^{-15}$ のままで、RK4 は $|\Delta H| = 13.6$ と軌道が保てない。
Dormand–Prince 法は近点で刻みを縮め、29501 刻みで $|\Delta H| \le 9.1 \times 10^{-8}$ を保つ。
許容誤差を $10^{-6}$ に緩めると、Dormand–Prince 法の誤差は 500 周で $7.8 \times 10^{-4}$ に増える。

## まとめ

Kepler 問題では、Störmer–Verlet 法のエネルギー誤差は周回の数によらず一定の幅にとどまり、角運動量は丸め誤差の水準で保たれる。
同じ刻みの RK4 と、許容誤差で刻みを選ぶ Dormand–Prince 8(5,3) 法では、エネルギーの誤差が周回ごとに積み重なる。
ただし保存量が保たれても位相の誤差は増えるので、$N$ 周後の位置は Störmer–Verlet 法でも大きくずれる。
離心率が大きい軌道では近点で固定刻みが粗くなるので、1 周の刻みの数を増やすか、適応型の方式で許容誤差を小さくする。
長時間の統計的な性質（エネルギーの分布、軌道の形）が目的なら Störmer–Verlet 法、ある時刻の正確な位置が目的なら厳しい許容誤差の適応型の方式を選ぶ。
