Lorenz 系は大気の熱対流を 3 つのモードに切り詰めたモデルで、決定論的な方程式の解が初期値の小さな差を指数的に拡大する例として知られる。
初期値の差がどの速さで広がるかは Lyapunov 指数で表され、正の指数を持つ解は長い時間の後の状態を予測できない。
この例題では変分方程式（接方程式）を前進感度の仕組みで解と同時に積分し、接ベクトルを一定の時間ごとに QR 分解で直交化し直して、3 つの Lyapunov 指数を求める。
結果はヤコビ行列の跡から決まる指数の和の厳密値、文献値、2 本の近い軌道の分離から求めた最大指数と比べる。

## Lorenz 系

状態 $y = (x, y_2, z)$ の Lorenz 系は

$$
x' = \sigma (y_2 - x), \qquad
y_2' = x (\rho - z) - y_2, \qquad
z' = x y_2 - \beta z
$$

である。
$\sigma$ は Prandtl 数、$\rho$ は Rayleigh 数を臨界値で割った値、$\beta$ は対流セルの縦横比から決まる定数で、どれも無次元である。
時間も無次元で、以下では単位を書かない。
この例題は Lorenz（1963）の値 $\sigma = 10$、$\beta = 8/3$ に固定し、$\rho$ を入力にする。

$\rho > 1$ では 2 つの平衡点 $C_\pm = (\pm\sqrt{\beta(\rho - 1)}, \pm\sqrt{\beta(\rho - 1)}, \rho - 1)$ が現れる。
$C_\pm$ は $\rho < \rho_H = \sigma(\sigma + \beta + 3)/(\sigma - \beta - 1) \approx 24.74$ で線形安定であり、$\rho = 28$ では不安定になって、解は 2 つの平衡点のまわりを不規則に行き来するカオス的な軌道（Lorenz アトラクタ）に引き込まれる。

## 変分方程式と指数の和

解 $y(t)$ に沿った微小な摂動 $v(t)$ は、線形化した変分方程式

$$
v' = J(y(t))\,v, \qquad
J(y) = \begin{pmatrix} -\sigma & \sigma & 0 \\ \rho - z & -1 & -x \\ y_2 & x & -\beta \end{pmatrix}
$$

に従う。
初期の摂動 $v(0)$ から $v(t) = \Phi(t)\,v(0)$ を与える $3 \times 3$ の行列 $\Phi(t)$ は基本行列で、各列は初期値の各成分に対する解の感度 $\partial y(t)/\partial y(0)$ である。
Oseledets の乗法エルゴード定理によれば、ほとんどすべての初期値に対して $\Phi(t)$ の特異値 $s_1(t) \ge s_2(t) \ge s_3(t)$ の対数の増加率

$$
\lambda_i = \lim_{t \to \infty} \frac{1}{t} \ln s_i(t)
$$

が存在し、軌道の取り方によらない。
これが Lyapunov 指数で、$\lambda_1 > 0$ なら近い初期値から出た 2 本の軌道の距離は平均して $e^{\lambda_1 t}$ で広がる。
平衡点に収束しない有界な軌道では、軌道に沿う向きの摂動は増えも減りもしないので、指数の 1 つは 0 である。

Lorenz 系の $J$ の跡は位置によらず $\operatorname{tr} J = -(\sigma + 1 + \beta)$ である。
Liouville の公式 $\det \Phi(t) = \exp\left(\int_0^t \operatorname{tr} J\,ds\right)$ と $\det \Phi = s_1 s_2 s_3$ から、指数の和は

$$
\lambda_1 + \lambda_2 + \lambda_3 = -(\sigma + 1 + \beta) = -\frac{41}{3} \approx -13.667
$$

となる。
この値は軌道の長さや統計的なゆらぎに依存しないので、数値計算の精度の検算に使える。
一方 $\lambda_1$ と $\lambda_3$ の個々の値には解析的な表式がなく、Sprott（*Chaos and Time-Series Analysis*、Oxford University Press、2003）は $\rho = 28$ で $(\lambda_1, \lambda_2, \lambda_3) \approx (0.9056, 0, -14.5723)$ を挙げている。

## 接ベクトルの再直交化

$\Phi(t)$ をそのまま積分すると、3 本の列はどれも最も速く伸びる方向へ向き、$e^{(\lambda_1 - \lambda_3)t}$ の比で縮む成分は丸め誤差に埋もれる。
Benettin、Galgani、Giorgilli、Strelcyn（*Meccanica* 15, 1980）と Shimada、Nagashima（*Prog. Theor. Phys.* 61, 1979）の方法は、長さ $\Delta$ の区間ごとに接ベクトルを直交化し直してこれを避ける。
時刻 $t_k = k\Delta$ の正規直交な枠 $Q_k$ から区間の終わりまで変分方程式を積分した行列を QR 分解し、

$$
\Phi(t_{k+1}, t_k)\,Q_k = Q_{k+1} R_{k+1}, \qquad
\lambda_i \approx \frac{1}{t_K} \sum_{k=1}^{K} \ln \left| (R_k)_{ii} \right|
$$

とする。
$Q_{k+1}$ は次の区間の初期の接ベクトルになる。
$\Phi(t_K, 0) = Q_K R_K \cdots R_1$ なので、上三角行列の積の対角成分が各方向の伸びを表す。
QR 分解の代わりに Gram–Schmidt の直交化を使っても同じ値になる。

区間 $\Delta$ の間に最も伸びる列と最も縮む列の比は約 $e^{(\lambda_1 - \lambda_3)\Delta}$ になる。
この比が倍精度の $1/\varepsilon \approx 4.5 \times 10^{15}$ を超えると、QR 分解は 3 本目の列を丸め誤差から作ることになり、$\lambda_3$ が失われる。
Lorenz 系では $\lambda_1 - \lambda_3 \approx 15.5$ なので、$\Delta < \ln(1/\varepsilon)/15.5 \approx 2.3$ が目安になる。
$\Delta$ を小さくすると QR 分解の回数が増えるが、指数の推定値は変わらない。

## 前進感度で接ベクトルを伝播させる

`ForwardSensitivitySystem` は、状態 $y \in \mathbb{R}^n$ と $k$ 本の感度 $s_1, \ldots, s_k$ を並べた $n(k + 1)$ 次元の系

$$
y' = f(t, y, p), \qquad
s_j' = \frac{\partial f}{\partial y} s_j + \frac{\partial f}{\partial p} d_j \quad (j = 1, \ldots, k)
$$

を普通の `OdeSystem` として組み立てる。
$p \in \mathbb{R}^m$ は実数のパラメータ、$d_j$ はパラメータ空間の方向である。
右辺と方向微分は `OdeSensitivitySystem` を実装した型が `rhs` と `tangent_rhs` で返し、`tangent_rhs` は $(\partial f/\partial y)\,s + (\partial f/\partial p)\,d$ を書く。
`ForwardSensitivitySystem::bind` の `parameter_directions` は $k \times m$ の行列で、行 $j$ が $d_j$ になる。

すべての行を 0 にすると、パラメータの項が消えて $s_j' = J s_j$ だけが残り、感度は初期値に対するものになる。
`initialize_into` に初期の接ベクトルを列に持つ $n \times k$ の行列を渡すと、拡大した状態 $[y, s_1, \ldots, s_k]$ が作られる。
単位ベクトル $e_i$ を列に置けば、その列は初期値の成分 $y_i(0)$ に対する感度になる。
したがって、この例題では接方程式を自分で `OdeSystem` に書き直す必要はない。
$n = 3$、$k = 3$ で拡大した系は 12 次元になり、右辺の 1 回の評価で `rhs` を 1 回、`tangent_rhs` を 3 回呼ぶ。
`tangent_rhs` の呼び出しは解の評価回数の記録で `LinearOperator` の評価として数えられる。

区間の終わりでは `extract_into` が拡大した状態を $y$ と $3 \times 3$ の行列 $[s_1, s_2, s_3]$ に分け、その行列を `HouseholderDecomposition::factor` で QR 分解する。
得られた $Q$ を `initialize_into` に渡し、`OdeState::reset` で状態を差し替えて次の区間へ進む。
`OdeMethod::advance` は呼び出しごとに方式を状態から始め直し、前の呼び出しの刻み幅を引き継がない。
そのため各区間の始めに初期刻みの推定が入り、区間が短いほど右辺の評価回数が増える。

許容誤差は `ForwardSensitivitySystem::error_tolerance` で作る。
解と感度に別々の絶対許容誤差を与えられ、相対許容誤差は共通である。
陽的な `DormandPrince5` はヤコビ行列を使わないので、陰的な方式のように拡大した系のヤコビ行列を差分で作る計算コストはかからない。

次のブロックは 3 つのセルが共有する定義である。
`Lorenz` は $p = (\sigma, \rho, \beta)$ をパラメータに持つ `OdeSensitivitySystem` で、`tangent_rhs` は上の $J$ による積とパラメータの方向の項を書く。
`lorenz_rhs` は 2 本の軌道を同時に積分するセルでも使う右辺である。
`batch_means_2se` は、相関のある値の列の平均の標準誤差を batch means 法で見積もり、その 2 倍を返す。
値の列を同じ長さの $B$ 個のかたまりに分け、かたまりごとの平均 $\bar{\ell}_b$ の標本標準偏差を $\sqrt{B}$ で割る。
かたまりが相関の長さより十分長ければ、かたまりの平均はほぼ独立になり、この値は有限の時間平均のゆらぎの目安になる。

```rust
//| id: ode-lorenz-model
//| kind: definitions
//| title: Lorenz 系の右辺と方向微分
//| crates: [scioxide-core, scioxide-ode]
use scioxide_core::{SciOxideError, RealScalar, SolveContext};
use scioxide_ode::OdeSensitivitySystem;

/// Prandtl 数 σ と幾何の定数 β（Lorenz 1963 の値）。
pub(crate) const SIGMA: f64 = 10.0;
pub(crate) const BETA: f64 = 8.0 / 3.0;

/// Lorenz 系の右辺 f(y; σ, ρ, β)。
pub(crate) fn lorenz_rhs(y: &[f64], p: [f64; 3], out: &mut [f64]) {
    let [sigma, rho, beta] = p;
    out[0] = sigma * (y[1] - y[0]);
    out[1] = y[0] * (rho - y[2]) - y[1];
    out[2] = y[0] * y[1] - beta * y[2];
}

/// パラメータ p = (σ, ρ, β) を持つ Lorenz 系。
pub(crate) struct Lorenz;

impl OdeSensitivitySystem<f64> for Lorenz {
    fn dimension(&self) -> usize {
        3
    }
    fn parameter_dimension(&self) -> usize {
        3
    }
    fn rhs(
        &self,
        _time: f64,
        state: &[f64],
        parameters: &[f64],
        output: &mut [f64],
        _scratch: &mut [f64],
        _cx: &mut SolveContext<'_, '_>,
    ) -> Result<(), SciOxideError> {
        lorenz_rhs(state, [parameters[0], parameters[1], parameters[2]], output);
        Ok(())
    }
    /// (∂f/∂y) v + (∂f/∂p) d を書く。∂f/∂y は本文の J。
    fn tangent_rhs(
        &self,
        _time: f64,
        y: &[f64],
        p: &[f64],
        v: &[f64],
        d: &[f64],
        output: &mut [f64],
        _scratch: &mut [f64],
        _cx: &mut SolveContext<'_, '_>,
    ) -> Result<(), SciOxideError> {
        output[0] = p[0] * (v[1] - v[0]) + d[0] * (y[1] - y[0]);
        output[1] = (p[1] - y[2]) * v[0] - v[1] - y[0] * v[2] + d[1] * y[0];
        output[2] = y[1] * v[0] + y[0] * v[1] - p[2] * v[2] - d[2] * y[2];
        Ok(())
    }
}

/// 値の列を batches 個のかたまりに分け、かたまりの平均の標準誤差の 2 倍を返す。
/// かたまりに 2 個未満しか入らないときは None。
pub(crate) fn batch_means_2se(values: &[f64], batches: usize) -> Option<f64> {
    let size = values.len() / batches;
    if size < 2 {
        return None;
    }
    let means: Vec<f64> = values
        .chunks_exact(size)
        .take(batches)
        .map(|chunk| chunk.iter().sum::<f64>() / size as f64)
        .collect();
    let mean = means.iter().sum::<f64>() / batches as f64;
    let variance = means.iter().map(|m| (m - mean).powi(2)).sum::<f64>() / (batches - 1) as f64;
    Some(2.0 * RealScalar::sqrt(variance / batches as f64))
}
```

## Lyapunov スペクトルの計算

次のセルは $\rho$、再直交化の区間 $\Delta$、積分時間 $T$、許容誤差 $\varepsilon$（解と感度の絶対・相対許容誤差に共通）を選び、`DormandPrince5` で 3 つの指数を求める。
初期値 $(1, 1, 1)$ から $t = -20$ に出発し、$t = 0$ までを過渡として捨ててから接ベクトルを単位行列に置き、$[0, T]$ で指数を累積する。
セルの出力は、すべての区間が終端に達したかを示す outcome で、診断の欄に 3 つの指数、和と $-41/3$ の差、受理した刻みの数を示す。
指数の表と途中の推定値のグラフは次のセルが描く。
このセルは $\rho$、$\Delta$、$\varepsilon$、$t = 0$ の点、指数とその 2SE、途中の推定値を後のセルに渡す。

```rust
//| id: ode-lorenz-lyapunov-spectrum
//| ref: ode-lorenz-lyapunov-spectrum
//| title: QR 再直交化による Lorenz 系の Lyapunov スペクトル
//| run: button
//| cache: inputs
//| uses: [ode-lorenz-model]
//| crates: [scioxide-core, scioxide-linalg, scioxide-ode]
//| exports: [rho, interval, tolerance, start, exponents, two_se, running]
//| inputs:
//|   rho: {"type":"range","label":"ρ [-]","description":"Rayleigh 数の比。24.74 より小さいと平衡点 C± が安定になる。","min":10,"max":60,"step":0.5,"value":28}
//|   interval: {"type":"range","label":"再直交化の区間 Δ [-]","description":"QR 分解で接ベクトルを直交化し直す時間間隔。","min":0.05,"max":5,"step":0.05,"value":1}
//|   horizon: {"type":"range","label":"積分時間 T [-]","description":"指数を累積する時間。","min":100,"max":1000,"step":50,"value":500}
//|   tolerance_exponent: {"type":"range","label":"許容誤差の指数 p（ε = 10^p）","description":"解と感度の絶対・相対許容誤差をそろえて変える。","min":-10,"max":-5,"step":1,"value":-8}
//| cases:
//|   - {"id":"stable-equilibrium","label":"ρ = 10","description":"平衡点が安定で、指数は平衡点のヤコビ行列の固有値の実部に近づく。","inputs":{"rho":10}}
//|   - {"id":"long-interval","label":"Δ = 5","description":"区間の伸びの比が 1/ε を超え、λ₃ と指数の和が失われる。","inputs":{"interval":5}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"path":"/outputs/0/state","equals":"satisfied"}
//|       - {"path":"/outputs/0/diagnostics/0/value","approx":{"value":0.9056,"atol":0.03}}
//|       - {"path":"/outputs/0/diagnostics/1/value","range":{"min":-0.02,"max":0.02}}
//|       - {"path":"/outputs/0/diagnostics/2/value","approx":{"value":-14.5723,"atol":0.05}}
//|       - {"path":"/outputs/0/diagnostics/3/value","range":{"max":1e-5}}
//|   - case: stable-equilibrium
//|     expect:
//|       - {"path":"/outputs/0/diagnostics/0/value","approx":{"value":-0.5955,"atol":0.02}}
//|       - {"path":"/outputs/0/diagnostics/2/value","approx":{"value":-12.4757,"atol":0.02}}
//|   - case: long-interval
//|     expect:
//|       - {"path":"/outputs/0/diagnostics/3/value","range":{"min":1}}
use scioxide_core::{ExecutionContext, NormSelection, RealScalar};
use scioxide_linalg::{HouseholderDecomposition, HouseholderOrientation, HouseholderPivoting};
use scioxide_linalg::{Matrix, MatrixView};
use scioxide_ode::{DormandPrince5, ForwardSensitivitySystem, ForwardSensitivityWorkspace};
use scioxide_ode::{OdeMethod, OdeOptions, OdeProblem, OdeState};

let parameters = [SIGMA, rho, BETA];
// パラメータの方向の行をすべて 0 にし、初期値に対する感度だけを伝播させる。
let directions = MatrixView::from_slice(3, 3, &[0.0; 9]).map_err(|e| e.to_string())?;
let mut binding = ForwardSensitivityWorkspace::new();
let system = ForwardSensitivitySystem::bind(&Lorenz, &parameters, directions, &mut binding)
    .map_err(|e| e.to_string())?;
let epsilon = 10.0_f64.powf(tolerance_exponent);
let tolerance = system
    .error_tolerance(epsilon, epsilon, epsilon, NormSelection::Infinity)
    .map_err(|e| e.to_string())?;
let options = OdeOptions::new().with_error_tolerance(tolerance);
let method = DormandPrince5::new();
// t = −20 から 0 までを過渡として捨て、t = 0 で接ベクトルを単位行列に置き直す。
let mut frame = Matrix::identity(3).map_err(|e| e.to_string())?;
let mut augmented = vec![0.0; system.augmented_dimension()];
system
    .initialize_into(&[1.0, 1.0, 1.0], frame.view(), &mut augmented)
    .map_err(|e| e.to_string())?;
let mut state = OdeState::from_slice(-20.0, &augmented).map_err(|e| e.to_string())?;
let mut ws = method
    .workspace(&OdeProblem::new(&system, 0.0), &options)
    .map_err(|e| e.to_string())?;
let intervals = (horizon / interval).round() as usize;
let stride = (intervals / 600).max(1);
let (mut y, mut start) = ([0.0; 3], [0.0; 3]);
let mut tangents = Matrix::zeros(3, 3).map_err(|e| e.to_string())?;
let (mut log_sums, mut rates) = ([0.0_f64; 3], vec![Vec::new(); 3]);
let (mut running, mut reached, mut accepted, mut status) = (Vec::new(), 0.0, 0, None);
for k in 0..=intervals {
    let end = k as f64 * interval;
    let (problem, cx) = (
        OdeProblem::new(&system, end),
        ExecutionContext::sequential(),
    );
    let report = method
        .advance(&problem, &options, &mut state, &mut (), &mut ws, cx)
        .map_err(|e| e.to_string())?;
    accepted += report.accepted_steps();
    status = report.termination();
    if !report.is_success() {
        break;
    }
    system
        .extract_into(state.values(), &mut y, tangents.view_mut())
        .map_err(|e| e.to_string())?;
    if k == 0 {
        start = y;
    } else {
        // Φ(t_k, t_{k−1}) Q_{k−1} = Q_k R_k。|(R_k)_ii| の対数を累積する。
        let qr = HouseholderDecomposition::factor(
            &tangents,
            HouseholderOrientation::Qr,
            HouseholderPivoting::None,
        )
        .map_err(|e| e.to_string())?;
        for (i, r) in qr.triangular_diagonal().iter().enumerate() {
            let growth = RealScalar::ln(r.abs());
            if !growth.is_finite() {
                return Err(format!("t = {end} で R の対角成分 {i} が 0 になった"));
            }
            log_sums[i] += growth;
            rates[i].push(growth / interval);
        }
        frame = qr.to_q_matrix().map_err(|e| e.to_string())?;
        reached = end;
        if k % stride == 0 || k == intervals {
            running.push([end, log_sums[0] / end, log_sums[1] / end, log_sums[2] / end]);
        }
    }
    system
        .initialize_into(&y, frame.view(), &mut augmented)
        .map_err(|e| e.to_string())?;
    state.reset(end, &augmented).map_err(|e| e.to_string())?;
}
if reached == 0.0 {
    return Err(format!("最初の区間で積分が {status:?} で止まった"));
}
let exponents = log_sums.map(|s| s / reached);
let sum_error = (exponents.iter().sum::<f64>() + SIGMA + 1.0 + BETA).abs();
export!(rho, rho);
export!(interval, interval);
export!(tolerance, epsilon);
export!(start, start);
export!(exponents, exponents);
export!(
    two_se,
    rates
        .iter()
        .map(|r| batch_means_2se(r, 10))
        .collect::<Vec<_>>()
);
export!(running, running);

let outcome = if status.is_some_and(|t| t.is_success()) {
    Outcome::satisfied("すべての区間で積分が終端に達した")
} else {
    Outcome::partial("積分が途中で止まり、指数は止まった時刻までの推定値である")
        .explanation("許容誤差か区間 Δ を見直す。")
};
emit_outcome!(
    outcome
        .status(status.map_or("なし".to_string(), |t| t.to_string()))
        .diagnostic("λ₁", exponents[0], None)
        .diagnostic("λ₂", exponents[1], None)
        .diagnostic("λ₃", exponents[2], None)
        .diagnostic("和と −41/3 の差", sum_error, None)
        .diagnostic("受理した刻み", accepted as f64, None)
        .diagnostic("指数を累積した時間", reached, None)
);
```

既定値（$\rho = 28$、$\Delta = 1$、$T = 500$、$\varepsilon = 10^{-8}$）では、500 個の区間がすべて `ReachedEnd` で終わり、受理した刻みは合わせて 71518 である。
指数は $\lambda_1 = 0.9092$、$\lambda_2 = -0.0020$、$\lambda_3 = -14.5738$ で、和 $-13.66666609$ と厳密値 $-41/3$ の差は $5.7 \times 10^{-7}$ である。
許容誤差を $10^{-10}$ にすると和の差は $7.5 \times 10^{-9}$ に、$10^{-5}$ にすると $1.1 \times 10^{-3}$ になり、和のずれは積分の精度とともに変わる。

$\rho = 10$ では平衡点 $C_\pm$ が安定で、軌道は $C_\pm$ に近づく。
このとき指数は $C_\pm$ での $J$ の固有値の実部に近づき、特性多項式 $\mu^3 + (\sigma + \beta + 1)\mu^2 + \beta(\sigma + \rho)\mu + 2\sigma\beta(\rho - 1)$ の根の実部は複素共役な対の $-0.5955$ と実根の $-12.4757$ である。
計算した指数は $-0.5978$、$-0.5952$、$-12.4737$ で、固有値の実部との差は 0.003 以下である。
残る差は、$t = 0$ の点から平衡点へ近づく途中の伸び縮みが $1/T$ の重みで平均に入ったものと考えられる。

$\Delta = 5$ にすると、$\lambda_1$ と $\lambda_2$ は 2SE の範囲で変わらないが、$\lambda_3$ は $-6.689$、和は $-5.774$ になり、和の差が 7.89 に跳ぶ。
区間あたりの伸びの比 $e^{(\lambda_1 - \lambda_3) \cdot 5} \approx e^{77}$ が $1/\varepsilon$ を大きく超え、3 本目の列が丸め誤差から作られたためである。
$\Delta = 0.05$ では $\lambda_1 = 0.9049$、和の差は $4.5 \times 10^{-8}$ で、指数は $\Delta = 1$ と 2SE の範囲で一致するが、受理した刻みは 89567 に増える。
`advance` を呼ぶたびに初期刻みを推定し直すので、短い区間では刻みが小さく始まるためである。

## 指数の表と途中の推定値

## 初期値の差の拡大

接方程式を使わずに、近い 2 本の軌道の距離を直接見ることもできる。
次のセルは前のセルから $\rho$、$\varepsilon$ と $t = 0$ の点 $y(0)$ を受け取り、$\tilde{y}(0) = y(0) + (d_0, 0, 0)$ とした 2 本の軌道を 1 つの 6 次元の系として `DormandPrince5` で $t \in [0, 40]$ まで積分する。
グラフは距離 $|\tilde{y}(t) - y(t)|$ を 0.1 ごとに対数の縦軸に描き、前のセルの $\lambda_1$ による $d_0 e^{\lambda_1 t}$ を破線で重ねる。
距離が小さいあいだは平均して破線の傾きで増え、アトラクタの大きさ（座標の幅は数十）に近づくと増えなくなる。

```rust
//| id: ode-lorenz-separation
//| ref: ode-lorenz-separation
//| title: 近い 2 本の軌道の距離
//| run: button
//| uses: [ode-lorenz-model]
//| crates: [scioxide-core, scioxide-ode]
//| dependsOn:
//|   spectrum: ode-lorenz-lyapunov-spectrum
//| inputs:
//|   separation_exponent: {"type":"range","label":"初期の距離の指数 q（d₀ = 10^q）","description":"2 本の軌道の初期の距離。","min":-12,"max":-2,"step":1,"value":-8}
use scioxide_core::{ErrorTolerance, NormSelection, RealScalar};
use scioxide_ode::OdeState;
use scioxide_ode::{DormandPrince5, OdeFn, OdeMethod, OdeOptions, OdeOutputSchedule, OdeProblem};

let rho = spectrum["rho"].as_f64().ok_or("ρ がない")?;
let epsilon = spectrum["tolerance"].as_f64().ok_or("許容誤差がない")?;
let lambda1 = spectrum["exponents"][0].as_f64().ok_or("λ₁ がない")?;
let y0: [f64; 3] =
    serde_json::from_value(spectrum["start"].clone()).map_err(|e| e.to_string())?;
let d0 = 10.0_f64.powf(separation_exponent);
let rhs = OdeFn::new(6, move |_t: f64, y: &[f64], out: &mut [f64]| {
    lorenz_rhs(&y[..3], [SIGMA, rho, BETA], &mut out[..3]);
    lorenz_rhs(&y[3..], [SIGMA, rho, BETA], &mut out[3..]);
    Ok(())
})
.map_err(|e| e.to_string())?;
let tolerance = ErrorTolerance::scalar(epsilon, epsilon, NormSelection::Infinity)
    .map_err(|e| e.to_string())?;
let times: Vec<f64> = (1..=400).map(|i| 0.1 * i as f64).collect();
let options = OdeOptions::new()
    .with_error_tolerance(tolerance)
    .with_output_schedule(OdeOutputSchedule::times(times));
let initial = OdeState::from_slice(0.0, &[y0[0], y0[1], y0[2], y0[0] + d0, y0[1], y0[2]])
    .map_err(|e| e.to_string())?;
let solution = DormandPrince5::new()
    .solve(&OdeProblem::new(&rhs, 40.0), &options, initial)
    .map_err(|e| e.error().to_string())?;
let trajectory = solution.trajectory();
let separation: Vec<[f64; 2]> = trajectory
    .times()
    .iter()
    .zip(trajectory.states())
    .map(|(&t, s)| {
        let y = s.as_slice();
        [
            t,
            RealScalar::sqrt((0..3).map(|i| (y[i + 3] - y[i]).powi(2)).sum::<f64>()),
        ]
    })
    .collect();
// 参照の曲線 d₀ e^{λ₁ t}（f64 の標準関数）。距離 100 を超える部分は描かない。
let reference: Vec<[f64; 2]> = separation
    .iter()
    .map(|p| [p[0], d0 * (lambda1 * p[0]).exp()])
    .take_while(|p| p[1] < 100.0)
    .collect();
emit_chart!(serde_json::json!({
    "kind": "xy",
    "xLabel": "時刻 t [-]",
    "yLabel": "2 本の軌道の距離 [-]",
    "yType": "log",
    "dataZoom": true,
    "tooltip": true,
    "layers": [
        { "id": "distance", "kind": "line", "name": "|ỹ(t) − y(t)|", "points": separation },
        {
            "id": "growth",
            "kind": "line",
            "name": "d₀ e^(λ₁ t)（QR の λ₁）",
            "points": reference,
            "style": { "lineType": "dashed", "showSymbol": false }
        }
    ]
}));
```

既定値の $d_0 = 10^{-8}$ では、距離は $t = 4.3$ で $10^{-6}$、$t = 9.0$ で $10^{-4}$、$t = 10.9$ で $10^{-2}$ を超え、$t = 18.8$ で 1、$t = 21.8$ で 10 に達する。
その後はアトラクタの大きさの程度（最大 44.6）で増えなくなる。
増え方は一様ではなく、軌道がアトラクタのどの部分を通るかによって速くなったり遅くなったりするが、平均すると破線の傾き $\lambda_1$ に沿う。
$d_0 = 10^{-12}$ にすると曲線全体が 4 桁下から始まり、距離は $t = 29.4$ で 1 に達する。
$d_0 = 10^{-8}$ より 10.6 遅く、$\ln(10^{4})/\lambda_1 \approx 10.1$ に近い。
初期値の誤差を 1 桁減らしても、予測できる時間は $\ln 10/\lambda_1 \approx 2.5$ しか延びない。

## 2 本の軌道の分離による別推定

Benettin らの原論文は 2 本の軌道の距離を区間 $\Delta$ ごとに測って $\lambda_1$ を求めた。
距離 $d_k = |\tilde{y}(t_k) - y(t_k)|$ を測ったら、$\tilde{y}$ を $y$ から同じ向きに距離 $d_0$ の点へ戻し（再正規化）、

$$
\lambda_1 \approx \frac{1}{K\Delta} \sum_{k=1}^{K} \ln\frac{d_k}{d_0}
$$

とする。
$d_0$ が小さければ、差 $\tilde{y} - y$ は変分方程式の解に近く、最も速く伸びる方向へ向いていく。
距離が非線形の項の効く大きさまで伸びる前に戻すので、上のグラフのような飽和は起こらない。

次のセルは前のセルと同じ $d_0$ と 6 次元の系で、前のセルが指数を累積したのと同じ時間 $T$ と区間 $\Delta$ で再正規化を繰り返す。
表は 2 本の軌道による $\lambda_1$ を接方程式と QR 分解による $\lambda_1$ と比べる。
2 つの推定値は同じ点から出発するが、軌道の誤差が $e^{\lambda_1 t}$ で拡大するので、長い時間の後には別の軌道の時間平均になる。
そのため、差は 2 つの推定値の 2SE を合わせた $\sqrt{(2\mathrm{SE}_1)^2 + (2\mathrm{SE}_2)^2}$ と比べる。

```rust
//| id: ode-lorenz-twin-trajectories
//| ref: ode-lorenz-twin-trajectories
//| title: 2 本の軌道の分離による最大 Lyapunov 指数
//| run: button
//| uses: [ode-lorenz-model]
//| crates: [scioxide-core, scioxide-ode]
//| dependsOn:
//|   spectrum: ode-lorenz-lyapunov-spectrum
//| inputs:
//|   separation_exponent: {"type":"range","label":"初期の距離の指数 q（d₀ = 10^q）","description":"2 本の軌道の初期の距離。","min":-12,"max":-2,"step":1,"value":-8}
//| cases:
//|   - {"id":"tiny-separation","label":"d₀ = 10⁻¹²","description":"初期の距離を許容誤差より小さくしても、推定値は 2SE の範囲で変わらない。","inputs":{"separation_exponent":-12}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"comparison","path":"/rows/1/1","approx":{"value":0.9,"atol":0.05}}
//|   - case: tiny-separation
//|     expect:
//|       - {"artifact":"comparison","path":"/rows/1/1","approx":{"value":0.9,"atol":0.05}}
use scioxide_core::{ErrorTolerance, ExecutionContext, NormSelection, RealScalar};
use scioxide_ode::{DormandPrince5, OdeFn, OdeMethod, OdeOptions, OdeProblem, OdeState};

let read = |key: &str| spectrum[key].as_f64().ok_or(format!("{key} がない"));
let (rho, interval, epsilon) = (read("rho")?, read("interval")?, read("tolerance")?);
let y0: [f64; 3] =
    serde_json::from_value(spectrum["start"].clone()).map_err(|e| e.to_string())?;
let horizon = spectrum["running"]
    .as_array()
    .and_then(|r| r.last())
    .and_then(|r| r[0].as_f64());
let horizon = horizon.ok_or("指数を累積した時間がない")?;
let d0 = 10.0_f64.powf(separation_exponent);
let rhs = OdeFn::new(6, move |_t: f64, y: &[f64], out: &mut [f64]| {
    lorenz_rhs(&y[..3], [SIGMA, rho, BETA], &mut out[..3]);
    lorenz_rhs(&y[3..], [SIGMA, rho, BETA], &mut out[3..]);
    Ok(())
})
.map_err(|e| e.to_string())?;
let tolerance = ErrorTolerance::scalar(epsilon, epsilon, NormSelection::Infinity)
    .map_err(|e| e.to_string())?;
let options = OdeOptions::new().with_error_tolerance(tolerance);
let method = DormandPrince5::new();
let mut y = [y0[0], y0[1], y0[2], y0[0] + d0, y0[1], y0[2]];
let mut state = OdeState::from_slice(0.0, &y).map_err(|e| e.to_string())?;
let mut ws = method
    .workspace(&OdeProblem::new(&rhs, interval), &options)
    .map_err(|e| e.to_string())?;
let mut rates = Vec::new();
for k in 1..=(horizon / interval).round() as usize {
    let end = k as f64 * interval;
    let (problem, cx) = (OdeProblem::new(&rhs, end), ExecutionContext::sequential());
    let report = method
        .advance(&problem, &options, &mut state, &mut (), &mut ws, cx)
        .map_err(|e| e.to_string())?;
    if !report.is_success() {
        return Err(format!(
            "t = {end} までの積分が {:?} で止まった",
            report.termination()
        ));
    }
    // 距離 d_k を測り、2 本目の軌道を 1 本目から同じ向きに距離 d₀ の点へ戻す。
    y.copy_from_slice(state.values());
    let d = RealScalar::sqrt((0..3).map(|i| (y[i + 3] - y[i]).powi(2)).sum::<f64>());
    rates.push(RealScalar::ln(d / d0) / interval);
    for i in 0..3 {
        y[i + 3] = y[i] + (y[i + 3] - y[i]) * d0 / d;
    }
    state.reset(end, &y).map_err(|e| e.to_string())?;
}
let twin = rates.iter().sum::<f64>() / rates.len() as f64;
let twin_2se = batch_means_2se(&rates, 10);
let qr = spectrum["exponents"][0].as_f64();
let qr_2se = spectrum["two_se"][0].as_f64();
let combined = qr_2se.zip(twin_2se).map(|(a, b)| RealScalar::hypot(a, b));
let fixed4 = serde_json::json!({ "fractionDigits": 4 });
let columns = serde_json::json!([
    { "key": "0", "label": "推定の方法" },
    { "key": "1", "label": "λ₁ [-]", "type": "number", "format": fixed4, "nullText": "未定義" },
    { "key": "2", "label": "2SE [-]", "type": "number", "format": fixed4, "nullText": "なし" }
]);
let rows = vec![
    ("接方程式と QR 分解", qr, qr_2se),
    ("2 本の軌道の分離", Some(twin), twin_2se),
    (
        "差の絶対値と合わせた 2SE",
        qr.map(|a| (a - twin).abs()),
        combined,
    ),
];
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "comparison" })
);
```

既定値の $d_0 = 10^{-8}$ では、2 本の軌道による推定値は $\lambda_1 = 0.9185$（2SE 0.020）で、QR 分解による 0.9092 との差 0.0093 は合わせた 2SE の 0.032 より小さい。
$d_0 = 10^{-12}$ では 0.9050、$d_0 = 10^{-2}$ では 0.9128 で、どちらも QR 分解の値と合わせた 2SE の範囲で一致する。
$d_0 = 10^{-12}$ は許容誤差 $10^{-8}$ による局所誤差より小さいが、推定値は変わらなかった。
2 つの推定値の差は区間ごとの伸び率の時間平均のゆらぎで説明できる大きさである。

## まとめ

Lyapunov 指数は変分方程式の基本行列の伸び率で、`ForwardSensitivitySystem` のパラメータの方向を 0 にし、初期の接ベクトルを `initialize_into` に渡せば、初期値に対する感度として接方程式を解と同時に積分できる。
接ベクトルは放っておくと最も伸びる方向にそろうので、区間 $\Delta$ ごとに QR 分解で直交化し直し、$R$ の対角成分の対数を累積する。
$\Delta$ は伸びの比 $e^{(\lambda_1 - \lambda_3)\Delta}$ が $1/\varepsilon$ を超えない長さ（Lorenz 系では 2.3 程度まで）にする。
指数の和はヤコビ行列の跡から $-41/3$ と決まるので、軌道のゆらぎによらない精度の検算になり、個々の指数は時間平均のゆらぎを batch means の 2SE で見積もって文献値や別の推定と比べる。
2 本の軌道の分離による推定は接方程式を使わない独立な確認になり、この例題では $d_0$ を $10^{-12}$ から $10^{-2}$ まで変えても QR 分解の値と 2SE の範囲で一致した。
