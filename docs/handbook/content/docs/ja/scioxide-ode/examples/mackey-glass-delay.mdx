遅延微分方程式は、変化の速さが過去の状態で決まる系を表す。
Mackey と Glass（*Science* 197, 1977）は、骨髄で作られた血球が成熟して血中に出るまでの時間の遅れを含むモデルを提案し、遅れが長くなると血球数が周期的に、さらに不規則に変動することを示した。
この例題では Mackey–Glass 方程式を `DdePlan` で解き、平衡点の線形化から求めた臨界遅延と周期を数値解の振動の開始と比べる。
最後に、カオス的な解が初期の履歴の小さな差を拡大する様子を確かめる。

## Mackey–Glass 方程式

血中の血球の濃度を平衡値で無次元化した量を $x(t)$ とし、時間の単位を日とする。
Mackey–Glass 方程式は

$$
x'(t) = \frac{\beta\, x(t - \tau)}{1 + x(t - \tau)^n} - \gamma\, x(t)
$$

である。
右辺の第 1 項は時刻 $t - \tau$ の濃度に応じた産生、第 2 項は血中からの消失を表す。
産生率 $\beta = 0.2$ [1/日]、消失率 $\gamma = 0.1$ [1/日]、Hill 係数 $n = 10$ は Mackey と Glass が数値例に使った値で、遅延 $\tau$ [日] を入力にする。
産生の項は $x(t - \tau)$ が小さいときは比例して増え、大きいときは負の帰還で減る。

遅延方程式の解を決めるには、初期時刻 $t_0 = 0$ の値だけでなく、区間 $[-\tau, 0]$ の履歴 $\varphi(t)$ を与える。
この例題では定数の履歴 $\varphi(t) = x_0$ を使う。
状態は区間上の関数なので、遅延方程式は無限次元の力学系である。

## 段階法による積分

`DdePlan` は一定の遅延を持つ遅延方程式を段階法で積分する。
刻みの長さを最小の遅延以下に抑えるので、遅延した値 $x(t - \tau)$ は初期の履歴か、すでに受理した刻みの連続出力（Dormand–Prince 5(4) の 4 次の補間）から求まり、刻みの中で反復は要らない。
解の導関数は $t_0$ で一般に跳び（$\varphi'(0) = 0$ だが $x'(0)$ は右辺で決まる）、その跳びは $t_0 + \tau$ で 2 階の導関数、$t_0 + 2\tau$ で 3 階の導関数へと伝わる。
`DdePlan::new` はこの不連続点の表を 5 階まで前もって作り、刻みの境目を不連続点にそろえる。
誤差の制御は `DdeOptions::with_ode_options` に渡した `OdeOptions` の許容誤差による。
局所誤差の推定は補間した履歴の誤差を含まない。
段階法の不連続点の伝わり方と連続出力の役割は[遅延微分方程式と段階法](../../algorithms/delay-equations/)で詳しく扱う。

## 平衡点の線形化と特性方程式

$x(t) = x^*$ が一定なら $\beta/(1 + x^{*n}) = \gamma$ なので、正の平衡点は $x^{*n} = \beta/\gamma - 1 = 1$、つまり $x^* = 1$ である。
産生の関数 $g(u) = \beta u/(1 + u^n)$ の微分は

$$
g'(u) = \beta\,\frac{1 + (1 - n)u^n}{(1 + u^n)^2}
$$

で、$x^* = 1$ では $a = g'(1) = \beta(2 - n)/4 = -0.4$ [1/日] になる。
小さな摂動 $u(t) = x(t) - 1$ は線形の遅延方程式

$$
u'(t) = -\gamma\, u(t) + a\, u(t - \tau)
$$

に従う。
$u = e^{\lambda t}$ を代入すると特性方程式

$$
\lambda = -\gamma + a\, e^{-\lambda \tau}
$$

が得られる。
遅延のない常微分方程式と違って根は無限個あり、すべての根の実部が負なら平衡点は漸近安定である。
$\tau = 0$ では根は $\lambda = -\gamma + a = -0.5$ だけで、平衡点は安定である。

## 臨界遅延と発症時の周期

$\tau$ を増やすと、ある値 $\tau_c$ で 1 対の複素共役な根が虚軸を横切る。
$\lambda = i\omega$（$\omega > 0$）を特性方程式に代入して実部と虚部に分けると

$$
0 = -\gamma + a\cos(\omega\tau), \qquad
\omega = -a\sin(\omega\tau)
$$

となる。
2 式を 2 乗して足すと $\omega^2 = a^2 - \gamma^2$ で、

$$
\omega_c = \sqrt{0.16 - 0.01} = \sqrt{0.15} \approx 0.3873 \ \text{[rad/日]}
$$

を得る。
$\cos(\omega\tau) = \gamma/a = -1/4$ と $\sin(\omega\tau) = \omega/|a| > 0$ から $\omega\tau$ は第 2 象限にあり、

$$
\tau_c = \frac{\arccos(-1/4)}{\omega_c} = \frac{1.8235}{0.3873} \approx 4.708 \ \text{[日]}, \qquad
P_c = \frac{2\pi}{\omega_c} \approx 16.22 \ \text{[日]}
$$

となる。
$\tau$ が $\tau_c$ を超えると、この根の対の実部は正になり、平衡点は不安定になって周期 $P_c$ に近い振動が始まる（Hopf 分岐）。
$\tau$ がさらに大きくなると周期倍分岐を経て、$\tau = 17$ 付近では解は非周期的なカオス的な振動になる。

$\tau \ne \tau_c$ での最右の根は閉形式では書けない。
次のセルでは $\tau_c$ の根 $i\omega_c$ から出発し、$\tau$ を少しずつ動かしながら特性方程式に Newton 法を当てて根を追う（継続法）。
これは数値解とは独立な検算で、根の追跡は `Complex64` の演算で行う。

次のブロックは 3 つのセルが共有する定義である。
`production` が $g(u)$、`integrate` が一定の履歴 $x_0$ から間隔 `spacing` の時刻に解を出力する `DdePlan` の求解、`rightmost_root` が上の継続法による特性方程式の根である。

```rust
//| id: ode-mackey-glass-model
//| kind: definitions
//| title: Mackey–Glass 方程式と特性方程式の根
//| crates: [scioxide-core, scioxide-linalg, scioxide-ode]
use scioxide_core::{Complex64, ErrorTolerance, SciOxideError, NormSelection, RealScalar};
use scioxide_linalg::MatrixView;
use scioxide_ode::{DdeOptions, DdePlan, DdeProblem, DdeReport, OdeOptions, OdeOutputSchedule};

/// 産生率 β [1/日]、消失率 γ [1/日]、Hill 係数 n（Mackey と Glass の値）。
pub(crate) const BETA: f64 = 0.2;
pub(crate) const GAMMA: f64 = 0.1;
pub(crate) const HILL: i32 = 10;
/// 平衡点 x* = 1 での g′ の値 a = β(2 − n)/4。
pub(crate) const SLOPE: f64 = BETA * (2 - HILL) as f64 / 4.0;

/// 産生の関数 g(u) = βu/(1 + uⁿ)。
pub(crate) fn production(u: f64) -> f64 {
    BETA * u / (1.0 + RealScalar::powi(u, HILL))
}

/// 一定の履歴 x₀ から求めた解。times は 0 から間隔 spacing の時刻。
pub(crate) struct Path {
    pub(crate) times: Vec<f64>,
    pub(crate) values: Vec<f64>,
    pub(crate) report: DdeReport<f64>,
}

pub(crate) fn integrate(
    tau: f64,
    horizon: f64,
    history: f64,
    tolerance: f64,
    spacing: f64,
) -> Result<Path, String> {
    let rhs = |_t: f64, x: &[f64], delayed: MatrixView<'_, f64>, out: &mut [f64]| {
        out[0] = production(delayed.get(0, 0)?) - GAMMA * x[0];
        Ok::<(), SciOxideError>(())
    };
    let constant = move |_t: f64, out: &mut [f64]| {
        out[0] = history;
        Ok::<(), SciOxideError>(())
    };
    let samples = (horizon / spacing).floor() as usize;
    let times = (1..=samples).map(|i| i as f64 * spacing).collect();
    let schedule = OdeOutputSchedule::Times {
        times,
        initial: true,
        final_state: false,
    };
    let tolerance = ErrorTolerance::scalar(tolerance, tolerance, NormSelection::Infinity)
        .map_err(|e| e.to_string())?;
    let ode = OdeOptions::new()
        .with_error_tolerance(tolerance)
        .with_output_schedule(schedule);
    let options = DdeOptions::new().with_ode_options(ode);
    let plan = DdePlan::new(1, (0.0, horizon), &[tau], &[], options).map_err(|e| e.to_string())?;
    let solution = plan
        .solve(&DdeProblem::new(&rhs, &constant))
        .map_err(|e| e.error().to_string())?;
    let (_, report, trajectory) = solution.into_parts();
    let (times, states, _) = trajectory.into_parts();
    let values = states.iter().map(|s| s.as_slice()[0]).collect();
    Ok(Path {
        times,
        values,
        report,
    })
}

/// 臨界遅延 τ_c = arccos(γ/a)/ω_c と ω_c = √(a² − γ²)（参照値、f64 の標準関数）。
pub(crate) fn critical() -> (f64, f64) {
    let omega = (SLOPE * SLOPE - GAMMA * GAMMA).sqrt();
    ((GAMMA / SLOPE).acos() / omega, omega)
}

/// λ = −γ + a e^{−λτ} の最右の根。τ_c の根 iω_c から τ まで継続法で追う（検算用）。
pub(crate) fn rightmost_root(tau: f64) -> Complex64 {
    let (tau_c, omega_c) = critical();
    let mut lambda = Complex64::new(0.0, omega_c);
    for step in 1..=200 {
        let delay = tau_c + (tau - tau_c) * step as f64 / 200.0;
        for _ in 0..6 {
            let decay = (lambda * Complex64::new(-delay, 0.0)).exp() * SLOPE;
            let residual = lambda + Complex64::new(GAMMA, 0.0) - decay;
            lambda = lambda - residual / (Complex64::new(1.0, 0.0) + decay * delay);
        }
    }
    lambda
}
```

## 振動の開始と遅延埋め込み

次のセルは遅延 $\tau$、積分時間 $T$、履歴の値 $x_0$ を選び、許容誤差 $10^{-8}$ で解を求める。
上のグラフは $x(t)$ で、平衡点 $x^* = 1$ を破線で示す。
下のグラフは後半 $t \ge T/2$ の点 $(x(t), x(t - \tau))$ を描く遅延埋め込みで、平衡点に収束すれば 1 点に、周期解なら閉曲線に、カオス的な解なら帯状の集合になる。
出力の間隔を $\tau$ の整数分の 1 にしてあるので、$x(t - \tau)$ は同じ解の出力を添字でずらして得られる。
表は線形化から求めた $\tau_c$、$\omega_c$、$P_c$、この $\tau$ での最右の根と、数値解の後半から測った振幅と平均周期を並べる。
振幅は後半の $(\max x - \min x)/2$、平均周期は $x = 1$ を下から上へ横切る時刻の間隔の平均である。

```rust
//| id: ode-mackey-glass-onset
//| ref: ode-mackey-glass-onset
//| title: Mackey–Glass 方程式の解と遅延埋め込み
//| run: button
//| uses: [ode-mackey-glass-model]
//| crates: [scioxide-core, scioxide-linalg, scioxide-ode]
//| inputs:
//|   tau: {"type":"range","label":"遅延 τ [日]","description":"産生が応じる過去の時刻までの遅れ。","min":2,"max":30,"step":0.1,"value":17}
//|   horizon: {"type":"range","label":"積分時間 T [日]","description":"解を求める時間。","min":200,"max":1500,"step":50,"value":600}
//|   history: {"type":"range","label":"履歴の値 x₀ [-]","description":"区間 [−τ, 0] の一定の履歴。","min":0.2,"max":2,"step":0.05,"value":0.5}
//| cases:
//|   - {"id":"below-critical","label":"τ = 4","description":"臨界遅延より短く、振動は減衰して平衡点に戻る。","inputs":{"tau":4,"history":1.2}}
//|   - {"id":"limit-cycle","label":"τ = 6","description":"臨界遅延を超え、一定の振幅の周期解になる。","inputs":{"tau":6}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"linearization","path":"/rows/1/1","approx":{"value":4.7082,"atol":1e-3}}
//|       - {"artifact":"linearization","path":"/rows/2/1","approx":{"value":16.2231,"atol":1e-3}}
//|       - {"path":"/outputs/3/state","equals":"satisfied"}
//|   - case: below-critical
//|     expect:
//|       - {"artifact":"linearization","path":"/rows/3/1","approx":{"value":-0.02487,"atol":1e-4}}
//|       - {"artifact":"linearization","path":"/rows/5/1","range":{"max":0.01}}
//|   - case: limit-cycle
//|     expect:
//|       - {"artifact":"linearization","path":"/rows/3/1","approx":{"value":0.02416,"atol":1e-4}}
let spacing = tau / (2.0 * tau).ceil();
let shift = (2.0 * tau).ceil() as usize;
let path = integrate(tau, horizon, history, 1e-8, spacing)?;
let (times, values) = (&path.times, &path.values);
let half = times.len() / 2;
let series: Vec<[f64; 2]> = times.iter().zip(values).map(|(&t, &x)| [t, x]).collect();
let embedding: Vec<[f64; 2]> = (half.max(shift)..values.len())
    .map(|i| [values[i], values[i - shift]])
    .collect();
emit_line_chart!(
    &vec![serde_json::json!({ "name": "x(t)", "points": series })],
    options = &serde_json::json!({
        "xLabel": "時刻 t [日]",
        "yLabel": "血球の濃度 x [-]",
        "annotations": [{
            "kind": "line", "axis": "y", "value": 1.0, "label": "x* = 1",
            "style": { "lineType": "dashed" }
        }]
    })
);
emit_scatter_chart!(
    &vec![serde_json::json!({ "name": "t ≥ T/2", "points": embedding })],
    options = &serde_json::json!({
        "xLabel": "x(t) [-]",
        "yLabel": "x(t − τ) [-]",
        "style": { "symbolSize": 3 }
    })
);

// 後半の振幅と、x = 1 を下から上へ横切る時刻（線形補間）の間隔の平均。
let late = &values[half..];
let amplitude = (late.iter().copied().fold(f64::MIN, f64::max)
    - late.iter().copied().fold(f64::MAX, f64::min))
    / 2.0;
let crossings: Vec<f64> = (half + 1..values.len())
    .filter(|&i| values[i - 1] < 1.0 && values[i] >= 1.0)
    .map(|i| times[i - 1] + spacing * (1.0 - values[i - 1]) / (values[i] - values[i - 1]))
    .collect();
let period = (crossings.len() >= 2)
    .then(|| (crossings[crossings.len() - 1] - crossings[0]) / (crossings.len() - 1) as f64);
let (tau_c, omega_c) = critical();
let root = rightmost_root(tau);
let fixed4 = serde_json::json!({ "fractionDigits": 4 });
let columns = serde_json::json!([
    { "key": "0", "label": "量" },
    { "key": "1", "label": "値", "type": "number", "format": fixed4, "nullText": "横切りが 2 回未満" },
    { "key": "2", "label": "単位" }
]);
let rows = vec![
    ("ω_c（線形化）", Some(omega_c), "rad/日"),
    ("臨界遅延 τ_c（線形化）", Some(tau_c), "日"),
    (
        "発症時の周期 2π/ω_c（線形化）",
        Some(2.0 * std::f64::consts::PI / omega_c),
        "日",
    ),
    ("この τ の最右の根の実部 Re λ", Some(root.re), "1/日"),
    (
        "この τ の線形化の周期 2π/Im λ",
        Some(2.0 * std::f64::consts::PI / root.im),
        "日",
    ),
    ("後半の振幅 (max − min)/2", Some(amplitude), "-"),
    ("後半の平均周期", period, "日"),
];
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "linearization" })
);

let report = &path.report;
let status = report
    .termination()
    .map_or("なし".to_string(), |t| format!("{t:?}"));
let outcome = if report.is_success() {
    Outcome::satisfied("段階法の積分が終端に達した")
} else {
    Outcome::partial("段階法の積分が終端の前に止まった")
        .explanation("図と表は止まった時刻までの解である。")
};
emit_outcome!(
    outcome
        .status(status)
        .diagnostic("受理した刻み", report.accepted_steps() as f64, None)
        .diagnostic("棄却した刻み", report.rejected_steps() as f64, None)
);
```

表の最初の 3 行は入力によらず、$\omega_c = 0.3873$ rad/日、$\tau_c = 4.7082$ 日、$P_c = 16.2231$ 日で、上の導出の値と一致する。
既定値の $\tau = 17$、$x_0 = 0.5$ では積分が `ReachedEnd` で終わり、受理した刻みは 611、棄却した刻みは 122 である。
解は後半で振幅 0.44 の不規則な振動を続け、$x = 1$ を下から上へ横切る間隔の平均は 42.1 日になる。
最右の根は $\operatorname{Re}\lambda = 0.0413$ /日、$2\pi/\operatorname{Im}\lambda = 45.2$ 日で、平衡点が不安定であることと振動の時間の尺度は線形化から分かるが、振幅と波形は非線形の項で決まる。
遅延埋め込みの点は閉曲線にならず、折り重なった帯になる。

$\tau = 4$、$x_0 = 1.2$ のケースでは $\operatorname{Re}\lambda = -0.0249$ /日で、後半の振幅は $5.0 \times 10^{-5}$ まで減り、埋め込みの点は $(1, 1)$ に集まる。
後半の平均周期 14.431 日は線形化の $2\pi/\operatorname{Im}\lambda = 14.430$ 日と小数第 2 位まで一致する。
$\tau = 6$ では平衡点が不安定で、解は振幅 0.157 の周期解に落ち着き、埋め込みの点は 1 本の閉曲線になる。
周期 20.08 日は線形化の 19.45 日より長く、振幅が有限になった非線形の振動では周期も線形化からずれる。
$\tau = 2$ では根が $-0.267 \pm 0.662i$ で減衰が速く、後半には $x = 1$ を横切らないので、平均周期は求まらない。

## 線形化した成長率との比較

振動の開始を線形化と定量的に比べるには、平衡点のごく近くから出発した解の振幅の増減を測る。
次のセルは $\tau$ を臨界遅延の前後の 9 つの値に取り、履歴を $x_0 = 1 + \varepsilon$ として、許容誤差 $10^{-10}$ で $T = 400$ 日まで解く。
各解の極大 $t_j$ での振幅 $A_j = x(t_j) - 1$ のうち、$t_j \ge 50$ 日かつ $10^{-4}\varepsilon < A_j < 0.02$ のものを線形の範囲とみなし、$\ln A_j$ を $t_j$ に最小二乗で当てはめた傾きを観測した成長率とする。
極大の時刻の間隔の平均を観測した周期とする。
グラフは継続法で求めた $\operatorname{Re}\lambda(\tau)$ を破線で描き、観測した成長率を点で重ねる。
$\varepsilon$ を大きくすると振幅がはじめから線形の範囲を外れ、当てはめに使える極大が減る。

```rust
//| id: ode-mackey-glass-growth-rates
//| ref: ode-mackey-glass-growth-rates
//| title: 臨界遅延の前後の成長率と周期
//| run: button
//| uses: [ode-mackey-glass-model]
//| crates: [scioxide-core, scioxide-linalg, scioxide-ode]
//| inputs:
//|   offset_exponent: {"type":"range","label":"履歴のずれの指数 q（ε = 10^q）","description":"平衡点からの履歴のずれ。","min":-5,"max":-1,"step":1,"value":-3}
//| cases:
//|   - {"id":"large-offset","label":"ε = 10⁻¹","description":"振幅がはじめから大きく、線形の範囲の極大が足りない τ が出る。","inputs":{"offset_exponent":-1}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"rates","path":"/rows/3/2","approx":{"value":-0.0061,"atol":5e-4}}
//|       - {"artifact":"rates","path":"/rows/6/2","approx":{"value":0.0073,"atol":5e-4}}
use scioxide_core::RealScalar;

let epsilon = 10.0_f64.powf(offset_exponent);
let delays = [3.5, 4.0, 4.4, 4.5, 4.6, 4.7, 5.0, 5.5, 6.0];
let mut rows = Vec::new();
let mut observed = Vec::new();
for &tau in &delays {
    let path = integrate(tau, 400.0, 1.0 + epsilon, 1e-10, 0.05)?;
    let (t, x) = (&path.times, &path.values);
    let peaks: Vec<(f64, f64)> = (1..x.len() - 1)
        .filter(|&i| x[i] > x[i - 1] && x[i] >= x[i + 1])
        .map(|i| (t[i], x[i] - 1.0))
        .collect();
    let linear: Vec<(f64, f64)> = peaks
        .iter()
        .filter(|&&(time, amplitude)| {
            time >= 50.0 && amplitude > 1e-4 * epsilon && amplitude < 0.02
        })
        .map(|&(time, amplitude)| (time, RealScalar::ln(amplitude)))
        .collect();
    // ln A = c + r t の最小二乗の傾き r。
    let rate = (linear.len() >= 3).then(|| {
        let m = linear.len() as f64;
        let (st, sy) = linear
            .iter()
            .fold((0.0, 0.0), |(a, b), &(t, y)| (a + t, b + y));
        let (mt, my) = (st / m, sy / m);
        let sxy: f64 = linear.iter().map(|&(t, y)| (t - mt) * (y - my)).sum();
        let sxx: f64 = linear.iter().map(|&(t, _)| (t - mt).powi(2)).sum();
        sxy / sxx
    });
    let period = (linear.len() >= 2)
        .then(|| (linear[linear.len() - 1].0 - linear[0].0) / (linear.len() - 1) as f64);
    let root = rightmost_root(tau);
    let theory_period = 2.0 * std::f64::consts::PI / root.im;
    let status = path
        .report
        .termination()
        .map_or("なし".to_string(), |s| format!("{s:?}"));
    if let Some(r) = rate {
        observed.push([tau, r]);
    }
    rows.push((
        tau,
        root.re,
        rate,
        theory_period,
        period,
        linear.len(),
        status,
    ));
}

let theory: Vec<[f64; 2]> = (0..=60)
    .map(|i| 3.4 + 2.7 * i as f64 / 60.0)
    .map(|tau| [tau, rightmost_root(tau).re])
    .collect();
emit_chart!(serde_json::json!({
```

既定値の $\varepsilon = 10^{-3}$ では、9 つの $\tau$ のすべてで観測した成長率の符号と大きさが線形化の $\operatorname{Re}\lambda$ に合う。
$\tau \le 4.6$ では相対差が $2 \times 10^{-4}$ 以下で、たとえば $\tau = 4.5$ では $-6.1017 \times 10^{-3}$ と $-6.1022 \times 10^{-3}$ /日である。
$\tau = 4.7$ では $\operatorname{Re}\lambda = -2.25 \times 10^{-4}$ /日とほぼ 0 で、観測値 $-2.26 \times 10^{-4}$ /日も負になり、まだ臨界遅延の手前にあることが分かる。
$\tau = 5$、5.5、6 では成長率が正になり、振幅が 0.02 を超えるまでの極大だけを使うので、使える極大は 20、7、4 個に減る。
このとき観測値は $\operatorname{Re}\lambda$ より 0.6% から 1.1% 小さい。
当てはめに振幅 0.02 近くまでの極大を使うので、振幅の成長を抑える非線形の項の影響を受けていると考えられる。
観測した周期は $\tau = 4.7$ で 16.2025 日と $P_c = 16.2231$ 日に近く、$\tau = 6$ の 19.45 日まで $2\pi/\operatorname{Im}\lambda$ と小数第 1 位まで一致する。

$\varepsilon = 10^{-1}$ では、振幅がはじめから線形の範囲を外れる。
$\tau \ge 4.7$ では 0.02 より小さい極大が 1 つもなく、成長率は求まらない。
$\tau = 4.6$ では観測値が $-3.40 \times 10^{-3}$ /日と、線形化の $-3.07 \times 10^{-3}$ /日から 1 割ずれる。
振幅の下限 $10^{-4}\varepsilon$ は、減衰して丸め誤差の水準に近づいた極大を当てはめから除くためのものである。

## 履歴の小さな差の拡大

$\tau = 17$ の解はカオス的で、初期の履歴のわずかな差が時間とともに指数的に広がる。
次のセルは $\tau = 17$、履歴 $x_0 = 0.5$ の解 $x_A$ と、履歴を $0.5 + \delta$ にした解 $x_B$ を同じ許容誤差 $10^{p}$ で求める。
さらに、履歴が $x_A$ と同じで許容誤差を $10^{p-2}$ にした解 $x_C$ を求め、$|x_C - x_A|$ を $x_A$ の数値誤差の目安とする。
グラフは $|x_B - x_A|$ と $|x_C - x_A|$ の 5 日ごとの最大値を対数の縦軸に描く。
表は、$|x_B - x_A|$ が初めて 0.1 を超えた時刻と、5 日ごとの最大値が $10\delta$ から $10^{-2}$ の間にある区間の $\ln$ に当てはめた増加率を示す。
増加率はこの解の最大 Lyapunov 指数の目安になる。

```rust
//| id: ode-mackey-glass-sensitivity
//| ref: ode-mackey-glass-sensitivity
//| title: τ = 17 で履歴の差が広がる様子
//| run: button
//| uses: [ode-mackey-glass-model]
//| crates: [scioxide-core, scioxide-linalg, scioxide-ode]
//| inputs:
//|   offset_exponent: {"type":"range","label":"履歴の差の指数 q（δ = 10^q）","description":"2 つの解の履歴の差。","min":-10,"max":-4,"step":1,"value":-8}
//|   horizon: {"type":"range","label":"積分時間 T [日]","description":"解を求める時間。","min":1000,"max":6000,"step":250,"value":4000}
//|   tolerance_exponent: {"type":"range","label":"許容誤差の指数 p（ε = 10^p）","description":"x_A と x_B の絶対・相対許容誤差。x_C は 10^(p−2)。","min":-11,"max":-6,"step":1,"value":-10}
//| cases:
//|   - {"id":"loose-tolerance","label":"ε = 10⁻⁶","description":"数値誤差が履歴の差 10⁻⁸ を上回り、2 つの曲線の区別がなくなる。","inputs":{"tolerance_exponent":-6}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"separation","path":"/rows/0/1","range":{"min":2000,"max":4000}}
//|       - {"artifact":"separation","path":"/rows/0/2","range":{"min":0.003,"max":0.012}}
use scioxide_core::RealScalar;

let delta = 10.0_f64.powf(offset_exponent);
let tolerance = 10.0_f64.powf(tolerance_exponent);
let a = integrate(17.0, horizon, 0.5, tolerance, 0.5)?;
let b = integrate(17.0, horizon, 0.5 + delta, tolerance, 0.5)?;
let c = integrate(17.0, horizon, 0.5, tolerance / 100.0, 0.5)?;
let difference = |other: &Path| -> Vec<f64> {
    a.values
        .iter()
        .zip(&other.values)
        .map(|(x, y)| (x - y).abs())
        .collect()
};
let (perturbed, numerical) = (difference(&b), difference(&c));
// 5 日（10 点）ごとの最大値。0 は対数の縦軸に描けないので除く。
let envelope = |values: &[f64]| -> Vec<[f64; 2]> {
    values
        .chunks(10)
        .enumerate()
        .map(|(j, chunk)| [a.times[10 * j], chunk.iter().copied().fold(0.0, f64::max)])
        .filter(|p| p[1] > 0.0)
        .collect()
};
let (upper, noise) = (envelope(&perturbed), envelope(&numerical));
let separated = perturbed.iter().position(|&d| d > 0.1).map(|i| a.times[i]);
let growth: Vec<(f64, f64)> = upper
    .iter()
    .filter(|p| p[1] > 10.0 * delta && p[1] < 1e-2)
    .map(|p| (p[0], RealScalar::ln(p[1])))
    .collect();
let rate = (growth.len() >= 3).then(|| {
    let m = growth.len() as f64;
    let (mt, my) = growth
        .iter()
        .fold((0.0, 0.0), |(s, r), &(t, y)| (s + t / m, r + y / m));
    let sxy: f64 = growth.iter().map(|&(t, y)| (t - mt) * (y - my)).sum();
    let sxx: f64 = growth.iter().map(|&(t, _)| (t - mt).powi(2)).sum();
    sxy / sxx
});
emit_chart!(serde_json::json!({
    "kind": "xy",
    "xLabel": "時刻 t [日]",
    "yLabel": "解の差の 5 日ごとの最大値 [-]",
    "yType": "log",
    "dataZoom": true,
    "tooltip": true,
    "layers": [
        { "id": "perturbed", "kind": "line", "name": "|x_B − x_A|（履歴の差 δ）", "points": upper },
        { "id": "numerical", "kind": "line", "name": "|x_C − x_A|（許容誤差の差）", "points": noise }
    ],
    "annotations": [{
        "kind": "line", "axis": "y", "value": delta, "label": "δ", "style": { "lineType": "dashed" }
    }]
}));
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let fixed1 = serde_json::json!({ "fractionDigits": 1 });
let columns = serde_json::json!([
    { "key": "0", "label": "履歴の差 δ [-]", "type": "number", "format": sci3 },
    {
        "key": "1",
        "label": "差が 0.1 を超えた時刻 [日]",
        "type": "number",
        "format": fixed1,
        "nullText": "超えない"
    },
    { "key": "2", "label": "増加率 [1/日]", "type": "number", "format": sci3, "nullText": "点が不足" },
    { "key": "3", "label": "|x_C − x_A| の最大値 [-]", "type": "number", "format": sci3 }

let rows = vec![(delta, separated, rate, worst)];
emit_table_with_columns!(

let outcome = if complete {
    Outcome::satisfied("3 つの解がすべて終端に達した")
} else {

};

    .report
    .termination()
    .map_or("なし".to_string(), |t| format!("{t:?}"));
emit_outcome!(outcome.status(status).diagnostic(
    "x_A の受理した刻み",
    a.report.accepted_steps() as f64,
    None
```

既定値（$\delta = 10^{-8}$、$T = 4000$ 日、$\varepsilon = 10^{-10}$）では、$|x_B - x_A|$ の 5 日ごとの最大値は $t = 1000$ 日で $3.8 \times 10^{-6}$、2500 日で $6.0 \times 10^{-3}$ に増え、3013 日で初めて 0.1 を超える。
増加率は $4.4 \times 10^{-3}$ /日で、差が $e$ 倍になるのに約 230 日かかる。
$\delta$ を $10^{-4}$ にすると 0.1 を超える時刻は 1006.5 日、$10^{-10}$ にすると 3741.5 日で、$\delta$ を 1 桁小さくするごとに平均で約 460 日遅れる。

数値誤差の目安 $|x_C - x_A|$ も同じ割合で増え、2500 日で $2.4 \times 10^{-5}$、3500 日で $6.4 \times 10^{-3}$ になり、4000 日までの最大値は 0.14 に達する。
許容誤差 $10^{-10}$ の解は、3500 日から 4000 日の間に数値誤差だけで 0.1 程度の差を持つようになる。
3000 日までは $|x_B - x_A|$ が $|x_C - x_A|$ の数十倍から 300 倍程度あるので、そこまでの分離は履歴の差によるものと読める。
許容誤差を $10^{-6}$ にしたケースでは、$|x_C - x_A|$ がはじめから $4 \times 10^{-7}$ と $\delta$ より大きく、2000 日で 0.4 に達する。
このとき $|x_B - x_A|$ は履歴の差ではなく数値誤差の違いを表していて、0.1 を超える時刻 2129 日は $\delta$ の効果を表さない。
カオス的な解では局所誤差が履歴の差と同じように拡大されるので、1 本の数値解の細部が信頼できる時間は許容誤差で決まる。

## まとめ

`DdePlan` は一定の遅延を持つ遅延方程式を段階法で解き、初期時刻から伝わる導関数の不連続点を刻みの境目にそろえる。
Mackey–Glass 方程式を平衡点 $x^* = 1$ で線形化すると特性方程式 $\lambda = -\gamma + a e^{-\lambda\tau}$（$a = -0.4$）が得られ、臨界遅延 $\tau_c \approx 4.708$ 日と発症時の周期 $2\pi/\sqrt{0.15} \approx 16.22$ 日が閉形式で求まる。
平衡点の近くから出発した数値解の振幅の成長率と周期は、継続法で追った最右の根と比べられる。
カオス的な $\tau = 17$ の解では履歴の差が指数的に広がるので、1 本の数値解の細部は長い時間の後には許容誤差とともに変わり、長い時間について比べられるのは遅延埋め込みの形や統計的な量になる。
