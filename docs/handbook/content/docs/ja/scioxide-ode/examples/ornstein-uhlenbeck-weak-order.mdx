確率微分方程式の数値解の誤差には、1 本の経路ごとの近さを測る強収束と、期待値などの分布の量の近さを測る弱収束の 2 つの見方がある。
期待値を Monte Carlo 法で推定すると、離散化による偏りに、有限個の経路による標本誤差が加わる。
この例題では Ornstein–Uhlenbeck 過程を Euler–Maruyama 法で解き、期待値の偏りを閉形式で、標本誤差を標準誤差で求めて別々に示す。
刻み幅を半分にするごとに偏りが半分になること（弱次数 1）と、細かい刻みでは標本誤差が偏りを上回ることを確かめる。

## Ornstein–Uhlenbeck 過程

Ornstein–Uhlenbeck 過程は

$$
dX_t = -\theta X_t\,dt + \sigma\,dW_t, \qquad X_0 = x_0
$$

で定まる。
$W_t$ は標準 Wiener 過程、$\theta > 0$ [1/s] は平均への戻りの速さ、$\sigma$ [$\mathrm{s}^{-1/2}$] はノイズの強さである。
粘性のある流体中の粒子の速度（Langevin 方程式）や、金利の Vasicek モデルがこの形をしている。
この例題では $x_0 = 1$、$\sigma = 0.5\ \mathrm{s}^{-1/2}$、終端 $T = 1$ s に固定し、$\theta$ を入力にする。

拡散係数 $\sigma$ が状態によらない（加法的なノイズ）ので、Itô 積分と Stratonovich 積分の差を生む補正項 $\tfrac12 \sigma\,\partial\sigma/\partial x$ は 0 で、2 つの解釈は同じ過程を表す。
変数変換 $e^{\theta t}X_t$ に Itô の公式を当てると

$$
X_T = x_0 e^{-\theta T} + \sigma \int_0^T e^{-\theta(T - s)}\,dW_s
$$

が得られる。
右辺の確率積分は平均 0 の正規分布に従い、Itô の等長性から分散が求まるので、

$$
\mathbb{E}[X_T] = x_0 e^{-\theta T}, \qquad
\operatorname{Var}[X_T] = \frac{\sigma^2}{2\theta}\left(1 - e^{-2\theta T}\right)
$$

である。
$\theta = 1$ s⁻¹ では $\mathbb{E}[X_1] = e^{-1} \approx 0.36788$、$\operatorname{Var}[X_1] = 0.125(1 - e^{-2}) \approx 0.10808$ になる。

## Euler–Maruyama 法の平均と分散の閉形式

刻み幅 $h = T/N$ の Euler–Maruyama 法は、Wiener 増分 $\Delta W_k \sim N(0, h)$ を使って

$$
X_{k+1} = X_k - \theta h X_k + \sigma\,\Delta W_k = q X_k + \sigma\,\Delta W_k, \qquad q = 1 - \theta h
$$

と進める。
増分は互いに独立で $X_k$ とも独立なので、数値解 $X_N$ の平均と分散は等比数列の和として閉じた形で求まる。

$$
\mathbb{E}[X_N] = x_0 q^N, \qquad
\operatorname{Var}[X_N] = \sigma^2 h \sum_{k=0}^{N-1} q^{2k} = \sigma^2 h\,\frac{1 - q^{2N}}{1 - q^2}
$$

（$q^2 = 1$ のときは $\sigma^2 h N$）である。
平均の偏り $b(h) = x_0 q^N - x_0 e^{-\theta T}$ は、$N \ln(1 - \theta h) = -\theta T - \theta^2 T h/2 + O(h^2)$ から

$$
b(h) = -\frac{\theta^2 T}{2}\, x_0 e^{-\theta T}\, h + O(h^2)
$$

となり、刻み幅に比例する。
これが Euler–Maruyama 法の弱次数 1 にあたる。
一般の SDE では、係数の滑らかさと増大度の条件のもとで、滑らかな関数 $\varphi$ について $|\mathbb{E}[\varphi(X_N)] - \mathbb{E}[\varphi(X_T)]| = O(h)$ が成り立つ（Kloeden と Platen、*Numerical Solution of Stochastic Differential Equations*、Springer、1992、§14.1）。
$\theta h > 1$ では $q < 0$ となって数値解の平均が符号を変えながら減り、$\theta h > 2$ では $|q| > 1$ で平均も分散も増える。

次のブロックは 2 つのセルが共有する定義である。
`X0`、`SIGMA`、`END` が $x_0$、$\sigma$、$T$、`exact_mean` が $\mathbb{E}[X_t] = x_0 e^{-\theta t}$、`em_moments` が $k$ 刻み目の Euler–Maruyama 法の平均 $x_0 q^k$ と分散 $\sigma^2 h (1 - q^{2k})/(1 - q^2)$ に対応する。

```rust
//| id: ode-ornstein-uhlenbeck-model
//| kind: definitions
//| title: Ornstein–Uhlenbeck 過程と Euler–Maruyama 法の平均と分散
//| crates: [scioxide-core]
use scioxide_core::RealScalar;

/// 初期値 x₀ [-]、ノイズの強さ σ [s^(−1/2)]、終端 T [s]。
pub(crate) const X0: f64 = 1.0;
pub(crate) const SIGMA: f64 = 0.5;
pub(crate) const END: f64 = 1.0;

/// 厳密な平均 E[X_t] = x₀ e^{−θt}。
pub(crate) fn exact_mean(theta: f64, time: f64) -> f64 {
    X0 * RealScalar::exp(-theta * time)
}

/// 刻み幅 h の Euler–Maruyama 法の k 刻み目の平均 x₀qᵏ と分散 σ²h(1 − q²ᵏ)/(1 − q²)。
/// q = 1 − θh。q² = 1 のときの分散は σ²hk。
pub(crate) fn em_moments(theta: f64, h: f64, steps: usize) -> (f64, f64) {
    let q = 1.0 - theta * h;
    let mean = X0 * RealScalar::powi(q, steps as i32);
    let variance = if (1.0 - q * q).abs() < 1e-12 {
        SIGMA * SIGMA * h * steps as f64
    } else {
        SIGMA * SIGMA * h * (1.0 - RealScalar::powi(q, 2 * steps as i32)) / (1.0 - q * q)
    };
    (mean, variance)
}
```

## 偏りと標本誤差の分離

$M$ 本の独立な経路の終端の値 $X_N^{(1)}, \ldots, X_N^{(M)}$ の標本平均 $\bar{X}_N$ で期待値を推定すると、誤差は

$$
\bar{X}_N - \mathbb{E}[X_T] =
\underbrace{\left(\mathbb{E}[X_N] - \mathbb{E}[X_T]\right)}_{\text{偏り } b(h)} +
\underbrace{\left(\bar{X}_N - \mathbb{E}[X_N]\right)}_{\text{標本誤差}}
$$

に分かれる。
偏りは $h$ だけで決まる確定した量で、上の閉形式で正確に分かる。
標本誤差は平均 0、標準偏差 $\sqrt{\operatorname{Var}[X_N]/M}$ の確率変数で、標本分散 $s^2$ から標準誤差 $\mathrm{SE} = s/\sqrt{M}$ を求め、$\pm 2\,\mathrm{SE}$ を約 95% の範囲の目安にする。
偏りは $h$ に比例して減るが、標本誤差は $M^{-1/2}$ でしか減らないので、$h$ を小さくしていくと、ある所から先は観測した誤差が標本誤差で決まり、偏りの減少は見えなくなる。
偏りを $\varepsilon$ 程度まで下げるには $h \propto \varepsilon$、標本誤差を同じ程度にするには $M \propto \varepsilon^{-2}$ が要り、計算コスト $MN$ は $\varepsilon^{-3}$ に比例する。

## 経路を並べた 1 つの系としての積分

`solve_sde` は、ドリフト $a(t, X)$ と拡散の積 $B(t, X)\,\Delta W$ を返すクロージャ、時刻の格子、Wiener 増分の行列、初期値を受け取り、Euler–Maruyama 法で全経路の値を行列で返す。
増分の行列は行 $i$ が区間 $[t_i, t_{i+1}]$ の増分、列 $j$ が Wiener 過程の成分 $j$ である。
ソルバーは乱数を生成しないので、増分は呼び出し側が scioxide-random で作る。
`solve_sde` は内部で `SdeMethod::EulerMaruyama` の `advance` を呼び、終了状態が成功でなければ `PartialFailure` を返す。

この例題では $M$ 本の経路を $M$ 次元の状態の成分として並べ、Wiener 過程も $M$ 成分にする。
ドリフト $-\theta X_j$ と拡散 $\sigma\,\Delta W_j$ は成分ごとに閉じているので、Euler–Maruyama 法の 1 刻みは $M$ 本の経路を別々に 1 刻み進めるのと同じ計算になる。
経路ごとに別の問題として解くなら `solve_ensemble_into` が使える。
これは各メンバーに別のパラメータと作業領域を渡して独立な求解を逐次または並列に実行する関数だが、この例題のように成分ごとに閉じた系なら、1 回の呼び出しで足りる。

Wiener 増分は `Philox4x64` の乱数生成器から作る。
シード $s$ から作ったルート生成器を `SplittableRng::split` で経路ごとの系列 $j = 0, \ldots, M - 1$ に分け、系列 $j$ から経路 $j$ の最も細かい刻み $h_{\min} = T/N_{\max}$ の増分を $N_{\max}$ 個引く。
系列は経路の番号だけで決まるので、$M$ を増やしても前からある経路は変わらない。
粗い刻み $h = 2^l h_{\min}$ の増分は、細かい増分を $2^l$ 個ずつ足して作る。
独立な正規分布の和なので、粗い増分も正確に $N(0, h)$ に従い、すべての刻み幅で同じ Brown 運動の経路を使うことになる。

## 刻み幅を変えた期待値の推定

次のセルは経路の数 $M$、最も細かい刻みの数 $N_{\max} = 2^K$、$\theta$、乱数のシードを選び、$N = 1, 2, 4, \ldots, N_{\max}$ のそれぞれで終端の値の標本平均と標本分散を求める。
表は各 $N$ の閉形式の平均 $\mathbb{E}[X_N]$、標本平均、2SE、偏り $b(h)$、標本誤差 $\bar{X}_N - \mathbb{E}[X_N]$、閉形式の分散と標本分散を並べる。
「偏りの次数」の列は 1 つ粗い刻みとの偏りの比 $\log_2\left(b(2h)/b(h)\right)$ で、弱次数 1 なら 1 に近づく。
偏りの符号が変わる刻みでは比が負になり、次数は定義されない。
このセルは $\theta$、各刻み幅の誤差と 2SE、最も細かい刻みの各時刻の標本平均と 2SE を次のセルに渡す。

//| title: 刻み幅ごとの期待値の偏りと標本誤差
//| run: button
//| cache: inputs

//| inputs:
//|   paths: {"type":"range","label":"経路の数 M [本]","description":"標本平均に使う独立な経路の数。","min":1000,"max":20000,"step":1000,"value":10000}
//|   finest_level: {"type":"range","label":"最も細かい刻みの指数 K（N_max = 2^K）","description":"刻みの数を 1 から 2^K まで倍々に変える。","min":3,"max":6,"step":1,"value":6}

//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"levels","path":"/rows/6/4","approx":{"value":-2.892917e-3,"rtol":1e-6}}
//|       - {"artifact":"levels","path":"/rows/6/5","range":{"min":-6.6e-3,"max":6.6e-3}}
//|       - {"artifact":"levels","path":"/rows/6/6","approx":{"value":1.0095,"atol":1e-3}}
//|       - {"artifact":"levels","path":"/rows/6/7","approx":{"value":0.1092012,"rtol":1e-6}}
//|   - case: fast-reversion
//|     expect:
//|       - {"artifact":"levels","path":"/rows/0/1","approx":{"value":-3.0,"rtol":1e-12}}
//|       - {"artifact":"levels","path":"/rows/1/6","equals":null}
use scioxide_core::{SciOxideError, RealScalar};
use scioxide_linalg::MatrixView;
use scioxide_random::{Distribution, Normal, Philox4x64, SeedableRng, SplittableRng};

let (m, finest) = (paths as usize, 1_usize << (finest_level as u32));
// 経路 j の細かい増分を系列 j から引き、行 k・列 j に置く。
let normal =
    Normal::new(0.0, RealScalar::sqrt(END / finest as f64)).map_err(|e| e.to_string())?;
let root = Philox4x64::from_seed(seed as u64);
let mut fine = vec![0.0; finest * m];
for j in 0..m {
    let mut stream = root.split(j as u64).map_err(|e| e.to_string())?;
    for k in 0..finest {
        fine[k * m + j] = normal.sample(&mut stream).map_err(|e| e.to_string())?;
    }
}
let exact = exact_mean(theta, END);
let (mut rows, mut levels, mut mean_path) = (Vec::new(), Vec::new(), Vec::new());
let mut previous_bias: Option<f64> = None;
for level in 0..=finest_level as u32 {
    let (steps, ratio) = (1_usize << level, finest >> level);
    let h = END / steps as f64;
    // 粗い増分は細かい増分を ratio 個ずつ足したもの（同じ Brown 運動の経路）。
    let mut increments = vec![0.0; steps * m];
    for (k, row) in increments.chunks_exact_mut(m).enumerate() {
        for fine_row in fine[k * ratio * m..(k + 1) * ratio * m].chunks_exact(m) {
            row.iter_mut().zip(fine_row).for_each(|(w, dw)| *w += dw);
        }
    }
    let times: Vec<f64> = (0..=steps).map(|k| k as f64 * h).collect();
    let view = MatrixView::from_slice(steps, m, &increments).map_err(|e| e.to_string())?;
    // 経路 j は状態の成分 j。ドリフト −θX_j と拡散 σΔW_j は成分ごとに閉じている。
    let drift = |_t: f64, x: &[f64], a: &mut [f64]| {
        a.iter_mut().zip(x).for_each(|(a, &x)| *a = -theta * x);
        Ok::<(), SciOxideError>(())
    };
    let diffusion = |_t: f64, _x: &[f64], dw: &[f64], b: &mut [f64]| {
        b.iter_mut().zip(dw).for_each(|(b, &w)| *b = SIGMA * w);
        Ok::<(), SciOxideError>(())
    };
    let path = scioxide_ode::solve_sde(drift, diffusion, &times, view, &vec![X0; m])
        .map_err(|e| e.error().to_string())?;
    // 各時刻の標本平均と 2SE（標本分散は M − 1 で割る）。
    let moments: Vec<(f64, f64, f64)> = path
        .as_slice()
        .chunks_exact(m)
        .map(|values| {
            let mean = values.iter().sum::<f64>() / m as f64;
            let variance =
                values.iter().map(|x| (x - mean).powi(2)).sum::<f64>() / (m - 1) as f64;
            (mean, variance, 2.0 * RealScalar::sqrt(variance / m as f64))
        })
        .collect();
    let (sample_mean, sample_variance, two_se) = moments[steps];
    let (em_mean, em_variance) = em_moments(theta, h, steps);
    let bias = em_mean - exact;
    let order = previous_bias
        .map(|coarse| coarse / bias)
        .filter(|&ratio| ratio > 0.0)
        .map(RealScalar::log2);
    previous_bias = Some(bias);
    let sampling = sample_mean - em_mean;
    rows.push((
        steps,
        em_mean,
        sample_mean,
        two_se,
        bias,
        sampling,
        order,
        em_variance,
        sample_variance,
    ));
    levels.push([h, bias.abs(), (sample_mean - exact).abs(), two_se]);
    if steps == finest {
        mean_path = times
            .iter()
            .zip(&moments)
            .map(|(&t, &(mean, _, se))| [t, mean, se])
            .collect();
    }
}

既定値（$M = 10000$、$N_{\max} = 64$、$\theta = 1$ s⁻¹、シード 1）では、厳密な平均は $\mathbb{E}[X_1] = 0.36788$ である。
偏りは $N = 1$ の $-0.368$ から $N = 64$ の $-2.89 \times 10^{-3}$ まで、刻みを半分にするごとにほぼ半分になり、偏りの次数は 1.642、1.195、1.085、1.040、1.019、1.0095 と 1 に近づく。
粗い刻みで次数が 1 より大きいのは、偏りの展開の $O(h^2)$ の項が残っているためである。
2SE は $N \ge 2$ で $6.6 \times 10^{-3}$ から $7.9 \times 10^{-3}$ の間にあり、偏りが 2SE を上回るのは $N \le 16$ の刻みだけである。
$N = 32$ と $N = 64$ では偏りが 2SE より小さく、標本平均だけからは偏りを確かめられない。

標本誤差 $\bar{X}_N - \mathbb{E}[X_N]$ は $N \ge 2$ でどれも $1.6 \times 10^{-3}$ から $1.8 \times 10^{-3}$ の間にあり、刻みによらずほぼ同じ値になる。
すべての刻み幅で同じ Brown 運動の経路を使ったので、標本誤差の大部分が共通になるためである。
独立な増分を刻み幅ごとに引くと、標本誤差は刻みごとにばらばらの値になり、2SE の範囲で偏りの差を読み取りにくくなる。
分散は、閉形式と標本分散の差が $N \ge 4$ で $4.1 \times 10^{-4}$ 以下である。
標本分散の標準誤差はおよそ $\sqrt{2/M}\,s^2 \approx 1.5 \times 10^{-3}$ なので、この差は標本のばらつきの範囲にある。
$N = 64$ の分散 0.10920 は厳密な $\operatorname{Var}[X_1] = 0.10808$ より $1.1 \times 10^{-3}$ 大きく、分散にも刻み幅に比例する偏りがある。

$M = 1000$ にすると 2SE は $2.1 \times 10^{-2}$ から $3.2 \times 10^{-2}$ に増え、偏りが 2SE を上回るのは $N \le 8$ だけになる。
$\theta = 4$ s⁻¹ では $N = 1$ で $q = -3$、$N = 2$ で $q = -1$、$N = 4$ で $q = 0$ となり、閉形式の平均は $-3$、1、0 と符号を変える。
偏りの符号が変わるこれらの刻みでは次数が定義されず、$N = 8$ 以降の次数は 0.346、0.797、0.922、0.966 と遅れて 1 に近づく。
$\theta h$ が小さくなるまでは、偏りの展開の主要項が支配的にならないためである。

## 偏りの減り方と標本平均の時間変化

次のセルは前のセルの結果を 2 つのグラフに描く。
上のグラフは両対数の軸で、閉形式の偏り $|b(h)|$（破線）、観測した誤差 $|\bar{X}_N - \mathbb{E}[X_T]|$（記号）、2SE（点線）を刻み幅 $h$ に対して描く。
偏りの線の傾きが 1 なら弱次数 1 で、観測した誤差が 2SE の線より下にある刻みでは、偏りは標本誤差に埋もれている。
下のグラフは最も細かい刻みでの標本平均 $\bar{X}(t_k)$ と $\pm 2\,\mathrm{SE}$ の帯で、厳密な平均 $x_0 e^{-\theta t}$ を破線、同じ刻みの Euler–Maruyama 法の平均 $x_0 q^k$ を点で重ねる。

## まとめ

Euler–Maruyama 法の期待値の誤差は、刻み幅に比例する偏りと、経路の数の平方根に反比例する標本誤差の和である。
Ornstein–Uhlenbeck 過程では数値解の平均 $x_0(1 - \theta h)^N$ と分散が閉形式で求まるので、偏りを標本誤差と混ぜずに正確に示せる。
`solve_sde` は乱数を生成せず、Wiener 増分の行列を受け取るので、scioxide-random の `SplittableRng::split` で経路ごとの系列を作れば、結果はシードと経路の番号で決まる。
細かい増分を足して粗い増分を作ると、すべての刻み幅で同じ Brown 運動の経路を使え、刻み幅による違いが標本のばらつきに隠れにくくなる。
弱次数を測るときは、偏りが 2SE より十分大きい刻み幅の範囲だけで傾きを読み、それより細かい刻みでは経路の数を増やす。
