ばね・振り子の微小振動、LC 回路、分子の結合の伸縮など、多くの振動は調和振動子で近似できる。
厳密解ではエネルギーが一定で、相平面の軌道は閉じた楕円になる。
数値解法で何百周期も積分すると、方式によってエネルギーが少しずつ減るもの、丸め誤差の範囲で保つもの、一定の幅で振動するものに分かれる。
この例題では古典的 RK4（`ClassicalRk4`）、2 段 4 次の Gauss 法（`GaussRk`）、Störmer–Verlet 法（`StormerVerlet`）を同じ固定刻みで比べ、違いを 1 刻みの写像の固有値から説明する。
シンプレクティック性と修正 Hamiltonian の一般論は[シンプレクティック積分と拘束のある力学系](../../algorithms/geometric-integrators/)で扱う。

## 調和振動子とエネルギー

質量 1 kg、角振動数 $\omega$ [rad/s] の調和振動子の運動方程式は、変位 $q$ [m] と運動量 $p$ [kg·m/s] で

$$
q' = p, \qquad p' = -\omega^2 q
$$

である。
エネルギー

$$
E(q, p) = \frac{p^2}{2} + \frac{\omega^2 q^2}{2}
$$

は $\frac{dE}{dt} = p\,p' + \omega^2 q\,q' = 0$ を満たし、一定である。
$(q, p) = (1, 0)$ から始めると、厳密解は $q = \cos\omega t$、$p = -\omega\sin\omega t$ で、規格化した相平面 $(q, p/\omega)$ では単位円を一定の速さで回る。
周期は $P = 2\pi/\omega$ である。

$w = q - i p/\omega$ とおくと $w' = i\omega w$ なので、この系は試験方程式 $y' = \lambda y$ の $\lambda = i\omega$（純虚数）の場合にあたる。
線形の方式では 1 刻みの写像は $2 \times 2$ の行列 $\Phi$ で、$\xi = h\omega$ だけで決まり、$K$ 周期（1 周期 $m$ 刻みなら $Km$ 刻み）の後の状態は $\Phi^{Km}$ を掛けたものである。

次のブロックは 2 つのセルが使うモデルである。
`Oscillator` は $f(t, y) = (p, -\omega^2 q)$ を `OdeSystem` として実装し、`GaussRk` の Newton 法のために定数の Jacobian を与える。

```rust
//| id: ode-oscillator-model
//| kind: definitions
//| title: 調和振動子の右辺と定数の Jacobian
//| crates: [scioxide-core, scioxide-linalg, scioxide-ode]
use scioxide_core::{SciOxideError, SolveContext};
use scioxide_linalg::MatrixViewMut;
use scioxide_ode::OdeSystem;

/// q′ = p、p′ = −ω² q。フィールドは ω [rad/s]。
pub(crate) struct Oscillator(pub(crate) f64);

impl OdeSystem<f64> for Oscillator {
    fn dimension(&self) -> usize {
        2
    }
    fn rhs(
        &self,
        _: f64,
        y: &[f64],
        dydt: &mut [f64],
        _: &mut SolveContext<'_, '_>,
    ) -> Result<(), SciOxideError> {
        dydt[0] = y[1];
        dydt[1] = -self.0 * self.0 * y[0];
        Ok(())
    }
    fn jacobian(
        &self,
        _: f64,
        _: &[f64],
        jac: &mut MatrixViewMut<'_, f64>,
        _: &mut SolveContext<'_, '_>,
    ) -> Result<Option<()>, SciOxideError> {
        jac.set(0, 0, 0.0)?;
        jac.set(0, 1, 1.0)?;
        jac.set(1, 0, -self.0 * self.0)?;
        jac.set(1, 1, 0.0)?;
        Ok(Some(()))
    }
    fn jacobian_is_constant(&self) -> bool {
        true
    }
}
```

## 長時間のエネルギーと軌道

次のセルは、角振動数 $\omega$、周期の数 $K$、1 周期の刻みの数 $m$ を選び、刻み $h = P/m$ で $K$ 周期を 3 つの方式で解く。
`ClassicalRk4` と `GaussRk` は `OdeMethod` の `advance` で、受理した刻みごとの状態を `OdeTrajectory` に残す。
`GaussRk` の段は許容誤差 $10^{-12}$ で解く。
Störmer–Verlet 法は $\nabla T(p) = p$、$\nabla V(q) = \omega^2 q$ を `HamiltonianFn` で与え、`StormerVerlet::advance` の受け取り手で各刻みの状態を集める。
上の図は規格化した相平面 $(q, p/\omega)$、下の図は相対エネルギー誤差 $(E_n - E_0)/E_0$ を経過した周期の数 $t/P$ に対して描く。
表は最大の相対エネルギー誤差、次節の式による理論値、終端での解析解との差 $\sqrt{(q - q_{\mathrm{exact}})^2 + ((p - p_{\mathrm{exact}})/\omega)^2}$、刻みの数、評価回数、終了状態を示す。

```rust
//| id: ode-oscillator-energy
//| ref: ode-oscillator-energy
//| title: 調和振動子の長時間のエネルギーを RK4・Gauss 法・Störmer–Verlet 法で比べる
//| run: reactive
//| uses: [ode-oscillator-model]
//| crates: [scioxide-core, scioxide-linalg, scioxide-ode]
//| inputs:
//|   oscillator_frequency: {"type":"range","label":"角振動数 ω [rad/s]","description":"周期 P = 2π/ω を変える。1 周期の刻み数 m を固定すると、結果は ω によらない。","min":0.5,"max":5,"step":0.25,"value":1}
//|   oscillator_cycles: {"type":"range","label":"周期の数 K","description":"誤差を蓄積させる長さ。","min":10,"max":200,"step":10,"value":80}
//|   oscillator_steps_per_cycle: {"type":"range","label":"1 周期の刻みの数 m","description":"無次元の刻み ξ = hω = 2π/m を変える。","min":6,"max":40,"step":1,"value":16}
//| cases:
//|   - {"id":"coarse","label":"m = 8","description":"刻みを粗くすると RK4 のエネルギーは 8 割以上減り、Störmer–Verlet の振動の幅は ξ²/4 に比例して広がる。","inputs":{"oscillator_steps_per_cycle":8}}
//|   - {"id":"fast","label":"ω = 3 rad/s","description":"m を固定すれば、相対エネルギー誤差は ω によらない。","inputs":{"oscillator_frequency":3}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"energy","path":"/rows/0/1","approx":{"value":6.2e-2,"rtol":0.02}}
//|       - {"artifact":"energy","path":"/rows/1/1","range":{"max":1e-12}}
//|       - {"artifact":"energy","path":"/rows/2/1","approx":{"value":0.0386,"rtol":0.01}}
//|   - case: fast
//|     expect:
//|       - {"artifact":"energy","path":"/rows/0/1","approx":{"value":6.2e-2,"rtol":0.02}}
use scioxide_core::{
    Budget, ErrorTolerance, EvaluationRole, ExecutionContext, SciOxideError, NormSelection,
    RealScalar,
};
use scioxide_linalg::Vector;
use scioxide_ode::{
    ClassicalRk4, GaussRk, HamiltonianFn, MechanicalOptions, OdeMethod, OdeOptions,
    OdeOutputSchedule, OdeProblem, OdeState, OdeTrajectory, PhaseSpace, StormerVerlet,
};

let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let omega = oscillator_frequency;
let (cycles, m) = (
    oscillator_cycles as usize,
    oscillator_steps_per_cycle as usize,
);
let period = 2.0 * std::f64::consts::PI / omega;
let (h, steps) = (period / m as f64, cycles * m);
let end = steps as f64 * h;
let xi = h * omega;
let energy = |q: f64, p: f64| 0.5 * p * p + 0.5 * omega * omega * q * q;
let e0 = energy(1.0, 0.0);
// 解析解 q = cos ωt、p = −ω sin ωt との差（p は ω で割って同じ尺度にする）。
let (sin, cos) = RealScalar::sin_cos(omega * end);
let distance = |q: f64, p: f64| RealScalar::hypot(q - cos, (p + omega * sin) / omega);
// 次節の式: RK4 は 1 − |R(iξ)|^{2Km}、Gauss 法は 0、Störmer–Verlet は (ξ²/4)/(1 − ξ²/4)。
let rk4_modulus2 = 1.0 - xi.powi(6) / 72.0 + xi.powi(8) / 576.0;
let theory = [
    1.0 - rk4_modulus2.powf(steps as f64),
    0.0,
    xi * xi / 4.0 / (1.0 - xi * xi / 4.0),
];

let tolerance = ErrorTolerance::scalar(1e-12, 1e-12, NormSelection::RootMeanSquare)
    .map_err(|e| e.to_string())?;
let options = OdeOptions::new()
    .with_error_tolerance(tolerance)
    .with_initial_step(h)
    .with_max_steps(Budget::try_from(steps + 10).map_err(|e| e.to_string())?)
    .with_output_schedule(OdeOutputSchedule::AcceptedSteps);
let system = Oscillator(omega);
let problem = OdeProblem::new(&system, end);
let mut paths = Vec::new();
let mut rows = Vec::new();
for (k, name) in ["古典 RK4", "2 段 Gauss 法"].into_iter().enumerate() {
    let mut path = OdeTrajectory::new();
    let mut state = OdeState::new(0.0, Vector::from_vec(vec![1.0, 0.0]));
    let report = if k == 0 {
        let method = ClassicalRk4::new();
        let mut workspace = method
            .workspace(&problem, &options)
            .map_err(|e| e.to_string())?;
        method.advance(
            &problem,
            &options,
            &mut state,
            &mut path,
            &mut workspace,
            ExecutionContext::sequential(),
        )
    } else {
        let method = GaussRk::new();
        let mut workspace = method
            .workspace(&problem, &options)
            .map_err(|e| e.to_string())?;
        method.advance(
            &problem,
            &options,
            &mut state,
            &mut path,
            &mut workspace,
            ExecutionContext::sequential(),
        )
    }
    .map_err(|e| e.to_string())?;
    let points: Vec<[f64; 3]> = path
        .times()
        .iter()
        .zip(path.states())
        .map(|(&t, y)| [t, y.as_slice()[0], y.as_slice()[1]])
        .collect();
    let y = state.values();
    rows.push((
        name,
        points
            .iter()
            .fold(0.0_f64, |w, s| w.max((energy(s[1], s[2]) - e0).abs() / e0)),
        theory[k],
        distance(y[0], y[1]),
        report.accepted_steps(),
        report.counts().provider(EvaluationRole::RightHandSide),
        report
            .termination()
            .map_or_else(|| "なし".to_string(), |t| t.to_string()),
    ));
    paths.push((name, points));
}

// Störmer–Verlet: ∇T(p) = p、∇V(q) = ω² q。
let hamiltonian = HamiltonianFn::new(
    1,
    |p: &[f64], velocity: &mut [f64]| {
        velocity[0] = p[0];
        Ok::<(), SciOxideError>(())
    },
    |q: &[f64], gradient: &mut [f64]| {
        gradient[0] = omega * omega * q[0];
        Ok::<(), SciOxideError>(())
    },
);
let mut phase = PhaseSpace::new(vec![1.0], vec![0.0]).map_err(|e| e.to_string())?;
let mut workspace = StormerVerlet
    .workspace(&hamiltonian)
    .map_err(|e| e.to_string())?;
let mut verlet = vec![[0.0, 1.0, 0.0]];
let report = StormerVerlet
    .advance(
        &hamiltonian,
        h,
        steps,
        &MechanicalOptions::new(),
        &mut phase,
        &mut |n: usize, q: &[f64], p: &[f64]| {
            verlet.push([n as f64 * h, q[0], p[0]]);
            Ok(())
        },
        &mut workspace,
        ExecutionContext::sequential(),
    )
    .map_err(|e| e.to_string())?;
rows.push((
    "Störmer–Verlet",
    verlet
        .iter()
        .fold(0.0_f64, |w, s| w.max((energy(s[1], s[2]) - e0).abs() / e0)),
    theory[2],
    distance(phase.position()[0], phase.momentum()[0]),
    report.accepted_steps(),
    report.counts().provider(EvaluationRole::Gradient)
        + report.counts().provider(EvaluationRole::RightHandSide),
    report
        .termination()
        .map_or_else(|| "なし".to_string(), |t| format!("{t:?}")),
));
paths.push(("Störmer–Verlet", verlet));

let columns = serde_json::json!([
    { "key": "0", "label": "方式" },
    { "key": "1", "label": "最大の |E − E₀|/E₀ [-]", "type": "number", "format": sci3 },
    { "key": "2", "label": "式による値 [-]", "type": "number", "format": sci3 },
    { "key": "3", "label": "終端の解析解との差 [m]", "type": "number", "format": sci3 },
    { "key": "4", "label": "刻み", "type": "integer" },
    { "key": "5", "label": "評価 [回]", "type": "integer" },
    { "key": "6", "label": "終了状態" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "energy" })
);
// 規格化した相平面は単位円になるので、縦横とも ±1.05 に固定する。
let portrait: Vec<_> = paths
    .iter()
    .map(|(name, points)| {
        let curve: Vec<[f64; 2]> = points.iter().map(|s| [s[1], s[2] / omega]).collect();
        serde_json::json!({ "name": name, "points": curve, "style": { "showSymbol": false } })
    })
    .collect();
emit_line_chart!(
    &portrait,
    options = &serde_json::json!({
        "xLabel": "変位 q [m]",
        "yLabel": "規格化した運動量 p/ω [m]",
        "xMin": -1.05,
        "xMax": 1.05,
        "yMin": -1.05,
        "yMax": 1.05
    })
);
let drift: Vec<_> = paths
    .iter()
    .map(|(name, points)| {
        let curve: Vec<[f64; 2]> = points
            .iter()
            .map(|s| [s[0] / period, (energy(s[1], s[2]) - e0) / e0])
            .collect();
        serde_json::json!({ "name": name, "points": curve, "style": { "showSymbol": false } })
    })
    .collect();
emit_line_chart!(
    &drift,
    options = &serde_json::json!({
        "xLabel": "経過した周期の数 t/P [-]",
        "yLabel": "相対エネルギー誤差 (E − E₀)/E₀ [-]",
        "annotations": [{ "kind": "line", "axis": "y", "value": 0.0 }]
    })
);
```

既定の $m = 16$（$\xi = 0.393$）、$K = 80$ 周期では、RK4 の相対エネルギー誤差は最大 $6.2 \times 10^{-2}$ で、次節の式 $1 - |R(i\xi)|^{2Km}$ と 10 桁以上一致する。
相平面では RK4 の軌道が少しずつ内側へ巻き込む。
2 段 Gauss 法の誤差は $2.7 \times 10^{-15}$ で、丸め誤差の水準である。
Störmer–Verlet 法の誤差は最大 $3.9 \times 10^{-2}$ で、図では 0 と最大の間の振動を全区間でくり返し、増えも減りもしない。
式の値 $4.0 \times 10^{-2}$ は $p = 0$ の瞬間の値で、刻みの点がちょうどその瞬間に乗らないので、測った最大は少し小さい。
終端の解析解との差は RK4 が $0.098$、Gauss 法が $0.016$ で、Störmer–Verlet 法は $1.99$ である。
Störmer–Verlet 法は 2 次なので位相の誤差が大きく、80 周期の後には軌道上でほぼ反対側にいる。
エネルギーを保つことと軌道の位置が正しいことは別である。
$\omega = 3$ rad/s にしても、$m$ が同じなら相対エネルギー誤差は変わらない。

## 1 刻みの写像と位相の誤差

Runge–Kutta 法を $w' = i\omega w$ に使うと、1 刻みは $w_{n+1} = R(i\xi)\,w_n$ で、$R$ は安定関数である。
写像の固有値は $R(\pm i\xi)$ で、その絶対値が振幅の、偏角が位相の 1 刻みの変化を決める。
古典的 RK4 の安定関数は

$$
R_{\mathrm{RK4}}(i\xi) = 1 + i\xi - \frac{\xi^2}{2} - i\frac{\xi^3}{6} + \frac{\xi^4}{24}, \qquad
|R_{\mathrm{RK4}}(i\xi)|^2 = 1 - \frac{\xi^6}{72} + \frac{\xi^8}{576}
$$

で、$0 < \xi < 2\sqrt 2$ では $|R| < 1$ なので、振幅は刻みごとに縮む。
$K$ 周期の後のエネルギーは $|R|^{2Km}$ 倍になる。
偏角は $\arg R_{\mathrm{RK4}}(i\xi) = \xi - \xi^5/120 + O(\xi^7)$ で、1 刻みに $\xi^5/120$ ずつ位相が遅れる。

2 段 Gauss 法の安定関数は指数関数の $[2/2]$ Padé 近似

$$
R_{\mathrm{G}}(i\xi) = \frac{1 + i\xi/2 - \xi^2/12}{1 - i\xi/2 - \xi^2/12}
$$

で、分子と分母が互いに複素共役なので、すべての実数 $\xi$ で $|R_{\mathrm{G}}(i\xi)| = 1$ である。
偏角は $2\arctan\bigl((\xi/2)/(1 - \xi^2/12)\bigr) = \xi - \xi^5/720 + O(\xi^7)$ で、位相の遅れは RK4 の約 1/6 である。

Störmer–Verlet 法の 1 刻みの写像は

$$
\Phi_{\mathrm{SV}} = \begin{pmatrix} 1 - \xi^2/2 & h \\ -\omega\,\xi\,(1 - \xi^2/4) & 1 - \xi^2/2 \end{pmatrix}
$$

で、$\det \Phi_{\mathrm{SV}} = 1$ である。
$\xi < 2$ では固有値は $e^{\pm i\theta}$、$\cos\theta = 1 - \xi^2/2$ で、$\theta = \xi + \xi^3/24 + O(\xi^5)$ なので、位相は 1 刻みに $\xi^3/24$ ずつ進む（2 次の方式）。
写像は回転ではないので $E$ は一定にならないが、2 次形式

$$
\tilde E = \frac{p^2}{2} + \frac{\omega^2 q^2}{2}\Bigl(1 - \frac{\xi^2}{4}\Bigr)
$$

は丸め誤差の範囲で保たれる。
$q = 0$ では $E = \tilde E$、$p = 0$ では $E = \tilde E/(1 - \xi^2/4)$ なので、$E$ は相対的な幅 $(\xi^2/4)/(1 - \xi^2/4)$ で振動し、増え続けることはない。
これが調和振動子の修正 Hamiltonian である。

一般の $2 \times 2$ の写像 $\Phi$ の固有値は、$\det\Phi$ と $\operatorname{tr}\Phi$ から $|\mu| = \sqrt{\det\Phi}$、$\cos\theta = \operatorname{tr}\Phi/(2\sqrt{\det\Phi})$ で求まる。
次のセルは $\omega = 1$ で各方式を $(1, 0)$ と $(0, 1)$ から 1 刻みだけ解いて $\Phi$ の 2 列を測り、固有値の絶対値と偏角 $\theta$ を求める。
`ClassicalRk4` と `GaussRk` は `OdeMethod::solve`、Störmer–Verlet 法は `solve_hamiltonian` で 1 刻み進める。
線形の系なので、$K$ 周期（$Km$ 刻み）の後の位相の誤差は $Km(\xi - \theta)$（正なら遅れ、負なら進み）である。
表は $m = 8, 16, 32, 60$ の値と式による値を並べ、図は $m = 4, \ldots, 60$ の位相の誤差の大きさを両対数で描く。

```rust
//| id: ode-oscillator-phase-analysis
//| ref: ode-oscillator-phase-analysis
//| title: 1 刻みの写像の固有値から振幅と位相の誤差を求める
//| run: reactive
//| uses: [ode-oscillator-model]
//| crates: [scioxide-core, scioxide-linalg, scioxide-ode]
//| inputs:
//|   phase_analysis_cycles: {"type":"range","label":"周期の数 K","description":"1 刻みの写像を何周期分くり返すか。","min":10,"max":1000,"step":10,"value":100}
//| cases:
//|   - {"id":"long","label":"K = 1000","description":"位相の誤差は K に比例して増える。","inputs":{"phase_analysis_cycles":1000}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"step-map","path":"/rows/1/1","approx":{"value":0.999975,"atol":2e-6}}
//|       - {"artifact":"step-map","path":"/rows/1/3","approx":{"value":0.118,"rtol":0.02}}
//|       - {"artifact":"step-map","path":"/rows/1/4","approx":{"value":0.0206,"rtol":0.02}}
//|       - {"artifact":"step-map","path":"/rows/1/5","approx":{"value":-4.109,"rtol":0.01}}
use scioxide_core::{ErrorTolerance, SciOxideError, NormSelection, RealScalar};
use scioxide_linalg::Vector;
use scioxide_ode::{
    ClassicalRk4, GaussRk, OdeMethod, OdeOptions, OdeProblem, OdeState, solve_hamiltonian,
};

/// (1, 0) と (0, 1) から 1 刻み ξ だけ解いた 2 列から、写像の固有値の絶対値と偏角を返す。
fn eigen<F: Fn([f64; 2]) -> Result<[f64; 2], String>>(step: F) -> Result<(f64, f64), String> {
    let (a, b) = (step([1.0, 0.0])?, step([0.0, 1.0])?);
    let det = a[0] * b[1] - b[0] * a[1];
    let half_trace = 0.5 * (a[0] + b[1]);
    let modulus = RealScalar::sqrt(det);
    let imaginary = RealScalar::sqrt((det - half_trace * half_trace).max(0.0));
    Ok((modulus, RealScalar::atan2(imaginary, half_trace)))
}
/// OdeMethod で 1 刻み ξ だけ解く。
fn one_step<M: OdeMethod<f64> + Clone>(
    method: M,
    xi: f64,
    y0: [f64; 2],
) -> Result<[f64; 2], String> {
    // 段の方程式を丸め誤差まで解くため、許容誤差を 1e-14 にする。
    let tolerance = ErrorTolerance::scalar(1e-14, 1e-14, NormSelection::RootMeanSquare)
        .map_err(|e| e.to_string())?;
    let options = OdeOptions::new()
        .with_error_tolerance(tolerance)
        .with_initial_step(xi);
    let system = Oscillator(1.0);
    let initial = OdeState::new(0.0, Vector::from_vec(y0.to_vec()));
    let solution = method
        .solve(&OdeProblem::new(&system, xi), &options, initial)
        .map_err(|e| SciOxideError::from(e).to_string())?;
    let y = solution.state().values();
    Ok([y[0], y[1]])
}
```

測った RK4 の $|\mu|$ は、式 $\sqrt{1 - \xi^6/72 + \xi^8/576}$ と表示した桁（10 桁）まで一致する。
$m = 16$ では $|\mu| = 0.9999750$ で、$K = 80$ 周期の後のエネルギーは $0.9999750^{2 \cdot 1280} = 0.938$ 倍、つまり 6.2% 減ると見積もられ、前のセルで長時間積分して測った値と一致する。
Gauss 法と Störmer–Verlet 法の $|\mu|$ は倍精度で 1 である。
$K = 100$、$m = 16$ の位相の誤差は、RK4 が $0.118$ rad の遅れ、Gauss 法が $0.0206$ rad の遅れで、比はおよそ 6（$\xi^5/120$ と $\xi^5/720$ の比）である。
Störmer–Verlet 法は $-4.11$ rad で、位相が進み、式 $Km(\xi - \arccos(1 - \xi^2/2))$ と一致する。
$m$ を 2 倍にすると、RK4 と Gauss 法の位相の誤差は約 1/16、Störmer–Verlet 法は約 1/4 になり（$m = 16$ から $32$ で RK4 が $0.118$ から $0.0077$、Störmer–Verlet 法が $4.11$ から $1.01$）、両対数の図の傾きは $-4$ と $-2$ である。
前のセルの Gauss 法の終端の誤差 $0.016$（$K = 80$）は、この位相の遅れ $0.0206 \times 0.8$ でほぼ説明できる。

## まとめ

調和振動子では、RK4 の振幅は 1 刻みに $|R(i\xi)| < 1$ 倍ずつ縮み、エネルギーは周期の数に比例して減っていく。
2 段 Gauss 法は $|R(i\xi)| = 1$ なのでエネルギーを丸め誤差の範囲で保ち、Störmer–Verlet 法はエネルギーを幅 $(\xi^2/4)/(1 - \xi^2/4)$ の振動にとどめる。
どの方式でも位相の誤差は周期の数に比例して増え、1 刻みあたり RK4 が $\xi^5/120$ の遅れ、Gauss 法が $\xi^5/720$ の遅れ、Störmer–Verlet 法が $\xi^3/24$ の進みである。
エネルギーが保たれても軌道の位置は正しいとは限らないので、長時間の積分は振幅と位相を分けて確かめる。
非線形の Hamiltonian では Gauss 法でもエネルギーは厳密には一定にならず、有界な振動になる。
