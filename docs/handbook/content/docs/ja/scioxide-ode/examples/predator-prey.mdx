Lotka–Volterra 方程式は、被食者と捕食者の個体数の周期的な増減を表す非線形の常微分方程式である。
この系には真の軌道の上で値が変わらない第一積分がある。
このページでは第一積分のずれを解析解の代わりの誤差の指標にして、`DormandPrince5` の許容誤差とずれの関係を調べる。
最後に、対数変数で正準形に書き直した系を Störmer–Verlet 法で解き、長い時間でのずれの振る舞いを比べる。

## Lotka–Volterra 方程式

被食者の数を $x(t) > 0$、捕食者の数を $y(t) > 0$ [匹]、時間 $t$ の単位を日とする。
環境収容力による制限がない場合、個体数の変化は次の連立方程式で表される。

$$
\frac{dx}{dt} = \alpha x - \beta x y = x(\alpha - \beta y), \qquad
\frac{dy}{dt} = \delta x y - \gamma y = y(\delta x - \gamma)
$$

係数はどれも正で、意味と単位は次のとおりである。

- $\alpha$ [1/日]: 被食者の増殖率
- $\beta$ [(匹·日)⁻¹]: 捕食者との遭遇による被食者の減少率
- $\delta$ [(匹·日)⁻¹]: 捕食による捕食者の増加率
- $\gamma$ [1/日]: 捕食者の死亡率

右辺を同時に 0 にすると、正の平衡点

$$
x^* = \frac{\gamma}{\delta}, \qquad y^* = \frac{\alpha}{\beta}
$$

が得られる。
平衡点での Jacobian 行列の固有値は純虚数 $\lambda = \pm i\sqrt{\alpha\gamma}$ で、平衡点は中心である。
平衡点の近くの小さい振動の周期は $2\pi/\sqrt{\alpha\gamma}$ で、振幅が大きくなると周期は長くなる。
このページでは $\alpha = 1.1$、$\gamma = 0.7$ [1/日] に固定し、小振幅の周期は約 7.16 日である。

## 第一積分

$dx/dt$ と $dy/dt$ の比から時間を消すと、相平面での軌道の方程式

$$
\frac{dy}{dx} = \frac{y(\delta x - \gamma)}{x(\alpha - \beta y)}
$$

が得られる。
変数を分けて

$$
\left( \frac{\alpha}{y} - \beta \right) dy = \left( \delta - \frac{\gamma}{x} \right) dx
$$

を積分すると、第一積分

$$
H(x, y) = \delta x - \gamma \ln x + \beta y - \alpha \ln y
$$

が得られる。
軌道に沿って微分すると

$$
\frac{dH}{dt} = \left( \delta - \frac{\gamma}{x} \right) x(\alpha - \beta y) + \left( \beta - \frac{\alpha}{y} \right) y(\delta x - \gamma) = 0
$$

となり、真の軌道は等高線 $H(x, y) = H(x_0, y_0)$ の閉曲線を回り続ける。
$H$ は平衡点で最小になる凸関数なので、等高線は平衡点を囲む 1 本の閉曲線である。

数値解では、第一積分のずれ $\Delta H(t) = H(x(t), y(t)) - H(x_0, y_0)$ を、解析解を使わない誤差の指標にできる。
ただし $\Delta H = 0$ でも、軌道の上での位置（位相）の誤差は残る。
$\Delta H$ は軌道が隣の等高線へ移る誤差だけを測る。

次のブロックはこのページのセルが共有する定義である。
`LotkaVolterra` が右辺、`invariant` が $H$ に対応する。
`solve_dormand_prince` は、絶対・相対許容誤差 $\varepsilon$、最大刻み 0.4 日の `DormandPrince5` で $[0, T]$ を解く。
$H$ の対数は検算用で、`f64` の標準関数で計算する。

```rust
//| id: ode-predator-prey-model
//| kind: definitions
//| title: Lotka–Volterra 系の右辺と第一積分
//| crates: [scioxide-core, scioxide-linalg, scioxide-ode]
use scioxide_core::{Budget, ErrorTolerance, SciOxideError, NormSelection, SolveContext};
use scioxide_linalg::Vector;
use scioxide_ode::{
    DormandPrince5, OdeMethod, OdeOptions, OdeOutputSchedule, OdeProblem, OdeSolveReport,
    OdeState, OdeSystem, OdeTrajectory,
};

/// x′ = x(α − βy)、y′ = y(δx − γ)。成分の順は (x, y)。
#[derive(Clone, Copy)]
pub(crate) struct LotkaVolterra {
    pub(crate) alpha: f64,
    pub(crate) beta: f64,
    pub(crate) delta: f64,
    pub(crate) gamma: f64,
}

impl LotkaVolterra {
    /// 第一積分 H = δx − γ ln x + βy − α ln y。参照値（f64 の標準関数）。
    pub(crate) fn invariant(&self, y: &[f64]) -> f64 {
        self.delta * y[0] - self.gamma * y[0].ln() + self.beta * y[1] - self.alpha * y[1].ln()
    }
}

impl OdeSystem<f64> for LotkaVolterra {
    fn dimension(&self) -> usize {
        2
    }

    fn rhs(
        &self,
        _: f64,
        y: &[f64],
        out: &mut [f64],
        _: &mut SolveContext<'_, '_>,
    ) -> Result<(), SciOxideError> {
        out[0] = y[0] * (self.alpha - self.beta * y[1]);
        out[1] = y[1] * (self.delta * y[0] - self.gamma);
        Ok(())
    }
}

/// 許容誤差 ε（絶対・相対、RMS ノルム）、最大刻み 0.4 日の DormandPrince5 で [0, T] を解く。
pub(crate) fn solve_dormand_prince(
    system: &LotkaVolterra,
    y0: [f64; 2],
    horizon: f64,
    eps: f64,
    schedule: OdeOutputSchedule<f64>,
) -> Result<(OdeTrajectory<f64>, OdeSolveReport<f64>), SciOxideError> {
    let tolerance = ErrorTolerance::scalar(eps, eps, NormSelection::RootMeanSquare)?;
    let options = OdeOptions::new()
        .with_error_tolerance(tolerance)
        .with_maximum_step(0.4)
        .with_max_steps(Budget::try_from(200_000)?)
        .with_output_schedule(schedule);
    let problem = OdeProblem::new(system, horizon);
    let initial = OdeState::new(0.0, Vector::from_vec(y0.to_vec()));
    let solution = DormandPrince5::new()
        .solve(&problem, &options, initial)
        .map_err(SciOxideError::from)?;
    let (_, report, path) = solution.into_parts();
    Ok((path, report))
}
```

## 軌道と第一積分のずれ

次のセルは、初期個体数 $(x_0, y_0)$、捕食係数 $\beta$、捕食者の増加係数 $\delta$ を選び、30 日の軌道を許容誤差 $\varepsilon = 10^{-7}$ の `DormandPrince5` で解く。
出力は 0.125 日ごとの 241 点で、受理した刻みの間は連続出力で補間した値である。
上の図は個体数の時系列、中の図は $\Delta H(t)$ で、二つの図の時間軸は連動する。
下の図は相平面の軌道で、平衡点を縦線と横線で示す。
表は平衡点、$H(x_0, y_0)$、出力点での最大の $\lvert \Delta H \rvert$、個体数の最小、刻みの数と右辺の評価回数を示す。
このセルの係数と初期値は下の二つのセルにも渡す。

既定値（$x_0 = 30$、$y_0 = 8$、$\beta = 0.08$、$\delta = 0.03$）では平衡点は $(23.33, 13.75)$ で、30 日の軌道は受理した 145 刻み（棄却 6、右辺の評価 908 回）で解けた。
出力点での最大の $\lvert \Delta H \rvert$ は $1.2 \times 10^{-7}$ で、許容誤差 $10^{-7}$ と同じ程度である。
中の図の $\Delta H(t)$ は符号を変えながら $10^{-8}$〜$10^{-7}$ の幅で動き、被食者が急に減る時刻（$t \approx 3$、10.5、18 日の付近）で大きく変わる。
軌道は平衡点の周りを回り、被食者は最小 10.90 匹、捕食者は最小 7.61 匹まで減る。
$x_0 = 55$、$y_0 = 4$ では振幅が大きくなって刻みが 193 に増え、最大の $\lvert \Delta H \rvert$ は $4.5 \times 10^{-7}$ になる。

## 許容誤差とずれ

$\lvert \Delta H \rvert$ は局所誤差が積み重なった大きさなので、許容誤差 $\varepsilon$ を小さくすると減るはずである。
5 次の方式で刻み幅が許容誤差だけで決まる範囲では、局所誤差を $\varepsilon$ に保つ刻みは $\varepsilon^{1/5}$ に比例するので、刻みの数は $\varepsilon^{-1/5}$ に比例して増える。
次のセルは上のセルの係数と初期値を受け取り、$\varepsilon$ を $10^{-3}$ から $10^{-11}$ まで 17 通りに変えて $[0, T]$ を解く。
受理した各刻みでの最大の $\lvert \Delta H \rvert$ と、受理した刻みの数を両対数の図に描く。
二つの図の横軸 $\varepsilon$ は連動する。

```rust
//| id: ode-predator-prey-tolerance
//| ref: ode-predator-prey-tolerance
//| title: 許容誤差に対する第一積分のずれと刻みの数を調べる
//| run: button
//| uses: [ode-predator-prey-model]
//| crates: [scioxide-core, scioxide-linalg, scioxide-ode]
//| dependsOn:
//|   orbit: ode-predator-prey
//| inputs:
//|   invariant_time_horizon: {"type":"range","label":"積分の終端 T [日]","description":"ずれが積み重なる時間を変える。","min":10,"max":80,"step":5,"value":35}
//| cases:
//|   - {"id":"long-horizon","label":"T = 80 日","description":"終端を延ばすと、同じ ε でずれと刻みの数がともに増える。","inputs":{"invariant_time_horizon":80}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"sweep","path":"/rows/16/1","range":{"max":1e-10}}
//|       - {"artifact":"sweep","path":"/rows/0/5","equals":"ReachedEnd"}
//|       - {"path":"/outputs/3/state","equals":"satisfied"}
//|   - case: long-horizon
//|     expect:
//|       - {"artifact":"sweep","path":"/rows/16/1","range":{"max":1e-9}}
use scioxide_core::EvaluationRole;
use scioxide_ode::OdeOutputSchedule;

let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let beta = orbit["beta"].as_f64().ok_or("β がない")?;
let delta = orbit["delta"].as_f64().ok_or("δ がない")?;
let y0: [f64; 2] =
    serde_json::from_value(orbit["initial_state"].clone()).map_err(|e| e.to_string())?;
let system = LotkaVolterra {
    alpha: 1.1,
    beta,
    delta,
    gamma: 0.7,
};
let h0 = system.invariant(&y0);
let (mut drift_curve, mut step_curve, mut rows) = (Vec::new(), Vec::new(), Vec::new());
for k in 0..=16 {
    let eps = 10.0_f64.powf(-3.0 - 0.5 * f64::from(k));
    let (path, report) = solve_dormand_prince(
        &system,
        y0,
        invariant_time_horizon,
        eps,
        OdeOutputSchedule::AcceptedSteps,
    )
    .map_err(|e| e.to_string())?;
    // 独立な検算: 受理した各刻みの終点での第一積分のずれの最大。
    let drift = path
        .states()
        .iter()
        .map(|y| (system.invariant(y.as_slice()) - h0).abs())
        .fold(0.0_f64, f64::max);
    // ずれがちょうど 0 の点は対数軸に描けないので図から除く（表には残る）。
    if drift > 0.0 {
        drift_curve.push([eps, drift]);
    }
    step_curve.push([eps, report.accepted_steps() as f64]);
    let termination = report.termination().ok_or("終了状態がない")?;
    rows.push((
        eps,
        drift,
        report.accepted_steps(),
        report.rejected_steps(),
        report.counts().provider(EvaluationRole::RightHandSide),
        termination.to_string(),
    ));
}
emit_line_chart!(
    &vec![serde_json::json!({ "name": "最大の |ΔH|", "points": drift_curve })],
    options = &serde_json::json!({
        "link": { "group": "lv-tolerance" },
        "xLabel": "許容誤差 ε [-]",
        "yLabel": "最大の |ΔH| [-]",
        "xType": "log",
        "yType": "log"
    })
);
emit_line_chart!(
    &vec![serde_json::json!({ "name": "受理した刻み", "points": step_curve })],
    options = &serde_json::json!({
        "link": { "group": "lv-tolerance" },
        "xLabel": "許容誤差 ε [-]",
        "yLabel": "受理した刻み [回]",
        "xType": "log",
        "yType": "log"
    })
);
let columns = serde_json::json!([
    { "key": "0", "label": "許容誤差 ε [-]", "type": "number", "format": sci2 },
    { "key": "1", "label": "最大の |ΔH| [-]", "type": "number", "format": sci2 },
    { "key": "2", "label": "受理した刻み", "type": "integer" },
    { "key": "3", "label": "棄却した刻み", "type": "integer" },
    { "key": "4", "label": "右辺の評価回数", "type": "integer" },
    { "key": "5", "label": "終了状態" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "sweep" })
);

let stopped = rows.iter().filter(|row| row.5 != "ReachedEnd").count();
let status = rows
    .iter()
    .map(|row| row.5.clone())
    .find(|name| name != "ReachedEnd")
    .unwrap_or_else(|| "ReachedEnd".to_string());
let outcome = if stopped == 0 {
    Outcome::satisfied("17 通りの許容誤差のすべてで終端に達した")
} else {
    Outcome::partial(format!("17 通りのうち {stopped} 通りが終端の前に止まった"))
        .explanation("止まった行の値は最後に受理した状態までの推定値として扱う。")
};
emit_outcome!(
    outcome
        .status(status)
        .diagnostic("ε = 10⁻¹¹ の最大の |ΔH|", rows[16].1, None)
);
```

既定値（$T = 35$ 日）では、$\varepsilon \ge 10^{-5}$ の 5 通りで受理した刻みは 89 のまま変わらず、$\lvert \Delta H \rvert$ も $3.3 \times 10^{-6}$〜$3.4 \times 10^{-6}$ にとどまる。
この範囲では最大刻み 0.4 日の制限が刻みを決めていて（$35/0.4 = 87.5$）、許容誤差は効いていない。
$\varepsilon \le 10^{-5.5}$ では $\lvert \Delta H \rvert$ が $\varepsilon$ にほぼ比例して減り、$\varepsilon = 10^{-6}$ で $8.4 \times 10^{-7}$、$10^{-11}$ で $1.3 \times 10^{-11}$ になる。
受理した刻みは 96 から 1071 に増え、$\varepsilon = 10^{-7}$ から $10^{-11}$ までの 4 桁で 171 から 1071 へ約 6.3 倍になる。
これは $10^{4/5} \approx 6.3$ で、刻みの数が $\varepsilon^{-1/5}$ に比例するという見積もりと合う。
$T = 80$ 日に延ばすと、$\varepsilon \ge 10^{-5}$ の $\lvert \Delta H \rvert$ は $6.9 \times 10^{-6}$〜$7.1 \times 10^{-6}$ に増え、ずれが時間とともに積み重なることが分かる。

## 対数変数の正準形と Störmer–Verlet 法

`DormandPrince5` のような一般の Runge–Kutta 法は第一積分を保たないので、許容誤差を固定して積分の時間を延ばすと $\lvert \Delta H \rvert$ はおおむね時間に比例して増える。
Lotka–Volterra 系は、対数変数 $p = \ln x$、$q = \ln y$ に移すと正準な Hamilton 系になる。
$H$ を $p$ と $q$ で書くと

$$
H(q, p) = T(p) + V(q), \qquad T(p) = \delta e^{p} - \gamma p, \qquad V(q) = \beta e^{q} - \alpha q
$$

で、運動方程式は

$$
\frac{dq}{dt} = \frac{\partial H}{\partial p} = \delta e^{p} - \gamma = \frac{1}{y}\frac{dy}{dt}, \qquad
\frac{dp}{dt} = -\frac{\partial H}{\partial q} = \alpha - \beta e^{q} = \frac{1}{x}\frac{dx}{dt}
$$

となって、元の方程式と一致する。
$H$ が $T(p) + V(q)$ の形に分かれるので、陽的な Störmer–Verlet 法を使える。
Störmer–Verlet 法はシンプレクティックな 2 次の方式で、刻み $h$ を固定すると $\lvert \Delta H \rvert$ は $O(h^2)$ の幅で振動し、長い時間でも増え続けない（[力学系の幾何積分](../../algorithms/geometric-integrators/)）。

次のセルは上のセルの係数と初期値を受け取り、終端 $T$ までを二つの方法で解く。
`DormandPrince5` は許容誤差 $\varepsilon$ で解き、受理した刻みごとの状態を出力する。
`solve_hamiltonian` は $\nabla T(p) = \delta e^{p} - \gamma$ と $\nabla V(q) = \beta e^{q} - \alpha$ を受け取り、刻み $h$ の Störmer–Verlet 法で 1 日ずつ進める。
図は時刻 $t$ までの最大の $\lvert \Delta H \rvert$ を対数軸で示し、表は刻みの数、評価回数、終端での $\lvert \Delta H \rvert$ を比べる。

```rust
//| id: ode-predator-prey-symplectic
//| ref: ode-predator-prey-symplectic
//| title: 対数変数の Störmer–Verlet 法と DormandPrince5 の長時間のずれを比べる
//| run: button
//| uses: [ode-predator-prey-model]
//| crates: [scioxide-core, scioxide-linalg, scioxide-ode]
//| dependsOn:
//|   orbit: ode-predator-prey
//| inputs:
//|   long_horizon: {"type":"range","label":"積分の終端 T [日]","description":"ずれが積み重なる時間を変える。","min":100,"max":2000,"step":100,"value":1000}
//|   long_tolerance_exponent: {"type":"range","label":"DormandPrince5 の許容誤差の指数 p（ε = 10^p）","description":"絶対・相対許容誤差をそろえて変える。","min":-10,"max":-4,"step":1,"value":-6}
//|   verlet_step: {"type":"range","label":"Störmer–Verlet 法の刻み h [日]","description":"ずれの振幅は h² に比例する。","min":0.01,"max":0.2,"step":0.01,"value":0.02}
//| cases:
//|   - {"id":"fine-verlet","label":"h = 0.01 日","description":"刻みを半分にすると、Störmer–Verlet 法のずれはおよそ 1/4 になる。","inputs":{"verlet_step":0.01}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"long-time","path":"/rows/1/0","equals":"Störmer–Verlet"}
//|       - {"artifact":"long-time","path":"/rows/1/4","range":{"max":1e-3}}
//|   - case: fine-verlet
//|     expect:
//|       - {"artifact":"long-time","path":"/rows/1/4","range":{"max":5e-5}}
use scioxide_core::{EvaluationRole, SciOxideError, RealScalar};
use scioxide_ode::{OdeOutputSchedule, solve_hamiltonian};

let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let beta = orbit["beta"].as_f64().ok_or("β がない")?;
let delta = orbit["delta"].as_f64().ok_or("δ がない")?;
let y0: [f64; 2] =
    serde_json::from_value(orbit["initial_state"].clone()).map_err(|e| e.to_string())?;
let system = LotkaVolterra {
    alpha: 1.1,
    beta,
    delta,
    gamma: 0.7,
};
let h0 = system.invariant(&y0);
let days = long_horizon as usize;

// DormandPrince5: 受理した刻みの終点での |ΔH| の累積最大。
let eps = 10.0_f64.powf(long_tolerance_exponent);
let (path, report) = solve_dormand_prince(
    &system,
    y0,
    long_horizon,
    eps,
    OdeOutputSchedule::AcceptedSteps,
)
.map_err(|e| e.to_string())?;
// 図は約 400 点に間引く（最大値は全刻みで取る）。
let spacing = long_horizon / 400.0;
let (mut running, mut next, mut dp_curve) = (0.0_f64, 0.0, Vec::new());
for (&t, y) in path.times().iter().zip(path.states()) {
    running = running.max((system.invariant(y.as_slice()) - h0).abs());
    if t >= next && running > 0.0 {
        dp_curve.push([t, running]);
        next = t + spacing;
    }
}
let dp_final =
    (system.invariant(path.states().last().ok_or("出力がない")?.as_slice()) - h0).abs();

// Störmer–Verlet: q = ln y、p = ln x。1 日ごとに solve_hamiltonian を続けて呼ぶ。
let per_day = (1.0 / verlet_step).round() as usize;
let step = 1.0 / per_day as f64;
let velocity = |p: &[f64], v: &mut [f64]| {
    v[0] = delta * RealScalar::exp(p[0]) - 0.7;
    Ok(())
};
let gradient = |q: &[f64], g: &mut [f64]| {
    g[0] = beta * RealScalar::exp(q[0]) - 1.1;
    Ok(())
};
let (mut q, mut p) = (RealScalar::ln(y0[1]), RealScalar::ln(y0[0]));
let (mut sv_running, mut sv_curve, mut sv_final) = (0.0_f64, Vec::new(), 0.0_f64);
for day in 1..=days {
    let state = solve_hamiltonian(velocity, gradient, &[q], &[p], step, per_day)
        .map_err(|e| SciOxideError::from(e).to_string())?;
    (q, p) = (state.position()[0], state.momentum()[0]);
    // 検算: (x, y) = (e^p, e^q) に戻して H のずれを測る（f64 の標準関数）。
    sv_final = (system.invariant(&[p.exp(), q.exp()]) - h0).abs();
    sv_running = sv_running.max(sv_final);
    if day % (days / 400).max(1) == 0 && sv_running > 0.0 {
        sv_curve.push([day as f64, sv_running]);
    }
}
emit_line_chart!(
    &vec![
        serde_json::json!({ "name": "DormandPrince5", "points": dp_curve }),
        serde_json::json!({ "name": "Störmer–Verlet", "points": sv_curve })
    ],
    options = &serde_json::json!({
        "xLabel": "時間 t [日]",
        "yLabel": "t までの最大の |ΔH| [-]",
        "yType": "log"
    })
);
let columns = serde_json::json!([
    { "key": "0", "label": "方法" },
    { "key": "1", "label": "受理した刻み", "type": "integer" },
    { "key": "2", "label": "評価回数", "type": "integer" },
    { "key": "3", "label": "最大の |ΔH| [-]", "type": "number", "format": sci2 },
    { "key": "4", "label": "終端の |ΔH| [-]", "type": "number", "format": sci2 }
]);
// Störmer–Verlet の評価回数は 1 刻みに ∇T と ∇V を 1 回ずつ、各呼び出しの最初に ∇V(q₀) を 1 回。
let rows = vec![
    (
        "DormandPrince5".to_string(),
        report.accepted_steps(),
        report.counts().provider(EvaluationRole::RightHandSide),
        running,
        dp_final,
    ),
    (
        "Störmer–Verlet".to_string(),
        days * per_day,
        days * (2 * per_day + 1),
        sv_running,
        sv_final,
    ),
];
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "long-time" })
);
```

既定値（$T = 1000$ 日、$\varepsilon = 10^{-6}$、$h = 0.02$ 日）では、`DormandPrince5` の最大の $\lvert \Delta H \rvert$ は $2.0 \times 10^{-5}$ で、図では時間にほぼ比例して増える。
Störmer–Verlet 法の最大の $\lvert \Delta H \rvert$ は $1.5 \times 10^{-5}$ で、図では 100 日までに達した値から増えない。
$T = 100$ 日では `DormandPrince5` が $2.1 \times 10^{-6}$、Störmer–Verlet 法が $1.5 \times 10^{-5}$ で、短い時間なら `DormandPrince5` のほうがずれは小さい。
$T = 2000$ 日では `DormandPrince5` が $3.9 \times 10^{-5}$ に増え、Störmer–Verlet 法は $1.5 \times 10^{-5}$ のままである。
$h = 0.01$ 日にすると Störmer–Verlet 法のずれは $3.8 \times 10^{-6}$ になり、刻みを半分にするとずれがおよそ 1/4 になる $O(h^2)$ の振る舞いと合う。
既定値での評価回数は `DormandPrince5` の 21968 回に対して Störmer–Verlet 法は 101000 回で、同じ程度のずれを得るための評価回数はこの時間では `DormandPrince5` のほうが少ない。
Störmer–Verlet 法の利点は、ずれが積分の時間に依らないことにある。

## まとめ

Lotka–Volterra 系の第一積分 $H$ は、解析解がなくても数値解の誤差の一部を測る指標になる。
`DormandPrince5` では $\lvert \Delta H \rvert$ が許容誤差にほぼ比例して減るが、最大刻みのような別の制約が刻みを決める範囲では、許容誤差を緩めても変わらない。
許容誤差を固定して積分の時間を延ばすと、`DormandPrince5` のずれは時間とともに増える。
対数変数で正準形に直した系を Störmer–Verlet 法で解くと、ずれは $h^2$ に比例する幅にとどまり、長い時間でも増え続けない。
長い周期軌道で不変量を保ちたいときは、系を分離可能な Hamilton 系に書き直せるかを確かめる（[方式の選び方](../../choosing/)）。
