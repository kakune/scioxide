Robertson の反応系は、三つの化学種の濃度が 10⁻⁵ s から 10¹⁰ s を超える時間にわたって変わる、剛性の強い常微分方程式の標準的な試験問題である。
中間体の濃度は最大でも 10⁻⁵ 程度にとどまるので、他の成分と同じ絶対許容誤差では中間体の誤差を制御できない。
このページでは `RosenbrockW`、`Bdf`、`RadauIia` で同じ系を解き、成分ごとの絶対許容誤差を与えたときと与えないときの差を見る。
解の正しさは、中間体の準定常近似、t = 40 s での参照値、許容誤差を厳しくしたときの収束で確かめる。

## Robertson 反応系

化学種 A、B、C の濃度を $y_1$、$y_2$、$y_3$ とし、次の三つの反応を考える。

$$
\mathrm{A} \xrightarrow{k_1} \mathrm{B}, \qquad
\mathrm{B} + \mathrm{B} \xrightarrow{k_2} \mathrm{C} + \mathrm{B}, \qquad
\mathrm{B} + \mathrm{C} \xrightarrow{k_3} \mathrm{A} + \mathrm{C}
$$

速度定数は $k_1 = 0.04$ s⁻¹、$k_2 = 3 \times 10^7$、$k_3 = 10^4$ [濃度⁻¹ s⁻¹] である。
質量作用の法則から、濃度の変化は

$$
\begin{aligned}
y_1' &= -k_1 y_1 + k_3 y_2 y_3, \\
y_2' &= k_1 y_1 - k_3 y_2 y_3 - k_2 y_2^2, \\
y_3' &= k_2 y_2^2
\end{aligned}
$$

となる。
初期値は $(y_1, y_2, y_3) = (1, 0, 0)$ で、濃度は初期の A の濃度を単位にした無次元の量である。
三つの式を足すと $(y_1 + y_2 + y_3)' = 0$ なので、総和は 1 に保たれる。

Jacobian 行列

$$
J = \begin{pmatrix}
-k_1 & k_3 y_3 & k_3 y_2 \\
k_1 & -k_3 y_3 - 2 k_2 y_2 & -k_3 y_2 \\
0 & 2 k_2 y_2 & 0
\end{pmatrix}
$$

の固有値の一つは保存則に対応する 0 で、残りの二つは負である。
大きさの大きい方は $k_3 y_3 + 2 k_2 y_2$ 程度で、$y_3$ が 1 に近づく後半では約 $-10^4$ s⁻¹ になる。
解は 10¹⁰ s の尺度で動くので、時間の尺度の比は 10¹⁴ に達する。
陽解法の刻みは $10^{-4}$ s 程度に制限されるので、この区間を陽解法で解くのは現実的でない。

## 準定常近似

$y_2$ は生成と消費が速く、生成と消費がほぼつり合った値に追従する。
$y_2' \approx 0$ とおくと、$y_2$ の 2 次方程式

$$
k_2 y_2^2 + k_3 y_3 y_2 - k_1 y_1 = 0
$$

から、正の根

$$
y_2^{\mathrm{qss}} = \frac{-k_3 y_3 + \sqrt{k_3^2 y_3^2 + 4 k_1 k_2 y_1}}{2 k_2}
$$

が得られる（準定常近似）。
数値解の $y_1$、$y_3$ をこの式に入れた値は、初期の過渡（およそ $t < 10^{-2}$ s）を過ぎた $y_2$ とよく一致するはずである。
$y_2$ だけを独立に確かめる手段になる。

## 成分ごとの絶対許容誤差

適応刻みの方式は各成分の局所誤差の推定 $e_i$ を

$$
r = \left\lVert \frac{e_i}{\mathrm{atol}_i + \mathrm{rtol} \cdot \max(\lvert y_i \rvert, \lvert \hat y_i \rvert)} \right\rVert \le 1
$$

で受理する（[誤差・次数・安定性](../../algorithms/error-order-and-stability/)）。
$y_2$ は最大でも約 $3.65 \times 10^{-5}$、t = 40 s では約 $9.2 \times 10^{-6}$ で、後半は $10^{-11}$ から $10^{-13}$ まで下がる。
$\mathrm{rtol} = 10^{-4}$ では $\mathrm{rtol} \cdot \lvert y_2 \rvert$ は $10^{-9}$ 以下なので、$\mathrm{atol}_2 = 10^{-6}$ にすると分母はほとんど $\mathrm{atol}_2$ で決まる。
そのため、$y_2(40)$ の 1 割にあたる $10^{-6}$ 程度の誤差も 1 刻みで受理される。
成分の大きさに合わせて $\mathrm{atol}_2$ だけを小さくするには、`ErrorTolerance::try_vector` に成分ごとの絶対許容誤差を渡す。
長さが成分の数と違うと、積分を始める前の検証で `InvalidInput` になる。

総和 $y_1 + y_2 + y_3 = 1$ は線形の保存量なので、Runge–Kutta 法、Rosenbrock 法、BDF は、段の方程式が解けている限り丸め誤差の範囲で保つ。
$y_2$ が 30 % ずれていても総和は保たれるので（下のセルの $\mathrm{atol}_2 = 10^{-6}$ の例）、総和の保存は精度の証拠にならない。

次のブロックはこのページのセルが共有する定義である。
`Robertson` は右辺と解析的な Jacobian を与え、自励系なので時間微分に 0 を返す。
`quasi_steady` は $y_2^{\mathrm{qss}}$、`integrate` は与えた方式、許容誤差、出力時刻で $[0, t_{\mathrm{end}}]$ を解く。

```rust
//| id: ode-robertson-model
//| kind: definitions
//| title: Robertson 反応系の右辺・Jacobian・準定常近似
//| crates: [scioxide-core, scioxide-linalg, scioxide-ode]
use scioxide_core::{Budget, ErrorTolerance, SciOxideError, RealScalar, SolveContext};
use scioxide_linalg::{MatrixViewMut, Vector};
use scioxide_ode::{
    OdeMethod, OdeOptions, OdeOutputSchedule, OdeProblem, OdeSolveReport, OdeState, OdeSystem,
    OdeTrajectory,
};

pub(crate) const K1: f64 = 0.04;
pub(crate) const K2: f64 = 3.0e7;
pub(crate) const K3: f64 = 1.0e4;

/// y₁′ = −k₁y₁ + k₃y₂y₃、y₂′ = k₁y₁ − k₃y₂y₃ − k₂y₂²、y₃′ = k₂y₂²。
pub(crate) struct Robertson;

impl OdeSystem<f64> for Robertson {
    fn dimension(&self) -> usize {
        3
    }

    fn rhs(
        &self,
        _: f64,
        y: &[f64],
        out: &mut [f64],
        _: &mut SolveContext<'_, '_>,
    ) -> Result<(), SciOxideError> {
        let (r1, r2, r3) = (K1 * y[0], K2 * y[1] * y[1], K3 * y[1] * y[2]);
        out[0] = -r1 + r3;
        out[1] = r1 - r3 - r2;
        out[2] = r2;
        Ok(())
    }

    fn jacobian(
        &self,
        _: f64,
        y: &[f64],
        j: &mut MatrixViewMut<'_, f64>,
        _: &mut SolveContext<'_, '_>,
    ) -> Result<Option<()>, SciOxideError> {
        let rows = [
            [-K1, K3 * y[2], K3 * y[1]],
            [K1, -K3 * y[2] - 2.0 * K2 * y[1], -K3 * y[1]],
            [0.0, 2.0 * K2 * y[1], 0.0],
        ];
        for (r, row) in rows.iter().enumerate() {
            for (c, &value) in row.iter().enumerate() {
                j.set(r, c, value)?;
            }
        }
        Ok(Some(()))
    }

    fn time_derivative(
        &self,
        _: f64,
        _: &[f64],
        out: &mut [f64],
        _: &mut SolveContext<'_, '_>,
    ) -> Result<Option<()>, SciOxideError> {
        out.fill(0.0);
        Ok(Some(()))
    }
}

/// 準定常近似 y₂ = (−k₃y₃ + √(k₃²y₃² + 4k₁k₂y₁)) / (2k₂)。
pub(crate) fn quasi_steady(y1: f64, y3: f64) -> f64 {
    let b = K3 * y3;
    (-b + RealScalar::sqrt(b * b + 4.0 * K1 * K2 * y1)) / (2.0 * K2)
}

/// (1, 0, 0) から end まで、試みた刻み 50000 回までで解く。
pub(crate) fn integrate<M: OdeMethod<f64> + Clone>(
    method: &M,
    tolerance: ErrorTolerance<f64>,
    end: f64,
    schedule: OdeOutputSchedule<f64>,
) -> Result<(OdeTrajectory<f64>, OdeSolveReport<f64>), SciOxideError> {
    let options = OdeOptions::new()
        .with_error_tolerance(tolerance)
        .with_max_steps(Budget::try_from(50_000)?)
        .with_output_schedule(schedule);
    let initial = OdeState::new(0.0, Vector::from_vec(vec![1.0, 0.0, 0.0]));
    let solution = method
        .solve(&OdeProblem::new(&Robertson, end), &options, initial)
        .map_err(SciOxideError::from)?;
    let (_, report, path) = solution.into_parts();
    Ok((path, report))
}
```

## 15 桁にわたる時間区間の積分

次のセルは、相対許容誤差 $\mathrm{rtol}$ と $y_2$ の絶対許容誤差 $\mathrm{atol}_2$ を選び、三つの方式で $[0, 4 \times 10^{10}]$ s を解く。
$y_1$ と $y_3$ の絶対許容誤差は $10^{-8}$ に固定する。
$\mathrm{atol}_2 = 10^{-8}$ にすると、三成分に同じ絶対許容誤差を与えたことになる。

- `RosenbrockW`（`RosenbrockMethod::Ros34Pw2`）: 3 次の線形陰的な方式。
- `Bdf`（`MultistepOrder::Automatic(5)`）: 次数 1〜5 の後退差分公式。
- `RadauIia`: 5 次の L 安定な陰的 Runge–Kutta 法。

出力は $10^{-5}$ s から $4 \times 10^{10}$ s までの対数に等間隔な 61 点と t = 40 s で、受理した刻みの間は連続出力で補間する。
表は方式ごとの終了状態、刻みの数、評価回数、t = 40 s の値、$y_2 \le 0$ になった出力点の数、出力点での総和の誤差の最大を示す。
このセルは濃度の時系列を次のセルに渡す。

```rust

//|   relative_exponent: {"type":"range","label":"相対許容誤差の指数 p（rtol = 10^p）","description":"三成分に共通の相対許容誤差。","min":-8,"max":-3,"step":1,"value":-4}
//| cases:
//|   - {"id":"uniform-atol","label":"atol₂ = 10⁻⁶","description":"y₂ の誤差が絶対許容誤差に隠れ、RosenbrockW の t = 40 s の y₂ が参照値より約 30 % 小さくなる。","inputs":{"intermediate_atol_exponent":-6}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"methods","path":"/rows/2/1","equals":"ReachedEnd"}
//|       - {"artifact":"methods","path":"/rows/2/7","approx":{"value":0.715827,"rtol":1e-4}}
//|       - {"artifact":"methods","path":"/rows/2/8","approx":{"value":9.1855e-6,"rtol":1e-3}}
//|       - {"artifact":"methods","path":"/rows/2/11","range":{"max":1e-12}}
//|       - {"path":"/outputs/1/state","equals":"satisfied"}

use scioxide_ode::{
    Bdf, MultistepOrder, OdeOutputSchedule, OdeTrajectory, RadauIia, RosenbrockMethod,
    RosenbrockW,
};

let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let digits6 = serde_json::json!({ "significantDigits": 6 });
let atol = [1e-8, 10.0_f64.powf(intermediate_atol_exponent), 1e-8];
let rtol = 10.0_f64.powf(relative_exponent);
let tolerance = ErrorTolerance::try_vector(&atol, rtol, NormSelection::RootMeanSquare)
    .map_err(|e| e.to_string())?;
// 出力時刻: 10⁻⁵ s から 4×10¹⁰ s まで対数に等間隔な 61 点と、参照値を比べる t = 40 s。
let (first, last) = (1e-5_f64, 4e10_f64);
let mut times: Vec<f64> = (0..60)
    .map(|k| first * (last / first).powf(f64::from(k) / 60.0))
    .collect();
times.push(last);
times.push(40.0);
times.sort_by(f64::total_cmp);
let schedule = OdeOutputSchedule::times(times);
let rosenbrock = RosenbrockW::new(RosenbrockMethod::Ros34Pw2).map_err(|e| e.to_string())?;
let bdf = Bdf::with_order_policy(MultistepOrder::Automatic(5)).map_err(|e| e.to_string())?;
let runs = vec![
    (
        "RosenbrockW",
        integrate(&rosenbrock, tolerance.clone(), last, schedule.clone()),
    ),
    (

        "RadauIia",
        integrate(&RadauIia::new(), tolerance, last, schedule),
    ),
];
let positive = |path: &OdeTrajectory<f64>, k: usize| -> Vec<[f64; 2]> {

        .iter()
        .zip(path.states())
        .map(|(&t, y)| [t, y.as_slice()[k]])
        .filter(|p| p[1] > 0.0)
        .collect()
};

    }
    let at40 = path
        .times()
        .iter()
        .position(|&t| t == 40.0)
        .map(|i| path.states()[i].as_slice().to_vec());
    let nonpositive = path
        .states()
        .iter()
        .filter(|y| y.as_slice()[1] <= 0.0)
        .count();

        .states()
        .iter()

        .fold(0.0_f64, f64::max);
    let counts = report.counts();
    rows.push((
        name.to_string(),
        termination.to_string(),
        report.accepted_steps(),
        report.rejected_steps(),

        counts.provider(EvaluationRole::Jacobian),
        counts.provider(EvaluationRole::Factorization),
        at40.as_ref().map(|y| y[0]),
        at40.as_ref().map(|y| y[1]),
        at40.as_ref().map(|y| y[2]),
        nonpositive,
        sum_error,
    ));

        serde_json::json!({ "name": format!("y₂（{name}）"), "points": positive(path, 1) }),
    );
}

    { "key": "6", "label": "LU 分解", "type": "integer" },

既定値（$\mathrm{atol}_2 = 10^{-14}$、$\mathrm{rtol} = 10^{-4}$）では、三つの方式とも 450 刻み以下で $4 \times 10^{10}$ s まで進んだ。
`RadauIia` は 154 刻み（右辺の評価 1250 回、LU 分解 244 回）、`Bdf` は 421 刻み、`RosenbrockW` は 434 刻みである。
15 桁の時間を数百刻みで進めるのは、刻み幅が解の変化に合わせて変わるからで、`RadauIia` の受理した刻みは $2.5 \times 10^{-9}$ s から $1.1 \times 10^{10}$ s までの 19 桁にわたる。
t = 40 s の $y_2$ は `RadauIia` が $9.1856 \times 10^{-6}$、`Bdf` が $9.1852 \times 10^{-6}$ で参照値と 4 桁以上一致し、`RosenbrockW` は $8.95 \times 10^{-6}$ で 2.6 % 小さい。

`RosenbrockW` の $y_2$ は出力点 62 点のうち 11 点で 0 以下になる。
受理した刻みの終点で出力すると `RosenbrockW` の $y_2$ は負にならないので、負の値は刻みの間の連続出力から来る。
`RosenbrockW` の連続出力は 3 次の Hermite 補間で、$10^{9}$ s 程度の大きい刻みの間で値が何桁も変わる $y_2$ を補間すると、0 の下に行き過ぎる。
`Bdf` と `RadauIia` は刻みの履歴や選点の多項式で補間し、この例では負の値を出さない。

$\mathrm{atol}_2 = 10^{-6}$ にすると、`RosenbrockW` の $y_2(40)$ は $6.39 \times 10^{-6}$ と参照値より約 30 % 小さくなり、0 以下の点は 14 点に増える。
`Bdf` の $y_2(40)$ は $9.187 \times 10^{-6}$ で、相対差は $2 \times 10^{-4}$ にとどまる。
どの計算でも総和の誤差の最大は $4 \times 10^{-14}$ 以下で、30 % ずれた $y_2$ も総和の上では見えない。
$\mathrm{rtol} = 10^{-8}$ にすると、三つの方式の $y_2(40)$ は $9.18553 \times 10^{-6}$ で 6 桁一致するが、`RosenbrockW` は 3878 刻みと `RadauIia` の 683 刻みの約 6 倍を要する。

## 濃度の時間変化

次のセルは上のセルの結果を受け取って描く。
上の図は `RadauIia` の $y_1$ と $y_3$、下の図は三つの方式の $y_2$ と、`RadauIia` の $y_1$、$y_3$ から求めた準定常近似（破線）である。
どちらも両対数で描き、横軸は連動する。
対数軸に描けない $y_2 \le 0$ の点は、上のセルで図から除いてある。

    })
);
emit_line_chart!(
    &intermediate,
    options = &serde_json::json!({
        "link": { "group": "robertson-time" },
        "xLabel": "時間 t [s]",
        "yLabel": "中間体の濃度 y₂ [-]",
        "xType": "log",
        "yType": "log"
    })

```

上の図では、$y_1$ は 1 s あたりから目に見えて減り（t = 10 s で約 0.85）、$y_3$ は 1 に近づく。
下の図の $y_2$ は $4 \times 10^{-3}$ s 付近で最大の約 $3.6 \times 10^{-5}$ に達し、その後は準定常近似の破線に重なって $10^{-13}$ 程度まで減る。
`RosenbrockW` の系列は $10^{5}$ s より後で途切れ途切れになり、0 以下になった出力点が抜けている。

## t = 40 s での収束

参照値としてよく引かれる t = 40 s の値は $y_1 \approx 0.715827$、$y_2 \approx 9.1855 \times 10^{-6}$、$y_3 \approx 0.284164$ である。
引用した値を信じる代わりに、許容誤差を厳しくしていったときに数値解が一つの値に収束することを確かめる。
次のセルは $\mathrm{rtol}$ を $10^{-4}$ から $10^{-11}$ まで 8 通りに変え、絶対許容誤差を $(\mathrm{atol}_1, \mathrm{atol}_2, \mathrm{atol}_3) = \mathrm{rtol} \cdot (10^{-4}, 10^{-9}, 10^{-4})$ として、`RadauIia` と `Bdf` で $[0, 40]$ s を解く。
最も厳しい $\mathrm{rtol} = 10^{-11}$ の `RadauIia` の値を基準にして、各計算の $y_2(40)$ の相対差を両対数の図に描く。
表は各計算の $y_1(40)$、$y_2(40)$ と、基準との相対差、受理した刻みの数を示す。

```rust
//| id: ode-robertson-convergence
//| ref: ode-robertson-convergence
//| title: 許容誤差を厳しくして t = 40 s の値の収束を確かめる
//| run: button
//| uses: [ode-robertson-model]
//| crates: [scioxide-core, scioxide-linalg, scioxide-ode]
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"convergence","path":"/rows/14/2","approx":{"value":0.7158270687,"rtol":1e-9}}
//|       - {"artifact":"convergence","path":"/rows/14/3","approx":{"value":9.185534765e-6,"rtol":1e-8}}
//|       - {"artifact":"convergence","path":"/rows/12/4","range":{"max":1e-12}}
//|       - {"artifact":"convergence","path":"/rows/15/4","range":{"max":1e-9}}
use scioxide_core::{ErrorTolerance, NormSelection};
use scioxide_ode::{Bdf, MultistepOrder, OdeOutputSchedule, RadauIia};

let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let digits10 = serde_json::json!({ "significantDigits": 10 });
let bdf = Bdf::with_order_policy(MultistepOrder::Automatic(5)).map_err(|e| e.to_string())?;
let radau = RadauIia::new();
let mut runs = Vec::new();
for k in 4..=11 {
    let rtol = 10.0_f64.powi(-k);
    let atol = [rtol * 1e-4, rtol * 1e-9, rtol * 1e-4];
    let tolerance = ErrorTolerance::try_vector(&atol, rtol, NormSelection::RootMeanSquare)
        .map_err(|e| e.to_string())?;
    for (name, run) in [
        (
            "RadauIia",
            integrate(
                &radau,
                tolerance.clone(),
                40.0,
                OdeOutputSchedule::FinalOnly,
            ),
        ),
        (
            "Bdf",
            integrate(&bdf, tolerance, 40.0, OdeOutputSchedule::FinalOnly),
        ),
    ] {
        let (path, report) = run.map_err(|e| e.to_string())?;
        let termination = report.termination().ok_or("終了状態がない")?;
        if !termination.is_success() {
            return Err(format!(
                "{name}（rtol = {rtol:e}）が {termination} で止まった"
            ));
        }
        let y = path
            .states()
            .last()
            .ok_or("出力がない")?
            .as_slice()
            .to_vec();
        runs.push((name, rtol, y, report.accepted_steps()));
    }
}
// 基準: rtol = 10⁻¹¹ の RadauIia。
let reference = runs[runs.len() - 2].2.clone();
let mut series = vec![Vec::new(), Vec::new()];
let mut rows = Vec::new();
for (name, rtol, y, steps) in &runs {
    let gap = (y[1] - reference[1]).abs() / reference[1];
    if gap > 0.0 {
        series[usize::from(*name == "Bdf")].push([*rtol, gap]);
    }
    rows.push((
        name.to_string(),
        *rtol,
        y[0],
        y[1],
        (gap > 0.0).then_some(gap),
        *steps,
    ));
}
emit_line_chart!(
    &vec![
        serde_json::json!({ "name": "RadauIia", "points": series[0] }),
        serde_json::json!({ "name": "Bdf", "points": series[1] })
    ],
    options = &serde_json::json!({
        "xLabel": "相対許容誤差 rtol [-]",
        "yLabel": "y₂(40) の基準との相対差 [-]",
        "xType": "log",
        "yType": "log"
    })
);
let columns = serde_json::json!([
    { "key": "0", "label": "方式" },
    { "key": "1", "label": "rtol [-]", "type": "number", "format": sci3 },
    { "key": "2", "label": "y₁(40) [-]", "type": "number", "format": digits10 },
    { "key": "3", "label": "y₂(40) [-]", "type": "number", "format": digits10 },
    { "key": "4", "label": "y₂ の基準との相対差 [-]", "type": "number", "format": sci3, "nullText": "基準" },
    { "key": "5", "label": "受理した刻み", "type": "integer" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "convergence" })
);
emit_outcome!(
    Outcome::satisfied("16 通りの計算のすべてで t = 40 s に達した")
        .status("ReachedEnd")
        .diagnostic(
            "rtol = 10⁻¹¹ の Bdf と基準の y₂ の相対差",
            rows[15].4.unwrap_or(0.0),
            None
        )
);
```

`RadauIia` の $y_2(40)$ の基準との相対差は、$\mathrm{rtol} = 10^{-4}$ の $2.0 \times 10^{-6}$ から $10^{-10}$ の $3.5 \times 10^{-14}$ まで減り、図では rtol が 1 桁下がるごとに約 1 桁下がる。
`Bdf` の相対差も $4.0 \times 10^{-5}$ から $10^{-11}$ の $1.6 \times 10^{-10}$ まで減り、別の方式が同じ値に近づく。
基準の値は $y_1(40) = 0.7158270687$、$y_2(40) = 9.185534765 \times 10^{-6}$ で、引用した $0.715827$、$9.1855 \times 10^{-6}$ と示された桁まで一致する。
このセルの終端は t = 40 s なので、値は刻みの終点の値で、連続出力の補間を含まない。
相対差は基準との差なので、基準そのものの誤差は測れない。
二つの方式が同じ値に近づくことが、基準が数値誤差の小さい値であることの根拠になる。

## まとめ

Robertson 反応系では成分の大きさが 5 桁から 13 桁違うので、絶対許容誤差を成分ごとに `ErrorTolerance::try_vector` で与える。
小さい成分の絶対許容誤差を大きいまま使うと、その成分の誤差が許容誤差に隠れ、`RosenbrockW` の $y_2(40)$ は 30 % ずれた。
総和 $y_1 + y_2 + y_3$ の保存は、このずれがあっても $10^{-14}$ の精度で成り立つので、精度の確認には使えない。
$y_2$ の時間変化は準定常近似で、t = 40 s の値は許容誤差を厳しくした `RadauIia` と `Bdf` の収束で確かめる。
出力時刻の値は連続出力の補間値なので、`RosenbrockW` の 3 次 Hermite 補間のように刻みが大きいと負の濃度が出ることがあり、刻みの終点の値と分けて読む。
