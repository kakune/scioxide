SIR モデル（Susceptible–Infectious–Recovered）は、感染症の流行の拡大と収束を表す非線形の連立常微分方程式である。
接触を減らす介入で接触率が時間とともに変わる場合、感染者の割合 $I(t)$ のピークは、実効再生産数 $\mathcal{R}_e(t)$ が 1 を下回る時刻として求まる。
この例題では連続出力の上の事象の検出でピークの時刻を出力の格子によらずに求め、総人口の保存 $S + I + R = 1$ と最終規模の関係式で数値解を確かめる。

## SIR モデルと保存量

閉じた均一な集団で、感受性者の割合 $S(t)$、感染性者の割合 $I(t)$、回復または隔離された者の割合 $R(t)$ は

$$
\frac{dS}{dt} = -\beta(t) S I, \qquad \frac{dI}{dt} = \beta(t) S I - \gamma I, \qquad \frac{dR}{dt} = \gamma I
$$

に従う。
$\beta(t)$ は接触率 [1/day]、$\gamma$ は回復率 [1/day] で、平均の感染期間は $1/\gamma$ である。
この例題では $\gamma = 1/7$（感染期間 7 日）とする。
3 式を足すと右辺は 0 になるので、$S + I + R$ は保存量で、初期値の 1 のまま変わらない。

$\dot I$ を書き直すと

$$
\frac{dI}{dt} = \gamma\bigl(\mathcal{R}_e(t) - 1\bigr) I, \qquad \mathcal{R}_e(t) = \frac{\beta(t)}{\gamma}\,S(t)
$$

になる。
$\mathcal{R}_e$ は 1 人の感染者がその時点の条件で生む新しい感染者の平均の数（実効再生産数）で、$\mathcal{R}_e > 1$ の間は $I$ が増え、$\mathcal{R}_e < 1$ の間は減る。
したがって $I$ のピークは、事象関数 $g(t, S, I, R) = \beta(t) S - \gamma$ が正から負へ横切る時刻（`EventDirection::Falling`）である。
介入の前の $\mathcal{R}_0 = \beta_0/\gamma$ を基本再生産数という。

## ロジスティック関数による介入

時刻 $t_c$ を中心に接触を割合 $r \in [0, 1)$ だけ減らす介入を、移行の幅 $w$ [day] のロジスティック関数で表す。

$$
L(t) = \frac{1}{1 + e^{-(t - t_c)/w}}, \qquad \beta(t) = \beta_0\bigl[1 - r L(t)\bigr]
$$

接触率が不連続に変わると、そこで Runge–Kutta 法の局所誤差の推定が成り立たず、刻みが極端に小さくなる。
滑らかに変えれば、適応刻みの積分をそのまま使える。
$L$ は $\tfrac12\bigl[1 + \tanh\bigl((t - t_c)/(2w)\bigr)\bigr]$ と同じ値なので、指数の桁あふれを避けるためにこの形で計算する。
$r \ge 0$ なら $\beta(t)$ は増えず、$S(t)$ は減り続けるので、$\mathcal{R}_e(t)$ は単調に減る。
そのためこのモデルでは $\mathcal{R}_e$ が 1 を下回るのは 1 回だけで、ピークは高々一つである。

介入がない場合（$r = 0$）は、$dS/dR = -\mathcal{R}_0 S$ を積分して、十分に時間が経った後の $S_\infty$ が最終規模の関係式

$$
S_\infty = S_0 \exp\bigl(-\mathcal{R}_0 (1 - S_\infty)\bigr)
$$

を満たす（$R(0) = 0$、$I(\infty) = 0$）。
これを数値解の独立な検算に使う。

次のブロックは二つのセルが共有する定義である。
`Sir` が右辺と接触率 $\beta(t)$、`Peak` がピークの事象 $g = \beta(t)S - \gamma$ である。

```rust
//| id: ode-sir-model
//| kind: definitions
//| title: 介入のある SIR モデルとピークの事象
//| crates: [scioxide-core, scioxide-ode]
use scioxide_core::{SciOxideError, RealScalar, SolveContext};
use scioxide_ode::{EventDirection, EventFunction, OdeSystem};

/// 割合 (S, I, R) の SIR モデル。接触率 β(t) = β₀[1 − r L(t)]、L はロジスティック関数。
#[derive(Clone, Copy)]
pub(crate) struct Sir {
    pub(crate) beta0: f64,
    pub(crate) gamma: f64,
    pub(crate) reduction: f64,
    pub(crate) center: f64,
    pub(crate) width: f64,
}
impl Sir {
    /// L(t) = 1/(1 + e^{−(t − tc)/w}) を ½[1 + tanh((t − tc)/(2w))] の形で計算し、指数の桁あふれを避ける。
    pub(crate) fn beta(&self, t: f64) -> f64 {
        let switch = 0.5 * (1.0 + RealScalar::tanh((t - self.center) / (2.0 * self.width)));
        self.beta0 * (1.0 - self.reduction * switch)
    }
}
impl OdeSystem<f64> for Sir {
    fn dimension(&self) -> usize {
        3
    }
    /// S' = −βSI、I' = βSI − γI、R' = γI。
    fn rhs(
        &self,
        t: f64,
        y: &[f64],
        out: &mut [f64],
        _: &mut SolveContext<'_, '_>,
    ) -> Result<(), SciOxideError> {
        let (incidence, removal) = (self.beta(t) * y[0] * y[1], self.gamma * y[1]);
        out.copy_from_slice(&[-incidence, incidence - removal, removal]);
        Ok(())
    }
}
/// 感染性割合のピーク I' = 0、つまり g = β(t)S − γ が正から負へ横切る時刻。
pub(crate) struct Peak(pub(crate) Sir);
impl EventFunction<f64> for Peak {
    fn eval(&self, t: f64, y: &[f64]) -> Result<f64, SciOxideError> {
        Ok(self.0.beta(t) * y[0] - self.0.gamma)
    }
    fn direction(&self) -> EventDirection {
        EventDirection::Falling
    }
    fn is_terminal(&self) -> bool {
        false
    }
}
```

## 介入とピークの事象

次のセルは基本再生産数 $\mathcal{R}_0$、初期の感染割合 $I_0$、介入の中心日、削減率、移行の幅を変え、240 日の流行を `DormandPrince5`（局所誤差の許容誤差 $10^{-9}$、最大刻み 0.5 日）で解く。
状態は 0.5 日ごとの時刻に連続出力で出し、ピークは事象として別に求める。
上の図は $S, I, R$ の積み上げ、下の図は $\mathcal{R}_e(t)$ で、横軸の時刻は二つの図で連動する。
表は事象として求めたピーク、事象の時刻の $\mathcal{R}_e$、出力の格子での最大の時刻、累積の感染割合、総人口の保存の誤差を示す。
このセルのパラメータは次のセルに渡す。

```rust
//| id: ode-sir-intervention
//| ref: ode-sir-intervention
//| title: SIR 流行の介入と感染のピークの事象
//| run: reactive
//| uses: [ode-sir-model]
//| crates: [scioxide-core, scioxide-linalg, scioxide-ode]
//| exports: [beta0, gamma, reduction, width, initial_infected]
//| inputs:
//|   sir_basic_reproduction_number: {"type":"range","label":"基本再生産数 R₀ [-]","description":"介入の前の 1 人あたりの二次感染者の数。","min":1.1,"max":4,"step":0.1,"value":2.4}
//|   sir_initial_infected_exponent: {"type":"range","label":"初期の感染割合 I₀ = 10^q の指数 q","description":"流行が立ち上がる時期を変える。","min":-6,"max":-2,"step":0.5,"value":-4}
//|   sir_intervention_day: {"type":"range","label":"介入の中心日 tc [day]","description":"感染が広がるどの段階で接触を減らすか。","min":5,"max":100,"step":5,"value":35}
//|   sir_contact_reduction: {"type":"range","label":"接触の削減率 r [-]","description":"介入の後の接触率は β₀(1 − r)。","min":0,"max":0.9,"step":0.05,"value":0.45}

//| cases:
//|   - {"id":"no-intervention","label":"r = 0","description":"介入がないとピークは高く、最終規模の関係式と比べられる。","inputs":{"sir_contact_reduction":0}}
//|   - {"id":"fast-spread","label":"R₀ = 4","description":"介入の前にピークが来る。","inputs":{"sir_basic_reproduction_number":4}}
//|   - {"id":"late-start","label":"I₀ = 10⁻⁶","description":"流行が遅れ、介入の後に低いピークが来る。","inputs":{"sir_initial_infected_exponent":-6}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"peak","path":"/rows/0/0","approx":{"value":44.962,"atol":0.01}}
//|       - {"artifact":"peak","path":"/rows/0/2","approx":{"value":1,"atol":1e-8}}
//|       - {"artifact":"peak","path":"/rows/0/5","range":{"max":1e-13}}
//|       - {"path":"/outputs/3/state","equals":"satisfied"}
//|   - case: no-intervention
//|     expect:
//|       - {"artifact":"peak","path":"/rows/0/4","approx":{"value":0.8786,"atol":1e-3}}
//|   - case: fast-spread
//|     expect:
//|       - {"artifact":"peak","path":"/rows/0/0","range":{"max":30}}
//|   - case: late-start
//|     expect:
//|       - {"artifact":"peak","path":"/rows/0/0","range":{"min":100}}
use scioxide_core::{Budget, ErrorTolerance, ExecutionContext, NormSelection};
use scioxide_linalg::Vector;
use scioxide_ode::{
    DormandPrince5, EventFunction, OdeMethod, OdeOptions, OdeOutputSchedule, OdeProblem,
    OdeState, OdeTrajectory,
};

let gamma = 1.0 / 7.0; // 平均の感染期間 7 日
let model = Sir {
    beta0: sir_basic_reproduction_number * gamma,
    gamma,
    reduction: sir_contact_reduction,
    center: sir_intervention_day,
    width: sir_transition_width,
};
let i0 = 10.0_f64.powf(sir_initial_infected_exponent);
let tolerance = ErrorTolerance::scalar(1e-9, 1e-9, NormSelection::RootMeanSquare)
    .map_err(|e| e.to_string())?;
// 0.5 日ごとの時刻に連続出力で値を出し、ピークは事象として別に求める。
let options = OdeOptions::new()
    .with_error_tolerance(tolerance)
    .with_initial_step(0.05)
    .with_maximum_step(0.5)
    .with_max_steps(Budget::try_from(30_000).map_err(|e| e.to_string())?)
    .with_output_schedule(OdeOutputSchedule::times(
        (0..=480).map(|i| f64::from(i) / 2.0).collect(),
    ));
let event = Peak(model);
let events: &[&dyn EventFunction<f64>] = &[&event];
let problem = OdeProblem::new(&model, 240.0).with_events(events);
let method = DormandPrince5::new();
let mut workspace = method
    .workspace(&problem, &options)
    .map_err(|e| e.to_string())?;
let mut state = OdeState::new(0.0, Vector::from_vec(vec![1.0 - i0, i0, 0.0]));
let mut path = OdeTrajectory::new();
let report = method
    .advance(
        &problem,
        &options,
        &mut state,
        &mut path,
        &mut workspace,
        ExecutionContext::sequential(),
    )
    .map_err(|e| e.to_string())?;
let samples = || {
    path.times()
        .iter()
        .zip(path.states())
        .map(|(&t, y)| (t, y.as_slice()))
};
let names = ["感受性 S", "感染性 I", "除去済み R"];
let series: Vec<_> = (0..3)
    .map(|k| {
        let points: Vec<_> = samples().map(|(t, y)| [t, y[k]]).collect();
        serde_json::json!({ "name": names[k], "points": points, "stack": "population" })
    })
    .collect();
// S + I + R = 1 なので、積み上げた面の上端が 1 に張り付くことで保存も読める。
emit_area_chart!(
    &series,
    options = &serde_json::json!({
        "link": { "group": "sir-time" },
        "xLabel": "時刻 t [day]",
        "yLabel": "人口の割合 [-]",
        "yMin": 0.0,
        "yMax": 1.0
    })
);
let re: Vec<_> = samples()
    .map(|(t, y)| [t, model.beta(t) * y[0] / gamma])
    .collect();
// 網掛けは接触率が切り替わる移行期間 [tc − w, tc + w]。
let (from, to) = (model.center - model.width, model.center + model.width);
let transition = serde_json::json!({ "kind": "range", "axis": "x", "from": from, "to": to });
let threshold =
    serde_json::json!({ "kind": "line", "axis": "y", "value": 1.0, "label": "Re = 1" });
emit_line_chart!(
    &vec![serde_json::json!({ "name": "Re(t)", "points": re })],
    options = &serde_json::json!({
        "link": { "group": "sir-time" },
        "xLabel": "時刻 t [day]",
        "yLabel": "実効再生産数 Re [-]",
        "annotations": [transition, threshold]
    })
);
// 独立な検算: 総人口の保存と、出力の格子での最大との比較。
let conservation = samples()
    .map(|(_, y)| (y.iter().sum::<f64>() - 1.0).abs())
    .fold(0.0, f64::max);
let sampled = samples()
    .max_by(|a, b| a.1[1].total_cmp(&b.1[1]))
    .ok_or("軌道が空")?
    .0;
let peak = path.events().first();
let row = (
    peak.map(|e| e.time()),
    peak.map(|e| 100.0 * e.state()[1]),
    peak.map(|e| model.beta(e.time()) * e.state()[0] / gamma),
    sampled,
    1.0 - state.values()[0],
    conservation,
    report.accepted_steps(),
);
let fixed1 = serde_json::json!({ "fractionDigits": 1 });
let fixed3 = serde_json::json!({ "fractionDigits": 3 });
let fixed4 = serde_json::json!({ "fractionDigits": 4 });
let fixed10 = serde_json::json!({ "fractionDigits": 10 });
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let columns = serde_json::json!([
    { "key": "0", "label": "ピークの時刻 [day]", "type": "number", "format": fixed3, "nullText": "なし" },
    { "key": "1", "label": "ピークの I [%]", "type": "number", "format": fixed3, "nullText": "なし" },
    { "key": "2", "label": "事象の時刻の Re [-]", "type": "number", "format": fixed10, "nullText": "なし" },
    { "key": "3", "label": "格子での最大の時刻 [day]", "type": "number", "format": fixed1 },
    { "key": "4", "label": "累積の感染割合 1 − S(240) [-]", "type": "number", "format": fixed4 },
    { "key": "5", "label": "max |S + I + R − 1| [-]", "type": "number", "format": sci2 },
    { "key": "6", "label": "受理した刻み [回]", "type": "integer" }
]);
emit_table_with_columns!(
    columns,
    vec![row],
    metadata = serde_json::json!({ "id": "peak" })
);
export!(beta0, model.beta0);
export!(gamma, gamma);
export!(reduction, model.reduction);
export!(width, model.width);
export!(initial_infected, i0);
let termination = report.termination().ok_or("終了状態がない")?;
let outcome = if report.is_success() {
    Outcome::satisfied("240 日まで積分した")
} else {
    Outcome::partial("240 日の前に刻みの上限で止まった")
};
emit_outcome!(outcome.status(termination.to_string()).diagnostic(
    "保存の誤差",
    conservation,
    None
));
```

既定値（$\mathcal{R}_0 = 2.4$、$I_0 = 10^{-4}$、介入の中心 35 日、削減率 45 %、移行の幅 3 日）では、事象として求めたピークは 44.962 日、感染性割合 8.828 % で、事象の時刻の $\mathcal{R}_e$ は表の 10 桁で 1 に一致する。
0.5 日ごとの出力の格子での最大は 45.0 日で、格子の間隔の分だけ時刻がずれる。
累積の感染割合は 0.5538 で、総人口の保存の誤差は $6.7 \times 10^{-16}$ と丸め誤差の程度である。
線形の保存量は Runge–Kutta 法の各段で保たれるので、この誤差の小ささは解の精度を示さない。
介入がない場合（$r = 0$）はピークが 47.645 日、21.860 % に高まり、累積の感染割合は 0.8786 になる。
$\mathcal{R}_0 = 4$ では介入の前の 24.385 日に 40.17 % のピークが来て、累積の感染割合は 0.9693 になる。
$I_0 = 10^{-6}$ では流行が遅れ、介入の後の 141.005 日に 3.281 % の低いピークが来る。

## 介入の時期とピーク・最終規模

介入の効果は削減率だけでなく時期にも依存する。
次のセルは前のセルの $\mathcal{R}_0$、$I_0$、削減率、移行の幅を受け取り、介入の中心日 $t_c$ を 0 日から 120 日まで 5 日ごとに変えて、ピークの高さと 240 日での累積の感染割合を求める。
出力は終端の状態だけにし（既定の `OdeOutputSchedule::FinalOnly`）、ピークは事象として受け取る。
図の横線は介入がない場合の値で、二つの図の横軸は連動する。
表の 1 行目は介入がない場合で、累積の感染割合を最終規模の関係式（固定点反復で解く）と比べる。

```rust
//| id: ode-sir-intervention-timing
//| ref: ode-sir-intervention-timing
//| title: 介入の中心日を変えたときのピークと最終規模
//| run: button
//| uses: [ode-sir-model]
//| crates: [scioxide-core, scioxide-linalg, scioxide-ode]
//| dependsOn:
//|   run: ode-sir-intervention
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"timing","path":"/rows/0/3","approx":{"value":0.87861295,"atol":1e-6}}
//|       - {"artifact":"timing","path":"/rows/0/4","approx":{"value":0.87861295,"atol":1e-6}}
//|       - {"artifact":"timing","path":"/rows/1/2","range":{"max":5}}
use scioxide_core::{ErrorTolerance, ExecutionContext, NormSelection};
use scioxide_linalg::Vector;
use scioxide_ode::{
    DormandPrince5, EventFunction, OdeMethod, OdeOptions, OdeProblem, OdeState, OdeTrajectory,
};

let read = |key: &str| run[key].as_f64().ok_or(format!("{key} がない"));
let (beta0, gamma, i0) = (read("beta0")?, read("gamma")?, read("initial_infected")?);
let (reduction, width) = (read("reduction")?, read("width")?);
let tolerance = ErrorTolerance::scalar(1e-9, 1e-9, NormSelection::RootMeanSquare)
    .map_err(|e| e.to_string())?;
// 出力は終端の状態だけにし、ピークは事象として受け取る。
let options = OdeOptions::new()
    .with_error_tolerance(tolerance)
    .with_initial_step(0.05)
    .with_maximum_step(0.5);
let method = DormandPrince5::new();
// 介入の中心日 tc で解き、(ピークの時刻, ピークの I [%], 1 − S(240)) を返す。
let simulate =
    |reduction: f64, center: f64| -> Result<(Option<f64>, Option<f64>, f64), String> {
        let model = Sir {
            beta0,
            gamma,
            reduction,
            center,
            width,
        };
        let event = Peak(model);
        let events: &[&dyn EventFunction<f64>] = &[&event];
        let problem = OdeProblem::new(&model, 240.0).with_events(events);
        let mut workspace = method
            .workspace(&problem, &options)
            .map_err(|e| e.to_string())?;
        let mut state = OdeState::new(0.0, Vector::from_vec(vec![1.0 - i0, i0, 0.0]));
        let mut path = OdeTrajectory::new();
        let context = ExecutionContext::sequential();
        let report = method
            .advance(
                &problem,
                &options,
                &mut state,
                &mut path,
                &mut workspace,
                context,
            )
            .map_err(|e| e.to_string())?;
        if !report.is_success() {
            return Err(format!("積分が途中で止まった: {:?}", report.termination()));
        }
        let peak = path.events().first();
        let size = 1.0 - state.values()[0];
        Ok((
            peak.map(|e| e.time()),
            peak.map(|e| 100.0 * e.state()[1]),
            size,
        ))
    };
// 独立な検算: 介入がなければ S∞ = S₀ exp(−R₀(1 − S∞))（t → ∞ の最終規模の関係式）。
let r0 = beta0 / gamma;
let s_inf = (0..500).fold(0.0, |s, _| (1.0 - i0) * (-r0 * (1.0 - s)).exp());
let (time, height, size) = simulate(0.0, 0.0)?;
let mut rows = vec![(None, time, height, size, Some(1.0 - s_inf))];
let (mut peaks, mut sizes) = (Vec::new(), Vec::new());
for k in 0..=24 {
    let center = 5.0 * f64::from(k);
    let (time, height, size) = simulate(reduction, center)?;
    if let Some(h) = height {
        peaks.push([center, h]);
    }
    sizes.push([center, size]);
    if k % 4 == 0 {
        rows.push((Some(center), time, height, size, None));
    }
}
let none_peak =
    serde_json::json!({ "kind": "line", "axis": "y", "value": height, "label": "介入なし" });
let none_size =
    serde_json::json!({ "kind": "line", "axis": "y", "value": size, "label": "介入なし" });
let symbols = serde_json::json!({ "showSymbol": true });
emit_line_chart!(
```

既定のパラメータで介入がない場合、240 日での累積の感染割合 0.87861295 は最終規模の関係式の解 0.87861295 と $8 \times 10^{-10}$ の差で一致する（240 日では $I$ がほぼ 0 まで減っている）。
介入の中心を 0 日にすると、接触率は初めの数日で $\beta_0(1 - r)$ に近づき、ピークは 152.2 日の 3.22 % まで下がり、累積の感染割合は 0.4312 になる。
介入の中心が 40 日ではピークは 13.57 % で、60 日以降は介入の前にピークが過ぎるので、ピークの高さは介入がない場合とほとんど変わらない。
ただし累積の感染割合は、ピークの後の介入でも 0.837（60 日）と少し下がる。

## まとめ

SIR モデルでは総人口の保存が丸め誤差の範囲で成り立つが、これは線形の保存量を Runge–Kutta 法が保つためで、精度の証拠にはならない。
解の精度は、介入がない場合の最終規模の関係式との比較で確かめる。
感染のピークは $\mathcal{R}_e$ が 1 を下回る事象として、出力の格子によらずに求まる。
このモデルの介入は一度始まると続くので、早いほどピークと最終規模は下がり、ピークの後の介入はピークの高さを変えない。
事象の時刻の精度は軌道の精度で決まり、その確かめ方は [空気抵抗のある落体の接地事象](../ground-event/)にある。
