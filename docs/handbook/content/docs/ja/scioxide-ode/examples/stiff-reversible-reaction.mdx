化学反応や燃焼のモデルでは、ライフタイムの短い中間体（時定数 10⁻⁸ s 程度）と主反応物の変化（10² s 程度）が同じ系に現れ、強い剛性を持つ。
陽解法の刻み幅は最も速く減衰する成分の安定条件で制限され、遅い変化を追うにも多くの刻みが要る。
このページでは緩和の速さを操作できる最も簡単な剛性のある系として可逆 1 次反応を取り上げる。
固定刻みの後退 Euler 法（`BackwardEuler`）と陰的台形則（`ImplicitTrapezoid`）の数値解を解析解と比べ、濃度が負にならないかを増幅因子から確かめる。

## 可逆 1 次反応と固有値

二つの化学種 A、B の可逆 1 次反応

$$
\mathrm{A} \underset{k_r}{\overset{k_f}{\rightleftharpoons}} \mathrm{B}
$$

の濃度 $A(t)$、$B(t)$ [mol/L] は、正反応と逆反応の速度定数 $k_f$、$k_r$ [1/s] を使って

$$
\frac{dA}{dt} = -k_f A + k_r B, \qquad \frac{dB}{dt} = k_f A - k_r B
$$

に従う。
二つの式を足すと $(A + B)' = 0$ なので、総濃度 $M = A + B$ は保存される。
$B = M - A$ を代入すると、$A$ だけの方程式

$$
\frac{dA}{dt} = -(k_f + k_r) A + k_r M = -\lambda (A - A_{\mathrm{eq}})
$$

が得られる。
緩和の速さ $\lambda$ [1/s] と平衡濃度 $A_{\mathrm{eq}}$ は

$$
\lambda = k_f + k_r, \qquad A_{\mathrm{eq}} = \frac{k_r}{k_f + k_r} M
$$

で、解析解は

$$
A(t) = A_{\mathrm{eq}} + (A(0) - A_{\mathrm{eq}}) e^{-\lambda t}
$$

である。
Jacobian 行列の固有値は $0$（総量の保存）と $-\lambda$（緩和）である。
$\lambda$ が大きいと緩和はすぐに終わるが、陽的 Euler 法は平衡に達した後も、安定のために $h < 2/\lambda$ の刻みしか使えない。

## 増幅因子

線形の系では、1 刻みで $A - A_{\mathrm{eq}}$ は増幅因子 $R(-z)$ 倍になる。
$z = h\lambda$ は無次元の刻みで、$R$ は方式の安定関数である。

$$
R_{\mathrm{BE}}(-z) = \frac{1}{1 + z}, \qquad
R_{\mathrm{TR}}(-z) = \frac{1 - z/2}{1 + z/2}
$$

後退 Euler 法の $R_{\mathrm{BE}}$ は $z > 0$ でつねに 0 と 1 の間にあり、$z \to \infty$ で 0 に近づく（L 安定）。
陰的台形則の $R_{\mathrm{TR}}$ は $\lvert R \rvert \le 1$ を満たす（A 安定）が、$z > 2$ で負になり、$z \to \infty$ で $-1$ に近づく。
$R$ が負だと、単調に減衰するはずの $A - A_{\mathrm{eq}}$ が刻みごとに符号を変える。
最初の刻みで $A_1 = A_{\mathrm{eq}} + R(-z)(A_0 - A_{\mathrm{eq}})$ が負になるのは、$A_0 > A_{\mathrm{eq}}$ のとき

$$
R(-z) < -\frac{A_{\mathrm{eq}}}{A_0 - A_{\mathrm{eq}}}
$$

の場合である。
安定関数と L 安定性の定義は[誤差・次数・安定性](../../algorithms/error-order-and-stability/)にある。

次のブロックはこのページのセルが共有する定義である。
`Reaction` は右辺と定数の Jacobian を与え、`jacobian_is_constant` で Jacobian が定数であることを伝える。
`march` は、与えた固定刻みの方式で刻み $h$ のまま `steps` 刻み進め、受理した各刻みの状態を返す。

```rust
//| id: ode-stiff-reaction-model
//| kind: definitions
//| title: 可逆反応の右辺・定数の Jacobian・固定刻みの積分
//| crates: [scioxide-core, scioxide-linalg, scioxide-ode]
use scioxide_core::{SciOxideError, SolveContext};
use scioxide_linalg::{MatrixViewMut, Vector};
use scioxide_ode::{
    OdeMethod, OdeOptions, OdeOutputSchedule, OdeProblem, OdeState, OdeSystem, OdeTrajectory,
};

/// A′ = −k_f A + k_r B、B′ = k_f A − k_r B。成分の順は (A, B)。
pub(crate) struct Reaction {
    pub(crate) kf: f64,
    pub(crate) kr: f64,
}

impl OdeSystem<f64> for Reaction {
    fn dimension(&self) -> usize {
        2
    }

    fn rhs(
        &self,
        _: f64,
        y: &[f64],
        out: &mut [f64],
        _: &mut SolveContext<'_, '_>,
    ) -> Result<(), SciOxideError> {
        let rate = self.kf * y[0] - self.kr * y[1];
        out[0] = -rate;
        out[1] = rate;
        Ok(())
    }

    fn jacobian(
        &self,
        _: f64,
        _: &[f64],
        j: &mut MatrixViewMut<'_, f64>,
        _: &mut SolveContext<'_, '_>,
    ) -> Result<Option<()>, SciOxideError> {
        j.set(0, 0, -self.kf)?;
        j.set(0, 1, self.kr)?;
        j.set(1, 0, self.kf)?;
        j.set(1, 1, -self.kr)?;
        Ok(Some(()))
    }

    fn jacobian_is_constant(&self) -> bool {
        true
    }
}

/// 固定刻みの方式で、(A₀, M − A₀) から刻み h のまま steps 刻み進める。
/// 刻みの数の上限を置かないので、段の方程式が解けなければエラーを返す。
pub(crate) fn march<M: OdeMethod<f64> + Clone>(
    method: &M,
    reaction: &Reaction,
    initial_a: f64,
    total: f64,
    step: f64,
    steps: usize,
) -> Result<OdeTrajectory<f64>, SciOxideError> {
    let options = OdeOptions::new()
        .with_initial_step(step)
        .with_output_schedule(OdeOutputSchedule::AcceptedSteps);
    let problem = OdeProblem::new(reaction, step * steps as f64);
    let initial = OdeState::new(0.0, Vector::from_vec(vec![initial_a, total - initial_a]));
    let solution = method
        .solve(&problem, &options, initial)
        .map_err(SciOxideError::from)?;
    let (_, _, path) = solution.into_parts();
    Ok(path)
}
```

## 陰的方式による固定刻みの積分

次のセルは、`BackwardEuler`（1 次、L 安定）と `ImplicitTrapezoid`（2 次、A 安定）を同じ固定刻み $h$ で 40 刻み進め、解析解と比べる。
固定刻みの方式は `OdeOptions::with_initial_step` の刻みのまま進み、誤差の推定と刻みの調整をしない。
図は二つの方式の $A(t)$ と解析解（破線）で、平衡濃度を横線で示す。
上の表は、1 刻み目の比 $(A_1 - A_{\mathrm{eq}})/(A_0 - A_{\mathrm{eq}})$（増幅因子の実測値）、解析解との最大の差、$A$ の最小、総量 $A + B$ の誤差の最大を示す。
下の表は $z$ と増幅因子の式の値である。

```rust
//| id: ode-stiff-reaction-solve
//| ref: ode-stiff-reaction-solve
//| title: 後退 Euler 法と陰的台形則で剛性のある可逆反応を解く
//| run: reactive
//| uses: [ode-stiff-reaction-model]
//| crates: [scioxide-core, scioxide-linalg, scioxide-ode]
//| inputs:
//|   forward_rate: {"type":"range","label":"正反応の速度定数 k_f [1/s]","min":10,"max":200,"step":10,"value":100}
//|   reverse_rate: {"type":"range","label":"逆反応の速度定数 k_r [1/s]","min":2,"max":40,"step":2,"value":20}
//|   stiff_step_size: {"type":"range","label":"刻み h [s]","description":"無次元の刻み z = h(k_f + k_r) を変える。","min":0.005,"max":0.1,"step":0.005,"value":0.04}
//|   initial_a: {"type":"range","label":"初期濃度 A₀ [mol/L]","min":0,"max":2,"step":0.1,"value":1.5}
//|   total_mass: {"type":"range","label":"総濃度 M = A + B [mol/L]","min":1,"max":3,"step":0.1,"value":2}
//| cases:
//|   - {"id":"small-step","label":"h = 0.005 s（z = 0.6）","description":"z < 2 では陰的台形則の比も正になり、誤差は後退 Euler 法より小さい。","inputs":{"stiff_step_size":0.005}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"methods","path":"/rows/0/1","approx":{"value":0.1724137931,"rtol":1e-9}}
//|       - {"artifact":"methods","path":"/rows/1/1","approx":{"value":-0.4117647059,"rtol":1e-9}}
//|       - {"artifact":"methods","path":"/rows/1/3","range":{"max":0}}
//|       - {"artifact":"methods","path":"/rows/0/4","range":{"max":1e-14}}
//|   - case: small-step
//|     expect:
//|       - {"artifact":"methods","path":"/rows/1/1","approx":{"value":0.5384615385,"rtol":1e-9}}
use scioxide_ode::{BackwardEuler, ImplicitTrapezoid};

let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let fixed4 = serde_json::json!({ "fractionDigits": 4 });
let reaction = Reaction {
    kf: forward_rate,
    kr: reverse_rate,
};
let (h, m, steps) = (stiff_step_size, total_mass, 40);
let lambda = reaction.kf + reaction.kr;
let a_eq = reaction.kr * m / lambda;
// 独立な検算: 解析解 A(t) = A_eq + (A₀ − A_eq) e^{−λt}（f64 の標準関数）。
let exact = |t: f64| a_eq + (initial_a - a_eq) * (-lambda * t).exp();
let backward = march(&BackwardEuler::new(), &reaction, initial_a, m, h, steps)
    .map_err(|e| e.to_string())?;
let trapezoid = march(&ImplicitTrapezoid::new(), &reaction, initial_a, m, h, steps)
    .map_err(|e| e.to_string())?;
let exact_curve: Vec<[f64; 2]> = (0..=4 * steps)
    .map(|i| {
        let t = h * i as f64 / 4.0;
        [t, exact(t)]
    })
    .collect();
let mut series = vec![serde_json::json!({
    "name": "解析解",
    "points": exact_curve,
    "style": { "lineType": "dashed", "showSymbol": false }
})];
let mut rows = Vec::new();
for (name, path) in [("後退 Euler 法", &backward), ("陰的台形則", &trapezoid)] {
    let points: Vec<[f64; 2]> = path
        .times()
        .iter()
        .zip(path.states())
        .map(|(&t, y)| [t, y.as_slice()[0]])
        .collect();
    let error = points
        .iter()
        .map(|p| (p[1] - exact(p[0])).abs())
        .fold(0.0_f64, f64::max);
    let minimum = points.iter().map(|p| p[1]).fold(f64::INFINITY, f64::min);
    let mass = path
        .states()
        .iter()
        .map(|y| (y.as_slice()[0] + y.as_slice()[1] - m).abs())
        .fold(0.0_f64, f64::max);
    // 1 刻み目の比 (A₁ − A_eq)/(A₀ − A_eq) は増幅因子 R(−z) の実測値。A₀ = A_eq なら定義しない。
    let ratio = (initial_a != a_eq).then(|| (points[1][1] - a_eq) / (initial_a - a_eq));
    rows.push((
        name.to_string(),
        ratio,
        error,
        minimum,
        mass,
        path.times().len() - 1,
    ));
    series.push(serde_json::json!({ "name": name, "points": points }));
}
emit_line_chart!(
    &series,
    options = &serde_json::json!({
        "xLabel": "時間 t [s]",
        "yLabel": "A の濃度 [mol/L]",
        "annotations": [{ "kind": "line", "axis": "y", "value": a_eq, "label": "A_eq" }]
    })
);
let columns = serde_json::json!([
    { "key": "0", "label": "方式" },
    { "key": "1", "label": "1 刻み目の比 [-]", "type": "number", "format": fixed4, "nullText": "未定義" },
    { "key": "2", "label": "解析解との最大の差 [mol/L]", "type": "number", "format": sci2 },
    { "key": "3", "label": "A の最小 [mol/L]", "type": "number", "format": fixed4 },
    { "key": "4", "label": "max |A + B − M| [mol/L]", "type": "number", "format": sci2 },
    { "key": "5", "label": "刻みの数", "type": "integer" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "methods" })
);
let z = h * lambda;
let factor_columns = serde_json::json!([
    { "key": "0", "label": "z = hλ [-]", "type": "number", "format": { "fractionDigits": 2 } },
    { "key": "1", "label": "A_eq [mol/L]", "type": "number", "format": fixed4 },
    { "key": "2", "label": "1/(1 + z) [-]", "type": "number", "format": fixed4 },
    { "key": "3", "label": "(1 − z/2)/(1 + z/2) [-]", "type": "number", "format": fixed4 }
]);
emit_table_with_columns!(
    factor_columns,
    vec![(z, a_eq, 1.0 / (1.0 + z), (1.0 - z / 2.0) / (1.0 + z / 2.0))],
    metadata = serde_json::json!({ "id": "factors" })
);
```

既定値（$k_f = 100$、$k_r = 20$ s⁻¹、$h = 0.04$ s、$A_0 = 1.5$、$M = 2$ mol/L）では $z = h\lambda = 4.8$ である。
1 刻み目の比は後退 Euler 法で 0.1724、陰的台形則で $-0.4118$ で、増幅因子の式 $1/(1 + z)$ と $(1 - z/2)/(1 + z/2)$ の値に一致する。
陰的台形則の $A$ は平衡濃度 0.3333 の上下を振動し、最小で $-0.1471$ mol/L と負になる。
後退 Euler 法の $A$ は単調に平衡濃度へ近づく。
解析解との最大の差は、どちらも緩和が速い最初の刻みで生じ、後退 Euler 法で 0.19、陰的台形則で 0.49 mol/L である。
総量 $A + B$ の誤差はどちらの方式でも $2 \times 10^{-15}$ mol/L 以下で、線形の保存量は段の方程式が解けている限り Runge–Kutta 法で保たれる。
$h = 0.005$ s（$z = 0.6$）では陰的台形則の比も正（0.5385）になり、解析解との最大の差は 0.013 mol/L と、後退 Euler 法の 0.10 mol/L より小さい。
$z < 2$ では 2 次の陰的台形則のほうが誤差が小さく、$z$ が大きいと速い成分を減衰させる後退 Euler 法のほうが誤差が小さい。

## 刻みと濃度の最小

次のセルは $k_f = 100$、$k_r = 20$ s⁻¹（$\lambda = 120$ s⁻¹）、$A_0 = 1.5$、$M = 2$ mol/L（$A_{\mathrm{eq}} = 1/3$）に固定し、$z = h\lambda$ を 0.25 から上限まで 40 通りに変えて 40 刻み進める。
後退 Euler 法と陰的台形則に、3 段 3 次の L 安定な SDIRK 法（`Sdirk`、Alexander の係数）を加えて比べる。
上の図は 1 刻み目の比、下の図は 40 刻みの間の $A$ の最小で、二つの図の横軸 $z$ は連動する。
表は 8 通りおきの $z$ での値である。

```rust
//| id: ode-stiff-amplification-comparison
//| ref: ode-stiff-amplification-comparison
//| title: 刻みを変えて濃度の最小と 1 刻みの増幅を測る
//| run: reactive
//| uses: [ode-stiff-reaction-model]
//| crates: [scioxide-core, scioxide-linalg, scioxide-ode]
//| inputs:
//|   amplification_maximum_z: {"type":"range","label":"z = hλ の上限 [-]","description":"z を 0.25 からこの値まで 40 通りに変える。","min":2.5,"max":20,"step":0.5,"value":10}
//| cases:
//|   - {"id":"large-z","label":"z ≤ 20","description":"z を大きくすると、陰的台形則の比は −1 に近づく。","inputs":{"amplification_maximum_z":20}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"sweep","path":"/rows/5/1","approx":{"value":0.0909090909,"rtol":1e-9}}
//|       - {"artifact":"sweep","path":"/rows/5/3","approx":{"value":-0.6666666667,"rtol":1e-9}}
//|       - {"artifact":"sweep","path":"/rows/5/2","approx":{"value":0.3333333333,"rtol":1e-9}}
use scioxide_ode::{BackwardEuler, ImplicitTrapezoid, OdeTrajectory, Sdirk};

let fixed4 = serde_json::json!({ "fractionDigits": 4 });
let reaction = Reaction {
    kf: 100.0,
    kr: 20.0,
};
let (initial_a, total, a_eq) = (1.5, 2.0, 1.0 / 3.0);
let names = ["後退 Euler 法", "陰的台形則", "SDIRK 法"];
let (mut ratio, mut minimum) = (vec![Vec::new(); 3], vec![Vec::new(); 3]);
let mut rows = Vec::new();
for i in 0..40 {
    let z = 0.25 + (amplification_maximum_z - 0.25) * f64::from(i) / 39.0;
    let h = z / 120.0;
    let paths: [OdeTrajectory<f64>; 3] = [
        march(&BackwardEuler::new(), &reaction, initial_a, total, h, 40)
            .map_err(|e| e.to_string())?,
        march(
            &ImplicitTrapezoid::new(),
            &reaction,
            initial_a,
            total,
            h,
            40,
        )
        .map_err(|e| e.to_string())?,
        march(&Sdirk::new(), &reaction, initial_a, total, h, 40).map_err(|e| e.to_string())?,
    ];
    let mut row = vec![z];
    for (k, path) in paths.iter().enumerate() {
        // 1 刻み目の (A₁ − A_eq)/(A₀ − A_eq) が増幅因子 R(−z) の実測値。
        let r = (path.states()[1].as_slice()[0] - a_eq) / (initial_a - a_eq);
        let low = path
            .states()
            .iter()
            .map(|y| y.as_slice()[0])
            .fold(f64::INFINITY, f64::min);
        ratio[k].push([z, r]);
        minimum[k].push([z, low]);
        row.extend([r, low]);
    }
    if i % 8 == 0 || i == 39 {
        rows.push((row[0], row[1], row[2], row[3], row[4], row[5], row[6]));
    }
}
let series = |data: &[Vec<[f64; 2]>]| -> Vec<serde_json::Value> {
    names
        .iter()
        .zip(data)
        .map(|(name, points)| serde_json::json!({ "name": name, "points": points }))
        .collect()
};
// R = 0 より下では A − A_eq が刻みごとに符号を変える。
emit_line_chart!(
    &series(&ratio),
    options = &serde_json::json!({
        "link": { "group": "reaction-z" },
        "xLabel": "z = hλ [-]",
        "yLabel": "1 刻み目の比 [-]",
        "annotations": [
            { "kind": "line", "axis": "y", "value": 0.0 },
            { "kind": "line", "axis": "y", "value": -1.0, "label": "R = −1" }
        ]
    })
);
emit_line_chart!(
    &series(&minimum),
    options = &serde_json::json!({
        "link": { "group": "reaction-z" },
        "xLabel": "z = hλ [-]",
        "yLabel": "40 刻みの間の A の最小 [mol/L]",
        "annotations": [{ "kind": "line", "axis": "y", "value": 0.0, "label": "A = 0" }]
    })
);
let columns = serde_json::json!([
    { "key": "0", "label": "z [-]", "type": "number", "format": { "fractionDigits": 2 } },
    { "key": "1", "label": "後退 Euler 法の比 [-]", "type": "number", "format": fixed4 },
    { "key": "2", "label": "後退 Euler 法の A の最小 [mol/L]", "type": "number", "format": fixed4 },
    { "key": "3", "label": "陰的台形則の比 [-]", "type": "number", "format": fixed4 },
    { "key": "4", "label": "陰的台形則の A の最小 [mol/L]", "type": "number", "format": fixed4 },
    { "key": "5", "label": "SDIRK 法の比 [-]", "type": "number", "format": fixed4 },
    { "key": "6", "label": "SDIRK 法の A の最小 [mol/L]", "type": "number", "format": fixed4 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "sweep" })
);
```

陰的台形則の比は $z > 2$ で負になり、$z = 10$ で $-0.6667$、$z = 20$ の近くでは $-0.8$ を下回って $-1$ に近づく。
$A$ が負になる条件 $R(-z) < -A_{\mathrm{eq}}/(A_0 - A_{\mathrm{eq}}) = -2/7 \approx -0.286$ は、陰的台形則では $z > 3.6$ にあたる。
表では $z = 4.25$ で $A$ の最小が $-0.0867$ mol/L、$z = 10$ で $-0.4444$ mol/L である。
後退 Euler 法の比 $1/(1 + z)$ はどの $z$ でも 0 と 1 の間にあり、$A$ の最小は平衡濃度 0.3333 にとどまる。

`Sdirk` も L 安定だが、比は $z = 4.25$ で $-0.0855$、$z = 8.25$ で $-0.1302$ と負になる。
L 安定性は A 安定であることと $z \to \infty$ で $R \to 0$ になることを言うだけで、途中の $z$ で $R$ が負にならないことは言わない。
この例では `Sdirk` の比は $-0.286$ を下回らず、$A$ の最小は 0.18 mol/L 以上にとどまるが、$A_{\mathrm{eq}}/(A_0 - A_{\mathrm{eq}})$ が 0.13 より小さい問題（平衡濃度が初期濃度よりずっと小さい問題）では負になりうる。
非負性が要る問題では方式の安定関数の符号を確かめる。

## まとめ

剛性のある系では、陽解法の刻み幅は精度ではなく安定性で決まる。
固定刻みの陰的方式は大きい刻みでも発散しないが、陰的台形則（A 安定）は $z > 2$ で速い成分を符号を変える振動として残し、濃度を負にすることがある。
後退 Euler 法の増幅因子は $0 < R < 1$ なので濃度は単調に平衡へ近づくが、精度は 1 次にとどまる。
L 安定な `Sdirk` でも増幅因子は負になりうるので、非負性は方式ごとに安定関数で確かめる。
精度と安定性の両方が要る剛性の問題には、適応刻みの `RadauIia` や `Bdf` を使う（[方式の選び方](../../choosing/)）。
