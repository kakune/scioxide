Van der Pol 振動子は、真空管の発振回路のモデルとして導かれた非線形の振動子である。
減衰の係数 $\mu$ を大きくすると、ゆっくり動く区間と急に跳ぶ区間を交互に繰り返す緩和振動になり、方程式は剛性を持つ。
このページでは同じ方程式を $\mu = 1$ から 1000 まで変えて、陽解法 `DormandPrince5` と剛性向けの方式の刻みと評価回数を比べる。
解の正しさは、事象で測った周期を小さい $\mu$ と大きい $\mu$ の近似式と比べ、終端の状態を方式の間で比べて確かめる。

## Van der Pol 方程式

無次元の時間 $t$ と変位 $x$ で、方程式は

$$
x'' - \mu (1 - x^2) x' + x = 0, \qquad \mu > 0
$$

である。
$\lvert x \rvert < 1$ では減衰の項が負になってエネルギーを注ぎ、$\lvert x \rvert > 1$ では正になってエネルギーを奪う。
そのため、どの初期値から始めても軌道は振幅およそ 2 のただ一つの周期軌道（リミットサイクル）に近づく。
$v = x'$ とおくと、1 階の系

$$
x' = v, \qquad v' = \mu (1 - x^2) v - x
$$

になる。
成分の順は $(x, v)$ で、Jacobian 行列は

$$
J = \begin{pmatrix} 0 & 1 \\ -2\mu x v - 1 & \mu (1 - x^2) \end{pmatrix}
$$

である。

$\mu$ が大きいと、周期軌道は二つの区間に分かれる。
$\lvert x \rvert$ が 2 から 1 へゆっくり減る区間では $v$ は小さく、$J$ の固有値の一つはおよそ $\mu(1 - x^2)$ で、$x = 2$ では $-3\mu$ に達する。
$\lvert x \rvert = 1$ に着くと、$x$ は時間 $O(1/\mu)$ で反対側の $\mp 2$ 付近へ跳ぶ。
ゆっくりした区間の解は $O(\mu)$ の時間をかけて変わるのに、$J$ には大きさ $3\mu$ の負の固有値がある。
解の変化よりずっと速く減衰する成分があることが、この方程式の剛性である。

陽解法の刻み $h$ は、$h\lambda$ が方式の安定領域に入る大きさに制限される。
`DormandPrince5` の `linear_stability` は、負の実軸の安定な区間を $[-3.3065, 0]$ と返す。
$\lambda \approx -3\mu$ では、刻みは $h \le 3.3065/(3\mu) \approx 1.1/\mu$ に制限され、精度に必要な刻みよりずっと小さくなる。
ゆっくりした区間の長さは $O(\mu)$ なので、1 周期の刻みの数は $\mu^2$ に比例して増える。
剛性向けの方式（[Rosenbrock-W 法と剛性の自動切り替え](../../algorithms/rosenbrock-and-stiffness-switching/)、[多段法](../../algorithms/multistep-methods/)）は負の実軸全体で安定なので、刻みは精度だけで決まる。

## 周期の近似式

$\mu$ が小さいときは、Lindstedt–Poincaré 法で振動数を $\mu$ のべきに展開できる。
振動数は $\omega = 1 - \mu^2/16 + O(\mu^4)$ なので、周期は

$$
T \approx 2\pi \left( 1 + \frac{\mu^2}{16} \right)
$$

である。
$\mu$ が大きいときは、ゆっくりした区間の時間が主になる。
ゆっくりした区間で $x''$ を無視すると、$\mu(1 - x^2)x' \approx x$ から $dt = \mu (1 - x^2)/x \, dx$ となる。
$x$ が 2 から 1 まで動く時間を 2 倍すると、主要項

$$
T_0 = 2\mu \int_1^2 \frac{x^2 - 1}{x} \, dx = (3 - 2\ln 2)\mu \approx 1.6137\mu
$$

が得られる。
跳ぶ区間の始まりにある境界層を Airy 関数で扱うと、次の項まで含めて

$$
T \approx (3 - 2\ln 2)\mu + 3\alpha \mu^{-1/3}
$$

となる（Dorodnitsyn の公式）。
ここで $\alpha \approx 2.338107$ は Airy 関数 $\mathrm{Ai}(-z)$ の最初の零点である。
残る項は $O(\mu^{-1}\ln\mu)$ なので、$\mu$ が大きいほど式の相対誤差は小さくなる。
どちらの式も中くらいの $\mu$（3 程度）では精度が落ちる。

次のブロックはこのページのセルが共有する定義である。
`VanDerPol` は右辺と解析的な Jacobian を与え、自励系なので時間微分 $\partial f/\partial t$ に 0 を返す。
0 を返すと、`RosenbrockW` は $\partial f/\partial t$ を差分で近似する評価を省く。
`upward_crossing` は $x$ が負から正へ 0 を横切る事象で、終端にはしない。
`integrate` は初期値 $(x, v) = (2, 0)$ から終端 `horizon` まで、絶対・相対許容誤差 $\varepsilon$（RMS ノルム）と、試みた刻み 20000 回の上限で解く。
`period` は事象の最後の二つの時刻の差である。

```rust
//| id: ode-van-der-pol-model
//| kind: definitions
//| title: Van der Pol 振動子の右辺・Jacobian・周期の事象
//| crates: [scioxide-core, scioxide-linalg, scioxide-ode]
use scioxide_core::{Budget, ErrorTolerance, SciOxideError, NormSelection, SolveContext};
use scioxide_linalg::{MatrixViewMut, Vector};
use scioxide_ode::{
    EventDirection, EventFn, EventFunction, OdeMethod, OdeOptions, OdeOutputSchedule,
    OdeProblem, OdeSolveReport, OdeState, OdeSystem, OdeTrajectory,
};

/// x′ = v、v′ = μ(1 − x²)v − x。成分の順は (x, v)。
pub(crate) struct VanDerPol {
    pub(crate) mu: f64,
}

impl OdeSystem<f64> for VanDerPol {
    fn dimension(&self) -> usize {
        2
    }

    fn rhs(
        &self,
        _: f64,
        y: &[f64],
        out: &mut [f64],
        _: &mut SolveContext<'_, '_>,
    ) -> Result<(), SciOxideError> {
        out[0] = y[1];
        out[1] = self.mu * (1.0 - y[0] * y[0]) * y[1] - y[0];
        Ok(())
    }

    fn jacobian(
        &self,
        _: f64,
        y: &[f64],
        j: &mut MatrixViewMut<'_, f64>,
        _: &mut SolveContext<'_, '_>,
    ) -> Result<Option<()>, SciOxideError> {
        j.set(0, 0, 0.0)?;
        j.set(0, 1, 1.0)?;
        j.set(1, 0, -2.0 * self.mu * y[0] * y[1] - 1.0)?;
        j.set(1, 1, self.mu * (1.0 - y[0] * y[0]))?;
        Ok(Some(()))
    }

    fn time_derivative(
        &self,
        _: f64,
        _: &[f64],
        out: &mut [f64],
        _: &mut SolveContext<'_, '_>,
    ) -> Result<Option<()>, SciOxideError> {
        out.fill(0.0);
        Ok(Some(()))
    }
}

/// x が負から正へ 0 を横切る事象。終端にはしない。
pub(crate) fn upward_crossing() -> impl EventFunction<f64> {
    EventFn::new(|_: f64, y: &[f64]| Ok(y[0])).with_direction(EventDirection::Rising)
}

/// 周期の近似の 3 倍を終端にする。上向きの横断が 3 回入り、最後の 1 周期は初期値の影響が消えている。
pub(crate) fn horizon(mu: f64) -> f64 {
    3.0 * (2.0 * std::f64::consts::PI + (3.0 - 2.0 * std::f64::consts::LN_2) * mu)
}

/// (x, v) = (2, 0) から horizon まで、許容誤差 ε、試みた刻み 20000 回までで解く。
pub(crate) fn integrate<M: OdeMethod<f64> + Clone>(
    method: &M,
    mu: f64,
    eps: f64,
    schedule: OdeOutputSchedule<f64>,
) -> Result<(OdeTrajectory<f64>, OdeSolveReport<f64>), SciOxideError> {
    let system = VanDerPol { mu };
    let crossing = upward_crossing();
    let events: [&dyn EventFunction<f64>; 1] = [&crossing];
    let problem = OdeProblem::new(&system, horizon(mu)).with_events(&events);
    let options = OdeOptions::new()
        .with_error_tolerance(ErrorTolerance::scalar(
            eps,
            eps,
            NormSelection::RootMeanSquare,
        )?)
        .with_max_steps(Budget::try_from(20_000)?)
        .with_output_schedule(schedule);
    let initial = OdeState::new(0.0, Vector::from_vec(vec![2.0, 0.0]));
    let solution = method
        .solve(&problem, &options, initial)
        .map_err(SciOxideError::from)?;
    let (_, report, path) = solution.into_parts();
    Ok((path, report))
}

/// 上向きの横断の最後の 2 回の時刻の差。2 回に満たなければ None。
pub(crate) fn period(path: &OdeTrajectory<f64>) -> Option<f64> {
    match path.events() {
        [.., previous, last] => Some(last.time() - previous.time()),
        _ => None,
    }
}
```

## 陽解法と剛性向けの方式の比較

次のセルは $\mu$ と許容誤差 $\varepsilon$ を選び、同じ問題を四つの方式で解く。

- `DormandPrince5`: 陽的な Runge–Kutta 法 5(4)。
- `RosenbrockW`（`RosenbrockMethod::Ros34Pw2`）: 3 次の線形陰的な方式。
  刻みごとに $I - h\gamma J$ を LU 分解し、Newton 反復を使わない。
- `Bdf`（`MultistepOrder::Automatic(5)`）: 次数 1〜5 を自動で選ぶ後退差分公式。
  `Bdf::new(5)` は次数と刻みを固定するので、適応刻みには `with_order_policy` を使う。
- `AdamsBdf`: Adams 法で始め、剛性の指標 $\lvert h \rvert \rho(J)$ が閾値を超えると `Bdf` に切り替える `AutoStiff` の組。

どの方式も、試みた刻みが 20000 回に達すると `BudgetLimit(Proposal)` で止まり、最後に受理した状態を返す。
表は方式ごとの終了状態、刻みの数、右辺・Jacobian・LU 分解の回数、事象で測った周期、終端に達した方式の終端の状態を示す。
`RosenbrockW` は $\partial f/\partial t$ の呼び出しも Jacobian の評価に数える。
二つ目の表は `AdamsBdf` の切り替えの回数と最後の切り替えの記録（`OdeMethodSwitch`）である。
このセルは `Bdf` の解 $x(t)$ と各方式の受理した刻みの幅を、次のセルに渡す。

既定値（$\mu = 100$、$\varepsilon = 10^{-6}$）では、終端は $t = 503.0$ で周期は約 163 である。
`DormandPrince5` は 20000 回の試みのうち 16703 刻みを受理し、3297 刻みを棄却したところで `BudgetLimit(Proposal)` で止まり、$t = 291.0$ までしか進まない。
剛性向けの三つの方式は終端に達した。
`Bdf` は 2105 刻み（右辺の評価 7437 回、LU 分解 801 回）、`RosenbrockW` は 3 次なので刻みが多く 5342 刻みである。
`AdamsBdf` は $t = 0.038$ で指標 $\lvert h \rvert \rho(J) = 1.10$ が閾値 1 を超えて `AdamsMoulton` から `Bdf` に切り替え（理由 `Stiffness`）、その後は戻らない。
戻る条件は、指標が 1/4 を下回る受理が 6 刻み続くことで、指標の $h$ には切り替え後に `Bdf` が使った最大の刻みを使う。
周期軌道の上では $\rho(J)$ は 1 を下回らない（ゆっくりした区間では $\lvert \det J \rvert \ge 5/3$、跳ぶ区間では $\lvert \operatorname{tr} J \rvert$ が大きい）ので、最大の刻み 5 程度と掛けた指標は 1/4 を下回らない。

方式の間の一致は許容誤差の大きさで決まる。
$\varepsilon = 10^{-6}$ では周期は `RosenbrockW` が 162.83696、`Bdf` が 162.82850 で、相対差は $5 \times 10^{-5}$、終端の $x$ の差は $1.9 \times 10^{-4}$ である。
$\varepsilon = 10^{-8}$ では `Bdf` と `AdamsBdf` の終端の $x$ は 1.8994446 で 8 桁まで一致し、周期 162.83689 は下のセルの `RadauIia` の値 162.83708 と $1.2 \times 10^{-6}$ の相対差で合う。
この許容誤差では `RosenbrockW` も試みた刻み 20000 回の上限に達し、$t = 406.9$ で止まる。

$\mu = 1$ では剛性がなく、`DormandPrince5` が 169 刻みで最も少なく、`AdamsBdf` は切り替えずに Adams 法のまま 497 刻みで終わる。
$\mu = 30$ では `DormandPrince5` も終端に達するが、3124 刻みと 658 回の棄却を要し、`Bdf` の 1659 刻みより多い。
$\mu = 1000$ では `DormandPrince5` は $t = 18.3$ までしか進まず、最初の跳びにも届かない。
`Bdf` の刻みは $\mu = 100$ から 1000 で 2105 から 2596 に増えるだけで、$\mu^2$ に比例する陽解法の刻みの数とは増え方が違う。

## 周期と近似式の照合

次のセルは $\mu$ を 1 から 1000 までの 7 通りに変え、`RadauIia` で解いて周期を測る。
`RadauIia` は 5 次の L 安定な陰的 Runge–Kutta 法で、上の比較とは別の方式による検算になる。
表は測った周期 $T$、Lindstedt 展開の $2\pi(1 + \mu^2/16)$、大きい $\mu$ の漸近形 $(3 - 2\ln 2)\mu + 3\alpha\mu^{-1/3}$ と、それぞれの相対差を示す。
上の図は周期を両対数で描き、近似式を破線で重ねる。
下の図は相対差で、横軸は上の図と連動する。
許容誤差を $10^{-6}$ と $10^{-8}$ で比べると、測った周期の変化から数値誤差の大きさが分かる。

```rust
//| id: ode-van-der-pol-period
//| ref: ode-van-der-pol-period
//| title: 7 通りの μ で周期を測り、近似式と比べる
//| run: button
//| uses: [ode-van-der-pol-model]
//| crates: [scioxide-core, scioxide-linalg, scioxide-ode]
//| inputs:
//|   period_tolerance: {"type":"select","label":"許容誤差 ε [-]","description":"絶対・相対許容誤差。","options":["1e-6","1e-8"],"value":"1e-8"}
//| cases:
//|   - {"id":"loose","label":"ε = 10⁻⁶","description":"許容誤差を緩めると、μ = 1000 の周期が 10⁻² 程度動く。","inputs":{"period_tolerance":"1e-6"}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"periods","path":"/rows/0/1","approx":{"value":6.6632868549,"rtol":1e-8}}
//|       - {"artifact":"periods","path":"/rows/6/1","approx":{"value":1614.4011,"rtol":1e-6}}
//|       - {"artifact":"periods","path":"/rows/6/5","range":{"max":1e-5}}
//|   - case: loose
//|     expect:
//|       - {"artifact":"periods","path":"/rows/6/1","approx":{"value":1614.4,"rtol":1e-4}}
use scioxide_ode::{OdeOutputSchedule, RadauIia};

let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let digits8 = serde_json::json!({ "significantDigits": 8 });
let eps: f64 = period_tolerance.parse().map_err(|_| "許容誤差を読めない")?;
// α は Ai(−z) の最初の零点。
let airy_zero = 2.338107410459767;
let lindstedt = |mu: f64| 2.0 * std::f64::consts::PI * (1.0 + mu * mu / 16.0);
let asymptotic =
    |mu: f64| (3.0 - 2.0 * std::f64::consts::LN_2) * mu + 3.0 * airy_zero * mu.powf(-1.0 / 3.0);
let method = RadauIia::new();
let (mut rows, mut measured, mut small_gap, mut large_gap) =
    (Vec::new(), Vec::new(), Vec::new(), Vec::new());
for mu in [1.0, 3.0, 10.0, 30.0, 100.0, 300.0, 1000.0] {
    let (path, report) =
        integrate(&method, mu, eps, OdeOutputSchedule::FinalOnly).map_err(|e| e.to_string())?;
    let termination = report.termination().ok_or("終了状態がない")?;
    if !termination.is_success() {
        return Err(format!("μ = {mu} で {termination} により止まった"));
    }
    let t = period(&path).ok_or("横断が 2 回に満たない")?;
    let (small, large) = (lindstedt(mu), asymptotic(mu));
    let (small_rel, large_rel) = ((small - t).abs() / t, (large - t).abs() / t);
    measured.push([mu, t]);
    small_gap.push([mu, small_rel]);
    large_gap.push([mu, large_rel]);
    rows.push((
        mu,
        t,
        small,
        small_rel,
        large,
        large_rel,
        report.accepted_steps(),
    ));
}
let curve = |f: &dyn Fn(f64) -> f64, top: f64| -> Vec<[f64; 2]> {
    (0..=60)
        .map(|i| 10.0_f64.powf(3.0 * f64::from(i) / 60.0))
        .filter(|&mu| mu <= top)
        .map(|mu| [mu, f(mu)])
        .collect()
};
emit_chart!(
    serde_json::json!({
        "kind": "xy",
        "link": { "group": "vdp-mu" },
        "dataZoom": true,
        "tooltip": true,
        "xLabel": "減衰の係数 μ [-]",
        "yLabel": "周期 T [-]",
        "xType": "log",
        "yType": "log",
        "layers": [
            {
                "id": "lindstedt",
                "kind": "line",
                "name": "2π(1 + μ²/16)",
                "points": curve(&lindstedt, 10.0),
                "style": { "lineType": "dashed", "showSymbol": false }
            },
            {
                "id": "asymptotic",
                "kind": "line",
                "name": "(3 − 2 ln 2)μ + 3αμ^(−1/3)",
                "points": curve(&asymptotic, 1000.0),
                "style": { "lineType": "dashed", "showSymbol": false }
            },
            { "id": "measured", "kind": "scatter", "name": "RadauIia で測った周期", "points": measured }
        ]
    }),
    metadata = serde_json::json!({ "id": "period-chart" })
);
emit_line_chart!(
    &vec![
        serde_json::json!({ "name": "Lindstedt 展開", "points": small_gap }),
        serde_json::json!({ "name": "大きい μ の漸近形", "points": large_gap })
    ],
    options = &serde_json::json!({
        "link": { "group": "vdp-mu" },
        "xLabel": "減衰の係数 μ [-]",
        "yLabel": "近似式と測った周期の相対差 [-]",
        "xType": "log",
        "yType": "log"
    })
);
let columns = serde_json::json!([
    { "key": "0", "label": "μ [-]", "type": "number", "format": { "significantDigits": 4 } },
    { "key": "1", "label": "測った周期 T [-]", "type": "number", "format": digits8 },
    { "key": "2", "label": "2π(1 + μ²/16) [-]", "type": "number", "format": digits8 },
    { "key": "3", "label": "相対差 [-]", "type": "number", "format": sci2 },
    { "key": "4", "label": "漸近形 [-]", "type": "number", "format": digits8 },
    { "key": "5", "label": "相対差 [-]", "type": "number", "format": sci2 },
    { "key": "6", "label": "受理した刻み", "type": "integer" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "periods" })
);
emit_outcome!(
    Outcome::satisfied("7 通りの μ のすべてで終端に達し、周期を測った")
        .status("ReachedEnd")
        .diagnostic("μ = 1000 の漸近形との相対差", large_gap[6][1], None)
);
```

既定値（$\varepsilon = 10^{-8}$）では、$\mu = 1$ の周期は 6.6632869 で、Lindstedt 展開との相対差は $1.9 \times 10^{-3}$ である。
これは展開で省いた $O(\mu^4)$ の項の大きさで、$\mu = 3$ では相対差が 0.11 に増え、$\mu = 10$ では展開は使えない。
大きい $\mu$ の漸近形との相対差は、$\mu = 10$ で $1.6 \times 10^{-2}$、100 で $2.7 \times 10^{-4}$、1000 で $3.6 \times 10^{-6}$ と減る。
$\mu$ を 10 倍にすると相対差は約 1/77 になり、残る項が相対的に $O(\mu^{-2}\ln\mu)$ であることと合う。
$\mu = 1000$ の周期は 1614.4013 で、漸近形 1614.4071 との差 0.0058 は残る項 $-(2/3)\mu^{-1}\ln\mu \approx -0.0046$ と同じ大きさである。
$\varepsilon = 10^{-6}$ にすると $\mu = 1000$ の周期は 1614.4082 に動き、数値誤差（0.0069）が漸近形の残る項より大きくなるので、漸近形の検証には $10^{-8}$ が要る。
$\mu = 3$ のような中くらいの値ではどちらの式も 10 % 程度ずれ、数値解だけが周期を与える。

## まとめ

Van der Pol 振動子は $\mu$ を大きくすると、ゆっくりした区間で $-3\mu$ 程度の固有値を持つ剛性のある方程式になる。
陽解法 `DormandPrince5` の刻みは安定の限界 $3.3065/(3\mu)$ に縛られて $\mu^2$ に比例して増え、$\mu \ge 100$ では刻みの上限で止まる。
上限で止まったときは `BudgetLimit` のレポートと最後に受理した時刻を確かめ、値を終端の解として使わない。
剛性向けの `Bdf`、`AdamsBdf`、`RosenbrockW` の刻みは $\mu$ を 1 から 1000 にしても 4〜5 倍にしか増えず、`AdamsBdf` の切り替えの記録は `last_method_switch` で確かめられる。
解の確かさは、事象で測った周期を Lindstedt 展開と大きい $\mu$ の漸近形に、許容誤差を変えた計算と別の方式（`RadauIia`）で照合して確かめる。
