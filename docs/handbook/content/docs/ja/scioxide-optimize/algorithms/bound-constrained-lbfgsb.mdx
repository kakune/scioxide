ボックス制約付き最小化

$$
\min_{\mathbf{x}\in\mathbb{R}^n} f(\mathbf{x}) \quad \text{subject to} \quad l_i\le x_i\le u_i \quad (i=1,\dots,n)
$$

では、境界から外へ向かう移動は許されない。
$f$ は一回連続微分可能とし、端点は片側だけでも、$l_i=u_i$ の固定でもよい（$l_i=-\infty$、$u_i=+\infty$ は境界なしを表す）。
最小点でも通常の勾配が零になるとは限らないので、実行可能な方向への改善が残るかを調べる。
このページでは一次の最適性条件、射影勾配による停止、SciOxide の `LbfgsB` の一反復、設定と作業領域を順に説明する。
古典的な L-BFGS-B の一般化 Cauchy 点と、反復で有効な境界が入れ替わる様子は[一般化 Cauchy 点と有効集合の特定](../lbfgsb-cauchy-point-and-active-set/)で扱う。

## 境界での一次条件

不等式 $x_i-l_i\ge0$、$u_i-x_i\ge0$ に乗数 $\lambda_i,\mu_i\ge0$ を付けると、KKT 条件は

$$
\nabla f(\mathbf{x}) = \boldsymbol{\lambda} - \boldsymbol{\mu}, \qquad \lambda_i (x_i-l_i)=0, \qquad \mu_i (u_i-x_i)=0, \qquad \boldsymbol{\lambda},\boldsymbol{\mu}\ge\mathbf{0}
$$

になる。
ボックス制約はすべて線形なので制約想定が成り立ち、局所最小点はこの条件を満たす。
$l_i=u_i$ の成分では二つの制約の勾配 $\pm\mathbf{e}_i$ が一次従属になるが、線形な制約ではこれも妨げにならない。
一成分ずつ見ると、内部では $g_i=0$、下限では $g_i=\lambda_i\ge0$、上限では $g_i=-\mu_i\le0$ が必要になる（$g_i=\partial f/\partial x_i$）。
下限で勾配が正なら、許される増加方向では目的が増えるので、その成分は動かさなくてよい。
上下限が等しい成分には自由な移動方向がなく、勾配の符号は問わない。

射影勾配は境界の外へ向かう負勾配の成分を取り除いた量である。

$$
(\mathbf{P}\mathbf{g})_i = \begin{cases}
0 & (l_i=u_i,\ \text{または}\ x_i=l_i \text{ かつ } g_i\ge0,\ \text{または}\ x_i=u_i \text{ かつ } g_i\le0) \\
g_i & (\text{それ以外})
\end{cases}
$$

実行可能な点では、一次の最適性条件は $\mathbf{P}\mathbf{g}=\mathbf{0}$ と同値である。
箱への射影を $P_{[\mathbf{l},\mathbf{u}]}$ とすると、これは任意の $\alpha>0$ に対する不動点条件 $\mathbf{x}=P_{[\mathbf{l},\mathbf{u}]}(\mathbf{x}-\alpha\mathbf{g})$ とも同値である。
凸な目的ではこの条件は大域最小性の十分条件にもなるが、非凸な目的では停留性までしか示さない。

### 射影勾配による停止

`LbfgsB` は各反復の前に射影勾配の最大成分を調べ、

$$
\|\mathbf{P}\mathbf{g}\|_\infty \le \tau_{\mathrm{abs}} + \tau_{\mathrm{rel}}\max\!\left(1, \frac{|f(\mathbf{x})|}{\max(1,\|\mathbf{x}\|_\infty)}\right)
$$

を満たしたら `GradientSmall` で止める。
既定の `GradientTolerance` は $\tau_{\mathrm{abs}}=\tau_{\mathrm{rel}}=\sqrt{\varepsilon_{\mathrm{mach}}}\approx1.49\times10^{-8}$ である。
結果の診断 `diagnostics().stationarity()` は同じ射影勾配の 2 ノルム、`bound_violation()` は箱からのはみ出しの最大値を返す。
停止判定の量（$\infty$ ノルム）と診断の量（2 ノルム）は別のノルムである。
目的値の変化や刻みの小ささでは止まらず、成功はこの判定だけで決まる。

## 射影 L-BFGS の一反復

`LbfgsB` は射影勾配に逆 L-BFGS モデルを作用させ、その結果も同じ自由な成分へ射影する。
勾配で境界に押し付けられた成分と固定成分を除いた残りを自由な成分の集合 $F$ とし、$F$ の成分だけを残す対角の 0/1 行列を $\mathbf{P}_F$ とすると、射影勾配は $\mathbf{P}\mathbf{g}=\mathbf{P}_F\mathbf{g}$ と書ける。
現在点 $\mathbf{x}_k$、勾配 $\mathbf{g}_k$、直近 $m$ 対の差分から作る逆ヘッセ行列の近似 $\mathbf{H}_k$（[二重ループ再帰](../first-order-and-quasi-newton/)で積だけを計算する）を使い、一反復は次の手順で進む。

1. 射影勾配 $\mathbf{q}=\mathbf{P}_F\mathbf{g}_k$ を作る（境界の外へ押す成分と固定成分を 0 にする）。
2. モデルの方向 $\mathbf{d}=-\mathbf{H}_k\mathbf{q}$ を二重ループ再帰で求める。
   再帰が数値的に破綻した場合は履歴を捨て、$\mathbf{d}=-\mathbf{g}_k$ とする。
3. $F$ に含まれない成分と、境界上にあって $\mathbf{d}$ が外へ向かう成分（$x_i=l_i$ かつ $d_i<0$、または $x_i=u_i$ かつ $d_i>0$）を 0 にする。
   外向きの成分を 0 にする前の方向は $\mathbf{d}=-\mathbf{P}_F\mathbf{H}_k\mathbf{P}_F\mathbf{g}_k$ である。
4. $\mathbf{g}_k^\mathsf{T}\mathbf{d}<0$ でなければ履歴を捨て、$\mathbf{d}=-\mathbf{g}_k$ として手順 3 からやり直す（射影最急降下）。
5. 単位ステップ幅の終点を箱へ射影し、方向を $\mathbf{d}\leftarrow P_{[\mathbf{l},\mathbf{u}]}(\mathbf{x}_k+\mathbf{d})-\mathbf{x}_k$ と置き換える。
   置き換えた方向の傾き $\mathbf{g}_k^\mathsf{T}\mathbf{d}$ を計算し直し、負でなければ手順 4 の射影最急降下へ移る。
   射影最急降下でも負の傾きが得られなければ `Stagnation` で止める。
6. 線分 $\mathbf{x}_k+\alpha\mathbf{d}$（$0<\alpha\le1$）上の刻み $\alpha$ を Armijo 後退（$c_1=10^{-4}$、縮小率 0.5、最大 40 回）で選ぶ。
   箱は凸なので、この線分上の点はすべて実行可能である。
   受理できる刻みがなければ `LineSearchFailed` で止める。
7. 受理した点で $\mathbf{s}_k=\mathbf{x}_{k+1}-\mathbf{x}_k$、$\mathbf{y}_k=\mathbf{g}_{k+1}-\mathbf{g}_k$ を作り、曲率を確かめて履歴に加える。

### 方向が降下方向になる理由

$\mathbf{P}_F$ は対称なので、手順 3 で外向きの成分を除く前の方向の傾きは $\mathbf{g}_k^\mathsf{T}\mathbf{d}=-(\mathbf{P}_F\mathbf{g}_k)^\mathsf{T}\mathbf{H}_k(\mathbf{P}_F\mathbf{g}_k)$ となり、$\mathbf{H}_k$ が正定値で $\mathbf{P}_F\mathbf{g}_k\ne\mathbf{0}$ なら負になる。
出力側の $\mathbf{P}_F$ がなければ、$\mathbf{H}_k$ の非対角成分を通して勾配で押し付けられた成分が内向きに動き、傾きが正になることがある。
外向きの成分を 0 にした後と手順 5 の置き換えの後はこの保証がないので、傾きを計算し直して負であることを確かめてから探索する。
Armijo の比較には比較する量の大きさに対して $8\varepsilon_{\mathrm{mach}}$ の丸めの余裕を持たせるが、停止は上の射影勾配の判定だけで決める。

一反復で有効な境界は何個でも入れ替わる。
手順 5 の射影で多くの成分が同時に境界に達しうる一方、手順 1 と 3 は勾配と方向の符号だけで成分を止めるので、勾配の符号が内向きに変われば次の反復でその成分は境界を離れる。

### 曲率の確認と減衰

手順 7 の曲率の確認はヘッセ近似 $\mathbf{B}_k=\mathbf{H}_k^{-1}$ の形で行い、$\mathbf{s}_k^\mathsf{T}\mathbf{y}_k$ が $\eta\,\mathbf{s}_k^\mathsf{T}\mathbf{B}_k\mathbf{s}_k$（既定 $\eta=0.2$）を下回ると $\mathbf{y}_k$ を Powell の方法で減衰させる。
$\mathbf{s}_k^\mathsf{T}\mathbf{B}_k\mathbf{s}_k$ は、履歴の内積を正規化して保存したコンパクト表現 $\mathbf{B}_k=\theta\mathbf{I}-\theta\mathbf{W}\mathbf{K}^{-1}\mathbf{W}^\mathsf{T}$（$\mathbf{W}=[\mathbf{S},\mathbf{Y}]$）の $2m\times2m$ 係数行列の LU 分解から求める。
減衰させる対と、係数空間の計算が決まらない対では、正規化した $n$ 次元の列を作り直して評価する。
減衰で $\mathbf{s}_k^\mathsf{T}\mathbf{y}_k>0$ が保たれるので、$\mathbf{H}_k$ は正定値のまま更新される。

この方式は古典的な BLNZ（Byrd–Lu–Nocedal–Zhu）の L-BFGS-B が計算する一般化 Cauchy 点や自由部分空間のコンパクトな線形系を使わない。
古典的アルゴリズムの説明を、この実装の一反復の手順として読み替えない。
両者の違いは[古典的な L-BFGS-B との違い](oxref:optimize-lbfgsb-vs-classical)で比べる。

## 問題と作業領域

目的と境界を `BoundedObjective` にまとめ、`LbfgsBOptions` で履歴長と許容誤差を設定する。
開始点は箱の中になければならず、外にあれば `InvalidInput` のエラーになる。
開始点の長さが次元と違えば `DimensionMismatch`、開始点か開始点での目的・勾配が NaN や無限大なら `NonFinite` になる。
`LbfgsBOptions` の既定は次のとおりである。

| 設定 | 既定 | 意味 |
|---|---|---|
| `with_memory` | 10 対 | 保持する差分対 $(\mathbf{s}_i,\mathbf{y}_i)$ の数 $m$ |
| `with_max_iterations` | 1000 回 | 外側の反復の上限（到達すると `IterationLimit`） |
| `with_gradient_tolerance` | $\sqrt{\varepsilon_{\mathrm{mach}}}$（絶対・相対） | 射影勾配の停止判定 |
| `with_curvature_policy` | Powell 減衰、$\eta=0.2$ | 曲率が足りない対の扱い |
| `with_derivative_strategy` | `AnalyticOrForward`（解析的な勾配がなければ前進差分） | 勾配の取得方法（数値微分は箱の中で評価する） |
| `with_time_limit` | なし | 処理の区切りで確認する時間上限 |

直線探索は Armijo 後退に固定され、設定で強 Wolfe 条件へ替えることはできない。

終了理由は `OptimizeTermination` で返る。
`GradientSmall` だけが成功で、射影勾配の判定を満たしたことを表す。
`IterationLimit`、時間上限、`Stagnation` では最後に受理した点が推定値として返る。
`LineSearchFailed` は、その反復で受理できる刻みがなかったことを表す。

`LbfgsBWorkspaceRequirements` は必要容量、`LbfgsBWorkspace` は反復のメモリを表す。
`LbfgsB::workspace(n)` で作った作業領域を `minimize_into` に渡せば、同じ大きさの問題を解き直すときにメモリを確保し直さない。
変数数 $n$、履歴長 $m$ に対するメモリ使用量は $O(nm+m^2)$ である。
一反復のベクトル演算は $O(nm)$、係数空間での曲率評価は $O(m^3)$、例外的な再評価は $O(nm^2)$ の計算量を要する。
履歴を増やす効果と、メモリと曲率評価の負担を併せて考える。

ワンショット関数 `minimize_bounded(f, &x0, &bounds)` は、目的のクロージャと `scioxide_core::Bounds` から `BoundedObjective` を作り、既定の設定の `LbfgsB` で解く。
勾配は前進差分で求め、成功しない終了は `Err` で返す。

変数を尺度変換すると、境界と勾配の尺度も変わる。
目的値の小ささだけでなく、どの座標の射影勾配に許容誤差を適用したかを明示する。

## 境界に達する二次関数

$f(x)=\tfrac12[(x_0-a)^2+(x_1+1)^2]$ を $0\le x_i\le1$ で最小化する。
入力は無制約最小点の第一成分 $a$ で、開始点は $(0.5, 0.5)$ である。
出力は各成分の解、元の勾配、射影勾配、境界の状態、解析解との差の表と、終了理由・反復・評価回数の表である。
独立な解析解は $(\min(1,\max(0,a)),0)$ となる。
最後に、終了理由を計算の判定として示す。

```rust
//| id: optimize-lbfgsb-active-set
//| ref: optimize-lbfgsb-active-set
//| title: 箱の内部と境界で勾配の符号を比べる
//| run: reactive
//| crates: [scioxide-core, scioxide-optimize]
//| inputs:
//|   target: {"type":"range","label":"無制約最小点 a [-]","min":-1,"max":2,"step":0.25,"value":1.5}
//| cases:
//|   - {"id":"interior","label":"a = 0.5（内部）","description":"第一成分は内部の x₀ = 0.5 で勾配 0、第二成分だけが下限に残る。","inputs":{"target":0.5}}
//|   - {"id":"lower","label":"a = −1（下限）","description":"両成分が下限 0 にあり、元の勾配はともに +1 だが射影勾配は 0 になる。","inputs":{"target":-1}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"components","path":"/rows/0/1","approx":{"value":1.0,"atol":1e-12}}
//|       - {"artifact":"components","path":"/rows/0/2","approx":{"value":-0.5,"atol":1e-12}}
//|       - {"artifact":"components","path":"/rows/0/4","equals":"上限"}
//|       - {"artifact":"components","path":"/rows/1/4","equals":"下限"}
//|       - {"artifact":"components","path":"/rows/0/5","range":{"min":0,"max":1e-12}}
//|       - {"artifact":"components","path":"/rows/1/5","range":{"min":0,"max":1e-12}}
//|       - {"artifact":"summary","path":"/rows/0/0","equals":"GradientSmall"}
//|       - {"artifact":"summary","path":"/rows/0/1","equals":1}
//|       - {"path":"/outputs/2/state","equals":"satisfied"}
//|   - case: interior
//|     expect:
//|       - {"artifact":"components","path":"/rows/0/1","approx":{"value":0.5,"atol":1e-8}}
//|       - {"artifact":"components","path":"/rows/0/4","equals":"内部"}
//|       - {"artifact":"components","path":"/rows/0/3","range":{"min":-1e-8,"max":1e-8}}
//|       - {"path":"/outputs/2/state","equals":"satisfied"}
//|   - case: lower
//|     expect:
//|       - {"artifact":"components","path":"/rows/0/1","approx":{"value":0.0,"atol":1e-12}}
//|       - {"artifact":"components","path":"/rows/0/2","approx":{"value":1.0,"atol":1e-12}}
//|       - {"artifact":"components","path":"/rows/0/4","equals":"下限"}
//|       - {"path":"/outputs/2/state","equals":"satisfied"}
use scioxide_core::Bounds;
use scioxide_optimize::{BoundedObjective, LbfgsB, ObjectiveFn, OptimizeTermination};

let a = target;
let f = ObjectiveFn::new(2, move |x: &[f64]| {
    Ok(0.5 * ((x[0] - a) * (x[0] - a) + (x[1] + 1.0) * (x[1] + 1.0)))
})
.with_gradient(move |x: &[f64], g: &mut [f64]| {
    g.copy_from_slice(&[x[0] - a, x[1] + 1.0]);
    Ok(())
});
let bounds = Bounds::new(vec![(Some(0.0), Some(1.0)); 2]).map_err(|e| e.to_string())?;
let problem = BoundedObjective::new(&f, &bounds).map_err(|e| e.to_string())?;
let result = LbfgsB::default()
    .minimize(&problem, &[0.5, 0.5])
    .map_err(|e| e.to_string())?;
let x = result.x();
// 独立検算: 分離した二つの放物線の頂点を区間 [0, 1] に射影する。
let exact = [a.clamp(0.0, 1.0), 0.0];
let gradient = [x[0] - a, x[1] + 1.0];
let mut rows = Vec::new();
for i in 0..2 {
    // 下限で g ≥ 0、上限で g ≤ 0 の成分は射影勾配では 0 になる。
    let (state, projected) = if x[i] == 0.0 && gradient[i] >= 0.0 {
        ("下限", 0.0)
    } else if x[i] == 1.0 && gradient[i] <= 0.0 {
        ("上限", 0.0)
    } else {
        ("内部", gradient[i])
    };
    rows.push((
        i,
        x[i],
        gradient[i],
        projected,
        state,
        (x[i] - exact[i]).abs(),
    ));
}
let general = serde_json::json!({ "significantDigits": 6 });
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let columns = serde_json::json!([
    { "key": "0", "label": "成分 i", "type": "integer" },
    { "key": "1", "label": "解 xᵢ [-]", "type": "number", "format": general },
    { "key": "2", "label": "元の勾配 gᵢ [-]", "type": "number", "format": general },
    { "key": "3", "label": "射影勾配 (Pg)ᵢ [-]", "type": "number", "format": general },
    { "key": "4", "label": "状態" },
    { "key": "5", "label": "解析解との差 [-]", "type": "number", "format": sci3 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "components" })
);
let summary_columns = serde_json::json!([
    { "key": "0", "label": "終了理由" },
    { "key": "1", "label": "反復 [回]", "type": "integer" },
    { "key": "2", "label": "目的の評価 [回]", "type": "integer" }
]);
let termination = result.termination();
emit_table_with_columns!(
    summary_columns,
    vec![(
        termination.to_string(),
        result.iterations(),
        result.fun_evals()
    )],
    metadata = serde_json::json!({ "id": "summary" })
);
let outcome = if termination.is_success() {
    Outcome::satisfied("射影勾配が停止の閾値を下回った")
} else if matches!(termination, OptimizeTermination::LineSearchFailed(_)) {
    Outcome::failed("直線探索が受理できる刻みを見つけられなかった")
} else {
    Outcome::partial("射影勾配の判定を満たす前に止まった")
};
emit_outcome!(
    outcome
        .status(termination.to_string())
        .diagnostic("反復", result.iterations() as f64, None)
        .diagnostic("目的の評価", result.fun_evals() as f64, None)
);
```

$a=1.5$ では第一成分が上限、第二成分が下限にあり、元の勾配は $(-0.5, 1)$ だが射影勾配は $(0,0)$ で、1 反復（目的の評価 2 回）で `GradientSmall` になる。
開始点 $(0.5,0.5)$ での勾配は $(-1,1.5)$ なので、最初の方向 $-\mathbf{g}=(1,-1.5)$ の終点 $(1.5,-1)$ を箱へ射影すると $(1,0)$ がそのまま解になるからである。
$a=0.5$ では第一成分が内部に入り、その勾配が 0 になる。
$a=-1$ では両成分が下限にあり、元の勾配はともに $+1$ だが、許される増加方向では目的が増えるので射影勾配は 0 である。
元の勾配の大きさは $a$ によって 1 程度のまま残るので、無制約の勾配ノルムで停止を判定すると、どの場合も成功と判定できない。

## まとめ

ボックス制約の最適点では、内部で $g_i=0$、下限で $g_i\ge0$、上限で $g_i\le0$ となり、これは射影勾配 $\mathbf{P}\mathbf{g}=\mathbf{0}$ とまとめて書ける。
`LbfgsB` は $\|\mathbf{P}\mathbf{g}\|_\infty$ が $\sqrt{\varepsilon_{\mathrm{mach}}}$ を基にした閾値を下回ったときだけ `GradientSmall` を返し、元の勾配の大きさや刻みの小ささでは成功としない。
各反復は射影勾配に逆 L-BFGS モデルを掛け、単位ステップ幅の終点を箱へ射影した線分上で Armijo 条件により刻みを選ぶので、試行点は常に箱の中にある。
方向は $-\mathbf{P}_F\mathbf{H}_k\mathbf{P}_F\mathbf{g}$ で、$\mathbf{H}_k$ が正定値なら降下方向になり、数値的な破綻か降下性の喪失のときだけ履歴を捨てて射影最急降下に戻る。
結果は終了理由、射影勾配、境界の状態を合わせて読み、`IterationLimit` や `Stagnation` の点は推定値として扱う。
