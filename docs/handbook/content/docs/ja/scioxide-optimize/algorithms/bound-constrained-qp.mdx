制約が変数の上下限 $\mathbf{l}\le\mathbf{x}\le\mathbf{u}$ だけの凸二次計画は、非負最小二乗や箱で制限した回帰の部分問題として現れる。
この形では実行可能領域への射影が成分ごとに計算できるので、行列を分解しない方法が使える。
このページでは射影勾配法と Barzilai–Borwein（BB）刻みを導き、`QpMethod::Automatic` の実装と、有効集合法との違いを説明する。
KKT 条件、有効集合法、凸性の検査は[凸二次計画と KKT 系](../quadratic-programming/)にある。

## 射影勾配と Barzilai–Borwein 刻み

箱 $\{\mathbf{x}:\mathbf{l}\le\mathbf{x}\le\mathbf{u}\}$ への射影は

$$
P(\mathbf{x})=\min(\max(\mathbf{x},\mathbf{l}),\mathbf{u})
$$

で、成分ごとに計算できる（境界のない成分はそのまま残す）。
射影勾配法は

$$
\mathbf{x}_{k+1}=P\big(\mathbf{x}_k-\alpha_k\nabla f(\mathbf{x}_k)\big)
$$

で反復し、行列の分解を必要としない。
凸な $f$ では、ある $\alpha>0$ で $\mathbf{x}^*=P(\mathbf{x}^*-\alpha\nabla f(\mathbf{x}^*))$ が成り立つことと、$\mathbf{x}^*$ が最小点であることは同値である。
成分ごとに書くと、内点の成分では $\partial_j f=0$、下限にある成分では $\partial_j f\ge0$、上限にある成分では $\partial_j f\le0$ で、これは上下限の KKT 条件そのものである。
この条件の破れは境界にあって外側を向く成分を 0 にした勾配のノルム（射影勾配のノルム）で測る。

ステップ幅は Barzilai–Borwein の式

$$
\alpha_{k+1}=\frac{\mathbf{s}_k^\mathsf{T}\mathbf{s}_k}{\mathbf{s}_k^\mathsf{T}\mathbf{y}_k},\qquad \mathbf{s}_k=\mathbf{x}_{k+1}-\mathbf{x}_k,\quad \mathbf{y}_k=\nabla f(\mathbf{x}_{k+1})-\nabla f(\mathbf{x}_k)=\mathbf{Q}\mathbf{s}_k
$$

で決める（Barzilai and Borwein, 1988）。
これはスカラー行列 $\alpha^{-1}\mathbf{I}$ が割線条件 $\alpha^{-1}\mathbf{s}_k\approx\mathbf{y}_k$ を最小二乗の意味で満たすように選んだもので、$\alpha^{-1}=\mathbf{s}_k^\mathsf{T}\mathbf{Q}\mathbf{s}_k/\mathbf{s}_k^\mathsf{T}\mathbf{s}_k$ は $\mathbf{Q}$ の Rayleigh 商として最大と最小の固有値の間に入る。
曲率の情報を一つのスカラーで取り込むので、固定のステップ幅の勾配法より少ない反復で進むことが多いが、純粋な BB の刻みでは目的が単調に減るとは限らない。
1 反復の計算は $\mathbf{Q}\mathbf{x}$ の積で、密な $\mathbf{Q}$ なら $O(n^2)$ である。
$\mathbf{Q}$ の条件数が大きいと反復回数が増える。

## Automatic の射影 BB 法

`QpMethod::Automatic` は、一般の行制約がなく変数の上下限だけを持つ問題にこの方法を使う。

- 初期点は `QpWarmStart` の点か、0 を上下限へ射影した点である。
- 初期のステップ幅は $1/\max_iQ_{ii}$ とする。
- 試した点の目的が前の点より大きければ、ステップ幅を半分にして射影し直す（最大 64 回）。
  64 回で下がらなければ、前の点を返して `Stagnation` で止まる。
  この後退により、実装の反復では目的が増えない。
- $\mathbf{s}_k$ と $\mathbf{y}_k$ を正規化した内積（なす角の余弦）が $\sqrt{\epsilon}$ 以下なら BB の更新を見送り、前のステップ幅を使う。
- 射影勾配のノルムが勾配の許容誤差以下になったら、元の問題の KKT 証明用データを作って検査する。
  検査を通れば `Converged` で止まる。
  通らない場合は反復を続け、点が動かなくなっていれば `Stagnation` で止まる。
- 反復上限（既定 1000 回）に達すると `IterationLimit` で、最後の点と証明用データを返す。

`QpMethod::ActiveSet` を指定すると、同じ問題を有効集合法で解く。
有効集合法は能動な座標を消去した Cholesky 分解を更新し、境界にある成分を厳密に境界の値にする。
どちらの方式でも、求解の前に $\mathbf{Q}$ が半正定値かを確かめ、そうでなければ `InvalidInput` で拒否する。

## 射影 BB 法と有効集合法の比較

変数の上下限だけを持つ QP を、`Automatic`（射影 BB 法）と `ActiveSet` で解く。
目的は $\tfrac12\mathbf{x}^\mathsf{T}\begin{bmatrix}2&q\\q&2\end{bmatrix}\mathbf{x}-4x_1+x_2$、箱は $0\le x_i\le1$ で、$\mathbf{Q}$ の固有値は $2\pm q$ である。
$|q|\le2$ では $x_1=1$ のとき $\partial_1f=qx_2-2\le0$ なので $x_1$ は上限 1 に止まり、$x_2$ は $\partial_2f=q+2x_2+1=0$ の解を $[0,1]$ に射影した値 $\max(0,-(q+1)/2)$ になる。
$|q|>2$ では $\mathbf{Q}$ が不定値になり、ソルバーは解かずに拒否する。
入力は非対角成分 $q$ で、表は終了理由（拒否の場合はエラーの分類）、解、解析解との差、反復回数を示す。

```rust
//| id: optimize-qp-projected-bb
//| ref: optimize-qp-projected-bb
//| title: ボックス制約だけの QP を射影 BB 法と有効集合法で解き、非凸な Q を拒否する
//| run: reactive
//| crates: [scioxide-core, scioxide-linalg, scioxide-optimize]
//| inputs:
//|   coupling: {"type":"range","label":"Q の非対角成分 q [-]","description":"|q| > 2 で Q は不定値になる。","min":-3,"max":3,"step":0.5,"value":1}
//| cases:
//|   - {"id":"interior-second","label":"q = −1.5","description":"x₂ の下限が外れ、解は (1, 0.25) になる。両方式とも解析解に一致する。","inputs":{"coupling":-1.5}}
//|   - {"id":"singular","label":"q = 2（半正定値）","description":"最小固有値が 0 の Q も受け付け、解は (1, 0) になる。","inputs":{"coupling":2}}
//|   - {"id":"indefinite","label":"q = 2.5（不定値）","description":"最小固有値 −0.5 の Q をソルバーが InvalidInput で拒否し、表には拒否の分類が出る。","inputs":{"coupling":2.5}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"methods","path":"/rows/0/1","equals":"Converged"}
//|       - {"artifact":"methods","path":"/rows/1/1","equals":"Converged"}
//|       - {"artifact":"methods","path":"/rows/0/4","range":{"min":0,"max":1e-8}}
//|       - {"artifact":"methods","path":"/rows/1/4","range":{"min":0,"max":1e-12}}
//|   - case: interior-second
//|     expect:
//|       - {"artifact":"methods","path":"/rows/0/3","approx":{"value":0.25,"atol":1e-8}}
//|       - {"artifact":"methods","path":"/rows/1/3","approx":{"value":0.25,"atol":1e-12}}
//|   - case: singular
//|     expect:
//|       - {"artifact":"methods","path":"/rows/0/1","equals":"Converged"}
//|       - {"artifact":"methods","path":"/rows/1/4","range":{"min":0,"max":1e-8}}
//|   - case: indefinite
//|     expect:
//|       - {"artifact":"methods","path":"/rows/0/1","equals":"InvalidInput"}
//|       - {"artifact":"methods","path":"/rows/1/1","equals":"InvalidInput"}
//|       - {"artifact":"methods","path":"/rows/0/2","equals":null}
use scioxide_core::Bounds;
use scioxide_linalg::Matrix;
use scioxide_optimize::{QpMethod, QpProblem, QpSolver};
let general = serde_json::json!({ "significantDigits": 6 });
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
// 目的 ½ xᵀ [[2, q], [q, 2]] x + (−4, 1)ᵀ x、箱 0 ≤ x ≤ 1。Q の固有値は 2 ± q。
let q = coupling;
let h = Matrix::from_vec(2, 2, vec![2.0_f64, q, q, 2.0]).map_err(|e| e.to_string())?;
let bounds = Bounds::new(vec![(Some(0.0), Some(1.0)); 2]).map_err(|e| e.to_string())?;
let p = QpProblem::new(h, vec![-4.0, 1.0])
    .and_then(|p| p.with_bounds(bounds))
    .map_err(|e| e.to_string())?;
// 独立な解析解（|q| ≤ 2）: x₁ は上限 1、x₂ は勾配 q + 2x₂ + 1 = 0 を [0, 1] に射影した値。
let analytic = [1.0, (-(q + 1.0) / 2.0).clamp(0.0, 1.0)];
let mut rows = Vec::new();
for (name, method) in [
    ("Automatic（射影 BB）", QpMethod::Automatic),
    ("ActiveSet", QpMethod::ActiveSet),
] {
    match QpSolver::default().with_method(method).solve(&p) {
        Ok(r) => {
            let x = r.x();
            rows.push((
                name,
                r.termination().to_string(),
                Some(x[0]),
                Some(x[1]),
                Some((x[0] - analytic[0]).abs().max((x[1] - analytic[1]).abs())),
                Some(r.iterations()),
            ));
        }
        // 非凸な Q は解かずに拒否される。分類を表に残す。
        Err(e) => rows.push((name, format!("{:?}", e.kind()), None, None, None, None)),
    }
}
let columns = serde_json::json!([
    { "key": "0", "label": "方式" },
    { "key": "1", "label": "終了理由または拒否の分類" },
    { "key": "2", "label": "x₁ [-]", "type": "number", "format": general, "nullText": "なし" },
    { "key": "3", "label": "x₂ [-]", "type": "number", "format": general, "nullText": "なし" },
    { "key": "4", "label": "解析解との差 [-]", "type": "number", "format": sci2, "nullText": "なし" },
    { "key": "5", "label": "反復 [回]", "type": "integer", "nullText": "なし" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "methods" })
);
```

既定の $q=1$ では解は $(1,0)$ で、両方式とも `Converged` になり、解析解に丸め誤差なしで一致する。
$q=-1.5$ では $x_2$ の下限が外れて、解は $(1,0.25)$ になる。
$q=2$ では $\mathbf{Q}$ の最小固有値が 0 の半正定値になるが、両方式とも受け付けて $(1,0)$ を返す。
$|q|\ge2.5$ では最小固有値が負になり、両方式とも `InvalidInput` で拒否されて、点も反復回数も返らない。
この小さい例では射影 BB 法が 1〜2 反復、有効集合法が 3〜5 反復で止まる。
1 反復の計算コストと反復の数え方は方式ごとに違うので、回数だけで速さを比べない。

## まとめ

ボックス制約だけの凸 QP では、射影が成分ごとに計算できるので、射影勾配法は行列を分解せずに $\mathbf{Q}\mathbf{x}$ の積だけで進む。
最適性は射影勾配が 0 になることで判定でき、これは上下限の KKT 条件と同値である。
BB の刻みは $\mathbf{Q}$ の Rayleigh 商からステップ幅を決め、`Automatic` の実装はステップ幅を半分にする後退で目的を増やさず、最後に元の問題の KKT 証明用データを検査してから `Converged` を返す。
境界にある成分を厳密に境界の値にしたいときや、$\mathbf{Q}$ の条件数が大きく反復が増えるときは、`QpMethod::ActiveSet` を指定できる。
どちらの方式も半正定値でない $\mathbf{Q}$ を `InvalidInput` で拒否する。
