CMA-ES（covariance matrix adaptation evolution strategy、Hansen と Ostermeier 2001）は、多変量正規分布から候補を引き、良い候補の変位から分布の平均、共分散、全体の尺度を更新する大域探索法である。
分布の更新は目的値の順位だけを使うので、目的を狭義単調増加の関数で変換しても分布の更新は変わらない（停止の判定は目的値の広がりを使うので変わりうる）。
変数間に強い相関がある連続な黒箱関数で、伸びて回転した谷の向きを探索分布が学ぶ。
このページでは CMA-ES の一世代の更新式を導き、SciOxide の `CmaEs` の設定、停止、再開始を説明し、回転した楕円の谷で共分散が条件数を学ぶ様子を確かめる。
`CmaEs` は大域最適性を主張せず、その終了はどれも成功ではない。

## CMA-ES の共分散更新

SciOxide の実装は箱を単位箱 $[0, 1]^d$ へ正規化した座標で動く。
探索分布は平均 $m$、全体の尺度（ステップ幅）$\sigma$、共分散 $C$ の正規分布 $N(m, \sigma^2 C)$ である。
各世代で $\lambda$ 個の子

$$
x_i = m + \sigma y_i, \qquad y_i \sim N(0, C), \qquad i = 1, \dots, \lambda
$$

を作る。
$C = B D^2 B^T$ の固有分解を使い、標準正規の乱数 $z_i$ から $y_i = B D z_i$ とする。
単位箱の外へ出た座標は端で折り返し、折り返した点から $y_i$ を計算し直す。

子を目的値の良い順に並べ、$i$ 番目に良い子の変位を $y_{i:\lambda}$ とする。
上位 $\mu = \lfloor \lambda/2 \rfloor$ 個に、$\ln(\mu + \frac12) - \ln i$ に比例して和が 1 の正の重み $w_i$ を付け、

$$
\langle y \rangle_w = \sum_{i=1}^{\mu} w_i y_{i:\lambda}, \qquad \mu_{\mathrm{eff}} = \frac{1}{\sum_i w_i^2}
$$

とする。
$\mu_{\mathrm{eff}}$ は有効な選択数で、重みが均等なら $\mu$ に等しい。
更新は

$$
\begin{aligned}
m &\leftarrow m + \sigma \langle y \rangle_w, \\
p_\sigma &\leftarrow (1 - c_\sigma) p_\sigma + \sqrt{c_\sigma (2 - c_\sigma) \mu_{\mathrm{eff}}}\, C^{-1/2} \langle y \rangle_w, \\
p_c &\leftarrow (1 - c_c) p_c + h_\sigma \sqrt{c_c (2 - c_c) \mu_{\mathrm{eff}}}\, \langle y \rangle_w, \\
C &\leftarrow (1 - c_1 - c_\mu) C + c_1 p_c p_c^T + c_\mu \textstyle\sum_i w_i y_{i:\lambda} y_{i:\lambda}^T, \\
\sigma &\leftarrow \sigma \exp\!\Bigl(\frac{c_\sigma}{d_\sigma}\Bigl(\frac{\|p_\sigma\|}{\mathrm{E}\|N(0, I)\|} - 1\Bigr)\Bigr)
\end{aligned}
$$

である。
$p_\sigma$ と $p_c$ は進化経路（evolution path）と呼ぶ、平均の移動の指数移動平均である。
$C$ の更新の第 2 項は $p_c$ による階数 1 の更新、第 3 項は選んだ変位による階数 $\mu$ の更新である。
$h_\sigma$ は $\|p_\sigma\|/\sqrt{1 - (1 - c_\sigma)^{2g}}$（$g$ は世代数）が $(1.4 + 2/(d + 1))\,\mathrm{E}\|N(0, I)\|$ を下回るとき 1、そうでなければ 0 で、0 のときは $C$ の係数に $c_1 c_c (2 - c_c)$ を足す。
平均は更新後に単位箱の中へ切り詰める。

係数は Hansen の解説（2016）の標準の値で、次元 $d$ と $\mu_{\mathrm{eff}}$ から

$$
\begin{gathered}
c_\sigma = \frac{\mu_{\mathrm{eff}} + 2}{d + \mu_{\mathrm{eff}} + 5}, \qquad
d_\sigma = 1 + 2\max\Bigl(0, \sqrt{\tfrac{\mu_{\mathrm{eff}} - 1}{d + 1}} - 1\Bigr) + c_\sigma, \qquad
c_c = \frac{4 + \mu_{\mathrm{eff}}/d}{d + 4 + 2\mu_{\mathrm{eff}}/d}, \\
c_1 = \frac{2}{(d + 1.3)^2 + \mu_{\mathrm{eff}}}, \qquad
c_\mu = \min\Bigl(1 - c_1, \frac{2(\mu_{\mathrm{eff}} - 2 + 1/\mu_{\mathrm{eff}})}{(d + 2)^2 + \mu_{\mathrm{eff}}}\Bigr)
\end{gathered}
$$

と決まる。
$\mathrm{E}\|N(0, I)\| \approx \sqrt{d}\,(1 - \frac{1}{4d} + \frac{1}{21 d^2})$ は $d$ 次元標準正規ベクトルの長さの期待値である。

ステップ幅の更新は累積ステップ幅適応（cumulative step-size adaptation）と呼ぶ。
$C^{-1/2}$ で白色化した進化経路 $p_\sigma$ は、選択が無作為なら標準正規ベクトルと同じ長さの分布を持つ。
経路がこれより長ければ同じ方向へ進み続けているので $\sigma$ を大きくし、短ければ行き来しているので小さくする。
凸二次関数 $f(x) = \frac12 (x - x^\star)^T H (x - x^\star)$ では、$C$ はヘッセ行列の逆 $H^{-1}$ に比例する形に近づくことが知られている。
これは $C$ が良い変位の分布を学んだ結果であり、目的のヘッセ行列を直接推定しているわけではない。

一世代の計算コストは目的の評価 $\lambda$ 回、$C$ の密な固有分解の $O(d^3)$、標本化の $O(\lambda d^2)$ で、共分散の保存に $O(d^2)$ のメモリを使う。

## 停止と再開始

一回の探索（run）は次のどれかで終わる。
最初の二つは各世代の更新の後に、三つ目は次の世代の始めの $C$ の固有分解で判定する。

- 世代の目的値の広がり $f_{\max} - f_{\min}$ が `ResidualTolerance` の許容誤差（既定は絶対・相対とも $\sqrt{\varepsilon}$、尺度は $\max(|f_{\min}|, |f_{\max}|)$）以下になる。
- 実効的なステップ幅 $\sigma \sqrt{\lambda_{\max}(C)}$ が `StepTolerance` の許容誤差（正規化した箱の単位で尺度は 1、既定は絶対・相対とも $\sqrt{\varepsilon}$）以下になる。
- $C$ の数値的な階数が $d$ を下回るか、$\sigma$ が 0 になる。

`CmaEsRestartPolicy::IncreasingPopulation { max_restarts }` を選ぶと、探索が終わるたびに子の数を倍にして、開始点の設計の点から最大 `max_restarts` 回まで再開始する（IPOP-CMA-ES、Auger と Hansen 2005）。
最初の探索は `x0` から始め、$k$ 回目の再開始は設計の $k - 1$ 番目の点から始める。
設計の既定は一様乱数の `UniformStartDesign` で、`CmaEs::with_design` で替えられる。
各探索は開始点を 1 回評価してから世代を始める。

最後の探索が終わると `PopulationStagnation`、全ての探索を通した世代の上限に達すると `SearchBudgetCompleted` で止まり、どちらも成功ではない。
評価回数の上限、取り消し、期限で最初の評価の後に止まった場合も、それまでの最良点が結果に入る。
`CmaEs::with_local` で局所ソルバーの factory を与えると、最後に最良点を局所最適化し、値が下がったときだけ置き換える。
局所最適化が失敗しても探索は失敗せず、そのエラーは `CmaEsWorkspace::local_error()` で読める。

## CmaEs の設定と診断

`CmaEsOptions::default()` は、初期のステップ幅 0.3（正規化した箱の単位）、子の数 $4 + \lfloor 3 \ln d \rfloor$、全ての再開始を通した世代の上限 1000、再開始なし、シード 42、局所最適化の上限なし、逐次実行である。
`with_initial_step`、`with_population_size`、`with_max_generations`、`with_fitness_tolerance`、`with_step_tolerance`、`with_restart`、`with_seed`、`with_local_budgets`、`with_execution` で変える。
`CmaEs::new(options)` は、初期のステップ幅が NaN、無限大、0 以下のときと、子の数が 4 より少ないときに `InvalidInput` を返す。
逐次でない実行方針では子の評価を並列にし、問題を `BoundedObjective::new_sync` で作る必要がある。
子は添字の順に作って順位を付けるので、決定論的な目的なら結果はワーカーの数に依存しない。

`workspace(dimension)` が、最大の再開始の集団に合わせた `CmaEsWorkspace` を用意し、必要量は `CmaEsWorkspaceRequirements` で分かる。
`minimize_into(problem, x0, output, workspace, scope)` と `minimize(problem, x0)` が解く。
`x0` の長さが違えば `DimensionMismatch`、NaN か無限大を含むか目的が NaN か無限大を返せば `NonFinite`、箱の外なら `InvalidInput`、標本かステップ幅が桁あふれすれば `NumericalInstability` である。

`CmaEsWorkspace::generations()` は完了した世代ごとの `CmaEsGeneration` を返す。
各世代のレポートは世代番号 `generation()`（再開始を通した通し番号）、探索の番号 `restart()`、世代の最良と最悪の目的値、世代の始めの $C$ の数値的な階数 `covariance_rank()` と正の固有値の比の対数 $\ln(\lambda_{\max}/\lambda_{\min})$ の `covariance_log_condition()`、更新後の $\sigma$ の `step_size()`、折り返した座標の数 `repaired_coordinates()` を持つ。
`restarts()` は再開始の回数を返す。
集団が縮んだことは探索の進行を表すが、大域的最小点へ到達した証明ではない。

## 伸びた谷での共分散の学習

CMA-ES が谷の向きと伸びを学ぶ様子を、回転した楕円の二次関数で調べる。
目的は $f(x) = u^2 + \kappa v^2$ で、$(u, v)$ は $x - x^\star$ を角度 $\theta$ だけ回した座標、$x^\star = (0.2, -0.1)$、箱は $[-1, 1]^2$ である。
ヘッセ行列の条件数は $\kappa$ なので、$C$ が $H^{-1}$ の形を学べば、その固有値の比の対数 $\ln(\lambda_{\max}/\lambda_{\min})$ は $\ln \kappa$ に近づく。
正規化した座標は箱の幅 2 で一様に縮めた座標なので、固有値の比は変わらない。
入力は $\log_{10} \kappa$、回転角 $\theta$、乱数のシードである。
出力は世代ごとの最良の目的値と $C$ の固有値の比の対数の図（横軸は連動する）、最終点の誤差と評価回数と最後の世代の固有値比の対数の表、判定である。
$\ln \kappa$ は基準の線で示す。

```rust
//| id: optimize-cma-es-ellipsoid
//| ref: optimize-cma-es-ellipsoid
//| title: CMA-ES の共分散が楕円の谷の条件数を学ぶ様子を見る
//| run: reactive
//| crates: [scioxide-core, scioxide-optimize]
//| inputs:
//|   condition_exponent: {"type":"range","label":"条件数 log₁₀κ [-]","min":0,"max":4,"step":0.5,"value":3}
//|   angle: {"type":"range","label":"回転角 θ [度]","min":0,"max":90,"step":15,"value":30}
//|   seed: {"type":"range","label":"乱数のシード [-]","min":1,"max":100,"step":1,"value":42}
//| cases:
//|   - {"id":"isotropic","label":"κ = 1（等方）","description":"谷は円で、48 世代 289 回の評価で止まる。C の固有値の比の対数は 1.05 で、ln κ = 0 からの差は、毎世代 3 個の選んだ変位で C を更新することによる揺らぎである。","inputs":{"condition_exponent":0}}
//|   - {"id":"steep-valley","label":"κ = 10⁴","description":"93 世代 559 回の評価で止まり、C の固有値の比の対数は 8.72 で ln κ = 9.21 に近づく。","inputs":{"condition_exponent":4}}
//|   - {"id":"seed-100","label":"シード 100","description":"同じ κ = 10³ でも 81 世代 487 回の評価で止まり、最後の比の対数は 7.40 と ln κ = 6.91 を上回る。","inputs":{"seed":100}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"cma","path":"/rows/0/0","equals":"PopulationStagnation"}
//|       - {"artifact":"cma","path":"/rows/0/1","range":{"min":50,"max":85}}
//|       - {"artifact":"cma","path":"/rows/0/3","range":{"min":0,"max":2e-8}}
//|       - {"artifact":"cma","path":"/rows/0/4","range":{"min":0,"max":1e-4}}
//|       - {"artifact":"cma","path":"/rows/0/5","range":{"min":5.5,"max":7.6}}
//|       - {"artifact":"cma","path":"/rows/0/6","approx":{"value":6.907755,"atol":1e-6}}
//|       - {"path":"/outputs/3/state","equals":"partial"}
//|   - case: isotropic
//|     expect:
//|       - {"artifact":"cma","path":"/rows/0/3","range":{"min":0,"max":2e-8}}
//|       - {"artifact":"cma","path":"/rows/0/5","range":{"min":0,"max":2}}
//|   - case: steep-valley
//|     expect:
//|       - {"artifact":"cma","path":"/rows/0/3","range":{"min":0,"max":2e-8}}
//|       - {"artifact":"cma","path":"/rows/0/5","range":{"min":7.5,"max":10}}
//|   - case: seed-100
//|     expect:
//|       - {"artifact":"cma","path":"/rows/0/3","range":{"min":0,"max":2e-8}}
//|       - {"artifact":"cma","path":"/rows/0/5","range":{"min":5.5,"max":8}}
use scioxide_core::{Bounds, ExecutionContext, RealScalar};
use scioxide_optimize::{BoundedObjective, CmaEs, CmaEsOptions, ObjectiveFn, OptimizeResult};

let kappa = RealScalar::powf(10.0, condition_exponent);
let theta = angle * std::f64::consts::PI / 180.0;
let (cos, sin) = (RealScalar::cos(theta), RealScalar::sin(theta));
let center = [0.2, -0.1];
// f = u² + κ v²、(u, v) は x − x* を θ だけ回した座標。
let ellipsoid = ObjectiveFn::new(2, |x: &[f64]| {
    let (dx, dy) = (x[0] - center[0], x[1] - center[1]);
    let u = cos * dx + sin * dy;
    let v = -sin * dx + cos * dy;
    Ok(u * u + kappa * v * v)
});
let bounds = Bounds::new(vec![(Some(-1.0), Some(1.0)); 2]).map_err(|e| e.to_string())?;
let problem = BoundedObjective::new(&ellipsoid, &bounds).map_err(|e| e.to_string())?;
let solver = CmaEs::new(CmaEsOptions::default().with_seed(seed.round() as u64))
    .map_err(|e| e.to_string())?;
let mut workspace = solver.workspace(2).map_err(|e| e.to_string())?;
let mut output = OptimizeResult::empty();
solver
    .minimize_into(
        &problem,
        &[-0.8, 0.8],
        &mut output,
        &mut workspace,
        ExecutionContext::sequential(),
    )
    .map_err(|e| e.to_string())?;
let generations = workspace.generations();
// 最良値が 0 以下の世代は対数軸に描けないので除き、件数を表に示す。
let best: Vec<[f64; 2]> = generations
    .iter()
    .filter(|g| g.best_fitness() > 0.0)
    .map(|g| [g.generation() as f64, g.best_fitness()])
    .collect();
let condition: Vec<[f64; 2]> = generations
    .iter()
    .map(|g| [g.generation() as f64, g.covariance_log_condition()])
    .collect();
emit_line_chart!(
    &vec![serde_json::json!({ "name": "世代の最良値", "points": best })],
    options = &serde_json::json!({
        "xLabel": "世代 [-]",
        "yLabel": "目的値 [-]",
        "yType": "log",
        "link": { "group": "cma-generation" }
    })
);
let log_kappa = RealScalar::ln(kappa);
emit_line_chart!(
    &vec![serde_json::json!({ "name": "ln(λmax/λmin)", "points": condition })],
    options = &serde_json::json!({
        "xLabel": "世代 [-]",
        "yLabel": "C の固有値の比の対数 [-]",
        "link": { "group": "cma-generation" },
        "annotations": [{ "kind": "line", "axis": "y", "value": log_kappa, "label": "ln κ" }]
    })
);
// 独立な検算: 最終点と既知の最小点 x* の距離。
let x = output.x();
let error = RealScalar::hypot(x[0] - center[0], x[1] - center[1]);
let last = generations.last().map(|g| g.covariance_log_condition());
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let fixed2 = serde_json::json!({ "fractionDigits": 2 });
let na = "なし";
emit_table_with_columns!(
    serde_json::json!([
        { "key": "0", "label": "終了理由" },
        { "key": "1", "label": "世代 [-]", "type": "integer" },
        { "key": "2", "label": "目的の評価 [回]", "type": "integer" },
        { "key": "3", "label": "最終の目的値 [-]", "type": "number", "format": sci3 },
        { "key": "4", "label": "x* までの距離 [-]", "type": "number", "format": sci3 },
        { "key": "5", "label": "固有値比の対数 [-]", "type": "number", "format": fixed2, "nullText": na },
        { "key": "6", "label": "ln κ [-]", "type": "number", "format": fixed2 },
        { "key": "7", "label": "対数軸に描けない世代 [個]", "type": "integer" }
    ]),
    vec![(
        output.termination().to_string(),
        generations.len(),
        output.fun_evals(),
        output.fun(),
        error,
        last,
        log_kappa,
        generations.len() - best.len()
    )],
    metadata = serde_json::json!({ "id": "cma" })
);
emit_outcome!(
    Outcome::partial("集団の目的値の広がりが許容誤差を下回った。最小点に達した証明ではない")
        .status(output.termination().to_string())
        .diagnostic("最終の目的値", output.fun(), None)
        .diagnostic("x* までの距離", error, None)
        .diagnostic("世代", generations.len() as f64, None)
);
```

既定の $\kappa = 10^3$、$\theta = 30°$ では、子の数は $\lambda = 4 + \lfloor 3 \ln 2 \rfloor = 6$ で、65 世代、391 回の評価で `PopulationStagnation` になる。
評価の回数は開始点の 1 回と、65 世代の 6 個ずつの 390 回の和である。
最終の目的値は $9.9 \times 10^{-10}$、$x^\star$ までの距離は $1.2 \times 10^{-6}$ である。
固有値の比の対数は最初の世代の 0 から増えて最後に 6.52 になり、$\ln \kappa = 6.91$ に近い。
目的値の図では、最初の 13 世代ほどで目的値が 550 から 0.1 程度まで下がって谷に入る。
そのあと 25 世代目ごろまでは $C$ の固有値の比の対数が 1 から 4 程度へ伸びるあいだ目的値はほとんど下がらず、そこからは揺らぎながらほぼ一定の傾きで下がる。

$\kappa = 1$ では 48 世代、$\kappa = 10^4$ では 93 世代で止まり、条件数が 1 万倍になっても世代の数は 2 倍程度にとどまる。
$\kappa = 10^4$ の最後の比の対数は 8.72 で、$\ln \kappa = 9.21$ に近づく。
回転角を 0° と 90° にすると世代の数は 79、比の対数は 6.71 と 6.13 で、座標軸に沿わない 30° の谷でも同じ程度に $C$ が谷の向きを学ぶ。
$C$ は毎世代、選んだ 3 個の変位と進化経路だけで少しずつ更新されるので、比の対数は乱数で揺らぐ。
$\kappa = 1$ でも 1.05 になり、シード 100 では 7.40 と $\ln \kappa$ を上回る。
終了理由は集団の目的値の広がりが許容誤差を下回ったことを表し、最小点に達した証明ではない。
最小点に近いことは既知の $x^\star$ までの距離で確かめている。

## まとめ

CMA-ES は正規分布から子を引き、上位の子の重み付き平均へ平均を動かし、進化経路と選んだ変位で共分散を、累積ステップ幅適応で全体の尺度を更新する。
凸二次関数では共分散がヘッセ行列の逆の形を学ぶので、回転して伸びた谷でも世代の数が条件数ほどには増えない。
一回の探索は目的値の広がり、実効的なステップ幅、共分散の階数で終わり、`IncreasingPopulation` を選ぶと子の数を倍にして再開始する。
`PopulationStagnation` と `SearchBudgetCompleted` はどちらも成功ではないので、最終点は既知の性質、`with_local` の局所最適化、別のシードで確かめる。
世代ごとの $C$ の階数、固有値の比、ステップ幅は `CmaEsWorkspace::generations()` から読める。
