$F(x)=f(x)+g(x)$ を最小にする問題を考える。
$f$ は滑らかで、勾配が Lipschitz 連続（$\|\nabla f(x)-\nabla f(z)\|\le L_f\|x-z\|$）とする。
$g$ は微分できない点を持ってもよいが、次の節の近接写像を計算できるものとする。
例えば $\ell_1$ 正則化 $\lambda\|x\|_1$ は零で微分できないが、近接写像は成分ごとの式で計算できる。
収束の議論では $f$ と $g$ を凸、$g$ を真閉凸関数（どこかで有限の値をとり、$-\infty$ をとらず、下半連続）とする。
$g$ を線形写像の像で評価する $g(Dx)$ のように近接写像が閉形式にならない場合は、変数を分けて [ADMM](../admm-splitting/) で解く。

## 近接写像の導出

$\nabla f$ の Lipschitz 定数の上界を $L\ge L_f$ とすると、

$$
f(z)\le f(x)+\nabla f(x)^T(z-x)+\frac L2\|z-x\|^2
$$

という二次の上界を使える。
この上界と $g(z)$ の和を $z$ について最小化すると、

$$
x^+=\operatorname{prox}_{g/L}(x-\nabla f(x)/L),\qquad
\operatorname{prox}_{tg}(v)=\arg\min_z\left(g(z)+\frac{\|z-v\|^2}{2t}\right)
$$

となる。
つまり、$f$ の勾配で刻み $1/L$ だけ進み、その点に $g$ の近接写像をかける。
$g(z)=\lambda\|z\|_1$ なら各成分で正・負・零の場合を分け、$\operatorname{sign}(v_i)\max(|v_i|-t\lambda,0)$ を得る。
これがソフト閾値処理である。
$g$ が凸集合 $C$ の指示関数（$C$ の上で 0、外で $+\infty$）なら、近接写像は $C$ への射影になり、ボックス制約では成分ごとの切り詰めになる。
$\operatorname{prox}_{tg}$ は非拡大（$\|\operatorname{prox}(u)-\operatorname{prox}(v)\|\le\|u-v\|$）なので、入力の丸め誤差を増幅しない。

API では `SmoothGradient` が $f$ の値と勾配を、`ProximalMap` が近接写像を供給し、`CompositeProblem::new(&smooth, &prox)` が両者を借用する。
`ProximalMap::apply_into(point, step, output)` は $\operatorname{prox}_{\text{step}\cdot g}(\text{point})$ を書き、解法は `step` に $1/L$ を渡す。
停止に使う勾配写像 $G_L(x)=L(x-x^+)$ が零になることは、合成目的の停留条件 $0\in\nabla f(x)+\partial g(x)$ と同値である。

## 近接勾配法の収束と停止

近接勾配法は $x_{k+1}=\operatorname{prox}_{g/L}(x_k-\nabla f(x_k)/L)$ を繰り返す。
一回の反復は $f$ の値、$f$ の勾配、近接写像を一回ずつ使う。
$f,g$ が凸で最小点 $x^*$ があれば、$F(x_k)-F(x^*)\le L\|x_0-x^*\|^2/(2k)$ が成り立つ（Beck と Teboulle, 2009）。
$f$ が強凸率 $\mu$ を持てば、反復点の誤差 $\|x_k-x^*\|$ は比 $1-\mu/L$ で一次収束する。
したがって $L$ を大きく見積もるほど一歩が短くなり、収束は遅くなる。

`ProximalOptions::new(L)` は固定の $L$ を使い、既定では上界の検査をしない。
$L<L_f$ では上界が成り立つとは限らず、刻みが長すぎて反復が振動したり発散したりすることがある。
$L_f$ が未知なら `with_backtracking(growth, trials)` で上界の検査（後退）を有効にする。
検査では試行点 $x^+$ で $f(x^+)\le f(y)+\nabla f(y)^T(x^+-y)+\frac L2\|x^+-y\|^2$ を確かめ、成り立たなければ $L$ を `growth` 倍（1 より大きい有限の値）して近接写像からやり直す。
$f(x^+)$ が非有限の場合と、試行点の座標が浮動小数点数で表せない場合も、上界を満たさない試行として扱う。
一回の反復で `trials` 回試しても受理できないか、次の $L$ が表せなければ、`Stagnation` で止まる。
後退がある場合、一回の試行ごとに $f$ の値を一回追加で評価する。
$L$ は反復をまたいで引き継がれ、増えるだけで減らない。

停止は勾配写像の最大値ノルム $\|G_L\|_\infty=L\|x^+-y\|_\infty$ が `GradientTolerance` の閾値以下になったときで、終了理由は `Converged` である。
$y$ は勾配の一歩を始めた点で、近接勾配法では $x_k$、FISTA では次の節の外挿点である。
既定の閾値は絶対・相対とも $\sqrt{\varepsilon}$、尺度 1 で、`f64` では $2\sqrt{\varepsilon}\approx2.98\times10^{-8}$ になる。
外側の反復の上限は既定 1000 回（`with_max_iterations` で変更）で、達すると `IterationLimit` になる。
滑らかな一歩が丸めで $y$ に戻り、近接写像も点を動かさないのに勾配の成分が許容誤差を超えている場合は、停留点と判定せずに `Stagnation` で止まる。
$f(y)$、勾配、近接写像の値のどれかが非有限なら、終了理由ではなく `NonFinite` のエラーになる。

`ProximalResult` は最後に受理した点 `x()`、`mapping_norm()`、最後の反復の `lipschitz()`、`iterations()`、`restarts()`、`termination()`、`counts()` を返し、目的値 $F(x)$ は返さない。
目的値が必要なら $f(x)+g(x)$ を利用者側で計算する。
`mapping_norm()` は反復を一回も終えていなければ `None` である。
`is_success()` は `Converged` のときだけ真で、`IterationLimit` や `Stagnation` でも最後に受理した点は返る。
`mapping_norm()` は停留性の推定値で、最適値との差の証明ではない。

## FISTA の加速

FISTA は直前の変位を使って外挿点 $y_k$ を作り、その点で近接勾配の一歩を計算する。
加速係数は $t_0=1$、$t_{k+1}=(1+\sqrt{1+4t_k^2})/2$、外挿は $y_{k+1}=x_{k+1}+\frac{t_k-1}{t_{k+1}}(x_{k+1}-x_k)$ である。
凸性、Lipschitz 勾配、正確な近接写像などの仮定の下で、この基本形の目的値の誤差は $2L\|x_0-x^*\|^2/(k+1)^2=O(k^{-2})$ で抑えられる。
通常の近接勾配法の $O(k^{-1})$ より速いが、有限精度の個々の反復で目的値が単調に下がるわけではない。

`Fista` は既定で勾配による再開始（O'Donoghue と Candès, 2015）を使う。
$y_k-x_{k+1}=G_L(y_k)/L$ なので、$\langle y_k-x_{k+1},\,x_{k+1}-x_k\rangle>0$ は直前の変位が勾配写像と鋭角をなし、加速が目的の増える向きに働いたことを表す。
このとき $y_{k+1}=x_{k+1}$、$t_{k+1}=1$ に戻す。
強凸な問題では、再開始によって一次収束の速さが戻る。
再開始の回数は `ProximalResult::restarts()` で読み、`with_restart(false)` で基本形にできる。
一回の反復の評価回数とエラーは `ProximalGradient` と同じである。

`minimize(&problem, &x0)` は呼び出しごとに作業領域と結果を確保する。
同じ次元を繰り返し解くときは、`workspace_requirements(n)` で必要量を求め、`ProximalWorkspace` と `ProximalResult::empty()` を `minimize_into` に渡して再利用する。
`workspace_requirements(n)` が返す `ProximalWorkspaceRequirements` は次元 `dimension()` と、次元の 7 倍の成分を収めるバイト数 `bytes()` を持つ。
`minimize_into` がエラーを返したとき、出力の結果は書き換えられない。
`ProximalWorkspace` は直前の呼び出しを記録し、`last_attempt()` の `progress()` が返す `ProximalProgress` から受理した点までの反復回数 `iterations()` と最後の勾配写像 `mapping_norm()` を読める。

## ソフト閾値の検算

$\tfrac12(x-a)^2+\lambda|x|$ を `ProximalGradient` と `Fista` で解く。
解析解はソフト閾値 $S_\lambda(a)=\operatorname{sign}(a)\max(|a|-\lambda,0)$ である。
$f$ の勾配の Lipschitz 定数は $L_f=1$、強凸率も $\mu=1$ なので、$L=1$ なら近接勾配法は一回目の反復で解析解に達する。
入力は $a$、$\lambda$、$L$ の初期値と後退の有無である。
$L>1$ は刻み $1/L$ を短くし、$L<1$ は上界を破る長い刻みになる。
出力は二つの方法の解、セルの中で f64 の固有メソッドで計算した解析解との差、反復数、再開始の回数、最後の $L$、勾配写像のノルム、終了理由の表と、二つの方法の終了状態から決めた判定である。

    CompositeProblem, Fista, ProximalGradient, ProximalMap, ProximalOptions, SmoothGradient,

// f(x) = ½(x − a)²。∇f は Lipschitz 定数 1 を持つ。
struct Quadratic(f64);
impl SmoothGradient<f64> for Quadratic {
    fn dimension(&self) -> usize {
        1
    }
    fn value(&self, x: &[f64]) -> Result<f64, SciOxideError> {
        let residual = x[0] - self.0;
        Ok(0.5 * residual * residual)
    }
    fn gradient_into(&self, x: &[f64], out: &mut [f64]) -> Result<(), SciOxideError> {
        out[0] = x[0] - self.0;
        Ok(())
    }
}
struct Shrink(f64);
impl ProximalMap<f64> for Shrink {

        let shrunk = RealScalar::max(NumericScalar::abs(x[0]) - step * self.0, 0.0);
        out[0] = RealScalar::copysign(shrunk, x[0]);
        Ok(())
    }
}

二回目の反復で勾配写像が 0 になり、`Converged` で止まる。
$L=10$ と過大に見積もると刻みが 1/10 になり、近接勾配法は誤差が比 $1-\mu/L=0.9$ で減って 170 回、FISTA は再開始 2 回を含む 33 回で止まる。
$1.5$ から停止の閾値 $3\times10^{-8}$ までの縮小に必要な回数は $\ln(5\times10^7)/\ln(1/0.9)\approx168$ で、強凸の一次収束の見積もりと合う。
このとき解析解との差は $2.5\times10^{-8}$ と $1.6\times10^{-8}$ で、$\mu=1$ のこの問題では解の誤差が勾配写像のノルムと同程度になる。
$\lambda=2.5>|a|$ では一回目の近接写像で解が 0 になる。

$L=0.5$ で後退をしないと刻みは $2$ になり、上界 $f(x^+)\le f(y)+\nabla f(y)^T(x^+-y)+\frac L2\|x^+-y\|^2$ が破れる。
近接勾配法の反復は $x=0$ と $x=3$ の間を往復し、勾配写像は $0.5\times3=1.5$ のまま減らない。
1000 回の上限で `IterationLimit` になり、返る $x=0$ は解析解から 1.5 離れている。
FISTA の反復は発散し、$f$ の値が非有限になって `NonFinite` のエラーを返す。
反復点を返さない方法があるので、判定は failed になる。
後退を有効にすると、一回目の試行で $f(x^+)=0.5$ が上界の値 $-1.75$ を超えるので $L$ が 1 に増え、以後は $L=1$ の場合と同じ反復になる。
表の「最後の L」が 1 になることで、後退が $L$ を増やしたことを確かめられる。

より多くの係数と観測を持つ場合は、[LASSO の例題](../../examples/lasso-kkt-verification/)で FISTA と ADMM を比較する。

## 解法の選択

`ProximalGradient` は基本の近接勾配法、`Fista` は外挿と再開始を加えた方式を実装する。
$g$ の近接写像が閉形式で計算できるなら、まず `Fista` を使い、反復数と再開始の回数を `ProximalGradient` と比べる。
$L_f$ の上界が分からなければ後退を有効にし、結果の `lipschitz()` で最後に使った $L$ を確かめる。
$g(Dx)$ のように線形写像を挟んで近接写像が閉形式にならない場合は、$z=Dx$ と分割して [ADMM](../admm-splitting/) を使う。

## まとめ

非滑らかな項を近接写像へ分けると、微分できない点を含む目的も、勾配の一歩と近接写像の繰り返しで解ける。
近接勾配法の刻みは $1/L$ で、$L$ を大きく見積もるほど遅くなり、$L_f$ より小さいと振動や発散が起きうるので、上界が分からなければ `with_backtracking` で検査する。
FISTA の加速には凸性などの仮定があり、外挿の効果は勾配写像のノルム、反復数、再開始の回数と併せて読む。
`Converged` 以外の終了理由でも最後に受理した点は返るので、`is_success()` で判定してから最小点として使う。
結果は目的値を含まないので、$f(x)+g(x)$ は利用者側で計算する。
