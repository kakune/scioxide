目的と制約の値しか得られない場合でも、近傍の標本から局所モデルを作れる。
COBYLA は線形補間、COBYQA は二次補間を使い、モデルを使ってよい範囲を信頼領域で制限する。
どちらも関数値だけを呼び出し、元の導関数は一度も評価しない。
対象は変数が数十程度までで評価コストが大きい問題で、たとえばシミュレーションの出力やノイズの小さい実験値を目的にする問題である。
制約付き問題の記号と KKT 条件は[非線形制約と KKT 条件](../nonlinear-constraints/)に従う。

## 補間モデルと幾何

点 $\mathbf{x}$ の近傍で、COBYLA は目的の線形モデル $m_f(\mathbf{s})=a_f+\mathbf{b}_f^\mathsf{T}\mathbf{s}$ と、各制約の行の線形モデルを作る。
上下限が等しい変数は固定してモデルから外すので、以下の $n$ は固定されない変数の数である。
$n$ 次元の一次モデルには、同じ超平面に乗らない $n+1$ 点が必要である。
中心 $\mathbf{y}_0$ と残りの点 $\mathbf{y}_1,\dots,\mathbf{y}_n$ から、係数 $\mathbf{b}_f$ は

$$
\begin{bmatrix}(\mathbf{y}_1-\mathbf{y}_0)^\mathsf{T}\\ \vdots\\ (\mathbf{y}_n-\mathbf{y}_0)^\mathsf{T}\end{bmatrix}\mathbf{b}_f
=\begin{bmatrix}f(\mathbf{y}_1)-f(\mathbf{y}_0)\\ \vdots\\ f(\mathbf{y}_n)-f(\mathbf{y}_0)\end{bmatrix}
$$

を解いて決まり、各制約の係数も同じ行列で解く。
この行列は $n+1$ 点が作る単体の辺を並べたもので、点がほぼ同じ超平面に並ぶと特異に近づき、小さい評価誤差から大きい勾配推定が生じる。
単体の形を修復する操作は、この補間の悪条件化を抑えるためにある。

`Cobyla` はモデルを作る前に、各辺の長さが半径の $\sqrt{\varepsilon_{\mathrm{mach}}}$ 倍（階数の閾値の絶対値）より長いこと、各辺の前の辺の張る空間に直交する成分が辺の長さの 0.05 倍より大きいことを確かめる。
条件を満たさなければ、中心から座標軸方向に半径だけ離れた点で補間点を作り直す。
反復の途中では新しい点を入れるたびに、単体の体積の変化が大きく中心から遠い点を一つ選んで入れ替える。
モデルの改善が止まったときは、中心から $2.1\Delta$ より遠い点などを、信頼領域の中で補間のラグランジュ基底多項式の絶対値（体積の変化の比）を最大にする点に置き換える幾何ステップを試す。
滑らかな関数では、線形モデルから得る勾配の誤差は半径 $\Delta$ に比例する（$O(\Delta)$）。

COBYQA は二次モデル $m_f(\mathbf{s})=a_f+\mathbf{b}_f^\mathsf{T}\mathbf{s}+\tfrac12\mathbf{s}^\mathsf{T}\mathbf{H}_f\mathbf{s}$ を使う。
二次式の係数は $(n+1)(n+2)/2$ 個あるが、`Cobyqa` が保持する補間点は $2n+1$ 個で、$n\ge2$ では係数をすべて決めるには足りない。
そこで、補間条件を満たす二次式のうち、前回のヘッセ行列からの変化 $\|\mathbf{H}_f-\mathbf{H}_f^{\mathrm{old}}\|_F$（Frobenius ノルム）が最小のものを選ぶ。
この変化は、初期の補間点の広がりで座標ごとに尺度をそろえた座標で測る。
最初のモデルは $\mathbf{H}^{\mathrm{old}}=\mathbf{0}$ から作り、初期の補間点は中心から座標軸の正負の向きに半径だけ離れた $2n$ 点である。
そのため、最初のモデルでは対角の曲率だけが決まり、点の配置で決まらない交差項は 0 になる。
目的と制約のそれぞれについてこの補間を解き、曲率の情報は反復を重ねて少しずつ蓄積する。
補間点の数を有限に抑えたモデルは、元のヘッセ行列に一致するとは限らない。

## 信頼領域の部分問題とメリット関数

制約付きのモデルをそのまま最小にすると、線形モデルでは非有界になり、二次モデルでもモデルが信頼できない遠方へ進む。
そこで半径 $\Delta$ の球の中だけでモデルを使い、目的と制約違反を一つにまとめたメリット関数

$$
\phi_\sigma(\mathbf{x})=\frac{f(\mathbf{x})}{f_s}+\sigma\max\Big(0,\ \max_i v_i(\mathbf{x})\Big)
$$

で試行点を評価する。
$v_i$ は等式なら $|c_i|$、不等式なら $g_j$ を、最初に作ったモデルの勾配から決めた行ごとの尺度で割った値で、$f_s$ も同じく目的の尺度である。
ペナルティ係数 $\sigma$ は 1 から始まる。
モデルの予測で違反が減って目的が増えるステップでは、予測したメリットの減少が違反の減少の $\sigma/2$ 倍以上になるよう $\sigma$ を大きくする。
$\sigma$ は減らさないので、一度大きくなったペナルティ係数は反復の終わりまで残る。

COBYLA の部分問題は球 $\|\mathbf{d}\|_2\le\Delta$ と変数の箱の中の線形計画である。
第一段で線形化した制約違反の最大値を最小にし、第二段で、その違反を増やさない範囲で線形化した目的を最小にする。
実行不能な点から始めた場合も、この第一段が違反を先に減らすので、別の復元段階は持たない。

COBYQA の部分問題は Byrd–Omojokun の分解による二段のステップである。
法線ステップ $\mathbf{n}$ は半径 $0.8\Delta$ の中で線形化した制約違反の二乗和を減らす。
接線ステップ $\mathbf{t}$ は線形化した違反を $\mathbf{n}$ の値に保ったまま、モデルのラグランジュ関数の二次モデルを残りの信頼領域で最小にする。
法線ステップの半径を $\Delta$ より小さくするのは、接線ステップが目的を減らす余地を残すためである。
COBYLA と同じ線形計画のステップを半径 $\rho$（次の節の分解能）で解き、その予測減少（必要なら半分ずつ縮めたもの）がこのステップの 10 倍を超える場合は、線形計画のステップを使う。

## 半径と分解能の更新

試行点を評価したら、実際のメリットの減少とモデルの予測減少の比 $r$ で半径を更新する。
ステップの長さを $\|\mathbf{d}\|$、分解能を $\rho$ とすると、新しい半径は次のとおりで、どの場合も $\rho$ を下回らない。

$$
\Delta_{\mathrm{new}} =
\begin{cases}
\min\big(\Delta/2,\ \max(\|\mathbf{d}\|,\ \rho/2)\big) & (r\le0.1) \\
\max(\Delta/2,\ \|\mathbf{d}\|) & (0.1<r\le0.7) \\
\max(\Delta/2,\ 2\|\mathbf{d}\|) & (r>0.7)
\end{cases}
$$

分解能 $\rho$ は半径の下限で、初期半径 $\rho_{\mathrm{beg}}$ から始まる。
モデルが改善しなくなり半径が $1.5\rho$ 以下になると、$\rho/\rho_{\mathrm{end}}>250$ なら $\rho/10$、$>16$ なら $\sqrt{\rho\,\rho_{\mathrm{end}}}$、それ以外では最終半径 $\rho_{\mathrm{end}}$ まで下げ、半径も $\rho$ に合わせる。
この規則は Powell の COBYLA と同じ形で、分解能が最終半径に達するまでモデルを作り直しながら近傍を細かくしていく。

1 反復の計算量は、COBYLA が $n\times n$ の補間行列の LU 分解と線形計画で $O(n^3)$ 程度である。
COBYQA は目的と $m$ 本の制約のそれぞれに $n\times n$ のヘッセ行列を持ち、メモリ使用量は $O((m+1)n^2)$ で、補間の更新には SVD を使う。
どちらも評価回数が主な計算コストになる問題を想定している。
評価が安価で導関数が得られる問題では、[逐次二次計画法](../sqp-and-interior-point/)や[非線形内点法](../nonlinear-interior-point/)のほうが少ない評価で高い精度に達する。

## 実行可能性と終了

両手法とも `ConstrainedProblem` から等式、不等式、箱を受け取る。
初期点と試行点は箱に射影するので、すべての評価は箱の中で行われるが、非線形制約は途中の試行で破ることがある。
非線形制約の実行可能性は受理した中心で判定する。
試行点で目的か制約が有限でなければ、その試行を棄却する。
初期点と、補間点を作る・作り直すときの座標軸方向の点で有限でなければ `NonFinite` エラーになる。

値がノイズを含む場合は、半径を小さくしすぎるとモデルの変化よりノイズが大きくなる。
ノイズの標準偏差が $\epsilon$ なら、差分 $f(\mathbf{y}_k)-f(\mathbf{y}_0)$ から作る勾配の誤差はおよそ $\epsilon/\Delta$ なので、$\rho_{\mathrm{end}}$ はノイズで決まる値より小さくしない。

`Converged` は、次の条件がすべて成り立つ場合だけである。

- 分解能が最終半径に達し、半径が分解能の 1.5 倍以下である。
- 中心の正規化した違反が基準量 $\max(1,\|\mathbf{x}\|_\infty)$ での実行可能性の閾値以下である。
- 補間点の配置が階数の検査を通る。
- モデルの予測減少を半径で割った値が分解能の程度まで小さい。
  COBYLA では、線形モデルのステップが分解能の半分より短いことでもよい。

最終分解能で改善のない試行が $2n+8$ 回を超えた場合と、補間モデルを作れないまま半径が最終半径に達した場合は `Stagnation` である。
反復の上限に達すると `IterationLimit`、目的の評価回数の上限に達すると `EvaluationLimit` で止まり、どれも成功ではない。

`CobylaOptions`、`CobyqaOptions` で半径や反復の上限を設定し、`CobylaWorkspace`、`CobyqaWorkspace` を準備する。
半径は `with_radii(initial, final)` で座標の単位で指定し、既定は初期 1、最終 $10^{-4}$ である。
`with_radii` は値を検査しない `const` の builder で、$0<\text{final}\le\text{initial}$ と有限性は `Cobyla::new` と `Cobyqa::new` が検査し、違反すれば `InvalidInput` か `NonFinite` を返す。
ほかに正規化した違反の許容誤差（`with_feasibility_tolerance`）、補間の階数を判定する閾値（`with_rank_threshold`）、反復の上限（`with_max_iterations`、既定 1000 回）、補間点と修復の点を含む目的評価の上限（`with_max_evaluations`、既定 1000 回）、時間上限を設定できる。
容量は `CobylaWorkspaceRequirements` と `CobyqaWorkspaceRequirements` で確認し、`free_variables()` が固定されない変数の数を返す。

幾何とモデルの情報は `OptimizeResult::method_diagnostics()` が返す `OptimizeDiagnostics::Cobyla` と `OptimizeDiagnostics::Cobyqa` から、`CobylaDiagnostics` と `CobyqaDiagnostics` の読み出しメソッドで確認する。

| 読み出し | 内容 |
|---|---|
| `radius()` | 最後の半径 $\Delta$（座標の単位） |
| `resolution()` | 最後の分解能 $\rho$（座標の単位） |
| `penalty()` | メリット関数のペナルティ係数 $\sigma$ |
| `model_error()` | 最後の試行でのモデルと実際の値の最大差（正規化した単位）。試行がなければ `None` |
| `model_stationarity()` | 線形計画のステップによるメリットの予測減少を、その半径（COBYLA は $\Delta$、COBYQA は $\rho$）で割った値 |
| `geometry_repairs()` | 幾何の修復の回数（最初の補間点の作成、全点の作り直し、1 点を入れ替える幾何ステップを含む） |
| `poised()` | 補間点の配置が階数の検査を通ったか |

元の導関数を観測していないので、`OptimizeResult::stationarity()` は `None` を返し、モデルの勾配を元の KKT 残差の証明として扱わない。
`primal_feasibility()` は元の単位の制約違反を返す。
終了時には制約違反、半径、モデルの診断、終了理由を併記する。

## 円板への射影

$(2,0)$ からの距離の二乗を単位円板上で最小化する。
解析解は $(1,0)$ で、制約 $x^2+y^2\le1$ は解で能動になる。
目的も制約も微分を渡さず、幾何から得た解析解で検算する。

次のセルは `Cobyla` と `Cobyqa` を同じ初期点 $(0, h)$ から、初期半径 1 で解く。
入力は開始点の高さ $h$ と最終半径 $\rho_{\mathrm{end}}=10^{q}$ で、出力は各方式の最適点、元の式で測った円板の違反、解析解との差、目的の評価回数とモデルの診断である。

```rust
//| id: optimize-cobyla-feasibility
//| ref: optimize-cobyla-feasibility
//| title: 円板上の最適点を関数値だけから求める
//| run: reactive
//| crates: [scioxide-core, scioxide-optimize]
//| inputs:
//|   height: {"type":"range","label":"開始点の高さ h [-]","min":-1,"max":1,"step":0.25,"value":0.5}
//|   final_radius_exponent: {"type":"range","label":"最終半径の指数 q（ρ_end = 10^q）[-]","min":-8,"max":-2,"step":1,"value":-4}
//| cases:
//|   - {"id":"fine-radius","label":"ρ_end = 10⁻⁸","description":"COBYLA の解析解との差は 6.4×10⁻⁹ に下がるが、目的の評価は 35 回から 62 回に増える。COBYQA の差は 10⁻¹³ 程度のまま変わらない。","inputs":{"final_radius_exponent":-8}}
//|   - {"id":"coarse-radius","label":"ρ_end = 10⁻²","description":"COBYLA は 24 回の評価で止まり、解析解との差は 9.2×10⁻⁴ にとどまる。","inputs":{"final_radius_exponent":-2}}
//|   - {"id":"top-start","label":"開始点の高さ 1","description":"COBYLA のペナルティ係数は 1.67 まで増え、元の式で測った違反 6.0×10⁻⁹ が残る。","inputs":{"height":1}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"methods","path":"/rows/0/1","equals":"Converged"}
//|       - {"artifact":"methods","path":"/rows/1/1","equals":"Converged"}
//|       - {"artifact":"methods","path":"/rows/0/4","range":{"min":0,"max":1e-8}}
//|       - {"artifact":"methods","path":"/rows/0/5","range":{"min":1e-6,"max":1e-4}}
//|       - {"artifact":"methods","path":"/rows/1/5","range":{"min":0,"max":1e-10}}
//|       - {"artifact":"methods","path":"/rows/0/6","range":{"min":25,"max":50}}
//|       - {"artifact":"methods","path":"/rows/1/6","range":{"min":12,"max":30}}
//|       - {"artifact":"methods","path":"/rows/0/8","approx":{"value":1e-4,"rtol":1e-9}}
//|       - {"path":"/outputs/1/state","equals":"satisfied"}
//|   - case: fine-radius
//|     expect:
//|       - {"artifact":"methods","path":"/rows/0/1","equals":"Converged"}
//|       - {"artifact":"methods","path":"/rows/0/5","range":{"min":0,"max":1e-7}}
//|       - {"artifact":"methods","path":"/rows/1/5","range":{"min":0,"max":1e-10}}
//|   - case: coarse-radius
//|     expect:
//|       - {"artifact":"methods","path":"/rows/0/1","equals":"Converged"}
//|       - {"artifact":"methods","path":"/rows/0/5","range":{"min":1e-4,"max":1e-2}}
//|   - case: top-start
//|     expect:
//|       - {"artifact":"methods","path":"/rows/0/1","equals":"Converged"}
//|       - {"artifact":"methods","path":"/rows/1/1","equals":"Converged"}
//|       - {"artifact":"methods","path":"/rows/0/4","range":{"min":0,"max":1e-7}}
//|       - {"artifact":"methods","path":"/rows/0/9","range":{"min":1,"max":3}}
//|       - {"path":"/outputs/1/state","equals":"satisfied"}
use scioxide_core::RealScalar;
use scioxide_optimize::{
    Cobyla, CobylaOptions, Cobyqa, CobyqaOptions, ConstrainedProblem, ConstraintFn,
    Constraints, ObjectiveFn, OptimizeDiagnostics,
};
// 目的 (x − 2)² + y² と不等式 x² + y² − 1 ≤ 0。導関数は渡さない。
let f = ObjectiveFn::new(2, |x: &[f64]| Ok((x[0] - 2.0) * (x[0] - 2.0) + x[1] * x[1]));
let c = ConstraintFn::new(2, |x: &[f64]| Ok(x[0] * x[0] + x[1] * x[1] - 1.0));
let constraints = Constraints::new(2)
    .map_err(|e| e.to_string())?
    .inequality(c)
    .map_err(|e| e.to_string())?;
let problem = ConstrainedProblem::new(&f, &constraints).map_err(|e| e.to_string())?;
// 半径の組は builder では検査されず、new で 0 < 最終 ≤ 初期 を検査する。
let final_radius = RealScalar::powf(10.0, final_radius_exponent);
let cobyla = Cobyla::new(CobylaOptions::default().with_radii(1.0, final_radius))
    .map_err(|e| e.to_string())?;
let cobyqa = Cobyqa::new(CobyqaOptions::default().with_radii(1.0, final_radius))
    .map_err(|e| e.to_string())?;
let start = [0.0, height];
let mut rows = Vec::new();
let mut all_converged = true;
for (name, result) in [
    ("COBYLA", cobyla.minimize(&problem, &start)),
    ("COBYQA", cobyqa.minimize(&problem, &start)),
] {
    let r = result.map_err(|e| e.to_string())?;
    let (radius, resolution, penalty, repairs) = match r.method_diagnostics() {
        OptimizeDiagnostics::Cobyla(d) => (
            d.radius(),
            d.resolution(),
            d.penalty(),
            d.geometry_repairs(),
        ),
        OptimizeDiagnostics::Cobyqa(d) => (
            d.radius(),
            d.resolution(),
            d.penalty(),
            d.geometry_repairs(),
        ),
        _ => return Err("補間法の診断がない".to_string()),
    };
    all_converged &= r.is_success();
    let x = r.x();
    // 独立な検算: 円板への射影の解析解 (1, 0) との距離と、元の式で測った違反。
    rows.push((
        name,
        r.termination().to_string(),
        x[0],
        x[1],
        (x[0] * x[0] + x[1] * x[1] - 1.0).max(0.0),
        RealScalar::sqrt((x[0] - 1.0) * (x[0] - 1.0) + x[1] * x[1]),
        r.fun_evals(),
        radius,
        resolution,
        penalty,
        repairs,
    ));
}
let status = format!("{} / {}", rows[0].1, rows[1].1);
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let fixed8 = serde_json::json!({ "fractionDigits": 8 });
let fixed3 = serde_json::json!({ "fractionDigits": 3 });
emit_table_with_columns!(
    serde_json::json!([
        { "key": "0", "label": "方法" },
        { "key": "1", "label": "終了理由" },
        { "key": "2", "label": "x [-]", "type": "number", "format": fixed8 },
        { "key": "3", "label": "y [-]", "type": "number", "format": sci2 },
        { "key": "4", "label": "制約違反 [-]", "type": "number", "format": sci2 },
        { "key": "5", "label": "解析解との差 [-]", "type": "number", "format": sci2 },
        { "key": "6", "label": "目的の評価 [回]", "type": "integer" },
        { "key": "7", "label": "最終半径 [-]", "type": "number", "format": sci2 },
        { "key": "8", "label": "分解能 ρ [-]", "type": "number", "format": sci2 },
        { "key": "9", "label": "ペナルティ係数 σ [-]", "type": "number", "format": fixed3 },
        { "key": "10", "label": "幾何修復 [回]", "type": "integer" }
    ]),
    rows,
    metadata = serde_json::json!({ "id": "methods" })
);
let outcome = if all_converged {
    Outcome::satisfied("両方式とも分解能とモデルの判定を満たした")
        .explanation("元の導関数による KKT 残差はないので、解析解との差で精度を確かめる。")
} else {
    Outcome::partial("一方の方式が判定を満たす前に止まった")
};
emit_outcome!(
    outcome
        .status(status)
        .diagnostic("最終半径", final_radius, None)
);
```

既定の $\rho_{\mathrm{end}}=10^{-4}$ では両方式とも `Converged` で終了する。
COBYLA は 35 回の評価で解析解との差 $2.0\times10^{-5}$、COBYQA は 19 回の評価で差 $8.6\times10^{-14}$ に達し、どちらも元の式で測った違反は 0 である。
開始点は円板の中にあるが、最適点は境界上にある。
COBYLA のペナルティ係数は 1 から 1.48 に増え、違反を減らすステップで目的が増えたことを表す。
COBYLA の差が最終半径の 0.2 倍程度にとどまるのは、線形モデルでは制約の曲率を表せず、分解能 $\rho$ より細かい位置を決められないためである。
$\rho_{\mathrm{end}}=10^{-8}$ では COBYLA の差は $6.4\times10^{-9}$ に下がるが、評価は 62 回に増え、$10^{-2}$ では 24 回の評価で差 $9.2\times10^{-4}$ にとどまる。
COBYQA の差は $\rho_{\mathrm{end}}$ によらず $10^{-13}$ 程度である。
この問題の目的と制約は交差項のない二次式なので、座標軸方向の初期の 5 点と最小 Frobenius ノルムの補間で、モデルが元の関数に一致する。
二次式でない問題ではこの一致は起きないので、COBYQA の精度も $\rho_{\mathrm{end}}$ とモデルの誤差で決まる。
解析解との差と制約違反は異なる量なので、両方を確認する。

## まとめ

COBYLA は $n+1$ 点の線形モデルと球の中の線形計画、COBYQA は $2n+1$ 点の二次モデルと Byrd–Omojokun の分解で、どちらも関数値だけから信頼領域のステップを作る。
到達精度は最終半径 $\rho_{\mathrm{end}}$（既定 $10^{-4}$）でおおよそ決まり、線形モデルの COBYLA では $\rho_{\mathrm{end}}$ を超えない程度の解の誤差が残り、$\rho_{\mathrm{end}}$ を下げるまで減らない。
半径の組は `Cobyla::new` と `Cobyqa::new` で検査されるので、`with_radii` のあとで `?` を通す。
`Converged` でも元の導関数による KKT 残差はないので、終了理由、元の単位の違反、`resolution()` と `model_stationarity()` を併記し、可能なら解析解や別の方式で検算する。
ノイズのある関数では、$\rho_{\mathrm{end}}$ をノイズで決まる尺度より小さくしない。
