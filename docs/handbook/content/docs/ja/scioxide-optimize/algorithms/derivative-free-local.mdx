関数値を計算できても、微分を安定して求められない場合がある。
測定装置や分岐を含むシミュレーションでは、評価値だけで局所的な改善を探す方法が候補になる。
ただし微分を渡さないことと、不連続・ノイズの大きい関数でも収束することは同じではない。

## 導関数を使わない局所法

シミュレーションコードが外部のプログラムであったり、関数値に高周波の離散化誤差が含まれて差分勾配が意味を持たなかったりする場合は、目的関数の値だけを評価して探索を進める手法が必要になる。
SciOxide の導関数を使わない局所法は、値の大小比較だけで点を更新する Nelder–Mead 法（`NelderMead`）と、方向ごとの一次元最小化を繰り返す Powell の共役方向法（`Powell`）である。
このページは Nelder–Mead 法を扱い、Powell 法は[Powell の共役方向法](../powell-conjugate-directions/)で扱う。
`NelderMead` は上下限を扱わず、`BoundedObjective` を渡すと `InvalidInput`（`UnsupportedConfiguration`）になる。
有限の箱の中で探すときは `Powell` を使う。

どちらも値の比較だけで進むので、微分できない点を含む目的にも使える。
一方で、変数が多く評価が計算コストが小さい滑らかな目的では、数値微分を使う勾配法のほうが少ない評価で済むことが多い。

## Nelder–Mead 法の単体操作

$n$ 次元空間で、$n+1$ 個のアフィン独立な頂点 $\{\mathbf{x}_1, \dots, \mathbf{x}_{n+1}\}$ からなる単体（simplex）を作る。
頂点を目的関数値の昇順に並べ

$$
f(\mathbf{x}_1) \le f(\mathbf{x}_2) \le \dots \le f(\mathbf{x}_{n+1})
$$

最良点 $\mathbf{x}_1$、次悪点 $\mathbf{x}_n$、最悪点 $\mathbf{x}_{n+1}$ を決める。
最悪点を除く重心 $\mathbf{c} = \frac{1}{n}\sum_{i=1}^n \mathbf{x}_i$ を通して最悪点を置き換える候補を、次の順に試す（$f_r=f(\mathbf{x}_r)$ などと書く）。

1. 反射 $\mathbf{x}_r=\mathbf{c}+(\mathbf{c}-\mathbf{x}_{n+1})$ を評価し、$f_1\le f_r<f_n$ なら $\mathbf{x}_r$ で置き換える。
2. $f_r<f_1$ なら膨張 $\mathbf{x}_e=\mathbf{c}+\gamma(\mathbf{c}-\mathbf{x}_{n+1})$ を評価し、$f_e<f_r$ なら $\mathbf{x}_e$、そうでなければ $\mathbf{x}_r$ で置き換える。
3. $f_n\le f_r<f_{n+1}$ なら外側の収縮 $\mathbf{x}_{oc}=\mathbf{c}+\beta(\mathbf{c}-\mathbf{x}_{n+1})$ を評価し、$f_{oc}\le f_r$ なら置き換える。
4. $f_r\ge f_{n+1}$ なら内側の収縮 $\mathbf{x}_{ic}=\mathbf{c}-\beta(\mathbf{c}-\mathbf{x}_{n+1})$ を評価し、$f_{ic}<f_{n+1}$ なら置き換える。
5. 収縮した点が受理されなければ、最良点以外の頂点を $\mathbf{x}_i\leftarrow\mathbf{x}_1+\delta(\mathbf{x}_i-\mathbf{x}_1)$ と縮小する。

一反復の評価は反射だけなら 1 回、膨張か収縮を試せば 2 回、縮小では $n$ 回が加わる。
NaN や無限大を返した点は、どの有限の値よりも悪い点として順位付けられるので、単体はその点から離れる向きに収縮か縮小をする。
ただし開始点の値は有限でなければならず、そうでなければ `NonFinite` のエラーになる。

### 次元に合わせた係数

`NelderMead` の係数は Gao–Han の適応係数で、$n \ge 2$ では膨張 $\gamma = 1 + 2/n$、収縮 $\beta = 3/4 - 1/(2n)$、縮小 $\delta = 1 - 1/n$ である。
$n = 2$ ではこれは標準の係数 $\gamma=2$、$\beta=\delta=1/2$ と一致し、$n = 1$ でも標準の係数を使う。
次元が上がると $\gamma$ は 1 に、$\beta$ は 3/4 に、$\delta$ は 1 に近づくので、膨張・収縮・縮小による単体の変化は小さくなる。
Gao–Han は、標準の係数では次元が上がると Nelder–Mead 法の効率が落ちる理由を膨張と収縮の性質から説明し、次元に依存するこの係数を提案した（Gao–Han 2012）。

### 収束の理論

Nelder–Mead 法には、一般の $n$ で停留点への収束を保証する理論がない。
McKinnon は二次元の狭義凸で連続微分可能な関数に対して、単体が停留点でない点に縮んでいく例を示した。
得られた点は勾配や既知解などで独立に検算する。

## 単体の幾何と停止

$n$ 次元の単体の辺 $\mathbf{x}_{i+1}-\mathbf{x}_1$（$i=1,\dots,n$）を列に並べた行列の階数が落ちると、調べていない方向が残る。
`NelderMead` は各辺を絶対値が最大の成分で割って正規化し、列ピボット付き QR 分解の数値階数を `RankThreshold`（既定は絶対・相対とも $\sqrt{\varepsilon_{\mathrm{mach}}}$）で判定する。
`NelderMeadGeometry` は最後に調べた単体の幾何を表し、`FullRank` は正規化した辺が数値的に階数 $n$ を持つこと、`Degenerate` は階数が落ちたこと、`Incomplete` は単体を作ってから、あるいは変えてから調べていないことを表す。

単体が `Degenerate` になると、最良点のまわりに単体を作り直す（修復、$n$ 回の評価）。
修復の回数は `with_max_repairs`（既定 2 回）で制限し、上限に達すると `Stagnation` で止まる。
初期単体は、明示しなければ開始点の第 $i$ 座標に座標の参照尺度 $s_x$（既定 1）の 0.05 倍を足した $n$ 個の点と開始点で作る。
`NelderMeadOptions::with_initial_simplex` に $(n+1)\times n$ の行列を渡すと、それを初期単体にする（最初の行は開始点と同じでなければならない）。

停止の判定は、目的値の広がり（頂点の最大値と最小値の差）と単体の直径（2 頂点間の $\infty$ ノルムの距離の最大）を使う。

$$
\max_i f_i-\min_i f_i\le\tau^f_{\mathrm{abs}}+\tau^f_{\mathrm{rel}}\,s_f,\qquad
\max_{i,j}\|\mathbf{x}_i-\mathbf{x}_j\|_\infty\le\tau^x_{\mathrm{abs}}+\tau^x_{\mathrm{rel}}\,s_x
$$

二つの不等式が成り立ち、かつ単体が `FullRank` のときだけ `Converged` になる。
$s_f$ と $s_x$ は `with_reference_scales` で指定する目的と座標の参照尺度（既定はどちらも 1）で、現在の目的値や座標の大きさには追従しない。
許容誤差は `with_function_tolerance`（`ResidualTolerance`）と `with_step_tolerance`（`StepTolerance`）で指定し、既定はどれも $\sqrt{\varepsilon_{\mathrm{mach}}}$ なので、閾値は $2\sqrt{\varepsilon_{\mathrm{mach}}}\approx2.98\times10^{-8}$ になる。
目的値の広がりだけを小さくしても、細長くつぶれた単体が最小点の近くにあるとは限らないので、直径と幾何を合わせて調べる。

ほかの終了は反復の上限（既定 1000 回）の `IterationLimit`、初期単体と修復を含めた評価回数の上限（既定 2000 回、`with_max_evaluations`）の `EvaluationLimit`、時間上限である。
これらと `Stagnation` では、それまでの最良の頂点が推定値として返る。
`NelderMeadDiagnostics` は目的値の広がり・直径とそれぞれの閾値、幾何、数値階数、修復の回数を持つ。

`NelderMeadOptions` は不変の設定で、`NelderMead::new` が参照尺度と初期単体を検査する。
準備した `NelderMeadWorkspace` は $O(n^2)$ のメモリで単体と頂点の値を保持し、呼び出しの後に `simplex()` と `values()` で最後の単体を読める。
必要容量は `NelderMeadWorkspaceRequirements` で確認する。

## Rosenbrock 関数と単体の探索

$f(x,y)=100(y-x^2)^2+(1-x)^2$ は曲がった細い谷を持ち、解析最小点は $(1,1)$ で $f=0$ である。
二乗の和なので $f\ge0$ で、二項がともに零になる $(1,1)$ が大域最小点になる。
入力は開始点の第一成分 $x$（第二成分は 1）と座標の参照尺度 $s_x$ で、目的の参照尺度は 1 のままにする。
$s_x$ は初期単体の大きさ $0.05\,s_x$ と直径の閾値 $\sqrt{\varepsilon_{\mathrm{mach}}}(1+s_x)$ を同時に変える。
図は評価ごとの最良値 $f_{\mathrm{best}}-f^*$（$f^*=0$）を対数軸で示す。
表は到達点、解析点との距離、評価回数、終了理由と、停止に使った目的値の広がり・単体の直径とそれぞれの閾値、幾何、修復の回数である。
最後に、終了理由を計算の判定として示す。

```rust
//| id: optimize-nelder-mead-rosenbrock
//| ref: optimize-nelder-mead-rosenbrock
//| title: Nelder–Mead 法の到達点と評価回数を読む
//| run: reactive
//| crates: [scioxide-core, scioxide-optimize]
//| inputs:
//|   initial: {"type":"range","label":"開始点 x [-]","min":-2,"max":2,"step":0.25,"value":-1.25}
//|   coordinate_scale: {"type":"select","label":"座標の参照尺度 sₓ [-]","description":"初期単体の大きさ 0.05 sₓ と直径の閾値 √ε (1 + sₓ) を変える。","options":["0.1","1","10"],"value":"1"}
//| cases:
//|   - {"id":"start-right","label":"開始点 x = 2","description":"谷の外側から入り、160 回の評価で解析点から 1.2×10⁻⁸ の距離に止まる。","inputs":{"initial":2}}
//|   - {"id":"start-left","label":"開始点 x = −2","description":"曲がった谷を長くたどり、235 回の評価で止まる。","inputs":{"initial":-2}}
//|   - {"id":"coarse-scale","label":"sₓ = 10","description":"初期単体が 0.5 に広がり、直径の閾値も 5.5 倍に緩む。","inputs":{"coordinate_scale":"10"}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"summary","path":"/rows/0/2","range":{"min":0,"max":1e-6}}
//|       - {"artifact":"summary","path":"/rows/0/4","range":{"min":180,"max":260}}
//|       - {"artifact":"summary","path":"/rows/0/5","equals":"Converged"}
//|       - {"artifact":"stopping","path":"/rows/0/4","equals":"FullRank"}
//|       - {"artifact":"stopping","path":"/rows/0/3","approx":{"value":2.9802322e-8,"rtol":1e-6}}
//|       - {"path":"/outputs/3/state","equals":"satisfied"}
//|   - case: start-right
//|     expect:
//|       - {"artifact":"summary","path":"/rows/0/2","range":{"min":0,"max":1e-6}}
//|       - {"path":"/outputs/3/state","equals":"satisfied"}
//|   - case: start-left
//|     expect:
//|       - {"artifact":"summary","path":"/rows/0/2","range":{"min":0,"max":1e-6}}
//|       - {"path":"/outputs/3/state","equals":"satisfied"}
//|   - case: coarse-scale
//|     expect:
//|       - {"artifact":"stopping","path":"/rows/0/3","approx":{"value":1.6391277e-7,"rtol":1e-6}}
//|       - {"artifact":"summary","path":"/rows/0/2","range":{"min":0,"max":1e-6}}
//|       - {"path":"/outputs/3/state","equals":"satisfied"}
use scioxide_optimize::{NelderMead, NelderMeadOptions, ObjectiveFn, OptimizeDiagnostics};
use std::cell::RefCell;

let scale: f64 = coordinate_scale
    .parse()
    .map_err(|_| "参照尺度を読めない".to_string())?;
// 評価した値を順に記録し、最良値の推移を描く。
let history = RefCell::new(Vec::new());
let f = ObjectiveFn::new(2, |x: &[f64]| {
    let (valley, offset) = (x[1] - x[0] * x[0], 1.0 - x[0]);
    let value = 100.0 * valley * valley + offset * offset;
    history.borrow_mut().push(value);
    Ok(value)
});
let options = NelderMeadOptions::default().with_reference_scales(scale, 1.0);
let result = NelderMead::new(options)
    .map_err(|e| e.to_string())?
    .minimize(&f, &[initial, 1.0])
    .map_err(|e| e.to_string())?;
let x = result.x();
let OptimizeDiagnostics::NelderMead(diagnostic) = result.method_diagnostics() else {
    return Err("対応するアルゴリズムの診断がない".to_string());
};
// 最良値 f_best − f*（f* = 0）。0 以下の点は対数軸に描かず数える。
let mut best = f64::INFINITY;
let mut dropped = 0_usize;
let mut progress = Vec::new();
for (k, &value) in history.borrow().iter().enumerate() {
    best = best.min(value);
    if best > 0.0 {
        progress.push([(k + 1) as f64, best]);
    } else {
        dropped += 1;
    }
}
emit_line_chart!(
    &vec![serde_json::json!({ "name": "最良値 f_best − f*", "points": progress })],
    options = &serde_json::json!({
        "xLabel": "目的の評価 [回]",
        "yLabel": "最良値と最小値の差 [-]",
        "yType": "log"
    })
);
// 独立検算: 解析的な最小点 (1, 1) との距離。
let distance = scioxide_core::RealScalar::hypot(x[0] - 1.0, x[1] - 1.0);
let general = serde_json::json!({ "significantDigits": 8 });
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let columns = serde_json::json!([
    { "key": "0", "label": "x [-]", "type": "number", "format": general },
    { "key": "1", "label": "y [-]", "type": "number", "format": general },
    { "key": "2", "label": "解析点との距離 [-]", "type": "number", "format": sci3 },
    { "key": "3", "label": "目的値 [-]", "type": "number", "format": sci3 },
    { "key": "4", "label": "評価 [回]", "type": "integer" },
    { "key": "5", "label": "終了理由" },
    { "key": "6", "label": "図から除いた点 [個]", "type": "integer" }
]);
let termination = result.termination();
emit_table_with_columns!(
    columns,
    vec![(
        x[0],
        x[1],
        distance,
        result.fun(),
        result.fun_evals(),
        termination.to_string(),
        dropped
    )],
    metadata = serde_json::json!({ "id": "summary" })
);
let none = "未計算";
let stopping_columns = serde_json::json!([
    { "key": "0", "label": "値の広がり [-]", "type": "number", "format": sci3, "nullText": none },
    { "key": "1", "label": "その閾値 [-]", "type": "number", "format": sci3, "nullText": none },
    { "key": "2", "label": "直径 [-]", "type": "number", "format": sci3, "nullText": none },
    { "key": "3", "label": "その閾値 [-]", "type": "number", "format": sci3, "nullText": none },
    { "key": "4", "label": "幾何" },
    { "key": "5", "label": "修復 [回]", "type": "integer" }
]);
emit_table_with_columns!(
    stopping_columns,
    vec![(
        diagnostic.objective_spread(),
        diagnostic.function_threshold(),
        diagnostic.diameter(),
        diagnostic.step_threshold(),
        format!("{:?}", diagnostic.geometry()),
        diagnostic.repairs()
    )],
    metadata = serde_json::json!({ "id": "stopping" })
);
let outcome = if termination.is_success() {
    Outcome::satisfied("目的値の広がりと単体の直径が閾値を下回り、単体の階数が落ちていない")
} else {
    Outcome::partial("停止の判定を満たす前に止まった")
        .explanation("返された最良の頂点は推定値として扱う。")
};
emit_outcome!(
    outcome
        .status(termination.to_string())
        .diagnostic("目的の評価", result.fun_evals() as f64, None)
        .diagnostic("解析点との距離", distance, None)
);
```

二乗の和という解析的な事実と、セルの終了判定は別々に確認する。
既定の開始点 $(-1.25,1)$ では 221 回の評価で `Converged` になり、解析点との距離は $8.3\times10^{-9}$ である。
図の最良値は、曲がった谷をたどる最初の約 110 回の評価では 37 から 0.08 までゆっくり下がり、最小点の近くに来てからの約 100 回で $10^{-16}$ 程度まで対数軸でほぼ直線的に下がる。
停止の時点で目的値の広がりは $3.8\times10^{-17}$、単体の直径は $2.2\times10^{-8}$ で、ともに閾値 $2.98\times10^{-8}$ を下回り、幾何は `FullRank`、修復は 0 回である。
開始点 $x=2$ では 160 回、$x=-2$ では 235 回の評価を使い、評価回数は谷をたどる距離で変わる。
直径が閾値を下回っても、最小点からの距離が同じ大きさになる保証はない。
ここでは解析点との距離 $8.3\times10^{-9}$ が直径と同程度であることを、解析解から確かめている。
$s_x=10$ では直径の閾値が $1.6\times10^{-7}$ に緩み、202 回の評価で止まる時点の直径は $9.4\times10^{-8}$、解析点との距離は $2.5\times10^{-8}$ になる。
この例では閾値を緩めると到達点の誤差も約 3 倍になる。

## まとめ

Nelder–Mead 法は $n+1$ 個の頂点を反射・膨張・外側と内側の収縮・縮小で動かし、目的値の比較だけで最悪点を置き換える。
`NelderMead` の係数は次元に合わせた Gao–Han の値で、$n=2$ では標準の係数と一致する。
`Converged` は目的値の広がりと単体の直径が参照尺度に基づく閾値を下回り、単体の階数が落ちていないことを示すだけで、勾配が 0 であることは示さない。
閾値は参照尺度 $s_f$、$s_x$ とともに緩むので、変数と目的の単位をそろえてから尺度を決め、到達点は既知解や別の方法で検算する。
上下限がある問題や方向の組を指定したい問題では Powell 法を使う。
