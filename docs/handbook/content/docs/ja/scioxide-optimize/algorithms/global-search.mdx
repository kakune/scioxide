ある極小点の吸引域（basin of attraction）は、そこから出発した局所ソルバーがその極小点へ収束する初期点の集合であり、目的関数だけでなく局所ソルバーの規則でも決まる。
多数の極小点を持つ多峰性関数では、勾配法や準 Newton 法のような局所ソルバーは、初期点を含む吸引域の極小点へ収束する。
Lipschitz 定数や凸性のような大域的な情報がなければ、有限回の評価で大域的最小点を見つけたと証明することはできない。
評価していない点のすぐ近くに、より低い谷が隠れている可能性を除けないからである。

大域探索はこの限界を前提に大域的最小点の候補を探す。
このページでは、一様に選んだ開始点が大域的最小点の吸引域に当たる確率から、必要な評価の量が次元とともにどう増えるかを導く。
そのうえで、大域探索と局所最適化を組み合わせる考え方と、SciOxide の大域探索法の使い分けを示す。

SciOxide の大域探索はどれも大域最適性を主張しない。
`OptimizeTermination::is_success()` が真になる `Converged` と `GradientSmall` で大域探索が終わることはない。
開始点や世代を使い切った `SearchBudgetCompleted` は、観測した最良点を返す部分結果である。

## 吸引域の命中確率

有界な探索領域 $\Omega = [\mathbf{l}, \mathbf{u}] \subset \mathbb{R}^d$ の中で、大域的最小点の吸引域を $\mathcal{B} \subset \Omega$ とする。
開始点を $\Omega$ から一様に選ぶと、その点が $\mathcal{B}$ に入る確率 $p$ は体積比

$$
p = \frac{\operatorname{Vol}(\mathcal{B})}{\operatorname{Vol}(\Omega)}
$$

に等しい。
独立な $M$ 個の開始点がどれも $\mathcal{B}$ に入らない確率は $(1-p)^M$ なので、少なくとも 1 点が入る確率（命中確率）$P_{\mathrm{hit}}$ は

$$
P_{\mathrm{hit}} = 1 - (1 - p)^M
$$

である。
命中確率を $q$ 以上にするには $(1-p)^M \le 1-q$、つまり

$$
M \ge \frac{\ln(1 - q)}{\ln(1 - p)} \approx \frac{-\ln(1 - q)}{p} \quad (p \ll 1)
$$

の開始点が要る。
近似は $\ln(1-p) \approx -p$ による。
$q = 0.95$ では $-\ln 0.05 \approx 3.0$ なので、必要な開始点の数はおよそ $3/p$ である。

この式で問題になるのが次元の呪い（curse of dimensionality）である。
探索領域を $[-1, 1]^d$、吸引域を半径 $r < 1$ の球とするモデルでは、体積比は

$$
p_d = \frac{\pi^{d/2} r^d}{2^d \, \Gamma(d/2 + 1)}
$$

になる。
$\Gamma$ はガンマ関数で、分子が半径 $r$ の $d$ 次元球の体積、分母の $2^d$ が箱の体積である。
$r = 0.5$ では $p_2 \approx 0.196$ だが、$p_{10} \approx 2.4 \times 10^{-6}$ になり、必要な開始点の数は次元とともに指数関数的に増える。
吸引域を球としたのは説明のためのモデルであり、実際の吸引域の形と大きさは問題と局所ソルバーで決まる。

準乱数列（低ディスクレパンシー列）は点を箱の中に偏りなく並べるので、少ない点数で箱の全体に開始点を置ける。
ただし $N$ 点のうち小さな吸引域に入る点の数はおよそ $pN$ なので、少なくとも 1 点を入れるにはおよそ $1/p$ 点が要ることは一様乱数と変わらない。

### 次元と半径による命中確率

探索領域 $[-1, 1]^d$ にある半径 $r$ の球の吸引域を、独立な一様開始点で少なくとも一度当てる確率 $P_{\mathrm{hit}} = 1 - (1 - p_d)^M$ を、次元 $d$、半径 $r$、目標確率 $q$ を変えて調べる。
このセルは上の式を評価するだけで、ソルバーは呼ばない。
ガンマ関数は scioxide-special の `gamma` で計算する。
$p_d$ が小さいと $1-(1-p_d)^M$ は 1 に近い数どうしの差になって桁落ちするので、$-\operatorname{expm1}(M\ln(1-p_d))$ の形で計算する。
開始点の数は桁が広がるので、横軸を対数にする。

```rust
//| id: optimize-multistart-hit-probability
//| ref: optimize-multistart-hit-probability
//| title: 次元と吸引域半径を動かして複数開始点の命中確率を見る
//| run: reactive
//| crates: [scioxide-core, scioxide-optimize, scioxide-special]
//| inputs:
//|   dimension: {"type":"range","label":"探索次元 d [-]","description":"探索箱の次元数を変える。","min":1,"max":12,"step":1,"value":5}
//|   basin_radius: {"type":"range","label":"吸引域半径 r [-]","description":"極小点まわりの吸引域の大きさ。","min":0.1,"max":0.9,"step":0.05,"value":0.4}
//|   target_probability: {"type":"range","label":"目標命中確率 q [-]","description":"要求する命中確率。","min":0.5,"max":0.99,"step":0.01,"value":0.95}
//| cases:
//|   - {"id":"twelve-dimensions","label":"d = 12","description":"体積比は 5.5×10⁻⁹ に下がり、q = 0.95 に必要な開始点は約 5.5 億点、100 点での命中確率は 5.5×10⁻⁷ になる。","inputs":{"dimension":12}}
//|   - {"id":"wide-basin","label":"r = 0.9","description":"d = 5 でも体積比は 0.0971 で、必要な開始点は 30 点、100 点での命中確率は 0.99996 になる。","inputs":{"basin_radius":0.9}}
//|   - {"id":"one-dimension","label":"d = 1","description":"体積比は 0.4 で、6 点で q = 0.95 に達する。","inputs":{"dimension":1}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"hit","path":"/rows/0/2","approx":{"value":1.684e-3,"rtol":1e-3}}
//|       - {"artifact":"hit","path":"/rows/0/4","equals":1778}
//|       - {"artifact":"hit","path":"/rows/0/5","approx":{"value":0.1551,"rtol":1e-3}}
//|   - case: twelve-dimensions
//|     expect:
//|       - {"artifact":"hit","path":"/rows/0/2","approx":{"value":5.469e-9,"rtol":1e-3}}
//|   - case: wide-basin
//|     expect:
//|       - {"artifact":"hit","path":"/rows/0/2","approx":{"value":9.713e-2,"rtol":1e-3}}
//|       - {"artifact":"hit","path":"/rows/0/4","equals":30}
//|   - case: one-dimension
//|     expect:
//|       - {"artifact":"hit","path":"/rows/0/2","approx":{"value":0.4,"rtol":1e-12}}
//|       - {"artifact":"hit","path":"/rows/0/4","equals":6}
use scioxide_core::RealScalar;
use scioxide_special::gamma;

// d 次元球の体積と、探索箱 [-1, 1]^d に対する体積比 p_d。
let dim = dimension.round() as i32;
let half_dim = f64::from(dim) / 2.0;
let ball_volume = RealScalar::powf(std::f64::consts::PI, half_dim)
    * RealScalar::powi(basin_radius, dim)
    / gamma(half_dim + 1.0).map_err(|e| e.to_string())?;
let fraction = ball_volume / RealScalar::powi(2.0, dim);
// P_hit = 1 − (1 − p)^M を −expm1(M ln(1 − p)) で計算し、p が小さいときの桁落ちを避ける。
let log_miss = RealScalar::ln_1p(-fraction);
let hit = |m: f64| -RealScalar::exp_m1(m * log_miss);
let required = RealScalar::ln(1.0 - target_probability) / log_miss;
// 横軸は 1 点から必要な点数の 10 倍まで、対数で等間隔に取る。
let decades = RealScalar::ceil(RealScalar::log10(required.max(1.0))) + 1.0;
let curve: Vec<[f64; 2]> = (0..=200)
    .map(|i| RealScalar::powf(10.0, decades * f64::from(i) / 200.0))
    .map(|m| [m, hit(m)])
    .collect();
emit_line_chart!(
    &vec![serde_json::json!({ "name": "命中確率", "points": curve })],
    options = &serde_json::json!({
        "xLabel": "独立な開始点の数 M [点]",
        "yLabel": "少なくとも一度の命中確率 [-]",
        "xType": "log",
        "yMin": 0.0,
        "yMax": 1.0,
        "annotations": [
            { "kind": "line", "axis": "y", "value": target_probability, "label": "目標確率 q" },
            { "kind": "line", "axis": "x", "value": required, "label": "必要な M" }
        ]
    })
);
let fixed2 = serde_json::json!({ "fractionDigits": 2 });
let sci4 = serde_json::json!({ "notation": "scientific", "significantDigits": 4 });
let digits4 = serde_json::json!({ "significantDigits": 4 });
emit_table_with_columns!(
    serde_json::json!([
        { "key": "0", "label": "次元 d [-]", "type": "integer" },
        { "key": "1", "label": "半径 r [-]", "type": "number", "format": fixed2 },
        { "key": "2", "label": "体積比 p_d [-]", "type": "number", "format": sci4 },
        { "key": "3", "label": "目標確率 q [-]", "type": "number", "format": fixed2 },
        { "key": "4", "label": "必要な開始点の数 M [点]", "type": "integer" },
        { "key": "5", "label": "M = 100 での命中確率 [-]", "type": "number", "format": digits4 }
    ]),
    vec![(
        dim,
        basin_radius,
        fraction,
        target_probability,
        RealScalar::ceil(required) as u64,
        hit(100.0)
    )],
    metadata = serde_json::json!({ "id": "hit" })
);
```

既定の $d = 5$、$r = 0.4$ では体積比は $p_5 = 1.68 \times 10^{-3}$ で、$q = 0.95$ に必要な開始点は 1778 点、100 点での命中確率は 0.155 にとどまる。
$d = 1$ では $p_1 = 0.4$ で 6 点、$d = 12$ では $p_{12} = 5.5 \times 10^{-9}$ で約 5.5 億点が必要になる。
半径を $r = 0.9$ に広げると $d = 5$ でも $p_5 = 0.0971$ で、必要な開始点は 30 点になる。
曲線は $M \approx 1/p_d$ の付近で 0 から 1 へ立ち上がるので、次元が 1 増えるごとに立ち上がりの位置が右へずれる。

## 大域探索と局所最適化

大域探索の方法は、どの谷が深いかを見つけることには向くが、局所最小点の近くで解の精度を改善する速さは局所ソルバーに劣る。
そこで、次の二段階に分けることが多い。

1. 大域探索：控えめな評価回数で大域探索を行い、深い谷の近くの点を得る。
2. 局所最適化：その点を初期値として準 Newton 法や Newton 法を実行し、局所ソルバーの停止判定（`GradientSmall` など）まで詰める。

[複数開始点法](../multistart/)はこの二段階を開始点ごとに行う方法であり、dual annealing と CMA-ES は最後や途中に局所最適化を組み込める。
局所最適化の成功はその谷の中での一次の停留性を示すだけで、谷が大域的最小点を含むことは示さない。

## 大域探索法の位置づけ

SciOxide の大域探索法はどれも有限の箱の上で動き、大域最適性の証明は返さない。

| 方法 | 探索の仕組み | 向く問題と注意 |
|---|---|---|
| `MultiStart`（[複数開始点法](../multistart/)） | 開始点の設計から局所ソルバーを独立に走らせる | 局所ソルバーが速く、吸引域が大きい問題。開始点の数は体積比で決まる |
| `DifferentialEvolution`（[差分進化法](../differential-evolution/)） | 集団の差ベクトルで変異し、交叉と一対一の選択で集団を更新する | 微分のない連続な黒箱関数。最良点は局所最適化で詰める |
| `BasinHopping`（[basin hopping](../basin-hopping-and-annealing/)） | 局所解をずらして局所最小化し、Metropolis 則で受理する | 局所解が階段状に並ぶ地形。温度は目的値の単位を持つ |
| `DualAnnealing`（[dual annealing](../basin-hopping-and-annealing/)） | 一般化焼きなましの訪問分布と冷却、再加熱に局所最適化を組み合わせる | 粗い大域探索と局所最適化を一度に行いたい場合 |
| `Direct`（[DIRECT](../deterministic-and-surrogate-global/)） | 箱を長方形に分割し、中心の値と大きさから分割する長方形を決める | 低次元で、乱数を使わずに再現したい場合 |
| `Shgo`（[SHGO](../deterministic-and-surrogate-global/)） | 標本点の Delaunay 分割から極小の候補を選び、局所ソルバーで精度を改善する | 低次元で、複数の極小点の一覧が欲しい場合 |
| `SurrogateSearch`（[サロゲートモデルによる探索](../surrogate-search/)） | 観測から kriging か RBF のサロゲートモデルを当てはめ、獲得関数が最大の点を評価する | 一回の評価コストが大きく、評価回数を少なくしたい場合 |
| `CmaEs`（[CMA-ES](../cma-es/)） | 多変量正規分布から子を作り、共分散行列とステップ幅を適応させる | 変数間の相関が強い連続な黒箱関数 |

ワンショット関数 `minimize_global(f, &bounds, seed)` は、上下端の組の列とシードから既定の設定の差分進化を作り、箱の中点を集団の最初の個体にして解く。
設定や局所ソルバーを選ぶ場合は、表の手法オブジェクトを作る。

## まとめ

一様な開始点で吸引域に当たる確率は体積比 $p$ で決まり、命中確率 $q$ に必要な開始点の数はおよそ $-\ln(1-q)/p$ である。
体積比は次元とともに指数関数的に小さくなるので、高次元で小さな吸引域を一様な開始点だけで当てるのは難しい。
有限回の評価では大域最適性を証明できないので、SciOxide の大域探索は成功の終了を返さず、観測した最良点を候補として返す。
候補は局所最適化で詰め、既知の性質、別のシード、別の方法で確かめる。
方法は局所ソルバーの速さ、評価コスト、次元、再現性の要求に応じて上の表から選ぶ。

## 次に読むページ

- [複数開始点法](../multistart/)：開始点の設計、乱数源、局所ソルバーの差し替えと、開始点ごとのレポートの読み方を確かめる。
- [差分進化法](../differential-evolution/)：集団の差ベクトルによる変異、交叉、選択と、世代ごとの受理と広がりを確かめる。
- [basin hopping と dual annealing](../basin-hopping-and-annealing/)：局所解の連鎖を温度で受理する探索と、一般化焼きなましの温度の下げ方を確かめる。
- [DIRECT と SHGO による大域探索](../deterministic-and-surrogate-global/)：乱数を使わない領域分割と、標本の幾何から極小の候補を選ぶ方法を確かめる。
- [サロゲートモデルによる探索](../surrogate-search/)：評価の評価コストが大きい目的で、サロゲートモデルと獲得関数から次の評価点を選ぶ方法を確かめる。
- [CMA-ES](../cma-es/)：探索分布の共分散を集団から学ぶ方法を確かめる。
