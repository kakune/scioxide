当てはめの残差を小さくできても、各母数がデータから一意に決まるとは限らない。
これを識別可能性（identifiability）の問題と呼ぶ。
例えば指数減衰 $y(t) = A e^{-k t}$ を区間 $[0,T]$ で観測し、$kT \ll 1$ なら $A e^{-k t} \approx A - (A k) t$ である。
データから読み取れるのはおよそ切片 $A$ と傾き $-Ak$ だけで、$k$ の情報は傾きにしか現れない。
$k$ を $\delta k$ だけ増やし、区間の中ほどの値 $Ae^{-kT/2}$ が変わらないように $A$ も増やすと、予測の変化はおよそ $Ae^{-kt}\,\delta k\,(T/2-t)$ で、その大きさは $T$ に比例して小さく、ノイズに埋もれやすい。

一般に、予測 $\mathbf{m}(\boldsymbol\theta)\in\mathbb{R}^m$ の母数 $\boldsymbol\theta\in\mathbb{R}^n$ に関するヤコビ行列 $\mathbf{J}$ に $\mathbf{J}\mathbf{v}\approx\mathbf{0}$ を満たす方向 $\mathbf{v}$ があると、その方向に母数を動かしても予測はほとんど変わらない。
これが推定点の近くでの識別の難しさ（局所的な識別可能性の欠如）である。
このページでは[非線形最小二乗法](../nonlinear-least-squares/)で得た推定点での線形化を使い、特異値、共分散、プロファイル尤度の三つの見方で識別可能性を読む。
推定した母数を scioxide-stats の推定へ渡す型は、[統計推定へのソルバーの受け渡し](../statistical-fitting-solvers/)で扱う。

## 特異値と共分散

推定点 $\hat{\boldsymbol\theta}$ の近くでは、予測の変化は $\delta\mathbf{m}\approx\mathbf{J}\,\delta\boldsymbol\theta$ と近似できる。
特異値分解 $\mathbf{J}=\mathbf{U}\boldsymbol\Sigma\mathbf{V}^\mathsf{T}=\sum_i\sigma_i\mathbf{u}_i\mathbf{v}_i^\mathsf{T}$（$\sigma_1\ge\dots\ge\sigma_n\ge0$）を使うと、右特異ベクトル $\mathbf{v}_i$ の方向へ母数を単位長だけ動かしたときの予測の変化の大きさは $\sigma_i$ である。
小さい特異値に対応する右特異ベクトルが、弱くしか観測されない母数の組合せである。
閾値 $\tau$ を超える特異値の数を数値階数と呼ぶ。
数値階数が $n$ より小さければ、少なくとも一つの組合せは観測で決まらない（線形化の範囲での構造的な非識別）。
$\mathbf{J}^\mathsf{T}\mathbf{J}$ を作ってから条件数を測ると条件数を二乗してしまうので、識別の診断では $\mathbf{J}$ 自体の特異値を見る。
単位を変えると列の尺度が変わり、特異値と条件数 $\kappa_2(\mathbf{J})=\sigma_1/\sigma_n$ も変わるので、母数の尺度を明示して比べる。

独立で等分散のノイズ、正しいモデル、全列階数、局所線形近似の妥当性を仮定すると、母数の共分散は

$$
\widehat{\operatorname{Cov}}(\hat{\boldsymbol\theta}) = s^2(\mathbf{J}^\mathsf{T}\mathbf{J})^{-1} = s^2\,\mathbf{J}^{+}\mathbf{J}^{+\mathsf{T}} = s^2\sum_i\frac{\mathbf{v}_i\mathbf{v}_i^\mathsf{T}}{\sigma_i^2}, \qquad s^2=\frac{\|\mathbf{r}(\hat{\boldsymbol\theta})\|^2}{m-n}
$$

で近似できる（$\mathbf{J}^{+}$ は擬似逆行列、$s^2$ はノイズの分散を推定した値）。
方向 $\mathbf{v}_i$ に沿った母数の組合せの標準誤差は $s/\sigma_i$ なので、特異値が小さい方向ほど不確かさが大きい。
母数ごとの標準誤差 $\mathrm{SE}(\theta_j)$ は対角成分の平方根、相関は非対角成分を二つの標準誤差で割った値である。
相関の絶対値が 1 に近いほど、二つの母数を分けにくい。
$n=2$ では、母数の相関はヤコビ行列の二つの列のなす角の余弦と符号が逆で大きさが等しい（$2\times2$ 行列を逆にすると非対角成分の符号が反転するため）。
残差を測定の不確かさ $\sigma_i$ で割って無次元化した場合は、モデルと $\sigma_i$ が正しければ $s^2\approx1$ になることも確かめられる。

境界にある解、階数の不足、強い非線形性では、この近似をそのまま使えない。
その場合は、プロファイル、リサンプリング、観測範囲の変更で解の不確かさを調べる。

## プロファイル尤度との関係

ノイズが分散 $\sigma^2$ の正規分布に従うなら、負の対数尤度は $\Phi(\boldsymbol\theta)/\sigma^2$ に定数を足したものになる（$\Phi=\tfrac12\|\mathbf{r}\|^2$）。
一つの母数 $\theta_j$ を固定して残りを最適化したプロファイル $\Phi_{\mathrm{prof}}(\theta_j)=\min_{\boldsymbol\theta_{-j}}\Phi$ を使うと、尤度比の統計量

$$
\Lambda(\theta_j) = \frac{2\,(\Phi_{\mathrm{prof}}(\theta_j)-\Phi(\hat{\boldsymbol\theta}))}{s^2}
$$

は、真の $\theta_j$ で近似的に自由度 1 の $\chi^2$ 分布に従う。
$\Lambda\le3.84$（$\chi^2_1$ の 95% 点）の範囲が、およそ 95% の信頼区間になる。
モデルが母数について線形なら $\Lambda=((\theta_j-\hat\theta_j)/\mathrm{SE}(\theta_j))^2$ の放物線になり、この区間は Wald 区間 $\hat\theta_j\pm1.96\,\mathrm{SE}(\theta_j)$ と一致する。
二つが食い違えば、線形化が区間の幅で成り立っていないことを示す。
プロファイルが平らで $3.84$ に届かなければ、その母数は観測からほとんど決まらない。
[酵素反応の例題](../../examples/enzyme-identifiability/)では観測範囲を変えて二つの母数の感度を比べる。
[薬物動態の例題](../../examples/pharmacokinetics-sampling-design/)では次のセルと同じ形の一室モデル $C_0e^{-kt}$ で、観測終端とプロファイル目的の谷の幅の関係を調べる。

## 観測区間による特異値と信頼区間の変化

指数減衰 $y=Ae^{-kt}$（真の値 $A=2$ [濃度]、$k=0.35$ h$^{-1}$）を $[0,T]$ の 21 点で観測し、標準偏差 0.04 [濃度] の正規ノイズを加える。
入力は観測終端 $T$ [h] とノイズの擬似乱数のシードである。
既定の `LeastSquares`（LM 法）で当てはめ、推定点のヤコビ行列を `ThinSvdDecomposition` で分解して、特異値、数値階数、擬似逆行列から作った共分散による標準誤差と相関を求める。
当てはめが成功の判定を満たさなければ、セルはエラーで止まる。
$k$ のプロファイルは、$k$ を固定すると $A$ が閉じた形 $A(k)=\sum_i e^{-kt_i}y_i/\sum_i e^{-2kt_i}$ で求まることを使って、式で計算する。
図は $\Lambda(k)$ と、共分散から作った放物線（破線）を重ね、$\chi^2_1$ の 95% 点 3.84 と真の $k$ を基準線で示す。
一つ目の表は特異値と推定値・標準誤差、二つ目の表は相関、$s$、Wald 区間と、$\Lambda\le3.84$ から読んだプロファイル区間（Λ 区間）である。
プロファイル区間が $k$ の格子 $[0.05, 0.8]$ の端に達した場合は、区間が格子の外まで伸びるので、その端を「格子外」と表示する。

//|       - {"artifact":"intervals","path":"/rows/0/4","approx":{"value":0.3256,"atol":3e-3}}

use scioxide_core::RealScalar;
use scioxide_linalg::{Matrix, RankPolicy, ThinSvdDecomposition};
use scioxide_optimize::{LeastSquares, LeastSquaresFn, LeastSquaresOptions};
use scioxide_random::{Distribution, Normal, SeedableRng, SplitMix64};

let sig4 = serde_json::json!({ "significantDigits": 4 });
let sig5 = serde_json::json!({ "significantDigits": 5 });
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
// 観測 y_i = 2 e^{−0.35 t_i} + 0.04 z_i（z_i は標準正規、シードは入力）を [0, T] の 21 点で得る。
let (m, noise) = (21_usize, 0.04_f64);
let times: Vec<f64> = (0..m)
    .map(|i| observation_end * i as f64 / (m - 1) as f64)
    .collect();
let mut rng = SplitMix64::from_seed(seed as u64);
let z = Normal::new(0.0_f64, 1.0)
    .map_err(|e| e.to_string())?
    .sample_n(&mut rng, m)
    .map_err(|e| e.to_string())?;
let data: Vec<f64> = times
    .iter()
    .zip(&z)
    .map(|(&t, &e)| 2.0 * RealScalar::exp(-0.35 * t) + noise * e)
    .collect();
let jacobian_at = |p: &[f64], t: &[f64]| -> Vec<f64> {
    t.iter()
        .flat_map(|&ti| {
            let e = RealScalar::exp(-p[1] * ti);
            [e, -p[0] * ti * e]
        })
        .collect()
};
let (rt, ry, jt) = (times.clone(), data.clone(), times.clone());
let problem = LeastSquaresFn::new::<f64>(2, m, move |p: &[f64], r: &mut [f64]| {
    for ((ri, &t), &y) in r.iter_mut().zip(&rt).zip(&ry) {
        *ri = p[0] * RealScalar::exp(-p[1] * t) - y;
    }
    Ok(())
})
.map_err(|e| e.to_string())?
.with_jacobian(move |p: &[f64], j: &mut Matrix<f64>| {
    j.as_mut_slice().copy_from_slice(&jacobian_at(p, &jt));
    Ok(())
});
let result = LeastSquares::new(LeastSquaresOptions::default())
    .map_err(|e| e.to_string())?
    .solve(&problem, &[1.5, 0.2])
    .map_err(|e| e.to_string())?;
result.require_success().map_err(|e| e.to_string())?;
let fit = result.x().to_vec();
let cost = result.cost().map_err(|e| e.to_string())?;

// 推定点のヤコビ行列の特異値と、共分散 s² (JᵀJ)⁻¹ = s² J⁺ J⁺ᵀ（s² = ‖r‖² / (m − 2)）。
let j = Matrix::from_vec(m, 2, jacobian_at(&fit, &times)).map_err(|e| e.to_string())?;
let svd = ThinSvdDecomposition::compute(&j).map_err(|e| e.to_string())?;
let sigma = svd.singular_values().to_vec();
let rank = svd
    .analyze_rank(RankPolicy::DimensionScaledEpsilon)
    .map_err(|e| e.to_string())?
    .rank();
let pinv = svd
    .pseudoinverse(RankPolicy::DimensionScaledEpsilon)
    .map_err(|e| e.to_string())?;
let s2 = 2.0 * cost / (m - 2) as f64;
let p = pinv.as_slice();
let cov = |a: usize, b: usize| s2 * (0..m).map(|i| p[a * m + i] * p[b * m + i]).sum::<f64>();
let (se_a, se_k) = (RealScalar::sqrt(cov(0, 0)), RealScalar::sqrt(cov(1, 1)));
let correlation = cov(0, 1) / (se_a * se_k);

// 比較用（式）: k を固定して A を閉じた形で消去したプロファイル Φ_prof(k) と、
// 尤度比の統計量 2(Φ_prof(k) − Φ̂)/s²。線形化では ((k − k̂)/SE_k)² の放物線になる。
let profile = |k: f64| {
    let w: Vec<f64> = times.iter().map(|&t| RealScalar::exp(-k * t)).collect();
    let a = w.iter().zip(&data).map(|(u, y)| u * y).sum::<f64>()
        / w.iter().map(|u| u * u).sum::<f64>();
    w.iter()
        .zip(&data)
        .map(|(u, y)| 0.5 * (a * u - y) * (a * u - y))
        .sum::<f64>()
};
let grid: Vec<f64> = (0..=400).map(|i| 0.05 + 0.75 * i as f64 / 400.0).collect();
let statistic: Vec<[f64; 2]> = grid
    .iter()
    .map(|&k| [k, 2.0 * (profile(k) - cost) / s2])
    .collect();
let quadratic: Vec<[f64; 2]> = grid
    .iter()
    .map(|&k| [k, ((k - fit[1]) / se_k) * ((k - fit[1]) / se_k)])
    .collect();
// χ²₁ の 95% 点 3.84 以下の範囲。格子の端に達した端点は格子の外まで伸びるので None にする。
let inside: Vec<usize> = (0..grid.len())
    .filter(|&i| statistic[i][1] <= 3.84)
    .collect();
let low = inside.first().filter(|&&i| i > 0).map(|&i| grid[i]);
let high = inside
    .last()
    .filter(|&&i| i + 1 < grid.len())
    .map(|&i| grid[i]);
emit_line_chart!(
    &vec![
        serde_json::json!({"name": "プロファイル尤度比 2(Φ_prof − Φ̂)/s²", "points": statistic}),
        serde_json::json!({
            "name": "線形化（共分散）の放物線",
            "points": quadratic,
            "style": {"lineType": "dashed"}
        }),
    ],
    options = &serde_json::json!({
        "xLabel": "固定した減衰率 k [1/h]",

        "xMin": 0.05,
        "xMax": 0.8,
        "yMin": 0.0,
        "yMax": 10.0,
        "annotations": [
            {"kind": "line", "axis": "y", "value": 3.84, "label": "χ²₁ の 95% 点"},
            {"kind": "line", "axis": "x", "value": 0.35, "label": "真の k"}
        ]
    })
);

    { "key": "0", "label": "σ₁ [-]", "type": "number", "format": sig4 },

    { "key": "2", "label": "κ₂(J) [-]", "type": "number", "format": sig4 },
    { "key": "3", "label": "数値階数", "type": "integer" },
    { "key": "4", "label": "推定 A [濃度]", "type": "number", "format": sig5 },
    { "key": "5", "label": "SE(A) [濃度]", "type": "number", "format": sci3 },

既定の $T=3$ h、シード 7 では $\sigma_1=7.94$、$\sigma_2=1.84$、$\kappa_2(\mathbf{J})=4.3$、数値階数 2 で、推定は $k=0.3441\pm0.0101\,\mathrm{h^{-1}}$（推定値 ± 標準誤差）、$\mathrm{corr}(A,k)=0.77$ である。
$s=0.049$ は加えたノイズの標準偏差 0.04 と同程度である。
Wald 区間 $[0.324, 0.364]$ とプロファイル区間 $[0.326, 0.363]$ はほぼ一致し、どちらも真の 0.35 を含む。
$T=0.3$ h では $\sigma_2$ が 0.76 に下がり、$\mathrm{SE}(k)=0.062\,\mathrm{h^{-1}}$ と約 6 倍に広がり、相関は 0.85 に近づく。
観測区間が短いと減衰の曲がりが見えず、$A$ と $k$ を同時に動かしても予測がほとんど変わらないからである。
[非線形最小二乗法の例](oxref:optimize-least-squares-identifiability)の $T=0.3$ h でのヤコビ行列の列の相関 $-0.846$ と、ここでの母数の相関 $0.847$ は、観測のずれが違うので完全には一致しないが、符号が逆でほぼ同じ大きさになる。

シードを変えると推定値は標準誤差の程度で動く（シード 1 では $k=0.363$）。
区間が真の値を含むかどうかはシードごとに変わる確率的な結果で、一つのシードの結果からは被覆率を判断できない。
被覆率を確かめるには、多数のシードで区間を作り直し、真の値を含む割合を数える。

## 不足決定の最小ノルム補正

数値階数が母数の数より小さい極端な場合として、一つの残差 $x_1+x_2-a$ を二つの母数で最小化する。
入力は観測された和 $a$ で、初期値は零である。
残差の数 1 が母数の数 2 より少ないので、`LeastSquares` は SVD による最小ノルムの刻みを使う。
既定では勾配の判定で止まった点の分解を残さないので、`with_condition_estimation(Estimation::Estimate)` を指定して最終の線形化の数値階数を結果に残す。
和が $a$ になる解は無数にあり、零から最小ノルムの補正を選ぶと $(a/2,a/2)$ になることを独立に検算する。
出力は二つの母数、和の残差、最小ノルム解との差、数値階数とその最大値、終了理由の表である。

```rust
//| id: optimize-underdetermined-minimum-norm
//| ref: optimize-underdetermined-minimum-norm
//| title: 一つの観測から二母数の最小ノルム補正を選ぶ
//| run: reactive
//| crates: [scioxide-optimize, scioxide-linalg]
//| inputs:
//|   target_sum: {"type":"range","label":"観測された和 a [-]","description":"一つの観測が与える和を変える。","min":1,"max":6,"step":0.5,"value":4}
//| cases:
//|   - {"id":"sum-one","label":"a = 1","description":"最小ノルム解は (0.5, 0.5) に移るが、数値階数は 1 のまま変わらない。","inputs":{"target_sum":1}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"minimum-norm","path":"/rows/0/0","approx":{"value":2.0,"atol":1e-12}}
//|       - {"artifact":"minimum-norm","path":"/rows/0/1","approx":{"value":2.0,"atol":1e-12}}
//|       - {"artifact":"minimum-norm","path":"/rows/0/3","range":{"min":0,"max":1e-12}}
//|       - {"artifact":"minimum-norm","path":"/rows/0/4","equals":1}
//|       - {"artifact":"minimum-norm","path":"/rows/0/6","equals":"GradientSmall"}
//|   - case: sum-one
//|     expect:
//|       - {"artifact":"minimum-norm","path":"/rows/0/0","approx":{"value":0.5,"atol":1e-12}}
//|       - {"artifact":"minimum-norm","path":"/rows/0/4","equals":1}
use scioxide_linalg::{Estimation, Matrix};
use scioxide_optimize::{
    LeastSquares, LeastSquaresFn, LeastSquaresGlobalization, LeastSquaresOptions,
};

let sig6 = serde_json::json!({ "significantDigits": 6 });
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let a = target_sum;
let problem = LeastSquaresFn::new(2, 1, move |x: &[f64], r: &mut [f64]| {
    r[0] = x[0] + x[1] - a;
    Ok(())
})
.map_err(|e| e.to_string())?
.with_jacobian(|_x: &[f64], j: &mut Matrix<f64>| {
    j.as_mut_slice().copy_from_slice(&[1.0, 1.0]);
    Ok(())
});
// 残差数 1 < 母数 2 なので、Gauss–Newton は SVD による最小ノルムの刻みを使う。
// 既定では勾配で止まった点の分解を残さないので、条件数推定を要求して数値階数を残す。
let result = LeastSquares::new(
    LeastSquaresOptions::default()
        .with_globalization(LeastSquaresGlobalization::gauss_newton())
        .with_condition_estimation(Estimation::Estimate),
)
.map_err(|e| e.to_string())?
.solve(&problem, &[0.0, 0.0])
.map_err(|e| e.to_string())?;
let rank = result
    .rank()
    .ok_or("最終の線形化の階数のレポートがない".to_string())?;
let x = result.x();
// 独立な検算: 和が a になる解のうち零からの距離が最小の点は (a/2, a/2)。
let columns = serde_json::json!([
    { "key": "0", "label": "x₁ [-]", "type": "number", "format": sig6 },
    { "key": "1", "label": "x₂ [-]", "type": "number", "format": sig6 },
    { "key": "2", "label": "|x₁ + x₂ − a| [-]", "type": "number", "format": sci2 },
    { "key": "3", "label": "(a/2, a/2) との差の最大 [-]", "type": "number", "format": sci2 },
    { "key": "4", "label": "数値階数", "type": "integer" },
    { "key": "5", "label": "最大の階数", "type": "integer" },
    { "key": "6", "label": "終了理由" }
]);
emit_table_with_columns!(
    columns,
    vec![(
        x[0],
        x[1],
        (x[0] + x[1] - a).abs(),
        (x[0] - a / 2.0).abs().max((x[1] - a / 2.0).abs()),
        rank.rank(),
        rank.maximum_rank(),
        result.termination().to_string()
    )],
    metadata = serde_json::json!({ "id": "minimum-norm" })
);
```

既定の $a=4$ では、母数は $(2, 2)$ と $10^{-15}$ の程度で一致し、終了理由は `GradientSmall` である。
ヤコビ行列 $[1\ 1]$ の数値階数は 1 で、母数の数 2 より小さい。
特異値 0 に対応する方向 $(1,-1)/\sqrt2$ に母数を動かしても残差は変わらないので、この方向はデータから決まらない。
最小ノルム解を選んだのは初期値からの補正の決め方であって、データが二つの母数を個別に決めたわけではない。

## まとめ

小さい残差は個々の母数が決まったことを意味しないので、推定点のヤコビ行列の特異値と数値階数を `ThinSvdDecomposition` や `LeastSquaresResult::rank()`（`Estimation::Estimate` を指定した場合）で確かめる。
標準誤差と相関は $s^2(\mathbf{J}^\mathsf{T}\mathbf{J})^{-1}$ から読めるが、独立な正規ノイズ、正しいモデル、全列階数、線形化の妥当性を仮定した近似である。
プロファイル尤度の区間が Wald 区間と一致すれば線形化を使ってよく、平らなプロファイルや 1 に近い相関は、観測区間や実験配置を見直す合図になる。
数値階数が母数の数より小さい場合は、最小ノルム解が返っても、決まらない方向が残っていると読む。
