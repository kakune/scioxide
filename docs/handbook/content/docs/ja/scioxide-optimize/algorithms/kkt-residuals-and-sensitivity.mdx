[非線形制約と KKT 条件](../nonlinear-constraints/)で導いた 4 つの条件は、数値計算では残差として近似的にしか満たされない。
このページでは、SciOxide の制約付きソルバーがその残差をどう定義し、どの基準で `Converged` を返すかを説明する。
最後に、解析解のある問題で、示された残差と乗数を独立に計算し直し、乗数が最適値の感度であることを確かめる。

## KKT 残差と終了判定

導関数を使う制約付きソルバー（`PenaltyMethod`、`AugmentedLagrangian`、`Sqp`、`InteriorPoint`）は、KKT 条件の各残差を `OptimizeResult::diagnostics()` が返す `OptimalityDiagnostics` に分けて返す。
残差の定義は次のとおりで、どれも 0 以上の値である。

| 残差 | 読み出し | 定義 |
|---|---|---|
| 主実行可能性 | `primal_feasibility()` | $\max_i\lvert c_i\rvert$、$\max_j\max(0,g_j)$、箱の違反の最大値 |
| 停留性 | `stationarity()` | $\lVert\nabla_{\mathbf{x}}\mathcal{L}\rVert_2$（境界の乗数の項を含む） |
| 双対実行可能性 | `dual_feasibility()` | 不等式と境界の乗数の $\max(0,-\mu_j)$ の最大値 |
| 相補性 | `complementarity()` | $\max_j\lvert\mu_jg_j\rvert$（境界も同じ形） |
| 箱の違反 | `bound_violation()` | 変数が上下限を超えた量の最大値 |

値が `None` の残差は評価していないことを表し、0 を意味しない。
関数値だけを使う `Cobyla` と `Cobyqa` は元の導関数を観測しないので、`stationarity()` は `None` になる。

目的と制約の尺度をそろえるため、4 つのソルバーは初期点の導関数から問題を正規化する。
`Sqp` では箱に射影した初期点、`InteriorPoint` では箱の内側へ移した初期点の導関数を使う。
目的は $f_s=\max_k\lvert\partial f/\partial x_k(\mathbf{x}_0)\rvert$ で割り、各制約の行はその行の勾配の最大絶対値で割る。
勾配が 0 の行はその値の絶対値で割り、それも 0 なら尺度を 1 にする。
勾配が 0 の目的は `PenaltyMethod` と `AugmentedLagrangian` では 1、`Sqp` と `InteriorPoint` では $\max(1,\lvert f(\mathbf{x}_0)\rvert)$ で割る。
尺度は初期点で固定し、反復の途中では変えない。

終了判定はこの正規化した問題で行う。
各残差 $r$ は絶対許容誤差 $a$ と相対許容誤差 $b$ から作った閾値 $a + b\,s$ と比べる。
基準量 $s$ は主実行可能性では $\max(1,\lVert\mathbf{x}\rVert_\infty)$、停留性では $\lVert\nabla f\rVert_2 + \sum_i\lvert\lambda_i\rvert\lVert\nabla c_i\rVert_2$（境界の乗数の大きさを加える）、相補性では $\lvert f\rvert$、双対実行可能性では乗数の最大絶対値で、どれも正規化した量である。
`OptimalityTolerances` の既定はどの役割でも $a=b=\sqrt{\varepsilon_{\mathrm{mach}}}\approx1.49\times10^{-8}$（$\varepsilon_{\mathrm{mach}}$ は倍精度の計算機イプシロン）である。
`Converged` は、すべての残差がそれぞれの閾値以下になったときだけ返る。

一方、`diagnostics()` が返す残差は元の単位に戻した値である。
停留性と相補性は正規化した値に $f_s$ を掛け、主実行可能性は元の制約値から、双対実行可能性は元の単位に戻した乗数から計算し直す。
そのため、示された残差を許容誤差と直接比べると、正規化の倍率の分だけ食い違うことがある。

`SqpState` と `InteriorPointState` が返す乗数も、正規化を戻した元の単位の値である。
乗数は制約の定数倍に応じて逆数倍になるので（[非線形制約と KKT 条件](oxref:optimize-kkt-conditions)）、物理的な張力やシャドープライスとして解釈するときは、自分で制約を何倍したかに合わせて換算する。

## KKT 条件と感度の実験

点 $\mathbf{p}=(a,\,0.5)$ に最も近い単位円板上の点を求める。

$$
\min_{x,y}\ (x-a)^2+(y-0.5)^2
\quad\text{subject to}\quad
g_1 = x^2+y^2-1-\varepsilon \le 0,\quad
g_2 = y-1 \le 0
$$

$r=\lVert\mathbf{p}\rVert_2>1$ なら、解は $\mathbf{x}^*=\mathbf{p}/r$、乗数は $\mu_1^*=r-1$、$\mu_2^*=0$、最適値は $f^*=(r-1)^2$ である。
$r\le1$ なら $\mathbf{p}$ 自身が解で、両方の乗数は 0 になる。
$g_2$ は解で能動にならず、相補性によって乗数が 0 になることを確かめるために置く。
制約を $\varepsilon$ だけ緩めると円板の半径は $\sqrt{1+\varepsilon}$ になり、$\mathrm{d}f^*/\mathrm{d}\varepsilon=-\mu_1^*$ が成り立つ。

次のブロックは二つのセルが共有する定義である。
`solve_disk(a, relax)` は $\varepsilon$ を `relax` とした問題を `Sqp` で原点から解き、結果と受理点の乗数 $(\mu_1,\mu_2)$ を返す。

```rust
//| id: optimize-kkt-disk-model
//| kind: definitions
//| title: 円板への射影問題を Sqp で解く
//| crates: [scioxide-core, scioxide-optimize]
use scioxide_core::ExecutionContext;
use scioxide_optimize::{
    ConstrainedProblem, ConstraintFn, Constraints, ObjectiveFn, OptimizeResult, Sqp,
};

/// 点 (a, 0.5) への距離の二乗を g₁ = x² + y² − 1 − relax ≤ 0 と g₂ = y − 1 ≤ 0 のもとで最小にする。
pub(crate) fn solve_disk(a: f64, relax: f64) -> Result<(OptimizeResult<f64>, Vec<f64>), String> {
    let b = 0.5;
    let objective = ObjectiveFn::new(2, move |x: &[f64]| {
        Ok((x[0] - a) * (x[0] - a) + (x[1] - b) * (x[1] - b))
    })
    .with_gradient(move |x: &[f64], g: &mut [f64]| {
        g.copy_from_slice(&[2.0 * (x[0] - a), 2.0 * (x[1] - b)]);
        Ok(())
    });
    let disk = ConstraintFn::new(2, move |x: &[f64]| {
        Ok(x[0] * x[0] + x[1] * x[1] - 1.0 - relax)
    })
    .with_jacobian(|x: &[f64], row: &mut [f64]| {
        row.copy_from_slice(&[2.0 * x[0], 2.0 * x[1]]);
        Ok(())
    });
    let cap = ConstraintFn::new(2, |x: &[f64]| Ok(x[1] - 1.0)).with_jacobian(
        |_: &[f64], row: &mut [f64]| {
            row.copy_from_slice(&[0.0, 1.0]);
            Ok(())
        },
    );
    let constraints = Constraints::new(2)
        .map_err(|e| e.to_string())?
        .inequality(disk)
        .map_err(|e| e.to_string())?
        .inequality(cap)
        .map_err(|e| e.to_string())?;
    let problem = ConstrainedProblem::new(&objective, &constraints).map_err(|e| e.to_string())?;
    let solver = Sqp::default();
    let mut work = solver.workspace(&problem).map_err(|e| e.to_string())?;
    let mut result = OptimizeResult::empty();
    solver
        .minimize_into(
            &problem,
            &[0.0, 0.0],
            &mut result,
            &mut work,
            ExecutionContext::sequential(),
        )
        .map_err(|e| e.to_string())?;
    Ok((result, work.state().multipliers().to_vec()))
}
```

最初のセルは $\varepsilon=0$ の問題を解き、点と乗数を解析解と比べる。
示された残差は返った点と乗数から上の表の定義で計算し直した値と並べる。
入力は点の $x$ 成分 $a$ で、$a$ と求めた乗数 $\mu_1$ を次のセルに渡す。

```rust
//| id: optimize-kkt-disk-residuals
//| ref: optimize-kkt-disk-residuals
//| title: 円板への射影で点・乗数・KKT 残差を解析解と比べる
//| run: reactive
//| uses: [optimize-kkt-disk-model]
//| crates: [scioxide-core, scioxide-optimize]
//| exports: [target_x, multiplier]
//| inputs:
//|   target_x: {"type":"range","label":"点の x 成分 a [-]","description":"点 (a, 0.5) が円板の外なら円板の制約が能動になる。","min":0,"max":3,"step":0.1,"value":2}
//| cases:
//|   - {"id":"inside","label":"a = 0.5（円板の内側）","description":"点が円板の内側にあり、両方の乗数が 0 になる。","inputs":{"target_x":0.5}}
//|   - {"id":"far","label":"a = 3（大きい乗数）","description":"円板の乗数は √9.25 − 1 ≈ 2.041 になる。","inputs":{"target_x":3}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"solution","path":"/rows/2/3","range":{"max":1e-8}}
//|       - {"artifact":"solution","path":"/rows/3/1","range":{"min":-1e-8,"max":1e-8}}
//|       - {"artifact":"residuals","path":"/rows/0/2","range":{"max":1e-7}}
//|       - {"path":"/outputs/2/state","equals":"satisfied"}
//|   - case: inside
//|     expect:
//|       - {"artifact":"solution","path":"/rows/0/3","range":{"max":1e-8}}
//|       - {"artifact":"solution","path":"/rows/2/1","range":{"min":-1e-8,"max":1e-8}}
//|       - {"path":"/outputs/2/state","equals":"satisfied"}
//|   - case: far
//|     expect:
//|       - {"artifact":"solution","path":"/rows/2/2","approx":{"value":2.0413812651491097,"rtol":1e-12}}
//|       - {"artifact":"solution","path":"/rows/2/3","range":{"max":1e-8}}
//|       - {"path":"/outputs/2/state","equals":"satisfied"}
use scioxide_core::RealScalar;

let (a, b) = (target_x, 0.5);
let (result, mu) = solve_disk(a, 0.0)?;
let (x, y) = (result.x()[0], result.x()[1]);
// 解析解（独立な検算）。r > 1 なら p/r に射影し、乗数は r − 1。
let r = RealScalar::sqrt(a * a + b * b);
let shrink = if r > 1.0 { 1.0 / r } else { 1.0 };
let excess = (r - 1.0).max(0.0);
let exact = [a * shrink, b * shrink, excess, 0.0, excess * excess];
let found = [x, y, mu[0], mu[1], result.fun()];
let names = ["x", "y", "円板の乗数 μ₁", "y ≤ 1 の乗数 μ₂", "最適値 f*"];
let distance = (x - exact[0]).abs().max((y - exact[1]).abs());
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let fixed10 = serde_json::json!({ "fractionDigits": 10 });
emit_table_with_columns!(
    serde_json::json!([
        { "key": "0", "label": "量" },
        { "key": "1", "label": "Sqp [-]", "type": "number", "format": fixed10 },
        { "key": "2", "label": "解析解 [-]", "type": "number", "format": fixed10 },
        { "key": "3", "label": "差 [-]", "type": "number", "format": sci3 }
    ]),
    (0..5)
        .map(|i| (names[i], found[i], exact[i], (found[i] - exact[i]).abs()))
        .collect::<Vec<_>>(),
    metadata = serde_json::json!({ "id": "solution" })
);
// 返った点と乗数から 4 つの残差を定義どおりに計算し直す（独立な検算）。
let g = [x * x + y * y - 1.0, y - 1.0];
let grad = [
    2.0 * (x - a) + 2.0 * mu[0] * x,
    2.0 * (y - b) + 2.0 * mu[0] * y + mu[1],
];
let recomputed = [
    RealScalar::sqrt(grad[0] * grad[0] + grad[1] * grad[1]),
    g[0].max(g[1]).max(0.0),
    (-mu[0]).max(-mu[1]).max(0.0),
    (mu[0] * g[0]).abs().max((mu[1] * g[1]).abs()),
];
let d = result.diagnostics();
let reported = [
    d.stationarity(),
    d.primal_feasibility(),
    d.dual_feasibility(),
    d.complementarity(),
];
let residuals = ["停留性", "主実行可能性", "双対実行可能性", "相補性"];
emit_table_with_columns!(
    serde_json::json!([
        { "key": "0", "label": "残差" },
        { "key": "1", "label": "レポート値 [-]", "type": "number", "format": sci3, "nullText": "なし" },
        { "key": "2", "label": "点と乗数からの再計算 [-]", "type": "number", "format": sci3 }
    ]),
    (0..4)
        .map(|i| (residuals[i], reported[i], recomputed[i]))
        .collect::<Vec<_>>(),
    metadata = serde_json::json!({ "id": "residuals" })
);
export!(target_x, a);
export!(multiplier, mu[0]);
let termination = result.termination();
let outcome = if termination.is_success() {
    Outcome::satisfied("KKT 残差が許容誤差を満たした")
} else {
    Outcome::partial("KKT 残差の判定を満たす前に止まった")
        .explanation("返った点と乗数は最後に受理した推定値として扱う。")
};
emit_outcome!(
    outcome
        .status(termination.to_string())
        .diagnostic("反復", result.iterations() as f64, None)
        .diagnostic("解析解との差", distance, None)
);
```

既定の $a=2$ では、`Sqp` は 4 反復で `Converged` になる。
点は解析解 $\mathbf{p}/r$（$r=\sqrt{4.25}$）と $5.2\times10^{-15}$ 以内で一致し、円板の乗数 $\mu_1=1.0615528128$ は $r-1$ と $1.6\times10^{-12}$ の差で一致する。
$g_2$ は解で $-0.76$ の非能動な制約で、その乗数は 0 になり、相補性が成り立つ。
示された 4 つの残差は返った点と乗数から計算し直した値と一致する（停留性 $3.2\times10^{-12}$、主実行可能性と相補性は $1.1\times10^{-14}$）。
レポート値が元の単位で計算されていることは、この一致から確かめられる。

$a=0.5$ では点が円板の内側にあり、1 反復で $\mathbf{p}$ に止まって両方の乗数が 0 になる。
$a=3$ では乗数 2.0413812651 が $\sqrt{9.25}-1$ と $1.2\times10^{-14}$ の差で一致する一方、点の差は $4.3\times10^{-9}$ である。
このとき停留性の残差は $2.7\times10^{-8}$ で、`Converged` の判定を満たす範囲にある。
点の精度は残差の閾値で決まり、計算機イプシロンの程度までは下がらない。

次のセルは円板の制約を $\varepsilon=\pm h$ だけ動かした二つの問題を解き、最適値の中心差分 $\{f^*(h)-f^*(-h)\}/(2h)$ を前のセルの $-\mu_1$ と比べる。
中心差分の打ち切り誤差は $O(h^2)$ で、最適値の誤差 $\delta$ は差分で $\delta/h$ に拡大される。
入力は差分の幅 $h=10^{q}$ だけで、点 $a$ と乗数は前のセルから受け取る。

```rust
//| id: optimize-kkt-disk-sensitivity
//| ref: optimize-kkt-disk-sensitivity
//| title: 制約を緩めた最適値の差分を乗数と比べる
//| run: reactive
//| uses: [optimize-kkt-disk-model]
//| crates: [scioxide-core, scioxide-optimize]
//| dependsOn:
//|   base: optimize-kkt-disk-residuals
//| inputs:
//|   step_exponent: {"type":"range","label":"差分の幅の指数 q（h = 10^q）[-]","min":-7,"max":-1,"step":1,"value":-3}
//| cases:
//|   - {"id":"narrow-step","label":"h = 10⁻⁷","description":"差は最適値の丸め誤差を 1/h で拡大した程度になる。","inputs":{"step_exponent":-7}}
//|   - {"id":"wide-step","label":"h = 10⁻¹","description":"差分の幅を広げると、打ち切り誤差 O(h²) が目立つ。","inputs":{"step_exponent":-1}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"sensitivity","path":"/rows/0/5","range":{"max":1e-5}}
//|       - {"artifact":"sensitivity","path":"/rows/0/6","equals":"Converged / Converged"}
//|   - case: narrow-step
//|     expect:
//|       - {"artifact":"sensitivity","path":"/rows/0/5","range":{"max":1e-8}}
//|   - case: wide-step
//|     expect:
//|       - {"artifact":"sensitivity","path":"/rows/0/5","range":{"min":1e-5,"max":1e-2}}
use scioxide_core::RealScalar;

let a = base["target_x"].as_f64().ok_or("点の x 成分がない")?;
let multiplier = base["multiplier"].as_f64().ok_or("乗数がない")?;
let h = RealScalar::powf(10.0, step_exponent);
let (plus, _) = solve_disk(a, h)?;
let (minus, _) = solve_disk(a, -h)?;
let slope = (plus.fun() - minus.fun()) / (2.0 * h);
let status = format!("{} / {}", plus.termination(), minus.termination());
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let fixed10 = serde_json::json!({ "fractionDigits": 10 });
emit_table_with_columns!(
    serde_json::json!([
        { "key": "0", "label": "h [-]", "type": "number", "format": sci3 },
        { "key": "1", "label": "f*(h) [-]", "type": "number", "format": fixed10 },
        { "key": "2", "label": "f*(−h) [-]", "type": "number", "format": fixed10 },
        { "key": "3", "label": "中心差分 [-]", "type": "number", "format": fixed10 },
        { "key": "4", "label": "−μ₁ [-]", "type": "number", "format": fixed10 },
        { "key": "5", "label": "差 [-]", "type": "number", "format": sci3 },
        { "key": "6", "label": "終了理由（+h / −h）" }
    ]),
    vec![(
        h,
        plus.fun(),
        minus.fun(),
        slope,
        -multiplier,
        (slope + multiplier).abs(),
        status
    )],
    metadata = serde_json::json!({ "id": "sensitivity" })
);
```

既定の $h=10^{-3}$ では、中心差分 $-1.0615530705$ が $-\mu_1$ と $2.6\times10^{-7}$ の差で一致する。
この差は中心差分の打ち切り誤差 $O(h^2)$ によるもので、$h=10^{-1}$ では $2.6\times10^{-3}$ に増え、$h$ を 100 倍にすると $10^4$ 倍になる。
$h=10^{-7}$ では差は $4.9\times10^{-10}$ まで下がる。
このとき打ち切り誤差は $h=10^{-3}$ の差から外挿して $2.6\times10^{-15}$ 程度で、最適値の丸め誤差 $\varepsilon_{\mathrm{mach}}\lvert f^*\rvert\approx2.5\times10^{-16}$ を $1/(2h)$ 倍した $1.3\times10^{-9}$ 程度が差の目安になる。
ソルバーの乗数と、制約を動かして解き直した最適値の差分は独立な量であり、両者の一致は乗数が最適値の感度であることを数値で示す。

## まとめ

`OptimizeResult::diagnostics()` は停留性、主実行可能性、双対実行可能性、相補性、箱の違反を元の単位で返し、`None` は評価していないことを表す。
`Converged` はこれらの残差を、初期点の導関数で正規化した問題で $a+b\,s$ 型の閾値と比べて判定するので、レポート値と許容誤差を比べるときは正規化の倍率を考える。
返った点と乗数があれば、残差は定義どおりに計算し直して確かめられる。
乗数は制約を緩めた最適値の差分と比べて感度として検算でき、差分の幅は打ち切り誤差と丸め誤差の兼ね合いで選ぶ。
点の精度は残差の閾値で決まるので、解析解や別の方式でも確かめる。
