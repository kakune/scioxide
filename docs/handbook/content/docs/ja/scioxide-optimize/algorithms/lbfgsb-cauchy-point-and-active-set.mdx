ボックス制約付き最小化では、最適点でどの成分が境界上にあるか（有効集合）を前もって知らない。
古典的な L-BFGS-B（Byrd–Lu–Nocedal–Zhu、以下 BLNZ）は、二次モデルの上で射影勾配の折れ線をたどって有効集合を推定し、残りの成分だけでモデルを最小にする。
SciOxide の `LbfgsB` はこの二段階を持たず、[射影 L-BFGS の一反復](oxref:optimize-lbfgsb-iteration)で説明した射影方向を使う。
このページでは古典的な二段階を導き、`LbfgsB` との違いを表にまとめ、反復で有効な境界が入れ替わる様子を障害物問題で確かめる。
記号は[ボックス制約と射影 L-BFGS](../bound-constrained-lbfgsb/)に合わせ、$\mathbf{B}_k$ はヘッセ行列の L-BFGS 近似、$P_{[\mathbf{l},\mathbf{u}]}$ は箱への射影を表す。

## 一般化 Cauchy 点

BLNZ の L-BFGS-B は現在点 $\mathbf{x}_k$ のまわりの二次モデル

$$
m_k(\mathbf{x})=f_k+\mathbf{g}_k^\mathsf{T}(\mathbf{x}-\mathbf{x}_k)+\tfrac12(\mathbf{x}-\mathbf{x}_k)^\mathsf{T}\mathbf{B}_k(\mathbf{x}-\mathbf{x}_k)
$$

を使う（$\mathbf{B}_k$ は正定値）。
最初の段階では射影した最急降下の折れ線 $\mathbf{x}(t)=P_{[\mathbf{l},\mathbf{u}]}(\mathbf{x}_k-t\mathbf{g}_k)$（$t\ge0$）の上で $m_k$ の最初の極小点を探す。
成分 $i$ が境界に達する時刻（区切り点）は

$$
t_i=\begin{cases}(x_i-u_i)/g_i & (g_i<0)\\ (x_i-l_i)/g_i & (g_i>0)\\ \infty & (g_i=0)\end{cases}
$$

で、区切り点を小さい順に並べると、隣り合う区切り点の間で折れ線は直線になる。
区間 $[t_{j-1},t_j]$ では、まだ境界に達していない成分だけが $-g_i$ の向きに動く。
この向きを $\mathbf{d}^{(j)}$、区間の始点を $\mathbf{x}^{(j)}$、$\mathbf{z}^{(j)}=\mathbf{x}^{(j)}-\mathbf{x}_k$ とすると、区間の中のモデルは $\Delta t=t-t_{j-1}$ の一変数二次関数

$$
m_k(\mathbf{x}^{(j)}+\Delta t\,\mathbf{d}^{(j)}) = m_k(\mathbf{x}^{(j)}) + f'_j\,\Delta t + \tfrac12 f''_j\,\Delta t^2,\qquad
f'_j=\mathbf{g}_k^\mathsf{T}\mathbf{d}^{(j)}+\mathbf{d}^{(j)\mathsf{T}}\mathbf{B}_k\mathbf{z}^{(j)},\quad f''_j=\mathbf{d}^{(j)\mathsf{T}}\mathbf{B}_k\mathbf{d}^{(j)}
$$

になる。
$f'_j\ge0$ なら区間の始点が極小点であり、そうでなければ $\Delta t^*=-f'_j/f''_j$ が区間の長さ $t_j-t_{j-1}$ より短いときに区間の内部で止まる。
どちらでもなければ次の区間へ進む。
こうして得た点が一般化 Cauchy 点 $\mathbf{x}^{\mathrm{c}}$ で、$\mathbf{x}^{\mathrm{c}}$ で境界にある成分を有効集合 $\mathcal{A}$ とする。
$\mathbf{B}_k$ のコンパクト表現を使うと、区間を進むごとの $f'_j$、$f''_j$ の更新は $\mathbf{B}_k$ を作らずに行える（BLNZ 1995 の第 4 節）。

一般化 Cauchy 点は射影勾配法の一歩をモデルの上の最初の極小点まで進めた点にあたる。
射影勾配法や、一般化 Cauchy 点を使う信頼領域法では、最適点で狭義相補性（境界にある成分の乗数が正であること）が成り立てば、有限回の反復で最適点の有効集合を特定するという結果がある（Calamai–Moré 1987、Conn–Gould–Toint 1988）。
古典的な L-BFGS-B は有効集合の推定をこの点に任せる設計である。

## 部分空間の最小化

次の段階では $\mathcal{A}$ の成分を $\mathbf{x}^{\mathrm{c}}$ の値に固定し、残りの自由成分 $\mathcal{F}$ について $m_k$ を最小にする。
自由成分を取り出す行列を $\mathbf{Z}$ とすると、縮約したモデルは $\hat{\mathbf{d}}\in\mathbb{R}^{|\mathcal{F}|}$ について

$$
\hat m(\hat{\mathbf{d}})=\hat{\mathbf{r}}^\mathsf{T}\hat{\mathbf{d}}+\tfrac12\hat{\mathbf{d}}^\mathsf{T}\hat{\mathbf{B}}\hat{\mathbf{d}},\qquad
\hat{\mathbf{r}}=\mathbf{Z}^\mathsf{T}\bigl(\mathbf{g}_k+\mathbf{B}_k(\mathbf{x}^{\mathrm{c}}-\mathbf{x}_k)\bigr),\quad
\hat{\mathbf{B}}=\mathbf{Z}^\mathsf{T}\mathbf{B}_k\mathbf{Z}
$$

になり、制約を無視した最小点は $\hat{\mathbf{d}}^{\mathrm{u}}=-\hat{\mathbf{B}}^{-1}\hat{\mathbf{r}}$ である。
$\hat{\mathbf{B}}^{-1}$ はコンパクト表現に Sherman–Morrison–Woodbury の公式を当てて計算し、計算量は $|\mathcal{F}|$ に比例する項と、$m$ だけで大きさが決まる小さな行列の分解で済む。
得た点 $\mathbf{x}^{\mathrm{c}}+\mathbf{Z}\hat{\mathbf{d}}^{\mathrm{u}}$ が箱の外に出る場合は、箱の中に収まるところまで縮める。
探索方向はこの点と $\mathbf{x}_k$ の差で、刻みは強 Wolfe 条件を満たすように直線探索で選ぶ。
停止は射影勾配 $\|P_{[\mathbf{l},\mathbf{u}]}(\mathbf{x}-\mathbf{g})-\mathbf{x}\|_\infty$ が `pgtol` 以下になるか、目的の相対減少 $(f_k-f_{k+1})/\max(|f_k|,|f_{k+1}|,1)$ が `factr`$\cdot\varepsilon_{\mathrm{mach}}$ 以下になったときである。

## 古典的な L-BFGS-B との違い

`LbfgsB` と古典的な L-BFGS-B は同じボックス制約付き問題を次のように異なる手順で解く。

| 項目 | 古典的な L-BFGS-B | `LbfgsB` |
|---|---|---|
| 有効集合 | 一般化 Cauchy 点で境界にある成分 | 現在点で境界にあり、勾配が外向きの成分 |
| 探索方向 | 自由成分の部分空間でモデルを最小にした点への方向 | $-\mathbf{P}_F\mathbf{H}_k\mathbf{P}_F\mathbf{g}_k$ から外向きの成分を除き、単位ステップ幅の終点を射影した方向 |
| 刻み | 強 Wolfe 条件の直線探索 | 射影した線分上の Armijo 後退 |
| 曲率が足りない対 | 更新を飛ばす | Powell 減衰（既定 $\eta=0.2$） |
| 停止 | 射影勾配か目的の相対減少 | 射影勾配だけ |
| 射影勾配の内部の成分 | 境界までの距離で切った $\min(\lvert g_i\rvert,\text{距離})$ | $\lvert g_i\rvert$ のまま |

最後の行から、同じ許容誤差なら `LbfgsB` の停止判定は成分ごとに古典的な判定と同じか厳しい。
内部の成分では古典的な量 $|x_i-P(x_i-g_i)|$ が $|g_i|$ を超えず、境界の成分ではどちらも同じ符号条件で 0 になるからである。

`LbfgsB` には一般化 Cauchy 点がないので、上の有効集合の特定の結果や古典的な方式の収束解析はそのまま当てはまらない。
`LbfgsB` で成り立つのは、探索する方向が降下方向であること、試行点が箱の中にあること、成功の判定が元の射影勾配で行われることである。
履歴を捨てるのは数値的な破綻と降下性の喪失の場合だけなので、有効な境界の並びが落ち着いた後は、降下性を失わない限り自由な成分だけの L-BFGS として履歴を保ったまま進む。
反復数は履歴長や境界の位置によって変わり、次の例のように単調な関係にはならない。

## 反復で入れ替わる有効な境界

両端を固定した弦の 12 個の節点の変位 $x_1,\dots,x_{12}$（$x_0=x_{13}=0$）に荷重 $q_i$ を掛け、床 $x_i\ge0$ と天井 $x_i\le u$ の間に閉じ込める障害物問題を解く。

$$
\min_{0\le\mathbf{x}\le u}\ f(\mathbf{x})=\frac12\sum_{i=0}^{12}(x_{i+1}-x_i)^2-\sum_{i=1}^{12}q_ix_i, \qquad q_i=0.6\sin\frac{2\pi i}{13}+0.25
$$

量はすべて無次元である。
目的は強凸な二次関数（ヘッセ行列は差分の行列 $\mathbf{L}=\mathbf{C}^\mathsf{T}\mathbf{C}$）なので、最小点は一つに決まる。
荷重は $i\le7$ で上向き、$i\ge8$ で下向きなので、天井に触れる区間と床に触れる区間ができる。
入力は天井の高さ $u$ と履歴長 $m$ で、開始点は全成分 $u/2$ である。

独立な基準として、同じ問題を $\tfrac12\|\mathbf{C}\mathbf{x}-\mathbf{d}\|^2$（$\mathbf{C}$ は $13\times12$ の差分行列、$\mathbf{C}^\mathsf{T}\mathbf{d}=\mathbf{q}$）と書き直し、有効集合法の `BoundedLinearLeastSquares`（BVLS、[非負・境界付き線形最小二乗](../linear-least-squares/)）で解く。
$\tfrac12\|\mathbf{C}\mathbf{x}-\mathbf{d}\|^2=\tfrac12\mathbf{x}^\mathsf{T}\mathbf{L}\mathbf{x}-\mathbf{q}^\mathsf{T}\mathbf{x}+\text{定数}$ なので、二つは同じ最小点を持つ。
反復ごとの様子は反復上限を $k=1,2,\dots,50$ と変えた独立な実行の点から作る。
図は BVLS の目的値との差 $f-f^*$ と射影勾配の最大成分を対数軸で示し、停止の閾値を横線で示す。
一つ目の表は有効な境界の並びが変わった反復だけを示し、二つ目の表は既定の反復上限で解いた結果と BVLS 解との差である。

```rust
use scioxide_core::{Bounds, Budget};
use scioxide_linalg::Matrix;
use scioxide_optimize::{
    BoundedLinearLeastSquares, BoundedObjective, LbfgsB, LbfgsBOptions,
    LinearLeastSquaresProblem, ObjectiveFn, ObjectiveFunction, OptimizeTermination,
};

// 弦の変位 x_1..x_n（両端 x_0 = x_{n+1} = 0）に荷重 q を掛け、0 ≤ x ≤ u に閉じ込める。
// f(x) = ½ Σ (x_{i+1} − x_i)² − qᵀx、勾配 (L x − q)_i = 2x_i − x_{i−1} − x_{i+1} − q_i。
let n = 12_usize;
let u = ceiling;
let q: Vec<f64> = (0..n)
    .map(|i| {
        let t = (i + 1) as f64 / (n + 1) as f64;
        0.6 * scioxide_core::RealScalar::sin(2.0 * core::f64::consts::PI * t) + 0.25
    })
    .collect();
let gradient_of = |x: &[f64], q: &[f64]| -> Vec<f64> {
    (0..x.len())
        .map(|i| {
            let left = if i > 0 { x[i - 1] } else { 0.0 };
            let right = if i + 1 < x.len() { x[i + 1] } else { 0.0 };
            2.0 * x[i] - left - right - q[i]
        })
        .collect()
};
let (qf, qg) = (q.clone(), q.clone());
let objective = ObjectiveFn::new(n, move |x: &[f64]| {
    let mut energy = 0.0;
    for i in 0..=x.len() {
        let left = if i > 0 { x[i - 1] } else { 0.0 };
        let right = if i < x.len() { x[i] } else { 0.0 };
        energy += 0.5 * (right - left) * (right - left);
    }
    Ok(energy - x.iter().zip(&qf).map(|(a, b)| a * b).sum::<f64>())
})
.with_gradient(move |x: &[f64], g: &mut [f64]| {
    g.copy_from_slice(&gradient_of(x, &qg));
    Ok(())
});
let bounds = Bounds::new(vec![(Some(0.0), Some(u)); n]).map_err(|e| e.to_string())?;
let problem = BoundedObjective::new(&objective, &bounds).map_err(|e| e.to_string())?;
let start = vec![0.5 * u; n];
let memory = Budget::try_from(history as usize).map_err(|e| e.to_string())?;

// 独立な基準: 同じ問題を ½‖C x − d‖²（C は差分行列、Cᵀd = q）として BVLS で解く。
let mut c = vec![0.0_f64; (n + 1) * n];
for j in 0..n {
    c[j * n + j] = 1.0;
    c[(j + 1) * n + j] = -1.0;
}
let mut d = vec![0.0_f64; n + 1];
for i in 0..n {
    d[i + 1] = d[i] - q[i];
}
let c = Matrix::from_vec(n + 1, n, c).map_err(|e| e.to_string())?;
let linear = LinearLeastSquaresProblem::from_dense(&c, &d)
    .map_err(|e| e.to_string())?
    .with_bounds(&bounds)
    .map_err(|e| e.to_string())?;
let reference = BoundedLinearLeastSquares::<f64>::default()
    .solve(&linear)
    .map_err(|e| e.to_string())?;
if !reference.is_success() {
    return Err(format!("BVLS が収束しない: {}", reference.termination()));
}
let x_ref = reference.x();
let f_ref = objective.eval(x_ref).map_err(|e| e.to_string())?;

let pattern_of = |x: &[f64]| -> String {
    x.iter()
        .map(|&xi| {
            if xi == 0.0 {
                'L'
            } else if xi == u {
                'U'
            } else {
                '·'
            }
        })
        .collect()
};
// 射影勾配の最大成分: 下限で g ≥ 0、上限で g ≤ 0 の成分を除く（停止判定と同じ量）。
let projected_of = |x: &[f64]| -> f64 {
    x.iter()
        .zip(gradient_of(x, &q))
        .map(|(&xi, gi)| {
            if (xi == 0.0 && gi >= 0.0) || (xi == u && gi <= 0.0) {
                0.0
            } else {
                gi.abs()
            }
        })
        .fold(0.0_f64, f64::max)
};
let (mut gap, mut stationarity, mut changes) = (Vec::new(), Vec::new(), Vec::new());
let mut dropped = 0_usize;
let mut previous = pattern_of(&start);
for k in 1..=50_usize {
    let options = LbfgsBOptions::default()
        .with_memory(memory)
        .with_max_iterations(Budget::try_from(k).map_err(|e| e.to_string())?);
    let result = LbfgsB::new(options)
        .minimize(&problem, &start)
        .map_err(|e| e.to_string())?;
    let iteration = result.iterations() as f64;
    // f − f* が 0 以下になった点（丸めで BVLS の値と一致）は対数軸に描かず数える。

        gap.push([iteration, result.fun() - f_ref]);

        dropped += 1;

            result.iterations(),
            pattern.clone(),
            projected_of(result.x()),

        previous = pattern;
    }
    if result.is_success() {

    }

        dropped
    )],
    metadata = serde_json::json!({ "id": "summary" })
);
let outcome = if termination.is_success() {
    Outcome::satisfied("射影勾配が停止の閾値を下回った")
} else if matches!(termination, OptimizeTermination::LineSearchFailed(_)) {
    Outcome::failed("直線探索が受理できる刻みを見つけられなかった")
} else {
    Outcome::partial("射影勾配の判定を満たす前に止まった")
};
emit_outcome!(
    outcome
        .status(termination.to_string())
        .diagnostic("反復", last.iterations() as f64, None)
        .diagnostic("BVLS 解との差の最大", difference, None)
);
```

既定の $u=1.5$、$m=10$ では、最初の反復で 2 成分が天井、1 成分が床に触れる。
2 反復目に天井の成分は 5 個、床の成分は 2 個に増え、3〜5 反復目に床の成分が 4 個まで増えてから 3 個に戻り、天井の成分も 1 個が離れる。
5 反復目に BVLS と同じ「`·UUUU····LLL`」の並びに落ち着き、その後は自由な 5 成分だけの問題として 26 反復（目的の評価 27 回）で `GradientSmall` になる。
BVLS 解との差の最大は $5.3\times10^{-8}$ で、射影勾配の最大成分 $5.3\times10^{-8}$ は閾値 $6.2\times10^{-8}$ を下回る。
$u=0.5$ では天井に 6 成分、床に 4 成分が触れ、4 反復目に並びが落ち着いて 20 反復で止まる。
$m=1$ では 21 反復で止まり、3 反復目の並びが既定と異なる。

$u=4$ では天井に触れる成分が 3 個に減る。
2 反復目には床に触れていた成分も離れて全成分が内部に入り、7 反復目に BVLS と同じ「`··UUU·····LL`」の並びに落ち着く。
28 反復で `GradientSmall` になり、BVLS 解との差の最大は $1.9\times10^{-8}$ である。
入力の範囲（$0.5\le u\le4$、$1\le m\le10$）では反復数は 16〜42 回で、履歴長を増やしても単調には減らない。
BVLS 解との差は射影勾配の閾値と同じ程度である。
停止判定は解の誤差を直接には保証しないので、二次の問題なら有効集合法で検算できる。

## まとめ

古典的な L-BFGS-B は射影した最急降下の折れ線でモデルの最初の極小点（一般化 Cauchy 点）を求めて有効集合を決め、残りの成分でモデルを最小にする。
`LbfgsB` はこの二段階を持たず、勾配と方向の符号で成分を止め、射影した線分上の Armijo 探索で進むので、古典的な方式の有効集合の特定と収束解析は当てはまらない。
停止は射影勾配だけで判定し、内部の成分を境界までの距離で切らないので、同じ許容誤差なら古典的な判定と同じか厳しい。
有効な境界は一反復で何個でも入れ替わり、並びが落ち着いた後は自由な成分だけの L-BFGS として履歴を保ったまま進む。
二次の問題では、有効集合法の BVLS の解と比べて、終了理由と解の誤差を別々に確かめられる。
