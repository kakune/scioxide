観測 $b\in\mathbb R^m$ と設計行列 $A\in\mathbb R^{m\times n}$ に対して、$f(x)=\tfrac12\|Ax-b\|_2^2$ を最小にする。
勾配は $g=A^T(Ax-b)$ で、無制約の停留条件は正規方程式 $A^TAx=A^Tb$ になる。
このページでは無制約問題の解法と条件数、非負・ボックス制約の下での一次条件、Lawson–Hanson の NNLS と BVLS の有効集合法、SciOxide の結果の読み方を順に説明する。

## 正規方程式と QR の条件数

全列階数の場合でも $\kappa_2(A^TA)=\kappa_2(A)^2$ なので、正規方程式を作って Cholesky 分解で解くと、計算した解の相対誤差はおよそ $\kappa_2(A)^2\varepsilon_{\mathrm{mach}}$ の大きさになりうる。
$\kappa_2(A)=10^6$ なら $10^{-4}$ 程度の誤差を見込むことになり、小さい特異値の方向の情報が失われやすい。
QR 分解 $A=QR$ は $A$ を直接扱い、$Rx=Q^Tb$ を解く後退安定な方法である。
最小二乗問題そのものの解の相対的な感度は、$\theta$ を $b$ と $A$ の列空間のなす角として、およそ $\kappa_2(A)+\kappa_2(A)^2\tan\theta$ に比例する（Golub–Van Loan 5.3 節）。
残差 $\|Ax^*-b\|$ が小さく $\theta\approx0$ なら感度は $\kappa_2(A)$ の程度で、QR はこの精度を保つが、正規方程式は $\kappa_2(A)^2$ の誤差を持ち込む。
残差が大きい問題では問題自体の感度が $\kappa_2(A)^2\tan\theta$ を含むので、二つの方法の差は小さくなる。
階数不足では SVD $A=\sum_i\sigma_iu_iv_i^T$ で観測から決まる方向（$\sigma_i>\tau$）と決まらない方向を区別し、決まらない成分を 0 にした最小ノルム解を選ぶ。
密な長方形行列の Householder QR は、$m\ge n$ で約 $2mn^2-\tfrac23n^3$ flops を要する。

## 有効集合と符号条件

境界 $l\le x\le u$ の下では、KKT 条件は $g=\lambda-\mu$、$\lambda,\mu\ge0$、$\lambda_i(x_i-l_i)=0$、$\mu_i(u_i-x_i)=0$ になる（[ボックス制約の一次条件](../bound-constrained-lbfgsb/)と同じ形である）。
下限 $x_i=l_i$ では増加方向だけが許されるため、最適点での勾配は $g_i=\lambda_i\ge0$ でなければならない。
上限 $x_i=u_i$ では $g_i=-\mu_i\le0$、内部では $g_i=0$ となる。
目的が凸なので、この条件は大域最小の必要十分条件である。
解の切り詰めだけでは、列の相関によって自由成分の最適値が変わることを考慮できない。

境界にない成分の集合を受動集合 $\mathcal{P}$、境界に固定した成分を有効集合 $\mathcal{Z}$ と呼ぶ。
$\mathcal{Z}$ の成分を境界値に固定すれば、残りは $\mathcal{P}$ の列だけの無制約の最小二乗 $\min\|A_{\mathcal{P}}x_{\mathcal{P}}-(b-A_{\mathcal{Z}}x_{\mathcal{Z}})\|$ になる。
正しい $\mathcal{Z}$ が分かれば一回の最小二乗で解けるので、有効集合法はこの集合を探す。

### Lawson–Hanson の NNLS

非負制約 $x\ge0$ の場合、Lawson–Hanson 法は $x=0$、$\mathcal{P}=\emptyset$ から次を繰り返す。

1. 双対変数 $w=-g=A^T(b-Ax)$ を計算する。
   $\mathcal{Z}$ のすべての $j$ で $w_j\le0$（すなわち $g_j\ge0$）なら KKT 条件が成り立つので止める。
2. $w_j$ が最大の $j\in\mathcal{Z}$ を $\mathcal{P}$ へ移す（その成分を増やすと目的が最も速く減る）。
3. $\mathcal{P}$ の列だけで無制約の最小二乗を解いて $z$ を得る。
   $z_{\mathcal{P}}>0$ なら $x\leftarrow z$ として手順 1 へ戻る。
4. そうでなければ、$x$ から $z$ への線分で最初に 0 に達する成分までの比 $\alpha=\min_{j\in\mathcal{P},\,z_j\le0}x_j/(x_j-z_j)$ を求め、$x\leftarrow x+\alpha(z-x)$ とする。
   0 になった成分を $\mathcal{Z}$ へ戻し、手順 3 をやり直す。

各外側反復で目的は厳密に減り、同じ受動集合は二度現れないので、厳密な算術では有限回で終わる。
止まった点では $\mathcal{Z}$ の成分の乗数 $\lambda_j=g_j\ge0$ が KKT 条件の乗数そのものになる。

### BVLS（上下限つき）

Stark–Parker の BVLS は同じ考えを $l\le x\le u$ に広げる。
有効集合の成分は下限か上限のどちらかに固定され、受動集合へ移す候補は下限にあって $-g_j>0$（増やすと減る）、上限にあって $g_j>0$（減らすと減る）成分である。
手順 4 の比は、受動集合の成分が下限・上限のどちらかに最初に達するまでの比になる。
上下限が等しい成分は最初から固定し、乗数の符号を問わない。

`Nnls` と `BoundedLinearLeastSquares` は境界へ射影した零点を最初の受理点とし、続けて無制約の解を箱へ切り詰めた点から始める。
この初期点は多くの成分を一度に受動集合へ入れるので、正の成分が多い問題で列を一本ずつ加える手間を省く。
その後の反復は双対実行可能性の破れが最大の成分を一つずつ解放し（手順 2）、受動集合の部分問題を解き直す。
解き直しで境界に達した成分は有効集合へ戻し、受動集合の勾配が閾値以下になれば、点が動かなかった場合も含めて成分の選択（手順 1）へ戻る。
初期点の切り詰めで境界に置いた成分は、後の選択で解放する候補から外さない。
解放した直後に点を動かさず境界へ戻った成分だけを、次に点が動くまで候補から外す。
密な問題では QR 因子を更新する（列の追加は Householder、削除は Givens で、列の変更一回あたり $O(mn)$）。
数値階数が決まらない場合や横長の系では、列ピボット付き QR か SVD へ移る。
成功は、元の座標で計算し直した KKT 残差が許容誤差を満たした場合だけで、追加できる成分がないのに KKT 条件を満たさなければ `Stagnation` で止まる。

## 入力と結果

`LinearLeastSquaresProblem` は係数行列、右辺、境界の情報を借用する。
`from_dense` と `from_view` は密な行列を受け取って QR・SVD の直接法を選び、`new` は `AdjointOperator`（$Av$ と $A^Tw$ の積だけを持つ作用素、疎行列を含む）を受け取って、受動集合に絞った部分問題を LSMR で解く。
境界は `with_bounds` で付け、指定のない端点は境界なしとして扱う。
`Nnls` は暗黙に $x\ge0$ を課すので、明示した境界を付けた問題は入力エラーになる。
一度だけ解くなら、ワンショット関数 `nnls(&a, &b)` と `bvls(&a, &b, &bounds)` が密な行列から問題を作り、既定の `Nnls` と `BoundedLinearLeastSquares` で解いて、成功しない終了を `Err` で返す。

`LinearLeastSquaresOptions` は次を設定する。

- `with_tolerances`：停留性・実行可能性・相補性の許容誤差。
  既定はいずれも絶対・相対とも $\sqrt{\varepsilon_{\mathrm{mach}}}$ で、相対許容誤差に掛ける尺度は、実行可能性が $\max(1,\max_i|x_i|)$、停留性が $\max(1,\ |f|/\max(1,\max_i|x_i|),\ \max_i|g_i|,\ \max_i\lambda_i,\ \max_i\mu_i)$、相補性が $\max(1,|f|)$ である。
- `with_rank_policy`：密な部分問題で数値階数を決める閾値。
  既定の `DimensionScaledEpsilon` は R の対角の最大値か最大の特異値に $\min(\max(m,n)\,\varepsilon_{\mathrm{mach}},1/2)$ を掛けた値である。
- `with_max_iterations`：外側反復の上限（既定 1000）。
- `with_max_inner_iterations`：作用素の問題で部分問題ごとの LSMR の反復の上限（既定 1000）。

`solve(&problem)` は成功しない終了でも `Ok` で結果を返し、そのとき `x()` は最後に受理した実行可能な点である。
成功の判定は `is_success()`（`Converged` のときだけ真）で読み、`require_success()` は成功でない終了を構造化したエラーにする。
同じ形の問題を繰り返し解く場合は、`Nnls::workspace(&problem)` か `BoundedLinearLeastSquares::workspace(&problem)` で `NnlsWorkspace` か `BoundedLinearLeastSquaresWorkspace` を準備し、`solve_into` に渡す。
作業領域は一つの問題の形と演算の種類（密か作用素か）に合わせて全メモリを確保して大きくならず、事前確保した出力と組み合わせれば求解中にメモリを確保しない。
別の形の問題を渡すと `DimensionMismatch`、解法や演算の種類が異なる問題を渡すと `InvalidInput` を返す。

`LinearLeastSquaresResult` の主な量は次のとおりである。

| 量 | 意味 |
|---|---|
| `x()`、`residual()`、`gradient()` | 解、元の残差 $Ax-b$、元の勾配 $A^T(Ax-b)$ |
| `activity()` | 各成分の `LinearLeastSquaresActivity`（`Free`、`Lower`、`Upper`、`Fixed`）。端点までの距離が実行可能性の許容誤差以下なら境界上とする |
| `lower_multipliers()`、`upper_multipliers()` | 境界上の成分について $\lambda_i=\max(g_i,0)$、$\mu_i=\max(-g_i,0)$ と作った非負の乗数 |
| `kkt()` | `LinearLeastSquaresKkt` の四つの $\infty$ ノルムの観測値 |
| `rank()` | 最後の受動集合の列の数値階数（作用素の問題と、零点を射影した初期点のまま止まった場合は `None`） |
| `objective()`、`residual_norm()` | $\tfrac12\|Ax-b\|^2$ と $\|Ax-b\|$ |

`LinearLeastSquaresKkt` の四つの量は、`primal_feasibility` が境界からのはみ出しの最大、`stationarity` が正の乗数を持たない成分の $|g_i|$ の最大、`dual_feasibility` が負の乗数の大きさの最大（上の作り方では常に 0）、`complementarity` が乗数と端点までの距離の積の最大である。
境界上で勾配の符号が逆の成分は乗数が 0 になり、その $|g_i|$ が停留性の残差に現れる。
これらは元の座標で計算した観測値で、区間演算による証明ではない。
残差 $\|Ax-b\|$ は観測への適合度であり、最適性の残差とは別である。

## 非負・境界付き最小二乗

$\min\|Ax-b\|^2/2$ に $x\ge0$ またはボックス制約を付けると、無制約解を事後的に切り詰めるだけでは最適解にならない。
`Nnls` と `BoundedLinearLeastSquares` は自由な成分と境界上の成分を扱い、KKT 条件を確認する。

次のセルは $A = \begin{bmatrix} 1 & 0 \\ 0 & 1 \\ 1 & 1 \end{bmatrix}$、$b = (-1, 2, 1)$ の非負最小二乗を `Nnls` で解く。
無制約の最小二乗解は $x = (-1, 2)$ で $x_0 < 0$ なので、切り詰めた $(0, 2)$ は最適ではない。
$x_0 = 0$ を境界に固定して残りを解くと $x_1 = (2 + 1)/2 = 1.5$ になり、これを独立な検算に使う。
出力は終了理由、解、既知解との差、$A$ と $b$ から計算し直した $x_0$ の勾配成分、$x_0$ の状態の表と、KKT の四つの量、乗数、反復回数の表である。
セルの最後に、`is_success()` から決めた判定を出す。

```rust
//| id: optimize-nonnegative-kkt
//| ref: optimize-nonnegative-kkt
//| title: 非負最小二乗の制約と最適性を確認する
//| run: reactive
//| crates: [scioxide-linalg, scioxide-optimize]
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"solution","path":"/rows/0/0","equals":"Converged"}
//|       - {"artifact":"solution","path":"/rows/0/1","approx":{"value":0.0,"atol":1e-14}}
//|       - {"artifact":"solution","path":"/rows/0/2","approx":{"value":1.5,"atol":1e-14}}
//|       - {"artifact":"solution","path":"/rows/0/4","approx":{"value":1.5,"atol":1e-14}}
//|       - {"artifact":"solution","path":"/rows/0/5","equals":"Lower"}
//|       - {"artifact":"kkt","path":"/rows/0/0","range":{"min":0,"max":1e-14}}
//|       - {"artifact":"kkt","path":"/rows/0/3","range":{"min":0,"max":1e-14}}
//|       - {"artifact":"kkt","path":"/rows/0/4","approx":{"value":1.5,"atol":1e-14}}
//|       - {"path":"/outputs/2/state","equals":"satisfied"}
use scioxide_linalg::Matrix;
use scioxide_optimize::{LinearLeastSquaresProblem, Nnls};

let sig6 = serde_json::json!({ "significantDigits": 6 });
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let a = Matrix::from_vec(3, 2, vec![1.0_f64, 0.0, 0.0, 1.0, 1.0, 1.0])
    .map_err(|e| e.to_string())?;
let b = [-1.0, 2.0, 1.0];
let problem = LinearLeastSquaresProblem::from_dense(&a, &b).map_err(|e| e.to_string())?;
let result = Nnls::<f64>::default()
    .solve(&problem)
    .map_err(|e| e.to_string())?;
let x = result.x();
// 独立な検算: x₀ = 0 の境界で x₁ だけを最小化すると x₁ = (2 + 1)/2 = 1.5。
// x₀ の勾配成分 (Aᵀ(Ax − b))₀ = r₀ + r₂ を A と b から計算し直す（境界での乗数）。
let residual: Vec<f64> = (0..3)
    .map(|i| a.as_slice()[2 * i] * x[0] + a.as_slice()[2 * i + 1] * x[1] - b[i])
    .collect();
let gradient0 = residual[0] + residual[2];
let columns = serde_json::json!([
    { "key": "0", "label": "終了理由" },
    { "key": "1", "label": "x₀ [-]", "type": "number", "format": sig6 },
    { "key": "2", "label": "x₁ [-]", "type": "number", "format": sig6 },
    { "key": "3", "label": "既知解との差 [-]", "type": "number", "format": sci2 },
    { "key": "4", "label": "x₀ の勾配成分（検算） [-]", "type": "number", "format": sig6 },
    { "key": "5", "label": "x₀ の状態" }
]);
emit_table_with_columns!(
    columns,
    vec![(
        result.termination().to_string(),
        x[0],
        x[1],
        x[0].abs().max((x[1] - 1.5).abs()),
        gradient0,
        format!("{:?}", result.activity()[0])
    )],
    metadata = serde_json::json!({ "id": "solution" })
);
let kkt = result.kkt();
let columns = serde_json::json!([
    { "key": "0", "label": "停留性 [-]", "type": "number", "format": sci2 },
    { "key": "1", "label": "主実行可能性 [-]", "type": "number", "format": sci2 },
    { "key": "2", "label": "双対実行可能性 [-]", "type": "number", "format": sci2 },
    { "key": "3", "label": "相補性 [-]", "type": "number", "format": sci2 },
    { "key": "4", "label": "下限の乗数 λ₀ [-]", "type": "number", "format": sig6 },
    { "key": "5", "label": "反復 [回]", "type": "integer" }
]);
emit_table_with_columns!(
    columns,
    vec![(
        kkt.stationarity(),
        kkt.primal_feasibility(),
        kkt.dual_feasibility(),
        kkt.complementarity(),
        result.lower_multipliers()[0],
        result.iterations()
    )],
    metadata = serde_json::json!({ "id": "kkt" })
);
let outcome = if result.is_success() {
    Outcome::satisfied("元の座標で計算し直した KKT 条件が許容誤差を満たした")
} else {
    Outcome::partial("KKT 条件を満たす前に止まった")
        .explanation("返された点は最後に受理した実行可能な点で、残差から停留条件を満たしていないことが分かる。")
};
emit_outcome!(
    outcome
        .status(result.termination().to_string())
        .diagnostic("停留性", kkt.stationarity(), None)
        .diagnostic("反復", result.iterations() as f64, None)
);
```

`Nnls` は 2 回の反復で `Converged` に達し、$x = (0, 1.5)$ を既知解と差 0 で返す。
境界上の $x_0$ の勾配成分は 1.5 で正なので、$x_0$ を増やすと目的が増え、境界に留まることが最適である。
この値がそのまま下限の乗数 $\lambda_0=1.5$ になり、停留性・主実行可能性・双対実行可能性・相補性の残差はいずれも 0 である。

## 吸収スペクトルの混合比

四つの成分のガウス型吸収帯（中心 430、470、520、580 nm、幅 25〜35 nm）を 400〜634 nm の 40 波長で並べた行列 $A$ と、第 2 成分を含まない混合 $x_{\mathrm{true}}=(0.8,0,0.5,1.2)$ の吸光度に振幅 0.02 の測定のずれを加えた $b$ を考える。
濃度は負になれず、入力 $u$ を全成分に共通の上限とする（$0\le x\le u$）。
同じ $A$、$b$ を境界なし（`BoundedLinearLeastSquares` に境界を付けない場合は QR の最小二乗）、非負だけの `Nnls`、箱付きの `BoundedLinearLeastSquares` で解く。
一つ目の表は各成分の三つの解、BVLS の状態、勾配、乗数で、二つ目の表は BVLS の終了理由、反復、残差、KKT の量、$A$ と $b$ から計算し直した符号条件の破れの最大、自由な列の数値階数である。

use scioxide_core::{Bounds, RealScalar};
use scioxide_linalg::Matrix;
use scioxide_optimize::{BoundedLinearLeastSquares, LinearLeastSquaresProblem, Nnls};

let sig6 = serde_json::json!({ "significantDigits": 6 });
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
// 4 成分のガウス型吸収帯（中心 [nm]、幅 [nm]）を 40 波長で並べた A と、
// 第 2 成分を含まない混合 x_true = (0.8, 0, 0.5, 1.2) の吸光度に測定のずれを足した b。
let (m, n) = (40_usize, 4_usize);
let centers = [430.0, 470.0, 520.0, 580.0];
let widths = [25.0, 30.0, 25.0, 35.0];
let truth = [0.8, 0.0, 0.5, 1.2];
let mut a = vec![0.0_f64; m * n];
let mut b = vec![0.0_f64; m];
for i in 0..m {
    let wavelength = 400.0 + 6.0 * i as f64;
    for j in 0..n {
        let u = (wavelength - centers[j]) / widths[j];
        a[i * n + j] = RealScalar::exp(-0.5 * u * u);
        b[i] += truth[j] * a[i * n + j];
    }
    b[i] += 0.02 * RealScalar::sin(1.3 * i as f64 + 0.4);
}
let a = Matrix::from_vec(m, n, a).map_err(|e| e.to_string())?;
let free = LinearLeastSquaresProblem::from_dense(&a, &b).map_err(|e| e.to_string())?;
// 境界なしの最小二乗（QR）、非負だけの NNLS、0 ≤ x ≤ u の BVLS を同じ A, b で解く。
let unconstrained = BoundedLinearLeastSquares::<f64>::default()
    .solve(&free)
    .map_err(|e| e.to_string())?;
let nnls = Nnls::<f64>::default()
    .solve(&free)
    .map_err(|e| e.to_string())?;
let bounds = Bounds::new(vec![(Some(0.0), Some(upper)); n]).map_err(|e| e.to_string())?;
let boxed = free.with_bounds(&bounds).map_err(|e| e.to_string())?;
let bvls = BoundedLinearLeastSquares::<f64>::default()
    .solve(&boxed)
    .map_err(|e| e.to_string())?;
let rows: Vec<_> = (0..n)
    .map(|j| {
        (
            j + 1,
            unconstrained.x()[j],
            nnls.x()[j],
            bvls.x()[j],
            format!("{:?}", bvls.activity()[j]),
            bvls.gradient()[j],
            bvls.lower_multipliers()[j],
            bvls.upper_multipliers()[j],
        )
    })
    .collect();
let columns = serde_json::json!([
    { "key": "0", "label": "成分", "type": "integer" },
    { "key": "1", "label": "境界なし x [-]", "type": "number", "format": sig6 },
    { "key": "2", "label": "NNLS x [-]", "type": "number", "format": sig6 },
    { "key": "3", "label": "BVLS x [-]", "type": "number", "format": sig6 },
    { "key": "4", "label": "BVLS の状態" },
    { "key": "5", "label": "勾配 g = Aᵀ(Ax − b) [-]", "type": "number", "format": sig6 },
    { "key": "6", "label": "下限の乗数 [-]", "type": "number", "format": sig6 },
    { "key": "7", "label": "上限の乗数 [-]", "type": "number", "format": sig6 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "components" })
);
// 独立な検算: BVLS の点で勾配を A と b から計算し直し、符号条件の破れの最大を測る。
let mut sign_violation = 0.0_f64;
for j in 0..n {
    let g: f64 = (0..m)
        .map(|i| {
            let row = &a.as_slice()[i * n..(i + 1) * n];
            let fitted: f64 = row.iter().zip(bvls.x()).map(|(p, q)| p * q).sum();
            row[j] * (fitted - b[i])
        })
        .sum();
    let x = bvls.x()[j];
    let violation = if x <= 0.0 {
        (-g).max(0.0)
    } else if x >= upper {
        g.max(0.0)
    } else {
        g.abs()
    };
    sign_violation = sign_violation.max(violation);
}
let kkt = bvls.kkt();
let columns = serde_json::json!([
    { "key": "0", "label": "BVLS の終了理由" },
    { "key": "1", "label": "反復 [回]", "type": "integer" },
    { "key": "2", "label": "残差 ‖Ax − b‖ [-]", "type": "number", "format": sig6 },
    { "key": "3", "label": "停留性 [-]", "type": "number", "format": sci2 },
    { "key": "4", "label": "主実行可能性 [-]", "type": "number", "format": sci2 },
    { "key": "5", "label": "相補性 [-]", "type": "number", "format": sci2 },
    { "key": "6", "label": "符号条件の破れ（検算） [-]", "type": "number", "format": sci2 },
    { "key": "7", "label": "自由な列の数値階数", "type": "integer", "nullText": "レポートなし" }
]);
emit_table_with_columns!(
    columns,
    vec![(
        bvls.termination().to_string(),
        bvls.iterations(),
        bvls.residual_norm(),
        kkt.stationarity(),
        kkt.primal_feasibility(),
        kkt.complementarity(),
        sign_violation,
        bvls.rank().map(|r| r.rank())
    )],
    metadata = serde_json::json!({ "id": "bvls" })
);
let outcome = if bvls.is_success() {
    Outcome::satisfied("BVLS の KKT 条件が元の座標で許容誤差を満たした")
} else {
    Outcome::partial("BVLS が KKT 条件を満たす前に止まった")
        .explanation("返された点は最後に受理した実行可能な点で、残差から停留条件を満たしていないことが分かる。")
};
emit_outcome!(
    outcome
        .status(bvls.termination().to_string())
        .diagnostic("停留性", kkt.stationarity(), None)
        .diagnostic("反復", bvls.iterations() as f64, None)
);

既定の $u=1$ では、境界なしの解は第 2 成分が $-0.0009$ と負になり、`Nnls` はそれを 0 にして $(0.801, 0, 0.500, 1.200)$ を返す。
BVLS では第 4 成分が上限 1 に、第 2 成分が下限 0 に固定され、その影響で自由な第 3 成分が 0.587 に上がる。
第 2 成分の勾配は $+0.187$（下限の乗数）、第 4 成分の勾配は $-1.765$（上限の乗数 1.765）で、どちらも符号条件を満たし、2 回の反復で `Converged` になる。
自由な成分の勾配は $10^{-15}$ の程度で、検算した符号条件の破れも同じ大きさである。
$u=2$ では上限に触れる成分がなく、BVLS は `Nnls` と同じ解を返す。
二つは同じ有効集合の実装を共有するので、この一致は独立な検算ではなく、検算は $A$ と $b$ から計算し直した符号条件で行う。

$u=0.7$ と $u=0.6$ では第 1、3、4 成分がすべて上限に止まり、真の混合に含まれない第 2 成分だけが自由な成分として残る。
第 2 成分は $u=0.7$ で 0.0048、$u=0.6$ で 0.104 の正の値を取り、上限で抑えた三成分の吸光度の一部を代わりに説明する。
$u=0.6$ での三成分の勾配は $-0.929$、$-0.878$、$-5.763$ で上限の符号条件を満たし、BVLS は 4 回の反復で `Converged` になり、残差は 1.888 に増える。
検算した符号条件の破れも $10^{-15}$ の程度なので、この点はボックス制約の下の最適解である。
ただし第 2 成分が正になったのは上限を課した結果であり、第 2 成分が試料に含まれることを示すものではない。
上限の乗数は上限を緩めたときに目的が減る割合を表すので、乗数が最も大きい第 4 成分の上限（5.763）が適合を最も強く妨げている。

## まとめ

無制約の線形最小二乗は正規方程式を作らず QR で解き、階数不足なら SVD の最小ノルム解を選ぶので、残差が小さい問題でも精度は $\kappa_2(A)^2$ ではなく問題の条件数で決まる。
非負・ボックス制約では、下限で $g_i\ge0$、上限で $g_i\le0$、内部で $g_i=0$ という符号条件が最適性の必要十分条件で、無制約解の切り詰めはこれを満たさないことがある。
`Nnls`（Lawson–Hanson）と `BoundedLinearLeastSquares`（BVLS）は受動集合を一成分ずつ入れ替える有効集合法で、乗数 `lower_multipliers()`、`upper_multipliers()` と `kkt()` の四つの量を元の座標で計算し直してから `Converged` を返す。
成功は `is_success()` で判定し、`Stagnation` や `IterationLimit` で止まった結果は最後に受理した実行可能な点として、`activity()` と停留性の残差から破れている成分を特定する。
疎な行列や作用素だけの問題では `LinearLeastSquaresProblem::new` で LSMR の経路を選び、繰り返す求解では作業領域を `solve_into` に渡す。
