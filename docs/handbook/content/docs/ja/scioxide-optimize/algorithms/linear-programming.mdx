線形計画（LP）は線形の目的を線形の等式・不等式の下で最小にする問題である。
最適解は実行可能領域の頂点で達成されるので、単体法は頂点を順にたどり、内点法は領域の内側から最適な面へ近づく。
このページでは二つの方法の導出、停止の判定、計算量と、SciOxide の `SimplexSolver` と `InteriorPointLp` の実装を説明する。
ソルバーが返した点と乗数を元の式で確かめる方法は[線形・二次計画の証明用データと検証](../programming-certificates/)で扱う。

## 標準形と基底解

標準形の線形計画問題は

$$
\min_{\mathbf{x} \in \mathbb{R}^n} \mathbf{c}^\mathsf{T}\mathbf{x} \quad \text{subject to} \quad \mathbf{A}\mathbf{x} = \mathbf{b}, \quad \mathbf{x} \ge \mathbf{0}
$$

である（$\mathbf{A}\in\mathbb{R}^{m\times n}$、$\mathbf{b}\in\mathbb{R}^m$、$\mathbf{c}\in\mathbb{R}^n$）。
実行可能領域は凸多面体（polyhedron）になり、目的の等高面は超平面である。
実行可能領域が空でなく目的が下に有界なら、最小値は多面体の頂点のどれかで達成される。
不等式 $\mathbf{a}_i^\mathsf{T}\mathbf{x}\le b_i$ には非負の余裕変数を足して等式にし、符号の自由な変数は二つの非負変数の差に分けると、どの LP もこの形に直せる。

$\operatorname{rank}(\mathbf{A}) = m < n$ を仮定し、列の添字集合を $m$ 個の基底添字 $\mathcal{B}$ と $n-m$ 個の非基底添字 $\mathcal{N}$ に分ける。
基底行列 $\mathbf{B} = \mathbf{A}_{:, \mathcal{B}}$ が正則なら、非基底変数を $\mathbf{x}_{\mathcal{N}} = \mathbf{0}$ と置いて

$$
\mathbf{x}_{\mathcal{B}} = \mathbf{B}^{-1}\mathbf{b}
$$

が決まる。
これが $\mathbf{x}_{\mathcal{B}} \ge \mathbf{0}$ を満たすとき、基底実行可能解（basic feasible solution）と呼ぶ。
基底実行可能解は多面体の頂点に対応し、正の成分は高々 $m$ 個である。
基底変数のどれかが 0 の頂点を退化した頂点と呼び、退化した頂点には複数の基底が対応しうる。

## 被約費用と比率検査

目的を非基底変数だけで書き直すと

$$
\mathbf{c}^\mathsf{T}\mathbf{x} = \mathbf{c}_{\mathcal{B}}^\mathsf{T}\mathbf{B}^{-1}\mathbf{b} + \bar{\mathbf{c}}_{\mathcal{N}}^\mathsf{T}\mathbf{x}_{\mathcal{N}},\qquad
\bar{\mathbf{c}}_{\mathcal{N}}^\mathsf{T} = \mathbf{c}_{\mathcal{N}}^\mathsf{T} - \mathbf{c}_{\mathcal{B}}^\mathsf{T}\mathbf{B}^{-1}\mathbf{A}_{:,\mathcal{N}}
$$

になり、$\bar{\mathbf{c}}_{\mathcal{N}}$ を被約費用（reduced cost）と呼ぶ。

- $\bar{\mathbf{c}}_{\mathcal{N}} \ge \mathbf{0}$ なら、非負の $\mathbf{x}_{\mathcal{N}}$ をどう増やしても目的は下がらないので、現在の基底解は最適である。
  LP は凸なので、この局所的な判定で大域最適が分かる。
- 負の成分 $\bar{c}_j < 0$ があれば、$x_j$ を基底に入れる（ピボット）と目的を下げられる。

$x_j$ を $\theta\ge0$ だけ増やすと、等式を保つために基底変数は $\mathbf{x}_{\mathcal{B}}-\theta\mathbf{d}$（$\mathbf{d}=\mathbf{B}^{-1}\mathbf{A}_{:,j}$）と動く。
非負性を保てる最大のステップ幅は比率検査

$$
\theta^*=\min_{i:\,d_i>0}\frac{(\mathbf{x}_{\mathcal{B}})_i}{d_i}
$$

で決まり、最小を与えた基底変数が 0 になって非基底へ出る。
$d_i>0$ となる成分がなければ $\theta$ をいくらでも大きくでき、目的は下に非有界である。
1 回のピボットで目的は $\theta^*|\bar{c}_j|$ だけ下がる。

退化した基底では $(\mathbf{x}_{\mathcal{B}})_i=0$ の行で $\theta^*=0$ となり、基底だけが変わって点は動かない。
このようなピボットが続くと同じ基底の列を巡回することがある。
入る変数を被約費用が負の変数のうち最小の添字で選び、出る変数を最小比率を与える行のうち最小の添字で選ぶ Bland の規則を使うと、巡回は起きない（Bland, 1977）。
基底の数は有限なので、巡回しなければ単体法は有限回で終わる。
ピボットの回数は最悪の場合に変数の数に対して指数的になり（Dantzig の規則に対する Klee–Minty の例）、実際の問題では行数の数倍程度で終わることが多い（Chvátal, 1983, 4 章）。

## SimplexSolver の実装

`SimplexSolver` は上下限つきの二段階改訂単体法である。
段階 I で実行可能な基底を作り、段階 II で元の目的を下げる。
有限な変数の上限は行に展開せず直接保持し、非基底変数を下端から上端へ移すだけの反復（上下端の切り替え）もピボットと同じく反復として数える。
行と列は 2 のべき乗の係数で均衡化し、入る変数の選択（価格付け、pricing）と比率検査はこの座標で比べる。

- 入る変数は Dantzig の規則（被約費用が最も負の変数）で選ぶ。
- 出る変数は二段階の Harris 比率検査で選ぶ。
  一段目で実行可能性を許容誤差だけ緩めた最小比率を求め、二段目でその範囲に入る行から $|d_i|$ が最大のものを選ぶ。
  小さい枢軸を避けるので、丸め誤差の増幅を抑えられる（Harris, 1973）。
- ステップ幅か目的の改善が許容誤差以下のピボットが 8 回続くと、その段階の残りは Bland の規則で選ぶ。

基底行列は LU 分解で解く。
行制約を疎行列で渡したか `with_sparse_limits` を設定した場合は疎な LU、それ以外は密な LU を使う。
分解の間は eta 更新で基底の変化を表し、`with_basis_update_limit`（既定 32 回）ごとに分解し直す。
密な基底での 1 ピボットの計算量は $O(m^2)$、分解し直しは $O(m^3)$ である。
既定の反復上限は元の変数の数 $n$ と行数 $m$ から $\max(1000,\,10(n+m))$ で決まり、`with_max_iterations` で置き換えられる。
許容誤差は既定で各役割とも絶対・相対 $10^{-8}$（機械イプシロンが $10^{-8}$ より大きいスカラーでは $10^{-6}$）で、`with_tolerances` で変える。

`BasisMatrix` は現在の基底行列を借用する型で、`order()`、`column_entries(column)`、`get(row, col)` で成分を読む。
基底の列は標準形の列で、人工変数の単位列は保存せず、冗長として除いた行も含まない。
`BasisProvider` はこの行列の分解（`factor`）と $\mathbf{B}\mathbf{y}=\mathbf{r}$ または $\mathbf{B}^\mathsf{T}\mathbf{y}=\mathbf{r}$ の求解を供給するトレイトである。
組み込みの選択肢は `DenseBasisProvider`（部分ピボット付き密 LU）と `SparseBasisProvider`（疎 LU、パターンが変わらなければ記号解析を再利用）で、`SimplexWorkspace::with_basis_provider` で組み込みの分解と替える。

## 基底の再利用

`SimplexWorkspace` は直近の試行の基底と記録を持つ。
`SimplexSolver::solve_into` のあとに `SimplexWorkspace::warm_start()` を呼ぶと、基底と非基底変数の端の状態を所有する `SimplexWarmStart` が得られる。
ワンショット呼び出しの `solve` は基底を記録しないので、再利用するときは作業領域を使う。
`SimplexSolver::resume_into` にこのスナップショットと変更後の問題を渡すと、次のように扱う。

- 目的か右辺だけが変わった場合と、不等式行を追加した場合は、記録した基底から始める。
  その基底が主実行可能でなければ、双対単体法で実行可能性を取り戻すか、実行不能の Farkas 証明用データを返す。
- 係数、行の向き、変数の境界、形が変わった場合は、最初から解き直す。
  古いスナップショットでもエラーにはならない。

どちらで解いたかは新しいスナップショットの `reused_basis()` で読む。
分枝限定法の子節点は変数の境界だけが変わるので、この規則では最初から解き直しになる。
[混合整数計画と分枝切除法](../mixed-integer-programming/)の `BranchAndBound` は、境界の変更に対する再最適化を専用の `MipSimplexWorkspace` で行う。

## 双対定理とシャドープライス

標準形の主問題に対応する双対問題（dual problem）は

$$
\max_{\mathbf{y} \in \mathbb{R}^m} \mathbf{b}^\mathsf{T}\mathbf{y} \quad \text{subject to} \quad \mathbf{A}^\mathsf{T}\mathbf{y} \le \mathbf{c}
$$

である。
主問題の実行可能解 $\mathbf{x}$ と双対問題の実行可能解 $\mathbf{y}$ について

$$
\mathbf{c}^\mathsf{T}\mathbf{x}-\mathbf{b}^\mathsf{T}\mathbf{y}=(\mathbf{c}-\mathbf{A}^\mathsf{T}\mathbf{y})^\mathsf{T}\mathbf{x}\ge0
$$

が成り立つ（弱双対定理）。
したがって双対の実行可能解は、主問題の最適値の下界を与える。
等号は相補性 $x_j(\mathbf{c}-\mathbf{A}^\mathsf{T}\mathbf{y})_j=0$（$j=1,\dots,n$）が成り立つときだけ成り立つ。
一方が有限の最適解を持てば他方も持ち、最適値は一致する（強双対定理）。

単体法の最適基底では $\mathbf{y}^{*\mathsf{T}}=\mathbf{c}_{\mathcal{B}}^\mathsf{T}\mathbf{B}^{-1}$ が双対の最適解になる。
このとき $\mathbf{c}-\mathbf{A}^\mathsf{T}\mathbf{y}^*$ の非基底成分は被約費用で、$\bar{\mathbf{c}}_{\mathcal{N}}\ge\mathbf{0}$ は双対実行可能性と同じ条件である。
最適基底が変わらない範囲で右辺 $b_i$ を変えると、最適値は $y_i^*$ の割合で変わる。
この変化率をシャドープライス（shadow price）と呼ぶ。

主問題が実行不能であることは Farkas の補題による乗数で、非有界であることは実行可能点と目的を下げる回帰方向の組で示せる（[実行不能・非有界の証明用データと外部の結果の検証](../infeasibility-certificates/)）。

SciOxide の結果はこれらの乗数を元の問題の形（$\le$・$=$・$\ge$ の行と変数の上下限）のまま持つ。
その符号の規約は上の教科書の形と逆で、$\le$ 行の乗数は非負になり、右辺を 1 増やしたときの最適値の減少量を表す。
規約の詳細と検証の手順は[線形・二次計画の証明用データと検証](../programming-certificates/)にある。

## 同次自己双対内点法

単体法が頂点を移るのに対し、主双対内点法は $\mathbf{x} > \mathbf{0}$ と双対の余裕 $\mathbf{s}=\mathbf{c}-\mathbf{A}^\mathsf{T}\mathbf{y} > \mathbf{0}$ を保ったまま最適解へ近づく。
相補性 $x_j s_j = 0$ を $\mu > 0$ で緩めた連立方程式

$$
\mathbf{A}\mathbf{x} = \mathbf{b}, \quad \mathbf{A}^\mathsf{T}\mathbf{y} + \mathbf{s} = \mathbf{c}, \quad \mathbf{X}\mathbf{S}\mathbf{e} = \mu \mathbf{e}
$$

（$\mathbf{X} = \operatorname{diag}(\mathbf{x})$、$\mathbf{S} = \operatorname{diag}(\mathbf{s})$、$\mathbf{e}$ は全成分 1）の解は、$\mu\to0$ で最適解へ向かう中心経路をなす。
Newton 方程式から $\Delta\mathbf{x}$ と $\Delta\mathbf{s}$ を消去すると、$\Delta\mathbf{y}$ についての正規方程式

$$
\mathbf{A}\mathbf{D}\mathbf{A}^\mathsf{T}\Delta\mathbf{y}=\mathbf{r},\qquad \mathbf{D}=\mathbf{X}\mathbf{S}^{-1}
$$

が残る（$\mathbf{r}$ は残差から決まる右辺）。

Mehrotra の予測子・修正子法は、まず $\mu = 0$ のアフィン方向（予測子）を求め、その方向で境界まで進んだときの平均相補性 $\mu_{\mathrm{aff}}$ を見積もる。
次に中心化係数 $\sigma=(\mu_{\mathrm{aff}}/\mu)^3$ による中心化と二次の補正項を加えた方向（修正子）を、同じ分解で求める（Mehrotra, 1992）。
ステップ幅は正の成分が境界に達するまでの距離の 0.995 倍にする。

`InteriorPointLp` はこの方法を同次自己双対埋め込み（Ye, Todd and Mizuno, 1994; Xu, Hung and Ye, 1996）に適用する。
埋め込みは非負のスカラー $\tau,\kappa$ を加えた同次の系

$$
\mathbf{A}\mathbf{x}-\mathbf{b}\tau=\mathbf{0},\qquad -\mathbf{A}^\mathsf{T}\mathbf{y}+\mathbf{c}\tau-\mathbf{s}=\mathbf{0},\qquad \mathbf{b}^\mathsf{T}\mathbf{y}-\mathbf{c}^\mathsf{T}\mathbf{x}-\kappa=0
$$

で、自明でない解の極限で $\tau>0$ なら $(\mathbf{x}/\tau,\mathbf{y}/\tau)$ が主と双対の最適解、$\kappa>0$ なら $\mathbf{b}^\mathsf{T}\mathbf{y}>\mathbf{c}^\mathsf{T}\mathbf{x}$ から主問題か双対問題が実行不能だと分かる。
このため実行可能な初期点を必要としない。
Ye, Todd and Mizuno（1994）の経路追跡法でこの埋め込みを解くと、反復回数は $O(\sqrt{n}\log(1/\varepsilon))$ で抑えられる。
Mehrotra の予測子・修正子法にはこの上界の証明はないが、実際の反復回数は問題の大きさにあまり依存しないことが多い。

1 反復の主な計算量は次数 $m$ の正規行列 $\mathbf{A}\mathbf{D}\mathbf{A}^\mathsf{T}$ の分解（密なら $O(m^3)$）である。
最適解に近づくと $\mathbf{D}$ の成分が 0 と $\infty$ に分かれ、正規行列は悪条件になる。
`InteriorPointLp` は一つの分解を予測子と修正子で共有し、元の Newton 方程式の残差を同じ分解で最大 3 回補正してこの悪条件を補う。
正規行列には尺度に比例した対角の正則化を加え、既定では密な $\mathrm{LDL}^\mathsf{T}$ 分解で解く。
最後の反復点はその能動な面で補正してから、最適性の証明用データを作る。
既定の反復上限は 1000 回、許容誤差は単体法と同じ $10^{-8}$（精度の足りないスカラーでは $10^{-6}$）である。
`Unbounded` と返すのは、実行可能な基点と非有界方向が元の問題の検査を通った場合だけで、$\tau$ が小さいことだけでは返しない。
基点を得るために単体法を 1 回使うことがあり、その反復も反復上限に数える。

## 問題の入力と作業領域

`LpProblem::new(c)` で目的を作り、`with_constraints` で行制約、`with_bounds` で変数の上下限を加える。
境界を付けない変数は $x\ge0$ として扱う。
`LinearConstraints::new(a, b, senses)` は係数行列、右辺、各行の `LinearConstraintSense`（`Equal`、`LessEqual`、`GreaterEqual`）をまとめ、全ての行が同じ向きなら `less_equal(a, b)`、`equal`、`greater_equal` で作れる。
列数は変数の数、右辺と向きの個数は行数に一致させる。
係数は `CoefficientMatrix` として密行列か疎（CSR）行列で受け取る。
入力を疎に保存できることと、ソルバーが分解を疎に行うことは別で、どう分解するかは上の節のとおりソルバーごとに決まる。

`LpProblem::solve()` は既定の `SimplexSolver` で解くワンショット呼び出しのメソッドである。
成功しない終了は `Err` で返し、実行不能や非有界と確かめた問題は `DomainError`、反復上限による停止は `ConvergenceFailure` になる。
`SimplexSolver::default().solve(&lp)` のように手法オブジェクトで解くと、同じ終了を結果の `termination()` として返し、上限で止まった点も読める。

`SimplexWorkspace` は任意の LP を受け付け、分解のメモリは呼び出しごとに大きさを決める。
一方、`InteriorPointLpWorkspace` は `InteriorPointLp::workspace(&problem)` で作ったときの標準形の形（列数と行数、`shape()`）に固定され、形の違う問題は分解の前に `DimensionMismatch` で拒否する。
`InteriorPointLpWorkspace::with_kkt_provider` には、尺度に比例した対角の正則化を含む次数 $m$ の対称な正規行列を受け付ける `KktProvider` を渡す。
`embedding_scalars()` は直近に受理した反復の $(\tau,\kappa)$ を返す。

## 問題の大きさと反復回数

単体法のピボット数と内点法の反復数が、問題の大きさにどう依存するかを確かめる。
題材は $n$ 品目と $n$ 種類のリソースを持つ生産計画で、品目 $j$ を 1 単位作るのにリソース $i$ を $A_{ij}$ 単位使い、利益は $p_j$ である。
$A_{ij}$ と $p_j$ は乱数のシードから作る 1〜9 の整数、リソース量はすべて 100 単位で、$\mathbf{A}\mathbf{x}\le\mathbf{b}$、$\mathbf{x}\ge\mathbf{0}$ の下で利益 $\mathbf{p}^\mathsf{T}\mathbf{x}$ を最大にする（目的は $-\mathbf{p}$ の最小化に写す）。
$n=10,20,40,80,120$ の問題を `SimplexSolver` と `InteriorPointLp` の既定の設定で解き、二つの方法の目的値の相対差を独立な検算にする。
入力は乱数のシードだけである。
表はピボット数を行数 $m=n$ で割った値と、単体法の解で正になった変数の数（頂点なので高々 $m$ 個）も示す。

```rust
    let matrix = Matrix::from_vec(n, n, a).map_err(|e| e.to_string())?;
    let resources =
        LinearConstraints::less_equal(matrix, vec![100.0; n]).map_err(|e| e.to_string())?;
    let lp = LpProblem::new(cost)
        .and_then(|p| p.with_constraints(resources))
        .map_err(|e| e.to_string())?;
    let simplex = SimplexSolver::default()
        .solve(&lp)
        .map_err(|e| e.to_string())?;
    let interior = InteriorPointLp::default()
        .solve(&lp)
        .map_err(|e| e.to_string())?;
    // 独立な検算: 二つの方法の目的値の相対差。
    let difference = (simplex.fun() - interior.fun()).abs() / simplex.fun().abs().max(1.0);
    let positive = simplex.x().iter().filter(|&&v| v > 0.0).count();
    let size = n as f64;
    simplex_points.push([size, simplex.iterations() as f64]);
    interior_points.push([size, interior.iterations() as f64]);
    reference.push([size, size]);
    rows.push((
        n,
        simplex.iterations(),
        simplex.iterations() as f64 / size,
        interior.iterations(),
        difference,
        positive,
        simplex.termination().to_string(),
        interior.termination().to_string(),
    ));
}
emit_line_chart!(
    &vec![
        serde_json::json!({
            "name": "単体法のピボット",
            "points": simplex_points,
            "style": {"showSymbol": true}
        }),
        serde_json::json!({
            "name": "内点法の反復",
            "points": interior_points,
            "style": {"showSymbol": true}
        }),
        serde_json::json!({
            "name": "参照: 行数 m",
            "points": reference,
            "style": {"lineType": "dashed"}
        }),
    ],
    options = &serde_json::json!({
        "xLabel": "品目数 n = リソース数 m [-]",
        "yLabel": "反復 [回]",
        "xType": "log",
        "yType": "log"
    })
);
let columns = serde_json::json!([
    { "key": "0", "label": "n = m [-]", "type": "integer" },
    { "key": "1", "label": "単体法のピボット [回]", "type": "integer" },
    { "key": "2", "label": "ピボット / m [-]", "type": "number", "format": fixed2 },
    { "key": "3", "label": "内点法の反復 [回]", "type": "integer" },
    { "key": "4", "label": "目的値の相対差 [-]", "type": "number", "format": sci2 },
    { "key": "5", "label": "単体法の解の正の成分 [個]", "type": "integer" },
    { "key": "6", "label": "単体法の終了" },
    { "key": "7", "label": "内点法の終了" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "iterations" })

```

既定のシード 3 では、単体法のピボットは $n=10$ の 6 回から $n=120$ の 78 回まで増え、行数に対する比は 0.53〜0.65 にとどまる。
内点法の反復は 8 回から 11 回までしか増えない。
両対数の図では、ピボットの点が傾き 1 の参照線にほぼ平行に並び、内点法の点はほぼ水平に並ぶ。
二つの方法の目的値の相対差はどの大きさでも $2\times10^{-9}$ 未満で、単体法の解の正の成分は 5〜24 個と行数より少ない。
1 ピボットの計算量は密な基底で $O(m^2)$、内点法の 1 反復は $O(m^3)$ なので、反復回数だけで計算時間を比べない。

シード 1 にすると、$n=120$ のピボットが 739 回（行数の 6.2 倍）になり、シード 3 の 78 回やシード 20 の 110 回から大きく外れる。
内点法の反復はこの問題でも 11 回である。
単体法のピボット数は同じ大きさの問題でも係数によって桁で変わることがある。

## まとめ

被約費用が非負になった基底は最適で、比率検査が進めるステップ幅を決め、退化したピボットの巡回は Bland の規則で防げる。
双対の実行可能解は弱双対定理から主の目的の下界を与え、最適基底の双対解は右辺に対するシャドープライスになる。
基底の再利用、シャドープライスの読み出し、少数のピボットでの再最適化が必要なら `SimplexSolver`、実行可能な初期点がない問題や反復回数を大きさに依存させたくない問題には `InteriorPointLp` を選べる。
`LpProblem::solve()` は反復上限 $\max(1000,10(n+m))$ の単体法で、上限で止まった点を読むには `SimplexSolver` の値で解く。
どちらの方法の結果もソルバーとは独立に元の式で検算できる。
