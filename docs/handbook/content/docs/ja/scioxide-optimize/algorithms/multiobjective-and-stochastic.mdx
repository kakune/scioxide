複数の目的 $f(x)=(f_1(x),\dots,f_M(x))$ を同時に小さくしたいとき、一般にはすべての目的を同時に最小にする点はない。
一つの目的を良くすると別の目的が悪くなる交換条件（トレードオフ）があり、結果は一点ではなく候補の集合として示す。
このページでは候補の比べ方（Pareto 支配）、近似の良さの測り方（超体積）、集団で前線を近似する NSGA-II を説明する。
目的の評価にノイズがある場合に観測を標本化する仕組みと、ノイズのある一つの目的を最小にする確率的な一階法は、[確率的勾配降下法と確率的信頼領域法](../stochastic-gradient-and-trust-region/)で扱う。

## Pareto 支配

最小化する目的ベクトルについて、全成分で $f_i(x)\le f_i(y)$、少なくとも一成分で $f_i(x)<f_i(y)$ が成り立つとき、$x$ は $y$ を支配するという。
どの目的を重く見るかを決めなければ、互いに支配しない候補の間に順位は付かない。
どの点にも支配されない点を Pareto 最適と呼び、その集合を Pareto 集合、目的空間での像を Pareto 前線と呼ぶ。
`pareto_dominance(a, b)` は二つの目的ベクトルを許容誤差なしで比較し、`ParetoDominance` の `Dominates`（$a$ が支配する）、`Dominated`（$b$ が支配する）、`Equal`（全成分が等しく、$-0$ と $+0$ も等しい）、`Incomparable`（互いに支配しない）のどれかを返す。
空のベクトル、長さの違い、非有限な成分は `InvalidInput` になる。

重み付き和 $\sum_iw_if_i$ を一つの目的として最小化すると、前線の凸包の上にある点しか得られない。
前線が凹んだ部分を持つ問題でも交換条件全体を示すために、点の集団で前線を近似する方法を使う。
近似の良さは、参照点 $r$ と候補が支配する領域の面積（二目的の超体積）で測る。
候補が支配する点は Pareto 前線のどれかの点にも支配されるので、超体積は真の前線の超体積を上限とし、前線への近さと広がりの両方で大きくなる。

`ParetoArchive::new(dimension, objectives, capacity)` は、支配されない実行可能な候補を最大 `capacity` 個保存する保管庫（アーカイブ）である。
`insert` は、実行可能で、保存した点に支配も一致もされない候補だけを残し、その候補が支配する点を取り除く。
容量を超えると混雑距離（次の節）の最も小さい候補を捨て、捨てた数は `pruned()` で読む。
`ParetoArchive::hypervolume_2d(reference)` は二目的のアーカイブの超体積を $O(n^2)$（$n$ は保存した点の数）で計算し、参照点より悪い成分を持つ点があれば `InvalidInput` を返す。
`verify()` は、残した候補が実行可能で互いに支配しないことを独立に確かめる。
`entries()` は保存した点を `ParetoEntry`（点、目的、制約の値、違反量、反復観測の数と標準誤差の借用）として返す。
容量を制限したアーカイブは Pareto 集合全体の列挙ではない。

## NSGA-II の世代

NSGA-II（Deb ほか, 2002）は、候補を非支配の階層で順位付けし、同じ階層では混雑距離で目的空間の広がりを保つ。
最初の集団は `StartDesign`（既定は箱の中の一様乱数）で作り、一世代は次の手順で進む。

1. 集団から二つを無作為に選んで比べる勝ち抜きで、親を二つ選ぶ。
   順位が小さい方が勝ち、同じなら混雑距離が大きい方、それも同じなら先に作られた方が勝つ。
2. 座標を $[0,1]$ に正規化し、確率 0.9 で模擬二進交叉（SBX、分布指数 15）を行う。
   交叉する場合は座標ごとに確率 1/2 で交叉の値をとり、それ以外の座標は一つ目の親の値を写す。
   さらに座標ごとに確率 $1/d$（$d$ は変数の数）で多項式変異（分布指数 20）をかける。
   これを $P$ 回繰り返して、$P$ 個の子を作る。
3. 親と子の $2P$ 個を非支配ソートで階層に分け、各階層の中で混雑距離を計算する。
4. 階層の順に $P$ 個を残し、入りきらない階層は混雑距離の大きい順に選ぶ（エリート保存）。

混雑距離は階層の中で目的 $m$ の値で並べたときの両隣の差をその目的の範囲で割り、全目的で足した量で、両端の点は無限大とする。
制約がある場合は Deb の制約付き支配を使い、実行可能な点は実行不可能な点に勝ち、実行不可能な点どうしは制約違反の総和の小さい方が勝つ。
評価した点はすべてアーカイブに渡され、アーカイブは実行可能で支配されない点を残す。
非支配ソートは一世代に $O(M(2P)^2)$ の比較を使い、作業領域も集団の大きさの 2 乗で増える。

`Nsga2Problem::new(objective, bounds)` は `SampledObjective` と `FiniteBounds` の箱を借用し、目的の成分が 0 個か次元が箱と違えば `InvalidInput` を返す。
`with_constraints` で制約、`with_sampler` で標本器を加える。
`Nsga2Options::new(population, archive, generations)` は失敗せず、集団数 4 未満、アーカイブ容量 0、$[0,1]$ の外の確率、正の有限値でない分布指数は `Nsga2::new` が `InvalidInput` で拒否する。
既定は目的の反復観測 1 回、シード 42、上の交叉と変異の値、実行可能性の既定の許容誤差、逐次実行で、`with_replicates`、`with_seed`、`with_variation`、`with_feasibility` で変える。
目的にノイズがあるときは `with_replicates` で各点の観測を平均するが、支配の判定は標本平均で行い、標準誤差を考慮しない。
標本化した目的の仕様は[標本化した目的と勾配](oxref:optimize-sampled-objective)にまとめた。

`Nsga2Result` は `population()`（最終の集団で、実行不可能な点も含む）、`archive()`（全世代で見つけた実行可能で支配されない候補）、`least_violating()`（違反の総和が最小の点）、`generations()` を返す。
`Nsga2Workspace` を `solve_into` に渡すと作業領域を再利用でき、`checkpoint()` で保存した `Nsga2Checkpoint` から `resume_into` で続けられる。
`workspace_requirements(&problem)` が返す `Nsga2WorkspaceRequirements` は変数の数、目的の数、等式と不等式の制約の数、集団の大きさを持ち、作業領域は親と子を合わせた 2 倍の候補を保持する。
`Nsga2Workspace` は直前の呼び出しを記録し、`last_attempt()` の `progress()` が返す `Nsga2Progress` から完了した世代数 `generations()` とアーカイブの点の数 `archived()` を読める。
世代の上限に達した終了は `SearchBudgetCompleted` で、NSGA-II は成功を返しない。
この終了は真の Pareto 前線を求め終えたことを意味せず、アーカイブの点が Pareto 最適である保証もない。

## 解析前線との比較

二変数の ZDT1 で $f_1=x_0$、$g=1+9x_1$、$f_2=g(1-\sqrt{x_0/g})$ とする（$x\in[0,1]^2$）。
$f_1$ を固定すると $f_2=g-\sqrt{f_1g}$ は $g\ge1$ で増加する（$\partial f_2/\partial g=1-\sqrt{f_1}/(2\sqrt g)>0$）ので、$g=1$、つまり $x_1=0$ が解析前線 $f_2=1-\sqrt{f_1}$ を与える。
参照点 $r=(1.1,1.1)$ に対する解析前線の超体積は、$0\le f_1\le1$ の部分 $\int_0^1(1.1-f_2)\,df_1=0.1+\tfrac23$ と、点 $(1,0)$ が支配する $1\le f_1\le1.1$ の帯 $0.1\times1.1$ の和で、$0.87667$ である。

次のセルは集団 40、アーカイブの容量 80 で解く。
入力は世代数とシードである。
グラフは目的空間に解析前線（破線）と最終の集団（点）を重ねる。
表はアーカイブの候補数、参照点の外にある候補数、超体積と解析値、集団の縦方向の隔たり $f_2-(1-\sqrt{f_1})$ の平均と最大、終了理由である。
参照点の外に候補が残ると超体積は定義されないので、その場合は空欄にする。
最後に終了状態を判定として示す。

```rust
//|       - {"artifact":"front","path":"/rows/0/1","equals":0}

//|       - {"artifact":"front","path":"/rows/0/3","approx":{"value":0.876667,"atol":1e-6}}
//|       - {"artifact":"front","path":"/rows/0/4","range":{"min":0,"max":1e-3}}
//|       - {"artifact":"front","path":"/rows/0/6","equals":"SearchBudgetCompleted"}
//|       - {"path":"/outputs/2/state","equals":"partial"}
//|   - case: long-run
//|     expect:
//|       - {"artifact":"front","path":"/rows/0/1","equals":0}
//|       - {"artifact":"front","path":"/rows/0/2","range":{"min":0.865,"max":0.8767}}
//|   - case: short-run
//|     expect:
//|       - {"artifact":"front","path":"/rows/0/1","range":{"min":1,"max":80}}
//|       - {"artifact":"front","path":"/rows/0/2","equals":null}
//|   - case: seed-1
//|     expect:
//|       - {"artifact":"front","path":"/rows/0/1","equals":0}
//|       - {"artifact":"front","path":"/rows/0/2","range":{"min":0.865,"max":0.8767}}
use scioxide_core::{Budget, SciOxideError, RealScalar};
use scioxide_optimize::{
    FiniteBounds, NoiseModel, Nsga2, Nsga2Options, Nsga2Problem, SampledObjective,
};
struct Zdt;
impl SampledObjective<f64> for Zdt {
    fn dimension(&self) -> usize {
        2
    }
    fn objectives(&self) -> usize {
        2
    }
    fn noise_model(&self) -> NoiseModel {
        NoiseModel::Deterministic
    }
    fn sample_into(&self, x: &[f64], _: u64, out: &mut [f64]) -> Result<(), SciOxideError> {
        let g = 1.0 + 9.0 * x[1];
        out[0] = x[0];
        out[1] = g * (1.0 - RealScalar::sqrt(x[0] / g));
        Ok(())
    }
}
let bounds = FiniteBounds::new(vec![(0.0, 1.0); 2]).map_err(|e| e.to_string())?;
let problem = Nsga2Problem::new(&Zdt, &bounds).map_err(|e| e.to_string())?;
let options = Nsga2Options::new(
    40,
    80,
    Budget::try_from(generations as usize).map_err(|e| e.to_string())?,
)
.with_seed(seed as u64);
let result = Nsga2::new(options)
    .map_err(|e| e.to_string())?
    .solve(&problem)
    .map_err(|e| e.to_string())?;
let points: Vec<_> = result
    .population()
    .filter(|p| p.is_feasible())
    .map(|p| [p.objectives()[0], p.objectives()[1]])
    .collect();
// 参照曲線: 解析前線 f₂ = 1 − √f₁（f64 の固有メソッドで書いた独立な式）。
let exact: Vec<_> = (0..=100)
    .map(|i| {
        let x = i as f64 / 100.0;
        [x, 1.0 - x.sqrt()]
    })
    .collect();
emit_chart!(serde_json::json!({
    "kind": "xy",
    "dataZoom": true,
    "tooltip": true,
    "xLabel": "目的 f₁ [-]",
    "yLabel": "目的 f₂ [-]",
    "layers": [
        {"id": "front", "kind": "line", "name": "解析前線", "points": exact, "style": {"lineType": "dashed"}},
        {"id": "population", "kind": "scatter", "name": "最終の集団", "points": points}
    ]
}));
// 解析前線の超体積（参照点 (1.1, 1.1)）: 0.1 + 2/3 + 0.11。
let exact_volume = 0.1 + 2.0 / 3.0 + 0.11;
// 超体積は全ての候補が参照点の内側にあるときだけ定義する。
let outside = result
    .archive()
    .entries()
    .filter(|e| e.objectives()[0] > 1.1 || e.objectives()[1] > 1.1)
    .count();
let volume = if outside == 0 {
    Some(
        result
            .archive()
            .hypervolume_2d([1.1, 1.1])
            .map_err(|e| e.to_string())?,
    )
} else {
    None
};
// 独立検算: 解析前線からの縦方向の差（f64 の固有メソッドで書いた式）。
let gaps: Vec<f64> = points.iter().map(|p| p[1] - (1.0 - p[0].sqrt())).collect();
let worst = gaps.iter().copied().fold(0.0, f64::max);
let mean = gaps.iter().sum::<f64>() / gaps.len() as f64;
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let fixed5 = serde_json::json!({ "fractionDigits": 5 });
let columns = serde_json::json!([

    { "key": "4", "label": "集団の縦差の平均 [-]", "type": "number", "format": sci2 },
    { "key": "5", "label": "集団の縦差の最大 [-]", "type": "number", "format": sci2 },
    { "key": "6", "label": "終了理由" }
]);
emit_table_with_columns!(
    columns,
    vec![(
        result.archive().len(),
        outside,
        volume,
        exact_volume,
        mean,
        worst,
        result.termination().to_string()
    )],
    metadata = serde_json::json!({ "id": "front" })
);
// NSGA-II は成功を返しないので、世代の上限による終了は partial にする。
let mut outcome =
    Outcome::partial("世代の上限まで探索し、アーカイブを Pareto 前線の近似として返した")
        .explanation("アーカイブの点が Pareto 最適である保証はない。")
        .status(result.termination().to_string())
        .diagnostic("世代", result.generations() as f64, None)
        .diagnostic("アーカイブの候補", result.archive().len() as f64, None);

    outcome = outcome.diagnostic("超体積の不足", exact_volume - v, None);
}

```

既定の 40 世代、シード 7 では、アーカイブは容量いっぱいの 80 個の候補を持ち、超体積は 0.87060、解析値 0.87667 との差は 0.0061 である。
最終の集団では縦方向の隔たりが平均 $4.1\times10^{-4}$、最大 0.014 で、グラフでは点が破線の前線に沿って $f_1\in[0,1]$ 全体に並ぶ。
解析前線の上に 80 点を置いた階段が失う面積を前線の積分から求めると、$f_1$ を等間隔にした場合は 0.0066、両目的の正規化した差の和を等間隔にした場合は 0.0057 である。
観測した不足 0.0061 はこの範囲にあるので、超体積の不足のほとんどは点の数が有限であることによる。
100 世代でも不足は 0.0059 までしか縮まず、10 世代では参照点の外の候補が残って超体積が求まらない。
シード 1 では超体積が 0.87002 で、シード 7 との違いは $6\times10^{-4}$ 程度である。
判定は世代の上限による終了なので partial である。
縦方向の隔たりは前線へのユークリッド距離ではない。
前線に近くても、その一部に候補が偏っていれば交換条件を十分に示せない。

## まとめ

多目的最適化は目的間の交換条件を候補の集合として示し、近似の良さは解析前線や既知の前線に対する超体積で測れる。
NSGA-II の超体積の不足には点の数による階段近似の分が含まれるので、世代を増やす前にアーカイブの容量と候補の分布を確かめる。
NSGA-II は世代の上限まで進んでも成功でない `SearchBudgetCompleted` で止まり、成功を返しないので、アーカイブの点は Pareto 前線の近似として読み、別の方法か既知の前線で確かめる。
制約がある問題では、アーカイブが空なら `least_violating()` で違反の最も小さい点を調べる。
