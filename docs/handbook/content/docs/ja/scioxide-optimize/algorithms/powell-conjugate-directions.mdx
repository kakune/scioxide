Powell の共役方向法は方向の組に沿った一次元の最小化を順に繰り返し、一周の正味の移動から新しい方向を作る導関数不要の局所法である。
評価値だけを使う点は [Nelder–Mead 法](../derivative-free-local/)と同じだが、二次関数の構造を利用して方向を作り、有限の箱の中も探せる。
このページでは共役方向の性質からアルゴリズムを導き、SciOxide の `Powell` の方向の置き換え、箱と固定変数、一次元探索の上限と停止を説明する。

## 共役方向と平行部分空間の性質

正定値行列 $\mathbf{A}$ を持つ二次関数 $f(\mathbf{x})=\tfrac12\mathbf{x}^\mathsf{T}\mathbf{A}\mathbf{x}-\mathbf{b}^\mathsf{T}\mathbf{x}$ を考える。
方向の組 $\mathbf{d}_1,\dots,\mathbf{d}_n$ が $\mathbf{d}_i^\mathsf{T}\mathbf{A}\mathbf{d}_j=0$（$i\ne j$）を満たすとき、$\mathbf{A}$ に関して共役であるという。
共役な方向に沿って順に厳密な一次元最小化を行うと、どの開始点からも $n$ 回で最小点 $\mathbf{A}^{-1}\mathbf{b}$ に達する。
一回の最小化が以前の方向での最小性を壊さないからである。

導関数を使わずに共役な方向を作る鍵は、平行部分空間の性質である。
同じ方向 $\mathbf{d}$ に沿って、異なる二つの点から一次元最小化を行い、最小点 $\mathbf{x}_a$、$\mathbf{x}_b$ を得たとする。
最小点では方向微分が零なので $\mathbf{d}^\mathsf{T}(\mathbf{A}\mathbf{x}_a-\mathbf{b})=0$、$\mathbf{d}^\mathsf{T}(\mathbf{A}\mathbf{x}_b-\mathbf{b})=0$ で、差を取ると

$$
\mathbf{d}^\mathsf{T}\mathbf{A}(\mathbf{x}_b-\mathbf{x}_a)=0
$$

となる。
二点を結ぶ方向は $\mathbf{d}$ と共役であり、評価値だけで共役な方向が得られる。

Powell 法はこの性質を一周ごとに使う。
始点 $\mathbf{x}_0$ から方向 $\mathbf{d}_1,\dots,\mathbf{d}_n$ に沿って順に最小化して $\mathbf{x}_N$ に達したら、正味の変位 $\mathbf{d}_{\mathrm{new}}=\mathbf{x}_N-\mathbf{x}_0$ に沿ってもう一度最小化し、古い方向の一つを $\mathbf{d}_{\mathrm{new}}$ で置き換える。
二次関数で、厳密な一次元最小化と一次独立な方向の組が保たれれば、$n$ 周のうちに共役な方向の組ができて最小点に達する（Powell 1964）。
実際には置き換えを続けると方向の組が一次従属に近づくので、置き換えを判定して避ける。

## 方向の置き換えと階数

一周の目的値を $f_0=f(\mathbf{x}_0)$、$f_N=f(\mathbf{x}_N)$、外挿点の値を $f_E=f(2\mathbf{x}_N-\mathbf{x}_0)$ とし、一周の中で一つの方向が与えた最大の減少を $\Delta f$ とする。
`Powell` は Powell の判定

$$
f_E<f_0 \quad\text{かつ}\quad 2(f_0-2f_N+f_E)(f_0-f_N-\Delta f)^2<\Delta f\,(f_0-f_E)^2
$$

を満たすときだけ、最大の減少を与えた方向を置き換える候補にする。
判定が成り立たなければ置き換えず、同じ組で次の周へ進む。
判定の根拠は、置き換えた組で方向の行列式が小さくならないことを求める Powell の議論にある（Powell 1964、Brent 1973 の第 7 章）。

候補を採るときは、さらに方向の組の数値階数を確かめる。
各方向を絶対値が最大の成分で割り、固定変数の行を 0 にした $n\times n$ の方向行列に列ピボット付き QR 分解を行い、`RankThreshold`（既定は絶対・相対とも $\sqrt{\varepsilon_{\mathrm{mach}}}$）で数値階数を決める。
階数が自由変数の数に満たなければ置き換えを捨て、`PowellDiagnostics::rejected_replacements` に数える。
採った場合は新しい方向に沿って最小化し、置き換える列に最後の古い方向を移して、新しい方向を最後の列に置く。
置き換えた回数は `replacements` に数える。

この行列の階数は最大で $n$ だが、固定変数があれば階数は自由変数の数までしか上がらない。
`PowellDiagnostics` の自由変数の数（`free_dimension`）と階数（`rank`）を比べると、固定変数による見かけの階数不足と、方向の組の本当の退化を区別できる。
初期の方向（既定は座標軸、`PowellOptions::with_directions` で $n\times n$ 行列の列として指定）が自由変数を張らなければ、解く前に `InvalidInput` になる。

## 箱と固定変数

`Powell` は無制約の目的か、有限の箱を持つ `BoundedObjective` を受け取る。
箱を使う場合はすべての変数に有限の上下限が要り、片側だけの境界は `InvalidInput` になる。
上下限が等しい変数は固定変数で、方向のその成分を 0 にして動かさない。
一次元最小化は方向に沿って箱の中に収まる区間の上で行うので、試行点はすべて箱の中にある。
外挿点 $2\mathbf{x}_N-\mathbf{x}_0$ が箱の外に出る周では、置き換えの判定を飛ばす。
すべての変数が固定なら、開始点を一回評価して `Converged` で止まる。

## 一次元探索と停止

各方向の一次元最小化は `ScalarMinimizer` の Brent 法で行う。
無制約なら刻み 0 と 1 の点から括弧を探し、箱があれば方向に沿って箱に収まる区間全体で最小化する。
区間全体の探索は現在の点から離れた別の谷に落ち着くことがある。
そのため箱があるとき、区間全体の探索で現在の値より下がらなければ、現在の点から方向に沿って刻み $+1$ と $-1$（区間の端が近ければその端まで）の試し点を一つずつ評価する。
現在の値より低い試し点があれば現在の点とその点の間で、両側とも高ければ二つの試し点が現在の点を囲む括弧の中で、もう一度 Brent 法で最小化する。
これで現在の点のすぐ近くにある減少を見落とさない。
一次元探索の設定は `PowellOptions::with_scalar_options` の `ScalarMinimumOptions`（既定は絶対・相対とも $\sqrt{\varepsilon_{\mathrm{mach}}}$ の許容誤差、1000 反復、2000 評価）である。
一次元探索が停滞するか、それ自身の反復上限に達した場合は、その方向の探索だけを打ち切って次の方向へ進む。
`Powell` 全体の評価の上限、時間上限、取り消しに当たった場合は、解法全体が止まる。
一次元探索の結果は目的が下がったときだけ採り、NaN や無限大を返した試行はどの有限の値よりも悪い点として扱う。

一周を終えるたびに、各方向の移動と正味の変位のうち最大の座標の移動 $\delta_x$ と、一周の目的の減少 $\delta_f=|f_0-f_N|$ を調べ、

$$
\delta_x\le\tau^x_{\mathrm{abs}}+\tau^x_{\mathrm{rel}}\max(\|\mathbf{x}_0\|_\infty,\|\mathbf{x}_N\|_\infty),\qquad
\delta_f\le\tau^f_{\mathrm{abs}}+\tau^f_{\mathrm{rel}}\max(|f_0|,|f_N|)
$$

の両方を満たせば `Converged` で止まる。
許容誤差は `with_step_tolerance` と `with_function_tolerance` で指定し、既定はどれも $\sqrt{\varepsilon_{\mathrm{mach}}}$ である。
正味の変位が 0 になった周は `Stagnation`、周の上限（既定 1000 周、`with_max_iterations`）は `IterationLimit`、一次元探索を含めた目的の評価の上限（既定 2000 回、`with_max_evaluations`）は `EvaluationLimit` で止まる。
`Converged` 以外では、それまでに評価した最良の点が推定値として返る。
`PowellDiagnostics` の `step`、`step_scale`、`function_change`、`function_scale` は最後に終えた周の $\delta_x$、座標の尺度、$\delta_f$、目的の尺度である。

一周の評価回数は $n$ 回の一次元最小化の評価の和に、外挿点の 1 回（箱の外なら評価しない）と、置き換えたときの一次元最小化 1 回分を足した数である。
箱があるときは、区間全体の探索で下がらなかった方向ごとに、試し点の評価（最大 2 回）ともう一度の一次元最小化の評価が加わる。
評価以外の演算は一周あたり $O(n^2)$ で、Powell の判定を満たした置き換えの候補ごとに、方向行列の列ピボット付き QR 分解の $O(n^3)$ が加わる。
一次元最小化の評価回数は目的の形と許容誤差で決まり、$\sqrt{\varepsilon_{\mathrm{mach}}}$ の許容誤差では一回に数十回になることが多い。
`PowellOptions` は不変の設定で、`Powell::new` が初期の方向の形と有限性を検査する。
準備した `PowellWorkspace` は方向行列、QR 分解と試行点のメモリ（$O(n^2)$）を保持し、必要容量は `PowellWorkspaceRequirements` で確認する。

## 固定変数と方向階数

二変数のうち第二成分を 1 に固定し、$|x_1-a|+x_2^2$ を最小にする。
入力は目標 $a$ で、開始点を $(0,1)$ とする。
出力は最小点と解析解との差の表と、自由変数の数、射影した方向行列の数値階数、その大きさ $n$、評価回数、終了理由の表である。
独立な解析解は $(a,1)$ で、そこでの目的値は 1 になる。
射影した $2\times2$ の方向行列の階数 1 は $n=2$ より小さいが、自由変数の数 1 と一致していればよいことを確かめる。
最後に、終了理由を計算の判定として示す。

```rust
//| id: optimize-powell-fixed-coordinate
//| ref: optimize-powell-fixed-coordinate
//| title: 固定変数を含む方向集合で解析最小点を求める
//| run: reactive
//| crates: [scioxide-optimize, scioxide-core, scioxide-linalg]
//| inputs:
//|   target_coordinate: {"type":"range","label":"自由成分の目標 a [-]","min":-1,"max":1,"step":0.25,"value":0.25}
//| cases:
//|   - {"id":"target-at-start","label":"a = 1","description":"目標が開始点から長さ 1 の位置にあり、70 回の評価で x₁ = 1 に一致する。","inputs":{"target_coordinate":1}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"solution","path":"/rows/0/1","equals":1}
//|       - {"artifact":"solution","path":"/rows/0/2","range":{"min":0,"max":1e-8}}
//|       - {"artifact":"rank","path":"/rows/0/0","equals":1}
//|       - {"artifact":"rank","path":"/rows/0/1","equals":1}
//|       - {"artifact":"rank","path":"/rows/0/2","equals":2}
//|       - {"artifact":"rank","path":"/rows/0/3","range":{"min":70,"max":110}}
//|       - {"artifact":"rank","path":"/rows/0/4","equals":"Converged"}
//|       - {"path":"/outputs/2/state","equals":"satisfied"}
//|   - case: target-at-start
//|     expect:
//|       - {"artifact":"solution","path":"/rows/0/2","range":{"min":0,"max":1e-8}}
//|       - {"artifact":"rank","path":"/rows/0/4","equals":"Converged"}
//|       - {"path":"/outputs/2/state","equals":"satisfied"}
use scioxide_core::Bounds;
use scioxide_optimize::{ObjectiveFn, OptimizeResult, Powell, PowellOptions};

let a = target_coordinate;
let objective = ObjectiveFn::new(2, move |x: &[f64]| Ok((x[0] - a).abs() + x[1] * x[1]));
// 第二成分は上下限が等しい固定変数。方向は単位行列の二列。
let bounds = Bounds::new(vec![(Some(-2.0), Some(2.0)), (Some(1.0), Some(1.0))])
    .map_err(|e| e.to_string())?;
let matrix = [1.0_f64, 0.0, 0.0, 1.0];
let directions =
    scioxide_linalg::Matrix::from_vec(2, 2, matrix.to_vec()).map_err(|e| e.to_string())?;
let bounded =
    scioxide_optimize::BoundedObjective::new(&objective, &bounds).map_err(|e| e.to_string())?;
let options = PowellOptions::default().with_directions(directions);
let solver = Powell::new(options).map_err(|e| e.to_string())?;
// 作業領域と結果の格納先を先に確保し、準備済みの呼び出しで解く。
let mut work = solver.workspace(2).map_err(|e| e.to_string())?;
let mut result = OptimizeResult::empty();
result.try_reserve(2).map_err(|e| e.to_string())?;
solver
    .minimize_into(
        &bounded,
        &[0.0, 1.0],
        &mut result,
        &mut work,
        scioxide_core::ExecutionContext::sequential(),
    )
    .map_err(|e| e.to_string())?;
let diagnostic = match result.method_diagnostics() {
    scioxide_optimize::OptimizeDiagnostics::Powell(diagnostic) => diagnostic,
    _ => return Err("対応するアルゴリズムの診断がない".to_string()),
};
let (rank, maximum_rank) = diagnostic
    .rank()
    .map_or((0, 0), |r| (r.rank(), r.maximum_rank()));
// 独立検算: 解析解 (a, 1) との差と、最小値 1 との差を元の座標で測る。
let x = result.x();
let general = serde_json::json!({ "significantDigits": 10 });
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let columns = serde_json::json!([
    { "key": "0", "label": "x₁ [-]", "type": "number", "format": general },
    { "key": "1", "label": "x₂ [-]", "type": "number", "format": general },
    { "key": "2", "label": "|x₁ − a| [-]", "type": "number", "format": sci3 },
    { "key": "3", "label": "目的値 − 1 [-]", "type": "number", "format": sci3 }
]);
emit_table_with_columns!(
    columns,
    vec![(x[0], x[1], (x[0] - a).abs(), result.fun() - 1.0)],
    metadata = serde_json::json!({ "id": "solution" })
);
let rank_columns = serde_json::json!([
    { "key": "0", "label": "自由変数の数 [個]", "type": "integer" },
    { "key": "1", "label": "射影した方向行列の数値階数", "type": "integer" },
    { "key": "2", "label": "方向行列の大きさ n", "type": "integer" },
    { "key": "3", "label": "目的の評価 [回]", "type": "integer" },
    { "key": "4", "label": "終了理由" }
]);
let termination = result.termination();
emit_table_with_columns!(
    rank_columns,
    vec![(
        diagnostic.free_dimension(),
        rank,
        maximum_rank,
        result.fun_evals(),
        termination.to_string()
    )],
    metadata = serde_json::json!({ "id": "rank" })
);
let outcome = if termination.is_success() {
    Outcome::satisfied("一周の移動と目的の減少が許容誤差を下回った")
} else {
    Outcome::partial("停止の判定を満たす前に止まった")
};
emit_outcome!(
    outcome
        .status(termination.to_string())
        .diagnostic("目的の評価", result.fun_evals() as f64, None)
        .diagnostic("|x₁ − a|", (x[0] - a).abs(), None)
);
```

既定の $a=0.25$ では 2 周、87 回の評価で `Converged` に達し、$|x_1-a|=2.5\times10^{-10}$、第二成分は 1 のまま動かない。
1 周目で $x_1$ はほぼ $a$ に達するので、停止を確かめる 2 周目では区間全体の探索で値が下がらず、両側の試し点 2 回と、それが作る括弧の中の一次元最小化の評価が加わる。
自由変数は 1 個、射影した方向行列の数値階数は 1 で、その大きさ $n=2$ には届かないが、自由変数の数とは一致する。
`RankReport::is_full_rank()` はこの $2\times2$ 行列が取りうる最大の階数 2 と比べるので `false` を返し、自由空間での退化を表すわけではない。
目的の $|x_1-a|$ は最小点で微分できないが、Powell 法は値の比較だけを使うので問題にならない。

## 回転した楕円の谷と初期の方向

初期の方向が周の数と評価回数に与える効果を、$n=8$ の二次関数 $f(\mathbf{x})=\tfrac12(\mathbf{x}-\mathbf{c})^\mathsf{T}\mathbf{A}(\mathbf{x}-\mathbf{c})$ で調べる。
$\mathbf{A}=\mathbf{Q}\boldsymbol{\Lambda}\mathbf{Q}^\mathsf{T}$ の固有値は $\lambda_k=\kappa^{k/7}$（$k=0,\dots,7$）で、条件数は $\kappa$ である。
$\mathbf{Q}$ は座標の組 $(x_1,x_2)$、$(x_3,x_4)$、… をそれぞれ角度 $\theta$ だけ回す回転で、$\theta=0$ なら座標軸が固有ベクトルになる。
最小点は $c_i=1+0.5(i-1)$ で、開始点は原点である。
固有ベクトルは互いに $\mathbf{A}$ に関して共役なので、$\mathbf{Q}$ の列を初期の方向に渡した実行は、一周で最小点に達し、次の周で停止を確かめる。
座標軸から始めた実行と比べ、周の数、評価回数、置き換えの回数、最小点との差を読む。
最後に、座標軸から始めた実行の終了理由を計算の判定として示す。

```rust
//| id: optimize-powell-rotated-quadratic
//| ref: optimize-powell-rotated-quadratic
//| title: 座標軸から始めた方向の組と共役な方向の組を比べる
//| run: reactive
//| crates: [scioxide-core, scioxide-linalg, scioxide-optimize]
//| inputs:
//|   condition: {"type":"select","label":"条件数 κ [-]","description":"固有値の広がり。1 では等方的な二次関数になる。","options":["1","100","10000"],"value":"100"}
//|   angle: {"type":"range","label":"回転角 θ [°]","description":"固有ベクトルを座標軸から回す角度。0° では座標軸が共役になる。","min":0,"max":45,"step":5,"value":30}
//| cases:
//|   - {"id":"aligned","label":"θ = 0°","description":"座標軸が固有ベクトルなので、どちらの組も 2 周で止まる。","inputs":{"angle":0}}
//|   - {"id":"budget","label":"κ = 10⁴、θ = 45°","description":"座標軸から始めた実行は 2000 回の評価の上限に達する。","inputs":{"condition":"10000","angle":45}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"directions","path":"/rows/0/1","equals":"Converged"}
//|       - {"artifact":"directions","path":"/rows/0/2","range":{"min":5,"max":15}}
//|       - {"artifact":"directions","path":"/rows/0/6","range":{"min":0,"max":1e-7}}
//|       - {"artifact":"directions","path":"/rows/1/1","equals":"Converged"}
//|       - {"artifact":"directions","path":"/rows/1/2","equals":2}
//|       - {"artifact":"directions","path":"/rows/1/6","range":{"min":0,"max":1e-12}}
//|       - {"path":"/outputs/1/state","equals":"satisfied"}
//|   - case: aligned
//|     expect:
//|       - {"artifact":"directions","path":"/rows/0/2","equals":2}
//|       - {"artifact":"directions","path":"/rows/1/2","equals":2}
//|   - case: budget
//|     expect:
//|       - {"artifact":"directions","path":"/rows/0/1","equals":"EvaluationLimit"}
//|       - {"artifact":"directions","path":"/rows/0/3","equals":2000}
//|       - {"artifact":"directions","path":"/rows/1/1","equals":"Converged"}
//|       - {"path":"/outputs/1/state","equals":"partial"}
use scioxide_core::RealScalar;
use scioxide_linalg::Matrix;
use scioxide_optimize::{
    ObjectiveFn, OptimizeDiagnostics, OptimizeResult, Powell, PowellOptions,
};

let n = 8_usize;
let kappa: f64 = condition
    .parse()
    .map_err(|_| "条件数を読めない".to_string())?;
let theta = RealScalar::to_radians(angle);
let (cos, sin) = (RealScalar::cos(theta), RealScalar::sin(theta));
// Q: 座標の組 (0, 1), (2, 3), … を θ だけ回す。Q の列が A の固有ベクトル。
let mut q = vec![0.0_f64; n * n];
for pair in (0..n).step_by(2) {
    q[pair * n + pair] = cos;
    q[pair * n + pair + 1] = -sin;
    q[(pair + 1) * n + pair] = sin;
    q[(pair + 1) * n + pair + 1] = cos;
}
let lambda: Vec<f64> = (0..n)
    .map(|k| RealScalar::powf(kappa, k as f64 / (n - 1) as f64))
    .collect();
// A = Q Λ Qᵀ（行優先）。
let mut a = vec![0.0_f64; n * n];
for row in 0..n {
    for col in 0..n {
        a[row * n + col] = (0..n)
            .map(|k| q[row * n + k] * lambda[k] * q[col * n + k])
            .sum();
    }
}
let center: Vec<f64> = (0..n).map(|i| 1.0 + 0.5 * i as f64).collect();
let objective = ObjectiveFn::new(n, |x: &[f64]| {
    let d: Vec<f64> = x.iter().zip(&center).map(|(xi, ci)| xi - ci).collect();
    let mut value = 0.0;
    for row in 0..n {
        for col in 0..n {
            value += 0.5 * d[row] * a[row * n + col] * d[col];
        }
    }
    Ok(value)
});
let start = vec![0.0; n];
let solve = |options: PowellOptions<f64>| -> Result<OptimizeResult<f64>, String> {
    Powell::new(options)
        .map_err(|e| e.to_string())?
        .minimize(&objective, &start)
        .map_err(|e| e.to_string())
};
let coordinate = solve(PowellOptions::default())?;
let eigen = Matrix::from_vec(n, n, q.clone()).map_err(|e| e.to_string())?;
let conjugate = solve(PowellOptions::default().with_directions(eigen))?;
let mut rows = Vec::new();
for (name, run) in [
    ("座標軸", &coordinate),
    ("固有ベクトル（共役）", &conjugate),
] {
    let OptimizeDiagnostics::Powell(diagnostic) = run.method_diagnostics() else {
        return Err("対応するアルゴリズムの診断がない".to_string());
    };
    // 独立検算: 解析的な最小点 c との差の最大成分。
    let error = run
        .x()
        .iter()
        .zip(&center)
        .fold(0.0_f64, |m, (xi, ci)| m.max((xi - ci).abs()));
    rows.push((
        name,
        run.termination().to_string(),
        run.iterations(),
        run.fun_evals(),
        diagnostic.replacements(),
        diagnostic.rejected_replacements(),
        error,
    ));
}
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let columns = serde_json::json!([
    { "key": "0", "label": "初期の方向" },
    { "key": "1", "label": "終了理由" },
    { "key": "2", "label": "周 [回]", "type": "integer" },
    { "key": "3", "label": "目的の評価 [回]", "type": "integer" },
    { "key": "4", "label": "置き換え [回]", "type": "integer" },
    { "key": "5", "label": "捨てた置き換え [回]", "type": "integer" },
    { "key": "6", "label": "最小点との差の最大 [-]", "type": "number", "format": sci3 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "directions" })
);
let termination = coordinate.termination();
let outcome = if termination.is_success() {
    Outcome::satisfied("座標軸から始めた実行が停止の判定を満たした")
} else {
    Outcome::partial("座標軸から始めた実行が停止の判定を満たす前に止まった")
        .explanation("返された点を推定値として扱い、評価回数の上限や初期の探索方向を見直す。")
};
emit_outcome!(
    outcome
        .status(termination.to_string())
        .diagnostic("目的の評価", coordinate.fun_evals() as f64, None)
        .diagnostic("周", coordinate.iterations() as f64, None)
);
```

既定の $\kappa=100$、$\theta=30^\circ$ では、固有ベクトルを渡した実行は 2 周（目的の評価 358 回）で止まり、最小点との差は 0 である。
座標軸から始めた実行は 9 周、1510 回の評価で `Converged` になり、最小点との差は $1.9\times10^{-9}$ である。
この実行では Powell の判定が一度も成り立たず、置き換えは 0 回で、座標軸のまま周を重ねた。
判定が成り立たなかった周は `rejected_replacements` には数えず、この量は階数の検査で捨てた置き換えだけを数える。
$\theta=0^\circ$ では座標軸が固有ベクトルなので、二つの実行は同じ 2 周、398 回の評価になる。
$\kappa=10^4$、$\theta=45^\circ$ では、座標軸から始めた実行は置き換えを 3 回行うが、10 周で 2000 回の評価の上限に達して `EvaluationLimit` で止まり、最小点との差が $2.9\times10^{-7}$ の点が推定値として返る。
共役な方向が分かっているなら初期の方向として渡し、分からないなら評価の上限と終了理由を合わせて読む。

## まとめ

Powell 法は方向の組に沿った一次元最小化を一周ごとに行い、正味の変位で古い方向を置き換えて共役な方向の組に近づける。
二次関数では平行部分空間の性質から正味の変位が共役になるが、置き換えを続けると方向が一次従属に近づくので、`Powell` は Powell の判定と方向行列の数値階数で置き換えを選ぶ。
`Converged` は一周の座標の移動と目的の減少が許容誤差を下回ったことを示し、勾配が 0 であることは示さない。
固定変数があると方向行列の階数は自由変数の数までしか上がらないので、`free_dimension` と `rank` を比べて退化を判定する。
共役な方向が分かっていれば `with_directions` で渡すと周と評価が減り、評価の上限に達した実行は最良の点を推定値として扱う。
