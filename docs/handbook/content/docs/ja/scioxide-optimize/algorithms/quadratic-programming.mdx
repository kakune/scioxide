凸二次計画（QP）は二次の目的を線形の等式・不等式と変数の上下限の下で最小にする問題である。
最小二乗、ポートフォリオの分散最小化、モデル予測制御、SQP の部分問題など、多くの問題がこの形になる。
目的を $f(\mathbf{x})=\tfrac12\mathbf{x}^\mathsf{T}\mathbf{Q}\mathbf{x}+\mathbf{c}^\mathsf{T}\mathbf{x}$ と書くと、勾配は $\mathbf{Q}\mathbf{x}+\mathbf{c}$ である。
係数 $\tfrac12$ を落とすと勾配も最適点も変わるので、他の定式化から移すときは最初に確かめる。

## KKT 条件と解の一意性

線形の不等式制約だけを持つ問題

$$
\min_{\mathbf{x} \in \mathbb{R}^n} \frac{1}{2}\mathbf{x}^\mathsf{T}\mathbf{Q}\mathbf{x} + \mathbf{c}^\mathsf{T}\mathbf{x} \quad \text{subject to} \quad \mathbf{A}\mathbf{x} \le \mathbf{b}
$$

を考える（$\mathbf{Q}$ は対称な $n\times n$ 行列、$\mathbf{A}\in\mathbb{R}^{m\times n}$）。
制約が線形なので制約想定がいつも成り立ち、局所最小点では KKT 条件

$$
\mathbf{Q}\mathbf{x}+\mathbf{c}+\mathbf{A}^\mathsf{T}\boldsymbol{\lambda}=\mathbf{0},\quad \mathbf{A}\mathbf{x}\le\mathbf{b},\quad \boldsymbol{\lambda}\ge\mathbf{0},\quad \lambda_j(\mathbf{A}\mathbf{x}-\mathbf{b})_j=0
$$

を満たす乗数 $\boldsymbol{\lambda}$ が存在する。
$\mathbf{Q}\succeq0$（半正定値）なら目的は凸で、KKT 条件を満たす点は大域最小点になる。
$\mathbf{Q}\succ0$（正定値）なら目的は強凸で、最小点は存在すれば一意である。
半正定値の場合は目的が平坦な方向が残り、最小点が複数ある場合や、線形項に沿って下に非有界になる場合がある。
元の座標で $\mathbf{Q}$ が正定値でなくても、実行可能な変位の空間に制限して正定値なら、最小点は一意である。

## 方式の選び方

`QpProblem::new(q, c)` で目的を作り、`with_constraints` で行制約、`with_bounds` で変数の上下限を加える。
`QpProblem` では境界を付けない変数は自由変数で、境界のない変数を $x\ge0$ とみなす `LpProblem` とは既定が違う。
非対称な $\mathbf{Q}$ の扱いは列挙型 `HessianSymmetry` で選ぶ。
既定の `RequireSymmetric` は厳密な対称性を要求し、`QpProblem::new` はこの扱いで非対称な $\mathbf{Q}$ を `InvalidInput`（`Inconsistent`）で拒否する。
`QpProblem::new_with_symmetry(q, c, HessianSymmetry::SymmetricPart)` で作ると、非対称な $\mathbf{Q}$ を同じ目的を与える対称部分 $(\mathbf{Q}+\mathbf{Q}^\mathsf{T})/2$ として解釈する。

`QpSolver` は `with_method` で受け取る `QpMethod` に応じて方式を選ぶ。

- `Automatic`（既定）は、変数の上下限だけの問題に射影 Barzilai–Borwein 法、一般の行制約がある問題に有効集合法を使う。
- `ActiveSet` は、上下限だけの問題も含めて有効集合法を使う。
- `PrimalDual` は、拡大 KKT 系に主双対の予測子・修正子法を使う。

どの方式を選んでも、次の二つの場合は専用の経路で解く。
$\mathbf{Q}=\mathbf{0}$ の問題は、`KktProvider` を差し替えていなければ LP として上下限つきの改訂単体法（`SimplexSolver`）で解く。
制約も上下限もない問題は、$\mathbf{Q}\mathbf{x}=-\mathbf{c}$ を $\mathrm{LDL}^\mathsf{T}$ 分解で、$\mathbf{Q}$ が特異なら階数を考慮したスペクトル分解で解く。
上下限だけの問題の射影 BB 法は[ボックス制約の凸二次計画と射影勾配法](../bound-constrained-qp/)で扱う。

## 有効集合法

点 $\mathbf{x}_k$ で等号が成り立っている制約の添字の集合を有効集合 $\mathcal{W}_k$ とする。
有効集合法は $\mathcal{W}_k$ の制約を等式として保ったまま二次モデルを最小にするステップ $\mathbf{p}$ を、KKT 線形系

$$
\begin{bmatrix} \mathbf{Q} & \mathbf{A}_{\mathcal{W}}^\mathsf{T} \\ \mathbf{A}_{\mathcal{W}} & \mathbf{0} \end{bmatrix} \begin{bmatrix} \mathbf{p} \\ \boldsymbol{\lambda}_{\mathcal{W}} \end{bmatrix} = - \begin{bmatrix} \mathbf{Q}\mathbf{x}_k + \mathbf{c} \\ \mathbf{A}_{\mathcal{W}}\mathbf{x}_k - \mathbf{b}_{\mathcal{W}} \end{bmatrix}
$$

から求める。
反復点を実行可能に保つので $\mathbf{A}_{\mathcal{W}}\mathbf{x}_k=\mathbf{b}_{\mathcal{W}}$ であり、$\boldsymbol{\lambda}_{\mathcal{W}}$ は $\mathbf{x}_k+\mathbf{p}$ での乗数になる。

$\mathbf{p}$ に沿って進むとき、能動でない制約を破る手前で止める。
ステップ幅は

$$
\alpha_k=\min\Big(1,\ \min_{i\notin\mathcal{W}_k,\ \mathbf{a}_i^\mathsf{T}\mathbf{p}>0}\frac{b_i-\mathbf{a}_i^\mathsf{T}\mathbf{x}_k}{\mathbf{a}_i^\mathsf{T}\mathbf{p}}\Big)
$$

で、$\alpha_k<1$ なら最小を与えた制約（ぶつかった制約）を有効集合に加える。

$\mathbf{p} = \mathbf{0}$ のときは $\nabla f(\mathbf{x}_k)=-\mathbf{A}_{\mathcal{W}}^\mathsf{T}\boldsymbol{\lambda}_{\mathcal{W}}$ が成り立つ。
制約 $j$ だけを内側へ外す方向 $\mathbf{d}$（$\mathbf{A}_{\mathcal{W}}\mathbf{d}=-\mathbf{e}_j$）では $\nabla f^\mathsf{T}\mathbf{d}=\lambda_j$ なので、負の乗数 $\lambda_j < 0$ を持つ制約を外すと目的が下がる。
そこで負の乗数を持つ制約があれば有効集合から外し、なければ KKT 条件がすべて成り立つので終了する。
$\mathbf{Q}\succ0$ の強凸な QP では $\alpha_k>0$ のステップで目的が真に減って同じ有効集合に戻らないので、退化がなければ有限回の有効集合の変更で最適解に達する（Nocedal and Wright, 2006, 16.5 節）。

`QpSolver` の有効集合法は、初期点（`QpWarmStart` か、0 を上下限へ射影した点）が実行可能でなければ、補助変数を一つ加えた線形計画（段階 I）で実行可能な点を作ってから反復を始める。
外す制約は最も負の乗数を持つものを選び、進まない反復が 8 回続くと最小添字の規則に切り替えて巡回を防ぐ。
変数の上下限は一般の行に展開せず、能動な座標を直接消去し、上下限が等しい変数は等式として扱う。
自由変数に制限した $\mathbf{Q}$ が正定値なら、その Cholesky 分解と、射影した一般の行の QR 分解を保持し、制約が出入りするたびに次元の二乗に比例する作業で更新する。
制限した $\mathbf{Q}$ が特異になる半正定値の部分問題では、階数を考慮した KKT 系の求解に移る。
ステップに沿って制約にぶつからない非有界な方向が見つかると `SuspectedUnbounded` とし、その方向が元の問題で非有界の証明用データとして検査を通れば `Unbounded` にする。
準備の分解は $O(n^3)$、メモリ使用量は $O(n^2)$ である。

## 主双対内点法

主双対法は不等式の余裕 $\mathbf{s}$ と乗数 $\mathbf{z}$ を正に保ち、相補性を徐々に満たす。
不等式を $\mathbf{A}\mathbf{x}+\mathbf{s}=\mathbf{b}$、$\mathbf{s}\ge\mathbf{0}$ と書くと、相補性を $\sigma\mu$ に緩めた KKT 条件は

$$
\mathbf{Q}\mathbf{x}+\mathbf{c}+\mathbf{A}^\mathsf{T}\mathbf{z}=\mathbf{0},\quad \mathbf{A}\mathbf{x}+\mathbf{s}-\mathbf{b}=\mathbf{0},\quad \mathbf{S}\mathbf{Z}\mathbf{e}=\sigma\mu\mathbf{e}
$$

である（$\mathbf{S}=\operatorname{diag}(\mathbf{s})$、$\mathbf{Z}=\operatorname{diag}(\mathbf{z})$、$\mu=\mathbf{s}^\mathsf{T}\mathbf{z}/m$ は平均相補性、$\sigma\in[0,1]$ は中心化係数）。
Newton 方程式から $\Delta\mathbf{s}$ を消去すると、拡大 KKT 系

$$
\begin{bmatrix}\mathbf{Q}&\mathbf{A}^\mathsf{T}\\ \mathbf{A}&-\mathbf{Z}^{-1}\mathbf{S}\end{bmatrix}
\begin{bmatrix}\Delta\mathbf{x}\\ \Delta\mathbf{z}\end{bmatrix}=-\begin{bmatrix}\mathbf{r}_d\\ \mathbf{r}_p+\mathbf{Z}^{-1}\mathbf{r}_c\end{bmatrix}
$$

が残る（$\mathbf{r}_d,\mathbf{r}_p,\mathbf{r}_c$ は上の三つの式の残差）。
予測子と修正子は右辺だけが違うので、同じ分解を使える。

`PrimalDual` は、まず等式行を整理し、段階 I で実行可能な点を作り、不等式の余裕を 1 以上、乗数を 1 に置いて始める。
変数の上下限は拡大系の行にせず、座標ごとに消去する。
各反復では予測子で $\sigma=0$ の方向を求め、その方向で進んだときの平均相補性 $\mu_{\mathrm{aff}}$ から Mehrotra の中心化係数 $\sigma=(\mu_{\mathrm{aff}}/\mu)^3$ を決め、二次の補正項 $-\Delta\mathbf{s}_{\mathrm{aff}}\circ\Delta\mathbf{z}_{\mathrm{aff}}$ を加えた修正子の方向を同じ分解で求める。
ステップ幅は余裕と乗数が正のまま残るよう、1 と境界までの距離の小さい方の 0.995 倍にする。
内点法の反復点は境界に厳密には乗らないので、能動な制約の解は許容誤差の範囲で近づくだけである。

## 凸性の検査

`QpSolver` は凸 QP だけを解き、求解の前に $\mathbf{Q}$（`SymmetricPart` なら対称部分）が半正定値かを確かめる。
Gershgorin の円板か Cholesky 分解で正定値と分かればそのまま進み、分からなければ固有値を計算する。
最小固有値が $-(\tau_{\mathrm{abs}}+\tau_{\mathrm{rel}}\max_{ij}|Q_{ij}|)$（$\tau_{\mathrm{abs}}$、$\tau_{\mathrm{rel}}$ は `OptimalityTolerances` の階数の許容誤差、既定はどちらも $10^{-8}$）より小さければ、解かずに `InvalidInput`（`InvalidInputReason::UnsupportedConfiguration`）のエラーを返す。
非凸 QP の局所解や大域解は提供しないので、そのような問題は[逐次二次計画法（SQP）](../sqp-and-interior-point/)か[非線形内点法](../nonlinear-interior-point/)で局所解を求めるか、[大域探索](../global-search/)を検討する。

## 作業領域と再利用

`QpWorkspace` は有効集合法の作業メモリと試行の記録を持ち、任意の QP を受け付ける。
`QpWorkspace::with_kkt_provider` で KKT 系の分解を差し替えられ、組み込みの選択肢は `DenseKktProvider`（Ruiz の均衡化と rook ピボット付きの密な $\mathrm{LDL}^\mathsf{T}$ 分解）と `SparseKktProvider`（疎な $\mathrm{LDL}^\mathsf{T}$、パターンが変わらなければ並べ替えと記号解析を再利用）である。
差し替えた分解に渡す系は、能動な座標を消去した一般の行だけを含む。
ソルバーは分解が返した解の残差を元の系で確かめるので、不正確な求解は検出される。
分解の差し替えは目的の凸性の証明にはならない。

`QpSolver::with_warm_start(QpWarmStart::new(point)?)` は初期点を与える。
各求解で長さ（違えば `DimensionMismatch`）と実行可能性（実行不能なら `InvalidInput`）を確かめる。
一回だけ解くなら `QpProblem::solve()` が既定の `QpSolver`（`Automatic`、反復上限 1000 回、許容誤差 $10^{-8}$）で解き、成功しない終了を `Err` で返す。
実行不能や非有界と確かめた問題は `DomainError` になる。

結果は `ProgrammingResult` で、`primal_feasibility()`、`stationarity()`、`dual_feasibility()`、`complementarity()` が元の問題での残差を返す。
`ProgrammingVerifier::verify` に元の `QpProblem`（または `QpVerificationProblem::from_problem` で借用した検証用の問題）と結果を渡すと、元の座標の証明用データをソルバーとは独立に再計算できる。
係数の見える問題では半正定値性も確かめて `Accepted` を返しうるが、ヘッセ行列を作用素として渡した `QpVerificationProblem::new` では KKT 条件が通っても `KktOnly` にとどまる。
検査の詳細は[線形・二次計画の証明用データと検証](../programming-certificates/)にある。

## 元の KKT 条件の検算

$x+y=t$、$0\le x\le u$、$y\ge0$ の下で $x^2+2y^2$ を最小にする。
上限が効かなければ、$y=t-x$ を代入して微分すると解析解は $(2t/3,t/3)$ で、等式の乗数は $-4t/3$ になる。
$u<2t/3$ では上限が能動になり、解は $(u,t-u)$ である。
停留性 $2x+\lambda+\alpha_u=0$、$4y+\lambda=0$ から、等式の乗数は $\lambda=-4(t-u)$、上限の乗数は $\alpha_u=4t-6u>0$ になる。
入力は和の右辺 $t$ と $x$ の上限 $u$ である。
セルは 3 つの方式の解と乗数を解析解と比べ、解析乗数で計算した停留性の残差と、ソルバーの結果を `ProgrammingVerifier` で再検査した状態を示す。
等式の乗数と上限の乗数は結果の証明用データ（`ProgrammingResult::certificate()`）から読む。

```rust
//| id: optimize-qp-kkt
//| ref: optimize-qp-kkt
//| title: QP の解と乗数を元の式で確かめる
//| run: reactive
//| crates: [scioxide-core, scioxide-linalg, scioxide-optimize]
//| inputs:
//|   total: {"type":"range","label":"変数の和 t [-]","min":0.5,"max":2,"step":0.25,"value":1}
//|   x_cap: {"type":"range","label":"x の上限 u [-]","description":"u < 2t/3 で上限が能動になる。","min":0.1,"max":2,"step":0.1,"value":2}
//| cases:
//|   - {"id":"active-cap","label":"上限 u = 0.4（能動）","description":"解は (0.4, 0.6) に移り、等式の乗数は −2.4、上限の乗数は 1.6 になる。","inputs":{"x_cap":0.4}}
//|   - {"id":"large-total","label":"和 t = 2","description":"上限は非能動のまま解は (4/3, 2/3)、等式の乗数は −8/3 になる。","inputs":{"total":2}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"methods","path":"/rows/0/1","equals":"Converged"}
//|       - {"artifact":"methods","path":"/rows/1/1","equals":"Converged"}
//|       - {"artifact":"methods","path":"/rows/2/1","equals":"Converged"}
//|       - {"artifact":"methods","path":"/rows/0/4","range":{"min":0,"max":1e-12}}
//|       - {"artifact":"methods","path":"/rows/2/4","range":{"min":0,"max":1e-8}}
//|       - {"artifact":"methods","path":"/rows/0/5","approx":{"value":-1.3333333333333333,"atol":1e-12}}
//|       - {"artifact":"methods","path":"/rows/0/8","equals":"Accepted"}
//|       - {"artifact":"methods","path":"/rows/2/8","equals":"Accepted"}
//|   - case: active-cap
//|     expect:
//|       - {"artifact":"methods","path":"/rows/0/4","range":{"min":0,"max":1e-12}}
//|       - {"artifact":"methods","path":"/rows/0/5","approx":{"value":-2.4,"atol":1e-10}}
//|       - {"artifact":"methods","path":"/rows/0/6","approx":{"value":1.6,"atol":1e-10}}
//|       - {"artifact":"methods","path":"/rows/2/4","range":{"min":0,"max":1e-7}}
//|   - case: large-total
//|     expect:
//|       - {"artifact":"methods","path":"/rows/1/2","approx":{"value":1.3333333333333333,"atol":1e-12}}
//|       - {"artifact":"analytic","path":"/rows/0/2","approx":{"value":-2.6666666666666665,"atol":1e-12}}
use scioxide_core::Bounds;
use scioxide_linalg::Matrix;
use scioxide_optimize::{
    LinearConstraintSense, LinearConstraints, ProgrammingCertificate, ProgrammingVerifier,
    QpMethod, QpProblem, QpSolver, QpVerificationProblem,
};
let general = serde_json::json!({ "significantDigits": 6 });
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
// 目的 x² + 2y² = ½ xᵀ diag(2, 4) x、等式 x + y = t、0 ≤ x ≤ u、y ≥ 0。
let h = Matrix::from_vec(2, 2, vec![2.0_f64, 0.0, 0.0, 4.0]).map_err(|e| e.to_string())?;
let c = LinearConstraints::new(
    Matrix::from_vec(1, 2, vec![1.0, 1.0]).map_err(|e| e.to_string())?,
    vec![total],
    vec![LinearConstraintSense::Equal],
)
.map_err(|e| e.to_string())?;
let bounds = Bounds::new(vec![(Some(0.0), Some(x_cap)), (Some(0.0), None)])
    .map_err(|e| e.to_string())?;
let p = QpProblem::new(h, vec![0.0; 2])
    .and_then(|p| p.with_constraints(c))
    .and_then(|p| p.with_bounds(bounds))
    .map_err(|e| e.to_string())?;
// 独立な解析解: 上限が非能動なら (2t/3, t/3)、能動なら (u, t − u)。
let (ax, ay) = if x_cap >= 2.0 * total / 3.0 {
    (2.0 * total / 3.0, total / 3.0)
} else {
    (x_cap, total - x_cap)
};
// 停留性 Qx + λ(1, 1) + (α_u, 0) = 0 から等式の乗数 λ と上限の乗数 α_u を決める。
let lambda = -4.0 * ay;
let alpha = -2.0 * ax - lambda;
let view = QpVerificationProblem::from_problem(&p);
let verifier = ProgrammingVerifier::default();
let mut rows = Vec::new();
for (name, method) in [
    ("Automatic", QpMethod::Automatic),
    ("ActiveSet", QpMethod::ActiveSet),
    ("PrimalDual", QpMethod::PrimalDual),
] {
    let r = QpSolver::default()
        .with_method(method)
        .solve(&p)
        .map_err(|e| e.to_string())?;
    let x = r.x();
    let (row, upper) = match r.certificate() {
        Some(ProgrammingCertificate::Optimality { dual, .. }) => {
            (Some(dual.rows[0]), Some(dual.upper[0]))
        }
        _ => (None, None),
    };
    let stationary = (2.0 * x[0] + lambda + alpha)
        .abs()
        .max((4.0 * x[1] + lambda).abs());
    let report = verifier.verify(&view, &r).map_err(|e| e.to_string())?;
    rows.push((
        name,
        r.termination().to_string(),
        x[0],
        x[1],
        (x[0] - ax).abs().max((x[1] - ay).abs()),
        row,
        upper,
        stationary,
        format!("{:?}", report.status()),
        r.iterations(),
    ));
}
let columns = serde_json::json!([
    { "key": "0", "label": "方式" },
    { "key": "1", "label": "終了理由" },
    { "key": "2", "label": "x [-]", "type": "number", "format": general },
    { "key": "3", "label": "y [-]", "type": "number", "format": general },
    { "key": "4", "label": "解析解との差 [-]", "type": "number", "format": sci2 },
    { "key": "5", "label": "等式の乗数 [-]", "type": "number", "format": general, "nullText": "なし" },
    { "key": "6", "label": "x 上限の乗数 [-]", "type": "number", "format": general, "nullText": "なし" },
    { "key": "7", "label": "解析乗数での停留残差 [-]", "type": "number", "format": sci2 },
    { "key": "8", "label": "検証状態" },
    { "key": "9", "label": "反復 [回]", "type": "integer" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "methods" })
);
let analytic_columns = serde_json::json!([
    { "key": "0", "label": "解析解 x [-]", "type": "number", "format": general },
    { "key": "1", "label": "解析解 y [-]", "type": "number", "format": general },
    { "key": "2", "label": "等式の乗数 λ [-]", "type": "number", "format": general },
    { "key": "3", "label": "上限の乗数 α_u [-]", "type": "number", "format": general }
]);
emit_table_with_columns!(
    analytic_columns,
    vec![(ax, ay, lambda, alpha)],
    metadata = serde_json::json!({ "id": "analytic" })
);
```

既定の $t=1$、$u=2$ では 3 方式とも `Converged` で、検証状態は `Accepted` である。
`Automatic` と `ActiveSet` は一般の行があるのでどちらも有効集合法になり、5 反復で解析解 $(2/3,1/3)$ に丸め誤差なしで一致し、等式の乗数は $-4/3$ である。
`PrimalDual` は 8 反復で解析解との差 $4.5\times10^{-11}$ に達し、上限の乗数も 0 ではなく $6.6\times10^{-12}$ になる。
内点法の解は許容誤差の範囲で解析解に近づくだけであることが分かる。
$u=0.4$ にすると上限が能動になり、有効集合法は 4 反復で $(0.4,0.6)$、等式の乗数 $-2.4$、上限の乗数 $1.6$ を返して解析的な値と一致する。
`PrimalDual` はこのとき解析解との差が $7.6\times10^{-9}$ で、$u=0.1$ では $9.2\times10^{-12}$ になり、差の大きさは反復が止まった位置で変わる。
解析乗数による停留残差は、ソルバーが内部で推定した乗数を使わずに計算した独立な検算である。

## まとめ

凸 QP の最適性は KKT 条件で判定でき、$\mathbf{Q}\succeq0$ なら KKT 点は大域最小点、$\mathbf{Q}\succ0$ なら一意である。
有効集合法は等式制約つきの KKT 系を解き、ぶつかった制約を加え、負の乗数を持つ制約を外して、能動な制約を丸め誤差の範囲で正確に満たす解を返す。
主双対内点法は境界の内側から近づくので、能動な制約は許容誤差の範囲でしか満たさないが、反復回数は有効集合の変更回数に左右されない。
`QpMethod::Automatic` は上下限だけの問題に射影 BB 法、一般の行制約がある問題に有効集合法を使い、`ActiveSet` と `PrimalDual` で方式を固定できる。
`QpSolver` は半正定値でない $\mathbf{Q}$ を `InvalidInput` で拒否するので、非凸な問題は SQP や大域探索に回し、凸な問題の結果は `ProgrammingVerifier` で元の座標の検算に回す。
