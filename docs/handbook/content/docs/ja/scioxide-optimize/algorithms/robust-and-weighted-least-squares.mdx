[非線形最小二乗法](../nonlinear-least-squares/)の目的 $\tfrac12\|\mathbf{r}\|^2$ は、すべての観測を同じ重みで扱い、残差の二乗で罰する。
測定の不確かさが観測ごとに違う場合、外れ値を含む場合、残差が複素数の場合には、この形をそのまま使えない。
`LeastSquares` が最小化する目的は、一般には

$$
f(\boldsymbol\theta) = \frac12\sum_{i=1}^{m} w_i\,c^2\,\rho(t_i), \qquad t_i = \frac{|r_i(\boldsymbol\theta)/\sigma_i|^2}{c^2}
$$

である。
$w_i\ge0$ は観測の重み、$\sigma_i>0$ は残差の尺度、$c>0$ は損失の尺度、$\rho$ は損失関数である。
既定の二乗損失 $\rho(t)=t$、$w_i=\sigma_i=1$ では $f=\tfrac12\|\mathbf{r}\|^2$ に戻る。
このページでは重みと尺度の役割、ロバストな損失の性質と線形化の作り方、複素残差の扱いを順に説明する。

## 観測の重みと尺度

残差の尺度 $\sigma_i$ は `LeastSquaresProblem::residual_scale` で与え、既定は 1 である。
$\sigma_i$ を観測 $i$ の測定の標準偏差にすると $r_i/\sigma_i$ は無次元になり、誤差が独立な正規分布に従う場合、二乗損失の最小点は最尤推定になる。
重み $w_i$ は `LeastSquaresProblem::residual_weight` で与え、既定は 1 である。
$w_i=0$ はその観測を目的から除く。
観測の値 $y_i$ が 0 であることとは別で、値が 0 の観測は残差 $m_i(\boldsymbol\theta)$ として目的に残る。

二乗損失では、項は $w_i r_i^2/\sigma_i^2$ なので、最小点は $w_i/\sigma_i^2$ だけで決まる。
ロバストな損失では、$\sigma_i$ は損失が二乗から変わる位置 $|r_i|=c\,\sigma_i$ も決めるが、$w_i$ は項全体に掛かるだけである。
`LeastSquares::solve` は、尺度が正で有限でない場合と、重みが負か非有限の場合に `InvalidInput` を返す。
結果の `residual()` は重みも尺度も掛けない生の残差 $\mathbf{r}$ である。
母数の尺度 $\mathbf{D}$（`parameter_scale`）は観測ではなく母数の座標に掛かるもので、[LM 法の信頼領域](oxref:optimize-gauss-newton-lm-derivation)の形を決める。

## ロバストな損失関数

外れ値（outlier）があると、二乗損失は大きな残差に二乗の重みを与えるので、当てはめ全体が外れ値の側に引かれる。
`LeastSquaresLoss` は、$t_i$ が 1 を超える観測の寄与を弱める損失を提供し、尺度 $c$ は `LeastSquaresOptions::with_loss(loss, c)` で設定する（既定は 1）。
一つの観測の項を無次元の残差 $u=r/\sigma$ の関数 $\tfrac12c^2\rho(u^2/c^2)$ と見ると、その $u$ についての一階導関数 $\psi(u)=\rho'(t)\,u$（影響関数）と二階導関数 $\rho'(t)+2t\rho''(t)$ が損失の性質を決める。

| 損失（`LeastSquaresLoss`） | $\rho(t)$ | $\rho'(t)$ | 曲率 $\rho'+2t\rho''$ | 影響関数 $\psi(u)$ の振る舞い |
|---|---|---|---|---|
| `Quadratic`（既定） | $t$ | $1$ | $1$ | $\psi=u$ で有界でない |
| `Huber` | $t$（$t\le1$）、$2\sqrt t-1$（$t>1$） | $1$、$1/\sqrt t$ | $1$、$0$ | $\lvert u\rvert>c$ で $c\,\mathrm{sign}(u)$ に飽和する |
| `SoftL1` | $2(\sqrt{1+t}-1)$ | $(1+t)^{-1/2}$ | $(1+t)^{-3/2}$ | 滑らかに増え、$\lvert\psi\rvert<c$ |
| `Cauchy` | $\ln(1+t)$ | $1/(1+t)$ | $(1-t)/(1+t)^2$ | $\lvert u\rvert=c$ で最大 $c/2$ をとり、遠い観測ほど 0 に近づく（再下降型） |

二乗損失は正規分布の誤差に対する最尤推定で、外れ値一つの影響は残差に比例して増える。
Huber 損失と Soft-L1 損失は曲率が非負なので、残差が母数について線形なら目的は凸のままで、外れ値一つの影響は $c$ で抑えられる。
Huber 損失は Huber の M 推定量で、正規分布の誤差のもとで効率 95% を与える $c=1.345$（$u$ の単位）がよく使われる。
Cauchy 損失は Cauchy 分布の誤差に対する最尤推定と同じ形で、$|u|>c$ で曲率が負になるので目的は凸でなく、局所解が複数ありうる。
Cauchy 損失では初期値によって異なる局所解に止まりうるので、Huber 損失の解などから始めて結果を比べる。
損失を選ぶことは誤差の分布についての仮定を変える操作で、どれだけ大きい残差を外れ値と見なすかを決める。

### 曲率を補正した線形化

ロバストな損失を最小二乗の反復に乗せる単純な方法は、各行に $\sqrt{w_i\rho'(t_i)}/\sigma_i$ を掛ける反復再重み付け（IRLS）である。
これは勾配を正しく与えるが、損失の二階の項 $2t\rho''$ を無視する。
`LeastSquares` は Triggs ら（2000）の補正に従い、観測 $i$ の線形化の行と残差を

$$
\tilde{\mathbf{J}}_i = \frac{\sqrt{w_i\,\kappa_i}}{\sigma_i}\,\mathbf{J}_i, \qquad
\tilde r_i = \frac{\sqrt{w_i}\,\rho'(t_i)}{\sigma_i\sqrt{\kappa_i}}\,r_i, \qquad
\kappa_i = \max(\rho'(t_i)+2t_i\rho''(t_i),\ \varepsilon_{\mathrm{mach}})
$$

で置き換える。
このとき $\tilde{\mathbf{J}}^\mathsf{T}\tilde{\mathbf{r}}=\sum_i w_i\rho'(t_i)\mathbf{J}_i^\mathsf{T}r_i/\sigma_i^2=\nabla f$ で勾配は変わらず、$\tilde{\mathbf{J}}^\mathsf{T}\tilde{\mathbf{J}}$ は損失の曲率を含むヘッセ行列の近似になる。
Huber 損失の $t>1$ や Cauchy 損失の $t>1$ では曲率が 0 以下になるので、$\varepsilon_{\mathrm{mach}}$ で下から抑えて平方根を取れるようにする。
密なヤコビ行列でも、積だけを渡す問題でも、この線形化を使う。
試行の受理には線形化ではなく元の目的 $f$ の実際の減少を使うので、補正したモデルが外れても、目的を増やす点は受理しない。

## 外れ値を含む位置推定

四つの観測を 1 に固定し、一つの大きな観測 $b$ を入力で動かして、位置 $\mu$ を推定する。
残差は $r_i=\mu-y_i$、ヤコビ行列は全要素 1 である。
二乗損失には Gauss–Newton 法、Huber 損失（尺度 $c=1$）には LM 法を使う。
二乗損失の解析解は平均 $(4+b)/5$ である。
Huber 損失では、$|\mu-1|\le1$ の四つの観測の勾配が $\mu-1$、外れ値の勾配が $-1$ に飽和するので、$4(\mu-1)-1=0$ から $\mu=1.25$ と手計算できる。
二つの手法の一致ではなく、異なる目的の解析的な最小点と比べて検証する。
出力は二つの位置推定、解析解、その差、終了理由の表である。

```rust
//| id: optimize-robust-location
//| ref: optimize-robust-location
//| title: 二つの損失の異なる解析最小点を確かめる
//| run: reactive
//| crates: [scioxide-optimize, scioxide-linalg]
//| inputs:
//|   outlier_value: {"type":"range","label":"第五観測の値 b [-]","description":"外れ値の位置を変える。","min":10,"max":100,"step":10,"value":50}
//| cases:
//|   - {"id":"outlier-100","label":"b = 100","description":"二乗損失の位置は (4 + 100)/5 = 20.8 まで引かれ、Huber 損失の位置は 1.25 のまま変わらない。","inputs":{"outlier_value":100}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"location","path":"/rows/0/1","approx":{"value":10.8,"atol":1e-9}}
//|       - {"artifact":"location","path":"/rows/1/1","approx":{"value":1.25,"atol":1e-9}}
//|       - {"artifact":"location","path":"/rows/0/4","equals":"GradientSmall"}
//|       - {"artifact":"location","path":"/rows/1/4","equals":"GradientSmall"}
//|   - case: outlier-100
//|     expect:
//|       - {"artifact":"location","path":"/rows/0/1","approx":{"value":20.8,"atol":1e-9}}
//|       - {"artifact":"location","path":"/rows/1/1","approx":{"value":1.25,"atol":1e-9}}
use scioxide_optimize::{
    LeastSquares, LeastSquaresFn, LeastSquaresGlobalization, LeastSquaresLoss,
    LeastSquaresOptions,
};

let sig6 = serde_json::json!({ "significantDigits": 6 });
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let b = outlier_value;
let problem = LeastSquaresFn::new(1, 5, move |x: &[f64], r: &mut [f64]| {
    r.copy_from_slice(&[x[0] - 1.0, x[0] - 1.0, x[0] - 1.0, x[0] - 1.0, x[0] - b]);
    Ok(())
})
.map_err(|e| e.to_string())?
.with_jacobian(|_x: &[f64], j: &mut scioxide_linalg::Matrix<f64>| {
    j.as_mut_slice().fill(1.0);
    Ok(())
});
let ordinary = LeastSquares::new(
    LeastSquaresOptions::default()
        .with_globalization(LeastSquaresGlobalization::gauss_newton()),
)
.map_err(|e| e.to_string())?
.solve(&problem, &[0.0])
.map_err(|e| e.to_string())?;
let options = LeastSquaresOptions::default().with_loss(LeastSquaresLoss::Huber, 1.0);
let robust = LeastSquares::new(
    options.with_globalization(LeastSquaresGlobalization::levenberg_marquardt()),
)
.map_err(|e| e.to_string())?
.solve(&problem, &[0.0])
.map_err(|e| e.to_string())?;
// 検算: 二乗損失の最小点は平均 (4 + b)/5。
// Huber 損失（c = 1）の最小点は 4(μ − 1) − 1 = 0 の解 1.25。
let columns = serde_json::json!([
    { "key": "0", "label": "損失" },
    { "key": "1", "label": "位置推定 μ [-]", "type": "number", "format": sig6 },
    { "key": "2", "label": "解析解 [-]", "type": "number", "format": sig6 },
    { "key": "3", "label": "差 [-]", "type": "number", "format": sci2 },
    { "key": "4", "label": "終了理由" }
]);
emit_table_with_columns!(
    columns,
    vec![
        (
            "二乗（Gauss–Newton）",
            ordinary.x()[0],
            (4.0 + b) / 5.0,
            (ordinary.x()[0] - (4.0 + b) / 5.0).abs(),
            ordinary.termination().to_string()
        ),
        (
            "Huber 尺度 1（LM）",
            robust.x()[0],
            1.25,
            (robust.x()[0] - 1.25).abs(),
            robust.termination().to_string()
        ),
    ],
    metadata = serde_json::json!({ "id": "location" })
);
```

既定の $b=50$ では、二乗損失の位置は 10.8 で外れ値に引かれ、Huber 損失の位置は 1.25 にとどまる。
解析解との差はそれぞれ $1.8\times10^{-15}$ と $2.2\times10^{-16}$ で、どちらも `GradientSmall` で終了する。
$b$ を 10 から 100 へ動かすと、二乗損失の位置は 2.8 から 20.8 まで動くが、Huber 損失の位置は 1.25 のままである。
外れ値の勾配が一定値 $-c$ に飽和するので、外れ値がどれだけ離れても位置への影響は変わらない。

## 複素残差

インピーダンスの測定や位相を持つ信号の当てはめでは、モデルと観測が複素数になる。
`ComplexLeastSquares` は、残差 $\mathbf{r}:\mathbb{C}^n\to\mathbb{C}^m$ を、実座標の `LeastSquaresProblem` に変える。
母数と残差は $[\operatorname{Re}z_0,\operatorname{Im}z_0,\operatorname{Re}z_1,\operatorname{Im}z_1,\dots]$ の順に交互に並べ、実の問題は $2n$ 個の母数と $2m$ 個の残差の成分を持つ。
目的は $\tfrac12\sum_i|r_i|^2$ で、複素数の大小を比べる最適化ではない。

実部と虚部の組は一つの観測として扱う（`residual_group_size()` が 2）。
重み $w_i$ と尺度 $\sigma_i$ は複素残差ごとに一つで、ロバストな損失は $|r_i|$ に掛かる。
`ComplexLeastSquares` は重みと尺度を設定せず、どちらも既定の 1 である。
複素残差に重みや尺度を付ける場合は、`residual_group_size()` が 2 を返す `LeastSquaresProblem` を自分で実装し、`residual_weight` と `residual_scale` を観測（複素残差）の番号で返す。
線形化では、損失の曲率を $r_i$ の向き（動径方向）にだけ補正する。
実座標で微分するので、残差は正則（複素微分可能）でなくてもよい。
`with_jacobian` で渡す解析的なヤコビ行列は、交互に並べた実座標についての $2m\times2n$ の実行列である。
正則な $r$ の導関数が $r'=\alpha+i\beta$ なら、対応する $2\times2$ の区画は $\begin{bmatrix}\alpha&-\beta\\\beta&\alpha\end{bmatrix}$ になる。

`ComplexLeastSquares::new(residual, parameter_scratch, residual_scratch)` は、呼び出し側が渡す長さ $n$ と $m$ の二つの作業用スライスで値を変換し、メモリを確保しない。
$2n$ か $2m$ が `usize` に収まらなければ `SizeOverflow` を返す。
作業用スライスを内部で可変に借用するので `Sync` を実装せず、残差の呼び出しの中から同じ問題を呼び直すと `InvalidInput` になる。

ロックイン検出を例にとる。
参照信号 $e_k=\exp(i\omega t_k)$ に同期した信号 $y_k=z\,e_k$ の複素振幅（位相子）$z$ [V] を、1 測定区間に 3 周期を含む $N=32$ 個の標本から推定する。
真の値は $z=0.8-0.6i$ V で、各標本に振幅 0.02 V の決定論的なずれを加え、第 8 標本（$k=7$）にだけ大きさ $g$ [V] の外れ値を加える。
残差は $r_k=z e_k-y_k$ で、二乗損失の最小点は $|e_k|=1$ から閉じた形 $\hat z=\frac1N\sum_k y_k\overline{e_k}$ になる。
外れ値のない標本から作った閉じた形の値を $\hat z_0$ とすると、二乗損失の推定のずれは $|\hat z-\hat z_0|=g/N$ と予測でき、これを独立な検算に使う。
Huber 損失（$c=0.1$ V）では、外れ値の勾配が大きさ $c$ に飽和するので、ずれはおよそ $c/(N-1)\approx3.2\times10^{-3}$ V に抑えられると見込める。
出力は二つの損失の推定値、$\hat z_0$ からのずれ、二乗損失についての予測、終了理由、反復回数の表である。

```rust
//| id: optimize-complex-phasor-huber
//| ref: optimize-complex-phasor-huber
//| title: 外れ値を含む位相子を二乗損失と Huber 損失で推定する
//| run: reactive
//| crates: [scioxide-core, scioxide-linalg, scioxide-optimize]
//| inputs:
//|   glitch: {"type":"range","label":"外れ値の大きさ g [V]","description":"第 8 標本に加える外れ値の絶対値を変える。","min":0,"max":5,"step":0.5,"value":2}
//| cases:
//|   - {"id":"no-glitch","label":"g = 0","description":"外れ値がないと残差はすべて c より小さく、二つの損失は同じ推定を返す。","inputs":{"glitch":0}}
//|   - {"id":"large-glitch","label":"g = 5 V","description":"二乗損失のずれは g/N = 0.156 V に増えるが、Huber 損失のずれは 3.1×10⁻³ V のままである。","inputs":{"glitch":5}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"phasor","path":"/rows/0/3","approx":{"value":0.0625,"atol":1e-10}}
//|       - {"artifact":"phasor","path":"/rows/0/4","approx":{"value":0.0625,"atol":1e-12}}
//|       - {"artifact":"phasor","path":"/rows/1/3","range":{"min":0.002,"max":0.005}}
//|       - {"artifact":"phasor","path":"/rows/0/5","equals":"GradientSmall"}
//|       - {"artifact":"phasor","path":"/rows/1/5","equals":"GradientSmall"}
//|   - case: no-glitch
//|     expect:
//|       - {"artifact":"phasor","path":"/rows/0/3","range":{"min":0,"max":1e-10}}
//|       - {"artifact":"phasor","path":"/rows/1/3","range":{"min":0,"max":1e-8}}
//|   - case: large-glitch
//|     expect:
//|       - {"artifact":"phasor","path":"/rows/0/3","approx":{"value":0.15625,"atol":1e-10}}
//|       - {"artifact":"phasor","path":"/rows/1/3","range":{"min":0.002,"max":0.005}}
use scioxide_core::{Complex, SciOxideError, RealScalar};
use scioxide_linalg::Matrix;
use scioxide_optimize::{
    ComplexLeastSquares, LeastSquares, LeastSquaresLoss, LeastSquaresOptions,
};

let sig6 = serde_json::json!({ "significantDigits": 6 });
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
// N 標本で 3 周期。参照の位相因子 e_k = exp(iωt_k)、真の位相子 z = 0.8 − 0.6i [V]。
let n = 32_usize;
let truth = Complex::new(0.8_f64, -0.6);
let reference: Vec<Complex<f64>> = (0..n)
    .map(|k| Complex::from_polar(1.0, 2.0 * core::f64::consts::PI * 3.0 * k as f64 / n as f64))
    .collect();
let clean: Vec<Complex<f64>> = reference
    .iter()
    .enumerate()
    .map(|(k, &e)| {
        let drift = Complex::new(
            0.02 * RealScalar::sin(1.3 * k as f64),
            0.02 * RealScalar::cos(0.7 * k as f64),
        );
        truth * e + drift
    })
    .collect();
// 第 8 標本（k = 7）にだけ大きさ g の外れ値を加える。
let mut data = clean.clone();
data[7] += Complex::from_polar(glitch, 1.0);
// 残差 r_k = z e_k − y_k。実座標 (Re z, Im z) についての行は [Re e, −Im e]、[Im e, Re e]。
let residual = |z: &[Complex<f64>], r: &mut [Complex<f64>]| -> Result<(), SciOxideError> {
    for ((rk, &e), &y) in r.iter_mut().zip(&reference).zip(&data) {
        *rk = z[0] * e - y;
    }
    Ok(())
};
let jacobian = |_z: &[Complex<f64>], j: &mut Matrix<f64>| -> Result<(), SciOxideError> {
    for (rows, e) in j.as_mut_slice().chunks_exact_mut(4).zip(&reference) {
        rows.copy_from_slice(&[e.re, -e.im, e.im, e.re]);
    }
    Ok(())
};
let mut parameter_scratch = [Complex::new(0.0, 0.0)];
let mut residual_scratch = vec![Complex::new(0.0, 0.0); n];
let problem = ComplexLeastSquares::new(residual, &mut parameter_scratch, &mut residual_scratch)
    .map_err(|e| e.to_string())?
    .with_jacobian(&jacobian);
let quadratic = LeastSquares::new(LeastSquaresOptions::default())
    .map_err(|e| e.to_string())?
    .solve(&problem, &[0.0, 0.0])
    .map_err(|e| e.to_string())?;
let huber =
    LeastSquares::new(LeastSquaresOptions::default().with_loss(LeastSquaresLoss::Huber, 0.1))
        .map_err(|e| e.to_string())?
        .solve(&problem, &[0.0, 0.0])
        .map_err(|e| e.to_string())?;
// 検算用（式）: 外れ値のない標本の二乗損失の最小点 ẑ₀ = (1/N) Σ y_k conj(e_k)。
let baseline = clean
    .iter()
    .zip(&reference)
    .fold(Complex::new(0.0, 0.0), |sum, (&y, &e)| sum + y * e.conj())
    .unscale(n as f64);
let rows: Vec<(&str, f64, f64, f64, Option<f64>, String, usize)> = [
    ("二乗", &quadratic, Some(glitch / n as f64)),
    ("Huber（c = 0.1 V）", &huber, None),
]
.into_iter()
.map(|(name, fit, predicted)| {
    let z = Complex::new(fit.x()[0], fit.x()[1]);
    (
        name,
        z.re,
        z.im,
        (z - baseline).norm(),
        predicted,
        fit.termination().to_string(),
        fit.iterations(),
    )
})
.collect();

    { "key": "0", "label": "損失" },
```

既定の $g=2$ V では、二乗損失の推定は $\hat z_0$ から $0.0625$ V ずれ、予測 $g/N=2/32$ と一致する。
Huber 損失のずれは $3.1\times10^{-3}$ V で、見込み $c/(N-1)\approx3.2\times10^{-3}$ V に近く、外れ値の影響はその大きさに抑えられている。
外れ値がない $g=0$ では、すべての残差が $c=0.1$ V より小さい二乗の領域にあり、二つの損失は同じ推定を返す。
$g=5$ V では二乗損失のずれが $0.156$ V に増えるが、Huber 損失のずれは $3.1\times10^{-3}$ V のままで、$g$ にほとんどよらない。
どちらも実座標の 2 母数の問題として `GradientSmall` で止まる。

`NoiseModel` は、同じ点を何度も評価する標本化した目的について、評価どうしの関係を宣言する[確率的最適化](../stochastic-gradient-and-trust-region/)の型である。
非線形最小二乗の観測ノイズを設定するものではなく、測定の不確かさは上の $\sigma_i$ と $w_i$ で表す。

## まとめ

測定の標準偏差が観測ごとに違う場合は `residual_scale` で $\sigma_i$ を、観測を除くか重み付けする場合は `residual_weight` で $w_i$ を与え、`residual()` は生の残差を返すことに注意して結果を読む。
外れ値がある場合は、凸性を保つ `Huber` か `SoftL1` を尺度 $c$ を決めて使い、`Cauchy` は良い初期値と組み合わせる。
`LeastSquares` は損失の曲率を補正した線形化と、元の目的による試行の受理でロバストな損失を扱う。
複素残差は `ComplexLeastSquares` で実部と虚部を交互に並べた問題にでき、ロバストな損失は複素残差の絶対値に掛かる。
