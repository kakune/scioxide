一変数の実関数 $f: \mathbb{R} \to \mathbb{R}$ の局所最小点を、導関数を使わずに関数値の比較だけで求める。
多変数の最適化で使う直線探索は[Armijo 条件や Wolfe 条件](oxref:optimize-armijo-condition)を満たす近似で済むことが多いが、ここでは一変数関数の最小点そのものを許容誤差まで求める。
`Powell` の直線最小化もこのページの方法を使う。
求根は $f(x) = 0$ となる符号の変わり目を探すが、最小化は関数値の大小を比べるので、到達できる精度が求根より粗い（[停止判定と到達精度](#停止判定と到達精度)）。

## 最小点の括弧と単峰性

三点 $a < b < c$ が

$$
f(b) \le f(a), \qquad f(b) \le f(c)
$$

を満たし、少なくとも一方の不等号が狭義に成り立つとき、この三点を最小点の括弧（bracket）と呼ぶ。
$f$ が連続なら、括弧の開区間 $(a, c)$ に局所最小点がある。
区間の中の一点を境に、その左で狭義に減少し右で狭義に増加する関数を単峰（unimodal）と呼び、単峰関数では括弧を縮めていくとその最小点に収束する。
多峰な関数では、括弧を縮めて得るのは括弧の中の局所最小点の一つで、区間全体の最小点とは限らない。

括弧を縮める基本の操作は、区間の内側に新しい点 $u$ を一つ置き、$f(u)$ と $f(b)$ を比べて新しい括弧を選ぶことである。
$f(u) < f(b)$ なら $u$ が新しい中央の点になり、そうでなければ $u$ が新しい端点になる。
どちらの場合も新しい括弧は前の括弧に含まれ、評価は 1 回で済む。

## 黄金分割探索

新しい点をどこに置くかで縮小の速さが決まる。
区間の長さを 1 とし、中央の点が左端から $1 - \tau$ の位置にあるとする（$1/2 < \tau < 1$）。
対称の位置 $\tau$ に新しい点を置くと、どちらの比較結果でも新しい区間の長さは $\tau$ になる。
次の段で同じ比を保つには、残った中央の点が新しい区間の中でも同じ比の位置にある必要があり、$1 - \tau = \tau^2$ から

$$
\tau = \frac{\sqrt5 - 1}{2} \approx 0.618
$$

を得る。
この黄金分割探索（golden-section search）は、評価 1 回ごとに区間を $\tau$ 倍にする一次収束で、長さ $L$ の区間を $\delta$ まで縮めるには約 $\ln(\delta/L)/\ln\tau \approx 4.78\log_{10}(L/\delta)$ 回の評価を使う。
比較だけを使う方法のなかで、決められた評価回数で区間を最も縮める方法は Fibonacci 探索であり、黄金分割探索はその回数を固定しない極限にあたる（Kiefer 1953）。

`ScalarMinimumMethod::GoldenSection` は、中央の点 $x$ から長いほうの部分区間へ、その長さの $(3 - \sqrt5)/2 \approx 0.382$ 倍だけ進んだ位置に新しい点を置く。
丸めで新しい点が $x$ と同じか区間の外になる場合は、$x$ の隣の浮動小数点数を試し、それも置けなければ `Stagnation` で止まる。

## Brent 法

最小点の近くでは、$f$ は放物線でよく近似できる。
三点 $(x, f_x)$、$(w, f_w)$、$(v, f_v)$ を通る放物線の頂点は

$$
u = x - \frac{1}{2}\,\frac{(x - w)^2 (f_x - f_v) - (x - v)^2 (f_x - f_w)}{(x - w)(f_x - f_v) - (x - v)(f_x - f_w)}
$$

である。
この点を順に使う逐次放物線補間は、二次導関数が正の最小点の近くで次数約 1.32 の超一次収束をするが、それだけでは遠くから収束する保証がない。

Brent 法（Brent 1973、第 5 章）は、$x$ を最良の点、$w$ を二番目に良い点、$v$ を一つ前の $w$ として放物線補間の点を作り、補間の点が安全なときだけ採用する。
`ScalarMinimumMethod::Brent` は次の条件をすべて満たすときに補間の点を採用する。

- 頂点が括弧の内側に狭義にあり、$x$ と異なる。
- $|u - x|$ が直前のステップの幅（直前が黄金分割なら長いほうの部分区間の幅）の半分より小さい。

条件を満たさないときは黄金分割の点を使う。
二つ目の条件は補間のステップが縮まらないまま続くことを防ぎ、補間がうまく働かないときは黄金分割の点に切り替える。
Brent の原著のアルゴリズムはこの比較に二つ前のステップの幅を使うが、`Brent` は直前のステップの幅を使う。
`Brent` は `ScalarMinimizer` の既定である。

## 停止判定と到達精度

`ScalarMinimizer` は、括弧 $a < x < b$ が次の二つを同時に満たすと `Converged` で止まる。

$$
|b - a| \le \mathrm{atol}_x + \mathrm{rtol}_x \max(|a|, |b|), \qquad
\max(|f(a) - f(x)|, |f(b) - f(x)|) \le \mathrm{atol}_f + \mathrm{rtol}_f \max(|f(a)|, |f(x)|, |f(b)|)
$$

位置の許容誤差は `StepTolerance`、目的値の許容誤差は `ResidualTolerance` で、既定はどちらも絶対・相対とも $\sqrt{\varepsilon_{\mathrm{mach}}}$ である。

最小点 $x^*$ の近くでは $f(x^* + \delta) \approx f(x^*) + \tfrac12 f''(x^*)\delta^2$ なので、目的値の差が丸めの大きさ $\varepsilon_{\mathrm{mach}}|f(x^*)|$ に埋もれる範囲は

$$
|\delta| \approx \sqrt{\frac{2\varepsilon_{\mathrm{mach}}|f(x^*)|}{|f''(x^*)|}}
$$

に及ぶ。
関数値の比較だけでは、位置は相対で $\sqrt{\varepsilon_{\mathrm{mach}}} \approx 1.5\times10^{-8}$ 程度までしか定まらず、既定の許容誤差はこの限界に合わせてある。
これより小さい許容誤差を指定しても、位置の精度は上がらず、評価が増えるか `Stagnation` で止まる。

## 一変数の最小化の API

`ScalarObjective` は値を返す一変数の目的関数で、`Fn(S) -> Result<S, SciOxideError>` のクロージャがそのまま実装になる。
有限でない値はその試行の棄却として扱い、どの有限な値よりも大きいとみなす。
目的関数が返したエラーは探索を止め、そのまま返る。

`ScalarMinimizer::new(method, options)` が方式と設定を持ち、`minimize(&objective, start)` が解く。
`ScalarMinimumStart` は始め方を選ぶ。

- `Bounded(interval)` は閉区間 $[a, b]$ を探す。
  両端と中点を評価し、最良の点を中央にする。
  最小点が端点にあってもよい。
- `Bracket(bracket)` は `MinimumBracket` から始める。
  三点を評価し直して括弧の条件を確かめる。
- `Seeds(a, b)` は異なる二点から下り方向へ括弧を探す。
  値の小さい点 $b$ から、$c = b + 2(b - a)$ と直前の幅を 2 倍にしながら進む。

`bracket_minimum(&objective, a, b)` は括弧を探すだけで縮めず、見つけた括弧を結果の `bracket()` に入れる。
`ScalarMinimumOptions` は `with_step_tolerance`、`with_function_tolerance`、`with_max_iterations`（括弧の探索を含む、既定 1000 回）、`with_max_evaluations`（初期の評価を含む、既定 2000 回）を設定する。
各反復の評価は高々 1 回で、メモリは観測した三点の分だけなので、出力への反映の作業領域はない。

`ScalarMinimumResult` の `x()` と `fun()` は観測した最良の点とその値、`samples()` は最後の三点、`bracket()` は最後の括弧である。
最小点が区間の端点にある場合や、括弧の探索が終わらなかった場合は、`bracket()` が `None` になる。
`termination()` は `OptimizeTermination` を返し、`Converged` だけが成功（`is_success()`）である。
上限に達すると `IterationLimit` か `EvaluationLimit`、丸めで点を置けなくなるか目的値が括弧の探索の向きで一定になると `Stagnation` になり、どれも最良の点を返す。
`require_success()` は成功しない終了をエラーに変える。
`fun_evals()` と `iterations()` は、括弧の探索と初期の評価を含めて数える。

`minimize_scoped` は親の求解コンテキストの中で解き、評価をその親の上限にも数える。
ワンショット関数 `minimize_scalar(f, a, b)` は区間 $[a, b]$ で既定の設定の Brent 法を使い、成功しない終了を `Err` で返す。

## 内部の最小と端点の最小

次のセルは $f(x) = (x - v)^2$ を区間 $[-1, 1]$ で黄金分割探索と Brent 法により最小化する。
入力は放物線の頂点 $v$ である。
表は二つの方式の最小点、解析解 $\min(1, \max(-1, v))$ との差、目的の評価と反復の回数、括弧の有無、終了理由である。
頂点を区間の外へ動かすと、最小点が端点に移る。

```rust
//| id: optimize-scalar-brent-golden
//| ref: optimize-scalar-brent-golden
//| title: 黄金分割と Brent 法で内部と端点の最小を調べる
//| run: reactive
//| crates: [scioxide-core, scioxide-optimize]
//| inputs:
//|   vertex: {"type":"range","label":"放物線の頂点 v [-]","description":"区間 [−1, 1] の外に出すと最小点が端点になる。","min":-2,"max":2,"step":0.25,"value":0.25}
//| cases:
//|   - {"id":"vertex-outside","label":"v = 2（区間の外）","description":"最小点は端点 x = 1 に移り、両方式とも 23 回の評価で端点に一致する。最後の括弧はない。","inputs":{"vertex":2}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"methods","path":"/rows/0/6","equals":"Converged"}
//|       - {"artifact":"methods","path":"/rows/1/6","equals":"Converged"}
//|       - {"artifact":"methods","path":"/rows/0/2","range":{"min":0,"max":1e-7}}
//|       - {"artifact":"methods","path":"/rows/1/2","range":{"min":0,"max":1e-7}}
//|       - {"artifact":"methods","path":"/rows/0/3","range":{"min":38,"max":44}}
//|       - {"artifact":"methods","path":"/rows/1/3","range":{"min":20,"max":30}}
//|       - {"path":"/outputs/1/state","equals":"satisfied"}
//|   - case: vertex-outside
//|     expect:
//|       - {"artifact":"methods","path":"/rows/0/1","approx":{"value":1.0,"atol":1e-8}}
//|       - {"artifact":"methods","path":"/rows/1/1","approx":{"value":1.0,"atol":1e-8}}
//|       - {"artifact":"methods","path":"/rows/1/5","equals":"なし"}
use scioxide_core::Interval;
use scioxide_optimize::{
    ScalarMinimizer, ScalarMinimumMethod, ScalarMinimumOptions, ScalarMinimumStart,
};

let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let sig10 = serde_json::json!({ "significantDigits": 10 });
let interval = Interval::new(-1.0_f64, 1.0).map_err(|e| e.to_string())?;
// 独立検算: 区間 [−1, 1] での最小点は頂点を区間へ射影した点。
let exact = vertex.clamp(-1.0, 1.0);
let mut rows = Vec::new();
let mut brent = None;
for method in [
    ScalarMinimumMethod::GoldenSection,
    ScalarMinimumMethod::Brent,
] {
    let result = ScalarMinimizer::new(method, ScalarMinimumOptions::default())
        .minimize(
            &|x: f64| Ok((x - vertex) * (x - vertex)),
            ScalarMinimumStart::Bounded(interval),
        )
        .map_err(|e| e.to_string())?;
    let bracket = if result.bracket().is_some() {
        "あり"
    } else {
        "なし"
    };
    rows.push((
        format!("{method:?}"),
        result.x(),
        (result.x() - exact).abs(),
        result.fun_evals(),
        result.iterations(),
        bracket,
        result.termination().to_string(),
    ));
    brent = Some(result);
}
let columns = serde_json::json!([
    { "key": "0", "label": "方式" },
    { "key": "1", "label": "最小点 [-]", "type": "number", "format": sig10 },
    { "key": "2", "label": "解析解との差 [-]", "type": "number", "format": sci3 },
    { "key": "3", "label": "目的の評価 [回]", "type": "integer" },
    { "key": "4", "label": "反復 [回]", "type": "integer" },
    { "key": "5", "label": "最後の括弧" },
    { "key": "6", "label": "終了理由" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "methods" })
);
// 既定の方式（Brent 法）の終了理由をセルの結論にする。
let result = brent.ok_or("Brent 法の結果がない")?;
let outcome = if result.is_success() {
    Outcome::satisfied("Brent 法が位置と目的値の許容誤差を満たした")
} else {
    Outcome::partial("Brent 法が許容誤差を満たす前に止まり、最良の点を返した")
};
emit_outcome!(
    outcome
        .status(result.termination().to_string())
        .diagnostic("目的の評価", result.fun_evals() as f64, None)
        .diagnostic("解析解との差", (result.x() - exact).abs(), None)
);
```

既定の $v = 0.25$ では、黄金分割探索は 41 回の評価で解析解との差 $4.0\times10^{-9}$、Brent 法は 25 回の評価で差 0 に達し、どちらも `Converged` で終わる。
幅 2 の区間を位置の閾値 $\sqrt{\varepsilon_{\mathrm{mach}}}(1 + 0.25) \approx 1.9\times10^{-8}$ まで縮める回数は $\ln(1.9\times10^{-8}/2)/\ln 0.618 \approx 38.4$ で、黄金分割探索の反復 38 回とよく合う。
Brent 法では目的が厳密な放物線なので放物線補間が頂点そのものを与え、残りの評価は括弧の幅を許容誤差まで縮めるために使われる。
$v = 2$ では最小点が端点 $x = 1$ に移り、両方式とも 23 回の評価で端点に一致する。
端点の最小では最後の三点が括弧の条件を満たさないので、`bracket()` は `None` を返す。

## 括弧の探索と局所最小

多峰な関数ではどの局所最小点に達するかが始め方で決まる。
題材は、一変数の大域最適化の試験に使われる $f(x) = \sin x + \sin(10x/3)$（Hansen、Jaumard、Lu 1992 の試験関数の一つ）である。
次のセルは二点 $x_0$、$x_0 + 0.1$ から `bracket_minimum` で括弧を探し、その括弧から Brent 法で縮める。
$[0, 8]$ には局所最小点が $x \approx 1.398$、$3.387$、$5.146$、$7.000$ の四つあり、区間 $[2.7, 7.5]$ の最小点は $x^* = 5.145735$、$f(x^*) = -1.899599$ と示されている。
入力は始点 $x_0$ である。
図は $f$ と、見つけた括弧の範囲と最小点を示す。
表は括弧の三点、最小点、$f$ の値、閉形式から計算した $f'(x) = \cos x + \tfrac{10}{3}\cos(10x/3)$ と $f''(x)$（独立検算）、括弧の探索と縮小の評価回数、終了理由である。

```rust
//| id: optimize-scalar-seeds-local-minima
//| ref: optimize-scalar-seeds-local-minima
//| title: 二点から括弧を探して多峰な関数の局所最小に達する
//| run: reactive
//| crates: [scioxide-core, scioxide-optimize]
//| inputs:
//|   start: {"type":"range","label":"始点 x₀ [-]","description":"二点目は x₀ + 0.1。括弧はこの二点から下り方向に広げる。","min":2,"max":7.5,"step":0.1,"value":4.5}
//| cases:
//|   - {"id":"left-basin","label":"x₀ = 2.5","description":"左の谷の局所最小点 x = 3.387（f = −1.200）に収束する。","inputs":{"start":2.5}}
//|   - {"id":"right-basin","label":"x₀ = 6.6","description":"右の谷の局所最小点 x = 7.000（f = −0.317）に収束する。","inputs":{"start":6.6}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"seeds","path":"/rows/0/3","approx":{"value":5.145735,"atol":1e-6}}
//|       - {"artifact":"seeds","path":"/rows/0/4","approx":{"value":-1.899599,"atol":1e-6}}
//|       - {"path":"/outputs/2/state","equals":"satisfied"}
//|   - case: left-basin
//|     expect:
//|       - {"artifact":"seeds","path":"/rows/0/3","approx":{"value":3.387252,"atol":1e-6}}
//|   - case: right-basin
//|     expect:
//|       - {"artifact":"seeds","path":"/rows/0/3","approx":{"value":7.000149,"atol":1e-5}}
use scioxide_core::RealScalar;
use scioxide_optimize::{ScalarMinimizer, ScalarMinimumStart};

let sig7 = serde_json::json!({ "significantDigits": 7 });
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let f = |x: f64| RealScalar::sin(x) + RealScalar::sin(10.0 * x / 3.0);
let objective = |x: f64| Ok(f(x));
let solver = ScalarMinimizer::<f64>::default();
// 括弧の探索: x₀ と x₀ + 0.1 から下り方向へ幅を 2 倍ずつ広げる。
let found = solver
    .bracket_minimum(&objective, start, start + 0.1)
    .map_err(|e| e.to_string())?;
let bracket = found.bracket().ok_or("括弧が見つからなかった")?;
let [a, b, c] = bracket.samples().map(|sample| sample.x());
// 括弧から Brent 法で縮める。括弧の三点は評価し直す。
let result = solver
    .minimize(&objective, ScalarMinimumStart::Bracket(bracket))
    .map_err(|e| e.to_string())?;
let x = result.x();
// 独立検算: 閉形式の f′(x) と f″(x)。最小点では f′ ≈ 0、f″ > 0。
let first = RealScalar::cos(x) + 10.0 / 3.0 * RealScalar::cos(10.0 * x / 3.0);
let second = -RealScalar::sin(x) - 100.0 / 9.0 * RealScalar::sin(10.0 * x / 3.0);
let curve: Vec<[f64; 2]> = (0..=300)
    .map(|i| {
        let t = 8.0 * i as f64 / 300.0;
        [t, f(t)]
    })
    .collect();
emit_line_chart!(
    &vec![serde_json::json!({ "name": "f(x) = sin x + sin(10x/3)", "points": curve })],
    options = &serde_json::json!({
        "xLabel": "x [-]",
        "yLabel": "f(x) [-]",
        "xMin": 0.0,
        "xMax": 8.0,
        "annotations": [
            { "kind": "range", "axis": "x", "from": a, "to": c, "label": "見つけた括弧" },
            { "kind": "line", "axis": "x", "value": x, "label": "最小点" }
        ]
    })
);
let columns = serde_json::json!([
    { "key": "0", "label": "括弧の左端 [-]", "type": "number", "format": sig7 },
    { "key": "1", "label": "括弧の中央 [-]", "type": "number", "format": sig7 },
    { "key": "2", "label": "括弧の右端 [-]", "type": "number", "format": sig7 },
    { "key": "3", "label": "最小点 [-]", "type": "number", "format": sig7 },
    { "key": "4", "label": "f(x) [-]", "type": "number", "format": sig7 },
    { "key": "5", "label": "f′(x) [-]", "type": "number", "format": sci3 },
    { "key": "6", "label": "f″(x) [-]", "type": "number", "format": sig7 },
    { "key": "7", "label": "括弧の探索の評価 [回]", "type": "integer" },
    { "key": "8", "label": "縮小の評価 [回]", "type": "integer" },
    { "key": "9", "label": "終了理由" }
]);
let row = (
    a,
    b,
    c,
    x,
    result.fun(),
    first,
    second,
    found.fun_evals(),
    result.fun_evals(),
    result.termination().to_string(),
);
emit_table_with_columns!(
    columns,
    vec![row],
    metadata = serde_json::json!({ "id": "seeds" })
);
let outcome = if result.is_success() {
    Outcome::satisfied("括弧の中の局所最小点に収束した")
} else {
    Outcome::partial("許容誤差を満たす前に止まり、最良の点を返した")
};
emit_outcome!(
    outcome
        .status(result.termination().to_string())
        .diagnostic("f′(x)", first, None)
        .diagnostic(
            "目的の評価",
            (found.fun_evals() + result.fun_evals()) as f64,
            None
        )
);
```

既定の $x_0 = 4.5$ では、括弧の探索が 5 回の評価で括弧 $(4.8, 5.2, 6.0)$ を見つけ、Brent 法は 11 回の評価（括弧の三点の評価し直しを含む）で $x = 5.145735$、$f = -1.899599$ に収束する。
この値は示されている区間 $[2.7, 7.5]$ の最小点と表示の桁まで一致し、閉形式の $f'(x)$ は $-3.9\times10^{-10}$、$f''(x) = 11.93 > 0$ である。
$x_0 = 2.5$ では左の谷の $x = 3.387$（$f = -1.200$）、$x_0 = 6.6$ では右の谷の $x = 7.000$（$f = -0.317$）に収束する。
どちらも $f' \approx 0$、$f'' > 0$ の局所最小点だが、区間 $[2.7, 7.5]$ の最小点ではない。
$x_0 = 2$ では二点目のほうが値が大きいので括弧を左へ広げ、浅い極小 $x = 1.398$（$f = -0.0135$）に達する。
`Converged` は括弧の中の局所最小点に収束したことを示し、どの谷に入ったかは示さない。

## まとめ

関数値の比較による一変数の最小化は、最小点の括弧を保って縮める方法で、黄金分割探索は評価 1 回ごとに区間を 0.618 倍にし、Brent 法は放物線補間が使えるときに超一次で収束する。
滑らかな最小点の位置は関数値の比較だけでは相対 $\sqrt{\varepsilon_{\mathrm{mach}}}$ 程度までしか定まらないので、既定の許容誤差より小さくしても精度は上がらない。
区間で探すときは `Bounded`、二点から探すときは `Seeds` を使い、端点の最小は `bracket()` が `None` になることで読み分ける。
多峰な関数では結果は始め方で決まる局所最小点なので、始点を変えた比較か[大域探索](../global-search/)と組み合わせる。
