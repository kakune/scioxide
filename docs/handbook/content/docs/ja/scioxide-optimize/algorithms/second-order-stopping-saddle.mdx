勾配が零になる点は極小点とは限らず、鞍点や極大点でも勾配の判定は満たされる。
このページでは `TrustRegionOptimizer` の `SteihaugCg` に二次の停止を有効にしたときの判定と、鞍点から抜け出す試行を説明する。
部分問題の解き方は[切断共役勾配法と負曲率](../truncated-cg-trust-region/)、受理比と半径の規則は[受理比と半径の更新](oxref:optimize-trust-region-ratio)と同じである。

## 慣性による二次の判定

勾配の判定は一次の条件なので、勾配が零の鞍点や極大点でも `GradientSmall` で止まる。
`SteihaugCg` の `second_order_stopping` を `true` にすると、勾配が小さい点で密なヘッセ行列を対称不定値の LDLᵀ 分解で分解し、慣性を調べる。
負の固有値がなければ `Converged` で止まり、`NewtonDiagnostics::second_order_checked()` が `true` になる。
負の固有値があれば、負のピボットのブロックから負曲率の方向 $\mathbf{v}$（$\mathbf{v}^\mathsf{T}\mathbf{B}\mathbf{v}<0$）を作り、$\mathbf{g}^\mathsf{T}\mathbf{v}\le0$ の向きに半径の長さだけ進む試行を出す。
この方向の曲率を元の行列で確かめて負でなければ、`NumericalInstability`（`Breakdown`）のエラーになる。

この判定は零の固有値を負とみなさないので、半正定値のヘッセ行列を持つ退化した停留点でも `Converged` になりうる。
密なヘッセ行列が必要なので、解析的なヘッセ行列を持っていても `has_hessian_vector_product` が `true` の目的は `InvalidInput`（`UnsupportedConfiguration`）で拒まれる。
この設定では初期半径が $\max(\|\mathbf{g}_0\|,1)$ になり、勾配が零の点から始めても半径が 1 以上ある。

## 二重井戸の鞍点

次のセルは二重井戸と横方向の調和ポテンシャルを足した $V(x,y)=x^4/4-x^2/2+y^2/2$（無次元）で、粒子の安定な位置を探す。
$(0,0)$ は鞍点（ヘッセ行列 $\operatorname{diag}(-1,1)$）、$(\pm1,0)$ は極小点で $V=-1/4$ である。
開始点は $(x_0,0.5)$ で、入力は対称軸 $x=0$ からのずれ $x_0$ である。
$x_0=0$ では勾配の $x$ 成分が常に 0 なので、勾配だけを使う反復は対称軸の上にとどまり、鞍点に向かう。
ドッグレッグ、`SteihaugCg`、二次の停止を有効にした `SteihaugCg` を比べ、到達点で解析的なヘッセ行列 $\operatorname{diag}(3x^2-1,1)$ の最小固有値を独立に計算する。
最後に、二次の停止を有効にした実行の終了理由を計算の判定として示す。

```rust
//| id: optimize-trust-second-order-saddle
//| ref: optimize-trust-second-order-saddle
//| title: 鞍点で止まる一次の停止と、負曲率で抜け出す二次の停止を比べる
//| run: reactive
//| crates: [scioxide-core, scioxide-linalg, scioxide-optimize]
//| inputs:
//|   offset: {"type":"range","label":"対称軸からのずれ x₀ [-]","description":"開始点 (x₀, 0.5) の x 成分。0 では勾配の x 成分が消える。","min":0,"max":0.2,"step":0.01,"value":0}
//| cases:
//|   - {"id":"off-axis","label":"x₀ = 0.1","description":"対称性が崩れ、どの方式も極小点 (1, 0) に達する。","inputs":{"offset":0.1}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"methods","path":"/rows/0/1","equals":"GradientSmall"}
//|       - {"artifact":"methods","path":"/rows/0/7","approx":{"value":-1.0,"atol":1e-9}}
//|       - {"artifact":"methods","path":"/rows/1/7","approx":{"value":-1.0,"atol":1e-9}}
//|       - {"artifact":"methods","path":"/rows/2/1","equals":"Converged"}
//|       - {"artifact":"methods","path":"/rows/2/2","approx":{"value":1.0,"atol":1e-6}}
//|       - {"artifact":"methods","path":"/rows/2/6","equals":"あり"}
//|       - {"artifact":"methods","path":"/rows/2/7","approx":{"value":1.0,"atol":1e-5}}
//|       - {"path":"/outputs/1/state","equals":"satisfied"}
//|   - case: off-axis
//|     expect:
//|       - {"artifact":"methods","path":"/rows/0/2","approx":{"value":1.0,"atol":1e-6}}
//|       - {"artifact":"methods","path":"/rows/1/2","approx":{"value":1.0,"atol":1e-6}}
//|       - {"path":"/outputs/1/state","equals":"satisfied"}
use scioxide_core::Budget;
use scioxide_linalg::Matrix;
use scioxide_optimize::{
    ObjectiveFn, OptimizeDiagnostics, OptimizeResult, TrustRegionOptimizer, TrustRegionOptions,
    TrustRegionSubproblem,
};

// V(x, y) = x⁴/4 − x²/2 + y²/2。(0, 0) は鞍点、(±1, 0) は極小点。
let potential = ObjectiveFn::new(2, |p: &[f64]| {
    Ok(0.25 * p[0] * p[0] * p[0] * p[0] - 0.5 * p[0] * p[0] + 0.5 * p[1] * p[1])
})
.with_gradient(|p: &[f64], g: &mut [f64]| {
    g[0] = p[0] * p[0] * p[0] - p[0];
    g[1] = p[1];
    Ok(())
})
.with_hessian(|p: &[f64], h: &mut Matrix<f64>| {
    h.as_mut_slice()
        .copy_from_slice(&[3.0 * p[0] * p[0] - 1.0, 0.0, 0.0, 1.0]);
    Ok(())
});
let inner = Budget::try_from(20).map_err(|e| e.to_string())?;
let solve = |subproblem: TrustRegionSubproblem| -> Result<OptimizeResult<f64>, String> {
    TrustRegionOptimizer::new(TrustRegionOptions::default().with_subproblem(subproblem))
        .minimize(&potential, &[offset, 0.5])
        .map_err(|e| e.to_string())
};
let dogleg = solve(TrustRegionSubproblem::Dogleg)?;
let first_order = solve(TrustRegionSubproblem::SteihaugCg {
    max_inner_iterations: inner,
    second_order_stopping: false,
})?;
let second_order = solve(TrustRegionSubproblem::SteihaugCg {
    max_inner_iterations: inner,
    second_order_stopping: true,
})?;
let mut rows = Vec::new();
for (name, run) in [
    ("Dogleg", &dogleg),
    ("SteihaugCg", &first_order),
    ("SteihaugCg（二次の停止）", &second_order),
] {
    let OptimizeDiagnostics::Newton(diag) = run.method_diagnostics() else {
        return Err("対応するアルゴリズムの診断がない".to_string());
    };
    let x = run.x();
    // 独立検算: 到達点の解析的なヘッセ行列 diag(3x² − 1, 1) の最小固有値。
    let lowest = (3.0 * x[0] * x[0] - 1.0).min(1.0);
    rows.push((
        name,
        run.termination().to_string(),
        x[0],
        x[1],
        run.fun(),
        run.iterations(),
        if diag.second_order_checked() {
            "あり"
        } else {
            "なし"
        },
        lowest,
    ));
}
let general = serde_json::json!({ "significantDigits": 6 });
let columns = serde_json::json!([
    { "key": "0", "label": "方法" },
    { "key": "1", "label": "終了理由" },
    { "key": "2", "label": "x [-]", "type": "number", "format": general },
    { "key": "3", "label": "y [-]", "type": "number", "format": general },
    { "key": "4", "label": "V [-]", "type": "number", "format": general },
    { "key": "5", "label": "反復 [回]", "type": "integer" },
    { "key": "6", "label": "曲率の確認" },
    { "key": "7", "label": "ヘッセ行列の最小固有値 [-]", "type": "number", "format": general }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "methods" })
);
let termination = second_order.termination();
let outcome = if termination.is_success() {
    Outcome::satisfied("勾配が小さい点でヘッセ行列に負の固有値がないことを確かめた")
} else {
    Outcome::partial("二次の停止を満たす前に止まった")
};
emit_outcome!(
    outcome
        .status(termination.to_string())
        .diagnostic("x", second_order.x()[0], None)
        .diagnostic("V", second_order.fun(), None)
);
```

既定の $x_0=0$ では、ドッグレッグと `SteihaugCg` はどちらも 1 反復で鞍点 $(0,0)$ に達し、`GradientSmall` で止まる。
開始点の勾配は $(0,0.5)$ なので、最初の試行は $y$ だけを動かし、着いた点で勾配が 0 になるからである。
到達点のヘッセ行列の最小固有値は $-1$ で、この点は極小点ではないが、勾配の判定だけでは成功として返る。
二次の停止を有効にした実行は、鞍点で負の固有値を見つけて $x$ 方向へ半径 1 だけ進み、2 反復で極小点 $(1,0)$、$V=-0.25$ に達して `Converged` になる（最小固有値 1）。
$x_0=0.1$ では対称性が崩れ、3 つの方式とも $(1,0)$ に達する。

## まとめ

勾配の判定は一次の条件なので、勾配が零の鞍点でも `GradientSmall` が成功として返る。
`second_order_stopping` を有効にした `SteihaugCg` は、勾配が小さい点で密なヘッセ行列の慣性を調べ、負の固有値があれば負曲率の方向へ半径の長さだけ進む。
負の固有値がなければ `Converged` を返し、`second_order_checked()` が `true` になる。
この判定は零の固有値を負とみなさないので、半正定値のヘッセ行列を持つ退化した停留点では、到達点の曲率を別に検算する。
対称性のある問題で対称面の上から始めると勾配だけの反復は鞍点に向かうので、二次の停止を有効にするか、開始点をずらして結果を比べる。
