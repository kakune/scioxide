逐次二次計画法（SQP）は KKT 条件そのものに Newton 法を当てる方式である。
[ペナルティ法と拡張ラグランジュ法](../penalty-and-augmented-lagrangian/)のようにペナルティ係数を大きくして制約を満たすのではなく、乗数を部分問題の解として毎反復で求める。
記号と残差の定義は[非線形制約と KKT 条件](../nonlinear-constraints/)に従う。
不等式を余裕変数と対数障壁で扱う方式は[非線形内点法](../nonlinear-interior-point/)で説明する。

## 逐次二次計画法（SQP: Sequential Quadratic Programming）

まず等式制約だけの場合を考える。
KKT 条件 $\nabla f+\mathbf{J}_c^\mathsf{T}\boldsymbol{\lambda}=\mathbf{0}$、$\mathbf{c}=\mathbf{0}$ を未知数 $(\mathbf{x},\boldsymbol{\lambda})$ の連立方程式とみて Newton 法を当てると、補正 $\mathbf{p}$ と次の乗数 $\boldsymbol{\lambda}_{k+1}$ は

$$
\begin{bmatrix} \nabla^2_{\mathbf{x}\mathbf{x}}\mathcal{L}_k & \mathbf{J}_c(\mathbf{x}_k)^\mathsf{T} \\ \mathbf{J}_c(\mathbf{x}_k) & \mathbf{0} \end{bmatrix}
\begin{bmatrix} \mathbf{p} \\ \boldsymbol{\lambda}_{k+1} \end{bmatrix}
= -\begin{bmatrix} \nabla f(\mathbf{x}_k) \\ \mathbf{c}(\mathbf{x}_k) \end{bmatrix}
$$

を満たす（$\mathbf{J}_c$ は等式制約のヤコビ行列）。
これは二次モデル $\nabla f^\mathsf{T}\mathbf{p}+\tfrac12\mathbf{p}^\mathsf{T}\nabla^2_{\mathbf{x}\mathbf{x}}\mathcal{L}_k\mathbf{p}$ を線形化した制約 $\mathbf{c}+\mathbf{J}_c\mathbf{p}=\mathbf{0}$ の下で最小にする問題の KKT 系そのものである。
不等式も線形化して加えると、現在点 $(\mathbf{x}_k, \boldsymbol{\lambda}_k, \boldsymbol{\mu}_k)$ での補正 $\mathbf{p}$ は次の二次計画（QP）部分問題の解として得られる。

$$
\begin{aligned}
\min_{\mathbf{p} \in \mathbb{R}^n} \quad & \nabla f(\mathbf{x}_k)^\mathsf{T}\mathbf{p} + \frac{1}{2}\mathbf{p}^\mathsf{T} \mathbf{B}_k \mathbf{p} \\
\text{subject to} \quad & c_i(\mathbf{x}_k) + \nabla c_i(\mathbf{x}_k)^\mathsf{T}\mathbf{p} = 0 \quad (i \in \mathcal{E}) \\
& g_j(\mathbf{x}_k) + \nabla g_j(\mathbf{x}_k)^\mathsf{T}\mathbf{p} \le 0 \quad (j \in \mathcal{I}) \\
& \mathbf{l} - \mathbf{x}_k \le \mathbf{p} \le \mathbf{u} - \mathbf{x}_k
\end{aligned}
$$

$\mathbf{B}_k$ はラグランジュ関数のヘッセ行列の近似である。
部分問題を解くと、ステップ $\mathbf{p}$ と次の乗数推定が同時に得られる。
解の近くで有効集合が変わらず、$\mathbf{B}_k$ が厳密なヘッセ行列なら Newton 法と同じく二次収束する。
準 Newton 近似で期待できるのは超一次収束までである。

`Sqp` は変数の上下限を線形化した行ではなく、上の最後の行のようにステップの箱として部分問題に直接渡す。
初期点は箱に射影され、すべての試行点が箱の中にある。
目的と制約は、[KKT 残差と終了判定](oxref:optimize-kkt-residuals)で説明したとおり初期点の導関数で正規化してから扱う。

## メリット関数と二次補正

Newton 補正は解から遠い点では目的と違反のどちらも減らさないことがあるので、ステップの受理はメリット関数で判定する。
`Sqp` は正規化した問題の L1 メリット関数

$$
\phi_\nu(\mathbf{x})=f(\mathbf{x})+\nu\Big(\sum_{i\in\mathcal{E}}|c_i(\mathbf{x})|+\sum_{j\in\mathcal{I}}\max(0,g_j(\mathbf{x}))\Big)
$$

を使い、Armijo 条件を満たすまでステップ幅 $\alpha$ を 1 から半分ずつにする。
ペナルティ係数 $\nu$ は 2 から始まり、部分問題が返す乗数（境界の乗数を含む）の最大絶対値に 1 を足した値を下回らないように増やす。
$\nu$ は減らさない。
$\mathbf{B}_k$ が正定値で $\nu$ が乗数の最大絶対値より大きければ、部分問題の解 $\mathbf{p}$ での $\phi_\nu$ の方向微分は負になり、$\mathbf{p}$ は降下方向になる。
方向微分が負でなければ直線探索をせず、後で述べる復元段階に入る。

最初の試行 $\alpha=1$ が棄却されたときは、二次補正を 1 回試す。
試行点での制約値に合わせて線形化した制約のもとで $\min\tfrac12\|\mathbf{d}\|_2^2$ を解き、補正 $\mathbf{d}$ が元のステップより短ければ試行点に加えて判定し直す。
L1 メリット関数では、解の近くの完全な Newton 補正でも制約の曲率のために違反が増えて棄却されることがある（Maratos 効果）。
二次補正は、曲がった制約面に沿って試行点を戻し、この棄却を避けるためにある。

$\mathbf{B}_k$ は $\mathbf{B}_0=\mathbf{I}/\max(1,\|\mathbf{x}_0\|_\infty)$ から始め、ラグランジュ関数の勾配差 $\mathbf{y}_k$ と変位 $\mathbf{s}_k$ で BFGS 更新する。
制約付き問題では $\mathbf{s}_k^\mathsf{T}\mathbf{y}_k>0$ が保証されない。
そこで Powell の減衰により、$\mathbf{s}_k^\mathsf{T}\mathbf{y}_k\ge0.2\,\mathbf{s}_k^\mathsf{T}\mathbf{B}_k\mathbf{s}_k$ となるまで $\mathbf{y}_k$ を $\mathbf{B}_k\mathbf{s}_k$ の側へ寄せ、$\mathbf{B}_k$ を正定値に保つ。
`Sqp` は `ConstrainedProblem::with_lagrangian_hessian` の厳密なヘッセ行列を使わず、常にこの近似を使うので、二次収束は期待できない。

## 部分問題の解法と復元

部分問題は既定の `DenseSqpSubproblem` が主有効集合法で解く。
まず等式だけを能動として解き、その解がすべての線形化不等式とステップの箱を満たせば、それを部分問題の解とする。
満たさない場合は、違反を表す 1 個の弾性変数を加えた問題で線形化制約を満たす初期点を作る（弾性段階）。
弾性段階で違反を許容誤差まで下げられなければ、線形化した制約は矛盾しているとみなし、`SuspectedInfeasible` を返す。
これは非線形問題が実行不能であることを意味しない。

有効集合法の各段では列選択つきの Householder QR 分解で一次独立な能動制約の法線を選ぶ。
等式制約つきの KKT 系は `DenseKktProvider`（Ruiz の平衡化と有界ルーク枢軸選択つきの $\mathbf{L}\mathbf{D}\mathbf{L}^\mathsf{T}$ 分解）で解き、特異な最小二乗系は最小ノルムの SVD 解で解く。
部分問題の目的は正定値でなければならず、正定値でない $\mathbf{B}_k$ を渡すと `InvalidInput` になる。
`Converged` と示された部分問題の解は、部分問題の KKT 条件（線形化した制約、停留性、乗数の符号、相補性）に照らして検査し直す。
検査に通らなければ有効集合を空にして 1 回解き直し、それでも通らなければ `Stagnation` とする。

部分問題が `SuspectedInfeasible` を返した場合と、直線探索でステップを受理できなかった場合は、有界な復元段階に入る。
復元段階は等式と違反している不等式の行 $A$ について $\tfrac12\|\mathbf{J}_A\mathbf{d}+\mathbf{c}_A\|_2^2$ をステップの箱の中で最小にする線形最小二乗を解き、ステップ幅を半分ずつにしながら違反が減る点を探す。
違反が許容誤差以下か、復元を始めたときの半分以下になれば元の反復へ戻る。
違反が減っただけなら、そこから最小二乗を解き直し、これを最大 20 回（`with_max_restoration_iterations`）繰り返す。
違反が減らない場合、20 回で戻れない場合、復元を始めた点がすでに実行可能な場合は `Stagnation` で止まる。
復元の後は $\mathbf{B}_k$ を単位行列に戻し、乗数を 0 から推定し直す。

終了状態は次のとおりである。

- `Converged`：元の問題の KKT 残差がすべて閾値を満たした場合だけで、部分問題のステップが小さいことだけでは停留性とみなさない。
- `StepSmall`：実行可能な点で、部分問題のステップ $\|\mathbf{p}\|_2$ がステップの許容誤差を 2 回続けて下回った場合で、成功ではない。
- `Stagnation`：復元できない場合と、部分問題の解が検査に通らない場合。
- `IterationLimit`：反復の上限に達した場合。
  部分問題が反復の上限などの理由で止まった場合も、その終了理由をそのまま返す。

`SqpOptions` の既定は外側反復 1000 回、部分問題の有効集合反復 1000 回（`with_max_subproblem_iterations`）、復元 20 回で、ステップの許容誤差（既定は絶対・相対とも $\sqrt{\varepsilon_{\mathrm{mach}}}$）、微分の取り方、`OptimalityTolerances`、時間上限も設定できる。
ワンショット関数 `minimize_constrained(f, &x0, &constraints)` は、目的のクロージャを既定の `Sqp`（前進差分の導関数）で解き、成功しない終了を `Err` で返す。

## 部分問題の供給と受理状態

`SqpSubproblem` は現在点で線形化した部分問題を表し、公開フィールドとして目的のモデル `objective`、制約のヤコビ行列 `jacobian`、制約値 `values`、等式の行数 `equalities`、ステップの上下限 `bounds`、許容誤差 `tolerances`、反復上限 `max_iterations` を借用で持つ。
線形化した制約は `values + jacobian * d` で、等式が先、不等式は $\le0$ の向きである。
`SqpSubproblemObjective` は二次モデル（正定値な `hessian` と `gradient`）と最小二乗モデル（`design` と `target`）を区別し、後者は復元段階が使う。
`SqpSubproblemReport` は求解した部分問題の結果で、`new(termination)` に `with_active_rank`、`with_ambiguous_multipliers`、`with_inertia` を続けて作り、同名の読み出しメソッドで読む。
部分問題の成功は `Converged` で返し、`GradientSmall` を返すと `InvalidInput` になる。
目的の勾配が小さいことは、制約付きの KKT 条件の成立を意味しないからである。

`SqpSubproblemProvider` を実装した型を `SqpWorkspace::with_subproblem_provider` で設定すると、`DenseSqpSubproblem` の代わりに使われる。
供給側の解も `Sqp` が同じ検査にかけ、部分問題の成功とは別に、受理点で元の KKT 残差を計算し直す。

`SqpWorkspace::state()` が返す `SqpState` は、最後に受理した点の乗数と有効集合を元の単位で持つ。
`multipliers()` は非線形の行の乗数（等式が先）、`lower_multipliers()` と `upper_multipliers()` は変数ごとの境界の乗数、`step()` は最後に受理したステップ、`active_constraints()` は能動な制約の番号を返す。
番号 $i<m$ は非線形の行 $i$、$m+2j$ と $m+2j+1$ は変数 $j$ の下限と上限を表す（$m$ は非線形の行の数）。
`SqpWorkspace::set_warm_start` に `SqpState` を渡すと、次の求解の乗数と有効集合の初期値になり、$\mathbf{B}_k$ は初期化される。
寸法が問題と合わない状態や負の不等式乗数を渡すと、次の `minimize_into` が `InvalidInput` を返す。

`OptimizeResult::method_diagnostics()` が返す `OptimizeDiagnostics::Sqp(sqp, globalization)` の `SqpDiagnostics` は、最後に受理した部分問題の能動法線の階数 `active_rank()`、乗数が一意でない可能性 `multipliers_ambiguous()`、慣性 `inertia()` を持つ。
ほかに二次補正の試行と受理の回数（`second_order_corrections()`、`accepted_corrections()`）、復元の回数 `restoration_solves()`、固定変数の導関数の有無 `fixed_derivatives_available()` を読める。
準備容量は `SqpWorkspaceRequirements` で確認する。

## 従属する等式と乗数

$x+y=b$ の下で $\tfrac12(x^2+y^2)$ を最小にする。
独立な解析解は $(b/2,b/2)$ で、等式乗数は $\lambda=-b/2$ である。
同じ等式を 2 倍して追加すると、最適点は変わらないが、二つの法線が平行になり LICQ が成り立たなくなる。
$\lambda_1+2\lambda_2=-b/2$ を満たす乗数の組はすべて停留性を満たし、二つの等式乗数は一意に決まらない。

次のセルは `Sqp` で原点から解き、点、等式違反、乗数から計算し直した停留残差、受理点の乗数、`SqpDiagnostics` の階数と曖昧さの印を出す。
入力は右辺 $b$ と従属制約の有無である。

```rust
//| id: optimize-sqp-kkt-residuals
//| ref: optimize-sqp-kkt-residuals
//| title: 従属制約の有無と元の KKT 残差を比べる
//| run: reactive
//| crates: [scioxide-core, scioxide-optimize]
//| inputs:
//|   rhs: {"type":"range","label":"等式の右辺 b [-]","min":0.5,"max":2,"step":0.25,"value":1}
//|   redundant: {"type":"checkbox","label":"2 倍した等式を加える","value":true}
//| cases:
//|   - {"id":"independent","label":"従属制約なし","description":"能動法線の階数は 1 のまま乗数が一意になり、乗数 −0.5 だけが残る。","inputs":{"redundant":false}}
//|   - {"id":"rhs-two","label":"右辺 b = 2","description":"解は (1, 1) に移り、1 本目の乗数は −1 になる。","inputs":{"rhs":2}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"point","path":"/rows/0/0","approx":{"value":0.5,"atol":1e-10}}
//|       - {"artifact":"point","path":"/rows/0/3","range":{"min":0,"max":1e-10}}
//|       - {"artifact":"point","path":"/rows/0/5","equals":"Converged"}
//|       - {"artifact":"multipliers","path":"/rows/0/1","approx":{"value":-0.5,"atol":1e-10}}
//|       - {"artifact":"rank","path":"/rows/0/0","equals":1}
//|       - {"artifact":"rank","path":"/rows/0/1","equals":true}
//|       - {"path":"/outputs/3/state","equals":"satisfied"}
//|   - case: independent
//|     expect:
//|       - {"artifact":"point","path":"/rows/0/5","equals":"Converged"}
//|       - {"artifact":"multipliers","path":"/rows/0/1","approx":{"value":-0.5,"atol":1e-10}}
//|       - {"artifact":"rank","path":"/rows/0/1","equals":false}
//|       - {"path":"/outputs/3/state","equals":"satisfied"}
//|   - case: rhs-two
//|     expect:
//|       - {"artifact":"point","path":"/rows/0/0","approx":{"value":1,"atol":1e-10}}
//|       - {"artifact":"point","path":"/rows/0/4","range":{"min":0,"max":1e-10}}
//|       - {"artifact":"rank","path":"/rows/0/1","equals":true}
use scioxide_core::ExecutionContext;
use scioxide_optimize::{
    ConstrainedProblem, ConstraintFn, Constraints, ObjectiveFn, OptimizeDiagnostics,
    OptimizeResult, Sqp,
};
let b = rhs;
let objective = ObjectiveFn::new(2, |x: &[f64]| Ok(0.5 * (x[0] * x[0] + x[1] * x[1])))
    .with_gradient(|x: &[f64], g: &mut [f64]| {
        g.copy_from_slice(x);
        Ok(())
    });
// 2 本目は 1 本目を 2 倍した等式 2(x + y − b) = 0 で、法線が平行になる。
let mut constraints = Constraints::new(2).map_err(|e| e.to_string())?;
let scales: &[f64] = if redundant { &[1.0, 2.0] } else { &[1.0] };
for &scale in scales {
    let c = ConstraintFn::new(2, move |x: &[f64]| Ok(scale * (x[0] + x[1] - b))).with_jacobian(
        move |_: &[f64], row: &mut [f64]| {
            row.copy_from_slice(&[scale, scale]);
            Ok(())
        },
    );
    constraints = constraints.equality(c).map_err(|e| e.to_string())?;
}
let problem = ConstrainedProblem::new(&objective, &constraints).map_err(|e| e.to_string())?;
let solver = Sqp::default();
let mut work = solver.workspace(&problem).map_err(|e| e.to_string())?;
let mut result = OptimizeResult::empty();
solver
    .minimize_into(
        &problem,
        &[0.0, 0.0],
        &mut result,
        &mut work,
        ExecutionContext::sequential(),
    )
    .map_err(|e| e.to_string())?;
// 独立な検算: 法線 (k, k) に乗数を掛けた和で停留性 x + Σ k λ_k を元の式から計算する。
let multipliers = work.state().multipliers();
let weighted: f64 = scales.iter().zip(multipliers).map(|(k, v)| k * v).sum();
let x = result.x();
let stationarity = (x[0] + weighted).abs().max((x[1] + weighted).abs());
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let fixed6 = serde_json::json!({ "fractionDigits": 6 });
emit_table_with_columns!(
    serde_json::json!([
        { "key": "0", "label": "x [-]", "type": "number", "format": fixed6 },
        { "key": "1", "label": "y [-]", "type": "number", "format": fixed6 },
        { "key": "2", "label": "等式違反 [-]", "type": "number", "format": sci3 },
        { "key": "3", "label": "停留残差（検算） [-]", "type": "number", "format": sci3 },
        { "key": "4", "label": "解析解との差 [-]", "type": "number", "format": sci3 },
        { "key": "5", "label": "終了理由" }
    ]),
    vec![(
        x[0],
        x[1],
        (x[0] + x[1] - b).abs(),
        stationarity,
        (x[0] - b / 2.0).abs().max((x[1] - b / 2.0).abs()),
        result.termination().to_string()
    )],
    metadata = serde_json::json!({ "id": "point" })
);
emit_table_with_columns!(
    serde_json::json!([
        { "key": "0", "label": "等式の番号", "type": "integer" },
        { "key": "1", "label": "受理点の乗数 [-]", "type": "number", "format": fixed6 }
    ]),
    multipliers.iter().copied().enumerate().collect::<Vec<_>>(),
    metadata = serde_json::json!({ "id": "multipliers" })
);
let OptimizeDiagnostics::Sqp(sqp, _) = result.method_diagnostics() else {
    return Err("SQP の診断がない".to_string());
};
emit_table_with_columns!(
    serde_json::json!([
        { "key": "0", "label": "能動法線の階数", "type": "integer" },
        { "key": "1", "label": "乗数が一意でない" },
        { "key": "2", "label": "停留性 [-]", "type": "number", "format": sci3, "nullText": "なし" },
        { "key": "3", "label": "反復 [回]", "type": "integer" }
    ]),
    vec![(
        sqp.active_rank(),
        sqp.multipliers_ambiguous(),
        result.stationarity(),
        result.iterations()
    )],
    metadata = serde_json::json!({ "id": "rank" })
);
let termination = result.termination();
let outcome = if termination.is_success() {
    Outcome::satisfied("元の問題の KKT 残差が許容誤差を満たした")
} else {
    Outcome::partial("KKT 残差の判定を満たす前に止まった")
};
emit_outcome!(
    outcome
        .status(termination.to_string())
        .diagnostic("反復", result.iterations() as f64, None)
        .diagnostic("停留残差（検算）", stationarity, None)
);
```

既定の $b=1$ で従属制約がある場合、`Sqp` は 1 反復で $(0.5, 0.5)$ に達して `Converged` になり、等式違反と停留残差は 0 である。
原点では目的の勾配が 0 なので目的の尺度は 1 になり、正規化した問題の $\mathbf{B}_0=\mathbf{I}$ が厳密なヘッセ行列と一致する。
そのため、最初の QP 部分問題の解がそのまま解になる。
乗数は $(\lambda_1,\lambda_2)=(-0.5,0)$ で、重みをすべて 1 本目の制約に置いた解の一つである。
能動法線の階数は 1、`multipliers_ambiguous()` は `true` で、二つの法線が従属していることを返す。
従属制約をなくすと階数は 1 のまま `multipliers_ambiguous()` が `false` になり、乗数 $-0.5$ は一意に決まる。
$b=2$ では解が $(1,1)$ に移り、1 本目の乗数は $-1$ になる。
従属制約がある場合は、個々の乗数の一致を最適性の条件にせず、重みを付けた法線の和 $\lambda_1+2\lambda_2$ が目的の勾配と釣り合うことを確かめる。

## まとめ

SQP は線形化した制約の下で二次モデルを解き、乗数を部分問題の解として毎反復で得る。
`Sqp` は減衰 BFGS の近似ヘッセ行列、L1 メリット関数の Armijo 探索、1 回の二次補正、有界な復元段階を組み合わせ、変数の箱は部分問題のステップの箱として守る。
`Converged` は元の問題の KKT 残差が閾値を満たした場合だけで、`StepSmall`、`Stagnation`、`IterationLimit` は成功ではない。
乗数は `SqpWorkspace::state()`、部分問題の階数や二次補正の回数は `method_diagnostics()` から読む。
従属制約があると個々の乗数は一意でないので、`multipliers_ambiguous()` を確かめ、法線の重み付き和が目的の勾配と釣り合うことで判断する。
