[Wolfe 条件と強 Wolfe 条件](oxref:optimize-wolfe-conditions)は受理するステップ幅の性質を定めるが、それを満たす $\alpha$ の探し方は定めない。
このページでは、`StrongWolfeLineSearch` が強 Wolfe 条件

$$
\phi(\alpha) \le \phi(0) + c_1 \alpha \phi'(0), \qquad |\phi'(\alpha)| \le c_2 |\phi'(0)|
$$

を満たす $\alpha$ を、条件を満たす区間を囲むブラケティング（bracketing）と、その区間を縮めるzoom フェーズで探す手順を説明する。
記号は[直線探索のページ](../line-search-and-scaling/)と同じで、$\phi(\alpha) = f(\mathbf{x} + \alpha\mathbf{p})$、$0 < c_1 < c_2 < 1$ である。

## ブラケティングとzoom フェーズの手順

`StrongWolfeLineSearch` は Nocedal–Wright のアルゴリズム 3.5 と 3.6 に沿って探す。
各試行で目的値と勾配を 1 回ずつ評価し、$\phi(\alpha)$ と $\phi'(\alpha)$ を得る。

```text
ブラケティング: α₁ = α_init、α₀ = 0 として i = 1, 2, … について
  1. Armijo 条件が成り立たないか、i > 1 で φ(αᵢ) ≥ φ(αᵢ₋₁) なら zoom(αᵢ₋₁, αᵢ)
  2. 強 Wolfe 条件が成り立てば αᵢ を受理
  3. φ′(αᵢ) ≥ 0 なら zoom(αᵢ, αᵢ₋₁)
  4. αᵢ₊₁ = 2αᵢ
zoom(lo, hi): lo は Armijo 条件を満たす試行のうち目的値が最小の端
  1. φ(lo)、φ′(lo)、φ(hi) を通る二次式の最小点 α を求め、
     区間の両端から幅の 1/10 以内なら中点に置き換える
  2. Armijo 条件が成り立たないか φ(α) ≥ φ(lo) なら hi = α
  3. 強 Wolfe 条件が成り立てば α を受理
  4. φ′(α)(hi − lo) ≥ 0 なら hi = lo、そのうえで lo = α
```

ブラケティングの段階は Armijo 条件を満たす点 $\alpha_{i-1}$ と、それより先で目的値が増えたか傾きが正になった点 $\alpha_i$ を見つけるまで $\alpha$ を 2 倍ずつ広げる。
このとき二点の間に強 Wolfe 条件を満たす区間があることは、Nocedal–Wright 補題 3.1 の証明と同じ議論で示せる。
zoom フェーズの段階は端 lo で常に Armijo 条件を満たし、lo での傾きが hi の方向に下る、という性質を保ったまま区間を縮める。

## 保護付きの二次補間

lo を $\alpha_\ell$、hi を $\alpha_h$、$\Delta = \alpha_h - \alpha_\ell$ とおく。
$\phi(\alpha_\ell)$、$\phi'(\alpha_\ell)$、$\phi(\alpha_h)$ を通る二次式 $q(\alpha) = \phi(\alpha_\ell) + \phi'(\alpha_\ell)(\alpha - \alpha_\ell) + c(\alpha - \alpha_\ell)^2$ の係数は $c = \{\phi(\alpha_h) - \phi(\alpha_\ell) - \phi'(\alpha_\ell)\Delta\}/\Delta^2$ で、$c > 0$ のときの最小点は

$$
\alpha_q = \alpha_\ell - \frac{\phi'(\alpha_\ell)\,\Delta^2}{2\{\phi(\alpha_h) - \phi(\alpha_\ell) - \phi'(\alpha_\ell)\Delta\}}
$$

である。
$\phi$ が二次関数なら $\alpha_q$ は直線上の最小点に一致する。
$\alpha_q$ が区間の両端から幅の 1/10 以内にあるか、区間の外にあるか、計算できない場合は、中点を試行にする。
この保護により、次の区間の幅は少なくとも 1 割縮み、端のすぐそばの点を繰り返し試す停滞を避ける。

## 試行の上限と失敗

ブラケティングとzoom フェーズは合わせて `new` の `max_iterations`（既定 40 回）の試行を上限とし、上限に達すると `IterationLimit` になる。
区間の幅が $8\varepsilon_{\mathrm{mach}}\max(|\mathrm{lo}|, |\mathrm{hi}|)$ 以下になるか中点が区間の内側に表せなくなると `Stagnation`、次の試行が最小ステップ幅を下回ると `StepSizeLimit` で止まる。
`with_step_tolerance` で区間の幅の許容誤差を設定すると、幅がそれを下回ったときも `StepSizeLimit` で止まる。
試行点が定義域の外にあるか目的値が有限でない場合は、その点を区間の端として、lo（Armijo 条件を満たした最後の試行、初めは $\alpha = 0$）との中点へ進む。

既定は $\alpha_{\mathrm{init}} = 1$、$c_1 = 10^{-4}$、$c_2 = 0.9$、最小ステップ幅 $\varepsilon_{\mathrm{mach}}$ と最小の正規化数の積（f64 で $2^{-1074} \approx 4.9\times10^{-324}$）である。
`for_nonlinear_cg` は $c_2 = 0.1$ を使い、直線上の最小点により近い $\alpha$ を求める。
Armijo 条件と曲率条件の比較は、比べる量の大きさに対して $8\varepsilon_{\mathrm{mach}}$ の丸めの余裕を持たせる。
`BacktrackingLineSearch` は Armijo 条件をこの余裕なしで比べる。
各試行は目的値と勾配を 1 回ずつ評価するので、強 Wolfe 条件の探索は試行あたり `BacktrackingLineSearch` の 2 倍の評価を使う（勾配を差分で求める場合はさらに増える）。
探索が受理せずに終わったときに結果をどう読むかは、[直線探索の API](oxref:optimize-line-search-api)で説明する。

## 試行列の実験

[直線探索のページの実験](oxref:optimize-armijo-scaling)と同じ二次関数 $f(x, y) = \tfrac12(x^2 + \kappa y^2)$ で、点 $(1, 1)$ から最急降下方向 $\mathbf{p} = -(1, \kappa)$ へ `StrongWolfeLineSearch`（$c_1 = 10^{-4}$、試行 40 回）を動かし、ブラケティングとzoom フェーズの試行を順に並べる。
直線上の最小点は $\alpha^* = (1 + \kappa^2)/(1 + \kappa^3)$ である。
目的関数は評価した点の $x$ 座標から試行のステップ幅 $\alpha = 1 - x$ を記録する。
入力は曲率比 $\kappa$、曲率条件の定数 $c_2$（$c_2 = 0.1$ は非線形共役勾配法の既定）、初期ステップ幅 $\alpha_{\mathrm{init}}$ である。
表の各行は 1 回の試行で、$\alpha/\alpha^*$、$\phi(\alpha)$、閉形式から計算した $\phi'(\alpha)/\phi'(0)$、二つの条件の成否（閉形式による独立な判定）を示す。
二次関数では $\phi'(\alpha)/\phi'(0) = 1 - \alpha/\alpha^*$ なので、曲率条件は $|1 - \alpha/\alpha^*| \le c_2$ と同じになる。

```rust
//| id: optimize-strong-wolfe-trials
//| ref: optimize-strong-wolfe-trials
//| title: 強 Wolfe 条件のブラケティングとzoom フェーズの試行を追う
//| run: reactive
//| crates: [scioxide-core, scioxide-optimize, scioxide-differentiate]
//| inputs:
//|   condition_number: {"type":"range","label":"曲率比 κ [-]","description":"y 方向の曲率を変える。","min":1,"max":1000,"step":1,"value":100}
//|   curvature: {"type":"select","label":"曲率条件の定数 c₂","description":"小さいほど直線上の最小点に近い α を求める。","options":["0.9","0.1"],"value":"0.9"}
//|   initial_step: {"type":"range","label":"初期ステップ幅 α_init [-]","description":"ブラケティングの最初の試行。小さいと倍々に広げる段階が現れる。","min":0.001,"max":1,"step":0.001,"value":1}
//| cases:
//|   - {"id":"short-start","label":"α_init = 0.002","description":"最初の α = 0.002（0.2α*）で φ′(α)/φ′(0) = 0.80 ≤ 0.9 となり、そのまま受理する。","inputs":{"initial_step":0.002}}
//|   - {"id":"short-start-cg","label":"α_init = 0.002、c₂ = 0.1","description":"α を 0.002 から倍々に 0.016 まで広げ、φ が前の試行より増えた区間 [0.008, 0.016] を補間して 5 回目の試行で α* を受理する。","inputs":{"initial_step":0.002,"curvature":"0.1"}}
//|   - {"id":"kappa-1","label":"κ = 1","description":"最初の α = 1 で φ′(α) = 0 になり、1 回の試行で受理する。","inputs":{"condition_number":1}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"trials","path":"/rowCount","equals":6}
//|       - {"artifact":"trials","path":"/rows/4/1","approx":{"value":0.0625,"atol":1e-12}}
//|       - {"artifact":"trials","path":"/rows/5/2","approx":{"value":1.0,"atol":1e-9}}
//|       - {"artifact":"trials","path":"/rows/5/6","equals":"成立"}
//|       - {"path":"/outputs/1/state","equals":"satisfied"}
//|   - case: short-start
//|     expect:
//|       - {"artifact":"trials","path":"/rowCount","equals":1}
//|       - {"artifact":"trials","path":"/rows/0/4","approx":{"value":0.80002,"atol":1e-4}}
//|   - case: short-start-cg
//|     expect:
//|       - {"artifact":"trials","path":"/rowCount","equals":5}
//|       - {"artifact":"trials","path":"/rows/3/4","approx":{"value":-0.59984,"atol":1e-4}}
//|       - {"artifact":"trials","path":"/rows/4/2","approx":{"value":1.0,"atol":1e-9}}
//|   - case: kappa-1
//|     expect:
//|       - {"artifact":"trials","path":"/rowCount","equals":1}
//|       - {"artifact":"trials","path":"/rows/0/1","approx":{"value":1.0,"atol":1e-12}}
use scioxide_core::{Budget, ExecutionContext, SciOxideError};
use scioxide_differentiate::{DerivativeOperation, DerivativeStrategy};
use scioxide_optimize::{
    DerivativeWorkspace, LineSearch, ObjectiveFunction, StrongWolfeLineSearch,
};
use std::cell::RefCell;

// f(x, y) = ½(x² + κy²)。評価した試行のステップ幅 α = 1 − x を記録する。
struct Valley {
    kappa: f64,
    trials: RefCell<Vec<f64>>,
}
impl ObjectiveFunction<f64> for Valley {
    fn dim(&self) -> usize {
        2
    }
    fn eval(&self, v: &[f64]) -> Result<f64, SciOxideError> {
        self.trials.borrow_mut().push(1.0 - v[0]);
        Ok(0.5 * (v[0] * v[0] + self.kappa * v[1] * v[1]))
    }
    fn gradient_into(&self, v: &[f64], output: &mut [f64]) -> Result<bool, SciOxideError> {
        output.copy_from_slice(&[v[0], self.kappa * v[1]]);
        Ok(true)
    }
}

let sig4 = serde_json::json!({ "significantDigits": 4 });
let c2: f64 = curvature
    .parse()
    .map_err(|e: std::num::ParseFloatError| e.to_string())?;
let kappa = condition_number;
let valley = Valley {
    kappa,
    trials: RefCell::new(Vec::new()),
};
// 比較用（式）: φ(α)、φ′(α) = ∇f(x + αp)ᵀp、直線上の最小点 α* = (1 + κ²)/(1 + κ³)。
let phi = |a: f64| {
    let (u, v) = (1.0 - a, 1.0 - kappa * a);
    0.5 * (u * u + kappa * v * v)
};
let dphi = |a: f64| -(1.0 - a) - kappa * kappa * (1.0 - kappa * a);
let exact = (1.0 + kappa * kappa) / (1.0 + kappa * kappa * kappa);
// 起点 (1, 1)、最急降下方向 p = −(1, κ)、φ(0) と φ′(0)。
let (x, p) = ([1.0_f64, 1.0], [-1.0, -kappa]);
let (f0, slope) = (phi(0.0), dphi(0.0));
let trials = Budget::try_from(40).map_err(|e| e.to_string())?;
let minimum = f64::MIN_POSITIVE * f64::EPSILON;
let search = StrongWolfeLineSearch::new(initial_step, minimum, 1.0e-4, c2, trials)
    .map_err(|e| e.to_string())?;
let mut derivatives =
    DerivativeWorkspace::new(DerivativeOperation::Gradient, 2, 1).map_err(|e| e.to_string())?;
let mut buffers = [[0.0_f64; 2]; 4];
let [trial, gradient, candidate, candidate_gradient] = &mut buffers;
let result = search
    .search_into(
        &valley,
        &x,
        f0,
        &p,
        slope,
        DerivativeStrategy::default(),
        trial,
        gradient,
        candidate,
        candidate_gradient,
        &mut derivatives,
        ExecutionContext::sequential().into(),
        None,
    )
    .map_err(|e| e.to_string())?;
// 独立検算: 記録した各試行の α で、二つの条件を閉形式の φ と φ′ から判定する。
let rows: Vec<_> = valley
    .trials
    .borrow()
    .iter()
    .enumerate()
    .map(|(i, &a)| {
        let mark = |holds: bool| if holds { "成立" } else { "不成立" };
        let ratio = dphi(a) / slope;
        let armijo = mark(phi(a) <= f0 + 1.0e-4 * a * slope);
        let curvature = mark(ratio.abs() <= c2);
        (i + 1, a, a / exact, phi(a), ratio, armijo, curvature)
    })
    .collect();
let columns = serde_json::json!([
    { "key": "0", "label": "試行", "type": "integer" },
    { "key": "1", "label": "α [-]", "type": "number", "format": sig4 },
    { "key": "2", "label": "α/α* [-]", "type": "number", "format": sig4 },
    { "key": "3", "label": "φ(α) [-]", "type": "number", "format": sig4 },
    { "key": "4", "label": "φ′(α)/φ′(0) [-]", "type": "number", "format": sig4 },
    { "key": "5", "label": "Armijo 条件" },
    { "key": "6", "label": "強い曲率条件" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "trials" })
);
let outcome = if result.is_success() {
    Outcome::satisfied("強 Wolfe 条件を満たすステップ幅を受理した")
} else if result.has_trial() {
    Outcome::partial("受理せずに止まり、最良の試行だけを返した")
} else {
    Outcome::failed("有限な目的値を持つ試行がない")
};
emit_outcome!(
    outcome
        .status(format!("{:?}", result.termination()))
        .diagnostic("目的の評価", result.fun_evals() as f64, None)
        .diagnostic("勾配の評価", result.grad_evals() as f64, None)
);
```

既定の $\kappa = 100$、$\alpha_{\mathrm{init}} = 1$ では、最初の $\alpha = 1$ が Armijo 条件を満たさないので、区間 $[0, 1]$ のzoom フェーズに入る。
二次補間の最小点は $\alpha^* = 0.0100$ だが、区間の端から幅の 1/10 以内にあるので中点に置き換わり、試行は 0.5、0.25、0.125、0.0625 と区間を半分にする。
区間が $[0, 0.0625]$ まで縮むと $\alpha^*$ が端の 1/10 より内側に入り、$\phi$ が二次式なので補間がそのまま $\alpha^*$ を与え、6 回目の試行で受理する。
$c_2 = 0.1$ でも同じ試行列になるのは、受理した点で $\phi'(\alpha) = 0$ となり、どちらの $c_2$ の曲率条件も満たすからである。
$\kappa = 1000$ では区間を 7 回半分にした後、9 回目の試行で $\alpha^*$ を受理する。

$\alpha_{\mathrm{init}} = 0.002$ から始めると、$c_2 = 0.9$ では最初の点（$\alpha = 0.2\alpha^*$、$\phi'(\alpha)/\phi'(0) = 0.80$）をそのまま受理し、$\phi$ は 50.5 から 32.5 までしか下がらない。
$c_2 = 0.1$ では 0.004、0.008、0.016 と倍々に広げ、0.016 で $\phi$ が $\phi(0.008)$ を上回ったので区間 $[0.008, 0.016]$ を補間し、5 回目の試行で $\alpha^*$ を受理する。
$c_2$ は短すぎるステップをどこまで除くかを決め、小さい $c_2$ は直線上の最小点に近いステップと引き換えに試行を増やす。
$\phi$ が二次式でなければ補間の最小点は近似になり、受理までの試行は一般に増える。

## まとめ

`StrongWolfeLineSearch` は、$\alpha$ を 2 倍ずつ広げて条件を満たす区間を囲み、保護付きの二次補間と中点で区間を縮める。
二次関数では補間が直線上の最小点をそのまま与えるが、補間点が区間の端に近いうちは中点が選ばれ、区間を半分ずつ縮める試行が続く。
$c_2$ は受理する傾きの範囲を決め、$c_2 = 0.9$ は短いステップも受理し、$c_2 = 0.1$ は試行を増やして直線上の最小点に近いステップを求める。
試行が上限（既定 40 回）に達するか区間が丸めの幅まで縮むと受理なしで止まるので、終了理由を `LineSearchTermination` で確かめる。
