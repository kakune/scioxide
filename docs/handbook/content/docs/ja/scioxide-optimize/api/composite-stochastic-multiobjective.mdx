このページは滑らかな部分と近接写像で表す合成目的の解法、等式で結んだ二ブロックの分割法（ADMM）、観測ごとにノイズを含む目的を標本化して扱う確率的一階法、複数の目的を同時に最小化する Pareto 探索の公開項目をまとめる。
どの解法も形の不一致、非有限な入力、コールバックやプロバイダーの失敗、数値的な破綻を `Err` で返し、そのとき呼び出し側の結果は書き換えない。
反復・評価・標本の上限、取り消し、期限による停止は `Ok` で返り、受理済みの点と唯一の終了理由（`OptimizeTermination`）が残る。
最初の点を受理する前に上限・取り消し・期限で止まった場合は、どの解法も構造化エラーを返す。
成功とみなすのは `Converged` と `GradientSmall` だけである。
作業領域は `workspace_requirements` と `workspace` で準備し、求解は問題・出力・作業領域・実行スコープを受け取る `minimize_into` または `solve_into` を使う。
作業領域と結果を内部で確保する所有値を返す API の `minimize` または `solve` もあり、成功でない終了も `Ok` の結果で返す。
近接法・ADMM・確率的一階法の結果は `require_success()` で成功を必須にできる。
実行スコープには実行コンテキストか親の `SolveContext` を渡し、試行の記録は作業領域の `last_attempt()` から読む。
確率的一階法と NSGA-II の再開には、作業領域から作った所有チェックポイントを `resume_into` へ渡す。

## 合成目的の近接勾配法

合成目的は $F(x) = f(x) + g(x)$ の形で、$f$ は勾配が Lipschitz 連続な滑らかな実数値関数、$g$ は真閉凸関数（L1 ノルムや箱の指示関数など、微分できなくてよい）である。
近接写像（proximal map）$\operatorname{prox}_{t g}(v) = \arg\min_u \{ g(u) + \lVert u - v \rVert_2^2 / (2t) \}$ は $g$ の情報を一回の写像で与える。
変数は実数でも複素数でもよいが、$f$ は実数値で、勾配は実内積 $\operatorname{Re}(g^{\mathsf H} \Delta x)$ の規約に従う。

## 二ブロック ADMM

ADMM（交互方向乗数法）は等式制約 $Ax + Bz = c$ のもとで $\min f(x) + g(z)$ を解くために、$x$ と $z$ の部分問題を交互に解き、尺度付きの双対変数 $u = y/\rho$ を更新する。
`Admm` は二つの部分問題を自分では解かず、呼び出し側が `AdmmBlockUpdate` として与える。
作用素は scioxide-core の `LinearOperator`（$A$ は随伴も要るので `AdjointOperator`）で、密行列、疎行列、注入した作用素を受け付ける。

## 標本化した観測と標本キー

標本化した目的とは同じ点でも呼ぶたびにノイズを含む値（ミニバッチの損失やシミュレーションの出力）を返す目的である。
解法は観測ごとに標本キー `OptimizationSampleKey` を作り、標本器（sampler）がその標本キーからソルバーが内容を解釈しないトークンを一つ返し、目的のコールバックがトークンを観測のシードやデータの添字として解釈する。
標本キーはエグゼキューターの分割に依存しないので、逐次でも注入したエグゼキューターでも同じ観測列になり、平均と分散は添字の順に集約する。
一回の観測は標本の上限を 1、プロバイダーの評価を 2 件（標本と目的または勾配）消費し、失敗した観測も数える。

## 確率的一階法

確率的勾配降下法（SGD）はミニバッチの平均勾配に沿って決めたステップ幅で進み、試行点を常に受理する。
確率的信頼領域法は一次のモデル $m(p) = \bar f + \bar g^{\mathsf T} p$ を半径 $\Delta$ の球の中だけで使い、基準点と試行点の目的の標本平均の差と、その経験的な標準誤差から受理を決める。
どちらも終了理由 `EstimatedStationarity` と `NoiseLimit` は統計的な推定の結果で、停留点の証明ではない。

## Pareto 支配と多目的探索

複数の目的 $F(x) = (F_1(x), \dots, F_m(x))$ を最小化するとき、$a$ が $b$ を Pareto 支配するとは、すべての成分で $a_i \le b_i$ かつある成分で $a_i < b_i$ であることをいう。
どの点にも支配されない点の集合が Pareto 前線で、`Nsga2` は有限の箱の中でその近似を集団として探す。
保持する値は標本の推定で、前線全体を得たことやノイズに対する保証にはならない。

## まとめ

微分できない正則化項や制約の指示関数を含む目的は、近接写像を与えて `ProximalGradient` か `Fista` で解き、`ProximalResult::mapping_norm` を一次の停留性の尺度として解釈する（最小点までの距離の上界ではない）。
変数を二つに分けると部分問題が易しくなる問題は `Admm` に部分問題の解法を注入し、主問題の残差と双対残差の両方を確かめる。
観測にノイズがある目的では、`NoiseModel` を正しく提示し、SGD か確率的信頼領域法の `StochasticResult` の標準誤差と終了理由を合わせて読み、`EstimatedStationarity` と `NoiseLimit` を収束と読み替えない。
複数の目的を比べる場合は `Nsga2` の保管庫を有限の近似として扱い、`ParetoArchive::verify` と `hypervolume_2d` で保持した推定を確かめる。
