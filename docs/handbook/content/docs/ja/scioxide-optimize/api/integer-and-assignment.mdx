この表は整数に制限した変数を含む線形計画（混合整数線形計画、MILP）の分枝限定法と、置換を一つ選ぶ二次割当問題（QAP）の発見的解法をまとめる。
どちらも探索量・メモリ使用量の上限を設定で受け取る。
設定した解法が探索量の上限で止まった場合は `Err` を返さず、`Ok` の結果に終了理由を入れて、それまでに検査した最良の候補を返す。
既定の設定で一回だけ解く `MipProblem::solve()` と `quadratic_assignment` は成功しなければ構造化エラーを返す。
QAP のメモリ使用量の上限は解く前に検査し、超えれば `ResourceLimit` のエラーになる。
MILP の結果の隔たり（ギャップ）は浮動小数点で検査した数値であり、厳密な算術による最適性の証明ではない。
QAP の結果は置換が全単射であることと目的値を検査するが、大域最適性を主張しない。

## 二次割当

二次割当問題は $n \times n$ の行列 $A$、$B$ に対して置換 $p$ を選び、$\sum_{i,j} A_{ij} B_{p(i)\,p(j)}$ を最小化（または最大化）する。
FAQ（Fast Approximate QAP）は二重確率行列の上で Frank–Wolfe 法による緩和を解き、線形割当で置換へ射影する。
2-opt は二つの割当の交換で目的を改善する。

## まとめ

MILP は `LpProblem` に整数変数の添字を加えた `MipProblem` で書き、既定の設定なら `MipProblem::solve()`、設定を選ぶなら `BranchAndBound` の節点数・ピボット数・`MipLimits` を用途に合わせて決める。
結果は `termination` に加えて `has_incumbent`、`absolute_gap`、`global_lower_bound` を読み、上限で止まった場合は隔たりが用途の許容範囲かを判断する。
探索を中断した後の前線を調べたい場合は `BranchAndBoundWorkspace::state()` の `MipSearchState` を読み、別の LP ソルバーを使う場合は `MipRelaxationSolver` を実装して `BranchAndBoundWorkspace::new` に渡す。
QAP を既定の設定で一回だけ解くなら `quadratic_assignment` を使う。
部分的な結果を受け取りたい場合や設定を選ぶ場合は、`QapProblemView` から `QapPlan` を作り、`QapOptions` の上限と再始動のシードを明示して解き、得た置換の目的値を `QapPlan::objective` で確かめる。
`fw_gap` や `relaxation_objective` は緩和の情報であり、置換の最適性の証明として読まない。
