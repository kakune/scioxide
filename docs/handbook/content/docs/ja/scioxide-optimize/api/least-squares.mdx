この表は残差ベクトル $r(x)$ から $\tfrac12\sum_i w_i\,\rho(\cdot)$ の形の目的を最小化する非線形最小二乗、$\tfrac12\lVert Ax-b\rVert^2$ に非負条件や上下限を付けた線形最小二乗、および scioxide-stats の当てはめに最適化の解法を渡すアダプターをまとめる。
非線形最小二乗の目的値（`cost`）は重みと損失を含み、因子 $\tfrac12$ を掛けた値である。
残差の問題そのものは `LeastSquaresProblem` トレイトかクロージャをラップする `LeastSquaresFn` で与え、これらは[目的関数・制約・結果の共通仕様](../problems-and-results/)の表にある。
初期点を取る解法と関数は、初期点の次元違いを `DimensionMismatch`、非有限な初期点を `NonFinite` にし、利用者の関数のエラーはそのまま返す。
最初の点を受理した後に反復の上限や停滞で止まった場合は `Ok` の結果に終了理由を入れて返すので、成功かどうかは `is_success()` で判定する。
既定の設定で一回だけ解く関数 `least_squares`、`curve_fit`、`nnls`、`bvls` は、成功しなければ結果の `require_success()` と同じ構造化エラーを返す。

## 非線形最小二乗の解法と作業領域

一つの型 `LeastSquares` が `LeastSquaresGlobalization` の二つの列挙子 `GaussNewton`（ステップ幅の後退）と `LevenbergMarquardt`（信頼領域の減衰）を設定で切り替えて使う。
二つは階数を考慮した線形化、損失、停止判定を共有し、違うのは一歩の守り方と試行の受理の判定である。
既定の `OriginalGradient` では、受理した点の勾配 $J^\mathsf{T}r$（重みと損失を含む元の単位）のノルムが `LeastSquaresOptions` の勾配の閾値以下になったとき、どちらの大域化も `GradientSmall`（成功）で止まる。
明示した `Minpack` はこの勾配の判定を別の収束基準に置き換えて `Converged` を返し、元の勾配が小さいとは限らない。
変位が小さいだけの停止は `StepSmall`、受理できる試行がない停止は `Stagnation` で、どちらも成功ではない。
受理したパラメータと残差は一緒に書き換えるので、退けた試行や失敗した試行が受理状態を部分的に変えることはない。

## 非負・上下限付きの線形最小二乗

$\min\tfrac12\lVert Ax-b\rVert^2$ を、`Nnls` は $x\ge0$ のもとで、`BoundedLinearLeastSquares` は任意の上下限のもとで解く。
どちらも有効集合法で、境界上の成分と自由な成分を区別し、元の座標で KKT 条件を再計算して停止を判定する。
無制約の解を後から切り詰めて答えにすることはしない。
成功は `Converged` だけで、密な問題の階数の打ち切りも KKT の検査を省かない。

## scioxide-stats の当てはめへの接続

scioxide-stats の当てはめ（`FitSolver` トレイト）に、最適化の解法を部品として渡すアダプターである。
数値計算は元の解法がそのまま行い、scioxide-stats は出力に反映する前に元の目的を独立に計算し直す。
終了理由は `Converged` と `GradientSmall` を収束、反復・評価・メモリ領域・節点・深さ・提案・標本の上限を上限到達、`Cancelled` と `TimeLimit` を停止、それ以外を未収束として scioxide-stats の `StatsTermination` に写す。

## まとめ

残差の構造があるときは一般の最小化ではなく最小二乗の解法を使う。
既定の Levenberg–Marquardt 法で一回だけ解くなら `least_squares` か、観測の組にモデルを当てはめる `curve_fit` を使う。
設定を選ぶ場合は `LeastSquares` を使い、`LeastSquaresGlobalization::GaussNewton` か `LeastSquaresGlobalization::LevenbergMarquardt` を選ぶ。
初期値が遠い・パラメータの相関が強い問題では、減衰のある後者を選ぶ。
外れ値への感度は `LeastSquaresOptions::with_loss` で変えられるが、損失の尺度は観測の単位とノイズの大きさに合わせて決める必要がある。
停止は既定の基準では `GradientSmall` だけが成功で、`StepSmall` や `Stagnation` の点は `rank()`、`condition_estimate()`、残差を見て識別可能性を疑う材料にする。
線形の問題に非負条件や上下限があれば `nnls` か `bvls`、設定を選ぶ場合は `Nnls` か `BoundedLinearLeastSquares` で解き、`kkt()` と `activity()` で境界上の成分と乗数を確かめる。
scioxide-stats の当てはめから使う場合は三つのアダプターのどれかを渡し、`result()` で元の解法の診断を読む。
