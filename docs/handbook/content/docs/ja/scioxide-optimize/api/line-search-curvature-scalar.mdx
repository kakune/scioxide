この表は局所法の部品として使う直線探索と準 Newton の曲率更新、および単独で使える一変数の最小化をまとめる。
直線探索は降下方向 $p$ に沿ってステップ幅 $\alpha>0$ を選び、受理できなかった場合は `Ok` の結果に `LineSearchTermination::Unsuccessful` とその理由を入れて返す。
構造の誤り（降下方向でない、長さの不一致）、起点の値や試行点の勾配が非有限な場合、コールバックの失敗はエラーで返り、呼び出し側の試行点の領域は書き換えない。
試行点の値が非有限な試行と定義域の外の試行はエラーにせず、棄却してステップ幅を縮める。
曲率更新は候補を検査してから確定し、条件を満たさない更新は前の近似を残して `Skipped` を返す。

## 一変数の最小化

区間内の最小を値だけで探す。
最小の括弧（bracket）は、順に並ぶ 3 点で中央の値が両端以下（少なくとも一方より小さい）の組で、求根の符号変化の括弧とは異なり、大域的な最小の証明でもない。

## まとめ

直線探索は設定（既定の BFGS 系は強 Wolfe、勾配降下と Newton は Armijo 後退）を選び、受理できなかった場合は `LineSearchFailure` で上限・最小ステップ幅・停滞を区別し、局所法はそれを `OptimizeTermination::LineSearchFailed` として返す。
独自の直線探索を作る場合は、試行ごとに `LineSearchScope` へ提案と棄却を伝え、結果は `LineSearchResult::try_accepted` などで検査して返す。
BFGS の曲率不足は `CurvaturePolicy` で減衰か飛ばしを選び、`method_diagnostics()` の `FirstOrder` が持つ `GlobalizationDiagnostics` の回数で、どちらが何回起きたかを確かめる。
区間 $[a, b]$ の最小化を既定の Brent 法で一回だけ行うなら `minimize_scalar` を使う。
設定を選ぶ場合の一変数の最小化は区間・括弧・2 点のシードのどれかから始め、`termination()` が `Converged` でなければ最良の観測を最小点として扱わない。
