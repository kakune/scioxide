この表は線形計画（LP）と凸二次計画（QP）の入力、ソルバー、結果、および結果に付く証拠を元の座標で検算する検証器をまとめる。
入力の検査（形、非有限値、対称性、凸性）に失敗すると `Err` が返り、計算が上限や停止で終わった場合は `Ok` の結果に終了理由 `OptimizeTermination` が入る。
LP と QP のソルバーは終了理由を `Converged`・`Infeasible`・`Unbounded` にする前に、元の問題に対する証拠（双対変数、Farkas 乗数、後退方向）を独立に検査し、検査に通らなければ `Stagnation`・`SuspectedInfeasible`・`SuspectedUnbounded` に下げる。
検証のレポートは浮動小数点の許容誤差による数値的な証拠であり、区間演算による包含が保証された区間ではない。
LP・QP の結果の型 `ProgrammingResult` は[目的関数・制約・結果の共通仕様](../problems-and-results/)の表にある。
既定の設定で一回だけ解くなら `LpProblem::solve()` と `QpProblem::solve()` を使い、検証済みの実行不能・非有界は `DomainError`、そのほかの成功でない終了は `ProgrammingResult::require_success` と同じエラーで返る。

## 証拠と独立な検証

検証器は与えられた証拠を元の座標で検査するだけで、代わりの乗数を解き直さない。
主変数の点と双対変数は呼び出し側が与え、主実行可能性、変数境界、乗数の符号、停留性（Lagrange 関数の勾配）、相補性、目的の差を別々に測る。

## まとめ

LP は `LinearConstraints` と `LpProblem` で書き（境界を付けない変数は非負になる）、既定の単体法で一回だけ解くなら `LpProblem::solve()`、設定を選ぶなら `SimplexSolver` か `InteriorPointLp` を使う。
QP は `QpProblem` でヘッセ行列の対称性の解釈を明示し、`QpProblem::solve()` か `QpSolver` で解く。
どちらで解いても非凸な問題は `Err` で拒まれ、境界のない変数は自由変数として扱われる。
結果は `is_success` だけでなく、終了理由が `Suspected…` か `Stagnation` かを読み、元座標の残差と `certificate()` の証拠を確かめる。
ソルバーと独立に主張を確かめたい場合は `ProgrammingVerifier::verify` か `ProgrammingVerifier::verify_into` に元の問題（`LpProblem` や `QpProblem` そのもの）を渡し、`VerificationStatus` と `objective_gap`・`dual_bound` を読む。
これらは浮動小数点の許容誤差による数値的な証拠であり、`KktOnly` は凸性が確認されていないことを意味する。
