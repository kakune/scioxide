このページは探索の途中で目的関数の地形のモデルや分割を作る大域探索をまとめる。
CMA-ES は正規分布の平均と共分散行列を適応させ、DIRECT は箱を矩形に分割して標本点を決定論的に選び、SHGO は標本点の Delaunay 単体複体から局所最小の候補を選び、サロゲートモデルによる探索は評価コストが大きい目的関数の観測からモデルを当てはめて次の評価点を提案する。
どれも探索そのものは目的関数の値だけを使い（注入した局所解法は導関数を使ってよい）、大域最適性の証明を返さない。

## 共通の規約

- 終了：計算回数などの上限に達した終了は `SearchBudgetCompleted` などの成功でない終了で、観測した最良の有限な点を保持する。
  CMA-ES の停滞は `PopulationStagnation`、DIRECT の選べる矩形がなくなった終了は `Stagnation` である。
- 有限箱：CMA-ES、DIRECT、SHGO は目的関数と scioxide-core の `Bounds` を束ねた `&BoundedObjective`（[目的関数・制約・結果の共通仕様](../problems-and-results/)）を受け取り、片側でも無限の端があれば `InvalidInput`（`UnsupportedConfiguration`）である。
  CMA-ES と SHGO は下端が上端より小さいことも要し、DIRECT は等しい両端を固定座標として扱う。
  サロゲートモデルの探索では、有限箱 `FiniteBounds` と観測を持つ `SurrogateHistory` が問題になる。
  初期点や設計が生成した点が箱の外なら `InvalidInput` である。
- 乱数と再現：CMA-ES と SHGO の既定のシードは 42 である。
  CMA-ES はシードで初期化した一本の `Xoshiro256**` の列を使い、SHGO はシードから標本ごとのシードを作ってそれぞれの `Xoshiro256**` を初期化する。
  DIRECT は乱数を使わない決定論的な方法である。
  サロゲートモデルの探索はシードから獲得関数の開始点を作る。
- メモリ領域：CMA-ES・DIRECT・SHGO は解法の `workspace(dimension)`、サロゲートモデルの探索は `workspace()` で要件に合うメモリを準備する。
  局所解法を使う方法では、その状態も作業領域が所有する。
  CMA-ES・DIRECT・SHGO の作業領域は直近の試行の記録 `last_attempt()` と受理した最良点 `last_accepted()` を返し、サロゲートモデルの探索の作業領域は `last_attempt()` だけを返す。
  エラーのとき呼び出し側の出力は変わらない。
  ただしサロゲートモデルの探索では、エラーより前に履歴へ加えた観測は残る。
- 局所解法：CMA-ES の任意の最終局所最適化と SHGO の局所最適化は、[複数開始点・basin hopping・dual annealing・差分進化](../global-search/)と同じ `SearchLocalSolver`・`LocalSolverFactory` を使う。
  局所の `ConvergenceFailure`、`NumericalInstability`、`Singular` は記録だけして探索を続ける。

## サロゲートモデルによる探索

サロゲートモデルによる探索は評価に計算コストのかかる目的関数の観測履歴 $\{(x_i, y_i, \sigma_i^2)\}$ にモデルを当てはめ、獲得関数（次に評価する価値を測る関数）を最大にする点を提案して評価する。
モデルの当てはめと予測は scioxide-interp の型に任せ、提案点の探索は `MultiStart` で行う。

## まとめ

連続で滑らかだが悪条件・非分離な地形には `CmaEs`、乱数を使わず評価点を再現したい低次元の箱には `Direct`、標本の地形から局所最小の候補を列挙して精度を改善したい低次元の問題には `Shgo`、1 回の評価コストが大きく評価回数を数十から数百に抑えたい問題には `SurrogateSearch` を選ぶ。
DIRECT と SHGO はメモリ領域と幾何の上限を設定で宣言し、上限を超える問題は計算の前に拒む。
どの方法も観測した最良点と探索の診断を返すだけで、大域最適性を証明しない。
得た点は局所解法で解の精度を改善し、別のシード・別の方法・既知の下界と照合してから採用する。
