摩擦のない斜面を静止状態から滑る質点を考える。
始点を $(0,0)$、終点を $(X,-H)$ とし、最も短い時間で到達する曲線を求める。
これは Johann Bernoulli が 1696 年に提起した最速降下線（brachistochrone）の問題である。
下向きの深さを $h=-y$ とすると、エネルギー保存から速さは $v=\sqrt{2gh}$ になる。
降下時間は曲線に沿った $\int ds/v$ で、連続問題は変分法で解ける。
ここでは曲線を折線で近似し、有限次元の制約のない最小化として L-BFGS で解く。

## 折線の時間と変数

横座標を $n$ 区間に等分して固定し、内部節点の深さを変数にする。
一つの直線区間では重力の接線成分が一定なので加速度も一定であり、速さは時間の一次関数で変わる。
したがって区間の平均の速さは両端の速さの平均 $(v_i+v_{i+1})/2$ で、区間長 $d_i$ の通過時間は厳密に

$$
T_i=\frac{2d_i}{v_i+v_{i+1}}
=\sqrt{\frac2g}\frac{\sqrt{(\Delta x)^2+(h_{i+1}-h_i)^2}}{\sqrt{h_i}+\sqrt{h_{i+1}}}
$$

と計算できる。
ここで $\Delta x=X/n$ は区間の横幅、$h_i$ は節点 $i$ の深さで、$h_0=0$、$h_n=H$ である。
始点の速さは零だが、隣の節点の深さが正なら分母は零にならない。
途中で始点より上へ戻る曲線は、静止からの運動では到達できない。
そこで内部節点を $h_i=\exp(q_i)$ と表して深さを正に保ち、端点を変数から除く。
変数は $q_1,\ldots,q_{n-1}$ の $n-1$ 個で、深さが終点の $H$ を超えることは許す。

深さ $a,b$ の区間について $d=\sqrt{(\Delta x)^2+(a-b)^2}$、$s=\sqrt a+\sqrt b$ と置くと、内部節点側の微分は

$$
\frac{\partial T_i}{\partial a}=\sqrt{\frac2g}
\left(\frac{a-b}{ds}-\frac{d}{2\sqrt a\,s^2}\right)
$$

である。
各節点は隣り合う二区間に現れるので、二つの寄与を足し、$\partial T/\partial q_i=h_i\,\partial T/\partial h_i$ を L-BFGS に渡す。
時間と勾配の一回の評価は $O(n)$ である。

L-BFGS は直近 $m$ 組の刻みと勾配の差から逆ヘッセ近似の作用を二重ループで作り、一反復に $O(mn)$ の演算と $O(mn)$ のメモリを使う。
`LbfgsOptions::default()` は $m=10$ と強 Wolfe 条件の直線探索を使う。
ここでは勾配の 2 ノルムの許容誤差を絶対値 $10^{-6}$（相対値 0）、反復の上限を 2000 回にする。
勾配の判定を満たして止まると、終了理由は `GradientSmall` になる。

## 解析解と精度改善

連続問題の解はサイクロイドで、$x=a(\theta-\sin\theta)$、$h=a(1-\cos\theta)$ と書ける。
終点の条件から $(\theta_1-\sin\theta_1)/(1-\cos\theta_1)=X/H$ で $\theta_1$ が決まり、$a=H/(1-\cos\theta_1)$ となる。
降下時間は $T_*=\theta_1\sqrt{a/g}$ である。
$X/H>\pi/2$ では $\theta_1>\pi$ となり、曲線は最深点 $h=2a$ まで終点より深く潜ってから上る。
比較の基準に使う直線の時間は、長さ $\ell=\sqrt{X^2+H^2}$ と加速度 $gH/\ell$ から $\sqrt{2\ell^2/(gH)}$ になる。

折線もサイクロイドと同じ端点を結ぶ曲線なので、どの折線の時間も $T_*$ 以上である。
差 $T_n-T_*$ は離散化誤差と最適化誤差の和であり、勾配が十分小さく止まっていれば主に離散化誤差である。
区間数を $n$ から $2n$ にしたときの差の比から、観測次数 $p=\log_2(e_n/e_{2n})$ を求める。
ここで $e_n=T_n-T_*$ である。

以下では $H=1\,\mathrm m$、$g=9.81\,\mathrm{m/s^2}$ を固定する。
入力は区間数 $n$ と終点の横位置 $X$ である。
出力は折線と解析曲線の図、区間数 $n$ と $2n$ の降下時間・厳密時間・差・反復回数・終了理由の表、観測次数の表、二つの求解の判定である。
サイクロイドの $\theta_1$ を求める二分法と三角関数は独立検算にだけ使い、f64 の固有メソッドで計算する。

```rust
//| id: optimize-brachistochrone
//| ref: optimize-brachistochrone
//| title: 折線の降下時間とサイクロイドを比較する
//| run: button
//| crates: [scioxide-core, scioxide-optimize]
//| inputs:
//|   segments: {"type":"range","label":"区間数 n [区間]","min":8,"max":32,"step":8,"value":16}
//|   endpoint: {"type":"range","label":"終点の横位置 X [m]","min":0.5,"max":3,"step":0.25,"value":2}
//| cases:
//|   - {"id":"fine","label":"区間数 32 と 64","description":"時間差は 2.35×10⁻³ s から 1.15×10⁻³ s に約半分になり、観測次数は 1.03 である。反復は 152 回から 384 回に増える。","inputs":{"segments":32}}
//|   - {"id":"short","label":"X = 0.5 m（急な斜面）","description":"θ₁ < π で終点より下へ潜らず、16 区間の時間差は 7.4×10⁻⁴ s と小さい。","inputs":{"endpoint":0.5}}
//|   - {"id":"long","label":"X = 3 m（終点より深く潜る）","description":"厳密時間は 1.0183 s で、曲線は終点より約 0.24 m 深く潜ってから上る。16 区間の時間差は 6.8×10⁻³ s。","inputs":{"endpoint":3}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"times","path":"/rows/0/2","approx":{"value":0.8055638295,"atol":1e-9}}
//|       - {"artifact":"times","path":"/rows/0/3","approx":{"value":4.881e-3,"atol":1e-5}}
//|       - {"artifact":"times","path":"/rows/1/3","approx":{"value":2.348e-3,"atol":1e-5}}
//|       - {"artifact":"times","path":"/rows/0/4","range":{"min":5,"max":2000}}
//|       - {"artifact":"times","path":"/rows/1/5","equals":"GradientSmall"}
//|       - {"artifact":"order","path":"/rows/0/2","approx":{"value":1.056,"atol":0.02}}
//|       - {"path":"/outputs/3/state","equals":"satisfied"}
//|   - case: fine
//|     expect:
//|       - {"artifact":"times","path":"/rows/1/3","approx":{"value":1.146e-3,"atol":1e-5}}
//|       - {"artifact":"order","path":"/rows/0/2","approx":{"value":1.035,"atol":0.02}}
//|       - {"path":"/outputs/3/state","equals":"satisfied"}
//|   - case: short
//|     expect:
//|       - {"artifact":"times","path":"/rows/0/2","approx":{"value":0.4907024394,"atol":1e-9}}
//|       - {"artifact":"times","path":"/rows/0/3","approx":{"value":7.39e-4,"atol":1e-5}}
//|   - case: long
//|     expect:
//|       - {"artifact":"times","path":"/rows/0/2","approx":{"value":1.0183129452,"atol":1e-9}}
//|       - {"artifact":"times","path":"/rows/0/3","approx":{"value":6.838e-3,"atol":1e-5}}
use scioxide_core::{Budget, GradientTolerance, RealScalar};
use scioxide_optimize::{Lbfgs, LbfgsOptions, ObjectiveFn};
// q は内部節点の深さの対数 qᵢ = ln hᵢ。端点の深さは 0 と H = 1 m に固定する。
// 降下時間 T = Σ √(2/g) dᵢ / (√hᵢ + √hᵢ₊₁) と、連鎖律で求めた ∂T/∂qᵢ = hᵢ ∂T/∂hᵢ を返す。
fn model(q: &[f64], width: f64) -> (f64, Vec<f64>) {
    let n = q.len() + 1;
    let mut h = vec![0.0];
    h.extend(q.iter().map(|&v| RealScalar::exp(v)));
    h.push(1.0);
    let mut gradient = vec![0.0; q.len()];
    let mut time = 0.0;
    let c = RealScalar::sqrt(2.0_f64 / 9.81);
    for i in 0..n {
        let (a, b) = (h[i], h[i + 1]);
        let d = RealScalar::sqrt((width / n as f64).powi(2) + (a - b).powi(2));
        let s = RealScalar::sqrt(a) + RealScalar::sqrt(b);
        time += c * d / s;
        if i > 0 {
            gradient[i - 1] +=
                a * c * ((a - b) / (d * s) - d / (2.0 * RealScalar::sqrt(a) * s * s));
        }
        if i + 1 < n {
            gradient[i] +=
                b * c * ((b - a) / (d * s) - d / (2.0 * RealScalar::sqrt(b) * s * s));
        }
    }
    (time, gradient)
}
// 独立検算: 終点条件 (θ − sin θ)/(1 − cos θ) = X/H から、
// サイクロイドの θ₁ と a を二分法で求める。参照値なので f64 の三角関数を使う。
let (mut lo, mut hi) = (1e-6_f64, 2.0 * std::f64::consts::PI - 1e-6);
for _ in 0..80 {
    let t = 0.5 * (lo + hi);
    if (t - t.sin()) / (1.0 - t.cos()) < endpoint {
        lo = t;
    } else {
        hi = t;
    }
}
let theta = 0.5 * (lo + hi);
let radius = 1.0 / (1.0 - theta.cos());
let exact_time = theta * (radius / 9.81).sqrt();
let reference: Vec<_> = (0..=100)
    .map(|i| {
        let t = theta * i as f64 / 100.0;
        [radius * (t - t.sin()), -radius * (1.0 - t.cos())]
    })
    .collect();
let mut series = vec![serde_json::json!({
    "name": "サイクロイド（解析解）",
    "points": reference,
    "style": {"lineType": "dashed"}
})];
let mut rows = Vec::new();
let mut all_success = true;
for n in [segments as usize, 2 * segments as usize] {
    let width = endpoint;
    let objective = ObjectiveFn::new(n - 1, move |q: &[f64]| Ok(model(q, width).0))
        .with_gradient(move |q: &[f64], g: &mut [f64]| {
            g.copy_from_slice(&model(q, width).1);
            Ok(())
        });
    // 開始点は始点と終点を結ぶ直線（hᵢ = i/n）。
    let start: Vec<_> = (1..n)
        .map(|i| RealScalar::ln(i as f64 / n as f64))
        .collect();
    let options = LbfgsOptions::default()
        .with_gradient_tolerance(GradientTolerance::new(1e-6, 0.0).map_err(|e| e.to_string())?)
        .with_max_iterations(Budget::try_from(2000_usize).map_err(|e| e.to_string())?);
    let result = Lbfgs::new(options)
        .minimize(&objective, &start)
        .map_err(|e| e.to_string())?;
    all_success &= result.is_success();
    let mut points = vec![[0.0, 0.0]];
    points.extend(
        result
            .x()
            .iter()
            .enumerate()
            .map(|(i, &q)| [width * (i + 1) as f64 / n as f64, -RealScalar::exp(q)]),
    );
    points.push([width, -1.0]);
    series.push(serde_json::json!({"name": format!("{n} 区間"), "points": points}));
    rows.push((
        n,
        result.fun(),
        exact_time,
        result.fun() - exact_time,
        result.iterations(),
        result.termination().to_string(),
    ));
}
// 区間数を 2 倍にしたときの差の比から、離散化誤差の観測次数 p = log₂(eₙ/e₂ₙ) を求める。
let order = RealScalar::log2(rows[0].3 / rows[1].3);
emit_line_chart!(
    &series,
    options = &serde_json::json!({
        "xLabel": "横位置 x [m]",
        "yLabel": "高さ y [m]",
        "annotations": [{"kind": "line", "axis": "y", "value": -1.0, "label": "終点の高さ"}]
    })
);
let fixed5 = serde_json::json!({ "fractionDigits": 5 });
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let time_columns = serde_json::json!([
    { "key": "0", "label": "区間数 n [区間]", "type": "integer" },
    { "key": "1", "label": "降下時間 Tₙ [s]", "type": "number", "format": fixed5 },
    { "key": "2", "label": "厳密時間 T* [s]", "type": "number", "format": fixed5 },
    { "key": "3", "label": "差 Tₙ − T* [s]", "type": "number", "format": sci3 },
    { "key": "4", "label": "反復 [回]", "type": "integer" },
    { "key": "5", "label": "終了理由" }
]);
emit_table_with_columns!(
    time_columns,
    rows.clone(),
    metadata = serde_json::json!({ "id": "times" })
);
let order_columns = serde_json::json!([
    { "key": "0", "label": "粗い区間数 n [区間]", "type": "integer" },
    { "key": "1", "label": "細かい区間数 2n [区間]", "type": "integer" },
    { "key": "2", "label": "観測次数 p [-]", "type": "number", "format": { "fractionDigits": 3 } }
]);
emit_table_with_columns!(
    order_columns,
    vec![(rows[0].0, rows[1].0, order)],
    metadata = serde_json::json!({ "id": "order" })
);
let outcome = if all_success {
    Outcome::satisfied("二つの折線とも勾配の判定を満たした")
} else {
    Outcome::partial("勾配の判定を満たす前に止まった折線がある")
        .explanation("差には最適化誤差が混ざるので、観測次数を離散化誤差として読まない。")
};
emit_outcome!(
    outcome
        .status(format!("{} / {}", rows[0].5, rows[1].5))
        .diagnostic("観測次数", order, None)
        .diagnostic("細かい折線の時間差", rows[1].3, Some("s"))
);
```

既定の $X=2\,\mathrm m$ では $\theta_1=3.508>\pi$ で、曲線は終点より 0.034 m 深く潜る。
16 区間の時間は 0.81044 s、32 区間は 0.80791 s で、厳密時間 0.80556 s との差は $4.88\times10^{-3}$ s から $2.35\times10^{-3}$ s へ約半分になる。
直線で降りる時間 1.0096 s と比べると、16 区間の折線でも厳密時間との差は直線の差の 2% 程度に縮まる。
観測次数は 1.06 で、32 区間と 64 区間の組でも 1.03 なので、この格子での離散化誤差は区間数にほぼ反比例する。
始点の近くではサイクロイドが $h\propto x^{2/3}$ と鉛直に立ち上がり、横座標の等間隔格子ではこの部分を粗くしか表せないことと整合する。
既定とどのケースでも終了理由は `GradientSmall` で、$X=2\,\mathrm m$ の反復回数は区間数 16、32、64 で 44 回、152 回、384 回と増える。

$X=0.5\,\mathrm m$ では $\theta_1<\pi$ で曲線は潜らず、16 区間の差は $7.4\times10^{-4}$ s と小さい。
$X=3\,\mathrm m$ では曲線は終点より約 0.24 m 深く潜り、16 区間の差は $6.8\times10^{-3}$ s になる。
反復が上限で止まれば最適化誤差が混ざるため、判定が `partial` のときは差と観測次数を離散化誤差として読まない。

## まとめ

降下時間は斜面の長さだけでなく途中で得る速さにも依存し、直線区間の時間は両端の速さの平均から厳密に計算できる。
深さを $h=\exp(q)$ と表すと始点より上へ戻る曲線を除けるので、区間の時間の勾配を連鎖律で求めて L-BFGS に渡せる。
解析曲線との差は離散化誤差と最適化誤差の和であり、終了理由が `GradientSmall` のときに限って離散化誤差として読める。
区間数を倍にしたときの観測次数がほぼ 1 なので、この等間隔格子では区間数を増やすより、始点の近くに節点を寄せるほうが離散化誤差を減らせる可能性がある。
