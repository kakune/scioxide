同じ高さの二つの支点の間に、長さ $L$ の一様な鎖をつるす。
鎖は伸び縮みせず曲げに抵抗しないとし、位置エネルギーが最小になる形を求める。
支点間隔を $D$、線密度を $\rho$、重力加速度を $g$ とする。
長さを $D$、エネルギーを $\rho gD^2$、張力を $\rho gD$ で割った無次元量を使うと、支点間隔、線密度、重力加速度はどれも 1 になる。
以下の座標、長さ、張力はすべてこの無次元量で、残る入力は比 $L/D$ だけである。
$L>D$ が必要であり、$L=D$ では鎖が張り切った特異な極限になる。

## 連続体の釣り合い

鎖の一部を切り出すと、両端の張力と重さが釣り合う。
張力を水平成分 $H$ と鉛直成分 $V$ に分けると、水平方向には外力がないので $H$ は鎖のどこでも一定である。
鉛直成分は弧長 $s$ あたりの重さ 1 だけ増え、$dV/ds=1$ となる。
$V=Hy'$ と $ds=\sqrt{1+y'^2}\,dx$ を使うと

$$
y''=\frac1H\sqrt{1+y'^2}
$$

を得る。
$a=H$ と置くと、支点を $(0,0)$ と $(1,0)$ に置いた対称な解は $y=a\cosh((x-1/2)/a)-a\cosh(1/(2a))$ である。
これは懸垂線 $y=a\cosh(x/a)+c$ を $x=1/2$ が最下点になるように平行移動し、定数 $c$ を両端の高さが 0 になるように選んだものである。
弧長の条件 $L=2a\sinh(1/(2a))$ から $a$ が一つに決まり、各位置の張力は $T=H\sqrt{1+y'^2}=a\cosh((x-1/2)/a)$ となる。
$L\to1$ では $a\to\infty$ で鎖は張り切り、$L$ を長くするほど $a$、すなわち水平張力は小さくなる。

## 離散モデルと張力

鎖を $n$ 個の長さ $\ell=L/n$ の直線区間に分け、端点を固定する。
各区間の質量 $\ell$ を中点に置くと、内部節点 $i$ は隣り合う二区間から半分ずつ受け持つので、位置エネルギーは $U=\ell\sum_{i=1}^{n-1}y_i$ になる。
内部節点の $x_i,y_i$ の $2(n-1)$ 個を変数とし、各区間に $c_i=\|r_{i+1}-r_i\|-\ell=0$ の $n$ 本の等式制約を課す。
ここで $r_i=(x_i,y_i)$ は節点 $i$ の位置である。
変数の数が制約の数以上であるためには $n\ge2$ が要り、ここでは $n\ge4$ を使う。

ラグランジュ関数を $\mathcal L=U+\sum_i\lambda_i c_i$ とする。
区間の長さの勾配は接線の単位ベクトル $t_i=(r_{i+1}-r_i)/\|r_{i+1}-r_i\|$ なので、内部節点 $k$ の停留条件 $\nabla_{r_k}\mathcal L=0$ は

$$
\lambda_k t_k-\lambda_{k-1}t_{k-1}=(0,\ell)
$$

になる。
これは節点 $k$ に区間の張力 $T_k$ が接線方向に掛かり、重さ $\ell$ と釣り合う式 $T_kt_k-T_{k-1}t_{k-1}=(0,\ell)$ と同じ形である。
したがって乗数 $\lambda_i$ はこの無次元の単位で区間の張力 $T_i$ に等しい。
`SqpState::multipliers` は $\nabla\mathcal L=\nabla U+\sum_i\lambda_i\nabla c_i$ の向きで乗数を返すので、張力は正の値として読める。
長さの二乗を制約に使う場合は $\nabla c_i$ が $2\|r_{i+1}-r_i\|$ 倍になるため、乗数をそのまま張力と読んではいけない。

この式の水平成分から、離散モデルでも $\lambda_kt_{k,x}$ は区間によらず一定になる。
離散鎖の水平張力は連続解の $a$ に近いが、曲線を直線の区間でつなぎ、重さを節点に集めたモデルなので一致はしない。

## SQP の反復と計算コスト

SQP は各反復で、ラグランジュ関数のヘッセ行列を減衰付き BFGS で近似した二次モデルと、制約の一次近似からなる二次計画の部分問題を解き、刻みと乗数を更新する。
刻みは $\ell_1$ メリット関数 $U+\nu\sum_i|c_i|$ の Armijo 型の後退で受理し、ペナルティ係数 $\nu$ は乗数の絶対値より 1 以上大きく保つ（線密度の $\rho$ とは別の記号である）。
制約は全て等式なので、部分問題は KKT 系の解になる。
変数 $2(n-1)$ 個、制約 $n$ 本の密な系なので、一反復の線形代数は $O(n^3)$ である。
SQP の受理の条件と乗数の扱いは [逐次二次計画法](oxref:optimize-sqp-method)で詳しく述べる。

## 連続解との比較

独立検算では弧長の条件を二分法で解いた $a$ と、連続解の張力と形を使う。
差は離散化と求解の両方に依存するが、制約違反と停留性が十分小さければ、残りは主に離散化の差である。

入力は鎖の長さ $L/D$ と区間数 $n$ である。
出力は形状の図、区間ごとの長さの違反・張力・水平張力の表、終了理由と診断・連続解との差の表、求解の判定である。
SQP の開始点には連続解の上で等間隔の横位置を取った点を使う。
その節点間の距離は等しくないので、離散制約は SQP が改めて満たす。

```rust
//| id: optimize-catenary-sqp
//| ref: optimize-catenary-sqp
//| title: 鎖の形と SQP の乗数を懸垂線で検算する
//| run: button
//| crates: [scioxide-core, scioxide-optimize]
//| inputs:
//|   length: {"type":"range","label":"鎖の長さ L/D [-]","min":1.1,"max":2,"step":0.1,"value":1.5}
//|   segments: {"type":"range","label":"区間数 n [区間]","min":4,"max":16,"step":4,"value":8}
//| cases:
//|   - {"id":"refined","label":"区間数 16","description":"区間数を 2 倍にすると、水平張力と a の差は −8.9×10⁻⁴ から −2.3×10⁻⁴ に、高さの最大差は 5.3×10⁻³ から 1.3×10⁻³ に約 1/4 ずつ減る。","inputs":{"segments":16}}
//|   - {"id":"taut","label":"L/D = 1.1（張った鎖）","description":"a = 0.655 と水平張力が大きくなり、区間 8 個では水平張力と a の差は −3.8×10⁻³ になる。","inputs":{"length":1.1}}
//|   - {"id":"slack","label":"L/D = 2（たるんだ鎖）","description":"a = 0.230 まで水平張力が下がり、端の区間の張力は 0.905 になる。","inputs":{"length":2}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"segments","path":"/rows/0/1","range":{"min":0,"max":1e-9}}
//|       - {"artifact":"segments","path":"/rows/0/2","approx":{"value":0.724655,"atol":1e-5}}
//|       - {"artifact":"segments","path":"/rows/3/2","approx":{"value":0.321326,"atol":1e-5}}
//|       - {"artifact":"segments","path":"/rows/0/3","approx":{"value":0.307345,"atol":1e-5}}
//|       - {"artifact":"segments","path":"/rows/0/4","approx":{"value":-8.91e-4,"atol":1e-5}}
//|       - {"artifact":"summary","path":"/rows/0/0","equals":"Converged"}
//|       - {"artifact":"summary","path":"/rows/0/4","approx":{"value":0.308236,"atol":1e-5}}
//|       - {"artifact":"summary","path":"/rows/0/5","approx":{"value":5.25e-3,"atol":5e-5}}
//|       - {"path":"/outputs/3/state","equals":"satisfied"}
//|   - case: refined
//|     expect:
//|       - {"artifact":"segments","path":"/rows/0/4","approx":{"value":-2.27e-4,"atol":5e-6}}
//|       - {"artifact":"summary","path":"/rows/0/5","approx":{"value":1.27e-3,"atol":2e-5}}
//|   - case: taut
//|     expect:
//|       - {"artifact":"segments","path":"/rows/0/4","approx":{"value":-3.77e-3,"atol":5e-5}}
//|       - {"artifact":"summary","path":"/rows/0/4","approx":{"value":0.65496,"atol":1e-4}}
//|   - case: slack
//|     expect:
//|       - {"artifact":"segments","path":"/rows/0/2","approx":{"value":0.90467,"atol":1e-4}}
//|       - {"artifact":"summary","path":"/rows/0/4","approx":{"value":0.22964,"atol":1e-4}}
//|       - {"path":"/outputs/3/state","equals":"satisfied"}
use scioxide_core::{Budget, ExecutionContext, RealScalar};
use scioxide_optimize::{
    ConstrainedProblem, ConstraintFn, Constraints, ObjectiveFn, OptimizeResult, Sqp, SqpOptions,
};
// 節点 i の座標。端点 (0, 0) と (1, 0) は固定し、内部節点だけを変数にする。
fn point(q: &[f64], i: usize, n: usize) -> [f64; 2] {
    if i == 0 {
        [0.0, 0.0]
    } else if i == n {
        [1.0, 0.0]
    } else {
        [q[2 * (i - 1)], q[2 * (i - 1) + 1]]
    }
}
let n = segments as usize;
let ell = length / n as f64;
let dim = 2 * (n - 1);
// U = ℓ Σ yᵢ（各区間の質量 ℓ を中点に置き、内部節点が半分ずつ受け持つ）。
let objective = ObjectiveFn::new(dim, move |q: &[f64]| {
    Ok(ell * q.chunks_exact(2).map(|p| p[1]).sum::<f64>())
})
.with_gradient(move |_: &[f64], g: &mut [f64]| {
    for (i, gi) in g.iter_mut().enumerate() {
        *gi = if i % 2 == 1 { ell } else { 0.0 };
    }
    Ok(())
});
// cᵢ = ‖rᵢ₊₁ − rᵢ‖ − ℓ。勾配は接線の単位ベクトルなので、乗数が張力になる。
let mut constraints = Constraints::new(dim).map_err(|e| e.to_string())?;
for edge in 0..n {
    let constraint = ConstraintFn::new(dim, move |q: &[f64]| {
        let (a, b) = (point(q, edge, n), point(q, edge + 1, n));
        Ok(RealScalar::hypot(b[0] - a[0], b[1] - a[1]) - ell)
    })
    .with_jacobian(move |q: &[f64], row: &mut [f64]| {
        let (a, b) = (point(q, edge, n), point(q, edge + 1, n));
        let d = RealScalar::hypot(b[0] - a[0], b[1] - a[1]);
        row.fill(0.0);
        for k in 0..2 {
            if edge > 0 {
                row[2 * (edge - 1) + k] = (a[k] - b[k]) / d;
            }
            if edge + 1 < n {
                row[2 * edge + k] = (b[k] - a[k]) / d;
            }
        }
        Ok(())
    });
    constraints = constraints
        .equality(constraint)
        .map_err(|e| e.to_string())?;
}
// 独立検算: 連続解の弧長の条件 L = 2a sinh(1/(2a)) を二分法で解く。
let (mut lo, mut hi) = (0.01_f64, 10.0_f64);
for _ in 0..80 {
    let a = (lo + hi) / 2.0;
    if 2.0 * a * RealScalar::sinh(0.5 / a) > length {
        lo = a;
    } else {
        hi = a;
    }
}
let a = (lo + hi) / 2.0;
let exact = |x: f64| a * (RealScalar::cosh((x - 0.5) / a) - RealScalar::cosh(0.5 / a));
// 開始点は連続解の上の等間隔の横位置。節点間の距離は等しくない。
let start: Vec<_> = (1..n)
    .flat_map(|i| {
        let x = i as f64 / n as f64;
        [x, exact(x)]
    })
    .collect();
let problem = ConstrainedProblem::new(&objective, &constraints).map_err(|e| e.to_string())?;
let solver = Sqp::new(
    SqpOptions::default()
        .with_max_iterations(Budget::try_from(500_usize).map_err(|e| e.to_string())?),
);
let mut work = solver.workspace(&problem).map_err(|e| e.to_string())?;
let mut result = OptimizeResult::empty();
solver
    .minimize_into(
        &problem,
        &start,
        &mut result,
        &mut work,
        ExecutionContext::sequential(),
    )
    .map_err(|e| e.to_string())?;
let points: Vec<_> = (0..=n).map(|i| point(result.x(), i, n)).collect();
let reference: Vec<_> = (0..=100)
    .map(|i| {
        let x = i as f64 / 100.0;
        [x, exact(x)]
    })
    .collect();
emit_line_chart!(
    &vec![
        serde_json::json!({"name": "離散鎖（SQP）", "points": points}),
        serde_json::json!({
            "name": "懸垂線（連続解）",
            "points": reference,
            "style": {"lineType": "dashed"}
        })
    ],
    options = &serde_json::json!({"xLabel": "横位置 x/D [-]", "yLabel": "高さ y/D [-]"})
);
// 乗数は等式制約の順（区間 0, 1, …）に並ぶ。水平張力は λᵢ と接線の x 成分の積。
let rows: Vec<_> = points
    .windows(2)
    .enumerate()
    .map(|(i, p)| {
        let distance = RealScalar::hypot(p[1][0] - p[0][0], p[1][1] - p[0][1]);
        let tension = work.state().multipliers()[i];
        let horizontal = tension * (p[1][0] - p[0][0]) / distance;
        (i, (distance - ell).abs(), tension, horizontal, horizontal - a)
    })
    .collect();
let fixed6 = serde_json::json!({ "fractionDigits": 6 });
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let segment_columns = serde_json::json!([
    { "key": "0", "label": "区間 i", "type": "integer" },
    { "key": "1", "label": "長さの違反 |cᵢ| [-]", "type": "number", "format": sci2 },
    { "key": "2", "label": "張力 λᵢ = T/(ρgD) [-]", "type": "number", "format": fixed6 },
    { "key": "3", "label": "水平張力 H/(ρgD) [-]", "type": "number", "format": fixed6 },
    { "key": "4", "label": "水平張力と a の差 [-]", "type": "number", "format": sci3 }
]);
emit_table_with_columns!(
    segment_columns,
    rows,
    metadata = serde_json::json!({ "id": "segments" })
);
let shape_error = points
    .iter()
    .map(|p| (p[1] - exact(p[0])).abs())
    .fold(0.0_f64, f64::max);
let summary_columns = serde_json::json!([
    { "key": "0", "label": "終了理由" },
    { "key": "1", "label": "反復 [回]", "type": "integer" },
    { "key": "2", "label": "主実行可能性 [-]", "type": "number", "format": sci2, "nullText": "未計算" },
    { "key": "3", "label": "停留性 [-]", "type": "number", "format": sci2, "nullText": "未計算" },
    { "key": "4", "label": "連続解の a [-]", "type": "number", "format": fixed6 },
    { "key": "5", "label": "高さの最大差 [-]", "type": "number", "format": sci3 }
]);
emit_table_with_columns!(
    summary_columns,
    vec![(
        result.termination().to_string(),
        result.iterations(),
        result.primal_feasibility(),
        result.stationarity(),
        a,
        shape_error
    )],
    metadata = serde_json::json!({ "id": "summary" })
);
let outcome = if result.is_success() {
    Outcome::satisfied("SQP の停止判定を満たし、乗数を張力として読める")
} else {
    Outcome::partial("SQP が停止判定を満たす前に止まった")
        .explanation("制約違反と停留性が小さくない限り、乗数を張力として読まない。")
};
let mut outcome = outcome
    .status(result.termination().to_string())
    .diagnostic("反復回数", result.iterations() as f64, None)
    .diagnostic("高さの最大差", shape_error, None);
if let Some(stationarity) = result.stationarity() {
    outcome = outcome.diagnostic("停留性", stationarity, None);
}
emit_outcome!(outcome);
```

既定の $L/D=1.5$、区間数 8 では、終了理由は `Converged` で、区間の長さの違反は $10^{-13}$ 以下、停留性は $1.2\times10^{-8}$ である。
乗数から読んだ張力は端の区間で 0.7247、中央の区間で 0.3213 で、鎖が低いところほど張力が小さい。
水平張力は全ての区間で 0.30735 にそろい、連続解の $a=0.30824$ との差は $-8.9\times10^{-4}$ である。
区間数を 16 にすると、この差は $-2.3\times10^{-4}$、高さの最大差は $5.3\times10^{-3}$ から $1.3\times10^{-3}$ に減る。
区間数を 2 倍にして差が約 1/4 になるので、離散化の差は $O(n^{-2})$ で減っていると読める。
ただし区間数 4 の水平張力の差 $-8.1\times10^{-4}$ は区間数 8 とほぼ同じで、少ない区間数ではこの減り方はまだ見えない。

$L/D=1.1$ では $a=0.655$ と水平張力が大きく、$L/D=2$ では $a=0.230$ まで下がり、端の区間の張力は 0.905 になる。
長さの違反が小さくても高さの差が残る場合は、区間数を増やして離散化の影響を調べる。

## まとめ

鎖の形は位置エネルギーと長さ制約から定まり、連続解は懸垂線 $y=a\cosh((x-1/2)/a)+\text{const}$ になる。
制約を長さそのもので書くと、SQP の乗数は区間の張力に等しく、長さの二乗で書くと係数が変わる。
無次元化すると張力の単位は $\rho gD$ で、実際の鎖の張力はこの値に線密度、重力加速度、支点間隔を掛けて戻す。
制約違反、停留性、水平張力の一定性、連続解との差を分けて読み、区間数を倍にしたときの差の減り方から離散化誤差を見積もる。
