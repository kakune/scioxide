期待収益を高くすることと、収益の分散を小さくすることは一般に競合する。
$n$ 資産への配分を $w_i\ge0$、$\sum_iw_i=1$ とし、期待収益 $\mu^\mathsf Tw$、分散 $w^\mathsf T\Sigma w$ を使って、この交換条件を図にする。
同じ期待収益で分散が最小の配分を全ての収益について集めた曲線を最小分散集合と呼び、そのうち最小分散点より収益の高い枝を効率的フロンティア（efficient frontier）と呼ぶ。
例題の資産は期待収益 $\mu=(0.03,0.07,0.11)$、標準偏差 $\sigma=(0.08,0.14,0.20)$ を持ち、全ての組に共通の相関 $\rho$ を置く。
これらは説明用の仮想値で、収益率は 1 年あたりの値を小数で表した年率（0.03 は年 3%）、標準偏差も同じ年率の単位で表す。

共通相関の共分散行列は $\Sigma_{ij}=\sigma_i\sigma_j(\rho+(1-\rho)\delta_{ij})$ である。
相関行列の固有値は $1-\rho$ と $1+(n-1)\rho$ なので、$\Sigma$ が半正定値であるためには $\rho\ge-1/(n-1)$ が要る。
三資産では $\rho\ge-0.5$ で、入力の範囲 $[-0.4,0.8]$ はこれを満たす。
分散は $w$ の凸二次関数で、実行可能集合は単体と収益の等式の交わりなので、収益を固定した問題は凸二次計画になる。

## 収益を固定した二次計画

QP では目標収益 $R$ に対して、$\sum_iw_i=1$、$\mu^\mathsf Tw=R$、$0\le w_i\le1$ のもとで分散を最小化する。
$Q=2\Sigma$ とすれば、SciOxide の $\tfrac12w^\mathsf TQw$ が分散になる。
$R$ を最小の収益 0.03 から最大の収益 $0.03+0.04(n-1)$ まで 31 点で動かし、各点で `QpSolver` を呼ぶ。

同じ交換条件を二目的の最小化として扱い、多目的進化計算で前線を近似する方法は[NSGA-II による効率的フロンティアの近似](../efficient-frontier-nsga2/)で扱う。
そのページでも、ここで導く閉形式を前線の基準に使う。

## 制約を消去した検算

二資産で収益を固定すると、$w_2=(R-0.03)/0.04$ から配分は一意に決まる。
三資産では二つの等式を消去すると一変数が残る。
$\beta=(R-0.03)/0.04$ と置くと、基準の配分 $b=(1-\beta,\beta,0)$ と方向 $d=(1,-2,1)$ は和と収益の等式を満たし、$w=b+td$ と書ける。
$d$ の成分の和は 0、$\mu^\mathsf Td=0.03-0.14+0.11=0$ なので、$t$ を動かしても二つの等式は崩れない。
このとき $t$ はそのまま第 3 の資産の重み $w_3$ になる。

分散は $b^\mathsf T\Sigma b+2t\,d^\mathsf T\Sigma b+t^2d^\mathsf T\Sigma d$ となり、頂点は $t_*=-d^\mathsf T\Sigma b/(d^\mathsf T\Sigma d)$ にある。
$t_*$ を非負配分の許す区間 $\max(0,\beta-1)\le t\le\beta/2$ へ射影すれば、空売りを許さない場合の最小点になる。
一変数の凸二次関数なので、区間への射影が区間上の最小点である。
この計算は QP の KKT 系を解き直さない独立検算である。

射影しない $t_*$ は重みの負を許す（空売りを許す）場合の最小点である。
このときの最小分散は Markowitz の閉形式

$$
\sigma^2(R)=\frac{AR^2-2BR+C}{AC-B^2},\qquad
A=\mathbf 1^\mathsf T\Sigma^{-1}\mathbf 1,\quad B=\mathbf 1^\mathsf T\Sigma^{-1}\mu,\quad C=\mu^\mathsf T\Sigma^{-1}\mu
$$

に等しく、三資産では二つの等式を消去した一変数の頂点として同じ値を得る。
空売りを許す曲線の分散は非負の制約がない分だけ小さいか等しく、二つの曲線が一致する収益では非負の制約が効いていない。

次の定義は共分散行列・分散・二つの閉形式を Rust の項目にまとめる。
`minimum_variance` は収益 $R$ での最小分散で、`long_only` が真なら $t_*$ を区間へ射影する。

```rust
//| id: optimize-efficient-frontier-model
//| kind: definitions
//| title: 平均分散モデルと等式を消去した閉形式
//| crates: [scioxide-core]
pub(crate) struct Portfolio {
    pub(crate) n: usize,
    pub(crate) covariance: Vec<f64>,
}
impl Portfolio {
    // 標準偏差 (0.08, 0.14, 0.20) と共通相関 ρ から Σᵢⱼ = σᵢσⱼ(ρ + (1 − ρ)δᵢⱼ) を作る。
    pub(crate) fn new(n: usize, correlation: f64) -> Self {
        let sd = [0.08, 0.14, 0.20];
        let covariance = (0..n)
            .flat_map(|i| {
                (0..n).map(move |j| sd[i] * sd[j] * if i == j { 1.0 } else { correlation })
            })
            .collect();
        Self { n, covariance }
    }
    pub(crate) fn variance(&self, w: &[f64]) -> f64 {
        (0..self.n)
            .map(|i| {
                (0..self.n)
                    .map(|j| w[i] * self.covariance[i * self.n + j] * w[j])
                    .sum::<f64>()
            })
            .sum()
    }
    // 独立検算: 等式を消去した一変数の二次式を最小化する。
    // 三資産は w = b + t d、b = (1 − β, β, 0)、d = (1, −2, 1) で、t は第 3 の重み。
    // long_only なら頂点 t* を max(0, β − 1) ≤ t ≤ β/2 へ射影し、偽なら空売りを許す。
    pub(crate) fn minimum_variance(&self, r: f64, long_only: bool) -> f64 {
        let b = (r - 0.03) / 0.04;
        if self.n == 2 {
            return self.variance(&[1.0 - b, b]);
        }
        let base = [1.0 - b, b, 0.0];
        let direction = [1.0, -2.0, 1.0];
        let linear: f64 = (0..3)
            .map(|i| {
                (0..3)
                    .map(|j| direction[i] * self.covariance[i * 3 + j] * base[j])
                    .sum::<f64>()
            })
            .sum();
        let vertex = -linear / self.variance(&direction);
        let t = if long_only {
            vertex.clamp((b - 1.0).max(0.0), b / 2.0)
        } else {
            vertex
        };
        let w: Vec<_> = (0..3).map(|i| base[i] + t * direction[i]).collect();
        self.variance(&w)
    }
}
```

## QP による最小分散集合

次のセルは 31 個の目標収益で QP を解き、等式を消去した閉形式と比べる。
入力は資産数と共通相関、出力は最小分散集合の図、収益ごとの最小分散と閉形式との差の表、QP の判定である。
図の横軸は標準偏差 $\sqrt{w^\mathsf T\Sigma w}$、縦軸は期待収益で、最小分散点より下の枝は同じ分散でより高い収益を持つ点に支配される。

```rust
//| id: optimize-efficient-frontier
//| ref: optimize-efficient-frontier
//| title: QP の最小分散集合を閉形式と比べる
//| run: reactive
//| uses: [optimize-efficient-frontier-model]
//| crates: [scioxide-core, scioxide-linalg, scioxide-optimize]
//| inputs:
//|   assets: {"type":"range","label":"資産数 n [資産]","min":2,"max":3,"step":1,"value":3}
//|   correlation: {"type":"range","label":"共通相関 ρ [-]","min":-0.4,"max":0.8,"step":0.1,"value":0.2}
//| cases:
//|   - {"id":"two-assets","label":"二資産","description":"収益を決めると配分が一つに決まるので、QP、閉形式、空売りを許す曲線が一致する。","inputs":{"assets":2}}
//|   - {"id":"negative-correlation","label":"共通相関 −0.4","description":"分散の打ち消しで、31 点のうち分散が最小の点は収益 0.0567、標準偏差 0.031 に移る。","inputs":{"correlation":-0.4}}
//|   - {"id":"high-correlation","label":"共通相関 0.8","description":"空売りを許さない最小分散点は資産 1 だけの配分（収益 0.03、標準偏差 0.08）になり、空売りを許す曲線はそれより低い。","inputs":{"correlation":0.8}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"frontier","path":"/rows/4/1","approx":{"value":0.0054989675,"atol":1e-9}}
//|       - {"artifact":"frontier","path":"/rows/4/2","range":{"min":-1e-12,"max":1e-12}}
//|       - {"artifact":"frontier","path":"/rows/30/1","approx":{"value":0.04,"atol":1e-9}}
//|       - {"artifact":"frontier","path":"/rows/15/4","equals":"Converged"}
//|       - {"path":"/outputs/2/state","equals":"satisfied"}
//|   - case: two-assets
//|     expect:
//|       - {"artifact":"frontier","path":"/rows/30/1","approx":{"value":0.0196,"atol":1e-9}}
//|       - {"artifact":"frontier","path":"/rows/30/3","approx":{"value":0.0196,"atol":1e-9}}
//|   - case: negative-correlation
//|     expect:
//|       - {"artifact":"frontier","path":"/rows/10/1","approx":{"value":0.00096957265,"atol":1e-10}}
//|   - case: high-correlation
//|     expect:
//|       - {"artifact":"frontier","path":"/rows/0/1","approx":{"value":0.0064,"atol":1e-12}}
//|       - {"artifact":"frontier","path":"/rows/1/1","range":{"min":0.0064}}
//|       - {"artifact":"frontier","path":"/rows/0/3","range":{"max":0.0064}}
use scioxide_core::{Bounds, RealScalar};
use scioxide_linalg::Matrix;
use scioxide_optimize::{LinearConstraintSense, LinearConstraints, QpProblem, QpSolver};
let n = assets as usize;
let model = Portfolio::new(n, correlation);
let q = Matrix::from_vec(n, n, model.covariance.iter().map(|v| 2.0 * v).collect())
    .map_err(|e| e.to_string())?;
let mut rows = Vec::new();
let mut frontier = Vec::new();
let mut exact = Vec::new();
let mut short = Vec::new();
let mut all_success = true;
for k in 0..=30 {
    let r = 0.03 + 0.04 * (n - 1) as f64 * k as f64 / 30.0;
    // 等式の行: Σwᵢ = 1 と μᵀw = R。
    let mut a = vec![1.0; n];
    a.extend((0..n).map(|i| 0.03 + 0.04 * i as f64));
    let c = LinearConstraints::new(
        Matrix::from_vec(2, n, a).map_err(|e| e.to_string())?,
        vec![1.0, r],
        vec![LinearConstraintSense::Equal; 2],
    )
    .map_err(|e| e.to_string())?;
    let problem = QpProblem::new(q.clone(), vec![0.0; n])
        .and_then(|p| p.with_constraints(c))
        .and_then(|p| p.with_bounds(Bounds::new(vec![(Some(0.0), Some(1.0)); n])?))
        .map_err(|e| e.to_string())?;
    let result = QpSolver::default()
        .solve(&problem)
        .map_err(|e| e.to_string())?;
    all_success &= result.is_success();
    // 独立検算: 二つの等式を消去し、残る一変数の二次式を最小化する。
    let exact_variance = model.minimum_variance(r, true);
    let short_variance = model.minimum_variance(r, false);
    let variance = model.variance(result.x());
    frontier.push([RealScalar::sqrt(variance), r]);
    exact.push([RealScalar::sqrt(exact_variance), r]);
    short.push([RealScalar::sqrt(short_variance), r]);
    rows.push((
        r,
        variance,
        variance - exact_variance,
        short_variance,
        result.termination().to_string(),
    ));
}
let minimum = frontier
    .iter()
    .copied()
    .min_by(|a, b| a[0].total_cmp(&b[0]))
    .ok_or("前線が空")?;
let line = |id: &str, name: &str, points: &Vec<[f64; 2]>, style: serde_json::Value| {
    serde_json::json!({ "id": id, "kind": "line", "name": name, "points": points, "style": style })
};
emit_chart!(serde_json::json!({
    "kind": "xy",
    "xLabel": "収益の標準偏差 [年率]",
    "yLabel": "期待収益 [年率]",
    "xMin": 0,
    "xMax": 0.22,
    "yMin": 0.02,
    "yMax": 0.12,
    "dataZoom": true,
    "tooltip": true,
    "annotations": [
        { "kind": "line", "axis": "y", "value": minimum[1], "label": "最小分散点の収益" }
    ],
    "layers": [
        line("qp", "QP", &frontier, serde_json::json!({ "showSymbol": true })),
        line("long-only", "閉形式（空売りなし）", &exact, serde_json::json!({ "lineType": "dashed" })),
        line("short", "閉形式（空売りあり）", &short, serde_json::json!({ "lineType": "dotted" }))
    ]
}));
let fixed4 = serde_json::json!({ "fractionDigits": 4 });
let sig6 = serde_json::json!({ "significantDigits": 6 });
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let columns = serde_json::json!([
    { "key": "0", "label": "期待収益 R [年率]", "type": "number", "format": fixed4 },
    { "key": "1", "label": "QP の最小分散 [年率²]", "type": "number", "format": sig6 },
    { "key": "2", "label": "閉形式との差 [年率²]", "type": "number", "format": sci2 },
    { "key": "3", "label": "空売りありの最小分散 [年率²]", "type": "number", "format": sig6 },
    { "key": "4", "label": "QP 終了理由" }
]);
let max_difference = rows.iter().map(|r| r.2.abs()).fold(0.0_f64, f64::max);
emit_table_with_columns!(columns, rows, metadata = serde_json::json!({ "id": "frontier" }));
let outcome = if all_success {
    Outcome::satisfied("31 個の QP がすべて停止判定を満たした")
} else {
    Outcome::partial("停止判定を満たさなかった QP がある")
        .explanation("表の終了理由を見て、その収益の分散を推定値として扱う。")
};
emit_outcome!(
    outcome
        .status(if all_success { "Converged" } else { "一部未収束" })
        .diagnostic("閉形式との最大差", max_difference, None)
        .diagnostic("最小分散点の標準偏差", minimum[0], None)
);
```

既定の三資産、$\rho=0.2$ では、31 点のうち分散が最小の点は収益 0.0407、分散 0.005499（標準偏差 0.0742）にあり、31 点の QP と閉形式の差は $10^{-17}$ 程度である。
閉形式を細かい収益の刻みで最小化すると、最小分散点は収益 0.0412、分散 0.005498 にあり、格子の点とは収益で 0.0005 ずれる。
空売りを許す曲線は収益の両端の近くで空売りなしの曲線より左にあり、そこでは非負の制約が最小点を決めている。
収益がおよそ 0.036〜0.090 の範囲では二つの曲線が一致し、空売りを許す最小点の重みもすべて非負である。
二資産では収益が配分を一つに決めるので、三つの曲線は一致する。
相関を $-0.4$ にすると分散が打ち消し合い、31 点のうち分散が最小の点は収益 0.0567、分散 0.00097 に移る（閉形式の最小分散点は収益 0.0562）。
相関を 0.8 にすると分散を下げる効果が小さくなり、空売りを許さない最小分散点は資産 1 だけの配分（収益 0.03、標準偏差 0.08）になる。

## まとめ

収益を固定した平均分散問題は凸 QP で、二資産・三資産では等式の消去による一変数の閉形式で QP を独立検算できる。
三資産の消去では $w=b+td$ の $t$ が第 3 の重みになり、非負配分の区間 $\max(0,\beta-1)\le t\le\beta/2$ への射影で空売りなしの最小点が、射影しない頂点で Markowitz の閉形式が決まる。
二つの閉形式が離れる収益では、非負の制約が最小分散を押し上げている。
資産数が増えて閉形式がなくなったら、QP の終了理由と KKT 条件の残差、独立検証の状態で QP の前線を評価する。
