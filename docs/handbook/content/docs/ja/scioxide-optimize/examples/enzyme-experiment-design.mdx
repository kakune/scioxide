[酵素反応の速度論パラメータを識別する](../enzyme-identifiability/)では、$K_m$ より低い濃度だけを測ると、$V_{\max}$ と $K_m$ が個別に定まらないことを見た。
このページでは測定の前に、どの基質濃度を何点測れば二つの母数が決まりやすいかを比べる。
比べる尺度は局所 Fisher 情報行列の行列式で、真の母数 $V_{\max}=2.4\,\mathrm{mmol/L/min}$、$K_m=1.3\,\mathrm{mmol/L}$ を仮定した局所的な設計である。

## 局所 Fisher 情報と D 最適性

観測 $y_i=v(S_i)+\varepsilon_i$ の誤差 $\varepsilon_i$ が独立で、分散 $\sigma^2$ が一定の正規分布に従うとする。
母数 $\beta=(V_{\max},K_m)$ の Fisher 情報行列は、残差のヤコビ行列 $J$ を使って

$$
I(\beta)=\sigma^{-2}J^\mathsf TJ
$$

となり、最小二乗推定量の漸近共分散はその逆行列 $\sigma^2(J^\mathsf TJ)^{-1}$ である。
$J$ の第 $i$ 行は $\bigl(S_i/(K_m+S_i),\ -V_{\max}S_i/(K_m+S_i)^2\bigr)$ で、母数に依存するので、設計の比較には仮定した母数の値が要る。

二つの母数に対する信頼楕円の面積は $\det(J^\mathsf TJ)^{-1/2}$ に比例する。
行列式を最大にする設計を D 最適設計と呼ぶ。
$\det(J^\mathsf TJ)$ は $J$ の二つの列が張る平行四辺形の面積の二乗（Gram 行列式）で、Cauchy–Binet の公式から

$$
\det(J^\mathsf TJ)=\sum_{i<k}\bigl(J_{i1}J_{k2}-J_{k1}J_{i2}\bigr)^2
$$

と、行の組ごとの 2×2 小行列式の二乗の和にも書ける。
$S_i\ne S_k$ なら行 $i$ と行 $k$ の小行列式は 0 でないので、相異なる正の濃度が 2 つ以上あれば行列式は正である。
$J^\mathsf TJ$ の単位は、成分 $(1,1)$ が無次元、$(2,2)$ が $\mathrm{min}^{-2}$ なので、行列式は $\mathrm{min}^{-2}$ を持つ。

## 2 点の D 最適設計

濃度を $(0,S_{\max}]$ から選ぶとき、2 母数の Michaelis–Menten 式の局所 D 最適設計は、2 つの濃度に測定を半分ずつ置く設計になることが知られている（R. G. Duggleby, *J. Theor. Biol.* 81, 671–684, 1979）。
一方の濃度は上限 $S_{\max}$ である。
もう一方の濃度 $x$ を決めるには、行 $x$ と行 $S_{\max}$ の小行列式

$$
J_{x1}J_{S_{\max}2}-J_{S_{\max}1}J_{x2}
=\frac{V_{\max}\,x\,S_{\max}(S_{\max}-x)}{(K_m+x)^2(K_m+S_{\max})^2}
$$

の絶対値を $x$ について最大にすればよい。
$x(S_{\max}-x)/(K_m+x)^2$ を微分して 0 とおくと

$$
x^\ast=\frac{K_mS_{\max}}{S_{\max}+2K_m}
$$

を得る。
$S_{\max}\gg K_m$ では $x^\ast\to K_m$ なので、半飽和の濃度と上限で測ることになる。
$n$ 回の測定を $x^\ast$ に $m_1=\lfloor n/2\rfloor$ 回、$S_{\max}$ に $m_2=n-m_1$ 回置くと、Cauchy–Binet の公式で同じ濃度どうしの組は 0 なので、行列式は $m_1m_2$ と小行列式の二乗の積になる。

## 対数間隔の設計の最大濃度

実際の測定では濃度を最小値 $S_{\min}$ から最大値 $S_{\max}$ まで対数間隔に $n$ 点並べることが多い。
次のセルは $S_{\max}\in[0.2,200]\,\mathrm{mmol/L}$ を動かして $\det(J^\mathsf TJ)$ と条件数 $\mathrm{cond}(J^\mathsf TJ)=\lambda_{\max}/\lambda_{\min}$ を描き、行列式を最大にする $S_{\max}$ を求める。
条件数は前のページの $\kappa_2(J)$ の二乗に当たる。
$S_{\max}$ の最適化は $u=\log_{10}S_{\max}$ について $-\ln\det(J^\mathsf TJ)$ を `ScalarMinimizer`（既定は Brent 法）で最小化して行う。
「最良」はこの一変数の設計族の中だけを指し、上の 2 点 D 最適設計を同じ $S_{\max}$ と $n$ での参照値（破線）として重ねる。
入力は最小濃度と測定点の数で、$S_{\min}$ が $0.95\,S_{\max}$ を超える区間では $S_{\min}$ を $0.95\,S_{\max}$ に置き換える。

検算は 3 つある。
Brent 法の最大を、図に描く 121 点の格子での最大と比べる。
最大点の行列式を、$J^\mathsf TJ$ の成分から計算した値と、Cauchy–Binet の和で計算した値で比べる。
対数間隔で並べた設計の行列式が同じ $S_{\max}$ の 2 点 D 最適設計の値を超えないことを図と表で確かめる。

```rust
//| id: optimize-enzyme-experiment-design
//| ref: optimize-enzyme-experiment-design
//| title: 基質濃度範囲と測定点数が Fisher 情報へ与える影響を見る
//| run: reactive
//| crates: [scioxide-core, scioxide-optimize]
//| inputs:
//|   design_minimum_substrate: {"type":"range","label":"最小の基質濃度 Smin [mmol/L]","description":"低濃度の傾きを測る端の濃度を変える。","min":0.01,"max":0.5,"step":0.01,"value":0.05}
//|   design_measurements: {"type":"range","label":"対数間隔の測定点の数 n [点]","description":"同じ濃度範囲に置く測定の数を変える。","min":3,"max":20,"step":1,"value":8}
//| cases:
//|   - {"id":"three-points","label":"測定点の数 3","description":"行列式の最大は内部の Smax ≈ 56 mmol/L に移り、det = 0.18、cond = 10.1 になる。上限 200 では det は 0.142 に下がる。","inputs":{"design_measurements":3}}
//|   - {"id":"twenty-points","label":"測定点の数 20","description":"Smax = 200 の det は 8.3 に増えるが、Smax = 0.2 の det は 4.6×10⁻⁵ にとどまる。","inputs":{"design_measurements":20}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"design","path":"/rows/0/1","approx":{"value":200,"atol":1e-3}}
//|       - {"artifact":"design","path":"/rows/1/1","approx":{"value":1.27504,"atol":1e-4}}
//|       - {"artifact":"design","path":"/rows/2/1","approx":{"value":1.27504,"atol":1e-4}}
//|       - {"artifact":"design","path":"/rows/3/1","range":{"min":0,"max":1e-12}}
//|       - {"artifact":"design","path":"/rows/4/1","approx":{"value":13.043,"atol":1e-2}}
//|       - {"artifact":"design","path":"/rows/5/1","approx":{"value":9.0499e-6,"atol":1e-8}}
//|       - {"artifact":"design","path":"/rows/7/1","approx":{"value":3.27833,"atol":1e-4}}
//|       - {"path":"/outputs/3/state","equals":"satisfied"}
//|   - case: three-points
//|     expect:
//|       - {"artifact":"design","path":"/rows/0/1","approx":{"value":56.02,"atol":0.05}}
//|       - {"artifact":"design","path":"/rows/1/1","approx":{"value":0.18153,"atol":1e-4}}
//|       - {"artifact":"design","path":"/rows/6/1","approx":{"value":0.14240,"atol":1e-4}}
//|       - {"artifact":"design","path":"/rows/7/1","approx":{"value":0.37125,"atol":1e-4}}
//|   - case: twenty-points
//|     expect:
//|       - {"artifact":"design","path":"/rows/5/1","approx":{"value":4.5951e-5,"atol":1e-8}}
//|       - {"artifact":"design","path":"/rows/6/1","approx":{"value":8.3053,"atol":1e-3}}
use scioxide_core::{Interval, RealScalar};
use scioxide_optimize::{ScalarMinimizer, ScalarMinimumStart};
use serde_json::json;

// 仮定する真の母数 Vmax [mmol/L/min] と Km [mmol/L]、感度の行 [∂v/∂Vmax, ∂v/∂Km]。
let (vmax, km) = (2.4_f64, 1.3_f64);
let row = |s: f64| [s / (km + s), -vmax * s / ((km + s) * (km + s))];
let n = design_measurements.round() as usize;
// Smin から Smax までの対数間隔の n 点。
let design = |maximum: f64| -> Vec<f64> {
    let minimum = design_minimum_substrate.min(0.95 * maximum);
    let log_ratio = RealScalar::ln(maximum / minimum);
    (0..n)
        .map(|k| minimum * RealScalar::exp(k as f64 / (n - 1) as f64 * log_ratio))
        .collect()
};
// JᵀJ = [[a, b], [b, d]] の行列式と条件数 λmax/λmin。
let information = |maximum: f64| {
    let (mut a, mut b, mut d) = (0.0_f64, 0.0_f64, 0.0_f64);
    for s in design(maximum) {
        let [j0, j1] = row(s);
        a += j0 * j0;
        b += j0 * j1;
        d += j1 * j1;
    }
    let disc = RealScalar::sqrt((a - d) * (a - d) + 4.0 * b * b);
    (a * d - b * b, (a + d + disc) / (a + d - disc))
};
// 2 点 D 最適設計: x* = Km Smax/(Smax + 2Km) に ⌊n/2⌋ 回、Smax に残りを置く。
let two_point = |maximum: f64| {
    let (u, w) = (row(km * maximum / (maximum + 2.0 * km)), row(maximum));
    let m1 = (n / 2) as f64;
    m1 * (n as f64 - m1) * (u[0] * w[1] - u[1] * w[0]) * (u[0] * w[1] - u[1] * w[0])
};
// u = log₁₀ Smax について −ln det(JᵀJ) を最小化する（一変数の D 最適化）。
let start = ScalarMinimumStart::Bounded(
    Interval::new(RealScalar::log10(0.2_f64), RealScalar::log10(200.0_f64))
        .map_err(|e| e.to_string())?,
);
let best = ScalarMinimizer::default()
    .minimize(
        &|u: f64| Ok(-RealScalar::ln(information(RealScalar::exp10(u)).0)),
        start,
    )
    .map_err(|e| e.to_string())?;
let s_best = RealScalar::exp10(best.x());
let (det_best, cond_best) = information(s_best);
// 独立な検算: Cauchy–Binet の和 Σ_{i<k} (2×2 小行列式)² で同じ行列式を計算する。
let rows: Vec<[f64; 2]> = design(s_best).into_iter().map(row).collect();
let mut binet = 0.0_f64;
for (i, p) in rows.iter().enumerate() {
    for q in &rows[i + 1..] {
        binet += (p[0] * q[1] - q[0] * p[1]) * (p[0] * q[1] - q[0] * p[1]);
    }
}
// 表示用の 121 点の格子。相異なる正の濃度では det > 0 なので、0 以下の点はない。
let grid: Vec<f64> = (0..=120)
    .map(|i| 0.2 * RealScalar::exp10(3.0 * f64::from(i) / 120.0))
    .collect();
let det_curve: Vec<[f64; 2]> = grid.iter().map(|&m| [m, information(m).0]).collect();
let two_curve: Vec<[f64; 2]> = grid.iter().map(|&m| [m, two_point(m)]).collect();
let cond_curve: Vec<[f64; 2]> = grid.iter().map(|&m| [m, information(m).1]).collect();
let grid_best = det_curve.iter().fold(0.0_f64, |acc, p| acc.max(p[1]));
let mark = json!([{"kind": "line", "axis": "x", "value": s_best, "label": "det 最大の Smax"}]);
let axes = |label: &str| {
    json!({
        "link": {"group": "enzyme-design-smax"},
        "xLabel": "設計の最大基質濃度 Smax [mmol/L]",
        "yLabel": label,
        "xType": "log",
        "yType": "log",
        "annotations": mark
    })
};
emit_line_chart!(
    &vec![
        json!({"name": "対数間隔の n 点", "points": det_curve}),
        json!({
            "name": "2 点 D 最適設計（参照）",
            "points": two_curve,
            "style": {"lineType": "dashed"}
        }),
    ],
    options = &axes("det(JᵀJ) [min⁻²]")
);
emit_line_chart!(
    &vec![json!({"name": "対数間隔の n 点", "points": cond_curve})],
    options = &axes("cond(JᵀJ) [-]")
);
let columns = json!([
    { "key": "0", "label": "量" },
    { "key": "1", "label": "値", "type": "number", "format": { "significantDigits": 6 } }
]);
emit_table_with_columns!(
    columns,
    vec![
        ("det 最大の Smax [mmol/L]", s_best),
        ("そのときの det(JᵀJ) [min⁻²]", det_best),
        ("格子 121 点での det の最大 [min⁻²]", grid_best),
        (
            "Cauchy–Binet の和との相対差 [-]",
            (binet - det_best).abs() / det_best
        ),
        ("そのときの cond(JᵀJ) [-]", cond_best),
        ("Smax = 0.2 の det(JᵀJ) [min⁻²]", information(0.2).0),
        ("Smax = 200 の det(JᵀJ) [min⁻²]", information(200.0).0),
        (
            "同じ Smax の 2 点 D 最適設計の det [min⁻²]",
            two_point(s_best)
        ),
        ("目的の評価 [回]", best.fun_evals() as f64),
    ],
    metadata = json!({ "id": "design" })
);
let outcome = if best.is_success() {
    Outcome::satisfied("Brent 法が det 最大の Smax を許容誤差内で求めた")
} else {
    Outcome::partial("Brent 法が許容誤差を満たす前に止まった")
        .explanation("Smax は最良の標本で、推定値として扱う。")
};
emit_outcome!(
    outcome
        .status(best.termination().to_string())
        .diagnostic("det 最大の Smax", s_best, Some("mmol/L"))
        .diagnostic("目的の評価", best.fun_evals() as f64, None)
);
```

既定の $n=8$、$S_{\min}=0.05\,\mathrm{mmol/L}$ では、行列式は走査範囲の全体で増え続け、Brent 法は上限 $S_{\max}=200\,\mathrm{mmol/L}$ に達して `Converged` を返す（$\det=1.275\,\mathrm{min^{-2}}$、条件数 13.0）。
格子での最大も同じ 1.275 で、Cauchy–Binet の和との相対差は丸め誤差の程度である。
$S_{\max}=0.2$ では $\det=9.0\times10^{-6}$ で、最大濃度が $K_m$ よりはるかに低いと、点を増やしてもほぼ同じ感度の方向を繰り返し測るだけになる。
点の数を 20 にしても $S_{\max}=0.2$ の行列式は $4.6\times10^{-5}$ にとどまり、点の数を増やすことと濃度範囲を広げることは同じ改善にならない。

同じ $S_{\max}=200$ と $n=8$ の 2 点 D 最適設計（$x^\ast=1.28\,\mathrm{mmol/L}$ と $200\,\mathrm{mmol/L}$ に 4 回ずつ）の行列式は 3.28 で、対数間隔の設計の約 2.6 倍である。
対数間隔の設計は感度の小さい低濃度域にも点を置くので、同じ測定の回数で得る情報が少ない。
ただし 2 点設計は仮定した $K_m$ に強く依存し、モデルの当てはまりを残差で確かめるための濃度も含まない。

測定点を 3 点にすると、最大は内部の $S_{\max}=56\,\mathrm{mmol/L}$（$\det=0.18$）に移り、上限 200 の行列式は 0.142 に下がる。
対数間隔の 3 点では中央の点が $\sqrt{S_{\min}S_{\max}}$（$S_{\max}=56$ で 1.67）にあり、最大濃度を上げすぎるとこの点が $K_m$ 付近から離れ、$K_m$ に感度を持つ点がなくなる。
$S\gg K_m$ では $K_m$ への感度は $V_{\max}/S$ の程度で減る。
同じ $S_{\max}=56$ の 2 点 D 最適設計（$x^\ast=1.24$ に 1 回、56 に 2 回）の行列式は 0.371 である。

対数間隔は複数の桁を覆う一つの案にすぎず、実際の最適設計は測定の回数、誤差の分散の濃度依存性、未知の母数の事前の範囲、溶解度などの実験上の上限にも依存する。
ここでの上限 200 mmol/L は走査のために置いた値である。

## まとめ

局所 Fisher 情報行列の行列式 $\det(J^\mathsf TJ)$ は、仮定した母数のもとで、測定の前に濃度の配置を比べる尺度になる。
最大濃度が $K_m$ よりはるかに低い設計は、点の数を増やしても行列式がほとんど増えないので、まず $K_m$ をはさむ濃度範囲を確保する。
対数間隔の 8 点の行列式は同じ上限の 2 点 D 最適設計（$x^\ast=K_mS_{\max}/(S_{\max}+2K_m)$ と $S_{\max}$ に半分ずつ）の約 4 割にとどまる。
最適設計の結果は仮定した母数、誤差のモデル、探索した設計族の範囲で解釈する。
