酵素反応の初期速度は基質濃度を上げると飽和し、その飽和曲線を Michaelis–Menten 式で表す。
観測する濃度の範囲が狭いと、最大反応速度 $V_{\max}$ と Michaelis 定数 $K_m$ の推定値は強く相関し、二つの母数を個別に決められなくなる。
このとき母数は（実用上）識別できないという。
このページでは反応機構から速度式を導き、Levenberg–Marquardt（LM）法で当てはめ、観測範囲を狭めたときに何が決まり何が決まらないかを残差のヤコビ行列で調べる。

## 反応機構から飽和曲線へ

酵素 $E$ が基質 $S$ と結合して複合体 $ES$ を作り、生成物 $P$ を放出する反応

$$
E+S
\mathrel{\mathop{\rightleftharpoons}^{k_1}_{k_{-1}}}
ES
\mathrel{\mathop{\longrightarrow}^{k_{\mathrm{cat}}}}
E+P
$$

を考える。
初期速度を測る短い時間では生成物からの逆反応を無視し、複合体が準定常

$$
\frac{d[ES]}{dt}
=k_1[E][S]-(k_{-1}+k_{\mathrm{cat}})[ES]
\approx0
$$

にあるとする。
全酵素濃度 $[E]_T=[E]+[ES]$ を使って $[E]$ を消去すると

$$
[ES]=\frac{[E]_T[S]}{K_m+[S]},
\qquad
K_m=\frac{k_{-1}+k_{\mathrm{cat}}}{k_1}
$$

を得る。
生成速度 $v=k_{\mathrm{cat}}[ES]$ は、基質濃度を $S=[S]$ と書くと

$$
v(S;V_{\max},K_m)
=\frac{V_{\max}S}{K_m+S},
\qquad
V_{\max}=k_{\mathrm{cat}}[E]_T
$$

となる。
$V_{\max}$ は速度の単位 [mmol/L/min]、$K_m$ は基質濃度の単位 [mmol/L] を持ち、$S=K_m$ で $v=V_{\max}/2$ になる。

## 二つの極限と感度

低基質域 $S\ll K_m$ では

$$
v(S)\approx\frac{V_{\max}}{K_m}S
$$

となる。
観測がこの範囲にしかなければ、データは傾き $V_{\max}/K_m$ を決めるが、二つの母数を個別には決めにくい。
たとえば両方を 2 倍にしても、低濃度での予測はほとんど変わらない。

高基質域 $S\gg K_m$ では

$$
v(S)=V_{\max}\left(1-\frac{K_m}{S}+O\!\left(\frac{K_m^2}{S^2}\right)\right)
$$

となり、平坦部が $V_{\max}$ を決める一方、$K_m$ への感度 $\partial v/\partial K_m\approx-V_{\max}/S$ は $S$ に反比例して弱くなる。
したがって $K_m$ より十分低い濃度、同程度の濃度、十分高い濃度を組み合わせて測る必要がある。

残差 $r_i=v(S_i)-y_i$ のヤコビ行列 $J$ の第 $i$ 行は

$$
\frac{\partial r_i}{\partial V_{\max}}
=\frac{S_i}{K_m+S_i},
\qquad
\frac{\partial r_i}{\partial K_m}
=-\frac{V_{\max}S_i}{(K_m+S_i)^2}
$$

である。
第 2 成分と第 1 成分の比は $-V_{\max}/(K_m+S_i)$ なので、$S_i\ll K_m$ ではどの行でも比がほぼ $-V_{\max}/K_m$ になり、二つの列はほぼ平行になる。
相異なる正の濃度が 2 つ以上あれば比は行ごとに違うので、$J$ の階数は 2 のままである。
問題は階数の不足ではなく二つの列のなす角 $\theta$ が 0 か $\pi$ に近づき、$J$ の条件数 $\kappa_2(J)$ が大きくなることである。

$J^\mathsf TJ=\begin{pmatrix}a&b\\b&d\end{pmatrix}$ と書くと、列の余弦は $\cos\theta=b/\sqrt{ad}$ である。
観測誤差が独立で分散が一定なら、推定量の漸近共分散は $\sigma^2(J^\mathsf TJ)^{-1}$ に比例し、$V_{\max}$ と $K_m$ の推定量の相関係数は $-b/\sqrt{ad}=-\cos\theta$ になる。
$|\cos\theta|$ が 1 に近いほど、二つの推定値は一緒に動き、目的関数の谷は細長くなる。
$\kappa_2(J)$ は $J^\mathsf TJ$ の固有値 $\lambda_{\max}\ge\lambda_{\min}$ から $\sqrt{\lambda_{\max}/\lambda_{\min}}$ で求める。

## 観測範囲を狭める

既知の母数 $V_{\max}=2.4\,\mathrm{mmol/L/min}$、$K_m=1.3\,\mathrm{mmol/L}$ から擬似観測を作り、指定した上限以下の濃度だけを使って LM 法で当てはめる。
候補の濃度は 0.05〜10 mmol/L の 10 点で、各点に振幅を指定した決定論的な正弦波の摂動を加える。
入力は二つの母数の初期値、摂動の振幅、使う最大の基質濃度である。

図には LM の当てはめ、真の速度曲線（破線）、擬似観測（記号）を描く。
1 つ目の表で推定値と真値の相対誤差を、2 つ目の表で観測数、残差の RMSE、列の余弦、推定量の相関係数、$\kappa_2(J)$、反復回数を示す。
列の余弦と $\kappa_2(J)$ は、LM の解で解析的なヤコビ行列から $J^\mathsf TJ$ を作り、2×2 の固有値を閉形式で求めた独立な値である。
摂動を 0 にすると観測はモデルの曲線そのものになるので、真値を再現できるかでモデルと解法を検算できる。
最後の判定は LM の終了理由の `is_success()` で決めるが、これは停止判定を満たしたことを示すだけで、母数が個別に定まったことは示さない。

use scioxide_core::{GradientTolerance, RealScalar, StepTolerance};
use scioxide_linalg::Matrix;
use scioxide_optimize::{
    LeastSquares, LeastSquaresFn, LeastSquaresGlobalization, LeastSquaresOptions,
};
use serde_json::json;

// 候補の濃度のうち上限以下だけを使い、既知の母数 Vmax = 2.4、Km = 1.3 に決定論的な摂動を加える。
let candidates = [0.05_f64, 0.1, 0.2, 0.4, 0.8, 1.3, 2.0, 3.5, 6.0, 10.0];
let substrate: Vec<f64> = candidates
    .into_iter()
    .filter(|&s| s <= maximum_substrate + 1.0e-12)
    .collect();
let rates: Vec<f64> = substrate
    .iter()
    .enumerate()
    .map(|(i, &s)| 2.4 * s / (1.3 + s) + enzyme_noise * RealScalar::sin(1.73 * i as f64 + 0.2))
    .collect();
let (s_r, v_r, s_j) = (substrate.clone(), rates.clone(), substrate.clone());
// 残差 rᵢ = Vmax Sᵢ/(Km + Sᵢ) − vᵢ と、解析的なヤコビ行列の行 [S/(Km+S), −Vmax S/(Km+S)²]。
let problem = LeastSquaresFn::new(2, substrate.len(), move |p: &[f64], r: &mut [f64]| {
    for ((ri, &s), &v) in r.iter_mut().zip(&s_r).zip(&v_r) {
        *ri = p[0] * s / (p[1] + s) - v;
    }
    Ok(())
})
.map_err(|e| e.to_string())?
.with_jacobian(move |p: &[f64], j: &mut Matrix<f64>| {
    for (row, &s) in j.as_mut_slice().chunks_exact_mut(2).zip(&s_j) {
        row[0] = s / (p[1] + s);
        row[1] = -p[0] * s / ((p[1] + s) * (p[1] + s));
    }
    Ok(())
});
let options = LeastSquaresOptions::default()
    .with_gradient_tolerance(
        GradientTolerance::new(1.0e-8_f64, 1.0e-8).map_err(|e| e.to_string())?,
    )
    .with_step_tolerance(StepTolerance::new(1.0e-14_f64, 1.0e-14).map_err(|e| e.to_string())?)
    .with_globalization(LeastSquaresGlobalization::levenberg_marquardt());
let result = LeastSquares::new(options)
    .map_err(|e| e.to_string())?
    .solve(&problem, &[enzyme_initial_vmax, enzyme_initial_km])
    .map_err(|e| e.to_string())?;
let (vmax, km) = (result.x()[0], result.x()[1]);
let curve = |vm: f64, k: f64| {
    (0..=240)
        .map(|i| {
            let s = maximum_substrate * i as f64 / 240.0;
            [s, vm * s / (k + s)]
        })
        .collect::<Vec<_>>()
};
let observed: Vec<[f64; 2]> = substrate
    .iter()
    .zip(&rates)
    .map(|(&s, &v)| [s, v])
    .collect();
emit_chart!(json!({
    "kind": "xy",
    "dataZoom": true,
    "tooltip": true,
    "xLabel": "基質濃度 S [mmol/L]",
    "yLabel": "初期反応速度 v [mmol/L/min]",

        { "id": "fit", "kind": "line", "name": "LM の当てはめ", "points": curve(vmax, km) },
        {
            "id": "truth",
            "kind": "line",
            "name": "既知の真の曲線",
            "points": curve(2.4, 1.3),
            "style": { "lineType": "dashed", "showSymbol": false }
        },
        { "id": "observed", "kind": "scatter", "name": "擬似観測", "points": observed }
    ]
}));
let sig6 = json!({ "significantDigits": 6 });
let sci3 = json!({ "notation": "scientific", "significantDigits": 3 });

    { "key": "0", "label": "量" },
    { "key": "1", "label": "LM の推定", "type": "number", "format": sig6 },
    { "key": "2", "label": "既知の真値", "type": "number", "format": sig6 },
    { "key": "3", "label": "相対誤差 [-]", "type": "number", "format": sci3 }
]);
let relative = |estimate: f64, truth: f64| (estimate - truth) / truth;
emit_table_with_columns!(
    estimate_columns,
    vec![
        ("Vmax [mmol/L/min]", vmax, 2.4, relative(vmax, 2.4)),
        ("Km [mmol/L]", km, 1.3, relative(km, 1.3)),
        (
            "低濃度の傾き Vmax/Km [1/min]",
            vmax / km,
            2.4 / 1.3,
            relative(vmax / km, 2.4 / 1.3)
        ),
    ],
    metadata = json!({ "id": "estimates" })
);
// 独立な診断: LM の解で JᵀJ = [[a, b], [b, d]] を作り、2×2 の固有値を閉形式で求める。
let (mut a, mut b, mut d) = (0.0_f64, 0.0_f64, 0.0_f64);
for &s in &substrate {
    let (j0, j1) = (s / (km + s), -vmax * s / ((km + s) * (km + s)));
    a += j0 * j0;
    b += j0 * j1;
    d += j1 * j1;
}
let disc = RealScalar::sqrt((a - d) * (a - d) + 4.0 * b * b);
let (largest, smallest) = (0.5 * (a + d + disc), 0.5 * (a + d - disc));
let cosine = b / RealScalar::sqrt(a * d);
let rmse =
    RealScalar::sqrt(2.0 * result.cost().map_err(|e| e.to_string())? / substrate.len() as f64);
let diagnostic_columns = json!([
    { "key": "0", "label": "診断" },
    { "key": "1", "label": "値", "type": "number", "format": sig6 }
]);
emit_table_with_columns!(
    diagnostic_columns,
    vec![
        ("観測数 [点]", substrate.len() as f64),
        ("残差の RMSE [mmol/L/min]", rmse),
        ("J の列の余弦 cos θ [-]", cosine),
        ("推定量の相関係数 −cos θ [-]", -cosine),
        ("条件数 κ₂(J) [-]", RealScalar::sqrt(largest / smallest)),
        ("反復 [回]", result.iterations() as f64),
    ],
    metadata = json!({ "id": "diagnostics" })
);
let outcome = if result.is_success() {
    Outcome::satisfied("LM の停止判定を満たした")
        .explanation("母数が個別に定まるかは、列の余弦と推定値の相対誤差で別に判断する。")
} else {
    Outcome::partial("LM が停止判定を満たす前に止まった")
        .explanation("返された母数は最後に受理した反復点で、推定値として扱う。")
};
emit_outcome!(
    outcome
        .status(result.termination().to_string())
        .diagnostic("残差の RMSE", rmse, Some("mmol/L/min"))
        .diagnostic("反復", result.iterations() as f64, None)
);

既定の入力（$S\le6\,\mathrm{mmol/L}$ の 9 点、摂動の振幅 0.03）では、LM は 5 回の反復で `GradientSmall` に達し、$V_{\max}=2.424$、$K_m=1.328$、残差の RMSE $0.021\,\mathrm{mmol/L/min}$ を返す。
推定値の相対誤差は 1% と 2% で、列の余弦は $-0.898$、推定量の相関係数は $0.898$、$\kappa_2(J)=4.66$ である。
初期値を変えても同じ点に達し、$K_m$ の初期値を 4 にすると反復は 9 回に増える。
摂動を 0 にすると、LM は 4 回の反復で $V_{\max}=2.4$、$K_m=1.3$ を相対誤差 $3\times10^{-14}$ 以内で再現する。

最大の濃度を $0.4\,\mathrm{mmol/L}$ にすると、使える観測は $K_m$ より低い 4 点だけになる。
当てはめ曲線は観測点によく一致し（RMSE $0.0135$）、終了理由も `GradientSmall` だが、推定値は $V_{\max}=1.589$、$K_m=0.783$ で、真値から 34% と 40% 離れる。
一方、比 $V_{\max}/K_m=2.028$ の真値 1.846 からのずれは 10% にとどまる。
データが決めているのは二つの母数ではなく低濃度の傾きという一つの組合せで、列の余弦は $-0.9935$ まで $-1$ に近づき、$\kappa_2(J)$ は 18.8 に増える。
停止判定を満たしたことと残差が小さいことは、母数が個別に識別できたことを意味しない。

同じ 4 点でも摂動を 0 にすると、真値を相対誤差 $7\times10^{-10}$ 以内で再現する。
$J$ の階数は 2 のままなので、モデルと解法は母数を決められる。
濃度範囲が狭いと母数が大きくずれるのは、ほぼ平行な二つの列が作る弱い方向に、観測の摂動が増幅されるからである。
この弱い方向は $J^\mathsf TJ$ の小さい固有値の固有ベクトルで、$V_{\max}$ と $K_m$ をほぼ同じ割合で動かすので、比 $V_{\max}/K_m$ の変化は小さい。

条件数は母数の単位をどう選ぶかにも依存するので、絶対的な閾値にはならない。
同じ単位と同じ尺度で観測設計を比べる指標として使う。

## 直線化の誘惑

逆数を取る Lineweaver–Burk 変換

$$
\frac1v=\frac{K_m}{V_{\max}}\frac1S+\frac1{V_{\max}}
$$

は直線回帰に見える。
しかし $1/v$ は小さい $v$ の誤差を強く増幅し、元の尺度で分散が一定だった誤差を大きく不均一にする。
図示や初期値には使えても、誤差モデルを無視した最終の推定には偏りを生みやすい。
元の非線形な式を、観測誤差に合った重みで直接当てはめるほうが、仮定を明示しやすい。

基質の枯渇、生成物阻害、協同性、酵素の失活があれば、Michaelis–Menten 式そのものが不十分である。
残差を濃度の順に調べ、平坦部付近の系統的なずれを数値解法の不収束と混同しない。

最終のレポートには濃度の配置、反復測定の数、誤差の尺度、初期値、ヤコビ行列の診断（列の余弦、条件数）、母数の共分散またはプロファイル、終了理由を含める。
当てはめ曲線の図だけでは識別性を伝えられない。

## まとめ

摂動 0 で真値を再現できることを先に確かめ、そのうえで観測範囲を狭めたときの推定値の動きを見る。
$K_m$ より低い濃度だけの観測では、RMSE が小さく `GradientSmall` で終わっても $V_{\max}$ と $K_m$ は数十 % ずれ、データが決めるのは比 $V_{\max}/K_m$ である。
列の余弦の絶対値が 1 に近いか、$\kappa_2(J)$ が大きいかで識別性の不足を判断し、測定点を増やすより先に $K_m$ をはさむ濃度範囲を確保する。
LM の終了理由は停止判定の結果で、識別性の判定には使えない。
