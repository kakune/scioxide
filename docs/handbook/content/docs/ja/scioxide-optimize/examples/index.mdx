最小値らしい数値が得られたことと、意思決定に必要な根拠が得られたことは別である。
残差の構造、目的の凸性、線形制約の多面体、変数の整数性、母数の識別性によって、使えるアルゴリズムと結果の評価基準が変わる。
各例題は自然科学・工学・経済の具体的な問題から目的と制約を導き、数値解を元の単位と制約へ戻して、解析解・全列挙・別の手法などの独立な検算と照合する。
次の表は例題ごとの主題、使う API、独立な検算の方法を示す。

## モデルからアルゴリズムまでの四つの層

最適化の問題は四つの層に分けて組み立てる。
一つ目は現象モデルで、物質収支、反応機構、収益表、共分散、Bernoulli 観測から変数と予測式を決める。
二つ目は統計・意思決定モデルで、最小二乗、負の対数尤度、リスクのペナルティ、利益を選ぶ。
三つ目は実行可能集合で、等式、不等式、境界、整数条件を記述する。
四つ目が数値アルゴリズムである。

上位層の誤りを下位層の高精度では直せない。
たとえば一室薬物モデルが誤っていれば、Gauss–Newton の残差を $10^{-12}$ まで解いても現象予測は正しくならない。
整数ロットを連続 LP として解けば、LP の最適性の証拠は元の生産問題の証拠にならない。

## 目的値と併せて読む指標

局所非線形法では勾配または停留性、刻みの受理、ヘッセ行列・ヤコビ行列の条件を見る。
制約問題では元の式へ解を代入し、主実行可能性、境界、相補性を確認する。
LP・QP・MIP では、双対の証拠や緩和の下界に裏付けられた隔たりが、単なる二手法の一致より強い証拠になる。

確率的探索では一回の最良値ではなく、シードによる分布と総評価回数を返す。
母数推定では訓練目的値だけでなく、識別可能な母数の組合せ、観測設計、未知データでの性能を分ける。

## 終了理由と成功の根拠

成功に分類される終了理由は、方法が自分の停止判定を満たしたことを示す。
例題ではそれに加えて次の量で結果の妥当性を確かめる。

| 問題族 | 成功の分類 | 成功を裏付ける量 |
|---|---|---|
| 局所の微分法 | `GradientSmall`、`Converged` | 勾配ノルム。`StepSmall`・`FunctionChangeSmall`・`Stagnation` は成功ではない |
| 非線形最小二乗 | `GradientSmall`（既定の元の勾配の判定）、`Converged`（Moré の収束判定） | 元の勾配、ヤコビ行列の特異値、ノイズ 0 での真値の再現 |
| 制約付き非線形 | `Converged` | 主実行可能性、停留性、相補性 |
| LP・QP | `Converged` と独立検証の `Accepted` | 主・双対実行可能性、停留性、相補性 |
| MIP | `Converged` | 検証済みの整数解、探索の下界（浮動小数点の推定）、絶対ギャップ |
| 近接法・ADMM | `Converged` | 元の目的の KKT 違反。ADMM の主・双対残差だけでは足りない |
| 多開始・進化計算・basin hopping・焼きなまし・NSGA-II | 成功に分類しない（`SearchBudgetCompleted`、`PopulationStagnation`） | 有限の探索回数の上限と最良の観測値。大域最適性や前線全体の近似は示さない |
| 二次割当て | `Converged` は各段階の停止 | 置換の計算コストの再計算と参照値への隔たり。大域最適性は示さない |

`StepSmall` や `FunctionChangeSmall` は「もう動かなかった」ことを表し、一階の最適性を表さない。
`SearchBudgetCompleted` は予定した探索を終えただけである。
返り値があること、終了が成功の分類であること、目的に必要な証拠があることを三段階に分けて読む。
終了理由の全体は[終了理由の分類](oxref:optimize-termination-classes)にある。
例題の式を変えたときは、この表でどの問題族に移り、どの量で結果を確かめるかを引く。

## まとめ

目的関数の形だけでなく、制約の種類と求めたい診断から例題を選ぶ。
最小二乗の母数推定は薬物動態と酵素反応、LP・QP・MIP の双対と下界は生産計画、ポートフォリオ、施設配置で、等式制約の乗数が持つ物理的な意味は懸垂線で確かめられる。
大域探索では Rastrigin、Thomson 問題、Lennard-Jones クラスタ、施設レイアウトが、シードと評価回数による結果の違いを示す。
どの例題でも、数値解を解析解、全探索、文献値、元の式への代入と比較し、終了理由と独立な検算を並べて読む。
操作入力を変え、解の変化がモデル、観測、数値アルゴリズムのどれに由来するかを確かめる。
