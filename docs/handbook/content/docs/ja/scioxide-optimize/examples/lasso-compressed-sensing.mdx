少数の非零成分を持つ係数 $x_*\in\mathbb R^n$ を、$m$ 個の線形観測 $y=Ax_*+\varepsilon$ から復元する。
信号処理の圧縮センシングや、多数の説明変数から効く変数を選ぶ回帰がこの形になる。
観測数が係数の数より少ないと $A$ は非自明な零空間を持ち、残差だけでは係数を一意に決められない。
LASSO（least absolute shrinkage and selection operator）は $\ell_1$ ペナルティを加え、

$$
\min_x F(x)=f(x)+\lambda\|x\|_1,\qquad f(x)=\frac12\|Ax-y\|_2^2
$$

を解く。
$F$ は凸だが、$\|x\|_1$ は成分が 0 のところで微分できない。
LASSO は疎な解を選びやすいが、真の非零位置を必ず復元できるわけではない。
行列の列の相関、測定数、ノイズ、ペナルティの強さが結果を左右する。

## KKT 条件と零解

$g=\nabla f(x)=A^\mathsf T(Ax-y)$ とする。
微分できない点では劣微分を使い、最適性条件（KKT 条件）は $0\in g+\lambda\partial\|x\|_1$ になる。
成分ごとに書くと、非零成分では $g_i+\lambda\operatorname{sign}(x_i)=0$、零成分では $|g_i|\le\lambda$ である。
そこで成分 $i$ の違反を、非零成分では $|g_i+\lambda\operatorname{sign}(x_i)|$、零成分では $\max(|g_i|-\lambda,0)$ とし、その最大値を KKT 違反と呼ぶ。
これは $0$ と劣微分 $\partial F(x)$ の $\infty$ ノルムでの距離に等しい。

$x=0$ を代入すると $g=-A^\mathsf Ty$ なので、$\lambda\ge\lambda_{\max}=\|A^\mathsf Ty\|_\infty$ のとき零解が最適になる。
逆に $\lambda<\lambda_{\max}$ では零成分の条件が破れるので、零解は最適でない。
この閾値はデータだけから計算でき、ソルバーの終了判定とは独立に正則化パスの右端を検算できる。

## 正則化パスの計算

$\lambda\|\cdot\|_1$ の近接写像はソフト閾値写像

$$
\operatorname{prox}_{s\lambda\|\cdot\|_1}(v)_i=\operatorname{sign}(v_i)\max(|v_i|-s\lambda,0)
$$

で、$|v_i|\le s\lambda$ の成分を厳密に 0 にする。
FISTA は滑らかな部分 $f$ の勾配で一歩進み、この写像で小さな成分を 0 に落とし、前の反復点からの外挿で加速する。
刻み $1/L$ の $L$ には $\nabla f$ の Lipschitz 定数 $\|A\|_2^2$ の上界 $L=\|A\|_F^2$ を使い、一反復の計算コストは $O(mn)$ である。
反復点の非零位置は $x_i\ne0$ で数えられ、閾値を決めて丸める必要はない。

正則化パスは、$\lambda$ を変えながら解いた係数の列である。
ここでは $\lambda/\lambda_{\max}=0.05,0.10,\dots,1.00$ の 20 点で、それぞれ零から解く。
前の $\lambda$ の解から始める連続法（warm start）は反復を減らせるが、各点の結果を独立にするため使わない。
FISTA の停止判定、ADMM との比較、返った係数の KKT 違反の検算は[LASSO の解を FISTA と ADMM で求めて KKT 条件で検算する](../lasso-kkt-verification/)で扱う。

## モデルと乱数データ

係数の数は $n=12$、真の非零成分は先頭から交互符号の $\pm1$ とする。
行列の成分は $[-1,1]$ の一様乱数を $\sqrt m$ で割った値で、各成分の二乗の期待値は $1/(3m)$ なので、列のノルムはおよそ $1/\sqrt3$ にそろう。
ノイズは平均 0 の一様分布で、入力はその半幅を表す。
行列とノイズは指定したシードの SplitMix64 から作る。

上の図は各係数の値で、真の非零成分を実線、真値が 0 の成分を点線で描く。
下の図は非零成分の数と、非零か零かの判定が真値と一致する成分の数（12 個中）で、横軸を上の図と連動させる。
一つ目の表は下の図と同じ数を $\lambda/\lambda_{\max}$ ごとに並べる。
二つ目の表は $\lambda_{\max}$、刻みに使う $L=\|A\|_F^2$、20 回の求解のうち `Converged` で終わった回数と、全成分が 0 になった格子点のうち最小の $\lambda/\lambda_{\max}$ である。
最後の列は理論どおりなら 1.00 で、$\lambda_{\max}$ の検算になる。

```rust
//| id: optimize-lasso-path
//| ref: optimize-lasso-path
//| title: 正則化パスと非零位置の回復を λ/λmax に沿って調べる
//| run: button
//| timeoutMs: 120000
//| crates: [scioxide-core, scioxide-optimize, scioxide-random]
//| inputs:
//|   measurements: {"type":"range","label":"測定数 m [点]","min":6,"max":20,"step":2,"value":10}
//|   sparsity: {"type":"range","label":"真の非零成分 [個]","min":1,"max":4,"step":1,"value":2}
//|   noise: {"type":"range","label":"ノイズの半幅 [-]","min":0,"max":0.2,"step":0.02,"value":0.02}
//|   seed: {"type":"range","label":"乱数のシード [-]","min":1,"max":100,"step":1,"value":17}
//| cases:
//|   - {"id":"noisy","label":"ノイズの半幅 0.2","description":"λmax は 0.28923 に増え、λ/λmax = 0.10 では 8 成分が非零で、判定の一致は 6 個に減る。","inputs":{"noise":0.2}}
//|   - {"id":"many-measurements","label":"測定 20 点","description":"m = 20 > n では、λ/λmax ≤ 0.80 で非零成分が真の 2 個だけになり、12 個すべての判定が一致する。","inputs":{"measurements":20}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"summary","path":"/rows/0/0","approx":{"value":0.26306004,"atol":1e-7}}
//|       - {"artifact":"summary","path":"/rows/0/2","equals":20}
//|       - {"artifact":"summary","path":"/rows/0/3","approx":{"value":1,"atol":1e-12}}
//|       - {"artifact":"support","path":"/rows/1/1","equals":5}
//|       - {"artifact":"support","path":"/rows/1/2","equals":9}
//|   - case: noisy
//|     expect:
//|       - {"artifact":"summary","path":"/rows/0/0","approx":{"value":0.28922713,"atol":1e-7}}
//|       - {"artifact":"support","path":"/rows/1/2","equals":6}
//|   - case: many-measurements
//|     expect:
//|       - {"artifact":"support","path":"/rows/15/2","equals":12}
use scioxide_core::{Budget, SciOxideError, NumericScalar, RealScalar};
use scioxide_optimize::{CompositeProblem, Fista, ProximalMap, ProximalOptions, SmoothGradient};
use scioxide_random::{BitGenerator, SeedableRng, SplitMix64, decode_u64};
// 滑らかな部分 f(x) = ½‖Ax − y‖²。a は m×n の A を行ごとに並べる。
struct Loss {
    a: Vec<f64>,
    y: Vec<f64>,
    n: usize,
}
impl SmoothGradient<f64> for Loss {
    fn dimension(&self) -> usize {
        self.n
    }
    fn value(&self, x: &[f64]) -> Result<f64, SciOxideError> {
        let rows = self.a.chunks_exact(self.n).zip(&self.y);
        let squares = rows.map(|(row, y)| (dot(row, x) - y) * (dot(row, x) - y));
        Ok(0.5 * squares.sum::<f64>())
    }
    fn gradient_into(&self, x: &[f64], out: &mut [f64]) -> Result<(), SciOxideError> {
        out.fill(0.0);
        for (row, y) in self.a.chunks_exact(self.n).zip(&self.y) {
            let r = dot(row, x) - y;
            out.iter_mut().zip(row).for_each(|(g, a)| *g += a * r);
        }
        Ok(())
    }
}
fn dot(u: &[f64], v: &[f64]) -> f64 {
    u.iter().zip(v).map(|(a, b)| a * b).sum()
}
// g(x) = λ‖x‖₁ のソフト閾値写像 prox_{sλ‖·‖₁}(v)ᵢ = sign(vᵢ) max(|vᵢ| − sλ, 0)。値は λ。
struct Shrink(f64);
impl ProximalMap<f64> for Shrink {
    fn apply_into(&self, x: &[f64], step: f64, out: &mut [f64]) -> Result<(), SciOxideError> {
        for (o, &v) in out.iter_mut().zip(x) {
            let shrunk = RealScalar::max(NumericScalar::abs(v) - step * self.0, 0.0);
            *o = RealScalar::copysign(shrunk, v);
        }
        Ok(())
    }
}
// A の成分は [−1, 1] の一様乱数を √m で割った値。続けて行ごとにノイズを引く。
let (m, n) = (measurements as usize, 12_usize);
let mut rng = SplitMix64::from_seed(seed as u64);
let mut uniform = || -> Result<f64, String> {
    let bits = rng.next_uniform_u64().map_err(|e| e.to_string())?;
    Ok(decode_u64::<f64>(bits) * 2.0 - 1.0)
};
let scale = RealScalar::sqrt(m as f64);
let a: Vec<f64> = (0..m * n)
    .map(|_| uniform().map(|v| v / scale))
    .collect::<Result<_, _>>()?;
let truth: Vec<f64> = (0..n)
    .map(|i| match i {
        i if i >= sparsity as usize => 0.0,
        i if i % 2 == 0 => 1.0,
        _ => -1.0,
    })
    .collect();
let mut y = Vec::with_capacity(m);
for row in a.chunks_exact(n) {
    y.push(dot(row, &truth) + noise * uniform()?);
}
let loss = Loss { a, y, n };
// 零点の勾配は −Aᵀy なので λmax = ‖Aᵀy‖∞。L = ‖A‖_F² は ‖A‖₂² の上界。
let zero = vec![0.0; n];
let mut gradient = vec![0.0; n];
loss.gradient_into(&zero, &mut gradient)
    .map_err(|e| e.to_string())?;
let lambda_max = gradient
    .iter()
    .fold(0.0, |m, &g| RealScalar::max(m, NumericScalar::abs(g)));
let lipschitz = loss.a.iter().map(|v| v * v).sum::<f64>();
let budget = Budget::try_from(3000_usize).map_err(|e| e.to_string())?;
let solver = Fista::new(ProximalOptions::new(lipschitz).with_max_iterations(budget))
    .map_err(|e| e.to_string())?;
let mut paths = vec![Vec::new(); n];
let mut support = Vec::new();
let (mut converged, mut first_zero) = (0_usize, None);
for k in 1..=20 {
    let fraction = k as f64 / 20.0;
    let result = solver
        .minimize(
            &CompositeProblem::new(&loss, &Shrink(fraction * lambda_max)),
            &zero,
        )
        .map_err(|e| e.to_string())?;
    let x = result.x();
    for (path, &v) in paths.iter_mut().zip(x) {
        path.push([fraction, v]);
    }
    // 近接写像は小さな成分を厳密に 0 にするので、非零位置は xᵢ ≠ 0 で数える。
    let nonzero = x.iter().filter(|&&v| v != 0.0).count();
    let matches = x
        .iter()
        .zip(&truth)
        .filter(|(x, t)| (**x != 0.0) == (**t != 0.0));
    support.push((fraction, nonzero, matches.count()));
    converged += usize::from(result.is_success());
    if nonzero == 0 && first_zero.is_none() {
        first_zero = Some(fraction);
    }
}
let series: Vec<_> = paths
    .iter()
    .zip(&truth)
    .enumerate()
    .map(|(i, (p, &t))| {
        let line = if t == 0.0 { "dotted" } else { "solid" };
        serde_json::json!({ "name": format!("係数 {i}"), "points": p, "style": { "lineType": line } })
    })
    .collect();
let threshold =
    serde_json::json!([{ "kind": "line", "axis": "x", "value": 1.0, "label": "λmax" }]);
emit_line_chart!(
    &series,
    options = &serde_json::json!({
        "xLabel": "λ / λmax [-]",
        "yLabel": "係数 [-]",
        "link": { "group": "lasso-ratio" },
        "annotations": threshold
    })
);
let counts = |column: fn(&(f64, usize, usize)) -> usize| -> Vec<[f64; 2]> {
    support
        .iter()
        .map(|row| [row.0, column(row) as f64])
        .collect()
};
emit_line_chart!(
    &vec![
        serde_json::json!({ "name": "非零成分", "points": counts(|r| r.1), "style": { "step": "end" } }),
        serde_json::json!({ "name": "判定の一致", "points": counts(|r| r.2), "style": { "step": "end" } }),
    ],
    options = &serde_json::json!({
        "xLabel": "λ / λmax [-]",
        "yLabel": "成分 [個]",
        "link": { "group": "lasso-ratio" },
        "annotations": threshold
    })
);
let fixed2 = serde_json::json!({ "fractionDigits": 2 });
let sig5 = serde_json::json!({ "significantDigits": 5 });
emit_table_with_columns!(
    serde_json::json!([
        { "key": "0", "label": "λ / λmax [-]", "type": "number", "format": fixed2 },
        { "key": "1", "label": "非零成分 [個]", "type": "integer" },
        { "key": "2", "label": "判定の一致 [個]", "type": "integer" }
    ]),
    support,
    metadata = serde_json::json!({ "id": "support" })
);
emit_table_with_columns!(
    serde_json::json!([
        { "key": "0", "label": "λmax = ‖Aᵀy‖∞ [-]", "type": "number", "format": sig5 },
        { "key": "1", "label": "L = ‖A‖_F² [-]", "type": "number", "format": sig5 },
        { "key": "2", "label": "Converged の求解 [回]", "type": "integer" },
        { "key": "3", "label": "零解になる最小の λ/λmax [-]", "type": "number", "format": fixed2, "nullText": "なし" }
    ]),
    vec![(lambda_max, lipschitz, converged, first_zero)],
    metadata = serde_json::json!({ "id": "summary" })
);
```

既定の入力（測定 10、非零 2、ノイズの半幅 0.02、シード 17）では $\lambda_{\max}=0.26306$、$L=4.6246$ で、20 回の求解はすべて `Converged` で終わる。
全成分が 0 になる最小の格子点は $\lambda/\lambda_{\max}=1.00$ で、0.95 では非零の成分が残るので、零解の閾値は理論どおり $\lambda_{\max}$ にある。
$\lambda$ を $\lambda_{\max}$ から下げると、最初に非零になるのは真値が 0 の成分 7 である。
零解での KKT 条件が最初に破れるのは $|A_i^\mathsf Ty|$ が最大の成分なので、$\lambda_{\max}$ を与える列が真の非零位置にあるとは限らない。
真の非零成分は、成分 1 が $\lambda/\lambda_{\max}=0.80$、成分 0 が $0.60$ で加わる。
$0.15$ から $0.60$ では、真値が 0 なのに非零になる成分 4 と 7 を含めて 4 成分が非零で、判定の一致は 10 個である。
$0.10$ 以下ではさらに成分 9 が加わり、一致は 9 個になる。
この例ではどの $\lambda$ でも 12 個すべての判定は一致せず、ソルバーの精度とは別に、$m<n$ のデータと LASSO のモデルが非零位置の回復を制限している。

測定を 20 点に増やすと、$\lambda/\lambda_{\max}\le0.80$ で非零成分は真の 2 個だけになり、12 個すべての判定が一致する。
ノイズの半幅を 0.2 にすると $\lambda_{\max}$ は 0.28923 に増え、$\lambda/\lambda_{\max}=0.10$ では 8 成分が非零で、一致は 6 個に減る。

## まとめ

LASSO の KKT 条件は零成分と非零成分で形が変わり、零解が最適になる閾値 $\lambda_{\max}=\|A^\mathsf Ty\|_\infty$ はデータから直接計算できる。
正則化パスの右端はこの閾値で検算でき、$\lambda$ を下げて最初に非零になるのは $|A_i^\mathsf Ty|$ が最大の成分である。
その成分が真の非零位置にあるとは限らないので、非零位置の回復は測定数、ノイズ、列の相関に左右される。
係数の縮みと誤検出は LASSO のモデルの性質で、ソルバーの精度を上げても消えない。
解の精度そのものは KKT 違反と終了理由を別に確かめて判断する。
