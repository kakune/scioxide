[LASSO の正則化パスと疎な信号の復元](../lasso-compressed-sensing/)では、FISTA の解を使って係数の縮みと非零位置の回復を調べた。
このページは同じ問題

$$
\min_x F(x)=f(x)+\lambda\|x\|_1,\qquad f(x)=\frac12\|Ax-y\|_2^2
$$

を FISTA と ADMM で解き、返った係数が最適性条件をどれだけ満たすかを確かめる。
解法の停止判定は勾配写像や残差で行われ、元の目的の最適性を直接は測らない。
そこで停止判定の量から KKT 違反の上界を導き、係数を代入して計算し直した違反と比べる。

データは前のページの既定値と同じで、$m=10$ 個の測定、$n=12$ 個の係数、真の非零成分 2 個（$+1$ と $-1$）、ノイズの半幅 0.02、シード 17 から作る。
このとき $\lambda_{\max}=\|A^\mathsf Ty\|_\infty=0.26306$ である。

## KKT 違反の定義

$g=\nabla f(x)=A^\mathsf T(Ax-y)$ とすると、最適性条件（KKT 条件）は $0\in g+\lambda\partial\|x\|_1$ である。
成分 $i$ の違反を、非零成分では $|g_i+\lambda\operatorname{sign}(x_i)|$、零成分では $\max(|g_i|-\lambda,0)$ とし、その最大値を KKT 違反と呼ぶ。
これは $0$ と劣微分 $\partial F(x)$ の $\infty$ ノルムでの距離に等しく、$\partial F(x)$ のどの要素 $v$ についても $\|v\|_\infty$ 以下である。
導出は[前のページの KKT 条件](../lasso-compressed-sensing/)にある。

## 近接勾配法と ADMM

$\lambda\|\cdot\|_1$ の近接写像は、成分ごとの一変数問題 $\min_z\tfrac12(z-v)^2+s\lambda|z|$ の解

$$
\operatorname{prox}_{s\lambda\|\cdot\|_1}(v)_i=\operatorname{sign}(v_i)\max(|v_i|-s\lambda,0)
$$

で、ソフト閾値写像と呼ぶ。
$|v_i|\le s\lambda$ の成分は厳密に 0 になるので、反復点の非零位置は $x_i\ne0$ で数えられる。

### FISTA の停止と KKT 違反の上界

FISTA は前の二つの反復点から外挿した点 $y_k$ で $x^+=\operatorname{prox}_{\lambda\|\cdot\|_1/L}(y_k-\nabla f(y_k)/L)$ と進み、刻み $1/L$ で目的値の誤差を $O(1/k^2)$ で減らす。
$L$ は $\nabla f$ の Lipschitz 定数 $\|A\|_2^2$ 以上であればよく、ここでは計算の簡単な上界 $L=\|A\|_F^2=4.6246$ を使う。
刻み $1/L$ は最良の $1/\|A\|_2^2$ 以下になり、$A$ の階数が 2 以上なら真に小さい。
一反復の計算コストは $A$ と $A^\mathsf T$ の積の $O(mn)$ である。

`ProximalOptions::new(L)` の既定では、反復上限は 1000 回で、勾配再開始が有効である。
再開始は $(y_k-x^+)^\mathsf T(x^+-x_k)>0$ のとき外挿をやめ、加速をやり直す。
停止は勾配写像 $G=L\|x^+-y_k\|_\infty$ で判定し、既定の `GradientTolerance` では $G\le\sqrt\epsilon+\sqrt\epsilon\cdot1\approx2.98\times10^{-8}$ で `Converged` になる（$\epsilon$ は倍精度の計算機イプシロン）。

$G$ は KKT 違反そのものではないが、上界を与える。
$x^+$ を定める近接写像の最適性条件は $L(y_k-x^+)-\nabla f(y_k)\in\lambda\partial\|x^+\|_1$ なので、

$$
\nabla f(x^+)-\nabla f(y_k)+L(y_k-x^+)\in\partial F(x^+)
$$

である。
$\|\nabla f(x^+)-\nabla f(y_k)\|_\infty\le\|A\|_2^2\|x^+-y_k\|_2\le\sqrt n\,L\|x^+-y_k\|_\infty$ から、$x^+$ での KKT 違反は $(1+\sqrt n)\,G$ 以下になる。

### ADMM の停止と KKT 違反の上界

ADMM（交互方向乗数法）は $x=z$ と変数を分け、尺度化した双対変数 $u$ とともに次の三つの更新を繰り返す。

$$
(A^\mathsf TA+\rho I)x=A^\mathsf Ty+\rho(z-u),\qquad
z=\operatorname{prox}_{(\lambda/\rho)\|\cdot\|_1}(x+u),\qquad
u\leftarrow u+x-z
$$

ペナルティ $\rho$ を固定すると、$A^\mathsf TA+\rho I$ の Cholesky 分解は最初に一度だけ作ればよい（$O(mn^2+n^3)$）。
その後の一反復は前進・後退代入の $O(n^2)$ である。
`Admm` は制約を $\mathcal Ax+\mathcal Bz=c$ の形で受け取るので、ここでは $\mathcal A=I$、$\mathcal B=-I$、$c=0$ と置く。
主問題の残差は $r=x-z$、双対残差は $s=\rho\,\mathcal A^\mathsf T\mathcal B(z-z_{\text{prev}})=-\rho(z-z_{\text{prev}})$ である。
既定の `ResidualTolerance` では $\|r\|\le\sqrt\epsilon\,(1+\max(\|x\|,\|z\|))$ と $\|s\|\le\sqrt\epsilon\,(1+\rho\|u\|)$ がともに成り立つと `Converged` になる。

二つの残差も元の目的の KKT 違反とは別の量である。
$x$ 更新の最適性条件は $\nabla f(x)+\rho(x-z_{\text{prev}}+u_{\text{prev}})=0$、$z$ 更新の最適性条件は $\rho(x+u_{\text{prev}}-z)\in\lambda\partial\|z\|_1$ である。
更新後の $u=u_{\text{prev}}+x-z$ を使うと、後者は $\rho u\in\lambda\partial\|z\|_1$、前者は $\nabla f(x)=-\rho u+s$ と書ける。
二つを合わせると

$$
\nabla f(z)-\nabla f(x)+s\in\partial F(z)
$$

となる。
$\|\nabla f(z)-\nabla f(x)\|_\infty\le\|A\|_2^2\|r\|_2$ なので、$z$ での KKT 違反は $L\|r\|+\|s\|$ 以下である。

二つの上界はソルバーが返す量だけから計算でき、KKT 違反の大きさを上から見積もる。
近接勾配法の停止の一般形は[近接勾配法の収束と停止](oxref:optimize-proximal-gradient-convergence)、ペナルティの調整と ADMM の停止判定は [ADMM の停止判定とペナルティの調整](oxref:optimize-admm-stopping-penalty)にある。

## モデルと ADMM の更新

次の定義のブロックは、このページの二つのセルが共有する。
`lasso_data` は前のページの既定値と同じ手順でデータを作り、`Loss` が $f$ とその勾配、`Shrink` がソフト閾値写像、`kkt_violation` が KKT 違反である。
`Normal` は $x$ 更新、`Threshold` は $z$ 更新で、どちらも部分問題の最適性条件の残差を返す。
`solve_admm` は $\mathcal A=I$、$\mathcal B=-I$、$c=0$ の問題を零から解く。

```rust
//| id: optimize-lasso-admm-model
//| kind: definitions
//| title: LASSO のデータ、損失、ソフト閾値写像と ADMM の更新
//| crates: [scioxide-core, scioxide-linalg, scioxide-optimize, scioxide-random]
use scioxide_core::{Budget, SciOxideError, NumericScalar, RealScalar, SolveContext};
use scioxide_linalg::{CholeskyDecomposition, CholeskyPivoting, HermitianInput, Matrix};
use scioxide_optimize::{
    Admm, AdmmBlockUpdate, AdmmOptions, AdmmProblem, AdmmResult, AdmmStart, AdmmUpdateInput,
    AdmmUpdateReport, ProximalMap, SmoothGradient,
};
use scioxide_random::{BitGenerator, SeedableRng, SplitMix64, decode_u64};

/// 滑らかな部分 f(x) = ½‖Ax − y‖²。a は m×n の A を行ごとに並べる。
pub(crate) struct Loss {
    pub(crate) a: Vec<f64>,
    pub(crate) y: Vec<f64>,
    pub(crate) n: usize,
}

impl SmoothGradient<f64> for Loss {
    fn dimension(&self) -> usize {
        self.n
    }
    fn value(&self, x: &[f64]) -> Result<f64, SciOxideError> {
        let rows = self.a.chunks_exact(self.n).zip(&self.y);
        let squares = rows.map(|(row, y)| (dot(row, x) - y) * (dot(row, x) - y));
        Ok(0.5 * squares.sum::<f64>())
    }
    fn gradient_into(&self, x: &[f64], out: &mut [f64]) -> Result<(), SciOxideError> {
        out.fill(0.0);
        for (row, y) in self.a.chunks_exact(self.n).zip(&self.y) {
            let r = dot(row, x) - y;
            out.iter_mut().zip(row).for_each(|(g, a)| *g += a * r);
        }
        Ok(())
    }
}

fn dot(u: &[f64], v: &[f64]) -> f64 {
    u.iter().zip(v).map(|(a, b)| a * b).sum()
}

/// 前のページの既定値（m = 10、n = 12、非零 2、ノイズの半幅 0.02、シード 17）のデータと真の係数。
pub(crate) fn lasso_data() -> Result<(Loss, Vec<f64>), SciOxideError> {
    let (m, n) = (10, 12);
    let mut rng = SplitMix64::from_seed(17);
    let mut uniform = || {
        rng.next_uniform_u64()
            .map(|w| decode_u64::<f64>(w) * 2.0 - 1.0)
    };
    let scale = RealScalar::sqrt(m as f64);
    let a: Vec<f64> = (0..m * n)
        .map(|_| uniform().map(|v| v / scale))
        .collect::<Result<_, _>>()?;
    let truth: Vec<f64> = (0..n)
        .map(|i| [1.0, -1.0].get(i).copied().unwrap_or(0.0))
        .collect();
    let mut y = Vec::with_capacity(m);
    for row in a.chunks_exact(n) {
        y.push(dot(row, &truth) + 0.02 * uniform()?);
    }
    Ok((Loss { a, y, n }, truth))
}

/// g(x) = λ‖x‖₁ のソフト閾値写像 prox_{sλ‖·‖₁}(v)ᵢ = sign(vᵢ) max(|vᵢ| − sλ, 0)。値は λ。
pub(crate) struct Shrink(pub(crate) f64);

impl ProximalMap<f64> for Shrink {
    fn apply_into(&self, x: &[f64], step: f64, out: &mut [f64]) -> Result<(), SciOxideError> {
        for (o, &v) in out.iter_mut().zip(x) {
            let shrunk = RealScalar::max(NumericScalar::abs(v) - step * self.0, 0.0);
            *o = RealScalar::copysign(shrunk, v);
        }
        Ok(())
    }
}

/// x の各成分について、g = ∇f(x) と λ による KKT 条件の違反を返す。
/// 解法とは独立な検算なので、f64 の固有メソッドで書く。
fn violations(g: &[f64], lambda: f64, x: &[f64]) -> f64 {
    let each = x.iter().zip(g).map(|(&v, &g)| {
        if v == 0.0 {
            (g.abs() - lambda).max(0.0)
        } else {
            (g + lambda * v.signum()).abs()
        }
    });
    each.fold(0.0, f64::max)
}

/// 元の目的の KKT 違反: 零成分は max(|gᵢ| − λ, 0)、非零成分は |gᵢ + λ sign(xᵢ)| の最大値。
pub(crate) fn kkt_violation(loss: &Loss, lambda: f64, x: &[f64]) -> Result<f64, SciOxideError> {
    let mut g = vec![0.0; x.len()];
    loss.gradient_into(x, &mut g)?;
    Ok(violations(&g, lambda, x))
}

/// x 更新: (AᵀA + ρI) x = Aᵀy + ρ(z − u)。返すのはこの連立方程式の残差の最大値。
struct Normal {
    factor: CholeskyDecomposition<f64>,
    matrix: Vec<f64>,
    aty: Vec<f64>,
}

impl AdmmBlockUpdate<f64> for Normal {
    fn update_into(
        &self,
        input: AdmmUpdateInput<'_, f64>,
        out: &mut [f64],
        _: &mut SolveContext<'_, '_>,
    ) -> Result<AdmmUpdateReport<f64>, SciOxideError> {
        let rho = input.rho();
        let rhs: Vec<f64> = (self.aty.iter().zip(input.other()).zip(input.scaled_dual()))
            .map(|((&b, &z), &u)| b + rho * (z - u))
            .collect();
        out.copy_from_slice(self.factor.solve(&rhs[..])?.as_slice());
        let rows = self.matrix.chunks_exact(out.len()).zip(&rhs);
        let defect = rows
            .map(|(row, b)| (dot(row, out) - b).abs())
            .fold(0.0, f64::max);
        Ok(AdmmUpdateReport::new(true, defect))
    }
}

/// z 更新: z = prox_{(λ/ρ)‖·‖₁}(x + u)。返すのは z の部分問題の最適性条件の違反。
struct Threshold(f64);

impl AdmmBlockUpdate<f64> for Threshold {
    fn update_into(
        &self,
        input: AdmmUpdateInput<'_, f64>,
        out: &mut [f64],
        _: &mut SolveContext<'_, '_>,
    ) -> Result<AdmmUpdateReport<f64>, SciOxideError> {
        let rho = input.rho();
        let v: Vec<f64> = (input.other().iter().zip(input.scaled_dual()))
            .map(|(x, u)| x + u)
            .collect();
        Shrink(self.0).apply_into(&v, 1.0 / rho, out)?;
        // z の部分問題の勾配は ρ(z − v) で、λ‖z‖₁ の劣微分との和が 0 を含むかを測る。
        let g: Vec<f64> = out.iter().zip(&v).map(|(z, v)| rho * (z - v)).collect();
        Ok(AdmmUpdateReport::new(true, violations(&g, self.0, out)))
    }
}

/// x = z の制約を 𝒜 = I、ℬ = −I、c = 0 で表し、ペナルティ ρ を固定して零から解く。
pub(crate) fn solve_admm(
    loss: &Loss,
    lambda: f64,
    rho: f64,
    limit: Budget,
) -> Result<AdmmResult<f64>, SciOxideError> {
    let n = loss.n;
    let mut matrix = vec![0.0; n * n];
    for row in loss.a.chunks_exact(n) {
        for (i, &ai) in row.iter().enumerate() {
            row.iter()
                .enumerate()
                .for_each(|(j, &aj)| matrix[i * n + j] += ai * aj);
        }
    }
    (0..n).for_each(|i| matrix[i * n + i] += rho);
    // 零点の勾配は −Aᵀy なので、符号を変えて Aᵀy を得る。
    let mut aty = vec![0.0; n];
    loss.gradient_into(&vec![0.0; n], &mut aty)?;
    aty.iter_mut().for_each(|v| *v = -*v);
    let dense = Matrix::from_vec(n, n, matrix.clone())?;
    let factor =
        CholeskyDecomposition::factor(&dense, HermitianInput::Exact, CholeskyPivoting::None)?;
    let normal = Normal {
        factor,
        matrix,
        aty,
    };
    let identity = Matrix::<f64>::identity(n)?;
    let minus = Matrix::from_vec(n, n, identity.as_slice().iter().map(|v| -v).collect())?;
    let (identity, minus) = (identity.view().try_finite()?, minus.view().try_finite()?);
    let zero = vec![0.0; n];
    let threshold = Threshold(lambda);
    let problem = AdmmProblem::new(&identity, &minus, &zero, &normal, &threshold)?;
    Admm::new(AdmmOptions::new(rho).with_max_iterations(limit))?
        .solve(&problem, AdmmStart::new(&zero, &zero, &zero))
}
```

## 指定した λ での検算

次のセルは指定した $\lambda/\lambda_{\max}$ で FISTA と ADMM を解く。
入力は $\lambda/\lambda_{\max}$、ADMM のペナルティ $\rho$、ADMM の反復上限で、FISTA の反復上限は 3000 回に固定する。

```rust
        .iter()
        .zip(&truth)
        .filter(|(x, t)| (**x != 0.0) == (**t != 0.0));
    rows.push((
        name,

}
```

既定の入力（$\lambda=0.1\lambda_{\max}=0.026306$、$\rho=1$）では、FISTA は 164 反復、ADMM は 287 反復で `Converged` に達する。
二手法の係数の差は $6\times10^{-7}$ 以下で、真の非零成分は 0.8295 と $-0.8147$ に縮み、真値が 0 の成分 4、7、9 が 0.009〜0.033 の大きさで残る。
KKT 違反は FISTA で $2.6\times10^{-8}$、ADMM で $9.3\times10^{-9}$ で、それぞれ上界 $1.2\times10^{-7}$ と $2.3\times10^{-8}$ 以下に収まる。
二手法はどちらも最適性条件をほぼ満たしているので、真の係数との差は最適化の誤差ではなく、$\ell_1$ ペナルティによる縮みと誤検出である。

ADMM の反復上限を 200 回にすると、ADMM は `IterationLimit` で止まり、outcome は partial になる。
最後の反復点の KKT 違反は $6.2\times10^{-7}$ で、示された残差からの上界 $1.3\times10^{-6}$ 以下にある。
係数は小数第 4 位まで FISTA と一致するので、表を眺めるだけでは未収束に気づきにくく、終了理由と KKT 違反の列で判断する。
$\lambda/\lambda_{\max}=1.2$ では零解が最適で、FISTA は 1 反復で全成分 0 を返し、KKT 違反は 0 になる。

## ペナルティ ρ と ADMM の反復数

ADMM の残差の収束は良くて線形で、その速さは $\rho$ に強く依存する。
$\rho$ を大きくすると $x$ と $z$ の差に強いペナルティがかかって主問題の残差は小さくなりやすい一方、双対残差 $\|s\|=\rho\|z-z_{\text{prev}}\|$ は大きくなりやすく、$\rho$ を小さくするとその逆になる。
次のセルは指定した $\lambda/\lambda_{\max}$ で $\rho=10^{-2},10^{-1.75},\dots,10^{2}$ の 17 点について ADMM を反復上限 3000 回で解く。
グラフは両対数軸で反復回数を描き、同じ問題の FISTA の反復回数を破線の基準線で示す。
表は $\rho$ ごとの反復回数、終了理由、KKT 違反である。

```rust
//| id: optimize-lasso-admm-rho
//| ref: optimize-lasso-admm-rho
//| title: ADMM のペナルティ ρ を掃引して反復数と KKT 違反を比べる
//| run: button
//| timeoutMs: 120000

//| crates: [scioxide-core, scioxide-optimize]

//|   - {"id":"strong","label":"λ/λmax = 0.9","description":"反復が最小になる ρ が 0.18 から 1 に移り、最小の反復は 31 回になる。","inputs":{"ratio":0.9}}

//|   - case: default

//|       - {"artifact":"sweep","path":"/rows/13/2","equals":"IterationLimit"}
//|   - case: strong
//|     expect:
//|       - {"artifact":"sweep","path":"/rows/8/1","equals":31}
use scioxide_core::{Budget, NumericScalar, RealScalar};
use scioxide_optimize::{CompositeProblem, Fista, ProximalOptions, SmoothGradient};
let (loss, _) = lasso_data().map_err(|e| e.to_string())?;
let n = loss.n;
let zero = vec![0.0; n];
let mut gradient = vec![0.0; n];
loss.gradient_into(&zero, &mut gradient)
    .map_err(|e| e.to_string())?;
let lambda_max = gradient
    .iter()
    .fold(0.0, |m, &g| RealScalar::max(m, NumericScalar::abs(g)));
let lambda = ratio * lambda_max;
let lipschitz = loss.a.iter().map(|v| v * v).sum::<f64>();

let fista = Fista::new(ProximalOptions::new(lipschitz).with_max_iterations(limit))

    .map_err(|e| e.to_string())?;
let mut rows = Vec::new();
let mut points = Vec::new();
for k in -8..=8 {
    // ρ = 10^(k/4)、k = −8, …, 8。

    let admm = solve_admm(&loss, lambda, rho, limit).map_err(|e| e.to_string())?;
    let kkt = kkt_violation(&loss, lambda, admm.z()).map_err(|e| e.to_string())?;

    rows.push((rho, admm.iterations(), admm.termination().to_string(), kkt));
}

        "yLabel": "反復 [回]",
        "xType": "log",
        "yType": "log",
        "annotations": [{
            "kind": "line",
            "axis": "y",
            "value": fista.iterations(),
            "label": "FISTA の反復",
            "style": { "lineType": "dashed" }
        }]
    })
);
```

既定の $\lambda/\lambda_{\max}=0.1$ では、反復回数は $\rho\approx0.18$ で最小の 64 回になり、そこから離れると両側で増える。
$\rho=0.01$ では 990 回、$\rho=10$ では 2821 回で、両対数軸の上ではおよそ傾き $-1$ と $+1$ の直線に近い。
$\rho\ge17.8$ では 3000 回の上限で `IterationLimit` になり、KKT 違反は $\rho=17.8$ で $2.5\times10^{-6}$、$\rho=100$ で $7.4\times10^{-3}$ と大きくなる。

$\lambda/\lambda_{\max}=0.9$ では最小が $\rho=1$ の 31 回に移り、良い $\rho$ は $\lambda$ によって変わる。
`AdmmOptions::with_residual_balancing` は、二つの残差の比に応じて $\rho$ を反復中に変える残差均衡を有効にし、この調整を自動化する。

## まとめ

FISTA の勾配写像 $G$ と ADMM の残差 $\|r\|$、$\|s\|$ は KKT 違反そのものではないが、$(1+\sqrt n)G$ と $L\|r\|+\|s\|$ で KKT 違反を上から押さえる。
返った係数を代入した KKT 違反は、ソルバーのレポートとは独立にこの上界と照合できる。
終了理由が `IterationLimit` のときは、係数が収束した解に近く見えても、KKT 違反の大きさで精度を判断する。
ADMM の反復数は $\rho$ で桁が変わるので、固定の $\rho$ で FISTA と速さを比べた結果は、その $\rho$ についての結果として解釈する。
FISTA は $O(mn)$ の反復を、ADMM は一度の Cholesky 分解のあと $O(n^2)$ の反復を回すので、どちらが速いかは $m$、$n$、$\lambda$、$\rho$ による。
