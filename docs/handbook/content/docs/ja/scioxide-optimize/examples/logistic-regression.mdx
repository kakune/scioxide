反応する・しない、合格・不合格のような二値の結果について、説明量から事象の起こる確率を予測する代表的なモデルがロジスティック回帰である。
このページでは用量と反応の例で、Bernoulli 分布の負の対数尤度から目的関数と勾配を導き、あふれない計算を `scioxide_core::softplus` と `scioxide_core::sigmoid` に任せて BFGS 法で係数を求める。
解は設計の対称性から導いた切片 $\beta_0=0$ と照合し、解析式のヘッセ行列で係数の決まりやすさを読む。
両クラスが用量で完全に分かれるデータでは有限の最尤推定値がなくなり、その扱いは[完全分離とリッジ正則化経路](../logistic-separation-path/)で調べる。

## 線形予測子から確率への変換

薬剤の用量、温度、部品の寸法などの説明量 $x$ から、反応するかどうか $Y\in\{0,1\}$ の確率を推定したい。
線形予測子

$$
z=\beta_0+\beta_1x
$$

は任意の実数を取るので、そのままでは確率にならない。
ロジスティック関数

$$
p(x)=\sigma(z)=\frac1{1+e^{-z}}
$$

に通すと $0<p<1$ になる。
オッズ $p/(1-p)$ の対数を取ると

$$
\log\frac{p(x)}{1-p(x)}=\beta_0+\beta_1x
$$

なので、$\beta_1$ は $x$ が 1 単位増えたときの対数オッズの変化、$e^{\beta_1}$ はそのときのオッズ比である。
$\beta_0$ は無次元、$\beta_1$ は $x$ の逆数の単位を持つ。

## 尤度から目的関数を導く

各用量 $x_i$ で $n_i$ 回試行し、成功の割合を $y_i$ とする。
成功回数は $n_iy_i$ で、定数を除いた負の対数尤度は

$$
L(\beta)
=-\sum_i n_i
\{y_i\log p_i+(1-y_i)\log(1-p_i)\}
$$

である。
これは観測の割合と予測確率の交差エントロピーを重み $n_i$ で足したものに等しい。
$p_i=\sigma(z_i)$ を代入すると、一つの群の寄与は

$$
n_i\bigl\{\log(1+e^{z_i})-y_iz_i\bigr\}
$$

になる。
しかし $z_i$ が大きいと $e^{z_i}$ が桁あふれする。
softplus を

$$
\log(1+e^z)
=\max(z,0)+\log\bigl(1+e^{-|z|}\bigr)
$$

と計算すれば、指数関数へ渡す値は常に 0 以下になる。
数学的には同じ式だが、浮動小数点ではあふれを防ぐためにこの変形が要る。
`scioxide_core::softplus` はこの形で、`scioxide_core::sigmoid` は $e^{-|z|}$ だけを計算する形で実装されており、どちらも実数の引数で 16 ulp 以内の精度を持つ。
どちらも非有限の入力には `NonFinite` のエラーを返す。

傾きにリッジペナルティを加えた

$$
\Phi(\beta)
=L(\beta)+\frac{\lambda}{2}\beta_1^2
$$

を最小化する。
勾配は

$$
\nabla\Phi
=\sum_i n_i(p_i-y_i)
\begin{pmatrix}1\\x_i\end{pmatrix}
+\lambda
\begin{pmatrix}0\\\beta_1\end{pmatrix},
$$

ヘッセ行列は

$$
H=\sum_i n_ip_i(1-p_i)
\begin{pmatrix}1\\x_i\end{pmatrix}
\begin{pmatrix}1&x_i\end{pmatrix}
+\lambda
\begin{pmatrix}0&0\\0&1\end{pmatrix}
$$

である。
有限の $\beta$ では $p_i(1-p_i)>0$ なので、異なる用量が 2 つ以上あれば第一項は正定値で、$\Phi$ は狭義凸になる。
したがって最小点があれば一つに決まる。
最小点があるかどうかはデータで決まり、両クラスが用量で完全に分かれると $\lambda=0$ では最小点がない。
切片にはペナルティを付けないので、全群が同じクラスなら $\lambda>0$ でも切片の有限な最適値はない。

## 対称な設計と切片の検算

この例の用量は $x\mapsto-x$ で対称に並び、成功の割合は $y\mapsto1-y$ で反転する。
$x$ と $-x$ の群の組では $\mathrm{softplus}(-u)=\mathrm{softplus}(u)-u$ から $\Phi(\beta_0,\beta_1)=\Phi(-\beta_0,\beta_1)$ が成り立つ。
狭義凸な関数の最小点は一つなので、その切片は $\beta_0=0$ でなければならず、そのとき $p(0)=1/2$ になる。
これを BFGS の解の独立な検算に使う。

1 回の目的と勾配の評価は用量の群の数 $m$ に比例する $O(m)$ の計算である。
BFGS は逆ヘッセ行列の $2\times2$ の近似を持ち、1 反復の更新は $O(n^2)$（ここでは $n=2$）で済む。
停止判定は勾配の Euclid ノルム $\lVert\nabla\Phi\rVert_2$ を既定の許容誤差 $\sqrt\varepsilon\,(1+s)$ と比べる。
ここで $\varepsilon$ は倍精度の計算機イプシロン、$s=\max\bigl(1,|\Phi|/\max(1,\lVert\beta\rVert_\infty)\bigr)$ は目的の尺度である。

## 係数とヘッセ行列の計算

負側と正側に 4 群ずつ、計 8 群の用量 $x=\pm0.4,\pm1,\pm2,\pm3$ を置く。
規格化した用量 $x$ は無次元で、$\lambda$ も無次元である。
境界に最も近い 2 群（$x=\pm0.4$）だけに反対クラスを割合 $f$ で混ぜ、成功の割合を $x<0$ の群で $(0,0,0,f)$、$x>0$ の群で $(1-f,1,1,1)$ とする。
$f=0$ なら両クラスが完全に分かれる。
各群に同じ重み $n=20$ を与えるので、重みと割合の積が整数なら集約した二項データの尤度に一致する。
入力は連続の割合も許すので、すべての設定が実在する成功回数を表すわけではない。

入力は反対クラスの割合 $f$、リッジ係数の指数 $q=\log_{10}\lambda$、切片と傾きの初期値である。
出力は係数の表と、目的と曲率の表である。
ヘッセ行列の固有値は上の解析式から計算した独立な値で、BFGS の内部の近似は使わない。
最後の判定は `OptimizeResult::is_success()` に従う。
このセルは係数を次の確率曲線のセルへ渡す。

```rust
//| id: optimize-logistic-regression
//| ref: optimize-logistic-regression
//| title: ロジスティック回帰の重なり・リッジ・初期値を動かす
//| run: reactive
//| crates: [scioxide-core, scioxide-optimize]
//| exports: [intercept, slope, groups]
//| inputs:
//|   overlap_fraction: {"type":"range","label":"境界の群の反対クラス割合 f [-]","description":"完全分離から重なるデータへ変える。","min":0,"max":0.45,"step":0.025,"value":0.1}
//|   logistic_regularization_exponent: {"type":"range","label":"リッジ係数の指数 q = log₁₀ λ [-]","description":"傾きを縮める強さを対数尺度で変える。","min":-6,"max":1,"step":0.5,"value":-2}
//|   logistic_initial_intercept: {"type":"range","label":"切片の初期値 β₀ [-]","description":"反復の開始点を変える。","min":-5,"max":5,"step":0.5,"value":1}
//|   logistic_initial_slope: {"type":"range","label":"傾きの初期値 β₁ [-]","description":"反復開始時の確率曲線の向きを変える。","min":-6,"max":6,"step":0.5,"value":-1}
//| cases:
//|   - {"id":"complete-separation","label":"反対クラス割合 0（完全分離）","description":"同じ λ = 10⁻² で傾きは 5.645 から 12.18 に増え、ヘッセ行列の最小固有値は 0.70 から 0.058 へ下がるが、条件数は 5.16 とほとんど変わらない。","inputs":{"overlap_fraction":0}}
//|   - {"id":"strong-ridge","label":"リッジ係数の指数 q = 1（λ = 10）","description":"ペナルティが尤度に勝って傾きは 1.553 まで縮み、ヘッセ行列の最小固有値は 16.9、条件数は 1.61 になる。","inputs":{"logistic_regularization_exponent":1}}
//|   - {"id":"far-start","label":"初期値 (β₀, β₁) = (5, 6)","description":"開始点を変えても係数は 10⁻⁸ 以内で同じ値に達し、変わるのは反復回数だけである。","inputs":{"logistic_initial_intercept":5,"logistic_initial_slope":6}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"coefficients","path":"/rows/0/0","range":{"min":-1e-6,"max":1e-6}}
//|       - {"artifact":"coefficients","path":"/rows/0/1","approx":{"value":5.64507,"atol":1e-5}}
//|       - {"artifact":"curvature","path":"/rows/0/0","approx":{"value":13.1515,"atol":1e-4}}
//|       - {"artifact":"curvature","path":"/rows/0/1","approx":{"value":0.159334,"atol":1e-5}}
//|       - {"artifact":"curvature","path":"/rows/0/2","approx":{"value":0.70089,"atol":1e-4}}
//|       - {"artifact":"curvature","path":"/rows/0/3","approx":{"value":5.0919,"atol":1e-3}}
//|       - {"artifact":"curvature","path":"/rows/0/4","range":{"min":0,"max":1e-6}}
//|       - {"path":"/outputs/2/state","equals":"satisfied"}
//|   - case: complete-separation
//|     expect:
//|       - {"artifact":"coefficients","path":"/rows/0/1","approx":{"value":12.18004,"atol":1e-4}}
//|       - {"artifact":"curvature","path":"/rows/0/2","approx":{"value":0.05847,"atol":1e-4}}
//|       - {"artifact":"curvature","path":"/rows/0/3","approx":{"value":5.1627,"atol":1e-3}}
//|   - case: strong-ridge
//|     expect:
//|       - {"artifact":"coefficients","path":"/rows/0/1","approx":{"value":1.55313,"atol":1e-5}}
//|       - {"artifact":"curvature","path":"/rows/0/2","approx":{"value":16.872,"atol":1e-2}}
//|   - case: far-start
//|     expect:
//|       - {"artifact":"coefficients","path":"/rows/0/1","approx":{"value":5.64507,"atol":1e-5}}
//|       - {"path":"/outputs/2/state","equals":"satisfied"}
use scioxide_core::{SciOxideError, RealScalar, sigmoid, softplus};
use scioxide_optimize::{Bfgs, ObjectiveFn, OptimizeTermination};

// σ(z) と softplus(z) = log(1 + e^z) は、指数があふれない scioxide_core の関数で計算する。
// 8 群、各群の重み n = 20。境界の 2 群（x = ±0.4）だけに反対クラスを混ぜる。
let doses = [-3.0_f64, -2.0, -1.0, -0.4, 0.4, 1.0, 2.0, 3.0];
let f = overlap_fraction;
let props = [0.0_f64, 0.0, 0.0, f, 1.0 - f, 1.0, 1.0, 1.0];
let n = 20.0_f64;
let lambda = RealScalar::powf(10.0_f64, logistic_regularization_exponent);
// L(β) = Σ n{softplus(zᵢ) − yᵢzᵢ}、Φ = L + (λ/2)β₁²、∇Φ = Σ n(pᵢ − yᵢ)(1, xᵢ) + (0, λβ₁)。
let nll = move |b: &[f64]| -> Result<f64, SciOxideError> {
    let mut total = 0.0;
    for (&x, &y) in doses.iter().zip(&props) {
        let z = b[0] + b[1] * x;
        total += n * (softplus(z)? - y * z);
    }
    Ok(total)
};
let objective = ObjectiveFn::new(2, move |b: &[f64]| Ok(nll(b)? + 0.5 * lambda * b[1] * b[1]))
    .with_gradient(move |b: &[f64], g: &mut [f64]| {
        g[0] = 0.0;
        g[1] = lambda * b[1];
        for (&x, &y) in doses.iter().zip(&props) {
            let d = n * (sigmoid(b[0] + b[1] * x)? - y);
            g[0] += d;
            g[1] += d * x;
        }
        Ok(())
    });
let start = [logistic_initial_intercept, logistic_initial_slope];
let result = Bfgs::<f64>::default()
    .minimize(&objective, &start)
    .map_err(|e| e.to_string())?;
let (b0, b1) = (result.x()[0], result.x()[1]);
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let digits6 = serde_json::json!({ "significantDigits": 6 });
let digits4 = serde_json::json!({ "significantDigits": 4 });
let coefficient_columns = serde_json::json!([
    { "key": "0", "label": "切片 β₀ [-]", "type": "number", "format": sci2 },
    { "key": "1", "label": "傾き β₁ [-]", "type": "number", "format": digits6 },
    { "key": "2", "label": "オッズ比 e^β₁ [-]", "type": "number", "format": digits4 }
]);
emit_table_with_columns!(
    coefficient_columns,
    vec![(b0, b1, RealScalar::exp(b1))],
    metadata = serde_json::json!({ "id": "coefficients" })
);
// 独立な曲率の診断: 解析ヘッセ行列 H = Σ n p(1−p)(1, x)(1, x)ᵀ + diag(0, λ) の固有値。
let (mut h00, mut h01, mut h11) = (0.0_f64, 0.0_f64, lambda);
for &x in &doses {
    let px = sigmoid(b0 + b1 * x).map_err(|e| e.to_string())?;
    let w = n * px * (1.0 - px);
    h00 += w;
    h01 += w * x;
    h11 += w * x * x;
}
let disc = RealScalar::hypot(h00 - h11, 2.0 * h01);
let (largest, smallest) = (0.5 * (h00 + h11 + disc), 0.5 * (h00 + h11 - disc));
let gradient = result.grad().ok_or("BFGS が勾配を返さなかった")?;
// 停止判定と同じ Euclid ノルム ‖∇Φ‖₂。
let gradient_norm = RealScalar::hypot(gradient[0], gradient[1]);
let curvature_columns = serde_json::json!([
    { "key": "0", "label": "負の対数尤度 L [-]", "type": "number", "format": digits6 },
    { "key": "1", "label": "ペナルティ (λ/2)β₁² [-]", "type": "number", "format": digits4 },
    { "key": "2", "label": "H の最小固有値 [-]", "type": "number", "format": digits4 },
    { "key": "3", "label": "H の条件数 [-]", "type": "number", "format": digits4 },
    { "key": "4", "label": "‖∇Φ‖₂ [-]", "type": "number", "format": sci2 },
    { "key": "5", "label": "反復 [回]", "type": "integer" },
    { "key": "6", "label": "目的の評価 [回]", "type": "integer" }
]);
emit_table_with_columns!(
    curvature_columns,
    vec![(
        nll(result.x()).map_err(|e| e.to_string())?,
        0.5 * lambda * b1 * b1,
        smallest,
        largest / smallest,
        gradient_norm,
        result.iterations(),
        result.fun_evals(),
    )],
    metadata = serde_json::json!({ "id": "curvature" })
);
export!(intercept, &b0);
export!(slope, &b1);
let groups: Vec<[f64; 2]> = doses.iter().zip(&props).map(|(&x, &y)| [x, y]).collect();
export!(groups, &groups);
let termination = result.termination();
let outcome = if result.is_success() {
    Outcome::satisfied("勾配の停止判定を満たした")
} else if matches!(termination, OptimizeTermination::LineSearchFailed(_)) {
    Outcome::failed("直線探索が受理できる刻みを見つけられなかった")
} else {
    Outcome::partial("停止判定を満たす前に止まり、最後に受理した点を返した")
};
emit_outcome!(
    outcome
        .status(termination.to_string())
        .diagnostic("‖∇Φ‖₂", gradient_norm, None)
        .diagnostic("反復", result.iterations() as f64, Some("回"))
);
```

既定の入力（$f=0.1$、$\lambda=10^{-2}$）では、BFGS は 18 回の反復で `GradientSmall` に達し、$\beta_0=1.2\times10^{-9}$、$\beta_1=5.645$、オッズ比 283 を返す。
切片は対称性から導いた $\beta_0=0$ と勾配の許容誤差の範囲で一致し、$p(0)=0.5$ になる。
負の対数尤度は 13.15、ペナルティは 0.159 で、解析ヘッセ行列の最小固有値は 0.70、条件数は 5.09 になる。
切片の初期値を $\pm5$、傾きの初期値を $\pm6$ にしても係数は $10^{-8}$ 以内で同じ値に達し、変わるのは反復回数（7〜18 回）だけである。

反対クラスの割合を 0（完全分離）にすると、同じ $\lambda=10^{-2}$ で $\beta_1=12.18$、オッズ比は $1.9\times10^5$ に増える。
多くの群で $p(1-p)$ が 0 へ近づき、ヘッセ行列の最小固有値は 0.058 へ下がる。
条件数は 5.16 とほとんど変わらないが、これは二つの固有値がそろって小さくなるためで、曲率の大きさ（母数の決まりやすさ）は一桁以上失われている。
条件数だけを見ると、母数が決まりにくくなったことを見落とす。
逆にリッジ係数の指数を 1（$\lambda=10$）にすると、ペナルティが尤度に勝って傾きは 1.553 まで縮み、最小固有値は 16.9 に増える。

## 確率曲線と代表点の確率

大きなオッズ比が大きな確率の差を意味するとは限らない。
用量に対する確率の傾き

$$
\frac{dp}{dx}=\beta_1p(1-p)
$$

は $p=1/2$ で最大の $\beta_1/4$ になり、確率が 0 や 1 に近い端では小さい。
次のセルは前のセルの係数を受け取り、確率曲線 $p(x)$ を群の成功割合と重ねて描き、$x=-1,0,1$ での $p(x)$ と $dp/dx$ を表にする。
このセルは自分の入力を持たず、前のセルの入力に従って描き直される。

```rust
//| id: optimize-logistic-probability-curve
//| ref: optimize-logistic-probability-curve
//| title: 当てはめた確率曲線と代表点の確率の傾き
//| run: reactive
//| crates: [scioxide-core]
//| dependsOn:
//|   fit: optimize-logistic-regression
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"probabilities","path":"/rows/1/1","approx":{"value":0.5,"atol":1e-6}}
//|       - {"artifact":"probabilities","path":"/rows/1/2","approx":{"value":1.41127,"atol":1e-4}}
use scioxide_core::sigmoid;

let b0 = fit["intercept"].as_f64().ok_or("切片がない")?;
let b1 = fit["slope"].as_f64().ok_or("傾きがない")?;
let groups: Vec<[f64; 2]> =
    serde_json::from_value(fit["groups"].clone()).map_err(|e| e.to_string())?;
let p = |x: f64| sigmoid(b0 + b1 * x).map_err(|e| e.to_string());
let mut curve = Vec::new();
for i in 0..=240 {
    let x = -3.5 + 7.0 * i as f64 / 240.0;
    curve.push([x, p(x)?]);
}
emit_chart!(
    serde_json::json!({
        "kind": "xy",
        "dataZoom": true,
        "tooltip": true,
        "xLabel": "規格化した用量 x [-]",
        "yLabel": "反応確率・成功割合 [-]",
        "yMin": 0.0,
        "yMax": 1.0,
        "layers": [
            { "id": "model", "kind": "line", "name": "当てはめた反応確率 p(x)", "points": curve },
            { "id": "groups", "kind": "scatter", "name": "群の成功割合", "points": groups }
        ]
    }),
    metadata = serde_json::json!({ "id": "fit" })
);
// dp/dx = β₁p(1 − p) は p = 1/2 で最大の β₁/4 になる。
let mut probabilities = Vec::new();
for x in [-1.0_f64, 0.0, 1.0] {
    let px = p(x)?;
    probabilities.push((x, px, b1 * px * (1.0 - px)));
}
let digits6 = serde_json::json!({ "significantDigits": 6 });
let digits4 = serde_json::json!({ "significantDigits": 4 });
let probability_columns = serde_json::json!([
    { "key": "0", "label": "用量 x [-]", "type": "number" },
    { "key": "1", "label": "確率 p(x) [-]", "type": "number", "format": digits6 },
    { "key": "2", "label": "dp/dx = β₁p(1 − p) [-]", "type": "number", "format": digits4 }
]);
emit_table_with_columns!(
    probability_columns,
    probabilities,
    metadata = serde_json::json!({ "id": "probabilities" })
);
```

図の記号は個々の 0/1 ではなく群の成功割合である。
各群に重み 20 を掛けるので、データ項の影響は単位重みの 20 倍になる。
成功回数が整数になる設定では、各群を 20 回の試行として読める。
曲線が群の割合を滑らかにつなぐのは補間ではなく、2 母数の確率モデルでデータを要約した結果である。

既定の入力では $p(0)=0.5$ で、$x=0$ の傾きが $\beta_1/4=1.41$ なのに対し、$x=\pm1$ では 0.020 にすぎない。
確率の表の $p(x)$ と $dp/dx$ を係数と並べると、実際の確率の尺度で効果を読める。

## 予測性能と前処理

訓練データの負の対数尤度が小さいほど、未知のデータでの性能が良いとは限らない。
$\lambda$ は交差検証や外部のデータで選び、分類の閾値は誤判定の損失から別に決める。
クラスの比率に偏りがあれば、正解率だけでなく対数損失、確率の較正、適合率と再現率も見る。

説明量を平行移動すると切片の意味が、尺度を変えると傾きとペナルティの意味が変わる。
標準化の規則を学習時と予測時で共有し、係数、前処理、$\lambda$、終了の診断を一組として保存する。

## まとめ

ロジスティック回帰の目的関数と勾配は Bernoulli 尤度から導け、あふれない計算には `scioxide_core::softplus` と `scioxide_core::sigmoid` を使う。
対称な設計では切片が 0 になるので、BFGS の解をこの値と照合して確かめられる。
係数はオッズ比だけでなく代表点の確率と $dp/dx$ でも読み、ヘッセ行列は条件数だけでなく最小固有値の大きさも確かめる。
完全分離に近いデータでは、`GradientSmall` で止まった係数でも $\lambda$ に強く依存するので、正則化経路で有限の極限があるかを確かめてから返す。
