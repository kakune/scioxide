ロジスティック回帰では、両クラスが説明量で完全に分かれるデータは当てはまりがよく見えるが、有限の最尤推定値を持たない。
このときペナルティを付けた最適化は勾配が小さい点で正常に止まるが、その係数はペナルティの強さで決まった値にすぎない。
このページでは[二値反応をロジスティック回帰で推定する](../logistic-regression/)と同じ 8 群の用量のデータで、リッジ係数 $\lambda$ を $10^{-6}$ から $10$ まで掃引した傾きの経路を BFGS 法で求める。
重なりのあるデータでは経路が有限の値に止まり、完全分離では $\log(1/\lambda)$ にほぼ比例して増え続けることを、漸近式と照合して確かめる。

## 完全分離で最尤推定値がなくなる理由

負例がすべて $x<0$、正例がすべて $x>0$ にあるとする。
これを完全分離と呼ぶ（Albert と Anderson, 1984）。
$\beta_0=0$ のまま $\beta_1\to+\infty$ とすると、すべての群の予測確率が観測と同じ側の端へ近づき、負の対数尤度 $L$ は単調に減って 0 に近づく。
$L$ はどの有限の $\beta$ でも正なので、下限 0 に達する有限の点はなく、最尤推定値は存在しない。
分類の誤りがないことは、母数を精密に推定できたことを意味しない。

リッジペナルティ $\tfrac{\lambda}{2}\beta_1^2$ は大きい傾きに代価を課し、$\lambda>0$ なら $\beta_1$ を有限に留める。
これは反復を安定にする工夫ではなく、傾きが極端に大きくないというモデルの仮定である。
$\lambda$ を変えれば確率の較正と係数の解釈が変わる。

反対クラスを境界の群に少しでも混ぜると、$\beta_1\to\infty$ で反対クラスの観測の対数尤度が $-\infty$ へ向かうので、$\lambda=0$ でも有限の最小点がある。
その場合、$\lambda\to0$ の経路はペナルティのない最尤推定値へ収束して平坦になる。

## 完全分離での傾きの漸近式

完全分離では、最適点で勾配の $\beta_1$ 成分が 0 になる条件

$$
\lambda\beta_1=\sum_i n_i(y_i-p_i)x_i
$$

の右辺を、大きい $\beta_1$ について近似できる。
対称な設計では $\beta_0=0$ で、$x>0$ の群の誤差は $1-\sigma(\beta_1x)\approx e^{-\beta_1x}$、$x<0$ の群も同じ大きさになる。
右辺は境界に最も近い 2 群 $x=\pm x_m$（ここでは $x_m=0.4$）が支配し、次に近い $x=\pm1$ の群の寄与でも、境界の群の $e^{-(1-x_m)\beta_1}/x_m$ 倍にすぎない。
各群の重みを $n$ とすると

$$
\lambda\beta_1\approx2nx_me^{-x_m\beta_1}
$$

になる。
両辺の対数を取ると $x_m\beta_1+\log\beta_1=\log(2nx_m/\lambda)$ になる。
$\lambda$ を 1 桁下げるたびに左辺は $\log10$ だけ増えるので、傾きの増分は $\log10/x_m\approx5.76$ より、$\log\beta_1$ の増加分を $x_m$ で割った量だけ小さい。
傾きは $\lambda\to0$ で有限の極限を持たず、$\log(1/\lambda)$ にほぼ比例して増え続ける。
1 桁あたりの増分は境界の 2 群の位置 $x_m$ で決まり、その外側の群の配置にはほとんどよらない。

## 経路の計算

$\lambda=10^{q}$、$q=-6,-5.75,\dots,1$ の 29 点で、各点を同じ初期値 $(0,1)$ から独立に BFGS で解く。
入力は境界の群の反対クラスの割合 $f$ と、一群の試行数 $n$ である。

出力は傾きの経路と、解析ヘッセ行列の最小固有値の経路の二つの図、4 点おきの表である。
二つの図は同じ $\lambda$ を横軸に持つので、ズームとカーソルを連動させる。
完全分離（$f=0$）のときは、漸近式の解を二分法で求めて破線で重ね、表にも並べる。
重なりがあるときは漸近式が成り立たないので、表では「重なりあり」と示す。
成功しなかった点は経路に混ぜず、その $\lambda$ を添えてエラーを返す。

```rust
//| id: optimize-logistic-regularization-path
//| ref: optimize-logistic-regularization-path
//| title: データの重なりと試行数に対する正則化経路
//| run: reactive
//| crates: [scioxide-core, scioxide-optimize]
//| inputs:
//|   path_overlap_fraction: {"type":"range","label":"境界の群の反対クラス割合 f [-]","description":"完全分離の有無を変える。","min":0,"max":0.45,"step":0.025,"value":0.1}
//|   path_trials_per_group: {"type":"range","label":"一群の試行数 n [回]","description":"尤度の情報とペナルティの相対的な強さを変える。","min":2,"max":100,"step":2,"value":20}
//| cases:
//|   - {"id":"complete-separation","label":"反対クラス割合 0（完全分離）","description":"λ を 1 桁下げるごとに傾きが約 5 ずつ増え（λ = 10⁻² で 12.18、10⁻⁶ で 32.75）、λ ≤ 10⁻² では漸近式の解と 0.2% 以内で一致する。","inputs":{"path_overlap_fraction":0}}
//|   - {"id":"many-trials","label":"一群の試行数 n = 100","description":"尤度の項が 5 倍に強まり、同じ λ = 10⁻² の傾きは 5.645 から 5.711 へ、ペナルティのない値 5.728 に近づく。","inputs":{"path_trials_per_group":100}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"path","path":"/rows/0/2","approx":{"value":5.72836,"atol":1e-4}}
//|       - {"artifact":"path","path":"/rows/4/2","approx":{"value":5.64507,"atol":1e-4}}
//|       - {"artifact":"path","path":"/rows/7/2","approx":{"value":1.55313,"atol":1e-4}}
//|       - {"artifact":"path","path":"/rows/0/3","equals":null}
//|       - {"artifact":"path","path":"/rows/0/6","equals":"GradientSmall"}
//|   - case: complete-separation
//|     expect:
//|       - {"artifact":"path","path":"/rows/0/2","approx":{"value":32.748,"atol":1e-2}}
//|       - {"artifact":"path","path":"/rows/0/3","approx":{"value":32.748,"atol":2e-2}}
//|       - {"artifact":"path","path":"/rows/4/2","approx":{"value":12.1800,"atol":1e-3}}
//|   - case: many-trials
//|     expect:
//|       - {"artifact":"path","path":"/rows/4/2","approx":{"value":5.71125,"atol":1e-4}}
use scioxide_core::{RealScalar, sigmoid, softplus};
use scioxide_optimize::{Bfgs, ObjectiveFn};

let doses = [-3.0_f64, -2.0, -1.0, -0.4, 0.4, 1.0, 2.0, 3.0];
let f = path_overlap_fraction;
let props = [0.0_f64, 0.0, 0.0, f, 1.0 - f, 1.0, 1.0, 1.0];
let n = path_trials_per_group;
// 完全分離の漸近式 λβ = 2n·x_m·e^{−x_m β}（x_m = 0.4）の解を二分法で求める（独立な検算）。
let asymptote = |lambda: f64| {
    let (mut lo, mut hi) = (0.0_f64, 200.0_f64);
    for _ in 0..100 {
        let mid = 0.5 * (lo + hi);
        if lambda * mid > 2.0 * n * 0.4 * RealScalar::exp(-0.4 * mid) {
            hi = mid;
        } else {
            lo = mid;
        }
    }
    0.5 * (lo + hi)
};
let (mut slope, mut reference, mut eigen, mut rows) =
    (Vec::new(), Vec::new(), Vec::new(), Vec::new());
// λ = 10^{−6} … 10^{1} の 29 点。各点を同じ初期値 (0, 1) から独立に解く。
for k in 0..=28 {
    let lambda = RealScalar::powf(10.0_f64, -6.0 + 0.25 * k as f64);
    let objective = ObjectiveFn::new(2, move |b: &[f64]| {
        let mut total = 0.5 * lambda * b[1] * b[1];
        for (&x, &y) in doses.iter().zip(&props) {
            let z = b[0] + b[1] * x;
            total += n * (softplus(z)? - y * z);
        }
        Ok(total)
    })
    .with_gradient(move |b: &[f64], g: &mut [f64]| {
        g[0] = 0.0;
        g[1] = lambda * b[1];
        for (&x, &y) in doses.iter().zip(&props) {
            let d = n * (sigmoid(b[0] + b[1] * x)? - y);
            g[0] += d;
            g[1] += d * x;
        }
        Ok(())
    });
    let r = Bfgs::<f64>::default()
        .minimize(&objective, &[0.0, 1.0])
        .map_err(|e| e.to_string())?;
    if !r.is_success() {
        return Err(format!(
            "λ = {lambda:.1e} で成功しなかった: {}",
            r.termination()
        ));
    }
    let (b0, b1) = (r.x()[0], r.x()[1]);
    // 解析ヘッセ行列 H = Σ n p(1−p)(1, x)(1, x)ᵀ + diag(0, λ) の 2×2 固有値（独立な曲率の診断）。
    let (mut h00, mut h01, mut h11) = (0.0_f64, 0.0_f64, lambda);
    for &x in &doses {
        let p = sigmoid(b0 + b1 * x).map_err(|e| e.to_string())?;
        let w = n * p * (1.0 - p);
        h00 += w;
        h01 += w * x;
        h11 += w * x * x;
    }
    let disc = RealScalar::hypot(h00 - h11, 2.0 * h01);
    let (largest, smallest) = (0.5 * (h00 + h11 + disc), 0.5 * (h00 + h11 - disc));
    let predicted = (f == 0.0).then(|| asymptote(lambda));
    slope.push([lambda, b1]);
    eigen.push([lambda, smallest]);
    if let Some(value) = predicted {
        reference.push([lambda, value]);
    }
    if k % 4 == 0 {
        let termination = r.termination().to_string();
        rows.push((
            lambda,
            b0,
            b1,
            predicted,
            smallest,
            largest / smallest,
            termination,
        ));
    }
}
let mut series = vec![serde_json::json!({ "name": "BFGS の傾き β₁", "points": slope })];
if !reference.is_empty() {
    series.push(serde_json::json!({
        "name": "漸近式 λβ = 2n·x_m·e^(−x_m β)",
        "points": reference,
        "style": { "lineType": "dashed" }
    }));
}
emit_line_chart!(
    &series,
    options = &serde_json::json!({
        "link": { "group": "logistic-lambda" },
        "xLabel": "リッジ係数 λ [-]",
        "yLabel": "傾き β₁ [-]",
        "xType": "log"
    })
);
emit_line_chart!(
    &vec![serde_json::json!({ "name": "H の最小固有値", "points": eigen })],
    options = &serde_json::json!({
        "link": { "group": "logistic-lambda" },
        "xLabel": "リッジ係数 λ [-]",
        "yLabel": "ヘッセ行列の最小固有値 [-]",
        "xType": "log",
        "yType": "log"
    })
);
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let digits5 = serde_json::json!({ "significantDigits": 5 });
let digits4 = serde_json::json!({ "significantDigits": 4 });
let columns = serde_json::json!([
    { "key": "0", "label": "λ [-]", "type": "number", "format": sci2 },
    { "key": "1", "label": "切片 β₀ [-]", "type": "number", "format": sci2 },
    { "key": "2", "label": "傾き β₁ [-]", "type": "number", "format": digits5 },
    { "key": "3", "label": "漸近式 β₁ [-]", "type": "number", "format": digits5, "nullText": "重なりあり" },
    { "key": "4", "label": "H の最小固有値 [-]", "type": "number", "format": digits4 },
    { "key": "5", "label": "H の条件数 [-]", "type": "number", "format": digits4 },
    { "key": "6", "label": "終了状態" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "path" })
);
```

既定の重なり $f=0.1$ では、$\lambda$ を $10^{-3}$ 以下にすると傾きは 5.72〜5.73 で平坦になり、ペナルティのない最尤推定値が有限であることが分かる。
完全分離（$f=0$）では、$\lambda$ を 1 桁下げるごとに傾きが約 5 ずつ増え（$\lambda=10^{-2}$ で 12.18、$10^{-6}$ で 32.75）、経路は止まらない。
$\lambda=10^{-5}$ から $10^{-6}$ への増分は 5.31 で、$\log(32.75/27.43)/x_m=0.44$ を 5.76 から引いた 5.32 とほぼ一致する。
破線の漸近式は $\lambda\le10^{-2}$ で BFGS の傾きと 0.2% 以内で重なる。
$\lambda\ge1$ では傾きが小さく、$x=\pm1$ 以遠の群の寄与 $e^{-\beta_1}$ を無視できないので、漸近式は外れる。
どの $\lambda$ でも終了状態は `GradientSmall` である。
成功の終了は各 $\lambda$ の正則化した問題を解いたことを示すだけで、$\lambda\to0$ の極限に有限の解があることは示さない。

最小固有値の図では、完全分離のとき $\lambda$ を下げるほど曲率が小さくなり続ける。
重なりがあれば、最小固有値も傾きと同じく有限の値で平坦になる。

試行数 $n$ を増やすと尤度の項だけが比例して強くなり、同じ数値の $\lambda$ は相対的に弱くなる。
$n=100$ にすると、$\lambda=10^{-2}$ の傾きは 5.645 から 5.711 へ、ペナルティのない値 5.728 に近づく。
ペナルティを $\lambda$ で書くか $\lambda/n$ で書くかは実装によって異なるので、目的関数の式を明示しなければ同じ名前の母数でも結果を再現できない。

経路の各点は同じ初期値から独立に解いている。
大きな問題では直前の解を次の点の初期値にすると速いが、一つの点の失敗が隣の点へ伝わりうる。
その場合も各点の勾配と終了状態を確かめる。

## まとめ

完全分離したデータでは負の対数尤度が下限 0 に達する有限の点がなく、最尤推定値は存在しない。
リッジペナルティを付ければ各 $\lambda$ で BFGS は `GradientSmall` で止まるが、その傾きは $\lambda\beta_1\approx2nx_me^{-x_m\beta_1}$ に従って $\log(1/\lambda)$ にほぼ比例して増え続ける。
$\lambda$ を下げた経路が平坦部に止まるかどうかで、有限の最尤推定値があるかを判断できる。
止まらないときは、係数を推定値としてレポートせず、$\lambda$ をモデルの仮定として明示するか、データの分離そのものを結果として返す。
