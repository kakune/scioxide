Markowitz（1952）の平均分散モデルは、期待収益を大きくする目標と収益率の分散を小さくする目標を一つの目的関数にまとめる。
このページでは低変動資産と成長資産の二資産について、このモデルを凸二次計画問題（QP）として `QpSolver` で解く。
等式制約を消去した一変数の解析解で QP の配分を検算し、解が効率的フロンティアのどこに来るかを読む。
推定した相関や期待収益の誤差が配分をどれだけ動かすかは、[最適比率の感度](../portfolio-sensitivity/)で調べる。

## 平均分散モデル

低変動資産と成長資産へ割合 $w_1,w_2$ を配分し、

$$
w_1+w_2=1,\qquad 0\le w_1,w_2\le1
$$

とする。
全額を投資し、空売り（負の割合）と借入れ（1 を超える割合）を許さない。
一期間の収益率ベクトルを確率変数 $R$、期待値を $\mu=\operatorname E[R]$、共分散行列を $\Sigma$ とすると、ポートフォリオの収益率 $R_p=w^\mathsf TR$ は

$$
\operatorname E[R_p]=\mu^\mathsf Tw,
\qquad
\operatorname{Var}(R_p)=w^\mathsf T\Sigma w
$$

を持つ。
期待収益だけを見るなら、最大の $\mu_i$ を持つ資産へ全額を置けばよい。
変動も嫌う投資家を表す最も単純な折衷は

$$
\min_w
\left\{
\frac{\lambda}{2}w^\mathsf T\Sigma w-\mu^\mathsf Tw
\right\},
\qquad \lambda>0
$$

である。
$\lambda$ はリスク回避度で、大きいほど分散を強く罰する。
目的の第一項は収益率の二乗、第二項は収益率の次元を持つので、$\lambda$ は収益率の逆数の次元を持ち、その値は期間と収益の単位に依存する。
百分率と小数を混ぜると、同じ配分を表す $\lambda$ が 100 倍ずれる。

例題の資産は、低変動資産が $\mu_1=0.03$、$\sigma_1=0.08$、成長資産が $\mu_2=0.09$（既定値）、$\sigma_2=0.20$ を持つ。
これらは説明用の仮想値で、収益率は 1 年あたりの値を小数で表した年率（0.03 は年 3%）、標準偏差も同じ年率の単位で表す。
[平均分散モデルの効率的フロンティア](../efficient-frontier/)の資産 1 と同じ $\mu_1$、$\sigma_1$ を使う。

SciOxide の `QpProblem` は

$$
\frac12w^\mathsf TQw+c^\mathsf Tw
$$

を最小化するので、$Q=\lambda\Sigma$、$c=-\mu$ と渡す。
和の等式は 1 行の `LinearConstraints`、$0\le w_i\le1$ は `Bounds` で与える。

## 共分散行列と凸性

標準偏差を $\sigma_1,\sigma_2$、相関を $\rho$ とすると

$$
\Sigma=
\begin{pmatrix}
\sigma_1^2&\rho\sigma_1\sigma_2\\
\rho\sigma_1\sigma_2&\sigma_2^2
\end{pmatrix}
$$

である。
$|\rho|\le1$ なら

$$
\det\Sigma=\sigma_1^2\sigma_2^2(1-\rho^2)\ge0
$$

で、対角成分も非負だから $\Sigma$ は半正定値である。
したがって目的は凸関数で、可行集合も凸集合なので、局所最小は大域最小になる。
`QpProblem::new` は厳密に対称な $Q$ だけを受け付け、対称でなければ `InvalidInput` を返す。
`QpSolver` は解く前に $Q$ が半正定値かを確かめ、許容誤差を超える負の固有値を持つ $Q$ も `InvalidInput` のエラーで拒む。
丸めや不整合な推定から組み立てた共分散行列は負の固有値を持つことがあるので、相関の範囲、対称性、固有値を入力の段階で確かめる。

相関が 1 未満なら、二資産を混ぜた分散は完全正相関の場合より小さい。
ただし、混ぜた分散がどちらの単独資産より小さくなるとは限らない。
$\sigma_1<\sigma_2$ のとき、低変動資産だけの点から成長資産を少し混ぜて分散が減る条件は $\rho\sigma_2<\sigma_1$ である。
既定の $\rho=0.25$ では $\rho\sigma_2=0.05<0.08$ なので分散を下げる余地があり、$\rho\ge0.4$ ではこの余地がなくなる。

## 一変数への消去と解析解

$z=w_2$、$w_1=1-z$ と置くと、和の等式は $z$ によらず成り立つ。
共分散を $\sigma_{12}=\rho\sigma_1\sigma_2$ とすれば、分散は

$$
V(z)=\sigma_1^2(1-z)^2
+2\sigma_{12}z(1-z)+\sigma_2^2z^2
$$

である。
目的 $\tfrac{\lambda}{2}V(z)-\mu_1-(\mu_2-\mu_1)z$ を $z$ で微分して 0 と置くと、上下限を外した解は

$$
z_{\mathrm{free}}
=z_{\mathrm{mv}}+\frac{\mu_2-\mu_1}{\lambda D},
\qquad
z_{\mathrm{mv}}=\frac{\sigma_1^2-\sigma_{12}}{D},
\qquad
D=\sigma_1^2-2\sigma_{12}+\sigma_2^2
$$

になる。
$D=\operatorname{Var}(R_2-R_1)$ は $(\sigma_1-\sigma_2)^2$ 以上なので、$\sigma_1\ne\sigma_2$ なら正で、目的は $z$ の狭義凸な二次関数である。
$z_{\mathrm{mv}}$ は分散だけを最小にする比率（$\lambda\to\infty$ の極限）で、$\lambda$ を下げるほど解は成長資産の側へ $(\mu_2-\mu_1)/(\lambda D)$ だけ移る。
$z_{\mathrm{free}}$ は、和の等式だけを課して空売りと借入れを許したときの最適比率でもある。

一変数の狭義凸な二次関数なので、区間 $[0,1]$ 上の最小点は頂点を区間へ射影した

$$
z^\star=\min\bigl(1,\max(0,z_{\mathrm{free}})\bigr)
$$

である。
$z_{\mathrm{free}}>1$ なら上限 $w_2\le1$、$z_{\mathrm{free}}<0$ なら上限 $w_1\le1$ が活性（等号で成り立つ制約）になる。
この式は QP の KKT 系を解き直さないので、QP の配分の独立な検算に使える。

既定の入力では $D=0.0384$、$z_{\mathrm{mv}}=0.0625$、$(\mu_2-\mu_1)/(\lambda D)=0.390625$ で、$z^\star=z_{\mathrm{free}}=0.453125$ になる。

## 配分の計算と検算

成長資産の期待収益 $\mu_2$、相関 $\rho$、リスク回避度 $\lambda$ を動かして QP を解く。
和の等式という一般の行制約があるので、`QpSolver` の既定の `QpMethod::Automatic` は[有効集合法](../../algorithms/quadratic-programming/)を使い、終了時に元の問題で KKT 条件の証明用データを検算する。

一つ目の表は QP の解、区間へ射影した解析解 $z^\star$、空売りを許す解 $z_{\mathrm{free}}$ の配分を並べる。
二つ目の表は解析解との差、和の等式の残差、`ProgrammingResult` の診断値、証明用データの検算の状態、反復回数を示す。
最後の判定は `ProgrammingResult::is_success()` に従う。
このセルは資産のパラメータと解を次の図のセルへ渡す。

```rust
//| id: optimize-portfolio-qp
//| ref: optimize-portfolio-qp
//| title: 期待収益・相関・リスク回避度を動かして凸 QP を解く
//| run: reactive
//| crates: [scioxide-core, scioxide-linalg, scioxide-optimize]
//| exports: [mu, sd, correlation, risk_aversion, weight, free]
//| inputs:
//|   growth_expected_return: {"type":"range","label":"成長資産の期待収益 μ₂ [年率]","description":"成長資産を持つ利点を変える。","min":0.04,"max":0.16,"step":0.005,"value":0.09}
//|   asset_correlation: {"type":"range","label":"資産の相関 ρ [-]","description":"分散を下げる効果と共分散を変える。","min":-0.8,"max":0.95,"step":0.05,"value":0.25}
//|   risk_aversion: {"type":"range","label":"リスク回避度 λ [-]","description":"分散の罰と期待収益の交換比を変える。","min":0.2,"max":20,"step":0.2,"value":4}
//| cases:
//|   - {"id":"low-risk-aversion","label":"リスク回避度 λ = 0.2","description":"上下限を外した解は z_free = 7.875 で区間の外にあり、QP は上限 w₂ = 1 を返して変数の上限が活性になる。","inputs":{"risk_aversion":0.2}}
//|   - {"id":"high-correlation","label":"資産の相関 ρ = 0.95","description":"分散を下げる効果がほぼ消え、比率は w₂ = 0.3875 へ下がる。QP と解析解の差は 10⁻¹⁶ 以下に保たれる。","inputs":{"asset_correlation":0.95}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"allocation","path":"/rows/0/2","approx":{"value":0.453125,"atol":1e-12}}
//|       - {"artifact":"allocation","path":"/rows/1/2","approx":{"value":0.453125,"atol":1e-12}}
//|       - {"artifact":"allocation","path":"/rows/0/3","approx":{"value":0.0571875,"atol":1e-10}}
//|       - {"artifact":"allocation","path":"/rows/0/4","approx":{"value":0.11004,"atol":1e-5}}
//|       - {"artifact":"checks","path":"/rows/0/0","range":{"min":0,"max":1e-12}}
//|       - {"artifact":"checks","path":"/rows/0/1","range":{"min":-1e-14,"max":1e-14}}
//|       - {"artifact":"checks","path":"/rows/0/5","equals":"Accepted"}
//|       - {"path":"/outputs/2/state","equals":"satisfied"}
//|   - case: low-risk-aversion
//|     expect:
//|       - {"artifact":"allocation","path":"/rows/0/2","approx":{"value":1,"atol":1e-12}}
//|       - {"artifact":"allocation","path":"/rows/2/2","approx":{"value":7.875,"atol":1e-9}}
//|       - {"artifact":"checks","path":"/rows/0/0","range":{"min":0,"max":1e-12}}
//|       - {"path":"/outputs/2/state","equals":"satisfied"}
//|   - case: high-correlation
//|     expect:
//|       - {"artifact":"allocation","path":"/rows/0/2","approx":{"value":0.3875,"atol":1e-12}}
//|       - {"artifact":"checks","path":"/rows/0/0","range":{"min":0,"max":1e-12}}
use scioxide_core::{Bounds, RealScalar};
use scioxide_linalg::Matrix;
use scioxide_optimize::{LinearConstraintSense, LinearConstraints, QpProblem, QpSolver};

// μ = (0.03, μ₂)、σ = (0.08, 0.20)。Q = λΣ、c = −μ とし、w₁ + w₂ = 1、0 ≤ wᵢ ≤ 1 を課す。
let (mu, sd) = ([0.03_f64, growth_expected_return], [0.08_f64, 0.20]);
let (s11, s12, s22) = (
    sd[0] * sd[0],
    asset_correlation * sd[0] * sd[1],
    sd[1] * sd[1],
);
let q = [s11, s12, s12, s22]
    .iter()
    .map(|s| risk_aversion * s)
    .collect();
let hessian = Matrix::from_vec(2, 2, q).map_err(|e| e.to_string())?;
let budget = LinearConstraints::new(
    Matrix::from_vec(1, 2, vec![1.0_f64, 1.0]).map_err(|e| e.to_string())?,
    vec![1.0],
    vec![LinearConstraintSense::Equal],
)
.map_err(|e| e.to_string())?;
let problem = QpProblem::new(hessian, vec![-mu[0], -mu[1]])
    .and_then(|p| p.with_constraints(budget))
    .and_then(|p| p.with_bounds(Bounds::new(vec![(Some(0.0), Some(1.0)); 2])?))
    .map_err(|e| e.to_string())?;
let result = QpSolver::<f64>::default()
    .solve(&problem)
    .map_err(|e| e.to_string())?;
let w = result.x();
// 独立な検算: w₂ = z について一変数に消去した解析解を [0, 1] へ射影する。
let d = s11 - 2.0 * s12 + s22;
let free = (s11 - s12) / d + (mu[1] - mu[0]) / (risk_aversion * d);
let analytic = free.clamp(0.0, 1.0);
let variance = |z: f64| s11 * (1.0 - z) * (1.0 - z) + 2.0 * s12 * z * (1.0 - z) + s22 * z * z;
let row = |name: &str, z: f64| {
    let (expected, deviation) = (mu[0] + (mu[1] - mu[0]) * z, RealScalar::sqrt(variance(z)));
    (name.to_owned(), 1.0 - z, z, expected, deviation)
};
let fixed6 = serde_json::json!({ "fractionDigits": 6 });
let digits4 = serde_json::json!({ "significantDigits": 4 });
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let allocation_columns = serde_json::json!([
    { "key": "0", "label": "配分" },
    { "key": "1", "label": "w₁ [-]", "type": "number", "format": fixed6 },
    { "key": "2", "label": "w₂ [-]", "type": "number", "format": fixed6 },
    { "key": "3", "label": "期待収益 μₚ [年率]", "type": "number", "format": digits4 },
    { "key": "4", "label": "標準偏差 σₚ [年率]", "type": "number", "format": digits4 }
]);
emit_table_with_columns!(
    allocation_columns,
    vec![
        row("QP の解", w[1]),
        row("解析解 z*（[0, 1] へ射影）", analytic),
        row("空売りを許す解 z_free", free),
    ],
    metadata = serde_json::json!({ "id": "allocation" })
);
let check_columns = serde_json::json!([
    { "key": "0", "label": "|w₂ − z*| [-]", "type": "number", "format": sci2 },
    { "key": "1", "label": "w₁ + w₂ − 1 [-]", "type": "number", "format": sci2 },
    { "key": "2", "label": "制約の違反 [-]", "type": "number", "format": sci2, "nullText": "なし" },
    { "key": "3", "label": "停留性 [-]", "type": "number", "format": sci2, "nullText": "なし" },
    { "key": "4", "label": "上下限の違反 [-]", "type": "number", "format": sci2, "nullText": "なし" },
    { "key": "5", "label": "証明用データの検算", "nullText": "なし" },
    { "key": "6", "label": "反復 [回]", "type": "integer" }
]);
let verification = result
    .verification_report()
    .map(|report| format!("{:?}", report.status()));
emit_table_with_columns!(
    check_columns,
    vec![(
        (w[1] - analytic).abs(),
        w[0] + w[1] - 1.0,
        result.primal_feasibility(),
        result.stationarity(),
        result.bound_violation(),
        verification,
        result.iterations(),
    )],
    metadata = serde_json::json!({ "id": "checks" })
);
export!(mu, &mu);
export!(sd, &sd);
export!(correlation, &asset_correlation);
export!(risk_aversion, &risk_aversion);
export!(weight, &w[1]);
export!(free, &free);
// 成功しなかったときは、最後の点を最適性の示されていない配分として解釈する。
let outcome = if result.is_success() {
    Outcome::satisfied("QP の停止判定を満たし、証明用データを元の問題で検算した")
} else {
    Outcome::partial("停止判定を満たす前に止まり、最後の点を返した")
};
emit_outcome!(
    outcome
        .status(result.termination().to_string())
        .diagnostic("|w₂ − z*|", (w[1] - analytic).abs(), None)
        .diagnostic("反復", result.iterations() as f64, Some("回"))
);
```

既定の入力（$\mu_2=0.09$、$\rho=0.25$、$\lambda=4$）では、`QpSolver` は 5 回の反復で `Converged` に達し、比率 $(w_1,w_2)=(0.546875, 0.453125)$ を返す。
上下限を外した解は $z_{\mathrm{free}}=0.453125$ で区間の内部にあり、QP との差は $5.6\times10^{-17}$ である。
ポートフォリオの期待収益は 0.0572、標準偏差は 0.110 で、証明用データの検算は `Accepted` になる。

$\lambda=0.2$ では $z_{\mathrm{free}}=7.875$ が区間の外にあり、QP は上限 $w_2=1$ を返して変数の上限が活性になる。
表の 3 行目は、空売りと借入れを許すと $(w_1,w_2)=(-6.875,7.875)$ が最適になることを示す。
相関を 0.95 にすると分散を下げる効果がほぼ消え、比率は $w_2=0.3875$ へ下がる。

解析解との差は二資産に特有の独立な検算である。
資産の数が増えて解析解がないときは、和の等式の残差、上下限の違反、停留性、証明用データの検算、終了状態を合わせて読む。
見た目に妥当な比率でも、等式制約を満たしていなければポートフォリオとして無効である。

## 効率的フロンティアと目的関数

前のセルが返した解を、平均と標準偏差の平面と目的関数の上で読む。
このセルは前のセルの入力に従って描き直され、自分の入力を持たない。

第一図は横軸を標準偏差、縦軸を期待収益とし、$z\in[0,1]$ が描く到達可能な曲線を閉形式から描く。
$z\ge z_{\mathrm{mv}}$ の枝が効率的フロンティアで破線、それより下の枝は点線にし、QP の解を記号で重ねる。
第二図は同じ $z$ に対する目的関数で、QP の解と上下限を外した解 $z_{\mathrm{free}}$ を縦線で示す。

```rust
//| id: optimize-portfolio-qp-frontier
//| ref: optimize-portfolio-qp-frontier
//| title: QP の解を効率的フロンティアと目的関数の上で見る
//| run: reactive
//| crates: [scioxide-core]
//| dependsOn:
//|   qp: optimize-portfolio-qp
use scioxide_core::RealScalar;

let read = |name: &str| qp[name].as_f64().ok_or(format!("{name} がない"));
let mu: [f64; 2] = serde_json::from_value(qp["mu"].clone()).map_err(|e| e.to_string())?;
let sd: [f64; 2] = serde_json::from_value(qp["sd"].clone()).map_err(|e| e.to_string())?;
let (rho, lambda, weight, free) = (
    read("correlation")?,
    read("risk_aversion")?,
    read("weight")?,
    read("free")?,
);
let (s11, s12, s22) = (sd[0] * sd[0], rho * sd[0] * sd[1], sd[1] * sd[1]);
let variance = |z: f64| s11 * (1.0 - z) * (1.0 - z) + 2.0 * s12 * z * (1.0 - z) + s22 * z * z;
let point = |z: f64| [RealScalar::sqrt(variance(z)), mu[0] + (mu[1] - mu[0]) * z];
// z ≥ z_mv の枝が効率的フロンティア、z < z_mv の枝は分散も収益も劣る。
let z_mv = ((s11 - s12) / (s11 - 2.0 * s12 + s22)).clamp(0.0, 1.0);
let dominated: Vec<[f64; 2]> = (0..=100).map(|i| point(z_mv * i as f64 / 100.0)).collect();
let efficient: Vec<[f64; 2]> = (0..=100)
    .map(|i| point(z_mv + (1.0 - z_mv) * i as f64 / 100.0))
    .collect();
emit_chart!(
    serde_json::json!({
        "kind": "xy",
        "dataZoom": true,
        "tooltip": true,
        "xLabel": "ポートフォリオの標準偏差 σₚ [年率]",
        "yLabel": "期待収益 μₚ [年率]",
        "layers": [
            {
                "id": "efficient",
                "kind": "line",
                "name": "効率的フロンティア（閉形式）",
                "points": efficient,
                "style": { "lineType": "dashed" }
            },
            {
                "id": "dominated",
                "kind": "line",
                "name": "劣る枝（閉形式）",
                "points": dominated,
                "style": { "lineType": "dotted" }
            },
            { "id": "qp", "kind": "scatter", "name": "QP の解", "points": [point(weight)] }
        ]
    }),
    metadata = serde_json::json!({ "id": "frontier" })
);
let objective: Vec<[f64; 2]> = (0..=200)
    .map(|i| {
        let z = i as f64 / 200.0;
        [z, 0.5 * lambda * variance(z) - mu[0] - (mu[1] - mu[0]) * z]
    })
    .collect();
// 縦線は QP の解と上下限を外した解（[0, 1] の外なら表示範囲外）。
emit_line_chart!(
    &vec![serde_json::json!({ "name": "平均分散の目的", "points": objective })],
    options = &serde_json::json!({
        "xLabel": "成長資産の比率 w₂ [-]",
        "yLabel": "目的 (λ/2)wᵀΣw − μᵀw [年率]",
        "xMin": 0.0,
        "xMax": 1.0,
        "annotations": [
            { "kind": "line", "axis": "x", "value": weight, "label": "QP の解" },
            {
                "kind": "line",
                "axis": "x",
                "value": free,
                "label": "z_free",
                "style": { "lineType": "dotted" }
            }
        ]
    })
);
```

到達可能な曲線のすべてが効率的フロンティアではない。
同じかより小さい標準偏差でより高い期待収益を持つ点があれば、その点に劣る配分は効率的とは呼ばない。
二資産では最小分散点 $z_{\mathrm{mv}}$ より下の点線の枝が劣る配分で、$\mu_2>\mu_1$ なら $z^\star\ge z_{\mathrm{mv}}$ なので QP の解は常に破線の枝に乗る。
効率的フロンティアの上では右上へ進むほど期待収益も標準偏差も増える。
どの点を選ぶかは $\lambda$ が決め、$\lambda$ を下げると解は破線に沿って右上へ動く。
既定の入力では最小分散点は $z_{\mathrm{mv}}=0.0625$（標準偏差 0.0791）にあり、QP の解はそこから成長資産の側へ 0.39 だけ進んだ位置にある。

目的関数の図で最小点が区間の端に達すると、上下限が活性になる。
そこから $\lambda$ をさらに下げても、比率は $w_2=1$ より先へは進まない。

## まとめ

平均分散モデルは $Q=\lambda\Sigma$、$c=-\mu$ として `QpProblem` に渡し、和の等式を `LinearConstraints`、空売りの禁止を `Bounds` で与える。
二資産の問題は一変数へ消去でき、$z_{\mathrm{free}}=z_{\mathrm{mv}}+(\mu_2-\mu_1)/(\lambda D)$ を $[0,1]$ へ射影した解析解と QP の比率が $10^{-16}$ 以下の差で一致することを検算に使える。
$z_{\mathrm{free}}$ が区間の外に出ると上下限が活性になり、その先は $\lambda$ を下げても配分は変わらない。
解析解のない多資産の問題では、和の等式の残差、上下限の違反、停留性、証明用データの検算 `Accepted`、終了状態 `Converged` をそろえて確かめる。
