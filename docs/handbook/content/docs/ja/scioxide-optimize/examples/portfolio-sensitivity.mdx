平均分散モデルの期待収益 $\mu$ と共分散行列 $\Sigma$ は、過去の標本から推定した値である。
推定値が少し違うだけで最適比率が大きく動くなら、小数点以下まで返した比率に意味はない。
このページでは[二資産ポートフォリオを二次計画で設計する](../portfolio-qp/)と同じ資産を使い、相関 $\rho$ とリスク回避度 $\lambda$ の格子の各点で QP を解いて、最適比率のヒートマップを作る。
比率が上下限に張り付く領域と内部解になる領域の境目を解析式で求め、格子の QP の結果と照合する。

## 等式を消去した一変数の QP

低変動資産は $\mu_1=0.03$、$\sigma_1=0.08$ に固定し、成長資産の標準偏差 $\sigma_2$ と期待収益差 $\Delta\mu=\mu_2-\mu_1$ を入力にする。
どれも年率で表し、既定値は前のページと同じ $\sigma_2=0.20$、$\Delta\mu=0.06$ である。

格子では $z=w_2$、$w_1=1-z$ を先に代入する。
和の等式は $z$ によらず成り立ち、$0\le w_1\le1$ は $0\le z\le1$ と同じ条件になる。
共分散を $\sigma_{12}=\rho\sigma_1\sigma_2$、$D=\sigma_1^2-2\sigma_{12}+\sigma_2^2$ とすると、定数項を除いた目的は

$$
\frac12\lambda Dz^2+\bigl[\lambda(\sigma_{12}-\sigma_1^2)-\Delta\mu\bigr]z,
\qquad 0\le z\le1
$$

である。
これは元の二資産の問題と同じ最適比率を持つ、上下限だけの 1 変数の凸 QP である。
上下限だけの問題に対して、`QpSolver` の既定の `QpMethod::Automatic` は[射影勾配法と Barzilai–Borwein 刻み](oxref:optimize-qp-projected-gradient-bb)を使う。
546 点の格子でも、各点の求解は 1 変数の小さな計算で済む。

## 境界解と内部解の境目

上下限を外した解は

$$
z_{\mathrm{free}}=\frac{\Delta\mu/\lambda+\sigma_1^2-\sigma_{12}}{D}
$$

で、最適比率はこれを $[0,1]$ へ射影した $z^\star$ である。
$z_{\mathrm{free}}\ge1$ を $\lambda$ について解くと

$$
\lambda\le\lambda_{\mathrm{up}}(\rho)=\frac{\Delta\mu}{\sigma_2(\sigma_2-\rho\sigma_1)}
$$

になる。
入力の範囲では $\sigma_2\ge0.1>\rho\sigma_1$ なので分母は正で、この領域ではどの $\rho$ でも成長資産だけの配分 $w_2=1$ になる。
$z_{\mathrm{free}}\le0$ は、$\rho\sigma_2>\sigma_1$ のときに限り

$$
\lambda\ge\lambda_{\mathrm{low}}(\rho)=\frac{\Delta\mu}{\sigma_1(\rho\sigma_2-\sigma_1)}
$$

で成り立ち、低変動資産だけの配分 $w_2=0$ になる。
$\rho\sigma_2\le\sigma_1$ では成長資産を少し混ぜると分散が下がるので、どれほど $\lambda$ が大きくても $w_2=0$ にはならない。

二つの曲線の間が内部解の領域で、そこでは比率が $\lambda$ と $\rho$ に連続に依存する。
曲線の近くでは、推定値のわずかな違いで活性な上下限が入れ替わる。

## 感度のヒートマップ

横軸を相関 $\rho\in[-0.9,0.95]$、縦軸をリスク回避度 $\lambda\in[0.2,20]$ とする 26×21 の格子の各点で QP を解き、成長資産の比率 $w_2$ を色で描く。
入力は期待収益差 $\Delta\mu$ と成長資産の標準偏差 $\sigma_2$ である。

出力は比率の色図、要約の表、境目の表である。
要約の表は解いた QP の数、射影した解析解との差の最大、内部解の割合を示す。
境目の表は 5 つの $\rho$ について、解析式の $\lambda_{\mathrm{up}}$、$\lambda_{\mathrm{low}}$ と、格子の上で QP が $w_2=1$ を返した最大の $\lambda$、$w_2=0$ を返した最小の $\lambda$ を並べる。
格子の $\lambda$ は 0.99 刻みなので、境目が格子の範囲 $[0.2,20]$ の内側にあり QP が正しければ、$\lambda_{\mathrm{up}}$ は「$w_2=1$ の最大の $\lambda$」から 0.99 以内の上にあり、$\lambda_{\mathrm{low}}$ は「$w_2=0$ の最小の $\lambda$」から 0.99 以内の下にある。
成功しなかった QP があれば、その $(\rho,\lambda)$ を添えてエラーを返す。

```rust
//| id: optimize-portfolio-sensitivity
//| ref: optimize-portfolio-sensitivity
//| title: 相関とリスク回避度に対する最適比率の感度面を見る
//| run: reactive
//| crates: [scioxide-core, scioxide-linalg, scioxide-optimize]
//| inputs:
//|   return_advantage: {"type":"range","label":"期待収益差 μ₂ − μ₁ [年率]","description":"成長資産を持つ利点を変える。","min":0.005,"max":0.13,"step":0.005,"value":0.06}
//|   growth_volatility: {"type":"range","label":"成長資産の標準偏差 σ₂ [年率]","description":"成長資産の分散の罰を変える。","min":0.1,"max":0.35,"step":0.01,"value":0.2}
//| cases:
//|   - {"id":"low-growth-volatility","label":"成長資産の標準偏差 σ₂ = 0.10","description":"分散の罰が弱まって w₂ = 1 の領域が λ の大きい側へ広がり、w₂ = 0 の領域は格子から消えて、内部解の割合は 0.810 から 0.595 へ下がる。","inputs":{"growth_volatility":0.1}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"summary","path":"/rows/0/0","equals":546}
//|       - {"artifact":"summary","path":"/rows/0/1","range":{"min":0,"max":1e-12}}
//|       - {"artifact":"summary","path":"/rows/0/2","approx":{"value":0.80952,"atol":1e-4}}
//|       - {"artifact":"thresholds","path":"/rows/0/1","approx":{"value":1.10294,"atol":1e-4}}
//|       - {"artifact":"thresholds","path":"/rows/0/2","approx":{"value":0.2,"atol":1e-12}}
//|       - {"artifact":"thresholds","path":"/rows/0/3","equals":null}
//|   - case: low-growth-volatility
//|     expect:
//|       - {"artifact":"summary","path":"/rows/0/1","range":{"min":0,"max":1e-12}}
//|       - {"artifact":"summary","path":"/rows/0/2","approx":{"value":0.59524,"atol":1e-4}}
use scioxide_core::{Bounds, SciOxideError};
use scioxide_linalg::Matrix;
use scioxide_optimize::{ProgrammingResult, QpProblem, QpSolver};

// μ₁ = 0.03、σ₁ = 0.08 を固定し、(ρ, λ) の 26×21 格子の各点で同じ形の QP を解く。
let (sd1, sd2) = (0.08_f64, growth_volatility);
// w₁ = 1 − z を先に代入し、等式制約を消去した 1 変数の凸 QP を解く。
let solve = |rho: f64, lambda: f64| -> Result<ProgrammingResult<f64>, SciOxideError> {
    let s12 = rho * sd1 * sd2;
    let d = sd1 * sd1 - 2.0 * s12 + sd2 * sd2;
    let q = Matrix::from_vec(1, 1, vec![lambda * d])?;
    let linear = lambda * (s12 - sd1 * sd1) - return_advantage;
    let problem = QpProblem::new(q, vec![linear])?
        .with_bounds(Bounds::new(vec![(Some(0.0), Some(1.0))])?)?;
    QpSolver::<f64>::default().solve(&problem)
};
let rhos: Vec<f64> = (0..=25)
    .map(|col| -0.9 + 1.85 * col as f64 / 25.0)
    .collect();
let lambdas: Vec<f64> = (0..=20).map(|row| 0.2 + 0.99 * row as f64).collect();
let (mut map, mut max_error, mut interior) = (Vec::new(), 0.0_f64, 0_usize);
for &lambda in &lambdas {
    for &rho in &rhos {
        let result = solve(rho, lambda).map_err(|e| e.to_string())?;
        if !result.is_success() {
            return Err(format!(
                "ρ = {rho:.3}、λ = {lambda:.2} の QP が成功しなかった: {}",
                result.termination()
            ));
        }
        let w2 = result.x()[0];
        // 独立な検算: 一変数の解析解を [0, 1] へ射影した値との差。
        let s12 = rho * sd1 * sd2;
        let free =
            (return_advantage / lambda + sd1 * sd1 - s12) / (sd1 * sd1 - 2.0 * s12 + sd2 * sd2);
        let analytic = free.clamp(0.0, 1.0);
        max_error = max_error.max((w2 - analytic).abs());
        if free > 0.0 && free < 1.0 {
            interior += 1;
        }
        map.push([rho, lambda, w2]);
    }
}
// 比率は [0, 1] なので色範囲を固定する。
emit_chart!(
    serde_json::json!({
        "kind": "heatmap",
        "data": map,
        "xLabel": "資産の相関 ρ [-]",
        "yLabel": "リスク回避度 λ [-]",
        "colorMin": 0.0,
        "colorMax": 1.0,
        "tooltip": true,
        "style": { "animation": false }
    }),
    metadata = serde_json::json!({
        "id": "allocation-map",
        "title": "QP が返した成長資産の比率 w₂ [-]"
    })
);
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let fixed3 = serde_json::json!({ "fractionDigits": 3 });
let digits4 = serde_json::json!({ "significantDigits": 4 });
let summary_columns = serde_json::json!([
    { "key": "0", "label": "解いた QP [個]", "type": "integer" },
    { "key": "1", "label": "max |w₂ − z*| [-]", "type": "number", "format": sci2 },
    { "key": "2", "label": "内部解の割合 [-]", "type": "number", "format": fixed3 }
]);
emit_table_with_columns!(
    summary_columns,
    vec![(map.len(), max_error, interior as f64 / map.len() as f64)],
    metadata = serde_json::json!({ "id": "summary" })
);
// 境目の解析式と、格子の各列で QP が w₂ = 1 を返した最大の λ、w₂ = 0 を返した最小の λ。
let mut thresholds = Vec::new();
for col in [0_usize, 10, 15, 20, 25] {
    let rho = rhos[col];
    let upper = return_advantage / (sd2 * (sd2 - rho * sd1));
    let lower = (rho * sd2 > sd1).then(|| return_advantage / (sd1 * (rho * sd2 - sd1)));
    let column: Vec<[f64; 3]> = map[col..].iter().step_by(rhos.len()).copied().collect();
    let last_growth = column.iter().filter(|p| p[2] == 1.0).map(|p| p[1]).last();
    let first_low = column.iter().find(|p| p[2] == 0.0).map(|p| p[1]);
    thresholds.push((rho, upper, last_growth, lower, first_low));
}
let threshold_columns = serde_json::json!([
    { "key": "0", "label": "相関 ρ [-]", "type": "number", "format": fixed3 },
    { "key": "1", "label": "λ_up（解析）[-]", "type": "number", "format": digits4 },
    { "key": "2", "label": "w₂ = 1 の最大 λ [-]", "type": "number", "format": digits4, "nullText": "なし" },
    { "key": "3", "label": "λ_low（解析）[-]", "type": "number", "format": digits4, "nullText": "なし" },
    { "key": "4", "label": "w₂ = 0 の最小 λ [-]", "type": "number", "format": digits4, "nullText": "なし" }
]);
emit_table_with_columns!(
    threshold_columns,
    thresholds,
    metadata = serde_json::json!({ "id": "thresholds" })
);
```

既定の入力では 546 個の QP がすべて成功し、射影した解析解との差の最大は $2.2\times10^{-16}$、内部解の割合は 0.810 である。
色図の下端に $w_2=1$ の帯があり、右上の隅（$\rho\ge0.59$ で $\lambda\ge\lambda_{\mathrm{low}}$）に $w_2=0$ の領域がある。
$\rho>0.4$ でも $\lambda_{\mathrm{low}}$ が格子の上限 20 を超える範囲では、$w_2=0$ の点は現れない。
境目の表ではどの $\rho$ でも解析式の $\lambda_{\mathrm{up}}$、$\lambda_{\mathrm{low}}$ が格子の QP の切り替わりを挟む。

成長資産の標準偏差を 0.10 に下げると、内部解の割合は 0.595 へ下がる。
分散の罰が弱まり、$\lambda_{\mathrm{up}}$ が 3.5〜25 に上がって $w_2=1$ の帯が $\lambda$ の大きい側へ広がる。
$\rho\sigma_2>\sigma_1$ となるのは $\rho>0.8$ だけで、そこでも $\lambda_{\mathrm{low}}$ は 50 以上なので、$w_2=0$ の領域は格子から消える。

## 推定誤差とモデルの限界

張り付いた色の領域が広いところでは、入力の推定値が少し変わっても比率は変わらない。
一方、内部解との境目の近くでは、収益差や相関のわずかな違いで活性な上下限が入れ替わる。
点推定だけを QP に入れて小数点以下まで比率を返しても、その精度は統計的に裏付けられない。

平均分散モデルは収益の分布を平均と分散だけに縮約し、歪み、厚い裾、最大損失、流動性、取引費用を含まない。
過去の標本から推定した $\mu$ は特に不安定で、わずかな誤差が線形項を通じて重みを端へ押しやすい。
縮小推定、ロバスト最適化、重みの変更へのペナルティが必要になる場合がある。

ここでの「リスク」は一期間の収益率の標準偏差であり、損失確率そのものではない。
最適比率を伝えるときは、$\lambda$、推定期間、資産の集合、空売りと全額投資の制約、診断の残差を一緒に示す。

## まとめ

二資産の配分は和の等式を消去すると上下限だけの 1 変数の凸 QP になり、`QpSolver` は射影勾配法で解く。
最適比率が上限に張り付くのは $\lambda\le\Delta\mu/(\sigma_2(\sigma_2-\rho\sigma_1))$、下限に張り付くのは $\rho\sigma_2>\sigma_1$ かつ $\lambda\ge\Delta\mu/(\sigma_1(\rho\sigma_2-\sigma_1))$ のときで、格子の QP の切り替わりはこの式と一致する。
自分の推定値がこの境目の近くにあるかを確かめ、近ければ比率を細かい桁までレポートせず、推定の不確かさとともに示す。
相関や収益差の推定が変わっても比率が動かない領域と、活性な上下限が入れ替わる領域を、このヒートマップで区別できる。
