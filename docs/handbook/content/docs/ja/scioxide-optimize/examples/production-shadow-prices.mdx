[再生可能エネルギー機器の生産計画](../production-lp/)では、資材、作業時間、蓄電池専用工程の機能という三つのリソースのもとで、太陽電池装置 $x$ 台と蓄電池装置 $y$ 台の利益を最大にする LP を解いた。
次に知りたいのは、どのリソースを 1 単位増やすと利益がいくら増えるかである。
この値をシャドープライス（shadow price）と呼び、LP の双対問題の最適解として得られる。
このページでは `SimplexSolver` が返す双対乗数をシャドープライスとして読み、右辺を少しずらして解き直した有限差分と、双対目的と最適利益の一致（強双対性）で独立に確かめる。

## 価値関数と双対問題

リソースの量 $b=(M,H,B)^\mathsf T$ の関数として最大利益を

$$
V(b)=\max\{\,p^\mathsf Tq : Aq\le b,\ q\ge0\,\}
$$

と書く。
ここで $q=(x,y)^\mathsf T$ は生産量、$p=(300,p_y)^\mathsf T$ は 1 台あたりの利益、$A$ はリソースの使用量の表である。

$$
A=\begin{pmatrix}2&3\\1&2\\0&1\end{pmatrix}
$$

この LP の双対問題は、リソース $i$ に単価 $\lambda_i\ge0$ を付けて

$$
\min_{\lambda}\;b^\mathsf T\lambda
\quad\text{subject to}\quad
A^\mathsf T\lambda\ge p,\ \lambda\ge0
$$

を解く問題である。
制約 $A^\mathsf T\lambda\ge p$ は、製品 1 台が使うリソースをこの単価で評価した額がその製品の利益以上になることを表す。
主問題と双対問題の実行可能解 $q,\lambda$ について $p^\mathsf Tq\le\lambda^\mathsf TAq\le b^\mathsf T\lambda$（弱双対性）が成り立ち、最適解では等号 $V(b)=b^\mathsf T\lambda^\star$ が成り立つ（強双対性）。
等号の条件は相補性

$$
\lambda_i\,(b_i-a_i^\mathsf Tq)=0,
\qquad
q_j\,(A^\mathsf T\lambda-p)_j=0
$$

である（$a_i^\mathsf T$ は $A$ の第 $i$ 行）。
余りのあるリソースの単価は 0 で、作っている製品ではリソースの評価額と利益が等しい。

既定の最適点 $(30,20)$ では資材と作業が活性で、$x,y>0$ なので双対の制約は二つとも等号になる。

$$
2\lambda_M+\lambda_H=300,\qquad 3\lambda_M+2\lambda_H=500
$$

これを解くと $\lambda_M=\lambda_H=100$、$\lambda_B=0$ で、$b^\mathsf T\lambda=120\cdot100+70\cdot100=19000$ が最大利益に一致する。

## シャドープライスの局所性と退化

最適基底（活性な制約の組）が変わらない範囲では、$V$ は $b$ について線形で、傾きが $\lambda^\star$ になる。
基底が切り替わる点で $V$ は折れ曲がり、全体としては $b$ の区分線形な凹関数になる。
シャドープライスは右辺を片側に動かした差分で近似できる。

$$
\frac{V(b+\Delta e_i)-V(b)}{\Delta}
\quad\text{と}\quad
\frac{V(b)-V(b-\Delta e_i)}{\Delta}
$$

基底が切り替わらない小さな $\Delta$ では、両方の差分が $\lambda_i^\star$ に一致する。
三つ以上の制約が同じ頂点で活性になる退化した頂点では、双対の最適解が一意に決まらないことがある。
このとき $V$ はその点で折れ曲がることがあり、凹性から前進差分 $\le\lambda_i^\star\le$ 後退差分となって、ソルバーが返す乗数はその間の一つの値である。

差分の刻み $\Delta$ を小さくしすぎると、目的値の差の丸め誤差が支配する（利益が $2\times10^4$ 程度なら、$\Delta=0.1$ での丸めの影響は $10^{-10}$ 程度以下）。
大きすぎると基底の切り替わりをまたぐ。

## 双対乗数と差分を比べる

入力は基準の三つのリソース量と蓄電池 1 台の利益である。
出力は次のとおりである。

- リソースごとの双対乗数 $\lambda_i$ と、右辺を $\Delta=0.1$ だけ増やした前進差分、減らした後退差分の表
- 基準の最大利益 $V$、双対目的 $b^\mathsf T\lambda$、その差の表（強双対性の検算）
- 一つのリソースだけを基準の 0.7〜1.3 倍に動かしたときの最大利益の図
- 基準の LP の最適性の証拠を検証した結果による判定

双対乗数は `ProgrammingResult::certificate()` の `ProgrammingCertificate::Optimality { dual, .. }` から、元の制約の行の順に読む。
SciOxide は最小化の形で解くので、利益の符号を反転した LP では $\le$ 行の乗数が非負になり、右辺を 1 増やしたときの最小値の減少量、つまり利益の増加量を表す。
差分は同じ LP を右辺だけ変えて解き直す独立な計算である。

```rust
//| id: optimize-production-shadow-prices
//| ref: optimize-production-shadow-prices
//| title: リソースを 1 単位増やす価値と基底の切り替わりを調べる
//| run: reactive
//| crates: [scioxide-core, scioxide-linalg, scioxide-optimize]
//| inputs:
//|   shadow_material_capacity: {"type":"range","label":"基準の資材 M [単位]","description":"価値関数を評価する基準点を変える。","min":70,"max":170,"step":5,"value":120}
//|   shadow_labor_capacity: {"type":"range","label":"基準の作業 H [h]","description":"資材との競合を変える。","min":45,"max":110,"step":5,"value":70}
//|   shadow_line_capacity: {"type":"range","label":"基準の工程 B [台]","description":"蓄電池専用工程の逼迫度を変える。","min":10,"max":40,"step":1,"value":25}
//|   shadow_battery_profit: {"type":"range","label":"蓄電池 1 台の利益 pᵧ [千円]","description":"リソースの限界価値を変える。","min":350,"max":750,"step":25,"value":500}
//| cases:
//|   - {"id":"high-battery-profit","label":"蓄電池の利益 pᵧ = 750","description":"活性な制約の組が作業と専用工程に変わり、双対乗数は資材 0、作業 300、専用工程 150 になって両側の差分と一致する。","inputs":{"shadow_battery_profit":750}}
//|   - {"id":"scarce-material","label":"基準の資材 M = 70","description":"資材だけが Plan を制約し、資材の乗数は 500/3 ≈ 166.67、作業と専用工程の乗数は 0 になる。","inputs":{"shadow_material_capacity":70}}
//|   - {"id":"degenerate","label":"基準の工程 B = 20","description":"三つのリソースが同じ頂点 (30, 20) で活性になり、資材の前進差分 100 と後退差分 150 が分かれる。","inputs":{"shadow_line_capacity":20}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"duals","path":"/rows/0/1","approx":{"value":100,"atol":1e-9}}
//|       - {"artifact":"duals","path":"/rows/1/1","approx":{"value":100,"atol":1e-9}}
//|       - {"artifact":"duals","path":"/rows/2/1","approx":{"value":0,"atol":1e-9}}
//|       - {"artifact":"duals","path":"/rows/0/2","approx":{"value":100,"atol":1e-6}}
//|       - {"artifact":"duals","path":"/rows/0/3","approx":{"value":100,"atol":1e-6}}
//|       - {"artifact":"duals","path":"/rows/2/2","approx":{"value":0,"atol":1e-6}}
//|       - {"artifact":"duality","path":"/rows/0/1","approx":{"value":19000,"atol":1e-6}}
//|       - {"artifact":"duality","path":"/rows/0/2","range":{"min":0,"max":1e-8}}
//|       - {"path":"/outputs/3/state","equals":"satisfied"}
//|   - case: high-battery-profit
//|     expect:
//|       - {"artifact":"duals","path":"/rows/0/1","approx":{"value":0,"atol":1e-9}}
//|       - {"artifact":"duals","path":"/rows/1/1","approx":{"value":300,"atol":1e-9}}
//|       - {"artifact":"duals","path":"/rows/2/1","approx":{"value":150,"atol":1e-9}}
//|       - {"artifact":"duals","path":"/rows/2/2","approx":{"value":150,"atol":1e-6}}
//|   - case: scarce-material
//|     expect:
//|       - {"artifact":"duals","path":"/rows/0/1","approx":{"value":166.666667,"atol":1e-5}}
//|       - {"artifact":"duals","path":"/rows/0/2","approx":{"value":166.666667,"atol":1e-5}}
//|       - {"artifact":"duals","path":"/rows/1/1","approx":{"value":0,"atol":1e-9}}
//|   - case: degenerate
//|     expect:
//|       - {"artifact":"duals","path":"/rows/0/2","approx":{"value":100,"atol":1e-6}}
//|       - {"artifact":"duals","path":"/rows/0/3","approx":{"value":150,"atol":1e-6}}
use scioxide_core::{Bounds, SciOxideError};
use scioxide_linalg::Matrix;
use scioxide_optimize::{
    LinearConstraintSense, LinearConstraints, LpProblem, ProgrammingCertificate,
    ProgrammingResult, SimplexSolver,
};

let sig6 = serde_json::json!({ "significantDigits": 6 });
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
// 右辺 (M, H, B) だけを変えて同じ LP を解く。利益は符号を反転した最小化で渡す。
let solve = |rhs: [f64; 3]| -> Result<ProgrammingResult<f64>, SciOxideError> {
    let rows = LinearConstraints::new(
        Matrix::from_vec(3, 2, vec![2.0_f64, 3.0, 1.0, 2.0, 0.0, 1.0])?,
        rhs.to_vec(),
        vec![LinearConstraintSense::LessEqual; 3],
    )?;
    let problem = LpProblem::new(vec![-300.0_f64, -shadow_battery_profit])?
        .with_constraints(rows)?
        .with_bounds(Bounds::new(vec![(Some(0.0), None); 2])?)?;
    let result = SimplexSolver::<f64>::default().solve(&problem)?;
    result.require_success()?;
    Ok(result)
};
let base = [
    shadow_material_capacity,
    shadow_labor_capacity,
    shadow_line_capacity,
];
let result = solve(base).map_err(|e| e.to_string())?;
// 単体法が返す元座標の双対の証拠。≤ 行の乗数 λᵢ ≥ 0 が利益のシャドープライスになる。
let duals = match result.certificate() {
    Some(ProgrammingCertificate::Optimality { dual, .. }) => dual.rows.to_vec(),
    _ => return Err("最適性の双対の証拠がない".to_owned()),
};
// 独立検算: 右辺を Δ = 0.1 だけ増減して解き直した片側差分。利益は −fun。
let delta = 0.1_f64;
let names = [
    "資材 M [千円/単位]",
    "作業 H [千円/h]",
    "専用工程 B [千円/台]",
];
let mut rows = Vec::new();
for (i, name) in names.into_iter().enumerate() {
    let (mut up, mut down) = (base, base);
    up[i] += delta;
    down[i] -= delta;
    let forward = (result.fun() - solve(up).map_err(|e| e.to_string())?.fun()) / delta;
    let backward = (solve(down).map_err(|e| e.to_string())?.fun() - result.fun()) / delta;
    rows.push((name, duals[i], forward, backward));
}
let dual_columns = serde_json::json!([
    { "key": "0", "label": "リソース" },
    { "key": "1", "label": "双対乗数 λᵢ", "type": "number", "format": sig6 },
    { "key": "2", "label": "前進差分", "type": "number", "format": sig6 },
    { "key": "3", "label": "後退差分", "type": "number", "format": sig6 }
]);
emit_table_with_columns!(
    dual_columns,
    rows,
    metadata = serde_json::json!({ "id": "duals" })
);
// 独立検算: 強双対性 V = bᵀλ。
let dual_objective: f64 = base.iter().zip(&duals).map(|(b, l)| b * l).sum();
let duality_columns = serde_json::json!([
    { "key": "0", "label": "最大利益 V [千円]", "type": "number", "format": sig6 },
    { "key": "1", "label": "双対目的 bᵀλ [千円]", "type": "number", "format": sig6 },
    { "key": "2", "label": "差 |V − bᵀλ| [千円]", "type": "number", "format": sci3 }
]);
emit_table_with_columns!(
    duality_columns,
    vec![(
        -result.fun(),
        dual_objective,
        (-result.fun() - dual_objective).abs()
    )],
    metadata = serde_json::json!({ "id": "duality" })
);
// 一つのリソースだけを基準の 0.7〜1.3 倍に動かし、最大利益 V の折れ線を描く。
let mut series = Vec::new();
for (i, label) in ["資材だけを変更", "作業だけを変更", "専用工程だけを変更"]
    .into_iter()
    .enumerate()
{
    let mut points = Vec::new();
    for k in 0..=60 {
        let scale = 0.7 + 0.6 * k as f64 / 60.0;
        let mut rhs = base;
        rhs[i] *= scale;
        points.push([scale, -solve(rhs).map_err(|e| e.to_string())?.fun()]);
    }
    series.push(serde_json::json!({ "name": label, "points": points }));
}
emit_line_chart!(
    &series,
    options = &serde_json::json!({
        "xLabel": "基準のリソース量に対する倍率 [-]",
        "yLabel": "最大利益 V [千円]",
        "annotations": [{ "kind": "line", "axis": "x", "value": 1.0, "label": "基準のリソース量" }]
    })
);
// 判定: シャドープライスの元になる双対の証拠が、元の座標の検証で受理されたか。
let outcome = if result
    .verification_report()
    .is_some_and(|v| v.is_accepted())
{
    Outcome::satisfied("基準の LP の解と双対乗数が元の座標の検証で受理された")
} else {
    Outcome::partial("基準の LP は終了したが、双対の証拠が検証で受理されなかった")
        .explanation("双対乗数はシャドープライスの候補として読み、差分と照合する。")
};
let outcome = outcome
    .status(result.termination().to_string())
    .diagnostic("最大利益", -result.fun(), None)
    .diagnostic("強双対性の差", (-result.fun() - dual_objective).abs(), None);
emit_outcome!(outcome);
```

既定の基準では、双対乗数は資材 100 千円/単位、作業 100 千円/h、専用工程 0 で、前進差分と後退差分の両方と一致する。
双対目的 $b^\mathsf T\lambda=19000$ は最大利益と一致し、上で手計算した値とも同じである。
余りのある専用工程の乗数が 0 になるのは相補性 $\lambda_i(b_i-a_i^\mathsf Tq)=0$ のとおりである。
資材を少し増やすと 1 単位あたり利益が 100 千円増えるので、追加で買う資材の単価が 100 千円未満なら増やす価値がある、と読める。

蓄電池の利益を 750 にすると活性な制約の組が作業と専用工程に変わり、乗数は資材 0、作業 300、専用工程 150 になる。
基準の資材を 70 にすると資材だけが Plan を制約し、資材の乗数は $500/3\approx166.67$、他は 0 になる。
どちらの場合も両側の差分は乗数と一致し、双対目的は最大利益と一致する。

基準の工程を $B=20$ にすると、三つのリソースの境界がすべて $(30,20)$ を通り、退化した頂点になる。
単体法の乗数は資材 150、作業 0、専用工程 50 で、双対目的 $120\cdot150+20\cdot50=19000$ は最大利益と一致する。
しかし資材の前進差分は 100、後退差分は 150、作業は 0 と 100、専用工程は 0 と 50 に分かれる。
どの乗数も前進差分と後退差分の間にあり、凹な価値関数の折れ目で傾きが一意に決まらないことを示す。
退化した頂点の乗数はリソースを増やす向きの価値を過大に、減らす向きの損失を過小に見積もることがあるので、差分を両側で確かめる。

図の折れ線は一つのリソースだけを動かしたときの $V$ である。
傾きが 0 の区間では、そのリソースを増やしても別の制約が先に詰まっている。
折れ曲がる点は活性な制約の組が切り替わる点で、双対乗数はその間の区間の傾きにあたる。
折れ曲がりをまたぐ大きな変化には乗数を使えないので、シャドープライスを設備投資の判断に使うときは、価格、需要、歩留まりを固定した局所的なモデルであることも明記する。

## まとめ

リソースのシャドープライスは LP の双対乗数として単体法が返す最適性の証拠から読める。
乗数は双対目的と最大利益の一致（強双対性）と、右辺を少しずらして解き直した差分で独立に確かめられる。
既定の Plan では資材 1 単位と作業 1 時間がそれぞれ 100 千円の利益に当たり、余りのある専用工程の価値は 0 である。
シャドープライスは活性な制約の組が変わらない範囲での変化率なので、退化した頂点や折れ曲がりの近くでは前進差分と後退差分を両方計算し、リソースを増やす向きの価値には前進差分を使う。
