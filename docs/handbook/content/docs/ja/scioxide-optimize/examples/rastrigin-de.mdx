目的関数がなだらかな大域的傾向の上に多数の周期的な凹凸を持つと、勾配法は初期点の近くにある局所的なくぼみで止まる。
その典型が Rastrigin 関数で、大域最小点が原点、最小値が 0 と解析的に分かるので、大域探索の試験問題として広く使われる。
このページでは Rastrigin 関数の局所極小の構造を調べ、準 Newton 法（BFGS）が局所極小で止まる様子と、差分進化法（differential evolution: DE）の探索を比べる。
差分進化の最良点から BFGS を始めて停留性を確かめ、結果を既知の大域最小値と照合する。

## 小さな波と局所極小

二次元の Rastrigin 関数

$$
f(x,y)=2A+x^2+y^2
-A\{\cos(2\pi x)+\cos(2\pi y)\},
\qquad (x,y)\in[-5.12,5.12]^2
$$

を考える（座標と $f$ は無次元）。
$A>0$ は周期的な凹凸の強さである。
$f=\{x^2+A(1-\cos2\pi x)\}+\{y^2+A(1-\cos2\pi y)\}$ と書き直すと、各項は 0 以上で、$x=y=0$ のときだけ 0 になる。
したがって原点が唯一の大域最小点で、$f(0,0)=0$ である。
この既知の答えを、アルゴリズムを比べるときの独立検算に使う。

偏微分は

$$
\frac{\partial f}{\partial x}
=2x+2\pi A\sin(2\pi x),\qquad
\frac{\partial f}{\partial y}
=2y+2\pi A\sin(2\pi y)
$$

である。
$A$ が大きいと正弦の項が勾配を支配し、各座標の整数の近くに停留点を作る。
$x$ 方向の局所極小は整数 $n$ の少し原点寄りにあり、$f$ の値はおよそ $n^2$ ずつ上がる（$A=10$ の $x=\pm0.995$ で 0.995、$\pm1.990$ で 3.98）。
二次元では各座標の局所極小の組み合わせが局所極小になるので、$A=10$ では箱の中に $11^2=121$ 個ある。

この地形は実際の配置設計そのものではないが、格子との干渉、周期的なペナルティ、複数の共振条件を持つ目的関数の縮図になる。
既知の答えを持つ試験問題で確かめた性質を、答えの分からない実問題の保証と取り違えない。

## 局所法の限界

BFGS のような局所法は、勾配と直線探索で目的を下げ、勾配が 0 に近い点に収束する。
`GradientSmall` は勾配のノルムが許容誤差以下になったことを示すが、その停留点がどの局所極小かは、初期点と途中の刻みで決まる。
終了時の勾配が小さくても、そこが最も低い極小とは限らない。
BFGS の更新と直線探索は[一階法・非線形共役勾配・準 Newton 法](../../algorithms/first-order-and-quasi-newton/)にある。

## 差分進化の三つの操作

差分進化は一つの点ではなく、集団 $\{x_i\}_{i=1}^{N_p}$ を持つ。
既定の戦略 DE/rand/1 では、$i$ と異なる互いに異なる個体 $r_1,r_2,r_3$ から

$$
v_i=x_{r_1}+F(x_{r_2}-x_{r_3})
$$

という変異個体を作る（変異係数 $F\in(0,2]$）。
差のベクトルは、現在の集団の広がりと向きをそのまま反映する。
次に二項交叉で、各成分を確率 $C_R$ で変異個体から、残りを親 $x_i$ から採り、少なくとも 1 成分は変異個体から採る。
箱の外に出た成分は既定では最も近い境界へ戻す。
試行点 $u_i$ が

$$
f(u_i)\le f(x_i)
$$

なら $x_i$ と置き換える。

$F$ が小さいと探索は集団の近くに縮み、大きいと境界の外へ出る試行が増える。
$C_R$ が小さいと少数の成分だけを変える保守的な試行になり、大きいと変異個体の成分をまとめて試す。
集団が小さいと計算量は減るが、差の方向の多様性を失う。
どの母数にも、すべての問題で最良の値はない。

1 世代は集団の各個体について目的を 1 回評価する。
初期集団の評価を含めると、評価回数の上限は

$$
N_{\mathrm{eval}}=N_p(G+1)
$$

である（$G$ は世代数の上限）。
世代数だけで比べず、集団数との積で計算量を読む。
1 回の評価が $O(d)$ の目的なら、1 世代の変異・交叉・選択は $O(N_pd)$ の算術で済み、計算コストの大半は目的の評価が占める。

`DifferentialEvolution` は集団の目的値の広がり $f_{\max}-f_{\min}$ が許容誤差（$\max(|f_{\min}|,|f_{\max}|)$ に対する相対値と絶対値）以下になると `PopulationStagnation`、世代数の上限に達すると `SearchBudgetCompleted` で止まる。
どちらも成功の分類ではなく、大域最小に達したことを示さない。
集団全体が誤った吸引域へ縮んでも `PopulationStagnation` になる。
変異戦略と境界の扱いは[差分進化法](../../algorithms/differential-evolution/)にある。

## 局所法と集団探索

Rastrigin の振幅、BFGS の初期点、差分進化の集団数・世代数・変異係数・交叉率・シードを動かす。
差分進化の初期集団には BFGS と同じ初期点を含める。
差分進化の集団の目的値の広がりに対する許容誤差は、絶対・相対とも $10^{-10}$ とする。

出力は次のとおりである。

- BFGS、差分進化、差分進化の最良点から始めた BFGS（差分進化 → BFGS）の結果の表
- 目的関数の地形の図と、対角線 $x=y$ 上の断面の図
- 差分進化 → BFGS の結果の判定

目的関数と勾配の余弦・正弦は `RealScalar::cos` と `RealScalar::sin` で計算する。
既知の大域最小値 0 と原点からの距離で、局所的な停留性と大域的な位置を別々に確かめる。
判定は、差分進化 → BFGS が `GradientSmall` で終わり、かつ $f\le10^{-8}$ のときだけ satisfied とする。

```rust
//|   de_seed: {"type":"range","label":"差分進化のシード [-]","description":"再現できる初期集団と乱数列を選ぶ。","min":1,"max":1000,"step":1,"value":202}
//| cases:

//|   - {"id":"small-mutation","label":"変異係数 F = 0.2","description":"集団は f = 0.112 で停滞する。そこからの BFGS は原点から 6×10⁻¹⁰ まで進むが、f が丸めで 0 になるので直線探索が失敗して LineSearchFailed で止まる。","inputs":{"de_mutation_factor":0.2}}
//|   - {"id":"near-start","label":"初期座標 s = 0.4","description":"初期点が原点の吸引域に入るので、BFGS 単独でも 4 回の反復で原点（f = 0）に達する。","inputs":{"local_initial_coordinate":0.4}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"methods","path":"/rows/0/3","approx":{"value":7.95966,"atol":1e-4}}
//|       - {"artifact":"methods","path":"/rows/0/4","approx":{"value":2.81416,"atol":1e-4}}

//|       - {"path":"/outputs/3/state","equals":"satisfied"}
//|   - case: short-budget
//|     expect:
//|       - {"artifact":"methods","path":"/rows/1/8","equals":"SearchBudgetCompleted"}
//|       - {"artifact":"methods","path":"/rows/1/6","equals":20}
//|       - {"artifact":"methods","path":"/rows/2/3","approx":{"value":0.994959,"atol":1e-5}}
//|       - {"artifact":"methods","path":"/rows/2/4","approx":{"value":0.994959,"atol":1e-5}}
//|       - {"artifact":"methods","path":"/rows/2/8","equals":"GradientSmall"}
//|       - {"path":"/outputs/3/state","equals":"partial"}
//|   - case: small-mutation
//|     expect:
//|       - {"artifact":"methods","path":"/rows/1/3","approx":{"value":0.1124,"atol":5e-3}}
//|       - {"artifact":"methods","path":"/rows/2/4","range":{"min":0,"max":1e-6}}
//|       - {"artifact":"methods","path":"/rows/2/3","range":{"min":0,"max":1e-12}}
//|       - {"path":"/outputs/3/state","equals":"failed"}
//|   - case: near-start
//|     expect:
//|       - {"artifact":"methods","path":"/rows/0/3","range":{"min":0,"max":1e-12}}

//|       - {"artifact":"methods","path":"/rows/0/8","equals":"GradientSmall"}
use scioxide_core::{Bounds, Budget, RealScalar, ResidualTolerance};
use scioxide_optimize::{
    Bfgs, BoundedObjective, DifferentialEvolution, DifferentialEvolutionOptions, ObjectiveFn,
    OptimizeTermination,
};
use std::f64::consts::PI;

let sig4 = serde_json::json!({ "significantDigits": 4 });
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
// f(x) = 2A + Σ (xᵢ² − A cos 2πxᵢ)。既知の大域最小は原点で f = 0。
let a = rastrigin_amplitude;
let f = move |p: &[f64]| {
    2.0 * a
        + p.iter()
            .map(|&v| v * v - a * RealScalar::cos(2.0 * PI * v))
            .sum::<f64>()
};
// 勾配 ∂f/∂xᵢ = 2xᵢ + 2πA sin 2πxᵢ。
let objective = ObjectiveFn::new(2, move |p: &[f64]| Ok(f(p))).with_gradient(
    move |p: &[f64], g: &mut [f64]| {
        for (gi, &v) in g.iter_mut().zip(p) {
            *gi = 2.0 * v + 2.0 * PI * a * RealScalar::sin(2.0 * PI * v);
        }
        Ok(())
    },
);
// 局所法: (s, −s) から BFGS を始める。
let initial = [local_initial_coordinate, -local_initial_coordinate];
let local = Bfgs::<f64>::default()
    .minimize(&objective, &initial)
    .map_err(|e| e.to_string())?;
// 集団法: 箱 [−5.12, 5.12]² の中で差分進化を世代数の上限まで回す。
let bounds = Bounds::new(vec![(Some(-5.12_f64), Some(5.12)); 2]).map_err(|e| e.to_string())?;
let bounded = BoundedObjective::new(&objective, &bounds).map_err(|e| e.to_string())?;
let options = DifferentialEvolutionOptions::default()
    .with_fitness_tolerance(
        ResidualTolerance::new(1.0e-10_f64, 1.0e-10).map_err(|e| e.to_string())?,
    )
    .with_max_generations(
        Budget::try_from(de_generation_budget.round() as usize).map_err(|e| e.to_string())?,
    )
    .with_population_size(
        Budget::try_from(de_population_size.round() as usize).map_err(|e| e.to_string())?,
    )
    .with_mutation_factor(de_mutation_factor)
    .with_crossover_rate(de_crossover_rate)
    .with_seed(de_seed.round() as u64);
let global = DifferentialEvolution::new(options)
    .map_err(|e| e.to_string())?
    .minimize(&bounded, &initial)
    .map_err(|e| e.to_string())?;
// 二段構え: 差分進化の最良点から BFGS で局所的な停留性を確かめる。
let polished = Bfgs::<f64>::default()
    .minimize(&objective, global.x())
    .map_err(|e| e.to_string())?;
let norm = |v: &[f64]| v.iter().map(|x| x * x).sum::<f64>().sqrt();
let rows: Vec<_> = [
    ("BFGS（局所法）", &local),
    ("差分進化", &global),
    ("差分進化 → BFGS", &polished),
]
.into_iter()
.map(|(name, r)| {
    (
        name,
        r.x()[0],
        r.x()[1],
        r.fun(),
        norm(r.x()),
        r.grad().map(norm),
        r.iterations(),
        r.fun_evals(),
        r.termination().to_string(),
    )
})
.collect();
let columns = serde_json::json!([
    { "key": "0", "label": "手法" },
    { "key": "1", "label": "最終点 x [-]", "type": "number", "format": sig4 },
    { "key": "2", "label": "最終点 y [-]", "type": "number", "format": sig4 },
    { "key": "3", "label": "目的値 f [-]", "type": "number", "format": sci3 },
    { "key": "4", "label": "原点からの距離 [-]", "type": "number", "format": sci3 },
    { "key": "5", "label": "勾配ノルム [-]", "type": "number", "format": sci3, "nullText": "なし" },
    { "key": "6", "label": "反復・世代 [回]", "type": "integer" },
    { "key": "7", "label": "目的の評価 [回]", "type": "integer" },
    { "key": "8", "label": "終了理由" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "methods" })
);
// 地形（61×61 の格子）と対角線上の断面 f(x, x) を描く。
let grid = |i: usize| -5.12 + 10.24 * i as f64 / 60.0;
let landscape: Vec<[f64; 3]> = (0..=60)
    .flat_map(|r| (0..=60).map(move |c| [grid(c), grid(r), f(&[grid(c), grid(r)])]))
    .collect();
emit_chart!(serde_json::json!({
    "kind": "heatmap",
    "title": "Rastrigin 関数 f(x, y) [-]（色）",
    "data": landscape,
    "xLabel": "設計座標 x [-]",
    "yLabel": "設計座標 y [-]",
    "tooltip": true
}));
let diagonal: Vec<[f64; 2]> = (0..=400)
    .map(|i| {
        let v = -5.12 + 10.24 * i as f64 / 400.0;
        [v, f(&[v, v])]
    })
    .collect();
emit_line_chart!(
    &vec![serde_json::json!({ "name": "f(x, x)", "points": diagonal })],
    options = &serde_json::json!({
        "xLabel": "対角線の座標 x = y [-]",
        "yLabel": "目的関数 f(x, x) [-]",
        "annotations": [{ "kind": "line", "axis": "x", "value": 0.0, "label": "大域最小 x = 0" }]
    })
);
// 判定: 停留性（GradientSmall）と既知の大域最小値 f = 0 の両方を満たすか。
let termination = polished.termination();
let outcome = if polished.is_success() && polished.fun() <= 1.0e-8 {
    Outcome::satisfied("差分進化 → BFGS が既知の大域最小 f = 0 の停留点に達した")
} else if polished.is_success() {
    Outcome::partial("BFGS は停留点に達したが、既知の大域最小 f = 0 ではない")
        .explanation("差分進化の世代数、集団数、シードを変えて、原点の吸引域を探し直す。")
} else if matches!(termination, OptimizeTermination::LineSearchFailed(_)) {
    Outcome::failed("BFGS の直線探索が受理できる刻みを見つけられなかった").explanation(
        "返った点は成功の判定を持たないので、目的値と原点からの距離を別に確かめる。",
    )
} else {
    Outcome::partial("BFGS は勾配の判定を満たす前に止まった")
};
let outcome = outcome
    .status(termination.to_string())
    .diagnostic("目的値 f", polished.fun(), None)
    .diagnostic("原点からの距離", norm(polished.x()), None);
emit_outcome!(outcome);
```

既定の入力では、BFGS は $(3.4,-3.4)$ から 4 回の反復で $(-1.990,1.990)$ に達し、勾配ノルム $1.9\times10^{-10}$ の `GradientSmall` で終わる。
しかし目的値は 7.96、原点からの距離は 2.81 で、精密に求めたのは局所極小である。
しかもこの極小は初期点に最も近い極小 $(2.985,-2.985)$ ではなく、原点の反対側にある。
局所法がどの極小に着くかは、初期点だけでは予想しにくい。

差分進化は 121 世代・4392 回の評価で目的値 $1.6\times10^{-13}$、原点からの距離 $2.9\times10^{-8}$ の点を返すが、終了理由は集団の目的値の広がりが縮んだ `PopulationStagnation` で、成功の分類ではない。
評価回数は $36\times(121+1)=4392$ で、$N_p(G+1)$ の式と一致する。
その点から BFGS を 1 回反復すると、目的値 0、勾配ノルム $2.8\times10^{-9}$ の `GradientSmall` になり、判定は satisfied になる。
探索で吸引域を選び、局所法で停留性を確かめるという役割の分担である。

二段構えの成功は、探索が正しい吸引域を選んだ場合に限られる。
世代数の上限を 20 にすると、差分進化は `SearchBudgetCompleted` で $f=1.08$ の点に止まる。
そこからの BFGS は $(-0.995,0)$、$f=0.995$ の隣の局所極小へ `GradientSmall` で収束し、判定は partial になる。
勾配の判定だけでは、この結果と原点の結果を区別できない。

変異係数を 0.2 にすると、集団は $f=0.112$ で停滞する。
そこからの BFGS は原点から $5.9\times10^{-10}$ の点まで進むが、そこでは $f$ が丸めで 0 になる。
$x^2$ と $A(1-\cos2\pi x)$ はどちらも $10^{-16}$ 程度以下で、$f$ の計算で $A\cos2\pi x\approx10$ や $2A=20$ と足し引きするときの丸め（10 の 1 ulp は $1.8\times10^{-15}$）に埋もれるためである。
勾配ノルムは $2.3\times10^{-7}$ と残り、許容誤差を満たさないので、直線探索は十分な減少を確かめられる刻みを見つけられず `LineSearchFailed(iteration limit reached)` で止まる。
点が原点にあっても、この終了は成功ではなく、判定は failed になる。
初期座標を $s=0.4$ にすると初期点が原点の吸引域に入り、BFGS 単独でも 4 回の反復で原点に達する。

地形の図では、原点を中心とする放物面の上に格子状の凹凸が並ぶ。
対角線の断面では、整数の近くの谷が外側ほど高くなり、谷と谷の間の山の高さは $A$ で決まる。
振幅を 2 にすると山が低くなり、BFGS は $(0.975,-0.975)$、$f=1.95$ の極小に止まる。

## まとめ

BFGS の `GradientSmall` は停留点に達したことだけを示し、既定の初期点 $(3.4,-3.4)$ では $f=7.96$ の局所極小に止まる。
差分進化の `SearchBudgetCompleted` と `PopulationStagnation` は大域最適性の成功ではないので、最良点から BFGS を始めて停留性を確かめる。
そのうえで目的値を既知の答えや別の手法と照合し、隣の局所極小に止まった結果を見分ける。
原点の近くでは目的値が丸めで 0 になり、直線探索が `LineSearchFailed` で止まることがあるので、点の位置と終了理由を分けて読む。
差分進化の計算量は世代数ではなく評価回数の上限 $N_p(G+1)$ で比べる。
