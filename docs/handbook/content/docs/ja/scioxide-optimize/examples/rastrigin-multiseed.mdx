[多峰性のある配置設計を探索する](../rastrigin-de/)では、差分進化（DE）を一つのシードで動かし、最良点から BFGS で停留性を確かめた。
差分進化は乱数を使うので、有限の世代数で得る最良値はシードによって変わる確率変数である。
このページでは同じ Rastrigin 関数 $f(x,y)=2A+\sum\{x_i^2-A\cos(2\pi x_i)\}$（大域最小は原点で $f=0$）を、シードだけを変えて $R$ 回解く。
既知の大域最小点に達した回数を数え、到達率を 95% 信頼区間とともに返し、評価回数の上限をそろえて設定を比べる。

## 到達率と二項分布

各反復の最良点と原点との距離が $10^{-3}$ 未満のとき「原点に到達した」と数える。
この基準は、答えが分かっている試験問題でだけ使える便宜的なものである。
シードが独立なら、$R$ 回のうちの到達数 $K$ は二項分布 $\mathrm{Bin}(R,p)$ に従う（$p$ はこの設定で 1 回の反復が原点に達する確率）。
推定値は $\hat p=K/R$、標準誤差は $\sqrt{p(1-p)/R}$ である。

$\hat p\pm1.96\sqrt{\hat p(1-\hat p)/R}$ の Wald 区間は、$K=0$ や $K=R$ で幅が 0 になり、$R$ が小さいと被覆確率が名目の 95% を大きく下回る。
Wilson 区間は、$|\hat p-p|\le z\sqrt{p(1-p)/R}$（$z=1.96$）を $p$ について解いた範囲で、

$$
\frac{\hat p+\dfrac{z^2}{2R}}{1+\dfrac{z^2}{R}}
\pm
\frac{z}{1+\dfrac{z^2}{R}}
\sqrt{\frac{\hat p(1-\hat p)}{R}+\frac{z^2}{4R^2}}
$$

となる。
$K=0$ でも上限は正で、$R=20$ なら $0.161$ になる。
二つの設定の区間が大きく重なるなら、その反復数では到達率の違いを結論できない。

1 回の反復で評価できる回数の上限は $N_p(G+1)$ である（$N_p$ は集団数、$G$ は世代数の上限）。
集団数と世代数を同時に変えるときは、この上限をそろえて比べる。
集団を大きくすると多くの吸引域を同時に探せるが、世代数が減ると一つの吸引域を詰める回数が減る。
`DifferentialEvolutionOptions` の既定の集団数は変数の数 $n$ に比例する $\max(15n,4)$ である。

## シードを変えて繰り返す

反復 $r$ $(r=0,\dots,R-1)$ のシードを $s_0+10007r$ とし、箱 $[-5.12,5.12]^2$、集団数、世代数の上限、開始点 $(3.5,-3.5)$ はすべての反復で同じにする。
変異係数 $F=0.8$、交叉率 $C_R=0.9$、目的値の広がりの許容誤差は既定（絶対・相対とも $\sqrt{\varepsilon_{\mathrm{mach}}}$）である。

入力は反復数 $R$、集団数、世代数の上限、振幅 $A$、シードの基点 $s_0$ である。
出力は次のとおりである。

- 各反復の最良値と原点からの距離の図（縦軸は対数）
- 各反復のシード、最良値、距離、世代数、評価回数、終了理由の表
- 到達数、到達率と 95% Wilson 区間、最良値の平均と標準偏差、評価回数の上限の表

基準の距離 $10^{-3}$ は固定し、偶然よいシードだけを選ばずに全反復を数える。
最良値や距離が厳密に 0 の反復は対数軸に描けないので、その数を表に示す。

```rust
//| id: optimize-rastrigin-multiseed
//| ref: optimize-rastrigin-multiseed
//| title: 有限の世代数の差分進化を独立なシードで繰り返す
//| run: reactive
//| crates: [scioxide-core, scioxide-optimize]
//| inputs:
//|   multiseed_runs: {"type":"range","label":"反復数 R [回]","description":"到達率を数える独立な反復の数を変える。","min":8,"max":32,"step":2,"value":20}
//|   multiseed_population: {"type":"range","label":"集団数 Nₚ [点]","description":"多様性と 1 世代の計算コストを変える。","min":8,"max":48,"step":4,"value":20}
//|   multiseed_generations: {"type":"range","label":"世代数の上限 G [世代]","description":"各反復の探索の長さを変える。","min":15,"max":150,"step":5,"value":55}
//|   multiseed_amplitude: {"type":"range","label":"凹凸の振幅 A [-]","description":"局所極小の吸引域の強さを変える。","min":3,"max":18,"step":1,"value":10}
//|   multiseed_base_seed: {"type":"range","label":"シードの基点 s₀ [-]","description":"反復 r のシードを s₀ + 10007r とする。","min":1,"max":1000,"step":1,"value":97}
//| cases:
//|   - {"id":"long-budget","label":"世代数の上限 G = 150","description":"1 反復の評価回数の上限は 3020 回に増え、到達は 19/20 回（95% Wilson 区間 0.764〜0.991）になる。","inputs":{"multiseed_generations":150}}
//|   - {"id":"tiny-budget","label":"世代数の上限 G = 15","description":"1 反復の評価回数の上限は 320 回で、原点に達する反復はなく（区間 0〜0.161）、最良値の平均は 2.43 に上がる。","inputs":{"multiseed_generations":15}}
//|   - {"id":"other-seeds","label":"シードの基点 s₀ = 1000","description":"同じ設定でシードだけを変えると到達は 7/20 回（区間 0.181〜0.567）になり、既定の区間 0.081〜0.416 と重なる。","inputs":{"multiseed_base_seed":1000}}
//|   - {"id":"deep-search","label":"Nₚ = 12、G = 90","description":"評価回数の上限 1092 回は既定とほぼ同じで、到達は 11/20 回（区間 0.342〜0.742）に増えるが、残りの反復は f = 0.995 の隣の極小に止まる。","inputs":{"multiseed_population":12,"multiseed_generations":90}}
//|   - {"id":"wide-search","label":"Nₚ = 40、G = 25","description":"評価回数の上限 1040 回で、到達は 0/20 回（区間 0〜0.161）になり、どの反復も世代数の上限で止まる。","inputs":{"multiseed_population":40,"multiseed_generations":25}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"summary","path":"/rows/0/1","equals":4}
//|       - {"artifact":"summary","path":"/rows/2/1","approx":{"value":0.08066,"atol":1e-4}}
//|       - {"artifact":"summary","path":"/rows/3/1","approx":{"value":0.41602,"atol":1e-4}}
//|       - {"artifact":"summary","path":"/rows/6/1","equals":1120}
//|   - case: long-budget
//|     expect:
//|       - {"artifact":"summary","path":"/rows/0/1","equals":19}
//|       - {"artifact":"summary","path":"/rows/6/1","equals":3020}
//|   - case: tiny-budget
//|     expect:
//|       - {"artifact":"summary","path":"/rows/0/1","equals":0}
//|       - {"artifact":"summary","path":"/rows/3/1","approx":{"value":0.16113,"atol":1e-4}}
//|       - {"artifact":"summary","path":"/rows/6/1","equals":320}
//|   - case: other-seeds
//|     expect:
//|       - {"artifact":"summary","path":"/rows/0/1","equals":7}
//|   - case: deep-search
//|     expect:
//|       - {"artifact":"summary","path":"/rows/0/1","equals":11}
//|       - {"artifact":"summary","path":"/rows/6/1","equals":1092}
//|   - case: wide-search
//|     expect:
//|       - {"artifact":"summary","path":"/rows/0/1","equals":0}
//|       - {"artifact":"summary","path":"/rows/6/1","equals":1040}
use scioxide_core::{Bounds, Budget, RealScalar};
use scioxide_optimize::{
    BoundedObjective, DifferentialEvolution, DifferentialEvolutionOptions, ObjectiveFn,
};
use std::f64::consts::PI;

let sig4 = serde_json::json!({ "significantDigits": 4 });
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let a = multiseed_amplitude;
let objective = ObjectiveFn::new(2, move |p: &[f64]| {
    Ok(2.0 * a
        + p.iter()
            .map(|&v| v * v - a * RealScalar::cos(2.0 * PI * v))
            .sum::<f64>())
});
let bounds = Bounds::new(vec![(Some(-5.12_f64), Some(5.12)); 2]).map_err(|e| e.to_string())?;
let bounded = BoundedObjective::new(&objective, &bounds).map_err(|e| e.to_string())?;
let (runs, population, generations) = (
    multiseed_runs.round() as usize,
    multiseed_population.round() as usize,
    multiseed_generations.round() as usize,
);
let (mut rows, mut values, mut distances, mut reached) =
    (Vec::new(), Vec::new(), Vec::new(), 0_usize);
for run in 0..runs {
    // シードだけを変え、箱・集団数・世代数・開始点はすべての反復で同じにする。
    let seed = multiseed_base_seed.round() as u64 + 10_007 * run as u64;
    let options = DifferentialEvolutionOptions::default()
        .with_max_generations(Budget::try_from(generations).map_err(|e| e.to_string())?)
        .with_population_size(Budget::try_from(population).map_err(|e| e.to_string())?)
        .with_seed(seed);
    let r = DifferentialEvolution::new(options)
        .map_err(|e| e.to_string())?
        .minimize(&bounded, &[3.5_f64, -3.5])
        .map_err(|e| e.to_string())?;
    let distance = r.x().iter().map(|v| v * v).sum::<f64>().sqrt();
    // 原点からの距離 10⁻³ 未満を「原点に到達」と数える（答えが既知の試験問題でだけ使える基準）。
    if distance < 1.0e-3 {
        reached += 1;
    }
    values.push(r.fun());
    distances.push(distance);
    rows.push((
        run + 1,
        seed,
        r.fun(),
        distance,
        r.iterations(),
        r.fun_evals(),
        r.termination().to_string(),
    ));
}
let mean = values.iter().sum::<f64>() / runs as f64;
let sd = (values.iter().map(|v| (v - mean).powi(2)).sum::<f64>() / (runs - 1) as f64).sqrt();
// 到達率 p̂ = K/R の 95% Wilson 区間。
let (p, n, z) = (reached as f64 / runs as f64, runs as f64, 1.96_f64);
let centre = (p + z * z / (2.0 * n)) / (1.0 + z * z / n);
let half = z / (1.0 + z * z / n) * (p * (1.0 - p) / n + z * z / (4.0 * n * n)).sqrt();
// K = 0 では下限は厳密に 0 なので、丸めで生じる負の微小値だけを 0 にそろえる。
let (lower, upper) = ((centre - half).max(0.0), centre + half);
// 目的値・距離が 0 の反復は対数軸に描けないので点を置かない（件数を表に出す）。
let positive = |v: &[f64]| {
    v.iter()
        .enumerate()
        .filter(|&(_, &x)| x > 0.0)
        .map(|(i, &x)| [i as f64 + 1.0, x])
        .collect::<Vec<_>>()
};
let zero_count = values
    .iter()
    .chain(&distances)
    .filter(|&&v| v <= 0.0)
    .count();
emit_scatter_chart!(
    &vec![
        serde_json::json!({ "name": "最良値 f", "points": positive(&values) }),
        serde_json::json!({
            "name": "原点からの距離",
            "points": positive(&distances),
            "style": { "symbol": "triangle" }
        }),
    ],
    options = &serde_json::json!({
        "xLabel": "反復の番号 r + 1 [-]",
        "yLabel": "最良値 f・原点からの距離 [-]",
        "yType": "log",
        "annotations": [
            { "kind": "line", "axis": "y", "value": 1.0e-3, "label": "到達とみなす距離 10⁻³" }
        ]
    })
);
let run_columns = serde_json::json!([
    { "key": "0", "label": "反復", "type": "integer" },
    { "key": "1", "label": "シード", "type": "integer" },
    { "key": "2", "label": "最良値 f [-]", "type": "number", "format": sci3 },
    { "key": "3", "label": "原点からの距離 [-]", "type": "number", "format": sci3 },
    { "key": "4", "label": "世代 [回]", "type": "integer" },
    { "key": "5", "label": "目的の評価 [回]", "type": "integer" },
    { "key": "6", "label": "終了理由" }
]);
emit_table_with_columns!(
    run_columns,
    rows,
    metadata = serde_json::json!({ "id": "runs" })
);
let summary_columns = serde_json::json!([
    { "key": "0", "label": "集計" },
    { "key": "1", "label": "値", "type": "number", "format": sig4 }
]);
emit_table_with_columns!(
    summary_columns,
    vec![
        ("原点への到達数 K [回]", reached as f64),
        ("到達率 p̂ = K/R [-]", p),
        ("95% Wilson 区間の下限 [-]", lower),
        ("95% Wilson 区間の上限 [-]", upper),
        ("最良値の平均 [-]", mean),
        ("最良値の標準偏差 [-]", sd),
        (
            "1 反復の評価回数の上限 Nₚ(G+1) [回]",
            (population * (generations + 1)) as f64
        ),
        ("対数軸から除いた 0 の値 [個]", zero_count as f64),
    ],
    metadata = serde_json::json!({ "id": "summary" })
);
```

既定の 20 反復（集団数 20、世代数の上限 55、$A=10$）では、どの反復も世代数の上限に達して `SearchBudgetCompleted` で止まる。
原点に達したのは 4 回で、到達率 $\hat p=0.20$ の 95% Wilson 区間は $0.081$〜$0.416$ である。
最良値の平均は 0.119、標準偏差は 0.254 である。
16 回は $f<0.1$ だが、そのうち 12 回は原点からの距離が $10^{-3}$ に届かない。
残りの 4 回の最良値は $f=0.23$〜$0.995$ で、そのうち 1 回は隣の局所極小の値 0.995 に止まっている。
シードの基点を 1000 にすると到達は 7 回（0.35、区間 0.181〜0.567）になり、区間は既定の区間と重なる。
20 回の反復では、シードの違いと設定の違いを区別できるほどの精度はない。

世代数の上限を 150 にすると到達は 19 回（区間 0.764〜0.991）、15 にすると 0 回（区間 0〜0.161）になる。
世代数の上限を 150 にした 20 回は、すべて集団が縮んで `PopulationStagnation` で止まり、そのうち 1 回は $f=0.995$ の隣の極小で縮んでいる。
停滞が成功を意味しないことが、この 1 回から分かる。

評価回数の上限をおよそ 1100 回にそろえて集団数と世代数の配分を変えると、結果は大きく変わる。
集団数 12、世代数 90（上限 1092 回）では到達は 11 回（区間 0.342〜0.742）に増えるが、到達しなかった 9 回はすべて $f=0.995$ の隣の極小に止まり、最良値の平均は 0.448 と既定より大きい。
集団数 40、世代数 25（上限 1040 回）では到達は 0 回で、最良値は 0.04 から 1.2 に散らばる。
この二次元の問題で比べた二つの配分では、集団を小さくして世代を重ねるほうが原点に達しやすい。
ただし到達率と最良値の平均は別の性質を測っており、どちらで設定を選ぶかは目的によって決める。
次元が上がると既定の集団数 $15n$ も増えるので、二次元の結論をそのまま高次元へ移さない。

## 答えの分からない問題での停止と検証

実際の設計問題では、$f^\star=0$ のような答えを使えない。
その代わりに、独立なシードの最良値が同じ範囲に集まる、集団探索と多開始の局所法が同じ吸引域を見つける、評価回数の上限を倍にしても改善が小さい、制約と物理モデルを独立に評価し直す、といった証拠を重ねる。

境界を狭くすれば探索は易しくなるが、真の解を切り落とすおそれがある。
有限の境界は差分進化に必須の入力であり、単なる数値の設定ではなく、設計できる範囲というモデルの仮定である。
最良点が境界に張り付くなら、境界の妥当性か目的の単調性を見直す。

結果を再現するには、シード、集団数、世代数の上限、$F$、$C_R$、戦略、境界をすべて記録する。
「差分進化を使った」だけでは結果を再現できない。

## まとめ

確率的な探索の性能は一つのシードで判断せず、独立なシードで繰り返した到達数を 95% Wilson 区間とともに返す。
到達が 0 回でも Wilson 区間の上限は正なので、「一度も成功しなかった」を「成功しない」と読まない。
設定を比べるときは評価回数の上限 $N_p(G+1)$ をそろえ、区間が重なる差は反復数を増やしてから判断する。
到達率と最良値の平均は異なる性質を測るので、停滞した反復が隣の極小に集まっていないかを表で確かめる。
答えの分からない問題では、独立なシードの最良値の集まり方、多開始の局所法との一致、評価回数を倍にしたときの改善量で候補を評価する。
