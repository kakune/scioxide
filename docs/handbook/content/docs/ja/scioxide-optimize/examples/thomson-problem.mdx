単位球面上に $N$ 個の同符号の点電荷を置くと、電荷は互いの距離を広げようとする。
最もエネルギーの低い配置を求める問題は J. J. Thomson が 1904 年に原子モデルの研究で提起したもので、Thomson 問題と呼ばれる。
電荷の大きさと Coulomb 定数を 1 とし、長さを球の半径で測った無次元のエネルギーは

$$
E=\sum_{i<j}\frac1{\|r_i-r_j\|_2},\qquad \|r_i\|_2=1
$$

である。
ここで $r_i\in\mathbb R^3$ は電荷 $i$ の位置である。
各点を $r=(\sin\theta\cos\phi,\sin\theta\sin\phi,\cos\theta)$ と表せば、球面制約を常に満たしたまま制約のない最小化として解ける。
変数は $2N$ 個の角度 $(\theta_i,\phi_i)$ である。

## 勾配と座標の性質

直交座標での勾配は $\partial E/\partial r_i=-\sum_{j\ne i}(r_i-r_j)/\|r_i-r_j\|^3$ である。
連鎖律により、角度の勾配はこれと

$$
\frac{\partial r}{\partial\theta}=(\cos\theta\cos\phi,\cos\theta\sin\phi,-\sin\theta),\qquad
\frac{\partial r}{\partial\phi}=(-\sin\theta\sin\phi,\sin\theta\cos\phi,0)
$$

との内積になる。
一回の評価は $N(N-1)/2$ 対を回るので $O(N^2)$ である。
密な BFGS は $2N\times2N$ の逆ヘッセ近似を持ち、その更新に一反復 $O(N^2)$ の演算を使う。

全体の回転でエネルギーは変わらないので、最小点は 3 次元の族をなし、ヘッセ行列には零固有値が残る。
極 $\sin\theta=0$ では $\partial r/\partial\phi=0$ となり、方位角が点を動かさないため、角度のヘッセ行列はさらに退化しうる。
二つの電荷が衝突すると目的は発散する。
これらは座標とモデルの性質であり、BFGS の収束が遅くなる形で現れる。
勾配の判定で停止したかを終了理由で確かめ、返った点で角度の勾配の 2 ノルムを計算し直す。

`Bfgs::default()` の勾配の判定は、勾配の 2 ノルムが $\varepsilon_a+\varepsilon_r\max(1,|E|/\max(1,\|q\|_\infty))$ 以下になることで、$\varepsilon_a=\varepsilon_r=\sqrt{\varepsilon}\approx1.5\times10^{-8}$ である。
ここで $q$ は角度を並べた変数、$\varepsilon$ は倍精度の計算機イプシロンである。
判定を満たすと終了理由は `GradientSmall` になる。

## 対称な配置による検算

2 点は対蹠点で $E=1/2$、3 点は大円上の正三角形で辺が $\sqrt3$ なので $E=3/\sqrt3=\sqrt3$ になる。
4 点は正四面体で、辺の長さ $\sqrt{8/3}$ の 6 組から $E=6/\sqrt{8/3}=3.6742346142\ldots$ を得る。
6 点の正八面体は距離 $\sqrt2$ の 12 組と距離 2 の 3 組から $E=12/\sqrt2+3/2=9.9852813742\ldots$ を得る。
12 点の正二十面体では、各点から距離 $a=1/\sin(2\pi/5)$ の 5 点、距離 $\varphi a$（$\varphi$ は黄金比）の 5 点、対蹠点 1 点が見えるので、$E=30/a+30/(\varphi a)+6/2=49.1652530576\ldots$ になる。
これらは対称性から導いた値で、最小であることの証明ではない。

他の点数の参照値は Wikipedia の [Thomson problem の表](https://en.wikipedia.org/wiki/Thomson_problem)（小数 9 桁）の値である。
10〜12 点は [Cambridge Cluster Database](https://www-wales.ch.cam.ac.uk/~wales/CCD/Thomson/table.html)（小数 7 桁）にも載っており、7 桁で一致する。
表の値は丸めてあるので、差が $5\times10^{-10}$ 以下なら丸めの範囲にある。
11 点だけはこのセルのどの開始点も 40.5964505082 に達し、表の値 40.596450510 との差 $-1.8\times10^{-9}$ が丸めの範囲を超える。
返った値は実際の配置のエネルギーなので、最小エネルギーはこの値以下である。
したがって表の値は最小エネルギーより少なくとも $1.8\times10^{-9}$ 大きく、この差は求解の未収束では説明できない。
Cambridge Cluster Database の値 40.5964505 とは一致するので、9 桁の表の最後の 1〜2 桁には意味を持たせない。

## 計算の入力と出力

入力は点数、開始点の数、乱数のシードである。
開始点は球面上の一様分布から引き、$\cos\theta$ を $[-1,1]$、$\phi$ を $[0,2\pi)$ の一様乱数にする。
出力は最良の配置の 3 次元図、各開始点の結果の表、全体の判定である。
表には各開始点のエネルギー、参照値との差、角度の勾配のノルム、終了理由を並べ、最良値だけを抜き出して不成功の試行を隠すことはしない。
図は最もエネルギーの低い配置の点と、その凸包の辺を描く。
凸包の計算には `scioxide-spatial` の `ConvexHull` を使い、3 点以下では凸包が立体にならないので全ての組を結ぶ。
点の id は電荷の番号なので、入力を変えても選んだ点と視点は保たれる。

```rust
//| id: optimize-thomson-multistart
//| ref: optimize-thomson-multistart
//| title: 球面上の電荷を複数の開始点から配置する
//| run: button
//| timeoutMs: 120000
//| crates: [scioxide-core, scioxide-optimize, scioxide-random, scioxide-spatial]
//| inputs:
//|   charges: {"type":"range","label":"電荷数 N [個]","min":2,"max":12,"step":1,"value":4}
//|   starts: {"type":"range","label":"開始点数 [回]","min":1,"max":8,"step":1,"value":3}
//|   seed: {"type":"range","label":"乱数のシード [-]","min":1,"max":100,"step":1,"value":7}
//| cases:
//|   - {"id":"icosahedron","label":"12 個（正二十面体）","description":"3 個の開始点がどれも 49.165253058 に達し、正二十面体の閉形式との差は 10⁻¹⁰ 以下になる。凸包の各点は 5 本の辺を持つ。","inputs":{"charges":12}}
//|   - {"id":"eleven","label":"11 個","description":"どの開始点も 40.5964505082 に達し、Wikipedia の表の値 40.596450510 との差は −1.8×10⁻⁹ で、表の丸めの範囲を超える。","inputs":{"charges":11}}
//|   - {"id":"single-start","label":"5 個、開始点 1 個","description":"一つの開始点でも 6.474691495 の三角両錐に達するが、一回の到達は大域最小の証拠にならない。","inputs":{"charges":5,"starts":1}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"runs","path":"/rows/0/1","approx":{"value":3.674234614,"atol":1e-8}}
//|       - {"artifact":"runs","path":"/rows/2/1","approx":{"value":3.674234614,"atol":1e-8}}
//|       - {"artifact":"runs","path":"/rows/0/4","range":{"min":0,"max":1e-5}}
//|       - {"artifact":"runs","path":"/rows/0/5","equals":"GradientSmall"}
//|       - {"artifact":"configuration","path":"/points/3/id","equals":"charge-3"}
//|       - {"path":"/outputs/2/state","equals":"satisfied"}
//|   - case: icosahedron
//|     expect:
//|       - {"artifact":"runs","path":"/rows/0/1","approx":{"value":49.165253058,"atol":1e-8}}
//|       - {"artifact":"runs","path":"/rows/1/1","approx":{"value":49.165253058,"atol":1e-8}}
//|       - {"artifact":"runs","path":"/rows/2/1","approx":{"value":49.165253058,"atol":1e-8}}
//|       - {"path":"/outputs/2/state","equals":"satisfied"}
//|   - case: eleven
//|     expect:
//|       - {"artifact":"runs","path":"/rows/0/1","approx":{"value":40.5964505082,"atol":1e-9}}
//|       - {"artifact":"runs","path":"/rows/0/3","approx":{"value":-1.8e-9,"atol":5e-10}}
//|   - case: single-start
//|     expect:
//|       - {"artifact":"runs","path":"/rows/0/1","approx":{"value":6.474691495,"atol":1e-8}}
use scioxide_core::RealScalar;
use scioxide_optimize::{Bfgs, ObjectiveFn};
use scioxide_random::{BitGenerator, SeedableRng, SplitMix64, decode_u64};
use scioxide_spatial::{ConvexHull, PointSet};
// q = (θ₀, φ₀, θ₁, φ₁, …)。点 r と ∂r/∂θ、∂r/∂φ を作り、直交座標の勾配と内積を取る。
fn energy(q: &[f64]) -> (f64, Vec<f64>) {
    let points: Vec<_> = q
        .chunks_exact(2)
        .map(|a| {
            let (s, c) = (RealScalar::sin(a[0]), RealScalar::cos(a[0]));
            let (sp, cp) = (RealScalar::sin(a[1]), RealScalar::cos(a[1]));
            (
                [s * cp, s * sp, c],
                [c * cp, c * sp, -s],
                [-s * sp, s * cp, 0.0],
            )
        })
        .collect();
    let mut value = 0.0;
    let mut gradient = vec![0.0; q.len()];
    for i in 0..points.len() {
        for j in 0..i {
            let d: [f64; 3] = std::array::from_fn(|k| points[i].0[k] - points[j].0[k]);
            let distance = RealScalar::sqrt(d.iter().map(|v| v * v).sum::<f64>());
            value += 1.0 / distance;
            for k in 0..3 {
                let force = -d[k] / distance.powi(3);
                gradient[2 * i] += force * points[i].1[k];
                gradient[2 * i + 1] += force * points[i].2[k];
                gradient[2 * j] -= force * points[j].1[k];
                gradient[2 * j + 1] -= force * points[j].2[k];
            }
        }
    }
    (value, gradient)
}
let n = charges as usize;
// N = 2, …, 12 の参照値（2、3、4、6、12 は閉形式、他は文献の表の値。小数 9 桁）。
let references = [
    0.5,
    1.732050808,
    3.674234614,
    6.474691495,
    9.985281374,
    14.452977414,
    19.675287861,
    25.759986531,
    32.716949460,
    40.596450510,
    49.165253058,
];
let objective = ObjectiveFn::new(2 * n, |q: &[f64]| Ok(energy(q).0)).with_gradient(
    |q: &[f64], g: &mut [f64]| {
        g.copy_from_slice(&energy(q).1);
        Ok(())
    },
);
let mut rng = SplitMix64::from_seed(seed as u64);
let mut rows = Vec::new();
let mut best: Option<(f64, Vec<f64>)> = None;
let mut all_success = true;
for run in 0..starts as usize {
    // 球面上の一様分布: cos θ を [−1, 1] の一様乱数、φ を [0, 2π) の一様乱数にする。
    let mut q = Vec::new();
    for _ in 0..n {
        let u: f64 = decode_u64(rng.next_uniform_u64().map_err(|e| e.to_string())?);
        let v: f64 = decode_u64(rng.next_uniform_u64().map_err(|e| e.to_string())?);
        q.push(RealScalar::acos(2.0 * u - 1.0));
        q.push(2.0 * std::f64::consts::PI * v);
    }
    let result = Bfgs::default()
        .minimize(&objective, &q)
        .map_err(|e| e.to_string())?;
    all_success &= result.is_success();
    // 独立な検算: 返った角度を目的に代入し直し、角度の勾配の 2 ノルムを求める。
    let gradient = energy(result.x()).1;
    rows.push((
        run + 1,
        result.fun(),
        references[n - 2],
        result.fun() - references[n - 2],
        RealScalar::sqrt(gradient.iter().map(|g| g * g).sum::<f64>()),
        result.termination().to_string(),
    ));
    if best.as_ref().is_none_or(|b| result.fun() < b.0) {
        best = Some((result.fun(), result.x().to_vec()));
    }
}
let (best_energy, best_q) = best.ok_or("開始点がない")?;
// 最良の配置を直交座標に戻し、凸包の三角形の辺を描く。3 点以下は全ての組を結ぶ。
let cartesian: Vec<f64> = best_q
    .chunks_exact(2)
    .flat_map(|a| {
        let s = RealScalar::sin(a[0]);
        [s * RealScalar::cos(a[1]), s * RealScalar::sin(a[1]), RealScalar::cos(a[0])]
    })
    .collect();
let mut pairs = std::collections::BTreeSet::new();
if n <= 3 {
    for i in 0..n {
        for j in 0..i {
            pairs.insert((j, i));
        }
    }
} else {
    let sites = PointSet::from_rows(&cartesian, 3).map_err(|e| e.to_string())?;
    let hull = ConvexHull::new(&sites).map_err(|e| e.to_string())?;
    for facet in hull.facets().chunks_exact(3) {
        for (a, b) in [(facet[0], facet[1]), (facet[1], facet[2]), (facet[2], facet[0])] {
            pairs.insert((a.min(b), a.max(b)));
        }
    }
}
let points: Vec<_> = cartesian
    .chunks_exact(3)
    .enumerate()
    .map(|(i, p)| {
        serde_json::json!({
            "id": format!("charge-{i}"),
            "position": [p[0], p[1], p[2]],
            "label": format!("電荷 {i}"),
            "group": "charges"
        })
    })
    .collect();
let edges: Vec<_> = pairs
    .iter()
    .map(|&(a, b)| {
        serde_json::json!({ "from": format!("charge-{a}"), "to": format!("charge-{b}") })
    })
    .collect();
let unit = |label: &str| serde_json::json!({ "label": label, "unit": "球の半径" });
emit_scene3d!(
    serde_json::json!({
        "points": points,
        "edges": edges,
        "groups": [{ "id": "charges", "label": "最良の配置の電荷" }],
        "axes": { "x": unit("x"), "y": unit("y"), "z": unit("z") }
    }),
    metadata = serde_json::json!({ "id": "configuration", "title": "最良の配置と凸包の辺" })
);
let fixed10 = serde_json::json!({ "fractionDigits": 10 });
let fixed9 = serde_json::json!({ "fractionDigits": 9 });
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let columns = serde_json::json!([
    { "key": "0", "label": "開始点", "type": "integer" },
    { "key": "1", "label": "エネルギー E [-]", "type": "number", "format": fixed10 },
    { "key": "2", "label": "参照値 [-]", "type": "number", "format": fixed9 },
    { "key": "3", "label": "差 [-]", "type": "number", "format": sci2 },
    { "key": "4", "label": "角度の勾配のノルム [-]", "type": "number", "format": sci2 },
    { "key": "5", "label": "終了理由" }
]);
emit_table_with_columns!(
    columns,
    rows.clone(),
    metadata = serde_json::json!({ "id": "runs" })
);
let spread = rows.iter().map(|r| r.1).fold(f64::NEG_INFINITY, f64::max) - best_energy;
let outcome = if all_success {
    Outcome::satisfied("全ての開始点が勾配の判定を満たした")
        .explanation("大域最小の証明ではなく、試した開始点の範囲での観測である。")
} else {
    Outcome::partial("勾配の判定を満たさずに止まった開始点がある")
        .explanation("その開始点のエネルギーは推定値として読み、終了理由を表で確かめる。")
};
emit_outcome!(
    outcome
        .status(rows[0].5.clone())
        .diagnostic("最良のエネルギー", best_energy, None)
        .diagnostic("開始点の間の最大差", spread, None)
);
```

既定の 4 点では、3 個の開始点がどれも 3.6742346142 に達し、正四面体の閉形式 $6/\sqrt{8/3}$ と $2\times10^{-10}$ の差（参照値の丸め）で一致する。
図の凸包は 4 枚の三角形からなる正四面体で、2 点の距離を測ると辺の長さ $\sqrt{8/3}\approx1.633$ が読める。
12 点ではどの開始点も 49.165253058 に達し、凸包は正二十面体になって各点から 5 本の辺が出る。
5 点では 2 個の極と赤道上の正三角形からなる三角両錐に達する。
シード 7 で開始点を 8 個にして 3〜12 点を試すと、点数ごとに全ての開始点が同じ値（差は $10^{-14}$ 程度）に達した。
それでも、シードを変えたときの目的値の違いは異なる局所配置に到達した可能性を示すので、全ての開始点の値を並べて読む。
同じエネルギーでも回転や粒子番号の交換により座標は異なる。

凸包は計算した座標の厳密な凸包を三角形に分割したもので、8 点の正方反柱のように四角形の面を持つ配置では、その面に対角線が 1 本引かれる。
図の辺は配置を見るための補助で、対称性の判定には使わない。

## まとめ

球面座標を使うと球面制約が変数の取り方に含まれ、Thomson 問題を制約のない BFGS で解ける。
角度の勾配は直交座標の勾配と $\partial r/\partial\theta$、$\partial r/\partial\phi$ の内積で求まり、極ではこの座標が退化する。
2、3、4、6、12 点は対蹠点と正多面体の閉形式と照合し、他の点数は文献の表と照合して、表の最後の桁より小さい差には意味を持たせない。
複数の開始点が同じ値に達しても、それは試した開始点の範囲での観測であり、大域最小の証明ではない。
