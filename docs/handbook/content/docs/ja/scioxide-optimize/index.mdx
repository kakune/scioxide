数理最適化は実行可能領域 $\Omega \subseteq \mathbb{R}^n$ の中で目的関数 $f: \mathbb{R}^n \to \mathbb{R}$ を最小にする決定変数 $\mathbf{x}^* \in \Omega$ を求める問題である。
等式制約 $c_i$、不等式制約 $g_j$、変数の上下限 $\mathbf{l}, \mathbf{u}$ で $\Omega$ を書くと、次の形になる。

$$
\min_{\mathbf{x} \in \mathbb{R}^n} f(\mathbf{x}) \quad \text{subject to} \quad \begin{cases} c_i(\mathbf{x}) = 0 & (i \in \mathcal{E}) \\ g_j(\mathbf{x}) \le 0 & (j \in \mathcal{I}) \\ \mathbf{l} \le \mathbf{x} \le \mathbf{u} \end{cases}
$$

パラメータの推定、損失関数の最小化、エネルギーが最小の状態の探索、軌道設計、資産配分などがこの形になる。
解き方は目的の滑らかさ、微分（勾配・ヘッセ行列）が得られるか、制約が線形か非線形か、変数が連続か整数か、極小点が一つか多数か（単峰か多峰か）で変わる。
`scioxide-optimize` は無制約・ボックス制約の局所法、非線形制約付きの方法、非線形・線形最小二乗、線形・二次・混合整数計画、二次割当て、合成目的と分割法、標本化した目的、多目的、大域探索を提供する。
最大化は目的の符号を反転して最小化として解く。

## 最初の計算

Rosenbrock 関数 $f(x_1, x_2) = (1 - x_1)^2 + 100 (x_2 - x_1^2)^2$ は、最小点 $(1, 1)$（最小値 0）へ向かう曲がった細い谷を持つ。
次のセルは解析的な勾配を渡した `Bfgs` で初期点から最小化し、終了理由、反復と評価の回数、勾配のノルムと停止のしきい値、既知の最小点との距離を表にする。
しきい値は勾配の許容誤差を定める式 $\tau = a + r \cdot \max\bigl(1, |f(\mathbf{x})| / \max(1, \lVert\mathbf{x}\rVert_\infty)\bigr)$ から計算し直した値で、既定は $a = r = \sqrt{\varepsilon} \approx 1.49 \times 10^{-8}$（$\varepsilon$ は `f64` の機械イプシロン）である。
`Bfgs` は $\lVert\nabla f(\mathbf{x})\rVert_2 \le \tau$ を満たすと `GradientSmall` で止まる。

```rust
//| id: optimize-overview-first-bfgs
//| ref: optimize-overview-first-bfgs
//| title: Rosenbrock 関数を BFGS で最小化して結果を読む
//| run: reactive
//| crates: [scioxide-core, scioxide-optimize]
//| inputs:
//|   start_x1: {"type":"range","label":"初期点 x₁ [-]","description":"谷の反対側から始めると反復が増える。","min":-2,"max":2,"step":0.1,"value":-1.2}
//|   start_x2: {"type":"range","label":"初期点 x₂ [-]","description":"谷からの離れ具合を変える。","min":-1,"max":3,"step":0.1,"value":1}
//| cases:
//|   - {"id":"far-above-valley","label":"初期点 (−1.2, 3)","description":"谷の上方から入ると 48 反復で GradientSmall になり、同じ最小点 (1, 1) に着く。","inputs":{"start_x1":-1.2,"start_x2":3}}
//|   - {"id":"left-edge","label":"初期点 (−2, 1)","description":"左端から入ると 26 反復で GradientSmall になり、最小点との距離は 10⁻⁹ 未満である。","inputs":{"start_x1":-2,"start_x2":1}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"bfgs","path":"/rows/0/0","equals":"GradientSmall"}
//|       - {"artifact":"bfgs","path":"/rows/0/2","range":{"min":35,"max":39}}
//|       - {"artifact":"bfgs","path":"/rows/0/5","range":{"min":0,"max":1e-12}}
//|       - {"artifact":"bfgs","path":"/rows/0/6","range":{"min":0,"max":3e-8}}
//|       - {"artifact":"bfgs","path":"/rows/0/7","approx":{"value":2.9802322387695312e-8,"rtol":1e-6}}
//|       - {"artifact":"bfgs","path":"/rows/0/8","range":{"min":0,"max":1e-6}}
//|       - {"path":"/outputs/1/state","equals":"satisfied"}
//|   - case: far-above-valley
//|     expect:
//|       - {"artifact":"bfgs","path":"/rows/0/0","equals":"GradientSmall"}
//|       - {"artifact":"bfgs","path":"/rows/0/2","range":{"min":45,"max":51}}
//|       - {"artifact":"bfgs","path":"/rows/0/8","range":{"min":0,"max":1e-6}}
//|   - case: left-edge
//|     expect:
//|       - {"artifact":"bfgs","path":"/rows/0/0","equals":"GradientSmall"}
//|       - {"artifact":"bfgs","path":"/rows/0/2","range":{"min":24,"max":28}}
//|       - {"artifact":"bfgs","path":"/rows/0/8","range":{"min":0,"max":1e-6}}
use scioxide_core::{GradientTolerance, RealScalar};
use scioxide_optimize::{Bfgs, ObjectiveFn, OptimizeTermination};

// 目的と解析的な勾配。ObjectiveFn は返り値の有限性を検査する。
let rosenbrock = ObjectiveFn::new(2, |x: &[f64]| {
    let a = 1.0 - x[0];
    let b = x[1] - x[0] * x[0];
    Ok(a * a + 100.0 * b * b)
})
.with_gradient(|x: &[f64], g: &mut [f64]| {
    let b = x[1] - x[0] * x[0];
    g[0] = -2.0 * (1.0 - x[0]) - 400.0 * x[0] * b;
    g[1] = 200.0 * b;
    Ok(())
});
let result = Bfgs::<f64>::default()
    .minimize(&rosenbrock, &[start_x1, start_x2])
    .map_err(|e| e.to_string())?;
let x = result.x();
let gradient_norm = result.grad().map(|g| RealScalar::hypot(g[0], g[1]));
// 停止のしきい値 τ = a + r·max(1, |f|/max(1, ‖x‖∞)) を既定の許容誤差から計算し直す。
let coordinate = RealScalar::max(1.0, RealScalar::max(x[0].abs(), x[1].abs()));
let scale = RealScalar::max(1.0, result.fun().abs() / coordinate);
let threshold = GradientTolerance::<f64>::default()
    .threshold(scale)
    .map_err(|e| e.to_string())?;
// 既知の最小点 (1, 1) との距離は独立な検算である。
let distance = RealScalar::hypot(x[0] - 1.0, x[1] - 1.0);
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let columns = serde_json::json!([
    { "key": "0", "label": "終了理由" },
    { "key": "1", "label": "成功", "type": "boolean" },
    { "key": "2", "label": "反復 [回]", "type": "integer" },
    { "key": "3", "label": "目的の評価 [回]", "type": "integer" },
    { "key": "4", "label": "勾配の評価 [回]", "type": "integer" },
    { "key": "5", "label": "f(x) [-]", "type": "number", "format": sci2 },
    { "key": "6", "label": "‖∇f(x)‖₂ [-]", "type": "number", "format": sci2, "nullText": "なし" },
    { "key": "7", "label": "しきい値 τ [-]", "type": "number", "format": sci2 },
    { "key": "8", "label": "‖x − (1, 1)‖₂ [-]", "type": "number", "format": sci2 }
]);
emit_table_with_columns!(
    columns,
    vec![(
        result.termination().to_string(),
        result.is_success(),
        result.iterations(),
        result.fun_evals(),
        result.grad_evals(),
        result.fun(),
        gradient_norm,
        threshold,
        distance,
    )],
    metadata = serde_json::json!({ "id": "bfgs" })
);

let termination = result.termination();
let outcome = match termination {
    _ if termination.is_success() => Outcome::satisfied("勾配ノルムが停止のしきい値を下回った")
        .explanation("一次の停止判定であり、極小点や大域的な最小点の証明ではない。"),
    OptimizeTermination::LineSearchFailed(_) => {
        Outcome::failed("直線探索が受理できるステップ幅を見つけられなかった")
    }
    _ => Outcome::partial("停止判定を満たす前に止まった")
        .explanation("返されるのは、反復中に最後に受理された点である。最適解とは限らないため、推定値として扱う。"),
};
emit_outcome!(
    outcome
        .status(termination.to_string())
        .diagnostic("反復", result.iterations() as f64, None)
        .diagnostic("既知の最小点との距離", distance, None)
);
```

既定の初期点 $(-1.2, 1)$ では、37 反復（目的と勾配の評価がそれぞれ 66 回）で `GradientSmall` になり、`is_success()` は真である。
最終の勾配ノルムは $7.7 \times 10^{-9}$ で、しきい値 $\tau = 2\sqrt{\varepsilon} \approx 3.0 \times 10^{-8}$ を下回っている。
最小点の近くでは $|f| < 1$ なので尺度は 1 になり、しきい値は $a + r$ に等しい。
既知の最小点との距離は $5.2 \times 10^{-10}$、目的値は $8.3 \times 10^{-20}$ である。
初期点を $(-1.2, 3)$ に変えると 48 反復、$(-2, 1)$ では 26 反復になり、谷のどこから入るかで反復数は変わる。
入力範囲の両端を含めて試した初期点では、どれも同じ最小点に着く。
`GradientSmall` は勾配が小さいという一次の停止判定であり、極小点であることの証明ではないので、既知解や別の初期点で確かめる。

勾配を書かずに一度だけ解くなら、ワンショット関数 `minimize` に目的のクロージャと初期点を渡す。
`minimize` は既定の設定の `Bfgs` で解き、勾配を中心差分（勾配一つに目的の評価 $2n$ 回）で近似し、成功しない終了は `Err` で返す。
ボックス制約があれば `minimize_bounded` が既定の `LbfgsB` で解き、勾配を前進差分（目的の評価 $n$ 回）で近似する。
次のセルは同じ Rosenbrock 関数を `minimize` で解き、さらに $x_1 \le 0.5$ の箱で `minimize_bounded` を呼ぶ。
箱の中の最小点は谷底 $x_2 = x_1^2$ と境界 $x_1 = 0.5$ の交点 $(0.5, 0.25)$ で、最小値は $(1 - 0.5)^2 = 0.25$ である。
この点で $\partial f / \partial x_1 = -1 < 0$ なので、目的は上限の方向へ下がり、上限が有効になる。

```rust
//| id: optimize-overview-one-shot
//| ref: optimize-overview-one-shot
//| title: ワンショット関数 minimize と minimize_bounded で解く
//| run: reactive
//| crates: [scioxide-core, scioxide-optimize]
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"one-shot","path":"/rows/0/1","equals":"GradientSmall"}
//|       - {"artifact":"one-shot","path":"/rows/0/3","equals":325}
//|       - {"artifact":"one-shot","path":"/rows/0/6","range":{"min":0,"max":1e-6}}
//|       - {"artifact":"one-shot","path":"/rows/1/1","equals":"GradientSmall"}
//|       - {"artifact":"one-shot","path":"/rows/1/5","approx":{"value":0.25,"atol":1e-8}}
//|       - {"artifact":"one-shot","path":"/rows/1/6","range":{"min":0,"max":1e-6}}
use scioxide_core::{Bounds, RealScalar};
use scioxide_optimize::{minimize, minimize_bounded};

let rosenbrock = |x: &[f64]| {
    let a = 1.0 - x[0];
    let b = x[1] - x[0] * x[0];
    Ok(a * a + 100.0 * b * b)
};
let start = [-1.2, 1.0];
// 勾配を渡さないので、minimize は中心差分、minimize_bounded は前進差分で勾配を近似する。
let free = minimize(rosenbrock, &start).map_err(|e| e.to_string())?;
let bounds = Bounds::new(vec![(Some(-2.0), Some(0.5)), (Some(-1.0), Some(3.0))])
    .map_err(|e| e.to_string())?;
let boxed = minimize_bounded(rosenbrock, &start, &bounds).map_err(|e| e.to_string())?;
// 独立な検算: 無制約の最小点 (1, 1) と箱の中の最小点 (0.5, 0.25) との距離。
let rows = [
    ("minimize", &free, [1.0, 1.0]),
    ("minimize_bounded", &boxed, [0.5, 0.25]),
]
.into_iter()
.map(|(name, r, exact)| {
    (
        name,
        r.termination().to_string(),
        r.iterations(),
        r.fun_evals(),
        r.grad_evals(),
        r.fun(),
        RealScalar::hypot(r.x()[0] - exact[0], r.x()[1] - exact[1]),
    )
})
.collect::<Vec<_>>();
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let columns = serde_json::json!([
    { "key": "0", "label": "呼び出し" },
    { "key": "1", "label": "終了理由" },
    { "key": "2", "label": "反復 [回]", "type": "integer" },
    { "key": "3", "label": "目的の評価 [回]", "type": "integer" },
    { "key": "4", "label": "近似した勾配 [個]", "type": "integer" },
    { "key": "5", "label": "f(x) [-]", "type": "number", "format": sci2 },
    { "key": "6", "label": "既知の最小点との距離 [-]", "type": "number", "format": sci2 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "one-shot" })
);
```

`minimize` は 36 反復で `GradientSmall` になり、既知の最小点との距離は $1.7 \times 10^{-8}$ である。
目的の評価は 325 回で、解析的な勾配を渡した上のセル（66 回）の約 5 倍である。
このうち 260 回は、差分で近似した勾配 65 個（1 個に $2n = 4$ 回）に使われた。
距離も解析的な勾配の $5.2 \times 10^{-10}$ より大きく、差分の誤差が停止点に残る。
`minimize_bounded` は 67 反復で `GradientSmall` になり、$f = 0.25$ と、箱の中の最小点 $(0.5, 0.25)$ との距離 $7.4 \times 10^{-9}$ を返す。
ワンショット関数は成功した結果だけを `Ok` で返すので、この表の終了理由は成功の分類しか現れない。
同じ問題を何度も解く、終了の許容誤差や反復の上限を変える、部分結果を受け取るといった場合は、上のセルのように手法オブジェクト（`Bfgs` など）を使う（[呼び出しの形](oxref:optimize-call-forms)）。

## 結果の読み方

- 終了理由: `OptimizeTermination` が唯一の終了状態である。
  成功（`is_success()` が真）は `Converged` と `GradientSmall` だけである。
  `StepSmall`、`FunctionChangeSmall`、`Stagnation` は最後に受理した点を返すが成功ではなく、直線探索がステップ幅を受理できずに止まった `LineSearchFailed` も成功ではない。
  反復・評価・探索木などの上限、時間上限、取り消しによる停止と、大域探索や標本化した目的の終了も成功ではない。
  分類の全体は[終了理由の分類](oxref:optimize-termination-classes)にある。
- エラー: 入力の形の誤り、非有限値、コールバックの失敗、最初の点を受理する前の停止は `Ok` ではなく `SciOxideError` で返る。
  ワンショット関数は成功しない終了も `ConvergenceFailure` などのエラーにし、手法オブジェクトの結果は `require_success()` で同じエラーへ変えられる。
  分類は `kind()` と `view()` で読み、エラーは呼び出し元の識別子を持たない。
- 最適性の証拠: `OptimalityDiagnostics` は、主実行可能性・停留性・双対実行可能性・相補性の残差、整数性と境界の違反、最適性のギャップを、方法が計算した範囲で別々に返す。
  計算していない量は `None` で、残差 0 を意味しない。
  LP・QP の結果は `ProgrammingVerifier::verify` でソルバーと独立に検証できる。
- 方式別の診断: `method_diagnostics()` は手法の分類ごとの観測（`OptimizeDiagnostics` の一つの列挙子）を返す。
  上の BFGS では減衰なしと減衰付きの曲率の更新回数が入るが、成否は終了理由だけで決まる。
- 計算量: `iterations()`、`fun_evals()`、`grad_evals()` のほかに、`counts()` が役割ごとの呼び出し回数を `SolveCounts` で返す。
  失敗した微分の試行も数え、入れ子の求解では自分の分（`own()`）と子孫の分（`nested()`）を分けて持つ。

詳しい読み方は [API ガイド](api/) と [最適化問題と結果の読み方](algorithms/) にある。

## 数理構造と問題の分類

`scioxide-optimize` は問題の構造を専用のトレイトと型で表す。

| 分類 | 数学モデル | 主なソルバー | ワンショット関数 | 結果の性質 |
| :--- | :--- | :--- | :--- | :--- |
| 無制約・ボックス制約の滑らかな最適化 | $\min_{\mathbf{x}} f(\mathbf{x})$、$\mathbf{l} \le \mathbf{x} \le \mathbf{u}$ | `Bfgs`, `Lbfgs`, `LbfgsB`, `NonlinearCg`, `GradientDescent`, `NewtonOptimizer`, `TrustRegionOptimizer`（`TrustRegionSubproblem::SteihaugCg` を選べる） | `minimize`（BFGS）、`minimize_bounded`（L-BFGS-B）、`minimize_scalar`（1 変数の Brent 法） | 勾配（とヘッセ行列）を使う局所法。収束速度は方式と解の近くの正則性に依存する。成功判定は一次の条件 |
| 微分を使わない局所最適化 | $\min_{\mathbf{x}} f(\mathbf{x})$（値だけ） | `NelderMead`, `Powell`（ボックス制約も可） | - | 値の広がりと単体・方向の大きさで停止。停留性の証明ではない |
| 非線形最小二乗 | $\min_{\mathbf{x}} \frac{1}{2} \lVert \mathbf{r}(\mathbf{x}) \rVert_2^2$ | `LeastSquares`（`LeastSquaresGlobalization::GaussNewton` または `LevenbergMarquardt`） | `least_squares`、`curve_fit`（Levenberg–Marquardt 法）、`nnls`、`bvls`（線形） | ヤコビ行列を使い、小残差問題で速く収束 |
| 非線形制約付き最適化 | $\min f(\mathbf{x})$ s.t. $\mathbf{c}(\mathbf{x})=\mathbf{0}$, $\mathbf{g}(\mathbf{x})\le\mathbf{0}$ | `Sqp`, `InteriorPoint`, `AugmentedLagrangian`, `PenaltyMethod`, `Cobyla`, `Cobyqa` | `minimize_constrained`（SQP） | KKT 条件の残差で終了を判定（`Cobyla`・`Cobyqa` は信頼半径、モデルの停留性、実行可能性で停止） |
| 線形計画（LP） | $\min \mathbf{c}^\mathsf{T}\mathbf{x}$ s.t. $\mathbf{A}\mathbf{x} \{\le, =, \ge\} \mathbf{b}$、$\mathbf{l} \le \mathbf{x} \le \mathbf{u}$ | `SimplexSolver`, `InteriorPointLp` | `LpProblem::solve`（単体法） | 主・双対の証拠を元の問題で検査してから最適・実行不能・非有界をレポート |
| 凸二次計画（QP） | $\min \frac{1}{2}\mathbf{x}^\mathsf{T}\mathbf{Q}\mathbf{x} + \mathbf{c}^\mathsf{T}\mathbf{x}$ | `QpSolver` | `QpProblem::solve` | $\mathbf{Q} \succeq 0$ が前提。射影勾配法、有効集合法、主双対内点法 |
| 混合整数計画（MIP） | $\min \mathbf{c}^\mathsf{T}\mathbf{x}$, $x_j \in \mathbb{Z}$ | `BranchAndBound` | `MipProblem::solve` | 最良下界探索による分枝限定。数値的なギャップをレポート |
| 合成目的・分割 | $\min f(\mathbf{x}) + g(\mathbf{x})$ | `ProximalGradient`, `Fista`, `Admm` | - | 近接写像を使う一階法。停止は勾配写像や残差の大きさ |
| 標本化した目的・多目的 | 期待値の最小化、複数の目的 | `StochasticGradientDescent`, `StochasticTrustRegion`, `Nsga2` | - | 推定に基づく停止と、非支配解の有限の近似 |
| 大域的な探索 | $\min_{\mathbf{x} \in [\mathbf{l}, \mathbf{u}]} f(\mathbf{x})$（多峰性） | `MultiStart`, `BasinHopping`, `DualAnnealing`, `DifferentialEvolution`, `CmaEs`, `Direct`, `Shgo`, `SurrogateSearch` | `minimize_global`（差分進化） | 観測した最良点。大域最適性は主張しない |
| 二次割当て | 置換 $\pi$ の選択 | `QapPlan` | `quadratic_assignment`（FAQ と 2-opt） | 検査済みの置換。緩和の値は証明ではない |

## 局所停留性と Karush–Kuhn–Tucker 条件

無制約の問題で点 $\mathbf{x}^*$ が局所最小点であるための一次の必要条件は、勾配が 0 になること（$\nabla f(\mathbf{x}^*) = \mathbf{0}$）である。
勾配が 0 でヘッセ行列が正定値（$\nabla^2 f(\mathbf{x}^*) \succ 0$）なら、二次の十分条件を満たし、$\mathbf{x}^*$ は狭義の局所最小点になる。

制約付きの問題では乗数 $\boldsymbol{\lambda}, \boldsymbol{\mu}$ を持つラグランジュ関数

$$
\mathcal{L}(\mathbf{x}, \boldsymbol{\lambda}, \boldsymbol{\mu}) = f(\mathbf{x}) + \sum_{i \in \mathcal{E}} \lambda_i c_i(\mathbf{x}) + \sum_{j \in \mathcal{I}} \mu_j g_j(\mathbf{x})
$$

を使う。
制約想定（有効な制約の勾配が一次独立という LICQ など）のもとで、局所最適解 $\mathbf{x}^*$ には次の Karush–Kuhn–Tucker（KKT）条件を満たす乗数 $(\boldsymbol{\lambda}^*, \boldsymbol{\mu}^*)$ が存在する。

$$
\begin{aligned}
\nabla_{\mathbf{x}} \mathcal{L}(\mathbf{x}^*, \boldsymbol{\lambda}^*, \boldsymbol{\mu}^*) = \mathbf{0} & \quad (\text{停留性}) \\
c_i(\mathbf{x}^*) = 0 \; (\forall i \in \mathcal{E}), \quad g_j(\mathbf{x}^*) \le 0 \; (\forall j \in \mathcal{I}) & \quad (\text{主実行可能性}) \\
\mu_j^* \ge 0 \; (\forall j \in \mathcal{I}) & \quad (\text{双対実行可能性}) \\
\mu_j^* g_j(\mathbf{x}^*) = 0 \; (\forall j \in \mathcal{I}) & \quad (\text{相補性})
\end{aligned}
$$

制約付きソルバーと `OptimalityDiagnostics` はこれらの残差を別々に返す。
目的値が下がっただけでは解とせず、制約の充足と乗数の整合を数値的な残差として確かめる。
残差は許容誤差の範囲での一次の条件であり、局所最適性の厳密な証明ではない。
導出は [非線形制約と KKT 条件](algorithms/nonlinear-constraints/) で扱う。

## 座標スケーリングと数値的安定性

収束の速さと停止判定の意味は、変数の尺度に左右される。
ある変数の変動幅が $10^{-6}$、別の変数の変動幅が $10^6$ なら、目的の等高線は極端に細長くなり、ヘッセ行列の条件数は $10^{24}$ に達しうる。
このとき勾配法はほとんど進まず、勾配の許容誤差もどちらかの変数の単位に支配される。

代表的な尺度 $s_i > 0$ で無次元化した変数 $\tilde{x}_i = x_i / s_i$ を使うと、等高線は円に近づき、条件数が下がることが多い。
一般の目的関数を受け取る局所法は変数の尺度を自動では決めないので、モデルを作る段階で無次元化する。
例外として、非線形最小二乗の密なソルバーは `parameter_scale` を与えなければヤコビ行列の列ノルムから尺度を取り、LP の解法は標準形の行と列の尺度を内部で調整する。
BFGS の曲率学習や信頼領域の半径の調整は歪みの一部を吸収するが、尺度の悪さを直すものではない。

## 作業領域の再利用と割り当て

同じ形の問題を何度も解く場合（時間発展の各ステップ、モデル予測制御、パラメータの掃引）、反復ごとのメモリ確保は計算時間を増やす。
ソルバーごとに再利用できる作業領域（`BfgsWorkspace`、`LbfgsWorkspace`、`SqpWorkspace`、`LeastSquaresWorkspace` など）があり、一度用意して `minimize_into` や `solve_into` に渡す。
`Bfgs` は `workspace_requirements` で必要なメモリ使用量を問い合わせ、`workspace` で確保し、`minimize_into` で呼び出し側の結果へ書き込む。
作業領域は最後の試行と受理した反復（`last_attempt`、`last_accepted`）を記録する。
BFGS、NSGA-II、確率的一階法は、作業領域の `checkpoint` と解法の `resume_into` で中断した計算を続けられる。

用意した作業領域と、出力先に書き込むコールバックを使えば、定常状態の反復はヒープを確保しない。
`ObjectiveFn`、`ConstraintFn`、`LeastSquaresFn` に付ける微分のクロージャも、解法のメモリへ直接書き込む。
勾配、制約のヤコビ行、残差は `(&[S], &mut [S])`、ヘッセ行列と残差のヤコビ行列は `(&[S], &mut Matrix<S>)`、ヘッセ行列とベクトルの積は `(&[S], &[S], &mut [S])` を受け取り、全成分を書いて `Ok(())` を返す。
LP・QP・MIP の API は、標準形、分解、証明用データ、探索木のメモリを明示的に確保する。
取り消しは `ExecutionContext::with_cancellation` で渡し、解法は計算の区切りでこれを確かめて `Cancelled` で止まる。
時間上限にはクロックが要り、`ExecutionContext::with_clock` でクロックを登録していないコンテキストで時間上限を設定すると、解法はコールバックを呼ぶ前に `CapabilityUnavailable` を返す。

## まとめ

`scioxide-optimize` は問題の構造ごとに専用のソルバーと、証拠を返す結果の型を持つ。
一度だけ解くなら `minimize` などのワンショット関数が成功した結果だけを返し、設定を選ぶ、部分結果を読む、作業領域を再利用する場合は手法オブジェクトを使う。
結果は最初に終了理由を読み、成功は `Converged` と `GradientSmall` だけと考え、`LineSearchFailed` や上限による停止を成功と読まない。
次に勾配と停止のしきい値、KKT 条件の残差、LP・QP の検証、MIP のギャップを見て、目的値だけで解の良し悪しを決めない。
変数の尺度をそろえ、同じ形の問題を繰り返すなら作業領域を再利用する。
