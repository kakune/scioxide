設計や同定では、偏微分方程式の解 $u$ から計算するスカラーの量 $J$（平均温度、境界の熱流束、観測値との二乗誤差など）を、係数・源項・境界データを決めるパラメータ $p=(p_1,\ldots,p_m)$ について微分したい。
パラメータを一つずつずらして解き直す差分商は、$m$ 個のパラメータに $m+1$ 回以上の求解を使い、刻みの選び方で丸め誤差と打ち切り誤差の兼ね合いも生じる。
随伴法（adjoint method）は、転置した線形方程式を 1 回解くだけで、パラメータの数によらず勾配全体を求める。

`scioxide-pde` の随伴は離散化した方程式そのものを微分する離散随伴（discretize-then-differentiate）である。
得られるのは計算した離散の $J$ の正確な勾配で、連続問題の勾配とは離散化誤差だけ異なる。
このページでは定常問題を扱い、時間発展の問題は[時間発展問題の離散随伴](../transient-adjoints/)で扱う。

## 離散随伴の導出

離散化した定常問題を、未知数 $u\in\mathbb{R}^n$ とパラメータ $p\in\mathbb{R}^m$ の残差の方程式

$$
R(u,p)=0
$$

と書く。
$R_u=\partial R/\partial u$ が正則なら、陰関数定理によって解は $u(p)$ と書け、$R_u\,du/dp=-R_p$ が成り立つ。
目的関数 $J(u,p)$ の全微分は

$$
\frac{dJ}{dp}=J_p+J_u\frac{du}{dp}=J_p-J_u R_u^{-1}R_p
$$

である。
右辺の $J_uR_u^{-1}$ を先に計算するのが随伴法で、随伴変数（乗数）$\lambda$ を随伴方程式

$$
R_u^{\mathsf T}\lambda=J_u^{\mathsf T}
$$

の解とすると

$$
\frac{dJ}{dp}=J_p-\lambda^{\mathsf T}R_p
$$

となる。
$R_u^{-1}R_p$ を先に計算するのが前進感度（forward sensitivity）で、パラメータごとに $R_u\,\delta u=-R_p\,\delta p$ を 1 回ずつ解く。
随伴法の線形求解は目的関数ごとに 1 回、前進感度はパラメータごとに 1 回なので、パラメータが多く目的関数が少ないときは随伴法が少ない求解で済む。
どちらも $R_p$ の作用は各パラメータについて 1 回ずつ必要である。

複素数の残差では、転置を共役転置 $R_u^{\mathsf H}$ に読み替え、実のパラメータについての勾配は $J_p-\operatorname{Re}(R_p^{\mathsf H}\lambda)$ になる。

連続の偏微分方程式に Lagrange の未定乗数を入れて随伴の偏微分方程式を導き、それを別に離散化する方法（differentiate-then-discretize、連続随伴）もある。
連続随伴の勾配は離散の $J$ の勾配と離散化誤差の程度だけ食い違うので、最適化で目的関数の値と勾配を組み合わせると、直線探索の判定が合わないことがある。
離散随伴は計算した $J$ と丸め誤差の範囲で整合する（Giles and Pierce, 2000）。

## Plan のデータのパラメータ微分

線形の空間の Plan（`StructuredFdmPlan`、`StructuredFvmPlan`、`SimplexFvmPlan`、`SimplexFemPlan`）の残差は、Dirichlet の未知数を対称に消去した

$$
R(u,p,t)=A(p)\,u-b(p,t)
$$

である。
Dirichlet の行は $u_i-g_D(t)$ と読む（消去の詳細は[楕円問題の FDM・FEM・FVM](../elliptic-fdm-fem-fvm/)を参照）。
パラメータ $p_j$ についての微分は

$$
\frac{\partial R}{\partial p_j}=\frac{\partial A}{\partial p_j}\,\bar u-b\!\left(\frac{\partial f}{\partial p_j},\frac{\partial g}{\partial p_j},t\right)-W_j(g,t)
$$

で、$\bar u$ は状態の自由な値と Plan の Dirichlet 値 $g_D(t)$ を並べたもの、$b(\cdot)$ は Plan 自身の荷重の重み・持ち上げ・Dirichlet 行で組み立てた荷重である。
$W_j$ は有限体積法の境界データの重みの接線で、他の族では現れない。
FDM と FEM の $A$ は係数について線形なので、$\partial A/\partial p_j$ は係数の微分で $A$ を組み立て直したものに等しい。
有限体積法は面の流束の法則が係数について非線形なので、微分を前進モードで伝える。

この微分は `DifferentiableDiscretization::parameterize(values, tangents)` が Plan 自身の組立で作り、呼び出し側は行列を組み立てない。
`DifferentiableDiscretization` は `SpatialDiscretization` を上位トレイトに持つ sealed トレイトで、上の四つの Plan が実装する。
`tangents` はパラメータごとに一つの `PdeParameterTangent` で、データが $p_j$ にどう依存するかを Plan の語彙で与える。

- `with_coefficients(c)`：係数の微分（FDM では `dyn StructuredFdmCoefficients` の値として $\partial k/\partial p_j$ など）。
  Plan の組立が同じ標本点で呼び、値は負でもよい。
- `with_source(f)`：源項の微分 $\partial f/\partial p_j$。
- `with_boundaries(list)`：境界条件ごとに一つの `PdeConditionTangent` を、条件を結合した順に並べる。
  `PdeConditionTangent::new(data)` はデータの微分 $\partial g/\partial p_j$、`with_robin_coefficient(a)` は Robin 係数の微分 $\partial\alpha/\partial p_j$ で、依存しない条件は `PdeConditionTangent::zero()` にする。

与えなかった部分はパラメータに依存しないとみなす。
`parameterize` は値と接ベクトルの数の不一致（`DimensionMismatch`）、条件の数と合わない境界の列、Robin でない条件への Robin 係数の微分（`InvalidInput`）、非有限の値を拒否する。
`values` は勾配を求める点の $p$ で、接ベクトルのデータも同じ $p$ で評価して渡す。
Plan を作ったときの $p$ とこの値が一致するかは検査されない。

返る `PdeParameterization` はパラメータの値（`values`）、数（`len`）、未知数の数（`unknowns`）、メッシュの revision（`mesh_token`）と、$\partial R/\partial p_j$ を評価する `residual_tangent_into(j, state, time, out, scratch)` を持つ。
作業領域は `scratch_len()` で、$2n$ 個である。
状態の拘束された成分は無視され、Plan の Dirichlet 値で評価される。
失敗したときは `out` を変えない。
係数か Robin 係数に依存するパラメータは、作用素と同じ構造の疎行列を一つずつ持つので、メモリ領域はおよそ（そのようなパラメータの数）×（非零要素の数）になる。
メッシュの座標は微分しない。
幾何、求積、境界の分割は固定され、形状の微分（shape derivative）は提供しない。
座標に依存する量を微分したいときは、呼び出し側が $R_p$ を作用素として作り、[一般の残差の随伴](#一般の残差の随伴)に渡す。

## 内部発熱する鋼板

厚さ $L=0.05$ m のステンレス鋼の板が、電流による一様な発熱 $q$ [W/m³] を持つとする。
左面 $x=0$ は冷却水で $T_0=300$ K に保たれ、右面 $x=L$ は外気温 $T_\infty$ の空気へ熱伝達率 $h$ [W/(m²·K)] で放熱する。
定常の温度 $u(x)$ [K] は

$$
-k\,u''=q,\qquad u(0)=T_0,\qquad k\,u'(L)+h\,u(L)=h\,T_\infty
$$

を満たす。
右端の条件は外向きの余法線流束 $n\cdot k\nabla u=k\,u'(L)$ を使った [Robin 条件](oxref:pde-robin-boundary)で、係数 $\alpha=h$、データ $g=hT_\infty$ である。
パラメータは $p=(k,q,h,T_\infty)$ で、既定値は $k=15$ W/(m·K)、$q=2\times10^5$ W/m³、$h=50$ W/(m²·K)、$T_\infty=290$ K とする。

目的関数は板の平均温度

$$
J=\frac{1}{L}\int_0^L u\,dx\;\approx\;\sum_i w_i u_i,\qquad w_i=\frac{m_i}{\sum_k m_k}
$$

で、$m_i$ は Plan の集中質量（節点の制御体積の幅）である。
この重みは台形則に等しい。
連続問題の解は $u=T_0+ax-qx^2/(2k)$、$a=\bigl(h(T_\infty-T_0)+qL+hqL^2/(2k)\bigr)/(k+hL)$ で、平均温度とその偏微分は閉形式で書ける。

接ベクトルは連鎖律でそのまま書ける。
$k$ の方向は係数の微分 $\partial k/\partial k=1$、$q$ の方向は源項の微分 1 である。
$h$ の方向は Robin 係数の微分 1 とデータの微分 $\partial(hT_\infty)/\partial h=T_\infty$、$T_\infty$ の方向はデータの微分 $h$ だけになる。
次の定義のブロックが Plan、接ベクトル、目的関数、閉形式の参照値をまとめる。
`MeanTemperature` は `scioxide_ode::AdjointObjective` を実装し、状態についての勾配 $w$ と、パラメータについての勾配 $J_p=0$ を書く。

```rust
//| id: pde-adjoint-slab-model
//| kind: definitions
//| title: 内部発熱する鋼板の熱伝導と平均温度
//| crates: [scioxide-core, scioxide-ode, scioxide-pde, scioxide-spatial]
use scioxide_core::{SciOxideError, ScaledNorm, SolveContext};
use scioxide_ode::{AdjointObjective, AdjointObjectivePart, AdjointObjectiveValue};
use scioxide_pde::{
    BoundaryCondition, BoundaryData, FieldData, PdeConditionTangent, PdeParameterTangent,
    SpatialDiscretization, StructuredBoundaries, StructuredFdmCoefficients, StructuredFdmPlan,
};
use scioxide_spatial::{AxisSide, AxisTopology, BoundarySet, CoordinateAxis, Grid1d, SegmentMesh};

/// 左面の温度 T₀ [K] と板の厚さ L [m]。
pub(crate) const WALL: f64 = 300.0;
pub(crate) const THICKNESS: f64 = 0.05;

/// 一様な熱伝導率 k [W/(m·K)]。接ベクトルでは ∂k/∂p_j を返す。
pub(crate) struct Uniform(pub(crate) f64);

impl StructuredFdmCoefficients<f64, f64, 1> for Uniform {
    fn diffusion(&self, _: usize, _: usize, _: [f64; 1]) -> Result<f64, SciOxideError> {
        Ok(self.0)
    }
}

pub(crate) type Coefficients = dyn StructuredFdmCoefficients<f64, f64, 1>;
pub(crate) type Plan = StructuredFdmPlan<f64, f64, 1>;

/// パラメータ p = (k, q, h, T∞) と格子点数 N。
#[derive(Clone, Copy)]
pub(crate) struct Slab {
    pub(crate) parameters: [f64; 4],
    pub(crate) nodes: usize,
}

impl Slab {
    /// 発熱密度 q = 2×10⁵ W/m³、外気温 T∞ = 290 K の鋼板。
    pub(crate) fn steel(conductivity: f64, transfer: f64, nodes: usize) -> Self {
        Self {
            parameters: [conductivity, 2.0e5, transfer, 290.0],
            nodes,
        }
    }

    pub(crate) fn shifted(self, j: usize, delta: f64) -> Self {
        let mut slab = self;
        slab.parameters[j] += delta;
        slab
    }

    /// −k u″ = q、u(0) = T₀、k u′(L) + h u(L) = h T∞ の差分の Plan。
    pub(crate) fn plan(&self) -> Result<Plan, SciOxideError> {
        let [k, _, h, ambient] = self.parameters;
        let axis = CoordinateAxis::uniform(0.0, THICKNESS, self.nodes)?;
        let mesh = SegmentMesh::new(Grid1d::new([axis], [AxisTopology::Bounded])?)?;
        let side = |s| BoundarySet::axis_side(&mesh, 0, s);
        let conditions = vec![
            BoundaryCondition::dirichlet(side(AxisSide::Start)?, BoundaryData::constant(WALL)),
            BoundaryCondition::robin(side(AxisSide::End)?, h, BoundaryData::constant(h * ambient)),
        ];
        let boundaries = StructuredBoundaries::new(&mesh, 1, conditions)?;
        StructuredFdmPlan::new(mesh, &Uniform(k), &boundaries)
    }

    pub(crate) fn source(&self) -> FieldData<f64, f64, 1> {
        FieldData::constant(self.parameters[1])
    }

    /// p_j ごとのデータの微分。境界は条件の順（Dirichlet、Robin）に並べる。
    pub(crate) fn tangents<'a>(
        &self,
        unit: &'a Uniform,
    ) -> Vec<PdeParameterTangent<'a, f64, f64, 1, Coefficients>> {
        let [_, _, h, ambient] = self.parameters;
        // Robin 条件の α = h と g = h T∞ の微分 (∂α/∂p_j, ∂g/∂p_j)。
        let robin = |alpha: f64, data: f64| {
            vec![
                PdeConditionTangent::zero(),
                PdeConditionTangent::new(BoundaryData::constant(data))
                    .with_robin_coefficient(alpha),
            ]
        };
        vec![
            PdeParameterTangent::new().with_coefficients(unit as &Coefficients),
            PdeParameterTangent::new().with_source(FieldData::constant(1.0)),
            PdeParameterTangent::new().with_boundaries(robin(1.0, ambient)),
            PdeParameterTangent::new().with_boundaries(robin(0.0, h)),
        ]
    }

    /// 連続問題の平均温度と dJ/dp の閉形式（f64 の四則による参照値）。
    pub(crate) fn continuum(&self) -> (f64, [f64; 4]) {
        let [k, q, h, ambient] = self.parameters;
        let l = THICKNESS;
        let (n, d) = (
            h * (ambient - WALL) + q * l + h * q * l * l / (2.0 * k),
            k + h * l,
        );
        let mean = WALL + n / d * l / 2.0 - q * l * l / (6.0 * k);
        let dk = l / 2.0 * (-h * q * l * l / (2.0 * k * k) * d - n) / (d * d)
            + q * l * l / (6.0 * k * k);
        let dq = l / 2.0 * (l + h * l * l / (2.0 * k)) / d - l * l / (6.0 * k);
        let dh = l / 2.0 * ((ambient - WALL + q * l * l / (2.0 * k)) * d - n * l) / (d * d);
        (mean, [dk, dq, dh, l / 2.0 * h / d])
    }

    /// 連続問題の随伴 ψ: −k ψ″ = 1/L、ψ(0) = 0、k ψ′(L) + h ψ(L) = 0（参照値）。
    pub(crate) fn continuum_adjoint(&self, x: f64) -> f64 {
        let [k, _, h, _] = self.parameters;
        let l = THICKNESS;
        (1.0 + h * l / (2.0 * k)) / (k + h * l) * x - x * x / (2.0 * k * l)
    }
}

/// J(u) = Σ wᵢ uᵢ。wᵢ = mᵢ / Σ m は集中質量（制御体積の幅）による台形則の重み。
pub(crate) struct MeanTemperature {
    pub(crate) weights: Vec<f64>,
}

impl MeanTemperature {
    pub(crate) fn of(plan: &Plan) -> Self {
        let mass = plan.lumped_mass();
        let total: f64 = mass.iter().sum();
        Self {
            weights: mass.iter().map(|m| m / total).collect(),
        }
    }

    pub(crate) fn value(&self, u: &[f64]) -> f64 {
        self.weights.iter().zip(u).map(|(w, x)| w * x).sum()
    }
}

impl AdjointObjective<f64> for MeanTemperature {
    fn evaluate(
        &self,
        _: AdjointObjectivePart,
        _: f64,
        u: &[f64],
        _: &[f64],
        state_gradient: &mut [f64],
        parameter_gradient: &mut [f64],
        _: &mut [f64],
        _: &mut SolveContext<'_, '_>,
    ) -> Result<AdjointObjectiveValue<f64>, SciOxideError> {
        state_gradient.copy_from_slice(&self.weights);
        parameter_gradient.fill(0.0);
        Ok(AdjointObjectiveValue {
            value: self.value(u),
            time_derivative: 0.0,
        })
    }
}

/// 荷重 b（Dirichlet 行は g_D）。平衡点の残差 A u − b と同じ単位 [W/m²] を持つ。
pub(crate) fn load(plan: &Plan, source: &FieldData<f64, f64, 1>) -> Result<Vec<f64>, SciOxideError> {
    let mut load = vec![0.0; plan.unknowns()];
    let mut scratch = vec![0.0; plan.load_workspace_len()];
    plan.load_into(source, 0.0, &mut load, &mut scratch)?;
    Ok(load)
}

pub(crate) fn norm(values: &[f64]) -> Result<f64, SciOxideError> {
    let mut norm = ScaledNorm::new();
    for value in values {
        norm.add(value.abs())?;
    }
    norm.finish()
}
```

## 楕円型の Plan の随伴

`PdeEllipticAdjointPlan` は、線形の Plan の `EllipticProblem` について、上の導出の $R_u=A$ の場合を計算する。
`new(problem, parameterization, objective, options)` は $A$ を CSR で一度組み立て、フィルを減らす順序付けの疎 LU で因子分解し、メモリ領域の上限を検査する。
既知の定数モードを持つ Plan や零空間の基底を持つ問題は拒否する（`InvalidInput`）。
勾配が[ゲージ](../compatibility-gauges-and-fluxes/)の選び方に依存するからである。
別の Plan のパラメータ化、時刻の標本（`observation_times`）を持つ目的関数、設定の誤り、上限を超えるメモリ領域も拒否し、特異な作用素は疎 LU の `Singular` になる。

`solve(problem, parameterization, solution, objective)` は呼び出しごとに次を行う。

1. Plan と問題が準備したものと同じかを検査し、荷重 $b$ を時刻 0 で評価する。
2. 渡された `solution` の残差 $\lVert Au-b\rVert_2$ を主の許容誤差と比べ、平衡点であることを確かめる。
3. 目的関数を時刻 0 で評価し、$J$ と $J_u$、$J_p$ を得る。
4. 準備した LU 因子で $A^{\mathsf T}\lambda=J_u^{\mathsf T}$ を解き、残差 $\lVert A^{\mathsf T}\lambda-J_u^{\mathsf T}\rVert_2$ を独立に計算して線形の許容誤差と比べる。
5. 各パラメータについて `residual_tangent_into` で $\partial R/\partial p_j$ を作り、$dJ/dp_j=J_{p_j}-\lambda^{\mathsf T}\partial R/\partial p_j$ を計算する。

結果の `PdeSteadyAdjointResult` は乗数 `adjoint()`（残差の方程式の乗数で、状態の勾配ではない）、勾配 `parameter_gradient()`、レポート `report()` を持つ。
`PdeSteadyAdjointReport` は目的関数の値 `objective()`、主の残差 `primal_residual()`、随伴方程式の残差 `derivative_residual()`、評価の計数 `counts()`、作業領域のバイト数 `workspace_bytes()` を返す。
これらは離散の勾配の代数的な診断で、連続問題に対する精度は示さない。
`solve_into(…, adjoint, gradient, workspace, scope)` は呼び出し側の出力と `PdeEllipticAdjointWorkspace` を使い、`scope` の一つのエポックとして計算する。
準備した作業領域での呼び出しは確保を行わず、失敗したときは乗数と勾配の両方を書き換えない。
`sensitivity_into(…, direction, output, workspace, scope)` は同じ因子で前進感度 $du=-A^{-1}(\partial R/\partial p)\,\delta p$ を一方向ぶん解き、このときのレポートの `objective()` は `None` である。
Plan は実数の型だけで、`Send + Sync + Clone` である。

次のセルは鋼板の平均温度の勾配を随伴で求め、三つの独立な値と比べる。
一つ目は同じ因子による前進感度 $\sum_i w_i\,\partial u_i/\partial p_j$、二つ目は $p_j$ を $\pm10^{-4}p_j$ ずらして平衡点を解き直した中心差分、三つ目は連続問題の閉形式である。
最後の列は $p_j$ を 1 % 上げたときの $J$ の変化の一次近似で、四つのパラメータの効き方を同じ単位 [K] で比べる。
主の残差の尺度は荷重のノルム $\lVert b\rVert_2$ にしてある（理由は[平衡点と線形解の検査](#平衡点と線形解の検査)で説明する）。


既定値（$N=41$）では、随伴の勾配は $dJ/dk=-0.55242$ m·K²/W、$dJ/dq=4.9594\times10^{-5}$ m³·K/W、$dJ/dh=-0.032653$ m²·K²/W、$dJ/dT_\infty=0.071429$ になった。

1 % の変化では外気温（$+0.21$ K）と発熱密度（$+0.099$ K）が大きく効き、熱伝導率（$-0.083$ K）がそれに次ぎ、熱伝達率の効果（$-0.016$ K）は小さい。

連続問題との相対差は $k$ と $q$ で $2\times10^{-4}$ 程度、$h$ と $T_\infty$ で $3\times10^{-13}$ 以下である。
一次元の差分の Plan は P1 有限要素と同じ節点値を与え、この問題の解は二次式なので、節点の温度は丸め誤差を除いて連続解に一致する。
残る差は台形則の誤差 $J_h-J=-\Delta x^2q/(12k)$ だけで、既定値では $-1.736\times10^{-3}$ K になり、表の $J=309.2046$ K と連続問題の $309.2063$ K の差に一致する。
この誤差は $h$ と $T_\infty$ によらないので、その二つの勾配は連続問題の勾配と一致する。
$N=161$ にすると $\Delta x$ が 1/4 になり、$k$ と $q$ の相対差は 1/16 の $1.3\times10^{-5}$ と $1.1\times10^{-5}$ に下がる。

レポートの主の残差は $2.7\times10^{-9}$ W/m²、随伴方程式の残差は $1.2\times10^{-14}$ で、作業領域の見積もりは 339,588 バイト（wasm）である。

乗数 $\lambda$ は何を表すのか。
平均温度の重み $w$ は $1/L$ を節点の幅で積分したものなので、$A^{\mathsf T}\lambda=w$ は連続問題の随伴方程式

$$
-k\,\psi''=\frac1L,\qquad \psi(0)=0,\qquad k\,\psi'(L)+h\,\psi(L)=0
$$

の離散化になっている。
$\psi(x)$ は位置 $x$ に単位の熱源を置いたときの平均温度の上がり方で、熱源の位置ごとの影響の大きさを表す。
次のセルは上のセルの乗数を受け取り、自由な節点の $\lambda_i$ と閉形式の $\psi(x)$ を重ねて描く。

## 一般の残差の随伴

`PdeDiscretizationDerivatives` は、Plan の作用素に限らず、呼び出し側が微分を与える残差を平衡点で陰的に微分する。
非線形の残差や、`parameterize` が扱わないパラメータ依存（座標など）に使う。
`new(solution, parameter_values, residual, state, parameters)` は、平衡点 $u$、パラメータの値、残差 `ResidualOperator`、$R_u$ を表す `AdjointOperator`（$n\times n$）、$R_p$ を表す `AdjointOperator`（$n\times m$、列は実のパラメータの方向）を借用して束縛する。
確保は行わず、形の不一致と非有限のパラメータの値を拒否する。
束縛している間は、プロバイダーのデータを変えてはならない。

勾配は `solve_adjoint(objective, time, solve)`（既定の許容誤差）、`solve_adjoint_with_options(…, options)`、呼び出し側の出力と `PdeSteadyAdjointWorkspace` を使う `solve_adjoint_into(…, options, adjoint, gradient, workspace, scope)` で求める。
`workspace(objective, options)` は作業領域を一度だけ確保し、以後の呼び出しは確保を行わない。
`sensitivity_into(direction, solve, options, output, workspace, scope)` は前進感度を一方向ぶん求める。
目的関数は終端項（`AdjointObjectivePart::Terminal`）として `time` で評価され、時刻の標本を持つ目的関数は拒否される。
平衡点の検査、随伴方程式の残差の検査、出力の扱いは楕円型の Plan と同じである。

非線形の定常問題では、[`NonlinearPdeProblem`](oxref:pde-jacobian-modes) を結合した `PdeResidual` が `ResidualOperator` と `PdeAdjointJacobian` を実装する。
`PdeTangent::new(&residual, point)` は平衡点でのヤコビ行列を表し、`PdeAdjointJacobian` のプロバイダーでは `AdjointOperator` になるので、そのまま $R_u$ に渡せる。
`PdeAdjointJacobian` は共役転置の積 $J(\text{point})^{\mathsf H}\,\text{seed}$ を `vjp_into` で書くトレイトで、`PdeResidual`、`HyperelasticityPlan`、`NavierStokesPlan` が実装する。
密と疎のヤコビ行列の表現では、組み立てた行列の転置で随伴の積を作る。
行列なしの表現（`PdeJacobianMode::Operator`）では、`NonlinearPdeProblem::with_adjoint(callback, scratch)` で `PdeAdjointCallback`（`Fn(time, state, seed, output, scratch)`）を与える。
コールバックは JVP と同じ微分の共役転置を表し、出力の全成分を宣言した作業領域だけで書く。
与えないまま随伴の積を求めると `InvalidInput`（`UnsupportedConfiguration`）になり、組み立てる表現にコールバックを与えると結合が拒否する。
$R_p$ は呼び出し側が作る。

## 随伴の線形解法

`PdeEllipticAdjointPlan` は準備で疎 LU 因子を作り、随伴の解では因子の転置の求解、前進感度では通常の求解に同じ因子を使う。
因子分解は準備の 1 回だけで、呼び出しごとの計算コストは荷重の評価、前進と後退の代入、$m$ 回の $\partial R/\partial p_j$ の評価になる。
この Plan の線形解法は選べない。

`PdeDiscretizationDerivatives` では、線形解法を呼び出し側が `PdeLinearSolve` として渡す。
これは `FnMut(&dyn LinearOperator<T>, &[T], &mut [T], &mut SolveContext) -> Result<(), SciOxideError>` の型のクロージャで、渡された作用素について $Ax=b$ を解く。
解の配列はゼロで初期化して渡される。
随伴の解では作用素は $R_u$ の共役転置、前進感度では $R_u$ そのものである。
クロージャは自分の因子や Krylov 法のメモリ領域を持ってよく、作用素の引数を使わずに、先に分解した因子で解いてもよい。
$R_u$ が対称でなければ、転置の系にも使える解法（LU 因子の転置の求解や GMRES など）を選ぶ。
共役勾配法は対称正定値の行列に限る。
求解は `SolveContext` の計数に線形求解として 1 回数えられ、評価の上限に達すると `ConvergenceFailure`（`EvaluationLimit`）になる。

クロージャが成功を返しても、ライブラリは結果の残差を自分で計算し直して線形の許容誤差と比べる。
反復解法を使うときは、その停止条件を線形の許容誤差より厳しくしておく。
そうしないと、反復解法が収束を返しても随伴の計算は `InvalidInput`（引数 `solve`）で失敗する。

## 平衡点と線形解の検査

`PdeSteadyAdjointOptions` は二つの許容誤差と一つの尺度を持つ。

- 主の許容誤差（`with_primal_tolerance`、既定は絶対・相対とも $\sqrt\varepsilon$）：渡した解が $\lVert R(u)\rVert_2\le\mathrm{atol}+\mathrm{rtol}\cdot s$ を満たすかを検査する。
  $s$ は `with_primal_scale` で与える有限で非負の尺度（既定 1）である。
- 線形の許容誤差（`with_linear_tolerance`、既定は同じ）：随伴方程式の残差が $\lVert R_u^{\mathsf T}\lambda-J_u^{\mathsf T}\rVert_2\le\mathrm{atol}+\mathrm{rtol}\cdot\lVert J_u\rVert_2$ を満たすかを検査する。
  前進感度では右辺 $-R_p\,\delta p$ のノルムを尺度にして同じ形で検査する。
- `with_max_workspace_bytes`：ライブラリが持つ作業領域の上限（既定はなし）。

随伴の公式は $R(u,p)=0$ を前提にしているので、平衡点でない $u$ で計算した勾配は意味を持たない。
主の残差は残差の行と同じ単位を持ち、鋼板では荷重 [W/m²]（Dirichlet の行だけは [K]）である。
既定の尺度 1 はこの単位での絶対的な閾値 $2\sqrt\varepsilon\approx3.0\times10^{-8}$ を意味する。
後退安定な直接法で解いた解でも、残差は $\varepsilon\lVert A\rVert\,\lVert u\rVert$ 程度残り（Higham, 2002, 7 章）、格子を細かくすると $\lVert A\rVert$ と $\lVert u\rVert_2$ の両方が大きくなる。
次のセルは鋼板（$k=15$、$h=50$）を $N=41$ から 2561 まで細かくし、直接法で解いた平衡点の残差と閾値を、尺度 1 と尺度 $\lVert b\rVert_2$ で比べる。
残差 $Au-b$ は Plan の作用（`LinearOperator::apply_into`）と荷重から独立に計算する。

```rust
//| id: pde-adjoint-primal-check
//| ref: pde-adjoint-primal-check
//| title: 平衡点の検査の尺度を格子の細かさとともに比べる
//| run: reactive
//| uses: [pde-adjoint-slab-model]
//| crates: [scioxide-core, scioxide-ode, scioxide-pde, scioxide-spatial]
//| inputs:
//|   primal_scale: {"type":"select","label":"主の残差の尺度","description":"平衡点の残差と比べる閾値 √ε(1 + 尺度) の尺度を選ぶ。","options":["1（既定）","荷重のノルム ‖b‖₂"],"value":"1（既定）"}
//| cases:
//|   - {"id":"load-scale","label":"尺度 ‖b‖₂","description":"閾値が残差と同じ単位の大きさになり、4 つの格子のすべてで平衡点が受理される。","inputs":{"primal_scale":"荷重のノルム ‖b‖₂"}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"checks","path":"/rows/0/4","equals":"受理"}
//|       - {"artifact":"checks","path":"/rows/0/2","range":{"max":1e-8}}
//|       - {"artifact":"checks","path":"/rows/0/3","approx":{"value":2.98023e-8,"rtol":1e-5}}
//|       - {"artifact":"checks","path":"/rows/2/5","equals":null}
//|       - {"artifact":"checks","path":"/rows/3/5","equals":null}
//|   - case: load-scale
//|     expect:
//|       - {"artifact":"checks","path":"/rows/2/4","equals":"受理"}
//|       - {"artifact":"checks","path":"/rows/3/4","equals":"受理"}
//|       - {"artifact":"checks","path":"/rows/3/5","approx":{"value":-0.5525320961,"rtol":1e-8}}
use scioxide_core::LinearOperator;
use scioxide_pde::{
    DifferentiableDiscretization, EllipticProblem, PdeEllipticAdjointPlan,
    PdeSteadyAdjointOptions,
};

let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let sig6 = serde_json::json!({ "significantDigits": 6 });
let mut rows = Vec::new();
for nodes in [41, 161, 641, 2561] {
    let slab = Slab::steel(15.0, 50.0, nodes);
    let plan = slab.plan().map_err(|e| e.to_string())?;
    let source = slab.source();
    let problem = EllipticProblem::new(&plan, &source);
    let solution = problem.solve().map_err(|e| e.to_string())?;
    let b = load(&plan, &source).map_err(|e| e.to_string())?;
    // 独立検算: 平衡点の残差 R(u) = A u − b を Plan の作用で作る。
    let mut residual = vec![0.0; nodes];
    let mut scratch = vec![0.0; plan.apply_workspace_len().map_err(|e| e.to_string())?];
    plan.apply_into(&solution, &mut residual, &mut scratch)
        .map_err(|e| e.to_string())?;
    for (r, bi) in residual.iter_mut().zip(&b) {
        *r -= bi;
    }
    let load_norm = norm(&b).map_err(|e| e.to_string())?;
    let scale = if primal_scale == "1（既定）" {
        1.0
    } else {
        load_norm
    };
    let options = PdeSteadyAdjointOptions::new().with_primal_scale(scale);
    let threshold = options
        .primal_tolerance()
        .threshold(scale)
        .map_err(|e| e.to_string())?;
    let objective = MeanTemperature::of(&plan);
    let unit = Uniform(1.0);
    let parameterization = plan
        .parameterize(&slab.parameters, &slab.tangents(&unit))
        .map_err(|e| e.to_string())?;
    let adjoint = PdeEllipticAdjointPlan::new(&problem, &parameterization, &objective, options)
        .map_err(|e| e.to_string())?;
    let (verdict, gradient) =
        match adjoint.solve(&problem, &parameterization, &solution, &objective) {
            Ok(result) => ("受理".to_string(), Some(result.parameter_gradient()[0])),
            Err(e) => (e.to_string(), None),
        };
    rows.push((
        nodes,
        load_norm,
        norm(&residual).map_err(|e| e.to_string())?,
        threshold,
        verdict,
        gradient,
    ));
}
let columns = serde_json::json!([
    { "key": "0", "label": "格子点数 N [点]", "type": "integer" },
    { "key": "1", "label": "‖b‖₂ [W/m²]", "type": "number", "format": sci3 },
    { "key": "2", "label": "‖R(u)‖₂ [W/m²]", "type": "number", "format": sci3 },
    { "key": "3", "label": "閾値 [W/m²]", "type": "number", "format": sci3 },
    { "key": "4", "label": "結果" },
    { "key": "5", "label": "dJ/dk [m·K²/W]", "type": "number", "format": sig6, "nullText": "なし" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "checks" })
);
```

尺度 1 では、残差 $2.7\times10^{-9}$、$2.3\times10^{-8}$、$1.9\times10^{-7}$、$1.6\times10^{-6}$ W/m² が格子を 4 倍にするごとに約 8 倍になり、$N=641$ から閾値 $3.0\times10^{-8}$ を超えて `InvalidInput`（引数 `derivatives`）で拒否された。
解が悪いのではなく、閾値の単位が合っていない。
尺度を $\lVert b\rVert_2$（$N=41$ で $3.6\times10^6$ W/m²。
最初の自由な節点の持ち上げ $kT_0/\Delta x$ が大部分を占める）にすると、閾値は 0.054 から 3.4 W/m² になり、すべて受理された。
受理された $dJ/dk$ は $N$ とともに $-0.552532096$ m·K²/W へ近づき、連続問題の $-0.552532124$ との差が縮む。
尺度には残差と同じ単位を持ち、問題の大きさで決まる量（$\lVert b\rVert_2$ や $\lVert A\rVert\,\lVert u\rVert$）を選ぶ。

失敗はどれも `SciOxideError` として返り、乗数と勾配の出力は書き換えられない。

| 原因 | 種類と引数 |
|---|---|
| 平衡点でない解 | `InvalidInput`（`derivatives`、`Inconsistent`） |
| 線形求解の残差が許容誤差を超えた | `InvalidInput`（`solve`、`Inconsistent`） |
| 形や作業領域が準備と合わない | `InvalidInput`（`derivatives` など）、`DimensionMismatch` |
| 解・パラメータ・コールバックの値が非有限 | `NonFinite`（起点は `Input` か `Callback`） |
| 評価の上限 | `ConvergenceFailure`（`EvaluationLimit`） |
| 作業領域が上限を超えた | `ResourceLimit` |

終了理由の列挙型はなく、成功は勾配が返ったことで示される。
`counts()` は残差、目的関数、線形求解、作用素の適用の回数を記録する。

## まとめ

離散随伴は離散化した残差 $R(u,p)=0$ を微分し、転置の線形方程式 1 回で全パラメータの勾配を求める。
線形の Plan では、係数・源項・境界データ・Robin 係数の微分を `PdeParameterTangent` で与えれば、`parameterize` が $\partial R/\partial p$ を組み立て、`PdeEllipticAdjointPlan` が一つの疎 LU 因子で随伴と前進感度の両方を解く。
得られる勾配は離散の $J$ の勾配で、鋼板では中心差分と $10^{-9}$ 程度で一致し、連続問題とは台形則の誤差だけ食い違った。
非線形の残差や独自の $R_p$ は `PdeDiscretizationDerivatives` に作用素と線形解法のクロージャを渡し、クロージャの停止条件は線形の許容誤差より厳しくする。
平衡点の検査の尺度には残差と同じ単位の量を選び、細かい格子で正しい解が拒否されないようにする。
