楕円型の方程式は、領域の内部の式だけでは解が決まらず、境界の全体で条件を一つずつ与えて初めて解ける問題になる。
このページでは三種類の境界条件を `scioxide-pde` の一つの規約で書き、その符号を一次元の直線解で確かめる。
用いる記号は[保存則と格子上の場](../models-grids-and-boundaries/)で導いた拡散方程式 $-(k u')'+c\,u=f$ のものである。

## 境界条件の書き方

一つの境界条件 `BoundaryCondition<R, V, D, Region>` は境界の領域、場の成分、条件の種類、データの四つを持つ。

- 領域 `Region` は、構造格子では `scioxide-spatial` の `BoundarySet`（`BoundarySet::axis_side(&mesh, axis, AxisSide::Start)` など）、単体のメッシュでは境界の面に付けた `u32` のタグである。
- 成分は既定ですべての成分で、`for_component(i)` を付けると成分 $i$ だけに課す。
- 種類 `BoundaryKind<V>` は `Dirichlet`、`Natural`、`Robin { alpha }` のどれかで、`BoundaryCondition::dirichlet(region, data)`、`natural(region, data)`、`robin(region, alpha, data)` が作る。
- データ `BoundaryData<R, V, D>` は境界上の関数 $g$ である。
  関数が受け取る `BoundaryPoint` は、物理座標 `point`、その面の外向きの単位法線 `normal`、成分 `component` を持つ。
  時間に依るかどうかは[源項と同じく](oxref:pde-field-data)作るときに宣言する。

データを評価する場所は離散化と条件の種類で異なる。
Dirichlet のデータは、FDM と FEM では境界の面の上の節点（P2 では辺の中点も含む）、FVM では境界の面の中心で評価する。
Neumann と Robin のデータは、FDM では境界の頂点、FVM では面の中心、FEM では面の求積点（一次元では端点そのもの）で評価する。

### Dirichlet 境界条件

第一種境界条件ともいい、境界上の値 $u=g$ を指定する。
FDM と FEM は値を固定した未知数の行と列を他から切り離して対角を 1 にし、既知の値を掛けた列を右辺へ移す（対称な消去）。
対称な問題は対称な行列のまま組み立てられる。
FVM は境界の値を未知数にせず、境界の面で既知の値と隣のセルの値から二点の流束を作る。

## Neumann 境界条件と外向きの符号

第二種境界条件ともいい、境界を通る流束を指定する。
`scioxide-pde` の Neumann 条件（`BoundaryCondition::natural`）のデータは、どの離散化でも外向きの余法線流束 $\mathbf{n}\cdot K\nabla u=g$ である。
ここで $\mathbf{n}$ は外向きの単位法線、$K$ は拡散係数（一次元ではスカラー $k$）で、余法線流束は法線微分 $\partial u/\partial n=\mathbf{n}\cdot\nabla u$ に拡散係数を掛けた量である。
法線微分そのものではないので、$k\neq1$ では $k\,\partial u/\partial n$ の値を渡す。

区間 $[a,b]$ の外向き法線は左端で $-1$、右端で $+1$ なので、データは両端で次の量になる。

$$
\left.k\frac{\partial u}{\partial n}\right|_{x=a}=-k(a)\,u'(a)=g_a,\qquad \left.k\frac{\partial u}{\partial n}\right|_{x=b}=k(b)\,u'(b)=g_b
$$

右向きの流束 $q=-k\,u'$ を使うと、$g_a=q(a)$、$g_b=-q(b)$ である。
どちらの端でも $g>0$ は境界から領域へ入る量を表す。
左端で符号を取り違えると、流入と流出が逆になる。
多次元で拡散がテンソル $K$ のときも $(K\nabla u)\cdot\mathbf{n}$ を渡す。
Neumann のデータは行列に寄与せず、荷重だけを作る。
FEM の弱形式では、このデータが部分積分の境界項にそのまま入るので、自然境界条件とも呼ぶ（[有限要素法の弱形式](oxref:pde-fem-weak-form)）。

## Robin 境界条件

第三種境界条件ともいい、外向きの余法線流束と値の一次結合を指定する（`BoundaryCondition::robin(region, alpha, data)`）。

$$
k\frac{\partial u}{\partial n}+\alpha\,u=g
$$

流束の係数は 1 に固定されており、利用者は $\alpha$ と $g$ だけを与える。
流束の係数を 0 にする書き方はなく、値の指定は `Dirichlet` で書く。
温度 $u_\infty$ の周囲の流体への熱伝達 $-k\,\partial u/\partial n=h\,(u-u_\infty)$（$h$ は熱伝達係数）は、$\alpha=h$、$g=h\,u_\infty$ に当たる。
$\alpha\to0$ の極限は Neumann 条件、$\alpha\to\infty$（$g/\alpha$ を固定）の極限は Dirichlet 条件 $u=g/\alpha$ である。

$\alpha>0$ なら、境界の項 $\alpha u^2$ がエネルギーに加わり、反応がなくても解は一意に決まる。
条件の集合を作るときは $\alpha$ が有限であることだけを確かめ、有限でない値を `NonFinite` で拒否する。
負の $\alpha$ は拒否されないが、そのときは一意性が保証されない。
複素数の $\alpha$ は FDM と FEM が受け付け、FVM は実数に限る。

## 条件の集合と検査

Plan は個々の条件ではなくメッシュの一つの revision に結び付けた条件の集合 `BoundaryConditions` を受け取る。
構造格子には `StructuredBoundaries::new(&mesh, components, conditions)`、単体のメッシュには面のタグ（`SimplexBoundaryTags`）を加えた `TaggedBoundaries::new(&mesh, &tags, components, conditions)` を使う。
すべての外側の面に同じ条件を付けるときは、どちらも `uniform(&mesh, components, kind, data)` で作れる。

作るときに、データの関数を一度も呼ばずに次のことを確かめる。

- 外側のすべての面とすべての成分に、条件がちょうど一つずつ付いている。
  抜けと重複は `InvalidInput` で拒否する。
- 条件の領域が別のメッシュの revision のものでなく、内部の面や周期境界の継ぎ目の面を含まず、少なくとも一つの外側の面を選ぶ。
- 成分の番号が範囲内にあり、Robin 係数が有限である。
- 単体のメッシュでは、タグの集合がメッシュと同じ revision のもので、外側のすべての面にタグが付いている。

周期境界は境界条件ではなくメッシュのトポロジー（`AxisTopology::Periodic`）で表す。
周期境界の継ぎ目の面は条件を受け付けない。
構造格子で周期境界を扱えるのは `StructuredFdmPlan` だけで、`StructuredFvmPlan` は周期的なメッシュを拒否する。
作る手間とメモリ使用量は、メッシュ全体ではなく外側の面の数に比例する。

二次元以上では、二つの Dirichlet の面が角の節点を共有し、異なる値を指定することがある。
その扱いは `DirichletConflictPolicy` で決め、`with_dirichlet_conflict_policy` で Plan の準備の前に設定する。
既定の `Reject` は、二つの値の差が機械イプシロンの絶対・相対の許容を超えると準備を拒否する。
`LastConditionWins` は、条件の並びで後の条件を優先し、同じ条件の中では番号の大きい面を優先する。
この順序はセルを走査する順序や並列実行に依らない。
どちらの方針でも、優先されなかった値も評価される。
FDM では、Dirichlet の面と Neumann・Robin の面が共有する頂点は Dirichlet が値を決める。

## 符号と Robin 係数の検算

熱伝導率 $k=2$ の棒 $[0,1]$ の定常な直線解 $u(x)=2+3x$ を、左端の Neumann 条件と右端の Robin 条件から求め直す。
左端の外向き法線は $-1$ なので、$u'=3$ に対する外向きの余法線流束は $k\,\partial u/\partial n=-6$ である。
右端では $u(1)=5$、$k\,\partial u/\partial n=6$ なので、Robin 係数 $\alpha$ の条件の右辺は $g=6+5\alpha$ になる。
入力は $\alpha$ で、右辺は同じ直線解に合うように $\alpha$ と一緒に変える。
係数と右辺が整合していれば、$\alpha$ に依らず同じ解が得られるはずである。

下のセルは 8 個のセルの格子で FDM、FVM、P1 FEM の三つの Plan を準備し、同じ条件で解く。
直線解は三つの離散化がいずれも厳密に表せる関数なので、誤差は丸め誤差の水準になるはずである。
未知数の位置は FDM と FEM が頂点、FVM がセル中心で、どれも `dof_point` で読んで厳密解と比べる。
流束は最初と最後の未知数の差から $-k\,\Delta u/\Delta x$ で求める。

```rust
//| id: pde-robin-normal-derivative
//| ref: pde-robin-normal-derivative
//| title: 外向きの余法線流束と Robin 係数を三つの離散化で検算する
//| run: reactive
//| crates: [scioxide-pde, scioxide-spatial, scioxide-core]
//| inputs:
//|   robin_alpha: {"type":"range","label":"Robin 係数 α [-]","description":"右端の境界反応係数。右辺 g = 6 + 5α は同じ直線解に合わせて変える。","min":0.25,"max":4,"step":0.25,"value":1}
//| cases:
//|   - {"id":"weak-exchange","label":"弱い熱交換 α = 0.25（g = 7.25）","description":"Robin 条件が Neumann 条件に近づいても、三つの離散化が同じ直線解と流束 −6 を返す。","inputs":{"robin_alpha":0.25}}
//|   - {"id":"strong-exchange","label":"強い熱交換 α = 4（g = 26）","description":"Robin 条件が Dirichlet 条件に近づいても、三つの離散化が同じ直線解と流束 −6 を返す。","inputs":{"robin_alpha":4}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"robin","path":"/rows/0/1","range":{"min":0,"max":1e-12}}
//|       - {"artifact":"robin","path":"/rows/1/1","range":{"min":0,"max":1e-12}}
//|       - {"artifact":"robin","path":"/rows/2/1","range":{"min":0,"max":1e-12}}
//|       - {"artifact":"robin","path":"/rows/0/2","approx":{"value":-6,"atol":1e-11}}
//|       - {"artifact":"robin","path":"/rows/1/2","approx":{"value":-6,"atol":1e-11}}
//|       - {"artifact":"robin","path":"/rows/2/2","approx":{"value":-6,"atol":1e-11}}
//|   - case: weak-exchange
//|     expect:
//|       - {"artifact":"robin","path":"/rows/1/1","range":{"min":0,"max":1e-12}}
//|       - {"artifact":"robin","path":"/rows/2/2","approx":{"value":-6,"atol":1e-11}}
//|   - case: strong-exchange
//|     expect:
//|       - {"artifact":"robin","path":"/rows/1/1","range":{"min":0,"max":1e-12}}
//|       - {"artifact":"robin","path":"/rows/2/2","approx":{"value":-6,"atol":1e-11}}
use scioxide_pde::{
    BoundaryCondition, BoundaryData, ConstantDiffusion, EllipticProblem, FieldData,
    SimplexFemGeometry, SimplexFemOrder, SimplexFemPlan, SpatialDiscretization,
    StructuredBoundaries, StructuredFdmPlan, StructuredFvmPlan, TaggedBoundaries,
};
use scioxide_spatial::{
    AxisSide, AxisTopology, BoundarySet, CoordinateAxis, Grid1d, IntervalMesh, Point,
    SegmentMesh, SimplexBoundaryTags,
};

// 解いて、厳密解 u = 2 + 3x との最大誤差と右向きの流束 −k Δu/Δx を返す。
fn check<P: SpatialDiscretization<f64, f64, 1>>(plan: &P) -> Result<(f64, f64), String> {
    let values = EllipticProblem::new(plan, &FieldData::zero())
        .solve()
        .map_err(|e| e.to_string())?;
    let mut xs = Vec::new();
    for i in 0..values.len() {
        xs.push(plan.dof_point(i).map_err(|e| e.to_string())?.point[0]);
    }
    let error = (xs.iter().zip(&values))
        .map(|(x, u)| (u - (2.0 + 3.0 * x)).abs())
        .fold(0.0_f64, f64::max);
    let last = values.len() - 1;
    let flux = -2.0 * (values[last] - values[0]) / (xs[last] - xs[0]);
    Ok((error, flux))
}
let alpha = robin_alpha;
let k = ConstantDiffusion::new(2.0);
// 左端: 外向きの余法線流束 n·k u' = −k u'(0) = −6。右端: k du/dn + αu = 6 + 5α。
let left = BoundaryData::constant(-6.0);
let right = BoundaryData::constant(6.0 + 5.0 * alpha);
let axis = CoordinateAxis::uniform(0.0, 1.0, 9).map_err(|e| e.to_string())?;
let grid = Grid1d::new([axis], [AxisTopology::Bounded]).map_err(|e| e.to_string())?;
let segment = SegmentMesh::new(grid).map_err(|e| e.to_string())?;
let side = |side| BoundarySet::axis_side(&segment, 0, side).map_err(|e| e.to_string());
let conditions = vec![
    BoundaryCondition::natural(side(AxisSide::Start)?, left.clone()),
    BoundaryCondition::robin(side(AxisSide::End)?, alpha, right.clone()),
];
let structured =
    StructuredBoundaries::new(&segment, 1, conditions).map_err(|e| e.to_string())?;
let fdm =
    StructuredFdmPlan::new(segment.clone(), &k, &structured).map_err(|e| e.to_string())?;
let fvm = StructuredFvmPlan::new(segment, &k, &structured).map_err(|e| e.to_string())?;
// 区間メッシュの端点 x = 0 にタグ 0、x = 1 にタグ 1 を付ける。
let points = (0..9)
    .map(|i| Point::new([i as f64 / 8.0]))
    .collect::<Result<Vec<_>, _>>()
    .map_err(|e| e.to_string())?;
let interval = IntervalMesh::new(points, (0..8).map(|i| [i, i + 1]).collect())
    .map_err(|e| e.to_string())?;
let mut faces = Vec::new();
for face in interval.boundary_faces() {
    let vertex = interval.face_vertices(face).map_err(|e| e.to_string())?[0];
    faces.push((face, u32::from(vertex != 0)));
}
let tags = SimplexBoundaryTags::new(&interval, faces).map_err(|e| e.to_string())?;
let conditions = vec![
    BoundaryCondition::natural(0, left),
    BoundaryCondition::robin(1, alpha, right),
];
let tagged =
    TaggedBoundaries::new(&interval, &tags, 1, conditions).map_err(|e| e.to_string())?;
let geometry = SimplexFemGeometry::Affine;
let fem = SimplexFemPlan::new(interval, geometry, SimplexFemOrder::P1, &k, &tagged)
    .map_err(|e| e.to_string())?;
let rows = vec![
    ("FDM（頂点）", check(&fdm)?),
    ("FVM（セル中心）", check(&fvm)?),
    ("FEM P1（頂点）", check(&fem)?),
];
let rows: Vec<_> = rows
    .into_iter()
    .map(|(name, (e, q))| (name, e, q))
    .collect();
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let fixed9 = serde_json::json!({ "fractionDigits": 9 });
let columns = serde_json::json!([
    { "key": "0", "label": "離散化（未知数の位置）" },
    { "key": "1", "label": "厳密解との最大誤差 [-]", "type": "number", "format": sci2 },
    { "key": "2", "label": "右向きの流束 −k Δu/Δx [-]", "type": "number", "format": fixed9 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "robin" })
);
```

$\alpha=0.25$・1・4 のどれでも、三つの離散化は流束 $-6$ を返し、厳密解との最大誤差は FDM と FEM で 0、FVM で $10^{-14}$ 未満だった。
FVM は境界の値を未知数に持たないが、境界の面の流束の式も直線を厳密に表すので、セル中心の値は同じ直線の上に乗る。
左端のデータの符号を $+6$ と取り違えると、傾きが $-3$ の別の直線が解になる。
この検算は直線解に対するもので、一般の解に対する誤差の保証ではない。

## 純 Neumann 問題の可解性と適合条件

$-(k u')'=f$ に両端の Neumann 条件 $k\,\partial u/\partial n=g_a,g_b$ を課し、方程式を区間全体で積分する。
左辺は $-(k u')(b)+(k u')(a)=-g_b-g_a$ になるので、次の等式が解の存在に必要である。

$$
g_a+g_b+\int_a^b f\,dx=0
$$

境界から入る量と内部の生成の和が 0 でなければ、熱が溜まり続けるか失われ続け、定常解は存在しない。
この条件を適合条件という。
成り立つ場合も、任意の定数 $C$ について $u+C$ が解になるので、解は一意でない。
離散系の行列は定数ベクトルを零空間に持つ。
すべての Robin 係数が 0 の場合と、周期境界で反応のない場合も同じである。

Plan はこの状況を構造から検出し、`has_constant_modes` で返す。
検出の条件は、反応係数がすべて 0 で（FDM では移流もすべて 0 で）、Dirichlet 条件も 0 でない Robin 係数もないことである。
このとき `EllipticProblem` は `EllipticOptions::with_gauge` でゲージ（解の定数を決める条件）を指定しない限り `InvalidInput`（`UnsupportedConfiguration`）で拒否する。
離散的な適合条件の検査、ゲージの種類、荷重の射影は[楕円問題の適合条件・ゲージ・保存的流束](../compatibility-gauges-and-fluxes/)で説明する。

## まとめ

`scioxide-pde` の Neumann と Robin のデータは、どの離散化でも外向きの余法線流束 $k\,\partial u/\partial n$ を基準にするので、左端では $-k\,u'$ を渡す。
Robin 条件は流束の係数を 1 に固定した $k\,\partial u/\partial n+\alpha u=g$ で、熱伝達なら $\alpha=h$、$g=h\,u_\infty$ を渡す。
条件の集合は外側の面と成分に一つずつ条件を付けたときだけ作れ、二次元以上の角で Dirichlet の値が食い違うときの扱いは `DirichletConflictPolicy` で選ぶ。
すべての境界が流束の条件で反応もない問題は、適合条件を満たす荷重とゲージの指定が必要になる。
