すべての境界が Neumann 条件で反応のない Poisson 問題では、解に定数を加えても方程式と境界条件は変わらない（[純 Neumann 問題](oxref:pde-pure-neumann-compatibility)）。
解を持つためには荷重が条件を満たす必要があり（適合条件）、解を一つに決めるには追加の条件（ゲージ）が要る。
小さな対角項を加えて特異性を消すと、元とは別の問題を解くことになる。
`scioxide-pde` はこのような正則化をせず、ゲージの指定を利用者に求める。
このページではその仕組みを線形代数から説明し、求解のレポート `PdeDiagnostics` の読み方をまとめる。

## 左零空間と右零空間

$n$ 元の離散系 $A\mathbf{u}=\mathbf{b}$ の行列 $A$ が特異なとき、$A\mathbf{r}=0$ を満たすベクトルの空間を右零空間、$\mathbf{l}^HA=0$ を満たすベクトルの空間を左零空間という（$^H$ は共役転置）。
それぞれの正規直交基底を並べた行列を $R$、$L$ とする。
$\mathbf{b}$ が $A$ の値域に入る、すなわち解を持つ条件は $L^H\mathbf{b}=0$ で、これが離散的な適合条件である。
解は $R$ の列の一次結合だけ不定なので、ゲージ $R^H\mathbf{u}=\mathbf{c}$ で一つに決める。

`scioxide-linalg` の `BorderedSystem` は行列に基底を縁取りとして加えた拡大系を作る。

$$
\begin{bmatrix}A&L\\R^H&0\end{bmatrix}
\begin{bmatrix}\mathbf{u}\\\boldsymbol{\lambda}\end{bmatrix}
=\begin{bmatrix}\hat{\mathbf{b}}\\\mathbf{c}\end{bmatrix}
$$

$\hat{\mathbf{b}}$ は適合条件を満たすように準備した荷重である。
基底が正しければこの拡大系は正則で、作るときに基底が正規直交であることと $\|A\mathbf{r}_j\|$、$\|A^H\mathbf{l}_j\|$ が許容誤差以下であることを確かめる。
$A$ が対称で $L=R$ なら拡大系は対称だが不定値なので、正定値を前提とする共役勾配法は使えない。

`EllipticProblem` は零空間を二通りに知る。

- **構造から分かる定数モード**（`PdeNullspaceSource::StructuralConstant`）：Plan の `has_constant_modes()` が真のとき、各成分の定数ベクトルを正規化したものを $L=R$ の基底にする。
  解くときは成分ごとに最初の未知数を 0 に固定した残りの系を既定の直接法（一次元の三重対角の系なら三重対角の消去、それ以外は疎 LU 分解）で解き、その後でゲージを課す。
- **利用者が与える基底**（`PdeNullspaceSource::Supplied`）：退化した拡散や複数の零空間のように構造から分からない場合は、消去済みの行列の左・右零空間の正規直交基底を `EllipticProblem::with_nullspace(left, right)` で与える。
  このときは疎な拡大系そのものを LU 分解で解くので、メモリ使用量は零空間の次元にも依存する。

`EllipticWorkspace::with_linear_solver` で反復法を注入すると、零空間を持つ問題では拡大系に対して反復する。

## ゲージの種類

ゲージは `EllipticOptions::with_gauge` で `EllipticGauge` から選ぶ。

| `EllipticGauge` | 課す条件 | 使える場合 |
|---|---|---|
| `Unspecified`（既定） | なし。零空間が分かっている問題は `InvalidInput`（`UnsupportedConfiguration`）で拒否する | 零空間のない問題 |
| `Orthogonal` | 右零空間の基底への座標を 0 にする（$R^H\mathbf{u}=0$）。定数モードでは各成分の単純平均を 0 にする | 構造から分かる定数モードと、利用者が与える基底 |
| `WeightedMean(c)` | 各成分の集中質量で重み付けた平均 $\bar u=\sum_i m_iu_i/\sum_i m_i$ を $c$ にする | 構造から分かる定数モードだけ |

$m_i$ は `lumped_mass()` の値で、FDM では頂点の支配幅（端では半分）、FVM ではセルの体積、FEM では尺度化した質量行列の対角である。
重み付き平均は連続な場の平均 $\frac{1}{|\Omega|}\int_\Omega u\,dx$ の求積による近似なので、物理的な基準（平均温度など）を指定するのに向く。
零空間のない問題に `Orthogonal` や `WeightedMean` を指定すると、`InvalidInput` で拒否する。
利用者が基底を与えた問題に `WeightedMean` を指定しても拒否する。
`solve()` はゲージを受け取らないので、零空間が分かっている問題では使えず、`solve_with_options` か `solve_into` を使う。

## 射影が変更する右辺

`EllipticOptions::with_compatibility(policy, tolerance)` は、適合条件の扱いと、その判定に使う許容誤差を選ぶ。
この許容誤差は解の受理の許容誤差とは独立で、既定はどちらも $\sqrt{\varepsilon}$ である。

- `CompatibilityPolicy::RequireCompatible`（既定）は、$\|L^H\mathbf{b}\|_2>\tau_a+\tau_r\|\mathbf{b}\|_2$ となる荷重を `DomainError` で拒否する（$\tau_a$、$\tau_r$ は適合条件の絶対・相対の許容誤差）。
- `CompatibilityPolicy::Project` は、射影した荷重 $\hat{\mathbf{b}}=\mathbf{b}-L(L^H\mathbf{b})$ を作って解く。

射影は離散化した荷重ベクトルの Euclid 射影であり、連続な源項や境界のデータをどう直すべきかを決めるものではない。
定数モードでは、射影は荷重の各成分から同じ値を引くことに当たる。
FDM と FVM の Plan は求解の前に荷重の適合性だけを確かめる `check_constant_mode_compatibility(&rhs, tolerance)` も持つ。
これは各成分の荷重の和が、絶対値の和に比べて許容誤差以下であるかを調べる。

## 診断の読み方

求解のレポート `PdeSolveReport` の `diagnostics()` は `PdeDiagnostics` を返す。
定常の求解で読む値は次のとおりである。

- `termination()` と `method()`：終了理由と、選んだ線形解法の名前。
- `linear_residual_report()`：元の方程式の残差と後退誤差の尺度（[解の受理の検査](oxref:pde-elliptic-acceptance)）。
  `residual_norm()` はその生の値である。
- `nullspace()`：拡大系の診断 `BorderedSystemDiagnostics`。
  基底の列の数 `nullity()`、元の荷重の左零空間成分 $\|L^H\mathbf{b}\|_2$（`compatibility_defect()`）、実際に加えた変更 $\|\mathbf{b}-\hat{\mathbf{b}}\|_2$（`projection_norm()`）、元の荷重に対する残差 $\|A\mathbf{u}-\mathbf{b}\|_2$（`original_residual_norm()`）、射影後の残差 $\|A\mathbf{u}-\hat{\mathbf{b}}\|_2$（`projected_residual_norm()`）を、元の系で独立に評価する。
- `nullspace_gauge_defect()`：要求したゲージの欠陥で、重み付き平均では $|\bar u-c|$ である。
  `EllipticProblem` は、この値が解の受理の許容誤差を超える解を `NumericalInstability` で拒否する。
- `nullspace_source()`：零空間の出所（`PdeNullspaceSource`）で、零空間がなければ `None` である。

`nullspace()` の `gauge_defect()` は拡大系が内部で使う直交ゲージ $R^H\mathbf{u}=0$ の欠陥である。
`WeightedMean` では解に定数を加えて平均を合わせるので、この値は要求したゲージの誤差を表さず、$c\neq0$ では大きくなる。
要求したゲージは `nullspace_gauge_defect()` で確かめる。

時間発展の求解では、同じ型が時間刻みの数（`num_time_steps()`、`num_accepted_steps()`、`num_rejected_steps()`、`num_failed_steps()`）、最後の刻みの誤差推定、右辺とヤコビ行列の評価回数、組み立てと分解の回数も記録する。

## 物理平均を指定した Neumann 問題

$-u''=0$ を $[0,1]$ で解き、両端の外向きの余法線流束（$k=1$ なので法線微分に等しい）を左 $-1$、右 $1+\delta$ とする。
重み付き平均 $c$ を指定すると、$\delta=0$ のとき解析解は $u(x)=x+c-\tfrac12$ である。
台形の重みは一次関数の平均を厳密に積分するので、離散解もこの式に一致するはずである。
$\delta\neq0$ では荷重の和が $\delta$ になって適合条件が崩れ、`RequireCompatible` は求解を拒否し、`Project` は荷重を射影して解く。
下のセルは 17 節点の `StructuredFdmPlan` を一度だけ作り、同じ `EllipticProblem` を二つの方針で解いて、二種類の欠陥と残差を並べる。
最後の行は、ゲージを指定しない既定の設定が拒否されることを確かめる。
outcome は `Project` で解いた結果の終了理由を示す。

```rust
//| id: pde-neumann-physical-mean
//| ref: pde-neumann-physical-mean
//| title: Neumann 問題に物理平均を指定し、適合しない荷重の扱いを比べる
//| run: reactive
//| crates: [scioxide-core, scioxide-spatial, scioxide-pde, scioxide-linalg]
//| inputs:
//|   mean_target: {"type":"range","label":"指定する重み付き平均 c [-]","min":-2,"max":4,"step":0.5,"value":2}
//|   flux_imbalance: {"type":"range","label":"右端の余法線流束の過不足 δ [-]","description":"0 以外では適合条件が崩れる。","min":0,"max":0.2,"step":0.05,"value":0}
//| cases:
//|   - {"id":"incompatible","label":"適合しない荷重 δ = 0.2","description":"RequireCompatible は DomainError で拒否し、Project は適合欠陥 4.85×10⁻² の分だけ元の残差を残して解く。","inputs":{"flux_imbalance":0.2}}
//|   - {"id":"negative-mean","label":"平均 c = −2","description":"指定した平均だけ解が平行移動し、解析解 u = x − 2.5 との差は丸め誤差の水準になる。","inputs":{"mean_target":-2}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"policies","path":"/rows/0/1","equals":"Completed"}
//|       - {"artifact":"policies","path":"/rows/1/1","equals":"Completed"}
//|       - {"artifact":"policies","path":"/rows/1/2","equals":"StructuralConstant"}
//|       - {"artifact":"policies","path":"/rows/0/6","range":{"min":0,"max":1e-14}}
//|       - {"artifact":"policies","path":"/rows/0/7","range":{"min":0,"max":1e-13}}
//|       - {"artifact":"policies","path":"/rows/2/1","equals":"拒否 InvalidInput"}
//|       - {"path":"/outputs/1/state","equals":"satisfied"}
//|   - case: incompatible
//|     expect:
//|       - {"artifact":"policies","path":"/rows/0/1","equals":"拒否 DomainError"}
//|       - {"artifact":"policies","path":"/rows/0/3","equals":null}
//|       - {"artifact":"policies","path":"/rows/1/1","equals":"Completed"}
//|       - {"artifact":"policies","path":"/rows/1/3","approx":{"value":0.0485071,"rtol":1e-5}}
//|       - {"artifact":"policies","path":"/rows/1/4","approx":{"value":0.0485071,"rtol":1e-5}}
//|       - {"artifact":"policies","path":"/rows/1/5","range":{"min":0,"max":1e-12}}
//|       - {"artifact":"policies","path":"/rows/1/7","equals":null}
//|       - {"path":"/outputs/1/state","equals":"satisfied"}
//|   - case: negative-mean
//|     expect:
//|       - {"artifact":"policies","path":"/rows/1/6","range":{"min":0,"max":1e-14}}
//|       - {"artifact":"policies","path":"/rows/1/7","range":{"min":0,"max":1e-13}}
use scioxide_core::ResidualTolerance;
use scioxide_linalg::CompatibilityPolicy;
use scioxide_pde::{
    BoundaryCondition, BoundaryData, ConstantDiffusion, EllipticGauge, EllipticOptions,
    EllipticProblem, FieldData, SpatialDiscretization, StructuredBoundaries, StructuredFdmPlan,
};
use scioxide_spatial::{
    AxisSide, AxisTopology, BoundarySet, CoordinateAxis, Grid1d, SegmentMesh,
};

let axis = CoordinateAxis::uniform(0.0_f64, 1.0, 17).map_err(|e| e.to_string())?;
let grid = Grid1d::new([axis], [AxisTopology::Bounded]).map_err(|e| e.to_string())?;
let mesh = SegmentMesh::new(grid).map_err(|e| e.to_string())?;
// 外向きの余法線流束 k du/dn（k = 1）: 左端は −1、右端は 1 + δ。
let side = |side| BoundarySet::axis_side(&mesh, 0, side).map_err(|e| e.to_string());
let conditions = vec![
    BoundaryCondition::natural(side(AxisSide::Start)?, BoundaryData::constant(-1.0)),
    BoundaryCondition::natural(
        side(AxisSide::End)?,
        BoundaryData::constant(1.0 + flux_imbalance),
    ),
];
let boundaries = StructuredBoundaries::new(&mesh, 1, conditions).map_err(|e| e.to_string())?;
let k = ConstantDiffusion::new(1.0);
let plan = StructuredFdmPlan::new(mesh, &k, &boundaries).map_err(|e| e.to_string())?;
let source = FieldData::zero();
let problem = EllipticProblem::new(&plan, &source);
let tolerance = ResidualTolerance::new(1e-10, 1e-10).map_err(|e| e.to_string())?;
let mut rows = Vec::new();
let mut outcome = None;
for (label, policy) in [
    ("RequireCompatible", CompatibilityPolicy::RequireCompatible),
    ("Project", CompatibilityPolicy::Project),
] {
    let options = EllipticOptions::new()
        .with_gauge(EllipticGauge::WeightedMean(mean_target))
        .with_compatibility(policy, tolerance);
    let solution = match problem.solve_with_options(&options) {
        Ok(solution) => solution,
        Err(e) => {
            let status = format!("拒否 {:?}", e.kind());
            rows.push((label, status, "-".to_owned(), None, None, None, None, None));
            continue;
        }
    };
    let report = solution.report();
    let d = report.diagnostics();
    let b = d.nullspace().ok_or("零空間の診断がない")?;
    let gauge = d.nullspace_gauge_defect().ok_or("ゲージの欠陥がない")?;
    let origin = d
        .nullspace_source()
        .map_or("-".to_owned(), |s| format!("{s:?}"));
    // 独立な検算: δ = 0 のときだけ解析解 u = x + c − 1/2 と比べる。
    let mut error = 0.0_f64;
    for (node, u) in solution.values().iter().enumerate() {
        let x = plan.dof_point(node).map_err(|e| e.to_string())?.point[0];
        error = error.max((u - (x + mean_target - 0.5)).abs());
    }
    let error = (flux_imbalance == 0.0).then_some(error);
    let (defect, original) = (b.compatibility_defect(), b.original_residual_norm());
    let projected = b.projected_residual_norm();
    let status = report.termination().to_string();
    rows.push((
        label,
        status,
        origin,
        Some(defect),
        Some(original),
        Some(projected),
        Some(gauge),
        error,
    ));
    if label == "Project" {
        outcome = Some((report.termination(), b.projection_norm(), gauge));
    }
}
// ゲージを指定しない既定の設定は、定数モードを持つ問題を拒否する。
let unspecified = problem.solve_with_options(&EllipticOptions::new());
let status = unspecified
    .err()
    .map_or("受理".to_owned(), |e| format!("拒否 {:?}", e.kind()));
let modes = format!("定数モード {}", plan.has_constant_modes());
rows.push(("Unspecified", status, modes, None, None, None, None, None));
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let columns = serde_json::json!([
    { "key": "0", "label": "方針" },
    { "key": "1", "label": "結果" },
    { "key": "2", "label": "零空間" },
    { "key": "3", "label": "適合欠陥 ‖Lᴴb‖ [-]", "type": "number", "format": sci3, "nullText": "-" },
    { "key": "4", "label": "残差 ‖Au−b‖ [-]", "type": "number", "format": sci3, "nullText": "-" },
    { "key": "5", "label": "残差 ‖Au−b̂‖ [-]", "type": "number", "format": sci3, "nullText": "-" },
    { "key": "6", "label": "ゲージの欠陥 |ū−c| [-]", "type": "number", "format": sci3, "nullText": "-" },
    { "key": "7", "label": "解析解との最大誤差 [-]", "type": "number", "format": sci3, "nullText": "-" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "policies" })
);
let (termination, projection, gauge) = outcome.ok_or("Project の結果がない")?;
let result = if termination.is_success() {
    Outcome::satisfied("Project の求解が完了した")
        .explanation("δ ≠ 0 では、射影した荷重に対する解である。")
} else {
    Outcome::partial("Project の求解が完了しなかった")
};
emit_outcome!(
    result
        .status(termination.to_string())
        .diagnostic("荷重の変更量 ‖b − b̂‖", projection, None)
        .diagnostic("要求したゲージの欠陥", gauge, None)
);
```

既定値（$c=2$、$\delta=0$）では、二つの方針がどちらも `Completed` で、零空間の出所は `StructuralConstant` だった。
解析解との最大誤差と要求したゲージの欠陥はどちらも 0 で、台形の重みが一次関数の平均を厳密に積分することと合う。
$\delta=0.2$ では荷重の和が 0.2 になり、適合欠陥は正規化した定数ベクトル $(1,\dots,1)/\sqrt{17}$ への成分 $\delta/\sqrt{17}\approx4.85\times10^{-2}$ になる。
`RequireCompatible` は `DomainError` で拒否し、`Project` は解を返した。
その解の元の荷重に対する残差は射影量と同じ $4.85\times10^{-2}$ で、射影後の残差は $1.8\times10^{-14}$ である。
この残差は解法の失敗ではなく、別の荷重を解いたことの記録である。
`nullspace()` の `gauge_defect()` は表に入れていない。
平均を合わせる前の直交ゲージに対する値なので、$c\neq0$ では大きくなる。

## 離散化ごとの零空間と多次元の Plan

Plan は反応係数を標本点で受け取るだけで、連続な関数としての符号を判定しない。
小さくても 0 でない反応は 0 として扱われず、定数モードは検出されない。
構造から定数モードを検出する条件は、離散化ごとに次のとおりである。

| Plan | 定数モードを返す条件 |
|---|---|
| `StructuredFdmPlan` | 反応と移流がすべて 0 で、Dirichlet 条件も 0 でない Robin 係数もない。周期境界の軸は条件を持たないので、この条件に含まれる |
| `StructuredFvmPlan`、`SimplexFvmPlan` | 反応がすべて 0 で、Dirichlet 条件も 0 でない Robin 係数もない。周期的なメッシュは受け付けない |
| `SimplexFemPlan` | 反応がすべて 0 で、値を固定した未知数も 0 でない Robin 係数もない |

複数の成分を持つ Plan では、成分ごとに定数モードがある。
退化した拡散や、定数以外の零空間を持つ問題には、問題に固有の基底を `EllipticProblem::with_nullspace` で与え、`Orthogonal` ゲージで解く。

`EllipticProblem` は次元に依らず、`StructuredFdmPlan`、`SimplexFemPlan`、`StructuredFvmPlan`、`SimplexFvmPlan` のどれでも同じ手順で解く（[構造格子の多次元差分](../multidimensional-spatial-plans/)、[多次元の有限体積](../multidimensional-finite-volumes/)、[単体メッシュの有限要素](../simplex-finite-elements/)）。
FVM は隣り合うセルで同じ面の流束を逆の符号で使うので、内部の寄与が打ち消し合い、`face_fluxes` が返す向き付きの面の流束で収支を確かめられる。
平均値を合わせることと流束が保存されることは別の性質である。
非圧縮流れの圧力のゲージは `IncompressibleOptions` が受け持ち、`new()` は閉じた連結成分に重み付き平均 0 のゲージを自動で置き、`with_gauges` は連結成分ごとの `EllipticGauge` の列を明示する（[圧力のゲージと流束の適合条件](oxref:pde-pressure-gauge)）。

## まとめ

零空間が分かっている楕円問題は、`EllipticOptions::with_gauge` でゲージを明示しない限り拒否される。
物理的な平均を指定するなら `WeightedMean(c)` を使い、その誤差は `nullspace_gauge_defect()` で確かめる。
適合しない荷重は既定で `DomainError` になり、`Project` を選べば射影した荷重を解き、`nullspace()` の適合欠陥、射影量、元の残差と射影後の残差でどれだけ変えたかを読める。
構造から分からない零空間は、正規直交基底を `with_nullspace` で与えて `Orthogonal` で解く。
