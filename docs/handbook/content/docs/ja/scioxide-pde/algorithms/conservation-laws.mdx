双曲型保存則は、質量・運動量・エネルギーのように総量が保存される量の輸送を表す。
解は有限の速さで伝わり、滑らかな初期値からでも有限時刻で不連続（衝撃波）が生じる。
このページは有限体積法（FVM）による半離散化、Riemann 問題、`scioxide-pde` が提供する数値流束と、それらを表す型を説明する。
面での再構成と境界は[保存則の再構成と境界](../conservation-reconstruction/)、CFL 条件、時間積分と空間 Plan は[保存則の CFL 条件と時間積分](../conservation-time-integration/)で扱う。

## 有限体積法の半離散形

$N$ 成分の保存量 $u(x,t)\in\mathbb{R}^N$ が $D$ 次元の領域で

$$
\partial_t u + \nabla\cdot F(u) = 0
$$

を満たすとする。
$F(u)$ は $N\times D$ の物理流束で、法線 $n$ 方向の成分を $F(u)\,n$ と書く。
セル $K$ で積分して発散定理を使うと

$$
\frac{d}{dt}\int_K u\,dx + \sum_{f\subset\partial K}\int_f F(u)\,n_{K,f}\,dS = 0
$$

となる。
$n_{K,f}$ は面 $f$ の $K$ から外向きの単位法線である。
セル平均 $\bar u_K = |K|^{-1}\int_K u\,dx$ を未知数とし、面の積分を数値流束 $\hat F$ と面の測度 $|f|$ の積で近似すると、半離散系

$$
\frac{d\bar u_K}{dt} = -\frac{1}{|K|}\sum_{f\subset\partial K} |f|\,\hat F\bigl(u_f^{-}, u_f^{+}, n_{K,f}\bigr)
$$

が得られる。
$u_f^{-}$ と $u_f^{+}$ は面の内側と外側の状態で、1 次の方法ではセル平均そのもの、2 次の方法では再構成した面の値である。
内部の面の流束は隣り合う 2 つのセルに逆符号で入るので、$\sum_K |K|\,d\bar u_K/dt$ は外部の面を通る流束の和だけになる。
この離散的な保存は衝撃波の速さを正しく求めるための条件でもある（Lax–Wendroff の定理: 保存形の一貫した方法が収束すれば、極限は弱解である）。

`scioxide-pde` の空間 Plan はこの右辺、つまり面の流束の和をセルの測度 $|K|$ で割った値（質量で正規化した残差）を返す。
面の向きは左のセルから右のセルへの単位法線で決まり、`NumericalFlux` は面の単位測度あたりの流束を返す。

このページの例は次の 3 つの方程式である。

- 線形移流 $u_t + v\cdot\nabla u = 0$: $N=1$、$F(u)\,n = (v\cdot n)\,u$。
- 方向付きの Burgers 方程式: $N=1$、$F(u)\,n = (d\cdot n)\,u^2/2$。
  $d=(1)$ の 1 次元では $u_t + (u^2/2)_x = 0$ である。
- 理想気体の Euler 方程式: 状態は $(\rho, \rho v, E)$ で、圧力は $p = (\gamma-1)\bigl(E - \tfrac12\rho|v|^2\bigr)$。
  $\rho$ は密度、$v$ は速度、$E$ は単位体積あたりの全エネルギー、$\gamma>1$ は比熱比である。

## 弱解と Riemann 問題

Burgers 方程式の滑らかな解は特性曲線 $dx/dt = u$ に沿って一定である。
速い部分が遅い部分に追いつくと特性曲線が交わり、微分形の方程式は意味を失う。
そこで積分形を満たす不連続な解（弱解）を考える。
速さ $s$ で動く不連続は、積分形から Rankine–Hugoniot 条件

$$
s\,(u_R - u_L) = f(u_R) - f(u_L)
$$

を満たす。
$u_L$、$u_R$ は不連続の左右の値、$f$ は 1 次元の流束である。
弱解は一意でないので、特性曲線が不連続に流れ込む解（Lax のエントロピー条件 $f'(u_L) > s > f'(u_R)$）を物理的な解として選ぶ。

Riemann 問題は区分的に一定な初期値

$$
u(x,0) = \begin{cases} u_L & x < 0 \\ u_R & x > 0 \end{cases}
$$

の初期値問題である。
解は $\xi = x/t$ だけの関数 $u(x,t) = w(\xi)$ になる（自己相似解）。
Burgers 方程式では $u_L > u_R$ なら速さ $s = (u_L+u_R)/2$ の衝撃波、$u_L < u_R$ なら $u_L \le \xi \le u_R$ で $w(\xi) = \xi$ となる膨張波が解である。

Euler 方程式の Riemann 問題の解は、左の音響波、接触不連続、右の音響波の 3 つの波からなる。
2 つの音響波は衝撃波か膨張波で、その間の中間状態では圧力 $p^*$ と速度 $u^*$ が左右で等しく、密度だけが接触不連続で跳ぶ。
$p^*$ は Toro の圧力関数

$$
f(p) = f_L(p) + f_R(p) + (u_R - u_L) = 0
$$

の唯一の根である。
$f_K$（$K = L, R$）は、$p > p_K$ では衝撃波の Rankine–Hugoniot 条件から

$$
f_K(p) = (p - p_K)\sqrt{\frac{A_K}{p + B_K}},\qquad A_K = \frac{2}{(\gamma+1)\rho_K},\quad B_K = \frac{\gamma-1}{\gamma+1}\,p_K,
$$

$p \le p_K$ では膨張波の等エントロピー関係から

$$
f_K(p) = \frac{2c_K}{\gamma-1}\left[\left(\frac{p}{p_K}\right)^{(\gamma-1)/(2\gamma)} - 1\right]
$$

で与えられる。
$c_K = \sqrt{\gamma p_K/\rho_K}$ は音速である。
$f$ は単調増加なので、$f(0) < 0$（真空が生じない条件）なら根は一つで、$u^* = \tfrac12(u_L+u_R) + \tfrac12\bigl(f_R(p^*) - f_L(p^*)\bigr)$ となる。
各波の位置と波の中の状態は $p^*$、$u^*$ から閉形式で求まる（Toro, 4 章）。

`scioxide-pde` は Euler 方程式の厳密な Riemann 解法を提供しない。
次の定義のブロックは、数値流束と比べる参照値として $p^*$ を `scioxide-rootfind` の Brent 法で求め、$\xi$ での状態を Toro の 4 章の式で返す。

```rust
//| id: pde-conservation-exact-euler
//| kind: definitions
//| title: 理想気体の Riemann 問題の厳密解（参照値）
//| crates: [scioxide-core, scioxide-rootfind]
use scioxide_core::{Interval, RealScalar};
use scioxide_rootfind::{Brent, ScalarFn, ScalarRootOptions, ScalarRootSolver};

/// 比熱比 γ。
pub(crate) const GAMMA: f64 = 1.4;

/// 基本変数 (ρ, u, p) の左右の状態と、中間状態の圧力 p* と速度 u*。
#[derive(Clone, Copy)]
pub(crate) struct ExactRiemann {
    pub(crate) left: [f64; 3],
    pub(crate) right: [f64; 3],
    pub(crate) pressure: f64,
    pub(crate) velocity: f64,
}

/// 波の関数 f_K(p)。p > p_K は衝撃波、p ≤ p_K は膨張波。
fn wave(state: [f64; 3], p: f64) -> f64 {
    let g = GAMMA;
    let [rho, _, pk] = state;
    if p > pk {
        let a = 2.0 / ((g + 1.0) * rho);
        let b = (g - 1.0) / (g + 1.0) * pk;
        (p - pk) * RealScalar::sqrt(a / (p + b))
    } else {
        let c = RealScalar::sqrt(g * pk / rho);
        2.0 * c / (g - 1.0) * (RealScalar::powf(p / pk, (g - 1.0) / (2.0 * g)) - 1.0)
    }
}

impl ExactRiemann {
    /// f(p*) = 0 を Brent 法で解く。真空が生じる組は拒否する。
    pub(crate) fn solve(left: [f64; 3], right: [f64; 3]) -> Result<Self, String> {
        let f = |p: f64| wave(left, p) + wave(right, p) + right[1] - left[1];
        let lower = 1e-12 * RealScalar::min(left[2], right[2]);
        if f(lower) >= 0.0 {
            return Err("この組は真空を生じる".into());
        }
        let mut upper = RealScalar::max(left[2], right[2]);
        while f(upper) <= 0.0 {
            upper *= 2.0;
        }
        let bracket = Interval::new(lower, upper).map_err(|e| e.to_string())?;
        let function = ScalarFn::new(|p: f64| Ok(f(p)));
        let root = Brent
            .solve(&function, bracket, &ScalarRootOptions::default())
            .map_err(|e| e.to_string())?;
        if !root.termination().is_success() {
            return Err(format!("p* の求根が {} で止まった", root.termination()));
        }
        let p = root.point();
        let velocity = 0.5 * (left[1] + right[1]) + 0.5 * (wave(right, p) - wave(left, p));
        Ok(Self {
            left,
            right,
            pressure: p,
            velocity,
        })
    }

    /// ξ = x/t での (ρ, u, p)。右側は x → −x の鏡像として左側と同じ式で求める。
    pub(crate) fn sample(&self, xi: f64) -> [f64; 3] {
        let g = GAMMA;
        let (p, sign) = (self.pressure, if xi <= self.velocity { 1.0 } else { -1.0 });
        let [rho, uk, pk] = if sign > 0.0 { self.left } else { self.right };
        let (xi, uk, us) = (sign * xi, sign * uk, sign * self.velocity);
        let c = RealScalar::sqrt(g * pk / rho);
        let w = if p > pk {
            let shock =
                uk - c * RealScalar::sqrt((g + 1.0) / (2.0 * g) * p / pk + (g - 1.0) / (2.0 * g));
            let m = (g - 1.0) / (g + 1.0);
            if xi <= shock {
                [rho, uk, pk]
            } else {
                [rho * (p / pk + m) / (m * p / pk + 1.0), us, p]
            }
        } else if xi <= uk - c {
            [rho, uk, pk]
        } else if xi >= us - c * RealScalar::powf(p / pk, (g - 1.0) / (2.0 * g)) {
            [rho * RealScalar::powf(p / pk, 1.0 / g), us, p]
        } else {
            // 膨張波の中: Riemann 不変量 u + 2c/(γ − 1) が一定で、特性曲線の傾き u − c = ξ から。
            let cf = 2.0 / (g + 1.0) * (c + 0.5 * (g - 1.0) * (uk - xi));
            let uf = 2.0 / (g + 1.0) * (c + 0.5 * (g - 1.0) * uk + xi);
            let ratio = cf / c;
            [
                rho * RealScalar::powf(ratio, 2.0 / (g - 1.0)),
                uf,
                pk * RealScalar::powf(ratio, 2.0 * g / (g - 1.0)),
            ]
        };
        [w[0], sign * w[1], w[2]]
    }
}

/// 基本変数から x 方向の物理流束 [ρu, ρu² + p, u(E + p)]。
pub(crate) fn euler_flux(w: [f64; 3]) -> [f64; 3] {
    let [rho, u, p] = w;
    let energy = p / (GAMMA - 1.0) + 0.5 * rho * u * u;
    [rho * u, rho * u * u + p, u * (energy + p)]
}
```

## 数値流束

数値流束 $\hat F(u^-, u^+, n)$ は、面の左右の状態から法線方向の流束を一つ返す。
保存形の方法が正しい弱解に収束するには、次の性質が要る。

- 一貫性: $\hat F(u, u, n) = F(u)\,n$。
- 保存: 面の両側のセルに同じ値を使う。
  向きを逆にすると $\hat F(u^+, u^-, -n) = -\hat F(u^-, u^+, n)$ となる。
- スカラーの場合の単調性: $\hat F$ が第 1 引数について非減少、第 2 引数について非増加。
  単調な流束と前進 Euler 法の組は、CFL 条件の下で最大値原理を満たし、エントロピー解に収束する（Crandall–Majda）。

### Godunov の流束

Godunov の方法は各面で厳密な Riemann 問題を解き、$\xi = 0$ での状態 $w(0)$ の物理流束を数値流束にする。
スカラーの保存則では、この値は

$$
\hat F_{\mathrm{G}}(u_L, u_R) = \begin{cases} \min_{u_L \le u \le u_R} f(u) & u_L \le u_R \\ \max_{u_R \le u \le u_L} f(u) & u_L > u_R \end{cases}
$$

と書ける（Osher の公式）。
Burgers 方程式 $f(u) = u^2/2$ で $u_L < 0 < u_R$ のとき、$\xi = 0$ は膨張波の中（音速点）にあり、$\hat F_{\mathrm G} = f(0) = 0$ となる。
近似解法の中にはこの場合に $\xi = 0$ を通る膨張衝撃波（エントロピー条件を破る不連続）を残すものがあるので、音速点の扱いは流束の重要な性質である。

`Godunov` は線形移流と Burgers 方程式に、この厳密な流束を実装する。
Euler 方程式には実装しない。

### Rusanov の流束

Rusanov の流束（局所 Lax–Friedrichs の流束）は、二つの状態の物理流束の平均に人工粘性を加える。

$$
\hat F_{\mathrm{Rus}} = \tfrac12\bigl(F(u^-)\,n + F(u^+)\,n\bigr) - \tfrac12\,a\,(u^+ - u^-),\qquad a = \max\bigl(|S_L|, |S_R|\bigr)
$$

$S_L \le S_R$ は方程式が返す、Riemann 問題の波を包む左右の信号速度である。
スカラーでは $a$ が $|f'|$ の上界なら単調で、どの保存則にも使えるが、粘性は最大の波速で決まるので、接触不連続のような遅い波を大きく拡散する。
`Rusanov` は任意の `ConservationLaw` に使える。

### HLL と HLLE の流束

HLL 法（Harten–Lax–van Leer）は、波の扇を速さ $S_L$ と $S_R$ の 2 つの波で包み、その間を一つの平均状態で近似する。
扇の上で積分形を使うと、$S_L < 0 < S_R$ のとき

$$
\hat F_{\mathrm{HLL}} = \frac{S_R\,F_L - S_L\,F_R + S_L S_R\,(u^+ - u^-)}{S_R - S_L}
$$

となる。
$F_L = F(u^-)\,n$、$F_R = F(u^+)\,n$ で、$S_L \ge 0$ なら $F_L$、$S_R \le 0$ なら $F_R$ を使う（風上）。
$S_L$、$S_R$ が真の信号速度を包むとき、平均状態は厳密解の扇の平均に一致し、Euler 方程式では密度と圧力の正値性が保たれる（Einfeldt ら, 1991）。
HLLE は Einfeldt の波速

$$
S_L = \min\bigl(v_L - c_L,\ \tilde v - \tilde c\bigr),\qquad S_R = \max\bigl(v_R + c_R,\ \tilde v + \tilde c\bigr)
$$

を使う HLL 法である。
$v_K$ は法線方向の速度、$\tilde v$、$\tilde c$ は Roe 平均の速度と音速である。
`IdealGasEuler` の波速はこの 2 つに加えて $v_R - c_R$ と $v_L + c_L$ も最小・最大に含めるので、少し広く包む。
`Hlle` はこの波速を使う HLL の流束で、`IdealGasEuler` だけに実装されている。
`Rusanov` も Euler 方程式では同じ波速を使い、$a = \max(|S_L|, |S_R|)$ とする。

### HLLC の流束

HLL の平均状態は接触不連続を表せないので、静止した接触不連続でも密度が拡散する。
HLLC 法（Toro–Spruce–Speares）は、扇の中に速さ

$$
S_M = \frac{p_R - p_L + \rho_L v_L (S_L - v_L) - \rho_R v_R (S_R - v_R)}{\rho_L (S_L - v_L) - \rho_R (S_R - v_R)}
$$

の接触波を加え、その左右に 2 つの中間状態を置く。
中間状態は

$$
\rho^*_K = \rho_K \frac{S_K - v_K}{S_K - S_M},\qquad
(\rho v)^*_K = \rho^*_K\bigl(v^{\mathrm{vec}}_K + (S_M - v_K)\,n\bigr),\qquad
E^*_K = \rho^*_K\left[\frac{E_K}{\rho_K} + (S_M - v_K)\left(S_M + \frac{p_K}{\rho_K (S_K - v_K)}\right)\right]
$$

である。
$v^{\mathrm{vec}}_K$ は速度ベクトルで、接線方向の速度は中間状態でも変わらない。
数値流束は $S_M \ge 0$ なら $F_L + S_L(u^*_L - u^-)$、$S_M < 0$ なら $F_R + S_R(u^*_R - u^+)$ である。
孤立した接触不連続（$v_L = v_R$、$p_L = p_R$）では $S_M = v_L$、$u^*_K = u_K$ となり、HLLC の流束は厳密な流束に一致する。

$S_M$ が $(S_L, S_R)$ の外にある場合、接触の圧力 $p_K + \rho_K(S_K - v_K)(S_M - v_K)$ が許容される下限以下の場合、中間状態の密度か圧力が許容されない場合には、`Hllc` はまず中間の値の桁あふれを避ける拡張範囲の演算で同じ計算をやり直す。
それでも同じ条件に当たると HLLE の流束に切り替え、その面で `used_hlle_fallback` を真にする。
真空に近い膨張波では HLLC の接触の圧力が負になりうるので、この切り替えが起こる。

## 方程式と流束の型

方程式は `ConservationLaw<R, D, N>` を実装する型で表す。
`R` は実数の型、`D` は空間次元（1〜3）、`N` は保存量の成分数である。
メソッドは次のとおりで、どれも純粋な関数として有限の値を返すことが求められる。

- `validate`: 次元と方程式の定数を、Plan の準備の前に検査する。
- `admissible`: 状態が許容集合（凸集合）に属するかを返す。
- `normal_flux`: 単位法線 $n$ 方向の物理流束 $F(u)\,n$。
- `wave_bounds`: 二つの状態の Riemann 問題の波を包む信号速度 $(S_L, S_R)$。
- `riemann_data`: 左右の物理流束と信号速度を `RiemannData` にまとめて返す。
  既定の実装は入力を検査して `normal_flux` と `wave_bounds` を呼ぶ。
  `IdealGasEuler` は各状態の圧力と音速の計算を一度だけ行い、流束と波速で共有するように上書きしている。
- `reflect`: 滑り壁での鏡像の状態。
  既定の実装はエラーを返す。

`RiemannData` は公開フィールド `left_flux`、`right_flux`、`wave_bounds` を持つ不変の値で、`Rusanov` と `Hlle` はこの値と左右の状態から流束を作る。
自作の方程式では、信号速度が実際の波を包むことと許容集合が凸であることを、実装する側が保証する。

数値流束は `NumericalFlux<R, E, D, N>` を実装する型で、`evaluate(equation, left, right, normal)` が `RiemannReport` を返す。
`normal` は $|\,|n|^2 - 1\,| \le 128\,\varepsilon$ を満たす有限の単位ベクトルでなければならず、それ以外の法線と許容されない状態は `InvalidInput` で拒否される。
`RiemannReport` の `flux()` は左から右への面の単位測度あたりの流束、`maximum_speed()` は $\max(|S_L|, |S_R|)$、`used_hlle_fallback()` は HLLC が HLLE に切り替えたかを返す。
自作の数値流束は `RiemannReport::new(flux, maximum_speed, used_hlle_fallback)` でレポートを作る。
`maximum_speed` は CFL の上限の計算に使われるので、波を包む速さを渡す。

組み込みの方程式は次の 3 つである。

- `LinearAdvection { velocity }`: 有限の速度 `velocity` の線形移流。
  許容集合は有限な値全体。
- `Burgers { direction }`: 流束 $(d\cdot n)\,u^2/2$ の Burgers 方程式。
  `direction` は有限であればよく、単位ベクトルでなくてよい。
  信号速度は $(d\cdot n)u_L$ と $(d\cdot n)u_R$ の小さいほうと大きいほうである。
- `IdealGasEuler`: 熱量的に完全な理想気体。
  状態は `[ρ, ρv_0, …, ρv_{D-1}, E]` で $N = D+2$ である。
  `new(gamma)` は有限な $\gamma > 1$ を要求し、`with_minima(density, pressure)` で非負の下限を設定する（既定は 0）。
  許容される状態は密度と圧力が下限を超える状態で、厳密な真空は扱わない。
  `conserved(rho, velocity, pressure)` は基本変数から保存量を作り、`pressure(u)` は保存量から圧力を求め、`gamma()` は比熱比を返す。
  `reflect` は法線方向の運動量 $m\cdot n$ を反転し、$m - 2(m\cdot n)n$ を返す。

方程式と数値流束の組み合わせは型で決まり、実装のない組はコンパイルできない。

| 数値流束 | `LinearAdvection` | `Burgers` | `IdealGasEuler` | 波速 |
|---|---|---|---|---|
| `Godunov` | 厳密 | 厳密（音速点を含む） | なし | $\max(\lvert S_L\rvert, \lvert S_R\rvert)$ |
| `Rusanov` | あり | あり | あり | 方程式の `wave_bounds` |
| `Hlle` | なし | なし | あり | Einfeldt・Roe と端点の固有値 |
| `Hllc` | なし | なし | あり（HLLE への切り替えを含む） | `Hlle` と同じ |

## 一つの界面での流束の比較

次のセルは一つの界面の左右に基本変数 $(\rho, u, p)$ の状態を置き、`Rusanov`、`Hlle`、`Hllc` の流束を厳密な Godunov の流束 $F(w(0))$ と比べる。
入力は左右の状態の組と、両側の速度に加える共通の速度 $\Delta v$ である。
組は Sod の衝撃波管の初期の界面、静止した接触不連続（$\rho$ だけが 1 と 0.125 で跳び、$u = 0$、$p = 1$）、Toro の二重膨張の問題（$\rho = 1$、$p = 0.4$、$u = \mp 2$）の 3 つである。
$\Delta v$ は波の扇を界面に対して動かすので、風上の向きと、界面がどの波の中にあるかが変わる。
量はすべて無次元で、$\gamma = 1.4$ とする。
表の「厳密値との差」は 3 成分の差の絶対値の最大である。

```rust
//|     expect:
//|       - {"artifact":"fluxes","path":"/rows/3/1","approx":{"value":0.39539107064,"rtol":1e-9}}
//|       - {"artifact":"fluxes","path":"/rows/0/4","approx":{"value":0.17708043385,"rtol":1e-9}}
//|       - {"artifact":"fluxes","path":"/rows/2/4","approx":{"value":0.17892757155,"rtol":1e-9}}
//|       - {"artifact":"fluxes","path":"/rows/0/5","approx":{"value":1.18321595662,"rtol":1e-10}}
//|   - case: contact
//|     expect:
//|       - {"artifact":"fluxes","path":"/rows/0/1","approx":{"value":1.46415504643,"rtol":1e-9}}
//|       - {"artifact":"fluxes","path":"/rows/2/4","range":{"max":1e-14}}
//|   - case: double-rarefaction
//|     expect:
//|       - {"artifact":"fluxes","path":"/rows/2/6","equals":"あり"}
//|       - {"artifact":"fluxes","path":"/rows/2/2","approx":{"value":-1.09666295471,"rtol":1e-9}}
//|       - {"artifact":"fluxes","path":"/rows/3/2","approx":{"value":0.00189387342,"rtol":1e-7}}
//|   - case: supersonic
//|     expect:
//|       - {"artifact":"fluxes","path":"/rows/1/4","range":{"max":1e-13}}
//|       - {"artifact":"fluxes","path":"/rows/2/4","range":{"max":1e-13}}

};
let left = [base_left[0], base_left[1] + shift, base_left[2]];
let right = [base_right[0], base_right[1] + shift, base_right[2]];

let gas = IdealGasEuler::new(GAMMA).map_err(|e| e.to_string())?;

    .map_err(|e| e.to_string())?;

export!(right, &base_right);
```

既定の Sod の界面では、厳密な Godunov の流束の質量の成分は 0.39539 である。
界面 $\xi = 0$ は左の膨張波の尾（$\xi = -0.0703$）と接触不連続（$\xi = 0.927$）の間にあり、流束は左の中間状態の物理流束になる。
3 つの近似の流束はどれもこの値と 0.18 程度ずれる。
この組では `IdealGasEuler` の波速が $S_L = -S_R = -c_L = -1.1832$ と対称になるので、HLLE の式は Rusanov の式と一致する。
Einfeldt の波速だけなら $S_R = \tilde v + \tilde c = 1.1519$ だが、端点の $v_L + c_L = 1.1832$ も含めるので $S_R$ がこの値になる。
HLLC の差（0.1789）も HLLE（0.1771）とほぼ同じである。
界面の厳密な状態は左の中間状態で、接触不連続の扱いとは関係しないので、接触波を加えても差は縮まない。

静止した接触不連続では、HLLC の流束は厳密な流束 $(0, 1, 0)$ に一致する。
Rusanov と HLLE は質量の流束に $\tfrac12 a(\rho_L - \rho_R) = 1.464$ を残し、密度の跳びを拡散させる。
二重膨張の組では HLLC の接触の圧力が負になり、HLLE への切り替えの列が「あり」になる。
このとき近似の運動量の流束は $-1.097$ で、厳密な流束（$p^* = 0.0019$）と符号まで違う。
HLL の平均状態は扇の上の積分の平均なので、密度と圧力の正値性は保たれるが、界面の流束の値そのものは厳密解から大きく離れうる。
$\Delta v = 2$ では左右の状態がどちらも超音速で右へ動き、HLLE と HLLC は風上の左の状態の物理流束を返して厳密値と一致する。
Rusanov は $a = 3.18$ の人工粘性を加え続けるので、差は 1.47 になる。

次のセルは同じ組で $\Delta v$ を $-3$ から $3$ まで動かし、3 つの流束と厳密な流束の差を描く。
組は前のセルから受け取り、前のセルで選んだ $\Delta v$ を縦線で示す。

```rust

//| ref: pde-conservation-flux-shift-sweep
//| title: 共通の速度 Δv に対する各流束と厳密な流束の差
//| run: reactive

//|   interface: pde-conservation-interface-fluxes

    serde_json::from_value(interface["left"].clone()).map_err(|e| e.to_string())?;

    serde_json::from_value(interface["right"].clone()).map_err(|e| e.to_string())?;

    let ul: [f64; 3] = gas
        .conserved(l[0], [l[1]], l[2])

        .conserved(r[0], [r[1]], r[2])
        .map_err(|e| e.to_string())?;

            .map(|i| NumericScalar::abs(flux[i] - reference[i]))
```

Sod の組では、HLLE と HLLC の差は $\Delta v \ge 1.2$ と $\Delta v \le -1.8$ で 0 になる。
この範囲ではすべての信号速度が同じ向きで、HLL の式は風上の物理流束になる。
亜音速の範囲ではどちらの差も 0.28 以下である。
Rusanov の差は $|\Delta v|$ とともに増え、$\Delta v = \pm 3$ で 2.31 になる。
Rusanov の人工粘性は流れの速さを含む $a$ に比例し、Galilei 変換で流れを速くすると拡散も増える。
静止した接触不連続の組を選ぶと、HLLC の差はどの $\Delta v$ でも $10^{-15}$ 以下で、接触不連続が動いても厳密な流束を返す。
この組の右の音速は 3.35 なので、HLLE の差は $|\Delta v| \le 3$ では 0 にならない。

## まとめ

保存則の有限体積法はセル平均の変化を面の数値流束の和で表し、内部の流束が打ち消し合うので総量を離散的に保存する。
スカラーの方程式では `Godunov` が厳密な Riemann 解の流束を返し、`Rusanov` はどの `ConservationLaw` にも使えるが、最大の波速に比例する拡散を加える。
Euler 方程式では `Hlle` が密度と圧力の正値性を保つ HLL の流束、`Hllc` が接触不連続を厳密に扱う流束で、`Hllc` は中間状態が許容されないとき HLLE に切り替えて `used_hlle_fallback` に記録する。
一つの界面の比較から、接触不連続を鋭く保つ必要があるなら `Hllc`、真空に近い状態でロバスト性を優先するなら `Hlle` を選べる。
自作の方程式は `ConservationLaw` を実装し、波を包む信号速度と凸な許容集合を保証すれば、組み込みの `Rusanov` と空間 Plan で解ける。
