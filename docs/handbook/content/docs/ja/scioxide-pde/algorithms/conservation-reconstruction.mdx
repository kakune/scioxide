[保存則と数値流束](../conservation-laws/)の半離散系は、面の左右の状態が決まれば閉じる。
このページはセル平均から面の状態を作る再構成と、外部の面の外側の状態を説明する。
刻みの上限、時間積分と空間 Plan は[保存則の CFL 条件と時間積分](../conservation-time-integration/)で扱う。

## MUSCL の再構成

1 次の方法は面の状態としてセル平均をそのまま使い、空間の精度は 1 次である。
MUSCL（van Leer）は各セルで線形の分布

$$
u_K(x) = \bar u_K + g_K\cdot(x - x_K)
$$

を作り、面の重心 $x_f$ での値 $u_K(x_f)$ を数値流束に渡す。
$x_K$ はセルの重心、$g_K$ は勾配の推定である。
線形の分布のセル平均は $\bar u_K$ のままなので、保存は崩れない。

不連続の近くで勾配をそのまま使うと、面の値が隣のセルの値を超えて新しい極値（振動）を作る。
Godunov の定理によれば、線形の方法で単調性を保つものは 1 次までなので、2 次の精度と単調性を両立させるには、解に応じて勾配を制限する非線形の制限関数（limiter）が要る。

構造格子では軸ごとに、左右の隣のセルとの片側の差分商

$$
a = \frac{\bar u_K - \bar u_{K-}}{h_-},\qquad b = \frac{\bar u_{K+} - \bar u_K}{h_+}
$$

から勾配の成分を選ぶ。
$h_\pm$ はセルの重心の間の距離である。
`scioxide-pde` の 2 つの制限関数は次のとおりである。

- minmod: $g = \operatorname{minmod}(a, b)$。
  $\operatorname{minmod}$ は引数の符号がすべて同じなら絶対値の最小のもの、そうでなければ 0 を返す。
- MC（monotonized central）: $g = \operatorname{minmod}\bigl(c,\ 2a,\ 2b\bigr)$。
  $c = (h_+ a + h_- b)/(h_- + h_+)$ は 3 点の 2 次補間の中心での微分で、一様格子では $(a+b)/2$ である。

どちらも $a$ と $b$ の符号が違う極値のセルでは勾配を 0 にする。
一様格子の 1 次元のスカラーの問題では、どちらの再構成も、[CFL 条件](oxref:pde-conservation-cfl)の下の前進 Euler 法と組むと TVD（全変動 $\sum_i |\bar u_{i+1} - \bar u_i|$ を増やさない）になり、滑らかで単調な部分では 2 次の精度になる。
minmod は 2 つの差分商の小さいほうを選ぶので拡散が大きく、MC は中心差分をできるだけ使うので不連続をより鋭く保つ。

外部の面に接するセルでその向きに隣のセルがない場合は、境界の外側の状態（下の[境界の外側の状態](#境界の外側の状態)）を、面の重心までの距離にある値として片側の差分商に使う。
片側に隣も外側の状態もない場合は、勾配の成分を 0 にする。

### 面の値の上下限と許容性

勾配を選んだあと、`scioxide-pde` はすべての再構成に 2 つの縮小を加える。

1 つ目は成分ごとの上下限である。
セル平均、面で隣り合うセルの平均、外部の面の外側の状態の最小値と最大値を $m_K$、$M_K$ とし、すべての面の値が $[m_K, M_K]$ に入るように勾配を係数 $\theta \in [0, 1]$ 倍する。
上下限に使う外側の状態は、再構成した面の値ではなくセル平均から作る（`Exterior` では指定した値を使う）ので、外挿した面の値が新しい極値を持ち込むことはない。

2 つ目は許容性である。
面の値がどれか一つでも `ConservationLaw::admissible` を満たさないと、全成分の勾配に共通の係数を掛けて半分にすることを繰り返し、最後は定数の再構成に戻す。
セル平均は許容されるので、定数の再構成の面の値も許容される。
密度や圧力が 0 に近い Euler 方程式の状態で、負の密度の面の値を数値流束に渡さないための処理である。

`ConservationReport::limited_cells` は、勾配が中心の差分商 $c$ と異なった、片側の差分商がなかった、または上の 2 つの縮小で小さくなったセルの数である。
minmod では $a \ne b$ のセルが（一様格子で $a = -b$ となる場合を除いて）数えられるので、滑らかな解でもこの数は 0 にならない。

## 単体メッシュの Barth–Jespersen の再構成

三角形と四面体では軸ごとの隣が定まらないので、面で隣り合うセルの重心への変位 $d_j = x_j - x_K$ を使う重み付き最小二乗で勾配を求める。

$$
g_K = \operatorname*{arg\,min}_{g}\ \sum_j \frac{\bigl(g\cdot d_j - (\bar u_j - \bar u_K)\bigr)^2}{|d_j|^2}
$$

境界のセルでは隣が $D$ 個より少ないことがあり、正規方程式が特異（階数落ち）になる。
その場合は勾配を 0 にし、`ConservationReport::rank_deficient_cells` に数える。
勾配は前節の上下限で縮小する。
この縮小は Barth–Jespersen の制限関数そのもので、面の値を隣のセル平均の範囲に収める。

`ConservationReconstruction` の 4 つの値と使えるメッシュは次のとおりである。

| 値 | 方法 | 構造格子 | 単体メッシュ |
|---|---|---|---|
| `Constant` | 区分定数（1 次） | 使える | 使える |
| `Minmod` | MUSCL、minmod | 使える | 使えない |
| `MonotonizedCentral` | MUSCL、MC | 使える | 使えない |
| `BarthJespersen` | 重み付き最小二乗の勾配と面での極値の制限 | 使えない | 使える |

使えない組み合わせは Plan の準備のときに `InvalidInput` で拒否される。

## 境界の外側の状態

外部の面では外側の状態を内側の面の値と組にして、内部の面と同じ数値流束で Riemann 問題を解く。
`ConservationBoundary` は外側の状態の作り方を表す。

- `Transmissive`: 内側の面の値をそのまま外側の状態にする。
  流束の一貫性から、面の流束は内側の状態の物理流束になる。
  波が反射せずに出ていく流出境界に使う。
- `Exterior(f)`: 外側の状態を `f(x, t)` で指定する。
  `x` は面の重心、`t` は物理時刻である。
  流入境界や遠方の一様流に使い、`ConservationBoundary::exterior(closure)` で作る。
- `SlipWall`: `ConservationLaw::reflect` で法線方向の運動量を反転した状態を外側に置く。
  対称な状態の Riemann 問題になるので、壁を通る質量の流束は 0 になる。
  `reflect` を実装した方程式（組み込みでは `IdealGasEuler`）だけで使える。

外側の状態が許容されない場合、残差の評価は `InvalidInput` で失敗する。

`ConservationReport::boundary_flux()` は、外部の面を通る外向きの流束を面の測度で積分した値の成分ごとの和である。
内部の流束は打ち消し合うので、総量 $Q = \sum_K |K|\,\bar u_K$ について

$$
\frac{dQ}{dt} = -\,(\text{boundary\_flux})
$$

が丸め誤差を除いて成り立つ。
周期境界の継ぎ目には条件を置かず、継ぎ目の面は内部の面として扱われる。

## 境界を通る矩形波の移流

この節の 2 つのセルは区間 $[0, 1]$ で速度 1 の線形移流 $u_t + u_x = 0$ を、初期値の矩形波（$0.1 \le x < 0.4$ で 1、他で 0）から終端時刻 $T$ まで進める。
左端の流入境界は `Exterior` で値 $u_{\mathrm{in}}$ を与え、右端の流出境界は `Transmissive` か値 0 の `Exterior` にする。
厳密解は $x \ge t$ で $u_0(x - t)$、$x < t$ で $u_{\mathrm{in}}$ で、$\min(0, u_{\mathrm{in}})$ と $\max(1, u_{\mathrm{in}})$ の間にある。
空間は `StructuredConservationPlan` と `Godunov`、時間は `Heun` で離散化し、刻みは CFL の上限 $\Delta t_{\max} = 0.45\,h/2$ にそろえる。
次の定義のブロックはこの計算と厳密なセル平均を 2 つのセルで共有する。

```rust
//| id: pde-conservation-advection-model
//| kind: definitions
//| title: 流入と流出の境界を持つ線形移流の計算と厳密なセル平均
//| crates: [scioxide-core, scioxide-ode, scioxide-pde, scioxide-spatial]
use scioxide_core::{ExecutionContext, NumericScalar, RealScalar};
use scioxide_ode::{Heun, OdeMethod, OdeOptions, OdeOutputSchedule, OdeProblem, OdeState};
use scioxide_pde::{ConservationBoundary, ConservationOptions, ConservationReconstruction};
use scioxide_pde::{Godunov, LinearAdvection, StructuredConservationPlan};
use scioxide_spatial::SegmentMesh;
use scioxide_spatial::{AxisSide, AxisTopology, BoundarySet, CellField, CoordinateAxis, Grid1d};

/// 厳密解 u(x, T) の区間 [a, b] での平均。境目は T、0.1 + T、0.4 + T。
pub(crate) fn exact_average(inflow: f64, end: f64, a: f64, b: f64) -> f64 {
    let pieces = [
        (f64::NEG_INFINITY, end, inflow),
        (0.1 + end, 0.4 + end, 1.0),
    ];
    let overlap =
        |lo: f64, hi: f64| RealScalar::max(RealScalar::min(b, hi) - RealScalar::max(a, lo), 0.0);
    pieces
        .iter()
        .map(|&(lo, hi, v)| v * overlap(lo, hi))
        .sum::<f64>()
        / (b - a)
}

/// 1 回の計算の結果。low と high は受理したすべての刻みでのセル平均の最小と最大。
pub(crate) struct AdvectionRun {
    pub(crate) centers: Vec<f64>,
    pub(crate) values: Vec<f64>,
    pub(crate) status: String,
    pub(crate) steps: usize,
    pub(crate) maximum_step: Option<f64>,
    pub(crate) low: f64,
    pub(crate) high: f64,
    pub(crate) error: f64,
    pub(crate) limited: usize,
}

/// N 個のセルで時刻 T まで進め、厳密なセル平均との L¹ 誤差を求める。
pub(crate) fn advect(
    reconstruction: ConservationReconstruction,
    inflow: f64,
    zero_outlet: bool,
    cells: usize,
    end: f64,
) -> Result<AdvectionRun, String> {
    let h = 1.0 / cells as f64;
    let axis = CoordinateAxis::uniform(0.0, 1.0, cells + 1).map_err(|e| e.to_string())?;
    let grid = Grid1d::new([axis], [AxisTopology::Bounded]).map_err(|e| e.to_string())?;
    let mesh = SegmentMesh::new(grid).map_err(|e| e.to_string())?;
    let start = BoundarySet::axis_side(&mesh, 0, AxisSide::Start).map_err(|e| e.to_string())?;
    let finish = BoundarySet::axis_side(&mesh, 0, AxisSide::End).map_err(|e| e.to_string())?;
    let outlet = if zero_outlet {
        ConservationBoundary::exterior(|_, _| Ok([0.0]))
    } else {
        ConservationBoundary::Transmissive
    };
    let conditions = vec![
        (
            start,
            ConservationBoundary::exterior(move |_, _| Ok([inflow])),
        ),
        (finish, outlet),
    ];
    let options = ConservationOptions::new().with_reconstruction(reconstruction);
    let plan = StructuredConservationPlan::with_options(mesh, conditions, options)
        .map_err(|e| e.to_string())?;
    let initial = CellField::from_fn(plan.mesh(), |i| {
        let x = plan.centers()[i][0];
        [if (0.1..0.4).contains(&x) { 1.0 } else { 0.0 }]
    })
    .map_err(|e| e.to_string())?;
    let law = LinearAdvection { velocity: [1.0] };
    let mut workspace = plan.workspace().map_err(|e| e.to_string())?;
    let system = plan
        .bind(&law, &Godunov, &mut workspace)
        .map_err(|e| e.to_string())?;
    let problem = OdeProblem::new(&system, end);
    // 固定刻みの Heun に大きな初期刻みを渡し、各刻みを CFL の上限にする。
    let options = OdeOptions::new()
        .with_initial_step(1.0)
        .with_output_schedule(OdeOutputSchedule::AcceptedSteps);
    let vector = plan
        .initial_state(&law, initial.view())
        .map_err(|e| e.to_string())?;
    let mut state = OdeState::new(0.0, vector);
    let (mut low, mut high) = (0.0_f64, 1.0_f64);
    let mut sink = |_: f64, u: &[f64]| {
        for &v in u {
            low = RealScalar::min(low, v);
            high = RealScalar::max(high, v);
        }
        Ok(())
    };
    let method = Heun::new();
    let mut ode_workspace = method
        .workspace(&problem, &options)
        .map_err(|e| e.to_string())?;
    let execution = ExecutionContext::sequential();
    let solve = method
        .advance(
            &problem,
            &options,
            &mut state,
            &mut sink,
            &mut ode_workspace,
            execution,
        )
        .map_err(|e| e.to_string())?;
    let report = system
        .report(state.time(), state.values(), execution)
        .map_err(|e| e.to_string())?;
    let values = state.values().to_vec();
    let error = values
        .iter()
        .enumerate()
        .map(|(i, &u)| {
            let a = i as f64 * h;
            h * NumericScalar::abs(u - exact_average(inflow, end, a, a + h))
        })
        .sum();
    Ok(AdvectionRun {
        centers: plan.centers().iter().map(|x| x[0]).collect(),
        values,
        status: solve.termination().map_or("なし".into(), |t| t.to_string()),
        steps: solve.accepted_steps(),
        maximum_step: report.maximum_step(),
        low,
        high,
        error,
        limited: report.limited_cells(),
    })
}
```

最初のセルは 3 つの再構成を同じ条件で解き、解の形と、受理したすべての刻みでのセル平均の最小と最大を比べる。
流出境界の Godunov の流束は風上である内側の面の値だけで決まるが、値 0 の `Exterior` では、その面の値を作る右端のセルの片側の差分商と上下限に 0 が入る。
`Transmissive` では外側の状態がセル平均と等しいので、右端のセルの勾配は 0 になる。

既定値（$u_{\mathrm{in}} = 0.5$、右端は値 0 の `Exterior`、$N = 200$、$T = 0.75$）では、3 つの計算はどれも `ReachedEnd` で終わり、667 回の刻みはすべて $\Delta t_{\max} = 0.45 \times 0.005/2 = 1.125 \times 10^{-3}$ だった。
受理したすべての刻みで、セル平均は $[0, 1]$ に収まった。
MC の最小値 $-7.6 \times 10^{-20}$ は丸め誤差の大きさで、境界の近くで値が範囲を外れることはない。
$L^1$ 誤差は定数の再構成で $6.94 \times 10^{-2}$、minmod で $2.74 \times 10^{-2}$、MC で $1.62 \times 10^{-2}$ で、グラフでは MC の矩形波の角が最も鋭い。
制限したセルの数は minmod の 138 に対して MC は 34 で、MC は中心の差分商を多く使っている。
右端を `Transmissive` にすると、minmod の誤差は 8 桁目で、MC の誤差は 13 桁目で変わる。
右端の外側の状態は右端のセルの勾配を通して流出する流束を変えるだけなので、その影響は小さい。

不連続を含む解では、$L^1$ 誤差の収束は方法の次数より遅い。
線形の $p$ 次の方法で不連続な初期値を移流すると、不連続の幅が $h^{p/(p+1)}$ 程度に広がるので、$L^1$ 誤差は $O(h^{p/(p+1)})$ になる（1 次で $h^{1/2}$、2 次で $h^{2/3}$。
LeVeque, *Finite Volume Methods for Hyperbolic Problems*, 2002）。
次のセルは流入の値を 0、流出境界を `Transmissive` にして、セル数を 25 から倍々に増やし、$L^1$ 誤差と、隣り合う $N$ の組から求めた観測次数 $\log_2(e_{N/2}/e_N)$ を示す。
グラフの破線は傾き $-1/2$ と $-2/3$ の参照線で、$N = 25$ の定数の再構成の誤差を通る。

```rust
//| id: pde-conservation-advection-refinement
//| ref: pde-conservation-advection-refinement
//| title: 矩形波の移流の L¹ 誤差の収束次数を再構成ごとに測る
//| run: button
//| uses: [pde-conservation-advection-model]
//| crates: [scioxide-core, scioxide-ode, scioxide-pde, scioxide-spatial]
//| inputs:
//|   finest: {"type":"select","label":"最大のセル数","options":["200","400","800"],"value":"400"}
//|   end_time: {"type":"range","label":"終端時刻 T [-]","description":"矩形波が右端に届く前の時刻を選ぶ。","min":0.1,"max":0.6,"step":0.1,"value":0.5}
//| timeoutMs: 30000
//| cases:
//|   - {"id":"short","label":"T = 0.1、N ≤ 200","description":"短い時間では不連続の広がりが小さく、粗い格子の次数は漸近値より小さい。","inputs":{"end_time":0.1,"finest":"200"}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"orders","path":"/rows/4/2","approx":{"value":0.491,"atol":0.01}}
//|       - {"artifact":"orders","path":"/rows/4/4","approx":{"value":0.653,"atol":0.01}}
//|       - {"artifact":"orders","path":"/rows/4/6","approx":{"value":0.688,"atol":0.01}}
//|       - {"artifact":"orders","path":"/rows/0/2","equals":null}
//|   - case: short
//|     expect:
//|       - {"artifact":"orders","path":"/rows/3/0","equals":200}
//|       - {"artifact":"orders","path":"/rows/3/2","approx":{"value":0.495,"atol":0.01}}
use scioxide_core::RealScalar;
use scioxide_pde::ConservationReconstruction;

let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let fixed2 = serde_json::json!({ "fractionDigits": 2 });
let finest: usize = finest.parse().map_err(|_| "セル数が不正")?;
let sizes: Vec<usize> = (0..)
    .map(|k| 25 << k)
    .take_while(|&n| n <= finest)
    .collect();
let methods = [
    ("定数", ConservationReconstruction::Constant),
    ("minmod", ConservationReconstruction::Minmod),
    ("MC", ConservationReconstruction::MonotonizedCentral),
];
let mut errors = vec![Vec::new(); methods.len()];
for &n in &sizes {
    for (k, &(_, reconstruction)) in methods.iter().enumerate() {
        errors[k].push(advect(reconstruction, 0.0, false, n, end_time)?.error);
    }
}
let order = |e: &[f64], i: usize| (i > 0).then(|| RealScalar::log2(e[i - 1] / e[i]));
let rows: Vec<_> = sizes
    .iter()
    .enumerate()
    .map(|(i, &n)| {
        let [c, m, mc] = [&errors[0], &errors[1], &errors[2]];
        (n, c[i], order(c, i), m[i], order(m, i), mc[i], order(mc, i))
    })
    .collect();
let columns = serde_json::json!([
    { "key": "0", "label": "セル数 N", "type": "integer" },
    { "key": "1", "label": "定数の L¹ 誤差 [-]", "type": "number", "format": sci3 },
    { "key": "2", "label": "定数の次数 [-]", "type": "number", "format": fixed2, "nullText": "—" },
    { "key": "3", "label": "minmod の L¹ 誤差 [-]", "type": "number", "format": sci3 },
    { "key": "4", "label": "minmod の次数 [-]", "type": "number", "format": fixed2, "nullText": "—" },
    { "key": "5", "label": "MC の L¹ 誤差 [-]", "type": "number", "format": sci3 },
    { "key": "6", "label": "MC の次数 [-]", "type": "number", "format": fixed2, "nullText": "—" }
]);

    rows,
    metadata = serde_json::json!({ "id": "orders" })

    .iter()
    .zip(&errors)
    .zip(markers)
```

既定値（$T = 0.5$、最大 400 セル）では、$N = 400$ での観測次数は定数で 0.49、minmod で 0.65、MC で 0.69 で、理論の $1/2$ と $2/3$ に近い。
2 次の再構成でも $L^1$ 誤差は $h^2$ では減らず、不連続の広がりが収束を決めている。
同じ $N$ では MC の誤差が定数の再構成の約 5 分の 1 なので、不連続を含む問題でも 2 次の再構成は同じ精度を少ないセルで達成する。
粗い格子（$N = 25 \to 50$）の次数は 0.3〜0.44 で、漸近的な次数には達していない。

## 三角形メッシュでの Barth–Jespersen の再構成

次のセルは単位正方形を $n \times n$ の正方形に分け、各正方形を対角線で 2 つの三角形に分けたメッシュで、速度 $(\cos\theta, \sin\theta)$ の線形移流の残差を一回評価する。
初期値は中心 $(0.5, 0.5)$、半径 0.25 の円の内側で 1、外側で 0 で、境界の外側の状態はすべて 0 とする。
定数の再構成と Barth–Jespersen の再構成で、`ConservationReport` の値と、最大の刻みで前進 Euler 法の 1 段を進めた値の範囲、総量の収支 $\sum_K |K|\,r_K + (\text{boundary\_flux})$ を比べる。
$r_K$ は `residual_into` が返す残差である。

```rust
//| id: pde-conservation-simplex-limiter
//| ref: pde-conservation-simplex-limiter
//| title: 三角形メッシュで定数と Barth–Jespersen の再構成のレポートを比べる
//| run: reactive
//| crates: [scioxide-core, scioxide-pde, scioxide-spatial]
//| inputs:
//|   divisions: {"type":"select","label":"一辺の分割数 n","options":["8","16","32"],"value":"16"}
//|   angle: {"type":"range","label":"移流の向き θ [deg]","min":0,"max":90,"step":15,"value":30}
//| cases:
//|   - {"id":"fine","label":"n = 32","description":"制限したセルは増えるが、階数落ちのセルは 2 つの角の三角形だけのまま。","inputs":{"divisions":"32"}}
//|   - {"id":"axis","label":"θ = 0°","description":"x 方向の移流では Δt_max = 0.45 × (h²/2)/(2h) = 0.45h/4 になる。","inputs":{"angle":0}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"reports","path":"/rows/0/1","approx":{"value":0.00811898816,"rtol":1e-8}}
//|       - {"artifact":"reports","path":"/rows/1/2","equals":54}
//|       - {"artifact":"reports","path":"/rows/1/3","equals":2}
//|       - {"artifact":"reports","path":"/rows/0/3","equals":0}
//|       - {"artifact":"reports","path":"/rows/1/4","range":{"min":-1e-14}}
//|       - {"artifact":"reports","path":"/rows/1/5","range":{"max":1.00000000000001}}
//|       - {"artifact":"reports","path":"/rows/1/6","range":{"max":1e-14}}
//|   - case: fine
//|     expect:
//|       - {"artifact":"reports","path":"/rows/1/3","equals":2}
//|       - {"artifact":"reports","path":"/rows/1/2","equals":108}
//|   - case: axis
//|     expect:
//|       - {"artifact":"reports","path":"/rows/0/1","approx":{"value":0.00703125,"rtol":1e-12}}
use scioxide_core::{ExecutionContext, NumericScalar, RealScalar};
use scioxide_pde::{ConservationBoundary, ConservationOptions, ConservationReconstruction};
use scioxide_pde::{Godunov, LinearAdvection, SimplexConservationPlan};
use scioxide_spatial::{CellField, Point, SimplexBoundaryTags, TriangleMesh};

let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let fixed4 = serde_json::json!({ "fractionDigits": 4 });
let n: usize = divisions.parse().map_err(|_| "分割数が不正")?;
let points = (0..=n)
    .flat_map(|j| (0..=n).map(move |i| Point::new([i as f64 / n as f64, j as f64 / n as f64])))
    .collect::<Result<Vec<_>, _>>()
    .map_err(|e| e.to_string())?;
// 正方形 (a, b, c, d) を対角線 a–c で 2 つの三角形に分ける。
let triangles: Vec<[usize; 3]> = (0..n)
    .flat_map(|j| {
        (0..n).flat_map(move |i| {
            let a = j * (n + 1) + i;
            [[a, a + 1, a + n + 2], [a, a + n + 2, a + n + 1]]
        })
    })
    .collect();
let theta = angle * <f64 as RealScalar>::PI / 180.0;
let law = LinearAdvection {
    velocity: [RealScalar::cos(theta), RealScalar::sin(theta)],
};
let mut rows = Vec::new();
for (name, reconstruction) in [
    ("定数", ConservationReconstruction::Constant),
    (
        "Barth–Jespersen",
        ConservationReconstruction::BarthJespersen,
    ),
] {
    let mesh =
        TriangleMesh::new(points.clone(), triangles.clone()).map_err(|e| e.to_string())?;
    let entries = mesh.boundary_faces().map(|face| (face, 0)).collect();
    let tags = SimplexBoundaryTags::new(&mesh, entries).map_err(|e| e.to_string())?;
    let conditions = vec![(0, ConservationBoundary::exterior(|_, _| Ok([0.0])))];
    let options = ConservationOptions::new().with_reconstruction(reconstruction);
    let plan = SimplexConservationPlan::with_options(mesh, &tags, conditions, options)
        .map_err(|e| e.to_string())?;
    let field = CellField::from_fn(plan.mesh(), |k| {
        let [x, y] = plan.centers()[k];
        [if (x - 0.5) * (x - 0.5) + (y - 0.5) * (y - 0.5) < 0.0625 {
            1.0
        } else {
            0.0
        }]
    })
    .map_err(|e| e.to_string())?;
    let mut residual = vec![[0.0]; plan.volumes().len()];
    let mut workspace = plan.workspace().map_err(|e| e.to_string())?;
    let report = plan
        .residual_into(
            &law,
            &Godunov,
            0.0,
            field.view(),
            &mut residual,
            &mut workspace,
            ExecutionContext::sequential(),
        )
        .map_err(|e| e.to_string())?;
    let dt = report.maximum_step().ok_or("波速が 0 で上限がない")?;
    let updated: Vec<f64> = field
        .values()
        .iter()
        .zip(&residual)
        .map(|(u, r)| u[0] + dt * r[0])
        .collect();
    let low = updated.iter().copied().fold(f64::INFINITY, f64::min);
    let high = updated.iter().copied().fold(f64::NEG_INFINITY, f64::max);
    let total: f64 = residual
        .iter()
        .zip(plan.volumes())
        .map(|(r, v)| r[0] * v)
        .sum();
    let balance = NumericScalar::abs(total + report.boundary_flux()[0]);
    rows.push((
        name,
        dt,
        report.limited_cells(),
        report.rank_deficient_cells(),
        low,
        high,
        balance,
    ));
}
let columns = serde_json::json!([
    { "key": "0", "label": "再構成" },
    { "key": "1", "label": "Δt_max [-]", "type": "number", "format": sci3 },
    { "key": "2", "label": "制限したセル [個]", "type": "integer" },
    { "key": "3", "label": "階数落ちのセル [個]", "type": "integer" },
    { "key": "4", "label": "1 段後の最小値 [-]", "type": "number", "format": fixed4 },
    { "key": "5", "label": "1 段後の最大値 [-]", "type": "number", "format": fixed4 },
    { "key": "6", "label": "総量の収支の残り [-]", "type": "number", "format": sci3 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "reports" })
);
```

既定値（$n = 16$、$\theta = 30^\circ$）では、2 つの再構成の $\Delta t_{\max}$ はどちらも $8.12 \times 10^{-3}$ である。
CFL の上限は面の波速で決まり、線形移流では波速が状態によらないので、再構成を変えても上限は変わらない。
Barth–Jespersen では 54 個のセルの勾配が制限され、階数落ちのセルは 2 個だった。
この 2 個は、右下と左上の角で 2 つの辺が外部の面になり、隣が一つしかない三角形である。
前進 Euler 法の 1 段のあとの値はどちらの再構成でも $[0, 1]$ に入り、総量の収支の残りは $2 \times 10^{-17}$ で、離散的な保存が丸め誤差の範囲で成り立つ。

## まとめ

2 次の再構成は面の値を線形の分布から作り、構造格子では minmod と MC、単体メッシュでは重み付き最小二乗の勾配と Barth–Jespersen の制限を使う。
`scioxide-pde` はどの再構成でも、面の値をセル平均、隣のセル平均、外側の状態の範囲に収め、許容されない面の値が出れば勾配を半分ずつ小さくする。
そのため境界の外側に流入の値や 0 を指定しても、スカラーの移流の解は受理したすべての刻みで初期値と境界値の範囲にとどまる。
不連続を含む解の $L^1$ 誤差は定数の再構成で $h^{1/2}$、2 次の再構成で $h^{2/3}$ 程度で減るので、格子の細分化の結果はこの次数と比べて読む。
`limited_cells` と `rank_deficient_cells` は、勾配がどれだけ制限されたか、最小二乗が使えなかったセルがいくつあるかを残差の評価ごとに示す。
