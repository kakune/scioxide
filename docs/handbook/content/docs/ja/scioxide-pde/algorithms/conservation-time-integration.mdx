[保存則と数値流束](../conservation-laws/)と[保存則の再構成と境界](../conservation-reconstruction/)で作った残差 $L(u)$ は、セル平均の常微分方程式 $du/dt = L(u)$ の右辺である。
このページは陽的な方法の刻みの上限、`scioxide-ode` の方法で進めるときの許容性の検査、それらをまとめる空間 Plan の API を説明する。

## CFL 条件と最大の刻み

1 次元のスカラーの問題で、Rusanov の流束と前進 Euler 法の 1 段を考える。

$$
\bar u_i^{n+1} = \bar u_i^n - \frac{\Delta t}{h}\Bigl(\hat F(\bar u_i, \bar u_{i+1}) - \hat F(\bar u_{i-1}, \bar u_i)\Bigr)
$$

面の $a$ が両側の $|f'|$ の上界なら、$\hat F$ の偏微分 $\partial_1 \hat F = \tfrac12(f'(u^-) + a)$、$\partial_2 \hat F = \tfrac12(f'(u^+) - a)$ は $0 \le \partial_1 \hat F \le a$、$-a \le \partial_2 \hat F \le 0$ を満たすので、$\bar u_i^{n+1}$ を $\bar u_i$ で微分した値は $1 - \frac{\Delta t}{h}(a_{i+1/2} + a_{i-1/2})$ 以上になる。
したがって

$$
\frac{\Delta t}{h}\,\bigl(a_{i-1/2} + a_{i+1/2}\bigr) \le 1
$$

なら更新は 3 つの値の単調な関数になり、最大値原理が成り立つ。
多次元のセル $K$ では、この条件は $\Delta t \sum_{f\subset\partial K} |f|\,s_f \le |K|$ になる。
$s_f$ は面 $f$ の数値流束が返した最大信号速度である。

2 次の再構成ではセル平均を面の値の平均に分けて、面ごとの 1 次の更新の凸結合として書く。
1 次元の線形の再構成では $\bar u_i = \tfrac12(u_{i-1/2}^+ + u_{i+1/2}^-)$ と分けられ、それぞれの更新の刻みが 2 倍になるので、条件は半分の $\Delta t \sum_f |f|\,s_f \le \tfrac12 |K|$ になる（Zhang–Shu, 2010）。

`scioxide-pde` は Courant 数 $\nu$ を使って、残差を評価した状態での最大の刻みを

$$
\Delta t_{\max} = \min_K \frac{\nu\,|K|}{\sum_{f\subset\partial K} |f|\,s_f}
$$

とする。
$\nu$ は `ConservationOptions::with_cfl` で 0 より大きく 1/2 以下の値を選び、既定は 0.45 である。
一様な 1 次元の格子で波速が一定値 $s$ なら、$\Delta t_{\max} = \nu h/(2s)$ で、通常の Courant 数 $s\Delta t/h$ は $\nu/2 \le 1/4$ になる。
`ConservationReport::maximum_step()` がこの値、`limiting_cell()` が最小を与えたセル、`maximum_speed()` が全面の最大信号速度で、すべての波速が 0 の状態では `maximum_step()` は `None` を返す。

この上限は評価した状態の波速から求めた局所的な値で、刻みの間に波速が増えた場合の安定性は保証しない。
系の許容性（密度と圧力の正値性）は次節の検査が受け持つ。

## SSP 法による時間積分

空間 Plan の `bind(equation, flux, workspace)` は方程式、数値流束、作業領域を借りた `ConservationSystem` を返す。
`ConservationSystem` は `scioxide_ode::OdeSystem` を実装する。
状態はセルごとに $N$ 成分を並べたセル平均で、右辺は質量（セルの測度 $|K|$）で正規化した残差である。
ヤコビアンは提供しないので、陽的な方法で進める。

想定する方法は SSP 法の `scioxide_ode::ForwardEuler` と `scioxide_ode::Heun` である。
`Heun` は 2 段の SSPRK2

$$
u^{(1)} = u^n + \Delta t\,L(u^n),\qquad
u^{n+1} = \tfrac12 u^n + \tfrac12\bigl(u^{(1)} + \Delta t\,L(u^{(1)})\bigr)
$$

で、$L$ は空間の残差である。
各段は前進 Euler 法の 1 段とその凸結合なので、前進 Euler 法が上限 $\Delta t_{\mathrm{FE}}$ の下で保つ性質（最大値原理、TVD、許容集合）を、同じ刻みの下で保つ（SSP 係数 1。
Gottlieb–Shu, 1998）。

許容性は `OdeSystem::admits` で検査される。
段の入力（`Heun` の $u^{(1)}$）か候補 $u^{n+1}$ のセル平均が一つでも許容されないと、その試行は受理した状態を変えずに棄却され、刻みを半分にして再試行される。
値をクリップすることはない。
再試行の刻みが `OdeOptions::with_minimum_step` の下限を下回るか、時刻が浮動小数点数として進まなくなると、積分は `StepSizeLimit` で止まり、最後に受理した状態を返す（部分結果）。
許容されない状態で `rhs` を直接呼ぶと、`InvalidInput`（引数 `y`）のエラーになる。

陽的 Runge–Kutta 法は受理した状態での最初の残差と CFL の上限を `OdeSystem::rhs_with_step_limit` で同時に受け取るので、上限のために残差を余分に評価しない。
各刻みは、方法が提案する刻み、$\Delta t_{\max}$、`OdeOptions` の最大の刻み、残りの区間の最小になる。
`ForwardEuler` と `Heun` は固定刻みの方法なので、`with_initial_step` に大きな値を渡せば、刻みは毎回 $\Delta t_{\max}$ になる。
他の方法は同じ上限を `step_limit` で受け取り、そのときは残差をもう一回評価する。
`ConservationSystem::report(time, state, execution)` は、キャッシュを残さずに一回の残差評価の `ConservationReport` を返す。

## 空間 Plan と作業領域

空間 Plan はメッシュの幾何、面の組、再構成のステンシル、境界条件を準備して保持する。

- `StructuredConservationPlan::new(mesh, conditions)` と `with_options(mesh, conditions, options)`: 線分・四辺形・六面体の構造格子（`CellMesh`）。
  `conditions` は `(BoundarySet, ConservationBoundary)` の列で、有界な外部の面をちょうど一回ずつ覆わなければならない。
  周期の継ぎ目には条件を置かない。
- `SimplexConservationPlan::new(mesh, tags, conditions)` と `with_options(mesh, tags, conditions, options)`: 三角形と四面体（`SimplexMesh`、$D = 2, 3$）。
  外部の面ごとのタグを `SimplexBoundaryTags` で与え、`conditions` はタグごとに一つの `(u32, ConservationBoundary)` を持つ。
  タグのない外部の面、条件のないタグ、重複した条件、使われない条件は拒否される。

`ConservationOptions::new()` は定数の再構成、$\nu = 0.45$、逐次実行、リソースの上限なしを選ぶ。
`with_reconstruction`、`with_cfl`、`with_execution_policy`、`with_limits` で変え、同名の取得メソッドで読める。
実行方針はセルと面の独立な処理を最大 32 のワーカーに決定論的に分ける。
`ConservationLimits::new(max_unknowns, max_faces, max_storage_bytes)` は、全成分のセルの未知数、周期の継ぎ目の重複を含む面の数、準備と作業領域一つのバイト数の上限で、超えると準備が `InvalidInput` で失敗する。
バイト数の見積もりはメッシュ、境界のコールバック、ODE のメモリ領域、出力の場を含まず、Plan の `storage_bound()` で読める。

Plan の主なメソッドは次のとおりである。

- `mesh()`、`centers()`、`volumes()`、`unknowns()`: メッシュ、セルの重心、セルの測度、ODE の成分数（セル数 × $N$）。
- `workspace()`: 作業領域 `ConservationWorkspace` を確保する。
  同じ寸法の Plan で再利用でき、成功した評価は初回も含めてライブラリのメモリ領域を確保しない。
- `residual_into(equation, flux, time, state, output, workspace, execution)`: 質量で正規化した残差を `output` に書き、`ConservationReport` を返す。
  計算量は $O((\text{セル数} + \text{面の数})\,N D)$ で、失敗したときは `output` を変えない。
- `face_fluxes_into(...)`: 面の測度を掛けた向き付きの流束を、正準な面の順に書く。
  周期の継ぎ目の重複した面には同じ流束が入る。
- `bind`、`initial_state(equation, field)`、`field(equation, state)`: ODE 系を作り、型付きの場と ODE の状態ベクトルを変換する。
  どちらの変換も許容されない状態を拒否する。

## CFL の上限を提示しない場合

次のセルは Toro の二重膨張の問題（$\rho = 1$、$p = 0.4$、$x < 0.5$ で $u = -2$、$x > 0.5$ で $u = 2$、$\gamma = 1.4$）を区間 $[0, 1]$ の 200 セル、`Hllc` と MC の再構成、透過境界で時刻 0.15 まで進める。
中央に密度と圧力が 0 に近い領域ができるので、許容性の検査が働きやすい問題である。
`ConservationSystem` をそのまま渡す計算と、`rhs` と `admits` だけを転送して CFL の上限を隠した系を渡す計算を、同じ初期刻み $\Delta t_0$ で比べる。
後者では刻みが $\Delta t_0$ のまま試され、許容されない段の入力や候補は棄却されて刻みが半分になる。
表は終了理由、受理と棄却の回数、受理した状態の密度と圧力の最小値、最後の状態の `ConservationReport` の値である。

```rust
//| id: pde-conservation-admissibility-retry
//| ref: pde-conservation-admissibility-retry
//| title: CFL の上限の有無で二重膨張の問題の刻みと棄却を比べる
//| run: reactive
//| crates: [scioxide-core, scioxide-ode, scioxide-pde, scioxide-spatial]
//| inputs:
//|   method: {"type":"select","label":"時間積分法","options":["Heun","ForwardEuler"],"value":"Heun"}
//|   cfl: {"type":"range","label":"Courant 数 ν [-]","description":"CFL の上限 Δt_max = ν|K|/Σ|f|s_f の係数。","min":0.05,"max":0.5,"step":0.05,"value":0.45}
//|   initial_step: {"type":"range","label":"初期刻みの指数 p（Δt₀ = 10^p）","min":-4,"max":-1,"step":0.5,"value":-2}
//| cases:
//|   - {"id":"forward-euler","label":"ForwardEuler","description":"前進 Euler 法でも、CFL を隠すと 3 回の棄却のあと同じ刻みで進む。","inputs":{"method":"ForwardEuler"}}
//|   - {"id":"large-step","label":"Δt₀ = 0.1","description":"初期刻みを大きくすると棄却が 6 回に増え、許容される刻み 0.1/64 で最後まで進む。","inputs":{"initial_step":-1}}
//|   - {"id":"half-cfl","label":"ν = 0.25","description":"Courant 数を下げると、CFL を提示した計算の刻みが小さくなり、受理の回数が増える。","inputs":{"cfl":0.25}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"runs","path":"/rows/0/1","equals":"ReachedEnd"}
//|       - {"artifact":"runs","path":"/rows/0/2","equals":367}
//|       - {"artifact":"runs","path":"/rows/0/3","equals":0}
//|       - {"artifact":"runs","path":"/rows/1/2","equals":120}
//|       - {"artifact":"runs","path":"/rows/1/3","equals":3}
//|       - {"artifact":"runs","path":"/rows/0/5","approx":{"value":0.0067097975,"rtol":1e-5}}
//|       - {"artifact":"runs","path":"/rows/0/8","approx":{"value":0.00040933879,"rtol":1e-5}}
//|   - case: forward-euler
//|     expect:
//|       - {"artifact":"runs","path":"/rows/1/3","equals":3}
//|       - {"artifact":"runs","path":"/rows/0/1","equals":"ReachedEnd"}
//|   - case: large-step
//|     expect:
//|       - {"artifact":"runs","path":"/rows/1/3","equals":6}
//|       - {"artifact":"runs","path":"/rows/1/2","equals":96}
//|   - case: half-cfl
//|     expect:
//|       - {"artifact":"runs","path":"/rows/0/3","equals":0}
use scioxide_core::{ExecutionContext, SciOxideError, RealScalar, SolveContext};
use scioxide_ode::{ForwardEuler, Heun, OdeMethod, OdeOptions, OdeOutputSchedule, OdeProblem};
use scioxide_ode::{OdeState, OdeSystem};
use scioxide_pde::{ConservationBoundary, ConservationOptions, Hllc, IdealGasEuler};
use scioxide_pde::{ConservationReconstruction, StructuredConservationPlan};
use scioxide_spatial::SegmentMesh;
use scioxide_spatial::{AxisSide, AxisTopology, BoundarySet, CellField, CoordinateAxis, Grid1d};

// rhs と admits だけを転送し、CFL の上限（step_limit など）を提示しない系。
struct WithoutCfl<'a, S>(&'a S);
impl<S: OdeSystem<f64>> OdeSystem<f64> for WithoutCfl<'_, S> {
    fn dimension(&self) -> usize {
        self.0.dimension()
    }
    fn rhs(
        &self,
        t: f64,
        y: &[f64],
        out: &mut [f64],
        cx: &mut SolveContext<'_, '_>,
    ) -> Result<(), SciOxideError> {
        self.0.rhs(t, y, out, cx)
    }
    fn admits(
        &self,
        t: f64,
        y: &[f64],
        cx: &mut SolveContext<'_, '_>,
    ) -> Result<bool, SciOxideError> {
        self.0.admits(t, y, cx)
    }
}

let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let gas = IdealGasEuler::new(1.4).map_err(|e| e.to_string())?;
let execution = ExecutionContext::sequential();
let mut rows = Vec::new();
for advertised in [true, false] {
    let axis = CoordinateAxis::uniform(0.0, 1.0, 201).map_err(|e| e.to_string())?;
    let grid = Grid1d::new([axis], [AxisTopology::Bounded]).map_err(|e| e.to_string())?;
    let mesh = SegmentMesh::new(grid).map_err(|e| e.to_string())?;
    let start = BoundarySet::axis_side(&mesh, 0, AxisSide::Start).map_err(|e| e.to_string())?;
    let finish = BoundarySet::axis_side(&mesh, 0, AxisSide::End).map_err(|e| e.to_string())?;
    let conditions = vec![
        (start, ConservationBoundary::Transmissive),
        (finish, ConservationBoundary::Transmissive),
    ];
    let options = ConservationOptions::new()
        .with_reconstruction(ConservationReconstruction::MonotonizedCentral)
        .with_cfl(cfl);
    let plan = StructuredConservationPlan::with_options(mesh, conditions, options)
        .map_err(|e| e.to_string())?;
    let values = plan
        .centers()
        .iter()
        .map(|x| gas.conserved(1.0, [if x[0] < 0.5 { -2.0 } else { 2.0 }], 0.4))
        .collect::<Result<Vec<[f64; 3]>, _>>()
        .map_err(|e| e.to_string())?;
    let field = CellField::new(plan.mesh(), values).map_err(|e| e.to_string())?;
    let mut workspace = plan.workspace().map_err(|e| e.to_string())?;
    let bound = plan
        .bind(&gas, &Hllc, &mut workspace)
        .map_err(|e| e.to_string())?;
    let hidden = WithoutCfl(&bound);
    let system: &dyn OdeSystem<f64> = if advertised { &bound } else { &hidden };
    let problem = OdeProblem::new(system, 0.15);
    let options = OdeOptions::new()
        .with_initial_step(RealScalar::powf(10.0, initial_step))
        .with_output_schedule(OdeOutputSchedule::AcceptedSteps);
    let vector = plan
        .initial_state(&gas, field.view())
        .map_err(|e| e.to_string())?;
    let mut state = OdeState::new(0.0, vector);
    // 受理した状態の密度と圧力の最小値。受理した状態はすべて許容される。
    let (mut density, mut pressure) = (f64::INFINITY, f64::INFINITY);
    let mut sink = |_: f64, y: &[f64]| {
        for u in y.as_chunks::<3>().0 {
            density = RealScalar::min(density, u[0]);
            pressure = RealScalar::min(pressure, gas.pressure::<1, 3>(u)?);
        }
        Ok(())
    };
    let solve = if method == "Heun" {
        let ode = Heun::new();
        let mut work = ode
            .workspace(&problem, &options)
            .map_err(|e| e.to_string())?;
        ode.advance(
            &problem, &options, &mut state, &mut sink, &mut work, execution,
        )
    } else {
        let ode = ForwardEuler::new();
        let mut work = ode
            .workspace(&problem, &options)
            .map_err(|e| e.to_string())?;
        ode.advance(
            &problem, &options, &mut state, &mut sink, &mut work, execution,
        )
    }
    .map_err(|e| e.to_string())?;
    let report = bound
        .report(state.time(), state.values(), execution)
        .map_err(|e| e.to_string())?;
    rows.push((
        if advertised {
            "CFL を提示内容"
        } else {
            "CFL を隠す"
        },
        solve.termination().map_or("なし".into(), |t| t.to_string()),
        solve.accepted_steps(),
        solve.rejected_steps(),
        solve.final_time(),
        density,
        pressure,
        report.hlle_fallback_faces(),
        report.maximum_step(),
    ));
}

    { "key": "0", "label": "系" },
    { "key": "1", "label": "終了理由" },
    { "key": "2", "label": "受理 [回]", "type": "integer" },
    { "key": "3", "label": "棄却 [回]", "type": "integer" },
    { "key": "4", "label": "最後の時刻 [-]", "type": "number", "format": { "significantDigits": 6 } },
    { "key": "5", "label": "最小の密度 [-]", "type": "number", "format": sci3 },
    { "key": "6", "label": "最小の圧力 [-]", "type": "number", "format": sci3 },
    { "key": "7", "label": "HLLE に切り替えた面 [個]", "type": "integer" },
    { "key": "8", "label": "最後の Δt_max [-]", "type": "number", "format": sci3, "nullText": "なし" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "runs" })
);
```

既定値（`Heun`、$\nu = 0.45$、$\Delta t_0 = 10^{-2}$）では、CFL の上限を提示した計算は 367 回の刻みを棄却なしで受理した。
最後の状態の $\Delta t_{\max}$ は $4.09 \times 10^{-4}$ で、最大信号速度は約 2.75 なので、通常の Courant 数 $s\Delta t/h$ は 0.225 である。
上限を隠した計算は、$\Delta t_0 = 10^{-2}$ の試行が 3 回棄却されて刻みが $1.25 \times 10^{-3}$ になり、その刻みのまま 120 回で終端に達した。
固定刻みの方法では、棄却で半分にした刻みが以後の刻みになる。
この刻みは Courant 数で約 0.69 にあたり、前節の理論が許す範囲を超えているが、受理した状態はすべて許容され、計算は `ReachedEnd` で終わった。

どちらの計算でも、受理した状態の最小の密度（$6.7 \times 10^{-3}$ と $7.5 \times 10^{-3}$）は厳密解の中央の密度 $\rho^* = 0.0219$ より小さい。
この差は空間の離散化の誤差で、[Sod の衝撃波管](../../examples/sod-shock-tube/)の二重膨張の計算では、セル数を増やすと密度の誤差が減る。
許容性の検査は正値性の破れを捕まえて試行をやり直すが、刻みの安定性や解の精度は保証しない。
刻みは CFL の上限に従わせ、許容性の検査は上限が局所的な見積もりであることへの備えとして使う。

## まとめ

陽的な方法の刻みは各セルで $\Delta t \sum_f |f| s_f \le \nu |K|$ を満たすように選ぶ。
`ConservationReport::maximum_step` はこの上限を残差の評価のたびに返し、`ConservationSystem` は陽的 Runge–Kutta 法に最初の残差と同時に渡すので、刻みの制御に追加の評価はいらない。
SSP 法の `ForwardEuler` と `Heun` はこの上限の下で前進 Euler 法の最大値原理と TVD の性質を保つ。
密度や圧力の正値性は `admits` で段ごとに検査され、許容されない試行は棄却されて刻みが半分になり、刻みの下限に達すれば `StepSizeLimit` の部分結果として止まる。
許容性の検査は安定性の代わりにはならないので、上限を提示する系をそのまま `OdeMethod` に渡して使う。
