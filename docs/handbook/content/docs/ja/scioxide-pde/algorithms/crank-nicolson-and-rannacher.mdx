Crank–Nicolson 法は 2 次精度で無条件安定なので、拡散方程式の時間積分によく使われる。
しかし段差のような滑らかでない初期値を与えると、格子規模の振動がなかなか消えない。
このページではその原因を増幅率から説明し、先頭の区間だけを後退 Euler 法に置き換える Rannacher 起動と、`RannacherStartup` による設定を説明する。
Fourier 数 $r=\alpha\Delta t/h^2$、θ 法の増幅率、`ParabolicProblem` の方式は[放物型方程式の時間積分](../parabolic-time-integration/)で定義した。

## 短い波長の増幅率と Rannacher 起動

Crank–Nicolson 法は A 安定な 2 次の方法で、滑らかな温度場では後退 Euler 法より時間の誤差がずっと小さい。
しかし $r$ が大きいと、最も短い波長（$\theta=\pi$）の増幅率は

$$
\lim_{r\to\infty}G_{\mathrm{CN}}(\pi)=\lim_{r\to\infty}\frac{1-2r}{1+2r}=-1
$$

に近づく。
半離散系ではすぐに減衰するはずの成分が、刻みごとに符号を反転させながらほとんど減衰せずに残る。
段差のような初期温度や急な境界温度の変化を与えると、これが格子規模の振動として現れる。

Rannacher 起動は最初の数区間（各区間の幅は $\Delta t$）だけを、刻み $\Delta t/2$ の後退 Euler 法 2 回に置き換える。
後退 Euler 法の半刻みの増幅率は $1/(1+2r\sin^2(\theta/2))$ なので、1 区間の増幅率は

$$
G_{\mathrm{R}}(\theta)=\left(\frac{1}{1+2r\sin^2(\theta/2)}\right)^2
$$

で、$\theta=\pi$ でも $r\to\infty$ で 0 に近づく。
初期の段差に含まれる短い波長の成分は、この起動区間で強く減衰する。
滑らかな解で起動区間の数を固定して刻みを細かくすると、後退 Euler 法の局所誤差 $O(\Delta t^2)$ が一定回数だけ加わるので、全体の誤差は $O(\Delta t^2)$ に保たれる。
Luskin と Rannacher（1982）は、滑らかでない初期値に対しても、起動を加えた Crank–Nicolson 法が正の時刻で 2 次の収束を回復することを示した。

`scioxide-pde` では `ParabolicOptions::with_rannacher_startup(intervals)` で起動区間の数を `Budget` で与える。
設定は `RannacherStartup::BackwardEuler { intervals }` になり、時刻 0 からの $n$ 区間 $[0,\,n\Delta t]$（$n$ は区間の数。
終端時刻がそれより前なら終端時刻まで）を後退 Euler 法の半刻みで進める。
既定は起動なしの `RannacherStartup::Disabled` である。
組み込みの `ParabolicScheme::CrankNicolson` 以外の方式や `with_ode_method` と組み合わせると、`initial_state` と `advance` の事前検査が `InvalidInput`（`UnsupportedConfiguration`）で拒む。
起動の終わりの時刻は `initial_state` がそのときの設定から状態に書き込み、`PdeState::startup_end` で読める。
途中で止めた積分を同じ状態で再開しても、起動の残りは保たれる。
`advance` と `resume` の事前検査は、状態の起動の終わりが、渡した設定から決まる値と一致するかを確かめる。
状態の時刻が $n\Delta t$ より前ならその設定の起動の終わり $n\Delta t$、それ以後なら「なし」が正しい値である。
そのため、起動なしで作った状態を起動区間の中で起動付きの設定に渡すと、事前検査が `InvalidInput`（`Inconsistent`）で拒み、状態は変わらない。
起動付きで作った状態を起動区間の中で起動なしの設定に渡したときも同じである。
起動区間を過ぎた状態は、どちらの設定でも進められる。

## モードごとの増幅率の実測

8 つの時間区間を進めた後のモードの増幅率を、波数 $\theta\in[0,\pi]$ について後退 Euler 法、Crank–Nicolson 法、Rannacher 起動付きの Crank–Nicolson 法で比べる。
入力は Fourier 数 $r$ と起動区間の数である。

セルは区間 $[0,1]$、$\alpha=1$、両端 Dirichlet の 17 点の格子（$h=1/16$）を `StructuredFdmPlan::dirichlet_laplacian` で作り、刻み $\Delta t=rh^2$ の固定刻みで 8 区間進める。
初期値に正弦モード $\sin(j\pi x)$（$j=1,\dots,15$、$\theta=j\pi/16$）を与え、終端の場を初期のモードへ射影して増幅率を読む。
三つの方式はそれぞれ `workspace` で作業領域を一度だけ作り、15 個のモードの `initial_state` と `advance` で使い回す。
図の破線は増幅率の閉形式（点線は半離散系の厳密な減衰）、点は `ParabolicProblem` で解いた値である。
表は $\theta=\pi$ の 1 区間と 8 区間の閉形式、格子で表せる最も短い $\theta=15\pi/16$ の閉形式と実測、および最初のモードを解いたときの因子分解の回数を並べる。
同じ現象を段差の初期値で解いた結果は[棒の熱拡散の例](../../examples/heat-crank-nicolson/)にある。
因子分解の回数がどう決まるかは[陰的段の線形系と因子分解](oxref:pde-implicit-stage-linear-systems)で説明する。

```rust
//| inputs:
//|   fourier_number: {"type":"range","label":"Fourier 数 r = αΔt/h² [-]","description":"1 区間の拡散の強さを変える。","min":0.05,"max":5,"step":0.05,"value":1.5}
//|   rannacher_intervals: {"type":"range","label":"Rannacher 起動の区間数 [-]","description":"先頭で後退 Euler 法の半刻み 2 回に置き換える区間の数を変える。","min":0,"max":4,"step":1,"value":1}
//| cases:
//|   - {"id":"mild-diffusion","label":"弱い拡散 r = 0.05","description":"θ = 15π/16 の 8 区間後の増幅率はどの方式でも正の 0.20〜0.24 で、符号は反転しない。","inputs":{"fourier_number":0.05}}
//|   - {"id":"stiff-step","label":"硬い刻み r = 5","description":"θ = π の 1 区間の CN 増幅率は −0.82 で、8 区間後も 0.20 が残る。起動 1 区間で −2.0×10⁻³ まで下がる。","inputs":{"fourier_number":5}}
//|   - {"id":"long-startup","label":"起動 4 区間","description":"r = 1.5 で起動を 4 区間にすると、θ = π の 8 区間後の増幅率は 9.5×10⁻⁷ まで下がる。","inputs":{"rannacher_intervals":4}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"damping","path":"/rows/1/2","approx":{"value":1.7346653e-7,"rtol":1e-6}}
//|       - {"artifact":"damping","path":"/rows/2/2","approx":{"value":0.00390625,"rtol":1e-12}}
//|       - {"artifact":"damping","path":"/rows/3/2","approx":{"value":-0.00048828125,"rtol":1e-12}}
//|       - {"artifact":"damping","path":"/rows/1/4","approx":{"value":1.8532971e-7,"rtol":1e-6}}
//|       - {"artifact":"damping","path":"/rows/2/4","approx":{"value":0.0036851218,"rtol":1e-6}}
//|       - {"artifact":"damping","path":"/rows/3/4","approx":{"value":-4.7076772e-4,"rtol":1e-6}}
//|       - {"artifact":"damping","path":"/rows/1/5","range":{"min":0,"max":1e-15}}
//|       - {"artifact":"damping","path":"/rows/2/5","range":{"min":0,"max":1e-15}}
//|       - {"artifact":"damping","path":"/rows/3/5","range":{"min":0,"max":1e-15}}
//|       - {"artifact":"damping","path":"/rows/0/4","equals":null}
//|   - case: mild-diffusion
//|     expect:
//|       - {"artifact":"damping","path":"/rows/1/4","approx":{"value":0.23556877,"rtol":1e-6}}
//|       - {"artifact":"damping","path":"/rows/2/4","approx":{"value":0.20395824,"rtol":1e-6}}
//|       - {"artifact":"damping","path":"/rows/3/4","approx":{"value":0.20597864,"rtol":1e-6}}
//|       - {"artifact":"damping","path":"/rows/3/5","range":{"min":0,"max":1e-14}}
//|   - case: stiff-step
//|     expect:
//|       - {"artifact":"damping","path":"/rows/2/1","approx":{"value":-0.81818182,"rtol":1e-7}}
//|       - {"artifact":"damping","path":"/rows/2/2","approx":{"value":0.20081613,"rtol":1e-6}}
//|       - {"artifact":"damping","path":"/rows/2/4","approx":{"value":0.19769205,"rtol":1e-6}}
//|       - {"artifact":"damping","path":"/rows/3/4","approx":{"value":-0.0020362201,"rtol":1e-6}}
//|       - {"artifact":"damping","path":"/rows/2/5","range":{"min":0,"max":1e-14}}
//|   - case: long-startup
//|     expect:
//|       - {"artifact":"damping","path":"/rows/3/2","approx":{"value":9.5367432e-7,"rtol":1e-6}}
//|       - {"artifact":"damping","path":"/rows/3/4","approx":{"value":9.8145674e-7,"rtol":1e-6}}
//|       - {"artifact":"damping","path":"/rows/3/5","range":{"min":0,"max":1e-17}}
use scioxide_core::{Budget, ExecutionContext, RealScalar};
use scioxide_pde::{
    FieldData, FieldPoint, ParabolicOptions, ParabolicProblem, ParabolicScheme,
    StructuredFdmPlan,
};

let r = fourier_number;
let startup = rannacher_intervals.round() as usize;
let intervals = 8_i32;
let pi = core::f64::consts::PI;
// 閉形式（独立な検算）。s = sin²(θ/2)。各方式の (1 区間, 8 区間後) の増幅率を返す。
let closed_form = |theta: f64| {
    let s = RealScalar::powi(RealScalar::sin(theta / 2.0), 2);
    let exact = RealScalar::exp(-4.0 * r * s);
    let euler = 1.0 / (1.0 + 4.0 * r * s);
    let cn = (1.0 - 2.0 * r * s) / (1.0 + 2.0 * r * s);
    let half_pair = RealScalar::powi(1.0 / (1.0 + 2.0 * r * s), 2);
    let with_startup = RealScalar::powi(half_pair, startup as i32)
        * RealScalar::powi(cn, intervals - startup as i32);
    [
        (exact, RealScalar::powi(exact, intervals)),
        (euler, RealScalar::powi(euler, intervals)),
        (cn, RealScalar::powi(cn, intervals)),
        (if startup > 0 { half_pair } else { cn }, with_startup),
    ]
};
let names = [
    "半離散の厳密な減衰",
    "後退 Euler",
    "Crank–Nicolson",
    "Rannacher 起動 + CN",
];
let cells = 16_usize;
let h = 1.0 / cells as f64;
let dt = r * h * h;
let plan = StructuredFdmPlan::dirichlet_laplacian([0.0], [1.0], [cells + 1])
    .map_err(|e| e.to_string())?;
let source = FieldData::zero();
let problem =
    ParabolicProblem::new(&plan, &source, intervals as f64 * dt).map_err(|e| e.to_string())?;
// 各方式で 15 個の正弦モードを 8 区間進め、初期のモードへの射影から増幅率を読む。
let measure =
    |scheme: ParabolicScheme, startup: usize| -> Result<(Vec<[f64; 2]>, usize), String> {
        let mut options = ParabolicOptions::new().with_step(dt).with_scheme(scheme);
        if startup > 0 {
            options = options
                .with_rannacher_startup(Budget::try_from(startup).map_err(|e| e.to_string())?);
        }
        let mut workspace = problem.workspace().map_err(|e| e.to_string())?;
        let mut measured = Vec::new();
        let mut factorizations = 0;
        for mode in 1..cells {
            let k = mode as f64 * pi;
            let initial = FieldData::time_invariant(move |p: FieldPoint<f64, 1>| {
                Ok(RealScalar::sin(k * p.point[0]))
            });
            let mut state = problem
                .initial_state(&initial, &options)
                .map_err(|e| e.to_string())?;
            let start = state.coordinates().to_vec();
            let report = problem
                .advance(
                    &options,
                    &mut state,
                    &mut (),
                    &mut workspace,
                    ExecutionContext::sequential(),
                )
                .map_err(|e| e.to_string())?;
            if !report.is_success() {
                return Err(format!("{}: {}", scheme.name(), report.termination()));
            }
            if mode == 1 {
                factorizations = report.diagnostics().num_factorizations();
            }
            let dot = |a: &[f64], b: &[f64]| a.iter().zip(b).map(|(x, y)| x * y).sum::<f64>();
            measured.push([
                mode as f64 * h,
                dot(state.coordinates(), &start) / dot(&start, &start),
            ]);
        }
        Ok((measured, factorizations))
    };
let runs = [
    measure(ParabolicScheme::BackwardEuler, 0)?,
    measure(ParabolicScheme::CrankNicolson, 0)?,
    measure(ParabolicScheme::CrankNicolson, startup)?,
];
let mut layers = Vec::new();
let mut rows = Vec::new();
let shortest = pi * (cells - 1) as f64 * h;
for (method, name) in names.iter().enumerate() {
    let curve = (0..=200)
        .map(|i| {
            let theta = pi * i as f64 / 200.0;
            [theta / pi, closed_form(theta)[method].1]
        })
        .collect::<Vec<_>>();
    let style = if method == 0 { "dotted" } else { "dashed" };
    layers.push(serde_json::json!({
        "id": format!("closed-{method}"),
        "kind": "line",
        "name": format!("{name}（閉形式）"),
        "points": curve,
        "style": { "lineType": style }
    }));
    let predicted = closed_form(shortest)[method].1;
    let run = method.checked_sub(1).map(|m| &runs[m]);
    let highest = run.map(|(measured, _)| measured[cells - 2][1]);
    rows.push((
        *name,
        closed_form(pi)[method].0,
        closed_form(pi)[method].1,
        predicted,
        highest,
        highest.map(|value| (value - predicted).abs()),
        run.map(|(_, factorizations)| *factorizations),
    ));
    if let Some((measured, _)) = run {
        layers.push(serde_json::json!({
            "id": format!("measured-{method}"),
            "kind": "scatter",
            "name": format!("{name}（ParabolicProblem）"),
            "points": measured
        }));
    }
}
// 0 より下は、短い波長の成分が符号を反転させながら残ることを示す。
emit_chart!(serde_json::json!({
    "kind": "xy",
    "xLabel": "正規化した波数 θ/π [-]",
    "yLabel": "8 区間後の符号付き増幅率 [-]",
    "dataZoom": true,
    "tooltip": true,
    "annotations": [{ "kind": "line", "axis": "y", "value": 0.0 }],
    "layers": layers
}));
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let sci5 = serde_json::json!({ "notation": "scientific", "significantDigits": 5 });
let columns = serde_json::json!([
    { "key": "0", "label": "方式" },
    { "key": "1", "label": "θ = π の 1 区間（閉形式）[-]", "type": "number", "format": sci5 },
    { "key": "2", "label": "θ = π の 8 区間後（閉形式）[-]", "type": "number", "format": sci5 },
    { "key": "3", "label": "θ = 15π/16 の 8 区間後（閉形式）[-]", "type": "number", "format": sci5 },
    { "key": "4", "label": "θ = 15π/16 の 8 区間後（実測）[-]", "type": "number", "format": sci5, "nullText": "解かない" },
    { "key": "5", "label": "実測と閉形式の差 [-]", "type": "number", "format": sci3, "nullText": "—" },
    { "key": "6", "label": "因子分解 [回]", "type": "integer", "nullText": "—" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "damping" })
);
```

既定の $r=1.5$、起動 1 区間では、$\theta=15\pi/16$ の実測と閉形式の差は後退 Euler 法で $1.6\times10^{-22}$、Crank–Nicolson 法で $2.2\times10^{-18}$、Rannacher 起動で $2.7\times10^{-19}$ だった。
`ParabolicProblem` の三つの方式は閉形式の増幅率を丸め誤差の水準で再現する。
$\theta=\pi$ の 1 区間の Crank–Nicolson 法の増幅率は $-0.5$ で、8 区間後にも $(-0.5)^8=3.9\times10^{-3}$ が残る。
起動 1 区間では $(1/16)\cdot(-0.5)^7=-4.9\times10^{-4}$、起動 4 区間では $9.5\times10^{-7}$ まで下がる。
後退 Euler 法は $1.7\times10^{-7}$ で、半離散の厳密な減衰 $1.4\times10^{-21}$ にはどの方式も遠い。
$r=0.05$ ではどの方式の増幅率も正で、$\theta=15\pi/16$ の 8 区間後の値は 0.20〜0.24 にそろい、符号は反転しない。

## まとめ

Crank–Nicolson 法は A 安定だが L 安定ではなく、Fourier 数 $r$ が大きいと最も短い波長の増幅率が $-1$ に近づくので、段差の初期値から生じた格子規模の振動が符号を反転させながら残る。
Rannacher 起動は先頭の数区間を後退 Euler 法の半刻み 2 回に置き換え、その区間の増幅率を 0 に近づけて振動を抑える。
起動区間の数を固定すれば、滑らかな解での 2 次の収束は保たれる。
`scioxide-pde` では `ParabolicOptions::with_rannacher_startup` で区間の数を与え、組み込みの `CrankNicolson` とだけ組み合わせられる。
起動の残りは状態が持ち、起動区間の中で設定と合わない状態は事前検査で拒まれるので、初期状態は進めるときと同じ設定で作る。
