弾性体は力を取り去ると元の形に戻る固体で、機械部品、建物、地盤、ゴム製品の変形と応力の計算に使われる。
このページでは変位を未知数とする線形弾性の境界値問題を導き、有限要素法（FEM）で離散化する方法と、非圧縮に近い材料で起こる体積ロッキング、それを避ける混合形を説明する。
大きな変形を扱う neo-Hooke 超弾性は[超弾性と整合接線](../hyperelasticity/)で扱う。
Plan は単体メッシュ（区間・三角形・四面体）の上の有限要素で、メッシュ、境界条件、求積の設定は[単体メッシュの有限要素](../simplex-finite-elements/)と共通である。

## ひずみ、応力と Hooke 則

物体の各点 $x$ の変位を $u(x)$ とする。
変位の勾配が小さいとき、変形の大きさは小ひずみテンソル

```text
ε(u) = (∇u + ∇uᵀ) / 2,   ε_ij = (∂u_i/∂x_j + ∂u_j/∂x_i) / 2
```

で測る。
剛体の並進と微小回転では $\varepsilon=0$ になる。
内部の力は Cauchy 応力テンソル $\sigma$ で表し、面の単位法線 $n$ の側に働く牽引力（単位面積あたりの力）は $t=\sigma n$ である。
物体力 $f$（単位体積あたりの力）の下での静的な釣り合いは

```text
−∇·σ = f   （Ω の中）
```

である。

等方な線形弾性体では、応力とひずみの関係（Hooke 則）が二つの定数で決まる。

```text
σ = 2μ ε + λ (tr ε) I = 2μ dev ε + K (tr ε) I,   dev ε = ε − (tr ε) I / 3
```

$\mu$ はせん断弾性率、$\lambda$ は Lamé の第 1 定数、$K=\lambda+2\mu/3$ は体積弾性率で、$\operatorname{tr}\varepsilon=\nabla\cdot u$ は体積変化の割合である。
平均応力 $p=\operatorname{tr}\sigma/3=K\operatorname{tr}\varepsilon$ は、引張を正とする圧力にあたる。
Young 率 $E$ と Poisson 比 $\nu$ からは $\mu=E/(2(1+\nu))$、$K=E/(3(1-2\nu))$ で換算する。
0 でない全てのひずみでひずみエネルギーが正になるのは、$\mu>0$、$K>0$、すなわち $E>0$、$-1<\nu<1/2$ のときである。

`IsotropicElasticMaterial` は、この二つの弾性率を保持する材料である。
`new(shear, bulk)` は正で有限な $\mu$、$K$ と、表現できる正の $1/K$ を要求し、`from_young_poisson(young, poisson)` は $E>0$、$-1<\nu<1/2$ を検査して換算する。
条件を満たさない値は `InvalidInput` で拒否する。
$\nu=1/2$ の完全な非圧縮は $K=\infty$ にあたり、この材料では表せない。

## 平面ひずみと平面応力

2 次元のメッシュで解くときは、厚さ方向 $z$ の状態を仮定して 3 次元の Hooke 則を縮約する。
`ElasticityKinematics` がこの選択で、2 次元のメッシュには `PlaneStrain` か `PlaneStress`、3 次元のメッシュには `ThreeDimensional` だけを受け付ける。
組み合わせが合わないと、Plan の準備が `InvalidInput` を返す。

厚さ方向に長く、断面が同じ形の物体（ダム、トンネル、長い梁の断面）では、厚さ方向のひずみを 0 とみなす。
これが平面ひずみ（`PlaneStrain`）で、$\varepsilon_{zz}=0$ から面外の応力 $\sigma_{zz}=\lambda(\varepsilon_{xx}+\varepsilon_{yy})$ が生じる。

薄い板では面外の応力を 0 とみなす。
これが平面応力（`PlaneStress`）で、$\sigma_{zz}=0$ から面外のひずみが

```text
ε_zz = −λ (ε_xx + ε_yy) / (λ + 2μ)
```

に決まる。
これを面内の式に代入すると、Lamé 定数を $\lambda^*=2\mu\lambda/(\lambda+2\mu)$ に置き換えた面内の Hooke 則になる。
Plan は $\varepsilon_{zz}$ の成分を 3 次元の接線行列から静的縮約（その成分の方程式を解いて消去する操作）で消し、同じ結果を得る。
平面ひずみは $\nu\to1/2$ で体積の拘束を強く受ける。
平面応力では面外に縮めるので、$\lambda\to\infty$ でも $\lambda^*$ は $2\mu$ を超えず、体積の拘束は強くならない。

## 弱形式と全ポテンシャルエネルギー

境界を、変位 $u=g$ を与える部分 $\Gamma_D$ と、牽引力 $\sigma n=t$ を与える部分 $\Gamma_N$ に分ける。
釣り合い式に試験関数 $v$（$\Gamma_D$ で 0）を掛けて部分積分すると、弱形式

```text
a(u, v) = ℓ(v)   （Γ_D で 0 の全ての v について）
a(u, v) = ∫_Ω σ(u) : ε(v) dx,   ℓ(v) = ∫_Ω f·v dx + ∫_{Γ_N} t·v ds
```

を得る。
$a$ は対称で、$\Gamma_D$ が剛体の動きを止めていれば正定値である（Korn の不等式）。
このとき弱形式の解は全ポテンシャルエネルギー $\Pi(u)=a(u,u)/2-\ell(u)$ を最小にする変位と一致する。

変位の各成分を P1 か P2 の連続な区分多項式で近似すると、弱形式は連立一次方程式 $Au=F$ になる。
剛性行列 $A$ の要素は Hooke 則の弾性テンソル $C$（$\sigma=C:\varepsilon$）を使ってセルごとに $\int\varepsilon(\phi_i):C:\varepsilon(\phi_j)\,dx$ を求積し、足し合わせる。
Plan はこの体積積分を、アフィン幾何では変位の次数の 2 倍以上、2 次の幾何では 7 次以上の多項式を厳密に積分する求積で行う。
既定の求積規則は重みが正で節点が単体の内部にあり、`SimplexFemOptions` で明示する規則にもこの次数以上の多項式を厳密に積分することを要求する。
$\Gamma_D$ の自由度は対称に消去するので、組み立てた行列は対称のまま保たれる。

境界条件は 2 成分または 3 成分の `TaggedBoundaries` で与え、外部面と成分の組ごとに条件がちょうど一つになるようにする。
`BoundaryCondition::dirichlet` は変位の成分 $u_a$ を、`BoundaryCondition::natural` は牽引力の成分 $t_a=\sigma_{ab}n_b$ を与える。
時間に依存するデータと Robin 条件は拒否する。
複数の面が共有する節点の Dirichlet 値の衝突は、`DirichletConflictPolicy`（既定は拒否）で扱う。

## Plan と未知数の並び

`LinearElasticityPlan` は等方 Hooke 則の Plan である。
弾性率は実数で、変位と荷重の型 `V` には実数か複素数（振幅）を選べる。
`new(mesh, geometry, material, &boundaries, body, options)` は逐次に、`build(…, scope)` は呼び出し側のスコープの一つのエポックとして準備し、失敗したときは Plan を返さない。
準備では全てのセルの要素行列と、物体力 `body` と牽引力の荷重を求めて保持する。

`ElasticityOptions::new(kinematics, formulation)` は縮約と要素を明示して選ぶ設定である。
`with_fem` で単体メッシュの共通設定（`SimplexFemOptions` の求積、幾何の条件、実行、リソースの上限）を、`with_plane_stress` で neo-Hooke の平面応力の局所求解の設定（[超弾性と整合接線](../hyperelasticity/)）を置き換える。
`ElasticityFormulation` は `Displacement(order)`（P1 か P2 の変位だけ）か `MixedP2P1`（P2 の変位と頂点の P1 圧力）で、変位の次数も決めるので、別に渡す FEM の次数と食い違うことはない。
2 次の幾何（`SimplexFemGeometry::Quadratic`）は P2 の変位と組み合わせたときだけ受け付ける。

未知数は変位の成分ごとのブロック（各ブロックは `displacement_nodes` 個の節点）を並べ、混合形ではその後に頂点の圧力を置く。
`node_point(node)` が変位の節点の物理座標を返す。
`fields(x)` は未知数のベクトルを `ElasticityField` に分ける。
`ElasticityField` は成分ごとの変位の場（`displacement`）と、混合形のときだけ `Some` になる頂点の圧力（`pressure`）を所有する。
逆向きの `pack_fields_into(view, out)` は、`ElasticityFieldView::new(displacement, pressure)` で借用した同じメッシュの revision の場を未知数のベクトルに詰め、失敗したときは `out` を変えない。

組み立ては `assemble_csr` が対称な消去後の CSR 行列を、`rhs` が消去で持ち上げた右辺を返す。
Dirichlet の行は単位行列の行になり、右辺には与えた値が入るので、$Ax=b$ の解 $x$ は Dirichlet の値も含む全体の未知数である。
同じ構造で何度も組み立て直すときは、`assembly_workspace` の作業領域で `assemble_csr_into` を使えば確保をしない。
Plan 自体も `LinearOperator`（`apply_into`）と `AdjointOperator` を実装するので、行列を作らずに Krylov 法に渡せる。
Plan は求解の手順を持たないので、支持が剛体の動きを止めている変位形の正定値の系は共役勾配法か疎 Cholesky 分解で、混合形の対称で不定値の系は MINRES 法か疎 LU 分解で解く。

次のブロックは、このページのセルが共有する長方形の板のメッシュと辺のタグである。

```rust
//| id: pde-elasticity-plate
//| kind: definitions
//| title: 長方形の板の三角形メッシュと辺のタグ
//| crates: [scioxide-core, scioxide-pde, scioxide-spatial]
use scioxide_core::SciOxideError;
use scioxide_pde::{BoundaryCondition, TaggedBoundaries};
use scioxide_spatial::{Point, SimplexBoundaryTags, TriangleMesh};

/// 長方形 [0, a] × [0, b] を nx × ny の長方形に分け、各長方形を 2 つの三角形にする。
/// 頂点の番号は j (nx + 1) + i。
pub(crate) fn plate_mesh(
    a: f64,
    b: f64,
    nx: usize,
    ny: usize,
) -> Result<TriangleMesh<f64>, SciOxideError> {
    let mut points = Vec::new();
    for j in 0..=ny {
        for i in 0..=nx {
            points.push(Point::new([
                a * i as f64 / nx as f64,
                b * j as f64 / ny as f64,
            ])?);
        }
    }
    let mut cells = Vec::new();
    for j in 0..ny {
        for i in 0..nx {
            let v = j * (nx + 1) + i;
            cells.push([v, v + 1, v + nx + 2]);
            cells.push([v, v + nx + 2, v + nx + 1]);
        }
    }
    TriangleMesh::new(points, cells)
}

/// 外部面のタグは左辺 x = 0 が 1、右辺 x = a が 2、下辺 y = 0 が 3、上辺 y = b が 4。
pub(crate) fn plate_boundaries(
    mesh: &TriangleMesh<f64>,
    a: f64,
    b: f64,
    conditions: Vec<BoundaryCondition<f64, f64, 2, u32>>,
) -> Result<TaggedBoundaries<f64, f64, 2>, SciOxideError> {
    let mut faces = Vec::new();
    for face in mesh.boundary_faces() {
        let v = mesh.face_vertices(face)?;
        let [x0, y0] = *mesh.points()[v[0]].as_array();
        let [x1, y1] = *mesh.points()[v[1]].as_array();
        let (x, y) = (0.5 * (x0 + x1), 0.5 * (y0 + y1));
        let tag = if x < 1e-9 * a {
            1
        } else if x > (1.0 - 1e-9) * a {
            2
        } else if y < 1e-9 * b {
            3
        } else {
            4
        };
        faces.push((face, tag));
    }
    let tags = SimplexBoundaryTags::new(mesh, faces)?;
    TaggedBoundaries::new(mesh, &tags, 2, conditions)
}
```

## 一軸引張の解析解との照合

長さ $a=200$ mm、幅 $b=100$ mm の鋼板（$E=200$ GPa）の右辺を 100 MPa で引っ張る。
左辺は $u_x=0$、下辺は $u_y=0$ のローラーで支え、他の辺は力を加えない。
応力は板全体で $\sigma_{xx}=100$ MPa、$\sigma_{xy}=\sigma_{yy}=0$ の一様な状態になり、平面応力では

```text
ε_xx = σ/E,   ε_yy = ε_zz = −νσ/E,   σ_zz = 0
```

平面ひずみでは

```text
ε_xx = (1 − ν²) σ/E,   ε_yy = −ν(1 + ν) σ/E,   ε_zz = 0,   σ_zz = νσ
```

である。
変位はどちらも座標の一次式なので、P1 要素でも厳密に表せる。
任意のメッシュで一次の変位を厳密に再現できることを確かめる検査を、パッチ試験と呼ぶ。
内部エネルギーは $U=\sigma\varepsilon_{xx}ab/2$（厚さ 1 mm あたり）で、牽引力の仕事は $W_\mathrm{ext}=2U$ になる。

次のセルは縮約、要素、Poisson 比を選んで板を解き、右上の角の変位、セル 0 の重心の応力とひずみ、エネルギーを解析解と比べる。
行列は `scioxide-sparse` の疎 LU 分解で解く。

```rust
//| id: pde-elasticity-uniaxial-tension
//| ref: pde-elasticity-uniaxial-tension
//| title: 一軸引張の板を解き、変位・応力・エネルギーを解析解と比べる
//| run: reactive
//| uses: [pde-elasticity-plate]
//| crates: [scioxide-core, scioxide-pde, scioxide-sparse, scioxide-spatial]
//| inputs:
//|   tension_kinematics: {"type":"select","label":"二次元の縮約","description":"面外の応力を 0 にするか、面外のひずみを 0 にするかを選ぶ。","options":[{"label":"平面応力","value":"stress"},{"label":"平面ひずみ","value":"strain"}],"value":"stress"}
//|   tension_formulation: {"type":"select","label":"要素","description":"変位の次数と混合形を選ぶ。","options":[{"label":"P1 変位","value":"p1"},{"label":"P2 変位","value":"p2"},{"label":"混合 P2/P1","value":"mixed"}],"value":"p1"}
//|   tension_poisson: {"type":"range","label":"Poisson 比 ν [-]","description":"横方向の縮みと面外の応力を変える。","min":0.0,"max":0.49,"step":0.01,"value":0.3}
//| cases:
//|   - {"id":"plane-strain","label":"平面ひずみ","description":"σ_zz = νσ = 30 MPa が生じ、u_x は (1 − ν²) 倍の 0.091 mm になる。","inputs":{"tension_kinematics":"strain"}}
//|   - {"id":"mixed-near-incompressible","label":"混合 P2/P1、ν = 0.49","description":"混合形でも解析解を丸め誤差の範囲で再現する。","inputs":{"tension_formulation":"mixed","tension_poisson":0.49}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"tension","path":"/rows/0/1","approx":{"value":0.1,"rtol":1e-12}}
//|       - {"artifact":"tension","path":"/rows/1/1","approx":{"value":-0.015,"rtol":1e-12}}
//|       - {"artifact":"tension","path":"/rows/5/1","approx":{"value":-1.5e-4,"rtol":1e-12}}
//|       - {"artifact":"tension","path":"/rows/8/1","approx":{"value":1000,"rtol":1e-12}}
//|   - case: plane-strain
//|     expect:
//|       - {"artifact":"tension","path":"/rows/0/1","approx":{"value":0.091,"rtol":1e-12}}
//|       - {"artifact":"tension","path":"/rows/4/1","approx":{"value":30,"rtol":1e-12}}
//|       - {"artifact":"tension","path":"/rows/6/1","approx":{"value":43.333333,"rtol":1e-7}}
//|   - case: mixed-near-incompressible
//|     expect:
//|       - {"artifact":"tension","path":"/rows/1/1","approx":{"value":-0.0245,"rtol":1e-10}}
//|       - {"artifact":"tension","path":"/rows/6/1","approx":{"value":33.333333,"rtol":1e-7}}
use scioxide_pde::{
    BoundaryCondition, BoundaryData, ElasticityFormulation, ElasticityKinematics,
    ElasticityOptions, IsotropicElasticMaterial, LinearElasticityPlan, SimplexFemGeometry,
    SimplexFemOrder,
};

// 鋼の板 200 mm × 100 mm（厚さ 1 mm あたり）、E = 200 GPa、右辺に 100 MPa の引張。
let (a, b, young, load) = (200.0, 100.0, 200_000.0, 100.0);
let nu = tension_poisson;
let (nx, ny) = (4, 2);
let mesh = plate_mesh(a, b, nx, ny).map_err(|e| e.to_string())?;
// 左辺は u_x = 0、下辺は u_y = 0 のローラー。他の成分と上辺は牽引力 0。
let conditions = vec![
    BoundaryCondition::dirichlet(1, BoundaryData::zero()).for_component(0),
    BoundaryCondition::natural(1, BoundaryData::zero()).for_component(1),
    BoundaryCondition::natural(2, BoundaryData::constant(load)).for_component(0),
    BoundaryCondition::natural(2, BoundaryData::zero()).for_component(1),
    BoundaryCondition::natural(3, BoundaryData::zero()).for_component(0),
    BoundaryCondition::dirichlet(3, BoundaryData::zero()).for_component(1),
    BoundaryCondition::natural(4, BoundaryData::zero()),
];
let boundaries = plate_boundaries(&mesh, a, b, conditions).map_err(|e| e.to_string())?;
let plane_strain = tension_kinematics == "strain";
let kinematics = if plane_strain {
    ElasticityKinematics::PlaneStrain
} else {
    ElasticityKinematics::PlaneStress
};
let formulation = match tension_formulation.as_str() {
    "p1" => ElasticityFormulation::Displacement(SimplexFemOrder::P1),
    "p2" => ElasticityFormulation::Displacement(SimplexFemOrder::P2),
    _ => ElasticityFormulation::MixedP2P1,
};
let material =
    IsotropicElasticMaterial::from_young_poisson(young, nu).map_err(|e| e.to_string())?;
let plan = LinearElasticityPlan::new(
    mesh,
    SimplexFemGeometry::Affine,
    material,
    &boundaries,
    &|_| Ok([0.0; 2]),
    ElasticityOptions::new(kinematics, formulation),
)
.map_err(|e| e.to_string())?;
let csr = plan.assemble_csr().map_err(|e| e.to_string())?;
let x = scioxide_sparse::solve(&csr, plan.rhs()).map_err(|e| e.to_string())?;
// 右上の角 (a, b) の変位と、セル 0 の重心の応力。
let corner = ny * (nx + 1) + nx;
let field = plan.fields(&x).map_err(|e| e.to_string())?;
let ux = field.displacement().vertices()[0].values()[corner];
let uy = field.displacement().vertices()[1].values()[corner];
let s = plan
    .stress(0, [1.0 / 3.0; 2], &x)
    .map_err(|e| e.to_string())?;
let energy = plan.energy(&x).map_err(|e| e.to_string())?;
// 解析解（参照値）。平面応力は σ_zz = 0、平面ひずみは ε_zz = 0。
let (exx, eyy, ezz, szz) = if plane_strain {
    (
        (1.0 - nu * nu) * load / young,
        -nu * (1.0 + nu) * load / young,
        0.0,
        nu * load,
    )
} else {
    (load / young, -nu * load / young, -nu * load / young, 0.0)
};
let internal = 0.5 * load * exx * a * b;
let rows = vec![
    ("u_x(a, b) [mm]", ux, exx * a),
    ("u_y(a, b) [mm]", uy, eyy * b),
    ("σ_xx [MPa]", s.cauchy()[0][0], load),
    ("σ_yy [MPa]", s.cauchy()[1][1], 0.0),
    ("σ_zz [MPa]", s.cauchy()[2][2], szz),
    ("ε_zz [-]", s.kinematic_tensor()[2][2], ezz),
    ("平均応力 p [MPa]", s.pressure(), (load + szz) / 3.0),
    ("内部エネルギー U [N·mm/mm]", energy.internal(), internal),
    (
        "外力の仕事 W_ext [N·mm/mm]",
        energy.external_work(),
        2.0 * internal,
    ),
    (
        "ポテンシャル U − W_ext [N·mm/mm]",
        energy.potential(),
        -internal,
    ),
];
let sig6 = serde_json::json!({ "significantDigits": 6 });
emit_table_with_columns!(
    serde_json::json!([
        { "key": "0", "label": "量 [単位]" },
        { "key": "1", "label": "有限要素", "type": "number", "format": sig6 },
        { "key": "2", "label": "解析解", "type": "number", "format": sig6 }
    ]),
    rows,
    metadata = serde_json::json!({ "id": "tension" })
);
```

既定の平面応力と P1 変位では、$u_x(a,b)=0.1$ mm、$u_y(a,b)=-0.015$ mm、$\varepsilon_{zz}=-1.5\times10^{-4}$ が解析解と丸め誤差の範囲で一致する。
平面ひずみに切り替えると $\sigma_{zz}=30$ MPa が生じ、$u_x$ は $(1-\nu^2)$ 倍の 0.091 mm になる。
平均応力も $(\sigma+\sigma_{zz})/3=43.33$ MPa に変わる。
エネルギーの行では $W_\mathrm{ext}=2U$ と、ポテンシャル $U-W_\mathrm{ext}=-U$ が成り立つ。
どの要素でも一様な応力を再現するので、この問題では要素の違いは表に現れない。
要素の違いは、応力が場所によって変わる曲げの問題（[片持ち梁のたわみとロッキング](../../examples/cantilever-beam/)）で現れる。

## エネルギーと応力の出力

`energy(x)` は `ElasticityEnergy` を返す。
`internal` は要素行列による $x^{\mathsf H}Ax/2$（消去する前の行列なので、Dirichlet の値も含む）、`external_work` は消去する前の荷重 $F$ との積 $\operatorname{Re}(x^{\mathsf H}F)$、`potential` はその差 $U-W_\mathrm{ext}$ である。
混合形の `internal` は次の節の鞍点の汎関数の値で、正とは限らない。
これらは与えた状態の値で、収束や空間誤差の証明ではない。

`stress(cell, point, x)` は、セルと参照座標の点を指定して `ElasticityStress` を返す。
参照座標は参照単体の上の座標で、三角形では $(1/3,1/3)$ が重心になる。
`kinematic_tensor` は Hooke 則では対称な小ひずみ、neo-Hooke では変形勾配 $F$ で、`cauchy` は Cauchy 応力、`first_piola` は第 1 Piola–Kirchhoff 応力（Hooke 則では Cauchy 応力と同じ）である。
テンソルは常に 3×3 で、平面応力では縮約で求めた $\varepsilon_{zz}$、平面ひずみでは $\sigma_{zz}$ も入る。
`pressure` は混合形では補間した圧力の未知数、変位形では構成則の平均応力（Hooke 則で $K\operatorname{tr}\varepsilon$、neo-Hooke で $K(J-1)$）である。
P1 の変位では応力がセル内で一定、P2 では一次なので、応力は求積点や重心で読むのが自然である。

## 剛体モードと支持

$\Gamma_D$ が剛体の動き（2 次元で並進 2 つと回転 1 つ、3 次元で並進 3 つと回転 3 つ）を止めていないと、剛性行列は特異になる。
止まっていない剛体の動きが剛体モードで、行列の零空間を張る。
零空間があるとき、方程式が解を持つのは荷重が全ての剛体モードと直交する（$F^{\mathsf T}m=0$、力と力のモーメントが釣り合う）ときだけで、解は剛体モードの分だけ一意でない（[適合条件・ゲージ・保存的流束](../compatibility-gauges-and-fluxes/)）。

`rigid_modes(tolerance, max_modes)` は、メッシュの連結成分ごとに並進と回転の場を作り、Dirichlet で固定した自由度の上でのグラム行列の特異値が `tolerance` 以下の組み合わせを、支持と両立する剛体モードとして返す。
返す `ElasticityRigidModes` の基底は Euclid 内積で正規直交化した列で、`nullity` が列の数、`basis` が列優先の `BlockVectorView` である。
`max_modes` が連結成分の数と $D(D+1)/2$ の積より小さいときと、許容誤差で支持の判定が曖昧になるときは `InvalidInput` を返す。
判定は支持の位置だけから行い、作用素の核が完全に得られたことは保証しない。
基底は `scioxide_linalg::BorderedSystem` に渡し、作用素が基底を消すこと、荷重の適合性、呼び出し側が選ぶゲージを検査し、ゲージを課した拡大系を解く。

次のセルは一軸引張と同じ板で支持を 4 通りに変え、剛体モードの数、作用素の値 $\max_k\|Am_k\|_\infty$、荷重との内積 $\max_k|F^{\mathsf T}m_k|$ を求める。
右辺の荷重は $x$ 方向の 100 MPa である。

```rust
//| id: pde-elasticity-rigid-modes
//| ref: pde-elasticity-rigid-modes
//| title: 支持の組み合わせごとに剛体モードを数え、作用素と荷重との関係を確かめる
//| run: reactive
//| uses: [pde-elasticity-plate]
//| crates: [scioxide-core, scioxide-pde, scioxide-spatial]
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"modes","path":"/rows/0/1","equals":0}
//|       - {"artifact":"modes","path":"/rows/0/2","equals":null}
//|       - {"artifact":"modes","path":"/rows/1/1","equals":1}
//|       - {"artifact":"modes","path":"/rows/1/2","range":{"max":1e-9}}
//|       - {"artifact":"modes","path":"/rows/1/3","range":{"max":1e-9}}
//|       - {"artifact":"modes","path":"/rows/2/3","approx":{"value":2581.9889,"rtol":1e-6}}
//|       - {"artifact":"modes","path":"/rows/3/1","equals":3}
use scioxide_core::{LinearOperator, Tolerance};
use scioxide_pde::{
    BoundaryCondition, BoundaryData, ElasticityFormulation, ElasticityKinematics,
    ElasticityOptions, IsotropicElasticMaterial, LinearElasticityPlan, SimplexFemGeometry,
    SimplexFemOrder,
};

let (a, b) = (200.0, 100.0);
let material =
    IsotropicElasticMaterial::from_young_poisson(200_000.0, 0.3).map_err(|e| e.to_string())?;
let options = ElasticityOptions::new(
    ElasticityKinematics::PlaneStress,
    ElasticityFormulation::Displacement(SimplexFemOrder::P1),
);
let tolerance = Tolerance::new(1e-10, 1e-10).map_err(|e| e.to_string())?;
let mut rows = Vec::new();
// (名前, 左辺の u_x を固定, 下辺の u_y を固定)。右辺には x 方向に 100 MPa を加える。
let supports = [
    ("左辺と下辺のローラー", true, true),
    ("左辺のローラーだけ", true, false),
    ("下辺のローラーだけ", false, true),
    ("支持なし", false, false),
];
for (name, left, bottom) in supports {
    let side = |fixed: bool, tag: u32, component: usize| {
        if fixed {
            BoundaryCondition::dirichlet(tag, BoundaryData::zero()).for_component(component)
        } else {
            BoundaryCondition::natural(tag, BoundaryData::zero()).for_component(component)
        }
    };
    let conditions = vec![
        side(left, 1, 0),
        side(false, 1, 1),
        BoundaryCondition::natural(2, BoundaryData::constant(100.0)).for_component(0),
        side(false, 2, 1),
        side(false, 3, 0),
        side(bottom, 3, 1),
        BoundaryCondition::natural(4, BoundaryData::zero()),
    ];
    let mesh = plate_mesh(a, b, 4, 2).map_err(|e| e.to_string())?;
    let boundaries = plate_boundaries(&mesh, a, b, conditions).map_err(|e| e.to_string())?;
    let plan = LinearElasticityPlan::new(
        mesh,
        SimplexFemGeometry::Affine,
        material,
        &boundaries,
        &|_| Ok([0.0; 2]),
        options.clone(),
    )
    .map_err(|e| e.to_string())?;
    // 二次元の剛体モードは並進 2 つと回転 1 つなので、列の上限は 3 で足りる。
    let modes = plan.rigid_modes(tolerance, 3).map_err(|e| e.to_string())?;
    let basis = modes.basis().map_err(|e| e.to_string())?;
    let mut image = vec![0.0; plan.unknowns()];
    let mut work = vec![0.0; plan.apply_workspace_len().map_err(|e| e.to_string())?];
    let (mut action, mut compatibility) = (None::<f64>, None::<f64>);
    for k in 0..modes.nullity() {
        let mode = basis.column(k).map_err(|e| e.to_string())?;
        plan.apply_into(mode, &mut image, &mut work)
            .map_err(|e| e.to_string())?;
        let norm = image.iter().fold(0.0_f64, |m, v| m.max(v.abs()));
        let dot: f64 = mode.iter().zip(plan.load()).map(|(m, f)| m * f).sum();
        action = Some(action.unwrap_or(0.0).max(norm));
        compatibility = Some(compatibility.unwrap_or(0.0).max(dot.abs()));
    }
    rows.push((name, modes.nullity(), action, compatibility));
}
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let columns = serde_json::json!([
    { "key": "0", "label": "支持" },
    { "key": "1", "label": "剛体モードの数 [-]", "type": "integer" },
    { "key": "2", "label": "max ‖A m‖∞ [N/mm]", "type": "number", "format": sci3, "nullText": "—" },
    { "key": "3", "label": "max |Fᵀm| [N/mm]", "type": "number", "format": sci3, "nullText": "—" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "modes" })
);
```

左辺と下辺のローラーでは剛体モードはなく、行列は正定値である。
左辺のローラーだけでは $y$ 方向の並進が残り、荷重は $x$ 方向なので $F^{\mathsf T}m=0$ で適合する。
この場合は解が存在するが一意でないので、ゲージで並進を決める。
下辺のローラーだけでは $x$ 方向の並進が残り、右辺の荷重と直交しないので $|F^{\mathsf T}m|=2582$ N/mm になり、釣り合う解は存在しない。
この値は厚さ 1 mm あたりの合力 $100\times100=10^4$ N/mm に、Euclid ノルム 1 に正規化した並進の節点値 $1/\sqrt{15}$（頂点は 15 個）を掛けたものである。
支持なしでは 3 つのモードが全て残る。
剛体モードが残る 3 つの場合とも $\|Am\|_\infty$ は $10^{-12}$ から $10^{-11}$ で、剛性行列の要素の大きさ（$10^5$ N/mm 程度）に比べて丸め誤差の水準なので、返した基底は作用素の零空間に入っている。

## 体積ロッキングと混合形

$\nu\to1/2$ では $K/\mu\to\infty$ になり、エネルギーの $K(\nabla\cdot u)^2/2$ の項が変位に $\nabla\cdot u\approx0$ を強制する。
離散の変位空間に発散が 0 の関数が少ないと、この拘束で変位がほとんど動けなくなり、解が 0 に近づく。
これを体積ロッキングと呼ぶ。
区分一次の連続な変位（P1）はとくに影響を受け、高次の要素でもメッシュによってはロッキングする（Brenner–Scott）。

混合形は平均応力 $p$ を別の未知数にして、体積の拘束を弱い形で課す。
Plan が使うエネルギー密度は

```text
ψ(ε, p) = μ dev ε : dev ε + p tr ε − p² / (2K)
```

で、$p$ について停留させると $p=K\operatorname{tr}\varepsilon$ となり、元の $\mu\,\mathrm{dev}\,\varepsilon:\mathrm{dev}\,\varepsilon+K(\operatorname{tr}\varepsilon)^2/2$ に戻る。
離散化すると鞍点系

```text
[ A_d   Bᵀ       ] [ u ]   [ F ]
[ B    −M_p / K  ] [ p ] = [ 0 ]
```

になる。
$A_d$ は偏差部分の剛性、$B$ は発散の行列、$M_p$ は圧力の質量行列である。
$K\to\infty$ で右下のブロックは 0 に近づくが、変位と圧力の空間が inf-sup 条件

```text
inf_q sup_v (q, ∇·v) / (‖q‖ ‖v‖₁) ≥ β > 0   （β はメッシュに依らない）
```

を満たせば、解は $K$ に依らずに安定である（Brezzi の理論）。
`MixedP2P1` は連続な P2 の変位と頂点の P1 圧力の組（Taylor–Hood 要素）で、メッシュに関する弱い条件の下でこの条件を満たす（Boffi–Brezzi–Fortin）。
圧力は引張を正とし、Dirichlet の条件は与えない。
行列は対称で不定値なので、正定値を前提にする共役勾配法と Cholesky 分解は使えない。

変位形と混合形でたわみと平均応力がどう変わるかは、[片持ち梁の例題](oxref:pde-cantilever-locking-section)で $\nu=0.3$ から 0.4999 まで比べる。

## まとめ

線形弾性は `IsotropicElasticMaterial` の $\mu$ と $K$、`ElasticityKinematics` の縮約、`ElasticityFormulation` の要素を選んで `LinearElasticityPlan` を準備し、`assemble_csr` と `rhs` の系を変位形なら共役勾配法か Cholesky 分解、混合形なら MINRES 法か LU 分解で解く。
一次の変位で表せる一様な応力は、どの要素でも丸め誤差の範囲で再現される。
支持が剛体の動きを止めているかは `rigid_modes` で調べられ、残るモードがあれば荷重の適合性とゲージを確かめてから解く。
$\nu$ が 1/2 に近い材料では、体積ロッキングを避けるために `MixedP2P1` を選ぶ。
エネルギーと応力は `energy` と `stress` で読み、エネルギーの収支で境界条件の扱いを点検できる。
