定常な拡散の問題は時間を含まないので、境界のデータと内部の源項が領域全体の解を同時に決める。
離散化すると、未知数のすべてを結ぶ一つの連立一次方程式 $\mathbf{A}\mathbf{u}=\mathbf{b}$ になる。
このページでは一次元の楕円型方程式から、有限差分法（FDM）、有限要素法（FEM）、有限体積法（FVM）の行列と荷重を導き、製造解（解を先に決めて源項を逆算する方法）で収束次数を測る。
未知数の位置は[保存則と格子上の場](../models-grids-and-boundaries/)、境界条件の規約は[境界条件と外向きの符号](../boundary-conditions/)、できた連立一次方程式の解き方は[楕円型の連立一次方程式の解き方](../elliptic-linear-solves/)で扱う。

## 定常境界値問題の標準形

区間 $\Omega=[a,b]$ の線形な楕円型方程式を考える。

$$
-\frac{d}{dx}\left(k(x)\frac{du}{dx}\right)+c(x)\,u=f(x),\qquad x\in(a,b)
$$

$k(x)>0$ は拡散係数（熱伝導率など）、$c(x)$ は反応係数（周囲への熱損失など）、$f(x)$ は単位長さあたりの生成（内部発熱など）である。
両端には Dirichlet、Neumann、Robin のどれかの条件を課す。
$c\ge0$ で、さらに $c$ が正になる区間があるか、少なくとも一端に Dirichlet 条件か $\alpha>0$ の Robin 条件があれば、解は一意に決まる。
どちらもなければ、解は定数の分だけ決まらない（[純 Neumann 問題](oxref:pde-pure-neumann-compatibility)）。
`scioxide-pde` は有限であれば符号の変わる $c$ も受け付けるが、そのとき行列が正則であることは保証されない。

## 係数の与え方

Plan は準備のときに係数を標本化して行列を組み立て、求解のときには係数を呼ばない。
係数は離散化ごとのトレイトで渡し、標本化する場所が異なる。

| トレイト | 拡散係数を評価する場所 | 反応係数を評価する場所 | 検査 |
|---|---|---|---|
| `StructuredFdmCoefficients` | 区間（面）の中点。軸と成分ごとのスカラー | 頂点。成分の間の結合を含む | 拡散係数が負なら `DomainError` |
| `FvmCoefficients` | セル中心。$D\times D$ のテンソル | セル中心 | テンソルが正定値でなければ `DomainError` |
| `SimplexFemCoefficients` | 要素の求積点。成分と方向のテンソル | 要素の求積点 | テンソルが正定値でなければ `DomainError` |

`StructuredFdmCoefficients` は保存形の移流速度 `advection` も返せる。
よく使う二つの形には、三つのトレイトをすべて実装した型がある。

- `ConstantDiffusion::new(k)` は定数の拡散係数 $k$ を返し、`with_reaction(c)` で定数の反応係数 $c$ を加える。
  有限要素法には場所に依らないことを提示する（`is_spatially_constant`）ので、係数を求積点ごとに評価せず、Plan ごとに一度だけ評価する。
- `IsotropicDiffusion::new(|x: [f64; D]| Ok(k(x)))` は場所の関数で等方的な拡散係数を返し、反応は 0 である。
  評価のたびに関数を一度呼び、メモリを確保しない。

どちらも値を検査せず、検査は Plan が標本化するときに行う。

## 有限差分法の保存形ステンシル

格子点を $a=x_0<x_1<\dots<x_N=b$、隣接点の間隔を $h_{i+1/2}=x_{i+1}-x_i$、格子点 $x_i$ の支配幅を $w_i=(x_{i+1}-x_{i-1})/2$ とする。
係数が場所で変わるとき、$(ku')'=ku''+k'u'$ と展開して差分にすると、隣の点と流束を共有しないので保存が崩れる。
そこで区間の中点 $x_{i+1/2}$ で標本化した $k_{i+1/2}=k(x_{i+1/2})$ を使って、区間ごとの流束を作る。

$$
q_{i+1/2}=-k_{i+1/2}\frac{u_{i+1}-u_i}{h_{i+1/2}}
$$

内部の格子点では流束の差と反応・源項を支配幅の上で釣り合わせる。

$$
q_{i+1/2}-q_{i-1/2}+c(x_i)\,u_i\,w_i=f(x_i)\,w_i
$$

行列の第 $i$ 行は、対角が $k_{i-1/2}/h_{i-1/2}+k_{i+1/2}/h_{i+1/2}+c(x_i)w_i$、隣の二つが $-k_{i\mp1/2}/h_{i\mp1/2}$ の三重対角になる。
反応と源項は頂点で標本化して支配幅を掛ける（集中化）。
したがって一次元の `StructuredFdmPlan` は、剛性行列を中点則で積分し、反応と荷重を集中化した P1 有限要素法と同じ連立一次方程式になる。

一様な格子と、隣接する間隔の差が $O(h^2)$ の滑らかに変化する格子では、内部の局所打切り誤差は $O(h^2)$ である。
間隔が不規則に変わる格子では $O(h)$ に下がる。
これは細かくしていく格子の族の性質で、一つの格子からは判定できないので、Plan は次数を返しない。

端点の Neumann 条件と Robin 条件には、幅 $h_{1/2}/2$ の半区間の収支を使う。
左端の式は $q_{1/2}-(g_a-\alpha u_0)+c(x_0)\,u_0\,h_{1/2}/2=f(x_0)\,h_{1/2}/2$ で、括弧の中は境界から入る流束である。
ここで $g_a$ と $\alpha$ はその端の Robin のデータと係数で、Neumann 条件では $\alpha=0$ とする。
この関係式を半幅で割ると局所残差の次数は一つ下がるが、滑らかな係数と安定な境界値問題では解の $O(h^2)$ の収束は保たれる。

## 有限要素法の弱形式と基底

方程式に試験関数 $v\in H^1(\Omega)$（$v$ とその導関数が二乗可積分な関数の空間）を掛けて区間全体で積分し、拡散の項を部分積分する。
左端の外向きの余法線流束 $-k\,u'(a)=g_a$ と右端の $k\,u'(b)=g_b$ を代入すると、次の**弱形式**になる。

$$
\int_a^b k\,u'v'\,dx+\int_a^b c\,u\,v\,dx=\int_a^b f\,v\,dx+g_a\,v(a)+g_b\,v(b)
$$

Neumann のデータは右辺の境界項にそのまま入り、条件が弱形式から自然に課されるので自然境界条件と呼ぶ。
Robin 条件 $k\,\partial u/\partial n+\alpha u=g$ では、境界項が $(g-\alpha u)v$ になり、$\alpha\,u\,v$ を左辺へ移す。
Dirichlet 条件は試験関数の空間から境界の自由度を除き、既知の値を持ち上げて課すので、本質境界条件と呼ぶ。

`SimplexFemPlan` は `IntervalMesh` の各要素 $e=[x_i,x_{i+1}]$ で、区分一次の帽子関数（`SimplexFemOrder::P1`）か区分二次の基底（`P2`）を使う。
解を $u_h=\sum_j u_j\phi_j$ と展開し、試験関数を $v=\phi_i$ とすると、要素ごとの行列と荷重を足し合わせた $\mathbf{A}\mathbf{u}=\mathbf{b}$ になる。
P1 で要素長が $h_e$ なら、局所行列と荷重は次の積分である。

$$
(\mathbf{K}_e)_{ij}=\int_e k\,\phi_i'\phi_j'\,dx=\frac{\pm1}{h_e^2}\int_e k\,dx,\qquad (\mathbf{M}_e)_{ij}=\int_e c\,\phi_i\phi_j\,dx,\qquad (\mathbf{f}_e)_i=\int_e f\,\phi_i\,dx
$$

$\pm$ は対角で $+$、非対角で $-$ である。
楕円型の問題では反応の行列を集中化せず、この積分のまま使う。

積分は重みが正で節点が要素の内部にある求積で行う。
既定の求積は次数 $p$ の要素で $2p$ 次（曲がった要素では 7 次）以上の多項式を厳密に積分する。
一次元では節点の数が最も少ない Gauss–Legendre 則で、P1 では 2 点則（3 次まで厳密）、P2 では 3 点則（5 次まで厳密）になる。
P1 では、$d$ 次まで厳密な求積が拡散係数を $d$ 次、反応係数を $d-2$ 次、源項を $d-1$ 次の多項式まで厳密に積分する。
`SimplexFemOptions::with_volume_rule` で次数の高い求積に替えられる。
`ConstantDiffusion` のように場所に依らない係数と affine の要素では、要素行列を参照要素の積分から作る。

積分が厳密で、$c\ge0$ と前節の一意性の条件が成り立てば、FEM の解はエネルギーノルム $\|v\|_E=(\int_a^b k\,|v'|^2+c\,|v|^2\,dx)^{1/2}$ で測った誤差が、選んだ要素の空間の中で最小になる（Galerkin 直交性）。
一次元の P1 では、$k$ が定数で $c=0$ なら、荷重を厳密に積分したときの節点の値は厳密解に一致する（Green 関数が区分一次関数になるため）。
既定の 2 点則では荷重の求積誤差が残り、節点の誤差は $O(h^4)$ で減る（[Poisson 問題の格子収束](../../examples/poisson-grid/)）。

## 有限体積法の収支と二点流束近似

有限体積法はセル $C_i=[x_{i-1/2},x_{i+1/2}]$ ごとに保存則を積分した収支を未知数の式にする。

$$
q(x_{i+1/2})-q(x_{i-1/2})+\int_{C_i}c\,u\,dx=\int_{C_i}f\,dx
$$

未知数はセル平均 $u_i$ で、セル中心で評価した拡散係数 $k_i$ をそのセルの材料の値とする。
面 $x_{i+1/2}$ の流束を、左右の半セルの中で一次関数とみなして書く。
セル中心から面までの距離を $d_L$、$d_R$、面の値を $u_f$ とすると、二つの半セルの流束は等しくなければならない。

$$
-k_L\frac{u_f-u_L}{d_L}=-k_R\frac{u_R-u_f}{d_R}
$$

これを解いて $u_f$ を消去すると、二点流束近似（TPFA）の式になる。

$$
T_{i+1/2}=\frac{1}{d_L/k_L+d_R/k_R},\qquad
q_{i+1/2}=-T_{i+1/2}\,(u_{i+1}-u_i)
$$

$T$ は二つの半セルの熱抵抗 $d/k$ を直列につないだものの逆数で、一様な材料では $k/(d_L+d_R)$、材料が面で変わると重み付きの調和平均になる。
反応と源項はセル中心で標本化して体積を掛ける（中点則）。
境界の面では Dirichlet の値と隣のセルの値から半セルの流束を作るか、Neumann・Robin の面の式を使う。
半セルの伝導係数が正でないときは、Plan の準備が `NumericalInstability` で拒否する。

セル $C_i$ から出る流束 $q_{i+1/2}$ は、隣のセル $C_{i+1}$ に同じ値の流入として入る。
したがって全セルの式を足すと内部の面の流束は打ち消し合い、境界の流束と生成の総和だけが残る。

$$
q_{\mathrm{right}}-q_{\mathrm{left}}+\sum_i\int_{C_i}c\,u\,dx=\sum_i\int_{C_i}f\,dx
$$

この保存は格子の粗さに依らず、丸め誤差の範囲で成り立つ。
保存は精度とは別の性質で、セル値は中点則によるセル平均の近似にすぎない。
`StructuredFvmPlan::face_fluxes` と `SimplexFvmPlan::face_fluxes` は解から面の流束を再構成するので、収支を直接確かめられる（[界面の流束の検算](oxref:pde-interface-flux-check)）。
一次元では、FDM、FVM、P1 FEM の行列はどれも三重対角になる。
ただし単体のメッシュ（`IntervalMesh`）の Plan は頂点やセルの番号の順に未知数を並べるので、三重対角になるのは頂点とセルを左から順に番号付けたときである。

## 製造解による収束次数の検証

格子を細かくしたときの誤差の減り方は、厳密解が分かる問題で測る。
解析解 $u_*(x)=\sin(m\pi x)$ に対し、両端が 0 の Dirichlet 条件で $-u''=(m\pi)^2\sin(m\pi x)$ を解く。
一様な格子の中心差分作用素に対して、$\sin(m\pi x_i)$ は厳密な固有ベクトルで、離散固有値は次の値である。

$$
\lambda_h=\frac{4}{h^2}\sin^2\left(\frac{m\pi h}{2}\right)
$$

一次元の `StructuredFdmPlan` は源項を頂点で標本化して支配幅を掛けるので、一様な格子では離散解が $((m\pi)^2/\lambda_h)\sin(m\pi x_i)$ になる。
節点の誤差は $((m\pi)^2/\lambda_h-1)\,|\sin(m\pi x_i)|$ で、その最大値は閉形式で予測できる。
下のセルは格子の区間数 $N=8,16,\dots,200$ の 25 通りで `StructuredFdmPlan` と `EllipticProblem` により解き、最大節点誤差を閉形式の予測と比べる。
FEM と FVM を含む三つの方法の比較は、[Poisson 問題の格子収束の例](../../examples/poisson-grid/)で行う。

```rust
//| id: pde-elliptic-spatial-order
//| ref: pde-elliptic-spatial-order
//| title: 解の波数を動かして中心差分の格子収束を測る
//| run: reactive
//| crates: [scioxide-pde, scioxide-spatial, scioxide-core]
//| inputs:
//|   mode_number: {"type":"range","label":"正弦モード m [-]","description":"製造解の空間波数を変える。","min":1,"max":8,"step":1,"value":3}
//| cases:
//|   - {"id":"fundamental","label":"基本モード m = 1","description":"最細格子で一波長 400 点になり、観測次数はほぼ 2 になる。","inputs":{"mode_number":1}}
//|   - {"id":"short-wave","label":"短い波 m = 8","description":"一波長 50 点では誤差が 1.3×10⁻³ に上がり、観測次数は 2.05 と漸近値からずれる。","inputs":{"mode_number":8}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"order","path":"/rows/0/2","approx":{"value":1.8507563e-4,"rtol":1e-6}}
//|       - {"artifact":"order","path":"/rows/0/3","approx":{"value":1.8507563e-4,"rtol":1e-6}}
//|       - {"artifact":"order","path":"/rows/0/4","approx":{"value":2.0002,"atol":1e-3}}
//|       - {"artifact":"order","path":"/rows/0/5","equals":"tridiagonal-direct"}
//|   - case: fundamental
//|     expect:
//|       - {"artifact":"order","path":"/rows/0/2","approx":{"value":2.0561929e-5,"rtol":1e-6}}
//|       - {"artifact":"order","path":"/rows/0/4","approx":{"value":2.00003,"atol":1e-3}}
//|   - case: short-wave
//|     expect:
//|       - {"artifact":"order","path":"/rows/0/2","approx":{"value":1.3143882e-3,"rtol":1e-6}}
//|       - {"artifact":"order","path":"/rows/0/3","approx":{"value":1.3143882e-3,"rtol":1e-6}}
//|       - {"artifact":"order","path":"/rows/0/4","approx":{"value":2.050,"atol":2e-3}}
use scioxide_pde::{
    BoundaryData, BoundaryKind, ConstantDiffusion, EllipticOptions, EllipticProblem, FieldData,
    FieldPoint, SpatialDiscretization, StructuredBoundaries, StructuredFdmPlan,
};
use scioxide_spatial::{AxisTopology, CoordinateAxis, Grid1d, SegmentMesh};

let mode = mode_number.round();
let wavenumber = mode * std::f64::consts::PI;
// 製造解 u = sin(mπx) の源項 f = (mπ)² sin(mπx)（データの定義に f64::sin を使う）。
let source = FieldData::time_invariant(move |p: FieldPoint<f64, 1>| {
    Ok(wavenumber * wavenumber * (wavenumber * p.point[0]).sin())
});
let k = ConstantDiffusion::new(1.0);
let mut measured = Vec::new();
let mut predicted = Vec::new();
let mut method = String::new();
for intervals in (8..=200).step_by(8) {
    let axis = CoordinateAxis::uniform(0.0, 1.0, intervals + 1).map_err(|e| e.to_string())?;
    let grid = Grid1d::new([axis], [AxisTopology::Bounded]).map_err(|e| e.to_string())?;
    let mesh = SegmentMesh::new(grid).map_err(|e| e.to_string())?;
    let ends =
        StructuredBoundaries::uniform(&mesh, 1, BoundaryKind::Dirichlet, BoundaryData::zero())
            .map_err(|e| e.to_string())?;
    let plan = StructuredFdmPlan::new(mesh, &k, &ends).map_err(|e| e.to_string())?;
    let solution = EllipticProblem::new(&plan, &source)
        .solve_with_options(&EllipticOptions::new())
        .map_err(|e| e.to_string())?;
    let report = solution.report();
    if !report.is_success() {
        return Err(format!("N = {intervals}: {}", report.termination()));
    }
    method = report.diagnostics().method().unwrap_or("-").to_owned();
    let mut maximum_error = 0.0_f64;
    for (node, u) in solution.values().iter().enumerate() {
        let x = plan.dof_point(node).map_err(|e| e.to_string())?.point[0];
        maximum_error = maximum_error.max((u - (wavenumber * x).sin()).abs());
    }
    // 独立な検算: 振幅の比 (mπ)²/λ_h と格子点上の |sin(mπx_i)| の最大値の積。
    let h = 1.0 / intervals as f64;
    let discrete_eigenvalue = 4.0 / (h * h) * (wavenumber * h / 2.0).sin().powi(2);
    let peak = (0..=intervals)
        .map(|i| (wavenumber * i as f64 * h).sin().abs())
        .fold(0.0_f64, f64::max);
    let closed_form = (wavenumber * wavenumber / discrete_eigenvalue - 1.0) * peak;
    measured.push([intervals as f64, maximum_error]);
    predicted.push([intervals as f64, closed_form]);
}
let count = measured.len();
let (coarse, finest) = (measured[count - 2][1], measured[count - 1][1]);
let observed_order = (coarse / finest).ln() / (200.0_f64 / 192.0).ln();
emit_line_chart!(
    &vec![
        serde_json::json!({
            "name": "離散固有値による予測",
            "style": { "lineType": "dashed" },
            "points": predicted
        }),
        serde_json::json!({
            "name": "最大節点誤差",
            "style": { "symbol": "circle", "showSymbol": true },
            "points": measured
        }),
    ],
    options = &serde_json::json!({
        "xLabel": "格子区間数 N [-]",
        "yLabel": "最大節点誤差 [-]",
        "xType": "log",
        "yType": "log"
    })
);
let sci4 = serde_json::json!({ "notation": "scientific", "significantDigits": 4 });
let fixed4 = serde_json::json!({ "fractionDigits": 4 });
let columns = serde_json::json!([
    { "key": "0", "label": "モード m", "type": "integer" },
    { "key": "1", "label": "一波長あたりの点数（N = 200）", "type": "number", "format": fixed4 },
    { "key": "2", "label": "最大誤差（N = 200）[-]", "type": "number", "format": sci4 },
    { "key": "3", "label": "閉形式の誤差 [-]", "type": "number", "format": sci4 },
    { "key": "4", "label": "観測次数（N = 192→200）", "type": "number", "format": fixed4 },
    { "key": "5", "label": "解法" }
]);
let rows = vec![(
    mode as u32,
    400.0 / mode,
    finest,
    predicted[count - 1][1],
    observed_order,
    method,
)];
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "order" })
);
```

両対数のグラフでは、誤差の点が傾き $-2$ の直線に乗り、格子幅 $h$ を半分にすると誤差が $1/4$ になる。
既定の $m=3$ では、最細格子 $N=200$ の最大誤差は $1.851\times10^{-4}$ で、閉形式の予測との差は $10^{-13}$ 未満だった。
観測次数は 2.0002 である。
展開 $\lambda_h=(m\pi)^2\bigl(1-(m\pi h)^2/12+O(h^4)\bigr)$ から、相対誤差の主要項は $(m\pi h)^2/12$ である。
モード数 $m$ を大きくすると、同じ格子で一波長あたりの格子点の数 $P=2/(mh)$ が減り、誤差の水準が上がる。
$m=8$ では最細格子でも $P=50$ で、誤差は $1.31\times10^{-3}$、観測次数は 2.05 になり、まだ漸近的な領域に入りきっていない。
解法の列の `tridiagonal-direct` は一次元の FDM の行列を三重対角の直接法で解いたことを示す。

## まとめ

FDM は区間の中点で標本化した係数による保存形の差分、FEM は正の重みの求積で積分した弱形式、FVM はセル中心の係数から半セルの直列抵抗を作る二点流束である。
一次元の FDM・P1 FEM・FVM は、節点を左から順に並べればどれも三重対角の行列になる。
係数は `ConstantDiffusion` か `IsotropicDiffusion`、あるいは離散化ごとのトレイトで渡し、標本化する場所は FDM が区間の中点、FVM がセル中心、FEM が求積点である。
FDM の精度は格子の族の規則性に依存し、P1 FEM は $k$ が定数で $c=0$ なら、荷重を厳密に積分したときに節点で厳密解に一致する。
FVM の保存は精度とは別の性質で、面の流束を再構成して収支を確かめられる。
代数的な残差は離散化誤差を表さないので、次数は製造解や格子の細分化で測る。
