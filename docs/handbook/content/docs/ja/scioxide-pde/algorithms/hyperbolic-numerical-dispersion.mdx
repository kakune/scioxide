波動方程式を安定な刻みで解いても、波の速さは正確には再現されない。
空間格子は短い波長ほど波を遅らせ、その遅れは伝播させた時間に比例して蓄積する。

このページでは一様格子の 2 次中心差分で離散化した波動作用素について半離散系の分散関係を導き、位相速度と群速度の誤差を波長あたりの格子点数で表す。
次に、時間積分の方法（Dormand–Prince 5(4) 法と蛙跳び法）が分散関係にどう加わるかを比べ、長い時間の計算で確かめる量をまとめる。
半離散系、Courant 数 $\nu$、安定関数 $R(z)$ の定義は[波動方程式と CFL 条件](../hyperbolic-waves-and-cfl/)にある。

## 半離散の波動作用素の数値分散

定係数の $u_{tt}=c^2u_{xx}$ を一様格子の 2 次中心差分で離散化し、離散平面波 $u_j(t)=e^{\mathrm{i}(jkh-\omega t)}$ を代入すると、半離散系の分散関係が得られる。

$$
\omega_h(k)=\frac{2c}{h}\sin\frac{kh}{2}
$$

$k$ は波数、$\theta=kh$ は格子幅で測った波数、$P=2\pi/\theta$ は一波長あたりの格子点数である。
真の分散関係 $\omega=ck$ と比べると、位相速度 $\omega_h/k$ と群速度 $d\omega_h/dk$ の比は次のようになる。

$$
\frac{c_{\mathrm{phase}}}{c}=\frac{\sin(\theta/2)}{\theta/2}=1-\frac{\theta^2}{24}+O(\theta^4),\qquad\frac{c_{\mathrm{group}}}{c}=\cos\frac{\theta}{2}
$$

どちらも 1 より小さく、短い波長ほど遅れる。
個々の位相は位相速度で進み、波束の包絡線とエネルギーは群速度で進む。
いろいろな波長を含むパルスを伝えると短い波長の成分が後ろに取り残され、波形の後ろに格子規模の小さな波が尾を引く。
これを数値分散と呼ぶ。
位相速度の誤差は約 $\theta^2/24=\pi^2/(6P^2)$ なので、1 % 以内に抑えるには $P\ge13$ が要る。

時間も離散化すると、分散関係は時間積分の方法にも依存する。
1 刻みで固有値 $\pm\mathrm{i}\,\omega_h$ のモードに掛かる因子は $R(\pm\mathrm{i}\,y)$、$y=\omega_h\Delta t=2\nu\sin(\theta/2)$ である。
実係数の $R$ では $R(-\mathrm{i}y)$ は $R(\mathrm{i}y)$ の複素共役なので、数値的な角振動数は $\arg R(\mathrm{i}y)/\Delta t$、1 刻みの振幅の比は $\lvert R(\mathrm{i}y)\rvert$ になる。
比較に、時間と空間の両方を中心差分にした蛙跳び法 $(u_j^{n+1}-2u_j^n+u_j^{n-1})/\Delta t^2=c^2(u_{j+1}^n-2u_j^n+u_{j-1}^n)/h^2$ を置く。
その分散関係は $\sin(\omega\Delta t/2)=\nu\sin(\theta/2)$ で、$\nu\le1$ なら振幅は変わらない。
`scioxide-pde` は蛙跳び法を提供しないので、蛙跳び法は閉形式の比較対象としてだけ使う。

次のセルは三つの分散関係を閉形式で評価する。
入力は Courant 数 $\nu$、一波長あたりの格子点数 $P$、伝播させる周期の数で、Dormand–Prince 5(4) 法の刻みが一定の $\nu$ に保たれた場合を表す。
図は $P$ に対する位相速度と群速度の比、表は選んだ $P$ での速度の比、指定した周期だけ伝えた後の振幅の比と位相の遅れ、および最も短い波（$\theta=\pi$）の 1 刻みの振幅の比である。
`HyperbolicProblem` で実際に解いた弦の倍音の位相の遅れは[固定端の弦の例](../../examples/fixed-string-wave/)で測る。

```rust
//| id: pde-wave-dispersion
//| ref: pde-wave-dispersion
//| title: Courant 数と波長あたりの格子点数を動かして分散関係を比べる
//| run: reactive
//| crates: [scioxide-core]
//| inputs:
//|   cfl_number: {"type":"range","label":"Courant 数 ν = cΔt/h [-]","description":"一刻みで波が進む格子幅の割合を変える。","min":0.05,"max":1,"step":0.05,"value":0.45}
//|   points_per_wavelength: {"type":"range","label":"一波長あたりの格子点数 P [-]","description":"表で読む波の空間解像度を変える。","min":3,"max":30,"step":1,"value":10}
//|   propagation_periods: {"type":"range","label":"伝播させる周期の数 [-]","description":"位相の遅れと振幅の変化を蓄積させる時間を変える。","min":1,"max":50,"step":1,"value":12}
//| cases:
//|   - {"id":"coarse-wave","label":"粗い波 P = 4","description":"位相速度の比は 0.900 に下がり、12 周期で約 1.2 周期遅れる。","inputs":{"points_per_wavelength":4}}
//|   - {"id":"unstable-step","label":"ν = 0.6","description":"θ = π の 1 刻みの振幅の比が 1 を超え、Dormand–Prince 5(4) 法は不安定になる。","inputs":{"cfl_number":0.6}}
//|   - {"id":"courant-limit","label":"ν = 1","description":"蛙跳び法は位相速度の比が 1 になり分散を持たない。","inputs":{"cfl_number":1}}
//|   - {"id":"long-run","label":"50 周期の伝播","description":"P = 10 の位相の遅れは 0.82 周期に増える。","inputs":{"propagation_periods":50}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"speeds","path":"/rows/0/1","approx":{"value":0.98363164,"rtol":1e-7}}
//|       - {"artifact":"speeds","path":"/rows/0/2","approx":{"value":0.95105652,"rtol":1e-7}}
//|       - {"artifact":"speeds","path":"/rows/1/1","approx":{"value":0.98363186,"rtol":1e-7}}
//|       - {"artifact":"speeds","path":"/rows/1/2","approx":{"value":0.95105795,"rtol":1e-6}}
//|       - {"artifact":"speeds","path":"/rows/1/3","approx":{"value":0.99996868,"rtol":1e-7}}
//|       - {"artifact":"speeds","path":"/rows/1/5","approx":{"value":0.99997518,"rtol":1e-7}}
//|       - {"artifact":"speeds","path":"/rows/2/1","approx":{"value":0.98682964,"rtol":1e-7}}
//|   - case: coarse-wave
//|     expect:
//|       - {"artifact":"speeds","path":"/rows/0/1","approx":{"value":0.90031632,"rtol":1e-7}}
//|       - {"artifact":"speeds","path":"/rows/0/4","approx":{"value":1.1962042,"rtol":1e-6}}
//|   - case: unstable-step
//|     expect:
//|       - {"artifact":"speeds","path":"/rows/1/5","approx":{"value":1.0003116,"rtol":1e-6}}
//|   - case: courant-limit
//|     expect:
//|       - {"artifact":"speeds","path":"/rows/2/1","approx":{"value":1.0,"atol":1e-12}}
//|       - {"artifact":"speeds","path":"/rows/2/2","approx":{"value":1.0,"atol":1e-6}}
//|   - case: long-run
//|     expect:
//|       - {"artifact":"speeds","path":"/rows/0/4","approx":{"value":0.81841785,"rtol":1e-6}}
use scioxide_core::RealScalar;

let nu = cfl_number;
let points = points_per_wavelength.round();
let periods = propagation_periods.round();
let pi = core::f64::consts::PI;
// Dormand–Prince 5(4) の安定関数 R(z) と R'(z) を z = iy で Horner 法により評価する。
// 複素数は (実部, 虚部) の組で持つ。
let horner = |coefficients: &[f64], y: f64| {
    coefficients
        .iter()
        .rev()
        .fold((0.0, 0.0), |(re, im), &a| (a - im * y, re * y))
};
let stability = [
    1.0,
    1.0,
    0.5,
    1.0 / 6.0,
    1.0 / 24.0,
    1.0 / 120.0,
    1.0 / 600.0,
];
let derivative = [1.0, 1.0, 0.5, 1.0 / 6.0, 1.0 / 24.0, 1.0 / 100.0];
// 戻り値: [半離散, DOPRI5, 蛙跳び法] の (位相速度比, 群速度比, 1 刻みの振幅の比)。
let ratios = |theta: f64| {
    let half = theta / 2.0;
    let s = RealScalar::sin(half);
    let c = RealScalar::cos(half);
    let semi = (s / half, c, 1.0);
    let y = 2.0 * nu * s;
    let (re, im) = horner(&stability, y);
    let (dre, dim) = horner(&derivative, y);
    let modulus2 = re * re + im * im;
    // d arg R(iy)/dy = Re(R'(iy) / R(iy))、群速度比 = cos(θ/2)·d arg R/dy。
    let dopri = (
        RealScalar::atan2(im, re) / (nu * theta),
        c * (dre * re + dim * im) / modulus2,
        RealScalar::sqrt(modulus2),
    );
    let leapfrog = (
        2.0 * RealScalar::asin(nu * s) / (nu * theta),
        c / RealScalar::sqrt(1.0 - nu * nu * s * s),
        1.0,
    );
    [semi, dopri, leapfrog]
};
let names = ["半離散（時間は厳密）", "半離散 + DOPRI5", "蛙跳び法"];
let mut phase_series = vec![Vec::new(); 3];
let mut group_series = vec![Vec::new(); 3];
for index in 0..=240 {
    let p = 3.0 + 37.0 * index as f64 / 240.0;
    for (method, r) in ratios(2.0 * pi / p).into_iter().enumerate() {
        phase_series[method].push([p, r.0]);
        group_series[method].push([p, r.1]);
    }
}
let theta = 2.0 * pi / points;
let steps = periods * points / nu;
let highest = ratios(pi);
let mut rows = Vec::new();
for (method, r) in ratios(theta).into_iter().enumerate() {
    // 半離散は時間を厳密に解くので振幅を保ち、1 刻みの量は定義しない。
    rows.push((
        names[method],
        r.0,
        r.1,
        RealScalar::powf(r.2, steps),
        periods * (1.0 - r.0),
        (method > 0).then_some(highest[method].2),
    ));
}
let series = |values: &[Vec<[f64; 2]>]| {
    (0..3)
        .map(|m| serde_json::json!({ "name": names[m], "points": values[m] }))
        .collect::<Vec<_>>()
};
let marker =
    serde_json::json!({ "kind": "line", "axis": "x", "value": points, "label": "選んだ P" });
for (values, label) in [
    (&phase_series, "位相速度の比 [-]"),
    (&group_series, "群速度の比 [-]"),
] {
    emit_line_chart!(
        &series(values),
        options = &serde_json::json!({
            "xLabel": "一波長あたりの格子点数 P [-]",
            "yLabel": label,
            "link": { "group": "wave-points-per-wavelength" },
            "annotations": [
                { "kind": "line", "axis": "y", "value": 1.0, "label": "真の波速" },
                marker
            ]
        })
    );
}
let fixed6 = serde_json::json!({ "notation": "standard", "significantDigits": 6 });
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let columns = serde_json::json!([
    { "key": "0", "label": "分散関係" },
    { "key": "1", "label": "位相速度の比 [-]", "type": "number", "format": fixed6 },
    { "key": "2", "label": "群速度の比 [-]", "type": "number", "format": fixed6 },
    { "key": "3", "label": "伝播後の振幅の比 [-]", "type": "number", "format": fixed6 },
    { "key": "4", "label": "位相の遅れ [周期]", "type": "number", "format": sci3 },
    { "key": "5", "label": "θ = π の 1 刻みの振幅の比 [-]", "type": "number", "format": fixed6, "nullText": "刻みなし" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "speeds" })
);
```

既定の $\nu=0.45$、$P=10$ では、半離散の位相速度の比は 0.98363、群速度の比は 0.95106 で、12 周期の伝播で 0.196 周期遅れる。
Dormand–Prince 5(4) 法を加えても位相速度の比の変化は $2\times10^{-7}$ にとどまり、12 周期後の振幅の比は 0.99997 である。
この刻みでは時間積分の誤差は空間の分散よりずっと小さく、位相の遅れを減らすには $P$ を増やすしかない。
蛙跳び法では時間の誤差が空間の誤差と逆向きに働き、位相速度の比は 0.98683 に上がる。
$\nu=1$ では二つの誤差が打ち消し合い、蛙跳び法はどの $P$ でも分散を持たない。
$\nu=0.6$ では $\theta=\pi$ の 1 刻みの振幅の比が 1.00031 になり、最も短い波が刻みごとに増える。
[`CflPolicy::Automatic` の上限](oxref:pde-wave-cfl-policy-steps) $\nu\le0.4487$ はこの不安定を避ける。

## 長い時間の計算で確かめる量

長い時間の波動計算では局所誤差の小ささと終了理由とは別に、次の量を確かめる。

1. 一波長あたりの格子点数：最も短い対象の波長に $P\ge13$ 点を置くと、半離散系での位相速度の誤差は 1 % 以内になる。
2. 離散エネルギー $E_h$ の推移：増えていれば不安定、大きく減っていれば数値散逸を疑う。
3. 境界での反射：固定端では反射波の符号が反転し、自由端では同じ符号のまま反射する。
4. 到着時刻の格子依存性：パルスが決まった位置に届く時刻を複数の格子で比べ、格子を細かくすると理論値に近づくことを確かめる。

## まとめ

一様格子の 2 次中心差分の半離散系では、位相速度の比が $\sin(\theta/2)/(\theta/2)$、群速度の比が $\cos(\theta/2)$ になり、短い波長ほど遅れる。
位相速度の誤差は約 $\pi^2/(6P^2)$ なので、1 % 以内に抑えるには対象の最短波長に 13 点以上を置く。
`HyperbolicProblem` の既定の Dormand–Prince 5(4) 法を安定な刻みで使うと、時間積分が加える位相の誤差と振幅の減少は空間の分散よりずっと小さく、精度は格子点数で決まる。
蛙跳び法と比べるときは、時間と空間の誤差が打ち消し合う $\nu=1$ の特殊な性質を一般の方法に当てはめない。
長い時間の計算では格子点数、離散エネルギー、境界での反射、到着時刻を終了理由とは別に確かめる。
