波動方程式は波形とエネルギーを保ったまま有限の速さで伝わる現象を表す双曲型の偏微分方程式である。
拡散方程式の解は時間とともに平滑化されるが、波動方程式の解は減衰しない。

そのため、数値解が発散しないこと（安定性）だけでは足りない。
波の速さ、振幅、エネルギーが長い時間にわたって正しく保たれるかも確かめる必要がある。

このページでは二階の波動方程式を変位と速度の一階連立系に直し、エネルギー保存、CFL 条件、陽解法の安定限界を導く。
そのうえで `HyperbolicProblem` が刻みをどう選ぶかを、`CflPolicy` を替えた計算で確かめる。
安定な刻みで解いたときに残る位相の誤差は[波動の数値分散](../hyperbolic-numerical-dispersion/)、時間発展の出力、チェックポイントからの再開、終了理由の読み方は[時間発展の出力・再開・終了理由](../transient-outputs-and-restart/)で扱う。

## 波動方程式とエネルギー保存

区間 $\Omega=[a,b]$ 上の一次元の変係数波動方程式を考える。

$$
m(x)\,\frac{\partial^2 u}{\partial t^2}=\frac{\partial}{\partial x}\left(k(x)\,\frac{\partial u}{\partial x}\right),\qquad m(x)>0,\quad k(x)>0
$$

$u$ は変位、$m$ は単位長さあたりの質量、$k$ は剛性（弦なら張力）で、局所的な波の速さは $c(x)=\sqrt{k(x)/m(x)}$ である。
解を一つに決めるには、初期変位 $u(x,0)=u_0(x)$ と初速度 $\partial_t u(x,0)=v_0(x)$ の二つの初期条件が要る。

方程式の両辺に速度 $\partial_t u$ を掛けて $\Omega$ で積分し、右辺を部分積分すると、次のエネルギー恒等式が得られる。

$$
\frac{d}{dt}\left[\frac12\int_a^b m\left(\frac{\partial u}{\partial t}\right)^2dx+\frac12\int_a^b k\left(\frac{\partial u}{\partial x}\right)^2dx\right]=\left[k\,\frac{\partial u}{\partial x}\,\frac{\partial u}{\partial t}\right]_a^b
$$

括弧の第 1 項は運動エネルギー、第 2 項はひずみエネルギーである。
固定端（Dirichlet 条件で $u$ が一定なので $\partial_t u=0$）と自由端（Neumann 条件 $k\,\partial_x u=0$）では右辺の境界項（境界でなされる仕事）が 0 になり、全エネルギー $E(t)$ は時間によらず一定になる。

## 一階連立系への変換と線の方法

速度 $v=\partial_t u$ を未知数に加えると、波動方程式は時間について一階の連立系になる。

$$
\frac{\partial}{\partial t}\begin{bmatrix}u\\ v\end{bmatrix}=\begin{bmatrix}v\\ \dfrac{1}{m}\,\dfrac{\partial}{\partial x}\left(k\,\dfrac{\partial u}{\partial x}\right)\end{bmatrix}
$$

空間だけを FDM・FEM・FVM で離散化すると（線の方法）、集中化した対角の質量行列 $\mathbf{M}$ と対称な剛性行列 $\mathbf{K}$ を持つ半離散系が得られる。

$$
\frac{d}{dt}\begin{bmatrix}\mathbf{u}\\ \mathbf{v}\end{bmatrix}=\begin{bmatrix}\mathbf{v}\\ \mathbf{M}^{-1}\left(\mathbf{b}(t)-\mathbf{K}\mathbf{u}\right)\end{bmatrix}
$$

源項と境界データが 0 のとき、離散エネルギー $E_h=\tfrac12\mathbf{v}^\mathsf{T}\mathbf{M}\mathbf{v}+\tfrac12\mathbf{u}^\mathsf{T}\mathbf{K}\mathbf{u}$ も保存される。
実際、$dE_h/dt=\mathbf{v}^\mathsf{T}\mathbf{M}\mathbf{v}'+\mathbf{u}^\mathsf{T}\mathbf{K}\mathbf{u}'=-\mathbf{v}^\mathsf{T}\mathbf{K}\mathbf{u}+\mathbf{u}^\mathsf{T}\mathbf{K}\mathbf{v}=0$ である。
$\mathbf{M}^{-1}\mathbf{K}$ の固有値を $\omega_j^2$ とすると、一階系の固有値は虚軸上の $\pm\mathrm{i}\,\omega_j$ に並ぶ。
この点が、固有値が負の実軸に並ぶ拡散の半離散系との違いである。

`HyperbolicProblem::new(discretization, source, end)` は空間の離散化が持つ拡散係数を $c^2$ と読み、Dirichlet の自由度を除いた半離散系 $\mathbf{M}\mathbf{u}''=\mathbf{b}(t)-\mathbf{K}\mathbf{u}$ を一度だけ準備する。
係数は時刻に依存せず、源項と境界データは時刻に依存してよい。
境界は Dirichlet（固定端）、Neumann（自由端）、Robin のどれでもよい。
初期状態は `initial_state(displacement, velocity)` が二つの `FieldData` を自由な未知数の位置で標本化して作り、状態 `PdeState` の座標は `[自由な変位, 自由な速度]` の順に並ぶ。
`values(state)` が返す場は Dirichlet の値を戻した変位だけで、速度は `state.coordinates()` の後半から読む。

時間積分の設定は `HyperbolicOptions` が持ち、終端時刻は問題の側が持つ。
`HyperbolicOptions::new()` は適応刻みの Dormand–Prince 5(4) 法（`scioxide_ode::DormandPrince5`）、相対・絶対とも $10^{-8}$ の二乗平均の局所誤差許容、`CflPolicy::Automatic`、試行刻み 100,000 回の上限を選ぶ。
`with_initial_step(step)` は局所誤差制御の最初の刻みで、固定刻みではない。
`with_error_tolerance`、`with_cfl_policy`、`with_step_budget`、`with_budgets`、`with_output_schedule` で各項目を替え、`with_ode_method` で `scioxide-ode` の別の組み込みの積分法に替える。
放物型の `ParabolicOptions` と違い、方式の列挙、段の後端、Rannacher 起動の設定は持たない。

## CFL 条件と陽解法の安定限界

$u_{tt}=c^2u_{xx}$ の解は特性曲線 $x\pm ct=\text{一定}$ に沿って速さ $c$ で伝わる。
点 $(x,t)$ の解が依存する初期データの範囲 $[x-ct,\,x+ct]$ を、物理的な依存領域と呼ぶ。
格子幅 $h$、刻み $\Delta t$ の陽的な差分が $(x,t)$ の値を計算するときに参照する初期格子点の範囲を、数値的な依存領域と呼ぶ。

Courant–Friedrichs–Lewy の定理は、数値的な依存領域が物理的な依存領域を含むことが収束の必要条件だと述べる。
含まなければ、依存領域の外の初期データを変えても数値解は変わらないので、格子を細かくしても真の解に近づけない。
隣の格子点だけを参照する 1 段の陽解法では、この条件は Courant 数（CFL 数）

$$
\nu=\frac{c\,\Delta t}{h}
$$

について $\nu\le1$ になる。

CFL 条件は必要条件であり、安定性を保証しない。
線の方法で使う陽的な Runge–Kutta 法の安定性は、固有値 $\pm\mathrm{i}\,\omega_j$ に刻みを掛けた $\pm\mathrm{i}\,\omega_j\Delta t$ が、安定関数 $R(z)$ の安定領域 $\lvert R(z)\rvert\le1$ に入るかで決まる。
Dormand–Prince 5(4) 法の安定関数は $R(z)=\sum_{k=0}^{5}z^k/k!+z^6/600$ で、虚軸上の安定区間は $\lvert y\rvert\le0.9972$（$z=\mathrm{i}y$）である。
一様格子の 2 次中心差分では最大の $\omega_j$ が $2c/h$ に近づくので、安定の条件は $2\nu\le0.9972$、すなわち $\nu\le0.4986$ になり、CFL 条件 $\nu\le1$ より厳しい。
前進 Euler 法の安定領域は虚軸と原点でしか交わらず、波動方程式にはどの刻みでも不安定である。

`CflPolicy` は、この安定限界を刻みの上限として ODE の積分法に渡す方法を選ぶ。

- `CflPolicy::Automatic`（既定）は質量で割ったヤコビアン $\mathbf{M}^{-1}\mathbf{K}$ の行の絶対値和の最大 $\rho$（Gershgorin の円による固有値の上界）と、積分法が `scioxide_ode::OdeLinearStability` で提示する虚軸の安定区間 $\beta_I$ から、刻みの上限 $0.9\,\beta_I/\sqrt\rho$ を求める。
  Dormand–Prince 5(4) 法は $\beta_I=0.9971$ を提示するので、一様格子の FDM（$\rho=4c^2/h^2$）では $\nu\le0.4487$ に当たる。
  安定領域を提示しない積分法や、虚軸で不安定な積分法（前進 Euler 法のように提示する長さが 0）を `with_ode_method` で選ぶと、`advance` は数値計算を始める前に `InvalidInput` のエラーを返す。
- `CflPolicy::MaximumStep(h_max)` は、正で有限の上限 $h_{\max}$ をそのまま使う。
- `CflPolicy::Disabled` は上限を付けず、刻みを局所誤差制御だけに任せる。

積分法は、各刻みの前にこの上限、局所誤差制御が提案する刻み、終端までの残りの区間のうち最小のものを選ぶ。
$\rho$ は Gershgorin の上界なので、不均一な格子や係数でも上限は安定側にずれる。
ただしこの上界は、固有値が虚軸上にある（減衰項を持たない）ことを仮定している。
多次元の一様格子では $\rho=4c^2\sum_d h_d^{-2}$ なので、許される刻みは次元とともに小さくなる。

## CflPolicy と刻みの選択

自動の上限が実際の計算でどう働くかを、弾いた弦で確かめる。
長さ 1、波の速さ $c=1$ の両端固定の弦を `StructuredFdmPlan::dirichlet_laplacian` の一様格子で離散化し、$x=0.3$ を高さ 0.1 だけ持ち上げた三角形の初期変位、初速度 0 から、基本振動の 1 周期 $T=2$ まで `HyperbolicProblem` で進める。
三角形の初期変位は格子で表せるすべての波長を含むので、刻みが安定限界を超えると短い波長の成分が増えようとする。

セルは同じ問題を三つの `CflPolicy` で解く。
`Automatic` の上限 $0.9\beta_I h/(2c)$、その上限に倍率を掛けた `MaximumStep`、上限を付けない `Disabled` である。
各計算について、試行した刻み・受理した刻み・棄却した刻みの数、受理した刻みの平均の Courant 数 $\bar\nu=T/(n_{\mathrm{acc}}h)$、離散エネルギー $E_h$ の相対変化、終了理由を表にする。
独立な検算は、半離散系が厳密に保つ $E_h$ である。

```rust
//| id: pde-wave-cfl-policy
//| ref: pde-wave-cfl-policy
//| title: CflPolicy を替えて弾いた弦の刻みとエネルギーを比べる
//| run: reactive
//| crates: [scioxide-pde, scioxide-ode, scioxide-core]
//| inputs:
//|   nodes: {"type":"range","label":"格子点数 N [-]","description":"格子幅 h = 1/(N − 1) と安定限界の刻みを変える。","min":21,"max":201,"step":20,"value":81}
//|   tolerance_digits: {"type":"range","label":"局所誤差許容の桁数 d [-]","description":"相対・絶対の許容誤差 10^(−d) を変える。","min":2,"max":10,"step":1,"value":3}
//|   step_factor: {"type":"range","label":"MaximumStep の倍率 [-]","description":"Automatic の上限に掛ける倍率を変える。","min":0.5,"max":3,"step":0.25,"value":2}
//| cases:
//|   - {"id":"tight-tolerance","label":"許容誤差 10⁻⁶","description":"誤差制御の刻みが安定限界より小さく、三つの方針がほぼ同じ刻みを選ぶ。","inputs":{"tolerance_digits":6}}
//|   - {"id":"very-loose","label":"許容誤差 10⁻²","description":"Disabled では短い波長が増え続け、エネルギーが千倍を超える。","inputs":{"tolerance_digits":2}}
//|   - {"id":"half-step","label":"倍率 0.5","description":"MaximumStep が Automatic の上限より小さく、刻みの数が倍になる。","inputs":{"step_factor":0.5}}
//|   - {"id":"fine-grid","label":"N = 201","description":"格子幅が小さくなり、Automatic の刻みも同じ割合で小さくなる。","inputs":{"nodes":201}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"policies","path":"/rows/0/4","range":{"min":0.44,"max":0.4487}}
//|       - {"artifact":"policies","path":"/rows/0/5","range":{"min":-0.001,"max":0}}
//|       - {"artifact":"policies","path":"/rows/1/5","range":{"min":0.05}}
//|       - {"artifact":"policies","path":"/rows/2/5","range":{"min":0.05}}
//|       - {"path":"/outputs/1/state","equals":"satisfied"}
//|   - case: tight-tolerance
//|     expect:
//|       - {"artifact":"policies","path":"/rows/2/4","range":{"max":0.4487}}
//|       - {"artifact":"policies","path":"/rows/2/5","range":{"min":-0.001,"max":0.001}}
//|   - case: very-loose
//|     expect:
//|       - {"artifact":"policies","path":"/rows/2/5","range":{"min":100}}
//|   - case: half-step
//|     expect:
//|       - {"artifact":"policies","path":"/rows/1/2","approx":{"value":714,"atol":2}}
//|       - {"artifact":"policies","path":"/rows/1/5","range":{"min":-0.0001,"max":0}}
//|   - case: fine-grid
//|     expect:
//|       - {"artifact":"policies","path":"/rows/0/2","approx":{"value":892,"atol":2}}
use scioxide_core::{ErrorTolerance, ExecutionContext, NormSelection, Tolerance};
use scioxide_ode::{DormandPrince5, OdeLinearStability, OdeMethod};
use scioxide_pde::{
    CflPolicy, FieldData, FieldPoint, HyperbolicOptions, HyperbolicProblem, StructuredFdmPlan,
};

let n = nodes.round() as usize;
let digits = tolerance_digits.round() as u32;
let h = 1.0 / (n - 1) as f64;
let end = 2.0;
let plan =
    StructuredFdmPlan::dirichlet_laplacian([0.0], [1.0], [n]).map_err(|e| e.to_string())?;
let source = FieldData::zero();
let problem = HyperbolicProblem::new(&plan, &source, end).map_err(|e| e.to_string())?;
// x = 0.3 を高さ 0.1 だけ持ち上げた三角形（弾いた弦）。
let pluck = FieldData::time_invariant(|p: FieldPoint<f64, 1>| {
    let x = p.point[0];
    Ok(if x < 0.3 {
        0.1 * x / 0.3
    } else {
        0.1 * (1.0 - x) / 0.7
    })
});
let rest = FieldData::zero();
// 離散エネルギー E_h = ½ h Σ v² + ½ Σ (u_{i+1} − u_i)²/h（自由な未知数は内部の格子点）。
let energy = |coordinates: &[f64]| {
    let (u, v) = coordinates.split_at(n - 2);
    let kinetic: f64 = v.iter().map(|vi| 0.5 * h * vi * vi).sum();
    let strain: f64 = (0..n - 1)
        .map(|i| {
            let left = if i == 0 { 0.0 } else { u[i - 1] };
            let right = if i == n - 2 { 0.0 } else { u[i] };
            0.5 * (right - left) * (right - left) / h
        })
        .sum();
    kinetic + strain
};
let OdeLinearStability::Axes {
    imaginary: Some(beta),
    ..
} = DormandPrince5::<f64>::new().linear_stability()
else {
    return Err("DormandPrince5 が虚軸の安定区間を提示しない".to_string());
};
let automatic_cap = 0.9 * beta * h / 2.0;
let policies = [
    ("Automatic", CflPolicy::Automatic),
    (
        "MaximumStep",
        CflPolicy::MaximumStep(step_factor * automatic_cap),
    ),
    ("Disabled", CflPolicy::Disabled),
];
let tolerance = ErrorTolerance::from_tolerance(
    Tolerance::from_decimal_places(digits, digits),
    NormSelection::RootMeanSquare,
);
let mut rows = Vec::new();
let mut automatic_report = None;
for (name, policy) in policies {
    let options = HyperbolicOptions::new()
        .with_error_tolerance(tolerance.clone())
        .with_cfl_policy(policy);
    let mut state = problem
        .initial_state(&pluck, &rest)
        .map_err(|e| e.to_string())?;
    let initial_energy = energy(state.coordinates());
    let mut workspace = problem.workspace().map_err(|e| e.to_string())?;
    let report = problem
        .advance(
            &options,
            &mut state,
            &mut (),
            &mut workspace,
            ExecutionContext::sequential(),
        )
        .map_err(|e| e.to_string())?;
    let d = report.diagnostics();
    rows.push((
        name,
        d.num_time_steps(),
        d.num_accepted_steps(),
        d.num_rejected_steps(),
        report.final_time() / (d.num_accepted_steps() as f64 * h),
        (energy(state.coordinates()) - initial_energy) / initial_energy,
        report.termination().to_string(),
    ));
    if name == "Automatic" {
        automatic_report = Some(report);
    }
}
let fixed4 = serde_json::json!({ "notation": "standard", "fractionDigits": 4 });
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let columns = serde_json::json!([
    { "key": "0", "label": "CflPolicy" },
    { "key": "1", "label": "試行した刻み [回]", "type": "integer" },
    { "key": "2", "label": "受理 [回]", "type": "integer" },
    { "key": "3", "label": "棄却 [回]", "type": "integer" },
    { "key": "4", "label": "平均の Courant 数 ν̄ [-]", "type": "number", "format": fixed4 },
    { "key": "5", "label": "E_h の相対変化 [-]", "type": "number", "format": sci3 },
    { "key": "6", "label": "終了理由" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "policies" })
);
let report = automatic_report.ok_or("Automatic の結果がない")?;
let d = report.diagnostics();
let outcome = if report.is_success() {
    Outcome::satisfied("Automatic の計算が終端時刻 T = 2 に達した")
} else {
    Outcome::partial("Automatic の計算が終端時刻の前に止まった")
        .explanation("状態は最後に受理した時刻の値で、終端時刻の解ではない。")
};
emit_outcome!(
    outcome
        .status(report.termination().to_string())
        .diagnostic("到達時刻", report.final_time(), None)
        .diagnostic("受理した刻み", d.num_accepted_steps() as f64, None)
        .diagnostic("刻みの上限 0.9β_I h/2", automatic_cap, None)
);
```

許容誤差 $10^{-3}$、$N=81$ の既定では、`Automatic` は上限 $\Delta t=5.61\times10^{-3}$ で 357 刻みを受理し、平均の Courant 数は 0.448 で、$E_h$ の相対変化は $-1.7\times10^{-4}$ だった。
この減少は Dormand–Prince 5(4) 法の $\lvert R(\mathrm{i}y)\rvert<1$ による弱い数値散逸である。
`MaximumStep` で上限を 2 倍にすると $\bar\nu=0.894$ で棄却なしに終端まで進み、$E_h$ は 27 % 増えた。
`Disabled` も $\bar\nu=0.879$ まで刻みを広げ、棄却は 6 回だけで、$E_h$ はほぼ 2 倍になった。
どちらも終了理由は `Completed` である。
局所誤差の推定が許容誤差を下回ったまま短い波長の成分が増えたので、終了理由だけでは安定に解けたかどうかは分からない。
許容誤差を $10^{-2}$ にすると、`Disabled` の $E_h$ は 1,000 倍を超える。

許容誤差を $10^{-6}$ にすると、局所誤差制御の刻み（$\bar\nu\approx0.33$）が安定限界より小さくなり、三つの方針はほぼ同じ刻みを選ぶ。
倍率 0.5 の `MaximumStep` は刻みを 2 倍の 714 回に増やし、エネルギーの変化を $-1.5\times10^{-5}$ に減らす。
$N=201$ では `Automatic` の刻みも格子幅に比例して小さくなり、受理した刻みは 892 回に増える。

## まとめ

波動方程式は変位と速度の一階系に直すと、固有値が虚軸上に並び、固定端と自由端で離散エネルギーを保つ半離散系になる。
CFL 条件は収束の必要条件にすぎず、`HyperbolicProblem` の既定の Dormand–Prince 5(4) 法では安定の条件 $\nu\le0.4986$ が刻みを決める。
`CflPolicy::Automatic` は Gershgorin の上界と積分法の安定区間から刻みの上限 $0.9\beta_I/\sqrt\rho$ を求める。
`MaximumStep` で上限を広げたり `Disabled` で外したりすると、ゆるい許容誤差では終了理由が `Completed` のまま解が不安定になりうる。
刻みの方針を替えたときは、終了理由とは別に離散エネルギー $E_h$ の推移を確かめる。
