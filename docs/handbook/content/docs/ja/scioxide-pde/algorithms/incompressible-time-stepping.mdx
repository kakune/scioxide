このページは[非圧縮流れの混合有限要素](../incompressible-flow/)の空間離散化を時間方向に進める方法を扱う。
`IncompressibleSystem` は速度だけを状態とする ODE 系で、圧力は右辺を評価するたびに速度質量の鞍点系から求める。
導出、拘束の欠陥の扱い、刻みの上限、初期値の射影を説明し、静止した流体が Poiseuille 流に近づく過程をセルで追う。
定常の鞍点系の前処理と Navier–Stokes 方程式の Newton 法は[非圧縮流れの鞍点系の解法](../incompressible-solvers/)、ODE の方法は[常微分方程式](../../../scioxide-ode/)の章にある。

---

## 速度と圧力の微分代数方程式

非定常の Stokes 方程式を空間だけ離散化すると、

$$
M\dot{\mathbf{u}}+A\mathbf{u}+B^{\mathsf T}\mathbf{p}=\mathbf{f},\qquad B\mathbf{u}=\mathbf{g}
$$

になる。
圧力には時間微分がない。
拘束 $B\mathbf{u}=\mathbf{g}$ を時間で 1 回微分すると $\mathbf{p}$ が代数的に決まり、$\mathbf{p}$ の微分方程式を得るにはさらに 1 回の微分が要るので、この系は指数 2 の微分代数方程式（DAE）である。
$\mathbf{g}$ が時刻に依らなければ $B\dot{\mathbf{u}}=0$ なので、加速度 $\mathbf{a}=\dot{\mathbf{u}}$ と圧力は速度質量の鞍点系

$$
\begin{pmatrix}M&B^{\mathsf T}\\B&0\end{pmatrix}\begin{pmatrix}\mathbf{a}\\\mathbf{p}\end{pmatrix}=\begin{pmatrix}\mathbf{f}-A\mathbf{u}\\-\mathbf{d}/\tau\end{pmatrix},\qquad \mathbf{d}=B\mathbf{u}-\mathbf{g}
$$

で決まる。
Navier–Stokes 方程式では、右辺の $\mathbf{f}-A\mathbf{u}$ から移流項 $\mathbf{c}(\mathbf{u})$ を引く。
右下の $-\mathbf{d}/\tau$ は拘束の欠陥を時定数 $\tau$ で 0 に戻す項で、欠陥は $\dot{\mathbf{d}}=-\mathbf{d}/\tau+\mathbf{e}$（$\mathbf{e}$ は鞍点系の残差）に従う。
したがって長時間の欠陥は刻みの数に比例して積み上がらず、$\tau\|\mathbf{e}\|$ と丸めの大きさにとどまる。

## `IncompressibleSystem` と作業領域

`IncompressibleSystem::stokes(plan, &mut work, forcing, maximum_step)` と `navier_stokes(…)` は、この右辺を `scioxide_ode::OdeSystem` として結合する。
状態は Dirichlet 条件のない P2 速度の座標（`free_velocity_indices` の順）で、圧力は積分せず、右辺を評価するたびに鞍点系から求める。
`forcing` は時刻に依存する単位体積あたりの体積力を加え、メッシュと境界の速度は固定である。
陰的なヤコビ行列を提供しないので、陽的な ODE の方法を使う。
`IncompressibleTimeWorkspace::new(plan, &options)` は GMRES、`VelocityMass` のライブラリ前処理、すべての作業用の配列を準備し、`with_linear_solver`・`with_preconditioner` で置き換えられる。
各評価では鞍点系の真の残差を独立に検査し、`options` の許容誤差を超えると `ConvergenceFailure` を返す。

## 陽的な方法の刻みの上限

陽的な方法の刻みは粘性で制限される。
P2 要素の逆不等式から、$\tau$ は $h^2\rho/(64D\mu)$ のセルごとの最小値（$h$ はセルの最小の高さ）で、`maximum_step` がそれより小さければ `maximum_step` を使う。
`step_limit` はこの $\tau$ を返し、Navier–Stokes では標本点ごとの移流の制限 $h/(10D|u|)$ の最小値と比べて小さいほうを返す。
`scioxide-ode` の管理された刻みはこの上限を守り、刻みを自分で選ぶときは呼び出し側が `step_limit` を適用する。
$\tau\propto h^2$ なので、格子を半分にすると刻みの数は 4 倍になる。

## 初期速度の射影と場の回復

初期速度は離散的な連続の式を満たす必要がある。
`validate_velocity(y)` はそれを検査し、満たさなければ `InvalidInput` を返す。
`project_velocity_into(y, &mut out, ctx)` は、質量行列の内積で最も近い、連続の式を満たす速度に射影する。
`out` は、鞍点系の求解が収束して残差と連続の式を独立に検査したあとにだけ書き換わる。
`recover_into(t, y, &mut out, ctx)` は時刻 $t$ の速度、圧力、ゲージの乗数を未知数の並びで返す。

## 立ち上がり流れの計算

次のセルは閉じた流路の内部の速度を 0 にした状態を射影して初期値とし、Dormand–Prince 5(4) 法で粘性時間 $T=\rho H^2/\mu$ の 0.4 倍まで進める。
$\mu=0.1$ Pa·s（$T=10$ s）とし、各時刻で Poiseuille 流との最大節点誤差と、離散的な連続の式の欠陥を読む。

```rust
//| id: pde-incompressible-startup
//| ref: pde-incompressible-startup
//| title: 静止した流体が Poiseuille 流に近づく過程を拘束速度の ODE で追う
//| run: button
//| timeoutMs: 120000
//| crates: [scioxide-pde, scioxide-spatial, scioxide-core, scioxide-ode, scioxide-linalg]
//| inputs:
//|   cells: {"type":"range","label":"高さ方向のセル数 n [-]","description":"刻みの上限は最小の高さの 2 乗に比例して小さくなる。","min":1,"max":3,"step":1,"value":2}
//| cases:
//|   - {"id":"coarse","label":"n = 1","description":"最小の高さが 2 倍になり、受理した刻みは 103 回と既定の約 4 分の 1 になる。","inputs":{"cells":1}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"startup","path":"/rows/0/2","approx":{"value":0.1703036,"rtol":1e-5}}
//|       - {"artifact":"startup","path":"/rows/3/2","approx":{"value":4.05998e-6,"rtol":1e-3}}
//|       - {"artifact":"startup","path":"/rows/5/2","range":{"min":0,"max":1e-8}}
//|       - {"artifact":"startup","path":"/rows/5/3","range":{"min":0,"max":1e-9}}
//|       - {"path":"/outputs/1/state","equals":"satisfied"}
//|       - {"path":"/outputs/1/diagnostics/0/value","equals":410}
//|   - case: coarse
//|     expect:
//|       - {"path":"/outputs/1/diagnostics/0/value","equals":103}
//|       - {"artifact":"startup","path":"/rows/0/2","approx":{"value":0.0613021,"rtol":1e-5}}
use scioxide_core::{
    ExecutionContext, SciOxideError, LinearOperator, ProblemToken, SolveBudgets, SolveIdentity,
    SolveState, algorithm_id,
};
use scioxide_linalg::Vector;
use scioxide_ode::{
    DormandPrince5, OdeMethod, OdeOptions, OdeOutputSchedule, OdeProblem, OdeState, OdeSystem,
};
use scioxide_pde::{
    BoundaryData, BoundaryKind, BoundaryPoint, IncompressibleOptions,
    IncompressibleSolveOptions, IncompressibleSystem, IncompressibleTimeWorkspace,
    SimplexFemGeometry, StokesPlan, TaggedBoundaries,
};
use scioxide_spatial::{Point, TriangleMesh};

// Poiseuille 流 u(y) = 4U y (H − y) / H²（U = 1 m/s、H = 1 m）。
let poiseuille = |y: f64| 4.0 * y * (1.0 - y);
// 流路 [0, 2]×[0, 1] [m] を 2n × n の正方形に分け、対角線で三角形にする。
let (nx, ny) = (2 * cells as usize, cells as usize);
let mut points = Vec::new();
for j in 0..=ny {
    for i in 0..=nx {
        let point = [2.0 * i as f64 / nx as f64, j as f64 / ny as f64];
        points.push(Point::new(point).map_err(|e| e.to_string())?);
    }
}
let mut triangles = Vec::new();
for j in 0..ny {
    for i in 0..nx {
        let a = j * (nx + 1) + i;
        triangles.push([a, a + 1, a + nx + 2]);
        triangles.push([a, a + nx + 2, a + nx + 1]);
    }
}
let mesh = TriangleMesh::new(points, triangles).map_err(|e| e.to_string())?;
// 壁では u(y) = 0 なので、入口・出口・壁の速度を一つの Dirichlet 条件で与える。
let data = BoundaryData::time_invariant(move |p: BoundaryPoint<f64, 2>| {
    Ok(if p.component == 0 {
        poiseuille(p.point[1])
    } else {
        0.0
    })
});
let boundaries = TaggedBoundaries::uniform(&mesh, 2, BoundaryKind::Dirichlet, data)
    .map_err(|e| e.to_string())?;
// μ = 0.1 Pa·s、ρ = 1 kg/m³、体積力なし。
let viscosity = 0.1;
let plan = StokesPlan::with_options(
    mesh,
    SimplexFemGeometry::Affine,
    1.0,
    viscosity,
    &boundaries,
    &|_| Ok([0.0; 2]),
    IncompressibleOptions::new(),
)
.map_err(|e| e.to_string())?;
let options = IncompressibleSolveOptions::new();
let mut work = IncompressibleTimeWorkspace::new(&plan, &options).map_err(|e| e.to_string())?;
let system =
    IncompressibleSystem::stokes(&plan, &mut work, None, 1.0).map_err(|e| e.to_string())?;
// 射影と回復は呼び出し側の求解コンテキストで行う。識別は任意の値でよい。
let mut solve_state = SolveState::new();
let mut budgets = SolveBudgets::unbounded();
let token = ProblemToken::new(1);
let identity = SolveIdentity::new(token, algorithm_id!("handbook", "startup", 1), 0, 0);
let mut context = solve_state
    .begin_solve(ExecutionContext::sequential(), identity, &mut budgets)
    .map_err(|e| e.to_string())?;
// 内部の速度 0 を、境界の速度と離散的な連続の式に合わせて射影する。
let zero = vec![0.0; system.dimension()];
let mut initial = vec![0.0; zero.len()];
system
    .project_velocity_into(&zero, &mut initial, &mut context)
    .map_err(|e| e.to_string())?;
// 粘性時間 T = ρH²/μ の分数で出力する。
let viscous_time = 1.0 / viscosity;
let fractions = [0.01, 0.02, 0.05, 0.1, 0.2, 0.4];
let times: Vec<f64> = fractions.iter().map(|f| f * viscous_time).collect();
let end = times[times.len() - 1];
let schedule = OdeOutputSchedule::Times {
    times,
    initial: false,
    final_state: false,
};
let ode_options = OdeOptions::new().with_output_schedule(schedule);
let solution = DormandPrince5::new()
    .solve(
        &OdeProblem::new(&system, end),
        &ode_options,
        OdeState::new(0.0, Vector::from_vec(initial)),
    )
    .map_err(|e| SciOxideError::from(e).to_string())?;
let mut full = vec![0.0; plan.unknowns()];
let mut scratch = vec![0.0; plan.apply_workspace_len().map_err(|e| e.to_string())?];
let mut rows = Vec::new();
for (fraction, state) in fractions.iter().zip(solution.trajectory().states()) {
    let time = fraction * viscous_time;
    system
        .recover_into(time, state.as_slice(), &mut full, &mut context)
        .map_err(|e| e.to_string())?;
    let mut error = 0.0_f64;
    for i in 0..plan.velocity_nodes() {
        let y = plan.node_point(i).map_err(|e| e.to_string())?[1];
        error = error.max((full[i] - poiseuille(y)).abs());
    }
    let diagnostics = plan
        .diagnostics(&full, 1.0, 0.0, &mut scratch)
        .map_err(|e| e.to_string())?;
    rows.push((*fraction, time, error, diagnostics.weak_divergence()));
}
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let columns = serde_json::json!([
    { "key": "0", "label": "t / T [-]", "type": "number" },
    { "key": "1", "label": "時刻 t [s]", "type": "number" },
    { "key": "2", "label": "Poiseuille 流との最大差 [m/s]", "type": "number", "format": sci3 },
    { "key": "3", "label": "弱形式の発散 [m²/s]", "type": "number", "format": sci3 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "startup" })
);
let report = solution.report();
// termination() が None なのは失敗した試行の途中経過だけなので failed にする。
let outcome = if report.is_success() {
    Outcome::satisfied("終了時刻まで積分した")
} else if report.termination().is_none() {
    Outcome::failed("積分が終了理由を残さずに止まった")
} else {
    Outcome::partial("終了時刻の前に積分が止まった")
};
let status = report
    .termination()
    .map_or_else(|| "None".to_string(), |t| format!("{t:?}"));
emit_outcome!(
    outcome
        .status(status)
        .diagnostic("受理した刻み", report.accepted_steps() as f64, None)
        .diagnostic("棄却した刻み", report.rejected_steps() as f64, None)
);
```

既定（$n=2$）では、射影した初期値と Poiseuille 流の差は $t/T=0.01$ で 0.17 m/s、$0.05$ で $1.2\times10^{-3}$ m/s、$0.1$ で $4.1\times10^{-6}$ m/s と指数的に減る。
$t/T=0.4$ では $1.3\times10^{-9}$ m/s になる。
離散的な連続の式の欠陥は全時刻で $2.5\times10^{-11}$ m²/s 以下にとどまり、刻みを重ねても積み上がらない。
Dormand–Prince 法は 410 回の刻みをすべて受理した。
刻みは誤差の制御ではなく $D=2$ の上限 $\tau=h^2\rho/(128\mu)$ で決まり、$n=1$ では 103 回、$n=3$ では 922 回と $n^2$ に比例する。

## まとめ

非定常の非圧縮流れは圧力を Lagrange 乗数とする指数 2 の DAE で、`IncompressibleSystem` は加速度と圧力を速度質量の鞍点系から求めて速度だけの ODE にする。
拘束の欠陥は時定数 $\tau$ で戻されるので、長時間積分しても鞍点系の残差と $\tau$ の積の大きさにとどまる。
陽的な方法の刻みは $\tau=h^2\rho/(64D\mu)$ で決まり、格子を半分にすると刻みの数は 4 倍になるので、格子の細かさと積分の計算コストを合わせて選ぶ。
初期速度は `project_velocity_into` で離散的な連続の式に合わせてから積分し、圧力が要る時刻では `recover_into` で求める。
