この節の各ページは偏微分方程式を空間について離散化し、得られた代数方程式や常微分方程式系を解くときの数理と API を説明する。
ここでは各ページが前提にする記号と約束、誤差の分け方、ページの一覧をまとめる。

## 記号

| 記号 | 意味 |
|---|---|
| $\Omega=[a,b]$、$\Omega\subset\mathbb{R}^D$ | 領域（一次元の区間、または $D=2,3$ 次元の領域） |
| $u$、$u_h$ | 厳密解と離散解 |
| $k(x)$、$K(x)$ | スカラーの拡散係数（熱伝導率など）と拡散テンソル |
| $c(x)$、$f(x,t)$ | 反応係数と源項 |
| $x_0<x_1<\dots<x_N$、$h_i=x_{i+1}-x_i$ | 一次元の頂点と区間の幅、$h=\max_i h_i$ |
| $\mathbf{n}$、$\partial u/\partial n$ | 外向きの単位法線と、その方向の微分。区間の左端では $-u'$、右端では $u'$ |
| $\mathbf{n}\cdot K\nabla u$ | 外向きの余法線流束。一次元では $k\,\partial u/\partial n$ |
| $q=-k\,\partial u/\partial x$ | 右向きの物理流束 |
| $A$、$M$、$\mathbf{b}(t)$ | 空間の Plan が組み立てる作用素、集中質量（正の対角）、時刻 $t$ の荷重 |
| $\mathbf{M}$、$\mathbf{K}$、$\mathbf{F}$ | 半離散系 $\mathbf{M}\dot{\mathbf{u}}+\mathbf{K}\mathbf{u}=\mathbf{F}$ の質量行列、剛性行列、荷重。API の記法では $M\mathbf{u}'=\mathbf{b}(t)-A\mathbf{u}$（$A=\mathbf{K}$、$\mathbf{b}=\mathbf{F}$） |
| $\Delta t$、$\nu=c\Delta t/h$、$r=\alpha\Delta t/h^2$ | 時間刻み、波動の Courant 数（$c$ は波の速さ）、拡散の Fourier 数（$\alpha$ は拡散率） |

## 共通の約束

### Plan と求解の分担

空間の Plan（`StructuredFdmPlan`、`SimplexFemPlan`、`StructuredFvmPlan`、`SimplexFvmPlan`）は、時刻に依存しない作用素 $A$、正の集中質量 $M$、任意の時刻の荷重 $\mathbf{b}(t)$ を組み立て、共通の約束 `SpatialDiscretization` を実装する。
`EllipticProblem`・`ParabolicProblem`・`HyperbolicProblem` はどの Plan も同じ手順で解き、定常の求解はデータを時刻 0 で評価する。
弾性体、非圧縮流れ、保存則、適応細分化の Plan は自分の求解の手段を持つか、`scioxide-linalg`・`scioxide-sparse`・`scioxide-rootfind`・`scioxide-ode` の解法に残差や作用素を渡す。

### 設定・準備・実行

どの操作も設定、準備、実行の順に進む。
準備した Plan は不変で `Send + Sync + Clone` であり、繰り返す求解のメモリ領域と最後の試行の記録は、呼び出し側が持つ作業領域に置く。
関数は呼び出し元の識別子を受け取らない。

### 未知数の並びと場の配置

未知数は成分ごとにまとまって並ぶ（成分優先）。
FDM と P1 の FEM の未知数は頂点、P2 の FEM では頂点と辺の中点、FVM ではセルにある。
一次元の FVM は $N+1$ 頂点に対して $N$ 個のセル値を返し、その値は中点則によるセル平均の近似である。
各未知数の位置と成分は `SpatialDiscretization::dof_point` で読める。
頂点の場とセルの場は `scioxide-spatial` の型で区別され、比べるときは同じ評価点へ補間するか、流束や積分量で比べる。

### Dirichlet 条件の消去

Dirichlet 条件で決まる未知数の行と列は単位行列の形にし、その値は荷重から入る。
消去は対称に行うので、対称な問題は対称な行列になる。

### 境界の符号

Neumann・Robin のデータは全ての離散化で外向きの余法線流束 $\mathbf{n}\cdot K\nabla u$ であり、法線微分そのものではない。
物理的な外向きの拡散流束 $q_n=-\mathbf{n}\cdot K\nabla u$ とは符号が逆で、データは $g=-q_n$ である。
Robin のデータは $\mathbf{n}\cdot K\nabla u+\alpha u=g$ で、流束の係数は 1 に固定される。

### メッシュの同一性

境界条件の集合と場はメッシュの族と revision（`MeshToken`）を保持し、座標が同じでも別に作ったメッシュのものは実行時に拒否される。

### 終了理由とエラー

求解の成否は `PdeTermination` だけで判定し、`is_success()` が真になるのは `Completed` だけである。
作業領域に注入した反復法が上限で止まった場合などは、未完了の終了理由のレポートが `Ok` で返る。
入力、コールバック、組立、分解の失敗は `SciOxideError` で返り、分類は `kind()` と `view()` で読む。

## 誤差の分解

数値解の誤差は空間離散化、時間積分、代数方程式の停止判定、丸めの和で上から抑えられる。

$$
\|u-u_h\|\le e_{\mathrm{space}}(h^p)+e_{\mathrm{time}}(\Delta t^q)+e_{\mathrm{linear}}+e_{\mathrm{round}}
$$

$p$ と $q$ は空間と時間の収束次数である。
空間と時間を同時に細かくすると、どちらの誤差が減ったのかを区別できない。
空間の次数は刻みを十分小さく固定して $h$ を半分ずつにし、時間の次数は格子を固定して $\Delta t$ を半分ずつにして測る。
内側の線形解法の許容誤差は離散化誤差より 2〜3 桁小さく選ぶ。
`PdeDiagnostics` の残差は $e_{\mathrm{linear}}$ の目安であり、$e_{\mathrm{space}}$ の推定ではない。
既知解、製造解（Method of Manufactured Solutions、解を先に決めて源項を逆算する方法）、保存量、異なる離散化の比較で独立に確かめる。

## まとめ

各ページは成分優先の未知数の並び、外向きの余法線流束による境界データ、Dirichlet 条件の対称な消去、`PdeTermination` による成否の判定という同じ約束の上で書かれている。
空間の Plan が作る $A$、$M$、$\mathbf{b}(t)$ の意味を押さえれば、どの離散化の結果も同じ求解の Plan で解ける。
誤差は空間・時間・代数・丸めに分けて測り、残差の小ささを離散化の精度と取り違えない。
