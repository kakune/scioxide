断熱材と金属を重ねた壁のように、材料の境目で伝導率が飛ぶ問題は多い。
係数が不連続なところでは解の導関数も不連続になるので、離散化が係数をどこで読むかによって精度が大きく変わる。
このページでは界面の条件から直列抵抗の式を導き、[楕円問題の FDM・FEM・FVM](../elliptic-fdm-fem-fvm/)の三つの離散化が界面をどう扱うかを、界面の位置を変えて確かめる。

## 界面の条件と直列抵抗

伝導率 $k_L$、$k_R$ の二つの材料が $x=s$ で接しているとする。
界面で温度が連続で、界面に熱が溜まらないなら、温度と流束が界面の両側で等しい。

$$
u(s^-)=u(s^+),\qquad -k_L\,u'(s^-)=-k_R\,u'(s^+)
$$

流束が等しく伝導率が違うので、温度の勾配 $u'$ は界面で飛び、解は界面で折れ曲がる。

界面をはさむ二点 $x_L<s<x_R$ の間の熱の流れを考える。
距離を $d_L=s-x_L$、$d_R=x_R-s$ とすると、二つの区間の熱抵抗 $R_L=d_L/k_L$、$R_R=d_R/k_R$ が直列につながる。
二点の間の流束は $q=(u_L-u_R)/(R_L+R_R)$ で、実効的な伝導率は重み付きの調和平均になる。

$$
k^{\mathrm{eff}}=\frac{d_L+d_R}{d_L/k_L+d_R/k_R}
$$

$d_L=d_R$ なら $k^{\mathrm{eff}}=2k_Lk_R/(k_L+k_R)$ である。
算術平均 $(k_L+k_R)/2$ は伝導率の大きい側に引っ張られ、伝導率の小さい層が流れを制限する直列の構造を表せない。
たとえば $k_L=1$、$k_R=100$ では、調和平均は約 1.98、算術平均は 50.5 である。

## 係数を標本化する場所と界面

三つの離散化は係数を読む場所が違うので、界面を置くべき場所も違う。

- **FVM**（`StructuredFvmPlan`、`SimplexFvmPlan`）はセル中心で拡散係数を読み、そのセル全体の材料とする。
  面の伝導係数は二つの半セルの抵抗を直列につないだ[二点流束近似](oxref:pde-fvm-tpfa)なので、界面がセルの面に一致すれば、材料ごとの値を返すだけで上の調和平均が得られる。
- **FDM**（`StructuredFdmPlan`）は区間の中点で拡散係数を読み、その区間全体の値とする。
  界面が頂点に一致すれば、各区間は一つの材料だけを含む。
- **FEM**（`SimplexFemPlan`）は要素の求積点で係数を読む。
  界面が頂点に一致すれば、各要素は一つの材料だけを含み、求積は滑らかな係数を積分する。

一次元の構造格子では頂点とセルの面が同じ点なので、界面を頂点に合わせれば三つの離散化のどれでも条件が整う。
界面がセルの内部にあると、FVM と FDM はそのセルや区間を一方の材料とみなすので、実効的な界面は最も近い面か頂点にずれる。
界面の位置の誤差は格子幅 $h$ の程度で、解の誤差も $O(h)$ に下がる。
FEM では、界面を含む要素の求積点が界面の両側に分かれ、不連続な係数を多項式の求積で積分するので、誤差は界面と求積点の位置関係で決まる。

## 界面の流束と温度の検算

長さ 1 m の棒を $x=s$ で二つの材料に分け、$u(0)=1$、$u(1)=0$ に保つ（内部の生成はない）。
厳密解は界面で折れ曲がる区分一次関数で、流束は棒のどこでも一定値 $q=1/(s/k_L+(1-s)/k_R)$ である。
下のセルは $k_L=1$ とし、伝導率比 $k_R/k_L$ と界面の位置を入力にする。
$N=20,40,80$ セルの一様な格子で、`IsotropicDiffusion` に材料ごとの伝導率を返させ、FDM、FVM、P1 FEM の三つの Plan で解く。
未知数の位置での温度の最大誤差を比べ、FVM では `StructuredFvmPlan::face_fluxes` で全ての面の流束を再構成して $q$ と比べる。
`face_fluxes` が返すのは、$x$ の増える向きの拡散流束 $-k\,u'$ を面で積分した値（一次元では面の値そのもの）である。

界面の位置は二つから選ぶ。
$s=0.4$ はどの格子でもセルの面に一致する。
$s=1/3$ はどの格子でも面に一致せず、最も近い面までの距離は格子幅の $1/3$ になる。

```rust
//| id: pde-interface-resistance
//| ref: pde-interface-resistance
//| title: 界面の位置を変えて FDM・FVM・FEM の誤差を比べる
//| run: reactive
//| crates: [scioxide-pde, scioxide-spatial, scioxide-core]
//| inputs:
//|   conductivity_ratio: {"type":"range","label":"伝導率比 kR/kL [-]","description":"右の材料の伝導しやすさを変える。","min":0.05,"max":20,"step":0.05,"value":5}
//|   interface: {"type":"select","label":"界面の位置 s","options":["s = 0.4（セルの面に一致）","s = 1/3（セルの内部）"],"value":"s = 0.4（セルの面に一致）"}
//| cases:
//|   - {"id":"inside-cell","label":"界面をセルの内部に置く（s = 1/3）","description":"三つの離散化の誤差が丸め誤差の水準から 10⁻² 程度に上がり、FDM と FVM は N を倍にするごとにほぼ半分になる。","inputs":{"interface":"s = 1/3（セルの内部）"}}
//|   - {"id":"insulating-right","label":"右の材料が 20 倍断熱的（kR/kL = 0.05）","description":"流束は 0.080645 に下がり、界面が面に一致する限り誤差は丸め誤差の水準にとどまる。","inputs":{"conductivity_ratio":0.05}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"interface","path":"/rows/1/2","range":{"min":0,"max":1e-13}}
//|       - {"artifact":"interface","path":"/rows/1/3","range":{"min":0,"max":1e-13}}
//|       - {"artifact":"interface","path":"/rows/0/2","range":{"min":0,"max":1e-13}}
//|       - {"artifact":"interface","path":"/rows/2/2","range":{"min":0,"max":1e-13}}
//|       - {"artifact":"interface","path":"/rows/0/3","equals":null}
//|   - case: inside-cell
//|     expect:
//|       - {"artifact":"interface","path":"/rows/1/2","range":{"min":5e-3,"max":5e-2}}
//|       - {"artifact":"interface","path":"/rows/4/2","range":{"min":2e-3,"max":2e-2}}
//|       - {"artifact":"interface","path":"/rows/7/2","range":{"min":1e-3,"max":1e-2}}
//|   - case: insulating-right
//|     expect:
//|       - {"artifact":"interface","path":"/rows/1/3","range":{"min":0,"max":5e-12}}
//|       - {"artifact":"interface","path":"/rows/1/2","range":{"min":0,"max":1e-13}}
use scioxide_pde::{
    BoundaryData, BoundaryKind, BoundaryPoint, EllipticProblem, FieldData, IsotropicDiffusion,
    SimplexFemGeometry, SimplexFemOrder, SimplexFemPlan, SpatialDiscretization,
    StructuredBoundaries, StructuredFdmPlan, StructuredFvmPlan, TaggedBoundaries,
};
use scioxide_spatial::{
    AxisTopology, Cell, CoordinateAxis, FieldView, Grid1d, IntervalMesh, Point, SegmentMesh,
};

// 解いて、未知数の位置での厳密解との最大誤差と、未知数の座標・値の組を返す。
fn solve<P: SpatialDiscretization<f64, f64, 1>>(
    plan: &P,
    exact: &dyn Fn(f64) -> f64,
) -> Result<(f64, Vec<[f64; 2]>, Vec<f64>), String> {
    let values = EllipticProblem::new(plan, &FieldData::zero())
        .solve()
        .map_err(|e| e.to_string())?;
    let mut profile = Vec::new();
    for (i, &u) in values.iter().enumerate() {
        profile.push([plan.dof_point(i).map_err(|e| e.to_string())?.point[0], u]);
    }
    let error = profile
        .iter()
        .map(|[x, u]| (u - exact(*x)).abs())
        .fold(0.0, f64::max);
    Ok((error, profile, values))
}
let s = if interface.starts_with("s = 0.4") {
    0.4
} else {
    1.0 / 3.0
};
let kr = conductivity_ratio;
// 独立な検算: 直列抵抗による一定の流束と、区分一次の厳密な温度。
let q = 1.0 / (s + (1.0 - s) / kr);
let exact = move |x: f64| {
    if x <= s {
        1.0 - q * x
    } else {
        1.0 - q * s - q * (x - s) / kr
    }
};
let k = IsotropicDiffusion::new(move |x: [f64; 1]| Ok(if x[0] < s { 1.0 } else { kr }));
// 外向き法線が負の左端で u = 1、右端で u = 0。
let ends = BoundaryData::time_invariant(|p: BoundaryPoint<f64, 1>| {
    Ok(if p.normal[0] < 0.0 { 1.0 } else { 0.0 })
});
let exact_points: Vec<[f64; 2]> = (0..=300)
    .map(|i| i as f64 / 300.0)
    .map(|x| [x, exact(x)])
    .collect();
let dashed = serde_json::json!({ "lineType": "dashed" });
let mut series =
    vec![serde_json::json!({ "name": "厳密解", "points": exact_points, "style": dashed })];
let mut rows = Vec::new();
for n in [20_usize, 40, 80] {
    let axis = CoordinateAxis::uniform(0.0, 1.0, n + 1).map_err(|e| e.to_string())?;
    let grid = Grid1d::new([axis], [AxisTopology::Bounded]).map_err(|e| e.to_string())?;
    let mesh = SegmentMesh::new(grid).map_err(|e| e.to_string())?;
    let dirichlet = BoundaryKind::Dirichlet;
    let structured = StructuredBoundaries::uniform(&mesh, 1, dirichlet, ends.clone())
        .map_err(|e| e.to_string())?;
    let fdm =
        StructuredFdmPlan::new(mesh.clone(), &k, &structured).map_err(|e| e.to_string())?;
    let fvm =
        StructuredFvmPlan::new(mesh.clone(), &k, &structured).map_err(|e| e.to_string())?;
    let points = (0..=n)
        .map(|i| Point::new([i as f64 / n as f64]))
        .collect::<Result<Vec<_>, _>>()
        .map_err(|e| e.to_string())?;
    let interval = IntervalMesh::new(points, (0..n).map(|i| [i, i + 1]).collect())
        .map_err(|e| e.to_string())?;
    let tagged = TaggedBoundaries::uniform(&interval, 1, dirichlet, ends.clone())
        .map_err(|e| e.to_string())?;
    let (geometry, p1) = (SimplexFemGeometry::Affine, SimplexFemOrder::P1);
    let fem =
        SimplexFemPlan::new(interval, geometry, p1, &k, &tagged).map_err(|e| e.to_string())?;
    let (fdm_error, fdm_profile, _) = solve(&fdm, &exact)?;
    let (fvm_error, fvm_profile, values) = solve(&fvm, &exact)?;
    let (fem_error, fem_profile, _) = solve(&fem, &exact)?;
    // FVM の面の流束（x の増える向き）を全ての面で再構成し、一定の流束 q と比べる。
    let cells = FieldView::<_, Cell, 1>::new(&mesh, &values).map_err(|e| e.to_string())?;
    let fluxes = fvm
        .face_fluxes::<0>(cells, 0.0)
        .map_err(|e| e.to_string())?;
    let flux_error = fluxes
        .values()
        .iter()
        .map(|f| (f - q).abs())
        .fold(0.0, f64::max)
        / q;
    rows.push(("FDM", n, fdm_error, None));
    rows.push(("FVM", n, fvm_error, Some(flux_error)));
    rows.push(("FEM P1", n, fem_error, None));
    if n == 20 {
        for (name, profile) in [
            ("FDM", fdm_profile),
            ("FVM", fvm_profile),
            ("FEM P1", fem_profile),
        ] {
            let style = serde_json::json!({ "symbol": "circle", "showSymbol": true });
            let name = format!("{name}（N = 20）");
            series.push(serde_json::json!({ "name": name, "points": profile, "style": style }));
        }
    }
}
emit_line_chart!(
    &series,
    options = &serde_json::json!({
        "xLabel": "棒の位置 x [m]",
        "yLabel": "温度 u [-]",
        "yMin": 0.0,
        "yMax": 1.0,
        "annotations": [{ "kind": "line", "axis": "x", "value": s, "label": "材料界面" }]
    })
);
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let columns = serde_json::json!([
    { "key": "0", "label": "離散化" },
    { "key": "1", "label": "セルの数 N", "type": "integer" },
    { "key": "2", "label": "温度の最大誤差 [-]", "type": "number", "format": sci2 },
    { "key": "3", "label": "面の流束の最大相対誤差 [-]", "type": "number", "format": sci2, "nullText": "-" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "interface" })
);
```

既定（$k_R/k_L=5$、$s=0.4$）では、厳密な流束は $q=1/(0.4+0.6/5)\approx1.923$ である。
三つの離散化の温度の誤差はどの格子でも $2\times10^{-14}$ 以下で、FVM の面の流束の相対誤差は $10^{-13}$ 以下だった。
区分一次の厳密解は、界面が頂点に一致すればどの離散化でも表せる関数なので、誤差は丸め誤差の水準になる。

$s=1/3$ にすると、$N=20$、40、80 の温度の誤差は FDM で $1.8\times10^{-2}$、$1.0\times10^{-2}$、$4.9\times10^{-3}$、FVM で $1.9\times10^{-2}$、$9.7\times10^{-3}$、$5.0\times10^{-3}$ になった。
$N$ を倍にするごとにほぼ半分になるので、収束は一次である。
FVM の面の流束の相対誤差も $2.8\times10^{-2}$、$1.4\times10^{-2}$、$7.1\times10^{-3}$ と半分ずつ減る。
流束はどの面でも同じ値のまま、実効的な界面がずれた分だけ厳密な $q$ からずれる。

P1 FEM の誤差は $2.9\times10^{-2}$、$5.0\times10^{-3}$、$7.5\times10^{-3}$ で、$N$ に対して単調に減らない。
2 点 Gauss 則の求積点は要素の長さの約 0.211 と 0.789 の位置にあり、$s=1/3$ を含む要素ではどの $N$ でも二つの点が両側の材料に一つずつ入る。
その要素の剛性は伝導率の算術平均 $(k_L+k_R)/2$ で積分され、直列抵抗との差は界面が要素の中のどこにあるかで決まる。
界面は $N=20$ と 80 では要素の左端から $2/3$、$N=40$ では $1/3$ の位置にあるので、誤差の大きさが格子ごとに入れ替わる。

## まとめ

伝導率が不連続な界面では温度と流束が連続になり、界面をはさむ二点の実効的な伝導率は直列抵抗による重み付きの調和平均になる。
FVM はセル中心、FDM は区間の中点、FEM は求積点で係数を読むので、一次元では界面を頂点（セルの面）に合わせ、各セルに材料ごとの値を返せばよい。
界面を格子に合わせられないときは、誤差が $O(h)$ に下がることを前提に、格子を細かくして誤差の減り方を確かめる。
FVM では `face_fluxes` で全ての面の流束を再構成し、界面を通る流束が一定であることを直接確かめられる。
