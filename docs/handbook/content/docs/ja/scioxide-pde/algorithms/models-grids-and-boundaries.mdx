物理の支配方程式の多くは、任意の小区間で保存量の出入りを数える収支から出発する。
このページでは収支から一次元の三つの型の方程式を導き、`scioxide-pde` がそれを格子の上の未知数にどう対応させるかを説明する。
境界条件は[境界条件と外向きの符号](../boundary-conditions/)、三つの離散化の導出は[楕円問題の FDM・FEM・FVM](../elliptic-fdm-fem-fvm/)で扱う。

## 保存則からの導出

区間 $a\le x\le b$ の中の小区間 $[x_-,x_+]$ を考える。
場を $u(x,t)$、単位長さあたりの容量（熱容量と断面積の積など）を $m(x)$、右向きの流束を $q(x,t)$、単位長さ・単位時間あたりの生成を $f(x,t)$ とする。
小区間に含まれる保存量の時間変化は、左端から入る流束から右端から出る流束を引き、内部の生成を加えたものに等しい。

$$
\frac{d}{dt}\int_{x_-}^{x_+} m(x)\,u(x,t)\,dx = q(x_-,t)-q(x_+,t)+\int_{x_-}^{x_+} f(x,t)\,dx
$$

被積分関数が連続なら、両辺を $x_+-x_-$ で割って幅を 0 に近づけると、局所的な保存則 $m\,\partial_t u=-\partial_x q+f$ が得られる。
流束と場を結ぶ式を構成則という。
熱伝導の Fourier の法則や拡散の Fick の法則 $q=-k\,\partial_x u$（$k>0$ は伝導率や拡散係数）を代入すると、拡散方程式になる。

$$
m(x)\frac{\partial u}{\partial t}=\frac{\partial}{\partial x}\left(k(x)\frac{\partial u}{\partial x}\right)-c(x)\,u+f(x,t)
$$

ここで $-c\,u$ は周囲への熱損失のように場に比例して失われる量で、$c$ を反応係数と呼ぶ。
$(k\,u_x)_x$ の形を保存形という。
積を展開した $k\,u_{xx}+k'u_x$ の形と式としては同じだが、離散化したときに隣の区間と流束を共有する性質は保存形からしか得られない。

二階の偏微分方程式 $A\,u_{tt}+2B\,u_{tx}+C\,u_{xx}+(\text{低階の項})=0$ は、判別式 $B^2-AC$ の符号で型を分ける。

- **楕円型**（$B^2-AC<0$）：定常状態（$\partial_t u=0$）では、境界値問題 $-(k u')'+c\,u=f$ になる。
  空間が二次元以上なら $-\nabla\cdot(k\nabla u)+c\,u=f$ で、主部 $-k(u_{xx}+u_{yy})$ の判別式は負である。
  解は領域全体の境界データと源項に同時に依存する。
- **放物型**（$B^2-AC=0$）：上の拡散方程式は $t$ の二階微分を持たないので $A=B=0$ で、判別式は 0 である。
  初期値から時間の前向きに解き、空間の高い波数の成分ほど速く減衰する。
- **双曲型**（$B^2-AC>0$）：蓄積の項が変位の時間の二階微分に置き換わると、波動方程式 $m\,u_{tt}=(k\,u_x)_x+f$ になる。
  $A=m$、$C=-k$ なので判別式は $mk>0$ で、波は有限の速さ $\sqrt{k/m}$ で伝わる。

`scioxide-pde` の係数を返す型は拡散係数 $k$ と反応係数 $c$（構造格子の有限差分法では保存形の移流速度も）を返し、容量 $m$ を受け取る引数を持たない。
時間発展の Plan は、空間の離散化が作る作用素 $A$ と、各未知数が受け持つ体積を対角に並べた集中質量 $M$ から、$Mu'=b(t)-Au$ または $Mu''=b(t)-Au$ を積分する。
したがって表せるのは $m=1$ の方程式で、放物型は $u_t=(k u_x)_x-c\,u+f$、双曲型は拡散係数に波の速さ $c_w$ の二乗を渡した $u_{tt}=(c_w^2u_x)_x-c\,u+f$ である。
容量が定数なら $k$、$c$、$f$ を $m$ で割って渡し、場所で変わる容量はこの形では表せない。

## メッシュと場の配置

一次元の構造格子は `scioxide-spatial` の `SegmentMesh`、単体のメッシュは `IntervalMesh` である。
`SegmentMesh` は座標軸の頂点の列から作り、`IntervalMesh` は頂点の座標と、各区間の両端の頂点番号から作る。
以下ではどちらも同じ頂点 $x_0<x_1<\dots<x_N$ と $N$ 個のセル（区間）を持つ場合を考える。
構造格子は `StructuredFdmPlan` と `StructuredFvmPlan`、単体のメッシュは `SimplexFemPlan` と `SimplexFvmPlan` が受け取る。
同じ頂点でも、離散化によって未知数を置く位置が違う。

- **頂点の場**（`VertexField<S, 1>`）：有限差分法（FDM）と P1 有限要素法（FEM）の未知数で、境界を含む各頂点に一つあり、長さは $N+1$ である。
  P2 FEM は頂点の値の後に各区間の中点の値（辺の場）を並べ、未知数は $2N+1$ 個になる。
- **セルの場**（`CellField<S, 1>`）：有限体積法（FVM）の未知数で、セル $C_i=[x_i,x_{i+1}]$ ごとに一つあり、長さは $N$ である。
  値はセル平均の近似で、代表点はセル中心 $(x_i+x_{i+1})/2$ である。

場が複数の成分を持つときは、未知数を成分ごとにまとめて並べる（成分 0 の全未知数、成分 1 の全未知数、の順）。
`StructuredFvmPlan` と `SimplexFvmPlan` は成分が一つの場に限る。
場の位置は型で区別され、長さが同じでも頂点の場とセルの場を取り違えるとコンパイルエラーになる。
メッシュはその族と revision を表す識別子（`MeshToken`）を持ち、境界条件の集合と場はそれを記録する。
座標が同じでも、別に作ったメッシュの境界条件や場を渡すと `InvalidInput` で拒否される。

## 空間離散化の共通の仕様

四つの Plan は共通のトレイト `SpatialDiscretization` を実装する。
これは時間に依らない作用素 $A$ の適用（`scioxide-core` の `LinearOperator`）に加えて、次のものを返す。

- `unknowns` と `components`：境界の値を含む全未知数の数と成分の数。
- `dof_point(i)`：未知数 $i$ の物理座標と成分を `FieldPoint` で返す。
- `constrained()`：未知数ごとに、Dirichlet 条件で値を固定したかどうか。
  固定した行と列は他から切り離して対角を 1 にし、値は荷重の側に入れる。
  対称な問題は対称な行列のまま組み立てられる。
- `lumped_mass()`：各未知数の集中質量で、すべて正である。
  FDM は頂点の支配幅（端では半分）、FVM はセルの体積、FEM は要素ごとに質量行列の対角を要素の全質量に合わせて尺度化し、節点ごとに足した値（P1 では行和に等しい）である。
- `has_constant_modes()`：定数ベクトルが作用素の零空間に入ることが、構造から分かるかどうか。
  反応がなく（FDM では移流もなく）、値を固定する条件も境界反応もない場合に真になる。
  このときの扱いは[楕円問題の適合条件・ゲージ・保存的流束](../compatibility-gauges-and-fluxes/)で説明する。
- `load(source, t)`：時刻 $t$ の荷重 $b(t)$ を返す。
  `load_into` は同じ荷重を利用者のメモリ領域に書き、メモリを確保しない。
  荷重は源項の重み付き和、Neumann・Robin のデータの重み付き和、Dirichlet の値を移した項からなる。
  定常の求解は時刻 0 で評価する。
- `assemble_csr()`：消去済みの作用素を圧縮行格納（CSR）の疎行列で返す。
- `field(values)`：未知数の並びを `VertexField` の列、`CellField` または `SimplexFemField` に戻す。

`StructuredFdmPlan`・`StructuredFvmPlan`・`SimplexFvmPlan` の準備はメモリ領域を確保する前に、未知数の数、組み立てる行列要素の数、確保するメモリ使用量のバイト数を `SpatialLimits::new(max_unknowns, max_entries, max_storage_bytes)` の上限と比べ、超えれば `InvalidInput` で拒否する。
既定値（`SpatialLimits::default()`、`new` で作る Plan）は上限を設けない。
`SimplexFemPlan` は同じ役割の `SimplexFemLimits` を使う。

## 源項と初期値のデータ

源項 $f$ と初期値は `FieldData<R, V, D>` で渡す。
これは場所と時刻の関数 $f(\text{site},t)$ を共有ポインタで保持する `PdeData` の別名で、引数の `FieldPoint` は物理座標 `point` と成分番号 `component` を持つ。
境界のデータ `BoundaryData` も同じ `PdeData` で、引数の `BoundaryPoint` はさらに外向きの単位法線 `normal` を持つ。

時間依存は値を見て推定せず、作るときに宣言する（`TimeDependence`）。

- `FieldData::time_invariant(f)` と `constant(v)`、`zero()` は `TimeInvariant` で、関数は時刻を受け取らない。
  時間発展の Plan は一度評価に成功した荷重を再利用することがあるので、関数が取り込んだ値を変えたときは Plan を作り直す。
- `FieldData::time_dependent(f)` は `TimeDependent` で、関数は `(site, t)` を受け取り、要求された時刻ごとに評価される。

評価は時刻が有限であることを確かめてから関数を呼び、有限でない戻り値を `NonFinite` で拒否する。
関数が返したエラーはそのまま伝わる。

## 場の配置を確かめる

下のセルは同じ区間 $[0,1]\,\mathrm{m}$ を $N$ 個の一様なセルに分け、拡散係数 1 の四つの Plan を準備して、`SpatialDiscretization` が返す量を並べる。
入力はセルの数と、両端の条件（Dirichlet か、流束 0 の Neumann か）である。
検算は二つある。
集中質量の和は区間の長さ 1 に等しく、P2 の未知数 $N+1$ 番目（0 から数える）は最初の区間の中点 $h/2$ にある。

```rust
//| id: pde-field-locations
//| ref: pde-field-locations
//| title: 四つの Plan の未知数の位置と集中質量を並べる
//| run: reactive
//| crates: [scioxide-pde, scioxide-spatial, scioxide-core]
//| inputs:
//|   cells: {"type":"range","label":"セルの数 N [-]","min":2,"max":10,"step":1,"value":4}
//|   ends: {"type":"select","label":"両端の条件","options":["Dirichlet（値を固定）","Neumann（流束 0）"],"value":"Dirichlet（値を固定）"}
//| cases:
//|   - {"id":"neumann","label":"両端 Neumann","description":"どの Plan も値を固定せず、定数モードを返す。","inputs":{"ends":"Neumann（流束 0）"}}
//|   - {"id":"fine","label":"N = 10","description":"未知数は FDM と P1 が 11、FVM が 10、P2 が 21 になる。","inputs":{"cells":10}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"plans","path":"/rows/0/2","equals":5}
//|       - {"artifact":"plans","path":"/rows/0/3","equals":2}
//|       - {"artifact":"plans","path":"/rows/1/2","equals":4}
//|       - {"artifact":"plans","path":"/rows/1/3","equals":0}
//|       - {"artifact":"plans","path":"/rows/3/2","equals":9}
//|       - {"artifact":"plans","path":"/rows/3/4","approx":{"value":1,"atol":1e-14}}
//|       - {"artifact":"plans","path":"/rows/0/5","equals":"なし"}
//|       - {"artifact":"dofs","path":"/rows/5/4","approx":{"value":0.125,"atol":1e-15}}
//|       - {"artifact":"dofs","path":"/rows/4/2","equals":null}
//|   - case: neumann
//|     expect:
//|       - {"artifact":"plans","path":"/rows/0/3","equals":0}
//|       - {"artifact":"plans","path":"/rows/0/5","equals":"あり"}
//|       - {"artifact":"plans","path":"/rows/3/5","equals":"あり"}
//|   - case: fine
//|     expect:
//|       - {"artifact":"plans","path":"/rows/3/2","equals":21}
//|       - {"artifact":"plans","path":"/rows/2/4","approx":{"value":1,"atol":1e-14}}
use scioxide_pde::{
    BoundaryData, BoundaryKind, ConstantDiffusion, SimplexFemGeometry, SimplexFemOrder,
    SimplexFemPlan, SpatialDiscretization, StructuredBoundaries, StructuredFdmPlan,
    StructuredFvmPlan, TaggedBoundaries,
};
use scioxide_spatial::{AxisTopology, CoordinateAxis, Grid1d, IntervalMesh, Point, SegmentMesh};

// Plan ごとに未知数、固定した未知数、集中質量の和、定数モードと座標を読む。
fn summary<P: SpatialDiscretization<f64, f64, 1>>(
    plan: &P,
) -> Result<(usize, usize, f64, bool, Vec<f64>), String> {
    let mut xs = Vec::new();
    for i in 0..plan.unknowns() {
        xs.push(plan.dof_point(i).map_err(|e| e.to_string())?.point[0]);
    }
    let fixed = plan.constrained().iter().filter(|&&c| c).count();
    let mass = plan.lumped_mass().iter().sum::<f64>();
    Ok((plan.unknowns(), fixed, mass, plan.has_constant_modes(), xs))
}
let n = cells as usize;
let kind = if ends.starts_with("Dirichlet") {
    BoundaryKind::Dirichlet
} else {
    BoundaryKind::Natural
};
let k = ConstantDiffusion::new(1.0);
// 構造格子: 頂点 x_i = i/N。両端の面に同じ条件を付ける。
let axis = CoordinateAxis::uniform(0.0, 1.0, n + 1).map_err(|e| e.to_string())?;
let grid = Grid1d::new([axis], [AxisTopology::Bounded]).map_err(|e| e.to_string())?;
let segment = SegmentMesh::new(grid).map_err(|e| e.to_string())?;
let structured = StructuredBoundaries::uniform(&segment, 1, kind, BoundaryData::zero())
    .map_err(|e| e.to_string())?;
let fdm =
    StructuredFdmPlan::new(segment.clone(), &k, &structured).map_err(|e| e.to_string())?;
let fvm = StructuredFvmPlan::new(segment, &k, &structured).map_err(|e| e.to_string())?;
let mut summaries = vec![
    ("FDM", "頂点", summary(&fdm)?),
    ("FVM", "セル中心", summary(&fvm)?),
];
// 単体のメッシュ: 同じ頂点を区間でつなぎ、すべての境界の面に同じ条件を付ける。
let points = (0..=n)
    .map(|i| Point::new([i as f64 / n as f64]))
    .collect::<Result<Vec<_>, _>>()
    .map_err(|e| e.to_string())?;
let interval = IntervalMesh::new(points, (0..n).map(|i| [i, i + 1]).collect())
    .map_err(|e| e.to_string())?;
let tagged = TaggedBoundaries::uniform(&interval, 1, kind, BoundaryData::zero())
    .map_err(|e| e.to_string())?;
for (name, place, order) in [
    ("FEM P1", "頂点", SimplexFemOrder::P1),
    ("FEM P2", "頂点と区間の中点", SimplexFemOrder::P2),
] {
    let geometry = SimplexFemGeometry::Affine;
    let plan = SimplexFemPlan::new(interval.clone(), geometry, order, &k, &tagged)
        .map_err(|e| e.to_string())?;
    summaries.push((name, place, summary(&plan)?));
}
let fixed3 = serde_json::json!({ "fractionDigits": 3 });
let plan_columns = serde_json::json!([
    { "key": "0", "label": "離散化" },
    { "key": "1", "label": "未知数の位置" },
    { "key": "2", "label": "未知数 [-]", "type": "integer" },
    { "key": "3", "label": "値を固定した未知数 [-]", "type": "integer" },
    { "key": "4", "label": "集中質量の和 [m]", "type": "number", "format": fixed3 },
    { "key": "5", "label": "定数モード" }
]);
let plan_rows: Vec<_> = summaries
    .iter()
    .map(|(name, place, (count, fixed, mass, modes, _))| {
        let modes = if *modes { "あり" } else { "なし" };
        (*name, *place, *count, *fixed, *mass, modes)
    })
    .collect();
emit_table_with_columns!(
    plan_columns,
    plan_rows,
    metadata = serde_json::json!({ "id": "plans" })
);
// 未知数の番号ごとの座標。未知数の少ない Plan の欄は空にする。
let x = |plan: usize, i: usize| summaries[plan].2.4.get(i).copied();
let dof_rows: Vec<_> = (0..summaries[3].2.4.len())
    .map(|i| (i, x(0, i), x(1, i), x(2, i), x(3, i)))
    .collect();
let dof_columns = serde_json::json!([
    { "key": "0", "label": "未知数の番号 i", "type": "integer" },
    { "key": "1", "label": "FDM の x [m]", "type": "number", "format": fixed3, "nullText": "-" },
    { "key": "2", "label": "FVM の x [m]", "type": "number", "format": fixed3, "nullText": "-" },
    { "key": "3", "label": "FEM P1 の x [m]", "type": "number", "format": fixed3, "nullText": "-" },
    { "key": "4", "label": "FEM P2 の x [m]", "type": "number", "format": fixed3, "nullText": "-" }
]);
emit_table_with_columns!(
    dof_columns,
    dof_rows,
    metadata = serde_json::json!({ "id": "dofs" })
);
```

既定（$N=4$、両端 Dirichlet）では、FDM と P1 の未知数は 5 個で、そのうち両端の 2 個が値を固定した未知数である。
FVM の未知数は 4 個のセル平均で、固定した未知数はない。
FVM は境界の値を未知数にせず、境界の面の流束の式に入れるからである。
P2 の未知数は 9 個で、番号 0〜4 が頂点、番号 5 からが区間の中点 0.125 m、0.375 m、… である。
集中質量の和はどの Plan でも区間の長さ 1 m になる。
両端を Neumann にすると、どの Plan も値を固定せず、定数モードを返す。

## まとめ

保存則の収支に構成則を代入すると、時間微分の有無と階数によって楕円型・放物型・双曲型の方程式が得られる。
`scioxide-pde` が表すのは容量 $m=1$ の形なので、定数の容量は係数と源項を割って渡す。
未知数の位置は FDM と P1 FEM が頂点、FVM がセル中心、P2 FEM が頂点と区間の中点で、`dof_point` と `lumped_mass` で確かめられる。
源項と境界のデータは `FieldData`・`BoundaryData` で作り、時間に依るかどうかを作るときに宣言する。
