このページは一次元から三次元のセル中心の有限体積法（FVM）を扱う。
未知数はセルの平均値の近似で、各セルで面の流束の収支をとるので、離散解は局所的な保存を満たす。
二点流束と非直交補正からなる面の流束の導出、境界の面の扱い、定数モード、材料の不連続での精度を説明し、三つのセルで確かめる。
一次元の FVM と二点流束は[楕円問題の FDM・FEM・FVM](../elliptic-fdm-fem-fvm/)、構造格子の頂点の差分は[構造格子の多次元差分](../multidimensional-spatial-plans/)で扱う。

## セル中心の有限体積

`StructuredFvmPlan`（有界な線分・四辺形・六面体の `CellMesh`）と `SimplexFvmPlan`（区間・三角形・四面体の `SimplexMesh`）は、スカラーの方程式

$$
-\nabla\cdot(K\nabla u)+c\,u=f
$$

をセル中心の値で離散化する。
$K$ は $D\times D$ の実対称正定値の拡散テンソル、$c$ は反応係数、$f$ は源項である。
境界条件の成分は 1 つに限り、複数の成分を持つ `BoundaryConditions` は準備の段階で拒否する。
未知数はセルの順に並び、構造格子では軸 0 が最も速く変わる。

係数はトレイト `FvmCoefficients` で与える。
`diffusion(point)` は完全なテンソル $[[K_{ij}]]$ を、`reaction(point)` は $c$ を返し、反応の既定は 0 である。
どちらも準備の段階で、各セルの中心（構造格子では箱の中心、単体では重心）で一度だけ呼ぶ。
セルはその点のテンソルを自分の材料として持ち、丸め程度の非対称は対称部分に射影して、正定値でなければ拒否する。
反応は複素数でもよい。

セル $T$ で方程式を積分し、発散定理を使うと

$$
\sum_{F\subset\partial T}\Phi_{T,F}+|T|\,c(\mathbf{x}_T)\,u_T=|T|\,f(\mathbf{x}_T)
$$

になる。
$\Phi_{T,F}=-\int_FK\nabla u\cdot\mathbf{n}_T\,dS$ は面 $F$ から外へ出る物理的な流束、$|T|$ はセルの体積、$\mathbf{x}_T$ はセルの中心である。
反応と源項は中心の値で代表させる（中点則）。
残る問題はセルの値から $\Phi_{T,F}$ を近似することである。

### 面の流束の近似

内部の面 $F$ の単位法線を $\mathbf{n}$（セル $L$ から $R$ への向き）、面積を $|F|$、面の中心を $\mathbf{x}_F$ とする。
両側のセルの中心から面への差を $\mathbf{d}_L=\mathbf{x}_F-\mathbf{x}_L$、$\mathbf{d}_R=\mathbf{x}_R-\mathbf{x}_F$ とし、各セルの $K_s\mathbf{n}$ を $\mathbf{d}_s$ に平行な成分と残りに分ける。

$$
K_s\mathbf{n}=a_s\mathbf{d}_s+\mathbf{t}_s,\qquad a_s=\frac{(K_s\mathbf{n})\cdot\mathbf{d}_s}{|\mathbf{d}_s|^2},\qquad s=L,R
$$

半セルの中で $u$ が線形なら $\mathbf{d}_s\cdot\nabla u$ は両端の値の差に等しいので、面での $K\nabla u\cdot\mathbf{n}$ は左側から見て $a_L(u_F-u_L)+\mathbf{t}_L\cdot\nabla u_L$、右側から見て $a_R(u_R-u_F)+\mathbf{t}_R\cdot\nabla u_R$ と書ける。
流束が面で連続であるという条件から面の値 $u_F$ を消去し、符号を変えて面積を掛けると、$L$ から $R$ への流束は

$$
\Phi_F=|F|\left[\frac{a_La_R}{a_L+a_R}(u_L-u_R)-\frac{a_R}{a_L+a_R}\,\mathbf{t}_L\cdot\nabla u_L-\frac{a_L}{a_L+a_R}\,\mathbf{t}_R\cdot\nabla u_R\right]
$$

になる。
第 1 項は二つの半セルの伝導係数を直列につないだ二点流束（TPFA）で、一次元では[一次元の FVM](../elliptic-fdm-fem-fvm/) の調和平均に一致する。
第 2・3 項は $K\mathbf{n}$ のうち $\mathbf{d}_s$ に平行でない成分を、セルの勾配 $\nabla u_s$ で補う非直交補正である。
勾配は隣のセルの中心との差と境界の面の条件を制約とし、各制約をその長さで正規化した最小二乗法で再構成する。
メッシュが $K$ に関して直交（すべての面で $\mathbf{t}_L=\mathbf{t}_R=0$）なら補正は消え、二点流束だけが残る。

補正は隣のセルの値を含むので、行列は一般に非対称で、1 行の非零要素は二点流束より多い。
$a_s\le0$ となる半セルは、準備の段階で `NumericalInstability`（`Breakdown`）として拒否する。
$a_s>0$ でも、歪んだ幾何や強い異方性では行列が M 行列になるとは限らず、離散最大値原理は保証されない。
勾配の再構成が階数落ちするメッシュも準備の段階で拒否する。
二点流束でも非直交補正でもない多点流束近似（MPFA）は提供しない。

### 境界の面

境界の面には $\alpha u+\beta\,K\nabla u\cdot\mathbf{n}=g$ の形の法則を置く。
Dirichlet は $(\alpha,\beta)=(1,0)$、Neumann は $(0,1)$、Robin は $(\alpha,1)$ で、$\mathbf{n}$ は外向き、$\alpha$ は実数に限る。
Neumann のデータ $g$ は[外向きの余法線流束](oxref:pde-neumann-outward-sign) $K\nabla u\cdot\mathbf{n}$ であり、法線微分 $\partial u/\partial n$ ではない。
異方的な $K$ では二つは一致しないので、製造解から境界データを作るときは $K\nabla u\cdot\mathbf{n}$ を渡す。

Neumann の面の流束は $\Phi_F=-|F|\,g$ で、セルの値に依らないので荷重だけに入る。
Dirichlet と Robin の面では、セルの半セルの法則と面の法則から面の値を消去し、行列と荷重の両方に寄与する。
どの未知数も拘束しないので、`constrained()` はすべて偽を返し、Dirichlet の値は荷重を通じて入る。
`StructuredFvmPlan` は周期軸を受け付けない。

### 保存と定数モード

同じ $\Phi_F$ の係数を、左のセルの行に正、右のセルの行に負で加える。
そのため列の和 $\mathbf{1}^{\mathsf T}A$ には境界の面と反応の寄与だけが残り、内部の面の寄与は打ち消し合う。
全周が Neumann 条件で $c=0$ なら、Neumann の面は行列に入らないので $\mathbf{1}^{\mathsf T}A=0$ が丸めの範囲で成り立つ。
定数の場の勾配は 0 に再構成され、二点流束も 0 になるので $A\mathbf{1}=0$ でもある。
これは異方的なテンソルでも同じで、荷重の和が 0 であることが離散系の可解条件になる。
`has_constant_modes` はこの場合に真を返し、`check_constant_mode_compatibility` は荷重の和をその絶対値の和に対する相対誤差で検査する。
ゲージの選び方は[楕円問題の適合条件・ゲージ・保存的流束](../compatibility-gauges-and-fluxes/)で説明する。

### 面の流束の再構成

解から面の流束を求め直すと、各セルの収支を直接確かめられる。
`StructuredFvmPlan::face_fluxes::<A>` は軸 `A` に垂直な面の流束を `FaceField` で返し、符号は座標が増える向きを正とする。
`SimplexFvmPlan::face_fluxes` は正準な面の順に `UnstructuredFaceField` で返し、向きは最初に接するセルから外向きである。
どちらも面積で積分した物理的な流束 $-\int_FK\nabla u\cdot\mathbf{n}\,dS$ で、境界データは指定した時刻で評価する。

同じ Plan で何度も再構成するときは、`workspace` で作った `FvmFluxWorkspace` を `face_fluxes_into` に渡す。
作業領域は Plan の面の数で一度だけ確保され、その後は大きくならない。
`face_fluxes_into` は全ての面を軸の順（構造格子）か正準な順（単体）に書き、失敗したときは出力を変えない。

## 異方性テンソルの収束と局所収支

次のセルは単位正方形で $K=\begin{pmatrix}1&\kappa\\\kappa&1\end{pmatrix}$ とし、製造解 $u=\sin\pi x\sin\pi y$ を与える。
源項は $f=2\pi^2u-2\kappa\pi^2\cos\pi x\cos\pi y$、境界条件は全周で $u=0$ の Dirichlet 条件である。
$N\times N$ セル（$N=8,16,32$）の `StructuredFvmPlan` を既定の疎 LU 分解で解き、セル中心での最大誤差を測る。
$\kappa\ne0$ では $K\mathbf{n}$ が面の法線から傾くので、非直交補正が働く。

解から `face_fluxes_into` で全ての面の流束を求め、面の流束密度（流束を面の長さで割った値）の誤差を、厳密な流束の面での積分と比べる。
各セルの局所収支の残差は $\max_T|\sum_F\Phi_{T,F}-|T|f(\mathbf{x}_T)|$ である。
収支は連立方程式そのものなので、残差は離散化誤差ではなく線形解法の丸めの大きさになるはずである。

```rust
//| id: pde-fvm-anisotropic-flux-balance
//| ref: pde-fvm-anisotropic-flux-balance
//| title: 異方性テンソルの FVM を解き、セル値と面の流束の収束次数と局所収支を測る
//| run: button
//| crates: [scioxide-core, scioxide-pde, scioxide-spatial]
//| inputs:
//|   kappa: {"type":"range","label":"テンソルの非対角 κ [-]","description":"K = [[1, κ], [κ, 1]] の非対角。|κ| < 1 で正定値。","min":0,"max":0.8,"step":0.2,"value":0.6}
//| cases:
//|   - {"id":"isotropic","label":"κ = 0","description":"等方的なテンソルでは非直交補正が消え、二点流束だけで 2 次に収束する。","inputs":{"kappa":0}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"fvm","path":"/rows/2/2","approx":{"value":2.0,"atol":0.15}}
//|       - {"artifact":"fvm","path":"/rows/2/5","range":{"min":1.6}}
//|       - {"artifact":"fvm","path":"/rows/2/6","range":{"max":1e-12}}
//|   - case: isotropic
//|     expect:
//|       - {"artifact":"fvm","path":"/rows/2/2","approx":{"value":2.0,"atol":0.15}}
//|       - {"artifact":"fvm","path":"/rows/2/6","range":{"max":1e-12}}
use scioxide_core::{ExecutionContext, SciOxideError};
use scioxide_pde::{
    BoundaryCondition, BoundaryData, EllipticOptions, EllipticProblem, FieldData, FieldPoint,
    FvmCoefficients, SpatialDiscretization, StructuredBoundaries, StructuredFvmPlan,
};
use scioxide_spatial::{
    AxisSide, AxisTopology, BoundarySet, Cell, CoordinateAxis, FieldView, Grid2d, QuadMesh,
};
use std::f64::consts::PI;

struct Tensor(f64);
impl FvmCoefficients<f64, f64, 2> for Tensor {
    fn diffusion(&self, _: [f64; 2]) -> Result<[[f64; 2]; 2], SciOxideError> {
        Ok([[1.0, self.0], [self.0, 1.0]])
    }
}
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let fixed3 = serde_json::json!({ "fractionDigits": 3 });
let source = FieldData::time_invariant(move |p: FieldPoint<f64, 2>| {
    let [x, y] = p.point;
    let product = (PI * x).sin() * (PI * y).sin();
    Ok(2.0 * PI * PI * (product - kappa * (PI * x).cos() * (PI * y).cos()))
});
// 厳密な流束 −∫K∇u·n dS。面の法線方向の座標 c、面に沿った区間 [s0, s1]。
// K と u は x と y の入れ替えで不変なので、両軸の面で同じ式になる。
let exact_flux = |c: f64, s0: f64, s1: f64| {
    let along = ((PI * s0).cos() - (PI * s1).cos()) / PI;
    let across = ((PI * s1).sin() - (PI * s0).sin()) / PI;
    -PI * ((PI * c).cos() * along + kappa * (PI * c).sin() * across)
};
let mut rows: Vec<(usize, f64, Option<f64>, f64, f64, Option<f64>, f64)> = Vec::new();
for n in [8_usize, 16, 32] {
    let axis = CoordinateAxis::uniform(0.0, 1.0, n + 1).map_err(|e| e.to_string())?;
    let grid = Grid2d::new([axis.clone(), axis], [AxisTopology::Bounded; 2])
        .map_err(|e| e.to_string())?;
    let mesh = QuadMesh::new(grid).map_err(|e| e.to_string())?;
    let mut conditions = Vec::new();
    for axis in 0..2 {
        for side in [AxisSide::Start, AxisSide::End] {
            let region =
                BoundarySet::axis_side(&mesh, axis, side).map_err(|e| e.to_string())?;
            conditions.push(BoundaryCondition::dirichlet(region, BoundaryData::zero()));
        }
    }
    let boundaries =
        StructuredBoundaries::new(&mesh, 1, conditions).map_err(|e| e.to_string())?;
    let plan = StructuredFvmPlan::new(mesh.clone(), &Tensor(kappa), &boundaries)
        .map_err(|e| e.to_string())?;
    let solution = EllipticProblem::new(&plan, &source)
        .solve_with_options(&EllipticOptions::new())
        .map_err(|e| e.to_string())?;
    if !solution.report().is_success() {
        return Err(format!("N={n}: {}", solution.report().termination()));
    }
    let values = solution.values();
    let h = 1.0 / n as f64;
    let mut error = 0.0_f64;
    for (cell, u) in values.iter().enumerate() {
        let [x, y] = plan.dof_point(cell).map_err(|e| e.to_string())?.point;
        error = error.max((u - (PI * x).sin() * (PI * y).sin()).abs());
    }
    // 全ての面の流束：軸 0 の面 (N+1)×N 個のあとに軸 1 の面 N×(N+1) 個が続く。
    let mut fluxes = vec![0.0; 2 * n * (n + 1)];
    let mut workspace = plan.workspace().map_err(|e| e.to_string())?;
    let cells = FieldView::<_, Cell, 2>::new(&mesh, values).map_err(|e| e.to_string())?;
    plan.face_fluxes_into(
        cells,
        0.0,
        &mut fluxes,
        &mut workspace,
        ExecutionContext::sequential(),
    )
    .map_err(|e| e.to_string())?;
    let (x_faces, y_faces) = fluxes.split_at(n * (n + 1));
    // 流束密度の誤差。面 (i, j) は法線方向の番号 i（0..=N）と面に沿った番号 j（0..N）。
    // far は両側のセルがどちらも境界のセルでない面。
    let far = |i: usize, j: usize| i >= 2 && i + 2 <= n && j >= 1 && j + 2 <= n;
    let (mut all, mut inner) = (0.0_f64, 0.0_f64);
    for i in 0..=n {
        for j in 0..n {
            let (c, s0, s1) = (i as f64 * h, j as f64 * h, (j + 1) as f64 * h);
            let exact = exact_flux(c, s0, s1);
            for computed in [x_faces[i + (n + 1) * j], y_faces[j + n * i]] {
                let e = (computed - exact).abs() / h;
                all = all.max(e);
                if far(i, j) {
                    inner = inner.max(e);
                }
            }
        }
    }
    // 局所収支：各セルの外向きの流束の和と、生成 |T| f(x_T) の差。
    let mut balance = 0.0_f64;
    for j in 0..n {
        for i in 0..n {
            let out = x_faces[i + 1 + (n + 1) * j] - x_faces[i + (n + 1) * j]
                + y_faces[i + n * (j + 1)]
                - y_faces[i + n * j];
            let center = [(i as f64 + 0.5) * h, (j as f64 + 0.5) * h];
            let site = FieldPoint {
                point: center,
                component: 0,
            };
            let produced = h * h * source.evaluate(site, 0.0).map_err(|e| e.to_string())?;
            balance = balance.max((out - produced).abs());
        }
    }
    let order = rows.last().map(|r| (r.1 / error).log2());
    let flux_order = rows.last().map(|r| (r.4 / inner).log2());
    rows.push((n, error, order, all, inner, flux_order, balance));
}
let columns = serde_json::json!([
    { "key": "0", "label": "一辺のセル数 N", "type": "integer" },
    { "key": "1", "label": "セル中心の最大誤差 [-]", "type": "number", "format": sci3 },
    { "key": "2", "label": "観測次数 [-]", "type": "number", "format": fixed3, "nullText": "—" },
    { "key": "3", "label": "流束密度の誤差（全ての面） [-]", "type": "number", "format": sci3 },
    { "key": "4", "label": "流束密度の誤差（境界のセルに接しない面） [-]", "type": "number", "format": sci3 },
    { "key": "5", "label": "内側の流束の観測次数 [-]", "type": "number", "format": fixed3, "nullText": "—" },
    { "key": "6", "label": "局所収支の最大残差 [-]", "type": "number", "format": sci3 }
]);
emit_table_with_columns!(columns, rows, metadata = serde_json::json!({ "id": "fvm" }));
```

既定（$\kappa=0.6$）では、セル中心の最大誤差は $N=8,16,32$ で $2.34\times10^{-2}$、$5.81\times10^{-3}$、$1.45\times10^{-3}$ で、観測次数は 2.005 だった。
局所収支の残差はどの格子でも $4\times10^{-15}$ 以下で、各セルの流束の和は丸めの範囲で生成 $|T|f(\mathbf{x}_T)$ に一致する。
FVM の保存性は離散化誤差の大きさに依らず、線形系を解いた精度で成り立つ。

面の流束密度の誤差は全ての面でとると $9.57\times10^{-2}$、$5.49\times10^{-2}$、$2.80\times10^{-2}$ と 1 次でしか減らない。
最大は境界のセルに接する面で生じる。
境界のセルの勾配は境界の面の条件を含む片側の制約から再構成され、一般に 1 次の精度しか持たない。
その誤差が非直交補正を通じて流束に入ると考えられる。
境界のセルに接しない面に限ると、誤差は $2.80\times10^{-3}$ まで下がり、観測次数は 1.79 で 2 に近づいている。
$\kappa=0$ では補正が消え、全ての面で流束が 2 次で収束する。
セルの値は 2 次で収束しても、境界付近の流束は 1 次になりうるので、境界の熱流束のような量を評価するときは格子を細かくして確かめる。

## 材料の不連続の位置と収束次数

次のセルは、$x=1/2$ を境に拡散係数が $k_L=1$ から $k_R$ に跳ぶ層状の材料で、$-\nabla\cdot(k\nabla u)=f$ を解く。
厳密解は $u=s(x)\sin\pi y$ で、$s(x)=x$（$x<1/2$）、$s(x)=1/2+(x-1/2)/k_R$（$x\ge1/2$）とする。
$s$ は連続で、流束 $-k\,s'=-1$ も界面で連続なので、これは界面条件を満たす弱解である。
源項は $f=k\pi^2u$、境界条件は全周で厳密解の値の Dirichlet 条件である。

セル数 $N$ が偶数なら界面はセルの面に一致し、各セルは一つの材料だけを含む。
$N$ が奇数なら中央の列のセルの中心がちょうど $x=1/2$ にあり、そのセルは中心の値 $k_R$ を材料として持つので、界面は実質的に半セルずれる。
二つの格子の族で、セル中心の最大誤差と観測次数を比べる。
界面の条件と直列抵抗の一次元での導出は[不連続な係数と材料界面](oxref:pde-interface-series-resistance)にある。

```rust
//| id: pde-fvm-material-jump-order
//| ref: pde-fvm-material-jump-order
//| title: 層状の材料の界面がセルの面に一致する格子と一致しない格子で FVM の収束次数を比べる
//| run: button
//| crates: [scioxide-core, scioxide-pde, scioxide-spatial]
//| inputs:
//|   contrast: {"type":"range","label":"右側の拡散係数 k_R [-]","description":"左側は k_L = 1。","min":10,"max":1000,"step":10,"value":100}
//| cases:
//|   - {"id":"mild","label":"k_R = 10","description":"跳びが小さくても、界面がセルの中にある格子の次数は 1 のままである。","inputs":{"contrast":10}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"jump","path":"/rows/2/3","approx":{"value":2.0,"atol":0.2}}
//|       - {"artifact":"jump","path":"/rows/5/3","approx":{"value":1.0,"atol":0.2}}
//|   - case: mild
//|     expect:
//|       - {"artifact":"jump","path":"/rows/2/3","approx":{"value":2.0,"atol":0.2}}

struct Layered(f64);
impl FvmCoefficients<f64, f64, 2> for Layered {
    fn diffusion(&self, p: [f64; 2]) -> Result<[[f64; 2]; 2], SciOxideError> {
        let k = if p[0] < 0.5 { 1.0 } else { self.0 };
        Ok([[k, 0.0], [0.0, k]])
    }
}
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let fixed3 = serde_json::json!({ "fractionDigits": 3 });
let exact = move |p: [f64; 2]| {
    let s = if p[0] < 0.5 {
        p[0]
    } else {
        0.5 + (p[0] - 0.5) / contrast
    };
    s * (PI * p[1]).sin()
};
let source = FieldData::time_invariant(move |p: FieldPoint<f64, 2>| {
    let k = if p.point[0] < 0.5 { 1.0 } else { contrast };
    Ok(k * PI * PI * exact(p.point))
});
let data = BoundaryData::time_invariant(move |p: BoundaryPoint<f64, 2>| Ok(exact(p.point)));
let mut rows: Vec<(&str, usize, f64, Option<f64>)> = Vec::new();
for (family, sizes) in [("面に一致", [8_usize, 16, 32]), ("セルの中", [9, 17, 33])] {

            .map_err(|e| e.to_string())?;
        let mesh = QuadMesh::new(grid).map_err(|e| e.to_string())?;

            for side in [AxisSide::Start, AxisSide::End] {
                let region =
                    BoundarySet::axis_side(&mesh, axis, side).map_err(|e| e.to_string())?;
                conditions.push(BoundaryCondition::dirichlet(region, data.clone()));
            }
        }
        let boundaries =
            StructuredBoundaries::new(&mesh, 1, conditions).map_err(|e| e.to_string())?;
        let plan = StructuredFvmPlan::new(mesh, &Layered(contrast), &boundaries)
            .map_err(|e| e.to_string())?;
        let solution = EllipticProblem::new(&plan, &source)
            .solve_with_options(&EllipticOptions::new())
            .map_err(|e| e.to_string())?;
        if !solution.report().is_success() {
            return Err(format!("N={n}: {}", solution.report().termination()));
        }
        let mut error = 0.0_f64;
        for (cell, u) in solution.values().iter().enumerate() {
            let p = plan.dof_point(cell).map_err(|e| e.to_string())?.point;
            error = error.max((u - exact(p)).abs());
        }
        // 格子幅の比が 2 でない族もあるので、h の比で次数を求める。
        let order = previous.map(|(m, e)| (e / error).ln() / (n as f64 / m as f64).ln());
        previous = Some((n, error));
        rows.push((family, n, error, order));
    }
}
```

既定（$k_R=100$）では、界面が面に一致する格子の誤差は $N=8,16,32$ で $3.78\times10^{-3}$、$9.61\times10^{-4}$、$2.41\times10^{-4}$ で、観測次数は 1.994 だった。
各セルが一つの材料だけを持ち、面の二点流束が二つの半セルの伝導係数を直列につなぐので、界面での流束の連続が正しく表される。
界面がセルの中にある格子では、誤差は $N=33$ でも $1.43\times10^{-2}$ で、観測次数は 0.943 と 1 次に下がる。
材料はセルの中心で一度だけ標本化され、界面をまたぐセルの中で材料を平均しないからである。
$k_R=10$ でも 1 次のままで、誤差は $1.20\times10^{-2}$ とわずかに小さいだけである。
材料の不連続がある問題では、界面がセルの面に一致するメッシュを作る。

## 全周 Neumann 条件の定数モード

次のセルは三角形メッシュの `SimplexFvmPlan` で、全周が Neumann 条件の異方性の問題を解く。
テンソルは $K=\begin{pmatrix}1&\kappa\\\kappa&1\end{pmatrix}$、厳密解は $u=\cos\pi x$、源項は $f=\pi^2\cos\pi x$ である。
$K\nabla u=(-\pi\sin\pi x,\,-\kappa\pi\sin\pi x)$ なので、正しい Neumann データ $g=K\nabla u\cdot\mathbf{n}$ は上下の辺で $\mp\kappa\pi\sin\pi x$ になり、法線微分 $\partial u/\partial n$（上下の辺で 0）とは異なる。
入力で境界データを余法線流束と法線微分から選び、解の誤差を比べる。

メッシュは $N\times N$ の正方形を対角線で二つに分けた三角形で、$N=8,16,32$ とする。
組み立てた行列の行の和 $A\mathbf{1}$ と列の和 $\mathbf{1}^{\mathsf T}A$ の最大値を、行列の最大要素との比で示す。
解は `EllipticGauge::WeightedMean(0)`（体積で重み付けした平均を 0 にするゲージ）で一意に決め、厳密解の平均も 0 である。

```rust
//| crates: [scioxide-core, scioxide-pde, scioxide-spatial]

//|   - case: default

//|       - {"artifact":"neumann","path":"/rows/2/3","range":{"max":1e-12}}
//|       - {"artifact":"neumann","path":"/rows/2/5","range":{"min":1.5}}
//|   - case: normal-derivative
//|     expect:
//|       - {"artifact":"neumann","path":"/rows/2/4","range":{"min":0.05}}
use scioxide_core::{SciOxideError, Tolerance};
use scioxide_pde::{
    BoundaryCondition, BoundaryData, BoundaryPoint, EllipticGauge, EllipticOptions,
    EllipticProblem, FieldData, FieldPoint, FvmCoefficients, SimplexFvmPlan,
    SpatialDiscretization, TaggedBoundaries,
};

use std::f64::consts::PI;

struct Tensor(f64);
impl FvmCoefficients<f64, f64, 2> for Tensor {
    fn diffusion(&self, _: [f64; 2]) -> Result<[[f64; 2]; 2], SciOxideError> {
        Ok([[1.0, self.0], [self.0, 1.0]])
    }
}

let fixed3 = serde_json::json!({ "fractionDigits": 3 });
let kappa = tensor_coupling;
let conormal = neumann_data.starts_with("余法線");
// g = K∇u·n（余法線流束）または ∇u·n（法線微分）。u = cos πx。
let data = BoundaryData::time_invariant(move |p: BoundaryPoint<f64, 2>| {
    let ux = -PI * (PI * p.point[0]).sin();
    let flux = if conormal {
        [ux, kappa * ux]
    } else {
        [ux, 0.0]
    };
    Ok(flux[0] * p.normal[0] + flux[1] * p.normal[1])
});
let source =
    FieldData::time_invariant(|p: FieldPoint<f64, 2>| Ok(PI * PI * (PI * p.point[0]).cos()));
let options = EllipticOptions::new().with_gauge(EllipticGauge::WeightedMean(0.0));
let mut rows: Vec<(usize, f64, f64, f64, f64, Option<f64>)> = Vec::new();

        .map(|i| Point::new([(i % (n + 1)) as f64 / scale, (i / (n + 1)) as f64 / scale]))

        .map_err(|e| e.to_string())?;

    for j in 0..n {
        for i in 0..n {
            let v = j * (n + 1) + i;
            cells.push([v, v + 1, v + n + 2]);
            cells.push([v, v + n + 2, v + n + 1]);
        }

    let mesh = TriangleMesh::new(points, cells).map_err(|e| e.to_string())?;

            row_sums[row] += matrix.values()[index];
            column_sums[matrix.col_indices()[index]] += matrix.values()[index];

        .map_err(|e| e.to_string())?;

    let mut error = 0.0_f64;
    for (cell, u) in solution.values().iter().enumerate() {
        let p = plan.dof_point(cell).map_err(|e| e.to_string())?.point;

        n,
        max_abs(&row_sums),
        max_abs(&column_sums),

        error,
        order,
```

余法線流束のデータ（既定、$\kappa=0.6$）では、セル中心の最大誤差は $4.51\times10^{-3}$、$1.14\times10^{-3}$、$2.86\times10^{-4}$ と 2 次で減り、観測次数は 1.994 だった。
行の和と列の和はどちらも行列の最大要素の $2.3\times10^{-16}$ 倍以下で、異方的なテンソルでも $A\mathbf{1}=0$ と $\mathbf{1}^{\mathsf T}A=0$ が丸めの範囲で成り立つ。
荷重の和も絶対値の和の $10^{-16}$ 倍以下で、`check_constant_mode_compatibility` は相対許容誤差 $10^{-10}$ で受け入れた。
法線微分をデータに渡すと、誤差は $N=32$ でも 1.22 で、格子を細かくしても減らない。
この場合も可解条件は満たされるので計算は成功するが、解いているのは上下の辺で余法線流束が 0 という別の問題である。

## まとめ

`StructuredFvmPlan` と `SimplexFvmPlan` は、セルが持つ完全な拡散テンソルに対して、直列の二点流束と最小二乗の勾配による非直交補正で面の流束を作る。
各セルの流束の収支は線形系を解いた精度で成り立ち、`face_fluxes`・`face_fluxes_into` で面の流束を求めて確かめられる。
滑らかな解ではセルの値が 2 次で収束するが、異方的なテンソルでは境界のセルに接する面の流束が 1 次になる。
材料はセルの中心で標本化されるので、不連続の界面がセルの面に一致するメッシュでは 2 次、セルの中にあると 1 次になる。
Neumann のデータは余法線流束 $K\nabla u\cdot\mathbf{n}$ で、全周が Neumann 条件なら異方性があっても行と列の和が 0 になり、荷重の和が可解条件になる。
