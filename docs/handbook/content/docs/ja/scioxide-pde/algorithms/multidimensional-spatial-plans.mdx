このページは直交する構造格子の頂点に未知数を置く有限差分法（FDM）を扱う。
`StructuredFdmPlan` は一つの型で $D=1,2,3$ の格子を受け持ち、$q$ 個の場が連成した線形の拡散・移流・反応の方程式を離散化する。
双対体積上の保存形の導出、係数の型、境界条件、移流による行列の非対称性、成分の連成を順に説明し、二次元の製造解で収束次数を測る。
セル中心の有限体積法は[多次元の有限体積](../multidimensional-finite-volumes/)、三角形・四面体の有限要素法は[単体メッシュの有限要素](../simplex-finite-elements/)で扱う。

空間の Plan は共通の [`SpatialDiscretization`](oxref:pde-spatial-discretization-contract) を実装する。
Plan は係数を準備時に一度だけ標本化し、時刻に依存しない作用素 $A$ を保持する。
境界データと源項は、荷重 $b(t)$ を評価するたびに呼ぶ。
求解は一次元と同じ `EllipticProblem`・`ParabolicProblem`・`HyperbolicProblem` が行い、反復法を使うときは `EllipticWorkspace::with_linear_solver` で `scioxide-linalg` の Krylov 法を注入する。

## 構造格子の有限差分

`StructuredFdmPlan` は、$D$ 次元の直交格子（`SegmentMesh`、`QuadMesh`、`HexMesh`、一般には `CellMesh`）の頂点で、次の連立方程式を離散化する。

$$
-\nabla\cdot(k_c\nabla u_c)+\nabla\cdot(\mathbf{v}_cu_c)+\sum_{c'=1}^{q}C_{cc'}u_{c'}=f_c,\qquad c=1,\dots,q
$$

$u_c$ は第 $c$ 成分の場、$k_c\ge0$ は拡散係数、$\mathbf{v}_c$ は移流の速度、$C$ は反応行列、$f_c$ は源項である。
拡散と移流は成分ごとに独立で、成分の間は反応行列 $C$ だけが結び付ける。

係数はトレイト `StructuredFdmCoefficients` で与える。

- `diffusion(axis, component, point)` は軸 `axis` 方向の拡散係数を面の中心で返す。
  負の値は準備の段階で拒否し、0 は受け付ける。
  軸ごとに違う値を返せるので、座標軸に沿った対角の異方性は表せるが、交差項を持つ完全なテンソルは表せない。
- `advection(axis, component, point)` は軸方向の速度成分を符号付きで返す。
  既定は 0 である。
- `reaction(row, column, point)` は頂点での $C_{\text{row},\text{column}}$ を返す。
  既定は 0 で、値の型 `V` が複素数なら複素数の値を返せる。

完全な拡散テンソルが必要なら、[多次元の有限体積](../multidimensional-finite-volumes/)か[単体メッシュの有限要素](../simplex-finite-elements/)を使う。

未知数は場ごとにまとまり、第 $c$ 成分の頂点 $i$ は $c\,n+i$ 番目に置かれる（$n$ は一意な頂点の数）。
頂点の番号は軸 0 が最も速く変わり、周期軸では継ぎ目の両端の頂点を一つの未知数にまとめる。
`node_point` と `volumes` は一意な頂点の座標と双対体積を返し、`pack_fields` と `apply_fields` は格子全体の頂点の場と未知数の並びを相互に変換する。

### 双対体積上の保存形

頂点 $i$ の双対体積 $V_i$ は各軸で隣の頂点との中点に囲まれた箱である。
軸 $a$ の双対幅 $w_a(i)$ は、内部の頂点では両側の格子幅の平均、境界の頂点では隣の格子幅の半分で、$V_i=\prod_a w_a(i)$ になる。
方程式を $V_i$ で積分して発散定理を使うと、左辺の拡散と移流の項は $V_i$ の各面を通る流束の和になる。

軸 $a$ 方向の隣の頂点 $j$ との間の面は、格子幅 $h$ の辺の中点 $\mathbf{x}_f$ を中心とし、面積は $A=\prod_{b\ne a}w_b(i)$ である。
この面を $i$ から $j$ へ通る流束を、次のように近似する。

$$
F_{ij}=\underbrace{\frac{k(\mathbf{x}_f)\,A}{h}}_{g}\,(u_i-u_j)+\underbrace{\frac{v_a(\mathbf{x}_f)\,A}{2}}_{\beta}\,(u_i+u_j)
$$

第 1 項は拡散流束 $-k\,\partial u/\partial x_a$ の中心差分、第 2 項は移流流束 $v_au$ の面での値を両側の平均で置いたものである。
反応と源項は頂点の値で代表させて $V_i\sum_{c'}C_{cc'}u_{c'}(\mathbf{x}_i)$、$V_if_c(\mathbf{x}_i)$ とする（集中化）。
頂点 $i$ の式は $\sum_jF_{ij}+V_i\sum_{c'}C_{cc'}u_{c'}=V_if_c$ で、面ごとに行 $i$ の対角へ $g+\beta$、列 $j$ へ $-g+\beta$ が加わる。

同じ $F_{ij}$ を $j$ の式では逆符号で使うので、内部の面の流束は二つの双対体積の間で打ち消し合う。
一様な格子と滑らかに変化する格子では内部の打切り誤差は 2 次で、任意の不等間隔の格子では 1 次に下がる。
一次元では、この差分は中点則で剛性を積分し反応と荷重を集中化した P1 有限要素と一致する。

### 移流と行列の非対称性

行 $j$ の式は $-F_{ij}$ を含むので、行 $j$ の列 $i$ には $-g-\beta$ が入る。
非対角の対 $(-g+\beta,\,-g-\beta)$ の差は $2\beta$ なので、移流があると行列は非対称になる。
反応行列 $C$ が非対称な場合も同じである。
対の大きいほう $-g+|\beta|$ は、格子 Péclet 数 $\mathrm{Pe}_h=|v|h/k$ が 2 を超えると正になる。
このとき行列は M 行列でなくなり、離散最大値原理が成り立たないので、境界層の近くで解が振動しうる。
Plan は中心平均だけを使い、風上化は提供しない。
移流が支配的な問題では $\mathrm{Pe}_h\le2$ まで格子を細かくするか、[保存則と数値流束](../conservation-laws/)の有限体積法を使う。

非対称な行列には CG を使えない。
反復法を注入しなければ、`EllipticProblem` は二次元以上の行列をフィルを抑える並べ替え付きの疎 LU 分解で解き、行列の対称性を仮定しない（[既定の直接法](oxref:pde-elliptic-solver-selection)）。
反復法を使うなら、GMRES（`scioxide_linalg::GmresSolver`）などの非対称向けの解法を注入する。

### 境界条件

境界条件は `StructuredBoundaries`（`BoundarySet` を領域とする `BoundaryConditions`）で与え、外部の面と成分の組ごとにちょうど一つの条件が必要である。
Neumann 条件（`BoundaryCondition::natural`）のデータは外向きの余法線流束 $\mathbf{n}\cdot k\nabla u=g$、Robin 条件は $\mathbf{n}\cdot k\nabla u+\alpha u=g$ である。
境界の頂点は接する外部の面それぞれから面積の $1/2^{D-1}$ を受け取り、その面積でデータを荷重に足す。
Neumann と Robin の面では、移流による流出 $(\mathbf{v}\cdot\mathbf{n})\,u$ がそのまま面を通り抜ける。

Dirichlet 条件の面はその面の頂点の値を固定する。
Neumann の面と Dirichlet の面が共有する頂点では Dirichlet が優先し、二つの Dirichlet 条件が同じ頂点で異なる値を与えると、既定（`DirichletConflictPolicy::Reject`）では荷重の評価が失敗する。
`assemble_csr` は固定した自由度を対称に消去する。
拘束した行と列を切り離して対角を 1 にし、自由な行の拘束した列の寄与は荷重に移す。
そのため移流がなく $C$ が対称なら行列は対称で、正定値なら CG で解ける。

全ての境界が余法線流束の条件（Neumann、または $\alpha=0$ の Robin）で、移流も反応もなければ、各成分に定数のモードが残る。
`has_constant_modes` でこれを確かめ、`check_constant_mode_compatibility` で荷重の適合条件を検査してから、[ゲージ](oxref:pde-nullspace-by-discretization)を課す。

### 成分の連成と計算量

反応行列 $C$ は同じ頂点の成分どうしだけを結ぶので、反応の非零要素は頂点あたり最大 $q^2$ 個である。
境界条件は `BoundaryCondition::for_component` で成分ごとに変えられる。
1 行の非零要素は自身、$2D$ 個の隣、他の $q-1$ 個の成分の最大 $2D+q$ 個で、準備の時間とメモリ領域は頂点の数 $n$ に比例する（$q$ を固定したとき）。
`SpatialLimits::new(max_unknowns, max_entries, max_storage_bytes)` を `with_options` に渡すと、確保の前に未知数、組立の三つ組の数、メモリ領域の上限を検査する。
`StructuredFdmPlan::dirichlet_laplacian(lower, upper, nodes)` は、直方体上の同次 Dirichlet 条件の $-\Delta$ を一度に作る。

## 二次元の Poisson 方程式の収束

次のセルは単位正方形の $-\Delta u=f$ に製造解 $u=x(1-x)\sin(m\pi y)$ を与え、$N\times N$ 頂点（$N=9,17,33$）で解く。
源項は $f=(2+(m\pi)^2x(1-x))\sin(m\pi y)$、境界条件は全周で $u=0$ である。
対称に消去した行列は対称正定値なので、`EllipticProblem` の作業領域に CG（`scioxide_linalg::CgSolver`）を注入し、相対残差 $10^{-12}$ まで反復する。
反復回数はレポートの `PdeDiagnostics::num_linear_iterations` で読む。
表は頂点での最大誤差と、一つ粗い格子との比から求めた観測次数 $p=\log_2(e_{2h}/e_h)$ を示す。

```rust
//| id: pde-structured-poisson-order
//| ref: pde-structured-poisson-order
//| title: 二次元の構造格子で Poisson 方程式を解き、収束次数を測る
//| run: button
//| crates: [scioxide-core, scioxide-linalg, scioxide-pde, scioxide-spatial]
//| inputs:
//|   structured_mode: {"type":"range","label":"正弦モード m [-]","description":"製造解の y 方向の波数を変える。","min":1,"max":3,"step":1,"value":1}
//| cases:
//|   - {"id":"third-mode","label":"m = 3","description":"誤差は N = 33 で 1.65×10⁻³ に上がるが、観測次数は 2.016 で 2 次が保たれる。","inputs":{"structured_mode":3}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"orders","path":"/rows/2/1","equals":1089}
//|       - {"artifact":"orders","path":"/rows/2/2","equals":4809}
//|       - {"artifact":"orders","path":"/rows/2/3","range":{"min":15,"max":30}}
//|       - {"artifact":"orders","path":"/rows/0/4","approx":{"value":1.6581716e-3,"rtol":1e-6}}
//|       - {"artifact":"orders","path":"/rows/2/4","approx":{"value":1.0294922e-4,"rtol":1e-6}}
//|       - {"artifact":"orders","path":"/rows/0/5","equals":null}
//|       - {"artifact":"orders","path":"/rows/2/5","approx":{"value":2.002,"atol":1e-3}}
//|   - case: third-mode
//|     expect:
//|       - {"artifact":"orders","path":"/rows/2/4","approx":{"value":1.6534476e-3,"rtol":1e-6}}
//|       - {"artifact":"orders","path":"/rows/2/5","approx":{"value":2.016,"atol":1e-3}}
use scioxide_core::{Budget, ExecutionContext, SciOxideError, LinearOperator, ResidualTolerance};
use scioxide_linalg::CgSolver;
use scioxide_pde::{
    BoundaryCondition, BoundaryData, EllipticOptions, EllipticProblem, EllipticWorkspace,
    FieldData, FieldPoint, SpatialDiscretization, SpatialLimits, StructuredBoundaries,
    StructuredFdmCoefficients, StructuredFdmPlan,
};
use scioxide_spatial::{AxisSide, AxisTopology, BoundarySet, CoordinateAxis, Grid2d, QuadMesh};
use std::f64::consts::PI;

// -Δu = f：拡散 1。移流と反応は既定の 0。
struct Laplace;
impl StructuredFdmCoefficients<f64, f64, 2> for Laplace {
    fn diffusion(&self, _: usize, _: usize, _: [f64; 2]) -> Result<f64, SciOxideError> {
        Ok(1.0)
    }
}
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let fixed3 = serde_json::json!({ "fractionDigits": 3 });
let k = structured_mode * PI;
// 製造解 u = x(1−x) sin(mπy) と源項 f = −Δu（参照値として f64 の sin を使う）。
let exact = move |p: [f64; 2]| p[0] * (1.0 - p[0]) * (k * p[1]).sin();
let source = FieldData::time_invariant(move |p: FieldPoint<f64, 2>| {
    let [x, y] = p.point;
    Ok((2.0 + k * k * x * (1.0 - x)) * (k * y).sin())
});
let elliptic = EllipticOptions::new();
let mut rows: Vec<(usize, usize, usize, usize, f64, Option<f64>)> = Vec::new();
for n in [9_usize, 17, 33] {
    let axis = CoordinateAxis::uniform(0.0, 1.0, n).map_err(|e| e.to_string())?;
    let grid = Grid2d::new([axis.clone(), axis], [AxisTopology::Bounded; 2])
        .map_err(|e| e.to_string())?;
    let mesh = QuadMesh::new(grid).map_err(|e| e.to_string())?;
    let mut conditions = Vec::new();
    for axis in 0..2 {
        for side in [AxisSide::Start, AxisSide::End] {
            let region =
                BoundarySet::axis_side(&mesh, axis, side).map_err(|e| e.to_string())?;
            conditions.push(BoundaryCondition::dirichlet(region, BoundaryData::zero()));
        }
    }
    let boundaries =
        StructuredBoundaries::new(&mesh, 1, conditions).map_err(|e| e.to_string())?;
    let limits = SpatialLimits::new(n * n, 20 * n * n, 1 << 24);
    let plan = StructuredFdmPlan::with_options(mesh, &Laplace, &boundaries, limits)
        .map_err(|e| e.to_string())?;
    // 対称に消去した作用素を CG で解く。反復法は作業領域に注入する。
    let cg = CgSolver::new(
        ResidualTolerance::new(0.0, 1e-12).map_err(|e| e.to_string())?,
        Budget::try_from(4 * plan.unknowns()).map_err(|e| e.to_string())?,
    );
    let mut workspace = EllipticWorkspace::new().with_linear_solver(Box::new(cg));
    let mut values = vec![0.0; plan.unknowns()];
    let report = EllipticProblem::new(&plan, &source)
        .solve_into(
            &elliptic,
            &mut values,
            &mut workspace,
            ExecutionContext::sequential(),
        )
        .map_err(|e| e.to_string())?;
    if !report.is_success() {
        return Err(format!("N={n}: CG 未収束 {}", report.termination()));
    }
    let mut error = 0.0_f64;
    for (node, u) in values.iter().enumerate() {
        let p = plan.dof_point(node).map_err(|e| e.to_string())?.point;
        error = error.max((u - exact(p)).abs());
    }
    let nonzeros = plan.assemble_csr().map_err(|e| e.to_string())?.nnz();
    // 格子幅は 1 段ごとに半分なので、観測次数は誤差の比の log₂。
    let order = rows.last().map(|r| (r.4 / error).log2());
    let iterations = report.diagnostics().num_linear_iterations();
    rows.push((n, plan.rows(), nonzeros, iterations, error, order));
}
let columns = serde_json::json!([
    { "key": "0", "label": "一辺の頂点数 N", "type": "integer" },
    { "key": "1", "label": "未知数", "type": "integer" },
    { "key": "2", "label": "CSR の非零要素", "type": "integer" },
    { "key": "3", "label": "CG の反復", "type": "integer" },
    { "key": "4", "label": "頂点での最大誤差 [-]", "type": "number", "format": sci3 },
    { "key": "5", "label": "観測次数 [-]", "type": "number", "format": fixed3, "nullText": "—" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "orders" })
);
```

既定（$m=1$）では、頂点での最大誤差は $N=9,17,33$ で $1.66\times10^{-3}$、$4.12\times10^{-4}$、$1.03\times10^{-4}$ と、格子幅を半分にするごとに約 1/4 になり、観測次数は 2.002 だった。
$m=3$ でも 2.016 である。
$x$ 方向は 2 次多項式なので中心差分の打切り誤差がなく、誤差は $y$ 方向の正弦関数だけから来る。
未知数は境界の頂点も含む $N^2$ で、境界の行は対角だけが残る。

CG の反復は 1089 未知数で 21 回と少ない。
一様格子では $\sin(m\pi y_j)$ が $y$ 方向の差分作用素の固有ベクトルなので、荷重と解はその一つのモードに沿い、Krylov 部分空間は実質的に $x$ 方向の一次元の問題の中で育つ。
一般の荷重では反復はもっと多くなり、前処理（`scioxide-sparse` の Jacobi や不完全分解など）を考える。

## 連成した移流拡散反応系の収束

次のセルは二つの成分が反応で連成し、第 1 成分だけが変数係数の拡散と移流を持つ系を単位正方形で解く。

$$
\begin{aligned}
-\nabla\cdot(k\nabla u_1)+b\,\partial_xu_1+u_1+\gamma u_2&=f_1,\\
-\Delta u_2-\gamma u_1+u_2&=f_2,
\end{aligned}
\qquad k(x,y)=1+\tfrac12xy
$$

製造解は $u_1=\sin\pi x\sin\pi y$、$u_2=\sin2\pi x\sin\pi y$ で、境界条件は全周で $u_1=u_2=0$ である。
$b$ は $x$ 方向の一様な移流の速度、$\gamma$ は反応行列 $C=\begin{pmatrix}1&\gamma\\-\gamma&1\end{pmatrix}$ の非対角である。
$b=\gamma=0$ なら行列は対称になり、どちらかが 0 でなければ非対称になる。
反復法を注入せず、`EllipticProblem` の既定の疎 LU 分解で解く。
表の非対称度は組み立てた行列 $A$ の $\max_{ij}|a_{ij}-a_{ji}|/\max_{ij}|a_{ij}|$ である。

```rust
//| id: pde-structured-fdm-order
//| ref: pde-structured-fdm-order
//| title: 反応で連成した二成分の移流拡散反応系を解き、収束次数と行列の非対称度を測る
//| run: button
//| crates: [scioxide-core, scioxide-pde, scioxide-spatial]
//| inputs:
//|   velocity: {"type":"range","label":"移流の速度 b [-]","description":"第 1 成分の x 方向の速度。","min":0,"max":40,"step":5,"value":10}
//|   coupling: {"type":"range","label":"反応の非対角 γ [-]","description":"反応行列 [[1, γ], [−γ, 1]] の非対角。","min":0,"max":2,"step":0.5,"value":1}

//|   - {"id":"symmetric","label":"b = 0, γ = 0","description":"移流も非対称な反応もないので、行列の非対称度は 0 になる。","inputs":{"velocity":0,"coupling":0}}
//|   - {"id":"strong-advection","label":"b = 40","description":"N = 9 と 17 では格子 Péclet 数の上界が 2 を超えて正の非対角が現れるが、滑らかな解なので 2 次の収束は保たれる。","inputs":{"velocity":40}}
//| tests:
//|   - case: default
//|     expect:

//|       - {"artifact":"system","path":"/rows/2/6","approx":{"value":2.0,"atol":0.1}}
//|       - {"artifact":"system","path":"/rows/2/7","approx":{"value":2.0,"atol":0.1}}
//|   - case: symmetric
//|     expect:
//|       - {"artifact":"system","path":"/rows/2/3","range":{"max":1e-15}}
//|       - {"artifact":"system","path":"/rows/2/6","approx":{"value":2.0,"atol":0.1}}
//|   - case: strong-advection
//|     expect:
//|       - {"artifact":"system","path":"/rows/0/1","approx":{"value":5,"rtol":1e-12}}
//|       - {"artifact":"system","path":"/rows/0/2","range":{"min":1}}
//|       - {"artifact":"system","path":"/rows/2/2","equals":0}
//|       - {"artifact":"system","path":"/rows/2/6","approx":{"value":2.0,"atol":0.2}}
use scioxide_core::SciOxideError;
use scioxide_pde::{
    BoundaryCondition, BoundaryData, EllipticOptions, EllipticProblem, FieldData, FieldPoint,
    SpatialDiscretization, StructuredBoundaries, StructuredFdmCoefficients, StructuredFdmPlan,

use scioxide_spatial::{AxisSide, AxisTopology, BoundarySet, CoordinateAxis, Grid2d, QuadMesh};
use std::collections::HashMap;
use std::f64::consts::PI;

// 第 1 成分：拡散 k = 1 + xy/2 と x 方向の速度 b。第 2 成分：拡散 1。反応 [[1, γ], [−γ, 1]]。
struct System {
    velocity: f64,
    coupling: f64,
}
impl StructuredFdmCoefficients<f64, f64, 2> for System {
    fn diffusion(&self, _: usize, component: usize, p: [f64; 2]) -> Result<f64, SciOxideError> {
        Ok(if component == 0 {
            1.0 + 0.5 * p[0] * p[1]
        } else {
            1.0
        })
    }
    fn advection(
        &self,
        axis: usize,
        component: usize,
        _: [f64; 2],
    ) -> Result<f64, SciOxideError> {
        Ok(if axis == 0 && component == 0 {
            self.velocity
        } else {
            0.0
        })
    }
    fn reaction(&self, row: usize, column: usize, _: [f64; 2]) -> Result<f64, SciOxideError> {
        let c = [[1.0, self.coupling], [-self.coupling, 1.0]];
        Ok(c[row][column])
    }
}
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let fixed2 = serde_json::json!({ "fractionDigits": 2 });
let fixed3 = serde_json::json!({ "fractionDigits": 3 });
let (b, g) = (velocity, coupling);
// 製造解（参照値として f64 の sin・cos を使う）。
let u1 = |x: f64, y: f64| (PI * x).sin() * (PI * y).sin();
let u2 = |x: f64, y: f64| (2.0 * PI * x).sin() * (PI * y).sin();
let source = FieldData::time_invariant(move |p: FieldPoint<f64, 2>| {
    let [x, y] = p.point;
    let (sx, cx, sy, cy) = (
        (PI * x).sin(),
        (PI * x).cos(),
        (PI * y).sin(),
        (PI * y).cos(),
    );
    let (a, c) = (u1(x, y), u2(x, y));
    Ok(if p.component == 0 {
        // −∇·(k∇u₁) = 2π²k u₁ − ∇k·∇u₁、移流 b ∂u₁/∂x。
        let diffusion =
            2.0 * PI * PI * (1.0 + 0.5 * x * y) * a - 0.5 * PI * (y * cx * sy + x * sx * cy);
        diffusion + b * PI * cx * sy + a + g * c
    } else {
        5.0 * PI * PI * c - g * a + c
    })
});
let coefficients = System {
    velocity: b,
    coupling: g,
};
let mut rows: Vec<(usize, f64, usize, f64, f64, f64, Option<f64>, Option<f64>)> = Vec::new();
for n in [9_usize, 17, 33] {
    let axis = CoordinateAxis::uniform(0.0, 1.0, n).map_err(|e| e.to_string())?;
    let grid = Grid2d::new([axis.clone(), axis], [AxisTopology::Bounded; 2])
        .map_err(|e| e.to_string())?;
    let mesh = QuadMesh::new(grid).map_err(|e| e.to_string())?;
    let mut conditions = Vec::new();
    for axis in 0..2 {
        for side in [AxisSide::Start, AxisSide::End] {
            let region =
                BoundarySet::axis_side(&mesh, axis, side).map_err(|e| e.to_string())?;
            conditions.push(BoundaryCondition::dirichlet(region, BoundaryData::zero()));
        }
    }
    // 成分を指定しない条件は二つの成分の両方に効く。
    let boundaries =
        StructuredBoundaries::new(&mesh, 2, conditions).map_err(|e| e.to_string())?;
    let plan =
        StructuredFdmPlan::new(mesh, &coefficients, &boundaries).map_err(|e| e.to_string())?;
    let solution = EllipticProblem::new(&plan, &source)
        .solve_with_options(&EllipticOptions::new())
        .map_err(|e| e.to_string())?;
    if !solution.report().is_success() {
        return Err(format!("N={n}: {}", solution.report().termination()));
    }
    // 非対称度 max|a_ij − a_ji| / max|a_ij| と、u₁ の成分の中の正の非対角要素の数。
    let matrix = plan.assemble_csr().map_err(|e| e.to_string())?;
    let mut entries = HashMap::new();
    let mut positive = 0_usize;
    for row in 0..matrix.rows() {
        for index in matrix.row_ptr()[row]..matrix.row_ptr()[row + 1] {
            let (column, value) = (matrix.col_indices()[index], matrix.values()[index]);
            if row != column && row < n * n && column < n * n && value > 0.0 {
                positive += 1;
            }
            entries.insert((row, column), value);
        }
    }
    let scale = entries.values().fold(0.0_f64, |m, v| m.max(v.abs()));
    let defect = entries.iter().fold(0.0_f64, |m, (&(i, j), &v)| {
        m.max((v - entries.get(&(j, i)).copied().unwrap_or(0.0)).abs())
    });
    let mut errors = [0.0_f64; 2];
    for (unknown, value) in solution.values().iter().enumerate() {
        let site = plan.dof_point(unknown).map_err(|e| e.to_string())?;
        let [x, y] = site.point;
        let exact = if site.component == 0 {
            u1(x, y)
        } else {
            u2(x, y)
        };
        errors[site.component] = errors[site.component].max((value - exact).abs());
    }
    let h = 1.0 / (n - 1) as f64;
    // k ≥ 1 なので bh は格子 Péclet 数 bh/k の上界。
    let peclet = b * h;
    let orders = rows
        .last()
        .map(|r| ((r.4 / errors[0]).log2(), (r.5 / errors[1]).log2()));
    let (p1, p2) = (orders.map(|o| o.0), orders.map(|o| o.1));
    rows.push((
        n,
        peclet,
        positive,
        defect / scale,
        errors[0],
        errors[1],
        p1,
        p2,
    ));
}
let columns = serde_json::json!([
    { "key": "0", "label": "一辺の頂点数 N", "type": "integer" },
    { "key": "1", "label": "格子 Péclet 数の上界 bh [-]", "type": "number", "format": fixed2 },
    { "key": "2", "label": "u₁ の正の非対角", "type": "integer" },
    { "key": "3", "label": "非対称度 [-]", "type": "number", "format": sci3 },
    { "key": "4", "label": "u₁ の最大誤差 [-]", "type": "number", "format": sci3 },
    { "key": "5", "label": "u₂ の最大誤差 [-]", "type": "number", "format": sci3 },
    { "key": "6", "label": "u₁ の観測次数 [-]", "type": "number", "format": fixed3, "nullText": "—" },
    { "key": "7", "label": "u₂ の観測次数 [-]", "type": "number", "format": fixed3, "nullText": "—" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "system" })
);
```

既定（$b=10$、$\gamma=1$）では、$N=9,17,33$ で $u_1$ の最大誤差が $1.69\times10^{-2}$、$4.30\times10^{-3}$、$1.07\times10^{-3}$ と約 1/4 ずつ減り、観測次数は 2.001 だった。
$u_2$ の観測次数も 2.006 で、変数係数、移流、成分の連成があっても内部の 2 次の打切り誤差がそのまま大域誤差の次数になる。
非対称度は $N=33$ で $5.3\times10^{-2}$ で、移流の項 $\beta=bA/2$ と拡散の項 $g=kA/h$ の比が $h$ に比例するので、格子を半分にするごとに約半分になる。
$b=\gamma=0$ では非対称度がちょうど 0 になる。
係数 $k$ は面の中心で一度だけ標本化され、同じ値が面の両側の行に入るからである。

$b=40$ では、$N=9$ で格子 Péclet 数の上界が 5 になり、$u_1$ の成分の中に正の非対角要素が 42 個現れる。
$N=17$ でも 183 個残り、$N=33$（上界 1.25）で 0 になる。
この製造解は境界層を持たない滑らかな関数なので、M 行列でなくなっても観測次数は 1.998 で、2 次の収束は保たれる。
境界層を持つ解で $\mathrm{Pe}_h>2$ の格子を使うと、離散解は境界層の手前で振動しうる。

## まとめ

`StructuredFdmPlan` は、構造格子の頂点で連成した拡散・移流・反応の方程式を、双対体積の面の流束の収支として離散化する。
拡散は面の中心で軸ごとに標本化するので、軸に沿った対角の異方性までを表せ、完全なテンソルには有限体積か有限要素を使う。
移流は面の両側の平均で近似し、風上化はないので、格子 Péclet 数 $|v|h/k$ が 2 以下になる格子を選ぶ。
移流か非対称な反応があると行列は非対称になるので、既定の疎 LU 分解か GMRES などで解き、純粋な拡散の問題では CG を注入できる。
二次元の製造解では、Poisson 方程式も連成した移流拡散反応系も頂点の最大誤差が 2 次で収束した。
