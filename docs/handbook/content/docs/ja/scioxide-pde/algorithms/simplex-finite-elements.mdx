このページは区間・三角形・四面体のメッシュ上の連続な有限要素法（FEM）を扱う。
`SimplexFemPlan` は P1 要素と P2 要素で連成した楕円型の弱形式を組み立て、幾何をアフィン写像か 2 次の写像で表す。
弱形式、自由度の並び、幾何の写像、求積、質量と剛性の組立、解の場の評価を順に説明し、二つのセルで収束次数と曲がった境界の幾何誤差を測る。
一次元の FEM の導出は[楕円問題の FDM・FEM・FVM](../elliptic-fdm-fem-fvm/)、構造格子の差分は[構造格子の多次元差分](../multidimensional-spatial-plans/)で扱う。

## 単体メッシュの有限要素

$\Omega\subset\mathbb{R}^D$（$D=1,2,3$）上の $q$ 成分の場 $u=(u_1,\dots,u_q)$ について、次の連立方程式を考える。

$$
-\sum_{b=1}^{q}\nabla\cdot(K_{ab}\nabla u_b)+\sum_{b=1}^{q}C_{ab}u_b=f_a,\qquad a=1,\dots,q
$$

$K_{ab}$ は成分 $a$ と $b$ を結ぶ $D\times D$ の拡散のブロック、$C$ は $q\times q$ の反応行列、$f_a$ は源項である。
試験関数 $v_a$ を掛けて部分積分すると、弱形式

$$
\sum_{a,b}\int_\Omega\left(\nabla v_a\cdot K_{ab}\nabla u_b+C_{ab}u_bv_a\right)dx+\sum_a\int_{\Gamma_R}\alpha\,u_av_a\,ds=\sum_a\int_\Omega f_av_a\,dx+\sum_a\int_{\Gamma_N\cup\Gamma_R}g_av_a\,ds
$$

になる。
境界の積分に現れる $g_a=\mathbf{n}\cdot\sum_bK_{ab}\nabla u_b$ が Neumann 条件の[外向きの余法線流束](oxref:pde-neumann-outward-sign)で、Robin 条件はこれに $\alpha u_a$ を加える。
Dirichlet 条件は試験関数の空間から外して、値を荷重に持ち上げる。

係数はトレイト `SimplexFemCoefficients` の `evaluate(point, diffusion, reaction)` で与える。
`diffusion` は $(qD)\times(qD)$ の行列を行優先で、添字の順は（成分, 方向）である。
`reaction` は $q\times q$ の行列で、呼び出しごとに全ての要素を書く。
拡散の行列はエルミート正定値でなければならず、要素ごとの相対 $32\,n\,\varepsilon$（$n=qD$）以内の非対称は $(K+K^{\mathsf H})/2$ に射影してから使う。
反応は有限なら任意の行列でよい。
係数は求積点でしか標本化しないので、求積点の間での正則性や正値性は保証されない。
`is_spatially_constant` が `true` を返すと位置に依らないと提示したことになり、準備は係数を一度だけ評価する。
源項 $f$ と境界データ $g$ は荷重を評価するときに `FieldData` と `BoundaryData` で渡し、時刻に依存してよい。

### 要素と自由度

`SimplexFemOrder::P1` は頂点に一つずつ、`P2` は頂点に加えて辺の中点に一つずつの自由度を持つ連続な区分多項式で、`degree` はそれぞれ 1 と 2 を返す。
三角形 1 枚の局所の自由度は P1 で 3、P2 で 6、四面体では 4 と 10 である。
成分ごとの自由度は頂点、その後に正準な辺の順に並び（`dofs_per_component`）、全体の未知数は成分ごとにまとまる。
`cell_dofs(cell)` はセルの局所の自由度に対応する全体の節点番号（成分のずらしを加える前）を、`node_point(node)` は補間点の物理座標を返す。

### 幾何の写像

参照単体から物理要素への写像は `SimplexFemGeometry` で選ぶ。
`Affine` はメッシュの頂点で決まるアフィン写像で、要素は直線の辺を持つ。
`Quadratic(edges)` は辺の中点の物理座標を正準な辺の順に `FieldView` で与え、各要素を 2 次の写像で曲げる。
隣のセルは同じ辺の中点の座標を共有するので、曲げた要素の境界も一致し、関数空間は連続のままである。
幾何の次数は解の次数と独立に選べ、P2 の解と 2 次の幾何を組み合わせると等パラメトリック要素になる。

`map(cell, reference)` は参照座標の点を写し、`SimplexFemMappedPoint` を返す。
`point` は物理座標、`jacobian` はヤコビ行列 $J=\partial x/\partial\hat x$、`inverse_jacobian` はその逆、`determinant` は $\det J>0$、`reciprocal_condition` は $\infty$ ノルムでの逆条件数の推定である。
準備は全ての幾何の補間点でこれらを検査し、向きが反転した要素と、逆条件数が `with_minimum_reciprocal_condition` の値（既定は $64\varepsilon$）を下回る要素を拒否する。

### 求積

要素の積分は単体上の求積で行う。
既定では `scioxide_integrate::SimplexRule::positive` が、全ての重みが正で節点が内部にある規則を選ぶ。
線分では Gauss–Legendre 則、三角形と四面体では Xiao–Gimbutas の表の規則で、正確に積分する多項式の次数は、アフィン写像で $2p$（$p$ は要素の次数）、2 次の写像で 7 である。
面の積分にも同じ次数の $D-1$ 次元の規則を使う。

| 次数 | 2 | 4 | 7 |
|---|---|---|---|
| 三角形の節点数 | 3 | 6 | 15 |
| 四面体の節点数 | 4 | 11 | 31 |

アフィン写像では $\det J$ が定数なので、次数 $2p$ の規則は一定の係数の質量行列（被積分関数の次数 $2p$）と剛性行列（$2p-2$）を正確に積分する。
2 次の写像では $\det J$ が 2 次の多項式で、逆ヤコビ行列は有理関数なので、剛性行列は近似になる。
`SimplexFemOptions::with_volume_rule` と `with_facet_rule` で別の規則を渡せるが、次元と正確な次数が足りない規則は拒否する。
負の重みを持つ規則を渡すと、正の重みによる正値性の性質は失われる。

### 質量と剛性の組立

準備の段階で、各セルの要素行列（拡散、反応、Robin の項）と整合質量行列を一度だけ計算して保持する。
アフィン写像で係数が位置に依らなければ、参照要素上の基底の積と勾配の積の積分を一度だけ求め、各セルではヤコビ行列による変換だけを行う。
`element_matrix(cell)` と `element_mass(cell)` は境界条件の消去をしていない局所の行列を返す。

`assemble_csr` は全体の行列を CSR で返し、Dirichlet の自由度を対称に消去する。
拡散がエルミート正定値で反応が対称なら、消去後の行列は対称になり、CG で解ける。
`assemble_mass_csr` は消去しない整合質量 $M_{ij}=\int\varphi_i\varphi_j\,dx$ を返し、`mass_operator` は同じ質量を `SimplexFemMassOperator` として返す。
`SimplexFemMassOperator` は `LinearOperator` を実装し、質量は実対称なので随伴は自分自身である。
時間発展の Plan が使う `lumped_mass` は、要素の質量の対角を要素の全質量に合わせて拡大する HRZ 法の集中質量で、P1 と P2 のどちらでも正になる。

行列の非零構造は準備の段階でセルと自由度の接続と Dirichlet の消去から一度だけ決まり、和が数値的に 0 になる要素も構造に残す。
`assembly_workspace` は構造上の要素ごとに一つの値を持つ `SimplexCsrWorkspace` を確保する。
これを使うと、`assemble_csr_into`（質量では `mass_assembly_workspace` と `assemble_mass_csr_into`）が、同じ構造の既存の CSR に確保なしで値を書き直し、失敗したときは出力を変えない。
寄与はセルの順に足すので、結果は実行のワーカー数（`with_execution_policy`、最大 32）に依らない。

### 解の場と点での評価

`fields(values)` は未知数の並びを `SimplexFemField` に変換し、`vertices` は成分ごとの頂点の場、`edges` は P2 の辺の中点の場を返す。
逆向きには、借用した頂点と辺の場から `SimplexFemFieldView::new(vertices, edges)` を作り、`pack_fields_into` で未知数の並びに詰める。
`apply_fields` は同じ借用の場に作用素を適用し、所有する場を返す。

`evaluate_into(cell, reference, input, values, gradients)` は、セルの参照座標の点で解の値と物理座標での勾配を成分ごとに求める。
読むのはそのセルの自由度だけで、作業領域は要らず、全成分の評価が成功してから出力を書く。
勾配は参照要素の基底の勾配に逆ヤコビ行列の転置を掛けて求める。
`basis_into` は参照要素の基底の値と勾配を返す。

### 上限と誤差の目安

`SimplexFemLimits::new(max_unknowns, max_element_entries, max_quadrature_nodes, max_storage_bytes)` は、未知数、要素行列の要素の総数、求積の節点数、準備のメモリ領域の上限を準備の前に検査する。
既定は求積の節点数だけが 31 で、他は上限なしである。
`preparation_storage_bound` は準備で同時に使うメモリ領域の見積もりを返す。

滑らかな解と形の整ったメッシュの族では、次数 $p$ の要素の誤差は $H^1$ ノルムで $O(h^p)$、$L^2$ ノルムで $O(h^{p+1})$ である（Brenner–Scott）。
最大値ノルムでも P2 では $O(h^3)$ が期待できる。
一様な三角形分割の節点では、これより速く収束する超収束が起こることがある。
曲がった境界を直線の辺で近似すると、領域の誤差は $O(h^2)$ で、P2 要素の精度はそこで頭打ちになる。

## P1・P2 の収束と場の評価

次のセルは単位正方形の $-\Delta u=f$ に製造解 $u=x(1-x)\sin(m\pi y)$ を与え、$N\times N$ 頂点（$N=9,17,33$）の正方格子の各正方形を 2 つの三角形に分けたメッシュで、P1 と P2 の要素により解く。
全ての外部の面にタグ 1 を付け、一つの Dirichlet 条件で境界を覆う。
消去した行列は対称正定値なので、CG で相対残差 $10^{-12}$ まで反復する。

誤差は三か所で測る。
一つは全ての自由度の補間点での最大誤差、もう一つは各セルの参照座標 $(0.2,0.3)$ の点（補間点でない内部の点）で `evaluate_into` が返す値の最大誤差、最後は同じ点の勾配の誤差 $\max|\nabla u_h-\nabla u|$ である。
点の物理座標は `map` で求める。
最初の表は格子ごとの誤差、二つ目の表は最も細かい二つの格子による観測次数である。

```rust
//| id: pde-simplex-fem-orders
//| ref: pde-simplex-fem-orders
//| title: 三角形メッシュの P1・P2 要素で Poisson 方程式を解き、節点と内部の点で誤差を比べる
//| run: button
//| crates: [scioxide-core, scioxide-linalg, scioxide-pde, scioxide-spatial]
//| inputs:
//|   simplex_mode: {"type":"range","label":"正弦モード m [-]","description":"製造解の y 方向の波数を変える。","min":1,"max":3,"step":1,"value":1}
//| cases:
//|   - {"id":"third-mode","label":"m = 3","description":"誤差は大きくなるが、内部の点での P2 の次数は 3 のままである。","inputs":{"simplex_mode":3}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"errors","path":"/rows/4/2","equals":1089}
//|       - {"artifact":"errors","path":"/rows/5/2","equals":4225}
//|       - {"artifact":"errors","path":"/rows/4/3","range":{"min":50,"max":90}}
//|       - {"artifact":"errors","path":"/rows/4/4","approx":{"value":1.9564156e-4,"rtol":1e-5}}
//|       - {"artifact":"errors","path":"/rows/5/4","approx":{"value":1.6560928e-7,"rtol":1e-4}}
//|       - {"artifact":"orders","path":"/rows/0/1","approx":{"value":1.997,"atol":0.01}}
//|       - {"artifact":"orders","path":"/rows/1/1","approx":{"value":3.998,"atol":0.01}}
//|       - {"artifact":"orders","path":"/rows/1/2","approx":{"value":3.0,"atol":0.15}}
//|       - {"artifact":"orders","path":"/rows/1/3","approx":{"value":2.0,"atol":0.15}}
//|   - case: third-mode
//|     expect:
//|       - {"artifact":"errors","path":"/rows/4/4","approx":{"value":5.0276758e-4,"rtol":1e-5}}
//|       - {"artifact":"orders","path":"/rows/1/2","approx":{"value":3.0,"atol":0.15}}
use scioxide_core::{Budget, ExecutionContext, SciOxideError, ResidualTolerance};
use scioxide_linalg::CgSolver;
use scioxide_pde::{
    BoundaryCondition, BoundaryData, EllipticOptions, EllipticProblem, EllipticWorkspace,
    FieldData, FieldPoint, SimplexFemCoefficients, SimplexFemGeometry, SimplexFemLimits,
    SimplexFemOptions, SimplexFemOrder, SimplexFemPlan, SpatialDiscretization,
    TaggedBoundaries,
};
use scioxide_spatial::{Point, SimplexBoundaryTags, TriangleMesh};
use std::f64::consts::PI;

// 拡散 = 単位行列、反応 0。位置に依らないと提示する。
struct Poisson;
impl SimplexFemCoefficients<f64, f64, 2> for Poisson {
    fn is_spatially_constant(&self) -> bool {
        true
    }
    fn evaluate(&self, _: [f64; 2], k: &mut [f64], c: &mut [f64]) -> Result<(), SciOxideError> {
        k.copy_from_slice(&[1.0, 0.0, 0.0, 1.0]);
        c[0] = 0.0;
        Ok(())
    }
}
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let fixed3 = serde_json::json!({ "fractionDigits": 3 });
let k = simplex_mode * PI;
// 製造解とその勾配（参照値として f64 の sin・cos を使う）。
let exact = move |p: [f64; 2]| p[0] * (1.0 - p[0]) * (k * p[1]).sin();
let grad = move |p: [f64; 2]| {
    let [x, y] = p;
    [
        (1.0 - 2.0 * x) * (k * y).sin(),
        k * x * (1.0 - x) * (k * y).cos(),
    ]
};
let source = FieldData::time_invariant(move |p: FieldPoint<f64, 2>| {
    let [x, y] = p.point;
    Ok((2.0 + k * k * x * (1.0 - x)) * (k * y).sin())
});
let limits = SimplexFemLimits::new(1 << 16, 1 << 20, 64, 1 << 26);
let mut rows: Vec<(&str, usize, usize, usize, f64, f64, f64)> = Vec::new();
for n in [9_usize, 17, 33] {
    let scale = (n - 1) as f64;
    let points = (0..n * n)
        .map(|i| Point::new([(i % n) as f64 / scale, (i / n) as f64 / scale]))
        .collect::<Result<Vec<_>, _>>()
        .map_err(|e| e.to_string())?;
    let mut cells = Vec::new();
    for j in 0..n - 1 {
        for i in 0..n - 1 {
            let v = j * n + i;
            cells.push([v, v + 1, v + n + 1]);
            cells.push([v, v + n + 1, v + n]);
        }
    }
    let mesh = TriangleMesh::new(points, cells).map_err(|e| e.to_string())?;
    let faces = mesh.boundary_faces().map(|face| (face, 1)).collect();
    let tags = SimplexBoundaryTags::new(&mesh, faces).map_err(|e| e.to_string())?;
    let conditions = vec![BoundaryCondition::dirichlet(1, BoundaryData::zero())];
    let boundaries =
        TaggedBoundaries::new(&mesh, &tags, 1, conditions).map_err(|e| e.to_string())?;
    for (label, order) in [("P1", SimplexFemOrder::P1), ("P2", SimplexFemOrder::P2)] {
        let options = SimplexFemOptions::new().with_limits(limits);
        let geometry = SimplexFemGeometry::Affine;
        let plan = SimplexFemPlan::with_options(
            mesh.clone(),
            geometry,
            order,
            &Poisson,
            &boundaries,
            options,
        )
        .map_err(|e| e.to_string())?;
        let cg = CgSolver::new(
            ResidualTolerance::new(0.0, 1e-12).map_err(|e| e.to_string())?,
            Budget::try_from(10 * plan.unknowns()).map_err(|e| e.to_string())?,
        );
        let mut workspace = EllipticWorkspace::new().with_linear_solver(Box::new(cg));
        let mut values = vec![0.0; plan.unknowns()];
        let report = EllipticProblem::new(&plan, &source)
            .solve_into(
                &EllipticOptions::new(),
                &mut values,
                &mut workspace,
                ExecutionContext::sequential(),
            )
            .map_err(|e| e.to_string())?;
        if !report.is_success() {
            return Err(format!("{label} N={n}: CG 未収束 {}", report.termination()));
        }
        let mut nodal = 0.0_f64;
        for (node, u) in values.iter().enumerate() {
            let p = plan.dof_point(node).map_err(|e| e.to_string())?.point;
            nodal = nodal.max((u - exact(p)).abs());
        }
        // 各セルの参照座標 (0.2, 0.3) で値と物理勾配を評価する。
        let (mut inner, mut slope) = (0.0_f64, 0.0_f64);
        let (mut value, mut gradient) = ([0.0], [[0.0; 2]]);
        for cell in 0..plan.mesh().cell_count() {
            let p = plan
                .map(cell, [0.2, 0.3])
                .map_err(|e| e.to_string())?
                .point();
            plan.evaluate_into(cell, [0.2, 0.3], &values, &mut value, &mut gradient)
                .map_err(|e| e.to_string())?;
            inner = inner.max((value[0] - exact(p)).abs());
            let g = grad(p);
            slope = slope.max((gradient[0][0] - g[0]).hypot(gradient[0][1] - g[1]));
        }
        let iterations = report.diagnostics().num_linear_iterations();
        rows.push((label, n, plan.unknowns(), iterations, nodal, inner, slope));
    }
}
let errors = serde_json::json!([
    { "key": "0", "label": "要素" },
    { "key": "1", "label": "一辺の頂点数 N", "type": "integer" },
    { "key": "2", "label": "未知数", "type": "integer" },
    { "key": "3", "label": "CG の反復", "type": "integer" },
    { "key": "4", "label": "補間点の最大誤差 [-]", "type": "number", "format": sci3 },
    { "key": "5", "label": "内部の点の最大誤差 [-]", "type": "number", "format": sci3 },
    { "key": "6", "label": "勾配の最大誤差 [-]", "type": "number", "format": sci3 }
]);
// 最も細かい二つの格子（h の比 2）による観測次数。
let observed = |label: &str, column: usize| {
    let e: Vec<f64> = rows
        .iter()
        .filter(|r| r.0 == label)
        .map(|r| [r.4, r.5, r.6][column])
        .collect();
    (e[1] / e[2]).log2()
};
let orders: Vec<(&str, f64, f64, f64)> = ["P1", "P2"]
    .into_iter()
    .map(|label| {
        (
            label,
            observed(label, 0),
            observed(label, 1),
            observed(label, 2),
        )
    })
    .collect();
let order_columns = serde_json::json!([
    { "key": "0", "label": "要素" },
    { "key": "1", "label": "補間点 [-]", "type": "number", "format": fixed3 },
    { "key": "2", "label": "内部の点 [-]", "type": "number", "format": fixed3 },
    { "key": "3", "label": "勾配 [-]", "type": "number", "format": fixed3 }
]);
emit_table_with_columns!(
    errors,
    rows,
    metadata = serde_json::json!({ "id": "errors" })
);
emit_table_with_columns!(
    order_columns,
    orders,
    metadata = serde_json::json!({ "id": "orders" })
);
```

既定（$m=1$）では、P1 の補間点の誤差が $N=33$ で $1.96\times10^{-4}$、P2 が $1.66\times10^{-7}$ で、補間点での観測次数は P1 が 1.997、P2 が 3.998 だった。
内部の点では P1 が 1.994、P2 が 3.010 で、P2 の補間点の 4 次は一様な三角形分割で起こる超収束である。
内部の点の誤差は P2 で $4.56\times10^{-6}$ と、補間点の 27 倍あり、精度を論じるときは評価する点を明示する必要がある。
勾配の誤差の次数は P1 が 0.969、P2 が 1.990 で、理論の $O(h^p)$ に合う。
P2 は同じ頂点数で未知数が約 4 倍になり、CG の反復も増える（$N=33$ で P1 が 67 回、P2 が 151 回）が、同じ誤差に必要な未知数ははるかに少ない。

## 曲がった境界と 2 次の幾何

次のセルは単位円板 $\Omega=\{|x|<1\}$ で $-\Delta u=1$、境界で $u=0$ の問題を P2 要素（入力で P1 に切り替えられる）で解く。
厳密解は $u=(1-|x|^2)/4$ で、2 次の多項式なので、P2 要素の誤差は解の近似からはほとんど生じない。
誤差の主な源は境界を要素の辺で近似する幾何誤差である。

メッシュは中心と半径 $k/n$（$k=1,\dots,n$）の円周上に等間隔に置いた $6k$ 個の頂点を、隣り合う円周の間で三角形に分けて作る（$n=4,8,16$）。
境界は正 $6n$ 角形で、全ての三角形の形はほぼそろっている。
`Affine` では境界の辺の中点の自由度は弦の中点に置かれる。
`Quadratic` には全ての辺の中点を渡し、境界の辺だけは中点を半径方向に円の上へ移すので、境界の辺は円に内接する放物線の弧になる。

表の誤差は全ての補間点での最大誤差である。
$\mathbf{1}^{\mathsf T}M\mathbf{1}$ は `mass_operator` で全て 1 のベクトルに整合質量を掛けた和で、離散化した領域の面積 $\int_{\Omega_h}1\,dx$ に等しい。
これを円の面積 $\pi$ と比べ、さらに解析的に求めた離散領域の面積と比べる。
アフィン写像の領域は正 $6n$ 角形で、面積は $3n\sin(\pi/3n)$ である。
2 次の写像では各辺が放物線の弧で、弧と弦の間の面積は Archimedes の求積により、両端と中点を結ぶ三角形の面積 $\sin\theta\,(1-\cos\theta)$（$\theta=\pi/6n$）の $4/3$ 倍になる。
被積分関数はアフィン写像では 4 次、2 次の写像でも $\det J$ を含めて 6 次の多項式なので、求積は二つの面積を丸めの範囲で再現するはずである。

```rust
//| id: pde-simplex-fem-curved-geometry
//| ref: pde-simplex-fem-curved-geometry
//| title: 円板の Poisson 方程式を P2 要素のアフィン写像と 2 次の写像で解き、幾何誤差と面積を比べる
//| run: button
//| crates: [scioxide-core, scioxide-pde, scioxide-spatial]
//| inputs:
//|   element: {"type":"select","label":"解の要素","options":["P2","P1"],"value":"P2"}
//| cases:
//|   - {"id":"linear-elements","label":"P1","description":"P1 では解の近似の誤差も 2 次なので、2 次の写像にしても次数は 2 のままである。","inputs":{"element":"P1"}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"disk","path":"/rows/2/4","approx":{"value":2.0,"atol":0.2}}
//|       - {"artifact":"disk","path":"/rows/5/4","range":{"min":2.8}}
//|       - {"artifact":"disk","path":"/rows/2/7","range":{"max":1e-12}}
//|       - {"artifact":"disk","path":"/rows/5/7","range":{"max":1e-12}}
//|   - case: linear-elements
//|     expect:
//|       - {"artifact":"disk","path":"/rows/5/4","approx":{"value":2.0,"atol":0.2}}
//|       - {"artifact":"disk","path":"/rows/5/7","range":{"max":1e-12}}
use scioxide_core::{SciOxideError, LinearOperator};
use scioxide_pde::{
    BoundaryCondition, BoundaryData, ConstantDiffusion, EllipticOptions, EllipticProblem,
    FieldData, SimplexFemGeometry, SimplexFemOrder, SimplexFemPlan, SpatialDiscretization,
    TaggedBoundaries,
};
use scioxide_spatial::{Point, SimplexBoundaryTags, TriangleMesh, UnstructuredEdgeField};
use std::f64::consts::PI;

let exact = |p: [f64; 2]| 0.25 * (1.0 - p[0] * p[0] - p[1] * p[1]);
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let fixed3 = serde_json::json!({ "fractionDigits": 3 });
let order = if element == "P1" {
    SimplexFemOrder::P1
} else {
    SimplexFemOrder::P2
};
// 半径 k/n の円周 k に 6k 個の頂点を置く。円周 k の j 番目の頂点の番号。
let vertex = |k: usize, j: usize| {
    if k == 0 {
        0
    } else {
        1 + 3 * k * (k - 1) + j % (6 * k)
    }
};
let mut rows: Vec<(&str, usize, usize, f64, Option<f64>, f64, f64, f64)> = Vec::new();
for kind in ["Affine", "Quadratic"] {
    let mut previous: Option<f64> = None;
    for n in [4_usize, 8, 16] {
        let mut points = vec![Point::new([0.0, 0.0]).map_err(|e| e.to_string())?];
        for k in 1..=n {
            for j in 0..6 * k {
                let angle = 2.0 * PI * j as f64 / (6 * k) as f64;
                let r = k as f64 / n as f64;
                points.push(
                    Point::new([r * angle.cos(), r * angle.sin()])
                        .map_err(|e| e.to_string())?,
                );
            }
        }
        // 円周 k − 1 と k の間の 6 つの扇形を、それぞれ 2k − 1 枚の三角形で埋める。
        let mut cells = Vec::new();
        for k in 1..=n {
            for s in 0..6 {
                for t in 0..k {
                    let inner = |t: usize| vertex(k - 1, s * (k - 1) + t);
                    cells.push([inner(t), vertex(k, s * k + t), vertex(k, s * k + t + 1)]);
                    if t + 1 < k {
                        cells.push([inner(t), vertex(k, s * k + t + 1), inner(t + 1)]);
                    }
                }
            }
        }
        let mesh = TriangleMesh::new(points, cells).map_err(|e| e.to_string())?;
        // 辺の中点。境界の辺だけ中点を円の上へ半径方向に移す。
        let mut midpoints = Vec::new();
        for edge in 0..mesh.edge_count() {
            let [u, v] = *mesh.edge_vertices(edge).map_err(|e| e.to_string())?;
            let (p, q) = (mesh.points()[u].as_array(), mesh.points()[v].as_array());
            midpoints.push([0.5 * (p[0] + q[0]), 0.5 * (p[1] + q[1])]);
        }
        for face in mesh.boundary_faces() {
            let m = midpoints[face];
            midpoints[face] = [m[0] / m[0].hypot(m[1]), m[1] / m[0].hypot(m[1])];
        }
        // 離散領域の面積：正 6n 角形と、2 次の写像では各辺の放物線の弧の分（三角形の 4/3 倍）。
        let half = PI / (6 * n) as f64;
        let mut area = 3.0 * n as f64 * (2.0 * half).sin();
        if kind == "Quadratic" {
            area += (6 * n) as f64 * 4.0 / 3.0 * half.sin() * (1.0 - half.cos());
        }
        let edges = UnstructuredEdgeField::new(&mesh, midpoints).map_err(|e| e.to_string())?;
        let geometry = if kind == "Affine" {
            SimplexFemGeometry::Affine
        } else {
            SimplexFemGeometry::Quadratic(edges.view())
        };
        let faces = mesh.boundary_faces().map(|face| (face, 1)).collect();
        let tags = SimplexBoundaryTags::new(&mesh, faces).map_err(|e| e.to_string())?;
        let conditions = vec![BoundaryCondition::dirichlet(1, BoundaryData::zero())];
        let boundaries =
            TaggedBoundaries::new(&mesh, &tags, 1, conditions).map_err(|e| e.to_string())?;
        let unit = ConstantDiffusion::new(1.0);
        let plan = SimplexFemPlan::new(mesh.clone(), geometry, order, &unit, &boundaries)
            .map_err(|e| e.to_string())?;
        let solution = EllipticProblem::new(&plan, &FieldData::constant(1.0))
            .solve_with_options(&EllipticOptions::new())
            .map_err(|e| e.to_string())?;
        if !solution.report().is_success() {
            return Err(format!("{kind} N={n}: {}", solution.report().termination()));
        }
        let mut error = 0.0_f64;
        for (node, u) in solution.values().iter().enumerate() {
            let p = plan.dof_point(node).map_err(|e| e.to_string())?.point;
            error = error.max((u - exact(p)).abs());
        }
        // 1ᵀM1：整合質量を全て 1 のベクトルに掛けた和。
        let mass = plan.mass_operator();
        let ones = vec![1.0; mass.cols()];
        let mut product = vec![0.0; mass.rows()];
        let mut scratch = vec![0.0; mass.apply_workspace_len().map_err(|e| e.to_string())?];
        mass.apply_into(&ones, &mut product, &mut scratch)
            .map_err(|e| e.to_string())?;
        let measured = product.iter().sum::<f64>();
        let observed = previous.map(|e| (e / error).log2());
        previous = Some(error);
        let gap = (measured - area).abs();
        rows.push((
            kind,
            n,
            plan.unknowns(),
            error,
            observed,
            measured - PI,
            area,
            gap,
        ));
    }
}
let columns = serde_json::json!([
    { "key": "0", "label": "幾何" },
    { "key": "1", "label": "分割数 N", "type": "integer" },
    { "key": "2", "label": "未知数", "type": "integer" },
    { "key": "3", "label": "補間点の最大誤差 [-]", "type": "number", "format": sci3 },
    { "key": "4", "label": "観測次数 [-]", "type": "number", "format": fixed3, "nullText": "—" },
    { "key": "5", "label": "1ᵀM1 − π [-]", "type": "number", "format": sci3 },
    { "key": "6", "label": "離散領域の面積 [-]", "type": "number", "format": { "significantDigits": 8 } },
    { "key": "7", "label": "|1ᵀM1 − 面積| [-]", "type": "number", "format": sci3 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "disk" })
);
```

既定（P2）では、アフィン写像の補間点の誤差は $n=4,8,16$ で $4.26\times10^{-3}$、$1.07\times10^{-3}$、$2.68\times10^{-4}$ と、観測次数 1.998 の 2 次で減った。
2 次の写像では $1.15\times10^{-4}$、$1.52\times10^{-5}$、$1.95\times10^{-6}$ と、観測次数 2.963 で 3 次に近づき、$n=16$ の誤差はアフィン写像の約 1/140 である。
未知数は同じなので、この差は境界の近似だけから来る。
$\mathbf{1}^{\mathsf T}M\mathbf{1}-\pi$ は $n=16$ でアフィン写像が $-2.24\times10^{-3}$、2 次の写像が $-1.20\times10^{-7}$ で、多角形の面積の誤差は $O(h^2)$、放物線の弧で囲んだ面積の誤差は $O(h^4)$ で減る。
どちらの幾何でも $\mathbf{1}^{\mathsf T}M\mathbf{1}$ は解析的な面積と $10^{-14}$ 程度で一致し、求積が質量行列を正確に積分していることを確かめられる。

P1 にすると、2 次の写像でも観測次数は 1.93 で、解の近似の 2 次の誤差が残るので、写像を高次にしても次数は上がらない。
この問題では、2 次の写像の P1 の誤差（$n=16$ で $2.62\times10^{-4}$）はアフィン写像（$8.02\times10^{-5}$）より大きい。
2 次の写像で曲げた境界の要素では、参照座標の 1 次関数が物理座標の 1 次関数にならないので、P1 の空間はそこで物理座標の 1 次関数を含まない。
2 次の写像は、P2 以上の要素で曲がった境界の精度を保つために使う。

## まとめ

`SimplexFemPlan` は、区間・三角形・四面体の P1・P2 要素で連成した楕円型の弱形式を組み立て、Dirichlet の自由度を対称に消去した行列と、消去しない整合質量を返す。
求積は既定で正の重みと内部の節点を持つ規則で、アフィン写像なら次数 $2p$ で質量と一定の係数の剛性を正確に積分する。
一様な三角形分割では P2 の補間点の誤差が 4 次の超収束を示すが、`evaluate_into` で内部の点を評価すると 3 次、勾配は 2 次であり、次数を論じるときは評価する点とメッシュの族を明示する。
曲がった境界では、アフィン写像の P2 要素は幾何誤差で 2 次に頭打ちになり、`SimplexFemGeometry::Quadratic` で境界の辺の中点を曲線の上に置くと 3 次に戻る。
$\mathbf{1}^{\mathsf T}M\mathbf{1}$ と離散領域の面積の比較は、写像と求積を独立に確かめる簡単な方法である。
