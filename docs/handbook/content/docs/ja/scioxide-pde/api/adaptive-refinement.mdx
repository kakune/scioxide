このページは誤差推定に基づいてメッシュを細分化する一連の項目をまとめる。
メッシュのトポロジーと細分化の実行（均衡の検査と確定）は `scioxide-spatial` の `AdaptiveMesh` が所有し、このクレートは節点空間、拡散問題の組立、誤差推定、マーキング、場の転送を提供する。
連立方程式の解法は利用者が選ぶ。
一回の循環は、解く、`AmrEstimator::estimate_into` で推定する、`AmrMarking::mark` でマーカーを付ける、`AdaptiveMesh::adapt(marks.request())` で位相を変える、新しい `AmrSpace` を作って `AmrBoundaryTags::transfer` でラベルを移す、`AmrNodalTransfer` か `AmrCellTransfer` で場を移す、の順に進む。
新しい空間・ラベル・場は、すべての段階が成功してから古いものと置き換える。
境界条件は他の族と同じ `BoundaryCondition` の語彙で書き、`TaggedBoundaries::adaptive` で適応メッシュの revision に結び付ける。

## まとめ

適応細分化は、推定・マーキング・位相の変更・場の転送を利用者が順に呼ぶ循環として組み立てる。
推定量は形状正則なスカラー拡散を対象とする指標であり、誤差の上界ではない。
マーキングは二乗寄与の総和に対する割合で決定論的に選ばれ、均衡の検査と確定は `scioxide-spatial` が行う。
場の転送では、セル平均の保存（`AmrCellTransfer`）と節点の補間・$L^2$ 射影（`AmrNodalTransfer`）を目的に応じて選ぶ。
どの準備も `AmrLimits` でリソースを制限でき、`with_options` か `build` で上限や実行コンテキストを与える。
