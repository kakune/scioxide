このページは離散化した偏微分方程式の目的関数 $J$ のパラメータ勾配を随伴法で求める項目をまとめる。
線形の Plan は自分の係数・源項・境界データの微分を `PdeParameterization` として組み立て、`PdeEllipticAdjointPlan` と `PdeTransientAdjointPlan` がそれを使う。
それ以外の残差は、呼び出し側が与える微分の作用素を `PdeDiscretizationDerivatives` が陰的に微分する。
メッシュの座標は微分せず、幾何・求積・境界の分割は固定する。
時間方向の逆走査とチェックポイントは `scioxide-ode` の随伴 Plan が担い、目的関数は `scioxide_ode::AdjointObjective` で与える。
得られる勾配は離散化した問題の勾配であり、連続問題の勾配の精度は保証しない。

## 定常問題の随伴

平衡点 $R(u,p)=0$ で随伴方程式 $R_u^{*}\lambda=J_u$ を解き、全勾配 $dJ/dp=J_p-R_p^{*}\lambda$ を得る。
平衡点は利用者が先に求めておき、Plan はそれが平衡点であることを主の許容誤差で検査する。

## 時間発展の随伴

`PdeTransientAdjointPlan` は、`ParabolicProblem` が同じ `ParabolicScheme` で積分する固定刻みの時間離散化そのものを、自由な未知数の線の方法の系 $Mu_f'=b_f(t,p)-(A(p)u)_f$ の上で微分する。
後退 Euler は `DaeAdjointSolver::backward_euler`、Crank–Nicolson は `DaeAdjointSolver::trapezoid`、DOPRI5 は adapter の刻みの上限を付けた `OdeAdjointSolver` に対応する。

## まとめ

線形の Plan では `parameterize` で係数・源項・境界データの微分を作り、定常なら `PdeEllipticAdjointPlan`、放物型の時間発展なら `PdeTransientAdjointPlan` で勾配を求める。
それ以外の残差は `PdeDiscretizationDerivatives` で残差と微分の作用素を束縛し、呼び出し側の線形解法 `PdeLinearSolve` の結果を Plan が独立に検査する。
平衡点は利用者が先に求め、随伴の Plan は主の許容誤差でそれを検査してから勾配を出力に反映する。
細分化の前後をまたぐ勾配は、`PdeTransferDerivatives` の引き戻しで隣のエポックへ渡す。
どの随伴もメッシュの座標を微分せず、得られるのは離散化した問題の勾配である。
