このページは斉次な双曲型保存則 $\partial_t u+\nabla\cdot F(u)=0$ を有限体積法で離散化する項目をまとめる。
状態はセル平均で、各面では左右の再構成値から数値流束（厳密または近似の Riemann 解法）を評価する。
空間 Plan は質量で正規化した残差 $du_K/dt=-\frac{1}{|K|}\sum_{F\subset\partial K} |F|\,\hat F_{K,F}$ を作る。
ここで $K$ はセル、$|K|$ はその体積、$F$ は $K$ の面、$|F|$ は面の測度、$\hat F_{K,F}$ は $K$ から外向きの単位法線方向の数値流束である。
時間積分は `scioxide-ode` の `OdeMethod` が行う。
`ConservationSystem` は `OdeSystem::admits` で密度・圧力などの許容条件を段の入力と候補について提示し、許容外の試行は受理状態を変えずに棄却されて、半分の刻みで再試行される。

## 時間積分

`ConservationSystem` は、組み込みの強安定性保存（SSP）法 `scioxide_ode::ForwardEuler` と `scioxide_ode::Heun`（SSPRK2）を `scioxide_ode::OdeMethod` で進める使い方を想定する。
Heun の最初の前進 Euler の部分更新は第 2 段の入力として、二つ目の部分更新は候補の凸結合として許容性が検査される。
再試行で刻みの下限に達すると `StepSizeLimit` で止まり、値をクリップすることはない。
陽的 Runge–Kutta の Plan は CFL の上限を最初の段の残差と同時に受け取るので、上限のために残差を余分に評価しない。

## まとめ

保存則の Plan はセル平均の残差と面の流束を作り、CFL による刻みの上限と許容性を ODE 系として `OdeMethod` に伝える。
数値流束は方程式ごとに実装が決まっており、`Godunov` はスカラーの二つの方程式、`Hlle`・`Hllc` は Euler 方程式だけで使え、`Rusanov` はどの方程式にも使える。
再構成は格子の族で選び、構造格子では `Minmod`・`MonotonizedCentral`、単体メッシュでは `BarthJespersen` を使う。
密度や圧力の正値性は `ConservationSystem` の `admits` を通して各段と候補で検査され、値をクリップすることはない。
一回の残差評価の CFL・境界収支・制限の診断は、`ConservationReport` で読む。
