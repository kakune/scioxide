このページは三角形・四面体のメッシュ（$D=2,3$）上の弾性体と非圧縮流れの Plan をまとめる。
一次元の区間メッシュはどちらの Plan も受け付けない。
どちらも `SimplexFemOptions`（求積・幾何の条件・実行・上限）と `TaggedBoundaries`（成分ごとの境界条件と共有節点の Dirichlet 衝突方針）を共有する。
境界条件は $D$ 成分の時刻に依存しない Dirichlet と牽引力（自然境界）に限り、Robin と時刻に依存するデータは拒否する。
線形の Plan は作用素と荷重、非線形の Plan は残差と整合接線（`scioxide_core::ResidualOperator`・`JacobianOperator`）を提供する。
固定した状態の接線は適用のたびに残差のプロバイダーの積を呼ぶ `PdeTangent` か、`linearize` が一度だけ評価して CSR に保つ `SimplexLinearization` で表す。
線形の Plan の行列は `assembly_workspace` の作業領域を使う `assemble_csr_into` で同じ構造の既存の CSR に確保なしで書き直せる。
Stokes と Navier–Stokes は、作業領域に解法と前処理を持つ求解も提供し、その解法と前処理は注入したもので置き換えられる。

## 弾性体

等方な Hooke 則（小ひずみ）と圧縮性 neo-Hooke 則（有限ひずみ）を、変位形または P2 変位と P1 圧力の混合形で離散化する。
平面ひずみ・平面応力・三次元を明示して選ぶ。
体積弾性率がせん断弾性率より非常に大きいとき、変位形はロッキング（体積拘束による過剰な剛性）を起こしうるので、混合形を選ぶ。

## 非圧縮流れ

密度と粘性が一定の Stokes 方程式と保存形の Navier–Stokes 方程式を、P2 速度と P1 圧力（Taylor–Hood 要素）で離散化する。
圧力は圧縮を正とする。
境界で圧力が定まらない連結成分ごとに圧力の定数モードのゲージを置き、既定では重み付き平均を 0 にするゲージを自動で選ぶ。
ライブラリの鞍点前処理は近似的なブロック LDU 逆作用で、定常の粘性問題では $S\approx M_p/\mu$、速度質量の鞍点では $S\approx B\,\mathrm{diag}(M_\rho)^{-1}B^{H}$ を Schur 補元に使う。
この逆作用は一般に不定値で非対称になりうるので、正の前処理を要求する方法ではなく GMRES と組み合わせる。

## まとめ

弾性体と非圧縮流れの Plan は作用素・残差・接線を既存の解法に渡し、非圧縮流れと混合形の弾性体は安定な混合要素対（P2/P1）を使う。
体積弾性率が大きい材料では混合形を選び、閉じた流路では圧力のゲージを確かめる。
同じ状態で接線の積や CSR を繰り返し使うときは、`linearize` で接線を一度だけ評価して作業領域に保つ。
定常の Stokes と Navier–Stokes は作業領域の解法と前処理で解き、時間発展は拘束速度の ODE を陽的な方法で進めて、圧力を各評価で鞍点系から回復する。
求解の結論は `IterativeSolveReport`・`NewtonKrylovResult` の終了理由と `IncompressibleDiagnostics` の物理的な診断を合わせて読む。
