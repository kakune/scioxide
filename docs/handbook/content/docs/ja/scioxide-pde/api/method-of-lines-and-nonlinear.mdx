このページは半離散系を `scioxide-ode` と `scioxide-rootfind` の解法へ渡すための項目をまとめる。
空間離散化の Plan からは `SemidiscreteSystem` が自由な未知数の物理残差を作り、自作の系は物理残差を `scioxide_ode::OdeSystem` で記述する。
線の方法（method of lines）の adapter は `MethodOfLinesPlan` ただ一つで、対角の質量と座標の尺度を正規化して時間積分へ渡し、`ParabolicProblem`・`HyperbolicProblem` も内部でこれを使う。
`NonlinearPdeProblem` は同じ形の右辺を定常残差 $f(t,u)=0$ として Newton–Krylov 法へ渡し、密・疎の微分の方式では同じ状態での積に組み立てたヤコビアンを再利用する。
どの Plan も反復や受理状態を持たず、収束の判定は注入した解法のレポートで行う。

## 線の方法の正規化

$My'=f(t,y)$（または非減衰の $Mu''=f(t,u)$）の $M$ と、物理状態 $y=Dz$ の尺度 $D$ を正の実対角行列として扱い、正規化した座標 $z$ の系を ODE 解法に渡す。
一般・特異・状態依存の質量は推測せず、パラメータに依存する質量は残差 DAE で扱う。
`CflPolicy::Automatic` の上限は一階の動力学では実で非正の固有値（対角質量の対称な拡散）、二階では純虚数の固有値を仮定する。

## まとめ

Plan の半離散系は `SemidiscreteSystem` が作り、`method_of_lines` で質量と構造を設定した `MethodOfLinesPlan` に結合して、任意の ODE 解法で積分できる。
自作の系は `OdeSystem` で物理の残差として書き、対角の質量と尺度の正規化は同じ adapter に任せる。
積分した ODE のレポートは `PdeSolveReport::try_from` で PDE の終了理由に分類し、完全な物理場は `MethodOfLinesSystem::reconstruct_into` で作る。
同じ形のプロバイダーは `NonlinearPdeProblem` で定常残差として Newton–Krylov 法に渡し、微分の表現（密・疎・作用素）は `PdeJacobianMode` で明示して選ぶ。
固定した状態の接線は `PdeTangent` で借用し、場ごとの前処理は `PdeFieldPreconditioner` で組み合わせる。
