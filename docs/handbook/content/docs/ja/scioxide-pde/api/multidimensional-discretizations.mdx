このページは一次元から三次元までの空間作用素を準備する四つの Plan をまとめる。
どの Plan も一つの型で $D=1,2,3$ を扱い、`SpatialDiscretization`・`scioxide_core::LinearOperator`・`DifferentiableDiscretization` を実装する。
係数は準備時に標本化し、源項と境界データは荷重を評価するたびにその時刻で評価する。
Plan は連立方程式を解かない。
`EllipticProblem`・`ParabolicProblem`・`HyperbolicProblem` に渡すか、`scioxide-linalg` の Krylov 法や `scioxide-sparse` の直接法を利用者が選び、その終了理由で収束を確かめる。
メッシュは `scioxide-spatial` の構造格子 `CellMesh`（`SegmentMesh`・`QuadMesh`・`HexMesh`）と単体メッシュ `SimplexMesh`（`IntervalMesh`・`TriangleMesh`・`TetrahedronMesh`）で、境界条件や場が同じメッシュの revision でなければ拒否する。
各 Plan は `new` で上限なしに準備し、`with_options` でリソースの上限や求積・実行の設定を与える。

## 構造格子の有限差分

$-\nabla\cdot(k\nabla u)+\nabla\cdot(vu)+Cu=f$ を、成分ごとの頂点の値で離散化する。
拡散と移流は成分ごとに対角で、反応行列 $C$ が成分を結合する。
未知数は軸 0 が最も速く変わる頂点の順で、成分ごとにまとまる。
周期軸の継ぎ目の頂点は一つの未知数にまとめる。
内部の各面は面の中心で標本化した $k$ による伝導度 $k\cdot\text{面積}/h$ を与え、反応と源項は双対の制御体積で集中化する。
このため一次元では、中点則の剛性と集中化した反応・荷重を持つ P1 有限要素と同じ式になる。
内部の打切り誤差は一様または滑らかに変化する軸で 2 次、任意の非一様な軸で 1 次であり、境界の関係式は 2 次である。

## 単体メッシュの有限要素

区間・三角形・四面体の上の連続な P1・P2 要素で、連成した異方性の拡散 $K_{ab}$ と反応行列を持つ楕円型の弱形式を組み立てる。
幾何は頂点で定まるアフィン写像か、辺の中点の物理座標を共有する 2 次写像で、解の次数とは独立に選ぶ。
自然境界のデータは外向きの余法線流束 $n\cdot\sum_b K_{ab}\nabla u_b$ で、Robin のデータは $\alpha u$ を加える。
Dirichlet 節点は対称に消去する。
準備は一度だけ確保し、借用した適用と評価は確保しない。
メモリ領域と適用の計算コストは、次数と成分の数を固定すればセルの数に比例する。
係数が位置に依らないと提示すると、Plan は拡散と反応を一度だけ評価し、アフィン幾何ではさらに参照要素上の基底のモーメントを一度だけ求めて各セルの写像で変換する。
行列の構造（数値的な零の要素を含む）は準備時に決まり、`assembly_workspace` の作業領域を使う `assemble_csr_into` は同じ構造の既存の CSR に確保なしで値を書き直す。

## セル中心の有限体積

$-\nabla\cdot(K\nabla u)+cu=f$ をセルの値で離散化する。
$K$ は実対称正定値の完全なテンソルでよく、丸めの水準の非対称性は対称部分へ射影する。
内部の面の流束は二つのセルの半セルの法則で共有の面の値を消去して作り、隣り合うセルが同じ流束を逆符号で使うので内部の寄与は相殺する。
準備は非正の半セルの伝導度を拒否するが、正の伝導度は一般の歪んだ幾何や異方性テンソルで M 行列を意味しない。
境界データは記号のまま保ち、荷重と面の流束を要求した時刻で評価する。
Dirichlet 値は境界の面の法則から入るので、拘束される未知数はない。
扱うのは一つの成分のスカラーの場である。

## まとめ

四つの Plan は同じ約束で作用素と荷重を作り、定常・時間発展の求解にも利用者の解法にも渡せる。
構造格子の FDM と単体の FEM は Dirichlet 節点を対称に消去し、セル中心の FVM は Dirichlet 値を面の法則で課すので拘束される未知数を持たない。
FVM の面流束は保存的で、構造格子では座標の増加方向、単体メッシュでは最初に接するセルから外向きの向きを持つ。
単体の FEM で行列を繰り返し組み立てるときは、`assembly_workspace` の作業領域で同じ構造の CSR に確保なしで書き直す。
準備のリソースは `SpatialLimits`・`SimplexFemLimits` で確保の前に制限できる。
