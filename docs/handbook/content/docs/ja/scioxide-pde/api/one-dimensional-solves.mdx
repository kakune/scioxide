このページはどの空間離散化にも共通する約束、定数・等方の係数の適合、境界条件と時空間データの語彙、時間積分の設定をまとめる。
一次元の問題も二次元・三次元と同じ Plan と求解で扱う。
一次元の構造格子は `scioxide-spatial` の `SegmentMesh`（`CellMesh<_, 1>`）、一次元の単体メッシュは `IntervalMesh`（`SimplexMesh<_, 1>`）である。
Plan そのものは[空間離散化の Plan](../multidimensional-discretizations/)、求解のライフサイクルと結果は[求解・出力・診断](../solves-outputs-and-diagnostics/)にある。

## 空間離散化の約束

四つの Plan は時刻に依存しない消去済みの作用素 $A$ と、任意の時刻で評価する荷重 $b(t)$ による線形の空間離散化 $Au=b(t)$ を同じ形で出力に反映する。
未知数は成分が外側にまとまる順（成分優先）で、Dirichlet の未知数は単位の行と列を持ち、その値は荷重から入る。
定常の求解はデータを時刻 0 で評価する。

## 境界条件

一つの語彙がすべての族に使われる。
自然境界のデータは外向きの余法線流束 $n\cdot K\nabla u=g$、Robin のデータは $n\cdot K\nabla u+\alpha u=g$ である。
周期性は境界条件ではなくメッシュのトポロジー（`AxisTopology::Periodic`）に属し、周期の継ぎ目の面には条件を置かない。

## 時間積分の設定

放物型 $Mu'=b(t)-Au$ と双曲型 $Mu''=b(t)-Au$ の時間積分の設定である。
終端時刻は設定ではなく `ParabolicProblem` が持つ。
どの境界条件の種類も、時刻に依存する源項と境界データも受け付けるが、係数は時刻に依存しない。

| 項目 | 種別 | 役割 | 仕様の要点 | 解説節 | 実行例 |

## まとめ

自作の Plan も四つの組み込みの Plan も、`SpatialDiscretization` を通して消去済みの作用素 $A$、集中質量、荷重 $b(t)$ を同じ形で渡す。
定数や位置だけに依存する等方の係数は、係数のトレイトを実装せずに `ConstantDiffusion`・`IsotropicDiffusion` で与えられる。
境界条件は種類・領域・成分・時間依存を提示した一つの語彙で書き、`StructuredBoundaries` か `TaggedBoundaries` で一つのメッシュの revision に結び付ける。
自然境界のデータはどの族でも外向きの余法線流束であり、周期性はメッシュのトポロジーで表す。
時間積分の設定は方式、刻み、許容誤差、出力、計算回数の上限、刻みの安定性の制限を持ち、終端時刻は問題の側に置く。
