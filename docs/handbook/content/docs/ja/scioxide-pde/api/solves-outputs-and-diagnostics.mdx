このページは空間離散化の Plan を解く定常・時間発展の求解、時間発展の出力と再開、結果の型をまとめる。
問題（`EllipticProblem`・`ParabolicProblem`・`HyperbolicProblem`）は Plan と源項を借用し、設定（`EllipticOptions`・`ParabolicOptions`・`HyperbolicOptions`）は呼び出しごとに渡す不変の値である。
作業領域と時間発展の状態は呼び出し側が所有する。
出力先を指定する API（`solve_into`・`advance`・`resume`）は呼び出し側の実行コンテキストを一つの求解のエポックとして使い、所有値を返す API（`solve`・`solve_with_options`）は逐次のネイティブ実行で結果を確保して返す。
成功でない終了理由は `Ok` のレポートに記録され、エラーとは区別される。
ただし所有値を返す API の `solve` は成功でない終了理由もエラーにする。

## まとめ

定常の求解は `EllipticProblem` で、時間発展は `ParabolicProblem`・`HyperbolicProblem`、`PdeState`、`PdeWorkspace` で組み立てる。
出力先を指定する API は呼び出し側の配列と状態を書き換え、所有値を返す API は結果を確保して返す。
時間発展の所有値を返す API は失敗のとき最後に受理した進行を `PartialFailure` に入れて返す。
途中の場は `PdeOutputSchedule` で選び、`PdeOutputSink` で逐次に受け取り、`PdeCheckpoint` で保存して `resume` で続けられる。
結果は `PdeTermination` の `is_success()` で判定し、零空間を持つ楕円問題では拡大系の診断と要求したゲージの欠陥を別々に確かめる。
