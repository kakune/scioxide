片持ち梁は一端を固定し他端に荷重を受ける梁で、構造力学でよく使われる検算問題である。
梁理論は細長い梁を断面の回転とたわみだけで表すが、有限要素法は梁を 2 次元の弾性体として解く。
この例題では線形弾性の Plan `LinearElasticityPlan` で梁を解き、弾性論の厳密解、Euler–Bernoulli と Timoshenko の梁理論、仕事とエネルギーの収支で結果を確かめる。
後半では平面ひずみで Poisson 比 ν を 1/2 に近づけ、変位だけを未知数にする要素が硬くなりすぎる体積ロッキングを、混合要素と比べて測る。
弾性体の弱形式、平面応力と平面ひずみの縮約、混合形の導出は[弾性体の有限要素](../../algorithms/elasticity/)にある。

## 問題設定

梁は長さ $L=10$、高さ $H=1$、厚さ 1 の長方形 $[0,L]\times[-H/2,H/2]$ で、$y$ は中立軸から測る。
材料は等方で、Young 率 $E=1000$、Poisson 比 $\nu=0.3$ とする。
先端 $x=L$ には高さ方向に放物分布するせん断の牽引力を、合力が下向きに $P=1$ になるように与える。
上下の面には力を加えず、物体力もない。
数値は一貫した単位系での無次元の値で、長さの単位を cm、力の単位を N とすれば $E$ は N/cm² になる。

線形理論ではたわみも応力も $P$ に比例するので、$P=1$ は比例の係数を読むための値である。
先端たわみは $L$ の約 4 割になり、実際の部材では小変形の仮定を超える。
同じ形の梁を実際に評価するときは、$P$ を十分小さくするか、有限ひずみの `HyperelasticityPlan` を使う。

厚さが小さく面外の応力がない薄板とみなすので、平面応力（`ElasticityKinematics::PlaneStress`）で解く。
断面二次モーメントは $I=H^3/12=1/12$ である。

## 弾性論の厳密解と梁理論

先端に放物分布のせん断を受ける長方形の片持ち梁には、平面応力の弾性論の厳密解がある（Timoshenko–Goodier）。
応力は

```text
σ_xx = M(x) y / I,   M(x) = P (L − x),
σ_yy = 0,
τ_xy = −P/(2I) · (H²/4 − y²)
```

で、$M$ は断面に働く曲げモーメントの大きさ、上面 $y>0$ が引張になる。
変位は

```text
u_x = c y [ (6L − 3x) x + (2 + ν)(y² − H²/4) ],
u_y = −c [ 3ν y² (L − x) + (4 + 5ν) H² x / 4 + (3L − x) x² ],   c = P / (6EI)
```

である。
この変位を平面応力の Hooke 則に代入すると上の応力が得られ、応力は釣り合い式と上下面・先端の境界条件を満たす。
ただし固定端 $x=0$ の変位は 0 ではなく、断面のそり $u_x$ と、Poisson 効果による $u_y$ が残る。
$x=0$ にこの変位を与えた問題の厳密解がこの場なので、有限要素解の誤差を正確に測れる。

先端のたわみ $\delta=-u_y(L,y)$ は $y$ に依らず

```text
δ = P L³ / (3EI) + (4 + 5ν) P H² L / (24EI) = 4 + 0.0275 = 4.0275
```

である。
第 1 項は断面が平面を保ち中立軸に垂直なままとする Euler–Bernoulli 梁のたわみ $\delta_\mathrm{EB}=4$ で、第 2 項がせん断変形の寄与である。
せん断変形を断面の回転とたわみ角の差として加える Timoshenko 梁では、せん断補正係数 $\kappa=5/6$、せん断弾性率 $G=E/(2(1+\nu))$ で

```text
δ_T = P L³ / (3EI) + P L / (κ G H) = 4 + 0.0312 = 4.0312
```

になる。
$\delta_\mathrm{T}$ と厳密解の差 0.0037 は、次に述べる固定端の反力の仕事 $W_0$ を $P$ で割った値に等しい。
長方形断面の $\kappa=5/6$ は、放物分布のせん断が蓄えるエネルギーから決まる係数である。
実際、厳密解のひずみエネルギー $U$ は $2U=P\delta_\mathrm{T}=4.0312$ を満たす。

線形弾性体では、平衡状態で外力のする仕事の総和がひずみエネルギーの 2 倍に等しい（Clapeyron の定理）。
先端の牽引力の仕事は $W_\mathrm{ext}=P\delta=4.0275$ で、残りは固定端の反力が厳密解の変位に対してする仕事

```text
W_0 = (4 − ν) P² L / (10 E H) = 0.0037
```

である。
$x=0$ の変位を全て 0 にすると $W_0=0$ になり、$2U=W_\mathrm{ext}$ が成り立つ。

## Plan と求解

梁を $n_x\times n_y$（$n_x=10n_y$）の長方形に分け、各長方形を対角線で 2 つの三角形に分ける。
外部面には固定端 $x=0$ にタグ 1、先端 $x=L$ にタグ 2、上下面にタグ 3 を付ける。
`TaggedBoundaries` は 2 成分の場について、外部面と成分の組ごとにちょうど一つの条件を求める。
タグ 1 には成分ごとの `BoundaryCondition::dirichlet` を、タグ 2 には $x$ 成分に 0、$y$ 成分に $t_y=-P/(2I)(H^2/4-y^2)$ の `BoundaryCondition::natural` を与える。
弾性体の自然境界条件のデータは牽引力 $t_a=\sigma_{ab}n_b$ の成分である。
タグ 3 は成分を指定しない一つの条件で、両成分の牽引力を 0 にする。

材料は `IsotropicElasticMaterial::from_young_poisson(E, ν)` でせん断弾性率と体積弾性率に変換し、`ElasticityOptions::new(kinematics, formulation)` で縮約と要素を選ぶ。
`LinearElasticityPlan::new` は要素行列と荷重を準備し、`assemble_csr` が Dirichlet 自由度を対称に消去した CSR 行列を、`rhs` が消去で持ち上げた右辺を返す。
弾性の Plan は求解を持たないので、この例題では `scioxide-sparse` の疎 LU 分解（`scioxide_sparse::solve`）で解き、Plan の作用素 `apply_into` で $Ax-b$ を測って求解を確かめる。
解は成分優先に並び、`fields` が頂点ごとの変位の場に分ける。
応力は `stress(cell, point, x)` で、セルと参照座標の点を指定して求める。

次のブロックは、二つのセルが共有するメッシュ、境界条件、厳密解、求解の手順である。

```rust
//| id: pde-cantilever-model
//| kind: definitions
//| title: 片持ち梁のメッシュ、境界条件と弾性論の厳密解
//| crates: [scioxide-core, scioxide-pde, scioxide-sparse, scioxide-spatial]
use scioxide_core::{SciOxideError, LinearOperator};
use scioxide_pde::{
    BoundaryCondition, BoundaryData, BoundaryPoint, ElasticityFormulation, ElasticityKinematics,
    ElasticityOptions, IsotropicElasticMaterial, LinearElasticityPlan, SimplexFemGeometry,
    SimplexFemLimits, SimplexFemOptions, TaggedBoundaries,
};
use scioxide_spatial::{Point, SimplexBoundaryTags, TriangleMesh};

/// 長さ L、高さ H、厚さ 1 の梁。先端 x = L に下向きの合力 P を放物分布のせん断で与える。
#[derive(Clone, Copy)]
pub(crate) struct Beam {
    pub(crate) length: f64,
    pub(crate) height: f64,
    pub(crate) young: f64,
    pub(crate) poisson: f64,
    pub(crate) load: f64,
    pub(crate) plane_strain: bool,
}

impl Beam {
    /// 断面二次モーメント I = H³/12（厚さ 1）。
    pub(crate) fn inertia(&self) -> f64 {
        self.height * self.height * self.height / 12.0
    }
    /// 平面ひずみは E' = E/(1−ν²)、ν' = ν/(1−ν) で平面応力の式に読み替える。
    pub(crate) fn effective(&self) -> (f64, f64) {
        let (e, nu) = (self.young, self.poisson);
        if self.plane_strain {
            (e / (1.0 - nu * nu), nu / (1.0 - nu))
        } else {
            (e, nu)
        }
    }
    /// Timoshenko–Goodier の厳密解の変位 (u_x, u_y)。y は中立軸から測る。
    pub(crate) fn exact(&self, x: f64, y: f64) -> [f64; 2] {
        let (e, nu) = self.effective();
        let (l, h) = (self.length, self.height);
        let c = self.load / (6.0 * e * self.inertia());
        let shear = (4.0 + 5.0 * nu) * h * h * x / 4.0;
        [
            c * y * ((6.0 * l - 3.0 * x) * x + (2.0 + nu) * (y * y - h * h / 4.0)),
            -c * (3.0 * nu * y * y * (l - x) + shear + (3.0 * l - x) * x * x),
        ]
    }
    /// 曲げ応力 σ_xx = M y / I、M = P (L − x)。平面ひずみでも同じ。
    pub(crate) fn bending_stress(&self, x: f64, y: f64) -> f64 {
        self.load * (self.length - x) * y / self.inertia()
    }
}

/// 固定端 x = 0 の条件。Exact は厳密解の変位を、Clamped は 0 を与える。
#[derive(Clone, Copy, PartialEq)]
pub(crate) enum Support {
    Exact,
    Clamped,
}

/// 頂点 j (n_x + 1) + i、セル 2 (j n_x + i) + k の長方形の三角形分割。
pub(crate) fn beam_mesh(beam: &Beam, ny: usize) -> Result<TriangleMesh<f64>, SciOxideError> {
    let nx = 10 * ny;
    let (dx, dy) = (beam.length / nx as f64, beam.height / ny as f64);
    let mut points = Vec::new();
    for j in 0..=ny {
        for i in 0..=nx {
            points.push(Point::new([
                i as f64 * dx,
                j as f64 * dy - beam.height / 2.0,
            ])?);
        }
    }
    let mut cells = Vec::new();
    for j in 0..ny {
        for i in 0..nx {
            let v = j * (nx + 1) + i;
            cells.push([v, v + 1, v + nx + 2]);
            cells.push([v, v + nx + 2, v + nx + 1]);
        }
    }
    TriangleMesh::new(points, cells)
}

/// 外部面のタグは x = 0 が 1、x = L が 2、上下面が 3。
pub(crate) fn beam_boundaries(
    beam: &Beam,
    mesh: &TriangleMesh<f64>,
    support: Support,
) -> Result<TaggedBoundaries<f64, f64, 2>, SciOxideError> {
    let mut faces = Vec::new();
    for face in mesh.boundary_faces() {
        let v = mesh.face_vertices(face)?;
        let x = 0.5 * (mesh.points()[v[0]].as_array()[0] + mesh.points()[v[1]].as_array()[0]);
        let tag = if x < 1e-9 * beam.length {
            1
        } else if x > (1.0 - 1e-9) * beam.length {
            2
        } else {
            3
        };
        faces.push((face, tag));
    }
    let tags = SimplexBoundaryTags::new(mesh, faces)?;
    let b = *beam;
    let support_data = |component: usize| match support {
        Support::Exact => BoundaryData::time_invariant(move |p: BoundaryPoint<f64, 2>| {
            Ok(b.exact(p.point[0], p.point[1])[component])
        }),
        Support::Clamped => BoundaryData::zero(),
    };
    // 先端の牽引力 t_y = −P/(2I) (H²/4 − y²)。合力は −P。
    let shear = BoundaryData::time_invariant(move |p: BoundaryPoint<f64, 2>| {
        let y = p.point[1];
        Ok(-b.load / (2.0 * b.inertia()) * (b.height * b.height / 4.0 - y * y))
    });
    let conditions = vec![
        BoundaryCondition::dirichlet(1, support_data(0)).for_component(0),
        BoundaryCondition::dirichlet(1, support_data(1)).for_component(1),
        BoundaryCondition::natural(2, BoundaryData::zero()).for_component(0),
        BoundaryCondition::natural(2, shear).for_component(1),
        BoundaryCondition::natural(3, BoundaryData::zero()),
    ];
    TaggedBoundaries::new(mesh, &tags, 2, conditions)
}

/// Plan を準備して疎 LU で解き、Plan の作用素で測った相対残差 ‖Ax − b‖∞/‖b‖∞ も返す。
pub(crate) fn solve_beam(
    beam: &Beam,
    ny: usize,
    formulation: ElasticityFormulation,
    support: Support,
) -> Result<(LinearElasticityPlan<f64, f64, 2>, Vec<f64>, f64), SciOxideError> {
    let mesh = beam_mesh(beam, ny)?;
    let boundaries = beam_boundaries(beam, &mesh, support)?;
    let kinematics = if beam.plane_strain {
        ElasticityKinematics::PlaneStrain
    } else {
        ElasticityKinematics::PlaneStress
    };
    let limits = SimplexFemLimits::new(1 << 16, 1 << 22, 64, 1 << 28);
    let options = ElasticityOptions::new(kinematics, formulation)
        .with_fem(SimplexFemOptions::new().with_limits(limits));
    let material = IsotropicElasticMaterial::from_young_poisson(beam.young, beam.poisson)?;
    let plan = LinearElasticityPlan::new(
        mesh,
        SimplexFemGeometry::Affine,
        material,
        &boundaries,
        &|_| Ok([0.0; 2]),
        options,
    )?;
    let x = scioxide_sparse::solve(&plan.assemble_csr()?, plan.rhs())?;
    let mut ax = vec![0.0; plan.unknowns()];
    let mut work = vec![0.0; plan.apply_workspace_len()?];
    plan.apply_into(&x, &mut ax, &mut work)?;
    let norm = |v: &[f64]| v.iter().fold(0.0_f64, |m, a| m.max(a.abs()));
    let defect: Vec<f64> = ax.iter().zip(plan.rhs()).map(|(a, b)| a - b).collect();
    let residual = norm(&defect) / norm(plan.rhs());
    Ok((plan, x, residual))
}

/// セルの重心の物理座標。参照座標の重心 (1/3, 1/3) に対応する。
pub(crate) fn centroid(mesh: &TriangleMesh<f64>, cell: usize) -> Result<[f64; 2], SciOxideError> {
    let mut c = [0.0; 2];
    for &v in mesh.cell_vertices(cell)? {
        c[0] += mesh.points()[v].as_array()[0] / 3.0;
        c[1] += mesh.points()[v].as_array()[1] / 3.0;
    }
    Ok(c)
}
```

`Beam::exact` が上の変位の式、`bending_stress` が $\sigma_{xx}=My/I$ である。
`solve_beam` は Plan の準備、組み立て、疎 LU による求解、作用素による残差の計算までを行う。
平面ひずみの場合は、後の節で述べる $E'$ と $\nu'$ への読み替えで同じ式を使う。

## たわみと曲げ応力の照合

次のセルは選んだ要素と分割数で梁を解き、先端たわみ、曲げ応力、仕事とエネルギーを参照値と比べる。
先端たわみは先端の頂点のうち中立軸に最も近いものの $-u_y$ で、厳密解では先端の $u_y$ は $y$ に依らない。
曲げ応力は梁の中央 $x\approx L/2$ の列で最も上にあるセルの重心で比べる。
`energy` は内部エネルギー $U$（`internal`）と、荷重ベクトルと解の内積である外力の仕事（`external_work`）を返す。
外力の仕事は牽引力と物体力の分だけで、固定端の反力の仕事を含まない。
解いた変位と応力の分布は `exports` で次のセルに渡す。

```rust
//| id: pde-cantilever-deflection
//| ref: pde-cantilever-deflection
//| title: 片持ち梁の先端たわみと曲げ応力を厳密解と梁理論で照合する
//| run: button
//| cache: inputs
//| uses: [pde-cantilever-model]
//| crates: [scioxide-core, scioxide-pde, scioxide-sparse, scioxide-spatial]
//| exports: [deflection, stress]
//| inputs:
//|   beam_formulation: {"type":"select","label":"要素","description":"変位の次数と混合形を選ぶ。","options":[{"label":"P1 変位","value":"p1"},{"label":"P2 変位","value":"p2"},{"label":"混合 P2/P1","value":"mixed"}],"value":"p2"}

//|   - {"id":"linear-triangles","label":"P1 変位","description":"一定ひずみの三角形は曲げを表せず、先端たわみは厳密解の 82 % にとどまる。","inputs":{"beam_formulation":"p1"}}

//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"summary","path":"/rows/0/1","approx":{"value":4.0274739,"rtol":1e-6}}
//|       - {"artifact":"summary","path":"/rows/0/2","approx":{"value":4.0275,"rtol":1e-12}}
//|       - {"artifact":"summary","path":"/rows/6/1","approx":{"value":3.68377e-3,"rtol":1e-4}}
//|       - {"artifact":"summary","path":"/rows/7/1","range":{"max":1e-9}}
//|   - case: linear-triangles
//|     expect:
//|       - {"artifact":"summary","path":"/rows/0/1","approx":{"value":3.3195832,"rtol":1e-6}}
//|   - case: clamped
//|     expect:
//|       - {"artifact":"summary","path":"/rows/0/1","approx":{"value":4.0218860,"rtol":1e-6}}
//|       - {"artifact":"summary","path":"/rows/4/2","equals":null}
//|       - {"artifact":"summary","path":"/rows/6/1","range":{"min":-1e-8,"max":1e-8}}
//|   - case: mixed-coarse
//|     expect:
//|       - {"artifact":"summary","path":"/rows/0/1","approx":{"value":4.0289240,"rtol":1e-6}}
use scioxide_pde::{ElasticityFormulation, SimplexFemOrder};

let beam = Beam {
    length: 10.0,
    height: 1.0,
    young: 1000.0,
    poisson: 0.3,
    load: 1.0,
    plane_strain: false,
};
let formulation = match beam_formulation.as_str() {
    "p1" => ElasticityFormulation::Displacement(SimplexFemOrder::P1),
    "p2" => ElasticityFormulation::Displacement(SimplexFemOrder::P2),
    _ => ElasticityFormulation::MixedP2P1,
};
let support = if beam_support == "exact" {
    Support::Exact
} else {
    Support::Clamped
};
let ny = beam_layers as usize;
let nx = 10 * ny;
let (plan, x, residual) =
    solve_beam(&beam, ny, formulation, support).map_err(|e| e.to_string())?;
let field = plan.fields(&x).map_err(|e| e.to_string())?;
let uy = field.displacement().vertices()[1].values();
let mesh = plan.mesh();
// 中立軸に最も近い頂点の列 j = n_y/2 に沿うたわみ (x, 有限要素, 厳密解)。
let mut deflection = Vec::new();
for i in 0..=nx {
    let v = (ny / 2) * (nx + 1) + i;
    let [px, py] = *mesh.points()[v].as_array();
    deflection.push([px, -uy[v], -beam.exact(px, py)[1]]);
}
// 中央の列 i = n_x/2 のセルの重心で σ_xx を比べる (y, 有限要素, 厳密解)。
let mut stress = Vec::new();
for j in 0..ny {
    for k in 0..2 {
        let cell = 2 * (j * nx + nx / 2) + k;
        let [cx, cy] = centroid(mesh, cell).map_err(|e| e.to_string())?;
        let s = plan
            .stress(cell, [1.0 / 3.0; 2], &x)
            .map_err(|e| e.to_string())?;
        stress.push([cy, s.cauchy()[0][0], beam.bending_stress(cx, cy)]);
    }
}
stress.sort_by(|a, b| a[0].total_cmp(&b[0]));
let top = stress[stress.len() - 1];
let energy = plan.energy(&x).map_err(|e| e.to_string())?;
let (two_u, work) = (2.0 * energy.internal(), energy.external_work());
let ei = beam.young * beam.inertia();
let euler = beam.load * beam.length.powi(3) / (3.0 * ei);
let shear_modulus = beam.young / (2.0 * (1.0 + beam.poisson));
let timoshenko = euler + beam.load * beam.length / (5.0 / 6.0 * shear_modulus * beam.height);
let exact = support == Support::Exact;
let support_work = (4.0 - beam.poisson) * beam.load * beam.load * beam.length
    / (10.0 * beam.young * beam.height);
let tip = deflection[nx];
let rows = vec![
    ("先端たわみ δ", Some(tip[1]), Some(tip[2])),
    ("Euler–Bernoulli 梁の δ_EB", None, Some(euler)),
    ("Timoshenko 梁の δ_T", None, Some(timoshenko)),
    ("上端付近の σ_xx", Some(top[1]), Some(top[2])),
    (
        "外力の仕事 W_ext",
        Some(work),
        exact.then_some(tip[2] * beam.load),
    ),
    ("2U", Some(two_u), exact.then_some(timoshenko * beam.load)),
    (
        "2U − W_ext",
        Some(two_u - work),
        Some(if exact { support_work } else { 0.0 }),
    ),
    ("相対残差 ‖Ax − b‖∞/‖b‖∞", Some(residual), None),
];
let sig6 = serde_json::json!({ "significantDigits": 6 });
emit_table_with_columns!(
    serde_json::json!([
        { "key": "0", "label": "量" },
        { "key": "1", "label": "有限要素 [-]", "type": "number", "format": sig6, "nullText": "—" },
        { "key": "2", "label": "参照値 [-]", "type": "number", "format": sig6, "nullText": "—" }
    ]),
    rows,
    metadata = serde_json::json!({ "id": "summary" })
);
export!(deflection, &deflection);
export!(stress, &stress);
```

既定の P2 変位、$n_y=4$、厳密解の変位の固定端では、先端たわみは 4.027474 で、厳密解 4.0275 との差は $3\times10^{-5}$ である。
Euler–Bernoulli 梁の 4 より 0.7 % 大きく、この差はせん断変形の寄与にあたる。
曲げ応力は中央の列で最も上にあるセルの重心 $y=0.4167$ で 24.560 になり、その重心での厳密値 24.583 と 0.09 % 違う。
$2U=4.031157$ は厳密値 4.0312 に近く、$2U-W_\mathrm{ext}=0.003683$ は固定端の反力の仕事 $W_0=0.0037$ とよく一致する。

P1 変位では先端たわみが 3.320 で、厳密解の 82 % にとどまる。
三角形の P1 要素はセル内でひずみが一定で、曲げで高さ方向に線形に変わる $\varepsilon_{xx}$ を表せない。
曲げの代わりに余分なせん断ひずみが生じて梁が硬くなる現象を、せん断ロッキングと呼ぶ。
分割を細かくすれば収束するが、$n_y=4$ でも誤差は 18 % ある。

固定端の全変位を 0 にすると、先端たわみは 4.0219 に下がる。
固定端で断面のそりと Poisson 効果による縮みを拘束した分だけ、梁が硬くなる。
このときは反力が仕事をしないので、$2U$ と $W_\mathrm{ext}$ は丸め誤差の範囲で一致する。
この一致は離散の連立方程式が満たす恒等式で、離散化誤差の評価ではない。
誤差は厳密解との比較か、分割数を変えた比較で測る。

次のセルは、前のセルが渡した分布を描く。
左の図は中立軸に沿うたわみで、有限要素解を点、厳密解と Euler–Bernoulli 梁のたわみ $\delta_\mathrm{EB}(x)=Px^2(3L-x)/(6EI)$ を破線で示す。
右の図は中央の断面の曲げ応力で、セルの重心の値を点、厳密な $\sigma_{xx}=My/I$ を破線で示す。

## 非圧縮に近い材料と体積ロッキング

ゴムのように体積がほとんど変わらない材料では、ν が 1/2 に近く、体積弾性率 $K$ がせん断弾性率 $\mu$ よりはるかに大きい。
$K/\mu=2(1+\nu)/(3(1-2\nu))$ は $\nu=0.3$ で 2.2、$\nu=0.4999$ で 5000 になる。
厚さ方向のひずみを 0 とする平面ひずみ（`ElasticityKinematics::PlaneStrain`）では、体積変化 $\nabla\cdot u$ を抑える拘束が強く働く。
厳密解は平面応力の式の $E$ と $\nu$ を $E'=E/(1-\nu^2)$、$\nu'=\nu/(1-\nu)$ に読み替えれば得られ、応力は平面応力と同じ $\sigma_{xx}=My/I$ である。
厚さ方向には $\sigma_{zz}=\nu\sigma_{xx}$ が生じるので、平均応力 $p=\operatorname{tr}\sigma/3$ の厳密値は $(1+\nu)\sigma_{xx}/3$ になる。

変位だけを未知数にする要素では、エネルギーの $K(\nabla\cdot u)^2/2$ の項が、$K\to\infty$ で離散の変位に $\nabla\cdot u_h\approx 0$ を強制する。
区分一次の連続な変位のうち発散が 0 のものは非常に少なく、変位全体が拘束されて動けなくなる。
これが体積ロッキングで、たわみが 0 に近づき、平均応力 $K\nabla\cdot u_h$ は大きな数と小さな数の積として振動する。
混合形（`ElasticityFormulation::MixedP2P1`）は平均応力を P1 の圧力として別に未知数に取り、体積の拘束を弱い形で課す。
P2 変位と P1 圧力の組はメッシュに関する弱い条件の下で inf-sup 条件を満たすので、$K/\mu$ に依らずに安定である（[弾性体の有限要素](../../algorithms/elasticity/)）。

次のセルは平面ひずみで ν を 0.3 から 0.4999 まで変え、3 種類の要素の先端たわみと厳密解の比、セルの重心での平均応力の最大誤差を求める。
平均応力は `stress` の `pressure` で、変位形では $K\operatorname{tr}\varepsilon$、混合形では補間した圧力の未知数である。
誤差は厳密な平均応力の最大値で割った相対値にする。
一回の実行で 15 回解くので、ブラウザでの実行時間を抑えるために分割数は 3 までにしている。

```rust
//| id: pde-cantilever-locking
//| ref: pde-cantilever-locking
//| title: 平面ひずみで ν を 1/2 に近づけ、変位形と混合形のたわみと平均応力を比べる
//| run: button
//| timeoutMs: 90000
//| uses: [pde-cantilever-model]
//| crates: [scioxide-core, scioxide-pde, scioxide-sparse, scioxide-spatial]
//| inputs:
//|   locking_layers: {"type":"range","label":"厚さ方向の分割数 n_y [-]","description":"長さ方向は 10 n_y に分ける。","min":1,"max":3,"step":1,"value":2}
//| cases:
//|   - {"id":"finer","label":"n_y = 3","description":"P1 のたわみ比は ν = 0.3 で 0.71 に上がるが、ν = 0.4999 では 0.019 のままである。","inputs":{"locking_layers":3}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"locking","path":"/rows/0/3","approx":{"value":0.52476,"rtol":1e-4}}
//|       - {"artifact":"locking","path":"/rows/12/3","approx":{"value":0.017377,"rtol":1e-3}}
//|       - {"artifact":"locking","path":"/rows/13/4","approx":{"value":0.016655,"rtol":1e-3}}
//|       - {"artifact":"locking","path":"/rows/14/3","approx":{"value":0.999978,"rtol":1e-5}}
//|       - {"artifact":"locking","path":"/rows/14/4","approx":{"value":3.0401e-3,"rtol":1e-3}}
//|   - case: finer
//|     expect:
//|       - {"artifact":"locking","path":"/rows/0/3","approx":{"value":0.71148,"rtol":1e-4}}
//|       - {"artifact":"locking","path":"/rows/12/3","approx":{"value":0.019288,"rtol":1e-3}}
use scioxide_pde::{ElasticityFormulation, SimplexFemOrder};

let ny = locking_layers as usize;
let nx = 10 * ny;
let forms = [
    (
        "P1 変位",
        ElasticityFormulation::Displacement(SimplexFemOrder::P1),
    ),
    (
        "P2 変位",
        ElasticityFormulation::Displacement(SimplexFemOrder::P2),
    ),
    ("混合 P2/P1", ElasticityFormulation::MixedP2P1),
];
let mut rows = Vec::new();
let mut ratio_series = vec![Vec::new(); 3];
let mut pressure_series = vec![Vec::new(); 3];
for nu in [0.3, 0.45, 0.49, 0.499, 0.4999] {
    let beam = Beam {
        length: 10.0,
        height: 1.0,
        young: 1000.0,
        poisson: nu,
        load: 1.0,
        plane_strain: true,
    };
    let bulk_ratio = 2.0 * (1.0 + nu) / (3.0 * (1.0 - 2.0 * nu));
    for (k, (label, form)) in forms.iter().enumerate() {
        let (plan, x, _) =
            solve_beam(&beam, ny, *form, Support::Exact).map_err(|e| e.to_string())?;
        let field = plan.fields(&x).map_err(|e| e.to_string())?;
        // 先端の頂点 (L, 中立軸に最も近い高さ) のたわみと、同じ点の厳密解の比。
        let tip = (ny / 2) * (nx + 1) + nx;
        let [px, py] = *plan.mesh().points()[tip].as_array();
        let ratio = field.displacement().vertices()[1].values()[tip] / beam.exact(px, py)[1];
        // セルの重心での平均応力の最大誤差を、厳密な平均応力の最大値で割る。
        let (mut error, mut scale) = (0.0_f64, 0.0_f64);
        for cell in 0..plan.mesh().cell_count() {
            let [cx, cy] = centroid(plan.mesh(), cell).map_err(|e| e.to_string())?;
            let s = plan
                .stress(cell, [1.0 / 3.0; 2], &x)
                .map_err(|e| e.to_string())?;
            let mean = (1.0 + nu) * beam.bending_stress(cx, cy) / 3.0;
            error = error.max((s.pressure() - mean).abs());
            scale = scale.max(mean.abs());
        }
        rows.push((nu, bulk_ratio, *label, ratio, error / scale));
        ratio_series[k].push([bulk_ratio, ratio]);
        pressure_series[k].push([bulk_ratio, error / scale]);
    }
}

let sig4 = serde_json::json!({ "significantDigits": 4 });
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
emit_table_with_columns!(
    serde_json::json!([
        { "key": "0", "label": "Poisson 比 ν [-]", "type": "number", "format": fixed4 },
        { "key": "1", "label": "K/μ [-]", "type": "number", "format": sig4 },
        { "key": "2", "label": "要素" },
        { "key": "3", "label": "先端たわみ / 厳密解 [-]", "type": "number", "format": sig4 },
        { "key": "4", "label": "平均応力の相対誤差 [-]", "type": "number", "format": sci3 }
    ]),
    rows,
    metadata = serde_json::json!({ "id": "locking" })
);
let names = forms.map(|(label, _)| label);
let series = |data: &[Vec<[f64; 2]>]| -> Vec<serde_json::Value> {
    let marker = serde_json::json!({ "showSymbol": true });
    (0..3)
        .map(|k| serde_json::json!({ "name": names[k], "points": data[k], "style": marker }))
        .collect()
};
emit_line_chart!(
    &series(&ratio_series),
    options = &serde_json::json!({
        "link": { "group": "cantilever-bulk-ratio" },
        "xLabel": "体積弾性率とせん断弾性率の比 K/μ [-]",
        "yLabel": "先端たわみ / 厳密解 [-]",
        "xType": "log",
        "yMin": 0.0,
        "yMax": 1.1,
        "annotations": [{ "kind": "line", "axis": "y", "value": 1.0, "label": "厳密解" }]
    })
);
emit_line_chart!(
    &series(&pressure_series),
    options = &serde_json::json!({
        "link": { "group": "cantilever-bulk-ratio" },
        "xLabel": "体積弾性率とせん断弾性率の比 K/μ [-]",
        "yLabel": "平均応力の相対誤差 [-]",
        "xType": "log",
        "yType": "log"
    })
);
```

既定の $n_y=2$ では、P1 変位のたわみ比は $\nu=0.3$ で 0.525、$\nu=0.4999$ で 0.0174 まで下がる。
平均応力の相対誤差は 1.03 から 20.3 に増え、応力が厳密値と無関係な値になる。
$n_y=3$ に細かくしても $\nu=0.4999$ のたわみ比は 0.019 で、格子を細かくするだけではロッキングは解消しない。

P2 変位では、この梁のたわみ比は $\nu=0.4999$ でも 1.0006 で、たわみはロッキングしていない。
ただし平均応力の相対誤差は $3.0\times10^{-3}$ から $1.7\times10^{-2}$ へ約 5.5 倍に増え、$K/\mu$ とともに悪化する。
連続な P2 変位の発散 0 の部分空間はメッシュの形に依存し、どのメッシュでもロッキングしないとは言えない。

混合 P2/P1 では、たわみ比が 0.99996 から 0.99998、平均応力の相対誤差が $3.0\times10^{-3}$ から $3.4\times10^{-3}$ の間にあり、どちらも $K/\mu$ にほとんど依存しない。
グラフでは P1 の点が右下がりに 0 に近づき、混合形の点はたわみ比 1、相対誤差 $3\times10^{-3}$ の付近に水平に並ぶ。
非圧縮に近い材料ではたわみだけでなく応力も確かめ、`MixedP2P1` を選ぶ。
混合形の内部エネルギーは鞍点の汎関数の値で、`energy` の `internal` は正とは限らない。

## まとめ

`LinearElasticityPlan` で組み立てた行列を疎 LU で解き、P2 変位の先端たわみが Timoshenko–Goodier の厳密解と $10^{-5}$ 程度の相対差で一致することを確かめた。
梁理論との差はせん断変形と固定端の条件で説明でき、Euler–Bernoulli 梁より 0.7 % 大きいたわみが厳密解の値である。
$2U$ と外力の仕事の差は固定端の反力の仕事に一致し、全変位を固定すれば 0 になるので、エネルギーの収支から境界条件の扱いを点検できる。
P1 変位は平面応力の曲げでもせん断ロッキングで硬く、平面ひずみで $\nu\to1/2$ にすると体積ロッキングでたわみが 2 % 以下になる。
非圧縮に近い材料ではたわみと平均応力の両方が安定な `ElasticityFormulation::MixedP2P1` を選ぶ。
