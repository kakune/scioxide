太鼓の膜のように周囲を固定した円形膜の固有振動数は、Bessel 関数の零点で決まる。
零点そのものを番号付きで求める方法と振動数の表は、scioxide-rootfind の[円形膜の固有振動数と Bessel 関数の零点](../../../scioxide-rootfind/examples/circular-membrane/)で扱う。
このページはその値を参照値として引用し、有限要素法（FEM）が同じ固有値をどれだけ正確に再現するかを調べる。

円板を三角形に分けると、曲がった周は折れ線で近似される。
このときの誤差には要素の多項式の次数で決まる離散化の誤差と、領域の形の近似で決まる幾何誤差の二つがある。
P1・P2 要素と、アフィン・2 次の幾何の四つの組み合わせで、二つの誤差がどう現れるかを測る。

## 膜の固有値問題

半径 $a$ [m] の円板 $\Omega$ に張った膜の横変位 $w$ は波動方程式 $w_{tt} = c^2\Delta w$ に従い、$c = \sqrt{T/\sigma}$ [m/s] は張力 $T$ [N/m] と面密度 $\sigma$ [kg/m²] で決まる波の速さである。
$w = u(\mathbf x)\cos(\omega t)$ とおくと、$u$ は Dirichlet 固有値問題

$$
-\Delta u = \lambda u \quad (\Omega), \qquad u = 0 \quad (\partial\Omega), \qquad \lambda = \omega^2/c^2
$$

を満たす。
極座標で変数を分けると、固有関数は $J_\nu(j_{\nu,m}r/a)\cos(\nu\varphi)$ と $J_\nu(j_{\nu,m}r/a)\sin(\nu\varphi)$ で、固有値は

$$
\lambda_{\nu,m} = \left(\frac{j_{\nu,m}}{a}\right)^2,
\qquad
f_{\nu,m} = \frac{c\,j_{\nu,m}}{2\pi a}
$$

である。
ここで $j_{\nu,m}$ は $J_\nu$ の $m$ 番目の正の零点を表す。
$\nu = 0$ の固有値は単純で、$\nu \ge 1$ の固有値は $\cos$ と $\sin$ の二つの固有関数を持つ二重の固有値である。
低い順の 8 個は $(\nu, m) = (0, 1), (1, 1)^2, (2, 1)^2, (0, 2), (3, 1)^2$ で、肩の 2 は重複度を表す。
rootfind の例題にそろえて、$a = 0.33$ m、$\sigma = 0.26$ kg/m²、$T = 4000$ N/m（$c = 124.03$ m/s）とする。

## Galerkin 法と一般化固有値問題

弱形式は $H^1_0(\Omega)$ のすべての $v$ に対して $\int_\Omega \nabla u\cdot\nabla v\,dx = \lambda\int_\Omega uv\,dx$ が成り立つことである。
有限要素空間 $V_h$ の基底で $u_h = \sum_j U_j\phi_j$ と展開すると、一般化固有値問題

$$
K\mathbf U = \lambda_h M\mathbf U,
\qquad
K_{ij} = \int \nabla\phi_i\cdot\nabla\phi_j\,dx,
\quad
M_{ij} = \int \phi_i\phi_j\,dx
$$

が得られる。
$K$ は剛性行列、$M$ は整合質量行列で、どちらも対称で、境界の自由度を除けば正定値である。

固有値の min-max 原理（Courant–Fischer）から、$V_h \subset H^1_0(\Omega)$ で $K$、$M$ を厳密に積分すれば $\lambda_{h,k} \ge \lambda_k$（$k$ 番目どうし）が成り立つ。
滑らかな領域で次数 $p$ の要素を使い、領域を正確に表せば、固有値の誤差は $O(h^{2p})$ である（I. Babuška and J. Osborn, Eigenvalue problems, *Handbook of Numerical Analysis* II, 1991）。
$h$ は要素の大きさである。

## 境界の近似と幾何誤差

円板の三角形分割では、周の頂点を円周上に置いても、辺が直線なら領域は内接する正多角形 $\Omega_h \subset \Omega$ になる。
アフィン幾何の P1・P2 要素は $\Omega_h$ の上の問題を解き、$H^1_0(\Omega_h)$ の関数は 0 で延長すれば $H^1_0(\Omega)$ に入るので、固有値は上から近づく。
誤差には $\Omega_h$ と $\Omega$ の違いによる幾何誤差が加わる。

幾何誤差の大きさは領域の変形に対する固有値の一次の変化（Hadamard の公式）で見積もれる。
境界を内側へ $\delta(s)$ だけ動かすと、正規化した固有関数 $u$ に対して $\delta\lambda \approx \int_{\partial\Omega}(\partial_n u)^2\,\delta\,ds$ である。
円板では $\int_{\partial\Omega}(\partial_n u)^2 ds = 2\lambda/a$（Rellich の恒等式）で、周に沿った平均は $\lambda/(\pi a^2)$ である。
$(\partial_n u)^2$ は $\nu = 0$ では周に沿って一様で、$\nu \ge 1$ でも $\cos^2(\nu\varphi)$ の形でゆっくり変わり、$\delta(s)$ は周の辺ごとに速く振動する。
そのため積の積分は、平均と $\int\delta\,ds = |\Omega| - |\Omega_h|$ の積で近似でき、

$$
\frac{\delta\lambda}{\lambda} \approx \frac{|\Omega| - |\Omega_h|}{|\Omega|}
= 1 - \frac{N_b}{2\pi}\sin\frac{2\pi}{N_b}
\approx \frac{2\pi^2}{3N_b^2}
$$

となる。
$N_b$ は周の頂点の数で、周の辺の長さは $h_b \approx 2\pi a/N_b$ だから、幾何誤差は $O(h^2)$ である。
したがって、アフィン幾何の P2 要素は離散化の誤差が $O(h^4)$ でも、全体の誤差は $O(h^2)$ にとどまる。

2 次の幾何（`SimplexFemGeometry::Quadratic`）は、各辺の中点の物理座標を与えて要素を 2 次の写像で曲げる。
周の辺の中点を円周の上に置くと、周は円弧を 2 次式で補間した曲線になり、領域の近似の誤差は $O(h^3)$ に下がる。
P2 要素と同じ次数の写像（等パラメトリック要素）では、固有値の誤差は $O(h^4)$ に戻る（M. Lenoir, Optimal isoparametric finite elements and error estimates for domains involving curved boundaries, *SIAM J. Numer. Anal.* 23, 1986）。
2 次の幾何では $\Omega_h$ が $\Omega$ に含まれるとは限らず、求積も厳密でないので、上からの近似は保証されない。

## 円板の三角形分割

円板は半径を $n$ 等分した同心円で分ける。
$k$ 番目の円（半径 $ka/n$）に $6k$ 個の頂点を等間隔に置き、60° ずつの 6 つの扇形の中で、内側と外側の円の頂点を角度の順にたどって三角形を作る。
三角形は $6n^2$ 個、頂点は $1 + 3n(n + 1)$ 個、周の頂点は $N_b = 6n$ 個で、メッシュの幅は $h \approx a/n$ である。
ここでは Delaunay 三角形分割を使わず、扇形ごとに同じ規則で三角形を作り、メッシュを 60° の回転で不変にする。

2 次の幾何では、両端が周にある辺の中点を円周へ射影し、ほかの辺は直線のまま中点を与える。
中点の座標は `UnstructuredEdgeField` に正準な辺の順で入れ、`SimplexFemGeometry::Quadratic(edges.view())` で Plan に渡す。
周の全体に `TaggedBoundaries::uniform` で同次 Dirichlet 条件を与える。

剛性行列は `assemble_csr()`、整合質量は `assemble_mass_csr()` で取り出す。
`assemble_csr()` は Dirichlet の自由度の行と列を単位行列に置き換えるので、`constrained()` が偽の自由な自由度の行と列だけを取り出して $K_{ff}$、$M_{ff}$ を作る。
固有値は scioxide-linalg の `GeneralizedHermitianEigenvaluesResult::compute` で求める。
$M_{ff}$ の Cholesky 分解で標準形に還元してすべての固有値を昇順に返し、計算量は自由度 $N$ に対して $O(N^3)$、メモリ領域は $O(N^2)$ である（[一般化固有値問題](../../../scioxide-linalg/algorithms/generalized-eigenproblems/)）。
組み立てた $K$ には丸めの範囲の非対称が残ることがあるので、入力は `HermitianInput::Projected` で対称部分 $(K + K^\top)/2$ にし、変更のノルム $\|K - (K + K^\top)/2\|_F$ が $\sqrt{\varepsilon}\,(1 + \|K\|_F)$ を超えれば拒否する。
変更の相対量は `a_projection_report()` で読め、このページの計算では $10^{-16}$ より小さい。

次の定義のブロックは分割を作る `disc_mesh` と、固有値を求める `membrane_spectrum`、低い順の 8 個のモードと rootfind の例題の零点 `MODES` を持ち、このページの二つのセルが使う。

```rust
//| id: pde-drum-membrane-model
//| kind: definitions
//| title: 円板の三角形分割と膜の一般化固有値問題
//| crates: [scioxide-core, scioxide-linalg, scioxide-pde, scioxide-spatial]
use scioxide_core::{RealScalar, Tolerance};
use scioxide_linalg::{
    GeneralizedHermitianEigenvaluesResult, HermitianInput, HermitianProjectionPolicy, Matrix,
};
use scioxide_pde::{
    BoundaryData, BoundaryKind, ConstantDiffusion, SimplexFemGeometry, SimplexFemOrder,
    SimplexFemPlan, SpatialDiscretization, TaggedBoundaries,
};
use scioxide_spatial::{Point, TriangleMesh, UnstructuredEdgeField};
use std::f64::consts::PI;

/// 膜の半径 a [m]（rootfind の例題と同じ値）。
pub(crate) const RADIUS: f64 = 0.33;

/// 低い順の 8 個の固有値の (ν, m, j_{ν,m})。j は rootfind の例題の値。
pub(crate) const MODES: [(usize, usize, f64); 8] = [
    (0, 1, 2.404825557695773),
    (1, 1, 3.831705970207512),
    (1, 1, 3.831705970207512),
    (2, 1, 5.135622301840683),
    (2, 1, 5.135622301840683),
    (0, 2, 5.520078110286311),
    (3, 1, 6.380161895923984),
    (3, 1, 6.380161895923984),
];

/// n 個の同心円による円板の分割。円 k（半径 ka/n）は 6k 個の頂点を持つ。
pub(crate) fn disc_mesh(rings: usize) -> Result<TriangleMesh<f64>, String> {
    let mut points = vec![[0.0, 0.0]];
    for k in 1..=rings {
        let radius = RADIUS * k as f64 / rings as f64;
        for j in 0..6 * k {
            let angle = 2.0 * PI * j as f64 / (6 * k) as f64;
            points.push([
                radius * RealScalar::cos(angle),
                radius * RealScalar::sin(angle),
            ]);
        }
    }
    // 円 k の j 番目の頂点の番号。円 0 は中心の 1 点。
    let index = |k: usize, j: usize| {
        if k == 0 {
            0
        } else {
            3 * k * (k - 1) + 1 + j % (6 * k)
        }
    };
    let mut cells = Vec::new();
    for k in 1..=rings {
        for sector in 0..6 {
            // 扇形の中で内側の円は k − 1 区間、外側の円は k 区間。角度の小さい側から進める。
            let (inner, mut i, mut j) = (k - 1, 0, 0);
            while i < inner || j < k {
                let outer_next = i == inner || (j < k && (j + 1) * inner <= (i + 1) * k);
                let a = index(k - 1, sector * inner + i);
                let b = index(k, sector * k + j);
                let c = if outer_next {
                    j += 1;
                    index(k, sector * k + j)
                } else {
                    i += 1;
                    index(k - 1, sector * inner + i)
                };
                cells.push([a, b, c]);
            }
        }
    }
    let points = points
        .into_iter()
        .map(Point::new)
        .collect::<Result<Vec<_>, _>>()
        .map_err(|e| e.to_string())?;
    TriangleMesh::new(points, cells).map_err(|e| e.to_string())
}

/// 固有値の計算の結果。
pub(crate) struct Spectrum {
    /// 低い順の固有値 λ_h [1/m²]。
    pub(crate) eigenvalues: Vec<f64>,
    /// 自由な自由度の数。
    pub(crate) free: usize,
    /// 三角形の数。
    pub(crate) cells: usize,
    /// 剛性行列の対称化で変わった量 ‖K − (K + Kᵀ)/2‖_F / max(‖K‖_F, 1)。
    pub(crate) asymmetry: f64,
}

/// 周を固定した膜の固有値。curved なら周の辺の中点を円周へ射影した 2 次の幾何を使う。
pub(crate) fn membrane_spectrum(
    rings: usize,
    order: SimplexFemOrder,
    curved: bool,
) -> Result<Spectrum, String> {
    let mesh = disc_mesh(rings)?;
    let cells = mesh.cell_count();
    let first_boundary = 3 * rings * (rings - 1) + 1;
    let mut midpoints = Vec::new();
    for edge in 0..mesh.edge_count() {
        let [a, b] = *mesh.edge_vertices(edge).map_err(|e| e.to_string())?;
        let (p, q) = (mesh.points()[a].as_array(), mesh.points()[b].as_array());
        let mid = [0.5 * (p[0] + q[0]), 0.5 * (p[1] + q[1])];
        let on_circle = curved && a >= first_boundary && b >= first_boundary;
        let scale = if on_circle {
            RADIUS / RealScalar::hypot(mid[0], mid[1])
        } else {
            1.0
        };
        midpoints.push([scale * mid[0], scale * mid[1]]);
    }
    let edges = UnstructuredEdgeField::new(&mesh, midpoints).map_err(|e| e.to_string())?;
    let geometry = if curved {
        SimplexFemGeometry::Quadratic(edges.view())
    } else {
        SimplexFemGeometry::Affine
    };
    let fixed = TaggedBoundaries::<f64, f64, 2>::uniform(
        &mesh,
        1,
        BoundaryKind::Dirichlet,
        BoundaryData::zero(),
    )
    .map_err(|e| e.to_string())?;
    // −Δu = λu: 拡散係数 1、反応 0 の剛性行列と整合質量。
    let unit = ConstantDiffusion::new(1.0);
    let plan =
        SimplexFemPlan::new(mesh, geometry, order, &unit, &fixed).map_err(|e| e.to_string())?;
    let stiffness = plan.assemble_csr().map_err(|e| e.to_string())?;
    let mass = plan.assemble_mass_csr().map_err(|e| e.to_string())?;
    // 自由な自由度に通し番号を付け、K_ff と M_ff を密行列に写す。
    let mut number = vec![None; plan.unknowns()];
    let mut free = 0;
    for (slot, &constrained) in number.iter_mut().zip(plan.constrained()) {
        if !constrained {
            *slot = Some(free);
            free += 1;
        }
    }
    let mut dense = [vec![0.0; free * free], vec![0.0; free * free]];
    for (target, matrix) in dense.iter_mut().zip([&stiffness, &mass]) {
        for (row, col, value) in matrix.iter() {
            if let (Some(i), Some(j)) = (number[row], number[col]) {
                target[i * free + j] = value;
            }
        }
    }
    let [k, m] = dense;
    let k = Matrix::from_vec(free, free, k).map_err(|e| e.to_string())?;
    let m = Matrix::from_vec(free, free, m).map_err(|e| e.to_string())?;
    let input = HermitianInput::Projected(HermitianProjectionPolicy::Within(
        Tolerance::from_sqrt_epsilon(),
    ));
    let result = GeneralizedHermitianEigenvaluesResult::compute(&k, &m, input, input)
        .map_err(|e| e.to_string())?;
    let asymmetry = result
        .a_projection_report()
        .map_or(0.0, |r| r.relative_frobenius());
    Ok(Spectrum {
        eigenvalues: result.into_eigenvalues(),
        free,
        cells,
        asymmetry,
    })
}
```

## 一つのメッシュの固有値と重複度

次のセルは同心円の数 $n$、要素の次数、幾何を入力に、低い順の 8 個の固有値を求める。
出力はモードごとの rootfind の零点 $j_{\nu,m}$、厳密な振動数、FEM の振動数、固有値の相対誤差 $(\lambda_h - \lambda)/\lambda$、音程の差（セント）、二重の固有値の対の相対差の表と、メッシュと固有値計算の診断の表である。
固有値は低い順に並べた番号でモードと対応させる。
$n \ge 3$ では、四つの組み合わせとも低い順の 8 個がこの順に並ぶ。

```rust
//| id: pde-drum-single-mesh
//| ref: pde-drum-single-mesh
//| title: 一つのメッシュで膜の固有値と重複度を確かめる
//| run: reactive
//| uses: [pde-drum-membrane-model]
//| crates: [scioxide-core, scioxide-linalg, scioxide-pde, scioxide-spatial]
//| timeoutMs: 150000
//| inputs:
//|   drum_rings: {"type":"range","label":"同心円の数 n [-]","description":"メッシュの幅 h ≈ a/n と周の頂点の数 6n を変える。","min":3,"max":8,"step":1,"value":4}
//|   drum_order: {"type":"select","label":"要素の次数","options":["P1","P2"],"value":"P2"}
//|   drum_geometry: {"type":"select","label":"幾何","options":["アフィン","2 次"],"value":"2 次"}
//| cases:
//|   - {"id":"affine-p2","label":"P2・アフィン","description":"周が多角形になり、どのモードも相対誤差が 1.3〜2.5 × 10⁻² に増える。","inputs":{"drum_geometry":"アフィン"}}
//|   - {"id":"p1","label":"P1・2 次","description":"P1 要素では基本モードの相対誤差が 2.5 × 10⁻² になる。","inputs":{"drum_order":"P1"}}
//|   - {"id":"fine","label":"n = 8","description":"P2・2 次では基本モードの相対誤差が 1.1 × 10⁻⁵ に下がる。","inputs":{"drum_rings":8}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"modes","path":"/rows/0/0","equals":"(0, 1)"}
//|       - {"artifact":"modes","path":"/rows/0/2","approx":{"value":143.8577,"atol":5e-4}}
//|       - {"artifact":"modes","path":"/rows/0/4","approx":{"value":2.089e-4,"rtol":1e-2}}
//|       - {"artifact":"modes","path":"/rows/1/6","range":{"max":1e-11}}
//|       - {"artifact":"modes","path":"/rows/3/6","range":{"max":1e-11}}
//|       - {"artifact":"modes","path":"/rows/6/6","range":{"min":1e-4}}
//|       - {"artifact":"modes","path":"/rows/0/6","equals":null}
//|       - {"artifact":"mesh","path":"/rows/0/0","equals":96}
//|   - case: affine-p2
//|     expect:
//|       - {"artifact":"modes","path":"/rows/0/4","approx":{"value":1.286e-2,"rtol":1e-2}}
//|   - case: p1
//|     expect:
//|       - {"artifact":"modes","path":"/rows/0/4","approx":{"value":2.478e-2,"rtol":1e-2}}
//|   - case: fine
//|     expect:
//|       - {"artifact":"modes","path":"/rows/0/4","approx":{"value":1.058e-5,"rtol":2e-2}}
use scioxide_core::RealScalar;
use scioxide_pde::SimplexFemOrder;
use std::f64::consts::PI;

let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let fixed2 = serde_json::json!({ "fractionDigits": 2 });
let fixed6 = serde_json::json!({ "fractionDigits": 6 });
let order = if drum_order == "P1" {
    SimplexFemOrder::P1
} else {
    SimplexFemOrder::P2
};
let spectrum = membrane_spectrum(drum_rings as usize, order, drum_geometry == "2 次")?;
// 波の速さ c = √(T/σ)（T = 4000 N/m、σ = 0.26 kg/m²）。振動数 f = c√λ/(2π) [Hz]。
let speed = RealScalar::sqrt(4000.0_f64 / 0.26);
let hertz = |lambda: f64| speed * RealScalar::sqrt(lambda) / (2.0 * PI);
let mut rows = Vec::new();
for (index, &(nu, m, j)) in MODES.iter().enumerate() {
    let exact = RealScalar::powi(j / RADIUS, 2);
    let lambda = spectrum.eigenvalues[index];
    // ν ≥ 1 の対では、同じ (ν, m) のもう一方の固有値との相対差を出す。
    let partner = match nu {
        0 => None,
        _ if MODES[index - 1].0 == nu => Some(index - 1),
        _ => Some(index + 1),
    };
    let split = partner.map(|p| (spectrum.eigenvalues[p] - lambda).abs() / lambda);
    let cents = 1200.0 * RealScalar::log2(hertz(lambda) / hertz(exact));
    let label = format!("({nu}, {m})");
    rows.push((
        label,
        j,
        hertz(exact),
        hertz(lambda),
        (lambda - exact) / exact,
        cents,
        split,
    ));
}
let columns = serde_json::json!([
    { "key": "0", "label": "モード (ν, m)" },
    { "key": "1", "label": "j_ν,m [-]", "type": "number", "format": fixed6 },
    { "key": "2", "label": "厳密な振動数 [Hz]", "type": "number", "format": fixed2 },
    { "key": "3", "label": "FEM の振動数 [Hz]", "type": "number", "format": fixed2 },
    { "key": "4", "label": "λ の相対誤差 [-]", "type": "number", "format": sci3 },
    { "key": "5", "label": "音程の差 [cent]", "type": "number", "format": fixed2 },
    { "key": "6", "label": "対の相対差 [-]", "type": "number", "format": sci2, "nullText": "単純" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "modes" })
);
let mesh_columns = serde_json::json!([
    { "key": "0", "label": "三角形 [個]", "type": "integer" },
    { "key": "1", "label": "自由な自由度 [個]", "type": "integer" },

```

既定（$n = 4$、P2 要素、2 次の幾何）では、三角形 96 個、自由な自由度 169 個で、基本モード $(0, 1)$ の固有値の相対誤差は $2.1 \times 10^{-4}$、音程の差は 0.18 セントである。
相対誤差はモードの番号とともに増え、$(3, 1)$ では $1.0 \times 10^{-2}$ になる。
高いモードほど波長が短く、同じメッシュでも一波長あたりの要素が少ないからである。
この例では、四つの組み合わせのすべての固有値が厳密な値より大きく、誤差は正だった。

幾何をアフィンにすると、基本モードの相対誤差は $1.3 \times 10^{-2}$ と 60 倍に増え、8 個の固有値がそろって $1.3 \sim 2.5 \times 10^{-2}$ になる。
多角形の面積の不足 $1 - (24/2\pi)\sin(2\pi/24) = 1.1 \times 10^{-2}$ がどのモードにもほぼ同じ大きさで加わるからである。
P1 要素では 2 次の幾何でも基本モードの相対誤差が $2.5 \times 10^{-2}$ で、$(3, 1)$ では 0.23〜0.33 に達する。

二重の固有値の扱いはモードの次数 $\nu$ で分かれる。
$(1, 1)$ と $(2, 1)$ の対は $10^{-13}$ 以下の相対差で一致し、$(3, 1)$ の対だけが $8.0 \times 10^{-4}$ 離れる。
メッシュは 60° の回転 $R$ で不変なので、離散の $K$ と $M$ は自由度の置換 $R$ と可換である。
$\cos(\nu\varphi)$ と $\sin(\nu\varphi)$ の張る平面に $R$ は角度 $60\nu$° の回転として働く。
$\nu = 1, 2$ ではこの回転が平面の中に不変な直線を持たないので、近似する固有空間は 2 次元のまま残り、固有値は丸めの範囲で重なる。
$\nu = 3$ では $R$ が両方の関数を $-1$ 倍するだけなので、対称性は二つを結び付けず、メッシュが向きの違う二つのモードを区別して固有値が分かれる。
対の差は誤差と同じ速さで縮み、$n = 8$ では $5.6 \times 10^{-5}$ になる。

## 細分化と収束次数

次のセルは同心円の数を $n = 3, 4, 6, 8$ のうち $n_{\max}$ 以下の値で増やし、四つの組み合わせで低い順の 8 個の固有値の相対誤差を求めて、次のセルへ渡す。
入力は最大の同心円の数 $n_{\max}$ である。
P2 要素の自由度は $n = 8$ で 721 になり、密行列の一般化固有値の計算量 $O(N^3)$ が計算時間を決めるので、ボタンで実行し、同じ入力の結果は再利用する。
出力はメッシュごとの自由度の表である。

```rust
//| id: pde-drum-convergence-runs
//| ref: pde-drum-convergence-runs
//| title: 同心円の数を増やして四つの組み合わせの固有値を求める
//| run: button
//| cache: inputs
//| uses: [pde-drum-membrane-model]
//| crates: [scioxide-core, scioxide-linalg, scioxide-pde, scioxide-spatial]
//| timeoutMs: 420000
//| exports: [rings, errors]
//| inputs:
//|   drum_max_rings: {"type":"select","label":"最大の同心円の数 n_max [-]","options":["6","8"],"value":"8"}
//| cases:
//|   - {"id":"coarse","label":"n_max = 6","description":"メッシュを 4 つに減らし、計算を短くする。","inputs":{"drum_max_rings":"6"}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"sizes","path":"/rows/3/0","equals":8}
//|       - {"artifact":"sizes","path":"/rows/3/2","equals":721}
//|   - case: coarse
//|     expect:
//|       - {"artifact":"sizes","path":"/rows/2/2","equals":397}
use scioxide_pde::SimplexFemOrder;

let max_rings: usize = drum_max_rings.parse().map_err(|_| "n_max を読めない")?;
let rings: Vec<usize> = [3, 4, 6, 8]
    .into_iter()
    .filter(|&n| n <= max_rings)
    .collect();
let configurations = [
    (SimplexFemOrder::P1, false),
    (SimplexFemOrder::P1, true),
    (SimplexFemOrder::P2, false),
    (SimplexFemOrder::P2, true),
];
// errors[組み合わせ][メッシュ][モード] = (λ_h − λ)/λ。
let mut errors = vec![Vec::new(); configurations.len()];
let mut sizes = Vec::new();
for &n in &rings {
    let mut free = [0; 2];
    for (target, &(order, curved)) in errors.iter_mut().zip(&configurations) {
        let spectrum = membrane_spectrum(n, order, curved)?;
        free[order.degree() - 1] = spectrum.free;
        let relative: Vec<f64> = MODES
            .iter()
            .zip(&spectrum.eigenvalues)
            .map(|(&(_, _, j), &lambda)| {
                let exact = (j / RADIUS) * (j / RADIUS);
                (lambda - exact) / exact
            })
            .collect();
        target.push(relative);
    }
    sizes.push((n, free[0], free[1]));
}
let columns = serde_json::json!([
    { "key": "0", "label": "同心円の数 n [-]", "type": "integer" },
    { "key": "1", "label": "P1 の自由度 [個]", "type": "integer" },
    { "key": "2", "label": "P2 の自由度 [個]", "type": "integer" }
]);
emit_table_with_columns!(
    columns,
    sizes,
    metadata = serde_json::json!({ "id": "sizes" })
);
export!(rings, rings);
export!(errors, errors);
```

次のセルは渡された相対誤差から収束次数を求める。
入力は追うモードである。
出力はメッシュの幅 $h = a/n$ に対する相対誤差の両対数の図、メッシュごとの相対誤差と多角形の面積の不足 $1 - (N_b/2\pi)\sin(2\pi/N_b)$ の表、隣り合うメッシュの間の観測次数 $p = \log(e_1/e_2)/\log(n_2/n_1)$ の表である。
図の破線は $h^2$ と $h^4$ に比例する参照の傾きで、P1・アフィンと P2・2 次の最も細かいメッシュの点を通る。

```rust
//| id: pde-drum-convergence-orders
//| ref: pde-drum-convergence-orders
//| title: 相対誤差の収束次数と多角形の面積の不足を比べる
//| run: reactive
//| uses: [pde-drum-membrane-model]
//| crates: [scioxide-core, scioxide-linalg, scioxide-pde, scioxide-spatial]
//| dependsOn:
//|   runs: pde-drum-convergence-runs
//| inputs:
//|   drum_tracked_mode: {"type":"select","label":"追うモード (ν, m)","options":["(0, 1)","(1, 1)","(2, 1)","(0, 2)","(3, 1)"],"value":"(0, 1)"}
//| cases:
//|   - {"id":"mode-31","label":"(3, 1)","description":"二重の固有値の低い方を追う。P2・2 次の観測次数は 3.8〜4.2、P2・アフィンは 3.1 から 2.5 へ下がる。","inputs":{"drum_tracked_mode":"(3, 1)"}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"orders","path":"/rows/2/1","approx":{"value":2.3,"atol":0.2}}
//|       - {"artifact":"orders","path":"/rows/2/3","approx":{"value":2.0,"atol":0.2}}
//|       - {"artifact":"orders","path":"/rows/2/4","approx":{"value":4.2,"atol":0.3}}
//|       - {"artifact":"errors","path":"/rows/3/5","approx":{"value":2.853e-3,"rtol":1e-3}}
//|   - case: mode-31
//|     expect:
//|       - {"artifact":"orders","path":"/rows/2/4","range":{"min":3.5,"max":5}}
use scioxide_core::RealScalar;
use std::f64::consts::PI;

let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let fixed2 = serde_json::json!({ "fractionDigits": 2 });
let rings: Vec<usize> =
    serde_json::from_value(runs["rings"].clone()).map_err(|e| e.to_string())?;
let errors: Vec<Vec<Vec<f64>>> =
    serde_json::from_value(runs["errors"].clone()).map_err(|e| e.to_string())?;
let labels = ["(0, 1)", "(1, 1)", "(2, 1)", "(0, 2)", "(3, 1)"];
let position = labels
    .iter()
    .position(|&l| l == drum_tracked_mode)
    .ok_or("モードがない")?;
// 二重の固有値は低い方（MODES の最初の行）を追う。
let mode = [0, 1, 3, 5, 6][position];
let names = ["P1・アフィン", "P1・2 次", "P2・アフィン", "P2・2 次"];
let h = |n: usize| RADIUS / n as f64;
let mut series = Vec::new();
for (name, runs) in names.iter().zip(&errors) {
    let points: Vec<[f64; 2]> = rings
        .iter()
        .zip(runs)
        .map(|(&n, e)| [h(n), e[mode]])
        .collect();
    series.push(
        serde_json::json!({ "name": name, "style": { "symbol": "circle" }, "points": points }),
    );
}
// 参照の傾き: 最も細かいメッシュの P1・アフィンと P2・2 次の点を通る h² と h⁴。
let last = rings.len() - 1;
let dashed = serde_json::json!({ "lineType": "dashed", "symbol": "none" });
for (power, runs, name) in [(2, &errors[0], "h² の傾き"), (4, &errors[3], "h⁴ の傾き")]
{
    let anchor = runs[last][mode] / RealScalar::powi(h(rings[last]), power);
    let points: Vec<[f64; 2]> = rings
        .iter()
        .map(|&n| [h(n), anchor * RealScalar::powi(h(n), power)])
        .collect();
    series.push(serde_json::json!({ "name": name, "style": dashed, "points": points }));
}
emit_chart!(
    serde_json::json!({
        "kind": "line",
        "dataZoom": true,
        "tooltip": true,
        "series": series,
        "xLabel": "メッシュの幅 h = a/n [m]",
        "yLabel": "固有値の相対誤差 (λ_h − λ)/λ [-]",
        "xType": "log",
        "yType": "log"
    }),
    metadata = serde_json::json!({ "id": "convergence" })
);
// 内接する正 6n 角形の面積の不足（幾何誤差の一次の見積もり）。
let deficit = |n: usize| {
    let sides = 6.0 * n as f64;
    1.0 - sides / (2.0 * PI) * RealScalar::sin(2.0 * PI / sides)
};
let rows: Vec<_> = rings
    .iter()
    .enumerate()
    .map(|(i, &n)| {
        (
            n,
            errors[0][i][mode],
            errors[1][i][mode],
            errors[2][i][mode],
            errors[3][i][mode],
            deficit(n),
        )
    })
    .collect();
let columns = serde_json::json!([
    { "key": "0", "label": "同心円の数 n [-]", "type": "integer" },
    { "key": "1", "label": "P1・アフィン [-]", "type": "number", "format": sci3 },
    { "key": "2", "label": "P1・2 次 [-]", "type": "number", "format": sci3 },
    { "key": "3", "label": "P2・アフィン [-]", "type": "number", "format": sci3 },
    { "key": "4", "label": "P2・2 次 [-]", "type": "number", "format": sci3 },
    { "key": "5", "label": "多角形の面積の不足 [-]", "type": "number", "format": sci3 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "errors" })
);
// 観測次数 p = log(e₁/e₂)/log(n₂/n₁)。
let order = |c: usize, i: usize| {
    let ratio = errors[c][i][mode] / errors[c][i + 1][mode];
    RealScalar::ln(ratio) / RealScalar::ln(rings[i + 1] as f64 / rings[i] as f64)
};
let orders: Vec<_> = (0..last)
    .map(|i| {
        (
            format!("{} → {}", rings[i], rings[i + 1]),
            order(0, i),
            order(1, i),
            order(2, i),
            order(3, i),
        )
    })
    .collect();
let order_columns = serde_json::json!([
    { "key": "0", "label": "同心円の数" },
    { "key": "1", "label": "P1・アフィン [-]", "type": "number", "format": fixed2 },
    { "key": "2", "label": "P1・2 次 [-]", "type": "number", "format": fixed2 },
    { "key": "3", "label": "P2・アフィン [-]", "type": "number", "format": fixed2 },
    { "key": "4", "label": "P2・2 次 [-]", "type": "number", "format": fixed2 }
]);
emit_table_with_columns!(
    order_columns,
    orders,
    metadata = serde_json::json!({ "id": "orders" })
);
```

既定（$n_{\max} = 8$）では、基本モード $(0, 1)$ の観測次数は、最も細かい $6 \to 8$ の区間で P1・アフィンが 2.23、P1・2 次が 2.31、P2・アフィンが 2.07、P2・2 次が 4.21 である。
P1 要素は幾何によらず $O(h^2)$ で、2 次の幾何は誤差の定数を 0.6 倍ほどに下げるだけである。
P2 要素の次数 4 は 2 次の幾何のときだけ現れる。
アフィン幾何の P2 要素は $O(h^2)$ にとどまり、P1・2 次との差は誤差の定数だけになる。

P2・アフィンの相対誤差と多角形の面積の不足の比は、$n = 3, 4, 6, 8$ で 1.21、1.13、1.07、1.05 と 1 に近づく。
アフィン幾何の P2 要素の誤差は面積の不足で見積もった幾何誤差で説明できる。
$(3, 1)$ のような高いモードでは、粗いメッシュで P2 の離散化の誤差も大きく、P2・アフィンの観測次数は 3.1 から 2.5 へと 2 に向かって下がる途中である。
$(0, 2)$ の P1 の観測次数は 1.5 から 2.05 へ上がり、粗いメッシュでは漸近の次数に達していない。

$n = 10$ では P2 の自由度が 1141 になり、密な一般化固有値の計算は、計算量 $O(N^3)$ から見積もると $n = 8$ の約 4 倍の時間がかかる。
低い数個の固有値だけが要る大きな問題では、scioxide-linalg の LOBPCG 法（`LobpcgSolver`）のように、行列との積だけを使って端の固有値を求める方法がある。

## まとめ

円形膜の Dirichlet 固有値は、`SimplexFemPlan` の剛性行列と整合質量から自由な自由度の部分を取り出し、一般化固有値問題として求められる。
アフィン幾何では周が多角形になり、P2 要素でも固有値の誤差は面積の不足とほぼ等しい $O(h^2)$ の幾何誤差で決まる。
周の辺の中点を円周に置く 2 次の幾何（`SimplexFemGeometry::Quadratic`）にすると、P2 要素の固有値は $O(h^4)$ で収束する。
P1 要素では幾何によらず $O(h^2)$ である。
メッシュの回転対称性は二重の固有値の一部（ここでは $\nu = 1, 2$）だけを丸めの範囲で重ねるので、重複度を確かめるときは対の相対差を誤差と比べて読む。
