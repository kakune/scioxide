張力を受けた弦の小さな横振動は、双曲型偏微分方程式の基本的な物理モデルの一つである。
短い時間の変位が滑らかに見えても、精度が高いとは限らない。
空間格子は波長ごとに異なる位相速度を持ち込み（数値分散）、波の位相を少しずつ遅らせる。

このページでは両端を固定した弦の一つの固有モードを FDM・FEM・FVM の Plan と `HyperbolicProblem` で時間発展させる。
終端の誤差を、時間積分の誤差と空間格子による位相の遅れに分け、どちらが支配するかを測る。
格子が倍音の音程をどれだけずらすかは[弦の倍音の音程と質量行列](../string-overtone-dispersion/)で扱う。

## 両端固定弦の波動方程式

線密度 $\rho$ [kg/m]、張力 $T$ [N] が一様な長さ $L$ [m] の弦の横変位を $u(x, t)$ [m] とする。
微小な区間 $[x, x + \Delta x]$ に働く張力の縦成分の差と Newton の運動方程式から、一次元の波動方程式

$$
\rho\, u_{tt} = T\, u_{xx}
\quad\Longleftrightarrow\quad
u_{tt} = c^2 u_{xx}, \qquad c = \sqrt{T/\rho}
$$

が得られる。
$c$ [m/s] は波の速さである。
両端を固定するので、境界条件は同次 Dirichlet 条件 $u(0, t) = u(L, t) = 0$ である。

初速度を 0、初期変位を振幅 $A$ [m] の第 $m$ 固有モード $u(x, 0) = A\sin(k_m x)$（$k_m = m\pi/L$）とすると、厳密解は定在波

$$
u(x, t) = A\cos(\omega_m t)\sin(k_m x), \qquad \omega_m = c\,k_m = \frac{m\pi c}{L}
$$

で、周期は $P_m = 2\pi/\omega_m = 2L/(mc)$ である。
この例では長さ $L = 0.65$ m、波の速さ $c = 143$ m/s の弦を考える。
基本振動数は $c/(2L) = 110$ Hz で、ギターの第 5 弦（A2）に当たる。
振幅は $A = 1$ mm とする。

## 半離散系と二つの誤差

一様な格子幅 $h = L/(N - 1)$ で $u_{xx}$ を三点の中心差分に置き換えると、未知数 $u_j(t) \approx u(x_j, t)$ の常微分方程式系（半離散系）

$$
\ddot u_j = c^2\,\frac{u_{j-1} - 2u_j + u_{j+1}}{h^2}
$$

が得られる。
離散の正弦 $\sin(k_m x_j)$ はこの系の固有ベクトルで、半離散系の厳密解は $u_j(t) = A\cos(\omega_{h,m} t)\sin(k_m x_j)$ になる。
角周波数は

$$
\omega_{h,m} = \frac{2c}{h}\sin\frac{k_m h}{2} < \omega_m
$$

で、連続の $\omega_m$ よりわずかに小さい。
P1 要素の FEM でも、集中質量（質量行列の行和を対角に置いた行列）を使えば一様格子で同じ式になる。

したがって、数値解と連続の厳密解の差は二つに分かれる。

1. **空間の誤差:** 半離散系の解は $\omega_{h,m} t$ の位相で振動するので、時刻 $t$ までに位相が $(\omega_m - \omega_{h,m})t$ だけ遅れる。
2. **時間の誤差:** 時間積分は半離散系の解を近似するだけで、その差が時間積分の誤差である。

時間の誤差は数値解を固有ベクトルへ射影したモードの振幅

$$
a(t) = \frac{\sum_j u_j(t)\sin(k_m x_j)}{A\sum_j \sin^2(k_m x_j)}
$$

と $\cos(\omega_{h,m}t)$ の差で測れる。
空間の誤差を含まないので、二つの誤差を分けて読める。

## 時間積分と刻みの上限

`HyperbolicProblem::new(&plan, &source, end)` は、Plan の作用素 $A$ と集中質量 $M$ で $M\ddot u = b(t) - Au$ を組み立てる。
`solve_with_options(&displacement, &velocity, &options)` は、変位と速度を並べた一階の系を適応刻みの Dormand–Prince 5(4) 法（DOPRI5）で $t = 0$ から `end` まで積分する。
局所誤差の許容誤差は、既定では絶対・相対とも $10^{-8}$ で、誤差は RMS ノルムで測る。
波動問題では三つの Plan に係数のプロバイダーから拡散係数として $c^2$ を渡す。

`HyperbolicOptions` の既定の `CflPolicy::Automatic` は、質量で正規化した剛性のスペクトル半径の上界 $\rho$ から、刻みを $0.9 \times 0.9971/\sqrt\rho$ 以下に抑える。
0.9971 は、DOPRI5 の安定関数 $R(z)$ が虚軸上で $|R(iy)| \le 1$ を満たす区間 $|y| \le 0.9971$ の端である。
変位と速度の一階の系の固有値は $\pm i\sqrt{\lambda}$（$\lambda$ は質量で正規化した剛性の固有値）なので、刻み $\Delta t$ が $\Delta t\sqrt\rho \le 0.9971$ を満たせば安定である。
三点差分では $\rho \approx 4c^2/h^2$ なので、上限はおよそ $0.45\,h/c$ になる。
`CflPolicy::Disabled` はこの上限を外し、局所誤差の制御だけで刻みを決める。
`PdeOutputSchedule::TimeSteps` を選ぶと、初期状態と受理した各刻みの場を `PdeSolution::trajectory` で受け取れる。

## 三つの Plan でのモードの追跡

次のセルは FDM（`StructuredFdmPlan`）、P1 の FEM（`SimplexFemPlan`）、セル中心の FVM（`StructuredFvmPlan`）で同じ初期値を解く。
入力はモード番号 $m$、格子点数 $N$、整数周期数 $K$、局所誤差の許容誤差と、安定性による刻みの上限を使うかどうかである。
終端は $t_{\mathrm{end}} = (K + 1/8)P_m$ とする。
整数周期ちょうどでは $\cos$ の傾きが 0 で、位相の遅れが変位の差に現れにくいので、1/8 周期ずらす。

出力は終端の変位の図、Plan ごとの終了理由・受理した刻み・棄却した刻み・連続解との最大誤差の表、三つの解の結論である。
最大誤差は振幅 $A$ で割った値である。
三つの Plan は `SpatialDiscretization` を共有するので、一つの関数 `track` で解き、未知数の位置を `dof_point` で読む。
FVM の未知数はセル中心の値である。
各刻みのモードの振幅 $a(t)$ も計算して次のセルへ渡す。

// 波動問題では拡散係数に波の速さの二乗 c² [m²/s²] を渡す。
struct SquaredSpeed(f64);
impl StructuredFdmCoefficients<f64, f64, 1> for SquaredSpeed {
    fn diffusion(&self, _: usize, _: usize, _: [f64; 1]) -> Result<f64, SciOxideError> {
        Ok(self.0)
    }
}
impl FvmCoefficients<f64, f64, 1> for SquaredSpeed {
    fn diffusion(&self, _: [f64; 1]) -> Result<[[f64; 1]; 1], SciOxideError> {
        Ok([[self.0]])
    }
}
impl SimplexFemCoefficients<f64, f64, 1> for SquaredSpeed {
    fn evaluate(&self, _: [f64; 1], k: &mut [f64], c: &mut [f64]) -> Result<(), SciOxideError> {
        (k[0], c[0]) = (self.0, 0.0);
        Ok(())
    }
}
/// 解いて (終了理由, 受理, 棄却, 連続解との最大誤差 / A, 終端の変位, 時刻, a(t)) を返す。
type Track = (String, usize, usize, f64, Vec<[f64; 2]>, Vec<f64>, Vec<f64>);
fn track<P: SpatialDiscretization<f64, f64, 1>>(
    plan: &P,
    options: &HyperbolicOptions<f64>,
    [k, omega, amplitude, end]: [f64; 4],
) -> Result<Track, String> {
    let source = FieldData::zero();
    // 初期変位 A sin(kx)（参照値として f64 の sin で与える）、初速度 0。
    let displacement = FieldData::time_invariant(move |p: FieldPoint<f64, 1>| {
        Ok(amplitude * (k * p.point[0]).sin())
    });
    let problem = HyperbolicProblem::new(plan, &source, end).map_err(|e| e.to_string())?;
    let solution = problem
        .solve_with_options(&displacement, &FieldData::zero(), options)
        .map_err(|e| e.error().to_string())?;
    let mut x = Vec::new();
    for unknown in 0..plan.unknowns() {
        x.push(plan.dof_point(unknown).map_err(|e| e.to_string())?.point[0]);
    }
    let u = solution.values();
    let error = x
        .iter()
        .zip(u)
        .map(|(x, v)| (v / amplitude - (omega * end).cos() * (k * x).sin()).abs())
        .fold(0.0_f64, f64::max);
    // 受理した各刻みで a(t) = Σ u sin(kx) / (A Σ sin²(kx)) を求める。
    let norm: f64 = x.iter().map(|x| (k * x).sin().powi(2)).sum::<f64>() * amplitude;
    let trajectory = solution.trajectory();
    let modal = trajectory
        .states()
        .iter()
        .map(|state| {
            state
                .iter()
                .zip(&x)
                .map(|(v, x)| v * (k * x).sin())
                .sum::<f64>()
                / norm
        })
        .collect();
    let report = solution.report();
    let d = report.diagnostics();
    Ok((
        report.termination().to_string(),
        d.num_accepted_steps(),
        d.num_rejected_steps(),
        error,
        x.iter().zip(u).map(|(x, v)| [*x, v / amplitude]).collect(),
        trajectory.times().to_vec(),
        modal,
    ))
}
// 長さ L = 0.65 m、c = 143 m/s（基本振動数 110 Hz）、振幅 A = 1 mm の弦。
let (length, c, amplitude) = (0.65, 143.0, 1e-3);
let nodes = string_grid_nodes as usize;
let k = string_mode_number * PI / length;
let (omega, h) = (c * k, length / (nodes - 1) as f64);
let end = (string_completed_cycles + 0.125) * 2.0 * PI / omega;

let segment = SegmentMesh::new(grid).map_err(|e| e.to_string())?;
let mut ends = Vec::new();
for side in [AxisSide::Start, AxisSide::End] {
    let set = BoundarySet::axis_side(&segment, 0, side).map_err(|e| e.to_string())?;
    ends.push(BoundaryCondition::dirichlet(set, BoundaryData::zero()));
}
let ends = StructuredBoundaries::new(&segment, 1, ends).map_err(|e| e.to_string())?;
let points = (0..nodes)
    .map(|i| Point::new([i as f64 * h]))
    .collect::<Result<Vec<_>, _>>()
    .map_err(|e| e.to_string())?;
let interval = IntervalMesh::new(points, (0..nodes - 1).map(|i| [i, i + 1]).collect())
    .map_err(|e| e.to_string())?;
let faces = interval.boundary_faces().map(|f| (f, 0)).collect();

let fixed = vec![BoundaryCondition::dirichlet(0, BoundaryData::zero())];

let fvm = StructuredFvmPlan::new(segment, &speed, &ends).map_err(|e| e.to_string())?;

    SimplexFemPlan::new(interval, affine, p1, &speed, &tagged).map_err(|e| e.to_string())?;

    .map_err(|e| e.to_string())?;

    .with_cfl_policy(cfl)

    ("FEM", track(&fem, &options, parameters)?),
    ("FVM", track(&fvm, &options, parameters)?),

    .map(|i| i as f64 * length / 200.0)
    .map(|x| [x, (omega * end).cos() * (k * x).sin()])

        )

既定（$m = 3$、$N = 49$、$K = 6$）では、三つの Plan とも `Completed` で、どれも 440 回の刻みを受理した。
連続解との最大誤差は FDM と FEM で $4.23 \times 10^{-2}$、FVM で $4.21 \times 10^{-2}$ である。
FDM と FEM の値は丸めの範囲で一致し、一様格子では集中質量の P1 要素が三点差分と同じ半離散系を作ることを確かめられる。

刻みの数は局所誤差の制御ではなく安定性の上限で決まっている。
既定の上限 $0.9 \times 0.9971/\sqrt\rho \approx 4.25 \times 10^{-5}$ s で終端 $t_{\mathrm{end}} = 1.86 \times 10^{-2}$ s まで進むと約 437 回になり、受理した 440 回とほぼ一致する。
上限を外すと局所誤差の制御だけで刻みが決まり、受理は 324 回に減る。
許容誤差を $10^{-6}$ に緩めても刻みは上限で決まったままなので、刻みの数も連続解との誤差も変わらない。
許容誤差を $10^{-10}$ に締めると、局所誤差の制御が上限より小さい刻みを選び、受理は 808 回に増える。

$K = 20$ では誤差が $1.3 \times 10^{-1}$ に増え、$N = 81$ では $1.6 \times 10^{-2}$ に下がる。
許容誤差を変えても誤差が変わらず、格子と観測時間で変わることは、誤差の主因が空間格子による位相の遅れであることを示唆する。
次のセルで、これを時間の誤差と比べて確かめる。

## 時間の誤差と位相の遅れの分離

次のセルは、前のセルが渡したモードの振幅 $a(t)$ を半離散系の厳密解 $\cos(\omega_{h,m}t)$ と比べる。
差の最大値が時間積分の誤差である。
さらに、位相の遅れだけから予測した終端の誤差

$$
e_{\mathrm{phase}} = \bigl|\cos(\omega_{h,m}t_{\mathrm{end}}) - \cos(\omega_m t_{\mathrm{end}})\bigr|
$$

を、前のセルで測った連続解との最大誤差と比べる。
半離散系の解の空間の形は $\sin(k_m x_j)$ のままなので、二つが一致すれば、終端の誤差はほとんど位相の遅れで説明できる。

```rust
//| id: pde-string-time-error
//| ref: pde-string-time-error
//| title: モードの振幅を半離散解と比べ、時間の誤差と位相の遅れを分ける
//| run: reactive
//| crates: [scioxide-core]
//| dependsOn:
//|   runs: pde-string-mode-comparison
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"split","path":"/rows/0/1","range":{"min":1e-10,"max":1e-6}}
//|       - {"artifact":"split","path":"/rows/0/2","approx":{"value":4.2315507e-2,"rtol":1e-3}}
//|       - {"artifact":"split","path":"/rows/0/3","approx":{"value":4.2315507e-2,"rtol":1e-3}}
//|       - {"artifact":"phase","path":"/rows/0/2","approx":{"value":1.6056e-3,"rtol":1e-3}}
use scioxide_core::RealScalar;

let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let fixed4 = serde_json::json!({ "fractionDigits": 4 });
let omega = runs["omega"].as_f64().ok_or("ω がない")?;
let semi = runs["semi_discrete"].as_f64().ok_or("ω_h がない")?;
let end = runs["end"].as_f64().ok_or("終端の時刻がない")?;
let tracks = runs["tracks"].as_array().ok_or("Plan ごとの結果がない")?;
// 位相の遅れだけによる終端の誤差 |cos(ω_h t) − cos(ω t)|。
let phase_only = (RealScalar::cos(semi * end) - RealScalar::cos(omega * end)).abs();
let mut series = Vec::new();
let mut rows = Vec::new();
for track in tracks {
    let name = track["name"].as_str().ok_or("Plan の名前がない")?;
    let times: Vec<f64> =
        serde_json::from_value(track["times"].clone()).map_err(|e| e.to_string())?;
    let modal: Vec<f64> =
        serde_json::from_value(track["amplitude"].clone()).map_err(|e| e.to_string())?;
    let measured = track["error"].as_f64().ok_or("連続解との誤差がない")?;
    // 時間の誤差 a(t) − cos(ω_h t)。
    let points: Vec<[f64; 2]> = times
        .iter()
        .zip(&modal)
        .map(|(&t, &a)| [t, a - RealScalar::cos(semi * t)])
        .collect();
    let time_error = points.iter().map(|p| p[1].abs()).fold(0.0_f64, f64::max);
    rows.push((name.to_owned(), time_error, measured, phase_only));
    series.push(serde_json::json!({ "name": name, "points": points }));
}
emit_line_chart!(
    &series,
    options = &serde_json::json!({
        "xLabel": "時刻 t [s]",
        "yLabel": "a(t) − cos(ω_h t) [-]"
    })
);
let columns = serde_json::json!([
    { "key": "0", "label": "Plan" },
    { "key": "1", "label": "時間の誤差の最大 [-]", "type": "number", "format": sci3 },
    { "key": "2", "label": "連続解との最大誤差 /A [-]", "type": "number", "format": sci3 },
    { "key": "3", "label": "位相の遅れから予測した誤差 [-]", "type": "number", "format": sci3 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "split" })
);
let phase_columns = serde_json::json!([
    { "key": "0", "label": "連続の ω [rad/s]", "type": "number", "format": fixed4 },
    { "key": "1", "label": "半離散の ω_h [rad/s]", "type": "number", "format": fixed4 },
    { "key": "2", "label": "相対差 1 − ω_h/ω [-]", "type": "number", "format": sci3 },
    { "key": "3", "label": "終端の位相の遅れ [rad]", "type": "number", "format": sci3 }
]);
emit_table_with_columns!(
    phase_columns,
    vec![(omega, semi, 1.0 - semi / omega, (omega - semi) * end)],
    metadata = serde_json::json!({ "id": "phase" })
);
```

既定では、三つの Plan の時間の誤差は $5.5 \times 10^{-8}$ で、連続解との誤差 $4.23 \times 10^{-2}$ より 6 桁小さい。
位相の遅れだけから予測した誤差 $4.231555 \times 10^{-2}$ は FDM の測定値 $4.231550 \times 10^{-2}$ と 6 桁一致し、差の $5 \times 10^{-8}$ は時間の誤差と同じ大きさである。
半離散の角周波数は連続より 0.16% 小さく、6.125 周期の間に位相が 0.062 rad 遅れる。
終端の誤差のほとんどは時間積分ではなく空間格子による位相の遅れである。

FVM の時間の誤差も FDM と同じ $5.5 \times 10^{-8}$ になる。
セル中心の値 $\sin(k_m x_j)$ も半離散系の固有ベクトルで、角周波数は同じ $\omega_{h,m}$ になる。
Dirichlet 境界の面で半セルの距離 $h/2$ を使う流束が、境界の外側のセルに $-u_0$ を置いた鏡像と同じ式になるからである。
FVM の連続解との誤差が $4.21 \times 10^{-2}$ とわずかに小さいのは、誤差をセル中心で測るからである。
既定では節点 $x = L/2$ が腹（$|\sin(k_3 x)| = 1$ の点）に乗るが、セル中心は乗らず、最大の $|\sin(k_3 x_j)|$ は $\cos(\pi/32) = 0.9952$ である。
$4.2316 \times 10^{-2} \times 0.9952 = 4.211 \times 10^{-2}$ は FVM の誤差と一致する。

## まとめ

固定端の弦の固有モードを三つの Plan で追跡すると、適応 DOPRI5 の時間の誤差は $10^{-7}$ 以下で、終端の変位の誤差は空間格子による位相の遅れで決まった。
`PdeOutputSchedule::TimeSteps` で受け取ったモードの振幅を半離散の厳密解と比べれば、時間積分の誤差と空間の誤差を分けて測れる。
既定の `CflPolicy::Automatic` では刻みの数が安定性の上限で決まるので、許容誤差を緩めても刻みは減らない。
誤差を減らすには時間の許容誤差ではなく、一波長あたりの格子点数を増やす。
