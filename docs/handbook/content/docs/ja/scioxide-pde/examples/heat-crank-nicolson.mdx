熱伝導は散逸の過程で、初期の温度分布に含まれる急な変化（高い波数の Fourier 成分）を速く減衰させ、温度場を滑らかにする。
この例題では金属棒の熱収支から熱方程式を導き、`ParabolicProblem` の後退 Euler 法と Crank–Nicolson 法を二つの観点で比べる。
滑らかな正弦モードでは空間誤差と時間誤差を分けて測る。
段差状の初期値では、Crank–Nicolson 法が高い波数の成分をほとんど減衰させずに残すことと、Rannacher 起動の効果を確かめる。
比べる基準は空間だけを離散化した系（半離散系）の厳密解である。

## 熱収支と一次元の熱方程式

密度 $\rho$、比熱 $c_p$、熱伝導率 $k$、断面積 $A$ が一様な細い棒を考える。
長さ $\Delta x$ の小区間に蓄えられる熱量は、単位時間に $\rho c_pA\Delta x\,\partial_tT$ だけ変わる。
両端面から入る正味の熱流は、Fourier の法則 $q=-k\,\partial_xT$ から $-A\,\partial_xq\,\Delta x=Ak\,\partial_x^2T\,\Delta x$ になる。
内部発熱がなければ両者は等しく、次の熱方程式を得る。

$$
\frac{\partial T}{\partial t}=\alpha\frac{\partial^2T}{\partial x^2},\qquad \alpha=\frac{k}{\rho c_p}
$$

$\alpha$ は熱拡散率である。
純銅や純アルミニウムの熱拡散率は室温で約 $1\ \mathrm{cm^2/s}$ なので、この例題では長さを cm、時間を s で測る。
長さ $L$ の棒の両端の温度を基準温度に保つと、基準温度からの差 $u$ は両端で $0$ になる。
初期分布を正弦級数 $u(x,0)=\sum_m a_m\sin(m\pi x/L)$ に展開すると、各モードは独立に次のように減衰する。

$$
u_m(x,t)=a_m\exp\!\left[-\alpha\left(\frac{m\pi}{L}\right)^2t\right]\sin\frac{m\pi x}{L}
$$

減衰率は $m^2$ に比例するので、細かい凹凸ほど速く消える。

## 一刻みの増幅率

空間を頂点の間隔 $h$ の中心差分で離散化すると、モード $m$ は半離散系 $u'=-\mu_m u$ の固有値 $-\mu_m$ を持つ。

$$
\mu_m=\frac{4\alpha}{h^2}\sin^2\frac{m\pi h}{2L}
$$

$z=\mu_m\Delta t$ とおくと、一刻みでモードの振幅に掛かる増幅率 $G(z)$ は次のとおりである。

| スキーム | 時間精度 | $G(z)$ | 安定性 | $z\to\infty$ の極限 | 注意点 |
|---|---|---|---|---|---|
| 半離散系の厳密解 | 厳密 | $e^{-z}$ | 減衰 | $0$ | $0<G\le1$ |
| 後退 Euler 法 | 1 次 | $1/(1+z)$ | L 安定 | $0$ | 単調に減衰するが、時間誤差は 1 次 |
| Crank–Nicolson 法 | 2 次 | $(1-z/2)/(1+z/2)$ | A 安定 | $-1$ | $z>2$ で $G<0$ になり、高い波数の成分が符号を変えながら残る |

Crank–Nicolson 法は A 安定だが、硬いモード（$z\gg1$）の増幅率が $-1$ に近い。
厳密解では速く消えるはずの成分が、ほとんど減衰しない。
滑らかな初期値ではそのような成分の振幅がもともと小さいので問題にならないが、段差状の初期値では格子規模の振動として残る。
増幅率の導出は[Crank–Nicolson 法の振動と Rannacher 起動](oxref:pde-crank-nicolson-rannacher)にある。

二つのセルは両端を $0$ に保つ棒の差分の Plan と、半離散系の減衰率 $\mu_m$ を次の定義から使う。
`StructuredFdmPlan` は熱拡散率 $\alpha$ を拡散係数とし、集中質量（頂点の周りの区間の長さ、内部の頂点では $h$）を持つので、半離散系の固有値は上の $\mu_m$ に一致する。

```rust
//| id: pde-heat-rod-model
//| kind: definitions
//| title: 両端を 0 に保つ棒の差分の Plan と半離散系の減衰率
//| crates: [scioxide-core, scioxide-pde, scioxide-spatial]
use scioxide_core::SciOxideError;
use scioxide_pde::{
    BoundaryData, BoundaryKind, ConstantDiffusion, StructuredBoundaries, StructuredFdmPlan,
};
use scioxide_spatial::{AxisTopology, CoordinateAxis, Grid1d, SegmentMesh};

/// 長さ 1 cm の棒に頂点 nodes 個を等間隔に置き、熱拡散率 α [cm²/s] を拡散係数とする Plan。
/// 両端の温度差は 0 K（Dirichlet）。
pub(crate) fn rod(
    nodes: usize,
    diffusivity: f64,
) -> Result<StructuredFdmPlan<f64, f64, 1>, SciOxideError> {
    let axis = CoordinateAxis::uniform(0.0, 1.0, nodes)?;
    let mesh = SegmentMesh::new(Grid1d::new([axis], [AxisTopology::Bounded])?)?;
    let ends =
        StructuredBoundaries::uniform(&mesh, 1, BoundaryKind::Dirichlet, BoundaryData::zero())?;
    StructuredFdmPlan::new(mesh, &ConstantDiffusion::new(diffusivity), &ends)
}

/// 半離散系のモード m の減衰率 μ_m = (4α/h²) sin²(mπh/2) [1/s]（L = 1 cm）。
/// 検算用の参照値として f64 の sin を使う。
pub(crate) fn semidiscrete_rate(mode: f64, h: f64, diffusivity: f64) -> f64 {
    4.0 * diffusivity / (h * h) * (std::f64::consts::PI * mode * h / 2.0).sin().powi(2)
}
```

## 滑らかなモードの時間誤差と空間誤差

$L=1$ cm、初期値 $u(x,0)=\sin(\pi x)$ K では、連続の厳密解は $e^{-\alpha\pi^2t}\sin(\pi x)$、半離散系の厳密解は $e^{-\mu_1t}\sin(\pi x)$ である。
両者の差が空間誤差、数値解と半離散系の厳密解の差が時間誤差なので、二つを別々に測れる。
空間誤差は閉形式 $|e^{-\mu_1t}-e^{-\alpha\pi^2t}|$ で計算できる。

次のセルは Plan と、終端時刻を持つ `ParabolicProblem` を一度だけ準備する。
`ParabolicProblem::new` は Dirichlet 条件の未知数を消去した半離散系、集中質量、ヤコビアンの構造をこのときに準備する。
`ParabolicOptions::with_scheme` で後退 Euler 法と Crank–Nicolson 法を選び、`with_step` で固定の刻み $\Delta t$ を与える。
固定刻みの方式では刻みの指定が必須で、最後の刻みは終端時刻にちょうど届くように調整される。
端数が残れば最後の刻みが短くなり、刻みを足し合わせた時刻の丸めの差も最後の刻みに吸収される。
初期値は `FieldData` で渡し、`solve_with_options` は終端の場とレポートを `PdeSolution` で返す。
表には二つの誤差と、刻みの回数・因子分解の回数（`PdeDiagnostics` の `num_time_steps`、`num_factorizations`）を出す。

```rust
    vec![(continuous_rate, discrete_rate, space_error)],
```

既定（$\alpha=1$ cm²/s、49 点、$\Delta t=0.002$ s、$t=0.05$ s）では、両方式とも 25 回の刻みで、因子分解は 2 回だった。
空間の作用素が時刻に依存しないので、ヤコビアンは定数として ODE の積分法に渡され、刻み幅が同じ段は一つの因子を使い回す。
$0.002$ は二進で正確に表せないので、終端に合わせた最後の刻みは丸めの水準で他と異なり、その段で因子を作り直す。
二進で正確に表せる $\Delta t=2^{-9}$ s と $t=2^{-4}$ s では、32 回の刻みで因子分解は 1 回になる。

後退 Euler 法の連続解との最大誤差は $3.05\times10^{-3}$ K で、そのうち時間誤差が $2.94\times10^{-3}$ K を占める。
Crank–Nicolson 法の時間誤差は $9.8\times10^{-6}$ K で、最大誤差 $9.8\times10^{-5}$ K のほとんどは空間誤差 $1.08\times10^{-4}$ K である。
刻みを $\Delta t=0.00025$ s（1/8）にすると、後退 Euler 法の時間誤差は $3.7\times10^{-4}$ K（約 1/8）、Crank–Nicolson 法の時間誤差は $1.5\times10^{-7}$ K（約 1/64）になり、それぞれ 1 次と 2 次の収束を示す。
このとき Crank–Nicolson 法の最大誤差は空間誤差でほぼ決まるので、さらに下げるには頂点数を増やす。
グラフでは、どちらの方式でも誤差が $\sin(\pi x)$ と同じ形で、両端で 0 になる。

## 段差の初期値と Rannacher 起動

中央 $0.25<x<0.75$ cm だけ $1$ K、他は $0$ K の段差（top-hat）の初期分布を、65 点の格子と $\alpha=1$ cm²/s で解く。
刻みは Fourier 数 $r=\alpha\Delta t/h^2$ で与える。
最も硬いモードの $z$ は約 $4r$ なので、$r>1/2$ では Crank–Nicolson 法の増幅率が負になるモードがある。
`ParabolicOptions::with_rannacher_startup` は、先頭の指定した区間数（`Budget` で渡す）の Crank–Nicolson 法の刻み $\Delta t$ を、後退 Euler 法の刻み $\Delta t/2$ の 2 回に置き換える。
設定は `ParabolicOptions::startup` が `RannacherStartup::BackwardEuler { intervals }` として返し、既定は `RannacherStartup::Disabled` である。
この起動は Crank–Nicolson 法を選んだときだけ使え、他の方式に付けると求解の開始時に `InvalidInput` のエラーになる。

比べる基準は同じ格子の半離散系を離散正弦変換で厳密に解いた $u_j(t)=\sum_m c_me^{-\mu_mt}\sin(m\pi x_j)$ である。
半離散系の固有値は $\mu_m$ に一致するので、数値解との差はすべて時間積分の誤差である。
格子規模の振動の目安として、二階差分 $\Delta^2u_j=u_{j-1}-2u_j+u_{j+1}$ の符号が変わる回数を数え、半離散系の厳密解の回数と比べる。

```rust
//|       - {"artifact":"profiles","path":"/rows/1/4","equals":2}
//|   - case: short-startup
//|     expect:
//|       - {"artifact":"profiles","path":"/rows/2/4","equals":6}
use scioxide_core::Budget;
use scioxide_pde::{FieldData, FieldPoint, ParabolicOptions, ParabolicProblem, ParabolicScheme};
use std::f64::consts::PI;

let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let fixed4 = serde_json::json!({ "fractionDigits": 4 });
let n = 64_usize; // 区間数（頂点 65 個）、α = 1 cm²/s
let h = 1.0 / n as f64;
let dt = heat_fourier_number * h * h;
let final_time = heat_evolution_intervals * dt;
let plan = rod(n + 1, 1.0).map_err(|e| e.to_string())?;
let source = FieldData::zero();
// 中央 0.25 < x < 0.75 cm だけ 1 K の段差。
let top_hat = |x: f64| if (x - 0.5).abs() < 0.25 { 1.0 } else { 0.0 };
let initial = FieldData::time_invariant(move |p: FieldPoint<f64, 1>| Ok(top_hat(p.point[0])));
let problem = ParabolicProblem::new(&plan, &source, final_time).map_err(|e| e.to_string())?;
// 独立な検算: 半離散系を離散正弦変換で厳密に解く（参照値として f64 の sin と exp を使う）。
let mut exact = vec![0.0; n + 1];
for m in 1..n {
    let c = (1..n)
        .map(|i| top_hat(i as f64 * h) * (PI * (m * i) as f64 / n as f64).sin())
        .sum::<f64>()
        * 2.0
        / n as f64;
    let decay = (-semidiscrete_rate(m as f64, h, 1.0) * final_time).exp();
    for (j, u) in exact.iter_mut().enumerate() {
        *u += c * decay * (PI * (m * j) as f64 / n as f64).sin();
    }
}
// 二階差分の符号変化の回数と、値の範囲。
let flips = |u: &[f64]| {
    let curvature: Vec<f64> = u.windows(3).map(|w| w[0] - 2.0 * w[1] + w[2]).collect();
    curvature.windows(2).filter(|p| p[0] * p[1] < 0.0).count()
};
let range = |u: &[f64]| {
    u.iter()
        .fold((f64::INFINITY, f64::NEG_INFINITY), |(a, b), &v| {
            (a.min(v), b.max(v))
        })
};
let profile = |u: &[f64]| -> Vec<[f64; 2]> {
    u.iter()
        .enumerate()
        .map(|(j, v)| [j as f64 * h, *v])
        .collect()
};
let startup = Budget::try_from(heat_rannacher_intervals as usize).map_err(|e| e.to_string())?;
let (mut rows, mut series) = (Vec::new(), Vec::new());
for (label, scheme, rannacher) in [
    ("後退 Euler 法", ParabolicScheme::BackwardEuler, false),
    ("Crank–Nicolson 法", ParabolicScheme::CrankNicolson, false),
    (
        "Rannacher 起動つき Crank–Nicolson 法",
        ParabolicScheme::CrankNicolson,
        true,
    ),
] {
    let mut options = ParabolicOptions::new().with_step(dt).with_scheme(scheme);
    if rannacher {
        options = options.with_rannacher_startup(startup);
    }
    let solution = problem
        .solve_with_options(&initial, &options)
        .map_err(|e| e.error().to_string())?;
    let u = solution.values();
    let error = u
        .iter()
        .zip(&exact)
        .map(|(a, b)| (a - b).abs())
        .fold(0.0_f64, f64::max);
    let (lo, hi) = range(u);
    rows.push((label, lo, hi, Some(error), flips(u)));
    series.push(serde_json::json!({ "name": label, "points": profile(u) }));
}
let (lo, hi) = range(&exact);
rows.push(("半離散系の厳密解", lo, hi, None, flips(&exact)));
series.push(serde_json::json!({
    "name": "半離散系の厳密解",
    "points": profile(&exact),
    "style": { "lineType": "dashed" }
}));
emit_line_chart!(
    &series,
    options = &serde_json::json!({
        "xLabel": "位置 x [cm]",
        "yLabel": "温度差 u [K]",
        "annotations": [
            { "kind": "range", "axis": "y", "from": 0.0, "to": 1.0, "label": "最大値原理の範囲" }
        ]
    })
);
let columns = serde_json::json!([
    { "key": "0", "label": "方式" },
    { "key": "1", "label": "最小値 [K]", "type": "number", "format": fixed4 },
    { "key": "2", "label": "最大値 [K]", "type": "number", "format": fixed4 },
    { "key": "3", "label": "半離散解との最大差 [K]", "type": "number", "format": sci3, "nullText": "（基準）" },
    { "key": "4", "label": "Δ²u の符号変化 [回]", "type": "integer" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "profiles" })
);
```

既定（$r=4$、起動 2 区間、時間区間 8）では、三方式とも値は $[0,1]$ K の範囲に収まり、この設定では最大値原理の違反は起こらなかった。
違いは半離散系の厳密解との差に現れる。
後退 Euler 法の差は $9.2\times10^{-3}$ K（時間 1 次の誤差）だった。
Crank–Nicolson 法の差は $2.2\times10^{-2}$ K で、二階差分の符号が 10 回変わる格子規模の振動が残った。
Rannacher 起動を付けると差は $8.7\times10^{-4}$ K に下がり、符号変化は半離散系の厳密解と同じ 2 回になった。
$r=8$ では Crank–Nicolson 法の差が $7.8\times10^{-2}$ K に増える。
$r=0.25$ では増幅率が負になるモードがないので、Crank–Nicolson 法の差は $3.7\times10^{-4}$ K で三方式のうち最小になる。
起動を 1 区間にすると、振動の一部が残る（符号変化 6 回）。
このとき差は $5.5\times10^{-4}$ K で 2 区間のときより小さく、最大の差と振動の有無は別々に確かめる必要がある。

この結果から、Crank–Nicolson 法の問題は値の範囲よりも、減衰しない高い波数の成分にあることが分かる。
Crank–Nicolson 法が離散的に最大値原理を保つ十分条件は $r\le1$ である（後退 Euler 法はどの $r$ でも保つ）。
$r>1$ では違反が起こりうるが、必ず起こるわけではなく、この設定では起こらなかった。
Rannacher 起動は先頭の区間だけを後退 Euler 法の半刻みに置き換え、段差に含まれる高い波数の成分を最初に減衰させる。
置き換えるのは決まった数の刻みだけなので、その後の Crank–Nicolson 法の 2 次の精度は損なわれない。

## まとめ

滑らかな初期値では、Crank–Nicolson 法の時間誤差は後退 Euler 法より 2 桁以上小さく、残る誤差は空間誤差である。
空間誤差と時間誤差は、半離散系の減衰率 $\mu_m$ を使えば閉形式で分けて測れる。
段差の初期値では、Crank–Nicolson 法は高い波数の成分を減衰させずに残し、半離散系の厳密解との差と格子規模の振動として現れる。
`ParabolicOptions::with_rannacher_startup` で起動の区間数を指定すると、この成分を最初の数区間で減衰させられる。
陰解法の因子分解の回数は `PdeDiagnostics::num_factorizations` で確かめられ、時刻に依存しない作用素では、最初の 1 回の後は刻み幅が変わるときだけ増える。
