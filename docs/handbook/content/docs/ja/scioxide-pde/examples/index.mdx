この節の例題は物理や工学の具体的な題材を微小な体積の保存則から方程式にし、`scioxide-pde` の Plan で解く。
どの例題も数値解とは独立な量で結果を確かめる。
独立な量には解析解、半離散系の閉じた形の解、保存量や不変量、格子の細分化による観測次数、別の離散化や別の方法との比較を使う。
代数方程式の残差や終了理由は、どの例題でも精度の根拠にしない。

## 例題の進め方

方程式の型によって、確かめる量が違う。
楕円型では格子の細分化による観測次数と境界の流束の収支、放物型では時間誤差の次数、最大原理、高い波数の成分の扱い、双曲型では位相の遅れ、離散エネルギー、衝撃波の位置と保存量の収支を見る。
空間の次数は刻みを小さく固定して格子だけを細かくし、時間の次数は格子を固定して刻みだけを変えて測る。
同じ問題を FDM・FEM・FVM で解いて比べるときは、未知数の位置が違うので、同じ評価点か流束のような位置に依らない量で比べる。

## まとめ

例題は題材ごとに解析解、半離散系の閉じた形の解、保存量や不変量、細分化、別の方法のどれかで数値結果を確かめる。
一覧の「独立な検算」の列から、自分の問題で使える確かめ方を選べる。
どの例題も一つの格子での小さな残差や `Completed` の終了理由を精度の根拠にしない。
