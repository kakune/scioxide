この例題は L 字の断面を持つ領域の静電ポテンシャルを解く。
L 字の内側の角（再入隅）では電界が発散し、解は滑らかでない。
一様に細かくしたメッシュでは、そのために誤差が自由度の数に対してゆっくりとしか減らない。
誤差推定子と Dörfler のマーキングで角の近くだけを細かくすると、滑らかな解と同じ率に戻ることを測って確かめる。
節点空間、推定子、マーキングの数理は[誤差推定に基づく適応細分化](../../algorithms/adaptive-mesh-refinement/)で説明している。

## 再入隅の特異性

長さの単位を $a=1\ \mathrm{m}$ とし、領域を正方形 $(-1,1)^2$ から第 4 象限の $[0,1)\times(-1,0]$ を除いた L 字形 $\Omega$ とする。
原点 $(0,0)$ が内角 $\omega=3\pi/2$ の再入隅である。
電荷のない領域の電位 $\varphi$ [V] は Laplace 方程式 $-\Delta\varphi=0$ を満たし、境界では次の電位を与える（$V_0=1\ \mathrm{V}$）。

$$
\varphi^*(r,\theta)=V_0\,r^{2/3}\sin\!\left(\frac{2\theta}{3}\right),\qquad 0\le\theta\le\frac{3\pi}{2}
$$

$(r,\theta)$ は原点を中心とする極座標で、偏角 $\theta$ は正の $x$ 軸から反時計回りに測る。
再入隅をはさむ 2 辺（$\theta=0$ と $\theta=3\pi/2$）では $\varphi^*=0$ である。

この関数は、変数分離 $r^\lambda\sin(\lambda\theta)$ のうち、2 辺で 0 になり $r\to0$ で有界なものの最低次である。
2 辺で 0 になる条件 $\sin(\lambda\omega)=0$ から $\lambda=\pi/\omega=2/3$ が決まる。
$\varphi^*$ は調和関数なので、これがこの境界値問題の厳密解になる。
勾配は

$$
\nabla\varphi^*=\frac{2V_0}{3}\,r^{-1/3}\bigl(-\sin(\theta/3),\ \cos(\theta/3)\bigr)
$$

で、電界 $E=-\nabla\varphi$ の大きさは再入隅で $r^{-1/3}$ のように発散する。
$\varphi^*$ は $H^1(\Omega)$ には入るが、$H^{1+s}$ には $s<2/3$ でしか入らない。

P1 有限要素の誤差はエネルギーノルム $\Vert\nabla(\varphi-\varphi_h)\Vert_{L^2(\Omega)}$ [V] で測る。
滑らかな解なら一様な細分の誤差は $O(h)$、自由度の数 $N\propto h^{-2}$ で書けば $O(N^{-1/2})$ になる。
この例題の解では正則性が $s=2/3$ までしかないので、一様な細分では $O(h^{2/3})=O(N^{-1/3})$ に落ちる。
角に向けて段階的に細かくしたメッシュでは、P1 の最適な率 $O(N^{-1/2})$ を回復できる（Babuška–Kellogg–Pitkäranta 1979）。
Dörfler のマーキングによる適応細分化がその率に達することは、最新頂点二分割について証明されている（Stevenson 2007）。
この例題の細分は宙づり節点を残す正則な 4 分割なので、率は測って確かめる。

## 境界積分によるエネルギー誤差

勾配が原点で発散するので、誤差 $\Vert\nabla(\varphi-\varphi_h)\Vert^2$ をセルごとの求積で計算すると、角のセルの求積の誤差が誤差そのものと同じ程度になりうる。
そこで、$\varphi$ が調和関数であることを使って体積積分を境界積分に直す。
$e=\varphi-\varphi_h$ を展開すると

$$
\Vert\nabla e\Vert^2=\Vert\nabla\varphi\Vert^2-2\int_\Omega\nabla\varphi\cdot\nabla\varphi_h+\Vert\nabla\varphi_h\Vert^2
$$

である。
$\Delta\varphi=0$ なので、Green の公式から $\int_\Omega\nabla\varphi\cdot\nabla v=\int_{\partial\Omega}v\,\partial_n\varphi\,ds$ が成り立つ。
ここで使う $v$ は $\varphi$ と $\varphi_h$ で、どちらも有界である。
原点の周りの半径 $\epsilon$ の円を除いて $\epsilon\to0$ とすると、円の上の寄与は $O(\epsilon^{2/3})$ で消えるので、特異点があってもこの式は使える。
再入隅をはさむ 2 辺では $\varphi=0$ で、$\varphi_h$ も節点の値 0 の一次補間なので 0 である。
残る外側の 4 辺は原点からの距離が 1 以上で、そこでは $\partial_n\varphi$ が滑らかである。
したがって、外側の辺を $\Gamma$ として

$$
\Vert\nabla e\Vert^2=\int_\Gamma(\varphi-2\varphi_h)\,\partial_n\varphi\,ds+\sum_K\vert\nabla\varphi_h\vert_K^2\,\vert K\vert
$$

となる。
P1 の $\nabla\varphi_h$ はセルごとに定数なので、最後の和は厳密に計算できる。
境界積分は境界の各面で 4 点の Gauss–Legendre 則を使う。
4 点の則は 7 次までの多項式を厳密に積分する。
外側の辺の上で $\partial_n\varphi$ は滑らかなので、$\int_\Gamma\varphi\,\partial_n\varphi\,ds$ の求積の誤差は、外側の辺を長さ 1 の面に分けたときに $2\times10^{-6}$、長さ 1/4 の面に分けたときに $5\times10^{-13}$ で、長さ 1/8 では丸めの程度になる。
長さ 1 の面を含む最初のメッシュでは誤差の二乗が $0.22$ なので、この程度の求積の誤差は表に出す 3 桁に影響しない。

Galerkin 直交性 $\int_\Omega\nabla e\cdot\nabla v_h=0$ は境界で 0 になる $v_h$ についてだけ成り立つ。
$\varphi_h$ は境界で 0 でないので、斉次 Dirichlet 条件の問題で使う $\Vert\nabla e\Vert^2=\Vert\nabla\varphi\Vert^2-\Vert\nabla\varphi_h\Vert^2$ はここでは使えず、上の式の交差項を計算する。

$\Vert\nabla\varphi\Vert^2$ は、極座標の積分と比べて独立に確かめる。
$\vert\nabla\varphi\vert^2=\tfrac49V_0^2r^{-2/3}$ を原点から境界までの距離 $R(\theta)=1/\max(\vert\cos\theta\vert,\vert\sin\theta\vert)$ まで積分すると

$$
\Vert\nabla\varphi\Vert^2=\frac{V_0^2}{3}\int_0^{3\pi/2}R(\theta)^{4/3}\,d\theta
$$

になる。
$R(\theta)$ は $\pi/4$ ごとの区間で滑らかなので、各区間の Gauss–Legendre 則で丸めの程度まで求まる。

## 計算の流れ

各周回は次の順に進む。

1. `AmrSpace::new(mesh, AmrOrder::P1)` で宙づり節点を拘束した P1 の空間を作る。
2. 外部の面すべてにラベル 0 を付け、`TaggedBoundaries::adaptive` で Dirichlet 条件 $\varphi=\varphi^*$ を結び付ける。
3. `AmrDiffusionPlan` を $k=1$、源項 0 で準備し、`assemble_csr` の行列を Jacobi 前処理付きの CG で解く（許容誤差は絶対・相対とも $10^{-12}$）。
4. 解を拘束で全節点へ延長し、`AmrEstimator` で $\eta_K$ を求める。
5. 上の境界積分でエネルギー誤差を求め、有効性指数 $\eta/\Vert\nabla e\Vert$ を記録する。
6. `AmrMarking::new(θ)` でマーカーを付け、`AdaptiveMesh::adapt` で細分した新しいメッシュ（revision）を作る。
7. 前の解を `AmrNodalTransfer::interpolate_into` で新しい空間へ移し、次の CG の初期値にする。

最初のメッシュは一辺 1 の正方形 3 枚をそれぞれ対角線で 2 つに分けた 6 個の三角形である。
自由度の数 $N$ は独立な節点の数（Dirichlet の節点を含む）とする。
定義のブロックには、メッシュ、厳密解、1 回の求解と誤差の計算を置く。

```rust
//| id: pde-lshape-model
//| kind: definitions
//| title: L 字領域、厳密解 r^(2/3) sin(2θ/3)、1 回の求解とエネルギー誤差
//| crates: [scioxide-core, scioxide-integrate, scioxide-linalg, scioxide-pde, scioxide-sparse, scioxide-spatial]
use scioxide_core::{
    Budget, ExecutionContext, SciOxideError, LinearOperator, NumericScalar, RealScalar,
    ResidualTolerance,
};
use scioxide_integrate::GaussianRulePlan;
use scioxide_linalg::{CgSolver, IterativeWorkspace, Preconditioning, Vector};
use scioxide_pde::{
    AmrBoundaryTags, AmrDiffusionData, AmrDiffusionPlan, AmrEstimator, AmrIndicators, AmrSpace,
    BoundaryCondition, BoundaryData, BoundaryPoint, TaggedBoundaries,
};
use scioxide_sparse::JacobiPreconditioner;
use scioxide_spatial::{AdaptationLimits, AdaptiveMesh, Cell, Field, Point, TriangleMesh};

/// 正の x 軸から反時計回りに測った偏角 θ ∈ [0, 2π)。
fn angle(p: [f64; 2]) -> f64 {
    let theta = RealScalar::atan2(p[1], p[0]);
    if theta < 0.0 {
        theta + 2.0 * core::f64::consts::PI
    } else {
        theta
    }
}

/// 厳密解 φ* = r^(2/3) sin(2θ/3) [V]（V₀ = 1 V、a = 1 m）。
pub(crate) fn potential(p: [f64; 2]) -> f64 {
    let r = RealScalar::hypot(p[0], p[1]);
    RealScalar::powf(r, 2.0 / 3.0) * RealScalar::sin(2.0 * angle(p) / 3.0)
}

/// ∇φ* = (2/3) r^(−1/3) (−sin(θ/3), cos(θ/3))（原点以外で使う）。
fn gradient(p: [f64; 2]) -> [f64; 2] {
    let scale = 2.0 / 3.0 * RealScalar::powf(RealScalar::hypot(p[0], p[1]), -1.0 / 3.0);
    let third = angle(p) / 3.0;
    [
        -scale * RealScalar::sin(third),
        scale * RealScalar::cos(third),
    ]
}

/// 一辺 1/m の正方形を対角線で分けた、L 字領域 (−1, 1)² ∖ [0, 1) × (−1, 0] の三角形メッシュ。
pub(crate) fn l_shape(m: usize) -> Result<AdaptiveMesh<f64, 2>, String> {
    let n = 2 * m;
    let inside = |i: usize, j: usize| i < m || j >= m;
    let mut index = vec![usize::MAX; (n + 1) * (n + 1)];
    let mut points = Vec::new();
    for j in 0..=n {
        for i in 0..=n {
            // 残す正方形のどれかの頂点だけを点にする。
            let used = (i.saturating_sub(1)..=i.min(n - 1))
                .any(|a| (j.saturating_sub(1)..=j.min(n - 1)).any(|b| inside(a, b)));
            if used {
                index[j * (n + 1) + i] = points.len();
                let p = [i as f64 / m as f64 - 1.0, j as f64 / m as f64 - 1.0];
                points.push(Point::new(p).map_err(|e| e.to_string())?);
            }
        }
    }
    let mut cells = Vec::new();
    for j in 0..n {
        for i in (0..n).filter(|&i| inside(i, j)) {
            let corner = |di: usize, dj: usize| index[(j + dj) * (n + 1) + i + di];
            cells.push([corner(0, 0), corner(1, 0), corner(1, 1)]);
            cells.push([corner(0, 0), corner(1, 1), corner(0, 1)]);
        }
    }
    let mesh = TriangleMesh::new(points, cells).map_err(|e| e.to_string())?;
    AdaptiveMesh::from_simplex(&mesh, AdaptationLimits::new()).map_err(|e| e.to_string())
}

/// 独立な検算：‖∇φ*‖² = (1/3) ∫₀^{3π/2} R(θ)^{4/3} dθ [V²]（R は原点から境界までの距離）。
/// R(θ) は π/4 ごとの区間で滑らかなので、各区間を 20 点の Gauss–Legendre 則で積分する。
pub(crate) fn polar_energy() -> Result<f64, String> {
    let rule = GaussianRulePlan::<f64>::gauss_legendre(20).map_err(|e| e.to_string())?;
    let quarter = core::f64::consts::FRAC_PI_4;
    let mut sum = 0.0;
    for piece in 0..6 {
        for (&t, &w) in rule.nodes().iter().zip(rule.weights()) {
            let theta = quarter * (piece as f64 + 0.5 * (t + 1.0));
            let (c, s) = (RealScalar::cos(theta), RealScalar::sin(theta));
            let distance = 1.0 / NumericScalar::abs(c).max(NumericScalar::abs(s));
            sum += 0.5 * quarter * w * RealScalar::powf(distance, 4.0 / 3.0) / 3.0;
        }
    }
    Ok(sum)
}

/// 電荷のない領域：源項 0。
struct Laplace;
impl AmrDiffusionData<f64, f64, 2> for Laplace {
    fn source(&self, _cell: usize, _point: [f64; 2]) -> Result<f64, SciOxideError> {
        Ok(0.0)
    }
}

/// 1 周回の記録。
#[derive(serde::Serialize, serde::Deserialize, Clone)]
pub(crate) struct Cycle {
    pub(crate) dofs: usize,
    pub(crate) cells: usize,
    pub(crate) error: f64,
    pub(crate) estimate: f64,
    pub(crate) exact_energy: f64,
    pub(crate) iterations: usize,
    pub(crate) status: String,
    pub(crate) converged: bool,
}

/// 適応細分化のセルが渡す値。
#[derive(serde::Deserialize)]
pub(crate) struct AdaptiveRun {
    pub(crate) adaptive: Vec<Cycle>,
    pub(crate) vertices: Vec<[f64; 2]>,
}

/// 一様細分化のセルが渡す値。
#[derive(serde::Deserialize)]
pub(crate) struct UniformRun {
    pub(crate) uniform: Vec<Cycle>,
}

/// 外側の辺の外向き単位法線。再入隅をはさむ 2 辺（φ = φ_h = 0）は None。
/// 頂点の座標は 2 進の分数なので、辺の上にあるかを等号で判定できる。
fn outer_normal(a: [f64; 2], b: [f64; 2]) -> Option<[f64; 2]> {
    for axis in 0..2 {
        for side in [-1.0, 1.0] {
            if a[axis] == side && b[axis] == side {
                let mut normal = [0.0; 2];
                normal[axis] = side;
                return Some(normal);
            }
        }
    }
    None
}

/// 空間 space で解き、記録、全節点の解、セルの指標を返す。guess は独立な節点の初期値。
pub(crate) fn solve(
    space: &AmrSpace<f64, 2>,
    guess: Vec<f64>,
) -> Result<(Cycle, Vec<f64>, AmrIndicators<f64, 2>), String> {
    let mesh = space.mesh();
    let exterior: Vec<(usize, u32)> = mesh
        .interfaces()
        .iter()
        .filter(|interface| interface.right.is_none())
        .map(|interface| (interface.left_face, 0))
        .collect();
    let tags = AmrBoundaryTags::new(mesh, &exterior).map_err(|e| e.to_string())?;
    let data = BoundaryData::time_invariant(|p: BoundaryPoint<f64, 2>| Ok(potential(p.point)));
    let conditions = vec![BoundaryCondition::dirichlet(0, data)];
    let boundaries =
        TaggedBoundaries::adaptive(mesh, &tags, 1, conditions).map_err(|e| e.to_string())?;
    let k = Field::<f64, Cell, 2>::new(mesh, vec![1.0; mesh.cell_count()])
        .map_err(|e| e.to_string())?;
    let plan =
        AmrDiffusionPlan::new(space, k.view(), &boundaries, &Laplace).map_err(|e| e.to_string())?;
    let matrix = plan.assemble_csr().map_err(|e| e.to_string())?;
    let jacobi = JacobiPreconditioner::new(&matrix).map_err(|e| e.to_string())?;
    let rhs = Vector::from_vec(plan.rhs().to_vec());
    let mut x = Vector::from_vec(guess);
    let tolerance = ResidualTolerance::new(1e-12, 1e-12).map_err(|e| e.to_string())?;
    let solver = CgSolver::new(
        tolerance,
        Budget::try_from(5000).map_err(|e| e.to_string())?,
    );
    let report = solver
        .solve_into(
            &matrix,
            &rhs,
            Preconditioning::Inverse(&jacobi),
            x.view_mut(),
            &mut IterativeWorkspace::new(),
            ExecutionContext::sequential(),
        )
        .map_err(|e| e.to_string())?;
    let mut full = vec![0.0; space.full_dofs()];
    let mut scratch = full.clone();
    space
        .constraints()
        .apply_into(x.as_slice(), &mut full, &mut scratch)
        .map_err(|e| e.to_string())?;
    let mut indicators = AmrIndicators::new(mesh).map_err(|e| e.to_string())?;
    {
        let residual = plan.residual(&full).map_err(|e| e.to_string())?;
        let estimator = AmrEstimator::new(space, k.view()).map_err(|e| e.to_string())?;
        let mut workspace = estimator.workspace().map_err(|e| e.to_string())?;
        estimator
            .estimate_into(
                &residual,
                &mut indicators,
                &mut workspace,
                ExecutionContext::sequential(),
            )
            .map_err(|e| e.to_string())?;
    }

    // ‖∇φ_h‖²：P1 の勾配はセルごとに定数なので、重心で評価して面積を掛ける。
    let mut discrete = 0.0;
    for cell in 0..mesh.cell_count() {
        let (_, g) = space
            .evaluate(cell, [1.0 / 3.0, 1.0 / 3.0], &full)
            .map_err(|e| e.to_string())?;
        discrete +=
            (g[0] * g[0] + g[1] * g[1]) * mesh.cell_measure(cell).map_err(|e| e.to_string())?;
    }
    // 外側の辺 Γ の上の ∫ φ ∂ₙφ と ∫ φ_h ∂ₙφ（各面で 4 点の Gauss–Legendre 則）。
    let rule = GaussianRulePlan::<f64>::gauss_legendre(4).map_err(|e| e.to_string())?;
    let (mut exact_energy, mut cross) = (0.0, 0.0);
    for interface in mesh.interfaces().iter().filter(|i| i.right.is_none()) {
        let ends: Vec<usize> = mesh
            .face_vertices(interface.piece_face)
            .map_err(|e| e.to_string())?
            .collect();
        let a = *mesh.point(ends[0]).map_err(|e| e.to_string())?.as_array();
        let b = *mesh.point(ends[1]).map_err(|e| e.to_string())?.as_array();
        let Some(normal) = outer_normal(a, b) else {
            continue;
        };
        let length = RealScalar::hypot(b[0] - a[0], b[1] - a[1]);
        for (&t, &w) in rule.nodes().iter().zip(rule.weights()) {
            let s = 0.5 * (t + 1.0);
            let p = [a[0] + s * (b[0] - a[0]), a[1] + s * (b[1] - a[1])];
            let g = gradient(p);
            let flux = g[0] * normal[0] + g[1] * normal[1];
            let discrete_value = full[ends[0]] + s * (full[ends[1]] - full[ends[0]]);
            exact_energy += 0.5 * w * length * potential(p) * flux;
            cross += 0.5 * w * length * discrete_value * flux;
        }
    }
    let squared_error = exact_energy - 2.0 * cross + discrete;
    let cycle = Cycle {
        dofs: space.independent_dofs(),
        cells: mesh.cell_count(),
        error: RealScalar::sqrt(squared_error.max(0.0)),
        estimate: indicators.global(),
        exact_energy,
        iterations: report.iterations(),
        status: format!("{:?}", report.termination()),
        converged: report.termination().is_success(),
    };
    Ok((cycle, full, indicators))
}
```

`solve` は、与えた空間で組立から推定子までを 1 回行い、周回の記録 `Cycle`、全節点の解、セルの指標を返す。
`Cycle` の `exact_energy` は境界積分で求めた $\Vert\nabla\varphi\Vert^2$ で、最後のセルで極座標の積分 `polar_energy` と比べる。
`outer_normal` は、境界の面が外側の 4 辺のどれに乗るかを頂点の座標で判定する。
頂点の座標は 2 進の分数なので、この判定は丸めの影響を受けない。

## 適応細分化の循環

次のセルは最初のメッシュから Dörfler のマーキングで細分を繰り返す。
入力は割合 $\theta$ と自由度の上限 $N_{\max}$ で、$N$ が $N_{\max}$ 以上になった周回で止める。
表は周回ごとの $N$、活性セルの数、エネルギー誤差、推定子 $\eta$、有効性指数、CG の反復回数と終了理由である。
最後に、すべての周回で CG が収束したかを判定として示す。
計算に時間がかかるので、ボタンで実行し、同じ入力の結果は再利用する。

```rust
//| cases:
//|   - {"id":"small-theta","label":"θ = 0.2","description":"一回に細かくするセルが減り、同じ自由度に達するまでの周回が 2 倍になる。","inputs":{"theta":0.2}}
//|   - {"id":"theta-one","label":"θ = 1","description":"すべてのセルにマーカーが付き、一様な細分と同じ列になる。","inputs":{"theta":1.0}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"cycles","path":"/rows/11/1","equals":1206}
//|       - {"artifact":"cycles","path":"/rows/11/3","approx":{"value":2.7627e-2,"rtol":1e-4}}
//|       - {"artifact":"cycles","path":"/rows/11/5","approx":{"value":3.980,"atol":5e-3}}
//|       - {"path":"/outputs/1/state","equals":"satisfied"}
//|   - case: small-theta
//|     expect:
//|       - {"artifact":"cycles","path":"/rows/1/1","equals":8}
//|       - {"artifact":"cycles","path":"/rows/23/1","equals":1005}
//|   - case: theta-one
//|     expect:
//|       - {"artifact":"cycles","path":"/rows/4/1","equals":833}
//|       - {"artifact":"cycles","path":"/rows/4/3","approx":{"value":7.9118e-2,"rtol":1e-4}}
use scioxide_core::ExecutionContext;
use scioxide_pde::{AmrMarking, AmrNodalTransfer, AmrOrder, AmrSpace};

let limit: usize = max_dofs.parse().map_err(|_| "自由度の上限が読めない")?;
let mut space = AmrSpace::new(&l_shape(1)?, AmrOrder::P1).map_err(|e| e.to_string())?;
let mut guess = vec![0.0; space.independent_dofs()];
let mut adaptive: Vec<Cycle> = Vec::new();
let mut marked = Vec::new();
loop {
    let (cycle, full, indicators) = solve(&space, guess)?;
    let stop = !cycle.converged || cycle.dofs >= limit;
    adaptive.push(cycle);
    if stop {
        marked.push(None);
        break;
    }
    let marks = AmrMarking::new(theta)
        .mark(space.mesh(), &indicators)
        .map_err(|e| e.to_string())?;
    marked.push(Some(marks.refine().len()));
    let next = space
        .mesh()
        .adapt(marks.request())
        .map_err(|e| e.to_string())?;
    let refined = AmrSpace::new(&next.mesh, AmrOrder::P1).map_err(|e| e.to_string())?;
    // 前の解を新しい空間へ補間し、独立な節点の値を次の CG の初期値にする。
    let mut moved = vec![0.0; refined.full_dofs()];
    {
        let transfer =
            AmrNodalTransfer::new(&space, &refined, &next.map).map_err(|e| e.to_string())?;
        let mut workspace = transfer.workspace::<f64>().map_err(|e| e.to_string())?;
        transfer
            .interpolate_into(
                &full,
                &mut moved,
                &mut workspace,
                ExecutionContext::sequential(),
            )
            .map_err(|e| e.to_string())?;
    }
    guess = refined
        .independent_nodes()
        .iter()
        .map(|&node| moved[node])
        .collect();
    space = refined;
}

let fixed2 = serde_json::json!({ "fractionDigits": 2 });
let columns = serde_json::json!([

    { "key": "7", "label": "CG の反復 [回]", "type": "integer" },
    { "key": "8", "label": "CG の終了理由" }
]);
let rows: Vec<_> = adaptive
    .iter()
    .zip(&marked)
    .enumerate()
    .map(|(i, (c, &m))| {
        let effectivity = c.estimate / c.error;
        (
            i,
            c.dofs,
            c.cells,
            c.error,
            c.estimate,
            effectivity,
            m,
            c.iterations,
            c.status.clone(),
        )
    })
    .collect();
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "cycles" })
);

let mesh = space.mesh();
let mut vertices = Vec::new();
for vertex in 0..mesh.vertex_count() {
    vertices.push(*mesh.point(vertex).map_err(|e| e.to_string())?.as_array());
}
export!(adaptive, &adaptive);
export!(vertices, &vertices);

let last = adaptive.last().ok_or("周回がない")?;
let outcome = if adaptive.iter().all(|c| c.converged) {
    Outcome::satisfied("すべての周回で CG が許容誤差に達した")
} else {
    Outcome::partial("CG が収束しなかった周回で循環を止めた")
        .explanation("最後の行の解は未収束で、誤差と推定子は推定値として扱う。")
};
emit_outcome!(
    outcome
        .status(last.status.clone())
        .diagnostic("周回の数", adaptive.len() as f64, None)
        .diagnostic("最後の自由度 N", last.dofs as f64, None)
        .diagnostic("最後のエネルギー誤差", last.error, Some("V"))
);
```

既定の $\theta=0.5$、$N_{\max}=1000$ では、12 回の周回で $N=1206$、活性セル 2532 個に達し、エネルギー誤差は $2.76\times10^{-2}$ V になる。
最初のメッシュ（$N=8$）の誤差 $0.466$ V から約 17 分の 1 になった。
どの周回でも CG は `Converged` で終わり、判定は satisfied である。
有効性指数は 2.47〜3.98 で、推定子は誤差の 2.5〜4 倍の値を取りながら、誤差とほぼ同じ割合で減っていく。

$\theta=0.2$ にすると、一回に細かくするセルが減り、$N\ge1000$ に達するまでの周回は 24 回に増える。
1 回目の細分では $N$ が 8 のまま変わらず、誤差も同じ値になる。
マーカーを付けたセルの 3 辺がすべて隣のセルと共有されていて、新しい辺の中点がすべて宙づり節点になり、P1 の空間が変わらないためである。
$\theta=1$ ではすべてのセルにマーカーが付き、$N=8,21,65,225,833,3201$ の列と誤差が次の一様細分の結果と一致する。

## 一様細分化との比較

次のセルは最初のメッシュの正方形の分割数を $m=1,2,4,\dots$ と倍にした一様なメッシュで同じ問題を解く。
入力は最も細かい分割数 $m_{\max}$ である。
一様なメッシュには宙づり節点がなく、推定子と誤差の計算は前のセルと同じ関数で行う。

```rust
//| ref: pde-lshape-uniform
//| title: 一様に細かくしたメッシュで同じ問題を解く
//| run: button
//| cache: inputs
//| uses: [pde-lshape-model]
```

## 収束率と有効性指数

次のセルは前の 2 つのセルの結果を受け取り、エネルギー誤差と推定子を $N$ に対して両対数で描く。
破線は傾き $-1/3$ と $-1/2$ の参照線で、それぞれ一様細分と適応細分の最後の点を通るように置く。
表は最後の 3 点に最小二乗で当てはめた傾き（観測した率）と、有効性指数の範囲である。
2 つ目の表は $\Vert\nabla\varphi\Vert^2$ の境界積分と極座標の積分の比較、図は最後の適応メッシュの頂点の配置である。

```rust
//| id: pde-lshape-rates
//| ref: pde-lshape-rates
//| title: 一様細分と適応細分の収束率、有効性指数、最後のメッシュ
//| run: reactive
//| uses: [pde-lshape-model]
//| crates: [scioxide-core, scioxide-integrate, scioxide-linalg, scioxide-pde, scioxide-sparse, scioxide-spatial]
//| dependsOn:
//|   adaptive_run: {cell: pde-lshape-adaptive, type: AdaptiveRun}
//|   uniform_run: {cell: pde-lshape-uniform, type: UniformRun}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"rates","path":"/rows/0/2","approx":{"value":-0.349,"atol":2e-3}}
//|       - {"artifact":"rates","path":"/rows/1/2","approx":{"value":-0.519,"atol":2e-3}}
//|       - {"artifact":"energy","path":"/rows/0/2","range":{"min":-1e-11,"max":1e-11}}
use scioxide_core::RealScalar;

// 最後の 3 点の (log N, log ‖∇e‖) に最小二乗で直線を当てはめた傾き（観測した率）。
let slope = |cycles: &[Cycle]| -> f64 {
    let tail = &cycles[cycles.len() - 3..];
    let xs: Vec<f64> = tail.iter().map(|c| RealScalar::ln(c.dofs as f64)).collect();
    let ys: Vec<f64> = tail.iter().map(|c| RealScalar::ln(c.error)).collect();
    let (mx, my) = (xs.iter().sum::<f64>() / 3.0, ys.iter().sum::<f64>() / 3.0);
    let sxy: f64 = xs.iter().zip(&ys).map(|(x, y)| (x - mx) * (y - my)).sum();
    let sxx: f64 = xs.iter().map(|x| (x - mx) * (x - mx)).sum();
    sxy / sxx
};
let points = |cycles: &[Cycle], estimate: bool| -> Vec<[f64; 2]> {
    let value = |c: &Cycle| if estimate { c.estimate } else { c.error };
    cycles.iter().map(|c| [c.dofs as f64, value(c)]).collect()
};
// 参照線 C N^p を、各系列の最後の点を通るように置く。
let reference = |cycles: &[Cycle], power: f64| -> Vec<[f64; 2]> {
    let last = &cycles[cycles.len() - 1];
    let scale = last.error / RealScalar::powf(last.dofs as f64, power);
    [8.0, 2.0e4]
        .iter()
        .map(|&n| [n, scale * RealScalar::powf(n, power)])
        .collect()
};
let (adaptive, uniform) = (&adaptive_run.adaptive, &uniform_run.uniform);

let adaptive_estimate = points(adaptive, true);
let (third, half) = (reference(uniform, -1.0 / 3.0), reference(adaptive, -0.5));
let circle = serde_json::json!({ "symbol": "circle" });
let diamond = serde_json::json!({ "symbol": "diamond" });
let hollow = serde_json::json!({ "symbol": "emptyCircle" });
let dashed = serde_json::json!({ "lineType": "dashed", "showSymbol": false });
let series = vec![
    serde_json::json!({ "name": "一様 ‖∇e‖", "points": uniform_error, "style": circle }),
    serde_json::json!({ "name": "適応 ‖∇e‖", "points": adaptive_error, "style": diamond }),
    serde_json::json!({ "name": "適応 η", "points": adaptive_estimate, "style": hollow }),
    serde_json::json!({ "name": "傾き −1/3", "points": third, "style": dashed }),
    serde_json::json!({ "name": "傾き −1/2", "points": half, "style": dashed }),
];
emit_line_chart!(

        "xLabel": "自由度 N [個]",
        "yLabel": "エネルギー誤差と推定子 [V]",
        "xType": "log",
        "yType": "log",

        "yMin": 5.0e-3,
        "yMax": 3.0
    })
);

    let ratios = cycles.iter().map(|c| c.estimate / c.error);
    let low = ratios.clone().fold(f64::INFINITY, f64::min);

let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
```

両対数の図では、一様細分の誤差（丸）は傾き $-1/3$ の破線に沿い、適応細分の誤差（菱形）は傾き $-1/2$ の破線に沿って下がる。
適応細分の推定子 $\eta$（白抜きの丸）は誤差の 2.5〜4 倍の高さを、誤差とほぼ平行に下がる。
最後の 3 点に当てはめた率は、一様細分で $-0.349$、適応細分で $-0.519$ で、理論の $-1/3$ と $-1/2$ に近い。
$\Vert\nabla\varphi\Vert^2$ の境界積分と極座標の積分はどちらも $1.8362266618752$ V² で、差は 0 だった。
この一致は、誤差の式の第 1 項と外向き法線の向きが正しいことの確認になる。
最後のメッシュの頂点の図では、頂点が原点の周りに集まり、原点から離れるほど疎になる。

$\varphi$ は外側の境界の近くでは滑らかで、一様なメッシュの誤差は再入隅の近くに集中する。
推定子は流束の跳びからこの分布を捉え、Dörfler のマーキングは誤差の大きい角のセルだけを細かくするので、同じ自由度で誤差が小さくなる。

## まとめ

再入隅を持つ領域では解の正則性が下がり、P1 の一様な細分の誤差は $N^{-1/3}$ でしか減らない。
残差型の推定子と Dörfler のマーキングで角の近くを細かくすると、この例題では率が $N^{-1/2}$ に戻り、$N\approx800$ で誤差が約 2.2 分の 1 になった。
推定子の値は誤差の 2.5〜4 倍で、誤差の上界ではないが、減り方は誤差とほぼ同じだった。
特異点のある問題では、セルごとの求積だと角のセルの誤差が大きくなりうるので、この例題のように調和性を使った境界積分などで特異点を避けて誤差を求める。
細分の循環、止める条件、前の解の転送は呼び出し側が組み立てるので、自分の問題でも同じ手順で使える。
