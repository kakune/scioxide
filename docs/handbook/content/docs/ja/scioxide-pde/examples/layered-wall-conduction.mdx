建物の断熱外壁、遮熱コーティング、電子基板の多層の放熱構造では、熱伝導率が層ごとに大きく変わる。
材料の界面では温度 $T(x)$ は連続だが、勾配 $dT/dx$ は折れ曲がる。
界面をまたいで連続なのは、熱流束 $q = -k\,dT/dx$ である。

このページでは二層の壁の定常熱伝導を対象に、直列熱抵抗の考え方で厳密解を導く。
有限差分法（FDM）、有限要素法（FEM）、有限体積法（FVM）が、界面で温度と流束をどう再現するかを確かめる。
さらに、界面が格子点と一致しない格子では、細分化しても誤差が単調に減らない理由を調べる。

## 直列熱抵抗と厳密解

厚さ $d = 0.2$ m の壁が、位置 $x = a d$（$0 < a < 1$）の界面で熱伝導率 $k_L$ の左層と $k_R$ の右層に分かれているとする。
左の表面 $x = 0$ を室内側の温度 $T_{\mathrm{hot}} = 20$ °C、右の表面 $x = d$ を屋外側の温度 $T_{\mathrm{cold}} = 0$ °C に保ち、内部の発熱はない。
左層は $k_L = 1$ W/(m·K) とし、右層の $k_R$ を入力で変える。

定常状態では $-d(k\,dT/dx)/dx = 0$ なので、熱流束 $q$ [W/m²] は壁全体で一定である。
各層の単位面積あたりの熱抵抗は $R_L = ad/k_L$、$R_R = (1 - a)d/k_R$ [m²·K/W] で、二層は直列につながるから

$$
q = \frac{T_{\mathrm{hot}} - T_{\mathrm{cold}}}{R_L + R_R},
\qquad
T_{\mathrm{int}} = T_{\mathrm{hot}} - q R_L
$$

である。
$T_{\mathrm{int}}$ は界面の温度である。
温度は各層の中で一次関数になり、界面で折れ曲がる。

$$
T(x) =
\begin{cases}
T_{\mathrm{hot}} - q x / k_L & (0 \le x \le ad) \\
T_{\mathrm{int}} - q (x - ad) / k_R & (ad < x \le d)
\end{cases}
$$

熱伝導率の小さい層（断熱層）では、同じ $q$ を流すのに大きな温度勾配が要るので、温度差の大半がその層にかかる。

## 三つの Plan と係数の標本化

三つの Plan は同じ材料の係数をそれぞれ別の位置で標本化する。

- `StructuredFdmPlan` の三点差分は隣り合う節点の間の面の中点で拡散係数を読む。
- `SimplexFemPlan` の P1 要素は要素内部の求積点で係数を読み、要素の剛性行列を積分する。
- `StructuredFvmPlan` のセル中心 FVM はセル中心の係数で二つの半セルの熱抵抗を作り、面の値を消去して直列にした二点流束を使う。
  界面が面に一致すれば、面の伝導率は二つの半セルの重み付き調和平均になる。

どの方法でも、要素（セル）の中で係数が一定なら、離散の解は「要素ごとに標本化した熱伝導率を持つ壁」の厳密な直列抵抗の解になる。
界面が格子点に一致すれば、標本化した壁は元の壁と同じなので、三つの方法とも厳密解を再現する。
界面が要素の内部にあると、その要素の熱伝導率が左右どちらかの値（または求積点の値の平均）に置き換わり、界面が見かけ上ずれる。

次の定義のブロックは材料 `Wall`（三つの係数のプロバイダーのトレイトを実装する）、直列抵抗の厳密解、三つの Plan を作る関数 `wall_plans` を持ち、このページの二つのセルが使う。
FEM の区間メッシュでは、左端の外部面にタグ 0、右端にタグ 1 を付けて、別々の Dirichlet 値を与える。

```rust
//| id: pde-layered-wall-model
//| kind: definitions
//| title: 二層壁の材料、直列抵抗の厳密解、三つの Plan
//| crates: [scioxide-core, scioxide-pde, scioxide-spatial]
use scioxide_core::SciOxideError;
use scioxide_pde::{
    BoundaryCondition, BoundaryData, FvmCoefficients, SimplexFemCoefficients, SimplexFemGeometry,
    SimplexFemOrder, SimplexFemPlan, StructuredBoundaries, StructuredFdmCoefficients,
    StructuredFdmPlan, StructuredFvmPlan, TaggedBoundaries,
};
use scioxide_spatial::{
    AxisSide, AxisTopology, BoundarySet, CoordinateAxis, Grid1d, IntervalMesh, Point, SegmentMesh,
    SimplexBoundaryTags,
};

/// 壁の厚さ d [m]、室内側と屋外側の表面温度 [°C]、左層の熱伝導率 k_L [W/(m·K)]。
pub(crate) const THICKNESS: f64 = 0.2;
pub(crate) const HOT: f64 = 20.0;
pub(crate) const COLD: f64 = 0.0;
pub(crate) const LEFT: f64 = 1.0;

/// 界面 x = interface [m] の左が k_L、右が k_R の二層壁。
pub(crate) struct Wall {
    pub(crate) interface: f64,
    pub(crate) right: f64,
}
impl Wall {
    /// 位置 x [m] の熱伝導率。界面上の点は右層に入れる。
    pub(crate) fn conductivity(&self, x: f64) -> f64 {
        if x < self.interface { LEFT } else { self.right }
    }
    /// 直列抵抗による一定の熱流束 q [W/m²]。
    pub(crate) fn flux(&self) -> f64 {
        let resistance = self.interface / LEFT + (THICKNESS - self.interface) / self.right;
        (HOT - COLD) / resistance
    }
    /// 区分一次の厳密な温度 [°C]。
    pub(crate) fn temperature(&self, x: f64) -> f64 {
        let q = self.flux();
        if x <= self.interface {
            HOT - q * x / LEFT
        } else {
            HOT - q * self.interface / LEFT - q * (x - self.interface) / self.right
        }
    }
}
impl StructuredFdmCoefficients<f64, f64, 1> for Wall {
    fn diffusion(&self, _: usize, _: usize, x: [f64; 1]) -> Result<f64, SciOxideError> {
        Ok(self.conductivity(x[0]))
    }
}
impl FvmCoefficients<f64, f64, 1> for Wall {
    fn diffusion(&self, x: [f64; 1]) -> Result<[[f64; 1]; 1], SciOxideError> {
        Ok([[self.conductivity(x[0])]])
    }
}
impl SimplexFemCoefficients<f64, f64, 1> for Wall {
    fn evaluate(&self, x: [f64; 1], k: &mut [f64], c: &mut [f64]) -> Result<(), SciOxideError> {
        (k[0], c[0]) = (self.conductivity(x[0]), 0.0);
        Ok(())
    }
}

/// 同じ N 個の節点の上の FDM、FVM（N − 1 個のセル）、P1 の FEM。
pub(crate) struct WallPlans {
    pub(crate) fdm: StructuredFdmPlan<f64, f64, 1>,
    pub(crate) fvm: StructuredFvmPlan<f64, f64, 1>,
    pub(crate) fem: SimplexFemPlan<f64, f64, 1>,
}
pub(crate) fn wall_plans(wall: &Wall, nodes: usize) -> Result<WallPlans, String> {
    let axis = CoordinateAxis::uniform(0.0, THICKNESS, nodes).map_err(|e| e.to_string())?;
    let grid = Grid1d::new([axis], [AxisTopology::Bounded]).map_err(|e| e.to_string())?;
    let segment = SegmentMesh::new(grid).map_err(|e| e.to_string())?;
    let mut sides = Vec::new();
    for (side, value) in [(AxisSide::Start, HOT), (AxisSide::End, COLD)] {
        let set = BoundarySet::axis_side(&segment, 0, side).map_err(|e| e.to_string())?;
        sides.push(BoundaryCondition::dirichlet(
            set,
            BoundaryData::constant(value),
        ));
    }
    let ends = StructuredBoundaries::new(&segment, 1, sides).map_err(|e| e.to_string())?;
    let h = THICKNESS / (nodes - 1) as f64;
    let points = (0..nodes)
        .map(|i| Point::new([i as f64 * h]))
        .collect::<Result<Vec<_>, _>>()
        .map_err(|e| e.to_string())?;
    let cells = (0..nodes - 1).map(|i| [i, i + 1]).collect();
    let interval = IntervalMesh::new(points, cells).map_err(|e| e.to_string())?;
    // x = 0 の端点にタグ 0、x = d の端点にタグ 1 を付ける。
    let mut faces = Vec::new();
    for face in interval.boundary_faces() {
        let vertex = interval.face_vertices(face).map_err(|e| e.to_string())?[0];
        faces.push((face, u32::from(vertex != 0)));
    }
    let tags = SimplexBoundaryTags::new(&interval, faces).map_err(|e| e.to_string())?;
    let conditions = vec![
        BoundaryCondition::dirichlet(0, BoundaryData::constant(HOT)),
        BoundaryCondition::dirichlet(1, BoundaryData::constant(COLD)),
    ];
    let tagged =
        TaggedBoundaries::new(&interval, &tags, 1, conditions).map_err(|e| e.to_string())?;
    let (affine, p1) = (SimplexFemGeometry::Affine, SimplexFemOrder::P1);
    Ok(WallPlans {
        fdm: StructuredFdmPlan::new(segment.clone(), wall, &ends).map_err(|e| e.to_string())?,
        fvm: StructuredFvmPlan::new(segment, wall, &ends).map_err(|e| e.to_string())?,
        fem: SimplexFemPlan::new(interval, affine, p1, wall, &tagged).map_err(|e| e.to_string())?,
    })
}
```

## 界面に合わせた格子での三つの方法

界面 $x = ad$ が格子点に一致する格子（適合格子）を考える。
次のセルは界面の位置 $a$、伝導率の比 $\log_{10}(k_R/k_L)$、格子点数 $N$ を入力に、三つの Plan を `EllipticProblem` で解く。
FVM の面流束は `face_fluxes::<0>(values, time)` ですべての面について再構成する。
符号は座標の増える向きで、ここでは室内から屋外へ流れる熱が正になる。
FDM と FEM の流束は、左層で最も左にある区間の差分 $-k_L(u_1 - u_0)/h$ から求める。

出力は温度分布の図、方法ごとの終了理由・温度の最大誤差・界面の温度の誤差・流束の相対誤差の表、厳密な $q$ と $T_{\mathrm{int}}$ の表、三つの解の結論である。
FVM の未知数はセル中心の値で、界面の上にないので、界面の温度の誤差は定義しない。

既定（$a = 0.5$、$k_R/k_L = 0.1$、41 点）では、厳密な流束は $q = 18.1818$ W/m²、界面の温度は 18.1818 °C である。
三つの方法とも `Completed` で、温度の最大誤差と流束の相対誤差は $3 \times 10^{-13}$ 以下になり、厳密解と丸めの範囲で一致した。
厳密解は各層で一次関数なので、界面を節点に置けば、三点差分・P1 要素・二点流束はどれも打ち切り誤差を持たない。
FVM の 41 個の面の流束がすべて一定値 $q$ になるのは、セル中心の係数から半セルの直列抵抗を作ったからである。
係数はセルの材料の値をそのまま返せばよく、調和平均を自分で計算して渡す必要はない。
伝導率の比を $10^{\pm 2}$ に変えても、流束の相対誤差は $2 \times 10^{-12}$ 以下にとどまる。

## 界面に合わない格子と誤差の揺れ

界面 $x = ad$ が格子点と一致しない格子（非適合格子）では、格子点数 $N$ を増やしても誤差が単調に減るとは限らない。
界面に最も近い格子点までの距離（格子幅を単位とするずれ）が、$N$ によって 0 に近い値と 0.5 に近い値を行き来するからである。

前の節の見方を当てはめると、FDM の誤差は予測できる。
三点差分は面の中点で係数を読むので、界面を含む区間の熱伝導率は中点がある側の材料の値になる。
これは、界面を最も近い節点 $a_{\mathrm{eff}}d$ へ移した壁と同じ離散方程式である。
その壁は界面に合った格子を持つので、FDM はその壁の厳密解を節点で再現する。
したがって FDM の節点の誤差は、界面を移した壁と元の壁の厳密な温度の差に等しく、直列抵抗の式だけで計算できる。

P1 の FEM は区間の 2 点 Gauss–Legendre 則（点は要素の両端から $0.211h$）で係数を読む。
界面と最も近い節点の距離が $0.211h$ より小さければ、二つの求積点は同じ材料にあり、FEM は FDM と同じ壁を解く。
界面が二つの求積点の間にあれば、要素の熱伝導率は $(k_L + k_R)/2$ の算術平均になり、FDM とは別の壁を解く。
FVM は界面を含むセルの中心で係数を読むので、そのセルは中心のある側の材料になり、界面は最も近い面へ移る。
セルの面は節点と同じ位置にあるので、FVM は FDM と同じ界面を移した壁を解き、その厳密な温度をセル中心で再現する。
FVM の誤差は二つの壁の温度の差をセル中心で測った値になり、FDM の誤差とは測る位置だけが違う。

次のセルは界面の位置 $a = 0.37$ を既定とし、$N = 17$ から 81 まで 4 点ずつ増やして三つの方法を解く。
入力は界面の位置 $a$ と伝導率の比である。
出力は格子点数に対する温度の最大誤差の図、格子ごとのずれと誤差の表、細分化で誤差が増えた回数の表である。
表の「界面を移した壁の差」は上の FDM の予測を直列抵抗の式で計算した独立な検算で、FDM の誤差と一致するかを確かめる。
三つの Plan は `SpatialDiscretization` を共有するので、一つの関数 `max_error` で解き、`dof_point` の位置で厳密解と比べる。

```rust
//| id: pde-layered-wall-alignment
//| ref: pde-layered-wall-alignment
//| title: 界面に合わない格子を細分化し、誤差の揺れを見る
//| run: reactive
//| uses: [pde-layered-wall-model]
//| crates: [scioxide-core, scioxide-pde, scioxide-spatial]
//| inputs:
//|   wall_unfitted_interface: {"type":"range","label":"左層の割合 a [-]","description":"界面が各格子のどこを横切るかを変える。","min":0.28,"max":0.72,"step":0.01,"value":0.37}
//|   wall_unfitted_log10_contrast: {"type":"range","label":"log₁₀(k_R/k_L) [-]","description":"界面の見かけのずれが温度に与える影響の大きさを変える。","min":-2,"max":2,"step":0.25,"value":-1}
//| cases:
//|   - {"id":"near-quarter","label":"a = 0.28","description":"ずれの並びが変わり、誤差が増えた回数は FDM 7、FEM 5、FVM 7 になる。","inputs":{"wall_unfitted_interface":0.28}}
//|   - {"id":"conductive-right","label":"k_R/k_L = 100","description":"右層が良導体でも誤差は格子ごとに揺れ、増えた回数は FDM 8、FEM 9、FVM 8 になる。","inputs":{"wall_unfitted_log10_contrast":2}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"grids","path":"/rows/0/2","approx":{"value":0.12729484,"rtol":1e-6}}
//|       - {"artifact":"grids","path":"/rows/0/3","approx":{"value":0.12729484,"rtol":1e-6}}
//|       - {"artifact":"grids","path":"/rows/1/4","approx":{"value":0.63990588,"rtol":1e-6}}
//|       - {"artifact":"increases","path":"/rows/0/1","equals":8}
//|       - {"artifact":"increases","path":"/rows/1/1","equals":8}
//|       - {"artifact":"increases","path":"/rows/2/1","equals":8}
//|   - case: near-quarter
//|     expect:
//|       - {"artifact":"increases","path":"/rows/1/1","equals":5}
//|   - case: conductive-right
//|     expect:
//|       - {"artifact":"increases","path":"/rows/1/1","equals":9}
use scioxide_pde::{EllipticOptions, EllipticProblem, FieldData, SpatialDiscretization};

let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let fixed2 = serde_json::json!({ "fractionDigits": 2 });
let a = wall_unfitted_interface;
let wall = Wall {
    interface: a * THICKNESS,
    right: LEFT * 10f64.powf(wall_unfitted_log10_contrast),
};
// 解いて、未知数の位置（節点またはセル中心）で厳密解との最大誤差 [K] を返す。
fn max_error<P: SpatialDiscretization<f64, f64, 1>>(
    plan: &P,
    wall: &Wall,
) -> Result<f64, String> {
    let source = FieldData::zero();
    let solution = EllipticProblem::new(plan, &source)
        .solve_with_options(&EllipticOptions::new())
        .map_err(|e| e.to_string())?;
    if !solution.report().is_success() {
        return Err(format!("未完了 {}", solution.report().termination()));
    }
    let mut error = 0.0_f64;
    for (unknown, u) in solution.values().iter().enumerate() {
        let x = plan.dof_point(unknown).map_err(|e| e.to_string())?.point[0];
        error = error.max((u - wall.temperature(x)).abs());
    }
    Ok(error)
}
let mut curves = [Vec::new(), Vec::new(), Vec::new()];
let mut rows = Vec::new();
for nodes in (17..=81).step_by(4) {
    let plans = wall_plans(&wall, nodes)?;
    let errors = [
        max_error(&plans.fdm, &wall).map_err(|e| format!("FDM N={nodes}: {e}"))?,
        max_error(&plans.fem, &wall).map_err(|e| format!("FEM N={nodes}: {e}"))?,
        max_error(&plans.fvm, &wall).map_err(|e| format!("FVM N={nodes}: {e}"))?,
    ];
    // FDM の予測（独立な検算）: 面の中点で係数を読むので、界面は最も近い節点へ移る。
    // 移した壁と元の壁の厳密な温度の差の最大を、直列抵抗の式で求める。
    let h = THICKNESS / (nodes - 1) as f64;
    let shifted = Wall {
        interface: (wall.interface / h).round() * h,
        right: wall.right,
    };
    let predicted = (0..nodes)
        .map(|i| (shifted.temperature(i as f64 * h) - wall.temperature(i as f64 * h)).abs())
        .fold(0.0, f64::max);
    // 界面から最も近い節点までの距離を格子幅で割った値（0 なら適合、0.5 なら区間の中央）。
    let offset = (wall.interface / h - (wall.interface / h).round()).abs();
    rows.push((nodes, offset, errors[0], predicted, errors[1], errors[2]));
    for (curve, e) in curves.iter_mut().zip(errors) {
        curve.push([nodes as f64, e]);
    }
}
// 格子を細かくしたのに誤差が増えた回数を数える。
let mut increases = Vec::new();
let mut series = Vec::new();
for (name, curve) in ["FDM", "FEM", "FVM"].into_iter().zip(&curves) {
    increases.push((name, curve.windows(2).filter(|p| p[1][1] > p[0][1]).count()));
    series.push(
        serde_json::json!({ "name": name, "style": { "symbol": "circle" }, "points": curve }),
    );
}
emit_line_chart!(
    &series,
    options = &serde_json::json!({
        "xLabel": "格子点数 N [点]",
        "yLabel": "温度の最大誤差 [K]",
        "xType": "log",
        "yType": "log"
    })
);
let columns = serde_json::json!([
    { "key": "0", "label": "格子点数 N [点]", "type": "integer" },
    { "key": "1", "label": "界面のずれ [格子幅]", "type": "number", "format": fixed2 },
    { "key": "2", "label": "FDM の誤差 [K]", "type": "number", "format": sci3 },
    { "key": "3", "label": "界面を移した壁の差 [K]", "type": "number", "format": sci3 },
    { "key": "4", "label": "FEM の誤差 [K]", "type": "number", "format": sci3 },
    { "key": "5", "label": "FVM の誤差 [K]", "type": "number", "format": sci3 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "grids" })
);
let count_columns = serde_json::json!([
    { "key": "0", "label": "方法" },
    { "key": "1", "label": "細分化で誤差が増えた回数（16 回中） [回]", "type": "integer" }
]);
emit_table_with_columns!(
    count_columns,
    increases,
    metadata = serde_json::json!({ "id": "increases" })
);
```

既定では、16 回の細分化のうち三つの方法とも 8 回で誤差が増えた。
表の FDM の誤差と「界面を移した壁の差」は、すべての格子で $10^{-12}$ K 以下の差で一致し、FDM の誤差が界面の見かけのずれだけで決まることを確かめられる。
FDM の誤差は $N = 17, 25, \dots, 81$ の 9 個の格子で 0.127 K のまま変わらない。
これらの格子は $h = d/(8j)$ の形で、界面 $0.37d$ に最も近い節点がどれも $0.375d$ になり、同じ壁を解くからである。
ずれが 0.40 の $N = 21$ では、FDM の誤差は 0.47 K に増える。

FEM の誤差は、ずれが 0.20 以下の格子で FDM と一致し、0.24 以上の格子で FDM と離れる。
$N = 21$ では、算術平均の熱伝導率を持つ要素が界面の抵抗を小さく見積もり、FEM の誤差は 0.64 K と三つの中で最大になる。
$N = 49, 57, \dots$ のように、ずれが 0.24〜0.40 でも FEM の誤差が FDM より小さい格子もある。
誤差の大小はずれと求積点の位置の組み合わせで決まり、細分化だけでは一様な次数で減らない。

多層材料で格子収束の次数を測るには、界面を格子点に置く適合格子を使う。
構造格子では `CoordinateAxis::explicit` の非一様な座標で `SegmentMesh` を作り、単体メッシュでは同じ頂点の `IntervalMesh` を作る。
界面を横切る要素に特別な形状関数を入れて流束の連続条件を組み込む定式化（拡張有限要素法など）は、`scioxide-pde` は提供しない。

## まとめ

界面を格子点に合わせると、二層の壁の区分一次の解は三つの方法とも丸めの範囲で再現され、FVM の面流束は直列抵抗の一定値と一致する。
FVM にはセルの材料の係数をそのまま渡せば、面に合った半セルの直列抵抗が使われる。
界面が格子に合わないと、各方法は係数を標本化する位置で界面を見かけ上ずらした壁を解き、細分化しても誤差はずれに応じて揺れる。
FDM の誤差は界面を最も近い節点へ移した壁との差として直列抵抗の式で予測できる。
物性が不連続な問題では、まず適合格子を作り、流束や界面の温度のような位置に依らない量で方法を比べる。
