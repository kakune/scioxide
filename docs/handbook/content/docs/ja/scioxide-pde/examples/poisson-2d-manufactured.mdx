繊維強化複合材の層のように、熱伝導率が方向で異なる材料では、定常温度は異方性の Poisson 方程式に従う。
この例題では単位正方形の板に製造解（先に解を決め、方程式から源項と境界データを逆算した解）を与え、`StructuredFdmPlan` が組み立てる CSR 行列と荷重を scioxide-linalg の CG で解く。
頂点数 $n=9,17,33$ の格子で最大誤差と $L^2$ 誤差を測り、観測次数が 2 になることを確かめる。
最後に、すべての辺を断熱にした板で発熱の総和が 0 でない荷重を与え、解が存在しないことを `EllipticProblem` がエラーで知らせる経路を見る。

2 次元の Poisson 方程式はほかの章でも扱う。
疎行列の並べ替えとフィルは [scioxide-sparse の例題](../../../scioxide-sparse/examples/poisson-reordering-fill/)、周期境界のスペクトル法は [scioxide-fft の例題](../../../scioxide-fft/examples/spectral-poisson/)にある。
このページは差分の収束次数と境界条件の扱いに絞る。

## 異方性の熱伝導と製造解

座標は板の一辺の長さ $L$ で、熱伝導率は $x$ 方向の熱伝導率 $k_x$ で割り、無次元の量で書く。
熱伝導率テンソルは $K=\mathrm{diag}(1,\kappa)$ で、$\kappa=k_y/k_x$ は異方性の比である。
体積発熱を $f$ とすると、定常温度 $u$ は次の境界値問題に従う。

$$
-\nabla\cdot(K\nabla u)=-\frac{\partial^2u}{\partial x^2}-\kappa\frac{\partial^2u}{\partial y^2}=f\quad\text{in }\Omega=(0,1)^2
$$

製造解を $u_*(x,y)=\sin(m_x\pi x)\sin(m_y\pi y)$ に選ぶ。
$m_x$、$m_y$ は各方向の半波長の数である。
これを方程式に代入すると、源項は次のとおりである。

$$
f(x,y)=\pi^2\left(m_x^2+\kappa m_y^2\right)u_*(x,y)
$$

境界条件は二通りを比べる。
一つは 4 辺すべてで $u=0$ とする Dirichlet 条件で、$u_*$ は境界で 0 なのでそのまま満たす。
もう一つは $x=1$ と $y=1$ の 2 辺を余法線流束の条件 $\boldsymbol n\cdot K\nabla u=g$ に替える混合境界である。
$\boldsymbol n$ は外向きの単位法線で、データは $g=\boldsymbol n\cdot K\nabla u_*$ を $u_*$ から計算する。
たとえば $x=1$ の辺では $g=m_x\pi\cos(m_x\pi)\sin(m_y\pi y)$ になる。
`BoundaryCondition::natural` はこの $g$ を受け取り、`BoundaryCondition::dirichlet` は $u$ の値を受け取る。

## 差分の行列と離散固有値

`StructuredFdmPlan` は頂点中心の保存形差分で、頂点 $i$ の周りの双対セル（隣の頂点との中点で囲んだ長方形）で熱の収支を取る。
隣り合う頂点の間の面ごとに、面の中心で標本化した熱伝導率 $k$ からコンダクタンス $k\cdot(\text{面の長さ})/h$ を作り、行列に加える。
源項は双対セルの面積 $|V_i|$ を掛けて荷重 $b_i=|V_i|f(\boldsymbol x_i)$ になる。
流束の条件の辺では、境界の各頂点が、接する境界の辺の長さの半分ずつを重みにして $g$ を荷重に加える。
格子幅を $h_x=h_y=h$ とすると、内部の頂点の行は 5 点の中心差分を $h^2$ 倍したものになる。

$$
\left(2u_{i,j}-u_{i-1,j}-u_{i+1,j}\right)+\kappa\left(2u_{i,j}-u_{i,j-1}-u_{i,j+1}\right)=h^2f_{i,j}
$$

Dirichlet 条件の頂点は対称に消去され、行列には対角 1 の行として残る。
移流と反応がないので行列は対称で、Dirichlet 条件の辺が 1 本以上あれば正定値になり、CG（共役勾配法）で解ける。
未知数は $x$ 方向が最も速く変わる頂点の順に並ぶ。
内部の打切り誤差は $O(h^2)$ なので、最大誤差も $L^2$ 誤差も $O(h^2)$ で減ると期待する。

全辺 Dirichlet の場合は、誤差を前もって計算できる。
格子点で標本化した $\sin(m_x\pi x_i)\sin(m_y\pi y_j)$ は上の離散作用素の固有ベクトルで、$h^2$ で割った固有値は次のとおりである。

$$
\lambda_h=\frac{4}{h^2}\left[\sin^2\frac{m_x\pi h}{2}+\kappa\sin^2\frac{m_y\pi h}{2}\right]
$$

荷重はこの固有ベクトルの $\pi^2(m_x^2+\kappa m_y^2)h^2$ 倍なので、離散解は $u_*$ の格子点の値を $\rho=\pi^2(m_x^2+\kappa m_y^2)/\lambda_h$ 倍したものになる。
したがって最大誤差は $|\rho-1|\max_{i,j}|u_*(\boldsymbol x_{i,j})|$ に等しい。
$\sin z\approx z-z^3/6$ から $\rho-1=O(h^2)$ も読み取れる。
荷重が固有ベクトルなので、CG は 1 回の反復で離散方程式の解に達する。
これは試験問題の性質で、CG の一般的な反復回数を表さない。
混合境界では境界の頂点の行が変わり、荷重は固有ベクトルでなくなる。

二つのセルは同じ係数、格子の組立てと誤差の計算を次の定義から使う。

```rust
//| id: pde-anisotropic-plate-model
//| kind: definitions
//| title: 異方性の板の係数、差分の Plan と頂点の誤差
//| crates: [scioxide-core, scioxide-pde, scioxide-spatial]
use scioxide_core::SciOxideError;
use scioxide_pde::{
    BoundaryCondition, BoundaryData, StructuredBoundaries, StructuredFdmCoefficients,
    StructuredFdmPlan,
};
use scioxide_spatial::{AxisSide, AxisTopology, BoundarySet, CoordinateAxis, Grid2d, QuadMesh};

/// 熱伝導率テンソル K = diag(1, κ)（x 方向の値 k_x で無次元化）。
pub(crate) struct Plate {
    pub(crate) kappa: f64,
}

impl StructuredFdmCoefficients<f64, f64, 2> for Plate {
    // 軸 axis に垂直な面の中心での熱伝導率。
    fn diffusion(&self, axis: usize, _: usize, _: [f64; 2]) -> Result<f64, SciOxideError> {
        Ok(if axis == 0 { 1.0 } else { self.kappa })
    }
}

/// 一辺 n 頂点の単位正方形の差分の Plan。
/// natural[軸][0: 始点側, 1: 終点側] が真の辺は n·K∇u = flux、偽の辺は u = 0。
pub(crate) fn plate_plan(
    n: usize,
    kappa: f64,
    natural: [[bool; 2]; 2],
    flux: &BoundaryData<f64, f64, 2>,
) -> Result<StructuredFdmPlan<f64, f64, 2>, SciOxideError> {
    let axes = [
        CoordinateAxis::uniform(0.0, 1.0, n)?,
        CoordinateAxis::uniform(0.0, 1.0, n)?,
    ];
    let mesh = QuadMesh::new(Grid2d::new(axes, [AxisTopology::Bounded; 2])?)?;
    let mut conditions = Vec::new();
    for (axis, sides) in natural.iter().enumerate() {
        for (side, &is_natural) in [AxisSide::Start, AxisSide::End].into_iter().zip(sides) {
            let region = BoundarySet::axis_side(&mesh, axis, side)?;
            conditions.push(if is_natural {
                BoundaryCondition::natural(region, flux.clone())
            } else {
                BoundaryCondition::dirichlet(region, BoundaryData::zero())
            });
        }
    }
    let boundaries = StructuredBoundaries::new(&mesh, 1, conditions)?;
    StructuredFdmPlan::new(mesh, &Plate { kappa }, &boundaries)
}

/// 頂点ごとの誤差 [x, y, u_h − u*]、最大誤差、双対セルの面積で重みを付けた離散 L² 誤差。
pub(crate) struct NodalErrors {
    pub(crate) field: Vec<[f64; 3]>,
    pub(crate) max: f64,
    pub(crate) l2: f64,
}

/// 未知数の順（x が最も速く変わる頂点の順）に並んだ values を製造解 exact と比べる。
pub(crate) fn nodal_errors(
    plan: &StructuredFdmPlan<f64, f64, 2>,
    values: &[f64],
    exact: impl Fn([f64; 2]) -> f64,
) -> Result<NodalErrors, SciOxideError> {
    let mut errors = NodalErrors {
        field: Vec::with_capacity(values.len()),
        max: 0.0,
        l2: 0.0,
    };
    for (node, (&u, &area)) in values.iter().zip(plan.volumes()).enumerate() {
        let [x, y] = plan.node_point(node)?;
        let error = u - exact([x, y]);
        errors.field.push([x, y, error]);
        errors.max = errors.max.max(error.abs());
        errors.l2 += area * error * error;
    }
    errors.l2 = errors.l2.sqrt();
    Ok(errors)
}
```

## 格子の細分化と観測次数

次のセルは異方性の比 $\kappa$、半波長の数 $m_x$、$m_y$、境界条件を選び、$n=9,17,33$ の格子で Plan を作る。
`SpatialDiscretization::assemble_csr` が消去済みの行列を CSR 形式で、`load` が荷重ベクトル $b$ を返す。
`StructuredFdmPlan::volumes` は双対セルの面積を、`node_point` は頂点の座標を、どちらも未知数と同じ順に返す。
これを `CgSolver`（相対残差 $10^{-12}$、反復の上限は未知数の 4 倍）で解き、頂点での最大誤差と、双対セルの面積 $|V_i|$ を重みにした離散 $L^2$ 誤差 $\bigl(\sum_i|V_i|e_i^2\bigr)^{1/2}$ を測る。
同じ CG は `EllipticWorkspace::with_linear_solver` で `EllipticProblem` に渡すこともでき、その場合は終了理由と反復回数が `PdeSolveReport` に入る。
このセルは行列と荷重を直接使う経路を示す。
観測次数は隣り合う二つの格子の誤差 $e_1$、$e_2$ と格子幅 $h_1$、$h_2$ から $p=\log(e_1/e_2)/\log(h_1/h_2)$ で求める。
全辺 Dirichlet の場合は、離散固有値から予測した最大誤差も並べる。
最後に、三つの格子の CG の終了理由（`LinearSolveTermination`）がすべて `is_success()` を満たしたかを判定する。
誤差の値と、最も細かい格子での誤差の分布は、次のセルに渡す。

//|       - {"artifact":"orders","path":"/rows/2/3","equals":null}

use scioxide_core::{Budget, ResidualTolerance};
use scioxide_linalg::{CgSolver, Preconditioning, Vector};
use scioxide_pde::{BoundaryData, BoundaryPoint, FieldData, FieldPoint, SpatialDiscretization};
use std::f64::consts::PI;

let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let fixed2 = serde_json::json!({ "fractionDigits": 2 });
let (kappa, wx, wy) = (plate_kappa, plate_mode_x * PI, plate_mode_y * PI);
let natural = [[false, plate_edges == "混合"]; 2];
// 製造解 u*、源項 f、流束 g = n·K∇u*（参照値として f64 の sin と cos を使う）。
let exact = move |[x, y]: [f64; 2]| (wx * x).sin() * (wy * y).sin();
let source = FieldData::time_invariant(move |p: FieldPoint<f64, 2>| {
    Ok((wx * wx + kappa * wy * wy) * exact(p.point))
});
let flux = BoundaryData::time_invariant(move |p: BoundaryPoint<f64, 2>| {
    let ([x, y], [nx, ny]) = (p.point, p.normal);
    let along_x = nx * wx * (wx * x).cos() * (wy * y).sin();
    Ok(along_x + ny * kappa * wy * (wx * x).sin() * (wy * y).cos())
});
let (mut rows, mut curves, mut field) = (Vec::new(), [Vec::new(), Vec::new()], Vec::new());
let mut terminations = Vec::new();
for n in [9_usize, 17, 33] {
    let h = 1.0 / (n - 1) as f64;
    let plan = plate_plan(n, kappa, natural, &flux).map_err(|e| e.to_string())?;
    let matrix = plan.assemble_csr().map_err(|e| e.to_string())?;
    let load = Vector::from_vec(plan.load(&source, 0.0).map_err(|e| e.to_string())?);
    let cg = CgSolver::new(
        ResidualTolerance::new(0.0, 1e-12).map_err(|e| e.to_string())?,
        Budget::try_from(4 * plan.unknowns()).map_err(|e| e.to_string())?,
    );
    let result = cg
        .solve_with_options(&matrix, &load, Preconditioning::None, None)
        .map_err(|e| e.to_string())?;

        nodal_errors(&plan, result.solution().as_slice(), exact).map_err(|e| e.to_string())?;

        4.0 / (h * h) * ((wx * h / 2.0).sin().powi(2) + kappa * (wy * h / 2.0).sin().powi(2));
    let peak = errors
        .field
        .iter()
        .fold(0.0_f64, |m, p| m.max(exact([p[0], p[1]]).abs()));
    let predicted =
        (!natural[0][1]).then(|| ((wx * wx + kappa * wy * wy) / lambda_h - 1.0).abs() * peak);
    // 一つ前の格子との観測次数。最初の格子では未定義。

        let [h0, e0]: [f64; 2] = curves[k].last().copied()?;
        Some((e0 / e).ln() / (h0 / h).ln())
    };
    let (max_order, l2_order) = (order(0, errors.max), order(1, errors.l2));
    rows.push((
        n,
        result.report().iterations(),
        errors.max,
        predicted,
        max_order,
        errors.l2,
        l2_order,
    ));
    curves[0].push([h, errors.max]);
    curves[1].push([h, errors.l2]);
    terminations.push(result.report().termination());
    field = errors.field;
}

    { "key": "0", "label": "一辺の頂点数 n", "type": "integer" },
    { "key": "1", "label": "CG の反復 [回]", "type": "integer" },
    { "key": "2", "label": "最大誤差 [-]", "type": "number", "format": sci3 },
    { "key": "3", "label": "予測した最大誤差 [-]", "type": "number", "format": sci3, "nullText": "—" },
    { "key": "4", "label": "最大誤差の次数 [-]", "type": "number", "format": fixed2, "nullText": "—" },
    { "key": "5", "label": "L² 誤差 [-]", "type": "number", "format": sci3 },

]);

);

    Outcome::satisfied("三つの格子で CG が相対残差 10⁻¹² を満たした")
} else {
    Outcome::partial("反復の上限で止まった CG があり、その格子の誤差は最後の反復の値である")
};

        .diagnostic("n = 33 の最大誤差", rows[2].2, None)

既定（$\kappa=4$、$m_x=1$、$m_y=2$、全辺 Dirichlet）では、最大誤差は $5.06\times10^{-2}$、$1.24\times10^{-2}$、$3.08\times10^{-3}$ と減り、観測次数は 2.03、2.01 だった。
離散固有値による予測は観測値と 12 桁以上一致し、CG はどの格子でも 1 回の反復で止まった。
誤差が $u_*$ の定数倍なので、$L^2$ 誤差は最大誤差のちょうど半分になる。

混合境界にすると、CG の反復は 54、106、207 回と、格子幅を半分にするたびにほぼ 2 倍になる。
CG が一定の相対残差に達するまでの反復回数の上界は条件数の平方根に比例し、離散ラプラシアンの条件数は $O(h^{-2})$ なので、上界は $O(h^{-1})$ で増える。
最大誤差は $2.24\times10^{-1}$、$5.63\times10^{-2}$、$1.41\times10^{-2}$ で、観測次数は最大誤差で 1.99、2.00、$L^2$ 誤差で 2.01、2.00 だった。
流束の条件の辺では境界の頂点の行が内部と異なるが、全体の誤差は 2 次で減る。
$\kappa=0.1$、$m_y=4$ では粗い格子の最大誤差が $1.38\times10^{-1}$ に増えるが、予測と観測はやはり一致する。

## 全 Neumann 境界と荷重の適合条件

4 辺すべてを断熱（$\boldsymbol n\cdot K\nabla u=0$）にすると、解に定数を足しても方程式と境界条件は変わらない。
発散定理から $\int_\Omega f\,dx=-\oint_{\partial\Omega}\boldsymbol n\cdot K\nabla u\,ds=0$ が必要で、これを適合条件と呼ぶ。
板の中の発熱の総和が 0 でなければ、熱の逃げ場がないので定常解は存在しない。
離散化でも同じことが起こる。
反応と移流がなく境界がすべて流束の条件なので、行列 $A$ は定数ベクトル $\boldsymbol 1$ を零空間に持ち、$A$ が対称なので $A u=b$ が解を持つ条件は $\boldsymbol 1^{\mathsf T}b=\sum_ib_i=0$ である。
`SpatialDiscretization::has_constant_modes` がこの零空間を返し、`StructuredFdmPlan::check_constant_mode_compatibility` は $|\sum_ib_i|$ を $\sum_i|b_i|$ と許容誤差 $\sqrt{\varepsilon}$（絶対・相対とも）で比べる。

`EllipticProblem` はこの零空間を知っているので、解の定数を決めるゲージ（`EllipticGauge::WeightedMean` で面積重み付きの平均値を指定する）がないと解かない。
荷重の扱いは `EllipticOptions::with_compatibility` に `scioxide_linalg::CompatibilityPolicy` で指定する。
既定の `RequireCompatible` は適合しない荷重をエラーで拒否し、`Project` は $b$ を $b-\boldsymbol 1\,(\boldsymbol 1^{\mathsf T}b)/N$（$N$ は未知数の数）に置き換えて解く。
適合条件の詳しい扱いは[楕円問題の適合条件・ゲージ・保存的流束](oxref:pde-projected-rhs)にある。

次のセルは $\kappa=4$、$n=33$ の板に製造解 $u_*=\cos(\pi x)\cos(2\pi y)$ を与える。
$u_*$ の法線微分は 4 辺で 0 で、面積重み付きの平均も 0 である。
源項は $f=\pi^2(1+4\kappa)u_*+c$ で、定数 $c$ は板全体に一様に加える正味の発熱である。
$c=0$ なら荷重は適合し、$c\ne0$ なら適合しない。
セルは荷重の総和を調べ、二つの方針で解いた結果を表にし、`RequireCompatible` で解けたかを最後に判定する。

```rust
//| id: pde-anisotropic-plate-neumann
//| ref: pde-anisotropic-plate-neumann
//| title: 全 Neumann 境界の板で、適合しない荷重が拒否されることを確かめる
//| run: reactive
//| uses: [pde-anisotropic-plate-model]
//| crates: [scioxide-core, scioxide-linalg, scioxide-pde, scioxide-spatial]
//| inputs:
//|   plate_net_heat: {"type":"range","label":"正味の発熱 c [-]","description":"源項に一様に加える定数。0 なら荷重は適合する。","min":0,"max":1,"step":0.05,"value":0.2}
//| cases:
//|   - {"id":"compatible","label":"c = 0","description":"荷重が適合し、RequireCompatible で解けて、製造解との誤差が O(h²) の大きさになる。","inputs":{"plate_net_heat":0}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"load","path":"/rows/0/0","approx":{"value":0.2,"rtol":1e-9}}
//|       - {"artifact":"policies","path":"/rows/0/1","equals":"DomainError"}
//|       - {"artifact":"policies","path":"/rows/1/1","equals":"DomainError"}
//|       - {"artifact":"policies","path":"/rows/1/2","equals":null}
//|       - {"artifact":"policies","path":"/rows/2/1","equals":"Completed"}
//|       - {"artifact":"policies","path":"/rows/2/2","approx":{"value":3.7441824e-3,"rtol":1e-5}}
//|       - {"path":"/outputs/2/state","equals":"failed"}
//|   - case: compatible
//|     expect:
//|       - {"artifact":"load","path":"/rows/0/2","range":{"max":1e-15}}
//|       - {"artifact":"policies","path":"/rows/0/1","equals":"適合"}
//|       - {"artifact":"policies","path":"/rows/1/1","equals":"Completed"}
//|       - {"artifact":"policies","path":"/rows/1/2","approx":{"value":3.0765602e-3,"rtol":1e-6}}
//|       - {"path":"/outputs/2/state","equals":"satisfied"}
use scioxide_core::{ResidualTolerance, Tolerance};
use scioxide_linalg::CompatibilityPolicy;
use scioxide_pde::{
    BoundaryData, EllipticGauge, EllipticOptions, EllipticProblem, FieldData, FieldPoint,
    SpatialDiscretization,
};
use std::f64::consts::PI;

let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let (kappa, c) = (4.0, plate_net_heat);
// 製造解 u* = cos(πx)cos(2πy)（参照値として f64 の cos を使う）と、一様な発熱 c を足した源項。
let exact = |[x, y]: [f64; 2]| (PI * x).cos() * (2.0 * PI * y).cos();
let source = FieldData::time_invariant(move |p: FieldPoint<f64, 2>| {
    Ok(PI * PI * (1.0 + 4.0 * kappa) * exact(p.point) + c)
});
let plan =
    plate_plan(33, kappa, [[true; 2]; 2], &BoundaryData::zero()).map_err(|e| e.to_string())?;
let load = plan.load(&source, 0.0).map_err(|e| e.to_string())?;
let (sum, scale) = load
    .iter()
    .fold((0.0, 0.0), |(s, a), &b| (s + b, a + f64::abs(b)));
let check = plan.check_constant_mode_compatibility(&load, Tolerance::from_sqrt_epsilon());
let mut rows = vec![(
    "荷重の検査".to_string(),
    match &check {
        Ok(()) => "適合".to_string(),
        Err(e) => format!("{:?}", e.kind()),
    },
    None,
)];
let mut accepted = None;
for (name, policy) in [
    ("RequireCompatible", CompatibilityPolicy::RequireCompatible),
    ("Project", CompatibilityPolicy::Project),
] {
    let options = EllipticOptions::new()
        .with_gauge(EllipticGauge::WeightedMean(0.0))
        .with_compatibility(
            policy,
            ResidualTolerance::from_tolerance(Tolerance::from_sqrt_epsilon()),
        );
    let row = match EllipticProblem::new(&plan, &source).solve_with_options(&options) {
        Ok(solution) => {
            let errors =
                nodal_errors(&plan, solution.values(), exact).map_err(|e| e.to_string())?;
            let termination = solution.report().termination().to_string();
            (name.to_string(), termination, Some(errors.max))
        }
        Err(e) => (name.to_string(), format!("{:?}", e.kind()), None),
    };
    if policy == CompatibilityPolicy::RequireCompatible {
        accepted = Some(row.clone());
    }
    rows.push(row);
}
let load_columns = serde_json::json!([
    { "key": "0", "label": "荷重の総和 Σb [-]", "type": "number", "format": sci3 },
    { "key": "1", "label": "荷重の絶対値の和 Σ|b| [-]", "type": "number", "format": sci3 },
    { "key": "2", "label": "比 |Σb|/Σ|b| [-]", "type": "number", "format": sci3 }
]);
emit_table_with_columns!(
    load_columns,
    vec![(sum, scale, f64::abs(sum) / scale)],
    metadata = serde_json::json!({ "id": "load" })
);
let columns = serde_json::json!([
    { "key": "0", "label": "手順" },
    { "key": "1", "label": "終了理由またはエラーの分類" },
    { "key": "2", "label": "製造解との最大誤差 [-]", "type": "number", "format": sci3, "nullText": "解なし" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "policies" })
);
let (_, status, error) = accepted.ok_or("RequireCompatible の行がない")?;
let outcome = match error {
    Some(e) => Outcome::satisfied("荷重が適合し、RequireCompatible で解けた").diagnostic(
        "製造解との最大誤差",
        e,
        None,
    ),
    None => Outcome::failed("荷重が適合条件を満たさず、RequireCompatible は解を返さなかった")
        .explanation("発熱の総和を 0 にするか、Project で荷重を変えた問題として解く。"),
};
emit_outcome!(
    outcome
        .status(status)
        .diagnostic("比 |Σb|/Σ|b|", f64::abs(sum) / scale, None)
);
```

既定の $c=0.2$ では荷重の総和は $\sum_ib_i=0.2$ で、これは板全体の発熱 $c\cdot|\Omega|$ に等しい。
比 $|\sum_ib_i|/\sum_i|b_i|=2.95\times10^{-3}$ は許容誤差 $\sqrt{\varepsilon}\approx1.5\times10^{-8}$ を大きく超えるので、検査は `DomainError` を返す。
`RequireCompatible` の求解は正規化した定数ベクトルへの射影 $|\sum_ib_i|/\sqrt N$ を $\lVert b\rVert_2$ と比べる別の尺度で調べるが、こちらも許容誤差を大きく超えて `DomainError` を返し、解は返らない。
`Project` は `Completed` で解を返し、製造解との最大誤差は $3.74\times10^{-3}$ だった。
この解は荷重を変えた問題の解である。
荷重の各成分から同じ値 $c/N$ を引くので、射影後の荷重は $b_*+c\,(|V_i|-1/N)$ になる（$b_*$ は $c=0$ の荷重、面積の和は 1）。
境界の頂点の双対セルは内部の半分以下なので、境界では熱を吸い込み、内部では湧き出す荷重が残る。
`Completed` は変更後の線形系を解いたことを示し、物理的に意味のある定常解を得たことは示さない。

$c=0$ にすると荷重の総和は $-2.8\times10^{-17}$ で丸め誤差の水準になり、`RequireCompatible` も `Completed` で解を返す。
最大誤差は $3.08\times10^{-3}$ で、全辺 Dirichlet の既定の値と同じである。
$\cos(\pi x)\cos(2\pi y)$ も、双対セルの面積で割った離散作用素の固有ベクトルで、固有値が同じ $\lambda_h$ になるためである。
このとき `Project` は荷重をほとんど変えないので、二つの方針の結果は一致する。

## まとめ

製造解を使うと、源項と境界データを逆算して、差分の誤差を厳密解と直接比べられる。
`StructuredFdmPlan` の `assemble_csr` と `load` で行列と荷重を取り出せば、scioxide-linalg の反復法で解き、誤差を自分で測れる。
全辺 Dirichlet と混合境界のどちらでも、最大誤差と $L^2$ 誤差は $n=9,17,33$ で 2 次で減った。
正弦の積の製造解は離散作用素の固有ベクトルなので、誤差は閉形式で予測でき、CG は 1 回で止まる。
反復回数を調べるときは、混合境界のように固有ベクトルでない荷重を使う。
全 Neumann 境界では荷重の総和を `check_constant_mode_compatibility` で調べ、`RequireCompatible` の拒否を発熱の釣り合いの誤りとして扱い、`Project` の結果は荷重を変えた問題の解として解釈する。
