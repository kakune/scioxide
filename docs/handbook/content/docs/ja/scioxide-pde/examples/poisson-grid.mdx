Poisson 方程式は定常熱伝導、静電ポテンシャル、地下水の定常浸透流などを表す楕円型方程式である。
各点で、内部の生成と周囲への流束の出入りが釣り合う状態を記述する。
この例題では 1 次元の Poisson 方程式 $-u''=f$ に製造解法（解を先に決めて源項を逆算する方法）で厳密解を与える。
同じ頂点の格子の上に `StructuredFdmPlan`・`SimplexFemPlan`（P1 要素）・`StructuredFvmPlan` を準備し、どれも `EllipticProblem` で解く。
離散固有値による振幅の予測、代数方程式の残差と離散化誤差の区別、格子の細分化による収束次数を確かめる。

## 棒の定常熱伝導と製造解

長さ $L$ の棒の位置を $L$ で、温度を基準の温度差で割った無次元の量を使う。
熱伝導率 $k=1$ の一様な棒 $\Omega=(0,1)$ に体積発熱 $f(x)$ があり、両端の温度を $0$ に保つ。
長さ $\Delta x$ の小区間では、両端面から出ていく流束 $q=-u'$ の差が発熱と釣り合うので、$q(x+\Delta x)-q(x)=f\,\Delta x$ となり、$\Delta x\to0$ で次の境界値問題を得る。

$$
-\frac{d^2u}{dx^2}=f(x),\qquad x\in(0,1),\qquad u(0)=u(1)=0
$$

厳密解を第 $m$ モードの正弦関数 $u_*(x)=\sin(m\pi x)$ に選ぶと、源項は $f(x)=(m\pi)^2\sin(m\pi x)$ である。
この $f$ を `FieldData::time_invariant` で与え、両端の値 $0$ を Dirichlet 条件にすれば、誤差 $\max_i|u_i-u_*(x_i)|$ を直接測れる。
セルでは製造解と源項を参照値として `f64` の `sin` で計算する。

## 三つの離散化と離散固有値

格子は $N$ 個の頂点 $x_i=ih$（$h=1/(N-1)$）で、三つの Plan は同じ頂点を使う。
各離散化の導出は[楕円問題の FDM・FEM・FVM](../../algorithms/elliptic-fdm-fem-fvm/)にあり、ここでは結果の違いに関わる点だけを挙げる。

- **有限差分法（FDM）**: `StructuredFdmPlan` は頂点の値を未知数にし、頂点の周りの区間 $[x_i-h/2,x_i+h/2]$ で熱の収支を取る。
  1 次元の一様格子では、行は 3 点の中心差分 $(2u_i-u_{i-1}-u_{i+1})/h=h f_i$ になる。
  熱伝導率は区間の中点で標本化する。
- **有限要素法（FEM）**: `SimplexFemPlan` は各区間を要素とし、要素ごとに 1 次式になる基底（P1）で弱形式を離散化する。
  荷重 $\int f\varphi_i\,dx$ は要素ごとの求積で計算し、1 次元の P1 の既定は 2 点の Gauss–Legendre 則である。
- **有限体積法（FVM）**: `StructuredFvmPlan` は $N-1$ 個のセルの中心の値を未知数にする。
  熱伝導率はセルの中心で標本化し、隣り合うセルの間の流束は二つの半セルの熱抵抗の直列で決まる。
  Dirichlet 条件は境界の面の法則として入り、未知数を固定しない。

熱伝導率を標本化する位置が違うと、物性が不連続な問題では結果が変わる。
この例題では $k=1$ なので影響せず、物性の不連続は[二層壁の例](../layered-wall-conduction/)で扱う。
三つの Plan は同じ `SpatialDiscretization` を実装するので、未知数の位置は `dof_point` で族に依らず読める。
FDM と FEM は頂点の値、FVM はセルの中心の値を、その位置の厳密解と比べる。

一様格子の中心差分では $\sin(m\pi x_i)$ が離散作用素の固有ベクトルで、$h$ で割った固有値は次のとおりである。

$$
\lambda_h=\frac{4}{h^2}\sin^2\left(\frac{m\pi h}{2}\right)
$$

荷重はこの固有ベクトルの $(m\pi)^2h$ 倍なので、FDM の節点の解は厳密解の $\rho=(m\pi)^2/\lambda_h$ 倍になる。
$\sin z<z$ から $\rho>1$ で、$\rho-1=(m\pi h)^2/12+O(h^4)$ なので誤差は $O(h^2)$ である。

FEM の節点の値には別の性質がある。
係数が一定の 1 次元の P1 要素では、荷重を厳密に積分すれば、節点の値は厳密解と一致する。
1 次元の Green 関数が P1 の空間に入るためである。
したがって節点の誤差は荷重を求積で計算するときの誤差だけになり、2 点の Gauss–Legendre 則では $O(h^4)$ になると予想できる。

二つのセルは、同じ格子の上の三つの Plan と、解いた値を未知数の位置と組にする処理を次の定義から使う。

```rust
//| id: pde-poisson-rod-model
//| kind: definitions
//| title: 1 次元の棒の三つの Plan と求解
//| crates: [scioxide-core, scioxide-pde, scioxide-spatial]
use scioxide_core::SciOxideError;
use scioxide_pde::{
    BoundaryData, BoundaryKind, ConstantDiffusion, EllipticProblem, FieldData,
    SimplexFemGeometry, SimplexFemOrder, SimplexFemPlan, SpatialDiscretization,
    StructuredBoundaries, StructuredFdmPlan, StructuredFvmPlan, TaggedBoundaries,
};
use scioxide_spatial::{IntervalMesh, Point};

/// 頂点 N 個の同じ格子の上の三つの Plan。熱伝導率 k = 1、両端 u = 0。
pub(crate) struct Rod {
    pub(crate) fdm: StructuredFdmPlan<f64, f64, 1>,
    pub(crate) fem: SimplexFemPlan<f64, f64, 1>,
    pub(crate) fvm: StructuredFvmPlan<f64, f64, 1>,
}

pub(crate) fn rod(nodes: usize) -> Result<Rod, SciOxideError> {
    let fdm = StructuredFdmPlan::dirichlet_laplacian([0.0], [1.0], [nodes])?;
    let unit = ConstantDiffusion::new(1.0);
    let mesh = fdm.mesh().clone();
    let ends =
        StructuredBoundaries::uniform(&mesh, 1, BoundaryKind::Dirichlet, BoundaryData::zero())?;
    let fvm = StructuredFvmPlan::new(mesh, &unit, &ends)?;
    // FEM は FDM と同じ頂点を区間メッシュに並べる。
    let mut points = Vec::with_capacity(nodes);
    for node in 0..nodes {
        points.push(Point::new(fdm.node_point(node)?)?);
    }
    let segments = (0..nodes - 1).map(|i| [i, i + 1]).collect();
    let interval = IntervalMesh::new(points, segments)?;
    let tagged =
        TaggedBoundaries::uniform(&interval, 1, BoundaryKind::Dirichlet, BoundaryData::zero())?;
    let fem = SimplexFemPlan::new(
        interval,
        SimplexFemGeometry::Affine,
        SimplexFemOrder::P1,
        &unit,
        &tagged,
    )?;
    Ok(Rod { fdm, fem, fvm })
}

/// 既定の直接法で解き、未知数の位置と値の組 [x, u] と、
/// 直接法の後退誤差（`linear_residual_report` の尺度化した残差）を返す。
pub(crate) fn solve<P: SpatialDiscretization<f64, f64, 1>>(
    plan: &P,
    source: &FieldData<f64, f64, 1>,
) -> Result<(Vec<[f64; 2]>, Option<f64>), SciOxideError> {
    let solution = EllipticProblem::new(plan, source).solve_with_options(&Default::default())?;
    let mut points = Vec::with_capacity(solution.values().len());
    for (unknown, &u) in solution.values().iter().enumerate() {
        points.push([plan.dof_point(unknown)?.point[0], u]);
    }
    let backward = solution
        .report()
        .diagnostics()
        .linear_residual_report()
        .map(|r| r.scaled_norm());
    Ok((points, backward))
}
```

`EllipticProblem::solve_with_options` は既定の `EllipticOptions` で、消去済みの行列が三重対角なら三重対角の直接法で、そうでなければ疎行列の LU 分解で解く。
1 次元の三つの Plan はどれも三重対角の行列を組み立てる。
直接法の解は元の方程式の残差を $\sqrt{\varepsilon}$ の後退誤差の許容誤差で検査してから返され、検査に通らなければエラーになる。

次のセルはモード番号 $m$ と頂点数 $N$ を変えて三つの方法で解く。
表には各方法の最大誤差と直接法の後退誤差、FDM の振幅比の実測値と予測値 $\rho$ を出す。
振幅比は $|\sin(m\pi x_i)|$ が最大の頂点で、FDM の解を厳密解で割って測る。

```rust
//| id: pde-poisson-methods
//| ref: pde-poisson-methods
//| title: 正弦モードと頂点数を変えて FDM・FEM・FVM を比較する
//| run: reactive
//| uses: [pde-poisson-rod-model]
//| crates: [scioxide-core, scioxide-pde, scioxide-spatial]
//| inputs:
//|   poisson_mode_number: {"type":"range","label":"正弦モード m [-]","description":"解に含まれる空間振動数を変える。","min":1,"max":7,"step":1,"value":3}
//|   poisson_grid_nodes: {"type":"range","label":"頂点数 N [点]","description":"一波長あたりの頂点数と離散化誤差を変える。","min":17,"max":81,"step":8,"value":41}
//| cases:
//|   - {"id":"short-wave","label":"m = 7（一波長約 11 点）","description":"FDM の誤差は 2.6×10⁻² に増え、振幅比 1.025573 が離散固有値の予測と一致する。","inputs":{"poisson_mode_number":7}}
//|   - {"id":"coarse-grid","label":"N = 17","description":"m = 3 の一波長が約 11 点になり、FDM の誤差は 2.9×10⁻² になる。","inputs":{"poisson_grid_nodes":17}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"methods","path":"/rows/0/1","approx":{"value":4.6392474e-3,"rtol":1e-6}}
//|       - {"artifact":"methods","path":"/rows/1/1","approx":{"value":2.1466365e-6,"rtol":1e-5}}
//|       - {"artifact":"methods","path":"/rows/2/1","approx":{"value":4.6356707e-3,"rtol":1e-6}}
//|       - {"artifact":"methods","path":"/rows/0/2","range":{"min":0,"max":1e-14}}
//|       - {"artifact":"methods","path":"/rows/2/2","range":{"min":0,"max":1e-14}}
//|       - {"artifact":"amplitude","path":"/rows/0/0","approx":{"value":1.0046392,"rtol":1e-7}}
//|       - {"artifact":"amplitude","path":"/rows/0/2","range":{"max":1e-12}}
//|   - case: short-wave
//|     expect:
//|       - {"artifact":"methods","path":"/rows/0/1","approx":{"value":2.557333e-2,"rtol":1e-6}}
//|       - {"artifact":"amplitude","path":"/rows/0/1","approx":{"value":1.025573,"rtol":1e-6}}
//|       - {"artifact":"amplitude","path":"/rows/0/2","range":{"max":1e-12}}
//|   - case: coarse-grid
//|     expect:
//|       - {"artifact":"methods","path":"/rows/0/1","approx":{"value":2.942349e-2,"rtol":1e-6}}
//|       - {"artifact":"amplitude","path":"/rows/0/1","approx":{"value":1.029423,"rtol":1e-6}}
use scioxide_pde::{FieldData, FieldPoint};
use std::f64::consts::PI;

let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let fixed7 = serde_json::json!({ "fractionDigits": 7 });
let wave = poisson_mode_number * PI;
let nodes = poisson_grid_nodes as usize;
let h = 1.0 / (nodes - 1) as f64;
// 製造解 u* = sin(mπx) と源項 f = (mπ)² sin(mπx)（参照値として f64 の sin を使う）。
let source = FieldData::time_invariant(move |p: FieldPoint<f64, 1>| {
    Ok(wave * wave * (wave * p.point[0]).sin())
});
let plans = rod(nodes).map_err(|e| e.to_string())?;
let solutions = [
    (
        "FDM（頂点）",
        solve(&plans.fdm, &source).map_err(|e| e.to_string())?,
    ),
    (
        "FEM（頂点）",
        solve(&plans.fem, &source).map_err(|e| e.to_string())?,
    ),
    (
        "FVM（セル中心）",
        solve(&plans.fvm, &source).map_err(|e| e.to_string())?,
    ),
];
let exact_points: Vec<[f64; 2]> = (0..=200)
    .map(|i| [i as f64 / 200.0, (wave * i as f64 / 200.0).sin()])
    .collect();
let mut series = vec![serde_json::json!({
    "name": "厳密解",
    "points": exact_points,
    "style": { "lineType": "dashed" }
})];
let mut rows = Vec::new();
for (label, (points, backward)) in &solutions {
    let error = points
        .iter()
        .map(|[x, u]| (u - (wave * x).sin()).abs())
        .fold(0.0_f64, f64::max);
    rows.push((*label, error, *backward));
    series.push(serde_json::json!({
        "name": label,
        "points": points,
        "style": { "showSymbol": true }
    }));
}
// FDM の振幅比を |sin(mπx)| が最大の頂点で測り、離散固有値の予測 ρ と比べる。
let fdm_points = &solutions[0].1.0;
let [x_peak, u_peak] = *fdm_points
    .iter()
    .max_by(|a, b| {
        (wave * a[0])
            .sin()
            .abs()
            .total_cmp(&(wave * b[0]).sin().abs())
    })
    .ok_or("頂点がない")?;
let measured = u_peak / (wave * x_peak).sin();
let predicted = wave * wave / (4.0 / (h * h) * (wave * h / 2.0).sin().powi(2));
emit_line_chart!(
    &series,
    options = &serde_json::json!({ "xLabel": "位置 x/L [-]", "yLabel": "温度 u [-]" })
);
let columns = serde_json::json!([
    { "key": "0", "label": "方法（未知数の位置）" },
    { "key": "1", "label": "最大誤差 [-]", "type": "number", "format": sci3 },
    { "key": "2", "label": "直接法の後退誤差 [-]", "type": "number", "format": sci3, "nullText": "なし" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "methods" })
);
let amplitude_columns = serde_json::json!([
    { "key": "0", "label": "FDM の振幅比（実測）[-]", "type": "number", "format": fixed7 },
    { "key": "1", "label": "予測 ρ = (mπ)²/λ_h [-]", "type": "number", "format": fixed7 },
    { "key": "2", "label": "差 [-]", "type": "number", "format": sci3 }
]);
emit_table_with_columns!(
    amplitude_columns,
    vec![(measured, predicted, (measured - predicted).abs())],
    metadata = serde_json::json!({ "id": "amplitude" })
);
```

既定（$m=3$、$N=41$）では、FDM と FVM の最大誤差がともに $4.6\times10^{-3}$、FEM の節点の誤差は $2.1\times10^{-6}$ だった。
FDM の振幅比の実測値 1.0046392 は、離散固有値による予測と丸め誤差の水準で一致する。
三つの方法とも、直接法の後退誤差は $10^{-16}$ 程度である。
この量は代数方程式を解いた精度を表し、離散化誤差とは別の量である。
後退誤差が小さくても、離散解と厳密解の差は $10^{-3}$ の桁で残る。
$m=7$ では一波長あたりの頂点数が約 11 に減り、FDM の誤差は $2.6\times10^{-2}$ に増える。

## 格子の細分化と観測次数

頂点数 $N=9,13,17,25,33,49,65,97$ の系列で最大誤差を測り、最も細かい二つの格子から観測次数 $p_{\mathrm{obs}}=\log(e_1/e_2)/\log(h_1/h_2)$ を求める。
FDM とセル中心の FVM は 2 次で、格子幅を半分にすると誤差が $1/4$ になると予想する。
前の節の議論から、FEM の節点の誤差は 4 次と予想する。
両対数のグラフでは観測点を記号で、傾き 2 と 4 の参照線を破線で描く。

```rust
//| id: pde-poisson-convergence
//| ref: pde-poisson-convergence
//| title: 三つの方法の格子誤差と観測収束次数を測る
//| run: reactive
//| uses: [pde-poisson-rod-model]
//| crates: [scioxide-core, scioxide-pde, scioxide-spatial]
//| inputs:
//|   poisson_convergence_mode: {"type":"range","label":"収束試験のモード m [-]","description":"微分が大きい解ほど、漸近域に入る格子が細かくなる。","min":1,"max":6,"step":1,"value":2}
//| cases:
//|   - {"id":"high-mode","label":"m = 6","description":"9 点の格子で FDM の誤差が 0.63 に達するが、最も細かい二つの格子の観測次数は FDM 2.006、FEM 4.006、FVM 2.015 になる。","inputs":{"poisson_convergence_mode":6}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"errors","path":"/rows/7/2","approx":{"value":3.5705001e-4,"rtol":1e-6}}
//|       - {"artifact":"errors","path":"/rows/7/3","approx":{"value":1.27459e-8,"rtol":1e-4}}
//|       - {"artifact":"errors","path":"/rows/7/4","approx":{"value":3.5685884e-4,"rtol":1e-6}}
//|       - {"artifact":"orders","path":"/rows/0/0","approx":{"value":2.0,"atol":5e-3}}
//|       - {"artifact":"orders","path":"/rows/0/1","approx":{"value":4.0,"atol":5e-3}}
//|       - {"artifact":"orders","path":"/rows/0/2","approx":{"value":2.0,"atol":5e-3}}
//|   - case: high-mode
//|     expect:
//|       - {"artifact":"errors","path":"/rows/0/2","approx":{"value":0.62604136,"rtol":1e-6}}
//|       - {"artifact":"orders","path":"/rows/0/0","approx":{"value":2.006,"atol":1e-3}}
//|       - {"artifact":"orders","path":"/rows/0/1","approx":{"value":4.006,"atol":1e-3}}
//|       - {"artifact":"orders","path":"/rows/0/2","approx":{"value":2.015,"atol":1e-3}}
use scioxide_pde::{FieldData, FieldPoint};
use std::f64::consts::PI;

let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let fixed3 = serde_json::json!({ "fractionDigits": 3 });
let wave = poisson_convergence_mode * PI;
// 製造解の源項（参照値として f64 の sin を使う）。
let source = FieldData::time_invariant(move |p: FieldPoint<f64, 1>| {
    Ok(wave * wave * (wave * p.point[0]).sin())
});
let max_error = |points: &[[f64; 2]]| {
    points
        .iter()
        .map(|[x, u]| (u - (wave * x).sin()).abs())
        .fold(0.0_f64, f64::max)
};
let mut curves: [Vec<[f64; 2]>; 3] = [Vec::new(), Vec::new(), Vec::new()];
let mut rows = Vec::new();
for nodes in [9_usize, 13, 17, 25, 33, 49, 65, 97] {
    let h = 1.0 / (nodes - 1) as f64;
    let plans = rod(nodes).map_err(|e| e.to_string())?;
    let errors = [
        max_error(&solve(&plans.fdm, &source).map_err(|e| e.to_string())?.0),
        max_error(&solve(&plans.fem, &source).map_err(|e| e.to_string())?.0),
        max_error(&solve(&plans.fvm, &source).map_err(|e| e.to_string())?.0),
    ];
    for (curve, e) in curves.iter_mut().zip(errors) {
        curve.push([h, e]);
    }
    rows.push((nodes, h, errors[0], errors[1], errors[2]));
}
// 最も細かい二つの格子から観測次数を求める。
let order = |c: &Vec<[f64; 2]>| {
    let (a, b) = (c[c.len() - 2], c[c.len() - 1]);
    (a[1] / b[1]).ln() / (a[0] / b[0]).ln()
};
// 最も細かい格子の点を通る傾き p の参照線。
let reference = |c: &Vec<[f64; 2]>, p: i32| -> Vec<[f64; 2]> {
    let [h, e] = c[c.len() - 1];
    c.iter().map(|q| [q[0], e * (q[0] / h).powi(p)]).collect()
};
let mut series: Vec<_> = ["FDM", "FEM", "FVM"]
    .iter()
    .zip(&curves)
    .zip(["circle", "diamond", "triangle"])
    .map(|((name, c), symbol)| {
        serde_json::json!({ "name": name, "points": c, "style": { "symbol": symbol } })
    })
    .collect();
for (name, curve, p) in [
    ("傾き 2（参照）", &curves[0], 2),
    ("傾き 4（参照）", &curves[1], 4),
] {
    series.push(serde_json::json!({
        "name": name,
        "points": reference(curve, p),
        "style": { "lineType": "dashed" }
    }));
}
emit_line_chart!(
    &series,
    options = &serde_json::json!({
        "xLabel": "格子幅 h [-]",
        "yLabel": "最大誤差 [-]",
```

既定（$m=2$）の観測次数は FDM が 2.001、FEM が 4.001、FVM が 1.999 だった。
FEM の点は傾き 4 の破線に沿い、節点の誤差が荷重の求積による誤差だけであることと合う。
モード番号を上げると、粗い格子では波が解像されずに曲線が曲がるが、一波長あたり 10 点程度より細かい格子では理論の傾きに近づく。
$m=6$ では 9 点の格子で FDM の誤差が 0.63 に達するが、最も細かい二つの格子の観測次数は FDM が 2.006、FEM が 4.006、FVM が 2.015 である。

FEM の 4 次は 1 次元で係数が一定の P1 要素の節点に特有の超収束である。
節点の間の誤差や $L^2$ 誤差は P1 の通常の次数（$L^2$ で 2 次）にとどまり、2 次元以上の P1 要素の節点の値にも 4 次は期待できない。

## まとめ

製造解を使うと、三つの離散化の誤差を厳密解と直接比べられる。
三つの Plan は同じ `SpatialDiscretization` を実装するので、一つの `EllipticProblem` で同じ手順で解け、`dof_point` で未知数の位置を読める。
一様格子の FDM の節点の解は厳密解の $\rho=(m\pi)^2/\lambda_h$ 倍なので、誤差を前もって計算して実装を確かめられる。
FDM と FVM は 2 次、1 次元の P1 の FEM の節点の値は 4 次で収束した。
直接法の後退誤差は代数方程式の精度であり、離散化誤差の推定には使えない。
