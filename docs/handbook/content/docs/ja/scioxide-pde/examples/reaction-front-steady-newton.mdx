このページは[非線形の定常問題](../../algorithms/nonlinear-steady-problems/)で説明した `NonlinearPdeProblem`、`PdeJacobianMode`、`PdeFieldPreconditioner`、`PdeTangent` を、二つの場が反応で連成する定常問題に使う。
解は Newton–Krylov 法で求め、ヤコビ行列の表現と前処理の有無で反復の回数がどう変わるかを比べる。
解の正しさは残差の大きさではなく、反応で消えない不変量と、反応が速い極限の閉形式で確かめる。

## 対向拡散する二種の反応面

厚さ $L=1$ mm の膜の左の面（$x=0$）に物質 A の溶液、右の面（$x=L$）に物質 B の溶液が接している。
A と B は膜の中へ拡散し、出会ったところで二次反応 $\mathrm{A}+\mathrm{B}\to\mathrm{P}$（速度定数 $k$ [m³/(mol·s)]）で消える。
濃度 $a(x),b(x)$ [mol/m³] の定常状態は

$$
D_A\,a''=k\,a\,b,\qquad D_B\,b''=k\,a\,b,\qquad 0<x<L
$$

$$
a(0)=a_0,\quad a(L)=0,\qquad b(0)=0,\quad b(L)=b_0
$$

を満たす。
パラメータは $D_A=1.0\times10^{-9}$ m²/s、$D_B=0.5\times10^{-9}$ m²/s、$a_0=b_0=1$ mol/m³ とする。
反応の速さは Damköhler 数 $\mathrm{Da}=k\,a_0L^2/D_A$（反応の速さと拡散の速さの比）で表す。

二つの式を引くと反応項が消え、$w=D_A a-D_B b$ は $w''=0$ を満たす。
したがって $w$ は境界値で決まる一次関数

$$
w(x)=D_A a_0\left(1-\frac{x}{L}\right)-D_B b_0\,\frac{x}{L}
$$

になる。
反応が十分に速い極限（$\mathrm{Da}\to\infty$）では A と B は共存できず、$w>0$ の側に A だけ、$w<0$ の側に B だけが残る。
極限の濃度は $a=\max(w,0)/D_A$、$b=\max(-w,0)/D_B$ で、反応面は $w=0$ の位置

$$
x_f=\frac{D_A a_0}{D_A a_0+D_B b_0}\,L=\frac{2}{3}\,L
$$

に集まる。
有限の Da では、反応は $x_f$ のまわりの幅 $\delta$ の帯で起こる。
帯の中で拡散と反応がつり合う条件 $D c/\delta^2\sim k c^2$ と、帯へ流れ込む流束 $D c/\delta\sim D_A a_0/L$ から、幅は $\delta/L\sim\mathrm{Da}^{-1/3}$、帯の中の濃度は $c/a_0\sim\mathrm{Da}^{-1/3}$ と見積もれる。
このため極限の濃度との差は $\mathrm{Da}^{-1/3}$ に比例して縮むと予想できる。

区間を $n+1$ 等分した内部の節点 $x_i=ih$（$h=L/(n+1)$、$i=1,\dots,n$）で 3 点差分を使い、各節点の式に $h$ を掛けた残差

$$
F^{a}_i=\frac{D_A}{h}\left(a_{i-1}-2a_i+a_{i+1}\right)-h\,k\,a_ib_i,\qquad
F^{b}_i=\frac{D_B}{h}\left(b_{i-1}-2b_i+b_{i+1}\right)-h\,k\,a_ib_i
$$

を使う（単位は mol/(m²·s)）。
$h$ を掛けた形は、集中化した質量が $h$ の半離散系 $h\,\dot{\mathbf{u}}=\mathbf{F}$ の右辺と同じである。
$a_0,a_{n+1},b_0,b_{n+1}$ は境界値で、未知数は $\mathbf{u}=(a_1,\dots,a_n,b_1,\dots,b_n)$ の順に並べる。
差分の $w_i=D_Aa_i-D_Bb_i$ も 3 点差分で $w_{i-1}-2w_i+w_{i+1}=0$ を満たすので、離散解の $w_i$ は丸めと残差の水準で一次関数に一致する。
これは二つの場を正しく連成して解いたかを確かめる検算になる。

ヤコビ行列は場ごとに三重対角で、場どうしの結合は対角だけである。

$$
\frac{\partial F^a_i}{\partial a_i}=-\frac{2D_A}{h}-hk\,b_i,\qquad
\frac{\partial F^a_i}{\partial a_{i\pm1}}=\frac{D_A}{h},\qquad
\frac{\partial F^a_i}{\partial b_i}=-hk\,a_i
$$

$F^b$ も $a$ と $b$ を入れ替えた同じ形である。
前処理の各ブロックには反応の項を除いた拡散の部分 $-(D/h)\,\mathrm{tridiag}(-1,2,-1)$ の逆を使い、Thomas 法（三重対角行列の LU 分解）で $O(n)$ の手間で適用する。

次のブロックは二つのセルが共有するモデルである。
`ReactionFront` の `rhs` が残差 $\mathbf{F}$、`jacobian`・`sparse_jacobian`・`jacobian_product` がヤコビ行列の三つの表現、`diffusion_inverse` が前処理のブロックに対応する。
`linear_profiles` は反応のない（$k=0$）ときの一次関数の濃度で、Newton 法の初期値にする。

```rust
//| id: pde-reaction-front-model
//| kind: definitions
//| title: 対向拡散する二種の反応面の残差とヤコビ行列
//| crates: [scioxide-core, scioxide-linalg, scioxide-ode]
use scioxide_core::{
    ClosurePreconditioner, SciOxideError, SolveContext, StructuralPattern, StructuralPatternView,
};
use scioxide_linalg::MatrixViewMut;
use scioxide_ode::OdeSystem;

/// 膜 0 < x < L の内部節点の残差。成分の順は [a_1..a_n, b_1..b_n]。
pub(crate) struct ReactionFront {
    pub(crate) nodes: usize,
    pub(crate) spacing: f64,
    pub(crate) diffusivity: [f64; 2],
    pub(crate) rate: f64,
    pub(crate) left: [f64; 2],
    pub(crate) right: [f64; 2],
}

impl ReactionFront {
    /// L = 1 mm、D_A = 1e-9 m²/s、D_B = 0.5e-9 m²/s、a0 = b0 = 1 mol/m³。
    pub(crate) fn new(nodes: usize, rate: f64) -> Self {
        Self {
            nodes,
            spacing: 1.0e-3 / (nodes + 1) as f64,
            diffusivity: [1.0e-9, 0.5e-9],
            rate,
            left: [1.0, 0.0],
            right: [0.0, 1.0],
        }
    }

    /// 節点 i (0 始まり) の位置 x = (i + 1) h [m]。
    pub(crate) fn position(&self, i: usize) -> f64 {
        (i + 1) as f64 * self.spacing
    }

    /// 場 field の節点 i の値。i = −1 と i = n は Dirichlet の境界値。
    fn value(&self, x: &[f64], field: usize, i: isize) -> f64 {
        match usize::try_from(i) {
            Err(_) => self.left[field],
            Ok(i) if i == self.nodes => self.right[field],
            Ok(i) => x[field * self.nodes + i],
        }
    }

    /// ヤコビ行列の (row, col) 成分。
    pub(crate) fn entry(&self, x: &[f64], row: usize, col: usize) -> f64 {
        let n = self.nodes;
        let (field, i, other, j) = (row / n, row % n, col / n, col % n);
        let mut value = 0.0;
        if field == other && i.abs_diff(j) <= 1 {
            let d = self.diffusivity[field] / self.spacing;
            value += if i == j { -2.0 * d } else { d };
        }
        if i == j {
            // ∂(h k a b)/∂a = h k b、∂(h k a b)/∂b = h k a。
            let partner = if other == 0 { x[n + i] } else { x[i] };
            value -= self.spacing * self.rate * partner;
        }
        value
    }

    /// 場ごとの三重対角と、同じ節点の場どうしの結合からなる構造。
    pub(crate) fn pattern(&self) -> Result<StructuralPattern, SciOxideError> {
        let n = self.nodes;
        let (mut rows, mut columns) = (vec![0], Vec::new());
        for row in 0..2 * n {
            let (field, i) = (row / n, row % n);
            let mut entries: Vec<usize> = (i.saturating_sub(1)..=(i + 1).min(n - 1))
                .map(|j| field * n + j)
                .collect();
            entries.push((1 - field) * n + i);
            entries.sort_unstable();
            columns.extend(entries);
            rows.push(columns.len());
        }
        StructuralPattern::new(2 * n, 2 * n, rows, columns)
    }

    /// 反応のない (k = 0) ときの一次関数の濃度。
    pub(crate) fn linear_profiles(&self) -> Vec<f64> {
        (0..2 * self.nodes)
            .map(|row| {
                let s = self.position(row % self.nodes) / 1.0e-3;
                let field = row / self.nodes;
                self.left[field] * (1.0 - s) + self.right[field] * s
            })
            .collect()
    }

    /// 節点 i の不変量 w = D_A a − D_B b の厳密な一次関数と、高速反応の極限の濃度 (a, b)。
    pub(crate) fn limit(&self, i: usize) -> (f64, f64, f64) {
        let s = self.position(i) / 1.0e-3;
        let [da, db] = self.diffusivity;
        let w = da * self.left[0] * (1.0 - s) - db * self.right[1] * s;
        (w, w.max(0.0) / da, (-w).max(0.0) / db)
    }

    /// 検算: (不変量のずれ / (D_A a0), 極限の濃度との最大差 [mol/m³], 反応帯の重心 x_c [m])。
    pub(crate) fn checks(&self, u: &[f64]) -> (f64, f64, f64) {
        let n = self.nodes;
        let [da, db] = self.diffusivity;
        let (mut invariant, mut limit, mut weighted, mut total) = (0.0_f64, 0.0_f64, 0.0, 0.0);
        for i in 0..n {
            let (w, a, b) = self.limit(i);
            invariant = invariant.max((da * u[i] - db * u[n + i] - w).abs() / (da * self.left[0]));
            limit = limit.max((u[i] - a).abs()).max((u[n + i] - b).abs());
            weighted += self.position(i) * u[i] * u[n + i];
            total += u[i] * u[n + i];
        }
        (invariant, limit, weighted / total)
    }

    /// 拡散の部分 −(D/h) tridiag(−1, 2, −1) の逆を Thomas 法で作用させる前処理。
    pub(crate) fn diffusion_inverse(
        &self,
        field: usize,
    ) -> ClosurePreconditioner<f64, impl Fn(&[f64], &mut [f64]) -> Result<(), SciOxideError>> {
        let (n, scale) = (self.nodes, self.spacing / self.diffusivity[field]);
        // LU 分解の対角 m_i と上の係数 c_i = −1/m_i を前もって作る。
        let mut pivots = vec![2.0; n];
        let mut upper = vec![-0.5; n];
        for i in 1..n {
            pivots[i] = 2.0 + upper[i - 1];
            upper[i] = -1.0 / pivots[i];
        }
        ClosurePreconditioner::new(n, move |input: &[f64], output: &mut [f64]| {
            for i in 0..n {
                let previous = if i > 0 { output[i - 1] } else { 0.0 };
                output[i] = (-scale * input[i] + previous) / pivots[i];
            }
            for i in (0..n.saturating_sub(1)).rev() {
                output[i] -= upper[i] * output[i + 1];
            }
            Ok(())
        })
    }
}

impl OdeSystem<f64> for ReactionFront {
    fn dimension(&self) -> usize {
        2 * self.nodes
    }

    fn rhs(
        &self,
        _: f64,
        x: &[f64],
        out: &mut [f64],
        _: &mut SolveContext<'_, '_>,
    ) -> Result<(), SciOxideError> {
        let n = self.nodes;
        for row in 0..2 * n {
            let (field, i) = (row / n, (row % n) as isize);
            let laplacian =
                self.value(x, field, i - 1) - 2.0 * x[row] + self.value(x, field, i + 1);
            let reaction = self.spacing * self.rate * x[row % n] * x[n + row % n];
            out[row] = self.diffusivity[field] / self.spacing * laplacian - reaction;
        }
        Ok(())
    }

    fn jacobian(
        &self,
        _: f64,
        x: &[f64],
        out: &mut MatrixViewMut<'_, f64>,
        _: &mut SolveContext<'_, '_>,
    ) -> Result<Option<()>, SciOxideError> {
        for row in 0..2 * self.nodes {
            for col in 0..2 * self.nodes {
                out.set(row, col, self.entry(x, row, col))?;
            }
        }
        Ok(Some(()))
    }

    fn sparse_jacobian(
        &self,
        _: f64,
        x: &[f64],
        p: StructuralPatternView<'_>,
        out: &mut [f64],
        _: &mut SolveContext<'_, '_>,
    ) -> Result<Option<()>, SciOxideError> {
        for row in 0..2 * self.nodes {
            for k in p.row_ptr()[row]..p.row_ptr()[row + 1] {
                out[k] = self.entry(x, row, p.col_indices()[k]);
            }
        }
        Ok(Some(()))
    }

    fn jacobian_product(
        &self,
        _: f64,
        x: &[f64],
        v: &[f64],
        out: &mut [f64],
        _: &mut [f64],
        _: &mut SolveContext<'_, '_>,
    ) -> Result<Option<()>, SciOxideError> {
        let n = self.nodes;
        for row in 0..2 * n {
            let i = row % n;
            // 境界値は固定なので、範囲外の方向成分は 0。
            let below = if i > 0 { v[row - 1] } else { 0.0 };
            let above = if i + 1 < n { v[row + 1] } else { 0.0 };
            let diffusion =
                self.diffusivity[row / n] / self.spacing * (below - 2.0 * v[row] + above);
            let reaction = self.spacing * self.rate * (x[n + i] * v[i] + x[i] * v[n + i]);
            out[row] = diffusion - reaction;
        }
        Ok(Some(()))
    }
}
```

## Newton–Krylov 法による求解

次のセルは速度定数 $k$、内部の節点数 $n$、ヤコビ行列の表現、場ごとの前処理の有無を選んで、定常解を `NewtonKrylovSolver` で求める。
残差の許容誤差は相対 $10^{-10}$（初期点の残差ノルムに対する比）とし、初期値は反応のない一次関数の濃度にする。
表は終了理由、Newton 法と GMRES の反復回数、ヤコビ行列を組み立てた回数、最後の残差ノルムを示す。
最後の列は、解の点で `PdeTangent` が返す $J(\mathbf{u})\mathbf{v}$ と、残差の中心差分 $[\mathbf{F}(\mathbf{u}+\sigma\mathbf{v})-\mathbf{F}(\mathbf{u}-\sigma\mathbf{v})]/(2\sigma)$ の相対差である。
残差は $\mathbf{u}$ の二次式なので中心差分は丸めを除いて厳密で、この列は選んだ表現の微分が残差と食い違っていないかを確かめる。
求めた濃度は次のセルに渡す。

```rust
//|       - {"path":"/outputs/1/state","equals":"satisfied"}
use scioxide_core::{
    EvaluationRole, LinearOperator, Preconditioner, ResidualOperator, ResidualTolerance,
};
use scioxide_pde::{
    NonlinearPdeProblem, PdeFieldLayout, PdeFieldPreconditioner, PdeJacobianMode, PdeTangent,
};
use scioxide_rootfind::{
    NewtonKrylovOptions, NewtonKrylovProblem, NewtonKrylovSolver, RootTermination,
};

let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let n = front_nodes as usize;
let model = ReactionFront::new(n, 10.0_f64.powf(rate_exponent));
let layout = PdeFieldLayout::new(&[n, n]).map_err(|e| e.to_string())?;
let mode = match jacobian_mode.as_str() {
    "疎（Sparse）" => PdeJacobianMode::Sparse(model.pattern().map_err(|e| e.to_string())?),
    "密（Dense）" => PdeJacobianMode::Dense,
    _ => PdeJacobianMode::Operator {
        operator_scratch: 0,
    },
};
let (inverse_a, inverse_b) = (model.diffusion_inverse(0), model.diffusion_inverse(1));
let blocks: [&dyn Preconditioner<f64>; 2] = [&inverse_a, &inverse_b];
let field_inverse = PdeFieldPreconditioner::new(&layout, &blocks).map_err(|e| e.to_string())?;

// 時刻 0 に固定した残差 F(u) = f(0, u) を Newton–Krylov 法に渡す。
let problem = NonlinearPdeProblem::new(&model, 0.0, &layout, &mode);
let mut workspace = problem.workspace().map_err(|e| e.to_string())?;
let residual = problem.bind(&mut workspace).map_err(|e| e.to_string())?;
let mut newton = NewtonKrylovProblem::with_jacobian(&residual);
if field_preconditioner {
    newton = newton.with_preconditioner(&field_inverse);
}
let tolerance = ResidualTolerance::new(0.0, 1.0e-10).map_err(|e| e.to_string())?;
let options = NewtonKrylovOptions::default().with_residual_tolerance(tolerance);
let result = NewtonKrylovSolver::new(options)
    .and_then(|solver| solver.solve(&newton, &model.linear_profiles()))
    .map_err(|e| e.to_string())?;
let termination = result.termination();
let u = result.point();

// 解の点の J v（PdeTangent）と、残差の中心差分（独立な検算）。
let v: Vec<f64> = (0..2 * n).map(|r| ((r % 7) as f64 - 3.0) / 3.0).collect();
let tangent = PdeTangent::new(&residual, u).map_err(|e| e.to_string())?;
let mut scratch = vec![0.0; tangent.apply_workspace_len().map_err(|e| e.to_string())?];
let mut product = vec![0.0; 2 * n];
tangent
    .apply_into(&v, &mut product, &mut scratch)
    .map_err(|e| e.to_string())?;
let sigma = 1.0e-4;
let mut difference = vec![0.0; 2 * n];
for sign in [1.0, -1.0] {
    let point: Vec<f64> = u
        .iter()
        .zip(&v)
        .map(|(x, d)| x + sign * sigma * d)
        .collect();
    let mut value = vec![0.0; 2 * n];
    residual
        .residual_into(&point, &mut value, &mut scratch)
        .map_err(|e| e.to_string())?;
    for (d, f) in difference.iter_mut().zip(&value) {
        *d += sign * f / (2.0 * sigma);
    }
}
let largest = product.iter().fold(0.0_f64, |m, p| m.max(p.abs()));
let gaps = product.iter().zip(&difference).map(|(p, d)| (p - d).abs());
let jvp_gap = gaps.fold(0.0_f64, f64::max) / largest;

let nested = result.accounting().nested();
let columns = serde_json::json!([
    { "key": "0", "label": "表現" },
    { "key": "1", "label": "終了理由" },
    { "key": "2", "label": "Newton 反復 [回]", "type": "integer" },
    { "key": "3", "label": "GMRES 反復 [回]", "type": "integer" },
    { "key": "4", "label": "ヤコビ行列の組立 [回]", "type": "integer" },
    { "key": "5", "label": "‖F‖₂ [mol/(m²·s)]", "type": "number", "format": sci3, "nullText": "なし" },
    { "key": "6", "label": "JVP と中心差分の相対差 [-]", "type": "number", "format": sci3 }
]);
emit_table_with_columns!(
    columns,
    vec![(
        jacobian_mode.clone(),
        termination.to_string(),
        result.iterations(),
        nested.iterations(),
        nested.provider(EvaluationRole::Jacobian),
        result.residual_norm(),
        jvp_gap,
    )],
    metadata = serde_json::json!({ "id": "solve" })
);
export!(nodes, n);
export!(rate, model.rate);
export!(state, u.to_vec());

let broken = matches!(
    termination,
    RootTermination::GlobalizationFailure | RootTermination::LinearFailure(_)
);
let outcome = if termination.is_success() {
    Outcome::satisfied("Newton–Krylov 法が残差の許容誤差を満たした")
} else if broken {
    Outcome::failed("直線探索か内側の線形解法が破綻し、定常解は得られていない")
} else {
    Outcome::partial("許容誤差を満たす前に止まった")
        .explanation("渡す濃度は最後に受理した点で、定常解ではない。")
};
emit_outcome!(
    outcome
        .status(termination.to_string())
        .diagnostic("Newton 反復", result.iterations() as f64, None)
        .diagnostic("GMRES 反復", nested.iterations() as f64, None)
);
```

既定の $k=1$ m³/(mol·s)（$\mathrm{Da}=1000$）と $n=99$ では、Newton 法は 7 回の反復で `ResidualTolerance` に達し、残差ノルムは $5.5\times10^{-20}$ mol/(m²·s) まで下がった。
GMRES の反復は 7 回の Newton 反復を合わせて 43 回である。
場ごとの前処理を外すと、Newton 法の反復は 15 回、GMRES の反復は 1107 回に増える。
拡散の逆は条件数 $O(h^{-2})$ の原因になる部分をそのまま打ち消すので、反応の項を無視していても GMRES の反復が大きく減る。

表現を疎や密に替えても、Newton 法と GMRES の反復の回数は変わらない。
組み立てた行列の積とプロバイダーの JVP は丸めの範囲で同じ $J(\mathbf{u})\mathbf{v}$ を返すからである。
疎と密の表現では、ヤコビ行列の組み立てが Newton の反復と同じ 7 回になり、GMRES の 43 回の積はその行列を再利用する。
JVP と中心差分の相対差は三つの表現とも $8\times10^{-14}$ 程度で、選んだ表現の微分は残差と一致している。
$k=10^{-3}$（Da = 1）では反応の項が小さく、初期値の一次関数が解に近いので、Newton 法は 4 回、GMRES は 7 回で止まる。

## 濃度の分布と高速反応の極限

次のセルは前のセルの濃度を受け取り、高速反応の極限と比べる。
上のグラフは二つの濃度（実線）と極限の濃度（破線）、下のグラフは反応速度 $k\,a\,b$ で、横軸は連動する。
縦の線は極限の反応面 $x_f=2L/3$ である。
表は Da、反応速度で重みを付けた反応帯の重心 $x_c=\sum_i x_i a_ib_i/\sum_i a_ib_i$、極限の濃度との差の最大値、不変量 $w_i$ と一次関数の差の最大値（$D_Aa_0$ との比）を示す。

```rust
//| id: pde-reaction-front-profiles
//| ref: pde-reaction-front-profiles
//| title: 反応面の濃度を高速反応の極限と比べる
//| run: reactive
//| uses: [pde-reaction-front-model]
//| crates: [scioxide-core, scioxide-linalg, scioxide-ode]

//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"checks","path":"/rows/0/0","approx":{"value":1000,"rtol":1e-12}}
//|       - {"artifact":"checks","path":"/rows/0/1","approx":{"value":0.6663,"atol":2e-4}}
//|       - {"artifact":"checks","path":"/rows/0/3","approx":{"value":0.1085,"rtol":1e-2}}
//|       - {"artifact":"checks","path":"/rows/0/4","range":{"max":1e-12}}
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let fixed4 = serde_json::json!({ "fractionDigits": 4 });
let n = steady["nodes"].as_u64().ok_or("節点数がない")? as usize;
let rate = steady["rate"].as_f64().ok_or("速度定数がない")?;
let u: Vec<f64> = serde_json::from_value(steady["state"].clone()).map_err(|e| e.to_string())?;
let model = ReactionFront::new(n, rate);

// 濃度と極限の濃度（x は mm）、反応速度 k a b [mol/(m³·s)]。
let mut series = [(); 5].map(|_| Vec::new());
for i in 0..n {
    let (_, a_limit, b_limit) = model.limit(i);
    let x = model.position(i) * 1.0e3;
    series[0].push([x, u[i]]);
    series[1].push([x, u[n + i]]);
    series[2].push([x, a_limit]);
    series[3].push([x, b_limit]);
    series[4].push([x, rate * u[i] * u[n + i]]);
}
let [a_line, b_line, a_limit, b_limit, rate_line] = series;
let front = serde_json::json!([
    { "kind": "line", "axis": "x", "value": 2.0 / 3.0, "label": "x_f = 2L/3" }
]);
let dashed = serde_json::json!({ "lineType": "dashed" });
emit_line_chart!(
    &vec![
        serde_json::json!({ "name": "a(x)", "points": a_line }),
        serde_json::json!({ "name": "b(x)", "points": b_line }),
        serde_json::json!({ "name": "a（極限）", "points": a_limit, "style": dashed }),
        serde_json::json!({ "name": "b（極限）", "points": b_limit, "style": dashed }),
    ],
    options = &serde_json::json!({
        "link": { "group": "front-x" },
        "xLabel": "位置 x [mm]",
        "yLabel": "濃度 [mol/m³]",
        "xMin": 0.0,
        "xMax": 1.0,
        "annotations": front
    })
);
emit_line_chart!(
    &vec![serde_json::json!({ "name": "k a b", "points": rate_line })],
    options = &serde_json::json!({
        "link": { "group": "front-x" },
        "xLabel": "位置 x [mm]",
        "yLabel": "反応速度 k a b [mol/(m³·s)]",
        "xMin": 0.0,
        "xMax": 1.0,
        "annotations": front
    })
);

let (invariant_gap, limit_gap, centroid) = model.checks(&u);
let columns = serde_json::json!([
    { "key": "0", "label": "Da [-]", "type": "number", "format": sci3 },
    { "key": "1", "label": "重心 x_c [mm]", "type": "number", "format": fixed4 },
    { "key": "2", "label": "極限 x_f [mm]", "type": "number", "format": fixed4 },
```

既定の濃度では、反応帯の重心 $x_c=0.6663$ mm が極限の $x_f=0.6667$ mm から $3.4\times10^{-4}$ mm の位置にある。
極限の濃度との差の最大値は 0.108 mol/m³ で、反応帯の中で A と B が共存するぶんの差である。
不変量のずれは $5\times10^{-16}$ で、二つの場が丸めの水準で正しく連成している。
前のセルで $k=10^{-3}$（Da = 1）を選ぶと、二種は膜の全体で共存し、重心は膜の中央 0.5 mm の近くに移る。

## 反応の速さと反応帯の幅

次のセルは速度定数を $k=10^{-2}$ から $10^{1.5}$ m³/(mol·s) まで 0.5 桁ずつ変え（$\mathrm{Da}=10$ から $3.2\times10^4$）、作用素の表現と場ごとの前処理で定常解を求める。
グラフは極限の濃度との差の最大値を Da に対して両対数で描き、破線は傾き $-1/3$ の参照線（$\mathrm{Da}=10^3$ の点を通る）である。
表の最後の列は隣り合う二点から求めた傾き $\Delta\log(\text{差})/\Delta\log\mathrm{Da}$ である。
節点数を増やすと、大きな Da で反応帯を分解する点の数が増える。

```rust
//| id: pde-reaction-front-damkohler
//| ref: pde-reaction-front-damkohler
//| title: Damköhler 数と極限からの差の縮み方
//| run: button
//| uses: [pde-reaction-front-model]
//| crates: [scioxide-core, scioxide-linalg, scioxide-ode, scioxide-pde, scioxide-rootfind]
//| inputs:
//|   scan_nodes: {"type":"range","label":"内部の節点数 n [点]","description":"反応帯を分解する点の数を変える。","min":99,"max":399,"step":100,"value":199}
//| cases:
//|   - {"id":"coarse","label":"n = 99","description":"大きな Da では反応帯が数点にしか乗らず、傾きが −1/3 からずれる。","inputs":{"scan_nodes":99}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"scan","path":"/rows/0/6","equals":null}
//|       - {"artifact":"scan","path":"/rows/4/4","approx":{"value":0.1109,"rtol":1e-2}}
//|       - {"artifact":"scan","path":"/rows/5/6","range":{"min":-0.36,"max":-0.32}}
//|       - {"artifact":"scan","path":"/rows/7/6","range":{"min":-0.37,"max":-0.33}}
//|       - {"path":"/outputs/2/state","equals":"satisfied"}
//|   - case: coarse
//|     expect:
//|       - {"artifact":"scan","path":"/rows/7/6","range":{"min":-0.40,"max":-0.36}}
//|       - {"path":"/outputs/2/state","equals":"satisfied"}
use scioxide_core::{Preconditioner, ResidualTolerance};
use scioxide_pde::{
    NonlinearPdeProblem, PdeFieldLayout, PdeFieldPreconditioner, PdeJacobianMode,
};
use scioxide_rootfind::{NewtonKrylovOptions, NewtonKrylovProblem, NewtonKrylovSolver};

let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let fixed3 = serde_json::json!({ "fractionDigits": 3 });
let n = scan_nodes as usize;
let layout = PdeFieldLayout::new(&[n, n]).map_err(|e| e.to_string())?;
let mode = PdeJacobianMode::Operator {
    operator_scratch: 0,
};
let tolerance = ResidualTolerance::new(0.0, 1.0e-10).map_err(|e| e.to_string())?;
let solver =
    NewtonKrylovSolver::new(NewtonKrylovOptions::default().with_residual_tolerance(tolerance))
        .map_err(|e| e.to_string())?;
let mut rows = Vec::new();
let mut points = Vec::new();
let mut first_failure = None;
for step in 0..8 {
    let model = ReactionFront::new(n, 10.0_f64.powf(-2.0 + 0.5 * step as f64));
    let (inverse_a, inverse_b) = (model.diffusion_inverse(0), model.diffusion_inverse(1));
    let blocks: [&dyn Preconditioner<f64>; 2] = [&inverse_a, &inverse_b];
    let field_inverse =
        PdeFieldPreconditioner::new(&layout, &blocks).map_err(|e| e.to_string())?;
    let problem = NonlinearPdeProblem::new(&model, 0.0, &layout, &mode);
    let mut workspace = problem.workspace().map_err(|e| e.to_string())?;
    let residual = problem.bind(&mut workspace).map_err(|e| e.to_string())?;
    let newton =
        NewtonKrylovProblem::with_jacobian(&residual).with_preconditioner(&field_inverse);
    let result = solver
        .solve(&newton, &model.linear_profiles())
        .map_err(|e| e.to_string())?;
    if !result.is_success() && first_failure.is_none() {
        first_failure = Some(result.termination().to_string());
    }
    let (_, limit_gap, centroid) = model.checks(result.point());
    let damkohler = model.rate * 1.0e-6 / model.diffusivity[0];
    // 隣の点との傾き（最初の点では未定義）。
    let slope = points
        .last()
        .map(|&[d0, g0]: &[f64; 2]| (limit_gap / g0).ln() / (damkohler / d0).ln());
    points.push([damkohler, limit_gap]);
    rows.push((
        damkohler,
        result.termination().to_string(),
        result.iterations(),
        result.accounting().nested().iterations(),
        limit_gap,
        centroid * 1.0e3,
        slope,
    ));
}
// 傾き −1/3 の参照線（Da = 10³ の点を通る）。
let anchor = points[4][1];
let reference: Vec<[f64; 2]> = points
    .iter()
    .map(|&[d, _]| [d, anchor * (d / 1.0e3).powf(-1.0 / 3.0)])
    .collect();
emit_line_chart!(
    &vec![
        serde_json::json!({ "name": "極限との最大差", "points": points, "style": { "symbol": "circle" } }),
        serde_json::json!({ "name": "傾き −1/3", "points": reference, "style": { "lineType": "dashed" } }),
    ],
    options = &serde_json::json!({
        "xLabel": "Damköhler 数 Da [-]",
        "yLabel": "極限の濃度との最大差 [mol/m³]",
        "xType": "log",
        "yType": "log"
    })
);
let columns = serde_json::json!([
    { "key": "0", "label": "Da [-]", "type": "number", "format": sci3 },
    { "key": "1", "label": "終了理由" },
    { "key": "2", "label": "Newton 反復 [回]", "type": "integer" },
    { "key": "3", "label": "GMRES 反復 [回]", "type": "integer" },
    { "key": "4", "label": "極限との最大差 [mol/m³]", "type": "number", "format": sci3 },
    { "key": "5", "label": "重心 x_c [mm]", "type": "number", "format": fixed3 },
    { "key": "6", "label": "傾き [-]", "type": "number", "format": fixed3, "nullText": "—" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "scan" })
);
let outcome = if first_failure.is_none() {
    Outcome::satisfied("8 つの Da のすべてで残差の許容誤差を満たした")
} else {
    Outcome::partial("許容誤差を満たさずに止まった Da がある")
        .explanation("その行の差と傾きは定常解の値ではない。")
};
emit_outcome!(
    outcome
        .status(first_failure.unwrap_or_else(|| "ResidualTolerance".to_string()))
        .diagnostic("求解の数", rows.len() as f64, None)
);
```

既定の $n=199$ では、8 つの Da のすべてで `ResidualTolerance` に達し、Newton 法の反復は 5〜8 回だった。
Da が $10^{0.5}$ 倍になるごとに差はおよそ $10^{-1/6}\approx0.68$ 倍になり、Da = 100 から先の区間の傾きは −0.33〜−0.35 で、見積もりの −1/3 に近い。
Da = 10〜100 の傾き −0.26〜−0.31 は −1/3 より緩い。
このあたりでは見積もった帯の幅 $L\,\mathrm{Da}^{-1/3}$ が 0.2〜0.46 mm で、膜の厚さに比べて小さいという見積もりの前提が成り立たない。
$n=99$ では最大の Da で傾きが −0.375、$n=399$ では −0.343 になる。
最大の Da = $3.2\times10^4$ では帯の幅の見積もりが約 31 µm で、$n=99$ の格子幅 10 µm では帯に 3 点ほどしか乗らず、差分の誤差が傾きに混ざる。
反応帯の重心は Da = $10^4$ 以上で $x_f$ と 9 桁ほど一致する。

## まとめ

対向拡散の反応面は二つの場の残差を `OdeSystem` の右辺として書けば、`NonlinearPdeProblem` を通して Newton–Krylov 法で解ける。
ヤコビ行列の三つの表現は同じ反復の経過を与え、変わるのはメモリ領域とプロバイダーの呼び出しの回数だけなので、表現はメモリ領域の大きさとプロバイダーが書ける微分で選ぶ。
拡散の逆を場ごとに並べた前処理は、反応の結合を無視していても GMRES の反復を 1107 回から 43 回に減らした。
解は、$w=D_Aa-D_Bb$ が一次関数になる不変量で丸めの水準まで確かめられ、極限の濃度との差は大きな Da でほぼ Da の $-1/3$ 乗に比例して縮む。
大きな Da では反応帯の幅 $L\,\mathrm{Da}^{-1/3}$ を数点以上で分解できる節点数を選ぶ必要がある。
