駆動キャビティは正方形の容器の蓋だけを一定の速さで動かしたときに中にできる渦を調べる問題で、非圧縮流れの数値計算でよく使われる検算問題である。
この例題では粘性の大きい液体のゆっくりした流れを `StokesPlan`（Taylor–Hood P2/P1 要素）で解き、主渦の中心と流れ関数を格子の細分で確かめる。
厳密解は知られていないので、Stokes 流の対称性、細分による差、中心線を横切る流量を独立な検算に使う。
弱形式、inf-sup 条件、圧力のゲージは[非圧縮流れの混合有限要素](../../algorithms/incompressible-flow/)、鞍点系の前処理は[非圧縮流れの鞍点系の解法](../../algorithms/incompressible-solvers/)にある。

## 問題設定

容器は一辺 $L=10$ mm の正方形 $[0,L]^2$ で、蓋 $y=L$ が右向きに $U=5$ mm/s で動き、他の 3 辺は静止した壁である。
液体の粘性係数は $\mu=1.41$ Pa·s、密度は $\rho=1261$ kg/m³ とする（20 °C のグリセリンに近い値）。
Reynolds 数は $\mathrm{Re}=\rho UL/\mu\approx0.045$ で、慣性は粘性に比べて無視でき、定常 Stokes 方程式がよい近似になる。
体積力はなく、全境界で速度を与えるので、圧力の定数は既定のゲージ（面積平均 0）で決める。
Stokes 方程式は線形なので、速度は $U$ に比例し、圧力の尺度は $\mu U/L\approx0.71$ Pa である。

蓋と壁が出会う上の二つの角では、境界の速度が $U$ から 0 へ不連続に変わる。
この角の近くで圧力は角からの距離 $r$ に対して $1/r$ のように発散し、速度の勾配も有界でない。
有限要素の節点では角の速度をどちらかに決める必要があり、`TaggedBoundaries` に `DirichletConflictPolicy::LastConditionWins` を付けると、条件の列で後に置いた条件が角の節点の値になる。
既定では壁を後に置いて角の速度を 0 とし、境界から流体が出入りしない容器にする。

メッシュは $n\times n$ の正方形を同じ向きの対角線で 2 つの三角形に分けたもので、$n=4$ から 2 倍ずつ細かくする。
この対角線の向きのために、メッシュは $x=L/2$ について対称ではない。

## Plan と求解

次のセルは各格子でメッシュと境界条件から `StokesPlan` を準備し、`solve_with_options` で解く。
表には未知数、GMRES の反復回数、点ごとの発散の $L^2$ ノルム、離散的な連続の式の残り（弱形式の発散）、終了理由を並べ、中心線の P2 節点の速度を次のセルに渡す。
入力で、最も細かい格子、GMRES の真の残差の許容誤差、上の角の節点の速度を選べる。
計算は格子の数だけ繰り返すので、ボタンで実行し、同じ入力の結果は保存して再利用する。

```rust
//| id: pde-stokes-cavity-solve
//| ref: pde-stokes-cavity-solve
//| title: 格子を細かくしながら駆動キャビティの Stokes 流を解く
//| run: button
//| cache: inputs
//| timeoutMs: 60000
//| crates: [scioxide-pde, scioxide-spatial, scioxide-core, scioxide-linalg]
//| exports: [side, lid_speed, profiles]
//| inputs:
//|   finest: {"type":"select","label":"最も細かい格子 n [-]","description":"n = 4 から 2 倍ずつ、ここまで細かくする。","options":["8","16","32"],"value":"16"}
//|   tolerance: {"type":"select","label":"GMRES の真の残差の許容誤差","description":"既定の √ε で止めた解と、10⁻¹⁴ まで解いた解を比べる。","options":["√ε（既定）","10⁻¹⁴"],"value":"10⁻¹⁴"}
//|   corner: {"type":"select","label":"上の角の節点の速度","description":"蓋と壁が出会う角は速度が不連続で、どちらの値を節点に与えるかを選ぶ。","options":["壁の値 0","蓋の値 U"],"value":"壁の値 0"}
//| cases:
//|   - {"id":"loose","label":"許容誤差 √ε","description":"GMRES は 7 回で止まり、弱形式の発散は 10⁻⁹ m²/s 程度残る。","inputs":{"tolerance":"√ε（既定）"}}
//|   - {"id":"leaky","label":"角の速度 U","description":"容器が角から漏れ、点ごとの発散のノルムは 1.6 mm/s 程度になる。","inputs":{"corner":"蓋の値 U"}}
//|   - {"id":"fine","label":"n = 32 まで","description":"未知数 9,540 個でも GMRES は 19 回で止まる。","inputs":{"finest":"32"}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"solves","path":"/rows/2/1","equals":2468}
//|       - {"artifact":"solves","path":"/rows/2/2","range":{"min":15,"max":22}}
//|       - {"artifact":"solves","path":"/rows/2/3","approx":{"value":8.4753,"rtol":1e-3}}
//|       - {"artifact":"solves","path":"/rows/2/4","range":{"min":0,"max":1e-12}}
//|       - {"artifact":"solves","path":"/rows/2/5","equals":"Converged"}
//|       - {"path":"/outputs/1/state","equals":"satisfied"}
//|   - case: loose
//|     expect:
//|       - {"artifact":"solves","path":"/rows/2/2","range":{"min":1,"max":10}}
//|       - {"artifact":"solves","path":"/rows/2/4","range":{"min":1e-10,"max":1e-7}}
//|   - case: leaky
//|     expect:
//|       - {"artifact":"solves","path":"/rows/2/3","approx":{"value":1.5817,"rtol":1e-3}}
//|   - case: fine
//|     expect:
//|       - {"artifact":"solves","path":"/rows/3/1","equals":9540}
//|       - {"artifact":"solves","path":"/rows/3/2","range":{"min":15,"max":22}}
use scioxide_core::{LinearOperator, ResidualTolerance};
use scioxide_linalg::LinearSolveTermination;
use scioxide_pde::{
    BoundaryCondition, BoundaryData, BoundaryPoint, DirichletConflictPolicy,
    IncompressibleOptions, IncompressibleSolveOptions, SimplexFemGeometry, StokesPlan,
    TaggedBoundaries,
};
use scioxide_spatial::{Point, SimplexBoundaryTags, TriangleMesh};

// 一辺 L = 10 mm の正方形、蓋の速さ U = 5 mm/s、グリセリンに近い μ = 1.41 Pa·s、ρ = 1261 kg/m³。
let (side, lid_speed, viscosity, density) = (0.01_f64, 0.005_f64, 1.41_f64, 1261.0_f64);
let finest: usize = finest.parse().map_err(|_| "格子の数が読めない")?;
// 既定の真の残差の許容誤差 √ε と、代数誤差を離散化誤差より小さくする 10⁻¹⁴。
let options = if tolerance == "10⁻¹⁴" {
    let residual = ResidualTolerance::new(1e-14, 1e-14).map_err(|e| e.to_string())?;
    IncompressibleSolveOptions::new().with_residual(residual)
} else {
    IncompressibleSolveOptions::new()
};
let mut rows = Vec::new();
let mut profiles = Vec::new();
// 最初に成功しなかった格子の (終了理由, 破綻か)。
let mut first_failure: Option<(String, bool)> = None;
let mut n = 4_usize;
while n <= finest {
    let mut points = Vec::new();
    for j in 0..=n {
        for i in 0..=n {
            let point = [side * i as f64 / n as f64, side * j as f64 / n as f64];
            points.push(Point::new(point).map_err(|e| e.to_string())?);
        }
    }
    let mut triangles = Vec::new();
    for j in 0..n {
        for i in 0..n {
            let a = j * (n + 1) + i;
            triangles.push([a, a + 1, a + n + 2]);
            triangles.push([a, a + n + 2, a + n + 1]);
        }
    }
    let mesh = TriangleMesh::new(points, triangles).map_err(|e| e.to_string())?;
    // 面のタグ: 両端が最上段 (j = n) の頂点なら蓋 1、それ以外は壁 0。
    let mut faces = Vec::new();
    for face in mesh.boundary_faces() {
        let vertices = mesh.face_vertices(face).map_err(|e| e.to_string())?;
        faces.push((face, u32::from(vertices.iter().all(|&v| v / (n + 1) == n))));
    }
    let tags = SimplexBoundaryTags::new(&mesh, faces).map_err(|e| e.to_string())?;
    let lid_velocity = BoundaryData::time_invariant(move |p: BoundaryPoint<f64, 2>| {
        Ok(if p.component == 0 { lid_speed } else { 0.0 })
    });
    let lid = BoundaryCondition::dirichlet(1, lid_velocity);
    let wall = BoundaryCondition::dirichlet(0, BoundaryData::zero());
    // LastConditionWins では、後に並べた条件が両方に属する角の節点の値を決める。
    let conditions = if corner == "蓋の値 U" {
        vec![wall, lid]
    } else {
        vec![lid, wall]
    };
    let boundaries = TaggedBoundaries::new(&mesh, &tags, 2, conditions)
        .map_err(|e| e.to_string())?
        .with_dirichlet_conflict_policy(DirichletConflictPolicy::LastConditionWins);
    let plan = StokesPlan::with_options(
        mesh,
        SimplexFemGeometry::Affine,
        density,
        viscosity,
        &boundaries,
        &|_| Ok([0.0; 2]),
        IncompressibleOptions::new(),
    )
    .map_err(|e| e.to_string())?;
    let result = plan
        .solve_with_options(&options)
        .map_err(|e| e.to_string())?;
    let report = result.report();
    let status = format!("{:?}", report.termination());
    if !report.is_success() && first_failure.is_none() {
        let broken = matches!(report.termination(), LinearSolveTermination::Breakdown(_));
        first_failure = Some((status.clone(), broken));
    }
    let x = result.solution().as_slice();
    // 縦の中心線 x = L/2 の上の P2 節点 (y, u, v) を下から並べて渡す。
    let nodes = plan.velocity_nodes();
    let mut line = Vec::new();
    for i in 0..nodes {
        let point = plan.node_point(i).map_err(|e| e.to_string())?;
        if (point[0] - 0.5 * side).abs() < 1e-9 * side {
            line.push([point[1], x[i], x[nodes + i]]);
        }
    }
    line.sort_by(|a, b| a[0].total_cmp(&b[0]));
    let mut scratch = vec![0.0; plan.apply_workspace_len().map_err(|e| e.to_string())?];
    let diagnostics = plan
        .diagnostics(x, side, 0.0, &mut scratch)
        .map_err(|e| e.to_string())?;
    let divergence = diagnostics.divergence_l2() * 1e3;
    let weak = diagnostics.weak_divergence();
    rows.push((
        n,
        plan.unknowns(),
        report.iterations(),
        divergence,
        weak,
        status,
    ));
    profiles.push((n, line));
    n *= 2;
}
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let columns = serde_json::json!([
    { "key": "0", "label": "n [-]", "type": "integer" },
    { "key": "1", "label": "未知数 [-]", "type": "integer" },
    { "key": "2", "label": "GMRES の反復 [-]", "type": "integer" },
    { "key": "3", "label": "‖∇·u_h‖ [mm/s]", "type": "number", "format": sci3 },
    { "key": "4", "label": "弱形式の発散 [m²/s]", "type": "number", "format": sci3 },
    { "key": "5", "label": "終了理由" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "solves" })
);
let outcome = match first_failure {
    None => Outcome::satisfied("すべての格子で GMRES が許容誤差に達した").status("Converged"),
    Some((status, true)) => Outcome::failed("GMRES が破綻した格子がある").status(status),
    Some((status, false)) => Outcome::partial("上限で止まった格子がある").status(status),
};
emit_outcome!(outcome.diagnostic("最も細かい格子 n", finest as f64, None));
export!(side, &side);
export!(lid_speed, &lid_speed);
export!(profiles, &profiles);
```

既定（許容誤差 $10^{-14}$、角の速度 0）では、GMRES の反復は $n=4,8,16$ で 17、18、19 回、$n=32$ でも 19 回で、未知数が 188 個から 9,540 個に増えてもほとんど変わらない。
弱形式の発散は $4\times10^{-15}$〜$8\times10^{-15}$ m²/s で、離散的な連続の式は許容誤差どおりに満たされる。
一方、点ごとの発散の $L^2$ ノルム $\|\nabla\cdot u_h\|$ は、どの格子でも 8.45〜8.48 mm/s でほとんど変わらない。
角の要素では速度が幅 $h$ の間に $U$ から 0 まで変わるので、勾配は $U/h$、面積は $h^2$ の程度で、勾配の $L^2$ ノルムへの寄与は $h$ に依らず $U$ の程度になる。
滑らかな解で成り立つ $O(h^2)$ の減少は、角の特異性のためにこの量には現れない。
許容誤差を既定の $\sqrt{\varepsilon}$ にすると、GMRES は 7 回で止まり、弱形式の発散は $10^{-9}$ m²/s の程度残る。

## 主渦の中心と流れ関数の求め方

Stokes 方程式では解を $x=L/2$ について鏡映し、さらに全体の符号を反転すると、同じ境界条件を満たす解になる（蓋の速度は鏡映で $-U$ になり、符号の反転で $U$ に戻る）。
解は一意なので、$u$ は $x=L/2$ について対称、$v$ は反対称で、中心線上では $v(L/2,y)=0$ である。
したがって主渦の中心（$u=v=0$ になる点）は中心線上にあり、中心線で $u$ が 0 になる高さ $y_c$ として求められる。
慣性があると鏡映の対称性は崩れ、渦の中心は蓋の動く向きへずれる。

中心線は縦の辺の連なりで、P2 の速度は各辺の上で 3 つの節点（両端と中点）を通る 2 次式になる。
蓋の側で $u>0$、中心の下で $u<0$ になるので、$u$ が正から負へ変わる辺の 2 次式に二分法を使って $y_c$ を求める。
流れ関数 $\psi$（$u=\partial\psi/\partial y$、$v=-\partial\psi/\partial x$、壁で $\psi=0$）の中心での値は $\psi(L/2,y_c)=\int_0^{y_c}u(L/2,y)\,dy$ で、2 次式を正確に積分して求める。
同じ積分を蓋まで延ばした $Q=\int_0^Lu(L/2,y)\,dy$ は中心線を横切る正味の流量で、閉じた容器の厳密解では 0 になる。
Taylor–Hood の速度は離散的な連続の式だけを満たすので、$Q$ は 0 にならず、細分とともに減るかを確かめる。
中心の $|v_h(L/2,y_c)|$ は、対称でないメッシュが生む対称性からのずれを示す。

次のセルは、最初のセルが渡す中心線の節点の値から、格子ごとに $y_c$、$\psi(L/2,y_c)$、中心の $|v_h|$、$|Q|$ を求めて表にし、中心線の速度を格子ごとに重ねて描く。
図の縦の破線は最も細かい格子の $y_c$ である。

```rust
//| id: pde-stokes-cavity-centre
//| ref: pde-stokes-cavity-centre
//| title: 中心線の速度から主渦の中心、流れ関数、流量を求める
//| run: reactive
//| crates: [scioxide-core]
//| dependsOn:
//|   solve: pde-stokes-cavity-solve
//| inputs:
//|   component: {"type":"select","label":"図に描く速度の成分","description":"横の成分 u は渦の形を、縦の成分 v は対称性からのずれを示す。","options":["u","v"],"value":"u"}
//| cases:
//|   - {"id":"vertical","label":"縦の成分 v","description":"中心線の v/U の最大は n = 4 の 1.5 × 10⁻² から n = 16 の 1.2 × 10⁻⁴ へ減る。","inputs":{"component":"v"}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"centre","path":"/rows/2/1","approx":{"value":7.6512785,"rtol":1e-6}}
//|       - {"artifact":"centre","path":"/rows/2/2","approx":{"value":-5.0011227,"rtol":1e-6}}
//|       - {"artifact":"centre","path":"/rows/2/4","range":{"min":0,"max":1e-3}}
//|       - {"artifact":"profile","path":"/spec/series/2/points/16/1","approx":{"value":-0.2050542,"rtol":1e-5}}
//|   - case: vertical
//|     expect:
//|       - {"artifact":"profile","path":"/spec/series/0/points/7/1","approx":{"value":0.0145766,"rtol":1e-4}}
//|       - {"artifact":"profile","path":"/spec/series/2/points/30/1","range":{"min":-2e-4,"max":2e-4}}
let side = solve["side"].as_f64().ok_or("一辺がない")?;
let lid_speed = solve["lid_speed"].as_f64().ok_or("蓋の速さがない")?;
let profiles: Vec<(usize, Vec<[f64; 3]>)> =
    serde_json::from_value(solve["profiles"].clone()).map_err(|e| e.to_string())?;
// 中心線は縦の辺でできていて、P2 の速度は各辺の上で 3 節点を通る 2 次式になる。
// q(s) = c₀ + c₁ s + c₂ s² (s ∈ [0, 1]) の係数、値、0 から s までの積分。
let quadratic = |q: [f64; 3]| {
    [
        q[0],
        -3.0 * q[0] + 4.0 * q[1] - q[2],
        2.0 * (q[0] - 2.0 * q[1] + q[2]),
    ]
};
let value = |c: [f64; 3], s: f64| c[0] + s * (c[1] + s * c[2]);
let integral = |c: [f64; 3], s: f64| s * (c[0] + s * (c[1] / 2.0 + s * c[2] / 3.0));
let mut rows = Vec::new();
let mut centre = 0.0;
for (n, line) in &profiles {
    let (mut flux, mut found) = (0.0_f64, None);
    for k in (0..line.len() - 1).step_by(2) {
        let (lower, upper) = (line[k], line[k + 2]);
        let h = upper[0] - lower[0];
        let u = quadratic([lower[1], line[k + 1][1], upper[1]]);
        let v = quadratic([lower[2], line[k + 1][2], upper[2]]);
        // 下端で負、上端で正になる辺に主渦の中心がある。二分法で u = 0 の位置を求める。
        if lower[1] < 0.0 && upper[1] > 0.0 {
            let (mut a, mut b) = (0.0_f64, 1.0_f64);
            for _ in 0..60 {
                let m = 0.5 * (a + b);
                if value(u, m) < 0.0 { a = m } else { b = m }
            }
            let s = 0.5 * (a + b);
            found = Some((lower[0] + s * h, flux + h * integral(u, s), value(v, s)));
        }
        // ψ と Q は 2 次式の正確な積分（Simpson 則）で積み上げる。
        flux += h * integral(u, 1.0);
    }
    let (yc, psi, vc) = found.ok_or("中心線に u の符号の変化がない")?;
    centre = yc;
    rows.push((*n, yc * 1e3, psi * 1e6, vc.abs() * 1e3, flux.abs() * 1e6));
}
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let digits6 = serde_json::json!({ "significantDigits": 6 });
let columns = serde_json::json!([
    { "key": "0", "label": "n [-]", "type": "integer" },
    { "key": "1", "label": "主渦の中心 y_c [mm]", "type": "number", "format": digits6 },
    { "key": "2", "label": "流れ関数 ψ(L/2, y_c) [mm²/s]", "type": "number", "format": digits6 },
    { "key": "3", "label": "中心の |v_h| [mm/s]", "type": "number", "format": sci3 },
    { "key": "4", "label": "中心線の流量 |Q| [mm²/s]", "type": "number", "format": sci3 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "centre" })
);
// 中心線の速度の節点の値を格子ごとに重ね、最も細かい格子の y_c を縦の破線で示す。
let index = if component == "u" { 1 } else { 2 };
let symbol = serde_json::json!({ "showSymbol": true });
let mut series = Vec::new();
for (n, line) in &profiles {
    let points: Vec<[f64; 2]> = line
        .iter()
        .map(|p| [p[0] * 1e3, p[index] / lid_speed])
        .collect();
    let name = format!("n = {n}");
    series.push(serde_json::json!({ "name": name, "points": points, "style": symbol }));
}
let dashed = serde_json::json!({ "lineType": "dashed" });
let annotations = serde_json::json!([
    { "kind": "line", "axis": "x", "value": centre * 1e3, "label": "y_c", "style": dashed }
]);
emit_chart!(
    serde_json::json!({
        "kind": "line",
        "dataZoom": true,
        "tooltip": true,
        "series": series,
        "xLabel": "高さ y [mm]",
        "yLabel": format!("{component} / U [-]"),
        "xMin": 0.0,
        "xMax": side * 1e3,
        "annotations": annotations
    }),
    metadata = serde_json::json!({ "id": "profile" })
);
```

既定では、$y_c$ は $n=4,8,16$ で 7.6041、7.6462、7.6513 mm で、差は 0.042 mm から 0.0051 mm に縮んだ。
最も細かい格子を $n=32$ にすると $y_c=7.6503$ mm で、$n=16$ との差は 0.001 mm（$L$ の $10^{-4}$）である。
流れ関数の中心の値は −4.692、−4.968、−5.001 mm²/s（$n=32$ で −5.004 mm²/s）と収束し、$UL=50$ mm²/s で割ると $\psi_c/(UL)\approx-0.1001$ になる。
中心線の流量 $|Q|$ は 0.33、0.021、$2.0\times10^{-4}$ mm²/s（$n=32$ で $1.1\times10^{-5}$ mm²/s）と速く減る。
中心の一点の $|v_h|$ は $n\ge8$ で $U$ の $1.2\times10^{-4}$ 倍以下になるが、単調には減らない。

横の成分 $u/U$ は、蓋の直下で 1 から急に下がり、$y_c$ で符号を変え、最小値 $-0.21$ を経て下の壁で 0 に戻る。
同じ高さの節点で $n=16$ の値と比べると、差の最大は $n=4$ で $0.028$、$n=8$ で $0.0035$ で、主渦の形は粗い格子でもおおむねとらえられる。
縦の成分 $v/U$ を選ぶと、中心線上の最大の大きさは $n=4,8,16$ で $1.5\times10^{-2}$、$1.0\times10^{-3}$、$1.2\times10^{-4}$ と減り、対称な厳密解の $v=0$ に近づく。

最初のセルで許容誤差を $\sqrt{\varepsilon}$ にしてこのセルを読み直すと、$n=16$ の $|Q|$ は $3.0\times10^{-3}$ mm²/s で、$10^{-14}$ まで解いた $2.0\times10^{-4}$ mm²/s の 15 倍になり、$y_c$ も $3.9\times10^{-4}$ mm ずれる。
相対の許容誤差は右辺のノルムに対して測るので、細分で小さな差を比べるときは代数誤差が差より小さくなるまで締める。

角の節点の速度を蓋の値 $U$ にすると、壁の最上段の辺で法線方向の速度が 0 でなくなり、容器は角から漏れる。
この辺の P2 の速度は角で $U$、中点と下端で 0 なので、漏れる流量は Simpson 則で正確に $Uh/6$ である。
このとき $|Q|$ は 2.17、1.05、0.52 mm²/s で、$Uh/6=2.08$、1.04、0.52 mm²/s に近づく。
$y_c$ も 7.156、7.451、7.556 mm と、角の速度 0 の場合よりゆっくり近づき、点ごとの発散のノルムは 1.55〜1.59 mm/s になる。
角の扱いは幅 $h$ の範囲の境界条件の違いで、細分とともに消えるが、粗い格子では渦の位置を目に見えるほど変える。

## まとめ

Stokes 駆動キャビティでは、解の鏡映の対称性から主渦の中心が中心線上にあり、中心線の P2 の 2 次式から中心の高さと流れ関数を正確な積分で求められる。
$10^{-14}$ まで解くと、中心の高さは $n=16$ と $32$ で $L$ の $10^{-4}$ の差に収まり、中心線の流量は細分とともに速く減る。
点ごとの発散の $L^2$ ノルムは角の特異性のために減らないので、これを精度の指標にせず、離散的な連続の式と内部の量で収束を判断する。
既定の許容誤差 $\sqrt{\varepsilon}$ では細かい格子の差が代数誤差に埋もれるので、細分の比較では許容誤差を締める。
角の節点に蓋の速度を与えると容器が $Uh/6$ だけ漏れるので、流量を問う計算では角の速度を壁の値にする。
