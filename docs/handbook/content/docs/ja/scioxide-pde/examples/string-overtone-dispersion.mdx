理想的な弦の倍音の振動数は基本振動数の整数倍で、この関係が弦楽器の音色を決める。
空間格子で弦を離散化すると、高い倍音ほど振動数がずれ、整数倍の関係が崩れる。
[張られた弦の波を位相と音程から読む](../fixed-string-wave/)では、時間積分の誤差が小さく、数値解が半離散系の解に従うことを確かめた。
したがって、格子が倍音をどれだけずらすかは、半離散系の固有振動数だけで決まる。

このページでは P1 要素の剛性行列と質量行列の一般化固有値から半離散系の振動数を求め、音程のずれをセントで表す。
質量行列の作り方（集中質量・整合質量・その平均）で、ずれの向きと大きさがどう変わるかを閉形式と比べる。

## 半離散系の固有振動数

長さ $L$ [m]、波の速さ $c$ [m/s] の弦を $J$ 個の等しい要素（$h = L/J$）に分ける。
P1 要素の Galerkin 法は内部の節点の値 $\mathbf u(t)$ に対する半離散系

$$
M\ddot{\mathbf u} + K\mathbf u = 0
$$

を作る。
$K$ は剛性行列で、内部の行は $(c^2/h)(-1, 2, -1)$ である。
$M$ は質量行列で、基底関数の積の積分から得る整合質量の行は $(h/6)(1, 4, 1)$ である。
各行の和を対角に置いた集中質量は $h$ の対角行列になり、このとき半離散系は三点差分と同じになる。

$\mathbf u(t) = \hat{\mathbf u}\cos(\omega t)$ を代入すると、一般化固有値問題 $K\hat{\mathbf u} = \omega^2 M\hat{\mathbf u}$ が得られる。
離散の正弦 $\hat u_j = \sin(m\pi x_j/L)$ は両方の質量で固有ベクトルになり、$\theta_m = m\pi h/(2L) = m\pi/(2J)$ とおくと

$$
\frac{\omega_{h,m}}{\omega_m} =
\begin{cases}
\dfrac{\sin\theta_m}{\theta_m} & \text{集中質量} \\[2ex]
\dfrac{\sin\theta_m}{\theta_m}\sqrt{\dfrac{3}{3 - 2\sin^2\theta_m}} & \text{整合質量} \\[2ex]
\dfrac{\sin\theta_m}{\theta_m}\sqrt{\dfrac{3}{3 - \sin^2\theta_m}} & \text{平均した質量 } (M_{\mathrm L} + M_{\mathrm C})/2
\end{cases}
$$

である。
$\omega_m = m\pi c/L$ は連続の角周波数である。
$\theta_m$ が小さいとき、集中質量の比は $1 - \theta_m^2/6$、整合質量の比は $1 + \theta_m^2/6$ に近い。
集中質量は倍音を低く、整合質量は高くずらし、二つを平均すると $\theta_m^2$ の項が打ち消し合う。
平均した質量の誤差は $O(\theta_m^4)$ になる。

$\theta_m = \pi/n_\lambda$ の $n_\lambda = 2J/m$ は一波長あたりの要素数である。
音程の差はセント（1 オクターブが 1200 セント、半音が 100 セント）で

$$
\Delta C_m = 1200\log_2\frac{\omega_{h,m}}{\omega_m}
$$

と表す。
集中質量では $\Delta C_m \approx -1200\,\theta_m^2/(6\ln 2) \approx -2847/n_\lambda^2$ セントになる。

## 剛性行列と質量行列の取り出し

`SimplexFemPlan` は、要素の行列から次の三つを作る。

- `assemble_csr()`: Dirichlet 境界の節点の行と列を単位行列に置き換えた剛性行列の CSR である。
- `assemble_mass_csr()`: 境界の消去をしない整合質量の CSR である。
- `lumped_mass()`: 節点ごとの正の集中質量である。
  P1 では整合質量の行和に等しく、P2 では対角成分を尺度変換する HRZ 法で作る。

境界の節点の値は 0 に固定されるので、`constrained()` が偽の自由な節点の行と列だけを取り出して $K_{ff}$、$M_{ff}$ とする。
単位行列に置き換えた行を残したまま一般化固有値を求めると、境界の行が見かけの固有値を作る。
固有値は scioxide-linalg の `GeneralizedHermitianEigenvaluesResult::compute` で求める。
この関数は $M$ の Cholesky 分解で標準形 $L^{-1}KL^{-\top}$ に還元し、すべての固有値を昇順に返す。
計算量は自由度 $n$ に対して $O(n^3)$ である（[一般化固有値問題](../../../scioxide-linalg/algorithms/generalized-eigenproblems/)）。

## 倍音の音程のずれ

次のセルは長さ $L = 0.65$ m、$c = 143$ m/s（基本振動数 110 Hz）の弦を $J$ 個の P1 要素に分け、第 1〜32 倍音の振動数を三つの質量行列で求める。
入力は要素数 $J$ と、表に取り出す倍音の番号 $m$ である。
出力は倍音の番号に対する音程の差の図、選んだ倍音の振動数と音程の差の表、閉形式との相対差の表である。
閉形式は独立な検算で、一般化固有値と丸めの範囲で一致すれば、上の式どおりの離散化が組み立てられていることを確かめられる。

```rust
//| id: pde-string-overtone-dispersion
//| ref: pde-string-overtone-dispersion
//| title: 質量行列ごとに倍音の音程のずれを求める
//| run: reactive
//| crates: [scioxide-core, scioxide-linalg, scioxide-pde, scioxide-spatial]
//| inputs:
//|   string_grid_intervals: {"type":"range","label":"要素数 J [-]","description":"一波長あたりの要素数 2J/m を変える。","min":40,"max":160,"step":8,"value":64}
//|   string_selected_overtone: {"type":"range","label":"表に取り出す倍音 m [-]","description":"表の行と図の縦線の位置を選ぶ。","min":1,"max":32,"step":1,"value":12}
//| cases:
//|   - {"id":"fine-grid","label":"J = 160","description":"第 12 倍音は一波長 26.7 要素になり、集中質量の音程の差は −4.0 セントに縮む。","inputs":{"string_grid_intervals":160}}
//|   - {"id":"highest-overtone","label":"第 32 倍音","description":"一波長 4 要素では集中質量が −182 セント、平均した質量でも数セントずれる。","inputs":{"string_selected_overtone":32}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"selected","path":"/rows/0/1","approx":{"value":10.666667,"rtol":1e-6}}
//|       - {"artifact":"selected","path":"/rows/0/4","approx":{"value":-25.101965,"rtol":1e-6}}
//|       - {"artifact":"check","path":"/rows/0/1","range":{"max":1e-10}}
//|       - {"artifact":"check","path":"/rows/1/1","range":{"max":1e-10}}
//|       - {"artifact":"check","path":"/rows/2/1","range":{"max":1e-10}}
//|   - case: fine-grid
//|     expect:
//|       - {"artifact":"selected","path":"/rows/0/4","approx":{"value":-4.0065251,"rtol":1e-6}}
//|   - case: highest-overtone
//|     expect:
//|       - {"artifact":"selected","path":"/rows/0/4","approx":{"value":-181.79536,"rtol":1e-6}}
use scioxide_core::RealScalar;
use scioxide_linalg::{GeneralizedHermitianEigenvaluesResult, HermitianInput, Matrix};
use scioxide_pde::{
    BoundaryData, BoundaryKind, ConstantDiffusion, SimplexFemGeometry, SimplexFemOrder,
    SimplexFemPlan, SpatialDiscretization, TaggedBoundaries,
};
use scioxide_spatial::{IntervalMesh, Point};
use std::f64::consts::PI;

// 長さ L = 0.65 m、c = 143 m/s（基本振動数 110 Hz）の弦を J 個の P1 要素に分ける。
let (length, c) = (0.65, 143.0);
let (intervals, selected) = (
    string_grid_intervals as usize,
    string_selected_overtone as usize,
);
let h = length / intervals as f64;
let points = (0..=intervals)
    .map(|i| Point::new([i as f64 * h]))
    .collect::<Result<Vec<_>, _>>()
    .map_err(|e| e.to_string())?;
let cells = (0..intervals).map(|i| [i, i + 1]).collect();
let mesh = IntervalMesh::new(points, cells).map_err(|e| e.to_string())?;
let fixed = TaggedBoundaries::<f64, f64, 1>::uniform(
    &mesh,
    1,
    BoundaryKind::Dirichlet,
    BoundaryData::zero(),
)
.map_err(|e| e.to_string())?;
// 拡散係数に c² を渡すと、剛性行列は c²∫u'v' になる。
let plan = SimplexFemPlan::new(
    mesh,
    SimplexFemGeometry::Affine,
    SimplexFemOrder::P1,
    &ConstantDiffusion::new(c * c),
    &fixed,
)
.map_err(|e| e.to_string())?;
let stiffness = plan.assemble_csr().map_err(|e| e.to_string())?;
let mass = plan.assemble_mass_csr().map_err(|e| e.to_string())?;
// 自由な節点の番号を詰め直し、K_ff、整合質量、集中質量、平均した質量の密行列を作る。
let free: Vec<usize> = (0..plan.unknowns())
    .filter(|&i| !plan.constrained()[i])
    .collect();
let n = free.len();
let position = |i: usize| free.iter().position(|&f| f == i);
let (mut k, mut consistent) = (vec![0.0; n * n], vec![0.0; n * n]);
for (target, matrix) in [(&mut k, &stiffness), (&mut consistent, &mass)] {
    for (row, col, value) in matrix.iter() {
        if let (Some(i), Some(j)) = (position(row), position(col)) {
            target[i * n + j] = value;
        }
    }
}
let mut lumped = vec![0.0; n * n];
for (i, &node) in free.iter().enumerate() {
    lumped[i * n + i] = plan.lumped_mass()[node];
}
let average: Vec<f64> = consistent
    .iter()
    .zip(&lumped)
    .map(|(a, b)| 0.5 * (a + b))
    .collect();
let stiffness = Matrix::from_vec(n, n, k).map_err(|e| e.to_string())?;
let mut frequencies = Vec::new();
for m in [lumped, consistent, average] {
    let m = Matrix::from_vec(n, n, m).map_err(|e| e.to_string())?;
    let exact = HermitianInput::Exact;
    let values = GeneralizedHermitianEigenvaluesResult::compute(&stiffness, &m, exact, exact)
        .map_err(|e| e.to_string())?;
    // 固有値 ω² の平方根を 2π で割った振動数 [Hz]、低い順。
    let hertz: Vec<f64> = values.eigenvalues()[..32]
        .iter()
        .map(|&w2| RealScalar::sqrt(w2) / (2.0 * PI))
        .collect();
    frequencies.push(hertz);
}
let names = ["集中質量", "整合質量", "平均した質量"];
// 閉形式の比 ω_h/ω（独立な検算、θ = mπ/(2J)）。
let ratio = |method: usize, m: usize| {
    let theta = m as f64 * PI / (2.0 * intervals as f64);
    let s2 = RealScalar::powi(RealScalar::sin(theta), 2);
    let base = RealScalar::sin(theta) / theta;
    match method {
        0 => base,
        1 => base * RealScalar::sqrt(3.0 / (3.0 - 2.0 * s2)),
        _ => base * RealScalar::sqrt(3.0 / (3.0 - s2)),
    }
};
let fundamental = c / (2.0 * length);
let cents = |f: f64, m: usize| 1200.0 * RealScalar::log2(f / (m as f64 * fundamental));
let mut series = Vec::new();
let mut check = Vec::new();
for (method, (name, hertz)) in names.iter().zip(&frequencies).enumerate() {
    let points: Vec<[f64; 2]> = (1..=32)
        .map(|m| [m as f64, cents(hertz[m - 1], m)])
        .collect();
    let deviation = (1..=32)
        .map(|m| (hertz[m - 1] / (m as f64 * fundamental * ratio(method, m)) - 1.0).abs())
        .fold(0.0_f64, f64::max);
    series.push(
        serde_json::json!({ "name": name, "style": { "symbol": "circle" }, "points": points }),
    );
    check.push((name.to_string(), deviation));
}
let mark = serde_json::json!([
    { "kind": "line", "axis": "x", "value": selected as f64, "label": "表の倍音" },
    { "kind": "line", "axis": "y", "value": 0.0, "label": "整数倍の音程" }
]);
emit_line_chart!(
    &series,
    options = &serde_json::json!({
        "xLabel": "倍音の番号 m [-]",
        "yLabel": "音程の差 ΔC [cent]",
        "annotations": mark
    })
);
let fixed2 = serde_json::json!({ "fractionDigits": 2 });
let fixed3 = serde_json::json!({ "fractionDigits": 3 });
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let columns = serde_json::json!([
    { "key": "0", "label": "倍音 m [-]", "type": "integer" },
    { "key": "1", "label": "一波長の要素数 [-]", "type": "number", "format": fixed2 },
    { "key": "2", "label": "整数倍の振動数 [Hz]", "type": "number", "format": fixed2 },
    { "key": "3", "label": "集中質量 [Hz]", "type": "number", "format": fixed3 },
    { "key": "4", "label": "集中質量 [cent]", "type": "number", "format": fixed2 },
    { "key": "5", "label": "整合質量 [cent]", "type": "number", "format": fixed2 },
    { "key": "6", "label": "平均した質量 [cent]", "type": "number", "format": fixed3 }
]);
let row = (
    selected,
    2.0 * intervals as f64 / selected as f64,
    selected as f64 * fundamental,
    frequencies[0][selected - 1],
    cents(frequencies[0][selected - 1], selected),
    cents(frequencies[1][selected - 1], selected),
    cents(frequencies[2][selected - 1], selected),
);
emit_table_with_columns!(
    columns,
    vec![row],
    metadata = serde_json::json!({ "id": "selected" })
);
let check_columns = serde_json::json!([
    { "key": "0", "label": "質量行列" },
    { "key": "1", "label": "閉形式との最大相対差 [-]", "type": "number", "format": sci2 }
]);
emit_table_with_columns!(
    check_columns,
    check,
    metadata = serde_json::json!({ "id": "check" })
);
```

既定（$J = 64$）では、第 12 倍音（一波長 10.67 要素）の振動数が集中質量で 1301.00 Hz になり、整数倍の 1320 Hz より 25.1 セント低い。
整合質量では同じ倍音が 24.9 セント高く、平均した質量では $-0.44$ セントにとどまる。
三つの質量行列とも、一般化固有値から求めた振動数と閉形式の相対差は $1.2 \times 10^{-13}$ 以下で、丸めの範囲で一致する。

図の三つの系列は、倍音の番号が上がるほど 0 から離れる。
集中質量は下へ、整合質量は上へほぼ対称に離れ、平均した質量は高い倍音までほぼ 0 に沿う。
$J = 160$ にすると第 12 倍音（一波長 26.7 要素）の集中質量の差は $-4.0$ セントに縮み、比は $25.1/4.0 = 6.3 \approx (160/64)^2$ で二次の収束である。
平均した質量の差は $-0.44$ から $-0.011$ セントへ約 40 分の 1 に縮み、$(160/64)^4 = 39$ に近い四次の収束を示す。
第 32 倍音（一波長 4 要素）では、集中質量が $-182$ セント、整合質量が $+169$ セント、平均した質量でも $-24$ セントずれる。

## 格子の目安

集中質量の近似式 $\Delta C \approx -2847/n_\lambda^2$ から、音程の差を $|\Delta C|$ セント以下にするには、一波長あたり $n_\lambda \ge \sqrt{2847/|\Delta C|}$ 個の要素が要る。
5 セント以下なら 24 要素、1 セント以下なら 54 要素である。
関心のある最も高い倍音について、この数の要素を一波長に置く。

`HyperbolicProblem` は集中質量で半離散系を組み立てるので、[固定端弦のモードの追跡](oxref:pde-string-mode-comparison)の倍音は集中質量の列のとおり低くずれる。
`HyperbolicProblem` と線の方法の Plan（`MethodOfLinesPlan`）は対角の質量だけを扱い、整合質量や平均した質量の半離散系を時間積分する選択肢は持たない。

## まとめ

P1 要素の剛性行列と質量行列の一般化固有値から、半離散系の倍音の振動数を求め、閉形式で検算できる。
集中質量は倍音を低く、整合質量は高くずらし、ずれは一波長あたりの要素数の二乗に反比例する。
二つの質量を平均すると $\theta^2$ の項が打ち消し合い、ずれは四次で縮む。
倍音の音程を $|\Delta C|$ セント以内に保つには、最も高い倍音の一波長に集中質量で $\sqrt{2847/|\Delta C|}$ 個以上の要素を置く。
