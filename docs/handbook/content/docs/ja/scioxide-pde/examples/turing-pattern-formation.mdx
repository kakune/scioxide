[Turing 不安定性の分散関係と離散モード](../turing-reaction-diffusion/)では、正方形の上の Schnakenberg 系で、どの波数の揺らぎがどれだけの速さで育つかを線形解析で求めた。
このページは同じ系を 2 次元で時間積分して模様を作り、その予測を確かめる。
確かめるのは、摂動が小さい段階の成長率、育った模様の支配的な波数、そして $d<d_c$ で摂動が減衰することの三つである。

パラメータは前のページとそろえ、供給速度 $a=0.1$、$b=0.9$、拡散係数 $D_u=1$、$D_v=d$、一様定常解 $(u^*,v^*)=(1,\,0.9)$ とする。
分散関係 $\operatorname{Re}\lambda(k)$ は[分散関係](oxref:pde-turing-dispersion)の節、臨界拡散比 $d_c\approx8.5676$ と臨界波数 $k_c\approx0.5845$ は[臨界拡散比と臨界波数](oxref:pde-turing-critical-ratio)の節で定義した。
$d=20$ で最も速く育つ波数は $k_{\max}\approx0.4867$、格子の離散モードの成長率は $\operatorname{Re}\lambda_h=\operatorname{Re}\lambda(k_h)$ である。
量はすべて無次元である。

## 半離散系と質量の正規化

空間を `StructuredFdmPlan` で離散化すると、頂点の値 $\mathbf{y}=[\mathbf{u};\mathbf{v}]$（成分ごとにまとめた順）は次の半離散系に従う。

$$
M\dot{\mathbf{y}} = -A\mathbf{y} + M\,\mathbf{R}(\mathbf{y}), \qquad \mathbf{R}(\mathbf{y})=\bigl(f(u_i,v_i)\bigr)_i \oplus \bigl(g(u_i,v_i)\bigr)_i
$$

$A$ は Plan の作用素（`LinearOperator::apply_into`）、$M$ は集中質量（`SpatialDiscretization::lumped_mass`）で、反応は頂点ごとの値から計算する。
空間を先に離散化し、常微分方程式系として時間積分するこの方法を、線の方法（method of lines）と呼ぶ（[線の方法と半離散系](../../algorithms/method-of-lines-and-nonlinear/)）。

`ParabolicProblem` は線形の $M\dot{\mathbf{u}}=\mathbf{b}(t)-A\mathbf{u}$ だけを積分するので、非線形の反応を持つこの系には使えない。
代わりに右辺 $\mathbf{F}(\mathbf{y})=-A\mathbf{y}+M\mathbf{R}(\mathbf{y})$ を単位質量の `OdeSystem` として書き、`MethodOfLinesPlan` に渡す。
ここではクロージャから `OdeSystem` を作る `scioxide-ode` の `OdeFn` を使う。
`MethodOfLinesPlan::new(dimension, mass, scales)` は正の対角質量 $M$ と場の尺度 $D$（`None` は単位行列）を検査する。
`bind` は `OdeSystem` を借用して、$\dot{\mathbf{z}}=M^{-1}D^{-1}\mathbf{F}(D\mathbf{z})$ を表す `MethodOfLinesSystem` を返す。
`encode_into` と `decode_into` は物理の値 $\mathbf{y}$ と正規化した状態 $\mathbf{z}=D^{-1}\mathbf{y}$ を変換し、`error_tolerance` は物理の絶対許容誤差を正規化した座標へ移す。
ここでは $D$ を単位行列にするので、正規化は質量での割り算だけである。

次の定義のブロックは反応項の係数、2 成分の差分 Plan、連続と離散の分散関係を、このページの 3 つのセルで共有する。
中身は[Turing 不安定性の分散関係と離散モード](../turing-reaction-diffusion/)の定義と同じで、反応項の供給速度と一様定常解を加えてある。
格子の刻みは $h=1$ に固定し、一辺に $L+1$ 個の頂点を置く。
`StructuredFdmCoefficients::diffusion` は軸と成分ごとの拡散係数を返し、成分 0 が $u$、成分 1 が $v$ である。
`BoundaryCondition::natural` は外向きの余法線流束 $\mathbf{n}\cdot D\nabla u$ を与える条件で、成分を指定しなければ両成分に掛かる。

```rust
//| id: pde-turing-formation-model
//| kind: definitions
//| title: Schnakenberg 系の係数、2 成分の差分 Plan、分散関係
//| crates: [scioxide-core, scioxide-pde, scioxide-spatial]
use scioxide_core::{SciOxideError, RealScalar};
use scioxide_pde::{
    BoundaryCondition, BoundaryData, StructuredBoundaries, StructuredFdmCoefficients,
    StructuredFdmPlan,
};
use scioxide_spatial::{AxisSide, AxisTopology, BoundarySet, CoordinateAxis, Grid2d, QuadMesh};

/// 供給速度 a、b。
pub(crate) const SUPPLY: [f64; 2] = [0.1, 0.9];
/// 一様定常解 (u*, v*) = (a + b, b/(a + b)²)。
pub(crate) const STEADY: [f64; 2] = [1.0, 0.9];
/// (u*, v*) でのヤコビ行列 J₀ = [[f_u, f_v], [g_u, g_v]]。
pub(crate) const JACOBIAN: [[f64; 2]; 2] = [[0.8, 1.0], [-1.8, -1.0]];

/// 拡散係数 D_u = 1、D_v = d。成分 0 が u、成分 1 が v で、両軸とも同じ値。
pub(crate) struct Diffusion {
    pub(crate) ratio: f64,
}
impl StructuredFdmCoefficients<f64, f64, 2> for Diffusion {
    fn diffusion(&self, _: usize, component: usize, _: [f64; 2]) -> Result<f64, SciOxideError> {
        Ok([1.0, self.ratio][component])
    }
}

/// [0, L]² を刻み h = 1 の頂点格子にし、2 成分とも 4 辺で外向きの流束を 0 にする。
pub(crate) fn turing_plan(
    length: usize,
    ratio: f64,
) -> Result<StructuredFdmPlan<f64, f64, 2>, SciOxideError> {
    let axis = CoordinateAxis::uniform(0.0, length as f64, length + 1)?;
    let grid = Grid2d::new([axis.clone(), axis], [AxisTopology::Bounded; 2])?;
    let mesh = QuadMesh::new(grid)?;
    let mut conditions = Vec::new();
    for axis in 0..2 {
        for side in [AxisSide::Start, AxisSide::End] {
            let region = BoundarySet::axis_side(&mesh, axis, side)?;
            conditions.push(BoundaryCondition::natural(region, BoundaryData::zero()));
        }
    }
    let boundaries = StructuredBoundaries::new(&mesh, 2, conditions)?;
    StructuredFdmPlan::new(mesh, &Diffusion { ratio }, &boundaries)
}

/// J₀ − κ diag(1, d) の固有値の最大実部。κ は連続の k² か離散の k_h²。
pub(crate) fn growth_rate(kappa: f64, ratio: f64) -> f64 {
    let [[fu, fv], [gu, gv]] = JACOBIAN;
    let trace = fu + gv - (1.0 + ratio) * kappa;
    let det = (fu - kappa) * (gv - ratio * kappa) - fv * gu;
    let disc = trace * trace - 4.0 * det;
    if disc >= 0.0 {
        0.5 * (trace + RealScalar::sqrt(disc))
    } else {
        0.5 * trace
    }
}

/// 刻み h = 1 の格子で、1 軸のモード番号 m が離散の波数の 2 乗に寄与する 4 sin²(mπ/2L)。
pub(crate) fn axis_wavenumber2(mode: usize, length: usize) -> f64 {
    let s = RealScalar::sin(mode as f64 * core::f64::consts::PI / (2.0 * length as f64));
    4.0 * s * s
}

/// (m_x, m_y) ≠ (0, 0) の全モードの (m_x, m_y, Re λ_h)。
pub(crate) fn discrete_modes(length: usize, ratio: f64) -> Vec<(usize, usize, f64)> {
    let mut modes = Vec::new();
    for my in 0..=length {
        for mx in 0..=length {
            if mx + my > 0 {
                let kh2 = axis_wavenumber2(mx, length) + axis_wavenumber2(my, length);
                modes.push((mx, my, growth_rate(kh2, ratio)));
            }
        }
    }
    modes
}

/// 不安定帯の端 [k₁, k₂]。h の 2 根 k² = (s ∓ √(s² − 4d det J₀))/(2d)、s = d f_u + g_v。
pub(crate) fn unstable_band(ratio: f64) -> Option<[f64; 2]> {
    let [[fu, fv], [gu, gv]] = JACOBIAN;
    let slope = ratio * fu + gv;
    let disc = slope * slope - 4.0 * ratio * (fu * gv - fv * gu);
    (slope > 0.0 && disc > 0.0).then(|| {
        let s = RealScalar::sqrt(disc);
        [(slope - s) / (2.0 * ratio), (slope + s) / (2.0 * ratio)].map(RealScalar::sqrt)
    })
}

/// 連続系の最速成長の波数 k_max を 0 < k ≤ 1.5 の刻み 10⁻⁴ の走査で求める。
pub(crate) fn fastest_wavenumber(ratio: f64) -> f64 {
    (1..=15_000)
        .map(|i| 1e-4 * i as f64)
        .max_by(|a, b| growth_rate(a * a, ratio).total_cmp(&growth_rate(b * b, ratio)))
        .unwrap_or(0.0)
}
```

## 剛性と Rosenbrock-W 法

$d=20$、$h=1$ では、$v$ の拡散の $M^{-1}A$ の固有値は最大で $8d/h^2=160$ になる。
陽的な古典的 4 段 Runge–Kutta 法（RK4）の実軸上の安定区間は約 $2.79$ なので、時間刻みは $\Delta t\lesssim2.79/160\approx0.017$ に制限され、$t=100$ まで約 5700 ステップが要る。
一方、模様が育つ時間の尺度は $1/\operatorname{Re}\lambda\approx4$ なので、精度だけを考えれば $0.017$ よりずっと大きい刻みで足りる。
精度ではなく安定性が刻みを決めるこの性質を剛性と呼び、陰的な方法を使う理由になる。

`scioxide-ode` の `RosenbrockW` は線形陰的な Rosenbrock-W 法である。
各段で $I-\Delta t\,\gamma J$（$\gamma$ は方法の対角係数、$J$ は $\partial\mathbf{F}/\partial\mathbf{z}$ の近似）を係数とする連立一次方程式を 1 回解き、Newton 反復を行わない。
W 法なので $J$ が近似でも次数を保つ。
`RosenbrockMethod::Ros34Pw2` は Rang と Angermann の 4 段 3 次の係数で、厳密なヤコビ行列を使えば L 安定である。
`RosenbrockW` は単位質量の系だけを受け付けるので、質量で割る `MethodOfLinesPlan` を間に置く。

段の連立方程式は `OdeStageBackend::Sparse` で疎 LU 分解を使って解く。
ヤコビ行列の非零の位置は拡散の 2 つの対角ブロック（`assemble_csr` が返す $A$ の構造）と、同じ頂点の $u_i$ と $v_i$ を結ぶ反応の 2 本の対角線である。
この構造を `MethodOfLinesPlan::with_jacobian_pattern` と疎 LU の段の両方に渡す。
`SparseLuLimits::new(max_factor_entries, max_workspace_bytes)` は、分解の非零の個数と作業領域のバイト数の上限である。
`OdeFn` はヤコビ行列を返さないので、`RosenbrockW` は構造の列を彩色した差分で $J$ を近似する。
時間の偏微分 $\partial\mathbf{F}/\partial t$ も返さないので時刻の差分で求めるが、右辺は時刻に依らないので、その差分は 0 になる。

## 積分の実行

次のセルは一辺 $L=32$（$33\times33$ 頂点、未知数 2178）の正方形で、一様定常解の両成分に振幅 $10^{-3}$ の一様乱数の摂動を加え、$t=100$ まで積分する。
相対許容誤差は $10^{-4}$、絶対許容誤差は $10^{-6}$ である。
入力は拡散係数比 $d$ と乱数のシードである。
`OdeOutputSchedule::times` で $t=2,4,\dots,100$ の連続出力（各ステップの 3 次 Hermite 補間）を受け取り、摂動の大きさ $\|\mathbf{u}-u^*\|_{\mathrm{RMS}}=\bigl(\frac{1}{N}\sum_i(u_i-u^*)^2\bigr)^{1/2}$（$N$ は頂点数）を記録する。
`OdeSolveReport` を `PdeSolveReport::try_from` で PDE のレポートに変換し、終了理由 `PdeTermination` を outcome にする。
`Completed` なら satisfied、時間刻みや評価の上限、実行の停止で止まったときは最後に受理した時刻の場を渡して partial にする。
ODE の失敗は終了理由にならず、エラーとして返る。
後の 2 つのセルが使うよう、摂動の大きさの記録と、$t=20$ と $t=100$ の $u$ を渡す。

```rust
//| id: pde-turing-pattern
//| ref: pde-turing-pattern
//| title: 2 成分の差分 Plan と線の方法、Rosenbrock-W 法で 2 次元の Schnakenberg 系を積分する
//| run: button
//| timeoutMs: 120000
//| cache: inputs
//| uses: [pde-turing-formation-model]
//| crates: [scioxide-core, scioxide-linalg, scioxide-ode, scioxide-pde, scioxide-random, scioxide-sparse, scioxide-spatial]
//| exports: [ratio, domain_length, early_time, history, early, last]
//| inputs:
//|   ratio: {"type":"range","label":"拡散係数比 d = D_v/D_u [-]","description":"d_c ≈ 8.57 より小さいと摂動は減衰し、模様は生じない。","min":6,"max":30,"step":1,"value":20}
//|   seed: {"type":"range","label":"乱数のシード [-]","description":"初期の摂動を選ぶ。","min":1,"max":20,"step":1,"value":1}
//| cases:
//|   - {"id":"below-critical","label":"d = 8 < d_c","description":"摂動は減衰し、u は一様定常解 1 に戻る。","inputs":{"ratio":8}}
//|   - {"id":"other-seed","label":"シード 2","description":"斑点の配置は変わるが、摂動の大きさの時間変化はほとんど同じになる。","inputs":{"seed":2}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"path":"/outputs/0/state","equals":"satisfied"}
//|   - case: below-critical
//|     expect:
//|       - {"path":"/outputs/0/state","equals":"satisfied"}
//|   - case: other-seed
//|     expect:
//|       - {"path":"/outputs/0/state","equals":"satisfied"}
use scioxide_core::{
    ErrorTolerance, ExecutionContext, SciOxideError, LinearOperator, NormSelection, RealScalar,
    StructuralPattern,
};
use scioxide_linalg::Vector;
use scioxide_ode::{
    OdeFn, OdeMethod, OdeOptions, OdeOutputSchedule, OdeProblem, OdeStageBackend, OdeState,
    RosenbrockMethod, RosenbrockW,
};
use scioxide_pde::{MethodOfLinesPlan, PdeSolveReport, SpatialDiscretization};
use scioxide_random::{Rng, SeedableRng, SplitMix64};
use scioxide_sparse::SparseLuLimits;
use std::cell::RefCell;

let (length, early_time, final_time) = (32_usize, 20.0, 100.0);
let plan = turing_plan(length, ratio).map_err(|e| e.to_string())?;
let nodes = plan.unknowns() / 2;
// ヤコビ行列の構造: A の 2 つの対角ブロックに、u_i と v_i を結ぶ反応の項を加える。
let csr = plan.assemble_csr().map_err(|e| e.to_string())?;
let (mut row_ptr, mut cols) = (vec![0], Vec::with_capacity(csr.nnz() + 2 * nodes));
for row in 0..2 * nodes {
    if row >= nodes {
        cols.push(row - nodes);
    }
    cols.extend_from_slice(&csr.col_indices()[csr.row_ptr()[row]..csr.row_ptr()[row + 1]]);
    if row < nodes {
        cols.push(row + nodes);
    }
    row_ptr.push(cols.len());
}
let pattern =
    StructuralPattern::new(2 * nodes, 2 * nodes, row_ptr, cols).map_err(|e| e.to_string())?;
let mol = MethodOfLinesPlan::new(2 * nodes, Some(plan.lumped_mass()), None)
    .and_then(|mol| mol.with_jacobian_pattern(pattern.clone()))
    .map_err(|e| e.to_string())?;
// 物理の右辺 F(y) = −A y + M R(y)。M での割り算は MethodOfLinesPlan が受け持つ。
let (mass, [a, b]) = (plan.lumped_mass(), SUPPLY);
let scratch = RefCell::new(vec![
    0.0;
    plan.apply_workspace_len().map_err(|e| e.to_string())?
]);
let rhs = |_: f64, y: &[f64], out: &mut [f64]| -> Result<(), SciOxideError> {
    plan.apply_into(y, out, &mut scratch.borrow_mut())?;
    let (u, v) = y.split_at(nodes);
    for i in 0..nodes {
        let uuv = u[i] * u[i] * v[i];
        out[i] = mass[i] * (a - u[i] + uuv) - out[i];
        out[nodes + i] = mass[nodes + i] * (b - uuv) - out[nodes + i];
    }
    Ok(())
};
let model = OdeFn::new(2 * nodes, rhs).map_err(|e| e.to_string())?;
let mut mol_workspace = mol.workspace().map_err(|e| e.to_string())?;
let system = mol
    .bind(&model, &mut mol_workspace)
    .map_err(|e| e.to_string())?;
// 初期値: 一様定常解に振幅 10⁻³ の一様乱数の摂動を加える（成分順 [u, v]）。
let mut rng = SplitMix64::from_seed(seed as u64);
let mut physical = Vec::with_capacity(2 * nodes);
for steady in STEADY {
    for _ in 0..nodes {
        let r: f64 = rng.next_float().map_err(|e| e.to_string())?;
        physical.push(steady + 1e-3 * (2.0 * r - 1.0));
    }
}
let mut initial = vec![0.0; 2 * nodes];
mol.encode_into(&physical, &mut initial)
    .map_err(|e| e.to_string())?;
let solver = RosenbrockW::<f64>::new(RosenbrockMethod::Ros34Pw2)
    .map_err(|e| e.to_string())?
    .with_backend(OdeStageBackend::Sparse {
        pattern,
        limits: SparseLuLimits::new(1 << 20, 1 << 28),
    });
let tolerance = ErrorTolerance::scalar(1e-6, 1e-4, NormSelection::RootMeanSquare)
    .and_then(|tolerance| mol.error_tolerance(&tolerance))
    .map_err(|e| e.to_string())?;
let times: Vec<f64> = (1..=50).map(|i| 2.0 * i as f64).collect();
let options = OdeOptions::new()
    .with_error_tolerance(tolerance)
    .with_output_schedule(OdeOutputSchedule::times(times));
let problem = OdeProblem::new(&system, final_time);
let mut workspace = solver
    .workspace(&problem, &options)
    .map_err(|e| e.to_string())?;
// 摂動の大きさ ‖u − u*‖_RMS を出力の時刻ごとに記録し、t = 20 の u を残す。
let rms = |u: &[f64]| {
    let sum: f64 = u.iter().map(|u| (u - STEADY[0]) * (u - STEADY[0])).sum();
    RealScalar::sqrt(sum / u.len() as f64)
};
let (mut history, mut field) = (vec![[0.0, rms(&physical[..nodes])]], vec![0.0; 2 * nodes]);
let mut early = Vec::new();
let mut state = OdeState::new(0.0, Vector::from_vec(initial));
let raw = solver
    .advance(
        &problem,
        &options,
        &mut state,
        &mut |t: f64, z: &[f64]| {
            mol.decode_into(z, &mut field)?;
            history.push([t, rms(&field[..nodes])]);
            if t == early_time {
                early = field[..nodes].to_vec();
            }
            Ok(())
        },
        &mut workspace,
        ExecutionContext::sequential(),
    )
    .map_err(|e| e.to_string())?;
let report = PdeSolveReport::try_from(&raw).map_err(|e| e.to_string())?;
mol.decode_into(state.values(), &mut field)
    .map_err(|e| e.to_string())?;
export!(ratio, &ratio);
export!(domain_length, &length);
export!(early_time, &early_time);
export!(history, &history);
export!(early, &early);
export!(last, &field[..nodes].to_vec());
let diagnostics = report.diagnostics();
let outcome = if report.is_success() {
    Outcome::satisfied("t = 100 まで時間積分が完了した")
} else {
    Outcome::partial("t = 100 に達する前に時間積分が止まった")
        .explanation("渡した場は最後に受理した時刻のもので、t = 100 の状態ではない。")
};
let steps = |n: usize| n as f64;
emit_outcome!(
    outcome
        .status(report.termination().to_string())
        .diagnostic("到達時刻", report.final_time(), None)
        .diagnostic(
            "受理したステップ",
            steps(diagnostics.num_accepted_steps()),
            None
        )
        .diagnostic(
            "棄却したステップ",
            steps(diagnostics.num_rejected_steps()),
            None
        )
        .diagnostic("LU 分解", steps(diagnostics.num_factorizations()), None)
);
```

既定値（$d=20$、シード 1）では、積分は `Completed` で $t=100$ に達し、受理したステップは 87、棄却は 2、疎 LU 分解は 87 回だった。
Rosenbrock-W 法は分解に現在の刻みを使うので、分解の回数は受理したステップの数とほぼ同じになる。
陽的な RK4 の安定性の制限（約 5700 ステップ）と比べると、ステップの数は 60 分の 1 程度である。
$d=8$ では摂動がすぐ小さくなり、受理したステップは 23 だった。

## 模様の形と成長の段階

次のセルは上のセルの結果から、$t=100$ の $u$ の heatmap と、摂動の大きさの時間変化を描く。
時間変化のグラフの点が実測、破線が線形理論である。
破線は成長率が最大の離散モードの $e^{\operatorname{Re}\lambda_h t}$ を $t=20$ の実測値に合わせたもので、1 を超える部分は描かない。
線形の段階では実測がこの傾きに沿い、摂動が 1 に近づくと非線形の項が効いて飽和する。
表は $t=10$ から $t=20$ までの実測の対数の傾きと、$\operatorname{Re}\lambda_h$ の最大値である。

その後は直線的に増え、$t=10$ から $t=20$ までの傾きは $0.247$ で、離散モードの最大の成長率 $0.2632$ より少し小さい。
摂動は最大に近い成長率を持つ多くのモードの和なので、その対数の傾きはそれらの成長率を重み付けた平均に近くなり、最大値を下回る。
$t\approx30$ を過ぎると実測は破線から離れ、$t=40$ で $0.678$、$t=50$ 以降は $0.75$〜$0.76$ でほぼ一定になる。

上のセルで $d=8$ にすると、摂動の大きさは $t=100$ で $4.3\times10^{-6}$ まで減る。
$t=90$ から $t=100$ までの傾きは $-0.029$ で、最も遅く減衰する離散モードの $\operatorname{Re}\lambda_h=-0.0272$ に近い。
$d<d_c$ ではすべてのモードが減衰するという線形解析の結論と合う。

## DCT による支配モードの解析

頂点の余弦モードは DCT-I の基底なので、`scioxide-fft` の `dctn` で $u-\bar u$（$\bar u$ は頂点の平均）の 2 次元 DCT-I を取ると、各モード $(m_x,m_y)$ の振幅 $c_{m_x,m_y}$ が得られる。
`Normalization::Inverse` の順変換は尺度を掛けない次の和である（$x_j$ は 1 軸に並ぶ $L+1$ 個の値）。

$$
X_{m}=x_0+(-1)^{m}x_{L}+2\sum_{j=1}^{L-1}x_j\cos\frac{\pi jm}{L}
$$

$x_j=c\cos(\pi jm/L)$ を代入すると $X_m=cLw_m$（$w_0=w_L=2$、それ以外は $w_m=1$）なので、2 次元の振幅は $c_{m_x,m_y}=X_{m_x,m_y}/(L^2w_{m_x}w_{m_y})$ である。
`dctn` は FFT を使い、頂点数 $n$ に対して $O(n\log n)$ の演算で計算する。

次のセルは $t=20$ と $t=100$ の $u$ について、$|c|$ が最大のモード（支配モード）とその波数 $k=\pi\sqrt{m_x^2+m_y^2}/L$、そのモードの $\operatorname{Re}\lambda_h$ を表にする。
もう一つの比べ方として、$s=\operatorname{round}(\sqrt{m_x^2+m_y^2})$ が同じモードを一つの殻にまとめ、殻ごとの $c^2$ の和を求める。
グラフはその和を殻の波数 $\pi s/L$ に対して対数の縦軸で描き、$k_{\max}$ を縦線、不安定帯を範囲で示す。
殻の幅は $\pi/L\approx0.098$ なので、波数はこの精度でしか比べられない。

```rust
//| id: pde-turing-spectrum
//| ref: pde-turing-spectrum
//| title: DCT-I で支配モードの波数を求め、最速成長の波数と比べる
//| run: button
//| uses: [pde-turing-formation-model]
//| crates: [scioxide-core, scioxide-fft]
//| dependsOn:
//|   pattern: pde-turing-pattern
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"modes","path":"/rows/0/0","equals":"t = 20"}
//|       - {"artifact":"modes","path":"/rows/0/4","range":{"min":0.45,"max":0.56}}
//|       - {"artifact":"modes","path":"/rows/0/6","approx":{"value":0.4908738521234052,"rtol":1e-12}}
//|       - {"artifact":"modes","path":"/rows/1/4","range":{"min":0.45,"max":0.7}}
use scioxide_core::RealScalar;
use scioxide_fft::{DctType, Normalization, dctn};
use std::f64::consts::PI;

let fixed4 = serde_json::json!({ "fractionDigits": 4 });
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let get = |key: &str| pattern[key].clone();
let ratio: f64 = serde_json::from_value(get("ratio")).map_err(|e| e.to_string())?;
let length: usize = serde_json::from_value(get("domain_length")).map_err(|e| e.to_string())?;
let early_time: f64 = serde_json::from_value(get("early_time")).map_err(|e| e.to_string())?;
let early: Vec<f64> = serde_json::from_value(get("early")).map_err(|e| e.to_string())?;
let last: Vec<f64> = serde_json::from_value(get("last")).map_err(|e| e.to_string())?;
let (side, size) = (length + 1, length as f64);
let weight = |m: usize| if m == 0 || m == length { 2.0 } else { 1.0 };
// 振幅 c = X / (L² w_x w_y)。殻 s = round(|m|) ごとに c² を足し、|c| が最大のモードを選ぶ。
let analyse = |u: &[f64]| -> Result<((usize, usize, f64), Vec<[f64; 2]>), String> {
    let mean = u.iter().sum::<f64>() / u.len() as f64;
    let centred: Vec<f64> = u.iter().map(|u| u - mean).collect();
    let types = [DctType::I; 2];
    let transform = dctn(
        &centred,
        &[side, side],
        &[0, 1],
        &types,
        Normalization::Inverse,
    )
    .map_err(|e| e.to_string())?;
    let (mut shells, mut dominant) = (vec![0.0; 2 * side], (0, 0, 0.0_f64));
    for my in 0..side {
        for mx in 0..side {
            let c = transform[my * side + mx] / (size * size * weight(mx) * weight(my));
            let s = RealScalar::round(RealScalar::sqrt((mx * mx + my * my) as f64)) as usize;
            shells[s] += c * c;
            if mx + my > 0 && c.abs() > dominant.2 {
                dominant = (mx, my, c.abs());
            }
        }
    }
    let spectrum = (1..side)
        .filter(|&s| shells[s] > 0.0)
        .map(|s| [PI * s as f64 / size, shells[s]])
        .collect();
    Ok((dominant, spectrum))
};
let (mut rows, mut layers) = (Vec::new(), Vec::new());
for (time, u) in [(early_time, &early), (100.0, &last)] {
    let ((mx, my, amplitude), spectrum) = analyse(u)?;
    let kh2 = axis_wavenumber2(mx, length) + axis_wavenumber2(my, length);
    let peak = spectrum.iter().fold(
        [0.0, 0.0],
        |b: [f64; 2], p| if p[1] > b[1] { *p } else { b },
    );
    let k = PI * RealScalar::sqrt((mx * mx + my * my) as f64) / size;
    let label = format!("t = {time}");
    let rate = growth_rate(kh2, ratio);
    rows.push((label.clone(), mx, my, amplitude, k, rate, peak[0]));
    layers.push(
        serde_json::json!({ "id": label, "kind": "line", "name": label, "points": spectrum }),
    );
}
let columns = serde_json::json!([
    { "key": "0", "label": "時刻" },
    { "key": "1", "label": "支配モード m_x", "type": "integer" },
    { "key": "2", "label": "支配モード m_y", "type": "integer" },
    { "key": "3", "label": "振幅 |c| [-]", "type": "number", "format": sci3 },
    { "key": "4", "label": "支配モードの波数 k [-]", "type": "number", "format": fixed4 },
    { "key": "5", "label": "そのモードの Re λ_h [-]", "type": "number", "format": fixed4 },
    { "key": "6", "label": "c² の和が最大の殻の波数 [-]", "type": "number", "format": fixed4 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "modes" })
);
let k_max = fastest_wavenumber(ratio);
let mut annotations =
    vec![serde_json::json!({ "kind": "line", "axis": "x", "value": k_max, "label": "k_max" })];
if let Some([low, high]) = unstable_band(ratio) {
    let band = serde_json::json!({ "kind": "range", "axis": "x", "from": low, "to": high });
    annotations.push(band);
}
emit_chart!(
    serde_json::json!({
        "kind": "xy",
        "xLabel": "殻の波数 π s / L [-]",
        "yLabel": "殻ごとの振幅の 2 乗和 Σ c² [-]",
        "yType": "log",
        "dataZoom": true,
        "tooltip": true,
        "annotations": annotations,
        "layers": layers
    }),
    metadata = serde_json::json!({ "id": "spectrum" })
);
```

既定値では、$t=20$ の支配モードは $(5,1)$（$k=0.5006$、$\operatorname{Re}\lambda_h=0.2629$）で、$c^2$ の和が最大の殻は $s=5$（$k=0.4909$）である。
この殻は $k_{\max}=0.4867$ と成長率が最大の離散モード $(5,0)$ を含み、線形の段階の模様の波数は殻の幅の精度で $k_{\max}$ と一致する。
支配モードが $(5,1)$ になったのは、その成長率が最大値と $3\times10^{-4}$ しか違わず、$t=20$ までには振幅にほとんど差がつかないためである。
どのモードが勝つかは初期の乱数の振幅で決まる。
$t=20$ のグラフでは、不安定帯の外の殻は帯の中の殻より何桁も小さく、最も波数の大きい殻は $10^{-25}$ 程度まで減衰している。

$t=100$ の支配モードは $(5,3)$（$k=0.5725$）、最大の殻は $s=6$（$k=0.5890$）で、どちらも $k_{\max}$ より大きい。
シードを 2 から 5 に変えて同じ計算をすると、$t=20$ の最大の殻はどれも $s=5$ だったが、$t=100$ の支配モードの波数は $0.50$ から $0.66$ に散らばった。
線形解析が予測するのは、摂動が小さい段階で育つ波長の目安である。
振幅が飽和したあとの斑点の間隔は非線形の項と初期値にも依存し、$k_{\max}$ だけでは決まらない。

## まとめ

非線形の反応を持つ反応拡散系は、`StructuredFdmPlan` の作用素と集中質量で右辺 $-A\mathbf{y}+M\mathbf{R}(\mathbf{y})$ を書き、`MethodOfLinesPlan` で質量を正規化して、`RosenbrockW` と疎 LU の段で積分できる。
拡散の剛性のため陽的な方法は刻みが安定性で制限されるが、Rosenbrock-W 法は $d=20$ の既定値を 87 ステップで $t=100$ まで進めた。
摂動の成長率は線形の段階で離散モードの最大の $\operatorname{Re}\lambda_h$ に近く、$d<d_c$ では最も遅く減衰する離散モードの減衰率に近い割合で減る。
DCT-I で求めた支配モードの波数は、線形の段階では殻の幅の精度で $k_{\max}$ と一致するが、飽和した模様では $k_{\max}$ からずれ、初期値によっても変わる。
模様の波長を見積もるときは分散関係を目安にし、実際の配置と間隔は時間積分で確かめる。
