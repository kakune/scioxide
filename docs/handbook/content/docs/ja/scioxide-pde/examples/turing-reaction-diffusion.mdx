2 種類の物質が反応しながら異なる速さで拡散すると、拡散がなければ安定な一様状態が、ある波長の空間的な揺らぎに対して不安定になることがある。
これを拡散誘導不安定性（Turing 不安定性）と呼び、育った揺らぎは縞や斑点の模様（Turing パターン）になる。
このページは正方形の上の Schnakenberg 系について、どの波数の揺らぎがどれだけの速さで育つかを分散関係で求め、有限の格子で実際に現れる離散のモードを数える。
その予測を 2 次元の時間発展と比べる計算は[Turing パターンの 2 次元の形成](../turing-pattern-formation/)にある。

パラメータは[反応拡散系の Turing 分岐](../../../applications/reaction-diffusion/)とそろえ、供給速度 $a=0.1$、$b=0.9$、拡散係数 $D_u=1$、$D_v=d$ とする。
応用のページは臨界拡散比の求根と単一モードの成長率の実測を扱う。
このページは 2 次元の正方形での分散関係と、差分 Plan の離散モードを扱う。
量はすべて無次元である。

## Schnakenberg 系と零流束の境界

正方形 $\Omega=[0,L]^2$ の上で、活性化因子の濃度 $u(x,y,t)$ と抑制因子の濃度 $v(x,y,t)$ は次の反応拡散系に従う。

$$
\partial_t u = D_u \Delta u + f(u,v), \qquad \partial_t v = D_v \Delta v + g(u,v), \qquad f = a - u + u^2 v, \quad g = b - u^2 v
$$

境界では両成分とも外向きの流束を 0 にする（$\mathbf{n}\cdot D_u\nabla u=\mathbf{n}\cdot D_v\nabla v=0$、$\mathbf{n}$ は外向きの単位法線）。
物質は境界から出入りせず、総量を変えるのは反応だけである。

反応項が 0 になる一様定常解は $u^*=a+b=1$、$v^*=b/(a+b)^2=0.9$ であり、そこでのヤコビ行列は次のとおりである。

$$
\mathbf{J}_0=\begin{pmatrix} f_u & f_v \\ g_u & g_v \end{pmatrix}=\begin{pmatrix} 0.8 & 1 \\ -1.8 & -1 \end{pmatrix}, \qquad \operatorname{tr}\mathbf{J}_0=-0.2, \quad \det\mathbf{J}_0=1
$$

跡が負で行列式が正なので、拡散がなければ一様定常解は漸近安定である。
$f_u>0$ は $u$ の自己触媒、$g_v<0$ は $v$ の消費を表す。

## 分散関係

一様定常解からのずれ $(\delta u,\delta v)$ の線形化方程式に、零流束の条件を満たす余弦モード

$$
(\delta u,\delta v) = \mathbf{w}\, e^{\lambda t}\cos(k_x x)\cos(k_y y), \qquad k_x=\frac{m_x\pi}{L},\quad k_y=\frac{m_y\pi}{L},\quad m_x,m_y=0,1,2,\dots
$$

を代入すると、成長率 $\lambda$ は $2\times2$ 行列 $\mathbf{J}_k=\mathbf{J}_0-k^2\operatorname{diag}(D_u,D_v)$ の固有値になる。
ここで $\mathbf{w}$ は 2 成分の振幅、$k^2=k_x^2+k_y^2$ であり、成長率は波数ベクトルの向きに依らず大きさ $k$ だけで決まる。
2 つの固有値のうち実部の大きい方を $\operatorname{Re}\lambda(k)$ と書き、これを分散関係と呼ぶ。

$$
\operatorname{Re}\lambda(k)=\frac{1}{2}\left(\tau+\operatorname{Re}\sqrt{\tau^2-4h}\right), \qquad \tau=\operatorname{tr}\mathbf{J}_0-(D_u+D_v)k^2, \quad h=D_uD_vk^4-(D_vf_u+D_ug_v)k^2+\det\mathbf{J}_0
$$

$\tau=\operatorname{tr}\mathbf{J}_k$ はどの $k$ でも負なので、$\operatorname{Re}\lambda(k)>0$ となるのは $h=\det\mathbf{J}_k<0$ のときに限る。
$h<0$ となる波数の範囲を不安定帯と呼び、その中で $\operatorname{Re}\lambda$ が最大になる波数を最速成長の波数 $k_{\max}$ と書く。
$\tau$ も $k$ とともに変わるので、$k_{\max}$ は $h$ を最小にする $k^2=(D_vf_u+D_ug_v)/(2D_uD_v)$ とは一致しない。

## 臨界拡散比と臨界波数

$h$ の最小値がちょうど 0 になる拡散係数比を臨界拡散比 $d_c$ と呼び、そのとき $h=0$ となる波数を臨界波数 $k_c$ と呼ぶ。
$D_u=1$ のとき、両者は次の閉形式で与えられる。

$$
d_c=\left(\frac{\sqrt{\det\mathbf{J}_0}+\sqrt{\det\mathbf{J}_0-f_ug_v}}{f_u}\right)^2\approx 8.5676, \qquad k_c^2=\sqrt{\frac{\det\mathbf{J}_0}{d_c}}\approx 0.3416,\quad k_c\approx 0.5845
$$

この式の導出と、$d_c$ を求根で求めて閉形式と照合する計算は[反応拡散系の Turing 分岐](../../../applications/reaction-diffusion/)にある。

$k_c$ は $d=d_c$ で最初に不安定になる波数で、$d>d_c$ で最も速く育つ波数 $k_{\max}$ とは別の量である。
$d=20$ では不安定帯が $k\in(0.2720,\,0.8222)$（$k^2\in(0.0740,\,0.6760)$）に開き、$k_{\max}\approx0.4867$ で $\operatorname{Re}\lambda\approx0.2632$ になる。
このとき $k_{\max}<k_c$ である。
$d<d_c$ ではどの $k$ でも $\operatorname{Re}\lambda<0$ で、すべてのモードが減衰する。

## 離散の Neumann モード

有限の正方形では、波数は $k=\pi\sqrt{m_x^2+m_y^2}/L$ の離散的な値しか取らない。
領域が小さいと不安定帯に入るモードがなく、$d>d_c$ でも模様は生じない。

`StructuredFdmPlan` は頂点に値を置く保存形の差分である。
各頂点の集中質量は双対コントロールボリュームの面積で、境界の頂点では内部の半分、角では 4 分の 1 になる。
この重みのため、格子幅 $h$ の一様格子では $M^{-1}A$（$A$ は拡散の作用素、$M$ は集中質量の対角行列）の境界の行が、鏡映の虚点を置いた中心差分と一致する。
したがって頂点の余弦 $\cos(m_x\pi x_i/L)\cos(m_y\pi y_j/L)$（$m_x,m_y=0,\dots,L/h$）は $M^{-1}A$ の固有ベクトルであり、拡散係数 1 に対する固有値は次の $k_h^2$ である。

$$
k_h^2=\frac{4}{h^2}\left(\sin^2\frac{m_x\pi h}{2L}+\sin^2\frac{m_y\pi h}{2L}\right)
$$

半離散系を線形化した成長率は、分散関係の $k$ を離散の波数 $k_h$ に置き換えた $\operatorname{Re}\lambda_h=\operatorname{Re}\lambda(k_h)$ になる。
$k_h<k$ なので、名目の波数 $k$ の位置に描いた離散モードの成長率は、連続の曲線を $k$ より左の $k_h$ で読んだ値になり、そのずれ $k-k_h$ は波数が大きいほど大きい。
この余弦の組は DCT-I（第 1 種離散コサイン変換）の基底なので、頂点の場に DCT-I をかければ各モードの振幅が得られる。
[Turing パターンの 2 次元の形成](../turing-pattern-formation/)では、この性質を使って模様の支配モードを求める。

次の定義のブロックは拡散係数、2 成分の差分 Plan、連続と離散の分散関係を、このページの 2 つのセルで共有する。
格子の刻みは $h=1$ に固定し、一辺に $L+1$ 個の頂点を置く。
`StructuredFdmCoefficients::diffusion` は軸と成分ごとの拡散係数を返し、成分 0 が $u$、成分 1 が $v$ である。
`BoundaryCondition::natural` は外向きの余法線流束 $\mathbf{n}\cdot D\nabla u$ を与える条件で、成分を指定しなければ両成分に掛かる。
```rust
//| id: pde-turing-model
//| kind: definitions
//| title: 拡散係数、2 成分の差分 Plan、連続と離散の分散関係
//| crates: [scioxide-core, scioxide-pde, scioxide-spatial]
use scioxide_core::{SciOxideError, RealScalar};
use scioxide_pde::{
    BoundaryCondition, BoundaryData, StructuredBoundaries, StructuredFdmCoefficients,
    StructuredFdmPlan,
};
use scioxide_spatial::{AxisSide, AxisTopology, BoundarySet, CoordinateAxis, Grid2d, QuadMesh};

/// (u*, v*) でのヤコビ行列 J₀ = [[f_u, f_v], [g_u, g_v]]。
pub(crate) const JACOBIAN: [[f64; 2]; 2] = [[0.8, 1.0], [-1.8, -1.0]];

/// 拡散係数 D_u = 1、D_v = d。成分 0 が u、成分 1 が v で、両軸とも同じ値。
pub(crate) struct Diffusion {
    pub(crate) ratio: f64,
}
impl StructuredFdmCoefficients<f64, f64, 2> for Diffusion {
    fn diffusion(&self, _: usize, component: usize, _: [f64; 2]) -> Result<f64, SciOxideError> {
        Ok([1.0, self.ratio][component])
    }
}

/// [0, L]² を刻み h = 1 の頂点格子にし、2 成分とも 4 辺で外向きの流束を 0 にする。
pub(crate) fn turing_plan(
    length: usize,
    ratio: f64,
) -> Result<StructuredFdmPlan<f64, f64, 2>, SciOxideError> {
    let axis = CoordinateAxis::uniform(0.0, length as f64, length + 1)?;
    let grid = Grid2d::new([axis.clone(), axis], [AxisTopology::Bounded; 2])?;
    let mesh = QuadMesh::new(grid)?;
    let mut conditions = Vec::new();
    for axis in 0..2 {
        for side in [AxisSide::Start, AxisSide::End] {
            let region = BoundarySet::axis_side(&mesh, axis, side)?;
            conditions.push(BoundaryCondition::natural(region, BoundaryData::zero()));
        }
    }
    let boundaries = StructuredBoundaries::new(&mesh, 2, conditions)?;
    StructuredFdmPlan::new(mesh, &Diffusion { ratio }, &boundaries)
}

/// J₀ − κ diag(1, d) の固有値の最大実部。κ は連続の k² か離散の k_h²。
pub(crate) fn growth_rate(kappa: f64, ratio: f64) -> f64 {
    let [[fu, fv], [gu, gv]] = JACOBIAN;
    let trace = fu + gv - (1.0 + ratio) * kappa;
    let det = (fu - kappa) * (gv - ratio * kappa) - fv * gu;
    let disc = trace * trace - 4.0 * det;
    if disc >= 0.0 {
        0.5 * (trace + RealScalar::sqrt(disc))
    } else {
        0.5 * trace
    }
}

/// 刻み h = 1 の格子で、1 軸のモード番号 m が離散の波数の 2 乗に寄与する 4 sin²(mπ/2L)。
pub(crate) fn axis_wavenumber2(mode: usize, length: usize) -> f64 {
    let s = RealScalar::sin(mode as f64 * core::f64::consts::PI / (2.0 * length as f64));
    4.0 * s * s
}

/// (m_x, m_y) ≠ (0, 0) の全モードの (m_x, m_y, Re λ_h)。
pub(crate) fn discrete_modes(length: usize, ratio: f64) -> Vec<(usize, usize, f64)> {
    let mut modes = Vec::new();
    for my in 0..=length {
        for mx in 0..=length {
            if mx + my > 0 {
                let kh2 = axis_wavenumber2(mx, length) + axis_wavenumber2(my, length);
                modes.push((mx, my, growth_rate(kh2, ratio)));
            }
        }
    }
    modes
}

/// 不安定帯の端 [k₁, k₂]。h の 2 根 k² = (s ∓ √(s² − 4d det J₀))/(2d)、s = d f_u + g_v。
pub(crate) fn unstable_band(ratio: f64) -> Option<[f64; 2]> {
    let [[fu, fv], [gu, gv]] = JACOBIAN;
    let slope = ratio * fu + gv;
    let disc = slope * slope - 4.0 * ratio * (fu * gv - fv * gu);
    (slope > 0.0 && disc > 0.0).then(|| {
        let s = RealScalar::sqrt(disc);
        [(slope - s) / (2.0 * ratio), (slope + s) / (2.0 * ratio)].map(RealScalar::sqrt)
    })
}

/// 連続系の最速成長の波数 k_max を 0 < k ≤ 1.5 の刻み 10⁻⁴ の走査で求める。
pub(crate) fn fastest_wavenumber(ratio: f64) -> f64 {
    (1..=15_000)
        .map(|i| 1e-4 * i as f64)
        .max_by(|a, b| growth_rate(a * a, ratio).total_cmp(&growth_rate(b * b, ratio)))
        .unwrap_or(0.0)
}
```

## 連続系の分散関係の計算

次のセルは拡散係数比 $d$ を入力とし、連続系の $d_c$、$k_c$、$k_{\max}$、不安定帯の端を表にする。
$k_{\max}$ は $0<k\le1.5$ を刻み $10^{-4}$ で走査して求めるので、その精度は $10^{-4}$ である。
グラフは選んだ $d$ の $\operatorname{Re}\lambda(k)$ を実線、$d=d_c$ の曲線を破線で描き、$k_c$ と $k_{\max}$ を縦線、不安定帯を範囲で示す。
破線は $k=k_c$ で $\operatorname{Re}\lambda=0$ に接する。

既定値（$d=20$）では、表の $d_c=8.5676$、$k_c=0.5845$ が閉形式の値と一致し、$k_{\max}=0.4867$ の成長率は $0.2632$ である。
実線は $k_1=0.2720$ と $k_2=0.8222$ で 0 を横切り、その間だけが正になる。
$k_c$ の縦線は $k_{\max}$ の縦線より右にあり、$d=20$ で最も速く育つ波数は臨界波数より小さい。
$d=8<d_c$ にすると不安定帯の列は「なし」になり、$\operatorname{Re}\lambda(k_{\max})=-0.0271$ と負になる。
$d=40$ では不安定帯が $k\in(0.1836,\,0.8610)$ に広がり、$k_{\max}=0.4205$ に下がる。

## 離散モードの計算

次のセルは拡散係数比 $d$ と一辺の長さ $L$ を入力とし、刻み $h=1$ の格子の全モード $(m_x,m_y)\ne(0,0)$ の $\operatorname{Re}\lambda_h$ を求める。
グラフは離散モードを点、連続の分散関係を参照の破線で描く。
点の横軸は離散の波数 $k_h$ ではなく、モード番号から決まる名目の波数 $k=\pi\sqrt{m_x^2+m_y^2}/L$ である。
表は成長率が最大の離散モード、そのモードの $k$ と $k_h$、成長率が正の離散モードの数である。
最後の列は検算で、そのモードの余弦 $\boldsymbol{\phi}$ を両成分に置いて Plan の作用素 $A$ に掛け、$A\boldsymbol{\phi}=D\,k_h^2M\boldsymbol{\phi}$ の相対残差 $\max_i|(A\boldsymbol{\phi}-Dk_h^2M\boldsymbol{\phi})_i|/\max_i|(A\boldsymbol{\phi})_i|$ を求める（$D$ は成分ごとの拡散係数）。
この残差が丸め誤差の程度なら、$k_h^2$ の式は `StructuredFdmPlan` の固有値と一致している。

```rust
//| id: pde-turing-dispersion-modes
//| ref: pde-turing-dispersion-modes
//| title: 離散の Neumann モードの成長率を数え、Plan の作用素で固有値を確かめる
//| run: reactive
//| uses: [pde-turing-model]
//| crates: [scioxide-core, scioxide-pde, scioxide-spatial]
//| inputs:
//|   ratio: {"type":"range","label":"拡散係数比 d = D_v/D_u [-]","description":"d_c ≈ 8.57 より小さいとすべてのモードが減衰する。","min":4,"max":40,"step":0.5,"value":20}
//|   length: {"type":"range","label":"一辺の長さ L [-]","description":"格子は刻み h = 1 で、一辺に L + 1 個の頂点を置く。","min":4,"max":64,"step":4,"value":32}
//| cases:
//|   - {"id":"below-critical","label":"d = 8 < d_c","description":"すべての離散モードが減衰する。","inputs":{"ratio":8}}
//|   - {"id":"small-domain","label":"d = 10, L = 4","description":"不安定帯は開くが、どの離散モードもその中に入らない。","inputs":{"ratio":10,"length":4}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"discrete","path":"/rows/0/0","equals":5}
//|       - {"artifact":"discrete","path":"/rows/0/4","approx":{"value":0.26315624593311115,"rtol":1e-9}}
//|       - {"artifact":"discrete","path":"/rows/0/5","equals":59}
//|       - {"artifact":"discrete","path":"/rows/0/6","range":{"max":1e-12}}
//|   - case: below-critical
//|     expect:
//|       - {"artifact":"discrete","path":"/rows/0/4","range":{"max":0}}
//|       - {"artifact":"discrete","path":"/rows/0/5","equals":0}
//|   - case: small-domain
//|     expect:
//|       - {"artifact":"discrete","path":"/rows/0/5","equals":0}
//|       - {"artifact":"discrete","path":"/rows/0/6","range":{"max":1e-12}}
use scioxide_core::{LinearOperator, RealScalar};
use scioxide_pde::SpatialDiscretization;
use std::f64::consts::PI;

let fixed4 = serde_json::json!({ "fractionDigits": 4 });
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let (size, length) = (length, length as usize);
let wavenumber =
    |mx: usize, my: usize| PI * RealScalar::sqrt((mx * mx + my * my) as f64) / size;
// 成長率が最大のモード、成長率が正のモードの数、描く点（m_x ≤ m_y、k ≤ 1）。
let modes = discrete_modes(length, ratio);
let unstable = modes.iter().filter(|m| m.2 > 0.0).count();
let (mx, my, rate) = modes
    .iter()
    .copied()
    .fold((0, 0, f64::MIN), |b, m| if m.2 > b.2 { m } else { b });
let points: Vec<[f64; 2]> = modes
    .iter()
    .filter(|m| m.0 <= m.1 && wavenumber(m.0, m.1) <= 1.0)
    .map(|m| [wavenumber(m.0, m.1), m.2])
    .collect();
// 検算: 最大のモードの余弦 φ を両成分に置き、A φ = D k_h² M φ の相対残差を見る。
let kh2 = axis_wavenumber2(mx, length) + axis_wavenumber2(my, length);
let plan = turing_plan(length, ratio).map_err(|e| e.to_string())?;
let nodes = plan.unknowns() / 2;
let mut mode = vec![0.0; 2 * nodes];
for node in 0..nodes {
    let [x, y] = plan.node_point(node).map_err(|e| e.to_string())?;
    let phi =
        RealScalar::cos(mx as f64 * PI * x / size) * RealScalar::cos(my as f64 * PI * y / size);
    mode[node] = phi;
    mode[nodes + node] = phi;
}
let mut applied = vec![0.0; 2 * nodes];
let mut scratch = vec![0.0; plan.apply_workspace_len().map_err(|e| e.to_string())?];
plan.apply_into(&mode, &mut applied, &mut scratch)
    .map_err(|e| e.to_string())?;
let mass = plan.lumped_mass();
let scale = applied.iter().fold(0.0_f64, |m, a| m.max(a.abs()));
let residual = (0..2 * nodes)
    .map(|i| (applied[i] - [1.0, ratio][i / nodes] * kh2 * mass[i] * mode[i]).abs())
    .fold(0.0_f64, f64::max)
    / scale;
let columns = serde_json::json!([
    { "key": "0", "label": "m_x", "type": "integer" },
    { "key": "1", "label": "m_y", "type": "integer" },
    { "key": "2", "label": "名目の波数 k [-]", "type": "number", "format": fixed4 },
    { "key": "3", "label": "離散の波数 k_h [-]", "type": "number", "format": fixed4 },
    { "key": "4", "label": "Re λ_h [-]", "type": "number", "format": fixed4 },
    { "key": "5", "label": "成長する離散モード [個]", "type": "integer" },
    { "key": "6", "label": "固有対の相対残差 [-]", "type": "number", "format": sci2 }
]);
let (k, k_h) = (wavenumber(mx, my), RealScalar::sqrt(kh2));
emit_table_with_columns!(
    columns,
    vec![(mx, my, k, k_h, rate, unstable, residual)],
    metadata = serde_json::json!({ "id": "discrete" })
);
let curve: Vec<[f64; 2]> = (0..=200)
    .map(|i| {
        [
            0.005 * i as f64,
            growth_rate(2.5e-5 * (i * i) as f64, ratio),
        ]
    })
    .collect();
emit_chart!(
    serde_json::json!({
        "kind": "xy",
        "xLabel": "名目の波数 k [-]",
        "yLabel": "成長率 Re λ [-]",
        "xMin": 0,
        "xMax": 1,
        "yMin": -1,
        "yMax": 0.5,
        "dataZoom": true,
        "tooltip": true,
        "annotations": [{ "kind": "line", "axis": "y", "value": 0.0, "label": "Re λ = 0" }],
        "layers": [
            {
                "id": "continuous",
                "kind": "line",
                "name": "連続系 Re λ(k)",
                "points": curve,
                "style": { "lineType": "dashed" }
            },
            { "id": "discrete", "kind": "scatter", "name": "離散モード Re λ_h", "points": points }
        ]
    }),
    metadata = serde_json::json!({ "id": "modes" })
);
```

既定値（$d=20$、$L=32$）では、成長率が正の離散モードは 59 個で、最大は $(m_x,m_y)=(5,0)$（$k=0.4909$、$k_h=0.4860$）の $\operatorname{Re}\lambda_h=0.2632$ である。
$(0,5)$ も同じ成長率を持ち、表はモード番号の順で先に見つかった方を示す。
このモードの $k$ は、名目の波数のうち $k_{\max}=0.4867$ に最も近い値である（$(3,4)$ と $(4,3)$ も同じ $k$ を持つ）。
固有対の相対残差は $6.4\times10^{-15}$ で、余弦が Plan の作用素の固有ベクトルであることを丸め誤差の範囲で確かめられる。
グラフの点は破線を $k-k_h$ だけ左にずらした位置の値を取り、そのずれは $k$ が大きいほど大きい。
$k_{\max}$ より大きい波数では破線が右下がりなので、点は破線より上に来る。

$d=8<d_c$ では離散モードの最大の成長率は $-0.0272$（モード $(6,1)$）で、成長するモードはない。
$d=10$、$L=4$ では連続系の不安定帯 $k\in(0.4472,\,0.7071)$ は開くが、最も低い非一様モード $(1,0)$ の $k_h=0.7654$ が帯の外にあるので、成長する離散モードは 0 個である。
この領域では $d>d_c$ でも一様状態が安定のままである。

## まとめ

Schnakenberg 系（$a=0.1$、$b=0.9$）の一様定常解は、拡散係数比が $d_c\approx8.5676$ を超えると不安定になる。
最初に不安定になる臨界波数 $k_c\approx0.5845$ と、$d=20$ で最も速く育つ $k_{\max}\approx0.4867$ は別の量で、模様の波長の目安になるのは後者である。
有限の正方形では、零流束の余弦モードの離散の波数 $k_h$ が不安定帯に入るかを数え、入るモードがなければ $d>d_c$ でも模様は生じないと判断できる。
`StructuredFdmPlan` の頂点の差分では、余弦モードが $M^{-1}A$ の固有ベクトルになることを、Plan の作用素で丸め誤差の範囲まで確かめられる。
