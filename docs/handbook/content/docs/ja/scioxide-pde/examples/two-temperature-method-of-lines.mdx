このページは[線の方法と半離散系](../../algorithms/method-of-lines-and-nonlinear/)で説明した `MethodOfLinesPlan` と `MethodOfLinesStagePreconditioner` を、二つの場が熱交換で連成する硬い系に使う。
二つの場の熱容量は 2 桁異なり、それが半離散系の対角の質量になる。
物理単位の残差を正規化して積分し、時間積分の誤差を許容誤差と比べ、陰的段の線形系を解く方法による違いを確かめる。

## 薄膜の二温度モデル

フェムト秒レーザーで加熱した金属の薄膜では、光を吸収した電子が先に高温になり、電子–格子の結合を通して格子へ熱を渡す。
二温度モデル（S. I. Anisimov, B. L. Kapeliovich, T. L. Perel'man, *Sov. Phys. JETP* **39**, 375 (1974)）は、電子の温度 $T_e$ と格子の温度 $T_l$ を別の場として

$$
C_e\,\frac{\partial T_e}{\partial t}=k_e\,\frac{\partial^2 T_e}{\partial x^2}-G\,(T_e-T_l),\qquad
C_l\,\frac{\partial T_l}{\partial t}=k_l\,\frac{\partial^2 T_l}{\partial x^2}+G\,(T_e-T_l)
$$

と書く。
$C_e,C_l$ [J/(m³·K)] は体積あたりの熱容量、$k_e,k_l$ [W/(m·K)] は熱伝導率、$G$ [W/(m³·K)] は電子–格子の結合定数である。
ここでは厚さ $L=1$ µm の膜の両面が周囲の温度に保たれるとし、$T_e,T_l$ を周囲からの温度上昇として $T_e=T_l=0$ を両端の Dirichlet 条件にする。
パラメータは金の値の程度に選んだ $C_e=2.0\times10^4$、$C_l=2.5\times10^6$ J/(m³·K)、$k_e=300$、$k_l=2$ W/(m·K)、$G=2\times10^{16}$ W/(m³·K) とする。
実際の電子の熱容量は温度に比例するが、このモデルでは定数として線形の系にする。
初期条件は $T_e(x,0)=100\sin(\pi x/L)$ K、$T_l(x,0)=0$ とする。

時間の尺度は三つある。
電子が格子へ熱を渡す時間 $C_e/G=1$ ps、電子の熱が膜の厚さを拡散する時間 $C_e/(k_e\pi^2/L^2)\approx6.8$ ps、二つの場がそろって冷える時間の目安 $(C_e+C_l)/((k_e+k_l)\pi^2/L^2)\approx850$ ps である。
後で導く 2 元の系の遅い固有値から求めると、この冷える時間は約 970 ps になる（目安との差は、$k_e\pi^2/L^2$ が $G$ の約 15% あるため、遅いモードでも電子の温度が格子より低く、電子の熱伝導で失う熱が目安より少ないことによる）。
さらに格子幅 $h$ の最も高い波数の電子のモードは $C_e h^2/(4k_e)$ の時間で減衰し、$n=63$ 点では $4\times10^{-3}$ ps になる。
最も速い尺度と最も遅い尺度の比は $10^5$ を超え、半離散系は硬い。

区間を $n+1$ 等分した内部の節点 $x_i=ih$ で 3 点差分を使い、各節点の式に $h$ を掛けると

$$
(C_e h)\,\dot T_{e,i}=\frac{k_e}{h}\left(T_{e,i-1}-2T_{e,i}+T_{e,i+1}\right)-hG\,(T_{e,i}-T_{l,i})
$$

と、$T_l$ の同じ形の式になる。
左辺の $C_e h$、$C_l h$ が対角の質量 $\mathbf{M}$、右辺が物理単位の残差 $\mathbf{f}$（単位は W/m²）である。
状態は $(T_{e,1},\dots,T_{e,n},T_{l,1},\dots,T_{l,n})$ の順に並べる。

初期値 $\sin(\pi x_i/L)$ は 3 点差分の Dirichlet 行列の固有ベクトルで、固有値は $-\mu_h$、$\mu_h=(4/h^2)\sin^2(\pi h/(2L))$ である。
二つの場の初期値がこのベクトルに比例するので、半離散系の解も $\mathbf{T}_e(t)=A_e(t)\,\mathbf{s}$、$\mathbf{T}_l(t)=A_l(t)\,\mathbf{s}$（$s_i=\sin(\pi x_i/L)$）の形を保ち、振幅は 2 元の線形系

$$
\frac{d}{dt}\begin{pmatrix}A_e\\A_l\end{pmatrix}=K\begin{pmatrix}A_e\\A_l\end{pmatrix},\qquad
K=\begin{pmatrix}-(k_e\mu_h+G)/C_e & G/C_e\\ G/C_l & -(k_l\mu_h+G)/C_l\end{pmatrix}
$$

に従う。
$K$ の固有値 $r_1\ne r_2$ を使うと $e^{Kt}=\left[e^{r_1t}(K-r_2I)-e^{r_2t}(K-r_1I)\right]/(r_1-r_2)$ で、半離散系の厳密解が閉形式で求まる。
$\mu_h$ を連続の $\mu=(\pi/L)^2$ に替えれば偏微分方程式の厳密解になる。
積分した解と半離散の厳密解の差は時間積分の誤差だけを、二つの厳密解の差は空間の離散化の誤差だけを表す。

次のブロックは二つのセルが共有するモデルである。
`TwoTemperature` の `rhs` と `jacobian_product` が残差 $\mathbf{f}$ とその微分、`sparse_jacobian` が疎な構造の上のヤコビ行列、`mass` が対角の質量 $C h$ を返す。
`amplitudes` は 2 元の振幅の閉形式で、引数の `mu` に $\mu_h$ か $\mu$ を渡す。
`FieldStage` と `StageInverse` は後半のセルで使う段の前処理である（[段の Krylov 法と場ごとの前処理](#段の-krylov-法と場ごとの前処理)）。

```rust
//| id: pde-two-temperature-model
//| kind: definitions
//| title: 薄膜の二温度モデルと段の前処理
//| crates: [scioxide-core, scioxide-ode, scioxide-pde]
use core::cell::{Cell, RefCell};
use scioxide_core::{
    ErrorTolerance, SciOxideError, NormSelection, Preconditioner, SolveContext, StructuralPattern,
    StructuralPatternView,
};
use scioxide_ode::OdeSystem;
use scioxide_pde::{MethodOfLinesStagePreconditioner, PdeFieldPreconditioner};

/// 厚さ L = 1 µm の膜の内部節点。成分の順は [T_e,1..T_e,n, T_l,1..T_l,n]、0 番の場が電子。
pub(crate) struct TwoTemperature {
    pub(crate) nodes: usize,
    pub(crate) spacing: f64,
    pub(crate) conductivity: [f64; 2],
    pub(crate) capacity: [f64; 2],
    pub(crate) coupling: f64,
}

impl TwoTemperature {
    pub(crate) const LENGTH: f64 = 1.0e-6;

    pub(crate) fn new(nodes: usize, coupling: f64) -> Self {
        Self {
            nodes,
            spacing: Self::LENGTH / (nodes + 1) as f64,
            conductivity: [300.0, 2.0],
            capacity: [2.0e4, 2.5e6],
            coupling,
        }
    }

    /// 場の代表的な大きさ [K]（電子、格子）。座標の尺度 D と許容誤差に使う。
    pub(crate) const TYPICAL: [f64; 2] = [100.0, 1.0];

    /// 座標の尺度 D（状態と同じ順）。
    pub(crate) fn scales(&self) -> Vec<f64> {
        (0..2 * self.nodes)
            .map(|row| Self::TYPICAL[row / self.nodes])
            .collect()
    }

    /// 初期値: T_e = 100 sin(πx/L) K、T_l = 0。
    pub(crate) fn initial(&self) -> Vec<f64> {
        (0..2 * self.nodes)
            .map(|row| {
                if row < self.nodes {
                    Self::TYPICAL[0] * self.mode(row)
                } else {
                    0.0
                }
            })
            .collect()
    }

    /// 物理の許容誤差: 相対 10^p、絶対 10^p ×（場の代表的な大きさ）[K]。
    pub(crate) fn tolerance(&self, exponent: f64) -> Result<ErrorTolerance<f64>, SciOxideError> {
        let epsilon = 10.0_f64.powf(exponent);
        let absolute: Vec<f64> = self.scales().iter().map(|d| epsilon * d).collect();
        ErrorTolerance::try_vector(&absolute, epsilon, NormSelection::Infinity)
    }

    /// 対角の質量 C h [J/(m²·K)]（状態と同じ順）。
    pub(crate) fn mass(&self) -> Vec<f64> {
        (0..2 * self.nodes)
            .map(|row| self.capacity[row / self.nodes] * self.spacing)
            .collect()
    }

    /// 節点 i の sin(π x_i / L)。初期値と厳密解の形。
    pub(crate) fn mode(&self, i: usize) -> f64 {
        let s = (i + 1) as f64 / (self.nodes + 1) as f64;
        scioxide_core::RealScalar::sin(core::f64::consts::PI * s)
    }

    /// 3 点差分の固有値の大きさ μ_h = (4/h²) sin²(πh/(2L))。
    pub(crate) fn discrete_mu(&self) -> f64 {
        let h = self.spacing;
        let s = scioxide_core::RealScalar::sin(core::f64::consts::PI * h / (2.0 * Self::LENGTH));
        4.0 / (h * h) * s * s
    }

    /// 振幅 (A_e, A_l)(t) = e^{Kt} (A_e(0), 0) の閉形式（検算用、f64 の標準関数）。
    pub(crate) fn amplitudes(&self, mu: f64, initial: f64, time: f64) -> [f64; 2] {
        let ([ce, cl], [ke, kl], g) = (self.capacity, self.conductivity, self.coupling);
        let k = [[-(ke * mu + g) / ce, g / ce], [g / cl, -(kl * mu + g) / cl]];
        let (trace, det) = (k[0][0] + k[1][1], k[0][0] * k[1][1] - k[0][1] * k[1][0]);
        let root = (trace * trace / 4.0 - det).sqrt();
        let (r1, r2) = (trace / 2.0 + root, trace / 2.0 - root);
        let (e1, e2) = ((r1 * time).exp(), (r2 * time).exp());
        let column = |row: usize, identity: f64| {
            (e1 * (k[row][0] - r2 * identity) - e2 * (k[row][0] - r1 * identity)) / (r1 - r2)
        };
        [initial * column(0, 1.0), initial * column(1, 0.0)]
    }

    /// 場ごとの三重対角と、同じ節点の電子–格子の結合からなる構造。
    pub(crate) fn pattern(&self) -> Result<StructuralPattern, SciOxideError> {
        let n = self.nodes;
        let (mut rows, mut columns) = (vec![0], Vec::new());
        for row in 0..2 * n {
            let (field, i) = (row / n, row % n);
            let mut entries: Vec<usize> = (i.saturating_sub(1)..=(i + 1).min(n - 1))
                .map(|j| field * n + j)
                .collect();
            entries.push((1 - field) * n + i);
            entries.sort_unstable();
            columns.extend(entries);
            rows.push(columns.len());
        }
        StructuralPattern::new(2 * n, 2 * n, rows, columns)
    }

    /// f(T) = (k/h) δ² T ∓ h G (T_e − T_l)。線形なので JVP も同じ式。
    fn apply(&self, x: &[f64], out: &mut [f64]) {
        let n = self.nodes;
        for row in 0..2 * n {
            let i = row % n;
            let below = if i > 0 { x[row - 1] } else { 0.0 };
            let above = if i + 1 < n { x[row + 1] } else { 0.0 };
            let diffusion =
                self.conductivity[row / n] / self.spacing * (below - 2.0 * x[row] + above);
            let exchange = self.spacing * self.coupling * (x[i] - x[n + i]);
            out[row] = if row < n {
                diffusion - exchange
            } else {
                diffusion + exchange
            };
        }
    }
}

impl OdeSystem<f64> for TwoTemperature {
    fn dimension(&self) -> usize {
        2 * self.nodes
    }

    fn jacobian_is_constant(&self) -> bool {
        true
    }

    fn rhs(
        &self,
        _: f64,
        x: &[f64],
        out: &mut [f64],
        _: &mut SolveContext<'_, '_>,
    ) -> Result<(), SciOxideError> {
        self.apply(x, out);
        Ok(())
    }

    fn jacobian_product(
        &self,
        _: f64,
        _: &[f64],
        v: &[f64],
        out: &mut [f64],
        _: &mut [f64],
        _: &mut SolveContext<'_, '_>,
    ) -> Result<Option<()>, SciOxideError> {
        self.apply(v, out);
        Ok(Some(()))
    }

    fn sparse_jacobian(
        &self,
        _: f64,
        _: &[f64],
        p: StructuralPatternView<'_>,
        out: &mut [f64],
        _: &mut SolveContext<'_, '_>,
    ) -> Result<Option<()>, SciOxideError> {
        let (n, g) = (self.nodes, self.spacing * self.coupling);
        for row in 0..2 * n {
            let d = self.conductivity[row / n] / self.spacing;
            for k in p.row_ptr()[row]..p.row_ptr()[row + 1] {
                let col = p.col_indices()[k];
                out[k] = match (col == row, col / n == row / n) {
                    (true, _) => -2.0 * d - g,
                    (false, true) => d,
                    (false, false) => g,
                };
            }
        }
        Ok(Some(()))
    }
}

/// 場の対角ブロック I − γ J_zz の逆。三重対角で係数が一定なので Thomas 法で解く。
pub(crate) struct FieldStage {
    pub(crate) calls: Cell<usize>,
    lower: Cell<f64>,
    pivots: RefCell<Vec<f64>>,
    upper: RefCell<Vec<f64>>,
}

impl FieldStage {
    pub(crate) fn new(nodes: usize) -> Self {
        Self {
            calls: Cell::new(0),
            lower: Cell::new(0.0),
            pivots: RefCell::new(vec![1.0; nodes]),
            upper: RefCell::new(vec![0.0; nodes]),
        }
    }

    /// 対角 diagonal、上下の成分 off の三重対角行列を LU 分解する。
    fn prepare(&self, diagonal: f64, off: f64) {
        let (mut m, mut c) = (self.pivots.borrow_mut(), self.upper.borrow_mut());
        for i in 0..m.len() {
            m[i] = diagonal - if i > 0 { off * c[i - 1] } else { 0.0 };
            c[i] = off / m[i];
        }
        self.lower.set(off);
    }
}

impl Preconditioner<f64> for FieldStage {
    fn dimension(&self) -> usize {
        self.pivots.borrow().len()
    }

    fn precondition_workspace_len(&self) -> Result<usize, SciOxideError> {
        Ok(0)
    }

    fn precondition_into(
        &self,
        r: &[f64],
        z: &mut [f64],
        _: &mut [f64],
    ) -> Result<(), SciOxideError> {
        self.calls.set(self.calls.get() + 1);
        let (m, c, off) = (self.pivots.borrow(), self.upper.borrow(), self.lower.get());
        for i in 0..m.len() {
            z[i] = (r[i] - if i > 0 { off * z[i - 1] } else { 0.0 }) / m[i];
        }
        for i in (0..m.len().saturating_sub(1)).rev() {
            z[i] -= c[i] * z[i + 1];
        }
        Ok(())
    }
}

/// 段の前処理: シフト γ を受け取るたびに場ごとのブロックを作り直す。
pub(crate) struct StageInverse<'a> {
    pub(crate) model: &'a TwoTemperature,
    pub(crate) blocks: [&'a FieldStage; 2],
    pub(crate) inverse: &'a PdeFieldPreconditioner<'a, f64>,
}

impl MethodOfLinesStagePreconditioner<f64> for StageInverse<'_> {
    fn preconditioner(
        &self,
        _: f64,
        _: &[f64],
        shift: f64,
    ) -> Result<Option<&dyn Preconditioner<f64>>, SciOxideError> {
        let m = self.model;
        for (field, block) in self.blocks.iter().enumerate() {
            // 正規化した座標の J_zz = (k/(C h²)) tridiag(1, −2, 1) − (G/C) I。
            let a = m.conductivity[field] / (m.capacity[field] * m.spacing * m.spacing);
            let g = m.coupling / m.capacity[field];
            block.prepare(1.0 + shift * (2.0 * a + g), -shift * a);
        }
        Ok(Some(self.inverse))
    }
}
```

## 熱容量を質量とする積分

次のセルは結合定数 $G$、内部の節点数 $n$、許容誤差の指数 $p$ を選んで、二温度モデルを $t=1$ ns まで積分する。
`MethodOfLinesPlan::new(2n, Some(&mass), Some(&scales))` は、対角の質量 $C h$ と、場の代表的な大きさ（電子 100 K、格子 1 K）を座標の尺度 $D$ として受け取る。
物理の絶対許容誤差は場ごとに $10^{p}\times$（代表的な大きさ）K、相対許容誤差は $10^{p}$ とし、`error_tolerance` で正規化した座標の許容誤差に直す。
積分は Rosenbrock W 法（`RosenbrockW`、`Ros34Pw2`）で、段の線形系は疎な LU 分解で解く。

積分法の出力の関数は、受理した刻みごとに膜の中央 $x=L/2$ の温度を記録する。
表は `PdeSolveReport` に直した積分の記録で、温度の履歴と終端の状態は次のセルに渡す。

```rust
//|   - {"id":"weak-coupling","label":"G = 0.5 × 10¹⁶","description":"格子へ移る熱が減り、終端の格子の温度が下がる。","inputs":{"coupling_scaled":0.5}}
//| tests:
//|   - case: default
//|     expect:

//|       - {"artifact":"record","path":"/rows/0/1","range":{"min":150,"max":250}}
//|       - {"artifact":"record","path":"/rows/0/2","equals":0}
//|       - {"path":"/outputs/1/state","equals":"satisfied"}
//|   - case: loose
//|     expect:
//|       - {"artifact":"record","path":"/rows/0/1","range":{"max":60}}
//|       - {"path":"/outputs/1/state","equals":"satisfied"}

//|     expect:
//|       - {"artifact":"record","path":"/rows/0/1","range":{"min":150,"max":250}}
//|       - {"path":"/outputs/1/state","equals":"satisfied"}
//|   - case: weak-coupling
//|     expect:
//|       - {"path":"/outputs/1/state","equals":"satisfied"}

use scioxide_linalg::Vector;

let n = tt_nodes as usize;
let model = TwoTemperature::new(n, coupling_scaled * 1.0e16);

let plan = MethodOfLinesPlan::new(2 * n, Some(&model.mass()), Some(&scales))

    .map_err(|e| e.to_string())?;
let mut workspace = plan.workspace().map_err(|e| e.to_string())?;

    .bind(&model, &mut workspace)
    .map_err(|e| e.to_string())?;

let physical = model
    .tolerance(tolerance_exponent)
    .map_err(|e| e.to_string())?;
let options = OdeOptions::new()
    .with_error_tolerance(plan.error_tolerance(&physical).map_err(|e| e.to_string())?)
    .with_initial_step(1.0e-16)
    .with_output_schedule(OdeOutputSchedule::AcceptedSteps);

    .map_err(|e| e.to_string())?
    .with_backend(OdeStageBackend::Sparse { pattern, limits });
let mut normalized = vec![0.0; 2 * n];
plan.encode_into(&model.initial(), &mut normalized)
    .map_err(|e| e.to_string())?;
let problem = OdeProblem::new(&system, 1.0e-9);
let mut state = OdeState::new(0.0, Vector::from_vec(normalized));
let center = (n - 1) / 2;
let mut history: [Vec<[f64; 2]>; 2] = [Vec::new(), Vec::new()];
let mut ode_workspace = solver
    .workspace(&problem, &options)
    .map_err(|e| e.to_string())?;
let raw = solver
    .advance(
        &problem,
        &options,
        &mut state,
        &mut |t: f64, z: &[f64]| {
            // 正規化した座標から物理の温度 y = D z に戻す（中央の節点だけ）。
            history[0].push([t * 1.0e12, z[center] * scales[center]]);
            history[1].push([t * 1.0e12, z[n + center] * scales[n + center]]);
            Ok(())
        },
        &mut ode_workspace,
        ExecutionContext::sequential(),
    )
    .map_err(|e| e.to_string())?;
let report = PdeSolveReport::try_from(&raw).map_err(|e| e.to_string())?;
let mut physical_state = vec![0.0; 2 * n];
plan.decode_into(state.values(), &mut physical_state)
    .map_err(|e| e.to_string())?;

let diagnostics = report.diagnostics();
let columns = serde_json::json!([
    { "key": "0", "label": "終了理由" },
    { "key": "1", "label": "受理した刻み [回]", "type": "integer" },
    { "key": "2", "label": "棄却した刻み [回]", "type": "integer" },
    { "key": "3", "label": "因子分解 [回]", "type": "integer" },
    { "key": "4", "label": "右辺の評価 [回]", "type": "integer" },
    { "key": "5", "label": "ヤコビ行列の評価 [回]", "type": "integer" }
]);
emit_table_with_columns!(
    columns,
    vec![(
        report.termination().to_string(),
        diagnostics.num_accepted_steps(),
        diagnostics.num_rejected_steps(),
        diagnostics.num_factorizations(),
        diagnostics.num_rhs_evaluations(),
        diagnostics.num_jacobian_evaluations(),
    )],
    metadata = serde_json::json!({ "id": "record" })
);
export!(nodes, n);
export!(coupling, model.coupling);
export!(tolerance_exponent, tolerance_exponent);
export!(final_state, physical_state.clone());
export!(electron_history, history[0].clone());
export!(lattice_history, history[1].clone());
export!(accepted_steps, diagnostics.num_accepted_steps());

let outcome = if report.is_success() {
    Outcome::satisfied("t = 1 ns まで積分した")
} else {
    Outcome::partial("終端の前で止まった")
        .explanation("表の温度は最後に受理した刻みの値である。")
};
emit_outcome!(
    outcome
        .status(report.termination().to_string())
        .diagnostic(
            "受理した刻み",
            diagnostics.num_accepted_steps() as f64,
            None
        )
        .diagnostic("到達した時刻", report.final_time() * 1.0e12, Some("ps"))
);
```

既定の $G=2\times10^{16}$ W/(m³·K)、$n=63$、$p=-6$ では、積分は 195 刻みで $t=1$ ns に達し（`Completed`）、棄却した刻みはなかった。
ヤコビ行列は定数（`jacobian_is_constant`）なので評価は 2 回で済み、因子分解は受理した刻みごとに 1 回の 195 回だった。
刻みの数は許容誤差で決まり、$p=-3$ では 40 刻み、$p=-9$ では 1713 刻みになる。
節点数を 15 から 255 まで変えても刻みの数は 195 のまま変わらない。
最も速い電子のモードの時間 $C_e h^2/(4k_e)$ は $n=63$ で $4\times10^{-3}$ ps だが、陰的な積分法の刻みはそれに縛られず、解の変化の速さで決まる。
同じ系を陽的な Dormand–Prince 5(4) 法で積分すると、`CflPolicy::Automatic` の刻みの上限は $0.9\times3.3065/\rho\approx1.2\times10^{-14}$ s（$\rho\approx2.47\times10^{14}$ s⁻¹ は $J_z$ の行和の最大）で、1 ns までに約 $8.3\times10^4$ 刻みが要る。

## 半離散系の厳密解との比較

次のセルは前のセルの結果を受け取り、二つの厳密解と比べる。
グラフは膜の中央の電子と格子の温度で、記号（受理した刻み）を結んだ線が積分した値、破線が半離散系の厳密解である。
横軸と縦軸は対数で、$t=0$ の初期値（各系列 1 点）は描かない。
表は終端の中央の温度、半離散の厳密値、すべての節点での時間積分の誤差の最大値、その場の絶対許容誤差、半離散と連続の厳密解の差（空間の離散化の誤差）を示す。

```rust

//| ref: pde-two-temperature-exact-check
//| title: 積分した温度を二つの厳密解と比べる

//|   - case: default

//|       - {"artifact":"fields","path":"/rows/0/3","range":{"max":1e-5}}
//|       - {"artifact":"fields","path":"/rows/1/3","range":{"max":1e-5}}

    .as_f64()
    .ok_or("許容誤差がない")?;

    serde_json::from_value(direct["final_state"].clone()).map_err(|e| e.to_string())?;

    serde_json::from_value(direct["electron_history"].clone()).map_err(|e| e.to_string())?;

// 対数の横軸に載らない t = 0 の初期値を除く（各系列 1 点）。

lattice.retain(|p| p[0] > 0.0);
let model = TwoTemperature::new(n, coupling);
let (end, center) = (1.0e-9, (n - 1) / 2);
let initial_amplitude = TwoTemperature::TYPICAL[0];

// 検算: 半離散系と偏微分方程式の厳密解（2 元の閉形式）。
let semi = model.amplitudes(model.discrete_mu(), initial_amplitude, end);
let continuum_mu = (core::f64::consts::PI / TwoTemperature::LENGTH).powi(2);
let exact = model.amplitudes(continuum_mu, initial_amplitude, end);
let mut rows = Vec::new();

        10.0_f64.powf(exponent) * TwoTemperature::TYPICAL[field],

}
let samples: Vec<f64> = (0..=140)

};
```

グラフでは、電子の温度が 1 ps で約 32 K、5 ps で約 1 K まで下がり、格子の温度は 6 ps のころに最大の約 0.69 K になる。
格子が受け取れる熱の上限は、電子の熱がすべて格子に移った場合の $100\,C_e/(C_e+C_l)\approx0.79$ K である。
10 ps より後は電子の温度が格子より少し低いまま、二つがいっしょに数百 ps の尺度で下がり、1 ns の中央の温度は電子 0.215 K、格子 0.247 K になる。
時間積分の誤差は電子 $1.4\times10^{-7}$ K、格子 $1.6\times10^{-7}$ K で、絶対許容誤差（電子 $10^{-4}$ K、格子 $10^{-6}$ K）より小さい。
許容誤差は 1 刻みの局所誤差に対する条件で、散逸する系では前の刻みの誤差が後で減衰するので、全体の誤差がこれより小さくなることが多い。
空間の離散化の誤差は $5\times10^{-5}$ K で、$n=255$ では約 1/16（$3\times10^{-6}$ K）になり、3 点差分の 2 次の収束と合う。
$p=-3$ では時間積分の誤差が $2\times10^{-5}$ K の桁に増え、空間の離散化の誤差に近づく。

## 段の Krylov 法と場ごとの前処理

陰的段の線形系 $(\mathbf{I}-\gamma J_z)\mathbf{k}=\mathbf{r}$ は、疎な LU 分解の代わりに行列なしの GMRES（`OdeStageBackend::Krylov`）でも解ける。
正規化した座標では、場 $i$ の対角ブロックは

$$
(\mathbf{I}-\gamma J_z)_{ii}=\mathbf{I}-\gamma\left[\frac{k_i}{C_ih^2}\,\mathrm{tridiag}(1,-2,1)-\frac{G}{C_i}\,\mathbf{I}\right]
$$

で、係数が一定の三重対角行列である（場の中の尺度 $d_i$ は打ち消し合う）。
`StageInverse` は、シフト $\gamma$ を受け取るたびにこの二つのブロックを LU 分解し、`PdeFieldPreconditioner` で並べたブロック対角の逆を返す。
無視するのは電子と格子の結合の非対角ブロック（成分の大きさ $\gamma\,(G/C_i)(d_j/d_i)$ の対角行列、$d_i,d_j$ は二つの場の尺度）だけである。

次のセルは内部の節点数 $n$ を選び、$G=2\times10^{16}$ W/(m³·K)、$p=-6$ で、段の前処理なしとありの二通りに $t=1$ ns まで積分する。
表は受理・棄却した刻み、GMRES の反復の合計、電子のブロックの前処理を適用した回数、半離散の厳密解との差の最大値を示す。
前処理なしの積分は重いので、ボタンで実行する。

```rust
//| id: pde-two-temperature-stage-krylov
//| ref: pde-two-temperature-stage-krylov
//| title: 段の Krylov 法に場ごとの前処理を与える
//| run: button
//| timeoutMs: 120000
//| uses: [pde-two-temperature-model]
//| crates: [scioxide-core, scioxide-linalg, scioxide-ode, scioxide-pde]
//| inputs:
//|   stage_nodes: {"type":"range","label":"内部の節点数 n [点]","description":"前処理なしの GMRES の反復は n とともに増える。","min":15,"max":63,"step":16,"value":31}
//| cases:
//|   - {"id":"fine","label":"n = 63","description":"前処理なしでは GMRES の反復が約 2.2 万回に増え、棄却された刻みが現れる。","inputs":{"stage_nodes":63}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"krylov","path":"/rows/0/4","range":{"min":2000}}
//|       - {"artifact":"krylov","path":"/rows/1/4","range":{"max":2000}}
//|       - {"artifact":"krylov","path":"/rows/1/3","equals":0}
//|       - {"artifact":"krylov","path":"/rows/1/6","range":{"max":1e-5}}
//|       - {"path":"/outputs/1/state","equals":"satisfied"}
//|   - case: fine
//|     expect:
//|       - {"artifact":"krylov","path":"/rows/0/3","range":{"min":20}}
//|       - {"artifact":"krylov","path":"/rows/0/4","range":{"min":10000}}
//|       - {"artifact":"krylov","path":"/rows/1/3","equals":0}
//|       - {"path":"/outputs/1/state","equals":"satisfied"}
use scioxide_core::{Budget, ExecutionContext, Preconditioner};
use scioxide_linalg::Vector;
use scioxide_ode::{
    OdeMethod, OdeOptions, OdeProblem, OdeStageBackend, OdeState, RosenbrockMethod, RosenbrockW,
};
use scioxide_pde::{MethodOfLinesPlan, PdeFieldLayout, PdeFieldPreconditioner, PdeSolveReport};

let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let n = stage_nodes as usize;
let (coupling, exponent, end) = (2.0e16, -6.0, 1.0e-9);
let model = TwoTemperature::new(n, coupling);
let plan = MethodOfLinesPlan::new(2 * n, Some(&model.mass()), Some(&model.scales()))
    .map_err(|e| e.to_string())?;
let physical = model.tolerance(exponent).map_err(|e| e.to_string())?;
let options = OdeOptions::new()
    .with_error_tolerance(plan.error_tolerance(&physical).map_err(|e| e.to_string())?)
    .with_initial_step(1.0e-16);

// 場ごとのブロック（電子、格子）を PdeFieldPreconditioner で並べる。
let layout = PdeFieldLayout::new(&[n, n]).map_err(|e| e.to_string())?;
let (electron, lattice) = (FieldStage::new(n), FieldStage::new(n));
let blocks: [&dyn Preconditioner<f64>; 2] = [&electron, &lattice];
let inverse = PdeFieldPreconditioner::new(&layout, &blocks).map_err(|e| e.to_string())?;
let stage = StageInverse {
    model: &model,
    blocks: [&electron, &lattice],
    inverse: &inverse,
};
let backend = OdeStageBackend::Krylov {
    iterations: Budget::try_from(200).map_err(|e| e.to_string())?,
    restart: Budget::try_from(30).map_err(|e| e.to_string())?,
    operator_scratch: 0,
    preconditioner_scratch: inverse
        .precondition_workspace_len()
        .map_err(|e| e.to_string())?,
};
let solver = RosenbrockW::new(RosenbrockMethod::Ros34Pw2)
    .map_err(|e| e.to_string())?
    .with_backend(backend);
let semi = model.amplitudes(model.discrete_mu(), TwoTemperature::TYPICAL[0], end);
let mut rows = Vec::new();
let mut all_reached = true;
for preconditioned in [false, true] {
    let mut workspace = plan.workspace().map_err(|e| e.to_string())?;
    let mut system = plan
        .bind(&model, &mut workspace)
        .map_err(|e| e.to_string())?;
    if preconditioned {
        system = system.with_stage_preconditioner(&stage);
    }
    let mut normalized = vec![0.0; 2 * n];
    plan.encode_into(&model.initial(), &mut normalized)
        .map_err(|e| e.to_string())?;
    let problem = OdeProblem::new(&system, end);
    let mut state = OdeState::new(0.0, Vector::from_vec(normalized));
    let calls_before = electron.calls.get();
    let mut ode_workspace = solver
        .workspace(&problem, &options)
        .map_err(|e| e.to_string())?;
    let raw = solver
        .advance(
            &problem,
            &options,
            &mut state,
            &mut (),
            &mut ode_workspace,
            ExecutionContext::sequential(),
        )
        .map_err(|e| e.to_string())?;
    let report = PdeSolveReport::try_from(&raw).map_err(|e| e.to_string())?;
    all_reached &= report.is_success();
    let mut values = vec![0.0; 2 * n];
    plan.decode_into(state.values(), &mut values)
        .map_err(|e| e.to_string())?;
    // 半離散の厳密解（閉形式）との差の最大値。
    let gap = (0..2 * n)
        .map(|row| (values[row] - semi[row / n] * model.mode(row % n)).abs())
        .fold(0.0_f64, f64::max);
    rows.push((
        ["前処理なし", "場ごとの前処理"][usize::from(preconditioned)],
        report.termination().to_string(),
        raw.accepted_steps(),
        raw.rejected_steps(),
        raw.accounting().nested().iterations(),
        electron.calls.get() - calls_before,
        gap,
    ));
}
let columns = serde_json::json!([
    { "key": "0", "label": "段の前処理" },
    { "key": "1", "label": "終了理由" },
    { "key": "2", "label": "受理した刻み [回]", "type": "integer" },
    { "key": "3", "label": "棄却した刻み [回]", "type": "integer" },
    { "key": "4", "label": "GMRES 反復 [回]", "type": "integer" },
    { "key": "5", "label": "前処理の適用 [回]", "type": "integer" },
    { "key": "6", "label": "厳密解との差 [K]", "type": "number", "format": sci3 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "krylov" })
);
let outcome = if all_reached {
    Outcome::satisfied("二つの段の解き方とも t = 1 ns まで積分した")
} else {
    Outcome::partial("終端の前で止まった積分がある")
        .explanation("その行の差は終端の値どうしの差ではない。")
};
emit_outcome!(
    outcome
        .status(rows[1].1.clone())
        .diagnostic("前処理なしの GMRES 反復", rows[0].4 as f64, None)
        .diagnostic("前処理ありの GMRES 反復", rows[1].4 as f64, None)
);
```

既定の $n=31$ では、どちらの積分も 195 刻みで終わり、GMRES の反復の合計は前処理なしで 3619 回、前処理ありで 1556 回だった。
195 刻みの 4 段で 780 回の線形方程式を解くので、前処理ありでは 1 回あたり 2 反復である。
前処理の適用の回数は GMRES の反復の回数と同じで、`PdeFieldPreconditioner` の 1 回の適用が電子のブロックを 1 回呼ぶことと合っている。
$n=63$ に増やすと、前処理なしでは GMRES の反復が 22055 回に増え、101 回の棄却が起き、受理した刻みも 396 回に増える。
前処理ありの 1556 回は $n=15$ から 63 まで変わらない。
ブロックが拡散と交換の対角を厳密に逆にするので、GMRES に残るのは場どうしの結合の部分だけで、格子の細かさに左右されないからである。
厳密解との差はどの場合も $1.3\times10^{-7}$〜$1.6\times10^{-7}$ K で、疎な LU 分解で段を解いた前のセルの時間積分の誤差と同じ水準である。

## まとめ

二温度モデルでは、電子と格子の熱容量 $C_e h$、$C_l h$ を `MethodOfLinesPlan` の対角の質量にし、プロバイダーは物理の単位の残差だけを書く。
場の代表的な大きさを座標の尺度にし、物理の許容誤差を `error_tolerance` で正規化した座標に直すと、許容誤差を K の単位で場ごとに指定できる。
陰的な積分法の刻みの数は許容誤差で決まり、節点数を 15 から 255 に増やしても変わらなかった。
初期値を固有ベクトルに選ぶと 2 元の閉形式で半離散系の厳密解が求まり、時間積分の誤差と空間の離散化の誤差を分けて確かめられる。
段を Krylov 法で解くときは、正規化した座標の場ごとの対角ブロックの逆を段の前処理に与えると、GMRES の反復と棄却が大きく減る。
