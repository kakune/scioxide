熱の拡散、弦の振動、静電ポテンシャル、弾性体の変形、流体の流れは、保存則を微小な体積で書いた偏微分方程式（Partial Differential Equation, PDE）で表される。
`scioxide-pde` はこれらの方程式を空間について離散化し、得られた連立一次方程式、常微分方程式系、非線形方程式を SciOxide の解法で解く。

空間の離散化は一次元から三次元までを一つの型で扱う。
構造格子の有限差分法（FDM）の `StructuredFdmPlan`、セル中心の有限体積法（FVM）の `StructuredFvmPlan` と `SimplexFvmPlan`、区間・三角形・四面体の P1・P2 有限要素法（FEM）の `SimplexFemPlan` が、共通の約束 `SpatialDiscretization` を実装する。
定常問題は `EllipticProblem`、拡散方程式は `ParabolicProblem`、波動方程式は `HyperbolicProblem` が、どの Plan に対しても同じ手順で解く。
弾性体、非圧縮流れ、双曲型保存則、適応細分化（AMR）、離散随伴にはそれぞれ専用の Plan がある。

メッシュ、境界の集合、場の位置は `scioxide-spatial`、疎行列は `scioxide-sparse`、反復法は `scioxide-linalg`、Newton–Krylov 法は `scioxide-rootfind`、時間積分は `scioxide-ode` が受け持つ。
どの操作も設定、準備、実行の順に進み、準備した Plan は不変で `Send + Sync + Clone` なので、同じ Plan を何度でも解ける。

## 最初の計算と結果の読み方

厚さ $L=10$ mm の石英ガラスの板に片面から光が入り、吸収長 $\delta$ で指数的に吸収される場合を考える。
板が吸収する熱流束は $I_0=10^4$ W/m²（1 W/cm²）で、両面は $T_0=20$ °C に保たれる。
面に沿った温度の変化を無視すると、温度 $T(x)$ は一次元の定常熱伝導方程式

$$
-k\,T''(x)=q(x),\qquad q(x)=\frac{I_0}{\delta}e^{-x/\delta},\qquad T(0)=T(L)=T_0
$$

に従う。
$x$ は光が入る面からの深さ、$k=1.4$ W/(m·K) は熱伝導率、$q$ は吸収した光による単位体積あたりの発熱である。
二回積分すると厳密解

$$
T(x)=T_0+\frac{I_0\delta}{k}\Bigl[\bigl(1-e^{-x/\delta}\bigr)-\frac{x}{L}\bigl(1-e^{-L/\delta}\bigr)\Bigr]
$$

が得られるので、これを数値解の独立な検算に使う。

計算の手順は次のとおりである。

1. `CoordinateAxis::uniform`、`Grid1d`、`SegmentMesh` で頂点数 $N+1$ の一様な格子を作る。
2. `StructuredBoundaries::uniform` で両面に Dirichlet 条件 $T=T_0$ を与える。
3. 熱伝導率を `ConstantDiffusion::new(k)` で与え、`StructuredFdmPlan::new` で差分の Plan を準備する。
4. 発熱 $q$ を `FieldData::time_invariant` で与え、`EllipticProblem::new(&plan, &source).solve_with_options(&EllipticOptions::new())` で解く。

次のセルは同じ問題を頂点数 $N+1$ と、格子幅を半分にした $2N+1$ の二つの格子で解く。
入力は粗い格子の頂点数と吸収長 $\delta$ である。
図は厳密解（破線）と二つの格子の節点の温度を描く。
表は格子幅と吸収長の比 $h/\delta$、最高温度、厳密解との最大誤差、二つの格子の誤差の比から求めた観測次数、直接法の後退誤差、終了理由を並べる。
観測次数は $\log_2(e_h/e_{h/2})$ で、2 に近ければ誤差が格子幅の二乗で減っている。

```rust
//| id: pde-index-absorbing-slab
//| ref: pde-index-absorbing-slab
//| title: 光を吸収する板の定常温度を差分法で求め、格子を半分にして誤差を確かめる
//| run: reactive
//| crates: [scioxide-core, scioxide-pde, scioxide-spatial]
//| inputs:
//|   vertex_count: {"type":"range","label":"粗い格子の頂点数 N+1 [-]","description":"細かい格子は 2N+1 頂点になる。","min":5,"max":129,"step":4,"value":9}
//|   absorption_depth: {"type":"range","label":"吸収長 δ [mm]","description":"発熱が e 分の 1 になる深さ。小さいほど発熱が表面に集まる。","min":0.2,"max":5,"step":0.1,"value":1}
//| cases:
//|   - {"id":"fine-grid","label":"頂点数 65","description":"h/δ が 0.16 と 0.08 になり、細かい格子の最大誤差は 2.4×10⁻³ K、観測次数は 2.00 になる。","inputs":{"vertex_count":65}}
//|   - {"id":"thin-absorber","label":"吸収長 0.2 mm","description":"格子幅が吸収長より大きく、最高温度の位置と値を粗い格子が捉えられない。","inputs":{"absorption_depth":0.2}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"slab","path":"/rows/0/0","equals":9}
//|       - {"artifact":"slab","path":"/rows/0/3","approx":{"value":0.5755317,"rtol":1e-6}}
//|       - {"artifact":"slab","path":"/rows/0/4","equals":null}
//|       - {"artifact":"slab","path":"/rows/1/4","approx":{"value":1.918,"atol":0.005}}
//|       - {"artifact":"slab","path":"/rows/1/5","range":{"min":0,"max":1e-14}}
//|       - {"artifact":"slab","path":"/rows/1/6","equals":"Completed"}
//|       - {"path":"/outputs/2/state","equals":"satisfied"}
//|   - case: fine-grid
//|     expect:
//|       - {"artifact":"slab","path":"/rows/1/3","approx":{"value":2.432245e-3,"rtol":1e-5}}
//|       - {"artifact":"slab","path":"/rows/1/4","approx":{"value":1.9986,"atol":0.002}}
//|   - case: thin-absorber
//|     expect:
//|       - {"artifact":"slab","path":"/rows/0/1","approx":{"value":6.25,"rtol":1e-12}}
//|       - {"artifact":"slab","path":"/rows/0/2","approx":{"value":20.0944,"atol":1e-3}}
//|       - {"artifact":"slab","path":"/rows/1/4","range":{"min":0.6,"max":0.9}}
use scioxide_core::{SciOxideError, RealScalar};
use scioxide_pde::{
    BoundaryData, BoundaryKind, ConstantDiffusion, EllipticOptions, EllipticProblem, FieldData,
    FieldPoint, PdeSolveReport, SpatialDiscretization, StructuredBoundaries, StructuredFdmPlan,
};
use scioxide_spatial::{AxisTopology, CoordinateAxis, Grid1d, SegmentMesh};

// 板の厚さ L [m]、熱伝導率 k [W/(m·K)]、吸収した熱流束 I₀ [W/m²]、両面の温度 T₀ [°C]。
let thickness = 0.01;
let conductivity = 1.4;
let absorbed = 1.0e4;
let face = 20.0;
let depth = absorption_depth * 1.0e-3;
// 独立な検算に使う厳密解 T(x) = T₀ + (I₀δ/k)[(1 − e^{−x/δ}) − (x/L)(1 − e^{−L/δ})]。
let exact = move |x: f64| {
    let through = 1.0 - RealScalar::exp(-thickness / depth);
    let inside = 1.0 - RealScalar::exp(-x / depth) - x / thickness * through;
    face + absorbed * depth / conductivity * inside
};
// 頂点数 n の格子で解き、(深さ [mm], 温度 [°C]) の組とレポートを返す。
let solve = |n: usize| -> Result<(Vec<[f64; 2]>, PdeSolveReport<f64>), SciOxideError> {
    let axis = CoordinateAxis::uniform(0.0, thickness, n)?;
    let mesh = SegmentMesh::new(Grid1d::new([axis], [AxisTopology::Bounded])?)?;
    let walls = BoundaryData::constant(face);
    let faces = StructuredBoundaries::uniform(&mesh, 1, BoundaryKind::Dirichlet, walls)?;
    let plan = StructuredFdmPlan::new(mesh, &ConstantDiffusion::new(conductivity), &faces)?;
    // 吸収した光の発熱 q(x) = (I₀/δ) e^{−x/δ} [W/m³]。
    let source = FieldData::time_invariant(move |p: FieldPoint<f64, 1>| {
        Ok(absorbed / depth * RealScalar::exp(-p.point[0] / depth))
    });
    let solution =
        EllipticProblem::new(&plan, &source).solve_with_options(&EllipticOptions::new())?;
    let mut points = Vec::with_capacity(n);
    for (unknown, &t) in solution.values().iter().enumerate() {
        points.push([plan.dof_point(unknown)?.point[0] * 1.0e3, t]);
    }
    Ok((points, solution.report().clone()))
};
let exact_points: Vec<[f64; 2]> = (0..=200)
    .map(|i| {
        let x = thickness * i as f64 / 200.0;
        [x * 1.0e3, exact(x)]
    })
    .collect();
let mut series = vec![serde_json::json!({
    "name": "厳密解",
    "points": exact_points,
    "style": { "lineType": "dashed" }
})];
let coarse = vertex_count as usize;
let mut rows = Vec::new();
let mut errors: Vec<f64> = Vec::new();
let mut reports = Vec::new();
for n in [coarse, 2 * coarse - 1] {
    let (points, report) = solve(n).map_err(|e| e.to_string())?;
    let error = points
        .iter()
        .map(|[x, t]| (t - exact(x * 1.0e-3)).abs())
        .fold(0.0_f64, f64::max);
    let peak = points.iter().map(|p| p[1]).fold(f64::MIN, f64::max);
    // 観測次数は粗い格子との誤差の比から求める（粗い格子では未定義）。
    let order = errors
        .last()
        .map(|&previous| RealScalar::log2(previous / error));
    let backward = report
        .diagnostics()
        .linear_residual_report()
        .map(|r| r.scaled_norm());
    let ratio = thickness / (n - 1) as f64 / depth;
    let status = report.termination().to_string();
    rows.push((n, ratio, peak, error, order, backward, status));
    series.push(serde_json::json!({
        "name": format!("差分法（{n} 頂点）"),
        "points": points,
        "style": { "showSymbol": true }
    }));
    errors.push(error);
    reports.push(report);
}
emit_line_chart!(
    &series,
    options = &serde_json::json!({ "xLabel": "深さ x [mm]", "yLabel": "温度 T [°C]" })
);
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let fixed2 = serde_json::json!({ "fractionDigits": 2 });
let fixed3 = serde_json::json!({ "fractionDigits": 3 });
let columns = serde_json::json!([
    { "key": "0", "label": "頂点数 [-]", "type": "integer" },
    { "key": "1", "label": "h/δ [-]", "type": "number", "format": fixed2 },
    { "key": "2", "label": "最高温度 [°C]", "type": "number", "format": fixed3 },
    { "key": "3", "label": "最大誤差 [K]", "type": "number", "format": sci2 },
    { "key": "4", "label": "観測次数 [-]", "type": "number", "format": fixed2, "nullText": "—" },
    { "key": "5", "label": "後退誤差 [-]", "type": "number", "format": sci2, "nullText": "なし" },
    { "key": "6", "label": "終了理由" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "slab" })
);
let fine = &reports[1];
let outcome = if reports.iter().all(|r| r.is_success()) {
    Outcome::satisfied("二つの格子で消去済みの連立一次方程式を解いた")
        .explanation("後退誤差の判定であり、離散化誤差は表の最大誤差と観測次数で読む。")
} else {
    Outcome::partial("求解が完了しなかった")
};
emit_outcome!(
    outcome
        .status(fine.termination().to_string())
        .diagnostic("細かい格子の最大誤差", errors[1], Some("K"))
        .diagnostic("誤差の比", errors[0] / errors[1], None)
);
```

既定の頂点数 9 では格子幅 $h=1.25$ mm が吸収長 1 mm より大きく、節点の最高温度 24.195 °C は厳密解の最高温度 24.784 °C（深さ 2.30 mm）に届かない。
節点での最大誤差は 0.58 K である。
頂点数 17 の格子では最大誤差が 0.15 K に下がり、観測次数 1.92 は二次精度の差分の誤差 $O(h^2)$ に近い。
頂点数 65 から 129 では観測次数が 2.00 になり、最大誤差は $2.4\times10^{-3}$ K まで下がる。
吸収長を 0.2 mm にすると $h/\delta$ は 6.25 と 3.13 で、観測次数は 0.77 にとどまる。
発熱が格子幅より薄い層に集まり、格子が温度の変化を表せないためである。
観測次数が 2 に近づくのは、$h/\delta$ が 1 より十分小さくなってからである。

どの行も直接法の後退誤差は $10^{-16}$ 未満で、終了理由は `Completed` である。
それでも温度には 0.1 K を超える誤差が残りうる。
後退誤差と終了理由は連立一次方程式を解けたことを示すだけで、空間の離散化誤差は既知解や格子の細分化で別に確かめる。

### 戻り値の読み方

`solve_with_options` の戻り値は次の順に読む。

1. `Err(SciOxideError)` は、入力の形やゲージの設定、係数や源項のコールバック、組立、分解の失敗、後退誤差が許容を超えた場合、計算回数の上限の超過である。
   分類は `kind()` と `view()` で読む。
2. `solve_with_options` は既定の直接法で解くので、`Ok(solution)` の終了理由は `Completed` で、`solution.report().is_success()` は真である。
   作業領域に反復法を注入して `solve_into` で解くと、反復法が上限で止まった場合などに、未収束の値と `is_success()` が偽のレポートが `Ok` で返る（[結果・エラー・診断の読み方](oxref:pde-api-reading-results)）。
   どちらの場合も、場を使う前に `is_success()` を確かめる。
3. 成功したときの `solution.values()` は離散化の未知数の順に並んだ場である。
   未知数は FDM と P1 の FEM では頂点、P2 の FEM では頂点と辺の中点、FVM ではセルにあり、各未知数の座標は `dof_point` で読める。
4. `solution.report().diagnostics()` は、選んだ線形解法の名前（`method()`）、反復の回数と残差、直接法の後退誤差（`linear_residual_report()`）を持つ。

時間発展の `solve_with_options` も同じ形のレポートを返し、時間刻みの試行・受理・棄却の回数を診断に加える。
所有した結果を返す時間発展の `solve` と `solve_with_options` は、エラーを `PartialFailure` で返し、保存できる場合は最後に受理した状態を進行（`PdeProgress`）として持たせる。

## まとめ

`scioxide-pde` は空間の Plan で作用素・集中質量・荷重を組み立て、次元と離散化の方法によらず `EllipticProblem`・`ParabolicProblem`・`HyperbolicProblem` で解く。
結果は `is_success()` で終了理由を確かめてから場と診断を読み、場の各値の位置は `dof_point` で確かめる。
後退誤差や残差が小さくても離散化誤差は残るので、既知解、格子の細分化による観測次数、保存量で精度を確かめる。
最初の計算のように解の変化の幅（ここでは吸収長）を格子幅が十分に分解しているかが、観測次数が理論の値に近づくかを決める。
