浮動小数点の係数では、終結式がちょうど 0 になることはまれで、小さい値が共通根によるのか丸めによるのかを値だけでは区別できない。
`scioxide-poly` の近似消去は、終結式や部分終結式の係数を Sylvester 行列の小行列式として計算し、同じ行列の数値ランクと逆条件数を診断として添える。
このページは計算の手順、行列式の誤差の目安、診断の読み方、同じ次数の消去を繰り返す Plan を説明し、近い重根で値と診断がどう振る舞うかを確かめる。
終結式・判別式・部分終結式の定義と恒等式、厳密な体での剰余列は[終結式・判別式・部分終結式](../resultants-and-elimination/)にある。
記号はそのページに従い、$f$ と $g$ の次数を $m$ と $n$、第 $j$ 部分終結式を $S_j$ と書く。
$u$ は単位丸め、$\varepsilon=2u$ は機械イプシロンである。

## 部分終結式と近似消去

浮動小数点の係数では、`approximate_resultant`、`approximate_subresultant`、`approximate_discriminant` が行列式の値と行列の診断を返す。
各値は次の手順で計算する。

1. 入力から厳密に 0 の末尾の係数を除き、実際の次数を決める。
   空の係数列は `InvalidInput`（`Empty`）、非有限の係数は `NonFinite` で拒否する。
2. 各入力の行を、係数の絶対値（複素係数では実部と虚部の絶対値）の最大が $[1, 2)$ に入る 2 の冪で割る（平衡化）。
   2 の冪による拡大縮小は、成分が非正規化数の範囲に入らない限り丸めを生まないので、行列の構造は変わらない。
   縮小で成分がアンダーフローして 0 になる場合は、構造が変わるので `NumericalInstability`（`Underflow`）として返す。
3. 平衡化した行列の特異値から、数値ランクと、最小特異値と最大特異値の比（逆条件数）を求める。
   数値ランクの判定には方針 `PolynomialApproximationPolicy` のうちランクの方針を使う。
   ランクは診断であり、ランクの方針が値を 0 に切り捨てることはない。
4. 同じ行列の部分ピボット選択付き LU 分解から行列式を求める。
   ピボットが厳密に 0 になったときだけ値を 0 とする。
5. 平衡化で除いた $2^{e}$ の冪を指数の側で戻す。
   値は範囲を考慮した `ScaledValue` で保持するので、`f64` の範囲を超える行列式も表せる。

逆条件数が値の精度の目安になる理由は、行列式の微分の公式（Jacobi の公式）$d(\det A) = \det A \cdot \operatorname{tr}(A^{-1}\,dA)$ にある。
$L \times L$ の行列 $A$ に摂動 $\Delta A$ が加わると、一次の近似で

$$
\frac{|\det(A + \Delta A) - \det A|}{|\det A|} \lesssim |\operatorname{tr}(A^{-1}\Delta A)| \le L\,\kappa_2(A)\,\frac{\|\Delta A\|_2}{\|A\|_2}
$$

となる（$\kappa_2(A) = \sigma_{\max}/\sigma_{\min}$ はレポートの逆条件数の逆数）。
部分ピボット選択付き LU 分解の後退誤差 $\|\Delta A\|_2/\|A\|_2$ は、増大因子が小さい通常の行列では $O(Lu)$ 程度にとどまる（最悪の場合の上界は増大因子と $L$ の多項式を含む。
Higham, *Accuracy and Stability of Numerical Algorithms*, 2nd ed., §9.3–9.4）。
したがって行列式の相対誤差の目安は $L^2 \kappa_2(A)\, u$ 程度で、逆条件数が $u$ に近づくと値の有効数字は失われる。
この見積もりは一次の近似と増大因子の仮定に基づく目安であり、SciOxide は誤差の上界を返さない。

結果の `ApproximateElimination` は `value()` で元の係数の単位の `ScaledValue` を、`report()` で `EliminationReport` を返す。
`try_value()` で通常の型に直すと、桁あふれする値と、0 でないのに 0 に丸められる値は `NumericalInstability` で失敗する。
`round()` は非正規化数への段階的なアンダーフローを許して丸める。
`EliminationReport` は実際の次数 `degrees()`、平衡化の指数 `equilibration_exponents()`、数値ランク `rank()`、`reciprocal_condition()`、使った方針 `policy()` を持つ。
入力に零多項式があると値は 0、逆条件数は 0 で、二つとも定数で行列の次数が 0 のときは値も逆条件数も 1 である。
どちらの場合も特異値分解を行わないので、`rank()` は `None` になる。
これらは行列全体の診断であり、係数ごとの誤差の上界でも共通因子の証明でもない。

判別式の計算では、$p$ を平衡化してから $p'/(n 2^{e})$ を作り、$\operatorname{Res}(p, p'/(n 2^e))$ に $(n 2^e)^n$ を掛け、$a_n$ で割り、$n \bmod 4$ が 2 か 3 のとき符号を反転する。
$n a_n$ のような積が桁あふれしないように、微分の前に係数を規格化している。
$p'/(n 2^e)$ の係数 $(i+1)p_{i+1}/(n2^e)$ は、$(i+1)/n$ が 2 進数で表せない $n$ では丸めを含む。
レポートは判別式の規格化の前の行列 $\mathbf{S}(p, p'/(n 2^e))$ の診断であり、平衡化の指数の二つ目は $p'/(n 2^e)$ をさらに平衡化した指数である。
次数が 2 未満の多項式では、レポートの次数は $[n, 0]$、逆条件数は 1、`rank()` は `None` になる。

`approximate_subresultant(left, right, j)` は正の添字 $j$ の $S_j$ の全係数を、昇べき順に $j + 1$ 個の `ApproximateElimination` として返す。
添字 0 は `InvalidInput`（`OutOfRange`）で拒否するので、終結式には `approximate_resultant` を使う。
$j \ge \min(m, n)$ は `InvalidInput`（`Inconsistent`）になる。

同じ次数の消去を繰り返すときは、次数と方針を検査済みの値として保持する。
`SylvesterElimination::new(left_degree, right_degree, index, policy)` は実際の次数と添字、レポートに使うランクの方針を保持し、前計算は行わない。
正の添字がどちらかの次数以上なら、ここで `InvalidInput`（`Inconsistent`）になる。
`matrix_order()` は行列の次数 $L = m + n - 2j$ を返す。
`coefficient(left, right, k)` は $S_j$ の $x^k$ の係数（$k \le j$）を一つ値で返し、呼ぶたびに作業領域を確保する。
`workspace()` は行列・LU 分解・特異値の領域を数値計算なしで確保した `EliminationWorkspace` を返し、`coefficient_scoped(left, right, k, &mut workspace, scope)` はその領域で同じ値を SciOxide 側の確保なしに求める。
`_scoped` の形は呼び出し側のスコープ（`ExecutionContext` か `SolveScope`）の一つのエポックとして動き、特異値分解と LU 分解の前後で取り消しと期限を確かめ、試行の記録を作業領域の `last_attempt()` に残す。
空の入力のようにエポックを始める前に拒否した呼び出しは、`PreflightRejected` として記録する。
次数や添字が値と合わない入力は `InvalidInput`（`Inconsistent`）、別の行列の次数の作業領域は `DimensionMismatch`、取り消しと期限切れは `ExecutionStopped` になる。
`SylvesterDiscriminant::new(degree, policy)` の `compute(coefficients)` と `compute_scoped(coefficients, &mut workspace, scope)` も同じ形で、`DiscriminantWorkspace` は導関数と消去の領域を持つ。
`_scoped` の形が失敗したときに変わるのは、作業領域の試行の記録だけである。
一つの係数の計算は時間 $O(L^3)$、メモリ $O(L^2)$ で、$S_j$ の全係数ではこれを $j + 1$ 回行う。
一度だけの計算には `approximate_resultant`、`approximate_subresultant`、`approximate_discriminant` を使えばよい。
これらは既定の方針のランクの方針 `RankPolicy::DimensionScaledEpsilon`（閾値 $\tau = L\varepsilon\,\sigma_{\max}$、$L$ は行列の次数）で数値ランクを判定する。

## 近い重根と第 1 部分終結式

次のセルは $p = (x-1)(x-1-\delta)(x+2)$ と $p'$ について、$\delta = 2^{-2}, 2^{-4}, \dots, 2^{-26}$ の終結式 $S_0$ と第 1 部分終結式 $S_1$（[定義](oxref:poly-subresultant-definition)）を求める。
次数は $\delta$ によらず 3 と 2 なので、終結式と $S_1$ の `SylvesterElimination` を一度だけ作り、作業領域を使い回す。
入力はランクの方針の閾値 $\tau = 2^{-q}$ で、変わるのはレポートの数値ランクだけであり、値は変わらない。
独立検算には記号計算で求めた閉形式を使う。

$$
\operatorname{Res}(p, p') = -9\delta^2(3+\delta)^2, \qquad
S_1(x) = -2(\delta^2 + 3\delta + 9)\,x + (18 + 15\delta - \delta^2)
$$

$S_1$ の根は $1 + \delta/2 - \delta^2/3 + O(\delta^3)$ で、近い 2 根の中点に近い。

```rust
//| id: poly-subresultant-near-double-root
//| ref: poly-subresultant-near-double-root
//| title: 近い重根と第 1 部分終結式
//| run: reactive
//| crates: [scioxide-core, scioxide-linalg, scioxide-poly]
//| inputs:
//|   threshold_power: {"type":"range","label":"ランク閾値 τ=2⁻ᑫ の q","description":"特異値が τ×最大特異値以下なら数値ランクから外す。","min":10,"max":50,"step":2,"value":30}
//| cases:
//|   - {"id":"loose-threshold","label":"τ = 2⁻¹⁰","description":"閾値を緩めると、δ = 2⁻⁴ の行から数値ランクが 4 に下がる。値の列は既定と変わらない。","inputs":{"threshold_power":10}}
//|   - {"id":"tight-threshold","label":"τ = 2⁻⁵⁰","description":"閾値を丸めの水準まで厳しくすると、数値ランクが下がるのは δ = 2⁻²⁴ 以下の 2 行だけになる。","inputs":{"threshold_power":50}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"near-double","path":"/rows/0/2","range":{"max":1e-13}}
//|       - {"artifact":"near-double","path":"/rows/5/4","equals":5}
//|       - {"artifact":"near-double","path":"/rows/6/4","equals":4}
//|       - {"artifact":"near-double","path":"/rows/12/6","range":{"max":1e-14}}
//|   - case: loose-threshold
//|     expect:
//|       - {"artifact":"near-double","path":"/rows/0/4","equals":5}
//|       - {"artifact":"near-double","path":"/rows/1/4","equals":4}
//|       - {"artifact":"near-double","path":"/rows/0/2","range":{"max":1e-13}}
//|   - case: tight-threshold
//|     expect:
//|       - {"artifact":"near-double","path":"/rows/10/4","equals":5}
//|       - {"artifact":"near-double","path":"/rows/11/4","equals":4}
//|       - {"artifact":"near-double","path":"/rows/0/2","range":{"max":1e-13}}
use scioxide_core::{ExecutionContext, RankThreshold, RealScalar, Tolerance};
use scioxide_linalg::RankPolicy;
use scioxide_poly::{
    ApproxPolynomial, PolynomialApproximationPolicy, PolynomialBasis, SylvesterElimination,
};

let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let sci6 = serde_json::json!({ "notation": "scientific", "significantDigits": 6 });
let fixed15 = serde_json::json!({ "fractionDigits": 15 });

let tau = RealScalar::powi(2.0_f64, -(threshold_power as i32));
let rank_policy =
    RankPolicy::Threshold(RankThreshold::new(0.0, tau).map_err(|e| e.to_string())?);
let policy = PolynomialApproximationPolicy::new(Tolerance::from_sqrt_epsilon(), rank_policy);
// p は 3 次、p′ は 2 次。S₀ = Res（5 次の行列）と S₁（3 次の行列）の消去を一度だけ作る
let resultant_plan = SylvesterElimination::new(3, 2, 0, policy).map_err(|e| e.to_string())?;
let first_plan = SylvesterElimination::new(3, 2, 1, policy).map_err(|e| e.to_string())?;
let mut resultant_workspace = resultant_plan.workspace().map_err(|e| e.to_string())?;
let mut first_workspace = first_plan.workspace().map_err(|e| e.to_string())?;
let context = ExecutionContext::sequential_native();
let (mut rows, mut values, mut conditions, mut theory) =
    (Vec::new(), Vec::new(), Vec::new(), Vec::new());
for k in (2..=26).step_by(2) {
    let delta = RealScalar::powi(2.0_f64, -k);
    let p = ApproxPolynomial::from_roots_with_options(&[1.0, 1.0 + delta, -2.0], policy)
        .map_err(|e| e.to_string())?;
    let derivative = p.derivative().map_err(|e| e.to_string())?;
    let (pc, dc) = (p.basis().coefficients(), derivative.basis().coefficients());
    let s0 = resultant_plan
        .coefficient_scoped(pc, dc, 0, &mut resultant_workspace, context)
        .map_err(|e| e.to_string())?;
    let s10 = first_plan
        .coefficient_scoped(pc, dc, 0, &mut first_workspace, context)
        .map_err(|e| e.to_string())?;
    let s11 = first_plan
        .coefficient_scoped(pc, dc, 1, &mut first_workspace, context)
        .map_err(|e| e.to_string())?;
    let resultant = s0.value().try_value().map_err(|e| e.to_string())?;
    let root = -s10.value().try_value().map_err(|e| e.to_string())?
        / s11.value().try_value().map_err(|e| e.to_string())?;
    // 独立検算: 記号計算による閉形式
    let resultant_exact = -9.0 * delta * delta * (3.0 + delta) * (3.0 + delta);
    let root_exact =
        (18.0 + 15.0 * delta - delta * delta) / (2.0 * (9.0 + 3.0 * delta + delta * delta));
    let rcond = s0.report().reciprocal_condition();
    let rank = s0.report().rank().map(|r| r.rank());
    rows.push((
        delta,
        resultant,
        ((resultant - resultant_exact) / resultant_exact).abs(),
        rcond,
        rank,
        root,
        (root - root_exact).abs(),
    ));
    values.push([delta, resultant.abs()]);
    conditions.push([delta, rcond]);
    theory.push([delta, resultant_exact.abs()]);
}
let columns = serde_json::json!([
    { "key": "0", "label": "δ [-]", "type": "number", "format": sci3 },
    { "key": "1", "label": "Res(p, p′) [-]", "type": "number", "format": sci6 },
    { "key": "2", "label": "閉形式との相対差 [-]", "type": "number", "format": sci3 },
    { "key": "3", "label": "Sylvester 行列の逆条件数 [-]", "type": "number", "format": sci3 },
    { "key": "4", "label": "数値ランク（最大 5）[-]", "type": "integer", "nullText": "-" },
    { "key": "5", "label": "S₁ の根 [-]", "type": "number", "format": fixed15 },
    { "key": "6", "label": "閉形式との差 [-]", "type": "number", "format": sci3 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "near-double" })
);
emit_line_chart!(
    &vec![
        serde_json::json!({
            "name": "|Res(p, p′)|",
            "points": values,
            "style": {"symbol": "circle", "showSymbol": true}
        }),
        serde_json::json!({
            "name": "閉形式 9δ²(3+δ)²",
            "points": theory,
            "style": {"lineType": "dashed"}
        }),
        serde_json::json!({
            "name": "Sylvester 行列の逆条件数",
            "points": conditions,
            "style": {"symbol": "diamond", "showSymbol": true}
        }),
    ],
    options = &serde_json::json!({
        "xLabel": "根の間隔 δ [-]",
        "yLabel": "大きさ [-]",
        "xType": "log",
        "yType": "log",
        "annotations": [{"kind": "line", "axis": "y", "value": tau, "label": "閾値 τ"}]
    })
);
```

表の終結式と逆条件数は、どちらも $\delta^2$ に比例して小さくなる。
中点 $1 + \delta/2$ では $p'$ の値が $-\delta^2/4$ で、$p$ の値も $O(\delta^2)$ なので、$p$ と $p'$ は $O(\delta^2)$ の摂動で共通根を持つ組に変わる。
逆条件数が $\tau$ を下回った行から数値ランクが 5 から 4 に下がり、数値的な GCD の次数は $5 - 4 = 1$ と読める。
既定の $q = 30$ では $\delta = 2^{-14}$ の行から、$q = 10$ では $\delta = 2^{-4}$ の行から、$q = 50$ では $\delta = 2^{-24}$ の行から下がる。
$q$ を変えると数値ランクの列だけが変わり、終結式の値と閉形式との相対差は変わらない。

終結式の閉形式との相対差は $\delta$ が小さくなると増え、$\delta = 2^{-24}$ で $0.17$、$2^{-26}$ で $1.7$ になって有効数字がなくなる。
$\delta = 2^{-24}$ では逆条件数が $1.9 \times 10^{-16}$ まで下がり、Jacobi の公式による目安 $L^2 \kappa_2 u$（$L = 5$）は約 15 になる。
係数が $O(1)$ の行列の行列式として、$10^{-13}$ を下回る値は丸めの水準に埋もれる。
一方、$S_1$ の主係数は $-18$ に近いまま小さくならず、$S_1$ の根は閉形式と $5 \times 10^{-16}$ 以内で一致し、近い 2 根の中点に近い。
近い共通根の位置は終結式の値ではなく次の部分終結式から精度よく求まる。
どの閾値で共通根とみなすかは方針の選択であり、表はその判断の材料である。

## まとめ

浮動小数点の終結式では、値（`ScaledValue`）と、平衡化した行列の数値ランク・逆条件数を分けて読む。
ランクの方針は数値ランクの診断だけを変え、値を変えない。
行列式の相対誤差の目安は $L^2 \kappa_2 u$ なので、逆条件数が $u$ に近い終結式の値には有効数字がないと考える。
近い共通根の位置は小さくなった終結式ではなく次の部分終結式 $S_1$ の根から求める。
どの閾値で共通根とみなすかは利用者の方針であり、逆条件数と数値ランクはその判断の材料で、共通因子の証明ではない。
同じ次数を繰り返すときは `SylvesterElimination` と `SylvesterDiscriminant` を作り、作業領域を使い回す。
