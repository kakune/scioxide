二つの多項式が共通因子を持つかどうかは、有理関数の約分、重根の判定、連立代数方程式の消去で問われる。
厳密な係数では Euclid の互除法が有限回の演算で最大公約多項式（GCD）を決める。
浮動小数点の係数ではわずかな丸めで GCD の次数が 0（互いに素）に落ちるので、「近くの多項式の組が持つ共通因子」を数値的に定める必要がある。
このページでは厳密な GCD、Sylvester 行列の特異値による近似 GCD の次数の判定と因子の回復、そのレポートの読み方を扱う。
除算の誤差の尺度は[多項式除算とデフレーション](../division-gcd-and-rational/)、近似 GCD による有理関数の約分は[有理関数の評価と約分](oxref:poly-rational-approximate-cancellation)で扱う。
記号 $u$ は単位丸め（`f64` で $2^{-53}$）、$\varepsilon$ は機械イプシロン（$2^{-52}$）を表し、多項式の係数は昇べき順に並べる。

## 最大公約多項式と Euclid の互除法

二つの多項式 $f, g$ の最大公約多項式 $\gcd(f, g)$ は、厳密な体では Euclid の互除法で有限回の演算で求まる。

$$
r_{-1} = f, \quad r_0 = g, \quad r_{k-1} = q_k r_k + r_{k+1} \quad (\deg r_{k+1} < \deg r_k)
$$

$r_{k+1} = 0$ となる直前の 0 でない剰余 $r_k$ をモニック（最高次の係数が 1）にしたものが $\gcd(f, g)$ である。
`ExactPolynomial::gcd` はこの方法で計算し、$\gcd(p, 0) = \operatorname{monic}(p)$、$\gcd(0, 0) = 0$ を返す。
`ExactPolynomial::lcm` は $(f/\gcd(f, g))\, g$ をモニックにした最小公倍多項式を返し、どちらかが 0 なら 0 を返す。
係数型の除算が $(a/b) \cdot b = a$ を満たさなければ、どちらも `NumericalInstability`（`Breakdown`）になる。

### 近似 GCD と数値ランク

浮動小数点の係数では、数学的に共通因子を持つ多項式の組でも、係数に $10^{-16}$ 程度の摂動が入るだけで最後の剰余が $O(u)$ の小さい定数になり、$\gcd(f, g) = 1$ と判定されてしまう。
互除法を続けて「小さい」剰余を 0 とみなす方法では、剰余列の打ち消しで誤差が増え、その閾値の選び方が結果を決める。
GCD は係数について不連続な関数なので、数値計算では「近くの多項式の組が持ちうる GCD のうち次数が最大のもの」を近似 GCD として扱う。

近似 GCD の次数は Sylvester 行列 $\mathbf{S}(f, g)$ の特異値から読める。
$f$ の次数を $m$、$g$ の次数を $n$ とする。
$\deg v < n$、$\deg w < m$ の組 $(v, w)$ を $vf + wg$ に移す線形写像の行列が $\mathbf{S}(f, g)^\top$ で、その核は $\gcd(f, g)$ の次数と同じ次元を持つ（[Sylvester 行列と終結式](oxref:poly-sylvester-resultant)）。
したがって厳密には $\deg \gcd(f, g) = m + n - \operatorname{rank} \mathbf{S}(f, g)$ であり、浮動小数点では小さい特異値の数がこの次数の推定になる。
$\mathbf{S}$ は係数について線形なので、次数を変えずに係数を $(\delta f, \delta g)$ だけずらした組が共通根を持つなら、特異値の Weyl の不等式から $\sigma_{\min}(\mathbf{S}(f, g)) \le \|\mathbf{S}(\delta f, \delta g)\|_2$ が成り立つ。
近くに共通根を持つ組がある入力ほど、最小特異値は小さい。
逆に最小特異値が小さいことから、近くの組が共通因子を持つことを厳密に導くことはできないので、次数の判定は推定である。

`approximate_gcd(left, right)` は次の手順で計算する。

1. 片方が零多項式なら、Sylvester 行列を使わずに $\gcd(p, 0) = \operatorname{monic}(p)$、$\gcd(0, 0) = 0$ を $O(m + n)$ で返す。
2. 各入力の行を、最大の係数が $[1, 2)$ に入る 2 の冪で割って平衡化した Sylvester 行列を作る。
   2 の冪による拡大縮小は丸めを生まず、係数の大きさの違う入力の一方が特異値を支配することを防ぐ。
3. 特異値分解で数値ランクを求め、$d = \min(m + n - \operatorname{rank}, m, n)$ を GCD の次数とする。
   数値ランクの判定には方針のうちランクの方針（`rank_policy()`）を使う。
4. 平衡化した入力 $\tilde f, \tilde g$ について、次数 $d$ の部分終結式に当たる畳み込み行列の最小特異値の右特異ベクトルから余因子 $v, w$（$\tilde f \approx hv$、$\tilde g \approx hw$）を初期化し、最小二乗で $d$ 次の因子 $h$ を作ってモニックにする（Z. Zeng, "The numerical greatest common divisor of univariate polynomials", *Contemp. Math.* 556, AMS, 2011, 187–217 の 7・9・10 節）。
5. 残差 $\|hv - \tilde f\|_2^2 + \|hw - \tilde g\|_2^2$ を $h, v, w$ について Gauss–Newton 法で小さくする。
   反復は最大 32 回、各反復の刻みの半減は最大 16 回とする。
   残差が 0 になったとき、刻みを 16 回半減しても残差が減らないとき、刻みの最大成分が（未知数と方程式の数の和）$\times\, \varepsilon \times$（係数の大きさ、ただし 1 以上）以下になったときに止まる。
   次数 $d$ はこの間に変えない。
6. 元の各入力を $h$ で一度ずつ長除法で割り、余因子と剰余を保持する。

特異値分解と Gauss–Newton の各反復は、どちらも次数 $m + n$ 程度の行列の計算で $O((m+n)^3)$ である。
方針が異なれば `InvalidInput`（`Inconsistent`）、特異値分解が収束しなければ `ConvergenceFailure` を返す。
手順 4 の最小二乗で作った因子の最高次の係数が 0 になれば `NumericalInstability`（`Breakdown`）、拡張指数の値を丸めて桁あふれすれば `NumericalInstability` を返す。
ランクの方針が緩すぎると、近い根を共通根とみなして不正確な次数を選ぶことがある。

### GCD と簡約のレポート

`ApproximateGcd` は、モニックな因子 `polynomial()`（$\gcd(0,0)$ では 0）、二つの入力の順の余因子 `cofactors()` と剰余 `remainders()`、レポート `report()` を持つ。
`ApproximateGcdReport` の各値は次のとおりである。

- `sylvester_rank()`：平衡化した Sylvester 行列の `RankReport`（ランク、最大ランク、使った閾値、尺度）。
  零入力の経路では `None` である。
- `reciprocal_condition()`：最小特異値と最大特異値の比で、閾値によらない。
  零入力の経路では `None` である。
- `operand_errors()`：入力ごとの $\max_i |\text{剰余}_i| / \max_i |\text{入力}_i|$ で、零多項式の入力では 0 である。
- `backward_error()`：`operand_errors()` の二つの値の最大である。
- `effective_degree()`：回復した因子の次数（零入力では代数的な恒等式による次数）。
- `equilibration_exponents()`：平衡化で除いた 2 の冪の指数（零入力では `[0, 0]`）。
- `policy()`：判定に使った方針。

`operand_errors()` は係数の最大絶対値で正規化した量で、[除算の再構成残差](oxref:poly-division-reconstruction-residual)の 1 ノルムによる定義とは異なる。
次数を決めるのはランクの方針だが、有理関数の約分（`ApproxRationalFunction::simplify`）は、各剰余が方針の許容誤差 $\tau_{\text{abs}} + \tau_{\text{rel}} \max_i |\text{入力}_i|$ 以下のときだけ行われる。
どちらの値も推定であり、共通根の証明ではない。

### 近い共通根と GCD の次数

次のセルは $f = (x-1)(x+2)$ と $g = (x - 1 - \delta)(x - 3)$ について、$\delta = 2^{-8}, 2^{-12}, \dots, 2^{-48}$ の近似 GCD を求める。
$\delta \ne 0$ なら厳密な GCD は定数である。
入力はランク閾値と許容誤差の相対値に共通に使う $\tau = 2^{-q}$ の $q$ で、表には逆条件数、選んだ次数、回復した因子の根の位置、正規化剰余を並べる。
独立検算には剰余の定理を使う。
次数 1 の因子 $x - \rho$ で割った剰余は $f(\rho)$ と $g(\rho)$ なので、正規化剰余は $|f(\rho)|/2$ と $|g(\rho)|/(4 + \delta)$ の大きい方になるはずである（分母は各入力の係数の最大絶対値）。
次数 0 の行には因子の根がないので、根の位置と剰余の定理による値を「-」で示す。

```rust
//| id: poly-approximate-gcd
//| ref: poly-approximate-gcd
//| title: 共通因子の摂動と数値ランク
//| run: reactive
//| crates: [scioxide-core, scioxide-linalg, scioxide-poly]
//| inputs:
//|   threshold_power: {"type":"range","label":"閾値 τ=2⁻ᑫ の q","description":"ランク閾値と許容誤差の相対値に同じ τ を使う。","min":12,"max":48,"step":4,"value":24}
//| cases:
//|   - {"id":"loose","label":"q = 12","description":"τ = 2⁻¹² では δ = 2⁻¹² から次数 1 が選ばれる。","inputs":{"threshold_power":12}}
//|   - {"id":"strict","label":"q = 48","description":"τ = 2⁻⁴⁸ では最後の行 δ = 2⁻⁴⁸ だけが次数 1 になる。","inputs":{"threshold_power":48}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"gcd","path":"/rows/3/2","equals":0}
//|       - {"artifact":"gcd","path":"/rows/4/2","equals":1}
//|       - {"artifact":"gcd","path":"/rows/4/3","approx":{"value":0.1,"atol":1e-3}}
//|       - {"artifact":"gcd","path":"/rows/4/4","approx":{"value":2.6822089593814276e-8,"rtol":1e-6}}
//|       - {"artifact":"gcd","path":"/rows/4/5","approx":{"value":2.6822089593814276e-8,"rtol":1e-6}}
//|   - case: loose
//|     expect:
//|       - {"artifact":"gcd","path":"/rows/0/2","equals":0}
//|       - {"artifact":"gcd","path":"/rows/1/2","equals":1}
//|   - case: strict
//|     expect:
//|       - {"artifact":"gcd","path":"/rows/9/2","equals":0}
//|       - {"artifact":"gcd","path":"/rows/10/2","equals":1}
use scioxide_core::{RankThreshold, RealScalar, Tolerance};
use scioxide_linalg::RankPolicy;
use scioxide_poly::{
    ApproxPolynomial, PolynomialApproximationPolicy, PolynomialBasis, approximate_gcd,
};

let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let sig4 = serde_json::json!({ "significantDigits": 4 });
let tau = RealScalar::powi(2.0_f64, -(threshold_power as i32));
let policy = PolynomialApproximationPolicy::new(
    Tolerance::new(0.0, tau).map_err(|e| e.to_string())?,
    RankPolicy::Threshold(RankThreshold::new(0.0, tau).map_err(|e| e.to_string())?),
);
// f = (x − 1)(x + 2) = x² + x − 2 は固定し、g = (x − 1 − δ)(x − 3) の根を動かす
let left = ApproxPolynomial::from_roots_with_options(&[1.0_f64, -2.0], policy)
    .map_err(|e| e.to_string())?;
let (mut rows, mut conditions, mut errors) = (Vec::new(), Vec::new(), Vec::new());
for p in (8..=48).step_by(4) {
    let delta = RealScalar::powi(2.0_f64, -p);
    let right = ApproxPolynomial::from_roots_with_options(&[1.0 + delta, 3.0], policy)
        .map_err(|e| e.to_string())?;
    let gcd = approximate_gcd(&left, &right).map_err(|e| e.to_string())?;
    let report = gcd.report();
    let factor = gcd.polynomial().basis().coefficients();
    // 次数 1 なら因子は x − ρ。独立検算: 剰余の定理で f(ρ)、g(ρ) から正規化剰余を作る
    // （分母 2 と 4 + δ は各入力の係数の最大絶対値）
    let (position, predicted) = if factor.len() == 2 {
        let rho = -factor[0];
        let f_rho = (rho - 1.0) * (rho + 2.0);
        let g_rho = (rho - 1.0 - delta) * (rho - 3.0);
        let predicted = (f_rho.abs() / 2.0).max(g_rho.abs() / (4.0 + delta));
        (Some((rho - 1.0) / delta), Some(predicted))
    } else {
        (None, None)
    };
    let rcond = report.reciprocal_condition();
    rows.push((
        delta,
        rcond,
        report.effective_degree(),
        position,
        report.backward_error(),
        predicted,
    ));
    if let Some(rcond) = rcond {
        conditions.push([delta, rcond]);
    }
    // 対数軸なので、剰余が 0 の行（次数 0）は図から除く
    if report.backward_error() > 0.0 {
        errors.push([delta, report.backward_error()]);
    }
}
let columns = serde_json::json!([
    { "key": "0", "label": "根の間隔 δ [-]", "type": "number", "format": sci3 },
    { "key": "1", "label": "逆条件数 [-]", "type": "number", "format": sci3, "nullText": "なし" },
    { "key": "2", "label": "選んだ次数 [-]", "type": "integer" },
    { "key": "3", "label": "(ρ − 1)/δ [-]", "type": "number", "format": sig4, "nullText": "-" },
    { "key": "4", "label": "正規化剰余の最大 [-]", "type": "number", "format": sci3 },
    { "key": "5", "label": "剰余の定理による値 [-]", "type": "number", "format": sci3, "nullText": "-" }
]);
emit_table_with_columns!(columns, rows, metadata = serde_json::json!({ "id": "gcd" }));
emit_line_chart!(
    &vec![
        serde_json::json!({
            "name": "Sylvester 行列の逆条件数",
            "points": conditions,
            "style": { "symbol": "diamond", "showSymbol": true }
        }),
        serde_json::json!({
            "name": "正規化剰余の最大（0 は除く）",
            "points": errors,
            "style": { "symbol": "circle", "showSymbol": true }
        })
    ],
    options = &serde_json::json!({
        "xLabel": "根の間隔 δ [-]",
        "yLabel": "大きさ [-]",
        "xType": "log",
        "yType": "log",
        "annotations": [{ "kind": "line", "axis": "y", "value": tau, "label": "閾値 τ" }]
    })
);
```

逆条件数はどの $\delta$ でもほぼ $0.14\,\delta$ で、$\tau$ を下回った行から次数 1 が選ばれる。
既定の $q = 24$（$\tau = 6.0 \times 10^{-8}$）では $\delta = 2^{-24}$ から、$q = 12$ では $\delta = 2^{-12}$ から、$q = 48$ では $\delta = 2^{-48}$ の行だけが次数 1 になる。
次数 1 の行では回復した根 $\rho$ が 1 と $1 + \delta$ の間にあり、$(\rho - 1)/\delta$ はほぼ $0.1$ で一定である（$\delta = 2^{-48}$ では $\rho - 1$ の丸めのため $0.125$）。
この $0.1$ は最小二乗の釣り合いで説明できる。
平衡化した入力は $\tilde f = f/2$、$\tilde g = g/4$ で、$t = \rho - 1$ とすると一次の範囲で $\tilde f(\rho) \approx 3t/2$、$\tilde g(\rho) \approx -(t - \delta)/2$ である。
二つの入力の次数は同じなので、$x - \rho$ の倍数までの距離はどちらも $|\tilde f(\rho)|$、$|\tilde g(\rho)|$ に同じ係数を掛けたものになり、その二乗和 $9t^2/4 + (t - \delta)^2/4$ は $t = \delta/10$ で最小になる。
正規化剰余はほぼ $0.45\,\delta$ で、剰余の定理による値と表示の桁まで一致する。
正規化剰余は逆条件数の約 3 倍なので、同じ $\tau$ を使っても、逆条件数が $\tau$ をわずかに下回るだけの $\delta$ では、次数 1 が選ばれる一方で約分の許容誤差の判定は通らないことがある。
次数 1 は指定した方針のもとで共通因子を近似した結果であり、厳密な共通根の証明ではない。
同じ $\delta$ でも $\tau$ を小さくすれば次数 0 が選ばれ、共通因子はないと判定される。

## まとめ

厳密な係数では `ExactPolynomial::gcd` と `lcm` が Euclid の互除法でモニックな結果を返す。
浮動小数点の係数では `approximate_gcd` を使い、次数は平衡化した Sylvester 行列の数値ランクで決まることを前提に、`reciprocal_condition()` を方針のランク閾値と比べて判定の余裕を読む。
回復した因子が入力をどれだけ割り切るかは `operand_errors()` で確かめ、一次の因子なら剰余の定理で独立に検算できる。
ランク閾値を緩めるほど近い根を共通根とみなすので、閾値は入力の係数の誤差の大きさに合わせて選ぶ。
次数の判定と剰余はどちらも推定であり、共通根の証明が必要なら厳密な係数か検証付きの計算を使う。
