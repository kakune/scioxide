[多項式補間・差商・Chebyshev 節点](../interpolation-and-chebyshev/)では重心公式を導き、補間誤差と Lebesgue 定数から節点の選び方を説明した。
このページはその公式を浮動小数点数で評価したときの丸め誤差と、重みの計算を扱う。
前半では二つの形の重心公式の誤差評価と、SciOxide の評価が返す条件数の推定を説明する。
後半では代表的な節点族の重みの閉じた形を `chebyshev_points` と一般の重みの計算で確かめ、差商と重みの低水準関数、厳密な体での補間をまとめる。

## 重心公式の丸め誤差

節点 $x_0,\dots,x_n$、節点多項式 $\omega(x)=\prod_k(x-x_k)$、重み $w_j=1/\prod_{k\ne j}(x_j-x_k)$、Lagrange 基底 $\ell_j$ の記号は[重心型 Lagrange 補間公式](oxref:poly-barycentric-formula)に従う。
単位丸めを $u$、評価点 $x$ での標本値に対する条件数を

$$
\kappa(x,y) = \frac{\sum_{j=0}^n |\ell_j(x)\,y_j|}{|p(x)|},\qquad
\lambda_n(x) = \sum_{j=0}^n |\ell_j(x)|
$$

とおく。
$\kappa(x,y)$ は各標本値を相対的に動かしたときの $p(x)$ の相対変化の倍率である。
$\lambda_n$ は [Lebesgue 関数](oxref:poly-lebesgue-constant)で、定数関数 $1$ を補間するときの $\kappa(x,1)$ に等しい。
Higham (2004) は重みの計算も含めた丸め誤差を一次の項まで次のように評価した（$n$ は次数）。

- 第一種の式は後退安定である。
  計算値は各標本値を相対的に $\gamma_{5n+5}=(5n+5)u/(1-(5n+5)u)$ 以内で動かした問題の正確な補間値に等しく、相対誤差は $\gamma_{5n+5}\,\kappa(x,y)$ 以下になる。
- 第二種の式の相対誤差は $(3n+4)u\,\kappa(x,y) + (3n+2)u\,\lambda_n(x)$ 以下になる。
  後退安定ではないが、$\lambda_n$ が小さい節点（Chebyshev 点）では前進安定である。

第二種の式で加わる項 $\lambda_n(x)$ は、分子と分母を別々に丸めることから来る。
分母の和 $\sum_j w_j/(x-x_j)$ は $\omega(x)$ を掛ければ $1$ になる量で、その相対条件数がちょうど $\lambda_n(x)$ である。
したがって節点の配置が悪いと、標本値が正確でも評価の精度が下がる。

### SciOxide の評価と条件数の推定

`ApproxPolynomial::interpolate_barycentric` で作った多項式は第二種の式で評価する。
評価は確保をせずに $O(n)$ で行い、次の三つの工夫で精度を保つ。

- 評価点に最も近い節点 $x_r$ を基準に選び、$\sum_j\ell_j=1$ を使って $p(x) = y_r + \sum_{j\ne r}\ell_j(x)(y_j - y_r)$ の形で計算する。
  分子と分母を基準の項 $w_r/(x-x_r)$ で割るので、小さな差 $x-x_r$ の逆数を作らない。
- 分子と分母の和は、各加算の丸め誤差を誤差なし変換（TwoSum）で取り出して足し戻す補償和で計算する。
- 途中の値が桁あふれ・アンダーフローすれば、指数の範囲を広げた表現で和全体を計算し直す。

評価点が節点に一致すれば、他の項がすべて 0 になり、保存した標本値をそのまま返す。
`evaluate_with_derivative` が返す `condition().condition_estimate()` は $\max(1,\kappa(x,y)) + \lambda_n(x)$ である。
$\sum_j|\ell_j(x)y_j|=0$ のとき（標本値がすべて 0 のときや、標本値が 0 の節点で評価したとき）は $p(x)=0$ が正確に求まるので、$1$ を返す。
この値は上の第二種の式の誤差評価の二つの項に対応し、節点が密集した点や等間隔節点の端の近くで大きくなる。
Higham の評価は工夫を加えない式についての上界なので、上の推定は誤差の拡大の目安として解釈する。

## 節点族の重心重み

代表的な節点では、重心重みが閉じた形で書ける（Berrut and Trefethen, 2004）。
第二種の重心公式では重みを共通の定数倍しても値が変わらないので、共通の因子を落とした次の形をそのまま使える。

| 節点 | 点 $x_j$（$j=0,\dots,n$） | 重み $w_j$（共通の因子を除く） | $\max\lvert w_j\rvert/\min\lvert w_j\rvert$ |
| :--- | :--- | :--- | :--- |
| 等間隔 | $-1+2j/n$ | $(-1)^j\binom{n}{j}$ | $\binom{n}{\lfloor n/2\rfloor}\approx 2^n\sqrt{2/(\pi n)}$ |
| 第 1 種 Chebyshev | $\cos\frac{(2j+1)\pi}{2n+2}$ | $(-1)^j\sin\frac{(2j+1)\pi}{2n+2}$ | $\approx 2(n+1)/\pi$ |
| 第 2 種 Chebyshev | $\cos\frac{j\pi}{n}$ | $(-1)^j\delta_j$（$\delta_0=\delta_n=\tfrac12$、他は 1） | $2$ |

等間隔節点の重みは $w_j = (-1)^{n-j}\binom{n}{j}/(h^n n!)$（$h=2/n$）から共通の因子を落としたもので、大きさが $2^n$ 程度の幅に広がる。
重みの大きさの広がりは、端の近くで Lebesgue 関数が大きくなることと対応する。
閉じた形を使えば重みの計算は $O(n)$ で済み、$O(n^2)$ の積を作らない。

`backend::barycentric::chebyshev_points(n, kind)` は、`ChebyshevPoints::Roots`（第 1 種、$T_n$ の零点）または `Extrema`（第 2 種、$T_{n-1}$ の極値点）の $n$ 点を $[-1,1]$ の昇順で作り、上の表の重みと一緒に返す。
ここでの `n` は点の個数で、表の $n$（次数）より一つ多い。
点は `OrthogonalFamily::zeros` と同じ角度の正弦から作るので厳密に対称で、点の個数が奇数なら中央は厳密に 0、第 2 種の両端は厳密に $\pm1$ である。
重みは先頭の点で正になる交互の符号を持ち、第 1 種では最大の絶対値が 1 になるように正規化する。
計算量は $O(n)$ で、長さ $n$ のベクトルを二つ確保する。
`n` が 0、または第 2 種で 2 未満なら `InvalidInput`（`OutOfRange`）、重みが表せなければ `NumericalInstability`（`Underflow`）になる。

次のセルは三つの節点族について、`barycentric_weights` が積から作る一般の重みと、上の表の閉じた形を比べる。
閉じた形は f64 の `sin` と二項係数の積で計算する独立な参照値で、最大の絶対値を 1 にそろえ、先頭の符号を比べる相手に合わせる。
`chebyshev_points` が返す重みも同じ参照値と比べ、重みの大きさを節点の位置に対して対数軸で描く。

```rust
//| id: poly-barycentric-weights
//| ref: poly-barycentric-weights
//| title: 三つの節点族の重心重みと閉じた形
//| run: reactive
//| crates: [scioxide-poly]
//| inputs:
//|   degree: {"type":"range","label":"次数 n","description":"節点数 n+1 を変える。","min":2,"max":40,"step":1,"value":14}
//| cases:
//|   - {"id":"degree-40","label":"n = 40","description":"等間隔節点の重みの広がりが 10¹¹ を超える。","inputs":{"degree":40}}
//|   - {"id":"degree-3","label":"n = 3","description":"低次では三つの節点族の重みの広がりに大差がない。","inputs":{"degree":3}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"weights","path":"/rows/0/1","range":{"max":1e-13}}
//|       - {"artifact":"weights","path":"/rows/1/1","range":{"max":1e-13}}
//|       - {"artifact":"weights","path":"/rows/1/2","range":{"max":1e-13}}
//|       - {"artifact":"weights","path":"/rows/2/2","range":{"max":1e-13}}
//|       - {"artifact":"weights","path":"/rows/0/3","approx":{"value":3432,"rtol":1e-12}}
//|       - {"artifact":"weights","path":"/rows/2/3","approx":{"value":2,"rtol":1e-12}}
//|   - case: degree-40
//|     expect:
//|       - {"artifact":"weights","path":"/rows/0/1","range":{"max":1e-12}}
//|       - {"artifact":"weights","path":"/rows/0/3","approx":{"value":137846528820,"rtol":1e-10}}
//|       - {"artifact":"weights","path":"/rows/1/3","approx":{"value":26.1,"atol":0.1}}
//|   - case: degree-3
//|     expect:
//|       - {"artifact":"weights","path":"/rows/0/3","approx":{"value":3,"rtol":1e-12}}
//|       - {"artifact":"weights","path":"/rows/1/2","range":{"max":1e-14}}
use scioxide_poly::backend::barycentric::{ChebyshevPoints, chebyshev_points};
use scioxide_poly::backend::polynomial_basis::barycentric_weights;

let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let n = degree.round() as usize;
let points = n + 1;
let equal: Vec<f64> = (0..points)
    .map(|j| -1.0 + 2.0 * j as f64 / n as f64)
    .collect();
let roots =
    chebyshev_points::<f64>(points, ChebyshevPoints::Roots).map_err(|e| e.to_string())?;
let lobatto =
    chebyshev_points::<f64>(points, ChebyshevPoints::Extrema).map_err(|e| e.to_string())?;
// 独立な参照値: 表の閉じた形の |w_j|（f64 の sin と二項係数の積）
let mut closed = [Vec::new(), Vec::new(), Vec::new()];
let mut binomial = 1.0_f64;
for j in 0..points {
    closed[0].push(binomial);
    binomial *= (n - j) as f64 / (j + 1) as f64;
    let angle = (2 * j + 1) as f64 * std::f64::consts::PI / (2 * points) as f64;
    closed[1].push(angle.sin());
    closed[2].push(if j == 0 || j == n { 0.5 } else { 1.0 });
}
// 閉じた形を最大 1 に正規化し、先頭の重みの符号から交互に符号を付けたときの差の最大
let gap = |weights: &[f64], magnitudes: &[f64]| {
    let largest = magnitudes.iter().fold(0.0_f64, |m, &c| m.max(c));
    let mut deviation = 0.0_f64;
    for (j, (&w, &c)) in weights.iter().zip(magnitudes).enumerate() {
        let sign = weights[0].signum() * if j % 2 == 0 { 1.0 } else { -1.0 };
        deviation = deviation.max((w - sign * c / largest).abs());
    }
    deviation
};
let families = [
    ("等間隔", &equal, None),
    ("第 1 種 Chebyshev", &roots.0, Some(&roots.1)),
    ("第 2 種 Chebyshev", &lobatto.0, Some(&lobatto.1)),
];
let (mut rows, mut series) = (Vec::new(), Vec::new());
for ((name, nodes, returned), magnitudes) in families.into_iter().zip(&closed) {
    // 一般の重み w_j = 1/Π(x_j − x_k) を O(n²) の積から作る（最大の絶対値 1 に正規化）
    let general = barycentric_weights(nodes).map_err(|e| e.to_string())?;
    // 正規化した一般の重みの最大は 1 なので、比は 1/min|w_j| になる
    let smallest = general.iter().fold(f64::INFINITY, |m, w| m.min(w.abs()));
    let reported = returned.map(|w| gap(w, magnitudes));
    rows.push((name, gap(&general, magnitudes), reported, 1.0 / smallest));
    let curve: Vec<[f64; 2]> = nodes
        .iter()
        .zip(&general)
        .map(|(&x, w)| [x, w.abs()])
        .collect();
    series.push(serde_json::json!({ "name": name, "points": curve }));
}
let columns = serde_json::json!([
    { "key": "0", "label": "節点" },
    { "key": "1", "label": "barycentric_weights と閉じた形の差 [-]", "type": "number", "format": sci3 },
    {
        "key": "2",
        "label": "chebyshev_points の重みと閉じた形の差 [-]",
        "type": "number",
        "format": sci3,
        "nullText": "対象外"
    },
    { "key": "3", "label": "max|w_j| / min|w_j| [-]", "type": "number", "format": sci3 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "weights" })
);
emit_scatter_chart!(
    &series,
    options = &serde_json::json!({
        "xLabel": "節点 x_j [-]",
        "yLabel": "正規化した重みの大きさ |w_j| [-]",
        "yType": "log"
    })
);
```

既定の $n=14$ では、どの族でも二つの重みと閉じた形の差は $10^{-16}$ から $10^{-15}$ の程度で、積から作る一般の重みも閉じた形と丸めの程度で一致する。
重みの大きさの比は等間隔節点で $\binom{14}{7}=3432$、第 1 種で約 9.57、第 2 種で厳密に 2 である。
$n=40$ では等間隔節点の比が $\binom{40}{20}\approx1.38\times10^{11}$ に広がる一方、第 1 種の比は $1/\sin(\pi/82)\approx26.1$ にとどまる。
図では等間隔節点の重みが中央で最大、端で最小になり、第 2 種の重みは両端の $1/2$ を除いて平らである。

## 差商の公開関数と厳密な補間

`backend` モジュールの関数は、他の SciOxide クレートが使う低水準の部品である。
入力の検査や失敗時の出力の扱いが関数ごとに違うので、通常の補間には `ApproxPolynomial` の構築関数を選ぶ。

`backend::polynomial_basis::barycentric_weights` は、相異なる実数または複素数の節点の重みを $O(n^2)$ で計算し、最大の絶対値が 1 になるように正規化して返す。
積は指数の範囲を広げた表現で作るので、差が桁あふれする節点や差がアンダーフローする節点でも重みを失わない。
正規化した重みが 0 に丸まれば `NumericalInstability`（`Underflow`）になる。
重心重みを呼び出し側が渡す一時領域へ作るときは `barycentric_weights_into` を使う。
出力と `ScaledValue` の一時領域はどちらも節点数と同じ長さにし、確保せずに同じ重みを計算する。
不正な節点と形状では出力を変えないが、数値計算が途中で失敗した場合は出力の一部が変わりうる。
呼び出し側は成功した重みだけを出力に反映する。

`backend::polynomial_basis::real_divided_differences_into` は、呼び出し側が所有する配列の実数の標本を、その場で差商に置き換える。
`dimension` 個の成分は同じ節点と一回の表の走査を共有し、$O(n^2\cdot\mathrm{dimension})$ の計算で確保は行わない。
失敗時は配列の内容が変わりうる。
`confluent_divided_differences_into` は値と傾きを受け取り、各節点を二重にした Hermite 補間の差商を作る。
`newton_value_from_iter`、`newton_value_and_derivative_from_iter` は係数の反復子を使って評価し、`newton_to_power_into` は単項式に変換する。
差の比を扱う `linear_difference_ratio`、`normalized_linear_difference`、`linear_multiply_difference` は、近い節点の差や積を、途中で桁あふれ・アンダーフローさせずに計算するための関数である。
結果の型と範囲エラーは[基底と評価の API](../../api/bases-and-evaluation/)で確認する。

`backend::barycentric::chebyshev_points` と `ChebyshevPoints` は[節点族の重心重み](#節点族の重心重み)で説明した。
同じモジュールの `evaluate` は第二種の重心公式を準備済みの節点・重み・係数で評価し、値、導関数、分母の和の条件数（補間多項式では $\lambda_n(x)$）、分子の項の絶対値の和を $|D|$ で割った値（`numerator_bound`）を `BarycentricEvaluation` で返す。
係数を標本値として扱えば補間多項式、独立な分子の係数として扱えば重心有理関数になるので、節点由来の多項式の重みと、任意の有理補間の重みを取り違えない。

厳密な体の補間では、`ExactPolynomialProductTree::new` で点の部分積の木を作り、`interpolate` へ値を渡す。
`new` は点が重複していても木を作るが、`interpolate` は重複した点を `InvalidInput` として拒む。
`interpolate` は $1/M'(x_i)$（$M=\prod_i(x-x_i)$）を剰余の木で求めてから Lagrange の項を木の上へ組み合わせ、高速な積を使えば $O(M(n)\log n)$ 回の体の演算で済む（$M(n)$ は長さ $n$ の積の計算コスト）。
$1/M'(x_i)$ は上の重心重み $w_i$ そのものである。
自由関数 `interpolate_exact` は提供しない。
SciOxide は `ExactField` をどの型にも実装しないので、有理数や有限体などの係数型は利用者が実装する。
`f64` は等号が厳密な体の演算を満たさず、Rust の孤児規則で外部の型に実装することもできないので、厳密な補間には使えない。
体の例と部分積の木による往復は[厳密な係数の演算と部分積の木](../exact-arithmetic-and-product-trees/)で扱う。

## まとめ

第二種の重心公式の丸め誤差は $\kappa(x,y)$ と $\lambda_n(x)$ の二つの項で決まり、SciOxide の `condition_estimate` はその和 $\max(1,\kappa)+\lambda_n$ を返すので、評価点ごとに精度の目安を確かめられる。
重みを共通の因子で割っても値は変わらないので、等間隔点と Chebyshev 点では閉じた形の重みを $O(n)$ で使える。
Chebyshev 点は `chebyshev_points` で点と重みを一緒に作り、任意の節点では `barycentric_weights` が $O(n^2)$ で指数の範囲を広げて重みを作る。
重みの大きさの比が $2^n$ 程度に広がる等間隔節点は、重みが正確でも評価と補間の両方で精度を失うので、高次では避ける。
`backend` の関数は失敗時の出力の扱いが関数ごとに違うので、成功した結果だけを使い、通常の補間には `ApproxPolynomial` の構築関数を使う。
