多項式環の除法は厳密な係数では有限回の演算で商と剰余を決める。
浮動小数点の係数では計算した商と剰余が恒等式をちょうどには満たさず、その残差が小さくても商の係数が正確とは限らない。
このページでは長除法のアルゴリズム、除算の誤差を測る二つの尺度（再構成残差と感度の推定）、根を一つずつ除くデフレーションで割る向きが誤差をどう変えるかを扱う。
除算を使う最大公約多項式は[最大公約多項式と近似 GCD](../approximate-gcd/)、有理関数は[有理関数の評価と約分](../rational-functions/)で扱う。
記号 $u$ は単位丸め（`f64` で $2^{-53}$）、$\varepsilon$ は機械イプシロン（$2^{-52}$）を表す。
多項式の係数は昇べき順に $p(x) = p_0 + p_1 x + \dots + p_m x^m$ と並べ、$\|p\|_1 = \sum_k |p_k|$ と書く。

## ユークリッド除法と後退誤差の評価

体 $F$ 上の多項式環 $F[x]$ で、被除多項式 $p(x)$（次数 $m$）と 0 でない除多項式 $d(x)$（次数 $n$）が与えられると、次の式を満たす商 $q(x)$ と剰余 $r(x)$ がただ一つ存在する。

$$
p(x) = d(x) q(x) + r(x) \quad (r = 0 \text{ または } \deg r < \deg d)
$$

$m < n$ なら $q = 0$、$r = p$ である。

### 長除法アルゴリズム

長除法（long division）は、剰余の候補 $r \leftarrow p$ から始め、$k = m - n, \dots, 0$ の順に次の二つを繰り返す。

1. 商の係数を $q_k = r_{n+k} / d_n$ と決める。
2. $r \leftarrow r - q_k x^k d$ と更新し、$x^{n+k}$ の係数を消す。

反復は $m - n + 1$ 回で、各回に $n$ 回の積和を行うので、計算量は $O((m - n + 1) n)$、追加のメモリは商と剰余の $O(m)$ である。
$d$ がモニック（最高次の係数が 1）なら係数の除算は要らない。

除多項式が一次式 $d(x) = x - c$ のとき、長除法は組立除法（Horner 法）と同じ漸化式になる。
商の係数は最高次の側から

$$
q_{m-1} = p_m, \qquad q_{k-1} = p_k + c\, q_k \quad (k = m - 1, \dots, 1)
$$

で決まり、剰余は $r = p_0 + c\, q_0 = p(c)$ である（剰余の定理）。
$c$ が $p$ の根なら剰余は 0 で、商は根を一つ除いた多項式になる。
根を一つ求めるたびに割って次数を下げ、残りの根を求める手順をデフレーション（deflation）という。

### 浮動小数点除算における相対再構成残差

浮動小数点の係数では、計算した商 $\hat q$ と剰余 $\hat r$ は恒等式をちょうどには満たさない。
SciOxide は次の正規化した再構成残差を後退誤差として返す。

$$
\eta_{\text{div}} = \frac{\|p - (d \hat q + \hat r)\|_1}{\|p\|_1 + \|\hat q\|_1 \|d\|_1 + \|\hat r\|_1}
$$

分母が 0 になるのは $p = 0$ のときだけで、そのときは $\eta_{\text{div}} = 0$ とする。
残差を $e = p - (d \hat q + \hat r)$ と置くと、$\hat q$ と $\hat r$ は被除多項式 $p - e$ の厳密な商と剰余である。
したがって $\eta_{\text{div}}$ が小さいことは、恒等式の各項の大きさに比べて $\eta_{\text{div}}$ 程度だけずらした被除多項式を厳密に割ったことを表す。
残差は指数部を別に持つ拡張指数の演算で計算するので、残差の計算そのものは桁あふれもアンダーフローも起こさない。
仮数の丸めは残るので、$\eta_{\text{div}}$ は $u$ 程度の大きさまでしか意味を持たない。

後退誤差が小さくても、商と剰余の係数が正確とは限らない。
レポートの `condition_estimate()` は感度の推定 $\kappa$ で、係数の一次の摂動 $|\delta p| \le u|p|$、$|\delta d| \le u|d|$ を長除法の漸化式に沿って絶対値で伝え、商と剰余の摂動の上界の和を $u(\|\hat q\|_1 + \|\hat r\|_1)$ で割って求める。
1 未満の値は 1 に切り上げ、`f64` で表せないほど大きい値は無限大で返す。
`forward_error_estimate()` は前進誤差の推定 $\gamma_N \kappa$（$\gamma_N = N\varepsilon/(1 - N\varepsilon)$、$N$ は被除多項式の係数の数）である。
どちらも一次の摂動による推定で、上界ではない。
$\gamma_N$ と評価の誤差のモデルは[表現と Horner 法](../representation-and-horner/)で説明している。

`ApproxPolynomial::div_rem(&divisor)` は単項式の基底の多項式どうしを割り、`PolynomialDivision` を返す。
`quotient()` と `remainder()` は商と剰余の多項式を借用し、`condition()` は上の後退誤差・感度・前進誤差の推定を持つ `PolynomialConditionReport` を返す。
許容誤差は商と剰余に影響せず、`div_rem` が除くのは厳密に 0 の末尾の係数だけである。
剰余が零多項式なら、係数 0 一つで表す。
二つの多項式の方針 `PolynomialApproximationPolicy` が異なると `InvalidInput`（`Inconsistent`）、除数が 0 なら `InvalidInput`（`OutOfRange`）、商か剰余の係数が `f64` の範囲を超えると `NumericalInstability` になる。
`div_rem` は呼ぶたびに Plan と作業領域を確保する。

同じ長さの除算を繰り返すときは、`PolynomialOperationRequest::Divide { dividend_len, divisor_len }` から `PolynomialOperationPlan` を準備し、`div_rem_into(a, b, quotient, remainder, workspace, context)` を使う（[高速な積・合成・Taylor シフト](../fast-operations-and-product-trees/)）。
入力は空でなく、末尾に厳密な 0 を持たない正準な係数列（零多項式は `[0]`）とし、外れると `InvalidInput` になる。
係数の数を $N_a, N_b$ とすると、商の長さは $\max(1, N_a + 1 - N_b)$、剰余の長さは $\max(1, \min(N_a, N_b - 1))$ で、出力は 0 のパディングを保つ。
長さの違う出力や足りない作業領域は `DimensionMismatch`、非有限の係数は `NonFinite`、取り消しや期限切れは `ExecutionStopped` になり、どの失敗でも出力は変わらない。
係数や途中の値が桁あふれかアンダーフローに近づくと、除算全体を拡張指数の演算でやり直し、各係数を最後に一度だけ丸める。
どちらの経路も、十分な作業領域があれば確保を行わない。

### 根を除く除算と誤差の増幅

一次式で割る漸化式 $q_{k-1} = p_k + c\, q_k$ では、$q_k$ に入った誤差が次の段で $c$ 倍される。
被除多項式の係数の摂動 $\delta p$ が商に与える誤差は、一次の範囲で

$$
\delta q_{k-1} = \delta p_k + c\, \delta q_k = \sum_{j=k}^{m} c^{\,j-k}\, \delta p_j
$$

となる。
$|c| > 1$ なら、$q_{k-1}$ の誤差は $\delta p_m$ の $|c|^{m-k}$ 倍程度まで増幅され、低次の係数ほど大きい。
$|c| < 1$ なら誤差は段ごとに縮む。
剰余が 0 のデフレーションでは、$p_k = q_{k-1} - c\, q_k$ を逆にたどり、同じ商を定数項の側から $q_0 = -p_0/c$、$q_k = (q_{k-1} - p_k)/c$ と求めることもできる。
この向きでは誤差が 1 段ごとに $1/c$ 倍になる。
Peters と Wilkinson は、残りの根より絶対値の小さい根は最高次の側から、大きい根は定数項の側から除くとデフレーションが安定になることを示した（G. Peters and J. H. Wilkinson, "Practical problems arising in the solution of polynomial equations", *J. Inst.
Maths Applics* 8, 1971, 16–35）。

SciOxide の長除法は常に最高次の側から進み、定数項の側から割る関数は提供しない。
係数を逆順に並べた $x^m p(1/x)$ を $x\, d(1/x) = 1 - cx$ で割り、商の係数を逆順に戻すと、同じ `div_rem` で定数項の側から割ったことになる。
剰余が 0 に近いデフレーションでは二つの向きはほぼ同じ商を与え、剰余は反対側の端の係数に現れる。

次のセルは $s(x) = 1 + x + \dots + x^m$（根は 1 以外の 1 の $m + 1$ 乗根で、絶対値は 1）と根 $c$ から積 $p = (x - c)s$ を作り、係数を $p_j(1 + (-1)^j \theta)$ に置き換えてから $x - c$ で割る。
セルの $m$ は商 $s$ の次数で、被除多項式 $p$ の次数は $m + 1$ である。
相対摂動 $\theta$ は測定値や前の計算から受け取った係数の誤差のモデルである。
$c$ が 0.5 の倍数なら積は丸めなしで求まるので、商の誤差はこの摂動と除算の丸めだけから生じる。
摂動前の厳密な商は $s$ なので、商の係数と 1 の差がそのまま前進誤差になる（独立検算）。
表は二つの向きの再構成残差 $\eta_{\text{div}}$、感度の推定 $\kappa$、$\kappa\theta$、商の相対誤差 $\|\hat q - s\|_1/\|s\|_1$、剰余の大きさを示す。
$\kappa\theta$ は、前進誤差の推定 $\gamma_N \kappa$ の $\gamma_N$ を摂動の大きさ $\theta$ に置き換えた値である。
図は係数ごとの誤差 $|\hat q_k - 1|$ を次数 $k$ に対して対数軸で描き、差が 0 の係数は図から除いてその数を表に出す。

```rust
//| id: poly-division-forward-error
//| ref: poly-division-forward-error
//| title: 根を除く除算の後退誤差と前進誤差
//| run: reactive
//| crates: [scioxide-poly]
//| inputs:
//|   root: {"type":"range","label":"除く根 c [-]","description":"|c| > 1 では、最高次から進む長除法が係数の誤差を 1 段ごとに c 倍にする。","min":0.5,"max":20,"step":0.5,"value":10}
//|   degree: {"type":"range","label":"商 s の次数 m","description":"長除法の段数を変える。","min":2,"max":14,"step":1,"value":6}
//|   perturbation_power: {"type":"range","label":"係数の相対摂動 θ = 10ᵉ の e","description":"被除多項式の係数 pⱼ を pⱼ(1 + (−1)ʲθ) に置き換える。","min":-15,"max":-6,"step":1,"value":-12}
//| cases:
//|   - {"id":"small-root","label":"c = 0.5","description":"|c| < 1 では、最高次から進む長除法でも誤差は増えない。","inputs":{"root":0.5}}
//|   - {"id":"high-degree","label":"m = 14","description":"段数が増えると、最高次から進む長除法の誤差は c¹⁴θ の桁まで増える。","inputs":{"degree":14}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"division","path":"/rows/0/1","range":{"max":1e-15}}
//|       - {"artifact":"division","path":"/rows/0/4","range":{"min":1e-7,"max":1e-5}}
//|       - {"artifact":"division","path":"/rows/1/4","range":{"max":1e-11}}
//|   - case: small-root
//|     expect:
//|       - {"artifact":"division","path":"/rows/0/4","range":{"max":1e-11}}
//|   - case: high-degree
//|     expect:
//|       - {"artifact":"division","path":"/rows/0/1","range":{"max":1e-15}}
//|       - {"artifact":"division","path":"/rows/0/4","range":{"min":0.1}}
//|       - {"artifact":"division","path":"/rows/1/4","range":{"max":1e-11}}
use scioxide_poly::{ApproxPolynomial, PolynomialBasis};

let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let theta = 10.0_f64.powf(perturbation_power);
// s(x) = 1 + x + … + xᵐ と d(x) = x − c。c が 0.5 の倍数なら積 p = d·s は丸めなしで求まる
let ones = vec![1.0_f64; degree as usize + 1];
let s = ApproxPolynomial::monomial(ones.clone()).map_err(|e| e.to_string())?;
let divisor = ApproxPolynomial::monomial(vec![-root, 1.0]).map_err(|e| e.to_string())?;
let product = divisor.try_mul(&s).map_err(|e| e.to_string())?;
// データの誤差のモデル: pⱼ に符号が交互の相対摂動 (−1)ʲθ を加える
let perturbed: Vec<f64> = product
    .basis()
    .coefficients()
    .iter()
    .enumerate()
    .map(|(j, &value)| value * (1.0 + if j % 2 == 0 { theta } else { -theta }))
    .collect();
let dividend = ApproxPolynomial::monomial(perturbed.clone()).map_err(|e| e.to_string())?;
// 逆順の係数 xⁿ f(1/x) を作る。p の逆順を [1, −c]（1 − cx）で割ると、商は s の逆順になる
let reversed = |coefficients: &[f64]| {
    ApproxPolynomial::monomial(coefficients.iter().rev().copied().collect())
        .map_err(|e| e.to_string())
};
let forward = dividend.div_rem(&divisor).map_err(|e| e.to_string())?;
let backward = reversed(&perturbed)?
    .div_rem(&reversed(divisor.basis().coefficients())?)
    .map_err(|e| e.to_string())?;
let backward_quotient = reversed(backward.quotient().basis().coefficients())?;

// 独立検算: 摂動前の厳密な商は s = [1, …, 1] なので、|q̂ₖ − 1| が前進誤差になる
let mut rows = Vec::new();
let mut series = Vec::new();
for (name, result, quotient) in [
    ("最高次から（x − c で割る）", &forward, forward.quotient()),
    (
        "定数項から（逆順を 1 − cx で割る）",
        &backward,
        &backward_quotient,
    ),
] {
    let errors: Vec<f64> = quotient
        .basis()
        .coefficients()
        .iter()
        .map(|&value| (value - 1.0).abs())
        .collect();
    let relative = errors.iter().sum::<f64>() / ones.len() as f64;
    let condition = result.condition();
    // 対数軸なので、差が 0 の係数は図から除く
    let points: Vec<[f64; 2]> = errors
        .iter()
        .enumerate()
        .filter(|(_, error)| **error > 0.0)
        .map(|(k, &error)| [k as f64, error])
        .collect();
    rows.push((
        name,
        condition.backward_error(),
        condition.condition_estimate(),
        condition.condition_estimate() * theta,
        relative,
        result.remainder().basis().coefficients()[0].abs(),
        errors.len() - points.len(),
    ));
    series.push(
        serde_json::json!({ "name": name, "points": points, "style": { "symbol": "circle" } }),
    );
}
let columns = serde_json::json!([
    { "key": "0", "label": "割る向き" },
    { "key": "1", "label": "再構成残差 η_div [-]", "type": "number", "format": sci3 },
    { "key": "2", "label": "感度の推定 κ [-]", "type": "number", "format": sci3 },
    { "key": "3", "label": "κθ [-]", "type": "number", "format": sci3 },
    { "key": "4", "label": "商の相対誤差 ‖q̂ − s‖₁/‖s‖₁ [-]", "type": "number", "format": sci3 },
    { "key": "5", "label": "剰余 |r̂| [-]", "type": "number", "format": sci3 },
    { "key": "6", "label": "差が 0 の係数 [個]", "type": "integer" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "division" })
);
emit_line_chart!(
    &series,
    options = &serde_json::json!({
        "xLabel": "商の係数の次数 k [-]",
        "yLabel": "|q̂ₖ − 1| [-]",
        "yType": "log",
        "annotations": [{
            "kind": "line",
            "axis": "y",
            "value": theta,
            "label": "摂動 θ",
            "style": { "lineType": "dashed" }
        }]
    })
);
```

既定値（$c = 10$、$m = 6$、$\theta = 10^{-12}$）で最高次から割ると、再構成残差は 0 だが、商の相対誤差は $2.9 \times 10^{-7}$ で摂動の約 $3 \times 10^5$ 倍になる。
図の誤差は $k = 6$ の $10^{-12}$ から $k = 0$ の $1.8 \times 10^{-6}$ まで、1 段ごとにほぼ 10 倍に増える。
感度の推定は $\kappa = 6.7 \times 10^6$ で、$\kappa\theta = 6.7 \times 10^{-6}$ は実際の誤差の約 23 倍である。
定数項の側から割ると $\kappa = 2.8$、商の相対誤差は $8.4 \times 10^{-13}$ で、摂動と同じ桁にとどまる。
$c = 0.5$ では関係が逆になり、最高次からの $4.0 \times 10^{-13}$ に対して、定数項からは $2.4 \times 10^{-11}$ になる。
$m = 14$ では最高次から割った商の相対誤差が 13 に達して商は一桁も正しくないが、再構成残差は $2.9 \times 10^{-18}$ のままである。
再構成残差は恒等式との整合だけを測るので、商の精度は $\kappa$ と摂動の大きさの積で見積もる。

### 厳密な係数の除算

厳密な係数（`ExactField`）の多項式 `ExactPolynomial` では、`div_rem` が体の演算だけで長除法を行い、商と剰余を丸めなしで返す。
零の除数は `InvalidInput`（`OutOfRange`）になる。
係数型の除算は $(a/b) \cdot b = a$ を満たす必要がある。
モニックでない除数での長除法は各段で最高次の項が消えることを確かめ、この法則が破れていれば `NumericalInstability`（`Breakdown`）で止まる。
厳密な演算の計算量は係数の演算回数で数え、係数のビット長の増え方は利用者の係数型が決める。

## まとめ

除算では商と剰余だけでなく、再構成残差 $\eta_{\text{div}}$ と感度の推定 $\kappa$ を別々に読み、残差が 0 でも商の係数が一桁も正しくない除算があることを前提にする。
根 $c$ で割るデフレーションは、$c$ が残りの根より絶対値で小さければ `div_rem` のまま、大きければ係数を逆順にして $1 - cx$ で割ると誤差が増えない。
商の係数の誤差は$\kappa$ に係数の相対誤差の大きさを掛けた値で見積もる。
同じ長さの除算を繰り返すときは `PolynomialOperationPlan` と `div_rem_into` で確保なしに割る。
厳密な係数では `ExactPolynomial::div_rem` が丸めなしで割り、係数型の除算の法則の破れだけを `Breakdown` で返す。
