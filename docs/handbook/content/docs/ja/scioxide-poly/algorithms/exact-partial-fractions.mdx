浮動小数点の係数の[部分分数分解](../partial-fractions/)では、極が近づくと係数の誤差が単位丸めを逆条件数で割った程度まで増え、極が近すぎると Plan の準備が拒否される。
係数が有理数のように厳密に表せるなら、丸めのない体の演算で分解でき、得られた項は等号として成り立つ。
このページでは `ExactPartialFractionPlan` のアルゴリズムと仕様、有理数の係数型を利用者が実装して使う方法を扱う。
分解の存在と一意性、留数の公式は[部分分数分解](oxref:poly-partial-fraction-form)で説明している。

## 補因子の逆元と F 進展開

`ExactPartialFractionPlan::new(&denominator, &[(&factor, multiplicity), ...])` は、`ExactField` の係数のモニックの分母と、モニックで定数でない因子と正の重複度を検査する。
分母がモニックでない、因子が定数かモニックでない、重複度が 0、次数の和が合わない、因子の冪の積が分母と厳密に一致しない、因子が互いに素でない、のどれかなら `InvalidInput`（`Inconsistent`）になる。
因子は既約である必要はなく、Plan が既約因子を探すことはない。
準備では、各因子について補因子 $C_i = D / F_i^{m_i}$ の $F_i^{m_i}$ を法とする逆元を、拡張 Euclid の互除法で一度だけ求める。
逆元が存在しないことが、因子が互いに素でないことの検出を兼ねる。
準備は $r$ 個の因子と $n = \deg D$ について $O(r n^2)$ 回の体の演算を使い、Plan は $O(n)$ 個の係数を保持する。
係数型の除算が $(a/b) \cdot b = a$ を満たさなければ `NumericalInstability`（`Breakdown`）になる。

`decompose(&numerator)` は、分子を分母で割って多項式部と剰余 $R$ を作り、因子ごとに $A_i = R\, C_i^{-1} \bmod F_i^{m_i}$ を一つの積と一つの剰余で計算する。
$A_i$ を $F_i$ で繰り返し割る $F_i$ 進展開で各冪の項を取り出す（J. von zur Gathen and J. Gerhard, *Modern Computer Algebra*, 3rd ed., Cambridge University Press, 2013, §5.11）。
分子の次数に制限はない。
結果の `ExactPartialFractions` は多項式部 `polynomial()` と、因子の入力順、冪の昇順の `ExactPartialFractionTerm` の列 `terms()` を持ち、`reconstruct()` で項の和を既約な `ExactRationalFunction` に戻せる。
各項は因子 `factor()`、冪 `power()`、分子 `numerator()` を持ち、一次の因子の冪 1 の項では分子が定数の留数になる。
分解は浮動小数点の丸めを含まないので、得られた項は等号として成り立ち、レポートや許容誤差を持たない。

## 有理数の係数での分解

SciOxide は有理数の係数型を提供しない。
次の定義のブロックは `i128` の既約分数 `Q` に `ExactCoefficient` と `ExactField` を実装し、多項式の係数を「分子/分母」の形で並べる表示用の関数 `show` を置く。
`Q` の演算は桁あふれを検査しないので、途中の値が `i128` を超えない入力に限って使う。

```rust
//| id: poly-partial-fraction-rational-type
//| kind: definitions
//| title: i128 の既約分数による有理数の係数型
//| crates: [scioxide-poly]
use scioxide_poly::{ExactCoefficient, ExactField, ExactPolynomial};
use std::ops::{Add, Div, Mul, Neg, Sub};

/// 既約分数 p/q（q > 0）で表す有理数。積と和の前に約して、i128 があふれにくくする
#[derive(Clone, Copy, Debug, PartialEq)]
pub(crate) struct Q(pub(crate) i128, pub(crate) i128);

fn gcd(x: i128, y: i128) -> i128 {
    let (mut x, mut y) = (x.abs(), y.abs());
    while y != 0 {
        (x, y) = (y, x % y);
    }
    x
}

impl Q {
    pub(crate) fn new(a: i128, b: i128) -> Self {
        let g = gcd(a, b) * b.signum();
        Self(a / g, b / g)
    }
}

impl Add for Q {
    type Output = Self;
    fn add(self, b: Self) -> Self {
        let g = gcd(self.1, b.1);
        Self::new(self.0 * (b.1 / g) + b.0 * (self.1 / g), self.1 / g * b.1)
    }
}

impl Neg for Q {
    type Output = Self;
    fn neg(self) -> Self {
        Self(-self.0, self.1)
    }
}

impl Sub for Q {
    type Output = Self;
    fn sub(self, b: Self) -> Self {
        self + -b
    }
}

impl Mul for Q {
    type Output = Self;
    fn mul(self, b: Self) -> Self {
        let (g, h) = (gcd(self.0, b.1), gcd(b.0, self.1));
        Self::new((self.0 / g) * (b.0 / h), (self.1 / h) * (b.1 / g))
    }
}

impl Div for Q {
    type Output = Self;
    fn div(self, b: Self) -> Self {
        self * Q::new(b.1, b.0)
    }
}

impl ExactCoefficient for Q {
    fn zero() -> Self {
        Q(0, 1)
    }
    fn one() -> Self {
        Q(1, 1)
    }
    fn from_usize(n: usize) -> Self {
        Q(n as i128, 1)
    }
}

impl ExactField for Q {}

/// 昇べき順の係数を「分子/分母」の形で並べた文字列
pub(crate) fn show(p: &ExactPolynomial<Q>) -> String {
    let terms: Vec<String> = p
        .coefficients()
        .iter()
        .map(|q| {
            if q.1 == 1 {
                q.0.to_string()
            } else {
                format!("{}/{}", q.0, q.1)
            }
        })
        .collect();
    terms.join(", ")
}
```

次のセルは[浮動小数点の分解のセル](oxref:poly-partial-fraction-repeated-poles)と同じ有理関数を有理数の係数で分解する。
分母は $D = (x - 1)^2 F_1$（$F_1 = (x - 1)^2 + s^2$）、分子は部分分数 $a/(x-1) + 2/(x-1)^2 + (3 + 4x)/F_1$ を通分した式で、因子 $x - 1$ に重複度 2、$F_1$ に重複度 1 を与える。
入力は一次の極の係数 $a$ と、極の対の距離 $s$ の選択である。
$s = 0$ では $F_1 = (x - 1)^2$ になり、二つの因子が互いに素でなくなる。
1 つ目の表は各項の因子と分子を、作るときに使った分子と比べる。
2 つ目の表は `reconstruct()` で戻した有理関数を、$N/D$ を既約にしたものと等号で比べる（独立検算）。

```rust
//| id: poly-exact-partial-fractions
//| ref: poly-exact-partial-fractions
//| title: 有理数の係数での厳密な部分分数分解
//| run: reactive
//| uses: [poly-partial-fraction-rational-type]
//| crates: [scioxide-poly]
//| inputs:
//|   residue: {"type":"range","label":"一次の極の係数 a [-]","min":-2,"max":3,"step":1,"value":1}
//|   spacing: {"type":"select","label":"極の対の距離 s","description":"s = 0 では F₁ = (x − 1)² になり、因子が互いに素でなくなる。","options":["1","1/16","1/256","0"],"value":"1/256"}
//| cases:
//|   - {"id":"unit-spacing","label":"s = 1","description":"離れた極でも、係数は作るときの値に厳密に一致する。","inputs":{"spacing":"1"}}
//|   - {"id":"coincident","label":"s = 0","description":"互いに素でない因子は、Plan の準備で InvalidInput として拒否される。","inputs":{"spacing":"0"}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"terms","path":"/rows/0/2","equals":"1"}
//|       - {"artifact":"terms","path":"/rows/2/2","equals":"3, 4"}
//|       - {"artifact":"terms","path":"/rows/2/4","equals":"一致"}
//|       - {"artifact":"check","path":"/rows/0/0","equals":"一致"}
//|   - case: unit-spacing
//|     expect:
//|       - {"artifact":"terms","path":"/rows/1/2","equals":"2"}
//|       - {"artifact":"check","path":"/rows/0/0","equals":"一致"}
//|   - case: coincident
//|     expect:
//|       - {"artifact":"rejection","path":"/rows/0/0","equals":"InvalidInput"}
use scioxide_poly::{ExactPartialFractionPlan, ExactPolynomial, ExactRationalFunction};

let s = match spacing.as_str() {
    "1" => Q(1, 1),
    "1/16" => Q(1, 16),
    "1/256" => Q(1, 256),
    _ => Q(0, 1),
};
let poly = |c: Vec<Q>| ExactPolynomial::new(c).map_err(|e| e.to_string());
let a = Q(residue as i128, 1);
let linear = poly(vec![Q(-1, 1), Q(1, 1)])?;
let square = linear.try_mul(&linear).map_err(|e| e.to_string())?;
// F₁ = (x − 1)² + s²。分子は a/(x − 1) + 2/(x − 1)² + (3 + 4x)/F₁ を通分した式
let pair = poly(vec![Q(1, 1) + s * s, Q(-2, 1), Q(1, 1)])?;
let denominator = square.try_mul(&pair).map_err(|e| e.to_string())?;
let head = poly(vec![Q(2, 1) - a, a])?;
let tail = poly(vec![Q(3, 1), Q(4, 1)])?;
let numerator = head
    .try_mul(&pair)
    .and_then(|p| p.try_add(&tail.try_mul(&square)?))
    .map_err(|e| e.to_string())?;
match ExactPartialFractionPlan::new(&denominator, &[(&linear, 2), (&pair, 1)]) {
    Err(error) => {
        emit_table_with_columns!(
            ["エラーの分類", "詳細"],
            vec![(format!("{:?}", error.kind()), format!("{:?}", error.view()))],
            metadata = serde_json::json!({ "id": "rejection" })
        );
    }
    Ok(plan) => {
        let fractions = plan.decompose(&numerator).map_err(|e| e.to_string())?;
        // 独立検算 1: 作るときに使った分子 a、2、3 + 4x と、厳密な係数のまま比べる
        let expected = [vec![a], vec![Q(2, 1)], vec![Q(3, 1), Q(4, 1)]];
        let mut rows = Vec::new();
        for (term, reference) in fractions.terms().iter().zip(expected) {
            let reference = poly(reference)?;
            let verdict = if term.numerator() == &reference {
                "一致"
            } else {
                "不一致"
            };
            rows.push((
                show(term.factor()),
                term.power(),
                show(term.numerator()),
                show(&reference),
                verdict,
            ));
        }
        emit_table_with_columns!(
            [
                "因子（昇べき順）",
                "分母の冪",
                "分子（昇べき順）",
                "作るときの分子",
                "比較"
            ],
            rows,
            metadata = serde_json::json!({ "id": "terms" })
        );
        // 独立検算 2: 項の和を既約な有理関数に戻し、N/D を既約にしたものと比べる
        let rebuilt = fractions.reconstruct().map_err(|e| e.to_string())?;
        let original = ExactRationalFunction::new(numerator.clone(), denominator.clone())
            .map_err(|e| e.to_string())?;
        let verdict = if rebuilt == original {
            "一致"
        } else {
            "不一致"
        };
        emit_table_with_columns!(
            ["reconstruct と N/D", "多項式部"],
            vec![(verdict, show(fractions.polynomial()))],
            metadata = serde_json::json!({ "id": "check" })
        );
    }
}
```

既定の $s = 1/256$ では、$F_1$ の定数項は $65537/65536$ で、三つの項の分子は作るときの値 $1$、$2$、$3 + 4x$ と厳密に一致し、`reconstruct()` も元の有理関数と一致する。
浮動小数点の Plan が $s = 2^{-24}$ で拒否した近い極（[近い極での係数の誤差と再構成](oxref:poly-partial-fraction-near-poles-error)）も、厳密な Plan は係数型が値を表せる限り分解する。
$s = 0$ では、Plan の準備が `InvalidInput`（`Inconsistent`、詳細は "factors must be pairwise coprime"）で拒否される。
浮動小数点の Plan が数値ランクで拒否するのに対し、厳密な Plan は逆元の不存在で拒否する。
厳密な演算の誤差は 0 だが、途中の有理数の桁は $s$ が小さいほど増える。
このセルの `Q` は $s = 1/4096$ で途中の積が `i128` を超えるので、その値を選択肢から除いた。
厳密な演算の計算量は係数の演算回数で数え、係数の桁の増え方は利用者の係数型が決める。

## まとめ

係数が厳密に表せる体なら、`ExactPartialFractionPlan` が補因子の逆元を準備の一度だけ求め、分解は丸めのない等号として成り立つ。
浮動小数点の Plan が数値ランクで拒否する近い極も、厳密な Plan は因子が互いに素である限り分解する。
互いに素でない因子は逆元が存在しないことで検出され、`InvalidInput`（`Inconsistent`）になる。
SciOxide は有理数の型を提供しないので、`ExactCoefficient` と `ExactField` を実装した型を用意し、係数の桁の増え方とその上限は係数型の側で管理する。
