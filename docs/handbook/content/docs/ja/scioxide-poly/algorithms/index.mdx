多項式の計算では、同じ式でも、どの基底でどの係数型に保存するかによって誤差の伝わり方が変わる。
関数の近似、係数の演算、根の診断は目的が異なるので、必要な結果に合う誤差の尺度で読む。
このページは各アルゴリズムページに共通する誤差の区別、記号、共通の規約をまとめ、最後にページの一覧を置く。

## 三種類の誤差

関数 $f$ を $n$ 次多項式 $p_n$ で近似し、点 $x$ での値を浮動小数点で計算して $\widehat p_n(x)$ を得るとする。
全体の誤差は二つの項に分かれる。

$$
f(x)-\widehat p_n(x)=\underbrace{f(x)-p_n(x)}_{\text{近似誤差}}+\underbrace{p_n(x)-\widehat p_n(x)}_{\text{計算の誤差}} .
$$

第一項の近似誤差（表現の誤差）は、次数、節点の配置、標本のノイズ、関数の滑らかさで決まり、計算をどれほど正確に行っても残る。
第二項は保存した係数の丸めと演算の丸めから生じる。
この項は後退誤差と条件数の積で見積もるのが数値解析の標準的な方法である。

後退誤差は計算値 $\widehat p_n(x)$ を「少し摂動した入力に対する厳密な値」とみなすときの、最小の入力の摂動の大きさである。
多項式の評価では、係数を $a_k(1+\theta_k)$ に変えた多項式の厳密な値とみなし、$\eta=\max_k|\theta_k|$ を成分ごとの後退誤差とする。
条件数は入力の相対的な摂動が出力の相対的な変化に何倍で伝わるかを表す、問題そのものの性質である。
二つを合わせると、一次の近似で次の関係が成り立つ。

$$
\frac{|p_n(x)-\widehat p_n(x)|}{|p_n(x)|}\lesssim\kappa(p_n,x)\,\eta .
$$

後退誤差が小さいアルゴリズムを後退安定という。
後退安定なアルゴリズムでも、条件数が大きい問題では前進誤差（値そのものの誤差）が大きくなる。

| 誤差・感度 | 調べる量 | 主な確認方法 |
|---|---|---|
| 近似誤差 | $f-p_n$。次数・節点・標本・関数の解析性で決まる | 既知の関数、次数を上げたときの変化、独立な格子での評価 |
| 丸め誤差と後退誤差 | 保存した多項式の厳密な値と計算値の差を、係数の摂動に置き換えた大きさ | 閉形式、別の評価法、適用条件を満たす誤差解析 |
| 条件数 | 係数・節点・標本値の摂動に対する値や根の変化の倍率 | 係数の摂動実験、条件数の推定、重根や近接根の診断 |

小さい残差は元の関数への近似誤差や根の前進誤差が小さいことを直接は意味しない。
厳密な係数型を使えば代数演算の等号を保てるが、入力のモデルの誤差はなくならない。
API が返す後退誤差・前進誤差・条件数・残差は推定値であり、包含が保証された区間ではない。
共通の概念の定義は[浮動小数点と条件](../../concepts/floating-point-and-conditioning/)、[許容誤差と残差](../../concepts/tolerances-and-residuals/)にある。

## 記号

| 記号 | 意味 |
|---|---|
| $n$、$N$ | 多項式の次数と、保存座標の数（単項式では $N=n+1$） |
| $m$ | 本文で指定する標本数または評価点の数 |
| $a_k$ | 昇べき順の単項式係数 |
| $c_k$、$\phi_k$ | 指定した基底の係数と基底関数 |
| $x$、$t$ | 物理座標と基準座標。直交基底では $t=(x-\mathrm{shift})/\mathrm{scale}$ |
| $u$、$\varepsilon$ | 単位丸めと機械イプシロン（`EPSILON`）。最近接丸めの binary64 では $u=\varepsilon/2=2^{-53}$ |
| $\gamma_j(u)$、$\gamma_j(\varepsilon)$ | $ju/(1-ju)$ と $j\varepsilon/(1-j\varepsilon)$。誤差解析の定理は前者、API の丸めのモデルは後者を使う |
| $\kappa$、$\eta$ | 指定した摂動モデルでの条件数と、正規化した後退誤差 |

$\gamma_j(\varepsilon)=\gamma_{2j}(u)$ なので、同じ添字でも $\varepsilon$ による値は $u$ による値のほぼ 2 倍になる。
定理の上界と API の推定を比べるときは、どちらの $\gamma$ かを先に確かめる。

## 共通の規約

保存座標とは多項式を表すために型が保持する数の並びで、基底によって係数・節点での値・制御点のいずれかになる。
`PolynomialBasis::coefficients` は保存座標を借用し、暗黙に単項式へ変換しない。
単項式の構築関数は末尾の厳密な零だけを除き、小さい係数を自動では落とさない。
近似多項式は `PolynomialApproximationPolicy`（係数の許容誤差と数値ランクの規則）を保持し、二項演算では両方の方針が等しいことを要求する。
データだけを取る構築関数は既定の方針を使い、`_with_options` の形が別の方針を受け取る。

呼び出し側が渡す一時領域は `&mut [..]` のスライスで、関数はそれを伸ばさない。
必要な長さは `workspace_requirements` が返し、短ければ数値計算の前に `DimensionMismatch` になり、長いスライスは受け付ける。
出力のスライスは要求と同じ長さでなければならない。
一時領域の内容は成功時にも失敗時にも変わりうるが、出力は成功したときだけ書き込まれる。
繰り返し使う作業領域は `workspace_requirements` で要件を求め、`workspace` で新しく作るか既存の領域を `try_reserve` で広げ、`check` で容量を確かめる。
事前確保は増える方向にしか変わらないので、最大の要求に合わせて事前確保した作業領域は小さい要求にも使える。
`backend` 以外の `_into` の形の関数は `ExecutionContext` を最後の引数に取り、出力を一度に書き込むか、失敗時は変えずに残す。
例外は `OrthogonalTransform` と `OrthogonalDerivative` が実装する `LinearOperator::apply_into` で、`ExecutionContext` を取らないが、失敗時に出力を変えない点は同じである。
`backend` の低水準の `_into` 関数は `ExecutionContext` を取らず、失敗時に出力の一部が変わりうるので、各ページで個別に説明する。

## まとめ

全体の誤差は近似誤差と計算の誤差に分け、計算の誤差は後退誤差と条件数の積で見積もる。
後退誤差が小さくても、条件数が大きければ値の相対誤差は大きくなりうる。
$\gamma_j$ が単位丸め $u$ と機械イプシロン $\varepsilon$ のどちらによるかを確かめてから、定理の上界と API の推定を比べる。
一時領域は呼び出し側が長さを問い合わせて渡し、出力は成功したときだけ書き込まれる。
