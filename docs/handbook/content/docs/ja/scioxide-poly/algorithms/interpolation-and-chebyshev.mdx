相異なる節点での値をすべて通る多項式は一意に定まる。
しかし、標本値の誤差への感度と、標本点の間で元の関数を近似する誤差は別に調べる必要がある。
重心形式と Newton 形式は単項式へ展開せずに評価でき、節点の選択は補間問題そのものの条件を左右する。
このページは重心公式の導出、補間誤差の剰余項、Lebesgue 定数、Runge 現象をまとめ、[Runge 現象の例題](../../examples/runge-nodes/)と [scioxide-interp の補間器](../../../scioxide-interp/algorithms/global-polynomial-and-rational/)がここを参照する。
重心公式を浮動小数点数で評価したときの丸め誤差と、節点族ごとの重みは[重心公式の丸め誤差と節点族の重み](../barycentric-rounding-and-weights/)で扱う。

## 補間多項式の一意性と表現形式

相異なる $n+1$ 個の節点 $x_0, x_1, \dots, x_n$ と標本値 $y_0, y_1, \dots, y_n$ が与えられたとき、$p(x_i) = y_i$（$i = 0, 1, \dots, n$）を満たす $n$ 次以下の多項式 $p \in \mathcal{P}_n$ は一意に存在する。
存在は下の Lagrange 形式で構成できる。

一意性は次のように示せる。
二つの多項式 $p, q \in \mathcal{P}_n$ が同じ補間条件を満たすとすれば、差 $r = p - q$ は $n$ 次以下でありながら $n+1$ 個の異なる零点 $x_i$ を持つ。
零でない多項式の根の個数は次数以下なので $r = 0$、すなわち $p = q$ である。

### 重心型 Lagrange 補間公式

Lagrange 形式は $p(x) = \sum_{j=0}^n y_j \ell_j(x)$、$\ell_j(x) = \prod_{k \ne j} \frac{x - x_k}{x_j - x_k}$ である。
このまま一点を評価すると $O(n^2)$ の演算が要り、点ごとに同じ積を作り直す。

節点多項式を $\omega(x) = \prod_{k=0}^n (x - x_k)$ とおき、重心重み（barycentric weights）$w_j$ を次のように定義する。

$$
w_j = \frac{1}{\prod_{k \ne j} (x_j - x_k)} = \frac{1}{\omega'(x_j)}
$$

この重みを用いると、Lagrange 基底は $\ell_j(x) = \omega(x) \frac{w_j}{x - x_j}$ と書き直せる。
これを代入した次の式を第一種の重心公式（修正 Lagrange 公式）と呼ぶ。

$$
p(x) = \omega(x)\sum_{j=0}^n \frac{w_j}{x - x_j}\, y_j
$$

定数関数 $1$ の補間は $1$ 自身なので $\sum_{j=0}^n \ell_j(x) = 1$、すなわち $1=\omega(x)\sum_j w_j/(x-x_j)$ が成り立つ。
第一種の式をこれで割ると $\omega(x)$ が消えて、第二種の重心公式が得られる。

$$
p(x) = \frac{\sum_{j=0}^n \dfrac{w_j}{x - x_j} y_j}{\sum_{j=0}^n \dfrac{w_j}{x - x_j}}
$$

重みを一度 $O(n^2)$ で計算しておけば、どちらの式でも任意点の評価は $O(n)$ で済む。
第二種の式では重みを共通の定数倍しても値が変わらないので、重みの尺度を自由に選べる。
第一種の式は $\omega(x)$ を掛けるため、次数が高いと $\omega$ が桁あふれ・アンダーフローしやすい。
節点 $x_{n+1}$ を一つ加えるときは、既存の各重みを $x_j - x_{n+1}$ で割り、新しい重みを一つ作るだけで、重みを $O(n)$ で更新できる。
SciOxide はこの更新を提供しないので、節点を加えたら補間を作り直す。

SciOxide の `ApproxPolynomial::interpolate_barycentric` は第二種の式を使う。
節点と標本値は実数でも複素数でもよく、節点の順序は任意である。
重みは一回だけ $O(n^2)$ で計算し、最大の絶対値が 1 になるように正規化して保存する。
重みを利用者が渡す経路はないので、結果は常に節点上の補間多項式である。
空の節点は `InvalidInput`（`Empty`）、長さの不一致は `DimensionMismatch`、NaN や無限大は `NonFinite`、重複した節点は `InvalidInput`（`Inconsistent`）、正規化した重みが 0 に丸まれば `NumericalInstability`（`Underflow`）になる。
`interpolate_barycentric_with_options` は同じ補間に `PolynomialApproximationPolicy` を付けて作り、方針の閾値が係数の尺度で桁あふれすれば `NumericalInstability`（`Overflow`）も返す。
保存した節点と重みは `basis().nodes()` と `basis().weights()` で借用でき、`basis().coefficients()` は標本値を返す。
単項式で表した多項式を与えた節点の重心形式へ移すときは `to_barycentric(nodes)` を使う。

評価は確保をせずに一点あたり $O(n)$ で行う。
浮動小数点数での丸め誤差、評価の工夫、`evaluate_with_derivative` が返す条件数の推定は[重心公式の丸め誤差](oxref:poly-barycentric-rounding)で説明する。

### Newton 補間と差商

Newton 形式は節点を順に含む基底 $1, (x-x_0), (x-x_0)(x-x_1), \dots$ を使い、差商（divided differences）を保存座標とする。

$$
p(x) = f[x_0] + f[x_0, x_1](x - x_0) + f[x_0, x_1, x_2](x - x_0)(x - x_1) + \dots
$$

差商は $f[x_i] = f(x_i)$ から始まる漸化式

$$
f[x_i, \dots, x_{i+k}] = \frac{f[x_{i+1}, \dots, x_{i+k}] - f[x_i, \dots, x_{i+k-1}]}{x_{i+k} - x_i}
$$

で $O(n^2)$ の表として作れる。
$f$ が $k$ 回連続微分可能なら、$f[x_0,\dots,x_k] = f^{(k)}(\xi)/k!$ を満たす点 $\xi$ が節点を含む最小の区間にある。
節点が一致する極限では差商が導関数に置き換わり、値と傾きを合わせる Hermite 補間になる。

新しい節点を末尾に加えても既存の差商は変わらず、表に一行を足すだけで次数を一つ上げられる。
評価は入れ子の積 $p(x)=f[x_0]+(x-x_0)(f[x_0,x_1]+(x-x_1)(\cdots))$ で $O(n)$ である。
差商は近い節点の差で割るため、丸め誤差の拡大は節点の順序と間隔で変わる。
節点を Leja 順序（既に選んだ節点からの距離の積が最大の点を次に選ぶ順序）に並べると拡大が抑えられることが知られている（Reichel, 1990）。

`ApproxPolynomial::interpolate_newton` は実数の節点と標本値から差商を $O(n^2)$ で計算し、Newton 形式の多項式を返す。
節点は与えた順序のまま使い、並べ替えない。
差商の表の途中で桁あふれ・アンダーフローする項は指数の範囲を広げて計算するので、範囲に収まる必要があるのは最後の係数だけである。
末尾の係数が厳密に 0 になれば、その係数と節点を除くので、直線上の標本からは 1 次の多項式が得られる。
入力のエラーは `interpolate_barycentric` と同じで、最後の係数が桁あふれするか、0 でない係数が 0 にアンダーフローすれば `NumericalInstability` になる。
方針を付けて作るときは `interpolate_newton_with_options` を使う。
複素数の標本は受け付けないので、`interpolate_barycentric` を使う。

Newton 形式の評価が返す条件数の推定は、入れ子の積の絶対値の包絡 $\sum_k |c_k|\prod_{i<k}|x-x_i|$ を $|p(x)|$ で割った値と 1 の大きい方である（$c_k$ は差商）。
差商は節点の順序に依存するので、同じ多項式でも節点を並べ替えると推定値も変わる。
`ApproxPolynomial` は不変な値なので、節点を追加するときは新しい多項式を作る。
単項式の多項式を Newton 形式へ移すときは `to_newton(nodes)` を使う。

## 補間誤差と Runge 現象の解析

関数 $f$ が区間 $[a, b]$ 上で $n+1$ 回連続微分可能で、節点と評価点 $x$ がこの区間にあるとき、補間誤差は次の剰余項で表される。

$$
f(x) - p_n(x) = \frac{f^{(n+1)}(\xi)}{(n+1)!} \, \omega(x),
\qquad \omega(x)=\prod_{j=0}^n (x - x_j)
$$

$\xi$ は $x$ と全節点を含む最小の区間の内部の点で、$x$ に依存する。
導出には Rolle の定理を繰り返し使う。
$x$ が節点でないとき、$g(t) = f(t) - p_n(t) - \bigl(f(x)-p_n(x)\bigr)\omega(t)/\omega(x)$ は節点と $x$ の $n+2$ 点で零になる。
Rolle の定理を $n+1$ 回適用すると、$g^{(n+1)}$ はその最小の区間の内部の点 $\xi$ で零になる。
$p_n^{(n+1)}=0$、$\omega^{(n+1)}=(n+1)!$ を代入すれば上の式になる。
差商で書けば同じ誤差は $f(x)-p_n(x) = f[x_0,\dots,x_n,x]\,\omega(x)$ である。
誤差は関数の高階導関数の大きさと、節点の配置だけで決まる $|\omega(x)|$ の積である。

### Lebesgue 定数と等間隔節点

補間作用素 $\mathcal{I}_n: C[a, b] \to \mathcal{P}_n$ の一様ノルムは、Lebesgue 定数

$$
\Lambda_n = \max_{x \in [a, b]} \lambda_n(x),\qquad \lambda_n(x)=\sum_{j=0}^n |\ell_j(x)|
$$

に等しい。
$\lambda_n$ を Lebesgue 関数と呼び、節点では値 1 を取る。
最良多項式近似（一様ノルムで誤差を最小にする多項式 $p_n^*$）の誤差 $\|f - p_n^*\|_\infty$ に対し、補間の誤差は次のように抑えられる。

$$
\|f - p_n\|_\infty \le (1 + \Lambda_n) \|f - p_n^*\|_\infty
$$

$\Lambda_n$ は標本値の誤差が補間値へ拡大される倍率でもあり、各標本値を絶対値 $\eta$ 以内で動かすと、補間値は区間上で最大 $\Lambda_n\eta$ まで動く。

$\Lambda_n$ の増え方には次の結果がある（Trefethen, ATAP, Theorem 15.2）。
どの節点配置でも $\Lambda_n \ge \frac{2}{\pi}\ln(n+1) + 0.5212$ であり、対数的な増加は避けられない。
等間隔節点 $x_j = -1 + 2j/n$ では $\Lambda_n > 2^{n-2}/n^2$ であり、次の漸近形のとおり指数関数的に増える。

$$
\Lambda_n \sim \frac{2^{n+1}}{e \, n \ln n} \quad (n \to \infty)
$$

Runge 関数 $f(x) = 1/(1 + 25x^2)$ は実軸上では何回でも微分できるが、複素平面の $z = \pm \mathrm{i}/5$ に極を持つ。
この極が区間に近いため、等間隔節点の補間は $|x|$ がおよそ $0.7267$ を超える範囲で次数とともに発散する。
節点そのものでは補間条件を満たすので、誤差は節点の間の振動として現れ、端点の近くで最も大きい。

### Chebyshev 節点の Lebesgue 定数

$n+1$ 個の節点の選び方のうち、モニックな節点多項式の最大値 $\max_{[-1,1]}|\omega(x)|$ を最小にするのは $T_{n+1}$ の零点 $x_j=\cos\bigl((2j+1)\pi/(2n+2)\bigr)$ である。
これを第 1 種の Chebyshev 点（Chebyshev 根節点）と呼ぶ。
このとき $\omega = 2^{-n}T_{n+1}$ で、最大値は $2^{-n}$ になる。
端点を含む $x_k = \cos(k\pi/n)$（$k = 0, 1, \dots, n$）は $T_n$ の極値点で、第 2 種の Chebyshev 点（Chebyshev–Lobatto 点）と呼ぶ。
第 2 種の点は $\max|\omega|$ の最小化問題の解ではないが、Lebesgue 定数は同じ速さで対数的に増え、$\Lambda_n \le \frac{2}{\pi}\ln(n+1) + 1$ を満たす。
どちらの点でも漸近形は次のとおりである。

$$
\Lambda_n^{\text{第 1 種}} \sim \frac{2}{\pi} \ln (n+1) + 0.9625\dots,\qquad
\Lambda_n^{\text{第 2 種}} \sim \frac{2}{\pi} \ln n + 0.9625\dots \quad (n \to \infty)
$$

定数は $\frac{2}{\pi}(\gamma+\ln\frac{8}{\pi})$ で、$\gamma$ は Euler の定数である。
下界 $\frac{2}{\pi}\ln(n+1)+0.5212$ との差は定数だけなので、Chebyshev 点は増え方の次数について最良である。

収束の速さは関数の解析性で決まる。
$[-1,1]$ を内部に含む楕円 $E_\rho$（焦点 $\pm1$、長半径と短半径の和が $\rho>1$）の内部で $f$ が解析的で $|f|\le M$ なら、第 2 種の Chebyshev 点による補間は $\|f-p_n\|_\infty \le 4M\rho^{-n}/(\rho-1)$ を満たす（ATAP, Theorem 8.2）。
Runge 関数では極 $\pm\mathrm{i}/5$ を通る楕円の $\rho = 1/5 + \sqrt{1 + 1/25} \approx 1.22$ が上限で、誤差はほぼ $\rho^{-n}$ の比で減る。

Chebyshev 点の重心重みは閉じた形で書け、`backend::barycentric::chebyshev_points` が点と重みを一緒に作る。
重みの式と、一般の重みの計算との比較は[節点族の重心重み](oxref:poly-node-family-weights)にある。

## 等間隔節点と Chebyshev–Lobatto 節点の誤差の比較

次のセルは Runge 関数 $f(x) = 1/(1 + 25x^2)$ を、同じ次数 $n$ で等間隔節点と Chebyshev–Lobatto 節点（第 2 種）に補間し、401 点の格子で誤差を測る。
Lobatto 節点は `chebyshev_points` の `Extrema` で $n+1$ 点を作る。
補間は `ApproxPolynomial::interpolate_barycentric`、重みは `backend::polynomial_basis::barycentric_weights` で求め、同じ重みから Lebesgue 関数 $\lambda_n(x)$ を格子上で評価する。
格子上の最大は真の $\Lambda_n$ を下から見積もる値である。
独立な参照として、漸近式 $2^{n+1}/(en\ln n)$ と $\frac{2}{\pi}\ln n + 0.9625$ を f64 の `powi` と `ln` で計算し、表の比の列で比べる。
節点上では誤差が 0 になり対数軸に描けないので、その点は誤差の系列から除き、件数を表に示す。
誤差と Lebesgue 関数の二つの図は横軸を共有し、ズームが連動する。

```rust
//| id: poly-chebyshev-runge
//| ref: poly-chebyshev-runge
//| title: 等間隔節点と Chebyshev 節点の Runge 誤差と Lebesgue 定数
//| run: reactive
//| crates: [scioxide-poly]
//| inputs:
//|   degree: {"type":"range","label":"補間次数 n","description":"節点数 n+1 を変える。","min":4,"max":30,"step":2,"value":14}
//| cases:
//|   - {"id":"degree-30","label":"n = 30","description":"等間隔節点の誤差は 10³ を超え、Chebyshev–Lobatto 節点の誤差は 10⁻³ まで下がる。","inputs":{"degree":30}}
//|   - {"id":"degree-4","label":"n = 4","description":"低次では節点の選び方による誤差の差がほとんどない。","inputs":{"degree":4}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"runge","path":"/rows/0/1","approx":{"value":7.19201,"rtol":1e-5}}
//|       - {"artifact":"runge","path":"/rows/1/1","approx":{"value":0.053466,"rtol":1e-4}}
//|       - {"artifact":"runge","path":"/rows/1/2","approx":{"value":2.63829,"rtol":1e-5}}
//|       - {"artifact":"runge","path":"/rows/1/4","range":{"min":0.99,"max":1.0}}
//|   - case: degree-30
//|     expect:
//|       - {"artifact":"runge","path":"/rows/0/1","range":{"min":1e3}}
//|       - {"artifact":"runge","path":"/rows/1/1","range":{"max":3e-3}}
//|       - {"artifact":"runge","path":"/rows/0/4","range":{"min":0.8,"max":0.9}}
//|   - case: degree-4
//|     expect:
//|       - {"artifact":"runge","path":"/rows/0/1","approx":{"value":0.43836,"rtol":1e-4}}
//|       - {"artifact":"runge","path":"/rows/1/1","approx":{"value":0.45995,"rtol":1e-4}}
use scioxide_poly::ApproxPolynomial;
use scioxide_poly::backend::barycentric::{ChebyshevPoints, chebyshev_points};
use scioxide_poly::backend::polynomial_basis::barycentric_weights;

let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let fixed3 = serde_json::json!({ "fractionDigits": 3 });
let n = degree.round() as usize;
let nf = n as f64;
let runge = |x: f64| 1.0 / (1.0 + 25.0 * x * x);
let equal: Vec<f64> = (0..=n).map(|i| -1.0 + 2.0 * i as f64 / nf).collect();
// Chebyshev–Lobatto 節点 cos(kπ/n) の n + 1 点（昇順）。重みは下で一般の式から求める。
let (lobatto, _) =
    chebyshev_points::<f64>(n + 1, ChebyshevPoints::Extrema).map_err(|e| e.to_string())?;
// 独立な参照値: Lebesgue 定数の漸近式（f64 の powi・ln による）
let asymptotes = [
    2f64.powi(n as i32 + 1) / (std::f64::consts::E * nf * nf.ln()),
    2.0 / std::f64::consts::PI * nf.ln() + 0.9625,
];
let grid: Vec<f64> = (0..=400).map(|i| -1.0 + 2.0 * i as f64 / 400.0).collect();
let (mut rows, mut errors, mut lebesgue_curves) = (Vec::new(), Vec::new(), Vec::new());
for ((name, nodes), asymptote) in [("等間隔", &equal), ("Chebyshev–Lobatto", &lobatto)]
    .into_iter()
    .zip(asymptotes)
{
    // 重心形式の補間（重みは SciOxide が計算する）
    let values: Vec<f64> = nodes.iter().map(|&x| runge(x)).collect();
    let p = ApproxPolynomial::interpolate_barycentric(nodes.clone(), values)
        .map_err(|e| e.to_string())?;
    let w = barycentric_weights(nodes).map_err(|e| e.to_string())?;
    let (mut max_error, mut lebesgue, mut omitted) = (0.0_f64, 1.0_f64, 0_usize);
    let (mut error_curve, mut lebesgue_curve) = (Vec::new(), Vec::new());
    for &x in &grid {
        let error = (p.evaluate(x).map_err(|e| e.to_string())? - runge(x)).abs();
        max_error = max_error.max(error);
        // 誤差が 0 の点（節点上）は対数軸に描けないので除く
        if error > 0.0 {
            error_curve.push([x, error]);
        } else {
            omitted += 1;
        }
        // λ(x) = Σ|w_j/(x − x_j)| / |Σ w_j/(x − x_j)|。節点上では λ = 1。
        let lambda = if nodes.contains(&x) {
            1.0
        } else {
            let (num, den) = nodes.iter().zip(&w).fold((0.0, 0.0), |(a, b), (&xj, &wj)| {
                (a + (wj / (x - xj)).abs(), b + wj / (x - xj))
            });
            num / den.abs()
        };
        lebesgue = lebesgue.max(lambda);
        lebesgue_curve.push([x, lambda]);
    }
    rows.push((
        name,
        max_error,
        lebesgue,
        asymptote,
        lebesgue / asymptote,
        omitted,
    ));
    errors.push(serde_json::json!({ "name": name, "points": error_curve }));
    lebesgue_curves.push(serde_json::json!({ "name": name, "points": lebesgue_curve }));
}
let columns = serde_json::json!([
    { "key": "0", "label": "節点" },
    { "key": "1", "label": "最大誤差 [-]", "type": "number", "format": sci3 },
    { "key": "2", "label": "格子上の λ_n の最大 [-]", "type": "number", "format": sci3 },
    { "key": "3", "label": "Λ_n の漸近式 [-]", "type": "number", "format": sci3 },
    { "key": "4", "label": "格子上の最大 / 漸近式 [-]", "type": "number", "format": fixed3 },
    { "key": "5", "label": "除いた零誤差の点 [点]", "type": "integer" }
]);
emit_table_with_columns!(
    columns,
```

### 数値結果の読み方

既定の $n = 14$ では、格子上の Lebesgue 関数の最大は等間隔節点で $2.8 \times 10^{2}$（漸近式 $3.3 \times 10^{2}$）、Chebyshev–Lobatto 節点で $2.638$（漸近式 $2.643$）である。
$n = 30$ ではそれぞれ $6.6 \times 10^{6}$（漸近式 $7.7 \times 10^{6}$）と $3.122$（漸近式 $3.128$）になり、等間隔節点では指数的に、Chebyshev 節点では対数的に増えることが確かめられる。
10 万点の格子で測り直すと Lobatto 節点の $n=30$ の値は $3.127$ で、401 点の格子は最大をわずかに下から見積もっている。
等間隔節点の格子上の値と漸近式の比は $n=14$ で 0.87、$n=30$ で 0.85 である。
漸近式は指数的な増え方を表すが、この範囲の $n$ では値を 15% ほど大きく見積もり、比は 1 に近づいていない。
Lebesgue 関数の図では、等間隔節点の $\lambda_n$ が端の近くの節点の間で大きく盛り上がり、Chebyshev–Lobatto 節点では区間全体でほぼ同じ高さの山が並ぶ。

補間誤差もこれに従う。
$n=14$ では等間隔節点の最大誤差が端点の近くで $7.2$ に達するのに対し、Chebyshev–Lobatto 節点の最大誤差は $0.053$ で、比は約 135 である。
誤差の図で等間隔節点の誤差が大きいのは $|x|\gtrsim0.73$ の範囲で、Lebesgue 関数が大きい位置と重なる。
$n = 30$ では等間隔節点の誤差が $2.4 \times 10^{3}$ に増える一方、Chebyshev 節点の誤差は $2.4 \times 10^{-3}$ に下がる。
$n=14$ から $30$ への Chebyshev 節点の誤差の減少は約 22 分の 1 で、上で求めた $\rho \approx 1.22$ から予想される $\rho^{16}\approx24$ に近い。
$n = 4$ では最大誤差が 0.44（等間隔）と 0.46（Chebyshev）で差がなく、節点の選び方が効くのは次数が高いときである。

## まとめ

補間の一意性と近似の精度は別の性質で、近似誤差は剰余項の $f^{(n+1)}$ と $\omega$、および Lebesgue 定数で読む。
重心公式は重みを一度 $O(n^2)$ で作れば一点を $O(n)$ で評価でき、`interpolate_barycentric` は実数でも複素数でもこの形で補間を作る。
等間隔節点の Lebesgue 定数は次数とともに指数的に増えるので、高次の補間では Lebesgue 定数が対数的にしか増えない Chebyshev 点を `chebyshev_points` で作って使う。
Newton 形式は節点の追加と差商の再利用に向くが、精度は節点の順序に依存するので、順序を決めてから `interpolate_newton` に渡す。
等間隔の標本しかない場合は次数を上げず、[最小二乗](../least-squares-and-vandermonde/)や区分的な補間を検討する。
