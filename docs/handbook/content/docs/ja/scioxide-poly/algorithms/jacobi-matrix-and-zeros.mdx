直交多項式の零点は Gauss 求積や補間の節点として使われ、閉じた形を持たない族では数値的に求める必要がある。
三項漸化式は零点を固有値に持つ対称三重対角行列（Jacobi 行列）を与える。
このページでは Jacobi 行列への帰着から零点の性質を導き、`jacobi_recurrence` と `zeros` の仕様と誤差の見積もりを説明し、セルで四つの族の零点を三つの方法で検算する。
三項漸化式の係数 $a_n,b_n,c_n$ とモニック形の係数 $d_n,e_n$ は[直交多項式族](oxref:poly-three-term-recurrence-favard)で定義した。

## 対称三重対角 Jacobi 行列への帰着

モニック多項式を正規化した正規直交多項式 $p_k=\pi_k/\|\pi_k\|_w$ は

$$
xp_k(x)=e_{k+1}p_{k+1}(x)+d_kp_k(x)+e_kp_{k-1}(x),\qquad e_k=\sqrt{\frac{c_k}{a_{k-1}a_k}}>0
$$

を満たす。
$\mathbf p(x)=(p_0(x),\dots,p_{n-1}(x))^{\mathsf T}$ とおくと、これは

$$
\mathbf J_n\mathbf p(x)=x\,\mathbf p(x)-e_np_n(x)\,\mathbf u_n,\qquad
\mathbf J_n=\begin{bmatrix}
d_0&e_1&&\\
e_1&d_1&\ddots&\\
&\ddots&\ddots&e_{n-1}\\
&&e_{n-1}&d_{n-1}
\end{bmatrix}
$$

と書ける（$\mathbf u_n$ は第 $n$ 成分だけが 1 の単位ベクトル）。
$p_n(x)=0$ なら $x$ は $\mathbf J_n$ の固有値で、$\mathbf p(x)$ がその固有ベクトルになる。
$\mathbf J_n$ は実対称で副対角が正なので、固有値は実数で互いに異なる。
したがって $p_n$ の零点は $n$ 個の相異なる実数である。
$\mathbf J_n$ は $\mathbf J_{n+1}$ の左上の主部分行列なので、Cauchy の交互定理により次数 $n$ と $n+1$ の零点は交互に並ぶ。
零点はすべて重みの台の凸包の内部（$[-1,1]$ の族では $(-1,1)$、Laguerre では $(0,\infty)$）にある。
副対角を正にそろえる対角相似変換は、Laguerre のような符号の規約の違いを吸収する。
固有値の和は対角和なので、零点の和は $\sum_{k<n}d_k$ に等しい。

## Jacobi 行列の係数と最後の要素

`jacobi_recurrence(order)` は $d_0,\dots,d_{\mathrm{order}-1}$ と $e_1,\dots,e_{\mathrm{order}-1}$ を計算し、`JacobiRecurrence` として所有して返す。
構成は $O(\mathrm{order})$ の時間とメモリで、結果は多項式の規格化によらない。
`diagonal()` と `off_diagonal()` は長さ `order` と `order - 1` のスライスを借用し、`into_parts()` は複製せずに二つの `Vec` を渡す。
`order` が 0 なら `InvalidInput`（`OutOfRange`）になる。
先頭の係数 $a_k$ が 0 か $e_k^2$ が正でなければ `NumericalInstability`（`Breakdown`）、$e_k$ が 0 にアンダーフローすれば `NumericalInstability`（`Underflow`）になる。
範囲内のパラメータの古典族では、$e_k^2>0$ が理論上成り立つので、これらは係数が表せないほど極端なパラメータでだけ起こる。

`last_member_scaled(x)` は、確率測度 $w/\mu_0$ に関して正規直交で最高次係数が正の多項式のうち、次数 `order - 1` のものを評価する。
古典的な規格化の $P_{\mathrm{order}-1}$ とは定数倍 $\pm\sqrt{\mu_0/h_{\mathrm{order}-1}}$ だけ異なる。
計算は $O(\mathrm{order})$ でメモリを確保せず、指数を拡張した `Scaled` の値を返すので、途中で範囲を超えない。
binary64 の値が必要なら `round()` で射影し、表現できない値はそこでエラーになる。

## 固有値としての零点とその誤差

`zeros(n)` は次数 $n$ の零点を昇順の `Vec` で返す。
`ChebyshevT` と `ChebyshevU` は正弦の閉じた形を使い、対称な組を鏡映で作るので、零点は正確に対称で、奇数次では中央が厳密に 0 になる。
他の族は $\mathbf J_n$ の固有値だけを `scioxide-linalg` の対称三重対角の固有値解法の既定の設定で求め、デフレーションは機械イプシロンに対する相対値で判定する。
この判定の閾値は個々の零点の誤差の上界ではない。
対称行列の固有値は摂動に対して良条件で、Weyl の定理により摂動 $\Delta\mathbf J$ による各固有値の変化は $\|\Delta\mathbf J\|_2$ 以下である。
後退安定な解法の誤差はこの意味で $\|\mathbf J_n\|_2$ に比例する絶対誤差になり、Laguerre の 0 に近い零点のように $\|\mathbf J_n\|_2$ より桁違いに小さい零点では、相対誤差が大きくなりうる。
別の設定で解くときは、`jacobi_recurrence` の係数をその解法に渡す。
$n=0$ は `InvalidInput`、固有値解法が収束しなければその失敗を返す。

Gauss 求積の節点はこの零点であり、重みは固有ベクトルの第 1 成分と $\mu_0$ から求まる（Golub–Welsch 法、G. H. Golub and J. H. Welsch, *Math. Comp.* 23, 1969, 221–230）。
`scioxide-poly` は重みを返さない。
重みと $2n-1$ 次の厳密性の導出は [integrate の Gauss 型求積と Clenshaw–Curtis 則](../../../scioxide-integrate/algorithms/gaussian-and-clenshaw-curtis/)、零点の和と交互配置の検算は [Hermite の例題](../../examples/gauss-nodes-as-zeros/)にある。

## Jacobi 行列による零点の検算

次のセルは閉じた形を持たない四つの族について `zeros(n)` の零点を三つの方法で確かめる。

- Newton 補正 $\delta_k=P_n(z_k)/P_n'(z_k)$：`evaluate` と `evaluate_derivative` で計算し、計算した零点 $z_k$ の誤差の一次の推定値として使う。
  $P_n$ の評価自体の丸め誤差を含むので、保証された誤差の上界ではない。
- 対角和：零点の和を `jacobi_recurrence(n)` の対角の和 $\sum_kd_k$ と比べる。
- 交互配置：`zeros(n + 1)` の零点が次数 $n$ の零点を一つずつ挟むかを数える。

比べる尺度として、Gershgorin の定理による上界 $\|\mathbf J_n\|_2\le\max_k(|d_k|+e_k+e_{k+1})$ に機械イプシロン $\varepsilon$ を掛けた値を表に出す。
族は Legendre、Laguerre、Jacobi（$\alpha=1/2$、$\beta=-1/2$）、Gegenbauer（$\lambda=2$）から選ぶ。
図は各零点の位置 $z_k$ と $|\delta_k|$ を対数軸で描き、$\delta_k=0$ の点は除いて件数を表に示す。

```rust
//| id: poly-jacobi-zeros
//| ref: poly-jacobi-zeros
//| title: Jacobi 行列の固有値として求めた零点の検算
//| run: reactive
//| crates: [scioxide-poly]
//| inputs:
//|   family_name: {"type":"select","label":"族","options":["Legendre","Laguerre","Jacobi (α = 1/2, β = −1/2)","Gegenbauer (λ = 2)"],"value":"Legendre"}
//|   degree: {"type":"range","label":"次数 n","description":"零点の数。","min":2,"max":60,"step":1,"value":20}
//| cases:
//|   - {"id":"laguerre","label":"Laguerre","description":"零点が (0, 4n) 程度に広がり、行列のノルムに比例した絶対誤差が大きい零点で目立つ。","inputs":{"family_name":"Laguerre"}}
//|   - {"id":"jacobi-60","label":"Jacobi, n = 60","description":"非対称な重みでも零点は交互に並び、対角和と一致する。","inputs":{"family_name":"Jacobi (α = 1/2, β = −1/2)","degree":60}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"zeros","path":"/rows/0/1","approx":{"value":0.9931285991850949,"rtol":1e-13}}
//|       - {"artifact":"zeros","path":"/rows/0/2","range":{"max":1e-14}}
//|       - {"artifact":"zeros","path":"/rows/0/4","range":{"max":1e-13}}
//|       - {"artifact":"zeros","path":"/rows/0/5","equals":0}
//|   - case: laguerre
//|     expect:
//|       - {"artifact":"zeros","path":"/rows/0/0","approx":{"value":0.07053988969198875,"rtol":1e-11}}
//|       - {"artifact":"zeros","path":"/rows/0/1","approx":{"value":66.52441652561575,"rtol":1e-12}}
//|       - {"artifact":"zeros","path":"/rows/0/2","range":{"max":1e-12}}
//|       - {"artifact":"zeros","path":"/rows/0/5","equals":0}
//|   - case: jacobi-60
//|     expect:
//|       - {"artifact":"zeros","path":"/rows/0/2","range":{"max":1e-14}}
//|       - {"artifact":"zeros","path":"/rows/0/4","range":{"max":1e-13}}
//|       - {"artifact":"zeros","path":"/rows/0/5","equals":0}
use scioxide_poly::OrthogonalFamily;

let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let fixed4 = serde_json::json!({ "fractionDigits": 4 });
let n = degree.round() as usize;
let family: OrthogonalFamily<f64> = match family_name.as_str() {
    "Laguerre" => OrthogonalFamily::Laguerre,
    "Jacobi (α = 1/2, β = −1/2)" => OrthogonalFamily::Jacobi {
        alpha: 0.5,
        beta: -0.5,
    },
    "Gegenbauer (λ = 2)" => OrthogonalFamily::Gegenbauer { lambda: 2.0 },
    _ => OrthogonalFamily::Legendre,
};
let zeros = family.zeros(n).map_err(|e| e.to_string())?;
let next = family.zeros(n + 1).map_err(|e| e.to_string())?;
let recurrence = family.jacobi_recurrence(n).map_err(|e| e.to_string())?;
let (diagonal, off) = (recurrence.diagonal(), recurrence.off_diagonal());
// Gershgorin の上界 max_k(|d_k| + e_k + e_{k+1}) ≥ ‖J_n‖₂
let mut gershgorin = 0.0_f64;
for (k, &d) in diagonal.iter().enumerate() {
    let below = if k > 0 { off[k - 1] } else { 0.0 };
    let above = off.get(k).copied().unwrap_or(0.0);
    gershgorin = gershgorin.max(d.abs() + below + above);
}
// Newton 補正 δ_k = P_n(z_k)/P_n'(z_k)（零点の誤差の一次の推定値）
let (mut corrections, mut largest, mut exact) = (Vec::new(), 0.0_f64, 0_usize);
for &z in &zeros {
    let value = family.evaluate(n, z).map_err(|e| e.to_string())?;
    let slope = family
        .evaluate_derivative(n, z)
        .map_err(|e| e.to_string())?;
    let delta = (value / slope).abs();
    largest = largest.max(delta);
    if delta > 0.0 {
        corrections.push([z, delta]);
    } else {
        exact += 1;
    }
}
// 交互配置: next[k] < zeros[k] < next[k + 1] を満たさない k の数
let violations = (0..n)
    .filter(|&k| !(next[k] < zeros[k] && zeros[k] < next[k + 1]))
    .count();
let trace_gap = (zeros.iter().sum::<f64>() - diagonal.iter().sum::<f64>()).abs();
let columns = serde_json::json!([
    { "key": "0", "label": "最小の零点 [-]", "type": "number", "format": fixed4 },
    { "key": "1", "label": "最大の零点 [-]", "type": "number", "format": fixed4 },
    { "key": "2", "label": "|δ_k| の最大 [-]", "type": "number", "format": sci3 },
    { "key": "3", "label": "ε × Gershgorin の上界 [-]", "type": "number", "format": sci3 },
    { "key": "4", "label": "零点の和と対角和の差 [-]", "type": "number", "format": sci3 },
    { "key": "5", "label": "交互配置の違反 [個]", "type": "integer" },
    { "key": "6", "label": "δ_k = 0 で除いた零点 [個]", "type": "integer" }
]);
let row = (
    zeros[0],
    zeros[n - 1],
    largest,
    f64::EPSILON * gershgorin,
    trace_gap,
    violations,
    exact,
);
emit_table_with_columns!(
    columns,
    vec![row],
    metadata = serde_json::json!({ "id": "zeros" })
);
emit_scatter_chart!(
    &vec![serde_json::json!({ "name": "|δ_k|", "points": corrections })],
    options = &serde_json::json!({
        "xLabel": "零点 z_k [-]",
        "yLabel": "Newton 補正 |P_n(z_k)/P_n′(z_k)| [-]",
        "yType": "log"
    })
);
```

既定の Legendre の $n=20$ では、最大の零点は $0.9931285991850948$ で、文献値 $0.99312859918509492$ と 1 ulp 以内で一致する。
Newton 補正の最大は $5.5\times10^{-16}$ で、$\varepsilon$ と Gershgorin の上界の積 $2.4\times10^{-16}$ と同程度であり、零点の和と対角和の差は $7.8\times10^{-16}$、交互配置の違反はない。
Laguerre の $n=20$ では、零点が $0.0705$ から $66.52$ まで広がり、行列のノルムも大きくなる。
最小と最大の零点は文献値 $0.070539889691988753$、$66.524416525615754$ と相対誤差 $10^{-14}$ 以内で一致する。
最小の零点の相対誤差 $3.7\times10^{-15}$ は最大の零点の $5\times10^{-16}$ より大きいが、絶対誤差は最大の零点のほうが 100 倍ほど大きい。
Newton 補正の最大 $8.1\times10^{-14}$ は大きい零点で現れ、図では $|\delta_k|$ が $z_k$ とともに増える。
これは誤差が $\|\mathbf J_n\|_2$ に比例する絶対誤差になるという Weyl の定理からの見積もりと合い、$\varepsilon$ と Gershgorin の上界の積との比 5 程度は、次数に緩やかに依存する後退誤差の係数と、$L_n$ の評価自体の丸め誤差を含む。
非対称な重みの Jacobi（$\alpha=1/2$、$\beta=-1/2$）で $n=60$ にしても、Newton 補正は $5.5\times10^{-16}$、交互配置の違反は 0 である。
$\delta_k$ が厳密に 0 になった零点は図から除き、表に件数を示す。

## まとめ

三項漸化式は零点を固有値に持つ対称な Jacobi 行列を与え、零点が相異なる実数で、隣の次数の零点と交互に並ぶこともそこから分かる。
`jacobi_recurrence(n)` は規格化によらない対角と副対角を $O(n)$ で返すので、別の設定の固有値解法で解くときはこれを渡す。
`zeros` が返すのは既定の固有値解法による数値解で、誤差は $\|\mathbf J_n\|_2$ に比例する絶対誤差と見積もり、Newton 補正 $P_n(z)/P_n'(z)$ で個別に確かめる。
Laguerre の 0 に近い零点のように $\|\mathbf J_n\|_2$ より桁違いに小さい零点では、相対誤差を Newton 補正の大きさで確かめてから使う。
Gauss 求積の重みは `scioxide-poly` が返さないので、求積には `scioxide-integrate` の Gauss 則を使う。
