曲線や曲面の形を制御点で表すときは、Bernstein 基底を使うと制御点から値の範囲を読み取れる。
制御点の配列だけでは意味が決まらず、媒介変数の区間を指定する必要がある。
このページは一変数の Bernstein 表現の評価と分割、その丸め誤差と条件数、単項式との変換を説明する。
テンソル積の曲面と、凸包性による値域の推定は[テンソル積 Bernstein と値域の推定](../tensor-bernstein-bounds/)で扱う。
疎な多変数多項式は[疎な多変数多項式](../sparse-multivariate/)で扱う。

## Bernstein 基底と de Casteljau 法

$t\in[0,1]$ の次数 $n$ の Bernstein 基底と、制御点 $b_i$ を持つ多項式を

$$
B_i^n(t)=\binom ni t^i(1-t)^{n-i},\qquad p(t)=\sum_{i=0}^nb_iB_i^n(t)
$$

で定義する。
二項定理から $\sum_iB_i^n(t)=(t+(1-t))^n=1$ であり、$[0,1]$ では各 $B_i^n$ が非負である。
したがって実数の $t\in[0,1]$ では $p(t)$ は制御点の凸結合になり、制御点の最小と最大の間にある（凸包性）。
この性質は厳密な算術で実数の $t\in[0,1]$ について成り立つもので、外挿や複素数の媒介変数には当てはまらない。
浮動小数点で何が保証されるかは、[凸包性と分割による範囲の縮小](oxref:poly-bernstein-subdivision-bounds)で述べる。
両端では $p(0)=b_0$、$p(1)=b_n$ となるが、Bernstein 基底は節点での補間基底ではなく、曲線は内側の制御点を通るとは限らない。

基底は漸化式 $B_i^n(t)=(1-t)B_i^{n-1}(t)+tB_{i-1}^{n-1}(t)$ を満たす。
これを $p$ の和に代入して次数を一つずつ下げると、$b_i^{(0)}=b_i$ から

$$
b_i^{(r)}=(1-t)\,b_i^{(r-1)}+t\,b_{i+1}^{(r-1)},\qquad r=1,\ldots,n
$$

と段を縮める de Casteljau 法が得られ、$p(t)=b_0^{(n)}$ になる。
演算は $n(n+1)/2$ 回の凸結合（$O(n^2)$）で、メモリは $O(n)$ である。
$t\in[0,1]$ では各段が凸結合なので、厳密な算術では途中の値も制御点の範囲を出ない。
最後から 2 段目の二つの値から、導関数 $p'(t)=n\,(b_1^{(n-1)}-b_0^{(n-1)})$ も同時に得られる。
三角形の左右の辺 $b_0^{(r)}$ と $b_{n-r}^{(r)}$（$r=0,\ldots,n$）は、$t$ で分割した二つの区間 $[0,t]$、$[t,1]$ の制御点になる。

## 丸め誤差と条件数

de Casteljau 法の各段は $\mathrm{fl}(\mathrm{fl}(a\,\hat s)+\mathrm{fl}(b\,t))$、$\hat s=\mathrm{fl}(1-t)$ を計算する。
標準の丸めのモデル $\mathrm{fl}(a\circ b)=(a\circ b)(1+\eta)$、$|\eta|\le u$ で数えると、$1-t$ の側を通る値は一段に最大 3 個、$t$ の側を通る値は最大 2 個の $(1+\eta)$ を受ける。
制御点 $b_i$ から $p(t)$ までの経路は $n$ 段なので、$\gamma_k=ku/(1-ku)$ として、実数の $t\in[0,1]$ での計算値 $\hat p(t)$ は

$$
|\hat p(t)-p(t)|\le\gamma_{3n}\sum_{i=0}^n|b_i|\,B_i^n(t)\le\gamma_{3n}\max_i|b_i|
$$

を満たす。
$t\in[1/2,1]$ では Sterbenz の補題により $1-t$ が丸めなしに求まるので、定数は $\gamma_{2n}$ になる。
物理区間の点 $x$ から $t$ を作る丸めは、評価点のずれとして別に現れる。
右辺の和を $|p(t)|$ で割った値が Bernstein 基底での評価の条件数で、相対誤差はこの条件数の $\gamma_{3n}$ 倍で抑えられる。
単項式基底の Horner 法では、同じ役割を $\sum_k|a_k||t|^k$ が担う（[Horner 評価の丸め誤差と診断](../horner-rounding-error/)）。
$[0,1]$ では、Bernstein 基底の条件数は同じ多項式の単項式基底の条件数を超えない（R. T. Farouki and V. T. Rajan, "On the numerical condition of polynomials in Bernstein form", *Comput. Aided Geom. Design* 4, 1987）。
さらに、$[0,1]$ で非負の基底の中には、Bernstein 基底より系統的に小さい条件数を与える基底はない（R. T. Farouki and T. N. T. Goodman, "On the optimal stability of the Bernstein basis", *Math. Comp.* 65, 1996）。

例として $p(t)=(t-1/2)^n$ をとる。
Bernstein 係数は $b_i=(-1)^{n-i}2^{-n}$ なので、$\sum_i|b_i|B_i^n(t)=2^{-n}$ である。
単項式の係数は $a_k=\binom nk(-1/2)^{n-k}$ で、$\sum_k|a_k|t^k=(t+1/2)^n$ は $t=1/2$ の近くで 1 程度になる。
根 $t=1/2$ の近くでは $|p|$ がどちらの基底でも同じなので、二つの条件数の比はおよそ $2^n$ になる。

`evaluate_with_derivative` の条件のレポートは、$t\in[0,1]$ では $\max_i|b_i|$ を、区間の外や複素数の $t$ では $\sum_i|B_i^n(t)|=(|t|+|1-t|)^n$ を $\max_i|b_i|$ に掛けた値を、値の大きさの上界として使う。
レポートの `forward_error_estimate()` は、この上界を $|p|$ で割った条件数に $(n+1)\varepsilon/(1-(n+1)\varepsilon)$（$\varepsilon=2u$）を掛けた推定値で、上の $\gamma_{3n}$ による最悪の評価とは定数が異なる。
上界は $\sum_i|b_i|B_i^n(t)$ ではなく $\max_i|b_i|$ なので、この例のように制御点の大きさがそろっている場合は鋭く、そろっていない場合は大きめになる。

次のセルは $(t-1/2)^n$ の Bernstein 表現を作り、`to_monomial` で単項式の係数へ変換する。
この例では係数が整数と 2 のべきの積なので、変換は丸めなしに行われる。
二つの表現を $t=1/2+\delta$ で `evaluate_with_derivative` により評価し、相対誤差とレポートの `forward_error_estimate()` を表にする。
参照値 $\delta^n$ は、$\delta=t-1/2$ を Sterbenz の補題により丸めなしに求め、`f64` の固有メソッド `powi` で累乗した値で、SciOxide の関数を使わない（相対誤差は $nu$ 程度）。
二つ目の表は変換のレポートの `condition_estimate()`（係数の最大の大きさの比）を、閉形式 $\max_k\binom nk2^k$ と比べる。

```rust
//| id: poly-bernstein-conditioning
//| ref: poly-bernstein-conditioning
//| title: 根の近くでの de Casteljau 法と Horner 法の精度
//| run: reactive
//| crates: [scioxide-poly]
//| inputs:
//|   degree: {"type":"range","label":"次数 n [-]","description":"p(t) = (t − 1/2)ⁿ の次数。二つの基底の条件数の比はおよそ 2ⁿ になる。","min":4,"max":20,"step":2,"value":10}
//| cases:
//|   - {"id":"low-degree","label":"n = 4","description":"条件数の比は 16 程度で、どちらの基底でも δ = 0.01 の値を 10 桁以上求められる。","inputs":{"degree":4}}
//|   - {"id":"high-degree","label":"n = 20","description":"単項式の Horner 法は δ = 0.05 でも有効な桁を失い、de Casteljau 法は相対誤差を小さく保つ。","inputs":{"degree":20}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"accuracy","path":"/rows/0/2","range":{"max":1e-14}}
//|       - {"artifact":"accuracy","path":"/rows/4/2","range":{"max":1e-13}}
//|       - {"artifact":"accuracy","path":"/rows/4/4","range":{"min":1}}
//|       - {"artifact":"conversion","path":"/rows/0/0","approx":{"value":15360,"rtol":1e-12}}
//|       - {"artifact":"conversion","path":"/rows/0/1","approx":{"value":15360,"rtol":1e-12}}
//|   - case: low-degree
//|     expect:
//|       - {"artifact":"accuracy","path":"/rows/4/2","range":{"max":1e-13}}
//|       - {"artifact":"accuracy","path":"/rows/4/4","range":{"max":1e-8}}
//|       - {"artifact":"conversion","path":"/rows/0/0","approx":{"value":32,"rtol":1e-12}}
//|   - case: high-degree
//|     expect:
//|       - {"artifact":"accuracy","path":"/rows/2/4","range":{"min":1}}
//|       - {"artifact":"accuracy","path":"/rows/4/2","range":{"max":1e-13}}
//|       - {"artifact":"conversion","path":"/rows/0/0","approx":{"value":635043840,"rtol":1e-12}}
use scioxide_poly::ApproxPolynomial;

let n = degree as usize;
// (t − 1/2)ⁿ の Bernstein 係数 bᵢ = (−1)ⁿ⁻ⁱ 2⁻ⁿ。どれも 2 のべきで厳密に表せる。
let scale = 0.5_f64.powi(n as i32);
let controls: Vec<f64> = (0..=n)
    .map(|i| if (n - i) % 2 == 0 { scale } else { -scale })
    .collect();
let bernstein = ApproxPolynomial::bernstein(controls, 0.0, 1.0).map_err(|e| e.to_string())?;
// 単項式の係数 a_k = C(n, k)(−1/2)ⁿ⁻ᵏ へ変換する。
let conversion = bernstein.to_monomial().map_err(|e| e.to_string())?;
let monomial = conversion.polynomial();
let mut rows = Vec::new();
for offset in [0.2_f64, 0.1, 0.05, 0.02, 0.01] {
    let t = 0.5 + offset;
    // 参照値: δ = t − 1/2 は Sterbenz の補題で厳密。f64 の powi による参照計算。
    let delta = t - 0.5;
    let reference = delta.powi(n as i32);
    let b = bernstein
        .evaluate_with_derivative(t)
        .map_err(|e| e.to_string())?;
    let m = monomial
        .evaluate_with_derivative(t)
        .map_err(|e| e.to_string())?;
    rows.push((
        delta,
        reference,
        (b.value() - reference).abs() / reference.abs(),
        b.condition().forward_error_estimate(),
        (m.value() - reference).abs() / reference.abs(),
        m.condition().forward_error_estimate(),
    ));
}
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let columns = serde_json::json!([
    { "key": "0", "label": "δ = t − 1/2 [-]", "type": "number", "format": sci3 },
    { "key": "1", "label": "参照値 δⁿ [-]", "type": "number", "format": sci3 },
    { "key": "2", "label": "de Casteljau の相対誤差 [-]", "type": "number", "format": sci3 },
    { "key": "3", "label": "de Casteljau の推定 [-]", "type": "number", "format": sci3 },
    { "key": "4", "label": "Horner の相対誤差 [-]", "type": "number", "format": sci3 },
    { "key": "5", "label": "Horner の推定 [-]", "type": "number", "format": sci3 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "accuracy" })
);
// 独立検算: 係数の最大の大きさの比は max_k C(n, k) 2ᵏ。
let mut binomial = 1.0_f64;
let mut growth = 1.0_f64;
for k in 1..=n {
    binomial *= (n + 1 - k) as f64 / k as f64;
    growth = growth.max(binomial * 2.0_f64.powi(k as i32));
}
let summary_columns = serde_json::json!([
    { "key": "0", "label": "変換の condition_estimate [-]", "type": "number" },
    { "key": "1", "label": "max C(n, k) 2ᵏ [-]", "type": "number" }
]);
let summary = vec![(conversion.condition().condition_estimate(), growth)];
emit_table_with_columns!(
    summary_columns,
    summary,
    metadata = serde_json::json!({ "id": "conversion" })
);
```

既定の $n=10$ では、$\delta=0.01$（参照値 $10^{-20}$）での Horner 法の相対誤差は $3.9\times10^3$ で、計算値に正しい桁は残らない。
単項式の条件数 $(t+1/2)^n/\delta^n$ はここで約 $10^{20}$ なので、相対誤差はその $u$ 倍の $10^4$ 程度になる。
同じ点での de Casteljau 法の相対誤差は $4.8\times10^{-15}$ である。
$n=20$ では、Horner 法は $\delta=0.05$ でも相対誤差が $1.3\times10^{10}$ になり、de Casteljau 法は $\delta=0.01$ でも $8.6\times10^{-15}$ にとどまる。
$n=4$ では条件数の差が小さく、Horner 法も $\delta=0.01$ で相対誤差 $1.6\times10^{-9}$ を保つ。

de Casteljau 法の誤差は条件数による上界 $\gamma_{3n}2^{-n}/\delta^n$（$n=10$、$\delta=0.01$ で約 $3\times10^{2}$）よりずっと小さい。
この例では $r$ 段目の値が $b_i^{(r)}=(-1)^{n-i-r}2^{-n}(2\delta)^r$ で、各段の打ち消しはその段の値の大きさに対して起こる。
同じ段の値は大きさが等しく符号だけが交互なので、各値の丸め誤差も同じ交互の形をとり、次の段では値と同じ $2\delta$ 倍に縮む。
一段の丸めは結果の大きさの相対 $u(1+1/(2\delta))$ 程度にとどまるので、全体の相対誤差は $nu(1+1/(2\delta))$ 程度になる。
条件数による上界は係数の任意の摂動に対する最悪の場合で、この例のように構造を持つ係数では実際の誤差より大きくなる。

レポートの推定は de Casteljau 法では $\delta=0.01$ で 238 と大きめで、上の最悪の評価に近い。
Horner 法の推定は $\delta=0.01$ で 69.5 と、実際の相対誤差 $3.9\times10^3$ より小さい。
推定は計算値 $|\hat p|$ で割って作るので、計算値が丸め誤差に埋もれると実際の相対誤差を下回る。
推定は上界ではないので、1 を超えたら計算値に有効な桁がないと読む。
変換の `condition_estimate()` は閉形式 $\max_k\binom nk2^k$ と一致し、$n=4,10,20$ で 32、15360、$6.35\times10^8$ と増える。

## 区間と基底の変換

物理区間 $[a,b]$ では $t=(x-a)/(b-a)$ と置き、導関数は $1/(b-a)$ 倍になる。
`BernsteinBasis` はこの区間と制御点を保持し、末尾の零の制御点も次数を決める座標として残す。
`ApproxPolynomial::bernstein(controls, lower, upper)` は、空の制御点と $\mathrm{lower}\ge\mathrm{upper}$ を `InvalidInput`、非有限の制御点と端点を `NonFinite` として拒否する。
既定でない方針を持たせるときは `bernstein_with_options(controls, lower, upper, policy)` を使う。
評価点が区間の端に一致すれば、凸結合をせずに端の制御点をそのまま返す。
途中の値が平方根の範囲（`f64` ではおよそ $2^{-511}$ から $2^{510}$）を外れた凸結合だけを、拡張した指数の範囲で計算し直す。

一点の評価は制御点の個数と同じ長さの一時ベクトルを呼び出しごとに確保する。
確保を避ける `evaluate_batch_into` は $m$ 点に点の個数と制御点の個数の和の長さの一時領域を使い、`workspace_requirements(m)` はそれに導関数つきの一括評価の分を加えた $2m+(n+1)$ を返す。
区間の外や複素数の点でも評価はでき、凸包性は使えないが、条件のレポートは前節の $(|t|+|1-t|)^n$ の上界で行う。
`subdivide(point)` は区間の真に内側の点で二つの Bernstein 表現に分け、端点か外側の点を `InvalidInput`、非有限の点を `NonFinite` とする。
`elevate_degree(degree)` は隣の制御点の凸結合で関数を変えずに次数を上げ、次数を下げる指定は `InvalidInput` になる。
`derivative`、`antiderivative(anchor, value)`、`integral(lower, upper)` も Bernstein 形式のまま計算する。
導関数の制御点は $n(b_{i+1}-b_i)/(b-a)$、原始関数の制御点は $d_0=0$、$d_{i+1}=d_i+(b-a)b_i/(n+1)$ に定数を足したものである。

単項式との変換は明示的に行う。
`to_monomial` は前進差分 $\Delta^rb_0$ から $[0,1]$ での単項式の係数 $\binom nr\Delta^rb_0$ を作り、区間への一次変換を代入する。
低水準の関数 `backend::polynomial_basis::bernstein_to_power_into` がこの差分と二項係数の漸化式 $\binom n{r+1}=\binom nr(n-r)/(r+1)$ を担う。
単項式の `to_bernstein(lower, upper)` は、区間への写像を代入した係数 $\hat a_j$ から $b_i=\sum_{j\le i}\binom ij\binom nj^{-1}\hat a_j$ を作る。
どちらも $O(n^2)$ の演算で、途中の係数は拡張した指数の範囲で持ち、最後の係数だけを通常の型へ丸める。
最後の係数が桁あふれするか、零でない係数が零へアンダーフローするときは、`NumericalInstability` を返す。
たとえば区間 $[-10^{308},10^{308}]$ の制御点 $(0,1)$ は、単項式の係数 $0.5$ と非正規化数の $5\times10^{-309}$ に変換され、逆の変換で $(0,1)$ に戻る。
変換のレポートの `condition_estimate()` は変換前後の係数の最大の大きさの比で、和の中の打ち消しで失う桁は含まない。
上のセルの $n=10$ でこの比は 15360 で、和 $\sum_k\binom nk2^k=3^n$ が示すように次数とともに指数的に増える。

## まとめ

Bernstein 表現は区間と制御点を保存し、de Casteljau 法で凸結合だけを使って $O(n^2)$ の演算で評価・分割する。
$[0,1]$ での評価の誤差は $\gamma_{3n}\sum_i|b_i|B_i^n(t)\le\gamma_{3n}\max_i|b_i|$ で抑えられ、根の近くでは単項式の Horner 法より条件数が小さいので、区間上の評価や根の分離には Bernstein 表現のまま計算する。
レポートの `forward_error_estimate()` は計算値で割る推定なので、1 を超えたら値に有効な桁がないと読み、1 未満でも保証とはみなさない。
単項式との変換は条件が悪く、変換のレポートの `condition_estimate()` は打ち消しを含まない下限の目安として解釈する。
