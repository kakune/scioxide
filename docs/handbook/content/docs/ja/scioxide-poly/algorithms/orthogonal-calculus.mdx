直交基底の展開 $p(x)=\sum_{k=0}^n\gamma_k\phi_k(x)$ は、単項式に直さずに同じ基底のまま微分・積分できる。
単項式を経由しないので、[直交基底の準備・評価・基底変換](oxref:poly-orthogonal-monomial-growth)で見た係数の増大を避けられる。
このページでは、基底を導関数で表す三項の関係から微分と原始関数の係数を導き、物理座標の尺度と積分定数の扱いを説明する。
三つのセルで、アフィン座標での尺度、多項式の API と Plan から作る作用素の違いを閉形式と比べて確かめる。
族・規格化・アフィン座標を指定する `OrthogonalBasisSpec` と Plan `OrthogonalBasisPlan` は前のページで説明した。

## 微分と積分定数

アフィン変換 $t=(x-\mathrm{shift})/s$（$s=\mathrm{scale}$）により

$$
\frac{d}{dx}=\frac1s\frac{d}{dt},\qquad dx=s\,dt
$$

となる。
この因子を省くと、値は正しくても微分と積分の単位が合わない。

同じ族の係数のまま微分・積分するには、基底を導関数で表す関係を使う。
Chebyshev 第 1 種では

$$
2T_k=\frac{T_{k+1}'}{k+1}-\frac{T_{k-1}'}{k-1}\quad(k\ge2),\qquad T_0=T_1',\qquad T_1=\frac{T_2'}4
$$

が成り立つ（DLMF 18.9）。
これを $p=\sum_{k=0}^n\gamma_kT_k(t)$ に当てはめると、導関数 $p'(x)=\sum_{k=0}^{n-1}\delta_kT_k(t)$ の係数は $\delta_n=\delta_{n+1}=0$ から

$$
\delta_k=\delta_{k+2}+\frac{2(k+1)\gamma_{k+1}}{s}\quad(k=n-1,\dots,1),\qquad
\delta_0=\frac{\gamma_1}{s}+\frac{\delta_2}{2}
$$

と逆向きに求まる。
原始関数 $F=\sum_{j=0}^{n+1}\Gamma_jT_j(t)$ の係数は、$\gamma_{n+1}=\gamma_{n+2}=0$ として

$$
\Gamma_j=\frac{s(\gamma_{j-1}-\gamma_{j+1})}{2j}\quad(j\ge2),\qquad
\Gamma_1=s\Bigl(\gamma_0-\frac{\gamma_2}2\Bigr)
$$

で、定数項 $\Gamma_0$ だけが積分定数として残る。
他の族も $\phi_k=A_k\phi_{k+1}'+B_k\phi_k'+C_k\phi_{k-1}'$ の三項の関係を持ち（Legendre では $(2k+1)P_k=P_{k+1}'-P_{k-1}'$、Laguerre では $L_k=L_k'-L_{k+1}'$、Hermite では $2(k+1)H_k=H_{k+1}'$）、SciOxide は族ごとのこの帯を使って同じ $O(n)$ の計算をする。
原始関数の各係数は入力の高々 3 個の係数の一次結合なので、各係数の丸め誤差はその一次結合の項の絶対値の和の数 $u$ 倍（$u$ は単位丸め）にとどまる。
導関数の逆向きの漸化式では誤差が後ろから積み重なり、$\delta_k$ は $\sum_{j>k}j|\gamma_j|$ の大きさの項の和になるので、高次の係数が大きい展開では低次の係数の相対誤差が大きくなりうる。
どちらも通常の算術で範囲を外れそうなときは、指数の範囲を広げてやり直す。

多項式に対する API は結果を所有する `ApproxPolynomial` を返す。

- `derivative()` は同じ族・規格化・座標の導関数を返す。
  係数の個数は展開の長さから決まり、Plan の最大次数が展開より大きくてもよい。
  返す多項式の Plan は導関数の次数に合わせて準備し直す。
- `antiderivative(anchor, value)` は物理座標で $F(\mathrm{anchor})=\mathrm{value}$ となる原始関数を返し、次数が一つ上がる。
  $\Gamma_0$ は、$\Gamma_0=0$ とした原始関数を `anchor` で [Clenshaw 法](oxref:poly-clenshaw)により評価し、`value` との差を $\phi_0$ で割って決める。
  `anchor` か `value` が有限でなければ `NonFinite` になる。
- `integral(lower, upper)` は重みを掛けない定積分 $\int_{\mathrm{lower}}^{\mathrm{upper}}p(x)\,dx$ を返す。
  $F(\mathrm{lower})=0$ とした原始関数を `upper` で評価するので、$|F(\mathrm{upper})|$ が途中の $|F|$ よりずっと小さいと打ち消しで相対精度が下がる。
  両端が等しければ厳密に 0 を返す。
  端点の型は係数と同じなので、複素数の端点を使うには複素数の係数で多項式を作る（多項式の積分は経路によらない）。

Plan から作る作用素は Plan の最大次数に合わせた長さで動く。

- `plan.derivative_operator()` は Plan を借用する `OrthogonalDerivative` を返し、作成時にはメモリを確保しない。
  `LinearOperator` として `max(degree, 1)` 行・`degree + 1` 列を持ち、入力は末尾の零を含めて正確に `degree + 1` 個でなければならない。
  `apply` は出力を確保して返し、`apply_into` は行数以上の一時領域を受け取って成功時にだけ出力を書く。
- `plan.antiderivative_plan()` は次数を一つ上げた出力の Plan を準備し、`OrthogonalAntiderivative` として所有する。
  `output_plan()` が出力の基底を、`workspace_requirements(())` が一時領域の長さ `degree + 2` を返す。
  `apply_into(input, (anchor, value), output, scratch, context)` は長さ `degree + 1` の入力から長さ `degree + 2` の出力を作り、メモリを確保しない。
  結果は一時領域で組み立て、実行コンテキストの停止を API と書き込みの直前で確かめてから `output` へ移すので、失敗時に `output` は変わらない。
  長さの不一致は `DimensionMismatch`、停止は `ExecutionStopped` になる。

## 座標を動かす微積分の検算

以下では $p=1+2T_1(t)+T_2(t)=2t+2t^2$ を作る。
入力は座標の中心 $x_0$ と尺度 $s$（いずれも無次元）、出力は $t=-1,-1/2,0,1/2,1$ に対応する点での値・物理座標での導関数・$F(x_0)=0$ とした原始関数と、区間 $[x_0-s,x_0+s]$ 全体の積分である。
独立検算には右辺の二次式を項別に微積分した閉形式 $p'=(2+4t)/s$、$F=s(t^2+2t^3/3)$ と、区間全体の積分 $4s/3$ を使う。
最初の表の差の列が丸めの大きさにとどまり、2 番目の表の積分が閉形式と一致することを確かめる。

```rust
//| id: poly-chebyshev-calculus
//| ref: poly-chebyshev-calculus
//| title: アフィン座標と微積分の尺度
//| run: reactive
//| crates: [scioxide-poly]
//| inputs:
//|   center: {"type":"range","label":"中心 x₀ [-]","min":-3,"max":3,"step":0.5,"value":1}
//|   width: {"type":"range","label":"尺度 s [-]","min":0.5,"max":4,"step":0.5,"value":2}
//| cases:
//|   - {"id":"narrow-shifted","label":"x₀ = −3, s = 0.5","description":"尺度を 1/4 にすると、同じ t での導関数は 4 倍、原始関数は 1/4 倍になる。","inputs":{"center":-3,"width":0.5}}
//|   - {"id":"wide","label":"s = 4","description":"尺度を倍にすると、導関数は半分、原始関数と積分は倍になる。","inputs":{"width":4}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"values","path":"/rows/4/2","approx":{"value":3,"rtol":1e-14}}
//|       - {"artifact":"values","path":"/rows/4/3","approx":{"value":3.3333333333333335,"rtol":1e-14}}
//|       - {"artifact":"values","path":"/rows/4/5","range":{"max":1e-14}}
//|       - {"artifact":"values","path":"/rows/0/6","range":{"max":1e-14}}
//|       - {"artifact":"integral","path":"/rows/0/1","approx":{"value":2.6666666666666665,"rtol":1e-14}}
//|   - case: narrow-shifted
//|     expect:
//|       - {"artifact":"values","path":"/rows/4/2","approx":{"value":12,"rtol":1e-14}}
//|       - {"artifact":"values","path":"/rows/4/3","approx":{"value":0.8333333333333334,"rtol":1e-13}}
//|       - {"artifact":"integral","path":"/rows/0/1","approx":{"value":0.6666666666666666,"rtol":1e-13}}
//|   - case: wide
//|     expect:
//|       - {"artifact":"values","path":"/rows/4/2","approx":{"value":1.5,"rtol":1e-14}}
//|       - {"artifact":"values","path":"/rows/4/3","approx":{"value":6.666666666666667,"rtol":1e-14}}
//|       - {"artifact":"integral","path":"/rows/0/1","approx":{"value":5.333333333333333,"rtol":1e-14}}
use scioxide_poly::{
    ApproxPolynomial, BasisNormalization, OrthogonalBasisSpec, OrthogonalFamily,
};

let fixed4 = serde_json::json!({ "fractionDigits": 4 });
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let spec = OrthogonalBasisSpec::new(
    OrthogonalFamily::ChebyshevT,
    BasisNormalization::Classical,
    center,
    width,
)
.map_err(|e| e.to_string())?;
let polynomial =
    ApproxPolynomial::orthogonal(vec![1.0_f64, 2.0, 1.0], spec).map_err(|e| e.to_string())?;
let derivative = polynomial.derivative().map_err(|e| e.to_string())?;
let primitive = polynomial
    .antiderivative(center, 0.0)
    .map_err(|e| e.to_string())?;
let mut rows = Vec::new();
for t in [-1.0_f64, -0.5, 0.0, 0.5, 1.0] {
    let x = center + width * t;
    let p = polynomial.evaluate(x).map_err(|e| e.to_string())?;
    let d = derivative.evaluate(x).map_err(|e| e.to_string())?;
    let f = primitive.evaluate(x).map_err(|e| e.to_string())?;
    // 独立検算: p=2t+2t²、dp/dx=(2+4t)/s、F=s(t²+2t³/3)。
    rows.push((
        x,
        p,
        d,
        f,
        (p - (2.0 * t + 2.0 * t * t)).abs(),
        (d - (2.0 + 4.0 * t) / width).abs(),
        (f - width * (t * t + 2.0 * t * t * t / 3.0)).abs(),
    ));
}
let columns = serde_json::json!([
    { "key": "0", "label": "x [-]", "type": "number", "format": fixed4 },
    { "key": "1", "label": "p [-]", "type": "number", "format": fixed4 },
    { "key": "2", "label": "p′ [-]", "type": "number", "format": fixed4 },
    { "key": "3", "label": "F [-]", "type": "number", "format": fixed4 },
    { "key": "4", "label": "値の差 [-]", "type": "number", "format": sci2 },
    { "key": "5", "label": "微分の差 [-]", "type": "number", "format": sci2 },
    { "key": "6", "label": "積分の差 [-]", "type": "number", "format": sci2 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "values" })
);
let integral = polynomial
    .integral(center - width, center + width)
    .map_err(|e| e.to_string())?;
let exact = 4.0 * width / 3.0;
let integral_columns = serde_json::json!([
    { "key": "0", "label": "量" },
    { "key": "1", "label": "SciOxide [-]", "type": "number", "format": fixed4 },
    { "key": "2", "label": "閉形式 [-]", "type": "number", "format": fixed4 },
    { "key": "3", "label": "差 [-]", "type": "number", "format": sci2 }
]);
emit_table_with_columns!(
    integral_columns,
    vec![("区間全体の積分", integral, exact, (integral - exact).abs())],
    metadata = serde_json::json!({ "id": "integral" })
);
```

尺度を倍にすると、同じ $t$ での値は変わらず、導関数は半分、原始関数は倍になる。
中心を変えると物理座標だけが移り、同じ $t$ に対応する値と微積分の検算は変わらない。
既定の $x_0=1$、$s=2$ では区間全体の積分が $8/3$ に一致し、差はどの列も $4.5\times10^{-16}$ 以下である。
既定以外の入力でも、差は $9\times10^{-16}$ 以下にとどまる。

## 展開の長さと Plan の次数

多項式の `derivative()` と `antiderivative()` は展開の長さで係数を作る。
一方、Plan から作る作用素 `OrthogonalDerivative` と `OrthogonalAntiderivative` は、Plan の最大次数で入力と出力の長さが決まる。
次の二つのセルは同じ $p=1+2T_1+T_2$ を最大次数 $N$ の Plan に置き、多項式の API と Plan の作用素が返す係数を、上の公式で手計算した閉形式と比べる。
入力は尺度 $s$ と Plan の最大次数 $N$ で、中心は 0 とする。
閉形式は $p'=(2+4T_1)/s$、$F=s(1/2+T_1/2+T_2/2+T_3/6)$（$F(0)=0$）であり、係数がない次数は「—」で示す。

次のブロックは二つのセルが共有する定義である。
`COEFFICIENTS` が $p$ の係数 $(1,2,1)$、`expansion_on_plan` が中心 0・尺度 $s$ の Chebyshev 基底を最大次数 $N$ で準備して $p$ を置いた多項式、`padded` が作用素へ渡すために末尾を零で $N+1$ 個に伸ばした係数に対応する。
`coefficient_rows` と `coefficient_columns` は、次数ごとに多項式の API・Plan の作用素・閉形式の係数を並べ、係数のない次数を `None` にして零と区別する表を作る。
`count_columns` は作用素の長さを示す 2 列の表の列である。

```rust
//| id: poly-orthogonal-calculus-model
//| kind: definitions
//| title: 最大次数 N の Plan に置いた 2 次の Chebyshev 展開と比較表
//| crates: [scioxide-poly]
use scioxide_poly::{
    ApproxPolynomial, BasisNormalization, OrthogonalBasis, OrthogonalBasisSpec, OrthogonalFamily,
};

/// p = T₀ + 2T₁ + T₂ の昇べき順の係数。
pub(crate) const COEFFICIENTS: [f64; 3] = [1.0, 2.0, 1.0];

/// 中心 0・尺度 s の Chebyshev 基底を最大次数 N で準備し、p をその Plan に置く。
/// Plan は多項式が所有し、basis().plan() で借用する。
pub(crate) fn expansion_on_plan(
    width: f64,
    degree: usize,
) -> Result<ApproxPolynomial<f64, OrthogonalBasis<f64>>, String> {
    let spec = OrthogonalBasisSpec::new(
        OrthogonalFamily::ChebyshevT,
        BasisNormalization::Classical,
        0.0,
        width,
    )
    .map_err(|e| e.to_string())?;
    let plan = spec
        .prepare(degree, Default::default())
        .map_err(|e| e.to_string())?;
    ApproxPolynomial::orthogonal_with_plan(COEFFICIENTS.to_vec(), plan, Default::default())
        .map_err(|e| e.to_string())
}

/// Plan の作用素は N + 1 個の入力を受け取るので、末尾を零で埋める。
pub(crate) fn padded(degree: usize) -> Vec<f64> {
    let mut values = COEFFICIENTS.to_vec();
    values.resize(degree + 1, 0.0);
    values
}

/// 次数 0..=last の行 (k, 多項式の API, Plan の作用素, 閉形式)。
/// 係数がない次数は None にし、零と区別する。
pub(crate) fn coefficient_rows(
    polynomial: &[f64],
    plan: &[f64],
    exact: &[f64],
    last: usize,
) -> Vec<(usize, Option<f64>, Option<f64>, Option<f64>)> {
    let entry = |values: &[f64], k: usize| values.get(k).copied();
    (0..=last)
        .map(|k| (k, entry(polynomial, k), entry(plan, k), entry(exact, k)))
        .collect()
}

/// coefficient_rows の表の列。polynomial と plan は比べる二つの API の名前。
pub(crate) fn coefficient_columns(polynomial: &str, plan: &str) -> serde_json::Value {
    let fixed6 = serde_json::json!({ "fractionDigits": 6 });
    serde_json::json!([
        { "key": "0", "label": "次数 k", "type": "integer" },
        { "key": "1", "label": polynomial, "type": "number", "format": fixed6, "nullText": "—" },
        { "key": "2", "label": plan, "type": "number", "format": fixed6, "nullText": "—" },
        { "key": "3", "label": "閉形式", "type": "number", "format": fixed6, "nullText": "—" }
    ])
}

/// 作用素の長さを示す「量・値」の表の列。
pub(crate) fn count_columns() -> serde_json::Value {
    serde_json::json!([
        { "key": "0", "label": "量" },
        { "key": "1", "label": "値", "type": "integer" }
    ])
}
```

最初のセルは導関数を比べる。
`derivative()` は展開の長さで係数を作り、返す多項式の Plan を導関数の次数に合わせて準備し直す。
`derivative_operator()` は Plan を借用し、`max(N, 1)` 行・$N+1$ 列の作用素として働く。
2 番目の表は作用素の行数・列数と、`derivative()` が返す多項式の Plan の次数を示す。

```rust
//| id: poly-orthogonal-calculus-operators
//| ref: poly-orthogonal-calculus-operators
//| title: 展開の長さと Plan の次数で決まる導関数の係数
//| run: reactive
//| uses: [poly-orthogonal-calculus-model]
//| crates: [scioxide-core, scioxide-poly]
//| inputs:
//|   width: {"type":"range","label":"尺度 s [-]","min":0.5,"max":4,"step":0.5,"value":2}
//|   plan_degree: {"type":"range","label":"Plan の最大次数 N","min":2,"max":6,"step":1,"value":4}
//| cases:
//|   - {"id":"exact-degree","label":"N = 2","description":"Plan の次数が展開と等しく、作用素と多項式の API が同じ長さの係数を返す。","inputs":{"plan_degree":2}}
//|   - {"id":"long-plan","label":"N = 6, s = 0.5","description":"長い Plan では作用素の出力の末尾に零が並び、尺度を 1/4 にすると係数が 4 倍になる。","inputs":{"plan_degree":6,"width":0.5}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"derivative","path":"/rows/0/1","approx":{"value":1,"rtol":1e-14}}
//|       - {"artifact":"derivative","path":"/rows/1/2","approx":{"value":2,"rtol":1e-14}}
//|       - {"artifact":"derivative","path":"/rows/2/1","equals":null}
//|       - {"artifact":"derivative","path":"/rows/3/2","equals":0}
//|       - {"artifact":"shapes","path":"/rows/0/1","equals":4}
//|       - {"artifact":"shapes","path":"/rows/1/1","equals":5}
//|       - {"artifact":"shapes","path":"/rows/2/1","equals":1}
//|   - case: exact-degree
//|     expect:
//|       - {"artifact":"derivative","path":"/rows/1/2","approx":{"value":2,"rtol":1e-14}}
//|       - {"artifact":"derivative","path":"/rows/2/2","equals":null}
//|       - {"artifact":"shapes","path":"/rows/0/1","equals":2}
//|   - case: long-plan
//|     expect:
//|       - {"artifact":"derivative","path":"/rows/1/2","approx":{"value":8,"rtol":1e-14}}
//|       - {"artifact":"derivative","path":"/rows/5/2","equals":0}
//|       - {"artifact":"shapes","path":"/rows/0/1","equals":6}
use scioxide_core::LinearOperator;
use scioxide_poly::PolynomialBasis;

let degree = plan_degree as usize;
let polynomial = expansion_on_plan(width, degree)?;
// 多項式の API は展開の長さ（3 係数）から係数を作る。
let derivative = polynomial.derivative().map_err(|e| e.to_string())?;
// Plan の作用素は N + 1 個の入力から max(N, 1) 個の係数を作る。
let operator = polynomial.basis().plan().derivative_operator();
let rows_out = LinearOperator::<f64>::rows(&operator);
let mut by_operator = vec![0.0_f64; rows_out];
let scratch_len =
    LinearOperator::<f64>::apply_workspace_len(&operator).map_err(|e| e.to_string())?;
let mut scratch = vec![0.0_f64; scratch_len];
operator
    .apply_into(&padded(degree), &mut by_operator, &mut scratch)
    .map_err(|e| e.to_string())?;
// 独立検算: T_k の微分の公式から手で求めた係数 p′ = (2 + 4T₁)/s。
let exact = [2.0 / width, 4.0 / width];
let rows = coefficient_rows(
    derivative.basis().coefficients(),
    &by_operator,
    &exact,
    degree,
);
emit_table_with_columns!(
    coefficient_columns("derivative()", "derivative_operator()"),
    rows,
    metadata = serde_json::json!({ "id": "derivative" })
);
let shapes = vec![
    ("作用素の行数", rows_out),
    ("作用素の列数", LinearOperator::<f64>::cols(&operator)),
    (
        "derivative() の Plan の最大次数",
        derivative.basis().plan().degree(),
    ),
];
emit_table_with_columns!(
    count_columns(),
    shapes,
    metadata = serde_json::json!({ "id": "shapes" })
);
```

`derivative()` は $N$ によらず 2 個の係数を返し、閉形式と一致する。
返す多項式の Plan も導関数の次数（ここでは 1）に合わせて準備し直される。
作用素は $N$ 個の係数を返し、展開を超える次数には零が入る。
したがって、Plan を $N$ 次で一度準備しておけば、それより短い展開にも多項式の API で微分を使える。
作用素を直接使うときは、入力の長さを Plan に合わせて零で埋める必要がある。

次のセルは原始関数を同じ形で比べる。
`antiderivative(0, 0)` は展開の長さから 4 個の係数を作り、`antiderivative_plan()` は次数を一つ上げた出力の Plan を準備して、$N+1$ 個の入力から $N+2$ 個の係数を書く。
2 番目の表は出力の Plan の次数、出力と一時領域の長さを示す。

```rust
//| id: poly-orthogonal-antiderivative-plan
//| ref: poly-orthogonal-antiderivative-plan
//| title: 展開の長さと Plan の次数で決まる原始関数の係数
//| run: reactive
//| uses: [poly-orthogonal-calculus-model]
//| crates: [scioxide-core, scioxide-poly]
//| inputs:
//|   width: {"type":"range","label":"尺度 s [-]","min":0.5,"max":4,"step":0.5,"value":2}
//|   plan_degree: {"type":"range","label":"Plan の最大次数 N","min":2,"max":6,"step":1,"value":4}
//| cases:
//|   - {"id":"exact-degree","label":"N = 2","description":"Plan の次数が展開と等しく、準備した原始関数と多項式の API が同じ 4 個の係数を返す。","inputs":{"plan_degree":2}}
//|   - {"id":"long-plan","label":"N = 6, s = 0.5","description":"長い Plan では出力の末尾に零が並び、尺度を 1/4 にすると係数も 1/4 になる。","inputs":{"plan_degree":6,"width":0.5}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"antiderivative","path":"/rows/0/1","approx":{"value":1,"rtol":1e-14}}
//|       - {"artifact":"antiderivative","path":"/rows/3/2","approx":{"value":0.3333333333333333,"rtol":1e-14}}
//|       - {"artifact":"antiderivative","path":"/rows/4/1","equals":null}
//|       - {"artifact":"antiderivative","path":"/rows/5/2","equals":0}
//|       - {"artifact":"lengths","path":"/rows/0/1","equals":5}
//|       - {"artifact":"lengths","path":"/rows/1/1","equals":6}
//|       - {"artifact":"lengths","path":"/rows/2/1","equals":6}
//|   - case: exact-degree
//|     expect:
//|       - {"artifact":"antiderivative","path":"/rows/3/2","approx":{"value":0.3333333333333333,"rtol":1e-14}}
//|       - {"artifact":"lengths","path":"/rows/1/1","equals":4}
//|   - case: long-plan
//|     expect:
//|       - {"artifact":"antiderivative","path":"/rows/3/2","approx":{"value":0.08333333333333333,"rtol":1e-14}}
//|       - {"artifact":"antiderivative","path":"/rows/7/2","equals":0}
//|       - {"artifact":"lengths","path":"/rows/1/1","equals":8}
use scioxide_core::ExecutionContext;
use scioxide_poly::PolynomialBasis;

let degree = plan_degree as usize;
let polynomial = expansion_on_plan(width, degree)?;
// 多項式の API は展開の長さから 4 個の係数を作り、F(0) = 0 で積分定数を決める。
let primitive = polynomial
    .antiderivative(0.0, 0.0)
    .map_err(|e| e.to_string())?;
// 準備した原始関数は N + 1 個の入力から N + 2 個の係数を書く。
let integral = polynomial
    .basis()
    .plan()
    .antiderivative_plan()
    .map_err(|e| e.to_string())?;
let output_degree = integral.output_plan().degree();
let mut by_plan = vec![0.0_f64; output_degree + 1];
let scratch_len = integral
    .workspace_requirements(())
    .map_err(|e| e.to_string())?
    .scratch_len();
let mut scratch = vec![0.0_f64; scratch_len];
integral
    .apply_into(
        &padded(degree),
        (0.0, 0.0),
        &mut by_plan,
        &mut scratch,
        ExecutionContext::sequential(),
    )
    .map_err(|e| e.to_string())?;
// 独立検算: T_k の積分の公式から手で求めた係数 F = s(1/2 + T₁/2 + T₂/2 + T₃/6)。
let exact = [width / 2.0, width / 2.0, width / 2.0, width / 6.0];
let rows = coefficient_rows(
    primitive.basis().coefficients(),
    &by_plan,
    &exact,
    degree + 1,
);
emit_table_with_columns!(
    coefficient_columns("antiderivative()", "antiderivative_plan()"),
    rows,
    metadata = serde_json::json!({ "id": "antiderivative" })
);
let lengths = vec![
    ("出力の Plan の最大次数", output_degree),
    ("出力の長さ", by_plan.len()),
    ("一時領域の長さ", scratch.len()),
];
emit_table_with_columns!(
    count_columns(),
    lengths,
    metadata = serde_json::json!({ "id": "lengths" })
);
```

`antiderivative()` は $N$ によらず 4 個の係数を返し、閉形式と一致する。
準備した原始関数は $N+2$ 個の係数を返し、$k\ge4$ には零が入る。
出力の Plan の次数は $N+1$、一時領域の長さは出力と同じ $N+2$ である。

## まとめ

直交展開は単項式に直さずに、族ごとの三項の関係で同じ基底のまま $O(n)$ で微分・積分できる。
物理座標の導関数には $1/s$、積分には $s$ が掛かるので、中心と尺度を明示して単位を確かめる。
積分定数は物理座標のアンカー $F(\mathrm{anchor})=\mathrm{value}$ で指定し、`integral` は重みを掛けない定積分である。
多項式の微積分は展開の長さで、作用素と準備した原始関数は Plan の最大次数で長さが決まるので、作用素への入力は零で埋めて長さをそろえる。
繰り返す微分と積分は `OrthogonalDerivative` と `OrthogonalAntiderivative` を再利用し、一時領域の長さは各要件から問い合わせる。
