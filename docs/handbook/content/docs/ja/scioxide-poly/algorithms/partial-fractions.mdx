有理関数を部分分数に分けると、逆 Laplace 変換や積分のように項ごとの公式が使える。
SciOxide は分母の因子と重複度を呼び出し側から受け取り、因子を探索せずに分解する。
このページでは分解の存在と一意性、浮動小数点の係数で解く連立方程式とその条件、繰り返す分解のための作業領域、近い極での係数の誤差を扱う。
厳密な体の係数での分解は[厳密な部分分数分解](../exact-partial-fractions/)で扱う。
記号 $u$ は単位丸め（`f64` で $2^{-53}$）を表し、多項式の係数は昇べき順に並べる。

## 分解の形と一意性

分母が互いに素なモニックの因子の冪の積 $D(x) = \prod_{i=1}^r F_i(x)^{m_i}$ で与えられると、有理関数 $N/D$ は次の形にただ一通りに分解できる。

$$
\frac{N(x)}{D(x)} = Q(x) + \sum_{i=1}^r \sum_{j=1}^{m_i} \frac{A_{ij}(x)}{F_i(x)^j} \quad (\deg A_{ij} < \deg F_i)
$$

$r$ は因子の数、$Q$ は $N$ を $D$ で割った商（多項式部）である。
存在と一意性は中国剰余定理による。
剰余 $R = N - QD$ を補因子 $C_i = D/F_i^{m_i}$ で表すと、$C_i$ は $F_i^{m_i}$ を法として逆元を持ち、$A_i = R\, C_i^{-1} \bmod F_i^{m_i}$ が $R/D = \sum_i A_i / F_i^{m_i}$ を満たす唯一の組になる。
$A_i$ を $F_i$ 進展開 $A_i = \sum_{k=0}^{m_i - 1} a_k F_i^k$（$\deg a_k < \deg F_i$）すると、$A_i/F_i^{m_i} = \sum_k a_k / F_i^{m_i - k}$ が各冪の項を与える。

一次の因子 $F_i = x - a$ では、$A_{ij}$ は極 $a$ での Laurent 展開の主要部の係数で、

$$
A_{ij} = \frac{1}{(m_i - j)!} \left.\frac{d^{\,m_i - j}}{dx^{\,m_i - j}} \Big[(x - a)^{m_i} \frac{N(x)}{D(x)}\Big]\right|_{x = a}
$$

で与えられる。
$A_{i1}$ が極 $a$ での留数である。
単純な極（$m_i = 1$）では $A_{i1} = N(a)/D'(a)$ になる。
二つの単純な極 $a, b$ が近づくと $D'(a)$ と $D'(b)$ はどちらも $a - b$ に比例して小さくなるので、留数は $1/(a - b)$ に比例して大きくなり、互いに打ち消し合って $N/D$ を作り直す。

## 重複極を含む係数の連立方程式

$N = QD + R$（$\deg R < n = \deg D$）と割ってから両辺に $D$ を掛けると、未知の係数 $A_{ij}$ について線形な恒等式になる。

$$
R(x) = \sum_{i=1}^r \sum_{j=1}^{m_i} A_{ij}(x)\, F_i(x)^{m_i - j} \prod_{l \ne i} F_l(x)^{m_l}
$$

未知数は $\sum_i m_i \deg F_i = n$ 個、方程式は $x^0, \dots, x^{n-1}$ の係数の $n$ 本で、$n \times n$ の連立一次方程式になる。
この行列が正則であることは、因子が互いに素であることと同値である（中国剰余定理による同型 $F[x]/(D) \cong \prod_i F[x]/(F_i^{m_i})$）。
近い極は互いに素だがほとんどそうでない因子の組に当たり、係数の行列が特異に近づく。

`ApproxPartialFractionPlan::new(&denominator, &[(&factor, multiplicity), ...])` は、次の手順で準備する。

1. 分母がモニック、各因子がモニックで定数でないこと、重複度が正で次数の和が分母の次数に一致すること、方針がすべて同じであることを確かめる。
   外れると `InvalidInput`（`Inconsistent`）、次数の和が `usize` を超えると `SizeOverflow` になる。
2. 因子の積 $P = \prod F_i^{m_i}$ を作り、係数の相対誤差 `factorization_error` $= \max_k |D_k - P_k| / \max(\max_k |D_k|, \max_k |P_k|)$ が方針の許容誤差 $\tau_{\text{abs}} + \tau_{\text{rel}}$ 以下であることを確かめる。
   超えると `NumericalInstability`（`IllConditioned`）になる。
3. 上の恒等式の係数行列を、根を割り出す操作ではなく多項式の積で作る。
   $A_{ij}$ の $x^s$ の係数に対応する列は、補因子 $F_i^{m_i - j} \prod_{l \ne i} F_l^{m_l}$ の係数を $s$ だけずらした列である。
4. 列、次に行を、それぞれの最大絶対値で割って平衡化し、列ピボット付きの Householder QR 分解を行う。
5. 方針のうちランクの方針で数値ランクを調べ、正則でなければ「互いに素でないか数値的に分離できない因子」として `NumericalInstability`（`IllConditioned`）で拒否する。

因子は既約である必要はなく（実係数の $x^2 + 1$ など）、Plan が因子を探索することも、近い極をまとめることもない。
係数は実数でも複素数でもよい。
準備は $O(n^2)$ のメモリと $O(n^3)$ の計算を使う。

`decompose(numerator)` は、分子を因子の積 $P$ で割って多項式部と剰余を作り、QR 分解で係数を解き、平衡化を戻す。
呼び出し側の分母ではなく $P$ で割るので、多項式部と剰余は方程式を作った因子分解と食い違わない。
最後に、多項式部と各項から分子を作り直し、係数ごとの誤差の最大を、係数ごとの尺度（元の係数と寄与した各項の大きさの和）の最大で割って `reconstruction_error` とする。
これが許容誤差 $\tau_{\text{abs}} + \tau_{\text{rel}}$ を超えるか、QR 分解での求解が満ランクを受け入れなければ `NumericalInstability`（`IllConditioned`）で拒否する。
尺度に寄与した項の大きさを含めるので、大きな係数どうしの打ち消しで分子を作り直している場合も、誤差として現れる。

極どうしが近いと、係数の方程式は特異に近づき、個々の係数 $A_{ij}$ の誤差は単位丸めを逆条件数で割った程度まで増えうる。
この悪条件は `PartialFractionReport` で読む。
`factorization_error()` は上の因子の積の相対誤差、`reconstruction_error()` は分子の作り直しの後退誤差、`rank()` は係数の方程式の数値ランク（Plan は満ランクだけを受け入れるので常に $n$）、`reciprocal_condition()` は平衡化した方程式の 1 ノルムの逆条件数の推定（Hager–Higham 法）である。
分母が定数なら解く方程式がないので、`reciprocal_condition()` は `None` を返す。
どれも推定値で、係数の誤差の保証ではない。

Plan の `denominator()` は分母、`factors()` は入力の順の `PartialFractionFactor` の列で、各要素は因子 `polynomial()`、重複度 `multiplicity()`、一次の因子なら極の感度 `pole_condition()` を持つ。
`pole_condition()` は、極 $a$ を元の分母 $D$ の根とみなした `RootConditionReport` で、二次以上の因子では `None` である。
重複した極では $D'(a) = 0$ なので、絶対感度 `absolute()` は `Singular` になる。
Plan の `terms()` は `PartialFractionTerm` の列で、因子の番号 `factor_index()`、分母の冪 `power()`、詰めて並べた係数の範囲 `coefficients()` を、因子の入力順、冪の昇順に持つ。

## Plan・作業領域・出力

同じ分母で分子だけが変わる分解を繰り返すときは、メモリを前もって確保する。
`workspace_requirements(numerator_len)` が返す `PartialFractionRequirements` は、係数の数が `numerator_len` 以下の分子に足りる長さで、商と長除法、拡張指数の一時領域、係数の方程式の右辺と解、Householder の求解の領域を表す。
商の要件は分子の長さそのものとし、剰余の要件は分子の長さと分母の次数の大きい方とするので、要件は Plan の次数と分子の長さのどちらについても単調に増える。
`degree()` は分母の次数（詰めた係数の数）、`required_bytes()` は作業領域の確保量（出力の容量と `Vec` の管理領域を除く）を返す。
`numerator_len` が 0 なら `InvalidInput`（`Empty`）になる。

`PartialFractionWorkspace` は呼び出し側が所有する作業領域で、`plan.workspace(numerator_len)` で作るか、`PartialFractionWorkspace::new()` から `try_reserve(&requirements)` で確保する。
事前確保は増えるだけで、`check(&requirements)` は保持している容量で判定するので、最大の Plan と分子に合わせて確保した領域は、それより小さい Plan・次数・分子にもそのまま使える。
出力の `ApproxPartialFractions` も同じ要件で `try_reserve` し、`polynomial()` で多項式部、`residues()` で Plan の項の順に詰めた係数、`report()` でレポート（成功するまで `None`）を返す。
`decompose_into(numerator, &mut output, &mut workspace, context)` は確保を行わず、作業領域か出力の容量が足りなければ `DimensionMismatch` を返す。
空の分子は `InvalidInput`（`Empty`）、非有限の係数は `NonFinite`、取り消しや期限切れは `ExecutionStopped` になる。
失敗しても出力は変わらず、作業領域は成功の後も失敗の後も再利用できる。
準備の後の計算量は $O(n^2 + N(n+1))$（$N$ は分子の係数の数）である。

`decompose` は、要件どおりに確保した領域で同じ処理を行う簡易形式で、`ExecutionContext::sequential_native()` のコンテキストで計算する。
このコンテキストはプロセッサ固有の命令を使う演算カーネルを選べるので、`ExecutionContext::sequential()` を渡した `decompose_into` とは最後の桁が異なることがある。
再利用した領域での結果は、許容誤差を付けて解析的な値や再構成誤差と照合する。

部分分数の Plan は実行の方針を持たず、呼び出したコンテキストの上で逐次に計算する。
並列実行の意図とワーカー数の上限を表す `PolynomialExecutionOptions`（既定は逐次、上限 64）は、演算の Plan `PolynomialOperationPlan`、直交基底の Plan、テンソル積 Bernstein、疎な多変数の評価 Plan が保持するもので、部分分数分解には関係しない。
このハンドブックのセルは wasm で逐次に動く。

## 重複極の分解と再構成

以下のセルは既知の因子 $(x-1)^2$ と $F_1 = (x-1)^2 + s^2$（極 $1 \pm is$）を持つ分母 $D = (x - 1)^2 F_1$ を使う。
分子 $N$ は、部分分数 $a/(x-1) + 2/(x-1)^2 + (3 + 4x)/F_1$ を通分した式 $(a(x - 1) + 2)F_1 + (3 + 4x)(x - 1)^2$ として、SciOxide の多項式の積で作る。
したがって分解の係数の真値は $a, 2, 3, 4$ で、計算した係数をこの真値と比べることが独立検算になる。
定義のブロックの `PartialFractionModel::new(a, s)` が因子・分母・分子を作り、`plan()` が因子 $x - 1$ の重複度 2 と $F_1$ の重複度 1 を与えた Plan を準備する。

```rust
//| id: poly-partial-fraction-model
//| kind: definitions
//| title: 重複極 x = 1 と共役な極の対 1 ± is を持つ有理関数
//| crates: [scioxide-core, scioxide-poly]
use scioxide_core::SciOxideError;
use scioxide_poly::{ApproxPartialFractionPlan, ApproxPolynomial, MonomialBasis};

pub(crate) type Monomial = ApproxPolynomial<f64, MonomialBasis<f64>>;

/// 分母 D = (x − 1)² F₁（F₁ = (x − 1)² + s²）の因子と、
/// 部分分数 a/(x − 1) + 2/(x − 1)² + (3 + 4x)/F₁ を通分した分子 N
pub(crate) struct PartialFractionModel {
    pub(crate) linear: Monomial,
    pub(crate) pair: Monomial,
    pub(crate) denominator: Monomial,
    pub(crate) numerator: Monomial,
}

impl PartialFractionModel {
    pub(crate) fn new(residue: f64, s: f64) -> Result<Self, SciOxideError> {
        let linear = ApproxPolynomial::monomial(vec![-1.0_f64, 1.0])?;
        let square = linear.try_mul(&linear)?;
        // F₁ = x² − 2x + 1 + s²
        let pair = ApproxPolynomial::monomial(vec![1.0 + s * s, -2.0, 1.0])?;
        let denominator = square.try_mul(&pair)?;
        // N = (a(x − 1) + 2)F₁ + (3 + 4x)(x − 1)²
        let head = ApproxPolynomial::monomial(vec![2.0 - residue, residue])?;
        let tail = ApproxPolynomial::monomial(vec![3.0, 4.0])?;
        let numerator = head.try_mul(&pair)?.try_add(&tail.try_mul(&square)?)?;
        Ok(Self {
            linear,
            pair,
            denominator,
            numerator,
        })
    }

    /// 因子 (x − 1) の重複度 2 と F₁ の重複度 1 を与えた Plan
    pub(crate) fn plan(&self) -> Result<ApproxPartialFractionPlan<f64>, SciOxideError> {
        ApproxPartialFractionPlan::new(&self.denominator, &[(&self.linear, 2), (&self.pair, 1)])
    }
}
```

次のセルは $s = 1$ の離れた極で、`workspace_requirements` から作業領域と出力を確保し、`ExecutionContext::sequential()` のコンテキストで `decompose_into` を呼ぶ。
入力は一次の極の係数 $a$ である。
1 つ目の表は返された係数を Plan の項の順（因子の入力順、冪の昇順）に並べ、作るときに使った値と比べる。
2 つ目の表はレポートの各値と作業領域の大きさを示し、極の絶対感度が有限でなければその列挙子の名前を表示する。

```rust
//| id: poly-partial-fraction-reconstruction
//| ref: poly-partial-fraction-reconstruction
//| title: 重複極の留数と分解のレポート
//| run: reactive
//| uses: [poly-partial-fraction-model]
//| crates: [scioxide-core, scioxide-poly]
//| inputs:
//|   residue: {"type":"range","label":"一次の極の係数 a [-]","description":"a = 0 では 1/(x − 1) の項が消える。","min":-2,"max":3,"step":0.5,"value":1}
//| cases:
//|   - {"id":"no-simple-term","label":"a = 0","description":"真値が 0 の係数も、丸めの程度の大きさで求まる。","inputs":{"residue":0}}
//|   - {"id":"negative-residue","label":"a = −2","description":"係数の符号が変わっても、レポートの逆条件数は分母だけで決まり変わらない。","inputs":{"residue":-2}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"coefficients","path":"/rows/0/3","approx":{"value":1,"atol":1e-13}}
//|       - {"artifact":"coefficients","path":"/rows/3/3","approx":{"value":4,"atol":1e-13}}
//|       - {"artifact":"report","path":"/rows/0/1","range":{"max":1e-15}}
//|       - {"artifact":"report","path":"/rows/0/3","approx":{"value":0.020202020202020204,"rtol":1e-6}}
//|       - {"artifact":"report","path":"/rows/0/4","equals":null}
//|       - {"artifact":"report","path":"/rows/0/5","equals":736}
//|   - case: no-simple-term
//|     expect:
//|       - {"artifact":"coefficients","path":"/rows/0/5","range":{"max":1e-14}}
//|       - {"artifact":"report","path":"/rows/0/1","range":{"max":1e-15}}
//|   - case: negative-residue
//|     expect:
//|       - {"artifact":"coefficients","path":"/rows/0/3","approx":{"value":-2,"atol":1e-13}}
//|       - {"artifact":"report","path":"/rows/0/3","approx":{"value":0.020202020202020204,"rtol":1e-6}}
use scioxide_core::ExecutionContext;
use scioxide_poly::{ApproxPartialFractions, PolynomialBasis};

let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let sig15 = serde_json::json!({ "significantDigits": 15 });
// s = 1 では F₁ = (x − 1)² + 1 の極は 1 ± i で、重複極 x = 1 から離れている
let model = PartialFractionModel::new(residue, 1.0).map_err(|e| e.to_string())?;
let plan = model.plan().map_err(|e| e.to_string())?;
let coefficients = model.numerator.basis().coefficients();
// 分子の係数の数に足りる要件から、作業領域と出力を確保する
let requirements = plan
    .workspace_requirements(coefficients.len())
    .map_err(|e| e.to_string())?;
let mut workspace = plan
    .workspace(coefficients.len())
    .map_err(|e| e.to_string())?;
let mut fractions = ApproxPartialFractions::new();

    .try_reserve(&requirements)
    .map_err(|e| e.to_string())?;
plan.decompose_into(
    coefficients,
    &mut fractions,
    &mut workspace,
    ExecutionContext::sequential(),

.map_err(|e| e.to_string())?;

// 独立検算: 係数を作るときに使った値（項の順は因子の入力順、冪の昇順）
let expected = [vec![residue], vec![2.0], vec![3.0, 4.0]];

    let computed = &fractions.residues()[term.coefficients()];
    for (degree, (&c, &r)) in computed.iter().zip(reference).enumerate() {
        rows.push((
            term.factor_index(),
            term.power(),
            degree,
            c,
            r,
            (c - r).abs(),
        ));
    }
}

    columns,
    rows,
    metadata = serde_json::json!({ "id": "coefficients" })

let pole = plan.factors()[0]
    .pole_condition()
    .ok_or("一次の因子の極の感度がない")?
    .absolute();
let pole_label = format!("{pole:?}");
let report_columns = serde_json::json!([
    { "key": "0", "label": "因子の積の相対誤差 [-]", "type": "number", "format": sci3 },
    { "key": "1", "label": "分子の再構成誤差 [-]", "type": "number", "format": sci3 },
    { "key": "2", "label": "数値ランク", "type": "integer" },
    { "key": "3", "label": "逆条件数 [-]", "type": "number", "format": sci3, "nullText": "なし" },
    { "key": "4", "label": "x = 1 の極の絶対感度 [-]", "type": "number", "nullText": pole_label },
    { "key": "5", "label": "作業領域 [バイト]", "type": "integer" }
]);
emit_table_with_columns!(
    report_columns,
    vec![(
        report.factorization_error(),
        report.reconstruction_error(),
        report.rank().rank(),
        report.reciprocal_condition(),
```

既定の $a = 1$ では、係数と作るときの値の差は $1.3 \times 10^{-15}$ 以下で、逆条件数は $2.0 \times 10^{-2}$、作業領域は 736 バイトである。
$x = 1$ は分母の二重根なので、極の絶対感度は `Singular` と示される。
$a = 0$ では、真値が 0 の係数が $-1.0 \times 10^{-15}$ と求まり、ちょうど 0 にはならない。
逆条件数、数値ランク、極の感度は Plan が分母と因子だけから決める量なので、$a$ を変えても変わらない。

### 近い極での係数の誤差と再構成

次のセルは $a = 1$ に固定し、$s = 2^{-k}$（$k = 0, 2, \dots, 24$）で共役な極の対を重複極 $x = 1$ に近づけながら、`decompose` で分解する。
表は各 $k$ の逆条件数、係数と真値の差の最大、計算した係数で作った部分分数の和と $N/D$ の 4 点での相対差の最大、レポートの再構成誤差を示す。
4 点での相対差は計算した係数 $[\hat a, \hat A_2, \hat b_0, \hat b_1]$ で $\hat a/(x-1) + \hat A_2/(x-1)^2 + (\hat b_0 + \hat b_1 x)/F_1$ を `f64` の演算で評価し、SciOxide で評価した $N(x)/D(x)$ と $x = -2, 0, 2, 4$ で比べた値である（独立検算）。
Plan の準備が拒否された $k$ では、エラーの分類だけを示す。
図は同じ量を $s$ に対して対数軸で描き、係数の誤差の目安 $u/\text{逆条件数}$ を破線で添える。

```rust
//| id: poly-partial-fraction-near-poles
//| ref: poly-partial-fraction-near-poles
//| title: 近い極での係数の誤差と関数の再構成
//| run: reactive
//| uses: [poly-partial-fraction-model]
//| crates: [scioxide-core, scioxide-poly]
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"near-poles","path":"/rows/0/2","approx":{"value":0.020202020202020204,"rtol":1e-6}}
//|       - {"artifact":"near-poles","path":"/rows/6/3","range":{"min":1e-10,"max":1e-6}}
//|       - {"artifact":"near-poles","path":"/rows/6/4","range":{"max":1e-13}}
//|       - {"artifact":"near-poles","path":"/rows/10/3","range":{"min":1e-4,"max":1e-1}}
//|       - {"artifact":"near-poles","path":"/rows/10/5","range":{"max":1e-14}}
//|       - {"artifact":"near-poles","path":"/rows/12/6","equals":"NumericalInstability"}
use scioxide_core::RealScalar;
use scioxide_poly::PolynomialBasis;

let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let unit_roundoff = RealScalar::powi(2.0_f64, -53);
let (mut rows, mut conditions, mut errors) = (Vec::new(), Vec::new(), Vec::new());
let (mut predicted, mut pointwise, mut exact_points) = (Vec::new(), Vec::new(), 0);
for k in (0..=24).step_by(2) {
    let s = RealScalar::powi(2.0_f64, -k);
    let model = PartialFractionModel::new(1.0, s).map_err(|e| e.to_string())?;
    // 因子が数値的に分離できなければ、Plan の準備が拒否される
    let plan = match model.plan() {
        Ok(plan) => plan,
        Err(error) => {
            let kind = format!("{:?}", error.kind());
            rows.push((k, s, None, None, None, None, kind));
            continue;
        }
    };
    let fractions = plan
        .decompose(model.numerator.basis().coefficients())
        .map_err(|e| e.to_string())?;
    let report = fractions.report().ok_or("分解のレポートがない")?;
    // 係数は因子の入力順、冪の昇順に [a, 2, b₀, b₁]（F₁ の項の分子は b₀ + b₁x）
    let c = fractions.residues();
    // 独立検算 1: 作るときに使った値 [1, 2, 3, 4] との差の最大
    let coefficient_error = c
        .iter()
        .zip([1.0, 2.0, 3.0, 4.0])
        .map(|(c, r)| (c - r).abs())
        .fold(0.0, f64::max);
    // 独立検算 2: 計算した係数で部分分数の和を f64 で評価し、SciOxide で評価した N/D と比べる
    let mut difference = 0.0_f64;
    for x in [-2.0_f64, 0.0, 2.0, 4.0] {
        let n = model.numerator.evaluate(x).map_err(|e| e.to_string())?;
        let d = model.denominator.evaluate(x).map_err(|e| e.to_string())?;
        let t = x - 1.0;
        let sum = c[0] / t + c[1] / (t * t) + (c[2] + c[3] * x) / (t * t + s * s);
        difference = difference.max(((sum - n / d) / (n / d)).abs());
    }
    let rcond = report.reciprocal_condition().ok_or("逆条件数がない")?;
    conditions.push([s, rcond]);
    errors.push([s, coefficient_error]);
    predicted.push([s, unit_roundoff / rcond]);
    // 対数軸なので、差が 0 の点は図から除いて数える
    if difference > 0.0 {
        pointwise.push([s, difference]);
    } else {
        exact_points += 1;
    }
    rows.push((
        k,
        s,
        Some(rcond),
        Some(coefficient_error),
        Some(difference),
        Some(report.reconstruction_error()),
        "値を返す".to_string(),
    ));
}
let columns = serde_json::json!([
    { "key": "0", "label": "k [-]", "type": "integer" },
    { "key": "1", "label": "極の対の距離 s [-]", "type": "number", "format": sci3 },
    { "key": "2", "label": "逆条件数 [-]", "type": "number", "format": sci3, "nullText": "-" },
    { "key": "3", "label": "係数の差の最大 [-]", "type": "number", "format": sci3, "nullText": "-" },
    { "key": "4", "label": "4 点での相対差 [-]", "type": "number", "format": sci3, "nullText": "-" },
    { "key": "5", "label": "再構成誤差 [-]", "type": "number", "format": sci3, "nullText": "-" },
    { "key": "6", "label": "結果" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "near-poles" })
);
let pointwise_name = format!("4 点での相対差の最大（0 の {exact_points} 点を除く）");
let series = vec![
    serde_json::json!({ "name": "逆条件数", "points": conditions }),
    serde_json::json!({ "name": "係数の差の最大", "points": errors }),
    serde_json::json!({ "name": pointwise_name, "points": pointwise }),
    serde_json::json!({
        "name": "u/逆条件数",
        "points": predicted,
        "style": { "lineType": "dashed" }
    }),
];
emit_line_chart!(
    &series,
    options = &serde_json::json!({
        "xLabel": "極の対の距離 s [-]",
        "yLabel": "大きさ [-]",
        "xType": "log",
        "yType": "log"
    })
);
```

逆条件数は $s^2$ に比例して下がり、$k = 8, 12, 16, 20$ でそれぞれ $3.3 \times 10^{-7}$、$1.3 \times 10^{-9}$、$5.0 \times 10^{-12}$、$1.9 \times 10^{-14}$ になる。
係数の差の最大は破線の $u/\text{逆条件数}$ とほぼ同じ大きさで増え、同じ $k$ でそれぞれ $1.2 \times 10^{-10}$、$8.7 \times 10^{-8}$、$1.1 \times 10^{-5}$、$6.4 \times 10^{-3}$ になる。
それでも 4 点での相対差は $10^{-15}$ 程度、再構成誤差は $10^{-16}$ 程度にとどまる。
個々の係数の誤差が、互いに打ち消し合う向きにそろうからである。
係数の誤差を $\delta a, \delta A_2, \delta b_0, \delta b_1$ とすると、和の誤差は

$$
\frac{\delta a}{x - 1} + \frac{\delta A_2}{(x - 1)^2} + \frac{\delta b_0 + \delta b_1 x}{F_1}
= \frac{(x - 1)^2 \big((\delta a + \delta b_1) x + \delta A_2 + \delta b_0 - \delta a\big) + s^2 \big(\delta a (x - 1) + \delta A_2\big)}{D(x)}
$$

である。
$\delta b_1 = -\delta a$、$\delta b_0 = \delta a - \delta A_2$ なら第 1 項が消え、残る第 2 項は $s^2$ 倍なので、$u/s^2$ 程度の係数の誤差でも和の誤差は $u$ 程度になる。
$k = 12$ の係数の誤差（$\delta a = -8.7 \times 10^{-8}$、$\delta A_2 = -5.9 \times 10^{-8}$、$\delta b_0 = -2.8 \times 10^{-8}$、$\delta b_1 = 8.7 \times 10^{-8}$）はこの関係を満たしている。
$k = 24$ では数値ランクが落ち、Plan の準備が `NumericalInstability`（`IllConditioned`）で拒否される。
係数の大きさや誤差と、再構成誤差は別の診断である。
重複極を既知の因子として与えることと、浮動小数点の係数から重複度を自動で判定することも区別する（後者は提供しない）。

## まとめ

部分分数分解は分母の因子と重複度を呼び出し側が与え、Plan が因子の積と分母の一致、互いに素であることを確かめてから行う。
近似版ではレポートの逆条件数と再構成誤差を別々に読み、近い極で個々の係数の誤差が単位丸めを逆条件数で割った程度まで増えても、項の和が関数を作り直しているかを再構成誤差で確かめる。
同じ分母で分子だけが変わるときは、要件から作業領域と出力を確保し、`decompose_into` を確保なしで繰り返す。
再利用した結果は `decompose` とビット単位では比べず、解析的な値か再構成誤差で確かめる。
係数が有理数のように厳密に表せるなら、[厳密な部分分数分解](../exact-partial-fractions/)で丸めのない分解ができる。
重複度を浮動小数点の係数から自動で判定する機能は提供しない。
