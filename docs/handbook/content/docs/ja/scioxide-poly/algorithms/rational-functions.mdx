有理関数 $r(x) = p(x)/q(x)$ は、多項式では表しにくい極や漸近線を持つ関数を表し、Padé 近似、伝達関数、飽和のモデルに現れる。
浮動小数点の係数では、極の近くで分母の値がどこまで信頼できるかと、分子と分母の近い因子を約すかどうかの判定が結果を左右する。
このページでは SciOxide の有理関数の正規形と演算、極に近い点での評価の判定、導関数の作り方、近似的な約分、厳密な係数の有理関数を扱う。
約分で使う近似 GCD は[最大公約多項式と近似 GCD](../approximate-gcd/)、分母の因子を与えた分解は[部分分数分解](../partial-fractions/)で扱う。
記号 $\varepsilon$ は機械イプシロン（`f64` で $2^{-52}$）を表し、多項式の係数は昇べき順に並べる。

## 有理関数の正規形と極

有理関数 $r(x) = p(x)/q(x)$ は、分子 $p$（次数 $m$）と 0 でない分母 $q$（次数 $n$）の比である。
$p$ の根が零点、$p$ と共通でない $q$ の根が極である。
$m \ge n$ の仮分数は除算 $p = sq + r_{\text{rem}}$ によって多項式部 $s$ と真分数 $r_{\text{rem}}/q$（$\deg r_{\text{rem}} < n$）に一意に分けられる。

### 正規形と演算

`ApproxRationalFunction::new(numerator, denominator)` は、分母をモニック（最高次の係数が 1）にし、分子を同じ最高次の係数で割った正規形を作る（割り算は拡張指数の演算で行い、係数ごとに一度だけ丸める）。
分子が 0 なら $0/1$ で表す。
共通因子は約さず、約分は後で述べる `simplify` で明示的に行う。
分母が 0 なら `InvalidInput`（`OutOfRange`）、分子と分母の方針が異なれば `InvalidInput`（`Inconsistent`）になる。

`try_add`、`try_sub`、`try_mul`、`try_div`、`reciprocal` は、たとえば $a/b + c/d = (ad + cb)/(bd)$ のように積で新しい分子と分母を作り、共通因子を約さない。
零の関数で割る `try_div` と零の関数の `reciprocal` は、分母が 0 になるので `InvalidInput`（`OutOfRange`）を返す。
演算を重ねると次数が増え、共通因子が近似的にしか消えない形が残るので、必要なら最後に `simplify` の診断を読んで約す。
`numerator()` と `denominator()` は正規形の分子と分母を借用する。

### 極に近い点での評価

`evaluate(x)` は分子と分母をそれぞれ Horner 法で評価し、有理関数の値を返す。
`evaluate_parts(x)` は値に加えて分子と分母の評価を持つ `ApproximateRationalEvaluation` を返し、極の判定は `evaluate` と同じである。
`value()` が有理関数の値、`numerator()` と `denominator()` がそれぞれの値・導関数・条件のレポートを持つ `PolynomialEvaluation` である。
分母の計算値が 0 か、分母の相対前進誤差の推定 $\gamma_N \max(1, \kappa_q(x))$ が 1 以上なら、$x$ を極とみなして `DomainError`（`OutsideDomain`）を返す。
ここで $\gamma_N = N\varepsilon/(1 - N\varepsilon)$、$N$ は分母の係数の数、$\kappa_q(x) = \sum_k |q_k||x|^k / |q(x)|$ は分母の評価の条件数である（[Horner 法の丸め誤差](../horner-rounding-error/)）。
推定が 1 以上ということは、分母の値がその誤差の見積もりより小さく、符号も大きさも決まらないことを意味する。
単純な極 $a$ の近くでは $|q(x)| \approx |q'(a)||x - a|$ なので、この判定に入る区間の幅はおよそ $\gamma_N \sum_k |q_k||a|^k / |q'(a)|$ である。
分母の値が小さくても正確に計算できていれば、係数の許容誤差に関係なく値を返す。
商は拡張指数の演算で割ってから一度だけ丸めるので、途中で桁あふれやアンダーフローは起こらず、丸めた商が `f64` で表せないときだけ `NumericalInstability`（`Overflow`）になる。
非有限の点は `NonFinite` で拒否する。

以下のセルは飽和のモデル $v(c)/V_{\max} = c/(K + c)$（$c$ は基質の濃度、$K$ は半飽和定数、どちらも mmol/L）と、その逆数 $(K + c)/c$ を使う。
前者の極 $c = -K$ では分母 $K + c$ が打ち消しで小さくなり、後者の極 $c = 0$ では分母 $c$ が打ち消しなしで小さくなる。
定義のブロックの `saturation(k)` がモデルの有理関数を作り、`denominator_estimate(f, c)` が点 $c$ での分母の相対前進誤差の推定を返す。
推定は有理関数の評価が拒否する点でも分母の評価から読め、分母が厳密に 0 の点では無限大なので `None` を返す。

```rust
//| id: poly-rational-pole-model
//| kind: definitions
//| title: 飽和モデル c/(K + c) と分母の誤差の推定
//| crates: [scioxide-core, scioxide-poly]
use scioxide_core::SciOxideError;
use scioxide_poly::{ApproxPolynomial, ApproxRationalFunction};

/// 飽和のモデル v/Vmax = c/(K + c)。分子 [0, 1]、分母 [K, 1]（昇べき順）。c と K の単位は mmol/L
pub(crate) fn saturation(k: f64) -> Result<ApproxRationalFunction<f64>, SciOxideError> {
    let numerator = ApproxPolynomial::monomial(vec![0.0_f64, 1.0])?;
    let denominator = ApproxPolynomial::monomial(vec![k, 1.0])?;
    ApproxRationalFunction::new(numerator, denominator)
}

/// 点 c での分母の相対前進誤差の推定 γ_N max(1, κ_q(c))。
/// 有理関数の評価が拒否する点でも、分母の評価から読める。分母が厳密に 0 なら推定は無限大なので None を返す
pub(crate) fn denominator_estimate(
    f: &ApproxRationalFunction<f64>,
    c: f64,
) -> Result<Option<f64>, SciOxideError> {
    let estimate = f
        .denominator()
        .evaluate_with_derivative(c)?
        .condition()
        .forward_error_estimate();
    Ok(Some(estimate).filter(|x| x.is_finite()))
}
```

次のセルは極までの相対距離 $h = 2^{-j}$ を選び、$c = -K(1 - h)$ で $v$ を、$c = K h$ で $1/v$ を `evaluate_parts` で評価する。
入力は半飽和定数 $K$ と $j$ で、表は評価点、分母の相対前進誤差の推定、値、閉形式との相対差、評価の結果を示す。
独立検算には閉形式 $v = 1 - 1/h$ と $1/v = 1 + 1/h$ を使う。
$K$ が整数なら $c$ は丸めなしで表せ、それ以外では $c$ の丸めが分母に入る。

```rust
//| id: poly-rational-saturation-scale
//| ref: poly-rational-saturation-scale
//| title: 飽和モデルを極に近づけて評価する
//| run: reactive
//| uses: [poly-rational-pole-model]
//| crates: [scioxide-core, scioxide-poly]
//| inputs:
//|   half_saturation: {"type":"range","label":"半飽和定数 K [mmol/L]","description":"整数なら極の近くの点が 2 進で正確に表せる。","min":0.2,"max":5,"step":0.2,"value":1}
//|   distance_power: {"type":"range","label":"極までの相対距離 h=2⁻ʲ の j","description":"評価点 c = −K(1 − h) と c = Kh を選ぶ。","min":2,"max":60,"step":2,"value":40}
//| cases:
//|   - {"id":"inexact-constant","label":"K = 0.2 mmol/L","description":"c の丸めが K + c に入り、閉形式との相対差が現れる。","inputs":{"half_saturation":0.2}}
//|   - {"id":"at-pole","label":"j = 52","description":"推定が 1 を超え、極とみなされて DomainError になる。","inputs":{"distance_power":52}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"evaluations","path":"/rows/0/6","equals":"値を返す"}
//|       - {"artifact":"evaluations","path":"/rows/0/5","range":{"max":1e-15}}
//|       - {"artifact":"evaluations","path":"/rows/0/2","approx":{"value":1.0e-3,"rtol":0.1}}
//|       - {"artifact":"evaluations","path":"/rows/1/2","approx":{"value":4.440892098500626e-16,"rtol":1e-6}}
//|   - case: inexact-constant
//|     expect:
//|       - {"artifact":"evaluations","path":"/rows/0/5","range":{"min":1e-6,"max":1e-3}}
//|   - case: at-pole
//|     expect:
//|       - {"artifact":"evaluations","path":"/rows/0/6","equals":"DomainError（OutsideDomain）"}
//|       - {"artifact":"evaluations","path":"/rows/1/6","equals":"値を返す"}
use scioxide_core::{SciOxideErrorKind, RealScalar};

let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let (sig12, sig17) = (
    serde_json::json!({ "significantDigits": 12 }),
    serde_json::json!({ "significantDigits": 17 }),
);
let k = half_saturation;
let model = saturation(k).map_err(|e| e.to_string())?;
// 逆数 (K + c)/c の極は c = 0 で、分母の評価に打ち消しがない
let inverse = model.reciprocal().map_err(|e| e.to_string())?;
let h = RealScalar::powi(2.0_f64, -(distance_power as i32));
let mut rows = Vec::new();
// 独立検算: 閉形式 v = 1 − 1/h と 1/v = 1 + 1/h（f64 の演算）
for (name, f, c, exact) in [
    ("v(c)、c = −K(1 − h)", &model, -k * (1.0 - h), 1.0 - 1.0 / h),
    ("1/v(c)、c = Kh", &inverse, k * h, 1.0 + 1.0 / h),
] {
    let (value, outcome) = match f.evaluate_parts(c) {
        Ok(e) => (Some(e.value()), "値を返す".to_string()),
        Err(error) if error.kind() == SciOxideErrorKind::DomainError => {
            (None, "DomainError（OutsideDomain）".to_string())
        }
        Err(error) => return Err(error.to_string()),
    };
    let difference = value.map(|v| ((v - exact) / exact).abs());
    let estimate = denominator_estimate(f, c).map_err(|e| e.to_string())?;
    rows.push((name, c, estimate, value, exact, difference, outcome));
}
let columns = serde_json::json!([
    { "key": "0", "label": "評価する関数と点" },
    { "key": "1", "label": "評価点 c [mmol/L]", "type": "number", "format": sig17 },
    { "key": "2", "label": "分母の相対誤差の推定 [-]", "type": "number", "format": sci3, "nullText": "∞" },
    { "key": "3", "label": "値 [-]", "type": "number", "format": sig12, "nullText": "なし" },
    { "key": "4", "label": "閉形式 [-]", "type": "number", "format": sig12 },
    { "key": "5", "label": "閉形式との相対差 [-]", "type": "number", "format": sci3, "nullText": "なし" },
    { "key": "6", "label": "評価の結果" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "evaluations" })
);
```

$c = -K(1 - h)$ では分母の条件数がおよそ $2/h$ になり、相対前進誤差の推定は $\gamma_2 \cdot 2/h \approx 8.9 \times 10^{-16}/h$ である。
既定値（$K = 1$、$h = 2^{-40}$）の推定は $9.8 \times 10^{-4}$ で、値を返し、閉形式との相対差は 0 である。
$j = 52$ では推定が 4.0 になり、`evaluate_parts` は `DomainError` を返す。
逆数の極 $c = 0$ に近づく $1/v(Kh)$ では、分母 $c$ の評価に打ち消しがないので、推定は $\gamma_2 = 4.4 \times 10^{-16}$ のまま変わらず、値 $1 + 1/h$ を返す。
$K = 0.2$ のように 2 進で表せない値では、$c$ の丸めが $K + c$ に入り、$h = 2^{-40}$ での閉形式との相対差は $6.1 \times 10^{-5}$ になる。

次のセルは $j = 2, 4, \dots, 60$ の 30 点で同じ推定を求め、$h$ に対して対数軸で描く。
$c = -K(1 - h)$ では `evaluate` の値も閉形式と比べる。
表は `evaluate` が最初に `DomainError` を返した $j$、分母が厳密に 0 になった点の数、閉形式との相対差が 0 の点の数（どちらも図から除く）と、相対差の最大を示す。
入力は半飽和定数 $K$ だけである。

```rust
//| id: poly-rational-pole-sweep
//| ref: poly-rational-pole-sweep
//| title: 極までの距離と分母の誤差の推定
//| run: reactive
//| uses: [poly-rational-pole-model]
//| crates: [scioxide-core, scioxide-poly]
//| inputs:
//|   half_saturation: {"type":"range","label":"半飽和定数 K [mmol/L]","description":"整数なら評価できる点で閉形式との差が 0 になる。","min":0.2,"max":5,"step":0.2,"value":1}
//| cases:
//|   - {"id":"inexact-constant","label":"K = 0.2 mmol/L","description":"c の丸めのため、閉形式との相対差が 1/h に比例して増える。","inputs":{"half_saturation":0.2}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"sweep","path":"/rows/0/0","equals":50}
//|       - {"artifact":"sweep","path":"/rows/0/1","equals":4}
//|       - {"artifact":"sweep","path":"/rows/0/2","equals":24}
//|   - case: inexact-constant
//|     expect:
//|       - {"artifact":"sweep","path":"/rows/0/0","equals":50}
//|       - {"artifact":"sweep","path":"/rows/0/3","range":{"min":1e-3,"max":0.1}}
use scioxide_core::{SciOxideErrorKind, RealScalar};

let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let model = saturation(half_saturation).map_err(|e| e.to_string())?;
let inverse = model.reciprocal().map_err(|e| e.to_string())?;
// 対数軸なので、推定が無限大の点（分母が 0）と相対差が 0 の点は図から除いて数える
let (mut cancelling, mut plain, mut observed) = (Vec::new(), Vec::new(), Vec::new());
let (mut zero_denominator, mut exact_values, mut first_pole) = (0, 0, None);
for j in (2..=60).step_by(2) {
    let h = RealScalar::powi(2.0_f64, -j);
    let c = -half_saturation * (1.0 - h);
    match denominator_estimate(&model, c).map_err(|e| e.to_string())? {
        Some(value) => cancelling.push([h, value]),
        None => zero_denominator += 1,
    }
    let plain_estimate = denominator_estimate(&inverse, half_saturation * h);
    if let Some(value) = plain_estimate.map_err(|e| e.to_string())? {
        plain.push([h, value]);
    }
    // 独立検算: 評価できた点で閉形式 1 − 1/h と比べる。最初に拒否された j を記録する
    match model.evaluate(c) {
        Ok(value) => {
            let difference = ((value - (1.0 - 1.0 / h)) / (1.0 - 1.0 / h)).abs();
            if difference > 0.0 {
                observed.push([h, difference]);
            } else {
                exact_values += 1;
            }
        }
        Err(error) if error.kind() == SciOxideErrorKind::DomainError => {
            first_pole = first_pole.or(Some(j));
        }
        Err(error) => return Err(error.to_string()),
    }
}
let largest = observed.iter().map(|point| point[1]).reduce(f64::max);
let columns = serde_json::json!([
    { "key": "0", "label": "最初に拒否された j [-]", "type": "integer", "nullText": "なし" },
    { "key": "1", "label": "分母が 0 の点 [個]", "type": "integer" },
    { "key": "2", "label": "閉形式との差が 0 の点 [個]", "type": "integer" },
    { "key": "3", "label": "相対差の最大 [-]", "type": "number", "format": sci3, "nullText": "0" }
]);
emit_table_with_columns!(
    columns,
    vec![(first_pole, zero_denominator, exact_values, largest)],
    metadata = serde_json::json!({ "id": "sweep" })
);
emit_line_chart!(
    &vec![
        serde_json::json!({
            "name": "推定: K + c（極 c = −K）",
            "points": cancelling,
            "style": { "lineType": "dashed" }
        }),
        serde_json::json!({
            "name": "推定: c（極 c = 0）",
            "points": plain,
            "style": { "lineType": "dotted" }
        }),
        serde_json::json!({
            "name": "閉形式 1 − 1/h との相対差",
            "points": observed,
            "style": { "symbol": "circle", "showSymbol": true }
        })
    ],
    options = &serde_json::json!({
        "xLabel": "極までの相対距離 h [-]",
        "yLabel": "相対誤差 [-]",
        "xType": "log",
        "yType": "log",
        "annotations": [{ "kind": "line", "axis": "y", "value": 1.0, "label": "極と判定する境界" }]
    })
);
```

破線の推定は $h$ に反比例して増え、$h = 2^{-50}$ で 1 に達するので、$j \ge 50$ では `evaluate` は `DomainError` を返す。
$h \le 2^{-54}$ では $c$ が $-K$ に丸められて分母が厳密に 0 になり、推定は無限大になる（入力の範囲のどの $K$ でも $j = 54, \dots, 60$ の 4 点で、図から除く）。
点線の推定は逆数の分母 $c$ に打ち消しがないので $h$ によらず $\gamma_2$ のままで、$h = 2^{-60}$ でも値を返す。
極の判定は分母の値の大きさそのものではなく、分母の値とその誤差の見積もりの比で決まる。

$K = 1$ のような整数では $c$ も $K + c$ も丸めなしで表せるので、評価できる 24 点すべてで閉形式との相対差は 0（図から除く）である。
$K = 0.2$ では閉形式との相対差が推定より 1 桁ほど小さい大きさで $1/h$ に比例して増え、最大は $j = 48$ の点の $1.5 \times 10^{-2}$ である。
推定は係数と点にこの程度の丸めがあると分母の値がどれだけ動くかの見積もりであり、実際の誤差がそれより小さくても判定は推定で行う。

### 分子と分母の導関数

有理関数の導関数を返す関数は提供しない。
`evaluate_parts` の分子と分母の評価はそれぞれ導関数を持つので、商の微分

$$
r'(x) = \frac{p'(x)\, q(x) - p(x)\, q'(x)}{q(x)^2}
$$

で作る。
極から離れた点では分子と分母の値と導関数がどれも相対誤差 $O(\varepsilon)$ で求まり、この式の丸めも数回の演算の分だけなので、$r'$ の相対誤差も $O(\varepsilon)$ にとどまる。
極に近づくと $q^2$ が小さくなり、分子の打ち消しも起こりうるので、極の判定を通った点でも $r'$ の精度は別に確かめる。

次のセルは飽和のモデルの導関数を $c/K = 0, 1/2, 1, 4$ の 4 点で求め、閉形式 $K/(K + c)^2$ と比べる（独立検算）。
$c = 0$ の値は原点の傾き $1/K$ である。

```rust
//| id: poly-rational-quotient-derivative
//| ref: poly-rational-quotient-derivative
//| title: 分子と分母の導関数から作る有理関数の導関数
//| run: reactive
//| uses: [poly-rational-pole-model]
//| crates: [scioxide-core, scioxide-poly]
//| inputs:
//|   half_saturation: {"type":"range","label":"半飽和定数 K [mmol/L]","description":"導関数の閉形式は K/(K + c)² である。","min":0.2,"max":5,"step":0.2,"value":1}
//| cases:
//|   - {"id":"inexact-constant","label":"K = 0.2 mmol/L","description":"2 進で表せない K でも、導関数は丸めの程度で閉形式に一致する。","inputs":{"half_saturation":0.2}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"derivative","path":"/rows/0/1","approx":{"value":1,"rtol":1e-15}}
//|       - {"artifact":"derivative","path":"/rows/3/3","range":{"max":1e-15}}
//|   - case: inexact-constant
//|     expect:
//|       - {"artifact":"derivative","path":"/rows/0/1","approx":{"value":5,"rtol":1e-15}}
//|       - {"artifact":"derivative","path":"/rows/2/3","range":{"max":1e-15}}
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let sig15 = serde_json::json!({ "significantDigits": 15 });
let k = half_saturation;
let model = saturation(k).map_err(|e| e.to_string())?;
let mut rows = Vec::new();
// c/K = 0、1/2、1、4 の点。c = 0 での値は原点の傾き 1/K
for ratio in [0.0_f64, 0.5, 1.0, 4.0] {
    let c = ratio * k;
    let parts = model.evaluate_parts(c).map_err(|e| e.to_string())?;
    let (p, q) = (parts.numerator(), parts.denominator());
    // 商の微分 r′ = (p′q − pq′)/q²
    let derivative =
        (p.derivative() * q.value() - p.value() * q.derivative()) / (q.value() * q.value());
    // 独立検算: d/dc [c/(K + c)] = K/(K + c)²（f64 の演算）
    let exact = k / ((k + c) * (k + c));
    rows.push((c, derivative, exact, ((derivative - exact) / exact).abs()));
}
let columns = serde_json::json!([
    { "key": "0", "label": "点 c [mmol/L]", "type": "number", "format": sig15 },
    { "key": "1", "label": "商の微分 r′(c) [L/mmol]", "type": "number", "format": sig15 },
    { "key": "2", "label": "閉形式 K/(K + c)² [L/mmol]", "type": "number", "format": sig15 },
    { "key": "3", "label": "相対差 [-]", "type": "number", "format": sci3 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "derivative" })
);
```

既定値 $K = 1$ では、4 点すべてで閉形式との相対差が 0 で、$c = 0$ の値は原点の傾き $1/K = 1$ に一致する。
$K = 0.2$ でも相対差は $2.8 \times 10^{-16}$ 以下で、$K$ と $c$ の丸めを含めて $\varepsilon$ の程度にとどまる。

### 近似的な約分

`ApproxRationalFunction::simplify()` は、分子と分母に `approximate_gcd` を適用し、各剰余が方針の許容誤差を満たすときだけ、保持した余因子から新しい有理関数を作る。
除算を繰り返さず、GCD の計算で割ったときの余因子をそのまま使う。
許容誤差の判定は各剰余の係数の最大絶対値が $\tau_{\text{abs}} + \tau_{\text{rel}} \max_i |\text{入力}_i|$ 以下であることである（[GCD と簡約のレポート](oxref:poly-gcd-simplification-report)）。
どちらかの剰余が許容誤差を超えると `NumericalInstability`（`IllConditioned`）を返し、部分的な結果は返さない。
成功すると `ApproximateRationalSimplification` が、約分した有理関数 `rational()`、根拠になった `gcd_report()`、元の分子と分母の尺度での正規化剰余 `numerator_error()` と `denominator_error()` を返す。
GCD の次数が 0 なら、式は正規形のまま変わらない。

因子が近似的にしか共通でないとき、約分した式は元の関数と異なる。
共通因子の次数はランク閾値が、約分を受け入れるかどうかは許容誤差が決めるので、二つは方針の別の部品として選ぶ。
約分の前後で関数の値がどれだけ変わり、零点のようなモデルの性質が保たれるかは、[有理飽和の例題](../../examples/rational-saturation/)で確かめられる。

## 厳密な係数の有理関数

厳密な係数（`ExactField`）では、`ExactRationalFunction::new` が厳密な GCD で約した既約な形（分母はモニック）を作り、和・差・積・商のたびに約分する。
既約な形は一意なので、等しい有理関数は `==` で等しくなる。
`reciprocal` は既約な分子と分母を入れ替えるだけなので GCD を計算せず、零の関数では `InvalidInput`（`OutOfRange`）を返す。
`ExactRationalFunction::evaluate` は、分母が厳密に 0 になる点を `InvalidInput`（`OutOfRange`）で拒否する。
係数型の除算が $(a/b) \cdot b = a$ を満たさなければ `NumericalInstability`（`Breakdown`）になる。

## まとめ

`ApproxRationalFunction` は分母をモニックにした正規形を保ち、演算では共通因子を約さないので、約分は `simplify` で明示的に行う。
極の判定は分母の値の大きさではなく相対前進誤差の推定 $\gamma_N \max(1, \kappa_q)$ が 1 に達するかで決まり、打ち消しのない分母は 0 のすぐ近くまで評価できる。
`DomainError` を受けた点は極とみなし、推定の値は分母の評価の `condition()` で読む。
導関数は `evaluate_parts` の分子と分母の導関数から商の微分で作り、極の近くでは精度を別に確かめる。
厳密な係数では `ExactRationalFunction` が演算のたびに既約な形へ約し、分母が厳密に 0 になる点だけを拒否する。
