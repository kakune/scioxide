曲面や多変数の多項式を軸ごとの Bernstein 基底の積で表すと、制御点の最小と最大から値域を推定できる。
制御点の配列だけでは意味が決まらず、軸の順序、各軸の区間、出力の成分の並びを指定する必要がある。
このページはテンソル積の制御網の保存順と評価、凸包性による範囲の推定が何を保証するか、分割で範囲がどの速さで縮むかを説明する。
一変数の Bernstein 基底、de Casteljau 法とその丸め誤差は[Bernstein 表現と de Casteljau 法](../multivariate-and-bernstein/)で扱う。

## テンソル積の制御網

`TensorBernstein` は、軸ごとの Bernstein 基底の積

$$
p(t_0,\ldots,t_{d-1})=\sum_{i_0,\ldots,i_{d-1}}b_{i_0\cdots i_{d-1}}\prod_jB_{i_j}^{n_j}(t_j)
$$

で曲面などを表す。
次数が $(n_0,\ldots,n_{d-1})$ なら制御点は $N=\prod_j(n_j+1)$ 個で、各制御点が出力の成分を持つ。
保存は最後の軸が最も速く変わる行優先で、各制御点の出力成分を続けて並べる。
二軸・三成分なら、$(i,j)$ の三成分を並べてから $j$ を進め、$j$ を一巡したら $i$ を進める。
成分が一つなら多変数の多項式、実数の成分が複数なら Bézier 曲線や曲面、軸が 0 個なら一点を表す。

`TensorBernstein::new(degrees, domains, components, coefficients)` は、成分の個数 0、軸と区間の個数の違い、$\mathrm{lower}\ge\mathrm{upper}$ の区間、制御点の個数の不一致を `InvalidInput`、非有限の制御点を `NonFinite` として拒否する。
`TensorBernstein::with_options` は同じ検査に加えて、一括評価の実行設定 `PolynomialExecutionOptions` を受け取り、ワーカーの上限が 64 を超えれば `InvalidInput` を返す。
評価は最後の軸から一軸ずつ de Casteljau 法で縮約する。
最後の軸の縮約は $N/(n_{d-1}+1)$ 本の列それぞれに $O(n_{d-1}^2)$ の演算を使うので、一点の一成分あたり全体で $O(N\max_j(n_j+1))$ の演算になる。
丸め誤差は軸ごとの誤差が積み重なり、実数の箱の上で $\gamma_{3\sum_jn_j}\max|b|$ 以下である（$\gamma_k=ku/(1-ku)$、$u$ は単位丸め。
一変数の評価は[丸め誤差と条件数](oxref:poly-bernstein-rounding-condition)を参照）。

`evaluate(point)` は出力と一時領域を確保して、一点の全成分をベクトルで返す。
`as_view()` は制御網を借用する `TensorBernsteinView` を返し、係数を複製せず、キャッシュも持たない。
`TensorBernsteinView::new(extents, domains, components, coefficients, options)` は呼び出し側の配列を借用し、次数ではなく軸ごとの制御点の個数（次数 + 1）を `extents` で受け取って、零の個数を含めて同じ検査をする。
`evaluate_into(point, output, scratch, context)` には、点・出力・呼び出し側が渡す一時領域・実行コンテキストを渡す。
一時領域の長さは `workspace_requirements(1).scratch_len()` で問い合わせ、既定の逐次の実行設定では成分の個数 $k$ と制御点の個数 $N$ の和である。
並列の実行設定ではワーカーごとに $N$ 個ずつ増える。
実数・複素数の媒介変数と区間の外への外挿を受け付け、形が合わないときや一時領域が短いときは `DimensionMismatch` を返し、失敗しても出力を変えない。
`evaluate_batch_into` は `[点, 軸]` の形の点を評価し、各点の $k$ 成分を順に書く。
`derivative(axis)`、`elevate_degree(axis, degree)`、`subdivide(axis, point)` は一つの軸に沿って作用し、範囲外の軸を `InvalidInput` とする。

## 凸包性と分割による範囲の縮小

実数の制御網では、`control_bounds()` が `BernsteinBounds` を返し、`coordinates()` が成分ごとの制御点の最小と最大の区間を与える。
一変数の実数の Bernstein 表現も同じ `control_bounds()` を持つ。
この区間が何を保証するかは、厳密な算術と浮動小数点で分けて考える。

- 厳密な算術では、実数の媒介変数の箱の上で、各成分の値はこの区間に入る。
  `control_bounds()` は保存した制御点の最小と最大を丸めなしに取り出すので、保存した制御点が定める多項式そのものについては、この包含は厳密に成り立つ。
- 保存した制御点は構築・基底の変換・分割・次数上げの丸めを受けた値である。
  分割した小片の制御点は親の制御点から丸めて計算され、分割点の正規化 $t=(x-a)/(b-a)$ も丸めるので、小片の区間の和集合は親の多項式の値域を丸めの分だけ含まないことがある。
- 浮動小数点で評価した値 $\hat p$ は、評価の丸め誤差（実数の箱の上で $\gamma_{3\sum_jn_j}\max|b|$ 以下）の分だけ区間からはみ出しうる。
- したがって `BernsteinBounds` は外向き丸めによる包含が保証された区間ではなく、丸めの分だけずれうる推定である。
  証明付きの範囲が要るときは scioxide-validated の区間演算を使う。

制御点の範囲は値域より広いことが多いが、分割すると値域に近づく。
二次式 $(u-c)^2$ を幅 $h$ の区間 $[c+e,c+e+h]$ で表すと、局所変数 $s\in[0,1]$ で $(e+hs)^2=e^2+2ehs+h^2s^2$ なので、制御点は $e^2$、$e^2+eh$、$(e+h)^2$ である。
両端の制御点は両端の値に等しく、中央の制御点は区間の中点での値 $(e+h/2)^2$ より $h^2/4$ だけ小さい。
したがって制御点の範囲は、下にだけ最大 $h^2/4$ はみ出す。
$z(u,v)=(u-c_u)^2+\kappa(v-c_v)^2$ の制御網は二つの軸の制御点の和 $f_i+\kappa g_j$ なので、$[0,1]^2$ を $k\times k$ に等分すると、制御点の範囲の和集合が値域からはみ出す量は $(1+|\kappa|)/(4k^2)$ 以下になる。
一般の次数でも、分割した制御多角形は $O(h^2)$ の速さで多項式に近づく（G. Farin, *Curves and Surfaces for CAGD*, 5th ed., Morgan Kaufmann, 2002）。

次のセルは無次元の曲面 $z(u,v)=(u-a)^2+\kappa(v-0.6)^2$ を $[0,1]^2$ の双二次の制御網で表す。
操作入力は $u$ 方向の極値の位置 $a$ と、$v$ 方向の係数 $\kappa$ である。
$\kappa<0$ では曲面は鞍点を持つ。
分割数 $k=1,2,4,8,16$ ごとに $k\times k$ の小片に分け、小片の制御点の範囲の和集合を、閉形式の値域 $[\min z,\max z]$ と比べる。
各小片で $5\times5$ の格子点を `TensorBernsteinView::evaluate_into` で評価し、値が小片の制御点の範囲からはみ出す量と、閉形式との差も求める。
有限の格子での確認は凸包性の証明の代わりにはならない。
制御網の構築と等分割は次の定義のブロックに置く。
`surface(center, kappa)` は各軸の制御点を `to_bernstein` で求めて制御網を作り、`split_uniform(patch, k)` は `subdivide` を軸ごとに $k-1$ 回呼んで $k^2$ 個の小片を返す。

```rust
//| id: poly-bernstein-surface-model
//| kind: definitions
//| title: 双二次の制御網と等分割
//| crates: [scioxide-core, scioxide-poly]
use scioxide_core::Interval;
use scioxide_poly::{ApproxPolynomial, PolynomialBasis, TensorBernstein};

/// v 方向の極値の位置 b。
pub(crate) const V_CENTER: f64 = 0.6;

/// (s − c)² = c² − 2c s + s² の [0, 1] での制御点を to_bernstein で求める。
pub(crate) fn quadratic_controls(c: f64) -> Result<Vec<f64>, String> {
    let monomial =
        ApproxPolynomial::monomial(vec![c * c, -2.0 * c, 1.0]).map_err(|e| e.to_string())?;
    let conversion = monomial.to_bernstein(0.0, 1.0).map_err(|e| e.to_string())?;
    Ok(conversion.polynomial().basis().coefficients().to_vec())
}

/// z(u, v) = (u − a)² + κ(v − b)² の [0, 1]² の制御網。行優先（v 軸が速い）に f_i + κ g_j を並べる。
pub(crate) fn surface(center: f64, kappa: f64) -> Result<TensorBernstein<f64>, String> {
    let (f, g) = (quadratic_controls(center)?, quadratic_controls(V_CENTER)?);
    let net: Vec<f64> = f
        .iter()
        .flat_map(|&fi| g.iter().map(move |&gj| fi + kappa * gj))
        .collect();
    let unit = Interval::new(0.0_f64, 1.0).map_err(|e| e.to_string())?;
    TensorBernstein::new(&[2, 2], vec![unit; 2], 1, net).map_err(|e| e.to_string())
}

/// 各軸を k 等分した k² 個の小片。分割点 j/k は残りの区間の真に内側にある。
pub(crate) fn split_uniform(
    surface: &TensorBernstein<f64>,
    k: usize,
) -> Result<Vec<TensorBernstein<f64>>, String> {
    let mut patches = vec![surface.clone()];
    for axis in 0..2 {
        let mut next = Vec::new();
        for patch in patches {
            let mut rest = patch;
            for j in 1..k {
                let (left, right) = rest
                    .subdivide(axis, j as f64 / k as f64)
                    .map_err(|e| e.to_string())?;
                next.push(left);
                rest = right;
            }
            next.push(rest);
        }
        patches = next;
    }
    Ok(patches)
}
```

```rust
//| id: poly-bernstein-bounds
//| ref: poly-bernstein-bounds
//| title: 制御点の範囲と分割による縮小
//| run: reactive
//| crates: [scioxide-core, scioxide-poly]
//| uses: [poly-bernstein-surface-model]
//| inputs:
//|   center: {"type":"range","label":"u 方向の極値の位置 a [-]","description":"(u − a)² の最小の位置。端に寄せると最小が角に現れる。","min":0,"max":1,"step":0.05,"value":0.35}
//|   kappa: {"type":"range","label":"v 方向の係数 κ [-]","description":"負にすると v 方向が凹になり、曲面は鞍点を持つ。","min":-2,"max":2,"step":0.5,"value":1}
//| cases:
//|   - {"id":"saddle","label":"κ = −1.5","description":"上側にもはみ出し、はみ出し × k² の上界は (1 + 1.5)/4 = 0.625 になる。","inputs":{"kappa":-1.5}}
//|   - {"id":"corner-extrema","label":"a = 0, κ = 0","description":"最小も最大も角にあるので、分割前から制御点の範囲が値域に一致する。","inputs":{"center":0,"kappa":0}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"bounds","path":"/rows/0/4","approx":{"value":0.4675,"atol":1e-12}}
//|       - {"artifact":"bounds","path":"/rows/4/4","approx":{"value":0.001875,"atol":1e-12}}
//|       - {"artifact":"bounds","path":"/rows/4/5","range":{"max":0.5}}
//|       - {"artifact":"bounds","path":"/rows/4/6","range":{"max":1e-15}}
//|       - {"artifact":"bounds","path":"/rows/4/7","range":{"max":1e-14}}
//|       - {"artifact":"range","path":"/rows/0/1","approx":{"value":0.7825,"atol":1e-12}}
//|   - case: saddle
//|     expect:
//|       - {"artifact":"bounds","path":"/rows/0/3","approx":{"value":0.7825,"atol":1e-12}}
//|       - {"artifact":"bounds","path":"/rows/4/5","range":{"max":0.625}}
//|       - {"artifact":"range","path":"/rows/0/0","approx":{"value":-0.54,"atol":1e-12}}
//|   - case: corner-extrema
//|     expect:
//|       - {"artifact":"bounds","path":"/rows/0/4","range":{"min":-1e-15,"max":1e-15}}
//|       - {"artifact":"bounds","path":"/rows/4/4","range":{"min":-1e-15,"max":1e-15}}
use scioxide_core::ExecutionContext;
use scioxide_poly::{BernsteinBounds, TensorBernsteinView};

let b = V_CENTER;
let net = surface(center, kappa)?;
// 独立検算: 変数分離形なので値域は各軸の二次式の値域の和（閉形式）。
let f_max = (center * center).max((1.0 - center) * (1.0 - center));
let g_max = kappa * (b * b).max((1.0 - b) * (1.0 - b));
let (exact_low, exact_high) = (g_max.min(0.0), f_max + g_max.max(0.0));
let mut rows = Vec::new();
for k in [1_usize, 2, 4, 8, 16] {
    let patches = split_uniform(&net, k)?;
    let (mut low, mut high) = (f64::INFINITY, f64::NEG_INFINITY);
    let (mut overshoot, mut error) = (0.0_f64, 0.0_f64);
    for patch in &patches {
        let bounds: BernsteinBounds<f64> = patch.control_bounds().map_err(|e| e.to_string())?;
        let range = bounds.coordinates()[0];
        low = low.min(range.lower());
        high = high.max(range.upper());
        let view: TensorBernsteinView<'_, f64> = patch.as_view();
        let requirements = view.workspace_requirements(1).map_err(|e| e.to_string())?;
        let mut scratch = vec![0.0; requirements.scratch_len()];
        let mut output = [0.0];
        let (du, dv) = (patch.domains()[0], patch.domains()[1]);
        for i in 0..5 {
            for j in 0..5 {
                let u = du.lower() + (du.upper() - du.lower()) * i as f64 / 4.0;
                let v = dv.lower() + (dv.upper() - dv.lower()) * j as f64 / 4.0;
                view.evaluate_into(
                    &[u, v],
                    &mut output,
                    &mut scratch,
                    ExecutionContext::sequential(),
                )
                .map_err(|e| e.to_string())?;
                let z = output[0];
                overshoot = overshoot.max(range.lower() - z).max(z - range.upper());
                let closed = (u - center) * (u - center) + kappa * (v - b) * (v - b);
                error = error.max((z - closed).abs());
            }
        }
    }
    let excess = (exact_low - low) + (high - exact_high);
    rows.push((
        k,
        patches.len(),
        low,
        high,
        excess,
        excess * (k * k) as f64,
        overshoot,
        error,
    ));
}
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let sig4 = serde_json::json!({ "significantDigits": 4 });
let columns = serde_json::json!([
    { "key": "0", "label": "分割数 k [-]", "type": "integer" },
    { "key": "1", "label": "小片の数 [-]", "type": "integer" },
    { "key": "2", "label": "制御点の最小 [-]", "type": "number", "format": sig4 },
    { "key": "3", "label": "制御点の最大 [-]", "type": "number", "format": sig4 },
    { "key": "4", "label": "値域からのはみ出し [-]", "type": "number", "format": sig4 },
    { "key": "5", "label": "はみ出し × k² [-]", "type": "number", "format": sig4 },
    { "key": "6", "label": "格子値の範囲外れ [-]", "type": "number", "format": sci2 },
    { "key": "7", "label": "閉形式との最大差 [-]", "type": "number", "format": sci2 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "bounds" })
);
let summary_columns = serde_json::json!([
    { "key": "0", "label": "閉形式の最小 [-]", "type": "number", "format": sig4 },
    { "key": "1", "label": "閉形式の最大 [-]", "type": "number", "format": sig4 },
    { "key": "2", "label": "上界 (1 + |κ|)/4 [-]", "type": "number", "format": sig4 }
]);
let summary = vec![(exact_low, exact_high, (1.0 + kappa.abs()) / 4.0)];
emit_table_with_columns!(
    summary_columns,
    summary,
    metadata = serde_json::json!({ "id": "range" })
);
```

既定の入力では、はみ出しは $k=1$ の $0.4675$ から $k=16$ の $0.001875$ まで減り、はみ出し × $k^2$ は 0.32 から 0.48 の間で上界 0.5 を超えない。
$k=1$ の制御点の最小 $-0.4675$ は、二つの軸の中央の制御点 $a^2-a=-0.2275$ と $b^2-b=-0.24$ の和に一致する。
$\kappa>0$ では曲面が凸なので、値域の上端は角の制御点に現れ、上側のはみ出しは 0 である。
$\kappa=-1.5$ では $v$ 方向が凹になり、$\kappa g$ の中央の制御点 $0.36$ が値域の上端 $0.4225$ を押し上げて、上側にも $0.36$ はみ出す。
このとき下側のはみ出し $0.2275$ は $u$ 方向の項だけから来る。
はみ出し × $k^2$ は 0.40 から 0.60 の間で、上界 $(1+1.5)/4=0.625$ を超えない。
$a=0,\kappa=0$ では最小も最大も角にあるので、はみ出しは分割前から 0 である。
試した入力（既定、二つのケース、各入力の両端）では、格子値の範囲外れは 0 で、閉形式との差は $7\times10^{-16}$ 以下だった。
双一次のように各軸で一次の場合は制御点が角の値そのものなので、値域の端は必ず角に現れ、制御点の範囲は値域に一致する。
二次以上ではこの例のように制御点の範囲が値域より広く、分割で狭まる。

## まとめ

テンソル積の曲面は軸の順序と各軸の区間をそろえて制御網を作り、制御点は最後の軸が最も速く変わる順に、各制御点の出力成分を続けて並べる。
評価は最後の軸から de Casteljau 法で縮約し、確保を避けるときは `TensorBernsteinView::evaluate_into` に `workspace_requirements(1)` の長さの一時領域を渡す。
`control_bounds()` の範囲は保存した制御点の多項式については厳密に値域を含むが、構築と分割の丸めを含む推定なので、証明付きの範囲が要るときは scioxide-validated を使う。
二次以上の制御網では範囲が値域より広く、各軸を $k$ 等分すると $O(1/k^2)$ の速さで値域に近づくので、必要な精度から分割数を見積もる。
