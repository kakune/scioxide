この表は浮動小数点の多項式の表現・評価・基底の変換に使う公開項目をまとめる。
`ApproxPolynomial<C, B>` は係数のスカラー型 `C`（実数か複素数）と準備済みの基底 `B` を型で持ち、不変な近似の方針 `PolynomialApproximationPolicy` を保持する。
保存座標（係数・標本値・制御点など、基底ごとに保存する数の列）の意味は基底によって異なる。
単項式の係数と、補間・変換で作る Newton 形式の係数は末尾の厳密な零を除く。
`newton` で与えた Newton 形式の係数、重心形式の標本値、Bernstein の制御点、直交展開の係数は末尾の零も保つ。
一点の評価は一時領域を引数に取らない。
多くの点を確保なしで評価する `evaluate_batch_into` などに渡す一時領域の長さは、`workspace_requirements(m)`（$m$ は点の数）で問い合わせる。

`scioxide_poly::backend` は、scioxide-poly と scioxide-interp などが共有する低水準の関数と型である。
入力のスライスは変更しない。
出力や作業用の配列を受け取る関数の多くは、失敗時に出力を未規定のまま残しうる。
通常の用途には `ApproxPolynomial` の構築関数と評価を使う。

## まとめ

浮動小数点の多項式は `ApproxPolynomial` で作り、基底を型で明示し、基底の変換は `to_*` で明示的に行って `PolynomialConversion` の診断を読む。
評価は `evaluate` が値を、`evaluate_with_derivative` が値と導関数に条件のレポートを添えて返し、一括評価の `_into` の形の一時領域の長さは `workspace_requirements(m)` で問い合わせる。
複素数の点や根の反復では、`PolynomialRootBasisRef` で基底を指定して `checked_basis_evaluation` を使う。
根を固有値に持つ行列は `root_matrix` または `polynomial_root_matrix_into` で作り、固有値は `scioxide-linalg` で求める。
