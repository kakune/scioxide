この表は厳密な係数の演算、繰り返し使う係数の演算の Plan、多変数の表現をまとめる。
厳密な演算の係数型は呼び出し側が `ExactCoefficient`（除算には `ExactField`）を実装して与える。
等号と加減乗算（除算は `ExactField` だけ）が厳密であることが仕様である。
SciOxide はどの型にもこれらを実装しないので、浮動小数点型を厳密な演算に渡すことはできない。
係数の演算や複製にかかる時間とメモリは、呼び出し側の係数型が決める。

## 部分積の木と多点評価

浮動小数点の部分積の木と剰余の木は提供しない。
厳密な係数の多点評価と補間には上の `ExactPolynomialProductTree` を使う。
近似値の多点評価には点ごとの評価を順に行う `ApproxPolynomial::evaluate_batch` か `evaluate_batch_into` を使い、標本値からの補間には重心形式 `ApproxPolynomial::interpolate_barycentric` を使う。

## まとめ

係数を厳密に扱う必要があれば `ExactPolynomial` と `ExactRationalFunction` を使い、終結式・部分分数分解にも厳密な係数の関数と型を使う。
浮動小数点の積や合成を繰り返すときは、`PolynomialOperationRequest` で形を宣言した `PolynomialOperationPlan` と作業領域を保持し、返された `PolynomialProductAlgorithm` と条件の推定で結果を読む。
厳密な係数の積・合成・Taylor シフトは Plan を持たない `exact_*_into` に、最大の出力に合わせた `ExactPolynomialWorkspace` を渡して繰り返す。
厳密な多点処理には `ExactPolynomialProductTree` を使い、近似値には点ごとの評価と重心補間を使う。
多変数では単項式の順序と代入の項数の上限を明示し、Bernstein の範囲は丸めを含む推定として扱う。
