この表は古典的な直交多項式族とその展開を扱う公開項目と、標本行列と最小二乗近似の公開項目をまとめる。
族を表す列挙型 `OrthogonalFamily`（`ChebyshevT` などの変種）は、値・導関数・零点・重み関数・三項漸化式の係数を返す。
展開の係数を扱うときは、族・正規化・座標の変換を `OrthogonalBasisSpec` で指定し、最大次数まで準備した `OrthogonalBasisPlan` を使い回す。

`ApproxPolynomial::orthogonal(coefficients, spec)` は係数の個数から次数を決めて既定の実行設定で Plan を準備し、既定の方針で多項式を作る。
`ApproxPolynomial::orthogonal_with_plan(coefficients, plan, policy)` は `OrthogonalBasisSpec::prepare` で作った `OrthogonalBasisPlan` と方針を受け取って所有する。
係数の個数は 1 以上、準備した最大次数 + 1 以下であればよく、短い展開でも準備の最大次数と実行設定を保持する。
直交基底の `PolynomialFitPlan` も準備済みの Plan を保持し、当てはめた多項式へその準備を引き継ぐ。
`to_orthogonal(spec)` は、直交基底からの変換では元の実行設定を引き継ぎ、単項式・Bernstein 基底からの変換では既定の実行設定で準備する。

`OrthogonalFamily::Legendre` の `evaluate` は `scioxide-special` の `legendre_p` に委ね、その精度・次数・計算量の仕様に従う。
`legendre_p` の漸化式は次数 $n$ に対して $n-1$ ステップで、既定の計算量の上限は 65,536 ステップである。
そのため、$x=\pm1$ 以外の点では、上限を超える次数で `ConvergenceFailure`（`IterationLimit`）、$n>2^{52}$ で `InvalidInput`（`OutOfRange`）になる。
導関数 `evaluate_derivative` は他の族と同じ $O(n)$ の漸化式で求める。
展開・微分・基底の変換は正規化と座標の写像を含む準備済みの漸化式を使う。

## まとめ

古典族の値・零点・重み関数は `OrthogonalFamily` の対応する変種で求め、零点は Chebyshev 族では閉形式、ほかの族では対称三重対角の固有値問題で得られる。
求積の重みは返さないので、必要なら `JacobiRecurrence` の行列の固有ベクトルを `scioxide-linalg` で求めて `log_weight_mass` と組み合わせるか、[scioxide-integrate の Gauss 型求積と Clenshaw–Curtis 則](../../../scioxide-integrate/algorithms/gaussian-and-clenshaw-curtis/)を使う。
展開の係数を繰り返し扱うときは、`OrthogonalBasisSpec` で族・正規化・座標を決め、`OrthogonalBasisPlan` で変換・微分・原始関数の写像を準備する。
ノイズのある標本には `PolynomialFitPlan` を準備し、`PolynomialFitReport` のランクと残差を読んでから結果を使う。
