この表は浮動小数点の係数で除算・有理関数・共通因子・消去・根の信頼性を扱う公開項目をまとめる。
ここでの数値ランク・条件数・円板・クラスタはどれも推定値であり、共通因子や根の個数の証明ではない。
証明が必要なら、厳密な係数の演算（[厳密な演算・高速演算・多変数の API](../exact-and-fast/)）か、区間演算（scioxide-validated）を使う。
準備済みの Plan の実行は最後の引数に `ExecutionContext` を受け取る。
`SylvesterElimination` と `SylvesterDiscriminant` の `_scoped` の形は、呼び出し側のスコープ（`ExecutionContext`、`SolveScope`、子のエポックにする `&mut SolveContext`）を受け取る。
反復の上限や呼び出し側の識別子は渡さない（近似 GCD の精度改善の反復の上限は内部で固定している）。

## まとめ

除算は `div_rem` の `PolynomialDivision` で商・剰余と再構成残差を受け取り、係数が刈り込まれないことを前提に次数を読む。
有理関数は `ApproxRationalFunction` で表し、約分は `simplify` の診断を読んでから受け入れる。
近似 GCD・終結式・判別式は平衡化した行列の数値ランクと逆条件数を添えて返る。
それらは行列の診断であり、共通因子の証明ではない（零の入力ではランクを持たない）。
部分分数分解は分母の因子を与えて準備し、レポートの再構成誤差と逆条件数（定数の分母では `None`）を確かめる。
根の候補は `ApproxPolynomial::root_condition` と `polynomial_root_diagnostics` で感度と円板の重なりを推定する。
