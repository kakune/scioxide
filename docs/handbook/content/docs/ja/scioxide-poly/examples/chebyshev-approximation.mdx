実軸上のグラフだけでは、高次の多項式でどれほど近似しやすいかを判断できない。
Runge 関数 $1/(1+25x^2)$ は実軸上で何回でも微分できるが、複素平面の $\pm i/5$ に極を持つ。
指数関数 $e^x$ は有限の複素平面に特異点を持たず、絶対値 $|x|$ は原点で微分できない。
この三つの関数の Chebyshev 係数の減衰を比べ、減衰の速さが関数のどの性質で決まるかを確かめる。
座標と関数値はすべて無次元である。

## 展開の規約と複素特異点

$[-1,1]$ 上の関数を $f(x)=\sum_{k=0}^\infty c_kT_k(x)$ と展開し、$c_0$ にも他の係数と同じ $T_0=1$ を掛ける規約を使う。
$x=\cos\theta$ とおくと、Chebyshev 展開は $f(\cos\theta)$ の余弦級数になり、

$$
c_k=\frac{2-\delta_{k0}}{\pi}\int_0^\pi f(\cos\theta)\cos k\theta\,d\theta
$$

である。
解析的な関数では、この積分を複素平面の積分路へ移すことで係数の幾何級数的な減衰を評価できる。

写像 $x=(w+w^{-1})/2$ で円 $|w|=\rho>1$ を移した曲線を、焦点 $\pm1$ の Bernstein 楕円 $E_\rho$ と呼ぶ。
$f$ が $E_\rho$ の内部で解析的で、そこで $|f|\le M$ なら、$k\ge1$ の係数は $|c_k|\le2M\rho^{-k}$ を満たす（Trefethen, ATAP, 定理 8.1）。
点 $ia$（$a>0$）を通る楕円は $w=i(a+\sqrt{a^2+1})$ から

$$
\rho=a+\sqrt{a^2+1}
$$

で、Runge 関数の極 $\pm i/5$（$a=1/5$）では $\rho=1/5+\sqrt{1+1/25}\approx1.2198$、$\ln\rho\approx0.1987$ になる。
極を通る楕円の内部で $f$ は解析的だが有界ではないので、定理の上界にはこれより少し小さい $\rho$ を使う。
一方で減衰率そのものはこの $\rho$ で決まる。
Runge 関数では、部分分数と Cauchy 核の展開 $1/(z-x)=(z^2-1)^{-1/2}\bigl(1+2\sum_{k\ge1}w^{-k}T_k(x)\bigr)$（$z=(w+w^{-1})/2$、$|w|>1$）から、係数を閉じた形で書ける。
$s=\sqrt{1+a^2}$ として

$$
c_0=\frac as,\qquad c_{2j}=(-1)^j\frac{2a}{s}\rho^{-2j},\qquad c_{2j+1}=0
$$

であり、偶数次の係数は正確に公比 $-\rho^{-2}$ の等比数列になる。
片対数グラフでは傾き $-\ln\rho$ の直線に並ぶ。

指数関数はどの $\rho$ の楕円の内部でも解析的なので、係数は任意の幾何級数より速く減る。
実際 $e^x=I_0(1)+2\sum_{k\ge1}I_k(1)T_k(x)$（$I_k$ は第 1 種変形 Bessel 関数）で、$c_k\approx2^{1-k}/k!$ となる。
片対数グラフでは傾きが次第に急になる曲線で、一本の直線にはならない。

絶対値では

$$
c_0=\frac2\pi,\qquad c_{2j}=\frac{4(-1)^{j-1}}{\pi(4j^2-1)},\qquad c_{2j+1}=0
$$

で、$|c_k|=O(k^{-2})$ の代数的な減衰になる。
これは $|x|$ が絶対連続で、1 階導関数 $\operatorname{sign}x$ が $x=0$ で不連続だが有界変動（全変動 $V=2$）であることに対応する。
ATAP の定理 7.1 を $\nu=1$ で使うと $|c_k|\le2V/(\pi k(k-1))=4/(\pi k(k-1))$ となり、実際の $4/(\pi(k^2-1))$ はこの上界のすぐ内側にある。
両対数グラフでは傾き $-2$ の直線に並ぶ。
Runge 関数と $|x|$ は偶関数なので、奇数次の係数は 0 である。

$n$ 次で打ち切った展開の誤差は、裾の和

$$
S_n=\sum_{k>n}|c_k|
$$

で抑えられ、$\max_{[-1,1]}|f-\sum_{k\le n}c_kT_k|\le S_n$ となる。
Runge 関数では $S_n=(2a/s)\rho^{-(n+2)}/(1-\rho^{-2})=O(\rho^{-n})$（$n$ が偶数のとき）である。
絶対値では部分分数 $1/(4j^2-1)=\tfrac12\bigl(1/(2j-1)-1/(2j+1)\bigr)$ の和が隣どうしで打ち消し合い、$S_n=2/(\pi(n+1))=O(1/n)$ になる。
係数の減衰と打ち切り誤差の理論は Trefethen, *Approximation Theory and Approximation Practice*（ATAP）の第 7、8 章と [DLMF §3.11(ii)](https://dlmf.nist.gov/3.11.ii) にある。

## 離散標本からの係数と折り返し

セルでは $T_{n+1}$ の零点（第 1 種 Chebyshev 点）$x_j=\cos((j+1/2)\pi/(n+1))$（$j=0,\dots,n$）で $n+1$ 個の標本を作り、`PolynomialFitPlan::orthogonal` で次数 $n$ の係数 $\tilde c_k$ を求める。
標本行列は正方でフルランクなので、この当てはめは補間になる。
得られる $\tilde c_k$ は無限級数の係数 $c_k$ そのものではない。
$T_{2m(n+1)\pm k}(x_j)=(-1)^mT_k(x_j)$ なので、高い次数の成分が低い次数へ折り返し、

$$
\tilde c_k=c_k+\sum_{m\ge1}(-1)^m\bigl(c_{2m(n+1)-k}+c_{2m(n+1)+k}\bigr)\qquad(1\le k\le n)
$$

となる（折り返し、エイリアシング）。
$k=0$ では二つの項が同じ $c_{2m(n+1)}$ になるので、一つだけを数える。
たとえば $k=n$ では主項が $-c_{n+2}$ で、Runge 関数では $c_{n+2}=-\rho^{-2}c_n$ なので $\tilde c_n\approx(1+\rho^{-2})c_n\approx1.67\,c_n$ になる。
$k$ が $n$ に近いと折り返しが $c_k$ と同程度になるので、閉形式との比較と回帰は $k\le n/2$ に限る。

折り返しの式から、補間の誤差も裾の和で抑えられる。
各 $T_k$（$k>n$）は標本点で低い次数の $\pm T_{k'}$ に置き換わるので、$|f-p_n|\le\sum_{k>n}|c_k|\,|T_k-(\pm T_{k'})|\le2S_n$ である（$T_k$ が標本点で 0 になる $k$ では $|T_k|\le1$ だけが残る）。
ATAP の定理 4.2 は第 2 種の Chebyshev 点について同じ形の誤差の展開を示している。
これに当てはめの丸めが加わるので、$\varepsilon|c_0|$ 程度より小さい係数は丸めの影響を受けた値として解釈する（$\varepsilon=2^{-52}$）。

次のブロックは二つのセルが共有する定義である。
`Subject` が三つの関数を表し、`value` が $f(x)$、`coefficient` が無限級数の係数 $c_k$ の閉形式、`tail` が裾の和 $S_n$ に対応する。
`bernstein_rho` は極 $i/5$ を通る楕円の $\rho$ を返す。
指数関数の係数は `scioxide-special` の `bessel_i` で $2I_k(1)$ として求める。
閉形式は当てはめとは独立な検算値である。

```rust
//| id: poly-chebyshev-model
//| kind: definitions
//| title: 三つの関数と無限級数の係数の閉形式
//| crates: [scioxide-core, scioxide-special]
use scioxide_core::RealScalar;
use std::f64::consts::PI;

/// Runge 関数 1/(1 + 25x²) の極 ±ia の a。
pub(crate) const RUNGE_POLE: f64 = 0.2;

/// 極 ia を通る Bernstein 楕円の ρ = a + √(a² + 1)。
pub(crate) fn bernstein_rho() -> f64 {
    RUNGE_POLE + RealScalar::sqrt(1.0 + RUNGE_POLE * RUNGE_POLE)
}

/// 係数の減衰を比べる三つの関数。
#[derive(Clone, Copy, PartialEq)]
pub(crate) enum Subject {
    Runge,
    Exponential,
    Absolute,
}

impl Subject {
    /// セルの選択肢の文字列から関数を選ぶ。
    pub(crate) fn from_label(label: &str) -> Self {
        match label {
            "Runge 関数 1/(1+25x²)" => Self::Runge,
            "指数関数 eˣ" => Self::Exponential,
            _ => Self::Absolute,
        }
    }

    /// 偶関数なら奇数次の係数は 0 である。
    pub(crate) fn is_even(self) -> bool {
        self != Self::Exponential
    }

    /// f(x)。
    pub(crate) fn value(self, x: f64) -> f64 {
        match self {
            Self::Runge => 1.0 / (1.0 + 25.0 * x * x),
            Self::Exponential => RealScalar::exp(x),
            Self::Absolute => x.abs(),
        }
    }

    /// 無限級数の係数 c_k の閉形式。指数関数は 2 I_k(1)（k = 0 は I_0(1)）。
    pub(crate) fn coefficient(self, k: usize) -> Result<f64, String> {
        let scale = if k == 0 { 1.0 } else { 2.0 };
        let sign = if (k / 2) % 2 == 0 { 1.0 } else { -1.0 };
        let (a, s) = (RUNGE_POLE, RealScalar::sqrt(1.0 + RUNGE_POLE * RUNGE_POLE));
        Ok(match self {
            Self::Exponential => {
                scale * scioxide_special::bessel_i(k as f64, 1.0).map_err(|e| e.to_string())?
            }
            _ if k % 2 == 1 => 0.0,
            Self::Runge => scale * a / s * sign * RealScalar::powi(bernstein_rho(), -(k as i32)),
            Self::Absolute if k == 0 => 2.0 / PI,
            Self::Absolute => -4.0 * sign / (PI * (k * k - 1) as f64),
        })
    }

    /// 裾の和 S_n = Σ_{k>n} |c_k|（n は偶数）。
    pub(crate) fn tail(self, n: usize) -> Result<f64, String> {
        let (a, s) = (RUNGE_POLE, RealScalar::sqrt(1.0 + RUNGE_POLE * RUNGE_POLE));
        let rho = bernstein_rho();
        Ok(match self {
            // 公比 ρ⁻² の等比級数 Σ_{j≥0} (2a/s) ρ^{−(n+2+2j)}
            Self::Runge => {
                2.0 * a / s * RealScalar::powi(rho, -((n + 2) as i32))
                    / (1.0 - RealScalar::powi(rho, -2))
            }
            // 2 I_k(1) は k = n + 30 までで binary64 の精度に足りる
            Self::Exponential => (n + 1..=n + 30)
                .map(|k| self.coefficient(k))
                .sum::<Result<f64, String>>()?,
            // (4/π) Σ_{j>n/2} 1/(4j² − 1) = 2/(π(n + 1))（部分分数の和）
            Self::Absolute => 2.0 / (PI * (n + 1) as f64),
        })
    }
}
```

## 係数の減衰を描く

次のセルは関数と次数 $n$ を選び、標本から求めた $|\tilde c_k|$（記号）と無限級数の $|c_k|$（破線）を片対数グラフに描く。
点線は丸めの水準 $\varepsilon|c_0|$ である。
偶関数では理論的に 0 の奇数次を図から除く。
標本から求めた係数が厳密に 0 になった次数は対数軸に描けないので図から除き、その数を次のセルの表に示す（この入力範囲では 0 件だった）。
縦軸は $[10^{-20},10]$ に固定しており、それより小さい閉形式の値は図の下に外れる。
セルは係数と関数の選択を次のセルへ渡す。

```rust
//| id: poly-chebyshev-coefficient-decay
//| ref: poly-chebyshev-coefficient-decay
//| title: 解析性と係数の減衰
//| run: reactive
//| uses: [poly-chebyshev-model]
//| crates: [scioxide-core, scioxide-poly]
//| exports: [function, degree, coefficients, rank, omitted]
//| inputs:
//|   function: {"type":"select","label":"関数","options":["Runge 関数 1/(1+25x²)","指数関数 eˣ","絶対値 |x|"],"value":"Runge 関数 1/(1+25x²)"}
//|   degree: {"type":"range","label":"次数 n [-]","description":"標本の数 n + 1 と当てはめる係数の個数を変える。","min":16,"max":64,"step":8,"value":32}
//| cases:
//|   - {"id":"exponential","label":"eˣ","description":"係数は幾何級数より速く減り、k ≈ 15 で丸めの水準に達する。","inputs":{"function":"指数関数 eˣ"}}
//|   - {"id":"absolute","label":"|x|","description":"係数は O(k⁻²) で代数的に減り、k ≤ n/2 でも折り返しが残る。","inputs":{"function":"絶対値 |x|"}}
//|   - {"id":"runge-64","label":"Runge 関数、n = 64","description":"標本を増やすと、折り返しの影響が k ≈ n/2 より後ろへ移る。","inputs":{"degree":64}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"coefficients","path":"/spec/layers/1/points/0/1","approx":{"value":0.19611613513818404,"atol":1e-4}}
//|       - {"artifact":"coefficients","path":"/spec/layers/1/points/16/1","approx":{"value":1.1363e-3,"rtol":1e-3}}
//|   - case: exponential
//|     expect:
//|       - {"artifact":"coefficients","path":"/spec/layers/1/points/10/1","approx":{"value":5.5059e-10,"rtol":1e-4}}
//|   - case: absolute
//|     expect:
//|       - {"artifact":"coefficients","path":"/spec/layers/1/points/1/1","approx":{"value":0.42441318157838759,"atol":2e-3}}
//|   - case: runge-64
//|     expect:
//|       - {"artifact":"coefficients","path":"/spec/layers/1/points/16/1","approx":{"value":6.796e-4,"rtol":1e-3}}
use scioxide_core::RealScalar;
use scioxide_poly::{
    BasisNormalization, OrthogonalBasisSpec, OrthogonalFamily, PolynomialBasis,
    PolynomialFitPlan,
};
use std::f64::consts::PI;

let subject = Subject::from_label(&function);
// 次数 n は 16〜64 の 8 の倍数（偶数）。
let n = degree as usize;
// 第 1 種 Chebyshev 点（T_(n+1) の零点）で n + 1 個の標本を取り、n 次の係数を当てはめる。
let nodes: Vec<f64> = (0..=n)
    .map(|j| RealScalar::cos(PI * (j as f64 + 0.5) / (n + 1) as f64))
    .collect();
let values: Vec<f64> = nodes.iter().map(|&x| subject.value(x)).collect();
let spec = OrthogonalBasisSpec::new(
    OrthogonalFamily::ChebyshevT,
    BasisNormalization::Classical,
    0.0_f64,
    1.0,
)
.map_err(|e| e.to_string())?;
let basis = spec
    .prepare(n, Default::default())
    .map_err(|e| e.to_string())?;
let plan = PolynomialFitPlan::orthogonal(&nodes, basis, None, Default::default())
    .map_err(|e| e.to_string())?;
let fit = plan.fit(&values).map_err(|e| e.to_string())?;
let coefficients = fit.polynomial().basis().coefficients().to_vec();

// 偶関数では理論的に 0 の奇数次を図から除く。厳密に 0 の係数は対数軸に描けないので数える。
let mut fitted = Vec::new();
let mut reference = Vec::new();
let mut omitted = 0_usize;
for (k, &coefficient) in coefficients.iter().enumerate() {
    if subject.is_even() && k % 2 == 1 {
        continue;
    }
    if coefficient == 0.0 {
        omitted += 1;
    } else {
        fitted.push([k as f64, coefficient.abs()]);
    }
    // 独立検算: 無限級数の係数の閉形式
    reference.push([k as f64, subject.coefficient(k)?.abs()]);
}
emit_chart!(
    serde_json::json!({
        "kind": "xy",
        "dataZoom": true,
        "tooltip": true,
        "xLabel": "次数 k [-]",
        "yLabel": "係数の絶対値 |c_k| [-]",
        "yType": "log",
        "xMin": 0.0,
        "xMax": 64.0,
        "yMin": 1e-20,
        "yMax": 10.0,
        "layers": [
            {
                "id": "series",
                "kind": "line",
                "name": "無限級数の |c_k|（閉形式）",
                "points": reference,
                "style": { "lineType": "dashed", "showSymbol": false }
            },
            { "id": "fitted", "kind": "scatter", "name": "標本から求めた |c̃_k|", "points": fitted }
        ],
        "annotations": [{
            "kind": "line",
            "axis": "y",
            "value": f64::EPSILON * coefficients[0].abs(),
            "label": "丸めの水準 ε|c₀|",
            "style": { "lineType": "dotted" }
        }]
    }),
    metadata = serde_json::json!({ "id": "coefficients" })
);
export!(function, function);
export!(degree, n);
export!(coefficients, coefficients);
export!(rank, fit.report().rank().rank());
export!(omitted, omitted);
```

既定の Runge 関数（$n=32$）では、偶数次の記号が破線に沿ってほぼ直線に並ぶ。
$k\le n/2$ では記号と破線の比は 1.001 以内に収まるが、$k=30$ で 1.30、$k=32$ で 1.67 と破線から上に離れる。
$k=n$ の比 1.67 は折り返しの主項から予測した $1+\rho^{-2}$ と一致する。
$n=64$ にすると同じ $k=32$ の比は 1.000 に戻り、離れる位置が $k=62$、$64$ へ移る。
$n=16$ では $k=10$ でも比が 1.06 で、折り返しの影響が回帰の範囲に入る。

指数関数では、係数は $k\approx15$ で丸めの水準 $\varepsilon|c_0|\approx2.8\times10^{-16}$ に達し、その後は $10^{-16}$ 程度で上下するだけになる。
この平らな部分の大小は解析性を表さないので、そこから減衰率を読まない。
閉形式の係数は $k\ge18$ で図の下端 $10^{-20}$ を下回り、図の範囲から外れる。

絶対値では、記号は破線に沿って代数的に減るが、$k=10$ でも比が 1.08、$k=n=32$ では 2.3 と、Runge 関数より手前から破線を離れる。
係数が $O(k^{-2})$ でしか減らないので、折り返す高次の係数も同じ桁で残るからである。

## 減衰率と打ち切り誤差の検算

次のセルは前のセルの係数を受け取り、三つの独立検算を表にする。
一つ目は $k\le n/2$ での閉形式 $c_k$ との差の最大である。
二つ目は偶数の $2\le k\le n/2$ での最小二乗の傾きで、Runge 関数は $(k,\ln|\tilde c_k|)$、絶対値は $(\ln k,\ln|\tilde c_k|)$ の組を使い、予測 $-\ln\rho$、$-2$ と比べる。
指数関数は直線にならないので傾きを求めない。
三つ目は係数から作った展開を `ApproxPolynomial::orthogonal` で 801 点の格子で評価した最大誤差 $E_n$ と、裾の和 $S_n$ の比である。
理論からは $E_n/S_n\le2$ が成り立つ。
$S_n$ が $10^3\varepsilon$ より小さいときは $E_n$ が丸めで決まるので、比を出さない。

```rust
//| id: poly-chebyshev-decay-checks
//| ref: poly-chebyshev-decay-checks
//| title: 減衰率の回帰と打ち切り誤差の検算
//| run: reactive
//| uses: [poly-chebyshev-model]
//| crates: [scioxide-core, scioxide-poly]
//| dependsOn:
//|   fit: poly-chebyshev-coefficient-decay
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"summary","path":"/rows/0/0","approx":{"value":-0.19869011034924142,"atol":2e-4}}
//|       - {"artifact":"summary","path":"/rows/0/2","range":{"max":3e-5}}
//|       - {"artifact":"summary","path":"/rows/0/5","range":{"min":0.5,"max":2}}
//|       - {"artifact":"summary","path":"/rows/0/6","equals":33}
use scioxide_core::RealScalar;
use scioxide_poly::{ApproxPolynomial, OrthogonalBasisSpec, OrthogonalFamily};

let subject = Subject::from_label(fit["function"].as_str().ok_or("関数がない")?);
let n = fit["degree"].as_u64().ok_or("次数がない")? as usize;
let coefficients: Vec<f64> =
    serde_json::from_value(fit["coefficients"].clone()).map_err(|e| e.to_string())?;

// k ≤ n/2 の係数を閉形式と比べ、減衰率を回帰する（後半は折り返しの影響が大きい）。
let mut deviation = 0.0_f64;
let mut regression = Vec::new();
for (k, &coefficient) in coefficients.iter().enumerate().take(n / 2 + 1) {
    deviation = deviation.max((coefficient - subject.coefficient(k)?).abs());
    if k >= 2 && !(subject.is_even() && k % 2 == 1) && coefficient != 0.0 {
        // Runge 関数は ln|c̃_k| と k、絶対値は ln|c̃_k| と ln k の組を使う。
        let x = match subject {
            Subject::Absolute => RealScalar::ln(k as f64),
            _ => k as f64,
        };
        regression.push((x, RealScalar::ln(coefficient.abs())));
    }
}
// 最小二乗の傾き。指数関数は幾何級数より速く減り、直線にならないので求めない。
let m = regression.len() as f64;
let (mx, my) = regression
    .iter()
    .fold((0.0, 0.0), |(sx, sy), &(x, y)| (sx + x / m, sy + y / m));
let (sxy, sxx) = regression.iter().fold((0.0, 0.0), |(sxy, sxx), &(x, y)| {
    (sxy + (x - mx) * (y - my), sxx + (x - mx) * (x - mx))
});
let (slope, predicted) = match subject {
    Subject::Runge => (Some(sxy / sxx), Some(-RealScalar::ln(bernstein_rho()))),
    Subject::Exponential => (None, None),
    Subject::Absolute => (Some(sxy / sxx), Some(-2.0)),
};

// 当てはめた展開を 801 点の格子で評価し、関数との最大誤差を測る。
let spec =
    OrthogonalBasisSpec::classical(OrthogonalFamily::ChebyshevT).map_err(|e| e.to_string())?;
let expansion = ApproxPolynomial::orthogonal(coefficients, spec).map_err(|e| e.to_string())?;
let mut max_error = 0.0_f64;
for j in 0..=800 {
    let x = -1.0 + j as f64 / 400.0;
    let value = expansion.evaluate(x).map_err(|e| e.to_string())?;
    max_error = max_error.max((value - subject.value(x)).abs());
}
let tail = subject.tail(n)?;
// 裾の和が丸めの水準より小さいと、最大誤差は丸めで決まるので比を出さない。
let ratio = (tail > 1e3 * f64::EPSILON).then(|| max_error / tail);

let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let fixed2 = serde_json::json!({ "fractionDigits": 2 });
let fixed4 = serde_json::json!({ "fractionDigits": 4 });
let columns = serde_json::json!([
    { "key": "0", "label": "回帰の傾き [-]", "type": "number", "format": fixed4, "nullText": "対象外" },
    { "key": "1", "label": "予測の傾き [-]", "type": "number", "format": fixed4, "nullText": "—" },
    { "key": "2", "label": "k ≤ n/2 での閉形式との差 [-]", "type": "number", "format": sci2 },
    { "key": "3", "label": "格子での最大誤差 E_n [-]", "type": "number", "format": sci2 },
    { "key": "4", "label": "裾の和 S_n [-]", "type": "number", "format": sci2 },
    { "key": "5", "label": "E_n/S_n [-]", "type": "number", "format": fixed2, "nullText": "丸めの水準" },
    { "key": "6", "label": "標本行列のランク", "type": "integer" },
    { "key": "7", "label": "対数軸から除いた零係数", "type": "integer" }
]);
let row = (
    slope,
    predicted,
    deviation,
    max_error,
    tail,
    ratio,
    fit["rank"].as_u64().ok_or("ランクがない")?,
    fit["omitted"].as_u64().ok_or("零係数の数がない")?,
);
emit_table_with_columns!(
    columns,
    vec![row],
    metadata = serde_json::json!({ "id": "summary" })
);
```

既定の Runge 関数（$n=32$）では、回帰の傾き $-0.1986$ は予測 $-\ln\rho=-0.1987$ と 3 桁一致する。
$k\le n/2$ での閉形式との差の最大 $1.9\times10^{-5}$ は、折り返しの主項 $|c_{2(n+1)-k}|=|c_{50}|\approx1.9\times10^{-5}$（$k=16$）と同じ大きさである。
格子での最大誤差 $E_{32}=1.4\times10^{-3}$ は裾の和 $S_{32}=1.4\times10^{-3}$ とほぼ等しく（比 1.01）、上界 $2S_n$ の内側にある。
$n=64$ では $E_{64}=2.5\times10^{-6}$、$S_{64}=2.4\times10^{-6}$ で、傾き $-0.19869007$ は予測と相対差 $2\times10^{-7}$ で一致する。
$n=16$ では回帰の範囲が短く折り返しも入るので、傾きは $-0.195$ になる。
次数を 32 増やすごとに誤差は $\rho^{-32}\approx1/580$ 倍になる。

指数関数では、$n=32$ での閉形式との差は $1.8\times10^{-15}$、格子での最大誤差は $5.3\times10^{-15}$ で、どちらも丸めの水準にある。
裾の和は $S_{32}=2.7\times10^{-47}$ なので、誤差はすべて丸めによるもので、比は表示しない。
$n=64$ では最大誤差が $1.6\times10^{-14}$ に増える。
必要以上に次数を上げると、当てはめと評価の丸めが増えるだけである。

絶対値では、回帰の傾きは $n=32$ で $-2.03$、$n=64$ で $-2.0004$ になる。
折り返しが係数と同じ $O(k^{-2})$ の大きさなので、$k\le n/2$ でも閉形式との差は $1.1\times10^{-3}$（$n=32$）残る。
格子での最大誤差は $n=32$ で $1.8\times10^{-2}$、$n=64$ で $9.2\times10^{-3}$ と、$S_n=2/(\pi(n+1))$ に比 0.94 で沿って $O(1/n)$ で半分になる。
グラフの小さい係数を機械的に捨てる前に、丸めの水準、折り返し、必要な値の精度を確かめる。

## まとめ

Chebyshev 係数の減衰は実軸上の滑らかさだけでなく複素平面の特異点の位置で決まり、最も近い特異点を通る Bernstein 楕円の $\rho$ が幾何級数的な減衰率 $\rho^{-k}$ を与える。
特異点のない関数は幾何級数より速く、1 階導関数が不連続な関数は $O(k^{-2})$ で代数的に減衰する。
補間の誤差は裾の和 $S_n=\sum_{k>n}|c_k|$ の 2 倍以下で、Runge 関数と $|x|$ では実際に $S_n$ とほぼ同じ大きさになる。
標本から求めた係数は無限級数の係数に折り返しと丸めが加わったもので、減衰率は $k\le n/2$ の範囲、かつ丸めの水準 $\varepsilon|c_0|$ より上の係数から読む。
係数が丸めの水準に達した後に次数を上げても、誤差は減らず丸めが増えるだけである。
