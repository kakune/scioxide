複素数の Newton 法では、初期値によって収束する根が変わる。
同じ根へ収束する初期値の集合を、その根の吸引域と呼ぶ。
単純根の十分近くでは二次収束するが、遠くの点からの収束は保証されない。
三次多項式 $z^3-1$ の吸引域は、Cayley が 1879 年に問うた古典的な問題である。
このページでは $z^3-1$ の Newton 反復を一点から追い、どの根の吸引域に入るかを軌跡、後退誤差、解析的な根との距離で読む。
平面の格子全体で吸引域を塗り分けた図は [rootfind の複素数の根](../../../scioxide-rootfind/algorithms/complex-roots/)にある。

## Newton 写像と根

$p(z)=z^3-1$ の三つの根は、単位円周上に $2\pi/3$ の間隔で並ぶ 1 の三乗根

$$
r_0=1,\qquad r_1=e^{2\pi i/3}=-\frac12+\frac{\sqrt3}2i,\qquad r_2=e^{4\pi i/3}=-\frac12-\frac{\sqrt3}2i
$$

である。
導関数は $p'(z)=3z^2$ なので、Newton 写像 $N:\mathbb C\setminus\{0\}\to\mathbb C$ は

$$
N(z)=z-\frac{p(z)}{p'(z)}=z-\frac{z^3-1}{3z^2}=\frac{2z^3+1}{3z^2}
$$

という有理関数になる。
反復は $z_{k+1}=N(z_k)$ である。
$\omega=e^{2\pi i/3}$ とすると $N(\omega z)=\omega N(z)$、$N(\bar z)=\overline{N(z)}$ が成り立つので、三つの吸引域は互いに $2\pi/3$ の回転と実軸についての鏡映で移り合う。

### 根の近くの二次収束

各根は $N(r_j)=r_j$ を満たす固定点で、

$$
N'(z)=\frac{6z^2\cdot3z^2-(2z^3+1)\cdot6z}{9z^4}=\frac{2(z^3-1)}{3z^3}
$$

から $N'(r_j)=0$ になる。
固定点での導関数が零なので、根の近くでは誤差 $e_k=z_k-r_j$ が

$$
e_{k+1}\approx\frac{p''(r_j)}{2p'(r_j)}e_k^2=\frac{e_k^2}{r_j}
$$

のように二次で減る（$p''/(2p')=1/z$）。
$|r_j|=1$ なので、比 $|e_{k+1}|/|e_k|^2$ は 1 に近づく。
正しい桁数が反復ごとにほぼ倍になるのはこのためである。

### 導関数の零点と吸引域の境界

Newton 補正 $p(z_k)/p'(z_k)$ は $p'(z)=0$ の点、すなわち原点で定義できない。
原点の近くでは分母が小さく、反復点は遠方へ飛ばされる。
遠方では $N(z)\approx2z/3$ なので、飛ばされた点は公比 $2/3$ で原点の方へ戻ってくる。
三つの吸引域の境界はすべて同じ集合（この写像の Julia 集合）で、原点もこの集合に含まれる。
境界上のどの点の近くにも三つの根すべての吸引域の点がある。
したがって境界の近くでは、初期値をわずかに変えるだけで収束先の根が変わる。
境界上の点そのものからはどの根にも収束しない。

## 反復の軌跡と後退誤差

`checked_basis_evaluation` は一点での値、1 階と 2 階の導関数と、成分ごとの後退誤差

$$
\eta(z)=\frac{|p(z)|}{\sum_k|a_k||z|^k}=\frac{|z^3-1|}{1+|z|^3}
$$

（`normalized_residual`）を、Horner 法の一回の走査で返す。
$\eta(z)$ は、係数を相対的に $\eta$ だけ動かせば $z$ が厳密な根になる、という意味の後退誤差である。
遠方の点では $\eta\approx1$ で、$z$ は近くのどの多項式の根でもない。
単純根の近くでは、前進誤差は条件数と後退誤差の積 $|e|\approx\kappa\,\eta$ で見積もれる。
$\kappa$ は `root_condition` が返す絶対条件数 $\sum_k|a_k||z|^k/|p'(z)|$ で、$z^3-1$ の根では $\kappa=2/|3r_j^2|=2/3$ である。

`newton_correction` は商 $p(z)/p'(z)$ を返し、$p'(z)=0$ なら `None` を返す。
$p$ や $p'$ の一方が binary64 の範囲を超える点では、指数を拡張した範囲で商を作ってから binary64 に戻す。
停止の判定には `roundoff_limited` を使う。
これは後退誤差が評価の丸めの許容量 $\gamma_{32}=32\varepsilon/(1-32\varepsilon)\approx7.1\times10^{-15}$ 以下になったときに真になり、そこから先の反復では $z$ を改善できないことを示す。
32 は複素数の Horner 法の 1 段あたり 8 回の実数の丸めを 4 個の係数について数えた値で、$\varepsilon=2^{-52}$ は機械イプシロンである。
この許容量は丸め誤差の推定であり、根の包含区間ではない。
後退誤差と丸めの許容量の導出は [Horner 評価の丸め誤差と診断](oxref:poly-checked-evaluation-backward-error)にある。

次の定義のブロックは二つのセルが共有するモデルである。
`COEFFICIENTS` が $p(z)=z^3-1$ の昇べき順の係数、`cube_roots` が解析的な三根 $r_0,r_1,r_2$、`nearest_root` が点から最も近い根の番号と距離に対応する。
三根は独立検算の参照値で、反復には使わない。

```rust
//| id: poly-complex-newton-model
//| kind: definitions
//| title: z³ − 1 の係数と解析的な三根
//| crates: [scioxide-core]
use scioxide_core::{Complex, RealScalar};

/// p(z) = z³ − 1 の昇べき順の係数。
pub(crate) const COEFFICIENTS: [f64; 4] = [-1.0, 0.0, 0.0, 1.0];

/// 解析的な三根 r₀ = 1、r₁ = e^{2πi/3}、r₂ = e^{4πi/3}。
pub(crate) fn cube_roots() -> [Complex<f64>; 3] {
    let half_root_three = RealScalar::sqrt(3.0_f64) / 2.0;
    [
        Complex::new(1.0, 0.0),
        Complex::new(-0.5, half_root_three),
        Complex::new(-0.5, -half_root_three),
    ]
}

/// 最も近い解析的な根の番号と距離。
pub(crate) fn nearest_root(z: Complex<f64>) -> (usize, f64) {
    cube_roots()
        .iter()
        .map(|&root| (z - root).norm())
        .enumerate()
        .fold((0, f64::INFINITY), |best, item| {
            if item.1 < best.1 { item } else { best }
        })
}
```

次のセルは極座標 $(|z_0|,\theta_0)$ で指定した初期点から反復し、各反復の点、後退誤差、解析的な三根のうち最も近いものとの距離 $e_k$、比 $e_{k+1}/e_k^2$ を表に出す。
次の距離 $e_{k+1}$ が $10^{-13}$ 未満の行は丸めの影響が大きいので、比を空欄にする。
入力は初期角度 [deg]、初期半径（無次元）、更新の上限 [回] である。
独立検算は到達点と解析的な三根との距離、比 $e_{k+1}/e_k^2\to1$、$e_k\approx\tfrac23\eta(z_k)$ の三つである。
最後の outcome は停止の理由を示す。
`roundoff_limited` で止まれば `satisfied`、更新の上限で止まれば `partial`、$p'(z)=0$ の点に達すれば `failed` である。
軌跡は次のセルへ渡して図にする。

```rust
//| id: poly-complex-newton
//| ref: poly-complex-newton
//| title: z^3−1 の複素 Newton 軌跡をたどる
//| run: reactive
//| uses: [poly-complex-newton-model]
//| crates: [scioxide-core, scioxide-poly]
//| exports: [trajectory]
//| inputs:
//|   initial_angle_deg: {"type":"range","label":"初期角度 θ₀ [deg]","description":"開始方向を変え、到達する根を調べる。","min":0,"max":360,"step":5,"value":55}
//|   initial_radius: {"type":"range","label":"初期半径 |z₀| [-]","description":"導関数が零の原点や遠方からの距離を変える。","min":0.1,"max":2,"step":0.1,"value":0.8}
//|   iteration_limit: {"type":"range","label":"更新の上限 [回]","description":"境界近くの長い軌跡に使える更新の回数の上限を変える。","min":8,"max":40,"step":1,"value":24}
//| cases:
//|   - {"id":"small-radius","label":"|z₀| = 0.1","description":"原点の近くから始めると遠方へ飛ばされ、根 r₂ に収束する。","inputs":{"initial_radius":0.1}}
//|   - {"id":"large-radius","label":"|z₀| = 2","description":"同じ角度でも半径 2 からは根 r₁ に収束する。","inputs":{"initial_radius":2}}
//|   - {"id":"short-limit","label":"上限 8 回","description":"後退誤差が丸めの許容量に達する前に打ち切られ、partial になる。","inputs":{"iteration_limit":8}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"iterations","path":"/rows/2/1","approx":{"value":12.497492723727037,"rtol":1e-6}}
//|       - {"artifact":"iterations","path":"/rows/14/5","approx":{"value":1.0,"atol":1e-3}}
//|       - {"artifact":"iterations","path":"/rows/16/4","range":{"max":1e-15}}
//|       - {"path":"/outputs/1/state","equals":"satisfied"}
//|   - case: small-radius
//|     expect:
//|       - {"artifact":"iterations","path":"/rows/14/2","approx":{"value":-0.8660254037844386,"atol":1e-12}}
//|       - {"path":"/outputs/1/state","equals":"satisfied"}
//|   - case: large-radius
//|     expect:
//|       - {"artifact":"iterations","path":"/rows/10/2","approx":{"value":0.8660254037844386,"atol":1e-12}}
//|       - {"path":"/outputs/1/state","equals":"satisfied"}
//|   - case: short-limit
//|     expect:
//|       - {"artifact":"iterations","path":"/rows/8/3","approx":{"value":0.9209752733086967,"rtol":1e-6}}
//|       - {"path":"/outputs/1/state","equals":"partial"}
use scioxide_core::Complex;
use scioxide_poly::{PolynomialRootBasisRef, checked_basis_evaluation};
use std::f64::consts::PI;

let limit = iteration_limit.round() as usize;
let mut point = Complex::from_polar(initial_radius, initial_angle_deg * PI / 180.0);
// (k, Re z_k, Im z_k, η(z_k), |z_k − r|)
let mut rows: Vec<(usize, f64, f64, f64, f64)> = Vec::new();
// 停止の理由: 後退誤差が丸めの許容量以下、更新の上限、導関数が零
let stop = loop {
    let evaluation =
        checked_basis_evaluation(&COEFFICIENTS, point, PolynomialRootBasisRef::Monomial)
            .map_err(|e| e.to_string())?;
    let k = rows.len();
    rows.push((
        k,
        point.re,
        point.im,
        evaluation.normalized_residual(),
        nearest_root(point).1,
    ));
    if evaluation.roundoff_limited() {
        break "丸めの水準に到達";
    }
    if k == limit {
        break "更新の上限";
    }
    // p/p′ を拡張した指数の範囲で作ってから射影する。p′(z) = 0 なら None。
    let Some(correction) = evaluation.newton_correction().map_err(|e| e.to_string())? else {
        break "導関数が零";
    };
    point = point - correction;
};
let updates = rows.len() - 1;
let (root_index, distance) = nearest_root(point);

// 二次収束の検算: e_{k+1}/e_k² は |1/r| = 1 に近づく。次の誤差が丸めの水準に近い行は除く。
let table: Vec<_> = rows
    .iter()
    .enumerate()
    .map(|(k, &(_, re, im, eta, e))| {
        let ratio = rows
            .get(k + 1)
            .filter(|next| next.4 >= 1e-13)
            .map(|next| next.4 / (e * e));
        (k, re, im, eta, e, ratio)
    })
    .collect();
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let fixed6 = serde_json::json!({ "fractionDigits": 6 });
let fixed3 = serde_json::json!({ "fractionDigits": 3 });
let columns = serde_json::json!([
    { "key": "0", "label": "反復 k [回]", "type": "integer" },
    { "key": "1", "label": "Re z_k [-]", "type": "number", "format": fixed6 },
    { "key": "2", "label": "Im z_k [-]", "type": "number", "format": fixed6 },
    { "key": "3", "label": "後退誤差 η(z_k) [-]", "type": "number", "format": sci3 },
    { "key": "4", "label": "最も近い根との距離 e_k [-]", "type": "number", "format": sci3 },
    { "key": "5", "label": "e_(k+1)/e_k² [-]", "type": "number", "format": fixed3, "nullText": "—" }
]);
emit_table_with_columns!(
    columns,
    table,
    metadata = serde_json::json!({ "id": "iterations" })
);
let trajectory: Vec<[f64; 2]> = rows.iter().map(|row| [row.1, row.2]).collect();
export!(trajectory, &trajectory);

let outcome = match stop {
    "丸めの水準に到達" => Outcome::satisfied(format!(
        "後退誤差が丸めの許容量以下になり、根 r{root_index} に達した"
    )),
    "更新の上限" => {
        Outcome::partial("後退誤差が丸めの許容量に達する前に、更新の上限で止まった")
            .explanation("最後の点は途中の値であり、最も近い根を収束先とみなさない。")
    }
    _ => Outcome::failed("p′(z) = 0 の点に達し、Newton 補正を定義できない"),
};
emit_outcome!(
    outcome
        .status(stop)
        .diagnostic("更新回数", updates as f64, None)
        .diagnostic("後退誤差 η", rows[updates].3, None)
        .diagnostic("最も近い根との距離", distance, None)
);
```

表示範囲は $[-2.5,2.5]^2$ に固定するので、遠方へ飛んだ点は前のセルの表で確かめる。

既定の入力では、軌跡は原点の近くを通ってから右上の枠の外へ出る。
$N(z)\approx2z/3$ は偏角をほとんど変えないので、点は同じ方向の直線に近い経路で原点の方へ戻り、そこから $r_0=1$ に達する。

### 結果の読み方

既定の $\theta_0=55^\circ$、$|z_0|=0.8$ では、1 回目の更新で原点（$p'$ の零点）の近くの $(0.13,-0.05)$ に移り、2 回目で $(12.5,12.3)$ まで飛ばされる。
そこから $N(z)\approx2z/3$ に従って原点の方へ戻り、16 回の更新で根 $r_0$ に収束する。
遠方の反復では後退誤差は 1 に近く、点は根の候補として意味を持たない。

収束の直前の後退誤差は $1.9\times10^{-3}\to2.5\times10^{-6}\to4.3\times10^{-12}\to5.5\times10^{-24}$ と、指数がほぼ倍になる。
比 $e_{k+1}/e_k^2$ は $0.96\to0.9992\to1.000004$ と 1 に近づき、二次収束の係数 $1/|r_0|=1$ と一致する。
各行の距離 $e_k$ は $\tfrac23\eta(z_k)$ とよく合う（$k=13$ で $1.30\times10^{-3}$ と $\tfrac23\times1.95\times10^{-3}$）。
最後の後退誤差が丸めの許容量 $7.1\times10^{-15}$ よりはるかに小さいのは、反復点が $1+3.7\times10^{-24}i$ と表され、$|p(z)|\approx3|\mathrm{Im}\,z|$ をそのまま評価できるからである。
一方で実部は丸めて 1 に一致するので、$e_{16}$ は虚部の誤差だけを表す。
比 $e_{16}/e_{15}^2\approx0.46$ は収束の係数を表さないので、$k=15$ の行の比は空欄にしてある。

半径を 0.1 にすると最初の更新で $(-11.4,-31.3)$ へ飛び、14 回で $r_2$ に、半径 2 では 10 回で $r_1$ に収束する。
同じ角度でも半径によって行き先が三通りに変わるので、この方向の半直線は吸引域の境界を少なくとも二度横切る。
角度 $0^\circ$ のように根の方向から始めると、実軸上を進んで 5 回の更新で $r_0=1$ に収束する。
角度 $60^\circ$、半径 0.5 では $z_0^3=-1/8$ なので $N(z_0)=r_2$ となり、1 回の更新で収束する。

更新の上限を 8 にすると、後退誤差が許容量に達する前に打ち切られ、outcome は `partial` になる。
最後の点の後退誤差は 0.92 で、最も近い根までの距離も 0.99 あるので、この点を根の近似として扱ってはいけない。
`newton_correction` が `None` を返すのは、$p'(z)=3z^2$ が厳密に 0 になる $z=0$ だけである（binary64 でアンダーフローする評価は指数を拡張した範囲でやり直すので、小さな $z$ でも 0 にはならない）。
初期値の格子は $N(z_0)=0$ となる点（$2z_0^3=-1$、半径 $2^{-1/3}\approx0.794$）を含まないので、既定の入力範囲で `failed` を見ることはまずない。
それでも一般の多項式の反復では $p'(z)=0$ の場合を別の終了状態として扱う。

## まとめ

Newton 反復の行き先は初期値で決まり、導関数が零の原点の近くを通る軌跡は遠方へ飛ばされ、公比 $2/3$ で戻ってから別の根へ向かうことがある。
根の近くでは比 $e_{k+1}/e_k^2$ が $1/|r_j|$ に近づく二次収束になり、後退誤差の指数はほぼ倍々に減る。
停止は `roundoff_limited`（後退誤差と丸めの許容量 $\gamma_{32}$ の比較）で判定し、それ以上の反復を打ち切る。
丸めの水準への到達、更新の上限による打ち切り、導関数の零はそれぞれ別の終了状態として扱い、打ち切った点を最も近い根に割り当てない。
ここで表示するのは一つの初期値の有限回の軌跡であり、吸引域全体の図でも収束の証明でもない。
