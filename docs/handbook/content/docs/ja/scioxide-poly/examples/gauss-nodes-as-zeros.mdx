1 次元の量子調和振動子の第 $n$ 励起状態は、質量 $m$、角振動数 $\omega$ と長さの尺度 $\ell=\sqrt{\hbar/(m\omega)}$ による無次元の位置 $\xi=x/\ell$ を使って

$$
\psi_n(\xi)=\bigl(2^nn!\sqrt\pi\bigr)^{-1/2}H_n(\xi)\,e^{-\xi^2/2}
$$

と書ける。
$e^{-\xi^2/2}$ は 0 にならないので、確率密度 $|\psi_n|^2$ が 0 になる位置（波動関数の節）は物理学者の Hermite 多項式 $H_n$ の零点そのものである。
同じ零点は重み $e^{-\xi^2}$ の $n$ 点 Gauss–Hermite 求積の節点でもある。
このページでは $H_n$ の零点と三項漸化式だけを扱う。
期待値と Gauss–Hermite 求積の厳密次数は [integrate の量子調和振動子の期待値](../../../scioxide-integrate/examples/quantum-oscillator-expectations/)と [Gauss 型求積と Clenshaw–Curtis 則](../../../scioxide-integrate/algorithms/gaussian-and-clenshaw-curtis/)で扱う。

具体例として、一酸化炭素 ¹²C¹⁶O の伸縮振動を調和振動子で近似する。
換算質量 $\mu=6.8562$ u と調和振動数 $\tilde\nu=2169.81$ cm⁻¹（$\omega=2\pi c\tilde\nu$）から、長さの尺度は $\ell=\sqrt{\hbar/(\mu\omega)}\approx4.761$ pm になる。
節の位置は $x=\ell\,r_j$ で、平衡核間距離 112.8 pm からのずれを表す。
実際の CO の振動は非調和なので、この換算は低い準位での目安である。

## 三項漸化式から行列へ

物理学者の規約は $H_0=1$、$H_1=2\xi$、

$$
H_{k+1}=2\xi H_k-2kH_{k-1}
$$

で、直交の重みは $e^{-\xi^2}$ である。
[直交多項式族](oxref:poly-jacobi-matrix-reduction)の漸化式 $p_{k+1}=(a_kx+b_k)p_k-c_kp_{k-1}$ で $a_k=2$、$b_k=0$、$c_k=2k$ とすると、正規直交化した基底では $\xi$ を掛ける操作が対角 $d_k=0$、副対角 $e_k=\sqrt{c_k/(a_{k-1}a_k)}=\sqrt{k/2}$ の対称三重対角行列 $\mathbf J$ で表せる。
その左上の $n\times n$ の主部分行列 $\mathbf J_n$ の固有値が $H_n$ の零点になる（Golub–Welsch 法）。
`OrthogonalFamily::jacobi_recurrence(n)` はこの対角と副対角を所有して返し、単項式への展開を必要としない。
`OrthogonalFamily::HermiteH.zeros(n)` は同じ行列の固有値を `scioxide-linalg` の対称三重対角の固有値解法で求め、昇順に返す。
計算量は固有値だけなら $O(n^2)$ である。

$\mathbf J_n$ は実対称で副対角が正なので、固有値は実数で、すべて単純である。
$\mathbf J_n$ は $\mathbf J_{n+1}$ の主部分行列なので、Cauchy の交互定理から、次数 $n$ と $n+1$ の零点 $r_{n,j}$、$r_{n+1,j}$（昇順）は $r_{n+1,j}\le r_{n,j}\le r_{n+1,j+1}$ を満たす。
等号は成り立たない。
$H_n$ と $H_{n+1}$ が共通の零点を持てば、漸化式を下へたどって $H_0=1$ も 0 になるからである。
したがって

$$
r_{n+1,j}<r_{n,j}<r_{n+1,j+1}\qquad(j=1,\dots,n)
$$

と交互に並ぶ。
二つの次数の零点を独立に計算すれば、この性質を数値で確かめられる。
物理では、励起を一つ上げるごとに節が一つ増え、隣り合う状態の節が互い違いに並ぶことに対応する。

## 和と二乗和と規約

固有値の和はトレースに等しい。
$\mathbf J_n$ の対角は 0 なので $\sum_jr_j=0$ である。
零点が原点について対称に並ぶことは、偶奇性 $H_n(-\xi)=(-1)^nH_n(\xi)$ からも分かる。
二乗の和は $\mathrm{tr}\,\mathbf J_n^2$ で、副対角の二乗を二回ずつ数えるので

$$
\sum_jr_j^2=2\sum_{k=1}^{n-1}e_k^2=2\sum_{k=1}^{n-1}\frac k2=\frac{n(n-1)}2
$$

となる。
確率論の規約 $He_{k+1}=xHe_k-kHe_{k-1}$（重み $e^{-x^2/2}$）では副対角が $\sqrt k$ になり、二乗和は $n(n-1)$ に変わる。
二つは $H_n(\xi)=2^{n/2}He_n(\sqrt2\,\xi)$ で結ばれるので、$H_n$ の零点は $He_n$ の零点の $1/\sqrt2$ 倍である。
規約を取り違えると、零点はすべて $\sqrt2$ 倍または $1/\sqrt2$ 倍の位置に移る。
$n=2$ では $H_2=4\xi^2-2$ の零点 $\pm1/\sqrt2$ と二乗和 1 で、どちらの式も確かめられる。

## 零点と恒等式の計算

次のセルは `OrthogonalFamily::HermiteH.zeros` で $n$ 次と $n+1$ 次の零点を求める。
入力は次数 $n$（2〜20）で、座標 $\xi$ は無次元である。
1 つ目の表は各零点と、その両隣の $n+1$ 次の零点、CO の節の位置 $\ell r_j$ [pm]、Newton 補正 $|H_n/H_n'|$ を示す。
$H_n$ の値そのものは次数とともに急増するので、零点での残差の代わりに、零点までの距離の一次の推定である Newton 補正を見る。
2 つ目の表は二つの独立検算を示す。

- 上のトレースの恒等式（和 0、二乗和 $n(n-1)/2$）と、`JacobiRecurrence` の副対角から計算した $2\sum e_k^2$。
- 隣の次数との交互配置。
  「交互配置の最小の間隔」は $\min_j\min(r_{n,j}-r_{n+1,j},\ r_{n+1,j+1}-r_{n,j})$ で、正なら交互配置が成り立つ。

図は二つの次数の零点を横に並べ、縦軸に次数をとる。
セルは次数と零点を次のセルへ渡す。

```rust
//| id: poly-hermite-gauss-zeros
//| ref: poly-hermite-gauss-zeros
//| title: Hermite の零点と隣接次数の交互配置
//| run: reactive
//| crates: [scioxide-core, scioxide-poly]
//| exports: [degree, roots]
//| inputs:
//|   degree: {"type":"range","label":"次数 n [-]","description":"零点の個数（振動の量子数）を変える。","min":2,"max":20,"step":1,"value":8}
//| cases:
//|   - {"id":"degree-2","label":"n = 2","description":"零点は閉形式 ±1/√2 で、二乗和は 1 になる。","inputs":{"degree":2}}
//|   - {"id":"degree-20","label":"n = 20","description":"零点が増えても、和・二乗和・交互配置の検算は丸めの水準で成り立つ。","inputs":{"degree":20}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"zeros","path":"/rows/7/2","approx":{"value":2.930637420257244,"atol":1e-13}}
//|       - {"artifact":"identities","path":"/rows/0/1","range":{"min":-1e-13,"max":1e-13}}
//|       - {"artifact":"identities","path":"/rows/1/3","range":{"max":1e-12}}
//|       - {"artifact":"identities","path":"/rows/2/3","range":{"max":1e-12}}
//|       - {"artifact":"identities","path":"/rows/3/1","approx":{"value":0.2603557815242863,"rtol":1e-9}}
//|   - case: degree-2
//|     expect:
//|       - {"artifact":"zeros","path":"/rows/1/2","approx":{"value":0.7071067811865476,"atol":1e-15}}
//|       - {"artifact":"identities","path":"/rows/1/1","approx":{"value":1.0,"atol":1e-14}}
//|   - case: degree-20
//|     expect:
//|       - {"artifact":"zeros","path":"/rows/19/2","approx":{"value":5.387480890011233,"atol":1e-12}}
//|       - {"artifact":"identities","path":"/rows/1/3","range":{"max":1e-12}}
//|       - {"artifact":"identities","path":"/rows/3/1","approx":{"value":0.16287098325344118,"rtol":1e-9}}
use scioxide_core::RealScalar;
use scioxide_poly::OrthogonalFamily;

let n = degree as usize;
let family = OrthogonalFamily::<f64>::HermiteH;
// Jacobi 行列 J_n と J_(n+1) の固有値としての零点（昇順）
let roots = family.zeros(n).map_err(|e| e.to_string())?;
let next = family.zeros(n + 1).map_err(|e| e.to_string())?;
let recurrence = family.jacobi_recurrence(n).map_err(|e| e.to_string())?;
// CO の伸縮振動の長さの尺度 ℓ = √(ħ/(μω)) [pm]。μ = 6.8562 u、ω = 2πc·2169.81 cm⁻¹。
let hbar = 1.054_571_817e-34;
let mu = 6.8562 * 1.660_539_067e-27;
let omega = 2.0 * std::f64::consts::PI * 2.997_924_58e10 * 2169.81;
let length = RealScalar::sqrt(hbar / (mu * omega)) * 1e12;

let mut rows = Vec::new();
for (j, &x) in roots.iter().enumerate() {
    let value = family.evaluate(n, x).map_err(|e| e.to_string())?;
    let derivative = family
        .evaluate_derivative(n, x)
        .map_err(|e| e.to_string())?;
    // Newton 補正 |H_n/H_n′| は零点までの距離の一次の推定
    let correction = (value / derivative).abs();
    rows.push((j + 1, next[j], x, next[j + 1], x * length, correction));
}
let fixed6 = serde_json::json!({ "fractionDigits": 6 });
let fixed2 = serde_json::json!({ "fractionDigits": 2 });
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let columns = serde_json::json!([
    { "key": "0", "label": "番号 j", "type": "integer" },
    { "key": "1", "label": "左の n+1 次零点 [-]", "type": "number", "format": fixed6 },
    { "key": "2", "label": "n 次零点 r_j [-]", "type": "number", "format": fixed6 },
    { "key": "3", "label": "右の n+1 次零点 [-]", "type": "number", "format": fixed6 },
    { "key": "4", "label": "CO の節の位置 [pm]", "type": "number", "format": fixed2 },
    { "key": "5", "label": "|H_n/H_n′| [-]", "type": "number", "format": sci2 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "zeros" })
);

// トレースの恒等式と交互配置の検算
let sum = roots.iter().sum::<f64>();
let squares = roots.iter().map(|x| x * x).sum::<f64>();
let trace = 2.0 * recurrence.off_diagonal().iter().map(|e| e * e).sum::<f64>();
let expected = (n * (n - 1)) as f64 / 2.0;
let gap = roots
    .iter()
    .enumerate()
    .map(|(j, &x)| (x - next[j]).min(next[j + 1] - x))
    .fold(f64::INFINITY, f64::min);
let checks = vec![
    ("零点の和 Σr_j", sum, Some(0.0)),
    ("零点の二乗和 Σr_j²", squares, Some(expected)),
    ("副対角からの 2Σe_k²", trace, Some(expected)),
    ("交互配置の最小の間隔", gap, None),
];
let rows: Vec<_> = checks
    .into_iter()
    .map(|(name, value, exact)| (name, value, exact, exact.map(|e| (value - e).abs())))
    .collect();
let general = serde_json::json!({ "significantDigits": 15 });
let columns = serde_json::json!([
    { "key": "0", "label": "量" },
    { "key": "1", "label": "計算値 [-]", "type": "number", "format": general },
    { "key": "2", "label": "解析値 [-]", "type": "number", "format": general, "nullText": "—" },
    { "key": "3", "label": "差 [-]", "type": "number", "format": sci2, "nullText": "—" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "identities" })
);

let points: Vec<[f64; 2]> = roots.iter().map(|&x| [x, n as f64]).collect();
let next_points: Vec<[f64; 2]> = next.iter().map(|&x| [x, (n + 1) as f64]).collect();
emit_scatter_chart!(
    &vec![
        serde_json::json!({ "name": "H_n の零点", "points": points }),
        serde_json::json!({ "name": "H_(n+1) の零点", "points": next_points })
    ],
    options = &serde_json::json!({
        "xLabel": "零点 ξ [-]",
        "yLabel": "次数 [-]",
        "xMin": -7.0,
        "xMax": 7.0,
        "yMin": 1.0,
        "yMax": 22.0
    })
);
export!(degree, n);
export!(roots, roots);
```

既定の $n=8$ では、零点の和は $-1.8\times10^{-15}$、二乗和は解析値 28 と $10^{-13}$ 未満の差で一致する。
副対角から計算した $2\sum e_k^2$ も 28 になり、トレースの恒等式を行列のデータから確かめられる。
交互配置の最小の間隔は 0.26 で正なので、表示した零点はすべて隣の次数の零点の間にある。
Abramowitz–Stegun の表 25.10 の 8 点 Gauss–Hermite 節点（小数 15 桁）と比べると、中央に近い零点 0.381187 は表の桁まで一致し、最大の零点 2.930637 は表の値 2.930637420257244 と $5\times10^{-15}$ の差で一致する。
Newton 補正 $|H_n/H_n'|$ は $5\times10^{-15}$ 以下で、零点の誤差が丸めの水準にあることを示す。
CO の節は平衡位置から $\pm13.95$ pm の範囲に並び、古典的な折り返し点 $\pm\ell\sqrt{2n+1}=\pm19.6$ pm の内側にある。

$n=2$ では零点は $\pm0.707107$ で、閉形式 $\pm1/\sqrt2$ と一致し、二乗和は 1 である。
$n=20$ では二乗和 190 に対する差が $1.7\times10^{-13}$、交互配置の最小の間隔が 0.16 になる。
最大の零点は 5.39（CO では 25.6 pm）で、波動関数の節は古典的に許される領域 $|\xi|<\sqrt{2n+1}\approx6.40$ の内側にある。
隣り合う零点の間隔は中央で最も狭く（$n=20$ で 0.49）、端に向かって広がる（0.78）。

## 別のアルゴリズムと別の規約による検算

次のセルは前のセルの零点を受け取り、別の二つの方法で同じ零点を求め直す。

- 別のアルゴリズムによる零点。
  $H_n$ を係数 $(0,\dots,0,1)$ の Hermite 展開として `root_matrix()` で comrade 行列（直交基底の伴行列）を作り、`scioxide-linalg` の一般の固有値計算 `GeneralEigenvaluesResult::compute` で解く。
  comrade 行列は対称でないので、固有値は複素数として返る。
- 確率論の規約で求めた $He_n$ の零点を $\sqrt2$ で割った値。

1 つ目の表は各零点との差、2 つ目の表は差の最大と、comrade 行列の固有値の虚部の最大を示す。

```rust
//| id: poly-hermite-zero-crosscheck
//| ref: poly-hermite-zero-crosscheck
//| title: comrade 行列と確率論の規約による零点の検算
//| run: reactive
//| crates: [scioxide-linalg, scioxide-poly]
//| dependsOn:
//|   zeros: poly-hermite-gauss-zeros
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"summary","path":"/rows/0/0","range":{"max":1e-13}}
//|       - {"artifact":"summary","path":"/rows/0/1","range":{"max":1e-12}}
//|       - {"artifact":"summary","path":"/rows/0/2","range":{"max":1e-13}}
use scioxide_linalg::GeneralEigenvaluesResult;
use scioxide_poly::{ApproxPolynomial, OrthogonalBasisSpec, OrthogonalFamily};
use std::f64::consts::SQRT_2;

let n = zeros["degree"].as_u64().ok_or("次数がない")? as usize;
let roots: Vec<f64> =
    serde_json::from_value(zeros["roots"].clone()).map_err(|e| e.to_string())?;

// 別のアルゴリズム: H_n を Hermite 展開の係数 (0, …, 0, 1) とし、comrade 行列を一般の固有値計算で解く。
let family = OrthogonalFamily::<f64>::HermiteH;
let spec = OrthogonalBasisSpec::classical(family).map_err(|e| e.to_string())?;
let mut unit = vec![0.0_f64; n + 1];
unit[n] = 1.0;
let hermite = ApproxPolynomial::orthogonal(unit, spec).map_err(|e| e.to_string())?;
let matrix = hermite.root_matrix().map_err(|e| e.to_string())?;
let eigen = GeneralEigenvaluesResult::compute(&matrix).map_err(|e| e.to_string())?;
let imaginary = eigen
    .eigenvalues()
    .iter()
    .map(|z| z.im.abs())
    .fold(0.0_f64, f64::max);
let mut comrade: Vec<f64> = eigen.eigenvalues().iter().map(|z| z.re).collect();
comrade.sort_by(f64::total_cmp);

// 別の規約: 確率論の He_n の零点を √2 で割ると H_n の零点になる。
let probabilists = OrthogonalFamily::<f64>::HermiteHe
    .zeros(n)
    .map_err(|e| e.to_string())?;
let rows: Vec<(usize, f64, f64, f64)> = roots
    .iter()
    .enumerate()
    .map(|(j, &x)| (j + 1, x, comrade[j] - x, probabilists[j] / SQRT_2 - x))
    .collect();
let max_gap = |column: fn(&(usize, f64, f64, f64)) -> f64| {
    rows.iter()
        .map(column)
        .map(f64::abs)
        .fold(0.0_f64, f64::max)
};
let summary = vec![(max_gap(|row| row.2), imaginary, max_gap(|row| row.3))];

let fixed6 = serde_json::json!({ "fractionDigits": 6 });
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let columns = serde_json::json!([
    { "key": "0", "label": "番号 j", "type": "integer" },
    { "key": "1", "label": "零点 r_j（Jacobi 行列）[-]", "type": "number", "format": fixed6 },
    { "key": "2", "label": "comrade 行列 − r_j [-]", "type": "number", "format": sci2 },
    { "key": "3", "label": "He_n の零点/√2 − r_j [-]", "type": "number", "format": sci2 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "comparison" })
);
let columns = serde_json::json!([
    { "key": "0", "label": "comrade 行列との差の最大 [-]", "type": "number", "format": sci2 },
    { "key": "1", "label": "comrade 行列の固有値の虚部の最大 [-]", "type": "number", "format": sci2 },
    { "key": "2", "label": "He_n の零点/√2 との差の最大 [-]", "type": "number", "format": sci2 }
]);
emit_table_with_columns!(
    columns,
    summary,
    metadata = serde_json::json!({ "id": "summary" })
);
```

既定の $n=8$ では、comrade 行列の固有値はすべて実数（虚部の最大 0）で、`zeros` の値との差は $7.5\times10^{-15}$ 以下である。
$He_n$ の零点を $\sqrt2$ で割った値との差も $6.7\times10^{-15}$ 以下で、二つの規約の尺度の関係が数値でも成り立つ。
これらの一致は有限精度での数値の一致であり、零点を厳密に含む区間を求めたものではない。

## まとめ

Hermite の零点は三項漸化式から作る対称三重対角の Jacobi 行列の固有値であり、量子調和振動子の波動関数の節の位置でもある。
和・二乗和はトレース、交互配置は主部分行列の固有値の性質から導かれ、それぞれ独立な検算として使える。
comrade 行列と確率論の規約による計算は、同じ零点を別のアルゴリズムと別の規約から求め直す検算になる。
物理学者と確率論の規約では零点の尺度が $\sqrt2$ 倍異なり、二乗和は $n(n-1)/2$ と $n(n-1)$ になるので、求積の節点や期待値に使う前にどちらの規約かを確かめる。
物理の長さに戻すときは、無次元の零点に $\ell=\sqrt{\hbar/(m\omega)}$ を掛ける。
