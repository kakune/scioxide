各例題は SciOxide の API で求めた結果を、閉形式・出典のある基準値・別のアルゴリズム・代数的な恒等式のどれかと比べる。
グラフだけで精度を判断せず、表の誤差と診断の値も読む。
熱電対の例は温度 [°C] と起電力 [µV] を使い、有理飽和の例は濃度を解離定数で割った無次元量で書く。
ほかの例は無次元である。

## まとめ

補間と近似の例題では、標本点の間の誤差を解析的な関数や係数の閉形式と比べ、減少率を理論の $\rho$ と照合する。
根と極の例題では、残差・後退誤差・条件数・候補の個数を区別し、既知の根や Vieta の関係のような代数的な恒等式で確かめる。
校正式のように出典のある係数は、基準表と丸めの桁の範囲で一致することを先に確かめてから、微分・積分・逆算に使う。
厳密に判定したい性質（交点の個数や接触）は、浮動小数点の候補とは別に、有理数の厳密な演算で数える。
