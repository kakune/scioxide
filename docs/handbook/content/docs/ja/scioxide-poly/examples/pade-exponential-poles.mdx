指数関数 $e^x$ は有限の点に極を持たないが、有理関数で近似すると分母の零点が極として現れる。
この極は元の関数の特異点ではなく近似が作るもので、その位置は時間積分の安定性（安定関数）にも関係する。
ここでは閉形式の係数から $e^x$ の Padé 近似を作り、`ApproxRationalFunction` で評価して、原点での誤差の主項と極の配置を別々に確かめる。

## 原点での一致条件と閉形式

分子の次数が $m$、分母の次数が $n$ の有理関数 $R_{m,n} = P_m/Q_n$（$Q_n(0) = 1$）のうち

$$
Q_n(x)e^x - P_m(x) = O(x^{m+n+1})
$$

を満たすものを $[m/n]$ Padé 近似と呼ぶ。
未知係数は $P_m$ の $m+1$ 個と $Q_n$ の $n$ 個で、$x^0, \dots, x^{m+n}$ の係数を 0 にする $m+n+1$ 本の一次方程式で決まる。
指数関数ではこの方程式が閉じた形で解ける。

$$
P_m(x) = \sum_{k=0}^m \frac{(m+n-k)!\,m!}{(m+n)!\,(m-k)!\,k!} x^k,
\qquad
Q_n(x) = \sum_{k=0}^n \frac{(m+n-k)!\,n!}{(m+n)!\,(n-k)!\,k!} (-x)^k
$$

$n = 0$ なら $P_m$ は $e^x$ の Taylor 多項式で、$m = 0$ なら $Q_n$ は $e^{-x}$ の Taylor 多項式、$R_{0,n} = 1/Q_n$ はその逆数である。
$[1/1] = (1 + x/2)/(1 - x/2)$ は台形則、$[0/1] = 1/(1-x)$ は後退 Euler 法の安定関数になる（[誤差・次数・安定性](../../../scioxide-ode/algorithms/error-order-and-stability/)）。

`scioxide-poly` は Taylor 係数から Padé 近似を構成する機能を提供しない。
このページでは閉形式の係数を `ApproxRationalFunction` に渡して評価だけを行う。
Taylor 係数から $[m/n]$ を構成するには [interp の Padé 近似](oxref:interp-pade)の `PadeApproximant` を、標本値から有理近似を作るには [interp の有理近似](../../../scioxide-interp/algorithms/rational-approximation/)の AAA 法を使う。

次の定義のブロックは上の閉形式を Rust の関数にしたもので、このページの二つのセルが使う。
`pade_coefficients(m, n)` は $P_m$ と $Q_n$ の係数を昇べき順に返し、$Q_n$ は $(-x)^k$ を展開した符号で持つ。
入力の範囲 $m,n\le5$ では $11!$ までの階乗しか使わず、階乗は `f64` で正確に表せるので、係数の誤差は割り算の丸めだけである。

```rust
//| id: poly-pade-model
//| kind: definitions
//| title: 指数関数の Padé 近似の閉形式の係数
//| crates: []
/// k! を f64 の積で返す。22! までは正確に表せる。
pub(crate) fn factorial(k: usize) -> f64 {
    (1..=k).map(|j| j as f64).product()
}

/// e^x の [m/n] Padé 近似の分子 P_m と分母 Q_n の係数（昇べき順、Q_n(0) = 1）。
pub(crate) fn pade_coefficients(m: usize, n: usize) -> (Vec<f64>, Vec<f64>) {
    // (m+n−k)! d! / ((m+n)! (d−k)! k!)。d は分子なら m、分母なら n。
    let coefficient = |degree: usize, k: usize| {
        factorial(m + n - k) * factorial(degree)
            / (factorial(m + n) * factorial(degree - k) * factorial(k))
    };
    let numerator = (0..=m).map(|k| coefficient(m, k)).collect();
    // Q_n は (−x)^k の和なので、奇数次の係数の符号を反転する。
    let denominator = (0..=n)
        .map(|k| if k % 2 == 0 { 1.0 } else { -1.0 } * coefficient(n, k))
        .collect();
    (numerator, denominator)
}
```

## 誤差の主項と符号

一致条件の左辺の最初の 0 でない項を $C_{m,n}x^{m+n+1}$ と書くと、$Q_n(0)=1$ なので

$$
e^x - R_{m,n}(x) = \frac{Q_n(x)e^x - P_m(x)}{Q_n(x)} = C_{m,n}\,x^{m+n+1} + O(x^{m+n+2})
$$

である。
指数関数では係数が閉じた形で求まり、原点の近くの誤差は次の主項で表される。

$$
e^x - R_{m,n}(x) = \frac{(-1)^n\, m!\, n!}{(m+n)!\,(m+n+1)!}\, x^{m+n+1} + O(x^{m+n+2})
$$

$n = 0$ では Taylor 多項式の剰余の主項 $x^{m+1}/(m+1)!$ に一致する。
誤差を $R - e^x$ の向きで定義すると符号が逆になるので、比べるときは向きをそろえる。
主項は $x \to 0$ の漸近形で、離れた点での上界ではない。
$|x|$ が大きくなると高次の項が効き、$|x|$ が小さすぎると差が評価の丸めの水準に埋もれる。

## 誤差の主項の確認

次のセルは $[m/n]$ を $x = -2^{-j}$（$j = 0, \dots, 12$）で評価し、$e^x - R(x)$ を主項と比べる。
負の実軸では $Q_n$ の各項 $c_k(-x)^k$ がすべて正なので $Q_n > 0$ となり、どの $[m/n]$ も極を持たない。
入力は分子と分母の次数で、零から五までを選ぶ。
参照値 $e^x$ には `f64` の固有メソッド `exp` を使い、SciOxide の評価とは独立な検算とする。
`evaluate_parts` が返す `ApproximateRationalEvaluation` は、値とともに分子・分母の評価の条件のレポートを持つ。
その相対前進誤差の推定（丸めのモデル $\gamma_k\kappa$ による一次の推定で、上界ではない）の和に $|R|$ を掛けたものを評価誤差の目安として表に並べ、観測した差がそれより小さい行は丸めの水準とみなす。
差がちょうど 0 になる点では比を定義せず、表では「誤差 0」と示し、対数軸の図からも除く。

```rust
//| id: poly-pade-exponential
//| ref: poly-pade-exponential
//| title: Padé 近似の誤差と主項
//| run: reactive
//| uses: [poly-pade-model]
//| crates: [scioxide-poly]
//| inputs:
//|   numerator_degree: {"type":"range","label":"分子の次数 m [-]","min":0,"max":5,"step":1,"value":2}
//|   denominator_degree: {"type":"range","label":"分母の次数 n [-]","min":0,"max":5,"step":1,"value":2}
//| cases:
//|   - {"id":"taylor","label":"[4/0]（Taylor 多項式）","description":"誤差は Taylor の剰余の主項 x⁵/5! に従い、比は正のまま 1 に近づく。","inputs":{"numerator_degree":4,"denominator_degree":0}}
//|   - {"id":"diagonal-5","label":"[5/5]","description":"主項が x = −1 でも 10⁻¹⁰ 程度で、|x| ≤ 1/4 ではほとんどの点が丸めの水準に入る。","inputs":{"numerator_degree":5,"denominator_degree":5}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"leading","path":"/rows/0/0","approx":{"value":1.3888888888888889e-3,"rtol":1e-12}}
//|       - {"artifact":"errors","path":"/rows/0/3","approx":{"value":0.39,"atol":0.01}}
//|       - {"artifact":"errors","path":"/rows/7/3","approx":{"value":0.992,"atol":2e-3}}
//|       - {"artifact":"errors","path":"/rows/12/3","equals":null}
//|   - case: taylor
//|     expect:
//|       - {"artifact":"leading","path":"/rows/0/0","approx":{"value":8.333333333333333e-3,"rtol":1e-12}}
//|       - {"artifact":"errors","path":"/rows/7/3","approx":{"value":0.998,"atol":2e-3}}
//|   - case: diagonal-5
//|     expect:
//|       - {"artifact":"errors","path":"/rows/0/2","approx":{"value":9.94e-11,"rtol":1e-3}}
//|       - {"artifact":"errors","path":"/rows/0/3","approx":{"value":0.377,"atol":0.01}}
use scioxide_poly::{ApproxPolynomial, ApproxRationalFunction};

let (m, n) = (numerator_degree as usize, denominator_degree as usize);
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let sig4 = serde_json::json!({ "significantDigits": 4 });
let (p, q) = pade_coefficients(m, n);
let numerator = ApproxPolynomial::monomial(p).map_err(|e| e.to_string())?;
let denominator = ApproxPolynomial::monomial(q).map_err(|e| e.to_string())?;
let rational =
    ApproxRationalFunction::new(numerator, denominator).map_err(|e| e.to_string())?;
// 主項の係数 (−1)^n m! n! / ((m+n)! (m+n+1)!)
let sign = if n % 2 == 0 { 1.0 } else { -1.0 };
let leading = sign * factorial(m) * factorial(n) / (factorial(m + n) * factorial(m + n + 1));

let (mut rows, mut observed, mut predicted, mut floor) =
    (Vec::new(), Vec::new(), Vec::new(), Vec::new());
for j in 0..=12 {
    let x = -1.0 / (1_u32 << j) as f64;
    let evaluation = rational.evaluate_parts(x).map_err(|e| e.to_string())?;
    let value = evaluation.value();
    // 評価誤差の目安: 分子・分母の相対前進誤差の推定の和に |R| を掛ける
    let numerator_error = evaluation.numerator().condition().forward_error_estimate();
    let denominator_error = evaluation
        .denominator()
        .condition()
        .forward_error_estimate();
    let estimate = (numerator_error + denominator_error) * value.abs();
    // 独立検算: 参照値は f64 の固有メソッド exp（SciOxide の関数を通らない）、主項は閉形式
    let error = x.exp() - value;
    let term = leading * x.powi((m + n + 1) as i32);
    // 誤差が 0 の点では比を定義しない。
    let ratio = (error != 0.0).then_some(error / term);
    rows.push((x, error, term, ratio, estimate));
    // 対数軸に描けない誤差 0 の点は図から除き、件数を表に出す。
    if error != 0.0 {
        observed.push([-x, error.abs()]);
    }
    predicted.push([-x, term.abs()]);
    floor.push([-x, estimate]);
}
emit_table_with_columns!(
    serde_json::json!([
        { "key": "0", "label": "x [-]", "type": "number", "format": sci3 },
        { "key": "1", "label": "e^x − R(x) [-]", "type": "number", "format": sci3 },
        { "key": "2", "label": "主項 [-]", "type": "number", "format": sci3 },
        { "key": "3", "label": "比 [-]", "type": "number", "format": sig4, "nullText": "誤差 0" },
        { "key": "4", "label": "評価誤差の目安 [-]", "type": "number", "format": sci3 }
    ]),
    rows,
    metadata = serde_json::json!({ "id": "errors" })
);
emit_table_with_columns!(
    serde_json::json!([
        { "key": "0", "label": "主項の係数 [-]", "type": "number", "format": sci3 },
        { "key": "1", "label": "次数 m+n+1", "type": "integer" },
        { "key": "2", "label": "誤差が 0 で図から除いた点の数", "type": "integer" }
    ]),
    vec![(leading, m + n + 1, 13 - observed.len())],
    metadata = serde_json::json!({ "id": "leading" })
);
emit_line_chart!(
    &vec![
        serde_json::json!({
            "name": "|e^x − R(x)|",
            "points": observed,
            "style": { "symbol": "circle", "showSymbol": true }
        }),
        serde_json::json!({
            "name": "主項の絶対値",
            "points": predicted,
            "style": { "lineType": "dashed" }
        }),
        serde_json::json!({
            "name": "評価誤差の目安",
            "points": floor,
            "style": { "lineType": "dotted" }
        })
    ],
    options = &serde_json::json!({
        "xLabel": "原点からの距離 |x|（x < 0）[-]",
        "yLabel": "絶対誤差 [-]",
        "xType": "log",
        "yType": "log"
    })
);
```

既定の $[2/2]$ では主項の係数は $1/720 \approx 1.39 \times 10^{-3}$ で、比は $x = -1$ の $0.39$ から、$x = -2^{-7}$ の $0.992$ まで 1 に近づく。
比の 1 からのずれ（$0.61$、$0.38$、$0.22$、$0.12$、…）は $|x|$ を半分にするごとに半分に近い割合で減り、これは主項の次の $O(x^{m+n+2})$ の項の効果である。
評価誤差の目安は $1.3 \times 10^{-15}$ 程度で、$x = -2^{-8}$ では観測した差 $1.2 \times 10^{-15}$ がこれを下回り、比は $0.967$ と 1 から離れる。
$x = -2^{-9}$ より原点に近い 4 点では差が 0 になり、そこから先は丸めの水準である。
図では観測点が傾き $m+n+1 = 5$ の破線に沿い、点線の水準に近づいたところで破線から離れる。
主項の符号は $(-1)^n$ と $x^{m+n+1}$ の符号の積で決まり、丸めの水準より上の点では観測した差の符号もそれに一致するので、どの $m, n$ でも比は正のまま 1 に近づく。

$[4/0]$ は Taylor 多項式で、主項は剰余の $x^5/5!$ になり、比は $x=-1$ の $0.85$ から $x=-2^{-7}$ の $0.999$ まで 1 に近づく。
$[5/5]$ のように $m+n$ が大きいと、主項は $x = -1$ でも $9.9 \times 10^{-11}$ で、比は $0.38$ にとどまり、主項だけでは誤差を表せない。
$x = -1/4$ では差がすでに 0 になり、それより原点側では、比は定義されないか、丸めの水準の差を極めて小さい主項で割った $10^{3}$ を超える値になる。

## 極の位置と虚軸上の絶対値

### 極の半平面と Vieta の関係

$R_{m,n}$ の極は $Q_n$ の零点である。
Saff と Varga（Numer. Math. 25, 1975）は、$e^z$ の $[m/n]$ Padé 近似の極がすべて半平面 $\operatorname{Re} z > m - n$ にあることを示した。
このページの二つ目のセルで、入力の範囲 $m \le 5$、$1 \le n \le 5$ についてこの境界を確かめる。
$m \ge n$ なら極はすべて右半平面にあり、$[1/1]$ の極は $z = 2$、$[2/2]$ の極は $3 \pm i\sqrt{3}$ である。
$m < n$ では極が左半平面に入ることがあり、$[0/5]$ には実部が $-0.24$ の共役な極の対がある。
$e^{-x}$ の Padé 近似は $x$ を $-x$ に置き換えたものなので、極は鏡映の半平面 $\operatorname{Re} z < n - m$ に移る。
指数関数の近似の極が左半平面に並ぶという言い方は、この $e^{-x}$ の場合を指すので、$e^x$ と混同しない。

閉形式の係数から、極の和と積も計算できる。
$Q_n$ の $x^n$ と $x^{n-1}$ と定数項の係数の比を Vieta の関係に代入すると、次の式が得られる。

$$
\sum_{i} z_i = (m+1)\,n, \qquad \prod_i z_i = \frac{(m+n)!}{m!}
$$

この二つは固有値計算とは独立な検算になる。

### 対角近似と A 安定性

対角近似 $m = n$ では $P_n(z) = Q_n(-z)$ が成り立つ。
実係数なので $z = iy$ では $Q_n(-iy) = \overline{Q_n(iy)}$ となり、分母が 0 でなければ $|R_{n,n}(iy)| = 1$ である。
これは虚軸上で絶対値が正確に 1 であるという性質で、位相 $\arg R_{n,n}(iy)$ が $y$ に一致することは意味しない。

時間積分では $R$ を安定関数とし、左半平面で $|R(z)| \le 1$ となる性質を A 安定性と呼ぶ。
$[m/n]$ が A 安定であるのは $m \le n \le m + 2$ のときに限る（Ehle の予想、Wanner・Hairer・Nørsett が 1978 年に証明）。
$n \ge m + 3$ では、極がすべて右半平面にある $[0/3]$ でも、小さい $y$ で $|R(iy)|^2 = 1/(1 - y^4/12 + y^6/36)$ が 1 を超え、虚軸の上で $|R(iy)| > 1$ となる。

次のセルは分母の根を固有値に持つ行列（根を固有値に持つ行列）の固有値として極を求め、Vieta の関係と半平面 $\operatorname{Re} z > m - n$ を確かめる。
根を固有値に持つ行列の構成は[根を固有値に持つ行列と根の感度](../../algorithms/root-conditioning/)、固有値の計算は scioxide-linalg が受け持つ。
`ApproxRationalFunction::new` は分母がモニックになるように分子と分母を同じ数で割るので、`denominator()` の根を固有値に持つ行列は $Q_n$ を最高次の係数で割った多項式から作られ、根は変わらない。
表の「虚部」は、実数になるはずの和と積に固有値計算が残した虚部である。
虚軸上では $y = 0, 0.5, 1, 2$ で $|R(iy)|$ を評価する。
分母が定数（$n = 0$）では極がないので、分母の次数は 1 以上を選ぶ。
対角でない場合は、虚軸上の絶対値が 1 になるとは限らない。

```rust
//| id: poly-pade-poles
//| ref: poly-pade-poles
//| title: Padé 近似の極と虚軸上の絶対値
//| run: reactive
//| uses: [poly-pade-model]
//| crates: [scioxide-core, scioxide-linalg, scioxide-poly]
//| inputs:
//|   numerator_degree: {"type":"range","label":"分子の次数 m [-]","min":0,"max":5,"step":1,"value":2}
//|   denominator_degree: {"type":"range","label":"分母の次数 n [-]","min":1,"max":5,"step":1,"value":2}
//| cases:
//|   - {"id":"order-0-3","label":"[0/3]","description":"極はすべて右半平面にあるが、n ≥ m + 3 なので小さい y で |R(iy)| が 1 を超える。","inputs":{"numerator_degree":0,"denominator_degree":3}}

//|   - {"id":"diagonal-5","label":"[5/5]","description":"極は右半平面に並び、Vieta の関係が 10⁻¹⁵ 程度の相対差で成り立つ。","inputs":{"numerator_degree":5,"denominator_degree":5}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"vieta","path":"/rows/1/1","approx":{"value":6.0,"rtol":1e-12}}
//|       - {"artifact":"vieta","path":"/rows/2/1","approx":{"value":12.0,"rtol":1e-12}}
//|       - {"artifact":"vieta","path":"/rows/3/1","approx":{"value":3.0,"rtol":1e-12}}
//|       - {"artifact":"axis","path":"/rows/3/2","approx":{"value":0.0,"atol":1e-14}}
//|   - case: order-0-3
//|     expect:
//|       - {"artifact":"axis","path":"/rows/1/1","approx":{"value":1.00240,"rtol":1e-5}}
//|       - {"artifact":"axis","path":"/rows/3/1","approx":{"value":0.83205,"rtol":1e-4}}
//|       - {"artifact":"vieta","path":"/rows/3/1","range":{"min":0.0}}
//|   - case: order-0-5
//|     expect:
//|       - {"artifact":"vieta","path":"/rows/3/1","range":{"min":-5.0,"max":0.0}}
//|       - {"artifact":"vieta","path":"/rows/2/1","approx":{"value":120.0,"rtol":1e-12}}
//|   - case: diagonal-5
//|     expect:
//|       - {"artifact":"vieta","path":"/rows/1/1","approx":{"value":30.0,"rtol":1e-12}}
//|       - {"artifact":"vieta","path":"/rows/2/1","approx":{"value":30240.0,"rtol":1e-12}}
//|       - {"artifact":"axis","path":"/rows/3/2","approx":{"value":0.0,"atol":1e-14}}
use scioxide_core::Complex;
use scioxide_linalg::GeneralEigenvaluesResult;
use scioxide_poly::{ApproxPolynomial, ApproxRationalFunction};

let (m, n) = (numerator_degree as usize, denominator_degree as usize);
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let digits6 = serde_json::json!({ "significantDigits": 6 });
// 虚軸で評価するため、係数を複素数として持つ
let (p, q) = pade_coefficients(m, n);
let complex = |values: Vec<f64>| values.into_iter().map(|c| Complex::new(c, 0.0)).collect();
let numerator = ApproxPolynomial::monomial(complex(p)).map_err(|e| e.to_string())?;
let denominator = ApproxPolynomial::monomial(complex(q)).map_err(|e| e.to_string())?;
let rational =
    ApproxRationalFunction::new(numerator, denominator).map_err(|e| e.to_string())?;

// 極 = 分母（new がモニックにしたもの）の根を固有値に持つ行列の固有値
let matrix = rational
    .denominator()
    .root_matrix()
    .map_err(|e| e.to_string())?;
let poles = GeneralEigenvaluesResult::compute(&matrix)
    .map_err(|e| e.to_string())?
    .eigenvalues()
    .to_vec();
let sum = poles.iter().fold(Complex::new(0.0, 0.0), |s, &z| s + z);
let product = poles.iter().fold(Complex::new(1.0, 0.0), |s, &z| s * z);
let minimum_real = poles.iter().map(|z| z.re).fold(f64::INFINITY, f64::min);
// 独立検算: Vieta の関係の閉形式と Saff–Varga の境界
let rows = vec![
    ("極の数", poles.len() as f64, n as f64, None),
    ("極の和 (m+1)n", sum.re, ((m + 1) * n) as f64, Some(sum.im)),
    (
        "極の積 (m+n)!/m!",
        product.re,
        factorial(m + n) / factorial(m),
        Some(product.im),
    ),
    (
        "極の実部の最小（境界 m − n より大）",
        minimum_real,
        m as f64 - n as f64,
        None,
    ),
];
emit_table_with_columns!(
    serde_json::json!([
        { "key": "0", "label": "量" },
        { "key": "1", "label": "固有値から [-]", "type": "number", "format": digits6 },
        { "key": "2", "label": "閉形式・境界 [-]", "type": "number", "format": digits6 },
        { "key": "3", "label": "虚部 [-]", "type": "number", "format": sci3, "nullText": "—" }
    ]),
    rows,
    metadata = serde_json::json!({ "id": "vieta" })
);
let mut axis = Vec::new();
for y in [0.0, 0.5, 1.0, 2.0] {
    let value = rational
        .evaluate(Complex::new(0.0, y))
        .map_err(|e| e.to_string())?;
    axis.push((y, value.norm(), value.norm() - 1.0));
}
emit_table_with_columns!(
    serde_json::json!([
        { "key": "0", "label": "虚軸の y [-]", "type": "number" },
        { "key": "1", "label": "|R(iy)| [-]", "type": "number", "format": digits6 },
        { "key": "2", "label": "|R(iy)| − 1 [-]", "type": "number", "format": sci3 }
    ]),
    axis,
    metadata = serde_json::json!({ "id": "axis" })
);
let pole_points: Vec<_> = poles.iter().map(|z| [z.re, z.im]).collect();
emit_scatter_chart!(
    &vec![serde_json::json!({ "name": "極（分母の零点）", "points": pole_points })],
    options = &serde_json::json!({
        "xLabel": "極の実部 [-]",
        "yLabel": "極の虚部 [-]",
        "xMin": -6.0,
        "xMax": 8.0,
        "yMin": -8.0,
        "yMax": 8.0,
        "annotations": [
            { "kind": "line", "axis": "x", "value": 0.0, "label": "虚軸" },
            {
                "kind": "line",
                "axis": "x",
                "value": m as f64 - n as f64,
                "label": "Re z = m − n（Saff–Varga の境界）",
                "style": { "lineType": "dashed" }
            }
        ]
    })
);
```

既定の $[2/2]$ では極は $3 \pm 1.732i$ で、和 6 と積 12 が閉形式と $3 \times 10^{-16}$ 以下の相対差で一致し、四つの $y$ で $|R(iy)| - 1$ は 0 である。
$[5/5]$ では極の実部が $4.65$ から $7.29$ に並び、和 30 と積 30240 が閉形式と $10^{-15}$ 以下の相対差で一致する。
$[0/5]$ では最小の実部が $-0.240$ で左半平面に入るが、境界 $m - n = -5$ よりは大きい。
同じ $[0/5]$ で $|R(iy)|$ は $y=0.5, 1$ で 1 をわずかに下回り、$y=2$ で $1.009$ と 1 を超えるので、絶対値 1 の性質は対角近似に限られる。
$[0/3]$ の極は $1.596$ と $0.702 \pm 1.807i$ ですべて右半平面にあるが、$|R(0.5i)| = 1.0024$、$|R(i)| = 1.029$ と 1 を超え、$y = 2$ では $0.832$ に下がる。
この三つの値は上の式 $|R(iy)|^2 = 1/(1 - y^4/12 + y^6/36)$ と一致し、A 安定性の条件 $n \le m+2$ を外れることが数値でも分かる。
極の位置は誤差の主項の大きさとは別の情報であり、$x>0$ の実区間で評価するときは実軸上の極（$[0/1]$ の $x = 1$ など）を避ける。

## まとめ

$e^x$ の $[m/n]$ Padé 近似は閉形式の係数で書け、`ApproxRationalFunction` で評価すると、原点の近くの誤差は主項 $(-1)^n m!\,n!\,x^{m+n+1}/((m+n)!(m+n+1)!)$ に従う。
主項との比が 1 に近づく範囲と、`evaluate_parts` の評価誤差の目安を下回る丸めの範囲を分けて読み、$m+n$ が大きいときは $|x|=1$ でも主項だけでは誤差を表せないことに注意する。
極は半平面 $\operatorname{Re} z > m - n$ にあり、$m \ge n$ なら右半平面、$m < n$ では左半平面に入りうるので、「左半平面の極」は $e^{-x}$ の近似を指すときだけ使う。
極は分母の根を固有値に持つ行列の固有値として求め、Vieta の関係の閉形式で検算できる。
対角近似の $|R(iy)| = 1$ は虚軸上の絶対値の性質で、位相の一致や非対角の場合には及ばず、安定関数として使うなら $m \le n \le m+2$ を確かめる。
