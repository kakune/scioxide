受容体とリガンドの結合では、リガンドの濃度が増えると受容体の占有率は 1 に近づく。
この飽和応答は一次式の比で表せ、分子と分母に同じ因子を掛けた式も、その因子の零点を除けば同じ関数を表す。
ここでは、因子が厳密に共通な場合と近いだけの場合を分け、`ApproxRationalFunction::simplify` による約分の判定と、約分が関数値をどれだけ変えるかを調べる。
近似 GCD のアルゴリズムとレポートの定義は[最大公約多項式と近似 GCD](../../algorithms/approximate-gcd/)で説明している。

## 質量作用の法則と有理飽和モデル

受容体 $R$ とリガンド $L$ の一対一の可逆な結合平衡を考える。

$$
R + L \underset{k_{\text{off}}}{\overset{k_{\text{on}}}{\rightleftharpoons}} RL
$$

結合の速度定数を $k_{\text{on}}$（単位は濃度⁻¹·時間⁻¹）、解離の速度定数を $k_{\text{off}}$（単位は時間⁻¹）とする。
平衡では両方向の速度が等しく、$k_{\text{on}}[R][L] = k_{\text{off}}[RL]$ が成り立つ。
解離定数を $K_d = k_{\text{off}} / k_{\text{on}} = [R][L]/[RL]$（単位は濃度、たとえば nM）とおく。
全受容体の濃度を $[R]_{\text{tot}} = [R] + [RL]$ とする。
リガンドが受容体より十分多く、結合による減少を無視して自由リガンドの濃度 $[L]$ を一定とみなせるとき、受容体の占有率（fractional occupancy）は次のようになる。

$$
\theta = \frac{[RL]}{[R]_{\text{tot}}} = \frac{[RL]}{[R] + [RL]} = \frac{[L]/K_d}{1 + [L]/K_d}
$$

無次元の濃度 $x = [L] / K_d$ を使うと、標準形の有理飽和関数が得られる。

$$
\theta(x) = \frac{x}{1 + x} \quad (x \ge 0)
$$

これは Langmuir の吸着等温式や Hill 係数 1 の結合曲線と同じ形である。
この関数は $x \ll 1$ で線形の応答 $\theta(x) \approx x$ を示し、半飽和の濃度 $x = 1$（$[L] = K_d$）で $\theta(1) = 0.5$ となり、$x \to \infty$ で 1 に近づく。
飽和までの残り $1 - \theta(x) = 1/(1 + x)$ は $O(1/x)$ でしか減らないので、グラフで水平に見えても飽和しきってはいない。
占有率を 90% にするには $x = 9$、99% にするには $x = 99$ が必要である。
同じ形は酵素反応の Michaelis–Menten 式 $v/V_{\max} = c/(K_m + c)$ にも現れる。

## 共通因子と可除特異点

モデルを合成したりパラメータを同定したりする過程で、分子と分母に同じ一次式 $(x - r)$ が掛かることがある。

$$
\theta_{\text{raw}}(x) = \frac{x(x - r)}{(x + 1)(x - r)} = \frac{x^2 - rx}{x^2 + (1 - r)x - r}
$$

代数的には共通因子 $(x - r)$ を約して簡約形 $\theta(x) = x/(x + 1)$ が得られるが、二つの式は関数として次の点で異なる。

1. 可除特異点：未簡約の式 $\theta_{\text{raw}}$ は $x = r$ で $0/0$ になり、その点では評価できない。
   簡約後の式は $x = r$（$r \ne -1$）で有限の値 $r/(r+1)$ を返す。
2. 極：分母が 0 で分子が 0 でない点 $x = -1$ は極であり、値の絶対値は限りなく大きくなる。
   極は物理領域 $x \ge 0$ の外にあるが、原点での Taylor 展開 $\theta(x) = x - x^2 + x^3 - \cdots$ の収束半径は、原点から最も近い極までの距離 1 になる。

`ApproxRationalFunction::new` は分母をモニックにし、分子を同じ最高次係数で割るだけで、共通因子を自動では約さない。
未簡約の式を $x = r$ で `evaluate` すると、分母が 0 なので `DomainError` が返る。
約分は `simplify` を呼んだときに行う。
`simplify` は近似 GCD $g$ を求め、分子と分母をそれぞれ $g$ で割った商を新しい分子と分母にする。
割り算の剰余の係数の最大絶対値を、元の分子（分母）の係数の最大絶対値で割った値を正規化剰余と呼ぶ。
二つの正規化剰余がどちらも方針の許容誤差 $\varepsilon_{\rm abs}/\max_i|a_i| + \varepsilon_{\rm rel}$ 以下のときだけ約分を受け入れる。
既定の方針では $\varepsilon_{\rm abs} = \varepsilon_{\rm rel} = \sqrt{\varepsilon} \approx 1.5 \times 10^{-8}$ である。

次の定義のブロックはこのページの三つのセルが共有する。
`rational_from_roots` は分子と分母の根から $\prod_i(x-a_i)/\prod_j(x-b_j)$ を `ApproxPolynomial::from_roots_with_options` と `ApproxRationalFunction::new` で作り、共通因子は約さない。
`coefficient_pair` と `from_coefficient_pair` は、セルの間で有理関数を分子と分母の係数の組として受け渡す。
`compare` は各点 $x$ で元の式と約分後の式を `evaluate` で評価し、$(x, \text{元の値}, \text{約分後の値})$ を返す。

```rust
//| id: poly-rational-saturation-model
//| kind: definitions
//| title: 根から作る有理関数と約分前後の比較
//| crates: [scioxide-poly]
use scioxide_poly::{
    ApproxPolynomial, ApproxRationalFunction, PolynomialApproximationPolicy, PolynomialBasis,
};

/// ∏(x − aᵢ) / ∏(x − bⱼ) を共通因子を約さずに作る。
pub(crate) fn rational_from_roots(
    numerator_roots: &[f64],
    denominator_roots: &[f64],
    policy: PolynomialApproximationPolicy<f64>,
) -> Result<ApproxRationalFunction<f64>, String> {
    let numerator = ApproxPolynomial::from_roots_with_options(numerator_roots, policy)
        .map_err(|e| e.to_string())?;
    let denominator = ApproxPolynomial::from_roots_with_options(denominator_roots, policy)
        .map_err(|e| e.to_string())?;
    ApproxRationalFunction::new(numerator, denominator).map_err(|e| e.to_string())
}

/// 分子と分母の係数（昇べき順）の組。セルの間で有理関数を受け渡すのに使う。
pub(crate) fn coefficient_pair(rational: &ApproxRationalFunction<f64>) -> [Vec<f64>; 2] {
    [
        rational.numerator().basis().coefficients().to_vec(),
        rational.denominator().basis().coefficients().to_vec(),
    ]
}

/// 係数の組から有理関数を作り直す。
pub(crate) fn from_coefficient_pair(
    [numerator, denominator]: [Vec<f64>; 2],
) -> Result<ApproxRationalFunction<f64>, String> {
    let numerator = ApproxPolynomial::monomial(numerator).map_err(|e| e.to_string())?;
    let denominator = ApproxPolynomial::monomial(denominator).map_err(|e| e.to_string())?;
    ApproxRationalFunction::new(numerator, denominator).map_err(|e| e.to_string())
}

/// 各点 x での (x, 元の式の値, 約分後の式の値)。
pub(crate) fn compare(
    original: &ApproxRationalFunction<f64>,
    reduced: &ApproxRationalFunction<f64>,
    points: impl IntoIterator<Item = f64>,
) -> Result<Vec<(f64, f64, f64)>, String> {
    points
        .into_iter()
        .map(|x| {
            let before = original.evaluate(x).map_err(|e| e.to_string())?;
            let after = reduced.evaluate(x).map_err(|e| e.to_string())?;
            Ok((x, before, after))
        })
        .collect()
}
```

## 厳密な共通因子の約分

次のセルは物理領域の外の $r < 0$ について $\theta_{\text{raw}}$ を作り、既定の方針の `simplify` で約分する。
入力は共通因子の根 $r$ である。
1 つ目の表は近似 GCD の次数、Sylvester 行列の逆条件数とランク閾値の相対値を示す。
2 つ目の表は分子と分母の次数と約分後の係数を、$x/(x+1)$ の係数 $[0, 1]$ と $[1, 1]$ と比べられる形で示す。
独立検算は約分後の係数と $x/(x+1)$ の係数との比較である。
元の式と約分後の式は次のセルへ渡し、物理区間での値を比べる。

```rust
//| id: poly-rational-saturation
//| ref: poly-rational-saturation
//| title: 飽和応答の有理式を診断付きで約分する
//| run: reactive
//| uses: [poly-rational-saturation-model]
//| crates: [scioxide-poly]
//| exports: [original, reduced]
//| inputs:
//|   removable_root: {"type":"range","label":"共通因子の根 r [-]","description":"物理領域の外にある可除特異点の位置を変える。","min":-6,"max":-0.5,"step":0.5,"value":-2}
//| cases:
//|   - {"id":"double-pole","label":"r = −1","description":"分母が (x + 1)² になり、一つ約しても極 x = −1 は残る。","inputs":{"removable_root":-1}}
//|   - {"id":"rounded-factor","label":"r = −1.5","description":"約分後の係数に丸めの程度の誤差が残る。","inputs":{"removable_root":-1.5}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"summary","path":"/rows/0/0","equals":1}
//|       - {"artifact":"summary","path":"/rows/0/1","range":{"max":8.8e-16}}
//|       - {"artifact":"parts","path":"/rows/0/3","approx":{"value":0,"atol":1e-15}}
//|       - {"artifact":"parts","path":"/rows/1/3","approx":{"value":1,"atol":1e-15}}
//|   - case: double-pole
//|     expect:
//|       - {"artifact":"parts","path":"/rows/1/2","equals":1}
//|       - {"artifact":"parts","path":"/rows/1/3","approx":{"value":1,"atol":1e-15}}
//|   - case: rounded-factor
//|     expect:
//|       - {"artifact":"summary","path":"/rows/0/0","equals":1}
//|       - {"artifact":"parts","path":"/rows/0/5","range":{"max":1e-15}}
use scioxide_poly::{
    ApproxPolynomial, MonomialBasis, PolynomialApproximationPolicy, PolynomialBasis,
};

// 分子 x(x − r)、分母 (x + 1)(x − r) を既定の方針で作る
let r = removable_root;
let policy = PolynomialApproximationPolicy::default();
let model = rational_from_roots(&[0.0, r], &[-1.0, r], policy)?;
// 近似 GCD を求めて共通因子 (x − r) を約分する
let simplification = model.simplify().map_err(|e| e.to_string())?;
let simplified = simplification.rational();
let report = simplification.gcd_report();
// ランク閾値の相対値 τ/σ_max（零の入力では Sylvester 行列を作らないので None）
let threshold = report
    .sylvester_rank()
    .map(|rank| rank.threshold() / rank.scale());
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let exact = serde_json::json!({ "significantDigits": 17 });
let summary_columns = serde_json::json!([
    { "key": "0", "label": "近似 GCD の次数", "type": "integer" },
    { "key": "1", "label": "逆条件数 [-]", "type": "number", "format": sci3, "nullText": "なし" },
    { "key": "2", "label": "閾値 τ/σ_max [-]", "type": "number", "format": sci3, "nullText": "なし" }
]);
emit_table_with_columns!(
    summary_columns,
    vec![(
        report.effective_degree(),
        report.reciprocal_condition(),
        threshold
    )],
    metadata = serde_json::json!({ "id": "summary" })
);
// 部分ごとの次数、約分後の係数（昇べき順）、正規化剰余
type Monomial = ApproxPolynomial<f64, MonomialBasis<f64>>;
let part = |name: &'static str, before: &Monomial, after: &Monomial, error: f64| {
    let coefficients = after.basis().coefficients();
    let linear = coefficients.get(1).copied();
    (
        name,
        before.degree(),
        after.degree(),
        coefficients[0],
        linear,
        error,
    )
};
let parts_columns = serde_json::json!([
    { "key": "0", "label": "部分" },
    { "key": "1", "label": "元の次数", "type": "integer" },
    { "key": "2", "label": "約分後の次数", "type": "integer" },
    { "key": "3", "label": "約分後の定数項 [-]", "type": "number", "format": exact },
    { "key": "4", "label": "約分後の 1 次の係数 [-]", "type": "number", "format": exact, "nullText": "なし" },
    { "key": "5", "label": "正規化剰余 [-]", "type": "number", "format": sci3 }
]);
let numerator_error = simplification.numerator_error();
let denominator_error = simplification.denominator_error();
emit_table_with_columns!(
    parts_columns,
    vec![
        part(
            "分子",
            model.numerator(),
            simplified.numerator(),
            numerator_error
        ),
        part(
            "分母",
            model.denominator(),
            simplified.denominator(),
            denominator_error
        ),
    ],
    metadata = serde_json::json!({ "id": "parts" })
);
export!(original, &coefficient_pair(&model));
export!(reduced, &coefficient_pair(simplified));
```

既定の $r = -2$ では近似 GCD の次数は 1 で、分子と分母はどちらも 2 次から 1 次になり、約分後の係数は $[0, 1]$ と $[1, 1]$ に正確に一致する。
$r$ を $-6$ から $-0.5$ まで 0.5 刻みの 12 通りに動かしても次数は 1 である。
Sylvester 行列の逆条件数は $1.8 \times 10^{-18}$（$r = -5.5$）から $5.8 \times 10^{-17}$（$r = -1.5$）の範囲にある。
これは既定のランクの方針 `DimensionScaledEpsilon` の相対閾値 $\tau = 4\varepsilon \approx 8.9 \times 10^{-16}$（4 は Sylvester 行列の次数）を下回る。
12 通りのうち 10 通りでは正規化剰余が 0 である。
$r = -1.5$ では分子の側の正規化剰余が $2.2 \times 10^{-16}$ になり、約分後の係数も $[2.2 \times 10^{-16}, 1]$ と $[1 + 2.2 \times 10^{-16}, 1]$ になる。
$r = -4$ では正規化剰余が分子で $8.9 \times 10^{-16}$、分母で $5.3 \times 10^{-16}$ になる。
どの値も丸めの程度で、ネイティブの実行では最後の桁が変わることがある。
共通因子は係数の上では正確に割り切れても、近似 GCD の因子は特異ベクトルと最小二乗の精度改善から作るので、丸めの程度の誤差を持ちうる。
$r = -1$ では分母が $(x+1)^2$ となり、共通因子 $(x+1)$ を一つ約しても極 $x = -1$ は残る。

## 物理区間での値と飽和

次のセルは前のセルの元の式と約分後の式を受け取り、物理区間 $[0, x_{\max}]$ の 201 点で値を比べる。
入力は表示する最大濃度 $x_{\max}$ である。
表は二つの式の値の最大差、$\theta(1)$、$\theta(x_{\max})$ と飽和までの残り $1-\theta(x_{\max})$ を示す。
独立検算は半飽和の値 $\theta(1) = 0.5$ と閉形式 $1 - \theta(x) = 1/(1+x)$ との比較である。
グラフでは元の式を破線、約分後の式を実線で描き、二つの曲線が重なることを確かめる。

```rust
//| id: poly-rational-saturation-curve
//| ref: poly-rational-saturation-curve
//| title: 約分前後の飽和曲線を物理区間で比べる
//| run: reactive
//| uses: [poly-rational-saturation-model]
//| crates: [scioxide-poly]
//| dependsOn:
//|   cancellation: poly-rational-saturation
//| inputs:
//|   maximum_concentration: {"type":"range","label":"表示する最大濃度 x_max [-]","description":"線形域から飽和域までの範囲を変える。","min":2,"max":30,"step":1,"value":12}
//| cases:
//|   - {"id":"wide-range","label":"x_max = 30","description":"表示範囲を広げても飽和までの残りは 3% ある。","inputs":{"maximum_concentration":30}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"values","path":"/rows/0/0","range":{"max":1e-15}}
//|       - {"artifact":"values","path":"/rows/0/1","approx":{"value":0.5,"atol":1e-15}}
//|       - {"artifact":"values","path":"/rows/0/3","approx":{"value":0.07692307692307693,"rtol":1e-12}}
//|   - case: wide-range
//|     expect:
//|       - {"artifact":"values","path":"/rows/0/3","approx":{"value":0.03225806451612903,"rtol":1e-12}}
let read = |name: &str| -> Result<[Vec<f64>; 2], String> {
    serde_json::from_value(cancellation[name].clone()).map_err(|e| e.to_string())
};
let original = from_coefficient_pair(read("original")?)?;
let reduced = from_coefficient_pair(read("reduced")?)?;
// 物理区間 [0, x_max] の 201 点で元の式と約分後の式を比べる
let grid = (0..=200).map(|i| maximum_concentration * i as f64 / 200.0);
let values = compare(&original, &reduced, grid)?;
let difference = values
    .iter()
    .map(|&(_, before, after)| (before - after).abs())
    .fold(0.0_f64, f64::max);
let half = reduced.evaluate(1.0).map_err(|e| e.to_string())?;
let at_maximum = values[200].2;
// 独立検算: 1 − θ(x_max) を閉形式 1/(1 + x_max) と比べる
let closed = 1.0 / (1.0 + maximum_concentration);
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let fixed6 = serde_json::json!({ "fractionDigits": 6 });
let columns = serde_json::json!([
    { "key": "0", "label": "元の式との最大差 [-]", "type": "number", "format": sci3 },
    { "key": "1", "label": "θ(1) [-]", "type": "number", "format": fixed6 },
    { "key": "2", "label": "θ(x_max) [-]", "type": "number", "format": fixed6 },
    { "key": "3", "label": "飽和までの残り 1 − θ [-]", "type": "number", "format": fixed6 },
    { "key": "4", "label": "1/(1 + x_max) との差 [-]", "type": "number", "format": sci3 }
]);
emit_table_with_columns!(
    columns,
    vec![(
        difference,
        half,
        at_maximum,
        1.0 - at_maximum,
        1.0 - at_maximum - closed
    )],
    metadata = serde_json::json!({ "id": "values" })
);
// 約分後の θ = x / (x + 1) は x → ∞ で 1 に近づく
let original_curve: Vec<_> = values.iter().map(|&(x, before, _)| [x, before]).collect();
let reduced_curve: Vec<_> = values.iter().map(|&(x, _, after)| [x, after]).collect();
let dashed = serde_json::json!({ "lineType": "dashed" });
emit_line_chart!(
    &vec![
        serde_json::json!({ "name": "元の式", "points": original_curve, "style": dashed }),
        serde_json::json!({ "name": "約分後の θ(x)", "points": reduced_curve }),
    ],
    options = &serde_json::json!({
        "xLabel": "無次元濃度 x = [L]/K_d [-]",
        "yLabel": "占有率 θ [-]",
        "yMin": 0.0,
        "yMax": 1.0,
        "annotations": [
            { "kind": "line", "axis": "y", "value": 1.0, "label": "飽和 θ = 1", "style": dashed }
        ]
    })
);
```

既定の $r = -2$、$x_{\max} = 12$ では、二つの式の値の最大差は $2.2 \times 10^{-16}$ で、$\theta(1) = 0.5$ である。
前のセルの $r$ を $-6$ から $-0.5$ まで動かすと、最大差は $r = -4$ のときに最も大きく $8.9 \times 10^{-16}$ になるが、どの $r$ でも丸めの程度にとどまる。
飽和までの残り $1 - \theta(x)$ は $x = 12$ で $0.077$（約 7.7%）、$x = 30$ でも $0.032$（約 3.2%）で、閉形式 $1/(1+x)$ と丸めの程度で一致する。
最大濃度の入力で表示範囲を広げても、$1/(x+1)$ の割合でしか飽和に近づかない。

## 近い共通因子の簡約

分子 $x(x+2)$、分母 $(x+1)(x+2+\delta)$ の有理関数は、$\delta \ne 0$ なら共通因子を持たない。
これは可除特異点を持つモデルの係数が測定や同定の誤差で $\delta$ だけずれた状況にあたる。
それでも、方針 `PolynomialApproximationPolicy` のランク閾値 $\tau$ が Sylvester 行列の逆条件数より大きければ、近似 GCD は次数 1 の因子 $x + c$（$c \approx 2$）を選ぶ。
正確には、平衡化した Sylvester 行列の特異値のうち $\tau\,\sigma_{\max}$ 以下のものを零とみなし、その個数を GCD の次数とする。
`simplify` は、各入力を $x + c$ で割った正規化剰余が許容誤差の相対値以下のときだけ約分を受け入れ、そうでなければ `NumericalInstability`（`IllConditioned`）を返す。
受け入れたとき、簡約後の関数は元の関数と異なる。
剰余の定理（$p(x)$ を $x + c$ で割った剰余は $p(-c)$）と組立除法から、簡約後の式と二つの正規化剰余は $c$ の閉形式で書ける。

$$
\frac{x + 2 - c}{x + 3 + \delta - c}, \qquad
\frac{|c^2 - 2c|}{2}, \qquad
\frac{|c^2 - (3+\delta)c + 2 + \delta|}{3 + \delta}
$$

分母の 2 と $3 + \delta$ はそれぞれ分子と分母の係数の絶対値の最大である。
$c$ は 2 と $2 + \delta$ の間の値になるので、簡約後の式の原点での値 $(2 - c)/(3 + \delta - c)$ は $-\delta$ の程度の負の値になる。
元の式が厳密に持っていた零点 $x = 0$（占有率 0）が、簡約によって失われる。

次のセルの入力は摂動 $\delta = 2^{-p}$ の $p$、ランク閾値 $\tau = 2^{-q_r}$ の $q_r$、許容誤差の相対値 $2^{-q_t}$ の $q_t$ である。
許容誤差の絶対値は 0 にする。
近似 GCD のレポートは `approximate_gcd` で別に求め、簡約が拒否された場合でも次数と剰余を表示する。
1 つ目の表は逆条件数、ランク閾値、選ばれた次数と GCD の定数項 $c$ を示す。
2 つ目の表は分子と分母の正規化剰余を、$c$ から剰余の定理で計算した値と許容誤差に並べる。
簡約を受け入れた場合は、3 つ目の表で物理区間の五つの濃度について元の式と簡約後の式を比べ、簡約後の値を上の閉形式と照合する。

```rust
//| id: poly-rational-near-cancellation
//| ref: poly-rational-near-cancellation
//| title: 近い因子の簡約と関数値の変化
//| run: reactive
//| uses: [poly-rational-saturation-model]
//| crates: [scioxide-core, scioxide-linalg, scioxide-poly]
//| inputs:
//|   exponent: {"type":"range","label":"摂動 δ=2⁻ᵖ の p","min":12,"max":40,"step":2,"value":30}
//|   rank_power: {"type":"range","label":"ランク閾値 2^(−q_r) の q_r","description":"逆条件数がこれ以下なら共通因子の次数を 1 とする。","min":10,"max":50,"step":2,"value":20}
//|   tolerance_power: {"type":"range","label":"許容誤差 2^(−q_t) の q_t","description":"正規化剰余がこれ以下なら約分を受け入れる。","min":10,"max":50,"step":2,"value":20}
//| cases:
//|   - {"id":"large-perturbation","label":"p = 12","description":"逆条件数がランク閾値を上回り、定数の GCD が選ばれる。","inputs":{"exponent":12}}
//|   - {"id":"strict-tolerance","label":"q_t = 40","description":"次数 1 は選ばれるが、剰余が許容誤差を超えて簡約が拒否される。","inputs":{"tolerance_power":40}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"gcd","path":"/rows/0/3","equals":1}
//|       - {"artifact":"gcd","path":"/rows/0/4","approx":{"value":2,"atol":1e-8}}
//|       - {"artifact":"residuals","path":"/rows/0/1","approx":{"value":1.86e-10,"rtol":0.02}}
//|       - {"artifact":"values","path":"/rows/0/4","approx":{"value":-1.86e-10,"rtol":0.02}}
//|       - {"artifact":"values","path":"/rows/2/3","approx":{"value":0.5,"atol":1e-9}}
//|   - case: large-perturbation
//|     expect:
//|       - {"artifact":"gcd","path":"/rows/0/3","equals":0}
//|       - {"artifact":"values","path":"/rows/0/4","approx":{"value":0,"atol":1e-15}}
//|   - case: strict-tolerance
//|     expect:
//|       - {"artifact":"gcd","path":"/rows/0/3","equals":1}
//|       - {"artifact":"residuals","path":"/rows/1/1","range":{"min":9.1e-13}}
use scioxide_core::{RankThreshold, RealScalar, Tolerance};
use scioxide_linalg::RankPolicy;
use scioxide_poly::{PolynomialApproximationPolicy, PolynomialBasis, approximate_gcd};

let delta = RealScalar::powi(2.0_f64, -(exponent as i32));
let rank_threshold = RealScalar::powi(2.0_f64, -(rank_power as i32));
let tolerance = RealScalar::powi(2.0_f64, -(tolerance_power as i32));
let policy = PolynomialApproximationPolicy::new(
    Tolerance::new(0.0, tolerance).map_err(|e| e.to_string())?,
    RankPolicy::Threshold(RankThreshold::new(0.0, rank_threshold).map_err(|e| e.to_string())?),
);
// 分子 x(x + 2)、分母 (x + 1)(x + 2 + δ)
let rational = rational_from_roots(&[0.0, -2.0], &[-1.0, -2.0 - delta], policy)?;
let gcd =
    approximate_gcd(rational.numerator(), rational.denominator()).map_err(|e| e.to_string())?;
let report = gcd.report();
// 次数 1 なら GCD = x + c。次数 0 なら c は定義されない
let c = match gcd.polynomial().basis().coefficients() {
    [constant, _] => Some(*constant),
    _ => None,
};
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let c16 = serde_json::json!({ "significantDigits": 16 });
let gcd_columns = serde_json::json!([
    { "key": "0", "label": "摂動 δ [-]", "type": "number", "format": sci3 },
    { "key": "1", "label": "逆条件数 [-]", "type": "number", "format": sci3, "nullText": "なし" },
    { "key": "2", "label": "ランク閾値 τ [-]", "type": "number", "format": sci3 },
    { "key": "3", "label": "近似 GCD の次数", "type": "integer" },
    { "key": "4", "label": "GCD の定数項 c [-]", "type": "number", "format": c16, "nullText": "なし" }
]);
let degree = report.effective_degree();
emit_table_with_columns!(
    gcd_columns,
    vec![(
        delta,
        report.reciprocal_condition(),
        rank_threshold,
        degree,
        c
    )],
    metadata = serde_json::json!({ "id": "gcd" })
);
// 独立検算: 剰余の定理による正規化剰余 |p(−c)|/max|p_i|（次数 1 のときだけ）
let predicted = [
    c.map(|c| (c * c - 2.0 * c).abs() / 2.0),
    c.map(|c| (c * c - (3.0 + delta) * c + 2.0 + delta).abs() / (3.0 + delta)),
];
let [numerator_error, denominator_error] = report.operand_errors();
let residual_columns = serde_json::json!([
    { "key": "0", "label": "部分" },
    { "key": "1", "label": "正規化剰余 [-]", "type": "number", "format": sci3 },
    { "key": "2", "label": "剰余の定理による値 [-]", "type": "number", "format": sci3, "nullText": "なし" },
    { "key": "3", "label": "許容誤差の相対値 [-]", "type": "number", "format": sci3 }
]);
emit_table_with_columns!(
    residual_columns,
    vec![
        ("分子", numerator_error, predicted[0], tolerance),
        ("分母", denominator_error, predicted[1], tolerance),
    ],
    metadata = serde_json::json!({ "id": "residuals" })
);
// 独立検算: c から組立除法で作る簡約後の閉形式（次数 0 なら元の式のまま）
let closed = |x: f64| match c {
    Some(c) => (x + 2.0 - c) / (x + 3.0 + delta - c),
    None => x * (x + 2.0) / ((x + 1.0) * (x + 2.0 + delta)),
};
let fixed2 = serde_json::json!({ "fractionDigits": 2 });
let value = serde_json::json!({ "significantDigits": 12 });
let value_columns = serde_json::json!([
    { "key": "0", "label": "濃度 x [-]", "type": "number", "format": fixed2 },
    { "key": "1", "label": "元の値 [-]", "type": "number", "format": value },
    { "key": "2", "label": "簡約後 [-]", "type": "number", "format": value },
    { "key": "3", "label": "簡約後の閉形式 [-]", "type": "number", "format": value },
    { "key": "4", "label": "簡約による変化 [-]", "type": "number", "format": sci3 }
]);
// 簡約を受け入れた場合だけ、五つの濃度で元の式と簡約後の式を比べる
match rational.simplify() {
    Ok(simplified) => {
        let points = [0.0, 0.25, 1.0, 4.0, 16.0];
        let rows: Vec<_> = compare(&rational, simplified.rational(), points)?
            .into_iter()
            .map(|(x, before, after)| (x, before, after, closed(x), after - before))
            .collect();
        emit_table_with_columns!(
            value_columns,
            rows,
            metadata = serde_json::json!({ "id": "values" })
        );
    }
    Err(error) => emit_text!(&format!(
        "簡約を拒否: {:?}、{:?}",
        error.kind(),
        error.view()
    )),
}
```

既定の $p = 30$（$\delta \approx 9.3 \times 10^{-10}$）、$q_r = q_t = 20$ では、逆条件数 $2.2 \times 10^{-11}$ がランク閾値 $9.5 \times 10^{-7}$ を下回って次数 1 が選ばれる。
正規化剰余 $1.9 \times 10^{-10}$、$2.5 \times 10^{-10}$ も許容誤差 $9.5 \times 10^{-7}$ 以下なので、約分が受け入れられる。
逆条件数はどの $p$ でもほぼ $0.023\,\delta$ で、GCD の定数項は $c \approx 2 + 0.2\,\delta$ と、二つの近い根 $-2$ と $-2-\delta$ の間で $-2$ の側に寄る。
レポートの正規化剰余は剰余の定理による値と有効数字 9 桁以上で一致し、簡約後の値は $c$ から作った閉形式と表示の桁まで一致する。
簡約による変化は $x = 0$ で $-1.9 \times 10^{-10}$ と最も大きく、濃度が上がると小さくなり、$x = 16$ では $-3.5 \times 10^{-12}$ である。
原点の占有率が負の値になるので、簡約後の式は零点という元のモデルの性質を保たない。

$p = 12$ にすると逆条件数 $5.7 \times 10^{-6}$ がランク閾値を上回り、次数 0（定数の GCD）が選ばれて、簡約しても式は変わらない。
$q_t = 40$ にすると、次数 1 は選ばれるが正規化剰余が許容誤差 $9.1 \times 10^{-13}$ を超え、`simplify` は `NumericalInstability`（`IllConditioned`）を返す。
このように、共通因子の次数はランクの方針が、約分を受け入れるかどうかは許容誤差が決め、二つは方針の別の部品である。
`evaluate` が分母の値とその評価誤差の推定から極を判定して返す `DomainError` は、どちらとも別の条件である。
近似の簡約で曲線がほとんど変わらなくても、それは選んだ許容誤差のもとでの近似であり、真の極と可除特異点を区別した証明にはならない。

## まとめ

受容体の占有率 $\theta(x) = x/(1+x)$（$x = [L]/K_d$）は有理関数で表せ、分子と分母に共通な因子は `simplify` を呼んだときにだけ約される。
因子が厳密に共通なら約分後の式は物理区間で元の式と丸めの程度で一致するが、近いだけの因子を取り除くと関数が変わり、この例では原点の零点が失われる。
共通因子の次数は Sylvester 行列の逆条件数とランク閾値の比較で、約分の受け入れは正規化剰余と許容誤差の比較で決まるので、二つの値をレポートから読んでから簡約後の式を使う。
ランク閾値と許容誤差は、係数に含まれる誤差（測定、同定、丸め）の大きさに合わせて選び、それより大きくしない。
簡約の前後で、利用する区間の値の変化と、零点や極のようなモデルの性質が保たれるかを確かめる。
