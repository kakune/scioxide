二曲線の交点は二変数の連立代数方程式の解である。
片方の変数を終結式で消去すれば一変数の多項式の根の問題に移せるが、消去後の根を元の二式に戻す検算と、重根になる接触の扱いが必要になる。
ここでは円と放物線で、横断する交点と接触する交点を、浮動小数点の候補と有理数での厳密な数え上げの両方から調べる。

## 円と放物線の消去

無次元の座標 $(x, y)$ で、単位円と、上下に $h$ だけ動かした放物線

$$
f(x,y) = y^2 + x^2 - 1 = 0, \qquad g(x,y) = y - x^2 + h = 0
$$

の交点を求める。
$f$ と $g$ を $y$ の多項式（係数は $x$ の多項式）とみて $y$ を消去すると、[終結式の積の公式](oxref:poly-resultant-root-formula)から

$$
q_h(x) = \operatorname{Res}_y(f, g) = (-1)^{2 \cdot 1} \cdot 1^2 \cdot f(x, x^2 - h) = x^4 + (1-2h)x^2 + h^2 - 1
$$

を得る。
$g$ の $y$ についての根は $y = x^2 - h$ だけなので、これは代入と同じ結果である。
$q_h(x_0) = 0$ なら $y_0 = x_0^2 - h$ とした $(x_0, y_0)$ が交点になり、実数の $x_0$ ごとに実の交点がちょうど一つ対応する。
一般の消去では、$y$ の最高次の係数が $x$ の値によって消えると Sylvester 行列の形が変わり、余分な候補や失われる解が出る。
この例では $f$ と $g$ の $y$ の最高次の係数がともに 1 なので、そのような $x$ はない。

独立な検算には $t = x^2$ を使う。

$$
t^2 + (1-2h)t + h^2 - 1 = 0, \qquad t_\pm = \frac{2h - 1 \pm \sqrt{5 - 4h}}{2}
$$

正の $t$ は二つの実の交点 $x = \pm\sqrt{t}$、$t = 0$ は一つの交点 $x = 0$ を与え、負や複素数の $t$ は実の交点を与えない。
$q_h$ の判別式は $16(h^2 - 1)(5 - 4h)^2$ で（$x^4 + Bx^2 + C$ の判別式 $16C(B^2 - 4C)^2$ に $B = 1 - 2h$、$C = h^2 - 1$ を代入）、$h = \pm 1$ と $h = 5/4$ で 0 になる。
$h$ ごとの相異なる実の交点の数は次のとおりである。

| $h$ の範囲 | $t_\pm$ | 相異なる実の交点 | 接触 |
|---|---|---|---|
| $h < -1$ | 二つとも負 | 0 | なし |
| $h = -1$ | $t_+ = 0$ | 1（$(0, 1)$） | $(0, 1)$ で接する |
| $-1 < h < 1$ | $t_+ > 0 > t_-$ | 2 | なし |
| $h = 1$ | $t_- = 0$、$t_+ = 1$ | 3（$(0,-1)$、$(\pm1, 0)$） | $(0, -1)$ で接する |
| $1 < h < 5/4$ | 二つとも正 | 4 | なし |
| $h = 5/4$ | $t_+ = t_- = 3/4$ | 2（$(\pm\sqrt3/2, -1/2)$） | 両方で接する |
| $h > 5/4$ | 複素数 | 0 | なし |

接触では $q_h$ が重根を持つので、重複度を含めた根の数と、幾何学的に異なる交点の数は一致しない。

次の定義のブロックはこの節の閉形式を浮動小数点で書いたもので、最初のセルの独立検算と描画に使う。
`closed_form_coefficients` が $q_h$ の昇べき順の係数、`closed_form_real_roots` が $t_\pm \ge 0$ から作る実根 $\pm\sqrt{t_\pm}$（重複を含む）、`curves` が描画用の円と放物線の点列に対応する。
平方根と三角関数には `f64` の固有メソッドを使い、SciOxide の計算とは独立にする。

```rust
//| id: poly-resultant-closed-form
//| kind: definitions
//| title: q_h の閉形式と描画用の曲線
//| crates: []
/// q_h(x) = x⁴ + (1 − 2h)x² + h² − 1 の係数（昇べき順）。
pub(crate) fn closed_form_coefficients(h: f64) -> [f64; 5] {
    [h * h - 1.0, 0.0, 1.0 - 2.0 * h, 0.0, 1.0]
}

/// t = x² の二次方程式の解 t± ≥ 0 から作る実根 ±√t±（重複を含む、f64 の sqrt による参照値）。
pub(crate) fn closed_form_real_roots(h: f64) -> Vec<f64> {
    let discriminant = 5.0 - 4.0 * h;
    if discriminant < 0.0 {
        return Vec::new();
    }
    [1.0, -1.0]
        .iter()
        .map(|sign| (2.0 * h - 1.0 + sign * discriminant.sqrt()) / 2.0)
        .filter(|&t| t >= 0.0)
        .flat_map(|t| [t.sqrt(), -t.sqrt()])
        .collect()
}

/// 描画用の円 x² + y² = 1（241 点）と放物線 y = x² − h（x ∈ [−1.5, 1.5] の 201 点）。
pub(crate) fn curves(h: f64) -> (Vec<[f64; 2]>, Vec<[f64; 2]>) {
    let circle = (0..=240)
        .map(|i| {
            let (sin, cos) = (2.0 * std::f64::consts::PI * i as f64 / 240.0).sin_cos();
            [cos, sin]
        })
        .collect();
    let parabola = (0..=200)
        .map(|i| {
            let x = -1.5 + 3.0 * i as f64 / 200.0;
            [x, x * x - h]
        })
        .collect();
    (circle, parabola)
}
```

## 終結式の標本と交点の候補

最初のセルでは異なる五つの $x$ で `approximate_resultant` を計算し、その値を四次多項式として Newton 補間する。
主計算には SciOxide の終結式を使い、消去後の係数は手で入力しない。
補間した多項式を単項式に変換し、根を固有値に持つ行列（根を固有値に持つ行列）の固有値として $q_h$ の根を求め、虚部の小さい根を交点の候補とする。
候補は $y = x^2 - h$ で $y$ を決め、元の円の式 $f(x, y)$ に代入して残差を調べる。
$g$ の残差はこの決め方で 0 になるので、表には $f$ の残差だけを示す。

独立な検算は二つある。
補間した係数を閉形式 $[h^2 - 1, 0, 1 - 2h, 0, 1]$ と比べ、各候補を $t_\pm$ から作った根 $\pm\sqrt{t_\pm}$ のうち最も近いものと比べる。
入力は整数 $j$ で、$h = j/20$ とし、同じ有理数を後の二つのセルの厳密な計算でも使う。
表は候補ごとの $x$、根の虚部、閉形式の根との差、$y$、円の残差と、補間した係数の閉形式との最大差、候補の数である。
図には円と放物線と候補を描く。

//|   - case: default

let h = shift_index / 20.0;

// y の多項式として f = (x² − 1) + y²、g = (h − x²) + y（係数は y の昇べき順）
let nodes = [-2.0_f64, -1.0, 0.0, 1.0, 2.0];
let mut values = Vec::new();
for &x in &nodes {
    let elimination = approximate_resultant(&[x * x - 1.0, 0.0, 1.0], &[h - x * x, 1.0])
        .map_err(|e| e.to_string())?;
    values.push(elimination.value().try_value().map_err(|e| e.to_string())?);
}
// 次数 4 の q_h は 5 点の値で決まる。Newton 形で補間して単項式に変換する。
let interpolation =
    ApproxPolynomial::interpolate_newton(nodes.to_vec(), values).map_err(|e| e.to_string())?;
let conversion = interpolation.to_monomial().map_err(|e| e.to_string())?;
let polynomial = conversion.polynomial();
let matrix = polynomial.root_matrix().map_err(|e| e.to_string())?;
let roots = GeneralEigenvaluesResult::compute(&matrix).map_err(|e| e.to_string())?;

// 独立検算 1: 補間した係数と閉形式 q_h = x⁴ + (1 − 2h)x² + h² − 1
let coefficient_gap = polynomial
    .basis()
    .coefficients()
    .iter()
    .zip(closed_form_coefficients(h))
    .map(|(a, b)| (a - b).abs())
    .fold(0.0_f64, f64::max);

既定の $j = 0$（$h = 0$）では候補は $x = \pm 0.786$、$y = 0.618$ の二つで、閉形式の根との差は $1.1 \times 10^{-16}$、円の残差は $4.4 \times 10^{-16}$ である。
補間した係数は閉形式と一致し、終結式の標本と補間が係数を丸めの程度で再現することが分かる。
$j = 22$（$h = 1.1$）では四つの候補がすべて閉形式の根と $2 \times 10^{-15}$ 以内で一致し、$j = 30$（$h = 1.5$）と $j = -30$ では候補がない。
接触する $j = 25$（$h = 5/4$）では、二重根 $x = \pm\sqrt{3}/2$ が固有値の計算で $10^{-8}$ 程度に分かれる。
片方の対は $\pm 5 \times 10^{-9} i$ の虚部を持つ共役な対になり、もう片方は $0.8660253793$ と $0.8660254283$ の二つの実数になる。
単位丸めを $u$ とすると、二重根の摂動は $\sqrt{u} \approx 10^{-8}$ の程度なので、この分かれ方は根の条件の悪さから予想される大きさである。
実数の二つは閉形式の根から $2.5 \times 10^{-8}$ 離れているのに、円の残差は $2 \times 10^{-15}$ にとどまる。
接触では $q_h$ の値が根からの距離の 2 乗で増えるので、代入の残差が丸めの程度でも、位置の誤差は残差の平方根の程度になりうる。
虚部の閾値 $10^{-6}$ で選ぶと四つの候補が残るが、異なる交点は二つしかない。
$j = 20$（$h = 1$）では $x = \pm1$ の二つと、$x = 0$ の二重根が 0 のまま重なった二つの、計四つの候補が現れる。
$j = -20$ では $x = 0$ だけが二重に現れる。
このように、浮動小数点の候補の個数は重複度を含み、閾値の選び方にも左右されるので、交点の数の証明には使えない。

## 厳密な Sturm 列による個数

実係数の多項式 $q$ の Sturm 列は、$p_0 = q$、$p_1 = q'$ から始め、$p_{k+1} = -(p_{k-1} \bmod p_k)$ と剰余の符号を反転させて作り、剰余が 0 になったら止める。
最後の 0 でない要素は $\gcd(q, q')$ の定数倍で、$q$ が重根を持つと次数が 1 以上になる。
点 $x$ での列の符号の変化の数を、値が 0 の項を除いて $V(x)$ とすると、端点が $q$ の根でない区間 $(a, b)$ の相異なる実根の数は $V(a) - V(b)$ である（Sturm の定理）。
この定理は重根があっても成り立ち、重複度を数えずに相異なる根だけを数える。
各段の剰余に正の定数を掛けても符号の変化は変わらないが、負の数を掛けると変わるので、モニック化のような規格化は挟まない。
交点の $x$ 座標は円の上にあって $|x| \le 1$ を満たし、端点 $\pm 2$ は $q_h$ の根ではない（$q_h(\pm 2) = h^2 - 8h + 19 > 0$）ので、$V(-2) - V(2)$ が相異なる実の交点の数になる。

SciOxide は Sturm 列を作る専用の API を提供しないので、`ExactPolynomial` の `derivative` と `div_rem` を組み合わせる。
係数には有理数が要るが、SciOxide は有理数型も提供しない。
次の定義のブロックは `i128` の分子と分母を演算のたびに約分する小さな有理数型 `Q` と、$h = j/20$ から $q_h$ を作る関数である。
`Q` は `ExactCoefficient` と `ExactField` を実装し、桁あふれは黙って折り返さずに検査して止める。
任意精度の有理数ではないので、使えるのはこのページの入力の範囲のような小さな係数に限る。

```rust
//| id: poly-exact-rational-model
//| kind: definitions
//| title: 小さな有理数型と q_h の厳密な係数
//| crates: [scioxide-core, scioxide-poly]
use scioxide_core::SciOxideError;
use scioxide_poly::{ExactCoefficient, ExactField, ExactPolynomial};
use std::ops::{Add, Div, Mul, Neg, Sub};

/// 既約分数 numerator/denominator（分母は正）。演算の桁あふれは panic で止める。
#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub(crate) struct Q(pub(crate) i128, pub(crate) i128);

impl Q {
    pub(crate) fn new(numerator: i128, denominator: i128) -> Self {
        assert_ne!(denominator, 0, "有理数の分母が 0");
        let (mut a, mut b) = (numerator.abs(), denominator.abs());
        while b != 0 {
            (a, b) = (b, a % b);
        }
        let g = a * denominator.signum();
        Self(numerator / g, denominator / g)
    }

    pub(crate) fn to_f64(self) -> f64 {
        self.0 as f64 / self.1 as f64
    }
}

fn checked(value: Option<i128>) -> i128 {
    value.expect("有理数の演算が i128 の範囲を超えた")
}

impl Add for Q {
    type Output = Self;
    fn add(self, other: Self) -> Self {
        let left = checked(self.0.checked_mul(other.1));
        let right = checked(other.0.checked_mul(self.1));
        Self::new(
            checked(left.checked_add(right)),
            checked(self.1.checked_mul(other.1)),
        )
    }
}
impl Neg for Q {
    type Output = Self;
    fn neg(self) -> Self {
        Self(-self.0, self.1)
    }
}
impl Sub for Q {
    type Output = Self;
    fn sub(self, other: Self) -> Self {
        self + -other
    }
}
impl Mul for Q {
    type Output = Self;
    fn mul(self, other: Self) -> Self {
        Self::new(
            checked(self.0.checked_mul(other.0)),
            checked(self.1.checked_mul(other.1)),
        )
    }
}
impl Div for Q {
    type Output = Self;
    fn div(self, other: Self) -> Self {
        Self::new(
            checked(self.0.checked_mul(other.1)),
            checked(self.1.checked_mul(other.0)),
        )
    }
}
impl ExactCoefficient for Q {
    fn zero() -> Self {
        Q(0, 1)
    }
    fn one() -> Self {
        Q(1, 1)
    }
    fn from_usize(value: usize) -> Self {
        Q(value as i128, 1)
    }
}
impl ExactField for Q {}

/// q_h(x) = x⁴ + (1 − 2h)x² + h² − 1 の厳密な係数（昇べき順）。
pub(crate) fn intersection_polynomial(h: Q) -> Result<ExactPolynomial<Q>, SciOxideError> {
    let (zero, one, two) = (Q(0, 1), Q(1, 1), Q(2, 1));
    ExactPolynomial::new(vec![h * h - one, zero, one - two * h, zero, one])
}
```

次のセルは入力の $j$ から $q_h$ を作り、Sturm 列の各要素の次数と端点 $\pm 2$ での符号、符号の変化の数 $V(-2)$、$V(2)$ とその差を表にする。
独立な検算は最初の節の表にある $h$ の範囲ごとの交点の数である。

```rust

//| ref: poly-exact-sturm-intersections

//| inputs:
//|   shift_index: {"type":"range","label":"放物線の移動 h = j/20 の j","description":"放物線 y = x² − h を上下に動かす。","min":-30,"max":30,"step":1,"value":0}
//| cases:
//|   - {"id":"four-crossings","label":"j = 22（h = 1.1）","description":"相異なる実の交点は 4 個で、列は定数で終わる。","inputs":{"shift_index":22}}
//|   - {"id":"double-tangency","label":"j = 25（h = 5/4）","description":"相異なる交点は 2 個で、列は gcd(q, q′) = x² − 3/4 の定数倍で止まる。","inputs":{"shift_index":25}}
//|   - {"id":"tangent-and-crossing","label":"j = 20（h = 1）","description":"相異なる交点は 3 個で、列は gcd(q, q′) = x の定数倍で止まる。","inputs":{"shift_index":20}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"count","path":"/rows/0/2","equals":2}
//|       - {"artifact":"count","path":"/rows/0/3","equals":0}
//|   - case: four-crossings
//|     expect:
//|       - {"artifact":"count","path":"/rows/0/2","equals":4}
//|   - case: double-tangency
//|     expect:
//|       - {"artifact":"count","path":"/rows/0/2","equals":2}
//|       - {"artifact":"count","path":"/rows/0/3","equals":2}
//|   - case: tangent-and-crossing
//|     expect:
//|       - {"artifact":"count","path":"/rows/0/2","equals":3}
//|       - {"artifact":"count","path":"/rows/0/3","equals":1}
use scioxide_poly::ExactPolynomial;

let q = intersection_polynomial(Q::new(shift_index as i128, 20)).map_err(|e| e.to_string())?;
let derivative = q.derivative().map_err(|e| e.to_string())?;

// Sturm 列: p₀ = q、p₁ = q′、p_{k+1} = −(p_{k−1} mod p_k)
let zero = ExactPolynomial::constant(Q(0, 1)).map_err(|e| e.to_string())?;
let mut sequence = vec![q, derivative];
loop {
    let n = sequence.len();
    let (_, remainder) = sequence[n - 2]
        .div_rem(&sequence[n - 1])
        .map_err(|e| e.to_string())?;
    if remainder.is_zero() {
        break;
    }
    sequence.push(zero.try_sub(&remainder).map_err(|e| e.to_string())?);
}
// 符号の変化の数 V(x)。値が 0 の要素は数えない。
let sign = |p: &ExactPolynomial<Q>, x: Q| p.evaluate(x).0.signum() as i32;
let variations = |x: Q| {
    let signs: Vec<_> = sequence
        .iter()
        .map(|p| sign(p, x))
        .filter(|&s| s != 0)
        .collect();
    signs.windows(2).filter(|w| w[0] != w[1]).count()
};
let (left, right) = (Q(-2, 1), Q(2, 1));
let rows: Vec<_> = sequence
    .iter()
    .enumerate()
    .map(|(i, p)| (i, p.degree(), sign(p, left), sign(p, right)))
    .collect();
emit_table_with_columns!(
    serde_json::json!([
        { "key": "0", "label": "列の番号 k", "type": "integer" },
        { "key": "1", "label": "p_k の次数", "type": "integer" },
        { "key": "2", "label": "x = −2 での符号", "type": "integer" },
        { "key": "3", "label": "x = 2 での符号", "type": "integer" }
    ]),
    rows,
    metadata = serde_json::json!({ "id": "sequence" })
);
let (v_left, v_right) = (variations(left), variations(right));
let last_degree = sequence.last().map_or(0, |p| p.degree());
emit_table_with_columns!(
    serde_json::json!([
        { "key": "0", "label": "V(−2)", "type": "integer" },
        { "key": "1", "label": "V(2)", "type": "integer" },
        { "key": "2", "label": "相異なる実の交点", "type": "integer" },
        { "key": "3", "label": "最後の要素の次数", "type": "integer" }
    ]),
    vec![(v_left, v_right, v_left - v_right, last_degree)],
    metadata = serde_json::json!({ "id": "count" })
);
```

$j = 0$ は 2 個、$j = 22$ は 4 個、$j = 30$ と $j = -30$ は 0 個で、最初の節の表の $h$ の範囲と、最初のセルの候補の数に一致する。
接触を含む $j = -20, 20, 25$ では、相異なる実の交点がそれぞれ 1、3、2 個で、最初のセルの重複を含む候補の数（2、4、4）とは異なる。
このとき Sturm 列は $\gcd(q, q')$ の定数倍で止まり、最後の要素の次数は $j = \pm 20$ で 1（$x$ の定数倍）、$j = 25$ で 2（$x^2 - 3/4$ の定数倍）になる。
接触のない $j$ では最後の要素は 0 でない定数で、$q_h$ は重根を持たない。

## 判別式と部分終結式による接触の判定

接触は $q_h$ の重根なので、判別式 $D(q_h)$ が 0 になるかで判定できる。
次数 $n$、最高次の係数 $a$ の多項式では $D(q) = (-1)^{n(n-1)/2}\operatorname{Res}(q, q')/a$ で、$n = 4$ では $(-1)^6 = 1$、$a = 1$ なので $\operatorname{Res}(q_h, q_h') = D(q_h)$ となる。
`exact_discriminant` は判別式を、`exact_subresultants` は $q_h$ と $q_h'$ の部分終結式の剰余列と終結式を返す。
部分終結式の剰余列の最後の要素も $\gcd(q, q')$ の定数倍だが、Sturm 列とは各段の符号と定数倍の付け方が異なる（[終結式・判別式・部分終結式](../../algorithms/resultants-and-elimination/)）。

次のセルは同じ $q_h$ についてこの二つを計算し、閉形式 $16(h^2-1)(5-4h)^2$ との差を有理数のまま求めて表にする。
もう一つの表は部分終結式の剰余列の最後の要素の次数と、`ExactPolynomial::gcd` で求めた $\gcd(q_h, q_h')$ の次数である。

```rust
//| id: poly-exact-discriminant-intersections
//| ref: poly-exact-discriminant-intersections
//| title: 判別式と部分終結式による重根の判定
//| run: reactive
//| uses: [poly-exact-rational-model]
//| crates: [scioxide-poly]
//| inputs:
//|   shift_index: {"type":"range","label":"放物線の移動 h = j/20 の j","description":"放物線 y = x² − h を上下に動かす。","min":-30,"max":30,"step":1,"value":0}
//| cases:
//|   - {"id":"four-crossings","label":"j = 22（h = 1.1）","description":"判別式は正で、実根は 0 個か 4 個の場合にあたる。","inputs":{"shift_index":22}}
//|   - {"id":"double-tangency","label":"j = 25（h = 5/4）","description":"判別式と終結式は 0 で、gcd(q, q′) は 2 次になる。","inputs":{"shift_index":25}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"invariants","path":"/rows/0/1","approx":{"value":-400.0,"rtol":1e-12}}
//|       - {"artifact":"invariants","path":"/rows/0/3","equals":0}
//|       - {"artifact":"invariants","path":"/rows/1/3","equals":0}
//|       - {"artifact":"gcd","path":"/rows/1/1","equals":0}
//|   - case: four-crossings
//|     expect:
//|       - {"artifact":"invariants","path":"/rows/0/1","range":{"min":0.0}}
//|       - {"artifact":"invariants","path":"/rows/0/3","equals":0}
//|   - case: double-tangency
//|     expect:
//|       - {"artifact":"invariants","path":"/rows/0/1","equals":0}
//|       - {"artifact":"invariants","path":"/rows/1/1","equals":0}
//|       - {"artifact":"gcd","path":"/rows/0/1","equals":2}
//|       - {"artifact":"gcd","path":"/rows/1/1","equals":2}
use scioxide_poly::{ExactPolynomial, exact_discriminant, exact_subresultants};

let sig8 = serde_json::json!({ "significantDigits": 8 });
let h = Q::new(shift_index as i128, 20);
let q = intersection_polynomial(h).map_err(|e| e.to_string())?;
let derivative = q.derivative().map_err(|e| e.to_string())?;
let discriminant = exact_discriminant(&q).map_err(|e| e.to_string())?;
let subresultants = exact_subresultants(&q, &derivative).map_err(|e| e.to_string())?;
let resultant = *subresultants.resultant();
// 独立検算: 閉形式 D(q_h) = 16(h² − 1)(5 − 4h)²。差は有理数のまま求める。
let factor = Q(5, 1) - Q(4, 1) * h;
let closed = Q(16, 1) * (h * h - Q(1, 1)) * factor * factor;
let rows = vec![
    (
        "D(q_h)（exact_discriminant）",
        discriminant.to_f64(),
        closed.to_f64(),
        (discriminant - closed).to_f64(),
    ),
    (
        "Res(q_h, q_h′)（exact_subresultants）",
        resultant.to_f64(),
        closed.to_f64(),
        (resultant - closed).to_f64(),
    ),
];
emit_table_with_columns!(
    serde_json::json!([
        { "key": "0", "label": "量" },
        { "key": "1", "label": "厳密な計算 [-]", "type": "number", "format": sig8 },
        { "key": "2", "label": "閉形式 [-]", "type": "number", "format": sig8 },
        { "key": "3", "label": "差（有理数で計算）[-]", "type": "number" }
    ]),
    rows,
    metadata = serde_json::json!({ "id": "invariants" })
);
let last = |list: &[ExactPolynomial<Q>]| list.last().map_or(0, |p| p.degree());
let gcd = q.gcd(&derivative).map_err(|e| e.to_string())?;
emit_table_with_columns!(
    serde_json::json!([
        { "key": "0", "label": "量" },
        { "key": "1", "label": "次数", "type": "integer" }
    ]),
    vec![
        (
            "部分終結式の剰余列の最後の要素",
            last(subresultants.polynomials())
        ),
        ("gcd(q_h, q_h′)（ExactPolynomial::gcd）", gcd.degree()),
    ],
    metadata = serde_json::json!({ "id": "gcd" })
);
```

入力の範囲の $j = -30, \dots, 30$ のすべてで、判別式と終結式は閉形式 $16(h^2-1)(5-4h)^2$ と有理数として一致し、差は 0 である。
判別式は $|h| < 1$ で負（$j = 0$ では $-400$）、$|h| > 1$（$h \ne 5/4$）で正になる。
四次式の判別式が負なら相異なる実根はちょうど二つ、正なら 0 個か 4 個であり、Sturm 列の個数と矛盾しない。
接触を含む $j = -20, 20, 25$ では判別式と終結式がどちらも 0 になり、部分終結式の剰余列の最後の要素と $\gcd(q_h, q_h')$ の次数は Sturm 列と同じ 1、1、2 になる。

## まとめ

終結式で $y$ を消去すると交点の $x$ 座標は一変数の多項式の根になるが、候補は元の二式に代入して確かめ、閉形式があればそれとも比べる。
接触は重根になり、浮動小数点の固有値は二重根を $\sqrt{u} \approx 10^{-8}$ 程度に分けるので、候補の個数を交点の数とはみなさない。
相異なる交点の数は有理数で作った Sturm 列の符号の変化から厳密に数えられ、SciOxide には専用の API がないので `ExactPolynomial` の `derivative` と `div_rem` で組み立てる。
Sturm 列には剰余の符号を反転させる規約が必要で、部分終結式の剰余列とは符号の付け方が異なる。
接触は `exact_discriminant` が 0 を返すことと、$\gcd(q, q')$ の次数が 1 以上になることで判定できる。
係数を有理数で扱う型は呼び出し側が用意し、桁あふれを検査する。
