高次の多項式補間で「次数を上げれば精度が上がる」とは限らない代表例が、C. Runge が 1901 年に示した Runge 現象である。
実軸上で何回でも微分できる関数でも、複素平面の極が区間に近いと、等間隔の節点で次数を上げるにつれて端点付近の誤差が増える。
この例では Runge 関数 $f(x) = 1/(1 + 25x^2)$ と、その極の位置を変えた関数を、重心型補間 `ApproxPolynomial::interpolate_barycentric` で等間隔節点と Chebyshev 根節点に補間し、誤差の違いを調べる。
すべての量は無次元である。
剰余項、Lebesgue 定数、Chebyshev 節点の最小性の導出は[補間と Chebyshev 節点](../../algorithms/interpolation-and-chebyshev/)にあり、ここでは極の位置から収束と発散の速さを予測し、数値で確かめる。

## Runge 関数と極

極までの距離 $b > 0$ を持つ関数の族

$$
f_b(x) = \frac{1}{1 + (x/b)^2} \quad (x \in [-1, 1])
$$

を考える。
$b = 1/5$ のときが Runge 関数 $1/(1 + 25x^2)$ である。
$f_b$ は偶関数で、実軸上では何回でも微分できる。
一方、複素平面では虚軸上の点 $z = \pm \mathrm{i}b$ に 1 位の極を持ち、極と区間の距離は $b$ である。

## 等間隔節点の補間誤差

補間の剰余項 $f(x) - p_n(x) = \dfrac{f^{(n+1)}(\xi)}{(n+1)!} \omega(x)$、$\omega(x)=\prod_{j=0}^n (x - x_j)$ では、二つの因子が誤差を決める。

一つ目は高階導関数である。
部分分数 $f_b(x)=\frac{b}{2\mathrm{i}}\bigl(\frac{1}{x-\mathrm{i}b}-\frac{1}{x+\mathrm{i}b}\bigr)$ を $k$ 回微分すると、実数の $x$ では $|x\mp\mathrm{i}b|\ge b$ なので

$$
\max_{x\in\mathbb R}\bigl|f_b^{(k)}(x)\bigr| \le k!\,b^{-k}
$$

が得られ、$k$ が偶数なら $x=0$ で等号が成り立つ。
導関数は極までの距離の逆数 $1/b$ のべきと階乗の積の速さで増える。

二つ目は節点多項式 $\omega$ である。
等間隔節点 $x_j = -1 + 2j/n$ では、$n \to \infty$ で $|\omega(z)|^{1/n}$ が $e^{u(z)}$ に近づく（区間上では、節点で 0 になる $|\omega|$ の包絡についての極限である）。
ここで

$$
u(z)=\frac12\int_{-1}^{1}\ln|z-t|\,dt
$$

は区間上の一様分布の対数ポテンシャルである。
$u(0) = -1$、$u(\pm1) = \ln 2 - 1 \approx -0.3069$ なので、端点の近くの $|\omega|$ は中央より約 $2^n$ 倍大きい。
虚軸上の点では $u(\mathrm{i}b) = \frac12\bigl[\ln(1 + b^2) - 2 + 2b\arctan(1/b)\bigr]$ である。

二つの因子を合わせると、誤差はおよそ $e^{n(u(x) - u(\mathrm{i}b))}$ の速さで変わる。
等間隔節点の補間が収束する範囲は、$u$ の等高線のうち極 $\pm\mathrm{i}b$ を通るもので囲まれた領域 $u(z) < u(\mathrm{i}b)$ になる（Epperson, 1987; Trefethen, *Approximation Theory and Approximation Practice*, 2019, 13 章）。
Runge 関数では $u(\pm\mathrm{i}/5)\approx-0.7057$ で、この等高線は実軸と $\pm0.7267$ で交わる。
$0.7267 < |x| < 1$ では、節点を除く点で誤差が次数とともに有界でなくなる。
端点の近くの誤差は 1 次あたりおよそ $g_{\rm eq} = e^{u(1)-u(\mathrm{i}b)}$ 倍の速さで変わり、Runge 関数では $g_{\rm eq} \approx 1.490$ 倍で増える。
$u(\mathrm{i}b) = u(1)$ となる臨界距離は $b^* \approx 0.5255$ で、$b > b^*$ なら $g_{\rm eq} < 1$ となって、等間隔節点の補間も区間全体で収束する。

## Chebyshev 根節点

第一種 Chebyshev 多項式 $T_{n+1}(x)$ の零点（Chebyshev 根節点）は

$$
x_j = \cos\left( \frac{2j + 1}{2(n + 1)} \pi \right) \quad (j = 0, 1, \dots, n)
$$

で与えられる。
節点の間隔は中央で $O(1/n)$、端点の近くで $O(1/n^2)$ で、端点の近くほど密に並ぶ。
このとき節点多項式は $\omega(x) = 2^{-n} T_{n+1}(x)$ となり、$[-1,1]$ 上で $|\omega(x)| \le 2^{-n}$ が成り立つ。
この最大値は次数 $n+1$ のモニック多項式の $[-1,1]$ 上の最大値として最小である。
その結果、$f_b$ の補間誤差は極を通る Bernstein 楕円（焦点 $\pm1$、長半径と短半径の和 $\rho$）で決まる速さ $O(\rho^{-n})$ で 0 に近づく。
極 $z$ を通る楕円の $\rho$ は $|z + \sqrt{z^2 - 1}|$ で、$z = \mathrm{i}b$ なら

$$
\rho = b + \sqrt{1 + b^2}
$$

である。
Runge 関数では $\rho \approx 1.2198$ で、誤差は 1 次あたり $1/\rho \approx 0.8198$ 倍になる。
$\rho > 1$ はどの $b > 0$ でも成り立つので、Chebyshev 根節点の補間は極がどれだけ区間に近くても収束する。

次のブロックは二つのセルが共有する定義である。
`runge_function` が $f_b$、`interpolants` が次数 $n$ の二つの補間多項式（等間隔節点、Chebyshev 根節点の順）に対応する。
根節点は `backend::barycentric::chebyshev_points` の `Roots` で $n+1$ 点を昇順に作る。
重みは `interpolate_barycentric` が節点から計算し直すので、`chebyshev_points` が返す重みは使わない。

```rust
//| id: poly-runge-nodes-model
//| kind: definitions
//| title: 極までの距離 b の関数と二つの節点配置の補間
//| crates: [scioxide-core, scioxide-poly]
use scioxide_core::SciOxideError;
use scioxide_poly::backend::barycentric::{ChebyshevPoints, chebyshev_points};
use scioxide_poly::{ApproxPolynomial, BarycentricBasis};

/// 重心形式の補間多項式。
pub(crate) type Interpolant = ApproxPolynomial<f64, BarycentricBasis<f64>>;

/// f_b(x) = 1/(1 + (x/b)²)。極は ±ib で、b = 1/5 が Runge 関数。
pub(crate) fn runge_function(pole: f64, x: f64) -> f64 {
    let scaled = x / pole;
    1.0 / (1.0 + scaled * scaled)
}

/// 次数 n の補間多項式を、等間隔節点、Chebyshev 根節点（T_{n+1} の零点）の順に返す。
pub(crate) fn interpolants(n: usize, pole: f64) -> Result<[Interpolant; 2], SciOxideError> {
    let equispaced: Vec<f64> = (0..=n).map(|j| -1.0 + 2.0 * j as f64 / n as f64).collect();
    let (chebyshev, _) = chebyshev_points::<f64>(n + 1, ChebyshevPoints::Roots)?;
    let interpolate = |nodes: Vec<f64>| {
        let values = nodes.iter().map(|&x| runge_function(pole, x)).collect();
        ApproxPolynomial::interpolate_barycentric(nodes, values)
    };
    Ok([interpolate(equispaced)?, interpolate(chebyshev)?])
}
```

## 補間曲線と誤差の分布

次のセルは Runge 関数（$b = 1/5$）について補間次数 $n$ を変え、等間隔節点と Chebyshev 根節点の補間曲線と絶対誤差を 201 点の格子で比べる。
誤差は解析的な Runge 関数との差で測り、これが独立な検算になる。
上のグラフでは真の関数を破線、補間曲線を実線で描き、下のグラフでは絶対誤差を片対数軸で描く。
二つのグラフの横軸は連動する。
上のグラフの縦軸は $[-1.5, 1.5]$ に固定してあり、高次の等間隔補間の端の振動は枠の外に出るので、その大きさは下のグラフと表で読む。
節点上で誤差が 0 になる評価点は対数軸に描けないので除き、その数を表に示す。

```rust

//| run: reactive

//| crates: [scioxide-core, scioxide-poly]
```

補間次数を $n = 4, 10, 14$ と上げると、等間隔補間では中央部（$|x| \le 0.5$）の当てはまりがよくなる一方で、端部（$|x| \ge 0.8$）に大きな振動が現れ、最大誤差は $0.438$、$1.916$、$7.192$ と増える。
Chebyshev 根節点の補間では誤差が区間全体にほぼ均等に分布し、最大誤差は $0.402$、$0.109$、$0.0465$ と下がる。
誤差の曲線が端点の近くで大きいか、区間全体で同じ程度かが、二つの節点配置を見分ける目印になる。
既定の $n = 10$ で誤差が 0 になる評価点は、等間隔節点では 11 個の節点すべて、Chebyshev 根節点では $x = 0$ の 1 点で、どちらも節点が格子点に一致した点である。

## 次数を上げたときの最大誤差

次のセルは極までの距離 $b$ を選び、次数を 2 から 30 まで偶数で変えて、二つの節点配置の最大誤差 $e_n$ を 1001 点の格子で測る。
表の「比」は 1 次あたりの誤差の比で、隣の偶数次数との比の平方根 $(e_n/e_{n-2})^{1/2}$ である。
1 より大きければ誤差は次数とともに増え、小さければ減る。
独立な検算として、この比を理論の $g_{\rm eq} = e^{u(1)-u(\mathrm{i}b)}$ と $1/\rho$ に比べる。
理論値は上の閉形式を f64 の `sqrt`・`ln`・`atan`・`exp` で計算した参照値で、SciOxide の関数は使わない。
グラフの破線は $n=30$ の観測値を通り理論の比で変わる直線である。

```rust

//| ref: poly-runge-degree-sweep
//| title: 次数を上げたときの最大誤差を比べる

//| crates: [scioxide-core, scioxide-poly]
//| inputs:
//|   pole: {"type":"range","label":"極までの距離 b [-]","description":"f(x) = 1/(1 + (x/b)²) の極 ±ib の位置。b = 0.2 が Runge 関数。","min":0.1,"max":1,"step":0.05,"value":0.2}

//|   - {"id":"far-pole","label":"b = 0.6","description":"極が臨界距離 0.5255 より遠く、等間隔節点の補間も収束する。","inputs":{"pole":0.6}}

//|       - {"artifact":"sweep","path":"/rows/0/3","equals":null}
//|   - case: far-pole
//|     expect:
//|       - {"artifact":"theory","path":"/rows/0/3","approx":{"value":0.9242050973,"rtol":1e-9}}
//|       - {"artifact":"sweep","path":"/rows/14/4","approx":{"value":0.5662,"atol":0.005}}
//|       - {"artifact":"sweep","path":"/rows/14/1","range":{"max":0.01}}
//|   - case: near-pole
//|     expect:
//|       - {"artifact":"sweep","path":"/rows/14/4","approx":{"value":0.905,"atol":0.02}}

// 対数ポテンシャル u(ib) = ½[ln(1 + b²) − 2 + 2b·atan(1/b)]、u(1) = ln 2 − 1 による g_eq

    let models = interpolants(n, pole).map_err(|e| e.to_string())?;
    let mut worst = [0.0_f64; 2];
    for (k, model) in models.iter().enumerate() {
        // 1001 点の評価格子で最大誤差を測る
        for i in 0..=1000 {
            let x = -1.0 + 2.0 * i as f64 / 1000.0;
            let value = model.evaluate(x).map_err(|e| e.to_string())?;
            worst[k] = worst[k].max((value - runge_function(pole, x)).abs());

        series[k].push([n as f64, worst[k]]);

    // 1 次あたりの誤差の比 (e_n / e_{n−2})^{1/2}（f64 の sqrt）。最初の行は未定義。

    rows.push((n, worst[0], worst[1], ratio(0), ratio(1)));
    previous = Some(worst);
}

    vec![(pole, rho, 1.0 / rho, equal_factor)],

);
```

Runge 関数（$b = 0.2$）では、Chebyshev 根節点の最大誤差は片対数軸でほぼ直線に並び、破線の傾きと合う。
$n = 20$ から $30$ で最大誤差は $1.53 \times 10^{-2}$ から $2.06 \times 10^{-3}$ に下がり、1 次あたりの比は $0.82$ 前後で、理論の $1/\rho \approx 0.8198$ に近い。
同じ範囲で等間隔節点の最大誤差は $59.8$ から $2385$ に増え、1 次あたりの比は $1.431$ から $1.452$ へ理論の $g_{\rm eq} \approx 1.490$ に下から近づく。
比が理論値に届かないのは、誤差には指数の因子のほかに次数の多項式で変わる因子が掛かり、有限の $n$ ではその影響が残るためである。

$b = 0.6$ では極が臨界距離 $b^* \approx 0.5255$ より遠く、理論の比は $g_{\rm eq} \approx 0.924$ と 1 を下回る。
実際に等間隔節点の誤差も $n = 30$ で $2.85 \times 10^{-3}$ まで減るが、Chebyshev 根節点の $2.20 \times 10^{-8}$ より 5 桁大きい。
$b = 0.1$ では等間隔節点の誤差が $n = 30$ で $8.9 \times 10^{4}$ に達し、1 次あたりの比は $1.674$ と理論の $1.718$ に近づく。
Chebyshev 根節点の比は $0.89$ から $0.92$ のあいだで、理論の $1/\rho \approx 0.905$ の周りにある。
極が近いほど $\rho$ は 1 に近づいて収束は遅くなるが、どの $b$ でも誤差は減る。

$n = 30$ の等間隔節点では Lebesgue 定数が $2^{31}/(e \cdot 30 \ln 30) \approx 8 \times 10^{6}$ 程度になり、標本値の丸め誤差が $10^{-9}$ 程度まで拡大されうる。
この範囲の $b$ では打ち切りの誤差のほうが大きいので、表の値には丸めの影響は見えない。
次数をさらに上げると、極が遠くても等間隔節点の誤差は丸めの拡大で頭打ちになる。

## まとめ

等間隔節点の補間が収束するかどうかは、関数の極が節点分布の対数ポテンシャルの等高線のどちら側にあるかで決まり、虚軸上の極では距離 $b^* \approx 0.5255$ が境目である。
Runge 関数（$b = 0.2$）では $|x|>0.7267$ の範囲で誤差が増え続け、端点の近くの誤差は 1 次あたり約 $1.49$ 倍で増える。
Chebyshev 根節点では誤差が極を通る楕円の $\rho = b + \sqrt{1 + b^2}$ による $\rho^{-n}$ の速さで減り、表の 1 次あたりの比でその値を確かめられる。
高次の多項式で近似するときは、等間隔補間を避け、Chebyshev 節点の重心補間か直交展開を選ぶ。
有限の格子で観測した最大誤差は一様誤差の証明ではないので、格子を細かくした値や理論の速さと合わせて読む。
標本値にノイズがある場合は、補間と[最小二乗](../../algorithms/least-squares-and-vandermonde/)を使い分ける。
