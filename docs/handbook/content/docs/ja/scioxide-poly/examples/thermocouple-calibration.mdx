熱電対の測定では、温度から起電力を計算する順校正と、測定した起電力から温度を戻す逆校正が必要になる。
両者をつなぐのが校正式の導関数である。
この例では例示用の係数を使わず、NIST の Type T 熱電対（銅と銅ニッケル合金）の基準関数を用いる。
評価・微分・直交基底での積分・根を固有値に持つ行列を、NIST の基準表と近似逆関数で独立に確かめる。

## 基準関数の出典と適用範囲

係数は [NIST Monograph 175](https://doi.org/10.6028/NIST.MONO.175)（Burns ほか、1993）の表9.3.1にある、0–400 °C の八次式を使う。
同じ係数は [NIST の ITS-90 熱電対データベース](https://its90.nist.gov/)（SRD 60）にもミリボルト単位で収録されている。
表9.3.1の電圧はマイクロボルト、温度は ITS-90 の摂氏温度 $t_{90}$ で、基準接点は0 °Cである。
以下の係数と出力も同じ単位にし、温度を $T$ と書く。
この式の適用範囲は0–400 °Cであり、負温度側（−270–0 °C）には十四次の別の式が必要である。

$$
E(T)=\sum_{k=0}^8c_kT^k\quad[\mu\mathrm V],\qquad T\in[0,400]\quad[{}^\circ\mathrm C].
$$

| $k$ | $c_k$ の数値（単位は $\mu\mathrm V/({}^\circ\mathrm C)^k$） |
|---|---|
| 0 | 0 |
| 1 | $3.8748106364\times10^1$ |
| 2 | $3.3292227880\times10^{-2}$ |
| 3 | $2.0618243404\times10^{-4}$ |
| 4 | $-2.1882256846\times10^{-6}$ |
| 5 | $1.0996880928\times10^{-8}$ |
| 6 | $-3.0815758772\times10^{-11}$ |
| 7 | $4.5479135290\times10^{-14}$ |
| 8 | $-2.7512901673\times10^{-17}$ |

同じ Monograph の表9.3.3は、この式から計算した起電力 $E$ を0.1 µV、Seebeck 係数 $S=dE/dT$ を0.001 µV/°Cの桁で1 °Cごとに載せている。
表A9.1は温度を電圧の六次式で表す近似逆関数で、0–400 °Cでの基準関数との差は−0.03 °Cから0.03 °Cである。
この例ではこの三つの表を独立な検算に使う。

係数の数値計算が正しくても、個々の熱電対がこの基準関数に一致するとは限らない。
材料差、基準接点、測定器の補正は別の問題である。
この例で扱う不確かさは電圧の成分だけで、測定全体の校正証明ではない。

次のブロックは三つのセルが共有する定義である。
`TYPE_T_COEFFICIENTS` が表9.3.1の $c_0, \dots, c_8$（昇べき順）、`reference_function` が単項式基底の $E(T)$ に対応する。

```rust
//| id: poly-thermocouple-model
//| kind: definitions
//| title: Type T の基準関数（0–400 °C）
//| crates: [scioxide-core, scioxide-poly]
use scioxide_core::SciOxideError;
use scioxide_poly::{ApproxPolynomial, MonomialBasis};

/// NIST Monograph 175 表9.3.1 の c₀, …, c₈（0–400 °C）。E は µV、T は °C。
pub(crate) const TYPE_T_COEFFICIENTS: [f64; 9] = [
    0.0,
    3.8748106364e1,
    3.3292227880e-2,
    2.0618243404e-4,
    -2.1882256846e-6,
    1.0996880928e-8,
    -3.0815758772e-11,
    4.5479135290e-14,
    -2.7512901673e-17,
];

/// 単項式基底の多項式。
pub(crate) type Calibration = ApproxPolynomial<f64, MonomialBasis<f64>>;

/// 単項式基底の基準関数 E(T) [µV]。
pub(crate) fn reference_function() -> Result<Calibration, SciOxideError> {
    ApproxPolynomial::monomial(TYPE_T_COEFFICIENTS.to_vec())
}
```

## 感度と電圧の不確かさ

Seebeck 係数 $S(T)=dE/dT$ の単位は $\mu\mathrm V/{}^\circ\mathrm C$ である。
0–400 °Cでは $S$ は $38.748$ から $61.805$ µV/°Cまで増える。
表9.3.3の $dS/dT$ は0 °Cの66.58 nV/°C²から400 °Cの18.40 nV/°C²まで正のままなので、$S$ は単調に増え、$E$ は狭義単調増加で逆関数を持つ。
微小な電圧の変動には $\Delta T\approx\Delta E/S(T)$ が対応する。
電圧の標準不確かさ $u_E$ だけを考える一次近似なら

$$
u_T\approx\frac{u_E}{|S(T)|}
$$

となる。
これは一次の伝播による標準不確かさの推定で、有限の誤差区間の包含や信頼区間を意味しない。
$S$ が小さければ線形化と逆算の条件を改めて調べる必要がある。

セルでは `ApproxPolynomial::monomial` で校正式を作り、`derivative` で感度の多項式を新しく作る。
単項式基底の `derivative` は係数 $k c_k$ を並べ直すだけなので、丸めは各係数の掛け算の 1 回で済む。
どちらの多項式も `evaluate`（Horner 法）で値を読む。

## 起電力と感度の照合

操作入力は観測温度 $T$ と電圧の標準不確かさ $u_E$ である。
1 つ目の表は0・100・200・300・400 °Cでの起電力と感度を表9.3.3と比べる。
表9.3.3の値は丸めてあるので、起電力の差が ±0.05 µV、感度の差が ±0.0005 µV/°C 以内なら表と一致している。
2 つ目の表は観測点の起電力、感度と一次伝播の $u_T$ である。
グラフは校正式と感度の曲線で、横軸の温度は二つのグラフで連動し、縦線は選んだ観測温度を示す。

5 点の起電力の差は最大で0.030 µV（400 °C）、感度の差は最大で0.0003 µV/°C（300 °C）で、どちらも表の丸め幅に収まる。
既定の200 °Cでは $S = 53.150$ µV/°C で、$u_E = 1$ µV は $u_T = 0.0188$ °C に対応する。
電圧の不確かさだけを変えても曲線は変わらず、一次伝播の温度不確かさだけが比例して変わる。
温度を動かすと感度が変わり、同じ $u_E=1$ µVでも $u_T$ は0 °Cの0.0258 °Cから400 °Cの0.0162 °Cまで小さくなる。

## 逆校正と根の条件数

測定した起電力 $E_{\rm meas}$ から温度を戻すには、$E(T)-E_{\rm meas}=0$ の $[0,400]$ にある根を求める。
`try_sub` で定数の多項式を引き、`to_orthogonal` で中心200、尺度200の Legendre 展開に変換してから、`root_matrix` で根を固有値に持つ根を固有値に持つ行列（この基底では三項漸化式から作る comrade 行列）を作る。
単項式のままの根を固有値に持つ行列（companion 行列）は係数比 $c_k/c_8$ を成分に持ち、その大きさは $10^{18}$ 程度まで広がる。
温度を $t=(T-200)/200\in[-1,1]$ に移すと、展開係数の大きさがそろう。
根を固有値に持つ行列の固有値は scioxide-linalg の非対称行列の固有値計算 `GeneralEigenvaluesResult::compute`（平衡化、Hessenberg 化、Francis の QR 法）で求める。
comrade 行列の固有値は物理変数 $T$ の座標で返るので、実部が $[0, 400]$ にある候補を元の式へ戻して残差を確かめる。
$E$ は単調なので区間内の実根は一つで、虚部が最も小さい候補がそれに当たる。

根の精度の目安は根の絶対条件数

$$
\kappa(T^*) = \frac{\sum_k |a_k|\,|T^*|^k}{|p'(T^*)|}
$$

で表せる（Higham, *Accuracy and Stability of Numerical Algorithms*, 2002, §5.1）。
ここで $p(T) = E(T) - E_{\rm meas}$、$a_k$ はその単項式係数で、$p'(T^*) = S(T^*)$ である。
各係数を相対的に $\eta$ だけ動かすと、根は一次の近似で最大 $\kappa\,\eta$ [°C] 動く。
`ApproxPolynomial::root_condition` がこの値を返す。
表9.3.1の係数は有効数字11桁なので、$\eta = 5 \times 10^{-11}$ とおけば、係数の丸めが逆算温度に与える影響を見積もれる。

独立検算として、表A9.1の近似逆関数 $T_{\rm A9.1}(E)=\sum_{i=1}^6d_iE^i$ の値と比べる。
係数 $d_i$ は SRD 60 のミリボルト単位の値をマイクロボルト単位に換算したもので、表A9.1と同じである。

操作入力は測定した起電力 $E_{\rm meas}$ で、範囲は基準関数の値域 0–20871.97 µVの内側にとる。
表は根を固有値に持つ行列による逆算温度、選んだ固有値の虚部、戻した電圧の残差、根の絶対条件数、係数の丸めによる温度の変動の見積もり $\kappa\,\eta$、近似逆関数の温度とその差を示す。

```rust
//| id: poly-thermocouple-inverse
//| ref: poly-thermocouple-inverse
//| title: 根を固有値に持つ行列による逆校正を NIST の近似逆関数と比べる
//| run: reactive
//| uses: [poly-thermocouple-model]
//| crates: [scioxide-core, scioxide-linalg, scioxide-poly]
//| inputs:
//|   measured_voltage: {"type":"range","label":"測定した起電力 E_meas [µV]","min":0,"max":20800,"step":100,"value":9300}
//| cases:
//|   - {"id":"low-voltage","label":"E_meas = 400 µV","description":"近似逆関数の誤差が ±0.03 °C の端に近い。","inputs":{"measured_voltage":400}}
//|   - {"id":"high-voltage","label":"E_meas = 20800 µV","description":"適用範囲の上端 400 °C の近く。","inputs":{"measured_voltage":20800}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"inverse","path":"/rows/0/0","approx":{"value":200.223831132723,"rtol":1e-12}}
//|       - {"artifact":"inverse","path":"/rows/0/2","range":{"min":-1e-9,"max":1e-9}}
//|       - {"artifact":"inverse","path":"/rows/0/6","range":{"min":-0.03,"max":0.03}}
//|   - case: low-voltage
//|     expect:
//|       - {"artifact":"inverse","path":"/rows/0/0","approx":{"value":10.2280948171119,"rtol":1e-11}}
//|       - {"artifact":"inverse","path":"/rows/0/6","range":{"min":-0.03,"max":0.03}}
//|   - case: high-voltage
//|     expect:
//|       - {"artifact":"inverse","path":"/rows/0/0","approx":{"value":398.835321823694,"rtol":1e-12}}
//|       - {"artifact":"inverse","path":"/rows/0/6","range":{"min":-0.03,"max":0.03}}
use scioxide_linalg::GeneralEigenvaluesResult;
use scioxide_poly::{
    ApproxPolynomial, BasisNormalization, OrthogonalBasisSpec, OrthogonalFamily,
};

let calibration = reference_function().map_err(|e| e.to_string())?;
// p(T) = E(T) − E_meas を、温度 [0, 400] °C を t = (T − 200)/200 ∈ [−1, 1] に移す Legendre 展開にする
let spec = OrthogonalBasisSpec::new(
    OrthogonalFamily::Legendre,
    BasisNormalization::Classical,
    200.0_f64,
    200.0,
)
.map_err(|e| e.to_string())?;
let target = ApproxPolynomial::monomial(vec![measured_voltage]).map_err(|e| e.to_string())?;
let equation = calibration.try_sub(&target).map_err(|e| e.to_string())?;
let converted = equation.to_orthogonal(spec).map_err(|e| e.to_string())?;
let matrix = converted
    .polynomial()
    .root_matrix()
    .map_err(|e| e.to_string())?;
let roots = GeneralEigenvaluesResult::compute(&matrix).map_err(|e| e.to_string())?;
// 実部が区間内（固有値の丸めに対する余裕 1e-6 °C）の候補のうち、虚部が最小のもの
let root = roots
    .eigenvalues()
    .iter()
    .filter(|z| z.re >= -1e-6 && z.re <= 400.0 + 1e-6)
    .min_by(|a, b| a.im.abs().total_cmp(&b.im.abs()))
    .ok_or("適用区間に逆算の候補がない")?;
let inverse = root.re;
let residual = equation.evaluate(inverse).map_err(|e| e.to_string())?;
// 単項式係数に対する根の絶対条件数 Σ|a_k||T|^k / |p′(T)|
let condition = equation
    .root_condition(inverse)
    .map_err(|e| e.to_string())?
    .absolute()
    .value();
// 独立検算: 表A9.1 の近似逆関数（E は µV、0–400 °C、誤差 ±0.03 °C）
let approximate_inverse = ApproxPolynomial::monomial(vec![
    0.0_f64,
    2.592800e-2,
    -7.602961e-7,
    4.637791e-11,
    -2.165394e-15,
    6.048144e-20,
    -7.293422e-25,
])
.map_err(|e| e.to_string())?;
let nist = approximate_inverse
    .evaluate(measured_voltage)
    .map_err(|e| e.to_string())?;
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let fixed4 = serde_json::json!({ "fractionDigits": 4 });
let columns = serde_json::json!([
    { "key": "0", "label": "逆算温度 [°C]", "type": "number", "format": { "fractionDigits": 10 } },
    { "key": "1", "label": "固有値の虚部 [°C]", "type": "number", "format": sci3 },
    { "key": "2", "label": "残差 E(T) − E_meas [µV]", "type": "number", "format": sci3 },
    { "key": "3", "label": "根の絶対条件数 κ [°C]", "type": "number", "format": sci3, "nullText": "なし" },
    { "key": "4", "label": "κ × 5e-11 [°C]", "type": "number", "format": sci3, "nullText": "なし" },
    { "key": "5", "label": "表A9.1 の温度 [°C]", "type": "number", "format": fixed4 },
    { "key": "6", "label": "表A9.1 − 逆算温度 [°C]", "type": "number", "format": fixed4 }
]);
emit_table_with_columns!(
    columns,
    vec![(
        inverse,
        root.im,
        residual,
        condition,
        condition.map(|kappa| kappa * 5e-11),
        nist,
        nist - inverse
    )],
    metadata = serde_json::json!({ "id": "inverse" })
);
```

既定の $E_{\rm meas}=9300$ µVでは逆算温度は200.2238311327 °Cで、選んだ固有値の虚部は 0 である。
別に 50 桁の十進演算で Newton 法により求めた根 200.22383113272314… °C との差は $1.1\times10^{-13}$ °C で、戻した電圧の残差は $5.5\times10^{-12}$ µV である。
根の絶対条件数は $\kappa \approx 560$ °C で、機械イプシロン $\varepsilon \approx 2.2\times10^{-16}$ を掛けた $\kappa\varepsilon \approx 1.2 \times 10^{-13}$ °C は実際の誤差と同じ桁にある。
係数の丸めによる変動の見積もり $\kappa\eta \approx 2.8\times10^{-8}$ °C も、熱電対の測定で問題になる大きさよりずっと小さい。
近似逆関数との差は−0.0096 °Cで、表A9.1が示す ±0.03 °C の範囲に入る。

$E_{\rm meas} = 400$ µVでは近似逆関数との差が0.024 °C、20800 µVでは−0.020 °Cである。
同じ十進演算で100 µVから20800 µVまで100 µVごとに調べると、差の絶対値の最大は500 µVでの0.025 °Cで、どの点も ±0.03 °C に収まる。
根を固有値に持つ行列による逆算と独立な近似式が、近似式の誤差の範囲で整合することを確かめられる。
条件数は温度とともに増え、20800 µVでは $\kappa \approx 7.1 \times 10^{3}$ °C になる。
$\sum_k|a_k||T|^k$ が高次の項とともに大きくなる一方で、分母の感度 $S$ は 0–400 °C で 1.6 倍しか変わらないためである。

## 区間平均と独立検算

温度を0から $T_{\max}$ まで一様に掃引したときの平均起電力は

$$
\overline E=\frac1{T_{\max}}\int_0^{T_{\max}}E(T)\,dT
$$

である。
これは温度に一様な平均であり、任意の時間変化や空間分布での平均ではない。
単項式の `ApproxPolynomial::integral` は係数を項別に積分した原始関数を Horner 法で評価するので、手で書く項別積分と同じ計算になる。
ここでは別の経路にするため、Legendre 展開に変換して `integral` で計算する。
直交展開の `integral` は展開のまま原始関数の係数を作り、Clenshaw の漸化式で評価する。
独立検算は係数の項別積分 $\sum_k c_kT_{\max}^{k}/(k+1)$ で、$T_{\max}^k$ は f64 の `powi` で作る参照値である。

操作入力は平均を取る上限温度 $T_{\max}$ である。
表は平均起電力と、項別積分との差を示す。

```rust
//| id: poly-thermocouple-average
//| ref: poly-thermocouple-average
//| title: Legendre 展開の積分で温度平均の起電力を求める
//| run: reactive
//| uses: [poly-thermocouple-model]
//| crates: [scioxide-core, scioxide-poly]
//| inputs:
//|   upper_temperature: {"type":"range","label":"平均の上限温度 T_max [°C]","min":50,"max":400,"step":50,"value":400}
//| cases:
//|   - {"id":"short-range","label":"T_max = 50 °C","description":"区間が短く、平均は線形項だけの値から 3% ずれる。","inputs":{"upper_temperature":50}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"average","path":"/rows/0/1","approx":{"value":9667.49773081383,"rtol":1e-12}}
//|       - {"artifact":"average","path":"/rows/0/2","range":{"min":-1e-9,"max":1e-9}}
//|   - case: short-range
//|     expect:
//|       - {"artifact":"average","path":"/rows/0/1","approx":{"value":1000.66239223867,"rtol":1e-12}}
//|       - {"artifact":"average","path":"/rows/0/2","range":{"min":-1e-9,"max":1e-9}}
use scioxide_poly::{BasisNormalization, OrthogonalBasisSpec, OrthogonalFamily};

let calibration = reference_function().map_err(|e| e.to_string())?;
// 温度 [0, 400] °C を t = (T − 200)/200 ∈ [−1, 1] に移す Legendre 展開
let spec = OrthogonalBasisSpec::new(
    OrthogonalFamily::Legendre,
    BasisNormalization::Classical,
    200.0_f64,
    200.0,
)
.map_err(|e| e.to_string())?;
let expansion = calibration.to_orthogonal(spec).map_err(|e| e.to_string())?;
let average = expansion
    .polynomial()
    .integral(0.0, upper_temperature)
    .map_err(|e| e.to_string())?
    / upper_temperature;
// 独立検算: 係数の項別積分 Σ c_k T_max^k / (k + 1)（powi は f64 の参照値）
let reference_average = TYPE_T_COEFFICIENTS
    .iter()
    .enumerate()
    .map(|(k, &c)| c * upper_temperature.powi(k as i32) / (k + 1) as f64)
    .sum::<f64>();
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let columns = serde_json::json!([
    { "key": "0", "label": "上限温度 T_max [°C]", "type": "number", "format": { "fractionDigits": 0 } },
    { "key": "1", "label": "平均起電力 [µV]", "type": "number", "format": { "fractionDigits": 6 } },
    { "key": "2", "label": "項別積分との差 [µV]", "type": "number", "format": sci3 }
]);
emit_table_with_columns!(
    columns,
    vec![(upper_temperature, average, average - reference_average)],
    metadata = serde_json::json!({ "id": "average" })
);
```

平均起電力は $T_{\max}=400$ °Cで9667.4977 µV、$T_{\max}=50$ °Cで1000.6624 µVで、項別積分との差はどちらも $4\times10^{-12}$ µV以下である。
$T_{\max}=50$ °Cの平均は、線形項だけの値 $c_1T_{\max}/2 = 968.70$ µVより3.3%大きく、二次以上の項の寄与が平均にも残る。
基底の積分と項別積分が一致することは数値的な検算であり、材料や測定器の不確かさを評価した結果ではない。

## まとめ

校正式は出典・単位・基準接点・適用範囲をそろえて使い、基準表の値と丸め幅の範囲で一致することを先に確かめる。
導関数は逆算の局所感度で、電圧の不確かさを $u_T\approx u_E/S$ で温度に換算する。
逆校正は根を固有値に持つ行列の固有値を元の式へ戻し、温度の差、電圧の残差、根の条件数を別々に確認する。
定積分は指定した温度分布での平均に対応し、ここでは項別積分と別の経路にするため、単項式から直交展開へ明示的に変換して計算する。
