根が互いに離れた多項式でも、係数から根を求める問題が良条件とは限らない。
Wilkinson 多項式 $W_n(x)=\prod_{j=1}^n(x-j)$ は、根が 1 ずつ離れた整数であるにもかかわらず、係数の小さな誤差で根が大きく動く例である（J. H. Wilkinson, 1959）。
このページでは根の位置の誤差を三つの原因に分けて観察する。
一つ目は係数を binary64 に格納するときの丸め、二つ目は意図的に加える係数の摂動、三つ目は根を計算するアルゴリズム（根を固有値に持つ行列の固有値計算）の誤差である。
係数・根・摂動の量はすべて無次元である。

## 単純根での閉じた条件数

$W_n(x)=\sum_ja_jx^j$ の係数は符号が交互に変わり、その絶対値は $\prod_{j=1}^n(x+j)$ の係数に等しい。
したがって根 $k$ において

$$
|W_n'(k)|=\prod_{j\ne k}|k-j|=(k-1)!\,(n-k)!,\qquad
\sum_j|a_j|k^j=\prod_{j=1}^n(k+j)=\frac{(k+n)!}{k!}
$$

であり、[単純根の感度](oxref:poly-simple-root-sensitivity)の式に代入すると

$$
\kappa_{\rm abs}(k)=\frac{(k+n)!}{k!\,(k-1)!\,(n-k)!}
$$

となる。
$\kappa_{\rm abs}$ は、各係数を $|\Delta a_j|\le\eta|a_j|$ の範囲で動かしたときの根の移動 $|\Delta r_k|\lesssim\eta\,\kappa_{\rm abs}(k)$ の一次の係数である。
導関数そのものは $W_n'(k)=(-1)^{n-k}(k-1)!\,(n-k)!$ で、その符号は隣り合う根で交互に変わる。

次の定義のブロックは整数係数と二つの閉形式を Rust の関数にしたものである。
`wilkinson_coefficients` は $(x-k)$ を順に掛けて係数を `i128` で正確に作り、`derivative_at_root` が $W_n'(k)$、`closed_condition` が $\kappa_{\rm abs}(k)$ を返す。
階乗は `f64` の積で求め、$22!$ までは正確で、それより大きい引数では乗算 1 回ごとに相対 $u$ 以下の丸めが加わる。

```rust
//| id: poly-wilkinson-model
//| kind: definitions
//| title: Wilkinson 多項式の整数係数と閉じた条件数
//| crates: []
/// W_n(x) = (x − 1)(x − 2)…(x − n) の整数係数 a_0, …, a_n（昇べき順）。
/// n ≤ 20 では |a_j| < 2⁶⁴ なので i128 で正確に作れる。
pub(crate) fn wilkinson_coefficients(n: usize) -> Vec<i128> {
    let mut coefficients = vec![1_i128];
    for k in 1..=n {
        // 現在の多項式に (x − k) を掛ける。
        coefficients.push(0);
        for j in (1..coefficients.len()).rev() {
            coefficients[j] = coefficients[j - 1] - k as i128 * coefficients[j];
        }
        coefficients[0] *= -(k as i128);
    }
    coefficients
}

/// m! を f64 の積で返す。22! までは正確に表せる。
pub(crate) fn factorial(m: usize) -> f64 {
    (1..=m).map(|j| j as f64).product()
}

/// 根 k での導関数 W_n′(k) = (−1)^(n−k) (k−1)! (n−k)!。
pub(crate) fn derivative_at_root(n: usize, k: usize) -> f64 {
    let sign = if (n - k) % 2 == 0 { 1.0 } else { -1.0 };
    sign * factorial(k - 1) * factorial(n - k)
}

/// 根 k の絶対条件数 κ_abs(k) = (k+n)! / (k! (k−1)! (n−k)!)。
pub(crate) fn closed_condition(n: usize, k: usize) -> f64 {
    factorial(k + n) / (factorial(k) * factorial(k - 1) * factorial(n - k))
}
```

## 係数の丸め

$W_{20}$ の係数は $2^{53}$ を超える整数を含むので、binary64 に格納するとき正確に表せないものがある。
丸めによる係数の誤差 $\Delta a_j$ は、格納した値を整数に戻して元の整数と比べれば正確に求まる。
格納した多項式の根の一次の移動は、単純根の感度の式から

$$
\Delta r_k\approx-\frac{\sum_j\Delta a_jk^j}{W_n'(k)}
$$

である。
単位丸めを $u=2^{-53}\approx1.1\times10^{-16}$ とすると、各係数の相対誤差は $u$ 以下なので、$|\Delta r_k|$ は一次の範囲で $\kappa_{\rm abs}(k)\,u$ を超えない。
$\kappa_{\rm abs}u$ はすべての係数が最悪の向きに $u$ だけ動いた場合の見積もりで、実際の丸めは一部の係数にしか起こらないので、一次の予測はこれよりずっと小さくなりうる。

次のセルは次数 $n$ を入力とし、整数係数を一度だけ binary64 に丸めて、三つの表を出す。
一つ目は係数ごとに、格納値、丸めの誤差 $\Delta a_j$、相対誤差と $u$ の比を並べる。
二つ目は整数根 $k$ ごとに、閉じた条件数、SciOxide の推定（`root_condition` が返す `RootConditionReport::absolute`）と閉形式の相対差、丸めによる移動の一次の予測、$\kappa_{\rm abs}u$ を並べる。
三つ目は丸めで変わった係数の数、一次の予測の最大値とその根、推定と閉形式の相対差の最大をまとめる。
閉形式は独立な検算に使い、SciOxide の推定は格納した係数で $z=k$ における $\sum_j|a_j||z|^j/|p'(z)|$ を浮動小数点で評価する。

```rust
//| id: poly-wilkinson-rounding
//| ref: poly-wilkinson-rounding
//| title: 係数の丸めと根の条件数
//| run: reactive
//| uses: [poly-wilkinson-model]
//| crates: [scioxide-poly]
//| inputs:
//|   degree: {"type":"range","label":"次数 n [-]","description":"W_n(x) = (x − 1)(x − 2)…(x − n) の次数。","min":6,"max":20,"step":1,"value":20}
//| cases:
//|   - {"id":"degree-19","label":"n = 19","description":"丸められる係数は a₄ と a₅ の二つになる。","inputs":{"degree":19}}
//|   - {"id":"degree-18","label":"n = 18","description":"係数はすべて正確に格納され、丸めによる根の移動は 0 になる。","inputs":{"degree":18}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"coefficients","path":"/rows/2/1","approx":{"value":1.380375975364070e19,"rtol":1e-12}}
//|       - {"artifact":"coefficients","path":"/rows/5/3","range":{"min":0.0,"max":1.0}}
//|       - {"artifact":"roots","path":"/rows/13/1","approx":{"value":7.5528e14,"rtol":1e-4}}
//|       - {"artifact":"roots","path":"/rows/12/3","approx":{"value":-6.19e-4,"rtol":5e-3}}
//|       - {"artifact":"summary","path":"/rows/0/0","equals":5}
//|       - {"artifact":"summary","path":"/rows/0/2","equals":13}
//|       - {"artifact":"summary","path":"/rows/0/3","range":{"min":1e-3,"max":2e-2}}
//|   - case: degree-19
//|     expect:
//|       - {"artifact":"summary","path":"/rows/0/0","equals":2}
//|       - {"artifact":"coefficients","path":"/rows/4/3","range":{"min":0.0,"max":1.0}}
//|   - case: degree-18
//|     expect:
//|       - {"artifact":"summary","path":"/rows/0/0","equals":0}
//|       - {"artifact":"summary","path":"/rows/0/1","approx":{"value":0.0,"atol":1e-300}}
use scioxide_poly::ApproxPolynomial;

let n = degree as usize;
let unit_roundoff = f64::EPSILON / 2.0;
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let sci6 = serde_json::json!({ "notation": "scientific", "significantDigits": 6 });
let fixed3 = serde_json::json!({ "fractionDigits": 3 });

// 整数係数を正確に作ってから、一度だけ binary64 に丸める。
let integers = wilkinson_coefficients(n);
let stored: Vec<f64> = integers.iter().map(|&a| a as f64).collect();
// Δa_j = 格納値 − 整数値。格納値は整数なので i128 に戻して正確に引ける。
let rounding: Vec<f64> = integers
    .iter()
    .zip(&stored)
    .map(|(&exact, &value)| (value as i128 - exact) as f64)
    .collect();
let coefficient_rows: Vec<(usize, f64, f64, f64)> = stored
    .iter()
    .zip(&rounding)
    .enumerate()
    .map(|(j, (&a, &d))| (j, a, d, (d / a).abs() / unit_roundoff))
    .collect();
emit_table_with_columns!(
    serde_json::json!([
        { "key": "0", "label": "次数 j", "type": "integer" },
        { "key": "1", "label": "格納した係数 a_j [-]", "type": "number", "format": sci6 },
        { "key": "2", "label": "丸めの誤差 Δa_j [-]", "type": "number" },
        { "key": "3", "label": "|Δa_j| / (|a_j| u) [-]", "type": "number", "format": fixed3 }
    ]),
    coefficient_rows,
    metadata = serde_json::json!({ "id": "coefficients" })
);

let polynomial = ApproxPolynomial::monomial(stored).map_err(|e| e.to_string())?;
let mut rows = Vec::new();
for k in 1..=n {
    let x = k as f64;
    let condition = closed_condition(n, k);
    // SciOxide の推定: 格納した係数で z = k における RootConditionReport::absolute
    let estimate = polynomial
        .root_condition(x)
        .map_err(|e| e.to_string())?
        .absolute()
        .value()
        .ok_or("条件数の推定が得られない")?;
    // 独立検算: Σ Δa_j k^j を Horner 法で求める。Δa_j と k^j は整数で、和は 2⁵³ 未満なので正確。
    let shift = rounding.iter().rev().fold(0.0, |sum, &d| sum * x + d);
    let predicted = -shift / derivative_at_root(n, k);
    rows.push((
        k,
        condition,
        estimate / condition - 1.0,
        predicted,
        condition * unit_roundoff,
    ));
}
emit_table_with_columns!(
    serde_json::json!([
        { "key": "0", "label": "整数根 k", "type": "integer" },
        { "key": "1", "label": "κ_abs（閉形式）[-]", "type": "number", "format": sci3 },
        { "key": "2", "label": "推定 / 閉形式 − 1 [-]", "type": "number", "format": sci3 },
        { "key": "3", "label": "丸めによる移動の一次予測 Δr_k [-]", "type": "number", "format": sci3 },
        { "key": "4", "label": "κ_abs·u [-]", "type": "number", "format": sci3 }
    ]),
    rows.clone(),
    metadata = serde_json::json!({ "id": "roots" })
);

let largest = rows
    .iter()
    .max_by(|a, b| a.3.abs().total_cmp(&b.3.abs()))
    .ok_or("根がない")?;
let gap = rows.iter().map(|row| row.2.abs()).fold(0.0_f64, f64::max);
let changed = rounding.iter().filter(|&&d| d != 0.0).count();
emit_table_with_columns!(
    serde_json::json!([
        { "key": "0", "label": "丸めで変わった係数の数", "type": "integer" },
        { "key": "1", "label": "一次予測の最大 |Δr_k| [-]", "type": "number", "format": sci3 },
        { "key": "2", "label": "最大となる根 k", "type": "integer" },
        { "key": "3", "label": "推定と閉形式の相対差の最大 [-]", "type": "number", "format": sci3 }
    ]),
    vec![(changed, largest.3.abs(), largest.0, gap)],
    metadata = serde_json::json!({ "id": "summary" })
);
```

既定の $n=20$ では、$a_3,\dots,a_7$ の五つの係数が丸められ、それ以外の係数と $n\le18$ のすべての係数は正確に格納される。
$n=19$ で丸められるのは $a_4,a_5$ の二つである。
どの係数でも $|\Delta a_j|/(|a_j|u)$ は 1 以下で、binary64 への格納が相対誤差 $u$ 以下の丸めであることを確かめられる。
最大の係数は定数項 $20!\approx2.43\times10^{18}$ ではなく、$x^2$ の係数 $1.38\times10^{19}$ である。

条件数は $k=11$ から 18 で $10^{14}$ を超え、最大は $k=14,15$ の $7.55\times10^{14}$ である。
したがって $\kappa_{\rm abs}u$ は最大 $0.084$ に達する。
実際の丸めによる一次の移動は $k=13$ の $-6.19\times10^{-4}$ が最大で、$\kappa_{\rm abs}u$ の 100 分の 1 程度にとどまる。
この移動は根の間隔 1 より十分小さく、二次の項はさらに小さいので、一次の予測で格納した多項式の根の位置をよく近似できる。
単純な実根は小さな実の摂動では実根のままなので、格納した係数の多項式の根はすべて実数で、整数から $10^{-3}$ 以内にあると見積もれる。
これより大きなずれや複素数の根が計算に現れたら、それは係数の丸めではなく根の計算の誤差である。

SciOxide の推定と閉形式の相対差は最大 $7.5\times10^{-3}$ である。
格納した係数の丸めが $p'(k)$ を変える割合は $3\times10^{-4}$ 程度なので、差の大部分は $z=k$ での $p'(z)$ の浮動小数点の評価の丸めによる。
条件数は一次の推定値として使う量であり、この程度の相対差は読み方を変えない。

## 一係数の摂動と線形化

$x^{n-1}$ の係数から $\delta$ を引く（$a_{n-1}=-n(n+1)/2$ を $a_{n-1}-\delta$ にする）と、$p(x)=W_n(x)-\delta x^{n-1}$ の根の一次の移動は

$$
\Delta r_k\approx\frac{\delta\,k^{n-1}}{W_n'(k)}
$$

となる。
Wilkinson の古典的な例 $n=20$、$\delta=2^{-23}\approx1.19\times10^{-7}$ では、予測の絶対値が $k\ge10$ で $0.9$ を超え、$k=16$ では 287 に達する。
予測が根の間隔に近づく範囲では、一次の近似を実際の移動量として解釈することはできない。
実際には隣り合う根が衝突して複素共役の組に分かれ、$10.10\pm0.64i$、$11.79\pm1.65i$、$13.99\pm2.52i$、$16.73\pm2.81i$、$19.50\pm1.94i$ の 5 組と、実根 $8.007$、$8.92$、$20.85$ などになる。
実係数の多項式なので、複素数の根は必ず共役の組で現れる。

$\delta$ が小さいと、指定した減算が格納した係数を変えないことがある。
$a_{19}=-210$ の ULP は $2^{-45}$ なので、$\delta=2^{-p}$ が ULP の半分 $2^{-46}$ より小さい $p\ge47$ では差は丸めで消える。
ちょうど半分の $p=46$ では偶数への丸めで $-210$ に戻るので、$p\ge46$ で格納された変化量は 0 になる。
入力の摂動量と、実際に格納した変化量を両方確認する。

## 基底と入力誤差のモデル

根を固有値に持つ行列には単項式の伴行列のほか、直交基底の colleague 行列（[根を固有値に持つ行列と根の感度](oxref:poly-orthogonal-root-matrix)）も使える。
ここでは格納した単項式係数を `to_orthogonal` で Chebyshev 基底に変換してから colleague 行列を作る。
基底の座標 $t=(x-(n+1)/2)/((n-1)/2)$ は、根の区間 $[1,n]$ を $[-1,1]$ に移す。
変換は丸めた単項式係数から始まるので、最初の丸めで失われた情報は戻らず、変換そのものにも丸めが加わる。

固有値計算は行列に対して後退安定で、計算した固有値は行列のノルムに比べて小さい摂動を加えた行列の厳密な固有値である。
伴行列では、この行列の摂動が一次で係数の摂動に写り、その大きさは個々の $|a_j|$ ではなく係数全体の大きさで決まる（Edelman–Murakami, 1995）。
したがって絶対値の小さい係数には、成分ごとの相対誤差として $u$ よりずっと大きい摂動が加わりうる。
二つの基底では、固有値計算が引き起こす係数への後退誤差の形が異なる。
次のセルの比較は同じ格納多項式を別の行列で解く比較であり、同じ大きさの係数誤差を二つの基底に加える実験ではない。

## 丸め・摂動・アルゴリズムの誤差の比較

次のセルの入力は次数 $n$、摂動 $\delta=2^{-p}$ の指数 $p$、根を固有値に持つ行列の種類である。
丸めた係数と摂動後の係数のそれぞれで根を固有値に持つ行列を作り、`scioxide-linalg` の一般の固有値計算（既定で平衡化する）で根の候補を求める。
表は整数根 $k$ ごとに、摂動による移動の一次の予測、二つの係数の組それぞれで最も近い候補までの距離、$\kappa_{\rm abs}u$ を並べる。
「最寄り候補への距離」は根を一対一に追跡した結果ではない。
二つ目の表は要求した $\delta$、格納された $\delta$、実数でない候補の数である。
このセルは係数と候補を次の診断のセルに渡す。

```rust
//| id: poly-wilkinson-root-sensitivity
//| ref: poly-wilkinson-root-sensitivity
//| title: 係数の丸めと摂動後の根
//| run: reactive
//| uses: [poly-wilkinson-model]
//| crates: [scioxide-core, scioxide-linalg, scioxide-poly]
//| exports: [coefficients, candidates]
//| inputs:
//|   degree: {"type":"range","label":"次数 n [-]","description":"W_n(x) の次数。n ≤ 18 では係数の丸めがない。","min":6,"max":20,"step":1,"value":20}
//|   exponent: {"type":"range","label":"摂動 δ = 2⁻ᵖ の p","description":"x^(n−1) の係数から引く量の指数。","min":10,"max":50,"step":1,"value":23}
//|   basis: {"type":"select","label":"根を固有値に持つ行列","options":["単項式（伴行列）","Chebyshev（colleague 行列）"],"value":"単項式（伴行列）"}
//| cases:
//|   - {"id":"colleague","label":"colleague 行列","description":"丸めた係数の候補はすべて実数になり、距離は κ_abs·u の範囲に収まる。","inputs":{"basis":"Chebyshev（colleague 行列）"}}
//|   - {"id":"large-perturbation","label":"p = 10","description":"δ = 2⁻¹⁰ では 12 個の候補が実数でなくなり、一部は図の範囲の外に出る。","inputs":{"exponent":10}}
//|   - {"id":"degree-17","label":"n = 17","description":"係数の丸めがなくても、伴行列の候補の誤差は κ_abs·u を超える。","inputs":{"degree":17}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"roots","path":"/rows/15/1","approx":{"value":286.9,"rtol":1e-3}}
//|       - {"artifact":"roots","path":"/rows/14/2","range":{"min":0.3,"max":0.9}}
//|       - {"artifact":"roots","path":"/rows/7/3","approx":{"value":7.45e-3,"rtol":5e-2}}
//|       - {"artifact":"summary","path":"/rows/0/1","approx":{"value":1.1920928955078125e-7,"rtol":1e-12}}
//|       - {"artifact":"summary","path":"/rows/0/2","equals":4}
//|       - {"artifact":"summary","path":"/rows/0/3","equals":10}
//|   - case: colleague
//|     expect:
//|       - {"artifact":"summary","path":"/rows/0/2","equals":0}
//|       - {"artifact":"roots","path":"/rows/14/2","range":{"min":1e-3,"max":8.39e-2}}
//|       - {"artifact":"roots","path":"/rows/7/3","approx":{"value":7.37e-3,"rtol":5e-2}}
//|   - case: large-perturbation
//|     expect:
//|       - {"artifact":"summary","path":"/rows/0/3","equals":12}
//|   - case: degree-17
//|     expect:
//|       - {"artifact":"summary","path":"/rows/0/2","equals":0}
//|       - {"artifact":"roots","path":"/rows/12/2","range":{"min":4.2e-4,"max":5e-3}}
use scioxide_core::Complex;
use scioxide_linalg::GeneralEigenvaluesResult;
use scioxide_poly::{
    ApproxPolynomial, BasisNormalization, OrthogonalBasisSpec, OrthogonalFamily,
};

let n = degree as usize;
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let base: Vec<f64> = wilkinson_coefficients(n)
    .iter()
    .map(|&a| a as f64)
    .collect();
// x^(n−1) の係数から δ = 2^(−p) を引く。格納された変化量は丸めで δ と異なりうる。
let requested = 0.5_f64.powi(exponent as i32);
let mut changed = base.clone();
changed[n - 1] -= requested;
let stored_delta = base[n - 1] - changed[n - 1];
// Chebyshev 基底は根の区間 [1, n] を [−1, 1] に移す座標で作る。
let spec = OrthogonalBasisSpec::new(
    OrthogonalFamily::ChebyshevT,
    BasisNormalization::Classical,
    (n + 1) as f64 / 2.0,
    (n - 1) as f64 / 2.0,
)
.map_err(|e| e.to_string())?;
let mut spectra = Vec::new();
for coefficients in [&base, &changed] {
    let p = ApproxPolynomial::monomial(coefficients.clone()).map_err(|e| e.to_string())?;
    let matrix = match basis.as_str() {
        "単項式（伴行列）" => p.root_matrix(),
        _ => p
            .to_orthogonal(spec)
            .map_err(|e| e.to_string())?
            .polynomial()
            .root_matrix(),
    }
    .map_err(|e| e.to_string())?;
    let eigen = GeneralEigenvaluesResult::compute(&matrix).map_err(|e| e.to_string())?;
    spectra.push(eigen.eigenvalues().to_vec());
}
let nearest = |roots: &[Complex<f64>], k: f64| {
    roots
        .iter()
        .map(|&z| (z - Complex::new(k, 0.0)).norm())
        .fold(f64::INFINITY, f64::min)
};
let rows: Vec<_> = (1..=n)
    .map(|k| {
        let x = k as f64;
        // 一次の予測 Δr_k ≈ δ k^(n−1) / W_n′(k)。δ は格納された変化量を使う。
        let predicted = stored_delta * x.powi(n as i32 - 1) / derivative_at_root(n, k);
        let unit = closed_condition(n, k) * f64::EPSILON / 2.0;
        (
            k,
            predicted,
            nearest(&spectra[0], x),
            nearest(&spectra[1], x),
            unit,
        )
    })
    .collect();
emit_table_with_columns!(
    serde_json::json!([
        { "key": "0", "label": "整数根 k", "type": "integer" },
        { "key": "1", "label": "摂動による移動の一次予測 [-]", "type": "number", "format": sci3 },
        { "key": "2", "label": "丸めた係数: 最寄り候補への距離 [-]", "type": "number", "format": sci3 },
        { "key": "3", "label": "摂動後: 最寄り候補への距離 [-]", "type": "number", "format": sci3 },
        { "key": "4", "label": "κ_abs·u [-]", "type": "number", "format": sci3 }
    ]),
    rows,
    metadata = serde_json::json!({ "id": "roots" })
);
let nonreal = |roots: &[Complex<f64>]| roots.iter().filter(|z| z.im != 0.0).count();
emit_table_with_columns!(
    serde_json::json!([
        { "key": "0", "label": "要求した δ [-]", "type": "number", "format": sci3 },
        { "key": "1", "label": "格納された δ [-]", "type": "number", "format": sci3 },
        { "key": "2", "label": "実数でない候補（丸めた係数）", "type": "integer" },
        { "key": "3", "label": "実数でない候補（摂動後）", "type": "integer" }
    ]),
    vec![(
        requested,
        stored_delta,
        nonreal(&spectra[0]),
        nonreal(&spectra[1])
    )],
    metadata = serde_json::json!({ "id": "summary" })
);
// 候補は (実部, 虚部) の組で次のセルに渡す。
let points: Vec<Vec<[f64; 2]>> = spectra
    .iter()
    .map(|roots| roots.iter().map(|z| [z.re, z.im]).collect())
    .collect();
export!(coefficients, &vec![base, changed]);
export!(candidates, &points);
```

既定の $n=20$、$p=23$、伴行列では、丸めた係数の候補のうち 4 個が実数でなくなり、$k=13$〜16 の最寄り候補への距離は 0.49〜0.58 になる。
格納した多項式の根は丸めの一次予測どおり整数から $6.2\times10^{-4}$ 以内にあるので、このずれは固有値計算の誤差である。
しかも距離は $\kappa_{\rm abs}u\approx0.06$〜0.08 の 7〜8 倍あり、候補は格納した係数を成分ごとに相対 $u$ だけ動かした多項式の根としては説明できない。
次の節で、各候補を厳密な根に持つ多項式の係数がどれだけ動いているか（後退誤差）を測る。
係数の丸めがない $n=17$ でも、伴行列の候補の距離は $k=13$ で $1.07\times10^{-3}$ と $\kappa_{\rm abs}u=4.1\times10^{-4}$ を超える。
この誤差の大きさは多項式だけでは決まらず、固有値計算の平衡化や収束の判定にも左右される。

colleague 行列に切り替えると、丸めた係数の候補はすべて実数になり、最寄り候補への距離は最大 $1.6\times10^{-2}$（$k=15$）で $\kappa_{\rm abs}u$ の範囲に収まる。
それでも同じ $k=15$ の丸めの一次予測 $3.7\times10^{-4}$ の 40 倍あり、残りは基底変換と固有値計算の丸めによる。

摂動後の係数では、どちらの根を固有値に持つ行列でも 10 個の候補が 5 組の複素共役になる。
colleague 行列では $k=7,8$ で一次予測と最寄り候補への距離が 6% 以内で一致する（$k=8$ で $7.12\times10^{-3}$ と $7.37\times10^{-3}$）。
$k\le6$ では摂動による移動が $10^{-5}$ 以下と小さく、係数の丸めとアルゴリズムの誤差が同じ程度に加わるので、距離は予測から 30% 以上離れる。
$k=9$ では予測 $0.100$ に対して距離 $0.083$ と線形化の誤差が見え始め、$k\ge10$ では予測が実際の移動を大きく超える。
伴行列では、$k\le7$ の小さい移動に固有値計算の誤差が加わる。
たとえば $k=5$ の予測 $7.2\times10^{-8}$ に対し、距離は $5.1\times10^{-6}$ である。

$p=10$ では摂動が大きく、伴行列で 12 個の候補が実数でなくなる。
$n=17$ では丸めた係数の候補はすべて実数のままで、摂動後に 6 個が実数でなくなる。
$p\ge46$ では格納された $\delta$ が 0 になり、二つの系列は同じ多項式の候補になる。

## 候補の事後診断

候補の精度を真の根を知らずに見積もるには、`polynomial_root_diagnostics` を使う。
この関数は全候補から Weierstrass 補正による円板を作り、重なった円板の連結成分をクラスタにまとめる（[根の候補と円板の推定](oxref:poly-root-candidate-disks)）。
厳密な算術では、ほかと交わらない $k$ 個の円板の和集合はちょうど $k$ 個の根を含む。
実装は浮動小数点で計算し、$p(z_i)$ の評価の丸めのモデルから作った項を半径に加える。
円板は推定であって包含が保証された区間ではない。

同じ診断は各候補 $z$ の成分ごとの後退誤差

$$
\eta(z)=\frac{|p(z)|}{\sum_j|a_j||z|^j}
$$

も与える（`RootConditionReport::coefficient` がその逆数を返す）。
$\eta(z)$ は、係数を $|\Delta a_j|\le\eta|a_j|$ の範囲で（複素数も許して）動かした多項式が $z$ を厳密な根に持つような、最小の $\eta$ である（Mosier, 1986; Toh–Trefethen, 1994）。
一次の範囲では候補と真の根の距離は $\eta\,\kappa_{\rm abs}$ を超えないので、$\eta\le u$ なら距離は $\kappa_{\rm abs}u$ に収まり、$\eta$ が $u$ を大きく超えればアルゴリズムが係数の丸めより大きな誤差を加えたことになる。
$\eta$ も浮動小数点で $p(z)$ を評価して求めるので、$u$ 程度の値は評価の丸めと同じ水準の目安として解釈する。

次のセルは前のセルの係数と候補を受け取り、候補を複素平面に描いて、二つの組それぞれの後退誤差の最大 $\eta/u$、クラスタの数、最大の円板の半径、状態を表にする。
状態は `RootDiagnosticsStatus` で、両方の組が `Estimated` なら outcome を satisfied、どちらかが `Inconclusive` なら partial にする。
入力は前のセルで変える。

```rust
//| id: poly-wilkinson-root-diagnostics
//| ref: poly-wilkinson-root-diagnostics
//| title: 根の候補の円板とクラスタ
//| run: reactive
//| crates: [scioxide-core, scioxide-poly]
//| dependsOn:
//|   roots: poly-wilkinson-root-sensitivity
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"clusters","path":"/rows/0/1","range":{"min":1.0,"max":1000.0}}
//|       - {"artifact":"clusters","path":"/rows/0/2","equals":1}
//|       - {"artifact":"clusters","path":"/rows/0/3","range":{"min":100.0,"max":5000.0}}
//|       - {"artifact":"clusters","path":"/rows/1/2","equals":1}
//|       - {"path":"/outputs/2/state","equals":"satisfied"}
use scioxide_core::Complex;
use scioxide_poly::{RootDiagnosticsStatus, RootEstimate, polynomial_root_diagnostics};

let unit_roundoff = f64::EPSILON / 2.0;
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let fixed1 = serde_json::json!({ "fractionDigits": 1 });
let coefficients: Vec<Vec<f64>> =
    serde_json::from_value(roots["coefficients"].clone()).map_err(|e| e.to_string())?;
let candidates: Vec<Vec<[f64; 2]>> =
    serde_json::from_value(roots["candidates"].clone()).map_err(|e| e.to_string())?;
let mut reports = Vec::new();
for (values, points) in coefficients.iter().zip(&candidates) {
    let roots: Vec<_> = points
        .iter()
        .map(|&[re, im]| Complex::new(re, im))
        .collect();
    // 単項式の係数と全候補から Weierstrass 円板を推定する。
    reports.push(polynomial_root_diagnostics(values, &roots).map_err(|e| e.to_string())?);
}
let rows: Vec<_> = ["丸めた係数", "摂動後の係数"]
    .iter()
    .zip(&reports)
    .map(|(name, report)| {
        let radius = report
            .roots()
            .iter()
            .filter_map(|root| root.disk().map(|disk| disk.radius().value()))
            .reduce(f64::max);
        // 成分ごとの後退誤差 η = |p(z)| / Σ|a_j||z|^j は B/|p(z)| の逆数で、p(z) = 0 なら 0。
        let backward = report
            .roots()
            .iter()
            .filter_map(|root| match root.condition().coefficient() {
                RootEstimate::Singular => Some(0.0),
                estimate => estimate.value().map(|c| 1.0 / c),
            })
            .reduce(f64::max);
        (
            *name,
            backward.map(|eta| eta / unit_roundoff),
            report.clusters().len(),
            radius,
            format!("{:?}", report.status()),
        )
    })
    .collect();
let n = candidates[0].len();
let integers_on_axis: Vec<_> = (1..=n).map(|k| [k as f64, 0.0]).collect();
emit_scatter_chart!(
    &vec![
        serde_json::json!({
            "name": "整数根 k（厳密な根）",
            "points": integers_on_axis,
            "style": { "symbol": "diamond" }
        }),
        serde_json::json!({ "name": "丸めた係数の候補", "points": candidates[0] }),
        serde_json::json!({ "name": "摂動後の係数の候補", "points": candidates[1] })
    ],
    options = &serde_json::json!({
        "xLabel": "根の実部 [-]",
        "yLabel": "根の虚部 [-]",
        "xMin": 0.0,
        "xMax": 24.0,
        "yMin": -8.0,
        "yMax": 8.0
    })
);
emit_table_with_columns!(
    serde_json::json!([
        { "key": "0", "label": "係数" },
        { "key": "1", "label": "後退誤差の最大 η/u [-]", "type": "number", "format": fixed1, "nullText": "なし" },
        { "key": "2", "label": "クラスタの数", "type": "integer" },
        { "key": "3", "label": "最大の円板の半径 [-]", "type": "number", "format": sci3, "nullText": "なし" },
        { "key": "4", "label": "診断の状態" }
    ]),
    rows,
    metadata = serde_json::json!({ "id": "clusters" })
);

let estimated = reports
    .iter()
    .all(|report| report.status() == RootDiagnosticsStatus::Estimated);
let outcome = if estimated {
    Outcome::satisfied("両方の候補の組で円板とクラスタを推定した")
        .explanation("円板は丸めのモデルによる推定で、根の位置や個数の証明ではない。")
} else {
    Outcome::partial("円板を推定できない候補があり、Cauchy の円板で代替した")
};
let status = format!("{:?} / {:?}", reports[0].status(), reports[1].status());
emit_outcome!(
    outcome
        .status(status)
        .diagnostic(
            "クラスタの数（摂動後）",
            reports[1].clusters().len() as f64,
            None
        )
        .diagnostic("候補の数", candidates[1].len() as f64, None)
);
```

図では、整数根（菱形）の近くに丸めた係数の候補が並び、摂動後の候補は $k\ge10$ の範囲で上下に分かれた共役の組になる。
図の範囲は古典的な摂動での比較のために固定しているので、$p=10$ のように範囲の外に出る候補は図の「データを表で表示」で確認する。
範囲の外に出ても、候補の個数が減ったわけではない。

丸めた係数の候補の後退誤差の最大は、伴行列で $158u$、colleague 行列で $0.72u$ である。
colleague 行列の候補は格納した係数を成分ごとに相対 $u$ 未満だけ動かした多項式の根にあたり、距離が $\kappa_{\rm abs}u$ に収まったことと合う。
伴行列の候補には後退誤差が $u$ を大きく超えるものがあり、距離が $\kappa_{\rm abs}u$ を超えたことと矛盾しない。

既定の入力では、どちらの組も `Estimated` だが、20 個の候補が一つのクラスタにまとまる。
丸めた係数の円板の最大の半径は伴行列で 902、colleague 行列で 567 で、実際の距離 0.6 や 0.016 よりはるかに大きい。
半径には $n\cdot8(n+1)\varepsilon\sum_j|a_j||z_i|^j/(|a_n|\prod_{j\ne i}|z_i-z_j|)$（$\varepsilon=2^{-52}=2u$）の項が含まれるからである。
候補が整数の近くにあれば分母は $|W_n'(k)|$ に近いので、この項は $16n(n+1)\,\kappa_{\rm abs}u\approx6700\,\kappa_{\rm abs}u$ になり、$k=14,15$ では 560 程度になる。
浮動小数点の円板はこの多項式の中央の根を分離できない。
前のセルで $p=10$ にすると、摂動後の根が複素平面で互いに離れ、20 個の円板が別々のクラスタになり、最大の半径も 0.11 にとどまる。
円板が分離しても推定であることは変わらないので、個数を証明するには次の validated の方法を使う。

同じ $n=20$ の丸めた係数を rootfind の四つの方式（伴行列の固有値と Aberth 法の仕上げ、Aberth 法、Durand–Kerner 法、Laguerre 法）で解く比較は [rootfind の多項式の全根](../../../scioxide-rootfind/algorithms/polynomial-root-pipeline/)にある。
整数の近くの円板に根が何個あるかを証明付きで数える方法は [validated の多項式の根の個数](oxref:validated-api-roots-polynomial)（`PolynomialRootPlan`）で扱う。

## まとめ

根が互いに離れていることだけでは係数に対して良条件とはいえず、Wilkinson 多項式 $W_{20}$ の条件数は $7.6\times10^{14}$ に達する。
係数の丸め、意図的な摂動、固有値計算の誤差は大きさが異なるので、丸めの一次予測と $\kappa_{\rm abs}u$ を基準にして切り分ける。
一次の感度は小さい局所的な摂動のモデルであり、予測が根の間隔に近づいた後や根が衝突した後には使えない。
伴行列の固有値は係数の成分ごとの誤差に対して後退安定ではないので、候補の後退誤差 $\eta$ を $u$ と比べ、悪条件の多項式では colleague 行列への切り替えや仕上げの反復を検討する。
`polynomial_root_diagnostics` の円板は推定であり、中央の根が一つのクラスタにまとまったら、証明付きの方法で個数を確かめる。
入力の摂動量は格納された変化量で確かめる。
