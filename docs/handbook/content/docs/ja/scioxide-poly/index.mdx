`scioxide-poly` は一変数多項式の表現と演算、補間、最小二乗近似、直交展開、有理関数、部分分数分解、終結式による消去、根の感度の診断、疎な多変数多項式を扱う。
係数の型は二種類ある。
`ApproxPolynomial` は実数か複素数の浮動小数点の係数を、明示した基底で保持する。
`ExactPolynomial` は利用者が用意する厳密な環・体の係数で、丸めなしに計算する。
同じ多項式でも、何を保存するか（係数・節点での値・制御点）によって丸め誤差の伝わり方が変わる。
このページでは低次の多項式を評価して値と診断の読み方を確かめ、表現の選び方と章の構成を示す。

## 最初の計算

昇べき順の係数 $[a_0,a_1,a_2]=[2,-3,1]$ は $p(x)=2-3x+x^2=(x-1)(x-2)$ を表す。
次のセルは `ApproxPolynomial::monomial` でこの多項式を作り、`evaluate_with_derivative` で評価点 $x$ での値、導関数、誤差の推定を一度に求める。
入力は評価点 $x$ で、入力も出力も無次元である。
独立な検算として、因数表示 $(x-1)(x-2)$、解析的な導関数 $2x-3$、診断の式（次節）を手で計算して並べる。

```rust
//| id: poly-first-evaluation
//| ref: poly-first-evaluation
//| title: 係数から値・導関数・誤差の推定を求める
//| run: reactive
//| crates: [scioxide-poly]
//| inputs:
//|   point: {"type":"range","label":"評価点 x [-]","description":"x = 1, 2 は根で、相対的な診断が有界でなくなる。","min":-2,"max":4,"step":0.25,"value":1.5}
//| cases:
//|   - {"id":"at-root","label":"根 x = 1","description":"値が 0 になり、条件数と前進誤差の推定が +∞ になる。","inputs":{"point":1}}
//|   - {"id":"far-point","label":"x = 4","description":"項の打ち消しが小さく、条件数の推定が 5 に下がる。","inputs":{"point":4}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"values","path":"/rows/0/1","approx":{"value":-0.25,"atol":1e-15}}
//|       - {"artifact":"values","path":"/rows/1/1","approx":{"value":0,"atol":1e-15}}
//|       - {"artifact":"diagnostics","path":"/rows/0/1","approx":{"value":6.661338147750939e-16,"rtol":1e-12}}
//|       - {"artifact":"diagnostics","path":"/rows/1/1","approx":{"value":35,"rtol":1e-12}}
//|       - {"artifact":"diagnostics","path":"/rows/2/1","approx":{"value":2.3314683517128287e-14,"rtol":1e-12}}
//|   - case: at-root
//|     expect:
//|       - {"artifact":"values","path":"/rows/0/1","approx":{"value":0,"atol":1e-15}}
//|       - {"artifact":"values","path":"/rows/1/1","approx":{"value":-1,"atol":1e-15}}
//|       - {"artifact":"diagnostics","path":"/rows/1/1","equals":null}
//|       - {"artifact":"diagnostics","path":"/rows/2/1","equals":null}
//|   - case: far-point
//|     expect:
//|       - {"artifact":"values","path":"/rows/0/1","approx":{"value":6,"atol":1e-14}}
//|       - {"artifact":"values","path":"/rows/1/1","approx":{"value":5,"atol":1e-14}}
//|       - {"artifact":"diagnostics","path":"/rows/1/1","approx":{"value":5,"rtol":1e-12}}
//|       - {"artifact":"diagnostics","path":"/rows/1/2","approx":{"value":5,"rtol":1e-12}}
use scioxide_poly::ApproxPolynomial;

let polynomial =
    ApproxPolynomial::monomial(vec![2.0_f64, -3.0, 1.0]).map_err(|e| e.to_string())?;
let result = polynomial
    .evaluate_with_derivative(point)
    .map_err(|e| e.to_string())?;
let report = result.condition();
// 独立検算: 因数表示 (x − 1)(x − 2) と解析的な導関数 2x − 3。
let expected = (point - 1.0) * (point - 2.0);
let slope = 2.0 * point - 3.0;
// 独立検算: 包絡 Σ|a_k||x|^k、γ_3(ε) = 3ε/(1 − 3ε)、条件数 = 包絡 / |p(x)|。
let envelope = 2.0 + 3.0 * point.abs() + point * point;
let gamma = 3.0 * f64::EPSILON / (1.0 - 3.0 * f64::EPSILON);
let condition = (expected != 0.0).then(|| envelope / expected.abs());
// +∞ は「有界でない」という診断なので、表では空欄（None）にする。
let finite = |value: f64| Some(value).filter(|v| v.is_finite());
let digits = serde_json::json!({ "significantDigits": 15 });
let sci4 = serde_json::json!({ "notation": "scientific", "significantDigits": 4 });
let value_columns = serde_json::json!([
    { "key": "0", "label": "量" },
    { "key": "1", "label": "SciOxide [-]", "type": "number", "format": digits },
    { "key": "2", "label": "検算 [-]", "type": "number", "format": digits }
]);
emit_table_with_columns!(
    value_columns,
    vec![
        ("値 p(x)", result.value(), expected),
        ("導関数 p′(x)", result.derivative(), slope),
    ],
    metadata = serde_json::json!({ "id": "values" })
);
let diagnostic_columns = serde_json::json!([
    { "key": "0", "label": "診断" },
    { "key": "1", "label": "SciOxide [-]", "type": "number", "format": sci4, "nullText": "+∞" },
    { "key": "2", "label": "独立な式 [-]", "type": "number", "format": sci4, "nullText": "+∞" }
]);
emit_table_with_columns!(
    diagnostic_columns,
    vec![
        (
            "backward_error()",
            Some(report.backward_error()),
            Some(gamma)
        ),
        (
            "condition_estimate()",
            finite(report.condition_estimate()),
            condition
        ),
        (
            "forward_error_estimate()",
            finite(report.forward_error_estimate()),
            condition.map(|kappa| gamma * kappa),
        ),
    ],
    metadata = serde_json::json!({ "id": "diagnostics" })
);
```

既定の $x=1.5$ では値 $-0.25$、導関数 $0$ で、因数表示と解析的な導関数に一致する（$x=1.5$ は放物線の頂点である）。
$x=4$ では値 $6$、導関数 $5$ になる。
値だけが要るときは `evaluate` が同じ計算の値だけを返し、その値は `evaluate_with_derivative` の値と最後のビットまで一致する。

## 結果の読み方

`condition()` が返す `PolynomialConditionReport` の三つの量は、どれも丸めのモデルから作る推定である。
`backward_error()` は係数の数 $N=3$ と機械イプシロン $\varepsilon=2^{-52}$ による $\gamma_3(\varepsilon)=3\varepsilon/(1-3\varepsilon)\approx6.661\times10^{-16}$ で、評価点に依らない。
これは「計算値は、各係数を相対的にこの程度だけ動かした多項式の厳密な値とみなせる」という後退誤差のモデルである。
`condition_estimate()` は評価の相対条件数

$$
\kappa(p,x)=\frac{\sum_k|a_k||x|^k}{|p(x)|}
$$

の推定で、既定の $x=1.5$ では $(2+4.5+2.25)/0.25=35$ になる。
分子の $\sum_k|a_k||x|^k$ を評価の包絡と呼ぶ。
`forward_error_estimate()` は両者の積 $\gamma_3(\varepsilon)\,\kappa\approx2.33\times10^{-14}$ で、値の相対誤差の目安である。

根 $x=1,2$ では $p(x)=0$ なので相対誤差の尺度がなくなり、条件数と前進誤差の推定は $+\infty$ になる（表では空欄で示す）。
これはエラーではなく、相対的な診断が有界でないことを表す。
三つの量は証明付きの上界ではなく、表で観測した差とも別の量である。
条件数が大きいことは入力の摂動に敏感な問題であることを表し、この入力で必ず大きな誤差が出るという意味ではない。
上界の導出と、SciOxide の演算経路がその仮定を満たすことは [Horner 評価の丸め誤差と診断](algorithms/horner-rounding-error/)で確かめる。

| 相異なる節点と、正確に通したい値 | `interpolate_barycentric`、`interpolate_newton` | 節点での値または差商を保持し、単項式への展開を避ける | [補間と Chebyshev 節点](algorithms/interpolation-and-chebyshev/) |
| 区間上で滑らかな関数の展開 | `OrthogonalBasisSpec`、`ApproxPolynomial::orthogonal` | 族・規格化・中心・尺度を保持する | [直交基底の準備・評価・基底変換](algorithms/orthogonal-bases-and-calculus/) |
| ノイズを含む標本 | `fit_monomial`、`fit_orthogonal`、`PolynomialFitPlan` | 重み付き残差と数値ランクを確かめて次数を選ぶ | [標本行列と最小二乗](algorithms/least-squares-and-vandermonde/) |
| 曲線・曲面の制御点 | `ApproxPolynomial::bernstein`、`TensorBernstein` | 区間内の凸包性と分割を使う | [Bernstein 表現と de Casteljau 法](algorithms/multivariate-and-bernstein/)、[テンソル積 Bernstein と値域の推定](algorithms/tensor-bernstein-bounds/) |
| 多変数の疎な項 | `ApproxSparsePolynomial`、`SparseEvaluationPlan` | 零でない項の指数と係数だけを保持する | [疎な多変数多項式](algorithms/sparse-multivariate/) |
| 厳密な環・体の係数 | `ExactPolynomial`、`ExactRationalFunction` | 呼び出し側が実装する厳密な係数型で代数演算を行う | [厳密な係数の演算と部分積の木](algorithms/exact-arithmetic-and-product-trees/) |

重心形式を選ぶだけで Runge 現象はなくならない。
節点の配置は補間問題そのものの条件を決め、表現形式は同じ多項式を評価するときの丸め誤差の伝わり方を決める。
詳しい比較は[選択ガイド](choosing/)にある。

## 提供しない機能と他章の役割

`scioxide-poly` は根を求める問題を固有値問題に置き換える根を固有値に持つ行列（伴行列・comrade 行列）と、計算済みの根の候補の診断（Weierstrass 補正による円板、クラスタ、条件数）を提供する。
根そのものを求める全根のソルバーは提供しない。
求解は scioxide-rootfind の `polynomial_roots`、根を固有値に持つ行列の固有値は scioxide-linalg を使う。
本章の円板とクラスタは推定であり、円板の中の根の個数を証明するには scioxide-validated の `polynomial_roots`（Rouché の定理による円板）を使う。

直交多項式の零点（Jacobi 行列の固有値として求める Golub–Welsch 法の節点）と Jacobi 行列そのものは本章の `OrthogonalFamily` が返す。
Gauss 求積の重みと求積則は本章では提供せず、scioxide-integrate の `GaussianRulePlan` が担当する。
標本からの AAA 有理近似と、Taylor 係数からの Padé 近似の構成も本章では提供せず、scioxide-interp の `aaa` と `PadeApproximant` を使う。
本章の `ApproxRationalFunction` は分子と分母を与えた有理関数の評価・約分・部分分数分解を扱う。

一般の関数に対する Remez 交換法の最良多項式近似（ミニマックス近似）は、どのクレートも提供しない。
Remez 交換法は scioxide-signal の `design_fir_remez`（Parks–McClellan 法）が FIR フィルタの等リップル設計に限って使う。
最良近似の代わりには Chebyshev 節点での補間か Chebyshev 基底での最小二乗近似を使う。
多項式の因数をすべて探す因数分解も提供しない。
厳密な多項式の `gcd` や、与えた因子による部分分数分解は、因数を探索する処理ではない。

## まとめ

`evaluate_with_derivative` は値と導関数に加えて、後退誤差のモデル $\gamma_N(\varepsilon)$、条件数の推定、その積である前進誤差の推定を返す。
三つの診断は推定であり、根の上では条件数と前進誤差の推定が $+\infty$ になる。
係数・節点での値・制御点・直交展開の係数のどれを保存するかは、手元のデータと目的から選ぶ。
全最上位の求解、Gauss 求積の重み、AAA と Padé の構成はそれぞれ scioxide-rootfind、scioxide-integrate、scioxide-interp を使い、Remez 法の最良近似はどのクレートも提供しない。
