確率微分方程式や経路に依存する金融商品の評価では、時刻の格子の上の Wiener 過程の経路を $n$ 個の標準正規座標から作る。
QMC 点列を正規分位点で写してこの座標に使うとき、点列の先頭の座標ほど一様さが高いので、どの座標を経路のどの部分に割り当てるかが誤差を左右する。
このページは `scioxide-random` の `BrownianBridgePlan` が使う割り当ての順序と、その順序が経路の分散を先頭の座標に集める理由を説明する。
QMC 点列の構成は[Halton・Sobol 点列の構成とディスクレパンシー](../quasi-random-and-brownian-bridges/)、正規座標への輸送は[QMC 点の分布への輸送](oxref:random-qmc-transport)で扱った。

## 逐次の構成と条件付き分布

Wiener 過程 $W$ は $W(t_0) = 0$ で、重ならない区間の増分が互いに独立な正規分布 $W(t) - W(s) \sim \mathcal{N}(0, t - s)$ に従う過程である。
時刻 $t_0 < t_1 < \dots < t_n$ の値を独立な標準正規座標 $z_0, \dots, z_{n-1}$ から作る素直な方法は、前から順に

$$
W(t_{k+1}) = W(t_k) + \sqrt{t_{k+1} - t_k}\; z_k
$$

とすることである。
この逐次の構成では、座標 $z_k$ は $t_{k+1}$ 以降のすべての値に同じ大きさで入るので、経路の分散は多くの座標に分かれ、先頭の少数の座標には集まらない。

Brownian 橋は、両端の値が分かっている区間 $[t_l, t_r]$ の中の時刻 $t_m$ の値を条件付き分布から作る。
増分 $X = W(t_m) - W(t_l)$ と $Y = W(t_r) - W(t_m)$ は独立で、分散はそれぞれ $a = t_m - t_l$、$b = t_r - t_m$ である。
和 $X + Y = W(t_r) - W(t_l)$ を与えたときの $X$ の条件付き分布は、正規分布の条件付けから平均 $\frac{a}{a+b}(X+Y)$、分散 $\frac{ab}{a+b}$ の正規分布になる。
したがって

$$
W(t_m) \mid W(t_l), W(t_r) \sim \mathcal{N}\!\left( \frac{(t_r - t_m) W(t_l) + (t_m - t_l) W(t_r)}{t_r - t_l},\ \frac{(t_m - t_l)(t_r - t_m)}{t_r - t_l} \right)
$$

であり、平均は両端の値の線形補間、分散は区間の中央で最大になる。

## Brownian 橋による座標の割り当て

`BrownianBridgePlan::new(&times)` は時刻の格子 $t_0 < t_1 < \dots < t_n$ を検査して複製し、各段の補間の重みと条件付きの標準偏差を前もって計算する。
座標 $z_0$ で終端 $W(t_n) = \sqrt{t_n - t_0}\, z_0$ を決め、残りの座標で、両端が決まった添字の区間 $(l, r)$ の中点 $m = \lfloor (l + r)/2 \rfloor$ を幅優先・左から順に決める。
8 区間の格子では、座標は添字 $8, 4, 2, 6, 1, 3, 5, 7$ の順に使われる。
格子は不等間隔でもよく、区間の数は 2 の冪でなくてもよい。
$W(t_0)$ は 0 と置くので、結果は $\mathrm{Cov}(W(t_i), W(t_j)) = \min(t_i, t_j) - t_0$ を持つ。

時刻が 2 個未満なら `InvalidInput`、狭義に増加しなければ `DomainError`、非有限なら `NonFinite` である。
条件付きの標準偏差は $\sqrt{t_m - t_l}\sqrt{t_r - t_m}/\sqrt{t_r - t_l}$ の順で計算し、分散の積が非正規化数になる格子でも正の値を保つ。
それでも正の標準偏差が表せないときは `NumericalInstability` である。
構築は $O(n)$ の時間とメモリ領域で、`input_len()` と `output_len()` はどちらも $n$ を返す。

`apply(z)` は $O(n)$ で $W(t_1), \dots, W(t_n)$ を新しい `Vec` で返す（$W(t_0) = 0$ は出力しない）。
`apply_into(z, out, workspace)` は同じ経路を作業領域に作ってから呼び出し側の出力に写し、エラーのときは出力を変えない。
その作業領域は `plan.workspace(())` で作り、使い回せば経路ごとの確保がない。
`z` か出力の長さが $n$ でなければ `DimensionMismatch`、`z` に非有限の値があれば `NonFinite`、経路の値が桁あふれすれば `NumericalInstability` である。

## 先頭の座標が担う分散

経路は $z$ の線形写像 $W = A z$（$A$ は $n \times n$）なので、座標 $z_j$ が経路の分散の総和 $\sum_i \mathrm{Var}\,W(t_i) = \sum_i (t_i - t_0)$ に寄与する量は $\sum_i A_{ij}^2$ である。
逐次の構成では、座標 $z_j$ は時刻 $t_{j+1}$ 以降の $n - j$ 個の値にそれぞれ $t_{j+1} - t_j$ の分散を与えるので、寄与は $(t_{j+1} - t_j)(n - j)$ である。
橋の構成では、終端の座標 $z_0$ は線形補間を通して $W(t_i)$ に $(t_i - t_0)/\sqrt{t_n - t_0}$ の係数で入るので、$t_0 = 0$ のときの寄与の割合は $\sum_i t_i^2 / (t_n \sum_i t_i)$ になる。
等間隔の格子 $t_i = i/n$ では、この割合は $(2n + 1)/(3n)$ で、$n$ によらず 2/3 以上になる。

QMC の積分では、関数の値の変動の大部分を少数の座標の関数で説明できるとき（有効な次元が低いとき）に、低食い違い点列の利点が出る。
橋の順序は経路の大きな形を先頭の座標に任せるので、満期の値や経路の平均のような量の有効な次元を下げる。
ただし有効な次元は被積分関数で決まり、経路の細かい変動に敏感な量では利得は小さい。

次のセルは単位ベクトルを `apply_into` に渡して $A$ の列を取り出し、先頭の $k$ 個の座標が説明する分散の割合を、逐次の構成と比べる。
入力は区間の数 $n$ と時刻の格子（$T = t_n = 1$）である。
逐次の構成の寄与 $(t_{j+1} - t_j)(n - j)$、分散の総和 $\sum_i t_i$、終端の座標の割合 $\sum_i t_i^2 / \sum_i t_i$ は手で計算し、独立検算に使う。

```rust
//| id: random-bridge-variance-order
//| ref: random-bridge-variance-order
//| title: Brownian 橋と逐次の構成で先頭の座標が担う分散を比べる
//| run: reactive
//| crates: [scioxide-random]
//| inputs:
//|   steps: {"type":"range","label":"区間の数 n [-]","min":8,"max":128,"step":8,"value":64}
//|   grid: {"type":"select","label":"時刻の格子（T = 1）","options":["等間隔 t_i = i/n","前半が細かい t_i = (i/n)²","後半が細かい t_i = 1 − (1 − i/n)²"],"value":"等間隔 t_i = i/n"}
//| cases:
//|   - {"id":"fine-start","label":"前半が細かい格子","description":"逐次の構成の先頭 8 個の割合は 4.2% まで下がるが、橋は 94.0% を保つ。","inputs":{"grid":"前半が細かい t_i = (i/n)²"}}
//|   - {"id":"short-grid","label":"n = 8","description":"8 区間では座標が 8 個なので k = 8 でどちらも 1 になり、k = 1 では橋が 0.708、逐次の構成が 0.222 を担う。","inputs":{"steps":8}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"shares","path":"/rows/0/1","range":{"min":0.671,"max":0.673}}
//|       - {"artifact":"shares","path":"/rows/3/1","range":{"min":0.959,"max":0.961}}
//|       - {"artifact":"shares","path":"/rows/3/2","range":{"min":0.232,"max":0.234}}
//|       - {"artifact":"totals","path":"/rows/0/1","range":{"min":0,"max":1e-12}}
//|       - {"artifact":"totals","path":"/rows/0/3","range":{"min":0,"max":1e-12}}
//|   - case: fine-start
//|     expect:
//|       - {"artifact":"shares","path":"/rows/3/1","range":{"min":0.939,"max":0.941}}
//|       - {"artifact":"shares","path":"/rows/3/2","range":{"min":0.041,"max":0.043}}
//|       - {"artifact":"totals","path":"/rows/0/3","range":{"min":0,"max":1e-12}}
//|   - case: short-grid
//|     expect:
//|       - {"artifact":"shares","path":"/rows/3/1","range":{"min":0.999999,"max":1.000001}}
//|       - {"artifact":"shares","path":"/rows/0/1","range":{"min":0.7083,"max":0.7084}}
use scioxide_random::BrownianBridgePlan;

let fixed4 = serde_json::json!({ "fractionDigits": 4 });
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let n = steps.round() as usize;
let times: Vec<f64> = (0..=n)
    .map(|i| {
        let s = i as f64 / n as f64;
        match grid.as_str() {
            "前半が細かい t_i = (i/n)²" => s * s,
            "後半が細かい t_i = 1 − (1 − i/n)²" => 1.0 - (1.0 - s) * (1.0 - s),
            _ => s,
        }
    })
    .collect();
let plan = BrownianBridgePlan::new(&times).map_err(|e| e.to_string())?;
let mut workspace = plan.workspace(()).map_err(|e| e.to_string())?;
let (mut unit, mut column) = (vec![0.0_f64; n], vec![0.0_f64; n]);
// 座標 j の寄与 Σ_i A_ij²（橋）。単位ベクトル e_j を渡すと A の第 j 列が出る。
let mut bridge = Vec::with_capacity(n);
for j in 0..n {
    unit.fill(0.0);
    unit[j] = 1.0;
    plan.apply_into(&unit, &mut column, &mut workspace)
        .map_err(|e| e.to_string())?;
    bridge.push(column.iter().map(|w| w * w).sum::<f64>());
}
// 独立検算: 逐次の構成の寄与 (t_{j+1} − t_j)(n − j)、分散の総和 Σ t_i（t_0 = 0）、
// 終端の座標の割合 Σ t_i² / Σ t_i（T = 1）。
let forward: Vec<f64> = (0..n)
    .map(|j| (times[j + 1] - times[j]) * (n - j) as f64)
    .collect();
let total: f64 = times[1..].iter().sum();
let terminal = times[1..].iter().map(|t| t * t).sum::<f64>() / total;
let cumulative = |parts: &[f64]| {
    parts
        .iter()
        .scan(0.0, |acc, v| {
            *acc += v;
            Some(*acc / total)
        })
        .enumerate()
        .map(|(k, f)| [(k + 1) as f64, f])
        .collect::<Vec<[f64; 2]>>()
};
let (bridge_curve, forward_curve) = (cumulative(&bridge), cumulative(&forward));
emit_line_chart!(
    &vec![
        serde_json::json!({
            "name": "Brownian 橋",
            "points": bridge_curve,
            "style": { "showSymbol": true, "symbol": "circle" }
        }),
        serde_json::json!({
            "name": "逐次の構成（解析値）",
            "points": forward_curve,
            "style": { "lineType": "dashed" }
        }),
    ],
    options = &serde_json::json!({
        "xLabel": "使う座標の数 k [個]",
        "yLabel": "説明される分散の割合 [-]",
        "xType": "log",
        "yMin": 0.0,
        "yMax": 1.0
    })
);
let rows: Vec<(usize, f64, f64)> = [1_usize, 2, 4, 8]
    .iter()
    .map(|&k| (k, bridge_curve[k - 1][1], forward_curve[k - 1][1]))
    .collect();
let share_columns = serde_json::json!([
    { "key": "0", "label": "先頭の座標の数 k [個]", "type": "integer" },
    { "key": "1", "label": "Brownian 橋 [-]", "type": "number", "format": fixed4 },
    { "key": "2", "label": "逐次の構成 [-]", "type": "number", "format": fixed4 }
]);
emit_table_with_columns!(
    share_columns,
    rows,
    metadata = serde_json::json!({ "id": "shares" })
);
let gap = (bridge.iter().sum::<f64>() - total).abs();
let total_columns = serde_json::json!([
    { "key": "0", "label": "分散の総和 Σ t_i [-]", "type": "number", "format": fixed4 },
    { "key": "1", "label": "|橋の列の和 − Σ t_i| [-]", "type": "number", "format": sci3 },
    { "key": "2", "label": "終端の座標の割合（解析値）[-]", "type": "number", "format": fixed4 },
    { "key": "3", "label": "|橋の第 1 座標 − 解析値| [-]", "type": "number", "format": sci3 }
]);
emit_table_with_columns!(
    total_columns,
    vec![(total, gap, terminal, (bridge[0] / total - terminal).abs())],
    metadata = serde_json::json!({ "id": "totals" })
);
```

等間隔の 64 区間では、橋の最初の座標（終端値）が分散の総和の 67.2%、先頭の 8 個が 96.0% を担うのに対し、逐次の構成の先頭 8 個は 23.3% である。
最初の座標の割合 0.6719 は解析値 $(2n+1)/(3n) = 129/192$ に一致する。
前半が細かい格子では逐次の構成の先頭 8 個は 4.2% まで下がるが、橋は 94.0% を保つ。
逐次の構成では先頭の座標が短い区間の増分を受け持つので、格子が前半で細かいほど先頭の座標の寄与が小さくなる。
最後の表は、橋の列から求めた分散の総和が $\sum_i t_i = 32.5$ と一致し、差が 0 であることを示す（前半が細かい格子では $3.6 \times 10^{-15}$）。
有効な次元が低い関数では、この並べ方によって Sobol 点列の均一な先頭の座標が経路の大きな形を決める。

## まとめ

Brownian 橋は条件付き正規分布を使って、終端、中点、さらにその中点の順に経路の値を決め、構築 $O(n)$、一経路 $O(n)$ で逐次の構成と同じ共分散 $\min(t_i, t_j) - t_0$ を持つ経路を作る。
等間隔の格子では終端の座標だけで分散の総和の $(2n+1)/(3n)$ を担い、セルの格子では先頭の 8 個で 9 割以上を担うので、QMC 点列の先頭の座標を経路の大きな形に使える。
格子は不等間隔でも 2 の冪でなくてもよく、`apply_into` と作業領域を使い回せば経路ごとの確保なしに多数の経路を作れる。
利得は被積分関数の有効な次元で決まるので、経路の細かい変動に敏感な量ではランダム化した反復の標準誤差で効果を確かめる。
