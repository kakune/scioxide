風向、波の進行方向、概日リズムの位相のように、角度で表すデータは周期を持つ。
角度 $5^\circ$ と $355^\circ$ の算術平均は $180^\circ$ で、二つの観測がどちらもほぼ北を向いているのに南を指してしまう。
単位ベクトル $(\cos\theta, \sin\theta)$ の平均を取って向きを読む円周平均は $0^\circ$ で、こちらが二つの観測の代表になる。
`scioxide-random` は円周上の角度を値に取る分布として `VonMises`、`VonMisesLine`、`WrappedCauchy` を提供する。
このページは角度を実数として扱うための主区間の約束、各分布の評価と生成のアルゴリズム、平均合成ベクトル長の意味と標本での偏りを説明する。
球面 $S^{d-1} \subset \mathbb{R}^d$ 上の方向の分布（`UniformDirection` と `VonMisesFisher`）は[球面上の方向の確率分布](../spherical-directional-laws/)で扱う。

## 円周上の分布と主区間

角度の分布は値を実数で返すので、$2\pi$ だけずれた角度のどれを返すかを決めておく必要がある。
`scioxide-random` は分布ごとに長さ $2\pi$ の主区間を決め、分布関数、上側確率、分位点、平均と分散、標本をその区間の上で定義する。
角度の単位はラジアンである。

| 分布 | コンストラクター | 主区間 | 密度 | 平均の向き |
|---|---|---|---|---|
| `VonMises` | `new(location, concentration)`、$\kappa \ge 0$ | $[\mu - \pi, \mu + \pi]$ | $\dfrac{e^{\kappa\cos(\theta - \mu)}}{2\pi I_0(\kappa)}$、すべての実数で $2\pi$ 周期 | $\mu$ |
| `VonMisesLine` | `new(location, concentration)` | $[\mu - \pi, \mu + \pi]$ | 同じ式を主区間に限り、外では 0 | $\mu$ |
| `WrappedCauchy` | `new(location, rho)`、$0 \le \rho < 1$ | $[\mu, \mu + 2\pi]$ | $\dfrac{1 - \rho^2}{2\pi\bigl(1 + \rho^2 - 2\rho\cos(\theta - \mu)\bigr)}$、主区間の外では 0 | $\mu$ |

$I_\nu$ は第 1 種の変形 Bessel 関数、$\kappa$ は集中度で、$\kappa = 0$ と $\rho = 0$ はどちらも円周上の一様分布である。
`new` は既定の `LawOptions` を使い、`with_options(…, options)` は同じ母数の後に設定を取って精度とリソースの上限を変える。
`location` の $\pm\pi$（巻き込み Cauchy では $+2\pi$）が丸めで `location` に戻るほど大きな位置は、主区間を表せないので `DomainError` になる。

`VonMises` と `VonMisesLine` は同じ母数、同じ分布関数、分位点、モーメント、標本を持ち、違いは密度の定義域だけである。
`VonMises` の `pdf` は円周上の密度として、どの実数の角度にも周期的な値を返すので、$\theta$ と $\theta + 2\pi$ に同じ値を返す。
`VonMisesLine` は主区間の外で密度 0 を返し、実数直線上で積分が 1 になる確率分布になる。
混合や変換などの合成で実数値の確率変数として使うとき、あるいは密度の積分が 1 になることを使う計算では `VonMisesLine` を使う。

`VonMises` と `WrappedCauchy` は円周統計の量を別のメソッドで返す。
`mean_resultant_length()` は母集団の平均合成ベクトル長 $\rho = \lVert\mathbb{E}[(\cos\theta, \sin\theta)]\rVert$、`circular_variance()` は $1 - \rho$、`mean_direction()` は平均の向き $\mu$ を返す。
一様分布（$\kappa = 0$ または $\rho = 0$）には平均の向きがないので、`mean_direction()` は未定義のモーメントとして `DomainError` を返す。
`VonMises` の `winding_cdf(x)` は 1 周ごとに 1 増える持ち上げた分布関数で、主区間の外では確率ではない。

`Mean` と `Variance` のトレイトは主区間の上の実数としての平均と分散を返す。
`VonMises` の `mean()` は $\mu$ で円周の平均の向きと一致する。
`WrappedCauchy` の主区間 $[\mu, \mu + 2\pi]$ では質量が両端に集まり、密度が $\mu + \pi$ について対称なので、`mean()` は $\mu + \pi$ を返す。
円周の向きが必要なときは `mean()` ではなく `mean_direction()` を使う。

## von Mises 分布の評価と標本化

von Mises 分布の正規化定数は $I_0(\kappa)$ で、`new` は桁あふれを避けるため $e^{-\kappa}I_\nu(\kappa)$ の形で $I_0$ と $I_1$ を一度だけ計算する。
平均合成ベクトル長は $\rho = I_1(\kappa)/I_0(\kappa)$ で、$\kappa > 10^8$ では漸近形 $1 - \rho \approx \frac{1}{2\kappa}\bigl(1 + \frac{1}{4\kappa}\bigr)$ を使って $1 - \rho$ を失わない。
密度の指数は $\kappa\cos(\theta - \mu) - \kappa = -2\kappa\sin^2\bigl((\theta - \mu)/2\bigr)$ の形で評価し、大きな $\kappa$ で $\cos$ と 1 の差を取らない。

分布関数は小さい側の裾を直接積分して求める。
積分変数を有理関数で変換して、$\kappa$ が大きく質量が裾の始点の近くに集まる場合も少ない分割で解像し、適応 Gauss–Kronrod 法（7 点と 15 点の組）で積分する。
分位点は $y = \sqrt{\max(\kappa, 1)}\,\operatorname{atanh}\bigl((\theta - \mu)/\pi\bigr)$ に変換した座標で解く。
この座標は台が実数全体なので、$\kappa$ が大きく質量が狭い範囲に集まっても、括弧付けの区間を有限回の拡大で見つけられる。
裾の積分と分位点の探索は分布の `work_budget` に数える。

標本は角度 $\theta - \mu \in [-\pi, \pi]$ を棄却法で作って $\mu$ を足す。

- $\kappa = 0$ は一様分布で、$2\pi U - \pi$ を返す。
- $0 < \kappa < 0.5$ は一様分布を包絡に使い、$\ln V \le -2\kappa\sin^2(\theta/2)$ なら受理する。
  受理率は $e^{-2\kappa}$ 以上で、$\kappa < 0.5$ では $e^{-1}$ を上回る。
- $\kappa \ge 0.5$ は Best と Fisher（1979）の方法で、巻き込み Cauchy 分布を包絡に使う。
  包絡の母数 $r - 1 = (1 - b)^2/(2b)$ と $1 - \cos\theta$ を有理化した式で作り、大きな $\kappa$ でも桁落ちしない。
  候補の大きさ $\lvert\theta\rvert$ を受理してから、確率 1/2 ずつで符号を付ける。

どちらの棄却法も 1,024 回の提案で止まり、それまでに受理されなければエラーを返す。

## 巻き込み Cauchy 分布

巻き込み Cauchy 分布は Cauchy 分布の値を $2\pi$ で巻き込んだ分布で、平均合成ベクトル長は母数 $\rho$ そのものである。
分布関数は閉形式で、$\theta - \mu \in [0, \pi]$ では

$$
F(\theta) = \frac{1}{\pi}\arctan\Bigl(\frac{1 + \rho}{1 - \rho}\tan\frac{\theta - \mu}{2}\Bigr)
$$

である。
$\theta - \mu \in (\pi, 2\pi)$ では右端からの距離 $\mu + 2\pi - \theta$ を同じ式に入れた値が上側確率 $1 - F(\theta)$ になる。
実装は端に近い側の小さい裾を `atan2` で直接求め、もう一方はその補として作る。
この閉形式の逆関数も持ち、分位点と標本は逆関数法で作る。

## 平均合成ベクトル長と標本の偏り

角度の標本 $\theta_1, \dots, \theta_n$ の平均合成ベクトル

$$
(\bar{C}, \bar{S}) = \Bigl(\frac{1}{n}\sum_{i=1}^n\cos\theta_i,\ \frac{1}{n}\sum_{i=1}^n\sin\theta_i\Bigr),\qquad
\bar{R} = \sqrt{\bar{C}^2 + \bar{S}^2} \in [0, 1]
$$

の長さ $\bar{R}$ を標本の平均合成ベクトル長と呼ぶ。
$n \to \infty$ で $\bar{R}$ は母集団の値 $\rho$ に収束し、von Mises 分布では $\rho = I_1(\kappa)/I_0(\kappa)$、巻き込み Cauchy 分布では $\rho$ がそのまま母数である。
von Mises の $\rho$ は $\kappa = 0$ で 0、$\kappa \to \infty$ で 1 に近づくので、集中の度合いを $[0, 1]$ の数で表す。

有限の $n$ では $\bar{R}$ は $\rho$ より大きめに出る。
単位ベクトル $\mathbf{u}_i = (\cos\theta_i, \sin\theta_i)$ の平均の二乗の期待値は、平均の二乗と分散の和に分けて

$$
\mathbb{E}\bigl[\bar{R}^2\bigr] = \rho^2 + \frac{1 - \rho^2}{n}
$$

と正確に書ける（$\mathbb{E}\lVert\mathbf{u}_i\rVert^2 = 1$ を使う）。
一様分布（$\rho = 0$）でも $\mathbb{E}[\bar{R}^2] = 1/n$ で、$n = 10$ なら $\bar{R}$ は 0.3 程度になる。
小さな標本の $\bar{R}$ を集中の証拠として解釈するときは、この偏りを差し引いて比べる。

偏りのない比較には平均の向き $\mu$ に沿った成分 $\bar{C}_\mu = \frac{1}{n}\sum_i \cos(\theta_i - \mu)$ を使う。
$\mathbb{E}[\cos(\theta - \mu)] = \rho$ なので $\bar{C}_\mu$ は $\rho$ の偏りのない推定で、標準誤差は $\sqrt{\operatorname{Var}(\cos(\theta - \mu))/n}$ である。
von Mises 分布では $I_0(\kappa) - I_2(\kappa) = (2/\kappa)I_1(\kappa)$ から $\mathbb{E}[\cos 2(\theta - \mu)] = I_2/I_0 = 1 - 2\rho/\kappa$ となり、

$$
\operatorname{Var}\bigl(\cos(\theta - \mu)\bigr) = \frac{1 + I_2/I_0}{2} - \rho^2 = 1 - \frac{\rho}{\kappa} - \rho^2
$$

である（$\kappa = 0$ では極限の $1/2$）。
巻き込み Cauchy 分布では $\mathbb{E}[\cos 2(\theta - \mu)] = \rho^2$ なので、分散は $(1 - \rho^2)/2$ である。
観測の風向で $\bar{R}$ の偏りと平均の向きの標準誤差を確かめる例は、[風向の標本と平均合成ベクトル長の偏り](../../examples/von-mises-wind-samples/)にある。

## 主区間と余弦の平均の検算

次のセルは平均の向き $\mu = 0$ の `VonMises`、`VonMisesLine`、`WrappedCauchy` の密度を $[-\pi, 2\pi]$ で描き、主区間の違いを見せる。
`VonMises` の密度は周期的に続き、`VonMisesLine` は $[-\pi, \pi]$ の外で、`WrappedCauchy` は $[0, 2\pi]$ の外で 0 になる。
最初の表は `VonMises` と `WrappedCauchy` から $n$ 個ずつ作った標本の最小値と最大値、`mean()`、`mean_direction()` を出し、主区間の約束を確かめる。
二つ目の表は $\bar{C}_\mu$ を `mean_resultant_length()` と比べた $z$ と、$\bar{R}$ を偏りを含む大きさ $\sqrt{\rho^2 + (1 - \rho^2)/n}$ と並べる。
入力は von Mises の集中度 $\kappa$、巻き込み Cauchy の $\rho$、標本数 $n$、SplitMix64 のシードである。

```rust
//| id: random-circular-interval-moments
//| ref: random-circular-interval-moments
//| title: 円周上の分布の主区間と余弦の平均を確かめる
//| run: reactive
//| crates: [scioxide-core, scioxide-random]
//| inputs:
//|   concentration: {"type":"range","label":"von Mises の集中度 κ [-]","description":"0 では一様分布になり、mean_direction() が未定義になる。","min":0,"max":10,"step":0.5,"value":2}
//|   rho: {"type":"range","label":"巻き込み Cauchy の ρ [-]","description":"平均合成ベクトル長そのもので、1 に近いほど主区間の両端に質量が集まる。","min":0,"max":0.95,"step":0.05,"value":0.5}
//|   sample_count: {"type":"range","label":"標本数 n [個]","description":"z の標準誤差と R̄ の偏り (1 − ρ²)/n を変える。","min":20,"max":20000,"step":20,"value":4000}
//|   seed: {"type":"range","label":"SplitMix64 のシード [-]","description":"z の値の標本ごとの揺らぎを見る。","min":1,"max":1000,"step":1,"value":17}
//| cases:
//|   - {"id":"uniform","label":"κ = 0、ρ = 0","description":"どちらも一様分布になり、mean_direction() は未定義、R̄ は 1/√n 程度に出る。","inputs":{"concentration":0,"rho":0}}
//|   - {"id":"small-uniform","label":"κ = 0、ρ = 0、n = 20","description":"母集団の ρ は 0 だが、R̄ は √(1/n) ≈ 0.22 程度に出る。","inputs":{"concentration":0,"rho":0,"sample_count":20}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"intervals","path":"/rows/1/3","approx":{"value":3.141592653589793,"atol":1e-15}}
//|       - {"artifact":"intervals","path":"/rows/1/4","approx":{"value":0,"atol":1e-15}}
//|       - {"artifact":"resultant","path":"/rows/0/3","range":{"min":-4.5,"max":4.5}}
//|       - {"artifact":"resultant","path":"/rows/1/3","range":{"min":-4.5,"max":4.5}}
//|   - case: uniform
//|     expect:
//|       - {"artifact":"intervals","path":"/rows/0/4","equals":null}
//|       - {"artifact":"resultant","path":"/rows/0/3","range":{"min":-4.5,"max":4.5}}
use scioxide_core::RealScalar;
use scioxide_random::{
    Density, Distribution, Mean, SeedableRng, SplitMix64, VonMises, VonMisesLine, WrappedCauchy,
};

let (kappa, n) = (concentration, sample_count.round() as usize);
let pi = std::f64::consts::PI;
let circle = VonMises::<f64>::new(0.0, kappa).map_err(|e| e.to_string())?;
let line = VonMisesLine::<f64>::new(0.0, kappa).map_err(|e| e.to_string())?;
let wrapped = WrappedCauchy::<f64>::new(0.0, rho).map_err(|e| e.to_string())?;
let (mut periodic, mut restricted, mut cauchy) = (Vec::new(), Vec::new(), Vec::new());
for i in 0..=270 {
    let x = -pi + 3.0 * pi * i as f64 / 270.0;
    periodic.push([x, circle.pdf(x).map_err(|e| e.to_string())?]);
    restricted.push([x, line.pdf(x).map_err(|e| e.to_string())?]);
    cauchy.push([x, wrapped.pdf(x).map_err(|e| e.to_string())?]);
}
// 余弦の分散: von Mises は 1 − ρ/κ − ρ²（κ = 0 では極限の 1/2）、巻き込み Cauchy は (1 − ρ²)/2。
let von_mises_rho = circle.mean_resultant_length().map_err(|e| e.to_string())?;
let von_mises_variance = if kappa == 0.0 {
    0.5
} else {
    1.0 - von_mises_rho / kappa - von_mises_rho * von_mises_rho
};
let mut rng = SplitMix64::from_seed(seed.round() as u64);
let von_mises_draws = circle.sample_n(&mut rng, n).map_err(|e| e.to_string())?;
let cauchy_draws = wrapped.sample_n(&mut rng, n).map_err(|e| e.to_string())?;
let nf = n as f64;
// 標本の範囲、平均の向きに沿った余弦の平均 C̄_μ（μ = 0）とその z、R̄ と √(ρ² + (1 − ρ²)/n)。
let summarize = |theta: &[f64], population: f64, variance: f64| {
    let low = theta
        .iter()
        .fold(f64::INFINITY, |a, &t| RealScalar::min(a, t));
    let high = theta
        .iter()
        .fold(f64::NEG_INFINITY, |a, &t| RealScalar::max(a, t));
    let c = theta.iter().map(|&t| RealScalar::cos(t)).sum::<f64>() / nf;
    let s = theta.iter().map(|&t| RealScalar::sin(t)).sum::<f64>() / nf;
    let z = (c - population) / RealScalar::sqrt(variance / nf);
    let biased =
        RealScalar::sqrt(population * population + (1.0 - population * population) / nf);
    (low, high, c, z, RealScalar::hypot(c, s), biased)
};
let vm = summarize(&von_mises_draws, von_mises_rho, von_mises_variance);
let wc = summarize(&cauchy_draws, rho, (1.0 - rho * rho) / 2.0);
emit_line_chart!(
    &vec![
        serde_json::json!({"name": "VonMises", "points": periodic}),
        serde_json::json!({
            "name": "VonMisesLine",
            "points": restricted,
            "style": {"lineType": "dashed"}
        }),
        serde_json::json!({
            "name": "WrappedCauchy",
            "points": cauchy,
            "style": {"lineType": "dotted"}
        }),
    ],
    options = &serde_json::json!({
        "xLabel": "角度 θ [rad]",
        "yLabel": "確率密度 [1/rad]",
        "xMin": -pi,
        "xMax": 2.0 * pi,
        "annotations": [
            {"kind": "range", "axis": "x", "from": -pi, "to": pi, "label": "von Mises の主区間"},
            {"kind": "line", "axis": "x", "value": 2.0 * pi, "label": "巻き込み Cauchy の右端"}
        ]
    })
);
let fixed4 = serde_json::json!({ "fractionDigits": 4 });
let fixed2 = serde_json::json!({ "fractionDigits": 2 });
let interval_columns = serde_json::json!([
    { "key": "0", "label": "分布" },
    { "key": "1", "label": "標本の最小値 [rad]", "type": "number", "format": fixed4 },
    { "key": "2", "label": "標本の最大値 [rad]", "type": "number", "format": fixed4 },
    { "key": "3", "label": "mean() [rad]", "type": "number", "format": fixed4 },
    {
        "key": "4",
        "label": "mean_direction() [rad]",
        "type": "number",
        "format": fixed4,
        "nullText": "未定義"
    }
]);
// mean() は主区間の上の実数の平均、mean_direction() は円周の平均の向き（一様分布では未定義）。
let vm_mean = circle.mean().map_err(|e| e.to_string())?;
let wc_mean = wrapped.mean().map_err(|e| e.to_string())?;
let (vm_direction, wc_direction) =
    (circle.mean_direction().ok(), wrapped.mean_direction().ok());
emit_table_with_columns!(
    interval_columns,
    vec![
        ("VonMises", vm.0, vm.1, vm_mean, vm_direction),
        ("WrappedCauchy", wc.0, wc.1, wc_mean, wc_direction),
    ],
    metadata = serde_json::json!({ "id": "intervals" })
);
let resultant_columns = serde_json::json!([
    { "key": "0", "label": "分布" },
    { "key": "1", "label": "mean_resultant_length() ρ [-]", "type": "number", "format": fixed4 },
    { "key": "2", "label": "余弦の平均 C̄_μ [-]", "type": "number", "format": fixed4 },
    { "key": "3", "label": "z = (C̄_μ − ρ)/SE [-]", "type": "number", "format": fixed2 },
    { "key": "4", "label": "R̄ [-]", "type": "number", "format": fixed4 },
    { "key": "5", "label": "√(ρ² + (1 − ρ²)/n) [-]", "type": "number", "format": fixed4 }
]);
emit_table_with_columns!(
    resultant_columns,
    vec![
        ("VonMises", von_mises_rho, vm.2, vm.3, vm.4, vm.5),
        ("WrappedCauchy", rho, wc.2, wc.3, wc.4, wc.5),
    ],
    metadata = serde_json::json!({ "id": "resultant" })
);
```

既定値（$\kappa = 2$、$\rho = 0.5$、$n = 4\,000$、シード 17）では、von Mises の標本は $[-2.983, 3.078]$ に、巻き込み Cauchy の標本は $[9.7 \times 10^{-5}, 6.2828]$ に入り、どちらもそれぞれの主区間の中にある。
`WrappedCauchy` の `mean()` は $\pi \approx 3.1416$ を返すが、`mean_direction()` は 0 で、円周の平均の向きとは $\pi$ ずれる。
余弦の平均 $\bar{C}_\mu$ は von Mises で 0.6984（$\rho = I_1(2)/I_0(2) = 0.6978$、$z = 0.09$）、巻き込み Cauchy で 0.4899（$\rho = 0.5$、$z = -1.04$）である。
シードを 1 と 1000 に変えると、$z$ は $-1.16$ から $1.64$ の範囲に入る。

$\kappa = 0$、$\rho = 0$ では二つの分布がどちらも一様分布になり、`mean_direction()` は未定義になる。
母集団の $\rho$ は 0 なのに、$n = 4\,000$ の $\bar{R}$ は 0.021 と 0.015 で、$\sqrt{1/n} \approx 0.016$ 程度に出る。
$n = 20$ では $\bar{R}$ が 0.263 と 0.105 で、一様な標本からも $\sqrt{1/20} \approx 0.22$ 程度の値が出る。
このとき $\bar{C}_\mu$ の $z$ は $-0.88$ と $-0.57$ で、$\rho = 0$ と矛盾しない。

## まとめ

`VonMises` と `VonMisesLine` は同じ von Mises 分布で、前者は円周上の周期的な密度、後者は主区間 $[\mu - \pi, \mu + \pi]$ の外で 0 になる実数直線上の密度を返す。
`WrappedCauchy` の主区間は $[\mu, \mu + 2\pi]$ なので、`mean()` は $\mu + \pi$ を返し、円周の平均の向きは `mean_direction()` で得る。
平均合成ベクトル長 $\rho$ は母集団の値で、標本の $\bar{R}$ は $\mathbb{E}[\bar{R}^2] = \rho^2 + (1 - \rho^2)/n$ だけ大きめに出るので、小さな標本ではこの偏りを差し引いて読む。
生成器や母数を確かめるときは、平均の向きに沿った余弦の平均 $\bar{C}_\mu$ を $\rho$ と標準誤差で比べれば、偏りのない検算になる。
