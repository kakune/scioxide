連続分布の標本は一様乱数 $U$ を分位点関数で写す（逆関数法）か、密度の下の点を選ぶ（棄却法）か、すでに作れる変量を組み合わせて作る。
密度や分布関数が式で書けることと、有限精度の浮動小数点で端点や裾を損なわずに標本を作れることは別の問題である。
このページは `scioxide-random` の連続分布が使うこの三つの方法と、その数値上の注意を説明する。
生成器のワードから $U$ を作る規則は[一様乱数ワードと浮動小数点への変換](oxref:random-algorithms-uniform-conversion)にある。

## 逆関数法

分布関数 $F$ が連続なら、$U \sim \mathrm{Uniform}(0, 1)$ に対して $X = Q(U)$ は $F$ に従う。
ここで $Q(p) = \inf\{x : F(x) \ge p\}$ は $F$ の一般化逆関数（分位点関数）で、$Q(u) \le x$ と $u \le F(x)$ が同値なので

$$
P(Q(U) \le x) = P(U \le F(x)) = F(x)
$$

が成り立つ。
$Q$ は `Quantile::quantile` が計算する。
上側確率 $p$ に対応する点（$S(x) = 1 - F(x) = p$ の解）は、`InverseSurvival::isf` が $1 - p$ を作らずに求める。
そのため $p = 10^{-300}$ のように $1 - p$ が 1 に丸まる場合も、上側の裾の点を相対精度で求められる。

分位点が閉形式を持つ分布は、標本化にもその式を使う。
`Cauchy` は開区間 $(0, 1)$ の $U$ を取り、$\tan$ の極を避けるために中央の両側で別の形を使う。

$$
Q(u) = \begin{cases} x_0 - \gamma / \tan(\pi u) & (u < 1/2) \\ x_0 + \gamma / \tan(\pi (1 - u)) & (u > 1/2) \end{cases}
$$

ここで $x_0$ は位置、$\gamma$ は尺度である。
どちらの形も $\tan$ の引数は $(0, \pi/2)$ に入り、裾に近いほど小さくなるので、$u - 1/2$ の丸めを通らない。
`Logistic` は位置 $x_0$、尺度 $s$ について $s\,\operatorname{logit}(u) + x_0$（$\operatorname{logit}(u) = \ln\{u/(1 - u)\}$）を融合積和で計算する。
端点 $u = 0$ は無限大を生むので、これらの分布は `Rng::next_open_float` で 0 を除いた一様乱数を使う。
分位点を数値的に解く分布（`DoubleParetoLogNormal` など）の `quantile` は数値逆算で、作業量の上限は `LawOptions` の作業量である。
数値逆算の方法は[LawOptions と数値逆算](oxref:random-laws-options-and-inversion)で説明する。

## 256 層の Ziggurat 法

正規分布と指数分布の標本は Ziggurat 法で作る。
この方法は減少する密度 $f$（$x \ge 0$ の片側）の下の領域を、面積の等しい 256 個の水平な層で覆う。
層の面積を $V$、切断点を $R$ とすると、底の層は幅 $V/f(R)$、高さ $f(R)$ の帯で、$[0, R)$ の長方形と $R$ より外の裾を面積で合わせて表す。
その上の層 $i$（$i = 255, \dots, 1$）は幅 $x_i$ で、高さ $f(x_i)$ から $f(x_{i-1})$ までの長方形である（$x_{255} = R$ で、番号が小さいほど上の細い層になる）。
長方形の面積 $x_i\{f(x_{i-1}) - f(x_i)\} = V$ を解くと、層の右端は $x_{255} = R$ から順に

$$
x_{i-1} = f^{-1}\!\left( \frac{V}{x_{i}} + f(x_{i}) \right), \qquad V = R f(R) + \int_R^\infty f(x)\,dx
$$

で決まる（正規分布は $f(x) = e^{-x^2/2}$、指数分布は $f(x) = e^{-x}$）。
$R$ は最上層がちょうど $f(0)$ で閉じる、つまり漸化式が $x_0 = 0$ を与えるように選んだ値で、`f64` では正規分布が $R = 3.6541528853610088$、指数分布が $R = 7.69711747013105$ である。
表は正規分布で 100 桁、指数分布で 120 桁の精度で構成してから `f32` と `f64` に丸め、IEEE のビット列として保存してある。

層が同じ面積なので、層を一様に選び、その長方形の中で横座標 $x = u\,x_i$（$u$ は $[0, 1)$ の一様乱数）を選ぶと、覆った領域の中の一様な点の横座標になる。
$x < x_{i-1}$ なら点は一つ上の層の幅より内側にあり、高さによらず密度の下にあるので、そのまま受理する。
最上層（$i = 1$）は $x_0 = 0$ なので内側の部分を持たず、すべての点が次の判定に進む。
外側なら点はくさび形の部分にあり、高さ $y$ を $[f(x_i), f(x_{i-1})]$ から一様に選んで $y < f(x)$ のときだけ受理する。
底の層で $x \ge R$ となった点は裾の面積に当たるので、裾の分布から別に作る。
受理した $x$ の分布は密度 $f$ に比例し、アルゴリズムとしては近似を含まない。

一つの標本の速い経路は一様乱数ワードを一つだけ使う。
`f64` は 64 ビット、`f32` は 32 ビットの一様乱数ワードを使い、ワードを重ならないビットの区画に分ける。
下位 8 ビットが層 $i$ を選ぶ。
正規分布ではビット 8 が符号を表し、ビット 9 から上の 52 ビット（`f32` では 23 ビット）が $u$ を決める。
指数分布は符号を持たないので、ビット 8 から上を $u$ に使う。
$x < x_{i-1}$ の判定は比 $x_{i-1}/x_i$ を仮数の単位に直した整数の表との比較で行い、超越関数を評価しない。

正規分布の裾は Marsaglia の方法で作る。
一様乱数二つから $E_1, E_2 \sim \mathrm{Exp}(1)$ を作り（一様乱数が 0 なら新しいワードからやり直す）、$x = R + E_1/R$ を $2E_2 > (E_1/R)^2$ のとき受理する。
指数分布の裾は無メモリ性による $R - \ln U$ で、開区間の一様乱数を一つ使う。
`Exponential` の rustdoc によると、指数分布では約 98.9% の標本が一様乱数ワード一つで受理され、対数を評価しない。
どの棄却も 1,024 候補で止まり、`ConvergenceFailure` を返す（[棄却と作業量の上限](oxref:random-algorithms-rejection-limits)）。

`Normal::new(μ, σ)` の標本は標準正規変量 $z$ から $\sigma z + \mu$ を融合積和で作るので、結果は正確な値を一度だけ丸めたものになる。
$\mu = 0$、$\sigma = 1$ では $z$ をそのまま返す。
標準指数変量 $E$ から作る分布は、`Exponential` が $E/\lambda$、`WeibullMin` が $E^{1/c}$、`Pareto` が $\exp(E/b)$ を返す。
Box–Muller 変換 $Z = \sqrt{-2\ln U_1}\cos(2\pi U_2)$ も正規分布に従う標本を与えるが、SciOxide の正規分布はこれを使わない。

## 変量の組合せ

尺度 $\theta$ のガンマ分布 $\mathrm{Gamma}(\alpha, \theta)$（`Gamma::new(shape, scale)`）の標本は Marsaglia–Tsang 法で作る。
この方法は標準正規変量 $Z$ の三次式 $d(1 + cZ)^3$ の分布が $\mathrm{Gamma}(\alpha, 1)$ に近いこと（Wilson–Hilferty 近似）を使い、そのずれを棄却で正す。
$\alpha \ge 1$ では $d = \alpha - 1/3$、$c = 1/\sqrt{9d}$ を構築時に用意し、$V = (1 + cZ)^3$ を作る。
$1 + cZ \le 0$ では変換が単調でなく目標の密度が 0 なので棄却し、開区間の $U$ について

$$
U < 1 - 0.0331 Z^4 \quad\text{または}\quad \ln U < \tfrac{1}{2} Z^2 + d\,(1 - V + \ln V)
$$

なら $\theta d V$ を受理する。
最初の判定は受理確率の下界で、対数を使わずにほとんどの候補をここで受理する。
二つ目の判定は変換した密度と正規密度の比の対数で、これにも落ちた候補を棄却する。

$\alpha < 1$ では $\mathrm{Gamma}(\alpha + 1)$ の標本に $U^{1/\alpha}$ を掛ける（Stuart の定理による Ahrens–Dieter の昇格）。
`Gamma` はこの昇格と尺度 $\theta$ を対数のまま足してから指数を取る。
そのため $U^{1/\alpha}$ 単独ではアンダーフローする場合でも、尺度を掛けて表せる標本は失われない。
正の標本が 0 に丸まれば `NumericalInstability`（`Underflow`）、範囲を超えれば `Overflow` を返す。
`ChiSquared::new(k)` は $\mathrm{Gamma}(k/2, 2)$ である。

`Beta` は独立な $G_1 \sim \mathrm{Gamma}(\alpha, 1)$、$G_2 \sim \mathrm{Gamma}(\beta, 1)$ から $G_1/(G_1 + G_2)$ を作る。
形状母数が 1 未満だと、$U^{1/\alpha}$ の昇格で二つの変量が同時にアンダーフローしうる。
そのため構築時に $\alpha < 1$ か $\beta < 1$ なら、アンダーフローが起きるかによらず、すべての標本を対数の経路で作る。
この経路は昇格を $\ln U/\alpha$ のまま扱って対数オッズ $L = \ln G_1 - \ln G_2$ を作り、$1/(1 + e^{-L})$ を $e^{-\lvert L \rvert}$ から計算する。
組を捨てて引き直すことはないが、結果の確率は 0 や 1 に丸められることがある。
`BetaPrime` は母数によらず同じ対数オッズ $\ln G_a - \ln G_b$ の指数で $G_a/G_b$ を作る。
最後の値が 0 に丸められれば `NumericalInstability`（`Underflow`）、範囲を超えれば `Overflow` を返す。
`LogNormal` は正規標本の指数である。
`StudentT` は $T = Z / \sqrt{V/\nu}$（$V \sim \chi^2_\nu$）で、分母がアンダーフローで 0 になった場合は無限大を返さずに `NumericalInstability`（`Underflow`）とする。
これらの分布は使う標本化器を構築時に一度だけ準備し、標本ごとに特殊関数を評価しない。

## 重い裾とモーメント

Cauchy 分布には平均も分散もない。
`Cauchy` は `Mean` と `Variance` を実装しないので、平均を求めるコードはコンパイルできない。
Student t 分布では $\nu \le 1$ の平均と $\nu \le 2$ の分散が存在せず、`mean()` と `variance()` は理由 `Undefined` の `DomainError` を返す。
このような分布の標本は中央値や四分位範囲、あるいは分布関数との比較で点検し、標本平均は使わない。

標本化器の点検には、分位点で区切った等確率の区間を使う Pearson の適合度検定が向く。
区間を $K$ 個とし、$j$ 番目の区間を $[Q((j-1)/K), Q(j/K))$ とする。
標本が $F$ に従うとき、各区間の度数 $O_j$ は二項分布 $\mathrm{B}(n, 1/K)$ に従い、期待度数は $n/K$、標準偏差は $\sqrt{(n/K)(1 - 1/K)}$ である。
統計量

$$
X^2 = \sum_{j=1}^{K} \frac{(O_j - n/K)^2}{n/K}
$$

は $n \to \infty$ で自由度 $K - 1$ のカイ二乗分布に近づく。
区間の境界は $F$ から決まり、推定した母数を使わないので、自由度は減らない。

次のセルは選んだ分布から `sample_n` で $n$ 個の標本を作り、$K = 20$ の等確率区間の度数を数える。
入力は分布、標本数 $n$、乱数のシードである。
棒グラフは度数と、期待度数 $n/20$ の線と、期待度数 $\pm 2$ 標準偏差の範囲を示す。
表は $X^2$、自由度 19 のカイ二乗分布の 2.5% 点と 97.5% 点、上側確率 $P(\chi^2_{19} \ge X^2)$ と、標本平均を理論の標準誤差 $\sqrt{\mathrm{Var}/n}$ で標準化した値 $z$ を示す。
区間の境界、カイ二乗分布の分位点と上側確率は SciOxide の `quantile` と `sf` で計算する。

//| ref: random-continuous-goodness-of-fit
//| title: 等確率区間の度数で連続分布の標本を点検する
//| run: reactive
//| crates: [scioxide-core, scioxide-random]
//| inputs:
//|   law_name: {"type":"select","label":"分布","options":["正規 N(1, 2²)","指数 Exp(λ = 2)","ガンマ Gamma(0.5, 1)","ガンマ Gamma(4, 1)","ベータ Beta(2, 5)","Student t（ν = 5）"],"value":"ガンマ Gamma(0.5, 1)"}
//|   sample_count: {"type":"range","label":"標本数 n [個]","min":1000,"max":20000,"step":1000,"value":8000}
//|   seed: {"type":"range","label":"乱数のシード [-]","min":1,"max":1000,"step":1,"value":11}
//| cases:
//|   - {"id":"student-t","label":"Student t（ν = 5）","description":"X² は区間に入るが、標準化した平均は −2.32 と ±2 をわずかに超える。","inputs":{"law_name":"Student t（ν = 5）"}}
//|   - {"id":"beta-large","label":"Beta(2, 5)、n = 20000","description":"標本数を増やしても X² の分布は自由度 19 のまま変わらない。","inputs":{"law_name":"ベータ Beta(2, 5)","sample_count":20000}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"fit","path":"/rows/0/0","range":{"min":5,"max":45}}
//|       - {"artifact":"fit","path":"/rows/0/1","range":{"min":8.906,"max":8.908}}
//|       - {"artifact":"fit","path":"/rows/0/2","range":{"min":32.851,"max":32.853}}
//|       - {"artifact":"fit","path":"/rows/0/5","approx":{"value":0.5,"atol":1e-12}}
//|       - {"artifact":"fit","path":"/rows/0/6","range":{"min":-4,"max":4}}
//|   - case: student-t
//|     expect:
//|       - {"artifact":"fit","path":"/rows/0/0","range":{"min":5,"max":45}}
//|       - {"artifact":"fit","path":"/rows/0/5","approx":{"value":0.0,"atol":1e-12}}
//|       - {"artifact":"fit","path":"/rows/0/6","range":{"min":-4,"max":4}}
//|   - case: beta-large
//|     expect:
//|       - {"artifact":"fit","path":"/rows/0/0","range":{"min":5,"max":45}}
//|       - {"artifact":"fit","path":"/rows/0/5","approx":{"value":0.2857142857,"atol":1e-9}}
//|       - {"artifact":"fit","path":"/rows/0/6","range":{"min":-4,"max":4}}
use scioxide_core::RealScalar;
use scioxide_random::{
    Beta, Cdf, ChiSquared, Distribution, Exponential, Gamma, Mean, Normal, Quantile,
    SeedableRng, SplitMix64, StudentT, Survival, Variance,
};

const BINS: usize = 20;

// 分布の型によらず、等確率区間の度数、X²、標本平均、理論平均、標準化した平均の誤差を返す。
fn check<D>(law: &D, n: usize, seed: u64) -> Result<(Vec<f64>, f64, f64, f64, f64), String>
where
    D: Distribution<f64> + Cdf<f64> + Quantile<f64> + Mean<f64> + Variance<f64>,
{
    let mut rng = SplitMix64::from_seed(seed);
    let samples = law.sample_n(&mut rng, n).map_err(|e| e.to_string())?;
    // 区間の境界 Q(j/K)（j = 1, …, K−1）。最初と最後の区間は無限に延びる。
    let edges = (1..BINS)
        .map(|j| law.quantile(j as f64 / BINS as f64))
        .collect::<Result<Vec<_>, _>>()
        .map_err(|e| e.to_string())?;
    let mut counts = vec![0.0; BINS];
    for &x in &samples {
        counts[edges.partition_point(|&edge| edge <= x)] += 1.0;
    }
    let expected = n as f64 / BINS as f64;
    let chi_square: f64 = counts
        .iter()
        .map(|o| RealScalar::powi(o - expected, 2) / expected)
        .sum();
    // 標本平均の誤差を理論の標準誤差 √(Var/n) で割る。
    let mean = samples.iter().sum::<f64>() / n as f64;
    let theory = law.mean().map_err(|e| e.to_string())?;
    let variance = law.variance().map_err(|e| e.to_string())?;
    let z = (mean - theory) / RealScalar::sqrt(variance / n as f64);
    Ok((counts, chi_square, mean, theory, z))
}

let fixed3 = serde_json::json!({ "notation": "standard", "fractionDigits": 3 });
let sig5 = serde_json::json!({ "notation": "standard", "significantDigits": 5 });
let n = sample_count.round() as usize;
let seed = seed.round() as u64;
let (counts, chi_square, mean, theory, z) = match law_name.as_str() {
    "正規 N(1, 2²)" => check(&Normal::new(1.0, 2.0).map_err(|e| e.to_string())?, n, seed)?,
    "指数 Exp(λ = 2)" => check(&Exponential::new(2.0).map_err(|e| e.to_string())?, n, seed)?,
    "ガンマ Gamma(0.5, 1)" => {
        let law = Gamma::new(0.5, 1.0).map_err(|e| e.to_string())?;
        check(&law, n, seed)?
    }
    "ガンマ Gamma(4, 1)" => {
        let law = Gamma::new(4.0, 1.0).map_err(|e| e.to_string())?;
        check(&law, n, seed)?
    }
    "ベータ Beta(2, 5)" => {
        let law = Beta::new(2.0, 5.0).map_err(|e| e.to_string())?;
        check(&law, n, seed)?
    }
    _ => check(&StudentT::new(5.0).map_err(|e| e.to_string())?, n, seed)?,
};
// 自由度 19 のカイ二乗分布の 2.5% 点、97.5% 点と、X² の上側確率（SciOxide の参照分布）。
let reference = ChiSquared::new((BINS - 1) as f64).map_err(|e| e.to_string())?;
let low = reference.quantile(0.025).map_err(|e| e.to_string())?;
let high = reference.quantile(0.975).map_err(|e| e.to_string())?;
let upper_tail = reference.sf(chi_square).map_err(|e| e.to_string())?;
// 各区間の度数は二項分布 B(n, 1/K) に従い、標準偏差は √((n/K)(1 − 1/K))。
let expected = n as f64 / BINS as f64;
let spread = 2.0 * RealScalar::sqrt(expected * (1.0 - 1.0 / BINS as f64));
let labels: Vec<String> = (1..=BINS).map(|j| j.to_string()).collect();
emit_bar_chart!(
    &labels,
    &counts,
    options = &serde_json::json!({
        "xLabel": "等確率区間の番号 j [-]",
        "yLabel": "度数 [個]",
        "yMin": 0.0,
        "annotations": [
            {
                "kind": "range",
                "axis": "y",
                "from": expected - spread,
                "to": expected + spread,
                "label": "期待度数 ± 2 標準偏差"
            },
            {"kind": "line", "axis": "y", "value": expected, "label": "期待度数 n/20"}
        ]
    })
);
let columns = serde_json::json!([
    { "key": "0", "label": "X²（自由度 19）[-]", "type": "number", "format": fixed2 },
    { "key": "1", "label": "2.5% 点 [-]", "type": "number", "format": fixed3 },
    { "key": "2", "label": "97.5% 点 [-]", "type": "number", "format": fixed3 },
    { "key": "3", "label": "P(χ²₁₉ ≥ X²) [-]", "type": "number", "format": fixed3 },
    { "key": "4", "label": "標本平均 [-]", "type": "number", "format": sig5 },
    { "key": "5", "label": "理論平均 [-]", "type": "number", "format": sig5 },
    { "key": "6", "label": "標準化した平均の誤差 z [-]", "type": "number", "format": fixed2 }
]);
emit_table_with_columns!(
    columns,
    vec![(chi_square, low, high, upper_tail, mean, theory, z)],
    metadata = serde_json::json!({ "id": "fit" })
);

棒グラフは 20 個の区間の度数で、標本が分布に従っていれば、各区間の度数はおよそ 95% の確率で期待度数 $\pm 2$ 標準偏差の帯に入る。
$X^2$ が自由度 19 のカイ二乗分布の 95% 区間 $[8.91, 32.85]$ の外に出る確率は約 5% で、標準化した平均の誤差 $z$ の絶対値が 2 以上になる確率は約 4.6% である。
既定の入力（Gamma(0.5, 1)、$n = 8\,000$、シード 11）では $X^2 = 16.65$（上側確率 0.614）、$z = -1.23$ である。
同じシードと標本数で Student t（$\nu = 5$）を選ぶと $X^2 = 16.41$（上側確率 0.630）だが、$z = -2.32$ と $\pm 2$ をわずかに超える。
$\lvert z \rvert \ge 2.32$ になる確率は約 2.0% なので、この値だけで標本化器の誤りとは判断しない。
指数分布 Exp(2) では $X^2 = 29.93$（上側確率 0.053）で、区間の内側だが上端に近い。
Beta(2, 5) を $n = 20\,000$ にすると $X^2 = 20.55$、$z = 1.05$ で、標本数を増やしても $X^2$ の目安は自由度 19 のまま変わらない。
特定のシードで外に出ても誤りとは限らず、シードを変えても繰り返し外れる場合にだけ標本化器を疑う。

## まとめ

閉じた分位点を持つ分布の標本は開区間の $U$ を使う逆関数法で作り、正規分布と指数分布の標本は一様乱数ワード一つで大部分を受理する 256 層の Ziggurat 法で作る。
ガンマ、ベータ、Student t などは正規・指数・ガンマ変量の組合せで作り、使う標本化器は構築時に準備される。
形状母数が 1 未満のガンマ分布とベータ分布は対数の経路で標本を作るので、途中の変量がアンダーフローしても、表せる標本は失われない。
存在しないモーメントはトレイトを実装しないか `DomainError` を返すかで区別されるので、平均や分散で点検できない分布は分位点や度数で点検する。
等確率区間の $X^2$ と標準化した平均の誤差は、シードを変えたときの分布として読み、一つのシードの結果だけで判断しない。
