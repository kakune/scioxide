[古典的な連続分布の族](../continuous-law-families/)で定義した族について、このページは分位点と標本をどう計算し、裾の確率で桁落ちをどう避けるかを説明する。
分位点の求め方は計算量と精度を決め、標本化の方法は 1 標本あたりの計算コストと、標本の点検で何を確かめられるかを決める。
最後のセルは 5 つの族から標本を作り、Kolmogorov–Smirnov 距離をその帰無分布と比べ、標本平均と標本分散の信頼区間を閉形式の値と比べる。

## 分位点と標本化の方法

分位点の求め方は 3 種類ある。

- 閉形式: $F(x) = p$ を初等関数や標準正規の分位点で解く。
  たとえば `Burr12` は $Q(p) = \bigl((1 - p)^{-1/d} - 1\bigr)^{1/c}$、`Moyal` は $Q(p) = -\ln\bigl(2\,\operatorname{erfc}^{-1}(p)^2\bigr)$、`FatigueLife` は $w = c\,\Phi^{-1}(p)/2$ として $Q(p) = (w + \sqrt{w^2 + 1})^2$ である。
- 特殊関数の逆関数: `Argus` の上側は $P(3/2, \cdot)$ の逆関数、`DoubleGamma` と `Pearson3`（$\lvert\gamma\rvert \ge 0.002$）はガンマ分布の逆関数を使う。
- 数値逆算: 閉形式がない分位点は、小さいほうの裾の対数と目標の対数の差（$p \le 1/2$ なら $\ln F(x) - \ln p$、$p > 1/2$ なら $\ln S(x) - \ln(1 - p)$）を残差とする二分法か、安全策付きの Newton 法で求める。

二分法は台の端（無限の端は $\pm 1$ から広げる）で挟んでから区間を縮め、`LawOptions` の作業量を反復と評価の共通の上限とする。
対数確率の残差の許容値は `LawOptions` の相対許容誤差の 1/8 で、対数の差 $\delta$ は確率の相対誤差 $e^{\delta} - 1 \approx \delta$ に当たる。
`Cosine` と `GeneralizedExponential` はすべての分位点をこの二分法で求める。
一部の領域だけを数値で解く族もある。
`Alpha` は下側を閉形式 $x = 1/\bigl(a - \Phi^{-1}(p\,\Phi(a))\bigr)$ で解き、上側は閉形式（桁落ちするときは主要項 $1/x \approx q\,\Phi(a)/\varphi(a)$）を初期値とする $\ln x$ の Newton 法（最大 16 反復）で解く。
`Argus` は中央値より左の点（下側確率が 1/2 以下）を $\ln x$ についての安全策付きの Newton 法で解き、対数確率の残差 $8\varepsilon(1 + \lvert\ln p\rvert)$ で止める。
この停止条件は `LawOptions` の許容誤差によらない固定の値で、`LawOptions` からは作業量の上限だけを受け取る。
`Pearson3` は $0 < \lvert\gamma\rvert < 0.002$ では Cornish–Fisher 展開を初期値とする同じ Newton 法を使う。
`PowerNormal` は $\bar\Phi(x) = p^{1/c}$ が下位桁あふれしたときだけ二分法に切り替える。
`ReciprocalInverseGaussian` の分位点は、逆ガウス分布の分位点が数値逆算なので、やはり数値逆算になる。

`TukeyLambda` は逆向きで、分位点が閉形式で分布関数がない。
分布関数は $\ln p$ を $[\ln(\text{最小の正規化数}) - 60, \ln(1/2)]$ で 128 回まで二分して求め、裾の確率を相対精度で保つ。

標本化の方法は分位点の方法と独立に選ばれている。

| 方法 | 族 |
|---|---|
| 開区間 $(0, 1)$ の一様乱数 $U$ による逆関数法 $Q(U)$ | `Alpha`、`Anglit`、`Argus`、`Burr12`、`Cosine`、`ExponentiatedWeibull`、`GeneralizedExponential`、`GeneralizedHalfLogistic`、`GeneralizedLogistic`、`HyperbolicSecant`、`InverseWeibull`、`Mielke`、`Moyal`、`PowerNormal`、`TukeyLambda` |
| 正規乱数の変換 $Z \mapsto (w + \sqrt{w^2 + 1})^2$、$w = cZ/2$ | `FatigueLife` |
| ガンマ乱数の変換 | `DoubleGamma`（符号 $\pm$ とガンマ乱数）、`Pearson3`（$\lvert\gamma\rvert \ge 0.002$ で $(G - \beta^2)/\beta$。それより小さい $\lvert\gamma\rvert$ では `f64` の分布関数の逆関数法） |
| 指数乱数の冪 $\pm E^{1/c}$ | `DoubleWeibull` |
| 逆ガウス乱数（Michael–Schucany–Haas 法）の逆数 | `ReciprocalInverseGaussian` |

逆関数法で標本を作る族のうち、`Cosine` と `GeneralizedExponential` は 1 標本ごとに二分法で数値逆算するので、閉形式の族より 1 標本あたりの評価回数が多い。
`Argus` も 1 標本ごとに反復し、$U \le 1/2$ では Newton 法、$U > 1/2$ では $P(3/2, \cdot)$ の逆関数の反復を使う。
`Alpha` は $U > 1/2$ の標本で最大 16 回の Newton 反復を行う。

## 裾での桁落ちの避け方

これらの族は対数の裾 $\ln F(x)$ と $\ln S(x)$ を基本の量とし、確率が 1 に近い側を $1 - (\text{小さい側})$ の引き算で作らない。
小さい側を先に計算し、補数は $\ln(1 - e^{y})$ を $y$ の大きさで式を切り替えて評価する（`log1mexp`）。
例外は `Alpha` の上側で、$x \le 1/\sqrt{\varepsilon}$ では $S(x)$ を $\ln\Phi(a)$ と $\ln\Phi(a - 1/x)$ の差から作るので、$x$ が大きいほど相対精度が落ちる。
$a = 2$、$x = 10^7$ では相対誤差が約 $1.4 \times 10^{-9}$ だった。
族ごとの具体的な処理は次のとおりである。

- `Burr12` は $\ln S(x) = -d\ln(1 + e^{c\ln x})$ を softplus で評価し、$x^c$ のあふれを避ける。
- `InverseWeibull` は $t = x^{-c}$ が $\varepsilon$ より小さい上側で $\ln S(x) \approx \ln t$ を使う。
- `Moyal` は下側で $\ln \operatorname{erfc}(t) = \ln \operatorname{erfcx}(t) - t^2$ を使い、上側の遠方で $\ln S(x) \approx -x/2 + \tfrac{1}{2}\ln(2/\pi)$ を使う。
- `Cosine` は $F(-\pi + t) = (t - \sin t)/(2\pi)$ が小さな $t$ で桁落ちするので、$t < 0.01$ では Taylor 展開 $t^3/6 - t^5/120$ を使う。
- `HyperbolicSecant` は遠い下側で $\arctan z \approx z$ とし、$\ln F(x) = \ln(2/\pi) + \pi x/2$ を $e^{\pi x/2}$ を作らずに返す。
- `Alpha` は $x > 1/\sqrt{\varepsilon}$ で、$h = 1/x$ として $\Phi(a) - \Phi(a - h) = \varphi(a)\,h\,B$ と書き、$\ln B = ah/2 + (a^2/24 - 1/6)h^2$ までの Taylor 展開で $S(x)$ を求めて、$\Phi(a) - \Phi(a - 1/x)$ の引き算を避ける。
  省いた項は $O(h^3(1 + a^4))$ で、$h < \sqrt{\varepsilon}$ なので $\lvert a\rvert \le 100$ では $\varepsilon$ 未満の相対誤差になる。
- `Pearson3` は $\lvert\gamma\rvert < 0.002$ では大きな定数 $\beta^2$ どうしの引き算を避けるため、中心化したガンマを使わない。
  $\lvert\gamma\rvert(1 + \lvert x \rvert)^3 \le 10^{-3}$ の範囲では 2 次の Edgeworth 展開、$\lvert x \rvert > 128$ では端点の Laplace 展開、それ以外では中心化した密度の求積で裾を求める。
- `Argus` は $\chi^2 \to 0$ の極限で正規化定数 $P(3/2, \chi^2/2)$ が $\chi^3$ のように小さくなるので、$\chi^2/2 < \varepsilon$ では極限の閉形式に切り替える。

## 基本の族の数値上の注意

[ほかの標準形の族](oxref:random-families-other-standard)の 13 の族について、数値の扱いで注意する点は次のとおりである。

- `Uniform` は端点をそのまま保持し、幅 $\text{high} - \text{low}$ があふれる端点でも凸結合で標本と分位点を作る。
  $p < 1$ の分位点と標本は $\text{high}$ より小さく、$p = 1$ の分位点だけが $\text{high}$ を返す。
- `IrwinHall` は各単位区間の密度と分布関数を係数が非負の Bernstein 基底で持ち、交代和 $\sum_k (-1)^k\binom{n}{k}(x - k)^{n-1}$ の桁落ちを避ける。
  準備は $O(n^3)$ の計算と $O(n^2)$ の表で、表が `LawOptions::max_bytes` を超えると `ResourceLimit` になる。
  準備は作業量を約 $n^3/3$ 単位使うので、既定の作業量 65,536 では $n \ge 57$ の構築が `ConvergenceFailure` になり、大きな $n$ には `with_options` で上限を上げる。
  1 回の標本は一様乱数を $n$ 回使い、その要求を `sample_word_budget` に数える。
- `Rice` の標本も正規乱数の要求を `sample_word_budget` に数える。
- `InverseGaussian` は上側確率 $S(x) = \bar\Phi(a) - e^{2/\mu}\Phi(b)$（$a = (x/\mu - 1)/\sqrt{x}$、$b = -(x/\mu + 1)/\sqrt{x}$）を 2 項の対数の差で直接作り、$e^{2/\mu}$ を対数の中に入れて小さな $\mu$ でのあふれを避ける。
- `GeneralizedNormal` と `GeneralizedGamma` は標本を対数座標のガンマ乱数から作り、最後に一度だけ丸める。
  結果が 0 に丸まるか有限でなくなるときは、`Underflow` か `Overflow` の `NumericalInstability` を返す。
- `GaussHypergeometric` は正規化定数とモーメントを $x = 1/2$ で分けた求積で求め、裾は近いほうの端点から $x$ までを 1 回の求積で求める。
  どちらも端点の特異性を変数変換で取り除く。
- `RelativisticBreitWigner` は裾を正の被積分関数のまま直接求積し、$x$ が $\sqrt{(\rho\sqrt{1 + \rho^2} + \rho^2)/2}$ の $10^6$ 倍を超える上側では主要項 $\propto x^{-3}$ を使う。
- `Bradford` は上側確率を $\ln\bigl(1 + c(1 - x)/(1 + cx)\bigr)/\ln(1 + c)$ と書き換え、$x \to 1$ での引き算を避ける。

## 標本による分布関数とモーメントの照合

標本化器と分布関数は別の実装なので、一方の誤りは両者の食い違いとして現れる。
$n$ 個の標本の経験分布関数 $F_n$ と理論の $F$ の Kolmogorov–Smirnov 距離は、昇順の標本 $x_{(1)} \le \dots \le x_{(n)}$ について

$$
D_n = \sup_x \lvert F_n(x) - F(x) \rvert = \max_{1 \le i \le n} \max\Bigl( \tfrac{i}{n} - F(x_{(i)}),\; F(x_{(i)}) - \tfrac{i - 1}{n} \Bigr)
$$

である。
$F$ が連続で標本が $F$ に従うとき、$\sqrt{n}\,D_n$ の分布は $n \to \infty$ で Kolmogorov 分布 $K$ に近づき、その上側 5% 点は約 1.358 である。
このページは漸近の上側確率 $P(K > \sqrt{n}\,D_n)$ を近似の $p$ 値として示し、有限標本の正確な $p$ 値との差は $n^{-1/2}$ の程度で小さくなる。
有限標本の正確な分布は[検定統計量の分布と有限標本の KS 分布](../test-statistic-laws/)の `KolmogorovSmirnovTwoSided` で求められる。

正しい標本化器でも $p$ 値は近似的に $(0, 1)$ の一様分布に従う確率変数で、シードを変えれば 0 から 1 の間を動く。
1 回の実行で $p < 0.05$ となる確率は 5% なので、小さな $p$ 値が出たときはシードを変えて再現するかを確かめる。

モーメントについては標本平均 $\bar{x}$ の標準誤差を $s/\sqrt{n}$、標本分散 $s^2$ の標準誤差を $\sqrt{(m_4 - s^4)/n}$（$m_4$ は標本の 4 次中心モーメント）で推定し、$\pm 1.96$ 標準誤差の区間と $z = (\text{推定値} - \text{閉形式})/\text{標準誤差}$ を出す。
分散の区間には 4 次モーメントの存在が要るので、`Burr12` の母数は $cd = 6 > 4$ を満たすものを選んだ。

次のセルは選んだ族から $n$ 個の標本をシード `seed` で作り、$D_n$、$\sqrt{n}\,D_n$、近似の $p$ 値、Kolmogorov 分布の上側 5% 点を 1 つ目の表に出す。
2 つ目の表は標本平均と標本分散、その 95% 信頼区間、閉形式の値との差の $z$ である。
閉形式の値は文献の式をセルの中で計算した独立検算で、`Burr12` のガンマ関数だけ `scioxide_special::gamma` を使う。

```rust
// 標本を作って昇順に並べ、各点の分布関数 F(x) を返す。
fn draw<D: Distribution<f64> + Cdf<f64>>(
    law: &D,
    n: usize,
    seed: u64,
) -> Result<(Vec<f64>, Vec<f64>), String> {
    let mut rng = SplitMix64::from_seed(seed);
    let mut x = (0..n)
        .map(|_| law.sample(&mut rng))
        .collect::<Result<Vec<_>, _>>()
        .map_err(|e| e.to_string())?;
    x.sort_by(f64::total_cmp);
    let f = x
        .iter()
        .map(|&v| law.cdf(v))
        .collect::<Result<Vec<_>, _>>()
        .map_err(|e| e.to_string())?;
    Ok((x, f))
}

    }

// モーメント: 平均の SE は s/√n、分散の SE は √((m₄ − s⁴)/n)。
let mean = x.iter().sum::<f64>() / nf;
let (s2, s4) = x.iter().fold((0.0, 0.0), |(a, b), &v| {
    let d2 = RealScalar::powi(v - mean, 2);
    (a + d2, b + d2 * d2)
});
let var = s2 / (nf - 1.0);
let se = [
    RealScalar::sqrt(var / nf),
    RealScalar::sqrt((s4 / nf - var * var) / nf),
];
let row = |k: usize, name: &'static str, est: f64| {
    let (ci, z) = (1.96 * se[k], (est - exact[k]) / se[k]);
    (name, exact[k], est, est - ci, est + ci, z)
};
let moment_columns = serde_json::json!([
    { "key": "0", "label": "量" },
    { "key": "1", "label": "閉形式 [-]", "type": "number", "format": sig5 },
    { "key": "2", "label": "標本推定 [-]", "type": "number", "format": sig5 },
    { "key": "3", "label": "95% CI 下限 [-]", "type": "number", "format": sig5 },
    { "key": "4", "label": "95% CI 上限 [-]", "type": "number", "format": sig5 },
    { "key": "5", "label": "z [-]", "type": "number", "format": fixed2 }
]);
emit_table_with_columns!(
    moment_columns,
    vec![row(0, "平均", mean), row(1, "分散", var)],
    metadata = serde_json::json!({ "id": "moments" })
);
```

既定の入力（`Burr12`、$c = 3$、$d = 2$、$n = 2\,000$、シード 42）では $D_n = 0.01348$、$\sqrt{n}\,D_n = 0.603$ で、近似の $p$ 値は 0.860 である。
平均の閉形式 $\Gamma(4/3)\Gamma(5/3) = 0.80613$ に対して標本平均は 0.80866（$z = 0.29$）、分散の閉形式 0.15628 に対して標本分散は 0.14771（$z = -1.19$）で、どちらも 95% 信頼区間に入る。

`Cosine` と `Moyal` を選んでも $D_n$ は 0.01348 のまま変わらない。
逆関数法では $F(x_{(i)}) = F(Q(U_{(i)})) = U_{(i)}$ なので、$D_n$ は同じシードの一様乱数の KS 距離そのものになるからである。
`Cosine` と `Burr12` の $D_n$ の差は $4.7 \times 10^{-11}$ で、これは `Cosine` の数値逆算が $F(Q(u)) = u$ を満たす精度を表す。
したがって逆関数法の族では、KS 距離は $F$ と $Q$ が互いの逆関数になっていることだけを確かめ、$F$ と $Q$ に共通の誤りは見逃す。
その誤りは文献の閉形式と比べるモーメントの $z$ で検出する。

`FatigueLife` と `Pearson3`（$\lvert\gamma\rvert \ge 0.002$）は正規乱数やガンマ乱数の変換で標本を作り、分布関数の逆関数を通らない。
この場合の KS 距離は標本化器と分布関数という独立な二つの実装を比べる。
`FatigueLife`（$c = 0.5$）では $D_n = 0.00868$（$p = 0.998$）、平均 1.12379 は閉形式 1.125 と $z = -0.10$ である。
`Pearson3`（歪度 1）では $D_n = 0.0225$（$p = 0.263$）、平均の $z = 1.70$ で、$n = 5\,000$ にすると $D_n = 0.00619$（$p = 0.991$）、平均の $z = -0.12$ になる。

1 回の実行の $z$ が $\pm 1.96$ の外に出る確率は 1 つの量につき約 5% である。
シードを 1 にした `Burr12` では平均の $z = -1.72$、$p = 0.166$ で、どちらもシードによる揺らぎの範囲に入る。

## まとめ

分位点は閉形式、特殊関数の逆関数、数値逆算のいずれかで求まり、数値逆算は `LawOptions` の作業量を上限とする二分法か、固定の停止条件の Newton 法である。
`Cosine`、`GeneralizedExponential`、`Argus`、`GaussHypergeometric`、`RelativisticBreitWigner` は標本化のたびに、`Alpha` は $U > 1/2$ の標本で反復計算を行うので、大量の標本では閉形式の族より計算コストが大きい。
裾の確率は小さい側を対数で先に求めるので、`Alpha` の上側を除き、1 に近い確率の補数でも相対精度が保たれる。
逆関数法で標本を作る族の KS 距離は $F$ と $Q$ の整合だけを確かめるので、閉形式のモーメントとの比較を併せて行う。
変換で標本を作る族では、KS 距離とその帰無分布による $p$ 値が標本化器と分布関数を独立に比べる。
