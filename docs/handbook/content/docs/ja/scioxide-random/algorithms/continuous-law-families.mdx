正規分布、ガンマ分布、Weibull 分布のような基本の分布のほかに、`scioxide-random` は分布関数や分位点が初等関数・特殊関数で書ける古典的な族を 20 個持つ。
後半の節では一様分布、Irwin–Hall 分布、一般化正規分布、逆ガウス分布など、ほかのページで名前だけが出る 13 の族も同じ観点で表にする。
このページは各族の定義をコンストラクターの母数の名前のまま示し、台、母数の定義域、平均と分散の存在条件を表にまとめる。
分位点と標本の作り方、裾の計算、標本による点検は[古典的な族の分位点・標本化・裾の計算](../continuous-law-computation/)で説明する。

対応機能を表すトレイト（`Cdf`、`Quantile`、`Mean` など）の規約と `LawOptions` の意味は[対応機能を表すトレイト](oxref:random-laws-capability-traits)と[LawOptions と数値逆算](oxref:random-laws-options-and-inversion)にある。

## 標準形と機能の共通規約

このページの分布は `Uniform` と `DoubleParetoLogNormal` を除いて位置 0・尺度 1 の標準形で、位置と尺度は `Affine::new(law, μ, σ)` で加える。
`Affine` は元の分布が持つ機能だけを引き継ぎ、負の $\sigma$ は左右を反転する。

機能は族ごとに実装の有無が決まる。
平均や分散が母数によって存在しないときは、`mean()` や `variance()` が理由 `Undefined` の `DomainError` を返す。
`Alpha`（平均と分散が存在しない）と、閉形式を用意していない `ExponentiatedWeibull`、`GeneralizedExponential`、`GeneralizedHalfLogistic`、`PowerNormal` は `Mean` と `Variance` を実装しない。
これらのモーメントが必要なときは、$\mathrm{E}[X^r] = \int_0^1 Q(u)^r\,du$ を `quantile` と求積で利用者が計算する。
`Entropy` はこのページの族のうち `Uniform` だけが実装する。

`LawOptions` を使う族は、特殊関数の反復、求積、数値逆算にその許容誤差（既定は相対・絶対とも $\sqrt{\varepsilon} \approx 1.5 \times 10^{-8}$）と作業量の上限（既定 65,536）を使う。
ただし一部の Newton 法は固定の停止条件を使い、`LawOptions` からは作業量の上限だけを受け取る（[分位点と標本化の方法](oxref:random-families-quantiles-and-sampling)）。
これらの族の `new` は既定の `LawOptions` で分布を作り、`with_options` は母数の後に設定を取る。
下の表で `with_options` を併記した族がこれに当たる。
`LawOptions` を使わない族は `new` だけを持ち、すべての問い合わせを閉形式か上限の決まった計算で行う。

母数の検査はコンストラクターが行う。
有限の母数が定義域の外にあれば理由 `OutsideDomain` の `DomainError`、NaN や無限大の母数には `NonFinite` を返す。
定義域の中でも、$1/c$ や $\chi^2/2$ のような構築に使う量があふれる母数は `NumericalInstability`（`Overflow`）になる。

## 族の定義と台

$\Phi$ と $\varphi$ は標準正規の分布関数と密度、$\bar\Phi = 1 - \Phi$、$P(a, x)$ は正則化した下側不完全ガンマ関数である。
表の「定義」はコンストラクターの母数で書いた分布関数 $F$、上側確率 $S = 1 - F$、密度 $f$ のいずれかで、分布はこの式で決まる。

有界な台を持つ族は次のとおりである。

| コンストラクター | 母数の定義域 | 台 | 定義 |
|---|---|---|---|
| `Anglit::new()` | なし | $[-\pi/4, \pi/4]$ | $f(x) = \cos 2x$、$F(x) = \sin^2(x + \pi/4)$ |
| `Cosine::new()`（`with_options`） | なし | $[-\pi, \pi]$ | $f(x) = (1 + \cos x)/(2\pi)$、$F(x) = (\pi + x + \sin x)/(2\pi)$ |
| `Argus::new(chi)`（`with_options`） | $\chi > 0$、$\chi^2/2$ が有限 | $[0, 1]$ | $S(x) = P(3/2, \chi^2(1 - x^2)/2)\,/\,P(3/2, \chi^2/2)$ |
| `GeneralizedHalfLogistic::new(c)` | $c > 0$、$1/c$ が有限 | $[0, 1/c]$ | $t = (1 - cx)^{1/c}$ として $F(x) = (1 - t)/(1 + t)$ |
| `TukeyLambda::new(lambda)`（$\lambda > 0$） | $\lambda$ と $1/\lambda$ は有限 | $[-1/\lambda, 1/\lambda]$ | 分位点 $Q(p) = (p^\lambda - (1 - p)^\lambda)/\lambda$ |

正の半直線に台を持つ族は次のとおりである。

| コンストラクター | 母数の定義域 | 台 | 定義 |
|---|---|---|---|
| `Alpha::new(shape)`（`with_options`） | $a > 0$ | $(0, \infty)$ | $F(x) = \Phi(a - 1/x)/\Phi(a)$。$Z < a$ に条件付けた標準正規 $Z$ による $1/(a - Z)$ |
| `Burr12::new(c, d)` | $c, d > 0$ | $[0, \infty)$ | $F(x) = 1 - (1 + x^c)^{-d}$ |
| `ExponentiatedWeibull::new(a, c)` | $a, c > 0$ | $[0, \infty)$ | $F(x) = (1 - e^{-x^c})^a$ |
| `FatigueLife::new(shape)` | $c > 0$ | $(0, \infty)$ | $F(x) = \Phi\bigl((\sqrt{x} - 1/\sqrt{x})/c\bigr)$。中央値は 1 |
| `GeneralizedExponential::new(a, b, c)`（`with_options`） | $a, b, c > 0$ | $[0, \infty)$ | 危険率 $a + b(1 - e^{-cx})$、$S(x) = \exp\bigl(-(a + b)x + b(1 - e^{-cx})/c\bigr)$ |
| `InverseWeibull::new(c)` | $c > 0$ | $(0, \infty)$ | $F(x) = \exp(-x^{-c})$（Fréchet 型） |
| `Mielke::new(k, s)` | $k, s > 0$ | $[0, \infty)$ | $F(x) = \bigl(x^s/(1 + x^s)\bigr)^{k/s}$。$k = s$ は対数ロジスティック |
| `ReciprocalInverseGaussian::new(mu)`（`with_options`） | $\mu > 0$ | $(0, \infty)$ | $1/Y$、$Y$ は平均 $\mu$・形状 1 の逆ガウス分布 |

実数全体（`Pearson3` は歪度が 0 でなければ半直線）に台を持つ族は次のとおりである。

| コンストラクター | 母数の定義域 | 台 | 定義 |
|---|---|---|---|
| `DoubleGamma::new(shape)`（`with_options`） | $k > 0$ | $\mathbb{R}$ | $f(x) = \lvert x \rvert^{k-1} e^{-\lvert x \rvert}/(2\Gamma(k))$。$k = 1$ は Laplace |
| `DoubleWeibull::new(shape)` | $c > 0$ | $\mathbb{R}$ | $f(x) = (c/2)\lvert x \rvert^{c-1} e^{-\lvert x \rvert^c}$ |
| `GeneralizedLogistic::new(shape)` | $c > 0$ | $\mathbb{R}$ | $F(x) = (1 + e^{-x})^{-c}$ |
| `HyperbolicSecant::new()` | なし | $\mathbb{R}$ | $F(x) = (2/\pi)\arctan e^{\pi x/2}$、$f(x) = \tfrac{1}{2}\operatorname{sech}(\pi x/2)$ |
| `Moyal::new()` | なし | $\mathbb{R}$ | $f(x) = e^{-(x + e^{-x})/2}/\sqrt{2\pi}$、$F(x) = \operatorname{erfc}(e^{-x/2}/\sqrt{2})$ |
| `Pearson3::new(skew)`（`with_options`） | 歪度 $\gamma$ は有限 | $\gamma > 0$ で $[-2/\gamma, \infty)$、$\gamma < 0$ で $(-\infty, -2/\gamma]$、$\gamma = 0$ で $\mathbb{R}$ | $\beta = 2/\gamma$、$G \sim \mathrm{Gamma}(\beta^2, 1)$ として $(G - \beta^2)/\beta$。$\gamma = 0$ は標準正規 |
| `PowerNormal::new(c)`（`with_options`） | $c > 0$ | $\mathbb{R}$ | $S(x) = \bar\Phi(x)^c$ |
| `TukeyLambda::new(lambda)`（$\lambda \le 0$） | $\lambda$ は有限 | $\mathbb{R}$ | $Q(p) = (p^\lambda - (1 - p)^\lambda)/\lambda$、$\lambda = 0$ は $Q(p) = \ln(p/(1 - p))$（ロジスティック） |

`Pearson3` は平均 0・分散 1 に標準化した 1 母数（歪度）の分布で、3 母数の Pearson III 分布は `Affine` で位置と尺度を加えて作る。
`TukeyLambda` は分布関数の閉形式を持たず、分位点関数で定義される。
`DoubleGamma` の $k$ と `GeneralizedLogistic` の $c$ はどちらもコンストラクターの引数 `shape` に当たる。

## 平均と分散

平均と分散は閉形式で返し、ガンマ関数、ディガンマ関数 $\psi$、合流型超幾何関数 ${}_1F_1$ などを `scioxide-special` で評価する。

| 族 | 平均 | 分散 | 存在の条件 |
|---|---|---|---|
| `Anglit` | 0 | $\pi^2/16 - 1/2$ | 常に |
| `Cosine` | 0 | $\pi^2/3 - 2$ | 常に |
| `Argus` | ${}_1F_1$ と $P(3/2, \cdot)$ による | 2 次の原点モーメントから | 常に |
| `Burr12` | $\Gamma(1 + 1/c)\Gamma(d - 1/c)/\Gamma(d)$ | 2 次の原点モーメントから | $r$ 次は $r < cd$ |
| `FatigueLife` | $1 + c^2/2$ | $c^2(1 + 5c^2/4)$ | 常に |
| `InverseWeibull` | $\Gamma(1 - 1/c)$ | $\Gamma(1 - 2/c) - \Gamma(1 - 1/c)^2$ | $r$ 次は $r < c$ |
| `Mielke` | $\Gamma(k/s + 1/s)\Gamma(1 - 1/s)/\Gamma(k/s)$ | 2 次の原点モーメントから | $r$ 次は $r < s$ |
| `ReciprocalInverseGaussian` | $1/\mu + 1$ | $1/\mu + 2$ | 常に |
| `DoubleGamma` | 0 | $k(k + 1)$ | 常に |
| `DoubleWeibull` | 0 | $\Gamma(1 + 2/c)$ | 常に |
| `GeneralizedLogistic` | $\psi(c) - \psi(1)$ | $\psi'(c) + \psi'(1)$ | 常に |
| `HyperbolicSecant` | 0 | 1 | 常に |
| `Moyal` | $\gamma_{\mathrm{E}} + \ln 2$ | $\pi^2/2$ | 常に |
| `Pearson3` | 0 | 1 | 常に |
| `TukeyLambda` | 0 | $2\bigl(1/(1 + 2\lambda) - B(1 + \lambda, 1 + \lambda)\bigr)/\lambda^2$ | 平均は $\lambda > -1$、分散は $\lambda > -1/2$ |

`TukeyLambda` の分散の式は $\lambda \to 0$ で桁落ちするので、$\lvert\lambda\rvert < 0.05$ では $\ln\Gamma$ の級数（係数は $\zeta(k)$）から $B(1 + \lambda, 1 + \lambda)$ の対数を作り、`expm1` で引き算を避けて `f64` で評価する（$\lambda = 0$ で $\pi^2/3$）。
rustdoc はこの評価の相対誤差を $2 \times 10^{-15}$ 未満としている。

## ほかの標準形の族

次の 13 の族は一様分布や逆ガウス分布のような基本の分布と、モーメントや裾を求積で評価する分布である。
定義はコンストラクターの母数で書き、$Z$、$Z_1$、$Z_2$ は独立な標準正規、$E_1$、$E_2$ は独立な標準指数とする。
`Uniform` は端点で、`DoubleParetoLogNormal` は $\mu$、$\sigma$ で位置と尺度をコンストラクターに受け取る。

| コンストラクター | 母数の定義域 | 台 | 定義 |
|---|---|---|---|
| `Uniform::new(low, high)` | 有限で $\text{low} < \text{high}$ | $[\text{low}, \text{high})$ | $f(x) = 1/(\text{high} - \text{low})$ |
| `Trapezoid::new(c, d)` | $0 \le c \le d \le 1$ | $[0, 1]$ | 密度は $[0, c]$ で上がり、$[c, d]$ で高さ $2/(1 + d - c)$ の平ら、$[d, 1]$ で下がる。$c = d$ は三角分布 |
| `Bradford::new(shape)` | $c > 0$ | $[0, 1]$ | $F(x) = \ln(1 + cx)/\ln(1 + c)$ |
| `IrwinHall::new(n)`（`with_options`） | 整数 $n \ge 1$（$n = 0$ は `InvalidInput`） | $[0, n]$ | 独立な $n$ 個の標準一様の和 |
| `GeneralizedNormal::new(shape)`（`with_options`） | $\beta > 0$ | $\mathbb{R}$ | $f(x) = \beta e^{-\lvert x \rvert^\beta}/\bigl(2\Gamma(1/\beta)\bigr)$。$\beta = 1$ は Laplace、$\beta = 2$ は分散 1/2 の正規 |
| `GeneralizedGamma::new(a, c)`（`with_options`） | $a > 0$、$c \ne 0$ は有限 | $(0, \infty)$ | $f(x) = \lvert c \rvert x^{ac - 1}e^{-x^c}/\Gamma(a)$。$X^c \sim \mathrm{Gamma}(a, 1)$ |
| `InverseGaussian::new(mu)`（`with_options`） | $\mu > 0$ | $(0, \infty)$ | 平均 $\mu$、形状 1。$F(x) = \Phi\bigl((x/\mu - 1)/\sqrt{x}\bigr) + e^{2/\mu}\Phi\bigl(-(x/\mu + 1)/\sqrt{x}\bigr)$ |
| `ExponentialPower::new(shape)`（`with_options`） | $b > 0$ | $[0, \infty)$ | $S(x) = \exp(1 - e^{x^b})$。寿命の分布で、`GeneralizedNormal` とは別の分布 |
| `GaussHypergeometric::new(a, b, c, z)`（`with_options`） | $a, b > 0$、$c$ は有限、$z > -1$ | $[0, 1]$ | $f(x) \propto x^{a-1}(1 - x)^{b-1}(1 + zx)^{-c}$。$c = 0$ はベータ分布 |
| `JohnsonSB::new(a, b)`（`with_options`） | $a$ は有限、$b > 0$ | $(0, 1)$ | $a + b\,\operatorname{logit}(X)$ が標準正規 |
| `Rice::new(shape)`（`with_options`） | $b \ge 0$ | $[0, \infty)$ | $X = \sqrt{(Z_1 + b)^2 + Z_2^2}$。$b = 0$ は Rayleigh |
| `DoubleParetoLogNormal::new(mu, sigma, alpha, beta)`（`with_options`） | $\mu$ は有限、$\sigma, \alpha, \beta > 0$ | $(0, \infty)$ | $X = \exp(\mu + \sigma Z + E_1/\alpha - E_2/\beta)$ |
| `RelativisticBreitWigner::new(rho)`（`with_options`） | $\rho > 0$ | $[0, \infty)$ | $f(x) \propto 1/\bigl((x^2 - \rho^2)^2 + \rho^2\bigr)$ |

13 の族はすべて `Mean` と `Variance` を実装し、`Entropy` は `Uniform` だけが実装する（$\ln(\text{high} - \text{low})$）。

| 族 | 分位点 | 標本化 | 平均と分散 |
|---|---|---|---|
| `Uniform` | 閉形式 $(1 - p)\,\text{low} + p\,\text{high}$ | 逆関数法 | $(\text{low} + \text{high})/2$、$(\text{high} - \text{low})^2/12$ |
| `Trapezoid` | 閉形式（区分ごとの平方根） | 逆関数法 | 原点モーメントの閉形式 |
| `Bradford` | 閉形式 $\bigl((1 + c)^p - 1\bigr)/c$ | 逆関数法 | 平均 $1/\ln(1 + c) - 1/c$ と分散の閉形式（$c \le 1/8$ では桁落ちを避けて 20 項の級数） |
| `IrwinHall` | 数値逆算 | 一様乱数 $n$ 個の和 | $n/2$、$n/12$ |
| `GeneralizedNormal` | 上側の正則化不完全ガンマ関数の逆 $Q^{-1}(1/\beta, 2\min(p, 1 - p))^{1/\beta}$ に符号を付ける | 符号とガンマ乱数の冪 | 0、$\Gamma(3/\beta)/\Gamma(1/\beta)$ |
| `GeneralizedGamma` | ガンマ分布の逆関数の $1/c$ 乗 | ガンマ乱数の冪 | $\mathrm{E}[X^r] = \Gamma(a + r/c)/\Gamma(a)$（$a + r/c > 0$ のときだけ存在） |
| `InverseGaussian` | 数値逆算 | Michael–Schucany–Haas 法 | $\mu$、$\mu^3$ |
| `ExponentialPower` | 閉形式 $\bigl(\ln(1 - \ln(1 - p))\bigr)^{1/b}$ | 逆関数法 | 分位点の求積 |
| `GaussHypergeometric` | 数値逆算 | 逆関数法（1 標本ごとに数値逆算） | 密度の求積 |
| `JohnsonSB` | 閉形式 $\operatorname{sigmoid}\bigl((\Phi^{-1}(p) - a)/b\bigr)$ | 正規乱数の変換 | 分位点の求積 |
| `Rice` | 非心カイ二乗分布（自由度 2、非心度 $b^2$）の分位点の平方根 | 2 つの正規乱数 | 平均は Poisson 混合の級数（$b \ge 32$ では 12 項の漸近展開）、分散は $b < 32$ で $2 + b^2 - (\text{平均})^2$、$b \ge 32$ では同じ漸近展開 |
| `DoubleParetoLogNormal` | 数値逆算 | 正規乱数と 2 つの指数乱数 | $\mathrm{E}[X^r] = e^{r\mu + r^2\sigma^2/2}\frac{\alpha}{\alpha - r}\frac{\beta}{\beta + r}$（$r < \alpha$） |
| `RelativisticBreitWigner` | 数値逆算 | 逆関数法（1 標本ごとに数値逆算） | 平均は閉形式、$\mathrm{E}[X^2] = \rho\sqrt{1 + \rho^2}$。密度が $x^{-4}$ で減るので 3 次以上は存在しない |

「分位点の求積」は $\mathrm{E}[X^r] = \int_0^1 Q(u)^r\,du$ を `LawOptions` の許容誤差と作業量の中で求積する方法で、平均と分散は推定値である。
「数値逆算」は[分位点と標本化の方法](oxref:random-families-quantiles-and-sampling)で述べる二分法で、`LawOptions` の作業量を使う。
各族の数値上の注意は[基本の族の数値上の注意](oxref:random-families-other-numerics)にまとめた。

## まとめ

古典的な族は位置 0・尺度 1 の標準形で与えられ、位置と尺度は `Affine::new(law, μ, σ)` で加える。
母数が定義域の外ならコンストラクターが `DomainError` を返すので、表の定義域の列で引数の範囲を確かめてから分布を作る。
平均と分散は族と母数によって存在が決まり、存在しないときは理由 `Undefined` の `DomainError` になり、`Alpha` など 5 つの族はそもそも `Mean` と `Variance` を実装しない。
`ExponentialPower`、`JohnsonSB` など分位点の求積でモーメントを求める族の平均と分散は、`LawOptions` の許容誤差の範囲で求めた推定値として扱う。
`Entropy` が要るときは、ここの族では `Uniform` だけが直接返す。
