計数の分布は整数を返すので、標本化で浮動小数点の値を丸めて整数にすると、確率質量がずれた標本になる。
このページは、`scioxide-random` が整数の標本をどう作るか、二項分布と Poisson 分布で方法をどう切り替えるか、ほかの計数の分布と重み付きの添字の抽出（エイリアス法）をどう生成するかを説明する。
Poisson 二項分布、Boltzmann 分布、非心超幾何分布のように台が有限で表を作って扱う分布は[有限の台を持つ計数の分布](../finite-support-count-laws/)で、多変量正規分布などベクトル値の分布は[多変量・行列・群の確率分布](../multivariate-and-matrix-laws/)で扱う。
棄却とワードの上限は[棄却と作業量の上限](oxref:random-algorithms-rejection-limits)にまとめてある。

## 整数の標本と CountDistribution

計数の分布は `CountDistribution` を通じて標本を作る。
標本の型は非負の計数なら `usize`、`Skellam`、`DiscreteLaplace`、`DiscreteUniform` のような符号付きの計数なら `i64` である。
形は `sample`（一つ）、`sample_n`（所有した出力）、`sample_n_into`（呼び出し側の出力、`SamplingPolicy`、作業領域）の三つである。
標本化は分布のスカラー型に関係なく整数の一様乱数ワード（`next_uniform_u64`、幅が $2^{32}$ 以下の一様な整数の選択では `next_uniform_u32`）から作るので、母数が同じ値でシードが同じなら `f32` と `f64` の分布が同じ標本を返す。
表せない計数は切り詰めず、`NotImplemented` などのエラーにする。
確率質量と分布関数は `Mass`、`Cdf`、`Survival` で、引数は正確な整数であり、`cdf(k)` は $k$ の原子を含み、`sf(k)` は含まない。

準備に定数の計算が要る分布だけが、別の標本化器を持つ。
`Binomial::prepare_sampler` は `BinomialSampler` を、`Poisson::prepare_sampler` は `PoissonSampler` を、`Skellam::prepare_sampler` は二つの Poisson 標本化器の差 `SkellamSampler` を返す。
準備は乱数を読まず、メモリ領域も確保しない。
この三つの分布も `CountDistribution` を実装し、呼び出しのたびに標本化器を準備してから引くので、一つずつ引く繰り返しでは標本化器を一度だけ準備して使い回す。
ほかの計数の分布は構築時に準備を済ませ、自身が `CountDistribution` を実装する。

## 二項分布の三つの方法

$X \sim \mathrm{Binomial}(n, p)$ の標本化は、$p' = \min(p, 1 - p)$ で行い、$p > 1/2$ なら $n - X$ に反転する。
$n - X$ は $\mathrm{Binomial}(n, 1 - p)$ に従うので、反転しても分布は変わらない。
BINV の漸化式の安定性と BTPE の定数は $p \le 1/2$ を前提にしているので、どちらの方法も小さい方の確率で動かす。
方法は準備のときに一度だけ選ばれる。

| 条件 | 方法 | 一つの標本のワードの上限 |
|---|---|---|
| $n \le 16$ | Bernoulli 試行を $n$ 回直接行う | 272 |
| $n p' < 10$ | 逆変換（BINV） | 18 |
| それ以外 | BTPE（Kachitvichyanukul–Schmeiser の変換棄却法） | 2,048 |

BINV は確率質量を小さい $k$ から順に足し、和が一様乱数 $U$ を超えたところの $k$ を返す逆変換である。
最初に $P(X > 0) = 1 - (1 - p')^n$ の Bernoulli 試行で $X = 0$ かを決める。
$(1 - p')^n = \exp(n\ln(1 - p'))$ の対数は `ln_1p` で、$P(X > 0)$ は `expm1` で作るので、$np'$ が非常に小さくても $P(X > 0)$ が 0 に丸まらない。
$X > 0$ なら条件付きの確率 $P(X = 1 \mid X > 0)$ から始め、確率質量の比

$$
\frac{P(k+1)}{P(k)} = \frac{n - k}{k + 1}\cdot\frac{p'}{1 - p'}
$$

で次の項を作るので、階乗やべき乗をループの中で評価しない。
$X > 0$ のときの段数は $X$ そのものなので、期待される段数は平均 $np'$ に比例し、$np' < 10$ に限ると短い。

BTPE は最頻値のまわりの三角形、両側の平行四辺形、指数的に減る両側の裾からなる、確率質量を上から押さえる関数（包絡）で候補を作り、確率質量の比で受理する。
三角形の領域は確率質量の下にあるので、そこに落ちた候補は質量を評価せずに受理する。
それ以外の候補の受理の判定は最頻値の近く（距離 $d \le 20$）では隣り合う質量の比の積で行い、遠くでは Loader の Stirling 補正を含む対数の質量で行う。
正規近似による挟み込み（squeeze）の判定は、その評価が成り立つ範囲 $20 < d < npq/2 - 1$ でだけ使い、その外では対数の質量の比を直接比べる。
受理されるまでの候補は 1,024 個までで、それを超えるとエラーになる。
準備できるのは $n \le \min(\texttt{usize::MAX}, 2^{52} - 1)$ の非退化な分布で、それを超えると `NotImplemented` になる。

分位点 `quantile` は正規近似と Cornish–Fisher の補正で出発点を決め、倍々の拡大と二分法の離散探索で $\mathrm{CDF}(k) \ge p$ となる最小の $k$ を返す。
判定には分布自身の裾確率を使うので、近似は探索の出発点を決めるだけで、返す計数を決めることはない。

## Poisson 分布と Skellam 分布

`PoissonSampler` は率 $\lambda < 12$ では BINV と同じ形の逆変換を使う。
$P(X > 0) = 1 - e^{-\lambda}$ の Bernoulli 試行で 0 かどうかを先に決め、$X > 0$ なら $P(X = 1 \mid X > 0)$ から比 $P(k+1)/P(k) = \lambda/(k+1)$ で条件付きの分布関数を進める。
$\lambda \ge 12$ では Hörmann の PTRS（squeeze 付きの変換棄却法）を使う。
PTRS の包絡の定数は $\lambda \ge 10$ で有効なので、境界の 12 はその範囲に入る。
ワードの上限は逆変換で 18、PTRS で 2,048 で、率 0 ではワードを使わない。
逆変換の段数と棄却の候補はどちらも 1,024 で止まる。
`Poisson::new(lambda)` は既定の `LawOptions` を使い、`Poisson::with_options(lambda, options)` は設定を取る。
`prepare_sampler` は $\lambda > \min(\texttt{usize::MAX}/2, 2^{51})$ を `NotImplemented` で返し、標本化器の一括生成は分布の `max_bytes` の上限に従う。

`SkellamSampler` は二つの Poisson 標本の差 $X - Y$ を返し、二つの標本は分布の `sample_word_budget` を共有する。
差が `i64` に入らなければ `NotImplemented` になる。

## 符号付きの計数の分布

`Skellam`、`DiscreteLaplace`、`DiscreteUniform` は負の値も取る計数の分布で、標本と問い合わせの引数は `i64` である。
三つとも `Mass`、`LogMass`、`Cdf`、`Survival`、`LogCdf`、`LogSurvival`、`Quantile`、`InverseSurvival`、`Mean`、`Variance` を `i64` の計数について実装し、`cdf(k)` は $k$ の原子を含み、`sf(k)` は含まない。
三つとも分布自身が `CountDistribution` を実装し、`Skellam` は呼び出しのたびに `prepare_sampler()` で準備した `SkellamSampler` から標本を作る。
`Skellam` と `DiscreteLaplace` は、絶対値が $2^{53}$ を超える計数の問い合わせを `NotImplemented` で返す。

| 分布 | コンストラクター | 台 | 確率質量 | 平均 | 分散 |
|---|---|---|---|---|---|
| `Skellam` | `new(mu1, mu2)`、$\mu_1, \mu_2 \ge 0$ | $\mathbb{Z}$（片方の率が 0 なら片側、両方 0 なら $\{0\}$） | $e^{-(\mu_1 + \mu_2)}(\mu_1/\mu_2)^{k/2} I_{\lvert k \rvert}(2\sqrt{\mu_1\mu_2})$ | $\mu_1 - \mu_2$ | $\mu_1 + \mu_2$ |
| `DiscreteLaplace` | `new(a)`、$a > 0$ | $\mathbb{Z}$ | $\tanh(a/2)\,e^{-a\lvert k \rvert}$ | 0 | $2e^{-a}/(1 - e^{-a})^2$ |
| `DiscreteUniform` | `new(low, high)`、`low < high`（`i64`） | $\{\text{low}, \dots, \text{high} - 1\}$ | $1/w$、$w = \text{high} - \text{low}$ | $(\text{low} + \text{high} - 1)/2$ | $(w^2 - 1)/12$ |

どのコンストラクターも既定の `LawOptions` を使い、同じ母数の後に設定を取る `with_options` が精度と上限を変える。

`Skellam` は独立な $\mathrm{Poisson}(\mu_1)$ と $\mathrm{Poisson}(\mu_2)$ の差 $X - Y$ の分布で、$I_\nu$ は第 1 種の変形 Bessel 関数である。
確率質量は指数で尺度を付けた Bessel 関数 $e^{-x}I_{\lvert k \rvert}(x)$（$x = 2\sqrt{\mu_1\mu_2}$）で評価し、指数部を $-(\sqrt{\mu_1} - \sqrt{\mu_2})^2$ にまとめるので、大きな率でも桁あふれしない。
Bessel 関数の値が 0 に落ちる遠い裾では、Poisson 分布の畳み込み和に切り替える。
分布関数と上側確率は小さい方の率の Poisson 変数 $B$ について畳み込みを足す。
和は $B$ の最頻値から外へ向かって足し、まだ足していない $B$ の質量（残りの項の上界）が、それまでの和の相対許容誤差倍を下回ったところで止める。
片方の率が 0 なら Poisson 分布（またはその符号を反転したもの）、両方 0 なら 0 の点質量として正確に扱う。

`DiscreteLaplace` は $\mathbb{Z}$ 上の対称な離散指数分布で、正規化定数は $\sum_k e^{-a\lvert k \rvert} = (1 + e^{-a})/(1 - e^{-a})$ から $\tanh(a/2)$ になる。
0 から遠い側の裾は等比級数で、$k \ge 0$ では $P(K > k) = e^{-a(k+1)}/(1 + e^{-a})$、$k < 0$ では $P(K \le k) = e^{-a\lvert k \rvert}/(1 + e^{-a})$ の閉形式を対数で評価し、0 に近い側の裾はその補として作る。
数学的には独立な同じ幾何分布の二つの差に等しいが、実装はその構成を使わない。

`DiscreteUniform` の幅 $w$ は `u64` で表すので、`i64` の全範囲にわたる区間も扱える。
分布関数は整数の個数の比 $(k - \text{low} + 1)/w$ と補のうち小さい方を直接作り、補を引き算で作らない。
分位点は確率 $p$ の binary64 の仮数と指数を取り出し、$p \cdot w$ を 128 ビットの整数積で正確に求めて切り上げるので、$w > 2^{53}$ でも丸めで隣の整数に移らない。
確率質量は $-\ln w$ を binary64 で返すので、$w > 2^{53}$ では $w$ の丸めを含む。

標本の作り方は分布ごとに異なる。

- `SkellamSampler` は準備済みの二つの `PoissonSampler` で $X$ と $Y$ を引いて差を返し、二つの標本はワードの上限と作業量を共有する。
- `DiscreteLaplace` は開区間の一様乱数 $U$ に対して分布関数を逆に解き、閉形式の裾を使った倍々の拡大と二分法で整数を探す。
  探索の回数は `work_budget` で抑え、$\lvert k \rvert$ が大きいほど回数が増える。
- `DiscreteUniform` は Lemire の割り算をほとんど使わない棄却法で $[0, w)$ の一様な整数を作り、`low` を足す。
  $w \le 2^{32}$ では 32 ビットの一様乱数ワードを使い、浮動小数点の座標を丸めて作ることはしない。

`Skellam` と `DiscreteLaplace` の分位点 `quantile` と `isf` も、裾の値に対する同じ倍々の拡大と二分法で求め、`DiscreteUniform` の分位点だけが整数演算の閉形式である。

## その他の計数の分布

既定の標本化は開区間の一様乱数 $U$ について下側確率（$U > 1/2$ なら上側確率）を正確に逆に解く方法である。
台の上限が分かっている分布は $[\text{下限}, \text{上限}]$ を直接二分し、上限のない分布は倍々に広げた区間を二分する。
裾の評価と探索の回数は分布の `work_budget` に数える。
より安く正確に作れる分布は次の構成を使う。

| 分布 | 標本の作り方 |
|---|---|
| `Geometric` | $K = \lfloor \ln U / \ln q \rfloor + 1$（$\ln q$ は `ln_1p(-p)` で準備） |
| `NegativeBinomial` | $\Lambda \sim \mathrm{Gamma}(r, q/p)$ を対数 $\ln \Lambda$ で作り、$\mathrm{Poisson}(\Lambda)$ を引く。$\Lambda$ がアンダーフローすれば計数 0 |
| `BetaBinomial` | 試行数が 128 以下で $\min(\alpha, \beta) < 1$ または $\max(\alpha, \beta) > 1024$（U 字形と J 字形を含む）なら Pólya の逐次条件付き確率、それ以外は Beta の対数オッズから $p$ と $1 - p$ の小さい方を作って二項分布を引き、必要なら $n - X$ に反転する |
| `BetaNegativeBinomial` | Beta の対数オッズと Gamma–Poisson の対数の率を保って負の二項分布を引く |
| `LogSeries` | Kemp の二つの一様乱数による方法（LK） |
| `YuleSimon` | 成功確率 $e^{-E/\rho}$（$E \sim \mathrm{Exp}(1)$）の幾何分布 |
| `Zipf` | Devroye の棄却法（受理の判定は対数で評価） |
| `Zipfian` | メモリ領域が定数の rejection-inversion |
| `Hypergeometric` | Stadlober の HRUA（台全体を覆う包絡による一様比法）。抽出数と（母集団 − 抽出数）の小さい方が 10 未満なら一つずつ非復元で抽出する。メモリ領域は台の大きさによらない |

## 重み付きの添字とエイリアス法

`WeightedSampler::new(weights)` は、非負の重み $w_1, \dots, w_n$（少なくとも一つは正）から Walker–Vose の別名表を作る。
重みは最大値で割ってから補償付きの和で正規化し、$q_i = n w_i / \sum_j w_j$ とする。
$q_i$ の平均は丸めを除いて 1 で、最大値で割っておくので `f32::MAX` が並ぶような重みでも和が桁あふれしない。

表は各列 $i$ に保持確率 $F_i$ と別名 $A_i$ を一つずつ持たせる。
Vose の構成は $q_s < 1$ の列 $s$ と $q_l \ge 1$ の列 $l$ を組にし、$F_s = q_s$、$A_s = l$ と決めて、$l$ の残りを $q_l \leftarrow q_l - (1 - q_s)$ に減らす。
一回の組で一つの列が決まるので、構築は $O(n)$ の時間とメモリ領域である。
最後に残った列は丸めの誤差だけ 1 からずれているので、$F_i = 1$ として扱う。

一回の抽出は `uniform_index` で列 $i$ を一様に選び（$2^{32}$ 列以下なら 32 ビットの一様乱数ワード）、`next_float` で $u$ を一つ読んで、$u < F_i$ なら $i$、そうでなければ $A_i$ を返す。
添字 $j$ が返る確率は自分の列で保持される分と、$j$ を別名に持つ列からの分の和

$$
\frac{1}{n}\Bigl(F_j + \sum_{i : A_i = j}(1 - F_i)\Bigr) = \frac{q_j}{n} = \frac{w_j}{\sum_k w_k}
$$

になる。
期待時間は $O(1)$ で、メモリ領域は確保しない。
重み 0 の添字は保持確率が 0 で、どの列の別名にもならないので返らない。

## 正確に扱える計数の範囲

正確な計数演算の大きさの上限は $2^{53}$ で、符号付きの計数や整数の逆算も同じである。
例外は `DiscreteUniform` で、幅を `u64` で持ち、分位点を 128 ビットの整数積で求めるので、`i64` の全範囲を扱える。
連続値の候補を切り下げる二項分布の試行数と Poisson 分布の候補は、さらに $2^{52}$ 未満に制限する。
上限を超える計数は切り詰めず `NotImplemented` で返す。

```rust
use scioxide_core::RealScalar;
use scioxide_random::{
    Binomial, ChiSquared, CountDistribution, Mass, Quantile, SeedableRng, SplitMix64,
};

let n = trials.round() as usize;
let p = success_probability;
let m = draws.round() as usize;
let mf = m as f64;
let law = Binomial::new(n, p).map_err(|e| e.to_string())?;
let sampler = law.prepare_sampler().map_err(|e| e.to_string())?;
let mut rng = SplitMix64::from_seed(seed.round() as u64);
let samples = sampler.sample_n(&mut rng, m).map_err(|e| e.to_string())?;
let mut counts = vec![0.0_f64; n + 1];
for &k in &samples {
    counts[k] += 1.0;
}
let pmf = (0..=n)
    .map(|k| law.pmf(k))
    .collect::<Result<Vec<f64>, _>>()
    .map_err(|e| e.to_string())?;
// 期待度数 m·P(k) が 5 以上になるまで隣の k をまとめ、残りは最後の区間に入れる。
let (mut bins, mut expected, mut observed) = (Vec::new(), 0.0, 0.0);
for k in 0..=n {
    expected += mf * pmf[k];
    observed += counts[k];
    if expected >= 5.0 {
        bins.push((observed, expected));
        (expected, observed) = (0.0, 0.0);
    }
}
if let Some(last) = bins.last_mut() {
    (last.0, last.1) = (last.0 + observed, last.1 + expected);
}
let chi_square: f64 = bins.iter().map(|(o, e)| (o - e) * (o - e) / e).sum();
let df = bins.len().saturating_sub(1).max(1);
let reference = ChiSquared::new(df as f64).map_err(|e| e.to_string())?;
let low = reference.quantile(0.025).map_err(|e| e.to_string())?;
let high = reference.quantile(0.975).map_err(|e| e.to_string())?;
// 標本化器の準備と同じ規則を p' = min(p, 1 − p) と n に手で当てはめる。
let working = RealScalar::min(p, 1.0 - p);
let method = if n <= 16 {
    "直接"
} else if n as f64 * working < 10.0 {
    "BINV"
} else {
    "BTPE"
};
let mean = samples.iter().sum::<usize>() as f64 / mf;
let expected_mean = n as f64 * p;
let standard_error = RealScalar::sqrt(expected_mean * (1.0 - p) / mf);
let (mut band, mut theory, mut observed_points) = (Vec::new(), Vec::new(), Vec::new());
for k in 0..=n {
    let x = k as f64;
    let se = RealScalar::sqrt(pmf[k] * (1.0 - pmf[k]) / mf);
    band.push([x, pmf[k], pmf[k] - 2.0 * se, pmf[k] + 2.0 * se]);
    theory.push([x, pmf[k]]);
    observed_points.push([x, counts[k] / mf]);
}
emit_chart!(
    serde_json::json!({
        "kind": "xy",
        "xLabel": "成功回数 k [回]",
        "yLabel": "確率・相対度数 [-]",
        "dataZoom": true,
        "tooltip": true,
        "layers": [
            {"id": "band", "kind": "band", "name": "確率質量 ± 2 SE", "points": band},
            {
                "id": "pmf",
                "kind": "line",
                "name": "確率質量 pmf(k)",
                "style": {"lineType": "dashed", "step": "middle"},
                "points": theory
            },
            {"id": "sample", "kind": "scatter", "name": "標本の相対度数", "points": observed_points}
        ]
    }),
    metadata = serde_json::json!({ "id": "frequencies" })
);
let fixed4 = serde_json::json!({ "fractionDigits": 4 });
let fixed2 = serde_json::json!({ "fractionDigits": 2 });
let columns = serde_json::json!([
    { "key": "0", "label": "標本化の方法" },
    { "key": "1", "label": "標本平均 [回]", "type": "number", "format": fixed4 },
    { "key": "2", "label": "np [回]", "type": "number", "format": fixed4 },
    { "key": "3", "label": "z = (標本平均 − np)/SE [-]", "type": "number", "format": fixed2 },
    { "key": "4", "label": "Pearson の X² [-]", "type": "number", "format": fixed2 },
    { "key": "5", "label": "自由度", "type": "integer" },
    { "key": "6", "label": "X² の 2.5% 点 [-]", "type": "number", "format": fixed2 },
    { "key": "7", "label": "X² の 97.5% 点 [-]", "type": "number", "format": fixed2 }
]);
emit_table_with_columns!(
    columns,
    vec![(
        method,
        mean,
        expected_mean,
        (mean - expected_mean) / standard_error,
        chi_square,
        df,
        low,
        high
    )],
    metadata = serde_json::json!({ "id": "fit" })
);
```

相対度数は $\mathrm{pmf}(k)$ のまわりに標準誤差 $\sqrt{\mathrm{pmf}(k)(1 - \mathrm{pmf}(k))/m}$ 程度でばらつき、帯の外に出る点は一点あたり約 4.6% の割合で現れる。
既定の入力（$n = 40$、$p = 0.3$、$m = 10\,000$、シード 5）は BTPE を使い、$X^2 = 18.26$（自由度 19、2.5% 点と 97.5% 点は 8.91 と 32.85）、標本平均は $12.0612$ で、標準化した誤差は $2.11$ だった。
$|z| > 2$ となる確率は約 4.6% なので、この一回だけでは偏りの証拠にならない。
同じ設定でシードを 1 と 1000 に変えると、標準化した誤差は $1.18$ と $0.93$、$X^2$ は $19.75$ と $17.26$ になる。
$p = 0.02$ に下げると BINV、$n = 4$ にすると直接の方法に切り替わり、$X^2$ はそれぞれ $6.41$（自由度 5）と $2.10$（自由度 4）である。
$n = 200$、$p = 0.98$ では $p' = 0.02$ で $np' = 4 < 10$ となり、BINV で $n - X$ に反転した標本を作る（$X^2 = 9.45$、自由度 12）。
どれも統計的な確認なので、一つのシードで外れても、シードを変えて繰り返し外れるかで判断する。

## まとめ

計数の分布は `CountDistribution` の三つの形で整数の標本を作り、標本は分布のスカラー型によらず、表せない計数は切り詰めずにエラーにする。
二項分布は $n$ と $n\min(p, 1-p)$ で直接、BINV、BTPE を、Poisson 分布は率 12 を境に逆変換と PTRS を使い分け、それぞれ一つの標本のワード数に上限がある。
一つずつ引く繰り返しでは `prepare_sampler` で標本化器を一度だけ準備し、標本の検査は理論の確率質量と SE、または $X^2$ とその分位点で行う。
専用の構成を持たない計数の分布は分布関数の正確な逆算で標本を作るので、探索の回数を `work_budget` で見積もれる。
`WeightedSampler` は最大値で割って正規化した Walker–Vose の表で、一回の抽出を列の一様な選択と一回の比較で行う。
