最大値や高い閾値の超過量の分布は、元の分布の裾だけで決まる極限を持つことが多い。
このページはその極限の定理を条件とともに述べ、極限に現れる `GeneralizedExtremeValue` と `GeneralizedPareto`、裾の重さが冪で決まる分布（Pareto、Student t、Cauchy、安定分布）の定義と機能を説明する。
二つの極限の分布は形状母数の符号の決め方が逆なので、その対応を先に確かめる。
セルは極値指数から一般化極値分布を作り、標本、再現レベル、平均を閉形式と照合する。
閾値超過が一般化 Pareto 分布に近づく様子は[閾値超過と一般化 Pareto 近似](../threshold-exceedances/)で確かめる。

## 極値の極限定理

$X_1, X_2, \dots$ を分布関数 $F$ に従う独立な確率変数とし、$M_n = \max(X_1, \dots, X_n)$、$x_F = \sup\{x : F(x) < 1\}$（右端、無限大もありうる）とする。

Fisher–Tippett–Gnedenko の定理は次のとおりである。
定数 $a_n > 0$、$b_n$ があって $(M_n - b_n)/a_n$ の分布が退化しない分布 $G$ に収束するなら、$G$ は位置と尺度を除いて一般化極値分布

$$
G_\xi(x) = \exp\bigl(-(1 + \xi x)^{-1/\xi}\bigr), \qquad 1 + \xi x > 0
$$

である（$\xi = 0$ は極限 $\exp(-e^{-x})$）。
このとき $F$ は $G_\xi$ の吸引域にあるという。
どの $F$ にもこのような $a_n$、$b_n$ があるわけではない。
整数値の分布では、$(1 - F(n))/(1 - F(n - 1))$ が 1 に近づかない Poisson 分布や幾何分布は退化しない極限を持たない。
一方、裾が冪で減る整数値の分布（Zipf 分布など）は Fréchet 型の吸引域に入る。

Pickands–Balkema–de Haan の定理は、閾値 $u$ を超えた量 $X - u$ の条件付き分布を扱う。
$F$ が $G_\xi$ の吸引域にあることと、正の関数 $\sigma(u)$ があって

$$
\lim_{u \to x_F}\ \sup_{0 \le y < x_F - u} \Bigl\lvert P(X - u \le y \mid X > u) - H_\xi\bigl(y/\sigma(u)\bigr) \Bigr\rvert = 0, \qquad H_\xi(y) = 1 - (1 + \xi y)^{-1/\xi}
$$

が成り立つことは同値である。
$H_\xi$ は一般化 Pareto 分布で、尺度 $\sigma(u)$ は閾値とともに変わる。
閾値超過の極限に現れるのは一般化 Pareto 分布だけである。
`Pareto` の超過量はどの閾値でも一般化 Pareto 分布（$\xi = 1/b$、$\sigma(u) = u/b$）に一致し、`TruncatedPareto` は台が有界な別のモデルである。

極値指数 $\xi$ の符号で吸引域は 3 つに分かれる。
緩変動関数 $L$ は任意の $t > 0$ で $L(tx)/L(x) \to 1$（$x \to \infty$）となる関数である。

| 型 | $\xi$ | 元の分布の裾 | 例 |
|---|---|---|---|
| Fréchet 型 | $\xi > 0$ | $1 - F(x) = x^{-1/\xi}L(x)$。$r$ 次モーメントは $r < 1/\xi$ でだけ有限 | Pareto（$\xi = 1/b$）、Student t（$\xi = 1/\nu$）、Cauchy（$\xi = 1$）、$\alpha < 2$、$\beta > -1$ の安定分布の右裾（$\xi = 1/\alpha$）、`InverseWeibull`（$\xi = 1/c$） |
| Gumbel 型 | $\xi = 0$ | どの冪よりも速く減る裾（右端は有限でも無限でもよい） | 正規、指数、ガンマ、対数正規、`WeibullMin` |
| Weibull 型 | $\xi < 0$ | 有限の右端 $x_F$ を持ち、$1 - F(x_F - 1/t) = t^{1/\xi}L(t)$ | 一様（$\xi = -1$）、ベータ |

`InverseWeibull`（$F(x) = \exp(-x^{-c})$）の定義と機能は[族の定義と台](oxref:random-families-definitions)にある。

## 形状母数の符号の規約

`GeneralizedExtremeValue::new(c)` の形状母数は $c = -\xi$ である。
分布関数は

$$
F(x) = \exp\bigl(-(1 - cx)^{1/c}\bigr), \qquad 1 - cx > 0
$$

で、$c > 0$（Weibull 型）の台は $(-\infty, 1/c]$、$c < 0$（Fréchet 型）の台は $[1/c, \infty)$、$c = 0$ は `GumbelRight` と同じ分布である。
`GeneralizedPareto::new(c)` は $c = \xi$ の符号を使い、上側確率は $S(x) = (1 + cx)^{-1/c}$ である。
Fréchet 型の重い裾は `GeneralizedExtremeValue` では $c < 0$、`GeneralizedPareto` では $c > 0$ で表す。

| 極値指数 | `GeneralizedExtremeValue::new` に渡す値 | `GeneralizedPareto::new` に渡す値 |
|---|---|---|
| $\xi = 0.3$（Fréchet 型） | $-0.3$ | $0.3$ |
| $\xi = 0$（Gumbel 型） | $0$ | $0$（単位指数分布） |
| $\xi = -0.3$（Weibull 型） | $0.3$（台の上端 $1/0.3$） | $-0.3$（台の上端 $1/0.3$） |

## 分布の定義と機能

`Cauchy` は位置と尺度をコンストラクターで受け取り、ほかの分布は位置 0・尺度 1 の標準形なので、位置と尺度は `Affine::new(law, μ, σ)` で加える。
表で `with_options` を併記した分布は、`new` が既定の `LawOptions` を使い、`with_options` が母数の後に設定を取る。

| コンストラクター | 母数の定義域 | 台 | 定義 |
|---|---|---|---|
| `GeneralizedExtremeValue::new(c)` | $c$ は有限で、$c \ne 0$ では $1/c$ が表せる | $c > 0$ で $(-\infty, 1/c]$、$c < 0$ で $[1/c, \infty)$ | $F(x) = \exp\bigl(-(1 - cx)^{1/c}\bigr)$ |
| `GumbelRight::new()` | なし | $\mathbb{R}$ | $F(x) = \exp(-e^{-x})$。左に歪んだ Gumbel は `Affine::new(law, 0.0, -1.0)` |
| `GeneralizedPareto::new(c)` | $c$ は有限（$c < 0$ では $-1/c$ が表せる） | $c \ge 0$ で $[0, \infty)$、$c < 0$ で $[0, -1/c]$ | $S(x) = (1 + cx)^{-1/c}$、$c = 0$ は $e^{-x}$ |
| `Pareto::new(b)` | $b > 0$ | $[1, \infty)$ | $S(x) = x^{-b}$。`Affine::new(law, -1.0, 1.0)` は Lomax 分布 |
| `TruncatedPareto::new(b, c)` | $b \ne 0$ は有限、$c > 1$、$\lvert b \rvert \ln c$ が表せる | $[1, c]$ | $f(x) \propto x^{-b-1}$、$F(x) = (1 - x^{-b})/(1 - c^{-b})$ |
| `StudentT::new(nu)`（`with_options`） | $\nu > 0$ | $\mathbb{R}$ | 自由度 $\nu$ の $t$ 分布。裾の確率は $\lvert x \rvert^{-\nu}$ に比例して減る |
| `Cauchy::new(location, scale)` | 位置は有限、尺度 $> 0$ | $\mathbb{R}$ | $f(x) = 1/\bigl(\pi s(1 + ((x - \ell)/s)^2)\bigr)$ |
| `Kappa4::new(h, k)`（`with_options`） | $h$、$k$ は有限で、有限の台の端点が浮動小数点数で表せる | $k > 0$ で上端 $1/k$。下端は $h > 0$ で $(1 - h^{-k})/k$（$k = 0$ で $\ln h$）、$h \le 0$ かつ $k < 0$ で $1/k$ | $F(x) = \bigl(1 - h(1 - kx)^{1/k}\bigr)^{1/h}$。$h = 0$ は `GeneralizedExtremeValue::new(k)`、$h = 1$ は `GeneralizedPareto::new(-k)` |
| `Gompertz::new(shape)`（`with_options`） | $c > 0$ | $[0, \infty)$ | $S(x) = \exp\bigl(-c(e^x - 1)\bigr)$。左に歪んだ Gumbel を $x \ge 0$ に条件付けた分布 |
| `LevyStable::new(alpha, beta)`（`with_options`） | $0 < \alpha \le 2$、$\lvert\beta\rvert \le 1$ | $\mathbb{R}$（$\alpha < 1$、$\lvert\beta\rvert = 1$ では半直線） | Nolan の S1 の母数化の安定分布。$\alpha < 2$ では、右裾は $\beta > -1$、左裾は $\beta < 1$ のとき確率が $\lvert x \rvert^{-\alpha}$ に比例して減る。$\beta = \pm 1$ の反対側の裾は、$\alpha < 1$ では台の端、$1 \le \alpha < 2$ ではどの冪よりも速く減る |

`TruncatedPareto` は $[1, c]$ に制限した冪の密度で、$b < -1$ では密度が右上がりになる。
台が有界な冪則のモデルで、観測の上限が分かっているときに使う。
`Kappa4` は Hosking の 4 母数 kappa 分布の標準形で、一般化極値分布、一般化 Pareto 分布、一般化ロジスティック分布（$h = -1$）を一つの式に含む。
`Gompertz` は寿命の分布で、最小値の極限である左に歪んだ Gumbel 分布 $S(x) = \exp(-e^{x - \mu})$ を $x \ge 0$ に制限し、$c = e^{-\mu}$ と置いたものである。
`LevyStable` の $\alpha = 2$ は分散 2 の正規分布、$(\alpha, \beta) = (1, 0)$ は標準 Cauchy 分布である。

次の表の「分位点の求積」は $\mathrm{E}[X^r] = \int_0^1 Q(u)^r\,du$ を `LawOptions` の許容誤差と作業量の中で求積する方法で、`Kappa4` は $F(0)$ で積分を二つに分けて符号を扱う。

| 分布 | 平均 | 分散 | 標本化 | 分位点 |
|---|---|---|---|---|
| `GeneralizedExtremeValue` | $c > -1$：$(1 - \Gamma(1 + c))/c$（$c = 0$ で $\gamma_{\mathrm{E}}$） | $c > -1/2$：$\bigl(\Gamma(1 + 2c) - \Gamma(1 + c)^2\bigr)/c^2$ | 逆関数法 | 閉形式 |
| `GumbelRight` | $\gamma_{\mathrm{E}}$ | $\pi^2/6$ | $-\ln(-\ln U)$ | 閉形式 |
| `GeneralizedPareto` | $c < 1$：$1/(1 - c)$ | $c < 1/2$：$1/\bigl((1 - c)^2(1 - 2c)\bigr)$ | 逆関数法 | 閉形式 |
| `Pareto` | $b > 1$：$b/(b - 1)$ | $b > 2$：$b/\bigl((b - 1)^2(b - 2)\bigr)$ | $e^{E/b}$（$E$ は標準指数） | 閉形式 |
| `TruncatedPareto` | 実装しない | 実装しない | 逆関数法 | 閉形式 |
| `StudentT` | $\nu > 1$：0 | $\nu > 2$：$\nu/(\nu - 2)$ | $Z/\sqrt{\chi^2_\nu/\nu}$ | 不完全ベータ関数の逆。$\nu \ge 10^6$ では $\nu^{-4}$ までの Cornish–Fisher 展開 |
| `Cauchy` | 実装しない | 実装しない | 逆関数法 | 閉形式 |
| `Kappa4` | 分位点の求積。$k < 0$ では $r < -1/k$、$h < 0 < k$ では $r < -1/(hk)$ の次数だけ存在 | 同左 | 逆関数法 | 閉形式 |
| `Gompertz` | 分位点の求積 | 同左 | 逆関数法 | 閉形式 $\ln\bigl(1 - \ln(1 - p)/c\bigr)$ |
| `LevyStable` | $\alpha > 1$：0 | $\alpha = 2$：2 | Chambers–Mallows–Stuck 法。$\alpha = 2$、$(1, 0)$、$(1/2, \pm 1)$ は正規・Cauchy・逆ガンマの変量 | $\alpha = 2$、$(\alpha, \beta) = (1, 0)$、$(1/2, \pm 1)$（Lévy）は閉形式、$\beta = 0$ の中央値の近く（$\lvert p - 1/2 \rvert < 10^{-3}$ で、省いた項の相対的な上界が相対許容誤差の 1/16 より小さいとき）は 1 次の展開。ほかは Brent 法による数値逆算 |

逆関数法は開区間 $(0, 1)$ の一様乱数 $U$ を分位点関数で写す。
母数の範囲外の平均や分散は、理由 `Undefined` の `DomainError` になる。
`Cauchy` と `TruncatedPareto` は `Mean` と `Variance` を実装しないので、呼び出すコードはコンパイルできない。
Student t と Cauchy のモーメントの扱いは[連続分布の変換・棄却・裾野制御](oxref:random-continuous-heavy-tails)にもある。

## 裾と分位点の数値計算

一般化極値分布の分布関数は $t(x) = (1 - cx)^{1/c}$ を対数 $\ln t = \ln(1 - cx)/c$ で作り、$\ln(1 - cx)$ を `ln_1p` で評価する。
$c \to 0$ でも $\ln(1 - cx)/c \to -x$ に連続につながるので、$c = 0$ ちょうど以外で Gumbel の式に切り替える必要がない。
上側確率 $S = 1 - e^{-t}$ は $\ln t < \ln\varepsilon$ のとき $\ln S \approx \ln t$ とし、それ以外は $\ln(1 - e^{-t})$ を補数の式で評価する。

分位点は $\ell = \ln(-\ln p)$ として

$$
Q(p) = \frac{1 - (-\ln p)^{c}}{c} = -\ell\,\frac{e^{c\ell} - 1}{c\ell}
$$

を `exp_m1` で評価し、$c\ell = 0$ では $-\ell$ を返す。
上側確率 $q$ からの逆算（`isf`）は $-\ln p$ を $-\ln(1 - q)$ として `ln_1p` で作り、$1 - q$ の丸めを避ける。
一般化 Pareto 分布も同じ形で、$\ln S(x) = -\ln(1 + cx)/c$ と $Q(p) = \bigl((1 - p)^{-c} - 1\bigr)/c$ を `ln_1p` と `exp_m1` で評価する。
`Kappa4` も $t = (1 - kx)^{1/k}$ と $(1 - ht)^{1/h}$ を `ln_1p` と `exp_m1` で評価し、$h$ や $k$ が 0 に近づいても $h = 0$、$k = 0$ の極限の式に連続につながる。
`Gompertz` は $e^x - 1$ を `exp_m1` で作り、小さな $x$ の裾を保つ。

一般化極値分布の平均 $(1 - \Gamma(1 + c))/c$ は $\ln\Gamma(1 + c)$ を作ってから $-\operatorname{expm1}(\ln\Gamma(1 + c))/c$ で評価する。
$\lvert c \rvert \le 1/8$ では $\ln\Gamma(1 + c) = c\int_0^1 \psi(1 + ct)\,dt$（$\psi$ は digamma 関数）を求積で求めるので、$\Gamma(1 + c) - 1$ を引き算で作らない。
$\lvert c \rvert < \sqrt{\varepsilon}$ では 1 次の展開 $\gamma_{\mathrm{E}} - (\gamma_{\mathrm{E}}^2/2 + \pi^2/12)\,c$ を返す。
分散は $\Gamma(1 + c)^2\bigl(e^{\Delta} - 1\bigr)/c^2$、$\Delta = \ln\Gamma(1 + 2c) - 2\ln\Gamma(1 + c)$ と書き直し、$\lvert c \rvert \le 1/8$ では二階差分 $\Delta = c^2\int_0^1\int_0^1 \psi'(1 + c(s + t))\,ds\,dt$（$\psi'$ は trigamma 関数）を正の被積分関数の求積で求める。
どちらも近い二つの数の引き算をしないので、$c$ が 0 に近くても相対精度を保つ。

再現期間 $T$ の再現レベル $z_T$ は、1 期間の最大値が $z_T$ を超える確率が $1/T$ となる点で、$z_T = Q(1 - 1/T)$ である。
極値指数で書くと、標準の一般化極値分布の再現レベルは

$$
z_T = \frac{\bigl(-\ln(1 - 1/T)\bigr)^{-\xi} - 1}{\xi}
$$

で、$\xi \to 0$ では $-\ln(-\ln(1 - 1/T))$ になる。
`isf(1/T)` はこの値を上側確率から直接求める。

```rust
let low = x.iter().fold(f64::INFINITY, |a, &v| RealScalar::min(a, v));
let high = x
    .iter()
    .fold(f64::NEG_INFINITY, |a, &v| RealScalar::max(a, v));
// 再現レベル: API は上側確率 0.01 から直接、独立検算は ξ で書いた閉形式。
let z100 = law.isf(0.01).map_err(|e| e.to_string())?;
let y = -RealScalar::ln_1p(-0.01);
let by_hand = if xi == 0.0 {
    -RealScalar::ln(y)
} else {
    RealScalar::exp_m1(-xi * RealScalar::ln(y)) / xi
};
let mut rows = vec![("コンストラクターに渡した c", c)];
if c != 0.0 {
    rows.push(("台の有限な端点 1/c", 1.0 / c));
}
rows.push(("標本の最小値", low));
rows.push(("標本の最大値", high));
rows.push(("z₁₀₀ = isf(0.01)", z100));
rows.push(("z₁₀₀ − 閉形式", z100 - by_hand));
let columns = serde_json::json!([
    { "key": "0", "label": "量" },
    { "key": "1", "label": "値 [-]", "type": "number", "format": sig6 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "support" })
);
// 平均: 閉形式 (Γ(1 − ξ) − 1)/ξ（ξ = 0 で Euler 定数）と標本平均の CI。
let exact = if xi == 0.0 {
    0.577_215_664_901_532_9
} else {
    (scioxide_special::gamma(1.0 - xi).map_err(|e| e.to_string())? - 1.0) / xi
};
let nf = n as f64;
let mean = x.iter().sum::<f64>() / nf;
let var = x
    .iter()
    .map(|&v| RealScalar::powi(v - mean, 2))
    .sum::<f64>()
    / (nf - 1.0);
let (se, z) = (
    RealScalar::sqrt(var / nf),
    (mean - exact) / RealScalar::sqrt(var / nf),
);
let columns = serde_json::json!([
    { "key": "0", "label": "閉形式の平均 [-]", "type": "number", "format": sig6 },
    { "key": "1", "label": "標本平均 [-]", "type": "number", "format": sig6 },
    { "key": "2", "label": "95% CI 下限 [-]", "type": "number", "format": sig6 },
    { "key": "3", "label": "95% CI 上限 [-]", "type": "number", "format": sig6 },
    { "key": "4", "label": "z [-]", "type": "number", "format": fixed2 }
]);
emit_table_with_columns!(
    columns,
    vec![(exact, mean, mean - 1.96 * se, mean + 1.96 * se, z)],
    metadata = serde_json::json!({ "id": "mean" })
);
```

既定の入力（$\xi = 0.3$、$n = 3\,000$、シード 101）では、コンストラクターに $c = -0.3$ を渡し、台の下端は $1/c = -3.333$ である。
標本の最小値は $-1.668$、最大値は $34.57$ で、Fréchet 型の重い右裾が現れる。
再現レベルは `isf(0.01)` で $z_{100} = 9.9169$ で、閉形式との差は $1.8 \times 10^{-15}$（1 ulp）である。
平均の閉形式 $(\Gamma(0.7) - 1)/0.3 = 0.99352$ に対して標本平均は 0.99221（$z = -0.03$）である。

$\xi = -0.3$ ではコンストラクターに $c = 0.3$ を渡し、台の上端は $1/c = 3.333$、標本の最大値は $3.040$ で上端を超えない。
極値指数 $\xi = 0.3$ のつもりで `new(0.3)` を呼ぶとこの Weibull 型の分布ができ、$z_{100}$ は $9.9169$ ではなく $2.4948$ になる。
$\xi = 0$ では端点の行がなくなり、$z_{100} = -\ln(-\ln 0.99) = 4.6001$、平均は $\gamma_{\mathrm{E}} = 0.57722$ に対して標本平均 0.58043（$z = 0.14$）である。
$\xi = 0.4$、$n = 10\,000$ では標本の最大値が $109.3$ まで伸び、標本平均 1.16815 は閉形式 1.22298 と $z = -1.77$ だけ離れる。
裾が重いほど標本平均は少数の大きな値に左右され、$z$ の分布は正規分布より裾が重くなる。

## まとめ

Fisher–Tippett–Gnedenko の定理は、正規化した最大値に退化しない極限があるとき、その形を一般化極値分布に限る。
Pickands–Balkema–de Haan の定理は、同じ条件のもとで閾値超過の極限を尺度 $\sigma(u)$ の一般化 Pareto 分布に限る。
`GeneralizedExtremeValue::new(c)` は $c = -\xi$、`GeneralizedPareto::new(c)` は $c = \xi$ なので、極値指数から分布を作るときは符号を変えて渡し、台の端点で規約を確かめる。
再現レベルは `isf(1/T)` で上側確率から直接求め、閉形式と丸めの範囲で一致する。
一般化極値分布と一般化 Pareto 分布の平均と分散は $\xi < 1$、$\xi < 1/2$ のときだけ存在して範囲外は `DomainError` になり、`Cauchy` と `TruncatedPareto` は `Mean` と `Variance` を実装しないので、標本は分位点や再現レベルで点検する。
