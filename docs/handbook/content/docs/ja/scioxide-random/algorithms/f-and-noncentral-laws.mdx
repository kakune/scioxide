分散分析と回帰の F 検定は、帰無仮説のもとで F 分布に従う統計量を使う。
対立仮説のもとでは、平均のずれを非心度として持つ非心分布が現れ、その裾が検出力になる。
このページは F 分布と非心分布の評価のアルゴリズムを説明し、一元配置分散分析の検出力を独立な二つの方法と照合する。
最後に、データから検定を行う `scioxide-stats` がこれらの分布をどう使うかと、`scioxide-random` が提供しない帰無分布をまとめる。
分布に共通の仕様と裾のレポート `TestStatisticResult` は[検定統計量の分布一覧と数理仕様](oxref:random-tests-contracts)にある。

## F 分布と非心分布

`FisherF` は $F = (U_1/d_1)/(U_2/d_2)$（$U_i \sim \chi^2_{d_i}$ は独立）の分布である。
$z = d_1x/(d_1x + d_2)$ とおくと $P(F \le x) = I_z(d_1/2, d_2/2)$（正則化不完全ベータ関数）なので、$\ln z$ と $\ln(1 - z)$ を $\ln(d_1x/d_2)$ の softplus $\ln(1 + e^{y})$ から作り、上側確率は反転したベータ $I_{1-z}(d_2/2, d_1/2)$ で求める。
どちらの側も $1 - (\text{1 に近い数})$ を作らない。
分位点は小さい側の裾の不完全ベータ関数を逆に解き、標本は二つのカイ二乗変量の比を対数で作る。

非心分布は、平均がずれた正規変量から作る統計量の対立仮説のもとでの分布である。
非心度は平均のずれの大きさで、尺度の母数ではない。

- `NoncentralChiSquared::new(ν, λ)` は $\sum_{i=1}^{\nu}(Z_i + \mu_i)^2$（$\lambda = \sum \mu_i^2 \ge 0$）の分布で、$J \sim \mathrm{Poisson}(\lambda/2)$ を混ぜた $\chi^2_{\nu + 2J}$ に等しい。
  平均は $\nu + \lambda$、分散は $2(\nu + 2\lambda)$ である。
  裾は Benton–Krishnamoorthy の漸化式で一つの不完全ガンマ関数から各項を作り、重み付きの項が最大になる $j$ から両側へ正の項だけを足す。
  項は $j$ について対数凹なので、残りを等比級数で抑え、その上界が許容誤差を下回ったところで止める。
  分位点は最初の三つのキュムラントを合わせた Pearson（1959）の近似から始め、小さい側の対数の裾に安全化した Newton 法を対数座標で使う。
  標本は $\nu > 1$ なら $(Z + \sqrt{\lambda})^2 + \chi^2_{\nu-1}$、$\nu \le 1$ なら Poisson 混合で作る。
- `NoncentralF::new(d₁, d₂, λ)` は分子だけが非心の F で、裾は不完全ベータ $I_z(d_1/2 + j, d_2/2)$ の Poisson 混合を同じ漸化式で足す。
  分位点は分子を Patnaik の二次モーメントを合わせた尺度付きカイ二乗で近似した F から始める。
- `NoncentralStudentT::new(ν, δ)` は $(Z + \delta)/\sqrt{U/\nu}$（$U \sim \chi^2_\nu$）の分布で、$t < 0$ は $T(\delta) = -T(-\delta)$ で $t \ge 0$ へ反転してから Benton–Krishnamoorthy のベータ級数を使う。
  負の非心度や遠い裾のように、級数の差を取ると許容誤差を失う場合は、$P(T \le x) = \mathbb{E}_S[\Phi(xS - \delta)]$ をカイ尺度で積分する。
  分位点はモーメントを合わせた正規（分散がなければずらした t）から始め、$\operatorname{asinh}$ 座標で Newton 法を使う。

どの非心分布も非心度 0 では中心の分布による評価をそのまま使う。

## 分散分析の検出力

$k$ 群、各群 $n$ 個の一元配置分散分析で、群の平均 $\mu_i$ と共通の分散 $\sigma^2$ を考える。
F 統計量は帰無仮説（全平均が等しい）のもとで $F(d_1, d_2)$、$d_1 = k - 1$、$d_2 = k(n - 1)$ に従う。
対立仮説のもとでは非心度 $\lambda = n\sum_i(\mu_i - \bar\mu)^2/\sigma^2 = kn f^2$ の非心 F に従い、$f = \sqrt{\sum_i(\mu_i - \bar\mu)^2/k}/\sigma$ は Cohen の効果量である。
水準 $\alpha$ の臨界値 $c$（$P(F > c) = \alpha$）に対して、検出力は $P(F' > c)$ である。

次のセルは `FisherF::isf` で臨界値を求め、`NoncentralF::evaluate_tail` で検出力とその推定誤差を出す。
独立検算は二つある。
一つは Poisson 混合 $P(F' > c) = \sum_j e^{-\lambda/2}(\lambda/2)^j/j!\;P\bigl(F(d_1 + 2j, d_2) > c\,d_1/(d_1 + 2j)\bigr)$ を中心の `FisherF` の和で直接足した値である（項は $j \le \lambda/2 + 10\sqrt{\lambda/2} + 20$ まで）。
もう一つは、効果量 $f$ に合わせて等間隔に置いた群の平均から正規の観測を作り、F 統計量が臨界値を超えた割合を数える Monte Carlo 法で、二項分布の標準誤差 $\sqrt{p(1 - p)/R}$（$p$ は理論の検出力、$R$ は反復回数）で割った $z$ を出す。
$f = 0$ では検出力が $\alpha$ に等しく、Monte Carlo の割合は第一種の誤りの確率を表す。

```rust
//| id: random-anova-power
//| ref: random-anova-power
//| title: 一元配置分散分析の検出力を非心 F 分布で求め、Poisson 混合と Monte Carlo で照合する
//| run: reactive
//| crates: [scioxide-random, scioxide-core]
//| inputs:
//|   groups: {"type":"range","label":"群の数 k [個]","min":2,"max":8,"step":1,"value":4}
//|   per_group: {"type":"range","label":"各群の標本数 n [個]","min":3,"max":40,"step":1,"value":10}
//|   effect: {"type":"range","label":"効果量 f [-]","description":"群平均の標準偏差を誤差の標準偏差で割った値。0.1 が小、0.25 が中、0.4 が大の目安。","min":0,"max":0.6,"step":0.05,"value":0.25}
//|   level: {"type":"select","label":"有意水準 α","options":["0.05","0.01"],"value":"0.05"}
//|   replications: {"type":"range","label":"Monte Carlo の反復回数 R [回]","min":500,"max":4000,"step":500,"value":2000}
//|   seed: {"type":"range","label":"乱数のシード","min":1,"max":1000,"step":1,"value":3}
//| cases:
//|   - {"id":"no-effect","label":"f = 0","description":"帰無仮説のもとでは検出力が α に等しい。","inputs":{"effect":0}}
//|   - {"id":"large-design","label":"k = 3、n = 40、f = 0.4","description":"大きな効果と標本で検出力が 1 に近づく。","inputs":{"groups":3,"per_group":40,"effect":0.4}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"power","path":"/rows/0/2","approx":{"value":2.5,"atol":1e-12}}
//|       - {"artifact":"power","path":"/rows/0/7","range":{"min":-1e-9,"max":1e-9}}
//|       - {"artifact":"simulation","path":"/rows/0/4","range":{"min":-4,"max":4}}
//|   - case: no-effect
//|     expect:
//|       - {"artifact":"power","path":"/rows/0/4","approx":{"value":0.05,"atol":1e-9}}
//|       - {"artifact":"simulation","path":"/rows/0/4","range":{"min":-4,"max":4}}
//|   - case: large-design
//|     expect:
//|       - {"artifact":"power","path":"/rows/0/7","range":{"min":-1e-9,"max":1e-9}}
//|       - {"artifact":"simulation","path":"/rows/0/4","range":{"min":-4,"max":4}}
use scioxide_core::RealScalar;
use scioxide_random::{
    Distribution, FisherF, InverseSurvival, NoncentralF, Normal, SeedableRng, SplitMix64,
    Survival,
};

let sig5 = serde_json::json!({ "significantDigits": 5 });
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let fixed2 = serde_json::json!({ "fractionDigits": 2 });
let (k, n) = (groups.round() as usize, per_group.round() as usize);
let alpha: f64 = level
    .parse()
    .map_err(|e: std::num::ParseFloatError| e.to_string())?;
// 自由度と非心度 λ = k n f²。
let (d1, d2) = ((k - 1) as f64, (k * (n - 1)) as f64);
let lambda = (k * n) as f64 * effect * effect;
let critical = FisherF::new(d1, d2)
    .map_err(|e| e.to_string())?
    .isf(alpha)
    .map_err(|e| e.to_string())?;
let alternative = NoncentralF::new(d1, d2, lambda).map_err(|e| e.to_string())?;
let tail = alternative
    .evaluate_tail(critical, true)
    .map_err(|e| e.to_string())?;
let power = RealScalar::exp(tail.log_probability);
// 独立検算 1: Poisson(λ/2) の重みで中心 F の裾を直接足す。
let half = 0.5 * lambda;
let terms = (half + 10.0 * RealScalar::sqrt(half) + 20.0) as usize;
let (mut weight, mut mixture) = (RealScalar::exp(-half), 0.0);
for j in 0..=terms {
    let a = d1 + 2.0 * j as f64;
    let central = FisherF::new(a, d2).map_err(|e| e.to_string())?;
    mixture += weight * central.sf(critical * d1 / a).map_err(|e| e.to_string())?;
    weight *= half / (j as f64 + 1.0);
}
let columns = serde_json::json!([
    { "key": "0", "label": "d₁", "type": "number" },
    { "key": "1", "label": "d₂", "type": "number" },
    { "key": "2", "label": "非心度 λ [-]", "type": "number", "format": sig5 },
    { "key": "3", "label": "臨界値 c [-]", "type": "number", "format": sig5 },
    { "key": "4", "label": "検出力 P(F′ > c) [-]", "type": "number", "format": sig5 },
    { "key": "5", "label": "推定絶対誤差 [-]", "type": "number", "format": sci2 },
    { "key": "6", "label": "評価回数", "type": "integer" },
    { "key": "7", "label": "Poisson 混合 − 検出力 [-]", "type": "number", "format": sci2 }
]);
let row = (
    d1,
    d2,
    lambda,
    critical,
    power,
    tail.absolute_error,
    tail.evaluations,
    mixture - power,
);
emit_table_with_columns!(
    columns,
    vec![row],
    metadata = serde_json::json!({ "id": "power" })
);
// 独立検算 2: 群平均を等間隔に置き、√(Σ(μᵢ − μ̄)²/k) = f にして観測を作る。
let centre = 0.5 * (k as f64 + 1.0);
let spread = (1..=k)
    .map(|i| RealScalar::powi(i as f64 - centre, 2))
    .sum::<f64>();
let scale = effect / RealScalar::sqrt(spread / k as f64);
let normal = Normal::new(0.0, 1.0).map_err(|e| e.to_string())?;
let mut rng = SplitMix64::from_seed(seed as u64);
let (mut rejected, mut values, mut means) = (0_usize, vec![0.0; n], vec![0.0; k]);
for _ in 0..replications as usize {
    let mut within = 0.0;
    for (i, mean) in means.iter_mut().enumerate() {
        let shift = scale * ((i + 1) as f64 - centre);
        for value in values.iter_mut() {
            *value = shift + normal.sample(&mut rng).map_err(|e| e.to_string())?;
        }
        *mean = values.iter().sum::<f64>() / n as f64;
        within += values
            .iter()
            .map(|y| RealScalar::powi(y - *mean, 2))
            .sum::<f64>();
    }
    let grand = means.iter().sum::<f64>() / k as f64;
    let between = n as f64
        * means
            .iter()
            .map(|m| RealScalar::powi(m - grand, 2))
            .sum::<f64>();
    if (between / d1) / (within / d2) > critical {
        rejected += 1;
    }
}
let r = replications.round();
let rate = rejected as f64 / r;
let se = RealScalar::sqrt(power * (1.0 - power) / r);
let columns = serde_json::json!([
    { "key": "0", "label": "棄却した回数", "type": "integer" },
    { "key": "1", "label": "反復回数 R", "type": "integer" },
    { "key": "2", "label": "棄却の割合 [-]", "type": "number", "format": sig5 },
    { "key": "3", "label": "標準誤差 [-]", "type": "number", "format": sig5 },
    { "key": "4", "label": "z [-]", "type": "number", "format": fixed2 }
]);
emit_table_with_columns!(
    columns,
    vec![(rejected, r as usize, rate, se, (rate - power) / se)],
    metadata = serde_json::json!({ "id": "simulation" })
);
```

既定の入力（$k = 4$、$n = 10$、$f = 0.25$、$\alpha = 0.05$）では $d_1 = 3$、$d_2 = 36$、$\lambda = 2.5$ で、臨界値は $c = 2.8663$、検出力は $0.21224$ である。
効果量が中程度でも、各群 10 個では 5 回に 1 回ほどしか差を検出できない。
`evaluate_tail` の推定絶対誤差は $3.2 \times 10^{-9}$、評価回数は 44 回で、中心の `FisherF` の和による Poisson 混合との差は $8.1 \times 10^{-11}$ と推定の範囲に入る。
Monte Carlo の棄却の割合は 2,000 回中 384 回の 0.192 で、標準誤差 0.0091 に対して $z = -2.21$ である。
同じ設定でシードを 1 にすると $z = -1.17$、1000 にすると $z = 0.90$ なので、$\lvert z \rvert$ が 2 を少し超えたのはシードによる揺らぎと読める。
$f = 0$ では検出力は $0.05$（`FisherF` の裾と同じ値）になり、Poisson 混合との差は $4.2 \times 10^{-17}$ である。
$k = 3$、$n = 40$、$f = 0.4$ では $\lambda = 19.2$ で検出力は $0.97893$、Monte Carlo は $0.9845$（$z = 1.74$）である。
各群の標本数を 10 から 40 に増やすと、$f = 0.25$ の検出力は $0.21224$ から $0.74940$ に上がる。

## scioxide-stats との役割分担

`scioxide-random` は統計量の値を受け取って確率を返す分布だけを提供し、データから統計量を計算したり、検定の結論を返したりはしない。
データから検定を行うのは `scioxide-stats` で、次の関数が上の分布を使う。

- `PreparedGroups::pairwise` の Tukey–Kramer と Games–Howell は、[スチューデント化範囲](oxref:random-tests-studentized-range)の `StudentizedRange::evaluate_tail` で同時の $p$ 値と信頼区間を作る（[回帰分析・分散分析・GLM](oxref:stats-regression-anova-and-group-comparison)）。
- 回帰と分散分析の F 検定は `FisherF` の `sf` を使う。
- 平均の検出力 `power` は分散を推定する場合に `NoncentralStudentT` を使う（[検出力と標本サイズの設計](oxref:stats-power-estimated-variance-t-test)）。
- KS 検定と KS の分布の関係は[scioxide-stats の KS 検定](oxref:random-tests-ks-calibration)にある。

Anderson–Darling と Cramér–von Mises の統計量の帰無分布は、`scioxide-random` は提供しない。
`scioxide-stats` はこれらの $p$ 値を検定ごとに別の方法で求める。

- 母数をすべて指定した連続分布に対する一標本の `cramer_von_mises_test` は、Csörgő–Faraway の極限分布を使う。
- 二標本の `cramer_von_mises_two_sample_test` は、作業量の上限内ならラベルの並べ方をすべて数え上げ、超えれば同順位のないデータに Anderson の極限近似を使う。
- $k$ 標本の `anderson_k_sample_test`（Scholz–Stephens）は、公表された臨界値を補間し、$p$ 値を $[0.001, 0.25]$ に切り詰める。
- 一標本の Anderson–Darling は統計量 `anderson_darling_statistic` だけを返す。
  母数を推定した場合や離散の帰無分布と同じく、出力先を指定する API `goodness_of_fit_test_into` の Monte Carlo（各複製で母数を当て直す）で較正する。

## まとめ

F 分布の裾は不完全ベータ関数を小さい側で評価し、非心分布の裾は Poisson 混合を Benton–Krishnamoorthy の漸化式で正の項だけ足して求める。
非心分布の分位点は Pearson や Patnaik の近似、モーメントを合わせた正規から始め、安全化した Newton 法で小さい側の対数の裾を解く。
分散分析の検出力は `FisherF::isf` の臨界値で `NoncentralF` の上側確率を評価すれば求められ、非心度 $\lambda = knf^2$ から必要な標本数を見積もれる。
Monte Carlo で検出力を確かめるときは、二項分布の標準誤差と複数のシードで $z$ を読み、一つのシードの $\lvert z \rvert > 2$ だけで判断しない。
Anderson–Darling と Cramér–von Mises の帰無分布は `scioxide-random` にないので、`scioxide-stats` の検定関数で $p$ 値を求める。
