試行ごとに成功確率が異なる計数や、色によって選ばれやすさが違う非復元抽出は、二項分布や超幾何分布の閉形式では表せない。
台が有限なら、確率質量を一度すべて計算して表にすれば、その後の問い合わせは表を引くだけで済む。
このページは、`scioxide-random` が表で扱う Poisson 二項分布と非心超幾何分布の作り方、閉形式で扱う Boltzmann 分布、Fisher と Wallenius の非心超幾何分布の違いを説明する。
計数の分布に共通する標本化の約束（`CountDistribution`）は[離散分布と計数の分布](oxref:random-discrete-count-distribution)にある。

## 確率質量と累積の表

`PoissonBinomial`、`FisherNoncentralHypergeometric`、`WalleniusNoncentralHypergeometric` は、構築のときに台の上の確率質量の対数を計算し、和で正規化して表にする。
下側の累積 $\ln P(K \le k)$ は台の左端から、上側の累積 $\ln P(K > k)$ は右端から、それぞれ対数の和（`logadd`）で別々に足す。
どちらの累積も小さい質量から足し始めるので、遠い裾の確率も相対精度を保つ。
各 $k$ では二つの累積のうち小さい方の対数 $x$ をそのまま残し、大きい方をその補 $\ln(1 - e^{x})$ で作り直すので、二つの和は丸めを除いて 1 になる。

表は台の大きさ $L$ に対して $3L$ 個の `f64` で、構築の手間は `work_budget` に、メモリ領域は `max_bytes` に数える。
確率質量と裾の問い合わせは表を一回引く $O(1)$ で、メモリ領域を確保しない。
分位点は台の両端を区間とする二分法で $O(\log L)$ 回の表引きで求め、標本は開区間の一様乱数に対して同じ二分法で分布関数を逆に解く。
`PoissonBinomial` だけは標本を $m$ 個の Bernoulli 試行で直接作る。

## Poisson 二項分布の動的計画法

成功確率 $p_1, \dots, p_m$ の独立な Bernoulli 試行の成功数 $K$ を Poisson 二項分布という。
平均は $\sum_i p_i$、分散は $\sum_i p_i(1 - p_i)$ で、すべての $p_i$ が等しければ二項分布になる。
最初の $j$ 回の試行での確率質量 $P_j(k) = P(\text{最初の } j \text{ 試行で } k \text{ 回成功})$ は、$j$ 回目の試行が失敗か成功かで場合を分けて

$$
P_j(k) = (1 - p_j)\,P_{j-1}(k) + p_j\,P_{j-1}(k - 1),\qquad P_0(0) = 1
$$

を満たす。
右辺は非負の項の和なので、引き算による桁落ちが起きない。
`PoissonBinomial::new(&probabilities)` はこの漸化式を対数で回し、$k$ を大きい方から更新して一本の配列の上で書き換える。
確率がちょうど 0 の試行は取り除き、1 の試行は台を 1 つずらすだけにする。
残った $m$ 個の試行に対して、準備は $m(m+3)/2$ 回の更新（作業量の上限を超えればエラー）と多くて $4m + 3$ 個の `f64` のメモリ領域を使う。
確率質量と裾の問い合わせは $O(1)$、分位点は $O(\log m)$、標本は $m$ 個の Bernoulli 試行で $O(m)$ である。
離散 Fourier 変換による計算は使わない。

## Boltzmann 分布

`Boltzmann::new(lambda, n)` は $\{0, 1, \dots, n - 1\}$ 上の切断した離散指数分布

$$
P(X = k) = \frac{(1 - e^{-\lambda})\,e^{-\lambda k}}{1 - e^{-\lambda n}}
$$

である。
等間隔 $\varepsilon$ のエネルギー準位 $E_k = k\varepsilon$ を温度 $T$ で占める確率は Boltzmann 因子 $e^{-E_k/(k_BT)}$ に比例するので、$\lambda = \varepsilon/(k_BT)$ と読める（$k_B$ は Boltzmann 定数）。
分布関数 $F(k) = (1 - e^{-\lambda(k+1)})/(1 - e^{-\lambda n})$ と上側確率 $S(k) = e^{-\lambda(k+1)}(1 - e^{-\lambda(n-k-1)})/(1 - e^{-\lambda n})$ はどちらも閉形式で、対数で評価して補を取らない。
平均と分散は $\lambda n < 0.1$ では Bernoulli 数による展開で、それ以外は閉形式で求める。
標本は専用の構成を持たず、計数の分布に共通の既定の方法で作る。
開区間の一様乱数 $U$ に対して $F(k) \ge U$ となる最小の $k$ を、台が $\{0, \dots, n - 1\}$ と分かっているので区間 $[0, n - 1]$ の二分法で直接探し、閉形式の裾の評価は $\log_2 n$ 回程度で済む。
$n$ は 1 以上 $2^{53}$ 以下に限る。

## Fisher と Wallenius の非心超幾何分布

総数 $N$ 個のうち $M$ 個が成功（赤）、$N - M$ 個が失敗（白）の壺から $n$ 個を取り出すとき、赤の数 $K$ は超幾何分布に従う。
台は $\max(0, n - (N - M)) \le k \le \min(n, M)$ である。
赤が白の $\omega$ 倍選ばれやすいとき、偏りの入れ方で二つの異なる分布が生じる。

Fisher の非心超幾何分布は赤と白を独立な二項分布 $X \sim \mathrm{Bin}(M, p_1)$、$Y \sim \mathrm{Bin}(N - M, p_2)$ で選び、合計 $X + Y = n$ を条件にしたときの $X$ の分布である。
確率質量は

$$
P(K = k) \propto \binom{M}{k}\binom{N - M}{n - k}\,\omega^k,\qquad \omega = \frac{p_1/(1 - p_1)}{p_2/(1 - p_2)}
$$

で、$\omega$ はオッズ比である。
周辺和を固定した $2 \times 2$ 分割表の左上のセルはこの分布に従い、Fisher の正確検定の対立仮説やオッズ比の条件付き推定に使う。

Wallenius の非心超幾何分布は一つずつ順に取り出し、各回で残っている赤と白の数に重みを掛けた比で次の一つを選ぶ過程の分布である。
$t$ 回目までに $k$ 個の赤が出ている状態から、次に赤を引く確率は

$$
\frac{\omega\,(M - k)}{\omega\,(M - k) + \bigl(N - M - (t - k)\bigr)}
$$

で、重みは取り出すたびに残りの構成に応じて変わる。
重さの違う玉を一つずつ引く抽選や、捕まりやすさの違う魚が順に釣られる漁獲がこの型である。
二つの分布は $\omega = 1$ ではどちらも超幾何分布に等しいが、$\omega \ne 1$ では異なる。
$N = 10$、$M = 4$、$n = 3$、$\omega = 2$ では、Fisher の質量は $\binom{4}{k}\binom{6}{3-k}2^k = 20, 120, 144, 32$ に比例するので $P(K = 0) = 20/316 \approx 0.0633$ である。
Wallenius では白を 3 回続けて引く確率なので、$P(K = 0) = \frac{6}{14} \cdot \frac{5}{13} \cdot \frac{4}{12} = 5/91 \approx 0.0549$ になる。

二つのコンストラクターの引数は `population` が $N$、`successes` が $M$、`draws` が $n$、`odds` が $\omega$ である。
`FisherNoncentralHypergeometric::new(population, successes, draws, odds)` は、隣り合う質量の比

$$
\ln\frac{P(k+1)}{P(k)} = \ln\frac{(M - k)(n - k)}{(k + 1)(N - M - n + k + 1)} + \ln\omega
$$

で対数質量を作り、二項係数そのものは作らない。
この比は $k$ について単調に減るので、最頻値を比の符号の二分法で求め、そこから両側へ比を足していく。
表の各段は小さい質量へ向かって進むので、遠い裾まで桁あふれしない。

`WalleniusNoncentralHypergeometric::new(population, successes, draws, odds)` は、Wallenius の分布に安く評価できる閉形式がないので、上の推移確率で取り出しの回数 $t$ ごとに行 $\ln P(t \text{ 回で } k \text{ 個の赤})$ を更新する前向きの動的計画法で表を作る。
$k$ を大きい方から更新するので、行は一本の配列で足りる。
計算コストは $O(n \cdot \min(n, M))$ の更新で、更新の回数が `work_budget` を超えれば準備がエラーになる。
赤が白より多ければ色を入れ替えて $\omega$ を $1/\omega$ にする。
取り出さなかった玉を数える補の形は、Wallenius の過程では別の分布になるので使わない。
$\omega = 1$ では Fisher と同じ表を作る。
コンストラクターは、台が 2 点以上で `population` が $2^{53}$ を超えると `NotImplemented` を返す。

## 二つの非心超幾何分布の比較

次のセルは $N = 10$、$M = 4$ の壺から $n$ 個を取り出すときの Fisher と Wallenius の確率質量を並べ、二つの独立検算と比べる。
一つ目は Fisher の閉形式 $\binom{M}{k}\binom{N-M}{n-k}\omega^k$ を直接足して正規化した値で、`FisherNoncentralHypergeometric` の表との差の最大値を出す。
二つ目は Wallenius の過程を一様乱数でそのまままねた $m$ 回の試行の相対度数で、各 $k$ の $z = (\text{相対度数} - P(k))/\sqrt{P(k)(1 - P(k))/m}$ を Wallenius と Fisher の確率質量の両方について出す。
入力はオッズ比の $\log_2 \omega$、取り出す数 $n$、試行の回数 $m$、SplitMix64 のシードである。
図の帯は Wallenius の確率質量の $\pm 2$ SE、破線と点線の階段は Wallenius と Fisher の確率質量、記号は過程の相対度数である。

```rust
//| id: random-noncentral-hypergeometric-urn
//| ref: random-noncentral-hypergeometric-urn
//| title: 偏りのある壺の取り出しを Fisher と Wallenius の確率質量と比べる
//| run: reactive
//| crates: [scioxide-core, scioxide-random]
//| inputs:
//|   log2_odds: {"type":"range","label":"オッズ比の log₂ ω [-]","description":"0 では二つの分布が超幾何分布に一致し、絶対値が大きいほど違いが広がる。","min":-3,"max":3,"step":0.5,"value":1}
//|   draws: {"type":"range","label":"取り出す数 n [個]","description":"N = 10、M = 4 の壺から取り出す数で、台は max(0, n − 6) から min(n, 4) まで。","min":1,"max":9,"step":1,"value":3}
//|   trials: {"type":"range","label":"過程の試行回数 m [回]","description":"相対度数の標準誤差を 1/√m で変える。","min":4000,"max":40000,"step":4000,"value":20000}
//|   seed: {"type":"range","label":"SplitMix64 のシード [-]","description":"z の値の標本ごとの揺らぎを見る。","min":1,"max":1000,"step":1,"value":11}
//| cases:
//|   - {"id":"central","label":"ω = 1","description":"二つの分布がどちらも超幾何分布になり、全変動距離が 0 になる。","inputs":{"log2_odds":0}}
//|   - {"id":"strong","label":"ω = 8、n = 6","description":"偏りが強く取り出す数が多いので、過程の度数が Fisher の確率質量から大きく外れる。","inputs":{"log2_odds":3,"draws":6}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"masses","path":"/rows/0/1","approx":{"value":0.06329113924050633,"atol":1e-12}}
//|       - {"artifact":"masses","path":"/rows/0/3","approx":{"value":0.054945054945054944,"atol":1e-12}}
//|       - {"artifact":"masses","path":"/rows/0/5","range":{"min":-4.5,"max":4.5}}
//|       - {"artifact":"masses","path":"/rows/2/5","range":{"min":-4.5,"max":4.5}}
//|       - {"artifact":"checks","path":"/rows/0/0","range":{"min":0,"max":1e-14}}
//|   - case: central
//|     expect:
//|       - {"artifact":"checks","path":"/rows/0/1","range":{"min":0,"max":1e-14}}
//|   - case: strong
//|     expect:
//|       - {"artifact":"checks","path":"/rows/0/1","range":{"min":0.05,"max":0.5}}
//|       - {"artifact":"masses","path":"/rows/2/5","range":{"min":-4.5,"max":4.5}}
use scioxide_core::{NumericScalar, RealScalar};
use scioxide_random::{
    FisherNoncentralHypergeometric, Mass, Rng, SeedableRng, SplitMix64,
    WalleniusNoncentralHypergeometric,
};

let (population, successes) = (10_usize, 4_usize);
let n = draws.round() as usize;
let m = trials.round() as usize;
let omega = RealScalar::exp2(log2_odds);
let fisher = FisherNoncentralHypergeometric::new(population, successes, n, omega)
    .map_err(|e| e.to_string())?;
let wallenius = WalleniusNoncentralHypergeometric::new(population, successes, n, omega)
    .map_err(|e| e.to_string())?;
let (low, high) = (n.saturating_sub(population - successes), n.min(successes));
// 独立検算 1: Fisher の閉形式 C(M, k) C(N − M, n − k) ω^k を直接足して正規化する。
let choose = |a: usize, b: usize| (0..b).fold(1.0, |c, i| c * (a - i) as f64 / (i + 1) as f64);
let weights: Vec<f64> = (low..=high)
    .map(|k| {
        choose(successes, k)
            * choose(population - successes, n - k)
            * RealScalar::powi(omega, k as i32)
    })
    .collect();
let total: f64 = weights.iter().sum();
// 独立検算 2: 残りの赤 ω·r と白 w の重みの比で一つずつ取り出す過程をまねる。
let mut rng = SplitMix64::from_seed(seed.round() as u64);
let mut counts = vec![0.0_f64; high + 1];
for _ in 0..m {
    let (mut red, mut white, mut k) = (successes as f64, (population - successes) as f64, 0);
    for _ in 0..n {
        let u: f64 = rng.next_float().map_err(|e| e.to_string())?;
        if u * (omega * red + white) < omega * red {
            (red, k) = (red - 1.0, k + 1);
        } else {
            white -= 1.0;
        }
    }
    counts[k] += 1.0;
}
let mf = m as f64;
let (mut rows, mut band, mut fisher_line, mut wallenius_line, mut points) =
    (Vec::new(), Vec::new(), Vec::new(), Vec::new(), Vec::new());
let (mut closed_form_error, mut total_variation) = (0.0_f64, 0.0_f64);
for (k, weight) in (low..=high).zip(&weights) {
    let f = fisher.pmf(k).map_err(|e| e.to_string())?;
    let w = wallenius.pmf(k).map_err(|e| e.to_string())?;
    let frequency = counts[k] / mf;
    let (se_w, se_f) = (
        RealScalar::sqrt(w * (1.0 - w) / mf),
        RealScalar::sqrt(f * (1.0 - f) / mf),
    );
    closed_form_error =
        RealScalar::max(closed_form_error, NumericScalar::abs(f - weight / total));
    total_variation += 0.5 * NumericScalar::abs(f - w);
    rows.push((
        k,
        f,
        weight / total,
        w,
        frequency,
        (frequency - w) / se_w,
        (frequency - f) / se_f,
    ));
    let x = k as f64;
    band.push([x, w, w - 2.0 * se_w, w + 2.0 * se_w]);
    wallenius_line.push([x, w]);
    fisher_line.push([x, f]);
    points.push([x, frequency]);
}
emit_chart!(
    serde_json::json!({
        "kind": "xy",
        "xLabel": "赤の数 k [個]",
        "yLabel": "確率・相対度数 [-]",
        "dataZoom": true,
        "tooltip": true,
        "layers": [
            {"id": "band", "kind": "band", "name": "Wallenius ± 2 SE", "points": band},
            {
                "id": "wallenius",
                "kind": "line",
                "name": "Wallenius の確率質量",
                "style": {"lineType": "dashed", "step": "middle"},
                "points": wallenius_line
            },
            {
                "id": "fisher",
                "kind": "line",
                "name": "Fisher の確率質量",
                "style": {"lineType": "dotted", "step": "middle"},
                "points": fisher_line
            },
            {"id": "process", "kind": "scatter", "name": "過程の相対度数", "points": points}
        ]
    }),
    metadata = serde_json::json!({ "id": "urn" })
);
let digits4 = serde_json::json!({ "significantDigits": 4 });
let fixed2 = serde_json::json!({ "fractionDigits": 2 });
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let columns = serde_json::json!([
    { "key": "0", "label": "赤の数 k [個]", "type": "integer" },
    { "key": "1", "label": "Fisher の pmf [-]", "type": "number", "format": digits4 },
    { "key": "2", "label": "Fisher の閉形式 [-]", "type": "number", "format": digits4 },
    { "key": "3", "label": "Wallenius の pmf [-]", "type": "number", "format": digits4 },
    { "key": "4", "label": "過程の相対度数 [-]", "type": "number", "format": digits4 },
    { "key": "5", "label": "Wallenius に対する z [-]", "type": "number", "format": fixed2 },
    { "key": "6", "label": "Fisher に対する z [-]", "type": "number", "format": fixed2 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "masses" })
);
let check_columns = serde_json::json!([
    { "key": "0", "label": "閉形式との差の最大値 [-]", "type": "number", "format": sci2 },
    { "key": "1", "label": "Fisher と Wallenius の全変動距離 [-]", "type": "number", "format": digits4 }
]);
emit_table_with_columns!(
    check_columns,
    vec![(closed_form_error, total_variation)],
    metadata = serde_json::json!({ "id": "checks" })
);
```

既定値（$\omega = 2$、$n = 3$、$m = 20\,000$、シード 11）では、Fisher の表と閉形式の差は最大で $2.8 \times 10^{-17}$ で、$P(K = 0)$ は前節の $20/316$ と $5/91$ に一致する。
過程の相対度数は、Wallenius の確率質量に対する $z$ が $-2.13$ から $2.16$ の範囲にあり、Fisher の確率質量に対する $z$ は絶対値が 5.9 から 8.0 になる。
四つの $z$ は相対度数の和が 1 という拘束で互いに相関し、一つの $z$ が 2 を超える確率は約 4.6% あるので、一つの値ではなく列全体の大きさで比べる。
シードを 1 と 1000 に変えると、Wallenius に対する $|z|$ は 1.52 以下になり、Fisher に対する $|z|$ は 3.86 以上のままである。
二つの分布の全変動距離 $\frac{1}{2}\sum_k \lvert P_{\mathrm{F}}(k) - P_{\mathrm{W}}(k) \rvert$ は 0.02845 で、差は小さいが、2 万回の試行で区別できる大きさである。

$\omega = 1$ では二つの表が一致して全変動距離は 0 になり、二つの $z$ の列は同じ値になる。
$\omega = 8$、$n = 6$ では全変動距離が 0.2738 まで広がり、Fisher に対する $z$ は絶対値が最大で 79.6 になるが、Wallenius に対する $|z|$ は 2.49 以下にとどまる。
この壺では、$\omega > 1$ のとき Wallenius の質量が Fisher より $k$ の大きい側に、$\omega < 1$（$\log_2 \omega = -3$）のとき小さい側に寄っている。
どの入力でも、表の値は閉形式と丸めの範囲で一致し、過程の度数が従うのは Wallenius の分布である。

## まとめ

台が有限の計数の分布は、確率質量の対数と両側の累積を一度だけ表にし、裾の確率を小さい側から足すので遠い裾でも相対精度を保つ。
`PoissonBinomial` は非負の項だけの動的計画法で $O(m^2)$ の準備と $O(m)$ のメモリ領域を使い、問い合わせに $O(1)$ で答える。
`Boltzmann` は表を作らず、閉形式の裾と台の上の二分法で評価と標本化を行う。
Fisher の非心超幾何分布は合計を条件にした独立な選択、Wallenius の非心超幾何分布は一つずつの偏った取り出しの分布で、$\omega \ne 1$ では値が異なる。
データが一つずつの取り出しで生じたのか、独立な選択の合計を固定したものなのかを確かめてから、二つの分布のどちらを使うかを決める。
