標本数 $n$ が大きいとき、KS 統計量の $p$ 値は $\sqrt{n}\,D_n$ の極限の Kolmogorov 分布で近似されることが多い。
このページはその極限の分布の評価法と、有限標本の正確な値との差を、比べ方を分けて測る。
有限標本の分布のアルゴリズムと評価領域は[検定統計量の分布と有限標本の KS 分布](../test-statistic-laws/)にある。
同じ問い合わせを繰り返すときに行列法の作業領域を使い回す方法と、`scioxide-stats` の KS 検定が正確な値と漸近の値をどう選ぶかも扱う。

## 漸近の Kolmogorov 分布

$n \to \infty$ で $\sqrt{n}\,D_n$ は Kolmogorov 分布

$$
P(K \le x) = 1 - 2\sum_{j=1}^{\infty} (-1)^{j-1} e^{-2j^2x^2}
= \frac{\sqrt{2\pi}}{x} \sum_{j=1}^{\infty} e^{-(2j-1)^2\pi^2/(8x^2)}
$$

に収束する。
二つの級数は Jacobi のテータ関数の変換で結ばれた同じ関数の表示である。
`Kolmogorov` は $x < 0.82$ では右の級数で下側確率を、$x \ge 0.82$ では左の交代級数で上側確率を直接求める。
どちらも先頭の指数を括り出して和が 1 から始まるようにし、項が許容誤差の $1/100$ 倍の相対量を下回ったところで止める。
0.82 は二つの級数の項数がほぼ等しくなる境である。
平均は $\sqrt{\pi/2}\,\ln 2 \approx 0.8687$、分散は $\pi^2/12 - (\pi/2)\ln^2 2 \approx 0.0678$ の閉形式で返し、標本は開区間の一様乱数の分位点として作る。

## 漸近近似の誤差の大きさ

有限の $n$ で $D_n$ の裾を $P(K > \sqrt{n}\,d)$ で近似すると、誤差の主要項は $1/\sqrt{n}$ の大きさで、ゆっくり減る。
ただし、近似の良し悪しは比べ方によって逆に見える。

$d$ を固定して $n$ を増やすと、裾確率そのものが小さくなり、裾の奥ほど漸近近似の相対誤差は大きい。
[両側 KS の正確な裾を片側の二倍と漸近近似に比べるセル](oxref:random-ks-tail-regions)では、$n = 20$、$d = 0.3$ の正確な裾 0.04307 に対して漸近近似は 0.05465 で、正確な値を 26.9% 上回る。
相対誤差は $d$ とともに大きくなり、$d = 0.6$ では正確な値 $2.05 \times 10^{-7}$ に対して漸近近似は $1.11 \times 10^{-6}$ と 5.4 倍になる。
同じ $d = 0.3$ での相対誤差は $n = 5$ で 14.3%、$n = 60$ で 47.7% であり、$d$ を固定すると $n$ とともに増える。

検定で意味があるのは同じ水準で比べたときの誤差である。
水準 $\alpha$ の漸近の臨界値 $c$（$P(K > c) = \alpha$）から $d = c/\sqrt{n}$ を作って有限標本の裾確率と比べると、ずれは $1/\sqrt{n}$ に比例して減る。
次の二つの節はこの比較に必要な作業領域の使い回しと、その計算を示す。

## 作業領域を再利用する裾の評価

トレイトの問い合わせ（`sf` や `cdf`）は、行列法が要るたびに作業領域を確保する。
同じ分布や同程度の $d$ で何度も評価するときは、作業領域を呼び出し側が持つ。

- `workspace_requirements(x)` は、$x$ での問い合わせに要る行列の次数と分布の `max_bytes` を `KolmogorovRequirements` で返す。
  `dimension()` が 0 なら行列を使わない。
- `KolmogorovWorkspace::new()` は確保せずに空の作業領域を作り、`try_reserve(&requirements)` はメモリ領域の上限を確かめてから伸ばす。
  `check(&requirements)` は確保せずに `Capacity::Sufficient` か `Capacity::NeedsGrowth` を返す。
  `law.workspace(x)` はこの二つをまとめた近道である。
- `evaluate_tail(x, upper, &mut workspace)` は作業領域を伸ばさない。
  足りなければ `DimensionMismatch`、保持したメモリ領域が上限を超えれば `ResourceLimit` を返し、作業量を使い切れば `ConvergenceFailure`（反復上限）になる。

行列法の 1 回の裾の評価回数は $m^3 \log_2 n$ の 3 分の 1 程度で（次のセルの $n = 80$、$m = 25$ で 33,164 回、$n = 160$、$m = 35$ で 103,935 回）、$m$ が 25 を超えると既定の 65,536 では足りないことがある。
分位点と逆変換による標本化は裾の評価を何度も繰り返すので、さらに大きな上限が要る。
密度の問い合わせは二重数の行列を使うので、作業領域を受け取らずに毎回確保する。

## 漸近の臨界値での有限標本の裾確率

次のセルは水準 $\alpha$ の漸近の臨界値 $c$（`Kolmogorov::isf` で求める）から $d = c/\sqrt{n}$ を作り、$n = 5$ から 320 までの有限標本の裾確率 $P(D_n > d)$ を `evaluate_tail` で求める。
漸近の近似が正しければ、どの $n$ でも裾確率は $\alpha$ に等しい。
入力は水準 $\alpha$（無次元、0.01 から 0.2）である。
一つの `KolmogorovWorkspace` を全ての $n$ で使い回し、`workspace_requirements` が返す次数まで `try_reserve` で伸ばす。
表は $n$、$d$、行列の次数 $m$（0 は行列を使わない）、裾確率、推定絶対誤差、評価回数、比 $P/\alpha$、$\sqrt{n}\,(\alpha - P)$ を出す。
最後の列が $n$ によらずほぼ一定なら、ずれは $1/\sqrt{n}$ に比例して減っている。

```rust
//| id: random-ks-asymptotic-level
//| ref: random-ks-asymptotic-level
//| title: 漸近の臨界値での有限標本の両側 KS の裾確率を n ごとに求める
//| run: reactive
//| crates: [scioxide-core, scioxide-random]
//| inputs:
//|   level: {"type":"range","label":"漸近の水準 α [-]","description":"P(K > c) = α となる臨界値 c を作る。","min":0.01,"max":0.2,"step":0.01,"value":0.05}
//| cases:
//|   - {"id":"strict-level","label":"α = 0.01","description":"臨界値が大きく、n = 5 と 10 では d が 1/2 を超えて片側の裾の二倍を使う。","inputs":{"level":0.01}}
//|   - {"id":"loose-level","label":"α = 0.2","description":"臨界値が小さく、n = 5 でも行列法を使う。","inputs":{"level":0.2}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"levels","path":"/rows/0/2","equals":0}
//|       - {"artifact":"levels","path":"/rows/2/3","approx":{"value":0.03919,"rtol":0.001}}
//|       - {"artifact":"levels","path":"/rows/6/3","approx":{"value":0.04743,"rtol":0.001}}
//|       - {"artifact":"levels","path":"/rows/6/4","range":{"min":0,"max":1e-10}}
//|   - case: strict-level
//|     expect:
//|       - {"artifact":"levels","path":"/rows/0/2","equals":0}
//|       - {"artifact":"levels","path":"/rows/6/3","range":{"min":0.008,"max":0.01}}
//|   - case: loose-level
//|     expect:
//|       - {"artifact":"levels","path":"/rows/0/2","range":{"min":1,"max":20}}
//|       - {"artifact":"levels","path":"/rows/6/3","range":{"min":0.18,"max":0.2}}
use scioxide_core::{Budget, RealScalar};
use scioxide_random::{
    InverseSurvival, Kolmogorov, KolmogorovSmirnovTwoSided, KolmogorovWorkspace, LawOptions,
};

let sig4 = serde_json::json!({ "significantDigits": 4 });
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let fixed3 = serde_json::json!({ "fractionDigits": 3 });
// 行列法の評価回数は m³ log₂ n の 3 分の 1 程度で既定の 65,536 を超えるので、上限を大きくする。
let work = Budget::try_from(1_usize << 22).map_err(|e| e.to_string())?;
let options = LawOptions::default().with_work_budget(work);
let limit = Kolmogorov::with_options(options).map_err(|e| e.to_string())?;
// 漸近の臨界値 c: P(K > c) = α。
let critical = limit.isf(level).map_err(|e| e.to_string())?;
// 一つの作業領域を全ての n で使い回し、次数が増えたときだけ伸ばす。
let mut workspace = KolmogorovWorkspace::new();
let mut rows = Vec::new();
let mut points = Vec::new();
for n in [5_usize, 10, 20, 40, 80, 160, 320] {
    let law = KolmogorovSmirnovTwoSided::with_options(n, options).map_err(|e| e.to_string())?;
    let root_n = RealScalar::sqrt(n as f64);
    let d = critical / root_n;
    let requirements = law.workspace_requirements(d).map_err(|e| e.to_string())?;
    workspace
        .try_reserve(&requirements)
        .map_err(|e| e.to_string())?;
    let tail = law
        .evaluate_tail(d, true, &mut workspace)
        .map_err(|e| e.to_string())?;
    let p = RealScalar::exp(tail.log_probability);
    points.push([n as f64, p]);
    rows.push((
        n,
        d,
        requirements.dimension(),
        p,
        tail.absolute_error,
        tail.evaluations,
        p / level,
        root_n * (level - p),
    ));
}
emit_line_chart!(
    &vec![serde_json::json!({
        "name": "有限標本の P(D_n > c/√n)",
        "points": points,
        "style": {"symbol": "circle", "lineType": "dotted"}
    })],
    options = &serde_json::json!({
        "xLabel": "標本数 n [個]",
        "yLabel": "裾確率 [-]",
        "xType": "log",
        "yMin": 0.0,
        "yMax": 0.22,
        "annotations": [{"kind": "line", "axis": "y", "value": level, "label": "漸近の水準 α"}]
    })
);
let columns = serde_json::json!([
    { "key": "0", "label": "標本数 n", "type": "integer" },
    { "key": "1", "label": "d = c/√n [-]", "type": "number", "format": sig4 },
    { "key": "2", "label": "行列の次数 m", "type": "integer" },
    { "key": "3", "label": "P(D_n > d) [-]", "type": "number", "format": sig4 },
    { "key": "4", "label": "推定絶対誤差 [-]", "type": "number", "format": sci2 },
    { "key": "5", "label": "評価回数", "type": "integer" },
    { "key": "6", "label": "P/α [-]", "type": "number", "format": fixed3 },
    { "key": "7", "label": "√n (α − P) [-]", "type": "number", "format": fixed3 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "levels" })
);
```

図の点は有限標本の裾確率、横線は漸近の水準 $\alpha$ である。
既定の $\alpha = 0.05$ では、$d = c/\sqrt{n}$ の裾確率が $n = 5$ の 0.0270 から $n = 20$ の 0.0392、$n = 320$ の 0.0474 へと $\alpha$ に下から近づく。
比 $P/\alpha$ は 0.54、0.78、0.95 で、漸近の臨界値は小標本では保守的（第一種の誤りを犯す実際の確率が $\alpha$ より小さい）である。
$\sqrt{n}\,(\alpha - P)$ は 0.051 から 0.046 へとゆっくり変わるだけで、ずれはほぼ $1/\sqrt{n}$ に比例して減る。
$n = 5$ では $d = 0.607 \ge 1/2$ なので次数は 0 で、片側の Smirnov 和の二倍が正確な値を与える。
$n \ge 10$ では次数が 9 から 49 の行列法を使い、評価回数は $n = 320$ で 320,130 回、推定絶対誤差は $9.1 \times 10^{-12}$ 以下である。

$\alpha = 0.01$ では $n = 5$ と 10 の $d$ が 1/2 を超えて行列を使わず、比は $n = 5$ の 0.32 から $n = 320$ の 0.94 まで変わる。
$\alpha = 0.2$ では $n = 5$ でも次数 5 の行列法を使い、比は 0.71 から 0.96 まで変わる。
どの水準でも、小標本で漸近の $p$ 値を使うと $p$ 値を大きめに見積もる。
独立な照合として、Durbin の行列の冪 $(n!/n^n)(H^n)_{kk}$ を有理数で厳密に計算すると、既定の $\alpha$ の $n = 10$ から 320 の行の裾確率と相対差 $3 \times 10^{-12}$ 以下で一致し、実際の誤差は表の推定絶対誤差より小さい。

## scioxide-stats の KS 検定

`scioxide-random` は統計量の値を受け取って確率を返す分布だけを提供し、データから統計量を計算したり、検定の結論を返したりはしない。
データから KS 検定を行うのは `scioxide-stats` で、上の分布を次のように使う。

- `ks_one_sample_test` は指定した連続分布関数に対する一標本の KS 検定である。
  `TestCalibration::Auto` では、$n^2$ が検定の作業量の上限以内なら有限標本の `KolmogorovSmirnovTwoSided`（片側の対立仮説では `KolmogorovSmirnovOneSided`）の `sf` を使い、超えれば `Kolmogorov` の極限（片側は $e^{-2nd^2}$）を使う。
  有限標本の分布の評価が作業量かメモリ領域の上限に達したときも、`Auto` は極限の分布に切り替え、`TestCalibration::Exact` はエラーを返す。
  同順位のあるデータには `InvalidInput` を返す。
  帰無分布は母数を指定した連続分布を仮定するので、母数をデータから推定した場合や離散分布には `goodness_of_fit_test_into` を使う（[分布適合度検定と分散等質性検定](oxref:stats-dist-tests-kolmogorov-smirnov)）。
- `ks_two_sample_test` は正確な場合に格子の経路を数える独自の計算を使い、漸近の場合に `Kolmogorov` を使う。

## まとめ

漸近の Kolmogorov 分布は二つの級数を $x = 0.82$ で切り替え、それぞれ小さい側の裾を直接求める。
漸近の $p$ 値の誤差は、$d$ を固定すると $n$ とともに相対的に大きくなり、同じ水準で比べると $1/\sqrt{n}$ に比例して減るので、比べ方を決めてから読む。
漸近の臨界値は小標本では保守的で、$n = 20$ で実際の第一種の誤りの確率は名目の約 0.78 倍である。
同じ問い合わせを繰り返すなら `KolmogorovWorkspace` を一度事前確保して `evaluate_tail` に渡し、`TestStatisticResult` の推定絶対誤差と評価回数を確かめる。
行列法の次数が 25 を超える問い合わせでは、`LawOptions` の作業量の上限を既定より大きくする。
