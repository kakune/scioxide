`scioxide-random` の確率分布は標本化、密度、分布関数、分位点、モーメントといった機能を別々のトレイトとして実装する。
分布が持たない機能を数値積分などで補う既定の実装はない。
このページは対応機能を表すトレイトの規約、引き算をしない裾確率、閉形式を持たない分位点の数値逆算、分布を組み合わせる型を説明する。
組み込みにない密度からの標本化は[利用者の密度からの標本化](../user-density-sampling/)、多変量の分布は[多変量・行列・群の確率分布](../multivariate-and-matrix-laws/)、検定統計量の分布は[検定統計量の分布と有限標本の KS 分布](../test-statistic-laws/)で扱う。
一括生成と作業領域の規約は[乱数・分布・標本設計の数理](../)にある。

## 対応機能を表すトレイト

| トレイト | 計算する量 | 規約 |
|---|---|---|
| `Distribution`、`CountDistribution` | 標本 | 連続は `Rng` の浮動小数点から、計数は全幅の一様乱数ワードから作る |
| `Density`、`LogDensity` | $f(x)$、$\ln f(x)$ | 台の外は 0（対数は $-\infty$）で、エラーではない。端点では分布ごとに決めた値（`Uniform` は半開区間、発散する端点は $+\infty$） |
| `Mass`、`LogMass` | $P(X = k)$ | 正確な整数 $k$（`usize` か `i64`） |
| `Cdf`、`LogCdf` | $F(x) = P(X \le x)$ | 計数では $k$ の原子を含み、連続補正をしない |
| `Survival`、`LogSurvival` | $S(x) = P(X > x)$ | $1 - F$ を作らずに直接計算する |
| `Quantile` | $\inf\{x : F(x) \ge p\}$ | $F$ が平らな区間では左端。$p = 0, 1$ は台の端（無限大もありうる）。数値逆算する連続の分布は小さい側の裾を評価する |
| `InverseSurvival` | $S(x) = p$ となる点 | $1 - p$ を作らない。平らな区間では右端 |
| `Mean`、`Variance`、`Entropy` | 平均、分散、エントロピー（nats） | 分布ごとの式か評価法があるときだけ実装する。存在しない値は理由 `Undefined` の `DomainError`。非退化のスカラーの分布の分散は成功すれば正で、打ち消しやアンダーフローで 0 になる場合と、許容誤差の精度で求められない場合は 0 を返さずにエラーを返す |
| `Support`、`CountSupport`、`SignedCountSupport` | 台の閉包、整数の台の端 | `contains` は有限の点の正確な所属を返す |

機能の有無には型で決まるものと母数で決まるものがある。
`Cauchy` は `Mean` を実装しないので、平均を求めるコードはコンパイルできない。
`StudentT::new(1.0)` は `Mean` を実装するが、`mean()` は実行時に `DomainError` を返す。
整数の分布の $Q(1)$ は台が上に有界でなければ表せないので、`NotImplemented` になる。
分布の問い合わせは NaN と無限大の座標を `NonFinite` として拒否する。
ただし `log_interval_probability` は区間の端に $\pm\infty$ を受け付ける。

## 裾確率と区間確率

上側確率 $S(x)$ が小さいとき、$1 - F(x)$ は丸めで情報を失う。
正規分布の $x = 40$ では $1 - F$ は 0 に丸まるが、`log_sf(40)` は約 $-804.6$ を返す。
`isf(p)` は $p = 10^{-300}$ のように $1 - p$ が 1 に丸まる確率でも、相対精度を保って $S(x) = p$ の点を返す。

`log_interval_probability(&law, a, b)` は連続な分布の区間確率 $\ln P(a < X \le b)$ を求める。
二つの端の下側の対数確率 $\ln F$ と上側の対数確率 $\ln S$ のうち小さい方の組を選び、$\ln(e^{u} - e^{v}) = u + \ln(1 - e^{v - u})$ で差を作るので、二つの分布関数の値がともに 1 に丸まる区間でも相対精度を保つ。
無限の端を受け付け、空の区間には $-\infty$ を返し、NaN や $a > b$ の端は `InvalidInput` として拒否する。
裾の評価は高々 3 回で、既定の `LawOptions` の作業量の上限に従う。
`log_interval_probability_with_options(&law, a, b, options)` は与えた `LawOptions` の上限を使う。
`log_interval_probability_scoped(&law, a, b, options, scope)` は計算を呼び出し側の実行の範囲（`ExecutionContext` か、外側の求解の `SolveContext`）の一つの段として行い、各裾の評価の前に取り消しと期限を確かめ、分布の作業を外側の求解の評価回数にも数える。

次のセルは標準正規分布の上側確率 $p = 10^{-e}$ の点を `isf` で求め、`log_sf` で戻した値と、`scioxide_special::erfc` による別経路の値 $\ln\bigl(\operatorname{erfc}(x/\sqrt{2})/2\bigr)$ を $\ln p$ と比べる。
$1 - p$ を経由する `quantile` が有限の値を返すかどうかも示す。
さらに区間 $(a, a + 1]$ の対数確率を `log_interval_probability` と分布関数の差で比べ、その区間に打ち切った分布 `Truncated::new(normal, a, a + 1.0)` の中央値 $m$ を求める。
中央値の検算として、条件付き分布関数 $\bigl(\operatorname{erfc}(a/\sqrt{2}) - \operatorname{erfc}(m/\sqrt{2})\bigr)/\bigl(\operatorname{erfc}(a/\sqrt{2}) - \operatorname{erfc}((a+1)/\sqrt{2})\bigr)$ を `erfc` で計算し、0.5 との差を出す。

```rust
//| id: random-direct-tail-inversion
//| ref: random-direct-tail-inversion
//| title: 極小の上側確率を逆算し、打ち切った分布の中央値を求める
//| run: reactive
//| crates: [scioxide-random, scioxide-core, scioxide-special]
//| inputs:
//|   tail_exponent: {"type":"range","label":"上側確率の指数 e（p = 10⁻ᵉ）","min":2,"max":300,"step":2,"value":100}
//|   lower: {"type":"range","label":"打ち切りの下端 a","description":"区間 (a, a + 1] の確率は a = 30 で約 4.9 × 10⁻¹⁹⁸。","min":0,"max":30,"step":1,"value":10}
//| cases:
//|   - {"id":"moderate-tail","label":"e = 2、a = 0","description":"e ≤ 16 では 1 − p が 1 に丸まらないので quantile(1 − p) も有限で、a = 0 では分布関数の差も使える。","inputs":{"tail_exponent":2,"lower":0}}
//|   - {"id":"extreme","label":"e = 300、a = 30","description":"p = 10⁻³⁰⁰ と、確率が約 4.9 × 10⁻¹⁹⁸ の区間。","inputs":{"tail_exponent":300,"lower":30}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"inversion","path":"/rows/0/0","approx":{"value":21.2734535610,"atol":1e-8}}
//|       - {"artifact":"inversion","path":"/rows/0/3","equals":false}
//|       - {"artifact":"interval","path":"/rows/0/0","approx":{"value":-53.231310,"atol":1e-5}}
//|       - {"artifact":"interval","path":"/rows/0/2","equals":0}
//|       - {"artifact":"interval","path":"/rows/0/3","approx":{"value":10.0684093695,"atol":1e-8}}
//|       - {"artifact":"interval","path":"/rows/0/4","range":{"min":-1e-8,"max":1e-8}}
//|   - case: moderate-tail
//|     expect:
//|       - {"artifact":"inversion","path":"/rows/0/3","equals":true}
//|       - {"artifact":"interval","path":"/rows/0/2","range":{"min":0.34,"max":0.35}}
//|   - case: extreme
//|     expect:
//|       - {"artifact":"inversion","path":"/rows/0/0","approx":{"value":37.0470962994,"atol":1e-8}}
//|       - {"artifact":"interval","path":"/rows/0/3","approx":{"value":30.0230704678,"atol":1e-8}}
//|       - {"artifact":"interval","path":"/rows/0/4","range":{"min":-1e-8,"max":1e-8}}
use scioxide_core::RealScalar;
use scioxide_random::{
    Cdf, InverseSurvival, LogSurvival, Normal, Quantile, Truncated, log_interval_probability,
};

let fixed10 = serde_json::json!({ "fractionDigits": 10 });
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let sig8 = serde_json::json!({ "significantDigits": 8 });
let erfc =
    |x: f64| scioxide_special::erfc(x / std::f64::consts::SQRT_2).map_err(|e| e.to_string());
let normal = Normal::new(0.0_f64, 1.0).map_err(|e| e.to_string())?;
let log_p = -tail_exponent * std::f64::consts::LN_10;
let p = RealScalar::exp(log_p); // e ≤ 300 では正規化数
// 上側確率から直接逆算し、log_sf と別経路の erfc で ln p に戻す。
let x = normal.isf(p).map_err(|e| e.to_string())?;
let recovered = normal.log_sf(x).map_err(|e| e.to_string())?;
let by_erfc = RealScalar::ln(erfc(x)? / 2.0);
// 比較: binary64 の 1 − p は p ≤ 2⁻⁵⁴ で 1 に丸まり、quantile は +∞ を返す。
let via_complement = normal.quantile(1.0 - p).map_err(|e| e.to_string())?;
let columns = serde_json::json!([
    { "key": "0", "label": "isf(p)", "type": "number", "format": fixed10 },
    { "key": "1", "label": "log_sf(isf(p)) − ln p", "type": "number", "format": sci2 },
    { "key": "2", "label": "erfc 経路 − ln p", "type": "number", "format": sci2 },
    { "key": "3", "label": "quantile(1 − p) が有限", "type": "boolean" }
]);
emit_table_with_columns!(
    columns,
    vec![(
        x,
        recovered - log_p,
        by_erfc - log_p,
        RealScalar::is_finite(via_complement)
    )],
    metadata = serde_json::json!({ "id": "inversion" })
);
// 区間 (a, a+1] の確率: 対数のまま計算する方法と、分布関数の差。
let (a, b) = (lower, lower + 1.0);
let log_mass = log_interval_probability(&normal, a, b).map_err(|e| e.to_string())?;
let by_hand = RealScalar::ln((erfc(a)? - erfc(b)?) / 2.0);
let difference =
    normal.cdf(b).map_err(|e| e.to_string())? - normal.cdf(a).map_err(|e| e.to_string())?;
// 区間に打ち切った分布。小さい側の裾で逆算するので a が大きくても中央値が求まる。
let conditional = Truncated::new(normal.clone(), a, b).map_err(|e| e.to_string())?;
let median = conditional.quantile(0.5).map_err(|e| e.to_string())?;
let half = (erfc(a)? - erfc(median)?) / (erfc(a)? - erfc(b)?) - 0.5;
let columns = serde_json::json!([
    { "key": "0", "label": "ln P(a < X ≤ a+1)", "type": "number", "format": sig8 },
    { "key": "1", "label": "erfc 経路との差", "type": "number", "format": sci2 },
    { "key": "2", "label": "cdf(a+1) − cdf(a)", "type": "number", "format": sig8 },
    { "key": "3", "label": "中央値 m", "type": "number", "format": fixed10 },
    { "key": "4", "label": "erfc による F(m) − 0.5", "type": "number", "format": sci2 }
]);
emit_table_with_columns!(
    columns,
    vec![(log_mass, log_mass - by_hand, difference, median, half)],
    metadata = serde_json::json!({ "id": "interval" })
);
```

既定の入力（$e = 100$、$a = 10$）では `isf(p)` は $21.2734535610$ で、`log_sf` で戻した値と $\ln p$ の差は $-2.8 \times 10^{-14}$、`erfc` の経路との差は 0 である。
binary64 の $1 - p$ は $p \le 2^{-54} \approx 5.6 \times 10^{-17}$ で 1 に丸まるので、`quantile(1 − p)` は $e \le 16$ では有限、$e \ge 18$ では $+\infty$ になる。
区間 $(10, 11]$ の確率は分布関数の差では 0 になるが、`log_interval_probability` は $-53.231310$（約 $7.6 \times 10^{-24}$）を返し、`erfc` の経路との差は $-7.1 \times 10^{-15}$ である。
打ち切った分布の中央値は $10.0684093695$ で、`erfc` で計算した条件付き分布関数と 0.5 の差は $1.3 \times 10^{-15}$ である。
$e = 300$、$a = 30$ でも `isf` は $37.0470963$、区間の対数確率は $-454.32$（約 $4.9 \times 10^{-198}$）、中央値は $30.0230704678$ で、条件付き分布関数と 0.5 の差は $7.1 \times 10^{-14}$ にとどまる。

## LawOptions と数値逆算

閉形式を持たない分布は、問い合わせ、モーメント、エントロピーの計算に `LawOptions` の精度と上限を使う。
`new(母数…)` は既定の設定で分布を作り、`with_options(母数…, options)` は与えた設定を使う。
分布のコンストラクターが設定を確かめ、相対許容誤差が $[64\varepsilon, 0.1)$ の外なら `InvalidInput` を返す。

| 設定 | 既定値 | 対象 |
|---|---|---|
| 許容誤差 `tolerance` | 絶対・相対とも $\sqrt{\varepsilon} \approx 1.5 \times 10^{-8}$ | 正の項の和と求積は相対許容誤差で止まる。確率は絶対許容誤差でも止まりうる |
| 作業量 `work_budget` | 65,536 | 1 回の準備・問い合わせ・モーメントの計算 |
| 一様乱数ワード `sample_word_budget` | 65,536 | 複数の段を組み合わせる分布の 1 標本が要求する一様乱数ワード |
| メモリ領域 `max_bytes` | 64 MiB | 分布が確保する各バッファー |

作業量は漸化式の更新、求積で被積分関数を評価した回数、特殊関数の反復、準備の段を 1 単位ずつ数える。
根の挟み込みと二分、入れ子の積分、成分の分布への問い合わせも、同じ操作の一つの上限を共有する。
1 標本の中の棄却や逐次の探索はどの分布でも候補 1,024 個で打ち切る。
作業量、一様乱数ワード、候補のどれかの上限に達すると `ConvergenceFailure` を返し、近似値を成功として返さない（[棄却と作業量の上限](oxref:random-algorithms-rejection-limits)）。
許容誤差で止めた値は推定であり、誤差の上界は保証されない。
`StudentizedRange` と両側 KS の分布の分位点や、一般化双曲型の分位点のように分布関数の評価を繰り返す計算は、既定の作業量では足りないことがあり、`with_work_budget` で増やす。

分位点を閉形式で求められない分布は、対数確率を数値的に逆算する。
`invert_log_probability(&law, ln p, upper)` は公開されている逆算関数で、有限の負の $\ln p$ を受け取り、それ以外は `InvalidInput` を返す。
残差は $\ln F(x) - \ln p$（`upper` なら $\ln S(x)$ との比較）の符号 $\pm 1$ だけで、台の上で根を挟んでから二分法で区間を縮める。
符号だけを使うので導関数が要らず、平らな裾やノイズのある裾でも止まり、確率を引き算で作らないので $\ln p$ が浮動小数点で表せる最小の確率より小さくてもよい。
平らな区間では、下側の逆算が左端を、上側の逆算が右端を返す。
既定の `InversionOptions` は反復 4,096 回、作業量 65,536 単位（分布の 1 回の操作の既定の作業量と同じ。
反復的な分布では裾の 1 回の評価が多くの単位を使う）、区間幅の許容誤差を絶対・相対とも機械イプシロンとする。
`invert_log_probability` は二分法が最後に残した区間の上端だけを返し、最上位の求解が成功しなければ終了の理由を持つ `ConvergenceFailure`（取り消しや期限なら `ExecutionStopped`）を返す。
`invert_log_probability_with_options(&law, ln p, upper, &options)` は設定を取り、値 `value()`、最上位の求解の結果 `root()`、評価回数 `evaluations()` を持つ `InversionReport` を返す。
こちらは最上位の求解が成功しなくてもレポートを返すことがあるので、`root().is_success()` を確かめてから `value()` を使う。
作業量を使い切った場合と、有限の挟み込み区間が見つからない場合はエラーになる。
`invert_log_probability_scoped(&law, ln p, upper, &options, scope)` は `log_interval_probability_scoped` と同じく、呼び出し側の実行の範囲の一つの段として逆算する。

閉形式を持たない組み込み分布の分位点の多くも、同じ挟み込みと二分法を `LawOptions` の作業量の中で使う。
このとき $p > 1/2$ なら $\ln(1 - p)$ を `ln_1p` で作って反対側の裾で逆算し、$1 - p$ に近い大きな確率を比べない。
滑らかな裾を持つ分布では残差を符号ではなく対数確率の差とし、その大きさが相対許容誤差の 1/8 に入った時点でも止める。
内部の分位点が台の端に丸まる場合は `NumericalInstability` を返す。
`LevyStable` は Brent 法、非心分布は安全化した Newton 法という、分布ごとの逆算を使う。

## 合成した分布

| 型 | 分布 | 機能と計算 |
|---|---|---|
| `Affine::new(law, μ, σ)` | $\mu + \sigma X$（$\sigma \ne 0$ は有限） | 元の分布が持つ機能だけを持ち、各操作は元の分布の評価 1 回である。負の $\sigma$ は上側と下側、分位点と `isf` を入れ替える |
| `Truncated::new(law, a, b)` | $a < X \le b$ という条件付きの分布 | 有限の $a < b$ と、0 でない区間確率（対数で表せればよい）が必要。区間確率と裾は元の分布の小さい側の裾から対数で作る。分位点、`isf`、標本化には元の分布の `Quantile` と `InverseSurvival` が要る |
| `OrderStatistic::new(law, rank, count)` | 独立な `count` 個の中の `rank` 番目（1 から数える） | 分布関数 $I_{F(x)}(k, n - k + 1)$ を小さい側の裾から求め、分位点と標本はその数値逆算なので、元の分布に標本化器は要らない |
| `Mixture::new(components, &weights)` | 有限混合 | 評価は成分ごとの評価の和で $O(n)$。標本は Walker の別名表で成分を $O(1)$ で選び、その成分の `Distribution` で作る。`Entropy` は数値積分が要るので持たない。異なる型の成分は `&dyn ContinuousLaw` で借用でき、そのときは評価だけを行う |
| `Transformed::abs(law)`、`exp(law)`、`log(law)` | $\lvert X \rvert$、$e^X$、$\ln X$ | 密度と裾を変換し、分位点は裾の数値逆算、標本は元の標本の変換で作る。`log` は元の分布の `LogCoordinateLaw` を使う `LogTransformed` を返す。モーメントとエントロピーは持たない |
| `Histogram::from_masses(edges, masses)`、`from_densities(edges, densities)` | 区分的に一様な分布 | 準備は $O(n)$ の時間とメモリ領域、密度・裾・分位点・標本は累積質量の二分探索で $O(\log n)$。平均・分散・エントロピーは $O(n)$ |

数値計算を伴う `Truncated`、`OrderStatistic`、`Mixture`、`Transformed` は既定の `LawOptions` を使い、`with_options`（`Transformed` は `abs_with_options`、`exp_with_options`、`log_with_options`）が最後の引数で設定を取る。

`ContinuousLaw` は合成した分布が必要とする評価の機能（`Density`、`LogDensity`、`Cdf`、`Survival`、`LogCdf`、`LogSurvival`、`Support`）をまとめたオブジェクト安全なトレイトで、それらを持つすべての型が実装する。
$Y = \ln X$ の分布関数は $F_X(e^y)$、密度は $e^y f_X(e^y)$ だが、$y = -800$ のように $e^y$ が 0 に丸められる点ではこの式をそのまま評価できない。
そのため `Transformed::log` は正の座標を $y$ のまま受け取る評価 `LogCoordinateLaw`（$\ln F_X(e^y)$、$\ln S_X(e^y)$、Jacobian を含む $y + \ln f_X(e^y)$）を元の分布に要求する。
`Exponential`、`Gamma`、`GeneralizedGamma`、`LogNormal`、`Histogram` と `Transformed::exp` の結果（印 `ExponentialTransform`）がこれを実装し、`ln(exp(X))` は元の分布をそのまま評価する。

## まとめ

分布の機能はトレイトごとに実装され、存在しない平均や分散は、実装しないことによるコンパイル時の誤りか、実行時の `DomainError` で区別される。
小さな上側確率は `sf`、`log_sf`、`isf`、`log_interval_probability` で引き算をせずに扱い、`1 - p` を経由する `quantile` は $p \le 2^{-54}$ で使えないと判断できる。
`LawOptions` を持つ分布の数値計算と `invert_log_probability` は作業量の上限で打ち切られ、上限に達すると `ConvergenceFailure` を返すので、分位点を繰り返す分布では上限を増やす。
レポートが要るときは `invert_log_probability_with_options` を使い、`root()` の終了状態を確かめてから値を使う。
打ち切り、順序統計量、混合、変換、ヒストグラムは元の分布の機能を引き継ぐので、必要な機能を元の分布が持つかを型で確かめてから組み合わせる。
