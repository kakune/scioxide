ベクトル、行列、群の元を値に取る確率分布は、相関のある乱数の生成、ベイズ推定の事前分布、ランダム行列、回転の無作為な選択に使う。
`scioxide-random` は半正定値の共分散を持つ多変量正規分布と多変量 t 分布、単体と計数のベクトルの分布、正定値行列と行列値の分布、直交群とユニタリ群の Haar 測度、固有値を指定した相関行列を提供する。
このページは多変量正規分布の準備（固有分解と階数の判定）と特異な台の扱い、各分布を生成するアルゴリズム、群の Haar 測度が符号の固定で得られる理由を説明する。
多変量正規分布と多変量 t 分布の矩形の同時確率は[多変量正規・t 分布の矩形確率](../multivariate-rectangle-probability/)で扱う。

## 多変量正規分布の固有分解と特異な台

平均 $\boldsymbol{\mu} \in \mathbb{R}^d$、共分散 $\Sigma \in \mathbb{R}^{d \times d}$ の正規分布 $\mathcal{N}_d(\boldsymbol{\mu}, \Sigma)$ は、$\Sigma = BB^{\mathsf T}$ となる $d \times r$ 行列 $B$ と標準正規ベクトル $\mathbf{Z} \in \mathbb{R}^r$ から $\mathbf{X} = \boldsymbol{\mu} + B\mathbf{Z}$ として作れる。
$\Sigma$ が正定値なら Cholesky 分解で $B$ が得られる。
線形の拘束を持つ量（成分の和が一定の組成など）の共分散は半正定値で、階数 $r < d$ の場合に Cholesky 分解は零の対角で止まる。
そこで `MultivariateNormal` は対称固有分解 $\Sigma = Q\Lambda Q^{\mathsf T}$ を使い、正の固有値の組だけで $B = Q_r\Lambda_r^{1/2}$ を作る。

`MultivariateNormal::new(&mean, &covariance)` は平均を `&[S]` で、共分散を `&Matrix<S>` か（ストライド付きでもよい）`MatrixView<S>` で受け取り、どちらも複製してから次の順に準備する。
`MultivariateNormal::with_options(&mean, &covariance, rank_options, options)` は階数の規則 `MultivariateNormalOptions<S>` と、許容誤差と作業量の上限 `LawOptions<S>` を取り、`new` はどちらも既定値を使う。

1. 有限な値、正方の形、対称な成分が浮動小数点数として等しいこと、非負の対角を確かめる。
   対称性は丸めを許さないので、計算で作った共分散は呼び出し側で対称にそろえる。
2. 成分の最大絶対値 $s$ で割って $\Sigma/s$ にし、固有値の計算で桁あふれや下位桁あふれが起きないようにする。
   割った結果 0 になる非零の成分があれば、`NumericalInstability`（`Underflow`）を返す。
3. 正規化した行列を対称固有分解する。
   後退安定な固有値の計算は $d\varepsilon\lambda_{\max}$ 程度の誤差を持つので、$-8d\varepsilon\lambda_{\max}$ より小さい固有値があるときだけ半正定値でないとして `DomainError` を返し、それより小さな負の値は丸めの誤差として扱う。
4. `RankPolicy` が決める閾値を超える固有値だけを残し、その個数を階数 $r$ とする。
   残した方向の標準偏差 $\sqrt{s\lambda_j}$ と擬似行列式の対数 $\sum_j \ln(s\lambda_j)$ を、$s$ を戻して計算する。

`MultivariateNormalOptions` が持つのは `rank_policy`（`with_rank_policy` で設定）だけで、共分散に正則化を加える機能は持たない。
`RankPolicy`（`scioxide-linalg`）の三つの値は、正規化した固有値に対して次の閾値を与える。

| `RankPolicy` | 閾値（正規化した単位） | 用途 |
|---|---|---|
| `DimensionScaledEpsilon`（既定） | $d\varepsilon\lambda_{\max}$ | 丸めの大きさの固有値を落とす |
| `Exact` | 0 | 正の固有値をすべて残す |
| `Threshold(t)` | $t_{\mathrm{abs}}/s + t_{\mathrm{rel}}\lambda_{\max}$ | 共分散の単位で指定した絶対値と相対値の和 |

閾値以下の固有値はすべて落ちるので、既定では丸めの大きさの固有値が誤って次元を増やすことはない。
準備は $O(d^3)$ の時間と $O(d^2)$ のメモリ領域を使い、一つの標本は $r$ 個の標準正規乱数から $O(dr)$ で作る。
`rank()` は残した階数、`support_basis()` は台の向きを表す $d \times r$ の正規直交基底、`covariance()` は残した成分から作り直した共分散を返す。
`dimension()` は次元 $d$、`location()` は平均 $\boldsymbol{\mu}$、`rank_options()` と `options()` は構築に使った二つの設定を返す。

特異な分布（$r < d$）の標本は、$\boldsymbol{\mu}$ を通り $Q_r$ の列が張る $r$ 次元のアフィン部分空間に乗る。
`contains_support(x, tolerance)` は台への射影の残差を最大値ノルムで測り、

$$
\bigl\|(I - Q_rQ_r^{\mathsf T})(\mathbf{x} - \boldsymbol{\mu})\bigr\|_\infty \le \tau_{\mathrm{abs}} + \tau_{\mathrm{rel}}\,\|\mathbf{x} - \boldsymbol{\mu}\|_\infty
$$

を満たすかを返す。
$\tau_{\mathrm{abs}}$ と $\tau_{\mathrm{rel}}$ は `Tolerance` の絶対と相対の許容誤差で、全階数の分布は有限なすべての点を台に含む。
$d$ 次元の Lebesgue 測度に対する密度は存在しないので、`log_pseudo_density(x, tolerance)` は台の上の $r$ 次元の測度に対する対数密度

$$
\ln f_r(\mathbf{x}) = -\frac{1}{2}\Bigl[r\ln(2\pi) + \sum_{j=1}^{r}\ln(s\lambda_j) + \sum_{j=1}^{r}\frac{\bigl(\mathbf{q}_j^{\mathsf T}(\mathbf{x} - \boldsymbol{\mu})\bigr)^2}{s\lambda_j}\Bigr]
$$

を返し、台の外では $-\infty$ を返す。
ここで $\lambda_j$ は正規化した $\Sigma/s$ の固有値、$\mathbf{q}_j$ はその固有ベクトルなので、$s\lambda_j$ が $\Sigma$ の固有値である。
特異な分布に `LogDensity::log_pdf` を呼ぶと、擬似密度を使うよう求める `InvalidInput` になる。
台の判定と擬似密度は $O(dr)$ で、特異な分布では呼び出しごとに $O(d + r)$ の作業領域を確保する。
`evaluate_support` と `evaluate_log_pseudo_density` は標本化と同じ作業領域（`dimension + rank` 要素）を受け取り、確保せずに評価する。
階数の規則が標本と擬似密度をどう変えるかは、[半正定値共分散の正規分布と台](../../examples/singular-normal-support/)で確かめられる。

## 多変量の分布

ベクトル値の分布はどれも次の四つの形で標本を作る。

- `sample` は一つの標本を所有した `Vec` で返す。
- `sample_n` は $n$ 個を行ごとに並べた所有の `Vec` で返す。
- `sample_n_into` は呼び出し側の行バッファーに `SamplingPolicy` に従って行ごとに書き、失敗した行は出力に反映しない。
- `sample_indexed_into` は行 $i$ を `root.split(i)` の部分系列で作るので、結果は実行方針によらない。

`sample_width` は一つの標本の要素数、`workspace_requirements(policy, n)` と `workspace(policy, n)` は一括生成の作業領域を返し、行列値の分布は行優先に平らにした標本を返す。
表の分布のコンストラクターは既定の `LawOptions` を使い、同じ引数の後に設定を取る `with_options` が精度と上限を変える（`MultivariateNormal` と `MultivariateStudentT` はその前に `MultivariateNormalOptions` も取る）。

| 分布 | コンストラクター | 標本の空間 | 生成のアルゴリズム |
|---|---|---|---|
| `MultivariateNormal` | `new(&mean, &covariance)` | $\boldsymbol{\mu} + \operatorname{span}Q_r \subset \mathbb{R}^d$ | 固有分解の因子 $B = Q_r\Lambda_r^{1/2}$ と $r$ 個の標準正規乱数 |
| `MultivariateStudentT` | `new(&location, &shape, df)`、極限は `gaussian_limit(&location, &shape)` | 同上 | $\boldsymbol{\mu} + B\mathbf{Z}\sqrt{\nu/W}$（$W \sim \chi^2_\nu$ は対数で作る） |
| `Dirichlet` | `new(&alpha)`、$\alpha_i > 0$ | 単体 $\{x_i \ge 0, \sum x_i = 1\}$ | 独立な $\mathrm{Gamma}(\alpha_i, 1)$ を和で割る。最大値で割ってから和を取り、$\alpha_i < 1$ があれば対数から正規化する |
| `Multinomial` | `new(trials, &probabilities)` | 和が `trials` の計数 | 条件付きの二項分布を順に引く |
| `DirichletMultinomial` | `new(trials, &alpha)` | 和が `trials` の計数 | 条件付きのベータ二項分布を順に引き、Dirichlet ベクトルを作らない |
| `MultivariateHypergeometric` | `new(&population, draws)` | 各色が母集団の数以下の計数 | 一色ずつ残りの色に対する超幾何分布を引き、最後の色は残りの数 |
| `RandomTable` | `new(&rows, &cols)` | 周辺和を固定した分割表（行優先） | 各行を残りの列和からの多変量超幾何分布で引き、最後の行は残り |
| `NormalInverseGamma` | `new(mu, lambda, alpha, beta)` | $\mathbb{R} \times (0, \infty)$ | $v \sim \mathrm{InvGamma}(\alpha, \beta)$、$x \mid v \sim \mathcal{N}(\mu, v/\lambda)$ で $[x, v]$ を返す |

`MultivariateStudentT` の `shape` は共分散ではなく尺度行列で、$\nu > 2$ の共分散は $\nu/(\nu - 2)$ 倍の尺度行列である。
平均は $\nu > 1$、分散は $\nu > 2$ でだけ定義され、それ以外では未定義のモーメントとしてエラーを返す。
階数の判定、台の判定、擬似密度は `MultivariateNormal` と同じ規則に従う。
楕円型の分布として提供するのは多変量 t（とその正規の極限）だけで、一般の動径分布を指定する楕円型の分布は提供しない。

計数のベクトルの分布は確率質量の対数を条件付きの一変量の質量の和として組み立て、大きな対数階乗の差を作らない。
`Multinomial` は確率の和が $8k\varepsilon$（$k$ はカテゴリ数）以内で 1 であることを確かめてから正規化し、確率 0 のカテゴリは標本に現れない。
`NormalInverseGamma` の位置は一次元で、ベクトルの位置を持つ正規逆ガンマ分布は提供しない。
ベクトルの場合は分散 $v$ を逆ガンマ分布から引き、平均 0 で共分散 $\Sigma$ の `MultivariateNormal` の標本を $\sqrt{v/\lambda}$ 倍して $\boldsymbol{\mu}$ を足す。
$v$ は `Gamma::new(alpha, 1/beta)`（[連続分布の変換・棄却・裾野制御](oxref:random-continuous-variate-combinations)）で $1/v$ を引いて逆数を取るか、`Affine::new(GeneralizedGamma::new(alpha, -1.0)?, 0.0, beta)?`（[古典的な連続分布の族](oxref:random-families-other-standard)）から直接引く。
後者は $X^{-1} \sim \mathrm{Gamma}(\alpha, 1)$ の一般化ガンマ分布を $\beta$ 倍したもので、$\mathrm{InvGamma}(\alpha, \beta)$ に等しい。

## 行列と群の分布

| 分布 | コンストラクター | 標本の空間 | 生成のアルゴリズム |
|---|---|---|---|
| `Wishart` | `new(df, &scale)`、$\nu > p - 1$ | $p \times p$ 正定値行列 | Bartlett 分解 $W = LBB^{\mathsf T}L^{\mathsf T}$（$LL^{\mathsf T}$ は尺度、$B$ は下三角で $B_{ii}^2 \sim \chi^2_{\nu - i + 1}$（$i = 1, \dots, p$）、狭義下三角が標準正規） |
| `InverseWishart` | `new(df, &scale)`、$\nu > p - 1$ | $p \times p$ 正定値行列 | $Y = B^{-1}L^{\mathsf T}$ として $Y^{\mathsf T}Y$ |
| `MatrixNormal` | `new(&mean, &row, &col)` | $m \times n$ 行列 | $M + L_UZL_V^{\mathsf T}$（$U = L_UL_U^{\mathsf T}$ は $m \times m$ の行の共分散、$V = L_VL_V^{\mathsf T}$ は $n \times n$ の列の共分散） |
| `MatrixT` | `new(&mean, &row, &col, df)` | $m \times n$ 行列 | $M + S^{1/2}ZL_V^{\mathsf T}$（$S \sim W_m^{-1}(\nu + m - 1, \text{row})$） |
| `OrthogonalGroup` | `new(d)` | $O(d)$ | 標準正規の $d \times d$ 行列を分解し、三角因子の対角が正になるよう直交因子の符号をそろえる（Mezzadri 2007） |
| `SpecialOrthogonalGroup` | `new(d)` | $SO(d)$ | 同上で、行列式が $-1$ なら最後の行の符号を反転する |
| `UnitaryGroup` | `new(d)` | $U(d)$ | 複素正規行列の分解で、対角の位相をそろえる。成分は `Complex` |
| `RandomCorrelation` | `new(&eigenvalues)` | 対角が 1 の相関行列 | Haar の $Q$ で $Q\operatorname{diag}(\lambda)Q^{\mathsf T}$ を作り、Givens 回転で対角を 1 にする（Bendel–Mickey の方法を Davies–Higham の安定な形で使う） |

`MatrixT` の `row` と `col` は共分散ではなく行と列の広がりを表す正定値行列で、一次元では尺度が $\sqrt{\text{row}\cdot\text{col}/\nu}$ の t 分布になる。
Bartlett 分解の対角の $\chi$ 変量は対数で作るので、小さな非整数の自由度でも対角が 0 に落ちない。
それでも出力のスカラー型で対角が 0 に丸まれば、`NumericalInstability`（`Underflow`）を返す。
正定値行列の分布は対称な成分が等しいことと Cholesky 分解の成否で台を判定する。
密度の二次形式 $\operatorname{tr}(\Sigma^{-1}X)$ や $\operatorname{tr}(V^{-1}A^{\mathsf T}U^{-1}A)$ は、逆行列を作らずに Cholesky 分解による解で評価する。
各群と相関行列の一つの標本は $O(d^3)$ の手間である。

直交群の Haar 測度は群のどの元を掛けても変わらない唯一の確率測度である。
成分が独立な標準正規の行列 $G$ は、直交行列 $H$ を右から掛けても分布が変わらない。
$G = RQ$ と分解して三角因子 $R$ の対角を正にそろえると分解は一意になり、$GH = R(QH)$ から $GH$ の直交因子は $QH$ になる。
$GH$ と $G$ は同じ分布なので、$QH$ と $Q$ も同じ分布に従い、$Q$ の分布は Haar 測度になる。
符号をそろえない分解の直交因子は、分解の実装の符号の選び方が $G$ に依存するので、この不変性を持たない。
`SpecialOrthogonalGroup` は、最後の行の反転が $O(d) \setminus SO(d)$ から $SO(d)$ への測度を保つ全単射であることを使い、$O(d)$ の Haar 測度を $SO(d)$ へ写す。

`RandomCorrelation` は非負で和が $d$ の固有値の列を受け取り、その固有値を持つ相関行列を作る。
回転は固有値を保つので、出力の固有値は指定した列に丸めの範囲で一致する。
この分布は固有値を固定した相関行列の集合の上の一様分布ではない。

## Haar 測度の回転角の検算

$SO(3)$ の元はある軸のまわりの角 $\theta \in [0, \pi]$ の回転で、$\operatorname{tr} Q = 1 + 2\cos\theta$ を満たす。
Haar 測度のもとで回転角の密度は $(1 - \cos\theta)/\pi$ で、小さな角の回転は現れにくい（Miles 1965）。
この密度から $\mathbb{E}[\cos\theta] = -1/2$、$\mathbb{E}[\cos^2\theta] = 1/2$、$\mathbb{E}[\cos^3\theta] = -3/8$、$\mathbb{E}[\cos^4\theta] = 3/8$ が積分で求まり、トレースのモーメントは

$$
\mathbb{E}[\operatorname{tr} Q] = 0,\qquad \mathbb{E}[(\operatorname{tr} Q)^2] = 1,\qquad \mathbb{E}[(\operatorname{tr} Q)^4] = 3
$$

になる。
したがって $\operatorname{Var}(\operatorname{tr} Q) = 1$、$\operatorname{Var}((\operatorname{tr} Q)^2) = 2$ で、$n$ 個の標本の平均の標準誤差は $\sqrt{1/n}$ と $\sqrt{2/n}$ である。

次のセルは `SpecialOrthogonalGroup::<f64>::new(3)` から $n$ 個の回転を作り、回転角の度数を 10° 幅の 18 区間で数えて密度 $(1 - \cos\theta)/\pi$ と比べる。
区間 $[a, b]$ の確率は $\bigl[(\theta - \sin\theta)/\pi\bigr]_a^b$ で、図の帯はその区間の平均密度の $\pm 2$ SE である。
最初の表はトレースの二つのモーメントの標本平均と理論値、$z = (\text{推定} - \text{理論})/\mathrm{SE}$ を出す。
二つ目の表は標本ごとに直接計算した $Q^{\mathsf T}Q - I$ の成分の最大の絶対値と $\lvert\det Q - 1\rvert$ の最大値を出す。
入力は標本数 $n$ と SplitMix64 のシードである。

```rust
//| id: random-haar-rotation-angle
//| ref: random-haar-rotation-angle
//| title: SO(3) の Haar 測度の回転角とトレースのモーメントを確かめる
//| run: reactive
//| crates: [scioxide-core, scioxide-random]
//| inputs:
//|   sample_count: {"type":"range","label":"回転の標本数 n [個]","description":"度数とモーメントの標準誤差を 1/√n で変える。","min":1000,"max":20000,"step":1000,"value":5000}
//|   seed: {"type":"range","label":"SplitMix64 のシード [-]","description":"z の値の標本ごとの揺らぎを見る。","min":1,"max":1000,"step":1,"value":3}
//| cases:
//|   - {"id":"large","label":"n = 20000","description":"標準誤差が半分になり、度数が密度の曲線に近づく。","inputs":{"sample_count":20000}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"moments","path":"/rows/0/3","range":{"min":-4.5,"max":4.5}}
//|       - {"artifact":"moments","path":"/rows/1/3","range":{"min":-4.5,"max":4.5}}
//|       - {"artifact":"structure","path":"/rows/0/0","range":{"min":0,"max":1e-14}}
//|       - {"artifact":"structure","path":"/rows/0/1","range":{"min":0,"max":1e-14}}
//|   - case: large
//|     expect:
//|       - {"artifact":"moments","path":"/rows/1/3","range":{"min":-4.5,"max":4.5}}
use scioxide_core::{NumericScalar, RealScalar};
use scioxide_random::{SeedableRng, SpecialOrthogonalGroup, SplitMix64};

let n = sample_count.round() as usize;
let nf = n as f64;
let bins = 18_usize;
let pi = std::f64::consts::PI;
let width = pi / bins as f64;
let law = SpecialOrthogonalGroup::<f64>::new(3).map_err(|e| e.to_string())?;
let mut rng = SplitMix64::from_seed(seed.round() as u64);
let mut counts = vec![0.0_f64; bins];
let (mut first, mut second) = (0.0_f64, 0.0_f64);
let (mut orthogonality, mut determinant) = (0.0_f64, 0.0_f64);
for _ in 0..n {
    // q は行優先の 3 × 3 行列で、q[3i + j] が (i, j) 成分。
    let q = law.sample(&mut rng).map_err(|e| e.to_string())?;
    for i in 0..3 {
        for j in 0..3 {
            let dot: f64 = (0..3).map(|k| q[3 * k + i] * q[3 * k + j]).sum();
            let identity = if i == j { 1.0 } else { 0.0 };
            orthogonality = RealScalar::max(orthogonality, NumericScalar::abs(dot - identity));
        }
    }
    let det = q[0] * (q[4] * q[8] - q[5] * q[7]) - q[1] * (q[3] * q[8] - q[5] * q[6])
        + q[2] * (q[3] * q[7] - q[4] * q[6]);
    determinant = RealScalar::max(determinant, NumericScalar::abs(det - 1.0));
    let trace = q[0] + q[4] + q[8];
    (first, second) = (first + trace, second + trace * trace);
    // 回転角 θ = arccos((tr Q − 1)/2) ∈ [0, π]。丸めで ±1 を超えた値は端に戻す。
    let cosine = RealScalar::clamp((trace - 1.0) / 2.0, -1.0, 1.0);
    let bin = ((RealScalar::acos(cosine) / width) as usize).min(bins - 1);
    counts[bin] += 1.0;
}
// 独立検算: 区間の確率 [(θ − sin θ)/π]ₐᵇ と、その平均密度の ±2 SE。
let (mut band, mut observed) = (Vec::new(), Vec::new());
for (b, &count) in counts.iter().enumerate() {
    let (a, c) = (b as f64 * width, (b + 1) as f64 * width);
    let p = ((c - RealScalar::sin(c)) - (a - RealScalar::sin(a))) / pi;
    let se = RealScalar::sqrt(p * (1.0 - p) / nf) / width;
    let (center, mean_density) = ((a + 0.5 * width) * 180.0 / pi, p / width);
    band.push([
        center,
        mean_density,
        mean_density - 2.0 * se,
        mean_density + 2.0 * se,
    ]);
    observed.push([center, count / (nf * width)]);
}
let density: Vec<[f64; 2]> = (0..=90)
    .map(|i| {
        let theta = pi * i as f64 / 90.0;
        [theta * 180.0 / pi, (1.0 - RealScalar::cos(theta)) / pi]
    })
    .collect();
emit_chart!(
    serde_json::json!({
        "kind": "xy",
        "xLabel": "回転角 θ [°]",
        "yLabel": "確率密度 [1/rad]",
        "dataZoom": true,
        "tooltip": true,
        "layers": [
            {"id": "band", "kind": "band", "name": "区間の平均密度 ± 2 SE", "points": band},
            {
                "id": "density",
                "kind": "line",
                "name": "(1 − cos θ)/π",
                "style": {"lineType": "dashed"},
                "points": density
            },
            {"id": "observed", "kind": "scatter", "name": "標本の度数密度", "points": observed}
        ]
    }),
    metadata = serde_json::json!({ "id": "angles" })
);
let fixed4 = serde_json::json!({ "fractionDigits": 4 });
let fixed2 = serde_json::json!({ "fractionDigits": 2 });
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let moment_columns = serde_json::json!([
    { "key": "0", "label": "量" },
    { "key": "1", "label": "標本平均 [-]", "type": "number", "format": fixed4 },
    { "key": "2", "label": "Haar 測度の理論値 [-]", "type": "number", "format": fixed4 },
    { "key": "3", "label": "z [-]", "type": "number", "format": fixed2 }
]);
// 標準誤差は Var(tr Q) = 1 と Var((tr Q)²) = 2 から作る。
let (mean, square) = (first / nf, second / nf);
let (se_mean, se_square) = (RealScalar::sqrt(1.0 / nf), RealScalar::sqrt(2.0 / nf));
emit_table_with_columns!(
    moment_columns,
    vec![
        ("tr Q", mean, 0.0, mean / se_mean),
        ("(tr Q)²", square, 1.0, (square - 1.0) / se_square),
    ],
    metadata = serde_json::json!({ "id": "moments" })
);
let structure_columns = serde_json::json!([
    { "key": "0", "label": "max |QᵀQ − I| [-]", "type": "number", "format": sci2 },
    { "key": "1", "label": "max |det Q − 1| [-]", "type": "number", "format": sci2 }
]);
emit_table_with_columns!(
    structure_columns,
    vec![(orthogonality, determinant)],
    metadata = serde_json::json!({ "id": "structure" })
);
```

既定値（$n = 5\,000$、シード 3）では、$\operatorname{tr} Q$ の標本平均が $-0.0066$（$z = -0.47$）、$(\operatorname{tr} Q)^2$ の標本平均が $1.0107$（$z = 0.54$）で、どちらも理論値と 1 SE 以内で一致する。
シードを 1 と 1000 に変えると $z$ は $-0.77$ から $1.81$ の範囲に入り、$n = 20\,000$ では $0.24$ と $0.22$ になる。
回転角の度数密度は、$\theta$ が 0 に近いほど小さく、$\pi$ に近づくと $2/\pi \approx 0.64$ rad⁻¹ へ増える曲線 $(1 - \cos\theta)/\pi$ に沿う。
既定値では 18 区間のうち 16 区間が $\pm 2$ SE の帯に入り、帯の外に出る区間は一つあたり約 4.6% の割合で現れるので、2 区間の外れは偏りの証拠にならない。
$Q^{\mathsf T}Q - I$ の成分の絶対値は最大 $1.1 \times 10^{-15}$、$\lvert\det Q - 1\rvert$ は最大 $8.9 \times 10^{-16}$ で、直交性と行列式は丸めの大きさで成り立つ。
符号をそろえない分解の直交因子も直交行列なので、直交性からは Haar 測度かどうかを判断できず、回転角の度数とトレースのモーメントで確かめる。

## まとめ

`MultivariateNormal` は共分散を最大成分で正規化してから対称固有分解し、`RankPolicy` の閾値（既定は $d\varepsilon\lambda_{\max}$）を超える固有値だけを残すので、半正定値の共分散も扱える。
特異な分布は台の判定と $r$ 次元の擬似密度で扱い、`log_pdf` は使えない。
ベクトル、行列、群の分布は、それぞれの構造に合った分解（条件付きの一変量の抽出、Bartlett 分解、符号をそろえた直交分解）で標本を作る。
自作の分解で群の元を作ると、三角因子の対角の符号をそろえない限り Haar 測度にならない。
群の標本には `OrthogonalGroup`、`SpecialOrthogonalGroup`、`UnitaryGroup` を使い、Haar 測度に従うかは直交性ではなく回転角やトレースのモーメントで確かめる。
