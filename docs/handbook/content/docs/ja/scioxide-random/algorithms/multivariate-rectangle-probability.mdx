信頼性解析の同時の故障確率や多重比較の同時信頼区間の被覆確率は、相関のある正規ベクトルが矩形に入る確率 $P(\mathbf{a} < \mathbf{X} \le \mathbf{b})$ で表せる。
一般の矩形と相関では初等関数の閉形式がないので、`scioxide-random` は Genz の変数分離で滑らかな被積分関数に直し、ランダム化した準乱数で積分して、誤差の推定と終了状態を返す。
このページは変数分離による変換、Plan の準備、誤差の推定、終了状態と閉形式で答える場合、作業領域の使い回しを説明する。
分布そのものの準備（固有分解と階数）は[多変量正規分布の固有分解と特異な台](oxref:random-multivariate-normal-eigen)にある。

## 多変量同時確率の数値計算

$\mathbf{X} = \boldsymbol{\mu} + L\mathbf{Z}$（$\mathbf{Z}$ は $r$ 個の独立な標準正規変数）の矩形確率 $P(\mathbf{a} < \mathbf{X} \le \mathbf{b})$ を考える。
$L$ が対角が正の $d \times r$ の下台形行列なら、$i$ 番目の拘束は $Z_1, \dots, Z_{i-1}$ を固定したとき $Z_i$ の区間

$$
\alpha_i = \frac{a_i - \mu_i - \sum_{k<i}L_{ik}z_k}{L_{ii}},\qquad
\beta_i = \frac{b_i - \mu_i - \sum_{k<i}L_{ik}z_k}{L_{ii}}
$$

に書ける。
Genz の変数分離は各段で区間の正規確率 $e_i = \Phi(\beta_i) - \Phi(\alpha_i)$ を重みに掛け、一様な座標 $u_i$ から $z_i = \Phi^{-1}\bigl(\Phi(\alpha_i) + u_i e_i\bigr)$ と切断正規分布の次の座標を作る。
$\Phi$ は標準正規分布の分布関数である。
確率は単位超立方体 $[0, 1]^{r-1}$ 上の積分 $\int e_1(\mathbf{u})\cdots e_r(\mathbf{u})\,d\mathbf{u}$ になり、被積分関数は滑らかで値は $[0, 1]$ に収まる。
多変量 t 分布 $\mathbf{X} = \boldsymbol{\mu} + L\mathbf{Z}/\sqrt{W/\nu}$ では、もう一つの座標から $\chi^2_\nu$ の分位点で $W$ を作り、中心化した上下限に $\sqrt{W/\nu}$ を掛けてから同じ積分を行う。

`prepare_probability(options, &root)` は、残した因子 $B$ から列の枢軸選択付きの Householder LQ 分解で下台形の因子を作り、対角の符号を正にそろえて `MultivariateProbabilityPlan` を返す。
列の符号を潜在変数の符号と一緒に反転しても分布は変わらないので、この正規化は確率を変えない。
準備は $O(d^2 r)$ の手間で、同じ Plan で複数の矩形を評価すれば分解と点列の準備を使い回せる。
Sobol 点列の次元は $d$ ではなく残した階数 $r$（多変量 t では尺度の座標を加えて $r + 1$）で、正規の場合に被積分関数が使うのはそのうち $r - 1$ 個の座標である。

評価のたびに、周辺の区間確率が小さい拘束から先に積分するよう、先頭の $r$ 個の拘束を並べ替えて因子を作り直す（Genz–Bretz の並べ替え）。
確率を強く絞る拘束を先に積分すると、被積分関数の変動が Sobol 点列の先頭の座標に集まり、推定の分散が小さくなる。

## ランダム化した Sobol 点列と誤差の推定

Plan の `rectangle(&lower, &upper)` は `prepare_probability` に渡した Philox の根 `root` から作った互いに独立なランダム化（Matoušek の線形行列の攪拌と桁ごとのずらし）を持つ Sobol 点列の複製を使い、新しい作業領域を確保して呼び出したスレッドの上で評価する。
`rectangle_scoped(&lower, &upper, &mut workspace, scope)` は作業領域を使い回し、複製を実行の範囲（`ExecutionContext` か、外側の求解の `SolveContext`）のエグゼキューターで走らせ、被積分関数の各評価の前に取り消しと期限を確かめる。
結果は実行の順序によらず、逐次の範囲では `rectangle` と同じレポートになる。

複製の数を $R$（既定 8）、一つの複製の点数を $N$（2 の冪、既定 65,536）とすると、求積をするときの評価回数は常に $RN$ で、精度に応じて点を増やす適応はしない。
一つの評価は $O(dr)$ の手間である。
複製ごとの平均 $\hat{p}_1, \dots, \hat{p}_R$ はそれぞれ偏りのない推定で、返す確率はその平均 $\bar{p}$、`estimated_absolute_error` は複製ごとの平均から求めた標準誤差の 6 倍

$$
6\,\mathrm{SE} = 6\sqrt{\frac{1}{R(R-1)}\sum_{j=1}^{R}(\hat{p}_j - \bar{p})^2}
$$

である。
複製ごとの平均は対数で持ち、最大のもので割ってから平均するので、非常に小さい確率でも下位桁あふれしない。
6 SE は経験的な見積もりで、証明された上界ではない。
複製の平均が正規分布に従うと仮定すると、$\bar{p}$ の誤差が 6 SE を超える確率は自由度 $R - 1 = 7$ の t 分布で $P(|t_7| > 6) \approx 5.4 \times 10^{-4}$ である。

## レポートと終了状態

`MultivariateProbabilityReport` は `probability`、下位桁あふれでも残る `log_probability`、`estimated_absolute_error` とその対数、`evaluations`、`termination` を持つ。
`termination`（`MultivariateProbabilityTermination`）が唯一の判定で、6 SE が $\tau_{\mathrm{abs}} + \tau_{\mathrm{rel}}\,\bar{p}$ 以下なら `Converged`、指定した点をすべて評価しても届かなければ `AccuracyNotMet` になる。
$\tau_{\mathrm{abs}}$ と $\tau_{\mathrm{rel}}$ は設定の `Tolerance` の絶対と相対の許容誤差である。
`AccuracyNotMet` はエラーではなく、推定値と推定誤差はそのまま使える。
すべての複製で被積分関数が 0 だったときは、確率 0、推定誤差 1 の `AccuracyNotMet` になる。

次の場合は求積をせずに閉形式で答え、評価回数 0 の `Converged` を返す。

- 上下限が等しい成分があれば確率 0、階数 0 なら点質量が矩形に入るかで 0 か 1 になる。
- 階数 1 なら一つの潜在変数の区間確率になる（多変量 t では一変量の t 分布の区間確率）。
- 正規で全階数かつ因子が対角なら、成分が独立なので一次元の区間確率の積になる。

上下限の長さが $d$ でなければ `DimensionMismatch`、NaN の上下限や $a_i > b_i$ は `InvalidInput` を返す。

## 設定、作業領域、分布の簡便な問い合わせ

`MultivariateProbabilityOptions` は次の値を持つ。

| 設定 | 既定値 | 準備での確認 |
|---|---|---|
| `tolerance` | 絶対・相対とも $\sqrt{\varepsilon}$ | どの `Tolerance` も受け付ける |
| `points_per_replicate` | 65,536 | 2 の冪でなければ `InvalidInput` |
| `replicates` | 8 | 2 未満なら `InvalidInput` |
| `work_budget` | 524,288 回 | $RN$ がこれを超えると `ConvergenceFailure` |
| `max_bytes` | 64 MiB | Plan と作業領域が超えると `ResourceLimit` |
| `execution_policy` | 逐次 | 結果は実行方針によらない |

`MultivariateProbabilityWorkspace` は複製ごとの条件付きの座標と点列の座標、並べ替えた因子、上下限を持ち、`plan.workspace()` で一度確保すれば同じ Plan の評価で使い回せる。
`rectangle_scoped` は作業領域の形（次元、階数、複製の数、点列の次元）だけを確かめ、形の合わない作業領域には `InvalidInput` を返す。
形が同じなら別の Plan で作った作業領域も受け付け、エラーの後の作業領域の中身は定まらない。

分布の `rectangle(&lower, &upper, &root)`（`MultivariateNormal` と `MultivariateStudentT`）は、分布の `LawOptions` の許容誤差、作業量、メモリ領域の上限から Plan を作って矩形を一つ評価し、確率の値だけを返す。
複製の数は作業量の上限と 8 の小さい方、一つの複製の点数は作業量の上限を複製の数で割った値以下の最大の 2 の冪で、既定の `LawOptions`（作業量 65,536）では 8 複製 × 8,192 点になる。
`Converged` でなければ `ConvergenceFailure` を返すので、レポートを読みたいときや複数の矩形を同じ Plan で評価するときは `prepare_probability` を使う。
`Cdf`、`Survival` などのトレイトの問い合わせも同じ Plan をシード 0 の根 `Philox4x64::from_seed(0)` で作り、`cdf(x)` は下限を $-\infty$ にした `rectangle` のシード 0 での値に等しい。
相関のある階数 2 以上の分布は既定の許容誤差 $\sqrt{\varepsilon}$ をほとんど満たさないので、これらの形には `with_options` で緩い許容誤差を与えた分布を使う。

## 象限確率で推定誤差を確かめる

次のセルは相関係数 $\rho$ の二変量標準正規分布の象限確率 $P(X_1 \le 0, X_2 \le 0)$ を、複製の点数 $N = 2^6$ から $2^{13}$ までの 8 通りで求める。
独立検算には Sheppard の閉形式 $1/4 + \arcsin(\rho)/(2\pi)$ を使う。
入力は相関係数（無次元、$-1$ から $1$）、絶対許容誤差の指数、Philox のシードで、複製の数は既定の 8 のままにする。
図は評価回数に対する推定誤差 6 SE（破線）と閉形式との実際の誤差（記号）を両対数で描き、横線は絶対許容誤差である。
表は点数ごとの推定値、二つの誤差、終了状態を出す。
最後の outcome は最も多い点数 $N = 2^{13}$ の終了状態をセルの結論として示し、閉形式の値と閉形式との差を診断値に添える。

```rust
//| ref: random-mvn-orthant-probability
//| title: 二変量正規分布の象限確率で推定誤差と実際の誤差を比べる
//| run: reactive
//| crates: [scioxide-core, scioxide-linalg, scioxide-random]
//| inputs:
//|   correlation: {"type":"range","label":"相関係数 ρ [-]","description":"±1 では階数が 1、0 では共分散が対角になり、どちらも閉形式で評価される。","min":-1,"max":1,"step":0.05,"value":0.5}
//|   tolerance_exponent: {"type":"range","label":"許容誤差の指数 t（絶対許容誤差 10ᵗ）","description":"推定誤差 6 SE と比べる絶対許容誤差を変える。","min":-7,"max":-3,"step":1,"value":-5}
//|   seed: {"type":"range","label":"Philox のシード [-]","description":"Sobol 点列の 8 個のランダム化を決める。","min":1,"max":1000,"step":1,"value":7}
//| cases:
//|   - {"id":"strong-negative","label":"ρ = −0.9","description":"確率が 0.0718 と小さく、同じ点数でも推定誤差の相対的な大きさが変わる。","inputs":{"correlation":-0.9}}
//|   - {"id":"independent","label":"ρ = 0","description":"共分散が対角なので求積をせず、評価回数 0 の閉形式で 1/4 を返す。","inputs":{"correlation":0}}
//|   - {"id":"degenerate","label":"ρ = 1","description":"階数が 1 になり、一つの潜在変数の区間確率 1/2 を閉形式で返す。","inputs":{"correlation":1}}
//|   - {"id":"strong-positive","label":"ρ = 0.95","description":"相関が強く、一つ目の座標で積分の大部分が決まるので、実際の誤差が小さい。","inputs":{"correlation":0.95}}

//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"points","path":"/rows/0/5","equals":"AccuracyNotMet"}
//|       - {"artifact":"points","path":"/rows/7/5","equals":"Converged"}
//|       - {"artifact":"points","path":"/rows/7/2","approx":{"value":0.3333333,"atol":2e-6}}
//|       - {"artifact":"points","path":"/rows/7/3","range":{"min":1e-8,"max":5e-6}}
//|       - {"artifact":"points","path":"/rows/7/4","range":{"min":0,"max":5e-6}}
//|       - {"path":"/outputs/2/state","equals":"satisfied"}
//|   - case: strong-negative
//|     expect:
//|       - {"artifact":"points","path":"/rows/7/2","approx":{"value":0.0717831,"atol":2e-6}}
//|   - case: independent
//|     expect:
//|       - {"artifact":"points","path":"/rows/0/1","equals":0}
//|       - {"artifact":"points","path":"/rows/0/2","approx":{"value":0.25,"atol":1e-15}}
//|       - {"path":"/outputs/2/state","equals":"satisfied"}
//|   - case: degenerate
//|     expect:
//|       - {"artifact":"points","path":"/rows/0/1","equals":0}
//|       - {"artifact":"points","path":"/rows/0/2","approx":{"value":0.5,"atol":1e-15}}
//|   - case: tight
//|     expect:
//|       - {"artifact":"points","path":"/rows/7/5","equals":"AccuracyNotMet"}
//|       - {"path":"/outputs/2/state","equals":"partial"}
use scioxide_core::{NumericScalar, RealScalar, Tolerance};
use scioxide_linalg::Matrix;
use scioxide_random::{
    MultivariateNormal, MultivariateProbabilityOptions, MultivariateProbabilityTermination,
    Philox4x64, SeedableRng,
};

let rho = correlation;
let covariance = Matrix::from_vec(2, 2, vec![1.0, rho, rho, 1.0]).map_err(|e| e.to_string())?;
let law = MultivariateNormal::new(&[0.0; 2], &covariance).map_err(|e| e.to_string())?;
let tolerance = RealScalar::powi(10.0, tolerance_exponent.round() as i32);
// 独立検算: Sheppard の閉形式 P(X₁ ≤ 0, X₂ ≤ 0) = 1/4 + asin(ρ)/(2π)。
let exact = 0.25 + RealScalar::asin(rho) / (2.0 * std::f64::consts::PI);
let root = Philox4x64::from_seed(seed.round() as u64);
let (mut estimated_curve, mut actual_curve, mut rows) = (Vec::new(), Vec::new(), Vec::new());
let mut last = None;
for k in 6..=13_u32 {
    // 8 個のランダム化した Sobol 点列に、それぞれ 2ᵏ 点を使う。
    let options = MultivariateProbabilityOptions::default()
        .with_points_per_replicate(1 << k)
        .with_tolerance(Tolerance::new(tolerance, 0.0).map_err(|e| e.to_string())?);
    let plan = law
        .prepare_probability(options, &root)
        .map_err(|e| e.to_string())?;
    let report = plan
        .rectangle(&[f64::NEG_INFINITY; 2], &[0.0; 2])
        .map_err(|e| e.to_string())?;
    let actual = NumericScalar::abs(report.probability - exact);
    let total = report.evaluations as f64;
    // 対数軸に描けない 0 の誤差（閉形式で答えた場合など）は図から除き、表に残す。
    if report.estimated_absolute_error > 0.0 {
        estimated_curve.push([total, report.estimated_absolute_error]);
    }
    if actual > 0.0 {
        actual_curve.push([total, actual]);
    }
    let termination = match report.termination {
        MultivariateProbabilityTermination::Converged => "Converged",
        MultivariateProbabilityTermination::AccuracyNotMet => "AccuracyNotMet",
    };
    rows.push((
        1_usize << k,
        report.evaluations,
        report.probability,
        report.estimated_absolute_error,
        actual,
        termination,
    ));
    last = Some((report, actual, termination));
}
emit_line_chart!(
    &vec![
        serde_json::json!({
            "name": "推定誤差 6 SE",
            "points": estimated_curve,
            "style": {"lineType": "dashed"}
        }),
        serde_json::json!({
            "name": "閉形式との実際の誤差",
            "points": actual_curve,
            "style": {"symbol": "circle", "lineType": "dotted"}
        }),
    ],
    options = &serde_json::json!({
        "xLabel": "被積分関数の評価回数 [回]",
        "yLabel": "絶対誤差 [-]",
        "xType": "log",
        "yType": "log",
        "annotations": [{"kind": "line", "axis": "y", "value": tolerance, "label": "絶対許容誤差"}]
    })
);
let fixed7 = serde_json::json!({ "fractionDigits": 7 });
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let columns = serde_json::json!([
    { "key": "0", "label": "複製あたりの点数 N", "type": "integer" },
    { "key": "1", "label": "評価回数 [回]", "type": "integer" },
    { "key": "2", "label": "推定した確率 [-]", "type": "number", "format": fixed7 },
    { "key": "3", "label": "推定誤差 6 SE [-]", "type": "number", "format": sci2 },
    { "key": "4", "label": "閉形式との実際の誤差 [-]", "type": "number", "format": sci2 },
    { "key": "5", "label": "終了状態" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "points" })
);
// セルの結論は、最も多い点数 N = 2¹³ の終了状態で決める。
let (report, actual, status) = last.ok_or("点数の列が空")?;
let outcome = if report.termination == MultivariateProbabilityTermination::Converged {
    Outcome::satisfied("N = 2¹³ の推定誤差 6 SE が許容誤差を満たした")
        .explanation("6 SE は複製のばらつきから見積もった値で、上界ではない。")
} else {
    Outcome::partial("N = 2¹³ を評価しても推定誤差 6 SE が許容誤差に届かなかった")
        .explanation("推定値はそのまま使える。点数か複製の数を増やして Plan を作り直す。")
};
emit_outcome!(
    outcome
        .status(status)
        .diagnostic("評価回数", report.evaluations as f64, None)
        .diagnostic("推定誤差 6 SE", report.estimated_absolute_error, None)
        .diagnostic("閉形式 1/4 + asin(ρ)/(2π)", exact, None)
        .diagnostic("閉形式との差", actual, None)
);
```

既定の $\rho = 0.5$（閉形式は $1/3$）、許容誤差 $10^{-5}$、シード 7 では、評価回数 512 の推定誤差 6 SE が $3.5 \times 10^{-4}$、65,536 回で $3.5 \times 10^{-7}$ になる。
評価回数を 128 倍にして誤差がおよそ 1000 分の 1 になるので、減り方は $N^{-1.4}$ 程度で、独立な乱数による Monte Carlo 法の $N^{-1/2}$ より速い。
実際の誤差はどの行でも 6 SE の 0.06 倍から 0.23 倍、すなわち 0.3 SE から 1.4 SE の範囲にあり、推定誤差は実際の誤差を下回っていない。
`termination` は 4,096 回までは `AccuracyNotMet`、8,192 回（6 SE が $5.1 \times 10^{-6}$）からは `Converged` で、outcome は satisfied になる。
シードを 1000 に変えると 8,192 回の 6 SE が $1.05 \times 10^{-5}$ となって許容誤差をわずかに超え、`AccuracyNotMet` が返る。
許容誤差の近くでは、終了状態がランダム化の選び方で変わる。
許容誤差を $10^{-7}$ にすると、65,536 回の 6 SE $3.5 \times 10^{-7}$ でも届かないので、すべての行が `AccuracyNotMet` になり、outcome は partial になる。

$\rho = -0.9$ では確率が $0.07178$ と小さく、1,024 回で `Converged` になり、65,536 回の実際の誤差は $9.2 \times 10^{-12}$ である。
$\rho = 0.95$ でも 8,192 回で実際の誤差は $1.4 \times 10^{-9}$ で、相関が強いほど一つ目の座標で積分の大部分が決まり、残りの座標による変動が小さい。
$\rho = 0$ では因子が対角、$\rho = \pm 1$ では階数が 1 なので、どの点数でも評価回数 0 の閉形式（$1/4$、$1/2$、0）が返り、推定誤差と実際の誤差はどちらも 0 である。
この場合は対数軸に描ける点がなく、図は空になる。

## まとめ

矩形の同時確率は Genz の変数分離で $[0, 1]^{r-1}$ 上の滑らかな積分に直し、ランダム化した Sobol 点列の複製で評価回数を固定して求める。
レポートの `termination` が唯一の判定で、`Converged` は 6 SE が許容誤差を満たしたこと、`AccuracyNotMet` は推定値を使えるが精度が確かめられていないことを表す。
`AccuracyNotMet` なら点数か複製の数を増やして Plan を作り直し、6 SE は経験的な見積もりなので、重要な値は閉形式や別の方法で確かめる。
複数の矩形を評価するときは `prepare_probability` で Plan を一度作り、`rectangle_scoped` で作業領域を使い回す。
