準モンテカルロ法（QMC）は独立な一様乱数の代わりに、単位超立方体をむらなく埋める決定論的な点列で積分を近似する。
独立な点の誤差は $O(N^{-1/2})$ で減るが、点列の一様さを表すディスクレパンシーが小さければ、有界変動の被積分関数の誤差の上界はそれに比例して小さくなる。
このページは `scioxide-random` の QMC 点列の構成と、点数に対するディスクレパンシーの減り方を説明する。
点列の位置の扱い、ランダム化と誤差の推定は[QMC 点列の位置・ランダム化・誤差の推定](../qmc-positions-and-randomization/)で、正規座標を Brownian 経路に割り当てる順序は[Brownian 橋による経路の構成](../brownian-bridge-construction/)で扱う。

## ディスクレパンシーと Koksma–Hlawka の不等式

点集合 $P_N = \{\mathbf{u}_0, \dots, \mathbf{u}_{N-1}\} \subset [0, 1)^d$ のスター・ディスクレパンシーは、原点を角に持つ箱 $[\mathbf{0}, \mathbf{a})$ に入る点の割合と箱の体積の差の上限である。

$$
D_N^*(P_N) = \sup_{\mathbf{a} \in [0, 1]^d} \left| \frac{\#\{n : \mathbf{u}_n \in [\mathbf{0}, \mathbf{a})\}}{N} - \prod_{j=1}^d a_j \right|
$$

$f$ が Hardy–Krause の意味の有界変動 $V_{\mathrm{HK}}(f) < \infty$ を持つとき（$d = 1$ では全変動 $\int_0^1 |f'(x)|\,dx$ に一致する）、Koksma–Hlawka の不等式

$$
\left| \frac{1}{N} \sum_{n=0}^{N-1} f(\mathbf{u}_n) - \int_{[0,1]^d} f \right| \le V_{\mathrm{HK}}(f)\, D_N^*(P_N)
$$

が成り立つ。
これは上界であり、実際の誤差の推定値ではない。
$V_{\mathrm{HK}}(f)$ を計算できる関数は少なく、上界は実際の誤差を大きく上回ることが多い。
低食い違い点列では $D_N^* = O((\log N)^d / N)$ である。
ただし $d$ が大きいと有限の $N$ では対数の因子が支配し、関数の有効な次元が低くなければ独立な点より良くなるとは限らない。
$D_N^*$ の上限を正確に求めるのは高次元で難しいので、`discrepancy` は二乗平均型の $L^2$ ディスクレパンシーを閉形式で計算する（[ディスクレパンシーの尺度](oxref:random-sampling-discrepancy)）。

## Halton 点列

整数 $n \ge 0$ を素数 $b$ を基数として $n = \sum_{i \ge 0} a_i b^i$（$0 \le a_i < b$）と書くと、基数反転は桁を小数点の反対側に折り返した

$$
\phi_b(n) = \sum_{i \ge 0} a_i\, b^{-(i+1)}
$$

である。
$b = 2$ の van der Corput 列は $\phi_2(1), \phi_2(2), \phi_2(3), \dots = 1/2, 1/4, 3/4, 1/8, \dots$ で、新しい点は既存の点の最大の隙間に入る。
$d$ 次元の Halton 点列は異なる素数 $p_1, \dots, p_d$ で $\mathbf{x}_n = (\phi_{p_1}(n), \dots, \phi_{p_d}(n))$ とする。

`QmcPlan::halton(d)` は組み込みの最初の 100 個の素数 $2, 3, \dots, 541$ を使い（$1 \le d \le 100$）、`halton_with_bases` は利用者の素数を受け取って、空でないこと、素数であること、重複しないことを検査する。
基数反転は分子と分母を整数のまま求め、最後に浮動小数点に直して割る。
桁の除算は前もって用意した整数の逆数で正確に行い、$b = 2$ ではビットの反転で求める。
連続する点の一括生成は桁の繰り上がりで分子を整数のまま更新するので、浮動小数点の漸化式のような誤差の蓄積はない。
一点の計算量は $O(d \log n)$ で、状態は添字だけなので任意の添字への移動は $O(1)$ である。

基数が大きい座標では、$n < p_j$ の間 $\phi_{p_j}(n) = n/p_j$ である。
二つの座標の基数 $p_j, p_k$ がどちらも $n$ より大きいうちは、点 $(n/p_j, n/p_k)$ が原点を通る一本の直線に並ぶ。
たとえば $d = 100$ の最後の二つの座標（基数 523 と 541）の二次元射影では、最初の 523 点が一本の直線に並ぶ。

`QmcScramble::DigitPermutation(seed)` は基数ごとに桁 $1, \dots, b-1$ の置換をシードから一つ作り、すべての桁の位置に同じ置換を当てて、この縞を崩す。
桁 0 は動かさないので、先頭に無限に続く 0 の桁は 0 のままで、基数反転は有限の和のままである。
`with_permutations` は利用者が与えた置換を受け取り、基数ごとに一つあること、長さが基数に等しいこと、全単射であること、0 を 0 に写すことを検査する。
`QmcPlan::reverse_halton(d)` は 0 でない桁 $a$ を $b - a$ に置き換えた固定の置換（Vandewoestyne–Cools）で、それ以上のランダム化を受け付けない。
これらの桁置換は点の配置を変えるが、点を一様に分布させるものではない。

## Sobol 点列と Gray 符号

Sobol 点列は二進のデジタル点列である。
座標 $j$ ごとに $\mathbb{F}_2$ 上の生成行列 $C_j$ を決め、$n$ の二進の桁を並べたベクトルに $C_j$ を掛けた桁を二進小数として解釈する。
$C_j$ の第 $i$ 列が方向数 $v_i = m_i / 2^i$ の二進展開である。

方向数は座標ごとに $\mathbb{F}_2$ 上の原始多項式 $x^c + a_1 x^{c-1} + \dots + a_{c-1} x + 1$ と、奇数の初期値 $m_1, \dots, m_c$（$m_i < 2^i$）から、漸化式

$$
m_i = 2 a_1 m_{i-1} \oplus 2^2 a_2 m_{i-2} \oplus \dots \oplus 2^{c-1} a_{c-1} m_{i-c+1} \oplus 2^c m_{i-c} \oplus m_{i-c}
$$

で作る（$\oplus$ はビットごとの排他的論理和）。
$m_i$ が奇数なので $v_i$ の $2^{-i}$ の桁は 1 で、生成行列は対角が 1 の上三角になり、正則である。

デジタル点列の一様さは net の性質で表す。
$2^m$ 点の集合は体積 $2^{t-m}$ のどの基本区間 $\prod_j [a_j 2^{-k_j}, (a_j + 1) 2^{-k_j})$ にもちょうど $2^t$ 点を持つとき $(t, m, d)$-net と呼ぶ。
Sobol 点列では、先頭が $2^m$ の倍数の添字から始まる連続した $2^m$ 点の区画が、$m \ge t$ のどの $m$ についても $(t, m, d)$-net になる。
$t$ が小さいほど細かい箱まで均等に埋まり、$t$ は次元と方向数の選び方で決まる。

点 $n$ の座標は $n$ の Gray 符号 $g(n) = n \oplus \lfloor n/2 \rfloor$ の 1 のビットに対応する方向数の排他的論理和である。
$g(n)$ と $g(n+1)$ は $n+1$ の最下位の 1 のビットの位置 $c$ だけが違うので、$n$ から $n+1$ へは $\mathbf{x}_{n+1} = \mathbf{x}_n \oplus \mathbf{v}_c$ の一回の排他的論理和で進む（Antonov–Saleev）。
Gray 符号は、先頭が $2^m$ の倍数の $2^m$ 個の添字の区画を、自然な順序の別の区画に一対一に写す。
そのため区画が net になる性質は Gray 符号の順でも保たれ、先頭の $2^m$ 点の集合は自然な順序と同じである。

`QmcPlan::sobol(d)` は Joe–Kuo の D(6) 表で 21,201 次元まで使え、二次元射影が良くなるように選ばれた方向数を使う。
先頭の座標ほど射影が良いので、重要な変数を前に置く。
第 1 座標は単位行列を生成行列とする van der Corput 列である。
`sobol_with_direction_numbers(d, source)` は `DirectionNumberSet` を受け取り、`Custom` の `SobolDirection` の列を第 2 座標から順に使う。
`SobolDirection::new(c, a, m)` は次数 $c$ が 1〜32 であること、符号化した多項式が原始多項式であること、初期値が $c$ 個の奇数で $m_i < 2^i$ であることを検査し、満たさなければ `InvalidInput` を返す。

方向数は 64 ビットの整数に左詰めで持ち、点の添字は `u64` で、点列は $2^{64}$ 点を持つ。
出力は 64 ビットのワードの上位から作り、`f64` では 53 ビット、`f32` では 24 ビットが値に現れる。
ランダム化しない Sobol 点列の最初の点は原点である。
一点の計算量は前の点から $O(d)$ で、任意の添字への移動は $O(d \cdot \mathrm{popcount}(g(n)))$ である。

`QmcPlan::niederreiter_base2(d)` は 1〜12 次元の Niederreiter の基数 2 の構成（Bratley–Fox–Niederreiter）で、Sobol 点列と同じく Gray 符号の順に点を作る。
座標 $j$ には $\mathbb{F}_2$ 上の $j$ 番目のモニックな既約多項式 $x, x+1, x^2+x+1, x^3+x+1, \dots$ を使い、構成で自由に選べる Laurent 級数の係数は 1 にする。

## 点数に対するディスクレパンシーの減り方

次のセルは $d$ 次元でランダム化しない Sobol、`DigitalShift` でランダム化した Sobol、Halton、独立な一様点の $L^2$ スター・ディスクレパンシー（`DiscrepancyMethod::L2Star`、二乗平均の平方根）を、$N = 2^4$ から $2^k$ まで比べる。
入力は次元 $d$、点数の上限を決める指数 $k$、ずらしと独立点のシードである。
独立な一様点では $L^2$ スター・ディスクレパンシーの二乗の期待値が $(2^{-d} - 3^{-d})/N$ になるので、その平方根を独立検算の破線で示す。
各方法の点は最大の点数まで一度だけ作り、先頭の $N$ 点で測る。
計算量は $O(N^2 d)$ なので、このセルはボタンで実行する。

```rust
//| id: random-qmc-discrepancy-decay
//| ref: random-qmc-discrepancy-decay
//| title: Sobol・Halton・独立点のディスクレパンシーを点数ごとに比べる
//| run: button
//| crates: [scioxide-core, scioxide-random]
//| inputs:
//|   dimension: {"type":"range","label":"次元 d [-]","min":2,"max":8,"step":1,"value":4}
//|   maximum_exponent: {"type":"range","label":"最大の点数の指数 k（N = 2ᵏ）[-]","min":6,"max":11,"step":1,"value":10}
//|   seed: {"type":"range","label":"乱数のシード（ずらしと独立点）[-]","min":1,"max":1000,"step":1,"value":17}
//| cases:
//|   - {"id":"eight-dimensions","label":"d = 8、k = 9","description":"次元を上げると、Sobol と独立点の差は N = 512 でも小さい。","inputs":{"dimension":8,"maximum_exponent":9}}
//|   - {"id":"two-dimensions","label":"d = 2、シード 99","description":"2 次元では Sobol のディスクレパンシーは独立点より 1 桁以上小さい。","inputs":{"dimension":2,"seed":99}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"decay","path":"/rows/6/0","range":{"min":1024,"max":1024}}
//|       - {"artifact":"decay","path":"/rows/6/1","range":{"min":5e-4,"max":3e-3}}
//|       - {"artifact":"decay","path":"/rows/6/4","range":{"min":3.5e-3,"max":1.4e-2}}
//|       - {"artifact":"decay","path":"/rows/6/5","range":{"min":6.99e-3,"max":7.0e-3}}
//|   - case: eight-dimensions
//|     expect:
//|       - {"artifact":"decay","path":"/rows/5/0","range":{"min":512,"max":512}}
//|       - {"artifact":"decay","path":"/rows/5/4","range":{"min":1e-4,"max":5e-3}}
//|   - case: two-dimensions
//|     expect:
//|       - {"artifact":"decay","path":"/rows/6/2","range":{"min":1e-4,"max":2e-3}}
//|       - {"artifact":"decay","path":"/rows/6/4","range":{"min":4e-3,"max":2.5e-2}}
use scioxide_core::RealScalar;
use scioxide_random::{
    DiscrepancyMethod, QmcPlan, QmcScramble, QuasiRng, Rng, SeedableRng, SplitMix64, discrepancy,
};

let sci4 = serde_json::json!({ "notation": "scientific", "significantDigits": 4 });
let d = dimension.round() as usize;
let seed = seed.round() as u64;
let n_max = 1_usize << maximum_exponent.round() as u32;
// 各方法の点を最大の点数まで一度だけ作り、先頭 N 点でディスクレパンシーを測る。
let sobol = QmcPlan::sobol(d).map_err(|e| e.to_string())?;
let shifted = QmcPlan::sobol(d)
    .and_then(|plan| plan.with_scramble(QmcScramble::DigitalShift(seed)))
    .map_err(|e| e.to_string())?;
let halton = QmcPlan::halton(d).map_err(|e| e.to_string())?;
let mut sets = Vec::new();
for plan in [&sobol, &shifted, &halton] {
    let mut cursor = plan.sequence::<f64>().map_err(|e| e.to_string())?;
    sets.push(cursor.points(n_max).map_err(|e| e.to_string())?);
}
let mut rng = SplitMix64::from_seed(seed);
let mut independent = vec![0.0_f64; n_max * d];
for x in &mut independent {
    *x = rng.next_float().map_err(|e| e.to_string())?;
}
sets.push(independent);
let mut curves: Vec<Vec<[f64; 2]>> = vec![Vec::new(); 4];
let (mut theory, mut rows) = (Vec::new(), Vec::new());
let mut n = 16;
while n <= n_max {
    let mut values = [0.0; 4];
    for ((value, curve), points) in values.iter_mut().zip(&mut curves).zip(&sets) {
        *value = discrepancy(&points[..n * d], d, DiscrepancyMethod::L2Star)
            .map_err(|e| e.to_string())?;
        curve.push([n as f64, *value]);
    }
    // 独立検算: 独立な一様点の二乗平均 √((2^-d − 3^-d)/N)（解析値）。
    let moment = RealScalar::powi(0.5, d as i32) - RealScalar::powi(1.0 / 3.0, d as i32);
    let expected = RealScalar::sqrt(moment / n as f64);
    theory.push([n as f64, expected]);
    rows.push((n, values[0], values[1], values[2], values[3], expected));
    n *= 2;
}
let names = ["Sobol", "Sobol（DigitalShift）", "Halton", "独立な一様点"];
let mut series: Vec<_> = names
    .iter()
    .zip(curves)
    .map(|(name, points)| {
        serde_json::json!({
            "name": name,
            "points": points,
            "style": { "showSymbol": true, "symbol": "circle" }
        })
    })
    .collect();
series.push(serde_json::json!({
    "name": "独立点の理論 √((2⁻ᵈ − 3⁻ᵈ)/N)",
    "points": theory,
    "style": { "lineType": "dashed" }
}));
emit_line_chart!(
    &series,
    options = &serde_json::json!({
        "xLabel": "点数 N [点]",
        "yLabel": "L² スター・ディスクレパンシー [-]",
        "xType": "log",
        "yType": "log"
    })
);
let columns = serde_json::json!([
    { "key": "0", "label": "点数 N [点]", "type": "integer" },
    { "key": "1", "label": "Sobol [-]", "type": "number", "format": sci4 },
    { "key": "2", "label": "Sobol（DigitalShift）[-]", "type": "number", "format": sci4 },
    { "key": "3", "label": "Halton [-]", "type": "number", "format": sci4 },
    { "key": "4", "label": "独立な一様点 [-]", "type": "number", "format": sci4 },
    { "key": "5", "label": "独立点の理論 [-]", "type": "number", "format": sci4 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "decay" })
);
```

独立な一様点の曲線は破線の傾き $-1/2$ に沿い、Sobol と Halton の曲線はより急に下がる。
既定の入力（$d = 4$、$k = 10$、シード 17）では、ランダム化しない Sobol は $N = 16$ の $5.536 \times 10^{-2}$ から $N = 1024$ の $1.409 \times 10^{-3}$ へ、傾き約 $-0.88$ で下がる。
同じ範囲で独立な一様点は $3.989 \times 10^{-2}$ から $7.094 \times 10^{-3}$ へ下がり、$N = 1024$ の値は理論の $6.998 \times 10^{-3}$ に近い。
$N = 1024$ ではランダム化した Sobol（$1.323 \times 10^{-3}$）は独立点の約 5.4 分の 1、Halton（$1.926 \times 10^{-3}$）は約 3.7 分の 1 である。
独立点の値は一つの実現値なので、理論のまわりにばらつく。

$d = 8$、$k = 9$ では $N = 512$ の Sobol が $2.262 \times 10^{-3}$、独立点が $2.609 \times 10^{-3}$ で、差は小さい。
ランダム化しない Sobol は $N = 16$ で $6.149 \times 10^{-2}$ と独立点（$1.472 \times 10^{-2}$）より大きく、原点から始まる短い先頭部分の偏りが高い次元で目立つ。
同じ $N = 16$ でも `DigitalShift` でランダム化した Sobol は $1.277 \times 10^{-2}$ で、原点の偏りはずらしで消える。
$d = 2$、シード 99 では $N = 1024$ の Sobol が $8.679 \times 10^{-4}$、独立点が $1.018 \times 10^{-2}$ で、1 桁以上の差がある。

## まとめ

Koksma–Hlawka の不等式は QMC の誤差の上界をディスクレパンシーで与えるが、実際の誤差の推定値ではないので、誤差の評価にはランダム化と反復が要る。
Halton 点列は素数の基数反転で、`halton(d)` は 100 次元まで使えるが、大きな基数の座標どうしは先頭の点が直線に並ぶので、桁置換か逆 Halton で縞を崩す。
Sobol 点列は Joe–Kuo の方向数で 21,201 次元まで使え、$2^m$ 点の区画が net になるので、点数は 2 の冪にそろえるのがよい。
ディスクレパンシーは低い次元では点数とともに独立点より速く下がるが、次元が高く点数が少ないと差は小さく、ランダム化しない Sobol の先頭部分は独立点より偏ることもある。
