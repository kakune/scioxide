一様乱数ワードから有限集合の添字や置換を作るときは、写像の小さな偏りが試行の回数とともに系統的な誤差になる。
区間に点を置くときは、独立な一様点に生じる塊と隙間を、層化で減らせる。
このページは `scioxide-random` の添字の抽出、置換、非復元抽出のアルゴリズムと、層化抽出が積分の誤差をどこまで下げるかを説明する。
重み付きの抽出は `WeightedSampler` が Walker–Vose のエイリアス法で行い、その構成と計算量は[離散分布と計数の分布](oxref:random-discrete-alias-method)で扱う。
多次元の層化である ラテンハイパーキューブは[ラテンハイパーキューブ設計とディスクレパンシー](../latin-hypercube-and-discrepancy/)で扱う。

## 剰余の偏りと Lemire の棄却

$w$ ビットの一様乱数ワード $W \in \{0, \dots, 2^w - 1\}$ から $\{0, \dots, n-1\}$ の添字を $W \bmod n$ で作ると、$2^w$ が $n$ で割り切れないときに確率がずれる。
$t = 2^w \bmod n$ 個の小さい添字は $\lfloor 2^w/n \rfloor + 1$ 個の原像を持ち、残りの添字は $\lfloor 2^w/n \rfloor$ 個の原像を持つからである。
たとえば $w = 32$、$n = 3 \cdot 2^{30}$ では $\lfloor 2^{32}/n \rfloor = 1$、$t = 2^{30}$ なので、小さい $2^{30}$ 個の添字は他の添字の 2 倍の確率で出る。

`uniform_index(n, rng)` は Lemire の割り算をほとんど使わない棄却法で、この偏りを取り除く。
積 $W n$ を $2^w$ で割った商 $\lfloor W n / 2^w \rfloor$ を添字とし、余り $\ell = W n \bmod 2^w$ を棄却の判定に使う。
商が $k$ になるワードは $\lfloor 2^w/n \rfloor$ 個か、それより 1 個多い。
Lemire は $\ell < t$ となるワードを棄却すると、多い側の添字からだけちょうど 1 個ずつ原像が除かれることを示した。
受理される添字はどれもちょうど $\lfloor 2^w/n \rfloor$ 個の原像を持つので、結果は正確に一様である。

棄却の確率は $t / 2^w$ で、$t < n$ と $t \le 2^w - n$ から $1/2$ 未満になる。
$t$ を求める剰余の計算は割り算を含むが、$t < n$ なので $\ell \ge n$ のワードは $t$ を求めずに受理できる。
割り算を行うのは $\ell < n$ のときだけである。
積 $W n$ は $n$ の倍数なので、長さ $n$ の区間 $[q 2^w, q 2^w + n)$（$q = 0, \dots, n-1$）にちょうど一つずつ入り、$\ell < n$ となるワードはちょうど $n$ 個ある。
したがって割り算を行う確率は $n / 2^w$ である。
$n \le 2^{32}$ では 32 ビットの一様乱数ワードを、それより大きい $n$ では 64 ビットの一様乱数ワードを使う。

一様乱数ワードを 1,024 個試してすべて棄却されると、`ConvergenceFailure`（`IterationLimit`）を返す。
一回の棄却の確率が $1/2$ 未満なので、一様な生成器で 1,024 回続けて棄却される確率は $2^{-1024}$ 未満である。
実際にこの失敗が起きるのは、生成器の一様乱数ワードが一様でないとき（たとえば同じワードを返し続けるとき）である。
上限 $n = 0$ は `InvalidInput` である。
棄却したワードも消費されたままで、`uniform_index` 自体は生成器を巻き戻さない。
失敗の後の生成器の扱いは呼び出し側が決める。

## 置換と非復元抽出

`shuffle(slice, rng)` は Fisher–Yates（Durstenfeld）法で、長さ $N$ の配列の位置 $i = N-1, \dots, 1$ ごとに末尾から順に $\{0, \dots, i\}$ から `uniform_index` で $j$ を選び、位置 $i$ と $j$ を交換する。
位置 $i$ に入る要素は、まだ位置の決まっていない $i + 1$ 個から一様に選ばれる。
したがって特定の置換の確率は $\prod_{i=1}^{N-1} 1/(i+1) = 1/N!$ で、どの置換も等しい確率で出る。
抽出の回数は $N - 1$ 回で、`shuffle` はメモリ領域を確保せず要素を複製しない。
失敗したときは生成器を進めたまま、配列には入力を並べ替えた途中の状態を残す。

`shuffle_in_place(slice, rng, policy, workspace)` は同じ抽出を `SamplingPolicy` の下で行い、成功したときの置換は `shuffle` と同じである。
出力方針は[標本の一括生成と状態の扱い](oxref:random-algorithms-batches-and-state)に従う。
`Atomic` は配列と同じ長さの作業領域（長さ 2 未満では 0）に要素を複製して並べ替え、成功したときだけ配列と入れ替える。
`Incremental` は作業領域を使わず、失敗したときは完了した交換を配列に残す。
生成器の扱いは `policy` の状態方針に従う。

`choose(slice, rng)` は要素を一つ一様に選び、空の配列ではワードを使わずに `Ok(None)` を返す。
`sample_indices(n, k, rng)` は $\{0, \dots, n-1\}$ から $k$ 個の異なる添字を選んで所有の `Vec` で返し、抽出の割合で方法を切り替える。

| 条件 | 方法 | 計算量 | 順序 |
|---|---|---|---|
| $k \ge \lfloor n/16 \rfloor$ | $0, \dots, n-1$ を並べた配列の先頭 $k$ 位置だけ Fisher–Yates を行う | $O(n)$ の時間とメモリ領域 | 一様に無作為な順序付きの標本 |
| $k < \lfloor n/16 \rfloor$ | Floyd の方法と、高々 $4k$ 区画の開番地法の集合 | 期待 $O(k)$ の時間とメモリ領域 | 規定しない |

部分的な Fisher–Yates は位置 $i = 0, \dots, k-1$ を $\{i, \dots, n-1\}$ の一様な位置と交換し、残りの位置は捨てる。
$k = n$ なら $0, \dots, n-1$ の一様な置換になる。

Floyd の方法は $j = n-k, \dots, n-1$ について $t \in \{0, \dots, j\}$ を一様に引き、$t$ が集合になければ $t$ を、あれば $j$ を加える。
$j$ 段の後の集合は $\{0, \dots, j\}$ の大きさ $s = j - (n-k) + 1$ の一様な部分集合である。
これは帰納法で示せる。
大きさ $s$ の集合 $S$ が $j$ を含むときは、前の段の集合が $S \setminus \{j\}$ で、$t$ が $S$ のどれか（$s$ 通り）であれば $S$ になる。
$j$ を含まないときは、ある $x \in S$ について前の段の集合が $S \setminus \{x\}$ で $t = x$ のとき（$s$ 通り）に $S$ になる。
前の段の集合はどれも確率 $1/\binom{j}{s-1}$ を持つので、どちらの場合も確率は $s / \bigl((j+1)\binom{j}{s-1}\bigr) = 1/\binom{j+1}{s}$ である。
衝突したときに加える $j$ はその段で初めて候補になる数なので、添字の抽出はちょうど $k$ 回で済む。

どちらの方法もメモリ領域を最初の抽出の前に確保し、確保に失敗したときはワードを使わずに `AllocationFailure` を返す。
$k > n$ は `InvalidInput` で、$k = 0$ はワードを使わずに空の `Vec` を返す。
失敗すると何も返さず、生成器は消費したワードの分だけ進んだまま残る。

## 層化抽出の分散

$I = \int_0^1 f(x)\,dx$ を $m$ 個の標本の平均で推定する。
単純な Monte Carlo 法の推定量の分散は $\sigma_f^2/m$（$\sigma_f^2 = \mathrm{Var}\,f(U)$、$U$ は $[0, 1)$ 上の一様乱数）である。
層化抽出は $[0, 1)$ を $m$ 個の等しい層 $[j/m, (j+1)/m)$ に分け、各層から一点 $u_j = (j + U_j)/m$ を独立に作る。
1 次元の `latin_hypercube(m, 1, rng)` はこの $m$ 点を作る（並べ替えは 1 次元の推定に影響しない）。

一様乱数 $U$ が入る層を確率変数 $J$ とすると、全分散の公式は

$$
\mathrm{Var}\,f(U) = \mathrm{Var}\bigl(\mathrm{E}[f(U) \mid J]\bigr) + \mathrm{E}\bigl[\mathrm{Var}(f(U) \mid J)\bigr]
$$

である。
単純な Monte Carlo 法では各層に入る標本の数が揺らぐので、両方の項が分散に入る。
層ごとに一点ずつ置く層化推定量では右辺第 1 項の層の間の分散が消え、

$$
\mathrm{Var}\,\hat{I}_{\mathrm{strat}} = \frac{1}{m^2} \sum_{j=0}^{m-1} \mathrm{Var}\bigl(f(u_j)\bigr) = \frac{1}{m}\,\mathrm{E}\bigl[\mathrm{Var}(f(U) \mid J)\bigr] \le \frac{\sigma_f^2}{m}
$$

となる。
$f$ が滑らかなら、幅 $h = 1/m$ の層の中で $f(u) \approx f(x_j) + f'(x_j)(u - x_j)$ と近似でき、層の中の分散は $f'(x_j)^2 h^2 / 12$ 程度である（$x_j$ は層の中点）。
これを $m$ 個の層で足すと

$$
\mathrm{Var}\,\hat{I}_{\mathrm{strat}} \approx \frac{1}{12 m^3}\int_0^1 f'(x)^2\,dx
$$

で、標準誤差は $m^{-3/2}$ で減る。
単純な Monte Carlo 法の $m^{-1/2}$ と比べて、同じ標本数での誤差の比は $m$ に比例して開く。

次のセルは $f(x) = e^x$（$I = e - 1$）について、単純な Monte Carlo 法と層化抽出の推定を $R$ 回ずつ独立に繰り返し、誤差の二乗平均の平方根（RMSE）を $m = 8, 16, \dots, 2^k$ で測る。
入力は反復回数 $R$、最大の標本数 $m = 2^k$ の指数 $k$、シードである。
理論値には、$\sigma_f^2 = (e^2 - 1)/2 - (e-1)^2 \approx 0.2420$ による単純な Monte Carlo 法の $\sqrt{\sigma_f^2/m}$ と、$\int_0^1 (e^x)^2 dx = (e^2 - 1)/2$ による層化の漸近形 $\sqrt{(e^2-1)/(24 m^3)}$ を使う。
どちらも解析的に求めた独立検算の値で、表は RMSE と理論値の比を示す。
$R$ 回から求めた RMSE 自体の相対的な標準誤差は、誤差が正規分布に従うとき約 $1/\sqrt{2R}$ で、比はこの幅で 1 のまわりに揺らぐ。

```rust
//| id: random-stratified-rmse
//| ref: random-stratified-rmse
//| title: 単純な Monte Carlo 法と層化抽出の誤差を標本数ごとに測る
//| run: reactive
//| crates: [scioxide-core, scioxide-random]
//| inputs:
//|   replications: {"type":"range","label":"反復回数 R [回]","description":"RMSE の相対的な標準誤差は約 1/√(2R)。","min":50,"max":400,"step":50,"value":200}
//|   maximum_exponent: {"type":"range","label":"最大の標本数の指数 k（m = 2ᵏ）[-]","min":6,"max":12,"step":1,"value":10}
//|   seed: {"type":"range","label":"乱数のシード [-]","min":1,"max":1000,"step":1,"value":3}
//| cases:
//|   - {"id":"many-replications","label":"R = 400、シード 9","description":"反復を増やすと比の揺らぎは標準誤差 0.035 程度に縮む。","inputs":{"replications":400,"seed":9}}
//|   - {"id":"large-m","label":"k = 12","description":"m = 4096 では層化の RMSE は 10⁻⁶ 程度まで下がる。","inputs":{"maximum_exponent":12}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"rmse","path":"/rows/7/0","range":{"min":1024,"max":1024}}
//|       - {"artifact":"rmse","path":"/rows/7/3","range":{"min":0.8,"max":1.2}}
//|       - {"artifact":"rmse","path":"/rows/7/6","range":{"min":0.8,"max":1.2}}
//|       - {"artifact":"rmse","path":"/rows/0/6","range":{"min":0.8,"max":1.2}}
//|   - case: many-replications
//|     expect:
//|       - {"artifact":"rmse","path":"/rows/7/3","range":{"min":0.85,"max":1.15}}
//|       - {"artifact":"rmse","path":"/rows/7/6","range":{"min":0.85,"max":1.15}}
//|   - case: large-m
//|     expect:
//|       - {"artifact":"rmse","path":"/rows/9/0","range":{"min":4096,"max":4096}}
//|       - {"artifact":"rmse","path":"/rows/9/4","range":{"min":5e-7,"max":4e-6}}
//|       - {"artifact":"rmse","path":"/rows/9/6","range":{"min":0.8,"max":1.2}}
use scioxide_core::RealScalar;
use scioxide_random::{Rng, SeedableRng, SplitMix64, latin_hypercube};

let sci4 = serde_json::json!({ "notation": "scientific", "significantDigits": 4 });
let fixed3 = serde_json::json!({ "fractionDigits": 3 });
// 独立な解析値: I = e − 1、σ² = Var e^U、∫(e^x)² dx = (e² − 1)/2。
let e = std::f64::consts::E;
let exact = e - 1.0;
let variance = (e * e - 1.0) / 2.0 - exact * exact;
let r = replications.round() as usize;
let mut rng = SplitMix64::from_seed(seed.round() as u64);
let (mut simple_curve, mut strat_curve) = (Vec::new(), Vec::new());
let (mut simple_theory, mut strat_theory, mut rows) = (Vec::new(), Vec::new(), Vec::new());
for k in 3..=maximum_exponent.round() as u32 {
    let m = 1_usize << k;
    let (mut simple_square, mut strat_square) = (0.0_f64, 0.0_f64);
    for _ in 0..r {
        // 単純な Monte Carlo 法: 独立な一様乱数 m 個。
        let mut sum = 0.0;
        for _ in 0..m {
            let u: f64 = rng.next_float().map_err(|e| e.to_string())?;
            sum += RealScalar::exp(u);
        }
        simple_square += RealScalar::powi(sum / m as f64 - exact, 2);
        // 層化抽出: 各層 [j/m, (j+1)/m) から一点ずつ。
        let points: Vec<f64> = latin_hypercube(m, 1, &mut rng).map_err(|e| e.to_string())?;
        let estimate = points.iter().map(|&u| RealScalar::exp(u)).sum::<f64>() / m as f64;
        strat_square += RealScalar::powi(estimate - exact, 2);
    }
    let simple = RealScalar::sqrt(simple_square / r as f64);
    let strat = RealScalar::sqrt(strat_square / r as f64);
    let simple_ref = RealScalar::sqrt(variance / m as f64);
    let strat_ref = RealScalar::sqrt((e * e - 1.0) / (24.0 * RealScalar::powi(m as f64, 3)));
    simple_curve.push([m as f64, simple]);
    strat_curve.push([m as f64, strat]);
    simple_theory.push([m as f64, simple_ref]);
    strat_theory.push([m as f64, strat_ref]);
    rows.push((
        m,
        simple,
        simple_ref,
        simple / simple_ref,
        strat,
        strat_ref,
        strat / strat_ref,
    ));
}
let observed = serde_json::json!({ "showSymbol": true, "symbol": "circle" });
let dashed = serde_json::json!({ "lineType": "dashed" });
let series = |name: &str, points: &Vec<[f64; 2]>, style: &serde_json::Value| {
    serde_json::json!({
        "name": name,
        "points": points,
        "style": style
    })
};
emit_line_chart!(
    &vec![
        series("単純な Monte Carlo 法（測定）", &simple_curve, &observed),
        series(
            "単純な Monte Carlo 法の理論 √(σ²/m)",
            &simple_theory,
            &dashed
        ),
        series("層化抽出（測定）", &strat_curve, &observed),
        series("層化抽出の漸近形 √((e²−1)/(24m³))", &strat_theory, &dashed),
    ],
    options = &serde_json::json!({
        "xLabel": "標本数 m [個]",
        "yLabel": "RMSE [-]",
        "xType": "log",
        "yType": "log"
    })
);
let columns = serde_json::json!([
    { "key": "0", "label": "標本数 m [個]", "type": "integer" },
    { "key": "1", "label": "単純な MC の RMSE [-]", "type": "number", "format": sci4 },
    { "key": "2", "label": "理論 √(σ²/m) [-]", "type": "number", "format": sci4 },
    { "key": "3", "label": "単純な MC の比 [-]", "type": "number", "format": fixed3 },
    { "key": "4", "label": "層化の RMSE [-]", "type": "number", "format": sci4 },
    { "key": "5", "label": "漸近形 [-]", "type": "number", "format": sci4 },
    { "key": "6", "label": "層化の比 [-]", "type": "number", "format": fixed3 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "rmse" })
);
emit_text!(format!(
    "比の標準誤差 ≈ 1/√(2R) = {:.3}",
    1.0 / RealScalar::sqrt(2.0 * r as f64)
));
```

両対数のグラフで、単純な Monte Carlo 法の RMSE は傾き $-1/2$、層化抽出は傾き $-3/2$ の破線に沿う。
既定の入力（$R = 200$、シード 3）では、単純な Monte Carlo 法の理論との比は 0.918〜1.135、層化の漸近形との比は 0.943〜1.050 である。
比の標準誤差は約 0.050 なので、最も外れた $m = 512$ の単純な Monte Carlo 法の比 1.135 は 2.7 標準誤差にあたる。
16 個の比のどれかが 2.7 標準誤差以上外れる確率は、比が独立なら約 11% で、この外れは偶然の範囲にある。
$R = 400$、シード 9 にすると比の標準誤差は 0.035 になり、比は 0.959〜1.068 と 0.974〜1.029 に収まる。

$m = 1024$ では単純な Monte Carlo 法の RMSE $1.521 \times 10^{-2}$ に対して層化抽出は $1.653 \times 10^{-5}$ で、同じ標本数で約 920 分の 1 になる。
理論の比は $m\sqrt{24\sigma_f^2/(e^2 - 1)} \approx 0.954\,m \approx 977$ で、測定値の比は二つの RMSE の推定の揺らぎ（それぞれ約 5%）の範囲にある。
層化の利得は $f$ が滑らかなほど大きく、層の幅より細かい振動や不連続を持つ関数では漸近形が成り立たない。

## まとめ

`uniform_index` は Lemire の棄却で剰余の偏りを除き、棄却の確率は $1/2$ 未満なので、1,024 ワードの打ち切りに達するのは実際には生成器の一様乱数ワードが一様でないときに限られる。
置換と非復元抽出はすべてこの添字の抽出の上に作られ、`sample_indices` は $k \ge \lfloor n/16 \rfloor$ で部分的な Fisher–Yates、それより小さい $k$ で順序を規定しない Floyd の方法を使う。
失敗の後に配列や生成器を元に戻したいときは、`shuffle` ではなく `shuffle_in_place` に状態方針を渡す。
層化抽出は層の間の分散を除き、滑らかな被積分関数では RMSE が $m^{-3/2}$ で減ることを、理論値との比で確かめられる。
