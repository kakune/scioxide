対称な分布に歪度や裾の重さを与える族は、作り方で次の 5 つに分かれる。

- 正規密度に分布関数を掛けて歪ませる族（歪み正規）。
- 原点の左右で尺度や減衰率を変える族（二片 Cauchy、非対称 Laplace）。
- 正規変数やベータ変数を変換したり、正規変数に別の変数を足したりする族（Johnson SU、Jones–Faddy の歪み t、指数修正正規）。
- 正規の中心に冪の裾を片側だけつなぐ族（Crystal Ball）。
- 正規変数の分散と平均を混合する族（一般化双曲型、正規逆ガウス）。
  混合に使う正の変数の分布（一般化逆ガウス）もここに含める。

このページは各族の定義をコンストラクターの母数のまま示し、標本化の方法、分位点の求め方、平均と分散の有無を説明する。
最後のセルは 5 つの族の標本を Kolmogorov–Smirnov 距離とモーメントの信頼区間で点検する。

KS 距離と $p$ 値の読み方は[標本による分布関数とモーメントの照合](oxref:random-families-sample-check)と同じである。

## 族の定義と母数の定義域

このページの分布は位置と尺度の母数を持たない標準形で、位置と尺度は `Affine::new(law, μ, σ)` で加える。
$\varphi$、$\Phi$ は標準正規の密度と分布関数、$K_\nu$ は第 2 種変形 Bessel 関数、$B(a, b)$ はベータ関数である。
`with_options` を併記した族は、`new` が既定の `LawOptions` を使い、`with_options` が母数の後に設定を取る。
有限の母数が定義域の外にあればコンストラクターは理由 `OutsideDomain` の `DomainError` を返し、NaN や無限大の母数には `NonFinite` を返す。

| コンストラクター | 母数の定義域 | 定義 |
|---|---|---|
| `SkewNormal::new(a)`（`with_options`） | $a$ は有限 | $f(x) = 2\varphi(x)\Phi(ax)$。$a = 0$ は標準正規 |
| `SkewCauchy::new(a)` | $\lvert a \rvert < 1$ | $s = 1 - a$（$x < 0$）、$s = 1 + a$（$x \ge 0$）として $f(x) = 1/\bigl(\pi(1 + x^2/s^2)\bigr)$。$P(X < 0) = (1 - a)/2$ |
| `JonesFaddySkewT::new(a, b)`（`with_options`） | $a, b > 0$ | $r = a + b$、$u = x/\sqrt{r + x^2}$ として $f(x) = (1 + u)^{a + 1/2}(1 - u)^{b + 1/2}/\bigl(2^{r-1}B(a, b)\sqrt{r}\bigr)$。$a = b$ は自由度 $2a$ の $t$ |
| `AsymmetricLaplace::new(kappa)` | $\kappa > 0$ | $f(x) = \frac{\kappa}{1 + \kappa^2} e^{-\kappa x}$（$x \ge 0$）、$\frac{\kappa}{1 + \kappa^2} e^{x/\kappa}$（$x < 0$）。$P(X < 0) = \kappa^2/(1 + \kappa^2)$ |
| `ExponentiallyModifiedNormal::new(k)`（`with_options`） | $k > 0$（$1/k$ があふれる $k$ は `NumericalInstability`（`Overflow`）） | $X = Z + kE$（$Z$ は標準正規、$E$ は平均 1 の指数）、$F(x) = \Phi(x) - e^{-x/k + 1/(2k^2)}\Phi(x - 1/k)$ |
| `JohnsonSU::new(a, b)` | $a$ は有限、$b > 0$ | $X = \sinh\bigl((Z - a)/b\bigr)$、$F(x) = \Phi(a + b\operatorname{asinh} x)$ |
| `CrystalBall::new(beta, m)` | $\beta > 0$、$m > 1$ | $f(x) \propto e^{-x^2/2}$（$x > -\beta$）、$e^{-\beta^2/2}\bigl(1 + \beta(-x - \beta)/m\bigr)^{-m}$（$x \le -\beta$）。左側だけが冪の裾 |
| `GeneralizedInverseGaussian::new(p, b)`（`with_options`） | $p$ は有限、$b > 0$ | 台 $x > 0$、$f(x) \propto x^{p-1}\exp\bigl(-b(x + 1/x)/2\bigr)$ |
| `GeneralizedHyperbolic::new(p, a, b)`（`with_options`） | $a > 0$ かつ $\lvert b \rvert < a$（$b = 0$ を含む）、または $\lvert b \rvert = a$ かつ $p < 0$ | $\gamma = \sqrt{a^2 - b^2}$ として $f(x) = \dfrac{\gamma^p a^{1/2 - p}}{\sqrt{2\pi}K_p(\gamma)}(1 + x^2)^{(p - 1/2)/2}K_{p - 1/2}\bigl(a\sqrt{1 + x^2}\bigr)e^{bx}$（$\gamma = 0$ はその極限） |
| `NormalInverseGaussian::new(a, b)`（`with_options`） | $a > \lvert b \rvert$（$b = 0$ を含む） | `GeneralizedHyperbolic` の $p = -1/2$ |

`GeneralizedHyperbolic` は通常の 5 母数 $(\lambda, \alpha, \beta, \delta, \mu)$ のうち $\delta = 1$、$\mu = 0$ に固定した標準形で、$(p, a, b)$ が $(\lambda, \alpha, \beta)$ に当たる。
$\delta \ne 1$ の分布は $\alpha\delta$、$\beta\delta$ を $a$、$b$ に渡し、`Affine` で尺度 $\delta$ と位置 $\mu$ を加えて作る。

## 標本化の方法

歪み正規は Azzalini の表現 $X = \delta\lvert Z_0 \rvert + \sqrt{1 - \delta^2}\,Z_1$（$\delta = a/\sqrt{1 + a^2}$、$Z_0, Z_1$ は独立な標準正規）で作り、棄却を使わない。
Jones–Faddy の歪み t は $U \sim \mathrm{Beta}(a, b)$ から $X = \sqrt{r}\,(2U - 1)/\bigl(2\sqrt{U(1 - U)}\bigr)$ で作る。
指数修正正規は正規乱数と指数乱数の和、Johnson SU は正規乱数の変換である。
二片 Cauchy、非対称 Laplace、Crystal Ball は開区間の一様乱数を閉形式の分位点で写す逆関数法で作る。

一般化双曲型は正規分散平均混合

$$
X = bW + \sqrt{W}\,Z, \qquad Z \sim \mathcal{N}(0, 1),\ W \perp Z
$$

で作る。
混合する変数 $W$ は $\gamma > 0$ では $V/\gamma$（$V$ は `GeneralizedInverseGaussian` の $(p, \gamma)$）であり、その密度は $w^{p-1}\exp\bigl(-(1/w + \gamma^2 w)/2\bigr)$ に比例する。
$\lvert b \rvert = a$（$\gamma = 0$）では $W$ が逆ガンマ分布に退化するので、$G \sim \mathrm{Gamma}(-p, 1)$ から $W = 1/(2G)$ を直接作る。
位置の母数は持たず、$X$ の条件付き分布は $W$ を与えたとき平均 $bW$、分散 $W$ の正規分布である。

一般化逆ガウスの標本は $y = \ln x$ の座標での棄却法で作る。
$y$ の密度は $e^{py - b\cosh y}$ に比例し、$p \ge 0$ ではその最頻値は $y^\ast = \operatorname{asinh}(p/b)$ である。
$t = y - y^\ast$ と置くと対数密度は $-\ell(t)$（$\ell$ は凸で $\ell(0) = 0$）の形になる。
提案分布は 3 片からなる。
中央は $\ell < 1$ の区間を含む区間 $[t_-, t_+]$ で平らな高さ $1$（$e^{-\ell} \le 1$）を取り、区間の端は幅を倍にしながら $\ell \ge 1$ になるまで広げて決める。
両裾は端点での傾き $\ell'(t_\pm)$ を持つ指数関数で、$\ell$ が凸なので $e^{-\ell(t)} \le e^{-\ell'(t_\pm)(t - t_\pm)}$ が成り立ち、密度を上から抑える。
1 回の提案に開区間の一様乱数を 3 個使い、1,024 回の提案で受理がなければ `ConvergenceFailure` を返す。
$p < 0$ の標本は、$1/V$ が $(-p, b)$ の一般化逆ガウスに従うことを使い、$\lvert p \rvert$ の標本の逆数として作る。

## 分布関数と分位点の計算

閉形式の分布関数と分位点を持つのは、二片 Cauchy（各片の余接）、非対称 Laplace、Johnson SU（$\Phi^{-1}$ と $\sinh$）、Crystal Ball（冪の裾と正規の中心を確率で分けた区分的な式）である。
Jones–Faddy の歪み t は、$u = (1 + x/\sqrt{r + x^2})/2$ がベータ分布 $\mathrm{Beta}(a, b)$ に従うことを使い、分布関数を正則化不完全ベータ関数 $I_u(a, b)$、分位点をその逆関数で求める。
特殊関数の反復には `LawOptions` の作業量を使う。
分布関数は $u$ と $1 - u$ の小さいほうの座標から計算し、分位点も最後は小さいほうの座標から $x$ を作るので、遠い裾でも $1 - (\text{1 に近い値})$ を作らない。

歪み正規の上側確率は $a > 0$ かつ $x < 8$ では Owen の $T$ 関数による閉形式 $S(x) = \bar\Phi(x) + 2T(x, a)$ で求める。
$x \ge 8$ と、二つの項がほぼ打ち消し合う $a < 0$ の側では、密度を直接求積する。

指数修正正規は分布関数の 2 項を対数のまま組み合わせ、分位点は数値逆算で求める。
一般化逆ガウスは $y = \ln x$、一般化双曲型は $t = \operatorname{asinh} x$ の座標で裾の密度を求積する。
どちらも最頻値から遠い側の裾だけを積分し、反対側はその補数として作る。
一般化双曲型の密度の指数部 $-a\sqrt{1 + x^2} + bx$ は大きな 2 項の差なので、恒等式 $a\sqrt{1 + x^2} - bx - \gamma = (\gamma x - b)^2/(a\sqrt{1 + x^2} + bx + \gamma)$ で右辺の形に書き換えて桁落ちを避ける。

歪み正規、一般化逆ガウス、一般化双曲型（正規逆ガウスを含む）の分位点は、小さい側の裾の対数確率が目標値より大きいか小さいかだけを使う二分法で、浮動小数点の隣の数まで区間を縮めて求める。
指数修正正規の分位点は `LawOptions` の許容誤差で止まる数値逆算である。
1 回の分位点で行う分布関数の評価はすべて同じ作業量の上限を共有する。
歪み正規（$a > 0$）の裾は大部分が Owen の $T$ 関数で求まり、既定の作業量 65,536 の中で分位点が求まる。
一般化双曲型の分布関数は 1 回ごとに求積するので、1 回の分位点で求積を数十回行う。
正規逆ガウス（$a = 2$、$b = 1$）では分布関数 1 回が数千単位の作業量を使い、既定の上限では $p = 10^{-10}$ から $0.999$ までの試したどの点でも上限に達して `ConvergenceFailure` を返した。
分位点を求めるときは、`with_options` に `LawOptions::default().with_work_budget(Budget::try_from(1 << 20)?)` のような大きい上限を渡す。

## 平均と分散

| 族 | 平均 | 分散 | 存在の条件 |
|---|---|---|---|
| `SkewNormal` | $\delta\sqrt{2/\pi}$ | $1 - 2\delta^2/\pi$ | 常に |
| `SkewCauchy` | 実装しない | 実装しない | 存在しない |
| `JonesFaddySkewT` | $\dfrac{(a - b)\sqrt{a + b}}{2}\dfrac{\Gamma(a - 1/2)\Gamma(b - 1/2)}{\Gamma(a)\Gamma(b)}$ | $\dfrac{(a + b)\bigl((a - b)^2 + a + b - 2\bigr)}{4(a - 1)(b - 1)} - (\text{平均})^2$ | 平均は $a, b > 1/2$、分散は $a, b > 1$ |
| `AsymmetricLaplace` | $1/\kappa - \kappa$ | $1/\kappa^2 + \kappa^2$ | 常に |
| `ExponentiallyModifiedNormal` | $k$ | $1 + k^2$ | 常に |
| `JohnsonSU` | $-e^{1/(2b^2)}\sinh(a/b)$ | $\tfrac{1}{2}(e^{1/b^2} - 1)\bigl(e^{1/b^2}\cosh(2a/b) + 1\bigr)$ | 常に |
| `CrystalBall` | 冪の裾と正規の中心の寄与の和 | 2 次の原点モーメントから | $k$ 次は $m > k + 1$ |
| `GeneralizedInverseGaussian` | $K_{p+1}(b)/K_p(b)$ | 2 次の原点モーメントから | 常に |
| `GeneralizedHyperbolic` | $b\,\mathrm{E}[W]$ | $\mathrm{E}[W] + b^2\operatorname{Var}[W]$ | $\gamma > 0$ なら常に。$\gamma = 0$ では $\mathrm{E}[W^k]$ に $-p > k$ が要る |
| `NormalInverseGaussian` | $b/\gamma$ | $a^2/\gamma^3$ | 常に |

一般化双曲型の $\mathrm{E}[W^k]$ は $\gamma > 0$ で $K_{p+k}(\gamma)/\bigl(K_p(\gamma)\gamma^k\bigr)$ である。
`Entropy` はこのページのどの族も実装しない。

## 標本による分布関数とモーメントの照合

次のセルは、標本化の方法が異なる 5 つの族から $n$ 個の標本をシード `seed` で作る。
1 つ目の表は KS 距離 $D_n$、$\sqrt{n}\,D_n$、漸近の Kolmogorov 分布による近似の $p$ 値で、標本化器と分布関数の食い違いを測る。
2 つ目の表は標本平均と標本分散の 95% 信頼区間と、上の表の式をセルの中で計算した値（独立検算）との差の $z$ である。
5 つの族はどれも逆関数法を使わないので、KS 距離は二つの独立な実装を比べる。
分散の標準誤差には 4 次モーメントが要るので、Jones–Faddy の母数は $\min(a, b) > 2$ を満たすものを選んだ。

```rust
let kolmogorov = Kolmogorov::new().map_err(|e| e.to_string())?;
let scaled = RealScalar::sqrt(nf) * d_n;
let p_value = kolmogorov.sf(scaled).map_err(|e| e.to_string())?;
let ks_columns = serde_json::json!([
    { "key": "0", "label": "n [個]", "type": "integer" },
    { "key": "1", "label": "D_n [-]", "type": "number", "format": sig4 },
    { "key": "2", "label": "√n·D_n [-]", "type": "number", "format": fixed3 },
    { "key": "3", "label": "近似の p 値 [-]", "type": "number", "format": fixed3 }
]);
emit_table_with_columns!(
    ks_columns,
    vec![(n, d_n, scaled, p_value)],
    metadata = serde_json::json!({ "id": "ks" })
);
// モーメント: 平均の SE は s/√n、分散の SE は √((m₄ − s⁴)/n)。
let mean = x.iter().sum::<f64>() / nf;
let (s2, s4) = x.iter().fold((0.0, 0.0), |(a, b), &v| {
    let d2 = RealScalar::powi(v - mean, 2);
    (a + d2, b + d2 * d2)
});
let var = s2 / (nf - 1.0);
let se = [
    RealScalar::sqrt(var / nf),
    RealScalar::sqrt((s4 / nf - var * var) / nf),
];
let row = |k: usize, name: &'static str, est: f64| {
    let (ci, z) = (1.96 * se[k], (est - exact[k]) / se[k]);
    (name, exact[k], est, est - ci, est + ci, z)
};
let moment_columns = serde_json::json!([
    { "key": "0", "label": "量" },
    { "key": "1", "label": "閉形式 [-]", "type": "number", "format": sig5 },
    { "key": "2", "label": "標本推定 [-]", "type": "number", "format": sig5 },
    { "key": "3", "label": "95% CI 下限 [-]", "type": "number", "format": sig5 },
    { "key": "4", "label": "95% CI 上限 [-]", "type": "number", "format": sig5 },
    { "key": "5", "label": "z [-]", "type": "number", "format": fixed2 }
]);
emit_table_with_columns!(
    moment_columns,
    vec![row(0, "平均", mean), row(1, "分散", var)],
    metadata = serde_json::json!({ "id": "moments" })
);
```

既定の入力（`SkewNormal`、$a = 4$、$n = 2\,000$、シード 17）では $D_n = 0.0125$、$\sqrt{n}\,D_n = 0.559$、近似の $p$ 値は 0.914 である。
平均の閉形式 $\delta\sqrt{2/\pi} = 0.77406$（$\delta = 4/\sqrt{17}$）に対して標本平均は 0.77759（$z = 0.25$）、分散 0.40083 に対して標本分散は 0.39495（$z = -0.44$）である。

`JonesFaddySkewT`（$a = 6$、$b = 3$）では平均の閉形式 1.30465 に対して標本平均 1.26722（$z = -1.26$）、分散 1.89789 に対して 1.77044（$z = -1.48$）で、どちらも 95% 信頼区間に入る。
`NormalInverseGaussian`（$a = 2$、$b = 1$）では $D_n = 0.0294$、$p = 0.063$ と小さめの値が出る。
同じシードで $n = 5\,000$ にすると $p = 0.531$、シードを 1 と 1000 にした $n = 5\,000$ では 0.844 と 0.350 になり、0.063 はシードによる揺らぎの範囲と読める。
平均と分散の閉形式 $b/\gamma = 0.57735$、$a^2/\gamma^3 = 0.76980$ との差は $z = 1.22$ と $0.01$ である。
`ExponentiallyModifiedNormal`（$k = 1.5$、$n = 5\,000$）では $D_n = 0.0106$（$p = 0.626$）、平均の $z = 0.32$、分散の $z = -0.24$ である。

正規逆ガウスの分布関数は 1 点ごとに求積するので、$n = 5\,000$ の KS 距離では求積を 5,000 回繰り返す。
分布関数は 1 点ごとに作業量を数え直すので、試した入力（$n = 500$ から $5\,000$、シード 1 から 999 の 15 通り）のどれでも既定の作業量 65,536 の中で終わった。
このセルは正規逆ガウスで計算時間が長くなるので、ボタンで実行する。

## まとめ

歪み正規、Jones–Faddy の歪み t、指数修正正規、Johnson SU は正規変数やベータ変数の変換で標本を作り、二片 Cauchy、非対称 Laplace、Crystal Ball は開区間の一様乱数を閉形式の分位点で写す逆関数法で作る。
一般化双曲型と正規逆ガウスは位置の母数を持たない標準形で、標本は $X = bW + \sqrt{W}Z$ の混合で、$W$ は一般化逆ガウスの棄却法（$\gamma = 0$ では逆ガンマ）で作る。
一般化双曲型と正規逆ガウスの分位点は分布関数の求積を数十回繰り返す二分法なので、既定の作業量では足りず、`LawOptions` の作業量を上げて求める。
二片 Cauchy は平均と分散を実装せず、Jones–Faddy、Crystal Ball、$\gamma = 0$ の一般化双曲型は母数によってモーメントが存在しない。
変換や混合で作る標本は、KS 距離と閉形式のモーメントの両方で分布関数の実装と独立に点検できる。
