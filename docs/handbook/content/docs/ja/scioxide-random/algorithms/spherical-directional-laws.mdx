結晶の方位、宇宙線の到来方向、分子の向き、乱流中の粒子の運動方向のように、3 次元の向きを表すデータは単位球面上の点である。
球面上の確率分布はこうした向きの無作為な生成や、平均の向きのまわりに集まった向きのモデルに使う。
`scioxide-random` は単位球面 $S^{d-1} = \{\mathbf{x} \in \mathbb{R}^d : \lVert\mathbf{x}\rVert = 1\}$ 上の分布として `UniformDirection` と `VonMisesFisher` を提供する。
このページは二つの分布の密度と生成のアルゴリズム、一様方向の成分のモーメントの導出、von Mises–Fisher 分布の平均の向きに沿った成分の分布を説明する。
円周上の角度の分布と主区間の約束は[円周上の角度の確率分布](../circular-and-directional-laws/)にある。

## 球面上の一様方向

`UniformDirection::new(d)` は $\mathbb{R}^d$ の単位球面 $S^{d-1}$ 上の一様分布である。
密度は面積の逆数 $\Gamma(d/2)/(2\pi^{d/2})$ で、$d = 3$ なら $1/(4\pi)$ になる。
$d \ge 2$ の標本は標準正規ベクトル $\mathbf{Z} \sim \mathcal{N}_d(\mathbf{0}, I)$ を作ってそのノルムで割った $\mathbf{X} = \mathbf{Z}/\lVert\mathbf{Z}\rVert$ である。
$\mathbf{Z}$ の密度は $\lVert\mathbf{z}\rVert$ だけの関数なので任意の回転で不変であり、正規化した $\mathbf{X}$ の分布も回転不変になる。
球面上の回転不変な確率測度は一様分布だけなので、$\mathbf{X}$ は一様である。
ノルムは成分ごとに `hypot` で積み上げて桁あふれを避け、ノルムが 0 になった組（確率 0 の事象）は引き直す。
$d = 1$ の球面は $\{-1, +1\}$ で、確率 1/2 ずつの符号を返す。
`contains_support(x)` は、各成分の絶対値が $1 + 8\varepsilon$ 以下で、$\bigl|\lVert\mathbf{x}\rVert^2 - 1\bigr| \le 8d\varepsilon$ のとき真を返す（$\varepsilon$ はスカラー型の機械イプシロン）。
`new` は $d = 0$ を `InvalidInput` で返し、$d$ が `work_budget` を超えると `ConvergenceFailure` を返す。

成分のモーメントは対称性と $\lVert\mathbf{X}\rVert = 1$ から導ける。
$X_j$ と $-X_j$ は同じ分布に従うので $\mathbb{E}[X_j] = 0$ である。
成分を入れ替えても分布は変わらず、$\sum_j X_j^2 = 1$ なので $\mathbb{E}[X_j^2] = 1/d$ である。
$\mathbf{X} = \mathbf{Z}/\lVert\mathbf{Z}\rVert$ と $\lVert\mathbf{Z}\rVert$ が独立であることを使うと $\mathbb{E}[Z_j^4] = \mathbb{E}[X_j^4]\,\mathbb{E}\lVert\mathbf{Z}\rVert^4$ から

$$
\mathbb{E}[X_j^4] = \frac{3}{d(d+2)},\qquad
\operatorname{Var}(X_j^2) = \frac{3}{d(d+2)} - \frac{1}{d^2} = \frac{2(d-1)}{d^2(d+2)}
$$

が得られる（$\mathbb{E}[Z_j^4] = 3$、$\mathbb{E}\lVert\mathbf{Z}\rVert^4 = d(d+2)$）。
`mean()` は零ベクトル、`variance()` は各成分 $1/d$ を返す。

## 一様方向の成分の検算

次のセルは `UniformDirection` から $n$ 個の方向を作り、各成分の標本平均と標本の二次モーメント $\overline{X_j^2} = \frac{1}{n}\sum_i X_{ij}^2$ を理論値 0 と $1/d$ に比べる。
平均は既知（0）なので、分散の推定には平均を引かない二次モーメントを使う。
入力は次元 $d$（2 から 8）、標本数 $n$、SplitMix64 のシードである。
独立検算は前節で導いた $\mathbb{E}[X_j] = 0$、$\mathbb{E}[X_j^2] = 1/d$、$\operatorname{Var}(X_j^2) = 2(d-1)/(d^2(d+2))$ で、標準誤差は $\mathrm{SE}(\bar{X}_j) = \sqrt{1/(dn)}$、$\mathrm{SE}(\overline{X_j^2}) = \sqrt{\operatorname{Var}(X_j^2)/n}$ である。
図は各成分の $\overline{X_j^2}$ を $\pm 2$ SE のエラーバーで描き、横線で $1/d$ を示す。
表は成分ごとの平均、二次モーメント、それぞれの $z = (\text{推定} - \text{理論})/\mathrm{SE}$ を出し、最後の表はノルムの最大誤差と $\sum_j \overline{X_j^2}$ を出す。

```rust

//| ref: random-uniform-direction
//| title: 球面上の一様方向の成分の平均と二次モーメントを理論値と比べる

//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"components","path":"/rows/0/2","range":{"min":-4.5,"max":4.5}}
//|       - {"artifact":"components","path":"/rows/0/4","range":{"min":-4.5,"max":4.5}}

let columns = serde_json::json!([
    { "key": "0", "label": "成分 j", "type": "integer" },
    { "key": "1", "label": "平均 [-]", "type": "number", "format": fixed4 },
    { "key": "2", "label": "平均の z [-]", "type": "number", "format": fixed2 },
    { "key": "3", "label": "二次モーメント [-]", "type": "number", "format": fixed4 },

    { "key": "0", "label": "ノルムの最大誤差 max|‖X‖ − 1| [-]", "type": "number", "format": sci2 },
    { "key": "1", "label": "Σ_j 二次モーメント [-]", "type": "number", "format": fixed4 }
]);
emit_table_with_columns!(
```

既定の $d = 3$、$n = 4\,000$、シード 83 では、三つの成分の平均の $z$ が $0.90$、$-0.45$、$0.42$、二次モーメントが $0.3335$、$0.3261$、$0.3404$（$z$ は $0.03$、$-1.54$、$1.51$）で、理論値 $1/3$ との差はどれも 2 SE 以内である。
$|z| > 2$ となる確率は一つの量につき約 4.6% なので、6 個の $z$ のうち一つが 2 を超えても、それだけでは偏りの証拠にならない。
シードを 1 と 1000 に変えると二次モーメントの $z$ は $-1.73$ から $1.43$ の範囲に、$n = 20\,000$ では $-1.70$ から $1.34$ の範囲に入る。
ノルムの最大誤差は $3.3 \times 10^{-16}$ で、正規化の丸めの大きさにとどまる。

二次モーメントの和 $\sum_j \overline{X_j^2}$ は、各標本で $\sum_j X_{ij}^2 = 1$ が成り立つので丸めの範囲で 1 になり、統計的な検査にはならない。
同じ理由で成分の二次モーメントは負の相関を持ち、$d = 2$ では二つの $z$ が符号だけ違う値（$-0.18$ と $0.18$）になる。
$d = 8$、$n = 20\,000$ では理論値が $1/8$ に下がり、八つの二次モーメントの $z$ は $-1.47$ から $1.15$、平均の $z$ は $-1.95$ から $1.28$ の範囲にある。

## von Mises–Fisher 分布

平均の向き $\boldsymbol{\mu} \in S^{d-1}$ と集中度 $\kappa \ge 0$ の von Mises–Fisher 分布の密度は

$$
f(\mathbf{x}) = C_d(\kappa)\,e^{\kappa\boldsymbol{\mu}^{\mathsf T}\mathbf{x}},\qquad
C_d(\kappa) = \frac{\kappa^{d/2-1}}{(2\pi)^{d/2}I_{d/2-1}(\kappa)}
$$

で、平均は $A_d(\kappa)\boldsymbol{\mu}$（$A_d = I_{d/2}/I_{d/2-1}$）である。
$I_\nu$ は第 1 種の変形 Bessel 関数で、$\kappa = 0$ は一様分布、$d = 2$ は von Mises 分布になる。
`VonMisesFisher::new(&mean, concentration)` は $d \ge 2$ と、`contains_support` と同じ許容誤差で単位ベクトルの `mean` を求め、それ以外は `InvalidInput` か `DomainError` を返す。
$\kappa$ が 1 未満か $d/2 - 1$ 未満では Bessel 関数の正規化した級数を、それ以外では尺度付きの Bessel 関数を使い、$\kappa > 10^8 d^2$ では $1 - A_d$ の漸近展開を使う。
`mean_resultant_length()` は $A_d(\kappa)$、`direction()` は渡した平均の向きを返す。

標本は $\boldsymbol{\mu}$ 方向の成分 $W = \boldsymbol{\mu}^{\mathsf T}\mathbf{X}$ と、それに直交する一様な向きに分けて作る。
$W$ の周辺密度は $(1 - w^2)^{(d-3)/2}e^{\kappa w}$ に比例し、次元で方法を変える。

- $\kappa = 0$ は `UniformDirection` と同じ方法を使う。
- $d = 2$ は `VonMises` と同じ角度の標本化器（$\kappa < 0.5$ では一様包絡の棄却法、$\kappa \ge 0.5$ では Best–Fisher の方法）で角度を作り、平均の向きの角度だけ回す。
- $d = 3$ は周辺密度が $e^{\kappa w}$ に比例するので、分布関数を閉形式で逆に解いて $W = 1 + \kappa^{-1}\ln\bigl(U + (1 - U)e^{-2\kappa}\bigr)$ を作る。
- $d \ge 4$ は Wood（1994）の棄却法で、$\mathrm{Beta}\bigl(\frac{d-1}{2}, \frac{d-1}{2}\bigr)$ の変量から候補を作る。

どの場合も $1 - W$ を別に持ち、大きな $\kappa$ で接方向の小さな成分 $\sqrt{(1 - W)(1 + W)}$ を失わない。
接方向は $S^{d-2}$ 上の一様方向として作り、最後に北極を $\boldsymbol{\mu}$ に移す Householder 鏡映を掛ける。
鏡映の基準の極は $\mu_1$ の符号と反対側を選び、分母の打ち消しを避ける。

## von Mises–Fisher 分布の標本の検算

$d = 3$ では $W = \boldsymbol{\mu}^{\mathsf T}\mathbf{X}$ の密度が $[-1, 1]$ 上で $e^{\kappa w}$ に比例するので、その積分から

$$
\mathbb{E}[W] = \coth\kappa - \frac{1}{\kappa},\qquad
\mathbb{E}[W^2] = 1 - \frac{2\,\mathbb{E}[W]}{\kappa},\qquad
P(W > \cos\alpha) = \frac{1 - e^{-\kappa(1 - \cos\alpha)}}{1 - e^{-2\kappa}}
$$

が得られる。
$\mathbb{E}[W^2]$ は部分積分で、$P(W > \cos\alpha)$ は $\boldsymbol{\mu}$ から角度 $\alpha$ 以内に入る確率で、どちらも Bessel 関数を使わない閉形式である。
$\kappa \to 0$ の極限は一様分布の $0$、$1/3$、$(1 - \cos\alpha)/2$ になる。

次のセルは平均の向き $\boldsymbol{\mu} = (0.6, 0, 0.8)$ の `VonMisesFisher` から $n$ 個の方向を作り、$W$ の標本平均と、$\boldsymbol{\mu}$ から $30^\circ$ 以内に入った割合を上の閉形式と比べる。
$\boldsymbol{\mu}$ は北極から傾けてあるので、標本は Householder 鏡映を通る。
$W$ の標準誤差は $\sqrt{(\mathbb{E}[W^2] - \mathbb{E}[W]^2)/n}$、割合の標準誤差は $\sqrt{P(1 - P)/n}$ である。
3 次元の図は最初の 600 個の方向と $\boldsymbol{\mu}$ を単位球面の上に描き、回転させて集まり方を見られる。
入力は集中度 $\kappa$、標本数 $n$、SplitMix64 のシードである。

```rust
//| id: random-von-mises-fisher-sphere
//| ref: random-von-mises-fisher-sphere
//| title: 球面上の von Mises–Fisher 分布の標本を閉形式と比べる
//| run: reactive
//| crates: [scioxide-core, scioxide-random]
//| inputs:
//|   concentration: {"type":"range","label":"集中度 κ [-]","description":"0 では一様分布、大きいほど μ のまわりに集まる。","min":0,"max":40,"step":0.5,"value":5}
//|   sample_count: {"type":"range","label":"標本数 n [個]","description":"標準誤差を 1/√n で変える。","min":1000,"max":20000,"step":1000,"value":4000}
//|   seed: {"type":"range","label":"SplitMix64 のシード [-]","description":"z の値の標本ごとの揺らぎを見る。","min":1,"max":1000,"step":1,"value":29}
//| cases:
//|   - {"id":"uniform","label":"κ = 0","description":"一様分布で、E[W] = 0、30° 以内の割合は (1 − cos 30°)/2 ≈ 0.067。","inputs":{"concentration":0}}
//|   - {"id":"concentrated","label":"κ = 40","description":"ほとんどの方向が μ から 30° 以内に入り、E[W] = coth 40 − 1/40 = 0.975。","inputs":{"concentration":40}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"checks","path":"/rows/0/4","range":{"min":-4.5,"max":4.5}}
//|       - {"artifact":"checks","path":"/rows/1/4","range":{"min":-4.5,"max":4.5}}
//|       - {"artifact":"checks","path":"/rows/0/3","approx":{"value":0.8000908039820194,"atol":1e-12}}
//|       - {"artifact":"norms","path":"/rows/0/0","range":{"min":0,"max":1e-15}}
//|   - case: uniform
//|     expect:
//|       - {"artifact":"checks","path":"/rows/0/4","range":{"min":-4.5,"max":4.5}}
//|   - case: concentrated
//|     expect:
//|       - {"artifact":"checks","path":"/rows/0/4","range":{"min":-4.5,"max":4.5}}
//|       - {"artifact":"checks","path":"/rows/1/4","range":{"min":-4.5,"max":4.5}}
use scioxide_core::{NumericScalar, RealScalar};
use scioxide_random::{SeedableRng, SplitMix64, VonMisesFisher};

let (kappa, n) = (concentration, sample_count.round() as usize);
let nf = n as f64;
let mu = [0.6, 0.0, 0.8];
let law = VonMisesFisher::<f64>::new(&mu, kappa).map_err(|e| e.to_string())?;
let mut rng = SplitMix64::from_seed(seed.round() as u64);
// sample_n は n 個の方向を行ごとに並べた長さ 3n の列を返す。
let samples = law.sample_n(&mut rng, n).map_err(|e| e.to_string())?;
let cos_alpha = RealScalar::cos(30.0 * std::f64::consts::PI / 180.0);
let (mut w_sum, mut inside, mut norm_error) = (0.0_f64, 0.0_f64, 0.0_f64);
let mut points = Vec::new();
for (i, x) in samples.chunks(3).enumerate() {
    let w = mu[0] * x[0] + mu[1] * x[1] + mu[2] * x[2];
    w_sum += w;
    inside += if w > cos_alpha { 1.0 } else { 0.0 };
    let norm = x.iter().fold(0.0, |s: f64, &v| RealScalar::hypot(s, v));
    norm_error = RealScalar::max(norm_error, NumericScalar::abs(norm - 1.0));
    if i < 600 {
        points.push(serde_json::json!({
            "id": format!("x{i}"),
            "position": [x[0], x[1], x[2]],
            "group": "samples"
        }));
    }
}
points.push(serde_json::json!({ "id": "mu", "position": mu, "group": "mean", "label": "μ" }));
// 独立検算: W = μᵀX の密度は e^{κw} に比例し、E[W]、E[W²]、P(W > cos α) が閉形式になる。
let (mean_w, second_w, cap) = if kappa == 0.0 {
    (0.0, 1.0 / 3.0, (1.0 - cos_alpha) / 2.0)
} else {
    let a = 1.0 / RealScalar::tanh(kappa) - 1.0 / kappa;
    let cap = RealScalar::exp_m1(-kappa * (1.0 - cos_alpha)) / RealScalar::exp_m1(-2.0 * kappa);
    (a, 1.0 - 2.0 * a / kappa, cap)
};
let library = law.mean_resultant_length().map_err(|e| e.to_string())?;
let (w_bar, fraction) = (w_sum / nf, inside / nf);
let se_w = RealScalar::sqrt((second_w - mean_w * mean_w) / nf);
let se_cap = RealScalar::sqrt(cap * (1.0 - cap) / nf);
let (z_w, z_cap) = ((w_bar - mean_w) / se_w, (fraction - cap) / se_cap);
emit_scene3d!(
    serde_json::json!({
        "points": points,
        "groups": [
            { "id": "samples", "label": "標本の方向" },
            { "id": "mean", "label": "平均の向き μ" }
        ],
        "axes": {
            "x": { "label": "x₁", "unit": "-" },
            "y": { "label": "x₂", "unit": "-" },
            "z": { "label": "x₃", "unit": "-" }
        }
    }),
    metadata = serde_json::json!({ "id": "directions", "title": "単位球面上の方向" })
);
```

## まとめ

`UniformDirection` は正規ベクトルを正規化して作り、成分の平均 0、二次モーメント $1/d$、$\operatorname{Var}(X_j^2) = 2(d-1)/(d^2(d+2))$ を標準誤差付きで確かめられる。
`VonMisesFisher` は次元で生成法を切り替え（$d = 2$ は von Mises の角度、$d = 3$ は閉形式の逆関数、$d \ge 4$ は Wood の棄却法）、Householder 鏡映で平均の向きへ回す。
$d = 3$ の標本は平均の向きに沿った成分 $W$ の平均と、平均の向きのまわりの円錐に入る割合を、Bessel 関数を使わない閉形式と標準誤差で比べて確かめられる。
ノルムの誤差や成分の二乗和は丸めの確認にとどまるので、分布の検算には統計量と標準誤差を使う。
