分散分析で群の平均に差があると分かったとき、どの群の組に差があるかを調べるには、すべての対を同時に比べる多重比較を行う。
Tukey の方法は群の平均の最大と最小の差を誤差の標準偏差で割ったスチューデント化範囲の分布から、全体の第一種の誤りの確率を保つ臨界値を作る。
このページは `StudentizedRange` の裾を求める二重積分と評価の場合分けを説明し、臨界値での同時の誤り確率を独立な方法と照合する。
分布に共通の仕様と裾のレポート `TestStatisticResult` は[検定統計量の分布一覧と数理仕様](oxref:random-tests-contracts)にある。

## スチューデント化範囲

$k$ 個の群の平均が独立に $\mathcal{N}(\mu, \sigma^2/r)$ に従い、自由度 $\nu$ の独立な分散推定 $s^2$（$\nu s^2/\sigma^2 \sim \chi^2_\nu$）があるとき、

$$
Q = \frac{\max_i \bar{X}_i - \min_i \bar{X}_i}{s/\sqrt{r}}
$$

をスチューデント化範囲という。
Tukey の HSD による同時対比較は、$Q$ の上側分位点を臨界値に使う。
$Q = R/S$（$R$ は標準正規 $k$ 個の範囲、$S = s/\sigma$）と書くと、$S$ と $R$ が独立なので

$$
P(Q \le x) = \mathbb{E}_S\bigl[P(R \le xS)\bigr],\qquad
P(R \le w) = k\int_{-\infty}^{\infty} \phi(z)\bigl[\Phi(z + w) - \Phi(z)\bigr]^{k-1}\,dz
$$

となる（$\phi$、$\Phi$ は標準正規の密度と分布関数）。
内側の積分は最小値が $z$ にあり、残りの $k - 1$ 個が $(z, z + w]$ に入る確率を足し合わせたものである。

`StudentizedRange::new(k, degrees)` は実数の $k > 1$ と、正の $\nu$ または `f64::INFINITY` を受け付ける。
$\nu = \infty$ では $S = 1$ で、外側の平均はない。
評価は次の順に場合を分ける。

- $k = 2$ は $Q = \sqrt{2}\,\lvert T \rvert$（$T$ は自由度 $\nu$ の Student t、$\nu = \infty$ では標準正規）に帰着させ、その閉じた裾を使う。
- 小さな $w$（$kw^2$ が許容誤差の 1/100 未満）では $P(R \le w) \approx \sqrt{k}\,(w/\sqrt{2\pi})^{k-1}$、大きな $w$ では一組の差の裾 $k(k-1)\,P(Z > w/\sqrt{2})$ を使う。
  後者は二組の超過が重なる項が $e^{-w^2/3}$ の大きさで、先頭の $e^{-w^2/4}$ より小さいことを使い、省いた項が許容誤差の 1/1000 を下回る範囲に限る。
- $k = 3$ の正規範囲は Owen の T 関数で $P(R > w) = 12\,T(w/\sqrt{2}, 1/\sqrt{3})$ と書けるので、その評価を使う。
- それ以外は上の内側の積分を数値で求める。
  上側確率は $1 - P(R \le w)$ を作らず、正の被積分関数で直接積分する。

外側の平均は $r = \ln S$ の上の積分で、$S^2 \sim \chi^2_\nu/\nu$ の対数密度の中の $e^{2r} - 1 - 2r$ を桁落ちなしに評価するので、密度の峰 $r = 0$ の近くでも精度を失わない。
積分はどれも、対数で表した被積分関数に対する適応 Gauss–Kronrod 法（7 点の Gauss と 15 点の Kronrod の組）で、区間の二つの値の差で分割を決める。
内側の積分に与える許容誤差は外側の $1/32$ にして、内側の誤差が外側の見積もりを支配しないようにする。
この見積もりは証明された誤差限界ではない。
整数の $k$ の標本は $k$ 個の正規乱数の範囲を独立なカイ尺度で割って作り、整数でない $k$ には生成のモデルがないので逆変換で作る。
モーメントと分位点は裾の積分を繰り返すので、既定より大きな作業量が要ることがある。

## Tukey の臨界値と同時の誤り確率

Tukey の HSD では $k$ 群の対比較を同時に行い、全体の第一種の誤りの確率を $\alpha$ に保つ臨界値として、スチューデント化範囲の上側 $\alpha$ 点 $q_{\alpha}(k, \nu)$ を使う。
臨界値 $q$ を使ったときの全体の誤りの確率は $P(Q > q)$ である。
次のセルは与えた $q$ での $P(Q > q)$ を `StudentizedRange::evaluate_tail` で求め、推定絶対誤差と評価回数を出す。
有限の $\nu$ では 1 回の裾が二重積分で 10 万回を超える評価を要するので、作業量の上限を $2^{24}$ に上げ、セルはボタンで実行する。
分位点 `isf` はこの裾の評価を数十回繰り返すので、さらに時間がかかる。

独立検算は二つある。
$k = 2$ では $Q = \sqrt{2}\,\lvert T \rvert$ なので $P(Q > q) = 2P(T > q/\sqrt{2})$（$\nu = \infty$ では $T$ を標準正規に置き換える）と比べる。
どの $k$ でも、`Normal` の $k$ 個の範囲を `ChiSquared` のカイ尺度 $\sqrt{\chi^2_\nu/\nu}$ で割った $Q$ を $R$ 回作り、$Q > q$ となる割合を、理論の確率と二項分布の標準誤差で比べる。
この標本は `StudentizedRange` の積分も標本化器も通らない。

```rust
//| id: random-tukey-critical-value
//| ref: random-tukey-critical-value
//| title: Tukey の臨界値での同時の誤り確率をスチューデント化範囲の裾で求め、t 分布と Monte Carlo で照合する
//| run: button
//| crates: [scioxide-random, scioxide-core]
//| inputs:
//|   groups: {"type":"range","label":"群の数 k [個]","min":2,"max":8,"step":1,"value":4}
//|   degrees: {"type":"select","label":"誤差の自由度 ν","options":["5","10","20","60","∞"],"value":"20"}
//|   critical: {"type":"range","label":"臨界値 q [-]","min":2,"max":6,"step":0.01,"value":3.96}
//|   replications: {"type":"range","label":"Monte Carlo の反復回数 R [回]","min":10000,"max":50000,"step":10000,"value":20000}
//|   seed: {"type":"range","label":"乱数のシード","min":1,"max":1000,"step":1,"value":5}
//| cases:
//|   - {"id":"two-groups","label":"k = 2、q = 2.95","description":"Q = √2|T| の恒等式で照合できる。q_{0.05}(2, 20) = √2 t_{0.025, 20} の近く。","inputs":{"groups":2,"critical":2.95}}
//|   - {"id":"normal-scale","label":"k = 3、ν = ∞、q = 3.31","description":"外側の積分がなく、k = 3 の正規範囲は Owen の T 関数で評価する。","inputs":{"groups":3,"degrees":"∞","critical":3.31}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"tail","path":"/rows/0/2","range":{"min":0.045,"max":0.055}}
//|       - {"artifact":"simulation","path":"/rows/0/3","range":{"min":-4,"max":4}}
//|   - case: two-groups
//|     expect:
//|       - {"artifact":"tail","path":"/rows/0/4","range":{"min":-1e-12,"max":1e-12}}
//|       - {"artifact":"simulation","path":"/rows/0/3","range":{"min":-4,"max":4}}
//|   - case: normal-scale
//|     expect:
//|       - {"artifact":"tail","path":"/rows/0/2","range":{"min":0.045,"max":0.055}}
//|       - {"artifact":"simulation","path":"/rows/0/3","range":{"min":-4,"max":4}}
use scioxide_core::{Budget, RealScalar};
use scioxide_random::{
    ChiSquared, Distribution, LawOptions, Normal, SeedableRng, SplitMix64, StudentT,
    StudentizedRange, Survival,
};

let sig5 = serde_json::json!({ "significantDigits": 5 });
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let fixed2 = serde_json::json!({ "fractionDigits": 2 });
let k = groups.round() as usize;
let nu: f64 = if degrees == "∞" {
    f64::INFINITY
} else {
    degrees
        .parse()
        .map_err(|e: std::num::ParseFloatError| e.to_string())?
};
let q = critical;
let work = Budget::try_from(1_usize << 24).map_err(|e| e.to_string())?;
let options = LawOptions::default().with_work_budget(work);
let law = StudentizedRange::with_options(k as f64, nu, options).map_err(|e| e.to_string())?;
let tail = law.evaluate_tail(q, true).map_err(|e| e.to_string())?;
let probability = RealScalar::exp(tail.log_probability);
// k = 2 の恒等式 P(Q > q) = 2 P(T > q/√2)（ν = ∞ では標準正規）。
let identity = if k == 2 {
    let x = q / std::f64::consts::SQRT_2;
    let upper = if nu.is_finite() {
        StudentT::new(nu).map_err(|e| e.to_string())?.sf(x)
    } else {
        Normal::new(0.0, 1.0).map_err(|e| e.to_string())?.sf(x)
    };
    Some(probability - 2.0 * upper.map_err(|e| e.to_string())?)
} else {
    None
};
let columns = serde_json::json!([
    { "key": "0", "label": "群の数 k", "type": "integer" },
    { "key": "1", "label": "臨界値 q [-]", "type": "number" },
    { "key": "2", "label": "P(Q > q) [-]", "type": "number", "format": sig5 },
    { "key": "3", "label": "推定絶対誤差 [-]", "type": "number", "format": sci2 },
    { "key": "4", "label": "t 分布との差 [-]", "type": "number", "format": sci2, "nullText": "k ≠ 2" },
    { "key": "5", "label": "評価回数", "type": "integer" }
]);
emit_table_with_columns!(
    columns,
    vec![(
        k,
        q,
        probability,
        tail.absolute_error,
        identity,
        tail.evaluations
    )],
    metadata = serde_json::json!({ "id": "tail" })
);
// 独立検算: Normal の k 個の範囲を √(χ²_ν/ν) で割った Q を R 回作る。
let normal = Normal::new(0.0, 1.0).map_err(|e| e.to_string())?;
let chi = if nu.is_finite() {
    Some(ChiSquared::new(nu).map_err(|e| e.to_string())?)
} else {
    None
};
let mut rng = SplitMix64::from_seed(seed as u64);
let mut exceed = 0_usize;
for _ in 0..replications as usize {
    let (mut low, mut high) = (f64::INFINITY, f64::NEG_INFINITY);
    for _ in 0..k {
        let z = normal.sample(&mut rng).map_err(|e| e.to_string())?;
        (low, high) = (RealScalar::min(low, z), RealScalar::max(high, z));
    }
    let scale = match &chi {
        Some(chi) => RealScalar::sqrt(chi.sample(&mut rng).map_err(|e| e.to_string())? / nu),
        None => 1.0,
    };
    if (high - low) / scale > q {
        exceed += 1;
    }
}
let r = replications.round();
let rate = exceed as f64 / r;
let se = RealScalar::sqrt(probability * (1.0 - probability) / r);
let columns = serde_json::json!([
    { "key": "0", "label": "Q > q の回数", "type": "integer" },
    { "key": "1", "label": "割合 [-]", "type": "number", "format": sig5 },
    { "key": "2", "label": "標準誤差 [-]", "type": "number", "format": sci2 },
    { "key": "3", "label": "z [-]", "type": "number", "format": fixed2 }
]);
emit_table_with_columns!(
    columns,
    vec![(exceed, rate, se, (rate - probability) / se)],
    metadata = serde_json::json!({ "id": "simulation" })
);
```

既定の入力（$k = 4$、$\nu = 20$、$q = 3.96$）では $P(Q > q) = 0.049877$ で、推定絶対誤差は $7.4 \times 10^{-10}$、評価回数は 169,996 回である。
$q = 3.96$ で全体の誤りの確率が 0.05 をわずかに下回るので、$q_{0.05}(4, 20)$ は 3.96 のすぐ下にある。
Monte Carlo の割合は 20,000 回中 979 回の 0.04895 で、標準誤差 0.0015 に対して $z = -0.60$ である。
$k = 2$、$q = 2.95$ では $P(Q > q) = 0.0499998$ で、Student t による値との差は $1.4 \times 10^{-17}$ である。
$k = 3$、$\nu = \infty$、$q = 3.31$ では Owen の T 関数を使うので評価回数は 32 回に減り、$P(Q > q) = 0.050403$ に対して Monte Carlo は $z = -0.33$ となる。
同じ $q = 3.96$ でも、$\nu$ を 5 にすると $P(Q > q)$ は 0.12584、$k$ を 8 にすると 0.15030 に増える。
誤差の自由度が小さいほど、また群が多いほど、同じ臨界値での同時の誤りは増えるので、臨界値は $k$ と $\nu$ ごとに求め直す。

## まとめ

スチューデント化範囲の裾は正規範囲の積分とカイ尺度での平均からなる二重積分である。
`StudentizedRange` は $k = 2$ を Student t、$k = 3$ を Owen の T 関数に帰着させ、小さい範囲と大きい範囲は漸近形で、それ以外は適応 Gauss–Kronrod 法の求積で裾を求める。
有限の $\nu$ では 1 回の裾に 10 万回を超える評価が要るので、`LawOptions` の作業量の上限を大きくし、分位点 `isf` は時間がかかると見込んで使う。
臨界値 $q$ での同時の誤り確率は `evaluate_tail(q, true)` で推定絶対誤差とともに求められ、$k$ と $\nu$ を変えると同じ $q$ でも大きく変わる。
`scioxide-stats` の Tukey–Kramer と Games–Howell は、この裾を使って同時の $p$ 値と信頼区間を作る。
