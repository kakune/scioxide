洪水の水位や保険の損害額では、年最大値だけでなく、高い閾値 $u$ を超えたすべての観測を使って裾を推定することが多い（閾値超過法、peaks over threshold）。
その根拠は[極値の極限定理](oxref:random-extreme-limit-theorems)の Pickands–Balkema–de Haan の定理である。
このページは標準の一般化極値分布を例に、超過量の分布が一般化 Pareto 分布にどれだけ近いかを閉形式で求め、閾値の高さによる近似の偏りと統計的な揺らぎの釣り合いを標本で確かめる。
形状母数の符号（`GeneralizedExtremeValue::new(c)` は $c = -\xi$、`GeneralizedPareto::new(c)` は $c = \xi$）の対応は[形状母数の符号の規約](oxref:random-extreme-shape-sign)で確かめる。

## 閾値超過と一般化 Pareto 分布

標準の一般化極値分布（極値指数 $\xi$）の分布関数は $F(x) = e^{-t(x)}$、$t(x) = (1 + \xi x)^{-1/\xi}$ である。
上側確率は $S(x) = 1 - e^{-t(x)}$ で、大きな $x$ では $t(x)$ が小さいので $S(x) \approx t(x)$ である。
したがって閾値 $u$ の超過量 $Y = X - u$ について

$$
\frac{S(u + y)}{S(u)} \approx \frac{t(u + y)}{t(u)} = \Bigl(1 + \frac{\xi y}{1 + \xi u}\Bigr)^{-1/\xi}
$$

となり、$Y/\sigma(u)$（$\sigma(u) = 1 + \xi u$）は近似的に `GeneralizedPareto::new(ξ)` に従う。
$\xi = 0$ では $\sigma(u) = 1$ で、超過量は近似的に単位指数分布に従う。
近似の誤差は $S(u)$ が小さいほど、つまり閾値が高いほど小さい。

一般化 Pareto 分布の平均は $\xi < 1$ のとき $1/(1 - \xi)$ なので、超過量の平均（平均超過）は近似的に $\sigma(u)/(1 - \xi) = (1 + \xi u)/(1 - \xi)$ である。
平均超過が閾値 $u$ の一次関数で、傾きが $\xi/(1 - \xi)$ になることは、一般化 Pareto 分布に従う裾の特徴である。

閾値を上げると近似の偏りは減るが、超過の個数 $k$ も減って統計的な揺らぎが大きくなる。
閾値の選び方はこの偏りと揺らぎの釣り合いで決まる。

## 近似の偏りの閉形式

標準の一般化極値分布では近似の偏りを閉形式で書ける。
$1 + \xi y/\sigma(u) = (1 + \xi x)/(1 + \xi u)$（$x = u + y$）なので、一般化 Pareto 分布の分布関数に代入すると

$$
H_\xi\bigl(y/\sigma(u)\bigr) = 1 - \frac{t(x)}{t(u)}
$$

である。
$U = F(X)$ は一様分布に従い、$t(X) = -\ln U$ と書ける。
閾値の上側確率を $q = S(u)$、$t_q = t(u) = -\ln(1 - q)$ とすると、変換した値 $V = 1 + \ln U/t_q$ は $\xi$ によらない。
$X > u$ のとき $U$ は $(1 - q, 1)$ の上で一様なので、$V$ の分布関数は

$$
P(V \le v \mid X > u) = \frac{(1 - q)^{1 - v} - (1 - q)}{q}, \qquad 0 \le v \le 1
$$

である。
近似が正確なら $V$ は一様分布に従うので、この分布関数と $v$ の差の最大値が、母集団での超過量の分布と一般化 Pareto 分布との KS 距離になる。
差を $v$ で微分して 0 とおくと $(1 - q)^{1 - v} = q/t_q$ で、そこでの差の大きさは

$$
\delta(q) = \frac{1 - q/t_q}{q} - \frac{\ln(t_q/q)}{t_q}
$$

である。
$t_q = q + q^2/2 + O(q^3)$ を代入して展開すると、小さな $q$ では $\delta(q) \approx q/8$ になる。

標本から求めた KS 距離 $D_k$ は、三角不等式から、$\delta(q)$ と、真の条件付き分布に対する標本の KS 距離の和を超えない。
後者は 95% の確率で約 $1.358/\sqrt{k}$ 以下なので、$\sqrt{k}\,\delta(q)$ が Kolmogorov 分布の 95% 点 1.358 に届くほど $k$ が大きくなると、近似の偏りが検出されはじめる。
$q = 0.05$ では $\delta = 0.0064$ なので、その超過数は約 $4.5 \times 10^4$ 個（標本数にして約 $9 \times 10^5$ 個）である。

## 標本による照合

次のセルは一般化極値分布から $n$ 個の標本を作り、上側確率 $q$ の点 $u = $ `isf(q)` を閾値とする。
超過量を $\sigma(u)$ で割って `GeneralizedPareto::new(ξ)` との KS 距離 $D_k$ を求め、$p$ 値を有限標本の `KolmogorovSmirnovTwoSided`（標本数 $k$）と漸近の `Kolmogorov` の両方で出す。
1 つ目の表の最後の列 $\delta(q)$ は上で導いた母集団での KS 距離の閉形式（独立検算）である。
2 つ目の表は超過量の標本平均を一般化 Pareto 分布の平均 $\sigma(u)/(1 - \xi)$ と比べ、標準誤差で割った $z$ を出す。
入力の範囲 $\xi \le 0.4$ では超過量の分散が有限なので、標準誤差を $s/\sqrt{k}$ で推定できる。

```rust
//| id: random-gev-threshold-excess
//| ref: random-gev-threshold-excess
//| title: 一般化極値分布の閾値超過を一般化 Pareto 分布と比べる
//| run: reactive
//| crates: [scioxide-random, scioxide-core]
//| inputs:
//|   xi: {"type":"range","label":"極値指数 ξ","min":-0.3,"max":0.4,"step":0.05,"value":0.2}
//|   tail: {"type":"select","label":"閾値の上側確率 q","description":"小さいほど閾値が高く、超過の個数 k = nq が減る。","options":["0.5","0.2","0.05","0.01"],"value":"0.05"}
//|   sample_count: {"type":"range","label":"標本数 n [個]","min":10000,"max":50000,"step":10000,"value":40000}
//|   seed: {"type":"range","label":"乱数のシード","min":1,"max":1000,"step":1,"value":7}
//| cases:
//|   - {"id":"median-threshold","label":"q = 0.5（中央値を閾値）","description":"母集団での距離 δ(q) = 0.086 が揺らぎ 1.358/√k より大きく、p 値が極端に小さくなる。","inputs":{"tail":"0.5"}}
//|   - {"id":"high-threshold","label":"q = 0.01（高い閾値）","description":"δ(q) = 0.0013 は小さいが、超過数 k が約 400 に減って揺らぎが大きくなる。","inputs":{"tail":"0.01"}}
//|   - {"id":"weibull-type","label":"ξ = −0.3","description":"同じシードと q では D_k が ξ によらない。平均超過は ξ で変わる。","inputs":{"xi":-0.3}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"distance","path":"/rows/0/2","range":{"min":1800,"max":2200}}
//|       - {"artifact":"distance","path":"/rows/0/7","approx":{"value":0.0064114,"atol":1e-6}}
//|       - {"artifact":"distance","path":"/rows/0/3","range":{"min":0.003,"max":0.05}}
//|       - {"artifact":"mean-excess","path":"/rows/0/3","range":{"min":-4,"max":4}}
//|   - case: median-threshold
//|     expect:
//|       - {"artifact":"distance","path":"/rows/0/7","approx":{"value":0.0860713,"atol":1e-6}}
//|       - {"artifact":"distance","path":"/rows/0/3","range":{"min":0.07,"max":0.1}}
//|       - {"artifact":"distance","path":"/rows/0/5","range":{"min":0,"max":1e-10}}
//|   - case: high-threshold
//|     expect:
//|       - {"artifact":"distance","path":"/rows/0/2","range":{"min":320,"max":480}}
//|       - {"artifact":"distance","path":"/rows/0/7","approx":{"value":0.0012563,"atol":1e-6}}
//|       - {"artifact":"mean-excess","path":"/rows/0/3","range":{"min":-4.5,"max":4.5}}
//|   - case: weibull-type
//|     expect:
//|       - {"artifact":"distance","path":"/rows/0/3","range":{"min":0.003,"max":0.05}}
//|       - {"artifact":"mean-excess","path":"/rows/0/3","range":{"min":-4,"max":4}}
use scioxide_core::{Budget, RealScalar};
use scioxide_random::{
    Cdf, Distribution, GeneralizedExtremeValue, GeneralizedPareto, InverseSurvival, Kolmogorov,
    KolmogorovSmirnovTwoSided, LawOptions, SeedableRng, SplitMix64, Survival,
};

let sig4 = serde_json::json!({ "significantDigits": 4 });
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let fixed2 = serde_json::json!({ "fractionDigits": 2 });
let q: f64 = tail
    .parse()
    .map_err(|e: std::num::ParseFloatError| e.to_string())?;
let gev = GeneralizedExtremeValue::new(-xi).map_err(|e| e.to_string())?;
let gpd = GeneralizedPareto::new(xi).map_err(|e| e.to_string())?;
// 閾値 u は上側確率 q の点、GPD の尺度は σ(u) = 1 + ξu。
let u = gev.isf(q).map_err(|e| e.to_string())?;
let sigma = 1.0 + xi * u;
let mut rng = SplitMix64::from_seed(seed as u64);
let mut excess = Vec::new();
for _ in 0..sample_count as usize {
    let x = gev.sample(&mut rng).map_err(|e| e.to_string())?;
    if x > u {
        excess.push(x - u);
    }
}
excess.sort_by(f64::total_cmp);
// 超過量を σ(u) で割った値と GPD(ξ) の KS 距離。
let (k, kf) = (excess.len(), excess.len() as f64);
let mut d_k = 0.0;
for (i, &y) in excess.iter().enumerate() {
    let f = gpd.cdf(y / sigma).map_err(|e| e.to_string())?;
    d_k = RealScalar::max(
        d_k,
        RealScalar::max((i + 1) as f64 / kf - f, f - i as f64 / kf),
    );
}
// p 値: 有限標本の分布（行列法の作業量に足りる上限）と漸近の分布。
let work = Budget::try_from(1_usize << 24).map_err(|e| e.to_string())?;
let options = LawOptions::default().with_work_budget(work);
let finite = KolmogorovSmirnovTwoSided::with_options(k, options).map_err(|e| e.to_string())?;
let p_finite = finite.sf(d_k).map_err(|e| e.to_string())?;
let limit = Kolmogorov::new().map_err(|e| e.to_string())?;
let p_limit = limit
    .sf(RealScalar::sqrt(kf) * d_k)
    .map_err(|e| e.to_string())?;
// 独立検算: 母集団での KS 距離 δ(q) = (1 − q/t)/q − ln(t/q)/t、t = −ln(1 − q)。
let t = -RealScalar::ln_1p(-q);
let delta = (1.0 - q / t) / q - RealScalar::ln(t / q) / t;
let columns = serde_json::json!([
    { "key": "0", "label": "閾値 u [-]", "type": "number", "format": sig4 },
    { "key": "1", "label": "σ(u) [-]", "type": "number", "format": sig4 },
    { "key": "2", "label": "超過数 k", "type": "integer" },
    { "key": "3", "label": "D_k [-]", "type": "number", "format": sig4 },
    { "key": "4", "label": "√k·D_k [-]", "type": "number", "format": sig4 },
    { "key": "5", "label": "p 値（有限 k）", "type": "number", "format": sig4 },
    { "key": "6", "label": "p 値（漸近）", "type": "number", "format": sig4 },
    { "key": "7", "label": "δ(q) [-]", "type": "number", "format": sci3 }
]);
emit_table_with_columns!(
    columns,
    vec![(
        u,
        sigma,
        k,
        d_k,
        RealScalar::sqrt(kf) * d_k,
        p_finite,
        p_limit,
        delta
    )],
    metadata = serde_json::json!({ "id": "distance" })
);
// 平均超過: GPD の平均 σ(u)/(1 − ξ) と標本平均の z。
let mean = excess.iter().sum::<f64>() / kf;
let var = excess
    .iter()
    .map(|&y| RealScalar::powi(y - mean, 2))
    .sum::<f64>()
    / (kf - 1.0);
let se = RealScalar::sqrt(var / kf);
let gpd_mean = sigma / (1.0 - xi);
let columns = serde_json::json!([
    { "key": "0", "label": "GPD の平均超過 [-]", "type": "number", "format": sig4 },
    { "key": "1", "label": "標本の平均超過 [-]", "type": "number", "format": sig4 },
    { "key": "2", "label": "標準誤差 [-]", "type": "number", "format": sig4 },
    { "key": "3", "label": "z [-]", "type": "number", "format": fixed2 }
]);
emit_table_with_columns!(
    columns,
    vec![(gpd_mean, mean, se, (mean - gpd_mean) / se)],
    metadata = serde_json::json!({ "id": "mean-excess" })
);
```

既定の入力（$\xi = 0.2$、$q = 0.05$、$n = 40\,000$、シード 7）では閾値 $u = 4.056$、$\sigma(u) = 1.811$、超過数 $k = 1\,984$ である。
$D_k = 0.0197$、$\sqrt{k}\,D_k = 0.878$ で、$p$ 値は有限標本の分布で 0.418、漸近の分布で 0.423 となり、この $k$ では一般化 Pareto 分布との違いを検出できない。
母集団での偏り $\delta = 0.0064$ は揺らぎの目安 $1.358/\sqrt{1\,984} = 0.030$ の 5 分の 1 程度である。
平均超過は一般化 Pareto 分布の値 2.2641 に対して標本 2.2209（$z = -0.76$）である。
同じシードと $q$ で $\xi = -0.3$ にしても $D_k = 0.0197$ は変わらず、平均超過の比較（$z = 0.33$）だけが変わる。
標本を逆関数法で作るので、$D_k$ は前節の変換 $V$ を通して一様乱数だけで決まるからである。

閾値を中央値（$q = 0.5$）まで下げると $\delta = 0.0861$ が揺らぎ $1.358/\sqrt{19\,873} = 0.0096$ を大きく上回り、$D_k = 0.0888$、$p$ 値は有限標本の分布で $6.8 \times 10^{-137}$ になる。
平均超過も $z = 19.5$ で、近似の偏りがはっきり現れる。
$q = 0.01$ では $\delta = 0.00126$ と偏りは小さいが、超過数が $k = 393$ に減って揺らぎが大きくなる（$D_k = 0.0369$、$p = 0.646$）。
このとき平均超過の $z = -2.50$ は、偏りの小さい高い閾値での値なので主に揺らぎによるもので、正規近似で $\lvert z \rvert > 2.5$ となる確率は約 1.2% である。
有限標本と漸近の $p$ 値の差は $k = 1\,984$ で 0.005、$k = 393$ で 0.014 と、$k$ が小さいほど大きい。

## まとめ

高い閾値の超過量は Pickands–Balkema–de Haan の定理により尺度 $\sigma(u)$ の一般化 Pareto 分布で近似でき、標準の一般化極値分布では $\sigma(u) = 1 + \xi u$ である。
その近似の偏りは母集団での KS 距離 $\delta(q)$ として閉形式で書け、小さな上側確率 $q$ では $q/8$ 程度である。
閾値を下げると偏りが $1.358/\sqrt{k}$ の揺らぎを上回って検定で検出され、上げると超過数が減って推定の揺らぎが増えるので、閾値は両者を比べて選ぶ。
KS の $p$ 値は `KolmogorovSmirnovTwoSided` で超過数 $k$ の有限標本の分布から求められ、漸近の Kolmogorov 分布との差は $k$ が小さいほど大きい。
平均超過を一般化 Pareto 分布の平均と標準誤差で比べると、KS 距離とは別の角度から近似を点検できる。
