この表は実数値の確率分布をまとめる。
すべての分布は `Distribution`、`Density`、`LogDensity`、`Cdf`、`LogCdf`、`Survival`、`LogSurvival`、`Quantile`、`InverseSurvival`、`Support` を実装し、`f32` と `f64` で使える。
「仕様の要点」には母数の条件、位置と尺度の扱い、`Mean`・`Variance`・`Entropy` の有無、数値計算の方法を書く。
母数の定義域の違反は `DomainError`、非有限な母数は `NonFinite` である。
ただし `IrwinHall` の項数 $n = 0$ は `InvalidInput` になる。
`LawOptions` を使う分布は `new` で既定の設定を使い、`with_options` で受け取った設定の許容誤差が範囲外なら `InvalidInput` として拒否する。
標準形だけを持つ分布は `Affine::new(law, 位置, 尺度)` で位置と尺度を付ける。
標本化の方法は[連続分布の変換・棄却・裾野制御](../../algorithms/continuous-distributions/)で説明した。
