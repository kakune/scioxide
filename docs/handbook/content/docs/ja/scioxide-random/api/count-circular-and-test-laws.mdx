この表は整数を返す計数の分布、角度と方向の分布、検定統計量の分布をまとめる。
計数の分布は `Mass`、`LogMass`、`Cdf`、`LogCdf`、`Survival`、`LogSurvival`、`Quantile`、`InverseSurvival`、`Mean`、`Variance` と、台のトレイト（非負なら `CountSupport`、符号付きなら `SignedCountSupport`）を実装する。
`Entropy` を実装する計数の分布は `Binomial` だけである。
標本は `CountDistribution` の `sample`、`sample_n`、`sample_n_into` で作り（[整数の標本と CountDistribution](oxref:random-discrete-count-distribution)）、`LawOptions` を持つ分布は一つの標本のワードを `sample_word_budget` で数える。
`LawOptions` を取る分布のコンストラクター `new` は既定の設定を使い、`with_options` が最後の引数で設定を取る。
