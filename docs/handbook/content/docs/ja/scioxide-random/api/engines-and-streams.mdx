この表は整数のワードを作る生成器と、それを前進・分割・保存する手段をまとめる。
どの生成器も統計的なシミュレーション用で暗号用途には使えず、シードは `SeedableRng::from_seed` か、呼び出し側が渡すエントロピーから与える。
ネイティブ出力ワードと一様乱数ワードの違いは[一様乱数ワードと浮動小数点への変換](oxref:random-algorithms-uniform-conversion)、再現性の範囲は[再現性の範囲](oxref:random-algorithms-reproducibility)にある。

## 生成器
