この表はすべての確率分布が共有する対応機能を表すトレイトと、分布を組み合わせたり利用者の密度から標本を作ったりする型をまとめる。
分布は実装できる機能だけを実装し、存在しない量を数値積分で補う代替はない。
機能の規約は[分布の機能・裾確率・数値逆算](../../algorithms/laws-tails-and-multivariate-models/)で説明した。
