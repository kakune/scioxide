この表はベクトルや行列を値に持つ分布と、多変量の矩形確率を求める Plan をまとめる。
ベクトル・行列の分布は任意の `BitGenerator` に対し、`sample_width`、`workspace_requirements(policy, n)`、`workspace(policy, n)`、一つの標本を所有値を返す API の `Vec` で返す `sample`、$n$ 個の標本を行ごとに並べた所有の `Vec` で返す `sample_n(rng, n)`、行バッチの `sample_n_into(rng, policy, output, workspace)`、行ごとに `root.split(row)` を使う `sample_indexed_into` を持つ。
コンストラクター `new` は既定の `LawOptions` を使い、`with_options` が最後の引数で設定を取る。
行列の標本は `shape()` の行優先の平たい配列で返る。
台の判定 `contains_support` は多くの分布が持つが、`NormalInverseGamma`、`MatrixNormal`、`MatrixT`、群の Haar 測度と `RandomCorrelation` は持たない。
母数の定義域の違反は `DomainError`、形の不一致は `DimensionMismatch`、`LawOptions` のメモリ領域の上限の超過は `ResourceLimit` である。

|---|---|---|---|---|---|
| [`MultivariateProbabilityPlan`](https://docs.rs/scioxide-random/0.1.0/scioxide_random/struct.MultivariateProbabilityPlan.html) | 構造体 | 矩形確率の不変な Plan | `MultivariateNormal::prepare_probability(options, &root)`（`root` は `Philox4x64`）か `MultivariateStudentT` の同名の関数で作る。保持した因子を列ピボット付き Householder LQ で下台形にし、QMC の次元は保持階数 $r$（t 分布は $r + 1$）。`rectangle(&lower, &upper)` は $P(\mathbf{a} < \mathbf{X} \le \mathbf{b})$（無限の端を許す）を新しい作業領域で呼び出したスレッドの上で評価し、`rectangle_scoped(&lower, &upper, &mut workspace, scope)` は作業領域を使い回して反復を実行の範囲のエグゼキューターで走らせ、被積分関数の評価ごとに取り消しと期限を確かめる。結果は実行の順序によらない。階数 0 と 1、対角の正規の因子は閉形式、それ以外は Genz の条件付き積分をランダム化した Sobol の反復で評価する。精度が足りなくてもエラーにせず `termination` で返す | [多変量同時確率の数値計算](oxref:random-multivariate-probability) | - |

| [`MultivariateProbabilityWorkspace`](https://docs.rs/scioxide-random/0.1.0/scioxide_random/struct.MultivariateProbabilityWorkspace.html) | 構造体 | 反復ごとの条件付きの座標 | `plan.workspace()` で作る固定の大きさの作業領域で、`rectangle_scoped` に渡す。形の合わない作業領域は `InvalidInput`。ランダム化した点列は評価ごとに作る | [多変量同時確率の数値計算](oxref:random-multivariate-probability) | - |
| [`MultivariateProbabilityReport`](https://docs.rs/scioxide-random/0.1.0/scioxide_random/struct.MultivariateProbabilityReport.html) | 構造体 | 同時確率の推定 | `probability`、`log_probability`、`estimated_absolute_error`（ランダム化した反復の平均の標準誤差の 6 倍で、経験的な推定）、`log_estimated_absolute_error`、`evaluations`（閉形式では 0）、`termination`。標本化したすべての寄与が 0 のときは推定誤差を保守的な上界 1（対数 0）とし、`AccuracyNotMet` にする。解析的な確率 0 は誤差 0 のまま | [多変量同時確率の数値計算](oxref:random-multivariate-probability) | - |
| [`MultivariateProbabilityTermination`](https://docs.rs/scioxide-random/0.1.0/scioxide_random/enum.MultivariateProbabilityTermination.html) | 列挙型 | 同時確率の終了状態 | `Converged`（閉形式か、推定誤差が許容値以下）、`AccuracyNotMet`（指定の点をすべて評価したが推定誤差が許容値を超えたか、寄与がすべて 0 だった） | [多変量同時確率の数値計算](oxref:random-multivariate-probability) | [二変量正規分布の象限確率で推定誤差と実際の誤差を比べる](oxref:random-mvn-orthant-probability) |

## 行列と群の分布

| 項目 | 種別 | 役割 | 仕様の要点 | 解説節 | 実行例 |

| [`Wishart`](https://docs.rs/scioxide-random/0.1.0/scioxide_random/struct.Wishart.html) | 構造体 | 実 Wishart 分布 | `new(自由度, &scale)`、`with_options(自由度, &scale, options)`、正定値の尺度と次元 $-1$ より大きい自由度。構築時に $p^3$ の作業を `LawOptions` の作業量と、$24p^2$ 個の binary64 をバイト数の上限と照合する。標本は Bartlett 分解（$O(p^3)$）で、0 に丸められた正の対角は `NumericalInstability`（`Underflow`）。1 次元の標本は尺度と対数のガンマ変量を合わせてから一度だけ丸める | [行列と群の分布](oxref:random-multivariate-matrix-group)、[Bartlett 分解による生成](oxref:random-wishart-bartlett) | [W/n の固有値の分布を Marchenko–Pastur 則と比べる](oxref:random-wishart-marchenko-pastur)、[Wishart 行列と正規ベクトルの散布行列の平均と分散を比べる](oxref:random-wishart-moments) |
| [`InverseWishart`](https://docs.rs/scioxide-random/0.1.0/scioxide_random/struct.InverseWishart.html) | 構造体 | 逆 Wishart 分布 | `Wishart` と同じ引数と条件。標本は Bartlett 因子の逆で $O(p^3)$。平均は $\nu > p + 1$ で $\Psi/(\nu - p - 1)$ | [行列と群の分布](oxref:random-multivariate-matrix-group)、[Bartlett 分解による生成](oxref:random-wishart-bartlett) | - |
| [`MatrixNormal`](https://docs.rs/scioxide-random/0.1.0/scioxide_random/struct.MatrixNormal.html) | 構造体 | 行列正規分布 | `new(&平均, &行の共分散, &列の共分散)`、`with_options(&平均, &行の共分散, &列の共分散, options)`。三つの行列は `&Matrix` か `MatrixView` で、行の共分散は行数 × 行数、列の共分散は列数 × 列数で、どちらも正定値。標本は Cholesky 因子による $M + L_r Z L_c^{\mathsf T}$ で、Kronecker 積の共分散を作らない | [行列と群の分布](oxref:random-multivariate-matrix-group) | - |

| [`SpecialOrthogonalGroup`](https://docs.rs/scioxide-random/0.1.0/scioxide_random/struct.SpecialOrthogonalGroup.html) | 構造体 | 特殊直交群 $SO(d)$ の Haar 測度 | `new(d)`、`with_options(d, options)`、$d = 0$ は `InvalidInput`。`OrthogonalGroup` の標本の行列式が $-1$ なら最後の行の符号を反転する。標本は $O(d^3)$ | [行列と群の分布](oxref:random-multivariate-matrix-group) | [SO(3) の Haar 測度の回転角とトレースのモーメントを確かめる](oxref:random-haar-rotation-angle) |
| [`UnitaryGroup`](https://docs.rs/scioxide-random/0.1.0/scioxide_random/struct.UnitaryGroup.html) | 構造体 | ユニタリ群 $U(d)$ の Haar 測度 | `new(d)`、`with_options(d, options)`、$d = 0$ は `InvalidInput`。複素 Gauss 行列の三角因子の位相をそろえる Mezzadri の方法。成分は `Complex` で行優先。標本は $O(d^3)$ | [行列と群の分布](oxref:random-multivariate-matrix-group) | - |
