この表は低食い違い点列と、点列や乱数から作る設計と経路をまとめる。
Plan（`QmcPlan`、`QmcReplicatePlan`、`BrownianBridgePlan`）と設計 `PoissonDisk` は不変で `Send + Sync + Clone` であり、カーソルと作業領域は呼び出し側が持つ。
ラテンハイパーキューブは Plan を持たず、関数 `latin_hypercube`、`latin_hypercube_with_options`、`latin_hypercube_into` で作る。
点列の理論は[Halton・Sobol 点列の構成とディスクレパンシー](../../algorithms/quasi-random-and-brownian-bridges/)、[QMC 点列の位置・ランダム化・誤差の推定](../../algorithms/qmc-positions-and-randomization/)、[Brownian 橋による経路の構成](../../algorithms/brownian-bridge-construction/)で、設計は[ラテンハイパーキューブ設計とディスクレパンシー](../../algorithms/latin-hypercube-and-discrepancy/)と[Poisson 円板標本](../../algorithms/poisson-disk-sampling/)で説明した。
