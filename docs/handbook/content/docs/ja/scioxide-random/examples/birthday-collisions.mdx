$D = 365$ 日のどれかに等確率で生まれた $n$ 人がいるとき、誕生日が同じ組が一つ以上ある確率は $n = 23$ で 1/2 を超える。
同じ計算は並列計算のワーカーに乱数のシードを無作為に配ったとき、二つのワーカーが同じシードを引く確率にも当てはまる。
このページは正確な確率、指数近似、`uniform_index` によるシミュレーションの三つを比べ、近似の誤差とシミュレーションの信頼区間を数値で示す。
同じ式で 64 ビットのシードの衝突を見積もり、系列の選び方が何を保証するかは[乱数のシードの衝突と系列の分割](../seed-collisions-and-streams/)で扱う。

## 正確な確率と指数近似

$D$ 個の値から等確率・復元抽出で $k$ 個を引く。
どの 2 個も一致しない確率は、$i$ 番目（$i = 0, 1, \dots$）の値が先の $i$ 個と異なる確率 $1 - i/D$ の積なので

$$
P(k, D) = 1 - \prod_{i=0}^{k-1}\left(1 - \frac{i}{D}\right)
$$

が衝突する確率の正確な値である。
$k > D$ では鳩の巣原理で $P = 1$ になる。
セルは積を $\sum_i \ln(1 - i/D)$ として足し、$1 - e^{x}$ を `RealScalar::exp_m1` で求めるので、$P$ が小さいときも桁を失わない。

$\ln(1 - x) = -x - x^2/2 - \cdots$ の 1 次の項だけを残すと

$$
P_{\mathrm{approx}}(k, D) = 1 - \exp\!\left(-\frac{k(k-1)}{2D}\right)
$$

を得る。
このページはこの形を使う。
$k(k-1)$ を $k^2$ に置き換えた $1 - \exp(-k^2/(2D))$ もよく使われるが、$D = 365$、$k = 23$ では $0.5155$ を与え、正確な $0.5073$ より $0.0082$ 大きい。
省いた 2 次の項 $\sum_i i^2/(2D^2) \approx k^3/(6D^2)$ のため、$P_{\mathrm{approx}}$ は正確な値を約 $(1 - P)\,k^3/(6D^2)$ だけ小さく見積もる。
$D = 365$、$k = 23$ ではこの見積もりが $0.0075$ で、実際の差 $-0.0073$ とほぼ一致する。
$P = 1/2$ になる人数は $k(k-1)/(2D) = \ln 2$ から $k_{1/2} \approx 1/2 + \sqrt{2D\ln 2}$ で、$D$ が大きければ約 $1.1774\sqrt D$ である。

## シミュレーションと Wilson 区間

$R$ 回の試行で衝突が $C$ 回起きたとき、$\hat P = C/R$ の標準誤差は $\sqrt{P(1-P)/R}$ である。
$\hat P$ が 0 や 1 に近いと $\hat P \pm 1.96\sqrt{\hat P(1-\hat P)/R}$ の区間は $[0, 1]$ をはみ出し、真の値を含む割合が名目の 95% を下回る。
そこで Wilson の 95% 区間

$$
\frac{\hat P + \frac{z^2}{2R} \pm z\sqrt{\frac{\hat P(1-\hat P)}{R} + \frac{z^2}{4R^2}}}{1 + \frac{z^2}{R}}, \qquad z = 1.96
$$

を使う。
検定の反転による正確な Clopper–Pearson の限界は scioxide-stats の `binomial_confidence_limits` が求める（[分布フィッティング・反転信頼限界](../../../scioxide-stats/algorithms/distribution-fitting-and-confidence-limits/)）。

各試行は `uniform_index(D, &mut rng)` で $k$ 個の日を引く。
`uniform_index` は全幅の一様なワードから [Lemire の棄却法](oxref:random-sampling-lemire)で $0, \dots, D-1$ の偏りのない添字を作り、作業領域を確保しない。
同じ日が出たかは、試行ごとに試行番号を記録する配列で調べ、最初の衝突で試行を打ち切る。
人数 $k$ ごとに `Pcg64::split(k)` で別の系列を選ぶので、比べる人数の格子を変えても、ある $k$ の結果は変わらない。

次のセルの入力は人数 $n$（2–100）、日数 $D$（50–1000）、各 $k$ の試行数 $R$、乱数のシードである。
グラフは $k = 1, \dots, \max(\lceil 3\sqrt D\rceil, n)$ の正確な値を破線、近似を点線で描き、約 15 個の $k$ でシミュレーションの $\hat P$ を記号、Wilson 区間を帯で示す。
縦線は入力の $n$ である。
表の先頭行が入力の $n$ で、続く行がグラフの記号の $k$ である。

```rust
//| id: random-birthday-probability
//| ref: random-birthday-probability
//| title: 衝突の確率を正確な式・近似・シミュレーションで比べる
//| run: reactive
//| crates: [scioxide-core, scioxide-random]
//| inputs:
//|   people: {"type":"range","label":"人数 n [人]","description":"表の先頭行と縦線で示す人数。","min":2,"max":100,"step":1,"value":23}
//|   days: {"type":"range","label":"日数 D [日]","description":"誕生日の候補の数。小さくすると同じ人数で衝突しやすくなる。","min":50,"max":1000,"step":5,"value":365}
//|   trials: {"type":"range","label":"各 k の試行数 R [回]","description":"Wilson 区間の幅を変える。","min":500,"max":4000,"step":500,"value":2000}
//|   birthday_seed: {"type":"range","label":"乱数のシード [-]","description":"Pcg64 のシード。人数 k ごとに split(k) の系列を使う。","min":1,"max":1000,"step":1,"value":123}
//| cases:
//|   - {"id":"hundred-days","label":"D = 100 日、n = 13 人","description":"正確な P は 0.5572 で、近似は 0.0156 小さい。差は (1 − P)n³/(6D²) = 0.0162 とほぼ一致する。","inputs":{"days":100,"people":13}}
//|   - {"id":"more-trials","label":"R = 4000 回","description":"Wilson 区間の幅が R = 2000 の約 1/√2 になる。","inputs":{"trials":4000}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"comparison","path":"/rows/0/0","equals":23}
//|       - {"artifact":"comparison","path":"/rows/0/1","approx":{"value":0.5072972,"atol":1e-6}}
//|       - {"artifact":"comparison","path":"/rows/0/3","approx":{"value":-0.0072955,"atol":1e-6}}
//|       - {"artifact":"comparison","path":"/rows/0/4","range":{"min":0.47,"max":0.55}}
//|   - case: hundred-days
//|     expect:
//|       - {"artifact":"comparison","path":"/rows/0/1","approx":{"value":0.5572250,"atol":1e-6}}
//|       - {"artifact":"comparison","path":"/rows/0/4","range":{"min":0.52,"max":0.6}}
//|   - case: more-trials
//|     expect:
//|       - {"artifact":"comparison","path":"/rows/0/4","range":{"min":0.48,"max":0.54}}
//|       - {"artifact":"comparison","path":"/rows/0/6","range":{"min":0.51,"max":0.56}}
use scioxide_core::RealScalar;
use scioxide_random::{Pcg64, SeedableRng, SplittableRng, uniform_index};

let (n, d, r) = (
    people.round() as usize,
    days.round() as usize,
    trials.round() as usize,
);
// 独立検算: 正確な P = 1 − ∏(1 − i/D)。k > D では i = D の因子 0 で P = 1 になる。
let exact = |k: usize| {
    let log_q: f64 = (0..k.min(d + 1))
        .map(|i| RealScalar::ln_1p(-(i as f64) / d as f64))
        .sum();
    -RealScalar::exp_m1(log_q)
};
let approx = |k: usize| -RealScalar::exp_m1(-((k * (k - 1)) as f64) / (2.0 * d as f64));
let root = Pcg64::from_seed(birthday_seed.round() as u64);
let mut stamp = vec![0_u32; d];
let mut epoch = 0_u32;
let mut simulate = |k: usize| -> Result<usize, String> {
    let mut rng = root.split(k as u64).map_err(|e| e.to_string())?;
    let mut collisions = 0;
    for _ in 0..r {
        epoch += 1; // フラグを設定し直す代わりに試行の番号を変える
        for _ in 0..k {
            let day = uniform_index(d, &mut rng).map_err(|e| e.to_string())?;
            if stamp[day] == epoch {
                collisions += 1;
                break;
            }
            stamp[day] = epoch;
        }
    }
    Ok(collisions)
};
let k_max = (3.0 * RealScalar::sqrt(d as f64)).ceil() as usize;
let step = k_max.div_ceil(15);
let grid: Vec<usize> = (1..)
    .map(|j| j * step)
    .take_while(|&k| k <= k_max)
    .collect();
let z = 1.96_f64;
let (mut rows, mut band, mut marks) = (Vec::new(), Vec::new(), Vec::new());
for &k in std::iter::once(&n).chain(grid.iter().filter(|&&k| k >= 2)) {
    let p_hat = simulate(k)? as f64 / r as f64;
    // Wilson の 95% 区間。
    let centre = (p_hat + z * z / (2.0 * r as f64)) / (1.0 + z * z / r as f64);
    let spread =
        RealScalar::sqrt(p_hat * (1.0 - p_hat) / r as f64 + z * z / (4.0 * (r * r) as f64));
    let half = z * spread / (1.0 + z * z / r as f64);
    let (p, se) = (
        exact(k),
        RealScalar::sqrt(exact(k) * (1.0 - exact(k)) / r as f64),
    );
    rows.push((
        k,
        p,
        approx(k),
        approx(k) - p,
        p_hat,
        centre - half,
        centre + half,
        (p_hat - p) / se,
    ));
    if rows.len() > 1 {
        band.push([k as f64, p_hat, centre - half, centre + half]);
        marks.push([k as f64, p_hat]);
    }
}
let x_max = k_max.max(n);
let exact_line: Vec<[f64; 2]> = (1..=x_max).map(|k| [k as f64, exact(k)]).collect();
let approx_line: Vec<[f64; 2]> = (1..=x_max).map(|k| [k as f64, approx(k)]).collect();
emit_chart!(serde_json::json!({
    "kind": "xy",
    "dataZoom": true,
    "tooltip": true,
    "xLabel": "人数 k [人]",
    "yLabel": "誕生日が重なる確率 [-]",
    "xMin": 0.0,
    "xMax": x_max as f64,
    "yMin": 0.0,
    "yMax": 1.0,
    "layers": [
        { "id": "wilson", "kind": "band", "name": "Wilson 95% 区間", "points": band },
        { "id": "simulated", "kind": "scatter", "name": "シミュレーションの P̂", "points": marks },
        {
            "id": "exact",
            "kind": "line",
            "name": "正確な P",
            "points": exact_line,
            "style": { "lineType": "dashed" }
        },
        {
            "id": "approx",
            "kind": "line",
            "name": "近似 1 − exp(−k(k−1)/(2D))",
            "points": approx_line,
            "style": { "lineType": "dotted" }
        }
    ],
    "annotations": [{ "kind": "line", "axis": "x", "value": n as f64, "label": "入力の n" }]
}));
let fixed4 = serde_json::json!({ "fractionDigits": 4 });
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let fixed2 = serde_json::json!({ "fractionDigits": 2 });
let columns = serde_json::json!([
    { "key": "0", "label": "人数 k [人]", "type": "integer" },
    { "key": "1", "label": "正確な P [-]", "type": "number", "format": fixed4 },
    { "key": "2", "label": "近似 P [-]", "type": "number", "format": fixed4 },
    { "key": "3", "label": "近似 − 正確 [-]", "type": "number", "format": sci3 },
    { "key": "4", "label": "P̂ [-]", "type": "number", "format": fixed4 },
    { "key": "5", "label": "Wilson 下限 [-]", "type": "number", "format": fixed4 },
    { "key": "6", "label": "Wilson 上限 [-]", "type": "number", "format": fixed4 },
    { "key": "7", "label": "z = (P̂ − P)/SE [-]", "type": "number", "format": fixed2 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "comparison" })
);
```

既定の $n = 23$、$D = 365$ では正確な確率は $0.50730$、近似は $0.50000$ で、差は $-0.0073$ である。
近似の差は $k$ とともに広がって $k = 33$ で最も大きい $-0.0103$ になり、$P$ が 1 に近づくと縮む。
シード 123、$R = 2000$ の $k = 23$ のシミュレーションは $\hat P = 0.5150$、Wilson 区間は $[0.4931, 0.5369]$ で、正確な値との差は $0.69\,\mathrm{SE}$ だった。
グラフの 14 個の $k$ のうち、$k = 16$（$2.37\,\mathrm{SE}$）と $k = 36$（$2.49\,\mathrm{SE}$）の 2 点が 95% 区間の外に出た。
1 点が外に出る確率は約 5% なので、14 点で外れる点の数の期待値は 0.7 で、2 点以上が外れる確率は約 15% ある。
$D = 100$ にすると 13 人で $P = 0.5572$ になり、近似との差は $-0.0156$ に広がる。

## まとめ

$n$ 人の誕生日が重なる正確な確率は $1 - \prod_{i<n}(1 - i/D)$ で、$D = 365$ では $n = 23$ で 1/2 を超える。
対数の和と `exp_m1` で積を評価すれば、$P$ が小さいときも桁を失わずに求められる。
近似 $1 - \exp(-n(n-1)/(2D))$ は正確な値を約 $(1-P)n^3/(6D^2)$ だけ小さく見積もり、$D = 365$ ではその差が最大で約 0.01 になる。
シミュレーションの割合は Wilson 区間を付けて正確な値と比べ、区間の外に出た点の数を、1 点あたり 5% の確率から見込める数と照らして読む。
