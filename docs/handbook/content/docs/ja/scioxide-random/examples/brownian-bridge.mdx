微粒子の Brown 運動の変位や、株価の対数が描く変動は、Wiener 過程 $W(t)$ で表される。
その経路は確率微分方程式の数値解やオプションの価格評価の入力になる。
この例題は `BrownianBridgePlan` で標準正規座標から経路を作り、その経路が Wiener 過程の性質を持つことを確かめる。
このページは一本の経路の二次変分を確かめ、多くの経路から求める分散と共分散は[Brownian 経路の集合の分散と共分散](../brownian-ensemble/)で確かめる。
座標を割り当てる順序と、その順序が準モンテカルロ法（QMC）で有利になる理由は、[Brownian 橋による座標の割り当て](oxref:random-qmc-brownian-bridge)で説明した。

## Wiener 過程の性質

$W(0) = 0$ で、重ならない区間の増分 $W(t) - W(s)$（$s < t$）が互いに独立に $\mathcal{N}(0, t - s)$ に従う過程を、標準 Wiener 過程と呼ぶ。
$s \le t$ なら $W(t) = W(s) + (W(t) - W(s))$ と分けられ、後ろの増分は $W(s)$ と独立なので

$$
\mathrm{Cov}(W(s), W(t)) = \mathrm{Var}\,W(s) = \min(s, t)
$$

になる。

時間は秒で測り、変位は $\mathrm{Var}\,W(t) = t$ となる尺度（単位 $\sqrt{\mathrm{s}}$）で表す。
一次元で拡散係数 $D$ の粒子の変位は $X(t) = \sqrt{2D}\,W(t)$ と書けるので、$\mathrm{Var}\,X(t) = 2Dt$ となり、この係数を掛ければ物理の単位に戻る。

等間隔の格子 $t_i = iT/n$ の増分 $\Delta W_i = W(t_{i+1}) - W(t_i)$ は、互いに独立に $\mathcal{N}(0, T/n)$ に従う。
$(\Delta W_i)^2 / (T/n)$ は自由度 1 のカイ二乗分布に従い、平均は 1、分散は 2 である。
そのため、二次変分

$$
Q_n = \sum_{i=0}^{n-1} (\Delta W_i)^2, \qquad \mathrm{E}[Q_n] = T, \qquad \mathrm{sd}(Q_n) = \frac{T}{n}\sqrt{2n} = T\sqrt{2/n}
$$

は $n \to \infty$ で $T$ に収束する。
これは Itô 解析の規則 $(dW)^2 = dt$ の離散版である。
途中の時刻 $t_k$ までの部分和 $Q(t_k) = \sum_{i<k} (\Delta W_i)^2$ も、平均 $t_k$、標準偏差 $(T/n)\sqrt{2k}$ で $t_k$ のまわりに揺らぐ。

## Brownian 橋による座標の割り当て

`BrownianBridgePlan::new(times)` は、狭義単調増加する時刻の格子 $t_0 < t_1 < \dots < t_n$ を受け取る。
$n$ 個の標準正規座標 $z_0, \dots, z_{n-1}$ のうち、$z_0$ で終端 $W(t_n) = \sqrt{t_n - t_0}\,z_0$ を決める。
残りの座標は、値が決まった二点 $W(t_a)$、$W(t_b)$ の間の中点の添字 $c = \lfloor (a + b)/2 \rfloor$ に、幅優先・左から右の順で割り当てる。
二点が決まったときの $W(t_c)$ の条件付き分布は

$$
W(t_c) \mid W(t_a), W(t_b) \sim \mathcal{N}\!\left( \frac{(t_b - t_c) W(t_a) + (t_c - t_a) W(t_b)}{t_b - t_a},\; \frac{(t_c - t_a)(t_b - t_c)}{t_b - t_a} \right)
$$

である。
平均は二点の線形補間で、分散は区間の両端で 0、中央で最大になる。
Plan は各段の補間の重みと条件付き標準偏差を構築時に $O(n)$ の時間とメモリ領域で計算して保持し、経路 1 本を $O(n)$ で作る。
8 区間の格子なら、座標は添字 $8, 4, 2, 6, 1, 3, 5, 7$ の時刻に順に使われる。
格子は不等間隔でもよく、$n$ が 2 の冪である必要もない。

各段は条件付き分布から正確に標本を取るので、作られる経路の同時分布は、増分を前から順に足した経路と同じになる。
そのため、上の Wiener 過程の性質はそのまま成り立つ（`apply` の仕様では $\mathrm{Cov}(W(t_i), W(t_j)) = \min(t_i, t_j) - t_0$）。
違うのは、経路の大まかな形を先頭の座標が決めることである。
QMC 点列は先頭の座標ほど均一なので、その座標を経路の分散の大きい部分に当てられる。

格子が不正なとき、`new` は失敗する。
時刻が 2 個未満なら `InvalidInput`、NaN や無限大を含めば `NonFinite`、狭義単調増加でなければ `DomainError` になる。
`apply` と `apply_into` は、座標の長さが $n$ でなければ `DimensionMismatch`、座標に NaN や無限大があれば `NonFinite` を返す。
`apply_into` は出力の長さが $n$ でないときも `DimensionMismatch` を返す。

## 一本の経路と二次変分

次のセルは乱数のシードから $n$ 個の標準正規座標を `Normal::sample_n` で作り、`BrownianBridgePlan::apply` で $W(t_1), \dots, W(t_n)$ を求める。
入力は乱数のシード、時間刻みの数 $n$、終端時刻 $T$ [s] である。
`apply` は経路を新しい `Vec` で返し、$W(t_0) = 0$ は出力に含まない。
増分と二次変分は、セルの中で経路の差から計算する。
この計算は Plan を通らないので、閉形式の $\mathrm{E}[Q_n] = T$ と $\mathrm{sd}(Q_n) = T\sqrt{2/n}$ との比較は独立な検算になる。

上のグラフは経路と、各時刻の $\pm 2\sqrt{t}$ の帯（$W(t)$ が約 95% の確率で入る範囲）を重ねる。
下のグラフは二次変分の部分和 $Q(t)$（記号）を、理論値 $t$（破線）と $\pm 2$ 標準偏差の帯に重ねる。
二つのグラフの横軸の時刻は連動する。

```rust
//| id: random-brownian-bridge
//| ref: random-brownian-bridge
//| title: Brownian 橋で一本の経路を作り二次変分を測る
//| run: reactive
//| crates: [scioxide-core, scioxide-random]
//| inputs:
//|   path_seed: {"type":"range","label":"乱数のシード","min":1,"max":1000,"step":1,"value":17}
//|   time_steps: {"type":"range","label":"時間刻みの数 n [区間]","description":"二次変分の標準偏差 T√(2/n) を変える。","min":16,"max":1024,"step":16,"value":256}
//|   time_horizon: {"type":"range","label":"終端時刻 T [s]","min":0.25,"max":4,"step":0.25,"value":1}
//| cases:
//|   - {"id":"fine-grid","label":"n = 1024","description":"刻みを 4 倍にすると Q_n の標準偏差が半分の 0.0442 s になる。","inputs":{"time_steps":1024}}
//|   - {"id":"other-seed","label":"シード 1","description":"別の経路でも Q_n は T の近くに出る。","inputs":{"path_seed":1}}
//|   - {"id":"long-horizon","label":"T = 4 s","description":"同じシードで経路は √4 = 2 倍、Q_n は 4 倍になり、標準化した値は変わらない。","inputs":{"time_horizon":4}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"summary","path":"/rows/0/2","approx":{"value":0.8744,"atol":1e-3}}
//|       - {"artifact":"summary","path":"/rows/0/3","approx":{"value":0.088388,"atol":1e-5}}
//|       - {"artifact":"summary","path":"/rows/0/4","range":{"min":-4,"max":4}}
//|   - case: fine-grid
//|     expect:
//|       - {"artifact":"summary","path":"/rows/0/3","approx":{"value":0.044194,"atol":1e-5}}
//|       - {"artifact":"summary","path":"/rows/0/4","range":{"min":-4,"max":4}}
//|   - case: other-seed
//|     expect:
//|       - {"artifact":"summary","path":"/rows/0/4","range":{"min":-4,"max":4}}
//|   - case: long-horizon
//|     expect:
//|       - {"artifact":"summary","path":"/rows/0/2","approx":{"value":3.4976,"atol":4e-3}}
//|       - {"artifact":"summary","path":"/rows/0/4","approx":{"value":-1.4214,"atol":1e-3}}
use scioxide_core::RealScalar;
use scioxide_random::{BrownianBridgePlan, Distribution, Normal, SeedableRng, SplitMix64};

let n = time_steps.round() as usize;
let times: Vec<f64> = (0..=n)
    .map(|i| time_horizon * i as f64 / n as f64)
    .collect();
// 格子を検査し、各段の重みと条件付き標準偏差を保持する Plan。
let plan = BrownianBridgePlan::new(&times).map_err(|e| e.to_string())?;
// 標準正規座標 z。z[0] が終端 W(T)、続く座標が中点を決める。
let mut rng = SplitMix64::from_seed(path_seed.round() as u64);
let z = Normal::<f64>::standard()
    .sample_n(&mut rng, n)
    .map_err(|e| e.to_string())?;
let path = plan.apply(&z).map_err(|e| e.to_string())?;
// W(t_0) = 0 は出力に含まれないので先頭に足す。
let mut full = Vec::with_capacity(n + 1);
full.push(0.0);
full.extend_from_slice(&path);
// 二次変分の部分和 Q(t_k) を経路の差から求める（独立な検算）。
let mut running = Vec::with_capacity(n + 1);
let mut accumulated = 0.0_f64;
running.push(accumulated);
for w in full.windows(2) {
    accumulated += (w[1] - w[0]) * (w[1] - w[0]);
    running.push(accumulated);
}
let dt = time_horizon / n as f64;
let sd = time_horizon * RealScalar::sqrt(2.0 / n as f64);
let curve: Vec<[f64; 2]> = times.iter().zip(&full).map(|(&t, &w)| [t, w]).collect();
let envelope: Vec<[f64; 4]> = times
    .iter()
    .map(|&t| {
        let half_width = 2.0 * RealScalar::sqrt(t);
        [t, 0.0, -half_width, half_width]
    })
    .collect();
let partial_sums: Vec<[f64; 2]> = times.iter().zip(&running).map(|(&t, &q)| [t, q]).collect();
let theory: Vec<[f64; 2]> = times.iter().map(|&t| [t, t]).collect();
// Q(t_k) の標準偏差は dt √(2k)。
let qv_band: Vec<[f64; 4]> = times
    .iter()
    .enumerate()
    .map(|(k, &t)| {
        let spread = 2.0 * dt * RealScalar::sqrt(2.0 * k as f64);
        [t, t, t - spread, t + spread]
    })
    .collect();
emit_chart!(serde_json::json!({
    "kind": "xy",
    "link": { "group": "bridge-path-time" },
    "dataZoom": true,
    "tooltip": true,
    "xLabel": "時刻 t [s]",
    "yLabel": "変位 W(t) [√s]",
    "xMin": 0.0,
    "xMax": time_horizon,
    "layers": [
        { "id": "envelope", "kind": "band", "name": "各時刻の ±2√t", "points": envelope },
        { "id": "path", "kind": "line", "name": "W(t)", "points": curve }
    ]
}));
emit_chart!(serde_json::json!({
    "kind": "xy",
    "link": { "group": "bridge-path-time" },
    "dataZoom": true,
    "tooltip": true,
    "xLabel": "時刻 t [s]",
    "yLabel": "二次変分の部分和 Q(t) [s]",
    "xMin": 0.0,
    "xMax": time_horizon,
    "layers": [
        { "id": "band", "kind": "band", "name": "t ± 2 標準偏差", "points": qv_band },
        {
            "id": "theory",
            "kind": "line",
            "name": "理論値 E[Q(t)] = t",
            "style": { "lineType": "dashed" },
            "points": theory
        },
        { "id": "measured", "kind": "scatter", "name": "Q(t)", "points": partial_sums }
    ]
}));
let digits4 = serde_json::json!({ "significantDigits": 4 });
let fixed2 = serde_json::json!({ "fractionDigits": 2 });
let columns = serde_json::json!([
    { "key": "0", "label": "終端値 W(T) [√s]", "type": "number", "format": digits4 },
    { "key": "1", "label": "W(T)/√T [-]", "type": "number", "format": digits4 },
    { "key": "2", "label": "二次変分 Q_n [s]", "type": "number", "format": digits4 },
    { "key": "3", "label": "理論の標準偏差 T√(2/n) [s]", "type": "number", "format": digits4 },
    { "key": "4", "label": "z = (Q_n − T)/標準偏差 [-]", "type": "number", "format": fixed2 }
]);
emit_table_with_columns!(
    columns,
    vec![(
        full[n],
        full[n] / RealScalar::sqrt(time_horizon),
        accumulated,
        sd,
        (accumulated - time_horizon) / sd,
    )],
    metadata = serde_json::json!({ "id": "summary" })
);
```

経路は 0 から出発して上下に揺れ、ほとんどの時刻で $\pm 2\sqrt{t}$ の帯の中にある。
帯は時刻ごとの範囲なので、経路のどこか一点が帯の外に出ることは珍しくない。
経路の振れ幅が帯に比べて全体に小さすぎたり大きすぎたりすれば、座標の尺度か条件付き標準偏差の計算を疑う。
二次変分の部分和は経路が上下どちらに動いても増え続け、破線 $t$ に沿って伸びる。
経路の形が大きく揺れても $Q(t)$ はほぼ直線になることが、$(dW)^2 = dt$ の意味である。

既定の入力（シード 17、$n = 256$、$T = 1$ s）では、終端値は $-0.0217$ $\sqrt{\mathrm{s}}$、二次変分は $Q_n = 0.8744$ s だった。
理論値 $T = 1$ s との差は理論の標準偏差 $0.0884$ s の $-1.42$ 倍である。
同じシードで $n = 1024$ にすると $Q_n = 0.9492$ s（標準偏差 $0.0442$ s、$-1.15$ 倍）、シードを 1 にすると $n = 256$ で $Q_n = 1.0315$ s（$0.36$ 倍）になる。
刻みの数 $n$ を増やすと標準偏差 $T\sqrt{2/n}$ が小さくなり、$Q_n$ は $T$ に近づく。
$T = 4$ s にすると、同じシードの経路は $\sqrt{4} = 2$ 倍、二次変分は 4 倍の $3.4976$ s になり、標準化した値 $-1.42$ は変わらない。
格子と座標が同じなら、Plan の重みは $T$ によらず、条件付き標準偏差だけが $\sqrt{T}$ 倍になるからである。

## まとめ

`BrownianBridgePlan` は時刻の格子を一度検査して条件付き分布の係数を保持するので、同じ Plan で何本でも経路を作れる。
出力は $W(t_1), \dots, W(t_n)$ で $W(t_0) = 0$ を含まないので、増分を作るときは先頭に 0 を足す。
一本の経路の二次変分は $T$ のまわりに標準偏差 $T\sqrt{2/n}$ で揺らぐので、刻みを細かくすれば橋の係数と尺度を一本の経路で確かめられる。
$z = (Q_n - T)/(T\sqrt{2/n})$ がシードを変えても $\pm 2$ 程度に収まらなければ、座標の尺度か格子の作り方を疑う。
座標を割り当てる順序は経路の分布を変えないので、擬似乱数でも QMC 点列でも同じ Plan を使える。
