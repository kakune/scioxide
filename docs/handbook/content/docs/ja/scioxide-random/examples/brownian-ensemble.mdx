Wiener 過程 $W(t)$ は平均 0 の正規過程なので、その分布は共分散 $\mathrm{Cov}(W(s), W(t)) = \min(s, t)$（$s = t$ なら分散 $t$）で決まる。
一本の経路からは各時刻に一つの値しか得られないので、これらは多くの経路から推定する。
この例題は `BrownianBridgePlan` で経路を $R$ 本作り、標本分散と標本共分散を理論値と標準誤差で比べる。
経路の作り方と $\min(s, t)$ の導出は[Brownian 橋過程による確率経路の階層的生成](../brownian-bridge/)で、座標の割り当ては[Brownian 橋による座標の割り当て](oxref:random-bridge-coordinate-assignment)で説明した。

## 標本分散と標本共分散の標準誤差

$R$ 本の経路の時刻 $t$ の値を $W_r(t)$（$r = 1, \dots, R$）、標本平均を $\overline{W}(t)$ と書く。
標本分散と標本共分散は

$$
\hat{v}(t) = \frac{1}{R-1}\sum_{r=1}^{R} \bigl(W_r(t) - \overline{W}(t)\bigr)^2, \qquad
\hat{c}(s, t) = \frac{1}{R-1}\sum_{r=1}^{R} \bigl(W_r(s) - \overline{W}(s)\bigr)\bigl(W_r(t) - \overline{W}(t)\bigr)
$$

で、どちらも不偏推定量である。
標準誤差（SE）は、$W(t)$ が正規分布に従うことから求める。
正規標本の不偏分散は $t \cdot \chi^2_{R-1}/(R-1)$ に従い、カイ二乗分布の分散は自由度の 2 倍なので、$\hat{v}(t)$ の SE は $t\sqrt{2/(R-1)}$ である。
平均 0 の正規変数 $X$、$Y$ では Isserlis の公式から $\mathrm{E}[X^2Y^2] = \mathrm{Var}X\,\mathrm{Var}Y + 2\,\mathrm{Cov}(X, Y)^2$ となるので、積の分散は $\mathrm{Var}(XY) = \mathrm{Var}X\,\mathrm{Var}Y + \mathrm{Cov}(X, Y)^2$ である。
$X = W(s)$、$Y = W(t)$ を入れ、平均の推定による小さな補正を無視すると、$\hat{c}(s, t)$ の SE は約 $\sqrt{(st + \min(s, t)^2)/R}$ になる。
$t = s$ ではこれが $s\sqrt{2/R}$ となり、分散の SE とほぼ一致する。

## 経路の集合の計算

次のセルは終端時刻 $T = 2$ s を 64 区間に分け、一つの Plan と作業領域を `apply_into` で使い回して経路を $R$ 本作る。
`apply_into` は経路を作業領域で作ってから出力へ写すので、失敗したときは出力を書き換えない。
各時刻 $t$ の標本分散 $\hat{v}(t)$ と、時刻 $s$ を固定した標本共分散 $\hat{c}(s, t)$ を、和と二乗和から求める。
入力は経路の数 $R$、固定する時刻 $s$ [s]、乱数のシードである。

上のグラフは理論の分散 $t$（破線）とそのまわりの $\pm 2$ SE の帯に、標本分散（記号）を重ねる。
下のグラフは同じ形で、共分散の理論値 $\min(s, t)$ と標本共分散を重ね、$t = s$ に縦線を引く。
二つのグラフの横軸の時刻は連動する。
表は終端の分散 $\mathrm{Var}\,W(T)$ と共分散 $\mathrm{Cov}(W(s), W(T))$ を、理論値 $T$、$s$ と SE で比べる。

```rust
//|   anchor_time: {"type":"range","label":"固定する時刻 s [s]","description":"共分散 min(s, t) が折れ曲がる位置を動かす。","min":0.25,"max":1.75,"step":0.25,"value":0.5}
//|   ensemble_seed: {"type":"range","label":"乱数のシード","min":1,"max":1000,"step":1,"value":271}
//| cases:
//|   - {"id":"few-paths","label":"R = 64","description":"分散の標準誤差が理論値の約 18% に広がる。","inputs":{"path_count":64}}
//|   - {"id":"other-seed","label":"シード 1","description":"同じ R で終端の分散が理論値より少し大きく出るシード。","inputs":{"ensemble_seed":1}}

//| tests:
//|   - case: default
//|     expect:

//|       - {"artifact":"comparison","path":"/rows/0/3","approx":{"value":0.12512,"atol":1e-4}}
//|       - {"artifact":"comparison","path":"/rows/0/4","range":{"min":-4,"max":4}}
//|       - {"artifact":"comparison","path":"/rows/1/1","approx":{"value":0.3968,"atol":1e-3}}
//|       - {"artifact":"comparison","path":"/rows/1/3","approx":{"value":0.049411,"atol":1e-5}}
//|       - {"artifact":"comparison","path":"/rows/1/4","range":{"min":-4,"max":4}}
//|   - case: few-paths
//|     expect:
//|       - {"artifact":"comparison","path":"/rows/0/3","approx":{"value":0.35635,"atol":1e-4}}
//|       - {"artifact":"comparison","path":"/rows/0/4","range":{"min":-4,"max":4}}
//|   - case: other-seed
//|     expect:
//|       - {"artifact":"comparison","path":"/rows/0/4","range":{"min":-4,"max":4}}
//|       - {"artifact":"comparison","path":"/rows/1/4","range":{"min":-4,"max":4}}
//|   - case: late-anchor
//|     expect:
//|       - {"artifact":"comparison","path":"/rows/1/2","approx":{"value":1.5,"atol":1e-12}}
//|       - {"artifact":"comparison","path":"/rows/1/3","approx":{"value":0.10126,"atol":1e-4}}
//|       - {"artifact":"comparison","path":"/rows/1/4","range":{"min":-4,"max":4}}
use scioxide_core::RealScalar;
use scioxide_random::{BrownianBridgePlan, Distribution, Normal, SeedableRng, SplitMix64};

// 終端時刻 T = 2 s を 64 区間に分ける。
let (r, steps, horizon) = (path_count.round() as usize, 64_usize, 2.0_f64);
let rf = r as f64;
let times: Vec<f64> = (0..=steps)
    .map(|i| horizon * i as f64 / steps as f64)
    .collect();
let plan = BrownianBridgePlan::new(&times).map_err(|e| e.to_string())?;
// Plan と作業領域を全経路で使い回す。
let mut workspace = plan.workspace(()).map_err(|e| e.to_string())?;

let mut rng = SplitMix64::from_seed(ensemble_seed.round() as u64);
let (mut z, mut path) = (vec![0.0_f64; steps], vec![0.0_f64; steps]);
// path[i] は W(t_{i+1}) なので、固定する時刻 s は path[anchor]。
let anchor = (anchor_time * steps as f64 / horizon).round() as usize - 1;
let mut sums = vec![0.0_f64; steps];
let mut squares = vec![0.0_f64; steps];
let mut cross = vec![0.0_f64; steps];
for _ in 0..r {
    for value in &mut z {
        *value = standard.sample(&mut rng).map_err(|e| e.to_string())?;
    }
    plan.apply_into(&z, &mut path, &mut workspace)
        .map_err(|e| e.to_string())?;
    for (i, &w) in path.iter().enumerate() {
        sums[i] += w;
        squares[i] += w * w;
        cross[i] += path[anchor] * w;
    }
}
let mean = |i: usize| sums[i] / rf;
let variance = |i: usize| (squares[i] - rf * mean(i) * mean(i)) / (rf - 1.0);
let covariance = |i: usize| (cross[i] - rf * mean(anchor) * mean(i)) / (rf - 1.0);
// 独立検算の基準: Var W(t) = t、Cov(W(s), W(t)) = min(s, t) と、それぞれの SE。
let s = times[anchor + 1];
let variance_se = |t: f64| t * RealScalar::sqrt(2.0 / (rf - 1.0));
let covariance_se = |t: f64| RealScalar::sqrt((s * t + s.min(t) * s.min(t)) / rf);
let grid = &times[1..];
let variance_band: Vec<[f64; 4]> = grid
    .iter()
    .map(|&t| [t, t, t - 2.0 * variance_se(t), t + 2.0 * variance_se(t)])
    .collect();

    .iter()
    .map(|&t| {
        let c = s.min(t);
        [t, c, c - 2.0 * covariance_se(t), c + 2.0 * covariance_se(t)]
    })
    .collect();

let covariance_points: Vec<[f64; 2]> = (0..steps).map(|i| [grid[i], covariance(i)]).collect();
let variance_theory: Vec<[f64; 2]> = grid.iter().map(|&t| [t, t]).collect();
let covariance_theory: Vec<[f64; 2]> = grid.iter().map(|&t| [t, s.min(t)]).collect();
emit_chart!(serde_json::json!({
    "kind": "xy",
    "link": { "group": "bridge-ensemble-time" },
    "dataZoom": true,
    "tooltip": true,
    "xLabel": "時刻 t [s]",
    "yLabel": "経路の集合の分散 [s]",
    "layers": [
        { "id": "band", "kind": "band", "name": "理論値 ± 2 SE", "points": variance_band },
        {
            "id": "theory",
            "kind": "line",
            "name": "理論値 Var W(t) = t",
            "style": { "lineType": "dashed" },
            "points": variance_theory
        },
        { "id": "measured", "kind": "scatter", "name": "標本分散", "points": variance_points }
    ]
}));
emit_chart!(serde_json::json!({
    "kind": "xy",
    "link": { "group": "bridge-ensemble-time" },
    "dataZoom": true,
    "tooltip": true,
    "xLabel": "時刻 t [s]",
    "yLabel": "共分散 Cov(W(s), W(t)) [s]",
    "layers": [
        { "id": "band", "kind": "band", "name": "理論値 ± 2 SE", "points": covariance_band },
        {
            "id": "theory",
            "kind": "line",
            "name": "理論値 min(s, t)",
            "style": { "lineType": "dashed" },
            "points": covariance_theory
        },
        { "id": "measured", "kind": "scatter", "name": "標本共分散", "points": covariance_points }
    ],
    "annotations": [{ "kind": "line", "axis": "x", "value": s, "label": "固定した時刻 s" }]
}));
let digits4 = serde_json::json!({ "significantDigits": 4 });
let fixed2 = serde_json::json!({ "fractionDigits": 2 });
let columns = serde_json::json!([
    { "key": "0", "label": "量" },
    { "key": "1", "label": "測定値 [s]", "type": "number", "format": digits4 },
    { "key": "2", "label": "理論値 [s]", "type": "number", "format": digits4 },
    { "key": "3", "label": "SE [s]", "type": "number", "format": digits4 },
    { "key": "4", "label": "z = 差 / SE [-]", "type": "number", "format": fixed2 }
]);
let last = steps - 1;
let rows = vec![
    ("Var W(T)", variance(last), horizon, variance_se(horizon)),
    (
        "Cov(W(s), W(T))",
        covariance(last),
        s,
        covariance_se(horizon),
    ),
];
let rows: Vec<(&str, f64, f64, f64, f64)> = rows
    .into_iter()
    .map(|(name, value, exact, se)| (name, value, exact, se, (value - exact) / se))
    .collect();
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "comparison" })

```

標本分散の記号は破線のまわりに散らばり、ほとんどが帯の中に入る。
隣り合う時刻の分散は同じ経路から求めるので強く相関し、記号は独立に散らばらずに滑らかな曲線を描く。
そのため、一度帯の外に出た曲線はしばらく外にとどまることがあり、外に出た記号の数を独立な試行のように数えない。
共分散の記号は $t \le s$ では $t$ に沿って上がり、$t > s$ では $s$ の高さで横ばいになる。
この折れ曲がりが $\min(s, t)$ で、$s$ より後の増分が $W(s)$ と独立であることを表す。
分散の記号が $t$ に比例せずに曲がったり、全体が一定の倍率でずれたりすれば、橋の係数か座標の尺度を疑う。

既定の入力（$R = 512$、$s = 0.5$ s、シード 271）では、終端の分散は $1.7229$ s で、理論値 $2$ s との差は SE $0.125$ s の $-2.21$ 倍だった。
共分散 $\mathrm{Cov}(W(0.5), W(2))$ は $0.3968$ s で、理論値 $0.5$ s との差は SE $0.0494$ s の $-2.09$ 倍である。
正規近似で $|z| \ge 2.21$ となる両側の確率は約 2.7%、$|z| \ge 2.09$ は約 3.7% で、どちらもシードを変えれば数十回に一度は現れる大きさの揺らぎである。
二つの値は同じ経路の集合から求めるので互いに独立ではなく、同じ向きにずれやすい。
同じ $R$ でシードを 1 にすると、終端の分散は $2.0577$ s（$0.46$ 倍）、共分散は $0.5153$ s（$0.31$ 倍）になる。
$R = 64$ では分散の SE が理論値の約 18% に広がり、シード 271 の終端の分散は $1.4953$ s（$-1.42$ 倍）になる。
$s = 1.5$ s にすると折れ曲がりが後ろへ移り、共分散の理論値は $1.5$ s、SE は $0.101$ s に増え、測定値は $1.3295$ s（$-1.68$ 倍）になる。

## 一本の経路と経路の集合

[一本の経路の二次変分](../brownian-bridge/)と集合の分散・共分散は、どちらも経路を作る計算とは独立な、Wiener 過程の性質から求めた理論値である。
二次変分は一本の経路の中の多くの増分を平均するので、一本でも刻みの数 $n$ を増やせば $T$ に近づく。
集合の分散と共分散は経路ごとに一つの値しか得られないので、精度は経路の数 $R$ で決まる。
どちらの照合も SE の単位で読み、正規近似で $|z| > 2$ となる確率は一つの値につき約 4.6% である。

## まとめ

一つの `BrownianBridgePlan` と作業領域を `apply_into` で使い回せば、経路ごとの割り当てなしに多くの経路を作れる。
各時刻の標本分散は理論値 $t$ のまわりに SE $t\sqrt{2/(R-1)}$ で、標本共分散は $\min(s, t)$ のまわりに SE $\sqrt{(st + \min(s, t)^2)/R}$ で揺らぐ。
共分散が $t = s$ で折れ曲がって横ばいになれば、$s$ より後の増分が $W(s)$ と独立であることを確かめられる。
同じ経路の集合から求めた値どうしは相関するので、帯の外に出た記号の数は独立な試行として数えず、SE の単位の $z$ で一つずつ読む。
精度を上げるには経路の数 $R$ を増やし、SE が $1/\sqrt{R}$ で縮むことを使う。
