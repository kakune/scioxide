モンテカルロ推定の誤差は標本数 $N$ に対して $N^{-1/2}$ で減ると説明される。
この例題は [Buffon の針で π を推定する](../buffon-needle/)の推定量 $\hat\pi = 2\ell/(d\hat p)$ を標本数ごとに独立に反復し、誤差の減り方を実際に測る。
測った二乗平均誤差を両対数軸で直線に当てはめ、傾きが $-1/2$ と標準誤差（SE）の範囲で一致するかを確かめる。
針の落とし方、交差の確率 $p = 2\ell/(\pi d)$、デルタ法の標準誤差は前のページで導いた。

## 独立な反復と誤差の理論値

一つの系列の途中経過を並べると、前の標本を後の推定が含むので、点どうしの誤差は独立にならない。
次のセルは各 $N = 2^8, \dots, 2^{16}$ について $R$ 回の独立な反復を行い、二乗平均誤差 $\mathrm{RMSE} = \sqrt{\tfrac1R\sum (\hat\pi - \pi)^2}$ と絶対誤差の平均を求める。
反復は `root.substream(N の指数, 反復の番号)` で選んだ系列を使う。
異なる $N$ の反復は加算定数の異なる別の系列を使う。
同じ $N$ の反復は同じ系列の中で $2^{64}$ 遷移ずつ離れた部分系列を使い、一回の反復が読むワード数は $2^{64}$ よりずっと少ないので、どの反復も重ならない。
理論値は $\mathrm{SE}(N) = \pi\sqrt{(1-p)/(pN)}$ と、正規近似での $\mathrm E|\hat\pi - \pi| = \mathrm{SE}\sqrt{2/\pi}$ である。
入力は比 $\ell/d$、反復数 $R$、乱数のシードである。
$R = 32$ では針を合計約 420 万本落とし、ブラウザで 1 秒ほどかかるので、セルはボタンで実行する。

傾きは $x_j = \ln N_j$、$y_j = \ln \mathrm{RMSE}_j$ の最小二乗で求める。
$R$ 個の誤差が正規分布に従うとき、$\mathrm{RMSE}^2$ は $\mathrm{SE}^2 \chi^2_R / R$ に従うので、$\ln \mathrm{RMSE}$ の分散は約 $1/(2R)$ である。
各 $N$ の点は独立なので、傾きの SE は $\sqrt{1/(2R)}\,/\sqrt{\sum_j (x_j - \bar x)^2}$ になる。
最小二乗の当てはめと残差の読み方は[回帰分析・分散分析・GLM](../../../scioxide-stats/algorithms/regression-anova-and-glm/)で扱う。

グラフは両対数軸で、反復から測った RMSE と絶対誤差の平均を記号（点線でつなぐ）で、理論値を破線で描く。
記号が破線に沿って傾き $-1/2$ で下がれば、誤差は SE の理論どおりに縮んでいる。
表は各 $N$ の値と、当てはめた傾きを示す。

```rust
//| id: random-buffon-convergence
//| ref: random-buffon-convergence
//| title: 独立な反復で誤差の傾き −1/2 を測る
//| run: button
//| crates: [scioxide-core, scioxide-random]
//| inputs:
//|   slope_ratio: {"type":"range","label":"針の長さと線の間隔の比 ℓ/d [-]","description":"誤差の水準を変えるが、傾きは変えない。","min":0.2,"max":1,"step":0.1,"value":0.8}
//|   replicates: {"type":"range","label":"各 N の反復数 R [回]","description":"RMSE と傾きの推定の揺らぎを変える。","min":8,"max":64,"step":8,"value":32}
//|   slope_seed: {"type":"range","label":"乱数のシード [-]","description":"Pcg64 のシード。反復は substream で選んだ系列を使う。","min":1,"max":1000,"step":1,"value":7}
//| cases:
//|   - {"id":"many-replicates","label":"R = 64","description":"傾きの標準誤差が 0.0233 から 0.0165 に下がる。","inputs":{"replicates":64}}
//|   - {"id":"short-needle","label":"ℓ/d = 0.3","description":"誤差の水準は約 2.1 倍に上がり、傾きは −0.479 になる。","inputs":{"slope_ratio":0.3}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"slope","path":"/rows/0/0","range":{"min":-0.58,"max":-0.42}}
//|       - {"artifact":"slope","path":"/rows/0/1","approx":{"value":0.02328,"atol":0.0001}}
//|       - {"artifact":"errors","path":"/rows/8/4","range":{"min":0.6,"max":1.4}}
//|   - case: many-replicates
//|     expect:
//|       - {"artifact":"slope","path":"/rows/0/0","range":{"min":-0.56,"max":-0.44}}
//|       - {"artifact":"slope","path":"/rows/0/1","approx":{"value":0.01646,"atol":0.0001}}
//|   - case: short-needle
//|     expect:
//|       - {"artifact":"slope","path":"/rows/0/0","range":{"min":-0.58,"max":-0.42}}
use scioxide_core::RealScalar;
use scioxide_random::{
    Distribution, OutputPolicy, Pcg64, SamplingPolicy, SamplingRequest, SeedableRng,
    SplittableRng, Uniform, UniformDirection,
};

let r = replicates.round() as usize;
let pi = std::f64::consts::PI; // 比較の基準（真の値）
let p = 2.0 * slope_ratio / pi; // 閉形式の交差確率（独立検算の基準）
let direction = UniformDirection::<f64>::new(2).map_err(|e| e.to_string())?;
let offset = Uniform::new(0.0_f64, 0.5).map_err(|e| e.to_string())?;
let policy = SamplingPolicy::rollback(OutputPolicy::Incremental);
let mut direction_workspace = direction
    .workspace(policy, 1 << 16)
    .map_err(|e| e.to_string())?;
let mut offset_workspace = policy
    .workspace(SamplingRequest::scalars(1 << 16))
    .map_err(|e| e.to_string())?;
let (mut uv, mut y) = (vec![0.0_f64; 2 << 16], vec![0.0_f64; 1 << 16]);
let root = Pcg64::from_seed(slope_seed.round() as u64);
let (mut rows, mut fit) = (Vec::new(), Vec::new());
let (mut rmse_points, mut mae_points) = (Vec::new(), Vec::new());
let (mut se_line, mut mae_line) = (Vec::new(), Vec::new());
for exponent in 8..=16_u64 {
    let n = 1_usize << exponent;
    let (mut sum_sq, mut sum_abs) = (0.0, 0.0);
    for replicate in 0..r {
        let mut rng = root
            .substream(exponent, replicate as u64)
            .map_err(|e| e.to_string())?;
        direction
            .sample_n_into(&mut rng, policy, &mut uv[..2 * n], &mut direction_workspace)
            .map_err(|e| e.to_string())?;
        offset
            .sample_n_into(&mut rng, policy, &mut y[..n], &mut offset_workspace)
            .map_err(|e| e.to_string())?;
        let hits = y[..n]
            .iter()
            .zip(uv.chunks_exact(2))
            .filter(|&(&y, u)| y <= 0.5 * slope_ratio * u[1].abs())
            .count();
        if hits == 0 {
            return Err(format!("N = {n} で交差が 0 本のため π̂ が定義されない"));
        }
        let error = 2.0 * slope_ratio * n as f64 / hits as f64 - pi;
        sum_sq += error * error;
        sum_abs += error.abs();
    }
    let (rmse, mae) = (RealScalar::sqrt(sum_sq / r as f64), sum_abs / r as f64);
    // 独立検算: 真の p から求めた SE(N) = π √((1 − p)/(pN))。
    let n_f = n as f64;
    let se = pi * RealScalar::sqrt((1.0 - p) / (p * n_f));
    rmse_points.push([n_f, rmse]);
    mae_points.push([n_f, mae]);
    se_line.push([n_f, se]);
    mae_line.push([n_f, se * RealScalar::sqrt(2.0 / pi)]);
    fit.push((RealScalar::ln(n_f), RealScalar::ln(rmse)));
    rows.push((n, rmse, mae, se, rmse / se));
}
// ln RMSE を ln N に最小二乗で当てはめる。
let m = fit.len() as f64;
let x_mean = fit.iter().map(|f| f.0).sum::<f64>() / m;
let y_mean = fit.iter().map(|f| f.1).sum::<f64>() / m;
let sxx: f64 = fit.iter().map(|f| (f.0 - x_mean) * (f.0 - x_mean)).sum();
let sxy: f64 = fit.iter().map(|f| (f.0 - x_mean) * (f.1 - y_mean)).sum();
let slope = sxy / sxx;
let slope_se = RealScalar::sqrt(1.0 / (2.0 * r as f64)) / RealScalar::sqrt(sxx);
// 観測は記号（点線でつなぐ）、理論値は破線。xy 図は対数の x 軸を持たないので line 図で描く。
let dashed = serde_json::json!({ "lineType": "dashed" });
let circle =
    serde_json::json!({ "lineType": "dotted", "showSymbol": true, "symbol": "circle" });
let diamond =
    serde_json::json!({ "lineType": "dotted", "showSymbol": true, "symbol": "diamond" });
emit_chart!(serde_json::json!({
    "kind": "line",
    "dataZoom": true,
    "tooltip": true,
    "xLabel": "標本数 N [本]",
    "yLabel": "π̂ の誤差 [-]",
    "xType": "log",
    "yType": "log",
    "series": [
        { "name": "RMSE（反復）", "style": circle, "points": rmse_points },
        { "name": "|π̂ − π| の平均（反復）", "style": diamond, "points": mae_points },
        { "name": "理論 SE(N)", "style": dashed, "points": se_line },
        { "name": "理論 SE(N)·√(2/π)", "style": dashed, "points": mae_line }
    ]
}));
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let fixed3 = serde_json::json!({ "fractionDigits": 3 });
let fixed4 = serde_json::json!({ "fractionDigits": 4 });
let columns = serde_json::json!([
    { "key": "0", "label": "N [本]", "type": "integer" },
    { "key": "1", "label": "RMSE [-]", "type": "number", "format": sci3 },
    { "key": "2", "label": "|π̂ − π| の平均 [-]", "type": "number", "format": sci3 },
    { "key": "3", "label": "理論 SE(N) [-]", "type": "number", "format": sci3 },
    { "key": "4", "label": "RMSE / SE [-]", "type": "number", "format": fixed3 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "errors" })
);
let slope_columns = serde_json::json!([
    { "key": "0", "label": "傾き [-]", "type": "number", "format": fixed4 },
    { "key": "1", "label": "傾きの SE [-]", "type": "number", "format": fixed4 },
    { "key": "2", "label": "(傾き + 1/2)/SE [-]", "type": "number", "format": fixed3 }
]);
emit_table_with_columns!(
    slope_columns,
    vec![(slope, slope_se, (slope + 0.5) / slope_se)],
    metadata = serde_json::json!({ "id": "slope" })
);
```

既定の $\ell/d = 0.8$、$R = 32$、シード 7 では、RMSE と理論 SE の比は 9 点で 0.82 から 1.16 の間にある。
$R = 32$ の RMSE の相対的な揺らぎは約 $1/\sqrt{2R} = 0.125$ なので、この幅は反復数から見込める範囲である。
当てはめた傾きは $-0.4999$、その SE は $0.0233$ で、$-1/2$ との差は $0.004\,\mathrm{SE}$ だった。
シードを 1〜5 に変えると、傾きは $-0.512$ から $-0.487$ の間に入る。
$R = 64$ では傾きの SE が $0.0165$ に下がり、傾きは $-0.509$ になる。
$\ell/d = 0.3$ では誤差の水準が約 2.1 倍に上がり、傾きは $-0.479$（差は $0.91\,\mathrm{SE}$）になる。

## 小さい標本数での非線形性

$N$ を $2^8$ から始めるのは、逆数の非線形性が小さい $N$ で誤差を大きくするからである。
$\hat p$ を正規近似して $\hat\pi$ の分散を $N^{-2}$ の項まで展開すると、デルタ法の値の $1 + 8(1-p)/(pN)$ 倍になる。
$p = 0.509$ では、この増え方は $N = 64$ で約 12%、$N = 256$ で約 3% である。
増え方は $N$ とともに消えるので、小さい $N$ を当てはめに含めると傾きは $-1/2$ より急になる。

## まとめ

モンテカルロ推定の誤差の減り方は一つの系列の途中経過ではなく、`substream` で選んだ独立な系列による反復で測る。
$R$ 回の反復の RMSE は理論の SE のまわりに相対的に約 $1/\sqrt{2R}$ 揺らぐので、その幅を見込んで比べる。
両対数軸の最小二乗で求めた傾きは、SE $\sqrt{1/(2R)}/\sqrt{\sum_j (x_j - \bar x)^2}$ の範囲で $-1/2$ と比べられ、この例では差は SE の 1 倍以内だった。
傾きが $-1/2$ なので、SE を半分にするには標本を 4 倍にする。
逆数のような非線形な推定量では、小さい $N$ の点が傾きを急にするので、当てはめから外す。
