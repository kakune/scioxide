間隔 $d$ の平行線を引いた床に長さ $\ell$ の針を落とすと、針が線と交わる確率は $\pi$ を含む。
G.-L. L. Buffon が 1777 年に発表したこの関係を逆に使えば、交差の割合から $\pi$ を推定できる。
このページは `UniformDirection` で針の向きを、`Uniform` で針の中心の位置を引き、推定値 $\hat\pi$ の標準誤差と信頼区間をデルタ法で求める。
独立な反復で測った誤差が標本数 $N$ に対して傾き $-1/2$ で減ることは、[Buffon の針の誤差の収束率](../buffon-error-slope/)で確かめる。

## 交差の確率

線を $x$ 軸に平行に引き、針の長さを $\ell \le d$ とする。
針の中心から最も近い線までの距離を $y$、針の向きを単位ベクトル $\mathbf u = (u_x, u_y)$ とする。
針を無作為に落とすとき、$y$ は $[0, d/2]$ の一様分布に、$\mathbf u$ は単位円周上の一様分布に従い、両者は独立である。
針の両端は中心から線に垂直な方向へ $(\ell/2)|u_y|$ だけ離れるので、針は

$$
y \le \frac{\ell}{2}\,|u_y|
$$

のときに線と交わる。
$\mathbf u = (\cos\theta, \sin\theta)$ と書けば $\theta$ は $[0, 2\pi)$ の一様分布に従い、$|u_y| = |\sin\theta|$ の平均は $2/\pi$ である。
$y$ と $\mathbf u$ は独立なので、まず $\mathbf u$ を固定して $y$ について平均すると、交差の確率は

$$
p = \mathrm E\!\left[\frac{\ell |u_y| / 2}{d/2}\right] = \frac{\ell}{d}\,\mathrm E|u_y| = \frac{2\ell}{\pi d}
$$

になる。
$\ell \le d$ を仮定するのは、2 本の線に同時に交わる針を数えないためである。

## 推定量と標準誤差

$N$ 本の針のうち $K$ 本が線と交わったとする。
針は互いに独立なので $K$ は二項分布 $\mathrm{Binomial}(N, p)$ に従い、割合 $\hat p = K/N$ の標準誤差（SE）は $\sqrt{p(1-p)/N}$ である。
$p = 2\ell/(\pi d)$ を $\pi$ について解くと推定量

$$
\hat\pi = g(\hat p) = \frac{2\ell}{d\,\hat p}
$$

を得る。
$g$ は $\hat p$ の逆数なので非線形で、$\hat\pi$ の分布は $\hat p$ の分布を単に拡大したものにはならない。
そこで 1 次の Taylor 展開 $g(\hat p) \approx g(p) + g'(p)(\hat p - p)$（デルタ法）を使う。
$g'(p) = -2\ell/(d p^2) = -\pi/p$ なので、$p$ を $\hat p$ で置き換えた SE は

$$
\mathrm{SE}(\hat\pi) \approx |g'(\hat p)|\sqrt{\frac{\hat p(1-\hat p)}{N}} = \hat\pi\sqrt{\frac{1-\hat p}{K}}
$$

になる。
漸近 95% 信頼区間（CI）は $\hat\pi \pm 1.96\,\mathrm{SE}(\hat\pi)$ である。
真の値を入れた $\mathrm{SE} = \pi\sqrt{(1-p)/(pN)}$ は $N^{-1/2}$ に比例する。

2 次の項まで展開すると、$\hat\pi$ には約 $\pi(1-p)/(pN)$ の偏りもあり、SE との比は $\sqrt{(1-p)/(pN)}$ である。
$N \ge 256$ ではこの比が $\ell/d = 0.1$ でも 0.24 以下、既定の $\ell/d = 0.8$ では約 0.06 以下なので、信頼区間は偏りをほぼ無視できる。
$K = 0$ では $\hat\pi$ が定義されないので、セルはその場合にエラーを返す。

## 針の向きの標本化

`UniformDirection::<f64>::new(2)` は単位円周上の一様分布を表す。
標本を作るときは、互いに独立な標準正規の 2 成分を引き、`hypot` で求めた長さで割る。
2 次元の標準正規分布は回転で変わらないので、正規化したベクトルの向きは一様になる。
長さが 0 の組は棄却して引き直すが、この棄却はほとんど起こらない。
この方法は三角関数を呼ばない。
角度 $\theta$ を $[0, \pi)$ の一様乱数として引くと推定したい $\pi$ を入力に使うことになるが、方向ベクトルを使えば推定値の計算に $\pi$ は入らない。
球面の一般の次元での性質は[球面上の一様方向](oxref:random-circular-uniform-direction)で説明した。

行単位の `sample_n_into` は $N$ 本分の $(u_x, u_y)$ を一つの配列に行優先で書き込む。
中心の位置は `Uniform::new(0.0, 0.5)`（$d = 1$ の $[0, d/2)$）の `sample_n_into` で引く。
どちらも `SamplingPolicy::rollback(OutputPolicy::Incremental)` を渡し、失敗したときに生成器を呼び出し前の状態に戻す。
二つの分布は同じ生成器から順に引き、向きを $N$ 本分引いてから位置を $N$ 本分引く。

## 標本数を変えた推定

次のセルは $N = 2^8, 2^9, \dots, 2^{k}$ のそれぞれで針を落とし、$\hat\pi$、デルタ法の SE、95% CI、真の値との差を SE で割った値 $z$ を表にする。
入力は比 $\ell/d$（0.1〜1）、最大の指数 $k$、乱数のシードで、線の間隔を $d = 1$ とする。
各行の針は `Pcg64` の `split(指数)` で選んだ別々の系列から引く。
`split` はルート生成器から番号で系列を選び、異なる番号は増分の異なる別の合同列になる。
系列が重ならない条件は[系列の間隔と重なり](oxref:random-prng-stream-spacing)で説明した。
そのため、行どうしの推定値は独立とみなせる。

グラフは対数軸の $N$ に対して $\hat\pi$ と 95% CI をエラーバーで描き、真の $\pi$ を横線で示す。
エラーバーの長さは $N$ が 4 倍になるごとにほぼ半分になるはずである。

```rust
//| id: random-buffon-estimate
//| ref: random-buffon-estimate
//| title: 標本数を変えて π を推定し信頼区間を求める
//| run: reactive
//| crates: [scioxide-core, scioxide-random]
//| inputs:
//|   needle_ratio: {"type":"range","label":"針の長さと線の間隔の比 ℓ/d [-]","description":"交差の確率 p = 2ℓ/(πd) を変え、標準誤差を変える。","min":0.1,"max":1,"step":0.05,"value":0.8}
//|   max_exponent: {"type":"range","label":"最大の標本数の指数 k（N = 2ᵏ）[-]","description":"表とグラフの最後の行の標本数。","min":10,"max":18,"step":1,"value":16}
//|   needle_seed: {"type":"range","label":"乱数のシード [-]","description":"Pcg64 のシード。各行はこのシードから split で選んだ系列を使う。","min":1,"max":1000,"step":1,"value":42}
//| cases:
//|   - {"id":"short-needle","label":"短い針 ℓ/d = 0.2","description":"交差の確率が 0.127 に下がり、同じ N で標準誤差の理論値が約 2.7 倍になる。","inputs":{"needle_ratio":0.2}}
//|   - {"id":"long-run","label":"N = 2¹⁸ まで","description":"最後の行の標準誤差は約 0.0060 で、行の幅は N^{-1/2} で狭まる。","inputs":{"max_exponent":18}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"estimates","path":"/rows/8/0","equals":65536}
//|       - {"artifact":"estimates","path":"/rows/8/1","equals":33446}
//|       - {"artifact":"estimates","path":"/rows/8/3","range":{"min":3.10,"max":3.18}}
//|       - {"artifact":"estimates","path":"/rows/8/4","range":{"min":0.0110,"max":0.0130}}
//|   - case: short-needle
//|     expect:
//|       - {"artifact":"estimates","path":"/rows/8/2","range":{"min":0.12,"max":0.135}}
//|       - {"artifact":"estimates","path":"/rows/8/4","range":{"min":0.029,"max":0.035}}
//|   - case: long-run
//|     expect:
//|       - {"artifact":"estimates","path":"/rows/10/0","equals":262144}
//|       - {"artifact":"estimates","path":"/rows/10/4","range":{"min":0.0055,"max":0.0065}}
use scioxide_core::RealScalar;
use scioxide_random::{
    Distribution, OutputPolicy, Pcg64, SamplingPolicy, SamplingRequest, SeedableRng,
    SplittableRng, Uniform, UniformDirection,
};

let pi = std::f64::consts::PI; // 比較の基準（真の値）
let last = max_exponent.round() as usize;
let n_max = 1_usize << last;
let direction = UniformDirection::<f64>::new(2).map_err(|e| e.to_string())?;
// 中心から最も近い線までの距離 y は [0, d/2) で一様（d = 1）。
let offset = Uniform::new(0.0_f64, 0.5).map_err(|e| e.to_string())?;
let policy = SamplingPolicy::rollback(OutputPolicy::Incremental);
let mut direction_workspace = direction
    .workspace(policy, n_max)
    .map_err(|e| e.to_string())?;
let mut offset_workspace = policy
    .workspace(SamplingRequest::scalars(n_max))
    .map_err(|e| e.to_string())?;
let (mut uv, mut y) = (vec![0.0_f64; 2 * n_max], vec![0.0_f64; n_max]);
let root = Pcg64::from_seed(needle_seed.round() as u64);
let (mut rows, mut bars) = (Vec::new(), Vec::new());
for exponent in 8..=last {
    let n = 1_usize << exponent;
    // 標本数ごとに別の系列を選ぶ。
    let mut rng = root.split(exponent as u64).map_err(|e| e.to_string())?;
    direction
        .sample_n_into(&mut rng, policy, &mut uv[..2 * n], &mut direction_workspace)
        .map_err(|e| e.to_string())?;
    offset
        .sample_n_into(&mut rng, policy, &mut y[..n], &mut offset_workspace)
        .map_err(|e| e.to_string())?;
    // 交差の条件 y ≤ (ℓ/2)|u_y|（uv は行優先の (u_x, u_y)）。
    let hits = y[..n]
        .iter()
        .zip(uv.chunks_exact(2))
        .filter(|&(&y, u)| y <= 0.5 * needle_ratio * u[1].abs())
        .count();
    if hits == 0 {
        return Err(format!("N = {n} で交差が 0 本のため π̂ が定義されない"));
    }
    let p_hat = hits as f64 / n as f64;
    let pi_hat = 2.0 * needle_ratio / p_hat;
    // デルタ法: SE(π̂) = π̂ √((1 − p̂)/K)。
    let se = pi_hat * RealScalar::sqrt((1.0 - p_hat) / hits as f64);
    let (low, high) = (pi_hat - 1.96 * se, pi_hat + 1.96 * se);
    bars.push([n as f64, pi_hat, low, high]);
    rows.push((n, hits, p_hat, pi_hat, se, low, high, (pi_hat - pi) / se));
}
emit_chart!(serde_json::json!({
    "kind": "errorbar",
    "dataZoom": true,
    "tooltip": true,
    "xLabel": "標本数 N [本]",
    "yLabel": "π の推定値 [-]",
    "xType": "log",
    "yMin": 2.0,
    "yMax": 4.5,
    "series": [{ "name": "π̂ と 95% 信頼区間", "points": bars }],
    "annotations": [{ "kind": "line", "axis": "y", "value": pi, "label": "π" }]
}));
let fixed5 = serde_json::json!({ "fractionDigits": 5 });
let digits3 = serde_json::json!({ "significantDigits": 3 });
let fixed2 = serde_json::json!({ "fractionDigits": 2 });
let columns = serde_json::json!([
    { "key": "0", "label": "N [本]", "type": "integer" },
    { "key": "1", "label": "交差数 K [本]", "type": "integer" },
    { "key": "2", "label": "p̂ [-]", "type": "number", "format": fixed5 },
    { "key": "3", "label": "π̂ [-]", "type": "number", "format": fixed5 },
    { "key": "4", "label": "SE(π̂) [-]", "type": "number", "format": digits3 },
    { "key": "5", "label": "95% CI 下限 [-]", "type": "number", "format": fixed5 },
    { "key": "6", "label": "95% CI 上限 [-]", "type": "number", "format": fixed5 },
    { "key": "7", "label": "z = (π̂ − π)/SE [-]", "type": "number", "format": fixed2 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "estimates" })
);
```

既定の $\ell/d = 0.8$ では、交差の確率は $p = 1.6/\pi = 0.50930$ である。
シード 42 の $N = 65536$ の行は $K = 33446$、$\hat\pi = 3.13513$、$\mathrm{SE} = 0.0120$ で、95% CI $[3.11162, 3.15864]$ は $\pi$ を含み、差は $z = -0.54$ である。
9 行の $z$ は $-1.33$ から $1.55$ の間にあり、エラーバーの長さは $N$ が 4 倍になるごとにほぼ半分になる。
$k = 18$ にすると、$N = 262144$ の行は $\hat\pi = 3.14152$、$\mathrm{SE} = 0.00602$ になる。

$\ell/d = 0.2$ にすると $p = 0.12732$ に下がる。
SE の理論値 $\pi\sqrt{(1-p)/(pN)}$ は既定の約 2.67 倍になり、$N = 65536$ の行で測った SE は $0.0311$（既定の 2.59 倍）だった。
この行は $\hat\pi = 3.07861$、$z = -2.02$ で、95% CI の外に出た。
各行が CI の外に出る確率は約 5% なので、独立な 9 行のうち少なくとも 1 行が外に出る確率は $1 - 0.95^9 \approx 37\%$ あり、この程度の外れは珍しくない。
相対的な SE $\sqrt{(1-p)/(pN)}$ は $p$ が大きいほど小さいので、$\ell \le d$ の範囲では $\ell = d$ の針が最も少ない標本数で同じ精度に達する。

## まとめ

Buffon の針では交差の割合 $\hat p$ の逆数から $\hat\pi = 2\ell/(d\hat p)$ を作るので、SE はデルタ法で $\hat\pi\sqrt{(1-\hat p)/K}$ と求め、$\hat\pi \pm 1.96\,\mathrm{SE}$ を 95% CI として解釈する。
`UniformDirection` は正規の 2 成分を長さで割って向きを作り、三角関数も $\pi$ も使わずに単位円周上の一様な向きを与える。
標本数ごとに `split` で別の系列を選べば、行どうしの推定値を独立とみなし、CI の外に出た行の数を確率 5% の事象として数えられる。
$\ell/d$ を小さくすると $p$ が下がって同じ $N$ で SE が大きくなるので、この推定では $\ell = d$ が最も効率がよい。
