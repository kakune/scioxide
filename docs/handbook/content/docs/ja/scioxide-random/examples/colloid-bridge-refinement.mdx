[コロイド粒子の拡散と Stokes–Einstein の関係](../colloid-diffusion/)では、粒子の位置をフレームの間隔 $\Delta t$ ごとに作った。
フレームの間の動きが要ることもある。
たとえば露光時間中の像のぼけを模擬するときや、粗い刻みで作った経路を細かい刻みの計算に使うときである。
このページは `BrownianBridgePlan` で粗い軌跡を細分し、すでに作った点を変えずにフレームの間を埋められることを確かめる。

## 橋による軌跡の細分

位置の各成分は標準 Wiener 過程 $W(t)$ を $\sqrt{2D}$ 倍した $\sqrt{2D}\,W(t)$ である。
Brownian 橋は両端の値 $W(t_l)$ と $W(t_r)$ を固定したときの中点 $t_m$ の条件付き分布

$$
W(t_m) \mid W(t_l), W(t_r) \sim \mathcal N\!\left(W(t_l) + \frac{t_m - t_l}{t_r - t_l}\bigl(W(t_r) - W(t_l)\bigr),\ \frac{(t_m - t_l)(t_r - t_m)}{t_r - t_l}\right)
$$

から点を足していく。
条件付き平均は両端を結ぶ直線で、条件付き分散は区間の中央で最も大きく、両端で 0 になる。

`BrownianBridgePlan::new(&times)` は時刻の格子 $t_0 < t_1 < \dots < t_n$ を検査して保持し、各段の重みと条件付き標準偏差を $O(n)$ で前もって計算する。
`apply_into(z, output, workspace)` は $n$ 個の標準正規座標 `z` を、$W(t_0) = 0$ から始まる標準 Wiener 過程の値 $W(t_1), \dots, W(t_n)$ に $O(n)$ で写し、成功したときだけ `output` に書く。
座標 `z[0]` が終点 $W(t_n) = \sqrt{t_n - t_0}\,z_0$ を決め、残りの座標は両端が決まった区間の中点に、幅優先・左から右の順で割り当てられる。
8 区間の格子では、座標が経路の添字 8, 4, 2, 6, 1, 3, 5, 7 を順に埋める。

$8 \cdot 2^r$ 区間の格子を幅優先で二分すると、最初の 7 回の二分は 8 区間の格子と同じ区間を同じ順序で分ける。
そのため先頭の 8 個の座標は 8 区間の格子の点を同じ条件付き分布で決める。
細かい格子の時刻を粗い格子の時刻と同じ浮動小数点数にしておけば、重みも一致する。
8 区間の Plan に `z[..8]` を渡した軌跡と、細かい Plan に `z` 全体を渡した軌跡は、粗い格子の点で一致する。
粗い点を先に作り、後から座標を足してフレームの間を埋めても、粗い点の分布は変わらない。
Plan と作業領域の使い方は [Brownian 橋過程による確率経路の階層的生成](../brownian-bridge/)で説明した。

## 細分した軌跡の分散

次のセルは前のページの既定の粒子（$a = 0.5$ μm、293.15 K の水、$D = 0.4286$ μm²/s）の 1 成分を、$\Delta t = 0.1$ s の 8 フレーム（0.8 s）で作り、各フレームを $2^r$ 個の刻みに細分する。
入力は細分の段数 $r$、粒子数 $N$、乱数のシードである。
粒子ごとに 2 成分を独立な標本として扱うので、標本の数は $M = 2N$ である。

一つ目のグラフは最初の標本について細分した軌跡を線で、8 区間の Plan で作った粗い点を記号で描く。
二つ目のグラフは細かい格子の各時刻での変位の分散を記号と 95% 区間の帯で、理論値 $2Dt$ を破線で示す。
二つのグラフは時刻の軸を共有し、片方を拡大するともう片方も同じ範囲を表示する。
平均 0 は既知なので、分散は二乗の平均 $\hat v = \sum x^2/M$ で推定し、その SE は $2Dt\sqrt{2/M}$ になる。
一つ目の表は終点での変位、細かい増分、粗い増分の分散を理論値 $2Dt$ と比べ、二つ目の表は細分の前後で粗い格子の点がどれだけ違うかの最大値を出す。

```rust
//| id: random-colloid-bridge
//| ref: random-colloid-bridge
//| title: Brownian 橋で軌跡を細分し分散を確かめる
//| run: reactive
//| crates: [scioxide-core, scioxide-random]
//| inputs:
//|   refine_level: {"type":"range","label":"細分の段数 r [-]","description":"一つのフレームを 2^r 個の刻みに分ける。","min":1,"max":5,"step":1,"value":3}
//|   bridge_particles: {"type":"range","label":"粒子数 N [個]","description":"分散の標準誤差を変える。","min":64,"max":1024,"step":64,"value":256}
//|   bridge_seed: {"type":"range","label":"乱数のシード [-]","description":"SplitMix64 のシード。","min":1,"max":1000,"step":1,"value":7}
//| cases:
//|   - {"id":"finest","label":"r = 5（256 刻み）","description":"δt = 0.003125 s まで細分しても粗い点の差は 0 で、細かい増分の分散は理論値 0.002679 μm² と 0.43 SE の差になる。","inputs":{"refine_level":5}}
//|   - {"id":"many-particles","label":"N = 1024 個","description":"終点の分散の標準誤差が 0.0429 から 0.0214 μm² に半減する。","inputs":{"bridge_particles":1024}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"grid","path":"/rows/0/2","range":{"min":0,"max":1e-12}}
//|       - {"artifact":"variances","path":"/rows/1/3","approx":{"value":0.01071456,"atol":1e-7}}
//|       - {"artifact":"variances","path":"/rows/1/1","range":{"min":0.0104,"max":0.011}}
//|       - {"artifact":"variances","path":"/rows/0/1","range":{"min":0.58,"max":0.8}}
//|   - case: finest
//|     expect:
//|       - {"artifact":"grid","path":"/rows/0/1","equals":256}
//|       - {"artifact":"grid","path":"/rows/0/2","range":{"min":0,"max":1e-12}}
//|       - {"artifact":"variances","path":"/rows/1/3","approx":{"value":0.00267864,"atol":1e-7}}
//|   - case: many-particles
//|     expect:
//|       - {"artifact":"variances","path":"/rows/0/2","approx":{"value":0.021434,"atol":1e-5}}
use scioxide_core::RealScalar;
use scioxide_random::{
    BrownianBridgePlan, Distribution, Normal, OutputPolicy, SamplingPolicy, SamplingRequest,
    SeedableRng, SplitMix64,
};

// 前のページの既定の粒子: a = 0.5 μm、T = 293.15 K、η = 1.002 mPa·s。D [μm²/s]。
let d = 1.380649e-23 * 293.15 / (6.0 * std::f64::consts::PI * 1.002e-3 * 0.5e-6) * 1e12;
let (frame, coarse_n) = (0.1_f64, 8_usize);
let split = 1_usize << refine_level as u32;
let fine_n = coarse_n * split;
// 細かい格子の時刻を frame · (i / 2^r) で作り、粗い格子の時刻と同じ値にする。
let coarse_t: Vec<f64> = (0..=coarse_n).map(|j| frame * j as f64).collect();
let fine_t: Vec<f64> = (0..=fine_n)
    .map(|i| frame * (i as f64 / split as f64))
    .collect();
let coarse = BrownianBridgePlan::new(&coarse_t).map_err(|e| e.to_string())?;
let fine = BrownianBridgePlan::new(&fine_t).map_err(|e| e.to_string())?;
let mut coarse_ws = coarse.workspace(()).map_err(|e| e.to_string())?;
let mut fine_ws = fine.workspace(()).map_err(|e| e.to_string())?;
let standard = Normal::<f64>::standard();
let mut rng = SplitMix64::from_seed(bridge_seed as u64);
let policy = SamplingPolicy::rollback(OutputPolicy::Atomic);
let mut z_ws = policy
    .workspace(SamplingRequest::scalars(fine_n))
    .map_err(|e| e.to_string())?;
let (mut z, mut w_coarse, mut w_fine) =
    (vec![0.0; fine_n], vec![0.0; coarse_n], vec![0.0; fine_n]);
let scale = RealScalar::sqrt(2.0 * d); // W(t) [√s] を変位 [μm] に換算する
let mut var_t = vec![0.0; fine_n]; // 各時刻の変位の二乗和（平均 0 は既知）
let (mut fine_sq, mut coarse_sq, mut max_gap) = (0.0, 0.0, 0.0_f64);
let (mut path, mut knots) = (vec![[0.0, 0.0]], vec![[0.0, 0.0]]);
let samples = 2 * bridge_particles as usize; // 粒子数 × 2 成分
for sample in 0..samples {
    standard
        .sample_n_into(&mut rng, policy, &mut z, &mut z_ws)
        .map_err(|e| e.to_string())?;
    coarse
        .apply_into(&z[..coarse_n], &mut w_coarse, &mut coarse_ws)
        .map_err(|e| e.to_string())?;
    fine.apply_into(&z, &mut w_fine, &mut fine_ws)
        .map_err(|e| e.to_string())?;
    let mut previous = 0.0;
    for (i, &w) in w_fine.iter().enumerate() {
        let x = scale * w;
        var_t[i] += x * x;
        fine_sq += (x - previous) * (x - previous);
        previous = x;
        if sample == 0 {
            path.push([fine_t[i + 1], x]);
        }
    }
    let mut previous = 0.0;
    for (j, &w) in w_coarse.iter().enumerate() {
        // w_fine[(j + 1) 2^r − 1] は粗い格子の時刻 t_{j+1} の値。
        max_gap = max_gap.max(scale * (w_fine[(j + 1) * split - 1] - w).abs());
        coarse_sq += scale * scale * (w - previous) * (w - previous);
        previous = w;
        if sample == 0 {
            knots.push([coarse_t[j + 1], scale * w]);
        }
    }
}
let m = samples as f64;
let fine_dt = frame / split as f64;
let check = |name: &'static str, sum_sq: f64, count: f64, t: f64| {
    let (v, theory) = (sum_sq / count, 2.0 * d * t);
    let se = theory * RealScalar::sqrt(2.0 / count);
    (name, v, se, theory, (v - theory) / se)
};
let rows = vec![
    check(
        "終点 x(0.8 s) の分散",
        var_t[fine_n - 1],
        m,
        frame * coarse_n as f64,
    ),
    check("細かい増分の分散", fine_sq, m * fine_n as f64, fine_dt),
    check("粗い増分の分散", coarse_sq, m * coarse_n as f64, frame),
];
let (mut band, mut marks, mut theory) = (Vec::new(), Vec::new(), Vec::new());
for (i, &s) in var_t.iter().enumerate() {
    let (t, v) = (fine_t[i + 1], s / m);
    let se = 2.0 * d * t * RealScalar::sqrt(2.0 / m);
    band.push([t, v, v - 1.96 * se, v + 1.96 * se]);
    marks.push([t, v]);
    theory.push([t, 2.0 * d * t]);
}
emit_chart!(
    serde_json::json!({
        "kind": "xy",
        "link": { "group": "colloid-bridge-time" },
        "xLabel": "時刻 t [s]",
        "yLabel": "変位の x 成分 [μm]",
        "xMin": 0.0,
        "xMax": 0.8,
        "dataZoom": true,
        "tooltip": true,
        "layers": [
            {"id": "fine", "kind": "line", "name": "細分した軌跡", "points": path},
            {"id": "coarse", "kind": "scatter", "name": "8 区間の Plan の点", "points": knots}
        ]
    }),
    metadata = serde_json::json!({ "id": "path" })
);
emit_chart!(
    serde_json::json!({
        "kind": "xy",
        "link": { "group": "colloid-bridge-time" },
        "xLabel": "時刻 t [s]",
        "yLabel": "変位の 1 成分の分散 [μm²]",
        "xMin": 0.0,
        "xMax": 0.8,
        "yMin": 0.0,
        "dataZoom": true,
        "tooltip": true,
        "layers": [
            {"id": "ci", "kind": "band", "name": "分散の 95% 区間", "points": band},
            {"id": "variance", "kind": "scatter", "name": "細分した軌跡の分散", "points": marks},
            {"id": "theory", "kind": "line", "name": "理論 2Dt", "points": theory,
                "style": {"lineType": "dashed"}}
        ]
    }),
    metadata = serde_json::json!({ "id": "variance" })
);
let sig4 = serde_json::json!({ "significantDigits": 4 });
let sig3 = serde_json::json!({ "significantDigits": 3 });
let fixed2 = serde_json::json!({ "fractionDigits": 2 });
let columns = serde_json::json!([
    { "key": "0", "label": "量" },
    { "key": "1", "label": "推定値 [μm²]", "type": "number", "format": sig4 },
    { "key": "2", "label": "SE [μm²]", "type": "number", "format": sig3 },

]);

    rows,

    { "key": "0", "label": "細かい刻み δt [s]", "type": "number", "format": sig4 },
    { "key": "1", "label": "細かい刻みの数 [個]", "type": "integer" },
    { "key": "2", "label": "粗い格子の点の最大差 [μm]", "type": "number", "format": sig3 }

    columns,
    vec![(fine_dt, fine_n, max_gap)],
    metadata = serde_json::json!({ "id": "grid" })
```

既定の $r = 3$ では 1 フレームを 8 刻みに分け、$\delta t = 0.0125$ s の 64 刻みの軌跡を作る。
一つ目のグラフでは、細分した軌跡の線が 8 個の粗い点を全て通る。
粗い格子の点の最大差は 0 で、8 区間の Plan と細かい Plan は同じ座標から同じ浮動小数点数を作った。
$N = 256$ 個の粒子の 2 成分（512 標本）で、各量の分散は次のとおりである。

- 終点の分散は $0.7078 \pm 0.0429$ μm²（理論 $0.6857$）で、差は $0.52\,\mathrm{SE}$ である。
- 細かい増分の分散は $0.010796 \pm 0.000084$ μm²（理論 $0.010715$）で、差は $0.98\,\mathrm{SE}$ である。
- 粗い増分の分散は $0.08476 \pm 0.00189$ μm²（理論 $0.08572$）で、差は $-0.51\,\mathrm{SE}$ である。

二つ目のグラフの記号は破線 $2Dt$ に沿い、帯の幅は $t$ に比例して広がる。
一つ目のグラフを拡大すると、二つ目のグラフも同じ時刻の範囲に絞られ、その範囲の分散を軌跡と並べて読める。

ケース「r = 5」で $\delta t = 0.003125$ s まで細分しても、粗い点の差は 0 のままである。
細かい増分の分散は $0.0026832$ μm²（理論 $0.0026786$）で、差は $0.43\,\mathrm{SE}$ になる。
$r$ を変えると 1 標本あたりに引く座標の数 $8 \cdot 2^r$ が変わるので、2 番目以降の標本は別の座標から作られ、分散の推定値は $r$ ごとに異なる。
最初の標本の粗い点（一つ目のグラフの記号）は先頭の 8 個の座標だけで決まるので、$r$ によらず同じ値になる。
ケース「N = 1024 個」では終点での分散の SE が $0.0214$ μm² に半減し、差は $-0.09\,\mathrm{SE}$ になる。

## まとめ

`BrownianBridgePlan` は終点を先に決め、区間の中点を幅優先で埋めるので、$8 \cdot 2^r$ 区間の Plan の先頭の 8 個の座標は 8 区間の Plan と同じ点を作る。
粗い軌跡を先に作ってから座標を足して細分しても、粗い格子の点は変わらず、終点と増分の分散は $2Dt$ のままである。
細かい格子の時刻を粗い格子の時刻と同じ浮動小数点数で作れば、粗い点は丸め誤差も含めて一致する。
同じシードでも細分の段数を変えると引く座標の数が変わるので、段数ごとの比較にはシードではなく分散と SE を使う。
