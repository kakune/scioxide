水に浮かぶ直径 1 μm ほどの粒子を顕微鏡で追うと、溶媒の分子との衝突で不規則に動く。
A. Einstein（1905 年）はこの Brown 運動の拡散係数を温度と粘度に結び付け、J. Perrin はその測定から Avogadro 定数を求めた。
このページは Stokes–Einstein の式で求めた拡散係数 $D$ を使い、`Normal` の増分から粒子の軌跡を作る。
平均二乗変位（MSD）の傾きと増分の二乗和から $D$ を推定して理論値と信頼区間で比べ、位置の誤差がそれぞれの推定量をどれだけ偏らせるかを確かめる。

## Stokes–Einstein の式と平均二乗変位

温度 $T$ [K]、粘度 $\eta$ [Pa·s] の液体の中で半径 $a$ [m] の球が受ける粘性抵抗の係数は、Stokes の分布で $\gamma = 6\pi\eta a$ である。
揺動散逸の関係 $D = k_B T/\gamma$ から

$$
D = \frac{k_B T}{6\pi\eta a}
$$

を得る。
$k_B = 1.380649 \times 10^{-23}$ J/K は SI の定義値である。
20 ℃（$T = 293.15$ K）の水（$\eta = 1.002$ mPa·s）の中の $a = 0.5$ μm の粒子では $D = 0.4286$ μm²/s になる。

粒子の質量による速度の緩和時間 $m/\gamma$ は 1 μm の粒子で $10^{-7}$ s 程度なので、これより長い時間刻みでは位置の各成分が独立な Wiener 過程として動く。
時間 $t$ の間の変位の各成分は平均 0、分散 $2Dt$ の正規分布に従い、互いに重ならない時間の変位は独立である。
顕微鏡の像の面で追う $d = 2$ 次元の変位 $\Delta\mathbf r$ では、平均二乗変位は

$$
\mathrm{MSD}(t) = \mathrm E\,|\Delta\mathbf r(t)|^2 = 2dDt = 4Dt
$$

である。
3 次元で追うなら $6Dt$ になる。

## 平均二乗変位の傾きと増分による推定

$N$ 個の粒子をフレームの間隔 $\Delta t$ で $K$ フレーム追い、時刻 $t_j = j\Delta t$（$j = 1, \dots, K$）の位置の原点からの変位を $\mathbf r_i(t_j)$ とする。
粒子 $i$ ごとに原点を通る直線 $\mathrm{MSD} = 2dDt$ を最小二乗で当てはめると

$$
\hat D_i = \frac{\sum_j t_j\,|\mathbf r_i(t_j)|^2}{2d\sum_j t_j^2}
$$

を得る。
同じ粒子の異なる時刻の変位は相関するので、時刻ごとの MSD を独立な点として回帰すると標準誤差（SE）を小さく見積もる。
粒子どうしは独立なので、$\hat D = \frac1N\sum_i \hat D_i$ の SE は粒子間の標準偏差 $s_D$ から $s_D/\sqrt N$ と求め、95% 区間を $\hat D \pm 1.96\,s_D/\sqrt N$ とする。

別の推定として、全ての増分の二乗和から

$$
\hat D_{\mathrm{inc}} = \frac{\sum |\Delta\mathbf r|^2}{2d\,N K\,\Delta t}
$$

を作る。
増分の各成分は分散 $2D\Delta t$ の独立な正規変数なので、$\nu\hat D_{\mathrm{inc}}/D$ は自由度 $\nu = dNK$ のカイ二乗分布に正確に従う。
95% 区間は `ChiSquared` の分位点から $[\nu\hat D_{\mathrm{inc}}/\chi^2_{\nu,0.975},\ \nu\hat D_{\mathrm{inc}}/\chi^2_{\nu,0.025}]$ と求まり、SE は $\hat D_{\mathrm{inc}}\sqrt{2/\nu}$ である。
純粋な Brown 運動では $\hat D_{\mathrm{inc}}$ が最尤推定量で、MSD の傾きより SE が小さい。

## 位置の誤差による偏り

実測の位置には、像の重心を求めるときの誤差が加わる。
各フレームの位置の各成分に、互いに独立な平均 0、標準偏差 $\sigma$ の正規誤差 $\varepsilon_j$ が加わるとする。
原点も観測した位置から測るので、時刻 $t_j$ の観測した変位の各成分は $x(t_j) - x(0) + \varepsilon_j - \varepsilon_0$ で、分散は $2Dt_j + 2\sigma^2$ になる。
したがって観測した MSD は $2d(Dt + \sigma^2)$ で、直線に定数 $2d\sigma^2$ が足される。

この定数は三つの推定量に別々の偏りを与える。
増分の各成分は分散が $2D\Delta t + 2\sigma^2$ になるので、$\mathrm E\,\hat D_{\mathrm{inc}} = D + \sigma^2/\Delta t$ である。
原点を通る直線の傾きは $\mathrm E\,\hat D_i = D + \sigma^2\sum_j t_j/\sum_j t_j^2 = D + 3\sigma^2/((2K + 1)\Delta t)$ で、$K = 50$ では偏りが $\hat D_{\mathrm{inc}}$ の $3/101$ 倍に縮む。
切片を持つ直線 $\mathrm{MSD} = c + 2dDt$ を当てはめた傾き

$$
\hat D_i^{\mathrm{free}} = \frac{\sum_j (t_j - \bar t)\,|\mathbf r_i(t_j)|^2}{2d\sum_j (t_j - \bar t)^2},
\qquad \bar t = \frac1K\sum_j t_j
$$

は、$\sum_j (t_j - \bar t) = 0$ なので定数の項が消え、$\sigma$ によらず偏りがない。
その代わり、傾きだけでなく切片も推定するので SE は原点を通る直線より大きい。
偏り $\sigma^2/\Delta t$ はフレームの間隔が短いほど大きいので、速いカメラで撮った記録ほど、増分の二乗和は位置の誤差に左右される。
誤差があると隣り合う増分が $\varepsilon_j$ を共有して負に相関するので、$\hat D_{\mathrm{inc}}$ のカイ二乗の区間も成り立たない。

次のセルの入力は粒子の半径 $a$ [μm]、温度 $T$ [K]、粘度 $\eta$ [mPa·s]、フレームの間隔 $\Delta t$ [s]、位置の誤差 $\sigma$ [nm]、乱数のシードである。
粒子数は $N = 200$、フレーム数は $K = 50$ に固定する。
各粒子の $2K$ 個の増分は分散 $2D\Delta t$ の `Normal` の `sample_n_into` で、使い回す出力と作業領域に一度に引く。
続けて $2(K + 1)$ 個の標準正規変数を引き、$\sigma$ 倍して時刻 $t_0, \dots, t_K$ の位置に足す。
$\sigma$ を変えても乱数の列は変わらないので、同じシードの軌跡に誤差だけを足した結果を比べられる。
グラフは各時刻の MSD を記号、その 95% 区間を帯、理論値 $2d(Dt + \sigma^2)$ を破線で示す。
表は三つの推定値の SE と 95% 区間を、偏りを含めた期待値と Stokes–Einstein の理論値に比べる。

//| ref: random-colloid-msd
//| title: 平均二乗変位の傾きから拡散係数を推定する
//| run: reactive
//| crates: [scioxide-core, scioxide-random]
//| inputs:
//|   radius_um: {"type":"range","label":"粒子の半径 a [μm]","description":"D は a に反比例する。","min":0.1,"max":2,"step":0.05,"value":0.5}
//|   temperature_k: {"type":"range","label":"温度 T [K]","description":"D は T に比例する。","min":273.15,"max":363.15,"step":0.5,"value":293.15}
//|   viscosity_mpas: {"type":"range","label":"粘度 η [mPa·s]","description":"20 ℃ の水は 1.002 mPa·s。","min":0.3,"max":5,"step":0.001,"value":1.002}
//|   frame_s: {"type":"range","label":"フレームの間隔 Δt [s]","description":"位置の誤差による偏り σ²/Δt を変える。","min":0.01,"max":0.5,"step":0.01,"value":0.1}
//|   localization_nm: {"type":"range","label":"位置の誤差 σ [nm]","description":"各フレームの位置の各成分に加える正規誤差の標準偏差。","min":0,"max":100,"step":5,"value":0}
//|   colloid_seed: {"type":"range","label":"乱数のシード [-]","description":"SplitMix64 のシード。","min":1,"max":1000,"step":1,"value":42}
//| cases:
//|   - {"id":"large-particle","label":"a = 1 μm","description":"D は 0.2143 μm²/s に半減する。同じシードでは増分がそのまま縮むので (D̂ − D)/SE は変わらない。","inputs":{"radius_um":1}}
//|   - {"id":"hot-water","label":"80 ℃ の水","description":"T = 353.15 K、η = 0.355 mPa·s で D = 1.457 μm²/s になり、20 ℃ の約 3.4 倍に増える。","inputs":{"temperature_k":353.15,"viscosity_mpas":0.355}}
//|   - {"id":"localization","label":"σ = 30 nm","description":"増分の二乗和の期待値は σ²/Δt = 0.009 μm²/s だけ大きくなる。切片を持つ直線の傾きは偏らない。","inputs":{"localization_nm":30}}
//|   - {"id":"fast-camera","label":"σ = 30 nm、Δt = 0.02 s","description":"偏り σ²/Δt は 0.045 μm²/s に増え、D の約 10% になる。","inputs":{"localization_nm":30,"frame_s":0.02}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"estimates","path":"/rows/0/6","approx":{"value":0.4285824,"atol":1e-6}}
//|       - {"artifact":"estimates","path":"/rows/0/1","range":{"min":0.35,"max":0.51}}
//|       - {"artifact":"estimates","path":"/rows/1/1","range":{"min":0.3,"max":0.56}}
//|       - {"artifact":"estimates","path":"/rows/2/1","range":{"min":0.41,"max":0.45}}
//|       - {"artifact":"estimates","path":"/rows/2/2","approx":{"value":0.00432,"atol":0.0002}}
//|   - case: large-particle
//|     expect:
//|       - {"artifact":"estimates","path":"/rows/0/6","approx":{"value":0.2142912,"atol":1e-6}}
//|   - case: hot-water
//|     expect:
//|       - {"artifact":"estimates","path":"/rows/0/6","approx":{"value":1.45728,"atol":1e-4}}
//|       - {"artifact":"estimates","path":"/rows/2/1","range":{"min":1.4,"max":1.52}}
//|   - case: localization
//|     expect:
//|       - {"artifact":"estimates","path":"/rows/2/5","approx":{"value":0.4375824,"atol":1e-6}}
//|       - {"artifact":"estimates","path":"/rows/1/5","approx":{"value":0.4285824,"atol":1e-6}}
//|   - case: fast-camera
//|     expect:
//|       - {"artifact":"estimates","path":"/rows/2/5","approx":{"value":0.4735824,"atol":1e-6}}
//|       - {"artifact":"estimates","path":"/rows/2/1","range":{"min":0.46,"max":0.49}}
use scioxide_core::RealScalar;
use scioxide_random::{
    ChiSquared, Distribution, Normal, OutputPolicy, Quantile, SamplingPolicy, SamplingRequest,
    SeedableRng, SplitMix64,
};

const BOLTZMANN: f64 = 1.380649e-23; // [J/K]
let (particles, frames, dims) = (200_usize, 50_usize, 2_usize);
// Stokes–Einstein の D [m²/s] を [μm²/s] に換算する（独立検算の基準）。
let drag = 6.0 * std::f64::consts::PI * viscosity_mpas * 1e-3 * radius_um * 1e-6;
let d_theory = BOLTZMANN * temperature_k / drag * 1e12;
let sigma = localization_nm * 1e-3; // [μm]
let step = Normal::new(0.0_f64, RealScalar::sqrt(2.0 * d_theory * frame_s))
    .map_err(|e| e.to_string())?;
let standard = Normal::<f64>::standard();
let mut rng = SplitMix64::from_seed(colloid_seed as u64);
let policy = SamplingPolicy::rollback(OutputPolicy::Atomic);
let mut step_ws = policy
    .workspace(SamplingRequest::scalars(dims * frames))
    .map_err(|e| e.to_string())?;
let mut noise_ws = policy
    .workspace(SamplingRequest::scalars(dims * (frames + 1)))
    .map_err(|e| e.to_string())?;
let times: Vec<f64> = (1..=frames).map(|j| j as f64 * frame_s).collect();
let t_bar = times.iter().sum::<f64>() / frames as f64;
let sum_t2: f64 = times.iter().map(|t| t * t).sum();
let sum_c2: f64 = times.iter().map(|t| (t - t_bar) * (t - t_bar)).sum();
let (mut msd, mut msd_sq) = (vec![0.0; frames], vec![0.0; frames]);
let (mut origin_fit, mut free_fit) = (Vec::new(), Vec::new());
let mut squares = 0.0;
let mut increments = vec![0.0_f64; dims * frames]; // 行優先の (Δx, Δy)
let mut noise = vec![0.0_f64; dims * (frames + 1)]; // 時刻 t₀, …, t_K の位置の誤差
for _ in 0..particles {
    step.sample_n_into(&mut rng, policy, &mut increments, &mut step_ws)
        .map_err(|e| e.to_string())?;
    standard
        .sample_n_into(&mut rng, policy, &mut noise, &mut noise_ws)
        .map_err(|e| e.to_string())?;
    // 観測位置 = 真の位置 + σε。変位は観測した原点 σε₀ から測る。
    let origin = [sigma * noise[0], sigma * noise[1]];
    let (mut position, mut previous) = ([0.0_f64; 2], origin);
    let (mut origin_moment, mut free_moment) = (0.0, 0.0);
    for (j, dr) in increments.chunks_exact(dims).enumerate() {
        let mut r2 = 0.0;
        for k in 0..dims {
            position[k] += dr[k];
            let seen = position[k] + sigma * noise[(j + 1) * dims + k];
            squares += (seen - previous[k]) * (seen - previous[k]);
            r2 += (seen - origin[k]) * (seen - origin[k]);
            previous[k] = seen;
        }
        msd[j] += r2;
        msd_sq[j] += r2 * r2;
        origin_moment += times[j] * r2;
        free_moment += (times[j] - t_bar) * r2;
    }
    // 粒子ごとに MSD = 2dDt と MSD = c + 2dDt を最小二乗で当てはめる。
    origin_fit.push(origin_moment / (2.0 * dims as f64 * sum_t2));
    free_fit.push(free_moment / (2.0 * dims as f64 * sum_c2));
}
let nf = particles as f64;
// 粒子間の平均と、粒子間の標準偏差から求めた SE。
let mean_se = |v: &[f64]| {
    let mean = v.iter().sum::<f64>() / nf;
    let var = v.iter().map(|s| (s - mean) * (s - mean)).sum::<f64>() / (nf - 1.0);
    (mean, RealScalar::sqrt(var / nf))
};
let (d_origin, se_origin) = mean_se(&origin_fit);
let (d_free, se_free) = mean_se(&free_fit);
// 増分の二乗和: σ = 0 なら ν D̂/D は自由度 ν = dNK のカイ二乗分布に従う。
let nu = (dims * particles * frames) as f64;
let d_inc = squares / (nu * 2.0 * frame_s);
let chi = ChiSquared::new(nu).map_err(|e| e.to_string())?;
let upper = chi.quantile(0.975).map_err(|e| e.to_string())?;
let lower = chi.quantile(0.025).map_err(|e| e.to_string())?;
let se_inc = d_inc * RealScalar::sqrt(2.0 / nu);
// 偏りを含む期待値: 原点を通る直線は D + σ² Σt/Σt²、増分は D + σ²/Δt。
let origin_bias = sigma * sigma * t_bar * frames as f64 / sum_t2;
let rows = vec![
    (
        "MSD の傾き（原点を通る）",
        d_origin,
        se_origin,
        d_origin - 1.96 * se_origin,
        d_origin + 1.96 * se_origin,
        d_theory + origin_bias,
    ),
    (
        "MSD の傾き（切片あり）",
        d_free,
        se_free,
        d_free - 1.96 * se_free,
        d_free + 1.96 * se_free,
        d_theory,
    ),
    (
        "増分の二乗和",
        d_inc,
        se_inc,
        nu * d_inc / upper,
        nu * d_inc / lower,
        d_theory + sigma * sigma / frame_s,
    ),
];
let rows: Vec<_> = rows
    .into_iter()
    .map(|(name, x, se, lo, hi, expected)| {
        (name, x, se, lo, hi, expected, d_theory, (x - d_theory) / se)
    })
    .collect();
let (mut band, mut marks, mut theory) = (Vec::new(), Vec::new(), Vec::new());
for (j, &t) in times.iter().enumerate() {
    let mean = msd[j] / nf;
    let se = RealScalar::sqrt((msd_sq[j] / nf - mean * mean) / (nf - 1.0));
    band.push([t, mean, mean - 1.96 * se, mean + 1.96 * se]);
    marks.push([t, mean]);
    theory.push([t, 2.0 * dims as f64 * (d_theory * t + sigma * sigma)]);
}
emit_chart!(serde_json::json!({
    "kind": "xy",
    "xLabel": "経過時間 t [s]",
    "yLabel": "平均二乗変位 [μm²]",
    "xMin": 0.0,
    "yMin": 0.0,
    "dataZoom": true,
    "tooltip": true,
    "layers": [
        {"id": "ci", "kind": "band", "name": "MSD の 95% 区間", "points": band},
        {"id": "msd", "kind": "scatter", "name": "MSD（200 粒子）", "points": marks},
        {"id": "theory", "kind": "line", "name": "理論 4(Dt + σ²)", "points": theory,
            "style": {"lineType": "dashed"}}
    ]
}));
let sig4 = serde_json::json!({ "significantDigits": 4 });
let sig3 = serde_json::json!({ "significantDigits": 3 });
let fixed2 = serde_json::json!({ "fractionDigits": 2 });
let columns = serde_json::json!([
    { "key": "0", "label": "推定の方法" },
    { "key": "1", "label": "D̂ [μm²/s]", "type": "number", "format": sig4 },
    { "key": "2", "label": "SE [μm²/s]", "type": "number", "format": sig3 },
    { "key": "3", "label": "95% 区間の下限 [μm²/s]", "type": "number", "format": sig4 },
    { "key": "4", "label": "95% 区間の上限 [μm²/s]", "type": "number", "format": sig4 },
    { "key": "5", "label": "偏りを含む期待値 [μm²/s]", "type": "number", "format": sig4 },
    { "key": "6", "label": "Stokes–Einstein の D [μm²/s]", "type": "number", "format": sig4 },
    { "key": "7", "label": "(D̂ − D)/SE [-]", "type": "number", "format": fixed2 }
]);
emit_table_with_columns!(

    rows,
    metadata = serde_json::json!({ "id": "estimates" })
);

既定の入力では Stokes–Einstein の拡散係数は $D = 0.42858$ μm²/s で、位置の誤差は $\sigma = 0$ である。
シード 42 の原点を通る MSD の傾きは $\hat D = 0.4221 \pm 0.0264$ μm²/s、95% 区間 $[0.3703, 0.4739]$ で、理論値との差は $-0.25\,\mathrm{SE}$ である。
切片を持つ直線の傾きは $0.4191 \pm 0.0325$ μm²/s で、差は $-0.29\,\mathrm{SE}$ になる。
増分の二乗和は $\hat D_{\mathrm{inc}} = 0.42793 \pm 0.00428$ μm²/s、カイ二乗分布による区間 $[0.41967, 0.43644]$ で、差は $-0.15\,\mathrm{SE}$ である。
同じデータで、原点を通る直線の SE は増分の二乗和の約 6.2 倍、切片を持つ直線の SE はさらにその 1.23 倍になる。
原点を通る最小二乗は大きく揺らぐ長い時刻の変位に重みを置くので、独立な増分を一つずつ使う推定より SE が大きい。
グラフの記号は破線 $4Dt$ に沿い、MSD の標準偏差が $4Dt$ に比例するので、帯の幅は $t$ とともに広がる。

シードを 1 にすると、三つの推定値の差は $+0.02$、$-0.71$、$+0.54\,\mathrm{SE}$ になる。
ケース「a = 1 μm」では $D = 0.21429$ μm²/s に半減する。
同じシードでは標準正規の座標が同じで、増分が $\sqrt{D}$ に比例して縮むので、差を SE で割った値は変わらない。
同じ理由で、$\sigma = 0$ のままフレームの間隔 $\Delta t$ だけを変えても、推定値は $\Delta t = 0.01$ s でも $0.1$ s と同じになる。
ケース「80 ℃ の水」（353.15 K、0.355 mPa·s）では $D = 1.4573$ μm²/s で、$\hat D_{\mathrm{inc}} = 1.4551 \pm 0.0146$ μm²/s になる。

ケース「σ = 30 nm」では、増分の二乗和が $0.43745$ μm²/s に上がり、偏りを含む期待値 $D + \sigma^2/\Delta t = 0.43758$ μm²/s とほぼ一致して、$D$ からは $+2.03\,\mathrm{SE}$ 離れる。
原点を通る直線の期待値は $0.42885$ μm²/s で、偏りは $0.0003$ μm²/s しかない。
ケース「σ = 30 nm、Δt = 0.02 s」では、偏り $\sigma^2/\Delta t$ が $0.045$ μm²/s に増える。
増分の二乗和は $0.47408$ μm²/s（期待値 $0.47358$）で $D$ から $+9.60\,\mathrm{SE}$ 離れ、カイ二乗の区間 $[0.4649, 0.4835]$ は $D$ を含まない。
切片を持つ直線の傾きは $0.4208 \pm 0.0327$ μm²/s で、差は $-0.24\,\mathrm{SE}$ に留まる。
SE が最も小さい推定量は、位置の誤差があると偏りが最も大きい推定量でもある。

## まとめ

Stokes–Einstein の式 $D = k_BT/(6\pi\eta a)$ で求めた $D$ から、各成分の増分を分散 $2D\Delta t$ の `Normal` で引けば、2 次元の平均二乗変位は $4Dt$ になる。
MSD の傾きから $D$ を推定するときは、時刻ごとの点の相関を避けて、粒子ごとの傾きの標準偏差から SE を求める。
位置の誤差がなければ増分の二乗和による推定のほうが SE が小さく、カイ二乗分布から正確な区間が求まる。
位置の誤差 $\sigma$ があると増分の二乗和は $\sigma^2/\Delta t$ だけ偏るので、フレームの間隔が短い記録では切片を持つ直線を MSD に当てはめる。
多数の粒子の MSD に切片を持つ直線をまとめて当てはめるときは、scioxide-stats の回帰を使える。
