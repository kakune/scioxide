砂岩の薄片を顕微鏡で観察し、格子点に当たった粒子を石英（Q）、長石（F）、岩片（L）に分けて数える方法をポイントカウントと呼ぶ。
数えた割合 $(x_Q, x_F, x_L)$ は各成分が非負で和が 1 になる組成データで、砂岩の分類には QFL の三角図が使われる。
和が 1 に固定されるので、各成分を独立な正規分布で模擬すると、非負性と和の制約が崩れる。
Dirichlet 分布はこの制約の集合（単体）の上に定義された分布で、組成データの基本的なモデルである。
このページは `Dirichlet` で QFL 組成を生成して三角図に描き、モーメントと周辺分布を閉形式と照合する。
薄片ごとに数えた点の数の揺れは、[ポイントカウントの過分散と Dirichlet 多項分布](../dirichlet-point-counts/)で調べる。

## 単体上の Dirichlet 分布

$K$ 成分の組成は単体 $\Delta^{K-1} = \{x \in \mathbb{R}^K : x_k \ge 0,\ \sum_k x_k = 1\}$ の点である。
集中度 $\alpha = (\alpha_1, \dots, \alpha_K)$（各 $\alpha_k > 0$）、$\alpha_0 = \sum_k \alpha_k$ の Dirichlet 分布の、最初の $K - 1$ 個の座標についての密度は

$$
f(x;\alpha) = \frac{\Gamma(\alpha_0)}{\prod_k \Gamma(\alpha_k)} \prod_{k=1}^K x_k^{\alpha_k - 1}
$$

である。
平均、分散、共分散は

$$
E[x_k] = \frac{\alpha_k}{\alpha_0},
\qquad
\operatorname{Var} x_k = \frac{\alpha_k(\alpha_0 - \alpha_k)}{\alpha_0^2(\alpha_0 + 1)},
\qquad
\operatorname{Cov}(x_j, x_k) = -\frac{\alpha_j \alpha_k}{\alpha_0^2(\alpha_0 + 1)} \quad (j \ne k)
$$

で、和が 1 に固定されるので異なる成分の共分散は負になる。
平均は $\alpha$ の比だけで決まり、比を保って $\alpha_0$ を大きくすると、分散と共分散は $1/(\alpha_0 + 1)$ に比例して縮む。
$\alpha_k < 1$ の成分は $x_k \to 0$ で密度が発散するので、点は三角形の辺と頂点に集まる。

成分 $k$ だけを取り出した周辺分布は $\mathrm{Beta}(\alpha_k, \alpha_0 - \alpha_k)$ で、成分をまとめた $x_j + x_k$ も $\mathrm{Beta}(\alpha_j + \alpha_k, \alpha_0 - \alpha_j - \alpha_k)$ に従う。
確率 $p$ の多項分布の観測 $n$ に対して、事前分布 $\mathrm{Dirichlet}(\alpha)$ の事後分布は $\mathrm{Dirichlet}(\alpha + n)$ になる。
事後分布が事前分布と同じ族に入るこの関係を共役と呼び、Dirichlet 分布は多項分布の確率 $p$ の共役事前分布である。

## Gamma 変数の正規化による生成

$Y_k \sim \mathrm{Gamma}(\alpha_k, 1)$ を独立に引いて $x_k = Y_k / \sum_j Y_j$ とすると $x \sim \mathrm{Dirichlet}(\alpha)$ で、$x$ は和 $\sum_j Y_j$ と独立になる。
`Dirichlet::new(&alpha)` は成分ごとの Gamma の標本化の定数を一度だけ準備する。
空の `alpha` は `InvalidInput`、非有限の成分は `NonFinite`、正でない成分は `DomainError` になり、メモリ領域や作業量が上限を超えると `ResourceLimit` か `ConvergenceFailure` になる。
`Dirichlet::with_options(&alpha, options)` は `LawOptions` を取り、範囲外の設定は `InvalidInput` になる。

全ての $\alpha_k \ge 1$ なら、Marsaglia–Tsang 法の Gamma 変数を最大値で割ってから正規化し、和のあふれを避ける。
1 未満の $\alpha_k$ を含むときは、$\mathrm{Gamma}(\alpha) = \mathrm{Gamma}(\alpha + 1)\,U^{1/\alpha}$（$U$ は独立な一様乱数）の関係を対数で計算し、最大の対数を引いてから指数をとる。
小さい $\alpha_k$ の Gamma 変数は 0 にアンダーフローしやすいが、対数のまま比べるので成分の比が残る。

`sample(&mut rng)` は任意のビット生成器（`BitGenerator`）を受け取り、長さ $K$ の `Vec` を返す。
多数の行を作るときは、一度の確保で $n$ 行を行優先の `Vec` に返す `sample_n` か、作業領域を使い回して確保しない `sample_n_into` を使う。
どちらも `sample` を $n$ 回呼んだ結果と同じ行を返す。
`contains_support` は成分が $[0, 1]$ にあり、和の誤差が $8K\epsilon$ 以内かを判定する。
`mean()`、`variance()`、`covariance()` も分布が返すが、このページは検算を独立にするために閉形式を手で計算する。

## 三角図とモーメント

次のセルは集中度 $\alpha_Q, \alpha_F, \alpha_L$（0.2–30）、試料数 $N$（100–3000 個）、シードを受け取り、`sample_n` で $N$ 個の組成を生成する。
本書の図には三角図の型がないので、重心座標を平面に写して散布図で描く。
頂点 Q を $(0, 0)$、F を $(1, 0)$、L を $(1/2, \sqrt{3}/2)$ に置き、組成 $(x_Q, x_F, x_L)$ を点 $(x_F + x_L/2,\ \sqrt{3}\,x_L/2)$ に写す。
三角形の辺を線、期待値 $\alpha/\alpha_0$ をひし形で重ねる。
表は平均、分散、共分散の標本値、手計算の理論値、SE、差 / SE を出す。
平均の SE は理論の分散から $\sqrt{\operatorname{Var} x_k / N}$ で求める。
分散と共分散の SE は、中心化した積 $(x_j - \bar{x}_j)(x_k - \bar{x}_k)$ の標本標準偏差を $\sqrt{N}$ で割って求める。
生成した組成と集中度は、次の節のセルに渡す。

```rust
//| id: random-dirichlet-qfl-ternary
//| ref: random-dirichlet-qfl-ternary
//| title: QFL 組成を Dirichlet 分布で生成し、三角図とモーメントを確かめる
//| run: reactive
//| crates: [scioxide-core, scioxide-random]
//| exports: [alpha, compositions]
//| inputs:
//|   alpha_q: {"type":"range","label":"石英の集中度 α_Q [-]","min":0.2,"max":30,"step":0.1,"value":6}
//|   alpha_f: {"type":"range","label":"長石の集中度 α_F [-]","min":0.2,"max":30,"step":0.1,"value":2.5}
//|   alpha_l: {"type":"range","label":"岩片の集中度 α_L [-]","min":0.2,"max":30,"step":0.1,"value":1.5}
//|   count: {"type":"range","label":"試料数 N [個]","min":100,"max":3000,"step":100,"value":1000}
//|   seed: {"type":"range","label":"乱数のシード [-]","min":1,"max":1000,"step":1,"value":1}
//| cases:
//|   - {"id":"corners","label":"α = (0.6, 0.5, 0.4)","description":"全ての α_k が 1 未満で、点は三角形の頂点と辺に集まる。石英の分散は既定の約 4.4 倍になる。","inputs":{"alpha_q":0.6,"alpha_f":0.5,"alpha_l":0.4}}
//|   - {"id":"concentrated","label":"α = (18, 7.5, 4.5)","description":"期待値は既定と同じで α₀ が 3 倍になり、分散と共分散は (α₀ + 1) の比 11/31 に縮む。","inputs":{"alpha_q":18,"alpha_f":7.5,"alpha_l":4.5}}
//|   - {"id":"few-samples","label":"N = 100","description":"SE が √10 倍に広がり、次の節の KS 距離も大きくなる。","inputs":{"count":100}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"moments","path":"/rows/0/2","approx":{"value":0.6,"atol":1e-12}}
//|       - {"artifact":"moments","path":"/rows/3/2","approx":{"value":0.02181818181818182,"atol":1e-12}}
//|       - {"artifact":"moments","path":"/rows/6/2","approx":{"value":-0.013636363636363636,"atol":1e-12}}
//|       - {"artifact":"moments","path":"/rows/0/1","range":{"min":0.58,"max":0.62}}
//|       - {"artifact":"moments","path":"/rows/6/1","range":{"min":-0.0165,"max":-0.0108}}
//|   - case: corners
//|     expect:
//|       - {"artifact":"moments","path":"/rows/0/2","approx":{"value":0.4,"atol":1e-12}}
//|       - {"artifact":"moments","path":"/rows/3/2","approx":{"value":0.096,"atol":1e-12}}
//|   - case: concentrated
//|     expect:
//|       - {"artifact":"moments","path":"/rows/3/2","approx":{"value":0.007741935483870968,"atol":1e-12}}
//|       - {"artifact":"moments","path":"/rows/3/1","range":{"min":0.0063,"max":0.0092}}
//|   - case: few-samples
//|     expect:
//|       - {"artifact":"moments","path":"/rows/0/3","approx":{"value":0.014770978917519,"atol":1e-9}}
use scioxide_core::RealScalar;
use scioxide_random::{Dirichlet, SeedableRng, SplitMix64};

let alpha = [alpha_q, alpha_f, alpha_l];
let law = Dirichlet::<f64>::new(&alpha).map_err(|e| e.to_string())?;
let n = count as usize;
let mut rng = SplitMix64::from_seed(seed as u64);
// N 行を行優先で一度に引く。各行が 1 つの組成 (x_Q, x_F, x_L)。
let flat = law.sample_n(&mut rng, n).map_err(|e| e.to_string())?;
let xs: Vec<&[f64]> = flat.chunks_exact(3).collect();
// 三角図の座標: Q を左下 (0, 0)、F を右下 (1, 0)、L を頂点 (1/2, √3/2) に置く。
let h = RealScalar::sqrt(3.0) / 2.0;
let points: Vec<[f64; 2]> = xs.iter().map(|x| [x[1] + 0.5 * x[2], h * x[2]]).collect();
// 独立検算: E[x_k] = α_k/α₀、Var = α_k(α₀ − α_k)/(α₀²(α₀ + 1))、Cov = −α_jα_k/(α₀²(α₀ + 1))。
let a0: f64 = alpha.iter().sum();
let mean: Vec<f64> = alpha.iter().map(|a| a / a0).collect();
let cov = |j: usize, k: usize| {
    let diagonal = if j == k { alpha[j] * a0 } else { 0.0 };
    (diagonal - alpha[j] * alpha[k]) / (a0 * a0 * (a0 + 1.0))
};
emit_chart!(
    serde_json::json!({
        "kind": "xy",
        "xLabel": "F + L/2 [-]",
        "yLabel": "(√3/2) L [-]",
        "xMin": 0,
        "xMax": 1,
        "yMin": 0,
        "yMax": 0.9,
        "dataZoom": true,
        "tooltip": true,
        "layers": [
            {
                "id": "edges",
                "kind": "line",
                "name": "三角形の辺（頂点 Q・F・L）",
                "points": [[0.0, 0.0], [1.0, 0.0], [0.5, h], [0.0, 0.0]]
            },
            {"id": "samples", "kind": "scatter", "name": "試料の組成", "points": points},
            {
                "id": "mean",
                "kind": "scatter",
                "name": "期待値 α/α₀",
                "style": {"symbol": "diamond"},
                "points": [[mean[1] + 0.5 * mean[2], h * mean[2]]]
            }
        ]
    }),
    metadata = serde_json::json!({ "id": "ternary" })
);
let nf = n as f64;
let sample_mean: Vec<f64> = (0..3)
    .map(|k| xs.iter().map(|x| x[k]).sum::<f64>() / nf)
    .collect();
let names = ["Q", "F", "L"];
let mut rows = Vec::new();
for k in 0..3 {
    let se = RealScalar::sqrt(cov(k, k) / nf);
    let label = format!("E[x_{}]", names[k]);
    rows.push((
        label,
        sample_mean[k],
        mean[k],
        se,
        (sample_mean[k] - mean[k]) / se,
    ));
}
for (j, k) in [(0, 0), (1, 1), (2, 2), (0, 1), (0, 2), (1, 2)] {
    // 中心化した積 (x_j − x̄_j)(x_k − x̄_k) の平均と、その標本標準偏差から求めた SE。
    let products: Vec<f64> = xs
        .iter()
        .map(|x| (x[j] - sample_mean[j]) * (x[k] - sample_mean[k]))
        .collect();
    let estimate = products.iter().sum::<f64>() / (nf - 1.0);
    let spread = products
        .iter()
        .map(|p| (p - estimate) * (p - estimate))
        .sum::<f64>();
    let se = RealScalar::sqrt(spread / (nf - 1.0) / nf);
    let label = if j == k {
        format!("Var x_{}", names[j])
    } else {
        format!("Cov(x_{}, x_{})", names[j], names[k])
    };
    rows.push((label, estimate, cov(j, k), se, (estimate - cov(j, k)) / se));
}
let sig4 = serde_json::json!({ "significantDigits": 4 });
let sig3 = serde_json::json!({ "significantDigits": 3 });
let fixed2 = serde_json::json!({ "fractionDigits": 2 });
let columns = serde_json::json!([
    { "key": "0", "label": "量" },
    { "key": "1", "label": "標本値 [-]", "type": "number", "format": sig4 },
    { "key": "2", "label": "理論値（手計算）[-]", "type": "number", "format": sig4 },
    { "key": "3", "label": "SE [-]", "type": "number", "format": sig3 },
    { "key": "4", "label": "差 / SE [-]", "type": "number", "format": fixed2 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "moments" })
);
export!(alpha, &alpha);
export!(compositions, &flat);
```

既定の入力（$\alpha = (6, 2.5, 1.5)$、$\alpha_0 = 10$、$N = 1000$ 個、シード 1）では、点は石英の頂点に寄った期待値 $(0.33, 0.13)$ を中心に広がる。
理論の平均は $(0.6, 0.25, 0.15)$、石英の分散は 0.02182、石英と長石の共分散は $-0.01364$ である。
9 つの量の差は $-1.39$ から $+1.56$ SE の間にある。

ケース「α = (0.6, 0.5, 0.4)」では全ての $\alpha_k$ が 1 未満で、点は三角形の頂点と辺に集まる。
石英の分散は理論値が 0.096 で既定の約 4.4 倍になり、標本の分散 0.1032 は $+2.56$ SE である。
9 つの量を同時に見るので、1 つが 2.5 SE を超える程度の外れは起こりうる。
ケース「α = (18, 7.5, 4.5)」は期待値が既定と同じで $\alpha_0 = 30$ になり、分散と共分散は既定の $11/31$ に縮む。
ケース「N = 100」では SE が $\sqrt{10}$ 倍に広がり、石英の平均の差は $+1.82$ SE になる。

## 周辺の Beta 分布

周辺分布が $\mathrm{Beta}(\alpha_k, \alpha_0 - \alpha_k)$ に従うことは、Kolmogorov–Smirnov（KS）距離で確かめる。
KS 距離は経験分布関数 $F_N$ と理論の分布関数 $F$ の差の最大値 $D_N = \sup_x |F_N(x) - F(x)|$ である。
$F$ が母数を推定せずに決まっているとき、$\sqrt{N} D_N$ は $N \to \infty$ で Kolmogorov 分布に従い、$P(\sqrt{N} D_N > 1.358) \approx 0.05$ である。
`Kolmogorov::new()` はこの極限分布で、`sf` が漸近的な上側確率を返す。
有限の $N$ の KS 統計量の分布は `KolmogorovSmirnovTwoSided::new(n)` が与える。

次のセルは前のセルが生成した組成と集中度を受け取り、3 成分の $D_N$、$\sqrt{N} D_N$、上側確率 $P(K > \sqrt{N} D_N)$ を表に出す。
同じ組成を使うので、入力と乱数のシードは前のセルで変える。
$D_N$ は整列した標本の各点 $x_{(i)}$ で $i/N - F(x_{(i)})$ と $F(x_{(i)}) - (i - 1)/N$ の大きいほうをとって求める。
図は $x = 0.01, 0.02, \dots, 0.99$ での $F_N(x) - F(x)$ を成分ごとに描き、$\pm 1.358/\sqrt{N}$ に基準線を引く。
図の格子は粗いので、表の $D_N$ は標本の全ての点で計算した値である。

```rust
//| id: random-dirichlet-beta-marginal
//| ref: random-dirichlet-beta-marginal
//| title: 各成分の周辺分布を Beta 分布と Kolmogorov–Smirnov 距離で比べる
//| run: reactive
//| crates: [scioxide-core, scioxide-random]
//| dependsOn:
//|   draw: random-dirichlet-qfl-ternary
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"ks","path":"/rows/0/1","approx":{"value":6,"atol":1e-12}}
//|       - {"artifact":"ks","path":"/rows/0/2","approx":{"value":4,"atol":1e-12}}
//|       - {"artifact":"ks","path":"/rows/0/4","range":{"min":0.2,"max":2.0}}
//|       - {"artifact":"ks","path":"/rows/2/4","range":{"min":0.2,"max":2.0}}
use scioxide_core::RealScalar;
use scioxide_random::{Beta, Cdf, Kolmogorov, Survival};

// 前のセルの集中度 α と、行優先の組成 (x_Q, x_F, x_L) を受け取る。
let alpha: Vec<f64> =
    serde_json::from_value(draw["alpha"].clone()).map_err(|e| e.to_string())?;
let flat: Vec<f64> =
    serde_json::from_value(draw["compositions"].clone()).map_err(|e| e.to_string())?;
let a0: f64 = alpha.iter().sum();
let n = flat.len() / 3;
let kolmogorov = Kolmogorov::<f64>::new().map_err(|e| e.to_string())?;
let names = ["Q", "F", "L"];
let (mut rows, mut layers) = (Vec::new(), Vec::new());
for k in 0..3 {
    // 周辺分布 x_k ~ Beta(α_k, α₀ − α_k)。
    let beta = Beta::new(alpha[k], a0 - alpha[k]).map_err(|e| e.to_string())?;
    let mut values: Vec<f64> = flat.iter().skip(k).step_by(3).copied().collect();
    values.sort_by(f64::total_cmp);
    let mut distance = 0.0_f64;
    for (i, &x) in values.iter().enumerate() {
        let f = beta.cdf(x).map_err(|e| e.to_string())?;
        distance = distance
            .max((i + 1) as f64 / n as f64 - f)
            .max(f - i as f64 / n as f64);
    }
    let scaled = RealScalar::sqrt(n as f64) * distance;
    let tail = kolmogorov.sf(scaled).map_err(|e| e.to_string())?;
    rows.push((names[k], alpha[k], a0 - alpha[k], distance, scaled, tail));
    let mut gap = Vec::new();
    for j in 1..100 {
        let x = j as f64 / 100.0;
        let empirical = values.partition_point(|&v| v <= x) as f64 / n as f64;
        gap.push([x, empirical - beta.cdf(x).map_err(|e| e.to_string())?]);
    }
    layers.push(serde_json::json!({
        "id": names[k],
        "kind": "line",
        "name": format!("x_{}", names[k]),
        "points": gap
    }));
}
let limit = 1.358 / RealScalar::sqrt(n as f64);
emit_chart!(
    serde_json::json!({
        "kind": "xy",
        "xLabel": "組成の値 x [-]",
        "yLabel": "経験分布関数 − Beta の分布関数 [-]",
        "xMin": 0,
        "xMax": 1,
        "yMin": -0.1,
        "yMax": 0.1,
        "dataZoom": true,
        "tooltip": true,
        "annotations": [
            {"kind": "line", "axis": "y", "value": limit, "label": "+1.358/√N"},
            {"kind": "line", "axis": "y", "value": -limit, "label": "−1.358/√N"}
        ],
        "layers": layers
    }),
    metadata = serde_json::json!({ "id": "ecdf-gap" })
);
let fixed2 = serde_json::json!({ "fractionDigits": 2 });
let sig3 = serde_json::json!({ "significantDigits": 3 });
let columns = serde_json::json!([
    { "key": "0", "label": "成分" },
    { "key": "1", "label": "Beta の a [-]", "type": "number", "format": fixed2 },
    { "key": "2", "label": "Beta の b [-]", "type": "number", "format": fixed2 },
    { "key": "3", "label": "KS 距離 D [-]", "type": "number", "format": sig3 },
    { "key": "4", "label": "√N D [-]", "type": "number", "format": sig3 },
    { "key": "5", "label": "P(K > √N D) [-]", "type": "number", "format": sig3 }
]);
emit_table_with_columns!(columns, rows, metadata = serde_json::json!({ "id": "ks" }));
```

既定の入力では、3 成分の $\sqrt{N} D_N$ が 0.76 から 1.04 で、上側確率は 0.23 から 0.61 である。
$D_N$ は最大でも 0.033 で、図の 3 本の差は全て $\pm 1.358/\sqrt{N} = \pm 0.043$ の内側にある。
前のセルでケース「α = (0.6, 0.5, 0.4)」を選ぶと、周辺は $\mathrm{Beta}(0.4, 1.1)$ のように $a < 1$ になり、密度は 0 で発散する。
分布関数は連続なので KS 距離の尺度はそのまま使え、$\sqrt{N} D_N$ は 0.95 から 1.11、上側確率は 0.17 から 0.33 になる。
ケース「N = 100」では $D_N$ が 0.075–0.149 に大きくなり、$\sqrt{N} D_N$ は 0.75–1.49 である。
石英の上側確率は 0.024 で、$N = 100$ では漸近分布による近似の誤差も加わる。
上側確率はシードを変えるとほぼ一様に散らばるので、1 つのシードの値だけで分布の違いを判断しない。

## まとめ

`Dirichlet::new(&alpha)` は Gamma 変数を正規化して単体上の組成を生成し、$\alpha_k < 1$ の成分も対数で計算して比を保つ。
平均 $\alpha_k/\alpha_0$、分散 $\alpha_k(\alpha_0 - \alpha_k)/(\alpha_0^2(\alpha_0 + 1))$、負の共分散は手計算の閉形式で検算でき、比を保ったまま $\alpha_0$ を変えると組成の揺れの大きさだけが変わる。
各成分の周辺は $\mathrm{Beta}(\alpha_k, \alpha_0 - \alpha_k)$ で、`Beta` の分布関数との KS 距離 $\sqrt{N} D_N$ を `Kolmogorov` の上側確率で読める。
上側確率はシードごとに散らばるので、1 つのシードの値だけで分布の違いを判断せず、$N$ が小さいときは有限標本の `KolmogorovSmirnovTwoSided` を使う。
