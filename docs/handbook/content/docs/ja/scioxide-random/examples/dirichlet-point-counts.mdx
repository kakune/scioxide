[Dirichlet 分布で組成データを生成する](../dirichlet-composition/)では、砂岩の石英（Q）、長石（F）、岩片（L）の組成 $x$ を Dirichlet 分布で生成した。
実際の測定では、組成そのものではなく 1 枚の薄片の格子点に当たった粒子の数を数える。
このページは薄片ごとに組成が揺れるときの数の分布を Dirichlet 多項分布で表し、数の分散が組成を固定した多項分布よりどれだけ大きいかを確かめる。

## ポイントカウントと Dirichlet 多項分布

1 枚の薄片で $m$ 点を数えると、組成 $p$ を固定したときの数 $n = (n_Q, n_F, n_L)$ は多項分布 $\mathrm{Multinomial}(m, p)$ に従う。
薄片ごとに組成が $\mathrm{Dirichlet}(\alpha)$ で揺れると、$n$ は Dirichlet 多項分布に従う。
全分散の公式 $\operatorname{Var} n_k = E[\operatorname{Var}(n_k \mid p)] + \operatorname{Var}(E[n_k \mid p])$ に、$E[p_k^2] = \bar{p}_k^2 + \bar{p}_k(1 - \bar{p}_k)/(\alpha_0 + 1)$ を入れると

$$
\operatorname{Var} n_k = m\,\bar{p}_k(1 - \bar{p}_k)\,\frac{m + \alpha_0}{1 + \alpha_0},
\qquad \bar{p}_k = \frac{\alpha_k}{\alpha_0}
$$

となる。
多項分布の分散 $m\bar{p}_k(1 - \bar{p}_k)$ に掛かる係数 $(m + \alpha_0)/(1 + \alpha_0)$ を過分散の係数と呼ぶ。
係数は $m$ とともにほぼ比例して増えるので、割合 $n_k/m$ の分散は $m \to \infty$ でも 0 にならず、$\bar{p}_k(1 - \bar{p}_k)/(\alpha_0 + 1)$ に近づく。
点を多く数えても、薄片の間の組成の揺れは消えない。

成分 $k$ の数だけを見ると、$n_k$ はベータ二項分布に従う。
$a = \alpha_k$、$b = \alpha_0 - \alpha_k$ と置くと、その確率質量は

$$
P(n_k = j) = \binom{m}{j}\frac{B(j + a,\ m - j + b)}{B(a, b)}
$$

で、$B$ はベータ関数である。
組成を固定した多項分布では、$n_k$ は二項分布 $\mathrm{Binomial}(m, \bar{p}_k)$ に従う。

`Multinomial::new(trials, &probabilities)` は、確率の和が 1 から $8K\epsilon$ 以内であることを確かめてから和で割って正規化し、カテゴリごとに条件付きの二項分布を 1 回ずつ引いて数を作る。
空の確率は `InvalidInput`、$[0, 1]$ の外の確率や和の外れは `DomainError`、$2^{53}$ を超える試行数は `NotImplemented` になる。
`Dirichlet` の標本の和は 1 から丸め誤差の程度しか離れないので、そのまま `Multinomial::new` に渡せる。

同じ分布は `DirichletMultinomial::new(trials, &alpha)` として直接使え、`pmf`、`mean`、`variance`、`covariance` と標本化を持つ。
その標本化は Dirichlet の組成を作らず、成分ごとの条件付きのベータ二項分布を順に引く。
1 成分の周辺は `BetaBinomial::new(trials, a, b)` である。
このページは混合の構造を見るために `Dirichlet` と `Multinomial` を 2 段で引き、ベータ二項分布の確率質量は手で計算して検算に使う。

## 薄片ごとの点の数

次のセルは集中度、1 枚の点数 $m$（50–1000 点）、薄片の数 $R$（200–4000 枚）、シードを受け取り、薄片ごとに `Dirichlet` で組成を引いてから `Multinomial` で $m$ 点を数える。
比較のために、期待値の組成 $\bar{p}$ に固定した `Multinomial` でも同じ枚数を数える。
薄片ごとに `Multinomial::new` を呼ぶので、$K$ 個の確率の検査と小さな割り当てが $R$ 回起こる。

1 つ目の表は数の平均、二つのモデルの標本分散と SE、手計算の理論値を出す。
分散の SE は 4 次の中心モーメント $\mu_4$ から $\sqrt{(\mu_4 - s^4)/R}$ で求める。
図は石英の数を幅 $w$ 点のビンに集めた相対度数を $w$ で割って記号で描き、二項分布とベータ二項分布の確率質量を破線で重ねる。
ベータ二項分布の確率質量は scioxide-special の `ln_beta` で $\binom{m}{j} = 1/((m + 1)\,B(j + 1,\ m - j + 1))$ と分子のベータ関数を対数で計算した独立な検算である。

```rust
//| id: random-dirichlet-point-count
//| ref: random-dirichlet-point-count
//| title: ポイントカウントの数を Dirichlet 多項分布と多項分布で比べる
//| run: reactive
//| crates: [scioxide-core, scioxide-random, scioxide-special]
//| inputs:
//|   alpha_q: {"type":"range","label":"石英の集中度 α_Q [-]","min":0.2,"max":30,"step":0.1,"value":6}
//|   alpha_f: {"type":"range","label":"長石の集中度 α_F [-]","min":0.2,"max":30,"step":0.1,"value":2.5}
//|   alpha_l: {"type":"range","label":"岩片の集中度 α_L [-]","min":0.2,"max":30,"step":0.1,"value":1.5}
//|   points: {"type":"range","label":"1 枚の薄片で数える点 m [点]","min":50,"max":1000,"step":50,"value":300}
//|   sections: {"type":"range","label":"薄片の数 R [枚]","min":200,"max":4000,"step":200,"value":2000}
//|   seed: {"type":"range","label":"乱数のシード [-]","min":1,"max":1000,"step":1,"value":7}
//| cases:
//|   - {"id":"few-points","label":"m = 50 点","description":"過分散の係数は (50 + 10)/(1 + 10) = 5.45 に下がる。","inputs":{"points":50}}
//|   - {"id":"concentrated","label":"α = (18, 7.5, 4.5)","description":"α₀ = 30 で薄片の間の組成の揺れが小さく、係数は (300 + 30)/31 = 10.6 になる。","inputs":{"alpha_q":18,"alpha_f":7.5,"alpha_l":4.5}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"variances","path":"/rows/0/8","approx":{"value":2029.090909090909,"atol":1e-6}}
//|       - {"artifact":"variances","path":"/rows/0/6","range":{"min":1800,"max":2260}}
//|       - {"artifact":"variances","path":"/rows/0/3","range":{"min":63,"max":82}}
//|       - {"artifact":"variances","path":"/rows/0/5","approx":{"value":72,"atol":1e-9}}
//|   - case: few-points
//|     expect:
//|       - {"artifact":"variances","path":"/rows/0/8","approx":{"value":65.45454545454545,"atol":1e-9}}
//|       - {"artifact":"variances","path":"/rows/0/6","range":{"min":57,"max":74}}
//|   - case: concentrated
//|     expect:
//|       - {"artifact":"variances","path":"/rows/0/8","approx":{"value":766.4516129032257,"atol":1e-6}}
use scioxide_core::RealScalar;
use scioxide_random::{Binomial, Dirichlet, Mass, Multinomial, SeedableRng, SplitMix64};

let alpha = [alpha_q, alpha_f, alpha_l];
let a0: f64 = alpha.iter().sum();
let mean: Vec<f64> = alpha.iter().map(|a| a / a0).collect();
let (m, r) = (points as usize, sections as usize);
let law = Dirichlet::<f64>::new(&alpha).map_err(|e| e.to_string())?;
let fixed = Multinomial::new(m, &mean).map_err(|e| e.to_string())?;
let mut rng = SplitMix64::from_seed(seed as u64);
let (mut mixed, mut plain) = (Vec::with_capacity(r), Vec::with_capacity(r));
for _ in 0..r {
    // 薄片ごとに組成 p を引き、その p で m 点を数える（Dirichlet 多項分布）。
    let p = law.sample(&mut rng).map_err(|e| e.to_string())?;
    let counts = Multinomial::new(m, &p).map_err(|e| e.to_string())?;
    mixed.push(counts.sample(&mut rng).map_err(|e| e.to_string())?);
    plain.push(fixed.sample(&mut rng).map_err(|e| e.to_string())?);
}
// 標本分散と、4 次の中心モーメントから求めた分散の SE。
let moments = |data: &[Vec<usize>], k: usize| {
    let rf = data.len() as f64;
    let mu = data.iter().map(|c| c[k] as f64).sum::<f64>() / rf;
    let d2 = data.iter().map(|c| (c[k] as f64 - mu) * (c[k] as f64 - mu));
    let var = d2.clone().sum::<f64>() / (rf - 1.0);
    let m4 = d2.map(|d| d * d).sum::<f64>() / rf;
    (mu, var, RealScalar::sqrt((m4 - var * var) / rf))
};
// 独立検算: 多項分布 m p(1 − p)、Dirichlet 多項分布はそれに (m + α₀)/(1 + α₀) を掛ける。
let factor = (m as f64 + a0) / (1.0 + a0);
let names = ["石英 Q", "長石 F", "岩片 L"];
let mut rows = Vec::new();
for k in 0..3 {
    let (mu, var_dm, se_dm) = moments(&mixed, k);
    let (_, var_mn, se_mn) = moments(&plain, k);
    let binomial = m as f64 * mean[k] * (1.0 - mean[k]);
    rows.push((
        names[k],
        mu,
        m as f64 * mean[k],
        var_mn,
        se_mn,
        binomial,
        var_dm,
        se_dm,
        binomial * factor,
    ));
}
// 石英の数のヒストグラム（幅 w 点）と、二項分布・ベータ二項分布の確率質量。
let width = m.div_ceil(60);
let mut histogram = vec![[0_usize; 2]; m / width + 1];
for (c_mixed, c_plain) in mixed.iter().zip(&plain) {
    histogram[c_mixed[0] / width][0] += 1;
    histogram[c_plain[0] / width][1] += 1;
}
let scale = 1.0 / (r * width) as f64;
let center = |b: usize| (b * width) as f64 + 0.5 * (width - 1) as f64;
let observed_mixed: Vec<[f64; 2]> = (0..histogram.len())
    .filter(|&b| histogram[b][0] > 0)
    .map(|b| [center(b), histogram[b][0] as f64 * scale])
    .collect();
let observed_plain: Vec<[f64; 2]> = (0..histogram.len())
    .filter(|&b| histogram[b][1] > 0)
    .map(|b| [center(b), histogram[b][1] as f64 * scale])
    .collect();
let (a, b) = (alpha[0], a0 - alpha[0]);
let binomial = Binomial::new(m, mean[0]).map_err(|e| e.to_string())?;
let ln_norm = scioxide_special::ln_beta(a, b).map_err(|e| e.to_string())?;
let (mut beta_binomial, mut plain_pmf) = (Vec::new(), Vec::new());
for j in 0..=m {
    let (jf, mf) = (j as f64, m as f64);
    // ln C(m, j) = −ln(m + 1) − ln B(j + 1, m − j + 1)。
    let ln_choose = -RealScalar::ln(mf + 1.0)
        - scioxide_special::ln_beta(jf + 1.0, mf - jf + 1.0).map_err(|e| e.to_string())?;
    let ln_ratio =
        scioxide_special::ln_beta(jf + a, mf - jf + b).map_err(|e| e.to_string())? - ln_norm;
    beta_binomial.push([jf, RealScalar::exp(ln_choose + ln_ratio)]);
    plain_pmf.push([jf, binomial.pmf(j).map_err(|e| e.to_string())?]);
}
emit_chart!(
    serde_json::json!({
        "kind": "xy",
        "xLabel": "1 枚の薄片の石英の数 n_Q [点]",
        "yLabel": "確率質量・相対度数 / ビン幅 [1/点]",
        "xMin": 0,
        "xMax": m,
        "yMin": 0,
        "dataZoom": true,
        "tooltip": true,
        "layers": [
            {
                "id": "beta-binomial",
                "kind": "line",
                "name": "ベータ二項分布",
                "points": beta_binomial,
                "style": {"lineType": "dashed"}
            },
            {
                "id": "binomial",
                "kind": "line",
                "name": "二項分布 Binomial(m, p̄_Q)",
                "points": plain_pmf,
                "style": {"lineType": "dashed"}
            },
            {
                "id": "mixed",
                "kind": "scatter",
                "name": "Dirichlet 多項の度数",
                "points": observed_mixed
            },
            {"id": "plain", "kind": "scatter", "name": "多項の度数", "points": observed_plain}
        ]
    }),
    metadata = serde_json::json!({ "id": "quartz-counts" })
);
let fixed1 = serde_json::json!({ "fractionDigits": 1 });
let sig4 = serde_json::json!({ "significantDigits": 4 });
let sig3 = serde_json::json!({ "significantDigits": 3 });
let columns = serde_json::json!([
    { "key": "0", "label": "成分" },
    { "key": "1", "label": "数の平均 [点]", "type": "number", "format": fixed1 },
    { "key": "2", "label": "m α_k/α₀ [点]", "type": "number", "format": fixed1 },
    { "key": "3", "label": "多項の分散 [点²]", "type": "number", "format": sig4 },
    { "key": "4", "label": "その SE [点²]", "type": "number", "format": sig3 },
    { "key": "5", "label": "m p(1 − p) [点²]", "type": "number", "format": sig4 },
    { "key": "6", "label": "Dirichlet 多項の分散 [点²]", "type": "number", "format": sig4 },
    { "key": "7", "label": "その SE [点²]", "type": "number", "format": sig3 },
    { "key": "8", "label": "× (m + α₀)/(1 + α₀) [点²]", "type": "number", "format": sig4 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "variances" })
);
```

既定の入力（$\alpha = (6, 2.5, 1.5)$、$m = 300$ 点、$R = 2000$ 枚、シード 7）では、過分散の係数は $(300 + 10)/(1 + 10) = 28.2$ である。
石英の数の分散は多項分布で 72.9（理論 72.0、SE 2.3）、Dirichlet 多項分布で 2012（理論 2029、SE 56）になる。
Dirichlet 多項分布の分散と理論値の差は、石英で $-0.31$ SE、長石で $-0.25$ SE、岩片で $+0.07$ SE である。
数の平均は 180.3、74.7、45.0 点で、理論の 180、75、45 点に近い。
図では、多項分布の度数が 147–207 点の狭い山に集まり、Dirichlet 多項分布の度数は 32–287 点に広がる。
どちらの度数も破線の確率質量に沿う。

ケース「m = 50 点」では係数が 5.45 に下がり、石英の分散は多項分布で 11.8（理論 12.0）、Dirichlet 多項分布で 62.7（理論 65.5、SE 1.8）になる。
ケース「α = (18, 7.5, 4.5)」では $\alpha_0 = 30$ で係数が 10.6 になり、石英の Dirichlet 多項分布の分散は 759（理論 766）である。
1 枚の薄片で数えた数は組成の揺れの分だけ多項分布より大きく揺れる。

## 共役更新と組成の推定

Dirichlet 多項の共役更新（事前分布 $\mathrm{Dirichlet}(\alpha)$ と数 $n$ から事後分布 $\mathrm{Dirichlet}(\alpha + n)$ を作る関数）は scioxide-stats にない。
事後分布は $\alpha + n$ を手で作って `Dirichlet::new` に渡せば得られる。
複数の薄片から $\alpha$ そのものを推定するには、ベータ二項分布や Dirichlet 多項分布の尤度を最大化する。
各薄片の数の対数尤度は `DirichletMultinomial::log_pmf` で評価できる。

## まとめ

薄片ごとに組成が揺れるポイントカウントでは、数の分散が多項分布の $(m + \alpha_0)/(1 + \alpha_0)$ 倍になる。
`Multinomial` だけのモデルで組成の SE を $\sqrt{\bar{p}(1 - \bar{p})/m}$ と見積もると、薄片の間の揺れを見落として不確かさを小さく見積もる。
1 成分の数はベータ二項分布に従い、`ln_beta` で確率質量を独立に計算して度数と比べられる。
点の数 $m$ を増やしても割合の分散は $\bar{p}(1 - \bar{p})/(\alpha_0 + 1)$ より小さくならないので、精度を上げるには薄片の枚数を増やす。
