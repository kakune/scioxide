[年最大流量の GEV と 100 年確率の流量](../gev-flood-return-level/)では、母数を知っている河川の再現レベル $z_T$ を閉形式と `GeneralizedExtremeValue` の分位点で求めた。
実際に手元にあるのは、数十年から百年程度の年最大流量の記録である。
このページは同じ河川（$\mu = 1200$ m³/s、$\sigma = 350$ m³/s、$\xi = 0.15$）の記録を模擬し、記録の上側の点が再現レベルの曲線からどれだけ離れるか、$z_T$ を超えた年が何回現れるかを確かめる。

## 超過年数の分布

各年の最大流量 $X_1, \dots, X_N$ が独立に GEV に従うとき、$z_T$ を超えた年数 $K$ は二項分布 $\mathrm{Binomial}(N, 1/T)$ に従う。
`GeneralizedExtremeValue` の標本は開区間 $(0, 1)$ の一様乱数 $U$ を閉形式の分位点関数に通す逆変換で作る。
`Affine` の標本は基の標本の $\mu + \sigma Z$ である。
分布関数が連続なので、事象 $\{X > z_T\}$ は $\{U > 1 - 1/T\}$ と同じである。
そのため、同じシードなら $z_T$ を超える年数 $K$ は、丸めの境界に当たらない限り $\mu$、$\sigma$、$\xi$ によらない。

$N/T$ が数年しかないと $K$ の分布は右に歪み、正規近似 $N/T \pm 1.96\sqrt{N(1/T)(1 - 1/T)}$ は下端が負になることがある。
このページは二項分布の 2.5% 点 $k_{\mathrm{lo}}$ と 97.5% 点 $k_{\mathrm{hi}}$（`Binomial::quantile`）を「二項 95% 範囲」と呼ぶ。
`quantile(p)` は $P(K \le k) \ge p$ となる最小の $k$ を返すので、$P(K \le k_{\mathrm{hi}}) \ge 0.975$、$P(K < k_{\mathrm{lo}}) < 0.025$ で、両端を含めた範囲に $K$ が入る確率は 95% より大きい。
観測した $K$ の位置は下側確率 $P(K' \le K)$ と上側確率 $P(K' \ge K)$（$K'$ は同じ二項分布に従う変数）で読む。

次の 2 つのセルは同じ年最大値のモデルを使うので、Coles の符号の GEV を位置と尺度で作る関数を定義のブロックにまとめる。

```rust
//| id: random-gev-record-model
//| kind: definitions
//| title: Coles の形状 ξ の GEV を位置と尺度で作る
//| crates: [scioxide-random]
use scioxide_random::{Affine, GeneralizedExtremeValue};

/// 位置 μ [m³/s]、尺度 σ [m³/s]、Coles の形状 ξ の年最大流量の分布。scioxide-random の形状は c = −ξ。
pub(crate) fn annual_maximum_law(
    location: f64,
    scale: f64,
    xi: f64,
) -> Result<Affine<GeneralizedExtremeValue<f64>, f64>, String> {
    let gev = GeneralizedExtremeValue::new(-xi).map_err(|e| e.to_string())?;
    Affine::new(gev, location, scale).map_err(|e| e.to_string())
}
```

## 模擬した記録と再現レベルの図

図は横軸を対数の再現期間、縦軸を年最大流量にする。
GEV の再現レベル（`isf(1/T)`）を破線、同じ $\mu, \sigma$ の Gumbel を点線、模擬記録を点線でつないだ記号で描く。
模擬記録の $i$ 番目に小さい値には Gringorten のプロット位置 $p_i = (i - 0.44)/(N + 0.12)$ から $T_i = 1/(1 - p_i)$ を割り当てる。
点は $\log_{10} T$ で 0.04 以上離れたものだけを残すので、下側の密な部分は間引かれ、上位の点は全て残る。

上側の裾の点は少数の順序統計量なので、破線からの離れ方が大きい。
記録の最大値 $X_{(N)}$ は $P(X_{(N)} \le z) = F(z)^N$ に従うので、その中央 95% の範囲は $F(z)^N = 0.025$ と $0.975$ を解いた 2 つの流量である。
セルはこの範囲を `isf(1 − q^{1/N})`（$q = 0.025, 0.975$）で計算し、$1 - q^{1/N}$ は `expm1` で $-\operatorname{expm1}(\ln q / N)$ として桁落ちを避ける。
入力は $\mu$、$\sigma$、$\xi$、年数 $N$（100–5000 年）、乱数のシードである。
1 つ目の表は 5 つの $T$ の超過年数 $K$ を期待値 $N/T$、二項 95% 範囲、両側の裾確率と並べ、2 つ目の表は記録の最大値をその中央 95% の範囲と並べる。

既定の入力（$N = 2000$ 年、シード 123）では、$T \le 100$ 年の点は破線の近くにあり、それより上の点は破線より上にある。
最大値 8885.9 m³/s のプロット位置は $T_N = (N + 0.12)/0.56 \approx 3572$ 年で、そこでの破線の値 6826 m³/s を約 2060 m³/s 上回る。
最大値の中央 95% の範囲は 4865.9–11532.0 m³/s で、この記録の最大値はその中にある。
上側の裾の点が破線から離れることは、1 つの記録の順序統計量の揺らぎとして解釈する。

$u = -\ln y_T$ と置くと、GEV と Gumbel の再現レベルの差は $\sigma[(e^{\xi u} - 1)/\xi - u]$ である。
指数関数は下に凸なので $e^{\xi u} \ge 1 + \xi u$ で、差は $\xi > 0$ なら 0 以上、$\xi < 0$ なら 0 以下になり、$u = 0$、つまり $T = 1/(1 - e^{-1}) \approx 1.58$ 年でだけ 0 になる。
既定の $\xi = 0.15$ では、Gumbel の点線はこの点で破線に接し、それ以外では破線より下にあるので、$\xi = 0$ を仮定すると上側の裾を低く見積もる。

100 年確率の流量を超えた年数は $K = 25$ 年で、期待値 20 年、二項 95% 範囲 12–29 年の中にある。
500 年では $K = 9$ 年が範囲 1–8 年の上に出ていて、$P(K' \ge 9) = 0.021$ である。
5 つの $T$ の超過は同じ記録の上側の点を共有するので、互いに独立ではない。
$T = 500$ 年の $K$ は記録の上位 9 点だけで決まり、大きな $T$ ほど少数の最大値で決まる。

ケース「N = 100 年」では、$T \ge 50$ 年の二項 95% 範囲の下端が 0 になり、100 年の範囲は 0–3 年である。
このシードでは 2000 年の記録の最大値 8885.9 m³/s が最初の 100 年に入っていて、100 年の記録の最大値の 97.5% 点 6947.6 m³/s を超える。
100 年の記録の最大値が 97.5% 点を超える確率は定義から 2.5% で、このシードはその側に入った記録である。
ケース「ξ = −0.2」では曲線が上に凸になって上端 2950 m³/s に近づき、記録の最大値は 2699.3 m³/s になるが、超過年数の表は既定と同じ値になる。
これは逆変換の標本で $\{X > z_T\} = \{U > 1 - 1/T\}$ となることの確認である。

## 短い記録に現れる超過の回数

長さ $n$ 年の記録に $T$ 年確率の流量が 1 度も現れない確率は

$$
P(K = 0) = \left(1 - \frac{1}{T}\right)^n \approx e^{-n/T}
$$

で、$n = T = 100$ では 0.366 である。
次のセルは既定の河川で長さ $n$ 年の記録を $R$ 本模擬し、各記録で $z_T$（`isf(1/T)`）を超えた年数 $K$ を数える。
$K$ の分布は $\mu, \sigma, \xi$ によらないので、入力は再現期間 $T$（10–500 年）、記録の長さ $n$（10–300 年）、記録の本数 $R$（200–4000 本）、シードに限る。

図は `Binomial` の確率質量 $P(K = k)$ を破線の階段、記録の割合を記号で描き、確率質量の周りに割合の 95% の範囲 $P \pm 1.96\sqrt{P(1-P)/R}$ を帯で示す。
1 つ目の表は各 $k$ の記録の本数、割合、二項確率、割合の SE $\sqrt{P(1-P)/R}$ を出す。
2 つ目の表は $P(K = 0)$ の手計算 $(1 - 1/T)^n$、Poisson 近似、模擬記録の割合と、二項 95% 範囲、正規近似の範囲を並べる。

let columns = serde_json::json!([

    { "key": "1", "label": "記録 [本]", "type": "integer" },

    { "key": "3", "label": "二項確率 [-]", "type": "number", "format": sig4 },
    { "key": "4", "label": "割合の SE [-]", "type": "number", "format": sig3 }

// 独立検算: P(K = 0) = (1 − 1/T)^n と Poisson 近似 e^(−n/T)。正規近似の 95% 範囲と比べる。
let mean = n as f64 * p;
let sd = RealScalar::sqrt(mean * (1.0 - p));
let low = binomial.quantile(0.025).map_err(|e| e.to_string())?;
let high = binomial.quantile(0.975).map_err(|e| e.to_string())?;
let summary = vec![

    ("正規近似 n/T + 1.96 SD [年]", mean + 1.96 * sd),
];

    { "key": "0", "label": "量" },
    { "key": "1", "label": "値", "type": "number", "format": sig4 }

emit_table_with_columns!(

既定の入力（$T = 100$ 年、$n = 100$ 年、$R = 2000$ 本、シード 7）では、$P(K = 0)$ の手計算は 0.3660、Poisson 近似は 0.3679 である。
模擬記録で 1 度も超えなかった割合は 0.3805 で、SE 0.0108 に対して $+1.35$ SE の差である。
$K = 1, 2, 3$ の割合 0.361、0.1865、0.0545 も、二項確率 0.370、0.185、0.061 から 2 SE 以内にある。
図の記号は $K \le 5$ では帯の中にあるが、$K = 6, 7$ の記号（3 本と 1 本）は帯の上に出る。
二項確率から見込まれる本数は 0.93 本と 0.13 本で、記録が数本しかない $K$ では正規近似の帯で外れを判定できない。
二項 95% 範囲は 0–3 年で、正規近似の −0.95–2.95 年は下端が負になる。
100 年の記録に 100 年確率の流量が 1 度も現れない記録が約 37% あるので、記録の最大値だけから 100 年確率の流量を読むことはできない。

ケース「n = 30 年」では $P(K = 0) = 0.7397$（模擬記録 0.751）で、30 年の記録の約 4 分の 3 には 100 年確率の流量が現れない。
ケース「T = 10 年」では期待値が 10 年に増えて分布がほぼ対称になり、二項 95% 範囲 5–16 年と正規近似 4.12–15.88 年が近づく。

## 観測した超過回数からの推定

このページは母数を既知として記録を模擬した。
実際の記録から再現レベルを推定するには、[再現レベルの閉形式](oxref:random-gev-return-level-closed-form)に最尤推定した $(\mu, \sigma, \xi)$ を入れ、その信頼区間とともに返す。
観測した超過年数 $K$ から年超過確率 $1/T$ の信頼区間を直接作るなら、scioxide-stats の `binomial_confidence_limits` が Clopper–Pearson の区間を返す。
$K$ が 0 や 1 の短い記録では区間が広く、記録だけから $z_T$ の大きさを絞り込むことはできない。

## まとめ

$z_T$ を超えた年数は二項分布 $\mathrm{Binomial}(N, 1/T)$ に従うので、期待値が数年以下の比較には正規近似ではなく `Binomial` の分位点と裾確率を使う。
逆変換で作った標本では $\{X > z_T\} = \{U > 1 - 1/T\}$ なので、同じシードの超過年数は $\mu, \sigma, \xi$ によらない。
記録の上側の点は少数の順序統計量で大きく揺れるので、記録の最大値は分布 $F(z)^N$ の範囲と比べて読む。
$n = T$ 年の記録にその再現期間の流量が 1 度も現れない確率は約 37% で、記録の最大値は $z_T$ の推定値にならない。
