堤防や調節池の設計では、平均して $T$ 年に 1 回だけ超える流量（$T$ 年確率の流量）を見積もる。
各年の最大流量（年最大値）を集めた記録には、一般化極値分布（GEV、generalized extreme value distribution）を当てはめることが多い。
独立同分布に従う変数の最大値を位置と尺度で正規化した列が非退化の極限分布を持つなら、その極限は GEV の族に入る（Fisher–Tippett–Gnedenko の定理）。
このページは河川の年最大流量を GEV で表し、再現レベルの閉形式を `GeneralizedExtremeValue` の分位点と裾確率で照合する。
有限年の記録に再現レベルを超える年が何回現れるかは、[有限の流量記録に現れる超過の回数](../gev-flood-records/)で調べる。

## 年最大値のモデルと形状の符号

位置 $\mu$ [m³/s]、尺度 $\sigma > 0$ [m³/s]、形状 $\xi$ [-] の GEV の分布関数は、Coles の教科書の符号で

$$
F(x) = \exp\left\{-\left[1 + \xi\,\frac{x - \mu}{\sigma}\right]^{-1/\xi}\right\},
\qquad 1 + \xi\,\frac{x - \mu}{\sigma} > 0
$$

である。
$\xi > 0$ は上限のない重い裾（Fréchet 型）、$\xi = 0$ は極限 $F(x) = \exp(-e^{-(x-\mu)/\sigma})$ の Gumbel 型、$\xi < 0$ は上限 $\mu - \sigma/\xi$ を持つ Weibull 型である。

`GeneralizedExtremeValue::new(c)` は位置 0、尺度 1 の標準形を作り、形状母数に $c = -\xi$ を使う。
標準形の分布関数は $F(z) = \exp\{-(1 - cz)^{1/c}\}$（$1 - cz > 0$）で、$c > 0$ のとき台の上端が $1/c$、$c < 0$ のとき下端が $1/c$ になる。
したがって Coles の $\xi = 0.15$ を表すには `new(-0.15)` を渡す。
`new` は非有限の $c$ を `NonFinite`、台の端 $1/c$ があふれる $c$ を `NumericalInstability` で拒み、$c = 0$ は右に歪んだ Gumbel 分布になる。

位置と尺度はコンストラクターの引数にない。
`Affine::new(law, mu, sigma)` が $\mu + \sigma Z$ の分布を作り、基になる分布が持つ分位点（`Quantile`）、逆上側確率（`InverseSurvival`）、裾確率（`Survival`）、標本化（`Distribution`）を引き継ぐ。
`Affine::new` は非有限の位置と尺度を `NonFinite`、尺度 0 を `DomainError` で拒む。
比較に使う `GumbelRight::new()` は標準の Gumbel 分布 $F(z) = \exp(-e^{-z})$ で、これも `Affine` で位置と尺度を付ける。

## 再現レベルの閉形式

年超過確率が $1/T$ になる流量を、再現期間 $T$ 年の再現レベル $z_T$ と呼ぶ。
$z_T$ は $F(z_T) = 1 - 1/T$ の解である。
$y_T = -\ln(1 - 1/T)$ と置くと $[1 + \xi(z_T - \mu)/\sigma]^{-1/\xi} = y_T$ なので

$$
z_T = \mu - \frac{\sigma}{\xi}\left[1 - y_T^{-\xi}\right],
\qquad
z_T \xrightarrow{\ \xi \to 0\ } \mu - \sigma \ln y_T
$$

となる。
$\xi \to 0$ の極限は Gumbel の分位点 $\mu - \sigma\ln(-\ln p)$（$p = 1 - 1/T$）である。

$T$ が大きいと $y_T \approx 1/T$ なので、$z_T \approx \mu + (\sigma/\xi)(T^{\xi} - 1)$ と書ける。
$\xi > 0$ では $z_T$ が $T$ のべき乗で増え、$\ln T$ を横軸にした曲線は下に凸になる。
$\xi = 0$ では $\ln T$ にほぼ比例し、$\xi < 0$ では上に凸で上限 $\mu - \sigma/\xi$ に近づく。
同じ $\mu, \sigma$ でも、100 年を超える再現レベルは $\xi$ の符号と大きさで大きく変わる。

$|\xi|$ が小さいと $1 - y_T^{-\xi}$ は 1 に近い数どうしの差になり、桁落ちする。
セルの独立検算は、$1 - y_T^{-\xi} = -\operatorname{expm1}(-\xi \ln y_T)$ を使って

$$
z_T = \mu + \sigma\,\frac{\operatorname{expm1}(-\xi \ln y_T)}{\xi}
= \mu - \sigma \ln y_T + \xi\,\sigma\,\frac{(\ln y_T)^2}{2} + O(\xi^2)
$$

で計算する。
右辺の展開から、$\xi$ が小さいときの Gumbel との差は $\xi\sigma(\ln y_T)^2/2$ で、$\xi$ に比例する。

`GeneralizedExtremeValue` の `quantile(p)` も $\ln(-\ln p)$ を通る閉形式の逆関数で、$\operatorname{expm1}$ を使って計算する。
そのため閉形式と `quantile` の照合は、符号の約束、`Affine` の変換、丸め誤差を確かめるものである。
`isf(q)` は $\ln(-\ln(1 - q))$ を $\ln(1 - q)$ の `ln_1p` から作るので、$1 - 1/T$ を作らずに $z_T$ を返す。
$1/T$ が機械イプシロンに近い極端な再現期間でも、`isf(1/T)` は丸めの影響を受けにくい。
`sf` は分布関数の側から $1 - F$ を対数の裾の式で計算するので、$T \cdot \mathrm{sf}(z_T) = 1$ は逆向きの計算との往復の照合になる。

## 再現レベルの照合

次のセルは入力の $\mu$、$\sigma$、$\xi$ から $T = 10, 50, 100, 200, 500$ 年の再現レベルを閉形式で計算し、`quantile(1 − 1/T)`、`isf(1/T)`、`sf(z_T)` と比べる。
入力の範囲は $\mu$ が 800–1600 m³/s、$\sigma$ が 200–500 m³/s、$\xi$ が −0.3–0.4 で、$\xi = 0$ では閉形式の Gumbel の式を使う。
1 つ目の表は閉形式の $z_T$、`quantile` と `isf` の閉形式との差、$T \cdot \mathrm{sf}(z_T) - 1$、同じ $\mu, \sigma$ の Gumbel の $z_T$ を出す。
2 つ目の表は入力によらず、標準形（$\mu = 0$、$\sigma = 1$）の 0.99 分位点が $\xi \to 0$ で $-\ln(-\ln 0.99)$ と `GumbelRight` の値に近づく様子を出す。

```rust
//| id: random-gev-return-level
//| ref: random-gev-return-level
//| title: GEV の再現レベルを閉形式・分位点・裾確率と照合する
//| run: reactive
//| crates: [scioxide-core, scioxide-random]
//| inputs:
//|   location: {"type":"range","label":"位置 μ [m³/s]","min":800,"max":1600,"step":50,"value":1200}
//|   scale: {"type":"range","label":"尺度 σ [m³/s]","min":200,"max":500,"step":25,"value":350}
//|   xi: {"type":"range","label":"形状 ξ [-]（Coles の符号、c = −ξ）","description":"正で上限のない重い裾、0 で Gumbel、負で上限 μ − σ/ξ を持つ。","min":-0.3,"max":0.4,"step":0.05,"value":0.15}
//| cases:
//|   - {"id":"gumbel","label":"ξ = 0（Gumbel）","description":"閉形式は μ − σ ln y_T になり、z₁₀₀ は Gumbel の列と同じ 2810.1 m³/s になる。","inputs":{"xi":0}}
//|   - {"id":"bounded","label":"ξ = −0.2（上限あり）","description":"台の上端は μ − σ/ξ = 2950 m³/s で、z₅₀₀ = 2445.0 m³/s は Gumbel の 3374.8 m³/s より低い。","inputs":{"xi":-0.2}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"levels","path":"/rows/2/1","approx":{"value":3518.7737092424854,"atol":1e-6}}
//|       - {"artifact":"levels","path":"/rows/2/2","range":{"min":-1e-9,"max":1e-9}}
//|       - {"artifact":"levels","path":"/rows/2/3","range":{"min":-1e-9,"max":1e-9}}
//|       - {"artifact":"levels","path":"/rows/4/4","range":{"min":-1e-12,"max":1e-12}}
//|       - {"artifact":"levels","path":"/rows/2/5","approx":{"value":2810.0522293718027,"atol":1e-6}}
//|       - {"artifact":"limit","path":"/rows/3/2","approx":{"value":1.0580702679341414e-05,"atol":1e-8}}
//|       - {"artifact":"limit","path":"/rows/4/2","range":{"min":-1e-12,"max":1e-12}}
//|   - case: gumbel
//|     expect:
//|       - {"artifact":"levels","path":"/rows/2/1","approx":{"value":2810.0522293718027,"atol":1e-6}}
//|   - case: bounded
//|     expect:
//|       - {"artifact":"levels","path":"/rows/4/1","approx":{"value":2444.953949564004,"atol":1e-6}}
//|       - {"artifact":"levels","path":"/rows/4/2","range":{"min":-1e-9,"max":1e-9}}
use scioxide_core::RealScalar;
use scioxide_random::{
    Affine, GeneralizedExtremeValue, GumbelRight, InverseSurvival, Quantile, Survival,
};

// scioxide-random の形状は符号 c = −ξ を使う。
let gev = GeneralizedExtremeValue::<f64>::new(-xi).map_err(|e| e.to_string())?;
let law = Affine::new(gev, location, scale).map_err(|e| e.to_string())?;
let gumbel =
    Affine::new(GumbelRight::<f64>::new(), location, scale).map_err(|e| e.to_string())?;
// 独立検算: z_T = μ − (σ/ξ)[1 − y^(−ξ)]、y = −ln(1 − 1/T)。小さい ξ の桁落ちを expm1 で避ける。
let closed_form = |t: f64| {
    let ln_y = RealScalar::ln(-RealScalar::ln_1p(-1.0 / t));
    if xi == 0.0 {
        location - scale * ln_y
    } else {
        location + scale * RealScalar::exp_m1(-xi * ln_y) / xi
    }
};
let mut rows = Vec::new();
for t in [10_u32, 50, 100, 200, 500] {
    let tf = f64::from(t);
    let z = closed_form(tf);
    let q = law.quantile(1.0 - 1.0 / tf).map_err(|e| e.to_string())?;
    let upper = law.isf(1.0 / tf).map_err(|e| e.to_string())?;
    let sf = law.sf(z).map_err(|e| e.to_string())?;
    let g = gumbel.quantile(1.0 - 1.0 / tf).map_err(|e| e.to_string())?;
    rows.push((t, z, q - z, upper - z, tf * sf - 1.0, g));
}
let flow = serde_json::json!({ "fractionDigits": 1 });
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let columns = serde_json::json!([
    { "key": "0", "label": "T [年]", "type": "integer" },
    { "key": "1", "label": "閉形式 z_T [m³/s]", "type": "number", "format": flow },
    { "key": "2", "label": "quantile − 閉形式 [m³/s]", "type": "number", "format": sci2 },
    { "key": "3", "label": "isf − 閉形式 [m³/s]", "type": "number", "format": sci2 },
    { "key": "4", "label": "T·sf(z_T) − 1 [-]", "type": "number", "format": sci2 },
    { "key": "5", "label": "Gumbel の z_T [m³/s]", "type": "number", "format": flow }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "levels" })
);
// ξ → 0 の極限: 標準形の 0.99 分位点を −ln(−ln p) と GumbelRight に比べる。
let p = 0.99_f64;
let by_hand = -RealScalar::ln(-RealScalar::ln(p));
let standard_gumbel = GumbelRight::<f64>::new()
    .quantile(p)
    .map_err(|e| e.to_string())?;
let mut limit = Vec::new();
for shape in [1e-1_f64, 1e-2, 1e-4, 1e-6, 0.0] {
    let z = GeneralizedExtremeValue::<f64>::new(-shape)
        .map_err(|e| e.to_string())?
        .quantile(p)
        .map_err(|e| e.to_string())?;
    limit.push((shape, z, z - by_hand, z - standard_gumbel));
}
let sig6 = serde_json::json!({ "significantDigits": 6 });
let columns = serde_json::json!([
    { "key": "0", "label": "ξ [-]", "type": "number", "format": sci2 },
    { "key": "1", "label": "標準形の 0.99 分位点 [-]", "type": "number", "format": sig6 },
    { "key": "2", "label": "−ln(−ln p) との差 [-]", "type": "number", "format": sci2 },
    { "key": "3", "label": "GumbelRight との差 [-]", "type": "number", "format": sci2 }
]);
emit_table_with_columns!(
    columns,
    limit,
    metadata = serde_json::json!({ "id": "limit" })
);
```

既定の入力（$\mu = 1200$ m³/s、$\sigma = 350$ m³/s、$\xi = 0.15$）では、100 年確率の流量は $z_{100} = 3518.8$ m³/s である。
同じ $\mu, \sigma$ の Gumbel 分布では 2810.1 m³/s で、$\xi = 0.15$ の重い裾が 100 年確率の流量を約 709 m³/s 押し上げる。
10、50、200、500 年の再現レベルは 2136.9、3056.2、4030.5、4792.6 m³/s である。
`quantile` と閉形式の差は $9.1 \times 10^{-13}$ m³/s 以下、`isf` と閉形式の差は 5 つの $T$ で 0、$T \cdot \mathrm{sf}(z_T) - 1$ は $1.3 \times 10^{-15}$ 以下である。
どれも倍精度の丸め誤差の大きさで、符号の約束 $c = -\xi$ と `Affine` の変換が閉形式に対応していることを示す。

2 つ目の表では、標準形の 0.99 分位点と Gumbel の値 4.6001 の差が、$\xi = 10^{-2}, 10^{-4}, 10^{-6}$ で 0.107、$1.06 \times 10^{-3}$、$1.06 \times 10^{-5}$ と $\xi$ に比例して縮む。
比例係数 10.58 は展開の係数 $(\ln y)^2/2$（$\ln y = \ln(-\ln 0.99) = -4.600$）に等しく、$\xi = 0$ では差が 0 になる。
$\xi = 0.1$ の差 1.24 は 1 次の項 1.058 より大きく、ここでは $\xi^2$ 以上の項が効いている。

ケース「ξ = 0」では、閉形式の列と Gumbel の列の差が $5 \times 10^{-13}$ m³/s 以下になる。
ケース「ξ = −0.2」では台の上端が $\mu - \sigma/\xi = 2950$ m³/s で、$z_{500} = 2445.0$ m³/s は上端の手前に留まり、Gumbel の 3374.8 m³/s より 930 m³/s 低い。

## 母数の推定と不確かさ

このページは $\mu, \sigma, \xi$ を既知として、分布の性質を確かめた。
実データから母数を推定する GEV 専用の関数は scioxide-stats にない。
scioxide-stats の汎用の当てはめでは、`LawFitModel` のコンストラクターで $(\mu, \sigma, \xi)$ から `Affine::new(GeneralizedExtremeValue::new(-xi)?, mu, sigma)` を作り、`fit` に `FitMethod::Likelihood` と最適化器（scioxide-optimize の `LbfgsBFitSolver` など）を渡して最尤推定値を得る。
推定した $\xi$ の不確かさは 100 年を超える再現レベルに大きく効くので、$z_T$ は推定値だけでなく信頼区間とともに返す。

## まとめ

`GeneralizedExtremeValue::new(c)` は符号 $c = -\xi$ を使う標準形で、位置と尺度は `Affine` で付ける。
再現レベル $z_T = \mu - (\sigma/\xi)[1 - y_T^{-\xi}]$ は `quantile(1 − 1/T)` か `isf(1/T)` で求まり、極端な再現期間では $1 - 1/T$ を作らない `isf` を使う。
小さい $\xi$ を手で計算するときは `expm1` で桁落ちを避け、Gumbel との差が $\xi\sigma(\ln y_T)^2/2$ で縮むことを検算に使える。
$\xi > 0$ では $\ln T$ に対する再現レベルが下に凸になり、既定の河川の 100 年確率の流量 3518.8 m³/s は Gumbel の 2810.1 m³/s より約 709 m³/s 高い。
形状の符号を取り違えると重い裾と上限のある裾が入れ替わるので、Coles の $\xi$ を使う資料の値は `new(-xi)` で渡す。
