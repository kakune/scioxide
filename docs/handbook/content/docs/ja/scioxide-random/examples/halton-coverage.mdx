単位正方形の上で関数を平均したり、最適化の初期点を撒いたりするとき、独立な一様点には塊と空白が生じる。
Halton 点列は座標ごとに異なる素数を底にした基数反転で、それまでの点の隙間を順に埋める決定論的な点列である。
この例題は二次元の Halton 点列の配置を、独立な一様点と象限の度数とディスクレパンシーで比べ、点列の途中から使ったときとランダム化したときの影響を確かめる。

## 基数反転と二次元の Halton 点列

素数 $b$ について、非負の整数 $n = \sum_k a_k b^k$（$0 \le a_k < b$）の基数反転は、桁の並びを小数点の右へ鏡に映した

$$
\phi_b(n) = \sum_k a_k\, b^{-(k+1)}
$$

である。
$b = 2$ では $n = 1, 2, 3, 4, 5$ が $1/2, 1/4, 3/4, 1/8, 5/8$ に写り、前の点の間の中点が順に埋まる。
最下位の桁が最も大きい位に移るので、$\phi_b(n)$ が長さ $b^{-k}$ のどの区間 $[j b^{-k}, (j+1) b^{-k})$ に入るかは $n \bmod b^k$ だけで決まる。
したがって、連続する $b^k$ 個の添字はどこから数え始めても $[0, 1)$ を長さ $b^{-k}$ の区間に一つずつ分ける。

二次元の Halton 点列は $\mathbf{x}_n = (\phi_2(n), \phi_3(n))$ で、`QmcPlan::halton(2)` が準備する。
点が $2^{-j} \times 3^{-k}$ の長方形のどれに入るかは $(n \bmod 2^j,\ n \bmod 3^k)$ で決まる。
$2^j$ と $3^k$ は互いに素なので、中国剰余定理により、連続する $2^j 3^k$ 個の添字ではこの組がすべて一度ずつ現れ、点は $2^j \times 3^k$ 個の長方形に一つずつ入る。
点列は添字 0（原点）から始まり、カーソルの `skip_to(k)` で添字 $k$ から読み始められる。
Halton 点列のカーソルの一点の計算コストは $O(d \log n)$、`skip_to` は $O(1)$ である。

ランダム化は二通りある。
`with_scramble(QmcScramble::DigitPermutation(seed))` は、底 $b$ ごとに桁の値 $1, \dots, b-1$ の置換を一つシードから作り、すべての桁の位置に同じ置換を当てる。
桁 0 は 0 のまま固定するので、基数反転は有限の和のままである。
`with_randomization(QmcRandomization::RandomShift, rng)` は、座標ごとに生成器から一様な 64 ビットのワードを一つ引いて $[0, 1)$ の値 $U_k$ に変え、点を $(x_{nk} + U_k) \bmod 1$ とずらす（Cranley–Patterson のずらし）。
偏りのない推定の反復を作るのは `RandomShift` で、桁の置換は点を変えても推定を不偏にしない。

## ディスクレパンシーの二つの量り方

点集合 $\{\mathbf{x}_1, \dots, \mathbf{x}_N\}$ のスター・ディスクレパンシーは、原点を角に持つ長方形 $[0, a) \times [0, b)$ に入る点の割合と面積 $ab$ の差の上限である。

$$
D_N^* = \sup_{a, b \in [0, 1]} \left| \frac{\#\{n : \mathbf{x}_n \in [0, a) \times [0, b)\}}{N} - ab \right|
$$

二次元の Halton 点列では $D_N^* = O((\log N)^2 / N)$ が知られており、独立な一様点の典型的な大きさ $O(N^{-1/2})$ より速く減る。
上限を正確に求める代わりに、このページでは二つの量を使う。

一つは $a, b$ を $1/G$ 刻みの格子 $\{1/G, 2/G, \dots, 1\}$ に限った最大値 $\widehat{D}_N^*$ で、上限をとる範囲を狭めたので $D_N^*$ の下界である。
格子を 2 倍ずつ細かくすると下界は小さくならず、$D_N^*$ に近づく。

もう一つは差の二乗をすべての $(a, b)$ について平均した $L_2$ スター・ディスクレパンシー $T_N$ で、`discrepancy(points, 2, DiscrepancyMethod::L2Star)` が返す。
展開して積分すると閉形式（Warnock の式）

$$
T_N^2 = \frac{1}{9} - \frac{2}{N}\sum_{n} \prod_{k=1}^{2} \frac{1 - x_{nk}^2}{2} + \frac{1}{N^2}\sum_{n}\sum_{m} \prod_{k=1}^{2} \bigl(1 - \max(x_{nk}, x_{mk})\bigr)
$$

になり、計算量は $O(N^2)$ である。
`discrepancy` は二つの和の各項を丸めの誤差を持たない累積器で足し、和ごとに一回だけ丸める。

独立な一様点では、各 $(a, b)$ で長方形に入る点の数が二項分布 $\mathrm{Binomial}(N, ab)$ に従うので、差の二乗の期待値は $ab(1 - ab)/N$ である。
これを $[0, 1]^2$ で積分すると $\mathrm{E}[T_N^2] = (2^{-2} - 3^{-2})/N = 5/(36N)$ になり、$\sqrt{5/(36N)}$ を独立点の目安に使う。

## 象限の度数

象限の度数も見る。
独立点では各象限の度数が $\mathrm{Binomial}(N, 1/4)$ に従うので、標準偏差は $\sqrt{N \cdot \tfrac14 \cdot \tfrac34} = \sqrt{3N/16}$ である。
Halton 点列では、第一座標の最下位の桁が 0 と 1 を交互にとるので、連続する 2 点は必ず左右に分かれる。
第二座標は連続する 3 点ごとに $[0, 1)$ の三等分の区間へ一つずつ入る。
上下の境界 $x_2 = 1/2$ は真ん中の区間 $[1/3, 2/3)$ を二つに分けるので完全にはそろわないが、象限の度数は $N/4$ からほとんどずれない。

## 点の配置と象限の度数

次のセルは点の作り方、点数 $N$、捨てる先頭の点数、乱数のシードを入力に $N$ 個の点を作り、散布図に $x_1 = 0.5$、$x_2 = 0.5$ の線を引いて描く。
表は象限ごとの度数を、独立点の期待値 $N/4$ と標準偏差 $\sqrt{3N/16}$ で標準化した差と並べる。
作った点は次のセルに渡す。

```rust
//| id: random-halton-points
//| ref: random-halton-points
//| title: Halton 点列と独立な一様点の配置と象限の度数を比べる
//| run: reactive
//| crates: [scioxide-core, scioxide-random]
//| exports: [flat_points, point_set_name]
//| inputs:
//|   point_set: {"type":"select","label":"点の作り方","options":["Halton","DigitPermutation でランダム化した Halton","RandomShift でランダム化した Halton","独立な一様乱数"],"value":"Halton"}
//|   point_count: {"type":"range","label":"点数 N [点]","min":64,"max":1024,"step":64,"value":256}
//|   starting_index: {"type":"range","label":"捨てる先頭の点数 [点]","description":"Halton 系の点列だけに効く。","min":0,"max":2048,"step":64,"value":0}
//|   seed: {"type":"range","label":"乱数のシード（ランダム化と独立点）","min":1,"max":1000,"step":1,"value":5}
//| cases:
//|   - {"id":"independent","label":"独立な一様乱数","description":"象限の度数が N/4 から標準偏差 √(3N/16) の程度ずれる。","inputs":{"point_set":"独立な一様乱数"}}
//|   - {"id":"skip","label":"先頭の 2048 点を捨てる","description":"途中から使っても象限の度数はそろったまま。","inputs":{"starting_index":2048}}
//|   - {"id":"random-shift","label":"RandomShift（シード 5）","description":"一様なずらしでランダム化しても象限の度数はほとんどずれない。","inputs":{"point_set":"RandomShift でランダム化した Halton"}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"quadrants","path":"/rows/0/1","equals":64}
//|       - {"artifact":"quadrants","path":"/rows/3/1","equals":62}
//|   - case: independent
//|     expect:
//|       - {"artifact":"quadrants","path":"/rows/0/3","range":{"min":-4,"max":4}}
//|       - {"artifact":"quadrants","path":"/rows/1/3","range":{"min":-4,"max":4}}
//|   - case: skip
//|     expect:
//|       - {"artifact":"quadrants","path":"/rows/0/3","range":{"min":-1,"max":1}}
//|   - case: random-shift
//|     expect:
//|       - {"artifact":"quadrants","path":"/rows/0/3","range":{"min":-1,"max":1}}
use scioxide_core::RealScalar;
use scioxide_random::{
    QmcPlan, QmcRandomization, QmcScramble, QuasiRng, Rng, SeedableRng, SplitMix64,
};

let fixed2 = serde_json::json!({ "fractionDigits": 2 });
let (n, skip, seed) = (
    point_count.round() as usize,
    starting_index.round() as u64,
    seed.round() as u64,
);
// 点は行ごとに (x₁, x₂) を並べた平らな配列にする（discrepancy の入力の形）。
let flat: Vec<f64> = match point_set.as_str() {
    "独立な一様乱数" => {
        let mut rng = SplitMix64::from_seed(seed);
        (0..2 * n)
            .map(|_| rng.next_float())
            .collect::<Result<_, _>>()
            .map_err(|e| e.to_string())?
    }
    name => {
        let mut plan = QmcPlan::halton(2).map_err(|e| e.to_string())?;
        if name.starts_with("DigitPermutation") {
            plan = plan
                .with_scramble(QmcScramble::DigitPermutation(seed))
                .map_err(|e| e.to_string())?;
        } else if name.starts_with("RandomShift") {
            plan = plan
                .with_randomization(
                    QmcRandomization::RandomShift,
                    &mut SplitMix64::from_seed(seed),
                )
                .map_err(|e| e.to_string())?;
        }
        let mut cursor = plan.sequence::<f64>().map_err(|e| e.to_string())?;
        cursor.skip_to(skip).map_err(|e| e.to_string())?;
        cursor.points(n).map_err(|e| e.to_string())?
    }
};
let points: Vec<[f64; 2]> = flat.chunks_exact(2).map(|p| [p[0], p[1]]).collect();
emit_scatter_chart!(
    &points,
    options = &serde_json::json!({
        "xLabel": "第一座標 x₁（底 2）[-]",
        "yLabel": "第二座標 x₂（底 3）[-]",
        "xMin": 0.0,
        "xMax": 1.0,
        "yMin": 0.0,
        "yMax": 1.0,
        "annotations": [
            {"kind": "line", "axis": "x", "value": 0.5},
            {"kind": "line", "axis": "y", "value": 0.5}
        ]
    })
);
// 独立な一様点なら各象限の度数は Binomial(N, 1/4) で、標準偏差は √(3N/16)。
let mut quadrants = [0_usize; 4];
for p in &points {
    quadrants[usize::from(p[0] >= 0.5) + 2 * usize::from(p[1] >= 0.5)] += 1;
}
let nf = n as f64;
let sd = RealScalar::sqrt(3.0 * nf / 16.0);
let names = ["左下", "右下", "左上", "右上"];
let rows: Vec<_> = names
    .iter()
    .zip(quadrants)
    .map(|(&name, q)| (name, q, nf / 4.0, (q as f64 - nf / 4.0) / sd))
    .collect();
let columns = serde_json::json!([
    { "key": "0", "label": "象限" },
    { "key": "1", "label": "度数 [点]", "type": "integer" },
    { "key": "2", "label": "N/4 [点]", "type": "number", "format": fixed2 },
    { "key": "3", "label": "(度数 − N/4) / √(3N/16) [-]", "type": "number", "format": fixed2 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "quadrants" })
);
export!(flat_points, &flat);
export!(point_set_name, &point_set);
```

Halton 点列の散布図では、点は塊を作らずに正方形全体に広がり、四つの象限にほぼ同じ数ずつ入る。
既定の入力（Halton、$N = 256$、先頭から）では、象限の度数は 64、66、64、62 で、$N/4 = 64$ からのずれは最大 2 点だった。
独立な一様乱数（シード 5）では、度数は 77、67、53、59 で、ずれは最大 13 点（標準偏差 $\sqrt{3N/16} \approx 6.9$ 点の約 1.9 倍）になる。
独立点では象限の度数がこの程度ずれても二項分布の揺らぎの範囲で、Halton 点列のずれはそれよりはるかに小さい。

## ディスクレパンシーの測定

次のセルは前のセルの点集合を受け取り、先頭 $m$ 点の $\widehat{D}_m^*$ と $T_m$ の推移を、独立点の目安 $\sqrt{5/(36m)}$（破線）と両対数で比べる。
入力は格子の分割数 $G$ で、点の作り方と点数は前のセルで変える。
$\widehat{D}_m^*$ は 16 点ごとに、$G \times G$ のセルの度数の累積和から求める。
計算量が $m^2$ に比例する $T_m$ は、$m = 16 \cdot 2^j$ と $24 \cdot 2^j$ の点だけで求める。
表は $N$ 点での $\widehat{D}_N^*$ と、`discrepancy` の $T_N$、セルの中で Warnock の式の和を素朴に足して計算し直した $T_N$ を並べる。

```rust
//| id: random-halton-discrepancy-curves
//| ref: random-halton-discrepancy-curves
//| title: 点集合のディスクレパンシーを格子の数え上げと Warnock の式で測る
//| run: reactive
//| crates: [scioxide-core, scioxide-random]
//| dependsOn:
//|   design: random-halton-points
//| inputs:
//|   grid_cells: {"type":"select","label":"格子の分割数 G（a, b ∈ {1/G, …, 1}）","options":["8","16","32","64","128"],"value":"16"}
//| cases:
//|   - {"id":"fine-grid","label":"G = 128","description":"格子を細かくすると下界が大きくなり、スター・ディスクレパンシーに近づく。","inputs":{"grid_cells":"128"}}
//|   - {"id":"grid-64","label":"G = 64","description":"格子は入れ子なので、細かくするほど下界は小さくならない。","inputs":{"grid_cells":"64"}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"discrepancy","path":"/rows/0/0","approx":{"value":0.0117,"atol":5e-4}}
//|       - {"artifact":"discrepancy","path":"/rows/0/1","approx":{"value":0.0053,"atol":5e-4}}
//|       - {"artifact":"discrepancy","path":"/rows/0/3","range":{"min":0,"max":1e-10}}
//|       - {"artifact":"discrepancy","path":"/rows/0/4","approx":{"value":0.0233,"atol":1e-4}}
//|   - case: fine-grid
//|     expect:
//|       - {"artifact":"discrepancy","path":"/rows/0/0","range":{"min":0.0117,"max":0.05}}
//|       - {"artifact":"discrepancy","path":"/rows/0/3","range":{"min":0,"max":1e-10}}
//|   - case: grid-64
//|     expect:
//|       - {"artifact":"discrepancy","path":"/rows/0/0","approx":{"value":0.013671875,"atol":1e-9}}
use scioxide_core::RealScalar;
use scioxide_random::{DiscrepancyMethod, discrepancy};

let sig3 = serde_json::json!({ "significantDigits": 3 });
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let fixed1 = serde_json::json!({ "fractionDigits": 1 });
// 点集合は前のセルから受け取る（行ごとに x₁, x₂ を並べた平らな配列）。
let flat: Vec<f64> = design["flat_points"]
    .as_array()
    .ok_or("点がない")?
    .iter()
    .map(|v| v.as_f64().ok_or("座標が数でない"))
    .collect::<Result<_, _>>()?;
let name = design["point_set_name"]
    .as_str()
    .ok_or("点の作り方がない")?;
let n = flat.len() / 2;
let g: usize = grid_cells.parse().map_err(|_| "G を数として読めない")?;
// 箱 [0, k/G) × [0, l/G) に入る点の数を、G × G のセルの度数の累積和で数える。
// G は 2 の冪なので、floor(x G) < k と x < k/G は丸めなしで同値になる。
let mut cells = vec![0_usize; g * g];
let grid_bound = |cells: &[usize], m: usize| {
    let mut below = vec![0_usize; g];
    let mut worst = 0.0_f64;
    for k in 1..=g {
        let mut run = 0;
        for l in 0..g {
            run += cells[(k - 1) * g + l];
            below[l] += run;
            let volume = (k * (l + 1)) as f64 / (g * g) as f64;
            worst = worst.max((below[l] as f64 / m as f64 - volume).abs());
        }
    }
    worst
};
let (mut grid_curve, mut l2_curve, mut reference) = (Vec::new(), Vec::new(), Vec::new());
for m in 1..=n {
    let (x, y) = (flat[2 * m - 2], flat[2 * m - 1]);
    cells[(x * g as f64) as usize * g + (y * g as f64) as usize] += 1;
    if m % 16 != 0 {
        continue;
    }
    grid_curve.push([m as f64, grid_bound(&cells, m)]);
    // T_m は O(m²) の計算なので、m = 16·2ʲ と 24·2ʲ の点だけで求める。
    if (m / 16).is_power_of_two() || (m % 24 == 0 && (m / 24).is_power_of_two()) {
        let l2 = discrepancy(&flat[..2 * m], 2, DiscrepancyMethod::L2Star)
            .map_err(|e| e.to_string())?;
        l2_curve.push([m as f64, l2]);
        reference.push([m as f64, RealScalar::sqrt(5.0 / (36.0 * m as f64))]);
    }
}
// 独立な検算: Warnock の式で T_N² を素朴な和から計算し直す。
let mut cross = 0.0;
for p in flat.chunks_exact(2) {
    for q in flat.chunks_exact(2) {
        cross += (1.0 - p[0].max(q[0])) * (1.0 - p[1].max(q[1]));
    }
}
let single: f64 = flat
    .chunks_exact(2)
    .map(|p| 0.25 * (1.0 - p[0] * p[0]) * (1.0 - p[1] * p[1]))
    .sum();
let nf = n as f64;
let warnock = RealScalar::sqrt(1.0 / 9.0 - 2.0 * single / nf + cross / (nf * nf));
let l2_star = discrepancy(&flat, 2, DiscrepancyMethod::L2Star).map_err(|e| e.to_string())?;
emit_line_chart!(
    &vec![
        serde_json::json!({
            "name": format!("格子で近似した D*（{name}）"),
            "points": grid_curve,
            "style": {"symbol": "circle"}
        }),
        serde_json::json!({
            "name": format!("L2 スター・ディスクレパンシー T（{name}）"),
            "points": l2_curve,
            "style": {"symbol": "triangle"}
        }),
        serde_json::json!({
            "name": "独立点の目安 √(5/(36m))",
            "points": reference,
            "style": {"lineType": "dashed"}
        }),
    ],
    options = &serde_json::json!({
        "xLabel": "先頭から使う点数 m [点]",
        "yLabel": "ディスクレパンシー [-]",
        "xType": "log",
        "yType": "log"
    })
);
let expected = RealScalar::sqrt(5.0 / (36.0 * nf));
let columns = serde_json::json!([
    { "key": "0", "label": "格子で近似した D* [-]", "type": "number", "format": sig3 },
    { "key": "1", "label": "T_N（discrepancy）[-]", "type": "number", "format": sig3 },
    { "key": "2", "label": "T_N（Warnock の式）[-]", "type": "number", "format": sig3 },
    { "key": "3", "label": "二つの T_N の差 [-]", "type": "number", "format": sci3 },
    { "key": "4", "label": "目安 √(5/(36N)) [-]", "type": "number", "format": sig3 },
    { "key": "5", "label": "目安 / T_N [-]", "type": "number", "format": fixed1 }
]);
emit_table_with_columns!(
    columns,
    vec![(
        grid_bound(&cells, n),
        l2_star,
        warnock,
        (l2_star - warnock).abs(),
        expected,
        expected / l2_star,
    )],
    metadata = serde_json::json!({ "id": "discrepancy" })
);
```

ディスクレパンシーのグラフでは、Halton 点列の二つの記号は破線より下にあり、$m$ とともに破線より急な傾きで下がる。
独立な一様乱数に切り替えると、$T_m$ の記号は破線のまわりに散らばる。
Halton 点列の記号が破線の上に出たり、傾きが $-1/2$ に近かったりすれば、点列の生成か使い方（座標の取り違え、同じ点の繰り返し）を疑う。
$\widehat{D}_m^*$ の曲線は単調には減らず、新しい点が一部の長方形に偏った後で別の点が空白を埋めるために上下する。

既定の入力（Halton、$N = 256$、$G = 16$）では、$\widehat{D}_N^* = 0.0117$、$T_N = 0.0053$ で、$T_N$ は独立点の目安 $0.0233$ の約 4.4 分の 1 である。
$G = 64$ にすると下界は $0.0137$、$G = 128$ では $0.0152$ に上がる（$G = 8$ では $G = 16$ と同じ $0.0117$）。
格子 $1/G$ は $G$ を 2 倍するごとに前の格子を含むので、下界は $G$ とともに小さくならない。
独立な一様乱数（シード 5）では $\widehat{D}_N^* = 0.0703$、$T_N = 0.0267$ で、$T_N$ は目安 $0.0233$ と同じ程度である。
$N = 1024$ の Halton 点列では $T_N = 1.65 \times 10^{-3}$ で、目安 $0.0116$ との比は約 7 に広がる。

`discrepancy` の $T_N$ と Warnock の式で計算し直した値の差は $7.6 \times 10^{-13}$ だった。
Warnock の式は $1/9 \approx 0.11$ 程度の三つの項の差として $T_N^2 \approx 2.8 \times 10^{-5}$ を求める。
$T_N^2$ の誤差 $\delta$ は、平方根をとると $T_N$ の誤差 $\delta/(2T_N)$ になり、$T_N \approx 0.0053$ では約 94 倍に拡大する。
観測した差 $7.6 \times 10^{-13}$ は $T_N^2$ の誤差 $\delta \approx 8 \times 10^{-15}$ に相当する。
これは、セルの中で $N^2 = 65{,}536$ 個の交差項を素朴に足したときの丸めの誤差と同じ程度の大きさである。

## 開始位置とランダム化

先頭の 2,048 点を捨てても、$N = 256$ の $T_N$ は $0.0036$ で、Halton 点列の均一さは保たれる。
連続する $2^j 3^k$ 個の点が長方形を一つずつ埋める性質は、どの添字から数え始めても成り立つからである。

桁の置換は各桁の値を一度ずつ使う性質を保つので、長方形を一つずつ埋める性質も保つ。
ただし二次元では置換の選び方が少ない。
底 2 で 0 を固定した $\{0, 1\}$ の置換は恒等置換だけで、底 3 でも 1 と 2 の入れ替えの有無の 2 通りしかないので、ランダム化した点列は 2 通りにしかならない。
シード 5 は恒等置換を引き、点列はランダム化しない Halton 点列と同じになる（$T_N = 0.0053$）。
シード 7 は底 3 の 1 と 2 を入れ替え、$T_N = 0.0058$ になる。

一様なずらし（`RandomShift`）では、シード 5 で $T_N = 0.0036$、シード 7 で $0.0039$ で、どちらも目安の 6 分の 1 程度にとどまる。
ずらしの量は生成器が出す一様乱数ワードから作られ、$2^{-53}$ 刻みの値をとる。
生成器の出力を独立な一様乱数と見なせば、ずらした各点は（$2^{-53}$ 刻みの離散化を除いて）一様に分布するので、低い次元で独立な反復を作るにはこちらを使う。
ランダム化は異なるシードの点列を独立な反復として使い、誤差を統計的に推定するためのものである（[QmcReplicatePlan による標準誤差の推定](../qmc-replicate-standard-error/)）。

次元が高くなると、大きな素数を底にした二つの座標では、点数の少ないうちは点が平行な直線の上に並ぶ強い相関が現れる。
桁の置換はこの相関を弱めるが、推定を不偏にはしない。
一つの `QmcPlan` に当てられるランダム化は一つで、`with_scramble`、`with_randomization`、`with_permutations` は前のランダム化を置き換えるので、桁の置換と `RandomShift` は重ねられない。
Halton 点列は低い次元で使い、高い次元では Sobol 点列を使う。

## まとめ

`QmcPlan::halton(2)` の点列は独立な一様点より小さいディスクレパンシーで正方形を埋め、象限の度数もそろう。
格子で近似したスター・ディスクレパンシーは真の値の下界で、格子を 2 倍ずつ細かくしても小さくならない。
`DiscrepancyMethod::L2Star` は差の二乗平均の平方根で、Warnock の式で独立に計算し直せ、どちらも独立点の目安 $\sqrt{5/(36N)}$ と比べて読む。
`skip_to` で点列の途中から使っても均一さは保たれ、二次元の `DigitPermutation` は 2 通りの点列しか作らないので、独立な反復には `RandomShift` を使う。
ディスクレパンシーの曲線は単調ではないので、一つの点数の値ではなく、点数に対する傾向で判断する。
