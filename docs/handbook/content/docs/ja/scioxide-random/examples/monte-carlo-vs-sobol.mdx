単位超立方体 $[0, 1)^d$ の上の積分 $I = \int f(\mathbf{x})\,d\mathbf{x}$ を点の平均 $\hat{I}_N = \frac{1}{N}\sum_{n=1}^{N} f(\mathbf{x}_n)$ で近似するとき、点を独立な一様乱数で選ぶのが Monte Carlo 法（MC）、低食い違い点列で選ぶのが準 Monte Carlo 法（QMC）である。
この例題は解析解のある被積分関数で両者の誤差を比べ、ランダム化した QMC の誤差を独立な反復から測る。
点列の構成とランダム化の理論は [Sobol 点列と Gray 符号](oxref:random-qmc-sobol-gray)と[ランダム化と反復による誤差の推定](oxref:random-qmc-replicate-error)にある。
解析解を知らない積分に標準誤差を付ける方法は、[QmcReplicatePlan による標準誤差の推定](../qmc-replicate-standard-error/)で扱う。

## 吸収層の平均透過率

光が $d$ 枚の吸収層を順に通る場面を考える。
層 $j$ の光学的厚さ $x_j$ [-] が $[0, 1)$ の一様分布に従って独立にばらつくとき、透過率は $f(\mathbf{x}) = \exp(-\sum_j x_j)$ で、平均の透過率は

$$
I = \int_{[0, 1)^d} \exp\Bigl(-\sum_{j=1}^d x_j\Bigr)\,d\mathbf{x} = \prod_{j=1}^d \int_0^1 e^{-x_j}\,dx_j = (1 - e^{-1})^d
$$

である。
被積分関数が座標ごとの積に分かれるので、積分も一次元の積分の積になる。
$d = 4$ では $I = 0.15966$ である。

MC の推定量は不偏で、分散は $\sigma_f^2 / N$ である。
ここで $\sigma_f^2 = \mathrm{E}[f^2] - I^2$ は一点の分散で、$\mathrm{E}[f^2] = \prod_j \int_0^1 e^{-2x}\,dx = \bigl(\tfrac{1 - e^{-2}}{2}\bigr)^d$ なので、

$$
\sigma_f^2 = \Bigl(\frac{1 - e^{-2}}{2}\Bigr)^d - (1 - e^{-1})^{2d}
$$

になる。
MC の二乗平均平方根誤差（RMSE）は $\sigma_f/\sqrt{N}$ で、$N^{-1/2}$ で減る。

次の定義のブロックは透過率 $f$、解析解 $I$、一点の標準偏差 $\sigma_f$ を、このページの二つのセルで共有する。
$\sigma_f$ は MC の誤差の理論値に使う独立な基準である。

```rust
//| id: random-transmittance-model
//| kind: definitions
//| title: 吸収層の透過率と解析解
//| crates: [scioxide-core]
use scioxide_core::RealScalar;

/// 透過率 f(x) = exp(−Σⱼ xⱼ)。
pub(crate) fn transmittance(x: &[f64]) -> f64 {
    RealScalar::exp(-x.iter().sum::<f64>())
}

/// 解析解 I = (1 − e⁻¹)ᵈ。
pub(crate) fn exact_mean(d: usize) -> f64 {
    RealScalar::powi(1.0 - RealScalar::exp(-1.0_f64), d as i32)
}

/// 一点の標準偏差 σ_f = √(((1 − e⁻²)/2)ᵈ − I²)。MC の RMSE は σ_f/√N。
pub(crate) fn mc_sigma(d: usize) -> f64 {
    let second = RealScalar::powi(0.5 * (1.0 - RealScalar::exp(-2.0_f64)), d as i32);
    let mean = exact_mean(d);
    RealScalar::sqrt(second - mean * mean)
}
```

## QMC の誤差とランダム化

$f$ は滑らかで、Hardy–Krause の意味の変動 $V_{\mathrm{HK}}(f)$ は有限である。
QMC の誤差は Koksma–Hlawka の不等式で $V_{\mathrm{HK}}(f)\,D_N^*$ 以下に抑えられ、Sobol 点列ではスター・ディスクレパンシーが $D_N^* = O((\log N)^d / N)$ なので、$d$ が小さく $N$ が大きければ MC より速く減る。
ただしこの不等式は上界で、$V_{\mathrm{HK}}$ も $D_N^*$ も実際には計算しにくいので、誤差の大きさの推定には使えない。
そこで点列をランダム化し、独立なランダム化の反復のばらつきから誤差を測る。

Sobol 点列のランダム化は二通りある。
`QmcPlan::with_scramble(QmcScramble::DigitalShift(seed))` は、各座標の 64 ビットのワードを、シードと座標の番号から作ったワードとの排他的論理和でずらす（デジタルなずらし）。
点列の網の構造は保たれ、シードが一様に分布すれば、各座標は $2^{-53}$ 刻みの格子の上で一様に分布する。
ただし全座標のずらしが一つのシードから決まるので、座標どうしのずらしの独立は保証されず、推定量の不偏性はこのランダム化だけからは言えない。

`QmcPlan::with_randomization(QmcRandomization::LinearMatrixShift, rng)` は、座標ごとに生成器から 65 ワードを引き、対角が 1 の下三角の 64 × 64 の二進行列（GF(2) の上の正則行列）を掛けてからデジタルなずらしを加える（Matoušek の線形の scramble）。
生成器の出力を独立な一様乱数と見なせば、ランダム化した各点は $[0, 1)^d$ で一様に分布し、推定量は $2^{-53}$ 刻みの格子による離散化を除いて不偏になる。
独立な系列から引けば、独立な反復になる。
桁を混ぜるランダム化では、滑らかな被積分関数の分散がデジタルなずらしより速く減ることがある（Owen 1997 は入れ子の一様な scramble で分散 $O(N^{-3}(\log N)^{d-1})$ を示した）。

どちらのランダム化も先頭の $2^k$ 点からなるブロックの均等さ（網の性質）を保つ。
そのため点数 $N$ は 2 の冪で比べる。

## 一列の点での誤差の曲線

次のセルは同じシードから独立な一様乱数（`SplitMix64` の `next_float`）と `DigitalShift` でランダム化した Sobol 点列を作り、$N = 16, 32, \dots, 2^m$ での絶対誤差 $|\hat{I}_N - I|$ を両対数で描く。
入力は次元 $d$、点数の上限 $2^m$ を決める指数 $m$、乱数のシードである。
破線は MC の RMSE の理論値 $\sigma_f/\sqrt{N}$ で、MC の誤差の典型的な大きさを示す。
誤差がちょうど 0 になった点は対数軸に描けないので除き、表にはすべての $N$ を出す。

```rust

//| ref: random-monte-carlo-vs-sobol
//| title: Monte Carlo とランダム化した Sobol の積分誤差の曲線を比べる
//| run: reactive
//| uses: [random-transmittance-model]
//| crates: [scioxide-core, scioxide-random]
//| inputs:
//|   integration_dimension: {"type":"range","label":"積分の次元 d","min":2,"max":8,"step":1,"value":4}
//|   maximum_sample_exponent: {"type":"range","label":"最大の点数の指数 m（N = 2ᵐ）","min":7,"max":14,"step":1,"value":12}
//|   integration_seed: {"type":"range","label":"乱数のシード","min":1,"max":1000,"step":1,"value":41}
//| cases:
//|   - {"id":"eight-dimensions","label":"d = 8","description":"次元を上げると Sobol の誤差の減り方が遅くなる。","inputs":{"integration_dimension":8}}

//|       - {"artifact":"errors","path":"/rows/8/1","range":{"min":1e-6,"max":1e-2}}

//|     expect:
//|       - {"artifact":"errors","path":"/rows/8/1","range":{"min":1e-5,"max":6e-3}}
//|       - {"artifact":"errors","path":"/rows/8/2","range":{"min":1e-8,"max":1e-4}}

let d = integration_dimension.round() as usize;
let n_max = 1_usize << maximum_sample_exponent.round() as u32;
let seed = integration_seed.round() as u64;
let (exact, sigma) = (exact_mean(d), mc_sigma(d));
let mut pseudo = SplitMix64::from_seed(seed);
let plan = QmcPlan::sobol(d)
    .map_err(|e| e.to_string())?
    .with_scramble(QmcScramble::DigitalShift(seed))
    .map_err(|e| e.to_string())?;
let mut sobol = plan.sequence::<f64>().map_err(|e| e.to_string())?;
let (mut pseudo_point, mut point) = (vec![0.0_f64; d], vec![0.0_f64; d]);

    for value in pseudo_point.iter_mut() {
        *value = pseudo.next_float().map_err(|e| e.to_string())?;

    mc_sum += transmittance(&pseudo_point);
    // DigitalShift でランダム化した Sobol 点列の点。
    sobol
        .next_point_into(&mut point)
        .map_err(|e| e.to_string())?;
    qmc_sum += transmittance(&point);
    if n >= 16 && n.is_power_of_two() {
        let mc_error = (mc_sum / n as f64 - exact).abs();
        let qmc_error = (qmc_sum / n as f64 - exact).abs();

        // 誤差がちょうど 0 の点は対数軸に描けないので除く。
        if mc_error > 0.0 {
            mc_curve.push([n as f64, mc_error]);
        }
        if qmc_error > 0.0 {
            qmc_curve.push([n as f64, qmc_error]);
        }
        reference.push([n as f64, scale]);

    { "key": "0", "label": "N [点]", "type": "integer" },
    { "key": "1", "label": "MC の誤差 [-]", "type": "number", "format": sci3 },
    { "key": "2", "label": "Sobol の誤差 [-]", "type": "number", "format": sci3 },
    { "key": "3", "label": "σ_f/√N [-]", "type": "number", "format": sci3 }

    columns,
    rows,
    metadata = serde_json::json!({ "id": "errors" })
);
```

MC の記号は破線のまわりを上下しながら傾き $-1/2$ で下がり、Sobol の記号はそれより急に下がる。
MC の記号が破線から一桁以上離れ続けるなら、乱数の質か被積分関数の実装を疑う。

既定の入力（$d = 4$、$N = 2^{12}$、シード 41）では、$N = 4096$ での誤差は MC が $5.88 \times 10^{-4}$（$\sigma_f/\sqrt{N} = 1.52 \times 10^{-3}$）、Sobol が $3.99 \times 10^{-6}$ だった。
$d = 8$ にすると、$N = 4096$ での誤差は MC が $4.70 \times 10^{-4}$（$\sigma_f/\sqrt{N} = 3.73 \times 10^{-4}$）、Sobol が $1.70 \times 10^{-5}$ になる。
Sobol の記号は $N = 512$ 以降ほとんど下がらず、次元が上がると同じ点数での利点が小さくなる。
一列の点の誤差はランダム化の一つの実現値なので、曲線は偶然に深く落ち込むこともあり、二つの方法の比はこの曲線だけでは決められない。

## 独立なランダム化の反復による RMSE と収束の次数

$R$ 回の独立な反復の誤差 $e_r = \hat{I}_N^{(r)} - I$ から、RMSE を $\sqrt{\frac{1}{R}\sum_r e_r^2}$ で推定する。
解析解 $I$ を使うので、推定量に偏りがあっても、この量は偏りを含めた RMSE を測る。
誤差が平均 0 の正規分布に従うとき、$\sum_r e_r^2 / \mathrm{RMSE}^2$ は自由度 $R$ のカイ二乗分布に従い、その相対的な標準偏差は $\sqrt{2/R}$ である。
平方根をとると相対誤差はおよそ半分になるので、推定した RMSE の相対標準誤差は約 $1/\sqrt{2R}$ である。

次のセルはシード $s$ のルート生成器 `Pcg64` から `split` で反復ごとに系列を選び、$d = 4$ で $N = 32, 64, \dots, 2^m$ の RMSE を測る。
反復 $r$ は系列 $2r$ を独立な一様乱数に、系列 $2r + 1$ を Sobol 点列のランダム化に使うので、反復どうしも二つの方法どうしも同じ乱数を共有しない。
各反復は一列の点の先頭 $N$ 点の平均を順に記録するので、同じ反復の中の異なる $N$ の誤差は互いに相関する。
入力のランダム化は `LinearMatrixShift`（系列から座標ごとに 65 ワードを生成する）か `DigitalShift`（系列の1 ワードをシードにする）を選ぶ。

一つ目のグラフは両対数で、測った RMSE（記号）と MC の理論値 $\sigma_f/\sqrt{N}$（破線）を比べる。
二つ目のグラフは MC の RMSE と理論値の比を、推定の $\pm 2$ SE のエラーバーとともに描き、1 の線と比べる。
この二つのグラフと前のセルのグラフは、同じ点数 $N$ を横軸に持つので、拡大と移動が連動する。
表は各 $N$ の RMSE と、MC の RMSE の標準誤差（相対 $1/\sqrt{2R}$）、二つの RMSE の比を出す。
二つ目の表は $\log \mathrm{RMSE}$ を $\log N$ に最小二乗で当てはめた傾き（収束の次数の推定値）である。

```rust
//| id: random-rqmc-replications
//| ref: random-rqmc-replications
//| title: 独立なランダム化を反復して RMSE と収束の次数を比べる
//| run: reactive
//| uses: [random-transmittance-model]
//| crates: [scioxide-core, scioxide-random]
//| inputs:
//|   randomization: {"type":"select","label":"Sobol のランダム化","options":["LinearMatrixShift（座標ごとに 65 ワード）","DigitalShift（1 ワードのシード）"],"value":"LinearMatrixShift（座標ごとに 65 ワード）"}
//|   points_per_replication_exponent: {"type":"range","label":"最大の点数の指数 m（N = 2ᵐ）","min":7,"max":12,"step":1,"value":10}
//|   randomization_count: {"type":"range","label":"反復の回数 R","description":"RMSE の推定の相対標準誤差は 1/√(2R)。","min":8,"max":48,"step":4,"value":24}
//|   base_seed: {"type":"range","label":"ルート生成器のシード s","min":1,"max":1000,"step":1,"value":100}
//| cases:
//|   - {"id":"digital-shift","label":"DigitalShift","description":"デジタルなずらしだけでは Sobol の RMSE の傾きが緩くなる。","inputs":{"randomization":"DigitalShift（1 ワードのシード）"}}
//|   - {"id":"more-points","label":"N = 2¹²","description":"点数を増やすと RMSE の比が広がる。","inputs":{"points_per_replication_exponent":12}}
//|   - {"id":"other-seed","label":"派生元のシード 1","description":"別の反復の組でも MC の RMSE は理論値の近くにある。","inputs":{"base_seed":1}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"rmse","path":"/rows/5/0","equals":1024}
//|       - {"artifact":"rmse","path":"/rows/5/3","approx":{"value":3.0368e-3,"atol":1e-6}}
//|       - {"artifact":"rmse","path":"/rows/5/1","range":{"min":1.5e-3,"max":4.5e-3}}
//|       - {"artifact":"slopes","path":"/rows/0/0","range":{"min":-0.8,"max":-0.2}}
//|   - case: digital-shift
//|     expect:
//|       - {"artifact":"slopes","path":"/rows/0/0","range":{"min":-0.8,"max":-0.2}}
//|   - case: more-points
//|     expect:
//|       - {"artifact":"slopes","path":"/rows/0/0","range":{"min":-0.7,"max":-0.3}}
//|   - case: other-seed
//|     expect:
//|       - {"artifact":"rmse","path":"/rows/5/1","range":{"min":1.5e-3,"max":4.5e-3}}
use scioxide_core::RealScalar;
use scioxide_random::{
    BitGenerator, Pcg64, QmcPlan, QmcRandomization, QmcScramble, QuasiRng, Rng, SeedableRng,
    SplittableRng,
};

let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let fixed1 = serde_json::json!({ "fractionDigits": 1 });
let fixed2 = serde_json::json!({ "fractionDigits": 2 });
let d = 4_usize;
let m = points_per_replication_exponent.round() as u32;
let (n_max, r) = (1_usize << m, randomization_count.round() as usize);
let (exact, sigma) = (exact_mean(d), mc_sigma(d));
let matrix_scramble = randomization.starts_with("LinearMatrixShift");
// squares[k] は N = 2^(k+5) の二乗誤差の和（MC、Sobol）。
let levels = (m - 4) as usize;
let mut squares = vec![[0.0_f64; 2]; levels];
let (mut pseudo_point, mut point) = (vec![0.0_f64; d], vec![0.0_f64; d]);
let root = Pcg64::from_seed(base_seed.round() as u64);
for replication in 0..r as u64 {
    // 反復 r は根の系列 2r を MC に、2r + 1 を Sobol のランダム化に使う。
    let mut pseudo = root.split(2 * replication).map_err(|e| e.to_string())?;
    let mut stream = root.split(2 * replication + 1).map_err(|e| e.to_string())?;
    let base = QmcPlan::sobol(d).map_err(|e| e.to_string())?;
    let plan = if matrix_scramble {
        base.with_randomization(QmcRandomization::LinearMatrixShift, &mut stream)
    } else {
        let seed = stream.next_u64().map_err(|e| e.to_string())?;
        base.with_scramble(QmcScramble::DigitalShift(seed))
    }
    .map_err(|e| e.to_string())?;
    let mut sobol = plan.sequence::<f64>().map_err(|e| e.to_string())?;
    let (mut mc_sum, mut qmc_sum) = (0.0_f64, 0.0_f64);
    for n in 1..=n_max {
        for value in pseudo_point.iter_mut() {
            *value = pseudo.next_float().map_err(|e| e.to_string())?;
        }
        mc_sum += transmittance(&pseudo_point);
        sobol
            .next_point_into(&mut point)
            .map_err(|e| e.to_string())?;
        qmc_sum += transmittance(&point);
        if n >= 32 && n.is_power_of_two() {
            let k = n.trailing_zeros() as usize - 5;
            let (e_mc, e_qmc) = (mc_sum / n as f64 - exact, qmc_sum / n as f64 - exact);
            squares[k][0] += e_mc * e_mc;
            squares[k][1] += e_qmc * e_qmc;
        }
    }
}
// 推定した RMSE の相対標準誤差 1/√(2R)（誤差が平均 0 の正規分布のとき）。
let relative_se = 1.0 / RealScalar::sqrt(2.0 * r as f64);
let (mut mc_curve, mut qmc_curve, mut theory_curve) = (Vec::new(), Vec::new(), Vec::new());
let (mut ratio_bars, mut rows) = (Vec::new(), Vec::new());
for (k, square) in squares.iter().enumerate() {
    let n = 1_usize << (k + 5);
    let theory = sigma / RealScalar::sqrt(n as f64);
    let mc = RealScalar::sqrt(square[0] / r as f64);
    let qmc = RealScalar::sqrt(square[1] / r as f64);
    mc_curve.push([n as f64, mc]);
    qmc_curve.push([n as f64, qmc]);
    theory_curve.push([n as f64, theory]);
    let ratio = mc / theory;
    ratio_bars.push([
        n as f64,
        ratio,
        ratio * (1.0 - 2.0 * relative_se),
        ratio * (1.0 + 2.0 * relative_se),
    ]);
    rows.push((n, mc, mc * relative_se, theory, qmc, mc / qmc));
}
// 収束の次数: log RMSE を log N に最小二乗で当てはめた傾き。
let slope = |curve: &[[f64; 2]]| {
    let logs: Vec<[f64; 2]> = curve
        .iter()
        .map(|p| [RealScalar::ln(p[0]), RealScalar::ln(p[1])])
        .collect();
    let count = logs.len() as f64;
    let mean_x = logs.iter().map(|p| p[0]).sum::<f64>() / count;
    let mean_y = logs.iter().map(|p| p[1]).sum::<f64>() / count;
    let sxy: f64 = logs.iter().map(|p| (p[0] - mean_x) * (p[1] - mean_y)).sum();
    let sxx: f64 = logs.iter().map(|p| (p[0] - mean_x) * (p[0] - mean_x)).sum();
    sxy / sxx
};
```

MC の記号は破線に沿って傾き $-1/2$ で並び、比のエラーバーはおおむね 1 の線にかかる。
比が 1 からエラーバーを大きく超えて外れ続ければ、MC の標本化か理論値の計算に誤りがある。
ランダム化した Sobol の記号は MC よりはるかに下で、より急な傾きで下がる。

既定の入力（`LinearMatrixShift`、$N = 32$ から $1024$、$R = 24$、$s = 100$）では、$N = 1024$ での MC の RMSE は $2.34 \times 10^{-3}$（理論値 $3.04 \times 10^{-3}$）、ランダム化した Sobol は $1.77 \times 10^{-5}$ で、比は $132$ だった。
MC の RMSE と理論値の比は $0.77$ で、推定した RMSE の相対標準誤差 $1/\sqrt{48} \approx 0.14$ の約 1.6 倍だけ 1 から下にずれている。
同じ反復の中の点数どうしは相関するので、隣り合う $N$ の比は同じ向きにずれやすい。
当てはめた傾きは MC が $-0.50$、Sobol が $-1.23$ である。

ランダム化を `DigitalShift` に切り替えると、MC の値は変わらず、Sobol の傾きは $-1.02$ に緩み、$N = 1024$ での比は $28.5$ に下がる。
桁を混ぜる `LinearMatrixShift` はこの滑らかな被積分関数で、デジタルなずらしだけより速く誤差を減らす。
$N = 2^{12}$ まで広げると、`LinearMatrixShift` の傾きは MC が $-0.50$、Sobol が $-1.34$ になり、$N = 4096$ での比は $422$ に広がる。
派生元のシードを 1 にすると、傾きは MC が $-0.52$、Sobol が $-1.38$ になる。
少ない点数から当てはめた傾きはシードや点数の範囲によって $\pm 0.2$ 程度動くので、一つの値を収束の次数と断定しない。
推定した RMSE は相対標準誤差 $1/\sqrt{2R} \approx 0.14$ を持つので、比も $\pm 30\%$ 程度の幅で読む。

## まとめ

滑らかな被積分関数では、ランダム化した Sobol 点列の RMSE は独立な一様乱数より速く減る。
一列の点の誤差の曲線は一つの実現値なので、誤差の大きさは独立なランダム化の反復から推定し、推定した RMSE の相対標準誤差 $1/\sqrt{2R}$ を幅として解釈する。
`DigitalShift` は各座標を一様にするが座標どうしの独立を保証しないので、独立な反復には生成器から引く `LinearMatrixShift` を使う。
収束の次数は少ない点数から当てはめるとシードによって動くので、点数の範囲を広げて確かめる。
