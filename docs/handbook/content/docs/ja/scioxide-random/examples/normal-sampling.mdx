生成した正規標本の平均が母平均と一致しないことや、経験分位点が理論曲線からずれることは、それだけでは標本化器の誤りを意味しない。
有限個の標本から求めた統計量は、標準誤差で決まる幅で揺らぐからである。
この例題は旋盤で削る軸の直径を題材に、`Normal` の標本の統計量を閉形式の理論値と標準誤差で照合し、どの大きさのずれを誤りの兆候と読むかを確かめる。
特異な共分散を持つ `MultivariateNormal` の標本は、[特異な共分散を持つ多変量正規標本の台](../singular-normal-support/)で扱う。

## 題材と標本化の方法

軸の直径 $X$ [mm] が平均 $\mu$、標準偏差 $\sigma$ の正規分布 $\mathcal{N}(\mu, \sigma^2)$ に従う工程を考え、規格を $[L, U] = [12, 24]$ mm とする。
既定の工程は $\mu = 18$ mm、$\sigma = 3$ mm で、規格の両端がちょうど $\mu \pm 2\sigma$ にあたる。

`Normal::new(mean, std_dev)` は平均と標準偏差をこの順に受け取り、標準偏差が 0 以下なら `DomainError`、どちらかが NaN か無限大なら `NonFinite` を返す。
標本は 256 層の [Ziggurat 法](oxref:random-continuous-ziggurat)で標準正規変量 $z$ を作り、$\mu + \sigma z$ を一回の融合積和で丸めて返す。
`Distribution::sample_n(rng, n)` は $n$ 個の標本を所有の `Vec` で返す。
分布関数 `Cdf::cdf` と上側確率 `Survival::sf` は、標準化した $z = (x - \mu)/\sigma$ の側の裾の確率を、尺度付き相補誤差関数 $\operatorname{erfcx}(t) = e^{t^2}\operatorname{erfc}(t)$ を使って $\tfrac12 \operatorname{erfcx}(|z|/\sqrt{2})\,e^{-z^2/2}$ として直接求める。
そのため上側確率は $1 - F(x)$ の引き算を経ず、裾でも相対精度を保つ。

## 正規標本の統計量の分布

$X_1, \dots, X_N$ が独立に $\mathcal{N}(\mu, \sigma^2)$ に従うとき、標本平均 $\bar{X}$ と不偏分散 $s^2 = \frac{1}{N-1}\sum_i (X_i - \bar{X})^2$ は独立で、

$$
\bar{X} \sim \mathcal{N}\!\left(\mu, \frac{\sigma^2}{N}\right), \qquad \frac{(N-1)s^2}{\sigma^2} \sim \chi^2_{N-1}
$$

に従う。
標本平均の標準誤差は $\sigma/\sqrt{N}$ で、一桁小さくするには標本を 100 倍にする。
自由度 $k$ のカイ二乗分布の分散は $2k$ なので、$\mathrm{Var}(s^2) = \sigma^4 \cdot 2(N-1)/(N-1)^2 = 2\sigma^4/(N-1)$ となり、不偏分散の標準誤差は $\sigma^2\sqrt{2/(N-1)}$ である。

規格の外に出る確率を $q = F(L) + S(U)$ とする。
ここで $F$ は分布関数、$S(x) = 1 - F(x)$ は上側確率である。
規格の外に出た標本の数は二項分布 $\mathrm{Binomial}(N, q)$ に従うので、その割合の標準誤差は $\sqrt{q(1-q)/N}$ である。

確率 $p$ の理論分位点は $x_p = \mu + \sigma\Phi^{-1}(p)$ で、`Quantile::quantile` が計算する。
ここで $\Phi$ は標準正規分布関数である。
経験分位点 $\hat{x}_p$ は、$N$ が大きいとき近似的に平均 $x_p$、標準誤差

$$
\mathrm{SE}(\hat{x}_p) \approx \frac{1}{f(x_p)}\sqrt{\frac{p(1-p)}{N}}
$$

の正規分布に従う（$f$ は密度）。
$x_p$ 以下に入る標本の割合の標準誤差は $\sqrt{p(1-p)/N}$ で、この式はその揺らぎを分布関数の傾き $f(x_p)$ で横軸の幅に換算したものである。
密度の小さい両端では、同じ確率の揺らぎが大きな寸法の揺らぎになる。

以下の照合では統計量と理論値の差を標準誤差で割った $z = (\text{測定値} - \text{理論値})/\mathrm{SE}$ を読む。
標本化器が正しければ $z$ は近似的に標準正規分布に従い、$|z| > 2$ となる確率は約 4.6% である。

## 被検の Normal を通らない基準

規格外の確率と度数の期待値に使う $\Phi$ は、`Normal` の `cdf` とは別に、scioxide-special の相補誤差関数 `erfc` から

$$
\Phi(x) = \tfrac12 \operatorname{erfc}\!\left(-\frac{x}{\sqrt{2}}\right)
$$

として求める。
`Normal::cdf` は前の節の erfcx の式で計算するので、二つの値を比べれば、別の経路で求めた値どうしが整合しているかを確かめられる。
次の定義のブロックはこの基準の $\Phi$ と、表の一行を作る補助関数を二つのセルで共有する。

```rust
//| id: random-normal-reference-model
//| kind: definitions
//| title: erfc による基準の Φ と標準化した差
//| crates: [scioxide-core, scioxide-special]
use scioxide_core::{SciOxideError, RealScalar};

/// 基準の標準正規分布関数 Φ(x) = erfc(−x/√2)/2。被検の `Normal` を通さない。
pub(crate) fn reference_phi(x: f64) -> Result<f64, SciOxideError> {
    Ok(0.5 * scioxide_special::erfc(-x / RealScalar::sqrt(2.0_f64))?)
}

/// 表の一行（量、測定値、理論値、標準誤差、z = (測定値 − 理論値) / 標準誤差）。
pub(crate) fn z_row(
    name: &'static str,
    value: f64,
    theory: f64,
    se: f64,
) -> (&'static str, f64, f64, f64, f64) {
    (name, value, theory, se, (value - theory) / se)
}
```

## 工程の寸法の経験分位点

次のセルは工程平均 $\mu$ [mm]、工程標準偏差 $\sigma$ [mm]、標本数 $N$、乱数のシードを入力に、`Normal::new(μ, σ)` から `sample_n` で $N$ 個の標本を作る。
グラフは $p = k/64$（$k = 1, \dots, 63$）の経験分位点（記号）、理論分位点（破線）、理論分位点 $\pm 2\,\mathrm{SE}(\hat{x}_p)$ の帯を重ねる。
経験分位点には昇順に並べた標本の $\operatorname{round}(p(N-1))$ 番目（0 から数える）を使う。
破線と帯は被検の `Normal` の `quantile` と `pdf` から作るので、このグラフは標本化と分位点・密度の計算が互いに整合するかを見るもので、独立な検算ではない。

一つ目の表は平均、不偏分散、規格外の割合を、閉形式の理論値と標準誤差で比べる。
規格外の確率 $q$ の理論値は上の基準の $\Phi$ から $q = \Phi((L - \mu)/\sigma) + \Phi((\mu - U)/\sigma)$ として求める。
二つ目の表は帯の外に出た経験分位点の個数と、`cdf(12) + sf(24)` で求めた $q$ と基準の $q$ の差を出す。

```rust
//|       - {"artifact":"moments","path":"/rows/2/2","approx":{"value":0.160005,"atol":1e-5}}
//|       - {"artifact":"moments","path":"/rows/2/4","range":{"min":-4,"max":4}}

//|       - {"artifact":"moments","path":"/rows/0/4","range":{"min":-4,"max":4}}
//|       - {"artifact":"quantile-checks","path":"/rows/0/0","range":{"min":0,"max":20}}

let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });

let mut rng = SplitMix64::from_seed(seed.round() as u64);
let mut samples = law.sample_n(&mut rng, n).map_err(|e| e.to_string())?;

    .iter()
    .filter(|x| !(lower..=upper).contains(*x))
    .count() as f64

    .map_err(|e| e.to_string())?
    + reference_phi((process_mean_mm - upper) / process_std_mm).map_err(|e| e.to_string())?;

    z_row(
        "平均 [mm]",

    rows,
```

経験分位点の記号は破線に沿って並び、帯は密度の小さい両端で広がる。
誤りがあれば、記号が帯から系統的に外れる。
たとえば標準偏差を取り違えると傾きが変わり、平均を取り違えると全体が上下にずれ、裾の生成を誤ると両端だけが曲がる。

既定の入力（$\mu = 18$ mm、$\sigma = 3$ mm、$N = 4096$、シード 901）では、標本平均 $18.0385$ mm の $z$ は $0.82$、不偏分散 $8.7177$ mm² の $z$ は $-1.42$ だった。
規格外の割合は $0.0449$ で、理論値 $2(1 - \Phi(2)) = 0.04550$ に対して $z = -0.18$ である。
`cdf(12) + sf(24)` で求めた $q$ と基準の $q$ の差は $1.4 \times 10^{-17}$ だった。
63 個の経験分位点のうち、帯の外に出たのは 0 個だった。

帯の外に出る個数は独立な 63 回の試行のようには数えられない。
隣り合う経験分位点は同じ標本の順序統計量なので、互いに強く相関するからである。
一点ずつの外れる確率は約 4.6% だが、外れるときは隣の分位点もまとめて外れやすい。

$\mu = 21$ mm にすると、規格外の理論割合は $\Phi(-3) + (1 - \Phi(1)) = 0.1600$ に増え、標本の割合は $0.1626$（$z = 0.45$）になる。
$N = 256$ にすると平均の標準誤差は $3/\sqrt{256} = 0.1875$ mm に広がり、標本平均 $17.8484$ mm の $z$ は $-0.81$、帯の外の分位点は 0 個だった。

## 標本平均の反復と被覆率

一つの標本集合の結果だけでは偶然の一致を除けない。
そこで大きさ $n$ の群を $R$ 回独立に作り、標準化した標本平均 $Z_r = (\bar{X}_r - \mu)/(\sigma/\sqrt{n})$ の分布を調べる。
$Z_r$ は $\mathcal{N}(0, 1)$ に従うので、$R$ 個の $Z_r$ の平均の標準誤差は $1/\sqrt{R}$、不偏分散の標準誤差は前の節と同じ式で $\sqrt{2/(R-1)}$ である。
$|Z_r| \le 1.96$ となる割合を被覆率と呼ぶ。
その期待値は 0.95 で、$R$ 回から求めた被覆率は二項分布に従うので、標準誤差は $\sqrt{0.95 \times 0.05 / R}$ である。
区間 $[a, b)$ に入る群の数の期待値は $R\,(\Phi(b) - \Phi(a))$ で、標準誤差は二項分布の $\sqrt{R\,p(1-p)}$（$p = \Phi(b) - \Phi(a)$）になる。

次のセルは一群の標本数 $n$、群の数 $R$、乱数のシードを入力に、$[-4, 4]$ を 24 区間に分けた度数を、期待度数（破線）と期待度数 $\pm 2$ SE の帯に重ねる。
各群は `Normal::<f64>::standard()` から `sample_n` で作り、和を $\sqrt{n}$ で割って $Z_r$ にする。
期待度数の $\Phi$ は前の節の基準の $\Phi$ を使う。
表は $Z_r$ の平均、不偏分散、被覆率、$[-4, 4]$ の外の群の数を、理論値と標準誤差で比べる。

```rust
let (n, r) = (
    subgroup_size.round() as usize,
    replication_count.round() as usize,
);
let rf = r as f64;
let mut rng = SplitMix64::from_seed(seed.round() as u64);
let standard = Normal::<f64>::standard();
let mut z = Vec::with_capacity(r);
for _ in 0..r {
    // 一群 n 個の標準正規標本の和を √n で割ると、標準化した標本平均になる。
    let group = standard.sample_n(&mut rng, n).map_err(|e| e.to_string())?;
    z.push(group.iter().sum::<f64>() / RealScalar::sqrt(n as f64));
}
// [-4, 4] を 24 区間に分けた度数と、期待度数 ± 2 SE（基準の Φ による）。
let (bins, lower, width) = (24_usize, -4.0_f64, 8.0 / 24.0);
let mut counts = vec![0_usize; bins];
for &value in &z {
    let index = ((value - lower) / width).floor();
    if (0.0..bins as f64).contains(&index) {
        counts[index as usize] += 1;
    }
}
let (mut observed, mut expected, mut band) = (Vec::new(), Vec::new(), Vec::new());
for (i, &count) in counts.iter().enumerate() {
    let (a, b) = (lower + i as f64 * width, lower + (i + 1) as f64 * width);
    let p = reference_phi(b).map_err(|e| e.to_string())?
        - reference_phi(a).map_err(|e| e.to_string())?;
    let (centre, se) = (0.5 * (a + b), RealScalar::sqrt(rf * p * (1.0 - p)));
    observed.push([centre, count as f64]);
    expected.push([centre, rf * p]);
    band.push([centre, rf * p, rf * p - 2.0 * se, rf * p + 2.0 * se]);
}
emit_chart!(
    serde_json::json!({
        "kind": "xy",
        "xLabel": "標準化した標本平均 z [-]",
        "yLabel": "幅 1/3 の区間に入った群の数 [群]",
        "xMin": -4.0,
        "xMax": 4.0,
        "dataZoom": true,
        "tooltip": true,
        "annotations": [
            {"kind": "range", "axis": "x", "from": -1.96, "to": 1.96, "label": "±1.96"}
        ],
        "layers": [
            {"id": "band", "kind": "band", "name": "期待度数 ± 2 SE", "points": band},
            {
                "id": "expected",
                "kind": "line",
                "name": "期待度数 R (Φ(b) − Φ(a))",
                "style": {"lineType": "dashed"},
                "points": expected
            },
            {"id": "observed", "kind": "scatter", "name": "観測した度数", "points": observed}
        ]
    }),
    metadata = serde_json::json!({ "id": "histogram" })
);
let mean = z.iter().sum::<f64>() / rf;
let variance = z.iter().map(|v| (v - mean) * (v - mean)).sum::<f64>() / (rf - 1.0);
let coverage = z
    .iter()
    .filter(|v| v.abs() <= 1.959_963_984_540_054)
    .count() as f64
    / rf;
let tail = 2.0 * reference_phi(-4.0).map_err(|e| e.to_string())?;
let beyond = (r - counts.iter().sum::<usize>()) as f64;
let rows = vec![
    z_row("z の平均 [-]", mean, 0.0, 1.0 / RealScalar::sqrt(rf)),
    z_row(
        "z の不偏分散 [-]",
        variance,
        1.0,
        RealScalar::sqrt(2.0 / (rf - 1.0)),
    ),
    z_row(
        "被覆率 P(|z| ≤ 1.96) [-]",
        coverage,
        0.95,
        RealScalar::sqrt(0.95 * 0.05 / rf),
    ),
    z_row(
        "[-4, 4] の外の群 [群]",
        beyond,
        rf * tail,
        RealScalar::sqrt(rf * tail * (1.0 - tail)),
    ),
];
let columns = serde_json::json!([
    { "key": "0", "label": "量" },
    { "key": "1", "label": "測定値", "type": "number", "format": sig4 },
    { "key": "2", "label": "理論値", "type": "number", "format": sig4 },
    { "key": "3", "label": "標準誤差", "type": "number", "format": sci3 },
    { "key": "4", "label": "z = 差 / 標準誤差 [-]", "type": "number", "format": fixed2 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "replications" })

```

観測した度数の記号は、$n$ によらず破線の正規曲線に沿い、ほとんどが帯の中に入る。
帯は一区間ずつの $\pm 2$ SE なので、24 区間のうち 1 個前後が帯の外に出ても普通である。
標本化器の裾が誤っていれば両端の区間で、分散が誤っていれば中央と肩の区間で、記号が同じ向きに帯から外れる。

既定の入力（$n = 32$、$R = 512$、シード 12）では、$z$ の平均は $0.0752$（標準誤差 $0.0442$、$z = 1.70$）、分散は $1.0090$（標準誤差 $0.0626$、$z = 0.14$）、被覆率は $0.9395$（標準誤差 $0.0096$、$z = -1.09$）だった。
$[-4, 4]$ の外の群は 0 で、期待値は $512 \times 6.3 \times 10^{-5} = 0.032$ 群である。
$R = 2048$ にすると被覆率の標準誤差は $0.0048$ に半減し、被覆率は $0.9521$（$z = 0.45$）になる。

シード 364 では分散が $0.8072$ で、$z = -3.08$ になる。
正規近似で $|z| \ge 3.08$ となる両側の確率は約 0.21% で、シードをいくつも試せば 500 種類に 1 回程度は現れる大きさである。
このような値が一つのシードで出ても、別のシードや大きい $R$ で再現しなければ、標本化器の誤りとは判断しない。

この照合の結果は、標本平均の標準誤差が $\sigma/\sqrt{n}$ であることとも、群どうしの平均が独立な正規分布として振る舞うこととも矛盾しない。
ただし、これらの統計量では検出できない種類の依存（高次の相関など）まで否定するものではない。

## まとめ

正規標本の平均、不偏分散、規格外の割合は、閉形式の理論値との差を標準誤差 $\sigma/\sqrt{N}$、$\sigma^2\sqrt{2/(N-1)}$、$\sqrt{q(1-q)/N}$ で割った $z$ として解釈する。
経験分位点は $\pm 2\,\mathrm{SE}(\hat{x}_p)$ の帯と比べ、帯から系統的に外れる形（傾き、平行移動、両端だけの曲がり）で誤りの種類を見分ける。
帯の外に出た分位点の個数は、隣どうしが相関するので独立な試行の数としては読まない。
標本平均の反復は平方根則と 95% の被覆率を、群の数 $R$ で決まる標準誤差の範囲で再現する。
$|z| \approx 3$ の値は 500 種類に 1 回程度は現れるので、別のシードや大きい $R$ で再現するかを確かめてから判断する。
