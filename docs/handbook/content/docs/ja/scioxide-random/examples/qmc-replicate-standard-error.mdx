ランダム化した準 Monte Carlo 法（RQMC）の誤差は、解析解を知らなければ直接は測れない。
独立にランダム化した点列で同じ積分を $R$ 回推定すれば、推定値のばらつきから標準誤差を求め、信頼区間を付けられる。
この例題は[モンテカルロ法と Sobol 準モンテカルロ積分の比較](../monte-carlo-vs-sobol/)と同じ吸収層の平均透過率 $I = (1 - e^{-1})^4 = 0.15966$ を使い、`QmcReplicatePlan` が返す標準誤差を解析解と照合する。

## 反復による推定と標準誤差

$R$ 個の独立なランダム化 $r = 1, \dots, R$ のそれぞれで、点列の先頭 $N$ 点の平均 $I_r = \frac1N \sum_{n=1}^{N} f(\mathbf{x}_n^{(r)})$ を求める。
反復平均の平均 $\bar{I}$ と、その標準誤差は

$$
\bar{I} = \frac{1}{R}\sum_{r=1}^{R} I_r, \qquad
\mathrm{SE} = \sqrt{\frac{1}{R(R-1)}\sum_{r=1}^{R} (I_r - \bar{I})^2}
$$

である。
$\mathrm{SE}$ は反復平均 $I_r$ の不偏分散を $R$ で割った値の平方根で、$\bar{I}$ の標準偏差の推定値である。

ランダム化が各点を $[0, 1)^d$ で一様に分布させるなら、$I_r$ は $I$ の不偏な推定値になり、$\mathrm{E}[\mathrm{SE}^2] = \mathrm{Var}(\bar{I})$ が成り立つ。
さらに $I_r$ が独立に正規分布に従うなら、$t = (\bar{I} - I)/\mathrm{SE}$ は自由度 $R - 1$ の $t$ 分布に従い、

$$
\bar{I} \pm t_{R-1,\,0.975}\,\mathrm{SE}
$$

は $I$ を確率 95% で含む区間になる。
$I_r$ は正規分布に厳密には従わないので、この区間の被覆率は近似である。
$R$ が小さいと $\mathrm{SE}$ 自体が大きく揺れ、$t_{R-1,\,0.975}$ も大きくなる（$R = 4$ で $3.18$、$R = 16$ で $2.13$）。

## QmcReplicatePlan の準備と推定

`QmcReplicatePlan::new(&base, &root, options)` は、基の点列 `base` のランダム化を $R$ 回独立に作って保持する。
`QmcReplicateOptions` で反復の数 $R$（既定 8、2 以上）と反復一回の点数 $N$（既定 1,024）を指定し、Sobol 点列と Niederreiter 点列では $N$ は 2 の冪でなければならない。
$R < 2$、$N = 0$、2 の冪でない $N$、逆 Halton 点列の `base` は `InvalidInput` になる。

ランダム化は、Sobol 点列と Niederreiter 点列では `LinearMatrixShift`（Matoušek の線形の scramble とデジタルなずらし）、Halton 点列では `RandomShift`（Cranley–Patterson の一様なずらし）で、`base` に付いていたランダム化は置き換えられる。
反復 $r$ のランダム化は `Philox4x64` の根から、ドメインタグと反復の番号のバイト列で分けた系列から引く。
そのため反復 $r$ のランダム化は反復の総数や作る順序によらず同じで、`root` は進まない。
準備は $R$ 個の点列の複製と $O(Rd)$ ワードのランダム化を保持し、複数の関数の推定に使い回せる。

`estimate(f)` は呼び出したスレッドで $R \cdot N$ 回 `f` を評価し、各反復の平均 `replicate_means`、その平均 `mean`、標準誤差 `standard_error`、点数 `points_per_replicate` を返す。
`f` が返すエラーはそのまま返り、NaN か無限大を返すと `NonFinite` になる。
エラーのときは、終わった反復があっても推定値を返さない。
反復をエグゼキューターで並べたいときや、外側の求解の評価回数に数えたいときは、実行の範囲を渡す `estimate_scoped(f, scope)` を使う。
どちらでも推定値は実行の順序によらない。

次の定義のブロックは透過率と解析解を、このページの二つのセルで共有する。

```rust
//| id: random-replicate-transmittance-model
//| kind: definitions
//| title: 吸収層の透過率と解析解（反復の例題）
//| crates: [scioxide-core]
use scioxide_core::{SciOxideError, RealScalar};

/// 透過率 f(x) = exp(−Σⱼ xⱼ)。QmcReplicatePlan::estimate に渡す形。
pub(crate) fn transmittance(x: &[f64]) -> Result<f64, SciOxideError> {
    Ok(RealScalar::exp(-x.iter().sum::<f64>()))
}

/// 解析解 I = (1 − e⁻¹)ᵈ。
pub(crate) fn exact_mean(d: usize) -> f64 {
    RealScalar::powi(1.0 - RealScalar::exp(-1.0_f64), d as i32)
}
```

## 推定値と標準誤差の照合

次のセルは基の点列、反復一回の点数の指数 $m$（$N = 2^m$）、反復の数 $R$、Philox の鍵のシードを入力に、$d = 4$ の透過率の平均を推定する。
返された反復平均から上の定義で標準誤差を計算し直してレポート値と比べ、推定値と解析解の差を標準誤差の単位で表す。
`StudentT::quantile` で求めた $t_{R-1}$ の 97.5% 点から 95% 信頼区間を作り、解析解を含むかを示す。

```rust
//| id: random-prepared-replicate-error
//| ref: random-prepared-replicate-error
//| title: QmcReplicatePlan の平均と標準誤差を解析解と照合する
//| run: reactive
//| uses: [random-replicate-transmittance-model]
//| crates: [scioxide-random, scioxide-core]
//| inputs:
//|   base_family: {"type":"select","label":"基の点列","options":["Sobol","Halton"],"value":"Sobol"}
//|   points_exponent: {"type":"range","label":"反復一回の点数の指数 m（N = 2ᵐ）","min":5,"max":12,"step":1,"value":9}
//|   replicates: {"type":"range","label":"反復の数 R","min":4,"max":32,"step":4,"value":16}
//|   key_seed: {"type":"range","label":"Philox の鍵のシード","min":1,"max":1000,"step":1,"value":42}
//| cases:
//|   - {"id":"few-replicates","label":"R = 4","description":"t₃ の 97.5% 点は 3.18 で、区間が広がる。","inputs":{"replicates":4}}
//|   - {"id":"more-points","label":"N = 2¹²","description":"点数を 8 倍にすると標準誤差が 10 分の 1 以下になる。","inputs":{"points_exponent":12}}
//|   - {"id":"halton","label":"Halton","description":"一様なずらしでランダム化した Halton 点列では、同じ N で標準誤差が大きい。","inputs":{"base_family":"Halton"}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"estimate","path":"/rows/0/0","equals":16}
//|       - {"artifact":"estimate","path":"/rows/0/3","approx":{"value":0.1596613,"atol":1e-7}}
//|       - {"artifact":"estimate","path":"/rows/0/4","range":{"min":5e-6,"max":1e-4}}
//|       - {"artifact":"estimate","path":"/rows/0/5","range":{"min":0,"max":1e-15}}
//|       - {"artifact":"interval","path":"/rows/0/0","range":{"min":-4,"max":4}}
//|       - {"artifact":"interval","path":"/rows/0/1","approx":{"value":2.1314,"atol":1e-3}}
//|   - case: few-replicates
//|     expect:
//|       - {"artifact":"interval","path":"/rows/0/0","range":{"min":-8,"max":8}}
//|       - {"artifact":"interval","path":"/rows/0/1","approx":{"value":3.1824,"atol":1e-3}}
//|   - case: more-points
//|     expect:
//|       - {"artifact":"estimate","path":"/rows/0/4","range":{"min":2e-7,"max":1e-5}}
//|       - {"artifact":"interval","path":"/rows/0/0","range":{"min":-4,"max":4}}
//|   - case: halton
//|     expect:
//|       - {"artifact":"estimate","path":"/rows/0/4","range":{"min":1e-5,"max":1e-3}}
//|       - {"artifact":"interval","path":"/rows/0/0","range":{"min":-4,"max":4}}
use scioxide_core::RealScalar;
use scioxide_random::{
    Philox4x64, QmcPlan, QmcReplicateOptions, QmcReplicatePlan, Quantile, SeedableRng, StudentT,
};

let sig6 = serde_json::json!({ "significantDigits": 6 });
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let fixed2 = serde_json::json!({ "fractionDigits": 2 });
let fixed3 = serde_json::json!({ "fractionDigits": 3 });
let (points, r, d) = (
    1_usize << points_exponent.round() as u32,
    replicates.round() as usize,
    4_usize,
);
let exact = exact_mean(d);
let root = Philox4x64::from_seed(key_seed.round() as u64);
let base = if base_family == "Halton" {
    QmcPlan::halton(d)
} else {
    QmcPlan::sobol(d)
}
.map_err(|e| e.to_string())?;
let options = QmcReplicateOptions::default()
    .with_replicates(r)
    .with_points_per_replicate(points);
let plan = QmcReplicatePlan::new(&base, &root, options).map_err(|e| e.to_string())?;
let estimate = plan
    .estimate(|x: &[f64]| transmittance(x))
    .map_err(|e| e.to_string())?;
// 反復平均から標準誤差の定義を計算し直す（独立な検算）。
let means = &estimate.replicate_means;
let rf = means.len() as f64;
let average = means.iter().sum::<f64>() / rf;
let spread: f64 = means.iter().map(|m| (m - average) * (m - average)).sum();
let recomputed = RealScalar::sqrt(spread / (rf * (rf - 1.0)));
let se = estimate.standard_error;
let t_law = StudentT::new(rf - 1.0).map_err(|e| e.to_string())?;
let t_quantile = t_law.quantile(0.975).map_err(|e| e.to_string())?;
let (lower, upper) = (
    estimate.mean - t_quantile * se,
    estimate.mean + t_quantile * se,
);
let estimate_columns = serde_json::json!([
    { "key": "0", "label": "反復の数 R", "type": "integer" },
    { "key": "1", "label": "点数 N [点]", "type": "integer" },
    { "key": "2", "label": "mean [-]", "type": "number", "format": sig6 },
    { "key": "3", "label": "解析解 I [-]", "type": "number", "format": sig6 },
    { "key": "4", "label": "standard_error [-]", "type": "number", "format": sci3 },
    { "key": "5", "label": "計算し直した SE との差 [-]", "type": "number", "format": sci3 }
]);
emit_table_with_columns!(
    estimate_columns,
    vec![(
        means.len(),
        estimate.points_per_replicate,
        estimate.mean,
        exact,
        se,
        (recomputed - se).abs(),
    )],
    metadata = serde_json::json!({ "id": "estimate" })
);
let interval_columns = serde_json::json!([
    { "key": "0", "label": "t = (mean − I) / SE [-]", "type": "number", "format": fixed2 },
    { "key": "1", "label": "t_{R−1} の 97.5% 点 [-]", "type": "number", "format": fixed3 },
    { "key": "2", "label": "95% 区間の下限 [-]", "type": "number", "format": sig6 },
    { "key": "3", "label": "95% 区間の上限 [-]", "type": "number", "format": sig6 },
    { "key": "4", "label": "I を含むか" }
]);
let contains = if (lower..=upper).contains(&exact) {
    "含む"
} else {
    "含まない"
};
emit_table_with_columns!(
    interval_columns,
    vec![(
        (estimate.mean - exact) / se,
        t_quantile,
        lower,
        upper,
        contains
    )],
    metadata = serde_json::json!({ "id": "interval" })
);
```

示された標準誤差は反復平均から計算し直した値と丸めの範囲で一致する。
既定の入力（Sobol、$N = 512$、$R = 16$、鍵のシード 42）では、標準誤差は $2.02 \times 10^{-5}$ で、計算し直した値との差は 0 だった。
推定値と解析解の差は標準誤差の $-1.38$ 倍で、$t_{15}$ の 97.5% 点 $2.13$ より小さく、95% 区間 $[0.159590, 0.159676]$ は解析解を含む。
$N = 4096$ にすると標準誤差は $1.16 \times 10^{-6}$ と 17 分の 1 になり、$t = 0.83$ だった。
点数を 8 倍にして標準誤差が $\sqrt{8} \approx 2.8$ 分の 1 よりはるかに小さくなるのは、ランダム化した Sobol 点列の誤差が MC の $N^{-1/2}$ より速く減るからである。

$R = 4$ では $t_3$ の 97.5% 点が $3.18$ に広がり、標準誤差そのものも自由度 3 の推定なので大きく揺れる（この鍵では $t = 0.73$）。
基の点列を Halton にすると、一様なずらしでランダム化した同じ $N = 512$ 点の標準誤差は $1.33 \times 10^{-4}$ で、Sobol の約 7 倍になる。
Halton 点列は 2 の冪でない $N$ も受け付ける。

## 多数の鍵での被覆率

一回の推定で $|t|$ が小さくても、標準誤差が正しく較正されているとは言えない。
次のセルは Philox の鍵のシードを $k_0 + 1, \dots, k_0 + K$ と変えて $K$ 回の独立な推定を作り、95% 区間が解析解を含んだ割合（被覆率）を数える。
被覆率が 0.95 からその標準誤差 $\sqrt{0.95 \times 0.05 / K}$ の数倍以上ずれ続ければ、標準誤差か区間の作り方に問題がある。
あわせて、標準誤差の二乗平均平方根 $\sqrt{\overline{\mathrm{SE}^2}}$ と、$K$ 個の推定値の解析解からの RMSE を比べる。
$\mathrm{E}[\mathrm{SE}^2] = \mathrm{Var}(\bar{I})$ なので、偏りがなければ二つはほぼ等しい。
評価回数は $K \cdot R \cdot N$ 回になるので、ボタンで実行する。

```rust
//| id: random-replicate-coverage
//| ref: random-replicate-coverage
//| title: 多数の鍵で QmcReplicatePlan の区間の被覆率を測る
//| run: button
//| uses: [random-replicate-transmittance-model]
//| crates: [scioxide-random, scioxide-core]
//| inputs:
//|   key_count: {"type":"range","label":"推定の回数 K","min":50,"max":400,"step":50,"value":200}
//|   coverage_replicates: {"type":"range","label":"反復の数 R","min":4,"max":32,"step":4,"value":16}
//|   coverage_exponent: {"type":"range","label":"反復一回の点数の指数 m（N = 2ᵐ）","min":5,"max":10,"step":1,"value":9}
//|   first_key: {"type":"range","label":"鍵のシードのずらし k₀","min":0,"max":10000,"step":1000,"value":0}
//| cases:
//|   - {"id":"few-replicates","label":"R = 4","description":"R が小さくても、t 分布の分位点を使えば被覆率は 0.95 の近くにとどまる。","inputs":{"coverage_replicates":4}}
//|   - {"id":"other-keys","label":"k₀ = 5000","description":"別の鍵の組でも被覆率は標準誤差の範囲で 0.95 に近い。","inputs":{"first_key":5000}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"coverage","path":"/rows/0/0","equals":200}
//|       - {"artifact":"coverage","path":"/rows/0/3","range":{"min":-4,"max":4}}
//|       - {"artifact":"coverage","path":"/rows/0/6","range":{"min":0.7,"max":1.3}}
//|   - case: few-replicates
//|     expect:
//|       - {"artifact":"coverage","path":"/rows/0/3","range":{"min":-4,"max":4}}
//|   - case: other-keys
//|     expect:
//|       - {"artifact":"coverage","path":"/rows/0/3","range":{"min":-4,"max":4}}
use scioxide_core::RealScalar;
use scioxide_random::{
    Philox4x64, QmcPlan, QmcReplicateOptions, QmcReplicatePlan, Quantile, SeedableRng, StudentT,
};

let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let fixed2 = serde_json::json!({ "fractionDigits": 2 });
let fixed3 = serde_json::json!({ "fractionDigits": 3 });
let (k, r, d) = (
    key_count.round() as usize,
    coverage_replicates.round() as usize,
    4_usize,
);
let points = 1_usize << coverage_exponent.round() as u32;
let exact = exact_mean(d);
let base = QmcPlan::sobol(d).map_err(|e| e.to_string())?;
let options = QmcReplicateOptions::default()
    .with_replicates(r)
    .with_points_per_replicate(points);
let t_quantile = StudentT::new((r - 1) as f64)
    .map_err(|e| e.to_string())?
    .quantile(0.975)
    .map_err(|e| e.to_string())?;
let (mut covered, mut se_square, mut error_square) = (0_usize, 0.0_f64, 0.0_f64);
for key in 1..=k as u64 {
    let root = Philox4x64::from_seed(first_key.round() as u64 + key);
    let plan = QmcReplicatePlan::new(&base, &root, options).map_err(|e| e.to_string())?;
    let estimate = plan
        .estimate(|x: &[f64]| transmittance(x))
        .map_err(|e| e.to_string())?;
    let error = estimate.mean - exact;
    covered += usize::from(error.abs() <= t_quantile * estimate.standard_error);
    se_square += estimate.standard_error * estimate.standard_error;
    error_square += error * error;
}
let kf = k as f64;
let coverage = covered as f64 / kf;
// 被覆率の標準誤差（区間が正しく 95% を含むとき）。
let coverage_se = RealScalar::sqrt(0.95 * 0.05 / kf);
let rms_se = RealScalar::sqrt(se_square / kf);
let rmse = RealScalar::sqrt(error_square / kf);
let columns = serde_json::json!([
    { "key": "0", "label": "推定の回数 K", "type": "integer" },
    { "key": "1", "label": "被覆率 [-]", "type": "number", "format": fixed3 },
    { "key": "2", "label": "被覆率の SE [-]", "type": "number", "format": fixed3 },
    { "key": "3", "label": "z = (被覆率 − 0.95) / SE [-]", "type": "number", "format": fixed2 },
    { "key": "4", "label": "SE の二乗平均平方根 [-]", "type": "number", "format": sci3 },
    { "key": "5", "label": "推定値の RMSE [-]", "type": "number", "format": sci3 },
    { "key": "6", "label": "比 RMSE / SE [-]", "type": "number", "format": fixed2 }
]);
emit_table_with_columns!(
    columns,
    vec![(
        k,
        coverage,
        coverage_se,
        (coverage - 0.95) / coverage_se,
        rms_se,
        rmse,
        rmse / rms_se,
    )],
    metadata = serde_json::json!({ "id": "coverage" })
);
```

既定の入力（$K = 200$、$R = 16$、$N = 512$、$k_0 = 0$）では、被覆率は $0.960$（標準誤差 $0.015$、$z = 0.65$）だった。
標準誤差の二乗平均平方根 $1.73 \times 10^{-5}$ に対して、推定値の RMSE は $1.61 \times 10^{-5}$ で、比は $0.93$ である。
$K$ 個の推定値から求めた RMSE の相対的な不確かさは約 $1/\sqrt{2K} = 0.05$ なので、この比は 1 と標本の揺らぎの範囲で一致する。
$R = 4$ でも被覆率は $0.960$ で、$t$ 分布の分位点が小さい $R$ の標準誤差の揺れを補っている。
$k_0 = 5000$ の別の鍵の組では、被覆率 $0.930$（$z = -1.30$）、比 $1.04$ だった。
ここで試した三つの設定では、被覆率はどれも 0.95 から標準誤差の 2 倍以内にあり、標準誤差は推定値の実際の揺らぎと矛盾しない。

## まとめ

`QmcReplicatePlan` は Philox の根から反復ごとに独立なランダム化を作り、反復平均の平均と経験的な標準誤差を返す。
標準誤差は証明付きの限界ではない統計的な推定値なので、推定値と真の値の差は自由度 $R - 1$ の $t$ 分布の分位点と比べて読む。
返された `replicate_means` から標準誤差を計算し直せば、レポート値を独立に確かめられる。
区間の較正は一回の推定では判断できないので、多数の鍵での被覆率と、標準誤差と RMSE の比で確かめる。
$R$ を増やすと標準誤差そのものの揺れと $t$ の分位点が小さくなり、$N$ を増やすと標準誤差が速く減る。
