放射性の試料では原子核が互いに独立に崩壊し、単位時間あたりの崩壊率 $n$ はほぼ一定である。
このとき崩壊の時刻は Poisson 過程をなし、一定の計数時間 $t_{\mathrm g}$ に数えた個数は平均 $n t_{\mathrm g}$ の Poisson 分布に従う。
このページは `Exponential` の待ち時間から崩壊の時刻を作り、計数の分布を `Poisson` の確率質量と、Fano 因子を 1 と比べる。
検出器の不感時間が観測率と計数の揺らぎをどう変えるかは、[計数管の不感時間と計数率の補正](../radioactive-dead-time/)で扱う。

## Poisson 過程と Fano 因子

崩壊率 $n$ [s⁻¹] の Poisson 過程では、隣り合う崩壊の間隔が互いに独立に指数分布 $\mathrm{Exponential}(n)$（平均 $1/n$）に従う。
長さ $t_{\mathrm g}$ の区間に入る個数 $N$ は Poisson 分布

$$
\Pr(N = k) = e^{-\mu}\frac{\mu^k}{k!}, \qquad \mu = n t_{\mathrm g}
$$

に従い、平均と分散がどちらも $\mu$ になる。
分散と平均の比

$$
F = \frac{\mathrm{Var}\,N}{\mathrm E\,N}
$$

を Fano 因子と呼び、Poisson 過程では $F = 1$ である。
$F < 1$ の計数はサブポアソン（分散が平均より小さい）、$F > 1$ の計数はスーパーポアソンと呼ぶ。

$R$ 個の区間の計数から標本平均 $\bar N$ と不偏分散 $s^2$ を求め、$\hat F = s^2/\bar N$ とする。
Poisson 分布では、デルタ法で $\hat F$ の分散を求めると 4 次のモーメントの項と $s^2$ と $\bar N$ の共分散の項が打ち消し合い、

$$
\mathrm{SE}(\hat F) \approx F\sqrt{\frac{2}{R-1}}
$$

が残る。
$R = 2000$ では $\mathrm{SE} \approx 0.032$ なので、$\hat F$ の 95% 区間 $\hat F \pm 1.96\,\mathrm{SE}$ の幅は約 $\pm 0.06$ である。

## 計数の分布と Fano 因子

次のセルは `Exponential::new(n)` の待ち時間を足して崩壊の時刻を作り、長さ $t_{\mathrm g}$ の $R$ 個の連続した区間 $[g\,t_{\mathrm g}, (g+1)\,t_{\mathrm g})$ で個数を数える。
`Exponential::new` は率 $n$ を取り、平均 $1/n$ の待ち時間を返す。
待ち時間の和を区間の境と比べる計算は、Poisson 過程の定義そのものを使うので、`Poisson` の確率質量との比較は独立な検算になる。
入力は崩壊率 $n$ [s⁻¹]、計数時間 $t_{\mathrm g}$ [ms]、区間の数 $R$、乱数のシードである。
グラフは計数 $k$ の相対度数を記号で、`Poisson::new(μ)` の `pmf(k)` を破線の階段で示す。
表は平均、分散、Fano 因子の推定値、標準誤差、95% 区間、理論値、差を標準誤差で割った値である。
分散の標準誤差は標本の 4 次中心モーメント $m_4$ から $\sqrt{(m_4 - s^4)/R}$ と求め、分布を仮定しない。

```rust
//| id: random-radioactive-poisson
//| ref: random-radioactive-poisson
//| title: 指数分布の待ち時間から計数を作り Poisson 分布と比べる
//| run: reactive
//| crates: [scioxide-core, scioxide-random]
//| inputs:
//|   decay_rate: {"type":"range","label":"崩壊率 n [s⁻¹]","description":"平均計数 μ = n t_g を変える。","min":100,"max":5000,"step":100,"value":800}
//|   gate_ms: {"type":"range","label":"計数時間 t_g [ms]","description":"一つの区間の長さ。","min":2,"max":50,"step":1,"value":10}
//|   gates: {"type":"range","label":"区間の数 R [個]","description":"Fano 因子の標準誤差 √(2/(R−1)) を変える。","min":200,"max":5000,"step":200,"value":2000}
//|   poisson_seed: {"type":"range","label":"乱数のシード [-]","description":"SplitMix64 のシード。","min":1,"max":1000,"step":1,"value":1}
//| cases:
//|   - {"id":"seed-42","label":"シード 42","description":"Fano 因子は 1.085 で、95% 区間 [1.018, 1.153] は 1 を含まない。約 5% のシードで起こる外れである。","inputs":{"poisson_seed":42}}
//|   - {"id":"short-gate","label":"t_g = 2 ms","description":"平均計数 μ = 1.6 で分布は右に裾を引くが、Fano 因子は 1.009 ± 0.032 になる。","inputs":{"gate_ms":2}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"moments","path":"/rows/0/1","range":{"min":7.8,"max":8.2}}
//|       - {"artifact":"moments","path":"/rows/2/1","range":{"min":0.88,"max":1.12}}
//|       - {"artifact":"moments","path":"/rows/2/2","approx":{"value":0.031,"atol":0.002}}
//|   - case: seed-42
//|     expect:
//|       - {"artifact":"moments","path":"/rows/2/1","range":{"min":1.07,"max":1.1}}
//|   - case: short-gate
//|     expect:
//|       - {"artifact":"moments","path":"/rows/0/5","approx":{"value":1.6,"atol":1e-12}}
//|       - {"artifact":"moments","path":"/rows/2/1","range":{"min":0.88,"max":1.12}}
use scioxide_core::RealScalar;
use scioxide_random::{Distribution, Exponential, Mass, Poisson, SeedableRng, SplitMix64};

let gate = gate_ms * 1e-3; // [s]
let r = gates.round() as usize;
let mu = decay_rate * gate;
let waiting = Exponential::new(decay_rate).map_err(|e| e.to_string())?;
let mut rng = SplitMix64::from_seed(poisson_seed.round() as u64);
// 連続した区間 [g t_g, (g + 1) t_g) に入る崩壊を数える。
let mut counts = vec![0_usize; r];
let mut next = waiting.sample(&mut rng).map_err(|e| e.to_string())?;
for (g, count) in counts.iter_mut().enumerate() {
    let close = (g + 1) as f64 * gate;
    while next < close {
        *count += 1;
        next += waiting.sample(&mut rng).map_err(|e| e.to_string())?;
    }
}
let rf = r as f64;
let mean = counts.iter().sum::<usize>() as f64 / rf;
let central = |power: i32| {
    counts
        .iter()
        .map(|&c| RealScalar::powi(c as f64 - mean, power))
        .sum::<f64>()
};
let var = central(2) / (rf - 1.0);
let m4 = central(4) / rf;
let fano = var / mean;
let rows = vec![
    ("平均計数 [個]", mean, RealScalar::sqrt(var / rf), mu),
    (
        "分散 [個²]",
        var,
        RealScalar::sqrt((m4 - var * var) / rf),
        mu,
    ),
    (
        "Fano 因子 [-]",
        fano,
        fano * RealScalar::sqrt(2.0 / (rf - 1.0)),
        1.0,
    ),
];
let rows: Vec<_> = rows
    .into_iter()
    .map(|(name, x, se, theory)| {
        (
            name,
            x,
            se,
            x - 1.96 * se,
            x + 1.96 * se,
            theory,
            (x - theory) / se,
        )
    })
    .collect();
// 相対度数と Poisson の確率質量（独立検算の基準）。
let poisson = Poisson::new(mu).map_err(|e| e.to_string())?;
let k_max = counts.iter().copied().fold(0, usize::max);
let mut histogram = vec![0_usize; k_max + 1];
for &c in &counts {
    histogram[c] += 1;
}
let observed: Vec<[f64; 2]> = histogram
    .iter()
    .enumerate()
    .map(|(k, &h)| [k as f64, h as f64 / rf])
    .collect();
let mut pmf = Vec::new();
for k in 0..=k_max {
    pmf.push([k as f64, poisson.pmf(k).map_err(|e| e.to_string())?]);
}
emit_chart!(serde_json::json!({
    "kind": "xy",
    "dataZoom": true,
    "tooltip": true,
    "xLabel": "区間の計数 k [個]",
    "yLabel": "確率・相対度数 [-]",
    "yMin": 0.0,
    "layers": [
        { "id": "observed", "kind": "scatter", "name": "相対度数", "points": observed },
        {
            "id": "poisson",
            "kind": "line",
            "name": "Poisson(μ) の確率質量",
            "points": pmf,
            "style": { "lineType": "dashed", "step": "middle" }
        }
    ]
}));
let digits4 = serde_json::json!({ "significantDigits": 4 });
let fixed2 = serde_json::json!({ "fractionDigits": 2 });
let columns = serde_json::json!([
    { "key": "0", "label": "量" },
    { "key": "1", "label": "推定値", "type": "number", "format": digits4 },
    { "key": "2", "label": "SE", "type": "number", "format": digits4 },
    { "key": "3", "label": "95% 区間の下限", "type": "number", "format": digits4 },
    { "key": "4", "label": "95% 区間の上限", "type": "number", "format": digits4 },
    { "key": "5", "label": "理論値", "type": "number", "format": digits4 },
    { "key": "6", "label": "z = (推定 − 理論)/SE [-]", "type": "number", "format": fixed2 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "moments" })
);
```

既定の $n = 800$ s⁻¹、$t_{\mathrm g} = 10$ ms では平均計数は $\mu = 8$ である。
シード 1、$R = 2000$ では標本平均が $8.017$（標準誤差 $0.063$）、分散が $7.874$（標準誤差 $0.258$）で、$\mu$ との差はどちらも標準誤差の 0.5 倍以内である。
Fano 因子は $\hat F = 0.982$、標準誤差 $0.031$、95% 区間 $[0.921, 1.043]$ で、区間は 1 を含む。
相対度数の記号は Poisson の確率質量の階段に沿って並ぶ。

95% 区間はシードを変えると約 5% の確率で 1 を含まない。
シードを 1 から 40 まで変えると、$|\hat F - 1|$ が標準誤差の 1.96 倍を超えたのはシード 6 と 28 の二つだった。
シード 42 では $\hat F = 1.085$、区間 $[1.018, 1.153]$ で 1 を含まず、差は $2.49\,\mathrm{SE}$ である。
$t_{\mathrm g} = 2$ ms にすると $\mu = 1.6$ で、分布は 0 の近くに偏って右に裾を引くが、$\hat F = 1.009 \pm 0.032$ になる。

## まとめ

崩壊の時刻は `Exponential` の待ち時間を足して作り、一定の計数時間の個数は `Poisson` の `pmf` と相対度数で比べる。
Poisson 分布では標本の Fano 因子の SE が約 $F\sqrt{2/(R-1)}$ になるので、$R = 2000$ 区間で 1 からの差を読める幅は約 $\pm 0.06$ である。
95% 区間が 1 を含まないシードは約 5% の割合で現れるので、一つのシードの外れだけで Poisson 性を否定せず、シードを変えた結果を併せて読む。
平均計数 $\mu$ が小さく分布が偏っていても、Fano 因子は 1 のまわりに SE の幅で揺らぐ。
