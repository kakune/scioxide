放射線の検出器は一つのパルスを処理する間に来た崩壊を数えられない。
この不感時間 $\tau$ のために観測率は真の崩壊率より下がり、記録した計数の揺らぎも Poisson 分布より小さくなる。
Geiger–Müller 計数管の不感時間は 100 μs 程度なので、毎秒数千個の崩壊を数えると補正が欠かせない。
このページは[放射性計数の Poisson 性と Fano 因子](../radioactive-counting/)と同じ `Exponential` の待ち時間で崩壊の列を作り、非麻痺型の不感時間をかけて、観測率の式と補正式、Fano 因子の低下をシミュレーションで確かめる。

## 非麻痺型の不感時間

非麻痺型（non-paralyzable）の検出器は、崩壊を一つ記録すると続く $\tau$ の間は何も記録せず、その間に来た崩壊は不感時間を延ばさない。
記録された崩壊の間隔は $\tau$ と指数分布の待ち時間の和 $X = \tau + E$、$E \sim \mathrm{Exponential}(n)$ になり、その平均は $\tau + 1/n$ である。
観測率 $m$ はこの逆数なので

$$
m = \frac{1}{\tau + 1/n} = \frac{n}{1 + n\tau}, \qquad n = \frac{m}{1 - m\tau}
$$

になり、右の式で観測率から真の率を復元できる。
$\hat m$ の標準誤差を $\mathrm{SE}(\hat m)$ とすると、デルタ法で $\mathrm{SE}(\hat n) \approx \mathrm{SE}(\hat m)/(1 - \hat m\tau)^2$ である。
$m\tau$ が 1 に近いと分母が小さくなり、補正した率の不確かさが大きく増える。

記録の間隔が $\tau$ より短くならないので、記録の列は Poisson 過程より規則的になる。
間隔の平均を $\mu_X$、分散を $\sigma_X^2$ とする再生過程では、長い計数時間で Fano 因子が $\sigma_X^2/\mu_X^2$ に近づく。
$\sigma_X^2 = 1/n^2$ なので

$$
F_{\mathrm{obs}} \to \frac{1/n^2}{(\tau + 1/n)^2} = \frac{1}{(1 + n\tau)^2} = (1 - m\tau)^2
$$

で、観測した計数はサブポアソンになる。
有限の $t_{\mathrm g}$ では、定常な再生過程で計数の分散を展開すると（Cox, 1962）$F_{\mathrm{obs}} \approx \rho^2 + c/(m t_{\mathrm g})$ になる。
ここで $\rho = 1/(1+n\tau)$、$c = 1/6 + \rho^4/2 - 2\rho^3/3$ である。
$c$ は $0 \le c \le 1/6$ なので、補正は $1/(6 m t_{\mathrm g})$ を超えない。
$\hat F_{\mathrm{obs}}$ の標準誤差には同じ $F\sqrt{2/(R-1)}$ を近似として使う。

次のセルは一続きの崩壊の列に非麻痺型の不感時間をかけ、$R = 1000$ 個の連続した区間で真の計数と記録した計数を数える。
不感時間は区間の境をまたいで続く。
入力は崩壊率 $n$ [s⁻¹]、不感時間 $\tau$ [μs]、計数時間 $t_{\mathrm g}$ [ms]、乱数のシードである。
表は真の計数の Fano 因子、観測率 $\hat m$、補正した率 $\hat n$、記録した計数の Fano 因子を、閉形式の理論値と標準誤差で比べる。
グラフは真の率を $n/8, 2n/8, \dots, n$ と変え、各 300 区間で求めた $\hat m$ と $\hat n$ を記号で、$m = n/(1 + n\tau)$ を破線、不感時間がない場合の $m = n$ を点線で示す。

//| ref: random-radioactive-dead-time
//| title: 非麻痺型の不感時間で観測率と Fano 因子を測る
//| run: reactive

//|   dead_rate: {"type":"range","label":"崩壊率 n [s⁻¹]","description":"表の真の率で、グラフの横軸の最大値。","min":200,"max":5000,"step":200,"value":2000}
//|   dead_time_us: {"type":"range","label":"不感時間 τ [μs]","description":"0 で不感時間のない検出器になる。","min":0,"max":500,"step":25,"value":200}
//|   dead_gate_ms: {"type":"range","label":"計数時間 t_g [ms]","description":"短くすると Fano 因子の有限時間の補正が大きくなる。","min":2,"max":200,"step":2,"value":50}

use scioxide_core::RealScalar;
use scioxide_random::{Distribution, Exponential, SeedableRng, SplitMix64};

let (tau, gate) = (dead_time_us * 1e-6, dead_gate_ms * 1e-3); // [s]
let mut rng = SplitMix64::from_seed(dead_seed.round() as u64);
// 一続きの崩壊の列から、区間ごとの真の計数と記録した計数を返す。
let mut simulate = |rate: f64, r: usize| -> Result<Vec<(f64, f64)>, String> {
    let waiting = Exponential::new(rate).map_err(|e| e.to_string())?;
    let mut counts = vec![(0.0, 0.0); r];
    let mut next = waiting.sample(&mut rng).map_err(|e| e.to_string())?;
    let mut last = f64::NEG_INFINITY; // 最後に記録した時刻
    for (g, (n_true, n_obs)) in counts.iter_mut().enumerate() {
        let close = (g + 1) as f64 * gate;
        while next < close {
            *n_true += 1.0;
            if next - last >= tau {
                *n_obs += 1.0;
                last = next;
            }
            next += waiting.sample(&mut rng).map_err(|e| e.to_string())?;
        }
    }
    Ok(counts)
};
let moments = |x: &[f64]| {
    let mean = x.iter().sum::<f64>() / x.len() as f64;
    let var = x.iter().map(|v| (v - mean) * (v - mean)).sum::<f64>() / (x.len() - 1) as f64;
    (mean, var)
};
let r = 1000_usize;
let counts = simulate(dead_rate, r)?;
let (true_counts, obs_counts): (Vec<f64>, Vec<f64>) = counts.into_iter().unzip();
let (mean_t, var_t) = moments(&true_counts);
let (mean_o, var_o) = moments(&obs_counts);
let fano_se = RealScalar::sqrt(2.0 / (r as f64 - 1.0));
let m_hat = mean_o / gate;
let m_se = RealScalar::sqrt(var_o / r as f64) / gate;
let n_hat = m_hat / (1.0 - m_hat * tau);
let n_se = m_se / RealScalar::powi(1.0 - m_hat * tau, 2);
// 閉形式の理論値（独立検算の基準）。
let m = dead_rate / (1.0 + dead_rate * tau);
let rho = 1.0 / (1.0 + dead_rate * tau);
let c = 1.0 / 6.0 + RealScalar::powi(rho, 4) / 2.0 - 2.0 * RealScalar::powi(rho, 3) / 3.0;
let (f_t, f_o) = (var_t / mean_t, var_o / mean_o);
let rows: Vec<_> = [
    ("真の計数の Fano 因子 [-]", f_t, f_t * fano_se, 1.0),
    ("観測率 m̂ [s⁻¹]", m_hat, m_se, m),
    ("補正した率 n̂ [s⁻¹]", n_hat, n_se, dead_rate),
    (
        "記録した計数の Fano 因子（漸近値 ρ²）[-]",
        f_o,
        f_o * fano_se,
        rho * rho,
    ),
    (
        "記録した計数の Fano 因子（ρ² + c/(m t_g)）[-]",
        f_o,
        f_o * fano_se,
        rho * rho + c / (m * gate),
    ),
]
.into_iter()
.map(|(name, x, se, theory)| {
    (
        name,
        x,
        se,
        x - 1.96 * se,
        x + 1.96 * se,
        theory,
        (x - theory) / se,
    )
})
.collect();
let digits4 = serde_json::json!({ "significantDigits": 4 });
let fixed2 = serde_json::json!({ "fractionDigits": 2 });
let columns = serde_json::json!([
    { "key": "0", "label": "量" },
    { "key": "1", "label": "推定値", "type": "number", "format": digits4 },
    { "key": "2", "label": "SE", "type": "number", "format": digits4 },
    { "key": "3", "label": "95% 区間の下限", "type": "number", "format": digits4 },
    { "key": "4", "label": "95% 区間の上限", "type": "number", "format": digits4 },
    { "key": "5", "label": "理論値", "type": "number", "format": digits4 },
    { "key": "6", "label": "z = (推定 − 理論)/SE [-]", "type": "number", "format": fixed2 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "rates" })
);
let (mut observed, mut restored, mut curve) = (Vec::new(), Vec::new(), Vec::new());
for j in 1..=8 {
    let rate = dead_rate * j as f64 / 8.0;
    let sweep: Vec<f64> = simulate(rate, 300)?.into_iter().map(|c| c.1).collect();
    let rate_hat = moments(&sweep).0 / gate;
    observed.push([rate, rate_hat]);
    restored.push([rate, rate_hat / (1.0 - rate_hat * tau)]);
}
for j in 0..=40 {
    let rate = dead_rate * j as f64 / 40.0;
    curve.push([rate, rate / (1.0 + rate * tau)]);
}
let identity = vec![[0.0, 0.0], [dead_rate, dead_rate]];
emit_chart!(serde_json::json!({
    "kind": "xy",
    "dataZoom": true,
    "tooltip": true,
    "xLabel": "真の崩壊率 n [s⁻¹]",
    "yLabel": "率 [s⁻¹]",
    "xMin": 0.0,
    "yMin": 0.0,

        {

        },
        {
            "id": "identity",
            "kind": "line",
            "name": "不感時間なし m = n",
            "points": identity,
            "style": { "lineType": "dotted" }
        },
        { "id": "observed", "kind": "scatter", "name": "観測率 m̂", "points": observed },
        {
            "id": "restored",
            "kind": "scatter",
            "name": "補正した率 n̂",
            "points": restored,
            "style": { "symbol": "diamond" }
        }
    ]
}));

既定の $n = 2000$ s⁻¹、$\tau = 200$ μs では $n\tau = 0.4$ で、観測率の理論値は $m = 1428.57$ s⁻¹ である。
シード 42 の観測率は $\hat m = 1425.04 \pm 3.73$ s⁻¹（差は $-0.95\,\mathrm{SE}$）、補正した率は $\hat n = 1993.1 \pm 7.3$ s⁻¹ で、設定した 2000 s⁻¹ を 95% 区間 $[1978.8, 2007.4]$ に含む。
同じ列の真の計数の Fano 因子は $0.995 \pm 0.045$ である。
記録した計数の Fano 因子は $0.489 \pm 0.022$ で、漸近値 $(1 - m\tau)^2 = 0.510$ との差は $-0.95\,\mathrm{SE}$ である。
$t_{\mathrm g} = 50$ ms では有限時間の補正は $0.0008$ で、標準誤差よりずっと小さい。

$\tau = 0$ にすると記録した計数は真の計数と一致し、$\hat m = \hat n = 2000.1$ s⁻¹ になる。
$t_{\mathrm g} = 2$ ms では補正が $0.019$ に増えて理論値は $0.529$ になり、$\hat F_{\mathrm{obs}} = 0.523 \pm 0.023$ との差は漸近値に対して $0.56\,\mathrm{SE}$、補正込みの値に対して $-0.24\,\mathrm{SE}$ になる。
$n = 5000$ s⁻¹、$\tau = 500$ μs では $n\tau = 2.5$ で、観測率は $1430.4 \pm 1.6$ s⁻¹ まで下がる。
補正した率は $5022.7 \pm 19.5$ s⁻¹ で、標準誤差は $(1 - \hat m\tau)^{-2} \approx 12$ 倍に増える。
このとき記録した計数の Fano 因子は $0.088 \pm 0.004$ で、補正込みの理論値 $0.084$ との差は $0.97\,\mathrm{SE}$ である。
グラフでは観測率の記号が破線の曲線に、補正した率の記号が点線 $m = n$ に沿って並ぶ。

## まとめ

非麻痺型の不感時間 $\tau$ がある検出器では、観測率は $n/(1 + n\tau)$ に下がり、$n = m/(1 - m\tau)$ で真の率に戻せる。
補正した率の SE は観測率の SE の $(1 - m\tau)^{-2}$ 倍になるので、$m\tau$ が 1 に近い高い計数率では補正の不確かさを先に見積もる。
記録した計数は Fano 因子が $(1 - m\tau)^2$ のサブポアソンになり、短い計数時間では $c/(m t_{\mathrm g})$ の補正が加わる。
そのため、計数の分散から放射能の不確かさを見積もるときは、Poisson の $\sqrt N$ ではなく測った分散を使う。
