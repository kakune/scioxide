風向、海流の向き、動物の移動方向のような角度のデータは、実数軸の算術平均で要約できない。
350° と 10° の風はどちらも北（0°）から 10° 以内にあるが、角度を数のまま算術平均すると 180°（南）になる。
方向統計（directional statistics）は各角度を単位円上の単位ベクトルとして扱い、ベクトルの平均で平均方向と集中の度合いを定める。
von Mises 分布は円周上で釣鐘形をした分布で、集中度 $\kappa$ が大きいと正規分布に近づき、$\kappa = 0$ で一様分布になる。
このページは風向を `VonMises` で表し、集中の度合いを表す平均合成ベクトル長を scioxide-special の修正 Bessel 関数で計算した値と照合する。
有限個の観測から求めた統計量の偏りと標準誤差は、[風向の標本と平均合成ベクトル長の偏り](../von-mises-wind-samples/)で調べる。

## 方位角の約束

風向は方位角 $\theta$ で表し、北を 0°、時計回りに東 90°、南 180°、西 270° とする。
気象の風向は風が吹いてくる向きで、315° は北西の風である。
16 方位の名前は 22.5° ごとに付き、0° が北、337.5° が北北西、315° が北西である。
350° は北北西（337.5°）より北（360° = 0°）に近く、16 方位では北に入る。

方位角 $\theta$ の単位ベクトルは（東成分、北成分）$= (\sin\theta, \cos\theta)$ である。
x 軸を東、反時計回りを正とする数学の角度 $\vartheta$ とは $\vartheta = \pi/2 - \theta$ の関係にある。
von Mises 分布の族は回転と鏡映で閉じていて、平均合成ベクトル長も回転と鏡映で変わらないので、このページは方位角をそのまま角度として von Mises 分布に入れる。
平均方向は $\operatorname{atan2}(\text{東成分の平均}, \text{北成分の平均})$ で、方位角のまま得られる。

## von Mises 分布と平均合成ベクトル長

平均方向 $\mu$、集中度 $\kappa \ge 0$ の von Mises 分布の密度は

$$
f(\theta;\mu,\kappa) = \frac{\exp\{\kappa\cos(\theta - \mu)\}}{2\pi I_0(\kappa)}
$$

である。
$I_\nu$ は $\nu$ 次の第 1 種修正 Bessel 関数で、$\nu = 0, 1$ では

$$
I_\nu(\kappa) = \sum_{j \ge 0} \frac{(\kappa/2)^{2j+\nu}}{j!\,(j+\nu)!}
$$

と級数で書ける（DLMF 10.25.2）。
$\kappa = 0$ では $f = 1/(2\pi)$ の一様分布になり、$\kappa$ が大きいと平均 $\mu$、分散 $1/\kappa$ の正規分布に近づく。

単位ベクトルの期待値を $\mu$ を基準にした成分で書くと、$E[\cos(\theta - \mu)] = I_1(\kappa)/I_0(\kappa)$、$E[\sin(\theta - \mu)] = 0$ である。
1 つ目の式は密度の正規化 $\int_{-\pi}^{\pi} e^{\kappa\cos\phi}\,d\phi = 2\pi I_0(\kappa)$ を $\kappa$ で微分し、$I_0' = I_1$ を使うと得られる。
期待値のベクトルの長さ

$$
A(\kappa) = \frac{I_1(\kappa)}{I_0(\kappa)}
$$

を母集団の平均合成ベクトル長、$1 - A(\kappa)$ を円周分散と呼ぶ。
$A$ は 0 から 1 の値をとり、1 に近いほど風向が平均方向に集まる。
$\kappa = 3$ では $A = 0.8100$、円周分散は 0.1900 である。

級数の先頭の項から、小さい $\kappa$ では $A(\kappa) = \kappa/2 - \kappa^3/16 + O(\kappa^5)$ と立ち上がる。
大きい $\kappa$ では、$I_\nu$ の漸近展開（DLMF 10.40.1）から

$$
A(\kappa) = 1 - \frac{1}{2\kappa} - \frac{1}{8\kappa^2} + O(\kappa^{-3})
$$

となる。
$\kappa$ が大きいと $I_0(\kappa)$ と $I_1(\kappa)$ はどちらも $e^\kappa/\sqrt{2\pi\kappa}$ の程度に増え、$\kappa \approx 714$ で倍精度の上限を超える。
比を計算するときは、両方に $e^{-\kappa}$ を掛けた指数尺度付きの関数を使えば、あふれずに同じ比が得られる。

## VonMises の API

`VonMises::new(location, concentration)` は平均方向 `location` [rad] と集中度 `concentration` を受け取り、既定の `LawOptions` を使う。
許容誤差と作業量の上限を変えるときは `VonMises::with_options(location, concentration, options)` を使う。
非有限の `location` と `concentration` は `NonFinite`、負の `concentration` と、$\mu \pm \pi$ を丸めると $\mu$ に戻るほど大きい `location` は `DomainError` になる。
Bessel 関数の評価が作業量の上限に達すると `ConvergenceFailure`、`with_options` に範囲外の許容誤差を渡すと `InvalidInput` になる。

`pdf` は周期 $2\pi$ の密度で、どの実数の角度でも評価できる。
分布関数、分位点、モーメント、標本は主区間 $[\mu - \pi, \mu + \pi]$ の角度を扱い、`winding_cdf` が分布関数を実数軸に延ばす。
`sample` は $\kappa \ge 0.5$ では Best–Fisher（1979）の棄却法、$0 < \kappa < 0.5$ では一様な包絡の棄却法、$\kappa = 0$ では一様乱数を使う。
どちらの棄却法も 1,024 回の提案で受理されなければエラーを返す。

`mean_resultant_length()` は構築時に計算した $A(\kappa)$ を返し、`circular_variance()` は $1 - A$ を返す。
構築時の計算は scioxide-special の指数尺度付き修正 Bessel 関数の比で、$\kappa > 10^8$ では上の漸近形の 2 項 $1 - 1/(2\kappa) - 1/(8\kappa^2)$ を使う。
`mean_direction()` は $\kappa > 0$ で $\mu$ を返し、$\kappa = 0$ では平均方向が定まらないので `DomainError` を返す。

`mean_resultant_length()` の値は scioxide-special の Bessel 関数から来るので、`bessel_i(order, x)` の比との一致は同じクレートの 2 つの関数の照合で、独立な検算ではない。
このページは級数を手で計算した比を独立な検算として並べる。

## A(κ) の 4 通りの計算

次のセルは集中度 $\kappa$（0–10）を受け取り、$A(\kappa)$ を `bessel_i` の比、`VonMises::mean_resultant_length()`、級数の手計算、漸近形 $1 - 1/(2\kappa) - 1/(8\kappa^2)$ で求める。
級数は 80 項で打ち切る。
$\kappa \le 10$ では、81 項目以降の和が倍精度の丸めより小さい。
図は $\kappa \in [0, 10]$ の `bessel_i` の比を実線、0.5 刻みの級数の値を記号、$\kappa \ge 2$ の漸近形を破線で描き、入力の $\kappa$ を縦線で示す。
表は入力の $\kappa$ での 4 つの値、円周分散 $1 - A$、Bessel 比との差を出す。
$\kappa = 0$ では漸近形が定義されないので、その行は空欄になる。

```rust
//| id: random-von-mises-resultant-length
//| ref: random-von-mises-resultant-length
//| title: 平均合成ベクトル長 A(κ) を Bessel 関数と級数で計算する
//| run: reactive
//| crates: [scioxide-random, scioxide-special]
//| inputs:
//|   kappa: {"type":"range","label":"集中度 κ [-]","min":0,"max":10,"step":0.25,"value":3}
//| cases:
//|   - {"id":"uniform","label":"κ = 0","description":"I₁(0) = 0 なので A = 0、円周分散は 1 になる。漸近形の行は空欄になる。","inputs":{"kappa":0}}
//|   - {"id":"strong","label":"κ = 10","description":"A = 0.9486、円周分散 0.0514 で、漸近形との差は 1.5×10⁻⁴ に縮む。","inputs":{"kappa":10}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"lengths","path":"/rows/0/1","approx":{"value":0.8099852939565045,"atol":1e-12}}
//|       - {"artifact":"lengths","path":"/rows/1/3","range":{"min":-1e-13,"max":1e-13}}
//|       - {"artifact":"lengths","path":"/rows/2/3","range":{"min":-1e-13,"max":1e-13}}
//|       - {"artifact":"lengths","path":"/rows/3/3","approx":{"value":-0.00945915,"atol":1e-7}}
//|   - case: uniform
//|     expect:
//|       - {"artifact":"lengths","path":"/rows/0/1","approx":{"value":0,"atol":1e-15}}
//|       - {"artifact":"lengths","path":"/rows/1/1","approx":{"value":0,"atol":1e-15}}
//|       - {"artifact":"lengths","path":"/rows/3/1","equals":null}
//|   - case: strong
//|     expect:
//|       - {"artifact":"lengths","path":"/rows/0/1","approx":{"value":0.9485998259548459,"atol":1e-12}}
//|       - {"artifact":"lengths","path":"/rows/2/3","range":{"min":-1e-13,"max":1e-13}}
//|       - {"artifact":"lengths","path":"/rows/3/3","approx":{"value":-0.00015017,"atol":1e-7}}
use scioxide_random::VonMises;

// 独立検算: I_ν(κ) = Σ (κ/2)^(2j+ν) / (j! (j+ν)!) の級数で A = I₁/I₀ を求める。
let series = |k: f64| {
    let (mut i0, mut i1, mut term) = (0.0_f64, 0.0_f64, 1.0_f64);
    for j in 0..80 {
        i0 += term;
        i1 += term * k / (2.0 * (j + 1) as f64);
        term *= (k / 2.0) * (k / 2.0) / (((j + 1) * (j + 1)) as f64);
    }
    i1 / i0
};
let bessel = |k: f64| -> Result<f64, String> {
    let i1 = scioxide_special::bessel_i(1.0, k).map_err(|e| e.to_string())?;
    let i0 = scioxide_special::bessel_i(0.0, k).map_err(|e| e.to_string())?;
    Ok(i1 / i0)
};
// 大きい κ の漸近形 1 − 1/(2κ) − 1/(8κ²)。κ = 0 では定義しない。
let asymptotic = |k: f64| (k > 0.0).then(|| 1.0 - 0.5 / k - 0.125 / (k * k));
let (mut curve, mut checks, mut tail) = (Vec::new(), Vec::new(), Vec::new());
for j in 0..=80 {
    let k = 0.125 * j as f64;
    curve.push([k, bessel(k)?]);
    if j % 4 == 0 {
        checks.push([k, series(k)]);
    }
    if k >= 2.0 {
        tail.push([k, 1.0 - 0.5 / k - 0.125 / (k * k)]);
    }
}
emit_chart!(
    serde_json::json!({
        "kind": "xy",
        "xLabel": "集中度 κ [-]",
        "yLabel": "平均合成ベクトル長 A(κ) [-]",
        "xMin": 0,
        "xMax": 10,
        "yMin": 0,
        "yMax": 1,
        "dataZoom": true,
        "tooltip": true,
        "annotations": [{"kind": "line", "axis": "x", "value": kappa, "label": "入力の κ"}],
        "layers": [
            {
                "id": "bessel",
                "kind": "line",
                "name": "bessel_i(1, κ)/bessel_i(0, κ)",
                "points": curve
            },
            {"id": "series", "kind": "scatter", "name": "級数の手計算", "points": checks},
            {
                "id": "asymptotic",
                "kind": "line",
                "name": "漸近形 1 − 1/(2κ) − 1/(8κ²)",
                "points": tail,
                "style": {"lineType": "dashed"}
            }
        ]
    }),
    metadata = serde_json::json!({ "id": "curve" })
);
let law = VonMises::<f64>::new(0.0, kappa).map_err(|e| e.to_string())?;
let reference = bessel(kappa)?;
let mut rows = Vec::new();
for (name, value) in [
    ("bessel_i(1, κ)/bessel_i(0, κ)", Some(reference)),
    (
        "VonMises::mean_resultant_length",
        Some(law.mean_resultant_length().map_err(|e| e.to_string())?),
    ),
    ("級数の手計算", Some(series(kappa))),
    ("漸近形 1 − 1/(2κ) − 1/(8κ²)", asymptotic(kappa)),
] {
    rows.push((
        name,
        value,
        value.map(|v| 1.0 - v),
        value.map(|v| reference - v),
    ));
}
let fixed6 = serde_json::json!({ "fractionDigits": 6 });
let none = "定義なし";
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let columns = serde_json::json!([
    { "key": "0", "label": "A(κ) の計算" },
    { "key": "1", "label": "A(κ) [-]", "type": "number", "format": fixed6, "nullText": none },
    { "key": "2", "label": "円周分散 1 − A [-]", "type": "number", "format": fixed6, "nullText": none },
    { "key": "3", "label": "Bessel 比 − この値 [-]", "type": "number", "format": sci2, "nullText": none }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "lengths" })
);
```

既定の $\kappa = 3$ では `bessel_i` の比、`mean_resultant_length()`、級数の 3 つがどれも $A = 0.8100$、円周分散 0.1900 で、Bessel 比との差は $1.1 \times 10^{-16}$ 以下である。
漸近形は 0.8194 で、$\kappa = 3$ ではまだ $9.5 \times 10^{-3}$ ずれる。
曲線は $\kappa$ が小さいところで $A \approx \kappa/2$ と直線的に立ち上がり、$\kappa = 10$ で 0.9486 まで近づく。
破線の漸近形は $\kappa$ が増えるにつれて実線に近づく。
展開の次の項は $-1/(8\kappa^3)$ なので、漸近形との差は大きい $\kappa$ で $\kappa^{-3}$ に比例して縮む。
ケース「κ = 10」では差が $1.5 \times 10^{-4}$ で、次の項の大きさ $1.25 \times 10^{-4}$ に近い。
ケース「κ = 0」では $I_1(0) = 0$ なので $A = 0$、円周分散は 1 で、漸近形の行は空欄になる。

## まとめ

風向は北 0°、時計回りの方位角で表し、単位ベクトル $(\sin\theta, \cos\theta)$ の平均から平均方向と平均合成ベクトル長を求める。
`VonMises::new(location, concentration)` は角度をラジアンで受け取り、`pdf` は周期的な密度、`sample` は $[\mu - \pi, \mu + \pi]$ の角度を返す。
母集団の平均合成ベクトル長 $A(\kappa) = I_1(\kappa)/I_0(\kappa)$ は `mean_resultant_length()` か `bessel_i` の比で得られ、$\kappa = 3$ では 0.8100 である。
$A(\kappa)$ を自分で計算するなら、小さい $\kappa$ では級数、大きい $\kappa$ では指数尺度付きの Bessel 関数の比を使い、$\kappa = 3$ ほどでは漸近形の 2 項で済ませない。
`mean_resultant_length()` と `bessel_i` の比の一致は同じクレートの照合なので、独立な検算には級数を使う。
