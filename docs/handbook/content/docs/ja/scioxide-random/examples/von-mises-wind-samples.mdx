[風向の von Mises 分布](../von-mises-wind-direction/)では、母集団の平均合成ベクトル長 $A(\kappa) = I_1(\kappa)/I_0(\kappa)$ を計算した。
観測できるのは有限個の風向で、そこから求めた平均合成ベクトル長 $\bar{R}$ と平均風向 $\bar{\theta}$ は観測ごとに揺れる。
このページは `VonMises` で風向を模擬し、24 方位の度数を密度と比べ、$\bar{R}$ の上向きの偏りと $\bar{\theta}$ の標準誤差（SE）を理論値と照合する。
方位角の約束（北 0°、時計回り、単位ベクトル $(\sin\theta, \cos\theta)$）は前のページと同じである。

## 標本の平均合成ベクトル長

$N$ 個の観測から東成分の平均 $\bar{S}$ と北成分の平均 $\bar{C}$ を作り、標本の平均合成ベクトル長 $\bar{R} = \sqrt{\bar{S}^2 + \bar{C}^2}$ と平均方向 $\bar{\theta} = \operatorname{atan2}(\bar{S}, \bar{C})$ を求める。
$\bar{R}$ は $A(\kappa)$ の推定値だが、有限の $N$ では上向きに偏る。
独立な単位ベクトル $u_i$ の平均 $\bar{u}$ について、分散を平均の周りで分解すると

$$
E[\bar{R}^2] = \lVert E[u]\rVert^2 + \frac{E\lVert u - E[u]\rVert^2}{N} = A^2 + \frac{1 - A^2}{N}
$$

が正確に成り立つ（$\lVert u \rVert = 1$ なので $E\lVert u - E[u]\rVert^2 = 1 - A^2$）。
$A(\kappa)$ は $N \to \infty$ の極限で、$\kappa = 0$ でも $\bar{R}$ は 0 ではなく $1/\sqrt{N}$ 程度の値をとる。

$\theta - \mu$ の成分の分散は、漸化式 $I_2 = I_0 - (2/\kappa)I_1$ から $\operatorname{Var}\cos(\theta - \mu) = 1 - A/\kappa - A^2$、$\operatorname{Var}\sin(\theta - \mu) = A/\kappa$ である。
$\bar{R}$ はおよそ $\cos(\theta - \mu)$ の平均で、$\bar{\theta} - \mu$ はおよそ $\sin(\theta - \mu)$ の平均を $A$ で割ったものなので、デルタ法から

$$
\operatorname{SE}(\bar{R}) \approx \sqrt{\frac{1 - A/\kappa - A^2}{N}},
\qquad
\operatorname{SE}(\bar{\theta}) \approx \frac{1}{\sqrt{N\kappa A}}
$$

となる。
どちらも $\bar{R}$ が 0 から十分に離れている（$A\sqrt{N}$ が 1 より十分大きい）ときの近似で、$\kappa = 0$ では平均方向そのものが定まらない。

次の 2 つのセルは $A(\kappa)$、有限の $N$ の $E[\bar{R}^2]$、$\operatorname{SE}(\bar{\theta})$ を同じ式で使うので、定義のブロックにまとめる。
$A(\kappa)$ は scioxide-special の `bessel_i` の比で計算する。

```rust
//| id: random-von-mises-sample-model
//| kind: definitions
//| title: 平均合成ベクトル長の理論値と標準誤差の近似
//| crates: [scioxide-core, scioxide-special]
use scioxide_core::RealScalar;

/// 母集団の平均合成ベクトル長 A(κ) = I₁(κ)/I₀(κ)。
pub(crate) fn resultant_length(kappa: f64) -> Result<f64, String> {
    let i1 = scioxide_special::bessel_i(1.0, kappa).map_err(|e| e.to_string())?;
    let i0 = scioxide_special::bessel_i(0.0, kappa).map_err(|e| e.to_string())?;
    Ok(i1 / i0)
}

/// 観測数 N の標本で E[R̄²] = A² + (1 − A²)/N。
pub(crate) fn expected_square_length(a: f64, n: usize) -> f64 {
    a * a + (1.0 - a * a) / n as f64
}

/// 平均方向の SE ≈ 1/√(NκA) [rad]。κ = 0 では平均方向が定まらないので None。
pub(crate) fn direction_se(kappa: f64, a: f64, n: usize) -> Option<f64> {
    (kappa > 0.0).then(|| 1.0 / RealScalar::sqrt(n as f64 * kappa * a))
}
```

## 風配図と円周統計量

本書の図には極座標の型がないので、風配図（方位ごとの度数を放射状に描く図）を方位角の横軸に展開して描く。
次のセルは平均風向 $\mu$ [度]（0–345°）、集中度 $\kappa$（0–10）、観測数 $N$（100–5000 回）、シードを受け取り、風向を $N$ 回模擬する。
観測は中心 0°, 15°, …, 345° の 24 方位（幅 15°）に集計し、各方位に入る割合を記号で描く。
帯は各方位の確率 $p$ に二項分布の $\pm 2\sqrt{p(1-p)/N}$ を付けたもので、$p$ は `winding_cdf` の差 $F_w(\theta + 7.5°) - F_w(\theta - 7.5°)$ で正確に求める。
`winding_cdf` は主区間の分布関数を 1 周ごとに 1 ずつ増やして実数軸に延ばしたものなので、0° をまたぐ方位でも差がそのまま確率になる。
破線は密度に幅 15° を掛けた値 $f(\theta)\,\Delta\theta$ で、方位の確率を中点の密度で近似したものである。
中点による近似の相対誤差は $(\Delta\theta)^2\,|f''/f|/24$ 程度で、$\Delta\theta = 15°$ では $\kappa = 3$ の山の中央で約 1% だが、$\kappa = 10$ では山の中央で約 3%、中央から 45° の方位で約 11% になる。

1 つ目の表は標本の $\bar{R}$ を、$N \to \infty$ の値 $A$ と有限の $N$ の値 $\sqrt{A^2 + (1 - A^2)/N}$ に並べる。
2 つ目の表は $\bar{R}$ と平均風向 $\bar{\theta}$ の差を SE の単位で示す。
$\kappa = 0$ では平均方向が定まらず、$\bar{R}$ も 0 の近くで正規近似に従わないので、SE と差 / SE の欄は空欄になる。

```rust
//|       - {"artifact":"resultant","path":"/rows/0/3","approx":{"value":0.03162277660168379,"atol":1e-12}}

//|       - {"artifact":"deviations","path":"/rows/1/1","equals":null}
//|   - case: weak
//|     expect:
//|       - {"artifact":"resultant","path":"/rows/0/2","approx":{"value":0.2424996125808019,"atol":1e-12}}
//|       - {"artifact":"deviations","path":"/rows/1/2","approx":{"value":5.203338812841106,"atol":1e-9}}

    let theta = law.sample(&mut rng).map_err(|e| e.to_string())?;
    east += RealScalar::sin(theta);
    north += RealScalar::cos(theta);
    // 中心 0°, 15°, …, 345° の 15° 幅の方位に集計する。
    let k = RealScalar::round(RealScalar::to_degrees(theta) / 15.0) as i64;
    bins[k.rem_euclid(24) as usize] += 1;
}

let r_bar = RealScalar::hypot(s_bar, c_bar);
let width = RealScalar::to_radians(15.0);
let mut theory = Vec::new();

    { "key": "1", "label": "標本値 [-]", "type": "number", "format": fixed4 },
    { "key": "2", "label": "N → ∞ の値 A [-]", "type": "number", "format": fixed4 },

let se_r = (kappa > 0.0).then(|| RealScalar::sqrt((1.0 - a / kappa - a * a) / n as f64));

// 平均風向 θ̄ と μ の差を (−180°, 180°] に折り返す。κ = 0 では平均方向がない。
let theta_bar = RealScalar::atan2(s_bar, c_bar);

    RealScalar::to_degrees(RealScalar::atan2(
```

既定の入力（$\mu = 315°$、$\kappa = 3$、$N = 1000$ 回、シード 42）では、図の割合は北西の 315° を中心に左右対称に並び、24 方位の全てが帯の中にある。
標本の $\bar{R} = 0.8047$ は有限の $N$ の値 0.8102 から $-0.0055$ 離れ、SE 0.0086 に対して $-0.64$ SE である。
平均風向は $\mu$ から $-1.02°$ ずれ、SE 1.16° に対して $-0.88$ SE である。
標本の円周分散 $1 - \bar{R}$ は 0.1953 で、母集団の値 0.1900 より 0.0053 大きい。

ケース「κ = 0（一様）」では $A = 0$ で、破線は全方位で $1/24 = 0.0417$ の水平線になる。
標本の $\bar{R} = 0.037$ は $A = 0$ から離れ、$\sqrt{1/N} = 0.032$ と同じ大きさである。
平均方向が定まらないので、2 つ目の表の SE と差 / SE は空欄になる。
ケース「κ = 0.5」では $A = 0.2425$ で、$\bar{R} = 0.2699$ は有限の $N$ の値 0.2444 から $+1.19$ SE、平均風向の SE は 5.2° に広がる。
ケース「κ = 10、N = 5000」では $A = 0.9486$、円周分散 0.0514 で、平均風向の SE は 0.26° になる。
このケースでは中点による近似の誤差が二項の SE と同じ程度になり、破線と帯の中心（`winding_cdf` の差）の差は山の中央の 315° で 1.4 SE、中央から ±45° の方位で 1.1 SE である。
帯の外に出た方位は 24 のうち 2 つで、各方位が $\pm 2$ SE を外れる確率 0.046 から見込まれる 1.1 個と同じ程度である。

## 平均合成ベクトル長の偏り

$\bar{R}$ の上向きの偏りは、$N$ が小さく $\kappa$ が小さいほど大きい。
次のセルは $\mu = 0$、集中度 $\kappa$（0.25–10）の観測を $N = 5, 10, 20, 50, 100, 200, 500$ 回ずつ $R$ 組（200–4000 組）作り、各 $N$ で $\bar{R}$ の平均と $\bar{R}^2$ の平均を求める。
$E[\bar{R}^2] = A^2 + (1 - A^2)/N$ は正確な式なので、$\bar{R}^2$ の平均との差を SE（組の間の標本標準偏差 / $\sqrt{R}$）で割って照合する。
$\bar{R}$ の平均は Jensen の不等式から $\sqrt{E[\bar{R}^2]}$ 以下になる。
最後の列は $|\bar{\theta} - \mu| \le 1.96\,\operatorname{SE}(\bar{\theta})$ となった組の割合で、正規近似が成り立てば 0.95 に近い。
図は $\bar{R}$ の平均を点線でつないだ記号、$\sqrt{A^2 + (1 - A^2)/N}$ を破線、$A(\kappa)$ を水平の基準線で描き、横軸は対数にする。
$\bar{R}$ の平均の SE は記号の大きさより小さいので、表に出す。

```rust
//| id: random-von-mises-resultant-bias
//| ref: random-von-mises-resultant-bias
//| title: 平均合成ベクトル長の偏りを観測数ごとに調べる
//| run: reactive
//| uses: [random-von-mises-sample-model]
//| crates: [scioxide-core, scioxide-random, scioxide-special]
//| inputs:
//|   kappa: {"type":"range","label":"集中度 κ [-]","min":0.25,"max":10,"step":0.25,"value":3}
//|   replicates: {"type":"range","label":"反復 R [組]","min":200,"max":4000,"step":200,"value":2000}
//|   seed: {"type":"range","label":"乱数のシード [-]","min":1,"max":1000,"step":1,"value":5}
//| cases:
//|   - {"id":"weak","label":"κ = 0.25","description":"A = 0.124 に対し N = 5 の R̄ の平均は 0.417 になる。N = 5、10 では 1.96 SE が π を超えて割合は 1 になり、N = 50 では 0.89 に下がる。","inputs":{"kappa":0.25}}
//|   - {"id":"strong","label":"κ = 10","description":"A = 0.9486 で、N = 5 の偏りは 0.01 程度に縮み、平均風向の区間の割合は全ての N で 0.940 から 0.963 の間にある。","inputs":{"kappa":10}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"bias","path":"/rows/0/4","approx":{"value":0.7248609411406439,"atol":1e-9}}
//|       - {"artifact":"bias","path":"/rows/0/1","range":{"min":0.825,"max":0.86}}
//|       - {"artifact":"bias","path":"/rows/6/1","range":{"min":0.805,"max":0.816}}
//|       - {"artifact":"bias","path":"/rows/6/6","range":{"min":0.92,"max":0.98}}
//|   - case: weak
//|     expect:
//|       - {"artifact":"bias","path":"/rows/0/6","range":{"min":0.999,"max":1.0}}
//|       - {"artifact":"bias","path":"/rows/0/1","range":{"min":0.38,"max":0.45}}
//|       - {"artifact":"bias","path":"/rows/3/6","range":{"min":0.85,"max":0.93}}
//|   - case: strong
//|     expect:
//|       - {"artifact":"bias","path":"/rows/0/4","approx":{"value":0.9198733038412512,"atol":1e-9}}
use scioxide_core::RealScalar;
use scioxide_random::{Distribution, SeedableRng, SplitMix64, VonMises};

let law = VonMises::<f64>::new(0.0, kappa).map_err(|e| e.to_string())?;
let a = resultant_length(kappa)?;
let r = replicates as usize;
let mut rng = SplitMix64::from_seed(seed as u64);
let (mut rows, mut mean_points, mut theory) = (Vec::new(), Vec::new(), Vec::new());
for n in [5_usize, 10, 20, 50, 100, 200, 500] {
    let (mut sum_r, mut sum_r2, mut sum_r4, mut covered) = (0.0_f64, 0.0_f64, 0.0_f64, 0_usize);
    // 入力の κ は 0.25 以上なので、平均方向の SE は定まる。
    let se_dir = direction_se(kappa, a, n).ok_or("κ = 0 では平均方向が定まらない")?;
    for _ in 0..r {
        let (mut s, mut c) = (0.0_f64, 0.0_f64);
        for _ in 0..n {
            let theta = law.sample(&mut rng).map_err(|e| e.to_string())?;
            s += RealScalar::sin(theta);
            c += RealScalar::cos(theta);
        }
        let r_bar = RealScalar::hypot(s, c) / n as f64;
        sum_r += r_bar;
        sum_r2 += r_bar * r_bar;
        sum_r4 += r_bar * r_bar * r_bar * r_bar;
        // μ = 0 なので atan2(S, C) がそのまま平均方向の誤差になる。
        let error = RealScalar::atan2(s, c);
        if -1.96 * se_dir <= error && error <= 1.96 * se_dir {
            covered += 1;
        }
    }
    let rf = r as f64;
    let mean_r = sum_r / rf;
    let se_mean = RealScalar::sqrt((sum_r2 / rf - mean_r * mean_r) / (rf - 1.0));
    // 独立検算: 単位ベクトルの平均について E[R̄²] = A² + (1 − A²)/N。
    let mean_r2 = sum_r2 / rf;
    let expected_r2 = expected_square_length(a, n);
    let se_r2 = RealScalar::sqrt((sum_r4 / rf - mean_r2 * mean_r2) / (rf - 1.0));

    rows.push((n, mean_r, se_mean, mean_r2, expected_r2, z, coverage));
    let nf = n as f64;
    mean_points.push([nf, mean_r]);
    theory.push([nf, RealScalar::sqrt(expected_r2)]);
}
```

$\bar{R}^2$ の平均はこの範囲でも $A^2 + (1 - A^2)/N$ から 1.33 SE 以内にあり、正確な式は $N$ と $\kappa$ によらず使える。
ケース「κ = 10」では $N = 5$ の偏りが 0.01 程度に縮み、割合は全ての $N$ で 0.940 から 0.963 の間にある。

## 観測データの円周統計

このページは母数を既知として標本を作った。
観測した風向から平均方向、平均合成ベクトル長、円周分散を求める関数は、scioxide-stats の `statistic` と `Statistic::circular` にある。
von Mises 分布の $\kappa$ を $\bar{R}$ から推定するときは $A(\hat{\kappa}) = \bar{R}$ を解くが、小さい $N$ では上の偏りがそのまま $\hat{\kappa}$ の過大評価になる。

## まとめ

標本の $\bar{R}$ は $E[\bar{R}^2] = A^2 + (1 - A^2)/N$ のとおり上向きに偏るので、$\kappa$ が小さいときや $N$ が数十以下のときは $A$ ではなく $\sqrt{A^2 + (1 - A^2)/N}$ と比べる。
一様な風向（$\kappa = 0$）でも $\bar{R}$ は $1/\sqrt{N}$ 程度の値をとるので、小さい $\bar{R}$ を集中の証拠として読まない。
平均方向の SE $1/\sqrt{N\kappa A}$ は $A\sqrt{N}$ が 1 より十分大きいときだけ使い、$\kappa \to 0$ では平均方向が定まらない。
24 方位の度数はビンの確率に二項分布の SE を付けた範囲で密度と比べられる。
