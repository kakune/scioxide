需要のシミュレーション、粒子フィルタのリサンプリング、確率的な行動の選択では、非負の重み $w_0, \dots, w_{K-1}$ に比例する確率でカテゴリを選ぶ。
この例題は `WeightedSampler` で同じ重みから何度も添字を抽出し、観測比率が確率にどう近づくか、まれなカテゴリの比率がどれだけ不確かかを、多項分布と二項分布の理論で確かめる。
別名表の構成は[重み付きの添字とエイリアス法](oxref:random-discrete-alias-method)でも説明している。

## 重みから確率へ

カテゴリ $i$ の確率は

$$
p_i = \frac{w_i}{\sum_{j} w_j}
$$

で、重みを共通の正の定数倍しても変わらない。
`WeightedSampler::new(&weights)` は、重みを正の重みの最大値で割ってから補償付きの和（Neumaier の方法）で正規化し、Walker–Vose の別名表を作る。
最大値で割るので、`f32::MAX` が並ぶような重みでも和が桁あふれしない。
重みは和が 1 である必要はない。

重みは有限で非負でなければならない。
空の配列、負の値を含む配列、正の重みが一つもない配列は `InvalidInput`、NaN や無限大を含む配列は `NonFinite` になる。
重み 0 のカテゴリは抽出されない。
表の構築は $O(K)$ の時間とメモリ領域を使い、一回の抽出は期待 $O(1)$ の時間でメモリ領域を確保しない。

## エイリアス法が各カテゴリの確率を再現する理由

別名表は $K$ 本の列のそれぞれに保持確率 $F_i \in [0, 1]$ と別名 $A_i$ を一つずつ持つ。
一回の抽出は列 $i$ を確率 $1/K$ で一様に選び、一様乱数 $u$ が $F_i$ より小さければ $i$、そうでなければ $A_i$ を返す。
したがって、カテゴリ $i$ が返る確率は

$$
\Pr(\text{返る値} = i) = \frac{1}{K}\Bigl(F_i + \sum_{j:\,A_j = i} (1 - F_j)\Bigr)
$$

である。

Vose の構成は拡大した質量 $q_i = K p_i$（平均がちょうど 1）を、$q_i < 1$ の列と $q_i \ge 1$ の列の組で埋めていく。
質量の足りない列 $j$ は $F_j = q_j$ とし、残り $1 - q_j$ を質量の余る列 $i$ に別名として割り当て、$q_i$ から $1 - q_j$ を引く。
引いたあとの $q_i$ が 1 未満になれば、列 $i$ は質量の足りない側に移る。
一回の組で一本の列が確定するので、構成は $O(K)$ で終わる。
各列の高さ 1 の箱が二つのカテゴリの質量だけで埋まるので、上の和は $q_i/K = p_i$ に等しくなる。
最後に残った列は、丸めの誤差を除けば質量がちょうど 1 なので、$F_i = 1$ とする。
重み 0 のカテゴリの列は丸めで残った質量を捨てて保持確率を 0 にし、別名を正の重みのカテゴリに向ける。

抽出の形は添字を返す `sample_index(rng)`、値の配列から借用を返す `sample(rng, &values)`、$n$ 個の添字を所有の `Vec` で返す `sample_n(rng, n)`、呼び出し側の出力に書く `sample_n_into(rng, policy, output, workspace)` の四つである。
一回の抽出は列を選ぶ偏りのない整数の抽出 `uniform_index`（[Lemire の棄却](oxref:random-sampling-lemire)で剰余の偏りを除く）と、保持確率と比べる `next_float` を一つずつ使う。

## 多項分布の揺らぎ

独立に $N$ 回抽出した度数 $(C_0, \dots, C_{K-1})$ は多項分布 $\mathrm{Multinomial}(N, \mathbf{p})$ に従い、各 $C_i$ は二項分布 $\mathrm{Binomial}(N, p_i)$ に従う。
$C_i$ は $N$ 回の独立な 0/1 の試行の和で、一回の分散は $p_i(1 - p_i)$ なので、観測比率 $\hat{p}_i = C_i/N$ の標準誤差は

$$
\mathrm{SE}(\hat{p}_i) = \sqrt{\frac{p_i(1-p_i)}{N}}
$$

で、半分にするには $N$ を 4 倍にする。

確率の小さいカテゴリ $r$ では、絶対誤差 $|\hat{p}_r - p_r|$ が小さく見えても、相対的な不確かさ

$$
\frac{\mathrm{SE}(\hat{p}_r)}{p_r} = \sqrt{\frac{1 - p_r}{N p_r}} \approx \frac{1}{\sqrt{N p_r}}
$$

は大きい。
期待度数 $N p_r = 1$ でも、度数が 0 になる確率は $(1 - p_r)^N \approx e^{-1} \approx 0.368$ である。
期待度数が小さいときは正規近似の $z$ が使えないので、度数 $c$ そのものを二項分布の両側の確率 $\Pr(C_r \le c)$ と $\Pr(C_r \ge c)$ で読む。

全体の当てはまりは Pearson の統計量

$$
X^2 = \sum_{i=0}^{K-1} \frac{(C_i - N p_i)^2}{N p_i}
$$

で調べる。
各項の期待値は $\mathrm{Var}(C_i)/(N p_i) = 1 - p_i$ なので、$\mathrm{E}[X^2] = \sum_i (1 - p_i) = K - 1$ が $N$ によらず成り立つ。
さらにすべての $N p_i$ が 5 程度以上なら、$X^2$ は近似的に自由度 $K - 1$ のカイ二乗分布に従う。
度数の和が $N$ に固定されるので、独立な項は $K - 1$ 個に減る。

## 品種の重みと抽出回数

五つの製品品種の受注の重みを $[40, 25, 20, 10, w_r]$ とし、まれな品種の重み $w_r$、抽出回数 $N$、乱数のシードを動かす。
次のセルは品種ごとの標準化した差 $z_i = (\hat{p}_i - p_i)/\mathrm{SE}(\hat{p}_i)$ を棒グラフにし、$\pm 2$ の線と比べる。
二つ目のグラフは先頭からの抽出回数 $n$ に対する最大の絶対誤差 $\max_i |\hat{p}_i - p_i|$ を、最も揺らぎの大きい品種の標準誤差 $\max_i \sqrt{p_i(1-p_i)/n}$（破線）と両対数で比べる。
確率 $p_i$ はセルの中で重みを直接正規化して求め、別名表を通さない。

一つ目の表は品種ごとの確率、度数、観測比率、標準誤差、$z_i$ を出す。
二つ目の表は $X^2$ を自由度 4 のカイ二乗分布の 2.5% 点、97.5% 点、上側確率と比べ、これらは `ChiSquared::quantile` と `Survival::sf` で求める。
三つ目の表はまれな品種の度数 $c$ を `Binomial::new(N, p_r)` の `cdf(c)` と `sf(c - 1)` から求めた $\Pr(C_r \le c)$、$\Pr(C_r \ge c)$ と比べる。

//| inputs:
//|   rare_weight: {"type":"range","label":"まれな品種の重み wᵣ [-]","description":"小さくすると期待度数 N pᵣ が減り、相対的な不確かさが増える。","min":0.5,"max":15,"step":0.5,"value":5}

//|     expect:
//|       - {"artifact":"rare","path":"/rows/0/0","approx":{"value":10.7225,"atol":1e-3}}
//|       - {"artifact":"rare","path":"/rows/0/2","approx":{"value":0.3047,"atol":1e-3}}

//|     expect:

// 独立検算の基準: 重みを直接正規化した確率 pᵢ = wᵢ / Σw。

let mut rng = SplitMix64::from_seed(sampling_seed.round() as u64);
let n = draw_count.round() as usize;
let (mut counts, mut curve, mut reference) =

let largest_variance = expected
    .iter()
    .map(|p| p * (1.0 - p))
    .fold(0.0_f64, f64::max);
let checkpoint = (n / 32).max(1);
for draw in 1..=n {
    counts[sampler.sample_index(&mut rng).map_err(|e| e.to_string())?] += 1;
    if draw % checkpoint == 0 {
        // 先頭 draw 回の観測比率と確率の差の最大値（誤差 0 の点は対数軸に描けないので除く）。
        let error = counts
            .iter()
            .zip(&expected)
            .map(|(&c, &p)| (c as f64 / draw as f64 - p).abs())
            .fold(0.0, f64::max);
        if error > 0.0 {
            curve.push([draw as f64, error]);
        }
        reference.push([
            draw as f64,
            RealScalar::sqrt(largest_variance / draw as f64),
        ]);

    chi_square += (c - nf * p) * (c - nf * p) / (nf * p);
    rows.push((
        labels[i],
        weights[i],
        p,
        counts[i],
        c / nf,
        se,
        (c / nf - p) / se,
    ));
}

        ]
    })
);

    &vec![
        serde_json::json!({"name": "最大の絶対誤差", "points": curve, "style": {"symbol": "circle"}}),
        serde_json::json!({
            "name": "最大の標準誤差 max √(pᵢ(1 − pᵢ)/n)",
            "points": reference,
            "style": {"lineType": "dashed"}
        }),
    ],
    options = &serde_json::json!({
        "xLabel": "先頭からの抽出回数 n [回]",
        "yLabel": "max |観測比率 − 確率| [-]",
        "xType": "log",
        "yType": "log"
    })
);
let category_columns = serde_json::json!([
    { "key": "0", "label": "品種" },
    { "key": "1", "label": "重み [-]", "type": "number", "format": sig3 },
    { "key": "2", "label": "確率 pᵢ [-]", "type": "number", "format": sig4 },
    { "key": "3", "label": "度数 Cᵢ [回]", "type": "integer" },
    { "key": "4", "label": "観測比率 [-]", "type": "number", "format": sig4 },

    { "key": "6", "label": "z [-]", "type": "number", "format": fixed2 }
]);

    category_columns,
    rows,
    metadata = serde_json::json!({ "id": "categories" })
);

    { "key": "0", "label": "Pearson の X² [-]", "type": "number", "format": fixed2 },
    { "key": "1", "label": "期待値 K − 1 [-]", "type": "integer" },
    { "key": "2", "label": "χ²₄ の 2.5% 点 [-]", "type": "number", "format": sig4 },
    { "key": "3", "label": "χ²₄ の 97.5% 点 [-]", "type": "number", "format": sig4 },
    { "key": "4", "label": "上側確率 P(χ²₄ ≥ X²) [-]", "type": "number", "format": sig3 }

        nf * p_rare,

棒グラフでは、各品種の $z_i$ がおおむね $\pm 2$ の線の内側に並ぶ。
一本ずつの棒が $\pm 2$ の外に出る確率は約 4.6% なので、五本のうち一本が少し外に出ることは珍しくない。
別名表の構成を誤っていれば、同じ品種の棒がシードを変えても同じ向きに外れ続ける。
折れ線の最大絶対誤差は破線の $n^{-1/2}$ の傾きに沿って上下しながら下がる。
破線より桁違いに上で平らになるなら、確率そのものが誤っている。

既定の入力（$w_r = 5$、$N = 2048$、シード 29）では、まれな品種の確率は $0.05$、期待度数 $102.4$ に対して度数は 82 で、$z = -2.07$、相対的な不確かさは $0.096$ だった。
二項分布の下側確率は $\Pr(C_r \le 82) = 0.019$ で、正規近似の $\Phi(-2.07) \approx 0.019$ と合う。
一つの品種だけを見ると 2 標準誤差を少し超えるが、五つの品種をまとめた $X^2 = 6.59$ は、自由度 4 の 2.5% 点 $0.48$ と 97.5% 点 $11.14$ の間に入り、上側確率は $0.159$ である。
シードを 1 にすると、まれな品種の度数は 118 で $z = 1.58$、$X^2 = 3.54$ になる。

$w_r = 0.5$ にすると $p_r \approx 0.0052$ で、$N = 2048$ でも期待度数は $10.7$、相対的な不確かさは $0.305$ になる。
さらに $N = 256$ まで減らすと期待度数は約 $1.3$ で、$X^2$ のカイ二乗近似の前提（期待度数 5 程度以上）を満たさない。
このときの度数 1 は $\Pr(C_r \le 1) = 0.612$、$\Pr(C_r \ge 1) = 0.739$ で、二項分布のどちらの裾にも寄っていない。

## 結果の読み方

観測比率の差はその品種の標準誤差 $\sqrt{p_i(1-p_i)/N}$ を単位にした $z_i$ で読む。
まれな品種は、差の絶対値が小さくても相対的な不確かさが大きいので、期待度数 $N p_r$ が十分大きくなるまで比率から確率を結論しない。
期待度数が小さいときは、度数を二項分布の両側の確率で読む。
$X^2$ は正しい標本化器でもシードを変えると約 5% の確率で 95% 区間の外に出るので、一つのシードの値ではなく、シードを変えたときの分布として解釈する。
同じ重みから多数回抽出するなら、表を一度作って `sample_index` や `sample_n_into` を繰り返す。

## まとめ

`WeightedSampler` は重みを最大値で割って正規化した別名表を $O(K)$ で一度作り、一回の抽出を偏りのない整数の抽出と浮動小数点数一つで行う。
別名表の各列は二つのカテゴリの質量だけで埋まり、列を一様に選ぶと各カテゴリの確率がちょうど $p_i$ になる。
観測比率は確率のまわりに $\sqrt{p_i(1-p_i)/N}$ の幅で揺らぎ、最大の絶対誤差は $N^{-1/2}$ 程度で減る。
まれな品種の比率は期待度数 $N p_r$ が小さいうちは相対的に大きく揺らぐので、度数を二項分布の裾の確率で読む。
全体の当てはまりは Pearson の $X^2$（期待値 $K - 1$）をカイ二乗分布の分位点と比べて判断する。
