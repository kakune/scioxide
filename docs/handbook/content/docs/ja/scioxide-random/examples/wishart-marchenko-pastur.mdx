[Wishart 分布と標本共分散行列](../wishart-sample-covariance/)では、散布行列 $W$ の成分ごとの平均と分散を確かめた。
成分がそれぞれ偏りなく推定できても、行列の固有値は偏る。
次元 $p$ が観測数 $n$ に比べて無視できないと、真の共分散行列の固有値が全て等しくても、標本共分散行列の固有値は大きく広がる。
このページは $\Sigma = I$ の `Wishart` から $S = W/n$ を作り、scioxide-linalg の対称固有値で求めた固有値の分布を Marchenko–Pastur 則と比べる。

## 固有値の広がりと Marchenko–Pastur 則

$\Sigma = I$ のとき、$p, n \to \infty$、$p/n \to \gamma \in (0, 1]$ の極限で、$S = W/n$ の固有値の分布は密度

$$
f(\lambda) = \frac{\sqrt{(\lambda_+ - \lambda)(\lambda - \lambda_-)}}{2\pi\gamma\lambda},
\qquad \lambda_\pm = (1 \pm \sqrt{\gamma})^2,
\qquad \lambda_- \le \lambda \le \lambda_+
$$

に近づく（Marchenko–Pastur 則）。
母集団の固有値は全て 1 なのに、標本の固有値は $[\lambda_-, \lambda_+]$ に広がり、最大固有値は 1 を上回り、最小固有値は 1 を下回る。
主成分分析で標本共分散行列の最大固有値をそのまま母集団の値と読むと、この偏りの分だけ過大に見積もる。

固有値の平均は $\operatorname{tr}(S)/p$ で、$\operatorname{tr} W$ は $np$ 個の独立な標準正規変数の二乗和なので、$E[\operatorname{tr} W] = np$、$\operatorname{Var}(\operatorname{tr} W) = 2np$ である。
したがって固有値の平均は 1 で、1 回の行列あたりの SE は $\sqrt{2/(np)}$ になる。
有限の $p$ では、最大固有値は $n^{-2/3}$ 程度の尺度で揺らぎ（Tracy–Widom 分布）、その平均は端 $\lambda_+$ のやや内側に来る。
同じ理由で、台の外にも少数の固有値が出る。

## 固有値の計算

`HermitianEigenvaluesResult::compute(&s, HermitianInput::Exact)` は、対称行列の固有値を全て昇順に返す。
行列を最大の成分の大きさで尺度をそろえてから、Householder 変換で 3 重対角化し、平方根を使わない QL/QR 反復で固有値を求める。
計算量は $O(p^3)$、メモリ領域は $O(p^2)$ である。
`Exact` は成分が正確に対称であることを要求し、そうでない行列は `InvalidInput` になる。
`Wishart` の標本は $(i, j)$ 成分と $(j, i)$ 成分が同じ値なので、$n$ で割っても `Exact` で渡せる。

次のセルは次元 $p$（10–100）、自由度 $n$（100–1000）、反復 $R$（2–20 回）、シードを受け取り、$\Sigma = I$ の `Wishart` から $R$ 個の行列を引く。
$p = 41$ 以上では作業量が既定の上限を超えるので、構築時に上限を $p^3$ に上げる。
1 回の標本化と固有値計算はどちらも $O(p^3)$ の演算で、$p = 100$、$R = 20$ では 1 回あたり $10^6$ 程度の演算を 20 回繰り返すので、セルはボタンで実行する。
図は全ての固有値を幅 0.1 のビンに集めた密度を記号、Marchenko–Pastur の密度を破線で描き、台の両端と母集団の固有値 1 に基準線を引く。
1 つ目の表は固有値の平均と、最小固有値と最大固有値を反復で平均した値とその SE を出す。
2 つ目の表は台の外に出た固有値の個数を出す。

```rust
//| id: random-wishart-marchenko-pastur
//| ref: random-wishart-marchenko-pastur
//| title: W/n の固有値の分布を Marchenko–Pastur 則と比べる
//| run: button
//| crates: [scioxide-core, scioxide-linalg, scioxide-random]
//| inputs:
//|   dimension: {"type":"range","label":"次元 p [-]","min":10,"max":100,"step":10,"value":50}
//|   degrees: {"type":"range","label":"自由度 n [-]","min":100,"max":1000,"step":50,"value":200}
//|   replicates: {"type":"range","label":"反復 R [回]","min":2,"max":20,"step":1,"value":10}
//|   seed: {"type":"range","label":"乱数のシード [-]","min":1,"max":1000,"step":1,"value":3}
//| cases:
//|   - {"id":"square","label":"p = n = 100","description":"γ = 1 で台は [0, 4] になり、密度は 0 で発散する。最小固有値の平均は 5×10⁻⁵ まで下がる。","inputs":{"dimension":100,"degrees":100,"replicates":20}}
//|   - {"id":"tall","label":"p = 10、n = 1000","description":"γ = 0.01 で台は [0.81, 1.21] に縮む。p = 10 では端の近似が粗く、最大固有値の平均は 1.158 である。","inputs":{"dimension":10,"degrees":1000}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"edges","path":"/rows/0/1","range":{"min":0.98,"max":1.02}}
//|       - {"artifact":"edges","path":"/rows/1/3","approx":{"value":0.25,"atol":1e-12}}
//|       - {"artifact":"edges","path":"/rows/2/3","approx":{"value":2.25,"atol":1e-12}}
//|       - {"artifact":"edges","path":"/rows/2/1","range":{"min":2.05,"max":2.3}}
//|   - case: square
//|     expect:
//|       - {"artifact":"edges","path":"/rows/2/3","approx":{"value":4,"atol":1e-12}}
//|       - {"artifact":"edges","path":"/rows/1/1","range":{"min":0,"max":0.01}}
//|   - case: tall
//|     expect:
//|       - {"artifact":"edges","path":"/rows/1/3","approx":{"value":0.81,"atol":1e-12}}
//|       - {"artifact":"edges","path":"/rows/2/1","range":{"min":1.1,"max":1.25}}
use scioxide_core::{Budget, RealScalar};
use scioxide_linalg::{HermitianEigenvaluesResult, HermitianInput, Matrix};
use scioxide_random::{LawOptions, SeedableRng, SplitMix64, Wishart};

let (p, n, r) = (dimension as usize, degrees as usize, replicates as usize);
let identity = Matrix::<f64>::identity(p).map_err(|e| e.to_string())?;
// 構築は p³ の作業が上限に収まるかを確かめる。既定の 65 536 は p ≤ 40 までなので、p³ に上げる。
let work = Budget::try_from(p * p * p).map_err(|e| e.to_string())?;
let options = LawOptions::default().with_work_budget(work);
let law = Wishart::with_options(n as f64, &identity, options).map_err(|e| e.to_string())?;
let mut rng = SplitMix64::from_seed(seed as u64);
let gamma = p as f64 / n as f64;
let (low, high) = (
    RealScalar::powi(1.0 - RealScalar::sqrt(gamma), 2),
    RealScalar::powi(1.0 + RealScalar::sqrt(gamma), 2),
);
let mut values = Vec::with_capacity(p * r);
let (mut smallest, mut largest) = (Vec::with_capacity(r), Vec::with_capacity(r));
for _ in 0..r {
    let w = law.sample(&mut rng).map_err(|e| e.to_string())?;
    // S = W/n の固有値。Wishart の標本は成分ごとに対称なので Exact で渡せる。
    let s = Matrix::from_vec(p, p, w.iter().map(|v| v / n as f64).collect())
        .map_err(|e| e.to_string())?;
    let eigen = HermitianEigenvaluesResult::compute(&s, HermitianInput::Exact)
        .map_err(|e| e.to_string())?;
    let lambda = eigen.eigenvalues();
    smallest.push(lambda[0]);
    largest.push(lambda[p - 1]);
    values.extend_from_slice(lambda);
}
// 0 から 4 までを幅 0.1 の 40 個のビンに分け、度数を密度に直す。
let bins = 40;
let width = 4.0 / bins as f64;
let mut counts = vec![0_usize; bins];
for &v in &values {
    if v < 4.0 {
        counts[(v / width) as usize] += 1;
    }
}
let histogram: Vec<[f64; 2]> = counts
    .iter()
    .enumerate()
    .map(|(k, &c)| {
        [
            (k as f64 + 0.5) * width,
            c as f64 / (values.len() as f64 * width),
        ]
    })
    .collect();
// 独立検算: Marchenko–Pastur の密度 √((λ₊ − λ)(λ − λ₋)) / (2π γ λ)。
let mut density = Vec::new();
for k in 1..400 {
    let x = low + (high - low) * k as f64 / 400.0;
    let f =
        RealScalar::sqrt((high - x) * (x - low)) / (2.0 * core::f64::consts::PI * gamma * x);
    density.push([x, f]);
}
emit_chart!(
    serde_json::json!({
        "kind": "xy",
        "xLabel": "W/n の固有値 λ [-]",
        "yLabel": "確率密度 [-]",
        "xMin": 0,
        "xMax": 4,
        "yMin": 0,
        "dataZoom": true,
        "tooltip": true,
        "annotations": [
            {"kind": "line", "axis": "x", "value": low, "label": "(1 − √γ)²"},
            {"kind": "line", "axis": "x", "value": high, "label": "(1 + √γ)²"},
            {"kind": "line", "axis": "x", "value": 1.0, "label": "Σ の固有値 1"}
        ],
        "layers": [
            {
                "id": "mp",
                "kind": "line",
                "name": "Marchenko–Pastur の密度",
                "style": {"lineType": "dashed"},
                "points": density
            },
            {"id": "sample", "kind": "scatter", "name": "固有値のヒストグラム", "points": histogram}
        ]
    }),
    metadata = serde_json::json!({ "id": "spectrum" })
);
// 反復の間の平均と SE。固有値の平均の SE は Var tr(W) = 2np から √(2/(npR))。
let summary = |v: &[f64]| {
    let rf = v.len() as f64;
    let mu = v.iter().sum::<f64>() / rf;
    let var = v.iter().map(|x| (x - mu) * (x - mu)).sum::<f64>() / (rf - 1.0);
    (mu, RealScalar::sqrt(var / rf))
};
let (min_mean, min_se) = summary(&smallest);
let (max_mean, max_se) = summary(&largest);
let mean = values.iter().sum::<f64>() / values.len() as f64;
let mean_se = RealScalar::sqrt(2.0 / (n * p * r) as f64);
let outside = values.iter().filter(|&&v| v < low || v > high).count();
let sig4 = serde_json::json!({ "significantDigits": 4 });
let sig2 = serde_json::json!({ "significantDigits": 2 });
let columns = serde_json::json!([
    { "key": "0", "label": "量" },
    { "key": "1", "label": "標本値 [-]", "type": "number", "format": sig4 },
    { "key": "2", "label": "SE [-]", "type": "number", "format": sig2 },
    { "key": "3", "label": "比較の値 [-]", "type": "number", "format": sig4 }
]);
emit_table_with_columns!(
    columns,
    vec![
        ("固有値の平均 tr(W)/(np)", mean, mean_se, 1.0),
        ("最小固有値の平均（比較は λ₋）", min_mean, min_se, low),
        ("最大固有値の平均（比較は λ₊）", max_mean, max_se, high),
    ],
    metadata = serde_json::json!({ "id": "edges" })
);
let columns = serde_json::json!([
    { "key": "0", "label": "γ = p/n [-]", "type": "number", "format": sig4 },
    { "key": "1", "label": "台の外の固有値 [個]", "type": "integer" },
    { "key": "2", "label": "固有値の総数 [個]", "type": "integer" }
]);
emit_table_with_columns!(
    columns,
    vec![(gamma, outside, values.len())],
    metadata = serde_json::json!({ "id": "outside" })
);
```

既定の入力（$p = 50$、$n = 200$、$\gamma = 0.25$、$R = 10$ 回、シード 3）では、台は $[0.25, 2.25]$ で、ヒストグラムは破線の密度に沿う。
固有値の平均は 1.0014（SE 0.0045）である。
最小固有値の平均は 0.272（SE 0.006）、最大固有値の平均は 2.191（SE 0.022）で、どちらも台の端の少し内側にある。
母集団の固有値 1 に対し、標本の最大固有値は 2.19 倍、最小固有値は 0.27 倍で、$n = 4p$ の観測でもこの広がりが残る。
500 個の固有値のうち 4 個が台の外にあり、有限の $p$ では端の外にも固有値が出る。

ケース「p = n = 100」では $\gamma = 1$ で台は $[0, 4]$ になり、最小固有値の平均は $5.0 \times 10^{-5}$ まで下がる。
最大固有値の平均 3.867 は端 4 から SE 0.022 の 6 倍内側にあり、2000 個のうち台の外は 1 個である。
$p = n$ の標本共分散行列は特異に近く、そのまま逆行列を作ると数値的に不安定になる。
ケース「p = 10、n = 1000」では $\gamma = 0.01$ で台は $[0.81, 1.21]$ に縮むが、最大固有値の平均 1.158 は端 1.21 から離れる。
$p = 10$ では Marchenko–Pastur 則は台の大きさの目安で、端の位置の近似は粗い。

## まとめ

$\Sigma = I$ でも $W/n$ の固有値は $[(1 - \sqrt{\gamma})^2, (1 + \sqrt{\gamma})^2]$ に広がるので、標本共分散行列の最大固有値は母集団の値を過大に、最小固有値は過小に見積もる。
固有値の平均 $\operatorname{tr}(W)/(np)$ は 1 のままで、偏るのは固有値の広がりである。
$p = n$ に近い標本共分散行列は特異に近いので、逆行列を使う計算の前に $p/n$ を確かめる。
`Wishart` の標本は正確に対称なので、`HermitianEigenvaluesResult::compute` に `HermitianInput::Exact` で渡せる。
