複数の観測点で測った気温偏差、複数資産の収益、多チャンネルの信号のように、同時に測った量の関係は共分散行列で表す。
共分散行列の推定値である標本共分散行列は、それ自体が確率的に揺れる行列で、正規分布の標本ではその分布が Wishart 分布になる。
このページは `Wishart` で散布行列を生成し、平均と成分の分散を手計算の閉形式と `MultivariateNormal` の散布行列で照合する。
次元が観測数に比べて無視できないときの固有値の広がりは、[標本共分散行列の固有値と Marchenko–Pastur 則](../wishart-marchenko-pastur/)で調べる。

## Wishart 分布と散布行列

$x_1, \dots, x_n$ を独立な $N_p(0, \Sigma)$ のベクトルとすると、散布行列 $W = \sum_{t=1}^n x_t x_t^\mathsf{T}$ は自由度 $n$、尺度行列 $\Sigma$ の Wishart 分布 $W_p(n, \Sigma)$ に従う。
$p = 1$ では $W/\sigma^2$ が自由度 $n$ のカイ二乗分布に従い、Wishart 分布はその行列への拡張である。
Wishart 分布は実数の自由度 $n > p - 1$ でも定義され、そのときは $n$ 個のベクトルの和としての解釈を持たない。

平均は $E[W] = n\Sigma$ である。
正規ベクトルの 4 次モーメント $E[x_i x_j x_k x_l] = \Sigma_{ij}\Sigma_{kl} + \Sigma_{ik}\Sigma_{jl} + \Sigma_{il}\Sigma_{jk}$（Isserlis の公式）から $E[x_i^2 x_j^2] = \Sigma_{ii}\Sigma_{jj} + 2\Sigma_{ij}^2$ なので $\operatorname{Var}(x_i x_j) = \Sigma_{ij}^2 + \Sigma_{ii}\Sigma_{jj}$ となり、独立な $n$ 項の和について

$$
\operatorname{Var}(W_{ij}) = n\left(\Sigma_{ij}^2 + \Sigma_{ii}\Sigma_{jj}\right)
$$

が成り立つ。
平均が 0 と分かっているとき、$S = W/n$ は $\Sigma$ の不偏推定量である。
平均を標本平均 $\bar{x}$ で推定すると、$\sum_t (x_t - \bar{x})(x_t - \bar{x})^\mathsf{T}$ は $W_p(n - 1, \Sigma)$ に従い、不偏推定量は $n - 1$ で割ったものになる。

例題では $p$ 地点で測った日平均気温の偏差（単位 K）を想定し、尺度行列を $\Sigma_{ij} = \sigma^2\rho^{|i-j|}$ とする。
これは定常な 1 次の自己回帰過程の共分散である。
先頭の $k$ 行 $k$ 列の小行列も同じ形で、その行列式は $\sigma^{2k}(1 - \rho^2)^{k-1}$ なので、$|\rho| < 1$ なら全ての $k$ で正になる。
したがって Sylvester の判定法から、$|\rho| < 1$ の $\Sigma$ は全ての $p$ で正定値である。

## Bartlett 分解による生成

$\Sigma = LL^\mathsf{T}$ を Cholesky 分解し、下三角行列 $A$ の対角に $A_{ii} = \sqrt{\chi^2_{n-i+1}}$（$i = 1, \dots, p$）、対角より下に独立な標準正規変数を置くと、$W = L A A^\mathsf{T} L^\mathsf{T}$ は $W_p(n, \Sigma)$ に従う（Bartlett 分解）。
`Wishart::new(df, &scale)` は尺度行列の Cholesky 分解と $p$ 個のカイ二乗の標本化の定数を準備する。
空の行列や正方でない行列は `InvalidInput`、非有限の値は `NonFinite`、$\mathrm{df} \le p - 1$ は `DomainError` になり、正定値でない尺度行列は Cholesky 分解のエラーを返す。
カイ二乗変数は Gamma 変数の対数から作るので、小さい非整数の自由度でも対角が 0 に丸められにくい。
それでも対角が 0 に丸められた標本は、`NumericalInstability` のエラーになる。
`sample(&mut rng)` は $p \times p$ の行列を行優先で並べた長さ $p^2$ の `Vec` を返し、1 回の標本化の計算量は $O(p^3)$ である。

構築は、$p^3$ 回分の作業が `LawOptions` の作業量の上限に収まるかを確かめる。
既定の上限は 65 536 回なので、既定のままでは $p \le 40$ に限られ、それより大きい $p$ では `ConvergenceFailure` が返る。
大きい $p$ では `Wishart::with_options(df, &scale, options)` に `LawOptions::default().with_work_budget(Budget::try_from(p * p * p)?)` を渡して上限を上げる。
`InverseWishart::new(df, &scale)` は、尺度行列を $\Psi$ として $X^{-1} \sim W_p(\mathrm{df}, \Psi^{-1})$ となる $X$ の分布で、コンストラクターの形とエラーは `Wishart` と同じである。

比較に使う `MultivariateNormal::new(&mean, &covariance)` は共分散行列の対称固有分解を $O(p^3)$ で準備し、正則な共分散では 1 回の標本化が $O(p^2)$ である。
その散布行列は Bartlett 分解を通らないので、`Wishart` の標本化とは独立な検算になる。

## 平均と分散の照合

次のセルは地点数 $p$（2–6）、日数 $n$（7–60 日）、偏差の分散 $\sigma^2$ [K²]、隣の地点との相関 $\rho$（−0.9–0.9）、反復 $R$（500–5000 回）、シードを受け取る。
各反復で、`Wishart` の標本 1 個と、`MultivariateNormal` の $n$ 個のベクトルから作った 2 つの散布行列を作る。
1 つは原点の周りの $\sum_t x_t x_t^\mathsf{T}$、もう 1 つは標本平均の周りの $\sum_t (x_t - \bar{x})(x_t - \bar{x})^\mathsf{T}$ である。
1 つ目の表は成分 $(1,1)$、$(1,2)$、$(2,2)$ の平均を $n\Sigma$ と $(n - 1)\Sigma$ に比べ、平均の SE は手計算の分散から $\sqrt{\operatorname{Var}(W_{ij})/R}$ で求める。
2 つ目の表は成分の標本分散と、4 次の中心モーメント $\mu_4$ から求めた SE $\sqrt{(\mu_4 - s^4)/R}$ を、$n(\Sigma_{ij}^2 + \Sigma_{ii}\Sigma_{jj})$ と比べる。

```rust
//| id: random-wishart-moments
//| ref: random-wishart-moments
//| title: Wishart 行列と正規ベクトルの散布行列の平均と分散を比べる
//| run: reactive
//| crates: [scioxide-core, scioxide-linalg, scioxide-random]
//| inputs:
//|   dimension: {"type":"range","label":"地点数 p [地点]","min":2,"max":6,"step":1,"value":3}
//|   degrees: {"type":"range","label":"日数（自由度）n [日]","min":7,"max":60,"step":1,"value":10}
//|   variance: {"type":"range","label":"偏差の分散 σ² [K²]","min":0.5,"max":4,"step":0.5,"value":1}
//|   rho: {"type":"range","label":"隣の地点との相関 ρ [-]","min":-0.9,"max":0.9,"step":0.1,"value":0.5}
//|   replicates: {"type":"range","label":"反復 R [回]","min":500,"max":5000,"step":500,"value":2000}
//|   seed: {"type":"range","label":"乱数のシード [-]","min":1,"max":1000,"step":1,"value":11}
//| cases:
//|   - {"id":"negative","label":"ρ = −0.9","description":"Σ₁₂ = −0.9 K² で、E[W₁₂] = −9 K²、Var(W₁₂) = 18.1 K⁴ になる。","inputs":{"rho":-0.9}}
//|   - {"id":"near-singular","label":"p = 6、n = 7","description":"自由度が次元に近く W は特異に近いが、平均 nΣ と分散の式はそのまま成り立つ。","inputs":{"dimension":6,"degrees":7}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"means","path":"/rows/0/5","approx":{"value":10,"atol":1e-12}}
//|       - {"artifact":"means","path":"/rows/1/5","approx":{"value":5,"atol":1e-12}}
//|       - {"artifact":"means","path":"/rows/0/1","range":{"min":9.6,"max":10.4}}
//|       - {"artifact":"means","path":"/rows/1/3","range":{"min":4.6,"max":5.4}}
//|       - {"artifact":"means","path":"/rows/0/7","range":{"min":8.6,"max":9.4}}
//|       - {"artifact":"spreads","path":"/rows/1/7","approx":{"value":12.5,"atol":1e-12}}
//|       - {"artifact":"spreads","path":"/rows/1/1","range":{"min":10.5,"max":14.5}}
//|   - case: negative
//|     expect:
//|       - {"artifact":"means","path":"/rows/1/5","approx":{"value":-9,"atol":1e-12}}
//|       - {"artifact":"spreads","path":"/rows/1/7","approx":{"value":18.1,"atol":1e-12}}
//|   - case: near-singular
//|     expect:
//|       - {"artifact":"means","path":"/rows/0/5","approx":{"value":7,"atol":1e-12}}
//|       - {"artifact":"spreads","path":"/rows/0/7","approx":{"value":14,"atol":1e-12}}
//|       - {"artifact":"spreads","path":"/rows/0/1","range":{"min":11,"max":17}}
use scioxide_core::RealScalar;
use scioxide_linalg::Matrix;
use scioxide_random::{MultivariateNormal, SeedableRng, SplitMix64, Wishart};

let (p, n, r) = (dimension as usize, degrees as usize, replicates as usize);
// Σ_ij = σ² ρ^|i−j|（AR(1) 型の相関）。|ρ| < 1 なら全ての p で正定値になる。
let sigma: Vec<f64> = (0..p * p)
    .map(|k| variance * RealScalar::powi(rho, (k / p).abs_diff(k % p) as i32))
    .collect();
let scale = Matrix::from_vec(p, p, sigma.clone()).map_err(|e| e.to_string())?;
let wishart = Wishart::new(n as f64, &scale).map_err(|e| e.to_string())?;
let normal = MultivariateNormal::new(&vec![0.0; p], &scale).map_err(|e| e.to_string())?;
let mut rng = SplitMix64::from_seed(seed as u64);
let entries = [(0, 0), (0, 1), (1, 1)];
// draws[s][e] は 3 種類の行列 s（Wishart、原点の散布、標本平均の散布）の成分 e の値の列。
let mut draws = vec![vec![Vec::with_capacity(r); entries.len()]; 3];
for _ in 0..r {
    let w = wishart.sample(&mut rng).map_err(|e| e.to_string())?;
    let mut xs = Vec::with_capacity(n);
    for _ in 0..n {
        xs.push(normal.sample(&mut rng).map_err(|e| e.to_string())?);
    }
    let mean: Vec<f64> = (0..p)
        .map(|i| xs.iter().map(|x| x[i]).sum::<f64>() / n as f64)
        .collect();
    for (e, &(i, j)) in entries.iter().enumerate() {
        draws[0][e].push(w[i * p + j]);
        draws[1][e].push(xs.iter().map(|x| x[i] * x[j]).sum::<f64>());
        let centered = xs.iter().map(|x| (x[i] - mean[i]) * (x[j] - mean[j]));
        draws[2][e].push(centered.sum::<f64>());
    }
}
// 標本平均、標本分散、4 次の中心モーメントから求めた分散の SE。
let moments = |v: &[f64]| {
    let rf = v.len() as f64;
    let mu = v.iter().sum::<f64>() / rf;
    let var = v.iter().map(|x| (x - mu) * (x - mu)).sum::<f64>() / (rf - 1.0);
    let m4 = v.iter().map(|x| RealScalar::powi(x - mu, 4)).sum::<f64>() / rf;
    (mu, var, RealScalar::sqrt((m4 - var * var) / rf))
};
let (mut mean_rows, mut variance_rows) = (Vec::new(), Vec::new());
for (e, &(i, j)) in entries.iter().enumerate() {
    let label = format!("W[{},{}]", i + 1, j + 1);
    // 独立検算: E[W] = nΣ、Var(W_ij) = n(Σ_ij² + Σ_ii Σ_jj)。
    let s_ij = sigma[i * p + j];
    let expected = n as f64 * s_ij;
    let spread = n as f64 * (s_ij * s_ij + sigma[i * p + i] * sigma[j * p + j]);
    let (mw, vw, sw) = moments(&draws[0][e]);
    let (ms, vs, ss) = moments(&draws[1][e]);
    let (mc, _, _) = moments(&draws[2][e]);
    let se = RealScalar::sqrt(spread / r as f64);
    mean_rows.push((
        label.clone(),
        mw,
        (mw - expected) / se,
        ms,
        (ms - expected) / se,
        expected,
        se,
        mc,
        (n - 1) as f64 * s_ij,
    ));
    variance_rows.push((
        label,
        vw,
        sw,
        (vw - spread) / sw,
        vs,
        ss,
        (vs - spread) / ss,
        spread,
    ));
}
let sig4 = serde_json::json!({ "significantDigits": 4 });
let sig3 = serde_json::json!({ "significantDigits": 3 });
let fixed2 = serde_json::json!({ "fractionDigits": 2 });
let columns = serde_json::json!([
    { "key": "0", "label": "成分" },
    { "key": "1", "label": "Wishart の平均 [K²]", "type": "number", "format": sig4 },
    { "key": "2", "label": "(Wishart − nΣ)/SE [-]", "type": "number", "format": fixed2 },
    { "key": "3", "label": "散布 Σxxᵀ の平均 [K²]", "type": "number", "format": sig4 },
    { "key": "4", "label": "(散布 − nΣ)/SE [-]", "type": "number", "format": fixed2 },
    { "key": "5", "label": "nΣ [K²]", "type": "number", "format": sig4 },
    { "key": "6", "label": "平均の SE [K²]", "type": "number", "format": sig3 },
    { "key": "7", "label": "Σ(x − x̄)(x − x̄)ᵀ の平均 [K²]", "type": "number", "format": sig4 },
    { "key": "8", "label": "(n − 1)Σ [K²]", "type": "number", "format": sig4 }
]);
emit_table_with_columns!(
    columns,
    mean_rows,
    metadata = serde_json::json!({ "id": "means" })
);
let columns = serde_json::json!([
    { "key": "0", "label": "成分" },
    { "key": "1", "label": "Wishart の分散 [K⁴]", "type": "number", "format": sig4 },
    { "key": "2", "label": "その SE [K⁴]", "type": "number", "format": sig3 },
    { "key": "3", "label": "差 / SE [-]", "type": "number", "format": fixed2 },
    { "key": "4", "label": "散布 Σxxᵀ の分散 [K⁴]", "type": "number", "format": sig4 },
    { "key": "5", "label": "その SE [K⁴]", "type": "number", "format": sig3 },
    { "key": "6", "label": "差 / SE [-]", "type": "number", "format": fixed2 },
    { "key": "7", "label": "n(Σ_ij² + Σ_ii Σ_jj) [K⁴]", "type": "number", "format": sig4 }
]);
emit_table_with_columns!(
    columns,
    variance_rows,
    metadata = serde_json::json!({ "id": "spreads" })
);
```

既定の入力（$p = 3$、$n = 10$ 日、$\sigma^2 = 1$ K²、$\rho = 0.5$、$R = 2000$ 回、シード 11）では、$n\Sigma_{11} = 10$ K²、$n\Sigma_{12} = 5$ K² である。
`Wishart` の平均は 10.14、5.03、10.07 K² で、SE 0.10、0.079、0.10 K² に対して $+1.41$、$+0.44$、$+0.66$ SE である。
`MultivariateNormal` の散布行列の平均は 9.94、4.93、9.85 K² で、差は $-0.56$、$-0.84$、$-1.55$ SE になる。
標本平均を引いた散布行列の平均は 8.95、4.46、8.90 K² で、$n\Sigma$ より $(n - 1)\Sigma = 9, 4.5, 9$ K² に近い。
成分の分散は `Wishart` で 20.5、13.2、20.5 K⁴、散布行列で 20.3、12.7、19.5 K⁴ で、理論値 20、12.5、20 K⁴ からどれも 1.3 SE 以内にある。

ケース「ρ = −0.9」では $E[W_{12}] = -9$ K²、$\operatorname{Var}(W_{12}) = 18.1$ K⁴ になり、負の相関でも分散の式は $\Sigma_{12}^2$ を通して正の寄与を持つ。
このシードでは散布行列の 3 成分の絶対値がそろって小さめに出て、$(1,1)$ は $-2.32$ SE、$(1,2)$ は $+2.22$ SE（$-9$ より 0 に近い側）である。
`Wishart` の平均は同じシードで $+1.41$、$-1.53$、$+1.64$ SE で、3 成分とも散布行列と逆の向きにずれるので、2 つの生成法に共通の偏りは見られない。
`Wishart` の $(1,1)$ 成分の平均は既定と同じ 10.14 K² である。
Bartlett 分解では $W_{11} = L_{11}^2 A_{11}^2 = \sigma^2\chi^2_n$ で、同じシードなら $\rho$ によらず同じ乱数から作られる。
ケース「p = 6、n = 7」では自由度が次元に近く $W$ は特異に近いが、6 つの平均と 6 つの分散の差は全て 1.7 SE 以内で、平均 $7\Sigma$ と分散 14 K⁴ の式はそのまま成り立つ。

## まとめ

正規ベクトルの散布行列は Wishart 分布 $W_p(n, \Sigma)$ に従い、`Wishart::new(df, &scale)` は Bartlett 分解で $O(p^3)$ の標本を返す。
平均 $n\Sigma$ と分散 $n(\Sigma_{ij}^2 + \Sigma_{ii}\Sigma_{jj})$ は手計算で検算でき、`MultivariateNormal` の散布行列でも SE の範囲で同じ値になる。
平均が既知なら $W/n$、標本平均を使うなら $n - 1$ で割ったものが $\Sigma$ の不偏推定量である。
$p$ が 40 を超える `Wishart` を作るときは、`LawOptions` の作業量の上限を $p^3$ 以上に上げる。
