`scioxide-random` は、確率的な計算の入力を作るクレートである。
提供するものはシードから再現できる擬似乱数生成器、標本化・密度・分布関数・分位点を別々の機能として持つ確率分布、低食い違い点列（準乱数）、ラテンハイパーキューブや Poisson 円板標本などの標本設計、Brownian 橋による経路の構成の五つである。
生成器は統計的なシミュレーション用で、暗号用途の予測不可能性は持たない。
シードはいつも明示的に与え、クレートがプロセスや OS のエントロピーを読むことはない。

## 最初の計算：放射性崩壊の待ち時間

崩壊率 $\lambda$ [1/s] の放射性核種では、崩壊と崩壊の間の待ち時間 $X$ が指数分布 $\Pr(X > x) = e^{-\lambda x}$ に従う。
平均と標準偏差はどちらも $1/\lambda$ s なので、$n$ 個の標本平均 $\bar{X}$ の標準誤差は $1/(\lambda\sqrt{n})$ s である。

次のセルはシードを与えた `Pcg64` から `Exponential::new(λ)` の標本を $n$ 個作る。
入力は崩壊率 $\lambda$ [1/s]、標本数 $n$、乱数のシードである。
出力は最初の三つの待ち時間、標本平均、閉形式の平均 $1/\lambda$、`Mean::mean` が返す平均、標準誤差、標準化した差 $z = (\bar{X} - 1/\lambda)/\mathrm{SE}$ の表である。
同じシードから作り直した生成器で、新しい `Vec` を返す所有値を返す API `sample_n(rng, n)` と、呼び出し側が用意した出力に書く `sample_n_into(rng, policy, output, workspace)` を呼び、二つの列の差の最大値も出す。

```rust
//| id: random-first-exponential
//| ref: random-first-exponential
//| title: 指数分布の待ち時間をシードから作り、二つの形と理論値を比べる
//| run: reactive
//| crates: [scioxide-core, scioxide-random]
//| inputs:
//|   decay_rate: {"type":"range","label":"崩壊率 λ [1/s]","description":"待ち時間の尺度 1/λ を変える。","min":0.5,"max":5,"step":0.25,"value":2}
//|   sample_count: {"type":"range","label":"標本数 n","description":"標準誤差 1/(λ√n) を変える。","min":100,"max":10000,"step":100,"value":1000}
//|   seed: {"type":"range","label":"乱数のシード","min":1,"max":1000,"step":1,"value":24}
//| cases:
//|   - {"id":"fast-decay","label":"λ = 5 /s","description":"同じシードで待ち時間がすべて 2/5 倍に縮み、z は変わらない。","inputs":{"decay_rate":5}}
//|   - {"id":"many-samples","label":"n = 10000","description":"標準誤差が √10 分の 1 の 0.0050 s になる。","inputs":{"sample_count":10000}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"waiting-times","path":"/rows/0/1","approx":{"value":0.6656,"atol":1e-3}}
//|       - {"artifact":"waiting-times","path":"/rows/3/1","range":{"min":0.45,"max":0.55}}
//|       - {"artifact":"waiting-times","path":"/rows/4/1","approx":{"value":0.5,"atol":1e-12}}
//|       - {"artifact":"waiting-times","path":"/rows/5/1","approx":{"value":0.5,"atol":1e-12}}
//|       - {"artifact":"waiting-times","path":"/rows/6/1","approx":{"value":0.0158,"atol":1e-4}}
//|       - {"artifact":"waiting-times","path":"/rows/7/1","range":{"min":-4,"max":4}}
//|       - {"artifact":"waiting-times","path":"/rows/8/1","range":{"min":0,"max":0}}
//|   - case: fast-decay
//|     expect:
//|       - {"artifact":"waiting-times","path":"/rows/0/1","approx":{"value":0.2662,"atol":1e-3}}
//|       - {"artifact":"waiting-times","path":"/rows/4/1","approx":{"value":0.2,"atol":1e-12}}
//|       - {"artifact":"waiting-times","path":"/rows/7/1","range":{"min":-4,"max":4}}
//|   - case: many-samples
//|     expect:
//|       - {"artifact":"waiting-times","path":"/rows/6/1","approx":{"value":0.005,"atol":1e-5}}
//|       - {"artifact":"waiting-times","path":"/rows/7/1","range":{"min":-4,"max":4}}
//|       - {"artifact":"waiting-times","path":"/rows/8/1","range":{"min":0,"max":0}}
use scioxide_core::RealScalar;
use scioxide_random::{
    Distribution, Exponential, Mean, OutputPolicy, Pcg64, SamplingPolicy, SamplingRequest,
    SeedableRng,
};

let n = sample_count.round() as usize;
let seed = seed.round() as u64;
let law = Exponential::new(decay_rate).map_err(|e| e.to_string())?;
// 所有値を返す API: 成功したときだけ Vec を返す。失敗したら生成器は消費したワードの分だけ進む。
let owned = law
    .sample_n(&mut Pcg64::from_seed(seed), n)
    .map_err(|e| e.to_string())?;
// 呼び出し側の出力に書く形: 失敗したら生成器を巻き戻す（rollback）。
// 作業領域は要件から一度確保する。
let policy = SamplingPolicy::rollback(OutputPolicy::Atomic);
let mut workspace = policy
    .workspace(SamplingRequest::scalars(n))
    .map_err(|e| e.to_string())?;
let mut borrowed = vec![0.0_f64; n];
law.sample_n_into(
    &mut Pcg64::from_seed(seed),
    policy,
    &mut borrowed,
    &mut workspace,
)
.map_err(|e| e.to_string())?;
let max_difference = owned
    .iter()
    .zip(&borrowed)
    .map(|(a, b)| (a - b).abs())
    .fold(0.0_f64, f64::max);
let mean = owned.iter().sum::<f64>() / n as f64;
// 独立検算: 指数分布の平均と標準偏差はどちらも閉形式で 1/λ。
let theory = 1.0 / decay_rate;
let standard_error = theory / RealScalar::sqrt(n as f64);
let api_mean = law.mean().map_err(|e| e.to_string())?;
let sig4 = serde_json::json!({ "significantDigits": 4 });
let columns = serde_json::json!([
    { "key": "0", "label": "量" },
    { "key": "1", "label": "値", "type": "number", "format": sig4 }
]);
emit_table_with_columns!(
    columns,
    vec![
        ("最初の待ち時間 X₁ [s]", owned[0]),
        ("2 番目の待ち時間 X₂ [s]", owned[1]),
        ("3 番目の待ち時間 X₃ [s]", owned[2]),
        ("標本平均 [s]", mean),
        ("閉形式の平均 1/λ [s]", theory),
        ("Mean::mean の値 [s]", api_mean),
        ("標準誤差 1/(λ√n) [s]", standard_error),
        (
            "z = (標本平均 − 1/λ) / 標準誤差 [-]",
            (mean - theory) / standard_error
        ),
        ("sample_n と sample_n_into の最大の差 [s]", max_difference),
    ],
    metadata = serde_json::json!({ "id": "waiting-times" })
);
```

## 結果の読み方

既定の入力（$\lambda = 2$ /s、$n = 1000$、シード 24）では、最初の三つの待ち時間は $0.6656$、$0.3429$、$0.5742$ s だった。
標本平均は $0.5034$ s で、閉形式の平均 $0.5$ s との差は標準誤差 $0.0158$ s の $0.22$ 倍である。
$n$ が大きければ中心極限定理により $z$ はおおよそ標準正規分布に従うので、$|z| > 2$ となる確率は約 4.6%、$|z| > 3$ は約 0.27% である。
`Mean::mean` は閉形式と同じ $0.5$ s を返し、二つの形の列の差の最大値は 0 だった。

$\lambda = 5$ /s にすると、同じシードの待ち時間はすべて $2/5$ 倍になり（最初の値は $0.2662$ s）、$z$ は変わらない。
指数分布の標本は標準指数分布の標本を $\lambda$ で割って作るからである。
$n = 10000$ にすると標準誤差は $\sqrt{10}$ 分の 1 の $0.0050$ s になり、標本平均 $0.4944$ s の $z$ は $-1.12$ だった。

標本の値は生成器のシードと分布の標本化アルゴリズムの二つで決まる。
生成器が返すワードの列は、生成器のアルゴリズムと、ワードを一様乱数ワードや浮動小数点数に変換する規約のバージョンが同じなら再現される。
一方、分布の標本化アルゴリズムとその丸めはこの保証の外にあり、リリースが変わると同じシードでも標本が変わりうる（[再現性の範囲](oxref:random-algorithms-reproducibility)）。
したがって、結果は標本の値そのものではなく、理論値との差を標準誤差で割った値で読む。

関数は失敗を `Result` のエラーとして返し、`kind()` で分類する。
$\lambda \le 0$ は `DomainError`、NaN や無限大は `NonFinite` になる。
どの母数でも存在しない量は機能の有無で表され、たとえば `Cauchy` は `Mean` を実装しない。
母数によって存在しない量は `DomainError` になり、たとえば自由度 $\nu \le 1$ の `StudentT` の `mean` は理由 `Undefined` の `DomainError` を返す。

## まとめ

`scioxide-random` は、明示的なシードから再現できる生成器と、機能ごとのトレイトを持つ確率分布、準乱数点列と標本設計を提供する。
標本は `sample`、`sample_n`、`sample_n_into` の三つの形で作り、同じシードから作った `sample_n` と `sample_n_into` の列は一致する。
標本の統計量は閉形式の理論値と標準誤差で照合し、$|z|$ が 2 を少し超える程度ならシードによる揺らぎの範囲として解釈する。
