実数の範囲では根を持たない $z^2 + 1$ も、複素数では $z = \pm i$ を根に持つ。
複素数の求根では近似値だけでなく関数の定義域も複素平面へ広げる。
scioxide-rootfind には、実数の関数を自動で複素数の関数に読み替える処理はない。
平方根や対数を含む関数では分枝を決め、その分枝で微分できる範囲を確かめる必要がある。

## 正則性と局所収束

点 $z$ の近傍で複素微分できる関数を、そこで正則であるという。
正則な関数は Taylor 展開でき、実数の場合と同じ計算で Newton 法の誤差を評価できる。
正則な $f$ の単純根 $z_*$（$f'(z_*) \ne 0$）に対し、Newton 法は

$$
z_{k+1} = z_k - \frac{f(z_k)}{f'(z_k)}
$$

で更新する。
$e_k = z_k - z_*$ と置くと $e_{k+1} = \bigl(f''(z_*) / (2 f'(z_*))\bigr) e_k^2 + O(e_k^3)$ となり、十分近い初期値では 2 次で収束する。
Halley 法は

$$
z_{k+1} = z_k - \frac{2 f(z_k) f'(z_k)}{2 f'(z_k)^2 - f(z_k) f''(z_k)}
$$

を使い、単純根の近くで 3 次で収束する。
実数の `Halley` と同じく、`ComplexHalley` も $\lvert f f'' / (2 f'^2) \rvert \ge 1$ のときは Newton の更新に戻る（[Halley 法の局所 3 次収束](oxref:rootfind-halley-method)）。
導関数が 0 になる点や、微分できない分枝の切断線をまたぐ更新には、この議論を使えない。
$\overline z$ や $\lvert z \rvert$ を含む非正則な方程式は、実部と虚部を二つの実変数とした連立方程式として扱う（[非線形連立方程式と大域化](../nonlinear-systems/)）。

## 補間による更新

`ComplexSecant` は、二つの複素数の標本から傾きを近似する。
単純根の近くでの収束の次数は実数の場合と同じく $\varphi = (1 + \sqrt 5)/2 \approx 1.618$ である。
`ComplexMuller` は三つの標本を通る 2 次式を使い、その複素数の根のうち最後の点に近い方を次の点にする。
2 次式の二つの解を計算するときは、分母の絶対値が大きい方を選んで桁落ちを抑える。
局所的な収束の次数は約 1.839 だが、初期値から遠いときの収束を保証する値ではない。

実数の `Muller` は、複素数の更新が必要になると `ComplexStepRequired` で止まる。
一方、`ComplexMuller` には虚部が 0 の複素数を初期値として渡せ、実軸から複素平面へ進める。
ただし関数も `ComplexScalarFunction` として与える必要があり、返された根の虚部を小さいという理由だけで捨ててはいけない。

## 関数型と結果

| 項目 | 渡す情報・読み取る情報 |
|---|---|
| `ComplexScalarFunction` | 複素数の関数値と、利用できる正則な 1 階・2 階導関数 |
| `ComplexScalarFn` | 関数値を返すクロージャ |
| `ComplexScalarFnWithDerivative` | `with_derivative` で 1 階導関数を加えた型 |
| `ComplexScalarFnWithDerivatives` | `with_second_derivative` で 2 階導関数も加えた型 |
| `ComplexRootSolver` | `solve` と、実行スコープを受け取る `solve_scoped` |
| `ComplexRootResult` | 複素数の近似根 `point()` と関数値 `residual()`、その絶対値 `residual_norm()`、終了理由 `termination()`、評価回数 `counts()` |

`ComplexNewton`、`ComplexHalley`、`ComplexSecant`、`ComplexMuller` の初期化はそれぞれ一点、一点、二点、三点である。
`ComplexNewton` には解析的な 1 階導関数、`ComplexHalley` には 1 階・2 階導関数が必要で、ないと `InvalidInput` のエラーになる。
複素数の方法には差分による導関数の選択はない。
スカラーの方法なので、外部の作業領域は渡さない。

残差の大きさは $\lvert f(z) \rvert$（複素数の絶対値）、座標の更新の大きさは $\lvert z_{k+1} - z_k \rvert$ で測り、許容誤差の意味と既定の判定は実数の開いた方法と同じである（[1 変数の方法の既定の停止判定](oxref:rootfind-scalar-default-stopping)）。
関数値や導関数の非有限な成分は構造化されたエラーになり、反復の上限や停滞は未収束の結果として `Ok` で返る。
成功の判定には `termination().is_success()` を使い、残差の小ささだけで根の位置の精度を断定しない。

## 三つの根の吸引域

初期値を変えたとき同じ根へ収束する点の集合を、その根の吸引域（basin of attraction）という。
$z^3 - 1 = 0$ の三根は $1$ と $(-1 \pm i\sqrt3)/2$ で、Newton 法の写像は

$$
N(z) = z - \frac{z^3 - 1}{3 z^2} = \frac{2 z^3 + 1}{3 z^2}
$$

である。
$N$ は $z \mapsto e^{2\pi i/3} z$ の回転と可換なので、三つの吸引域は互いに 120° 回転した形になる。
三つの吸引域の境界は $N$ の Julia 集合と一致し、境界のどの点の近くにも三つの根すべての吸引域の点がある。
そのため、境界の近くでは初期値のわずかな違いで到達する根が変わる。
原点では $N$ を定義できず、原点に写る点も根に収束しない。

次のセルは正方形 $[-2, 2]^2$ の格子点を初期値として `ComplexNewton` を実行する。
入力は一辺の分割数と反復の上限で、残差の許容誤差は絶対値 $10^{-12}$ を明示する。
成功した点は既知の三根のうち最も近い根で分類し、その距離の最大値を独立な検算として出す。
出力は吸引域の図と、分類ごとの点数である。

```rust
//| id: rootfind-complex-newton-basins
//| ref: rootfind-complex-newton-basins
//| title: z³ − 1 の吸引域と既知の根との距離
//| run: button
//| crates: [scioxide-core, scioxide-rootfind]
//| inputs:
//|   grid: {"type":"range","label":"一辺の分割数 [-]","min":20,"max":80,"step":20,"value":40}
//|   iterations: {"type":"range","label":"反復上限 [回]","min":5,"max":80,"step":5,"value":40}
//| cases:
//|   - {"id":"five-iterations","label":"反復の上限 5","description":"未収束の点が 1497 点に増え、収束するのは根 1 の 64 点と複素共役の二根の 60 点ずつだけになる。","inputs":{"iterations":5}}
//|   - {"id":"ten-iterations","label":"反復の上限 10","description":"未収束の点は 238 点に減り、多くの格子点が 6〜10 回の反復で残差の基準に届く。","inputs":{"iterations":10}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"counts","path":"/rows/0/2","equals":602}
//|       - {"artifact":"counts","path":"/rows/1/2","equals":539}
//|       - {"artifact":"counts","path":"/rows/2/2","equals":539}
//|       - {"artifact":"counts","path":"/rows/3/2","equals":1}
//|       - {"artifact":"accuracy","path":"/rows/0/0","approx":{"value":3.3e-13,"atol":5e-15}}
//|   - case: five-iterations
//|     expect:
//|       - {"artifact":"counts","path":"/rows/0/2","equals":64}
//|       - {"artifact":"counts","path":"/rows/1/2","equals":60}
//|       - {"artifact":"counts","path":"/rows/2/2","equals":60}
//|       - {"artifact":"counts","path":"/rows/3/2","equals":1497}
//|   - case: ten-iterations
//|     expect:
//|       - {"artifact":"counts","path":"/rows/3/2","equals":238}
use scioxide_core::{Budget, Complex, RealScalar, ResidualTolerance};
use scioxide_rootfind::{ComplexNewton, ComplexRootSolver, ComplexScalarFn, ScalarRootOptions};

let f = ComplexScalarFn::new(|z: Complex<f64>| Ok(z * z * z - Complex::new(1.0, 0.0)))
    .with_derivative(|z| Ok(Complex::new(3.0, 0.0) * z * z));
let options = ScalarRootOptions::default()
    .with_max_iterations(Budget::try_from(iterations as usize).map_err(|e| e.to_string())?)
    .with_residual_tolerance(ResidualTolerance::new(1e-12, 0.0).map_err(|e| e.to_string())?);
// 独立な検算: 単位円上の三つの解析解。
let half_sqrt3 = RealScalar::sqrt(3.0_f64) / 2.0;
let roots = [
    Complex::new(1.0, 0.0),
    Complex::new(-0.5, half_sqrt3),
    Complex::new(-0.5, -half_sqrt3),
];
let mut counts = [0_usize; 4];
let mut data = Vec::new();
let mut maximum_error = 0.0_f64;
for j in 0..=grid as usize {
    for i in 0..=grid as usize {
        let x = -2.0 + 4.0 * i as f64 / grid;
        let y = -2.0 + 4.0 * j as f64 / grid;
        let result = ComplexNewton
            .solve(&f, Complex::new(x, y), &options)
            .map_err(|e| e.to_string())?;
        // 成功した点は最も近い既知の根の番号 0〜2、未収束は 3。
        let category = if result.is_success() {
            let distances = roots.map(|root| (result.point() - root).norm());
            let nearest = (1..3).fold(0, |best, k| {
                if distances[k] < distances[best] {
                    k
                } else {
                    best
                }
            });
            maximum_error = maximum_error.max(distances[nearest]);
            nearest
        } else {
            3
        };
        counts[category] += 1;
        data.push([x, y, category as f64]);
    }
}
emit_chart!(
    serde_json::json!({
        "kind": "heatmap",
        "data": data,
        "xLabel": "初期値の実部 [-]",
        "yLabel": "初期値の虚部 [-]",
        "colorMin": 0,
        "colorMax": 3,
        "tooltip": true,
        "style": {
            "animation": false,
            "palette": {
                "light": ["#3987e5", "#d95926", "#199e70", "#6b7280"],
                "dark": ["#3987e5", "#d95926", "#199e70", "#9ca3af"]
            }
        }
    }),
    metadata = serde_json::json!({ "id": "basins", "title": "色の値は表の分類番号に対応" })
);
let rows: Vec<_> = ["根 1", "上半平面の根", "下半平面の根", "未収束"]
    .iter()
    .enumerate()
    .map(|(k, label)| (k, *label, counts[k]))
    .collect();
let columns = serde_json::json!([
    { "key": "0", "label": "分類番号 [-]", "type": "integer" },
    { "key": "1", "label": "意味" },
    { "key": "2", "label": "格子点数 [点]", "type": "integer" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "counts" })
);
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let accuracy = serde_json::json!([
    { "key": "0", "label": "成功点の最大位置誤差 [-]", "type": "number", "format": sci2 }
]);
emit_table_with_columns!(
    accuracy,
    vec![(maximum_error,)],
    metadata = serde_json::json!({ "id": "accuracy" })
);
```

色は分類番号 0〜3 に一つずつ対応し、0 が根 1、1 が上半平面の根、2 が下半平面の根、3（灰色）が未収束である。
既定の入力（分割数 40、反復の上限 40）では、1681 点のうち 602 点が根 1、539 点ずつが複素共役の二根に収束し、未収束は 1 点である。
未収束の 1 点は原点で、導関数が 0 なので更新を作れず `Stagnation` で止まる。
根 1 の点数が他の二根より多いのは、正方形の格子が 120° の回転で自身に重ならないためで、吸引域の面積の違いを表すものではない。
成功した点と最も近い根との距離は最大で $3.3 \times 10^{-13}$ で、残差の基準 $10^{-12}$ を傾き $\lvert f'(z_*) \rvert = 3$ で割った見積もりと合う。

反復の上限を 5 に減らすと、未収束の点は 1497 点に増え、収束するのは根 1 の 64 点と複素共役の二根の 60 点ずつだけになる。
上限を 10 にすると未収束は 238 点に減るので、多くの格子点は残差 $10^{-12}$ に届くまでに 6〜10 回の反復を要する。
$\lvert z \rvert$ が大きいと $N(z) \approx 2z/3$ なので、最初の数反復は $\lvert z \rvert$ を約 2/3 倍ずつ縮めるだけで、2 次収束に入る前に上限に達するからである。
これらの点が発散することを意味しない。
図は有限の格子での観測であり、吸引域の境界を数学的に確定したものではない。

## まとめ

複素数の求根は関数を `ComplexScalarFunction` として与え、正則性と分枝を確かめてから使う。
局所的な収束の次数は実数の場合と同じで、`ComplexNewton` は 2 次、`ComplexHalley` は 3 次、`ComplexSecant` は約 1.618 次、`ComplexMuller` は約 1.839 次である。
どの根に到達するかは初期値で決まり、吸引域の境界の近くでは初期値のわずかな違いで結果が変わる。
特定の根が必要なら、その根の近くの初期値を選び、結果を既知の性質や元の方程式の残差で確かめる。
