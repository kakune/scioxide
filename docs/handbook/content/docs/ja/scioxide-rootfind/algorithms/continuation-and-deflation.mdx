パラメータ $\lambda$ を含む非線形方程式 $\mathbf{F}(\mathbf{x}, \lambda) = \mathbf{0}$（$\mathbf{x} \in \mathbb{R}^n$、$\mathbf{F}: \mathbb{R}^{n+1} \to \mathbb{R}^n$）の解は、$\lambda$ とともに曲線を描く。
この曲線を解の枝（solution branch）という。
一つの $\lambda$ に複数の解があることも、ある $\lambda$ を越えると解がなくなることもある。
継続法（continuation）は、受理した解から次の解を予測し、Newton 法で補正して、解の枝を少しずつたどる。
解を一つ見つけた後で別の解を探すデフレーション（deflation）は[デフレーションによる別の解の探索](../deflation/)で扱う。

## 解の枝と折り返し点

$\mathbf{y} = (\mathbf{x}, \lambda) \in \mathbb{R}^{n+1}$ とし、$\mathbf{F}$ のヤコビ行列を $F_{\mathbf{y}} = [\,F_{\mathbf{x}}\ \ F_\lambda\,]$（$n \times (n+1)$）と書く。
陰関数定理によれば、解 $\mathbf{y}_0$ で $F_{\mathbf{x}}$ が正則なら、その近くの解は $\lambda$ の滑らかな関数 $\mathbf{x}(\lambda)$ として一意に表せる。
$F_{\mathbf{x}}$ が特異になる点では、この表し方が崩れる。

- 折り返し点（fold、turning point）では $F_{\mathbf{x}}$ が特異だが $F_{\mathbf{y}}$ の階数は $n$ のままで、解の枝は $\lambda$ について折れ返す。
  折り返し点の近くでは、$\lambda$ を固定した方程式の解が片側で二つ、反対側で零個になる。
- 分岐点（branch point）では $F_{\mathbf{y}}$ の階数も $n$ より下がり、複数の枝が交わる。

$F_{\mathbf{y}}$ の階数が $n$ の点では、解の集合は $\mathbf{y}$ の空間の滑らかな曲線で、その単位接線 $\mathbf{t}$ は $F_{\mathbf{y}}\mathbf{t} = \mathbf{0}$ を満たす。
折り返し点では接線の $\lambda$ 成分 $t_\lambda$ が 0 になり、前後で符号が変わる。

## 自然継続と擬弧長継続

### 自然継続

自然継続（natural continuation）は $\lambda$ を目標の値へ順に動かし、各 $\lambda$ で $\mathbf{F}(\mathbf{x}, \lambda) = \mathbf{0}$ を $\mathbf{x}$ について解く。
`ContinuationPath::Parameters(targets)` は目標の列を順に（向きの反転も含めて）たどる。
予測子は受理点の接線で、$\lambda$ を $\Delta\lambda$ だけ動かすときの初期値は $\mathbf{x}_k + (\Delta\lambda / t_\lambda)\,\mathbf{t}_{\mathbf{x}}$ である。
修正子は $\lambda$ を固定した方程式を解き、受理点の $\lambda$ は要求した値に正確に一致する。

折り返し点に近づくと $F_{\mathbf{x}}$ が特異に近づき、その先には固定した $\lambda$ の解がない。
修正子が失敗して刻みが最小値まで縮むと `StepLimit` で止まる。
受理点の接線の $\lambda$ 成分が $|t_\lambda| \le \varepsilon$（$\varepsilon$ は機械イプシロン）になった場合は、予測子を作れないので `TangentFailure` で止まる。
どちらの場合も、自然継続は折り返し点を越えない。

### 擬弧長継続

擬弧長継続（pseudo-arclength continuation、Keller 1977）は $\lambda$ も未知数に含め、$\mathbf{y}$ の空間の曲線を一つの媒介変数 $s$ でたどる。
受理点 $\mathbf{y}_k$ と単位接線 $\mathbf{t}_k$ から予測点 $\hat{\mathbf{y}} = \mathbf{y}_k + \Delta s\,\mathbf{t}_k$ を作り、修正子では次の $n + 1$ 本の方程式を Newton 法で解く。

$$
\mathbf{F}(\mathbf{y}) = \mathbf{0}, \qquad \mathbf{t}_k^{\mathsf T} M\,(\mathbf{y} - \hat{\mathbf{y}}) = 0
$$

$M = \operatorname{diag}(1/s_x^2, \dots, 1/s_x^2, 1/s_\lambda^2)$ は弧長を測る計量で、`ContinuationOptions::with_scales(s_x, s_λ)`（既定は 1 と 1）で状態とパラメータの単位をそろえる。
$\mathbf{t}_k$ は $M$ で正規化してあるので、2 本目の式は $\mathbf{t}_k^{\mathsf T}M(\mathbf{y} - \mathbf{y}_k) = \Delta s$ と同じで、補正後の点の接線方向への射影が $\Delta s$ になる。
これは真の弧長ではなく、その 1 次近似なので「擬」弧長という。

修正子の拡大したヤコビ行列

$$
A = \begin{bmatrix} F_{\mathbf{y}} \\ \mathbf{t}_k^{\mathsf T}M \end{bmatrix} \in \mathbb{R}^{(n+1) \times (n+1)}
$$

は、$F_{\mathbf{y}}$ の階数が $n$ で $\mathbf{t}_k$ が零空間に十分近ければ正則である（$F_{\mathbf{y}}$ の零空間は $\mathbf{t}$ が張り、$\mathbf{t}^{\mathsf T}M\mathbf{t} \ne 0$ なので）。
この条件は折り返し点でも成り立つので、補正は折り返し点で止まらない。
分岐点では $F_{\mathbf{y}}$ の階数が落ちて $A$ は特異になり、どの枝へ進むかは決まらない。

接線は同じ形の縁付き方程式 $\begin{bmatrix} F_{\mathbf{y}} \\ \mathbf{t}_k^{\mathsf T}M \end{bmatrix}\mathbf{t} = \mathbf{e}_{n+1}$ を解いて $M$ で正規化する。
右辺の最後の成分が 1 なので $\mathbf{t}_k^{\mathsf T}M\mathbf{t} > 0$ となり、向きは前の接線から引き継がれる。
最初の点では縁を $\mathbf{e}_{n+1}$（$\lambda$ が増える向き）にし、`ContinuationState::with_initial_tangent` で別の向きを与えられる。
接線の $\lambda$ 成分の符号が前の受理点と変わった点は `ContinuationObservation::turning_point_candidate` が真になり、折り返し点の候補になる。

### 修正子と受理の検査

修正子は `NewtonKrylovSolver`（[行列を形成しない Newton–Krylov 法](../matrix-free-newton-krylov/)）で拡大した系を解き、その設定は `with_corrector` で替えられる。
既定の修正子は Newton–Krylov 法の既定の設定で、更新幅の許容誤差だけを絶対・相対とも $\varepsilon$ にしたものである。
修正子が成功した点は、次の検査をこの順にすべて通ったときだけ受理する。

1. 元の方程式の残差を改めて評価し、$\lVert \mathbf{F}(\mathbf{y}) \rVert_2$ が許容誤差を満たす。
   既定は絶対 0、相対 $\sqrt\varepsilon$ で、相対の基準は予測点での元の残差ノルムである。
   `with_residual_tolerance` で許容誤差を、`with_residual_scale` で固定の基準を与え、どちらも修正子の設定にも反映される。
2. 弧長の拘束の値 $|\mathbf{t}_k^{\mathsf T}M(\mathbf{y} - \hat{\mathbf{y}})|$ が `with_constraint_tolerance` の許容誤差（既定は絶対・相対とも $\sqrt\varepsilon$、尺度 1）以下である。
   元の方程式の残差と拘束を別々の許容誤差で検査するのは、両者の単位が違うからである。
3. 補正の方向 $\mathbf{d}$（予測点から補正後の点へ）について、前の受理点と新しい点のヤコビ行列の差が $\lVert (J_{\text{new}} - J_{\text{old}})\mathbf{d} \rVert \le 0.5\,\lVert J_{\text{old}}\mathbf{d} \rVert$（`with_correction_contraction`）を満たす。
   接線がほぼ平行な近くの別の枝へ飛び移ることを防ぐ検査で、ヤコビ行列とベクトルの積を 2 回使う。
4. 新しい点で接線を解き、その残差を検査できる。
5. 前後の接線のなす角が 45° 以内（`with_step_control` の最小の余弦 $1/\sqrt2$）で、補正の距離が予測の距離（前の受理点から予測点まで）の 0.5 倍以下である。
   角と距離は `with_scales` の計量で測る。

3 と 5 は局所的な検査で、経路が一つの枝にとどまることを証明しない。

### 刻みの制御

修正子が失敗した提案と検査に一つでも通らなかった提案は退け、刻みを半分にしてやり直す（最小値 `minimum` より小さくはしない）。
受理点 1 点あたりのやり直しは既定で 12 回まで（`with_rejection_limit`）で、使い切るか刻みが最小値に達すると止まる。
受理した点では、$1 - \cos\theta$（$\theta$ は前後の接線のなす角）と補正の距離の比がどちらも限度の半分以内に収まり、ヤコビ行列の変化も限度の半分以内で、修正子の反復が 4 回以下なら、次の刻みを受理した刻みの 1.5 倍にする。
それ以外の受理点では次の刻みを受理した刻みのままにする。
刻みは常に `maximum` 以下に保つ。
`ContinuationOptions::new(initial, minimum, maximum, max_points)` は $0 < \text{minimum} \le \text{initial} \le \text{maximum}$ と、シードを含めて 2 点以上の履歴の容量を要求する。

1 回の試行は予測点と補正後の点での $\mathbf{F}$ の評価と修正子の 1 回の求解を使う。
残差の検査を通った試行は、さらにヤコビ行列とベクトルの積 2 回と接線の求解 1 回を使う。

## 終了状態

`Continuation::advance` は呼ぶたびに最大 1 点を受理し、その時点の終了状態を `ContinuationReport::termination()` で返す。
最初の呼び出しでは $\lambda$ を固定してシード（seed）を補正し、その点の接線を求める。
`Continuation::follow` は新しい作業領域と逐次の実行コンテキストで、終了状態が `Advanced` でなくなるまで `advance` を繰り返し、最後の `ContinuationState` を返す。
途中の点を観察する、途中で止める、呼び出し側の実行コンテキストで数えるといった場合は `advance` を自分で呼ぶ。

| 終了状態 | 意味 |
|---|---|
| `Advanced` | 点を受理し、経路の残りがある |
| `Complete`（唯一の成功） | 要求した経路（目標の列、または擬弧長 $s$）をたどり終えた |
| `HistoryLimit` | 履歴の容量（`max_points`）が尽きた |
| `StepLimit` | やり直しの回数を使い切ったか、刻みが最小値に達した |
| `TangentFailure` | 最後の試行で接線を求められなかった。自然継続では $\lvert t_\lambda\rvert \le \varepsilon$ の点に達した |
| `WorkLimit`、`Cancelled`、`TimeLimit` | `SolveBudgets` や実行コンテキストが処理を止めた |

`StepLimit`、`HistoryLimit`、`TangentFailure` はエラーではなく、`ContinuationState::termination()` と `is_success()` で読む。
シードの補正や最初の接線に失敗した場合は `ConvergenceFailure` のエラーを返し、状態は変わらない。
受理済みの点と履歴は、後の失敗やエラーの後も残る。
`follow` がエラーで終わると、それまでの受理点を持つ状態を `PartialFailure` の途中経過として返す。

## Bratu 問題の解の枝

Bratu 問題 $u'' + \lambda e^{u} = 0$、$u(0) = u(1) = 0$ を、$N$ 個の内部格子点（$h = 1/(N+1)$）の 2 次の中心差分

$$
F_i(\mathbf{u}, \lambda) = \frac{u_{i-1} - 2u_i + u_{i+1}}{h^2} + \lambda e^{u_i} = 0, \qquad i = 1, \dots, N
$$

で近似する。
セルでは各式に $h^2$ を掛け、$u_{i-1} - 2u_i + u_{i+1} + h^2 \lambda e^{u_i} = 0$ として行の大きさを 1 程度にそろえる（理由は[接線の線形方程式と行の尺度](#接線の線形方程式と行の尺度)で述べる）。
連続な問題の解析解は $u(1/2) = 2 \ln\cosh(\theta/4)$、$\lambda = \theta^2 / \bigl(2\cosh^2(\theta/4)\bigr)$ を $\theta > 0$ で媒介変数表示したもので、折り返し点は $\lambda_c = 3.513831$（$\theta_c = 4.798715$、$u(1/2) = 1.186842$）にある。
$0 < \lambda < \lambda_c$ では解が二つあり、$\lambda = 1$ の二つの解は $u(1/2) = 0.140539$ と $4.091467$ である。
scioxide-ode の章は同じ問題を[2 点境界値問題の選点法](oxref:ode-bratu-two-solutions)で解き、同じ $\lambda = 1$ の二つの解を求める。

次の定義のブロックを、このページの二つのセルが共有する。
`Bratu(N)` は拡大した未知数 $\mathbf{y} = (u_1, \dots, u_N, \lambda)$ の写像で、`residual_into` が $h^2 F_i$、`jvp_into` が方向微分 $h^2 (F_{\mathbf{y}}\mathbf{v})_i = v_{i-1} - 2v_i + v_{i+1} + h^2 e^{u_i}(\lambda v_i + v_\lambda)$ を返す。
`trace` は厳密な解 $\mathbf{u} = \mathbf{0}$、$\lambda = 0$ をシードにして、`Continuation::follow` で経路の終わりまで継続する。
刻みの最小は $10^{-6}$、状態の尺度は $\sqrt N$（二乗平均の単位）、$\lambda$ の尺度は 1、元の方程式の許容誤差は絶対 $10^{-9}$ とし、刻みの初期値と上限と履歴の容量はセルが決める。

```rust
//| id: rootfind-bratu-model
//| kind: definitions
//| title: h² を掛けた Bratu 問題の差分方程式と継続の手順
//| crates: [scioxide-core, scioxide-rootfind]
use scioxide_core::{
    Budget, SciOxideError, JacobianOperator, RealScalar, ResidualOperator, ResidualTolerance,
};
use scioxide_rootfind::{
    Continuation, ContinuationOptions, ContinuationPath, ContinuationProblem, ContinuationState,
};

/// 拡大した未知数 y = (u_1, …, u_N, λ)。各式に h² を掛け、境界の u_0 = u_{N+1} = 0 は式に入れる。
pub(crate) struct Bratu(pub(crate) usize);

impl Bratu {
    /// 行 i の値。v が None なら残差 h² F_i、Some(v) なら方向微分 h² (F_y v)_i。
    fn row(&self, y: &[f64], v: Option<&[f64]>, i: usize) -> f64 {
        let (n, h2) = (self.0, 1.0 / ((self.0 + 1) * (self.0 + 1)) as f64);
        let w = v.unwrap_or(y);
        let left = if i > 0 { w[i - 1] } else { 0.0 };
        let right = if i + 1 < n { w[i + 1] } else { 0.0 };
        let growth = RealScalar::exp(y[i]);
        let source = match v {
            None => y[n] * growth,
            Some(v) => growth * (y[n] * v[i] + v[n]),
        };
        left - 2.0 * w[i] + right + h2 * source
    }
}

impl ResidualOperator<f64> for Bratu {
    fn input_dimension(&self) -> usize {
        self.0 + 1
    }
    fn output_dimension(&self) -> usize {
        self.0
    }
    fn residual_workspace_len(&self) -> Result<usize, SciOxideError> {
        Ok(0)
    }
    fn residual_into(&self, y: &[f64], out: &mut [f64], _: &mut [f64]) -> Result<(), SciOxideError> {
        (0..self.0).for_each(|i| out[i] = self.row(y, None, i));
        Ok(())
    }
}

impl JacobianOperator<f64> for Bratu {
    fn jvp_workspace_len(&self) -> Result<usize, SciOxideError> {
        Ok(0)
    }
    fn jvp_into(
        &self,
        y: &[f64],
        v: &[f64],
        out: &mut [f64],
        _: &mut [f64],
    ) -> Result<(), SciOxideError> {
        (0..self.0).for_each(|i| out[i] = self.row(y, Some(v), i));
        Ok(())
    }
}

/// N = n の問題を u = 0、λ = 0 から route に沿って終わりまで継続し、最後の状態を返す。
pub(crate) fn trace(
    n: usize,
    route: ContinuationPath<f64>,
    initial_step: f64,
    largest_step: f64,
    max_points: usize,
) -> Result<ContinuationState<f64>, String> {
    let map = Bratu(n);
    let problem = ContinuationProblem::new(&map).map_err(|e| e.to_string())?;
    let capacity = Budget::try_from(max_points).map_err(|e| e.to_string())?;
    let tolerance = ResidualTolerance::new(1e-9, 0.0).map_err(|e| e.to_string())?;
    let options = ContinuationOptions::new(initial_step, 1e-6, largest_step, capacity)
        .map_err(|e| e.to_string())?
        .with_scales(RealScalar::sqrt(n as f64), 1.0)
        .with_residual_tolerance(tolerance);
    let continuation = Continuation::new(route, options).map_err(|e| e.to_string())?;
    // u = 0、λ = 0 は厳密な解。既定の向きは λ が増える向き。
    let seed = continuation
        .state(&problem, &vec![0.0; n + 1])
        .map_err(|e| e.to_string())?;
    continuation
        .follow(&problem, seed)
        .map_err(|e| SciOxideError::from(e).to_string())
}
```

use scioxide_core::RealScalar;
use scioxide_rootfind::{ContinuationPath, RootTermination};

let n = interior_points as usize;
let route = if path == "擬弧長継続" {
    ContinuationPath::PseudoArclength(arclength)
} else {
    ContinuationPath::Parameters(vec![4.0])
};

// 受理点の (λ, u(1/2))。中点 x = 1/2 は 0 始まりの添字で n/2。

    .filter_map(|i| state.history_point(i).map(|y| [y[n], y[n / 2]]))
    .collect();
// 参照値（独立な検算）: 連続問題の解析解 u(1/2) = 2 ln cosh(θ/4)、λ = θ²/(2 cosh²(θ/4))。
let analytic: Vec<[f64; 2]> = (1..=240)
    .map(|i| 0.05 * i as f64)
    .map(|t| {
        let c = RealScalar::cosh(t / 4.0);
        [t * t / (2.0 * c * c), 2.0 * RealScalar::ln(c)]
    })
    .collect();
let series = vec![
    serde_json::json!({
        "name": "連続問題の解析解",
        "points": analytic,
        "style": { "lineType": "dashed" }
    }),
    serde_json::json!({
        "name": format!("{path}の受理点（N = {n}）"),
        "points": computed,
        "style": { "lineType": "dotted", "showSymbol": true }
    }),
];
emit_line_chart!(
    &series,
    options = &serde_json::json!({
        "xLabel": "パラメータ λ [-]",
        "yLabel": "中点の値 u(1/2) [-]",
        "xMin": 0.0,
        "xMax": 4.0,
        "yMin": 0.0,
        "yMax": 8.0,
        "annotations": [
            { "kind": "line", "axis": "x", "value": 3.5138307, "label": "λc（連続問題）" }
        ]
    })
);

let largest = history
    .iter()
    .map(|o| o.parameter())
    .fold(f64::NEG_INFINITY, f64::max);
let corrections: usize = history.iter().map(|o| o.corrector_iterations()).sum();
let rejected: usize = history.iter().map(|o| o.rejected_steps()).sum();
let candidates = history
    .iter()
    .filter(|o| o.turning_point_candidate())
    .count();
let termination = state.termination();
let fixed6 = serde_json::json!({ "notation": "standard", "fractionDigits": 6 });
let columns = serde_json::json!([
    { "key": "0", "label": "終了状態" },
    { "key": "1", "label": "受理点 [点]", "type": "integer" },
    { "key": "2", "label": "λ の最大 [-]", "type": "number", "format": fixed6 },
    { "key": "3", "label": "補正の反復の合計 [回]", "type": "integer" },
    { "key": "4", "label": "退けた提案の合計 [回]", "type": "integer" },
    { "key": "5", "label": "折り返し点の候補 [点]", "type": "integer" }
]);

    history.len(),
    largest,
    corrections,
    rejected,
    candidates,

    RootTermination::TangentFailure => {
        Outcome::failed("接線を求められず、経路の先へ進めなかった")
    }
    _ => Outcome::partial("経路の途中で止まった")
        .explanation("受理点までの枝は使えるが、要求した経路の終わりには届いていない。"),
};

    .status(termination.to_string())
    .diagnostic("受理点", history.len() as f64, None)
    .diagnostic("λ の最大", largest, None);

既定の $N = 31$、擬弧長 8 の擬弧長継続は 82 点を受理して `Complete` で終わり、折り返し点の候補が 1 点ある。
受理点は解析解の曲線に沿って下側の枝を上り、$\lambda_c$ の手前で折り返して上側の枝に入る。
受理点の $\lambda$ の最大は 3.511712 で、補正の反復は合計 302 回、退けた提案は 0 回である。
擬弧長を 2 にすると折り返し点に届かず、$\lambda$ の最大は 1.985181 で終わる。

経路を自然継続にすると、受理点は下側の枝を上り、$\lambda = 3.512044$ で `StepLimit` になる。
折り返し点の近くで修正子が失敗し続け、退けた提案は合計 16 回に達する。
上側の枝の点は一つもなく、目標の $\lambda = 4$ には解がないので、自然継続ではこの先へ進めない。
自然継続は失敗する補正に多くの反復を使うので、このセルでは擬弧長継続より計算時間が長い。

## 格子の細かさと折り返し点の誤差

差分の打切り誤差は $O(h^2)$ なので、離散化した問題の折り返し点 $\lambda_c(h)$ は $h \to 0$ で $\lambda_c$ に $O(h^2)$ で近づくはずである。
受理点の $\lambda$ の最大は、刻み $\Delta s$ で標本化した値なので、離散化の誤差に標本化の誤差が加わる。
次のセルは $N = 7, 15, 31$（$h = 1/8, 1/16, 1/32$）で擬弧長 8 の継続を行い、$\lambda$ が最大の受理点とその前後の 3 点を通る放物線 $\lambda(s)$ の頂点 $\lambda^*$ で折り返し点を見積もる。
入力は刻みの上限（刻みの初期値も同じ値にする）で、標本化の誤差の大きさを変える。
出力は $\lambda^* - \lambda_c$ と、前の行との誤差の比である。
$h$ を半分にするので、$O(h^2)$ なら比は 4 に近づく。
3 つの継続がすべて `Complete` なら satisfied、どれかが途中で止まれば partial にし、状態の名前には最も細かい $N = 31$ の終了状態を出す。

```rust
//| id: rootfind-bratu-grid-convergence
//| ref: rootfind-bratu-grid-convergence
//| title: 格子を細かくして継続法で求めた折り返し点の収束次数を調べる
//| run: button
//| uses: [rootfind-bratu-model]
//| crates: [scioxide-core, scioxide-rootfind]
//| inputs:
//|   largest_step: {"type":"select","label":"擬弧長の刻みの上限 [-]","description":"刻みの初期値も同じ値にする。","options":["0.1","0.05","0.02","0.01"],"value":"0.02"}
//| cases:
//|   - {"id":"coarse-step","label":"刻みの上限 0.1（標本化の誤差が大きい）","description":"誤差の比は 4.06 と 4.18 に乱れ、収束次数を読み取りにくくなる。","inputs":{"largest_step":"0.1"}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"orders","path":"/rows/0/5","approx":{"value":-2.87e-2,"atol":5e-5}}
//|       - {"artifact":"orders","path":"/rows/1/5","approx":{"value":-7.15e-3,"atol":5e-6}}
//|       - {"artifact":"orders","path":"/rows/2/5","approx":{"value":-1.79e-3,"atol":5e-6}}
//|       - {"artifact":"orders","path":"/rows/1/6","approx":{"value":4.02,"atol":5e-3}}
//|       - {"artifact":"orders","path":"/rows/2/6","approx":{"value":4.00,"atol":5e-3}}
//|       - {"artifact":"orders","path":"/rows/2/4","approx":{"value":3.512045,"atol":5e-7}}
//|       - {"path":"/outputs/1/state","equals":"satisfied"}
//|   - case: coarse-step
//|     expect:
//|       - {"artifact":"orders","path":"/rows/1/6","approx":{"value":4.06,"atol":5e-3}}
//|       - {"artifact":"orders","path":"/rows/2/6","approx":{"value":4.18,"atol":5e-3}}
//|       - {"path":"/outputs/1/state","equals":"satisfied"}
use scioxide_rootfind::ContinuationPath;

let step: f64 = largest_step.parse().map_err(|_| "刻みの上限を読めない")?;
// 受理点の (擬弧長 s, λ) の列から、λ が最大の点とその前後の 3 点を通る放物線 λ(s) の頂点を求める。
let fold = |points: &[[f64; 2]]| {
    let k = (1..points.len() - 1)
        .max_by(|&a, &b| points[a][1].total_cmp(&points[b][1]))
        .ok_or("受理点が 3 点に満たない")?;
    let ([s0, l0], [s1, l1], [s2, l2]) = (points[k - 1], points[k], points[k + 1]);
    // 差分商による Newton 形 λ(s) = l0 + d1 (s − s0) + c (s − s0)(s − s1) の頂点。
    let (d1, d2) = ((l1 - l0) / (s1 - s0), (l2 - l1) / (s2 - s1));
    let curvature = (d2 - d1) / (s2 - s0);
    let top = 0.5 * (s0 + s1) - d1 / (2.0 * curvature);
    let vertex = l0 + d1 * (top - s0) + curvature * (top - s0) * (top - s1);
    Ok::<_, String>((l1, vertex))
};
let exact = 3.513830719;
let mut rows = Vec::new();
let mut previous: Option<f64> = None;
let mut completed = 0;
for n in [7, 15, 31] {
    // 擬弧長 8 だけ進める。刻みの初期値と上限は同じ値にする。
    let state = trace(n, ContinuationPath::PseudoArclength(8.0), step, step, 1000)?;
    let h = 1.0 / (n + 1) as f64;
    let status = state.termination().to_string();
    if !state.is_success() {
        rows.push((n, h, status, None, None, None, None));
        previous = None;
        continue;
    }
    completed += 1;
    let points: Vec<[f64; 2]> = state
        .history()
        .iter()
        .map(|o| [o.arclength(), o.parameter()])
        .collect();
    let (largest, vertex) = fold(&points)?;
    let error = vertex - exact;
    let ratio = previous.map(|p| p / error);
    rows.push((
        n,
        h,
        status,
        Some(largest),
        Some(vertex),
        Some(error),
        ratio,
    ));
    previous = Some(error);
}
let fixed6 = serde_json::json!({ "notation": "standard", "fractionDigits": 6 });
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let fixed2 = serde_json::json!({ "notation": "standard", "fractionDigits": 2 });
let fixed5 = serde_json::json!({ "notation": "standard", "fractionDigits": 5 });
let columns = serde_json::json!([
    { "key": "0", "label": "N [-]", "type": "integer" },
    { "key": "1", "label": "h [-]", "type": "number", "format": fixed5 },
    { "key": "2", "label": "終了状態" },
    { "key": "3", "label": "受理点の λ の最大 [-]", "type": "number", "format": fixed6, "nullText": "-" },
    { "key": "4", "label": "放物線の頂点 λ* [-]", "type": "number", "format": fixed6, "nullText": "-" },
    { "key": "5", "label": "λ* − λc [-]", "type": "number", "format": sci3, "nullText": "-" },
    { "key": "6", "label": "前の行との誤差の比 [-]", "type": "number", "format": fixed2, "nullText": "-" }
]);
let finest = rows.last().map(|r| (r.2.clone(), r.6));
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "orders" })
);

let mut outcome = if completed == 3 {
    Outcome::satisfied("3 つの格子で擬弧長 8 の継続がすべて Complete になった")
} else {
    Outcome::partial("途中で止まった継続があり、その格子の頂点を求めていない")
};
if let Some((status, _)) = &finest {
    outcome = outcome.status(status.clone());
}
outcome = outcome.diagnostic("Complete の数", completed as f64, None);
if let Some((_, Some(ratio))) = finest {
    outcome = outcome.diagnostic("最も細かい格子の誤差の比", ratio, None);
}
emit_outcome!(outcome);
```

既定の刻みの上限 0.02 では、$\lambda^* - \lambda_c$ は $-2.87 \times 10^{-2}$、$-7.15 \times 10^{-3}$、$-1.79 \times 10^{-3}$ で、誤差の比は 4.02 と 4.00 になり、$O(h^2)$ の収束と整合する。
$N = 31$ の $\lambda^* = 3.512045$ は、前のセルの自然継続が止まった $\lambda = 3.512044$ ともよく合う。
二つの行から Richardson 補外 $\lambda^*(h) + \bigl(\lambda^*(h) - \lambda^*(2h)\bigr)/3$ を手計算すると 3.513833 になり、$\lambda_c$ との差は約 $2.5 \times 10^{-6}$ に縮む。
刻みの上限を 0.1 にすると比は 4.06 と 4.18 に乱れ、$N = 31$ では受理点の $\lambda$ の最大が $\lambda^*$ より $6.7 \times 10^{-4}$ 小さい。
標本化の誤差が離散化の誤差と同じ程度になると、収束次数を読み取れなくなる。

## 接線の線形方程式と行の尺度

セルで式に $h^2$ を掛けたのは、接線の線形方程式の解き方による。
`Continuation` は既定で、縁付きの方程式を前処理なしの GMRES（再始動 30、最大 200 反復）で相対残差 $100\varepsilon$ まで解き、元の作用で独立に検査する（`with_tangent_solver` で変えられる）。
$1/h^2$ の大きさの行のままでは丸め誤差だけでこの検査を満たせず、$N = 31$ でシードの接線の検査に失敗して `ConvergenceFailure`（`initial tangent could not be verified`）のエラーになる。
$h^2$ を掛けても、$N = 63$ では前処理なしの GMRES が 200 反復でこの精度に届かず、同じエラーになる。
大きな問題では前処理や直接法を `NonlinearLinearSolver` として実装し、`ContinuationProblem::with_linear_solver` で $n+1$ 次の拡大系の解法として渡す。
この解法は修正子の Newton 方程式と接線の方程式の両方を解き、接線の方程式には `with_tangent_solver` の許容誤差を使う。

## まとめ

自然継続は $\lambda$ を固定した方程式を解くので折り返し点で `StepLimit` か `TangentFailure` になり、擬弧長継続は $\lambda$ も未知数にして拡大系の正則性により折り返し点を越える。
受理点ごとに元の方程式の残差と弧長の拘束を別々に検査し、刻みは退けると半分、条件のよい受理が続くと 1.5 倍になるので、`StepLimit` は刻みの下限まで縮めても進めなかったことを表す。
`with_scales` で状態と $\lambda$ の単位をそろえ、行の大きさをそろえて接線の検査を通るようにし、大きな問題では `with_linear_solver` で前処理付きの解法を渡す。
折り返し点の候補は数値的な観察なので、Bratu 問題のように解析解や格子の収束（比 4 の $O(h^2)$）で確かめる。
