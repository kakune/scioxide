自己無撞着な場の計算や反復的なモデル更新では、$x = G(x)$ を満たす固定点を求める。
固定点の方程式の残差は $r(x) = G(x) - x$ であり、反復で実際に動かす更新量とは区別する。
緩和係数 $\alpha$ が小さければ更新量 $\alpha\, r(x)$ は小さくなるが、残差 $r(x)$ まで小さいとは限らない。
縮小写像の理論は計算できる残差から位置の誤差の上界を与える。

## 縮小写像と誤差の上界

完備距離空間 $D$（$\mathbb{R}^n$ の閉集合など）を自身へ写す $G$ が

$$
\|G(x)-G(y)\|\le q\|x-y\|,\qquad 0\le q<1
$$

を満たすとき、$G$ を縮小率 $q$ の縮小写像という。
Banach の不動点定理により、$D$ の中に固定点 $x_*$ がただ一つあり、Picard 反復 $x_{k+1} = G(x_k)$ はどの $x_0 \in D$ からもそこへ収束する。
誤差は $\|x_{k+1} - x_*\| = \|G(x_k) - G(x_*)\| \le q \|x_k - x_*\|$ なので 1 次収束で、誤差を 1 桁減らすには約 $\ln 10 / \ln(1/q)$ 回の反復が要る。
$q = 0.8$ なら約 10 回、$q = 0.95$ なら約 45 回である。

三角不等式から $\|x_k - x_*\| \le \|x_k - G(x_k)\| + \|G(x_k) - G(x_*)\| \le \|r(x_k)\| + q \|x_k - x_*\|$ なので、

$$
\|x_k-x_*\|\le\frac{\|G(x_k)-x_k\|}{1-q}
$$

が成り立つ。
これは計算できる残差から位置の誤差を抑える事後の上界で、$q$ が 1 に近いほど係数 $1/(1-q)$ が大きくなる。
この上界には、領域全体で成り立つ既知の縮小率 $q$ が必要である。
数回の反復から測った残差の比を、そのまま証明用の $q$ として使ってはいけない。
微分可能な写像の局所的な収束では、$G'(x_*)$ のスペクトル半径が 1 より小さいことが基本の条件になる。

## 緩和と七つの方法

緩和付きの反復は $G_\alpha(x) = x + \alpha\, r(x)$ を使う。
固定点の近くでは誤差の線形部分が $I + \alpha(G'(x_*) - I)$ となり、$G'(x_*)$ の固有値 $\lambda$ は $1 + \alpha(\lambda - 1)$ に写る。
したがって緩和は収束の速さと安定性の両方を変えるが、小さい $\alpha$ がどんな発散も解消するわけではない。

| `FixedPointMethod` | 更新の考え方 | 注意点 |
|---|---|---|
| `Picard` | $x + \alpha r$ | 履歴を使わない基本の緩和反復 |
| `Steffensen` | 緩和写像を 2 回評価し、成分ごとに Aitken の $\Delta^2$ 加速を掛ける | 1 反復の評価は 2 回。分母が小さい成分は加速を省き、成分の間の結合は表さない |
| `Anderson` | 残差の差分の最小二乗による type II 加速 | 履歴の一次従属性と成分の尺度が影響する |
| `BroydenFirst` | 残差のヤコビ行列の逆の近似 $H$（初期値 $-\alpha I$）を、割線条件を満たす第 1 の（good）Broyden 更新で直す | 割線の分母が小さい更新は省く |
| `BroydenSecond` | 同じ $H$（初期値 $-\alpha I$）を第 2 の（bad）Broyden 更新で直す | 残差の差分の方向を使った階数 1 の更新 |
| `DiagonalBroyden` | ヤコビ行列の対角成分だけを Broyden 則で直す | 成分の間の強い結合を表さない。対角が小さくなりすぎると $\alpha$ に戻す |
| `ExcitingMixing` | 残差の各成分の符号が続けば混合係数を $\alpha$ ずつ増やし、変われば $\alpha$ に戻す | 実数のみ。係数の上限は `with_maximum_mixing`（既定 1）で、既定の $\alpha = 1$ では `Picard` と同じ更新になる |

Steffensen 法のスカラーの式は、$y = G_\alpha(x)$、$z = G_\alpha(y)$ として $x - (y - x)^2 / (z - 2y + x)$ である。
これは $x$、$y$、$z$ を誤差が等比数列で減る列の 3 項とみなしたときの極限で、線形の写像には 1 回で正確な固定点を与える。
滑らかなスカラーの固定点で $G'(x_*) \ne 1$ なら局所的な 2 次収束が期待できるが、成分ごとの拡張には多変数 Newton 法の収束定理をそのまま当てはめられない。

## Anderson 加速と履歴

Anderson 加速は直近 $m + 1$ 個の点から $m$ 列の差分 $\Delta X = [x_{k-m+1} - x_{k-m}, \dots, x_k - x_{k-1}]$ と、同じ並びの残差の差分 $\Delta R$ を作り、最小二乗問題

$$
\gamma_k = \arg\min_\gamma \|r_k - \Delta R\, \gamma\|_2
$$

を解く。
$r_k - \Delta R\, \gamma$ は過去の残差の組み合わせで現在の残差をできるだけ打ち消したものである。
type II の提案は

$$
x_{k+1}=x_k+\alpha r_k-(\Delta X+\alpha\Delta R)\gamma_k
$$

で、$m = 0$ なら Picard 反復に戻る。
線形の写像では、履歴を切り捨てない Anderson 加速（$\alpha = 1$）は、方程式 $(I - G')x = G(0)$ に GMRES を当てた反復と同等になることが知られている（Walker と Ni, 2011）。
そのため、履歴の長さ $m$ が未知数の数 $n$ 以上あれば、線形の問題は丸め誤差を除いて高々 $n + 1$ 回程度の反復で解ける。
非線形の問題でも、固定点の近くでは同じ理由で、履歴が $G'$ の主な方向を覆うほど速くなる。

実装は成分の尺度で割った履歴の行列を列ピボット付きの Householder QR で分解し、数値的な階数を調べる。
階数の判定の既定は `RankPolicy::DimensionScaledEpsilon` で、`with_rank_policy` で変えられる。
既定の正則化は 0 で、階数 $r$ が $m$ より小さいと、ピボットの順で $r + 1$ 番目の列（数値的に従属と判定された最初の列）を履歴から捨て、省いた更新として数えて分解し直す。
`with_regularization` で $\lambda > 0$ を与えた場合だけ、列を捨てる代わりに $\sqrt\lambda\, I$ の行を加えた Tikhonov 正則化の最小二乗を毎回解き、その回数を数える。
正則化しても解けない場合は `InvalidInput` のエラーになる。

履歴を使う方法が保持する組は、`with_history` で与えた長さと未知数の数 $n$ の小さい方 $m = \min(m_{\max}, n)$ までである（既定の $m_{\max}$ は 5）。
主なメモリ使用量は $O(nm)$、1 反復の最小二乗の演算量はおおむね $O(nm^2)$ である。
履歴を長くしても常に速くなるとは限らず、古い履歴や一次従属に近い差分が妨げになる場合がある。
履歴が満杯になったとき、`HistoryRestart::Oldest` は最も古い組を捨て、`Restart` は履歴全体を捨てる。
`FixedPointDiagnostics` の `history_rank`、`skipped_updates`、`restarts`、`regularized_solves` から、この処理を観察できる。

## 入力と停止判定

`FixedPointInput::Map` では、`ResidualOperator` が $G(x)$ を返し、求解側が $G(x) - x$ を残差にする。
`FixedPointInput::Residual` ではコールバックが $F(x)$ を返し、基本の提案は $x + \alpha F(x)$ になる。
$F = x - G(x)$ を渡すと符号が逆になるので、定義を確かめる必要がある。
`ResidualFn` は、この作用をクロージャで与える型である。

停止判定は次のとおりである。

- `ResidualTolerance`：成分の尺度で割った残差の L2 ノルムが許容誤差を満たした。
  既定は絶対 0、初期の残差のノルムに対する相対 $\sqrt{\varepsilon}$ で、`with_residual_scale` で基準を固定できる。
  初期点が厳密な固定点なら、反復せずに成功する。
- `Stagnation`：提案が現在の点と一致したか、更新が座標の許容誤差 $\|\Delta x\|_2 \le \tau_a + \tau_r \max(1, \|x\|_2)$（既定は $\tau_a = \tau_r = \sqrt\varepsilon$）を満たすのに尺度付きの残差が減らなかった。
  座標の許容誤差を 0 にすると、後者の検査は行わない。
  この判定は根を保証せず、成功を決めるのは残差の判定だけである。
- `IterationLimit`：反復の上限（既定 200 回）に達した。

`with_residual_tolerance` は残差の許容誤差を、`with_step_tolerance` は座標の許容誤差を、`with_component_scales` は成分ごとの正の除数を設定する。
除数は停止判定と Anderson の最小二乗の両方に使われる。

`FixedPointSolver` は手法、入力の意味、`FixedPointOptions` を保持する。
`workspace_requirements` が返す `FixedPointWorkspaceRequirements` に従って `workspace` で `FixedPointWorkspace` を作り、`FixedPointResult::new(n)` とともに `solve_into` で再利用する。
所有した結果を返す `solve` はこの準備を内部で行う。
設定も診断も要らなければ、ワンショット関数 `fixed_point(g, initial)` が深さ $\min(5, n)$ の Anderson 加速と既定の設定で $G$ の固定点を求め、成功したときだけ点を返し、それ以外の終了は `ConvergenceFailure` などのエラーにする。
反復の上限や評価回数などの上限による停止では、最後に受理した点と未収束の終了理由が出力に入り、それ以外の `Err` では借用した出力を変えない。
`FixedPointResult` の `residual_norm()` は返した点での残差 $G(x) - x$ の L2 ノルム（除数で割る前）、`scaled_residual_norm()` は停止判定に使った尺度付きのノルムである。

## 縮小率と履歴を変える比較

次の写像は $\mathbb{R}^6$ 上の縮小写像で、固定点は解析的に $x_* = 0$ と分かる。

$$
G(x)_i = q \sin x_{i+1} \quad (i = 1, \dots, 6,\ x_7 = x_1), \qquad 0 < q < 1
$$

$\lvert \sin a - \sin b \rvert \le \lvert a - b \rvert$ と、添字をずらす写像がノルムを保つことから、Euclid ノルムでの縮小率は高々 $q$ である。
固定点でのヤコビ行列は $q$ 倍の巡回置換で、固有値 $q e^{2\pi i k/6}$（$k = 0, \dots, 5$）は半径 $q$ の円周上に等間隔に並ぶ。
固有値の絶対値はすべて $q$ で、$\pm q$ を除く 4 個は実数でない。
そのため成分ごとの加速や緩和では速くならず、6 方向を同時に扱う履歴が要る。

次のセルは七つの方法を同じ初期値 $x_i = \cos i$ から既定の許容誤差で実行する。
入力は縮小率 $q$、緩和係数 $\alpha$、履歴の長さ $m$ で、出力は終了理由、反復回数、写像の評価回数、既知の固定点との距離、残差から得た上界 $\|r\|/(1-q)$、履歴の診断である。
セルの最後の判定は、七つの方法がすべて成功の終了理由なら satisfied、止まった方法があれば partial とし、Anderson 加速の終了理由と、距離を上界で割った比の最大値を添える。

```rust
    for i in 0..N {
        out[i] = q * RealScalar::sin(x[(i + 1) % N]);
    }
    Ok(())

    FixedPointMethod::Steffensen,

emit_outcome!(
    outcome
        .status(status.to_string())

```

既定の入力（$q = 0.8$、$\alpha = 1$、$m = 5$）では、すべての方法が `ResidualTolerance` で終わる。
Picard 反復は 80 回（評価 81 回）かかり、固定点との距離 $2.3 \times 10^{-8}$ は上界 $1.1 \times 10^{-7}$ の内側にある。
Anderson 加速は 13 回（評価 14 回）で止まり、Broyden 型は 37 回と 42 回、Steffensen 法は 70 回だが評価は 141 回で、評価回数では Picard 反復より多い。
`DiagonalBroyden` は 144 回と Picard 反復より遅い。
固定点でのヤコビ行列の対角成分は 0 なので、対角だけのモデルでは写像の性質を表せない。
`ExcitingMixing` は既定の上限 1 と $\alpha = 1$ で混合係数を増やせないので Picard 反復と同じ結果になり、再始動の数は残差の成分の符号が変わった回数を表す。

履歴の長さを変えると、Anderson 加速の反復は $m = 1$ で 75 回、$m = 2$ で 67 回、$m = 4$ で 36 回、$m = 5$ で 13 回、$m = 6$ と $m = 8$ で 11 回になる。
履歴の階数は $\min(m, 6)$ で頭打ちになり、$m \ge 6$ で 6 方向の固有値をすべて扱えるようになると、それ以上長くしても変わらない。
$q = 0.95$ では Picard 反復が上限の 200 回に達して `IterationLimit` で止まり、距離 $3.3 \times 10^{-5}$ が残る一方、Anderson 加速は 22 回で収束する。
同じ $q = 0.95$ で `BroydenFirst` は発散し、距離 $1.5 \times 10^{21}$ の点を `IterationLimit` とともに返すので、終了理由を確かめずに点を使ってはいけない。
$\alpha = 0.2$ では Picard 反復も上限に達し、`ExcitingMixing` は係数を上限 1 まで増やして 118 回で収束する。
同じ $\alpha = 0.2$ でも `BroydenFirst` は発散して `IterationLimit` で止まるので、緩和を強めれば Broyden 型の更新が安定するわけではない。
どの行でも、固定点との距離は残差からの上界を超えない。
上界は縮小写像の数学的な性質から導いた値だが、残差の評価には丸め誤差があるので、区間演算による包含が保証された区間ではない。

## 線形写像による検算

非線形の比較に加えて、1 次元の線形写像 $G(x) = q x + 1$ を使う。
固定点は閉形式で $1/(1 - q)$ と分かり、Picard 反復の誤差はちょうど $q^k$ 倍ずつ減る。
次のセルは `Picard`、`Steffensen`、`Anderson` を $x_0 = 0$ から、残差の絶対許容誤差 $10^{-12}$、座標の許容誤差 $10^{-14}$ で解く。
入力は縮小率 $q$ で、出力は終了理由、固定点、求解側が返す残差 `residual_norm()`、閉形式との差（独立な検算）、写像の評価回数と、三つの方法の終了理由から決めたセルの判定である。

```rust
//| id: rootfind-fixed-point-acceleration
//| ref: rootfind-fixed-point-acceleration
//| title: 縮小率と履歴加速を既知の固定点で比較する
//| run: reactive
//| crates: [scioxide-core, scioxide-rootfind]
//| inputs:
//|   contraction_rate: {"type":"range","label":"縮小率 q [-]","description":"単純反復の収束の速さを変える。","min":0.2,"max":0.9,"step":0.1,"value":0.8}
//| cases:
//|   - {"id":"slow-contraction","label":"q = 0.9（縮小が弱い）","description":"Picard 反復の評価は 264 回に増えるが、Steffensen 法と Anderson 加速は 3 回のままである。","inputs":{"contraction_rate":0.9}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"linear","path":"/rows/0/1","equals":"ResidualTolerance"}
//|       - {"artifact":"linear","path":"/rows/0/3","approx":{"value":9.6e-13,"rtol":1e-2}}
//|       - {"artifact":"linear","path":"/rows/0/4","approx":{"value":4.8e-12,"rtol":1e-2}}
//|       - {"artifact":"linear","path":"/rows/0/5","equals":125}
//|       - {"artifact":"linear","path":"/rows/1/1","equals":"ResidualTolerance"}
//|       - {"artifact":"linear","path":"/rows/1/5","equals":3}
//|       - {"artifact":"linear","path":"/rows/2/1","equals":"ResidualTolerance"}
//|       - {"artifact":"linear","path":"/rows/2/5","equals":3}
//|       - {"path":"/outputs/1/state","equals":"satisfied"}
//|   - case: slow-contraction
//|     expect:
//|       - {"artifact":"linear","path":"/rows/0/1","equals":"ResidualTolerance"}
//|       - {"artifact":"linear","path":"/rows/0/5","equals":264}
//|       - {"artifact":"linear","path":"/rows/1/5","equals":3}
//|       - {"artifact":"linear","path":"/rows/2/5","equals":3}
//|       - {"path":"/outputs/1/state","equals":"satisfied"}
use scioxide_core::{Budget, EvaluationRole, ResidualTolerance, StepTolerance};
use scioxide_rootfind::{
    FixedPointInput, FixedPointMethod, FixedPointOptions, FixedPointSolver, ResidualFn,
};

// 残差と座標の変化の許容誤差、反復の上限。
let options = FixedPointOptions::default()
    .with_residual_tolerance(
        ResidualTolerance::new(1.0e-12_f64, 0.0).map_err(|e| e.to_string())?,
    )
    .with_step_tolerance(StepTolerance::new(1.0e-14, 0.0).map_err(|e| e.to_string())?)
    .with_max_iterations(Budget::try_from(800).map_err(|e| e.to_string())?);

// 縮小写像 G(x) = q x + 1。
let map = ResidualFn::new(1, |x: &[f64], out: &mut [f64]| {
    out[0] = contraction_rate * x[0] + 1.0;
    Ok(())
});
// 独立な検算: 閉形式の固定点 1/(1 − q)。
let expected = 1.0 / (1.0 - contraction_rate);
let (mut rows, mut all_success, mut largest_error) = (Vec::new(), true, 0.0_f64);
for method in [
    FixedPointMethod::Picard,
    FixedPointMethod::Steffensen,
    FixedPointMethod::Anderson,
] {
    let result = FixedPointSolver::new(method, FixedPointInput::Map, options.clone())
        .map_err(|e| e.to_string())?
        .solve(&map, &[0.0])
        .map_err(|e| e.to_string())?;
    let x = result.point()[0];
    let residual = result.residual_norm().ok_or("残差がまだ評価されていない")?;
    all_success &= result.is_success();
    largest_error = largest_error.max((x - expected).abs());
    rows.push((
        format!("{method:?}"),
        result.termination().to_string(),
        x,
        residual,
        (x - expected).abs(),
        result.counts().provider(EvaluationRole::Function),
    ));
}
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let digits16 = serde_json::json!({ "notation": "standard", "significantDigits": 16 });
let columns = serde_json::json!([
    { "key": "0", "label": "方法" },
    { "key": "1", "label": "終了理由" },
    { "key": "2", "label": "固定点 x [-]", "type": "number", "format": digits16 },
    { "key": "3", "label": "示された残差 |G(x) − x| [-]", "type": "number", "format": sci2 },
    { "key": "4", "label": "閉形式との差 [-]", "type": "number", "format": sci2 },
    { "key": "5", "label": "写像の評価 [回]", "type": "integer" }
]);
// 行の順は Picard、Steffensen、Anderson。判定には Anderson 加速の行を添える。
let (anderson_status, anderson_evaluations) = (rows[2].1.clone(), rows[2].5 as f64);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "linear" })
);
let outcome = if all_success {
    Outcome::satisfied("三つの方法がすべて残差の許容誤差を満たした")
} else {
    Outcome::partial("残差の許容誤差を満たす前に止まった方法がある")
};
emit_outcome!(
    outcome
        .status(anderson_status)
        .diagnostic("Anderson 加速の写像評価", anderson_evaluations, None)
        .diagnostic("閉形式との差の最大", largest_error, None)
);
```

Picard 反復は $q = 0.8$ で 125 回、$q = 0.9$ で 264 回を評価し、示された残差が許容誤差 $10^{-12}$ 以下になったところで止まる。
線形の写像では $r(x) = (q - 1)(x - x_*)$ なので、閉形式との差は示された残差の $1/(1 - q)$ 倍にちょうど等しく、$q = 0.8$ では $9.6 \times 10^{-13} / 0.2 = 4.8 \times 10^{-12}$ になる。
Steffensen 法と Anderson 加速は、どの $q$ でも 3 回の評価で丸め誤差の範囲の固定点に達する。
Steffensen 法は 1 反復の Aitken 外挿で線形の写像の固定点を正確に与え、Anderson 加速も 1 本の履歴で線形の残差を打ち消せるからである。
この線形問題での加速の効果は一般の非線形問題での評価回数を保証するものではない。

## まとめ

固定点反復ではまず写像の定義と残差 $G(x) - x$ の符号の約束を確かめる。
領域全体で成り立つ縮小率 $q$ が分かっていれば、示された残差を $\|r\|/(1-q)$ で位置の誤差の上界に換算できるが、$q$ が 1 に近いと上界も反復回数も大きくなる。
固有値が実数でない場合や $q$ が 1 に近い場合は、履歴の長さを未知数の数程度まで取った Anderson 加速が有効で、その効果は `history_rank` と `skipped_updates` で確かめる。
加速法は履歴と追加の評価を使うので、反復回数だけでなく写像の評価回数で比べる。
