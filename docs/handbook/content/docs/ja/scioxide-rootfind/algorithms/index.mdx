この章の数理ページは方程式 $f(x) = 0$（$x \in \mathbb{R}$ または $\mathbb{C}$）、$\mathbf{F}(\mathbf{x}) = \mathbf{0}$（$\mathbf{x} \in \mathbb{R}^n$）、多項式 $p(z) = 0$ を反復で解く方法を扱う。
多くの方法は根の存在を保つ仕組み（符号の変わる区間）と、根の近くで速く収束する局所モデル（Taylor 展開や補間）を組み合わせている。
記号、収束の次数、残差と位置の誤差、停止判定はどのページでも同じ意味で使う。

## 記号

| 記号 | 意味 |
|---|---|
| $x^*$、$\hat x$ | 真の根、計算した近似 |
| $e_k = x_k - x^*$ | 第 $k$ 反復の誤差 |
| $[a_k, b_k]$、$w_k = b_k - a_k$ | 根を挟む区間とその幅 |
| $J(\mathbf{x}) = \partial \mathbf{F}/\partial \mathbf{x}$ | ヤコビ行列 |
| $p$ | 収束の次数（下の定義） |
| $\varepsilon$ | 機械イプシロン（binary64 では $2^{-52}$）。[数値計算の記号と用語](../../reference/)の $\epsilon_{\mathrm{mach}}$ と同じ量 |
| $\varepsilon_{\mathrm{res}}$、$\varepsilon_{\mathrm{step}}$ | 残差（関数の単位）と座標の変化（変数の単位）の許容誤差 |

## 収束の次数と評価の効率

反復 $x_k \to x^*$ が次数 $p \ge 1$ で収束するとは、ある定数 $C > 0$（$p = 1$ では $C < 1$）について、十分大きい $k$ で

$$
\lvert e_{k+1} \rvert \le C \lvert e_k \rvert^p
$$

が成り立つことをいう。
$p = 1$ を 1 次収束、$p = 2$ を 2 次収束と呼び、$\lvert e_{k+1} \rvert / \lvert e_k \rvert \to 0$ となる収束を超 1 次収束と呼ぶ。
$p > 1$ なら、正しい桁数は 1 反復ごとにおよそ $p$ 倍になる。
これは根の近くでの局所的な性質で、初期値が遠いときの振る舞いは別に調べる必要がある。

方法を比べるときは、1 反復の計算コストも考える。
1 反復に関数（または導関数）を $w$ 回評価する方法は、評価 1 回あたりの次数が $p^{1/w}$ になる（Ostrowski の効率指数）。
導関数の評価が関数と同じ計算コストなら、Newton 法（$p = 2$、$w = 2$）は $\sqrt 2 \approx 1.414$、割線法（$p \approx 1.618$、$w = 1$）は $1.618$ で、割線法の方が評価あたりでは速い。
scioxide-rootfind の結果は、関数・1 階導関数・2 階導関数の評価回数を別々に数えるので、この比較を実測で確かめられる。

## 残差と位置の誤差

残差 $f(\hat x)$ は計算できるが、知りたいのは位置の誤差 $\hat x - x^*$ である。
平均値の定理から、$\hat x$ と $x^*$ の間のある $\xi$ について

$$
f(\hat x) = f(\hat x) - f(x^*) = f'(\xi)\,(\hat x - x^*)
$$

なので、単純根（$f'(x^*) \ne 0$）の近くでは $\lvert \hat x - x^* \rvert \approx \lvert f(\hat x) \rvert / \lvert f'(x^*) \rvert$ である。
$1/\lvert f'(x^*) \rvert$ は、関数の値の誤差が根の位置へ伝わる倍率で、根の（絶対）条件数と呼ぶ。

浮動小数点での評価には、根の近くでも大きさ $\delta$ 程度の誤差がある。
すると、$\lvert f \rvert \le \delta$ となる幅およそ $2\delta / \lvert f'(x^*) \rvert$ の範囲では、計算した $f$ の符号がほとんど決まらず、どの求根法もこれより細かく根の位置を決められない。
重複度 $m$ の根では $f(x) \approx f^{(m)}(x^*)(x - x^*)^m / m!$ なので、この範囲の幅は $(m!\,\delta / \lvert f^{(m)}(x^*) \rvert)^{1/m}$ の程度に広がる。
例えば $\delta \approx 10^{-16}$、$m = 4$ なら、位置は $10^{-4}$ 程度しか決まらない。
逆に $\lvert f'(x^*) \rvert$ が大きい根では、位置が丸め誤差の範囲で正しくても残差は大きく見える。

`ScalarRootOptions` は、関数の単位の `ResidualTolerance` と座標の単位の `StepTolerance` を別々に設定する。
残差の相対基準に使う尺度は、`with_residual_scale` で関数の単位の正の値として明示できる。
誤差・許容誤差・残差の一般的な区別は[許容誤差と残差の尺度化理論](../../concepts/tolerances-and-residuals/)と[浮動小数点数と条件数](../../concepts/floating-point-and-conditioning/)で扱う。

## 1 変数の方法の既定の停止判定

`ScalarRootOptions::default()` の判定は方法の種類で次のように分かれる。

| 方法の種類 | 既定で成功とする条件 | 終了理由 |
|---|---|---|
| すべての方法 | 評価した関数値が厳密に 0 | `ResidualTolerance` |
| 区間法と区間で保護した方法 | 区間の幅 $b - a \le 4\varepsilon + 4\varepsilon \max(\lvert a \rvert, \lvert b \rvert)$ | `BracketTolerance` |
| 区間を持たない方法（実数・複素数） | 更新 $\lvert x_{k+1} - x_k \rvert$ が同じ座標の許容誤差を満たし、かつ $\lvert f(x_{k+1}) \rvert \le \sqrt{\varepsilon}\, r_0$ | `StepTolerance` |

$r_0$ は初期点（区間法では区間の両端）での $\lvert f \rvert$ の最大値で、求解の途中では変えない。
区間法は既定では残差を見ず、区間の幅だけで受理する。
設定を変えると、受理の方式も次のように変わる。

- `with_residual_tolerance` を明示すると、区間を持たない方法は更新の大きさによらず残差だけで受理する（`ResidualTolerance`）。
  区間法では、区間の幅による受理に残差による受理が加わる。
  どちらも初期点でも判定する。
  絶対基準は関数の単位で、相対基準は `with_residual_scale` の尺度か、なければ $r_0$ に掛ける。
- 区間法では `with_residual_scale` だけを与えても、相対 $\sqrt{\varepsilon}$・絶対 0 の残差による受理が有効になる。
  区間を持たない方法では、この尺度は `StepTolerance` の残差の条件で $r_0$ の代わりに使われる。
- `with_step_tolerance` は、区間の幅と更新の大きさの両方の基準を変える。

成功しなかった場合の終了理由は次のとおりである。

- `IterationLimit`：反復の上限（既定 100 回、`with_max_iterations` で変更）に達した。
- `Stagnation`：区間法では区間の内側に表せる点が残っていない。
  区間を持たない方法では、同じ点が再び現れたか、小さい更新で残差が減らなかったか、導関数や補間の分母が 0 になって更新を作れなかった。
- `ComplexStepRequired`：実数の `Muller` の放物線補間が複素数の点を求めた。
- `WorkLimit`、`Cancelled`、`TimeLimit`：`SolveBudgets` の上限、取り消し、期限で止まった。

これらの場合も結果は `Ok` で返るが、値は未収束の候補である。
反復の上限と停滞で返る点は、それまでの最良の観測点（区間法と区間で保護した方法では区間の端点のうち $\lvert f \rvert$ の小さい方）である。
連立方程式・Newton–Krylov 法・固定点・多項式・継続法・特殊関数の零点は、それぞれのページで説明する唯一の終了理由を持つ。

## 根を挟む区間の記録

区間法と区間で保護した方法は、`RootResult::bracket()` で `Bracket` を返す。
これは、最後に評価した区間の両端の座標と関数値の記録で、厳密な零の端点か、厳密に反対の符号を持つ両端だけから作られる。
成功時に加えて、反復の上限、停滞、上限による停止でも返る。
関数の連続性を仮定すれば区間内に根があることの根拠になるが、浮動小数点で評価した符号の記録であり、区間演算による証明ではない。
外向き丸めによる存在と一意性の証明は[包含を保証する区間演算](../../scioxide-validated/)の章が扱う。

## 評価回数と作業領域

関数・導関数の評価回数と反復回数は結果の `counts()` で数え、scioxide-core の `SolveBudgets` と実行コンテキストで上限や取り消しを与えられる。
数値差分の試験点も関数の評価として数える。
関数の評価を数える役割は既定で `EvaluationRole::Function` で、`ScalarRootOptions::with_evaluation_role` で別の役割（たとえば事象の位置を求める内側の求根なら `Event`）に替えられる。
解析的な導関数は役割を替えても `Jacobian` と `Hessian` で数え、どの役割の評価も同じ上限に従う。
スカラーの方法は固定の大きさの状態だけを使い、外部の作業領域を受け取らない。
連立方程式や固定点の方法では、準備した作業領域（`SystemWorkspace`、`FixedPointWorkspace` など）を再利用すると、繰り返しの求解でメモリを確保し直さない。
作業領域は解の続きを持たず、呼ぶたびに新しい求解が始まる。

## まとめ

収束の次数は根の近くでの性質なので、方法の比較には 1 反復の評価回数も合わせて見る。
残差から位置の誤差へは $\lvert f \rvert / \lvert f' \rvert$ で換算し、評価の丸め誤差 $\delta$ があると根は幅 $2\delta / \lvert f' \rvert$ より細かく決まらない。
既定の区間法は区間の幅で、区間を持たない方法は小さい更新と残差の減少の両方で受理し、`with_residual_tolerance` や `with_residual_scale` はこの方式を変える。
成否は終了理由だけで判定し、区間の記録は連続性を仮定した根拠として扱う。
