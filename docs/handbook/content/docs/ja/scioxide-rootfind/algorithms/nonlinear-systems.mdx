化学平衡、電力系統の潮流計算、ロボットの逆運動学などは、$n$ 個の未知数 $\mathbf{x} = (x_1, \dots, x_n)^{\mathsf T}$ と同じ数の非線形方程式の連立系になる。

$$
\mathbf{F}(\mathbf{x}) = \bigl(F_1(\mathbf{x}), \dots, F_n(\mathbf{x})\bigr)^{\mathsf T} = \mathbf{0}, \qquad \mathbf{F}: \mathbb{R}^n \to \mathbb{R}^n
$$

変数が結合した系では、一つの変数を変えると複数の残差の成分が変わる。
このページはヤコビ行列 $J(\mathbf{x})$（成分 $J_{ij} = \partial F_i / \partial x_j$）を使う Newton 法とその大域化を扱う。
行列を作らずに作用 $J\mathbf{v}$ だけで解く方法は[行列を形成しない Newton–Krylov 法](../matrix-free-newton-krylov/)にある。

## 多変数 Newton 法

$\mathbf{F}$ が連続微分可能なら、現在の点 $\mathbf{x}_k$ の近くで

$$
\mathbf{F}(\mathbf{x}_k + \mathbf{s}) = \mathbf{F}(\mathbf{x}_k) + J(\mathbf{x}_k)\,\mathbf{s} + o(\lVert \mathbf{s} \rVert)
$$

と線形近似できる。
この線形モデルを零にする補正 $\mathbf{s}_k$ が Newton 方向である。

$$
J(\mathbf{x}_k)\,\mathbf{s}_k = -\mathbf{F}(\mathbf{x}_k), \qquad \mathbf{x}_{k+1} = \mathbf{x}_k + \mathbf{s}_k
$$

密な $J$ を LU 分解で解くと、1 反復の計算量は $O(n^3)$、メモリ使用量は $O(n^2)$ である。
ヤコビ行列を差分で作る場合は、さらに 1 反復あたり残差の評価が前進差分で $n$ 回、中心差分で $2n$ 回加わる。

### 局所収束の定理

次の仮定を置く（Dennis–Schnabel, *Numerical Methods for Unconstrained Optimization and Nonlinear Equations*, 定理 5.2.1）。

- 根 $\mathbf{x}^*$ で $J(\mathbf{x}^*)$ が正則で、$\lVert J(\mathbf{x}^*)^{-1} \rVert \le \beta$ である。
- 半径 $r$ の球 $B(\mathbf{x}^*, r)$ で $J$ が Lipschitz 連続で、$\lVert J(\mathbf{x}) - J(\mathbf{y}) \rVert \le \gamma \lVert \mathbf{x} - \mathbf{y} \rVert$ である。

このとき $\lVert \mathbf{x}_0 - \mathbf{x}^* \rVert < \min\bigl(r, 1/(2\beta\gamma)\bigr)$ なら Newton 法の反復は定義でき、

$$
\lVert \mathbf{x}_{k+1} - \mathbf{x}^* \rVert \le \beta\gamma\,\lVert \mathbf{x}_k - \mathbf{x}^* \rVert^2
$$

の 2 次収束をする。
仮定は根での性質なので、計算の前に確かめることはふつうできない。

Kantorovich の定理は初期点だけの量で根の存在と収束を言う。
$\lVert J(\mathbf{x}_0)^{-1} \rVert \le \beta$、$\lVert J(\mathbf{x}_0)^{-1}\mathbf{F}(\mathbf{x}_0) \rVert \le \eta$ とし、$\mathbf{x}_0$ を中心とする十分大きな球で $J$ が定数 $\gamma$ の Lipschitz 連続であるとする。
$h = \beta\gamma\eta \le 1/2$ なら、半径 $r_0 = \bigl(1 - \sqrt{1 - 2h}\bigr)/(\beta\gamma)$ の閉球の中に根があり、$\mathbf{x}_0$ からの Newton 法はその根に収束する。
最初の Newton 補正 $\eta$ が小さく、ヤコビ行列の変化 $\gamma$ が緩やかなほど条件を満たしやすい。
`scioxide-rootfind` はこの条件を検査しない。
外向き丸めの区間演算による存在と一意性の検証は[包含を保証する区間演算](../../../scioxide-validated/)の章が扱う。

Newton 法の反復はアフィン不変である。
正則な行列 $A$ を掛けた $A\mathbf{F}(\mathbf{x}) = \mathbf{0}$ に Newton 法を使っても、補正 $-(AJ)^{-1}A\mathbf{F} = -J^{-1}\mathbf{F}$ は変わらない。
したがって式の尺度を変えても、厳密な算術での反復点は変わらない。
変わるのは、残差のノルムを使う停止判定と大域化、および浮動小数点での線形方程式の誤差である。

## 停止判定と終了理由

`NewtonSystem`、`Broyden`、`TrustRegionSystem` は同じ停止判定を共有する。
受理の条件は $\lVert \mathbf{F}(\mathbf{x}_k) \rVert_2 \le \varepsilon_{\mathrm{abs}} + \varepsilon_{\mathrm{rel}}\,\rho$ で、既定は $\varepsilon_{\mathrm{abs}} = 0$、$\varepsilon_{\mathrm{rel}} = \sqrt{\varepsilon}$、基準 $\rho = \lVert \mathbf{F}(\mathbf{x}_0) \rVert_2$（初期点の残差ノルム）である。
`with_residual_scale(s)` は基準 $\rho$ を固定値 $s$ に替え、`with_residual_tolerance` は $\varepsilon_{\mathrm{abs}}$ と $\varepsilon_{\mathrm{rel}}$ を替える。
初期点がすでに条件を満たせば、反復 0 回で `ResidualTolerance` を返す。

| 終了理由 | 起こる条件 |
|---|---|
| `ResidualTolerance`（成功） | 受理した点の残差が上の条件を満たした |
| `Stagnation` | Newton 法と Broyden 法では、更新幅 $\lVert \Delta\mathbf{x} \rVert_2$ が `StepTolerance` の閾値 $\varepsilon_{\mathrm{abs}} + \varepsilon_{\mathrm{rel}}\max(1, \lVert \mathbf{x} \rVert_2)$（既定は絶対・相対とも $\sqrt\varepsilon$）以下で、残差が減らなかった。直線探索なしで更新後の点が元の点と同じになった場合も含む。信頼領域法では半径が縮みきったか、進展のない試行が続いた（後述） |
| `GlobalizationFailure` | 直線探索が受理できるステップ幅を見つけられなかった。信頼領域法では、残差の定義域の外の試行点で半径を縮め続け、半径が `StepTolerance` を満たしたか点が動かなくなった |
| `IterationLimit` | 外側の反復が上限（既定 100、`with_max_iterations`）に達した |
| `WorkLimit`、`Cancelled`、`TimeLimit` | `SolveBudgets` や実行コンテキストが処理を止めた |

成功は `ResidualTolerance` だけで、ほかの終了理由で返る点は未収束の候補である。
直線探索を付けない Newton 法は LU 分解の枢軸が 0 になるヤコビ行列に、直線探索を付けない Broyden 法は数値的に階数が落ちたモデルに `Singular` のエラーを返す。
上限、取り消し、期限で止まった場合も、受理した点がまだなければ結果ではなく `ConvergenceFailure` か `ExecutionStopped` のエラーになる。

残差が小さいことは、解の誤差が小さいことを意味しない。
単純根の近くでは $\mathbf{x} - \mathbf{x}^* \approx J(\mathbf{x}^*)^{-1}\mathbf{F}(\mathbf{x})$ なので、位置の誤差は $\lVert J(\mathbf{x}^*)^{-1} \rVert\,\lVert \mathbf{F}(\mathbf{x}) \rVert$ 程度になる。
$\mathbf{F}$ の評価に誤差 $\delta$ があると、どの方法でも位置の精度はおよそ $\lVert J(\mathbf{x}^*)^{-1} \rVert\,\delta$ より良くならない。

## 方程式の尺度と条件数

残差の成分ごとに単位や代表的な大きさが違うと、大きな成分がノルムを支配する。
例えば圧力とモル分率の残差を同じノルムに入れると、数値の大きな圧力の成分が停止判定を決めてしまう。
方程式の代表尺度 $D_F = \operatorname{diag}(s_1, \dots, s_n)$ と変数の尺度 $D_x = \operatorname{diag}(d_1, \dots, d_n)$ を使い、

$$
\hat{\mathbf{F}}(\hat{\mathbf{x}}) = D_F^{-1}\,\mathbf{F}(D_x \hat{\mathbf{x}}), \qquad \hat J = D_F^{-1}\,J\,D_x
$$

と無次元化すると、成分を同じ重みで比べられる。
Newton 法の反復点はこの変換で変わらないが、停止判定、直線探索のメリット関数、信頼領域の形は変わる。
条件数 $\kappa(\hat J)$ も変わり、部分ピボット付き LU 分解で求める補正の相対誤差はおよそ $\kappa(\hat J)\,\varepsilon$ の程度になる。
密な連立方程式の解法は成分ごとの尺度を引数に取らないので、呼び出し側が式と変数を無次元化してから渡す。
行列を作らない `NewtonKrylovSolver` は `NonlinearScaling` で成分ごとの除数を受け取る。

## 直線探索による大域化

初期点が根から遠いと、Newton 補正は大きすぎて残差を増やしたり、定義域の外へ出たりする。
大域化は根から遠い点でも残差を減らしながら進む工夫である。
メリット関数 $\phi(\mathbf{x}) = \tfrac12 \lVert \mathbf{F}(\mathbf{x}) \rVert_2^2$ の勾配は $\nabla\phi = J^{\mathsf T}\mathbf{F}$ で、Newton 方向との内積は

$$
\nabla\phi(\mathbf{x}_k)^{\mathsf T}\mathbf{s}_k = \mathbf{F}^{\mathsf T} J \bigl(-J^{-1}\mathbf{F}\bigr) = -\lVert \mathbf{F}(\mathbf{x}_k) \rVert_2^2 < 0
$$

になる。
根でない点では、正確に解いた Newton 方向は $\phi$ の降下方向である。

`BacktrackingLineSearch` は Dennis–Schnabel のアルゴリズム A6.3.1 に従い、ステップ幅 $\alpha = 1$ から始めて十分減少条件（Armijo 条件）

$$
\phi(\mathbf{x}_k + \alpha\,\mathbf{s}_k) \le \phi(\mathbf{x}_k) + c\,\alpha\,\mathbf{F}(\mathbf{x}_k)^{\mathsf T} J(\mathbf{x}_k)\,\mathbf{s}_k
$$

を満たす最初の $\alpha$ を採る。
既定は $c = 10^{-4}$ で、`BacktrackingLineSearch::new(c, min_relative_step)` で $0 < c < 1$ の値に変えられる。
退けたステップ幅は観測した $\phi$ の値による 2 次補間、2 回目からは 3 次補間の最小点に替え、直前のステップ幅の 0.1〜0.5 倍に制限する。
試行点の残差が非有限か、残差の関数が `DomainError`（`OutsideDomain`）を返した場合は、補間を使わずにステップ幅を半分にする。
相対的な移動量 $\alpha \max_i |s_i| / \max(1, |x_i|)$ が `min_relative_step`（既定 $\varepsilon^{2/3}$）を下回ると探索を打ち切る。

直線探索による大域収束の理論（Dennis–Schnabel 6.3 節と 6.5 節、Nocedal–Wright 11.2 節）は、$\phi(\mathbf{x}) \le \phi(\mathbf{x}_0)$ の集合で $J$ が有界かつ一様に正則であることを仮定する。
この仮定のもとでは $\lVert \mathbf{F}(\mathbf{x}_k) \rVert \to 0$ となり、根の近くでは $\alpha = 1$ が受理されて 2 次収束に戻る。
途中で $J$ が特異に近づくと、$J^{\mathsf T}\mathbf{F} = \mathbf{0}$ かつ $\mathbf{F} \ne \mathbf{0}$ の点（根でない $\phi$ の停留点）に近づくことがある。

`NewtonSystem` は既定では直線探索を使わず、補正をそのまま加える。
`NewtonSystemOptions::with_line_search` で探索を付けると、LU 分解の階数が数値的に落ちた場合は Dennis–Schnabel の摂動モデルの補正

$$
\bigl(J^{\mathsf T}J + \mu I\bigr)\mathbf{s} = -J^{\mathsf T}\mathbf{F}, \qquad \mu = \sqrt{n\varepsilon}\,\lVert J^{\mathsf T}J \rVert_1
$$

を使う。
Newton 方向の探索が尽きた場合も、同じ点でこの補正に一度だけ切り替え、それでも尽きると `GlobalizationFailure` で止まる。
`with_linear_solver` で反復型の線形解法を渡した場合は常に Newton 方程式を解き、探索が尽きると直ちに `GlobalizationFailure` になる。
探索に使う傾き $\mathbf{F}^{\mathsf T} J \mathbf{s}$ が負でない方向も、探索が尽きたものとして扱う。

## Broyden の準 Newton 法

ヤコビ行列の評価コストが大きいなら、近似 $B_k$ を割線条件 $B_{k+1}\mathbf{s}_k = \mathbf{y}_k$（$\mathbf{y}_k = \mathbf{F}(\mathbf{x}_{k+1}) - \mathbf{F}(\mathbf{x}_k)$）で更新して使い続ける。
第 1 の更新（`BroydenUpdate::First`）は、割線条件を満たす行列のうち $B_k$ に Frobenius ノルムで最も近いものである。

$$
B_{k+1} = B_k + \frac{(\mathbf{y}_k - B_k\mathbf{s}_k)\,\mathbf{s}_k^{\mathsf T}}{\mathbf{s}_k^{\mathsf T}\mathbf{s}_k}
$$

第 2 の更新（`BroydenUpdate::Second`）は逆行列 $H = B^{-1}$ を $H_{k+1} = H_k + (\mathbf{s}_k - H_k\mathbf{y}_k)\,\mathbf{y}_k^{\mathsf T} / (\mathbf{y}_k^{\mathsf T}\mathbf{y}_k)$ で更新するもので、$B$ に直すと $B_{k+1} = B_k + (\mathbf{y}_k - B_k\mathbf{s}_k)(B_k^{\mathsf T}\mathbf{y}_k)^{\mathsf T} / (\mathbf{y}_k^{\mathsf T}B_k\mathbf{s}_k)$ になる。
$B_0$ が $J(\mathbf{x}^*)$ に十分近く $\mathbf{x}_0$ が根に十分近ければ、Broyden 法は超 1 次収束する（Broyden–Dennis–Moré）。
直線探索がなければ 1 反復の評価は残差 1 回で済むが、2 次収束はしない。

`Broyden` は初期点でヤコビ行列を一度評価して $B_0$ とする。
第 1 の更新は前向きの行列 $B$ と逆行列のキャッシュを持ち、キャッシュの方向が $B$ の方程式を丸め誤差の範囲で満たさなければ、$B$ をピボット付き LU で解き直す。
第 2 の更新は明示的な QR 因子を持ち、平面回転で階数 1 の更新をする。
第 1 は更新幅が 0 のとき、第 2 は分母が $|\mathbf{y}^{\mathsf T}B\mathbf{s}| \le \sqrt{\varepsilon}\,\lVert B^{\mathsf T}\mathbf{y} \rVert\,\lVert \mathbf{s} \rVert$ のとき更新を飛ばす。
直線探索を付けると、探索の傾きにはモデルの値 $\mathbf{F}^{\mathsf T}B\mathbf{d}$ を使い、数値的に階数が落ちたモデルでは Newton 法と同じ摂動モデルの補正を使う。
割線更新で直したモデルで探索が尽きた場合は、受理済みの点でヤコビ行列を評価し直してやり直す。
評価し直したモデルでも尽きると摂動モデルの補正に一度だけ切り替え、それでも尽きると `GlobalizationFailure` になる。
そのためヤコビ行列の評価は初期点の 1 回だけとは限らず、評価回数は結果の `counts()` で確かめる。

## ドッグレッグ信頼領域法

直線探索は方向を固定してステップ幅を縮める。
信頼領域法は線形モデルを信用する範囲を半径 $\Delta_k$ に限り、その中でモデルの残差を最小にする補正を選ぶ。

$$
\min_{\lVert D\mathbf{p} \rVert_2 \le \Delta_k} \tfrac12 \lVert \mathbf{F}(\mathbf{x}_k) + J(\mathbf{x}_k)\,\mathbf{p} \rVert_2^2
$$

ドッグレッグ法はこの部分問題を近似的に解く。
尺度付きの最急降下方向でモデルを最小にする Cauchy 点と、Gauss–Newton 点 $-J^{-1}\mathbf{F}$ を折れ線で結び、その折れ線と信頼領域の境界の交点（Gauss–Newton 点が内側ならその点）を補正とする。
実際の減少とモデルが予測した減少の比 $\rho_k$ で、補正の採否と次の半径を決める。

`TrustRegionSystem` は Powell のハイブリッド法に従う。

- 尺度 $D$ の対角成分はヤコビ行列の各列の 2 ノルムである（零の列は 1）。
  最初の試行点を受理するまではヤコビ行列を評価するたびに置き直し、その後は評価したヤコビ行列の列ノルムとの成分ごとの最大値を保つ。
- Gauss–Newton 点はピボットなしの QR 分解から求め、$R$ の零の対角成分はその列の最大の絶対値の $\varepsilon$ 倍に置き換える。
- 初期半径は $100\lVert D\mathbf{x}_0 \rVert$（$D\mathbf{x}_0 = \mathbf{0}$ なら $100\lVert \mathbf{F}(\mathbf{x}_0) \rVert$）で、最初の受理までは半径を試行した補正の長さ $\lVert D\mathbf{p} \rVert$ 以下に縮める。
- $\rho_k$ は $\lVert \mathbf{F} \rVert_2^2$ の実際の相対減少と、線形モデルが予測した相対減少の比である。
- $\rho_k < 0.1$ なら半径を半分にする。
  $\rho_k \ge 0.5$ か成功が続いた場合は半径を $2\lVert D\mathbf{p} \rVert$ 以上に広げ、$|\rho_k - 1| \le 0.1$ なら $2\lVert D\mathbf{p} \rVert$ にする。
- $\rho_k \ge 10^{-4}$ なら試行点を受理する。
- 毎回の試行の後、尺度付きの Broyden 更新でモデルを直し、$\rho_k < 0.1$ が 2 回続いたときだけヤコビ行列を評価し直す。

終了理由 `Stagnation` は次のどれかで起こる。

- 半径が受理点の $\lVert D\mathbf{x} \rVert$ に対して `StepTolerance` を満たした。
- $0.1\max(0.1\Delta, \lVert D\mathbf{p} \rVert) \le \varepsilon \lVert D\mathbf{x} \rVert$ となり、表現できる改善が残らない。
- 評価し直したヤコビ行列による試行で、$\lVert \mathbf{F} \rVert_2^2$ を 10% 減らせない状態が 5 回続いた。
- $\lVert \mathbf{F} \rVert_2^2$ を 0.1% 減らせない試行が 10 回続いた。

試行点の残差が非有限か、残差の関数が `DomainError`（`OutsideDomain`）を返した場合は、半径を半分にして試行し直す。
これで半径が `StepTolerance` を満たすか点が動かなくなると、`GlobalizationFailure` で止まる。
ドッグレッグ補正が計算できない（勾配が零でないのにモデルの曲率が零になる、補正が非有限になる）場合は `NumericalInstability` のエラーになる。
信頼領域法の大域収束の理論（Dennis–Schnabel 6.4 節、Nocedal–Wright 4 章と 11.2 節）が仮定のもとで保証するのは $\phi$ の停留点 $J^{\mathsf T}\mathbf{F} = \mathbf{0}$ への接近であり、根への収束ではない。
`TrustRegionSystemOptions` には直線探索と反復型線形解法の設定がなく、QR 分解のモデルだけを使う。

## 遠い初期点からの大域化

Freudenstein–Roth 関数（Moré–Garbow–Hillstrom の試験問題 2）は、根 $(5, 4)$ のほかに $\phi$ の根でない極小点を $(11.41, -0.8968)$ の近くに持つ。

$$
F_1(x, y) = -13 + x + \bigl((5 - y)\,y - 2\bigr)\,y, \qquad
F_2(x, y) = -29 + x + \bigl((y + 1)\,y - 14\bigr)\,y
$$

この極小点では $\lVert \mathbf{F} \rVert_2 \approx 6.999$ で、$J^{\mathsf T}\mathbf{F} = \mathbf{0}$ を満たすので、$\phi$ を減らす大域化はここに引き寄せられうる。
次のセルは五つの設定で同じ初期点から解き、終了理由、反復回数、残差ノルム、根 $(5, 4)$ との距離、残差とヤコビ行列の評価回数を並べる。
ヤコビ行列は解析的に与えるので、評価回数は `counts()` の `EvaluationRole::Residual` と `EvaluationRole::Jacobian` で読める。
根との距離が独立な検算である。
入力の初期点は Moré–Garbow–Hillstrom の標準の $(0.5, -2)$、根に近い $(6, 3)$、$(0, 2)$ から選ぶ。
セルの outcome は `solve_system` の既定でもある `TrustRegionSystem` の終了理由を示す。

## 式の尺度と停止判定

円 $F_1(x, y) = x^2 + y^2 - 1$ と直線 $F_2(x, y) = \alpha\,(x - y - 0.2)$ の交点を $(0.8, 0.4)$ から求める（解は $(0.8, 0.6)$）。

解析解との距離が独立な検算である。

### 結果の読み方

- 反復点は尺度によらない。
  基準を 1 に固定した列ではどの $\alpha$ でも 4 反復で `ResidualTolerance` に達し、解との距離は $7.1 \times 10^{-16}$ で同じである。
  これは前に述べたアフィン不変性の現れである。
- 既定の判定は尺度に引きずられる。
  初期残差 $0.2\sqrt{1 + \alpha^2}$ は $\alpha$ とともに増えるので、相対 $\sqrt\varepsilon$ の閾値も大きくなる。
  一方、第 2 式は線形なので最初の補正の後は $F_2 \approx 0$ となり、その後の残差はほぼ $|F_1|$ で $\alpha$ によらない。
  $\alpha \le 10$ では 4 反復で距離 $7.1 \times 10^{-16}$ だが、$10^2 \le \alpha \le 10^5$ では 3 反復で止まり距離は $3.8 \times 10^{-8}$、$\alpha = 10^6$ では 2 反復で止まり距離は $2.7 \times 10^{-4}$ である。
  どの行も終了理由は成功の `ResidualTolerance` で、終了理由だけでは精度の違いが分からない。
- 条件数は $\alpha \approx 1.4$ で最小の 1.15 になり、$\alpha = 10^{-3}$ で $1.43 \times 10^3$、$\alpha = 10^6$ で $7.14 \times 10^5$ と、どちらの向きにも増える。
  この 2 変数の例では条件数が $10^6$ 程度でも距離 $10^{-16}$ に届くが、条件数が $10^8$ を超える系や差分で作ったヤコビ行列では、補正の誤差 $\kappa\varepsilon$ が収束を遅らせたり止めたりする。

セルの outcome は入力の $\alpha$ を既定の判定で解いた結果で、`satisfied` のときも解との距離を診断値に並べる。
初期残差を基準にした相対の判定は、成分の尺度がそろっているときに意味を持つ。
一つの式だけ大きな尺度を持つ系では、式と変数を無次元化するか、`with_residual_scale` で物理的に意味のある基準を与える。

## 残差とヤコビ行列の型

`ResidualOperator`（scioxide-core）は入力と出力の次元、残差を呼び出し側の配列へ書く作用、残差の評価に必要な一時領域の長さを表す。
密な連立方程式の解法は空でない正方系を扱い、入力と残差の成分順は呼び出し側の定義のまま使う。
`ResidualFn` はこの作用をクロージャで与え、`with_jacobian` で行優先の密なヤコビ行列（成分 $(i, j)$ が $\partial F_i/\partial x_j$）を加える。
`DenseJacobian` は解析的または自動微分による密なヤコビ行列を提供する機能を表す。
自動微分の機能は呼び出し側が実装して渡すもので、任意の Rust の残差関数から自動的に作られるわけではない。
ヤコビ行列の出所は `with_derivative_strategy` の `DerivativeStrategy` で選ぶ。
密な連立方程式の解法の既定は `AnalyticOrForward` で、問題が解析的なヤコビ行列を持てばそれを使い、なければ前進差分（1 回あたり残差の評価 $n$ 回）で作る。

`NewtonSystemOptions`、`BroydenOptions`、`TrustRegionSystemOptions` は各方法の設定を持ち、許容誤差、尺度、反復上限、`SolveBudgets`、実行方針、作業領域のメモリ使用量の上限を共通に設定できる。
直線探索の規則は `RootLineSearch` で、`BacktrackingLineSearch` がその実装である。
`NewtonSystemOptions` は `with_line_search` と `with_linear_solver`（LU の代わりの反復型線形解法）を受け取り、`BroydenOptions` は `with_line_search` だけを受け取る。
`TrustRegionSystemOptions` にはどちらの設定もない。
大域化は不適切な補正を避ける仕組みであり、任意の初期値から根へ到達する保証ではない。

## 準備した出力と作業領域

`solve` と `solve_into` は初期値をスライス `&[S]` で受け取り、長さが問題の次元と違えば `DimensionMismatch`、成分に NaN や無限大があれば `NonFinite` を返す。
`SystemRootSolver` の `workspace_requirements` は `SystemWorkspaceRequirements` を返し、`workspace` は `SystemWorkspace` を確保する。
作業領域は反復中のベクトル、ヤコビ行列、分解、数値微分の一時領域を持ち、必要量は次元のほか方法と残差の関数の一時領域にも依存する。
`SystemRootResult` を準備して `solve_into` を繰り返すと、そのたびの領域確保を避けられる。
設定も診断も要らなければ、ワンショット関数 `solve_system(f, initial)` が残差のクロージャ `f(x, out)` を既定の `TrustRegionSystem`（前進差分のヤコビ行列と Broyden 更新）で解き、成功したときだけ点を `Vec` で返し、それ以外の終了は `ConvergenceFailure` などのエラーにする。
入力や作業領域の不一致、数値的な破綻、残差の関数のエラーでは出力を変更しない。
受理した点がある後に上限で止まった場合は、未収束の結果を出力に書く。

結果の `residual_norm()` は未評価なら `None` である。
`counts()` は解法自身の残差・ヤコビ行列・分解・線形求解の回数を `EvaluationCounts` で返し、`accounting()` は入れ子の処理を含めた集計を返す。
計算コストの小さい反復を多く行う方法と、計算コストの大きい反復を少なく行う方法を比べるときは、[遠い初期点からの比較](#遠い初期点からの大域化)のように、反復回数だけでなく評価回数を読む。
密な行列のメモリ使用量は $O(n^2)$、分解は $O(n^3)$ なので、大規模な系では[行列を形成しない Newton–Krylov 法](../matrix-free-newton-krylov/)を検討する。

## まとめ

連立方程式の Newton 法は線形化した方程式を解いて進み、根でヤコビ行列が正則で初期点が十分近ければ 2 次収束する。
既定の停止判定は初期残差に対する相対 $\sqrt\varepsilon$ なので、一つの式の尺度が大きいと成功の `ResidualTolerance` でも解の誤差が大きく残る。
式と変数を無次元化するか `with_residual_scale` で基準を与え、残差だけでなく解の誤差の見積もり $\lVert J^{-1} \rVert \lVert \mathbf{F} \rVert$ も確かめる。
初期点が遠いときは `with_line_search` を付けた `NewtonSystem` か `TrustRegionSystem` を使い、ヤコビ行列の評価コストが大きいなら `Broyden` を使う。
Freudenstein–Roth 関数の例のように、どの大域化も根でない $\phi$ の停留点に止まりうるので、`GlobalizationFailure` や `Stagnation` の点は解として使わず、初期点を変えて解き直す。
