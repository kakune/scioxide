固有振動数の計算では関数を零にする点を一つ見つけるだけでは足りない。
必要なのは、例えば Bessel 関数 $J_\nu$ の正の零点を小さい順に並べたときの第 $m$ 零点 $j_{\nu,m}$ である。
ふつうの Newton 法を初期値だけ変えて繰り返すと、同じ零点に何度も収束したり、途中の零点を取り落としたりすることがある。
`special_zeros_with_options` は関数の族、分枝、開始の添字、個数を指定し、零点の値と番号を合わせて求める。

## 族と分枝

`special_zeros_with_options(family, branch, start, count, &options)` は、族 `SpecialZeroFamily`、分枝 `SpecialZeroBranch`、開始の添字、個数、`SpecialZeroOptions` を受け取る。
対応しない組合せや範囲外の次数は、関数を評価する前に `InvalidInput` のエラーにする。
`special_zeros(family, count)` は `Real` の列の添字 1 から `count` 個を既定の設定で求め、すべての零点が検査に通ったときだけ零点の実部の列を返し、それ以外の終了は `ConvergenceFailure` などのエラーにする。
導関数の零点と関数そのものの零点は別の列なので、要求を取り違えないようにする。

| 族 | 実軸の列（`Real`） | 原点（`Origin`） | 複素数の列（`Complex`） |
|---|---|---|---|
| `BesselJ(ν)`（$\nu > -1/2$） | 正の零点 | — | — |
| `BesselJPrime(ν)`（$\nu \ge 0$） | 正の零点（原点を除く） | $\nu = 0$ のとき（$J_0'(0) = 0$） | — |
| `BesselY(ν)`、`BesselYPrime(ν)`（$\nu \ge 0$） | 正の零点 | — | $\nu = 0, 1$ のとき、共役だけ |
| `AiryAi`、`AiryAiPrime` | 負の実零点 | — | — |
| `AiryBi`、`AiryBiPrime` | 負の実零点 | — | 共役だけ |
| `Kelvin(KelvinZeroFunction)` | 零次の ber・bei・ker・kei とその導関数の正の零点 | bei、ber′、bei′ | — |
| `Erf`、`FresnelC`、`FresnelS` | 零点なし（`NoZeros`） | あり | erf は共役と符号反転、Fresnel は三つの操作すべて |
| `FresnelCPrime`、`FresnelSPrime` | 正の零点 | $S'$ だけ | 三つの操作すべて |

`SpecialZeroBranch::Real` は実軸の列、`Origin` は原点だけ、`Complex { conjugate, negate, rotate }` は上半平面の標準の列に、共役、符号反転、$i$ 倍をこの順に施した列を表す。
`SpecialZeroBranch::UPPER` は変換を施さない上半平面の列である。
Airy 関数の実零点は原点に近いほうから数え、ほかの実軸の列は小さいほうから数える。
実軸と複素数の列の添字は 1 から始まる。
原点の要求は開始の添字 0、個数 1 以下に限り、原点が零点になる族（$J_0'$、erf、$C$、$S$、$S'$、bei、ber′、bei′）でだけ使える。
原点の零点の重複度は既知で（$S$ と ber′ は 3、$S'$ と bei は 2、ほかは 1）、`SpecialZero::multiplicity()` で読める。
erf と Fresnel 積分 $C$、$S$ は実軸上の原点以外に零点を持たないので、`Real` の要求は空の列と判定して `NoZeros` を返す。

## 初期近似と番号の決め方

零点を番号付きで求めるには、近似値だけでなく「何番目か」を決める必要がある。
`special_zeros_with_options` は族ごとに次のように番号を決める。

- Bessel 関数では $J_0$、$J_1$、$J_{5/2}$、$J_1'$、$Y_0$、$Y_1$ の第 8 零点までは表の値を初期近似にする。
  それ以外では、$\beta = (m + \nu/2 - 1/4)\pi$（$Y_\nu$ と $J_\nu'$ では $1/4$ が $3/4$）が $\beta > 8$ かつ $\beta > 2(\nu^2 + 1)$ を満たせば McMahon 展開（DLMF 10.21.19–20）、$\nu \ge 32$ で転回点 $x \approx \nu$ に近い零点なら Olver の一様漸近展開（DLMF 10.21）から初期近似を作る。
  初期近似があれば、その前後に隣の初期近似との間隔（なければ $\pi$）の 0.35 倍ずつ広げた区間で符号の変化を確かめ、区間の外に出る更新を二分法に置き換える Newton 法で仕上げる。
  初期近似がないか符号が変わらなければ、$\max(\nu, 1/8)$ から刻み $(\pi/4)/\sqrt{1 + 1/(4x^2)}$（振動の 4 分の 1 周期より短い）で右へ進みながら符号の変化を数え、$m$ 番目の変化の区間を使う。
  $J_\nu'$ と $Y_\nu'$ の零点は、$J_\nu$ や $Y_\nu$ の隣り合う零点の間にある（交互性）ことを使って挟む。
- Kelvin 関数は表と McMahon 型の展開（DLMF 10.70）から初期近似を作り、その前後 $0.4\pi$ の区間で符号の変化を確かめる。
  確かめられなければ Bessel 関数と同じ数え上げに移る。
- Airy 関数は第 8 零点までは表、それより先は DLMF 9.9.18–19 の展開から初期近似を作り、区間の端の符号を確かめる。
  端の符号には、誤差の伝播と剰余を検査した Airy の微分方程式の Taylor 多項式による値を使うことがある。
- erf と Fresnel 積分の複素数の零点は、添字 8 までは表、それより上は漸近展開（DLMF 7.13）から初期近似を作る。
  その近くで複素 Newton 法を使い、反復が次の初期近似までの距離の 0.45 倍の円から出たら `Unverified` で止める。
  $C'(z) = \cos(\pi z^2/2)$ と $S'(z) = \sin(\pi z^2/2)$ の実零点は、$\sqrt{2m - 1}$ と $\sqrt{2m}$ の閉形式である。

仕上げた点は出力の型に丸め、分枝の変換（共役など）を施した最終の座標で元の関数を評価し直す。
丸めと変換による座標の移動が隣の零点との間隔（Bessel・Kelvin 関数の実零点では $\pi$、ほかは隣の初期近似との距離）の 0.45 倍を超えた場合は、要求した番号の零点として受理せず `Unverified` にする。
推定誤差 $(|f| + \delta f)/|f'| + |\text{移動量}|$（$\delta f$ は $f$ の評価誤差の上界）が許容誤差を超えた場合と、零点の絶対値が前の零点より大きくならない場合も `Unverified` にする。
許容誤差は `SpecialZeroOptions::with_tolerance` の `StepTolerance` で、既定は絶対・相対とも $\sqrt\varepsilon$（相対の基準は零点の絶対値）である。

この手順は数値的な経験則であり、零点を飛ばしたり重複して数えたりしないことの証明ではない。
符号の変化は浮動小数点で評価した値の符号で、刻みの中に零点が二つ入らないことは振動の周期の評価に頼っている。
`SpecialZero::bracket()` が返す区間も外向き丸めの包含区間ではない。
SciOxide は特殊関数の零点の包含が保証された区間を提供しない。
scioxide-validated のワンショット関数 `roots` と検証器 `ScalarRootVerifier` は、値と導関数の区間拡張を呼び出し側が与えれば区間 Newton 法で根の存在と一意性を検証するが、Bessel 関数などの区間拡張は提供しない（[包含を保証する区間演算](../../../scioxide-validated/)）。

## McMahon 展開

$\nu$ を固定して $m \to \infty$ とすると、$\beta = (m + \nu/2 - 1/4)\pi$、$\mu = 4\nu^2$ として

$$
j_{\nu,m} \sim \beta - \frac{\mu - 1}{8\beta} - \frac{4(\mu - 1)(7\mu - 31)}{3(8\beta)^3} - \cdots
$$

となる（McMahon の展開、[DLMF 10.21.19](https://dlmf.nist.gov/10.21#vi)）。
$\beta$ は大きな $x$ での漸近形 $J_\nu(x) \approx \sqrt{2/(\pi x)}\cos(x - \nu\pi/2 - \pi/4)$ の零点で、以降の項はその補正である。
これは $\nu$ を固定した漸近展開で、$\nu$ が大きい場合に一様に正確な式ではない。
$m$ が小さく $\nu$ が大きい領域では、打ち切った展開を高精度の参照値として使えない。
$\nu = 1/2$ では $J_{1/2}(x) = \sqrt{2/(\pi x)}\,\sin x$ なので $j_{1/2,m} = m\pi$ である。
このとき $\mu - 1 = 0$ で、$\beta^{-1}$ 以降の項はすべて消える。

## Bessel 関数の零点の表

次のセルは次数 $\nu$ と開始の添字 $m$ を変え、$J_\nu$ の連続する六つの零点を求める。
表は零点、その点での $J_\nu$ の値、McMahon 展開（$\beta^{-3}$ の項まで）との差、推定誤差を示す。
番号の検算として、刻み 0.01 の格子で $J_\nu$ の符号変化を原点側から数え、各零点の 0.25 先までの数を表に出す。
関数の値は scioxide-special の `bessel_j` で求めるが、これは求根と同じ評価経路なので、値の独立な検算は McMahon 展開と $\nu = 1/2$ の厳密な零点 $m\pi$ で行う。
outcome は `SpecialZeroReport` の終了状態を示す。

```rust
    SpecialZeroFamily::BesselJ(order),
    SpecialZeroBranch::Real,
    start as usize,
    6,
    &SpecialZeroOptions::default(),
)

// 隣り合う零点の間隔は 3 以上なので、一つの刻みに二つの零点が入ることはない。
let step = 0.01;
let last = zeros.roots().last().map_or(0.0, |z| z.point().re);
let samples = (last / step) as usize + 50;
let mut values = Vec::with_capacity(samples);
for k in 1..=samples {

    values.push((x, bessel_j(order, x).map_err(|e| e.to_string())?));
}

    let m = zero.index();
    let x = zero.point().re;
    // 零点の 0.25 先までにある符号変化の数（次の零点はそれより遠い）。
    let counted = values
        .windows(2)
        .filter(|w| w[1].0 <= x + 0.25 && (w[0].1 < 0.0) != (w[1].1 < 0.0))

    Outcome::satisfied("要求した六つの零点がすべて元の関数での検査に通った")
} else if matches!(termination, RootTermination::Unverified) {
    Outcome::failed("零点の検査に通らない添字がある")
        .explanation("表には検査に通った先頭の零点だけを示す。")

        .explanation("表には検査に通った先頭の零点だけを示す。")

    .roots()
    .iter()
    .map(|z| z.estimated_error())
    .fold(0.0_f64, f64::max);
emit_outcome!(
    outcome
        .status(termination.to_string())
        .diagnostic("完了した個数", report.completed() as f64, None)

```

既定の $\nu = 0$、$m = 1$ では六つの零点がすべて検査に通り、outcome は `Complete` を示す。
符号変化から数えた番号は、要求した添字と一致する。
$J_0$ の値は絶対値で $1.8 \times 10^{-16}$ 以下、推定誤差は $8.1 \times 10^{-17}$ から $9.7 \times 10^{-16}$ である。
McMahon 展開との差は $m = 1$ で $1.8 \times 10^{-3}$、$m = 6$ で $1.3 \times 10^{-7}$ と、添字とともに小さくなる。
これは展開の打切り誤差で、零点の誤差ではない。
$\nu = 6$、$m = 1$ では差が $-0.105$ に増え、$m = 25$ では $-2.9 \times 10^{-6}$ まで小さくなるので、$\nu$ が $m$ に比べて大きいと固定次数の展開が使えないことが分かる。
$\nu = 1/2$ では展開との差が 0 で、零点は倍精度の $m\pi$ に一致する。

## 結果と作業領域

`special_zeros_with_options` が返す `SpecialZeros` は検査に通った `SpecialZero` の列と `SpecialZeroReport` を持つ。
各零点は番号 `index()`、座標 `point()`、元の関数の残差 `residual_norm()`、Newton 補正の大きさ `correction()`、推定誤差 `estimated_error()`、導関数の逆数 `inverse_slope()`、符号の区間 `bracket()`、重複度 `multiplicity()` を持つ。
`inverse_slope()` は零点の絶対条件数 $1/|f'(z)|$ で、関数値の誤差 $\delta f$ が零点を $\delta f/|f'|$ だけ動かすことを表す。
Kelvin 関数の残差は指数的な正規化をした関数（`ber x · exp(−x/√2)` など）の値で、`residual_is_scaled()` が真になる。
レポートの `termination()` が唯一の判定で、`Complete` は要求した列の完了、`NoZeros` は空と判定された列を表す。
上限で止まった場合や `Unverified` では、`completed()` 個の検査済みの先頭部分だけが要求に対応する零点で、`candidate()` は最初の未完了の要求の候補（検査済みではない）である。

`SpecialZeroOptions` では、零点の許容誤差（`with_tolerance`）、探索・仕上げ・検査で共有する評価の上限（`with_evaluation_budget`、既定 $2^{26}$ 回）、探索の反復と特殊関数の 1 回の評価の上限（`with_work_per_zero`、既定 $2^{20}$ 回）、仕上げの Newton 法の反復の上限（`with_refinement_steps`、既定 100 回）、`SolveBudgets`、実行方針、作業領域のメモリ使用量の上限を設定する。
`SpecialZeroWorkspace::workspace_requirements(count, &options)` が返す `SpecialZeroWorkspaceRequirements` は必要な作業領域の量を表し、その量は零点の個数だけで決まる。
`SpecialZeroWorkspace::workspace(count, &options)` で作った作業領域と出力 `&mut [Option<SpecialZero>]` を `special_zeros_into` に渡すと、割り当てなしに繰り返し使える。
`special_zeros_into` はエラーのときどの出力も変えず、上限で止まったときは検査済みの先頭部分だけを書く。
`counts()` は列の処理自身の計算量で、零点ごとの仕上げや特殊関数の評価は入れ子の範囲で数えられるので、`accounting()` から読む。
推定誤差と番号の数値的な検査は、区間演算による包含が保証された区間とは別のものである。

## まとめ

特殊関数の零点は族、分枝、添字を指定して求め、`termination()` が `Complete` か `NoZeros` のときだけ要求した列全体として使う。
未完了の結果では `completed()` 個の先頭部分だけが検査済みで、`candidate()` は解として使わない。
番号は初期近似の符号区間と符号変化の数え上げで決まる数値的な判定なので、重要な計算では符号変化の数や漸近展開、既知の厳密な零点で番号を独立に確かめる。
McMahon 展開は $\nu$ を固定した $m \to \infty$ の近似で、$\nu$ が $m$ に比べて大きいと参照値にならない。
