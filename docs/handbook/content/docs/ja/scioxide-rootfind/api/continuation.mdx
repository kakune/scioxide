この表はパラメータ $\lambda$ を含む $n$ 本の方程式 $F(x, \lambda) = 0$ の解の枝をたどる継続法と、既知の根を除いて別の根を探すデフレーションの項目をまとめる。
どちらも補正に scioxide-rootfind の Newton–Krylov 法を使い、元の方程式の残差を独立に検査する。
`Continuation` は検査した経路と設定だけを持ち、受理した点・接線・履歴は呼び出し側が持つ `ContinuationState` に入る。
折り返し点や分岐の候補は数値的な観察であり、証明ではない。

## まとめ

継続法は `ContinuationProblem` と `Continuation` で解の枝をたどる。
`follow` は経路の終わりまで進めた状態を返し、`advance` は 1 回に最大 1 点を受理するので、終了理由が `Advanced` の間は呼び続け、`Complete` になれば経路をたどり終えている。
受理した点ごとの元の残差と折り返し点の候補は、`ContinuationState` の履歴に残る。
補正と接線は既定で前処理のない GMRES で解くので、大きな問題や尺度の悪い問題では `with_linear_solver` で準備した解法を渡す。
デフレーションは `DeflationSet` に検査した根を加え、`DeflatedProblem::solve` の終了理由と元の残差で別の根を確かめる。
擬弧長継続が折り返し点を越える仕組みは[継続法による解の枝の追跡](../../algorithms/continuation-and-deflation/)、デフレーションの効果は[デフレーションによる別の解の探索](../../algorithms/deflation/)の Bratu 問題で確かめる。
