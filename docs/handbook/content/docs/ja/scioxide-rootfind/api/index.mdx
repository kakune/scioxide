`scioxide-rootfind` は、1 変数の実数・複素数の方程式、連立非線形方程式、固定点、多項式のすべての根を求める。
パラメータを含む方程式の解の枝をたどる継続法、既知の根を除いて別の根を探すデフレーション、特殊関数の番号付きの零点も扱う。
このガイドは目的ごとに使う項目を示し、公開されている 128 項目を用途別の表にまとめる。
表の項目名のリンクは、docs.rs の 0.1.0 の API リファレンスを指す。

## 目的別の API

| したいこと | API となる項目 | 表 |
|---|---|---|
| 区間 $[a, b]$ から 1 変数の根を求める | `find_root`、`Brent`、`Toms748`、`Bisection`、`ScalarFn`、`ScalarRootOptions` | [1 変数の求根](scalar/) |
| 初期値と導関数から 1 変数の根を求める | `Newton`、`Halley`、`SafeguardedNewton`、`Secant`、`Muller` | [1 変数の求根](scalar/) |
| 実行時に方法を選ぶ・区間を探す | `ScalarRootMethod`、`ScalarRootInput`、`find_bracket`、`find_bracket_with_options` | [1 変数の求根](scalar/) |
| 複素数の 1 変数の根を求める | `ComplexNewton`、`ComplexMuller`、`ComplexScalarFn` | [1 変数の求根](scalar/) |
| 連立方程式を解く | `solve_system`、`NewtonSystem`、`TrustRegionSystem`、`Broyden`、`ResidualFn`、各方法の設定 | [連立方程式・Newton–Krylov 法・固定点](systems/) |
| 行列を作らずに大規模な連立方程式を解く | `NewtonKrylovProblem`、`NewtonKrylovSolver`、`NonlinearLinearSolver` | [連立方程式・Newton–Krylov 法・固定点](systems/) |
| 固定点を加速して求める | `fixed_point`、`FixedPointSolver`、`FixedPointMethod`、`FixedPointOptions` | [連立方程式・Newton–Krylov 法・固定点](systems/) |
| パラメータに沿って解をたどる・別の解を探す | `Continuation`、`ContinuationProblem`、`LinearHomotopy`、`DeflationSet`、`DeflatedProblem` | [継続法とデフレーション](continuation/) |
| 多項式のすべての根を求める | `polynomial_roots`、`polynomial_roots_with_options`、`PolynomialRootOptions`、`PolynomialRootReport` | [多項式と特殊関数の零点](polynomial-and-special-zeros/) |
| 特殊関数の $m$ 番目の零点を求める | `special_zeros`、`special_zeros_with_options`、`SpecialZeroFamily`、`SpecialZeroReport` | [多項式と特殊関数の零点](polynomial-and-special-zeros/) |

区間（`Interval`）、許容誤差（`ResidualTolerance`、`StepTolerance`）、上限（`Budget`、`SolveBudgets`）、実行コンテキスト（`ExecutionContext`、`SolveScope`）、残差とヤコビ行列の作用のトレイト（`ResidualOperator`、`JacobianOperator`）は scioxide-core の項目である。
導関数の出所の方針（`DerivativeStrategy`）は scioxide-differentiate、ベクトル・行列・反復線形解法（`GmresSolver` など）は scioxide-linalg、基底付きの多項式（`ApproxPolynomial`）は scioxide-poly が提供する。
これらは各章の API ガイドで引く。

## 型の関係

- 問題：1 変数の実関数は `ScalarFunction`（クロージャなら `ScalarFn` など）、複素数の関数は `ComplexScalarFunction` で与える。
  密な連立方程式の方法は `DenseJacobian`（scioxide-core の `ResidualOperator` に任意の密なヤコビ行列を加えたトレイト。
  クロージャなら `ResidualFn`）を受け取る。
  固定点の方法は `ResidualOperator` を受け取る。
  Newton–Krylov 法は `ResidualOperator`（作用 $Jv$ を差分で作る）か `JacobianOperator`（作用を与える）を、継続法とデフレーションは `JacobianOperator` を使う（クロージャなら `ResidualFn::with_jvp`、パラメータを最後の入力にした写像は `ResidualFn::with_parameter`）。
- 方法と初期化：1 変数の方法は `ScalarRootSolver`（複素数は `ComplexRootSolver`）を実装し、関連型 `Initialization` で入力の形（`Interval`、初期値、2 点、3 点、`SafeguardedInitialGuess`）を区別する。
  区間法に初期値を渡すような誤りはコンパイル時に拒まれる。
  実行時に方法を選ぶ `ScalarRootMethod` は入力の形の食い違いを実行時に `InvalidInput` で拒む。
- ワンショット関数：`find_root`、`find_bracket`、`solve_system`、`fixed_point`、`polynomial_roots`、`special_zeros` は問題（クロージャや係数）を受け取り、既定の設定で解く。
  成功したときだけ答えを返し、それ以外の終了は `ConvergenceFailure`（上限による停止は上限の種類、ほかは `Stagnation`）、`ExecutionStopped`、`NumericalInstability` のエラーにする。
- 手法オブジェクト：連立方程式、Newton–Krylov 法、固定点、継続法では、検査した設定を持つ不変の値（`NewtonSystem`、`NewtonKrylovSolver`、`FixedPointSolver`、`Continuation` など）を先に作り、同じ値で何度でも解く。
  多項式と特殊関数の零点には手法オブジェクトがなく、`polynomial_roots_with_options` と `special_zeros_with_options` が設定を毎回受け取る。
- 作業領域：1 変数の方法と区間の探索は外部の作業領域を取らず、求解中に確保しない。
  手法オブジェクトは確保して結果を返す所有値を返す API の `solve`（継続法は `follow`）と、用意した出力と作業領域に書く出力先を指定する API の `solve_into` を持つ。
  出力先を指定する API では `workspace_requirements` で容量を求め、`try_reserve` で作業領域に事前確保してから、出力と作業領域を繰り返し使う。
  多項式と特殊関数の零点の出力先を指定する API は `polynomial_roots_into` と `special_zeros_into` で、作業領域を `PolynomialRootWorkspace::workspace(degree, &options)` と `SpecialZeroWorkspace::workspace(count, &options)` で作る。
  作業領域は解の世代（epoch）の状態と直前の試行の記録（`last_attempt()`）を持つので、呼び出し側は解の識別子を作らない。
  継続法の進行（受理した点、接線、履歴）は、作業領域とは別に呼び出し側が持つ `ContinuationState` に入る。
- 結果：1 変数は `RootResult`（複素数は `ComplexRootResult`）、連立は `SystemRootResult`、Newton–Krylov 法は `NewtonKrylovResult`、固定点は `FixedPointResult` に入る。
  多項式は `PolynomialRoots` と `PolynomialRootReport`、継続法は 1 回の進行ごとの `ContinuationReport` と `ContinuationState` の履歴、デフレーションは `DeflatedRootResult`、特殊関数の零点は `SpecialZeros` と `SpecialZeroReport` に入る。

## 最小の実行例：区間を保つ平方根

$f(x) = x^2 - 2$ の正の根 $\sqrt{2}$ を、区間 $[1, 2]$ から `Brent` で求め、解析値と比べる。
入力 $q$ は残差 $\lvert f(x) \rvert$ と座標の変化の許容誤差 $10^q$ を決める（どちらも絶対許容誤差）。
`with_residual_tolerance` で残差による受理を有効にしているので、残差が $10^q$ 以下になった時点で止まる。
表は終了理由、根、解析値との差、残差、反復回数、関数の評価回数、返る `Bracket` の両端を示す（区間を持たない方法では両端の欄が「なし」になる）。
セルの最後の判定（outcome）は、`termination().is_success()` が真なら satisfied、偽なら partial になる。

```rust
//| id: rootfind-api-brent-square-root
//| ref: rootfind-api-brent-square-root
//| title: 区間を保つ平方最上位の求解と終了理由
//| run: reactive
//| crates: [scioxide-core, scioxide-rootfind]
//| inputs:
//|   tolerance_exponent: {"type":"range","label":"許容誤差 10^q の指数 q","description":"残差と座標の変化の許容誤差。","min":-15,"max":-3,"step":1,"value":-12}
//| cases:
//|   - {"id":"tight","label":"q = −15（丸めの水準）","description":"6 反復で止まり、√2 との差は 2.2 × 10⁻¹⁶ になる。","inputs":{"tolerance_exponent":-15}}
//|   - {"id":"loose","label":"q = −3（粗い許容誤差）","description":"3 反復で止まり、√2 との差は 1.4 × 10⁻⁴ にとどまる。","inputs":{"tolerance_exponent":-3}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"summary","path":"/rows/0/0","equals":"ResidualTolerance"}
//|       - {"artifact":"summary","path":"/rows/0/2","approx":{"value":4.1e-14,"rtol":0.05}}
//|       - {"artifact":"summary","path":"/rows/0/3","approx":{"value":1.2e-13,"rtol":0.05}}
//|       - {"artifact":"summary","path":"/rows/0/4","equals":5}
//|       - {"artifact":"summary","path":"/rows/0/5","equals":7}
//|       - {"artifact":"summary","path":"/rows/0/6","approx":{"value":1.414213319995502,"atol":1e-15}}
//|       - {"artifact":"summary","path":"/rows/0/7","approx":{"value":1.414213562373136,"atol":1e-15}}
//|       - {"path":"/outputs/1/state","equals":"satisfied"}
//|   - case: tight
//|     expect:
//|       - {"artifact":"summary","path":"/rows/0/0","equals":"ResidualTolerance"}
//|       - {"artifact":"summary","path":"/rows/0/2","range":{"max":2.3e-16}}
//|       - {"artifact":"summary","path":"/rows/0/4","equals":6}
//|       - {"path":"/outputs/1/state","equals":"satisfied"}
//|   - case: loose
//|     expect:
//|       - {"artifact":"summary","path":"/rows/0/0","equals":"ResidualTolerance"}
//|       - {"artifact":"summary","path":"/rows/0/2","approx":{"value":1.4e-4,"rtol":0.05}}
//|       - {"artifact":"summary","path":"/rows/0/4","equals":3}
//|       - {"path":"/outputs/1/state","equals":"satisfied"}
use scioxide_core::{EvaluationRole, Interval, RealScalar, ResidualTolerance, StepTolerance};
use scioxide_rootfind::{Brent, ScalarFn, ScalarRootOptions, ScalarRootSolver};

// 残差（関数の単位）と座標の変化（変数の単位）の許容誤差を別々に設定する。
let tolerance = RealScalar::powf(10.0_f64, tolerance_exponent);
let options = ScalarRootOptions::default()
    .with_residual_tolerance(ResidualTolerance::new(tolerance, 0.0).map_err(|e| e.to_string())?)
    .with_step_tolerance(StepTolerance::new(tolerance, 0.0).map_err(|e| e.to_string())?);
let function = ScalarFn::new(|x: f64| Ok(x * x - 2.0));
let bracket = Interval::new(1.0, 2.0).map_err(|e| e.to_string())?;
let result = Brent
    .solve(&function, bracket, &options)
    .map_err(|e| e.to_string())?;
let termination = result.termination();
// 独立な検算: 解析値 √2（f64 の参照値）。
let x = result.point();
let error = (x - 2.0_f64.sqrt()).abs();
let evaluations = result.counts().provider(EvaluationRole::Function);
// 区間法は最後に評価した区間を返す。区間を持たない方法では None になる。
let (lower, upper) = result
    .bracket()
    .map_or((None, None), |b| (Some(b.lower()), Some(b.upper())));

let full = serde_json::json!({ "significantDigits": 16 });
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let columns = serde_json::json!([
    { "key": "0", "label": "終了理由" },
    { "key": "1", "label": "根 x [-]", "type": "number", "format": full },
    { "key": "2", "label": "|x − √2| [-]", "type": "number", "format": sci2 },
    { "key": "3", "label": "残差 |f(x)| [-]", "type": "number", "format": sci2 },
    { "key": "4", "label": "反復 [回]", "type": "integer" },
    { "key": "5", "label": "関数の評価 [回]", "type": "integer" },
    { "key": "6", "label": "区間の下端 [-]", "type": "number", "format": full, "nullText": "なし" },
    { "key": "7", "label": "区間の上端 [-]", "type": "number", "format": full, "nullText": "なし" }
]);
emit_table_with_columns!(
    columns,
    vec![(
        termination.to_string(),
        x,
        error,
        result.residual().abs(),
        result.counts().iterations(),
        evaluations,
        lower,
        upper,
    )],
    metadata = serde_json::json!({ "id": "summary" })
);

let outcome = if termination.is_success() {
    Outcome::satisfied("√2 の近似が終了条件を満たした")
} else {
    Outcome::partial("終了条件を満たす前に止まった")
        .explanation("返った点は未収束の候補として解釈する。")
};
emit_outcome!(
    outcome
        .status(termination.to_string())
        .diagnostic("残差 |f(x)|", result.residual().abs(), None)
        .diagnostic("√2 との差", error, None)
        .diagnostic("関数の評価", evaluations as f64, None)
);
```

入力の既定値 $q = -12$ では、5 反復（関数の評価 7 回。
初めの両端の 2 回を含む）で残差が $1.2 \times 10^{-13}$ になり、終了理由は `ResidualTolerance` である。
根と $\sqrt{2}$ の差は $4.1 \times 10^{-14}$ で、返る `Bracket` は $[1.414213319995502, 1.414213562373136]$、幅は $2.4 \times 10^{-7}$ である。
残差で止まったので、区間の幅は位置の誤差よりずっと大きい。
$q = -15$ では 6 反復で差が $2.2 \times 10^{-16}$、$q = -3$ では 3 反復で差が $1.4 \times 10^{-4}$ になる。

`with_residual_tolerance` を呼ばない `ScalarRootOptions::default()` では、区間法は区間の幅（既定 $4\varepsilon + 4\varepsilon \max(\lvert a \rvert, \lvert b \rvert)$）か厳密な零でだけ止まる。
この問題では 7 反復（評価 9 回）で `BracketTolerance` になり、区間の幅は $2.2 \times 10^{-16}$ まで縮む。
根の位置を区間の幅で押さえたいときは、残差の許容誤差を設定しない（端点の間の連続性は利用者の前提である）。

## 結果・エラー・診断の読み方

成否は `termination()` が返す `RootTermination` だけで判定する。
`is_success()` が真になるのは `ResidualTolerance`、`StepTolerance`、`BracketTolerance`、`Complete`、`NoZeros`（要求した特殊関数の零点の列が空と分かった）のときだけである。
`NotStarted`（出力を用意しただけ）と `Advanced`（継続法で 1 点を受理し、経路が残っている）は途中の状態を表し、失敗を意味しない。
次の終了理由では、`Ok` で返った値は未収束か未検証の候補である。

| 終了理由 | 意味 |
|---|---|
| `IterationLimit`、`WorkLimit(kind)` | 反復の上限か、局所または外側の求解の計算回数の上限（評価・反復などの種類 `kind`）に達した |
| `HistoryLimit`、`StepLimit` | 継続法で、事前確保した履歴が満杯になった、または再試行か最小の刻みを使い切った |
| `Stagnation` | 有限な点で進まなくなり、成功の条件を満たせなかった |
| `GlobalizationFailure` | 連立方程式の直線探索が尽き、最後に受理した点を返した |
| `LinearFailure(_)` | 内側の線形解法が精度か漸化式の検査に通らなかった |
| `TangentFailure` | 継続法で、最小の刻みでも接線を検証できなかったか、自然継続が折り返し点に達した |
| `Unverified` | 有限な候補が、元の方程式・根の分離・番号・枝の検査に通らなかった |
| `NumericalFailure(issue)` | 多項式の全根の計算が、数値的な破綻か値の範囲で完了しなかった |
| `ComplexStepRequired` | 実数の Muller 法の次の点が複素数になった |
| `Cancelled`、`TimeLimit` | 呼び出し側が取り消したか、注入した期限に達した |

エラーは `Err(SciOxideError)` で返り、`kind()` で分類する。
入力の形や値の誤り、非有限の入力と評価値、確保の失敗、コールバックのエラーは、どの方法でも `Err` になる。
数値的な破綻の扱いは方法で異なる。
1 変数の方法の破綻と、直線探索のない `NewtonSystem` の特異なヤコビ行列は `Err` になる。
多項式の全根（`polynomial_roots_with_options` と `polynomial_roots_into`）は破綻しても `NumericalFailure(issue)` のレポートを `Ok` で返し、有限な候補を出力に反映する。
計算回数の上限・取り消し・期限による停止は、検査済みの点があれば未成功の結果として `Ok` で返る。
区間の探索 `find_bracket` と `find_bracket_with_options` は例外で、根を挟む区間が得られなければ常に `Err` を返す。
ワンショット関数も成功でない終了をすべて `Err` で返す。
エラーは失敗の内容（分類、`Argument` または `Quantity`、詳細）を持ち、呼び出し元の識別子は持たない。
出力先を指定する API の `solve_into` などはエラーのとき出力を変えない。

推定と保証は区別する。
`Bracket` は両端で評価した符号の記録で、端点の間の連続性は利用者の前提である。
多項式の後退誤差と条件数、特殊関数の零点の推定誤差と符号の区間、継続法の分岐の診断は数値的な推定であり、区間演算による証明ではない。

計算量は 2 つのアクセサで読む。
`counts()` は、その求解が直接行った評価・反復・提案の回数を `EvaluationCounts` で返す。
`accounting()` は、入れ子の処理（内側の線形解法、特殊関数の評価など）の処理を分けて数えた `SolveCounts` を返し、合計は `accounting().total()` で読む。

規約の全体は[方程式の根を求める方法](../algorithms/)にある。

## まとめ

API は問題の形で決まる。
1 変数は `ScalarRootSolver` の方法か `ScalarRootMethod`、連立は `NewtonSystem`・`Broyden`・`TrustRegionSystem` か `NewtonKrylovSolver`、固定点は `FixedPointSolver`、多項式は `polynomial_roots_with_options`、パラメータを含む問題は `Continuation`、特殊関数の零点は `special_zeros_with_options` を使う。
既定の設定で答えだけが必要なら、`find_root`、`solve_system`、`fixed_point`、`polynomial_roots`、`special_zeros` のワンショット関数を使う。
どの API でも成否は `RootTermination` の `is_success()` で判定し、`Ok` で返った値でも終了理由が未成功なら候補として扱う。
残差・区間・後退誤差・条件数は推定として読み、精度は解析解や別の方法との比較で確かめる。
引数・既定値・エラーは用途別の表で確かめ、方法は[求根の選び方](../choosing/)で、区間が取れるか、導関数があるか、未知数がいくつかから選ぶ。
