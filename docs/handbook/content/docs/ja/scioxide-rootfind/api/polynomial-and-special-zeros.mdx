この表は多項式 $p(z) = \sum_k a_k z^k$ のすべての根と、特殊関数の番号付きの零点を求める項目をまとめる。
多項式の未収束（`IterationLimit`）、検証の不合格（`Unverified`）、数値的な破綻（`NumericalFailure`）は、`polynomial_roots_with_options` と `polynomial_roots_into` では `Ok` のレポートで表され、そのとき返る根は候補である。
各候補が元の係数での検査に通ったかは、`diagnostics()` の `is_validated` で読む。
特殊関数の零点の `special_zeros_with_options` と `special_zeros_into` は、リソースの上限などで止まっても検証済みの先頭の部分だけを返す。
ワンショット関数 `polynomial_roots` と `special_zeros` は、これらの未成功の終了をエラーにする。
どちらも成否は共通の `RootTermination` で判定する。
後退誤差、条件数、推定誤差は推定値で、区間演算の証明ではない。

複素数の零点の Newton 改良は同じ座標での関数値と導関数を一組として評価する。
補正が座標の丸めの水準 $2\varepsilon \max(\lvert z \rvert, 1)$ に達するか、関数値が自身の評価誤差の内側に入って補正が縮まなくなると、反復を止める。
最後の検証では評価の不確かさも含めて判定する。

## まとめ

多項式のすべての根は `polynomial_roots_with_options` で求め、`PolynomialRootReport` の終了理由・後退誤差・条件数で結果を読み、検査に通った根だけが必要なら `polynomial_roots` を使う。
scioxide-poly で準備した直交基底などの多項式は、単項式に変換せずに同じ関数に渡せる。
同じ次数の問題を繰り返すときは、`PolynomialRootWorkspace::workspace(degree, &options)` で準備した作業領域と `polynomial_roots_into` を使う。
特殊関数の零点は `special_zeros_with_options` に関数族・枝・番号を指定し、`SpecialZeroReport` の終了理由と検証済みの個数 `completed` を確かめ、実軸の零点の値だけが必要なら `special_zeros` を使う。
方法ごとの精度と計算コストは[実係数多項式の全根計算](../../algorithms/polynomial-root-pipeline/)で、零点の使い方と検算は[円形膜の固有振動数と Bessel 関数の零点](../../examples/circular-membrane/)で確かめる。
