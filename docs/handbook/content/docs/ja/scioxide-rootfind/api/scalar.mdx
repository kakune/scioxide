この表は 1 変数の方程式 $f(x) = 0$ を解く項目をまとめる。
方法は `ScalarRootSolver`（複素数は `ComplexRootSolver`）を実装し、関連型 `Initialization` が入力の形（区間、初期値、2 点、3 点、区間と初期値の組）を決める。
`solve` は上限や停滞で止まっても `Ok(RootResult)` を返すので、成否は `RootTermination` で判定する。
既定の設定のワンショット関数 `find_root` と `find_bracket` は、成功したときだけ答えを返し、それ以外の終了をエラーにする。
`Err` になるのは、入力の誤り、非有限の入力と評価値、要求した導関数がないこと、コールバックのエラー、数値的な破綻、検査済みの点を得る前の停止である。

## 作業領域を確保しないスカラー実行

実数・複素数の 1 変数の方法は外部の作業領域を受け取らない。
差分による導関数の評価も含めて、求解中に確保しない。
所有値を返す API の `solve` は逐次の実行コンテキストで解き、`solve_scoped` は渡した `ExecutionContext` か親の `SolveContext` の下で解く。
反復・評価・提案と入れ子の処理の上限は `ScalarRootOptions::with_budgets` に設定する。
反復は `with_max_iterations`（既定 100）でも制限される。

## 実行時の選択と区間の探索

`ScalarRootMethod` は方法を実行時の値で選び、`find_bracket` と `find_bracket_with_options` は区間法に渡す符号の変わる区間を探す。
`find_bracket_with_options` には、探索の初期の形（`BracketSearchInput`）と関数の向き（`BracketSearchDirection`）を別々の引数で渡す。
単調性は利用者が保証する前提で、標本から確かめるものではない。
加法的な探索は区間の幅を広げ、乗法的な探索は座標に拡大率を掛けるか拡大率で割る。
乗法的な探索では 0 を含まない定義域を `with_domain` で指定する。
定義域の開いた端はその内側で隣にある表現可能な数に置き換え、コールバックを定義域の外で呼ばない。
1 点から始める自動の加法的な探索は、半幅 $\max(\lvert x_0 \rvert, 1)$ の区間から始める。

## まとめ

1 変数の方法は入力の形で区間法・開いた方法・区間保護付きの方法に分かれ、取り違えは型で防がれる。
根を挟む区間が分かっていれば区間法か区間保護付きの方法を使い、返る `Bracket` で根の位置の範囲を確かめる。
区間が分からなければ、`find_bracket` で探してから `find_root` か区間法に渡す。
どの方法でも成否は `RootTermination` で判定し、反復と評価の内訳は `counts()`、子の処理を含む計数は `accounting().total()` で読む。
未知数が 2 つ以上の問題は、[連立方程式・Newton–Krylov 法・固定点](../systems/)の表で方法と作業領域を確かめる。
