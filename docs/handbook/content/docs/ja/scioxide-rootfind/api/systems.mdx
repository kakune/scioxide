この表は $n$ 元の連立方程式 $\mathbf{F}(\mathbf{x}) = \mathbf{0}$ と固定点 $\mathbf{x} = G(\mathbf{x})$ を解く項目をまとめる。
どの方法も、上限・停滞・大域化の失敗で止まった場合は `Ok` で結果を返すので、成否は結果の終了理由で判定する。
`Err` になるのは、入力・設定・作業領域の誤り、非有限の入力と評価値、コールバックのエラー、数値的な破綻（直線探索のない `NewtonSystem` の特異なヤコビ行列など）である。
出力先を指定する API の `solve_into` はエラーのとき出力を変えない。

## まとめ

既定の設定で解だけが必要なら、ワンショット関数 `solve_system` と `fixed_point` を使う。
ヤコビ行列を作れる連立方程式は `NewtonSystem`・`TrustRegionSystem`・`Broyden` で解き、作用 $Jv$ だけが使える大規模な問題は `NewtonKrylovSolver` で解く。
`NewtonSystem` は既定で直線探索を使わないので、初期値が根から遠いときは `with_line_search` で直線探索を加えるか、`TrustRegionSystem` を使う。
内側の線形解法は `NewtonSystemOptions::with_linear_solver` や `NonlinearLinearSolver` で差し替えられ、その補正は外側の解法が検査する。
固定点は `FixedPointSolver` で加速の規則を選び、独立に評価した残差と終了理由で結果を読む。
パラメータを含む問題と別の解の探索は、[継続法とデフレーション](../continuation/)の表で項目を確かめる。
