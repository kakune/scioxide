リガンドと受容体の結合、金属錯体の形成、酸塩基平衡などの化学平衡の計算は、非線形の連立方程式の典型的な応用である。

理想希薄溶液の中で、二成分 $A$ と $B$ が 1 対 1 で可逆的に会合する反応

$$
A + B \rightleftharpoons C
$$

を考える。
平衡での自由濃度を $a = [A]$、$b = [B]$、複合体の濃度を $c = [C]$（単位はいずれも mM）と置く。
Guldberg–Waage の質量作用の法則から、濃度で表した会合定数 $K$ [mM⁻¹] と濃度の間に次の関係が成り立つ。

$$
K = \frac{c}{a b} \iff c = K a b
$$

系に入れた全濃度を $A_T$、$B_T$ [mM] とすると、物質収支（各成分の総量の保存）から次の関係が得られる。

$$
A_T = a + c = a + K a b, \qquad B_T = b + c = b + K a b
$$

複合体の濃度 $c$ を消去すると、未知数 $(a, b)$ の 2 元の非線形連立方程式になる。

$$
\mathbf{F}(a, b) = \begin{bmatrix} F_1(a, b) \\ F_2(a, b) \end{bmatrix} = \begin{bmatrix} a + K a b - A_T \\ b + K a b - B_T \end{bmatrix} = \mathbf{0}
$$

## 物理的な制約と対数の変数

濃度は正でなければならず、物理的に意味のある解は次の範囲にある。

$$
0 < a \le A_T, \qquad 0 < b \le B_T, \qquad 0 \le c \le \min(A_T, B_T)
$$

$(a, b)$ をそのまま未知数にして Newton 法を使うと、最初の反復の大きな更新で $a < 0$ や $b < 0$ になることがある。
負の濃度は物理的に意味がないだけでなく、化学ポテンシャルの $\ln a$ のような項を含む系では、残差を評価できなくなる。

そこで、濃度を基準濃度 1 mM で割った無次元の数値の対数を未知数にする。

$$
a = e^u, \qquad b = e^v \qquad (u, v \in \mathbb{R})
$$

ここで $a$、$b$ は mM 単位の数値を表す。
$(u, v)$ が $\mathbb{R}^2$ のどこにあっても $a > 0$、$b > 0$ が保たれる。
変換した連立方程式は次のとおりである。

$$
\mathbf{G}(u, v) = \begin{bmatrix} G_1(u, v) \\ G_2(u, v) \end{bmatrix} = \begin{bmatrix} e^u + K e^{u+v} - A_T \\ e^v + K e^{u+v} - B_T \end{bmatrix} = \mathbf{0}
$$

残差 $\mathbf{G}$ の単位は、元の物質収支と同じ mM である。

## ヤコビ行列と解の一意性

連鎖律から、$\mathbf{G}(u, v)$ のヤコビ行列 $\mathbf{J}_G \in \mathbb{R}^{2 \times 2}$ の成分は次のようになる。

$$
\frac{\partial G_1}{\partial u} = e^u + K e^{u+v} = a + c, \qquad \frac{\partial G_1}{\partial v} = K e^{u+v} = c
$$

$$
\frac{\partial G_2}{\partial u} = K e^{u+v} = c, \qquad \frac{\partial G_2}{\partial v} = e^v + K e^{u+v} = b + c
$$

したがって、ヤコビ行列は対称行列である。

$$
\mathbf{J}_G = \begin{bmatrix} a + c & c \\ c & b + c \end{bmatrix}, \qquad \det \mathbf{J}_G = (a + c)(b + c) - c^2 = a b + a c + b c
$$

$a > 0$、$b > 0$、$c > 0$ なので行列式は正で、左上の成分 $a + c$ も正である。
Sylvester の判定法から、$\mathbf{J}_G$ は $(u, v)$ のどこでも正定値になる。
ヤコビ行列が特異になる点はないので、Newton 法の線形方程式 $\mathbf{J}_G \mathbf{s} = -\mathbf{G}$ はいつも一意に解ける。

さらに $\mathbf{G}$ は関数

$$
\Phi(u, v) = e^u + e^v + K e^{u+v} - A_T u - B_T v
$$

の勾配 $\nabla \Phi$ で、$\mathbf{J}_G$ はそのヘッセ行列である。
ヘッセ行列がどこでも正定値なので $\Phi$ は狭義凸で、$\nabla \Phi = \mathbf{0}$ となる点、すなわち平衡は高々一つである。
次に示す閉形式が正の解を一つ与えるので、平衡はちょうど一つある。
ただし、これは Newton 法がどの初期値からも速く収束することまでは意味しない（結果の節で、遠い初期値での反復回数を見る）。

## 閉形式による検算

物質収支の差から $a - b = A_T - B_T = \Delta$ が得られる。
これを $B_T = b + K a b$ に代入すると、$b$ の 2 次式 $K b^2 + (1 + K \Delta) b - B_T = 0$ になり、正の根は

$$
b=\begin{cases}
\displaystyle\frac{2B_T}{\beta+d},&\beta\ge0,\\[4pt]
\displaystyle\frac{d-\beta}{2K},&\beta<0,
\end{cases}
\qquad \beta=1+K\Delta,\quad d=\sqrt{\beta^2+4KB_T}
$$

である。
二つの式は数学的には同じだが、$\beta$ の符号に応じて使い分けると、近い数どうしの引き算による桁落ちを避けられる。
$a$ は $b + \Delta$ から求めず、同じ理由で $A_T/(1 + Kb)$ から求めて引き算を避ける。
セルではこの閉形式を、Newton 法とは別の独立な検算に使う。

次のブロックは、このページの二つのセルが共有する定義である。
`mass_balance` が物質収支の残差 $\mathbf{F}(a, b)$ [mM]、`closed_form` が上の閉形式による平衡濃度 $(a, b, c)$ [mM] に対応する。
対数濃度を未知数にした残差 $\mathbf{G}(u, v)$ は、$a = e^u$、$b = e^v$ を `mass_balance` に渡して作る。

```rust
//| id: rootfind-chemical-model
//| kind: definitions
//| title: 会合平衡の物質収支と閉形式
//| crates: [scioxide-core]
use scioxide_core::RealScalar;

/// 物質収支の残差 F(a, b) = (a + Kab − Aₜ, b + Kab − Bₜ) [mM]。
pub(crate) fn mass_balance(k: f64, total_a: f64, total_b: f64, a: f64, b: f64) -> [f64; 2] {
    let c = k * a * b;
    [a + c - total_a, b + c - total_b]
}

/// 閉形式による平衡濃度 [a, b, c] [mM]。
/// a − b = Δ を代入した K b² + (1 + KΔ) b − Bₜ = 0 の正の根を、桁落ちしない形で求める。
pub(crate) fn closed_form(k: f64, total_a: f64, total_b: f64) -> [f64; 3] {
    let beta = 1.0 + k * (total_a - total_b);
    let d = RealScalar::sqrt(beta * beta + 4.0 * k * total_b);
    let b = if beta >= 0.0 {
        2.0 * total_b / (beta + d)
    } else {
        (d - beta) / (2.0 * k)
    };
    let a = total_a / (1.0 + k * b);
    [a, b, k * a * b]
}
```

## 平衡濃度の計算

次のセルは会合定数 $K$、全濃度 $A_T$、$B_T$、Newton 法の初期値、直線探索の有無を変え、`NewtonSystem` に解析的なヤコビ行列を与えて $(u, v)$ を求める。
初期値は全濃度に対する自由濃度の割合 $f_0$ で与え、$(u_0, v_0) = (\ln f_0 A_T, \ln f_0 B_T)$ とする。

`NewtonSystem` の既定の残差の基準は初期点での残差の 2 ノルムに対する相対の減少（$\sqrt{\varepsilon}$ 倍）である。
ここでは残差の 2 ノルムが絶対の閾値 $10^{-12}$ mM 以下になったら受理するように、`ResidualTolerance::new(1e-12, 0.0)` を与える。
更新幅 $\Delta\mathbf{x}$ が $\lVert \Delta\mathbf{x} \rVert_2 \le \tau_a + \tau_r \max(1, \lVert \mathbf{x} \rVert_2)$ を満たし、しかも残差が減らなかったとき、解法は停滞（`Stagnation`）で止まる。
`StepTolerance` の $\tau_a$、$\tau_r$ を既定の $\sqrt{\varepsilon} \approx 1.5 \times 10^{-8}$ から $10^{-15}$ に小さくして、丸めの程度の更新でも残差が減る間は反復を続けるようにする。
既定の `NewtonSystem` は直線探索を使わず、Newton の更新をそのまま採用する。
直線探索の入力を `BacktrackingLineSearch` にすると、`with_line_search(BacktrackingLineSearch::default())` が、メリット関数 $\lVert \mathbf{G} \rVert_2^2 / 2$ を Armijo の条件で十分に減らすステップ幅まで更新を縮める。

1 つ目の表は終了理由、反復回数、残差の評価回数、最終の残差を示す。
終了理由が成功のときだけ、2 つ目の表に平衡濃度、閉形式との差、物質収支の誤差を出す。
セルの最後の判定は終了理由の成否で、成功でない場合は濃度を出さない。
このセルの $K$、$A_T$、$B_T$ は次のセルの残差の地形にも渡す。

```rust

//| title: 会合平衡を対数濃度の連立 Newton 法で解く
//| run: reactive
//| uses: [rootfind-chemical-model]

//|   - case: default
//|     expect:
//|       - {"artifact":"solve","path":"/rows/0/0","equals":"ResidualTolerance"}
//|       - {"artifact":"solve","path":"/rows/0/1","equals":5}

//|       - {"path":"/outputs/2/state","equals":"satisfied"}

//|     expect:
//|       - {"artifact":"solve","path":"/rows/0/0","equals":"ResidualTolerance"}
//|       - {"artifact":"solve","path":"/rows/0/1","equals":7}
//|       - {"artifact":"species","path":"/rows/1/1","approx":{"value":0.0737034184,"atol":5e-11}}
//|       - {"artifact":"species","path":"/rows/2/1","approx":{"value":0.8262965816,"atol":5e-11}}
//|       - {"path":"/outputs/2/state","equals":"satisfied"}
//|   - case: far-start
//|     expect:
//|       - {"artifact":"solve","path":"/rows/0/0","equals":"ResidualTolerance"}
//|       - {"artifact":"solve","path":"/rows/0/1","equals":28}
//|       - {"artifact":"species","path":"/rows/0/1","approx":{"value":0.5732928050,"atol":5e-11}}
//|       - {"path":"/outputs/2/state","equals":"satisfied"}
//|   - case: far-start-line-search
//|     expect:
//|       - {"artifact":"solve","path":"/rows/0/0","equals":"ResidualTolerance"}
//|       - {"artifact":"solve","path":"/rows/0/1","equals":8}
//|       - {"artifact":"solve","path":"/rows/0/2","equals":12}
//|       - {"artifact":"species","path":"/rows/0/1","approx":{"value":0.5732928050,"atol":5e-11}}
//|       - {"path":"/outputs/2/state","equals":"satisfied"}
use scioxide_core::{EvaluationRole, NumericScalar, RealScalar, ResidualTolerance, StepTolerance};
use scioxide_differentiate::DerivativeStrategy;
use scioxide_rootfind::{
    BacktrackingLineSearch, NewtonSystem, NewtonSystemOptions, ResidualFn, RootTermination,
    SystemRootSolver,
};

let (k, at, bt) = (association_constant, total_a_mm, total_b_mm);
// 未知数は u = ln a、v = ln b。G(u, v) = F(e^u, e^v) [mM]。
let equilibrium = ResidualFn::new(2, move |x: &[f64], out: &mut [f64]| {
    let (a, b) = (RealScalar::exp(x[0]), RealScalar::exp(x[1]));
    out.copy_from_slice(&mass_balance(k, at, bt, a, b));
    Ok(())
})
// 解析的なヤコビ行列 [[a + c, c], [c, b + c]]（c = Kab、行優先）。
.with_jacobian(move |x: &[f64], j: &mut [f64]| {
    let (a, b) = (RealScalar::exp(x[0]), RealScalar::exp(x[1]));
    let c = k * a * b;
    j.copy_from_slice(&[a + c, c, c, b + c]);
    Ok(())
});
let start = [
    RealScalar::ln(initial_free_fraction * at),
    RealScalar::ln(initial_free_fraction * bt),
];
// 残差の 2 ノルム ≤ 1e-12 mM（絶対の基準）で受理し、停滞の判定は更新幅 1e-15 まで待つ。
let options = NewtonSystemOptions::default()
    .with_derivative_strategy(DerivativeStrategy::Analytic)
    .with_residual_tolerance(ResidualTolerance::new(1e-12, 0.0).map_err(|e| e.to_string())?)
    .with_step_tolerance(StepTolerance::new(1e-15, 1e-15).map_err(|e| e.to_string())?);
// 直線探索の有無で設定の型が変わるので、解法の値は分岐ごとに作る。
let result = if line_search == "なし" {
    NewtonSystem::new(options)
        .map_err(|e| e.to_string())?
        .solve(&equilibrium, &start)
        .map_err(|e| e.to_string())?
} else {
    NewtonSystem::new(options.with_line_search(BacktrackingLineSearch::default()))
        .map_err(|e| e.to_string())?
        .solve(&equilibrium, &start)
        .map_err(|e| e.to_string())?
};
export!(association_constant, k);
export!(total_a_mm, at);
export!(total_b_mm, bt);
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let termination = result.termination();
let solve_columns = serde_json::json!([
    { "key": "0", "label": "終了理由" },
    { "key": "1", "label": "反復 [回]", "type": "integer" },
    { "key": "2", "label": "残差の評価 [回]", "type": "integer" },
    { "key": "3", "label": "最終の残差 ‖G‖₂ [mM]", "type": "number", "format": sci2, "nullText": "なし" }
]);
emit_table_with_columns!(
    solve_columns,
    vec![(
        termination.to_string(),
        result.iterations(),
        result.counts().provider(EvaluationRole::Residual),
        result.residual_norm()
    )],
    metadata = serde_json::json!({ "id": "solve" })
);
let outcome = if termination.is_success() {
    let (a, b) = (
        RealScalar::exp(result.point()[0]),
        RealScalar::exp(result.point()[1]),
    );
    let c = k * a * b;
    // 独立な検算: 閉形式の濃度と、物質収支 a + c = Aₜ、b + c = Bₜ。
    let exact = closed_form(k, at, bt);
    let fixed10 = serde_json::json!({ "fractionDigits": 10 });
    let species_columns = serde_json::json!([
        { "key": "0", "label": "化学種" },
        { "key": "1", "label": "平衡濃度 [mM]", "type": "number", "format": fixed10 },
        { "key": "2", "label": "閉形式との差 [mM]", "type": "number", "format": sci2 },
        { "key": "3", "label": "物質収支の誤差 [mM]", "type": "number", "format": sci2, "nullText": "-" }
    ]);
    let rows = vec![
        ("自由 A", a, NumericScalar::abs(a - exact[0]), Some(NumericScalar::abs(a + c - at))),
        ("自由 B", b, NumericScalar::abs(b - exact[1]), Some(NumericScalar::abs(b + c - bt))),
        ("複合体 C", c, NumericScalar::abs(c - exact[2]), None),
    ];
    emit_table_with_columns!(
        species_columns,
        rows,
        metadata = serde_json::json!({ "id": "species" })
    );
    Outcome::satisfied("残差の 2 ノルムが絶対の基準 10⁻¹² mM を満たした")
} else if matches!(
    termination,
    RootTermination::GlobalizationFailure | RootTermination::LinearFailure(_)
) {
    Outcome::failed("Newton 法が受理できる更新を作れずに止まった")
        .explanation("濃度は出さない。初期値の割合か直線探索の設定を見直す。")
} else {
    Outcome::partial("Newton 法が受理の条件を満たす前に止まった")
        .explanation("最後の点は推定値で、濃度は出さない。初期値の割合か直線探索の設定を見直す。")
};
let mut outcome = outcome
    .status(termination.to_string())
    .diagnostic("反復", result.iterations() as f64, None);
if let Some(residual) = result.residual_norm() {
    outcome = outcome.diagnostic("最終の残差 ‖G‖₂", residual, Some("mM"));
}
emit_outcome!(outcome);
```

既定値（$K = 4$ mM⁻¹、$A_T = 1.2$ mM、$B_T = 0.9$ mM、$f_0 = 0.6$）では、5 反復（残差の評価 6 回）で `ResidualTolerance` に達し、$a = 0.57329$、$b = 0.27329$、$c = 0.62671$ mM である。
最終の残差は $2.1 \times 10^{-14}$ mM、閉形式との差は $1.2 \times 10^{-14}$ mM 以下、物質収支の誤差は $1.2 \times 10^{-14}$ mM と $1.7 \times 10^{-14}$ mM である。
どれも、濃度の大きさ（約 1 mM）に倍精度の単位丸め誤差 $1.1 \times 10^{-16}$ を掛けた値の百倍程度にとどまる。
$K = 30$ mM⁻¹ では全濃度の少ない B の自由濃度が $b = 0.0737$ mM に下がり、複合体は $c = 0.8263$ mM と上限 $\min(A_T, B_T) = 0.9$ mM に近づく（7 反復）。

初期値の割合を $f_0 = 0.05$ にすると、同じ解に達するまでに 28 反復かかる。
初期点では $a$、$b$ が小さく、ヤコビ行列の成分も小さいので、最初の Newton の更新が大きく行き過ぎ、$(u, v) \approx (11.2, 9.3)$、残差は約 $5 \times 10^9$ mM になる。
そこから先は $K e^{u+v}$ の項が残差を支配する。
$e^w$ が支配的な方程式に対する Newton 法の刻みが $-1$ になるのと同じく、$w = u + v$ が 1 反復でほぼ 1 ずつ減るので、解の近くに戻るまでに 20 回以上かかる。
解の近くに戻ってからは 2 次収束で数回のうちに受理される。
このような行き過ぎは[非線形連立方程式と大域化](../../algorithms/nonlinear-systems/)で説明する直線探索や信頼領域法（`TrustRegionSystem`）で抑えられる。
直線探索の入力を `BacktrackingLineSearch` にすると、$f_0 = 0.05$ でも 8 反復（残差の評価 12 回）で同じ解に達する。
評価が反復より多いのは、棄却したステップ幅の試行も残差を評価するからである。
既定の $f_0 = 0.6$ では最初から完全な Newton の刻みが受理されるので、直線探索の有無で反復回数は変わらない（5 反復）。

## 残差の地形

次のセルは前のセルの $K$、$A_T$、$B_T$ を受け取り、自由濃度の平面 $(a, b)$ の上の残差ノルム $\lVert \mathbf{F}(a, b) \rVert_2$ [mM] を描く。
横軸は $0.01$ から $1.1 A_T$ mM、縦軸は $0.01$ から $1.1 B_T$ mM で、それぞれ 43 点の格子を取る。
これは Newton 法の結果を使わない図で、二つの物質収支の曲線 $F_1 = 0$、$F_2 = 0$ がどこで交わるかを見るためのものである。

```rust
//| id: rootfind-chemical-equilibrium-residual-map
//| ref: rootfind-chemical-equilibrium-residual-map
//| title: 自由濃度の平面での物質収支の残差を描く
//| run: reactive
//| uses: [rootfind-chemical-model]
//| crates: [scioxide-core]
//| dependsOn:
//|   solve: rootfind-chemical-equilibrium
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"residual-map","path":"/spec/data/0/0","approx":{"value":0.01,"atol":1e-12}}
//|       - {"artifact":"residual-map","path":"/spec/data/42/0","approx":{"value":1.32,"atol":1e-12}}
//|       - {"artifact":"residual-map","path":"/spec/data/1848/1","approx":{"value":0.99,"atol":1e-12}}
//|       - {"artifact":"residual-map","path":"/spec/data/491/0","approx":{"value":0.5714,"atol":5e-4}}
//|       - {"artifact":"residual-map","path":"/spec/data/491/1","approx":{"value":0.2667,"atol":5e-4}}
//|       - {"artifact":"residual-map","path":"/spec/data/491/2","range":{"max":0.05}}
use scioxide_core::RealScalar;

let field = |name: &str| solve[name].as_f64().ok_or(format!("{name} がない"));
let (k, at, bt) = (
    field("association_constant")?,
    field("total_a_mm")?,
    field("total_b_mm")?,
);
// 格子の座標 [mM]。
let axis = |total: f64| -> Vec<f64> {
    (0..=42)
        .map(|i| 0.01 + (1.1 * total - 0.01) * f64::from(i) / 42.0)
        .collect()
};
let (xs, ys) = (axis(at), axis(bt));
// [a, b, ‖F(a, b)‖₂]。‖F‖₂ = √(F₁² + F₂²) [mM]。
let map: Vec<[f64; 3]> = ys
    .iter()
    .flat_map(|&y| xs.iter().map(move |&x| (x, y)))
    .map(|(x, y)| {
        let [f1, f2] = mass_balance(k, at, bt, x, y);
        [x, y, RealScalar::hypot(f1, f2)]
    })
    .collect();
emit_chart!(
    serde_json::json!({
        "kind": "heatmap",
        "data": map,
        "xLabel": "自由濃度 a [mM]",
        "yLabel": "自由濃度 b [mM]",
        "title": "残差ノルム ‖F(a, b)‖₂ [mM]",
        "tooltip": true,
        "style": { "animation": false }
    }),
    metadata = serde_json::json!({
        "id": "residual-map",
        "caption": "色は ‖F(a, b)‖₂ [mM] の線形尺度"
    })
);
```

残差の小さい谷は二つの物質収支の曲線に沿って伸び、二つの谷が交わる点が平衡である。
$F_1 = 0$ は $b = (A_T/a - 1)/K$、$F_2 = 0$ は $a = (B_T/b - 1)/K$ という双曲線である。
$K$ を大きくすると両者は軸に近づき、交点は全濃度の少ない側の成分の自由濃度が 0 に近い位置へ寄る。
前のセルで $K = 30$ mM⁻¹ にすると、交点は $b \approx 0.07$ mM の位置へ下がる。
色は残差ノルムの線形尺度で、値を切り上げたり切り捨てたりしていない。
谷の底の小さい残差は色では区別しにくいので、平衡の値は前のセルの表で読む。

## まとめ

会合平衡は質量作用の法則と物質収支の連立方程式になり、自由濃度の対数を未知数にすると、反復の途中でも濃度が正に保たれる。
対数の変数ではヤコビ行列が対称正定値で、残差が狭義凸関数の勾配になるので、平衡はちょうど一つあり、Newton 法の線形方程式はいつも解ける。
`NewtonSystem` に解析的なヤコビ行列を与えると近い初期値からは数回で収束するが、遠い初期値では直線探索のない Newton 法が大きく行き過ぎて反復が増える。
残差を mM の絶対の基準で受理するときは `ResidualTolerance::new(atol, 0.0)` を与え、終了理由が成功であることを確かめてから濃度を使う。
結果は閉形式と物質収支のように、Newton 法とは別の関係で確かめる。
