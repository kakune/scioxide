太鼓の膜のように周囲を固定した円形膜の振動数は、Bessel 関数の零点で決まる。
必要なのは「どこかの零点」ではなく「$\nu$ 次の $m$ 番目の零点」なので、一般の求根法で零点を一つ見つけるだけでは足りない。
このページでは番号を指定して特殊関数の零点を求める `special_zeros_with_options` で固有振動数を計算する。
Bessel 関数そのものの性質と円筒波は [scioxide-special の円筒波](../../../scioxide-special/examples/cylindrical-wave/)で扱い、記号 $j_{\nu,m}$ もそれにそろえる。

## 膜の振動と境界条件

面密度 $\sigma$ [kg/m²]、張力 $T$ [N/m] の膜の変位 $w(r, \varphi, t)$ [m] は、波動方程式 $w_{tt} = c^2 \nabla^2 w$（$c = \sqrt{T/\sigma}$ [m/s]）に従う。
$w = R(r)\cos(\nu\varphi)\cos(\omega t)$ と変数を分けると、$R$ は Bessel の微分方程式

$$
r^2 R'' + r R' + \bigl(k^2 r^2 - \nu^2\bigr) R = 0, \qquad k = \omega / c
$$

を満たす。
周方向に一周して元に戻るので $\nu = 0, 1, 2, \dots$ で、中心で有限な解は $R = J_\nu(kr)$ である（もう一つの解 $Y_\nu$ は $r \to 0$ で発散する）。
半径 $a$ [m] の周囲で $R(a) = 0$ とすると $k a = j_{\nu,m}$（$J_\nu$ の $m$ 番目の正の零点）となり、固有振動数は

$$
f_{\nu,m} = \frac{\omega}{2\pi} = \frac{c\, j_{\nu,m}}{2\pi a}
$$

である。
モード $(\nu, m)$ は直径方向の節線を $\nu$ 本、周囲を除く節円を $m - 1$ 個持つ。
$j_{0,1} = 2.404826$ が基本振動数を決め、他の振動数の比 $j_{\nu,m}/j_{0,1}$ は整数にならないので、太鼓の音は非調和な倍音を含む。
ここでは半径 $a = 0.33$ m、面密度 $\sigma = 0.26$ kg/m² の膜を考え、張力を変える。

## 番号付きの零点の求め方

`special_zeros_with_options(family, branch, start, count, &options)` は、関数族（`SpecialZeroFamily::BesselJ(nu)` など）、分枝（正の実数の零点は `SpecialZeroBranch::Real`）、最初の番号（1 から）、個数、設定を受け取る。
返す `SpecialZeros` は検査に通った零点の列で、`report().termination()` が成功（`Complete`）なら要求したすべての零点が検査済みである。
零点の値だけでよければ、`special_zeros(SpecialZeroFamily::BesselJ(nu), count)` が番号 1 からの `count` 個を既定の設定で求め、すべて検査に通ったときだけ値の列を返す。

$J_\nu$ の実数の零点では、番号は次の手順で決まる。

1. $\nu = 0, 1, 5/2$ の第 8 零点までは表の値を初期近似にする。
   それ以外では、$\beta = (m + \nu/2 - 1/4)\pi$ が十分大きい場合（$\beta > 8$ かつ $\beta > 2(\nu^2 + 1)$）は McMahon の漸近展開、$\nu \ge 32$ で転回点の近くの零点は Olver の一様漸近展開から初期近似を作る。
2. 初期近似があれば、その周りの区間（隣の零点までの間隔の $\pm 0.35$ 倍）で符号の変化を確かめる。
3. 初期近似がないか符号が変わらなければ、$x = \max(\nu, 1/8)$ から振動の 4 分の 1 周期より短い刻みで右へ進み、符号の変化を数えて $m$ 番目の変化を選ぶ（$j_{\nu,1} > \nu$ なので、この点より左に零点はない）。
4. 選んだ区間の中で、区間の外へ出る更新を二分法に置き換える Newton 法（区間保護付きの Newton 法）で零点を絞り込む。
5. 最後に、丸めた座標で関数を評価し直し、推定誤差（関数値と評価誤差の和を傾きで割った量と、丸めによる移動の和）が許容誤差以下であることを確かめる。

刻みを振動の 4 分の 1 周期より短くするのは、一つの刻みの中に二つの零点が入って符号の変化が打ち消し合うのを避けるためである。
ただし、これらは浮動小数点の評価に基づく確認で、包含が保証された区間ではない。
この例の既定値では、$\nu = 2, 3$ の小さい番号の零点は表にも漸近展開の適用範囲にもないので、手順 3 の数え上げで番号が決まる。
各段階の詳細と、導関数の零点・複素数の分枝・原点の指定・部分結果の扱いは[特殊関数の添字付き零点](../../algorithms/special-function-zeros/)にある。

## モードの振動数

次のセルは次数 $\nu = 0, \dots, \nu_{\max}$ のそれぞれで最初の $M$ 個の零点を `special_zeros_with_options` で求め、振動数の低い順に並べる。
入力は最大の次数 $\nu_{\max}$、次数ごとの零点の数 $M$、張力 $T$ [N/m] である。
出力は振動数を次数ごとに並べた図、波の速さと基本振動数の表、低い順の 12 個までのモードの零点、振動数、基本振動数との比、推定誤差の表である。
次のセルで交互性を調べるため、零点は $\nu_{\max} + 1$ 次まで求めて渡す。
零点の列の終了状態が成功でなければ、その次数では検査に通った先頭の零点までを使って止め、outcome でそれを示す。

```rust
let (radius, density) = (0.33_f64, 0.26_f64);
let speed = RealScalar::sqrt(tension / density);
let frequency = |j: f64| speed * j / (2.0 * PI * radius);
let (orders, count) = (max_order as usize, zeros_per_order as usize);

        SpecialZeroFamily::BesselJ(nu as f64),
        SpecialZeroBranch::Real,
        1,
        count,
        &SpecialZeroOptions::default(),

    { "key": "0", "label": "波の速さ c [m/s]", "type": "number", "format": fixed2 },
    { "key": "1", "label": "基本振動数 f₀₁ [Hz]", "type": "number", "format": fixed2 }
]);

    vec![(speed, frequency(j01))],
    metadata = serde_json::json!({ "id": "summary" })

    .iter()
    .take(12)

    { "key": "0", "label": "(ν, m)" },
    { "key": "1", "label": "零点 j_ν,m [-]", "type": "number", "format": { "fractionDigits": 10 } },

    Outcome::satisfied("すべての次数で要求した零点が元の関数での検査に通った")
} else if matches!(termination, RootTermination::Unverified) {
    Outcome::failed("検査に通らない零点があり、その次数で止めた")
} else {
    Outcome::partial("上限で零点の探索が止まり、その次数で止めた")
};
emit_outcome!(
    outcome
```

既定の $T = 4000$ N/m では、波の速さは 124.03 m/s、基本振動数は $f_{0,1} = 143.86$ Hz である。
次に高いモード $(1, 1)$、$(2, 1)$、$(0, 2)$ の振動数の比は 1.5933、2.1355、2.2954 で、零点の比 $j_{\nu,m}/j_{0,1}$ そのものである。
12 個の零点の推定誤差（`SpecialZero::estimated_error`）は $1.7 \times 10^{-15}$ 以下で、outcome は `Complete` を示す。
張力は振動数を $\sqrt{T}$ に比例して変え、零点と振動数の比は変えない（$T = 1000$ N/m で基本振動数は 71.93 Hz）。
図では同じ番号 $m$ の振動数が次数とともに増え、$f_{\nu+1,m}$ は $f_{\nu,m}$ と $f_{\nu,m+1}$ の間に入る（零点の交互性）。
$\nu_{\max} = 6$ にすると、$(4, 1)$、$(5, 1)$、$(6, 1)$ のような節線の多いモードが低い順の 12 個に入る。
実際の太鼓では、空気の負荷や膜の曲げ剛性で振動数がこの理想的な値からずれる。

## 零点の独立な検算

`special_zeros_with_options` の結果は元の関数で検査した推定値である。
その関数値は scioxide-special の Bessel 関数と同じ評価経路で求めるので、`bessel_j` で評価し直しても独立な検算にはならない。
次のセルは前のセルの零点を受け取り、求根とは別の三つの関係で確かめる。

1. べき級数 $J_\nu(x) = \sum_{k \ge 0} (-1)^k (x/2)^{2k+\nu} / \bigl(k!\,(k+\nu)!\bigr)$（[DLMF 10.2.2](https://dlmf.nist.gov/10.2.E2)）を倍精度で足した値。
   項の絶対値の和 $A = \sum_k |t_k|$ は $I_\nu(x)$ に等しく、和の丸め誤差はおよそ $\varepsilon A$ の数倍である。
   $x$ が大きいと $A \approx e^x/\sqrt{2\pi x}$ が増えて桁落ちが大きくなるので、級数の値は $\varepsilon A$ と比べて読む。
2. McMahon の 3 項の漸近展開（[DLMF 10.21.19](https://dlmf.nist.gov/10.21.E19)）との差。

   $$
   j_{\nu,m} \sim \beta - \frac{\mu - 1}{8\beta} - \frac{4(\mu - 1)(7\mu - 31)}{3(8\beta)^3}, \qquad \beta = \left(m + \frac{\nu}{2} - \frac14\right)\pi, \quad \mu = 4\nu^2
   $$

   これは $\nu$ を固定して $m \to \infty$ とする漸近展開で、差は展開の打切り誤差を表す。
3. 交互性 $j_{\nu,m} < j_{\nu+1,m} < j_{\nu,m+1}$（[DLMF 10.21.2](https://dlmf.nist.gov/10.21.E2)、$\nu \ge 0$）の破れの数。
   値の精度ではなく番号の検算で、一つでも零点を取り違えると破れとして現れる。

```rust
//| id: rootfind-membrane-zero-checks
//| ref: rootfind-membrane-zero-checks
//| title: Bessel 関数の零点をべき級数・McMahon の展開・交互性で確かめる
//| run: reactive
//| crates: [scioxide-core]
//| dependsOn:
//|   modes: rootfind-membrane-modes
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"checks","path":"/rows/0/0","equals":0}
//|       - {"artifact":"checks","path":"/rows/0/1","equals":12}
//|       - {"artifact":"zeros","path":"/rows/0/2","range":{"min":-1e-15,"max":1e-15}}
//|       - {"artifact":"zeros","path":"/rows/11/0","equals":"(3, 3)"}
//|       - {"artifact":"zeros","path":"/rows/11/2","range":{"min":-7.8e-12,"max":7.8e-12}}
//|       - {"artifact":"zeros","path":"/rows/11/3","approx":{"value":7.79e-12,"rtol":0.01}}
//|       - {"artifact":"zeros","path":"/rows/0/4","approx":{"value":1.751e-3,"rtol":1e-3}}
//|       - {"artifact":"zeros","path":"/rows/1/4","approx":{"value":4.036e-5,"rtol":1e-3}}
//|       - {"artifact":"zeros","path":"/rows/2/4","approx":{"value":4.678e-6,"rtol":1e-3}}
//|       - {"artifact":"zeros","path":"/rows/9/4","approx":{"value":-1.245e-2,"rtol":1e-3}}
use scioxide_core::RealScalar;
use std::f64::consts::PI;

let zeros: Vec<Vec<f64>> =
    serde_json::from_value(modes["zeros"].clone()).map_err(|e| e.to_string())?;
let errors: Vec<Vec<f64>> =
    serde_json::from_value(modes["errors"].clone()).map_err(|e| e.to_string())?;
let orders = modes["max_order"].as_u64().ok_or("最大の次数がない")? as usize;
let mut rows = Vec::new();
for (nu, (row, error)) in zeros.iter().zip(&errors).enumerate().take(orders + 1) {
    for (index, (&j, &e)) in row.iter().zip(error).enumerate() {
        let m = index + 1;
        // 検算 1: べき級数 Σ t_k、t_k = (−1)^k (x/2)^{2k+ν} / (k! (k+ν)!) を f64 で足す。
        let half = j / 2.0;
        let mut term = RealScalar::powi(half, nu as i32);
        for k in 1..=nu {
            term /= k as f64;
        }
        let (mut sum, mut magnitude, mut k) = (term, term.abs(), 0.0_f64);
        while term.abs() > f64::EPSILON * magnitude * 1e-3 || k < half {
            k += 1.0;
            term *= -half * half / (k * (k + nu as f64));
            sum += term;
            magnitude += term.abs();
        }
        // 検算 2: McMahon の展開（DLMF 10.21.19 の 3 項）。
        let beta = (m as f64 + nu as f64 / 2.0 - 0.25) * PI;
        let mu = 4.0 * (nu * nu) as f64;
        let mcmahon = beta
            - (mu - 1.0) / (8.0 * beta)
            - 4.0 * (mu - 1.0) * (7.0 * mu - 31.0) / (3.0 * RealScalar::powi(8.0 * beta, 3));
        rows.push((format!("({nu}, {m})"), j, sum, f64::EPSILON * magnitude, j - mcmahon, e));
    }
}
// 検算 3: 交互性 j_{ν,m} < j_{ν+1,m} < j_{ν,m+1} の破れを数える。
let at = |nu: usize, m: usize| zeros.get(nu).and_then(|row| row.get(m)).copied();
let (mut pairs, mut violations) = (0_usize, 0_usize);
for nu in 0..=orders {
    for m in 0..zeros.get(nu).map_or(0, Vec::len) {
        let (Some(low), Some(next)) = (at(nu, m), at(nu + 1, m)) else {
            continue;
        };
        pairs += 1;
        let above = at(nu, m + 1).is_none_or(|high| next < high);
        if !(low < next && above) {
            violations += 1;
        }
    }
}
emit_table_with_columns!(
    serde_json::json!([
        { "key": "0", "label": "交互性の破れ [件]", "type": "integer" },
        { "key": "1", "label": "調べた組 [組]", "type": "integer" }
    ]),
    vec![(violations, pairs)],
    metadata = serde_json::json!({ "id": "checks" })
);
```

既定値（$\nu_{\max} = 3$、$M = 3$）の 12 個の零点では、べき級数で評価した $\lvert J_\nu(j_{\nu,m}) \rvert$ はどの零点でも丸めの目安 $\varepsilon A$ より小さい。
最大は $(3, 3)$ の $5.8 \times 10^{-13}$ で、そこでの $\varepsilon A$ は $7.8 \times 10^{-12}$ である。
級数の値は $x$ とともに大きくなるが、その大きさは桁落ちの目安 $\varepsilon A$ で説明でき、零点の位置と矛盾しない。
交互性は 12 組で調べ、破れは 0 件である。
McMahon の展開との差は同じ次数では番号とともに減り、$\nu = 0$ では $m = 1, 2, 3$ で $1.8 \times 10^{-3}$、$4.0 \times 10^{-5}$、$4.7 \times 10^{-6}$ となる。
前のセルで $M = 6$ にすると、$j_{0,6}$ との差は $1.3 \times 10^{-7}$ まで減る。
一方、同じ番号では差は次数とともに増え、$\nu_{\max} = 6$ では $j_{6,1}$ との差が $-0.105$ になる。
McMahon の展開は $\nu$ を固定して $m \to \infty$ とする展開なので、$m$ が $\nu$ に比べて小さい零点の検算には粗い参照値にしかならない。
$\nu_{\max} = 6$、$M = 6$ では、$j_{6,6} \approx 26.8$ での $\varepsilon A$ が $3.9 \times 10^{-6}$ まで増え、べき級数による検算の感度は落ちる。
このセルは入力を持たないので、確かめる範囲は前のセルの入力で変える。

## まとめ

円形膜の固有振動数は $J_\nu$ の $m$ 番目の零点で決まり、番号を取り違えると別の振動モードを答えてしまう。
`special_zeros_with_options` は、表と漸近展開の初期近似、または原点側からの符号の変化の数え上げで番号を決め、区間保護付きの Newton 法で絞り込んだ零点を元の関数で検査して返す。
零点を使う前に `SpecialZeroReport` の終了状態が成功であることを確かめ、部分的な結果では `completed()` までの先頭だけを使う。
結果は残差で検査した推定値で証明ではないので、べき級数のような別の評価、漸近展開、交互性のような独立な関係で確かめる。
Airy 関数、Kelvin 関数、誤差関数、Fresnel 積分の零点も、同じ `special_zeros_with_options` で族を変えて求められる。
