円管の圧力損失は Darcy–Weisbach の式 $\Delta p=f\,(L/D)\,\rho u^2/2$ で表せる。
ここで $f$ は Darcy 摩擦係数、$D$ は管径、$L$ は管の長さ、$\rho$ は流体の密度、$u$ は断面平均流速である。
Fanning 摩擦係数はこの $f$ の 4 分の 1 なので、二つの慣習を混ぜないようにする。
このページは十分に発達した円管の乱流に対する Colebrook 式を扱い、層流から乱流への遷移域（Reynolds 数 $\mathrm{Re}$ がおよそ 2300〜4000）は扱わない。

## 正の変数への変換

相対粗さ $\varepsilon_r=\varepsilon/D$（$\varepsilon$ は管壁の粗さの高さ）と $\mathrm{Re}$ に対し、$x=1/\sqrt f$ と置くと、Colebrook 式は

$$
g(x)=x+2\log_{10}\left(\frac{\varepsilon_r}{3.7}+\frac{2.51x}{\mathrm{Re}}\right)=0
$$

となる。
$x>0$ では

$$
g'(x)=1+\frac{2}{\ln10}\,\frac{2.51/\mathrm{Re}}{\varepsilon_r/3.7+2.51x/\mathrm{Re}}>1
$$

なので、$g$ は狭義単調増加で根は一つである。
このページの入力範囲（$5\times10^3\le\mathrm{Re}\le10^8$、$10^{-6}\le\varepsilon_r\le0.050$）では $g(1)<0<g(30)$ なので、固定した区間 $[1,30]$ が根を挟む。

$g'>1$ と平均値の定理から、近似解 $\hat x$ の位置の誤差は $|\hat x-x_*|\le|g(\hat x)|$ を満たす。
$f=x^{-2}$ なので、摩擦係数の相対誤差は一次近似で $2|\hat x-x_*|/x_*$ になる。
したがって残差 $g$ から、$x$ の誤差、$f$ の相対誤差の順に精度を見積もれる。
このページの入力範囲では $x$ はおよそ 3.7〜12.5 なので、$f$ の相対誤差の見積もり $2|g|/x$ は $|g|$ より小さい。

## 受理の規則と残差の尺度

区間法の既定の `ScalarRootOptions` は残差の大きさでは受理しない。
符号の異なる区間の幅が $4\varepsilon+4\varepsilon\max(|x_{\rm lo}|,|x_{\rm hi}|)$ 以下になるか、関数値がちょうど 0 になったときに受理し、終了理由は前者が `BracketTolerance`、後者が `ResidualTolerance` である。
ここで $\varepsilon$ は倍精度の計算機イプシロン $2.2\times10^{-16}$ である。
`with_residual_tolerance` で許容誤差 $\rho_a+\rho_r s$ を明示すると、残差だけによる受理が加わる。
絶対許容誤差 $\rho_a$ は関数値の単位（ここでは $x$ と同じ無次元量）で、相対許容誤差 $\rho_r$ は残差の尺度 $s$ に掛けて使う。

`with_residual_scale(s)` は、相対許容誤差の基準になる尺度 $s>0$ を関数値の単位で与える。
区間法ではこの設定だけで残差による受理も有効になり、許容誤差を明示しなければ $|g|\le\sqrt\varepsilon\,s$（$\sqrt\varepsilon\approx1.5\times10^{-8}$）で `ResidualTolerance` として止まる。
尺度を渡さない場合の基準 $s$ は、初期区間の両端の $|g|$ の大きいほうである。
有限でない尺度や正でない尺度は、コールバックを呼ぶ前に `InvalidInput` で拒否される。

この問題では $x$ の大きさそのものが自然な尺度になる。
$s=x_H$（下の Haaland 近似）とすると、$|g|\le\sqrt\varepsilon\,x_H$ から $x$ の相対誤差がおよそ $\sqrt\varepsilon$ 以下になり、$f$ の相対誤差は $3\times10^{-8}$ 程度に収まる。
Colebrook 式そのものが実験式であり、数 % の不確かさを持つので、工学的にはこの精度で十分である。

## 近似式と区間探索

Haaland の近似は

$$
x_H=-1.8\log_{10}\left[\left(\frac{\varepsilon_r}{3.7}\right)^{1.11}+\frac{6.9}{\mathrm{Re}}\right]
$$

である。
`find_bracket_with_options` はこの値を初期値とし、$g$ が単調増加であること（`BracketSearchDirection::Increasing`）と定義域 $x>0$ を受け取って、符号の変わる区間を探す。
単調増加を宣言すると、初期値での符号から根のある側だけへ区間を広げる。
単調性は呼び出し側の宣言であり、ソルバーは確かめない。
定義域が正の側だけなので、端点を拡大率（既定 2）で掛けるか割って動かす乗法的な拡大（`BracketExpansion::Multiplicative`）を使う。

比較には Swamee–Jain の近似 $f_{SJ}=0.25/[\log_{10}(\varepsilon_r/3.7+5.74/\mathrm{Re}^{0.9})]^2$ も使う。
二つの近似は経験式であり、求根の許容誤差を小さくしても近似式そのものの偏りは消えない。
近似式は初期化と比較に使い、最後は元の Colebrook 式を解く。

## Wright ω による閉形式

$c=\ln10/2$、$b=c\,\mathrm{Re}/2.51$、$A=b\,\varepsilon_r/3.7$ と置く。
Colebrook 式は $c\,x=-\ln(\varepsilon_r/3.7+2.51x/\mathrm{Re})$ と書けるので、$w=c\,x+A$ と置くと $\varepsilon_r/3.7+2.51x/\mathrm{Re}=w/b$ となり、

$$
w+\ln w=A+\ln b
$$

を満たす。
したがって $w=\omega(A+\ln b)$ である。
$\omega$ は Wright ω 関数で、$\omega+\ln\omega=z$ の解であり、scioxide-special の `wright_omega` で評価できる。
$x=(w-A)/c$ と計算すると、粗い管で Re が大きい場合に $w$ と $A$ がともに大きくなり、桁落ちが起こる。
同じ恒等式から得る $x=(\ln b-\ln w)/c$ は、この大きな値同士の減算を避ける。
閉形式と数値評価の関係は [Clamond の論文](https://arxiv.org/abs/0810.5564)にもある。

次のブロックは二つのセルが共有する定義である。
`colebrook_residual` が $g(x)$、`haaland` が $x_H$、`omega_closed_form` が二つの形の閉形式の $x$ に対応する。

```rust
//| id: rootfind-colebrook-model
//| kind: definitions
//| title: Colebrook 式の残差、Haaland の近似、Wright ω の閉形式
//| crates: [scioxide-core, scioxide-special]
use scioxide_core::{SciOxideError, RealScalar};

/// Colebrook 式の残差 g(x) = x + 2 log₁₀(ε_r/3.7 + 2.51x/Re)。x = 1/√f。
pub(crate) fn colebrook_residual(x: f64, re: f64, roughness: f64) -> f64 {
    x + 2.0 * RealScalar::log10(roughness / 3.7 + 2.51 * x / re)
}

/// Haaland の近似 x_H = −1.8 log₁₀[(ε_r/3.7)^1.11 + 6.9/Re]。
pub(crate) fn haaland(re: f64, roughness: f64) -> f64 {
    -1.8 * RealScalar::log10(RealScalar::powf(roughness / 3.7, 1.11) + 6.9 / re)
}

/// Wright ω による閉形式の x を (ln b − ln w)/c と (w − A)/c の二つの形で返す。
pub(crate) fn omega_closed_form(re: f64, roughness: f64) -> Result<(f64, f64), SciOxideError> {
    let c = core::f64::consts::LN_10 / 2.0;
    let b = c * re / 2.51;
    let a = b * roughness / 3.7;
    let w = scioxide_special::wright_omega(a + RealScalar::ln(b))?;
    Ok(((RealScalar::ln(b) - RealScalar::ln(w)) / c, (w - a) / c))
}
```

## 三つの区間法と受理の規則

次のセルは Re と $\varepsilon_r$ の常用対数、受理の規則を入力とする。
規則は既定（区間幅）、絶対許容誤差 $|g|\le10^{-12}$、残差の尺度 $s=x_H$ の三つから選ぶ。
`Brent`、`Toms748`、`Chandrupatla` を固定区間 $[1,30]$ で解き、`Brent` をもう一度 `find_bracket_with_options` の区間で解く。

```rust
let outcome = if accepted {
    Outcome::satisfied("四つの解がすべて受理の規則を満たした")
} else {
    Outcome::partial("受理の規則を満たす前に止まった解がある")
        .explanation("終了理由の列を見て、止まった解の値は推定値として扱う。")
};
emit_outcome!(
    outcome
        .status(statuses.join("、"))
        .diagnostic("関数評価の合計", evaluations as f64, None)
        .diagnostic("ω 解との最大の相対差", worst, None)
);
```

既定の $\mathrm{Re}=10^5$、$\varepsilon_r=10^{-3}$、既定の受理の規則では、四つの解がすべて $f=0.0221745359445$ に一致し、ω 解との相対差は $8\times10^{-16}$ 以下である。
`Brent` と `Toms748` は関数値がちょうど 0 になる点に当たって `ResidualTolerance` で止まり、`Chandrupatla` は区間幅の条件 `BracketTolerance` で止まる。
関数評価は固定区間で 7〜8 回、`find_bracket_with_options` の区間 $[3.37,6.75]$ から始めた `Brent` で 5 回である。
区間探索は $x_H=6.747$ と $x_H/2$ の 2 回の評価で符号の変化を見つけるので、探索を含めた合計は 7 回になる。

受理の規則を `残差 |g| ≤ 1e-12` にすると、評価回数は固定区間で 6〜7 回に減り、ω 解との相対差は最大 $1.7\times10^{-13}$（`Toms748`）に増える。
`残差の尺度 x_H` では受理の閾値が $\sqrt\varepsilon\,x_H\approx1.0\times10^{-7}$ になり、固定区間の `Brent` は 5 回の評価で残差 $5.9\times10^{-8}$ のまま止まる。
このときの相対差 $-1.7\times10^{-8}$ は、上の見積もり $2|g|/x\approx1.8\times10^{-8}$ と合う。
どの規則でも、求根の誤差は近似式の偏り（Haaland $-0.94\,\%$、Swamee–Jain $+0.76\,\%$）よりずっと小さい。

粗い管で Re が大きい $\mathrm{Re}=10^8$、$\varepsilon_r=0.050$ では、$A\approx6\times10^5$ に対して $w-A\approx4$ なので、桁落ちを含む形 $x=(w-A)/c$ の相対差が $-2.7\times10^{-11}$ に増える。
$x=(\ln b-\ln w)/c$ と区間法の解の差は $2.2\times10^{-16}$ 以下に保たれる。
この入力では Swamee–Jain の近似の誤差が $9\times10^{-6}$ まで小さくなり、Haaland の近似は $+0.20\,\%$ ずれる。

## Moody 線図

次のセルは相対粗さの異なる乱流の曲線（Re は $4\times10^3$〜$10^8$）と、層流の理論式 $f=64/\mathrm{Re}$（Re は 500〜2300、破線）を両対数の Moody 線図に描く。
曲線の各点は固定区間 $[1,30]$ の `Brent` で、既定の受理の規則で解き、受理されなかった点があればセルをエラーで止める。
入力の Re と $\varepsilon_r$ は、その粗さの曲線を加え、選んだ Re と摩擦係数の位置を縦線と横線で示すために使う。
遷移域の 2300〜4000 は描かない。

```rust
//| id: rootfind-colebrook-moody
//| ref: rootfind-colebrook-moody
//| title: Moody 線図と選んだ流れの位置
//| run: reactive
//| uses: [rootfind-colebrook-model]
//| crates: [scioxide-core, scioxide-rootfind]
//| inputs:
//|   reynolds_exponent: {"type":"range","label":"Re の常用対数 [-]","min":3.7,"max":8,"step":0.05,"value":5}
//|   roughness_exponent: {"type":"range","label":"相対粗さ ε/D の常用対数 [-]","min":-6,"max":-1.3,"step":0.05,"value":-3}
//| cases:
//|   - {"id":"smooth-high-re","label":"Re = 10⁸、ε/D = 10⁻⁶（滑らかな管）","description":"滑らかな管の曲線の右端に当たり、選んだ流れの摩擦係数は f = 0.0064 である。","inputs":{"reynolds_exponent":8,"roughness_exponent":-6}}
//|   - {"id":"rough-high-re","label":"Re = 10⁸、ε/D = 0.050（完全粗面）","description":"粗い管の曲線が水平になる領域で、選んだ流れの摩擦係数は f ≈ 0.072 である。","inputs":{"reynolds_exponent":8,"roughness_exponent":-1.3}}

//|   - case: default

let options = ScalarRootOptions::default();
// Colebrook 式を x = 1/√f について解き、f = x⁻² を返す
let friction = |re: f64, rough: f64| -> Result<f64, String> {
    let colebrook = ScalarFn::new(|x: f64| Ok(colebrook_residual(x, re, rough)));
    let result = Brent
        .solve(&colebrook, interval, &options)
        .map_err(|e| e.to_string())?;
    if !result.is_success() {
        return Err(format!("Re = {re} の摩擦係数が未収束: {}", result.termination()));

    "points": laminar,
    "style": { "lineType": "dashed" }

        ]
    }),

);
```

滑らかな管（$\varepsilon_r=10^{-6}$）の曲線は Re とともに下がり続け、$\mathrm{Re}=10^8$ で $f=0.0064$ になる。
粗い管の曲線は Re が大きい側で水平に近づき、$\varepsilon_r=0.05$ では $f\approx0.072$ で Re によらなくなる（完全粗面の領域）。
完全粗面の値は Colebrook 式で $2.51x/\mathrm{Re}\to0$ とした $x=-2\log_{10}(\varepsilon_r/3.7)$ で、$\varepsilon_r=0.05$ では $f=0.0716$ である。
層流の破線は $\mathrm{Re}=2300$ で $f=0.028$ であり、乱流の曲線とは遷移域を挟んで離れている。
選んだ $\varepsilon_r$ の曲線は、固定した粗さの曲線と重なることがある。
縦軸と横軸は対数軸で、正の値の Re と $f$ をそのまま渡している。

## まとめ

Colebrook 式は $x=1/\sqrt f$ に変換すると $g'>1$ の単調な一変数方程式になり、固定区間 $[1,30]$ がこのページの全入力で根を挟む。
$|g|$ は $x$ の誤差の上界になり、$f$ の相対誤差はその $2/x$ 倍で見積もれる。
区間法の既定は区間幅で受理し、`with_residual_tolerance` や `with_residual_scale` を与えると残差だけによる受理が加わるので、必要な精度に合わせて評価回数を減らせる。
`with_residual_scale` に $x$ の大きさ（ここでは $x_H$）を渡すと、$f$ を相対 $3\times10^{-8}$ 程度で求め、既定より少ない評価で止まる。
Wright ω の閉形式は大きな値同士の減算を避ける形 $x=(\ln b-\ln w)/c$ で評価すると、独立な検算として使える。
