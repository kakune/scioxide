半導体の量子井戸のように、粒子が有限の深さの井戸に閉じ込められると、エネルギーは離散的な値（準位）しか取らない。
幅 $L$ の井戸を $|x|<L/2$ に置き、内側のポテンシャルを 0、外側を $V_0>0$ とする。
粒子の有効質量 $m^*$ は内外で同じと仮定する（GaAs の伝導電子なら $m^*=0.067\,m_e$）。
定常 Schrödinger 方程式は

$$
-\frac{\hbar^2}{2m^*}\psi''(x)+V(x)\psi(x)=E\psi(x)
$$

で、束縛状態は $0<E<V_0$ を満たす。
外側では波動関数が指数的に減衰し、内側では三角関数になる。
ポテンシャルが左右対称なので、状態を偶関数と奇関数に分けられる。

## 接続条件と極の除去

内側の波数 $k=\sqrt{2m^*E}/\hbar$ を使って、$z=kL/2$、$z_0=(L/2)\sqrt{2m^*V_0}/\hbar$、$q=\sqrt{z_0^2-z^2}$ と置く。
$q$ は外側の減衰定数 $\kappa=\sqrt{2m^*(V_0-E)}/\hbar$ に $L/2$ を掛けた量である。
井戸の端で $\psi$ と $\psi'$ を連続にすると、偶状態は $z\tan z=q$、奇状態は $-z\cot z=q$ を満たす。
この形のまま符号の変化を探すと、$\tan$ や $\cot$ の極をまたぐ符号の変化を根と取り違える。
求根には、両辺に $\cos z$ または $\sin z$ を掛けた極のない式を使う。

$$
f_{\rm even}(z)=z\sin z-q\cos z,\qquad
f_{\rm odd}(z)=z\cos z+q\sin z
$$

偶状態の解は $\tan z\ge0$ の区間、奇状態の解は $\cot z\le0$ の区間にある。
そこで第 $k$ 区間を $[k\pi/2,\min((k+1)\pi/2,z_0)]$（$k=0,1,\dots$）とし、偶数の $k$ では偶状態、奇数の $k$ では奇状態を解く。
各区間の両端で $f$ の符号は逆になる。
さらに区間の内側では $z\tan z-q$（または $-z\cot z-q$）が狭義単調増加で、$f$ はそれに符号の一定な $\cos z$（または $-\sin z$）を掛けたものなので、区間ごとにちょうど一つの束縛状態がある。
したがって束縛状態の数は $\lceil2z_0/\pi\rceil$ である。

$z=z_0$ に達した解は減衰定数が 0 で正規化できないので、束縛状態に数えない。
$2z_0/\pi$ が整数になる深さを少し越えると、新しい状態が $E\approx V_0$ に現れる。
原点 $z=0$ で奇状態の式が 0 になるのは $\psi\equiv0$ に対応する自明な解であり、奇状態の区間は $z=\pi/2$ から始める。

エネルギーは $E=V_0(z/z_0)^2$ で求める。
井戸を深くすると $z\to n\pi/2$（$n=k+1$）となり、無限に深い井戸の値

$$
E_n^\infty=\frac{\hbar^2\pi^2n^2}{2m^*L^2}
$$

に近づく。
深い井戸の低い準位では $q\approx z_0$ であり、$z=n\pi/2$ の近くで $\tan z\approx-1/(z-n\pi/2)$（偶状態）と近似できるので、$z_n\approx(n\pi/2)\,z_0/(z_0+1)$ となる。
奇状態も $-\cot z$ について同じ近似が成り立つ。
したがって $E_n/E_n^\infty\approx[z_0/(z_0+1)]^2$ であり、無限井戸との相対差は $2/z_0\propto V_0^{-1/2}$ でゆっくり小さくなる。

次のブロックは三つのセルが共有する定義である。
`HBAR2_OVER_2ME` が換算定数 $\hbar^2/(2m_e)$、`matching_condition` が $f_{\rm even}$ と $f_{\rm odd}$、`solve_level` が第 $k$ 区間の求根に対応する。
換算定数は CODATA の値 $\hbar^2/(2m_e)=0.0380998212\,\mathrm{eV\,nm^2}$ を丸めたものである。

```rust
//| id: rootfind-finite-well-model
//| kind: definitions
//| title: 極のない接続条件と区間ごとの求根
//| crates: [scioxide-core, scioxide-rootfind]
use scioxide_core::{SciOxideError, Interval, RealScalar};
use scioxide_rootfind::{Brent, RootResult, ScalarFn, ScalarRootOptions, ScalarRootSolver};

/// ħ²/(2mₑ) [eV nm²]。
pub(crate) const HBAR2_OVER_2ME: f64 = 0.0380998212;

/// 第 k 区間の接続条件。偶数 k は f_even = z sin z − q cos z、奇数 k は f_odd = z cos z + q sin z。
pub(crate) fn matching_condition(z: f64, z0: f64, k: usize) -> f64 {
    // q = √(z₀² − z²) を (z₀ − z)(z₀ + z) で求め、z → z₀ での桁落ちを避ける
    let q = RealScalar::sqrt((z0 - z) * (z0 + z));
    let (sin, cos) = RealScalar::sin_cos(z);
    if k % 2 == 0 {
        z * sin - q * cos
    } else {
        z * cos + q * sin
    }
}

/// 区間 [kπ/2, min((k+1)π/2, z₀)] を既定の設定の Brent 法で解く。
pub(crate) fn solve_level(z0: f64, k: usize) -> Result<RootResult<f64>, SciOxideError> {
    let lower = k as f64 * core::f64::consts::FRAC_PI_2;
    let upper = RealScalar::min((k + 1) as f64 * core::f64::consts::FRAC_PI_2, z0);
    let condition = ScalarFn::new(|z: f64| Ok(matching_condition(z, z0, k)));
    Brent.solve(&condition, Interval::new(lower, upper)?, &ScalarRootOptions::default())
}
```

## 区間ごとの求根と無限井戸への収束

次のセルは井戸の深さ $V_0$ [eV]、幅 $L$ [nm]、有効質量の比 $m^*/m_e$ を入力とし、各区間を `Brent` で解く。
受理の規則は既定の `ScalarRootOptions` で、区間幅が数 ulp まで縮むか、関数値がちょうど 0 になると止まる。

一つ目の表は求根の結果（根 $z$、終了理由、最終的な区間の幅、関数評価回数）、二つ目の表はエネルギー、閾値までの余裕 $V_0-E$、無限井戸の値との比である。
三つ目の表は同じ $L$ と $m^*$ で深さを 1、4、16、…、1024 倍にしたときの基底状態の $E_1/E_1^\infty$ を、上の近似 $[z_0/(z_0+1)]^2$ と比べる。
すべての準位が `is_success()` を満たせば、セルの最後の判定は satisfied になる。
このセルは井戸のパラメータ、$z_0$、根、エネルギーを書き出し、後の二つのセルはそれを受け取る。

三つの根はどれも区間幅の条件 `BracketTolerance` で止まり、最終的な区間の幅は $4.4\times10^{-16}$ 以下、関数評価は 8〜10 回である。
エネルギーは 34.2、132.6、271.5 meV で、無限井戸の値の 0.61、0.59、0.54 倍である。
上の準位ほど閾値に近く（第 3 準位は $V_0-E=28.5$ meV）、外側へのしみ出しが大きいので、無限井戸との比が小さい。

深さを変える三つ目の表では、$V_0$ を 4 倍するごとに $z_0$ が 2 倍になり、$1-E_1/E_1^\infty$ は 0.39 から 0.017 までほぼ半分ずつ小さくなる。
近似 $1-[z_0/(z_0+1)]^2$ との差は $V_0=0.3$ eV で 0.005、$V_0=307$ eV で $5\times10^{-7}$ であり、深い井戸ほど近似がよく合う。
これは無限井戸の極限への収束が $V_0^{-1/2}$ の速さであることを示している。
$V_0=1$ eV にすると準位は 5 個に増え、第 1・第 2 準位は関数値がちょうど 0 になって `ResidualTolerance` で止まる。
$V_0=0.02$ eV では $z_0=0.94<\pi/2$ となり、偶の基底状態だけが残る。

## 差分化したハミルトニアンによる検算

求根とは別の方法として、Schrödinger 方程式を格子幅 $h$ の中心差分で離散化し、対称三重対角行列の固有値を求める。
計算領域は井戸を中心とするおよそ全幅 $wL$（$w=4$ または 8）の区間で、最初と最後の格子点のすぐ外側で $\psi=0$ とする。
格子点 $x_i$ は $h/2$ だけずらして置き、井戸の端 $\pm L/2$ が格子点の中間に来るようにする。
行列の対角成分は $2c/h^2+V(x_i)$、隣接成分は $-c/h^2$（$c=\hbar^2/2m^*$）である。

この近似には二つの誤差がある。
一つは格子幅による誤差で、中心差分の打ち切り誤差は $O(h^2)$ である。
ポテンシャルの段差を格子点の中間に置くと、この例では段差を含めても観測次数がほぼ 2 になる（下の表で確かめる）。
もう一つは計算領域を有限にした誤差で、外側の減衰の長さ $1/\kappa=L/(2q)$ に比べて領域が十分広くなければ固有値が上にずれる。
後者は $h$ を細かくしても減らないので、まず領域の幅を 4 倍から 8 倍に変えて値が動かないことを確かめてから、格子を細かくする。

次のセルは一つ目のセルが書き出した準位を基準に、$h=L/N$ と $h/2$ の差分固有値の誤差と、観測次数 $p=\log_2(e_h/e_{h/2})$ を出す。
$N$ は井戸の幅あたりの格子数である。
誤差の比が負のとき（$h$ と $h/2$ で誤差の符号が変わるとき）は、観測次数を定義できないので空欄にする。
固有値は scioxide-linalg の `HermitianEigenvaluesResult::tridiagonal_with_options` で下から最大 6 個を求める。

```rust
//|       - {"artifact":"orders","path":"/rows/2/5","range":{"max":0}}
//|   - case: wide-domain
//|     expect:
//|       - {"artifact":"orders","path":"/rows/2/6","approx":{"value":2.01,"atol":5e-3}}
//|   - case: fine-grid
//|     expect:
//|       - {"artifact":"orders","path":"/rows/2/4","range":{"max":0}}
//|       - {"artifact":"orders","path":"/rows/2/5","range":{"min":0}}
//|       - {"artifact":"orders","path":"/rows/2/6","equals":null}
use scioxide_core::RealScalar;
use scioxide_linalg::{EigenIndexRange, HermitianEigenOptions, HermitianEigenvaluesResult};

let read = |name: &str| levels[name].as_f64().ok_or(format!("{name} がない"));
let (depth, width, kinetic) = (read("depth")?, read("width")?, read("kinetic")?);
let reference: Vec<f64> =
    serde_json::from_value(levels["energies"].clone()).map_err(|e| e.to_string())?;
let extent: usize = if extent == "4" { 4 } else { 8 };
let grid = grid as usize;
// 比べる準位は下から最大 6 個
let count = reference.len().min(6);
// 独立な検算: 全幅 wL の領域を幅 L あたり per_width 点で中心差分化した固有値 [eV]
let finite_difference = |per_width: usize| -> Result<Vec<f64>, String> {
    let n = extent * per_width;
    let h = width / per_width as f64;
    let t = kinetic / (h * h);
    // x_i = (i + 1/2 − n/2) h なので、井戸の端 ±L/2 は格子点の中間に来る
    let diagonal: Vec<_> = (0..n)
        .map(|i| {
            let x = (i as f64 + 0.5 - n as f64 / 2.0) * h;
            let inside = -0.5 * width < x && x < 0.5 * width;
            let potential = if inside { 0.0 } else { depth };
            2.0 * t + potential
        })
        .collect();
    let off_diagonal = vec![-t; n - 1];
    let range = EigenIndexRange::new(0, count).map_err(|e| e.to_string())?;
    let eigen_options = HermitianEigenOptions::default().with_index_range(range);
    let result = HermitianEigenvaluesResult::tridiagonal_with_options(
        &diagonal,
        &off_diagonal,
        &eigen_options,
    )
    .map_err(|e| e.to_string())?;
    Ok(result.eigenvalues().to_vec())
};
let coarse = finite_difference(grid)?;
let fine = finite_difference(2 * grid)?;
let mut rows = Vec::new();
for k in 0..count {
    let error_h = coarse[k] - reference[k];
    let error_half = fine[k] - reference[k];
    // 誤差の比が正のときだけ観測次数を定義する
    let ratio = error_h / error_half;
    let order = (ratio > 0.0).then(|| RealScalar::log2(ratio));
    rows.push((
        k + 1,
        reference[k] * 1e3,
        coarse[k] * 1e3,
        fine[k] * 1e3,
        error_h * 1e3,
        error_half * 1e3,
        order,
    ));
}
let fixed3 = serde_json::json!({ "fractionDigits": 3 });
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let fixed2 = serde_json::json!({ "fractionDigits": 2 });
let columns = serde_json::json!([
    { "key": "0", "label": "準位 n [-]", "type": "integer" },
    { "key": "1", "label": "求根 E [meV]", "type": "number", "format": fixed3 },
    { "key": "2", "label": "差分 h [meV]", "type": "number", "format": fixed3 },
    { "key": "3", "label": "差分 h/2 [meV]", "type": "number", "format": fixed3 },
    { "key": "4", "label": "誤差 e_h [meV]", "type": "number", "format": sci3 },
    { "key": "5", "label": "誤差 e_h/2 [meV]", "type": "number", "format": sci3 },
    { "key": "6", "label": "観測次数 p [-]", "type": "number", "format": fixed2, "nullText": "定義できない" }
]);
emit_table_with_columns!(columns, rows, metadata = serde_json::json!({ "id": "orders" }));
```

既定の $N=32$、$w=4$ では、第 1・第 2 準位の誤差が $h$ で $-0.10$、$-0.44$ meV、$h/2$ で $-0.025$、$-0.11$ meV になり、観測次数は 2.00 である。
差分固有値は求根の値より低く、格子を細かくすると下から近づく。
中心差分は $\sin$ 型の波の 2 階微分の大きさを $(2-2\cos kh)/h^2<k^2$ と小さく見積もるので、固有値が下にずれる。
第 3 準位の観測次数は 2.45 で 2 からずれるが、$w=8$ にすると 2.01 になる。
閾値に近い第 3 準位は減衰が遅く、全幅 $4L$ では領域を切り詰めた誤差が無視できないからである。
$N=64$、$w=4$ では第 3 準位の誤差の符号が $h$ と $h/2$ で変わり、観測次数を定義できない。

一つ目のセルを浅い井戸 $V_0=0.02$ eV にすると、$w=4$ の誤差が $+0.32$ meV で $h$ によらず、観測次数はほぼ 0 になる。
差分固有値が求根の値より高いのは、領域の端の $\psi=0$ が状態を押し込めているからであり、$w=8$ にすると誤差は $10^{-3}$ meV の程度まで下がる。
$L=1$ nm、$V_0=0.3$ eV の唯一の準位は減衰の長さが約 4 nm あり、$w=8$ でも領域が足りずに誤差が 37 meV 残る。
このように、観測次数が 2 から外れるときは格子より先に領域の幅を疑う。

## 図による解法

接続条件は $z$ の関数として左辺 $z\tan z$（偶）、$-z\cot z$（奇）と右辺 $q=\sqrt{z_0^2-z^2}$ の交点として図に描ける。
右辺は半径 $z_0$ の円の四分の一であり、$z_0$ を大きくする（井戸を深く、広く、粒子を重くする）と円が広がって交点が増える。
次のセルは一つ目のセルが書き出した $z_0$ と根を受け取り、各区間の左辺の枝を実線、円弧を破線で描いて、根を記号で重ねる。
枝は区間ごとに別の系列にして、極をまたぐ線を描かないようにする。

```rust
//| id: rootfind-finite-well-graphical
//| ref: rootfind-finite-well-graphical
//| title: 接続条件の両辺の交点として束縛準位を図に示す
//| run: reactive
//| crates: [scioxide-core]
//| dependsOn:
//|   levels: rootfind-finite-well-levels
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"graphical","path":"/spec/layers/3/id","equals":"arc"}
//|       - {"artifact":"graphical","path":"/spec/layers/4/id","equals":"roots"}
//|       - {"artifact":"graphical","path":"/spec/layers/4/points/0/0","range":{"min":0,"max":1.5708}}
//|       - {"artifact":"graphical","path":"/spec/layers/4/points/1/0","range":{"min":1.5707,"max":3.1416}}
//|       - {"artifact":"graphical","path":"/spec/layers/4/points/2/0","range":{"min":3.1415,"max":3.6317}}
use core::f64::consts::FRAC_PI_2;
use scioxide_core::RealScalar;

let z0 = levels["z0"].as_f64().ok_or("z0 がない")?;
let roots: Vec<f64> = serde_json::from_value(levels["roots"].clone()).map_err(|e| e.to_string())?;
let circle = |z: f64| RealScalar::sqrt((z0 - z) * (z0 + z));
let mut layers = Vec::new();
for k in 0..roots.len() {
    let left = k as f64 * FRAC_PI_2;
    let right = RealScalar::min((k + 1) as f64 * FRAC_PI_2, z0);
    let even = k % 2 == 0;
    // 左辺の枝: 偶状態は z tan z、奇状態は −z cot z。区間の内点だけを描く
    let branch: Vec<_> = (1..60)
        .map(|j| {
            let z = left + (right - left) * j as f64 / 60.0;
            let tan = RealScalar::tan(z);
            [z, if even { z * tan } else { -z / tan }]
        })
        .collect();
    let name = format!("{}状態の枝 n = {}", if even { "偶" } else { "奇" }, k + 1);
    layers.push(serde_json::json!({
        "id": format!("branch-{k}"),
        "kind": "line",
        "name": name,
        "points": branch
    }));
}
let arc: Vec<_> = (0..=120)
    .map(|j| {
        let z = z0 * j as f64 / 120.0;
        [z, circle(z)]
    })
    .collect();
let marks: Vec<_> = roots.iter().map(|&z| [z, circle(z)]).collect();
layers.push(serde_json::json!({
    "id": "arc",
    "kind": "line",
    "name": "右辺 √(z₀² − z²)",
    "style": { "lineType": "dashed" },
    "points": arc
}));
layers.push(serde_json::json!({
    "id": "roots",
    "kind": "scatter",
    "name": "求めた根",
    "points": marks
}));
emit_chart!(
    serde_json::json!({
        "kind": "xy",
        "xLabel": "z = kL/2 [-]",
        "yLabel": "接続条件の両辺 [-]",
        "xMin": 0.0,
        "xMax": z0 * 1.05,
        "yMin": 0.0,
        "yMax": z0 * 1.1,
        "layers": layers
    }),
    metadata = serde_json::json!({ "id": "graphical" })
);
```

既定の入力では円弧が三つの枝と交わり、記号で示した根が交点に重なる。
一つ目の枝（偶）は $z\to\pi/2$ で発散し、二つ目の枝（奇）は $z=\pi/2$ の 0 から $z\to\pi$ で発散する。
三つ目の枝は $z_0=3.63<3\pi/2$ で打ち切られるので、極に達する前に円弧と交わる。
一つ目のセルの $V_0$ を下げて $z_0<\pi/2$ にすると、円弧は最初の枝としか交わらず、偶の基底状態だけが残る。
一つ目の枝は $z=0$ で 0 から始まって発散するので、$z_0>0$ である限り円弧と必ず交わる。
したがって一次元の対称な井戸では、どんなに浅くても偶の基底状態が一つは存在する。

## まとめ

有限井戸の接続条件は $\tan$ や $\cot$ の極を掛けて消した $f_{\rm even}$、$f_{\rm odd}$ にすると、区間 $[k\pi/2,\min((k+1)\pi/2,z_0)]$ ごとに符号の変化をちょうど一つ持つ。
束縛状態の数 $\lceil2z_0/\pi\rceil$ だけ区間を作って `Brent` で解けば、根の見落としも重複もない。
無限井戸との相対差はおよそ $2/z_0\propto V_0^{-1/2}$ でしか小さくならないので、深い井戸でも無限井戸の公式は粗い近似である。
差分固有値による検算では、まず計算領域の幅を変えて値が動かないことを確かめ、そのうえで $h$ と $h/2$ の観測次数が 2 に近いことを確かめる。
