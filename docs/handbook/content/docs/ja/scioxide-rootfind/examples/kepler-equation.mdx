惑星や人工衛星の楕円軌道では、近点を通過してからの時間に比例して平均近点角 $M$ が増える。
軌道上の位置は離心近点角 $E$ で表すと簡単な式になるが、$E$ は一定の速さでは増えない。
両者を結ぶ Kepler 方程式は、離心率 $0\le e<1$ について

$$
M=E-e\sin E
$$

である。
角度の単位は rad とし、一周分の $0\le M\le2\pi$ を扱う。
焦点を原点、近点の方向を $x$ 軸に取り、半長軸 $a$ で割った軌道面の座標と中心天体からの距離は

$$
\frac{x}{a}=\cos E-e,\qquad
\frac{y}{a}=\sqrt{1-e^2}\sin E,\qquad
\frac r a=1-e\cos E
$$

となる。
真近点角 $\nu=\operatorname{atan2}(y,x)$ は、焦点から見た近点方向からの実際の偏角である。
$M$ から $E$ を求めれば、時刻から位置が決まる。

## 根の一意性と誤差の上界

$f(E)=E-e\sin E-M$ とすると

$$
f'(E)=1-e\cos E\ge1-e>0,\qquad f''(E)=e\sin E
$$

である。
$f$ は狭義単調増加なので、根 $E_*$ は一つしかない。
$f(0)=-M\le0$、$f(2\pi)=2\pi-M\ge0$ なので、区間 $[0,2\pi]$ が根を挟む（$M=0$ と $M=2\pi$ では端点が根になる）。
$|E_*-M|=e|\sin E_*|\le e$ から、より狭い $[M-e,M+e]$ も使える。

平均値の定理から、近似解 $\widehat E$ について

$$
|\widehat E-E_*|=\frac{|f(\widehat E)|}{f'(\xi)}\le\frac{|f(\widehat E)|}{1-e}
$$

が成り立つ（$\xi$ は $\widehat E$ と $E_*$ の間の点）。
これは厳密な関数値に対する上界である。
浮動小数点で計算した $f$ には単位丸め誤差 $u=2^{-53}\approx1.1\times10^{-16}$ を使って $u\,(|E|+M)$ 程度の丸め誤差が含まれる。
そのため $E\approx2$ rad では $10^{-15}$ より小さい残差の違いには意味がない。
計算した残差に当てはめた上界も、証明付きの誤差限界ではない。

同じ導関数 $f'(E_*)$ は問題の条件数も決める。
$M$ が $\delta M$ だけずれると、根は $\delta E\approx\delta M/f'(E_*)$ だけずれる。
$e\to1$ では近点付近（$M\approx0$）で $f'(E_*)=1-e\cos E_*$ が $1-e$ 程度まで小さくなり、残差が同じでも角度の誤差が大きくなる。

次のブロックは、このページの三つのセルが共有する定義である。
`Kepler` は $f$、$f'$、$f''$ の解析式を `ScalarFunction` として与え、`full_turn` は根を挟む区間 $[0,2\pi]$ を作る。
`reference_solve` は比較に使わない `Bisection` を既定の停止判定で進め、成功した場合だけ結果を返す。
既定の `ScalarRootOptions` では、区間法は残差だけでは受理せず、区間幅が $4\varepsilon+4\varepsilon\max(|E_{\rm lo}|,|E_{\rm hi}|)$ 以下になるまで二分を続ける（$\varepsilon=2^{-52}$ は倍精度の機械イプシロン）。
$[0,2\pi]$ の二分では約 52 回でこの幅に達し、反復回数の上限（既定値 100 回）には届かない。

```rust
//| id: rootfind-kepler-model
//| kind: definitions
//| title: Kepler 方程式の関数と二分法の参照解
//| crates: [scioxide-core, scioxide-rootfind]
use scioxide_core::{SciOxideError, Interval, RealScalar};
use scioxide_rootfind::{Bisection, RootResult, ScalarFunction, ScalarRootOptions, ScalarRootSolver};

/// f(E) = E − e sin E − M と、その解析的な一階・二階導関数。
pub(crate) struct Kepler {
    pub(crate) eccentricity: f64,
    pub(crate) mean_anomaly: f64,
}

impl ScalarFunction<f64> for Kepler {
    fn eval(&self, x: f64) -> Result<f64, SciOxideError> {
        Ok(x - self.eccentricity * RealScalar::sin(x) - self.mean_anomaly)
    }

    fn derivative(&self, x: f64) -> Result<Option<f64>, SciOxideError> {
        Ok(Some(1.0 - self.eccentricity * RealScalar::cos(x)))
    }

    fn second_derivative(&self, x: f64) -> Result<Option<f64>, SciOxideError> {
        Ok(Some(self.eccentricity * RealScalar::sin(x)))
    }
}

/// f(0) = −M ≤ 0 ≤ f(2π) = 2π − M なので、[0, 2π] が根を挟む。
pub(crate) fn full_turn() -> Result<Interval<f64>, String> {
    Interval::new(0.0, core::f64::consts::TAU).map_err(|e| e.to_string())
}

/// 参照解: 既定の停止判定（区間幅が数 ulp）まで進めた二分法。成功した場合だけ返す。
pub(crate) fn reference_solve(
    eccentricity: f64,
    mean_anomaly: f64,
) -> Result<RootResult<f64>, String> {
    let function = Kepler {
        eccentricity,
        mean_anomaly,
    };
    let result = Bisection
        .solve(&function, full_turn()?, &ScalarRootOptions::default())
        .map_err(|e| e.to_string())?;
    if result.is_success() {
        Ok(result)
    } else {
        Err(format!("参照解の二分法が {} で止まった", result.termination()))
    }
}
```

## 初期値の規則

Newton 法は $E_{k+1}=E_k-f(E_k)/f'(E_k)$、Halley 法は二階導関数も使って

$$
E_{k+1}=E_k-\frac{2f(E_k)f'(E_k)}{2f'(E_k)^2-f(E_k)f''(E_k)}
$$

と進める。
単純根の近くでは、Newton 法は 2 次、Halley 法は 3 次で収束する。
どちらも区間を持たないので、収束するかどうかは初期値 $E_0$ で決まる。

$E_0=\pi$ から始めた Newton 法は、すべての $0\le e<1$ と $M$ で収束する。
$M<\pi$ のとき $f(\pi)=\pi-M>0$ なので根は $\pi$ より左にあり、$[0,\pi]$ では $f''=e\sin E\ge0$ だから $f$ は凸である。
凸な増加関数の接線はグラフより下にあるので、根の右側から始めた反復は根を越えずに単調に減り、根に収束する。
$M>\pi$ では $[\pi,2\pi]$ で $f$ が凹になり、左右を入れ替えた同じ議論が成り立つ。
$M=\pi$ では $E_0=\pi$ がそのまま根である。

$E_0=M$ は円軌道（$e=0$）では厳密な根であり、小さい $e$ では良い初期値である。
しかし $0<M<\pi$ では $f(M)=-e\sin M<0$ なので根の左側から始まり、凸性から最初の一歩で根を越えて右へ飛ぶ。
一歩の長さは $e\sin M/(1-e\cos M)$ で、$e\to1$、$M\to0$ では分母が小さくなり、凹の区間 $(\pi,2\pi)$ や $2\pi$ の外まで飛ぶことがある。
そうなると上の単調性の議論は使えず、反復の回数が増える。

安全化 Newton 法（`SafeguardedNewton`）は、初期値に加えて符号の異なる区間を受け取り、評価のたびに区間を縮める。
Newton の更新は、区間の内側に落ち、しかも長さが二つ前の更新の半分以下のときだけ採用し、そうでなければ区間を二分する。
`Brent`、`Toms748`、`Chandrupatla` は区間 $[0,2\pi]$ と関数値だけを使い、導関数を必要としない。

## 六手法の比較

次のセルは離心率 $e$、平均近点角 $M$ [rad]、初期値の規則（$E_0=M$ または $\pi$）を入力として、六つの方法で同じ $E_*$ を求める。
六手法は `ScalarRootMethod` で選び、同じ `ScalarRootOptions` を渡す。
停止の条件は残差 $|f|\le10^{-12}$ rad か、区間幅または更新幅が $10^{-12}$ rad 以下になることである。
`with_residual_tolerance` で明示した許容誤差は開いた方法にも区間法にも有効で、残差の条件だけで受理できるようにする。
開いた方法の更新幅による受理（`StepTolerance`）には、残差が初期の $|f|$ の $\sqrt{\varepsilon}$ 倍以下に下がっていることも必要である。

表の最初の行は定義のブロックの二分法による参照解で、終了理由と評価回数も示す。
表の列は終了理由、求めた $E$、残差 $f(E)$、参照解との差、残差から得る上界 $|f|/(1-e)$、関数・一階導関数・二階導関数の評価回数である。
評価回数は `RootResult::counts` の `EvaluationRole` ごとの値で、計算時間は比較しない。
導関数一回と関数値一回の計算コストが同じだとは解釈しない。

Newton 法は関数 6 回と一階導関数 5 回、Halley 法は関数 4 回と一階・二階導関数 3 回ずつ、安全化 Newton 法は関数 8 回と一階導関数 5 回である。
区間法の三つは関数だけを 9〜10 回評価する。
参照解との差は Brent 法の $-6.3\times10^{-14}$ rad が最大で、残差 $-7.1\times10^{-14}$ rad から得る上界 $1.8\times10^{-13}$ rad の内側にある。
ほかの方法の差は $4.4\times10^{-16}$ rad 以下で、二分法の参照解とは数 ulp しか違わない。
Brent 法だけが差を残すのは、最後の補間点で残差が $7.1\times10^{-14}$ rad と許容誤差 $10^{-12}$ rad を下回り、そこで止まったからである。
ほかの方法は最後の一歩で残差が丸めの水準（$2.2\times10^{-16}$ rad）まで下がってから止まる。

$e=0.99$、$M=0.1$ rad、$E_0=M$ にすると、Newton 法の最初の一歩は $M+e\sin M/(1-e\cos M)\approx6.7$ rad まで飛び、$2\pi$ を越える。
Newton 法は関数 16 回と一階導関数 15 回、Halley 法は関数 14 回と一・二階導関数 13 回ずつに増える。
初期値を $\pi$ に変えると[初期値の規則](#初期値の規則)で示した単調な収束になり、Newton 法は 8 回と 7 回、Halley 法は 6 回と 5 回ずつに減る。
区間法の三つと二分法は初期値を使わないので、初期値を変えても表の値は変わらない。
この入力では $f'(E_*)\approx0.33$ なので、Chandrupatla 法の参照解との差 $-1.8\times10^{-13}$ rad は、残差 $-5.9\times10^{-14}$ rad の約 3 倍になる。

## 離心率による評価回数の変化

次のセルは $M$ と初期値の規則を固定し、$e=0,0.01,\dots,0.99$ の 100 通りで六手法を解き、評価回数の合計（関数、一階導関数、二階導関数の和）を記号で描く。

合計は役割の異なる呼び出しを同じ重みで足した値であり、計算コストの比較ではない。
Kepler 方程式では $f'$ と $f''$ が $f$ と同じ $\sin E$、$\cos E$ から作れるので、導関数一回の追加の計算は関数値より小さい。
ただし `ScalarFunction` の三つのメソッド（`eval`、`derivative`、`second_derivative`）は別々に呼ばれ、表と図の回数はその呼び出しを数えている。

## Fourier–Bessel 級数による検算

Kepler 方程式には Bessel 関数 $J_n$ を使う級数解

$$
E=M+\sum_{n=1}^{\infty}\frac2nJ_n(ne)\sin(nM)
$$

がある（$E-M=e\sin E$ を $M$ の Fourier 正弦級数に展開すると、係数が $J_n(ne)$ で表される。
Kapteyn 型の級数）。
この級数はすべての $0\le e<1$ で収束する。
$J_n(n\operatorname{sech}\alpha)$ の Debye の漸近形（[DLMF 10.19.3](https://dlmf.nist.gov/10.19)）で $\operatorname{sech}\alpha=e$ と置くと、項の大きさは

$$
|J_n(ne)|\approx\frac{q(e)^n}{\sqrt{2\pi n\sqrt{1-e^2}}},\qquad
q(e)=\frac{e\,\exp\sqrt{1-e^2}}{1+\sqrt{1-e^2}}<1
$$

となり、項は公比 $q(e)$ の等比級数のように減る。
$q(0.6)\approx0.742$、$q(0.9)\approx0.969$、$q(0.99)\approx0.9991$ なので、$e\to1$ では収束が非常に遅くなる。
漸近形から見積もると、項の大きさが $10^{-16}$ を下回るまでの項数は $e=0.6$ で約 100、$e=0.9$ で約 860、$e=0.99$ で約 24000 である。

約 0.6627 という Laplace の限界は、これとは別の級数、すなわち解を $e$ の冪級数に展開し直したものの収束半径である。
限界の値 $\lambda$ は上の $q$ で $\sqrt{1-e^2}$ を $\sqrt{1+\lambda^2}$ に替えた式 $\lambda\exp\sqrt{1+\lambda^2}/(1+\sqrt{1+\lambda^2})=1$ の根である。
二つの級数を混同して、Fourier–Bessel 級数の適用範囲を $e<0.6627$ に制限してはならない。

次のセルは `scioxide_special::bessel_j` で $J_n(ne)$ を評価し、項数 $N=8,16,\dots$ の部分和を定義のブロックの二分法による参照解と比べる。
入力の項数 $N_{\max}$ が打ち切りの上限である。
表には部分和と参照解の差、$N$ 項目の大きさ、漸近形から予測した項の大きさ $2q^N/(N\sqrt{2\pi N\sqrt{1-e^2}})$ を出す。
予測は $|\sin(nM)|\le1$ の因子を 1 と置いた値なので、実際の項はこれより小さいことがある。
級数は求根とは独立な計算であり、Bessel 関数の値の誤差と和の丸め誤差を含む。
このセルは $e$ と $M$ を自分の入力に持つ。
六手法の比較とは別に、$e$ を 0.99 まで上げたときの級数の収束を確かめるためである。

後半の図は参照解の $E$ から描いた軌道上の位置である。
破線は楕円そのもの（$E$ を一周させた曲線）、記号は $M=2\pi k/12$（$k=0,\dots,11$）の等時間間隔の位置、大きい記号は入力の $M$ で求めた位置、原点の記号は焦点の中心天体である。
等時間間隔の位置は近点側で疎、遠点側で密になり、面積速度一定の法則と整合することを目で確かめられる。

for k in 0..12 {
    let anomaly = core::f64::consts::TAU * f64::from(k) / 12.0;
    equal_time.push(position(reference_solve(e, anomaly)?.point()));
}
let here = position(reference);
let (x, y) = (here[0], here[1]);
let position_columns = serde_json::json!([
    { "key": "0", "label": "E [rad]", "type": "number", "format": digits6 },

$N=64$ の項の大きさ $8.6\times10^{-12}$ rad は、予測 $8.7\times10^{-12}$ rad とよく合う。
$e=0.9$、$N_{\max}=1024$ にすると、差は $N=512$ で $-7.2\times10^{-12}$ rad、$N=1024$ で $-2.7\times10^{-15}$ rad になる。
$e=0.99$ では $N=1024$ でも差が $1.1\times10^{-5}$ rad 残り、級数は高離心率の参照値には向かない。
参照解の二分法は $e$ によらず約 52 回の二分で丸めの水準に達するので、この差は級数の打ち切り誤差と読める。

$\nu$ は `RealScalar::atan2` で求め、$(-\pi,\pi]$ の範囲で表す。

## まとめ

Kepler 方程式の $f$ は $f'\ge1-e>0$ を満たすので根は一つで、区間 $[0,2\pi]$ がいつも根を挟む。
残差から角度の誤差への換算係数は $1/f'(E_*)$ であり、$e\to1$ の近点付近では同じ残差でも誤差が大きくなる。
初期値に $E_0=\pi$ を選ぶと、凸性の議論から Newton 法はすべての $e$ と $M$ で単調に収束する。
$E_0=M$ は円軌道に近いときは良いが、高離心率の近点付近では最初の一歩が大きく飛び、評価回数が増える。
評価回数は役割ごとの内訳と終了理由を合わせて読み、Fourier–Bessel 級数のような独立な計算と、異なる方法による参照解の両方で結果を確かめる。
