臨界温度 $T_c$、臨界圧力 $p_c$、臨界体積 $V_c$ で割った換算量を使うと、van der Waals 状態方程式は物質によらない形

$$
p(V,T)=\frac{8T}{3V-1}-\frac3{V^2},\qquad V>\frac13
$$

になる。
このページの $p,T,V$ はすべて無次元の換算量を表す。
$T<1$ の等温線には $\partial p/\partial V>0$（圧縮すると圧力が下がる）の力学的に不安定な区間があり、平衡状態では液相と気相の共存に置き換わる。
共存する圧力（飽和蒸気圧）$p_{\rm sat}(T)$ を決めるのが Maxwell の等面積則である。
CO₂ の温度と圧力に戻すときは、微分と自動微分の章の例題と同じ $T_c=304.13\,\mathrm K$、$p_c=7.3773\,\mathrm{MPa}$ を使う。

## 体積の 3 次式

圧力 $p>0$ を固定して分母を払うと

$$
3pV^3-(p+8T)V^2+9V-3=0
$$

を得る。
$0<V<1/3$ や $V<0$ では $p(V,T)<0$ であり、$V=0$ と $V=1/3$ は 3 次式の根ではないので、$p>0$ の実根はすべて物理領域 $V>1/3$ にある。
実根が三つある場合、小さい順に $V_l<V_m<V_g$ とする。
液相と気相には両端の根 $V_l$、$V_g$ を使い、不安定な区間にある中間の根 $V_m$ は共存体積に採用しない。

実根が三つになる圧力の範囲は、等温線の極値（スピノーダル点）の圧力で決まる。
極値の体積は $\partial p/\partial V=0$、すなわち $4TV^3=(3V-1)^2$ の $V>1/3$ にある二つの根で、小体積側が極小、大体積側が極大である。
$T<27/32$ では小体積側の極小の圧力が負になるので、その場合は正の圧力の範囲 $(0,p_{\max})$ だけを使う。
極値の圧力では二つの根が重なって重根になり、根の条件数が大きくなる。

次のブロックは三つのセルが共有する定義である。
`isotherm` が $p(V,T)$、`cubic_coefficients` が 3 次式の係数、`volumes` が圧力 $p$ での三つの体積、`equal_area_residual` が次節の $G(p)$、`saturation_pressure` が Maxwell の圧力を求める入れ子の求根に対応する。
係数は昇べきの順 $[-3,\,9,\,-(p+8T),\,3p]$ に並べる。
`volumes` は `PolynomialRootReport` が成功しなければエラーを返す。

```rust
//| id: rootfind-maxwell-model
//| kind: definitions
//| title: 換算した van der Waals 状態方程式と入れ子の求根
//| crates: [scioxide-core, scioxide-rootfind]
use scioxide_core::{SciOxideError, Interval, NumericScalar, RealScalar, ResidualTolerance};
use scioxide_rootfind::{
    Brent, PolynomialRootOptions, RootResult, ScalarFn, ScalarRootOptions, ScalarRootSolver,
    polynomial_roots_with_options,
};

/// 換算した状態方程式 p(V, T) = 8T/(3V − 1) − 3/V²。
pub(crate) fn isotherm(v: f64, t: f64) -> f64 {
    8.0 * t / (3.0 * v - 1.0) - 3.0 / (v * v)
}

/// 3pV³ − (p + 8T)V² + 9V − 3 の係数を昇べきの順に返す。
pub(crate) fn cubic_coefficients(p: f64, t: f64) -> [f64; 4] {
    [-3.0, 9.0, -(p + 8.0 * t), 3.0 * p]
}

/// 圧力 p での根の実部を小さい順に返し、最大 |Im V| と最大の条件数の推定を添える。
pub(crate) fn volumes(p: f64, t: f64) -> Result<([f64; 3], f64, Option<f64>), SciOxideError> {
    let options = PolynomialRootOptions::default();
    let roots = polynomial_roots_with_options(&cubic_coefficients(p, t), &options)?;
    let report = roots.report();
    if !report.is_success() {
        return Err(SciOxideError::numerical_instability(
            scioxide_core::NumericalIssue::Breakdown,
            "3 次式の根が後退誤差の検査に通らない",
        ));
    }
    let z = roots.roots();
    let mut v = [z[0].re, z[1].re, z[2].re];
    v.sort_by(f64::total_cmp);
    let imaginary = z
        .iter()
        .fold(0.0, |m, z| RealScalar::max(m, NumericScalar::abs(z.im)));
    Ok((v, imaginary, report.max_root_condition().value()))
}

/// 原始関数による等面積の残差 G(p)。
pub(crate) fn equal_area_residual(p: f64, t: f64) -> Result<f64, SciOxideError> {
    let ([liquid, _, gas], _, _) = volumes(p, t)?;
    Ok(
        8.0 * t / 3.0 * RealScalar::ln((3.0 * gas - 1.0) / (3.0 * liquid - 1.0))
            + 3.0 * (1.0 / gas - 1.0 / liquid)
            - p * (gas - liquid),
    )
}

/// 極値の圧力から幅の 1 % だけ内側の区間で、|G| ≤ 10⁻¹² を受理する Brent 法を使う。
pub(crate) fn saturation_pressure(t: f64) -> Result<RootResult<f64>, SciOxideError> {
    let options =
        ScalarRootOptions::default().with_residual_tolerance(ResidualTolerance::new(1e-12, 0.0)?);
    // 極値の体積: 4TV³ = (3V − 1)² の [1/3, 1] と [1, 20] の根
    let extrema =
        ScalarFn::new(|v: f64| Ok(4.0 * t * v * v * v - RealScalar::powi(3.0 * v - 1.0, 2)));
    let mut bounds = [0.0; 2];
    for (bound, (a, b)) in bounds.iter_mut().zip([(1.0 / 3.0, 1.0), (1.0, 20.0)]) {
        let extremum = Brent.solve(&extrema, Interval::new(a, b)?, &options)?;
        *bound = isotherm(extremum.point(), t);
    }
    let lower = RealScalar::max(bounds[0], 0.0);
    let margin = 0.01 * (bounds[1] - lower);
    let equation = ScalarFn::new(|p: f64| equal_area_residual(p, t));
    Brent.solve(&equation, Interval::new(lower + margin, bounds[1] - margin)?, &options)
}
```

## 全根計算と PolynomialRootReport

横軸は対数なので、画面上の二つの面積の見かけの大きさを比べても等面積の検算にはならない。
等面積は線形の体積 $dV$ についての積分の値で確かめる。

## 等面積の方程式

Maxwell の条件は、液相と気相の化学ポテンシャル（モルあたりの Gibbs エネルギー）が等しいことを表し、等温線に沿った積分で

$$
G(p)=\int_{V_l(p)}^{V_g(p)}\bigl[p(V,T)-p\bigr]\,dV=0
$$

と書ける。
等温線は $[V_l,V_m]$ で横線 $p$ より下、$[V_m,V_g]$ で上にあるので、二つの部分の面積が等しいという条件になる。
原始関数を使うと

$$
G(p)=\frac{8T}{3}\ln\frac{3V_g-1}{3V_l-1}
+3\left(\frac1{V_g}-\frac1{V_l}\right)-p(V_g-V_l)
$$

となる。
積分の両端では被積分関数が 0 なので、端点の動きは $G$ の微分に寄与せず、$G'(p)=-(V_g-V_l)<0$ である。
したがって実根が三つある圧力の範囲で $G$ は単調減少であり、範囲の両端で $G$ の符号が逆になるので、等面積の圧力は一つに決まる。
この議論は $V_l$ と $V_g$ が最小と最大の根であることに依るので、3 次式の根を小さい順に並べてから使う。

## 入れ子の求根と適応求積による検算

次のセルは換算温度 $T$ を入力とし、Maxwell の圧力 $p_{\rm sat}$ を上の `saturation_pressure` の入れ子の求根で求める。
まず $4TV^3-(3V-1)^2$ の二つの根を `Brent` で求めて極値の圧力の範囲を決め、両端から幅の 1 % だけ内側の区間を外側の `Brent` に渡す。
両端そのものでは重根になり、内側の 3 次式の根の精度が落ちるからである。
$T<27/32$ で下端を $p=0$ にした場合も、内側に寄せることで 3 次の係数 $3p$ が 0 になって気相の根が発散するのを避ける。
外側の評価のたびに `polynomial_roots_with_options` が 3 次式を解き、`PolynomialRootReport` が成功したときだけ原始関数で $G(p)$ を計算する。
外側の許容誤差は $|G|\le10^{-12}$ である。

独立な検算には原始関数を使わない scioxide-integrate の適応 Gauss–Kronrod 求積を使い、$[V_l,V_m]$ と $[V_m,V_g]$ の積分を別々に求める。
求積の許容誤差は絶対 $10^{-14}$、相対 $10^{-13}$ と明示する。
既定の `SubdivisionOptions` は絶対・相対とも $\sqrt\varepsilon\approx1.5\times10^{-8}$ なので、そのままでは $10^{-12}$ の等面積を確かめられない。
表には二つの積分値、誤差の推定、評価回数、終了理由と、その和を原始関数の $G(p_{\rm sat})$ と並べて出す。
誤差の推定は求積の内部の推定値であり、証明付きの上界ではない。
セルの最後の判定は外側の `Brent` の `is_success()` で決め、温度と共存の値を次のセルに書き出す。

## 共存曲線と臨界点

臨界点 $T\to1$ では二つの共存体積が 1 に近づき、3 次式の三つの根が $V=1$ で重なる。
重なった根の条件数は大きくなり、係数の小さな誤差が体積の大きな誤差になる。
ここで外側の圧力の許容誤差だけを厳しくしても、内側の根の誤差は小さくならない。
一方、共存曲線の接線は臨界点で $dp_{\rm sat}/dT\to4$ となる。
これは臨界体積 $V=1$ での $\partial p/\partial T=8/(3V-1)=4$ に等しい。

次のセルは $T=0.55,0.57,\dots,0.99$ の 23 点で共存体積を求めて共存曲線を描き、臨界点 $(V,T)=(1,1)$ を別の記号で示す。
各温度の $p_{\rm sat}$ は `saturation_pressure` で求め、受理されなかった温度があればセルをエラーで止める。
臨界点への割線の勾配 $(1-p_{\rm sat}(1-\delta))/\delta$ を $\delta=0.02,0.01,0.005,0.0025$ で求め、理論値 4 と比べる。
割線の勾配は $\delta\to0$ で接線の勾配に近づくが、有限の $\delta$ では曲率による偏りが残る。
前のセルが書き出した温度と共存体積は、図の横線と記号で示し、CO₂ の温度と圧力に換算する。

```rust

//| title: 共存曲線、臨界点での勾配、CO₂ への換算
```

共存曲線は $T$ を上げると液相と気相の体積が近づき、臨界点 $(1,1)$ で一つになる形である。
気相の体積は低温で急に大きくなるので、横軸は対数にしている。
割線の勾配は $\delta=0.02$ で 3.904、$\delta=0.0025$ で 3.988 であり、理論値 4 との差は $\delta$ を半分にするたびにほぼ半分になる。
この一次の偏りは共存曲線の曲率によるもので、割線の勾配が接線の勾配 4 に $O(\delta)$ で近づくことと整合する。
これは有限の差分幅による検算であり、臨界点の重根そのものを単純根と同じ精度で求めた結果ではない。

$T=0.85$ を CO₂ に換算すると $T=258.5$ K、$p_{\rm sat}=3.72$ MPa になる。
前のセルを $T=0.55$ にすると、換算値は $T=167.3$ K、$p_{\rm sat}=0.381$ MPa になる。
van der Waals モデルは実在の CO₂ の飽和蒸気圧を定量的には再現しないので、この値はモデルの中での換算値として解釈する。

## まとめ

$p>0$ での体積の 3 次式の実根はすべて $V>1/3$ にあり、`polynomial_roots_with_options` の全根計算で液相・不安定・気相の三つの体積を一度に得られる。
Maxwell の圧力は $G'(p)=-(V_g-V_l)<0$ から一意であり、極値の圧力から少し内側の区間で外側の `Brent` を使えば、内側の根が重根に近づくことを避けられる。
外側の受理の閾値は面積の差として結果に残るので、検算の求積には同じ桁を測れる許容誤差を明示し、二つの面積を別々に確かめる。
臨界点に近づくと根の条件数が大きくなるので、`PolynomialRootReport::max_root_condition` で内側の精度の劣化を監視する。
