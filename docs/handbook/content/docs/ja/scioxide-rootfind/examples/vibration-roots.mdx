振動系の運動方程式から得る特性方程式の根（特性根）は、各モードの減衰の速さと減衰固有角振動数を与え、系の安定性を決める。
このページでは 2 つのモードを持つ振動系の 4 次の特性多項式のすべての根を `polynomial_roots_with_options` で求め、モードごとの 2 次因子の根と比べる。

## 2 自由度の振動系の特性多項式

減衰比 $\zeta_j$ [-] と非減衰固有角振動数 $\omega_j$ [rad/s] を持つ 2 つの独立なモード

$$
\ddot{q}_j + 2 \zeta_j \omega_j \dot{q}_j + \omega_j^2 q_j = 0 \qquad (j = 1, 2)
$$

に $q_j(t) = e^{st}$ を代入すると、各モードの 2 次の特性因子

$$
p_j(s) = s^2 + 2 \zeta_j \omega_j s + \omega_j^2
$$

を得る。
系全体の特性多項式はその積の 4 次のモニック多項式 $p(s) = p_1(s) p_2(s) = s^4 + a_3 s^3 + a_2 s^2 + a_1 s + a_0$ で、係数は

$$
a_0 = \omega_1^2 \omega_2^2, \qquad a_1 = 2 (\zeta_1 \omega_1 \omega_2^2 + \zeta_2 \omega_2 \omega_1^2)
$$

$$
a_2 = \omega_1^2 + \omega_2^2 + 4 \zeta_1 \zeta_2 \omega_1 \omega_2, \qquad a_3 = 2 (\zeta_1 \omega_1 + \zeta_2 \omega_2)
$$

である。
実際の構造ではモードが連成して、特性多項式が積に分解できないことが多い。
ここでは 2 次因子の根を独立な検算に使うため、モード座標で分かれた形を選ぶ。

## 特性根の意味

特性根 $s = \sigma + i \omega_d$ のモードは $e^{\sigma t} \cos(\omega_d t)$ のように振る舞う。

- 実部 $\sigma$ [1/s]：振幅の減衰の速さ。
  すべての根の実部が負なら、系は漸近安定である。
- 虚部 $\omega_d$ [rad/s]：減衰固有角振動数。
  $\zeta < 1$（不足減衰）では根は $-\zeta\omega \pm i \omega \sqrt{1 - \zeta^2}$ で、角振動数 $\omega_d = \omega \sqrt{1 - \zeta^2}$ で振動しながら減衰する。
  $\zeta \ge 1$（臨界減衰・過減衰）では根は実数 $-\zeta\omega \pm \omega\sqrt{\zeta^2 - 1}$ になり、振動せずに減衰する。

## 検算の方法

求めた根の集合 $\{s_1, \dots, s_4\}$ を、次の 3 つで確かめる。

1. 2 次因子の根との距離：各モードの $p_j(s) = 0$ を解の公式で解いた根と比べる。
2. Vieta の関係：$\sum_k s_k = -a_3$、$\prod_k s_k = a_0$。
   個々の根の残差では分からない根の欠落や重複が分かる。
3. 共役の対称性：実係数の多項式の非実根は共役の対で現れるので、$\max_k \min_j \lvert s_k - \overline{s_j} \rvert$ は 0 になるはずである。

あわせて、各根の正規化した後退誤差

$$
\eta(s) = \frac{\lvert p(s) \rvert}{\sum_m \lvert a_m \rvert \lvert s \rvert^m}
$$

を表に出す。
これは $s$ を厳密な根に持つ多項式を作るのに必要な、係数の成分ごとの相対的な変化の大きさで、`PolynomialRootDiagnostic::backward_error` が返す。
後退誤差が丸めの程度でも、根の誤差は条件数の倍だけ大きくなりうる（[根の条件数と重根](oxref:rootfind-polynomial-root-condition)）。

次のブロックは三つのセルが共有する定義である。
`characteristic` が係数 $[a_0, a_1, a_2, a_3, 1]$、`factor_roots` が 2 次因子の根、`magnitude` が $\lvert p(s) \rvert$ に対応する。
`factor_roots` と `magnitude` は検算用で、全根計算とは別の式で計算する。

```rust
//| id: rootfind-vibration-model
//| kind: definitions
//| title: 2 自由度の振動系の特性多項式と 2 次因子の根
//| crates: [scioxide-core]
use scioxide_core::{Complex, RealScalar};

/// p(s) = (s² + 2ζ₁ω₁s + ω₁²)(s² + 2ζ₂ω₂s + ω₂²) の係数 [a₀, a₁, a₂, a₃, 1]（定数項から昇べき順）。
pub(crate) fn characteristic(w1: f64, w2: f64, z1: f64, z2: f64) -> [f64; 5] {
    [
        w1 * w1 * w2 * w2,
        2.0 * (z1 * w1 * w2 * w2 + z2 * w2 * w1 * w1),
        w1 * w1 + w2 * w2 + 4.0 * z1 * z2 * w1 * w2,
        2.0 * (z1 * w1 + z2 * w2),
        1.0,
    ]
}

/// モードの因子 s² + 2ζωs + ω² の根 −ζω ± ω√(ζ² − 1)（解の公式）。
pub(crate) fn factor_roots(w: f64, z: f64) -> [Complex<f64>; 2] {
    let d = z * z - 1.0;
    if d < 0.0 {
        let im = w * RealScalar::sqrt(-d);
        [Complex::new(-z * w, im), Complex::new(-z * w, -im)]
    } else {
        let re = w * RealScalar::sqrt(d);
        [Complex::new(-z * w + re, 0.0), Complex::new(-z * w - re, 0.0)]
    }
}

/// |p(s)| を複素 Horner 法で評価する。
pub(crate) fn magnitude(c: &[f64; 5], s: Complex<f64>) -> f64 {
    c.iter()
        .rev()
        .fold(Complex::new(0.0, 0.0), |v, &a| v * s + Complex::new(a, 0.0))
        .norm()
}
```

## 4 つの特性根の計算

次のセルは $\omega_1 = 1$ rad/s に固定し、$\omega_2$ [rad/s] と 2 つの減衰比 $\zeta_1$、$\zeta_2$ [-] を変えて、特性多項式のすべての根を `polynomial_roots_with_options`（既定の `PolynomialRootOptions` で、方法は `PolynomialRootMethod::Auto`）で求める。
係数は定数項から昇べき順に $[a_0, a_1, a_2, a_3, 1]$ と渡す。
このセルの検算は答えを知らなくてもできる根の集合の関係に限る。
根ごとの表は $\lvert p(s) \rvert$ と `PolynomialRootDiagnostic::backward_error` の後退誤差を示す。
まとめの表は Vieta の関係の誤差、共役の対称性の誤差、`PolynomialRootReport::max_root_condition` の条件数、実部の最大を示す。
outcome は `PolynomialRootReport` の終了状態を示し、`Complete` ならすべての根が元の係数で後退誤差の検査に通っている。
求めた根と入力は、次のセルの比較と図に渡す。

既定値（$\omega_2 = 2$ rad/s、$\zeta_1 = 0.08$、$\zeta_2 = 0.18$）では、根は $-0.08 \pm 0.99679i$ と $-0.36 \pm 1.96733i$ で、終了状態は `Complete` である。
正規化した後退誤差は $3.6 \times 10^{-17}$ 以下である。
Vieta の和と積の誤差は $1.1 \times 10^{-16}$ と $8.9 \times 10^{-16}$、共役の対称性の誤差は 0 で、条件数の最大は 4.2 にとどまる。
実係数の入力では返す前に共役の対をそろえるので（[実数係数と複素共役根の対称性](oxref:rootfind-polynomial-conjugate-symmetry)）、この誤差が 0 でなければ、対をそろえられなかった根がある。
条件数が小さいので、後退誤差が丸めの程度なら、根の誤差も $\kappa\eta \approx 1.5 \times 10^{-16}$ の程度にとどまると見込める。
この見込みは次のセルで 2 次因子の根と比べて確かめる。

$\zeta_1 = 0$ にすると第一モードの根は数学的には虚軸の上 $\pm i$ に来るが、計算した実部の最大は $-4.8 \times 10^{-18}$ である。
$\zeta_2 = 0$ では逆に $+6.0 \times 10^{-18}$ になる。
どちらも丸めによる大きさで符号に意味はないので、実部の符号だけで安定と不安定を区別しない。
減衰が 0 の系は、漸近安定ではなく減衰しない振動を続ける系として扱う。
$\zeta_1 = 1.2$ のように過減衰にすると、第一モードの根は二つの負の実根 $-1.8633$ と $-0.5367$ になり、虚部は厳密に 0 になる。

## 2 次因子の根との比較と虚軸の上の特性多項式

根の位置を複素平面に描くと、モードごとの減衰の速さ（実部）と振動の速さ（虚部）を一度に読める。
次のセルは前のセルの根と入力を受け取り、各モードの 2 次因子 $p_j(s) = 0$ を解の公式で解いた根と比べる。
表は計算した各根から最も近い 2 次因子の根までの距離、上の図は複素平面の根と 2 次因子の根、下の図は虚軸の上の $\lvert p(i\Omega) \rvert$（対数軸）である。
$\lvert p_j(i\Omega) \rvert = \sqrt{(\omega_j^2 - \Omega^2)^2 + (2 \zeta_j \omega_j \Omega)^2}$ なので、減衰が小さいと $\lvert p(i\Omega) \rvert$ は $\Omega \approx \omega_j$ で深い谷を持ち、谷の深さは $\zeta_j$ に比例する。
$1/\lvert p(i\Omega) \rvert$ は、二つのモードを直列につないだ系の周波数応答の振幅にあたる。
入力を変えても図が跳ばないように、複素平面は $-7 \le \operatorname{Re} s \le 0.5$、$-4 \le \operatorname{Im} s \le 4$ に、角振動数は $0 < \Omega \le 5$ rad/s に固定する。
入力を変えるときは前のセルの入力を動かす。

```rust
//| id: rootfind-vibration-root-plane
//| ref: rootfind-vibration-root-plane
//| title: 特性根を 2 次因子の根と比べ、複素平面と虚軸の上の特性多項式を描く
//| run: reactive
//| uses: [rootfind-vibration-model]
//| crates: [scioxide-core]
//| dependsOn:
//|   solve: rootfind-vibration-roots
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"distances","path":"/rows/0/2","range":{"max":1e-15}}
//|       - {"artifact":"distances","path":"/rows/1/2","range":{"max":1e-15}}
//|       - {"artifact":"distances","path":"/rows/2/2","range":{"max":1e-15}}
//|       - {"artifact":"distances","path":"/rows/3/2","range":{"max":1e-15}}
//|       - {"artifact":"plane","path":"/spec/series/1/points/2/0","approx":{"value":-0.36,"atol":1e-15}}
//|       - {"artifact":"response","path":"/spec/series/0/points/99/0","approx":{"value":1.0,"atol":1e-12}}
//|       - {"artifact":"response","path":"/spec/series/0/points/99/1","approx":{"value":0.4936,"atol":5e-4}}
//|       - {"artifact":"valleys","path":"/rows/0/0","approx":{"value":0.4936,"atol":5e-4}}
//|       - {"artifact":"valleys","path":"/rows/0/1","approx":{"value":3.738,"atol":5e-3}}
//|       - {"artifact":"valleys","path":"/rows/0/2","equals":0}

    parameter("second_natural_frequency")?,
    parameter("first_damping_ratio")?,
    parameter("second_damping_ratio")?,
);

    serde_json::from_value(solve["roots"].clone()).map_err(|e| e.to_string())?;

    .into_iter()
    .chain(factor_roots(w2, z2))
    .collect();

    .iter()
    .map(|&[re, im]| {
        let distance = exact
            .iter()
            .map(|&q| (Complex::new(re, im) - q).norm())
            .fold(f64::INFINITY, RealScalar::min);
        (re, im, distance)
    })
    .collect();
let fixed10 = serde_json::json!({ "fractionDigits": 10 });
let columns = serde_json::json!([
    { "key": "0", "label": "Re s [1/s]", "type": "number", "format": fixed10 },
    { "key": "1", "label": "Im s [rad/s]", "type": "number", "format": fixed10 },
    {
        "key": "2",
        "label": "2 次因子の根との距離 [1/s]",
        "type": "number",
        "format": { "notation": "scientific", "significantDigits": 2 }
    }
]);
emit_table_with_columns!(
    columns,
    distances,
```

既定値では、2 次因子の根との距離は $4.6 \times 10^{-16}$ 以下である。
これは $\lvert s \rvert \approx 2$ での倍精度の間隔 $4.4 \times 10^{-16}$ の程度で、前のセルの見込み $\kappa\eta \approx 1.5 \times 10^{-16}$ に、参照値の解の公式自身の丸めを加えた大きさに収まる。
上の図では、計算した根と 2 次因子の根が重なり、二つずつ実軸に対して対称に並ぶ。
減衰比を大きくすると根は虚軸から左へ離れ、$\zeta_j \ge 1$ で実軸の上に移って二つに分かれる。

$\Omega = \omega_j$ での $\lvert p(i\Omega) \rvert$ の値は $2 \zeta_j \omega_j^2 \lvert p_k(i\omega_j) \rvert$（$k \ne j$）で、減衰比が小さいほど小さい。
下の図の既定値では、$\zeta_1 = 0.08$ の第一モードが $\Omega \approx 1$ rad/s に深い谷を作り、表の最小値は 0.494 である。
これは $2 \times 0.08 \times \lvert p_2(i) \rvert = 0.16 \times 3.085$ と一致する。
$\zeta_2 = 0.18$ の第二モードは $\Omega \approx 2$ rad/s で谷にならず、増え方が緩む肩になる（表の最小値は 3.74）。
$\lvert p_1(i\Omega) \rvert = \lvert 1 - \Omega^2 + 2 i \zeta_1 \Omega \rvert$ が $\Omega$ とともに増えるので、第二モードの減衰が大きいと谷が埋まるためである。
前のセルで $\zeta_2 = 0.02$ にすると、$\Omega \approx 2$ rad/s にも最小値 0.483 の谷が現れる。
$\zeta_1 = 0$ では $p(i\omega_1) = 0$ となり、計算した値も 0 になるので、その 1 点を対数軸から除き、表の「除いた点」に数える。

## 臨界減衰の近くの重根

モードの因子 $s^2 + 2\zeta \omega s + \omega^2$ は、$\zeta = 1$ で 2 つの根が $s = -\omega$ で重なり、重根になる。
単純根 $s_k$ では、定数項を $a_0 \to a_0(1 + \delta)$ と変えると $p(s) + \delta a_0 = 0$ を 1 次まで展開して、根の動きは

$$
\lvert \Delta s \rvert \approx \frac{\delta \lvert a_0 \rvert}{\lvert p'(s_k) \rvert}
$$

で、$\delta$ に比例する。
重根では $p'(-\omega) = 0$ なのでこの式は使えず、$p(s) \approx \tfrac12 p''(-\omega)(s + \omega)^2$ から

$$
\lvert \Delta s \rvert \approx \sqrt{\frac{2 \delta \lvert a_0 \rvert}{\lvert p''(-\omega) \rvert}}
$$

となり、根は $\sqrt{\delta}$ に比例して動く。
係数の相対的な丸め $\delta \approx 10^{-16}$ でも、重根の位置は $10^{-8}$ の程度しか決まらない。
これは方式の欠陥ではなく、重根という問題そのものの性質である。

次のセルは $\omega_1 = 1$、$\omega_2 = 2$ rad/s、$\zeta_2 = 0.18$ に固定し、定数項 $a_0$ を相対的に $\delta = 10^{-2}$ から $10^{-12}$ まで変えて、第一モードの根の動きを両対数の図と表に出す。
入力は第一モードの減衰比 $\zeta_1$ で、1 のとき重根になる。
根の移動 $\lvert \Delta s \rvert$ は、第一モードの元の根の近くにある二つの計算した根のうち、遠いほうの距離である。
図の記号付きの線は計算した根の移動、破線は 1 次の予測である。
予測には $\zeta_1 = 1$ では重根の式 $\sqrt{2\delta a_0/\lvert p''(-1) \rvert}$、それ以外では単純根の式 $\delta a_0/\lvert p'(s_1) \rvert$（二つの根のうち大きいほう）を使う。
予測は解の公式で得た元の根から計算するので、全根計算とは独立な検算になる。
outcome は、11 回の全根計算がすべて `Complete` だったかを示す。

既定の $\zeta_1 = 1$（重根）では、$\lvert \Delta s \rvert / \sqrt{\delta}$ がどの $\delta$ でも 0.967 で一定で、根の動きは $\sqrt{\delta}$ に比例する。
重根の式では $p''(-1) = 2 p_2(-1) = 2 \times 4.28$、$a_0 = 4$ なので、比は $\sqrt{4/4.28} = 0.967$ となり、計算と一致する。
$\delta = 10^{-12}$ でも根は $9.7 \times 10^{-7}$ 動く。
`PolynomialRootReport` の条件数の最大も $1/\sqrt{\delta}$ に比例して、$2.8 \times 10^{1}$ から $2.8 \times 10^{6}$ に増える。
これは摂動で分かれた二つの近い根での 1 次の条件数で、重根の重複度を判定するものではない。

$\zeta_1 = 0.5$（単純根）では $\lvert \Delta s \rvert / \delta$ が 0.733 で一定で、根の動きは $\delta$ に比例し、条件数は 5.3 程度にとどまる。
単純根の式でも、$\lvert p'(s_1) \rvert = \lvert p_1'(s_1) \rvert \lvert p_2(s_1) \rvert = 1.732 \times 3.149$ から、比は $4/5.45 = 0.733$ となる。
$\delta = 10^{-12}$ では比が 0.7335 と 4 桁目でずれ、丸め誤差が見え始める。
$\zeta_1 = 1.5$ でも同じく $\delta$ に比例する（比は 0.462、条件数は 10）。
$\zeta_1 = 0.99$ のように重根に近い単純根では、$\delta = 10^{-2}$ の移動 0.030 が 1 次の予測 0.033 より小さい。
根の間隔 $2\sqrt{1 - \zeta_1^2} \approx 0.28$ に比べて摂動が大きいと 1 次の予測が成り立たず、$\delta \le 10^{-4}$ で記号が破線に乗る（比は 3.33）。

## まとめ

モードに分かれた 2 自由度の振動系の特性根は 4 次多項式のすべての根で、`polynomial_roots_with_options` が一度に求め、`PolynomialRootReport` の終了状態が `Complete` なら元の係数で検査済みである。
根は独立に解いた 2 次因子の根、Vieta の和と積、共役の対称性の三つで確かめ、どれも丸めの程度で一致することを見る。
減衰が 0 の根の実部は丸めで正にも負にもなりうるので、安定性は実部の符号だけでなく、その大きさと条件数で判断する。
臨界減衰の近くでは重根になり、係数の変化 $\delta$ に対して根が $\sqrt{\delta}$ の程度動くので、根の位置を読むときは `PolynomialRootReport::max_root_condition` の条件数も見る。
