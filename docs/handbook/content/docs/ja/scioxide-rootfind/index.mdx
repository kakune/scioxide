求根（root finding）は与えられた関数の値を 0 にする点を求める計算である。

$$
f(x) = 0 \quad (x \in \mathbb{R}\ \text{または}\ \mathbb{C}), \qquad \mathbf{F}(\mathbf{x}) = \mathbf{0} \quad (\mathbf{x} \in \mathbb{R}^n), \qquad p(z) = \sum_{k=0}^{n} a_k z^k = 0
$$

平衡温度、内部収益率、化学平衡、軌道上の位置、振動系の固有値など、多くの問題がこの形になる。
解き方は、未知数の数、根を挟む区間が分かっているか、導関数が使えるか、根がいくつ必要かで決まる。
多くの方法は反復で近似を改善するので、どの条件で反復を止めたかを結果と一緒に読む必要がある。

`scioxide-rootfind` は次の問題を扱う。

| 問題 | 主な API |
|---|---|
| 1 変数の実方程式（区間法、導関数を使う開いた方法、区間で保護した方法） | `find_root`、`find_bracket`、`Brent`、`Toms748`、`Chandrupatla`、`Bisection`、`Newton`、`Halley`、`SafeguardedNewton`、`Secant`、`Muller`、実行時に方法を選ぶ `ScalarRootMethod` |
| 1 変数の複素方程式 | `ComplexNewton`、`ComplexHalley`、`ComplexSecant`、`ComplexMuller` |
| 連立非線形方程式 | `solve_system`、`NewtonSystem`、`Broyden`、`TrustRegionSystem`、行列を作らない `NewtonKrylovSolver` |
| 固定点 $x = G(x)$ と加速 | `fixed_point`、`FixedPointSolver`（Picard、Anderson、Steffensen、Broyden 型など） |
| 多項式のすべての根 | `polynomial_roots`、`polynomial_roots_with_options`、`PolynomialRootInput` |
| パラメータを含む方程式の解の枝と別の解 | `Continuation`、`LinearHomotopy`、`DeflatedProblem` |
| 特殊関数の番号付きの零点 | `special_zeros`、`special_zeros_with_options`（Bessel、Airy、Kelvin、誤差関数、Fresnel 積分） |

`find_root`、`find_bracket`、`solve_system`、`fixed_point`、`polynomial_roots`、`special_zeros` は既定の設定で解くワンショット関数である。
成功したときだけ答えを返し、それ以外の終了は `ConvergenceFailure`、`ExecutionStopped`、`NumericalInstability` のエラーにする。
設定を変える場合や、終了理由、残差、評価回数を読む場合は、表のほかの型と関数を使う。

## 最初の計算：Kepler 方程式

楕円軌道を回る天体の位置は、離心率 $e$ と平均近点角 $M$ から、Kepler 方程式

$$
f(E) = E - e \sin E - M = 0, \qquad 0 \le e < 1
$$

を解いて離心近点角 $E$ を求めると決まる。
$f'(E) = 1 - e\cos E \ge 1 - e > 0$ なので $f$ は狭義単調増加で、根はただ一つである。
さらに $\lvert \sin E \rvert \le 1$ から

$$
f(M - e) = -e\bigl(1 + \sin(M - e)\bigr) \le 0, \qquad f(M + e) = e\bigl(1 - \sin(M + e)\bigr) \ge 0
$$

となり、区間 $[M - e, M + e]$ が根を挟む。
このように、関数の性質から根を挟む区間を導けるときは、区間法がまず候補になる。

次のセルはこの区間を `Brent` に渡して離心近点角を求める。
入力は離心率 $e$ と平均近点角 $M$ [rad] で、既定値の $e = 0.6$、$M = 1.2$ rad は scioxide-core の[Kepler 方程式と求解の回数の集計](../scioxide-core/examples/kepler-solve-accounting/)とそろえている。
区間の幅による既定の停止条件に加えて、残差の絶対許容誤差 $10^{-12}$ rad を `with_residual_tolerance` で与える。
表は終了理由、近似解 $\hat E$、残差 $f(\hat E)$、残差から見積もった角度の誤差 $\lvert f(\hat E) \rvert / f'(\hat E)$、関数の評価回数を示す。
セルの最後の判定は、終了理由が成功かどうかを示す。

```rust
//| id: rootfind-kepler-methods
//| ref: rootfind-kepler-methods
//| title: Kepler 方程式を Brent 法で解く
//| run: reactive
//| crates: [scioxide-core, scioxide-rootfind]
//| inputs:
//|   eccentricity: {"type":"range","label":"離心率 e [-]","min":0,"max":0.95,"step":0.05,"value":0.6}
//|   mean_anomaly: {"type":"range","label":"平均近点角 M [rad]","min":0.1,"max":6,"step":0.1,"value":1.2}
//| cases:
//|   - {"id":"circular","label":"e = 0（円軌道）","description":"区間が一点 M に縮み、その点が厳密な根なので評価は 1 回で終わる。","inputs":{"eccentricity":0}}
//|   - {"id":"eccentric","label":"e = 0.95、M = 0.1 rad（傾きが小さい根）","description":"残差 6.0 × 10⁻¹³ rad に対して、角度の誤差の見積もりは 2.0 × 10⁻¹² rad になる。","inputs":{"eccentricity":0.95,"mean_anomaly":0.1}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"solution","path":"/rows/0/0","equals":"ResidualTolerance"}
//|       - {"artifact":"solution","path":"/rows/0/1","approx":{"value":1.786141603274,"atol":5e-12}}
//|       - {"artifact":"solution","path":"/rows/0/2","range":{"min":-1e-12,"max":1e-12}}
//|       - {"artifact":"solution","path":"/rows/0/4","equals":6}
//|       - {"path":"/outputs/1/state","equals":"satisfied"}
//|   - case: circular
//|     expect:
//|       - {"artifact":"solution","path":"/rows/0/0","equals":"ResidualTolerance"}
//|       - {"artifact":"solution","path":"/rows/0/1","approx":{"value":1.2,"atol":1e-15}}
//|       - {"artifact":"solution","path":"/rows/0/4","equals":1}
//|       - {"path":"/outputs/1/state","equals":"satisfied"}
//|   - case: eccentric
//|     expect:
//|       - {"artifact":"solution","path":"/rows/0/0","equals":"ResidualTolerance"}
//|       - {"artifact":"solution","path":"/rows/0/2","approx":{"value":-6.0e-13,"atol":5e-14}}
//|       - {"artifact":"solution","path":"/rows/0/3","approx":{"value":2.0e-12,"atol":5e-14}}
//|       - {"path":"/outputs/1/state","equals":"satisfied"}
use scioxide_core::{EvaluationRole, Interval, NumericScalar, RealScalar, ResidualTolerance};
use scioxide_rootfind::{Brent, ScalarFn, ScalarRootOptions, ScalarRootSolver};

let (e, m) = (eccentricity, mean_anomaly);
let function = ScalarFn::new(|x: f64| Ok(x - e * RealScalar::sin(x) - m));
// |sin E| ≤ 1 から導いた区間 [M − e, M + e] は根を挟む。
let bracket = Interval::new(m - e, m + e).map_err(|e| e.to_string())?;
// 区間の幅に加えて、残差 |f| ≤ 10⁻¹² rad でも受理する（絶対許容誤差）。
let options = ScalarRootOptions::default()
    .with_residual_tolerance(ResidualTolerance::new(1e-12, 0.0).map_err(|e| e.to_string())?);
let result = Brent
    .solve(&function, bracket, &options)
    .map_err(|e| e.to_string())?;
// 位置の誤差の見積もり |f(Ê)| / f′(Ê)。f′(E) = 1 − e cos E ≥ 1 − e > 0。
let slope = 1.0 - e * RealScalar::cos(result.point());
let residual = NumericScalar::abs(result.residual());
let evaluations = result.counts().provider(EvaluationRole::Function);
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let digits13 = serde_json::json!({ "significantDigits": 13 });
let columns = serde_json::json!([
    { "key": "0", "label": "終了理由" },
    { "key": "1", "label": "離心近点角 Ê [rad]", "type": "number", "format": digits13 },
    { "key": "2", "label": "残差 f(Ê) [rad]", "type": "number", "format": sci2 },
    { "key": "3", "label": "誤差の見積もり |f(Ê)|/f′(Ê) [rad]", "type": "number", "format": sci2 },
    { "key": "4", "label": "関数の評価 [回]", "type": "integer" }
]);
let termination = result.termination();
emit_table_with_columns!(
    columns,
    vec![(
        termination.to_string(),
        result.point(),
        result.residual(),
        residual / slope,
        evaluations
    )],
    metadata = serde_json::json!({ "id": "solution" })
);

let outcome = if termination.is_success() {
    Outcome::satisfied("Brent 法が根を受理した")
} else {
    Outcome::partial("Brent 法が受理の条件を満たす前に止まった")
        .explanation("返された点は最後に受理した近似で、根として使う前に残差と区間を確かめる。")
};
emit_outcome!(
    outcome
        .status(termination.to_string())
        .diagnostic("残差 |f(Ê)|", residual, Some("rad"))
        .diagnostic("関数の評価", evaluations as f64, None)
);
```

既定の入力では `ResidualTolerance` で終わり、離心近点角は約 1.78614 rad、残差は $-1.6 \times 10^{-15}$ rad、関数の評価は区間の両端の 2 回を含めて 6 回である。
$e = 0$ では区間が一点 $M$ に縮み、その点が厳密な根なので評価は 1 回で終わる。
残差は角度と同じ単位 rad を持つが、角度の誤差そのものではない。
根の近くでは $\lvert \hat E - E^* \rvert \approx \lvert f(\hat E) \rvert / f'(E^*)$ であり、$f' \ge 1 - e$ なので、$e$ が 1 に近いほど同じ残差に対応する角度の誤差は大きくなりうる。
例えば $e = 0.95$、$M = 0.1$ rad では根での傾きが約 0.30 で、残差 $6.0 \times 10^{-13}$ rad に対して誤差の見積もりは $2.0 \times 10^{-12}$ rad になる。
解法の比較、初期値の選び方、級数による独立な検算は[Kepler 方程式と離心率](examples/kepler-equation/)で扱う。

## 結果の読み方

スカラーの求解は `RootResult` を返し、次の量を別々に読む。

- 終了理由：`RootResult::termination()`（`RootTermination`）が成否を決める唯一の情報である。
  1 変数の方法の成功は次の三つである。
  - `ResidualTolerance`：厳密な零を観測したか、`with_residual_tolerance` で明示した残差の基準を満たした。
    区間法では `with_residual_scale` で残差の尺度を与えた場合も、残差による受理が有効になる。
  - `StepTolerance`：区間を持たない方法で、更新幅が座標の許容誤差以下になり、しかも残差が開始点での $\lvert f \rvert$ の最大の $\sqrt{\varepsilon}$ 倍以下に減った。
  - `BracketTolerance`：区間法と区間で保護した方法（`SafeguardedNewton` など）で、符号が変わる区間の幅が座標の許容誤差を満たした。

  集合を求める計算（多項式の全根、特殊関数の零点）は `Complete` と `NoZeros` も成功とする。
  `IterationLimit`、`Stagnation`、`ComplexStepRequired`、上限による停止（`WorkLimit`）、取り消し（`Cancelled`）、期限（`TimeLimit`）でも結果は `Ok` で返るので、値を使う前に `is_success()` を確かめる。
  ただし、受理した点がまだないうちに上限・取り消し・期限で止まった場合は、エラーが返る。
- 残差と位置の誤差：`residual()` は近似解での関数値 $f(\hat x)$ である。
  単純根の近くでは $\lvert \hat x - x^* \rvert \approx \lvert f(\hat x) \rvert / \lvert f'(x^*) \rvert$ なので、$\lvert f' \rvert$ が小さい根では残差が小さくても位置の誤差は大きい（[方程式の根を求める方法](oxref:rootfind-residual-and-position-error)）。
- 根を挟む区間の記録：区間法と区間で保護した方法では、`RootResult::bracket()` が最後に評価した区間の両端の座標と関数値を `Bracket` として返す。
  成功したときだけでなく、`IterationLimit`、`Stagnation`、上限による停止のときも返る。
  これは浮動小数点で評価した符号の変化の記録で、関数が連続であるという仮定の下で根の存在の根拠になるが、区間演算による証明ではない。
  区間を持たない方法では `None` である。
- 評価回数と上限：`counts()` は関数（`EvaluationRole::Function`）、1 階導関数（`Jacobian`）、2 階導関数（`Hessian`）の評価回数と反復回数を返す。
  関数の評価を数える役割は `ScalarRootOptions::with_evaluation_role` で替えられる。
  反復回数の上限は `with_max_iterations`、評価回数などの上限は scioxide-core の `SolveBudgets` を `with_budgets` で与える。

## まとめ

`scioxide-rootfind` は、1 変数・連立・多項式・固定点・パラメータを含む方程式・特殊関数の零点を、問題の形に合った型と関数で解く。
関数の性質から根を挟む区間を導けるなら、Kepler 方程式の $[M - e, M + e]$ のように区間を作って区間法に渡す。
結果は `termination()` で成否を判定し、`IterationLimit` や `Stagnation` で返った値を解として使わない。
残差は関数の単位の量なので、位置の誤差は $\lvert f \rvert / \lvert f' \rvert$ で見積もり、区間の記録は連続性を仮定した根拠として解釈する。
