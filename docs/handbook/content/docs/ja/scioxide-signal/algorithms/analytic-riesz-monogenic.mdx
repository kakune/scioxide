振動する信号の「振幅」と「位相」は、1 つの実数の標本列からは一通りに決まらない。
$x(t) = A(t)\cos\phi(t)$ と書ける組 $(A, \phi)$ は無数にあるからである。
解析信号は負の周波数を除いた複素信号 $z = x + i\,\mathcal{H}[x]$ を作り、その絶対値と偏角を振幅と位相と定める。
このページは離散の解析信号の重みを導き、包絡線と瞬時周波数を読む条件を示す。
続いて、同じ考えを多次元へ広げる 2 つの方法（単一象限の解析信号と Riesz 変換）と、事象の時刻が周期に同期する度合いを測るベクトル強度を扱う。

連続時間の Hilbert 変換の定義と、`rfft` と `ifft` から解析信号を組み立てる手順は、fft 章の[解析信号と離散 Hilbert 変換](../../../scioxide-fft/algorithms/analytic-signal/)で導いている。
このページはその結果を前提にし、`scioxide-signal` の関数が何を仮定し、どこまで信頼できるかを説明する。

## 離散の解析信号

長さ $N$ の実数列 $x_0, \dots, x_{N-1}$ を 1 周期とみなし、DFT を $X_k = \sum_n x_n e^{-2\pi i kn/N}$ とする。
実数列では $X_{N-k} = \overline{X_k}$ なので、添字 $k$ と $N-k$ の組は同じ情報を持つ。
添字を $(-N/2, N/2]$ の符号付きの周波数として読み、$0 < k < N/2$ を正の周波数、$N/2 < k < N$ を負の周波数とする。

連続の Hilbert 変換の周波数応答は $-i\,\mathrm{sgn}(f)$ である。
離散では、DC のビン $k = 0$ と、偶数長の Nyquist 周波数のビン $k = N/2$ は、自分自身と対になる。
これらのビンでは $X_k$ が実数なので、$-i$ を掛けると虚数になり、逆変換の結果が実数でなくなる。
Hilbert 変換を実数から実数への写像に保つには、この 2 つのビンの応答を 0 にするしかない。
したがって離散の Hilbert 変換の応答は

$$
H_k = \begin{cases} -i & 0 < k < N/2 \\ 0 & k = 0,\ \text{または } N \text{ が偶数で } k = N/2 \\ +i & N/2 < k < N \end{cases}
$$

で、解析信号 $z = x + i\,\mathcal{H}[x]$ の DFT は $Z_k = (1 + iH_k) X_k = w_k X_k$ になる。
重みは

$$
w_k = \begin{cases} 1 & k = 0,\ \text{または } N \text{ が偶数で } k = N/2 \\ 2 & 0 < k < N/2 \\ 0 & N/2 < k < N \end{cases}
$$

である。
奇数長では Nyquist のビンがないので、$1 \le k \le (N-1)/2$ のすべてが 2 倍になる。
$\mathcal{H}[x]$ は実数なので、$\operatorname{Re} z_n = x_n$ が成り立つ。

`hilbert(input)` はこの $z$ を返し、`envelope(input)` は $\lvert z_n \rvert$ を返す。
内部では実数の FFT で $X_k$ の非負周波数の半分を求め、正の周波数に $-i$ を掛け、DC と Nyquist を 0 にして実数の逆 FFT で $\mathcal{H}[x]$ を得る。
実部には入力の値をそのまま写すので、$\operatorname{Re} z_n$ は $x_n$ とビット単位で等しい。
計算量は $O(N \log N)$ である。
入力の最大絶対値が大きいか小さいときは、2 のべき乗で尺度を変えてから変換するので、有限な結果が途中であふれたり、早すぎる段階でアンダーフローしたりしない。
誤差は FFT の誤差と同じ型で、$\varepsilon$ と入力のノルムと $\log N$ に比例する（[作業精度の誤差](../)）。
最大の成分より桁違いに小さい成分は、相対精度を失う。

`complex_envelope_into(input, output, cx)` は、複素数の標本の絶対値を出力の先頭に書くだけで、Hilbert 変換はしない。
`hilbert` の結果や、復調したベースバンドの信号の包絡線を、出力の領域を使い回して求めるときに使う。
出力が入力より短いと `DimensionMismatch`、非有限の標本は `NonFinite` を返す。

### 周期の仮定

DFT は記録を 1 周期とみなすので、両端の値や傾きがつながらない記録は、周期延長の上で跳びを持つ。
跳びのスペクトルは全帯域に広がり、正の周波数を 2 倍して負の周波数を消す重みが、時間領域では両端の近くの振動になる。
その結果、両端の近くの包絡線と位相が乱れる。
`hilbert` は補零の長さを引数に取らない。
両端を滑らかに 0 に下げるウインドウを掛けるか、前後に余白を置いた記録を渡し、余白の部分の結果を使わない。

## 瞬時位相と瞬時周波数

解析信号を極形式 $z_n = A_n e^{i\phi_n}$ で書き、$A_n = \lvert z_n \rvert$ を瞬時振幅（包絡線）、$\phi_n = \arg z_n$ を瞬時位相と呼ぶ。
瞬時周波数は位相の時間微分 $f(t) = \phi'(t)/(2\pi)$ である。
離散では、隣り合う標本の位相差を

$$
\hat f_{n+1/2} = \frac{f_s}{2\pi}\arg\left(z_{n+1}\overline{z_n}\right)
$$

で求める（$f_s$ は標本化周波数）。
積の偏角を取るので位相のアンラップ（$2\pi$ の跳びの除去）が要らず、$\lvert f \rvert < f_s/2$ の範囲で正しい。
位相が時間の 2 次式（線形チャープ）なら、この差分は中点 $t_{n+1/2}$ での瞬時周波数に丸め誤差を除いて一致する。
$A_n$ が小さい標本では偏角が丸め誤差とノイズに支配されるので、瞬時周波数を読む範囲は包絡線の大きさで制限する。

## 包絡線として読める条件

$\lvert z \rvert$ がいつも「振幅」を表すとは限らない。
Bedrosian の定理は、2 つの信号のスペクトルが分かれているときにだけ、Hilbert 変換が低周波の因子を素通りさせることを述べる。

> 低周波の信号 $a(t)$ のスペクトルが $\lvert f \rvert < B$ に含まれ、高周波の信号 $c(t)$ のスペクトルが $\lvert f \rvert > B$ に含まれるとき、$\mathcal{H}[a\,c] = a\,\mathcal{H}[c]$ が成り立つ。

$a \ge 0$ で $c = \cos\phi$ がこの条件を満たせば、$z = a\,(\cos\phi + i\sin\phi)$ となり、$\lvert z \rvert = a$ と $\arg z = \phi$ が得られる。
包絡線 $a$ の帯域が搬送波の周波数に比べて狭いことが、包絡線と瞬時周波数を読む前提である。
条件が崩れる例（搬送波の周波数が変調の周波数より低い振幅変調波）は、[Hilbert 変換による包絡線の復元](../../examples/hilbert-envelope/)で扱う。

次のセルはガウス関数の包絡線 $a(t) = \exp(-(t - t_0)^2/(2w^2))$ を持つ線形チャープ

$$
x(t) = a(t)\cos\left(2\pi\left(f_0 (t - t_0) + \tfrac{c}{2}(t - t_0)^2\right)\right)
$$

を $f_s = 1000$ Hz、$N = 1000$ 標本（1 s）で作り、`hilbert`、`envelope`、`complex_envelope_into` を使う。
中心は $t_0 = 0.5$ s、中心周波数は $f_0 = 100$ Hz で、理論の瞬時周波数は $f(t) = f_0 + c\,(t - t_0)$ である。
入力は周波数の変化率 $c$ [Hz/s] と包絡線の幅 $w$ [s] である。
誤差は $a(t) \ge 0.1$ の範囲で測り、記録の端の振幅 $a(0)$ も表に出す。
信号の生成と理論値は f64 の固有メソッドによる参照計算で、SciOxide の計算とは独立である。

```rust
//|   - case: default

//|       - {"artifact":"errors","path":"/rows/1/1","range":{"max":1e-6}}

//|   - case: wide-envelope
//|     expect:
//|       - {"artifact":"errors","path":"/rows/0/1","equals":0}
//|       - {"artifact":"errors","path":"/rows/1/1","range":{"min":1e-3}}

//|   - case: pure-tone
//|     expect:
//|       - {"artifact":"errors","path":"/rows/2/1","range":{"max":1e-4}}
use scioxide_core::ExecutionContext;
use scioxide_signal::{complex_envelope_into, envelope, hilbert};

// f_s = 1000 Hz、N = 1000 標本（1 s）。中心 t₀ = 0.5 s、中心周波数 f₀ = 100 Hz。
let (n, fs, t0, f0) = (1000_usize, 1000.0_f64, 0.5_f64, 100.0_f64);
let tau = std::f64::consts::TAU;
// 生成と理論値は f64 の固有メソッドによる参照計算。
let amplitude = |t: f64| (-0.5 * ((t - t0) / width).powi(2)).exp();
let frequency = |t: f64| f0 + chirp_rate * (t - t0);
let time = |i: usize| i as f64 / fs;
let signal: Vec<f64> = (0..n)
    .map(|i| {
        let s = time(i) - t0;
        amplitude(time(i)) * (tau * (f0 * s + 0.5 * chirp_rate * s * s)).cos()
    })
    .collect();

let analytic = hilbert(&signal).map_err(|e| e.to_string())?;
let magnitude = envelope(&signal).map_err(|e| e.to_string())?;
// 同じ包絡線を hilbert の結果から出力先を指定する API で求める。
let mut from_analytic = vec![0.0; n];
complex_envelope_into(
    &analytic,
    &mut from_analytic,
    ExecutionContext::sequential(),
)
.map_err(|e| e.to_string())?;

// 誤差は a(t) ≥ 0.1 の範囲で測る。
let inside = |i: usize| amplitude(time(i)) >= 0.1;

        // 隣り合う標本の位相差 arg(z_{n+1} conj z_n) を中点の瞬時周波数とする。
        let estimate = fs / tau * (analytic[i + 1] * analytic[i].conj()).arg();
        let midpoint = time(i) + 0.5 / fs;
        if inside(i) && inside(i + 1) {
            frequency_gap = frequency_gap.max((estimate - frequency(midpoint)).abs());
        }
        frequency_points.push([midpoint, estimate]);
    }
}

emit_line_chart!(
```

$a \ge 0.1$ の範囲で、$\lvert z \rvert$ と $a(t)$ の差の最大は $1.8\times10^{-9}$、瞬時周波数の誤差の最大は $1.6\times10^{-6}$ Hz である。
包絡線の帯域（標準偏差 $1/(2\pi w) \approx 1.6$ Hz）は $f_0 = 100$ Hz より十分狭く、Bedrosian の条件による誤差は無視できる。
残る誤差は、記録の端に残る振幅 $a(0) = 3.7\times10^{-6}$ が周期延長で作る跳びから来る。
$w = 0.04$ s にすると $a(0)$ は $1.2\times10^{-34}$ まで下がり、包絡線の誤差は $4.9\times10^{-15}$、瞬時周波数の誤差は $4.3\times10^{-12}$ Hz と丸め誤差の水準になる。

$w = 0.3$ s では $a(0) = 0.25$ で、周期延長の跳びが大きい。
包絡線の誤差は $3.7\times10^{-2}$、瞬時周波数の誤差は 27.5 Hz に増える。
$c = 200$ Hz/s では、$t = 0$ の瞬時周波数が 0 Hz まで下がり、包絡線の誤差は $1.4\times10^{-7}$、瞬時周波数の誤差は $7.7\times10^{-5}$ Hz になる。
$c = 0$（一定の 100 Hz）では、それぞれ $8.1\times10^{-10}$ と $7.2\times10^{-7}$ Hz である。
どの場合も、誤差を決めるのは端の扱いと、包絡線の帯域と瞬時周波数の比である。

## 単一象限の解析信号

多次元の信号では、「負の周波数」が一通りに決まらない。
2 次元の周波数 $(k_1, k_2)$ には 4 つの象限があり、実数の信号のスペクトルは原点について対称な 2 つの象限に同じ情報を持つ。
Hahn の単一象限の解析信号は選んだ軸ごとの 1 次元の重みの積

$$
W_{k_1, \dots, k_d} = \prod_{j} w^{(j)}_{k_j}
$$

を DFT に掛けて逆変換する（$w^{(j)}$ は軸 $j$ の長さに対する前節の重み）。
結果のスペクトルは、選んだすべての軸で周波数が非負の象限だけに残る。

軸を 1 つだけ選べば、各行（または列）に前節の 1 次元の解析信号を適用したものと同じで、実部は入力に一致する。
軸を 2 つ以上選ぶと、実部は一般に入力と一致しない。
2 次元の平面波 $\cos(\boldsymbol{k}\cdot\boldsymbol{x})$ では、$e^{i\boldsymbol{k}\cdot\boldsymbol{x}}$ と $e^{-i\boldsymbol{k}\cdot\boldsymbol{x}}$ の 2 つの成分のどちらか一方だけが重み $w_{k_1} w_{k_2}$ を受ける。
$k_1, k_2 > 0$ なら重みは $2 \cdot 2 = 4$ で、$z = 2e^{i\boldsymbol{k}\cdot\boldsymbol{x}}$ となり、$\lvert z \rvert = 2$ である。
$k_1 > 0 > k_2$ のように 2 つの成分がともに残らない象限にあると、$z = 0$ になる。
単一象限の解析信号は向きに依存するので、向きのそろわない模様の局所振幅には向かない。
向きに依らない振幅には次節の monogenic 信号を使う。

`AnalyticSignalNdPlan::new(shape, axes, options)` は、配列の形 `shape` と選んだ軸 `axes` に対して FFT の Plan を準備する。
選ばなかった軸は独立なバッチとして扱う。
`analytic(input)` は行優先の複素配列を確保して返し、`analytic_into(input, output, ws, cx)` と `envelope_into(input, output, ws, cx)` は、`workspace(())` で確保した作業領域を使って、呼び出し側の出力（ストライド付きのビューでよい）に書く。
Plan の準備には確保が要るが、十分な作業領域を渡した実行は確保しない。
`build(shape, axes, options, cx)` は、FFT の Plan を実行コンテキスト `cx` の取り消しと期限のもとで準備する。
軸が空か重複している、選んだ軸の長さが 0 のときは `InvalidInput`、軸が配列の次元以上なら `OutOfBounds` を返す。
`hilbert` と `envelope` は、1 次元の Plan をその場で作って 1 回実行するワンショット呼び出しの形で、同じ長さの記録を繰り返し処理するなら Plan を作り置きする。
計算量は要素数 $M$ に対して $O(M \log M)$ である。

## Riesz 変換と monogenic 信号

Riesz 変換は Hilbert 変換を向きに依らない形で多次元へ広げる。
選んだ軸が $d$ 本のとき成分は $d$ 個あり、成分 $j$ の周波数応答は

$$
\widehat{R_j f}(\boldsymbol{\omega}) = -i\,\frac{\omega_j}{\lvert\boldsymbol{\omega}\rvert}\,\hat f(\boldsymbol{\omega}),
\qquad \omega_j = \frac{k_j}{n_j h_j},
\qquad \lvert\boldsymbol{\omega}\rvert^2 = \sum_i \omega_i^2
$$

である。
$k_j$ は軸 $j$ の符号付きの周波数の添字（$(-n_j/2, n_j/2]$）、$n_j$ は軸の長さ、$h_j$ は標本間隔である。
$\omega_j$ は標本間隔の逆数を単位とする周波数で、間隔が軸ごとに違えば同じ添字でも向きが変わる。
等方的な模様を正しい向きで扱うには、物理的な間隔を `spacing` に渡す。
1 次元では $\omega_j / \lvert\omega\rvert = \mathrm{sgn}(k)$ なので、Riesz 変換は前節の周期的な Hilbert 変換と一致する。

成分 $j$ の応答は $k_j = 0$ のビンと、$n_j$ が偶数のときの $k_j = n_j/2$ のビンで 0 にする。
1 次元の Nyquist のビンと同じく、自分自身と対になるビンに純虚数を掛けると、実数の入力から実数の成分が得られなくなるからである。
すべての軸で $k = 0$ の DC はどの成分にも寄与しない。

monogenic 信号は入力 $f$ と Riesz 成分を並べた組 $(f, R_1 f, \dots, R_d f)$ である。
2 次元では、局所振幅 $A = \sqrt{f^2 + (R_1 f)^2 + (R_2 f)^2}$、局所位相 $\varphi = \operatorname{atan2}(\lvert Rf \rvert, f)$、局所方向 $\theta = \operatorname{atan2}(R_2 f, R_1 f)$ を与える。
平面波 $f = \cos(\boldsymbol{k}\cdot\boldsymbol{x})$ では $R_j f = (k_j/\lvert\boldsymbol{k}\rvert)\sin(\boldsymbol{k}\cdot\boldsymbol{x})$ なので、局所振幅はどこでも 1 になり、局所方向は波数ベクトルの向きになる。
$\sin(\boldsymbol{k}\cdot\boldsymbol{x})$ の符号で $\theta$ は $180°$ だけ反転するので、向きを場全体で 1 つの値にまとめるときは、2 倍角の平均

$$
\bar\theta = \tfrac12\operatorname{atan2}\left(\textstyle\sum 2 R_1 f\,R_2 f,\ \sum \left((R_1 f)^2 - (R_2 f)^2\right)\right)
$$

を使う（$180°$ を法とする向き）。

`RieszPlan::new(shape, axes, spacing, options)` は、成分ごとの乗数を準備時に 1 回だけ計算して保持する（$d$ 本の軸と $M$ 要素で $dM$ 個の実数）。
出力の形は、Riesz 変換が `output_shape()`（先頭に長さ $d$ の成分の軸、続いて入力の形）、monogenic 信号が `monogenic_shape()`（先頭の長さが $d + 1$）で、どちらも行優先である。
成分は `axes` に書いた順に並び、monogenic 信号では入力が先頭に来る。
`riesz(input)` と `riesz_into` は実数と複素数の入力を受け取り、実数の入力の成分は実数になる。
`monogenic(input)` と `monogenic_into` は実数の入力に限る。
1 回の実行は順方向の FFT 1 回と成分ごとの逆 FFT で、計算量は $O((d + 1) M \log M)$ である。
ワンショット呼び出しの `riesz_nd(input, axes, spacing)` と `monogenic_nd(input, axes, spacing)` は、Plan をその場で作って 1 回実行する。
`spacing` の長さが `axes` と違うと `DimensionMismatch`、正でない間隔は `InvalidInput`、非有限の間隔は `NonFinite` を返す。

次のセルは、$32 \times 32$ の周期的な格子の平面波 $f = \cos(\boldsymbol{k}\cdot\boldsymbol{x})$ について、`RieszPlan` で monogenic 信号を求め、局所振幅、Riesz 成分、局所方向を解析解と比べる。
入力は格子の一辺あたりの周期の数 $m_x$、$m_y$ と、$y$ 方向の標本間隔 $h_y$ [m] で、$x$ 方向の間隔は 1 m に固定する。
物理的な波数ベクトルは $(k_x, k_y) = (m_x/(n_x h_x), m_y/(n_y h_y))$ である。
同じ平面波に 2 つの軸の `AnalyticSignalNdPlan` も適用し、$\lvert z \rvert$ を前節の予測（$2$、$1$、$0$ のいずれか）と比べる。
ワンショット呼び出しの `monogenic_nd` の結果が Plan の結果と一致することも確かめる。

```rust
//| id: signal-monogenic-plane-wave
//| ref: signal-monogenic-plane-wave
//| title: 平面波の monogenic 信号と単一象限の解析信号
//| run: reactive
//| crates: [scioxide-core, scioxide-signal]
//| inputs:
//|   wave_x: {"type":"range","label":"x 方向の周期の数 m_x [-]","description":"格子の一辺あたりの周期の数。","min":0,"max":6,"step":1,"value":3}
//|   wave_y: {"type":"range","label":"y 方向の周期の数 m_y [-]","description":"負の値は波数ベクトルが第 4 象限を向く。","min":-6,"max":6,"step":1,"value":2}
//|   spacing_y: {"type":"range","label":"y 方向の標本間隔 h_y [m]","description":"x 方向の間隔は 1 m に固定する。","min":0.5,"max":2,"step":0.5,"value":1}
//| cases:
//|   - {"id":"fourth-quadrant","label":"m_y = −2（第 4 象限）","description":"monogenic 信号は変わらず振幅 1 を返すが、単一象限の解析信号は 0 になる。","inputs":{"wave_y":-2}}
//|   - {"id":"fine-y-spacing","label":"h_y = 0.5 m","description":"物理的な波数ベクトルが y 方向に倒れ、向きが 33.7° から 53.1° に変わる。","inputs":{"spacing_y":0.5}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"monogenic","path":"/rows/0/3","range":{"min":-1e-13,"max":1e-13}}
//|       - {"artifact":"monogenic","path":"/rows/1/3","range":{"min":-1e-13,"max":1e-13}}
//|       - {"artifact":"monogenic","path":"/rows/2/1","approx":{"value":33.69,"atol":0.01}}
//|       - {"artifact":"monogenic","path":"/rows/2/3","range":{"min":-1e-10,"max":1e-10}}
//|       - {"artifact":"monogenic","path":"/rows/3/1","approx":{"value":2.0,"atol":1e-12}}
//|       - {"artifact":"monogenic","path":"/rows/5/3","range":{"max":1e-13}}
//|       - {"artifact":"monogenic","path":"/rows/6/3","equals":0}
//|   - case: fourth-quadrant
//|     expect:
//|       - {"artifact":"monogenic","path":"/rows/0/3","range":{"min":-1e-13,"max":1e-13}}
//|       - {"artifact":"monogenic","path":"/rows/2/1","approx":{"value":146.31,"atol":0.01}}
//|       - {"artifact":"monogenic","path":"/rows/4/1","range":{"max":1e-13}}
//|   - case: fine-y-spacing
//|     expect:
//|       - {"artifact":"monogenic","path":"/rows/2/1","approx":{"value":53.13,"atol":0.01}}
use scioxide_core::{NdView, StridedLayout};
use scioxide_signal::{AnalyticSignalNdPlan, RieszPlan, SignalExecutionOptions, monogenic_nd};

let (ny, nx) = (32_usize, 32_usize);
let (mx, my, hy) = (wave_x.round(), wave_y.round(), spacing_y);
if mx == 0.0 && my == 0.0 {
    return Err("定数場では Riesz 成分が 0 になる。どちらかの周期の数を 0 以外にする".to_owned());
}
// 行優先 [y][x] の平面波。物理的な波数ベクトルは (m_x/(n_x h_x), m_y/(n_y h_y))。
let phase = |p: usize| {
    let (i, j) = ((p / nx) as f64, (p % nx) as f64);
    std::f64::consts::TAU * (mx * j / nx as f64 + my * i / ny as f64)
};
let size = ny * nx;
let data: Vec<f64> = (0..size).map(|p| phase(p).cos()).collect();
let (shape, strides) = ([ny, nx], [nx, 1]);
let view = NdView::new(
    &data,
    StridedLayout::new(&shape, &strides).map_err(|e| e.to_string())?,
)
.map_err(|e| e.to_string())?;

// 軸 0 が y、軸 1 が x。monogenic 信号は [f, R_y f, R_x f] の順に並ぶ。
let options = SignalExecutionOptions::new();
let plan = RieszPlan::new(&shape, &[0, 1], &[hy, 1.0], options).map_err(|e| e.to_string())?;
let out = plan.monogenic(view).map_err(|e| e.to_string())?;
let one_shot = monogenic_nd(view, &[0, 1], &[hy, 1.0]).map_err(|e| e.to_string())?;
let orthant = AnalyticSignalNdPlan::new(&shape, &[0, 1], options)
    .and_then(|plan| plan.analytic(view))
    .map_err(|e| e.to_string())?;

let (ky, kx) = (my / (ny as f64 * hy), mx / nx as f64);
let norm = ky.hypot(kx);
let (mut a_min, mut a_max, mut component_gap) = (f64::INFINITY, 0.0_f64, 0.0_f64);
let (mut z_min, mut z_max, mut plan_gap) = (f64::INFINITY, 0.0_f64, 0.0_f64);
let (mut cross, mut difference) = (0.0, 0.0);
for p in 0..size {
    let (f, ry, rx) = (out[p], out[size + p], out[2 * size + p]);
    let amplitude = (f * f + ry * ry + rx * rx).sqrt();
    (a_min, a_max) = (a_min.min(amplitude), a_max.max(amplitude));
    let s = phase(p).sin();
    component_gap = component_gap.max((ry - ky / norm * s).abs().max((rx - kx / norm * s).abs()));
    // 2 倍角の和で、sin の符号による 180° の反転を打ち消す。
    cross += 2.0 * rx * ry;
    difference += rx * rx - ry * ry;
    (z_min, z_max) = (z_min.min(orthant[p].norm()), z_max.max(orthant[p].norm()));
}
for (a, b) in out.iter().zip(&one_shot) {
    plan_gap = plan_gap.max((a - b).abs());
}
let degrees = |angle: f64| angle.to_degrees().rem_euclid(180.0);
let orientation = degrees(0.5 * cross.atan2(difference));
let expected_orientation = degrees(ky.atan2(kx));
// 単一象限の重み: 1 次元の重み w(m) の積。2 つの成分のうち残る方の係数の半分が |z|。
let w = |m: f64| {
    if m > 0.0 {
        2.0_f64
    } else if m == 0.0 {
        1.0
    } else {
        0.0
    }
};
let expected_z = (w(mx) * w(my)).max(w(-mx) * w(-my)) / 2.0;

let fixed6 = serde_json::json!({ "significantDigits": 6 });
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let columns = serde_json::json!([
    { "key": "0", "label": "量" },
    { "key": "1", "label": "計算値", "type": "number", "format": fixed6, "nullText": "—" },
    { "key": "2", "label": "解析値", "type": "number", "format": fixed6, "nullText": "—" },
    { "key": "3", "label": "差", "type": "number", "format": sci2 }
]);
let row =
    |name: &str, value: f64, exact: f64| (name.to_owned(), Some(value), Some(exact), value - exact);
let rows = vec![
    row("局所振幅 A の最小 [-]", a_min, 1.0),
    row("局所振幅 A の最大 [-]", a_max, 1.0),
    row("局所方向 θ̄ [度]", orientation, expected_orientation),
    row("単一象限の |z| の最小 [-]", z_min, expected_z),
    row("単一象限の |z| の最大 [-]", z_max, expected_z),
    (
        "R_x f、R_y f と解析解の差の最大 [-]".to_owned(),
        None,
        None,
        component_gap,
    ),
    (
        "monogenic_nd と Plan の差の最大 [-]".to_owned(),
        None,
        None,
        plan_gap,
    ),
];
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "monogenic" })
);
```

既定の $(m_x, m_y) = (3, 2)$、$h_y = 1$ m では、局所振幅は $1 - 1.3\times10^{-15}$ から $1 + 8.9\times10^{-16}$ の範囲にあり、Riesz 成分と解析解の差の最大は $1.8\times10^{-15}$ である。
局所方向は $33.69°$ で、波数ベクトルの向き $\operatorname{atan2}(k_y, k_x)$ と $5\times10^{-14}$ 度の差で一致する。
単一象限の解析信号は $\lvert z \rvert = 2$ を $2.7\times10^{-15}$ の差で返し、実部は入力の 2 倍になる。
Plan と `monogenic_nd` の結果の差は 0 である。

$m_y = -2$ にすると、波数ベクトルは第 4 象限を向き、局所方向は $146.31°$ になる。
monogenic 信号の局所振幅は 1 のままだが、単一象限の解析信号の $\lvert z \rvert$ は最大でも $2.4\times10^{-15}$ で、平面波が消える。
$m_x = 0$（$y$ 方向だけに変化する波）では、$x$ 軸の重みが DC の 1 なので $\lvert z \rvert = 1$ になる。
$h_y = 0.5$ m では、物理的な波数 $k_y$ が 2 倍になり、局所方向は $33.69°$ から $53.13°$ に変わる。
同じ格子の添字でも、標本間隔を渡さなければ向きを誤ることがわかる。
周期の数が整数でない平面波は格子の周期に合わず、周期延長が不連続になるので、この一致は成り立たない。

## ベクトル強度

神経の発火、心拍、地震の発生時刻のような事象の列が、ある周期 $T$ の刺激にどれだけ同期しているかを測りたいことがある。
事象の時刻 $t_1, \dots, t_N$ を周期で割った余りから位相 $\theta_k = 2\pi (t_k \bmod T)/T$ を作り、単位円上の点 $e^{i\theta_k}$ の平均

$$
R = \frac{1}{N}\sum_{k=1}^{N} e^{i\theta_k}
$$

を平均合成ベクトルと呼ぶ。
ベクトル強度は $\lvert R \rvert \in [0, 1]$ で、すべての事象が同じ位相にあれば 1、位相が周期の上に一様に散らばれば 0 に近い。
平均位相は $\arg R \in [-\pi, \pi]$ で、$t \equiv 0 \pmod T$ の時刻を位相 0 とする。

事象の時刻と周期は同じ時間の単位で渡し、強度は無次元、位相はラジアンになる。
周期の代わりに周波数で走査するときは、$T = 1/f$ を時刻と同じ単位で作る（時刻が ms なら $T = 1000/f$ ms）。
余りは角度に直す前に周期の単位で取るので、大きな時刻に含まれる丸め誤差は位相に $2\pi\,\delta t/T$ として残る。
たとえば $t \approx 10^9$ s の倍精度の間隔 $\delta t \approx 1.2\times10^{-7}$ s は、$T = 2$ ms の位相では $3.7\times10^{-4}$ rad になる。
記録の開始時刻のような基準を先に引いてから渡す。

位相の散らばりを正規分布（標準偏差 $\sigma$ の時間の揺らぎ）で表すと、巻き込み正規分布の性質から $\mathrm{E}\,\lvert R\rvert \approx \rho = \exp(-(2\pi\sigma/T)^2/2)$ である。
$N$ が大きいとき、$\lvert R \rvert$ の標準誤差は、平均方向の成分の分散から $\mathrm{SE} \approx (1 - \rho^2)/\sqrt{2N}$ と見積もれる。
位相が一様に散らばっているという帰無仮説の検定には、Rayleigh の統計量 $Z = N\lvert R \rvert^2$ を使い、$N$ が大きいときの $p$ 値の近似は $e^{-Z}$ である。
$N$ が小さいときは補正項を加えた式を使う。

`vector_strength(events, period)` は 1 つの周期の $R$ を `VectorStrength` で返し、`strength()` が $\lvert R \rvert$、`phase()` が $\arg R$ を与える。
$R$ がちょうど 0 のとき位相は定まらないので、`phase()` は `None` を返す。
`vector_strength_into(events, periods, output, cx)` は複数の周期をまとめて計算し、`output[j]` に `periods[j]` の結果を書く。
計算量は事象の数 $N$ と周期の数 $P$ に対して $O(NP)$ で、和は補償付きで足す。
事象は並べ替えていなくてよい。
空の事象は `InvalidInput`（`Empty`）、正でない周期は `InvalidInput`（`OutOfRange`）、非有限の時刻や周期は `NonFinite`、出力が周期の数より短いと `DimensionMismatch` を返す。
`vector_strength_into` は、すべての周期の結果を確かめてから出力に書くので、エラーのときは出力を変えない。
`VectorStrength::default()` は強度 0、位相 `None` の値で、出力の領域の初期化に使う。

次のセルは 500 Hz の純音に同期して発火する聴神経の線維を模した合成データで、ベクトル強度を確かめる。
周期は $T = 2$ ms で、各周期に 1 回、位相 $\pi/2$（周期の始まりから 0.5 ms）を中心に標準偏差 $\sigma$ の正規分布の揺らぎで発火する。
時刻の単位は ms である。
入力は揺らぎ $\sigma$ [ms]、周期の数 $N$、乱数のシードである。
`vector_strength` で $T = 2$ ms の強度と位相を求めて理論値 $\rho$、標準誤差、Rayleigh の統計量と並べ、`vector_strength_into` で 490〜510 Hz の 201 個の周波数を走査する。

```rust
//| id: signal-vector-strength
//| ref: signal-vector-strength
//| title: 500 Hz の純音に同期する発火時刻のベクトル強度
//| run: reactive
//| crates: [scioxide-core, scioxide-random, scioxide-signal]
//| inputs:
//|   jitter: {"type":"range","label":"発火時刻の揺らぎ σ [ms]","description":"正規分布の標準偏差。","min":0.05,"max":1,"step":0.05,"value":0.2}
//|   cycles: {"type":"range","label":"周期の数 N [-]","description":"発火の回数（各周期に 1 回）。","min":50,"max":800,"step":50,"value":200}
//|   seed: {"type":"range","label":"乱数のシード","min":1,"max":100,"step":1,"value":7}
//| cases:
//|   - {"id":"weak-locking","label":"σ = 1 ms（ほぼ一様）","description":"理論値 ρ は 0.0072 で、Rayleigh の統計量は同期を示さない。","inputs":{"jitter":1}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"strength","path":"/rows/0/2","approx":{"value":0.8209,"atol":1e-4}}
//|       - {"artifact":"strength","path":"/rows/0/4","range":{"min":-3,"max":3}}
//|       - {"artifact":"strength","path":"/rows/1/1","approx":{"value":1.5708,"atol":0.05}}
//|       - {"artifact":"scan","path":"/spec/series/0/points/100/1","range":{"min":0.7}}
//|   - case: weak-locking
//|     expect:
//|       - {"artifact":"strength","path":"/rows/0/2","approx":{"value":0.00719,"atol":1e-4}}
//|       - {"artifact":"strength","path":"/rows/0/4","equals":null}
//|       - {"artifact":"rayleigh","path":"/rows/0/2","range":{"min":0.05}}
use scioxide_core::ExecutionContext;
use scioxide_random::{Distribution, Normal, SeedableRng, SplitMix64};
use scioxide_signal::{VectorStrength, vector_strength, vector_strength_into};

// 周期 T = 2 ms（500 Hz）。各周期の 0.5 ms 後（位相 π/2）を中心に発火する。
let period = 2.0_f64;
let n = cycles.round() as usize;
let mut rng = SplitMix64::from_seed(seed as u64);
let noise = Normal::new(0.0, jitter).map_err(|e| e.to_string())?;
let mut events = Vec::with_capacity(n);
for k in 0..n {
    let delay = noise.sample(&mut rng).map_err(|e| e.to_string())?;
    events.push(k as f64 * period + 0.5 + delay);
}

let locked = vector_strength(&events, period).map_err(|e| e.to_string())?;
let strength = locked.strength();
// 巻き込み正規分布の理論値と、平均方向の成分の分散から見積もる標準誤差。
let rho = (-0.5 * (std::f64::consts::TAU * jitter / period).powi(2)).exp();
let standard_error = (1.0 - rho * rho) / (2.0 * n as f64).sqrt();
let rayleigh = n as f64 * strength * strength;
// 正規近似は ρ√N が十分大きいときだけ使う。一様に近いときは Rayleigh の統計量で判断する。
let z_score = (rho * (n as f64).sqrt() >= 3.0).then(|| (strength - rho) / standard_error);

// 490〜510 Hz を 0.1 Hz 刻みで走査する。周期は時刻と同じ ms で渡す。
let frequencies: Vec<f64> = (0..=200).map(|i| 490.0 + 0.1 * i as f64).collect();
let periods: Vec<f64> = frequencies.iter().map(|f| 1000.0 / f).collect();
let mut scan = vec![VectorStrength::default(); periods.len()];
vector_strength_into(&events, &periods, &mut scan, ExecutionContext::sequential())
    .map_err(|e| e.to_string())?;
let points: Vec<[f64; 2]> = frequencies
    .iter()
    .zip(&scan)
    .map(|(&f, result)| [f, result.strength()])
    .collect();

let fixed4 = serde_json::json!({ "significantDigits": 4 });
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let columns = serde_json::json!([
    { "key": "0", "label": "量" },
    { "key": "1", "label": "計算値", "type": "number", "format": fixed4, "nullText": "未定義" },
    { "key": "2", "label": "理論値", "type": "number", "format": fixed4, "nullText": "—" },
    { "key": "3", "label": "標準誤差", "type": "number", "format": fixed4, "nullText": "—" },
    { "key": "4", "label": "(計算値 − 理論値)/SE", "type": "number", "format": fixed4, "nullText": "—" }
]);
let rows = vec![
    (
        "強度 |R| [-]".to_owned(),
        Some(strength),
        Some(rho),
        z_score.map(|_| standard_error),
        z_score,
    ),
    (
        "平均位相 arg R [rad]".to_owned(),
        locked.phase(),
```

既定の $\sigma = 0.2$ ms、$N = 200$、シード 7 では、強度は $0.8142$ で、理論値 $\rho = 0.8209$ との差は標準誤差 $0.0163$ の $-0.41$ 倍である。
平均位相は $1.594$ rad で、発火の中心の位相 $\pi/2 \approx 1.571$ rad に近い。
Rayleigh の統計量は $Z = 132.6$、$p$ 値の近似は $2.6\times10^{-58}$ で、位相が一様に散らばっているという仮説は退けられる。
$N = 800$ では強度が $0.8188$、標準誤差が $0.0082$ になり、差は標準誤差の $-0.25$ 倍で、推定の揺らぎは $1/\sqrt{N}$ に比例して小さくなる。

走査の図は 500 Hz で最大 $0.814$ を取り、499 Hz と 501 Hz では $0.607$ と $0.616$ に下がる。
記録の長さ $D = NT = 0.4$ s に対し、周波数を $\Delta f$ ずらすと位相が記録の中で $2\pi\Delta f\,t$ だけ回るので、強度はおよそ $\rho\,\lvert\mathrm{sinc}(\pi\Delta f D)\rvert$ で下がる。
$\Delta f = 1$ Hz では $0.821 \times 0.757 \approx 0.62$ で、図の値と合う。
周期の分解能は記録の長さの逆数 $1/D$ で決まり、事象の数を増やしても同じ記録の長さなら細かくならない。

$\sigma = 1$ ms では $\rho = 0.0072$ で、位相はほぼ一様に散らばる。
強度は $0.030$、$Z = 0.185$、$p$ 値の近似は $0.83$ で、同期は検出されない。
一様な位相でも $\lvert R \rvert$ は 0 にならず、平均がおよそ $\sqrt{\pi/(4N)} \approx 0.063$ の正の値を取る。
このように $\rho\sqrt{N}$ が小さいときは正規近似の標準誤差が使えないので、表では標準誤差と比を「—」とし、Rayleigh の統計量で判断する。

## まとめ

`hilbert` と `envelope` は、記録を 1 周期とみなし、DC と偶数長の Nyquist のビンを残して正の周波数を 2 倍する重みで解析信号を作る。
実部は入力とビット単位で一致し、包絡線と瞬時周波数は、包絡線の帯域が搬送波の周波数より狭く、記録の両端がつながるときに読める。
多次元では、単一象限の解析信号（`AnalyticSignalNdPlan`）は向きに依存し、向きに依らない局所振幅と局所方向には `RieszPlan` の monogenic 信号を、物理的な標本間隔とともに使う。
事象の時刻の周期への同期は、`vector_strength` の強度と位相で測り、Rayleigh の統計量と標準誤差の見積もりで偶然の大きさと比べる。

Bedrosian の条件が崩れたときに包絡線がどう誤るかは、[Hilbert 変換による包絡線の復元](../../examples/hilbert-envelope/)で確かめる。
時間とともに周波数が変わる信号を、解析信号ではなくウインドウを掛けた Fourier 変換で追う方法は、[短時間 Fourier 変換](../stft/)で比べる。
