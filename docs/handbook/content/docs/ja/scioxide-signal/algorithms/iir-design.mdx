無限インパルス応答（IIR）フィルタは、過去の出力も使う差分方程式

$$
\sum_{j=0}^{N} a_j\, y[k-j] = \sum_{i=0}^{M} b_i\, x[k-i], \qquad a_0 = 1
$$

で表され、伝達関数は $H(z) = B(z)/A(z)$（$B$、$A$ は $z^{-1}$ の多項式）である。
極（$A$ の零点）を持つので、同じ遮断の鋭さを FIR よりずっと少ない係数で実現できる。
その代わり位相は線形にならず、極が単位円の外に出れば出力が発散する。

古典的な IIR の設計は連続時間（アナログ）のフィルタの近似理論を借りる。
遮断 1 の低域通過プロトタイプを選び、周波数の変換で目的の帯域に移し、双一次変換で離散時間に写す。
このページはこの三段階と、仕様から次数を選ぶ方法、特定の周波数を除く・通す共振器を扱う。
設計したフィルタを記録に適用する方法は[IIR フィルタの実行とゼロ位相](../iir-filtering-and-zero-phase/)で扱う。

周波数の単位は章全体の規約に従う。
アナログの周波数は角周波数 $\omega$ [rad/時間単位] で $s = i\omega$ で評価し、デジタルの周波数は Nyquist 比 $f$ で $z = e^{i\pi f}$ で評価する。
`IirDomain::Analog` は $s$ の関数で極の実部が負なら安定、`IirDomain::Digital` は $z$ の関数で極の絶対値が 1 未満なら安定である。

## アナログ低域通過プロトタイプ

`iir_prototype(order, family)` は、次数 $N$ の低域通過プロトタイプを零点・極・利得の形 `PoleZeroGain`（領域は `Analog`）で返す。
`IirFamily` は五つの族を持ち、どれも特性周波数を $\omega = 1$ に置き、通過域の最大の振幅を 1 にそろえる。
リプルと減衰量は dB で与え、$\varepsilon_p^2 = 10^{R/10} - 1$（$R$ は通過域のリプル）、$\varepsilon_s^2 = 10^{A/10} - 1$（$A$ は阻止域の最小減衰量）とおく。

| 族 | 振幅の二乗 $\lvert H(i\omega) \rvert^2$ | $\omega = 1$ の意味 | 極と零点 |
|---|---|---|---|
| `Butterworth` | $\dfrac{1}{1 + \omega^{2N}}$ | 半電力点 | 単位円上の極、有限の零点なし |
| `ChebyshevI { ripple }` | $\dfrac{1}{1 + \varepsilon_p^2 T_N^2(\omega)}$ | 通過域の端 | 楕円上の極、有限の零点なし |
| `ChebyshevII { attenuation }` | $\dfrac{1}{1 + \varepsilon_s^2 / T_N^2(1/\omega)}$ | 阻止域の端 | 虚軸上の零点 $\omega = 1/\cos\theta_k$ |
| `Elliptic { ripple, attenuation }` | $\dfrac{1}{1 + \varepsilon_p^2 R_N^2(\omega)}$ | 通過域の端 | 虚軸上の零点、通過域と阻止域で等リプル |
| `Bessel(normalization)` | 閉じた形を持たない | 正規化による | 有限の零点なし |

$T_N$ は $N$ 次の Chebyshev 多項式、$R_N$ は楕円有理関数、$\theta_k = (2k+1)\pi/(2N)$（$k = 0, \dots, N-1$）である。
各族の性質は次のとおりである。

- Butterworth は $\omega = 0$ で振幅の $2N - 1$ 階までの導関数が 0 になる（最大平坦）。
  極は $p_k = -\sin\theta_k + i\cos\theta_k$ で、単位円の左半分に等間隔に並ぶ。
- Chebyshev I 型は通過域 $0 \le \omega \le 1$ で $1$ と $1/\sqrt{1 + \varepsilon_p^2}$ の間を等リプルで振動し、阻止域で単調に減る。
  $\mu = \operatorname{asinh}(1/\varepsilon_p)/N$ として、極は $-\sinh\mu \sin\theta_k + i\cosh\mu \cos\theta_k$ である。
  偶数次では直流の利得が $1/\sqrt{1 + \varepsilon_p^2}$ になる。
- Chebyshev II 型は通過域で単調、$\omega \ge 1$ の阻止域で等リプルになり、阻止域の端 $\omega = 1$ で振幅の二乗がちょうど $10^{-A/10}$ になる。
  極は I 型の式で $\varepsilon_p$ を $1/\varepsilon_s$ に替えた点の逆数である。
- 楕円（Cauer）は両方の帯域で等リプルになり、同じ次数・リプル・減衰量の中で遷移帯が最も狭い。
  阻止域の端は $\omega_s = 1/\sqrt{m}$ で、母数 $m$ は次数の方程式 $K(m)/K'(m) = N K(m_1)/K'(m_1)$（$m_1 = \varepsilon_p^2/\varepsilon_s^2$）を Brent 法で解いて求める。
  $K$ は第一種完全楕円積分、$K'(m) = K(1-m)$ で、極と零点は Jacobi の楕円関数から作る。
- Bessel（Thomson）は $H(s) = \theta_N(0)/\theta_N(s)$ で、$\theta_N(s) = \sum_{k=0}^{N} \frac{(N+k)!}{2^k\, k!\, (N-k)!} s^{N-k}$ は逆 Bessel 多項式である。
  $\omega = 0$ で群遅延が最大平坦になり、パルスの形を保ちやすい。
  極は Bessel 多項式の零点の逆数で、係数の打ち消しを避けた評価と Aberth–Ehrlich 法により `f64` で数 $\varepsilon$ の精度で求める。

`BesselNormalization` は Bessel プロトタイプの周波数の尺度を選ぶ。
`Delay` は低周波の群遅延を 1 に、`Phase` は極の絶対値の幾何平均を 1 にして高周波の漸近 $|H| \approx \omega^{-N}$ を Butterworth にそろえ、`Magnitude` は $|H(i)|^2 = 1/2$ にする。
`Magnitude` だけは正規化の方程式を Brent 法で解く。

次数 0、正でないリプルか減衰量、減衰量がリプル以下の楕円は `InvalidInput`、非有限の値は `NonFinite` になる。
楕円の母数や Bessel の正規化の方程式が収束しなければ `ConvergenceFailure` になる。
`iir_prototype_scoped` は最後の引数に実行コンテキストか外側の解法の `SolveContext` を取り、これらの反復をそのスコープの上限に数える。

## 帯域の変換

`IirBand` は設計の帯域で、各端はプロトタイプの $\omega = 1$ の像である。
`PoleZeroGain::transform(band)` はアナログのプロトタイプの $s$ を次のように置き換える。

| `IirBand` | 置換 |
|---|---|
| `Lowpass(ω_c)` | $s \to s/\omega_c$ |
| `Highpass(ω_c)` | $s \to \omega_c/s$ |
| `Bandpass(ω₁, ω₂)` | $s \to (s^2 + \omega_0^2)/(B s)$ |
| `Bandstop(ω₁, ω₂)` | $s \to B s/(s^2 + \omega_0^2)$ |

ここで $\omega_0 = \sqrt{\omega_1 \omega_2}$ は中心、$B = \omega_2 - \omega_1$ は帯域幅である。
帯域通過と帯域阻止では $s$ の二次式を代入するので、極の数がプロトタイプの 2 倍になる。
端は正で、帯域の端は $\omega_1 < \omega_2$ でなければ `InvalidInput` になる。
利得は拡張した指数の範囲で尺度を戻してから一度だけ丸めるので、途中のオーバーフローやアンダーフローで表せる結果を失わない。

## 双一次変換と事前ワーピング

積分器 $y(t) = \int_0^t x(\tau)\, d\tau$ に標本化周期 $T$ の台形公式を当てはめると

$$
y[k] - y[k-1] = \frac{T}{2}\bigl(x[k] + x[k-1]\bigr)
$$

となる。
$z$ 変換を取ると、積分器の伝達関数 $1/s$ が $\frac{T}{2} \frac{1 + z^{-1}}{1 - z^{-1}}$ に対応し、置換

$$
s = \frac{2}{T} \frac{1 - z^{-1}}{1 + z^{-1}} = \frac{2}{T} \frac{z - 1}{z + 1}
$$

が得られる。
これを**双一次変換**という。
逆に解くと $z = (1 + sT/2)/(1 - sT/2)$ なので、左半平面 $\operatorname{Re}s < 0$ は単位円の内部に、虚軸は単位円に一対一に写る。
安定なアナログプロトタイプは安定なデジタルフィルタになり、振幅のリプルの値も保たれる。

$s = i\Omega$、$z = e^{i\omega}$（$\omega$ は rad/標本）を代入すると

$$
i\Omega = \frac{2}{T} \frac{e^{i\omega} - 1}{e^{i\omega} + 1} = i \frac{2}{T} \tan\frac{\omega}{2}
$$

となり、アナログとデジタルの周波数は $\Omega = (2/T)\tan(\omega/2)$ で結ばれる。
デジタルの周波数 $\omega \in [0, \pi)$ が $\Omega \in [0, \infty)$ 全体に写るので、高い周波数ほど縮んで見える（周波数のゆがみ）。
そこで、デジタルの帯域端 $\omega_c$ を設計するときは、アナログ側の帯域端を $\Omega_c = (2/T)\tan(\omega_c/2)$ に置く。
これを**事前ワーピング**という。

`design_iir(order, family, band, domain)` は、`IirDomain::Digital` のとき帯域端 $f$（Nyquist 比、0 < $f$ < 1）を $\Omega = 2\tan(\pi f/2)$ に変換してから、$T = 1$ の双一次変換 $s = 2(z-1)/(z+1)$ を適用する。
したがって、帯域端でのデジタルの応答はプロトタイプの $\omega = 1$ での応答に一致し、任意の $f$ で

$$
H_d(f) = H_{\mathrm{proto}}\!\left(\frac{\tan(\pi f/2)}{\tan(\pi f_c/2)}\right) \qquad \text{（低域通過）}
$$

が成り立つ。
`IirDomain::Analog` のときは帯域端を角周波数のまま使い、双一次変換をしない。

`PoleZeroGain::bilinear(sample_rate)` は置換 $s = 2f_s(z-1)/(z+1)$ だけを行い、事前ワーピングをしない。
アナログの極か零点 $r$ は $(2f_s + r)/(2f_s - r)$ に、無限遠の零点は $z = -1$ に写る。
`r` が $2f_s$ に等しいと `NumericalInstability` になる。
Bessel の群遅延の平坦性は双一次変換で保たれず、遮断を Nyquist に近づけるほど崩れる（[群遅延の例題](../../examples/iir-group-delay-zero-phase/)）。

## 零点・極・利得と設計の結果

`design_iir` はプロトタイプの計算、帯域の変換、双一次変換を順に行い、`IirDesign` を返す。
楕円と Bessel の `Magnitude` の正規化はスカラー方程式を Brent 法で解き、`design_iir_scoped` はその反復を外側のスコープの上限に数える。

- `zpk()` は零点・極・利得 `PoleZeroGain` を返す。
  `PoleZeroGain::new(domain, zeros, poles, gain)` は根を与えたとおりに保ち、共通の根を消さず、不安定な極を反転しない。
  `response(f)` は根の因子の積で評価し、多項式に展開しない。
- `prototype_order()` はプロトタイプの次数で、帯域通過と帯域阻止では極の数がその 2 倍になる。
- `stability_margin()` は極と安定境界の最小距離で、アナログでは $-\operatorname{Re}p$、デジタルでは $1 - |p|$ である。
  安定性にどれだけ余裕があるかの目安で、誤差の上界ではない。
- `to_sos()` は根を二次節にまとめ、虚部（実数の設計の丸め誤差）を落とした実数の `SecondOrderSections` を返す。
  極は安定境界に近い順に取り、共役に最も近い極と組にし、近い零点を割り当てたあと、境界に近い節が最後に来るように並べ替える。
  根の組み合わせは極 $n$ 個に対して $O(n^2)$ の比較である。
  丸めた節の係数で極が厳密に安定でなければ `InvalidInput`、虚部が $\sqrt{\varepsilon}(1 + |\operatorname{Re}x|)$ を超えれば `DomainError` になる。

`TransferFunction::new(domain, b, a)` は分子 $b$ と分母 $a$ の係数を $a_0$ で割って保持する。
デジタルでは $z^{-1}$ の昇べき、アナログでは $s$ の降べきで並べる。
高次のフィルタの多項式の係数は根に対して悪条件なので、保存と適用には二次節を使う。
その理由と二次節の実行は[IIR フィルタの実行とゼロ位相](../iir-filtering-and-zero-phase/)で扱う。

`design_iir` は、次数 0、正でない帯域端、増加しない帯域端、1 以上のデジタルの帯域端、正でないリプルか減衰量を `InvalidInput` にする。
高次で遮断が低いと利得が正規の範囲より小さくなることがあり、そのときは `NumericalInstability`（`Underflow`）になる。
丸めた極が厳密に安定でなければ `NumericalInstability`（`LossOfSignificance`）になる。

### 帯域端での応答と周波数のゆがみ

次のセルは、族・次数 $N$・遮断 $f_c$ を入力として、デジタルの低域通過を `design_iir` で設計する。
同じ族のプロトタイプを `iir_prototype` で求め、デジタルの応答 $|H_d(f)|$ とプロトタイプの応答 $|H_{\mathrm{proto}}(\tan(\pi f/2)/\tan(\pi f_c/2))|$ を $0 \le f \le 0.99$ の 397 点で比べ、上の写像の式を確かめる。
Butterworth では閉じた形 $1/(1 + x^{2N})$（$x = \tan(\pi f/2)/\tan(\pi f_c/2)$）とも比べる。
表の $|H_d(f_c)|^2$ は、族ごとに意味の違う帯域端での値である。
図の破線は、周波数を線形に写したプロトタイプの応答 $|H_{\mathrm{proto}}(f/f_c)|$ で、実線との差が周波数のゆがみである。

既定の Butterworth、$N = 4$、$f_c = 0.5$ では、帯域端の $|H_d(f_c)|^2$ は $0.5$ で、プロトタイプの $|H(i)|^2$ と丸め誤差の範囲で一致する。
397 点でのデジタルの応答と写像の式の差の最大は $8.9 \times 10^{-16}$、閉じた形 $1/(1 + x^{2N})$ との差の最大は $1.8 \times 10^{-15}$ である。
この一致は丸め誤差の水準で、事前ワーピングの式が $f$ 全体で成り立つことを示す。
極は 4 個で 2 個の二次節にまとまり、安定余裕は $1 - \max|p| = 0.332$ である。

Chebyshev II 型では帯域端が阻止域の端なので $|H_d(f_c)|^2 = 1.0 \times 10^{-4}$（40 dB）になり、楕円と Chebyshev I 型では通過域の端なので $0.794$（1 dB の損失）になる。
Bessel の `Magnitude` の正規化では帯域端が半電力点になる。
図では、デジタルの応答が Nyquist に近づくほど線形に写したプロトタイプの応答より速く小さくなる。
Butterworth ではプロトタイプの無限遠の零点が $z = -1$ に写り、$f = 1$ で振幅が 0 になる。
楕円で $f_c = 0.8$ にすると安定余裕は $0.060$ まで小さくなり、極が単位円に近づく。

## 仕様からの次数の選択

フィルタの仕様は、通過域の端 $f_p$ で損失が $R$ dB 以下、阻止域の端 $f_s$ から先で減衰が $A$ dB 以上、という形で与えることが多い。
`select_iir_order(family, pass, stop, ripple, attenuation, domain)` は、この仕様を満たす最小の次数を選ぶ。
`pass` と `stop` は同じ種類の `IirBand` で、阻止域の端は低域通過なら通過域の端より上、高域通過なら下、帯域通過なら外側、帯域阻止なら内側に置く。
デジタルの端は `design_iir` と同じく事前ワーピングする。

仕様を、通過域の端が 1 の等価な低域通過プロトタイプの阻止域の端 $\Omega > 1$ に写す。
低域通過のデジタル設計では $\Omega = \tan(\pi f_s/2)/\tan(\pi f_p/2)$ で、帯域通過と帯域阻止では二つの阻止域の端から得る値の小さいほうを使う。
次数は次の実数解 $n^*$ 以上の最小の正の整数である。

$$
\begin{aligned}
\text{Butterworth:}\quad & n^* = \frac{\ln(\varepsilon_s^2/\varepsilon_p^2)}{2 \ln \Omega} \\
\text{Chebyshev I・II:}\quad & n^* = \frac{\operatorname{acosh}(\varepsilon_s/\varepsilon_p)}{\operatorname{acosh}\Omega} \\
\text{楕円:}\quad & n^* = \frac{K(1/\Omega^2)\, K'(\varepsilon_p^2/\varepsilon_s^2)}{K'(1/\Omega^2)\, K(\varepsilon_p^2/\varepsilon_s^2)}
\end{aligned}
$$

式の計算は $O(1)$ で、楕円の場合だけ完全楕円積分を評価する。
帯域阻止では、二つの阻止域の端の釣り合いを取るように通過域の端の一方を内側に動かし、次数を下げる。

`IirOrderFamily` は `Butterworth`、`ChebyshevI`、`ChebyshevII`、`Elliptic` の四つである。
Bessel は帯域端ではなく群遅延で仕様を書く族なので次数の方程式を持たず、次数を直接選ぶ。

結果の `IirOrderReport` はそのまま `design_iir` に渡せる三つの値を持つ。

- `order()`: 選んだプロトタイプの次数（帯域通過と帯域阻止では極の数がその 2 倍）
- `family()`: 指定したリップルと減衰量を入れた `IirFamily`
- `band()`: 設計に使う帯域端（入力と同じ単位）

Butterworth の `band()` は半電力点、Chebyshev II 型は阻止域の始まり、Chebyshev I 型と楕円は通過域の端である。
整数に切り上げた次数の余裕は、Butterworth と Chebyshev II 型では帯域端の位置の調整に使われる。
ほかに `termination()`、`is_success()`、楕円積分の評価の計数 `counts()`、次数不足 $\max(n^* - n, 0)$ の `order_deficit()`、結果の使える範囲 `trust()` を持つ。

`IirOrderTermination` は二つの値を取る。
`Selected` は選んだ次数が仕様を満たすことを、`OrderLimit` は必要な次数が上限を超えたことを示す。
三つの呼び出しの形は上限の扱いが違う。

- `select_iir_order` は上限を持たず、必要な次数が `usize` に収まらなければ `ConvergenceFailure`（`TruncationLimit`）を返す。
- `select_iir_order_with_options` は `IirOrderOptions::new().with_maximum_order(k)` の上限 $k$ を超える次数をエラーにせず、次数 $k$ と正の次数不足を持つ `OrderLimit` のレポートを返す。
  上限は必要な次数と比べるだけで、計算コストを変えない。
  既定の上限は `usize::MAX`（上限なし）で、上限 0 は `InvalidInput` になる。
- `select_iir_order_scoped` はオプション付き形式と同じ選択を外側のスコープの中で行い、楕円積分の評価をその上限に数える。

減衰量がリプル以下、正でない端やリプル、1 以上のデジタルの端、種類の違う帯域、阻止域の端の位置の誤りは `InvalidInput` になる。

### 四つの族の次数を比べる

次のセルは、通過域の端 $f_p$、遷移帯の幅 $\Delta$（阻止域の端 $f_s = f_p + \Delta$）、リプル $R$、減衰量 $A$、次数の上限を入力として、四つの族の次数を `select_iir_order_with_options` で選ぶ。
独立な検算として、上の式の $n^*$ を `f64` の参照計算で求める（完全楕円積分は算術幾何平均 $K(m) = \pi/(2\,\mathrm{AGM}(1, \sqrt{1-m}))$ で計算する）。
レポートの `order()`、`family()`、`band()` で `design_iir` を呼び、通過域の端の損失と、$[f_s, 0.999]$ を $10^{-3}$ 刻みにした格子での最小の減衰量を測る。
`OrderLimit` の行も上限の次数で設計し、仕様に届かないことを示す。
すべての族が `Selected` なら判定は satisfied、上限で止まった族があれば partial にする。

```rust
//| id: signal-iir-order-selection
//| ref: signal-iir-order-selection
//| title: 仕様から四つの族の最小次数を選んで設計する
//| run: reactive
//| crates: [scioxide-signal]
//| inputs:
//|   pass_edge: {"type":"range","label":"通過域の端 f_p [Nyquist 比]","description":"損失を R dB 以下に抑える上端。","min":0.05,"max":0.5,"step":0.01,"value":0.2}
//|   transition: {"type":"range","label":"遷移帯の幅 Δ [Nyquist 比]","description":"阻止域の端は f_s = f_p + Δ。","min":0.02,"max":0.3,"step":0.01,"value":0.1}
//|   ripple: {"type":"range","label":"通過域のリプル R [dB]","description":"通過域の端で許す損失。","min":0.1,"max":3,"step":0.1,"value":1}
//|   attenuation: {"type":"range","label":"阻止域の減衰量 A [dB]","description":"阻止域で求める最小の減衰。","min":20,"max":100,"step":5,"value":80}
//|   maximum_order: {"type":"range","label":"次数の上限","description":"これを超える次数は OrderLimit になる。","min":1,"max":40,"step":1,"value":30}
//| cases:
//|   - {"id":"order-limit","label":"上限 10","description":"Butterworth と Chebyshev が上限で止まり、判定が partial になる。","inputs":{"maximum_order":10}}
//|   - {"id":"loose","label":"R = 3 dB、A = 40 dB、Δ = 0.2","description":"緩い仕様では次数の差が縮む。","inputs":{"ripple":3,"attenuation":40,"transition":0.2}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"orders","path":"/rows/0/2","equals":22}
//|       - {"artifact":"orders","path":"/rows/1/2","equals":11}
//|       - {"artifact":"orders","path":"/rows/2/2","equals":11}
//|       - {"artifact":"orders","path":"/rows/3/2","equals":7}
//|       - {"artifact":"orders","path":"/rows/0/3","approx":{"value":21.9736,"atol":1e-3}}
//|       - {"artifact":"orders","path":"/rows/3/3","approx":{"value":6.5840,"atol":1e-3}}
//|       - {"artifact":"orders","path":"/rows/0/5","approx":{"value":0.20582,"atol":1e-5}}
//|       - {"artifact":"orders","path":"/rows/2/5","approx":{"value":0.28858,"atol":1e-5}}
//|       - {"artifact":"orders","path":"/rows/0/6","approx":{"value":1.0,"atol":1e-9}}
//|       - {"artifact":"orders","path":"/rows/1/7","approx":{"value":85.67,"atol":0.01}}
//|       - {"artifact":"orders","path":"/rows/3/7","range":{"min":79.999,"max":80.01}}
//|       - {"path":"/outputs/1/state","equals":"satisfied"}
//|   - case: order-limit
//|     expect:
//|       - {"artifact":"orders","path":"/rows/0/1","equals":"OrderLimit"}
//|       - {"artifact":"orders","path":"/rows/0/4","approx":{"value":11.9736,"atol":1e-3}}
//|       - {"artifact":"orders","path":"/rows/0/7","approx":{"value":33.21,"atol":0.01}}
//|       - {"artifact":"orders","path":"/rows/3/1","equals":"Selected"}
//|       - {"path":"/outputs/1/state","equals":"partial"}
//|   - case: loose
//|     expect:
//|       - {"artifact":"orders","path":"/rows/0/2","equals":6}
//|       - {"artifact":"orders","path":"/rows/3/2","equals":3}
//|       - {"path":"/outputs/1/state","equals":"satisfied"}
use scioxide_signal::{
    IirBand, IirDomain, IirOrderFamily, IirOrderOptions, design_iir,
    select_iir_order_with_options,
};

let stop_edge = pass_edge + transition;
let options = IirOrderOptions::new().with_maximum_order(maximum_order.round() as usize);
// 独立な検算に使う量（f64 の参照計算）
let half_pi = 0.5 * std::f64::consts::PI;
let omega = (half_pi * stop_edge).tan() / (half_pi * pass_edge).tan();
let ep2 = 10f64.powf(ripple / 10.0) - 1.0;
let es2 = 10f64.powf(attenuation / 10.0) - 1.0;
let k = |m: f64| {
    let (mut a, mut b) = (1.0_f64, (1.0 - m).sqrt());
    while (a - b).abs() > 1e-15 * a {
        (a, b) = (0.5 * (a + b), (a * b).sqrt());
    }
    half_pi / a
};
let families = [
    ("Butterworth", IirOrderFamily::Butterworth),
    ("Chebyshev I", IirOrderFamily::ChebyshevI),
    ("Chebyshev II", IirOrderFamily::ChebyshevII),
    ("楕円", IirOrderFamily::Elliptic),
];
let mut rows = Vec::new();
let mut limited = 0_usize;
for (name, family) in families {
    let report = select_iir_order_with_options(
        family,
        IirBand::Lowpass(pass_edge),
        IirBand::Lowpass(stop_edge),
        ripple,
        attenuation,
        IirDomain::Digital,
        options,
    )
    .map_err(|e| e.to_string())?;
    limited += usize::from(!report.is_success());
    let continuous = match family {
        IirOrderFamily::Butterworth => (es2 / ep2).ln() / (2.0 * omega.ln()),
        IirOrderFamily::ChebyshevI | IirOrderFamily::ChebyshevII => {
            (es2 / ep2).sqrt().acosh() / omega.acosh()
        }
        IirOrderFamily::Elliptic => {
            let (m, m1) = (1.0 / (omega * omega), ep2 / es2);
            k(m) * k(1.0 - m1) / (k(1.0 - m) * k(m1))
        }
    };
    let design = design_iir(
        report.order(),
        report.family(),
        report.band(),
        IirDomain::Digital,
    )
    .map_err(|e| e.to_string())?;

        * zpk
            .response(pass_edge)
            .map_err(|e| e.to_string())?
            .norm()
            .log10();

    let mut f = stop_edge;
    while f <= 0.999 {
        stop_peak = stop_peak.max(zpk.response(f).map_err(|e| e.to_string())?.norm());
        f += 1e-3;
    }
    // 低域通過の仕様には低域通過の帯域端が返る
    let IirBand::Lowpass(edge) = report.band() else {
        return Err("低域通過の帯域端が返らなかった".to_string());
    };
    rows.push((
        name,
        format!("{:?}", report.termination()),
        report.order(),
        continuous,
        report.order_deficit().raw_norm(),
        edge,
        pass_loss,
        -20.0 * stop_peak.log10(),
    ));
}

let fixed4 = serde_json::json!({ "fractionDigits": 4 });
let columns = serde_json::json!([
    { "key": "0", "label": "族" },
    { "key": "1", "label": "終了状態" },
    { "key": "2", "label": "次数", "type": "integer" },
    { "key": "3", "label": "n*（閉じた形）[-]", "type": "number", "format": fixed2 },
    { "key": "4", "label": "次数不足 [-]", "type": "number", "format": fixed2 },
    { "key": "5", "label": "設計の帯域端 [Nyquist 比]", "type": "number", "format": fixed4 },
    { "key": "6", "label": "f_p の損失 [dB]", "type": "number", "format": fixed2 },
    { "key": "7", "label": "阻止域の最小減衰 [dB]", "type": "number", "format": fixed2 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "orders" })
);

    Outcome::satisfied("四つの族で仕様を満たす次数を選んだ")
} else {
    Outcome::partial("次数の上限で止まった族がある")
        .explanation("OrderLimit の行は上限の次数で設計した結果で、仕様を満たさない。")
};
emit_outcome!(
    outcome
        .status(format!("Selected {}/4", 4 - limited))
        .diagnostic("OrderLimit の族の数", limited as f64, None)
);
```

既定の仕様（$f_p = 0.2$、$f_s = 0.3$、$R = 1$ dB、$A = 80$ dB）では、選ばれる次数は Butterworth 22、Chebyshev I 型と II 型 11、楕円 7 である。
どれも閉じた形の $n^*$（21.97、10.36、10.36、6.58）を切り上げた値に一致する。
設計した通過域の端の損失はどの族でも 1 dB（差は $10^{-12}$ 以下）、阻止域の最小減衰は 80 dB 以上になる。
Chebyshev I 型の阻止域の減衰が 85.67 dB と仕様より深いのは、次数を整数に切り上げた余裕が阻止域に回るからである。
Butterworth では余裕が帯域端の位置に使われ、`band()` の半電力点は 0.2058 と通過域の端より高い。
Chebyshev II 型の `band()` は 0.2886 で、阻止域が仕様の $f_s = 0.3$ より手前から始まる。

次数の上限を 10 にすると、Butterworth と二つの Chebyshev が `OrderLimit` になり、判定は partial に変わる。
Butterworth の次数不足は $21.97 - 10 = 11.97$ で、上限の次数で設計した阻止域の最小減衰は 33.21 dB しかない。
レポートの次数をそのまま使うと仕様を満たさないので、`is_success()` を確かめてから設計する。

## ノッチ・ピーク・櫛形・ガンマトーン

特定の周波数だけを除いたり通したりするフィルタは、プロトタイプから作るより閉じた形で書くほうが簡単である。

`design_notch_peak(frequency, quality, kind)` は二次のノッチかピークを `SecondOrderSections` で返す。
中心周波数 $f_0$（Nyquist 比、$0 < f_0 < 1$）と Q 値 $Q = f_0/\Delta f$（$\Delta f$ は −3 dB の帯域幅）から、$\beta = \tan(\pi\Delta f/2)$、$g = 1/(1+\beta)$ として

$$
\begin{aligned}
\text{ノッチ:}\quad & H(z) = g\,\frac{1 - 2\cos(\pi f_0) z^{-1} + z^{-2}}{D(z)} \\
\text{ピーク:}\quad & H(z) = (1-g)\,\frac{1 - z^{-2}}{D(z)} \\
& D(z) = 1 - 2g\cos(\pi f_0) z^{-1} + (2g-1) z^{-2}
\end{aligned}
$$

である。
ノッチは $f_0$ に零点を持ち、直流と Nyquist で利得 1 になる。
ピークは $f_0$ で利得 1、直流と Nyquist で零点を持つ。
$\beta$ に事前ワーピングした帯域幅を使うので、半電力点の間隔は $\Delta f$ に一致する。
$f_0/Q$ が 1 以上、$Q$ が正でない、丸めた極が安定でない場合は `InvalidInput` になる。

`ResonanceKind` は `Notch`（中心の周波数を除く）と `Peak`（中心の周波数を通す）を選び、`design_comb` でも使う。

`design_comb(delay, feedback, kind)` は、整数の遅延 $D$ と帰還 $\alpha$（$|\alpha| < 1$）の櫛形フィルタを `TransferFunction` で返す。

$$
\text{ノッチ:}\ H(z) = \frac{1+\alpha}{2}\,\frac{1 - z^{-D}}{1 - \alpha z^{-D}}, \qquad
\text{ピーク:}\ H(z) = \frac{1-\alpha}{1 - \alpha z^{-D}}
$$

高調波 $f = 2k/D$（$k = 0, 1, \dots$）で、ノッチは零点を、ピークは利得 1 を持つ。
$0 < \alpha < 1$ では $\alpha$ が 1 に近いほどノッチやピークの帯域幅が狭くなる。
遅延 0 か $|\alpha| \ge 1$ は `InvalidInput` になる。
電源のノイズのように基本波と高調波をまとめて除くときに使う。

`design_gammatone(order, frequency, bandwidth)` は、聴覚のフィルタのモデルであるガンマトーン $t^{n-1} e^{-\pi b t} e^{i\pi f_0 t}$（$t$ は標本、$f_0$ と $b$ は Nyquist 比）を、同じ一次の節 $H_1(z) = (1-r)/(1 - p z^{-1})$（$p = r e^{i\pi f_0}$、$r = e^{-\pi b}$）の $n$ 段の縦続で近似する。
係数は複素数で、$f_0$ で利得 1 になる。
`design_real_gammatone` はその実部 $(H + \bar H)/2$ を $f_0$ で利得 1 に正規化した次数 $2n$ の実数の二次節を返す。
零点は多項式の求根で求めて検査し、`design_real_gammatone_scoped` はその求根を外側のスコープの上限に数える。
$f_0 = 0$ では複素の設計がすでに実数なので、$n$ 個の一次の節を返す。

### ノッチの帯域幅を半電力点で確かめる

次のセルは、中心 $f_0$、Q 値、種類（ノッチかピーク）を入力として `design_notch_peak` で設計し、$|H(f)|^2 = 1/2$ になる二つの周波数 $f_1 < f_0 < f_2$ を二分法で求める。
二分法は独立な検算として書いたもので、応答の評価には `SecondOrderSections::response` を使う。
$f_2 - f_1$ が設計の $\Delta f = f_0/Q$ と一致するかを相対差で示し、$f_0$、直流、Nyquist での利得も示す。

```rust
//|   - case: default
//|     expect:
//|       - {"artifact":"bandwidth","path":"/rows/0/0","approx":{"value":0.190216,"atol":1e-6}}
//|       - {"artifact":"bandwidth","path":"/rows/0/2","approx":{"value":0.02,"rtol":1e-12}}
//|       - {"artifact":"bandwidth","path":"/rows/0/5","range":{"min":0,"max":1e-13}}
//|       - {"artifact":"bandwidth","path":"/rows/0/6","approx":{"value":1.0,"atol":1e-13}}
//|   - case: peak
//|     expect:
//|       - {"artifact":"bandwidth","path":"/rows/0/2","approx":{"value":0.02,"rtol":1e-12}}
//|       - {"artifact":"bandwidth","path":"/rows/0/5","approx":{"value":1.0,"atol":1e-13}}
//|       - {"artifact":"bandwidth","path":"/rows/0/6","range":{"min":0,"max":1e-13}}
//|   - case: wide
//|     expect:
//|       - {"artifact":"bandwidth","path":"/rows/0/0","approx":{"value":0.180431,"atol":1e-6}}
//|       - {"artifact":"bandwidth","path":"/rows/0/1","approx":{"value":0.980431,"atol":1e-6}}
//|       - {"artifact":"bandwidth","path":"/rows/0/4","range":{"min":-1e-12,"max":1e-12}}
use scioxide_signal::{ResonanceKind, design_notch_peak};

let resonance = if kind == "Peak" {
    ResonanceKind::Peak
} else {
    ResonanceKind::Notch
};
let sections = design_notch_peak(center, quality, resonance).map_err(|e| e.to_string())?;
let power = |f: f64| -> Result<f64, String> {
    Ok(sections.response(f).map_err(|e| e.to_string())?.norm_sqr())
};
// 独立な検算: |H|² − 1/2 の符号が変わる区間を二分法で縮める
let half_power = |mut lower: f64, mut upper: f64| -> Result<f64, String> {
    let sign = (power(lower)? - 0.5).signum();
    for _ in 0..60 {
        let middle = 0.5 * (lower + upper);
        if (power(middle)? - 0.5).signum() == sign {
            lower = middle;
        } else {
            upper = middle;
        }
    }
    Ok(0.5 * (lower + upper))
};
let lower_edge = half_power(0.0, center)?;
let upper_edge = half_power(center, 1.0)?;
let measured = upper_edge - lower_edge;
let designed = center / quality;

let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let fixed5 = serde_json::json!({ "fractionDigits": 5 });
let columns = serde_json::json!([
    { "key": "0", "label": "f₁ [Nyquist 比]", "type": "number", "format": fixed5 },
    { "key": "1", "label": "f₂ [Nyquist 比]", "type": "number", "format": fixed5 },
    { "key": "2", "label": "f₂ − f₁ [Nyquist 比]", "type": "number", "format": fixed5 },
    { "key": "3", "label": "f₀/Q [Nyquist 比]", "type": "number", "format": fixed5 },
    { "key": "4", "label": "相対差 [-]", "type": "number", "format": sci3 },
    { "key": "5", "label": "|H(f₀)| [-]", "type": "number", "format": sci3 },
    { "key": "6", "label": "|H(0)| [-]", "type": "number", "format": sci3 },
    { "key": "7", "label": "|H(1)| [-]", "type": "number", "format": sci3 }
]);
let row = (
    lower_edge,
    upper_edge,
    measured,
    designed,
    (measured - designed) / designed,
    power(center)?.sqrt(),
    power(0.0)?.sqrt(),
    power(1.0)?.sqrt(),
);
emit_table_with_columns!(
    columns,
    vec![row],
    metadata = serde_json::json!({ "id": "bandwidth" })
);
// 中心の近くを細かく取った周波数の格子
let mut grid: Vec<f64> = (0..=400).map(|i| i as f64 / 400.0).collect();
grid.extend((0..=200).map(|i| lower_edge - measured + 3.0 * measured * i as f64 / 200.0));
grid.retain(|f| (0.0..=1.0).contains(f));
grid.sort_by(f64::total_cmp);
let mut curve = Vec::new();
for f in grid {
    curve.push([f, power(f)?.sqrt()]);
}
emit_line_chart!(
    &vec![serde_json::json!({ "name": "|H(f)|", "points": curve })],
    options = &serde_json::json!({
        "xLabel": "周波数 f [Nyquist 比]",
        "yLabel": "振幅 |H| [-]",
        "yMin": 0.0,
        "yMax": 1.05,
        "annotations": [
            { "kind": "line", "axis": "y", "value": 0.5_f64.sqrt(), "label": "1/√2" },
            { "kind": "line", "axis": "x", "value": lower_edge, "label": "f₁" },
            { "kind": "line", "axis": "x", "value": upper_edge, "label": "f₂" }
        ]
    })
);
```

既定の $f_0 = 0.2$、$Q = 10$ のノッチでは、半電力点は $f_1 = 0.19022$、$f_2 = 0.21022$ で、間隔 $0.02$ は $f_0/Q$ と相対差 $2 \times 10^{-15}$ で一致する。
$|H(f_0)|$ は $3 \times 10^{-15}$、直流と Nyquist の利得は 1 である。
ピークに切り替えると、同じ半電力点で $|H(f_0)| = 1$、直流と Nyquist の利得が 0 になる。
$f_0 = 0.8$、$Q = 1$ では $f_1 = 0.1804$、$f_2 = 0.9804$ で、間隔は 0.8 のままだが、二つの半電力点は $f_0$ の左に 0.62、右に 0.18 離れる。
帯域幅は双一次変換で縮んだ周波数軸の上で決まるので、Nyquist に近い側が詰まる。

## まとめ

IIR の設計は、族と次数で決まるアナログ低域通過プロトタイプを帯域の変換で目的の帯域に移し、事前ワーピングした双一次変換で離散時間に写す。
帯域端の意味は族で違い、Butterworth は半電力点、Chebyshev I 型と楕円は通過域の端、Chebyshev II 型は阻止域の端である。
仕様から次数を決めるときは `select_iir_order_with_options` で上限を付け、`is_success()` を確かめてからレポートの `order()`、`family()`、`band()` を `design_iir` に渡す。
設計の結果は `stability_margin()` で極の余裕を確かめ、`to_sos()` で二次節に変換して適用する。
二次節での実行、チャンクに分けた処理、前後方向のゼロ位相は[IIR フィルタの実行とゼロ位相](../iir-filtering-and-zero-phase/)で、族による群遅延の違いは[群遅延の例題](../../examples/iir-group-delay-zero-phase/)で確かめる。
