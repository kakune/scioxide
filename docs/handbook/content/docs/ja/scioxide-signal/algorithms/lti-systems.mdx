回路、機械、化学反応器の多くは、平衡点の近くで線形の常微分方程式に近似できる。
係数が時間に依らないとき、その系を線形時不変（LTI）系と呼ぶ。
LTI 系の入出力関係は伝達関数、インパルス応答、状態空間モデルの三つの形で表せる。
このページは、`scioxide-signal` が中心に置く状態空間モデルについて、変換、離散化、時間応答と周波数応答の計算、状態フィードバックによる極配置を説明する。

LTI はモデルの仮定であり、非線形系や時変系には自動的には拡張されない。
非線形系を扱うときは、平衡点のまわりで線形化してから使う。

## 状態空間モデル

連続系と離散系の状態空間モデルは次の形をとる。

$$
\begin{aligned}
\text{連続系:}\quad & \dot x(t) = A x(t) + B u(t), & y(t) &= C x(t) + D u(t), \\
\text{離散系:}\quad & x[k+1] = A x[k] + B u[k], & y[k] &= C x[k] + D u[k].
\end{aligned}
$$

$x$ は長さ $n$ の状態、$u$ は長さ $m$ の入力、$y$ は長さ $p$ の出力である。
$A$ は $n \times n$、$B$ は $n \times m$、$C$ は $p \times n$、$D$ は $p \times m$ の行列で、$D$ は入力が出力へ直接届く直達項を表す。
連続系の時間の単位は呼び出し側が決め、$A$ の要素はその逆数の単位を持つ。

`StateSpace::new(time, a, b, c, d)` は、四つの行列の形と有限性を検査してから複製を保持する。
行列は行優先で、実数でも複素数でもよい。
$n$、$m$、$p$ のどれが 0 でもよい。
形が合わなければ `DimensionMismatch`、要素や標本周期が NaN か無限大なら `NonFinite`、離散系の標本周期が正でなければ `InvalidInput` を返す。

時間領域は `LtiTime` で選ぶ。
`LtiTime::Continuous` は連続系、`LtiTime::Discrete { sample_period }` は標本周期 $T$ の離散系で、`sample_period()` は連続系に `None` を返す。
`view()` は行列を複製せずに `StateSpaceView` を返し、`StateSpaceView::to_owned` で再び所有するモデルにできる。
借用のビューは、モデルを関数に渡して次元（`states`、`inputs`、`outputs`）や行列を読むだけのときに使う。

モデルの極は $A$ の固有値で、`poles()` が平衡化、Hessenberg 化、移動つき QR 反復により $O(n^3)$ で求める。
実数のモデルでは、複素数の極は正確な共役の組で返る。
`controllability_matrix()` は $[B, AB, \dots, A^{n-1}B]$、`observability_matrix()` は $[C; CA; \dots; CA^{n-1}]$ を作る。
`controllability(policy)` と `observability(policy)` は、それらの特異値のうち `RankPolicy` のしきい値を超える数を数値ランクとして返す。
ランクが $n$ なら、対は可制御（可観測）である。

## 伝達関数と零極表現への変換

入力 $j$ から出力 $i$ への経路の伝達関数は

$$
H_{ij}(\lambda) = c_i (\lambda I - A)^{-1} b_j + d_{ij} = \frac{N(\lambda)}{\det(\lambda I - A)}
$$

である。
$b_j$ は $B$ の列 $j$、$c_i$ は $C$ の行 $i$、$d_{ij}$ は $D$ の要素で、$\lambda$ は連続系では $s$、離散系では $z$ である。

`to_transfer(input, output)` は、引数を入力、出力の順にとり、この経路を `TransferFunction` に変換する。
分母は $A$ の固有値から展開し、分子は行列式の補題 $\det(\lambda I - A + b c) = \det(\lambda I - A) + c\,\mathrm{adj}(\lambda I - A)\,b$ により $A - b_j c_i$ の固有値から求める。
共通因子は約分しないので、可制御でない、または可観測でないモードは分子と分母に残る。
計算量は $O(n^3)$、メモリは $O(n^2)$ である。
`to_zpk(input, output)` は、その分子と分母の根を `TransferFunction::to_zpk` で求めて `PoleZeroGain` を返す。
外側の解法の上限の中で根を求める場合は `to_zpk_scoped` を使う。

高次の多項式の係数は根の悪条件な関数である。
次数の高いモデルの応答は、伝達関数を経由せずに後述の `frequency_response` で状態空間から直接求める。

逆向きの変換として、`TransferFunction::to_state_space(time)` は一入力一出力の可制御正準形を作る。
正規化した分母 $1, a_1, \dots, a_n$ に対し、$A$ は 1 行目が $-a_1, \dots, -a_n$ で副対角が 1 の随伴行列、$B = e_1$、$D = b_0$ である。
`PoleZeroGain::to_state_space(time)` は、極と零点を 2 次以下の節にまとめ、各節を可制御正準形にして直列につなぐ。
高次の多項式を展開しないので係数の悪条件を避けられるが、行列は複素数になる。
どちらの変換も、アナログの表現には `LtiTime::Continuous`、デジタルの表現には `LtiTime::Discrete` を要求し、食い違えば `InvalidInput` を返す。

## 連続系の離散化

連続系をデジタル制御器やシミュレーションで使うには、標本周期 $h$ の離散系に写す。
`discretize(h, method)` は連続系だけを受け付け、`LtiTime::Discrete { sample_period: h }` の新しいモデルを返す。
方法は `DiscretizationMethod` で選ぶ。

### 零次ホールドと行列指数

零次ホールド（ZOH）は、入力が各標本区間で一定に保たれると仮定する。
区間 $[kh, (k+1)h)$ で $u$ が一定なら、状態方程式の解は

$$
x[k+1] = e^{hA} x[k] + \left( \int_0^h e^{sA}\,ds \right) B\,u[k]
$$

となり、この仮定のもとで厳密である。
したがって $A_d = e^{hA}$、$B_d = \int_0^h e^{sA}\,ds\,B$、$C_d = C$、$D_d = D$ となる。

$B_d$ を $A^{-1}(A_d - I)B$ と書くと、$A$ が特異なとき（積分器を含む系など）に使えない。
`DiscretizationMethod::ZeroOrderHold` は代わりに、次数 $n + m$ のブロック行列の指数

$$
\exp\left( h \begin{bmatrix} A & B \\ 0 & 0 \end{bmatrix} \right) = \begin{bmatrix} A_d & B_d \\ 0 & I \end{bmatrix}
$$

を 1 回計算し、左上と右上のブロックを読む。
行列指数は `scioxide-linalg` の Padé 近似とスケーリング・二乗で計算する（[行列関数の計アルゴリズム](oxref:linalg-matrix-function-methods)）。

### 一般化双一次変換

`DiscretizationMethod::GeneralizedBilinear { alpha }` は、重み $\alpha \in [0, 1]$ の一般化双一次変換である。

$$
\begin{aligned}
A_d &= (I - \alpha h A)^{-1} \bigl( I + (1 - \alpha) h A \bigr), &
B_d &= (I - \alpha h A)^{-1} h B, \\
C_d &= C (I - \alpha h A)^{-1}, &
D_d &= D + \alpha C B_d.
\end{aligned}
$$

$I - \alpha h A$ の LU 分解 1 回から四つの行列を作る。
このモデルの伝達関数は連続系の $H_c(s)$ に置換

$$
s = \frac{z - 1}{h \bigl( \alpha z + 1 - \alpha \bigr)}
$$

を施したものに等しい。
$\alpha = 0$ は前進 Euler 法、$\alpha = 1/2$ は Tustin 変換（双一次変換、台形則）、$\alpha = 1$ は後退 Euler 法にあたる。
これらは常微分方程式の $\theta$ 法と同じ写像で、固有値 $\lambda$ は $z = (1 + (1 - \alpha) h\lambda) / (1 - \alpha h \lambda)$ に移る。

$\alpha \ge 1/2$ では左半平面が単位円板の内部に写るので、安定な連続系は刻みによらず安定な離散系になる。
$\alpha = 0$ では $|1 + h\lambda| < 1$ が必要で、減衰の小さい振動系では $h$ に厳しい上限がつく。
安定関数と絶対安定性領域は[常微分方程式の誤差と安定性](../../../scioxide-ode/algorithms/error-order-and-stability/)で説明している。

$\alpha$ が $[0, 1]$ の外にあるか、モデルがすでに離散系なら `InvalidInput`、$I - \alpha h A$ が特異なら `Singular`、行列指数や離散化した行列が桁あふれすれば `NumericalInstability` を返す。
どちらの方法も、$m, p \le n$ のとき $O(n^3)$ の演算で済む。

### 離散化の誤差と安定性

次のブロックは、このページの二つのセルが共有するモデルである。
無次元の時間で書いた減衰振動子 $\ddot x + 2\zeta \dot x + x = u$ を状態 $(x, \dot x)$ で表し、出力を位置と速度の 2 つにする。
固有角周波数は 1、極は $-\zeta \pm i\omega_d$（$\omega_d = \sqrt{1 - \zeta^2}$）である。
`step_position` と `ramp_position` は、$0 < \zeta < 1$ で零状態から単位ステップ $u = 1$ とランプ $u = t$ を与えたときの位置の閉形式

$$
\begin{aligned}
x_{\mathrm{step}}(t) &= 1 - e^{-\zeta t} \left( \cos \omega_d t + \frac{\zeta}{\omega_d} \sin \omega_d t \right), \\
x_{\mathrm{ramp}}(t) &= t - 2\zeta + e^{-\zeta t} \left( 2\zeta \cos \omega_d t + \frac{2\zeta^2 - 1}{\omega_d} \sin \omega_d t \right)
\end{aligned}
$$

で、検算に使う参照値である。

```rust
//| id: signal-lti-oscillator-model
//| kind: definitions
//| title: 減衰振動子の状態空間モデルとステップ応答の閉形式
//| crates: [scioxide-core, scioxide-linalg, scioxide-signal]
use scioxide_core::SciOxideError;
use scioxide_linalg::Matrix;
use scioxide_signal::{LtiTime, StateSpace};

/// x'' + 2ζx' + x = u を状態 (x, x') で表した連続系。出力は位置 x と速度 x' の順。
pub(crate) fn oscillator(damping_ratio: f64) -> Result<StateSpace<f64>, SciOxideError> {
    let a = Matrix::from_vec(2, 2, vec![0.0, 1.0, -1.0, -2.0 * damping_ratio])?;
    let b = Matrix::from_vec(2, 1, vec![0.0, 1.0])?;
    let c = Matrix::identity(2)?;
    let d = Matrix::zeros(2, 1)?;
    StateSpace::new(LtiTime::Continuous, a.view(), b.view(), c.view(), d.view())
}

/// 零状態からの単位ステップ u = 1 に対する位置 x(t)（0 < ζ < 1）。参照値（f64 の標準関数）。
pub(crate) fn step_position(damping_ratio: f64, time: f64) -> f64 {
    let damped = (1.0 - damping_ratio * damping_ratio).sqrt();
    let envelope = (-damping_ratio * time).exp();
    1.0 - envelope * ((damped * time).cos() + damping_ratio / damped * (damped * time).sin())
}

/// 零状態からのランプ u = t に対する位置 x(t)（0 < ζ < 1）。参照値（f64 の標準関数）。
pub(crate) fn ramp_position(damping_ratio: f64, time: f64) -> f64 {
    let damped = (1.0 - damping_ratio * damping_ratio).sqrt();
    let envelope = (-damping_ratio * time).exp();
    let sine = (2.0 * damping_ratio * damping_ratio - 1.0) / damped;
    let homogeneous = 2.0 * damping_ratio * (damped * time).cos() + sine * (damped * time).sin();
    time - 2.0 * damping_ratio + envelope * homogeneous
}
```

次のセルは、減衰比 $\zeta$、刻み $h$、入力の種類を選び、四つの方法で離散化したモデルの応答を時刻 $0 \le t \le 10$ の格子で求める。
離散系の計算には `simulate_zoh` を使い、入力の標本 $u[k] = u(kh)$ と零の初期状態を渡す。
離散系の `simulate_zoh` は、受け取った標本で自身の差分方程式を進める。
刻みを $h$、$h/2$、$h/4$ と半分にしたときの位置の最大誤差を閉形式と比べ、後の二つの比から観測次数 $\log_2(e_{h/2} / e_{h/4})$ を求める。
誤差が $10^{-12}$ を下回る場合は次数を定義しない。
表の最後の列は刻み $h$ での $A_d$ のスペクトル半径（極の絶対値の最大）で、1 を超えると離散系は不安定である。
図は刻み $h$ での各方法の位置を閉形式（破線）と重ねる。

```rust
//| id: signal-lti-discretization-order
//| ref: signal-lti-discretization-order
//| title: 離散化の方法ごとの応答の誤差と安定性
//| run: reactive
//| uses: [signal-lti-oscillator-model]
//| crates: [scioxide-core, scioxide-linalg, scioxide-signal]
//| inputs:
//|   damping_ratio: {"type":"range","label":"減衰比 ζ [-]","description":"振動の減衰の速さと前進 Euler 法の安定性の条件を変える。","min":0.05,"max":0.9,"step":0.05,"value":0.1}
//|   base_step: {"type":"range","label":"刻み h [-]","description":"最も粗い標本周期。誤差は h、h/2、h/4 で測る。","min":0.05,"max":1,"step":0.05,"value":0.4}
//|   input_kind: {"type":"select","label":"入力","description":"区間で一定の入力か、区間で線形に変わる入力かを選ぶ。","options":["ステップ u = 1","ランプ u = t"],"value":"ステップ u = 1"}
//| cases:
//|   - {"id":"ramp","label":"ランプ入力","description":"零次ホールドの仮定が崩れ、Tustin 変換が 2 次になる。","inputs":{"input_kind":"ランプ u = t"}}
//|   - {"id":"fine-step","label":"h = 0.1","description":"前進 Euler 法も安定になる。","inputs":{"base_step":0.1}}
//|   - {"id":"heavy-damping","label":"ζ = 0.9","description":"減衰が大きいと前進 Euler 法の安定性の条件が緩む。","inputs":{"damping_ratio":0.9}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"errors","path":"/rows/0/3","range":{"max":1e-12}}
//|       - {"artifact":"errors","path":"/rows/1/5","range":{"min":1.0}}
//|       - {"artifact":"errors","path":"/rows/2/4","approx":{"value":1.0,"atol":0.1}}
//|   - case: ramp
//|     expect:
//|       - {"artifact":"errors","path":"/rows/0/4","approx":{"value":1.0,"atol":0.15}}
//|       - {"artifact":"errors","path":"/rows/2/4","approx":{"value":2.0,"atol":0.15}}
//|   - case: fine-step
//|     expect:
//|       - {"artifact":"errors","path":"/rows/1/5","range":{"max":1.0}}
//|       - {"artifact":"errors","path":"/rows/1/4","approx":{"value":1.0,"atol":0.15}}
//|   - case: heavy-damping
//|     expect:
//|       - {"artifact":"errors","path":"/rows/0/3","range":{"max":1e-12}}
//|       - {"artifact":"errors","path":"/rows/1/5","range":{"max":1.0}}
use scioxide_signal::DiscretizationMethod;

let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let fixed3 = serde_json::json!({ "fractionDigits": 3 });
let model = oscillator(damping_ratio).map_err(|e| e.to_string())?;
let ramp = input_kind == "ランプ u = t";
let exact = |t: f64| {
    if ramp {
        ramp_position(damping_ratio, t)
    } else {
        step_position(damping_ratio, t)
    }
};
let horizon = 10.0_f64;
let methods = [
    ("零次ホールド", DiscretizationMethod::ZeroOrderHold),
    (
        "前進 Euler（α = 0）",
        DiscretizationMethod::GeneralizedBilinear { alpha: 0.0 },
    ),
    (
        "Tustin（α = 1/2）",
        DiscretizationMethod::GeneralizedBilinear { alpha: 0.5 },
    ),
    (
        "後退 Euler（α = 1）",
        DiscretizationMethod::GeneralizedBilinear { alpha: 1.0 },
    ),
];

let mut rows = Vec::new();
let mut series = Vec::new();
for (name, method) in methods {
    let mut errors = [0.0_f64; 3];
    let mut radius = 0.0_f64;
    for (level, error) in errors.iter_mut().enumerate() {
        let h = base_step / f64::from(1_u32 << level);
        let steps = (horizon / h).round() as usize;
        let times: Vec<f64> = (0..=steps).map(|k| k as f64 * h).collect();
        let inputs: Vec<f64> = times.iter().map(|&t| if ramp { t } else { 1.0 }).collect();
        let discrete = model.discretize(h, method).map_err(|e| e.to_string())?;
        let response = discrete
            .simulate_zoh(&times, &inputs, &[0.0, 0.0])
            .map_err(|e| e.to_string())?;
        // values() は [標本][出力] の順（経路は 1 つ）。出力は位置、速度の順なので位置は 2k 番目。
        *error = times
            .iter()
            .enumerate()
            .map(|(k, &t)| (response.values()[2 * k] - exact(t)).abs())
            .fold(0.0, f64::max);
        if level == 0 {
            let poles = discrete.poles().map_err(|e| e.to_string())?;
            radius = poles.iter().map(|z| z.norm()).fold(0.0, f64::max);
            let points: Vec<[f64; 2]> = times
                .iter()
                .enumerate()
                .map(|(k, &t)| [t, response.values()[2 * k]])
                .collect();
            series.push(serde_json::json!({ "name": name, "points": points }));
        }
    }
    let order = (errors[2] > 1e-12).then(|| (errors[1] / errors[2]).log2());
    rows.push((name, errors[0], errors[1], errors[2], order, radius));
}

let reference: Vec<[f64; 2]> = (0..=500)
    .map(|k| {
        let t = horizon * k as f64 / 500.0;
        [t, exact(t)]
    })
    .collect();
series.push(serde_json::json!({
    "name": "閉形式",
    "points": reference,
    "style": { "lineType": "dashed", "showSymbol": false }
}));
// 発散する前進 Euler 法で縦軸が跳ばないように、入力ごとに範囲を固定する。
let (y_min, y_max) = if ramp { (-1.0, 11.0) } else { (-0.5, 2.5) };
emit_line_chart!(
    &series,
    options = &serde_json::json!({
        "xLabel": "無次元の時刻 t [-]",
        "yLabel": "位置 x [-]",
        "yMin": y_min,
        "yMax": y_max
    })
);

let columns = serde_json::json!([
    { "key": "0", "label": "方法" },
    { "key": "1", "label": "最大誤差 e_h [-]", "type": "number", "format": sci3 },
    { "key": "2", "label": "最大誤差 e_h/2 [-]", "type": "number", "format": sci3 },
    { "key": "3", "label": "最大誤差 e_h/4 [-]", "type": "number", "format": sci3 },
    { "key": "4", "label": "観測次数 [-]", "type": "number", "format": fixed3, "nullText": "丸め誤差のみ" },
    { "key": "5", "label": "スペクトル半径 [-]", "type": "number", "format": fixed3 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "errors" })
);
```

既定値（$\zeta = 0.1$、$h = 0.4$、ステップ入力）では、零次ホールドの誤差はどの刻みでも $2.4 \times 10^{-15}$ 以下で、丸め誤差の程度である。
ステップは各区間で一定なので、零次ホールドの仮定がちょうど成り立ち、標本点の値は厳密になる。
前進 Euler 法のスペクトル半径は 1.039 で 1 を超え、図の応答は振動しながら発散する。
固有値 $\lambda$ は $1 + h\lambda$ に写り、$|1 + h\lambda|^2 = 1 - 2h\zeta + h^2$ なので、$h < 2\zeta$ でなければ不安定になる。
Tustin 変換の観測次数は 0.961 で、台形則の 2 次にならない。
双一次変換は入力の標本の間を直線で補うので、$t = 0$ の跳びを区間 $[-h, 0]$ に広がった傾きとして扱い、その分の $O(h)$ の誤差が残る。
後退 Euler 法の観測次数は 0.766 で、刻み $h/4 = 0.1$ ではまだ漸近的な 1 次に達していない。

ケース「ランプ入力」では関係が入れ替わる。
入力は区間の中で変わるので零次ホールドの仮定は崩れ、零次ホールドの観測次数は 1.000 に落ちる。
入力は直線なので Tustin 変換の補間は正確になり、観測次数は 1.999 になる。
離散化の誤差は、方法の次数だけでなく、標本の間で入力をどう仮定するかに左右される。

ケース「h = 0.1」では $h < 2\zeta$ を満たし、前進 Euler 法のスペクトル半径は 0.995 で安定になる。
ケース「ζ = 0.9」では減衰が大きく、刻み 0.4 でも前進 Euler 法のスペクトル半径は 0.663 である。
後退 Euler 法と Tustin 変換はどの刻みでも安定だが、後退 Euler 法は振動を余分に減衰させる。
安定であることと精度が高いことは別の性質である。

## 時間応答

`impulse_response(times)`、`step_response(times)`、`simulate_zoh(times, inputs, initial_state)` は時刻の格子で応答を標本化し、`TimeResponse` を返す。
格子 `times` は空でなく、0 から始まり、刻み $h$ = `times[1]` で等間隔でなければならない。
各標本は丸めた積 $kh$ から $64\varepsilon(|t_k| + h)$ まで離れてよいので、`k as f64 * h` や `k as f64 * T / (K - 1)` で作った格子は通る。
離散系では $h$ が標本周期 $T$ に $64\varepsilon(1 + T)$ の範囲で一致する必要があり、食い違えば `InvalidInput`（`Inconsistent`）を返す。

連続系では、刻み $h$ の零次ホールドの遷移 $(A_d, B_d)$ を準備の時点で 1 回だけ計算し、$x[k+1] = A_d x[k] + B_d u[k]$ を進める。
各区間で一定の入力に対して標本点の値は丸め誤差を除いて厳密で、精度は系の条件と刻みを重ねた丸め誤差で決まる。
計算コストは応答の経路ごとに $O(K(n + p)(n + m))$ で、$K$ は時刻の数である。

インパルス応答とステップ応答は、入力ごとに 1 つの経路（channel）を持つ。
経路 $j$ は入力 $j$ だけを駆動した応答である。
連続系のインパルス応答は通常の関数の部分 $C e^{At} B$ だけを標本化し、直達項によるデルタ関数 $D\delta(t)$ は含めない。
離散系のインパルス応答は $y[0] = D$、$k \ge 1$ で $y[k] = C A^{k-1} B$ である。
ステップ応答は零状態から始め、すべての標本で $D$ を含む。
`simulate_zoh` は `[標本][入力]` の順に並べた入力と初期状態から 1 つの経路を計算し、状態履歴の 1 行目は初期状態になる。

`TimeResponse` の `values()` は `[標本][出力][経路]`、`states()` は `[標本][状態][経路]` の順に並ぶ。
同じ格子で繰り返し計算するときは `TimeResponsePlan::new(model, times)` を作り、`workspace()` で作業領域 `TimeResponseWorkspace` を 1 回確保する。
`impulse_response_into`、`step_response_into`、`simulate_into` は出力と状態履歴を呼び出し側の領域へ書き、実行中に確保しない。
領域の長さは `output_len()`（$Kpm$）、`states_len()`（$Knm$）、`simulation_output_len()`（$Kp$）などで問い合わせ、長さが合わなければ `DimensionMismatch` を返す。
所有値を返す API の三つの関数は、Plan を作って逐次のコンテキストで実行する。

## 周波数応答と周波数の単位

周波数応答は $H(\lambda) = C(\lambda I - A)^{-1} B + D$ を周波数の格子で評価した値である。
単位はクレート全体の規約に従う。
連続系では角周波数 $\omega$ [rad/時間単位] を与えて $\lambda = i\omega$ を評価する。
離散系では Nyquist 周波数に対する比 $f$ を与えて $\lambda = e^{i\pi f}$ を評価し、標本周期は使わない。
$f = 1$ が Nyquist 周波数で、角周波数に直すと $\omega = \pi f / T$ である。
この規約は `TransferFunction::response` などのフィルタの評価と同じなので、同じ系を別の表現で評価しても値がそろう。

`FrequencyResponsePlan::new(model)` は、Householder 鏡映で $A = Q H Q^{\mathsf H}$ と上 Hessenberg 形に直し、$H$、$Q^{\mathsf H} B$、$C Q$ を保持する（$O(n^3)$）。
各周波数では $(\lambda I - H) X = Q^{\mathsf H} B$ を行交換つきの Gauss 消去で解いて $C Q X + D$ を作り、計算コストは $O(n^2 m)$ である。
特性多項式を作らないので、高次のモデルでも係数の悪条件の影響を受けない。
ただし $\lambda$ が極に近づくと $\lambda I - A$ が悪条件になり、精度は下がる。
$\lambda I - A$ がちょうど特異になる周波数では `Singular` を返す。

`workspace_requirements(K)` は $K$ 個の周波数に必要な大きさを `FrequencyResponseRequirements` で返し、`output_len()` が出力の長さ $Kpm$ を与える。
作業領域 `FrequencyResponseWorkspace` は `plan.workspace(K)` で確保し、長い掃引には `try_reserve` で広げる。
`frequency_response_into(frequencies, output, workspace, cx)` は、`output` の長さがちょうど $Kpm$ であることを要求し、`[周波数][出力][入力]` の順に書く。
周波数 $k$、出力 $i$、入力 $j$ の値は添字 $(kp + i)m + j$ にある。
所有値を返す API の `frequency_response` は Plan を作って 1 回掃引し、周波数の複製と値を `FrequencyResponse` に入れて返す。

次のセルは、上の振動子を標本周期 $h$ で離散化し、周波数応答の単位と Tustin 変換の周波数のゆがみを確かめる。
連続系には同じ Plan と作業領域で 2 回の掃引を行う。
1 回目は離散系の格子 $f$ と同じ角周波数 $\omega = \pi f / h$、2 回目は事前ワーピングした $\Omega = (2/h)\tan(\pi f / 2)$ である。
Tustin 変換は置換 $s = (2/h)(z - 1)/(z + 1)$ と等価なので、離散系の応答 $H_d(e^{i\pi f})$ は連続系の $H_c(i\Omega)$ に一致するはずである。
出力の並びの検算として、速度の応答が位置の応答の $i\omega$ 倍になることも確かめる。
図は振幅 $|H|$ を対数軸で描き、Nyquist 周波数 $\pi/h$ を縦線で示す。

```rust
//| id: signal-lti-frequency-units
//| ref: signal-lti-frequency-units
//| title: 離散系の周波数の単位と Tustin 変換の周波数のゆがみ
//| run: reactive
//| uses: [signal-lti-oscillator-model]
//| crates: [scioxide-core, scioxide-linalg, scioxide-signal]
//| inputs:
//|   damping_ratio: {"type":"range","label":"減衰比 ζ [-]","description":"共振の鋭さを変える。","min":0.05,"max":0.9,"step":0.05,"value":0.1}
//|   sample_period: {"type":"range","label":"標本周期 h [-]","description":"Nyquist 周波数 π/h と周波数のゆがみの大きさを変える。","min":0.1,"max":2,"step":0.1,"value":0.5}
//| cases:
//|   - {"id":"coarse-sampling","label":"h = 2","description":"Nyquist 周波数が共振の近くまで下がり、ゆがみが大きくなる。","inputs":{"sample_period":2}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"checks","path":"/rows/0/1","range":{"max":1e-12}}
//|       - {"artifact":"checks","path":"/rows/1/1","range":{"max":1e-12}}
//|   - case: coarse-sampling
//|     expect:
//|       - {"artifact":"checks","path":"/rows/0/1","range":{"max":1e-12}}
use scioxide_core::{Complex, ExecutionContext};
use scioxide_signal::{DiscretizationMethod, FrequencyResponsePlan};
use std::f64::consts::PI;

let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let model = oscillator(damping_ratio).map_err(|e| e.to_string())?;
let h = sample_period;
// 離散系の周波数は Nyquist 周波数に対する比 f（0 < f < 1）。
let ratios: Vec<f64> = (1..400).map(|k| k as f64 / 400.0).collect();
let analog: Vec<f64> = ratios.iter().map(|f| PI * f / h).collect();
// 事前ワーピングした角周波数 Ω = (2/h) tan(πf/2)。参照値（f64 の標準関数）。
let warped: Vec<f64> = ratios
    .iter()
    .map(|f| 2.0 / h * (PI * f / 2.0).tan())
    .collect();

// 連続系の Plan と作業領域を 1 回だけ作り、2 回の掃引で使い回す。
let plan = FrequencyResponsePlan::new(&model).map_err(|e| e.to_string())?;
let requirements = plan
    .workspace_requirements(ratios.len())
    .map_err(|e| e.to_string())?;
let mut workspace = plan.workspace(ratios.len()).map_err(|e| e.to_string())?;
let zero = Complex::new(0.0, 0.0);
let mut at_analog = vec![zero; requirements.output_len()];
let mut at_warped = vec![zero; requirements.output_len()];
let cx = ExecutionContext::sequential();
plan.frequency_response_into(&analog, &mut at_analog, &mut workspace, cx)
    .map_err(|e| e.to_string())?;
plan.frequency_response_into(&warped, &mut at_warped, &mut workspace, cx)
    .map_err(|e| e.to_string())?;

let tustin = model
    .discretize(h, DiscretizationMethod::GeneralizedBilinear { alpha: 0.5 })
    .and_then(|discrete| discrete.frequency_response(&ratios))
    .map_err(|e| e.to_string())?;
let zoh = model
    .discretize(h, DiscretizationMethod::ZeroOrderHold)
    .and_then(|discrete| discrete.frequency_response(&ratios))
    .map_err(|e| e.to_string())?;

// 出力は p = 2（位置、速度）、入力は m = 1 なので、周波数 k・出力 i の値は 2k + i 番目。
let warp_gap = tustin
    .values()
    .iter()
    .zip(&at_warped)
    .map(|(d, c)| (*d - *c).norm())
    .fold(0.0, f64::max);
let order_gap = analog
    .iter()
    .enumerate()
    .map(|(k, &w)| (at_analog[2 * k + 1] - Complex::new(0.0, w) * at_analog[2 * k]).norm())
    .fold(0.0, f64::max);
let rows = vec![
    ("max |H_d(e^{iπf}) − H_c(iΩ)|（Tustin、両出力）", warp_gap),
    ("max |H_速度 − iω H_位置|（連続系）", order_gap),
];
let columns = serde_json::json!([
    { "key": "0", "label": "検算" },
    { "key": "1", "label": "値 [-]", "type": "number", "format": sci3 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "checks" })
);

let magnitude = |values: &[Complex<f64>], k: usize| values[2 * k].norm();
let curve = |values: &[Complex<f64>]| -> Vec<[f64; 2]> {
    analog
        .iter()
        .enumerate()
        .map(|(k, &w)| [w, magnitude(values, k)])
        .collect()
};
emit_line_chart!(
    &vec![
        serde_json::json!({
            "name": "連続系 H_c(iω)",
            "points": curve(&at_analog),
            "style": { "lineType": "dashed" }
        }),
        serde_json::json!({ "name": "Tustin 変換", "points": curve(tustin.values()) }),
        serde_json::json!({ "name": "零次ホールド", "points": curve(zoh.values()) }),
    ],
    options = &serde_json::json!({
        "xLabel": "角周波数 ω = πf/h [rad/時間単位]",
        "yLabel": "位置の振幅 |H| [-]",
        "xType": "log",
        "yType": "log",
        "annotations": [{
            "kind": "line",
            "axis": "x",
            "value": PI / h,
            "label": "Nyquist 周波数 π/h",
            "style": { "lineType": "dotted" }
        }]
    })
);
```

既定値（$\zeta = 0.1$、$h = 0.5$）では、Tustin 変換の応答と事前ワーピングした連続系の応答の差は $1.7 \times 10^{-14}$ で、置換の等価性が丸め誤差の範囲で成り立つ。
速度と位置の比の検算の差も $8.9 \times 10^{-16}$ で、出力の並びが `[周波数][出力][入力]` であることが確かめられる。
図では、低い周波数で三つの曲線が重なる。
Tustin 変換の共振は、角周波数を $\Omega = (2/h)\tan(\pi f/2)$ に圧縮した分だけ低い $\omega$ に移り、Nyquist 周波数で振幅が 0 に向かう。
零次ホールドの応答は周期 $2\pi/h$ の折り返しを含み、Nyquist 周波数の近くで連続系から離れる。
ケース「h = 2」では Nyquist 周波数 $\pi/2$ が共振（角周波数 1）に近づき、二つの離散化の違いが大きくなる。
Tustin 変換で特定の周波数を合わせたいときは、その周波数で事前ワーピングしたアナログの設計から始める（[IIR フィルタの設計](../iir-design/)）。

## 極配置

状態フィードバック $u = -Kx$ を加えると、閉ループ系の行列は $A - BK$ になる。
極配置は、$A - BK$ の固有値が指定した $n$ 個の極 $\lambda_1, \dots, \lambda_n$ になるゲイン $K$（$m \times n$）を求める問題である。
対 $(A, B)$ が可制御なら、任意の極（実数の系では共役の組）を配置できる。

`place_poles(requested)` は次の手順で $K$ を求める。
状態か入力のないモデルは `InvalidInput`（`Empty`）、極の数が $n$ でなければ `DimensionMismatch` になる。

1. 実数の系では、非実数の極に相対距離 $32\varepsilon$ 以内の共役の相手があることを確かめ、組を正確な共役にそろえる。
   相手のない非実数の極は `InvalidInput`（`Inconsistent`）になる。
2. 可制御性行列の数値ランクを `RankPolicy` で判定し、満たなければ `NumericalInstability` を返す。
   同じ極を $\operatorname{rank}(B)$ 回より多く指定すると `InvalidInput`（`Inconsistent`）になる。
3. $\operatorname{rank}(B) = n$ なら、指定した極を固有値に持つブロック対角行列 $\Lambda$ を作り、$BK = A - \Lambda$ を $B$ の特異値分解で解く。
4. それ以外では、各極 $\lambda_j$ について $[A - \lambda_j I, -B]$ の零空間からベクトル $(v_j, w_j)$ を選び、$K = W V^{-1}$ とする。
   このとき $(A - BK) v_j = \lambda_j v_j$ が成り立つ。
   $V$ が数値的に正則になるまで零空間の列を選び直す。
5. $A - BK$ の固有値を独立に計算し、指定した極と照合する。

照合の残差 `maximum_residual` は、指定した極 $\lambda$ を順に最も近い未対応の実現した極 $\mu$ と組にしたときの $|\mu - \lambda| / (1 + |\lambda|)$ の最大値である。
残差が許容誤差（既定は $\sqrt{\varepsilon}$）以下なら終了状態 `PolePlacementTermination` は `Converged`、超えれば `ResidualToleranceNotMet` である。
標準形式 `place_poles` は後者を `ConvergenceFailure` にする。
オプション付き形式 `place_poles_with_options(requested, options)` は `PolePlacementOptions` でランクの方針（`with_rank_policy`）と許容誤差（`with_residual_tolerance`）を選び、許容誤差を満たさない場合も `PolePlacementReport` を返す。
外側の解法の上限の中で計算する場合は `place_poles_scoped` を使う。

レポートの `is_success()` が真のときだけゲインを使う。
偽でも `gain()` と `achieved_poles()` は有限な値を持ち、`trust()` は `DiagnosticOnly` を返す。
実現する極の精度は固有ベクトル行列 $V$ の条件で決まり、`transfer_condition()` がその推定を返す（$\operatorname{rank}(B) = n$ の場合は `None`）。
`controllability_condition()` と `input_condition()` は、可制御性行列と $B$ の条件の推定である。

次のセルは、積分器を $n$ 個つないだ系 $x_1' = x_2, \dots, x_{n-1}' = x_n, x_n' = u$ の極を $-1, -2, \dots, -n$ に配置する。
この系は可制御正準形なので、$A - BK$ の特性多項式は $s^n + K_n s^{n-1} + \dots + K_1$ になる。
したがって正確なゲインは $\prod_{j=1}^{n}(s + j)$ の係数で、セルはこの係数を整数演算で展開して独立に検算する。
指定した極は Wilkinson の多項式と同じく等間隔に並ぶので、$n$ を大きくすると $V$（Vandermonde 型の行列）の条件が急に悪くなる。
許容誤差の指数を変えると、同じゲインに対する終了状態の判定が変わる。

```rust
//| id: signal-lti-pole-placement
//| ref: signal-lti-pole-placement
//| title: 積分器の鎖の極配置とゲインの閉形式
//| run: reactive
//| crates: [scioxide-core, scioxide-linalg, scioxide-signal]
//| inputs:
//|   state_count: {"type":"range","label":"状態の数 n [-]","description":"積分器の数。指定する極は −1, …, −n。","min":2,"max":12,"step":1,"value":6}
//|   tolerance_exponent: {"type":"range","label":"残差の許容誤差の指数 q（10^q）","description":"PolePlacementOptions の許容誤差。","min":-14,"max":-4,"step":1,"value":-8}
//| cases:
//|   - {"id":"long-chain","label":"n = 12","description":"V の条件が悪くなり、残差が既定の許容誤差を超える。","inputs":{"state_count":12}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"gains","path":"/rows/0/3","range":{"max":1e-9}}
//|       - {"path":"/outputs/1/state","equals":"satisfied"}
//|   - case: long-chain
//|     expect:
//|       - {"path":"/outputs/1/state","equals":"partial"}
use scioxide_core::Complex;
use scioxide_linalg::Matrix;
use scioxide_signal::{LtiTime, PolePlacementOptions, StateSpace};

let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let n = state_count.round() as usize;
// A は上副対角が 1 の積分器の鎖、B = e_n、C = e_1ᵀ、D = 0。
let mut a = Matrix::zeros(n, n).map_err(|e| e.to_string())?;
for row in 0..n - 1 {
    a.as_mut_slice()[row * n + row + 1] = 1.0;
}
let mut b = Matrix::zeros(n, 1).map_err(|e| e.to_string())?;
b.as_mut_slice()[n - 1] = 1.0;
let mut c = Matrix::zeros(1, n).map_err(|e| e.to_string())?;
c.as_mut_slice()[0] = 1.0;
let d = Matrix::zeros(1, 1).map_err(|e| e.to_string())?;
let model = StateSpace::new(LtiTime::Continuous, a.view(), b.view(), c.view(), d.view())
    .map_err(|e| e.to_string())?;

let requested: Vec<Complex<f64>> = (1..=n).map(|j| Complex::new(-(j as f64), 0.0)).collect();
let options =
    PolePlacementOptions::new().with_residual_tolerance(10.0_f64.powf(tolerance_exponent));
let report = model
    .place_poles_with_options(&requested, options)
    .map_err(|e| e.to_string())?;

// 独立な検算: ∏(s + j) の係数を整数で展開する。coefficients[k] は s^k の係数。
let mut coefficients = vec![1_i64];
for j in 1..=n as i64 {
    let mut next = vec![0_i64; coefficients.len() + 1];
    for (k, &value) in coefficients.iter().enumerate() {
        next[k] += j * value;
        next[k + 1] += value;
    }
    coefficients = next;
}
let gain = report.gain().as_slice();
let gain_error = (0..n)
    .map(|k| (gain[k] - coefficients[k] as f64).abs() / coefficients[k] as f64)
    .fold(0.0, f64::max);
let condition = report
    .transfer_condition()
    .map(|estimate| 1.0 / estimate.reciprocal().value());

let columns = serde_json::json!([
    { "key": "0", "label": "K_1 = n! [-]", "type": "number", "format": sci3 },
    { "key": "1", "label": "K_n = n(n+1)/2 [-]", "type": "number", "format": sci3 },
    { "key": "2", "label": "V の条件数の推定 [-]", "type": "number", "format": sci3, "nullText": "なし" },
    { "key": "3", "label": "ゲインの最大相対誤差 [-]", "type": "number", "format": sci3 },
    { "key": "4", "label": "極の最大残差 [-]", "type": "number", "format": sci3 }
]);
emit_table_with_columns!(
    columns,
    vec![(
        gain[0],
        gain[n - 1],
        condition,
        gain_error,
        report.maximum_residual()
    )],
    metadata = serde_json::json!({ "id": "gains" })
);

let outcome = if report.is_success() {
    Outcome::satisfied("実現した極が指定した極の許容誤差の内にある")
} else {
    Outcome::partial("実現した極が許容誤差を満たさない")
        .explanation("ゲインは返るが、実現した極と V の条件を確かめてから使う。")
};
emit_outcome!(
    outcome
        .status(format!("{:?}", report.termination()))
        .diagnostic("極の最大残差", report.maximum_residual(), None)
        .diagnostic("ゲインの最大相対誤差", gain_error, None)
);
```

既定値（$n = 6$、許容誤差 $10^{-8}$）では、ゲインの最大相対誤差は $1.4 \times 10^{-13}$、極の最大残差は $4.6 \times 10^{-12}$ で、終了状態は `Converged` である。
$V$ の条件数の推定は $1.9 \times 10^{5}$ である。
ケース「n = 12」では条件数の推定が $2.1 \times 10^{14}$ まで増え、極の残差 $1.7 \times 10^{-4}$ が許容誤差を超えて `ResidualToleranceNotMet` になる。
このときゲインの相対誤差は $3.7 \times 10^{-9}$ で、ゲインそのものは閉形式に近いのに、閉ループの極は大きくずれる。
等間隔の極を持つ高次の多項式では、係数の小さな相対誤差が根を大きく動かすからである。
既定の $n = 6$ でも許容誤差の指数を $-14$ にすると、残差 $4.6 \times 10^{-12}$ が許容誤差を超えて判定は `ResidualToleranceNotMet` に変わるが、ゲインと極は変わらない。
判定は許容誤差に対する結論であり、配置の精度そのものは残差と条件数で読む。

可制御性グラミアンと最適レギュレータ（LQR）による設計は、[可制御性グラミアンと LQR の例題](oxref:linalg-lqr-controllability)で扱う。

## まとめ

状態空間モデルは `StateSpace::new` で検査して保持し、`LtiTime` で連続系と離散系を区別する。
離散化では、入力が区間で一定とみなせるなら零次ホールド、周波数軸の写像を保ちたいなら Tustin 変換を選び、前進 Euler 法の安定性の条件 $|1 + h\lambda| < 1$ に注意する。
周波数応答の周波数は、連続系では角周波数、離散系では Nyquist 周波数に対する比であり、出力は `[周波数][出力][入力]` の順に並ぶ。
連続系のインパルス応答はデルタ関数 $D\delta(t)$ を含まないので、直達項があるときは別に扱う。
極配置ではゲインだけでなく終了状態、実現した極の残差、$V$ の条件数を読む。
RLC 回路を例に Bode 線図とステップ応答の閉形式を照合するには[RLC 回路の LTI モデル](../../examples/rlc-circuit-lti/)へ進む。
