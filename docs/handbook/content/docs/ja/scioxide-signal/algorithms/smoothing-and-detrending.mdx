測定値には知りたい変化のほかに、高い周波数のノイズと、ゆっくりした傾向（ドリフト）が重なる。
平滑化は前者を減らし、トレンド除去（トレンド除去）は後者を取り除く。
どちらも、近くの標本どうしがなめらかにつながるという仮定を、多項式や差分のペナルティの形で表した最小二乗問題として書ける。
このページは、局所多項式による Savitzky–Golay フィルタ、差分のペナルティによる Whittaker–Henderson 平滑化、B スプラインの補間係数を求める再帰フィルタ、最小二乗のトレンド除去を説明する。

スパイクのような外れ値は最小二乗の当てはめを大きく動かす。
外れ値を含むデータには、先に[局所フィルタとピーク](../local-filters-and-features/)の中央値フィルタや Hampel フィルタを使う。

## Savitzky–Golay フィルタ

### 局所多項式の最小二乗

等間隔の標本 $x[i]$ のそれぞれについて、$i$ を中心とする $w = 2M + 1$ 個の標本に次数 $p$ の多項式を最小二乗で当てはめ、その値か導関数を中心で読む。
これが Savitzky–Golay フィルタである。
ウインドウの中の位置を $j = -M, \dots, M$、計画行列を $V_{jk} = j^k$（$k = 0, \dots, p$）とすると、当てはめの係数は $a = V^{+} x$ で、$V^{+}$ は擬似逆行列である。
中心での $d$ 階導関数は $d!\,a_d / h^d$（$h$ は標本間隔）なので、出力はウインドウの標本の固定した重み付き和

$$
y[i] = \sum_{j=-M}^{M} c_j\, x[i + j]
$$

になる。
重み $c_j$ はウインドウの中の位置だけで決まり、標本の値に依らないので、フィルタは FIR フィルタ（相関の形）である。

次数 $p$ 以下の多項式は当てはめで誤差なく表されるので、内部の出力はその値や導関数を丸め誤差を除いて再現する。
中心で値を読む平滑化（$d = 0$）では、ウインドウが左右対称なので、次数 $2q$ と $2q + 1$ の重みが一致する。
白色雑音の分散 $\sigma^2$ は出力で $\sigma^2 \sum_j c_j^2$ に減る。
ウインドウを広げるか次数を下げるとノイズは減るが、ピークの高さや幅のような細かい形も削られる。

`SavitzkyGolayOptions` は導関数の階数 $d$（`with_derivative`、$p$ 以下）、標本間隔 $h$（`with_spacing`、正）、評価点（`with_position`）を持つ。
既定は平滑化（$d = 0$）、間隔 1、ウインドウの中点での評価で、中点の評価には奇数のウインドウ長が要る。
`with_position(t)` はウインドウの先頭から $t \in [0, w - 1]$ 標本の位置で評価し、偶数のウインドウや中心からずれた評価に使う。

`SavitzkyGolayPlan::new(window_length, polynomial_degree, options)` は、ウインドウの座標を $[-1, 1]$ に尺度をそろえた単項式の計画行列を列交換つきの Householder QR で分解し、内部と端点のすべての重みを準備する。
準備は $O(wp^2)$、メモリは $O(wp)$ で、各出力は $O(w)$ の積和である。
積和の誤差はクレートの積和の誤差限界に従う。
ウインドウ長が 0 なら `InvalidInput`（`Empty`）、$p \ge w$ や $d > p$ なら `InvalidInput`（`OutOfRange`）、偶数のウインドウで中点を求めると `InvalidInput`（`UnsupportedConfiguration`）、計画行列が数値ランクを失えば `NumericalInstability` を返す。
`condition_estimate()` は、尺度をそろえた計画行列の 1 ノルム条件数の推定値である。
当てはめが丸め誤差にどれほど敏感かの目安であり、出力の誤差の上界ではない。
`coefficients()` は内部の重み $c$ をウインドウの時間順に返す。

### 端点の扱い

記録の端ではウインドウの一部が記録の外に出る。
`SavitzkyGolayBoundary` はその扱いを選ぶ。

- `Polynomial` は、最初（最後）の完全なウインドウに当てはめた多項式を、端の出力の位置で評価する（Gorry の方法）。
  記録の外の値を仮定しないが、空でない記録はウインドウ長以上の長さが必要で、足りなければ `InvalidInput`（`Inconsistent`）を返す。
- `Extend(SignalBoundary)` は、記録を延長してから内部の重みを適用する。
  `Zero` は外側を 0、`Periodic` は周期 $n$ の繰り返し、`Reflect` は端の標本を繰り返さない鏡像（$x[-1] = x[1]$）である。

延長は記録の外に値を作るので、その仮定が成り立たない限り、端の出力は多項式を再現しない。
ワンショット呼び出しの `savitzky_golay(input, window_length, polynomial_degree)` は、既定の `SavitzkyGolayOptions` と `Polynomial` の境界に固定した平滑化である。
導関数や他の境界を使うとき、同じウインドウで多くの記録を処理するときは Plan を作る。
Plan の `filter(input, boundary)` は結果を確保して返し、`filter_into` は `workspace_requirements` で準備した作業領域を使って呼び出し側の出力に書く。
`filter_axis_into` は N 次元の配列の一つの軸に沿う各列を処理する。

### 多項式の再現

次のセルは、次数 $q$ の多項式 $x(t) = \sum_{j=0}^{q} u^j$（$u = (t - 3)/3$、$t = 0, 0.1, \dots, 6$ の 61 標本）にフィルタをかけ、$d$ 階導関数の閉形式と比べる。
閉形式は検算のためにセルの中で独立に計算する。
表は、ウインドウが記録に収まる内部と、端の $M$ 標本のそれぞれの最大誤差、条件数の推定、重みの和 $\sum c_j$、ノイズの利得 $\sqrt{\sum c_j^2}$ を示す。
平滑化では $\sum c_j = 1$、導関数では $\sum c_j = 0$ になる。
図は閉形式（破線）とフィルタの出力（点）を重ねる。

## Whittaker–Henderson 平滑化

### ペナルティつき最小二乗と帯行列の解法

Whittaker–Henderson 平滑化は、記録全体を一度に当てはめる。
観測 $y_1, \dots, y_n$ と非負の重み $w_i$、ペナルティの強さ $\lambda \ge 0$、差分の階数 $d$ に対し、平滑化した列 $z$ は

$$
S(z) = \sum_{i=1}^{n} w_i\,|z_i - y_i|^2 + \lambda\,\lVert D_d z \rVert^2
$$

の最小点である。
$D_d$ は $d$ 階の前進差分の $(n - d) \times n$ 行列で、境界の行を加えない。
たとえば $d = 2$ では $(D_2 z)_i = z_{i+2} - 2z_{i+1} + z_i$ である。
最小点は正規方程式

$$
(W + \lambda D_d^{\mathsf T} D_d)\, z = W y, \qquad W = \operatorname{diag}(w)
$$

を満たす。
係数行列は半帯幅 $d$ の対称な帯行列なので、帯 Cholesky 分解で $O(nd^2)$ の演算と $O(nd)$ のメモリで分解できる。
$\lambda \to \infty$ では $z$ は $d - 1$ 次以下の多項式の重み付き最小二乗の当てはめに近づき、$\lambda = 0$ では $z = y$ である。
Savitzky–Golay フィルタと違い、記録の端も内部と同じ式で扱われ、ウインドウ長を選ぶ必要がない。

`WhittakerHendersonPlan::new(n, order, lambda, weights, options)` は、記録長 $n$、階数 $d$、$\lambda$、重み（`None` は単位の重み）を検査し、係数行列を 1 回だけ分解する。
各記録の平滑化は診断を含めて $O(nd)$ である。
データは実数でも複素数でもよく、重みと $\lambda$ は実数である。
$n < 2$、$d$ が $1 \le d < n$ の外、$\lambda$ や重みが負なら `InvalidInput` を返す。

### 重みと欠測

重み 0 の標本は欠測として扱われ、その値は最小点に影響しない。
欠測の区間では方程式の $W$ の行が 0 になるので、$z$ は $(D_d^{\mathsf T} D_d z)_i = 0$ を満たし、区間の中を $2d - 1$ 次の多項式でつなぐ。
最小点が一意であるには、正の重みが $d$ 個以上必要で、$\lambda = 0$ ではすべての重みが正でなければならない。
満たさなければ `InvalidInput` を返す。

正の重み $w_i$ がペナルティの対角成分に比べて小さすぎ、$w_i \le \varepsilon\lambda (D_d^{\mathsf T} D_d)_{ii}$ となると、加算の丸めで重みが失われる。
このとき準備は `NumericalInstability`（`IllConditioned`）を返す。
欠測を表すには、小さな正の重みではなく 0 を使う。

### 条件と解の診断

`conditioning()` は、データに依らない係数行列の条件を準備の時点で計算した `SmoothingConditioning` を返す。

- `Identity` は $\lambda = 0$ の場合で、系を解かずに入力を複製する。
- `ReciprocalSpectralBound(r)` は、すべての重みが正の場合の逆スペクトル条件数の下界 $r = \min w / (\max w + \lambda (\sum_j |\delta_j|)^2)$ である。
  $\delta_j$ は $d$ 階差分の係数で、$\sum_j |\delta_j| = 2^d$ である。
- `OneNormEstimate` は、重みに 0 を含む場合の、逆 1 ノルム条件数の Hager–Higham 推定である。

`smooth(input)` は結果と `SmoothingDiagnostics` を返す。
`data_fidelity()` は当てはめの項 $\sum w_i|z_i - y_i|^2$、`penalty()` はペナルティの項 $\lambda\lVert D_d z\rVert^2$ で、どちらも与えた重みの単位で表す。
`scaled_optimality_residual()` は、$A = W + \lambda D_d^{\mathsf T} D_d$、$b = Wy$ に対する成分ごとの後退誤差 $\max_i |Az - b|_i / (|A||z| + |b|)_i$ である。
これらは計算した解を記述する値で、誤差の上界ではない。
後退誤差が小さくても、条件が悪ければ前進誤差は大きくなりうるので、条件の診断と後退誤差は別々に読む。

出力先を指定する API `smooth_into(input, output, workspace, cx)` は、`workspace_requirements(lanes)` が返す `WhittakerRequirements` に合わせて準備した `WhittakerWorkspace` を使い、実行中に確保しない。
1 本の記録には `workspace(1)` を使う。
`smooth_axis_into` は N 次元の配列の一つの軸に沿う各列を同じ重みと階数で独立に平滑化し、診断は計算しない。
多次元のペナルティを持つ平滑化ではない。
一つの作業領域は、最大の要求に合わせて事前確保すれば複数の Plan で共有できる。

次のセルは、$y_k = \sin(2\pi k / 75) + 0.5\cos(2\pi k / 150) + \varepsilon_k$（$k = 0, \dots, 149$、$\varepsilon_k$ は標準偏差 0.2 の正規乱数）を平滑化する。
添字 60 から始まる区間の重みを 0 にして欠測にする。
表の上段はSciOxide の診断と、同じ量をセルの中で独立に計算した値を並べる。
停留条件の残差は、勾配 $W(z - y) + \lambda D_d^{\mathsf T} D_d z$ の最大値を $\max|Wy|$ で割った値で、差分を定義どおりに適用して手計算する。

let difference =
    |v: &[f64]| -> Vec<f64> { v.windows(2).map(|pair| pair[1] - pair[0]).collect() };
let transpose = |v: &[f64]| -> Vec<f64> {

        .map(|i| if i > 0 { v[i - 1] } else { 0.0 } - if i < v.len() { v[i] } else { 0.0 })

## B スプラインの係数と対称な再帰フィルタ

等間隔の標本 $x[0], \dots, x[n-1]$ を通る次数 $p$ の補間スプラインは

$$
s(u) = \sum_k c[k]\,\beta^p(u - k), \qquad s(i) = x[i] \quad (i = 0, \dots, n - 1)
$$

と書ける。
$\beta^p$ は中心をそろえた次数 $p$ の B スプラインで、$u$ は標本単位の位置である。
`SplineDegree::Quadratic` は $\beta^2(0) = 3/4$、$\beta^2(\pm 1) = 1/8$、`SplineDegree::Cubic` は $\beta^3(0) = 2/3$、$\beta^3(\pm 1) = 1/6$ を持つ。
補間の条件は係数の畳み込み $x[i] = \beta^p(0)c[i] + \beta^p(1)(c[i-1] + c[i+1])$ なので、係数はその逆フィルタで求まる。
逆フィルタは 1 次の因子に分解でき、極は 2 次で $-3 + 2\sqrt{2}$、3 次で $-2 + \sqrt{3}$ である。

`SymmetricFilter` は、この形の位相 0 の再帰フィルタを一般に与える。
伝達関数は

$$
H(z) = \frac{g}{A(z)\,A(z^{-1})}, \qquad A(z) = 1 - p z^{-1} \ \text{または}\ 1 - 2r\cos\theta\,z^{-1} + r^2 z^{-2}
$$

で、因果的な $1/A(z)$ の通過と反因果的な $1/A(z^{-1})$ の通過を続けて行う。
`first_order(pole, gain, options)` は実数の極 $|p| < 1$、`second_order(radius, angle, gain, options)` は半径 $[0, 1)$、角度 $[0, \pi]$ の共役な極をとり、外れれば `InvalidInput` を返す。
記録は半標本の鏡像（$x[-1] = x[0]$、$x[n] = x[n-1]$）で延長し、各通過はその周期的な延長の厳密な定常状態から始めるので、立ち上がりの過渡は生じない。
計算量は $O(n)$ である。
`filter`、`filter_into`、`filter_axis_into` を持ち、構築時には係数の検査だけを行う。

`SplineFilter::new(degree, options)` は次数と再帰フィルタを保持する。
`coefficients` は係数 $c$ を求め、`reconstruct` は係数から標本 $s(i)$ を再構成し、`evaluate_into` は任意の座標 $x$ を $u = (x - \text{origin})/\text{spacing}$ に写して $s(u)$ を評価する。
係数も半標本の鏡像で延長されるので、$s$ は $u = -1/2$ と $u = n - 1/2$ について偶関数になり、記録の外では周期 $2n$ の延長になる。
作業領域の大きさは操作に合わせて `SplineRequest::Coefficients(layout)`、`Reconstruct(layout)`、`Evaluate(count)` を `workspace_requirements` に渡して求める。
係数の計算は $O(n)$、再構成と評価は 1 点あたり $O(1)$ である。
これは平滑化ではなく補間であり、ノイズは除かれない。

次のセルは、周期 $P$ 標本の正弦波 $x[i] = \sin(2\pi i / P)$（$n = 200$）の係数を求め、三つの検算を行う。
再構成の誤差 $\max|s(i) - x[i]|$ は補間の条件を確かめる。
係数から $\beta^p$ の値で標本を手で組み立て、`reconstruct` と比べる。
内部の中点 $u = i + 1/2$ での誤差を周期 $P$ と $2P$ で測り、比の対数 $\log_2(e_P / e_{2P})$ から観測次数を求める。
次数 $p$ の補間スプラインの誤差は、十分なめらかな関数で $O(h^{p+1})$ である。

```rust
//| id: signal-spline-interpolation
//| ref: signal-spline-interpolation
//| title: B スプラインの係数による補間と中点の誤差の次数
//| run: reactive
//| crates: [scioxide-core, scioxide-signal]
//| inputs:
//|   samples_per_period: {"type":"range","label":"1 周期の標本数 P [標本]","description":"正弦波の周期。大きいほど標本が密になる。","min":6,"max":40,"step":2,"value":12}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"spline","path":"/rows/0/1","range":{"max":1e-12}}
//|       - {"artifact":"spline","path":"/rows/1/2","range":{"max":1e-12}}
//|       - {"artifact":"spline","path":"/rows/1/5","approx":{"value":4.0,"atol":0.3}}
use scioxide_core::ExecutionContext;
use scioxide_signal::{SignalExecutionOptions, SplineDegree, SplineFilter, SplineRequest};
use std::f64::consts::PI;

let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let fixed2 = serde_json::json!({ "fractionDigits": 2 });
let n = 200_usize;
// 中点は境界から離れた内部だけを使う。
let coordinates: Vec<f64> = (n / 4..3 * n / 4).map(|i| i as f64 + 0.5).collect();
let degrees = [
    ("2 次", SplineDegree::Quadratic, 0.75, 0.125),
    ("3 次", SplineDegree::Cubic, 2.0 / 3.0, 1.0 / 6.0),
];
let mut rows = Vec::new();
for (name, degree, center, neighbor) in degrees {
    let spline = SplineFilter::<f64>::new(degree, SignalExecutionOptions::new())
        .map_err(|e| e.to_string())?;
    let mut workspace = spline
        .workspace::<f64>(SplineRequest::Evaluate(coordinates.len()))
        .map_err(|e| e.to_string())?;
    let mut midpoint_errors = [0.0_f64; 2];
    let (mut interpolation, mut assembly) = (0.0_f64, 0.0_f64);
    for (level, error) in midpoint_errors.iter_mut().enumerate() {
        let period = samples_per_period * f64::from(1_u32 << level);
        // 標本と中点の真値は参照値（f64 の標準関数）。
        let samples: Vec<f64> = (0..n)
            .map(|i| (2.0 * PI * i as f64 / period).sin())
            .collect();
        let coefficients = spline.coefficients(&samples).map_err(|e| e.to_string())?;
        let mut values = vec![0.0; coordinates.len()];
        spline
            .evaluate_into(
                &coefficients,
                &coordinates,
                0.0,
                1.0,
                &mut values,
                &mut workspace,
                ExecutionContext::sequential(),
            )
            .map_err(|e| e.to_string())?;
        *error = coordinates
            .iter()
            .zip(&values)
            .map(|(&u, &s)| (s - (2.0 * PI * u / period).sin()).abs())
            .fold(0.0, f64::max);
        if level == 0 {
            let nodes = spline
                .reconstruct(&coefficients)
                .map_err(|e| e.to_string())?;
            interpolation = nodes
                .iter()
                .zip(&samples)
                .map(|(s, x)| (s - x).abs())
                .fold(0.0, f64::max);
            // 独立な検算: 半標本の鏡像 c[−1] = c[0]、c[n] = c[n−1] で β の値を掛けて足す。
            let c = |i: isize| coefficients[i.clamp(0, n as isize - 1) as usize];
            assembly = (0..n as isize)
                .map(|i| {
                    (center * c(i) + neighbor * (c(i - 1) + c(i + 1)) - nodes[i as usize]).abs()
                })
                .fold(0.0, f64::max);
        }
    }
    let order = (midpoint_errors[0] / midpoint_errors[1]).log2();
    rows.push((
        name,
        interpolation,
        assembly,
        midpoint_errors[0],
        midpoint_errors[1],
        order,
    ));
}
let columns = serde_json::json!([
    { "key": "0", "label": "次数" },
    { "key": "1", "label": "補間の誤差 [-]", "type": "number", "format": sci3 },
    { "key": "2", "label": "手計算の再構成との差 [-]", "type": "number", "format": sci3 },
    { "key": "3", "label": "中点の誤差（P）[-]", "type": "number", "format": sci3 },
    { "key": "4", "label": "中点の誤差（2P）[-]", "type": "number", "format": sci3 },
    { "key": "5", "label": "観測次数 [-]", "type": "number", "format": fixed2 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "spline" })
);
```

既定の $P = 12$ では、補間の誤差は 2 次で $1.0 \times 10^{-15}$、3 次で $4.4 \times 10^{-16}$ で、どちらの係数も標本を通るスプラインを与える。
手で組み立てた再構成との差も $2.3 \times 10^{-16}$ 以下である。
中点の誤差は 3 次で $2.0 \times 10^{-4}$ から $1.2 \times 10^{-5}$ に減り、観測次数は 4.04 で理論の 4 に近い。
2 次の観測次数も 3.99 で、一般の位置での $O(h^3)$ より速く減る。
2 次の中心 B スプラインの節点は標本の中点にあり、偶数次の補間スプラインでは節点の誤差が一段速く減る（超収束）。
$P$ を小さくして 1 周期 6 標本に近づけると、どちらの次数でも漸近的な次数から外れる。

## トレンド除去

トレンド除去は記録や区間ごとに定数か直線を最小二乗で当てはめ、その残差を返す。
`DetrendKind::Constant` は区間の平均、`DetrendKind::Linear` は標本の添字 $k$ についての最小二乗直線 $\alpha + \beta k$ を引く。
直線の傾きは

$$
\beta = \frac{\sum_k (k - \bar k)(x_k - \bar x)}{\sum_k (k - \bar k)^2}, \qquad \alpha + \beta k = \bar x + \beta (k - \bar k)
$$

で、SciOxide は区間の中点を原点にした添字でモーメントを累積して、桁の打ち消しを抑える。
1 標本の区間の残差は 0 である。
複素数の標本は実部と虚部を別々に当てはめる。

ワンショット呼び出しの `detrend(input, kind)` は記録全体に 1 本の傾向を当てはめ、結果を確保して返す。
空の記録は空の結果を返す。
`detrend_into(input, kind, breakpoints, output, cx)` は、狭義に増加する内部の添字 `breakpoints`（$1, \dots, n - 1$ の範囲）で記録を区間に分け、区間ごとに独立に当てはめる。
0 と $n$ は暗黙の区切りである。
区切りが増加していないか範囲の外にあれば `InvalidInput`（`OutOfRange`）を返す。
区間どうしの傾向は連続とは限らず、区切りで跳んでよい。
作業配列を借りず、すべての区間を検査してから書き込む 2 回の走査で $O(n)$ の計算を行い、確保しない。
各残差の成分の絶対誤差は、長さ $n$ の区間で $\gamma_{8n+32} M + (8n + 32)\eta$ 以下である（$M$ は区間の成分の最大の大きさ、$\eta$ は最小の正の非正規数）。

次のセルは、周期 25 標本の振動 $0.5\sin(2\pi k / 25)$ に、区切り $b$ で跳びと傾きが変わる傾向を加えた 200 標本の記録を作る。
傾向は $k < b$ で $0.01k$、$k \ge b$ で $J - 0.005(k - b)$ である（$J$ は跳び）。
記録全体の除去（`detrend`）と区切りを与えた除去（`detrend_into`）の残差を、それぞれ元の振動と比べる。
区間ごとの最小二乗直線をセルの中で正規方程式から独立に計算し、`detrend_into` の結果と照合する。

```rust
//| id: signal-detrend-piecewise
//| ref: signal-detrend-piecewise
//| title: 区切りを持つトレンド除去と記録全体のトレンド除去
//| run: reactive
//| crates: [scioxide-core, scioxide-signal]
//| inputs:
//|   breakpoint: {"type":"range","label":"区切り b [標本]","description":"傾向が跳ぶ添字。","min":40,"max":160,"step":10,"value":120}
//|   jump: {"type":"range","label":"跳び J [-]","description":"区切りでの傾向の値。","min":-2,"max":2,"step":0.5,"value":1.5}
//|   kind: {"type":"select","label":"当てはめる傾向","options":["Linear","Constant"],"value":"Linear"}
//| cases:
//|   - {"id":"constant","label":"Constant","description":"平均だけを引くと、区間の中の傾きが残る。","inputs":{"kind":"Constant"}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"detrend","path":"/rows/0/2","range":{"max":1e-12}}
//|       - {"artifact":"detrend","path":"/rows/0/1","range":{"max":0.1}}
//|   - case: constant
//|     expect:
//|       - {"artifact":"detrend","path":"/rows/0/2","range":{"max":1e-12}}
use scioxide_core::ExecutionContext;
use scioxide_signal::{DetrendKind, detrend, detrend_into};
use std::f64::consts::PI;

let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let n = 200_usize;
let b = breakpoint.round() as usize;
let linear = kind == "Linear";
let method = if linear {
    DetrendKind::Linear
} else {
    DetrendKind::Constant
};
// 振動は参照値（f64 の標準関数）。
let oscillation: Vec<f64> = (0..n)
    .map(|k| 0.5 * (2.0 * PI * k as f64 / 25.0).sin())
    .collect();
let record: Vec<f64> = (0..n)
    .map(|k| {
        let trend = if k < b {
            0.01 * k as f64
        } else {
            jump - 0.005 * (k - b) as f64
        };
        trend + oscillation[k]
    })
    .collect();

let global = detrend(&record, method).map_err(|e| e.to_string())?;
let mut piecewise = vec![0.0; n];
detrend_into(
    &record,
    method,
    &[b],
    &mut piecewise,
    ExecutionContext::sequential(),
)
.map_err(|e| e.to_string())?;

// 独立な検算: 区間ごとの最小二乗直線（または平均）を正規方程式から求める。
let mut hand = vec![0.0; n];
for (start, end) in [(0, b), (b, n)] {
    let count = (end - start) as f64;
    let mean_k = (start..end).map(|k| k as f64).sum::<f64>() / count;
    let mean_x = record[start..end].iter().sum::<f64>() / count;
    let sxx: f64 = (start..end).map(|k| (k as f64 - mean_k).powi(2)).sum();
    let sxy: f64 = (start..end)
        .map(|k| (k as f64 - mean_k) * (record[k] - mean_x))
        .sum();
    let slope = if linear { sxy / sxx } else { 0.0 };
    for k in start..end {
        hand[k] = record[k] - (mean_x + slope * (k as f64 - mean_k));
    }
}
let rms = |residual: &[f64]| {
    (residual
        .iter()
        .zip(&oscillation)
        .map(|(r, o)| (r - o).powi(2))
        .sum::<f64>()
        / n as f64)
        .sqrt()
};
let check = piecewise
    .iter()
    .zip(&hand)
    .map(|(a, h)| (a - h).abs())
    .fold(0.0, f64::max);
let columns = serde_json::json!([
    { "key": "0", "label": "全体の除去と振動の RMS 差 [-]", "type": "number", "format": sci3 },
    { "key": "1", "label": "区分的な除去と振動の RMS 差 [-]", "type": "number", "format": sci3 },
    { "key": "2", "label": "手計算との最大差 [-]", "type": "number", "format": sci3 }
]);
emit_table_with_columns!(
    columns,
    vec![(rms(&global), rms(&piecewise), check)],
    metadata = serde_json::json!({ "id": "detrend" })
);

let curve = |values: &[f64]| -> Vec<[f64; 2]> {
    values
        .iter()
        .enumerate()
        .map(|(k, &v)| [k as f64, v])
        .collect()
};
emit_line_chart!(
    &vec![
        serde_json::json!({ "name": "記録", "points": curve(&record) }),
        serde_json::json!({ "name": "全体の除去", "points": curve(&global) }),
        serde_json::json!({ "name": "区分的な除去", "points": curve(&piecewise) }),
    ],
    options = &serde_json::json!({
        "xLabel": "標本の添字 k [-]",
        "yLabel": "値 [-]",
        "yMin": -3.0,
        "yMax": 3.5,
        "annotations": [{
            "kind": "line",
            "axis": "x",
            "value": b as f64,
            "label": "区切り b",
            "style": { "lineType": "dotted" }
        }]
    })
);
```

既定値（$b = 120$、$J = 1.5$、`Linear`）では、区分的な除去の残差と元の振動の RMS 差は 0.044 で、残るのは振動のうち各区間の直線に射影された小さな成分だけである。
記録全体の除去では跳びを 1 本の直線で表せず、RMS 差は 0.196 に増える。
手計算との最大差は $6.7 \times 10^{-16}$ で、区間ごとの当てはめが独立に行われていることを確かめられる。
ケース「Constant」では平均だけを引くので区間の中の傾きが残り、区分的な除去でも RMS 差は 0.279 になる。
区切りを実際の跳びの位置からずらすと、ずれた区間に傾向の一部が残る。
区切りは、センサーの再起動のように外部の情報から分かる位置に置く。

## まとめ

Savitzky–Golay フィルタはウインドウの中の多項式を再現する FIR フィルタで、ウインドウ長と次数でノイズの低減と形の保存を交換し、端点の扱いを `SavitzkyGolayBoundary` で明示して選ぶ。
Whittaker–Henderson 平滑化は記録全体のペナルティつき最小二乗で、重み 0 で欠測を補い、条件の診断と後退誤差を別々に読む。
`SplineFilter` は平滑化ではなく B スプライン補間の係数を求め、`SymmetricFilter` は位相 0 の再帰フィルタを定常状態から始めて適用する。
トレンド除去は区間ごとの最小二乗で、跳びの位置が分かっていれば `detrend_into` に区切りを渡す。
外れ値を含むデータの前処理とピークの検出は[局所フィルタとピーク](../local-filters-and-features/)、ノイズとピークと外れ値を組み合わせた検算は[平滑化・ピーク・外れ値の検算](../../examples/smoothing-peaks-and-outliers/)で確かめる。
