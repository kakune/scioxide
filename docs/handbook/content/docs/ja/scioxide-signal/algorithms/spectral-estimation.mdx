ノイズを含む記録のパワーが周波数ごとにどう分布するかを知りたいとき、記録の DFT の絶対値の二乗をそのまま使うと、推定値は大きくばらつく。
このページでは、パワースペクトル密度の推定を確率過程の問題として定式化し、ばらつきを平均で抑える Welch 法、二つの記録の関係を測る相互スペクトルとコヒーレンス、時刻が等間隔でない標本の Lomb–Scargle 法を導く。
ウインドウの指標は[窓関数と DPSS](../windows-and-dpss/)、フレームの規約は [STFT と再構成](../stft/)を前提とする。

## パワースペクトル密度と推定の問題

標本化周波数 $f_s$ で標本化した平均 0 の弱定常過程 $x[n]$ の自己相関を $R[\ell] = \mathrm{E}[x[n+\ell]\,\overline{x[n]}]$ とする。
（両側の）パワースペクトル密度（PSD）は

$$
S(f) = \frac{1}{f_s} \sum_{\ell=-\infty}^{\infty} R[\ell]\, e^{-2\pi i f \ell / f_s}, \qquad -\frac{f_s}{2} \le f < \frac{f_s}{2}
$$

で、$\int S(f)\, df = R[0]$（過程の分散）を満たす。
単位は信号の単位の二乗を周波数の単位で割ったもの（電圧なら V²/Hz）である。
分散 $\sigma^2$ の白色雑音では $S(f) = \sigma^2/f_s$ で、実数の信号の正の周波数だけに電力をまとめた片側の密度は $2\sigma^2/f_s$ になる。

有限の記録 $x[0], \dots, x[N-1]$ にウインドウ $w$ を掛けた DFT $X_k$ から作るピリオドグラム

$$
\hat S_k = \frac{|X_k|^2}{f_s \sum_n w[n]^2}
$$

は、$N$ が大きいとき $S$ を $|W|^2$ でぼかした値の不偏推定に近づく。
しかし Gauss 過程では各ビンの $\hat S_k$ が自由度 2 の $\chi^2$ 分布に比例し、標準偏差が平均と同じ大きさになる。
記録を長くしてもビンが細かくなるだけで、各ビンのばらつきは減らない。
ばらつきを下げるには、独立に近い推定を平均する必要がある。

## 離散パワースペクトルと相互スペクトル

`power_spectrum(input)` は、長さ $n$ の記録の正規化しない DFT $X$ から離散パワースペクトル $|X[k]|^2/n$ を返す。
ビンは DFT の自然な順に並び、標本化周波数を含まないので密度ではない。
Parseval の関係から $\sum_k |X[k]|^2/n = \sum_j |x[j]|^2$ が成り立つ。
`cross_spectrum(a, b)` は $A[k]\,\overline{B[k]}/n$ を返し、ビン $k$ の位相は、その周波数で $a$ が $b$ より進んでいる位相である。
どちらも長さ $n$ の FFT を 1 回（相互スペクトルは 2 回）使い、空の入力は `InvalidInput`（`Empty`）、長さの違う入力は `DimensionMismatch`、NaN や無限大は `NonFinite`、桁あふれは `NumericalInstability` になる。
同じ長さで繰り返すときは `SpectralEstimatePlan::discrete(n)` が同じ計算を準備する。

## Welch 法

Welch 法は、記録を重なりのある短い区分に分け、区分ごとのピリオドグラムを平均する。
ウインドウ長（区分の長さ）を $m$、重なりを $o$ とすると、長さ $N \ge m$ の記録は

$$
K = 1 + \left\lfloor \frac{N - m}{m - o} \right\rfloor
$$

個の区分を持つ。
区分は標本 0 から始まり、最後の区分に入りきらない末尾の標本は使わない。
各区分から傾向（既定では平均）を引き、ウインドウを掛けて長さ $n \ge m$ の FFT をとる。
区分の推定は $P_{xx} = |X|^2/S$ で、尺度 $S$ は次の節で決める。
区分の推定を平均すると、重なりのない独立な区分では分散が $1/K$ になる。
重なった区分は相関を持つので、分散の減り方はその分だけ遅い。
50 % 重なりの Hann ウインドウでは隣の区分との相関が 16.7 % で、分散は $K$ が大きいとき約 $(1 + 2 \cdot 0.167^2)/K$ 倍になる（Harris の表 1）。

区分を短くすると $K$ が増えて分散は下がるが、ビンの幅 $f_s/m$ が広がり分解能が下がる。
Welch 法の調整はこの分散と分解能の交換である。

`SpectralAverage` は区分の推定をまとめる方法を選ぶ。
`Mean`（既定）は算術平均で、ビンごとに補償和で足す。
`Median` は中央値をとり、単位平均の指数分布の中央値 $\sum_{i=1}^{2J+1} (-1)^{i+1}/i$（$J = \lfloor (K-1)/2 \rfloor$）で割って偏りを補正する。
$K$ が偶数なら中央の二つの平均をとり、相互スペクトルでは実部と虚部の中央値を別々にとる。
中央値は一部の区分だけに入った過渡的な外れ値に強いが、正規分布のノイズでは平均より分散が大きい。

ワンショット呼び出しの `welch(input, sample_rate, segment_len)` は、ウインドウ長 $m$ に応じて三つの値を固定する。
ウインドウは周期 Hann ウインドウ $w[j] = \sin^2(\pi j/m)$、重なりは $\lfloor m/2 \rfloor$ 標本、並びは実数の標本では片側、複素数の標本では全体である。
他の設定は `SpectralEstimateOptions` の既定（FFT 長 $m$、密度の尺度、平均の除去、算術平均）である。
`segment_len` が 0 なら `InvalidInput`（`Empty`）、$2^{52}$ 以上か `sample_rate` が正でなければ `InvalidInput`（`OutOfRange`）、記録が 1 区分より短ければ `InvalidInput`（`Inconsistent`）になる。
計算量は区分ごとに長さ $m$ の FFT 1 回である。

## 密度とスペクトルの単位

`SpectralScaling` は尺度 $S$ を選ぶ。

- `Density`（既定）: $S = f_s \sum w^2$。
  パワースペクトル密度で、単位は信号の単位の二乗／周波数の単位である。
  全ビンにビンの幅 $f_s/n$ を掛けて足すと、区分ごとの $\sum_j (w[j] x[j])^2 / \sum_j w[j]^2$（ウインドウで重み付けした平均二乗）の平均になる。
- `Spectrum`: $S = (\sum w)^2$。
  パワースペクトルで、単位は信号の単位の二乗である。
  ビンの中心にある振幅 $A$ の正弦波の片側のピークの高さが、その平均電力 $A^2/2$ になる。

片側の並び（`StftPacking::OneSided`）では、DC と（$n$ が偶数なら）Nyquist のビン以外を 2 倍し、負の周波数の電力を正の側にまとめる。
密度はノイズのように帯域に広がった電力に、スペクトルは線スペクトルの振幅に使う。
ノイズフロアを読むときは、密度を使えば区分の長さを変えても値が変わらない。
スペクトルの尺度ではノイズフロアが ENBW $\cdot f_s/n$ 倍になり、区分の長さで変わる。

## 推定の Plan と作業領域

`SpectralEstimatePlan::new(window, options)` は実数のウインドウと設定を受け取り、ウインドウ長を区分の長さにする。
`SpectralEstimateOptions` の既定は、重なり 0、FFT 長がウインドウ長、標本化周波数 1、`StftPacking::Full`、`SpectralScaling::Density`、トレンド除去 `Some(DetrendKind::Constant)`、`SpectralAverage::Mean`、逐次実行である。
設定の関数は検査せず、`new` がウインドウ長以上の重なり、ウインドウより短い FFT 長、正でない標本化周波数を `InvalidInput` にする。
複素数の型での片側の並びは `InvalidInput`（`UnsupportedConfiguration`）、`Spectrum` で和が 0 のウインドウと `Density` で全標本が 0 のウインドウは `DomainError` になる。

Plan は不変で、`power`・`csd`・`coherence` の所有値を返す API と、`power_into`・`csd_into`・`coherence_into` の出力先を指定する API を持つ。
`bins()` がビンの数、`frequency(k)` がビン $k$ の周波数（時間単位あたりの周期）、`segments(N)` が区分の数 $K$ を返す。
作業領域は `workspace(SignalLayout::Contiguous(N))` で確保し、一つの大きさがすべての統計量に使える。
`Mean` の作業領域は区分の数によらず、`Median` は区分の数に比例する。
配列の 1 つの軸に沿った推定 `power_axis_into`・`csd_axis_into`・`coherence_axis_into` は、標本の軸をビンの軸に置き換える。

記録は必要なら 2 の冪で尺度を変えてから計算し、推定値が早すぎる桁あふれや下位桁あふれを起こさない。
各区分のスペクトルは FFT の正規ノルム誤差を持ち、$K$ 個の平均は $\gamma_{8K+32} M/K + (8K + 32)\eta$ 以下の誤差を加える。
$M$ は区分ごとの推定を作る積の絶対値の和、$\eta$ は最小の正の非正規数である。

次のセルは、標本化周波数 1000 Hz で 8.192 s 記録した振幅 1 V、100 Hz の正弦波と白色雑音の和から、記録全体のピリオドグラムと Welch 法の推定を作る。
どちらも周期 Hann ウインドウ、片側の並び、密度の尺度を使う。
ノイズの帯域 200〜450 Hz で推定の平均を理論のノイズフロア $2\sigma^2/f_s$ と比べ、相対標準偏差を上の分散の近似と比べる。
正弦波の電力は、100 Hz の前後 4 ビンの密度からノイズフロアを引いて積分し、$A^2/2 = 0.5$ V² と比べる。
Parseval の列は密度の積分とウインドウで重み付けした平均二乗の相対差である。

```rust
//| id: signal-welch-variance
//| ref: signal-welch-variance
//| title: ピリオドグラムと Welch 法のノイズフロアとばらつきを比べる
//| run: reactive
//| crates: [scioxide-core, scioxide-signal]
//| inputs:
//|   segment_len: {"type":"select","label":"Welch 法の区分の長さ m [標本]","options":["64","256","1024"],"value":"256"}
//|   median_average: {"type":"checkbox","label":"中央値で平均する","description":"SpectralAverage::Median を使う。","value":false}
//|   noise_sigma: {"type":"range","label":"ノイズの標準偏差 σ [V]","description":"白色雑音の大きさ。","min":0.1,"max":3,"step":0.1,"value":1}
//|   seed: {"type":"integer","label":"乱数のシード","description":"ノイズの系列を変える。","min":1,"max":9999,"value":3}
//| cases:
//|   - {"id":"short-segments","label":"m = 64","description":"区分が多く分散は小さいが、ビンの幅が 15.6 Hz に広がる。","inputs":{"segment_len":"64"}}
//|   - {"id":"median","label":"中央値","description":"中央値の偏りの補正でノイズフロアがそろうが、分散は平均より大きい。","inputs":{"median_average":true}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"estimates","path":"/rows/0/1","equals":1}
//|       - {"artifact":"estimates","path":"/rows/1/1","equals":63}
//|       - {"artifact":"estimates","path":"/rows/1/3","approx":{"value":1.0,"atol":0.1}}
//|       - {"artifact":"estimates","path":"/rows/1/6","approx":{"value":0.5,"atol":0.05}}
//|       - {"artifact":"estimates","path":"/rows/1/7","range":{"max":1e-12}}
//|   - case: median
//|     expect:
//|       - {"artifact":"estimates","path":"/rows/1/3","approx":{"value":1.0,"atol":0.15}}
//|       - {"artifact":"estimates","path":"/rows/1/7","equals":null}
use scioxide_core::RealScalar;
use scioxide_signal::{
    SpectralAverage, SpectralEstimateOptions, SpectralEstimatePlan, StftPacking, WindowKind,
    WindowNormalization, WindowSymmetry, window,
};

let (fs, len, f0, amplitude) = (1000.0_f64, 8192_usize, 100.0_f64, 1.0_f64);
// ノイズ: splitmix64 と Box–Muller（f64 の固有メソッドで変換）
let mut state = seed as u64;
let mut uniform = || -> f64 {
    state = state.wrapping_add(0x9E37_79B9_7F4A_7C15);
    let mut z = state;
    z = (z ^ (z >> 30)).wrapping_mul(0xBF58_476D_1CE4_E5B9);
    z = (z ^ (z >> 27)).wrapping_mul(0x94D0_49BB_1331_11EB);
    ((z ^ (z >> 31)) >> 11) as f64 / (1u64 << 53) as f64 + 0.5 / (1u64 << 53) as f64
};
let tau = 2.0 * core::f64::consts::PI;
let x: Vec<f64> = (0..len)
    .map(|i| {
        let gauss = (-2.0 * uniform().ln()).sqrt() * (tau * uniform()).cos();
        amplitude * RealScalar::sin(tau * f0 * i as f64 / fs) + noise_sigma * gauss
    })
    .collect();
let floor = 2.0 * noise_sigma * noise_sigma / fs;
let m: usize = segment_len.parse().map_err(|_| "区分の長さ")?;
let mut rows = Vec::new();
let mut curves = Vec::new();
for (name, seg, overlap) in [("ピリオドグラム", len, 0), ("Welch 法", m, m / 2)] {
    let w = window::<f64>(WindowKind::Hann, seg, WindowSymmetry::Periodic, WindowNormalization::Native)
        .map_err(|e| e.to_string())?;
    let average = if median_average { SpectralAverage::Median } else { SpectralAverage::Mean };
    let options = SpectralEstimateOptions::new()
        .with_sample_rate(fs)
        .with_overlap(overlap)
        .with_packing(StftPacking::OneSided)
        .with_average(average);
    let plan = SpectralEstimatePlan::new(&w, options).map_err(|e| e.to_string())?;
    let density = plan.power(&x).map_err(|e| e.to_string())?;
    let segments = plan.segments(len).map_err(|e| e.to_string())?;
    let df = fs / seg as f64;
    // ノイズの帯域 200〜450 Hz の平均と相対標準偏差
    let band: Vec<f64> = density
        .iter()
        .enumerate()
        .filter(|(k, _)| (200.0..=450.0).contains(&(*k as f64 * df)))
        .map(|(_, &p)| p)
        .collect();
    let mean = band.iter().sum::<f64>() / band.len() as f64;
    let spread = (band.iter().map(|p| (p - mean).powi(2)).sum::<f64>() / band.len() as f64).sqrt();
    let correlation = if overlap > 0 { 0.167_f64 } else { 0.0 };
    let theory = ((1.0 + 2.0 * (1.0 - 1.0 / segments as f64) * correlation.powi(2)) / segments as f64).sqrt();
    // 正弦波の電力: 100 Hz の前後 4 ビンでノイズフロアを引いて積分する
    let center = (f0 / df).round() as usize;
    let line: f64 = density[center - 4..=center + 4].iter().map(|p| (p - mean) * df).sum();
    // 独立な検算（平均のときだけ）: 密度の積分とウインドウで重み付けした平均二乗（区分の平均）
    let parseval = (!median_average).then(|| {
        let energy: f64 = w.iter().map(|v| v * v).sum();
        let step = seg - overlap;
        let weighted: f64 = (0..segments)
            .map(|s| {
                let segment = &x[s * step..s * step + seg];
                let mean_x = segment.iter().sum::<f64>() / seg as f64;
                segment.iter().zip(&w).map(|(v, c)| ((v - mean_x) * c).powi(2)).sum::<f64>()
            })
            .sum::<f64>()
            / (segments as f64 * energy);
        let integral = density.iter().sum::<f64>() * df;
        (integral - weighted).abs() / weighted
    });
    rows.push((name, segments, df, mean / floor, spread / mean, theory, line, parseval));
    let points: Vec<[f64; 2]> = density
        .iter()
        .enumerate()
        .filter(|(_, p)| **p > 0.0)
        .map(|(k, &p)| [k as f64 * df, p])
        .collect();
    curves.push(serde_json::json!({ "name": name, "points": points }));
}

let fixed3 = serde_json::json!({ "fractionDigits": 3 });
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let columns = serde_json::json!([
    { "key": "0", "label": "推定" },
    { "key": "1", "label": "区分の数 K", "type": "integer" },
    { "key": "2", "label": "ビンの幅 [Hz]", "type": "number", "format": fixed3 },
    { "key": "3", "label": "ノイズフロアの平均 / 2σ²/f_s [-]", "type": "number", "format": fixed3 },
    { "key": "4", "label": "ノイズフロアの相対標準偏差 [-]", "type": "number", "format": fixed3 },
    { "key": "5", "label": "分散の近似による値 [-]", "type": "number", "format": fixed3 },
    { "key": "6", "label": "正弦波の電力 [V²]", "type": "number", "format": fixed3 },
    { "key": "7", "label": "Parseval の相対差 [-]", "type": "number", "format": sci2, "nullText": "対象外" }
]);
emit_table_with_columns!(columns, rows, metadata = serde_json::json!({ "id": "estimates" }));
emit_line_chart!(
    &curves,
    options = &serde_json::json!({
        "xLabel": "周波数 f [Hz]",
        "yLabel": "片側のパワースペクトル密度 [V²/Hz]",
        "yType": "log",
        "xMin": 0.0,
        "xMax": 500.0,
        "yMin": 1e-7,
        "yMax": 10.0,
        "annotations": [
            { "kind": "line", "axis": "y", "value": floor, "label": "理論のノイズフロア 2σ²/f_s" },
            { "kind": "line", "axis": "x", "value": f0, "label": "100 Hz" }
        ]
    })
);
```

既定の $\sigma = 1$ V、$m = 256$、シード 3 では、ピリオドグラム（$K = 1$、ビンの幅 0.122 Hz）のノイズフロアは理論値の 1.021 倍で、相対標準偏差は 0.965 である。
ばらつきは平均とほぼ同じ大きさで、上の $\chi^2_2$ 分布の性質のとおりになる。
Welch 法（$K = 63$、ビンの幅 3.906 Hz）ではノイズフロアが 0.990 倍、相対標準偏差が 0.105 に下がる。
分散の近似による値は 0.129 で、シードを 1〜8 に変えると相対標準偏差は 0.101〜0.142 の範囲に散らばる。
帯域の 64 個のビンから求めた標準偏差そのものが 1 割程度の統計的なばらつきを持つので、この差は推定の不確かさの範囲にある。

$m = 64$ では $K = 255$ で相対標準偏差は 0.041（近似 0.064）に下がるが、ビンの幅は 15.6 Hz に広がる。
この場合は帯域のビンが 16 個しかなく、標準偏差の推定そのもののばらつきが大きい。
$m = 1024$ では $K = 15$、相対標準偏差は 0.240（近似 0.265）である。
正弦波の電力はピリオドグラムで 0.515 V²、Welch 法で 0.511 V² となり、$A^2/2 = 0.5$ V² に近い。
密度の積分とウインドウで重み付けした平均二乗の相対差は $4.0 \times 10^{-15}$ 以下で、Parseval の関係が丸め誤差の範囲で成り立つ。

中央値にすると、ノイズフロアは理論値の 0.988 倍にそろうが、相対標準偏差は 0.150 に増える。
正弦波の電力は 0.750 V² と大きく出る。
中央値の補正の除数（$K = 63$ で約 0.70）は、区分の推定がノイズのように指数分布に従うことを仮定している。
どの区分でもほぼ同じ値を持つ線スペクトルでは、補正が値を約 1/0.70 倍に過大にする。
σ を変えてもノイズフロアの比と相対標準偏差は変わらず、正弦波の電力のばらつきだけが σ とともに大きくなる。

## 相互スペクトルとコヒーレンス

二つの記録 $x$、$y$ の同じ区分の DFT を $X$、$Y$ とすると、相互スペクトルの推定は区分の $X\overline{Y}/S$ の平均 $P_{xy}$ である。
`csd` はこれを返し、位相はその周波数で $x$ が $y$ より進んでいる位相になる。
$y$ が $x$ を $D$ 標本遅らせたものなら、$P_{xy}$ の位相は $2\pi f D/f_s$ で、周波数に比例する。

二乗コヒーレンス

$$
\hat\gamma^2(f) = \frac{|P_{xy}(f)|^2}{P_{xx}(f)\, P_{yy}(f)}
$$

は、周波数ごとに $y$ のうち $x$ と線形に関係する電力の割合を表し、Cauchy–Schwarz の不等式から $[0, 1]$ に入る。
区分が 1 つしかなければ $|X\overline Y|^2 = |X|^2 |Y|^2$ なので、どんな記録でも $\hat\gamma^2 = 1$ になる。
これは推定の性質で、二つの記録の関係を示さない。
独立な記録（$\gamma^2 = 0$）でも、$K$ 個の独立な区分の平均は約 $1/K$ の正の偏りを持つ。

`coherence` は算術平均の推定から計算するので、`SpectralAverage::Median` の Plan では `InvalidInput`（`UnsupportedConfiguration`）を返す。
丸めで 1 を $64\varepsilon$ 以下だけ超えた値は 1 にし、それ以上なら `NumericalInstability`（`LossOfSignificance`）、あるビンで $P_{xx}$ か $P_{yy}$ が 0 なら `DomainError`（`Undefined`）になる。
どちらかの記録を 2 の冪倍してもコヒーレンスは変わらない。

次のセルは、単位分散の白色雑音 $s$ に独立なノイズ（標準偏差 $\sigma$）を加えた $x = s + n_1$ と、$s$ を $D$ 標本遅らせて別のノイズを加えた $y = s[\cdot - D] + n_2$ を作る（標本化周波数 1）。
このときの真のコヒーレンスはすべての周波数で $\gamma^2 = 1/(1 + \sigma^2)^2$ である。
区分の長さを 4096（区分 1 つ）から 64 まで変えて、コヒーレンスの平均、相互スペクトルの位相の傾きから求めた遅れ $\hat D$ を表にする。
期待値の近似の列は、独立な $K$ 個の区分を仮定した $\mathrm{E}[\hat\gamma^2] \approx \gamma^2 + (1 - \gamma^2)^2/K$（Carter らの近似）で、独立な検算にあたる。
$\hat D$ は隣り合うビンの位相差 $\arg \sum_k P_{xy}[k+1]\overline{P_{xy}[k]}$ を $2\pi/m$ で割って求め、位相を連続につなぐ処理を避ける。

```rust
//| id: signal-coherence-delay
//| ref: signal-coherence-delay
//| title: コヒーレンスの偏りと相互スペクトルの位相から遅れを読む
//| run: reactive
//| crates: [scioxide-signal]
//| inputs:
//|   noise_sigma: {"type":"range","label":"独立なノイズの標準偏差 σ [-]","description":"真のコヒーレンス 1/(1 + σ²)² を決める。","min":0,"max":2,"step":0.1,"value":1}
//|   delay: {"type":"range","label":"遅れ D [標本]","description":"y を x より遅らせる標本数。","min":0,"max":24,"step":1,"value":5}
//|   seed: {"type":"integer","label":"乱数のシード","description":"ノイズの系列を変える。","min":1,"max":9999,"value":17}
//| cases:
//|   - {"id":"independent","label":"σ = 2","description":"真のコヒーレンスは 0.04 で、区分の少ない推定は偏りで大きく出る。","inputs":{"noise_sigma":2}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"coherence","path":"/rows/0/1","equals":1}
//|       - {"artifact":"coherence","path":"/rows/0/2","approx":{"value":1.0,"atol":1e-12}}
//|       - {"artifact":"coherence","path":"/rows/3/2","approx":{"value":0.25,"atol":0.05}}
//|       - {"artifact":"coherence","path":"/rows/3/4","approx":{"value":5.0,"atol":0.3}}
use scioxide_signal::{
    SpectralEstimateOptions, SpectralEstimatePlan, StftPacking, WindowKind, WindowNormalization,
    WindowSymmetry, window,
};

let len = 4096_usize;
let d = delay.round() as usize;
let mut state = seed as u64;
let mut gauss = || -> f64 {
    let mut uniform = || {
        state = state.wrapping_add(0x9E37_79B9_7F4A_7C15);
        let mut z = state;
        z = (z ^ (z >> 30)).wrapping_mul(0xBF58_476D_1CE4_E5B9);
        z = (z ^ (z >> 27)).wrapping_mul(0x94D0_49BB_1331_11EB);
        ((z ^ (z >> 31)) >> 11) as f64 / (1u64 << 53) as f64 + 0.5 / (1u64 << 53) as f64
    };
    // Box–Muller（f64 の固有メソッド）
    (-2.0 * uniform().ln()).sqrt() * (2.0 * core::f64::consts::PI * uniform()).cos()
};
let source: Vec<f64> = (0..len + d).map(|_| gauss()).collect();
let x: Vec<f64> = (0..len).map(|i| source[i + d] + noise_sigma * gauss()).collect();
let y: Vec<f64> = (0..len).map(|i| source[i] + noise_sigma * gauss()).collect();
let truth = 1.0 / (1.0 + noise_sigma * noise_sigma).powi(2);

let mut rows = Vec::new();
for m in [4096_usize, 1024, 256, 64] {
    let w = window::<f64>(WindowKind::Hann, m, WindowSymmetry::Periodic, WindowNormalization::Native)
        .map_err(|e| e.to_string())?;
    let overlap = if m == len { 0 } else { m / 2 };
    let options = SpectralEstimateOptions::new()
        .with_overlap(overlap)
        .with_packing(StftPacking::OneSided);
    let plan = SpectralEstimatePlan::new(&w, options).map_err(|e| e.to_string())?;
    let coherence = plan.coherence(&x, &y).map_err(|e| e.to_string())?;
    let cross = plan.csd(&x, &y).map_err(|e| e.to_string())?;
    let segments = plan.segments(len).map_err(|e| e.to_string())?;
    // DC と Nyquist を除いたビンの平均
    let inner = &coherence[1..coherence.len() - 1];
    let mean = inner.iter().sum::<f64>() / inner.len() as f64;
    // 隣り合うビンの位相差の平均から遅れを読む（位相の傾き 2πD/m）
    let turn = cross.windows(2).fold(scioxide_core::Complex::new(0.0, 0.0), |acc, pair| {
        acc + pair[1] * pair[0].conj()
    });
    let estimate = turn.im.atan2(turn.re) * m as f64 / (2.0 * core::f64::consts::PI);
    // 独立な区分を仮定した期待値の近似 γ² + (1 − γ²)²/K（K = 1 では推定が恒等的に 1）
    let expected = (segments > 1).then(|| truth + (1.0 - truth).powi(2) / segments as f64);
    rows.push((m, segments, mean, expected, estimate));
}
let fixed3 = serde_json::json!({ "fractionDigits": 3 });
let fixed4 = serde_json::json!({ "fractionDigits": 4 });
let columns = serde_json::json!([
    { "key": "0", "label": "区分の長さ m [標本]", "type": "integer" },
    { "key": "1", "label": "区分の数 K", "type": "integer" },
    { "key": "2", "label": "コヒーレンスの平均 [-]", "type": "number", "format": fixed4 },
    { "key": "3", "label": "期待値の近似 [-]", "type": "number", "format": fixed4, "nullText": "対象外" },
    { "key": "4", "label": "位相から求めた遅れ D̂ [標本]", "type": "number", "format": fixed3 }
]);
emit_table_with_columns!(columns, rows, metadata = serde_json::json!({ "id": "coherence" }));
```

既定の $\sigma = 1$、$D = 5$ では真のコヒーレンスは 0.25 である。
区分 1 つ（$m = 4096$）の推定はすべてのビンで 1 になり、位相から求めた遅れも 14.1 標本と意味を持たない。
$K = 7$、31、127 ではコヒーレンスの平均が 0.344、0.278、0.256 と真値に近づき、近似の期待値 0.330、0.268、0.254 とほぼ一致する。
遅れの推定は 5.23、4.68、4.85 標本である。
ノイズの隣り合うビンどうしの相関は位相 0 の向きに寄与するので、遅れの推定は 0 の側にわずかに偏る。

$\sigma = 2$（真値 0.04）では、平均は 0.185、0.080、0.057 で、近似の期待値 0.161、0.067、0.047 より大きい。
重なった区分は独立でないので、実効的な区分の数が $K$ より少ないからである。
$\sigma = 0$ にしても、$m = 64$ の推定は 0.927 にとどまる。
遅れ $D$ が区分の長さに比べて無視できないと、$x$ と $y$ の区分が同じ部分を覆わず、コヒーレンスが下がる。
$D = 24$ では $m = 64$ のコヒーレンスが 0.045 まで下がるが、遅れの推定は 23.07 標本で、位相の傾きはまだ読める。

## 不等間隔の標本と Lomb–Scargle 法

天体の観測や臨床の記録のように、標本の時刻 $t_i$ が等間隔でないと、DFT のビンの直交性が崩れ、ピリオドグラムは定義できない。
Lomb–Scargle 法は角周波数 $\omega$ ごとに正弦波を最小二乗で当てはめ、当てはめで減った残差をパワーとする。

重み $w_i \ge 0$（既定は 1）と角周波数 $\omega$ に対して

$$
x_i \approx c + a \cos(\omega t_i) + b \sin(\omega t_i)
$$

を重み付き最小二乗で当てはめる。
正規化した重み $\hat w_i = w_i / \sum_j w_j$ で、基線だけの残差を $R_0 = \sum_i \hat w_i r_i^2$、正弦波を加えた残差を $R(\omega)$ とする。
`LombScargleMean::Floating`（既定）は周波数ごとに定数 $c$ も当てはめ（Zechmeister–Kürster の一般化ピリオドグラム）、`LombScargleMean::Zero` は $c = 0$ とする。
`LombScargleNormalization` は二つの量を選ぶ。

- `Normalized`（既定）: $(R_0 - R(\omega))/R_0 \in [0, 1]$。
  正弦波で説明できた残差の割合で、記録の尺度によらない。
- `Power`: $(N/2)(R_0 - R(\omega))$。
  標本数の半分と平均二乗残差の減少の積で、単位は信号の単位の二乗である。

どちらも周波数あたりの密度ではない。
重み 1、`Zero`、`Power` の組は Lomb と Scargle の古典的なピリオドグラムである。
等間隔の時刻 $t_j = j/f_s$ と Fourier 周波数 $\omega_k = 2\pi k f_s/N$（$0 < k < N/2$）では、余弦と正弦の列が直交してノルムの二乗がどちらも $N/2$ になるので、古典的なピリオドグラムは離散パワースペクトル $|X_k|^2/N$ に一致する。

周波数は角周波数（時間単位あたりのラジアン）で渡す。
Welch 法や STFT の周波数（時間単位あたりの周期）とは $2\pi$ 倍だけ違うので、周期 $P$ を探すときは $\omega = 2\pi/P$ を並べる。
時刻は並べ替えなくてよく、重みを一斉に正の定数倍しても結果は変わらない。

各周波数で余弦と正弦の列を基線と互いに対して再直交化付きで直交化し、重み付きノルムが `LombScargleOptions::with_tolerance` の許容誤差（既定 $\sqrt\varepsilon$）以下になった列はパワーに寄与させない。
標本数 $N$、周波数の数 $M$ に対して計算量は $O(NM)$ で、標本と周波数の組ごとに正弦と余弦を 1 回ずつ評価する。
内積の誤差は $k$ 項で $\gamma_{2k+8} \sum |a_i b_i| + (2k+8)\eta$ 以下だが、パワーが 0 のところと当てはめの階数が変わるところでは相対誤差の上界はない。

ワンショット呼び出しの `lomb_scargle(times, input, frequencies)` は、重み 1、`Floating`、`Normalized` の既定で `LombScargle::new` と `power` を続けて呼ぶ。
同じ時刻と周波数で何度も計算するときは、手法オブジェクト `LombScargle::new(times, frequencies, weights, options)` を作る。
`LombScargle` は時刻・周波数・重みを借用して検査するだけで、構築時には計算しない。
`power_into` は `workspace(1)` の作業領域（$4N + M$ 個の値）を使い、配列の軸に沿った `power_axis_into` はレーンの数を渡した `workspace(lanes)` を使う。

失敗は次のとおりである。
空の時刻や周波数は `InvalidInput`（`Empty`）、`Floating` で 3 個未満（`Zero` で 2 個未満）の正の重みの標本、正でない周波数、負の重みは `InvalidInput`（`OutOfRange`）になる。
長さの違う入力は `DimensionMismatch`、NaN や無限大は `NonFinite` になる。
`Normalized` で $R_0 = 0$（入力が 0、または `Floating` で定数）なら `DomainError`（`Undefined`）を返す。
当てはめが $(1 + 128\varepsilon) R_0$ を超えて説明した場合は `NumericalInstability`（`LossOfSignificance`）、位相 $\omega(t_i - t_0)$ やパワーの桁あふれは `NumericalInstability`（`Overflow`）である。

次のセルは等間隔の乱数の記録で、古典的な組（`Zero`、`Power`）の Lomb–Scargle のパワーを、Fourier 周波数で `power_spectrum` と比べる。
既定の組（`Floating`、`Normalized`）の値は、`Power` の値を $(N/2) R_0$ で割った値と比べる。
二つの比較はどちらも、上の導出から出る恒等式の検算である。

```rust
//| id: signal-lomb-scargle-uniform
//| ref: signal-lomb-scargle-uniform
//| title: 等間隔の標本で Lomb–Scargle 法と離散パワースペクトルを比べる
//| run: reactive
//| crates: [scioxide-signal]
//| inputs:
//|   record_len: {"type":"range","label":"標本数 N","description":"等間隔の記録の長さ。","min":16,"max":512,"step":16,"value":128}
//|   seed: {"type":"integer","label":"乱数のシード","description":"記録を変える。","min":1,"max":9999,"value":23}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"uniform","path":"/rows/0/1","range":{"max":1e-12}}
//|       - {"artifact":"uniform","path":"/rows/1/1","range":{"max":1e-12}}
use scioxide_signal::{
    LombScargle, LombScargleMean, LombScargleNormalization, LombScargleOptions, lomb_scargle,
    power_spectrum,
};

let (n, fs) = (record_len.round() as usize, 10.0_f64);
let mut state = seed as u64;
let mut uniform = || -> f64 {
    state = state.wrapping_add(0x9E37_79B9_7F4A_7C15);
    let mut z = state;
    z = (z ^ (z >> 30)).wrapping_mul(0xBF58_476D_1CE4_E5B9);
    z = (z ^ (z >> 27)).wrapping_mul(0x94D0_49BB_1331_11EB);
    ((z ^ (z >> 31)) >> 11) as f64 / (1u64 << 53) as f64 - 0.5
};
let x: Vec<f64> = (0..n).map(|_| uniform()).collect();
let times: Vec<f64> = (0..n).map(|j| j as f64 / fs).collect();
// Fourier 周波数 ω_k = 2π k f_s / N（0 < k < N/2）を角周波数で渡す
let omegas: Vec<f64> = (1..n / 2)
    .map(|k| 2.0 * core::f64::consts::PI * k as f64 * fs / n as f64)
    .collect();
let classical = LombScargleOptions::new()
    .with_mean(LombScargleMean::Zero)
    .with_normalization(LombScargleNormalization::Power);
let power = LombScargle::new(&times, &omegas, None, classical)
    .and_then(|p| p.power(&x))
    .map_err(|e| e.to_string())?;
let discrete = power_spectrum(&x).map_err(|e| e.to_string())?;
let classical_gap = power
    .iter()
    .zip(&discrete[1..n / 2])
    .map(|(a, b)| (a - b).abs() / b)
    .fold(0.0, f64::max);

// 既定の組（浮動平均、正規化）と、浮動平均の Power を (N/2)R₀ で割った値
let normalized = lomb_scargle(&times, &x, &omegas).map_err(|e| e.to_string())?;
let floating = LombScargleOptions::new().with_normalization(LombScargleNormalization::Power);
let floating_power = LombScargle::new(&times, &omegas, None, floating)
    .and_then(|p| p.power(&x))
    .map_err(|e| e.to_string())?;
let mean = x.iter().sum::<f64>() / n as f64;
let baseline = x.iter().map(|v| (v - mean).powi(2)).sum::<f64>() / n as f64;
let normalized_gap = normalized
    .iter()
    .zip(&floating_power)
    .map(|(z, p)| (z - p / (0.5 * n as f64 * baseline)).abs())
    .fold(0.0, f64::max);

let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let columns = serde_json::json!([
    { "key": "0", "label": "比較" },
    { "key": "1", "label": "最大の差 [-]", "type": "number", "format": sci2 }
]);
let rows = vec![
    ("古典的な組と |X_k|²/N の相対差", classical_gap),
    ("Normalized と Power/((N/2)R₀) の差", normalized_gap),
];
emit_table_with_columns!(columns, rows, metadata = serde_json::json!({ "id": "uniform" }));
```

既定の $N = 128$ では、古典的な組と $|X_k|^2/N$ の相対差は最大で $1.2 \times 10^{-13}$、`Normalized` と $\mathrm{Power}/((N/2)R_0)$ の差は $4.2 \times 10^{-17}$ である。
$N = 512$ では相対差が $6.6 \times 10^{-13}$ に増えるが、内積の項数と位相 $\omega t_j$ の大きさが増えた分の丸め誤差の程度である。
この一致から、`Power` の尺度と角周波数の単位を等間隔の場合の規約と対応づけられる。

不等間隔の観測での使い方、日周エイリアス、誤警報確率による有意性の評価は[変光星の周期推定](../../examples/variable-star-period/)で扱う。
多数の周波数で Fourier 和を高速に評価する非一様 FFT との関係は、scioxide-fft の[不等間隔観測の Fourier 和を NUFFT で求める](../../../scioxide-fft/examples/nonuniform-periodogram/)で扱う。

## まとめ

PSD の推定では、1 本のピリオドグラムは平均と同じ大きさの標準偏差を持つので、区分の平均でばらつきを下げ、その代わりに分解能を失う。
ノイズフロアを読むときは `SpectralScaling::Density`、線スペクトルの振幅を読むときは `Spectrum` を選び、片側の並びでは負の周波数の電力が正の側に足されていることに注意する。
`welch` は周期 Hann ウインドウ、半分の重なり、平均の除去を固定した関数で、他の設定は `SpectralEstimatePlan` で選ぶ。
コヒーレンスは区分が 1 つなら必ず 1 になり、区分が $K$ 個でも約 $1/K$ の偏りを持つので、区分の数と合わせて読む。
不等間隔の標本には `lomb_scargle` を角周波数で使い、等間隔の場合の離散パワースペクトルとの一致で規約を確かめられる。
時間とともに変わるスペクトルは [STFT と再構成](../stft/)、ウインドウの選び方は[窓関数と DPSS](../windows-and-dpss/)で確かめる。
