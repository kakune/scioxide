Fourier 変換は信号を周波数に分けるが、ある成分が「いつ」現れたかは係数に残らない。
段差やスパイクのような局所的な変化は、全周波数の係数に広がる。
離散ウェーブレット変換（DWT）は、低域と高域のフィルタで信号を 2 つに分け、それぞれを 1 つおきに間引くことを繰り返して、時間の位置と尺度（周波数の帯域）の両方に係数を割り当てる。
このページはその 1 段の計算と完全再構成の条件、組み込みのフィルタの族、多段の係数の並び、有限の記録の端の扱い、2 次元への拡張を順に説明する。
ノイズ除去への応用は[ウェーブレットによるノイズ除去](../../examples/wavelet-denoising/)で扱う。

## 2 チャネルのフィルタバンク

長さ $L$ の低域通過の解析フィルタ $h$ と高域通過の解析フィルタ $g$ を使い、信号 $x$ から近似係数 $a$ とディテール係数 $d$ を

$$
a[j] = \sum_{k=0}^{L-1} h[k]\,\tilde x[2j + k - o],
\qquad
d[j] = \sum_{k=0}^{L-1} g[k]\,\tilde x[2j + k - o]
$$

で作る。
$\tilde x$ は記録の外側を境界の規則で延長した信号、$o$ はフィルタの位相のずれ（後述）である。
係数の添字 $j$ は 2 標本ごとに進むので、$a$ と $d$ はそれぞれ元の約半分の長さになる。
この操作はフィルタを掛けてから 1 つおきに間引くこと（ダウンサンプリング）と同じである。

合成では、合成フィルタ $\tilde h$、$\tilde g$ を使って、間引いた係数から元の標本を

$$
x[n] = \sum_j \left(\tilde h[n + o - 2j]\,a[j] + \tilde g[n + o - 2j]\,d[j]\right)
$$

で組み立てる。
間引きは折り返し（エイリアシング）を生むが、z 変換で書いた 2 つの条件

$$
\tilde H(z) H(z) + \tilde G(z) G(z) = 2 z^{-\ell},
\qquad
\tilde H(z) H(-z) + \tilde G(z) G(-z) = 0
$$

が成り立てば、2 つの帯域の折り返しは打ち消し合い、合成は入力を遅れ $\ell$ だけで再現する（$z$ を $-z$ に替えた項が折り返しの成分である）。
これを完全再構成の条件と呼ぶ。
組み込みのフィルタはどれもこの条件を満たすように作られている。

フィルタ対が直交（正規直交）であるとは、合成フィルタが解析フィルタと同じで、平行移動したフィルタの族が正規直交基底をなすことをいう。
このとき高域のフィルタは $g[k] = (-1)^k h[L - 1 - k]$ で決まり、$\sum_k h[k] = \sqrt2$、$\sum_k h[k]^2 = 1$ を満たす。
変換は直交行列なので、周期的な延長と偶数長の記録では、係数の二乗和が信号の二乗和に等しい（Parseval の関係）。
双直交のフィルタ対は解析と合成に別のフィルタを使い、解析の基底と合成の基底が互いに双対になる。
対称なフィルタ（線形位相）とコンパクトな台を両立できるが、変換は直交行列でないので、係数の二乗和は信号のエネルギーと一致しない。
直交系と双直交系の係数を、同じエネルギーの規約で比べてはいけない。

## 組み込みの族

`WaveletFamily` は組み込みのフィルタ対を選ぶ。
どの族も、低域の解析フィルタの係数の和が $\sqrt2$ になるように正規化してある。

| 列挙子 | 族 | 指定できる値 | 性質 |
|---|---|---|---|
| `Haar` | Haar | なし | 2 タップの直交系。区分的に一定の信号を疎に表す |
| `Daubechies(L)` | Daubechies | 偶数の長さ $L = 4, 6, \dots, 20$ | 直交系。消失モーメントは $L/2$ 個で、次数 $L/2 - 1$ 以下の多項式に対するディテール係数は（端の影響を除いて）0 になる |
| `BiorthogonalSpline(c)` | Cohen–Daubechies–Feauveau のスプライン | $c = 100 i + j$ で 103、105、202、204、206、208、301、303、305、307、309 | 双直交系。$i$ と $j$ は Cohen–Daubechies–Feauveau の記法による 2 つのフィルタの次数で、フィルタは左右対称（線形位相）である |

`Daubechies(2)` は存在せず、2 タップの直交系は `Haar` で選ぶ。
表にない長さや符号は `InvalidInput` になる。

`WaveletFilters::new(family)` は、その族の解析と合成のフィルタを作業精度に丸めて返す。
`analysis_low()`、`analysis_high()`、`synthesis_low()`、`synthesis_high()` は、標本の添字が増える順に並んだ係数で、合成のフィルタも解析と同じ位相で適用する。
係数は倍精度の表から作るので、`f32` などの型では表の値を丸めた係数になる。
双直交系では、解析と合成の長さをそろえるために、係数の表を 0 で埋めた共通の偶数長にしてある。
フィルタは実数で、複素数の標本には実部と虚部に同じフィルタを適用する。

## 多段の分解と係数の詰め方

1 段の分解で得た近似 $a^{(1)}$ を、同じフィルタでさらに分解することを繰り返す。
$J$ 段の分解は最終の近似 $a^{(J)}$ と詳細 $d^{(J)}, d^{(J-1)}, \dots, d^{(1)}$ を返す。
段 $l$ の詳細は、標本化周波数を $f_s$ として、おおよそ $[f_s/2^{l+1}, f_s/2^{l}]$ の帯域を受け持つ。
各段の長さが半分になるので、長さ $n$ の記録の $J$ 段の分解の計算量は、段数によらず $O(nL)$ である。

`WaveletPlan::new(family, n, levels, options)` は、長さ $n$ の記録の `levels` 段の分解を準備する。
0 段は恒等写像である。
係数は 1 本の配列に詰めて返し、先頭に最終の近似、続いて粗い段から細かい段への詳細を並べる。

```text
[ a^(J) | d^(J) | d^(J−1) | … | d^(1) ]
```

`levels()` は細かい段から粗い段の順に `WaveletLevel` を返し、各段の形を示す。
`input_len()` はその段が分解する信号の長さ、`band_len()` は近似と詳細のそれぞれの長さ、`detail_offset()` は詰めた配列の中での詳細の先頭の位置、`first()` は帯域の最初の係数の添字 $j$ である。
`coefficient_len()` は詰めた係数の総数、`approximation_len()` は最終の近似の長さである。
各段は総数に $2\,\mathrm{band\_len} - \mathrm{input\_len}$ 個を足し、`Zero` と `Reflect` の境界で位相をずらさない場合は 1 段あたり $L - 2$ 個（入力の長さが奇数ならさらに 1 個）増える。

分解を深くしすぎると、最終の近似がフィルタより短くなり、ほとんど境界の延長だけを分解することになる。
`wavelet_max_level(n, family)` は、有用な最大の深さ

$$
J_{\max} = \max\left(0,\ \left\lfloor \log_2 \left\lfloor \frac{n}{L - 1} \right\rfloor \right\rfloor\right)
$$

を返す（$L$ は解析フィルタの長さで、双直交系では共通の偶数長）。
`Zero` と `Reflect` の境界の Plan はこれより深い段数を `InvalidInput` で拒む。
周期的な境界は $\lceil \log_2 n \rceil$ 段まで受け付ける。

## 境界の延長とフィルタの位相

有限の記録の端では、フィルタが記録の外の標本を参照する。
`WaveletOptions::with_boundary` に渡す `SignalBoundary` がその標本を決める（既定は `Periodic`）。

- `Periodic` は記録を周期 $n$ で繰り返す。
  奇数長の記録は、最後の標本を 1 つ繰り返して偶数長にしてから周期化するので、各帯域は $\lceil n/2 \rceil$ 個の係数を持つ。
- `Zero` は記録の外を 0 とする。
- `Reflect` は端の標本を繰り返さずに折り返す（$x[-1] = x[1]$、$x[n] = x[n-2]$）。
  `Zero` と `Reflect` の帯域は、フィルタの台が記録と重なるすべての位置の係数を持つので、`first()` が負になることがあり、係数の総数は $n$ より多い。

周期的な境界は係数の数が $n$ のまま（偶数長のとき）で、直交系なら変換が直交行列になる。
その代わり、記録の両端の値が違うと、周期延長の跳びが細かい段のディテール係数に大きな値を作る。
`Reflect` は端で値が連続な延長を作るので、端の近くのディテール係数が小さく保たれやすい。

`WaveletPhase` は、係数の添字 $j$ とフィルタの位置の対応を決める。
`Uncentered`（既定）は $o = 0$ で、タップ $k$ は標本 $2j + k$ に掛かる。
`Centered` は $o = \lfloor L/2 \rfloor$ で、フィルタの中央が標本 $2j$ に来るので、係数の位置が信号の特徴の位置とそろう。
解析と合成は同じ位相を使い、どちらの位相でも完全再構成が成り立つ。

次のセルは滑らかな正弦波に段差を加えた長さ $n$ の信号 $x_i = \sin(4\pi i/n) + 0.5\,[\,i \ge \lfloor 2n/3 \rfloor\,]$ を分解して合成し、元の信号との差の最大と、係数の二乗和と信号の二乗和の比を求める。
入力は族、境界、記録の長さ $n$、段数である。
要求した段数が上限（`Zero` と `Reflect` では `wavelet_max_level`、`Periodic` では $\lceil \log_2 n \rceil$）を超えるときは、上限の段数で Plan を作り、使った段数を表に示す。
分解は標準形式 `analyze`、合成は `workspace(1)` の作業領域を渡す出力先を指定する API `synthesize_into` で行う。
係数を削らない往復の検算であり、圧縮やノイズ除去の機能の実験とは区別する。
図は詰めた係数を添字の順に描き、縦線で各帯域の境目を示す。

```rust
//| id: signal-wavelet-reconstruction
//| ref: signal-wavelet-reconstruction
//| title: 段差のある信号の多段の分解と完全再構成
//| run: reactive
//| crates: [scioxide-core, scioxide-signal]
//| inputs:
//|   family_name: {"type":"select","label":"族","options":["Haar","Daubechies(4)","Daubechies(8)","BiorthogonalSpline(303)"],"value":"Daubechies(8)"}
//|   boundary_name: {"type":"select","label":"境界","options":["Periodic","Zero","Reflect"],"value":"Reflect"}
//|   length: {"type":"range","label":"記録の長さ n [-]","min":32,"max":80,"step":1,"value":63}
//|   levels: {"type":"range","label":"要求する段数 [-]","min":1,"max":6,"step":1,"value":3}
//| cases:
//|   - {"id":"periodic-even","label":"Periodic、n = 64","description":"直交系と周期的な境界の偶数長では、係数の数が 64 で、二乗和の比が 1 になる。","inputs":{"boundary_name":"Periodic","length":64}}
//|   - {"id":"biorthogonal","label":"BiorthogonalSpline(303)、Periodic、n = 64","description":"双直交系では完全再構成は成り立つが、二乗和の比は 1 にならない。","inputs":{"family_name":"BiorthogonalSpline(303)","boundary_name":"Periodic","length":64}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"summary","path":"/rows/0/0","equals":84}
//|       - {"artifact":"summary","path":"/rows/0/1","equals":14}
//|       - {"artifact":"summary","path":"/rows/0/2","equals":3}
//|       - {"artifact":"summary","path":"/rows/0/4","range":{"max":1e-13}}
//|       - {"artifact":"levels","path":"/rows/0/2","equals":35}
//|       - {"artifact":"levels","path":"/rows/0/3","equals":-3}
//|   - case: periodic-even
//|     expect:
//|       - {"artifact":"summary","path":"/rows/0/0","equals":64}
//|       - {"artifact":"summary","path":"/rows/0/5","approx":{"value":1.0,"atol":1e-13}}
//|   - case: biorthogonal
//|     expect:
//|       - {"artifact":"summary","path":"/rows/0/4","range":{"max":1e-13}}
//|       - {"artifact":"summary","path":"/rows/0/5","range":{"min":1.01}}
use scioxide_core::ExecutionContext;
use scioxide_signal::{
    SignalBoundary, WaveletFamily, WaveletOptions, WaveletPlan, wavelet_max_level,
};

let n = length.round() as usize;
let family = match family_name.as_str() {
    "Haar" => WaveletFamily::Haar,
    "Daubechies(4)" => WaveletFamily::Daubechies(4),
    "Daubechies(8)" => WaveletFamily::Daubechies(8),
    _ => WaveletFamily::BiorthogonalSpline(303),
};
let boundary = match boundary_name.as_str() {
    "Periodic" => SignalBoundary::Periodic,
    "Zero" => SignalBoundary::Zero,
    _ => SignalBoundary::Reflect,
};
// 段数の上限: Zero と Reflect は有用な最大の深さ、Periodic は ⌈log₂ n⌉。
let useful = wavelet_max_level(n, family).map_err(|e| e.to_string())?;
let periodic_limit = (usize::BITS - (n - 1).leading_zeros()) as usize;
let limit = if boundary == SignalBoundary::Periodic {
    periodic_limit
} else {
    useful
};
let depth = (levels.round() as usize).min(limit);
let options = WaveletOptions::new().with_boundary(boundary);
let plan = WaveletPlan::<f64>::new(family, n, depth, options).map_err(|e| e.to_string())?;

// 滑らかな正弦波（2 周期）と、i ≥ ⌊2n/3⌋ の段差 0.5。
let step = 2 * n / 3;
let signal: Vec<f64> = (0..n)
    .map(|i| {
        let jump = if i >= step { 0.5 } else { 0.0 };
        (4.0 * std::f64::consts::PI * i as f64 / n as f64).sin() + jump
    })
    .collect();
let coefficients = plan.analyze(&signal).map_err(|e| e.to_string())?;
let mut restored = vec![0.0; n];
let mut workspace = plan.workspace(1).map_err(|e| e.to_string())?;
plan.synthesize_into(
    &coefficients,
    &mut restored,
    &mut workspace,
    ExecutionContext::sequential(),
)
.map_err(|e| e.to_string())?;

// 検算: 元の信号との差の最大と、係数と信号の二乗和の比。
let error = restored
    .iter()
    .zip(&signal)
    .fold(0.0_f64, |acc, (y, x)| acc.max((y - x).abs()));
let energy = |values: &[f64]| values.iter().map(|v| v * v).sum::<f64>();
let ratio = energy(&coefficients) / energy(&signal);

let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let fixed10 = serde_json::json!({ "significantDigits": 10 });
let summary = serde_json::json!([
    { "key": "0", "label": "係数の個数 [-]", "type": "integer" },
    { "key": "1", "label": "最終の近似の個数 [-]", "type": "integer" },
    { "key": "2", "label": "使った段数 [-]", "type": "integer" },
    { "key": "3", "label": "wavelet_max_level [-]", "type": "integer" },
    { "key": "4", "label": "復元の誤差の最大 [-]", "type": "number", "format": sci2 },
    { "key": "5", "label": "二乗和の比 Σc²/Σx² [-]", "type": "number", "format": fixed10 }
]);
emit_table_with_columns!(
    summary,
    vec![(
        coefficients.len(),
        plan.approximation_len(),
        depth,
        useful,
        error,
        ratio
    )],
    metadata = serde_json::json!({ "id": "summary" })
);
let geometry = serde_json::json!([
    { "key": "0", "label": "段 l [-]", "type": "integer" },
    { "key": "1", "label": "入力の長さ [-]", "type": "integer" },
    { "key": "2", "label": "帯域の長さ [-]", "type": "integer" },
    { "key": "3", "label": "最初の係数の添字 j [-]", "type": "integer" },
    { "key": "4", "label": "詳細の先頭の位置 [-]", "type": "integer" }
]);
let rows: Vec<_> = plan
    .levels()
    .iter()
    .enumerate()
    .map(|(l, level)| {
        (
            l + 1,
            level.input_len(),
            level.band_len(),
            level.first() as i64,
            level.detail_offset(),
        )
    })
    .collect();
emit_table_with_columns!(
    geometry,
    rows,
    metadata = serde_json::json!({ "id": "levels" })
);

let points: Vec<[f64; 2]> = coefficients
    .iter()
    .enumerate()
    .map(|(k, &c)| [k as f64, c])
    .collect();
let borders: Vec<_> = plan
    .levels()
    .iter()
    .map(|level| {
        serde_json::json!({
            "kind": "line",
            "axis": "x",
            "value": level.detail_offset() as f64 - 0.5,
            "style": { "lineType": "dashed" }
        })
    })
    .collect();
emit_chart!(serde_json::json!({
    "kind": "scatter",
    "dataZoom": true,
    "tooltip": true,
    "series": [{ "name": "詰めた係数", "points": points }],
    "xLabel": "詰めた配列の添字 [-]",
    "yLabel": "係数 [-]",
    "annotations": borders
}));
```

既定の `Daubechies(8)`、`Reflect`、$n = 63$、3 段では、`wavelet_max_level` は $\lfloor\log_2\lfloor 63/7\rfloor\rfloor = 3$ で、要求どおり 3 段で分解する。
63 標本は 84 個の係数になり、先頭の 14 個が最終の近似である。
段の表では、各段の帯域の長さが 35、21、14 で、`first()` は $-3$ である。
1 段ごとに $2 \cdot 35 - 63 = 7$ 個（$L - 2 = 6$ と奇数長の 1 個）ずつ増え、3 段で 21 個増える。
復元の誤差の最大は $6.7\times10^{-16}$ で、二乗和の比は $1.41$ である。
`Reflect` の延長は記録の外に 0 でない標本を作るので、直交系でも二乗和は保たれない。
図の最も細かい段の詳細（添字 49〜83）では、段差の位置 $i = 42$ に当たる添字 70〜72 の係数（最大 0.24）と記録の両端の近くの数個を除くと、係数は $10^{-3}$ 以下である。
滑らかな正弦波は Daubechies(8) の 4 個の消失モーメントでほぼ打ち消され、ディテール係数は段差と端の位置に集まる。

`Periodic`、$n = 64$ にすると、係数は 64 個、最終の近似は 8 個で、二乗和の比は $1 - 4\times10^{-16}$ になり、Parseval の関係が丸め誤差の範囲で成り立つ。
同じ `Periodic` でも $n = 63$ では、最後の標本を繰り返して 64 標本にしてから変換するので、比は $1.0031$ になる。
`Zero` の境界では係数が 84 個に増えるが、記録の外が 0 なので、直交系の係数は信号の全エネルギーを持ち、比は $1 + 4\times10^{-16}$ である。
`BiorthogonalSpline(303)`、`Periodic`、$n = 64$ では、復元の誤差は $3.3\times10^{-16}$ で完全再構成は成り立つが、二乗和の比は $1.69$ になる。
$n = 32$ では `wavelet_max_level` が 2 に下がり、3 段を要求しても 2 段で Plan を作る。

## 2 次元の変換

画像のような 2 次元の配列には行と列の両方向に 1 次元の変換を掛ける分離可能な変換を使う。
`Wavelet2dPlan::new(family, shape, levels, layout, options)` は、形 `shape = [行数, 列数]` の行優先の行列の変換を準備する。
`levels[0]` は軸 0（行の並ぶ方向、つまり各列に沿った変換）の段数、`levels[1]` は軸 1（各行に沿った変換）の段数で、それぞれの上限は 1 次元の Plan と同じである。
`Wavelet2dLayout` は段の組み方を選ぶ。

- `Pyramid`（Mallat のピラミッド）は、各段で両方の軸を 1 回ずつ変換し、低域・低域の区画だけを次の段で分解する。
  2 つの軸の段数は等しくなければならず、違うと `InvalidInput`（`Inconsistent`）を返す。
  係数は最終の低域・低域の区画に続いて、粗い段から細かい段の順に、各段の 3 つの詳細の区画（詳細の段が `[0, l]`、`[l, 0]`、`[l, l]` のもの）を並べる。
- `Tensor`（テンソル積）は各軸に多段の 1 次元変換を完全に掛ける。
  軸ごとに段数を変えられ、係数は 2 つの軸の 1 次元の帯域のすべての組を、軸 0 を外側にして並べる。

`subbands()` は、詰めた係数の中の区画を格納の順に `WaveletSubband` で返す。
`offset()` は区画の先頭の位置、`shape()` は区画の形 `[行数, 列数]`、`detail_levels()` は軸 0 と軸 1 の詳細の段（1 が最も細かく、0 はその軸で低域）である。
各区画は行優先で連続に格納される。
`coefficient_len()` は係数の総数、`input_shape()` は行列の形、`layout()` は選んだ配置を返す。
変換の結果は 1 次元の変換を行と列に順に掛けた結果とビット単位で等しく、実行方針に依らない。

## 配列の軸に沿った変換

`WaveletPlan::analyze_axis_into(input, axis, output, ws, cx)` と `synthesize_axis_into` は、多次元配列の 1 つの軸に沿ったすべてのレーン（その軸に平行な 1 次元の列）を、同じ Plan で変換する。
出力の形は、入力の形のその軸の長さを `coefficient_len()`（合成では $n$）に置き換えたもので、入力と出力はストライド付きのビューでよい。
作業領域は `workspace(lanes)` で確保し、`lanes` には他の軸の長さの積を渡す。
レーンは `WaveletOptions::with_execution_policy` の実行方針で並列に処理でき（最大 32 のワーカー）、すべてのレーンが成功してから出力に書く。
軸の番号が配列の次元以上なら `InvalidInput`、軸の長さが $n$ と違うか出力の形が合わないと `DimensionMismatch` を返す。

次のセルは $32 \times 32$ の画像（値 1 の長方形と、列方向に 1 周期の余弦波 $0.25\cos(2\pi j/32)$ の和）を周期的な境界で 2 次元に分解する。
入力は族、配置、両軸の段数である。
表は各区画の位置、形、詳細の段、エネルギーの割合を示す。
検算として、合成の誤差、係数と画像の二乗和の比、`Tensor` の配置では `analyze_axis_into` を軸 1、軸 0 の順に掛けた結果との差を求める。
周期的な境界で一辺が 2 のべき乗のとき、区画は元の大きさの格子にすき間なく収まる。
図はその配置（左上が最終の近似）に係数を並べ、区画ごとに最大絶対値で割った値を符号付きの色で描く。

```rust
//| id: signal-wavelet-2d
//| ref: signal-wavelet-2d
//| title: 長方形を含む画像の 2 次元ウェーブレット分解
//| run: reactive
//| crates: [scioxide-core, scioxide-signal]
//| inputs:
//|   family_name: {"type":"select","label":"族","options":["Haar","Daubechies(4)"],"value":"Haar"}
//|   layout_name: {"type":"select","label":"配置","options":["Pyramid","Tensor"],"value":"Pyramid"}
//|   levels: {"type":"range","label":"各軸の段数 [-]","min":1,"max":3,"step":1,"value":2}
//| cases:
//|   - {"id":"tensor","label":"Tensor、2 段","description":"区画は 9 個になり、軸ごとの変換の合成と差 0 で一致する。","inputs":{"layout_name":"Tensor"}}
//|   - {"id":"daubechies","label":"Daubechies(4)、Pyramid","description":"長方形の辺のディテール係数が隣の係数へ広がり、細かい段の詳細のエネルギーの割合が変わる。","inputs":{"family_name":"Daubechies(4)"}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"bands","path":"/rows/6/1","equals":16}
//|       - {"artifact":"bands","path":"/rows/6/4","equals":1}
//|       - {"artifact":"checks","path":"/rows/0/0","range":{"max":1e-13}}
//|       - {"artifact":"checks","path":"/rows/0/1","approx":{"value":1.0,"atol":1e-13}}
//|       - {"artifact":"checks","path":"/rows/0/2","equals":null}
//|   - case: tensor
//|     expect:
//|       - {"artifact":"bands","path":"/rows/8/0","equals":768}
//|       - {"artifact":"checks","path":"/rows/0/2","equals":0}
//|   - case: daubechies
//|     expect:
//|       - {"artifact":"checks","path":"/rows/0/0","range":{"max":1e-13}}
//|       - {"artifact":"checks","path":"/rows/0/1","approx":{"value":1.0,"atol":1e-13}}
use scioxide_core::{ExecutionContext, NdView, NdViewMut, StridedLayout};
use scioxide_signal::{Wavelet2dLayout, Wavelet2dPlan, WaveletFamily, WaveletOptions, WaveletPlan};

let side = 32_usize;
let depth = levels.round() as usize;
let family = if family_name == "Haar" {
    WaveletFamily::Haar
} else {
    WaveletFamily::Daubechies(4)
};
let tensor = layout_name == "Tensor";
let layout = if tensor {
    Wavelet2dLayout::Tensor
} else {
    Wavelet2dLayout::Pyramid
};
// 行優先 [i][j]。行 8〜19、列 10〜23 が値 1 の長方形に、列方向の余弦波を加える。
let image: Vec<f64> = (0..side * side)
    .map(|p| {
        let (i, j) = (p / side, p % side);
        let inside = (8..20).contains(&i) && (10..24).contains(&j);
        let wave = 0.25 * (std::f64::consts::TAU * j as f64 / side as f64).cos();
        if inside { 1.0 + wave } else { wave }
    })
    .collect();
let options = WaveletOptions::new();
let plan = Wavelet2dPlan::new(family, [side, side], [depth, depth], layout, options)
    .map_err(|e| e.to_string())?;
let coefficients = plan.analyze(&image).map_err(|e| e.to_string())?;
let restored = plan.synthesize(&coefficients).map_err(|e| e.to_string())?;

// 区画を元の格子へ並べる。詳細の段 l ≥ 1 の軸では、区画は長さと同じ位置から始まる。
let total: f64 = coefficients.iter().map(|c| c * c).sum();
let (mut mosaic, mut shaded) = (vec![0.0; side * side], vec![0.0; side * side]);
let mut bands = Vec::new();
for band in plan.subbands() {
    let ([rows, cols], [l0, l1]) = (band.shape(), band.detail_levels());
    let block = &coefficients[band.offset()..band.offset() + rows * cols];
    let peak = block.iter().fold(0.0_f64, |acc, c| acc.max(c.abs()));
    let (r0, c0) = (
        if l0 == 0 { 0 } else { rows },
        if l1 == 0 { 0 } else { cols },
    );
    for (k, &value) in block.iter().enumerate() {
        let target = (r0 + k / cols) * side + c0 + k % cols;
        mosaic[target] = value;
        shaded[target] = if peak > 0.0 { value / peak } else { 0.0 };
    }
    let energy: f64 = block.iter().map(|c| c * c).sum();
    bands.push((band.offset(), rows, cols, l0, l1, energy / total));
}

// 検算 1: 合成の誤差と二乗和の比（直交系と周期的な境界では 1）。
let error = restored
    .iter()
    .zip(&image)
    .fold(0.0_f64, |acc, (y, x)| acc.max((y - x).abs()));
let ratio = total / image.iter().map(|x| x * x).sum::<f64>();
// 検算 2: 軸 1、軸 0 の順に 1 次元の多段変換を掛けた行列（Tensor の配置と比べる）。
let axis_plan = WaveletPlan::<f64>::new(family, side, depth, options).map_err(|e| e.to_string())?;
let (square, strides) = ([side, side], [side, 1]);
// 周期的な境界で一辺が 2 のべき乗なので、係数の行列も side × side の行優先になる。
let grid = StridedLayout::new(&square, &strides).map_err(|e| e.to_string())?;
let mut rows_done = vec![0.0; side * side];
let mut composed = vec![0.0; side * side];
let mut ws = axis_plan.workspace(side).map_err(|e| e.to_string())?;
let cx = ExecutionContext::sequential();
let input = NdView::new(&image, grid).map_err(|e| e.to_string())?;
let output = NdViewMut::new(&mut rows_done, grid).map_err(|e| e.to_string())?;
axis_plan
    .analyze_axis_into(input, 1, output, &mut ws, cx)
    .map_err(|e| e.to_string())?;
let input = NdView::new(&rows_done, grid).map_err(|e| e.to_string())?;
let output = NdViewMut::new(&mut composed, grid).map_err(|e| e.to_string())?;
axis_plan
    .analyze_axis_into(input, 0, output, &mut ws, cx)
    .map_err(|e| e.to_string())?;
let axis_gap = tensor.then(|| {
    composed
        .iter()
        .zip(&mosaic)
        .fold(0.0_f64, |acc, (a, b)| acc.max((a - b).abs()))
});

let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let fixed4 = serde_json::json!({ "significantDigits": 4 });
let band_columns = serde_json::json!([
    { "key": "0", "label": "先頭の位置 [-]", "type": "integer" },
    { "key": "1", "label": "行数 [-]", "type": "integer" },
    { "key": "2", "label": "列数 [-]", "type": "integer" },
    { "key": "3", "label": "軸 0 の詳細の段 [-]", "type": "integer" },
    { "key": "4", "label": "軸 1 の詳細の段 [-]", "type": "integer" },
    { "key": "5", "label": "エネルギーの割合 [-]", "type": "number", "format": fixed4 }
]);
emit_table_with_columns!(
    band_columns,
    bands,
    metadata = serde_json::json!({ "id": "bands" })
);
let check_columns = serde_json::json!([
    { "key": "0", "label": "合成の誤差の最大 [-]", "type": "number", "format": sci2 },
    { "key": "1", "label": "二乗和の比 [-]", "type": "number", "format": fixed4 },
    { "key": "2", "label": "軸ごとの変換との差 [-]", "type": "number", "format": sci2, "nullText": "Tensor のみ" }
]);
emit_table_with_columns!(
    check_columns,
    vec![(error, ratio, axis_gap)],
    metadata = serde_json::json!({ "id": "checks" })
);
let heat: Vec<[f64; 3]> = (0..side * side)
    .map(|p| [(p % side) as f64, (p / side) as f64, shaded[p]])
    .collect();
emit_chart!(serde_json::json!({
    "kind": "heatmap",
    "title": "区画ごとに正規化した係数（左上が最終の近似）",
    "data": heat,
    "xLabel": "列方向の位置 [-]",
    "yLabel": "行方向の位置 [-]",
    "colorScale": "diverging",
    "center": 0.0,
    "colorMin": -1.0,
    "colorMax": 1.0,
    "tooltip": true,
    "style": { "animation": false, "showGrid": false }
}));
```

既定の `Haar`、`Pyramid`、2 段では、区画は 7 個（最終の近似 1 個と 2 段 × 3 個の詳細）で、係数は合わせて 1024 個である。
合成の誤差の最大は $6.7\times10^{-16}$、二乗和の比は $1 + 2\times10^{-15}$ である。
エネルギーの 92.0% が $8\times8$ の最終の近似に、7.8% が軸 1 の 2 段目の詳細に集まる。
軸 0 の詳細（`[2, 0]`、`[1, 0]`、`[2, 2]`、`[1, 1]`）のエネルギーは 0 である。
長方形の上下の辺は行 8 と行 20 で、どちらも 4 の倍数なので、Haar の 2 段の区切りと重なり、各区切りの中で値が一定になるからである。
左右の辺は列 10 と列 24 で、列 10 は 2 の倍数だが 4 の倍数でないので、軸 1 の 2 段目の詳細に現れる。
軸 1 の 1 段目の詳細（0.22%）は、列方向の余弦波から来る。

`Tensor` にすると、区画は $3 \times 3 = 9$ 個で、最後の区画（`[1, 1]`）は 768 番目から始まる。
軸 1、軸 0 の順に `analyze_axis_into` を掛けた行列との差は 0 で、テンソル積の配置は 1 次元の変換の合成とビット単位で一致する。
`Daubechies(4)` では、4 タップのフィルタが区切りをまたぐので、長方形の辺が軸 0 の詳細にも現れ、`[2, 0]` に 4.3%、`[1, 0]` に 2.5% のエネルギーが移る。
二乗和の比は $1 + 1.4\times10^{-14}$ で、直交性はどちらの族でも保たれる。

## 誤差と API の使い分け

各段の係数は作業精度の積和で、$m$ 項の積和の各成分の絶対誤差は $\gamma(2m + 8)\,M + (2m + 8)\,\eta$ 以下である（$u$ を単位丸め誤差として $\gamma(k) = ku/(1 - ku)$、$M$ は積の絶対値の和、$\eta$ は最小の正の非正規化数）。
段をまたぐ誤差はフィルタの係数の絶対値を通して次の段へ伝わる。
直交系では変換が直交行列なので、合成で誤差は増幅されず、往復の誤差は前のセルのように信号の大きさの $10^{-15}$ 程度にとどまる。
双直交系では合成のフィルタの大きさに応じて誤差が増えるが、組み込みの族では同じ程度である。

`analyze` と `synthesize` は、出力と作業領域をその場で確保する一回の呼び出しに便利な形である。
同じ長さの記録を繰り返し変換するときは、Plan と `workspace(1)` を作り置きし、`analyze_into` と `synthesize_into` に出力の領域を渡すと、実行は確保しない。
1 つの作業領域は分解と合成の両方に使える。
入力の長さが $n$ でない、出力の長さが `coefficient_len()` でない、作業領域が足りないときは `DimensionMismatch`、非有限の標本は `NonFinite`、係数があふれると `NumericalInstability` を返す。
結果は作業領域の中で作ってから出力に写すので、エラーのとき出力は変わらない。
`WaveletPlan` は実数と複素数（`NumericScalar`）の標本を受け付け、`Wavelet2dPlan` も同じである。

## まとめ

離散ウェーブレット変換は、低域と高域のフィルタと間引きを繰り返し、完全再構成の条件のもとで係数から元の信号を丸め誤差の範囲で再現する。
直交系（`Haar`、`Daubechies`）は周期的な境界と偶数長で係数の二乗和を保ち、双直交系（`BiorthogonalSpline`）は対称なフィルタを持つが二乗和を保たない。
段数は `wavelet_max_level` を目安にし、詰めた係数の位置は `levels()` と `detail_offset()`、2 次元では `subbands()` で読む。
端の扱いは `SignalBoundary` で選び、`Zero` と `Reflect` では係数の数が記録より多くなることを見込んで領域を用意する。

係数を縮小してノイズを除く使い方と、族による結果の違いは、[ウェーブレットによるノイズ除去](../../examples/wavelet-denoising/)で確かめる。
フィルタの周波数応答の観点からの設計は、[FIR の設計と最小位相](../fir-design-and-minimum-phase/)で比べる。
