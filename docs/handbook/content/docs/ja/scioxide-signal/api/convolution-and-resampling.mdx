この表は、時間領域の畳み込みと相関、それを使う逐次処理とリサンプリングの公開項目をまとめる。
ワンショット関数（`convolve`、`correlate`、`resample`、`resample_periodic` など）は実数・複素数の記録を受け取り、Plan と作業領域をその場で作って結果を返す。
Plan（`ConvolutionNdPlan`、`OverlapPlan`、`PolyphasePlan`、`FourierResamplePlan`）は形と変換を準備時に検査し、出力先を指定する API `_into` では出力と作業領域を呼び出し側に持たせる。
Plan の実行は失敗したとき出力を変更しない。

## 実行方針と作業領域

Plan と手法オブジェクトは `workspace_requirements(request)` で必要量を返す。
要求は `()`、記録長、レーンの数、`SignalLayout`、または Plan に固有の値である。
`workspace(request)`、または `SignalWorkspace::default()` と `try_reserve` で実行前に領域を確保する。
出力先を指定する API `_into` の最後の引数は `ExecutionContext` で、実行中は領域を増やさない。
ピーク・リッジ・Whittaker 平滑化・LTI 応答は用途別の作業領域型を使う。

## まとめ

一度きりの畳み込みには `convolve`・`convolve_circular`・`correlate`、標本化周波数の変換には `resample`（有理比）と `resample_periodic`（周期的な記録）を使う。
同じ核で繰り返すときや、多次元の格子・切り出し・境界の指定が必要なときは、核を所有する `ConvolutionNdPlan` を再利用する。
終わりのない入力列には `OverlapPlan` と `PolyphasePlan` のストリームを使い、最後のチャンクで `StreamChunk::Final` を渡す。
スペクトル推定の項目は[スペクトル・時間周波数解析・解析信号](../spectra-and-time-frequency/)、フィルタの設計は[フィルタ設計・最小位相・LTI 系](../filter-design-and-systems/)にある。
