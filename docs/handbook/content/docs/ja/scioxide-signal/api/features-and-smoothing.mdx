この表は、信号の局所的な性質を扱う公開項目をまとめる。
ワンショット関数（`median_filter`、`find_peaks`、`peak_properties`、`savitzky_golay`、`vector_strength`、`waveform`、`detrend`）は結果を確保して返す。
出力先を指定する API（`find_peaks_into`、`detrend_into`、`waveform_into` など）は呼び出し側の出力と作業領域に書き込み、実行中に確保しない。
どの関数も、失敗したときは出力を変えない。

## 尺度間のピーク追跡

`RidgePlan::new(scales, options)` で尺度と Ricker 核を準備する。
一つの記録なら `plan.find_peaks(input)` がリッジを返す。
繰り返すときは `plan.workspace(max_input_len)` で `RidgeWorkspace` を準備し、出力とともに `plan.find_peaks_into` へ渡す。
最小の長さや強さを満たすリッジを返すが、ノイズのしきい値を推定する機能ではない。

| 項目 | 種別 | 役割 | 仕様の要点 | 解説節 | 実行例 |
|---|---|---|---|---|---|
| [`RidgePlan`](https://docs.rs/scioxide-signal/0.1.0/scioxide_signal/struct.RidgePlan.html) | 構造体 | Ricker 核を準備する尺度間のピーク追跡 | `new(scales, options)` は正で狭義に増加する標本単位の尺度から核を準備する。標準形式 `find_peaks` は作業領域と出力を確保して標本添字順の `Vec<RidgePeak>` を返す。出力先を指定する API `find_peaks_into` は `workspace(n)` の領域を使い、正の内部の極大（平坦部の中点）だけを粗い尺度から細かい尺度へつなぎ、同じ標本で終わるリッジは最も細かい尺度、次に最も長いものを返し、確保せず、失敗時は出力を保持する | [尺度をまたぐリッジ](oxref:signal-ridge-detection) | [Ricker ウェーブレットのリッジによるピークの検出](oxref:signal-ridge-peaks) |
| [`RidgeOptions`](https://docs.rs/scioxide-signal/0.1.0/scioxide_signal/struct.RidgeOptions.html) | 構造体 | リッジ検出のパラメータ | 核の半幅、一段あたりの最大移動、欠けてよい尺度の数、最小の長さ、最小の強さ。ノイズのしきい値は推定しない | [尺度をまたぐリッジ](oxref:signal-ridge-detection) | [Ricker ウェーブレットのリッジによるピークの検出](oxref:signal-ridge-peaks) |
| [`RidgePeak`](https://docs.rs/scioxide-signal/0.1.0/scioxide_signal/struct.RidgePeak.html) | 構造体 | 残ったリッジ | 最も細かい尺度での添字、尺度の添字、つながった極大の数、係数 | [尺度をまたぐリッジ](oxref:signal-ridge-detection) | [Ricker ウェーブレットのリッジによるピークの検出](oxref:signal-ridge-peaks) |
| [`RidgeRequirements`](https://docs.rs/scioxide-signal/0.1.0/scioxide_signal/struct.RidgeRequirements.html) | 構造体 | リッジ検出の必要領域 | `RidgePlan::workspace_requirements(max_input_len)` が返す。入力長と尺度の数に応じたメモリを実行前に事前確保する | [尺度をまたぐリッジ](oxref:signal-ridge-detection) | - |
| [`RidgeWorkspace`](https://docs.rs/scioxide-signal/0.1.0/scioxide_signal/struct.RidgeWorkspace.html) | 構造体 | リッジ検出の再利用領域 | `plan.workspace(max_input_len)` または `default` と `try_reserve` で準備する。`find_peaks_into` は実行中に拡張しない | [尺度をまたぐリッジ](oxref:signal-ridge-detection) | [Ricker ウェーブレットのリッジによるピークの検出](oxref:signal-ridge-peaks) |

## まとめ

外れ値の除去には `median_filter` か `LocalFilterPlan` の Hampel フィルタ、ガウスノイズには Wiener フィルタを使い、受信しながら処理するときは `LocalFilterStream` に状態の領域を渡す。
ピークは `find_peaks` で幾何を測り、条件で選ぶときは `find_peaks_with_options` に `PeakOptions` を渡し、尺度の異なる構造は `RidgePlan::find_peaks` で追う。
平滑化は局所多項式（`savitzky_golay`、`SavitzkyGolayPlan`）、差分のペナルティ（Whittaker–Henderson）、スプラインの係数から目的に合うものを選び、診断を確かめる。
ウェーブレットの係数の並びと境界の延長は Plan が保持し、配列の軸に沿った変換は同じ Plan の `analyze_axis_into` で行う。
API の一覧と型の関係は [API ガイド](../)にある。
