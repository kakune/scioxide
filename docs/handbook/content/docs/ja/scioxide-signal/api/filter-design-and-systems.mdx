この表は、フィルタを設計して適用する項目と、線形時不変（LTI）系の状態空間モデルをまとめる。
FIR と IIR の設計関数は、デジタルの周波数を Nyquist 周波数に対する比で受け取る。
FIR の設計の終了状態は `FirDesign::termination()` が唯一の根拠であり、IIR の設計は成功すれば有限で安定な極を持つ `IirDesign` を返し、そうでなければエラーを返す。
根・固有値・極値点を反復で求める設計と変換（`design_iir`、`iir_prototype`、`select_iir_order`、`design_fir_remez`、`design_real_gammatone`、`to_zpk`、`place_poles`）は、新しい根のスコープで逐次に実行する標準形式と、最後に実行コンテキストか外側の解法の `SolveContext` を受け取るスコープ付き API（`_scoped`）を持つ（[呼び出しの形](../#呼び出しの形)）。
`select_iir_order`、`design_fir_remez`、`place_poles` の標準形式は目標に届かなければ `ConvergenceFailure` を返し、オプション付き形式（`_with_options`）とスコープ付き API は最後の結果と終了状態を `Ok` で返す。
設定は `with_*` で組み立て、設計や Plan の準備で検査する。

## まとめ

FIR の設計は近似の基準で関数を選び、`termination()` と、方程式を解く設計では `condition_estimate()` を確かめてから係数を使う。
Remez 法の標準形式は未収束をエラーにし、上限で止まった近似も使いたいときはオプション付き形式 `design_fir_remez_with_options` で終了状態を読む。
IIR は `design_iir`（または `select_iir_order` で次数・族・帯域を選んでから）で設計し、`to_sos()` で二次節にして `filter` か `forward_backward` で適用する。
チャンクに分けた処理や状態の指定が必要なら手法オブジェクト `IirFilter` と呼び出し側の `IirState` を使う。
最小位相への変換は格子の上の診断と独立な周波数応答で確かめ、状態空間モデルは時間の規約を `LtiTime` で明示して離散化の方法を選ぶ。
局所フィルタや平滑化の項目は[局所フィルタ・特徴・平滑化・ウェーブレット](../features-and-smoothing/)にある。
