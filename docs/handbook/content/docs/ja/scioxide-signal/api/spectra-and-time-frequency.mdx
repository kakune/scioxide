この表は、周波数領域の解析に使う公開項目をまとめる。
周波数の単位は項目ごとに異なる。
`welch`、`SpectralEstimatePlan`、`StftPlan` は標本化周波数を受け取って時間単位あたりの周期で、`lomb_scargle` と `LombScargle` は角周波数（時間単位あたりのラジアン）で、`power_spectrum` と `cross_spectrum` は DFT のビンの番号で扱う。

## まとめ

ウインドウは `window` と `window_metrics` で作って確かめ、帯域への集中が必要なら `DpssTapers` を使う。
等間隔の標本のパワースペクトル密度はワンショット呼び出しの `welch` で求め、ウインドウ・重なり・尺度を選ぶときや相互スペクトルと coherence には `SpectralEstimatePlan` を使う。
不等間隔の標本の周期探索は `lomb_scargle` が API で、重みや設定を変えるとき、同じ時刻で何度も計算するときは手法オブジェクト `LombScargle` を使う。
周波数の単位は `welch` が周期、`lomb_scargle` が角周波数で異なる。
STFT の逆変換には NOLA が必要で、`check_overlap` と `StftPlan::dual_window` で確かめる。
解析信号は 1 次元では `hilbert`、多次元では `AnalyticSignalNdPlan` と Riesz 変換を使い、どちらも周期的な延長を仮定する。
畳み込みの項目は[畳み込み・相関・リサンプリング](../convolution-and-resampling/)、フィルタの設計は[フィルタ設計・最小位相・LTI 系](../filter-design-and-systems/)にある。
