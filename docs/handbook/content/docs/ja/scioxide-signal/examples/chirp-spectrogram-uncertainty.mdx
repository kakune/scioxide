周波数を時間とともに直線的に変える正弦波（線形チャープ）は、レーダーやソナーのパルス圧縮、音響系の伝達特性の測定、コウモリの反響定位の鳴き声などに現れる。
スペクトログラム（STFT の絶対値の二乗）では、チャープは時間周波数平面の斜めの直線（尾根）として見える。
この例題では、ウインドウの長さを変えると尾根の幅がどう変わるかを閉形式で導き、`StftPlan` で測った幅と比べる。
ウインドウを短くすると時間の精度が上がる代わりに周波数がぼけ、長くするとウインドウの中で周波数が動いてしまう。
この交換が時間周波数の不確定性である。

## 線形チャープと瞬時周波数

標本化周波数 $f_s = 1000$ Hz で、長さ $T = 2$ s の記録に

$$
x(t) = \cos\!\left( 2\pi \left( f_0 t + \frac{k}{2} t^2 \right) \right), \qquad k = \frac{f_1 - f_0}{T}
$$

を置く。
$f_0 = 50$ Hz、$f_1 = 450$ Hz なので、掃引の速さは $k = 200$ Hz/s である。
位相を $2\pi$ で割って時間で微分した瞬時周波数は $f(t) = f_0 + kt$ で、$t = 1$ s では 250 Hz になる。
標本は `waveform` に `Waveform::Chirp`（`ChirpLaw::Linear`）を渡して作る。
$x$ は振幅 1 の実数の信号で、負の周波数の像 $-f(t)$ も持つが、解析する 150〜350 Hz の帯域からは十分に離れている。

## 尾根の幅の閉形式

STFT のウインドウに、標準偏差 $\sigma$ [s] の Gauss ウインドウ $g(u) = e^{-u^2/(2\sigma^2)}$ を使う。
複素チャープ $e^{i\pi k t^2}$ の時刻 $\tau$ の STFT は、$t = \tau + u$ と置くと

$$
X(\tau, f) \propto \int_{-\infty}^{\infty} \exp\!\left( -\left( \frac{1}{2\sigma^2} - i\pi k \right) u^2 + 2\pi i (k\tau - f)\, u \right) du
$$

となる。
Gauss 積分 $\int e^{-a u^2 + ibu} du = \sqrt{\pi/a}\, e^{-b^2/(4a)}$ を使うと、$|X|^2$ は $f$ について平均 $k\tau$ の Gauss 関数になり、その標準偏差は

$$
s_f(\sigma) = \sqrt{ \frac{1}{8\pi^2 \sigma^2} + \frac{k^2 \sigma^2}{2} }
$$

である。
第 1 項はウインドウの長さで決まる周波数分解能（定常な正弦波でも残る幅）で、第 2 項はウインドウの中で周波数が $k\sigma$ の程度動くことによる広がりである。
$\sigma$ について微分して 0 とおくと、幅を最小にするウインドウは

$$
\sigma_\ast = \frac{1}{\sqrt{2\pi k}}, \qquad s_f(\sigma_\ast) = \sqrt{\frac{k}{2\pi}}
$$

で、$k = 200$ Hz/s では $\sigma_\ast = 28.2$ ms、$s_f = 5.64$ Hz になる。
ウインドウの電力 $|g|^2$ の時間の標準偏差 $\sigma/\sqrt2$ と、そのスペクトルの周波数の標準偏差 $1/(2\sqrt2\,\pi\sigma)$ の積は $1/(4\pi)$ で、Gauss ウインドウはこの積（Gabor の不確定性の下限）を等号で満たす。

## 解析の設定

Gauss ウインドウは `WindowKind::Gaussian { sigma }` で作り、`sigma` は標本で数える。
ウインドウ長は $m = 2\lceil 5\sigma f_s \rceil$ 標本とし、両端でウインドウの値は $e^{-12.5} \approx 4 \times 10^{-6}$ 以下になる。
hop は 20 標本（20 ms）、FFT 長は 1024（ビンの間隔 0.977 Hz）、並びは片側、尺度は `StftScaling::Psd` とする。
$|X|^2$ はパワースペクトル密度 [1/Hz] になる（信号は無次元）。

尾根は、時刻 0.5〜1.5 s（瞬時周波数 150〜350 Hz）のフレームごとに、最大のビンの前後 100 Hz の密度から重心と標準偏差を求めて測る。
重心は瞬時周波数 $f(\tau)$ と、標準偏差は $s_f(\sigma)$ と比べる。
フレームの時刻は `frame_time(p)`（$ph/f_s$）を使い、偶数長のウインドウの中心とは半標本（0.5 ms、周波数で 0.1 Hz）ずれる。

次のブロックは二つのセルが共有する定義である。
`chirp` が $x$ の標本、`plan` がウインドウと STFT の Plan、`theory_width` が $s_f(\sigma)$、`ridge` が尾根の重心と幅の測定に対応する。

```rust
//| id: signal-chirp-model
//| kind: definitions
//| title: 線形チャープと尾根の測定
//| crates: [scioxide-core, scioxide-signal]
use scioxide_core::SciOxideError;
use scioxide_signal::{
    ChirpLaw, StftOptions, StftPacking, StftPlan, StftScaling, Waveform, WindowKind,
    WindowNormalization, WindowSymmetry, waveform, window,
};

/// 標本化周波数 f_s [Hz]、記録長 T [s]、掃引の両端 f₀、f₁ [Hz]。
pub(crate) const SAMPLE_RATE: f64 = 1000.0;
pub(crate) const DURATION: f64 = 2.0;
pub(crate) const START: f64 = 50.0;
pub(crate) const END: f64 = 450.0;
/// hop [標本] と FFT 長 [標本]。
pub(crate) const HOP: usize = 20;
pub(crate) const FFT_LEN: usize = 1024;

/// 掃引の速さ k = (f₁ − f₀)/T [Hz/s]。
pub(crate) fn sweep_rate() -> f64 {
    (END - START) / DURATION
}

/// 線形チャープ cos(2π(f₀t + kt²/2)) の標本。
pub(crate) fn chirp() -> Result<Vec<f64>, SciOxideError> {
    let count = (DURATION * SAMPLE_RATE) as usize;
    let times: Vec<f64> = (0..count).map(|i| i as f64 / SAMPLE_RATE).collect();
    let law = Waveform::Chirp {
        initial: START,
        final_frequency: END,
        duration: DURATION,
        phase: 0.0,
        law: ChirpLaw::Linear,
    };
    waveform(law, &times)
}

/// 標準偏差 σ [s] の Gauss ウインドウ（長さ 2⌈5σf_s⌉）と、片側・PSD 尺度の STFT の Plan。
pub(crate) fn plan(sigma: f64) -> Result<StftPlan<f64>, SciOxideError> {
    let samples = sigma * SAMPLE_RATE;
    let length = 2 * (5.0 * samples).ceil() as usize;
    let kind = WindowKind::Gaussian { sigma: samples };
    let w = window::<f64>(kind, length, WindowSymmetry::Symmetric, WindowNormalization::Native)?;
    let options = StftOptions::new()
        .with_sample_rate(SAMPLE_RATE)
        .with_fft_len(Some(FFT_LEN))
        .with_packing(StftPacking::OneSided)
        .with_scaling(StftScaling::Psd);
    StftPlan::new(&w, HOP, options)
}

/// 尾根の幅の閉形式 s_f(σ) = √(1/(8π²σ²) + k²σ²/2) [Hz]（f64 の固有メソッドによる参照値）。
pub(crate) fn theory_width(sigma: f64) -> f64 {
    let pi = core::f64::consts::PI;
    let k = sweep_rate();
    (1.0 / (8.0 * pi * pi * sigma * sigma) + k * k * sigma * sigma / 2.0).sqrt()
}

/// 尾根の測定: 時刻 [s]、重心 [Hz]、標準偏差 [Hz] の列。0.5〜1.5 s のフレームだけを使う。
pub(crate) fn ridge(
    plan: &StftPlan<f64>,
    power: &[f64],
    len: usize,
) -> Result<Vec<(f64, f64, f64)>, SciOxideError> {
    let frames = plan.frames(len)?;
    let bins = plan.bins();
    let df = SAMPLE_RATE / FFT_LEN as f64;
    let reach = (100.0 / df).round() as usize;
    let mut rows = Vec::new();
    for i in 0..frames.count() {
        let time = plan.frame_time(frames.first() + i as i64)?;
        if !(0.5..=1.5).contains(&time) {
            continue;
        }
        let frame = &power[i * bins..(i + 1) * bins];
        let peak = (0..bins).max_by(|&a, &b| frame[a].total_cmp(&frame[b])).unwrap_or(0);
        let range = peak.saturating_sub(reach)..(peak + reach + 1).min(bins);
        let total: f64 = frame[range.clone()].iter().sum();
        let mean = range.clone().map(|j| j as f64 * df * frame[j]).sum::<f64>() / total;
        let spread = range.map(|j| (j as f64 * df - mean).powi(2) * frame[j]).sum::<f64>() / total;
        rows.push((time, mean, spread.sqrt()));
    }
    Ok(rows)
}
```

## スペクトログラムと尾根

次のセルは、Gauss ウインドウの標準偏差 $\sigma$ を選んでスペクトログラムを描き、尾根の重心と瞬時周波数の差の RMS、尾根の幅の平均と閉形式の値、逆変換の再構成誤差を表にする。
再構成は、Plan が準備した正準双対で係数から記録を戻し、元の標本との差の最大を測る。
図の色はパワースペクトル密度の線形の値である。

```rust
//| id: signal-chirp-spectrogram
//| ref: signal-chirp-spectrogram
//| title: Gauss ウインドウの STFT でチャープの尾根を測る
//| run: reactive
//| uses: [signal-chirp-model]
//| inputs:
//|   sigma_ms: {"type":"range","label":"ウインドウの標準偏差 σ [ms]","description":"短いと周波数が、長いと時間がぼける。","min":5,"max":60,"step":1,"value":28}
//| cases:
//|   - {"id":"short-window","label":"σ = 5 ms","description":"周波数分解能の項が支配し、尾根が太くなる。","inputs":{"sigma_ms":5}}
//|   - {"id":"long-window","label":"σ = 60 ms","description":"ウインドウの中の周波数の動きが支配し、尾根が太くなる。","inputs":{"sigma_ms":60}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"ridge","path":"/rows/0/1","range":{"max":0.2}}
//|       - {"artifact":"ridge","path":"/rows/0/2","approx":{"value":5.64,"atol":0.1}}
//|       - {"artifact":"ridge","path":"/rows/0/3","approx":{"value":5.64,"atol":0.01}}
//|       - {"artifact":"ridge","path":"/rows/0/4","range":{"max":1e-12}}
//|   - case: short-window
//|     expect:
//|       - {"artifact":"ridge","path":"/rows/0/3","approx":{"value":22.52,"atol":0.01}}
//|       - {"artifact":"ridge","path":"/rows/0/2","approx":{"value":22.5,"atol":0.5}}
//|   - case: long-window
//|     expect:
//|       - {"artifact":"ridge","path":"/rows/0/3","approx":{"value":8.69,"atol":0.01}}
//|       - {"artifact":"ridge","path":"/rows/0/2","approx":{"value":8.69,"atol":0.2}}
let sigma = sigma_ms / 1000.0;
let x = chirp().map_err(|e| e.to_string())?;
let plan = plan(sigma).map_err(|e| e.to_string())?;
let coefficients = plan.analyze(&x).map_err(|e| e.to_string())?;
let power: Vec<f64> = coefficients.iter().map(|c| c.norm_sqr()).collect();
let rows = ridge(&plan, &power, x.len()).map_err(|e| e.to_string())?;

// 尾根の重心と瞬時周波数 f₀ + kτ の差の RMS、幅の平均
let k = sweep_rate();
let squared: f64 = rows.iter().map(|r| (r.1 - (START + k * r.0)).powi(2)).sum();
let rms = (squared / rows.len() as f64).sqrt();
let width = rows.iter().map(|r| r.2).sum::<f64>() / rows.len() as f64;
// 逆変換: Plan の正準双対で戻し、元の標本との差の最大を測る
let restored = plan.synthesize(&coefficients, x.len()).map_err(|e| e.to_string())?;
let error = x.iter().zip(&restored).map(|(a, b)| (a - b).abs()).fold(0.0, f64::max);

let fixed2 = serde_json::json!({ "fractionDigits": 2 });
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let columns = serde_json::json!([
    { "key": "0", "label": "ウインドウ長 m [標本]", "type": "integer" },
    { "key": "1", "label": "尾根の重心の RMS 誤差 [Hz]", "type": "number", "format": fixed2 },
    { "key": "2", "label": "尾根の幅（測定） [Hz]", "type": "number", "format": fixed2 },
    { "key": "3", "label": "尾根の幅（閉形式） [Hz]", "type": "number", "format": fixed2 },
    { "key": "4", "label": "再構成誤差の最大 [-]", "type": "number", "format": sci2 }
]);
let table = vec![(plan.window().len(), rms, width, theory_width(sigma), error)];
emit_table_with_columns!(columns, table, metadata = serde_json::json!({ "id": "ridge" }));

// スペクトログラム: 時刻 [s] × 周波数 [Hz] の密度
let frames = plan.frames(x.len()).map_err(|e| e.to_string())?;
let bins = plan.bins();
let mut heat = Vec::with_capacity(power.len());
for i in 0..frames.count() {
    let time = plan.frame_time(frames.first() + i as i64).map_err(|e| e.to_string())?;
    // 表示を軽くするため、ビンを 1 つおきに描く（1.95 Hz 間隔）
    for j in (0..bins).step_by(2) {
        let frequency = plan.frequency(j).map_err(|e| e.to_string())?;
        heat.push(serde_json::json!([time, frequency, power[i * bins + j]]));
    }
}
emit_chart!(serde_json::json!({
    "kind": "heatmap",
    "data": heat,
    "xLabel": "時刻 τ [s]",
    "yLabel": "周波数 f [Hz]",
    "tooltip": true
}));
```

既定の $\sigma = 28$ ms（ウインドウ長 280 標本）では、尾根の幅の測定値 5.642 Hz が閉形式の 5.642 Hz と 9 桁一致する。
尾根の重心と瞬時周波数の差の RMS は 0.100 Hz である。
これは、フレームの時刻 $ph/f_s$ と偶数長のウインドウの中心が半標本ずれることによる $0.5\ \mathrm{ms} \times 200\ \mathrm{Hz/s} = 0.1$ Hz と一致し、原因の分かった系統誤差である。
逆変換の再構成誤差は $4.4 \times 10^{-16}$ で、丸め誤差の程度にとどまる。

$\sigma = 5$ ms（ウインドウ長 50 標本）では尾根の幅が 22.52 Hz に広がり、閉形式の 22.52 Hz と一致する。
$\sigma = 60$ ms（ウインドウ長 600 標本）では 8.69 Hz で、こちらはウインドウの中の掃引による広がりである。
どちらの場合も重心の誤差は 0.1 Hz のままで、ウインドウの長さは尾根の位置ではなく幅を変える。
図では短いウインドウでも長いウインドウでも尾根が周波数の方向に太くなる。

## ウインドウの長さと尾根の幅

次のセルは、$\sigma$ を 5〜60 ms の 7 点で変えて同じ測定を繰り返し、尾根の幅を閉形式の曲線と比べる。
図は閉形式を破線、測定を記号で描き、最小を与える $\sigma_\ast$ を縦線で示す。

```rust
//| id: signal-chirp-window-sweep
//| ref: signal-chirp-window-sweep
//| title: ウインドウの標準偏差を変えて尾根の幅の最小を確かめる
//| run: reactive
//| uses: [signal-chirp-model]
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"sweep","path":"/rows/0/2","approx":{"value":22.52,"atol":0.01}}
//|       - {"artifact":"sweep","path":"/rows/4/1","approx":{"value":5.64,"atol":0.1}}
//|       - {"artifact":"sweep","path":"/rows/6/1","approx":{"value":8.69,"atol":0.2}}
let x = chirp().map_err(|e| e.to_string())?;
let mut rows = Vec::new();
for sigma_ms in [5.0_f64, 10.0, 15.0, 20.0, 28.2, 40.0, 60.0] {
    let sigma = sigma_ms / 1000.0;
    let plan = plan(sigma).map_err(|e| e.to_string())?;
    let power = plan.spectrogram(&x).map_err(|e| e.to_string())?;
    let ridge = ridge(&plan, &power, x.len()).map_err(|e| e.to_string())?;
    let width = ridge.iter().map(|r| r.2).sum::<f64>() / ridge.len() as f64;
    rows.push((sigma_ms, width, theory_width(sigma)));
}
let fixed1 = serde_json::json!({ "fractionDigits": 1 });
let fixed2 = serde_json::json!({ "fractionDigits": 2 });
let columns = serde_json::json!([
    { "key": "0", "label": "ウインドウの標準偏差 σ [ms]", "type": "number", "format": fixed1 },
    { "key": "1", "label": "尾根の幅（測定） [Hz]", "type": "number", "format": fixed2 },
    { "key": "2", "label": "尾根の幅（閉形式） [Hz]", "type": "number", "format": fixed2 }
]);
emit_table_with_columns!(columns, rows.clone(), metadata = serde_json::json!({ "id": "sweep" }));

// 閉形式の曲線（参照値）と、最小を与える σ* = 1/√(2πk)
let optimum = 1000.0 / (2.0 * core::f64::consts::PI * sweep_rate()).sqrt();
let curve: Vec<[f64; 2]> = (0..=60)
    .map(|i| {
        let ms = 5.0 * 12.0_f64.powf(i as f64 / 60.0);
        [ms, theory_width(ms / 1000.0)]
    })
    .collect();
let measured: Vec<[f64; 2]> = rows.iter().map(|r| [r.0, r.1]).collect();
emit_chart!(serde_json::json!({
    "kind": "xy",
    "xLabel": "ウインドウの標準偏差 σ [ms]",
    "yLabel": "尾根の幅 s_f [Hz]",
    "yMin": 0.0,
    "layers": [
        {
            "id": "theory",
            "kind": "line",
            "name": "閉形式 s_f(σ)",
            "points": curve,
            "style": { "lineType": "dashed", "showSymbol": false }
        },
        { "id": "measured", "kind": "scatter", "name": "STFT での測定", "points": measured }
    ],
    "annotations": [{ "kind": "line", "axis": "x", "value": optimum, "label": "σ* = 1/√(2πk)" }],
    "dataZoom": true,
    "tooltip": true
}));
```

測定した幅は 7 点すべてで閉形式と 0.01 Hz 以内で一致し、最小は $\sigma = 28.2$ ms の 5.64 Hz である。
$\sigma$ を 15 ms に縮めても 40 ms に伸ばしても幅は 7.80 Hz、6.32 Hz で、最小の近くでは幅が $\sigma$ に鈍感である。
$\sigma < \sigma_\ast$ の側では第 1 項（ウインドウの周波数分解能）が、$\sigma > \sigma_\ast$ の側では第 2 項（ウインドウの中の掃引）が支配する。
$\sigma = 5$ ms の差 0.002 Hz は、尾根の重心と幅を前後 100 Hz で打ち切って計算したことによる。

## まとめ

線形チャープのスペクトログラムの尾根の幅は、ウインドウの周波数分解能 $1/(2\sqrt2\,\pi\sigma)$ と、ウインドウの中の周波数の動き $k\sigma/\sqrt2$ の二乗和の平方根で決まる。
掃引の速さ $k$ が分かれば、幅を最小にするウインドウの標準偏差 $\sigma_\ast = 1/\sqrt{2\pi k}$ を事前に決められる。
尾根の重心はウインドウの長さによらず瞬時周波数をよく追うので、周波数の推定には重心、分離能の判断には幅を使う。
STFT の係数は正準双対で丸め誤差の範囲まで元の記録に戻るので、時間周波数領域で係数を変えてから合成する処理にも使える。
ウインドウとフレームの規約は [STFT と再構成](../../algorithms/stft/)、ウインドウの指標は[窓関数と DPSS](../../algorithms/windows-and-dpss/)で確かめる。
