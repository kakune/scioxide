室内の音の伝わり方や通信路の伝送特性は、線形時不変（LTI）系として表せる。
LTI 系は単位インパルスに対する応答 $h[n]$ で決まり、任意の入力 $x[n]$ に対する出力は線形畳み込み $y = x * h$ である。
この例では直接音と二つの壁面反射からなる音圧のインパルス応答を、`scioxide-signal` の `ConvolutionNdPlan` で短いパルスと畳み込む。
結果を遅延した入力の重み付き和と比べ、反射が重なるときに出力のエネルギーに現れる交差項を、入力の自己相関から確かめる。

## 線形時不変系とインパルス応答

離散時間の系 $T$ が線形性 $T\{a x_1 + b x_2\} = aT\{x_1\} + bT\{x_2\}$ と時間不変性（入力を $k$ 標本ずらすと出力も $k$ 標本ずれる）を満たすとする。
入力を単位インパルスの和 $x[n] = \sum_k x[k]\,\delta[n-k]$ に分けると

$$
y[n] = \sum_{k} x[k]\, T\{\delta[n-k]\} = \sum_{k} x[k]\, h[n-k]
$$

となる。
$h = T\{\delta\}$ がインパルス応答で、出力は入力とインパルス応答の[線形畳み込み](oxref:signal-linear-convolution)である。

## 鏡像音源と音圧の減衰

平らな壁で反射した音は、壁に対して音源と対称な位置にある鏡像音源から直接届いた音とみなせる。
点音源から距離 $r$ の位置の音圧は、球面波の広がりにより $1/r$ に比例して小さくなる（音の強さは $1/r^2$ に比例する）。
直接音の経路の長さを $r_0$、第 $i$ 反射の経路の長さを $r_i$、壁の音圧反射係数を $R_i$ とすると、直接音に対する反射の振幅の比と遅延は

$$
a_i = R_i\, \frac{r_0}{r_i}, \qquad \tau_i = \frac{r_i - r_0}{c}
$$

である。
$c = 343$ m/s は空気中の音速である。
音響的に硬い壁では $R_i > 0$（同相の反射）、水中音響の海面のような圧力の解放端では $R_i < 0$（逆相の反射）になる。
標本化周波数 $f_s$ で遅延を標本数 $d_i = \mathrm{round}(\tau_i f_s)$ に丸めると、インパルス応答は遅延したインパルスの和

$$
h[n] = \delta[n] + \sum_{i=1}^{P} a_i\,\delta[n - d_i]
$$

で近似できる。
この例では $r_0 = 3$ m とし、第一反射の遅延 $\tau_1$ と二つの反射係数 $R_1$、$R_2$ を入力にする。
第二反射は第一反射の 18 ms 後に届くとし、経路の長さ $r_i = r_0 + c\,\tau_i$ から振幅の比 $a_i$ を計算する。

## 畳み込みの方法と出力の長さ

長さ $N$ の入力と長さ $M$ の応答の線形畳み込みの長さは $N + M - 1$ である。
`ConvolutionNdPlan::new(&[N], h, &[0], ConvolutionOptions::default())` は応答を核として所有し、同じ形の入力に何度でも使える Plan を作る。
既定の `ConvolutionMethod::Automatic` は、直接和の積の数 $NM$ と、$N + M - 1$ 以上の 2 のべき $P$ の FFT の計算量 $P \log_2 P$ を比べて方法を選ぶ（[直接和と FFT の選択](oxref:signal-convolution-method)）。
FFT を選んだ場合のゼロパディングは Plan が内部で行うので、呼び出し側が長さを調整する必要はない。
`scioxide-fft` の変換から同じ畳み込みを組み立てる方法とゼロパディングの長さの条件は、`scioxide-fft` の章の[ゼロパディングの長さ](oxref:fft-zero-padding)にある。

この見積もりは応答の値が 0 かどうかを見ない。
この例の応答は 0 でない係数を 3 個しか持たないので、遅延した入力の和なら出力 1 標本あたり 3 回の積で済む。
疎な応答では、遅延と係数の組を直接使う方が `Automatic` の選ぶ方法より少ない演算で済むことがある。

次のセルは標本化周波数 2 kHz（標本間隔 0.5 ms）で、中心 14 ms、標準偏差 $\sigma = 2$ ms（4 標本）の Gauss 形パルス 128 標本を入力にする。
応答を核に持つ `ConvolutionNdPlan` を作り、`workspace(ConvolutionKernel::Prepared)` で確保した作業領域で `convolve_into` を呼ぶ。
独立な検算として、$y[n] = x[n] + a_1 x[n - d_1] + a_2 x[n - d_2]$ を直接計算して比べる。
二つ目の表はエネルギーの比 $\lVert y \rVert^2 / \lVert x \rVert^2$ で、測った値、次の節の交差項の式による値、反射が重ならない場合の値を並べる。

```rust
//| id: signal-echo-convolution
//| ref: signal-echo-convolution
//| title: 鏡像音源の応答を ConvolutionNdPlan で畳み込みエネルギーの交差項を確かめる
//| run: reactive
//| crates: [scioxide-core, scioxide-signal]
//| inputs:
//|   first_delay_ms: {"type":"range","label":"第一反射の遅延 τ₁ [ms]","description":"直接音から最初の壁面反射までの遅延時間。","min":2,"max":20,"step":0.5,"value":7}
//|   first_reflection: {"type":"range","label":"第一反射の音圧反射係数 R₁ [-]","description":"硬い壁では 1 に近い正の値。","min":0,"max":1,"step":0.05,"value":0.9}
//|   second_reflection: {"type":"range","label":"第二反射の音圧反射係数 R₂ [-]","description":"負は逆相の反射（圧力の解放端）。","min":-1,"max":1,"step":0.05,"value":-0.7}
//| cases:
//|   - {"id":"short-delay","label":"τ₁ = 2 ms","description":"第一反射が直接音と大きく重なり、交差項でエネルギーが増える。","inputs":{"first_delay_ms":2}}
//|   - {"id":"separated","label":"τ₁ = 20 ms","description":"反射が重ならず、エネルギーの比が 1 + a₁² + a₂² に一致する。","inputs":{"first_delay_ms":20}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"convolution","path":"/rows/0/0","equals":178}
//|       - {"artifact":"convolution","path":"/rows/0/1","equals":"Fft"}
//|       - {"artifact":"convolution","path":"/rows/0/4","range":{"max":1e-14}}
//|       - {"artifact":"energy","path":"/rows/0/4","range":{"max":1e-12}}
//|   - case: separated
//|     expect:
//|       - {"artifact":"energy","path":"/rows/0/4","range":{"max":1e-12}}
//|       - {"artifact":"energy","path":"/rows/0/5","range":{"max":1e-9}}
//|   - case: short-delay
//|     expect:
//|       - {"artifact":"energy","path":"/rows/0/4","range":{"max":1e-12}}
//|       - {"artifact":"energy","path":"/rows/0/5","range":{"min":1.0}}
use scioxide_core::{ExecutionContext, NdView, NdViewMut, RealScalar, StridedLayout};
use scioxide_signal::{ConvolutionKernel, ConvolutionNdPlan, ConvolutionOptions};

// 標本化周波数 2 kHz、中心 14 ms・標準偏差 2 ms（4 標本）の Gauss 形パルス 128 標本
let (rate, sigma) = (2000.0_f64, 4.0_f64);
let input: Vec<f64> = (0..128)
    .map(|i| RealScalar::exp(-0.5 * ((i as f64 - 28.0) / sigma).powi(2)))
    .collect();
// 鏡像音源: 経路長 r_i = r₀ + c τ_i、音圧の比 a_i = R_i r₀ / r_i
let (direct_path, speed) = (3.0_f64, 343.0_f64);
let delays = [first_delay_ms / 1000.0, first_delay_ms / 1000.0 + 0.018];
let gains = [first_reflection, second_reflection]
    .iter()
    .zip(&delays)
    .map(|(r, tau)| r * direct_path / (direct_path + speed * tau))
    .collect::<Vec<_>>();
let lags: Vec<usize> = delays
    .iter()
    .map(|tau| (tau * rate).round() as usize)
    .collect();
let mut response = vec![0.0_f64; lags[1] + 1];
response[0] = 1.0;
response[lags[0]] = gains[0];
response[lags[1]] = gains[1];

// 応答を核に持つ Plan と、その作業領域を一度だけ準備する
let (n, m) = (input.len(), response.len());
let (signal_shape, kernel_shape, output_shape, unit) = ([n], [m], [n + m - 1], [1_usize]);
let kernel_layout = StridedLayout::new(&kernel_shape, &unit).map_err(|e| e.to_string())?;
let signal_layout = StridedLayout::new(&signal_shape, &unit).map_err(|e| e.to_string())?;
let output_layout = StridedLayout::new(&output_shape, &unit).map_err(|e| e.to_string())?;
let kernel = NdView::new(&response, kernel_layout).map_err(|e| e.to_string())?;
let plan = ConvolutionNdPlan::new(&signal_shape, kernel, &[0], ConvolutionOptions::default())
    .map_err(|e| e.to_string())?;
let mut workspace = plan
    .workspace(ConvolutionKernel::Prepared)
    .map_err(|e| e.to_string())?;
let mut output = vec![0.0_f64; n + m - 1];
plan.convolve_into(
    NdView::new(&input, signal_layout).map_err(|e| e.to_string())?,
    NdViewMut::new(&mut output, output_layout).map_err(|e| e.to_string())?,
    &mut workspace,
    ExecutionContext::sequential(),
)
.map_err(|e| e.to_string())?;

// 独立な検算: y[n] = x[n] + a₁ x[n − d₁] + a₂ x[n − d₂] を直接計算する
let shifted = |k: usize, d: usize| {
    if k >= d && k - d < n {
        input[k - d]
    } else {
        0.0
    }
};
let direct: Vec<f64> = (0..n + m - 1)
    .map(|k| shifted(k, 0) + gains[0] * shifted(k, lags[0]) + gains[1] * shifted(k, lags[1]))
    .collect();
let difference = direct
    .iter()
    .zip(&output)
    .fold(0.0_f64, |acc, (a, b)| acc.max((a - b).abs()));
let selection = plan.selection();
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let columns = serde_json::json!([
    { "key": "0", "label": "出力長 N + M − 1 [標本]", "type": "integer" },
    { "key": "1", "label": "選ばれた方法" },
    { "key": "2", "label": "直接法の積の数 [回]", "type": "integer" },
    { "key": "3", "label": "FFT の計算量 [-]", "type": "integer" },
    { "key": "4", "label": "重み付き和との最大差 [-]", "type": "number", "format": sci2 }
]);
let row = (
    output.len(),
    format!("{:?}", selection.method()),
    selection.direct_products(),
    selection.fft_work(),
    difference,
);
emit_table_with_columns!(
    columns,
    vec![row],
    metadata = serde_json::json!({ "id": "convolution" })
);

// 交差項の式: 入力の自己相関 R_xx[d] = Σ x[k] x[k − d] を直接和で求める（独立な検算）
let autocorrelation = |d: usize| (d..n).map(|k| input[k] * input[k - d]).sum::<f64>();
let base = autocorrelation(0);
let measured = output.iter().map(|y| y * y).sum::<f64>() / base;
let separated = 1.0 + gains[0] * gains[0] + gains[1] * gains[1];
let cross = 2.0 * gains[0] * autocorrelation(lags[0])
    + 2.0 * gains[1] * autocorrelation(lags[1])
    + 2.0 * gains[0] * gains[1] * autocorrelation(lags[1] - lags[0]);
let predicted = separated + cross / base;
let fixed5 = serde_json::json!({ "fractionDigits": 5 });
let columns = serde_json::json!([
    { "key": "0", "label": "a₁ [-]", "type": "number", "format": fixed5 },
    { "key": "1", "label": "a₂ [-]", "type": "number", "format": fixed5 },
    { "key": "2", "label": "測った ‖y‖²/‖x‖² [-]", "type": "number", "format": fixed5 },
    { "key": "3", "label": "交差項の式 [-]", "type": "number", "format": fixed5 },
    { "key": "4", "label": "測定と式の差 [-]", "type": "number", "format": sci2 },
    { "key": "5", "label": "重ならない場合との差 [-]", "type": "number", "format": sci2 }
]);
let row = (
    gains[0],
    gains[1],
    measured,
    predicted,
    (measured - predicted).abs(),
    (measured - separated).abs(),
);
emit_table_with_columns!(
    columns,
    vec![row],
    metadata = serde_json::json!({ "id": "energy" })
);

let ms = |k: usize| 1000.0 * k as f64 / rate;
let curve = |v: &[f64]| {
    v.iter()
        .enumerate()
        .map(|(k, &y)| [ms(k), y])
        .collect::<Vec<_>>()
};
emit_line_chart!(
    &vec![
        serde_json::json!({ "name": "入力のパルス x[n]", "points": curve(&input) }),
        serde_json::json!({ "name": "反射を含む出力 y[n]", "points": curve(&output) }),
    ],
    options = &serde_json::json!({
        "xLabel": "時間 [ms]",
        "yLabel": "音圧の比 [-]",
        "xMin": 0.0,
        "xMax": 110.0,
        "annotations": [
            {
                "kind": "line",
                "axis": "x",
                "value": ms(lags[0]) + 14.0,
                "label": "第一反射の中心"
            },
            {
                "kind": "line",
                "axis": "x",
                "value": ms(lags[1]) + 14.0,
                "label": "第二反射の中心"
            }
        ]
    })
);
```

既定の入力（$\tau_1 = 7$ ms、$R_1 = 0.9$、$R_2 = -0.7$）では、経路の長さは 5.40 m と 11.58 m で、振幅の比は $a_1 = 0.49991$、$a_2 = -0.18143$ になる。
出力の長さは $128 + 51 - 1 = 178$ で、`Automatic` は直接法の積の数 6528 が FFT の計算量 $256 \times 8 = 2048$ を超えるので `Fft` を選ぶ。
重み付き和との差は最大 $2.2 \times 10^{-16}$ である。
エネルギーの比は 1.3296 で、交差項の式と $8.9 \times 10^{-16}$ の差で一致し、重ならない場合の $1 + a_1^2 + a_2^2$ より 0.0468 大きい。
第一反射の遅延 14 標本はパルスの標準偏差 4 標本の 3.5 倍で、同相の反射が直接音の裾と重なっている。
$\tau_1 = 2$ ms（4 標本）では $a_1 = 0.7325$ に増え、比は 2.7229 と重ならない場合より 1.14 大きくなる。
$\tau_1 = 20$ ms では重ならない場合との差は $1.1 \times 10^{-10}$ まで小さくなり、残る差は 40 標本離れた Gauss の裾の重なり $e^{-40^2/(4 \cdot 4^2)} = e^{-25}$ の程度である。
$R_2$ を $-1$ と $+1$ にしても比はどちらも 1.3638 で、第二反射は他の成分と重ならないので符号が効かない。

## 波形の重なりとエネルギーの交差項

出力 $y[n] = x[n] + a_1 x[n - d_1] + a_2 x[n - d_2]$ のエネルギーを展開すると

$$
\lVert y \rVert^2 = \left(1 + a_1^2 + a_2^2\right)\lVert x \rVert^2 + 2a_1 R_{xx}[d_1] + 2a_2 R_{xx}[d_2] + 2a_1a_2 R_{xx}[d_2 - d_1]
$$

となる。
$R_{xx}[d] = \sum_n x[n]\,x[n-d]$ は入力の自己相関で、`correlate(x, x)` の添字 $N - 1 + d$ の値に等しい（[相関のラグの並び](oxref:signal-correlation-lags)）。
遅延した二つの成分のパルスが時間の上で重ならなければ、その自己相関は 0 で、エネルギーは各成分のエネルギーの和になる。
重なると交差項が現れ、同相の反射（$a_i > 0$）はエネルギーを増やし、逆相の反射（$a_i < 0$）は打ち消し合ってエネルギーを減らす。

Gauss 形のパルス（標準偏差 $\sigma$ 標本）では、連続の近似で $R_{xx}[d] \approx \lVert x \rVert^2 e^{-d^2/(4\sigma^2)}$ となり、遅延が $2\sigma$ 程度より短いと交差項が効く。
セルの交差項の式は、この近似ではなく離散の自己相関の直接和を使うので、丸めの範囲で測った値と一致する。
したがって、ピークの振幅やエネルギーの合計だけから反射の係数を推定することはできず、遅延ごとの自己相関を考慮する必要がある。

## 計算量と長い信号の処理

直接の畳み込みの演算量は $O(NM)$、FFT による畳み込みは $O(P \log P)$ である。
残響の長い部屋のように応答が長く密な場合（$M \sim 10^5$ 標本）は FFT の方が少ない演算で済み、この例のように 0 でない係数が少ない応答では遅延した入力の和の方が少ない。
同じ応答で多くの入力を処理するときは、このセルのように Plan と作業領域を一度だけ準備して `convolve_into` を繰り返す。
長い音声を区切って流すときは、オーバーラップ加算の `OverlapPlan` と `OverlapStream` を使い、最後のチャンクで `StreamChunk::Final` を渡す（[オーバーラップ加算による逐次処理](oxref:signal-overlap-add)）。
既知の応答で反射を取り除くには `deconvolve` で多項式の除算を行えるが、応答が最小位相でない場合は誤差が指数的に増える（[逆畳み込みと多項式の除算](oxref:signal-deconvolution)）。

## まとめ

LTI 系の出力は入力とインパルス応答の線形畳み込みで、壁の反射は鏡像音源からの経路として、音圧の比 $R_i r_0 / r_i$ と遅延 $(r_i - r_0)/c$ でモデル化できる。
`ConvolutionNdPlan` は応答を核として所有し、ゼロパディングと方法の選択を内部で行うので、同じ応答で入力を繰り返し畳み込める。
`Automatic` の選択は応答の疎らさを考慮しないので、0 でない係数が少ない応答では遅延した和の方が少ない演算で済む。
反射が直接音と重なると、エネルギーに自己相関の交差項が加わり、同相と逆相で増減が逆になる。
