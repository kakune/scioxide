AM ラジオの受信機、振動の監視、超音波の反射の検出では、速く振動する搬送波に載った遅い振幅の変化（包絡線）を取り出す。
解析信号 $z = x + i\,\mathcal{H}[x]$ の絶対値 $\lvert z \rvert$ は、包絡線を求める標準的な方法である。
ただし $\lvert z \rvert$ が包絡線に一致するのは、包絡線の帯域が搬送波の周波数より低いときに限る（Bedrosian の条件）。
この例では振幅変調波の解析信号を `scioxide-signal` の `hilbert` と `envelope` で求め、閉じた形の解析信号と比べる。
そのうえで、過変調と、搬送波の周波数が変調の周波数より低い場合に、$\lvert z \rvert$ が何を表すかを確かめる。

離散の解析信号の重み（DC と偶数長の Nyquist のビンは 1、正の周波数は 2、負の周波数は 0）の導出と、包絡線を読む条件は[解析信号、Riesz 変換、ベクトル強度](oxref:signal-analytic-signal)で説明している。
同じ重みを `rfft` と `ifft` から組み立てる手順は、fft 章の[解析信号と離散 Hilbert 変換](../../../scioxide-fft/algorithms/analytic-signal/)にある。

## 振幅変調波の解析信号

搬送波の周波数 $f_c$、変調の周波数 $f_m$、変調度 $m$ の振幅変調波は

$$
x(t) = \left[1 + m\cos(2\pi f_m t)\right]\cos(2\pi f_c t)
$$

である。
積和の公式で展開すると

$$
x(t) = \cos(2\pi f_c t) + \frac m2\cos\left(2\pi (f_c + f_m) t\right) + \frac m2\cos\left(2\pi (f_c - f_m) t\right)
$$

となり、搬送波と上下 2 つの側帯の 3 つの余弦波の和になる。
周波数 $g \ge 0$ の余弦波 $\cos(2\pi g t)$ の解析信号は $e^{2\pi i g t}$ である（$g = 0$ では定数 1 のまま）。
余弦は偶関数なので、$\cos(2\pi (f_c - f_m) t) = \cos(2\pi \lvert f_c - f_m \rvert t)$ と書き直せる。
したがって、どの $f_c$、$f_m$ でも、解析信号は閉じた形

$$
z(t) = e^{2\pi i f_c t} + \frac m2 e^{2\pi i (f_c + f_m) t} + \frac m2 e^{2\pi i \lvert f_c - f_m \rvert t}
$$

を持つ。
このページではこの $z$ を `hilbert` の結果の独立な検算に使う。

$f_c \ge f_m$ なら $\lvert f_c - f_m \rvert = f_c - f_m$ で、3 つの項から $e^{2\pi i f_c t}$ をくくり出せる。

$$
z(t) = \left[1 + m\cos(2\pi f_m t)\right] e^{2\pi i f_c t},
\qquad
\lvert z(t) \rvert = \left\lvert 1 + m\cos(2\pi f_m t) \right\rvert
$$

これは Bedrosian の定理の結論と同じで、$m \le 1$ なら $\lvert z \rvert$ は包絡線 $1 + m\cos(2\pi f_m t)$ そのものである。
$f_c = f_m$ では下側の側帯が DC になるが、くくり出しはそのまま成り立つ。

$m > 1$（過変調）では、包絡線 $1 + m\cos(2\pi f_m t)$ が負になる区間がある。
$\lvert z \rvert$ は定義から非負なので、復元されるのは負の部分を折り返した $\lvert 1 + m\cos(2\pi f_m t) \rvert$ である。
このとき $z$ の軌跡は原点を通り、位相 $\arg z$ は包絡線が 0 を横切る瞬間に $\pi$ だけ跳ぶ。
瞬時周波数を位相の差分で求めると、そこに大きな尖りが出る。

## 離散化と検算の設計

標本化周波数は $f_s = 256$ Hz、標本数は $N = 512$（観測時間 2 s）とする。
$f_c$ と $f_m$ を整数 Hz にすると、3 つの余弦波はどれも 2 s の間に整数回振動し、記録の両端で周期がつながる。
このとき DFT の周期の仮定が正しく、離散の解析信号は上の閉じた形の $z$ の標本と丸め誤差の範囲で一致するはずである。
入力の範囲では $f_c + f_m \le 124$ Hz で、Nyquist 周波数 128 Hz を超えない。

次のブロックは、2 つのセルが共有する定義である。
`am_signal` は $x(t)$、`closed_form` は閉じた形の解析信号 $z(t)$ を、どちらも f64 の固有メソッドによる参照計算で返す。

```rust
//| id: signal-hilbert-envelope-model
//| kind: definitions
//| title: 振幅変調波と閉じた形の解析信号
//| crates: [scioxide-core]
use scioxide_core::Complex;

/// 標本数 N と標本化周波数 f_s [Hz]（観測時間 2 s）。
pub(crate) const SAMPLES: usize = 512;
pub(crate) const SAMPLE_RATE: f64 = 256.0;

/// x(t) = [1 + m cos(2π f_m t)] cos(2π f_c t)。参照計算なので f64 の固有メソッドを使う。
pub(crate) fn am_signal(depth: f64, carrier: f64, modulation: f64, t: f64) -> f64 {
    let tau = std::f64::consts::TAU;
    (1.0 + depth * (tau * modulation * t).cos()) * (tau * carrier * t).cos()
}

/// z(t) = e^{2πi f_c t} + (m/2) e^{2πi (f_c + f_m) t} + (m/2) e^{2πi |f_c − f_m| t}。
pub(crate) fn closed_form(depth: f64, carrier: f64, modulation: f64, t: f64) -> Complex<f64> {
    let tau = std::f64::consts::TAU;
    let tone = |frequency: f64, amplitude: f64| {
        let phase = tau * frequency * t;
        Complex::new(amplitude * phase.cos(), amplitude * phase.sin())
    };
    tone(carrier, 1.0)
        + tone(carrier + modulation, 0.5 * depth)
        + tone((carrier - modulation).abs(), 0.5 * depth)
}
```

## 包絡線の復元

次のセルは、入力の $m$、$f_c$、$f_m$ の振幅変調波を作り、`hilbert` で解析信号を、`envelope` で包絡線を求める。
検算は 4 つである。
閉じた形の $z$ との差の最大は、`hilbert` の計算そのものを確かめる。
$\lvert z \rvert$ と $\lvert 1 + m\cos(2\pi f_m t) \rvert$ の差の最大は、$\lvert z \rvert$ を包絡線として読めるかを確かめる。
実部と入力の差の最大は、重みの付け方を確かめる（`hilbert` は実部に入力をそのまま写すので 0 になる）。
`envelope` の結果と `hilbert` の結果の絶対値の差は、2 つの関数が同じ計算をしていることを確かめる。
図の実線は $\lvert z \rvert$、破線は符号付きの理論の包絡線 $1 + m\cos(2\pi f_m t)$ である。

```rust
//| id: signal-hilbert-envelope
//| ref: signal-hilbert-envelope
//| title: 振幅変調波の解析信号と包絡線を閉じた形と比べる
//| run: reactive
//| uses: [signal-hilbert-envelope-model]
//| crates: [scioxide-core, scioxide-signal]
//| inputs:
//|   modulation_depth: {"type":"range","label":"変調度 m [-]","description":"1 を超えると過変調になる。","min":0,"max":1.2,"step":0.05,"value":0.65}
//|   carrier_hz: {"type":"range","label":"搬送波の周波数 f_c [Hz]","min":1,"max":100,"step":1,"value":32}
//|   modulation_hz: {"type":"range","label":"変調の周波数 f_m [Hz]","min":1,"max":24,"step":1,"value":3}
//| cases:
//|   - {"id":"overmodulation","label":"m = 1.2（過変調）","description":"包絡線の負の部分が折り返され、|z| は |1 + m cos| に一致する。","inputs":{"modulation_depth":1.2}}
//|   - {"id":"low-carrier","label":"f_c = 8 Hz、f_m = 20 Hz","description":"下側の側帯が負の周波数に移り、|z| は包絡線から最大 0.62 ずれるが、閉じた形の z とは一致する。","inputs":{"carrier_hz":8,"modulation_hz":20}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"checks","path":"/rows/0/1","range":{"max":1e-13}}
//|       - {"artifact":"checks","path":"/rows/1/1","range":{"max":1e-13}}
//|       - {"artifact":"checks","path":"/rows/2/1","equals":0}
//|       - {"artifact":"checks","path":"/rows/3/1","equals":0}
//|   - case: overmodulation
//|     expect:
//|       - {"artifact":"checks","path":"/rows/1/1","range":{"max":1e-13}}
//|   - case: low-carrier
//|     expect:
//|       - {"artifact":"checks","path":"/rows/0/1","range":{"max":1e-13}}
//|       - {"artifact":"checks","path":"/rows/1/1","approx":{"value":0.62,"atol":0.01}}
use scioxide_signal::{envelope, hilbert};

let (m, fc, fm) = (modulation_depth, carrier_hz, modulation_hz);
let time = |i: usize| i as f64 / SAMPLE_RATE;
let signal: Vec<f64> = (0..SAMPLES)
    .map(|i| am_signal(m, fc, fm, time(i)))
    .collect();
let analytic = hilbert(&signal).map_err(|e| e.to_string())?;
let magnitude = envelope(&signal).map_err(|e| e.to_string())?;

// 理論の包絡線 1 + m cos(2π f_m t)（符号付き）。
let theory = |t: f64| 1.0 + m * (std::f64::consts::TAU * fm * t).cos();
let (mut closed_gap, mut envelope_gap) = (0.0_f64, 0.0_f64);
let (mut real_gap, mut same_gap) = (0.0_f64, 0.0_f64);
let (mut estimated, mut expected) = (Vec::with_capacity(SAMPLES), Vec::with_capacity(SAMPLES));
for (i, z) in analytic.iter().enumerate() {
    let t = time(i);
    closed_gap = closed_gap.max((*z - closed_form(m, fc, fm, t)).norm());
    envelope_gap = envelope_gap.max((magnitude[i] - theory(t).abs()).abs());
    real_gap = real_gap.max((z.re - signal[i]).abs());
    same_gap = same_gap.max((magnitude[i] - z.norm()).abs());
    estimated.push([t, magnitude[i]]);
    expected.push([t, theory(t)]);
}

let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let columns = serde_json::json!([
    { "key": "0", "label": "検算" },
    { "key": "1", "label": "差の最大 [-]", "type": "number", "format": sci2 }
]);
let rows = vec![
    ("hilbert と閉じた形の z", closed_gap),
    ("envelope と |1 + m cos(2π fₘ t)|", envelope_gap),
    ("Re z と x", real_gap),
    ("envelope と |hilbert|", same_gap),
];
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "checks" })
);
emit_line_chart!(
    &vec![
        serde_json::json!({ "name": "|z(t)|（envelope）", "points": estimated }),
        serde_json::json!({
            "name": "1 + m cos(2π fₘ t)（理論）",
            "points": expected,
            "style": { "lineType": "dashed" }
        }),
    ],
    options = &serde_json::json!({
        "xLabel": "時間 t [s]",
        "yLabel": "包絡線 [-]",
        "xMin": 0.0,
        "xMax": 2.0,
        "yMin": -0.3,
        "yMax": 2.3,
        "annotations": [{ "kind": "line", "axis": "y", "value": 0.0 }]
    })
);
```

既定の $m = 0.65$、$f_c = 32$ Hz、$f_m = 3$ Hz では、`hilbert` と閉じた形の $z$ の差の最大は $4.8\times10^{-14}$、$\lvert z \rvert$ と包絡線の差の最大は $2.9\times10^{-14}$ である。
実部と入力の差、`envelope` と `hilbert` の絶対値の差はどちらも 0 である。
差の大きさは、参照の位相 $2\pi f t$（最大で約 440 rad）を倍精度で計算するときの丸め誤差 $u \cdot 440 \approx 5\times10^{-14}$（$u = 2^{-53}$）と同じ程度になる。
$f_c = 100$ Hz では位相が約 1300 rad まで大きくなり、閉じた形との差も $2.0\times10^{-13}$ に増える。

$m = 1.2$ にすると、図の破線（符号付きの包絡線）は 0 を下回るが、実線 $\lvert z \rvert$ は 0 で折り返して上に出る。
$\lvert z \rvert$ と $\lvert 1 + m\cos(2\pi f_m t) \rvert$ の差は $3.8\times10^{-14}$ で、折り返した形とは一致する。

$f_c = 8$ Hz、$f_m = 20$ Hz では、`hilbert` と閉じた形の $z$ の差は $1.8\times10^{-14}$ のままだが、$\lvert z \rvert$ と包絡線の差は 0.62 に広がる。
図の実線は破線から離れ、速く揺れる。
次節で、この食い違いを搬送波の周波数の関数として調べる。

## 搬送波が変調より低い場合

$f_c < f_m$ では、下側の側帯の周波数 $f_c - f_m$ が負になる。
実数の信号では $\cos(2\pi(f_c - f_m)t) = \cos(2\pi(f_m - f_c)t)$ なので、この成分は正の周波数 $f_m - f_c$ の余弦波と区別できず、解析信号では $e^{2\pi i (f_m - f_c) t}$ になる。
閉じた形の $z$ から $e^{2\pi i f_c t}$ をくくり出すと

$$
z(t) = e^{2\pi i f_c t}\left[1 + \frac m2 e^{2\pi i f_m t} + \frac m2 e^{2\pi i (f_m - 2 f_c) t}\right]
$$

となり、括弧の中は $1 + m\cos(2\pi f_m t)$ に戻らない。
包絡線の因子 $1 + m\cos(2\pi f_m t)$ のスペクトル（$\lvert f \rvert \le f_m$）と搬送波のスペクトル（$\lvert f \rvert = f_c$）が重なり、Bedrosian の条件が崩れたからである。
$\lvert z \rvert$ には周波数 $2 f_c$ の揺れが加わり、包絡線とは別の量になる。
`hilbert` の計算が誤っているのではなく、$\lvert z \rvert$ を包絡線と読む前提が成り立たない。

次のセルは、$m$ と $f_m$ を固定して $f_c = 1, 2, \dots, 60$ Hz を走査し、各 $f_c$ で `envelope` を求める。
各 $f_c$ について、$\lvert z \rvert$ と $\lvert 1 + m\cos(2\pi f_m t) \rvert$ の差の最大（包絡線の誤差）と、`hilbert` と閉じた形の $z$ の差の最大を記録する。
図は 2 つの差を対数軸で描き、縦線で $f_c = f_m$ を示す。
差がちょうど 0 になった点は対数軸に描けないので除き、その数を表に示す。

```rust
//| id: signal-hilbert-bedrosian-sweep
//| ref: signal-hilbert-bedrosian-sweep
//| title: 搬送波の周波数を走査して包絡線の誤差を測る
//| run: reactive
//| uses: [signal-hilbert-envelope-model]
//| crates: [scioxide-core, scioxide-signal]
//| inputs:
//|   modulation_depth: {"type":"range","label":"変調度 m [-]","min":0.05,"max":1,"step":0.05,"value":0.65}
//|   modulation_hz: {"type":"range","label":"変調の周波数 f_m [Hz]","min":1,"max":24,"step":1,"value":20}
//| cases:
//|   - {"id":"slow-modulation","label":"f_m = 3 Hz","description":"誤差が大きいのは f_c = 1, 2 Hz だけになる。","inputs":{"modulation_hz":3}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"sweep","path":"/rows/0/0","range":{"max":1e-13}}
//|       - {"artifact":"sweep","path":"/rows/0/1","range":{"min":0.1}}
//|       - {"artifact":"sweep","path":"/rows/0/2","range":{"max":5e-13}}
//|   - case: slow-modulation
//|     expect:
//|       - {"artifact":"sweep","path":"/rows/0/0","range":{"max":1e-13}}
use scioxide_signal::{envelope, hilbert};

let (m, fm) = (modulation_depth, modulation_hz);
let time = |i: usize| i as f64 / SAMPLE_RATE;
let theory = |t: f64| (1.0 + m * (std::f64::consts::TAU * fm * t).cos()).abs();
let (mut envelope_points, mut closed_points) = (Vec::new(), Vec::new());
let (mut above, mut below, mut closed_worst) = (0.0_f64, f64::INFINITY, 0.0_f64);
let mut zero_points = 0_usize;
for carrier in 1..=60 {
    let fc = carrier as f64;
    let signal: Vec<f64> = (0..SAMPLES)
        .map(|i| am_signal(m, fc, fm, time(i)))
        .collect();
    let magnitude = envelope(&signal).map_err(|e| e.to_string())?;
    let analytic = hilbert(&signal).map_err(|e| e.to_string())?;
    let envelope_gap = (0..SAMPLES).fold(0.0_f64, |acc, i| {
        acc.max((magnitude[i] - theory(time(i))).abs())
    });
    let closed_gap = (0..SAMPLES).fold(0.0_f64, |acc, i| {
        acc.max((analytic[i] - closed_form(m, fc, fm, time(i))).norm())
    });
    // f_c ≥ f_m では最大、f_c < f_m では最小を集計する。
    if fc >= fm {
        above = above.max(envelope_gap);
    } else {
        below = below.min(envelope_gap);
    }
    closed_worst = closed_worst.max(closed_gap);
    // 0 の差は対数軸に描けないので除いて数える。
    for (points, gap) in [
        (&mut envelope_points, envelope_gap),
        (&mut closed_points, closed_gap),
    ] {
        if gap > 0.0 {
            points.push([fc, gap]);
        } else {
            zero_points += 1;
        }
    }
}

let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let columns = serde_json::json!([
    { "key": "0", "label": "f_c ≥ f_m の包絡線の誤差の最大 [-]", "type": "number", "format": sci2 },
    { "key": "1", "label": "f_c < f_m の包絡線の誤差の最小 [-]", "type": "number", "format": sci2, "nullText": "該当なし" },
    { "key": "2", "label": "閉じた形の z との差の最大 [-]", "type": "number", "format": sci2 },
    { "key": "3", "label": "図から除いた 0 の点 [個]", "type": "integer" }
]);
let below = below.is_finite().then_some(below);
emit_table_with_columns!(
    columns,
    vec![(above, below, closed_worst, zero_points)],
    metadata = serde_json::json!({ "id": "sweep" })
);
emit_chart!(serde_json::json!({
    "kind": "scatter",
    "dataZoom": true,
    "tooltip": true,
    "series": [
        { "name": "| |z| − |1 + m cos| | の最大", "points": envelope_points },
        { "name": "|z − 閉じた形| の最大", "points": closed_points }
    ],
    "xLabel": "搬送波の周波数 f_c [Hz]",
    "yLabel": "差の最大 [-]",
    "yType": "log",
    "xMin": 0.0,
    "xMax": 61.0,
    "annotations": [{ "kind": "line", "axis": "x", "value": fm, "label": "f_c = f_m" }]
}));
```

既定の $m = 0.65$、$f_m = 20$ Hz では、$f_c \ge 20$ Hz の 41 通りで包絡線の誤差の最大は $8.1\times10^{-14}$ で、$f_c < 20$ Hz の 19 通りでは最小でも $0.60$ である。
図では、$f_c = f_m$ の縦線を境に、包絡線の誤差が丸め誤差の水準から $10^{-1}$ の桁へ跳ぶ。
一方、`hilbert` と閉じた形の $z$ の差は、60 通りのすべてで $1.3\times10^{-13}$ 以下にとどまる。
$f_c = f_m$ では下側の側帯が DC になるが、前節のくくり出しが成り立つので、誤差は丸め誤差の水準のままである。
誤差の大きさは変調度にほぼ比例し、$f_c < f_m$ での最小は $m = 0.05$ で $0.045$、$m = 1$ で $0.96$ である。
$f_m = 3$ Hz では、誤差が大きいのは $f_c = 1, 2$ Hz だけになり、最小は $0.54$ になる。
包絡線を読む前に、包絡線の帯域（ここでは $f_m$）が搬送波の周波数を超えないことを確かめる必要がある。

## まとめ

`hilbert` は記録を 1 周期とみなした解析信号を返し、整数周期の振幅変調波では閉じた形の解析信号と丸め誤差の範囲で一致する。
$\lvert z \rvert$ を包絡線と読めるのは、包絡線の帯域が搬送波の周波数を超えないとき（Bedrosian の条件）で、この例では $f_c \ge f_m$ のときに限る。
条件が崩れても `hilbert` の結果は正しいが、$\lvert z \rvert$ には $2 f_c$ の揺れが加わり、包絡線とは別の量になる。
過変調では、$\lvert z \rvert$ は負の部分を折り返した $\lvert 1 + m\cos(2\pi f_m t) \rvert$ を返し、位相は $\pi$ 跳ぶ。
記録の両端で周期がつながらない信号では、端の近くの包絡線が乱れるので、ウインドウを掛けるか余白を取って中央だけを使う。

瞬時周波数の求め方と、端の跳びが誤差に与える影響は、[解析信号、Riesz 変換、ベクトル強度](oxref:signal-instantaneous-frequency)のチャープの例で確かめる。
`rfft` と `ifft` で同じ解析信号を組み立てる手順は、[解析信号と離散 Hilbert 変換](../../../scioxide-fft/algorithms/analytic-signal/)で確かめる。
