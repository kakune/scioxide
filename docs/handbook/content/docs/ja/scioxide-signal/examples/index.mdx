信号処理の関数を測定データに使うときは、結果を別の計算経路で確かめられる形で使う。
この章の実例は、どれも閉じた形の値、定義どおりの直接計算、またはシードを変えた模擬観測の統計を同じページの中に置き、SciOxide の計算と並べて出力する。
入力を変えて一致の程度の変化を見れば、どの入力で手法の仮定が成り立たなくなるかも読み取れる。

| 実例 | 題材 | 使う API | 独立な検算 |
|---|---|---|---|
| [平滑化・ピーク・外れ値の検算](smoothing-peaks-and-outliers/) | Gauss 核による平滑化、平坦な頂部を持つピーク、センサー列のスパイク除去 | `convolve`、`power_spectrum`、`find_peaks_with_options`、`LocalFilterPlan`、`LocalFilterStream` | 二重ループの直接和、Parseval の関係と和の保存、突出度と幅の手計算、一括処理と逐次処理の一致 |
| [変光星の周期推定](variable-star-period/) | 不等間隔に観測したこと座 RR 型変光星（$P = 0.567$ 日）の周期と日周エイリアス | `lomb_scargle`、`LombScargle` | 真の周期との比較、誤警報確率の近似とノイズだけの模擬観測の超過割合（標準誤差付き） |
| [心電図の基線変動と電源ノイズの除去](ecg-baseline-and-mains/) | 合成した心電図に 0.3 Hz の基線変動と 50 Hz の電源ノイズを加え、ノッチと高域通過で除く | `design_notch_peak`、`design_iir`、`SecondOrderSections`、`detrend`、`find_peaks_with_options` | ノッチの閉じた形の応答、周波数応答から予測した残りのノイズの RMS、R 波の時刻のずれ |
| [IIR の群遅延とゼロ位相フィルタリング](iir-group-delay-zero-phase/) | Butterworth・Chebyshev・Bessel の低域通過の群遅延とパルスの歪み | `design_iir`、`SecondOrderSections`、`group_delay`、`forward_backward` | 零点と極からの群遅延の式と位相の数値微分、出力の重心のずれ、ゼロ位相の対称性 |
| [チャープのスペクトログラムと時間周波数の不確定性](chirp-spectrogram-uncertainty/) | 線形チャープの STFT で、ウインドウ長による時間分解能と周波数分解能の交換を測る | `waveform`、`window`、`StftPlan` | 尾根の幅の閉じた形と最適なウインドウ幅、瞬時周波数の理論値、逆変換の再構成誤差 |
| [ウェーブレットによるノイズ除去と完全再構成](wavelet-denoising/) | 区分的に滑らかな試験信号のノイズを、MAD で推定した普遍閾値で縮小する | `WaveletPlan`、`WaveletFamily` | 閾値 0 での往復の誤差、ノイズのない信号との誤差の改善、シードを変えた反復の平均と標準誤差 |
| [44.1 kHz と 48 kHz の変換とエイリアシング](audio-sample-rate-conversion/) | 比 160/147 のリサンプリングの通過域の誤差と折り返しの抑圧 | `resample`、`PolyphasePlan`、`resample_periodic` | 正弦波の振幅と位相の理論値、折り返し成分の測定、往復の誤差 |
| [地震波の到達時刻差を相互相関で推定する](seismic-delay-correlation/) | 2 観測点の記録の遅延を、相関と放物線補間で標本以下まで推定する | `correlate`、`waveform` | 真の遅延との誤差、線形化した誤差の式とシードを変えた反復の標準偏差 |
| [RLC 回路の LTI モデル](rlc-circuit-lti/) | 直列 RLC 回路の Bode 線図とステップ応答、離散化の誤差 | `StateSpace`、`frequency_response`、`step_response`、`discretize` | 共振での振幅と位相の閉じた形、ステップ応答と行き過ぎ量の閉じた形 |
| [インパルス応答と音響反射の線形畳み込み合成](echo-convolution/) | 直接音と壁面の多重反射の応答を、準備した畳み込みの Plan で合成する | `ConvolutionNdPlan`、`convolve` | 重み付き遅延和の直接計算、自己相関の交差項によるエネルギーの式 |
| [Hilbert 変換による解析信号生成と瞬時包絡線復元](hilbert-envelope/) | 振幅変調波の包絡線を求め、搬送波が変調より低い場合の破綻を見る | `hilbert`、`envelope` | 閉じた形の解析信号と理論の包絡線 |

数理のページにも検算付きのセルがある。
たとえば[窓関数と DPSS](../algorithms/windows-and-dpss/) は Hann ウインドウの利得と ENBW を閉じた形と比べ、[FIR フィルタの設計と最小位相](../algorithms/fir-design-and-minimum-phase/) は Remez 法の等リプルを密な格子で数え、[状態空間モデルと LTI 系](../algorithms/lti-systems/) は離散化の誤差の次数を測る。

## まとめ

実例は、局所処理（平滑化・ピーク・外れ値）、周期とスペクトルの推定（変光星、チャープ）、フィルタの設計と適用（心電図、群遅延）、ウェーブレットによるノイズ除去、リサンプリング、相関による遅延推定、LTI 系のモデル、畳み込みによる合成、包絡線の復元に分かれる。
どの実例でも、SciOxide の計算と独立な検算を並べて出力するので、入力を変えたときに一致の程度がどう変わるかを確かめられる。
題材の課題に近い実例から読み、使っている手法の数理は[数理とアルゴリズム](../algorithms/)で確かめる。
