抵抗 $R$、インダクタ $L$、コンデンサ $C$ を直列につないだ RLC 回路は、2 次の LTI 系の代表例である。
電源電圧を入力、コンデンサの電圧を出力とすると、回路は低域通過フィルタとして働き、抵抗が小さいほど共振の山が鋭くなる。
この例題では、回路を状態空間モデルで表し、周波数応答から Bode 線図と共振のピークを、時間応答からステップ応答の行き過ぎ量を求めて、どちらも閉形式と照合する。
最後に、標本化周波数を選んで零次ホールドと Tustin 変換で離散化し、標本点での誤差を比べる。
状態空間モデルと離散化の一般的な説明は[状態空間モデルと LTI 系](../../algorithms/lti-systems/)にある。

## 回路の方程式と状態空間モデル

電流を $i(t)$ [A]、コンデンサの電圧を $v_C(t)$ [V]、電源電圧を $u(t)$ [V] とする。
Kirchhoff の電圧則とコンデンサの関係 $i = C\,dv_C/dt$ から

$$
L \frac{di}{dt} = u - R i - v_C, \qquad C \frac{dv_C}{dt} = i
$$

が成り立つ。
状態を $x = (i, v_C)$、出力を $y = (v_C, i)$ の順にとると、状態空間モデルは

$$
A = \begin{bmatrix} -R/L & -1/L \\ 1/C & 0 \end{bmatrix}, \quad
B = \begin{bmatrix} 1/L \\ 0 \end{bmatrix}, \quad
C_{\mathrm{out}} = \begin{bmatrix} 0 & 1 \\ 1 & 0 \end{bmatrix}, \quad
D = \begin{bmatrix} 0 \\ 0 \end{bmatrix}
$$

になる（出力行列を容量 $C$ と区別して $C_{\mathrm{out}}$ と書く）。
時間の単位は秒、角周波数の単位は rad/s である。

固有角周波数と減衰比は

$$
\omega_0 = \frac{1}{\sqrt{LC}}, \qquad \zeta = \frac{R}{2}\sqrt{\frac{C}{L}}
$$

で、コンデンサの電圧への伝達関数は

$$
H(s) = \frac{V_C(s)}{U(s)} = \frac{\omega_0^2}{s^2 + 2\zeta\omega_0 s + \omega_0^2}
$$

である。
電流への伝達関数（アドミタンス）は $Y(s) = Cs\,H(s)$ で、$s = i\omega_0$ では $Y = 1/R$ になる。
この例題では $L = 10$ mH、$C = 1$ μF に固定し、$\omega_0 = 10^4$ rad/s（$f_0 \approx 1.59$ kHz）とする。
抵抗 $R$ は 2〜180 Ω の範囲で選び、$\zeta = R/200$ は 0.01〜0.9 になる。

## 共振のピークと過渡応答の閉形式

$s = i\omega$ を代入すると、振幅は

$$
|H(i\omega)| = \frac{1}{\sqrt{(1 - \Omega^2)^2 + (2\zeta\Omega)^2}}, \qquad \Omega = \omega / \omega_0
$$

である。
$\omega = \omega_0$ では $|H| = 1/(2\zeta)$、位相は $-90°$ になる。
$\zeta < 1/\sqrt{2}$ のとき、振幅は $\omega_r = \omega_0\sqrt{1 - 2\zeta^2}$ で最大値 $1/(2\zeta\sqrt{1 - \zeta^2})$ をとる。
$\zeta \ge 1/\sqrt{2}$ では山がなく、振幅は直流の 1 から単調に減る。

零状態から 1 V のステップ電圧を加えると、$0 < \zeta < 1$ では

$$
\begin{aligned}
v_C(t) &= 1 - e^{-\zeta\omega_0 t} \left( \cos\omega_d t + \frac{\zeta}{\sqrt{1 - \zeta^2}} \sin\omega_d t \right), \\
i(t) &= \frac{C\omega_0}{\sqrt{1 - \zeta^2}}\, e^{-\zeta\omega_0 t} \sin\omega_d t, \qquad \omega_d = \omega_0\sqrt{1 - \zeta^2}
\end{aligned}
$$

となる。
$v_C$ は時刻 $t_p = \pi/\omega_d$ で最大になり、最終値 1 V を超える行き過ぎ量は $e^{-\pi\zeta/\sqrt{1 - \zeta^2}}$ V である。

次のブロックは二つのセルが共有するモデルである。
`rlc_model` が上の状態空間モデル、`natural_frequency` と `damping_ratio` が $\omega_0$ と $\zeta$、`step_voltage` と `step_current` がステップ応答の閉形式に対応する。
閉形式は検算のための参照値で、`f64` の標準関数で計算する。

```rust
//| id: signal-rlc-model
//| kind: definitions
//| title: 直列 RLC 回路の状態空間モデルとステップ応答の閉形式
//| crates: [scioxide-core, scioxide-linalg, scioxide-signal]
use scioxide_core::SciOxideError;
use scioxide_linalg::Matrix;
use scioxide_signal::{LtiTime, StateSpace};

/// インダクタンス L [H] と容量 C [F]。
pub(crate) const INDUCTANCE: f64 = 10.0e-3;
pub(crate) const CAPACITANCE: f64 = 1.0e-6;

/// 状態 (i, v_C)、入力 u、出力 (v_C, i) の連続系。
pub(crate) fn rlc_model(resistance: f64) -> Result<StateSpace<f64>, SciOxideError> {
    let (l, c) = (INDUCTANCE, CAPACITANCE);
    let a = Matrix::from_vec(2, 2, vec![-resistance / l, -1.0 / l, 1.0 / c, 0.0])?;
    let b = Matrix::from_vec(2, 1, vec![1.0 / l, 0.0])?;
    let output = Matrix::from_vec(2, 2, vec![0.0, 1.0, 1.0, 0.0])?;
    let d = Matrix::zeros(2, 1)?;
    StateSpace::new(
        LtiTime::Continuous,
        a.view(),
        b.view(),
        output.view(),
        d.view(),
    )
}

/// 固有角周波数 ω₀ = 1/√(LC) [rad/s]。
pub(crate) fn natural_frequency() -> f64 {
    1.0 / (INDUCTANCE * CAPACITANCE).sqrt()
}

/// 減衰比 ζ = (R/2)√(C/L) [-]。
pub(crate) fn damping_ratio(resistance: f64) -> f64 {
    0.5 * resistance * (CAPACITANCE / INDUCTANCE).sqrt()
}

/// 1 V のステップに対するコンデンサの電圧 v_C(t) [V]（0 < ζ < 1）。参照値。
pub(crate) fn step_voltage(resistance: f64, time: f64) -> f64 {
    let (w0, z) = (natural_frequency(), damping_ratio(resistance));
    let root = (1.0 - z * z).sqrt();
    let phase = w0 * root * time;
    1.0 - (-z * w0 * time).exp() * (phase.cos() + z / root * phase.sin())
}

/// 1 V のステップに対する電流 i(t) [A]（0 < ζ < 1）。参照値。
pub(crate) fn step_current(resistance: f64, time: f64) -> f64 {
    let (w0, z) = (natural_frequency(), damping_ratio(resistance));
    let root = (1.0 - z * z).sqrt();
    CAPACITANCE * w0 / root * (-z * w0 * time).exp() * (w0 * root * time).sin()
}
```

## Bode 線図と共振のピーク

次のセルは、抵抗 $R$ を選び、$10^2$〜$10^6$ rad/s の対数格子 400 点で `frequency_response` を計算する。
返る値は `[周波数][出力][入力]` の順で、出力は $v_C$、$i$ の順なので、周波数 $k$ の $H$ は添字 $2k$、$Y$ は $2k + 1$ にある。
上の図は振幅 $|H|$ を両対数軸で、下の図は位相 $\arg H$ [°] を描き、どちらも閉形式を破線で重ねる。
二つの図の角周波数の軸は連動する。
表は$\omega_0$ と $\omega_r$ で評価した値を閉形式と比べ、格子全体の相対誤差の最大値も示す。
このセルの $R$ は次のセルにも渡す。

```rust
//| id: signal-rlc-bode
//| ref: signal-rlc-bode
//| title: 直列 RLC 回路の Bode 線図と共振のピーク
//| run: reactive
//| uses: [signal-rlc-model]
//| crates: [scioxide-core, scioxide-linalg, scioxide-signal]
//| exports: [resistance]
//| inputs:
//|   resistance: {"type":"range","label":"抵抗 R [Ω]","description":"減衰比 ζ = R/200 を変える。","min":2,"max":180,"step":2,"value":20}
//| cases:
//|   - {"id":"overdamped-peak","label":"R = 160 Ω","description":"ζ = 0.8 > 1/√2 で共振の山が消える。","inputs":{"resistance":160}}
//|   - {"id":"sharp","label":"R = 2 Ω","description":"ζ = 0.01 で山の高さが約 50 倍になる。","inputs":{"resistance":2}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"resonance","path":"/rows/0/1","approx":{"value":5.0,"rtol":1e-12}}
//|       - {"artifact":"resonance","path":"/rows/0/3","range":{"max":1e-12}}
//|       - {"artifact":"resonance","path":"/rows/2/3","range":{"max":1e-12}}
//|       - {"artifact":"resonance","path":"/rows/3/3","range":{"max":1e-12}}
//|       - {"artifact":"resonance","path":"/rows/4/1","range":{"max":1e-12}}
//|   - case: overdamped-peak
//|     expect:
//|       - {"artifact":"resonance","path":"/rows/3/1","equals":null}
//|   - case: sharp
//|     expect:
//|       - {"artifact":"resonance","path":"/rows/0/1","approx":{"value":50.0,"rtol":1e-10}}
use scioxide_core::Complex;

let sig6 = serde_json::json!({ "significantDigits": 6 });
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let model = rlc_model(resistance).map_err(|e| e.to_string())?;
let (w0, z) = (natural_frequency(), damping_ratio(resistance));
// 閉形式 H(iω) = ω₀² / (ω₀² − ω² + 2iζω₀ω)（参照値）。
let exact = |w: f64| {
    let denominator = Complex::new(w0 * w0 - w * w, 2.0 * z * w0 * w);
    Complex::new(w0 * w0, 0.0) / denominator
};

let omegas: Vec<f64> = (0..400)
    .map(|k| 10.0_f64.powf(2.0 + 4.0 * k as f64 / 399.0))
    .collect();
let response = model
    .frequency_response(&omegas)
    .map_err(|e| e.to_string())?;
let values = response.values();
let grid_error = omegas
    .iter()
    .enumerate()
    .map(|(k, &w)| (values[2 * k] - exact(w)).norm() / exact(w).norm())
    .fold(0.0, f64::max);

// ω₀ と、山がある場合は ω_r = ω₀√(1 − 2ζ²) で評価する。
let peak = (z * z < 0.5).then(|| w0 * (1.0 - 2.0 * z * z).sqrt());
let mut points = vec![w0];
points.extend(peak);
let special = model
    .frequency_response(&points)
    .map_err(|e| e.to_string())?;
let at = special.values();
let relative = |a: f64, b: f64| (a - b).abs() / b.abs();
let peak_value = peak.map(|_| at[2].norm());
let peak_exact = 1.0 / (2.0 * z * (1.0 - z * z).sqrt());
let rows = vec![
    (
        "|H(iω₀)| [V/V]",
        Some(at[0].norm()),
        Some(1.0 / (2.0 * z)),
        Some(relative(at[0].norm(), 0.5 / z)),
    ),
    (
        "arg H(iω₀) [°]",
        Some(at[0].arg().to_degrees()),
        Some(-90.0),
        Some(relative(at[0].arg().to_degrees(), -90.0)),
    ),
    (
        "|Y(iω₀)| [S]",
        Some(at[1].norm()),
        Some(1.0 / resistance),
        Some(relative(at[1].norm(), 1.0 / resistance)),
    ),
    (
        "|H(iω_r)|（山の高さ）[V/V]",
        peak_value,
        peak.map(|_| peak_exact),
        peak_value.map(|v| relative(v, peak_exact)),
    ),
    (
        "格子全体の H の最大相対誤差 [-]",
        Some(grid_error),
        None,
        None,
    ),
];
let columns = serde_json::json!([
    { "key": "0", "label": "量" },
    { "key": "1", "label": "計算値", "type": "number", "format": sig6, "nullText": "山なし" },
    { "key": "2", "label": "閉形式", "type": "number", "format": sig6, "nullText": "—" },
    { "key": "3", "label": "相対差 [-]", "type": "number", "format": sci3, "nullText": "—" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "resonance" })
);

let series = |f: &dyn Fn(Complex<f64>) -> f64| -> (Vec<[f64; 2]>, Vec<[f64; 2]>) {
    let computed = omegas
        .iter()
        .enumerate()
        .map(|(k, &w)| [w, f(values[2 * k])])
        .collect();
    let reference = omegas.iter().map(|&w| [w, f(exact(w))]).collect();
    (computed, reference)
};
let (magnitude, magnitude_exact) = series(&|h| h.norm());
let (phase, phase_exact) = series(&|h| h.arg().to_degrees());
let resonance_line = serde_json::json!([{
    "kind": "line",
    "axis": "x",
    "value": w0,
    "label": "ω₀",
    "style": { "lineType": "dotted" }
}]);
let dashed = serde_json::json!({ "lineType": "dashed", "showSymbol": false });
emit_line_chart!(
    &vec![
        serde_json::json!({ "name": "frequency_response", "points": magnitude }),
        serde_json::json!({ "name": "閉形式", "points": magnitude_exact, "style": dashed }),
    ],
    options = &serde_json::json!({
        "link": { "group": "rlc-omega" },
        "xLabel": "角周波数 ω [rad/s]",
        "yLabel": "振幅 |H| [V/V]",
        "xType": "log",
        "yType": "log",
        "annotations": resonance_line
    })
);
emit_line_chart!(
    &vec![
        serde_json::json!({ "name": "frequency_response", "points": phase }),
        serde_json::json!({ "name": "閉形式", "points": phase_exact, "style": dashed }),
    ],
    options = &serde_json::json!({
        "link": { "group": "rlc-omega" },
        "xLabel": "角周波数 ω [rad/s]",
        "yLabel": "位相 arg H [°]",
        "xType": "log",
        "yMin": -180.0,
        "yMax": 0.0,
        "annotations": resonance_line
    })
);
export!(resistance, resistance);
```

既定の $R = 20$ Ω（$\zeta = 0.1$）では、$|H(i\omega_0)|$ は閉形式の $1/(2\zeta) = 5$ に丸め誤差なく一致し、位相は $-90°$ との相対差 $6.3 \times 10^{-16}$ である。
アドミタンスの大きさ $|Y(i\omega_0)|$ も $1/R = 0.05$ S に一致し、出力の並び（$v_C$、$i$ の順）が確かめられる。
山の高さは $\omega_r \approx$ 9899.5 rad/s で 5.0252 になり、閉形式との相対差は $1.8 \times 10^{-16}$ である。
格子全体の最大相対誤差は $1.3 \times 10^{-15}$ で、Hessenberg 形を使う評価は共振の近くでも丸め誤差の程度にとどまる。
図の振幅は $\omega \ll \omega_0$ で 1、$\omega \gg \omega_0$ で $(\omega_0/\omega)^2$ に沿って傾き $-2$ の直線で減り、位相は $0°$ から $-180°$ へ移る。

ケース「R = 160 Ω」では $\zeta = 0.8 > 1/\sqrt{2}$ となり、山の行は「山なし」になる。
ケース「R = 2 Ω」では $|H(i\omega_0)| = 50$ になり、位相は $\omega_0$ の近くで急に $-180°$ へ移る。
抵抗を小さくするほど共振は鋭くなり、振幅が山の $1/\sqrt{2}$ 以上になる帯域の幅はおよそ $2\zeta\omega_0$ に縮む。

## ステップ応答と離散化の誤差

次のセルは、前のセルの $R$ を受け取り、零状態に 1 V のステップを加えた応答を三つの方法で求める。

1. 連続系の `step_response` を刻み 1 μs の格子で計算する。
   Plan は刻みの零次ホールドの遷移を 1 回だけ作って進めるので、一定の入力に対して標本点の値は丸め誤差を除いて厳密である。
2. 標本化周波数 $f_s$ で零次ホールドの離散化をした離散系の `step_response`。
3. 同じ $f_s$ で Tustin 変換（$\alpha = 1/2$）の離散化をした離散系の `step_response`。

離散系の格子は刻み $1/f_s$ で、離散化の標本周期と一致させる。
表は閉形式との最大誤差を $v_C$ [V] と $i$ [mA] について示し、連続系の格子から読んだ行き過ぎ量とその時刻を閉形式と比べる。
図は $v_C$ の閉形式（破線）に、二つの離散系の標本を重ねる。

```rust
//| id: signal-rlc-step
//| ref: signal-rlc-step
//| title: 直列 RLC 回路のステップ応答と離散化の誤差
//| run: reactive
//| uses: [signal-rlc-model]
//| dependsOn:
//|   bode: signal-rlc-bode
//| crates: [scioxide-core, scioxide-linalg, scioxide-signal]
//| inputs:
//|   sample_rate_khz: {"type":"range","label":"標本化周波数 f_s [kHz]","description":"離散化の標本周期 1/f_s を変える。","min":5,"max":100,"step":5,"value":20}
//| cases:
//|   - {"id":"fast-sampling","label":"f_s = 100 kHz","description":"標本化を速くすると Tustin 変換の誤差が小さくなる。","inputs":{"sample_rate_khz":100}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"step","path":"/rows/0/1","range":{"max":1e-12}}
//|       - {"artifact":"step","path":"/rows/1/1","range":{"max":1e-12}}
//|       - {"artifact":"step","path":"/rows/2/1","range":{"min":1e-3}}
//|       - {"artifact":"overshoot","path":"/rows/0/3","range":{"max":1e-5}}
//|   - case: fast-sampling
//|     expect:
//|       - {"artifact":"step","path":"/rows/1/1","range":{"max":1e-12}}
use scioxide_signal::DiscretizationMethod;

let sig6 = serde_json::json!({ "significantDigits": 6 });
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let resistance = bode["resistance"].as_f64().ok_or("抵抗 R を受け取れない")?;
let model = rlc_model(resistance).map_err(|e| e.to_string())?;
let horizon = 5.0e-3;

// values() は [標本][出力][入力] の順で、出力は v_C, i の順。
let max_errors = |times: &[f64], values: &[f64]| {
    times
        .iter()
        .enumerate()
        .fold((0.0_f64, 0.0_f64), |(ev, ei), (k, &t)| {
            let dv = (values[2 * k] - step_voltage(resistance, t)).abs();
            let di = (values[2 * k + 1] - step_current(resistance, t)).abs() * 1.0e3;
            (ev.max(dv), ei.max(di))
        })
};

let fine_step = 1.0e-6;
let fine: Vec<f64> = (0..=5000).map(|k| k as f64 * fine_step).collect();
let continuous = model.step_response(&fine).map_err(|e| e.to_string())?;
let mut rows = vec![(
    "連続系（刻み 1 μs）",
    max_errors(&fine, continuous.values()),
)];

let h = 1.0e-3 / sample_rate_khz;
let steps = (horizon / h).round() as usize;
let grid: Vec<f64> = (0..=steps).map(|k| k as f64 * h).collect();
let mut chart = Vec::new();
for (name, method) in [
    ("零次ホールド", DiscretizationMethod::ZeroOrderHold),
    (
        "Tustin 変換",
        DiscretizationMethod::GeneralizedBilinear { alpha: 0.5 },
    ),
] {
    let response = model
        .discretize(h, method)
        .and_then(|discrete| discrete.step_response(&grid))
        .map_err(|e| e.to_string())?;
    rows.push((name, max_errors(&grid, response.values())));
    let points: Vec<[f64; 2]> = grid
        .iter()
        .enumerate()
        .map(|(k, &t)| [t * 1.0e3, response.values()[2 * k]])
        .collect();
    chart.push(
        serde_json::json!({ "name": name, "points": points, "style": { "symbol": "circle" } }),
    );
}
let rows: Vec<(&str, f64, f64)> = rows.into_iter().map(|(n, (v, i))| (n, v, i)).collect();
let columns = serde_json::json!([
    { "key": "0", "label": "方法" },
    { "key": "1", "label": "v_C の最大誤差 [V]", "type": "number", "format": sci3 },
    { "key": "2", "label": "i の最大誤差 [mA]", "type": "number", "format": sci3 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "step" })
);

// 行き過ぎ量: 連続系の格子での最大値と、その時刻を閉形式と比べる。
let (peak_index, peak_voltage) =
    continuous
        .values()
        .iter()
        .step_by(2)
        .enumerate()
        .fold(
            (0, f64::MIN),
            |best, (k, &v)| if v > best.1 { (k, v) } else { best },
        );
let (w0, z) = (natural_frequency(), damping_ratio(resistance));
let root = (1.0 - z * z).sqrt();
let overshoot = (-std::f64::consts::PI * z / root).exp();
let peak_time = std::f64::consts::PI / (w0 * root);
let overshoot_columns = serde_json::json!([
    { "key": "0", "label": "行き過ぎ量（格子）[V]", "type": "number", "format": sig6 },
    { "key": "1", "label": "行き過ぎ量（閉形式）[V]", "type": "number", "format": sig6 },
    { "key": "2", "label": "最大の時刻（格子）[ms]", "type": "number", "format": sig6 },
    { "key": "3", "label": "行き過ぎ量の相対差 [-]", "type": "number", "format": sci3 }
]);
emit_table_with_columns!(
    overshoot_columns,
    vec![(
        peak_voltage - 1.0,
        overshoot,
        fine[peak_index] * 1.0e3,
        (peak_voltage - 1.0 - overshoot).abs() / overshoot,
    )],
    metadata = serde_json::json!({ "id": "overshoot" })
);
emit_text!(&format!(
    "閉形式の最大の時刻 t_p = π/ω_d = {:.4} ms",
    peak_time * 1.0e3
));

let reference: Vec<[f64; 2]> = fine
    .iter()
    .step_by(10)
    .map(|&t| [t * 1.0e3, step_voltage(resistance, t)])
    .collect();
chart.push(serde_json::json!({
    "name": "閉形式",
    "points": reference,
    "style": { "lineType": "dashed", "showSymbol": false }
}));
emit_line_chart!(
    &chart,
    options = &serde_json::json!({
        "xLabel": "時刻 t [ms]",
        "yLabel": "コンデンサの電圧 v_C [V]",
        "yMin": 0.0,
        "yMax": 2.0
    })
);
```

既定値（$R = 20$ Ω、$f_s = 20$ kHz）では、刻み 1 μs の連続系の応答は閉形式と $v_C$ で $4.7 \times 10^{-14}$ V、$i$ で $5.7 \times 10^{-13}$ mA の差で一致する。
零次ホールドの離散系も $8.9 \times 10^{-16}$ V の差で、ステップ入力に対して標本点で厳密である。
Tustin 変換の誤差は 0.186 V で、ステップの跳びを標本の間の傾きとして扱う分だけ遅れる（[離散化の誤差と安定性](oxref:signal-lti-discretization-error)）。
行き過ぎ量は格子で 0.729245 V、閉形式で 0.729248 V、相対差は $3.3 \times 10^{-6}$ で、格子の刻み 1 μs による最大の位置のずれの範囲にある。
最大の時刻は格子で 0.316 ms、閉形式で $\pi/\omega_d \approx 0.3157$ ms である。

ケース「f_s = 100 kHz」では Tustin 変換の誤差が 0.042 V に減る。
標本周期を 1/5 にすると誤差は約 1/4.4 になり、ほぼ標本周期に比例する。
零次ホールドは標本化周波数によらず厳密なので、ステップや区間で一定の入力を扱うデジタル制御のシミュレーションでは零次ホールドを選ぶ。
周波数応答の形を保ちたいフィルタの設計では、Tustin 変換と事前ワーピングを選ぶ。

## まとめ

直列 RLC 回路は、状態 $(i, v_C)$ の 2 次の状態空間モデルで表せ、周波数応答と時間応答のどちらも閉形式と丸め誤差の程度で一致する。
`frequency_response` の値は `[周波数][出力][入力]` の順に並ぶので、出力の順を決めてから添字を読む。
共振の山の高さ $1/(2\zeta\sqrt{1 - \zeta^2})$ と行き過ぎ量 $e^{-\pi\zeta/\sqrt{1 - \zeta^2}}$ は、どちらも減衰比 $\zeta = (R/2)\sqrt{C/L}$ で決まる。
離散化では、ステップ入力に対して零次ホールドは厳密で、Tustin 変換は標本周期に比例する誤差を持つ。
状態フィードバックで極を動かす設計は[状態空間モデルと LTI 系の極配置](oxref:signal-pole-placement)、IIR フィルタとしての設計は[IIR フィルタの設計](../../algorithms/iir-design/)で確かめる。
