二つの地震計に同じ地震波が届く時刻の差は、震源の方向や地下の速度構造を推定する基本的な観測量である。
波形が似ていれば、一方の記録をずらしてもう一方に最もよく重なるずれを探せばよく、これは相互相関の最大を探すことに当たる。
この例ではノイズを含む二つの観測点の合成記録から到達時刻差を推定する。
`correlate` のラグの符号の読み方、標本間隔より細かい遅延を求める放物線補間、ノイズによる誤差と大きな外れを、シードを変えた反復で確かめる。

## 合成記録のモデル

標本化周波数は $f_s = 100$ Hz、記録の長さは $N = 512$ 標本（5.12 s）とする。
到来する波は搬送波の周波数 $f_c = 5$ Hz、包絡線の標準偏差 $\sigma_w = 0.08$ s の Gauss 変調余弦

$$
s(t) = e^{-t^2/(2\sigma_w^2)} \cos(2\pi f_c t)
$$

で表し、最大振幅は 1 である。
これは実際の地震波形の再現ではなく、P 波の初動のような短い波束を表す定義上のモデルである。
観測点 A には時刻 $t_A = 1.5$ s、観測点 B には $t_B = t_A + \tau$ に同じ波束が届き、それぞれに独立な白色 Gauss ノイズ（標準偏差 $\sigma$）が加わる。

$$
a[n] = s(n/f_s - t_A) + e_a[n], \qquad b[n] = s(n/f_s - t_B) + e_b[n]
$$

SNR は波束の最大振幅とノイズの標準偏差の比 $1/\sigma$ をデシベルで表した $20 \log_{10}(1/\sigma)$ とする。
波束は `scioxide_signal::waveform` の `Waveform::GaussianPulse` で生成し、ノイズは `scioxide-random` の `Normal` からシードを指定して引く。

## 相互相関と放物線補間

`correlate(b, a)` は $c[\ell] = \sum_k b[k]\, a[k - \ell]$ をラグ $\ell = -(N-1), \dots, N-1$ の昇順に並べ、ラグ 0 は添字 $N - 1$ にある（[相関のラグの並び](oxref:signal-correlation-lags)）。
$b$ が $a$ を $d$ 標本遅らせた波形を含むとき、$c[\ell]$ は $\ell = d$ の近くで最大になる。
したがって、最大の添字 $j^\ast$ からラグ $\ell^\ast = j^\ast - (N-1)$ を求め、$\tau = \ell^\ast / f_s$ とすれば、正の値は B への到達が遅いことを示す。
引数を `correlate(a, b)` と入れ替えると、最大のラグの符号が反転する。

整数のラグの分解能は標本間隔 $1/f_s = 10$ ms である。
最大の点と前後の点 $c_- = c[j^\ast - 1]$、$c_0 = c[j^\ast]$、$c_+ = c[j^\ast + 1]$ を通る放物線の頂点を取ると、標本間隔より細かいずれ

$$
\delta = \frac{c_- - c_+}{2\,(c_- - 2c_0 + c_+)}, \qquad \hat\tau = \frac{\ell^\ast + \delta}{f_s}
$$

が得られる（$\lvert \delta \rvert \le 1/2$）。
相関の頂点の形は放物線ではなく、この例では搬送波の余弦に近いので、ノイズがなくても $\delta$ には小さな偏りが残る。

## 推定誤差の線形化

ノイズが小さいとき、相関の最大の位置のずれを一次まで展開すると、遅延の推定の標準偏差は

$$
\sigma_\tau \approx \sqrt{\frac{2\sigma^2}{\sum_n s'(t_n)^2}}
$$

になる。
$s'$ は波束の時間微分で、$t_n$ は観測点 A の記録の時刻である。
導出では、最大の条件 $c'(\ell) = 0$ を真の遅延の周りで展開し、ノイズと波束の積の項だけを残す。
二つの記録のノイズがそれぞれ分散 $\sigma^2 \sum s'^2$ の項を一つずつ加えるので、分子が $2\sigma^2$ になる。
波束の傾きが急なほど（搬送波の周波数が高いほど）、同じノイズでも遅延は正確に決まる。

この近似が無視したノイズどうしの積 $\sum_k e_b[k]\, e_a[k-\ell]$ は、記録全体の $N$ 標本にわたって和を取るので、分散が $N\sigma^4$ に比例する。
波束とノイズの積の項は $\sigma^2$ に比例するので、SNR が下がるほどノイズどうしの項の割合が増え、誤差は線形化の予測より大きくなる。
さらに SNR が下がると、搬送波の一周期 $1/f_c = 0.2$ s 離れた隣の山や、ノイズどうしの相関の山が最大になり、推定値が大きく外れる。
外れが起こり始めると、誤差の二乗平均平方根は線形化の予測から急に離れる。
到達時刻のおよその見当があるなら、記録をその前後に切り出して相関を取ると、ノイズどうしの項と外れの両方を減らせる。

次のブロックは、二つのセルが共有するモデルの定義である。
`record` は到達時刻とノイズの標準偏差から記録を作り、`estimate` は `correlate(b, a)` の最大のラグと放物線補間した遅延 [s] を返す。
`predicted_sd` は解析的な微分 $s'(t)$ から上の $\sigma_\tau$ を計算する（独立な検算）。

```rust
//| id: signal-seismic-model
//| kind: definitions
//| title: 合成地震記録と相互相関による遅延の推定
//| crates: [scioxide-core, scioxide-random, scioxide-signal]
use scioxide_core::RealScalar;
use scioxide_random::{Distribution, Normal, SplitMix64};
use scioxide_signal::{Waveform, correlate, waveform};

/// 標本化周波数 [Hz]、記録の標本数、観測点 A への到達時刻 [s]
pub(crate) const RATE: f64 = 100.0;
pub(crate) const LENGTH: usize = 512;
pub(crate) const ARRIVAL: f64 = 1.5;
/// 波束の搬送波の周波数 [Hz] と包絡線の標準偏差 [s]
pub(crate) const CARRIER: f64 = 5.0;
pub(crate) const WIDTH: f64 = 0.08;

/// SNR [dB] = 20 log₁₀(1/σ) からノイズの標準偏差 σ を求める
pub(crate) fn noise_sd(snr_db: f64) -> f64 {
    RealScalar::exp(-snr_db / 20.0 * core::f64::consts::LN_10)
}

/// 到達時刻 arrival [s] の波束に標準偏差 noise の白色 Gauss ノイズを加えた記録
pub(crate) fn record(
    arrival: f64,
    noise: f64,
    rng: &mut SplitMix64,
) -> Result<Vec<f64>, String> {
    let pulse = Waveform::GaussianPulse {
        frequency: CARRIER,
        phase: 0.0,
        sigma: WIDTH,
    };
    let times: Vec<f64> = (0..LENGTH).map(|n| n as f64 / RATE - arrival).collect();
    let clean = waveform(pulse, &times).map_err(|e| e.to_string())?;
    let normal = Normal::new(0.0, noise).map_err(|e| e.to_string())?;
    clean
        .iter()
        .map(|s| Ok(s + normal.sample(rng).map_err(|e| e.to_string())?))
        .collect()
}

/// correlate(b, a) の最大のラグ ℓ* [標本] と、放物線補間した遅延 [s]
pub(crate) fn estimate(a: &[f64], b: &[f64]) -> Result<(i64, f64), String> {
    let c = correlate(b, a).map_err(|e| e.to_string())?;
    // 前後の点が要るので、両端を除いて最大を探す
    let j = (1..c.len() - 1).fold(1, |best, j| if c[j] > c[best] { j } else { best });
    let lag = j as i64 - (a.len() as i64 - 1);
    let (left, mid, right) = (c[j - 1], c[j], c[j + 1]);
    let shift = 0.5 * (left - right) / (left - 2.0 * mid + right);
    Ok((lag, (lag as f64 + shift) / RATE))
}

/// 線形化した遅延の標準偏差 [s]: √(2σ² / Σ s'(tₙ)²)。s' は解析的な微分
pub(crate) fn predicted_sd(noise: f64) -> f64 {
    let omega = core::f64::consts::TAU * CARRIER;
    let slope: f64 = (0..LENGTH)
        .map(|n| {
            let t = n as f64 / RATE - ARRIVAL;
            let envelope = RealScalar::exp(-0.5 * (t / WIDTH) * (t / WIDTH));
            let carrier = RealScalar::cos(omega * t);
            let derivative = -envelope
                * (t / (WIDTH * WIDTH) * carrier + omega * RealScalar::sin(omega * t));
            derivative * derivative
        })
        .sum();
    RealScalar::sqrt(2.0 * noise * noise / slope)
}
```

## 一組の記録での推定

次のセルは真の遅延 $\tau$、SNR、乱数のシードを入力として二つの記録を作り、`correlate(b, a)` から遅延を推定する。
上の二つの図は観測点 A と B の記録で、横軸の時刻を連動させてある。
三つ目の図は相関をラグ [s] に対して描き、真の遅延を縦線で示す。
表は整数のラグによる遅延、放物線補間した遅延、真の値との誤差、線形化した標準偏差、引数を入れ替えた `correlate(a, b)` の最大のラグを並べる。

```rust
//| id: signal-seismic-single-record
//| ref: signal-seismic-single-record
//| title: 二つの観測点の記録から到達時刻差を推定する
//| run: reactive
//| uses: [signal-seismic-model]
//| inputs:
//|   delay: {"type":"range","label":"真の遅延 τ [s]","description":"観測点 B への到達が A より遅れる時間。","min":0.5,"max":2.5,"step":0.001,"value":1.234}
//|   snr_db: {"type":"range","label":"SNR [dB]","description":"波束の最大振幅とノイズの標準偏差の比。","min":-5,"max":40,"step":1,"value":20}
//|   seed: {"type":"range","label":"乱数のシード [-]","description":"二つの記録のノイズを決める。","min":1,"max":200,"step":1,"value":100}
//| cases:
//|   - {"id":"noisy","label":"SNR = 0 dB","description":"ノイズが波束と同じ大きさになり、誤差が線形化の予測を超えることがある。","inputs":{"snr_db":0}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"estimate","path":"/rows/0/1","equals":123}
//|       - {"artifact":"estimate","path":"/rows/0/3","approx":{"value":1.234,"atol":0.003}}
//|       - {"artifact":"estimate","path":"/rows/0/6","equals":-123}
use scioxide_random::{SeedableRng, SplitMix64};
use scioxide_signal::correlate;

let noise = noise_sd(snr_db);
let mut rng = SplitMix64::from_seed(seed.round() as u64);
let a = record(ARRIVAL, noise, &mut rng)?;
let b = record(ARRIVAL + delay, noise, &mut rng)?;
let (lag, estimated) = estimate(&a, &b)?;
// 引数を入れ替えると最大のラグの符号が反転する
let swapped = correlate(&a, &b).map_err(|e| e.to_string())?;
let swapped_peak =
    (0..swapped.len()).fold(
        0,
        |best, j| if swapped[j] > swapped[best] { j } else { best },
    );
let swapped_lag = swapped_peak as i64 - (b.len() as i64 - 1);

let fixed4 = serde_json::json!({ "fractionDigits": 4 });
let fixed2 = serde_json::json!({ "fractionDigits": 2 });
let columns = serde_json::json!([
    { "key": "0", "label": "真の遅延 τ [s]", "type": "number", "format": fixed4 },
    { "key": "1", "label": "最大のラグ ℓ* [標本]", "type": "integer" },
    { "key": "2", "label": "ℓ*/f_s [s]", "type": "number", "format": fixed4 },
    { "key": "3", "label": "放物線補間 τ̂ [s]", "type": "number", "format": fixed4 },
    { "key": "4", "label": "誤差 τ̂ − τ [ms]", "type": "number", "format": fixed2 },
    { "key": "5", "label": "線形化した σ_τ [ms]", "type": "number", "format": fixed2 },
    { "key": "6", "label": "correlate(a, b) のラグ [標本]", "type": "integer" }
]);
let row = (
    delay,
    lag,
    lag as f64 / RATE,
    estimated,
    1000.0 * (estimated - delay),
    1000.0 * predicted_sd(noise),
    swapped_lag,
);
emit_table_with_columns!(
    columns,
    vec![row],
    metadata = serde_json::json!({ "id": "estimate" })
);

let trace = |x: &[f64]| {
    x.iter()
        .enumerate()
        .map(|(n, &v)| [n as f64 / RATE, v])
        .collect::<Vec<_>>()
};
for (name, values) in [("観測点 A の記録 a[n]", &a), ("観測点 B の記録 b[n]", &b)] {
    emit_line_chart!(
        &vec![serde_json::json!({ "name": name, "points": trace(values) })],
        options = &serde_json::json!({
            "link": { "group": "seismic-time" },
            "xLabel": "時刻 t [s]",
            "yLabel": "振幅 [-]",
            "xMin": 0.0,
            "xMax": LENGTH as f64 / RATE
        })
    );
}
let c = correlate(&b, &a).map_err(|e| e.to_string())?;
let lags: Vec<[f64; 2]> = c
    .iter()
    .enumerate()
    .map(|(j, &v)| [(j as f64 - (LENGTH as f64 - 1.0)) / RATE, v])
    .collect();
emit_line_chart!(
    &vec![serde_json::json!({ "name": "c[ℓ] = correlate(b, a)", "points": lags })],
    options = &serde_json::json!({
        "xLabel": "ラグ ℓ/f_s [s]",
        "yLabel": "相関 [-]",
        "annotations": [{ "kind": "line", "axis": "x", "value": delay, "label": "真の遅延 τ" }]
    })
);
```

既定の $\tau = 1.234$ s、SNR 20 dB、シード 100 では、相関の最大はラグ 123 標本（1.23 s）にあり、放物線補間で $\hat\tau = 1.2329$ s が得られる。
誤差は $-1.06$ ms で、線形化した標準偏差 $\sigma_\tau = 1.63$ ms の範囲にある。
引数を入れ替えた `correlate(a, b)` の最大はラグ $-123$ で、符号だけが反転する。
SNR を 40 dB にすると $\sigma_\tau$ は 0.16 ms に下がり、誤差は $-0.12$ ms になる。
SNR を 0 dB に下げると、波束はノイズに埋もれ、最大のラグは $-11$ 標本に移って誤差は $-1343$ ms になる。
これは線形化した $\sigma_\tau = 16$ ms とは桁の違う外れで、相関の山の高さを比べるだけでは正しい山かどうかを判定できないことを示す。

## SNR と推定誤差

一組の記録の誤差は乱数で変わるので、誤差の大きさはシードを変えた反復で評価する。
次のセルは SNR を 0 dB から 40 dB までの 8 段階に変え、各段階で $R$ 組の記録を独立に生成して遅延を推定する。
真の遅延は $\tau = 1.234$ s（123.4 標本、端数 0.4 標本）に固定する。
各段階の誤差 $e_i = \hat\tau_i - \tau$ から、二乗平均平方根 $\mathrm{RMS} = \sqrt{\overline{e^2}}$、その標準誤差 $\mathrm{SE}(\overline{e^2}) / (2\,\mathrm{RMS})$、平均の偏り、$\lvert e_i \rvert > 0.1$ s（搬送波の半周期）となった外れの回数を求める。
図は RMS と線形化の予測 $\sigma_\tau$ の比を ±2 SE のエラーバーで描き、比 1 を縦軸の基準線で示す。
$R$ 組の生成と相関の計算は SNR ごとに繰り返すので、ボタンで実行する。

```rust
//| id: signal-seismic-snr-sweep
//| ref: signal-seismic-snr-sweep
//| title: 遅延の推定誤差を SNR に対して線形化の予測と比べる
//| run: button
//| uses: [signal-seismic-model]
//| inputs:
//|   trials: {"type":"range","label":"反復の数 R [-]","description":"各 SNR で生成する記録の組の数。","min":50,"max":200,"step":50,"value":100}
//|   seed: {"type":"range","label":"乱数のシード [-]","description":"反復全体のノイズの列を決める。","min":1,"max":100,"step":1,"value":11}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"sweep","path":"/rows/0/5","range":{"min":50}}
//|       - {"artifact":"sweep","path":"/rows/7/1","range":{"min":0.12,"max":0.21}}
//|       - {"artifact":"sweep","path":"/rows/7/5","equals":0}
use scioxide_random::{SeedableRng, SplitMix64};

let delay = 1.234;
let runs = trials.round() as usize;
let mut rng = SplitMix64::from_seed(seed.round() as u64);
let mut rows = Vec::new();
let mut bars = Vec::new();
for snr_db in [0.0_f64, 5.0, 10.0, 15.0, 20.0, 25.0, 30.0, 40.0] {
    let noise = noise_sd(snr_db);
    let mut errors = Vec::with_capacity(runs);
    for _ in 0..runs {
        let a = record(ARRIVAL, noise, &mut rng)?;
        let b = record(ARRIVAL + delay, noise, &mut rng)?;
        errors.push(estimate(&a, &b)?.1 - delay);
    }
    let count = runs as f64;
    let mean_square = errors.iter().map(|e| e * e).sum::<f64>() / count;
    let spread = errors
        .iter()
        .map(|e| (e * e - mean_square).powi(2))
        .sum::<f64>()
        / (count - 1.0);
    let rms = mean_square.sqrt();
    // RMS の標準誤差: SE(平均二乗) / (2 RMS)（デルタ法）
    let rms_se = (spread / count).sqrt() / (2.0 * rms);
    let bias = errors.iter().sum::<f64>() / count;
    let skips = errors.iter().filter(|e| e.abs() > 0.1).count();
    let predicted = predicted_sd(noise);
    rows.push((
        snr_db,
        1000.0 * rms,
        1000.0 * rms_se,
        1000.0 * predicted,
        1000.0 * bias,
        skips,
    ));
    let ratio = rms / predicted;
    let half = 2.0 * rms_se / predicted;
    bars.push([snr_db, ratio, ratio - half, ratio + half]);
}
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let columns = serde_json::json!([
    { "key": "0", "label": "SNR [dB]", "type": "number" },
    { "key": "1", "label": "RMS 誤差 [ms]", "type": "number", "format": sci3 },
    { "key": "2", "label": "RMS の SE [ms]", "type": "number", "format": sci3 },
    { "key": "3", "label": "線形化した σ_τ [ms]", "type": "number", "format": sci3 },
    { "key": "4", "label": "平均の偏り [ms]", "type": "number", "format": sci3 },
    { "key": "5", "label": "外れ |e| > 0.1 s [回]", "type": "integer" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "sweep" })
);
emit_chart!(serde_json::json!({
    "kind": "errorbar",
    "xLabel": "SNR [dB]",
    "yLabel": "RMS 誤差 / 線形化した σ_τ [-]",
    "yType": "log",
    "series": [{ "name": "比 ±2 SE", "points": bars }],
    "annotations": [{
        "kind": "line",
        "axis": "y",
        "value": 1.0,
        "label": "線形化の予測",
        "style": { "lineType": "dashed" }
    }]
}));
```

既定の $R = 100$、シード 11 では、40 dB の RMS 誤差は $0.173 \pm 0.011$ ms（±1 SE）で、線形化した $\sigma_\tau = 0.163$ ms と 1 SE の範囲で一致する。
SNR を下げると、RMS 誤差と予測の比は 30 dB で 1.13、25 dB で 1.36、20 dB で 1.80、15 dB で 2.17 と 1 から離れていき、ノイズどうしの積の項の寄与が大きくなることが分かる。
15 dB 以上では外れは一度も起こらず、平均の偏りは 30 dB と 40 dB で絶対値 0.05 ms 以下と RMS より小さい。
10 dB では 100 組のうち 19 組が外れて RMS 誤差は 473 ms に跳ね上がり、5 dB で 85 組、0 dB で 95 組が外れる。
図の比は 15 dB と 10 dB の間で 2 程度から 90 程度へ跳び、線形化が成り立つ範囲の下限がこの間にあることを示す。
$R = 200$ にすると SE はおよそ $1/\sqrt 2$ 倍に縮み、15 dB 以上の各段階の比は SE の 2 倍の範囲で変わらない。

## まとめ

`correlate(b, a)` の最大の添字から $N - 1$ を引いたラグが正なら、B への到達が A より遅い。
放物線補間は標本間隔 10 ms より細かい遅延を与え、この例では 40 dB で 0.17 ms の RMS 誤差に達する。
SNR が高い範囲では誤差を線形化した $\sigma_\tau = \sqrt{2\sigma^2/\sum s'^2}$ で見積もれるが、SNR が下がるとノイズどうしの積の項で予測より大きくなる。
SNR がさらに下がると、隣の山やノイズの山を選ぶ外れが起こって誤差が桁違いに増える。
推定値の信頼性は反復による誤差の分布で確かめ、必要なら到達時刻の前後に記録を切り出して相関を取る。

相関のラグの定義と符号、`correlate` が直接和と FFT のどちらで計算するかは[畳み込みと相関](../../algorithms/convolution-and-correlation/)で確かめられる。
波束のような帯域の限られた信号の包絡線を求める方法は[Hilbert 変換による解析信号生成と瞬時包絡線復元](../hilbert-envelope/)にある。
