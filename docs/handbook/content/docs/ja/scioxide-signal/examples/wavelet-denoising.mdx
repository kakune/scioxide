計測した波形からノイズを除くとき、移動平均や低域通過フィルタはノイズと一緒に段差や尖りも丸めてしまう。
滑らかな部分と急な変化が混ざった信号では、ノイズの帯域と信号の帯域が重なるからである。
ウェーブレット変換では、滑らかな部分は少数の大きな係数に、白色雑音はすべての係数に薄く広がる。
小さい係数を 0 に寄せて合成し直せば、段差を残したままノイズを減らせる。
この例では Donoho と Johnstone の縮小（ウェーブレット収縮）を `WaveletPlan` で組み立て、ノイズのない信号との誤差で効果を測る。

## 試験信号とノイズ

時間 $t \in [0, 1)$ s を $N = 1024$ 点（標本化周波数 1024 Hz）で標本化し、次の 2 つの試験信号を使う。
振幅は無次元とする。
どちらも Donoho と Johnstone が使った形にならったこのページの定義で、出典の値との一致は主張しない。

- HeaviSine: $f(t) = 4\sin(4\pi t) - \mathrm{sgn}(t - 0.3) - \mathrm{sgn}(0.72 - t)$。
  滑らかな正弦波に、$t = 0.3$ と $t = 0.72$ の 2 つの跳び（高さ 2）がある。
- Blocks: $f(t) = \sum_{j=1}^{11} h_j\,K(t - t_j)$、$K(u) = (1 + \mathrm{sgn}\,u)/2$。
  跳びの位置は $t_j = 0.10, 0.13, 0.15, 0.23, 0.25, 0.40, 0.44, 0.65, 0.76, 0.78, 0.81$、高さは $h_j = 4, -5, 3, -4, 5, -4.2, 2.1, 4.3, -3.1, 2.1, -4.2$ で、区分的に一定な信号になる。

どちらも $f(0) = 0$ で、$t \to 1$ の値も 0 なので、周期的な境界で端に跳びが生じない。
観測は $y_i = f(t_i) + \sigma\varepsilon_i$ で、$\varepsilon_i$ は独立な標準正規乱数とする。

## 直交変換とノイズの係数

正規直交のウェーブレット変換 $W$ は直交行列なので、白色雑音 $\sigma\varepsilon$ の係数 $W\sigma\varepsilon$ も、分散 $\sigma^2$ の独立な正規乱数になる。
これが成り立つのは、直交系（`Haar`、`Daubechies`）を周期的な境界で $N$ が 2 のべき乗の記録に使うときである。
双直交系では変換が直交でないので、ノイズの係数の分散は段ごとに変わり、独立でもない。

最も細かい段のディテール係数は、信号の滑らかな部分ではほとんど 0 で、主にノイズからなる。
そこで、その絶対値の中央値（MAD、median absolute deviation）から

$$
\hat\sigma = \frac{\operatorname{median}\lvert d^{(1)}_j \rvert}{\Phi^{-1}(3/4)},
\qquad \Phi^{-1}(3/4) \approx 0.6745
$$

でノイズの標準偏差を推定する（$\Phi$ は標準正規分布の分布関数）。
中央値を使うので、段差の位置にある少数の大きな係数の影響を受けにくい。

## 普遍閾値と縮小

$N$ 個の独立な $N(0, \sigma^2)$ の最大絶対値が $\sigma\sqrt{2\ln N}$ を超えない確率は、$N \to \infty$ で 1 に近づく。
この値を普遍閾値 $\lambda = \hat\sigma\sqrt{2\ln N}$ とし、ディテール係数 $d$ を

$$
\eta_{\mathrm{soft}}(d) = \mathrm{sgn}(d)\,\max(\lvert d \rvert - \lambda, 0),
\qquad
\eta_{\mathrm{hard}}(d) = d\,[\,\lvert d \rvert > \lambda\,]
$$

で縮小する（軟閾値と硬閾値）。
軟閾値は残す係数も $\lambda$ だけ小さくするので、推定は滑らかになるが振幅が縮む。
硬閾値は残す係数をそのまま使うので振幅を保つが、閾値の近くの係数が残るか消えるかで推定が不連続に変わる。
$N = 1024$ では $\sqrt{2\ln N} \approx 3.72$ である。
最終の近似の係数は縮小しない。

閾値を $c\lambda$ と書き、倍率 $c$ を操作入力にする。
$c = 0$ では縮小が何もしないので、合成は観測 $y$ をそのまま再現する。
係数を削らない往復の誤差は、変換の完全再構成の検算になる。

次のブロックは、このページの 2 つのセルが共有する定義である。
`test_signal` は上の 2 つの試験信号、`noisy_record` はシードを指定した正規乱数による観測、`denoise` は周期的な境界の 5 段の分解、MAD による $\hat\sigma$、閾値による縮小、合成をまとめた関数である。
`denoise` は縮小の前に、係数を削らない往復の誤差も測る。

```rust
//| id: signal-wavelet-denoising-model
//| kind: definitions
//| title: 試験信号とウェーブレット係数の縮小
//| crates: [scioxide-core, scioxide-random, scioxide-signal]
use scioxide_random::{Distribution, Normal, SeedableRng, SplitMix64};
use scioxide_signal::{WaveletFamily, WaveletOptions, WaveletPlan};

/// 標本の数 N（2 のべき乗）と分解の段数。
pub(crate) const SAMPLES: usize = 1024;
pub(crate) const LEVELS: usize = 5;

/// 試験信号 f(t)、t ∈ [0, 1)。
pub(crate) fn test_signal(name: &str, t: f64) -> f64 {
    let sign = |x: f64| {
        if x > 0.0 {
            1.0
        } else if x < 0.0 {
            -1.0
        } else {
            0.0
        }
    };
    if name == "HeaviSine" {
        // 参照値の生成なので f64 の固有メソッドを使う。
        4.0 * (4.0 * std::f64::consts::PI * t).sin() - sign(t - 0.3) - sign(0.72 - t)
    } else {
        const POSITIONS: [f64; 11] = [
            0.1, 0.13, 0.15, 0.23, 0.25, 0.4, 0.44, 0.65, 0.76, 0.78, 0.81,
        ];
        const HEIGHTS: [f64; 11] = [4.0, -5.0, 3.0, -4.0, 5.0, -4.2, 2.1, 4.3, -3.1, 2.1, -4.2];
        POSITIONS
            .iter()
            .zip(HEIGHTS)
            .map(|(&position, height)| height * (1.0 + sign(t - position)) / 2.0)
            .sum()
    }
}

/// 族の名前から WaveletFamily を選ぶ。
pub(crate) fn family(name: &str) -> WaveletFamily {
    match name {
        "Haar" => WaveletFamily::Haar,
        "Daubechies(4)" => WaveletFamily::Daubechies(4),
        "Daubechies(8)" => WaveletFamily::Daubechies(8),
        _ => WaveletFamily::BiorthogonalSpline(303),
    }
}

/// 観測 y_i = f(t_i) + σ ε_i。ε_i はシード seed の標準正規乱数。
pub(crate) fn noisy_record(clean: &[f64], sigma: f64, seed: u64) -> Result<Vec<f64>, String> {
    let mut rng = SplitMix64::from_seed(seed);
    let noise = Normal::new(0.0, sigma).map_err(|e| e.to_string())?;
    clean
        .iter()
        .map(|&f| Ok(f + noise.sample(&mut rng).map_err(|e| e.to_string())?))
        .collect()
}

/// 縮小の結果と診断。
pub(crate) struct Denoised {
    pub(crate) estimate: Vec<f64>,
    pub(crate) finest: Vec<f64>,
    pub(crate) sigma_hat: f64,
    pub(crate) threshold: f64,
    pub(crate) kept: usize,
    pub(crate) details: usize,
    pub(crate) round_trip: f64,
}

/// 5 段の分解、MAD による σ̂、閾値 factor·σ̂√(2 ln N) の縮小、合成。
pub(crate) fn denoise(
    family: WaveletFamily,
    noisy: &[f64],
    factor: f64,
    hard: bool,
) -> Result<Denoised, String> {
    let options = WaveletOptions::new();
    let plan =
        WaveletPlan::<f64>::new(family, noisy.len(), LEVELS, options).map_err(|e| e.to_string())?;
    let mut coefficients = plan.analyze(noisy).map_err(|e| e.to_string())?;
    // 閾値 0 の往復: 係数を削らずに合成し、観測との差の最大を測る。
    let restored = plan.synthesize(&coefficients).map_err(|e| e.to_string())?;
    let round_trip = restored
        .iter()
        .zip(noisy)
        .fold(0.0_f64, |acc, (a, b)| acc.max((a - b).abs()));
    // levels() の先頭が最も細かい段。その詳細の絶対値の中央値から σ を推定する。
    let level = plan.levels()[0];
    let start = level.detail_offset();
    let finest = coefficients[start..start + level.band_len()].to_vec();
    let mut magnitudes: Vec<f64> = finest.iter().map(|d| d.abs()).collect();
    magnitudes.sort_by(f64::total_cmp);
    let m = magnitudes.len();
    let median = if m % 2 == 1 {
        magnitudes[m / 2]
    } else {
        0.5 * (magnitudes[m / 2 - 1] + magnitudes[m / 2])
    };
    // Φ⁻¹(3/4) で割ると、正規分布の標準偏差の一致推定量になる。
    let sigma_hat = median / 0.674_489_750_196_081_7;
    let threshold = factor * sigma_hat * (2.0 * (noisy.len() as f64).ln()).sqrt();
    // 最終の近似（先頭）は残し、詳細だけを縮小する。
    let approximation = plan.approximation_len();
    let mut kept = 0;
    for d in &mut coefficients[approximation..] {
        let shrunk = if d.abs() <= threshold {
            0.0
        } else if hard {
            *d
        } else {
            d.signum() * (d.abs() - threshold)
        };
        kept += usize::from(shrunk != 0.0);
        *d = shrunk;
    }
    let estimate = plan.synthesize(&coefficients).map_err(|e| e.to_string())?;
    Ok(Denoised {
        estimate,
        finest,
        sigma_hat,
        threshold,
        kept,
        details: coefficients.len() - approximation,
        round_trip,
    })
}
```

## 1 回の観測のノイズ除去

次のセルは選んだ試験信号に $\sigma$ のノイズを加えて縮小し、ノイズのない信号 $f$ と比べる。
入力は試験信号、ノイズの標準偏差 $\sigma$、乱数のシード、族、閾値の倍率 $c$、閾値の種類である。
誤差は二乗平均平方根誤差（RMSE）$\sqrt{\frac1N\sum_i(\hat f_i - f_i)^2}$ と、信号対雑音比 $\mathrm{SNR} = 10\log_{10}\left(\sum_i f_i^2 / \sum_i (\hat f_i - f_i)^2\right)$ [dB] で測る。
上の図は観測（点）、ノイズのない信号（破線）、推定（実線）を、下の図は最も細かい段のディテール係数と閾値 $\pm c\lambda$ を、同じ時間軸で示す。
ディテール係数 $d^{(1)}_j$ は時刻 $t = 2j/N$ の位置に描く。

既定の HeaviSine、$\sigma = 0.5$、シード 11、`Daubechies(8)`、軟閾値、$c = 1$ では、MAD による推定は $\hat\sigma = 0.4618$ で、閾値は $\lambda = 1.720$ になる。
992 個のディテール係数のうち残るのは 5 個だけで、残りは 0 になる。
推定の RMSE は観測の $0.4929$ から $0.1651$ に下がり、SNR は $15.93$ dB から $25.43$ dB に上がる。
係数を削らない往復の誤差は $6.2\times10^{-15}$ で、ノイズ除去の効果は縮小だけから生じている。
下の図では、最も細かい段の 512 個のディテール係数のうち、$\pm\lambda$ の帯の外に出るのは $t \approx 0.13$ の 1 個だけで、残る 5 個の係数のほかの 4 個はより粗い段にある。
この 1 個は信号の特徴のない位置にあり、ノイズが閾値を超えたものである。
普遍閾値は、ノイズだけの係数がすべて閾値の内側に入る確率が $N \to \infty$ で 1 に近づくように選んだ値で、有限の $N$ では少数の超過が起こる。

$c = 0$ では縮小が何もせず、992 個の係数がすべて残り、推定の RMSE は観測と同じ $0.4929$ になる。
$c = 1.5$ では残る係数が 1 個に減り、RMSE は $0.1811$ に増える。
閾値を上げすぎると、ノイズと一緒に信号の細部も消える。
硬閾値にすると、同じ 5 個の係数を縮めずに残すので、RMSE は $0.1515$、SNR は $26.18$ dB になる。
$\sigma = 2$ では観測の RMSE $1.972$ が $0.3751$ まで下がり、SNR は $14.4$ dB 改善する。

Blocks を同じ `Daubechies(8)` と軟閾値で処理すると、RMSE は $0.4929$ から $0.4601$ にしか下がらない。
区分的に一定な信号の跳びは、長いフィルタでは多くの係数に分かれ、軟閾値がそのすべてを $\lambda$ だけ縮めるからである。
`Haar` と硬閾値にすると、跳びが少数の大きな係数に集まり、そのまま残るので、RMSE は $0.2187$、SNR は $13.98$ dB から $21.04$ dB に上がる。
`BiorthogonalSpline(303)` では $\hat\sigma = 0.3587$ と、真の $0.5$ より小さく推定される。
双直交系の解析の高域フィルタはノルムが 1 でなく、最も細かい段のノイズの係数の標準偏差が $\sigma$ にならないからである。

## 族による違い

1 回の観測の結果は乱数に左右されるので、族の違いは多くのシードで平均して比べる。
次のセルは選んだ試験信号と $\sigma$ について、シード $s_0, s_0 + 1, \dots, s_0 + R - 1$ の $R$ 回の観測を作り、4 つの族と 2 種類の閾値（$c = 1$）の 8 通りで縮小する。
表は方法ごとに、推定の RMSE の平均と標準誤差（標本標準偏差 $/\sqrt{R}$）、$\hat\sigma$ の平均、SNR の改善量の平均を示す。
8 通りの方法は同じシードの観測を共有するので、方法の間の差は観測ごとのノイズの違いを含まない。
最後の列は、各観測で RMSE が最小になった方法の回数である。

```rust
//| id: signal-wavelet-denoising-families
//| ref: signal-wavelet-denoising-families
//| title: 4 つの族と 2 種類の閾値の縮小を多数の観測で比べる
//| run: reactive
//| uses: [signal-wavelet-denoising-model]
//| crates: [scioxide-core, scioxide-random, scioxide-signal]
//| inputs:
//|   signal_name: {"type":"select","label":"試験信号","options":["HeaviSine","Blocks"],"value":"Blocks"}
//|   sigma: {"type":"range","label":"ノイズの標準偏差 σ [-]","min":0.1,"max":2,"step":0.1,"value":0.5}
//|   repetitions: {"type":"range","label":"観測の数 R [-]","min":10,"max":40,"step":10,"value":20}
//|   first_seed: {"type":"range","label":"最初のシード s₀","min":1,"max":100,"step":1,"value":1}
//| cases:
//|   - {"id":"heavisine","label":"HeaviSine","description":"滑らかな部分が多い信号では、Daubechies の RMSE が Haar のおよそ半分になる。","inputs":{"signal_name":"HeaviSine"}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"families","path":"/rows/1/1","equals":"硬閾値"}
//|       - {"artifact":"families","path":"/rows/1/2","range":{"max":0.25}}
//|   - case: heavisine
//|     expect:
//|       - {"artifact":"families","path":"/rows/2/2","range":{"max":0.2}}
let names = [
    "Haar",
    "Daubechies(4)",
    "Daubechies(8)",
    "BiorthogonalSpline(303)",
];
let clean: Vec<f64> = (0..SAMPLES)
    .map(|i| test_signal(&signal_name, i as f64 / SAMPLES as f64))
    .collect();
let count = repetitions.round() as usize;
let rmse = |values: &[f64]| {
    let sum: f64 = values
        .iter()
        .zip(&clean)
        .map(|(v, f)| (v - f).powi(2))
        .sum();
    (sum / SAMPLES as f64).sqrt()
};
// 8 通りの方法: 族ごとに軟閾値（hard = false）と硬閾値（hard = true）。
let methods: Vec<(&str, bool)> = names
    .iter()
    .flat_map(|&name| [(name, false), (name, true)])
    .collect();
// errors[方法][観測]、gains[方法][観測]（SNR の改善量 [dB]）、sigmas[方法][観測]。
let mut errors = vec![Vec::with_capacity(count); methods.len()];
let mut gains = vec![Vec::with_capacity(count); methods.len()];
let mut sigmas = vec![Vec::with_capacity(count); methods.len()];
let mut wins = vec![0_usize; methods.len()];
for r in 0..count {
    let noisy = noisy_record(&clean, sigma, first_seed as u64 + r as u64)?;
    let noisy_rmse = rmse(&noisy);
    let mut best = (0, f64::INFINITY);
    for (k, &(name, hard)) in methods.iter().enumerate() {
        let result = denoise(family(name), &noisy, 1.0, hard)?;
        let error = rmse(&result.estimate);
        errors[k].push(error);
        gains[k].push(20.0 * (noisy_rmse / error).log10());
        sigmas[k].push(result.sigma_hat);
        if error < best.1 {
            best = (k, error);
        }
    }
    wins[best.0] += 1;
}
let mean = |values: &[f64]| values.iter().sum::<f64>() / values.len() as f64;
let standard_error = |values: &[f64]| {
    let m = mean(values);
    let variance = values.iter().map(|v| (v - m).powi(2)).sum::<f64>() / (values.len() - 1) as f64;
    (variance / values.len() as f64).sqrt()
};
let rows: Vec<_> = methods
    .iter()
    .enumerate()
    .map(|(k, &(name, hard))| {
        (
            name.to_string(),
            if hard { "硬閾値" } else { "軟閾値" }.to_string(),
            mean(&errors[k]),
            standard_error(&errors[k]),
            mean(&sigmas[k]),
            mean(&gains[k]),
            wins[k],
        )
    })
    .collect();
let fixed4 = serde_json::json!({ "significantDigits": 4 });
let fixed2 = serde_json::json!({ "fractionDigits": 2 });
let columns = serde_json::json!([
    { "key": "0", "label": "族" },
    { "key": "1", "label": "閾値" },
    { "key": "2", "label": "RMSE の平均 [-]", "type": "number", "format": fixed4 },
    { "key": "3", "label": "RMSE の標準誤差 [-]", "type": "number", "format": fixed4 },
    { "key": "4", "label": "σ̂ の平均 [-]", "type": "number", "format": fixed4 },
    { "key": "5", "label": "SNR の改善量の平均 [dB]", "type": "number", "format": fixed2 },
    { "key": "6", "label": "RMSE が最小の回数 [回]", "type": "integer" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "families" })
);
```

既定の Blocks、$\sigma = 0.5$、$R = 20$、$s_0 = 1$ では、`Haar` と硬閾値の RMSE が $0.2134 \pm 0.0041$（平均 ± 標準誤差）で最も小さく、20 回の観測のすべてで最小になる。
同じ `Haar` の軟閾値は $0.3696$、`Daubechies(4)` と `Daubechies(8)` の硬閾値は $0.2888$ と $0.3266$ で、差は標準誤差の 15 倍以上ある。
軟閾値の `Daubechies(8)` は $0.4533$ で、観測の RMSE（約 0.49）からほとんど下がらない。
`BiorthogonalSpline(303)` の $\hat\sigma$ の平均は $0.4066$ で、直交系の $0.50$〜$0.52$ に比べて約 2 割小さい。
閾値も同じ割合で小さくなるので、この族の結果は普遍閾値の前提から外れた縮小の結果として解釈する。

HeaviSine では順位が入れ替わり、`Daubechies(4)` の硬閾値が $0.1497 \pm 0.0035$ で最も小さく、20 回のうち 14 回で最小になる。
`Daubechies(8)` の硬閾値は $0.1627$、軟閾値の `Daubechies(4)` と `Daubechies(8)` は $0.1654$ と $0.1732$ で、`Haar` は軟閾値で $0.3216$、硬閾値で $0.2727$ にとどまる。
滑らかな正弦波は、消失モーメントを持つ Daubechies のディテール係数ではほとんど 0 になるが、Haar では階段で近似するので多くの係数が残るからである。
$\sigma = 0.1$ の Blocks では、軟閾値の `Daubechies(4)` と `Daubechies(8)` の SNR の改善量が負になり、縮小がかえって誤差を増やす。
ノイズが小さいと、軟閾値が信号の係数を縮める偏りが、除いたノイズより大きくなるからである。

## まとめ

直交ウェーブレットと周期的な境界では、白色雑音の係数は同じ分散の独立な正規乱数になるので、最も細かい段のディテール係数の MAD からノイズの大きさを推定でき、普遍閾値で縮小できる。
縮小しないとき（$c = 0$）の往復の誤差は丸め誤差の水準で、ノイズ除去の効果は縮小だけから生じることを確かめられる。
推定の誤差は信号の形と族と閾値の組み合わせで決まり、区分的に一定な信号には Haar、滑らかな部分が多い信号には消失モーメントを持つ Daubechies が向く。
双直交系ではノイズの係数の分散が $\sigma^2$ にならないので、MAD による $\sigma$ の推定と普遍閾値が仮定する条件が成り立たない。
軟閾値は振幅を縮め、硬閾値は振幅を保つ代わりに残す係数の選び方に敏感になるので、目的に合わせて選ぶ。

族の定義、係数の並び、境界の扱いは[離散ウェーブレット変換](../../algorithms/wavelets/)で確かめる。
同じ記録を局所多項式で平滑化する方法と比べるには、[平滑化とトレンド除去](../../algorithms/smoothing-and-detrending/)を読む。
