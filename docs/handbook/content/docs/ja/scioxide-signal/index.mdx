音響波形、振動、生体電位、測光値のような観測データは、時間や空間の軸の上で標本化した数列として計算機に入る。
デジタル信号処理はその数列から必要な成分を取り出し、ノイズを抑え、伝送路や測定系の応答を推定・補正する計算の体系である。

`scioxide-signal` は、`scioxide-fft` の準備済みの変換を使って、次の処理を提供する。

- 線形・巡回・多次元の畳み込みと相関、長い記録の逐次の畳み込み
- FIR・IIR フィルタの設計と、二次節（SOS）による適用、前後方向のゼロ位相の実行
- 有理比の多相フィルタと Fourier によるリサンプリング
- 窓関数と DPSS、ピリオドグラム、Welch 推定、相互スペクトルとコヒーレンス、不等間隔標本の Lomb–Scargle 法
- 短時間 Fourier 変換（STFT）と双対ウインドウによる再構成
- 1 次元と多次元の解析信号、Riesz 変換と monogenic 信号、最小位相への変換
- 離散ウェーブレット変換（1 次元と 2 次元）
- Savitzky–Golay・Whittaker–Henderson・スプラインによる平滑化、トレンド除去
- 中央値・Hampel・局所 Wiener フィルタ、ピークと尺度をまたぐリッジの検出、位相の集中度、試験波形の生成
- 連続時間・離散時間の線形時不変（LTI）状態空間モデル

標本は実数か複素数の `f32` または `f64` で、どの機能も既定の `std` と `no_std + alloc` の両方で同じ API を持つ。

## 最初の計算

10 Hz の正弦波に 150 Hz のノイズが重なった記録から、低域通過フィルタで 10 Hz の成分を取り出す。
標本化周波数は $f_s = 1000$ Hz、記録は 1 秒（1000 標本）で、入力は

$$
x(t) = \sin(2\pi \cdot 10\, t) + 0.5 \sin(2\pi \cdot 150\, t)
$$

である。
フィルタは遮断周波数 $f_c$ の Butterworth 低域通過で、`design_iir` で設計して `to_sos()` で二次節の縦続に変える。
`design_iir` は帯域端を Nyquist 周波数 $f_s/2$ に対する比で受け取るので、$f_c$ [Hz] を $f_c / (f_s/2)$ に換算して渡す。

双一次変換で作った $N$ 次の Butterworth フィルタの振幅応答は閉じた形で書ける。
デジタル角周波数を $\omega = 2\pi f / f_s$ とすると

$$
\lvert H(e^{i\omega}) \rvert = \left[ 1 + \left( \frac{\tan(\omega/2)}{\tan(\omega_c/2)} \right)^{2N} \right]^{-1/2}
$$

である（導出は [IIR フィルタの設計](algorithms/iir-design/)）。
因果的な実行 `filter` は振幅を $\lvert H \rvert$ 倍し、位相を $\arg H$ だけずらす（低域通過の通過域では遅れになる）。
前後方向の実行 `forward_backward` は同じフィルタを順方向と逆方向に通すので、位相の遅れが打ち消され、振幅は $\lvert H \rvert^2$ 倍になる。

次のセルは設計したフィルタの周波数応答 `response` を閉じた形の振幅と比べ、二つの実行の出力を理想的な正弦波と比べる。
因果的な出力は過渡が消えた後半の 0.5 秒で $\lvert H \rvert \sin(2\pi f t + \arg H)$ と、ゼロ位相の出力は端の過渡を除いた中央の 0.5 秒で $\lvert H \rvert^2 \sin(2\pi f t)$ と比べる。
入力はフィルタの次数と遮断周波数である。

```rust
//| id: signal-first-lowpass
//| ref: signal-first-lowpass
//| title: Butterworth 低域通過で 10 Hz の成分を取り出す
//| run: reactive
//| crates: [scioxide-signal]
//| inputs:
//|   order: {"type":"range","label":"フィルタの次数 N","description":"次数を上げると遷移帯が急になり、群遅延が増える。","min":2,"max":8,"step":1,"value":4}
//|   cutoff: {"type":"range","label":"遮断周波数 f_c [Hz]","description":"振幅が 1/√2 になる周波数。","min":20,"max":100,"step":5,"value":40}
//| cases:
//|   - {"id":"order-8","label":"8 次、f_c = 40 Hz","description":"150 Hz の残りはさらに小さくなり、10 Hz の群遅延は増える。","inputs":{"order":8}}
//|   - {"id":"low-cutoff","label":"4 次、f_c = 20 Hz","description":"10 Hz が遮断周波数に近づき、通過域の振幅が 1 より小さくなる。","inputs":{"cutoff":20}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"gains","path":"/rows/0/3","range":{"max":1e-13}}
//|       - {"artifact":"gains","path":"/rows/1/3","range":{"max":1e-13}}
//|       - {"artifact":"outputs","path":"/rows/0/1","range":{"max":1e-3}}
//|       - {"artifact":"outputs","path":"/rows/1/1","range":{"max":1e-3}}
//|   - case: order-8
//|     expect:
//|       - {"artifact":"gains","path":"/rows/1/3","range":{"max":1e-13}}
//|   - case: low-cutoff
//|     expect:
//|       - {"artifact":"gains","path":"/rows/0/3","range":{"max":1e-13}}
use scioxide_signal::{IirBand, IirDomain, IirFamily, design_iir};

let rate = 1000.0_f64;
let n = 1000_usize;
let (tone, noise) = (10.0_f64, 150.0_f64);
let order = order.round() as usize;
let nyquist = rate / 2.0;

// 設計: 帯域端は Nyquist 周波数に対する比で渡す
let sos = design_iir(
    order,
    IirFamily::Butterworth,
    IirBand::Lowpass(cutoff / nyquist),
    IirDomain::Digital,
)
.map_err(|e| e.to_string())?
.to_sos()
.map_err(|e| e.to_string())?;

let tau = std::f64::consts::TAU;
let times: Vec<f64> = (0..n).map(|i| i as f64 / rate).collect();
let input: Vec<f64> = times
    .iter()
    .map(|&t| (tau * tone * t).sin() + 0.5 * (tau * noise * t).sin())
    .collect();
let causal = sos.filter(&input).map_err(|e| e.to_string())?;
let zero_phase = sos.forward_backward(&input).map_err(|e| e.to_string())?;

// 独立な検算: 双一次変換した Butterworth の振幅の閉じた形
let warp = |f: f64| (std::f64::consts::PI * f / rate).tan();
let closed_form = |f: f64| (1.0 + (warp(f) / warp(cutoff)).powi(2 * order as i32)).powf(-0.5);
let mut gains = Vec::new();
let mut response = Vec::new();
for f in [tone, noise] {
    let h = sos.response(f / nyquist).map_err(|e| e.to_string())?;
    let delay = sos.group_delay(f / nyquist).map_err(|e| e.to_string())?;
    let magnitude = h.re.hypot(h.im);
    gains.push((
        f,
        magnitude,
        closed_form(f),
        (magnitude - closed_form(f)).abs(),
        1000.0 * delay / rate,
    ));
    response.push((magnitude, h.im.atan2(h.re)));
}

// 理想の出力: 因果的な実行は |H| sin(2πft + arg H)、ゼロ位相の実行は |H|² sin(2πft)
let ideal = |t: f64, causal_form: bool| {
    [(tone, 1.0), (noise, 0.5)]
        .iter()
        .zip(&response)
        .map(|(&(f, a), &(g, phase))| {
            if causal_form {
                a * g * (tau * f * t + phase).sin()
            } else {
                a * g * g * (tau * f * t).sin()
            }
        })
        .sum::<f64>()
};
let max_gap = |output: &[f64], range: std::ops::Range<usize>, causal_form: bool| {
    range
        .map(|i| (output[i] - ideal(times[i], causal_form)).abs())
        .fold(0.0_f64, f64::max)
};
let outputs = vec![
    ("因果的 filter（0.5〜1 s）", max_gap(&causal, 500..n, true)),
    (
        "ゼロ位相 forward_backward（0.25〜0.75 s）",
        max_gap(&zero_phase, 250..750, false),
    ),
];

let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let fixed4 = serde_json::json!({ "fractionDigits": 4 });
let fixed2 = serde_json::json!({ "fractionDigits": 2 });
let gain_columns = serde_json::json!([
    { "key": "0", "label": "周波数 [Hz]", "type": "number" },
    { "key": "1", "label": "response の |H| [-]", "type": "number", "format": fixed4 },
    { "key": "2", "label": "閉じた形の |H| [-]", "type": "number", "format": fixed4 },
    { "key": "3", "label": "差 [-]", "type": "number", "format": sci3 },
    { "key": "4", "label": "群遅延 [ms]", "type": "number", "format": fixed2 }
]);
emit_table_with_columns!(
    gain_columns,
    gains,
    metadata = serde_json::json!({ "id": "gains" })
);
let output_columns = serde_json::json!([
    { "key": "0", "label": "出力（比較区間）", "type": "string" },
    { "key": "1", "label": "理想の正弦波との最大差 [-]", "type": "number", "format": sci3 }
]);
emit_table_with_columns!(
    output_columns,
    outputs,
    metadata = serde_json::json!({ "id": "outputs" })
);

let series = |name: &str, values: &[f64]| {
    let points: Vec<[f64; 2]> = times.iter().zip(values).map(|(&t, &y)| [t, y]).collect();
    serde_json::json!({ "name": name, "points": points })
};
emit_line_chart!(
    &vec![
        series("入力 x", &input),
        series("因果的 filter", &causal),
        series("ゼロ位相 forward_backward", &zero_phase),
    ],
    options = &serde_json::json!({
        "xLabel": "時刻 t [s]",
        "yLabel": "振幅 [-]",
        "yMin": -1.6,
        "yMax": 1.6
    })
);
```

既定の 4 次、$f_c = 40$ Hz では、`response` の振幅は 10 Hz で $0.99999$、150 Hz で $3.78 \times 10^{-3}$ で、閉じた形との差は $2.2 \times 10^{-15}$ 以下である。
150 Hz の成分は因果的な出力で約 $1/265$、ゼロ位相の出力では $\lvert H \rvert^2$ により約 $1/70000$ に減る。
因果的な出力は後半の 0.5 秒で理想の正弦波と $1.0 \times 10^{-14}$ まで一致し、10 Hz の成分は群遅延の 10.6 ms だけ入力より遅れる。
ゼロ位相の出力は中央の 0.5 秒で $4.6 \times 10^{-12}$ まで一致し、図の上で入力の 10 Hz の山と同じ時刻に山を持つ。

次数を 8 に上げると 150 Hz の振幅は $1.43 \times 10^{-5}$ まで下がるが、10 Hz の群遅延は 20.8 ms に増え、ゼロ位相の出力の過渡も長く残って中央での差は $2.8 \times 10^{-7}$ になる。
遮断周波数を 20 Hz に下げると 10 Hz が遷移帯に近づき、振幅は $0.998$ に下がる。
どの入力でも、設計の振幅と閉じた形の差は $5 \times 10^{-15}$ 以下である。

## 結果の読み方

この計算には、章全体で繰り返し現れる三つの規約が含まれている。

- 周波数の単位: デジタルのフィルタ設計と `response`、`group_delay` は Nyquist 周波数に対する比を受け取る。
  Welch 推定や STFT は時間単位あたりの周期、Lomb–Scargle 法と連続時間の系は角周波数を使うので、API ごとに単位を確かめる（[周波数の単位](oxref:signal-frequency-units)）。
- 遅延と位相: 因果的なフィルタは周波数ごとに位相を変え、この低域通過では 10 Hz の成分が群遅延の分だけ遅れる。
  波形の時刻を保ちたいときは前後方向の実行を使うが、振幅は 2 乗になり、記録全体がそろってから計算する一括処理になる。
- 端の過渡: 有限の記録では、フィルタの初期状態と記録の外側の延長が端の近くの出力を決める。
  中央で理想の値と一致していても、端の数標本は別に扱う（[記録の外側の延長](oxref:signal-boundaries)）。

一度きりの計算はこの例のようにワンショット関数や標準形式（`design_iir`、`filter`、`forward_backward`）で始める。
同じ処理を多くの記録やチャンクに繰り返すときは、Plan や手法オブジェクト（`IirFilter` など）と作業領域を呼び出し側で保持する形へ移る（[作業領域と実行コンテキスト](oxref:signal-workspaces)）。

## まとめ

`scioxide-signal` は、等間隔標本の畳み込み、フィルタの設計と適用、リサンプリング、スペクトルと時間周波数の解析、解析信号、ウェーブレット、平滑化、特徴抽出、LTI 系を一つのクレートで扱う。
デジタルのフィルタ設計では帯域端を Nyquist 比で渡し、設計した値は `response` と閉じた形の振幅で確かめられる。
因果的な実行は位相をずらし、前後方向の実行は位相を打ち消す代わりに振幅を 2 乗にするので、目的に合わせて選ぶ。
課題に合う演算と境界の仮定は[手法の選び方](choosing/)で決め、式の導出と誤差の性質は[数理とアルゴリズム](algorithms/)で確かめる。
