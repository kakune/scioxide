正方な疎行列 $\mathbf{W}$ の保存された成分 $(u, v)$ を辺、その値を重みとみなすと、疎行列は重み付きのグラフになる。
道路網、回路の節点の接続、確率の推移、有限要素の網目のつながりは、どれもこの形で表せる。
`scioxide-sparse` は疎行列から隣接リストを一度だけ作り、探索、連結成分、最小全域森、最短路、ラプラシアンの計算で使い回す。
このページでは行列をグラフとして解釈する規約、探索と連結成分、最小全域森、グラフのラプラシアンを説明する。
同じ Plan で求める最短路と負の閉路は、[最短路と負の閉路](../shortest-paths/)で扱う。
ワンショット関数、標準形式、スコープ付き API といった呼び出しの形の呼び方は、[共通仕様と構成](oxref:sparse-execution-forms)で定義している。

## 行列をグラフとして解釈する

`GraphPlan::new(view, direction)` は、正方な実数の疎行列のビューを重み付きのグラフとして読み、順向きと逆向きの隣接リストを持つ Plan `GraphPlan` を作る。
頂点 $i$ は行 $i$ と列 $i$ にあたる。
重みのない構造からは `GraphPlan::from_pattern(pattern, direction)` で Plan を作り、辺の重みはすべて 1 になる。
このとき Plan の重みの型は構造を取り出した行列の型によらず `f64` である。
頂点が $V$ 個、保存された成分が $E$ 個のとき、準備の計算量は $O(V + E \log E)$、メモリは $O(V + E)$ である。
どちらのコンストラクターも正方でない行列を `DimensionMismatch` で拒む。
疎行列の格納は有限の値だけを持つので、重みは常に有限である。

- `GraphDirection::Directed` では、保存された成分 $(u, v)$ が $u$ から $v$ への辺になる。
- `GraphDirection::Undirected` では、$(u, v)$ と $(v, u)$ のどちらか一方があれば辺 $\{u, v\}$ になる。
  両方が保存されていて重みが違えば、小さい方を使う。

`vertex_count()` は孤立した頂点を含む頂点の数、`direction()` は読み方を返す。
`edge_count()` は向きのある辺の数で、無向のグラフでは異なる 2 頂点を結ぶ辺を 2 本、自己ループを 1 本と数える。
隣接リストは頂点の番号順に並び、どのアルゴリズムも隣接する頂点を番号の小さい順に訪れるので、同じ行列と読み方からは結果が一通りに決まる。

### 辺の重みと行列の値

保存された値はどのアルゴリズムでも辺の重みとしてそのまま使われる。
ただし、値の大小が表す意味はアルゴリズムによって逆になる。
最小全域森と最短路では重みは辺の長さで、小さいほど近い。
ラプラシアンでは重みは結びつきの強さで、電気回路ならコンダクタンスにあたり、大きいほど強く結びつく。
同じ行列を両方の目的に使うときは、この違いに注意する。
例えば、コンダクタンス $g_{ij}$ の回路で抵抗 $1/g_{ij}$ を長さとする最短路を求めるには、値を逆数にした行列を別に組み立てる。

### 重み 0 の辺

保存された 0 も辺である。
重み 0 の辺は、探索と連結成分ではつながりそのものを表し、最小全域森と最短路では長さ 0 の辺になる。
一方、ラプラシアンへの寄与は 0 なので、ラプラシアンの上では辺がないのと同じになる（[グラフのラプラシアン](#グラフのラプラシアン)）。
組立てで `ExplicitZeroPolicy::Drop` を選ぶと、値が 0 の成分は構造から消え、グラフの辺も消える。
値の打ち消しで 0 になった成分も同じ規則に従う（[格納されていないゼロ成分と明示的に格納されたゼロ成分](oxref:sparse-explicit-zeros)）。
このページの二つのセルと、[最短路と負の閉路](oxref:sparse-zero-edge-dijkstra-experiment)のセルで、零の方針によって結果がどう変わるかを確かめる。

## 探索と連結成分

`breadth_first(source)` は幅優先探索、`depth_first(source)` は深さ優先探索で、どちらも $O(V + E)$ の時間で `GraphTraversal` を返す。
始点が頂点でなければ `OutOfBounds` で拒む。
`order()` は始点から届く頂点を見つけた順に並べ、`predecessors()` は探索木での親（始点と届かない頂点は `None`）、`depths()` は探索木での深さ（届かない頂点は `None`）を返す。
幅優先探索の深さは辺の重みを無視して数えた始点からの最短の辺の数に等しい。
深さ優先探索の深さは探索木の中での深さで、最短の辺の数とは限らない。
深さ優先探索は明示的なスタックを使うので、深いグラフでも呼び出しのスタックはあふれない。
位相的な並べ替えや閉路の検出の結果は返さない。

`weak_components()` は辺の向きを無視した連結成分（弱連結成分）を求める。
`strong_components()` は、互いに行き来できる頂点の極大な集合である強連結成分を、Kosaraju の方法で求める。
Kosaraju の方法はまず元のグラフで深さ優先探索を行い、探索を終えた時刻の遅い順に頂点を並べる。
次に、辺をすべて逆向きにしたグラフを、その順に始点を選んで探索する。
探索を最後に終えた頂点を含む成分には、元のグラフで他の成分から入る辺がない。
そのため逆向きのグラフでは、この成分から他の成分へ出る辺がなく、そこから始めた探索はちょうどその強連結成分に届く。
届いた頂点を除くと、残りの頂点でも同じ議論が成り立つ。
どちらも $O(V + E)$ の時間で `GraphComponents` を返し、`labels()` が各頂点の成分の番号、`count()` が成分の数である。
成分の番号は、各成分の最小の頂点の番号が小さい順に 0 から振られる。

ワンショット関数 `connected_components(pattern)` は、正方な構造から `from_pattern` と `GraphDirection::Directed` で Plan を作り、弱連結成分を返す。
計算量は Plan の準備を含めて $O(V + E \log E)$ である。
探索、連結成分、次の節の最小全域森は、オプション、作業領域、実行コンテキストを取らず、結果を新しく確保して返す。
反復回数の上限、取り消し、並列の実行はどれも使えない。

## 最小全域森

無向のグラフで、すべての頂点を結ぶ木のうち辺の重みの和が最小のものを**最小全域木**という。
連結でないグラフでは連結成分ごとの最小全域木の集まりを**最小全域森**という。
$V$ 頂点で $c$ 個の連結成分を持つグラフの全域森は、ちょうど $V - c$ 本の辺を持つ。

最小全域木は次の**切断の性質**を持つ。
頂点を二つの集合に分けたもの（切断）について、その間を渡る辺のうち重みが最小のものは、ある最小全域木に含まれる。
ある最小全域木 $T$ がその辺 $e$ を含まなければ、$T$ に $e$ を加えてできる閉路は切断をもう一度渡る辺 $f$ を含み、$e$ と $f$ を入れ替えても重みの和は増えないからである。

Kruskal 法は辺を重みの小さい順に見て、異なる二つの成分を結ぶ辺だけを森に加える。
辺 $e$ を加えるとき、$e$ より先に見た辺は、森に加えたものも捨てたものも、両端が同じ成分に入っている。
そのため、$e$ の一方の端点を含む成分とその外を分ける切断を渡る辺はどれも $e$ より後に見る辺で、$e$ はその中で最も軽い。
それまでに選んだ辺を含む最小全域森に切断の性質の議論を当てはめると、$e$ も含む最小全域森があることが分かる。
これを最後の辺まで続けると、選んだ辺が最小全域森になる。
成分の判定には素集合森（union–find）を使い、計算量は辺の整列の $O(E \log E)$ が支配する。
選ぶ辺は重みの順序だけで決まるので、負の重みがあっても同じ議論が成り立つ。

`minimum_spanning_forest()` は無向のグラフだけを受け付け、有向のグラフを `InvalidInput` で拒む。
負の重みは許し、自己ループは森に入らない。
結果の `MinimumSpanningForest` の `edges()` は、Kruskal 法が選んだ順（重みの順、同じ重みなら $(u, v)$ の順）に `ForestEdge { u, v, weight }`（$u < v$）を並べる。
`total_weight()` は、選んだ辺の重みの厳密な和を一度だけ丸めた値である。
途中の部分和が浮動小数点の範囲を超えても、最終的な和が表せれば有限の値を返す。
最終的な和が表せないときだけ、`NumericalInstability`（`Overflow`）で失敗する。
`components()` は孤立した頂点を含む連結成分を `GraphComponents` で返す。

### 最小全域森と重み 0 の辺

次のセルは 6 頂点の無向グラフの最小全域森を Kruskal 法で求める。
辺は $\{0, 1\}$: 0、$\{0, 2\}$: 4、$\{1, 2\}$: $d$、$\{1, 3\}$: 3、$\{2, 3\}$: 2、$\{2, 4\}$: 5、$\{3, 4\}$: 6 で、頂点 5 は辺を持たない。
各辺は $u < v$ の成分 $(u, v)$ として一度だけ置き、`GraphDirection::Undirected` で読む。
入力は辺 $\{1, 2\}$ の重み $d$（$-2$〜8）と、重み 0 の辺 $\{0, 1\}$ を構造に残すかどうかである。
一つ目の表は Kruskal 法が選んだ順の森の辺、二つ目の表は連結成分の数、森の辺の数、重みの和を示す。
独立な検算として、構造に残った辺のすべての組を調べ、閉路を作らない組のうち辺の数が最大のものの中で重みの和の最小を求める。
閉路を作らない辺の組は、辺の数が最大のときにちょうど全域森になり、その辺の数は $V - c$ である。

```rust
//| id: sparse-minimum-spanning-forest
//| ref: sparse-minimum-spanning-forest
//| title: Kruskal 法の最小全域森と全探索による照合
//| run: reactive
//| crates: [scioxide-core, scioxide-sparse]
//| inputs:
//|   edge_weight: {"type":"range","label":"辺 {1, 2} の重み d","description":"負の重みも使える。","min":-2.0,"max":8.0,"step":1.0,"value":1.0}
//|   keep_zero: {"type":"checkbox","label":"重み 0 の辺 {0, 1} を構造に残す（Preserve）","description":"外すと、組立てで値が 0 の成分を取り除く（Drop）。","value":true}
//| cases:
//|   - {"id":"negative-edge","label":"d = −2","description":"負の重みの辺が最初に選ばれ、重みの和が 5 に下がる。","inputs":{"edge_weight":-2}}
//|   - {"id":"heavy-edge","label":"d = 8","description":"辺 {1, 2} は閉路を作るので選ばれず、代わりに {1, 3} が入る。","inputs":{"edge_weight":8}}
//|   - {"id":"drop-zero","label":"重み 0 の辺を取り除く","description":"頂点 0 は重み 4 の辺 {0, 2} でつながり、重みの和が 12 に増える。","inputs":{"keep_zero":false}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"forest","path":"/rows/0/1","equals":0}
//|       - {"artifact":"forest","path":"/rows/0/2","equals":1}
//|       - {"artifact":"summary","path":"/rows/0/0","equals":2}
//|       - {"artifact":"summary","path":"/rows/0/1","equals":4}
//|       - {"artifact":"summary","path":"/rows/0/3","equals":4}
//|       - {"artifact":"summary","path":"/rows/0/2","approx":{"value":8,"atol":1e-15}}
//|       - {"artifact":"summary","path":"/rows/0/4","approx":{"value":8,"atol":1e-15}}
//|   - case: negative-edge
//|     expect:
//|       - {"artifact":"forest","path":"/rows/0/3","approx":{"value":-2,"atol":1e-15}}
//|       - {"artifact":"summary","path":"/rows/0/2","approx":{"value":5,"atol":1e-15}}
//|       - {"artifact":"summary","path":"/rows/0/4","approx":{"value":5,"atol":1e-15}}
//|   - case: heavy-edge
//|     expect:
//|       - {"artifact":"forest","path":"/rows/2/2","equals":3}
//|       - {"artifact":"summary","path":"/rows/0/2","approx":{"value":10,"atol":1e-15}}
//|       - {"artifact":"summary","path":"/rows/0/4","approx":{"value":10,"atol":1e-15}}
//|   - case: drop-zero
//|     expect:
//|       - {"artifact":"summary","path":"/rows/0/0","equals":2}
//|       - {"artifact":"summary","path":"/rows/0/2","approx":{"value":12,"atol":1e-15}}
//|       - {"artifact":"summary","path":"/rows/0/4","approx":{"value":12,"atol":1e-15}}
use scioxide_sparse::{
    DuplicatePolicy, ExplicitZeroPolicy, GraphDirection, GraphPlan, SparseBuilder,
};

let n = 6;
let edges = [
    (0, 1, 0.0_f64),
    (0, 2, 4.0),
    (1, 2, edge_weight),
    (1, 3, 3.0),
    (2, 3, 2.0),
    (2, 4, 5.0),
    (3, 4, 6.0),
];
let zeros = if keep_zero {
    ExplicitZeroPolicy::Preserve
} else {
    ExplicitZeroPolicy::Drop
};
let mut builder = SparseBuilder::new(n, n);
for &(u, v, w) in &edges {
    builder.push(u, v, w).map_err(|e| e.to_string())?;
}
let matrix = builder
    .finish_csr(DuplicatePolicy::Reject, zeros)
    .map_err(|e| e.to_string())?;
let graph =
    GraphPlan::new(matrix.view(), GraphDirection::Undirected).map_err(|e| e.to_string())?;
let forest = graph.minimum_spanning_forest().map_err(|e| e.to_string())?;
let chosen: Vec<_> = forest
    .edges()
    .iter()
    .enumerate()
    .map(|(k, e)| (k + 1, e.u, e.v, e.weight))
    .collect();
let columns = serde_json::json!([
    { "key": "0", "label": "選んだ順", "type": "integer" },
    { "key": "1", "label": "端点 u", "type": "integer" },
    { "key": "2", "label": "端点 v", "type": "integer" },
    { "key": "3", "label": "重み", "type": "number" }
]);
emit_table_with_columns!(
    columns,
    chosen,
    metadata = serde_json::json!({ "id": "forest" })
);

// 独立検算: Drop は値がちょうど 0 の成分を除くので、同じ規則で残る辺を選ぶ。
let kept: Vec<_> = edges
    .iter()
    .copied()
    .filter(|e| keep_zero || e.2 != 0.0)
    .collect();
// 素集合森の根（経路の圧縮はしない）。
let root = |parent: &[usize], mut u: usize| {
    while parent[u] != u {
        u = parent[u];
    }
    u
};
// 閉路を作らない辺の組のうち、辺の数が最大のもの（全域森）の重みの和の最小。
let mut best: Option<(usize, f64)> = None;
for mask in 0..1_usize << kept.len() {
    let mut parent: Vec<usize> = (0..n).collect();
    let mut acyclic = true;
    let mut total = 0.0;
    for (k, &(u, v, w)) in kept.iter().enumerate() {
        if mask >> k & 1 == 1 {
            let (a, b) = (root(&parent, u), root(&parent, v));
            acyclic &= a != b;
            parent[a] = b;
            total += w;
        }
    }
    let count = mask.count_ones() as usize;
    let better = best.is_none_or(|(m, t)| count > m || (count == m && total < t));
    if acyclic && better {
        best = Some((count, total));
    }
}
let columns = serde_json::json!([
    { "key": "0", "label": "連結成分の数 c", "type": "integer" },
    { "key": "1", "label": "森の辺の数", "type": "integer" },
    { "key": "2", "label": "重みの和 total_weight", "type": "number" },
    { "key": "3", "label": "全探索の辺の数", "type": "integer", "nullText": "なし" },
    { "key": "4", "label": "全探索の最小", "type": "number", "nullText": "なし" }
]);
let summary = (
    forest.components().count(),
    forest.edges().len(),
    forest.total_weight(),
    best.map(|b| b.0),
    best.map(|b| b.1),
);
emit_table_with_columns!(
    columns,
    vec![summary],
    metadata = serde_json::json!({ "id": "summary" })
);
```

既定の $d = 1$ では、Kruskal 法は $\{0, 1\}$（重み 0）、$\{1, 2\}$（1）、$\{2, 3\}$（2）を選ぶ。
続く $\{1, 3\}$ と $\{0, 2\}$ は閉路を作るので飛ばし、最後に $\{2, 4\}$（5）を選ぶ。
連結成分は $\{0, 1, 2, 3, 4\}$ と $\{5\}$ の 2 個で、森の辺は $V - c = 6 - 2 = 4$ 本、重みの和は 8 になり、全探索の辺の数と重みの和の最小に一致する。
$d = -2$ では負の重みの辺 $\{1, 2\}$ が最初に選ばれ、和は 5 に下がる。
$d = 8$ では $\{1, 2\}$ が閉路を作るので選ばれず、代わりに $\{1, 3\}$ が入って和は 10 になる。
重み 0 の辺を取り除くと、頂点 0 は重み 4 の辺 $\{0, 2\}$ でつながり、和は 12 に増える。
重み 0 の辺を残すかどうかで、連結成分の数は同じでも、森の辺と重みの和が変わる。

## グラフのラプラシアン

非負の重みを持つ無向グラフの重み行列を $\mathbf{W}$（$w_{ij} = w_{ji} \ge 0$、対角は 0）、頂点 $i$ の次数を $d_i = \sum_j w_{ij}$、$\mathbf{D} = \mathrm{diag}(d_i)$ とすると、グラフのラプラシアンは $\mathbf{L} = \mathbf{D} - \mathbf{W}$ である。
$\mathbf{W}$ の対称性を使って二次形式を書き直すと

$$
\mathbf{x}^{\mathsf{T}}\mathbf{L}\mathbf{x}
= \sum_i d_i x_i^2 - \sum_{i, j} w_{ij} x_i x_j
= \frac{1}{2}\sum_{i, j} w_{ij}\,(x_i - x_j)^2
= \sum_{\{i, j\} \in E} w_{ij}\,(x_i - x_j)^2
$$

となる。
右辺は非負なので、$\mathbf{L}$ は半正定値である。
半正定値な行列では $\mathbf{L}\mathbf{x} = \mathbf{0}$ と $\mathbf{x}^{\mathsf{T}}\mathbf{L}\mathbf{x} = 0$ が同値で、後者は $w_{ij} > 0$ のすべての辺で $x_i = x_j$ となることを意味する。
したがって $\mathbf{L}$ の零空間は、正の重みの辺だけでできるグラフの各連結成分で定数となるベクトルの全体で、固有値 0 の重複度はその連結成分の数に等しい。
重み 0 の辺は二次形式に現れないので、構造の上ではつながっていても、ここでの連結成分は分かれたままである。

固有値を $0 = \lambda_1 \le \lambda_2 \le \cdots \le \lambda_V$ と並べたとき、2 番目の $\lambda_2$ を**代数的連結度**という。
$\lambda_1$ の固有ベクトルは $\mathbf{1}$ なので、Courant–Fischer の定理から

$$
\lambda_2 = \min_{\mathbf{x} \ne \mathbf{0},\ \mathbf{x} \perp \mathbf{1}} \frac{\mathbf{x}^{\mathsf{T}}\mathbf{L}\mathbf{x}}{\mathbf{x}^{\mathsf{T}}\mathbf{x}}
$$

が成り立つ。
右辺で最小にする比 $\mathbf{x}^{\mathsf{T}}\mathbf{L}\mathbf{x} / \mathbf{x}^{\mathsf{T}}\mathbf{x}$ を **Rayleigh 商**という。
$\mathbf{1}$ に直交する任意のベクトルの Rayleigh 商は $\lambda_2$ の上界になる。
軽い辺を少し切るだけで二つに分けられるグラフでは、その分け方から作った $\mathbf{1}$ に直交するベクトルの Rayleigh 商が小さいので、$\lambda_2$ も小さい（[Fiedler ベクトルによるグラフ分割](../../examples/spectral-bisection/)）。
電気回路では $w_{ij}$ をコンダクタンスとすると、$\mathbf{L}$ は節点解析の行列になる（[抵抗回路網の節点解析と Foster の定理](../../examples/resistor-network/)）。

次数がすべて正のとき、対称に正規化したラプラシアンは

$$
\mathbf{L}_{\mathrm{sym}} = \mathbf{D}^{-1/2}(\mathbf{D} - \mathbf{W})\mathbf{D}^{-1/2}
$$

である。
$\mathbf{x} = \mathbf{D}^{1/2}\mathbf{y}$ と置くと $\mathbf{x}^{\mathsf{T}}\mathbf{L}_{\mathrm{sym}}\mathbf{x} = \mathbf{y}^{\mathsf{T}}\mathbf{L}\mathbf{y}$ なので、零空間は $\mathbf{D}^{1/2}\mathbf{1}$ を含み、Rayleigh 商は

$$
\frac{\mathbf{x}^{\mathsf{T}}\mathbf{L}_{\mathrm{sym}}\mathbf{x}}{\mathbf{x}^{\mathsf{T}}\mathbf{x}}
= \frac{\sum_{\{i, j\} \in E} w_{ij}\,(y_i - y_j)^2}{\sum_i d_i\,y_i^2}
$$

になる。
$(y_i - y_j)^2 \le 2(y_i^2 + y_j^2)$ と $\sum_{\{i, j\} \in E} w_{ij}(y_i^2 + y_j^2) = \sum_i d_i y_i^2$ から、この比は 2 を超えない。
したがって $\mathbf{L}_{\mathrm{sym}}$ の固有値は区間 $[0, 2]$ に入る。

`GraphPlan::laplacian::<T>(degree, normalization)` は、ラプラシアンを CSR の行列として持つ `LaplacianPlan` を作る。
`T` は重みの型 `S` か、実部が `S` の複素数の型で、複素数のベクトルにも作用させられる。
行列の $(u, v)$ 成分を $w_{uv}$ とすると、`LaplacianDegree::Out` は行の和 $d_u = \sum_v w_{uv}$、`In` は列の和 $d_v = \sum_u w_{uv}$ を次数とする。
無向のグラフではどちらも同じ次数になる。
有向のグラフで正規化しないとき、`Out` なら $\mathbf{L}\mathbf{1} = \mathbf{0}$、`In` なら $\mathbf{1}^{\mathsf{T}}\mathbf{L} = \mathbf{0}^{\mathsf{T}}$ が成り立つ。
`LaplacianNormalization::Unnormalized` は $\mathbf{D} - \mathbf{W}$、`Symmetric` は $\mathbf{D}^{-1/2}(\mathbf{D} - \mathbf{W})\mathbf{D}^{-1/2}$ で、次数 0 の頂点では $d^{-1/2}$ の代わりに尺度 1 を使うので、その頂点の対角成分は 0 になる。
自己ループは $\mathbf{D}$ にも $\mathbf{W}$ にも入れない。
行列は次数 0 の頂点を含むすべての対角成分と、$u \ne v$ の向きのある辺 $(u, v)$ ごとの成分 $(u, v)$ を持ち、重み 0 の辺も明示的に格納されたゼロ成分として残す。

負の重みは自己ループの重みも含めて `DomainError` で拒む。
次数の和が表せなければ `NumericalInstability`（`Overflow`）、対称な正規化で正の重みが 0 に丸められれば `NumericalInstability`（`Underflow`）で失敗する。
`degrees()` が自己ループを除いた次数、`matrix()` と `into_matrix()` が CSR の行列を返す。
`LaplacianPlan` は `LinearOperator`、`AdjointOperator`、`BlockOperator` を実装するので、scioxide-linalg の反復解法や固有値の計算にそのまま渡せる。
ワンショット関数 `laplacian(matrix)` は、行列を有向グラフとして読み、`Out` の次数で正規化しない $\mathbf{D} - \mathbf{W}$ を CSR の行列で返す。
計算量は Plan の準備を含めて $O(V + E \log E)$ である。
対称な行列を渡せば、無向のグラフのラプラシアンになる。

### 重み 0 の橋とラプラシアンの零空間

次のセルは重み 1 の三角形 $C = \{0, 1, 2\}$ と $\{3, 4, 5\}$ を、重み $b$ の橋 $\{2, 3\}$ でつないだ無向グラフのラプラシアンを作る。
入力は $b$（0〜2）と正規化の有無である。
三つのベクトル $\mathbf{y}$ を試し、正規化しないときは $\mathbf{x} = \mathbf{y}$、対称に正規化するときは $\mathbf{x} = \mathbf{D}^{1/2}\mathbf{y}$ に `LaplacianPlan` の行列を掛ける。
$\mathbf{y} = \mathbf{1}$ は零空間に入るはずのベクトル、$\mathbf{1}_C$ は三角形 $C$ の指示ベクトル、$\mathbf{1}_C - \tfrac{1}{2}\mathbf{1}$ は零空間に直交するベクトルである。
最後のベクトルでは $\sum_i d_i y_i = 0$ も成り立つので、どちらの正規化でも、Rayleigh 商はその行列の $\lambda_2$ の上界になる。
検算として、$\mathbf{x}^{\mathsf{T}}\mathbf{L}\mathbf{x}$ を辺の一覧から $\sum w_{ij}(y_i - y_j)^2$ で独立に計算する。
二つ目の表は重み 0 の成分を残した構造の連結成分の数と、正の重みの辺だけでできるグラフの連結成分の数を、`connected_components` で数える。

```rust
//| id: sparse-laplacian-null-space
//| ref: sparse-laplacian-null-space
//| title: 重み 0 の橋とラプラシアンの零空間
//| run: reactive
//| crates: [scioxide-core, scioxide-sparse]
//| inputs:
//|   bridge: {"type":"range","label":"橋 {2, 3} の重み b","description":"0 にすると、橋は構造に残るがラプラシアンへの寄与は 0 になる。","min":0.0,"max":2.0,"step":0.25,"value":1.0}
//|   scaling: {"type":"select","label":"正規化","options":[{"label":"なし（D − W）","value":"none"},{"label":"対称（D^(−1/2)(D − W)D^(−1/2)）","value":"symmetric"}],"value":"none"}
//| cases:
//|   - {"id":"zero-bridge","label":"b = 0","description":"構造は連結のままだが 1_C も零空間に入り、固有値 0 が二重になる。","inputs":{"bridge":0}}
//|   - {"id":"symmetric","label":"対称な正規化","description":"零空間は D^(1/2)1 に移り、Rayleigh 商の分母が Σ dᵢyᵢ² になる。","inputs":{"scaling":"symmetric"}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"quadratic","path":"/rows/0/1","range":{"max":1e-15}}
//|       - {"artifact":"quadratic","path":"/rows/1/2","approx":{"value":1,"rtol":1e-12}}
//|       - {"artifact":"quadratic","path":"/rows/1/3","approx":{"value":1,"rtol":1e-12}}
//|       - {"artifact":"quadratic","path":"/rows/1/1","approx":{"value":1.4142135623730951,"rtol":1e-12}}
//|       - {"artifact":"quadratic","path":"/rows/2/4","approx":{"value":0.6666666666666666,"rtol":1e-12}}
//|       - {"artifact":"components","path":"/rows/0/0","equals":1}
//|       - {"artifact":"components","path":"/rows/0/1","equals":1}
//|   - case: zero-bridge
//|     expect:
//|       - {"artifact":"quadratic","path":"/rows/1/1","range":{"max":1e-15}}
//|       - {"artifact":"quadratic","path":"/rows/2/4","range":{"max":1e-15}}
//|       - {"artifact":"components","path":"/rows/0/0","equals":1}
//|       - {"artifact":"components","path":"/rows/0/1","equals":2}
//|   - case: symmetric
//|     expect:
//|       - {"artifact":"quadratic","path":"/rows/0/1","range":{"max":1e-14}}
//|       - {"artifact":"quadratic","path":"/rows/1/2","approx":{"value":1,"rtol":1e-12}}
//|       - {"artifact":"quadratic","path":"/rows/2/4","approx":{"value":0.2857142857142857,"rtol":1e-12}}
use scioxide_core::RealScalar;
use scioxide_sparse::{
    DuplicatePolicy, ExplicitZeroPolicy, GraphDirection, GraphPlan, LaplacianDegree,
    LaplacianNormalization, SparseBuilder, connected_components,
};

// 三角形 C = {0, 1, 2} と {3, 4, 5}（重み 1）を、重み b の橋 {2, 3} でつなぐ。
let edges = [
    (0, 1, 1.0_f64),
    (0, 2, 1.0),
    (1, 2, 1.0),
    (3, 4, 1.0),
    (3, 5, 1.0),
    (4, 5, 1.0),
    (2, 3, bridge),
];
let n = 6;
let assemble = |zeros| {
    let mut builder = SparseBuilder::new(n, n);
    for &(u, v, w) in &edges {
        builder.push(u, v, w).map_err(|e| e.to_string())?;
    }
    builder
        .finish_csr(DuplicatePolicy::Reject, zeros)
        .map_err(|e| e.to_string())
};
let kept = assemble(ExplicitZeroPolicy::Preserve)?;
// 正の重みの辺だけの連結成分を数えるため、値が 0 の成分を除いた行列も作る。
let positive = assemble(ExplicitZeroPolicy::Drop)?;
let structural = connected_components(kept.structural_pattern()).map_err(|e| e.to_string())?;
let weighted =
    connected_components(positive.structural_pattern()).map_err(|e| e.to_string())?;

let graph =
    GraphPlan::new(kept.view(), GraphDirection::Undirected).map_err(|e| e.to_string())?;
let symmetric = scaling == "symmetric";
let normalization = if symmetric {
    LaplacianNormalization::Symmetric
} else {
    LaplacianNormalization::Unnormalized
};
let plan = graph
    .laplacian::<f64>(LaplacianDegree::Out, normalization)
    .map_err(|e| e.to_string())?;
let degrees = plan.degrees();
let candidates: [(&str, fn(usize) -> f64); 3] = [
    ("1", |_| 1.0),
    ("1_C", |i| if i < 3 { 1.0 } else { 0.0 }),
    ("1_C − 1/2", |i| if i < 3 { 0.5 } else { -0.5 }),
];
let mut rows = Vec::new();
for (name, y) in candidates {
    // 対称に正規化した L には x = D^{1/2} y を掛ける。
    let x: Vec<f64> = (0..n)
        .map(|i| {
            if symmetric {
                RealScalar::sqrt(degrees[i]) * y(i)
            } else {
                y(i)
            }
        })
        .collect();
    let lx = plan.matrix().apply(&x).map_err(|e| e.to_string())?;
    let residual = lx.iter().map(|v| v * v).sum::<f64>().sqrt();
    let form: f64 = x.iter().zip(&lx).map(|(a, b)| a * b).sum();
    // 独立検算: 二次形式を辺の一覧から Σ w_ij (y_i − y_j)² で計算する。
    let by_edges: f64 = edges
        .iter()
        .map(|&(i, j, w)| w * (y(i) - y(j)).powi(2))
        .sum();
    let rayleigh = form / x.iter().map(|v| v * v).sum::<f64>();
    rows.push((name, residual, form, by_edges, rayleigh));
}
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let fixed6 = serde_json::json!({ "significantDigits": 6 });
let columns = serde_json::json!([
    { "key": "0", "label": "y", "type": "string" },
    { "key": "1", "label": "‖Lx‖₂", "type": "number", "format": sci3 },
    { "key": "2", "label": "xᵀLx", "type": "number", "format": fixed6 },
    { "key": "3", "label": "Σ w(yᵢ − yⱼ)²", "type": "number", "format": fixed6 },
    { "key": "4", "label": "Rayleigh 商 xᵀLx / xᵀx", "type": "number", "format": fixed6 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "quadratic" })
);
let columns = serde_json::json!([
    { "key": "0", "label": "構造の連結成分の数", "type": "integer" },
    { "key": "1", "label": "正の重みの辺だけの連結成分の数", "type": "integer" }
]);
emit_table_with_columns!(
    columns,
    vec![(structural.count(), weighted.count())],
    metadata = serde_json::json!({ "id": "components" })
);
```

既定の $b = 1$ で正規化しないと、$\mathbf{y} = \mathbf{1}$ では $\lVert \mathbf{L}\mathbf{x} \rVert_2 = 0$ で、定数ベクトルが零空間に入る。
$\mathbf{1}_C$ では $\mathbf{L}\mathbf{1}_C$ の成分が頂点 2 で $b$、頂点 3 で $-b$ になるので、$\lVert \mathbf{L}\mathbf{x} \rVert_2 = \sqrt{2}\,b \approx 1.414$ である。
二次形式は橋の寄与 $b = 1$ だけになり、辺の一覧から計算した値とどの行でも一致する。
$\mathbf{1}_C - \tfrac{1}{2}\mathbf{1}$ の Rayleigh 商は $b/(6/4) = 2b/3 \approx 0.667$ なので、$\lambda_2 \le 0.667$ が分かる。
$b = 0$ にすると、橋の成分は構造に残るので構造の連結成分は 1 個のままだが、$\mathbf{1}_C$ も $\mathbf{L}\mathbf{x} = \mathbf{0}$ を満たす。
正の重みの辺だけの連結成分は 2 個で、固有値 0 は二重になり、$\lambda_2 = 0$ である。
対称な正規化では、$\mathbf{x} = \mathbf{D}^{1/2}\mathbf{1}$ の $\lVert \mathbf{L}\mathbf{x} \rVert_2$ は $5.4 \times 10^{-16}$ で、平方根の丸めの分だけ 0 からずれる。
最後のベクトルの Rayleigh 商は $b/\sum_i d_i y_i^2 = 2b/(6 + b) \approx 0.286$ になる。

## まとめ

疎行列の保存された成分は向きの規約に従って辺になり、保存された 0 も重み 0 の辺なので、組立ての零の方針がグラフの接続を決める。
重みは最小全域森と最短路では長さ、ラプラシアンでは結びつきの強さとして使われるので、目的に合わせて値を変換してから Plan を作る。
探索と連結成分は $O(V + E)$ で求まり、強連結成分には Kosaraju の方法を使う。
最小全域森は Kruskal 法で $O(E \log E)$ で求まり、$V - c$ 本の辺を持ち、重みの和は厳密な和を一度だけ丸めた値である。
ラプラシアンの固有値 0 の重複度は正の重みの辺だけで数えた連結成分の数に等しく、`LaplacianPlan` はそのまま作用素として固有値の計算や連立方程式に使える。
