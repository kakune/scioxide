大きな疎な系を、未知数を分けた小さな系の解の組み合わせで前処理する方法を領域分割法と呼ぶ。
小さな系にはそれぞれ疎な直接分解や不完全分解を使え、加法の組み合わせでは各部分領域を独立に解けるので並列に計算できる。
隣り合う部分領域を重ねると、境界をまたぐ誤差も局所の解で補正できる。
このページでは重なりのある Schwarz 法の三つの組み合わせ方、`SchwarzPlan` が確かめることと提供しないもの、反復回数の数え方を説明し、2 次元 Poisson 方程式で重なりと部分領域の数の効果を確かめる。
前処理付きの反復法が何を解くかは、[不完全分解と反復法の前処理](oxref:sparse-preconditioning-role)で説明した。

## 部分領域と局所の解

重なりのある領域分割法は、まず未知数を互いに重ならない $s$ 個の**持ち分**に分け、各持ち分を行列のグラフの隣接で $\delta$ 層ずつ広げて部分領域 $\Omega_1, \dots, \Omega_s$ とする。
隣り合う部分領域は $2\delta$ 層で重なる。
部分領域 $i$ の未知数を取り出す制限を $\mathbf{R}_i$、局所の行列を $\mathbf{A}_i = \mathbf{R}_i\mathbf{A}\mathbf{R}_i^{\mathsf{T}}$、その逆の作用（局所の解）を $\mathbf{M}_i \approx \mathbf{A}_i^{-1}$ とする。
$\mathbf{M}_i$ は疎な直接分解でも、不完全分解のような近似でもよい。

## 三つの組み合わせ方

残差 $\mathbf{r}$ に対する前処理の作用 $\mathbf{z}$ を、`SchwarzKind` で次の三通りに組み合わせる。

- **加法 Schwarz**（`Additive`）は局所の補正を同時に計算し、各部分領域の対角の重み $\mathbf{W}_i$ を掛けて足し合わせる。

  $$
  \mathbf{z} = \sum_i \mathbf{R}_i^{\mathsf{T}}\mathbf{W}_i\mathbf{M}_i\mathbf{R}_i\mathbf{r}
  $$

  重みは各未知数で和が 1 になるように取る（1 の分割）。
  重みを掛けた形は一般に Hermitian でないので、CG ではなく GMRES などと組み合わせる。
  重みを持たない古典的な加法 Schwarz（$\mathbf{W}_i = \mathbf{I}$）は Hermitian だが、重なりがあると重みの和が 1 にならないので、`SchwarzPlan` では表せない。
  すべての未知数がちょうど $c$ 個の部分領域に入るときだけは、$\mathbf{W}_i = \mathbf{I}/c$ として定数倍の違いで表せる。
- **制限付き加法 Schwarz**（`RestrictedAdditive`）は、重みを持ち分で 1、それ以外で 0 とし、各補正を持ち分の上だけに書き込む。
  通信が少なく、古典的な加法 Schwarz より速く収束することが多い（Cai and Sarkis, 1999）。
- **乗法 Schwarz**（`Multiplicative`）は、部分領域を与えた順に一つずつ解き、そのたびに残差を更新する。

  $$
  \mathbf{z} \leftarrow \mathbf{0}, \qquad \mathbf{z} \leftarrow \mathbf{z} + \mathbf{R}_i^{\mathsf{T}}\mathbf{M}_i\mathbf{R}_i(\mathbf{r} - \mathbf{A}\mathbf{z}) \quad (i = 1, \dots, s)
  $$

  前処理全体の作用 $\mathbf{r} \mapsto \mathbf{z}$ を $\mathbf{M}^{-1}$ と書くと、$\mathbf{M}_i = \mathbf{A}_i^{-1}$ なら $\mathbf{I} - \mathbf{M}^{-1}\mathbf{A} = (\mathbf{I} - \mathbf{\Pi}_s)\cdots(\mathbf{I} - \mathbf{\Pi}_1)$（$\mathbf{\Pi}_i = \mathbf{R}_i^{\mathsf{T}}\mathbf{A}_i^{-1}\mathbf{R}_i\mathbf{A}$）となり、ブロック Gauss–Seidel 法にあたる。
  前進の 1 回の掃引だけなので、この前処理も Hermitian でない。
  全体の作用素が必要で、並列の方針を与えても順に実行する。

## 一段の方法と提供しないもの

重なり $\delta$ を増やすと反復回数は一般に減るが、局所の系は大きくなる。
粗い空間の補正を持たない一段の Schwarz 法では、1 回の作用で情報が隣の部分領域にしか伝わらないので、部分領域の数を増やすと反復回数が増える。
大域的な誤差を減らすには、多重格子のような粗い補正を組み合わせる必要がある。

`SchwarzPlan` が提供するのは上の三つの一段の方法だけで、重なりのある古典的な加法 Schwarz（$\mathbf{W}_i = \mathbf{I}$）と、粗い空間の補正を加えた二段の方法は提供しない。
どちらかが必要なら、scioxide-core の `Preconditioner` を実装した型で、局所の解と補正を自分で組み合わせる。
格子によらない収束が目的なら、[代数的多重格子による前処理](../algebraic-multigrid/)の `AmgPreconditioner` を使う。

## SchwarzPlan の作成と検査

`SchwarzPlan::new(dimension, kind, subdomains, operator)` は、部分領域の添字と重みを検査してコピーし、局所の解と全体の作用素は借用する。
`SchwarzPlan::with_options(dimension, kind, subdomains, operator, options)` は、同じ Plan を `SchwarzOptions` の許容誤差と上限で作る。
`SchwarzSubdomainView` は、狭義に増加する全体の添字 `indices`、加法の 2 種類で使う重み `weights`、局所の解 `solve`（`SchwarzLocalSolveView::InverseOperator(&op)` か `Preconditioner(&p)`）からなる。
Plan は次のことを確かめ、満たさなければ `InvalidInput` か `DimensionMismatch`（重みが NaN か無限大なら `NonFinite`）を返す。

- 部分領域が空でなく、添字が範囲内で狭義に増加し、局所の解の次元が添字の数と等しいこと。
- 加法の 2 種類では、重みが 0 以上 1 以下で、各未知数の重みの和が正で 1 に等しいこと。
  加法は許容誤差 `SchwarzOptions::with_partition_tolerance`（既定は `Tolerance::from_machine_epsilon()`）の範囲で、制限付き加法は厳密に 1 を求め、重みは 0 か 1 に限る。
  和が正であることから、すべての未知数がどれかの部分領域に入ることも確かめられる。
- 乗法では重みを与えず、全体の作用素 `SchwarzOperatorView::Sparse(view)` か `MatrixFree(&op)` を渡し、加法の 2 種類には全体の作用素を渡さないこと。
  乗法は、どの部分領域にも入らない未知数があっても拒まず、その成分の補正は 0 のままである。

## Plan のメモリと数え方

`SchwarzOptions::new()` の `with_max_plan_bytes` と `with_max_workspace_bytes` は、Plan と作業領域の論理バイト数を制限し（既定は上限なし）、`plan_bytes()` と `preparation_peak_bytes()` で使った量を読める。
乗法の疎な作用素では局所の補正で変わる行だけの残差を計算し直し、行列を使わない作用素では補正のたびに全体に作用させる。
加法の 2 種類は作用を呼び出すときの `SparseSolveOptions` の実行の方針に従って部分領域をワーカーに分けて解き、補正を部分領域の順に足すので、結果はワーカーの数によらない。
右辺 1 本の作用を反復 1 回、局所の解 1 回を評価 1 回と数え、乗法では残差の更新 1 回も作用素の評価 1 回と数える。

## 重なりと部分領域の数

次のセルは $32 \times 32$ 格子の 5 点差分ラプラシアン（$N = 1024$、行優先の番号）を、格子の行で $s$ 本の帯の持ち分に分け、各帯を上下に $\delta$ 行ずつ広げて重ねる。
帯の未知数は番号が連続するので、局所の行列は $\mathbf{A}$ の主小行列 $\mathbf{A}_i = \mathbf{R}_i\mathbf{A}\mathbf{R}_i^{\mathsf{T}}$ として組み立て、準備を一括して行うコンストラクター `SparseCholesky::new` で分解する。
加法の重みは各点を覆う帯の数の逆数、制限付き加法の重みは持ち分で 1 である。
三種類の Schwarz 法を前処理として、scioxide-linalg の GMRES（再始動 60、反復回数の上限 3000）で一様な湧き出し $\mathbf{b} = \mathbf{1}$ の系を $\lVert \mathbf{r} \rVert_2 \le 10^{-8}\lVert \mathbf{b} \rVert_2$ まで解き、反復回数を前処理なしの場合と比べる。
入力は部分領域の数 $s$（2〜8）と重なり $\delta$（0〜4 行）である。
表は反復回数と終了理由に加えて、返された解から計算し直した真の相対残差 $\lVert \mathbf{b} - \mathbf{A}\mathbf{x} \rVert_2/\lVert \mathbf{b} \rVert_2$ と、Plan の大きさ `plan_bytes()` を示す。

```rust
//| id: sparse-schwarz-overlap
//| ref: sparse-schwarz-overlap
//| title: 重なりと部分領域の数による Schwarz 前処理の反復回数
//| run: reactive
//| crates: [scioxide-core, scioxide-sparse, scioxide-linalg]
//| inputs:
//|   parts: {"type":"range","label":"部分領域（帯）の数 s","description":"格子の行を s 本の帯に分ける。","min":2,"max":8,"step":1,"value":4}
//|   overlap: {"type":"range","label":"重なり δ [格子の行]","description":"各帯を上下に広げる行の数。","min":0,"max":4,"step":1,"value":1}
//| cases:
//|   - {"id":"no-overlap","label":"δ = 0","description":"重なりがないと加法と制限付き加法は同じブロック Jacobi 前処理になり、反復が増える。","inputs":{"overlap":0}}
//|   - {"id":"many-parts","label":"s = 8","description":"粗い補正がないので、部分領域を増やすと加法の反復が増える。","inputs":{"parts":8}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"schwarz","path":"/rows/0/1","equals":59}
//|       - {"artifact":"schwarz","path":"/rows/1/1","equals":14}
//|       - {"artifact":"schwarz","path":"/rows/2/1","equals":13}
//|       - {"artifact":"schwarz","path":"/rows/3/1","equals":10}
//|       - {"artifact":"schwarz","path":"/rows/3/2","equals":"Converged"}
//|       - {"artifact":"schwarz","path":"/rows/0/3","range":{"max":1e-8}}
//|       - {"artifact":"schwarz","path":"/rows/1/3","range":{"max":1e-8}}
//|       - {"artifact":"schwarz","path":"/rows/2/3","range":{"max":1e-8}}
//|       - {"artifact":"schwarz","path":"/rows/3/3","range":{"max":1e-8}}
//|   - case: no-overlap
//|     expect:
//|       - {"artifact":"schwarz","path":"/rows/2/1","equals":21}
//|       - {"artifact":"schwarz","path":"/rows/1/1","equals":21}
//|       - {"artifact":"schwarz","path":"/rows/3/1","equals":15}
//|       - {"artifact":"schwarz","path":"/rows/1/3","range":{"max":1e-8}}
//|       - {"artifact":"schwarz","path":"/rows/3/3","range":{"max":1e-8}}
//|   - case: many-parts
//|     expect:
//|       - {"artifact":"schwarz","path":"/rows/1/1","equals":17}
//|       - {"artifact":"schwarz","path":"/rows/3/1","equals":13}
//|       - {"artifact":"schwarz","path":"/rows/1/3","range":{"max":1e-8}}
//|       - {"artifact":"schwarz","path":"/rows/3/3","range":{"max":1e-8}}
use scioxide_core::{Budget, LinearOperator, RealScalar, ResidualTolerance};
use scioxide_linalg::{GmresSolver, Preconditioning};
use scioxide_sparse::{
    CsrMatrix, ExplicitZeroPolicy, SchwarzKind, SchwarzLocalSolveView, SchwarzOperatorView,
    SchwarzOptions, SchwarzPlan, SchwarzSubdomainView, SparseCholesky, sparse_diagonals,
};

let (k, s, delta) = (32, parts as usize, overlap as usize);
let n = k * k;
// m 行 × k 列の格子の 5 点差分ラプラシアン。格子の行で切った帯の主小行列も同じ形になる。
let laplacian = |m: usize| -> Result<CsrMatrix<f64>, String> {
    let size = m * k;
    // 第 p 成分は番号 p と p + 1 の結合で、格子の行の端では 0（あとで落とす）。
    let x: Vec<f64> = (1..size)
        .map(|p| if p % k == 0 { 0.0 } else { -1.0 })
        .collect();
    let (y, diagonal) = (vec![-1.0_f64; size - k], vec![4.0_f64; size]);
    let offsets = [-(k as isize), -1, 0, 1, k as isize];
    sparse_diagonals(size, size, &offsets, &[&y, &x, &diagonal, &x, &y])
        .map_err(|e| e.to_string())?
        .view()
        .to_csr(ExplicitZeroPolicy::Drop)
        .map_err(|e| e.to_string())
};
let a = laplacian(k)?;
// 持ち分は格子の行 [i k/s, (i + 1) k/s)、部分領域はそれを上下に δ 行広げたもの（番号の範囲）。
let owned: Vec<(usize, usize)> = (0..s)
    .map(|i| (i * k / s * k, (i + 1) * k / s * k))
    .collect();
let spans: Vec<(usize, usize)> = owned
    .iter()
    .map(|&(lo, hi)| (lo.saturating_sub(delta * k), (hi + delta * k).min(n)))
    .collect();
// 局所の行列 A_i = R_i A R_iᵀ を準備を一括して行うコンストラクターで Cholesky 分解する。
let mut factors = Vec::new();
for &(start, end) in &spans {
    let local = laplacian((end - start) / k)?;
    factors.push(SparseCholesky::new(&local).map_err(|e| e.to_string())?);
}
let indices: Vec<Vec<usize>> = spans
    .iter()
    .map(|&(start, end)| (start..end).collect())
    .collect();
// 加法の重みは各点を覆う帯の数の逆数、制限付き加法の重みは持ち分で 1。
let cover: Vec<f64> = (0..n)
    .map(|j| spans.iter().filter(|r| r.0 <= j && j < r.1).count() as f64)
    .collect();
let additive: Vec<Vec<f64>> = indices
    .iter()
    .map(|ix| ix.iter().map(|&j| 1.0 / cover[j]).collect())
    .collect();
let restricted: Vec<Vec<f64>> = owned
    .iter()
    .zip(&indices)
    .map(|(&(lo, hi), ix)| {
        ix.iter()
            .map(|&j| if (lo..hi).contains(&j) { 1.0 } else { 0.0 })
            .collect()
    })
    .collect();
let b = vec![1.0_f64; n];
let tolerance = ResidualTolerance::new(0.0, 1e-8).map_err(|e| e.to_string())?;
let limit = Budget::try_from(3000).map_err(|e| e.to_string())?;
let restart = Budget::try_from(60).map_err(|e| e.to_string())?;
let solver = GmresSolver::new(tolerance, limit).with_restart(restart);
// 独立検算: 返された解から真の相対残差 ‖b − Ax‖₂ / ‖b‖₂ を計算し直す（b = 1、‖b‖₂ = √N）。
let mut scratch = vec![0.0_f64; a.apply_workspace_len().map_err(|e| e.to_string())?];
let mut relative = |x: &[f64]| -> Result<f64, String> {
    let mut ax = vec![0.0_f64; n];
    a.apply_into(x, &mut ax, &mut scratch)
        .map_err(|e| e.to_string())?;
    let squares = ax
        .iter()
        .fold(0.0_f64, |sum, y| sum + (1.0 - y) * (1.0 - y));
    Ok(RealScalar::sqrt(squares / n as f64))
};
let none = solver
    .solve_with_options(&a, &b[..], Preconditioning::None, None)
    .map_err(|e| e.to_string())?;
let mut rows = vec![(
    "前処理なし",
    none.report().iterations(),
    format!("{:?}", none.report().termination()),
    relative(none.solution().as_slice())?,
    None,
)];
for (name, kind) in [
    ("加法", SchwarzKind::Additive),
    ("制限付き加法", SchwarzKind::RestrictedAdditive),
    ("乗法", SchwarzKind::Multiplicative),
] {
    let weights = |i: usize| match kind {
        SchwarzKind::Additive => Some(&additive[i][..]),
        SchwarzKind::RestrictedAdditive => Some(&restricted[i][..]),
        SchwarzKind::Multiplicative => None,
    };
    let domains: Vec<SchwarzSubdomainView<'_, f64>> = (0..s)
        .map(|i| SchwarzSubdomainView {
            indices: &indices[i],
            weights: weights(i),
            solve: SchwarzLocalSolveView::InverseOperator(&factors[i]),
        })
        .collect();
    // 乗法だけが残差の更新に全体の行列を使う。
    let global =
        (kind == SchwarzKind::Multiplicative).then(|| SchwarzOperatorView::Sparse(a.view()));
    let options = SchwarzOptions::new()
        .with_max_plan_bytes(1 << 24)
        .with_max_workspace_bytes(1 << 24);
    let plan = SchwarzPlan::with_options(n, kind, &domains, global, options)
        .map_err(|e| e.to_string())?;
    let result = solver
        .solve_with_options(&a, &b[..], Preconditioning::Inverse(&plan), None)
        .map_err(|e| e.to_string())?;
    rows.push((
        name,
        result.report().iterations(),
        format!("{:?}", result.report().termination()),
        relative(result.solution().as_slice())?,
        Some(plan.plan_bytes()),
    ));
}
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let columns = serde_json::json!([
    { "key": "0", "label": "前処理" },
    { "key": "1", "label": "GMRES の反復回数 [回]", "type": "integer" },
    { "key": "2", "label": "終了理由" },
    { "key": "3", "label": "真の相対残差 [-]", "type": "number", "format": sci2 },
    { "key": "4", "label": "plan_bytes() [B]", "type": "integer", "nullText": "なし" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "schwarz" })
);
```

既定の $s = 4$、$\delta = 1$ では、前処理なしの GMRES が 59 回かかるのに対し、加法は 14 回、制限付き加法は 13 回、乗法は 10 回で収束する。
解から計算し直した真の相対残差はどの行も $7.7 \times 10^{-10}$ から $7.6 \times 10^{-9}$ の間で、終了理由 `Converged` のとおり許容誤差 $10^{-8}$ を満たしている。
重なりを $\delta = 0, 1, 2, 3, 4$ と増やすと、制限付き加法は 21、13、10、9、8 回、乗法は 15、10、8、6、6 回と減る。
$\delta = 0$ では重みがすべて 1 になり、加法と制限付き加法はどちらも、各帯の対角ブロックの逆を並べたブロック Jacobi 前処理になるので、反復回数も 21 回で一致する。
重みを掛けた加法は 21、14、11、9、12 回と $\delta = 4$ で逆に増え、重なりについて単調には減らない。
$\delta = 1$ のまま部分領域を $s = 2, 4, 8$（帯の行数がそろう分割）と増やすと、加法の反復は 8、14、17 回と増える。
帯の行数がそろわない $s = 5, 6, 7$ では 18、20、20 回で、$s = 8$ より多い。
乗法は $s = 2$ から 8 まで 6、8、10、10、11、12、13 回と、減ることなく増える。
粗い補正がないので、帯の数が増えるほど、離れた帯の間で情報を伝えるのに多くの反復が必要になる。
この実験では、順に残差を更新する乗法が同じ分割で加法より少ない反復で収束するが、乗法は部分領域ごとの計算を並列に行えない。
`plan_bytes()` は添字と重みのコピー、部分領域ごとの記録、乗法では各部分領域の補正で変わる行の一覧の大きさの和である。
既定の分割では加法が 14816 B、乗法が 9440 B である（wasm の 32 ビットの `usize` での値）。

## まとめ

重なりのある Schwarz 法は部分領域の局所の解を組み合わせる前処理で、`SchwarzPlan` は重みを掛けた加法、制限付き加法、乗法の三つを提供する。
重なりがあると三つとも一般に Hermitian でないので、CG ではなく GMRES などの Krylov 部分空間法と組み合わせる。
重なりを 0 から 1 行に広げるだけで反復は 2/3 程度に減るが、局所の系が大きくなり、重みを掛けた加法では反復が重なりについて単調に減るとは限らない。
粗い補正のない一段の方法なので、部分領域を増やすと反復回数は増える傾向にあり、格子によらない収束が必要なら多重格子を使う。
この実験では乗法が同じ分割で最も少ない反復で収束するが、乗法は部分領域を順に解くので並列に計算できない。
