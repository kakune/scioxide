有限要素法の剛性行列、グラフのラプラシアン、最小二乗の正規方程式のように、Hermitian（実数なら対称）な行列は多い。
Hermitian 行列 $\mathbf{A} = \mathbf{A}^{\mathsf{H}}$ では、ピボットなしの LU 分解の $\mathbf{U}$ が対角行列 $\mathbf{D}$ を使って $\mathbf{U} = \mathbf{D}\mathbf{L}^{\mathsf{H}}$ と書けるので、下三角の半分だけを計算して保存すればよい。
正定値なら Cholesky 分解 $\mathbf{A} = \mathbf{L}\mathbf{L}^{\mathsf{H}}$ がピボットの選択なしに安定に計算でき、不定値なら $1 \times 1$ と $2 \times 2$ のブロックを対角に持つ LDL 分解 $\mathbf{A} = \mathbf{L}\mathbf{D}\mathbf{L}^{\mathsf{H}}$ を使う。
このページでは疎 Cholesky 分解の構造を決める消去木、不定値行列のピボット、LDL 分解から読める慣性とその応用、$2 \times 2$ ブロックの範囲安全な計算、記号解析と数値分解の分担を説明する。

## 疎 Cholesky 分解

$\mathbf{A}$ が Hermitian 正定値（すべての $\mathbf{x} \ne \mathbf{0}$ で $\mathbf{x}^{\mathsf{H}}\mathbf{A}\mathbf{x} > 0$）なら、対角が正の下三角行列 $\mathbf{L}$ がただ一つ存在して $\mathbf{A} = \mathbf{L}\mathbf{L}^{\mathsf{H}}$ となる。
$\mathbf{A} = \begin{pmatrix} a_{11} & \mathbf{a}_{21}^{\mathsf{H}} \\ \mathbf{a}_{21} & \mathbf{A}_{22} \end{pmatrix}$ と分けて最初の列を消去すると、残りの Schur 補行列 $\mathbf{A}_{22} - \mathbf{a}_{21}\mathbf{a}_{21}^{\mathsf{H}}/a_{11}$ もまた Hermitian 正定値になる。
そのため各段のピボットは常に正で、行や列を入れ替えずに分解を最後まで進められる。
$a_{ii} = \sum_k |l_{ik}|^2$ なので因子の成分は $|l_{ik}| \le \sqrt{a_{ii}}$ で抑えられ、実数の行列でアンダーフローがなければ、計算した因子は

$$
\mathbf{A} + \Delta\mathbf{A} = \hat{\mathbf{L}}\hat{\mathbf{L}}^{\mathsf{H}}, \qquad |\Delta\mathbf{A}| \le \gamma_{n+1}\, |\hat{\mathbf{L}}|\,|\hat{\mathbf{L}}^{\mathsf{H}}|
$$

を満たす（Higham の 10 章）。
ここで絶対値と不等号は成分ごとにとり、$u$ と $\gamma_k$ は [記号](oxref:sparse-notation) の単位丸めと誤差限界の係数である。
Cauchy–Schwarz の不等式から $(|\mathbf{L}|\,|\mathbf{L}^{\mathsf{H}}|)_{ij} \le \sqrt{a_{ii}\,a_{jj}}$ なので、この後退誤差はおおよそ元の行列の対角の大きさで抑えられ、Cholesky 分解はピボットなしで後退安定になる。
ピボットを数値で選ばないので、疎行列では対称な並べ替え $\mathbf{P}$ をフィルだけで選び、$\mathbf{P}\mathbf{A}\mathbf{P}^{\mathsf{T}} = \mathbf{L}\mathbf{L}^{\mathsf{H}}$ の構造を数値分解の前に確定できる。

`SparseCholesky` は、計算の途中で正でないピボットに出会うと `NumericalInstability`（`Breakdown`）を返す。
浮動小数点で計算したピボットが正でないことは、行列が数値的に正定値とはみなせないことを示すが、元の行列が正定値でないことの証明ではない。
条件数が $1/u$ に近い正定値行列では、丸めでピボットが正でなくなることがある。

### 消去木

$\mathbf{L}$ の第 $j$ 列で対角より下の最初の非零の行を

$$
\mathrm{parent}(j) = \min\{ i > j : l_{ij} \ne 0 \}
$$

と定めると、各頂点 $j$ から $\mathrm{parent}(j)$ へ辺を張ったグラフは森になる。
これが**消去木**である。
$l_{ij} \ne 0$（$i > j$）のときに辺 $j \to i$ を持つ有向グラフを $G(\mathbf{L})$ とすると、消去木は $G(\mathbf{L})$ から推移的に導ける辺を除いたもの（推移的縮約）にあたる。
第 $j$ 列の消去が影響する列は、木の上で $j$ から根に向かう道の上にしかない。
したがって、互いに外側の求解と子孫の関係にない部分木の列は独立に消去でき、木の高さ（葉から根までの道の頂点の数の最大値）が、列を並列に消去したときの段数の目安になる。
`scioxide-sparse` の分解は逐次に行い、この並列性は使わない。

$\mathbf{L}$ の第 $i$ 行の非零の位置は、$\mathbf{A}$ の第 $i$ 行の非零 $a_{ij}$（$j < i$）から消去木を根に向かって $i$ に届くまでたどった頂点の集合になる（行の部分木）。
この性質を使うと、$\mathbf{L}$ を作らずに、各列の非零の数を $\mathbf{A}$ の構造と消去木だけから数えられる。
`SparseSymmetricSymbolic::analyze` は消去木を経路圧縮で求め、各行の部分木をたどって $\mathbf{L}$ の構造を作るので、並べ替えた成分の整列を除けば、その手間は $\mathbf{A}$ と $\mathbf{L}$ の非零の数に比例する程度である。
この構造は値の打ち消しを考えない構造上のフィルで、`cholesky_entries()` がその狭義下三角の要素数を返す。
上限 `max_factor_entries` を超えるフィルは、数値分解の前に記号解析が `ResourceLimit` で拒む。
`elimination_tree()` は、並べ替えたあとの番号での各列の親（根なら `None`）を返す。
数値分解の `SparseCholesky` は、記号解析が求めた構造の位置を値が 0 になっても保存するので、`factor_entries()` は `cholesky_entries()` に等しい。

### 消去木と列の非零の数

次のセルは $k \times k$ 格子の 5 点差分ラプラシアン（対角 4、隣接 $-1$）の下三角を記号解析し、`SparseCholesky` で分解する。
入力は格子の辺の点の数 $k$（2〜5）と、並べ替えを自然順にするか AMD にするかである。
一つ目の表は列ごとの値、二つ目の表は構造上のフィル、保存した要素数、消去木の高さと、二つの検算（親と最初の非零の行の不一致の数、残差）である。
検算として、因子の成分 `lower_entries()` から各列の最初の非零の行を数えて消去木の定義と比べ、`diagonal()` と合わせて組み立てた $\mathbf{L}\mathbf{L}^{\mathsf{T}}$ を、並べ替えた行列 $(\mathbf{P}\mathbf{A}\mathbf{P}^{\mathsf{T}})_{ij} = a_{p_i p_j}$ と比べる。

```rust
//| id: sparse-cholesky-etree
//| ref: sparse-cholesky-etree
//| title: 疎 Cholesky 分解の消去木と列の非零の数
//| run: reactive
//| crates: [scioxide-core, scioxide-sparse]
//| inputs:
//|   grid: {"type":"range","label":"格子の辺の点の数 k","description":"未知数の数は n = k² になる。","min":2,"max":5,"step":1,"value":3}
//|   amd: {"type":"checkbox","label":"AMD で並べ替える（無効なら自然順）","value":false}
//| cases:
//|   - {"id":"amd","label":"AMD","description":"消去木が枝分かれし、構造上のフィルと木の高さが減る。","inputs":{"amd":true}}
//|   - {"id":"natural-five","label":"k = 5、自然順","description":"自然順のフィルは k³ − k² + k − 1 = 104 になる。","inputs":{"grid":5}}
//|   - {"id":"amd-five","label":"k = 5、AMD","description":"格子が大きいほど、自然順との差が広がる。","inputs":{"grid":5,"amd":true}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"columns","path":"/rows/0/2","equals":1}
//|       - {"artifact":"columns","path":"/rows/8/2","equals":null}
//|       - {"artifact":"columns","path":"/rows/0/4","equals":2}
//|       - {"artifact":"summary","path":"/rows/0/0","equals":20}
//|       - {"artifact":"summary","path":"/rows/0/1","equals":20}
//|       - {"artifact":"summary","path":"/rows/0/2","equals":9}
//|       - {"artifact":"summary","path":"/rows/0/3","equals":0}
//|       - {"artifact":"summary","path":"/rows/0/4","range":{"max":1e-14}}
//|   - case: amd
//|     expect:
//|       - {"artifact":"summary","path":"/rows/0/0","equals":17}
//|       - {"artifact":"summary","path":"/rows/0/1","equals":17}
//|       - {"artifact":"summary","path":"/rows/0/2","range":{"max":8}}
//|       - {"artifact":"summary","path":"/rows/0/3","equals":0}
//|       - {"artifact":"summary","path":"/rows/0/4","range":{"max":1e-14}}
//|   - case: natural-five
//|     expect:
//|       - {"artifact":"summary","path":"/rows/0/0","equals":104}
//|       - {"artifact":"summary","path":"/rows/0/3","equals":0}
//|       - {"artifact":"summary","path":"/rows/0/4","range":{"max":1e-14}}
//|   - case: amd-five
//|     expect:
//|       - {"artifact":"summary","path":"/rows/0/0","equals":77}
//|       - {"artifact":"summary","path":"/rows/0/3","equals":0}
//|       - {"artifact":"summary","path":"/rows/0/4","range":{"max":1e-14}}
use scioxide_core::Triangle;
use scioxide_sparse::{
    DuplicatePolicy, ExplicitZeroPolicy, SparseBuilder, SparseCholesky, SparseOrdering,
    SparseSymmetricLimits, SparseSymmetricSymbolic,
};

let k = grid as usize;
let n = k * k;
let mut builder = SparseBuilder::new(n, n);
for p in 0..n {
    builder.push(p, p, 4.0_f64).map_err(|e| e.to_string())?;
    // 下三角だけを与える（左と上の隣）。
    if p % k > 0 {
        builder.push(p, p - 1, -1.0).map_err(|e| e.to_string())?;
    }
    if p >= k {
        builder.push(p, p - k, -1.0).map_err(|e| e.to_string())?;
    }
}
let a = builder
    .finish_csr(DuplicatePolicy::Reject, ExplicitZeroPolicy::Drop)
    .map_err(|e| e.to_string())?;
let ordering = if amd {
    SparseOrdering::FillReducing
} else {
    SparseOrdering::Natural
};
// 因子の要素数と Schur 補行列の上限は密な n² で十分。
// Cholesky は後者を使わないが、作業領域はその分も事前確保する。
let limits = SparseSymmetricLimits::new(n * n, n * n, 1 << 20);
let symbolic = SparseSymmetricSymbolic::analyze(
    a.structural_pattern(),
    ordering,
    Some(Triangle::Lower),
    limits,
)
.map_err(|e| e.to_string())?;
let parents: Vec<Option<usize>> = symbolic.elimination_tree().collect();
let structural = symbolic.cholesky_entries();
let factor = SparseCholesky::factor(symbolic, a.view()).map_err(|e| e.to_string())?;

// 独立検算 1: 因子の各列の最初の非零の行（消去木の定義）と列の非零の数。
let mut first = vec![None::<usize>; n];
let mut counts = vec![0usize; n];
let mut l = vec![0.0_f64; n * n];
for (i, j, v) in factor.lower_entries() {
    first[j] = Some(first[j].map_or(i, |f: usize| f.min(i)));
    counts[j] += 1;
    l[i * n + j] = v;
}
for (j, d) in factor.diagonal().iter().enumerate() {
    l[j * n + j] = *d;
}
// 独立検算 2: L Lᵀ と P A Pᵀ（B[i][j] = A[p[i]][p[j]]、A は下三角だけを保存）を比べる。
let p = factor.permutation();
let mut residual = 0.0_f64;
for i in 0..n {
    for j in 0..=i {
        let llt = (0..=j).fold(0.0, |s, t| s + l[i * n + t] * l[j * n + t]);
        let (r, c) = (p[i].max(p[j]), p[i].min(p[j]));
        residual = residual.max((llt - a.get(r, c).map_err(|e| e.to_string())?).abs());
    }
}
// 消去木の高さ: 各頂点から根までの道の頂点の数の最大値。
let depth = |mut j: usize| {
    let mut d = 1;
    while let Some(q) = parents[j] {
        (j, d) = (q, d + 1);
    }
    d
};
let height = (0..n).map(depth).max().unwrap_or(0);
let mismatches = (0..n).filter(|&j| parents[j] != first[j]).count();

let rows: Vec<_> = (0..n)
    .map(|j| (j, p[j], parents[j], first[j], counts[j]))
    .collect();
let columns = serde_json::json!([
    { "key": "0", "label": "列 j", "type": "integer" },
    { "key": "1", "label": "元の番号 p[j]", "type": "integer" },
    { "key": "2", "label": "親（解析）", "type": "integer", "nullText": "根" },
    { "key": "3", "label": "最初の非零の行（因子）", "type": "integer", "nullText": "根" },
    { "key": "4", "label": "列の非零の数 [個]", "type": "integer" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "columns" })
);
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let summary = serde_json::json!([
    { "key": "0", "label": "cholesky_entries [個]", "type": "integer" },
    { "key": "1", "label": "factor_entries [個]", "type": "integer" },
    { "key": "2", "label": "消去木の高さ [個]", "type": "integer" },
    { "key": "3", "label": "親と最初の非零の不一致 [個]", "type": "integer" },
    { "key": "4", "label": "‖LLᵀ − PAPᵀ‖max [-]", "type": "number", "format": sci2 }
]);
emit_table_with_columns!(
    summary,
    vec![(
        structural,
        factor.factor_entries(),
        height,
        mismatches,
        residual
    )],
    metadata = serde_json::json!({ "id": "summary" })
);
```

既定の $k = 3$ の自然順では、消去木は $0 \to 1 \to 2 \to \cdots \to 8$ の一本の道で、高さは 9 になり、どの列も前の列が終わるまで消去できない。
列の非零の数は 2、3、3、3、3、3、2、1、0 と並び、合計 20 は構造上のフィル `cholesky_entries` と保存した要素数 `factor_entries` に一致する。
自然順では消去によって各列の非零が帯の幅 $k$ の近くまで埋まり、この 20 は $k \times k$ 格子での閉形式 $k^3 - k^2 + k - 1$ に等しい（[2 次元 Poisson 行列の並べ替えとフィル](../../examples/poisson-reordering-fill/) で導く）。
AMD に切り替えると、列 0 と列 1 がともに列 2 を親に持つように木が枝分かれし、高さは 6 に、合計は 17 に減る。
どの入力でも、消去木の親は因子の各列の最初の非零の行と一致し、$\|\mathbf{L}\mathbf{L}^{\mathsf{T}} - \mathbf{P}\mathbf{A}\mathbf{P}^{\mathsf{T}}\|_{\max}$ は $10^{-16}$ の程度になる。
$k = 5$ では自然順の 104（高さ 25）に対して AMD は 77（高さ 12）で、格子が大きいほど並べ替えの差が広がる。

## 不定値行列のブロック LDL 分解

$\mathbf{A}$ が正定値でなければ、Cholesky 分解は負や 0 のピボットで止まる。
$\mathbf{D}$ を対角行列とする $\mathbf{L}\mathbf{D}\mathbf{L}^{\mathsf{H}}$ でもピボットに 0 が現れうるので、たとえば

$$
\begin{pmatrix} 0 & 1 \\ 1 & 0 \end{pmatrix}
$$

は対角のピボットだけでは分解できない。
そこで $\mathbf{D}$ に $2 \times 2$ の Hermitian ブロックも許し、対称な行と列の入れ替え $\mathbf{P}$ と合わせて

$$
\mathbf{P}\mathbf{A}\mathbf{P}^{\mathsf{T}} = \mathbf{L}\mathbf{D}\mathbf{L}^{\mathsf{H}}
$$

と分解する。
$\mathbf{L}$ は対角が 1 の下三角行列、$\mathbf{D}$ は $1 \times 1$ と $2 \times 2$ のブロックからなるブロック対角行列である。
行と列を同じ置換で入れ替えるので、Hermitian 性は保たれる。

### 有界 rook ピボット

どのブロックを選ぶかは、乗数 $\mathbf{L}$ の成分が大きくならないことを基準に決める。
`SparseLdl` は Ashcraft、Grimes、Lewis の有界 rook ピボットを使い、定数 $\alpha = (1 + \sqrt{17})/8 \approx 0.64$ を用いる。
第 $k$ 段では、まだ消去していない Schur 補行列の列 $k$ で、対角以外の成分の大きさの最大 $\omega_k$ を求める。
$\omega_k = 0$ か $|a_{kk}| \ge \alpha\, \omega_k$ なら、$a_{kk}$ を $1 \times 1$ のピボットにする。
そうでなければ、その最大を与える行 $r$ の列について同じ判定を繰り返す。
対角が十分大きい行が見つかればそれを $1 \times 1$ のピボットにし、探索が直前の行に戻るか列の最大が増えなくなったら、最後の二つの行で $2 \times 2$ のピボットを作る。
大きさが等しい候補の間では、並べ替えたあとの番号の小さい行を選ぶ。

$1 \times 1$ のピボットは対角がその列の最大の $\alpha$ 倍以上のときだけ選ぶので、乗数は $|l_{ij}| \le 1/\alpha \approx 1.56$ を満たす。
$2 \times 2$ のピボットでは、ブロックの非対角の大きさ $\omega$ が二つの列のどちらでも最大で、二つの対角はどちらも $\alpha\,\omega$ より小さい。
そのため行列式の大きさは $(1 - \alpha^2)\,\omega^2$ より大きく、乗数は $|l_{ij}| \le (1 + \alpha)/(1 - \alpha^2) = 1/(1 - \alpha) \approx 2.78$ を満たす。
こうして成分の成長が制限される。
$\alpha = (1 + \sqrt{17})/8$ は、$1 \times 1$ のピボットで 2 段消去したときと $2 \times 2$ のピボットで 1 段消去したときの成長の上界 $(1 + 1/\alpha)^2 = 1 + 2/(1 - \alpha)$ を等しくする値で、Bunch と Parlett が導いた。

ピボットの入れ替えは値によって決まるので、LDL 分解のフィルは記号解析が求めた Cholesky の構造より大きくなりうる。
正定値行列でも、対角がその列の対角以外の最大の $\alpha$ 倍に満たない段では、別の行の対角が $1 \times 1$ のピボットに選ばれて入れ替えが起こる。
rook の規則が選ぶ $2 \times 2$ のブロックは行列式が負で、正定値行列の主小行列にはなりえないので、正定値行列では $2 \times 2$ のピボットは現れない。
`SparseSymmetricLimits` の `max_active_entries` は消去の途中の Schur 補行列で保持する下三角の非零（対角を含む）の数を、`max_factor_entries` は $\mathbf{L}$ の狭義下三角の要素数を制限し、超えると `ResourceLimit` で止まる。
Schur 補行列は最初に $\mathbf{A}$ の下三角（対角を含む）の 0 でない値をすべて保持するので、`max_active_entries` はその数以上にする。
厳密に 0 になった $\mathbf{L}$ の成分は保存しないので、`factor_entries()` は `cholesky_entries()` より少ないこともある。
$\omega_k = 0$ で $a_{kk} = 0$ のときは厳密に 0 のピボットになるが、分解はそれを拒まない。
0 のピボットは慣性の分類には使え、その因子で方程式を解こうとすると `Singular` になる。

## Sylvester の慣性法則

Hermitian 行列の**慣性** $\mathrm{In}(\mathbf{A}) = (n_+, n_-, n_0)$ を、正・負・0 の固有値の個数と定める。
Sylvester の慣性法則によれば、正則な $\mathbf{S}$ による合同変換 $\mathbf{S}\mathbf{A}\mathbf{S}^{\mathsf{H}}$ は慣性を変えない。
LDL 分解は $\mathbf{A} = \mathbf{S}\mathbf{D}\mathbf{S}^{\mathsf{H}}$（$\mathbf{S} = \mathbf{P}^{\mathsf{T}}\mathbf{L}$ は正則）という合同変換なので、

$$
\mathrm{In}(\mathbf{A}) = \mathrm{In}(\mathbf{D})
$$

が成り立ち、$\mathbf{D}$ の $1 \times 1$ ブロックの符号と $2 \times 2$ ブロックの固有値の符号を数えれば $\mathbf{A}$ の慣性が分かる。
$\mathbf{A}$ の固有値そのものを計算する必要はない。
同じ考え方で $\mathbf{A} - \sigma\mathbf{I}$ を分解すれば、$\sigma$ より小さい固有値の個数 $n_-$ が分かり、二分法と組み合わせて固有値を区間に閉じ込められる。

慣性は $\mathbf{D}$ の符号から決まるが、$\mathbf{A}$ の固有値の大きさは分からない。
`SparseLdl::inertia()` は計算した $\mathbf{D}$ のブロックの固有値の符号をそのまま数え、厳密に 0 の固有値だけを $n_0$ に入れる。
丸めで生じた小さな固有値を 0 とみなしたいときは、`inertia_with_threshold(threshold, scale)` で、大きさが `threshold.threshold(scale)`（$\tau_{\mathrm{abs}} + \tau_{\mathrm{rel}} \cdot \mathrm{scale}$）以下の固有値を 0 に数える。
この閾値は $\mathbf{D}$ に対するもので、合同変換で保たれる量ではないので、$\mathbf{A}$ の固有値に対する閾値とは一致せず、数値的な階数の推定にとどまる。
`LdlInertia` は `positive()`、`negative()`、`zero()`、`total()` を返す。
`pivot_blocks()` は $\mathbf{D}$ のブロックを `LdlPivotBlock::One { start }` と `LdlPivotBlock::Two { start }` として順に返し、`diagonal()` が $\mathbf{D}$ の対角、`off_diagonal()` が $2 \times 2$ ブロックの $\mathbf{D}_{k+1,k}$ を返す。

### 鞍点系の慣性

等式制約付きの二次計画

$$
\min_{\mathbf{x}} \ \tfrac{1}{2}\mathbf{x}^{\mathsf{T}}\mathbf{H}\mathbf{x} - \mathbf{c}^{\mathsf{T}}\mathbf{x} \quad \text{subject to} \quad \mathbf{B}\mathbf{x} = \mathbf{d}
$$

（$\mathbf{H} \in \mathbb{R}^{n \times n}$ は対称、$\mathbf{B} \in \mathbb{R}^{m \times n}$ は行の階数 $m$）の停留点は、Lagrange 乗数 $\boldsymbol{\lambda}$ とともに KKT 系

$$
\mathbf{K} \begin{pmatrix} \mathbf{x} \\ \boldsymbol{\lambda} \end{pmatrix} = \begin{pmatrix} \mathbf{c} \\ \mathbf{d} \end{pmatrix}, \qquad \mathbf{K} = \begin{pmatrix} \mathbf{H} & \mathbf{B}^{\mathsf{T}} \\ \mathbf{B} & \mathbf{0} \end{pmatrix}
$$

を満たす。
$\mathbf{Z}$ の列を $\mathbf{B}$ の零空間の基底とすると、

$$
\mathrm{In}(\mathbf{K}) = \mathrm{In}(\mathbf{Z}^{\mathsf{T}}\mathbf{H}\mathbf{Z}) + (m, m, 0)
$$

が成り立つ。
$\mathbf{B}$ の行の階数 $r$ が $m$ より小さいときは、$(m, m, 0)$ が $(r, r, m - r)$ に置き換わる。
停留点が狭義の最小点であるための二次の条件は縮約ヘッセ行列 $\mathbf{Z}^{\mathsf{T}}\mathbf{H}\mathbf{Z}$ が正定値であることなので、行の階数が $m$ なら、これは $\mathrm{In}(\mathbf{K}) = (n, m, 0)$ と同値になる。
$\mathbf{H}$ そのものは不定値でもよく、制約の零空間の上で正定値であればよい。
内点法などの最適化の解法はこの慣性を LDL 分解で調べ、$(n, m, 0)$ でなければ $\mathbf{H}$ に正則化を加えて解き直す。

### 鞍点系の慣性と縮約ヘッセ行列

次のセルは $n = 4$、$m = 2$ の鞍点系で $\mathbf{H} = \mathrm{diag}(1, 1, \sigma, \sigma)$、$\mathbf{B} = \begin{pmatrix} 1 & 0 & 1 & 0 \\ 0 & 1 & 0 & 1 \end{pmatrix}$ とする。
$\mathbf{B}$ の零空間は $\mathbf{Z} = (\mathbf{e}_0 - \mathbf{e}_2,\ \mathbf{e}_1 - \mathbf{e}_3)$ で張られ、$\mathbf{Z}^{\mathsf{T}}\mathbf{H}\mathbf{Z} = (1 + \sigma)\mathbf{I}_2$ になる。
入力は $\sigma$（$-3$〜$2$）、$\mathbf{B}$ の二つの行を同じにして制約を従属にするかどうか、消去の順序である。
順序は既定の AMD か、制約の行 4、5 と $\sigma$ の行 2、3 を先に置いた `Supplied` の順序 $[4, 5, 2, 3, 0, 1]$ で、後者では対角が 0 の行から消去が始まる。
一つ目の表は `inertia()`、閾値付きの `inertia_with_threshold`（$\tau_{\mathrm{rel}} = 10^{-12}$、尺度 $\max(1, |\sigma|)$）、上の公式に $\mathbf{Z}^{\mathsf{T}}\mathbf{H}\mathbf{Z}$ の閉形式の固有値を入れた慣性を並べる。
二つ目の表は $\mathbf{D}$ のブロックごとの固有値で、$2 \times 2$ ブロックの固有値と行列式は後で説明する `backend::hermitian` の `block_values` と `determinant` で求める。

既定の $\sigma = -0.5$ では $\mathbf{H}$ は不定値だが、$\mathbf{Z}^{\mathsf{T}}\mathbf{H}\mathbf{Z} = 0.5\,\mathbf{I}$ は正定値なので、三つの数え方はそろって $(4, 2, 0)$ を示し、停留点は狭義の最小点である。
$\sigma = -1$ では縮約ヘッセ行列が 0 になり、慣性は $(2, 2, 2)$ で、$\mathbf{K}$ は特異になる。
$\sigma < -1$ では $(2, 4, 0)$ となり、停留点は最小点ではない。
制約を従属にすると $\mathbf{B}$ の階数 $r$ が 1 に下がり、上の式の $(m, m, 0)$ は $(r, r, m - r) = (1, 1, 1)$ に置き換わる。
このとき零空間は 3 次元になり、$\mathbf{Z} = (\mathbf{e}_1,\ \mathbf{e}_3,\ \mathbf{e}_0 - \mathbf{e}_2)$ にとると $\mathbf{Z}^{\mathsf{T}}\mathbf{H}\mathbf{Z} = \mathrm{diag}(1, \sigma, 1 + \sigma)$ なので、$\sigma = -0.5$ では $(2, 1, 0) + (1, 1, 1) = (3, 2, 1)$ になる。
この例のどの入力でも、0 の固有値に対応するピボットは厳密に 0 になり、`inertia()` は閾値付きの数え方と一致する。
AMD の順序ではどの入力でもすべてのピボットが $1 \times 1$ で選ばれる。
制約の行を先に消去すると、対角が 0 の行 4 から rook ピボットの探索が始まり、$|\sigma| < \alpha$ のとき $2 \times 2$ のピボットが現れる。
$\sigma = -0.5$ では $\begin{pmatrix} 0 & 1 \\ 1 & \sigma \end{pmatrix}$ の形のブロックが二つでき、それぞれの固有値は $-1.281$ と $0.781$、行列式は $-1$ で、正と負を一つずつ数える。
残りの二つの $1 \times 1$ のピボットは $1 + \sigma = 0.5$ なので、慣性は AMD の順序と同じ $(4, 2, 0)$ になる。
Sylvester の慣性法則のとおり、慣性は $\mathbf{D}$ のブロックの選び方によらず $\mathbf{K}$ だけで決まる。

## 2×2 ブロックの範囲安全な算術

$\mathbf{D}$ の $2 \times 2$ ブロック

$$
\mathbf{D}_b = \begin{pmatrix} a & \bar{b} \\ b & c \end{pmatrix}, \qquad a, c \in \mathbb{R}
$$

の固有値は

$$
\lambda = \frac{a + c}{2} \pm \sqrt{\left(\frac{a - c}{2}\right)^2 + |b|^2}
$$

で、行列式は $ac - |b|^2 = \lambda_1 \lambda_2$ である。
行列式の計算には桁落ちと、オーバーフローやアンダーフローの危険があり、大きさの小さい方の固有値を上の式の差で求めると、二つの固有値の大きさが大きく違うときに桁落ちする。
`scioxide_sparse::backend::hermitian` は、`SparseLdl` と scioxide-linalg の密な LDL 分解が共有するこのブロックの算術を、scioxide-core の拡張範囲の値 `Scaled`（指数を別に持つ値）で提供する。
ほとんどの場合、これらを直接呼ぶ必要はない。

- `determinant(a, b, c)` は $ac - |b|^2$ を `Scaled<S::Real>` で返す。
  実数のブロックでは積の差 $ac - b^2$ を共通の指数で 1 回だけ丸め、複素数のブロックでは $b$ の虚部の 2 乗を作って引くときにさらに丸める。
  行列式が 0 になる特異なブロックも正しい結果として返す。
- `block_values(a, b, c)` は二つの固有値を、大きさの大きい方を先にして `[Scaled<S::Real>; 2]` で返す。
  大きい方は同じ符号の二項を足して求め、小さい方は「行列式 ÷ 大きい方の固有値」で求めるので、上の式の差で求めるときの桁落ちを避けられる。
  0 のブロックは二つの 0 を返す。
- `solve_block(a, b, c, x, y)` は $\mathbf{D}_b (u, v)^{\mathsf{T}} = (x, y)^{\mathsf{T}}$ を Cramer の公式で解き、$u$ と $v$ を複素数の拡張範囲の値で返す。
  分子 $cx - \bar{b}y$、$ay - bx$ はそれぞれ 1 回の丸めで作り、`determinant` と同じ方法で求めた行列式で割る。
  計算した行列式が 0 なら `Singular` を返す。
  ブロックの条件数は調べないので、行列式が 0 でなくても残差が小さいとは限らない。

三つの関数は、ブロックの成分（`solve_block` では右辺 $x$、$y$ も）が NaN か無限大なら `NonFinite`、$a$ か $c$ の虚部が 0 でなければ `InvalidInput`、結果が `Scaled` の指数の範囲を超えれば `NumericalInstability` を返す。
結果は拡張範囲の値なので、スカラーへの丸めは呼び出し側が `round()` で行う。
どれも定数の手間とメモリで、確保しない。
結果は推定値であり、包含が保証された区間ではない。

`SparseLdl` は、慣性を数えるときに $2 \times 2$ ブロックの固有値を `block_values` で求める。
$2 \times 2$ のピボットの連立方程式（分解での乗数の計算と、求解での $\mathbf{D}$ の作用）は、`Standard` の精度なら通常の浮動小数点演算の Cramer の公式で解く。
途中の積や和、行列式、分子が正規化数の範囲を外れたとき（行列式が 0 のときを含む）と、`Exact` の精度のときだけ `solve_block` を使う。

## 記号解析・分解・求解

対称な分解の計算も構造だけを見る記号解析と値を使う数値分解に分かれる。
Cholesky 分解では、並べ替え $\mathbf{P}$、消去木、$\mathbf{L}$ の構造がすべて記号解析で決まり、数値分解は値だけを計算する。
LDL 分解では、記号解析が決めるのは最初の並べ替えと Cholesky の構造までで、ピボットの入れ替え、$2 \times 2$ ブロック、追加のフィルは数値分解で決まる。

1. `SparseSymmetricSymbolic::analyze(pattern, ordering, triangle, limits)` は正方な構造を解析する。
   `triangle` が `Some(Triangle::Lower)` か `Some(Triangle::Upper)` なら、その三角だけを値として読み、反対の三角の成分は無視する。
   `None` なら両方の三角を読み、数値分解のたびに行列が厳密に Hermitian であることを確かめる。
   読まない三角も構造の一部で、あとで渡す行列と構造を比べるときにも使う。
   `ordering` の既定 `SparseOrdering::FillReducing` は、読む三角が表す対称な構造の AMD である。
   正方でない構造と長さの違う置換は `DimensionMismatch`、構造上の Cholesky のフィルが `max_factor_entries` を、解析と順序付けの一時的な領域がバイト数の上限を超えると `ResourceLimit` で拒む。
2. 標準形式の `SparseCholesky::factor(symbolic, matrix)` と `SparseLdl::factor` は記号解析を所有して数値分解を行い、スコープ付き API の `factor_scoped(symbolic, matrix, options, scope)` は同じ分解を実行コンテキストの中で行う。
   どちらも因子と一時的な作業領域を確保する。
   因子は記号解析を所有するので、同じ記号解析から別の因子を作るときは `try_clone()` で写しを作る。
   Cholesky 分解は上向き（$\mathbf{L}$ を行ごとに作る）で、各行の非零は消去木の行の部分木になる。
   `permutation()` は最終的な置換（LDL では数値的な入れ替えも含む）、`factor_entries()` は保存した狭義下三角の要素数、`lower_entries()` は並べ替えたあとの座標の成分、`diagonal()` は Cholesky の $\mathbf{L}$ の対角または LDL の $\mathbf{D}$ の対角を返す。
   `SparseSolveOptions::with_budgets` で反復回数の上限を与えると、分解は因子の 1 行ごとに 1 回（LDL の $2 \times 2$ のピボットは 2 回）と数え、上限に達すると `ConvergenceFailure`（`IterationLimit`）を返す。
3. `refactor(matrix, options, workspace, scope)` は、構造が厳密に一致する新しい値で分解をやり直し、構造・上限・数値のどの失敗でも直前の因子を保つ。
   構造の違う行列、実数でない対角、`triangle = None` での厳密に Hermitian でない値は `InvalidInput`、形の違う行列と別の記号解析のために事前確保した作業領域は `DimensionMismatch` で拒む。
   数値の失敗は Cholesky の正でないピボットの `NumericalInstability`（`Breakdown`）と、LDL の行列式が 0 の $2 \times 2$ ブロックの `Singular` である。
   作業領域 `SparseSymmetricWorkspace` は記号解析の `workspace(())` で作るか、`workspace_requirements(())` が返す `SparseSymmetricRequirements`（`symbolic_bytes()`、`factor_bytes()`、`workspace_bytes()`、`total_bytes()`）に対して事前確保し、再分解では確保しない。
   作業領域は 2 つ目の因子と、LDL の Schur 補行列を `max_active_entries` の大きさで含む。
4. 求解は LU と同じく、出力先を指定する API の `solve_into`、`solve_block_into`、標準形式の `solve` と、共通の `SparseSolveWorkspace` を使う。
   求解用の領域は `SparseSymmetricRequirements` に含まれず、`factor.workspace_requirements(rhs)` で別に求める。
   0 のピボットを持つ LDL の因子での求解は `Singular` になる。
   因子は `LinearOperator` を実装し、$\mathbf{A}^{-1}$ の作用として反復解法に渡せる。

`SparseSymmetricLimits::new(max_factor_entries, max_active_entries, max_workspace_bytes)` の `max_factor_entries` は因子の領域の大きさでもあり、因子と作業領域はこの要素数の領域を事前確保する。
Cholesky 分解では `cholesky_entries()` と同じ値で足り、LDL 分解ではピボットの入れ替えによるフィルの分だけ大きく与える。

準備を一括して行うコンストラクター `SparseCholesky::new(&a)` と `SparseLdl::new(&a)` は、両方の三角を保存した行列を `FillReducing` の順序と `triangle = None` で解析し、バイト数の上限なしで分解までを一度に行う。
`SparseCholesky::new` は記号解析の `cholesky_entries()` をそのまま因子の要素数の上限にするので、分解は 1 回で済む。
`SparseLdl::new` は要素数の上限 $c$ を `cholesky_entries()` から始め、Schur 補行列の上限を $\min(c + n, n(n + 1)/2)$ とし、`ResourceLimit` のたびに $c$ を倍にして密な狭義下三角の $n(n - 1)/2$ で止める。
ピボットの入れ替えが起きなければ最初の試行で成功し、入れ替えでフィルが増えると試行を繰り返す。
正定値行列でも入れ替えは起こりうる（[有界 rook ピボット](#有界-rook-ピボット)）ので、1 回で済むとは限らない。
どちらの結果も十分な上限で `analyze` と `factor` を呼んだ場合と同じ因子である。

## まとめ

正定値 Hermitian 行列では Cholesky 分解がピボットなしで後退安定に計算でき、並べ替えはフィルだけで選べるので、`cholesky_entries` で構造上のフィルを数値分解の前に確かめて上限を決められる。
消去木は列の依存関係を表し、その高さと枝分かれが並べ替えの良し悪しを示す。
不定値行列には有界 rook ピボットのブロック LDL 分解を使い、ピボットの入れ替えでフィルが Cholesky の構造より増えうることを `max_factor_entries` と `max_active_entries` で見込んでおく。
LDL 分解の $\mathbf{D}$ から慣性が分かり、鞍点系では $\mathrm{In}(\mathbf{K}) = (n, m, 0)$ かどうかで停留点が狭義の最小点かを判定できる。
丸めで生じる小さなピボットを 0 とみなすかどうかは、`inertia_with_threshold` で閾値を明示して決める。
