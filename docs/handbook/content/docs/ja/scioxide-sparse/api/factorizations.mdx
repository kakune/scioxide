この表は疎行列の直接解法の項目をまとめる。
LU、Cholesky・LDL、QR は、それぞれ不変な記号解析（`SparseLuSymbolic` などの `*Symbolic`）、記号解析を所有する数値因子、再分解の作業領域の型と、上限（`*Limits`）と要件（`*Requirements`）の型を持つ。

ワンショット関数 `solve`・`least_squares` と準備を一括して行うコンストラクター `SparseLu::new(&a)` などは、上限を受け取らず、AMD の順序で記号解析してから数値分解する。
要素数の上限は推定値から始めて `ResourceLimit` のたびに倍にし（Cholesky は解析が予測したフィルちょうど）、バイト数の上限は課さない。
標準形式 `factor(symbolic, matrix)` は既定の `SparseSolveOptions` と `ExecutionContext::sequential_native()` で、スコープ付き API `factor_scoped(symbolic, matrix, options, scope)` は呼び出し側のオプションとスコープで分解し、どちらも因子と一時的な作業領域を確保する。

再分解 `refactor` は解析と同じ構造（保存された 0 を含む）の行列だけを受け付け、事前確保済みの作業領域に候補を作ってから入れ替える。
`refactor` は確保せず、失敗しても前回成功した因子（置換と値を含む）はそのまま使える。
数値分解は逐次で、LU と QR は列ごと、Cholesky と LDL は行ごとに反復回数を 1 回と数える。
上限を超えると `ResourceLimit`、オプションかスコープの反復回数の上限に達すると `ConvergenceFailure`（`IterationLimit`）を返す。

三角系・LU・Cholesky・LDL の因子は `LinearOperator`、`AdjointOperator`、`BlockOperator` を $\mathbf{A}^{-1}$ の作用として実装するので、反復解法に渡せる。
これらの実装は既定のオプションで動き、反復回数に数えない。
`SparseQr` は作用素のトレイトを実装せず、方程式は `SparseQrMinimumNormPlan` で解く。

## Hermitian のピボットブロックと慣性

[`backend::hermitian`](https://docs.rs/scioxide-sparse/0.1.0/scioxide_sparse/backend/hermitian/index.html) モジュールは、密と疎の LDL 分解が共有する $2 \times 2$ ブロック $\begin{pmatrix} a & \bar{b} \\ b & c \end{pmatrix}$（$a$、$c$ は実数）の行列式、固有値、連立方程式の解を求める三つの関数を提供する。
三つの関数は、成分が有限で対角が実数のブロックを受け取り、途中の値を指数を別に持つ拡張範囲値 `Scaled` で計算するので、桁あふれもアンダーフローも起こさない。
結果も拡張範囲値で返し、スカラー型へ丸める時点は呼び出し側が決める。
どれも定数の手間とメモリで動き、確保しない。
慣性 `LdlInertia` とピボットのブロック `LdlPivotBlock` はクレートのルートにある。
