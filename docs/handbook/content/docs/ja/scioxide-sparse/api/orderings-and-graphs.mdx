この表は疎行列の構造を使う並べ替え・彩色と、グラフアルゴリズムの項目をまとめる。
並べ替え、彩色、構造の転置は値を読まず、`scioxide_core::StructuralPatternView` を受け取る。
行列や構造から作るグラフでは、保存された要素（値が 0 のものを含む）が辺になる。
最大流だけは容量付きの辺 `CapacityEdge` の列から網を作る。
重みと計算コストは有限なので、距離、次数、重みの和が無限大になれば、桁あふれとして `NumericalInstability`（`Overflow`）を返す。

ワンショット関数（`shortest_paths`、`connected_components`、`maximum_flow`、`maximum_bipartite_matching`、`minimum_cost_assignment`、`laplacian`）は、問題のデータから答えを返す。
このうち `shortest_paths` は始点から届く負の閉路を、`minimum_cost_assignment` は完全な割当てがないことを `DomainError` で返す。
Plan（`GraphPlan`、`MaxFlowPlan`、`AssignmentPlan`）のメソッドは、同じ状況を `PathOutcome::NegativeCycle` と `AssignmentOutcome::Infeasible` の値で返す。
二部マッチングは Plan を持たず、作業領域の型が要件を答える。

Plan を一度準備すれば、作業領域を事前確保して、確保なしに繰り返し解ける。
Plan の標準形式（`shortest_paths`、`maximum_flow`、`solve`）は、上限のない既定の `GraphExecutionOptions` と新しい作業領域を使い、`ExecutionContext::sequential_native()` で実行する。
スコープ付き API（`shortest_paths_scoped`、`maximum_flow_scoped`、`solve_scoped`、`maximum_bipartite_matching_scoped`）は、オプション、作業領域、根か子のスコープを受け取り、事前確保した作業領域の中で確保せずに計算する。
足りない作業領域は広げずに `DimensionMismatch` で拒み、反復回数の上限に達すると `ConvergenceFailure`、取り消しや期限切れでは `ExecutionStopped` を返す。
結果は作業領域を借用し、失敗したときは部分結果を出力に反映しない。
直前の試行の成否と数えた反復は、作業領域の `last_attempt()` で読む。
探索、連結成分、全域森は手間の決まった計算で、スコープを取らない。

| [`LaplacianDegree`](https://docs.rs/scioxide-sparse/0.1.0/scioxide_sparse/enum.LaplacianDegree.html) | 列挙型 | 有向グラフの次数の取り方 | $w_{uv}$ を $u \to v$ の辺の重みとして、`Out` は出次数 $d_u = \sum_v w_{uv}$（行和。正規化しない形では $\mathbf{L}\mathbf{1} = \mathbf{0}$）、`In` は入次数 $d_v = \sum_u w_{uv}$（列和。$\mathbf{1}^{\mathsf{T}}\mathbf{L} = \mathbf{0}^{\mathsf{T}}$）。無向グラフでは両者は同じ | [グラフのラプラシアン](oxref:sparse-graph-laplacian) | [重み 0 の橋とラプラシアンの零空間](oxref:sparse-laplacian-null-space)、[格子の抵抗回路網の有効抵抗と Foster の和](oxref:sparse-resistor-foster)、[シフト付き逆反復によるラプラシアンの λ₂ と Fiedler ベクトル](oxref:sparse-spectral-bisection) |

| [`LaplacianPlan`](https://docs.rs/scioxide-sparse/0.1.0/scioxide_sparse/struct.LaplacianPlan.html) | 構造体 | Laplacian を CSR 行列で持つ作用素 | Plan の `laplacian::<T>(degree, normalization)` が作る。重みは実数で、行列の型 `T` は同じ精度の実数か複素数から選ぶ。行列は対角と、異なる頂点を結ぶ各辺（重み 0 を含む）に 1 要素ずつ保存する。負の重み（自己ループを含む）は `DomainError`、次数の桁あふれは `NumericalInstability`（`Overflow`）、`Symmetric` で正の重みが 0 に丸められると `NumericalInstability`（`Underflow`）。`degrees()`（自己ループを除く）、`matrix()`、`into_matrix()`（コピーしない）。`Symmetric` の行列は厳密に Hermitian とは限らないので、`SparseCholesky` などに渡す前に $(\mathbf{L} + \mathbf{L}^{\mathsf{T}})/2$ で対称にする。`LinearOperator`、`AdjointOperator`、`BlockOperator` を実装する | [グラフのラプラシアン](oxref:sparse-graph-laplacian)、[組立てと接地](oxref:sparse-resistor-grounding) | [重み 0 の橋とラプラシアンの零空間](oxref:sparse-laplacian-null-space)、[シフト付き逆反復によるラプラシアンの λ₂ と Fiedler ベクトル](oxref:sparse-spectral-bisection)、[格子の抵抗回路網の有効抵抗と Foster の和](oxref:sparse-resistor-foster) |
