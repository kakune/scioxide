このページの表は疎行列を組み立てて正準な形式に確定する項目と、形式の変換、算術、積の項目をまとめる。
保存された値はすべて有限で、非有限な値は追加と構築の時点で `NonFinite` として拒まれる。

確定した行列の構造（値を保存する位置）は、値を更新しても変わらない。
COO・CSR・CSC は `set_value`、`copy_values_from`、`update_values` で値だけを書き換えられ、CSR だけは `try_assign_pattern` で構造ごと置き換えられる（値はすべて 0 になる）。
BSR と DIA は値を更新する方法を持たない。

行列ベクトル積、算術、疎行列の積は、既定で `scioxide_core::Accuracy::Standard`（桁あふれを避けるために再尺度化する通常の浮動小数点演算）を使う。
`Exact` を選ぶと、各和を厳密に累積して一回だけ丸める。
出力を書き込む演算は検査と計算を終えてから書き込むので、失敗しても出力と行列は変わらない。
