偏微分方程式を細かい格子で解くとき、反復法の手間は「一回の反復の手間 × 反復回数」で決まる。
一回の反復の手間は未知数の数 $N$ に比例するので、反復回数が格子の細かさによらなければ、全体の手間は $O(N)$ で済む。
この例題では 2 次元 Poisson 方程式を共役勾配法（CG）で解き、Jacobi、不完全 Cholesky 分解 IC(0)、平滑化集約の代数的多重格子（AMG）の三つの前処理について、格子を細かくしたときの反復回数を比べる。
独立な検算として、条件数の閉じた形から導く反復回数の上界と増え方（Jacobi では格子の辺の点の数 $n$ にほぼ比例）、各段の非零の数から数え直した演算子複雑度を使う。

## 条件数と反復回数

対称正定値な $\mathbf{A}$ に、対称正定値な前処理 $\mathbf{M}$ を付けた CG の $k$ 回目の誤差 $\mathbf{e}_k = \mathbf{x}_k - \mathbf{x}^\ast$ は、エネルギーノルム $\|\mathbf{e}\|_{\mathbf{A}} = \sqrt{\mathbf{e}^{\mathsf{T}}\mathbf{A}\mathbf{e}}$ で

$$
\|\mathbf{e}_k\|_{\mathbf{A}} \le 2\rho^k\,\|\mathbf{e}_0\|_{\mathbf{A}}, \qquad \rho = \frac{\sqrt{\kappa} - 1}{\sqrt{\kappa} + 1}, \qquad \kappa = \kappa(\mathbf{M}^{-1}\mathbf{A})
$$

で抑えられる（$\kappa$ は $\mathbf{M}^{-1}\mathbf{A}$ の最大と最小の固有値の比）。
`CgSolver` が停止を判定するのは誤差ではなく残差である。
漸化式で更新した残差が許容誤差を満たすと（50 回ごとと、反復回数の上限に達したときにも）、真の残差 $\mathbf{r}_k = \mathbf{b} - \mathbf{A}\mathbf{x}_k$ を計算し直し、$\|\mathbf{r}_k\|_2 \le \mathrm{atol} + \mathrm{rtol}\,\|\mathbf{b}\|_2$ を満たしたときにだけ `Converged` で止まる。
そこで $\lambda_{\min}(\mathbf{A})\|\mathbf{e}\|_{\mathbf{A}}^2 \le \|\mathbf{A}\mathbf{e}\|_2^2 \le \lambda_{\max}(\mathbf{A})\|\mathbf{e}\|_{\mathbf{A}}^2$ で評価を残差に移す。
$\mathbf{x}_0 = \mathbf{0}$ から始めると

$$
\frac{\|\mathbf{r}_k\|_2}{\|\mathbf{b}\|_2} \le 2\sqrt{\kappa(\mathbf{A})}\,\rho^k
$$

となり、右辺が許容誤差 $\varepsilon$ 以下になる最小の回数

$$
k_\kappa = \left\lceil \frac{\ln\bigl(2\sqrt{\kappa(\mathbf{A})}/\varepsilon\bigr)}{\ln(1/\rho)} \right\rceil \approx \frac{\sqrt{\kappa}}{2}\,\ln\frac{2\sqrt{\kappa(\mathbf{A})}}{\varepsilon}
$$

が、厳密な算術での反復回数の上界になる。

$n \times n$ 格子の 5 点差分ラプラシアン（対角が 4、上下左右の隣が $-1$、格子幅 $h = 1/(n + 1)$）の固有値は $4 - 2\cos(i\pi h) - 2\cos(j\pi h)$（$1 \le i, j \le n$）である。
最大と最小は $i = j = n$ と $i = j = 1$ のときで、$\cos(n\pi h) = -\cos(\pi h)$ から

$$
\kappa(\mathbf{A}) = \frac{1 + \cos(\pi h)}{1 - \cos(\pi h)} = \cot^2\frac{\pi h}{2} \approx \frac{4}{\pi^2 h^2}
$$

となる。
$\sqrt{\kappa(\mathbf{A})} \approx 2(n + 1)/\pi$ なので、前処理のない CG の上界 $k_\kappa$ は対数の因子を除いて $n = \sqrt{N}$ に比例して増える。
この行列は対角がすべて 4 なので、Jacobi 前処理 $\mathbf{M} = 4\mathbf{I}$ は行列全体を定数で割るだけで、厳密な算術では前処理のない CG と同じ反復をたどり、条件数も反復回数も変わらない。
IC(0) は条件数の定数を小さくするが、$O(h^{-2})$ の増え方は変えないので、反復回数はやはり $n$ にほぼ比例して増える。
条件数を $O(h^{-1})$ に下げる修正不完全 Cholesky 分解（MIC、Gustafsson, 1978）は scioxide-sparse では提供しないので、増え方を変えるには多重格子を使う。
多重格子法は平滑化と粗い格子の補正を組み合わせて誤差のすべての周波数を一定の割合で減らすので、Poisson 方程式のような楕円型の問題では反復回数がほとんど $n$ によらなくなる（[代数的多重格子による前処理](../../algorithms/algebraic-multigrid/)）。

### 演算子複雑度

AMG の階層は細かい格子の行列 $\mathbf{A}_0 = \mathbf{A}$ から粗い格子の行列 $\mathbf{A}_1, \mathbf{A}_2, \dots$ を作る。
一回の作用の手間は平滑化の回数と演算子複雑度

$$
C_{\mathrm{op}} = \frac{\sum_{\ell} \mathrm{nnz}(\mathbf{A}_\ell)}{\mathrm{nnz}(\mathbf{A}_0)}
$$

でおよそ見積もれる。
$C_{\mathrm{op}}$ が 1 に近い定数にとどまれば、V サイクルの一回の作用は細かい格子の行列ベクトル積の定数倍の手間で済み、反復回数が一定なら全体の手間は $O(N)$ に近づく。
`AmgHierarchy::diagnostics()` が返す `AmgDiagnostics` の `operator_complexity()` はこの比で、`levels()` は段の数、`termination()` は粗くするのを止めた理由（`AmgSetupTermination` の `CoarseSize`、`LevelLimit`、`Stagnation`）である。
これらはサイクルの手間の見積もりで、収束の速さを予測しない。

## 格子の大きさと反復回数

次のセルは $n = 16, 32, 48, 64$（$N = n^2$ は 256〜4096）の 5 点差分ラプラシアンについて、右辺 $\mathbf{b} = \mathbf{1}$ を scioxide-linalg の `CgSolver` で解く。
停止条件は $\|\mathbf{r}\|_2 \le 10^{-8}\|\mathbf{b}\|_2$（`ResidualTolerance::new(0.0, 1e-8)`）、反復回数の上限は 2000 回である。
前処理は準備を一括して行うコンストラクター `JacobiPreconditioner::new` と `IncompleteFactor::ic0` で作る Jacobi と IC(0)、`AmgHierarchy::build` と `AmgPreconditioner::build` で作る AMG の三つである。
AMG は定数ベクトルを近零空間のモードとし、粗くする設定は既定（`AmgSetupOptions::new()`：粗い格子の大きさ 16、強さの閾値 1/16）、上限は `AmgLimits::default()`（64 段まで、要素数とバイト数の上限なし）で、最も粗い行列を `SparseCholesky` で分解する（分解の上限は `SparseSymmetricLimits` で与える）。
準備を一括して行うコンストラクター `AmgPreconditioner::new` も同じ階層を作るが、サイクルは V サイクルで前後 1 回ずつの平滑化に決まっているので、サイクルを入力で変えるこのセルは `build` を使う。
三つとも scioxide-core の `Preconditioner` を実装し、`Preconditioning::Inverse` でオプション付き形式 `solve_with_options` に渡す。
CG の前処理は対称正定値でなければならない。
AMG のサイクルがそうなるには、前後の平滑化が互いに随伴で回数が等しいこと、各段で $\mathbf{R} = \mathbf{P}^{\mathsf{T}}$ であること、最も粗い段の解法が対称正定値であることが要る（[前処理としての使い方](oxref:sparse-amg-as-preconditioner)）。
`AmgPreconditioner` は減衰 Jacobi の平滑化、$\mathbf{R} = \mathbf{P}^{\mathsf{T}}$、最も粗い段の Cholesky 分解を使うので、残る条件は前後の回数だけである。
`AmgCycleOptions` は前と後の回数を別々に設定できるので、このセルは両方を $\nu$ にそろえる。

入力は AMG の前後の平滑化の回数 $\nu$（1〜3）とサイクルの種類（V か W）である。
表には格子と前処理ごとの反復回数、終了理由、真の相対残差 $\|\mathbf{r}\|_2/\|\mathbf{b}\|_2$ を示す。
反復回数は次のセルで閉じた形から求める上界 $k_\kappa$ と比べる。
このセルは許容誤差、格子ごとの AMG の階層の診断（段の数、`operator_complexity()`、各段の行列の `nnz()` から数え直した演算子複雑度、粗くするのを止めた理由）、各求解の反復回数・終了理由・成否、最も細かい格子の AMG 前処理付き CG が破綻したかどうかを次のセルに渡す。
12 回の求解に時間がかかるのでボタンで実行し、同じ入力の結果は再利用する。

```rust
//| id: sparse-amg-convergence
//| ref: sparse-amg-convergence
//| title: 2 次元 Poisson 方程式の CG の反復回数と格子の大きさ
//| run: button
//| cache: inputs
//| crates: [scioxide-core, scioxide-sparse, scioxide-linalg]
//| exports: [epsilon, hierarchies, solves, converged, breakdown]
//| inputs:
//|   sweeps: {"type":"range","label":"AMG の前後の平滑化の回数 ν","description":"サイクルの各段で、粗い格子の補正の前と後に行う減衰 Jacobi の回数。","min":1,"max":3,"step":1,"value":1}
//|   cycle: {"type":"select","label":"AMG のサイクル","description":"各段で粗い格子の補正を 1 回（V）か 2 回（W）行う。","options":["V","W"],"value":"V"}
//| cases:
//|   - {"id":"two-sweeps","label":"ν = 2","description":"平滑化を増やすと AMG の反復回数は減るが、一回の作用の手間は増える。","inputs":{"sweeps":2}}
//|   - {"id":"w-cycle","label":"W サイクル","description":"粗い格子の補正を 2 回行い、反復回数の格子への依存がさらに小さくなる。","inputs":{"cycle":"W"}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"solves","path":"/rows/0/2","range":{"min":20,"max":116}}
//|       - {"artifact":"solves","path":"/rows/9/2","range":{"min":100,"max":473}}
//|       - {"artifact":"solves","path":"/rows/10/2","range":{"min":40,"max":119}}
//|       - {"artifact":"solves","path":"/rows/2/2","range":{"max":20}}
//|       - {"artifact":"solves","path":"/rows/11/2","range":{"max":20}}
//|       - {"artifact":"solves","path":"/rows/11/3","equals":"Converged"}
//|       - {"artifact":"solves","path":"/rows/11/4","range":{"max":1e-8}}
//|   - case: two-sweeps
//|     expect:
//|       - {"artifact":"solves","path":"/rows/11/2","range":{"max":15}}
//|       - {"artifact":"solves","path":"/rows/11/3","equals":"Converged"}
//|       - {"artifact":"solves","path":"/rows/11/4","range":{"max":1e-8}}
//|   - case: w-cycle
//|     expect:
//|       - {"artifact":"solves","path":"/rows/2/2","range":{"max":15}}
//|       - {"artifact":"solves","path":"/rows/11/2","range":{"max":15}}
//|       - {"artifact":"solves","path":"/rows/11/3","equals":"Converged"}
use scioxide_core::{
    BlockVectorView, Budget, ExecutionContext, Preconditioner, ResidualTolerance,
};
use scioxide_linalg::{CgSolver, LinearSolveTermination, Preconditioning};
use scioxide_sparse::{
    AmgCycleKind, AmgCycleOptions, AmgHierarchy, AmgLimits, AmgPreconditioner, AmgSetupOptions,
    CsrMatrix, DuplicatePolicy, ExplicitZeroPolicy, IncompleteFactor, JacobiPreconditioner,
    SparseBuilder, SparseSolveOptions, SparseSymmetricLimits,
};

let kind = if cycle == "W" {
    AmgCycleKind::W
} else {
    AmgCycleKind::V
};
let cycle_options = AmgCycleOptions::new()
    .with_kind(kind)
    .with_pre_sweeps(sweeps as usize)
    .with_post_sweeps(sweeps as usize);
let (options, scope) = (SparseSolveOptions::new(), ExecutionContext::sequential());
let epsilon = 1e-8;
let tolerance = ResidualTolerance::new(0.0, epsilon).map_err(|e| e.to_string())?;
let budget = Budget::try_from(2000).map_err(|e| e.to_string())?;
let solver = CgSolver::new(tolerance, budget);
// 5 点差分: 格子点 (i, j) を番号 p = i n + j に置き、対角 4、上下左右の隣に −1。
let poisson = |n: usize| -> Result<CsrMatrix<f64>, String> {
    let mut builder = SparseBuilder::new(n * n, n * n);
    for (i, j) in (0..n).flat_map(|i| (0..n).map(move |j| (i, j))) {
        let p = i * n + j;
        let neighbors = [
            (j > 0, p.wrapping_sub(1)),
            (j + 1 < n, p + 1),
            (i > 0, p.wrapping_sub(n)),
            (i + 1 < n, p + n),
        ];
        builder.push(p, p, 4.0).map_err(|e| e.to_string())?;
        for (_, q) in neighbors.into_iter().filter(|e| e.0) {
            builder.push(p, q, -1.0).map_err(|e| e.to_string())?;
        }
    }
    builder
        .finish_csr(DuplicatePolicy::Reject, ExplicitZeroPolicy::Drop)
        .map_err(|e| e.to_string())
};
let names = ["Jacobi", "IC(0)", "AMG"];
let (mut hierarchies, mut solves, mut converged) = (Vec::new(), Vec::new(), Vec::new());
let mut finest = None;
for n in [16usize, 32, 48, 64] {
    let (a, size) = (poisson(n)?, n * n);
    let b = vec![1.0_f64; size];
    let jacobi = JacobiPreconditioner::new(&a).map_err(|e| e.to_string())?;
    let ic = IncompleteFactor::ic0(&a).map_err(|e| e.to_string())?;
    let modes = BlockVectorView::new(&b, size, 1).map_err(|e| e.to_string())?;
    let hierarchy = AmgHierarchy::build(
        a.view(),
        modes,
        AmgSetupOptions::new(),
        AmgLimits::default(),
        options,
        scope,
    )
    .map_err(|e| e.to_string())?;
    let coarse_limits = SparseSymmetricLimits::new(1 << 12, 1 << 12, 1 << 22);
    let amg = AmgPreconditioner::build(hierarchy, cycle_options, coarse_limits, options, scope)
        .map_err(|e| e.to_string())?;
    let d = amg.hierarchy().diagnostics();
    // 演算子複雑度を各段の行列の非零の数から数え直す（独立な検算）。
    let entries: usize = (0..d.levels())
        .filter_map(|level| amg.hierarchy().matrix(level))
        .map(|m| m.nnz())
        .sum();
    let recount = entries as f64 / a.nnz() as f64;
    let setup = format!("{:?}", d.termination());
    hierarchies.push((n, d.levels(), d.operator_complexity(), recount, setup));
    let preconditioners: [&dyn Preconditioner<f64>; 3] = [&jacobi, &ic, &amg];
    for (name, preconditioner) in names.into_iter().zip(preconditioners) {
        let result = solver
            .solve_with_options(&a, &b[..], Preconditioning::Inverse(preconditioner), None)
            .map_err(|e| e.to_string())?;
        let report = result.report();
        let termination = report.termination();
        let residual = report.true_residual().map(|r| r.scaled_norm());
        let status = format!("{termination:?}");
        solves.push((n, name, report.iterations(), status, residual));
        converged.push(termination.is_success());
        // 最後に残るのは最も細かい格子（n = 64）の AMG 前処理付き CG の終了状態。
        finest = Some(termination);
    }
}
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let columns = serde_json::json!([
    { "key": "0", "label": "n", "type": "integer" },
    { "key": "1", "label": "前処理" },
    { "key": "2", "label": "反復回数 [回]", "type": "integer" },
    { "key": "3", "label": "終了理由" },
    { "key": "4", "label": "相対残差 [-]", "type": "number", "format": sci3, "nullText": "なし" }
]);
emit_table_with_columns!(
    columns,
    solves,
    metadata = serde_json::json!({ "id": "solves" })
);
// 判定に使う最後の求解の成否は converged に、破綻したかどうかは breakdown に入れる。
let finest = finest.ok_or("AMG の行がない")?;
let breakdown = matches!(finest, LinearSolveTermination::Breakdown(_));
export!(epsilon, epsilon);
export!(hierarchies, hierarchies);
export!(solves, solves);
export!(converged, converged);
export!(breakdown, breakdown);
```

次のセルは前のセルの結果を受け取り、格子ごとに $\kappa(\mathbf{A}) = \cot^2(\pi h/2)$ と上界 $k_\kappa$（$\kappa(\mathbf{M}^{-1}\mathbf{A}) = \kappa(\mathbf{A})$ となる Jacobi の値）を閉じた形から計算する。
表は $\kappa(\mathbf{A})$、$k_\kappa$ と AMG の階層の診断で、`operator_complexity()` と数え直した値が一致することを確かめる。
グラフは許容誤差を満たした求解の反復回数と $n$ の両対数で、上界 $k_\kappa$ を破線で描く。
最後の判定には最も細かい格子の AMG 前処理付き CG の終了状態 `LinearSolveTermination` を使う。
`is_success()` が真（`Converged`）なら満たした、`Breakdown` なら失敗、それ以外（反復回数の上限、停滞、実行の停止など）なら途中で止まったと示す。
このセルは前のセルの入力に従い、自分の入力を持たない。

```rust
//| id: sparse-amg-convergence-report
//| ref: sparse-amg-convergence-report
//| title: CG の反復回数と条件数による上界、AMG の階層の診断
//| run: reactive
//| crates: [scioxide-core]
//| dependsOn:
//|   solved: sparse-amg-convergence
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"grids","path":"/rows/3/1","approx":{"value":1711.661375826,"rtol":1e-9}}
//|       - {"artifact":"grids","path":"/rows/3/2","equals":473}
//|       - {"artifact":"grids","path":"/rows/3/4","approx":{"value":1.3640723892,"rtol":1e-9}}
//|       - {"artifact":"grids","path":"/rows/3/5","approx":{"value":1.3640723892,"rtol":1e-9}}
//|       - {"artifact":"grids","path":"/rows/3/6","equals":"CoarseSize"}
//|       - {"path":"/outputs/2/state","equals":"satisfied"}
use scioxide_core::RealScalar;

let epsilon = solved["epsilon"].as_f64().ok_or("許容誤差がない")?;
let hierarchies: Vec<(usize, usize, Option<f64>, f64, String)> =
    serde_json::from_value(solved["hierarchies"].clone()).map_err(|e| e.to_string())?;
let solves: Vec<(usize, String, usize, String, Option<f64>)> =
    serde_json::from_value(solved["solves"].clone()).map_err(|e| e.to_string())?;
let converged: Vec<bool> =
    serde_json::from_value(solved["converged"].clone()).map_err(|e| e.to_string())?;
let (mut grids, mut bounds) = (Vec::new(), Vec::new());
for (n, levels, complexity, recount, setup) in hierarchies {
    // κ(A) = cot²(πh/2) と、‖r_k‖/‖b‖ ≤ 2√κ ρ^k から決まる上界 k_κ（閉じた形）。
    let h = 1.0 / (n + 1) as f64;
    let kappa = RealScalar::powi(1.0 / RealScalar::tan(0.5 * core::f64::consts::PI * h), 2);
    let rho = (RealScalar::sqrt(kappa) - 1.0) / (RealScalar::sqrt(kappa) + 1.0);
    let bound = RealScalar::ceil(
        RealScalar::ln(2.0 * RealScalar::sqrt(kappa) / epsilon) / RealScalar::ln(1.0 / rho),
    );
    bounds.push([n as f64, bound]);
    grids.push((n, kappa, bound as usize, levels, complexity, recount, setup));
}
let (sci3, fixed3) = (
    serde_json::json!({ "notation": "scientific", "significantDigits": 3 }),
    serde_json::json!({ "fractionDigits": 3 }),
);
let columns = serde_json::json!([
    { "key": "0", "label": "n", "type": "integer" },
    { "key": "1", "label": "κ(A) [-]", "type": "number", "format": sci3 },
    { "key": "2", "label": "上界 k_κ [回]", "type": "integer" },
    { "key": "3", "label": "AMG の段数 [段]", "type": "integer" },
    { "key": "4", "label": "C_op [-]", "type": "number", "format": fixed3, "nullText": "なし" },
    { "key": "5", "label": "数え直した C_op [-]", "type": "number", "format": fixed3 },
    { "key": "6", "label": "粗くするのを止めた理由" }
]);
emit_table_with_columns!(
    columns,
    grids,
    metadata = serde_json::json!({ "id": "grids" })
);
// 許容誤差を満たした求解だけを描く。
let mut series: Vec<serde_json::Value> = ["Jacobi", "IC(0)", "AMG"]
    .into_iter()
    .map(|name| {
        let points: Vec<[f64; 2]> = solves
            .iter()
            .zip(&converged)
            .filter(|(row, ok)| row.1 == name && **ok)
            .map(|(row, _)| [row.0 as f64, row.2 as f64])
            .collect();
        serde_json::json!({ "name": name, "points": points, "style": { "showSymbol": true } })
    })
    .collect();
series.push(serde_json::json!({
    "name": "上界 k_κ",
    "points": bounds,
    "style": { "lineType": "dashed" }
}));

    &series,
    options = &serde_json::json!({
        "xLabel": "格子の辺の点の数 n [-]",
        "yLabel": "CG の反復回数 [回]",
        "xType": "log",
        "yType": "log"
    })
);
// 判定: 最後の求解（n = 64 の AMG 前処理付き CG）の終了状態。
let (_, _, iterations, status, residual) = solves.last().ok_or("求解の行がない")?;
let success = converged.last() == Some(&true);
let outcome = if success {
    Outcome::satisfied("n = 64 の AMG 前処理付き CG が許容誤差を満たした")
} else if solved["breakdown"].as_bool() == Some(true) {
    Outcome::failed("n = 64 の AMG 前処理付き CG が破綻した")
} else {
    Outcome::partial("n = 64 の AMG 前処理付き CG が許容誤差を満たす前に止まった").explanation(
        "返された解は、検査点で真の残差を確かめた反復解のうち残差が最小のものである。",
    )
};
let mut outcome =
    outcome
        .status(status.clone())
        .diagnostic("反復回数", *iterations as f64, None);
if let Some(value) = residual {
    outcome = outcome.diagnostic("相対残差", *value, None);
}
emit_outcome!(outcome);
```

既定の $\nu = 1$ の V サイクルでは、Jacobi の反復回数は $n = 16, 32, 48, 64$ で 28、59、89、119 回と、$n$ にほぼ比例して増える。
上界 $k_\kappa$ は 116、233、352、473 回で、実際の回数はどの格子でも上界のほぼ 4 分の 1（比は 0.24〜0.25）にとどまり、増え方は上界の予測どおりである。
$n = 16$ から 64 への増え方 4.25 倍は、上界の比 4.1 倍（$\sqrt{\kappa(\mathbf{A})}$ の比 3.8 倍に、対数で増える因子の比を掛けた値）に近い。
IC(0) は 17、29、40、52 回で、Jacobi の 0.44〜0.61 倍だが、やはり $n$ にほぼ比例して増える。
AMG は 12、15、16、17 回で、未知数が 16 倍になっても反復は 1.4 倍しか増えず、グラフではほぼ水平に並ぶ。
AMG の階層は 3〜4 段で、どの格子でも粗い格子の大きさ 16 に達して止まり（`CoarseSize`）、演算子複雑度は 1.357〜1.374 の一定の値にとどまる。
各段の `nnz()` から数え直した値は `operator_complexity()` と一致する。
どの行も終了理由は `Converged` で、真の相対残差は許容誤差の $10^{-8}$ を下回り、判定は満たしたことを示す。

$\nu = 2$ にすると AMG の反復は 9、11、12、13 回に減るが、一回の作用で平滑化の回数が 2 倍になるので、手間は反復回数ほどには減らない。
W サイクルでは 12、12、13、13 回となり、格子の大きさへの依存はさらに小さくなる。
W サイクルは各段で粗い格子の補正を 2 回行うので、一回の作用の手間は V サイクルより大きい。

## まとめ

5 点差分の Poisson 行列の条件数は $\cot^2(\pi h/2) = O(n^2)$ で、前処理のない CG と Jacobi 前処理の CG の反復回数は格子の辺の点の数 $n$ にほぼ比例して増える。
条件数から導く上界 $k_\kappa$ は増え方を予測し、この問題では実際の反復回数がその 4 分の 1 程度になる。
IC(0) は反復回数の定数を小さくするが増え方は変えず、格子を細かくするほど多重格子との差が広がる。
平滑化集約 AMG の前処理では反復回数がほぼ一定にとどまり、演算子複雑度も 1 に近い定数なので、全体の手間は未知数の数にほぼ比例する。
AMG を CG と組み合わせるときは前後の平滑化の回数を等しくし、反復回数の比較は収束の観測であって保証ではないので、問題を変えたら `AmgDiagnostics` と反復回数を確かめ直す。
