この章の例題は物理・工学・ネットワーク・測量の具体的なモデルから疎行列を組み立て、直接法、前処理付きの反復法、グラフのアルゴリズムで解く。
どの例題にも解析解、恒等式、閉形式、別の方法のいずれかによる独立な検算を置いている。
操作入力を既定の値から変えると、行列の大きさ、係数のばらつき、乱数のシード、アルゴリズムの選択によって結果がどう変わるかを確かめられる。

## まとめ

ばね系、Poisson 行列、抵抗回路網の例題は、対称正定値な系の組立てと直接法を扱う。
PageRank は非対称な系での反復法と直接法の比較、代数的多重格子は反復法の前処理の選び方、水準測量網は階数の落ちた最小二乗、グラフ分割はラプラシアンの固有ベクトルを扱う。
検算には解析値や恒等式のように計算とは独立に分かる量を使い、残差が小さいことだけで結果を受け入れない。
並べ替えや前処理の効果は行列の大きさとともに現れるので、既定の値に加えて大きさの入力を変えて確かめるとよい。
