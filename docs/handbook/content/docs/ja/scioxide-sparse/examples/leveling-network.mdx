水準測量では二つの水準点の間の高低差を測り、多くの区間の観測を網にして各点の標高を決める。
観測には誤差があり、区間の数は点の数より多いので、標高は最小二乗で求める。
ただし高低差は標高の差しか決めないので、どこか一点の標高を基準として与えないと、解は一つに決まらない。
この例題では基準点を固定しない網を疎 QR 分解の最小ノルム解で解き、基準点を固定した解と比べる。
独立な検算として、推定した階数、最小ノルム解の標高の和、二つの解の差、閉合差と残差の関係、冗長数の和と自由度、標準誤差と有効抵抗の対称性を使う。

## 観測方程式

水準点 $P_0, \dots, P_{n-1}$ の標高を $h_i$ [m] とし、区間 $k$ で点 $u_k$ から点 $v_k$ への高低差 $\Delta h_k$ [m] を観測したとする。
観測の誤差を $\epsilon_k$ とすると、観測方程式は

$$
\Delta h_k = h_{v_k} - h_{u_k} + \epsilon_k \qquad (k = 0, \dots, m - 1)
$$

で、行列では $\mathbf{A}\mathbf{h} \approx \Delta\mathbf{h}$ と書ける。
$\mathbf{A} \in \mathbb{R}^{m \times n}$ の第 $k$ 行は列 $u_k$ に $-1$、列 $v_k$ に $+1$ を持ち、ほかは 0 で、網のグラフの接続行列である。
各行に非零が二つしかないので、$\mathbf{A}$ は疎である。

### 基準の欠如と階数

網が連結なら、すべての標高に同じ値を足しても高低差は変わらず、$\mathbf{A}\mathbf{1} = \mathbf{0}$ となる。
連結なグラフの接続行列の零空間は $\mathbf{1}$ で張られるので、$\mathbf{A}$ の階数はちょうど $n - 1$ である。
最小二乗解は $\mathbf{h} + t\mathbf{1}$（$t$ は任意）の形の直線をなし、一つに決まらない。

一点 $P_0$ の標高を $h_0 = 0$ m に固定すると、$\mathbf{A}$ から第 0 列を除いた行列 $\mathbf{A}_0$ は列が一次独立になり、最小二乗解 $\mathbf{h}^{(0)}$ が一つに決まる。
固定しない場合は、解の直線のうちノルムが最小の最小ノルム解 $\mathbf{h}^{+}$ を選ぶ。
$\mathbf{h}^{+}$ は $\mathbf{A}$ の行空間に含まれ、零空間 $\mathbf{1}$ に直交するので、

$$
\sum_{i=0}^{n-1} h_i^{+} = 0
$$

を満たす。
二つの解は同じ直線の上にあるので、差 $\mathbf{h}^{+} - \mathbf{h}^{(0)}$ はすべての点で同じ定数 $-\frac{1}{n}\sum_i h_i^{(0)}$ になる。
どちらも最小二乗解なので、残差のノルム $\|\mathbf{A}\mathbf{h} - \Delta\mathbf{h}\|_2$ も等しい。

### 閉合差と残差

区間をたどって元の点に戻る閉路 $C$ では、真の高低差の和は 0 である。
観測の和 $w_C = \sum_{k \in C} \pm\Delta h_k$（向きを閉路に合わせて符号を付ける）を**閉合差**と呼び、観測の誤差の和を表す。
残差を $r_k = (\mathbf{A}\mathbf{h})_k - \Delta h_k$ とすると、$\mathbf{A}\mathbf{h}$ の閉路での和は 0 なので

$$
\sum_{k \in C} \pm r_k = -w_C
$$

が、どの $\mathbf{h}$ についても成り立つ。
調整は閉合差を各区間の残差に配る操作とみなせる。

### 誤差の大きさの推定

観測の誤差 $\epsilon_k$ が平均 0、標準偏差 $\sigma$ の互いに独立な確率変数だとする。
固定解の残差は $\mathbf{r} = \mathbf{A}_0\mathbf{h}^{(0)} - \Delta\mathbf{h} = -(\mathbf{I} - \boldsymbol{\Pi})\boldsymbol{\epsilon}$ で、$\boldsymbol{\Pi} = \mathbf{A}_0(\mathbf{A}_0^{\mathsf{T}}\mathbf{A}_0)^{-1}\mathbf{A}_0^{\mathsf{T}}$ は $\mathbf{A}$ の列空間への直交射影である。
$\mathbf{I} - \boldsymbol{\Pi}$ は階数 $m - (n - 1)$ の直交射影なので、$\mathrm{E}\|\mathbf{r}\|_2^2 = \sigma^2\operatorname{tr}(\mathbf{I} - \boldsymbol{\Pi}) = \sigma^2(m - n + 1)$ となり、

$$
\hat{\sigma} = \sqrt{\frac{\|\mathbf{r}\|_2^2}{m - (n - 1)}}
$$

の 2 乗は $\sigma^2$ の不偏推定量である。
$\hat{\sigma}$ を事後の単位重みの標準偏差と呼ぶ。
分母の $m - (n - 1)$ は余分な観測の数（自由度）で、自由度が小さいと推定値のばらつきは大きい。

$\rho_k = 1 - \Pi_{kk}$ を観測 $k$ の**冗長数**と呼ぶ。
$\rho_k$ は 0 以上 1 以下で、観測 $k$ の誤差のうち残差 $r_k$ に現れる割合を表し、和は $\operatorname{tr}(\mathbf{I} - \boldsymbol{\Pi}) = m - n + 1$ になる。
ほかの観測と閉路を作らない区間では $\rho_k = 0$ で、その区間の誤差は残差に現れず、見つけられない。

### 標準誤差と有効抵抗

固定解の共分散行列は $\sigma^2(\mathbf{A}_0^{\mathsf{T}}\mathbf{A}_0)^{-1}$ なので、点 $P_i$ の標準誤差は $\hat{\sigma}\sqrt{G_{ii}}$、$\mathbf{G} = (\mathbf{A}_0^{\mathsf{T}}\mathbf{A}_0)^{-1}$ で見積もれる。
$\mathbf{A}^{\mathsf{T}}\mathbf{A}$ は、各区間を 1 Ω の抵抗とみなした網のグラフのラプラシアンで、$\mathbf{A}_0^{\mathsf{T}}\mathbf{A}_0$ はそこから基準点の行と列を除いた行列（基準点を接地したラプラシアン）である。
したがって $G_{ii}$ は基準点と $P_i$ の間の有効抵抗 $R_{\mathrm{eff}}(P_0, P_i)$ [Ω] に等しい（[抵抗回路網の節点解析と Foster の定理](../resistor-network/)）。
基準点を $P_j$ に替えると $\mathbf{G}$ も替わるが、有効抵抗の対称性 $R_{\mathrm{eff}}(P_i, P_j) = R_{\mathrm{eff}}(P_j, P_i)$ から、$P_j$ を固定したときの $P_i$ の標準誤差は、$P_i$ を固定したときの $P_j$ の標準誤差に等しい。
標準誤差は基準点との高低差の精度であり、迂回路の少ない遠い点ほど大きい。

射影の対角は $\Pi_{kk} = G_{u_k u_k} + G_{v_k v_k} - 2G_{u_k v_k} = R_{\mathrm{eff}}(u_k, v_k)$（基準点の添字の $G$ は 0 とする）で、冗長数は $\rho_k = 1 - R_{\mathrm{eff}}(u_k, v_k)$ になる。
$\mathbf{A}_0$ の列空間は基準点によらず $\mathbf{A}$ の列空間なので、冗長数も基準点によらない。
冗長数の和が $m - n + 1$ になることは、Foster の定理 $\sum_k R_{\mathrm{eff}}(u_k, v_k) = n - 1$ と同じである。

## 網と観測のモデル

実験の網は 6 点、9 区間である。
真の標高は $(0, 1.250, 2.875, 1.640, 0.430, 3.210)$ m で、区間は $0 \to 1$、$1 \to 2$、$2 \to 3$、$3 \to 0$、$1 \to 4$、$4 \to 3$、$2 \to 5$、$5 \to 3$、$0 \to 4$ である。
各観測には標準偏差 $\sigma$ [mm] の正規乱数を Box–Muller 法で作って加える。
次のブロックは、このページの二つのセルが共有する定義である。
`HEIGHTS` と `SECTIONS` が真の標高と区間、`observations` が観測 $\Delta\mathbf{h}$、`design` が観測方程式の行列 $\mathbf{A}$（基準点を固定するときはその列を除いた $\mathbf{A}_j$）に対応する。

```rust
//| id: sparse-leveling-model
//| kind: definitions
//| title: 水準網の区間と観測方程式
//| crates: [scioxide-core, scioxide-sparse]
use scioxide_core::{SciOxideError, RealScalar};
use scioxide_sparse::{CsrMatrix, DuplicatePolicy, ExplicitZeroPolicy, SparseBuilder};

/// 水準点 P₀〜P₅ の真の標高 [m]。
pub(crate) const HEIGHTS: [f64; 6] = [0.0, 1.250, 2.875, 1.640, 0.430, 3.210];

/// 区間 k の始点 u_k と終点 v_k（u_k から v_k への高低差を観測する）。
pub(crate) const SECTIONS: [(usize, usize); 9] = [
    (0, 1),
    (1, 2),
    (2, 3),
    (3, 0),
    (1, 4),
    (4, 3),
    (2, 5),
    (5, 3),
    (0, 4),
];

/// 観測 Δh_k = h_{v_k} − h_{u_k} + ε_k [m]。ε_k は標準偏差 σ [mm] の正規乱数（Box–Muller）。
pub(crate) fn observations(noise_mm: f64, seed: u64) -> Vec<f64> {
    let mut state = 0x9E37_79B9_7F4A_7C15_u64 ^ seed;
    let mut uniform = move || {
        state ^= state << 13;
        state ^= state >> 7;
        state ^= state << 17;
        ((state >> 11) as f64 + 0.5) / (1u64 << 53) as f64
    };
    SECTIONS
        .iter()
        .map(|&(u, v)| {
            let z = RealScalar::sqrt(-2.0 * RealScalar::ln(uniform()))
                * RealScalar::cos(2.0 * core::f64::consts::PI * uniform());
            HEIGHTS[v] - HEIGHTS[u] + noise_mm * 1e-3 * z
        })
        .collect()
}

/// 観測方程式の行列 A（区間 k の行は列 u_k に −1、列 v_k に +1）。
/// fixed = Some(j) なら点 j を基準点として、その列を除く。
pub(crate) fn design(fixed: Option<usize>) -> Result<CsrMatrix<f64>, SciOxideError> {
    let cols = HEIGHTS.len() - usize::from(fixed.is_some());
    let mut builder = SparseBuilder::new(SECTIONS.len(), cols);
    for (k, &(u, v)) in SECTIONS.iter().enumerate() {
        for (point, sign) in [(u, -1.0), (v, 1.0)] {
            // 除いた列より右の列は一つ左へ詰める。
            match fixed {
                Some(j) if point == j => {}
                Some(j) if point > j => builder.push(k, point - 1, sign)?,
                _ => builder.push(k, point, sign)?,
            }
        }
    }
    builder.finish_csr(DuplicatePolicy::Reject, ExplicitZeroPolicy::Drop)
}
```

## 基準を固定しない網の調整

次のセルは基準を固定しない $9 \times 6$ の系と、基準点 $P_0$ を 0 m に固定した $9 \times 5$ の系を、同じ手順の疎 QR で解く。
手順は `SparseQrSymbolic::analyze`（近似最小次数の列の並べ替え）、`SparseQr::factor`、相対閾値 $10^{-10}$ の `RankThreshold` を渡す `SparseQrMinimumNormPlan::build`、`solve` である。
`build` は列のノルムの最大 $s$ から階数の打ち切り $\tau = 10^{-10}s$ を決め、`solve` は解と `SparseQrSolveReport` を返す。
レポートの `rank()` は推定した階数、`threshold()` は $\tau$、`residual()` は残差 $\|\mathbf{A}\mathbf{h} - \Delta\mathbf{h}\|_2$、`normal_residual()` は正規方程式の残差 $\|\mathbf{A}^{\mathsf{T}}(\mathbf{A}\mathbf{h} - \Delta\mathbf{h})\|_2$ で、残差はどちらも元の行列 $\mathbf{A}$ で計算し直した値である。
入力は誤差の標準偏差 $\sigma$（0〜5 mm）と乱数のシードである。
一つ目の表には各点の真の標高、二つの解と、その差を示す。
二つ目の表には二つの求解のレポートと標高の和を、三つ目の表には二つの閉路 $0 \to 1 \to 2 \to 3 \to 0$ と $1 \to 4 \to 3 \to 2 \to 1$ の閉合差 $w$ と残差の向き付きの和を示す。
このセルは $\sigma$、観測、最小ノルム解の残差、階数を次のセルに渡す。

```rust
//| id: sparse-leveling-network
//| ref: sparse-leveling-network
//| title: 水準測量網の最小ノルム解と基準点を固定した解
//| run: reactive
//| uses: [sparse-leveling-model]
//| crates: [scioxide-core, scioxide-sparse]
//| exports: [noise_mm, observed, residuals, rank, residual_norm]
//| inputs:
//|   noise_mm: {"type":"range","label":"観測誤差の標準偏差 σ [mm]","description":"各区間の高低差に加える正規乱数の大きさ。","min":0.0,"max":5.0,"step":0.5,"value":2.0}
//|   seed: {"type":"range","label":"乱数のシード","description":"観測の誤差の実現値を選ぶ。","min":1,"max":20,"step":1,"value":1}
//| cases:
//|   - {"id":"exact","label":"σ = 0 mm","description":"誤差がないと閉合差も残差も 0 になり、固定解は真の標高に一致する。","inputs":{"noise_mm":0.0}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"reports","path":"/rows/0/1","equals":5}
//|       - {"artifact":"reports","path":"/rows/1/1","equals":5}
//|       - {"artifact":"reports","path":"/rows/0/2","approx":{"value":2e-10,"rtol":1e-12}}
//|       - {"artifact":"reports","path":"/rows/0/3","approx":{"value":3.7780456686,"rtol":1e-9}}
//|       - {"artifact":"reports","path":"/rows/1/3","approx":{"value":3.7780456686,"rtol":1e-9}}
//|       - {"artifact":"reports","path":"/rows/0/4","range":{"max":1e-9}}
//|       - {"artifact":"reports","path":"/rows/0/5","range":{"min":-1e-12,"max":1e-12}}
//|       - {"artifact":"heights","path":"/rows/0/4","approx":{"value":-1.5668595454,"rtol":1e-9}}
//|       - {"artifact":"heights","path":"/rows/5/4","approx":{"value":-1.5668595454,"rtol":1e-9}}
//|       - {"artifact":"loops","path":"/rows/0/1","approx":{"value":0.2329401288,"rtol":1e-8}}
//|       - {"artifact":"loops","path":"/rows/0/2","approx":{"value":-0.2329401288,"rtol":1e-8}}
//|       - {"artifact":"loops","path":"/rows/1/2","approx":{"value":-3.2276472078,"rtol":1e-9}}
//|   - case: exact
//|     expect:
//|       - {"artifact":"heights","path":"/rows/2/3","approx":{"value":2.875,"rtol":1e-12}}
//|       - {"artifact":"heights","path":"/rows/5/3","approx":{"value":3.21,"rtol":1e-12}}
//|       - {"artifact":"heights","path":"/rows/0/4","approx":{"value":-1.5675,"rtol":1e-12}}
//|       - {"artifact":"loops","path":"/rows/1/2","range":{"min":-1e-9,"max":1e-9}}
use scioxide_core::{ExecutionContext, RankThreshold};
use scioxide_sparse::{
    CsrMatrix, SparseOrdering, SparseQr, SparseQrLimits, SparseQrMinimumNormPlan,
    SparseQrSolveReport, SparseQrSymbolic, SparseSolveOptions,
};

let observed = observations(noise_mm, seed as u64);
let (options, scope) = (SparseSolveOptions::new(), ExecutionContext::sequential());
let threshold = RankThreshold::new(0.0, 1e-10).map_err(|e| e.to_string())?;
// 記号解析、数値分解、階数の閾値による Plan、最小ノルム解の順に解く。
let adjust = |a: &CsrMatrix<f64>| -> Result<(Vec<f64>, SparseQrSolveReport<f64>), String> {
    let limits = SparseQrLimits::new(256, 256, 1 << 20);
    let symbolic =
        SparseQrSymbolic::analyze(a.structural_pattern(), SparseOrdering::FillReducing, limits)
            .map_err(|e| e.to_string())?;
    let factor = SparseQr::factor(symbolic, a.view()).map_err(|e| e.to_string())?;
    let plan = SparseQrMinimumNormPlan::build(factor, threshold, options, scope)
        .map_err(|e| e.to_string())?;
    plan.solve(&observed).map_err(|e| e.to_string())
};
let free_design = design(None).map_err(|e| e.to_string())?;
let anchored_design = design(Some(0)).map_err(|e| e.to_string())?;
let (free, free_report) = adjust(&free_design)?;
let (mut anchored, anchored_report) = adjust(&anchored_design)?;
anchored.insert(0, 0.0);
let heights: Vec<(String, f64, f64, f64, f64)> = (0..HEIGHTS.len())
    .map(|i| {
        (
            format!("P{i}"),
            HEIGHTS[i],
            free[i],
            anchored[i],
            free[i] - anchored[i],
        )
    })
    .collect();
let (fixed4, sci2) = (
    serde_json::json!({ "fractionDigits": 4 }),
    serde_json::json!({ "notation": "scientific", "significantDigits": 2 }),
);
let columns = serde_json::json!([
    { "key": "0", "label": "点" },
    { "key": "1", "label": "真の標高 [m]", "type": "number", "format": fixed4 },
    { "key": "2", "label": "最小ノルム解 h⁺ [m]", "type": "number", "format": fixed4 },
    { "key": "3", "label": "P₀ 固定の解 h⁽⁰⁾ [m]", "type": "number", "format": fixed4 },
    { "key": "4", "label": "差 h⁺ − h⁽⁰⁾ [m]", "type": "number", "format": fixed4 }
]);
emit_table_with_columns!(
    columns,
    heights,
    metadata = serde_json::json!({ "id": "heights" })
);
let reports: Vec<(&str, usize, f64, f64, f64, f64)> = [
    ("固定しない", &free_report, &free),
    ("P₀ を固定", &anchored_report, &anchored),
]
.into_iter()
.map(|(name, report, h)| {
    (
        name,
        report.rank(),
        report.threshold(),
        report.residual().raw_norm() * 1e3,
        report.normal_residual().raw_norm() * 1e3,
        h.iter().sum::<f64>(),
    )
})
.collect();
let columns = serde_json::json!([
    { "key": "0", "label": "系" },
    { "key": "1", "label": "階数 rank()", "type": "integer" },
    { "key": "2", "label": "打ち切り τ [-]", "type": "number", "format": sci2 },
    { "key": "3", "label": "残差 ‖Ah − Δh‖₂ [mm]", "type": "number", "format": fixed4 },
    { "key": "4", "label": "正規方程式の残差 [mm]", "type": "number", "format": sci2 },
    { "key": "5", "label": "標高の和 Σh [m]", "type": "number", "format": sci2 }
]);
emit_table_with_columns!(
    columns,
    reports,
    metadata = serde_json::json!({ "id": "reports" })
);
// 独立検算: 閉路の閉合差 w と、残差 r = A h⁺ − Δh の向き付きの和（区間の番号と向き）。
let residuals: Vec<f64> = SECTIONS
    .iter()
    .zip(&observed)
    .map(|(&(u, v), d)| free[v] - free[u] - d)
    .collect();
let loops: [(&str, &[(usize, f64)]); 2] = [
    ("0→1→2→3→0", &[(0, 1.0), (1, 1.0), (2, 1.0), (3, 1.0)]),
    ("1→4→3→2→1", &[(4, 1.0), (5, 1.0), (2, -1.0), (1, -1.0)]),
];
let closures: Vec<(&str, f64, f64)> = loops
    .iter()
    .map(|&(name, sections)| {
        let w: f64 = sections.iter().map(|&(k, s)| s * observed[k]).sum();
        let r: f64 = sections.iter().map(|&(k, s)| s * residuals[k]).sum();
        (name, w * 1e3, r * 1e3)
    })
    .collect();
let columns = serde_json::json!([
    { "key": "0", "label": "閉路" },
    { "key": "1", "label": "閉合差 w [mm]", "type": "number", "format": fixed4 },
    { "key": "2", "label": "残差の和 Σ±r [mm]", "type": "number", "format": fixed4 }
]);
emit_table_with_columns!(
    columns,
    closures,
    metadata = serde_json::json!({ "id": "loops" })
);
export!(noise_mm, noise_mm);
export!(observed, observed);
export!(residuals, residuals);
export!(rank, free_report.rank());
export!(residual_norm, free_report.residual().raw_norm());
```

既定の $\sigma = 2$ mm、シード 1 では、どちらの系も推定した階数は 5 で、基準を固定しない系では $n - 1 = 5$ と一致する。
$P_3$ には 4 区間が集まるので列のノルムの最大は $s = \sqrt{4} = 2$ で、打ち切りは $\tau = 2 \times 10^{-10}$ になる。
最小ノルム解の標高の和は $-2.0 \times 10^{-15}$ m で、丸めの程度で 0 になる。
最小ノルム解は $h_0^{+} = -1.5669$ m のように全体が下にずれているが、固定解との差はすべての点で $-1.5669$ m で、固定解の標高の和 9.4012 m の $-1/6$ に等しい。
二つの系の残差のノルムはどちらも 3.7780 mm で、正規方程式の残差は $2 \times 10^{-12}$ mm 以下なので、どちらの解も同じ最小値に達している。
固定解と真の標高の差は最大で 3.7 mm（$P_5$）である。
二つの閉路の閉合差は 0.2329 mm と 3.2276 mm で、残差の向き付きの和はその符号を反転した値になる。
$\sigma = 0$ にすると閉合差も残差も 0 になり、固定解は真の標高に一致し、最小ノルム解との差は真の標高の和 9.405 m の $-1/6$ の $-1.5675$ m になる。

## 残差と精度

次のセルは前のセルから観測、最小ノルム解の残差、階数を受け取る。
残差はどの最小二乗解でも同じなので、最小ノルム解の残差を使う。
$\hat{\sigma}$ はレポートの残差のノルムと階数から $\|\mathbf{r}\|_2/\sqrt{m - \mathrm{rank}}$ で求める。
選んだ基準点 $P_j$ の列を除いた $\mathbf{A}_j$ から、正規方程式の行列 $\mathbf{A}_j^{\mathsf{T}}\mathbf{A}_j$（$5 \times 5$）を `transpose`、`to_csr`、`multiply` で作り、準備を一括して行うコンストラクター `SparseCholesky::new` で分解する。
単位ベクトルを右辺に 5 回解いて $\mathbf{G} = (\mathbf{A}_j^{\mathsf{T}}\mathbf{A}_j)^{-1}$ を一列ずつ求め、各点の有効抵抗 $G_{ii}$ と標準誤差、各区間の冗長数を計算する。
入力は基準点 $P_j$ で、基準点を替えても変わらない量（冗長数）と変わる量（標準誤差）を見分ける。
一つ目の表は区間ごとの観測、残差と冗長数、二つ目の表は点ごとの有効抵抗と標準誤差、三つ目の表は入力の $\sigma$、$\hat{\sigma}$、自由度、冗長数の和である。

```rust
//| id: sparse-leveling-precision
//| ref: sparse-leveling-precision
//| title: 水準測量網の残差、冗長数、事後の標準偏差と標準誤差
//| run: reactive
//| uses: [sparse-leveling-model]
//| crates: [scioxide-core, scioxide-sparse]
//| dependsOn:
//|   adjust: sparse-leveling-network
//| inputs:
//|   reference: {"type":"select","label":"標準誤差の基準点 P_j","description":"標高を既知として固定する点。","options":["P0","P1","P2","P3","P4","P5"],"value":"P0"}
//| cases:
//|   - {"id":"reference-p5","label":"基準点 P₅","description":"標準誤差は基準点に依存するが、冗長数と自由度は変わらない。","inputs":{"reference":"P5"}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"summary","path":"/rows/0/1","approx":{"value":1.8890228343,"rtol":1e-9}}
//|       - {"artifact":"summary","path":"/rows/0/2","equals":4}
//|       - {"artifact":"summary","path":"/rows/0/3","approx":{"value":4,"rtol":1e-12}}
//|       - {"artifact":"points","path":"/rows/0/1","equals":null}
//|       - {"artifact":"points","path":"/rows/1/1","approx":{"value":0.53125,"rtol":1e-12}}
//|       - {"artifact":"points","path":"/rows/5/1","approx":{"value":1.03125,"rtol":1e-12}}
//|       - {"artifact":"points","path":"/rows/5/2","approx":{"value":1.9183117566,"rtol":1e-9}}
//|       - {"artifact":"sections","path":"/rows/0/3","approx":{"value":0.46875,"rtol":1e-12}}
//|       - {"artifact":"sections","path":"/rows/8/3","approx":{"value":0.5,"rtol":1e-12}}
//|   - case: reference-p5
//|     expect:
//|       - {"artifact":"points","path":"/rows/0/1","approx":{"value":1.03125,"rtol":1e-12}}
//|       - {"artifact":"points","path":"/rows/0/2","approx":{"value":1.9183117566,"rtol":1e-9}}
//|       - {"artifact":"points","path":"/rows/5/2","equals":null}
//|       - {"artifact":"sections","path":"/rows/0/3","approx":{"value":0.46875,"rtol":1e-12}}
//|       - {"artifact":"summary","path":"/rows/0/3","approx":{"value":4,"rtol":1e-12}}
use scioxide_core::RealScalar;
use scioxide_sparse::SparseCholesky;

let noise_mm = adjust["noise_mm"].as_f64().ok_or("σ がない")?;
let observed: Vec<f64> =
    serde_json::from_value(adjust["observed"].clone()).map_err(|e| e.to_string())?;
let residuals: Vec<f64> =
    serde_json::from_value(adjust["residuals"].clone()).map_err(|e| e.to_string())?;
let rank = adjust["rank"].as_u64().ok_or("階数がない")? as usize;
let residual_norm = adjust["residual_norm"].as_f64().ok_or("残差がない")?;
let (n, m) = (HEIGHTS.len(), SECTIONS.len());
// 事後の単位重みの標準偏差 σ̂ = ‖r‖₂/√(m − rank) [m]。
let dof = m - rank;
let sigma_hat = residual_norm / RealScalar::sqrt(dof as f64);
// 基準点 P_j の列を除いた A_j と、接地したラプラシアン N = A_jᵀA_j。
let j: usize = reference[1..].parse().map_err(|_| "基準点の名前が不正")?;
let a = design(Some(j)).map_err(|e| e.to_string())?;
let normal = a
    .transpose()
    .and_then(|t| t.to_csr())
    .and_then(|t| t.multiply(&a))
    .map_err(|e| e.to_string())?;
let cholesky = SparseCholesky::new(&normal).map_err(|e| e.to_string())?;
// G = N⁻¹ を一列ずつ求め、基準点の行と列を 0 として n × n に広げる。
let full = |i: usize| if i < j { i } else { i + 1 };
let mut g = vec![0.0_f64; n * n];
for c in 0..n - 1 {
    let mut unit = vec![0.0_f64; n - 1];
    unit[c] = 1.0;
    let column = cholesky.solve(&unit).map_err(|e| e.to_string())?;
    for (r, value) in column.into_iter().enumerate() {
        g[full(r) * n + full(c)] = value;
    }
}
// 冗長数 ρ_k = 1 − R_eff(u_k, v_k) = 1 − (G_uu + G_vv − 2 G_uv)。
let redundancy: Vec<f64> = SECTIONS
    .iter()
    .map(|&(u, v)| 1.0 - (g[u * n + u] + g[v * n + v] - 2.0 * g[u * n + v]))
    .collect();
let sections: Vec<(String, f64, f64, f64)> = (0..m)
    .map(|k| {
        let (u, v) = SECTIONS[k];
        (
            format!("{u}→{v}"),
            observed[k],
            residuals[k] * 1e3,
            redundancy[k],
        )
    })
    .collect();
let (fixed2, fixed3, fixed4) = (
    serde_json::json!({ "fractionDigits": 2 }),
    serde_json::json!({ "fractionDigits": 3 }),
    serde_json::json!({ "fractionDigits": 4 }),
);
let columns = serde_json::json!([
    { "key": "0", "label": "区間" },
    { "key": "1", "label": "観測 Δh [m]", "type": "number", "format": fixed4 },
    { "key": "2", "label": "残差 r [mm]", "type": "number", "format": fixed2 },
    { "key": "3", "label": "冗長数 ρ [-]", "type": "number", "format": fixed3 }
]);
emit_table_with_columns!(
    columns,
    sections,
    metadata = serde_json::json!({ "id": "sections" })
);
// 標準誤差 σ̂√G_ii [mm]。基準点自身は定義しない。
let points: Vec<(String, Option<f64>, Option<f64>)> = (0..n)
    .map(|i| {
        let resistance = (i != j).then(|| g[i * n + i]);
        let error = resistance.map(|r| sigma_hat * RealScalar::sqrt(r) * 1e3);
        (format!("P{i}"), resistance, error)
    })
    .collect();
let columns = serde_json::json!([
    { "key": "0", "label": "点" },
    { "key": "1", "label": "有効抵抗 [Ω]", "type": "number", "format": fixed4, "nullText": "基準" },
    { "key": "2", "label": "標準誤差 [mm]", "type": "number", "format": fixed2, "nullText": "基準" }
]);
emit_table_with_columns!(
    columns,
    points,
    metadata = serde_json::json!({ "id": "points" })
);
let summary = vec![(
    noise_mm,
    sigma_hat * 1e3,
    dof,
    redundancy.iter().sum::<f64>(),
)];
let columns = serde_json::json!([
    { "key": "0", "label": "入力の σ [mm]", "type": "number", "format": fixed2 },
    { "key": "1", "label": "σ̂ [mm]", "type": "number", "format": fixed2 },
    { "key": "2", "label": "自由度 m − rank", "type": "integer" },
    { "key": "3", "label": "冗長数の和 Σρ [-]", "type": "number", "format": fixed4 }
]);
emit_table_with_columns!(
    columns,
    summary,
    metadata = serde_json::json!({ "id": "summary" })
);
```

既定の基準点 $P_0$ では、区間の残差は $-2.23$〜$0.82$ mm に収まり、$\hat{\sigma} = 1.89$ mm は入力の 2 mm に近い。
冗長数は 0.375〜0.5 で、和は自由度 $9 - 5 = 4$ に一致する。
各区間が 1 Ω の網なので、有効抵抗と冗長数は有理数になり、表の値は厳密値（$17/32$ Ω、$3/8$ など）と丸めの程度で一致する。
有効抵抗は、$P_0$ と直接つながる $P_1$、$P_3$、$P_4$ で $17/32 = 0.53$、$17/32$、$1/2$ Ω と小さい。
$P_0$ から 2 区間離れた点のうち、3 本の区間を持つ $P_2$ は $25/32 = 0.78$ Ω、2 本しか持たない $P_5$ は $33/32 = 1.03$ Ω で、迂回路の少ない $P_5$ のほうが大きい。
標準誤差は有効抵抗の平方根に比例し、1.34〜1.92 mm になる。
基準点を $P_5$ にすると、$P_5$ の標準誤差は定義されなくなり、$P_0$ の有効抵抗は 1.03125 Ω、標準誤差は 1.92 mm で、基準点が $P_0$ のときの $P_5$ の値と一致する。
冗長数と自由度は、基準点を替えても変わらない。

自由度が 4 しかないので、$\hat{\sigma}$ はシードによって大きくばらつく。
誤差が正規分布に従うなら $4\hat{\sigma}^2/\sigma^2$ は自由度 4 の $\chi^2$ 分布に従い、$\hat{\sigma}/\sigma$ の相対的なばらつきは $1/\sqrt{2 \cdot 4} \approx 0.35$ の程度である。
前のセルで $\sigma = 5$ mm とすると、シード 1〜10 の $\hat{\sigma}$ は 1.70〜6.97 mm に広がる。

## まとめ

基準点を固定しない水準網の観測行列は接続行列で、零空間が $\mathbf{1}$ なので階数はちょうど $n - 1$ である。
`SparseQrMinimumNormPlan` は階数を $n - 1$ と推定し、標高の和が 0 の最小ノルム解を返すので、基準を決めずに網の形だけを調整できる。
基準点を固定した解とは全点で同じ定数だけずれるので、あとから任意の点の標高を与えて全体を平行移動すればよい。
閉路では残差の和が閉合差の符号を反転した値になり、調整は閉合差を区間に配る操作であることが確かめられる。
観測の誤差の大きさは残差から $\hat{\sigma}$ で推定でき、分母の自由度は冗長数の和に等しいので、自由度が小さい網では推定値のばらつきが大きい。
標準誤差は基準点との間の有効抵抗の平方根に比例し、基準点を替えると変わるが、冗長数は変わらない。
