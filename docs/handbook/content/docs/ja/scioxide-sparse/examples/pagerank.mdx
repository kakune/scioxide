Web のリンクや論文の引用のような有向グラフで、各頂点の重要さを、リンクをたどり続ける酔歩の定常分布で測るのが PageRank である。
定常分布は大きな疎行列を係数に持つ線形方程式の解で、反復法でも直接法でも求められる。
この例題では宙づりの節点（出るリンクのない頂点）を含む乱数のグラフについて、疎な転置積を繰り返すべき乗法と、疎 LU 分解による直接法で PageRank を求める。
独立な検算として、確率の総和、二つの方法の一致、べき乗法の途中で計算できる事後の誤差上界、推移行列の固有値から予測する収束率を使う。

## 定式化

$n$ 頂点の有向グラフで、頂点 $i$ から出るリンクの数（出次数）を $k_i$ とする。
$i$ から $j$ へのリンクがあれば $h_{ij} = 1/k_i$、なければ $h_{ij} = 0$ とする行列を $\mathbf{H}$ とする。
出るリンクのない頂点を宙づりの節点と呼ぶ。
宙づりの節点 $i$（$k_i = 0$）の行は 0 なので、$\mathbf{H}$ の行和は 1 か 0 である。
宙づりの節点で 1、それ以外で 0 をとるベクトルを $\mathbf{d}$ とし、宙づりの節点からはすべての頂点へ等確率で移ると約束すると、推移行列

$$
\mathbf{P} = \mathbf{H} + \frac{1}{n}\mathbf{d}\mathbf{1}^{\mathsf{T}}
$$

は非負で、各行の和が 1 になる。
酔歩は確率 $\alpha$（減衰係数、0.85 がよく使われる）で $\mathbf{P}$ に従ってリンクをたどり、確率 $1 - \alpha$ で全頂点から一様に選んだ頂点へ飛ぶ。
PageRank はこの酔歩の定常分布 $\mathbf{x}$（$x_i \ge 0$、$\sum_i x_i = 1$）で、

$$
\mathbf{x} = \alpha\,\mathbf{P}^{\mathsf{T}}\mathbf{x} + \frac{1 - \alpha}{n}\mathbf{1}
$$

を満たす。
行列の 1 ノルム $\|\cdot\|_1$ は列の絶対値の和の最大で、$\mathbf{P}^{\mathsf{T}}$ は非負で列和が 1 なので $\|\alpha\mathbf{P}^{\mathsf{T}}\|_1 = \alpha < 1$ である。
したがって $\mathbf{I} - \alpha\mathbf{P}^{\mathsf{T}}$ は正則で、解は一つに決まる。
Neumann 級数 $\mathbf{x} = \frac{1 - \alpha}{n}\sum_{k \ge 0}(\alpha\mathbf{P}^{\mathsf{T}})^k\mathbf{1}$ から、解の成分は非負である。
両辺の成分の和をとると $\mathbf{1}^{\mathsf{T}}\mathbf{x} = \alpha\,\mathbf{1}^{\mathsf{T}}\mathbf{x} + 1 - \alpha$ なので、和は 1 になり、解は確率分布である。

$\mathbf{P}^{\mathsf{T}}$ には密な階数 1 の項 $\frac{1}{n}\mathbf{1}\mathbf{d}^{\mathsf{T}}$ が含まれる。
しかし作用 $\mathbf{P}^{\mathsf{T}}\mathbf{x} = \mathbf{H}^{\mathsf{T}}\mathbf{x} + \frac{1}{n}(\mathbf{d}^{\mathsf{T}}\mathbf{x})\mathbf{1}$ は内積 $\mathbf{d}^{\mathsf{T}}\mathbf{x}$ という一つの数で計算できるので、疎な $\mathbf{H}$ だけを保存すればよい。

## べき乗法

べき乗法は $\mathbf{x}_0 = \frac{1}{n}\mathbf{1}$ から

$$
\mathbf{x}_{k+1} = \alpha\,\mathbf{H}^{\mathsf{T}}\mathbf{x}_k + \frac{\alpha\,\mathbf{d}^{\mathsf{T}}\mathbf{x}_k + 1 - \alpha}{n}\,\mathbf{1}
$$

を繰り返す。
右辺は $\alpha\mathbf{P}^{\mathsf{T}}\mathbf{x}_k + \frac{1 - \alpha}{n}\mathbf{1}$ と等しく、$\mathbf{P}^{\mathsf{T}}$ の列和が 1 なので $\sum_i (x_{k+1})_i = \alpha\sum_i (x_k)_i + 1 - \alpha$ となる。
$\mathbf{x}_0$ の成分の和は 1 なので、どの反復でも和は 1 に保たれる。
一回の反復の手間は転置積 $\mathbf{H}^{\mathsf{T}}\mathbf{x}_k$ と内積 $\mathbf{d}^{\mathsf{T}}\mathbf{x}_k$ で、$O(n + \mathrm{nnz}(\mathbf{H}))$ である。

scioxide-sparse では転置積を出力先を指定する API `sparse_dense_into` に `SparseOperation::Transpose` を渡して計算し、CSR の $\mathbf{H}$ から $\mathbf{H}^{\mathsf{T}}$ を作らない。
`sparse_dense_into` は作業領域 `SparseProductWorkspace` の大きさを検査するだけで大きくせず、足りなければ `DimensionMismatch` を返す。
そこで `SparseProductRequirements::sparse_dense` の要件で反復の前に一度だけ事前確保すると、転置積は反復の中でメモリ領域を確保しない。

### 事前と事後の誤差上界

誤差 $\mathbf{e}_k = \mathbf{x}_k - \mathbf{x}$ は $\mathbf{e}_{k+1} = \alpha\,\mathbf{P}^{\mathsf{T}}\mathbf{e}_k$ を満たし、$\|\mathbf{P}^{\mathsf{T}}\|_1 = 1$ なので

$$
\|\mathbf{e}_k\|_1 \le \alpha^k\,\|\mathbf{e}_0\|_1 \le 2\alpha^k
$$

が成り立つ。
$\mathbf{x}_0$ と $\mathbf{x}$ はどちらも確率分布なので $\|\mathbf{e}_0\|_1 \le 2$ である。
この事前の上界から、誤差を $\tau$ 以下にする反復回数 $\lceil \ln(\tau/2)/\ln\alpha \rceil$ が、グラフによらず計算の前に分かる。

反復の途中で誤差を見積もるには、解 $\mathbf{x}$ を使わない事後の上界を使う。
$\mathbf{e}_k = \mathbf{e}_{k+1} - (\mathbf{x}_{k+1} - \mathbf{x}_k)$ と $\|\mathbf{e}_{k+1}\|_1 \le \alpha\|\mathbf{e}_k\|_1$ から $\|\mathbf{e}_{k+1}\|_1 \le \alpha\|\mathbf{e}_{k+1}\|_1 + \alpha\|\mathbf{x}_{k+1} - \mathbf{x}_k\|_1$ となり、

$$
\|\mathbf{x}_{k+1} - \mathbf{x}\|_1 \le \frac{\alpha}{1 - \alpha}\,\|\mathbf{x}_{k+1} - \mathbf{x}_k\|_1
$$

が得られる。
右辺は反復のたびに計算できるので、停止条件に使える。

### 漸近的な収束率

実際の誤差は多くのグラフで事前の上界 $\alpha^k$ より速く減る。
$\mathbf{x}_0$ と $\mathbf{x}$ の成分の和はどちらも 1 なので $\mathbf{1}^{\mathsf{T}}\mathbf{e}_0 = 0$ で、$\mathbf{1}^{\mathsf{T}}\mathbf{P}^{\mathsf{T}} = \mathbf{1}^{\mathsf{T}}$ から、$\mathbf{P}^{\mathsf{T}}$ は部分空間 $\{\mathbf{e} : \mathbf{1}^{\mathsf{T}}\mathbf{e} = 0\}$ を自分自身に写す。
この部分空間での $\mathbf{P}^{\mathsf{T}}$ の固有値は、$\mathbf{P}$ の固有値から固有値 1 を一つ除いたものである。
$\mathbf{P}$ の固有値を絶対値の大きい順に $1 = |\lambda_1| \ge |\lambda_2| \ge \cdots$ と並べると、誤差は反復を重ねるとおよそ一回ごとに $\alpha|\lambda_2|$ 倍になる。
宙づりの節点を含まず、集合の外へ出るリンクもない頂点の集合を閉じた部分と呼ぶ。
酔歩は閉じた部分に入ると、跳躍しない限りそこから出られない。
$\mathbf{P}$ が互いに交わらない閉じた部分を二つ以上持つときは、固有値 1 が重複して $|\lambda_2| = 1$ となる（Haveliwala and Kamvar, 2003）。
頂点を $d \ge 2$ 個の組に分けると酔歩が組を順に巡る閉じた部分（互いにだけリンクを張る 2 頂点など）を持つときも、1 の $d$ 乗根が固有値になるので $|\lambda_2| = 1$ である。
どちらの場合も、誤差の減り方は上界と同じ $\alpha$ になる。

## 直接法

$\gamma = (\alpha\,\mathbf{d}^{\mathsf{T}}\mathbf{x} + 1 - \alpha)/n$ とおくと、定常の式は $(\mathbf{I} - \alpha\mathbf{H}^{\mathsf{T}})\mathbf{x} = \gamma\mathbf{1}$ と書ける。
そこで疎な系

$$
\mathbf{M}\mathbf{y} = \mathbf{1}, \qquad \mathbf{M} = \mathbf{I} - \alpha\,\mathbf{H}^{\mathsf{T}}
$$

を解き、$\mathbf{x} = \mathbf{y}/\sum_i y_i$ と正規化すれば PageRank が得られる（$\mathbf{x} = \gamma\mathbf{y}$ と $\sum_i x_i = 1$ から $\gamma = 1/\sum_i y_i$）。
$\mathbf{H}^{\mathsf{T}}$ は非負で、その列和は $\mathbf{H}$ の行和なので $\|\alpha\mathbf{H}^{\mathsf{T}}\|_1 \le \alpha < 1$ である。
したがって Neumann 級数 $\mathbf{M}^{-1} = \sum_{k \ge 0}\alpha^k(\mathbf{H}^{\mathsf{T}})^k$ が収束して $\mathbf{M}$ は正則になり、$\mathbf{y} = \mathbf{M}^{-1}\mathbf{1} \ge \mathbf{1}$ なので正規化の分母は正である。
同じ評価から $\|\mathbf{M}\|_1 \le 1 + \alpha$、$\|\mathbf{M}^{-1}\|_1 \le 1/(1 - \alpha)$ で、1 ノルムの条件数は

$$
\kappa_1(\mathbf{M}) \le \frac{1 + \alpha}{1 - \alpha}
$$

で抑えられる。
上界は $\alpha = 0.85$ で 12.3、$\alpha = 0.99$ で 199 である。
宙づりでない頂点の列では $\mathbf{M}$ の列の絶対値の和が $1 + \alpha$ になる。
閉じた部分の頂点 $j$ ではどの $k$ でも $(\mathbf{H}^k\mathbf{1})_j = 1$ なので、$\mathbf{M}^{-1}$ の第 $j$ 列の和は $1/(1 - \alpha)$ になる。
したがって閉じた部分を持つグラフでは、この上界が等号で成り立つ。
$\alpha$ が 1 に近いほど、解は丸め誤差の影響を受けやすくなる。

$\mathbf{M}$ は対称でないので疎 LU 分解で解く。
$\mathbf{M}$ の第 $j$ 列では、対角の 1 が残りの成分の絶対値の和 $\alpha\sum_i h_{ji} \le \alpha$ より大きい。
このように列について狭義に対角優位な行列では、部分ピボットは列を並べ替えたあとも元の対角成分を選び、増大係数は 2 以下である（Wilkinson の定理。
Higham, 2002, §9.5）。
ピボットの順序が $\alpha$ によらないので、フィルと分解の手間も $\alpha$ によらない。
ワンショット関数 `scioxide_sparse::solve(&m, &b)` は `SparseLu::new` と同じ分解（近似最小次数の列の並べ替えのあと、部分ピボット付きの左向き LU 分解）を作り、二回の三角代入で解を返す。
同じ $\mathbf{M}$ で右辺だけが違う系を繰り返し解くときは、`SparseLu::new(&m)` が返す分解を保持して `solve` を呼ぶ。
分解の手間とメモリ使用量は、$\mathbf{M}$ の構造と並べ替えで決まるフィルに依存する。
非常に大きなグラフではフィルがメモリ使用量を超えることがあるので、べき乗法が使われる。

## 実験に使うグラフ

実験では頂点の数 $n$ と乱数のシードからグラフを作る。
各頂点は確率 0.15 で宙づりの節点になり、そうでなければ 1〜4 本（等確率）のリンクを自分以外の頂点へ一様に張る。
同じ相手へ $c$ 本張ったときは $h_{ij} = c/k_i$ とし、`DuplicatePolicy::Sum` で重みを合算する。
次のブロックは、このページの二つのセルが共有する定義である。
`random_web` が $\mathbf{H}$ と $\mathbf{d}$ を作り、`Web` の `links` が $\mathbf{H}$、`dangling` が $\mathbf{d}$ に対応する。

```rust
//| id: sparse-pagerank-model
//| kind: definitions
//| title: 宙づりの節点を含む乱数の有向グラフ
//| crates: [scioxide-core, scioxide-sparse]
use scioxide_core::SciOxideError;
use scioxide_sparse::{CsrMatrix, DuplicatePolicy, ExplicitZeroPolicy, SparseBuilder};

/// リンクの行列 H（h_ij = 本数/k_i）と、宙づりの節点の印 d。
pub(crate) struct Web {
    pub(crate) links: CsrMatrix<f64>,
    pub(crate) dangling: Vec<bool>,
}

/// 頂点 nodes 個のグラフをシード seed から作る（xorshift の一様乱数）。
pub(crate) fn random_web(nodes: usize, seed: u64) -> Result<Web, SciOxideError> {
    let mut state = 0x9E37_79B9_7F4A_7C15_u64 ^ seed;
    let mut uniform = move || {
        state ^= state << 13;
        state ^= state >> 7;
        state ^= state << 17;
        (state >> 11) as f64 / (1u64 << 53) as f64
    };
    let mut builder = SparseBuilder::new(nodes, nodes);
    let mut dangling = vec![false; nodes];
    for (i, mark) in dangling.iter_mut().enumerate() {
        if uniform() < 0.15 {
            *mark = true;
            continue;
        }
        // k 本のリンクを自分以外の頂点へ張り、それぞれに 1/k を置く。
        let k = 1 + (4.0 * uniform()) as usize;
        for _ in 0..k {
            let j = (i + 1 + (uniform() * (nodes - 1) as f64) as usize) % nodes;
            builder.push(i, j, 1.0 / k as f64)?;
        }
    }
    let links = builder.finish_csr(DuplicatePolicy::Sum, ExplicitZeroPolicy::Drop)?;
    Ok(Web { links, dangling })
}
```

## 二つの方法の比較

次のセルは直接法の PageRank $\mathbf{x}^\ast$ をワンショット関数 `solve` で求める。
続いてべき乗法を、事後の上界 $\frac{\alpha}{1 - \alpha}\|\mathbf{x}_{k+1} - \mathbf{x}_k\|_1$ が $\tau = 10^{-12}$ 以下になるまで（最大 5000 回）繰り返し、各反復の誤差 $\|\mathbf{x}_k - \mathbf{x}^\ast\|_1$ を記録する。
直接法の解はべき乗法を止める判定には使わず、検算だけに使う。
一つ目の表には PageRank の上位 5 頂点について二つの手法オブジェクトと差を示す。
二つ目の表には宙づりの節点の数、反復回数、事前の上界から決まる反復回数 $\lceil \ln(\tau/2)/\ln\alpha \rceil$、停止したときの事後の上界と実際の誤差、べき乗法で得た確率の総和と 1 の差、直接法の残差 $\|\mathbf{M}\mathbf{y} - \mathbf{1}\|_\infty$ を示す。
入力は減衰係数 $\alpha$（0.5〜0.99）、頂点の数 $n$（20〜200）、乱数のシードである。
このセルは $\alpha$、$n$、シードと誤差の記録を、次のセルに渡す。

```rust
use scioxide_sparse::{

    SparseProductWorkspace, sparse_dense_into,

let (n, alpha) = (nodes as usize, damping_alpha);
let web = random_web(n, seed as u64).map_err(|e| e.to_string())?;
let h = &web.links;
// 直接法: M = I − αHᵀ（αHᵀ は CSC の転置のビューを scaled で CSR にする）、M y = 1。
let m = h
    .transpose()
    .and_then(|t| t.view().scaled(alpha))

    .try_reserve(&requirements)
    .map_err(|e| e.to_string())?;

let (tolerance, mut posterior) = (1e-12, f64::INFINITY);

        SparseOperation::Transpose,
        input,
        SparseProductOptions::new(),

        ExecutionContext::sequential(),

    let leak: f64 = (0..n).filter(|&i| web.dangling[i]).map(|i| x[i]).sum();
    let jump = (alpha * leak + 1.0 - alpha) / n as f64;
    next.iter_mut().for_each(|v| *v = alpha * *v + jump);

    metadata = serde_json::json!({ "id": "ranking" })
);
// 事前の上界 2α^k ≤ τ を満たす最小の k。
let a_priori =
    RealScalar::ceil(RealScalar::ln(tolerance / 2.0) / RealScalar::ln(alpha)) as usize;
let summary = vec![(
    web.dangling.iter().filter(|&&d| d).count(),
    iterations,
    a_priori,
    posterior,
    errors[iterations][1],
    (x.iter().sum::<f64>() - 1.0).abs(),
    lu_residual,
)];
let columns = serde_json::json!([
    { "key": "0", "label": "宙づりの節点 [個]", "type": "integer" },
    { "key": "1", "label": "反復回数 [回]", "type": "integer" },
    { "key": "2", "label": "事前の上界による回数 [回]", "type": "integer" },
    { "key": "3", "label": "事後の上界 [-]", "type": "number", "format": sci2 },
    { "key": "4", "label": "誤差 ‖x_k − x*‖₁ [-]", "type": "number", "format": sci2 },
    { "key": "5", "label": "|Σx_k − 1| [-]", "type": "number", "format": sci2 },
    { "key": "6", "label": "直接法の残差 [-]", "type": "number", "format": sci2 }
]);
emit_table_with_columns!(
    columns,
    summary,
    metadata = serde_json::json!({ "id": "summary" })
);
export!(damping, alpha);
export!(vertices, n);
export!(graph_seed, seed as u64);
export!(errors, errors);
```

既定の $\alpha = 0.85$、$n = 60$、シード 3 のグラフには宙づりの節点が 11 個ある。
べき乗法は 47 回で停止し、事前の上界から決まる 175 回の 4 分の 1 ほどで済む。
停止したときの事後の上界は $7.8 \times 10^{-13}$、直接法の解との実際の差は $7.1 \times 10^{-14}$ で、事後の上界は誤差をおよそ 11 倍に見積もっている。
上位 5 頂点の値は二つの方法で $5 \times 10^{-15}$ 以内で一致する。
べき乗法で得た確率の総和と 1 の差は $2.2 \times 10^{-16}$、直接法の残差は $8.9 \times 10^{-16}$ で、どちらも丸め誤差の程度である。
$\alpha = 0.99$ にすると事前の上界は 2819 回に増えるが、べき乗法は 69 回で停止する。
$n = 200$ でも反復回数は 50 回で、頂点の数にはほとんどよらない。

$n = 40$、シード 7 のグラフでは、頂点 26 と 37 が互いにだけリンクを張り、外へ出るリンクのない 2 頂点の閉路（閉じた部分）を作る。
酔歩はこの閉路に入ると跳躍でしか抜け出せないので、二つの頂点の PageRank は 0.134 と 0.127 で 1 位と 2 位になる。
べき乗法は 151 回かかり、事前の上界の 175 回に近づく。
$\alpha = 0.99$ では二つの頂点の PageRank がどちらも 0.42 になり、反復は 2715 回に増える。
反復回数がこれほど違う理由は、次の実験で確かめる。

## べき乗法の収束の速さ

次のセルは前のセルからべき乗法の誤差の記録を受け取り、事前の上界 $\alpha^k\|\mathbf{e}_0\|_1$（破線）と対数軸で比べる。
下のグラフは一回あたりの誤差の比 $\|\mathbf{e}_{k}\|_1/\|\mathbf{e}_{k-1}\|_1$ で、上界の $\alpha$ と、予測した収束率 $\alpha|\lambda_2|$ を横線で示す。
二つのグラフの横軸の反復回数は連動する。
$|\lambda_2|$ は同じグラフの $\mathbf{P}$ を密行列にして scioxide-linalg の `GeneralEigenvaluesResult::compute`（Hessenberg 形への変換と Francis の QR 法、手間 $O(n^3)$）で全固有値を求め、絶対値が 2 番目に大きいものを取る。
この固有値の計算はべき乗法とは独立なので、測った収束率と一致すれば、漸近的な収束率の議論を確かめたことになる。
表は $\alpha$、$|\lambda_2|$、予測した収束率 $\alpha|\lambda_2|$、測った収束率、絶対値が 1 の固有値の数である。
測った収束率には丸め誤差に埋もれない $10^{-12}$ より大きい誤差の最後の 11 個を使い、隣り合う 10 組の比の幾何平均をとる。
このセルは前のセルの入力に従い、自分の入力を持たない。

```rust
//| id: sparse-pagerank-convergence
//| ref: sparse-pagerank-convergence
//| title: PageRank のべき乗法の誤差と推移行列の第 2 固有値
//| run: reactive
//| uses: [sparse-pagerank-model]
//| crates: [scioxide-core, scioxide-sparse, scioxide-linalg]
//| dependsOn:
//|   power: sparse-pagerank-comparison
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"rate","path":"/rows/0/1","approx":{"value":0.6455781212,"rtol":1e-8}}
//|       - {"artifact":"rate","path":"/rows/0/2","approx":{"value":0.5487414030,"rtol":1e-8}}
//|       - {"artifact":"rate","path":"/rows/0/3","approx":{"value":0.5487414030,"rtol":0.03}}
//|       - {"artifact":"rate","path":"/rows/0/4","equals":1}
use scioxide_core::RealScalar;
use scioxide_linalg::{GeneralEigenvaluesResult, Matrix};

let alpha = power["damping"].as_f64().ok_or("減衰係数がない")?;
let n = power["vertices"].as_u64().ok_or("頂点の数がない")? as usize;
let seed = power["graph_seed"].as_u64().ok_or("シードがない")?;
let errors: Vec<[f64; 2]> =
    serde_json::from_value(power["errors"].clone()).map_err(|e| e.to_string())?;
// 独立な検算: P = H + d1ᵀ/n を密行列（行優先）にして、全固有値を求める。
let web = random_web(n, seed).map_err(|e| e.to_string())?;
let mut dense: Vec<f64> = web
    .dangling
    .iter()
    .flat_map(|&d| std::iter::repeat_n(if d { 1.0 / n as f64 } else { 0.0 }, n))
    .collect();
for (i, j, v) in web.links.iter() {
    dense[i * n + j] += v;
}
let matrix = Matrix::from_vec(n, n, dense).map_err(|e| e.to_string())?;
let spectrum = GeneralEigenvaluesResult::compute(&matrix).map_err(|e| e.to_string())?;
let mut moduli: Vec<f64> = spectrum.eigenvalues().iter().map(|z| z.norm()).collect();
moduli.sort_by(|a, b| b.total_cmp(a));
let second = moduli[1];
let unit = moduli.iter().filter(|&&r| r > 1.0 - 1e-10).count();
// 収束率は丸め誤差に埋もれない誤差（10⁻¹² 超）の最後の 10 回の比の幾何平均で測る。
let positive: Vec<[f64; 2]> = errors.iter().copied().filter(|p| p[1] > 0.0).collect();
let resolved: Vec<[f64; 2]> = errors.iter().copied().filter(|p| p[1] > 1e-12).collect();
let tail = &resolved[resolved.len().saturating_sub(11)..];
let span = (tail.len() - 1) as f64;
let measured = RealScalar::powf(tail[tail.len() - 1][1] / tail[0][1], 1.0 / span);
let rows = vec![(alpha, second, alpha * second, measured, unit)];
let fixed4 = serde_json::json!({ "fractionDigits": 4 });
let columns = serde_json::json!([
    { "key": "0", "label": "α [-]", "type": "number", "format": fixed4 },
    { "key": "1", "label": "|λ₂(P)| [-]", "type": "number", "format": fixed4 },
    { "key": "2", "label": "予測した収束率 α|λ₂| [-]", "type": "number", "format": fixed4 },
    { "key": "3", "label": "測った収束率 [-]", "type": "number", "format": fixed4 },
    { "key": "4", "label": "|λ| = 1 の固有値 [個]", "type": "integer" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "rate" })
);
// 上界 α^k‖e₀‖₁ と、一回あたりの誤差の比。
let e0 = errors[0][1];
let bound: Vec<[f64; 2]> = errors
    .iter()
    .map(|p| [p[0], e0 * RealScalar::powi(alpha, p[0] as i32)])
    .collect();
let ratios: Vec<[f64; 2]> = resolved
    .windows(2)
    .map(|w| [w[1][0], w[1][1] / w[0][1]])
    .collect();
let ratio_series = vec![serde_json::json!({ "name": "誤差の比", "points": ratios })];
let error_series = vec![
    serde_json::json!({
        "name": "‖x_k − x*‖₁",
        "points": positive,
        "style": { "showSymbol": true }
    }),
    serde_json::json!({
        "name": "上界 α^k‖e₀‖₁",
        "points": bound,
        "style": { "lineType": "dashed" }
    }),
];
emit_line_chart!(
    &error_series,
    options = &serde_json::json!({
        "link": { "group": "pagerank-iteration" },
        "xLabel": "反復回数 k [回]",
        "yLabel": "誤差 ‖x_k − x*‖₁ [-]",
        "yType": "log"
    })
);
emit_scatter_chart!(
    &ratio_series,
    options = &serde_json::json!({
        "link": { "group": "pagerank-iteration" },
        "xLabel": "反復回数 k [回]",
        "yLabel": "誤差の比 ‖e_k‖₁/‖e_{k−1}‖₁ [-]",
        "yMin": 0.0,
        "yMax": 1.0,
        "annotations": [
            { "kind": "line", "axis": "y", "value": alpha, "label": "上界 α" },
            { "kind": "line", "axis": "y", "value": alpha * second, "label": "予測 α|λ₂|" }
        ]
    })
);
```

既定の入力では $|\lambda_2(\mathbf{P})| = 0.6456$ で、予測した収束率 $\alpha|\lambda_2| = 0.5487$ に対し、測った収束率は 0.5547 である。
上のグラフでは、誤差が 47 回目に $7.1 \times 10^{-14}$ まで下がり、同じ反復での事前の上界 $\alpha^{47}\|\mathbf{e}_0\|_1 = 2.3 \times 10^{-4}$ より 9 桁以上小さい。
下のグラフの比は 0.45〜0.62 の範囲で上下しながら予測の横線のまわりに集まり、どの反復でも上界の $\alpha$ を超えない。
$\alpha = 0.5$ と $0.99$ では、予測が 0.3228 と 0.6391、測った値が 0.3170 と 0.6454 である。
$|\lambda_2|$ はグラフだけで決まり $\alpha$ によらないので、収束率は $\alpha$ に比例し、$\alpha = 0.99$ でも $0.99 \times 0.6456$ にとどまる。

$n = 40$、シード 7 では、2 頂点の閉路に制限した推移行列 $\begin{pmatrix} 0 & 1 \\ 1 & 0 \end{pmatrix}$ が固有値 $\pm 1$ を持つので、$\mathbf{P}$ も固有値 $-1$ を持ち、絶対値が 1 の固有値は 2 個になる。
$|\lambda_2| = 1$ なので予測した収束率は $\alpha$ そのもので、測った収束率 0.847 も $\alpha = 0.85$ にほぼ一致する。
このとき誤差は上界と同じ速さでしか減らないので、反復回数は事前の上界に近づく。

## まとめ

PageRank は推移行列の定常分布で、宙づりの節点の密な寄与は内積 $\mathbf{d}^{\mathsf{T}}\mathbf{x}$ にまとめられるので、疎な $\mathbf{H}$ だけを保存すれば計算できる。
べき乗法の一回の手間は転置積の $O(n + \mathrm{nnz})$ で、停止は解を使わない事後の上界 $\frac{\alpha}{1 - \alpha}\|\mathbf{x}_{k+1} - \mathbf{x}_k\|_1$ で判定できる。
反復回数を決めるのは事前の上界の $\alpha$ ではなく $\alpha|\lambda_2(\mathbf{P})|$ で、既定のグラフのように $|\lambda_2|$ が 1 より十分小さければ、$\alpha$ を 1 に近づけても反復回数はあまり増えない。
直接法は $\mathbf{I} - \alpha\mathbf{H}^{\mathsf{T}}$ を疎 LU 分解で解いて正規化し、条件数は $(1 + \alpha)/(1 - \alpha)$ 以下で、手間は $\alpha$ によらずフィルで決まる。
閉じた部分を持つグラフで $\alpha$ が 1 に近いときや、同じ行列で右辺だけが違う系を何度も解くときは、手間が $\alpha$ によらず分解を再利用できる直接法が向く。
