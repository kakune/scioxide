抵抗だけからなる回路網の定常状態は、各節点での Kirchhoff の電流則と各枝の Ohm の法則で決まる。
節点の電位を未知数とする**節点解析**では、係数行列は回路網のグラフのラプラシアンで、疎な対称半正定値行列である。
この例題では、抵抗の値がばらついた格子の回路網を組み立て、一つの節点を接地して `SparseCholesky` で解き、すべての枝の有効抵抗を求める。
独立な検算として、有効抵抗の和についての Foster の定理、一様な格子での有効抵抗の固有展開、直列・並列の合成で手計算できる小さな回路を使う。

## 節点解析

節点 $0, \dots, n - 1$ と、抵抗 $R_e$ [Ω]（コンダクタンス $g_e = 1/R_e$ [S]）の枝 $e = \{u, v\}$ からなる連結な回路網を考える。
節点 $i$ の電位を $V_i$ [V]、外から節点 $i$ に流し込む電流を $I_i$ [A] とすると、電流則は

$$
\mathbf{L}\mathbf{V} = \mathbf{I}, \qquad \mathbf{L} = \mathbf{D} - \mathbf{G}
$$

となる。
$\mathbf{G}$ はコンダクタンスを成分とする重み行列、$\mathbf{D}$ は各節点につながるコンダクタンスの和を並べた対角行列で、$\mathbf{L}$ はコンダクタンスを重みとするグラフのラプラシアンである（[グラフのラプラシアン](oxref:sparse-graph-laplacian)）。
枝 $e$ の向きを一つ決め、$\mathbf{b}_e = \mathbf{e}_u - \mathbf{e}_v$ とすると

$$
\mathbf{L} = \sum_{e \in E} g_e\, \mathbf{b}_e \mathbf{b}_e^{\mathsf{T}}, \qquad \mathbf{x}^{\mathsf{T}}\mathbf{L}\mathbf{x} = \sum_{e = \{u, v\}} g_e (x_u - x_v)^2
$$

と書ける。
$\mathbf{x}$ を電位とすると右の式は枝で消費される電力の和 [W] で、どの $\mathbf{x}$ でも 0 以上なので $\mathbf{L}$ は半正定値である。
すべての電位に同じ値を足しても電流は変わらないので $\mathbf{L}\mathbf{1} = \mathbf{0}$ で、回路網が連結なら $\mathbf{L}$ の階数は $n - 1$ である。

基準の節点 $g$ を接地して $V_g = 0$ とし、その行と列を除いた $(n - 1) \times (n - 1)$ の行列を $\mathbf{L}_g$ とする。
$x_g = 0$ のもとで $\mathbf{x}^{\mathsf{T}}\mathbf{L}\mathbf{x} = 0$ なら、すべての枝で $x_u = x_v$ なので、連結な回路網では $\mathbf{x}$ は定数で、$x_g = 0$ から $\mathbf{x} = \mathbf{0}$ になる。
したがって $\mathbf{L}_g$ は対称正定値で、Cholesky 分解で解ける。
回路網が連結でなければ、接地した節点とつながらない部分の電位が決まらず、$\mathbf{L}_g$ は特異になる。

節点 $u$ に 1 A を流し込み、節点 $v$ から 1 A を取り出したときの電位差 $V_u - V_v$ を、$u$ と $v$ の間の**有効抵抗**と呼ぶ。
$\mathbf{L}$ の擬似逆行列 $\mathbf{L}^{+}$ と $\mathbf{b}_{uv} = \mathbf{e}_u - \mathbf{e}_v$ を使うと

$$
R_{\mathrm{eff}}(u, v) = \mathbf{b}_{uv}^{\mathsf{T}}\, \mathbf{L}^{+}\, \mathbf{b}_{uv}
$$

と書ける。
計算では $\mathbf{L}_g \mathbf{x} = \mathbf{b}_{uv}$（$g$ の成分を除く）を解き、$x_g = 0$ として $R_{\mathrm{eff}} = x_u - x_v$ とすればよい。
電位差は基準の取り方によらないからである。

## 組立てと接地

各枝のコンダクタンス $1/R_e$ は、`SparseBuilder` で上三角の位置 $(\min(u, v), \max(u, v))$ に一度ずつ置く。
同じ節点の組を結ぶ並列な枝は同じ位置への複数の寄与なので、`DuplicatePolicy::Sum` でコンダクタンスを合算する。
`GraphPlan::new(view, GraphDirection::Undirected)` は保存された $(u, v)$ を $u$ と $v$ を結ぶ無向の辺として読み、両向きの隣接に展開する。
$(u, v)$ と $(v, u)$ が両方保存されていると、辺の重みは二つのうち小さい方になり、合算はされない。
並列な枝の合算はこの前の組立ての段で済ませておく。

`GraphPlan::laplacian::<f64>(LaplacianDegree::Out, LaplacianNormalization::Unnormalized)` は $\mathbf{L} = \mathbf{D} - \mathbf{G}$ を `LaplacianPlan` として返し、`into_matrix()` で CSR の行列を取り出せる。
負の重みは `DomainError` で拒む。
関数 `laplacian(view)` も同じ $\mathbf{D} - \mathbf{G}$ を返すが、行列を有向グラフとして解釈するので、両方の三角を保存した重み行列を渡す必要がある。

接地では最後の節点 $g = n - 1$ の行と列を除き、残りの成分を新しい `SparseBuilder` に移す。
`SparseCholesky::new` は準備を一括して行うコンストラクターで、近似最小次数法（AMD）で並べ替え、両方の三角を読んで値が厳密に対称であることを確かめ、上限を取らずに分解する。
連結でない回路網では $\mathbf{L}_g$ が特異なので、消去の途中のピボットが 0 か丸めの程度の大きさになる。
それが正でなければ `NumericalInstability` になるが、小さな正の値になると分解は成功し、意味のない電位が返る。
回路網の連結性は分解の前に `connected_components` か `GraphPlan::weak_components` で確かめる。
分解は一度だけで、各有効抵抗は前進代入と後退代入の 1 組で求まり、その手間は因子の非零の数に比例する。

次のブロックは三つのセルが共有する定義である。
`GroundedNetwork::new` が組立てから $\mathbf{L}_g$ の分解まで、`potentials(u, v)` が $u$ に 1 A を流し込み $v$ から取り出したときの全節点の電位、`effective_resistance(u, v)` が $R_{\mathrm{eff}}(u, v)$ に対応する。
`grid_branches(m, resistance)` は、$m \times m$ の格子の節点（$n = m^2$、節点 $(i, j)$ の番号は $im + j$）を縦横の隣どうしでつなぐ枝を、抵抗を枝ごとに `resistance` で決めて返す。

```rust
//| id: sparse-resistor-model
//| kind: definitions
//| title: 接地したラプラシアンと有効抵抗
//| crates: [scioxide-core, scioxide-sparse]
use scioxide_core::SciOxideError;
use scioxide_sparse::{
    DuplicatePolicy, ExplicitZeroPolicy, GraphDirection, GraphPlan, LaplacianDegree,
    LaplacianNormalization, SparseBuilder, SparseCholesky,
};

/// 最後の節点 g = n − 1 を接地した抵抗回路網と、L_g の Cholesky 分解。
pub(crate) struct GroundedNetwork {
    pub(crate) nodes: usize,
    factor: SparseCholesky<f64>,
}

impl GroundedNetwork {
    /// 枝 (u, v, R [Ω]) から L = D − G を作り、g の行と列を除いた L_g を分解する（n ≥ 2）。
    pub(crate) fn new(nodes: usize, branches: &[(usize, usize, f64)]) -> Result<Self, SciOxideError> {
        // コンダクタンス 1/R を上三角に一度ずつ置き、並列な枝は Sum で合算する。
        let mut builder = SparseBuilder::new(nodes, nodes);
        for &(u, v, resistance) in branches {
            builder.push(u.min(v), u.max(v), 1.0 / resistance)?;
        }
        let conductance = builder.finish_csr(DuplicatePolicy::Sum, ExplicitZeroPolicy::Drop)?;
        // 無向グラフとして読み、上三角の成分を両向きの辺にする。
        let graph = GraphPlan::new(conductance.view(), GraphDirection::Undirected)?;
        let laplacian = graph
            .laplacian::<f64>(LaplacianDegree::Out, LaplacianNormalization::Unnormalized)?
            .into_matrix();
        // 接地: 節点 g = n − 1 の行と列を除く。
        let g = nodes - 1;
        let mut reduced = SparseBuilder::new(g, g);
        for (i, j, value) in laplacian.iter().filter(|&(i, j, _)| i < g && j < g) {
            reduced.push(i, j, value)?;
        }
        let grounded = reduced.finish_csr(DuplicatePolicy::Reject, ExplicitZeroPolicy::Preserve)?;
        let factor = SparseCholesky::new(&grounded)?;
        Ok(Self { nodes, factor })
    }

    /// 節点 u に 1 A を流し込み v から取り出したときの全節点の電位 [V]（V_g = 0）。
    pub(crate) fn potentials(&self, u: usize, v: usize) -> Result<Vec<f64>, SciOxideError> {
        let g = self.nodes - 1;
        let mut current = vec![0.0; g];
        if u < g {
            current[u] += 1.0;
        }
        if v < g {
            current[v] -= 1.0;
        }
        let mut potential = self.factor.solve(&current)?;
        potential.push(0.0);
        Ok(potential)
    }

    /// 有効抵抗 R_eff(u, v) = V_u − V_v [Ω]。
    pub(crate) fn effective_resistance(&self, u: usize, v: usize) -> Result<f64, SciOxideError> {
        let potential = self.potentials(u, v)?;
        Ok(potential[u] - potential[v])
    }
}

/// m × m の格子の右隣と下隣への枝 (p, q, R [Ω])。R は枝ごとに resistance() で決める。
pub(crate) fn grid_branches(
    m: usize,
    mut resistance: impl FnMut() -> f64,
) -> Vec<(usize, usize, f64)> {
    let n = m * m;
    let mut branches = Vec::new();
    for p in 0..n {
        for q in [p + 1, p + m] {
            if q < n && (q / m == p / m || q % m == p % m) {
                branches.push((p, q, resistance()));
            }
        }
    }
    branches
}
```

## Foster の定理

連結な回路網では、すべての枝にわたる和について

$$
\sum_{e \in E} \frac{R_{\mathrm{eff}}(e)}{R_e} = n - 1
$$

が成り立つ。
これを Foster の定理という（Foster, 1949）。
左辺の各項は $g_e\, \mathbf{b}_e^{\mathsf{T}}\mathbf{L}^{+}\mathbf{b}_e = \mathrm{tr}(\mathbf{L}^{+} g_e \mathbf{b}_e\mathbf{b}_e^{\mathsf{T}})$ と書け、$\sum_e g_e\mathbf{b}_e\mathbf{b}_e^{\mathsf{T}} = \mathbf{L}$ なので、和は $\mathrm{tr}(\mathbf{L}^{+}\mathbf{L})$ に等しい。
$\mathbf{L}^{+}\mathbf{L}$ は $\mathbf{L}$ の値域への直交射影なので、そのトレースは階数 $n - 1$ である。
この恒等式は抵抗の値にも回路網の形にもよらず、節点の数だけで決まるので、すべての枝の有効抵抗をまとめて確かめる検算になる。

各項の大きさは枝 $e = \{u, v\}$ を取り除いた回路網での $u$ と $v$ の間の有効抵抗 $R_{\mathrm{rest}}$ で決まる。
枝 $e$ は残りの回路網と並列なので $R_{\mathrm{eff}}(e) = R_e R_{\mathrm{rest}}/(R_e + R_{\mathrm{rest}})$ で、

$$
\frac{R_{\mathrm{eff}}(e)}{R_e} = \frac{R_{\mathrm{rest}}}{R_e + R_{\mathrm{rest}}} \in (0, 1]
$$

となる。
残りの経路より抵抗の小さい枝ほど項は 1 に近く、取り除くと回路網が切れる枝（$R_{\mathrm{rest}} = \infty$）では 1 になる。
全域木をその枝のコンダクタンスの積に比例する確率で選ぶと、この項は選んだ木が枝 $e$ を含む確率にも等しい（Kirchhoff の行列木定理による）。
全域木はちょうど $n - 1$ 本の枝を持つので、確率の和が $n - 1$ になることも Foster の定理の別の証明になる。

## 格子の回路網と Foster の和

次のセルは $m \times m$ の格子の節点を縦横の隣どうしで抵抗の枝につなぐ。
各枝の抵抗は $R_e = 10^{\sigma \xi_e}$ [Ω]（$\xi_e$ は $[-1, 1]$ の一様乱数）で、$\sigma$ は抵抗のばらつきを桁数で表す。
すべての枝の有効抵抗を一本ずつ求めて Foster の和を計算し、$n - 1$ と比べる。
入力は格子の辺の節点の数 $m$（3〜12）、ばらつき $\sigma$（0〜2 桁）、乱数のシードである。

表は節点と枝の数、Foster の和と $n - 1$ の差、項 $R_{\mathrm{eff}}(e)/R_e$ の最小と最大を示す。
グラフは各枝の項を抵抗 $R_e$ に対して描き、平均 $(n - 1)/\lvert E \rvert$ を破線で示す。
横軸は $\sigma$ の範囲全体（0.01〜100 Ω）に固定した。

既定の $m = 6$（$n = 36$、枝 60 本）、$\sigma = 1$ 桁、シード 1 では、Foster の和は $n - 1 = 35$ と $7.1 \times 10^{-15}$ の差で一致する。
60 本の枝の有効抵抗を別々の右辺で解いた結果が、丸めの程度でまとめて一つの恒等式を満たしている。
グラフでは、抵抗が 0.15 Ω 未満の 7 本の枝の項は 0.85〜0.98 で 1 に近く、抵抗が 7.5 Ω を超える 5 本の枝の項は 0.05〜0.32 と小さい。
項は 0.052 から 0.977 まで広がるが、平均は破線の $35/60 = 0.583$ に等しい。

$\sigma = 0$（すべて 1 Ω）にすると、点はすべて $R_e = 1$ Ω の上に並び、項は 0.517 から 0.698 の間に分かれる。
大きい値は隅の節点につながる枝で、隅の節点は枝を 2 本しか持たないので、残りの経路の抵抗が大きい。

$m = 12$、$\sigma = 2$ 桁では抵抗が 0.01 Ω から 99 Ω まで 4 桁にわたってばらつき、項も 0.0013 から 0.999 まで広がる。
それでも Foster の和と $n - 1 = 143$ の差は $3.7 \times 10^{-13}$ にとどまる。
差は既定の場合より大きいが、和 143 に対する相対差は $3 \times 10^{-15}$ 程度で、丸めの程度にある。

## 一様な格子の固有展開

すべての抵抗が 1 Ω の $m \times m$ の格子では、ラプラシアンの固有ベクトルが閉じた形で分かり、有効抵抗を節点解析とは独立に計算できる。
$m$ 個の節点の道のラプラシアンの固有値と正規直交な固有ベクトルは、$k = 0, \dots, m - 1$ について

$$
\mu_k = 4\sin^2\frac{k\pi}{2m}, \qquad \phi_k(i) = c_k \cos\frac{k\pi(i + 1/2)}{m}, \qquad c_0 = \sqrt{1/m},\ c_k = \sqrt{2/m}\ (k \ge 1)
$$

である。
格子は二つの道の直積なので、節点 $(i, j)$ の固有ベクトルは $\phi_k(i)\phi_l(j)$、固有値は $\mu_k + \mu_l$ になる。
固有値 0 の $(k, l) = (0, 0)$ を除いて $\mathbf{L}^{+}$ を固有展開すると、節点 $p = (i, j)$ と $q = (i', j')$ の間の有効抵抗は

$$
R_{\mathrm{eff}}(p, q) = \sum_{(k, l) \ne (0, 0)} \frac{\bigl(\phi_k(i)\phi_l(j) - \phi_k(i')\phi_l(j')\bigr)^2}{\mu_k + \mu_l}
$$

である（Wu, 2004）。

隅 0 に 1 A を流し込み、接地した隅 $n - 1$ から取り出したときの電位 $V_p$ には、格子の対称性から次の関係がある。
格子を 180° 回すと、節点 $p = (i, j)$ は $\bar{p} = (m - 1 - i, m - 1 - j)$（番号では $n - 1 - p$）に移り、電流を流し込む隅と取り出す隅が入れ替わるので、$V_{\bar{p}}$ を並べたベクトルは電流の向きを逆にした系の解になる。
その解は元の電位の符号を変えて定数を足したもので、$p = 0$ で $V_{n-1} = 0$ となることから定数は $V_0 = R_{\mathrm{eff}}$ と決まり、$V_p + V_{\bar{p}} = R_{\mathrm{eff}}$ が成り立つ。
主対角線についての折り返し $(i, j) \to (j, i)$ は二つの隅を動かさないので、$V_{(i, j)} = V_{(j, i)}$ でもある。
反対角線 $i + j = m - 1$ の上では $\bar{p} = (j, i)$ なので、二つの関係から電位は $R_{\mathrm{eff}}/2$ になる。

## 一様な格子の隅と隅の有効抵抗

次のセルは、辺の節点の数が 2 から $m$ までの一様な格子について、隅 $(0, 0)$ と対角の隅 $(m - 1, m - 1)$ の間の有効抵抗を節点解析と固有展開で求めて比べる。
グラフは $m \times m$ の格子で隅 0 に 1 A を流し込み、接地した対角の隅から取り出したときの電位 [V] を色で示す。

```rust
//| id: sparse-resistor-uniform-grid
//| ref: sparse-resistor-uniform-grid
//| title: 一様な格子の隅と隅の有効抵抗を固有展開と比べる
//| run: reactive
//| uses: [sparse-resistor-model]
//| crates: [scioxide-core, scioxide-sparse]
//| inputs:
//|   side: {"type":"range","label":"格子の辺の節点の数 m","description":"表は辺が 2 から m までの格子を並べ、グラフは m × m の格子の電位を示す。","min":2,"max":16,"step":1,"value":6}
//| cases:
//|   - {"id":"three","label":"m = 3","description":"3 × 3 の格子の隅と隅の有効抵抗は 1.5 Ω になる。","inputs":{"side":3}}
//|   - {"id":"sixteen","label":"m = 16","description":"節点が 256 個に増えても、隅と隅の有効抵抗は 3.6 Ω にとどまる。","inputs":{"side":16}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"corners","path":"/rows/0/2","approx":{"value":1.0,"rtol":1e-14}}
//|       - {"artifact":"corners","path":"/rows/2/2","approx":{"value":1.8571428571428572,"rtol":1e-13}}
//|       - {"artifact":"corners","path":"/rows/4/2","approx":{"value":2.3656565656565657,"rtol":1e-13}}
//|       - {"artifact":"corners","path":"/rows/4/4","range":{"min":-1e-13,"max":1e-13}}
//|   - case: three
//|     expect:
//|       - {"artifact":"corners","path":"/rows/1/2","approx":{"value":1.5,"rtol":1e-14}}
//|       - {"artifact":"corners","path":"/rows/1/3","approx":{"value":1.5,"rtol":1e-14}}
//|   - case: sixteen
//|     expect:
//|       - {"artifact":"corners","path":"/rows/14/2","approx":{"value":3.608519738730183,"rtol":1e-12}}
//|       - {"artifact":"corners","path":"/rows/14/4","range":{"min":-1e-12,"max":1e-12}}
// 独立な検算: 隅 (0, 0) と (m − 1, m − 1) の間の固有展開（f64 の標準関数による参照値）。
let spectral = |m: usize| {
    let (pi, size) = (core::f64::consts::PI, m as f64);
    let mu = |k: usize| 4.0 * (k as f64 * pi / (2.0 * size)).sin().powi(2);
    let phi = |k: usize, i: usize| {
        let scale = if k == 0 { 1.0 } else { 2.0 };
        (scale / size).sqrt() * (k as f64 * pi * (i as f64 + 0.5) / size).cos()
    };
    let mut sum = 0.0;
    for k in 0..m {
        for l in (0..m).filter(|&l| k + l > 0) {
            let d = phi(k, 0) * phi(l, 0) - phi(k, m - 1) * phi(l, m - 1);
            sum += d * d / (mu(k) + mu(l));
        }
    }
    sum
};

let mut rows = Vec::new();
let mut field = Vec::new();
for size in 2..=side as usize {
    let n = size * size;
    // 一様な格子（すべて 1 Ω）。
    let branches = grid_branches(size, || 1.0);
    let network = GroundedNetwork::new(n, &branches).map_err(|e| e.to_string())?;
    // 隅 0 に 1 A を流し込み、接地した対角の隅 n − 1 から取り出す。
    field = network.potentials(0, n - 1).map_err(|e| e.to_string())?;
    let reference = spectral(size);
    rows.push((size, n, field[0], reference, field[0] - reference));
}

let sig13 = serde_json::json!({ "significantDigits": 13 });
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let columns = serde_json::json!([
    { "key": "0", "label": "辺の節点 m", "type": "integer" },
    { "key": "1", "label": "節点 n", "type": "integer" },
    { "key": "2", "label": "節点解析の R_eff [Ω]", "type": "number", "format": sig13 },
    { "key": "3", "label": "固有展開の R_eff [Ω]", "type": "number", "format": sig13 },
    { "key": "4", "label": "差 [Ω]", "type": "number", "format": sci2 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "corners" })
);
let m = side as usize;
let data: Vec<[f64; 3]> = (0..m * m)
    .map(|p| [(p % m) as f64, (p / m) as f64, field[p]])
    .collect();
emit_chart!(
    serde_json::json!({
        "kind": "heatmap",
        "data": data,
        "xLabel": "格子の列 j [-]",
        "yLabel": "格子の行 i [-]",
        "tooltip": true,
        "style": { "animation": false }
    }),
    metadata = serde_json::json!({
        "id": "potential",
        "title": "隅 0 に 1 A を流し込み対角の隅から取り出したときの電位 [V]"
    })
);
```

既定の $m = 6$ では、表の 5 行がどれも節点解析と固有展開で $2.2 \times 10^{-15}$ Ω 以内の差で一致する。
$m = 2$ の正方形は 1 Ω、$m = 3$ は 1.5 Ω、$m = 4$ は $13/7 = 1.857$ Ω、$m = 6$ は 2.3657 Ω である。
グラフの電位は流し込む隅 0 で $R_{\mathrm{eff}}$ に等しい 2.366 V になり、反対角線の上ではちょうど半分の 1.183 V、接地した隅で 0 V になる。

$m = 16$ では節点が 256 個に増えても、隅と隅の有効抵抗は 3.6085 Ω にとどまる。
$m$ を 2 から 4、8、16 と 2 倍にするたびに 0.86〜0.88 Ω ずつ増えるので、有効抵抗は $m$ の対数にほぼ比例して増える。
格子を面抵抗 1 Ω の一様な板で近似すると、隅から流し込んだ 1 A は 4 分の 1 の平面に広がるので、隅と距離 $r$ の点の電位差はおよそ $(2/\pi)\ln r$ で増える。
二つの隅の寄与を合わせると有効抵抗は $(4/\pi)\ln m$ で増え、2 倍ごとの増分 $(4/\pi)\ln 2 = 0.883$ Ω は表の増分に近い。
固有展開との差は $6.1 \times 10^{-14}$ Ω 以下で、有効抵抗に対する相対差は $2 \times 10^{-14}$ 程度である。

## 直列と並列の合成

次のセルは節点 0〜3 の小さな回路で、0–1 に $R_1$、1–2 に $R_2$ と $R_3$ を並列、2–3 に $R_4$、さらに 0–2 に $R_5$ をつなぐ。
節点 1 は 0 と 2 にしかつながらないので、$R_1$ と $R_2 \parallel R_3 = R_2R_3/(R_2 + R_3)$ は直列で節点 0 と 2 を結ぶ。
これを $R_5$ と並列にし、最後に $R_4$ と直列にすると、節点 0 と 3 の間の合成抵抗は

$$
R_{03} = R_{02} + R_4, \qquad R_{02} = \left( \frac{1}{R_1 + R_2 \parallel R_3} + \frac{1}{R_5} \right)^{-1}
$$

と手で計算できる。
節点 0 に 1 A を流し込み、接地した節点 3 から取り出すと、$V_0 = R_{03}$、$V_2 = R_4 \times 1$ A で、$R_1$ の経路を流れる電流 $R_{02}/(R_1 + R_2 \parallel R_3)$ [A] から $V_1 = V_2 + (R_2 \parallel R_3)\,R_{02}/(R_1 + R_2 \parallel R_3)$ となる。
並列な枝 $R_2$ と $R_3$ は同じ節点の組への二つの寄与として渡し、組立ての `DuplicatePolicy::Sum` がコンダクタンスを合算する。

表は節点解析で求めた電位 $V_0$、$V_1$、$V_2$ を手計算の値と比べる。
入力は $R_1$ と $R_5$ [Ω] で、ほかは $R_2 = 2$、$R_3 = 3$、$R_4 = 1$ Ω に固定する。

```rust
//| id: sparse-resistor-series-parallel
//| ref: sparse-resistor-series-parallel
//| title: 直列・並列の小回路の合成抵抗と節点解析の照合
//| run: reactive
//| uses: [sparse-resistor-model]
//| crates: [scioxide-core, scioxide-sparse]
//| inputs:
//|   r1: {"type":"range","label":"R₁ [Ω]","description":"節点 0 と 1 を結ぶ抵抗。","min":0.5,"max":10.0,"step":0.5,"value":4.0}
//|   r5: {"type":"range","label":"R₅ [Ω]","description":"節点 0 と 2 を直接結ぶ抵抗。","min":0.5,"max":10.0,"step":0.5,"value":5.0}
//| cases:
//|   - {"id":"short-path","label":"R₁ = 0.5 Ω、R₅ = 10 Ω","description":"電流の大部分が R₁ の経路を通り、合成抵抗は 2.453 Ω に下がる。","inputs":{"r1":0.5,"r5":10}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"potentials","path":"/rows/0/1","approx":{"value":3.5490196078431373,"rtol":1e-14}}
//|       - {"artifact":"potentials","path":"/rows/0/3","range":{"min":-1e-14,"max":1e-14}}
//|       - {"artifact":"potentials","path":"/rows/1/1","approx":{"value":1.5882352941176471,"rtol":1e-14}}
//|       - {"artifact":"potentials","path":"/rows/2/1","approx":{"value":1.0,"rtol":1e-14}}
//|   - case: short-path
//|     expect:
//|       - {"artifact":"potentials","path":"/rows/0/1","approx":{"value":2.452991452991453,"rtol":1e-14}}
//|       - {"artifact":"potentials","path":"/rows/0/3","range":{"min":-1e-14,"max":1e-14}}
let (r2, r3, r4) = (2.0_f64, 3.0, 1.0);
// 並列な R₂ と R₃ は同じ節点の組 (1, 2) への二つの枝として渡す。
let branches = [(0, 1, r1), (1, 2, r2), (1, 2, r3), (2, 3, r4), (0, 2, r5)];
let network = GroundedNetwork::new(4, &branches).map_err(|e| e.to_string())?;
// 節点 0 に 1 A を流し込み、接地した節点 3 から取り出す。
let v = network.potentials(0, 3).map_err(|e| e.to_string())?;

// 独立な検算: 直列・並列の合成と電流の分配。
let r23 = r2 * r3 / (r2 + r3);
let upper = r1 + r23; // 0 → 1 → 2 の経路
let r02 = 1.0 / (1.0 / upper + 1.0 / r5);
let hand_v2 = r4 * 1.0;
let hand = [r02 + hand_v2, hand_v2 + r23 * r02 / upper, hand_v2];

let rows: Vec<(String, f64, f64, f64)> = ["V₀（= R₀₃）", "V₁", "V₂"]
    .iter()
    .enumerate()
    .map(|(i, name)| (name.to_string(), v[i], hand[i], v[i] - hand[i]))
    .collect();
let sig15 = serde_json::json!({ "significantDigits": 15 });
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let columns = serde_json::json!([
    { "key": "0", "label": "電位" },
    { "key": "1", "label": "節点解析 [V]", "type": "number", "format": sig15 },
    { "key": "2", "label": "直列・並列の手計算 [V]", "type": "number", "format": sig15 },
    { "key": "3", "label": "差 [V]", "type": "number", "format": sci2 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "potentials" })
);
```

既定の $R_1 = 4$、$R_5 = 5$ Ω では、$R_2 \parallel R_3 = 1.2$ Ω、$R_1 + 1.2 = 5.2$ Ω を $R_5$ と並列にして $R_{02} = 2.549$ Ω、$R_4$ を足して $R_{03} = 3.549$ Ω になる。
節点解析の $V_0$、$V_1$、$V_2$ は手計算の値と $2 \times 10^{-15}$ V 以内で一致する。
節点 2 の電位がちょうど 1 V になるのは、流し込んだ 1 A がすべて $R_4 = 1$ Ω を通って接地に流れるからである。
$R_1 = 0.5$、$R_5 = 10$ Ω では、流し込んだ電流の 85 % が $R_1$ の経路を通り、合成抵抗は 2.453 Ω に下がる。

## まとめ

抵抗回路網の節点解析の行列はコンダクタンスを重みとするグラフのラプラシアンで、上三角に置いたコンダクタンス行列から `GraphPlan` と `LaplacianPlan` で作れる。
並列な枝は `GraphPlan` では合算されないので、組立ての `DuplicatePolicy::Sum` でコンダクタンスを足してから渡す。
ラプラシアンは定数ベクトルを零空間に持つので、一つの節点を接地してその行と列を除けば、連結な回路網では対称正定値な系になり、`SparseCholesky::new` で解ける。
連結でない回路網では接地した行列が特異で、分解が成功しても意味のない電位が返ることがあるので、分解の前に `connected_components` で連結性を確かめる。
有効抵抗は二つの節点に単位の電流を出し入れした系の電位差で、一度の分解のあと、各枝について前進代入と後退代入の 1 組で求まる。
Foster の定理 $\sum_e R_{\mathrm{eff}}(e)/R_e = n - 1$ は抵抗のばらつきによらず成り立つので全枝の計算をまとめて確かめられ、一様な格子では個々の有効抵抗を固有展開の値と比べられる。
