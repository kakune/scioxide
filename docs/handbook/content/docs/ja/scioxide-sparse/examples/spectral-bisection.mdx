グラフの頂点を、間の辺ができるだけ少なくなるように二つに分ける問題は、並列計算の領域分割、画像の領域分け、クラスタリングに現れる。
大きさの釣り合いを条件に切断を最小にする分割を厳密に求める問題は NP 困難なので、実際にはラプラシアンの固有ベクトルを使う緩和がよく用いられる。
この例題ではラプラシアンの 2 番目に小さい固有値 $\lambda_2$（代数的連結度）とその固有ベクトル（Fiedler ベクトル）を、`SparseCholesky` によるシフト付き逆反復で求め、成分の符号でグラフを二つに分ける。
独立な検算として、道グラフと格子の $\lambda_2$ の解析値、固有対の残差、得られた分割の切断から作る $\lambda_2$ の上界、二つの塊を弱くつないだグラフの切断辺の数を使う。

## ラプラシアンのスペクトル

非負の重み $w_{ij}$ を持つ $n$ 頂点の無向グラフの重み行列を $\mathbf{W}$、次数 $d_i = \sum_j w_{ij}$ を並べた対角行列を $\mathbf{D}$ とする。
ラプラシアン $\mathbf{L} = \mathbf{D} - \mathbf{W}$ は

$$
\mathbf{x}^{\mathsf{T}}\mathbf{L}\mathbf{x} = \sum_{\{i,j\}} w_{ij}(x_i - x_j)^2 \ge 0
$$

（和は辺についてとる）を満たすので半正定値で、固有値を $0 = \lambda_1 \le \lambda_2 \le \cdots \le \lambda_n$ と並べると、$\lambda_1 = 0$ の固有ベクトルは $\mathbf{1}$ である（[グラフのラプラシアン](oxref:sparse-graph-laplacian)）。
Courant–Fischer の定理により

$$
\lambda_2 = \min_{\mathbf{x} \perp \mathbf{1},\ \mathbf{x} \ne \mathbf{0}} \frac{\mathbf{x}^{\mathsf{T}}\mathbf{L}\mathbf{x}}{\mathbf{x}^{\mathsf{T}}\mathbf{x}}
$$

で、$\lambda_2 > 0$ であることとグラフが連結であることは同値である（Fiedler, 1973）。

頂点の集合 $S$ とその補集合 $\bar{S}$ への分割について、両方にまたがる辺の重みの和を切断 $\mathrm{cut}(S)$ と書く。
$x_i = 1/|S|$（$i \in S$）、$x_i = -1/|\bar{S}|$（$i \in \bar{S}$）とおくと $\mathbf{x} \perp \mathbf{1}$ で、Rayleigh 商は $\mathrm{cut}(S)\,(1/|S| + 1/|\bar{S}|)$ になる。
したがってどの分割についても

$$
\lambda_2 \le \mathrm{cut}(S)\left(\frac{1}{|S|} + \frac{1}{|\bar{S}|}\right)
$$

が成り立ち、右辺（比切断と呼ぶ）を最小にする分割は、成分が二つの値しかとらない $\mathbf{x}$ についての最小化にあたる。
この制約を外して実数の $\mathbf{x}$ で最小化したものが $\lambda_2$ で、最小値を与える Fiedler ベクトルの符号で頂点を分けると、切断の小さい分割の近似が得られる。
これは発見的な方法で、最小の切断を保証しない。
上の不等式は、得られた分割の比切断が $\lambda_2$ をどれだけ上回るかで、分割の良さを確かめる手段にもなる。

対称に正規化したラプラシアン $\mathbf{L}_{\mathrm{sym}} = \mathbf{D}^{-1/2}\mathbf{L}\mathbf{D}^{-1/2}$ では、$\lambda_1 = 0$ の固有ベクトルが $\mathbf{D}^{1/2}\mathbf{1}$ になる。
固有ベクトル $\mathbf{g}$ を $\mathbf{f} = \mathbf{D}^{-1/2}\mathbf{g}$ で頂点の値に戻すと、Rayleigh 商は $\mathbf{f}^{\mathsf{T}}\mathbf{L}\mathbf{f}/\mathbf{f}^{\mathsf{T}}\mathbf{D}\mathbf{f}$ になり、上の議論の $|S|$ が次数の和 $\mathrm{vol}(S) = \sum_{i \in S} d_i$ に置き換わる。
上界は $\lambda_2 \le \mathrm{cut}(S)\,(1/\mathrm{vol}(S) + 1/\mathrm{vol}(\bar{S}))$（右辺は正規化切断と呼ぶ）で、$\mathbf{f}$ の符号で分ける。
正規化した $\lambda_2$ は Cheeger の不等式 $\lambda_2/2 \le h(G) \le \sqrt{2\lambda_2}$ で、Cheeger 定数 $h(G) = \min_S \mathrm{cut}(S)/\min(\mathrm{vol}(S), \mathrm{vol}(\bar{S}))$ と結び付く（Chung, 1997）。

### 解析値

$s$ 頂点の道グラフ（重み 1）のラプラシアンは、両端の対角が 1、内側の対角が 2 の三重対角行列で、固有値と固有ベクトルは

$$
\lambda_k = 2\left(1 - \cos\frac{(k - 1)\pi}{s}\right), \qquad x_i = \cos\frac{(k - 1)\pi\,(i + 1/2)}{s} \qquad (k = 1, \dots, s;\ i = 0, \dots, s - 1)
$$

である。
したがって $\lambda_2 = 2(1 - \cos(\pi/s))$ で、Fiedler ベクトルは半周期の余弦になり、符号は中央で変わる。
$s \times s$ の格子は二つの道グラフの直積なので、固有値は道グラフの固有値の和 $\lambda_k + \lambda_l$ である。
最小の正の固有値は $\lambda_2 + \lambda_1$ と $\lambda_1 + \lambda_2$ の二つで、格子の $\lambda_2$ も $2(1 - \cos(\pi/s))$ になり、重複度は 2 である。
正規化したラプラシアンでは、道グラフの固有値は $1 - \cos((k - 1)\pi/(s - 1))$、頂点の値に戻した固有ベクトルは $f_i = \cos((k - 1)\pi i/(s - 1))$ になり、$\lambda_2 = 1 - \cos(\pi/(s - 1))$ となる。
格子の正規化したラプラシアンは次数が頂点ごとに違うので直積にならず、簡単な閉じた形はない。

## シフト付き逆反復

$\lambda_2$ は小さい側の固有値なので、$\mathbf{L} + \sigma\mathbf{I}$（$\sigma > 0$ の小さなシフト）を一度だけ Cholesky 分解し、

$$
\mathbf{y}_{k+1} = (\mathbf{L} + \sigma\mathbf{I})^{-1}\mathbf{x}_k, \qquad \mathbf{x}_{k+1} = \frac{\mathbf{y}_{k+1} - (\mathbf{v}_1^{\mathsf{T}}\mathbf{y}_{k+1})\mathbf{v}_1}{\|\mathbf{y}_{k+1} - (\mathbf{v}_1^{\mathsf{T}}\mathbf{y}_{k+1})\mathbf{v}_1\|_2}
$$

を繰り返す。
$\mathbf{L}$ 自身は特異なので、シフトで正定値にしてから分解する。
$\mathbf{v}_1$ は正規化した $\lambda_1$ の固有ベクトル（$\mathbf{1}/\sqrt{n}$、正規化したラプラシアンでは $\mathbf{D}^{1/2}\mathbf{1}$ を正規化したもの）で、その成分を毎回取り除くので、反復は $\lambda_2$ の固有ベクトルに収束する。
誤差は一回ごとにおよそ $(\lambda_2 + \sigma)/(\lambda_3 + \sigma)$ 倍になる。
格子のように $\lambda_2 = \lambda_3$ のときは、$\mathbf{x}_k$ は二つの固有ベクトルが張る空間に $(\lambda_2 + \sigma)/(\lambda_4 + \sigma)$ の割合で近づき、その空間のどのベクトルになるかは初期値で決まる。

固有値は Rayleigh 商 $\theta = \mathbf{x}^{\mathsf{T}}\mathbf{L}\mathbf{x}$（$\|\mathbf{x}\|_2 = 1$）で求める。
$\mathbf{L}$ は対称なので、$\theta$ から距離 $\|\mathbf{L}\mathbf{x} - \theta\mathbf{x}\|_2$ 以内に少なくとも一つの固有値がある。
固有値の間隔が残差より十分大きければ、$\theta$ の誤差は残差の 2 乗を固有値の間隔で割った程度になる。

scioxide-sparse では重み行列から `GraphPlan::new` と `GraphPlan::laplacian` で `LaplacianPlan` を作り、`matrix()` が $\mathbf{L}$、`degrees()` が次数を返す。
シフトした行列は `CsrMatrix::identity` を `scaled` で $\sigma$ 倍して `add` で足し、準備を一括して行うコンストラクター `SparseCholesky::new` で分解する（近似最小次数の並べ替え、両方の三角を読んで対称性を確かめる）。
`SparseCholesky::new` は厳密に対称でない行列を `InvalidInput` で拒む。
対称に正規化したラプラシアンは、成分 $(u, v)$ を $(w_{uv}/\sqrt{d_u})/\sqrt{d_v}$、成分 $(v, u)$ を $(w_{uv}/\sqrt{d_v})/\sqrt{d_u}$ の順に割って丸めるので、最後の桁が食い違うことがある。
そこで実験の一つ目のセルは、分解の前に $(\mathbf{L} + \mathbf{L}^{\mathsf{T}})/2$ で対称にそろえる（正規化しない $\mathbf{L}$ は変わらない）。
反復の中では出力先を指定する API `solve_into` に、`workspace(1)` で一度だけ作った作業領域を渡すので、反復ごとのメモリ領域の確保は起きない。
大きなグラフで多くの固有値が必要なときは、scioxide-linalg の [LOBPCG](../../../scioxide-linalg/algorithms/partial-spectra/#lobpcg) のような部分固有値の解法を使う。

## 三種類のグラフの分割

実験には道グラフ（$s$ 頂点）、格子（$s \times s$ 頂点）、二つの塊（$s/2$ 頂点の完全グラフを二つ、重み $w$ の辺 2 本でつなぐ）を使い、辺の重みは塊の間の 2 本を除いて 1 とする。
次のブロックは、このページの二つのセルが共有する定義である。
`graph_edges` がグラフの種類と大きさから頂点の数と辺の一覧を作り、二つ目のセルは一つ目のセルと同じ入力から同じ辺を作り直して切断を数える。

```rust
//| id: sparse-spectral-graphs
//| kind: definitions
//| title: 道グラフ、格子、二つの塊の辺
//| crates: []
/// 頂点の数と、辺 (u, v, 重み) の一覧（各辺を一度だけ並べる）を返す。
/// 格子の頂点は p = 行の番号 · s + 列の番号、二つの塊は頂点 0〜s/2 − 1 と s/2〜s − 1。
pub(crate) fn graph_edges(kind: &str, s: usize, bridge: f64) -> (usize, Vec<(usize, usize, f64)>) {
    let mut edges: Vec<(usize, usize, f64)> = Vec::new();
    let n = match kind {
        "格子" => {
            for p in 0..s * s {
                if p % s + 1 < s {
                    edges.push((p, p + 1, 1.0));
                }
                if p + s < s * s {
                    edges.push((p, p + s, 1.0));
                }
            }
            s * s
        }
        "二つの塊" => {
            let h = s / 2;
            for c in [0, h] {
                for i in 0..h {
                    for j in i + 1..h {
                        edges.push((c + i, c + j, 1.0));
                    }
                }
            }
            edges.push((0, h, bridge));
            edges.push((h - 1, 2 * h - 1, bridge));
            2 * h
        }
        _ => {
            edges.extend((0..s - 1).map(|i| (i, i + 1, 1.0)));
            s
        }
    };
    (n, edges)
}
```

次のセルは選んだグラフの重み行列を組み立てる。
正規化しない、または対称に正規化したラプラシアンを作り、$\sigma = 10^{-3}$ のシフト付き逆反復を 200 回行って $\lambda_2$ と Fiedler ベクトルを求める。
入力はグラフの種類、大きさ $s$（6〜30）、塊の間の重み $w$（0.01〜1）、正規化の有無である。
表は頂点の数、Rayleigh 商で求めた $\lambda_2$、固有対の残差 $\|\mathbf{L}\mathbf{x} - \lambda_2\mathbf{x}\|_2$ で、残差が丸め誤差の程度であることを確かめる。
このセルはグラフの種類、大きさ、塊の間の重み、正規化の有無、次数、$\lambda_2$、頂点の値に戻した Fiedler ベクトル（正規化した場合は $\mathbf{D}^{-1/2}$ を掛けた値）を次のセルに渡す。

```rust
//| id: sparse-spectral-bisection
//| ref: sparse-spectral-bisection
//| title: シフト付き逆反復によるラプラシアンの λ₂ と Fiedler ベクトル
//| run: reactive
//| uses: [sparse-spectral-graphs]
//| crates: [scioxide-core, scioxide-sparse]
//| exports: [graph, size, bridge, normalized, degrees, lambda2, fiedler]
//| inputs:
//|   graph_kind: {"type":"select","label":"グラフ","description":"分割するグラフの形。","options":["道グラフ","格子","二つの塊"],"value":"道グラフ"}
//|   size: {"type":"range","label":"大きさ s","description":"道グラフの頂点の数、格子の辺の頂点の数、二つの塊の頂点の総数。","min":6,"max":30,"step":2,"value":16}
//|   bridge: {"type":"range","label":"塊の間の重み w","description":"二つの塊をつなぐ 2 本の辺の重み。","min":0.01,"max":1.0,"step":0.01,"value":0.1}
//|   normalized: {"type":"checkbox","label":"対称に正規化したラプラシアンを使う","description":"次数で重み付けた正規化切断を小さくする分割になる。","value":false}
//| cases:
//|   - {"id":"grid","label":"格子","description":"λ₂ は道グラフと同じで重複度 2、符号の分割は格子を一直線に切る。","inputs":{"graph_kind":"格子"}}
//|   - {"id":"clusters","label":"二つの塊、w = 0.1","description":"切断は塊の間の 2 本だけで、λ₂ は比切断の上界に近い。","inputs":{"graph_kind":"二つの塊"}}
//|   - {"id":"strong-bridge","label":"二つの塊、w = 1","description":"塊の間のつながりが強まり、λ₂ が増える。","inputs":{"graph_kind":"二つの塊","bridge":1.0}}
//|   - {"id":"normalized-path","label":"道グラフ、正規化","description":"λ₂ は 1 − cos(π/(s − 1)) に一致する。","inputs":{"normalized":true}}
//|   - {"id":"normalized-clusters","label":"二つの塊、正規化","description":"λ₂ は正規化切断の上界 2w(1/vol(S) + 1/vol(S̄)) をわずかに下回る。","inputs":{"graph_kind":"二つの塊","normalized":true}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"eigenpair","path":"/rows/0/0","equals":16}
//|       - {"artifact":"eigenpair","path":"/rows/0/1","approx":{"value":0.0384294391935391,"rtol":1e-10}}
//|       - {"artifact":"eigenpair","path":"/rows/0/2","range":{"max":1e-12}}
//|   - case: grid
//|     expect:
//|       - {"artifact":"eigenpair","path":"/rows/0/0","equals":256}
//|       - {"artifact":"eigenpair","path":"/rows/0/1","approx":{"value":0.0384294391935391,"rtol":1e-10}}
//|       - {"artifact":"eigenpair","path":"/rows/0/2","range":{"max":1e-12}}
//|   - case: clusters
//|     expect:
//|       - {"artifact":"eigenpair","path":"/rows/0/1","range":{"min":0.045,"max":0.05}}
//|       - {"artifact":"eigenpair","path":"/rows/0/2","range":{"max":1e-12}}
//|   - case: strong-bridge
//|     expect:
//|       - {"artifact":"eigenpair","path":"/rows/0/1","range":{"min":0.4,"max":0.5}}
//|   - case: normalized-path
//|     expect:
//|       - {"artifact":"eigenpair","path":"/rows/0/1","approx":{"value":0.0218523992661943,"rtol":1e-10}}
//|   - case: normalized-clusters
//|     expect:
//|       - {"artifact":"eigenpair","path":"/rows/0/1","range":{"min":0.0065,"max":0.0071174377}}
//|       - {"artifact":"eigenpair","path":"/rows/0/2","range":{"max":1e-12}}
use scioxide_core::{ExecutionContext, RealScalar};
use scioxide_sparse::{
    CsrMatrix, DuplicatePolicy, ExplicitZeroPolicy, GraphDirection, GraphPlan, LaplacianDegree,
    LaplacianNormalization, SparseBuilder, SparseCholesky, SparseOperation, SparseSolveOptions,
};

let s = size as usize;
let (n, edges) = graph_edges(&graph_kind, s, bridge);
// 重み行列 W（両方向の成分を持つ）から L = D − W または D^(−1/2)(D − W)D^(−1/2) を作る。
let mut builder = SparseBuilder::new(n, n);
for &(u, v, w) in &edges {
    builder.push(u, v, w).map_err(|e| e.to_string())?;
    builder.push(v, u, w).map_err(|e| e.to_string())?;
}
let weights = builder
    .finish_csr(DuplicatePolicy::Reject, ExplicitZeroPolicy::Drop)
    .map_err(|e| e.to_string())?;
let normalization = if normalized {
    LaplacianNormalization::Symmetric
} else {
    LaplacianNormalization::Unnormalized
};
let plan = GraphPlan::new(weights.view(), GraphDirection::Undirected)
    .and_then(|graph| graph.laplacian::<f64>(LaplacianDegree::Out, normalization))
    .map_err(|e| e.to_string())?;
// 正規化した値は (u, v) と (v, u) で別々に丸められ、最後の桁が食い違うことがある。
// SparseCholesky::new は厳密な対称性を求めるので、(L + Lᵀ)/2 で対称にそろえる。
let l = plan
    .matrix()
    .transpose()
    .and_then(|t| t.to_csr())
    .and_then(|t| t.add(plan.matrix()))
    .and_then(|t| t.view().scaled(0.5))
    .map_err(|e| e.to_string())?;
let degrees = plan.degrees();
// λ₁ の固有ベクトル v₁（正規化なしは 1、正規化ありは D^(1/2) 1）を正規化する。
let norm = |v: &[f64]| RealScalar::sqrt(v.iter().fold(0.0_f64, |t, x| t + x * x));
let mut v1: Vec<f64> = degrees
    .iter()
    .map(|&d| if normalized { RealScalar::sqrt(d) } else { 1.0 })
    .collect();
let scale = norm(&v1);
v1.iter_mut().for_each(|x| *x /= scale);
// L + σI（σ = 10⁻³）を準備を一括して行うコンストラクターで Cholesky 分解する。
let shifted = CsrMatrix::identity(n)
    .and_then(|identity| identity.view().scaled(1e-3))
    .and_then(|shift| l.add(&shift))
    .map_err(|e| e.to_string())?;
let factor = SparseCholesky::new(&shifted).map_err(|e| e.to_string())?;
let mut workspace = factor.workspace(1).map_err(|e| e.to_string())?;
// 逆反復。初期値は v₁ と平行でない傾いたベクトルで、毎回 v₁ の成分を除いて正規化する。
let mut x: Vec<f64> = (0..n).map(|i| i as f64 - 0.37 * n as f64).collect();
let mut y = vec![0.0_f64; n];
for _ in 0..200 {
    factor
        .solve_into(
            &x,
            SparseOperation::Normal,
            SparseSolveOptions::new(),
            &mut y,
            &mut workspace,
            ExecutionContext::sequential(),
        )
        .map_err(|e| e.to_string())?;
    let c = y.iter().zip(&v1).fold(0.0_f64, |t, (a, b)| t + a * b);
    y.iter_mut().zip(&v1).for_each(|(a, b)| *a -= c * b);
    let length = norm(&y);
    x.iter_mut().zip(&y).for_each(|(a, b)| *a = b / length);
}
// Rayleigh 商 θ = xᵀLx と固有対の残差 ‖Lx − θx‖₂。
let lx = l.apply(&x).map_err(|e| e.to_string())?;
let lambda2 = x.iter().zip(&lx).fold(0.0_f64, |t, (a, b)| t + a * b);
let pair: Vec<f64> = lx.iter().zip(&x).map(|(a, b)| a - lambda2 * b).collect();
let (fixed10, sci2) = (
    serde_json::json!({ "fractionDigits": 10 }),
    serde_json::json!({ "notation": "scientific", "significantDigits": 2 }),
);
let columns = serde_json::json!([
    { "key": "0", "label": "頂点の数 n", "type": "integer" },
    { "key": "1", "label": "λ₂（Rayleigh 商）[-]", "type": "number", "format": fixed10 },
    { "key": "2", "label": "残差 ‖Lx − λ₂x‖₂ [-]", "type": "number", "format": sci2 }
]);
emit_table_with_columns!(
    columns,
    vec![(n, lambda2, norm(&pair))],
    metadata = serde_json::json!({ "id": "eigenpair" })
);
// 頂点の値 f = D^(−1/2) x（正規化しないときは x のまま）を次のセルに渡す。
let fiedler: Vec<f64> = x
    .iter()
    .zip(degrees)
    .map(|(&a, &d)| {
        if normalized {
            a / RealScalar::sqrt(d)
        } else {
            a
        }
    })
    .collect();
export!(graph, graph_kind);
export!(size, s);
export!(bridge, bridge);
export!(normalized, normalized);
export!(degrees, degrees);
export!(lambda2, lambda2);
export!(fiedler, fiedler);
```

次のセルは前のセルの結果を受け取り、$\lambda_2$ を解析値と比べ、Fiedler ベクトルの符号でグラフを二つに分ける。
解析値（道グラフと、正規化しない格子）と破線の固有ベクトルは閉じた形から計算するので、逆反復とは独立な検算になる。
表は解析値と $\lambda_2$ との差、符号で分けた二つの集合の大きさ、切断辺の数と重み、その分割から作る $\lambda_2$ の上界（比切断、正規化した場合は正規化切断）と、上界の $\lambda_2$ に対する比である。
グラフは頂点の番号ごとの Fiedler ベクトルの値で、道グラフでは解析的な固有ベクトルを最小二乗で尺度を合わせて破線で重ねる。
このセルは前のセルの入力に従い、自分の入力を持たない。

```rust
//| id: sparse-spectral-bisection-analysis
//| ref: sparse-spectral-bisection-analysis
//| title: Fiedler ベクトルの符号による二分割と λ₂ の上界
//| run: reactive
//| uses: [sparse-spectral-graphs]
//| crates: [scioxide-core]
//| dependsOn:
//|   eigen: sparse-spectral-bisection
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"partition","path":"/rows/0/0","approx":{"value":0.0384294391935391,"rtol":1e-12}}
//|       - {"artifact":"partition","path":"/rows/0/1","range":{"max":1e-12}}
//|       - {"artifact":"partition","path":"/rows/0/2","equals":8}
//|       - {"artifact":"partition","path":"/rows/0/3","equals":8}
//|       - {"artifact":"partition","path":"/rows/0/4","equals":1}
//|       - {"artifact":"partition","path":"/rows/0/6","approx":{"value":0.25,"rtol":1e-12}}
//|       - {"artifact":"partition","path":"/rows/0/7","range":{"min":6.4,"max":6.6}}
use scioxide_core::RealScalar;

let graph = eigen["graph"].as_str().ok_or("グラフの種類がない")?;
let s = eigen["size"].as_u64().ok_or("大きさがない")? as usize;
let bridge = eigen["bridge"].as_f64().ok_or("塊の間の重みがない")?;
let normalized = eigen["normalized"].as_bool().ok_or("正規化の有無がない")?;
let lambda2 = eigen["lambda2"].as_f64().ok_or("λ₂ がない")?;
// 前のセルと同じ入力から、同じグラフの辺を作る。
let (n, edges) = graph_edges(graph, s, bridge);
let degrees: Vec<f64> =
    serde_json::from_value(eigen["degrees"].clone()).map_err(|e| e.to_string())?;
let fiedler: Vec<f64> =
    serde_json::from_value(eigen["fiedler"].clone()).map_err(|e| e.to_string())?;
// 符号で S = {i : f_i ≥ 0} と S̄ に分け、|S| または vol(S) で上界を作る。
let side: Vec<bool> = fiedler.iter().map(|&v| v >= 0.0).collect();
let crossing: Vec<f64> = edges
    .iter()
    .filter(|&&(u, v, _)| side[u] != side[v])
    .map(|e| e.2)
    .collect();
let cut: f64 = crossing.iter().sum();
let measure = |inside: bool| -> f64 {
    (0..n)
        .filter(|&i| side[i] == inside)
        .map(|i| if normalized { degrees[i] } else { 1.0 })
        .sum()
};
let bound = cut * (1.0 / measure(true) + 1.0 / measure(false));
let positive = side.iter().filter(|&&b| b).count();
// 解析値（逆反復とは独立な検算）: 道と格子は 2(1 − cos(π/s))、正規化した道は 1 − cos(π/(s − 1))。
let pi = core::f64::consts::PI;
let analytic = match (graph, normalized) {
    ("道グラフ", false) | ("格子", false) => {
        Some(2.0 * (1.0 - RealScalar::cos(pi / s as f64)))
    }
    ("道グラフ", true) => Some(1.0 - RealScalar::cos(pi / (s - 1) as f64)),
    _ => None,
};
let rows = vec![(
    analytic,
    analytic.map(|a| (lambda2 - a).abs()),
    positive,
    n - positive,
    crossing.len(),
    cut,
    bound,
    bound / lambda2,
)];
let (fixed10, sci2, fixed4) = (
    serde_json::json!({ "fractionDigits": 10 }),
    serde_json::json!({ "notation": "scientific", "significantDigits": 2 }),
    serde_json::json!({ "fractionDigits": 4 }),
);
let columns = serde_json::json!([
    { "key": "0", "label": "解析値 [-]", "type": "number", "format": fixed10, "nullText": "なし" },
    { "key": "1", "label": "|λ₂ − 解析値| [-]", "type": "number", "format": sci2, "nullText": "なし" },
    { "key": "2", "label": "|S| [個]", "type": "integer" },
    { "key": "3", "label": "|S̄| [個]", "type": "integer" },
    { "key": "4", "label": "切断辺 [本]", "type": "integer" },
    { "key": "5", "label": "切断の重み [-]", "type": "number", "format": fixed4 },
    { "key": "6", "label": "λ₂ の上界 [-]", "type": "number", "format": fixed4 },
    { "key": "7", "label": "上界と λ₂ の比 [-]", "type": "number", "format": fixed4 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "partition" })
);
let points: Vec<[f64; 2]> = fiedler
    .iter()
    .enumerate()
    .map(|(i, &v)| [i as f64, v])
    .collect();
let mut layers = vec![serde_json::json!({
    "id": "fiedler",
    "kind": "scatter",
    "name": "Fiedler ベクトル",
    "points": points
})];
// 道グラフ: 解析的な固有ベクトルを最小二乗で尺度を合わせて重ねる（検算用）。
if graph == "道グラフ" {
    let shape: Vec<f64> = (0..n)
        .map(|i| {
            if normalized {
                RealScalar::cos(pi * i as f64 / (s - 1) as f64)
            } else {
                RealScalar::cos(pi * (i as f64 + 0.5) / s as f64)
            }
        })
        .collect();
    let fit = fiedler.iter().zip(&shape).fold(0.0, |t, (a, b)| t + a * b)
        / shape.iter().fold(0.0, |t, b| t + b * b);
    let curve: Vec<[f64; 2]> = shape
        .iter()
        .enumerate()
        .map(|(i, &b)| [i as f64, fit * b])
        .collect();
    layers.push(serde_json::json!({
        "id": "analytic",
        "kind": "line",
        "name": "解析的な固有ベクトル",
        "points": curve,
        "style": { "lineType": "dashed", "showSymbol": false }
    }));
}
emit_chart!(serde_json::json!({
    "kind": "xy",
    "xLabel": "頂点の番号 i [-]",
    "yLabel": "Fiedler ベクトルの値 [-]",
    "dataZoom": true,
    "tooltip": true,
    "layers": layers,
    "annotations": [{ "kind": "line", "axis": "y", "value": 0.0, "label": "符号の境目" }]
}));
```

既定の道グラフ（$s = 16$）では、逆反復で求めた $\lambda_2 = 0.0384294392$ と解析値 $2(1 - \cos(\pi/16))$ の差は $1.4 \times 10^{-17}$ で、固有対の残差は $2.3 \times 10^{-16}$ である。
Fiedler ベクトルは破線で描いた半周期の余弦に重なり、符号で分けると 8 頂点ずつになって、切断辺は中央の 1 本だけである。
この分割の比切断は $1 \times (1/8 + 1/8) = 0.25$ になる。
2 本以上の辺を切る分割の比切断は $2 \times 4/16 = 0.5$ 以上なので、0.25 は道グラフの比切断の最小値だが、表の比のとおり $\lambda_2$ の 6.5 倍ある。
上界 $\lambda_2 \le \mathrm{cut}(S)(1/|S| + 1/|\bar{S}|)$ は成り立つが、道グラフでは緩和した問題と元の問題の差が大きい。

格子（$16 \times 16$）の $\lambda_2$ も道グラフと同じ値になり、固有対の残差は $7.2 \times 10^{-16}$ である。
符号の分割は格子を中央の一直線で 128 頂点ずつに切り、切断辺は 16 本である。
格子では $\lambda_2 = \lambda_3$ なので Fiedler ベクトルは一つに決まらない。
頂点の番号 $i$ は行の番号の $s$ 倍と列の番号の和なので、初期値 $x_i = i - 0.37n$ は行の番号とともに大きく変わり、行の方向に変わる固有ベクトルの成分を多く含む。
二つの固有ベクトルの成分は同じ割合で減るので、その比は反復の後も保たれ、符号の分割は横の一直線になる。

二つの塊（$8 + 8$ 頂点、$w = 0.1$）では、Fiedler ベクトルが塊ごとに符号をそろえ、切断辺は塊の間の 2 本だけになる。
$\lambda_2 = 0.0491$ は、この分割の比切断 $2w(1/8 + 1/8) = 0.05$ をわずかに下回り、上界がほぼ等号になる。
比切断の最小値は $\lambda_2$ 以上なので、この分割の比切断は最小値の 1.02 倍以内である。
$w = 1$ に強めると $\lambda_2$ は 0.417 に増え、比切断の 0.5 との差が広がる。
塊の間のつながりが強まることが、代数的連結度の増加として現れる。

正規化したラプラシアンでは、道グラフの $\lambda_2 = 0.0218523993$ と $1 - \cos(\pi/15)$ の差は $1.9 \times 10^{-16}$ で、Fiedler ベクトルは破線の $\cos(\pi i/15)$ に重なる。
二つの塊では各塊の次数の和が $\mathrm{vol}(S) = 8 \times 7 + 2w = 56.2$ なので、正規化切断は $2w \times 2/56.2 = 0.00712$ で、$\lambda_2 = 0.00699$ はこれをわずかに下回る。
格子の正規化した $\lambda_2$ には閉じた形がないが、符号の分割は正規化しない場合と同じく一直線で 16 本を切る。
これらのグラフでは、正規化の有無で分割は変わらない。

## まとめ

ラプラシアンの 2 番目の固有値 $\lambda_2$ はグラフのつながりの強さを表し、その固有ベクトルの符号で頂点を分けると、切断の小さい分割の近似が得られる。
$\lambda_2$ は小さい側の固有値なので、ラプラシアンに小さなシフトを加えて `SparseCholesky` で一度分解し、$\lambda_1$ の固有ベクトルを取り除きながら逆反復を繰り返せば求まる。
道グラフと格子では $\lambda_2 = 2(1 - \cos(\pi/s))$、正規化した道グラフでは $1 - \cos(\pi/(s - 1))$ と解析値が分かり、反復の結果をこれと固有対の残差で確かめられる。
どの分割についても $\lambda_2$ は比切断（正規化した場合は正規化切断）以下なので、得られた分割の比切断を $\lambda_2$ で割った値は、最小値に対する比の上界になる。
弱くつないだ二つの塊では、Fiedler ベクトルが塊ごとに符号をそろえ、符号の分割が塊の間の辺だけを切る。
