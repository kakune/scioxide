有限要素法（FEM）や有限体積法（FVM）では、要素ごとに計算した局所行列を、全体の自由度の番号の位置へ足し合わせて全体行列を作る。
この工程を**組立て**（アセンブリ）と呼ぶ。
隣り合う要素は節点を共有するので、同じ位置 $(i, j)$ に複数の寄与が入る。

この例題では、接地ばねと連成ばねでつながった 1 次元の質点系の弾性エネルギーから、全体の剛性行列を組み立てる。
`SparseBuilder` による重複の合算と `CsrMatrix` への確定を、要素の数の閉形式と行和で確かめる。
続いて行列ベクトル積を、差分式、正弦波の変位に対する閉じた形、弾性エネルギーの三つで独立に検算する。

## 局所の弾性エネルギーと剛性行列

$n$ 個の質点の変位を $x_i$ [m]（$i = 0, \dots, n - 1$）とする。
各質点はばね定数 $a$ [N/m] の接地ばねで壁につながり、隣り合う質点 $i$ と $i + 1$ はばね定数 $k$ [N/m] の連成ばねでつながる。
系の弾性エネルギー [J] は

$$
E(\mathbf{x}) = \frac{a}{2} \sum_{i=0}^{n-1} x_i^2 + \frac{k}{2} \sum_{i=0}^{n-2} (x_{i+1} - x_i)^2
$$

である。
その勾配 $\nabla E(\mathbf{x}) = \mathbf{A}\mathbf{x}$ は、変位 $\mathbf{x}$ を保つために各質点へ加える**節点力** [N] で、成分は

$$
(\mathbf{A}\mathbf{x})_i = \frac{\partial E}{\partial x_i} = a x_i + k (x_i - x_{i-1}) + k (x_i - x_{i+1})
$$

となる（$i = 0$ では左隣の項、$i = n - 1$ では右隣の項がない）。
ばねが質点に及ぼす復元力は、節点力の符号を変えた $-\mathbf{A}\mathbf{x}$ である。

要素 $e = (i, i + 1)$ のエネルギーは $\frac{k}{2}(x_{i+1} - x_i)^2 = \frac{1}{2} [x_i, x_{i+1}]\, \mathbf{K}_e\, [x_i, x_{i+1}]^{\mathsf{T}}$ で、局所の剛性行列は

$$
\mathbf{K}_e = k \begin{bmatrix} 1 & -1 \\ -1 & 1 \end{bmatrix}
$$

である。
全体の剛性行列 $\mathbf{A}$ は、接地ばねの $n$ 個の対角寄与 $(i, i, a)$ と、各要素の 4 個の寄与 $(i, i, k)$、$(i+1, i+1, k)$、$(i, i+1, -k)$、$(i+1, i, -k)$ を足し合わせて得られる。
投入する三つ組は $n + 4(n - 1) = 5n - 4$ 個、重複を合算した後の非零は三重対角の $3n - 2$ 個である。
対角は両端で $a + k$、内部で $a + 2k$ になる。
$\mathbf{K}_e$ の各行の和は 0 なので、$\mathbf{A}$ の各行の和は接地ばねの $a$ に等しく、$\mathbf{A}\mathbf{1} = a\mathbf{1}$ が成り立つ。
すべての質点を同じだけ動かしても連成ばねは伸びないことを表す関係で、組み立てた行列の検算に使える。

$a > 0$ のとき、$\mathbf{x} \ne \mathbf{0}$ なら $\mathbf{x}^{\mathsf{T}}\mathbf{A}\mathbf{x} = 2E(\mathbf{x}) \ge a\lVert\mathbf{x}\rVert_2^2 > 0$ なので、$\mathbf{A}$ は対称正定値である。
接地ばねがない $a = 0$ では、$\mathbf{x} = \mathbf{1}$ でエネルギーが 0 になり、$\mathbf{A}$ は特異になる。

次のブロックは二つのセルが共有する定義である。
`GROUND_STIFFNESS` が接地ばねの $a = 0.5$ N/m、`spring_builder` が上の $5n - 4$ 個の三つ組を投入した `SparseBuilder` を返す関数に対応する。

```rust
//| id: sparse-spring-assembly-model
//| kind: definitions
//| title: ばね系の局所寄与の投入
//| crates: [scioxide-core, scioxide-sparse]
use scioxide_core::SciOxideError;
use scioxide_sparse::SparseBuilder;

/// 接地ばねのばね定数 a [N/m]。
pub(crate) const GROUND_STIFFNESS: f64 = 0.5;

/// 接地ばねの対角寄与 (i, i, a) と、要素 (i, i + 1) ごとの局所剛性行列
/// k [[1, −1], [−1, 1]] の 4 寄与を投入した n × n の SparseBuilder（三つ組は 5n − 4 個）。
pub(crate) fn spring_builder(n: usize, k: f64) -> Result<SparseBuilder<f64>, SciOxideError> {
    let mut builder = SparseBuilder::new(n, n);
    for i in 0..n {
        builder.push(i, i, GROUND_STIFFNESS)?;
    }
    for (i, j) in (0..n).zip(1..n) {
        for (row, col, value) in [(i, i, k), (j, j, k), (i, j, -k), (j, i, -k)] {
            builder.push(row, col, value)?;
        }
    }
    Ok(builder)
}
```

## 重複の合算と確定

`SparseBuilder::push` は投入のたびに添字の範囲（`OutOfBounds`）と値の有限性（`NonFinite`）を検査する。
`finish_csr` は三つ組を行優先に整列し（三つ組の数 $t$ に対して $O(t \log t)$）、重複を `DuplicatePolicy` で、続いて厳密な 0 を `ExplicitZeroPolicy` で処理して CSR を作る。
`DuplicatePolicy::Sum` は同じ座標の値を厳密に累積して一度だけ丸めるので、結果は投入の順序によらない。
`DuplicatePolicy::Reject` は整列したあとの最初の重複を `InvalidInput` で拒むので、対角に寄与が重なるこの組立てには使えない。
`ExplicitZeroPolicy::Drop` は合算のあとで厳密に 0 になった要素を取り除くが、このモデルでは合算が 0 になる座標がないので、`Preserve` と同じ行列になる。
`CsrMatrix::from_triplets` は同じ処理を `(Sum, Preserve)` の組で一度に行う。

## 重複の合算と行和

次のセルは自由度 $n$ と連成ばねの $k$ を入力として三つ組を投入し、`Sum` と `Reject` の二つの方針で確定する。
一つ目の表は三つ組と保存した要素の数を閉形式 $5n - 4$、$3n - 2$ と比べ、`Reject` で確定したときの結果を示す。
二つ目の表は両端の行 0、$n - 1$ と内部の行 1 について、合算した対角を $a + k$、$a + 2k$ と、行和を $a$ と比べる。
行和は全体を 1 m だけ動かしたときの節点力 $(\mathbf{A}\mathbf{1})_i$ [N] で、積 `apply` で求める。

```rust
//| id: sparse-spring-assembly
//| ref: sparse-spring-assembly
//| title: 局所ばねの重複寄与を合算して CSR に確定する
//| run: reactive
//| uses: [sparse-spring-assembly-model]
//| crates: [scioxide-core, scioxide-sparse]
//| inputs:
//|   sparse_dimension: {"type":"range","label":"自由度 n","description":"質点の数。","min":16,"max":96,"step":8,"value":32}
//|   spring_stiffness: {"type":"range","label":"連成ばねのばね定数 k [N/m]","description":"隣り合う質点をつなぐばねの強さ。","min":0.2,"max":5,"step":0.2,"value":1}
//| cases:
//|   - {"id":"many-masses","label":"n = 96","description":"保存する要素は 3n − 2 = 286 個で、密行列の n² = 9216 個の約 3 % になる。","inputs":{"sparse_dimension":96}}
//|   - {"id":"inexact-stiffness","label":"k = 0.2 N/m","description":"k が 2 進数で正確に表せないので丸めが入り、行和は a から最後の桁 1 つ分ずれる。","inputs":{"spring_stiffness":0.2}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"counts","path":"/rows/0/0","equals":156}
//|       - {"artifact":"counts","path":"/rows/0/1","equals":156}
//|       - {"artifact":"counts","path":"/rows/0/2","equals":94}
//|       - {"artifact":"counts","path":"/rows/0/3","equals":94}
//|       - {"artifact":"counts","path":"/rows/0/5","equals":"InvalidInput"}
//|       - {"artifact":"rows","path":"/rows/0/1","approx":{"value":1.5,"atol":1e-15}}
//|       - {"artifact":"rows","path":"/rows/1/1","approx":{"value":2.5,"atol":1e-15}}
//|       - {"artifact":"rows","path":"/rows/1/3","approx":{"value":0.5,"atol":1e-15}}
//|       - {"artifact":"rows","path":"/rows/1/4","equals":0}
//|   - case: many-masses
//|     expect:
//|       - {"artifact":"counts","path":"/rows/0/0","equals":476}
//|       - {"artifact":"counts","path":"/rows/0/2","equals":286}
//|       - {"artifact":"counts","path":"/rows/0/4","equals":9216}
//|       - {"artifact":"rows","path":"/rows/2/3","approx":{"value":0.5,"atol":1e-15}}
//|   - case: inexact-stiffness
//|     expect:
//|       - {"artifact":"rows","path":"/rows/0/1","approx":{"value":0.7,"atol":1e-15}}
//|       - {"artifact":"rows","path":"/rows/0/4","approx":{"value":-5.551115123125783e-17,"atol":1e-30}}
use scioxide_sparse::{DuplicatePolicy, ExplicitZeroPolicy};

let n = sparse_dimension as usize;
let k = spring_stiffness;
let a = GROUND_STIFFNESS;
let builder = spring_builder(n, k).map_err(|e| e.to_string())?;
let triplets = builder.triplet_count();
// 重複を拒む方針では、対角に重なった寄与で確定に失敗する。
let rejected = match builder
    .clone()
    .finish_csr(DuplicatePolicy::Reject, ExplicitZeroPolicy::Drop)
{
    Ok(_) => "成功".to_string(),
    Err(e) => format!("{:?}", e.kind()),
};
// 重複は厳密に合算して一度だけ丸め、合算後に 0 となった要素は取り除く。
let matrix = builder
    .finish_csr(DuplicatePolicy::Sum, ExplicitZeroPolicy::Drop)
    .map_err(|e| e.to_string())?;
// 行和 (A1)ᵢ [N]: 全体を 1 m 動かしたときの節点力。
let row_sums = matrix.apply(&vec![1.0; n]).map_err(|e| e.to_string())?;

let counts = serde_json::json!([
    { "key": "0", "label": "投入した三つ組 t", "type": "integer" },
    { "key": "1", "label": "5n − 4", "type": "integer" },
    { "key": "2", "label": "保存した要素 nnz(A)", "type": "integer" },
    { "key": "3", "label": "3n − 2", "type": "integer" },
    { "key": "4", "label": "密行列の要素 n²", "type": "integer" },
    { "key": "5", "label": "Reject で確定した結果" }
]);
let count_row = (
    triplets,
    5 * n - 4,
    matrix.nnz(),
    3 * n - 2,
    n * n,
    rejected,
);
emit_table_with_columns!(
    counts,
    vec![count_row],
    metadata = serde_json::json!({ "id": "counts" })
);

// 両端の行 0 と n − 1、内部の行 1 の対角と行和を閉形式と比べる。
let mut rows = Vec::new();
for (i, expected) in [(0, a + k), (1, a + 2.0 * k), (n - 1, a + k)] {
    let diagonal = matrix.get(i, i).map_err(|e| e.to_string())?;
    rows.push((i, diagonal, expected, row_sums[i], row_sums[i] - a));
}
let sig17 = serde_json::json!({ "significantDigits": 17 });
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let columns = serde_json::json!([
    { "key": "0", "label": "行 i", "type": "integer" },
    { "key": "1", "label": "合算した対角 Aᵢᵢ [N/m]", "type": "number", "format": sig17 },
    { "key": "2", "label": "a + k または a + 2k [N/m]", "type": "number", "format": sig17 },
    { "key": "3", "label": "行和 (A1)ᵢ [N]", "type": "number", "format": sig17 },
    { "key": "4", "label": "行和 − a [N]", "type": "number", "format": sci3 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "rows" })
);
```

既定の $n = 32$ では、投入した三つ組は 156 個、保存した要素は 94 個で、それぞれ $5n - 4$ と $3n - 2$ に一致し、密行列の 1024 個より少ない。
同じ三つ組を `Reject` で確定すると、対角の重複で `InvalidInput` になる。
両端の対角は接地ばねと 1 本の連成ばねの和 $a + k = 1.5$ N/m、内部の対角は 2 本の連成ばねを加えた $a + 2k = 2.5$ N/m で、行和はどの行でも $a = 0.5$ N に等しい。
この入力では値がどれも 2 進数で正確に表せるので、合算にも積にも丸めが入らず、行和は $a$ とちょうど一致する。
$k = 0.2$ N/m は 2 進数で正確に表せないので、合算した対角 $0.7$ と積の途中の和が丸められ、行和は $a$ より最後の桁 1 つ分（$2^{-54} \approx 5.6 \times 10^{-17}$ N）小さくなる。
この程度の差は丸めによるもので、組立ての誤りなら差は $k$ の大きさで現れる。

$n = 96$ では保存した要素は 286 個で、密行列の 9216 個の約 3 % になる。
密行列に対する割合は $(3n - 2)/n^2$ なので、$n$ にほぼ反比例して小さくなる。

## 正弦波の変位に対する節点力

$\theta = 2\pi/(n - 1)$、振幅を $X$ [m] として、両端で 0 になる正弦波の変位 $x_i = X\sin(i\theta)$ を与える。
内部の質点（$1 \le i \le n - 2$）では $x_{i-1} + x_{i+1} = 2\cos\theta\, x_i$ なので、

$$
(\mathbf{A}\mathbf{x})_i = (a + 2k)\,x_i - k\,(x_{i-1} + x_{i+1}) = \lambda x_i, \qquad \lambda = a + 4k\sin^2\frac{\theta}{2}
$$

となり、節点力は変位に比例する。
両端の質点は連成ばねを片側にしか持たないので、この比例関係から外れる。
$x_0 = x_{n-1} = 0$ と $x_{n-2} = -X\sin\theta$ から、$(\mathbf{A}\mathbf{x})_0 = -kX\sin\theta$、$(\mathbf{A}\mathbf{x})_{n-1} = kX\sin\theta$ である。
内部の節点力の大きさは高々 $\lambda X$ なので、$k\sin\theta > \lambda$ のときは両端の節点力が最大になる。
この条件は $k(\sin\theta - 4\sin^2(\theta/2)) > a$ と同じで、$n = 32$、$a = 0.5$ N/m では $k > 3.12$ N/m にあたる。

## CSR の積の検算

次のセルは同じ行列を組み立て、振幅 $X = 0.01$ m の正弦波の変位に対する節点力 $\mathbf{A}\mathbf{x}$ を計算する。
積は標準形式の `apply` で求める。
`apply` は保存した要素を一度ずつ使う `Accuracy::Standard`（通常の浮動小数点演算）の積で、手間は $O(\mathrm{nnz}(\mathbf{A}) + n)$ である。

独立な検算は三つある。
一つ目は成分ごとの差分式を倍精度の四則演算で直接計算した値、二つ目は内部の質点での比例関係 $\lambda x_i$、三つ目はエネルギーの式 $2E(\mathbf{x})$ と二次形式 $\mathbf{x}^{\mathsf{T}}(\mathbf{A}\mathbf{x})$ の比較である。
グラフは CSR の積を記号、内部の比例関係 $\lambda x_i$ を破線で描く。
表は最大の節点力と三つの検算の値を示す。

```rust
//| id: sparse-spring-product
//| ref: sparse-spring-product
//| title: 正弦波の変位に対する CSR の積を三つの方法で検算する
//| run: reactive
//| uses: [sparse-spring-assembly-model]
//| crates: [scioxide-core, scioxide-sparse]
//| inputs:
//|   sparse_dimension: {"type":"range","label":"自由度 n","description":"質点の数。","min":16,"max":96,"step":8,"value":32}
//|   spring_stiffness: {"type":"range","label":"連成ばねのばね定数 k [N/m]","description":"隣り合う質点をつなぐばねの強さ。","min":0.2,"max":5,"step":0.2,"value":1}
//| cases:
//|   - {"id":"stiff-coupling","label":"k = 5 N/m","description":"両端の質点の節点力 kX sin θ が、内部の最大の節点力を上回る。","inputs":{"spring_stiffness":5}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"checks","path":"/rows/0/0","approx":{"value":5.402458247333163e-3,"rtol":1e-12}}
//|       - {"artifact":"checks","path":"/rows/0/1","range":{"max":2e-17}}
//|       - {"artifact":"checks","path":"/rows/0/2","range":{"max":2e-17}}
//|       - {"artifact":"checks","path":"/rows/0/5","range":{"max":1e-14}}
//|   - case: stiff-coupling
//|     expect:
//|       - {"artifact":"checks","path":"/rows/0/0","approx":{"value":1.0064926004433e-2,"rtol":1e-12}}
//|       - {"artifact":"checks","path":"/rows/0/1","range":{"max":1e-16}}
//|       - {"artifact":"checks","path":"/rows/0/2","range":{"max":1e-16}}
//|       - {"artifact":"checks","path":"/rows/0/5","range":{"max":1e-14}}
use scioxide_core::RealScalar;
use scioxide_sparse::{DuplicatePolicy, ExplicitZeroPolicy};

let n = sparse_dimension as usize;
let k = spring_stiffness;
let a = GROUND_STIFFNESS;
let matrix = spring_builder(n, k)
    .and_then(|b| b.finish_csr(DuplicatePolicy::Sum, ExplicitZeroPolicy::Drop))
    .map_err(|e| e.to_string())?;

// 正弦波の変位 xᵢ = X sin(iθ) [m] に対する節点力 Ax [N]。
let amplitude = 0.01_f64;
let theta = 2.0 * core::f64::consts::PI / (n - 1) as f64;
let x: Vec<f64> = (0..n)
    .map(|i| amplitude * RealScalar::sin(theta * i as f64))
    .collect();
let force = matrix.apply(&x).map_err(|e| e.to_string())?;

// 独立な検算 1: 成分ごとの差分式（f64 の四則演算）。
let max_difference = (0..n)
    .map(|i| {
        let left = if i > 0 { x[i] - x[i - 1] } else { 0.0 };
        let right = if i + 1 < n { x[i] - x[i + 1] } else { 0.0 };
        (force[i] - (a * x[i] + k * (left + right))).abs()
    })
    .fold(0.0_f64, f64::max);
// 独立な検算 2: 内部の質点では (Ax)ᵢ = λxᵢ（λ は f64 の標準関数による参照値）。
let lambda = a + 4.0 * k * (theta / 2.0).sin().powi(2);
let interior_gap = (1..n - 1)
    .map(|i| (force[i] - lambda * x[i]).abs())
    .fold(0.0_f64, f64::max);
// 独立な検算 3: 二次形式 xᵀ(Ax) と弾性エネルギーの 2 倍 2E(x) [J]。
let quadratic: f64 = x.iter().zip(&force).map(|(p, q)| p * q).sum();
let stretch: f64 = x.windows(2).map(|w| (w[1] - w[0]) * (w[1] - w[0])).sum();
let energy2 = a * x.iter().map(|v| v * v).sum::<f64>() + k * stretch;
let max_force = force.iter().map(|f| f.abs()).fold(0.0_f64, f64::max);

let observed: Vec<[f64; 2]> = (0..n).map(|i| [i as f64, force[i]]).collect();
let proportional: Vec<[f64; 2]> = (0..n).map(|i| [i as f64, lambda * x[i]]).collect();
emit_chart!(
    serde_json::json!({
        "kind": "xy",
        "dataZoom": true,
        "tooltip": true,
        "xLabel": "質点の番号 i [-]",
        "yLabel": "節点力 (Ax)ᵢ [N]",
        "layers": [
            {
                "id": "proportional",
                "kind": "line",
                "name": "λxᵢ（内部の閉じた形）",
                "points": proportional,
                "style": { "lineType": "dashed", "showSymbol": false }
            },
            { "id": "csr", "kind": "scatter", "name": "CSR の積 (Ax)ᵢ", "points": observed }
        ]
    }),
    metadata = serde_json::json!({ "id": "forces" })
);

let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let sig16 = serde_json::json!({ "significantDigits": 16 });
let checks = serde_json::json!([
    { "key": "0", "label": "最大の節点力 max|(Ax)ᵢ| [N]", "type": "number", "format": sci3 },
    { "key": "1", "label": "差分式との最大差 [N]", "type": "number", "format": sci3 },
    { "key": "2", "label": "内部の λxᵢ との最大差 [N]", "type": "number", "format": sci3 },
    { "key": "3", "label": "xᵀ(Ax) [J]", "type": "number", "format": sig16 },
    { "key": "4", "label": "2E(x) [J]", "type": "number", "format": sig16 },
    { "key": "5", "label": "相対差 [-]", "type": "number", "format": sci3 }
]);
let relative = (quadratic - energy2).abs() / energy2;
let check_row = (
    max_force,
    max_difference,
    interior_gap,
    quadratic,
    energy2,
    relative,
);
emit_table_with_columns!(
    checks,
    vec![check_row],
    metadata = serde_json::json!({ "id": "checks" })
);
```

既定の $n = 32$、$k = 1$ N/m では、グラフの内部の 30 点の記号が破線 $\lambda x_i$ の上にあり、両端の 2 点だけが破線から外れる。
両端の節点力は $(\mathbf{A}\mathbf{x})_0 = -2.01 \times 10^{-3}$ N と $(\mathbf{A}\mathbf{x})_{n-1} = 2.01 \times 10^{-3}$ N で、内部の最大 $\lambda X \max_i \lvert\sin(i\theta)\rvert = 5.40 \times 10^{-3}$ N より小さい。
$k = 5$ N/m にすると、両端の節点力 $1.0065 \times 10^{-2}$ N が内部の最大 $7.04 \times 10^{-3}$ N を上回り、表の最大の節点力は閉じた形 $kX\sin\theta$ と丸めの程度で一致する。

差分式との最大差は $1.7 \times 10^{-18}$ N、内部の比例関係との最大差は $5.2 \times 10^{-18}$ N である。
どちらも成分の大きさの目安 $(a + 2k)X = 2.5 \times 10^{-2}$ N に計算機イプシロン $\varepsilon \approx 2.2 \times 10^{-16}$ を掛けた $5.6 \times 10^{-18}$ N 程度で、積と検算の双方の丸めで説明できる。
丸めの程度を大きく超える差があれば、端点の扱いと局所の寄与の組立てを疑う。
一度だけ丸める積と比べたい場合は、`matrix.view().with_accuracy(Accuracy::Exact)` を作用素として使う。

$\mathbf{x}^{\mathsf{T}}(\mathbf{A}\mathbf{x})$ と $2E(\mathbf{x})$ は数学的に等しく、計算値の相対差は $2.6 \times 10^{-16}$ である。
エネルギーの式は行列を使わずに計算するので、この一致は、組み立てた行列がモデルの二次形式を表していることの独立な確認になる。
値が正であることは、この $\mathbf{x}$ について正定値性と矛盾しないことを示すだけで、正定値性の根拠は上の不等式 $2E(\mathbf{x}) \ge a\lVert\mathbf{x}\rVert_2^2$ である。

## まとめ

組立てでは局所の寄与を順不同に `SparseBuilder` へ投入し、`DuplicatePolicy::Sum` で重複を厳密に合算してから一度だけ CSR に確定する。
対角に寄与が重なる組立てでは `Reject` は `InvalidInput` で失敗するので、重複を拒む方針は寄与が重ならないと分かっている入力の検査に使う。
保存した要素の数は三重対角の $3n - 2$ に一致し、メモリ使用量は密行列の $n^2$ ではなく $O(n)$ になる。
組み立てた行列は行和 $\mathbf{A}\mathbf{1} = a\mathbf{1}$ で確かめ、CSR の積は差分式、内部の比例関係、弾性エネルギーと比べれば、組立ての誤りや境界の扱いの誤りを丸めの程度を超える差として見つけられる。
