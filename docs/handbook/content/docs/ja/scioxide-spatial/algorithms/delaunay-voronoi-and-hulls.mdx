$n$ 個の母点（site）が与えられたとき、母点を包む最小の凸集合が凸包、母点を頂点とし外接球が他の母点を含まない単体への分割が Delaunay 分割、各母点に最も近い点の集合への空間の分割が Voronoi 図である。
Delaunay 分割と Voronoi 図は互いに双対で、Delaunay 分割は母点を 1 次元高い放物面へ持ち上げた点の凸包から得られる。
どれも「どの母点がどの面に乗るか」という組合せの構造と、外心（外接球の中心）や重心座標のような座標の値からなる。
`scioxide-spatial` は組合せの構造を厳密な幾何述語で決め、座標の値は丸めた値として返す。
このページでは母点の扱い、各構造の定義とアルゴリズム、計算量、API と失敗の分類を説明し、格子点で結果を確かめる。
述語の符号の求め方は[厳密な幾何述語](../exact-predicates/)に、二つの退化の方針の比較とリソース上限・構築情報は[退化の方針・リソース上限・構築情報](../tessellation-degeneracy-and-limits/)に、点を含む単体の探索と重心座標は[Delaunay 分割での点の位置と重心座標](../point-location/)にある。

## 母点の正準化と退化の扱い

`ConvexHull`、`Delaunay`、`Voronoi`、`SphericalVoronoi` は、1 行に 1 点を持つ `PointSet` を受け取る。
次元 $d$ は 1 以上で、既定の上限は 8 である（[リソース上限](oxref:spatial-tessellation-limits)の `GeometryLimits`）。

構築はまず母点を座標の辞書式順に並べ、座標が等しい行を 1 個の母点にまとめる（`-0.0` と `0.0` は等しいとみなす）。
並べ替えた後の母点の番号を正準添字と呼ぶ。
以後のすべての番号（単体の頂点、凸包のファセット、`find_simplex` が返す単体、Voronoi 領域）は、この正準添字である。
入力の行との対応は `ConvexHull` と `Delaunay` の次の二つで引く。

- `input_mapping()[r]` は、入力行 $r$ が属する母点の正準添字を返す。
- `representatives()[s]` は、母点 $s$ の代表の入力行、つまり同じ座標を持つ入力行のうち番号が最小の行を返す。

`Voronoi` はこの二つを直接持たないので、`voronoi.delaunay()` を通して引く。
`SphericalVoronoi` は `input_mapping()` だけを持つ。

`points()` は並べ替えた母点の座標を正準添字の順に返す。
正準添字は、重複がなくても一般に入力行の番号と一致しない。
入力側のデータ（観測値や名前）を母点ごとに引くときは、`representatives()` を通す。
並べ替えるので、結果は母点の集合だけで決まり、入力の行の順序によらない。
重複を含む入力行と正準添字の対応を表で確かめる例は、[入力行と母点の対応を確かめ、照会点を含む単体を探すセル](oxref:spatial-delaunay-point-location)にある。

母点は $\mathbb{R}^d$ を張らなければならない。
相異なる母点が $d+1$ 個未満のときや、すべての母点が一つの超平面（平面では一直線）に乗るときは、構築は `Singular` を返す。

平面の 4 点が同じ円の上にあるときのように、述語の値が厳密に 0 になる配置を退化と呼ぶ。
退化の扱いは `GeometryOptions` の `GeometryDegeneracy` で選ぶ。

- `Deterministic`（既定）は重複した母点をまとめ、Delaunay 分割と Voronoi 図で持ち上げた行列式（`incircle`・`insphere` にあたる）の厳密な 0 を記号摂動で解く。
  記号摂動は正準添字 $k$ の母点の持ち上げた座標に無限小 $\epsilon^{2^k}$ を加えたものとして行列式の符号を決める。
  値が 0 の行列式では、余因子が 0 でない最初の母点の項が支配的になり、その余因子（残りの点の向き）に行の位置で決まる符号 $\pm 1$ を掛けた値の符号が結果になる。
  同点を一つずつ別々に決めず、全体として一つの正則な三角形分割を選ぶ。
  考え方は Edelsbrunner–Mücke の simulation of simplicity と同じである。
- `Strict` は、重複した母点に `InvalidInput` を返す。
  Delaunay 分割と Voronoi 図では、出力の隣り合う 2 個の単体が空の外接球を共有するとき、つまり分割が一意でないときにも `InvalidInput` を返す。
  出力の単体に影響しない同点は受け入れる。

どちらの方針も座標を動かさず、同じ記号摂動を使うので、`Strict` が受け入れる入力では二つの方針の結果は一致する。
凸包の構築は持ち上げを使わない。
ファセットの超平面の上にある母点はそのファセットから見えないとみなすので、記号摂動を使わずに端点だけを頂点にする。
二つの方針の結果と構築の計算量を格子点で比べる例は[退化の方針と構築情報のセル](oxref:spatial-delaunay-degeneracy-policy)にある。

## 凸包の構成

凸包 $\operatorname{conv} P$ は母点の集合 $P$ を含む最小の凸集合で、その境界は $(d-1)$ 次元の面からなる。
`ConvexHull` は境界を $(d-1)$ 単体のファセット（facet）に分けて持つ。
立方体の正方形の面のように単体でない面は複数のファセットに分け、`coplanar_faces()` が同じ支持超平面に乗るファセットに同じ面の番号を付ける。
ファセットの頂点は凸包の端点だけである。
正方形の辺の途中にある母点のように、境界に乗っていても端点でない母点は頂点にならない。

アルゴリズムは乱択逐次添加（randomized incremental construction、Clarkson–Shor）で、加える順序は乱数ではなく正準添字のハッシュで固定する。

1. 加える順序の先頭から母点を調べ、厳密な行列式の符号でアフィン独立な $d+1$ 個を選んで最初の単体とする。
2. 残りの母点を決まった順に一つずつ加える。
   まだ加えていない母点にはその点から見えるファセットを一つ記録しておく（衝突リスト）。
3. 加える点 $p$ から見えるファセット（$p$ が外側にあるファセット）をすべて取り除き、その境界（地平線）の各稜と $p$ を結ぶファセットで穴をふさぐ。
   凸包の内側に入った母点は以後の処理から外れる。

「見える」かどうかはファセットと $p$ の向き述語の符号で決め、すべて厳密に評価する。
したがって組合せの構造は与えた座標に対して正確で、丸めによる自己矛盾は起きない。

加える順序は正準添字に鍵付きの SplitMix64 ハッシュをかけた値の昇順である。
乱数生成器は使わない。
同じ母点の集合からは常に同じ順序と同じ結果が得られ、入力の行の順序にもよらない。
Clarkson–Shor の解析によれば、加える順序が一様に乱択のとき、期待計算量は 2・3 次元で $O(n \log n)$、$d \ge 4$ で $O(n^{\lfloor d/2 \rfloor})$ である。
この期待値は順序の取り方についての平均である。
ハッシュで固定した順序は乱択の順序を模すが、個々の入力でこの計算量を保証するものではない。
高次元では凸包のファセット数自体が最悪で $n^{\lfloor d/2 \rfloor}$ に比例して増える（上界定理）ので、ファセット数とメモリ領域の上限が効く。

`ConvexHull::new(&points)` で作り、`facet_count()`、`facet(i)`（頂点の正準添字を昇順で）、`neighbors(i)`（各頂点の向かいの稜を共有するファセット）で境界をたどる。
`facets()` は全ファセットの頂点を 1 ファセット $d$ 個ずつ並べた平らな列として参照を返す。
`contains(point)` は閉じた凸包に点が含まれるかを、ファセットごとに 1 回の厳密な向き述語で判定し、計算量は $O(\text{ファセット数})$ である。
`contains` は呼び出しごとに作業領域を確保するので、多数の点を判定するときは事前確保した作業領域を `contains_scoped(point, &mut workspace, cx)` に渡す。
点の長さが凸包の次元と違えば `DimensionMismatch`、NaN や無限大を含めば `NonFinite` を返す。

## 放物面持ち上げによる Delaunay 分割

母点を頂点とする単体分割のうち、どの単体の外接球の内部にも他の母点がないものを Delaunay 分割と呼ぶ。
平面では、Delaunay 分割はすべての三角形分割の中で最小の内角を最大にする（Lawson、Sibson）。
この性質は[Delaunay 分割の最小角最大化](../../examples/delaunay-min-angle/)で確かめられる。

Delaunay 分割は点 $x \in \mathbb{R}^d$ を放物面上の点

$$
\hat x = (x, \|x\|^2) \in \mathbb{R}^{d+1}
$$

に持ち上げて得られる。
平面で 3 点 $a, b, c$ を通る円の中心を $m$、半径を $\rho$ とすると、$\|x\|^2 - 2 m \cdot x + \|m\|^2 - \rho^2$ は円の内部で負、外部で正である。
これは $\hat x$ が、$\hat a, \hat b, \hat c$ を通る平面 $z = 2 m \cdot x - \|m\|^2 + \rho^2$ の下にあるか上にあるかと同じである。
したがって「点 $q$ が外接円の内部にある」ことは「$\hat q$ が持ち上げた 3 点の平面より下にある」ことと同値で、`incircle` は持ち上げた 4 点の向き述語にほかならない。
持ち上げた点の凸包の下側のファセット（最後の座標の負の向きから見えるもの）を $\mathbb{R}^d$ へ射影すると、その単体の外接球には他の母点がないので、Delaunay 分割が得られる。

`Delaunay` はこの持ち上げに凸包と同じ逐次添加のアルゴリズムを使い、下側のファセットを選んで単体とする。
母点がちょうど $d+1$ 個なら、その単体 1 個が分割である。
$d+2$ 個以上の母点が同じ球面の上にあり、その球の内部に他の母点がないと、下側の面が単体でなくなり、分割は一意に決まらない。
同じ球面に乗っていても、その球の内部に他の母点があれば、それらの母点は同じ Delaunay 単体の頂点にならず、一意性に影響しない。
`Deterministic` は記号摂動でそのうちの一つを選び、`Strict` は隣り合う 2 個の単体の持ち上げた行列式が摂動なしで 0 になるとき（空の外接球を共有するとき）に拒む。

各単体の外心と重心座標は、構築のときに `f64` で一度だけ作る丸めたアフィン写像から求める。
写像が悪条件の細い単体では、その単体の外心・重心座標・勾配の照会だけが `NumericalInstability` を返し、分割の組合せの構造はそのまま使える。
点を含む単体の探索、重心座標と区分線形補間、写像の条件の判定は[Delaunay 分割での点の位置と重心座標](../point-location/)で扱う。

`simplex_count()` と `simplex(s)` は単体の数と単体 $s$ の頂点（正準添字の昇順）を返し、`simplices()` は全単体の頂点を 1 単体 $d+1$ 個ずつ並べた平らな列として参照を返す。
`neighbors(s)` は単体 $s$ の各頂点の向かいの面を共有する単体を返し、その面が凸包の境界にあれば `None` になる。
`circumcenter_into(s, &mut output)` は単体 $s$ の外心を書き、`incident_simplices(v)` は母点 $v$ を含む単体を昇順で返す。
`point_set()` は母点を `KdTree` に渡せる `PointSet` として $O(1)$ として参照を返す。
`triangle_mesh()` と `tetrahedron_mesh()` は平面と 3 次元の分割を正の向きの `TriangleMesh`、`TetrahedronMesh` に変え、頂点は並べ替えた母点の順になる。
次元が合わなければ `InvalidInput` を返す。

## Voronoi 図と双対関係

母点 $p_i$ の Voronoi 領域は

$$
V_i = \{ x \in \mathbb{R}^d : \|x - p_i\| \le \|x - p_j\| \ \forall j \}
$$

である。
Delaunay 単体の外心はその単体の $d+1$ 個の母点から等距離で、他の母点はそれより近くにないので、Voronoi 頂点になる。
隣り合う単体の外心を結ぶと Voronoi 稜になり、凸包の境界に面を持つ単体の外心からは外向きの半直線が伸びる。
`Voronoi::new` は Delaunay 分割を作り、その双対として Voronoi 図を組み立てる。
分割は `delaunay()` で取り出せる。

共円・共球の配置では摂動なしで同じ球面に乗る隣り合う単体を一つの群にまとめ、群に 1 個の Voronoi 頂点を割り当てる。
平面の 4 点が同じ円の上にあれば、2 個の三角形に対して頂点は 1 個である。
頂点の座標は、群の中で番号が最小で、アフィン写像を持つ単体の外心である。
群の他の単体の外心は同じ点を別の経路で丸めた値なので、一致は丸めの範囲に限られる。
`simplex_vertices()[s]` は単体 $s$ の Voronoi 頂点の番号を返す。

- `vertex_count()` と `vertex(i)` は頂点の数と座標を返す。
  `vertices()` は全頂点の座標を返し、どれかの頂点の座標が求まらないと `NumericalInstability` を返す。
- `ridges()` は `VoronoiRidge` を母点の組の順に返す。
  `sites()` は領域が稜を共有する 2 個の母点（昇順）、`vertices()` は稜の Voronoi 頂点、`is_unbounded()` は稜が無限に伸びるかを返す。
  共円の群の中の対角線にあたる Delaunay 辺には稜がない。
- `rays()` は `VoronoiRay` を、対応する凸包の面を持つ単体のうち最小の番号と、向かいの頂点の番号の順に並べて返す。
  `vertex()` は始点の Voronoi 頂点、`sites()` は半直線上のすべての点から等距離にある母点（凸包の面の $d$ 個以上の母点、昇順）、`direction()` は丸めた外向きの単位ベクトルである。
  同じ超平面に乗り、同じ Voronoi 頂点を持つ凸包のファセットは 1 本の半直線にまとまる。
  方向を確かに計算できない半直線では、`direction()` が `NumericalInstability` を返す。
- `region_vertices(site)` は領域の Voronoi 頂点を番号の昇順で返す反復子で、角度の順ではない。
- `region_is_unbounded(site)` は領域が有界でないかを $O(1)$ で返し、凸包の境界に乗る母点でちょうど真になる。

## 球面 Voronoi 図

`SphericalVoronoi::new(&points, center, radius, tolerance)` は、中心 $c$、半径 $r$ の球面上の母点の、測地線距離による Voronoi 図を作る。
各母点は $\big|\,\|p - c\| - r\,\big| \le \tau$ を満たす必要があり、$\tau$ は `tolerance` の $r$ における閾値である。
母点が 3 座標でなければ `DimensionMismatch`、`center` に NaN や無限大があれば `NonFinite` になる。
半径が有限の正の数でないとき、球面上にない母点があるとき、`Strict` で母点が重複しているときは `InvalidInput` になる。

構築は入力の座標のまま母点の 3 次元の凸包を作り、組合せの構造を入力の座標に対する厳密な述語で決める。
球面上の点の凸包は球面 Delaunay 分割である。
単位球面に移した座標 $(p - c)/r$ は、球面上にあるかの検査、法線、面積の計算にだけ使う。
この座標は差 $p - c$ を丸めずに保ってから $r$ で割り、最後に 1 回だけ丸めるので、`f64` で表せないほど大きな差でも求まる。
凸包の各面（同じ平面のファセットはまとめる）の外向き単位法線を $n$ とすると、$c + r n$ がその面に双対な Voronoi 頂点になる。
`region(site)` は領域の頂点を巡回順に返し、`neighbors(site)` は弧を共有する母点を昇順で返す。
許容誤差の範囲で球面の内側にあるために凸包の頂点にならない母点があると、その領域の頂点が 3 個に満たず、`InvalidInput` になる。

`areas()` は各領域の面積を、母点 $g$ と隣り合う 2 頂点 $a$、$b$ がなす球面三角形の扇に分けて足し、$r^2$ を掛けて返す。
各三角形の立体角 $\Omega$ は、単位球面上の Van Oosterom–Strackee の式

$$
\tan\frac{\Omega}{2} = \frac{|g \cdot (a \times b)|}{1 + g \cdot a + a \cdot b + b \cdot g}
$$

を浮動小数点で評価して求める。
`atan2` で評価するので、小さい三角形でも半球に近い三角形でも精度を保つ。
領域や面積が確かに求まらないときは `NumericalInstability` を返す。
面積の和は丸めの範囲で $4\pi r^2$ になる。
明るい恒星を母点とする天球の Voronoi 図で、面積の和と最大・最小の領域を確かめる例が[星表の角距離近傍探索](../../examples/celestial-neighbor-search/)にある。

## 格子点での双対性の検算

$g \times g$ の格子点は、隣り合う 4 点が同じ円の上にある退化の典型である。
次のセルは格子の母点から `Voronoi` と `ConvexHull` を既定の `Deterministic` で作り、構造の要素を数えて理論の値と比べる。
入力行 $p$ は格子点 $(p \bmod g,\ \lfloor p/g \rfloor)$ で、間隔は 1 である。
「座標をずらす」を選ぶと、$k = (p+1)^2$ に無理数に近い定数を掛けた値の小数部から、各座標を $1/256$ 未満だけずらす。
ずらし方を $p$ に比例させると、格子の列と同じ規則でずれがそろい、3 点が厳密に一直線に乗ることがあるので、$p$ の 2 乗を使う。

平面の三角形分割では、Euler の関係から三角形の数は $T = 2n - b - 2$（$b$ は凸包の境界にある Delaunay 辺の数）、辺の数は $(3T + b)/2$ である。
格子では、各正方形の 2 個の三角形が 1 個の Voronoi 頂点を共有し、正方形の対角線には Voronoi 稜がない。
空円性は各三角形の頂点を反時計回りに並べ、他のすべての母点を `incircle` で分類して独立に確かめる。
表は数える対象ごとに実測と予測を並べ、ずらした配置で予測の式がない行は「予測なし」と示す。

```rust
//| id: spatial-delaunay-voronoi-duality
//| ref: spatial-delaunay-voronoi-duality
//| title: 格子点の Delaunay 分割と Voronoi 図の要素を数えて理論の値と比べる
//| run: reactive
//| crates: [scioxide-spatial]
//| inputs:
//|   grid_side: {"type":"range","label":"格子の一辺の点数 g","description":"母点は g × g の格子点で、間隔は 1。","min":3,"max":9,"step":1,"value":5}
//|   perturb: {"type":"checkbox","label":"座標をずらして共円をなくす","description":"各座標を 1/256 未満の決まった量だけずらす。","value":false}
//| cases:
//|   - {"id":"perturbed","label":"ずらした格子","description":"共円がなくなり、三角形ごとに Voronoi 頂点が 1 個になる。","inputs":{"perturb":true}}
//|   - {"id":"perturbed-large","label":"ずらした 9 × 9 の格子","description":"g = 9 でも共円がなく、実測と Euler の関係による予測が一致する。","inputs":{"grid_side":9,"perturb":true}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"counts","path":"/rows/2/1","equals":4}
//|       - {"artifact":"counts","path":"/rows/3/1","equals":32}
//|       - {"artifact":"counts","path":"/rows/5/1","equals":32}
//|       - {"artifact":"counts","path":"/rows/6/1","equals":16}
//|       - {"artifact":"counts","path":"/rows/7/1","equals":40}
//|   - case: perturbed
//|     expect:
//|       - {"artifact":"counts","path":"/rows/1/1","equals":11}
//|       - {"artifact":"counts","path":"/rows/2/1","equals":11}
//|       - {"artifact":"counts","path":"/rows/3/1","equals":37}
//|       - {"artifact":"counts","path":"/rows/5/1","equals":0}
//|       - {"artifact":"counts","path":"/rows/7/1","equals":61}
//|   - case: perturbed-large
//|     expect:
//|       - {"artifact":"counts","path":"/rows/3/1","equals":148}
//|       - {"artifact":"counts","path":"/rows/4/1","equals":0}
//|       - {"artifact":"counts","path":"/rows/5/1","equals":0}
use scioxide_spatial::{ConvexHull, PointSet, PredicateSign, Voronoi, incircle, orient2d};

let g = grid_side as usize;
let n = g * g;
// 入力行 p は格子点 (p mod g, ⌊p/g⌋)。
// ずらすときは k = (p + 1)² に無理数に近い定数を掛けた小数部で、1/256 未満のずれを決める。
let mut sites = Vec::with_capacity(n);
for p in 0..n {
    let (mut dx, mut dy) = (0.0, 0.0);
    if perturb {
        let k = (p as f64 + 1.0) * (p as f64 + 1.0);
        dx = ((k * 0.754_877_666_246_692_7).fract() - 0.5) / 128.0;
        dy = ((k * 0.569_840_290_998_053_3).fract() - 0.5) / 128.0;
    }
    sites.push([(p % g) as f64 + dx, (p / g) as f64 + dy]);
}
let points = PointSet::from_points(&sites).map_err(|e| e.to_string())?;
let voronoi = Voronoi::new(&points).map_err(|e| e.to_string())?;
let hull = ConvexHull::new(&points).map_err(|e| e.to_string())?;

let delaunay = voronoi.delaunay();
let coordinates = delaunay.points();
let site = |v: usize| [coordinates[2 * v], coordinates[2 * v + 1]];
let (mut inside, mut on_circle, mut b) = (0_usize, 0_usize, 0_usize);
for s in 0..delaunay.simplex_count() {
    let v = delaunay.simplex(s).map_err(|e| e.to_string())?;
    let across = delaunay.neighbors(s).map_err(|e| e.to_string())?;
    b += across.iter().filter(|x| x.is_none()).count();
    // 頂点を反時計回りに並べ、他の母点を厳密な incircle で分類する（独立な検算）。
    let (a, mut p, mut q) = (site(v[0]), site(v[1]), site(v[2]));
    if orient2d(&a, &p, &q).map_err(|e| e.to_string())? == PredicateSign::Negative {
        core::mem::swap(&mut p, &mut q);
    }
    for other in (0..n).filter(|d| !v.contains(d)) {
        match incircle(&a, &p, &q, &site(other)).map_err(|e| e.to_string())? {
            PredicateSign::Positive => inside += 1,
            PredicateSign::Zero => on_circle += 1,
            PredicateSign::Negative => {}
        }
    }
}

let t = delaunay.simplex_count();
let mut bounded = 0;
for s in 0..n {
    bounded += usize::from(!voronoi.region_is_unbounded(s).map_err(|e| e.to_string())?);
}
// 予測: 格子では正方形ごとの数え上げ、ずらした配置では Euler の関係による値。
let (squares, inner) = ((g - 1) * (g - 1), (g - 2) * (g - 2));
let pick = |grid: usize, generic: usize| Some(if perturb { generic } else { grid });
let grid_only = |grid: usize| (!perturb).then_some(grid);
let edges = (3 * t + b) / 2;
let rows: Vec<(&str, usize, Option<usize>, &str)> = vec![
    ("母点 n", n, Some(g * g), "g²"),
    (
        "凸包上の Delaunay 辺 b",
        b,
        grid_only(4 * (g - 1)),
        "4(g − 1)、なし",
    ),
    (
        "ConvexHull のファセット",
        hull.facet_count(),
        pick(4, b),
        "4、b",
    ),
    ("三角形 T", t, Some(2 * n - b - 2), "2n − b − 2"),
    ("外接円の内部の母点", inside, Some(0), "0（空円性）"),
    (
        "外接円の上の他の母点",
        on_circle,
        grid_only(2 * squares),
        "2(g − 1)²、なし",
    ),
    (
        "Voronoi 頂点",
        voronoi.vertex_count(),
        pick(squares, t),
        "(g − 1)²、T",
    ),
    (
        "Voronoi 稜",
        voronoi.ridges().len(),
        pick(2 * g * (g - 1), edges),
        "2g(g − 1)、(3T + b)/2",
    ),
    ("半直線", voronoi.rays().len(), Some(b), "b"),
    ("有界な領域", bounded, pick(inner, n - b), "(g − 2)²、n − b"),
];
let columns = serde_json::json!([
    { "key": "0", "label": "数える対象" },
    { "key": "1", "label": "実測 [個]", "type": "integer" },
    { "key": "2", "label": "予測 [個]", "type": "integer", "nullText": "予測なし" },
    { "key": "3", "label": "予測の式（格子、ずらした配置）" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "counts" })
);
```

既定値（$g = 5$、ずらさない格子）では、凸包の境界に $b = 16$ 本の Delaunay 辺があり、三角形は $T = 2 \cdot 25 - 16 - 2 = 32$ 個である。
`ConvexHull` のファセットは正方形の 4 辺だけで、辺の途中にある 12 個の母点は端点でないので頂点にならない。
外接円の内部に他の母点を持つ三角形はない。
各三角形の外接円の上にはちょうど 1 個の他の母点（正方形の残りの隅）があり、その数は三角形の数と同じ 32 である。
Voronoi 頂点は正方形ごとに 1 個の 16 個、稜は格子の辺と同じ 40 本で、正方形の対角線には稜がない。

「ずらした格子」では、外接円の上の母点が 0 になり、Voronoi 頂点の数は三角形の数 37 と一致する。
稜の数は $(3T + b)/2 = 61$ で、Delaunay 辺がすべて稜になる。
ずらすと凸包の辺の途中にあった母点の一部が内側に入り、$b$ は 16 から 11 に減って、`ConvexHull` のファセットの数と一致する。
$g$ を 3 から 9 まで変えても、ずらさない格子とずらした配置のどちらでも表の実測と予測は一致し、ずらした配置の外接円の上の母点は 0 である。

## まとめ

凸包、Delaunay 分割、Voronoi 図、球面 Voronoi 図の結果は並べ替えた母点の正準添字で読み、入力側のデータへは添字の対応を通して戻る。
`ConvexHull` と `Delaunay` は `input_mapping()` と `representatives()` を持ち、`Voronoi` は `delaunay()` を通して同じ対応を使い、`SphericalVoronoi` は `input_mapping()` だけを持つ。
組合せの構造は厳密な述語で決まり、共円・共球の同点は既定の `Deterministic` が記号摂動で一つの分割に解き、Voronoi 図はその群を 1 個の頂点にまとめる。
外心、Voronoi 頂点、半直線の方向、球面の面積は丸めた値なので、`NumericalInstability` を返した照会だけを別に扱えば、組合せの構造はそのまま使える。
