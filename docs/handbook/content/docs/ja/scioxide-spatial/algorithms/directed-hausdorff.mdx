形状の近似の精度、点群の位置合わせの残り、走査したデータと設計形状の食い違いは、2 つの点集合がどこまで離れているかで測れる。
平均的な隔たりではなく最も悪い場所のずれを知りたいときは、Hausdorff 距離を使う。
このページは有向 Hausdorff 距離と対称な Hausdorff 距離の定義と性質、早期打ち切りで全点対の計算を減らすアルゴリズム、最も離れた場所を示す距離を与える点対、KD 木を使う別の計アルゴリズムを説明する。
点集合と距離の扱いは[距離と非類似度](../distances/)で説明している。

## 定義と性質

2 つの空でない有限の点集合 $A$（$m$ 点）と $B$（$n$ 点）について、$A$ から $B$ への有向 Hausdorff 距離を

$$
h(A, B) = \max_{a \in A} \min_{b \in B} \lVert a - b\rVert_2
$$

と定める。
$\min_{b}$ は $a$ から $B$ の最も近い点までの距離で、$h(A, B)$ はその最大値、つまり $A$ の中で $B$ から最も離れた点の離れ具合である。
言い換えると、$h(A, B)$ は $B$ の各点を中心とする半径 $\varepsilon$ の閉球の和が $A$ を覆う最小の $\varepsilon$ である。

$h$ は対称でなく、一般に $h(A, B) \ne h(B, A)$ である。
有限集合では $h(A, B) = 0$ は $A \subseteq B$ と同値なので、$B$ に $A$ にない点があっても $h(A, B)$ には現れない。
有向距離は三角不等式 $h(A, C) \le h(A, B) + h(B, C)$ を満たす。
両方向の大きい方

$$
H(A, B) = \max\bigl(h(A, B),\; h(B, A)\bigr)
$$

を対称な Hausdorff 距離といい、空でない有限集合の上の距離になる。
$H$ は最大値で決まるので、1 点だけ外れた点があれば、ほかの点がよく一致していても大きくなる。
外れ値に影響されない尺度が要るときは、最近傍の距離の平均や分位点のような別の量を使う。

`directed_hausdorff(&source, &target)` は Euclid 距離で $h(\mathrm{source}, \mathrm{target})$ を求め、`HausdorffResult` を返す。
点集合は `PointSet`（1 行 1 点）で渡し、次元は任意で、座標は `f32` か `f64` である。
`distance` が $h$、`source` が最も遠い元の点の番号、`target` がその点に最も近い先の点の番号である。
この 2 点を距離を与える点対と呼ぶ。
対称な $H$ は 2 回呼んで大きい方をとる。
距離は Euclid 距離に限られ、ほかの距離は選べない。

どちらかの集合が空なら $h$ は定義されないので `DomainError`、2 つの集合の次元が違えば `DimensionMismatch` を返す。
距離が表せない値になれば `NumericalInstability` になるが、打ち切りのために評価しなかった対の桁あふれは示されない。
走査の順序のために $O(m + n)$ の添字のメモリ領域を割り当て、確保できなければ `AllocationFailure` を返す。

## 早期打ち切りのアルゴリズム

定義どおりに計算すると、$A$ の各点から $B$ の全点までの距離を調べるので、計算コストは $O(mnd)$ である。
Taha と Hanbury のアルゴリズムはそれまでに見つかった最大値 $c_{\max}$ を使って内側のループを打ち切る。
元の点 $a$ について先の点 $b$ を順に調べ、$\lVert a - b\rVert_2 < c_{\max}$ となる $b$ が見つかった時点で、$a$ の最近点の距離は $c_{\max}$ より小さいと分かる。
そのような $a$ は最大値を更新できないので、残りの $b$ を調べずに次の $a$ へ進んでよい。
打ち切らずに最後まで調べた $a$ だけが、最近点の距離 $\min_b \lVert a - b\rVert_2$ を確定させる。
その距離が $c_{\max}$ を超えれば最大値と距離を与える点対を更新し、$c_{\max}$ に等しければ番号が小さいときだけ距離を与える点対を替える。
打ち切った $a$ は最大値にならないので、打ち切りは最大値を変えず、結果は定義どおりの値と同じになる。

`directed_hausdorff` は元の点と先の点を、固定したシードによる乱択の順序（Fisher–Yates の並べ替え）で走査する。
入力の並び方によっては、最大値が小さいうちに多くの点を最後まで調べることになるので、順序を混ぜてその偏りを避ける。
シードは固定なので、同じ入力からは毎回同じ順序になる。
先の点は 32 点ずつの塊で距離を求め、塊の中の最小値が $c_{\max}$ を下回れば打ち切る。
距離の比較は結果のスカラー型（`f32` か `f64`）に丸めた値で行う。

打ち切りが起こらなければ、計算コストは定義どおりの $O(mnd)$ のままである。
たとえば $h(A, B) = 0$、つまり $A \subseteq B$ のときは $c_{\max}$ が 0 のままで、$\lVert a - b\rVert_2 < 0$ となる $b$ はないので、どの $a$ も $B$ の全点を調べる。
乱択の順序の下での期待計算コストは最悪の場合よりずっと小さいとされる（Taha–Hanbury）が、どれだけ減るかは点の配置による。

## 距離を与える点対の選び方

最近点の距離が同じ先の点が複数あれば、番号の最も小さい点を `target` にする。
最大値を与える元の点が複数あれば、番号の最も小さい点を `source` にする。
この規則は走査の順序に依らないので、距離を与える点対は計算した距離と点の番号だけで決まり、全点対の距離行列を総当たりで調べた結果と一致する。
閉形式では同じ距離になる点でも、計算した距離は丸めで最後の桁が違うことがあり、その場合は計算した距離が最大の点が選ばれる。

次のセルは単位円上に $n k$ 個の点を等間隔に並べた $A$ と、その中から $k$ 個おきに選んだ正 $n$ 角形の頂点を $x$ 方向に $\delta$ [m] ずらした $B$ を比べる。
$\delta = 0$ では $B \subset A$ なので $h(B, A) = 0$ で、この向きでは打ち切りが起こらない。
$k$ が偶数なら、$A$ は隣り合う頂点のちょうど中間の点を含み、そこから最も近い頂点までの弦の長さ

$$
h(A, B) = 2 \sin\frac{\pi}{2n}
$$

が最大になる。
独立な検算として、`pairwise` で全点対の距離行列を作り、行ごとの最小値の最大値を総当たりで求める。
表は 2 つの向きの距離、距離を与える点対、総当たりの値、閉形式（$\delta = 0$ のときだけ）を示し、図は 2 つの集合と $h(A, B)$ の距離を与える点対を結ぶ線分を描く。

```rust
//| id: spatial-hausdorff-witness
//| ref: spatial-hausdorff-witness
//| title: 円の標本と正多角形の頂点の有向 Hausdorff 距離を総当たりと閉形式で確かめる
//| run: reactive
//| crates: [scioxide-core, scioxide-spatial]
//| inputs:
//|   vertices: {"type":"range","label":"正多角形の頂点数 n","min":3,"max":24,"step":1,"value":6}
//|   samples_per_edge: {"type":"range","label":"辺あたりの円の標本数 k","min":2,"max":16,"step":2,"value":4}
//|   shift: {"type":"range","label":"B の x 方向のずれ δ [m]","min":0,"max":1,"step":0.1,"value":0}
//| cases:
//|   - {"id":"shifted","label":"δ = 0.5 m","description":"h(B, A) も正になり、2 つの向きの値が変わる。総当たりとの一致は保たれる。","inputs":{"shift":0.5}}
//|   - {"id":"fine-polygon","label":"n = 24","description":"h(A, B) = 2 sin(π/48) ≈ 0.1308 m で、頂点数に反比例して小さくなる。","inputs":{"vertices":24}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"hausdorff","path":"/rows/0/1","approx":{"value":0.5176380902050415,"rtol":1e-14}}
//|       - {"artifact":"hausdorff","path":"/rows/0/4","approx":{"value":0.5176380902050415,"rtol":1e-14}}
//|       - {"artifact":"hausdorff","path":"/rows/0/2","equals":18}
//|       - {"artifact":"hausdorff","path":"/rows/0/5","equals":18}
//|       - {"artifact":"hausdorff","path":"/rows/1/1","equals":0}
//|   - case: shifted
//|     expect:
//|       - {"artifact":"hausdorff","path":"/rows/0/1","approx":{"value":0.7247448713915892,"rtol":1e-14}}
//|       - {"artifact":"hausdorff","path":"/rows/1/1","approx":{"value":0.5,"rtol":1e-14}}
//|       - {"artifact":"hausdorff","path":"/rows/1/4","approx":{"value":0.5,"rtol":1e-14}}
//|   - case: fine-polygon
//|     expect:
//|       - {"artifact":"hausdorff","path":"/rows/0/1","approx":{"value":0.13080625846028612,"rtol":1e-14}}
use scioxide_core::{NdView, RealScalar, StridedLayout};
use scioxide_spatial::{HausdorffResult, PointSet, directed_hausdorff, pairwise};

// A: 単位円上の m = n k 点。B: その k 個おきの点（正 n 角形の頂点）を x 方向に δ ずらす。
let (n, k) = (vertices as usize, samples_per_edge as usize);
let m = n * k;
let angle = |i: usize| 2.0 * core::f64::consts::PI * i as f64 / m as f64;
let circle: Vec<f64> = (0..m)
    .flat_map(|i| [RealScalar::cos(angle(i)), RealScalar::sin(angle(i))])
    .collect();
// B の頂点は A の第 j k 点そのもの（δ = 0 なら B ⊂ A）。
let polygon: Vec<f64> = (0..n)
    .flat_map(|j| [circle[2 * j * k] + shift, circle[2 * j * k + 1]])
    .collect();
let (shape_a, shape_b, strides) = ([m, 2], [n, 2], [2, 1]);
let layout_a = StridedLayout::new(&shape_a, &strides).map_err(|e| e.to_string())?;
let layout_b = StridedLayout::new(&shape_b, &strides).map_err(|e| e.to_string())?;
let a = PointSet::new(NdView::new(&circle, layout_a).map_err(|e| e.to_string())?)
    .map_err(|e| e.to_string())?;
let b = PointSet::new(NdView::new(&polygon, layout_b).map_err(|e| e.to_string())?)
    .map_err(|e| e.to_string())?;
let ab = directed_hausdorff(&a, &b).map_err(|e| e.to_string())?;
let ba = directed_hausdorff(&b, &a).map_err(|e| e.to_string())?;

// 独立な検算: pairwise の行列で、行ごとの最小の最大を総当たりで求める（同点は小さい番号）。
let brute = |left: &PointSet<f64>, right: &PointSet<f64>| {
    let table = pairwise(left, right)?;
    let mut best = (-1.0, 0, 0);
    for (row, distances) in table.as_slice().chunks(right.len()).enumerate() {
        let mut nearest = (f64::INFINITY, 0);
        for (column, &d) in distances.iter().enumerate() {
            if d < nearest.0 {
                nearest = (d, column);
            }
        }
        if nearest.0 > best.0 {
            best = (nearest.0, row, nearest.1);
        }
    }
    Ok::<_, scioxide_core::SciOxideError>(best)
};
let brute_ab = brute(&a, &b).map_err(|e| e.to_string())?;
let brute_ba = brute(&b, &a).map_err(|e| e.to_string())?;
// 閉形式（δ = 0 のときだけ）: f64 の標準関数による参照値。
let chord = (shift == 0.0).then(|| 2.0 * (core::f64::consts::PI / (2.0 * n as f64)).sin());
let row = |label, h: &HausdorffResult<f64>, brute: (f64, usize, usize), exact: Option<f64>| {
    (
        label, h.distance, h.source, h.target, brute.0, brute.1, brute.2, exact,
    )
};
let rows = vec![
    row("h(A, B)", &ab, brute_ab, chord),
    row("h(B, A)", &ba, brute_ba, chord.map(|_| 0.0)),
];
let fixed6 = serde_json::json!({ "fractionDigits": 6 });
let columns = serde_json::json!([
    { "key": "0", "label": "向き" },
    { "key": "1", "label": "距離 [m]", "type": "number", "format": fixed6 },
    { "key": "2", "label": "距離を与える点対の元の点", "type": "integer" },
    { "key": "3", "label": "距離を与える点対の先の点", "type": "integer" },
    { "key": "4", "label": "総当たりの距離 [m]", "type": "number", "format": fixed6 },
    { "key": "5", "label": "総当たりの元の点", "type": "integer" },
    { "key": "6", "label": "総当たりの先の点", "type": "integer" },
    { "key": "7", "label": "閉形式 [m]", "type": "number", "format": fixed6, "nullText": "—" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "hausdorff" })
);

// A、B と、h(A, B) の距離を与える点対を結ぶ線分。
let points_of = |coordinates: &[f64]| -> Vec<[f64; 2]> {
    coordinates.chunks(2).map(|p| [p[0], p[1]]).collect()
};
let witness = vec![
    [circle[2 * ab.source], circle[2 * ab.source + 1]],
    [polygon[2 * ab.target], polygon[2 * ab.target + 1]],
];
emit_chart!(serde_json::json!({
    "kind": "xy",
    "xLabel": "x [m]",
    "yLabel": "y [m]",
    "xMin": -1.2,
    "xMax": 2.2,
    "yMin": -1.2,
    "yMax": 1.2,
    "tooltip": true,
    "layers": [
        { "id": "a", "kind": "scatter", "name": "A（円の標本）", "points": points_of(&circle) },
        {
            "id": "b",
            "kind": "scatter",
            "name": "B（正多角形の頂点）",
            "points": points_of(&polygon),
            "style": { "symbol": "diamond" }
        },
        { "id": "witness", "kind": "line", "name": "h(A, B) の距離を与える点対", "points": witness }
    ]
}));
```

既定値（$n = 6$、$k = 4$、$\delta = 0$）では、$h(A, B)$ は閉形式 $2\sin(\pi/12) \approx 0.517638$ m と一致し、$h(B, A) = 0$ である。
閉形式では 6 つの中間点がどれも同じ距離にあるが、計算した距離は丸めで最後の桁が違い、最大になった中間点 18 と頂点 4 が距離を与える点対になる。
総当たりも同じ対を返すので、距離を与える点対は走査の順序ではなく計算した距離と番号だけで決まっている。
$\delta = 0.5$ m では $B$ が円から外れるので $h(B, A)$ も正になり、2 つの向きの値の違いが見える。
どの入力でも、早期打ち切りの値と距離を与える点対は、全点対の距離行列を総当たりで調べた結果と一致する。
$n = 24$ では $h(A, B) = 2\sin(\pi/48) \approx 0.130806$ m で、多角形の頂点を増やすと円の標本との最大のずれは $1/n$ に比例して縮む。

## KD 木による計算との関係

$h(A, B)$ は $A$ の各点について $B$ の最近傍の距離を求め、その最大をとった値でもある。
そのため、$B$ に `KdTree` を作り、$A$ の全点を `nearest_batch_into` で $k = 1$ として照会しても求められる。
木の構築は $O(d\,n\log n)$ で、低い次元で点がほぼ一様なら、各照会は少数の葉を調べて終わる（[KD 木による近傍探索](../spatial-trees-and-distance/)）。
同じ $B$ に多くの集合を比べるときは木を使い回せ、`TreeMetric` の `CityBlock`・`Chebyshev`・`Minkowski(p)`（$p \ge 1$）や周期箱も使える。
`directed_hausdorff` は前処理なしで 1 回の比較を行い、距離は Euclid 距離に限られる。
KD 木の結果は（距離、番号）の順に並ぶので、最近傍の同点は番号の最も小さい点になる。
最大をとる元の点の同点も番号の小さい方を選べば、`directed_hausdorff` と同じ距離を与える点対になる。

次のセルはシード $s$ の乱数で単位正方形に $m$ 点の $A$ を、その中央の正方形 $[0.25, 0.75]^2$ に $n$ 点の $B$ を置く。
$h(A, B)$ は $A$ の角の近くの点で大きく、$h(B, A)$ は小さい。
両方向の $h$ を `directed_hausdorff` と、KD 木の 1 近傍の一括照会の 2 通りで求め、距離と距離を与える点対を並べる。

```rust
//| id: spatial-hausdorff-kdtree
//| ref: spatial-hausdorff-kdtree
//| title: 有向 Hausdorff 距離を KD 木の最近傍の照会で求め直す
//| run: reactive
//| crates: [scioxide-core, scioxide-random, scioxide-spatial]
//| inputs:
//|   source_count: {"type":"range","label":"A の点の数 m","min":10,"max":2000,"step":10,"value":400}
//|   target_count: {"type":"range","label":"B の点の数 n","min":10,"max":2000,"step":10,"value":200}
//|   seed: {"type":"range","label":"乱数のシード s","min":1,"max":50,"step":1,"value":11}
//| cases:
//|   - {"id":"large","label":"m = n = 2000","description":"点を増やしても、2 通りの計算は同じ距離と距離を与える点対を返す。","inputs":{"source_count":2000,"target_count":2000}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"comparison","path":"/rows/0/1","approx":{"value":0.3935228633647214,"rtol":1e-14}}
//|       - {"artifact":"comparison","path":"/rows/0/2","equals":35}
//|       - {"artifact":"comparison","path":"/rows/0/5","equals":35}
//|       - {"artifact":"comparison","path":"/rows/0/7","range":{"max":1e-15}}
//|       - {"artifact":"comparison","path":"/rows/1/2","equals":26}
//|       - {"artifact":"comparison","path":"/rows/1/5","equals":26}
//|       - {"artifact":"comparison","path":"/rows/1/7","range":{"max":1e-15}}
//|   - case: large
//|     expect:
//|       - {"artifact":"comparison","path":"/rows/0/1","approx":{"value":0.3651021533521946,"rtol":1e-14}}
//|       - {"artifact":"comparison","path":"/rows/0/7","range":{"max":1e-15}}
//|       - {"artifact":"comparison","path":"/rows/1/7","range":{"max":1e-15}}
use core::num::NonZeroUsize;
use scioxide_core::{ExecutionContext, NdView, StridedLayout};
use scioxide_random::{SeedableRng, SplitMix64, fill_uniforms};
use scioxide_spatial::{
    KdTree, Neighbor, PointSet, SearchOptions, SearchWorkspaceRequest, directed_hausdorff,
};

// A は単位正方形、B は中央の正方形 [0.25, 0.75]² の一様な点（1 行 1 点）。
let (m, n) = (source_count as usize, target_count as usize);
let mut rng = SplitMix64::from_seed(seed as u64);
let (mut a, mut b) = (vec![0.0_f64; 2 * m], vec![0.0_f64; 2 * n]);
fill_uniforms(&mut rng, &mut a, &mut 0).map_err(|e| e.to_string())?;
fill_uniforms(&mut rng, &mut b, &mut 0).map_err(|e| e.to_string())?;
b.iter_mut().for_each(|x| *x = 0.25 + 0.5 * *x);
let (shape_a, shape_b, strides) = ([m, 2], [n, 2], [2, 1]);
let layout_a = StridedLayout::new(&shape_a, &strides).map_err(|e| e.to_string())?;
let layout_b = StridedLayout::new(&shape_b, &strides).map_err(|e| e.to_string())?;
let set_a = PointSet::new(NdView::new(&a, layout_a).map_err(|e| e.to_string())?)
    .map_err(|e| e.to_string())?;
let set_b = PointSet::new(NdView::new(&b, layout_b).map_err(|e| e.to_string())?)
    .map_err(|e| e.to_string())?;

// KD 木による h(source, target): target に木を作り、source の全点の 1 近傍の最大をとる。
let via_tree = |source: &PointSet<f64>, target: &PointSet<f64>| {
    let tree = KdTree::new(target)?;
    let options = SearchOptions::new();
    let count = source.len();
    let request =
        SearchWorkspaceRequest::new(1, options).with_batch(count, count, NonZeroUsize::MIN);
    let mut workspace = tree.workspace(request)?;
    let mut found = vec![Neighbor::default(); count];
    let context = ExecutionContext::sequential();
    tree.nearest_batch_into(source, 1, options, &mut found, &mut workspace, context)?;
    // 同じ最大値なら番号の小さい元の点を残す。
    let mut best = (-1.0, 0, 0);
    for (i, neighbor) in found.iter().enumerate() {
        if neighbor.distance > best.0 {
            best = (neighbor.distance, i, neighbor.index);
        }
    }
    Ok::<_, scioxide_core::SciOxideError>(best)
};
let mut rows = Vec::new();
for (label, source, target) in [("h(A, B)", &set_a, &set_b), ("h(B, A)", &set_b, &set_a)] {
    let direct = directed_hausdorff(source, target).map_err(|e| e.to_string())?;
    let tree = via_tree(source, target).map_err(|e| e.to_string())?;
    let gap = (direct.distance - tree.0).abs();
    rows.push((
        label,
        direct.distance,
        direct.source,
        direct.target,
        tree.0,
        tree.1,
        tree.2,
        gap,
    ));
}
let fixed6 = serde_json::json!({ "fractionDigits": 6 });
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let columns = serde_json::json!([
    { "key": "0", "label": "向き" },
    { "key": "1", "label": "directed_hausdorff [-]", "type": "number", "format": fixed6 },
    { "key": "2", "label": "元の点", "type": "integer" },
    { "key": "3", "label": "先の点", "type": "integer" },
    { "key": "4", "label": "KD 木 [-]", "type": "number", "format": fixed6 },
    { "key": "5", "label": "KD 木の元の点", "type": "integer" },
    { "key": "6", "label": "KD 木の先の点", "type": "integer" },
    { "key": "7", "label": "距離の差 [-]", "type": "number", "format": sci3 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "comparison" })
);
```

既定値（$m = 400$、$n = 200$、$s = 11$）では、$h(A, B) = 0.393523$ と $h(B, A) = 0.074170$ が 2 通りの計算でビットまで一致し、距離を与える点対も $(35, 12)$ と $(26, 312)$ で同じになる。
$h(A, B)$ は $A$ の角の近くの点から $B$ までの距離で決まり、$B$ の点を増やすと、単位正方形の角から中央の正方形の角までの距離 $\sqrt2/4 \approx 0.353553$ に近づく（$m = n = 2000$ で $0.365102$）。
$h(B, A)$ は $B$ の点が $A$ の点の間にどれだけ隙間を残すかで決まり、$A$ を増やすと小さくなる（$m = n = 2000$ で $0.035856$）。
2 つの向きの値の大きな違いは、$h$ が対称でないことを示している。

## まとめ

形状の最も悪い食い違いを測るときは、`directed_hausdorff` を両方向に呼び、大きい方を対称な Hausdorff 距離 $H$ とする。
Taha–Hanbury の早期打ち切りを使っても結果は定義どおりの値と一致し、距離を与える点対は番号の最も小さい点で決まるので、最も離れた場所を再現性のある形で特定できる。
$A \subseteq B$ のように打ち切りが起こらない配置では計算コストが全点対の $O(mnd)$ のままなので、大きな集合ではこの最悪の場合を見込む。
1 点の外れ値で値が大きくなるので、平均的な一致を見たいときは最近傍の距離の平均や分位点を使う。
同じ集合に何度も照会するときや、Euclid 以外の `TreeMetric` の距離や周期箱が要るときは、KD 木の 1 近傍の照会の最大で同じ値を求める。
