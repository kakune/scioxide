クラスタ分析、最近傍による分類、形状の比較は、点と点の隔たりを数で表すことから始まる。
隔たりの測り方はデータの意味で決まる。
座標の差の大きさを測るなら Euclid 距離、向きだけを比べるなら余弦、確率分布どうしなら Jensen–Shannon 距離、0/1 の属性なら一致表に基づく尺度を選ぶ。
このページは距離と非類似度の定義と定義域、成分のばらつきと相関を考慮する距離、1 対の評価での桁あふれと丸めの扱いを説明する。
多数の点の対の距離を並べる配列と作業領域は[距離行列と圧縮表現](../distance-matrices/)で、2 つの点集合のずれを測る有向 Hausdorff 距離は[有向 Hausdorff 距離](../directed-hausdorff/)で扱う。

## 距離の公理と点集合

集合 $X$ 上の関数 $d : X \times X \to [0, \infty)$ が、すべての $x, y, z \in X$ で

1. $d(x, y) = 0 \iff x = y$（同一性）
2. $d(x, y) = d(y, x)$（対称性）
3. $d(x, z) \le d(x, y) + d(y, z)$（三角不等式）

を満たすとき、$d$ を距離（計量）という。
三角不等式などの条件の一部を満たさない隔たりの尺度は、非類似度と呼んで区別する。
三角不等式が成り立てば、既知の距離から $\lvert d(x, z) - d(y, z)\rvert \le d(x, y)$ のように未知の距離の上下界が得られる。
非類似度ではこの推論が使えない。

点集合は `PointSet` で渡し、どの作り方でも座標を複製せずに借りる。
`PointSet::from_points(&points)` は `[[S; D]]` の各要素を 1 点として読み、`PointSet::from_rows(&coordinates, d)` は行優先の平らな配列を $d$ 個ずつ 1 点として解釈する。
`from_rows` は $d = 0$ を `InvalidInput`、長さが $d$ で割り切れない配列を `DimensionMismatch` で拒む。
`PointSet::new` は `scioxide_core` の 2 階のビュー `NdView` を借り、1 行を 1 点（形状 $[n, d]$）として解釈する。
ストライドは任意で、0 のストライドで同じ行を繰り返すこともできる。
`new` は 2 階でないビューを `InvalidInput` で拒む。
どの作り方も構築時に全座標の有限性を 1 回だけ調べる（NaN や無限大は `NonFinite`）。

## 名前付きの距離と非類似度

`DistanceMetric` は 17 種類の関数を列挙し、`PreparedDistance::new(metric)` で評価の準備をする。
2 つのベクトルを $u, v \in \mathbb{R}^d$ とする。
定義されない入力で評価すると `DomainError` が返り、値を 0 や NaN に置き換えることはしない。
Euclid 距離には準備の要らない関数 `distance(&u, &v)` もあり、`PreparedDistance::new(DistanceMetric::Euclidean)` の `distance` と同じ値を返す。

| 列挙子 | 定義 | 定義されない入力 | 性質 |
|---|---|---|---|
| `Euclidean` | $\lVert u - v\rVert_2$ | なし | 距離 |
| `SquaredEuclidean` | $\lVert u - v\rVert_2^2$ | なし | 非類似度（三角不等式を満たさない） |
| `CityBlock` | $\sum_i \lvert u_i - v_i\rvert$ | なし | 距離 |
| `Chebyshev` | $\max_i \lvert u_i - v_i\rvert$（$d = 0$ では 0） | なし | 距離 |
| `Minkowski(p)` | $\bigl(\sum_i \lvert u_i - v_i\rvert^p\bigr)^{1/p}$、有限の $p > 0$ | なし | $p \ge 1$ で距離、$p < 1$ で非類似度 |
| `Cosine` | $1 - u \cdot v / (\lVert u\rVert_2 \lVert v\rVert_2)$ | どちらかが零ベクトル | 非類似度、値は $[0, 2]$ |
| `Correlation` | 平均を引いた $u - \bar u$、$v - \bar v$ の `Cosine` | どちらかが定数ベクトル | 非類似度、値は $[0, 2]$ |
| `BrayCurtis` | $\sum_i \lvert u_i - v_i\rvert / \sum_i \lvert u_i + v_i\rvert$ | $\sum_i \lvert u_i + v_i\rvert = 0$（すなわち $u = -v$） | 非類似度 |
| `Canberra` | $\sum_i \lvert u_i - v_i\rvert / (\lvert u_i\rvert + \lvert v_i\rvert)$、$0/0$ の項は 0 | なし | 距離 |
| `JensenShannon` | $\sqrt{\mathrm{JS}(p, q)}$（下で定義） | 負の座標、和が 0 のベクトル | 距離 |
| `Hamming` | 異なる座標の割合 $\#\{i : u_i \ne v_i\}/d$ | $d = 0$ | 距離 |
| `Dice` | $(c_{10} + c_{01})/(2c_{11} + c_{10} + c_{01})$ | 両方が全 0 | 非類似度 |
| `Jaccard` | $(c_{10} + c_{01})/(c_{11} + c_{10} + c_{01})$（両方が全 0 なら 0） | なし | 距離 |
| `RogersTanimoto` | $2(c_{10} + c_{01})/(c_{11} + c_{00} + 2(c_{10} + c_{01}))$ | $d = 0$ | 距離 |
| `RussellRao` | $(d - c_{11})/d$ | $d = 0$ | 非類似度（$u = v$ でも 0 とは限らない） |
| `SokalSneath` | $2(c_{10} + c_{01})/(c_{11} + 2(c_{10} + c_{01}))$ | 両方が全 0 | 距離（全 0 のベクトルを除く） |
| `Yule` | $2c_{10}c_{01}/(c_{11}c_{00} + c_{10}c_{01})$（$c_{10}c_{01} = 0$ なら 0） | なし | 非類似度 |

`Dice` から `Yule` までの 0/1 の尺度（`Hamming` を除く）は、全座標が 0 か 1 であることを求め、ほかの値は `DomainError` になる。
$c_{ab}$ は $u_i = a$ かつ $v_i = b$ となる座標の数で、たとえば $c_{10}$ は $u$ だけが 1 の座標の数である。
`Hamming` は 0/1 に限らず任意の実数の座標を受け付け、値が等しいかだけを比べる。
0/1 のベクトルの上では、`Jaccard`、`RogersTanimoto`、`SokalSneath` が三角不等式を満たして距離になり、`Dice` と `Yule` は満たさない（Gower–Legendre）。

`JensenShannon` は確率分布の隔たりである。
各ベクトルをそれぞれ和が 1 になるように正規化した $p$、$q$ と、その平均 $m = (p + q)/2$ を使って

$$
\mathrm{JS}(p, q) = \tfrac{1}{2}\,\mathrm{KL}(p \,\Vert\, m) + \tfrac{1}{2}\,\mathrm{KL}(q \,\Vert\, m), \qquad
\mathrm{KL}(p \,\Vert\, m) = \sum_i p_i \ln\frac{p_i}{m_i}
$$

と定める。
対数は自然対数で、$\mathrm{JS}$ は $[0, \ln 2]$ に、その平方根は $[0, \sqrt{\ln 2}]$ に入る。
入力の和を 1 にそろえる必要はないが、座標は非負で、2 つのベクトルの和はどちらも正でなければならない。
$\mathrm{JS}$ そのものは三角不等式を満たさないが、その平方根は距離になる（Endres–Schindelin）。

`JensenShannon` は座標ごとの寄与を、$s_i = p_i + q_i$ と $t_i = \lvert p_i - q_i\rvert / s_i$ を使って

$$
\mathrm{JS}(p, q) = \sum_i \frac{s_i}{4}\, h(t_i), \qquad h(t) = (1 + t)\ln(1 + t) + (1 - t)\ln(1 - t)
$$

と書き直して計算する。
$t_i$ が小さいときは $h(t) = \sum_{k \ge 1} t^{2k} / \bigl(k(2k - 1)\bigr)$ の正の級数を使うので、2 つの分布がほぼ等しくても桁落ちしない。
和が `f64` の範囲を超えるベクトルは、最大成分で割ってから和をとる。
正規化した値は指数の範囲を広げた表現で持ったまま平方根まで運ぶので、正規化の途中でアンダーフローして小さな距離が 0 になることはない。

`Minkowski(p)` は $p$ が有限で正でなければ、準備の段階で `InvalidInput` になる。
$p < 1$ では三角不等式が成り立たず、たとえば $p = 1/2$ で $d\bigl((0, 0), (1, 1)\bigr) = 4$ は $d\bigl((0, 0), (1, 0)\bigr) + d\bigl((1, 0), (1, 1)\bigr) = 2$ を超える。
$p = 1$ では差の絶対値をそのまま足し、$p = 2$ では Euclid 距離と同じ計算をする。
それ以外の $p$ では差を最大成分で割ってから $p$ 乗を足す。
$p < 1$ で最大成分との比が正規化数の範囲を下回る成分は、比を作らずに対数の差から $p$ 乗を求めるので、比のアンダーフローで寄与を失わない。
$p < 1$ で和の $1/p$ 乗が桁あふれするときも対数を通して根を求めるので、表せる結果を拒むことはないが、その経路の誤差は結果の指数とともに増える。

次のセルは定義域の端にある 2 次元の入力で 11 通りの距離を `PreparedDistance::distance` で評価し、値かエラーの分類を `f64` の標準関数による参照値と並べる。
`JensenShannon` の 3 行目は、座標の和が `f64` の範囲を超えるベクトルの正規化を確かめる。
入力は最後の行の `Minkowski(p)` の指数 $p$ で、$d\bigl((0, 0), (1, 1)\bigr) = 2^{1/p}$ が、$(1, 0)$ を経由する 2 辺の和 2 を超えるかどうかを見る。

//|   - case: default
//|     expect:

//|       - {"artifact":"domains","path":"/rows/1/7","equals":"DomainError"}

//|       - {"artifact":"domains","path":"/rows/3/7","equals":"DomainError"}

`Canberra` は $0/0$ の項を 0 とするので、零ベクトルどうしでも 0 を返す。
`BrayCurtis` は $u = -v$ で分母が 0 になり、`Cosine` は零ベクトル、`Correlation` は定数ベクトルで、どれも `DomainError` を返す。
`JensenShannon` は $(1, 0)$ と $(0, 1)$ でも、和をそろえていない $(2, 0)$ と $(0, 3)$ でも、上限の $\sqrt{\ln 2} \approx 0.832555$ を返す。
和が `f64` の最大値を超える $(10^{308}, 10^{308})$ と $(10^{308}, 0)$ でも、正規化した $p = (1/2, 1/2)$、$q = (1, 0)$ の値 $\sqrt{(3/4)\ln(4/3)} \approx 0.464502$ を返し、負の座標は拒む。
`Hamming` は 0/1 でない座標でも異なる座標の割合 0.5 を返し、`Dice` は 0.5 という座標を拒む。
既定の $p = 1/2$ では `Minkowski` の値が 4 になり、2 辺の和 2 を超えて三角不等式が破れる。
$p \ge 1$ では値 $2^{1/p}$ は 2 以下になり、$p = 2$ では Euclid 距離の $\sqrt 2$ に一致する。

## 標準化 Euclid 距離と Mahalanobis 距離

成分の単位やばらつきが違うとき、差をそのまま足すと分散の大きい成分が距離を支配する。
`PreparedDistance::standardized(variances)` は成分ごとの分散 $\sigma_i^2 > 0$ で割った標準化 Euclid 距離

$$
d_\sigma(u, v) = \Bigl(\sum_i \frac{(u_i - v_i)^2}{\sigma_i^2}\Bigr)^{1/2}
$$

を準備する。
分散はデータから推定せず、呼び出し側が与える。
有限で正でない分散は `InvalidInput` になる。

成分の間に相関があるときは、共分散行列 $V$ の逆行列を使う Mahalanobis 距離

$$
d_M(u, v) = \sqrt{(u - v)^\mathsf{T} V^{-1} (u - v)} = \bigl\lVert L^\mathsf{T}(u - v)\bigr\rVert_2, \qquad V^{-1} = L L^\mathsf{T}
$$

を使う。
$L$ は対角が正の下三角行列である。
`PreparedDistance::mahalanobis(inverse_covariance)` は $V^{-1}$ を受け取り、ピボットなしの Cholesky 分解で $L$ を準備時に 1 回求める。
$V^{-1}$ は厳密に対称でなければならず、非対称な行列は分解の段階で `InvalidInput`（理由は `Inconsistent`）になる。
正方でない行列も `InvalidInput`、正定値でない行列は `DomainError` を返す。
評価は三角行列とベクトルの積 $L^\mathsf{T}(u - v)$ とそのノルムで、代入は行わず、1 対あたり約 $d^2/2$ 回の積和である。
$V$ が対角行列なら、Mahalanobis 距離は標準化 Euclid 距離に一致する。
全点対の計算で Cholesky 因子による値を 2 次形式の参照値と比べる例は、[距離行列と圧縮表現](oxref:spatial-condensed-distance)のセルにある。

## 1 対の評価と浮動小数点の扱い

`PreparedDistance` は不変で、準備は割り当てを行うことがあるが、評価は割り当てを行わない。
1 対の距離は `distance(&u, &v)`（スライス）か `between(&left, i, &right, j)`（点集合の行）で求める。
長さや次元の違いは `DimensionMismatch`、範囲外の行番号は `OutOfBounds`、スライスの NaN や無限大は `NonFinite` になる。
中間の計算は `f32` と `f64` のどちらの入力でも `f64` で行う。
Euclid 型のノルムはまず尺度を変えずに 2 乗和をとり、和が桁あふれするか、正規化数の範囲を下回ったときだけ、最大成分で尺度を変えて足し直す。
`Cosine` と `Correlation` も各ベクトルを最大成分で割ってから内積をとるので、有限の入力で内積が桁あふれすることはない。
差、変換した成分、結果が `f64` で表せない値になるか、結果が出力のスカラー型（`f32` など）の範囲を超えれば、無限大を返さずに `NumericalInstability`（`Overflow`）を返す。

## まとめ

距離はデータの意味に合う `DistanceMetric` を選び、その定義域と、三角不等式を満たす距離か非類似度かを表で確かめて使う。
`Cosine`、`Correlation`、`BrayCurtis`、`JensenShannon` と 0/1 の尺度は定義されない入力で `DomainError` を返すので、零ベクトルや負の値の扱いを呼び出し側で決める。
`JensenShannon` は各ベクトルを別々に正規化するので、和をそろえていない非負のベクトルをそのまま渡せる。
成分の尺度や相関が違うデータには、分散を与えた標準化 Euclid 距離か、逆共分散を与えた Mahalanobis 距離を使う。
後者は準備時の Cholesky 分解で、評価が三角行列とベクトルの積になる。
