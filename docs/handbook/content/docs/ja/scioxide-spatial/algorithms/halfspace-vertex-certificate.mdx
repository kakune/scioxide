`HalfspaceIntersection` は、有効な半空間と頂点の隣接を厳密に決めるが、頂点の座標は丸めた値として返す。
構築は各座標の誤差を証明し、証明できなければ失敗する。
このページはその証明の手順と、誤差の上界が成り立つ理由を導く。
座標軸の上かそのすぐ近くにある頂点では、ある座標が他の座標に比べて非常に小さいか 0 になり、通常の前処理付き残差の証明が成り立ちにくい。
そうした座標を縁取りした行列式の符号で直接証明する方法も説明し、正多角形を回したときの頂点で証明の結果を独立に確かめる。
問題の定式化、極双対、有界性の判定は[半空間の交差と双対凸包](../halfspace-intersection/)にある。

## 頂点の座標と誤差の証明

有界な交差の頂点は双対のファセットに乗る $d$ 個の不等式を等式にした連立方程式 $A x = \beta$（$A$ の行が $a_i$、$\beta_i = -b_i$）の解 $x^\ast$ である。
$\varepsilon$ をスカラー型の機械イプシロン（`f64` では $2^{-52} \approx 2.2 \times 10^{-16}$）とし、半径の係数を $\rho = 32\,\varepsilon\,(d+1)$ と書く。
`HalfspaceIntersection` は各頂点について次の手順で座標 $\tilde x$ を求め、各座標の誤差が半径 $t_i = \rho\,\lvert \tilde x_i \rvert$ 以内であることを証明する。

1. 定数項を含む各行をその成分の最大の絶対値で割って $A$ を平衡化し、部分ピボット選択付きの LU 分解で解いて、近似解 $\tilde x$ をスカラー型に丸める。
2. $0 < \lvert \tilde x_i \rvert \le \rho \max_j \lvert \tilde x_j \rvert$ の座標について、縁取りした行列式 $D_i(0)$（定義は後述）の符号を厳密に求める。
   符号が 0 なら真の座標 $x^\ast_i$ は 0 なので、$\tilde x_i$ を 0 に置き換える。
3. 残差 $\beta - A\tilde x$ を厳密な和で求め、すべての成分が厳密に 0 なら $\tilde x$ は真の頂点である。
4. そうでなければ、最初の候補のときに、平衡化した行列の逆行列を行の尺度で戻して、元の $A$ の近似逆行列 $R \approx A^{-1}$ を作る。
   $E = I - RA$ の各成分の絶対値の上界を、上向き・下向きの丸めで求める。
   $\lVert E \rVert_\infty \ge 1$ なら構築は直ちに `NumericalInstability` を返す。
5. 半径 $t_i = \rho\,\lvert \tilde x_i \rvert$ を決め、$z = R(\beta - A\tilde x)$ を厳密な積和から求めて、座標ごとに条件
   $$
   \lvert z_i \rvert + \sum_j \lvert E_{ij} \rvert\, t_j \le t_i
   $$
   を上向きの丸めで確かめる。
6. 5 の条件が成り立たない座標は、区間 $[\tilde x_i - t_i,\ \tilde x_i + t_i]$ の両端（内側に丸めた値）で $D_i$ の符号を厳密に求め、符号が異なるか一方が 0 なら証明できたとする。
   $t_i = 0$ の座標は $D_i(\tilde x_i) = 0$ のときだけ証明できたとする。
7. 証明できない座標が残れば $\tilde x \leftarrow \tilde x + z$ と修正し、スカラー型に丸めて 2 から繰り返す（$R$ と $E$ は最初に作ったものを使う）。
   修正は 2 回までで、最初の解と合わせて 3 回の候補で証明できなければ、構築は `NumericalInstability` を返す。

LU 分解の途中で軸が 0 になったときと、$R$ の成分が有限の値で表せないときも、構築は `NumericalInstability` を返す。

### 前処理付き残差による成分ごとの証明

5 の条件が誤差の上界を与える理由は次のとおりである。
$e = x^\ast - \tilde x$ とすると $A e = \beta - A \tilde x$ なので、$e = R(\beta - A\tilde x) + (I - RA)e = z + E e$ が成り立つ。
$\lVert E \rVert_\infty < 1$ なら Neumann 級数 $(I - \lvert E \rvert)^{-1} = \sum_k \lvert E \rvert^k$ が収束し、その成分は非負になる。
$\lvert e \rvert \le \lvert z \rvert + \lvert E \rvert\,\lvert e \rvert$ と $\lvert z \rvert + \lvert E \rvert\,t \le t$ にこの行列を掛けると、$\lvert e \rvert \le (I - \lvert E \rvert)^{-1}\lvert z \rvert \le t$ が従う。
これは Rump の検証法（Acta Numerica 2010、10.3 節）の前処理付き残差による成分ごとの証明である。

この条件は、座標の大きさがそろっていないと成り立たないことがある。
$t_j / t_i = \lvert \tilde x_j \rvert / \lvert \tilde x_i \rvert$ なので、成分 $i$ の条件には少なくとも $\lvert \tilde x_i \rvert \ge \sum_j \lvert E_{ij} \rvert\, \lvert \tilde x_j \rvert$ が要る。
$E$ の成分は丸めの大きさ（$\varepsilon$ 程度）なので、真の値が 0 か他の座標の $\varepsilon$ 倍程度しかない座標では、$\tilde x_i$ が正しくても 5 の条件が成り立たないことが多い。
係数を丸めた正多角形で頂点が座標軸の上に来る向きが、その典型である。
6 と 2 はこのような座標を $E$ を使わずに証明する。

### 縁取りした行列式による座標の証明

6 と 2 で使う縁取りした行列式は、$u_i$ を第 $i$ 単位ベクトルとして

$$
D_i(v) = \det \begin{pmatrix} A & \beta \\ u_i^{\mathsf T} & v \end{pmatrix} = \det(A)\,\big(v - x^\ast_i\big)
$$

である（Schur 補行列 $v - u_i^{\mathsf T} A^{-1}\beta$ による）。
$D_i$ は $v$ の 1 次関数で零点は真の座標 $x^\ast_i$ だから、区間の両端で符号が異なれば $x^\ast_i$ は区間の内側にあり、端で 0 なら端点が $x^\ast_i$ である。
符号は内点の判定と同じ厳密な行列式の述語で求めるので、$R$ や $E$ の丸めの影響を受けない。
したがって、$\tilde x_i$ 自身の誤差が端点の丸めの幅を除いて $t_i$ 以内であれば、座標の大きさによらず証明できる。
6 の計算コストは 1 座標あたり $(d+1)$ 次の厳密な行列式 2 個で、その項数は述語の計算量を抑える `max_predicate_terms` に数えられる。
真の座標が厳密に 0 のときは、$t_i < \lvert \tilde x_i \rvert$ なので 0 を含む区間を作れない。
そこで 2 で $D_i(0) = 0$ を確かめて $\tilde x_i = 0$ に置き換え、6 で半径 0 の座標として扱う。

### 二つの証明の組み合わせと違反の上界

6 で証明した座標の添字の集合を $\mathcal{B}$、5 の条件で証明した座標の添字の集合を $\mathcal{U}$ とする。
$e_{\mathcal{U}} = z_{\mathcal{U}} + E_{\mathcal{U}\mathcal{U}}\, e_{\mathcal{U}} + E_{\mathcal{U}\mathcal{B}}\, e_{\mathcal{B}}$ で、$\lvert e_{\mathcal{B}} \rvert \le t_{\mathcal{B}}$ は 6 で示されている。
$\mathcal{U}$ の各成分で確かめた 5 の条件は $\lvert z_{\mathcal{U}} \rvert + \lvert E_{\mathcal{U}\mathcal{B}} \rvert\, t_{\mathcal{B}} + \lvert E_{\mathcal{U}\mathcal{U}} \rvert\, t_{\mathcal{U}} \le t_{\mathcal{U}}$ にあたる。
$\lVert E_{\mathcal{U}\mathcal{U}} \rVert_\infty \le \lVert E \rVert_\infty < 1$ なので、同じ Neumann 級数の議論から $\lvert e_{\mathcal{U}} \rvert \le t_{\mathcal{U}}$ が従う。
こうして、どちらの方法で証明した座標についても $\lvert x^\ast_i - \tilde x_i \rvert \le t_i$ が成り立つ。

真の頂点 $x^\ast$ はすべての不等式を満たすので、

$$
a_i \cdot \tilde x + b_i = a_i \cdot (\tilde x - x^\ast) + (a_i \cdot x^\ast + b_i) \le \sum_j \lvert a_{ij} \rvert\, t_j \le \rho \sum_j \lvert a_{ij} \tilde x_j \rvert
$$

となり、有効でない不等式も含めて違反が抑えられる。
出力に反映している仕様は、これを緩めた

$$
a_i \cdot \tilde x + b_i \le 128\,\varepsilon\,(d+1) \Big( \lvert b_i \rvert + \sum_j \lvert a_{ij} \tilde x_j \rvert \Big)
$$

で、すべての頂点とすべての不等式について成り立つ。
上の導出から、違反は出力に反映している上界の $\rho / (128\,\varepsilon\,(d+1)) = 1/4$ 以下になる。
証明に失敗するのは、$A$ が悪条件で $\lVert E \rVert_\infty < 1$ を示せないときや、3 回の候補のどれにも 5 でも 6 でも証明できない座標が残るときで、構築全体が `NumericalInstability` を返す。

## 座標軸の上の頂点と厳密な検算

次のセルは[半空間の交差と双対凸包](oxref:spatial-halfspace-polygon)と同じ単位円に外接する正 $m$ 角形

$$
\cos\theta_k\, x + \sin\theta_k\, y - 1 \le 0, \qquad \theta_k = \varphi + \frac{2\pi k}{m}, \quad k = 0, \dots, m-1
$$

に冗長な不等式 $x - 3 \le 0$ を加え、辺の数 $m$ を固定して $\varphi = 0^\circ, 5^\circ, \dots, 90^\circ$ の 19 通りに回して、それぞれで交差を作る。
向きによっては頂点が座標軸の上かそのすぐ近くに来て、ある座標が他の座標の $\varepsilon$ 倍程度か 0 になるので、手順 5 の条件が成り立ちにくい。
返った頂点 $\tilde x$ の誤差は、証明の手順とは別の独立な検算で確かめる。
各頂点で有効な 2 行 $r$、$s$ について、Cramer の公式 $x^\ast_i = N_i / \det A$ の分子と分母を `RangeAccumulator`（[厳密累積と範囲安全な算術](../../../scioxide-core/algorithms/range-safe-arithmetic/)）で丸めずに求める。
$x^\ast_i - \tilde x_i = (N_i - \tilde x_i \det A) / \det A$ は、厳密な分子を丸めた $\det A$ で割って得る（相対誤差は $2\varepsilon$ 程度）。
$N_i$ の厳密な符号から、$x^\ast_i = 0$ かどうかも厳密に分かる。

表は向きごとに、構築の結果、頂点の数、0 でない座標の相対的な大きさ $\lvert \tilde x_i \rvert / \max_j \lvert \tilde x_j \rvert$（$j$ は同じ頂点の座標）の最小、$\tilde x_i = 0$ の座標の数、$x^\ast_i = 0$ の座標の数を示す。
さらに、0 でない座標の誤差と半径の比 $\lvert x^\ast_i - \tilde x_i \rvert / t_i$ の最大と、違反と上界の比の最大を示す。
違反は丸めずに積み上げてから 1 回だけ丸める。
証明が正しければ、誤差と半径の比は 1 以下、違反と上界の比は $1/4$ 以下で、$\tilde x_i = 0$ の座標と $x^\ast_i = 0$ の座標の数は一致する。
構築が失敗した向きは、その分類を結果の欄に出す。

```rust
//| id: spatial-halfspace-axis-scan
//| ref: spatial-halfspace-axis-scan
//| title: 正多角形を回し、座標軸の近くの頂点の誤差を厳密な Cramer の公式で確かめる
//| run: reactive
//| crates: [scioxide-core, scioxide-spatial]
//| inputs:
//|   sides: {"type":"range","label":"辺の数 m","min":3,"max":12,"step":1,"value":6}
//| cases:
//|   - {"id":"square","label":"m = 4","description":"φ = 45° で 4 個の頂点がすべて座標軸のすぐ近くに来る。","inputs":{"sides":4}}
//|   - {"id":"dodecagon","label":"m = 12","description":"φ = 15°、45°、75° で頂点が座標軸の上に来て、そのうち 2 つの向きでは座標が厳密に 0 になる。","inputs":{"sides":12}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"orientations","path":"/rows/0/1","equals":"Bounded"}
//|       - {"artifact":"orientations","path":"/rows/0/3","range":{"max":1e-15}}
//|       - {"artifact":"orientations","path":"/rows/0/6","range":{"max":1}}
//|       - {"artifact":"orientations","path":"/rows/6/1","equals":"Bounded"}
//|       - {"artifact":"orientations","path":"/rows/14/6","range":{"max":1}}
//|       - {"artifact":"orientations","path":"/rows/14/7","range":{"max":0.25}}
//|       - {"artifact":"orientations","path":"/rows/18/1","equals":"Bounded"}
//|       - {"artifact":"orientations","path":"/rows/18/6","range":{"max":1}}
//|   - case: square
//|     expect:
//|       - {"artifact":"orientations","path":"/rows/9/1","equals":"Bounded"}
//|       - {"artifact":"orientations","path":"/rows/9/3","range":{"max":1e-15}}
//|       - {"artifact":"orientations","path":"/rows/9/6","range":{"max":1}}
//|       - {"artifact":"orientations","path":"/rows/8/6","range":{"max":1}}
//|   - case: dodecagon
//|     expect:
//|       - {"artifact":"orientations","path":"/rows/3/1","equals":"Bounded"}
//|       - {"artifact":"orientations","path":"/rows/3/4","equals":1}
//|       - {"artifact":"orientations","path":"/rows/3/5","equals":1}
//|       - {"artifact":"orientations","path":"/rows/3/6","range":{"max":1}}
//|       - {"artifact":"orientations","path":"/rows/9/4","equals":0}
use scioxide_core::{SciOxideError, RangeAccumulator, RealScalar};
use scioxide_spatial::{HalfspaceIntersection, PointSet};

let m = sides as usize;
let pi = std::f64::consts::PI;
let rho = 32.0 * f64::EPSILON * 3.0; // 半径の係数 ρ = 32 ε (d + 1)、d = 2
let scale = 128.0 * f64::EPSILON * 3.0; // 違反の上界の係数 128 ε (d + 1)
// 独立な検算: 有効な 2 行 r, s の解の座標 axis について、x* − x̃ と x* = 0 かどうかを返す。
// x*₀ det A = −b_r s₁ + b_s r₁、x*₁ det A = −r₀ b_s + s₀ b_r を丸めずに積み上げる。
let offset = |r: &[f64], s: &[f64], axis: usize, value: f64| -> Result<_, SciOxideError> {
    let mut det = RangeAccumulator::<f64>::new();
    det.add_product(r[0], s[1])?;
    det.subtract_product(r[1], s[0])?;
    let mut numerator = RangeAccumulator::<f64>::new();
    if axis == 0 {
        numerator.subtract_product(r[2], s[1])?;
        numerator.add_product(s[2], r[1])?;
    } else {
        numerator.subtract_product(r[0], s[2])?;
        numerator.add_product(s[0], r[2])?;
    }
    let exact_zero = numerator.sign().is_eq();
    // (x* − x̃) det A = N − x̃ (r₀ s₁ − r₁ s₀)
    numerator.subtract_triple_product(value, r[0], s[1])?;
    numerator.add_triple_product(value, r[1], s[0])?;
    Ok((numerator.finish_quotient(det.finish()?)?, exact_zero))
};
// 違反 a·x̃ + b を丸めずに積み上げ、最後に 1 回だけ丸める。
let violation = |row: &[f64], x: &[f64]| -> Result<f64, SciOxideError> {
    let mut sum = RangeAccumulator::<f64>::new();
    sum.add(row[2])?;
    sum.add_product(row[0], x[0])?;
    sum.add_product(row[1], x[1])?;
    sum.finish()
};
let mut table = Vec::new();
for step in 0..=18 {
    let rotation = 5.0 * step as f64;
    let phase = rotation * pi / 180.0;
    // 行 k < m は [cos θ_k, sin θ_k, −1]、行 m は冗長な x − 3 ≤ 0。
    let mut rows: Vec<f64> = Vec::with_capacity(3 * (m + 1));
    for k in 0..m {
        let theta = phase + 2.0 * pi * k as f64 / m as f64;
        rows.extend([RealScalar::cos(theta), RealScalar::sin(theta), -1.0]);
    }
    rows.extend([1.0, 0.0, -3.0]);
    let halfspaces = PointSet::from_rows(&rows, 3).map_err(|e| e.to_string())?;
    let polygon = match HalfspaceIntersection::new(&halfspaces, &[0.0, 0.0]) {
        Ok(polygon) => polygon,
        Err(e) => {
            let kind = format!("{:?}", e.kind());
            table.push((rotation, kind, None, None, None, None, None, None));
            continue;
        }
    };
    let vertices = polygon.vertices();
    let (mut smallest, mut zeros, mut exact_zeros) = (f64::INFINITY, 0, 0);
    let (mut error_ratio, mut violation_ratio) = (0.0_f64, f64::NEG_INFINITY);
    for (v, x) in vertices.chunks(2).enumerate() {
        let active = polygon.active_halfspaces(v).map_err(|e| e.to_string())?;
        let (r, s) = (&rows[3 * active[0]..][..3], &rows[3 * active[1]..][..3]);
        let largest = x[0].abs().max(x[1].abs());
        for axis in 0..2 {
            let (error, exact_zero) = offset(r, s, axis, x[axis]).map_err(|e| e.to_string())?;
            exact_zeros += usize::from(exact_zero);
            if x[axis] == 0.0 {
                zeros += 1;
            } else {
                smallest = smallest.min(x[axis].abs() / largest);
                error_ratio = error_ratio.max(error.abs() / (rho * x[axis].abs()));
            }
        }
        for row in rows.chunks(3) {
            let excess = violation(row, x).map_err(|e| e.to_string())?;
            let bound = scale * (row[2].abs() + (row[0] * x[0]).abs() + (row[1] * x[1]).abs());
            violation_ratio = violation_ratio.max(excess / bound);
        }
    }
    let kind = format!("{:?}", polygon.kind());
    table.push((
        rotation,
        kind,
        Some(vertices.len() / 2),
        Some(smallest),
        Some(zeros),
        Some(exact_zeros),
        Some(error_ratio),
        Some(violation_ratio),
    ));
}
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let fixed4 = serde_json::json!({ "fractionDigits": 4 });
let columns = serde_json::json!([
    { "key": "0", "label": "φ [deg]", "type": "number", "format": { "fractionDigits": 0 } },
    { "key": "1", "label": "結果" },
    { "key": "2", "label": "頂点 [個]", "type": "integer", "nullText": "—" },
    { "key": "3", "label": "相対的な大きさの最小 [-]", "type": "number", "format": sci2, "nullText": "—" },
    { "key": "4", "label": "x̃ᵢ = 0 の座標 [個]", "type": "integer", "nullText": "—" },
    { "key": "5", "label": "x*ᵢ = 0 の座標 [個]", "type": "integer", "nullText": "—" },
    { "key": "6", "label": "誤差 / 半径の最大 [-]", "type": "number", "format": sci2, "nullText": "—" },
    { "key": "7", "label": "違反 / 上界の最大 [-]", "type": "number", "format": fixed4, "nullText": "—" }
]);
emit_table_with_columns!(
    columns,
    table,
    metadata = serde_json::json!({ "id": "orientations" })
);
```

既定値（$m = 6$）では、19 通りの向きのすべてで構築が `Bounded` になる。
$\varphi = 0^\circ$、$30^\circ$、$60^\circ$ では相対的な大きさの最小が $1.1 \times 10^{-16}$、$\varphi = 90^\circ$ では $2.2 \times 10^{-16}$ で、頂点が座標軸のすぐ近くにある。
どの向きでも $x^\ast_i = 0$ の座標はなく、軸の近くの座標は丸めた係数のもとで真に 0 でない小さな値である。
誤差と半径の比は最大 0.067（$\varphi = 70^\circ$）で、軸の近くの座標を含むすべての座標で真の頂点が証明した半径の内側にあり、半径には 10 倍以上の余裕がある。
違反と上界の比は最大 0.0017 で、導出から決まる $1/4$ を大きく下回る。

「m = 4」では、$\varphi = 45^\circ$ で 4 個の頂点がすべて座標軸の上に来て、相対的な大きさの最小は $7.9 \times 10^{-17}$ になるが、構築は成功し、誤差と半径の比は 0.0027 である。
全向きでの比の最大は 0.093（$\varphi = 40^\circ$）である。
「m = 12」では $\varphi = 15^\circ$、$45^\circ$、$75^\circ$ で頂点が座標軸の上に来る。
$15^\circ$ と $75^\circ$ では $x^\ast_i = 0$ が厳密に成り立つ座標が 1 個ずつあり、返った座標もちょうど 0 である。
この座標は手順 2 で 0 に置き換えないかぎり、$\lvert \tilde x_i \rvert$ に比例する半径では証明できない。
$45^\circ$ では軸の上の頂点の座標は真には 0 でなく（相対的な大きさ $2.1 \times 10^{-16}$）、0 に置き換えられずにそのまま証明されている。
全向きでの誤差と半径の比の最大は 0.18（$\varphi = 10^\circ$）である。

半径 $t_i = \rho\,\lvert \tilde x_i \rvert$ は $\lvert \tilde x_i \rvert$ より小さいので、証明した区間は 0 を含まない。
したがって構築が成功すれば、返った座標の符号は真の座標の符号と一致し、$\tilde x_i = 0$ と $x^\ast_i = 0$ は同値になる。
表の 2 つの数の列が一致するのは、この性質による。

## まとめ

`HalfspaceIntersection` が返す頂点の各座標は、真の座標から $32\,\varepsilon\,(d+1)\,\lvert \tilde x_i \rvert$ 以内にあることを証明した値である。
証明は Rump の前処理付き残差による成分ごとの条件を主に使い、座標軸の近くで成り立たない座標は縁取りした行列式の符号で区間を直接確かめる。
構築が成功すれば返った座標の符号は真の座標の符号と一致し、真の値が 0 の座標は厳密に 0 で返る。
すべての不等式の違反は出力に反映している上界 $128\,\varepsilon\,(d+1)(\lvert b_i \rvert + \sum_j \lvert a_{ij} \tilde x_j \rvert)$ 以下で、導出からはその $1/4$ 以下になる。
頂点の連立方程式が悪条件で証明できなければ、構築全体が `NumericalInstability` を返すので、一部の頂点だけが不確かな結果を受け取ることはない。
