Delaunay 分割を作った後の典型的な問いは、「点 $x$ はどの単体に入っているか」と「その単体の頂点に置いた値から $x$ での値をどう作るか」の二つである。
前者が点の位置の探索（point location）で、後者は単体の重心座標を重みとする区分線形補間で答えられる。
`Delaunay::find_simplex` は前者を厳密な幾何述語だけで決め、`barycentric_into` は後者の重みを丸めた値として返す。
このページでは重心座標の定義とアフィン写像、探索のアルゴリズムと計算量、境界と凸包の外の扱い、重心座標の条件数と単体の形の関係を説明し、入力行の対応、境界上の点、細い三角形で結果を確かめる。
分割の作り方、母点の並べ替え、退化の扱いは[凸包・Delaunay 分割・Voronoi 図](../delaunay-voronoi-and-hulls/)にある。

## 重心座標とアフィン写像

$d$ 単体の頂点を $p_0, \dots, p_d \in \mathbb{R}^d$ とする。
点 $x$ の重心座標 $\lambda = (\lambda_0, \dots, \lambda_d)$ は

$$
x = \sum_{i=0}^{d} \lambda_i\, p_i, \qquad \sum_{i=0}^{d} \lambda_i = 1
$$

を満たす数の組である。
辺の行列 $A = [\,p_1 - p_0, \dots, p_d - p_0\,]$（$d \times d$）を使うと、$\mu = (\lambda_1, \dots, \lambda_d)$ は

$$
\mu = A^{-1}(x - p_0), \qquad \lambda_0 = 1 - \sum_{i=1}^{d} \mu_i
$$

で決まり、重心座標は $x$ のアフィン関数になる。
単体が潰れていなければ $A$ は正則で、重心座標は一意である。

重心座標は向き述語の比としても書ける。
$\lambda_i$ は頂点 $p_i$ を $x$ に置き換えた単体の向きの行列式を、元の単体の向きの行列式 $\det[\,p_1 - p_0, \dots, p_d - p_0\,]$ で割った値である。
したがって $x$ が閉じた単体に含まれることは、置き換えた $d+1$ 個の行列式の符号がどれも単体の向きと逆にならないことと同値で、この判定には丸めた $\lambda$ を使わずに厳密な述語を使える。
ある $\lambda_i$ が厳密に 0 なら、$x$ は $p_i$ の向かいの面の上にある。

重心座標の勾配 $\nabla \lambda_i$ は単体の上で一定で、$\nabla \lambda_1, \dots, \nabla \lambda_d$ は $A^{-1}$ の行、$\nabla \lambda_0 = -\sum_{i \ge 1} \nabla \lambda_i$ である。
頂点の値 $f_i$ から作る

$$
f_h(x) = \sum_{i=0}^{d} \lambda_i(x)\, f_i
$$

は単体ごとに線形で、隣り合う単体の共有面の上で一致する連続な区分線形補間になり、$\nabla f_h = \sum_i f_i \nabla \lambda_i$ は単体の上で一定である。
$\lambda_i$ は 1 次の有限要素の形状関数そのものでもある。
散在点の補間での使い方は[三角形分割を共有する散在点補間](oxref:interp-nearest-and-linear)にある。

## 点の位置の探索と重心座標

`find_simplex(point)` は点を含む閉じた単体を探し、`SimplexLocation { simplex, boundary }` を `Some` で返す。
点が凸包の外にあれば `None` を返す。
点が複数の単体が共有する面・辺・頂点の上にあるときは番号が最小の単体を返し、`boundary` を真にする。
`boundary` はある重心座標が厳密に 0 であることを意味し、この判定も厳密な述語による。
単体の頂点の番号は座標の辞書式順に並べた母点の正準添字である（[母点の正準化と退化の扱い](oxref:spatial-tessellation-sites)）。
`find_simplex` は照会ごとに作業領域を確保して逐次に実行する。
多数の点を照会するときは、事前確保した `GeometryWorkspace` と実行コンテキストを `find_simplex_scoped(point, &mut workspace, cx)` に渡す。

探索は可視性歩行（visibility walk、Devillers–Pion–Teillaud）である。

1. 出発点の単体を選ぶ。
   構築のときに、単体の重心を中央値で分ける木を作っておく（重心の各座標は、その座標軸で最も大きい母点の座標の絶対値で割っておく）。
   この木を照会点へ向けて 1 回たどり、たどった節点の重心のうち照会点に最も近いものの単体を使う。
   同じ作業領域で前回見つけた単体があればそれを最初の候補にし、たどる途中でより近い重心が現れれば置き換える。
2. いまの単体の各面について、面の向かいの頂点を照会点で置き換えた向き述語の符号を調べる。
   照会点が面の外側にあれば、その面を越えて隣の単体へ移る。
   直前にいた単体との共有面は調べない。
   調べ始める面は照会ごとに同じシードから始める xorshift の擬似乱数で歩ごとに変える（確率的な歩行）。
3. どの面の外側にもなければ、その単体が点を含む。
   面を越えた先に単体がなければ、点は凸包の外にある。
4. 歩いた単体の数が単体の総数に達したときは、すべての単体を番号順に調べる。
   退化した分割で歩行が循環しても、探索は必ず止まる。

1 歩あたりの処理は $d+1$ 個の向き述語で、歩く単体の数は出発点から照会点までの距離で決まる。
照会点の近くの単体から歩き始めれば、多くの照会で歩く単体はわずかで済む。
最悪の場合は単体の数に比例する。
照会点が並んでいるときは、作業領域が覚えた前回の単体が近い出発点になり、近くの照会で歩く単体が減る。

`find_simplex_scoped` に渡した `GeometryWorkspace` が覚える前回の単体は分割の `MeshToken` に結び付いた出発点の候補にすぎず、結果は前回の照会によらない。
確保した作業領域を使う照会は新たな確保をせず、`workspace.predicate_terms()` はその作業領域を使った直前の照会の述語の計算量を返す。
照会点の長さが次元と違うか、作業領域が要件を満たさなければ `DimensionMismatch`、NaN や無限大を含めば `NonFinite`、述語の計算量の上限を超えれば `ResourceLimit` になる。
実行コンテキストの取り消しと期限では `ExecutionStopped`、求解コンテキストの節点数を使い切ると `ConvergenceFailure` を返す。

点を含む単体が分かれば、重心座標を求められる。
`barycentric(simplex, point)` は $\lambda$ を `simplex(s)` の頂点の順に並べた長さ $d+1$ の `Vec` を返す。
確保をしない形 `barycentric_into(simplex, point, &mut output, &mut scratch)` は同じ値を `output` に書き、`output` の長さは $d+1$、`scratch` は $d+1$ 以上である。
点は単体の外にあってもよい（いくつかの $\lambda_i$ が負になる）ので、包含の判定には `find_simplex` を使う。
`barycentric_gradients_into` は $\nabla \lambda_i$ を $d+1$ 行 $d$ 列で、`circumcenter_into` は外心（外接球の中心）を書く。
どの照会も、単体の番号が範囲外なら `OutOfBounds`、渡した `point`・`output` の長さが違うか `scratch` が短ければ `DimensionMismatch`、`point` に NaN や無限大があれば `NonFinite` を返す。

## 重心座標の条件数と単体の形

$x$ を $\delta x$ だけ動かすと $\mu$ は $A^{-1}\delta x$ だけ変わるので、$\|A^{-1}\|$ が重心座標の条件数の目安になる。
平面の三角形で辺の長さを $1$ 程度にそろえたとき、$\|A^{-1}\|$ はおよそ最小の高さの逆数に比例する。
最小角が小さい針のような三角形や、3 次元で体積がほとんどない単体（スリバー）では $A^{-1}$ の成分が大きくなり、座標の丸め誤差が重心座標に拡大されて現れる。

`Delaunay` は各単体のアフィン写像を構築のときに一度だけ `f64` で作る。
座標を 2 のべきで正規化し、辺の行列 $A$ を最大の成分が 1 になるように割ってから、LU 分解で逆行列を求める。
以下の $A$ はこの正規化した辺の行列である。
丸めた局所座標の誤差は重心座標におよそ $\max_{i,j} |(A^{-1})_{ij}| \cdot \varepsilon \cdot d^2$ の大きさで伝わるので、$\varepsilon$ を `f64` の機械イプシロンとして

$$
\max_{i,j} |(A^{-1})_{ij}| \cdot \varepsilon \cdot d^2 > \sqrt{\varepsilon}
$$

となる単体は写像を持たない。
そのような単体では、重心座標・勾配・外心の照会だけが `NumericalInstability` を返す。
この判定は悪条件の単体を除くためのもので、単体から遠い点での誤差を抑えるものではない。
点の位置の探索は厳密な述語だけで決まり、丸めた写像を使わないので、その単体でもそのまま使える。
Voronoi 頂点の座標も同じ写像の外心から作るので、写像を持たない単体だけの群では `Voronoi::vertex` が `NumericalInstability` を返す。

## 正準添字の対応と境界上の照会点

次のセルは単位正方形の 4 隅と内部の 2 点を、順序を崩し、1 点を重複させた 7 行で与える。
1 つ目の表は入力行ごとに正準添字と代表の入力行を示す。
2 つ目の表は照会点ごとに、含む単体、境界上かどうか、単体の頂点の入力行、最小の重心座標、照会で使った述語の計算量を示す。
照会点の一つは入力で動かせ、残りの三つは母点の上、凸包の辺の上、凸包の外に固定する。
最後の表は、入力行を逆順にして作り直した分割が、正準添字で書いた単体の列として同じになるかを示す。

```rust
//| id: spatial-delaunay-point-location
//| ref: spatial-delaunay-point-location
//| title: 入力行と母点の対応を確かめ、照会点を含む単体を探す
//| run: reactive
//| crates: [scioxide-core, scioxide-spatial]
//| inputs:
//|   query_x: {"type":"range","label":"照会点の x [-]","min":-0.2,"max":1.2,"step":0.05,"value":0.5}
//|   query_y: {"type":"range","label":"照会点の y [-]","min":-0.2,"max":1.2,"step":0.05,"value":0.3}
//| cases:
//|   - {"id":"outside","label":"凸包の外 (1.2, 0.3)","description":"凸包の外では単体がなく None になる。","inputs":{"query_x":1.2}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"sites","path":"/rows/4/3","equals":2}
//|       - {"artifact":"sites","path":"/rows/4/4","equals":1}
//|       - {"artifact":"location","path":"/rows/0/4","equals":false}
//|       - {"artifact":"location","path":"/rows/0/6","range":{"min":1e-17,"max":1e-15}}
//|       - {"artifact":"location","path":"/rows/1/4","equals":true}
//|       - {"artifact":"location","path":"/rows/3/3","equals":null}
//|       - {"artifact":"order","path":"/rows/0/0","equals":true}
//|   - case: outside
//|     expect:
//|       - {"artifact":"location","path":"/rows/0/3","equals":null}
//|       - {"artifact":"location","path":"/rows/1/3","equals":2}
use scioxide_core::{ExecutionContext, SciOxideError};
use scioxide_spatial::{Delaunay, PointSet};

// 7 行の入力。行 4 は行 1 と同じ座標なので、母点は 6 個になる。
let rows: [[f64; 2]; 7] = [
    [1.0, 1.0],
    [0.3, 0.4],
    [0.0, 0.0],
    [1.0, 0.0],
    [0.3, 0.4],
    [0.0, 1.0],
    [0.7, 0.2],
];
let build = |sites: &[[f64; 2]]| -> Result<Delaunay<f64>, SciOxideError> {
    Delaunay::new(&PointSet::from_points(sites)?)
};
let mesh = build(&rows).map_err(|e| e.to_string())?;
let (mapping, first_row) = (mesh.input_mapping(), mesh.representatives());
let site_rows: Vec<(usize, f64, f64, usize, usize)> = rows
    .iter()
    .enumerate()
    .map(|(r, p)| (r, p[0], p[1], mapping[r], first_row[mapping[r]]))
    .collect();
let fixed2 = serde_json::json!({ "fractionDigits": 2 });
let columns = serde_json::json!([
    { "key": "0", "label": "入力行", "type": "integer" },
    { "key": "1", "label": "x [-]", "type": "number", "format": fixed2 },
    { "key": "2", "label": "y [-]", "type": "number", "format": fixed2 },
    { "key": "3", "label": "正準添字 input_mapping", "type": "integer" },
    { "key": "4", "label": "代表の入力行 representatives", "type": "integer" }
]);
emit_table_with_columns!(
    columns,
    site_rows,
    metadata = serde_json::json!({ "id": "sites" })
);

let mut workspace = mesh.workspace(()).map_err(|e| e.to_string())?;
let queries = [
    ("入力の点", [query_x, query_y]),
    ("母点 (1, 0)", [1.0, 0.0]),
    ("凸包の辺の中点", [0.5, 0.0]),
    ("凸包の外", [1.1, 0.5]),
];
let mut located = Vec::new();
for (name, query) in queries {
    let found = mesh
        .find_simplex_scoped(&query, &mut workspace, ExecutionContext::sequential())
        .map_err(|e| e.to_string())?;
    let terms = workspace.predicate_terms();
    let (mut corners, mut smallest) = (None, None);
    if let Some(location) = found {
        let (mut weights, mut scratch) = ([0.0; 3], [0.0; 3]);
        mesh.barycentric_into(location.simplex, &query, &mut weights, &mut scratch)
            .map_err(|e| e.to_string())?;
        smallest = weights.iter().copied().reduce(f64::min);
        // 単体の頂点は正準添字なので、representatives で入力行へ戻す。
        let vertices = mesh.simplex(location.simplex).map_err(|e| e.to_string())?;
        let names: Vec<String> = vertices.iter().map(|&v| first_row[v].to_string()).collect();
        corners = Some(names.join(", "));
    }
    let simplex = found.map(|l| l.simplex);
    let boundary = found.map(|l| l.boundary);
    located.push((
        name, query[0], query[1], simplex, boundary, corners, smallest, terms,
    ));
}
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let columns = serde_json::json!([
    { "key": "0", "label": "照会" },
    { "key": "1", "label": "x [-]", "type": "number", "format": fixed2 },
    { "key": "2", "label": "y [-]", "type": "number", "format": fixed2 },
    { "key": "3", "label": "単体", "type": "integer", "nullText": "なし" },
    { "key": "4", "label": "境界上", "type": "boolean", "nullText": "—" },
    { "key": "5", "label": "頂点の入力行", "nullText": "—" },
    { "key": "6", "label": "最小の重心座標 [-]", "type": "number", "format": sci2, "nullText": "—" },
    { "key": "7", "label": "述語の計算量 [処理単位]", "type": "integer" }
]);
emit_table_with_columns!(
    columns,
    located,
    metadata = serde_json::json!({ "id": "location" })
);

// 入力行を逆順にしても、正準添字で書いた単体の列は同じになる。
let reversed: Vec<[f64; 2]> = rows.iter().rev().copied().collect();
let other = build(&reversed).map_err(|e| e.to_string())?;
let count = mesh.simplex_count();
let same = count == other.simplex_count()
    && (0..count).all(|s| mesh.simplex(s).ok() == other.simplex(s).ok());
let columns = serde_json::json!([
    { "key": "0", "label": "逆順の入力でも同じ単体の列", "type": "boolean" },
    { "key": "1", "label": "単体 [個]", "type": "integer" }
]);
emit_table_with_columns!(
    columns,
    vec![(same, count)],
    metadata = serde_json::json!({ "id": "order" })
);
```

1 つ目の表で、入力行 1 と 4 は同じ母点 2 にまとまり、代表の入力行は小さいほうの 1 である。
正準添字は座標の辞書式順で、入力行 2 の原点が母点 0、入力行 0 の $(1, 1)$ が母点 5 になる。
単体の頂点は正準添字なので、2 つ目の表の「頂点の入力行」は `representatives()` で入力行に戻した値を示している。

既定の照会点 $(0.5, 0.3)$ は、実数の座標なら 2 点 $(0.3, 0.4)$ と $(0.7, 0.2)$ を結ぶ辺の中点である。
しかし `f64` の 0.3、0.4、0.7、0.2 は 10 進の値を丸めた 2 進数なので、与えた座標に対する厳密な判定では、この点は辺の上にない。
そのため「境界上」は偽で、最小の重心座標は $1.1 \times 10^{-16}$ と 0 に近い正の値になる。
母点 $(1, 0)$ と凸包の辺の中点 $(0.5, 0)$ は単体 2 の境界上にあり、「境界上」は真、最小の重心座標は厳密に 0 である。
母点 $(1, 0)$ は複数の三角形に共有されるが、番号が最小の単体 2 が返る。
凸包の外の点には単体がなく、`None` になる。
最後の表のとおり、入力行を逆順にしても 6 個の単体は正準添字で同じ列になる。

## 写像を持たなくなる高さと針状の三角形

次のセルは頂点 $(0, 0)$、$(1, 0)$、$(1/2, h)$ の三角形 1 個の分割を作り、重心 $(1/2, h/3)$ の位置を探してから、重心座標と外心を求める。
辺の行列は $A = \begin{pmatrix} 1 & 1/2 \\ 0 & h \end{pmatrix}$ で、$\max |(A^{-1})_{ij}| = 1/h$ だから、写像を持たなくなる境目は $(1/h)\,\varepsilon \cdot 2^2 = \sqrt{\varepsilon}$、つまり $h^\ast = 4\sqrt{\varepsilon} \approx 6.0 \times 10^{-8}$ である。
表は高さ $h$、重心を含む単体、二つの照会の結果（成功か失敗の分類）、重心座標の和から 1 を引いた値を示す。

```rust
//| id: spatial-delaunay-sliver-map
//| ref: spatial-delaunay-sliver-map
//| title: 細い三角形で位置の探索は成功し、丸めたアフィン写像の照会だけが失敗することを確かめる
//| run: reactive
//| crates: [scioxide-core, scioxide-spatial]
//| inputs:
//|   height_exponent: {"type":"range","label":"高さの指数 k（h = 10^k）[-]","min":-12,"max":-1,"step":1,"value":-6}
//| cases:
//|   - {"id":"needle","label":"h = 10⁻⁹","description":"境目 4√ε より細いと、重心座標と外心の照会が NumericalInstability を返す。","inputs":{"height_exponent":-9}}
//|   - {"id":"above-threshold","label":"h = 10⁻⁷","description":"境目 4√ε ≈ 6.0 × 10⁻⁸ のすぐ上で、照会はまだ成功する。","inputs":{"height_exponent":-7}}
//|   - {"id":"below-threshold","label":"h = 10⁻⁸","description":"境目のすぐ下で、照会が NumericalInstability を返す。","inputs":{"height_exponent":-8}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"sliver","path":"/rows/0/1","equals":0}
//|       - {"artifact":"sliver","path":"/rows/0/2","equals":"成功"}
//|       - {"artifact":"sliver","path":"/rows/0/4","range":{"min":-1e-15,"max":1e-15}}
//|   - case: needle
//|     expect:
//|       - {"artifact":"sliver","path":"/rows/0/1","equals":0}
//|       - {"artifact":"sliver","path":"/rows/0/2","equals":"NumericalInstability"}
//|       - {"artifact":"sliver","path":"/rows/0/3","equals":"NumericalInstability"}
//|   - case: above-threshold
//|     expect:
//|       - {"artifact":"sliver","path":"/rows/0/2","equals":"成功"}
//|       - {"artifact":"sliver","path":"/rows/0/4","range":{"min":-1e-15,"max":1e-15}}
//|   - case: below-threshold
//|     expect:
//|       - {"artifact":"sliver","path":"/rows/0/1","equals":0}
//|       - {"artifact":"sliver","path":"/rows/0/2","equals":"NumericalInstability"}
use scioxide_core::{ExecutionContext, SciOxideError};
use scioxide_spatial::{Delaunay, PointSet};

let h = 10.0_f64.powf(height_exponent);
let vertices = [[0.0, 0.0], [1.0, 0.0], [0.5, h]];
let points = PointSet::from_points(&vertices).map_err(|e| e.to_string())?;
let mesh = Delaunay::new(&points).map_err(|e| e.to_string())?;

// 位置の探索は厳密な向き述語だけで決まる。
let centroid = [0.5, h / 3.0];
let mut workspace = mesh.workspace(()).map_err(|e| e.to_string())?;
let found = mesh
    .find_simplex_scoped(&centroid, &mut workspace, ExecutionContext::sequential())
    .map_err(|e| e.to_string())?;
// 重心座標と外心は、構築のときに作った丸めたアフィン写像を使う。
let (mut weights, mut scratch, mut center) = ([0.0; 3], [0.0; 3], [0.0; 2]);
let verdict = |result: Result<(), SciOxideError>| match result {
    Ok(()) => "成功".to_string(),
    Err(e) => format!("{:?}", e.kind()),
};
let barycentric = mesh.barycentric_into(0, &centroid, &mut weights, &mut scratch);
let sum_error = barycentric
    .is_ok()
    .then(|| weights.iter().sum::<f64>() - 1.0);
let circumcenter = verdict(mesh.circumcenter_into(0, &mut center));
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let columns = serde_json::json!([
    { "key": "0", "label": "高さ h [-]", "type": "number", "format": sci2 },
    { "key": "1", "label": "重心を含む単体", "type": "integer", "nullText": "なし" },
    { "key": "2", "label": "barycentric_into" },
    { "key": "3", "label": "circumcenter_into" },
    { "key": "4", "label": "Σλ − 1 [-]", "type": "number", "format": sci2, "nullText": "—" }
]);
emit_table_with_columns!(
    columns,
    vec![(
        h,
        found.map(|l| l.simplex),
        verdict(barycentric),
        circumcenter,
        sum_error
    )],
    metadata = serde_json::json!({ "id": "sliver" })
```

既定値 $h = 10^{-6}$ では、重心座標と外心がどちらも求まり、重心座標の和と 1 の差は $-1.1 \times 10^{-16}$ である。
$h = 10^{-9}$ の「針」では、位置の探索は単体 0 を返すが、重心座標と外心の照会は `NumericalInstability` を返す。
$k$ を動かすと、$h = 10^{-7}$ では成功し、$10^{-8}$ では失敗して、境目 $h^\ast \approx 6.0 \times 10^{-8}$ と合う。
この失敗はその単体の照会に限られ、分割の構築と位置の探索は影響を受けない。
細い三角形の外心は $(1/2, (h^2 - 1/4)/(2h))$ で、$h \to 0$ で遠くへ離れる。
写像を持たない単体だけからなる群では、Voronoi 頂点の座標も `NumericalInstability` になる。

## まとめ

点を含む単体は `find_simplex` で探し、`None` なら凸包の外、`boundary` が真なら共有する面の上の点として、番号が最小の単体を受け取る。
並んだ照会では同じ作業領域を `find_simplex_scoped` に使い回すと、覚えた前回の単体が近い出発点になり、結果を変えずに歩く単体が減る。
区分線形補間や 1 次の有限要素の重みには `barycentric_into` の重心座標 $\mu = A^{-1}(x - p_0)$ を使い、包含の判定には `find_simplex` の厳密な結果を使う。
$\max |(A^{-1})_{ij}|\,\varepsilon\,d^2 > \sqrt{\varepsilon}$ となる細い単体では重心座標・勾配・外心の照会だけが `NumericalInstability` を返すので、その単体だけを別に扱えば、位置の探索と分割の構造はそのまま使える。
単体の頂点の番号は正準添字なので、入力側のデータは `representatives()` で引く。
