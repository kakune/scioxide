同じ物体を二つの座標系で測った点の組があるとき、二つを重ねる回転と並進を求める問題を剛体位置合わせという。
分子構造の重ね合わせ、レーザー測距の点群の位置合わせ、測量の標識点による座標変換などに現れる。
対応が分かっていれば、最小二乗の解は 3×3 行列の特異値分解（SVD）で閉じた形に求まる（Kabsch 1976）。
このページでは `estimate_rigid_transform` の数学と計算の手順を説明し、ノイズと外れ値のある点で推定の精度を確かめる。
解が一意に決まらない配置と不正な入力の扱いは[剛体位置合わせの一意性と失敗](../rigid-registration-degeneracy/)で扱う。
推定の結果は剛体変換 `RigidTransform` で、その合成、逆変換、多数の点への一括適用は[剛体変換と一括変換](../rigid-transforms/)で扱う。

## 重み付き最小二乗の問題

対応する点 $p_i, q_i \in \mathbb{R}^3$（$i = 1, \ldots, n$）と重み $w_i \ge 0$（$W = \sum_i w_i > 0$）に対して

$$
E(R, t) = \sum_{i=1}^n w_i \left\lvert R p_i + t - q_i \right\rvert^2
$$

を $R \in \mathrm{SO}(3)$ と $t \in \mathbb{R}^3$ について最小にする。
$p_i$ を元の点（source）、$q_i$ を目標の点（target）と呼ぶ。
重みは点ごとの信頼度で、各点の測定誤差の分散が $s_i^2$ なら $w_i = 1/s_i^2$ とし、分子では原子量を使うことが多い。
重みが 0 の点は解に影響しない。

## 並進の消去

$E$ を $t$ で微分して 0 とおくと、$\sum_i w_i (R p_i + t - q_i) = 0$ から

$$
t = \bar q - R \bar p, \qquad \bar p = \frac{1}{W}\sum_i w_i p_i, \qquad \bar q = \frac{1}{W}\sum_i w_i q_i
$$

を得る。
最適な並進は重み付き重心を重ねる。
中心化した点 $p_i' = p_i - \bar p$、$q_i' = q_i - \bar q$ を使うと、問題は回転だけの

$$
\sum_i w_i \lvert R p_i' - q_i' \rvert^2 = \sum_i w_i \left(\lvert p_i'\rvert^2 + \lvert q_i'\rvert^2\right) - 2\,\mathrm{tr}(R H), \qquad H = \sum_i w_i\, p_i' {q_i'}^\top
$$

になる。
第 1 項は $R$ によらないので、$\mathrm{tr}(RH)$ を最大にする回転を求めればよい。
$H$ は 3×3 の相互共分散行列である。

## 特異値分解と鏡映の補正

$H = U \Sigma V^\top$（$U, V$ は直交行列、$\Sigma = \mathrm{diag}(\sigma_1, \sigma_2, \sigma_3)$、$\sigma_1 \ge \sigma_2 \ge \sigma_3 \ge 0$）とすると、$Z = V^\top R U$ は直交行列で

$$
\mathrm{tr}(R H) = \mathrm{tr}(Z \Sigma) = \sum_k z_{kk}\sigma_k \le \sigma_1 + \sigma_2 + \sigma_3
$$

である（$\lvert z_{kk}\rvert \le 1$）。
等号は $Z = I$、つまり $R = V U^\top$ のときに成り立つ。
ただし $\det(VU^\top) = -1$ なら、$VU^\top$ は鏡映を含み、回転ではない。
このとき $R$ が回転なら $\det Z = \det(VU^\top)\det R = -1$ なので、行列式が $-1$ の直交行列 $Z$ の中で $\sum_k z_{kk}\sigma_k$ を最大にすればよい。
最大にするのは $Z = \mathrm{diag}(1, 1, -1)$ で、最適な回転は

$$
R = V\,\mathrm{diag}(1, 1, -1)\,U^\top = V U^\top - 2\, v_3 u_3^\top, \qquad \mathrm{tr}(RH) = \sigma_1 + \sigma_2 - \sigma_3
$$

になる（$u_3, v_3$ は $U, V$ の第 3 列）。
鏡映を最も小さい特異値の方向で打ち消すので、失う量は $2\sigma_3$ で済む。
ノイズのない鏡像の点を与えると、この補正のために残差は 0 にならない。

この最適解が一つに決まるのは、点が一直線上になく（$\sigma_2 > 0$）、鏡映を補正するときは $\sigma_2 > \sigma_3$ のときである。
平面上の点（$\sigma_3 = 0$）でも回転は一意に決まる。
数値的な判定の方法と、判定に掛かる配置の例は[一意性と階数の判定](oxref:spatial-kabsch-uniqueness)で説明する。

## 計算の手順と精度

推定は 3 つの形で呼べる。
`estimate_rigid_transform(source, target)` は重みをすべて 1、選択肢を既定値とし、`estimate_rigid_transform_with_options(source, target, weights, options)` は重みの配列（`None` なら全点が 1）と選択肢を受け取る。
どちらも取り消しのない逐次の実行で、実行コンテキストか求解コンテキストを渡すときは `estimate_rigid_transform_scoped(source, target, weights, options, scope)` を使う。
3 つの形は同じ計算を行い、3 次元の `PointSet` を 2 つ受け取って、次の順に点を走査する。

1. 重みを与えたときは、重みが有限で負でないことを確かめ、最大の重みを求める。
2. 重みが正の点について座標の絶対値の最大値を求め、最大の重みで割った重みを足し合わせる。
3. 座標を最大値で割り、重み付き重心 $\bar p, \bar q$ を求める。
4. 重心を引いた点から $H$ を足し上げる。
5. $H$ を最大の成分の絶対値で割ってから SVD を求め、数値的な階数を判定し、回転と並進を求める。
6. 重み付きの RMS 残差を求める。

座標と重みを最大値で割るので、総和と共分散は大きさ 1 程度の量の和になる。
回転は入力の単位によらず、並進と残差は最後に元の単位へ戻す。
手順 4 で $H = \sum_i w_i p_i q_i^\top - W\bar p\bar q^\top$ の形を使わないのは、原点から遠い点群では二つの大きな項が打ち消し合って桁落ちするからである。
手順 5 で $H$ を割るのは、階数の判定を点の広がりの大きさによらないものにするためである。
手順 6 で二乗の和がアンダーフローかオーバーフローを起こしそうなときは、尺度付きのノルムの累積でもう一度計算する。

SVD は `scioxide_linalg::SvdDecomposition::compute_into` で 3×3 の行列に対して求める。
Householder 変換による二重対角化と陰的シフトの二重対角 QR 法を使い、特異値の絶対誤差は $\varepsilon\sigma_1$ の程度である（Golub & Van Loan 2013、§5.4、§8.6）。
得られた行列は `Rotation::from_matrix` に `Tolerance::new(128ε, 128ε)` を渡して直交性を検査し、通らなければ `NumericalInstability` を返す。
検査する $R R^\top - I$ の各成分と $\det R - 1$ の尺度は 1 なので、実効の閾値は $128\varepsilon + 128\varepsilon \cdot 1 = 256\varepsilon$ である。
この検査は SVD と行列積の丸めによる直交性のずれを見るもので、当てはめの精度を保証するものではない。
計算量は $O(n)$ で、点数によらない大きさの 3×3 の行列、SVD の結果と作業領域を呼び出しごとに確保する。
取り消しと期限は 256 行ごとに確かめる。
`estimate_rigid_transform_scoped` に求解コンテキストを渡すと、推定は入れ子の求解になり、推定と SVD の反復は外側の求解に入れ子の反復として記録される（[入れ子の求解と回数の集計](oxref:core-nested-accounting)）。
推定は自分の求解の中で 1 回の反復として数え、その反復に上限はない。
入れ子の反復は外側の求解の反復の上限には数えない。

結果の `RigidEstimationResult` は次のフィールドを持つ。

| フィールド | 内容 |
|---|---|
| `transform` | 元の点を目標の点へ写す `RigidTransform`（[剛体変換の定義](oxref:spatial-rigid-transform)） |
| `rms_residual` | $\left(\sum_i w_i \lvert R p_i + t - q_i\rvert^2 / W\right)^{1/2}$ [入力の単位]。重みの総和で正規化する |
| `singular_values` | 最大の成分の絶対値が 1 になるように割った $H$ の特異値 $[\sigma_1, \sigma_2, \sigma_3]$ |
| `rank` | 数値的な階数（3、または平面の点で 2） |

`singular_values` は $H$ を最大の成分で割った行列の特異値なので、点の広がりの形は比 $\sigma_2/\sigma_1$、$\sigma_3/\sigma_1$ で読む。
失敗の分類と条件は[失敗の分類](oxref:spatial-kabsch-failures)の表にまとめた。

## ノイズと外れ値のある点からの復元

次のセルは立方体 $[-1, 1]^3$ m の中の一様乱数の点 $p_i$（$n$ 個）を、軸 $(1, 2, 2)/3$ のまわりの角 $\theta$ の回転と並進 $(10, 20, 30)$ m で写し、各座標に独立な正規ノイズ $N(0, \sigma^2)$ を加えて $q_i$ を作る。
点 0 の $x$ 座標にはさらに外れ値 $o$ [m] を加える。
乱数は scioxide-random のシードを指定したの生成器 `SplitMix64` で作り、シードを入力にする。
点の配列は `PointSet::from_points` で複製せずに借りる。

推定は 2 通りで行う。
全点を重み 1 とする推定は `estimate_rigid_transform` で、点 0 の重みを 0 にする推定は `estimate_rigid_transform_with_options` で求める。
表 `fits` は階数、特異値、真の回転との差の角 $d(R_{\text{true}}, R)$ [deg]（[合成の順序と逆回転](oxref:spatial-rotation-composition)の回転の距離）、並進の誤差 $\lvert t - t_{\text{true}}\rvert$ [m]、RMS 残差と、ノイズだけのときの期待値を示す。
ノイズが小さく重みが一様なら、6 つの自由度を当てはめた残りの $3m - 6$ 自由度の残差から

$$
\mathrm{E}\left[\mathrm{RMS}^2\right] \approx \frac{\sigma^2 (3m - 6)}{m}
$$

となる（$m$ は重みが正の点の数）。
期待値の列はこの式の平方根 $\sigma\sqrt{(3m - 6)/m}$ である。
3 次元の図は元の点、目標の点、点 0 の重みを 0 にした推定で写した点を同じ単位 [m] で示し、写した点と目標の点を線で結ぶ。

```rust
//| id: spatial-kabsch-recovery
//| ref: spatial-kabsch-recovery
//| title: ノイズと外れ値のある対応点から剛体変換を復元する
//| run: reactive
//| crates: [scioxide-core, scioxide-random, scioxide-spatial]
//| inputs:
//|   angle_degrees: {"type":"range","label":"真の回転角 θ [deg]","description":"軸 (1, 2, 2)/3 のまわりの角。","min":0,"max":180,"step":15,"value":90}
//|   noise: {"type":"range","label":"ノイズの標準偏差 σ [m]","description":"各座標に加える正規ノイズ。","min":0.001,"max":0.2,"step":0.001,"value":0.02}
//|   point_count: {"type":"range","label":"点の数 n","description":"立方体の中の一様乱数の点。","min":4,"max":64,"step":4,"value":16}
//|   outlier: {"type":"range","label":"外れ値 o [m]","description":"点 0 の x 座標に加えるずれ。","min":0,"max":2,"step":0.1,"value":0.5}
//|   seed: {"type":"range","label":"乱数のシード","description":"点とノイズを作るシード。","min":1,"max":100,"step":1,"value":7}
//| cases:
//|   - {"id":"no-outlier","label":"o = 0","description":"外れ値がなければ、二つの推定の RMS 残差はどちらも期待値に近い。","inputs":{"outlier":0}}
//|   - {"id":"many-points","label":"n = 64, σ = 0.1 m","description":"点を増やすと、RMS 残差の期待値 σ√((3m − 6)/m) は √3 σ に近づく。","inputs":{"point_count":64,"noise":0.1}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"fits","path":"/rows/0/1","equals":3}
//|       - {"artifact":"fits","path":"/rows/0/7","range":{"min":0.05}}
//|       - {"artifact":"fits","path":"/rows/1/7","range":{"min":0.01,"max":0.04}}
//|       - {"artifact":"fits","path":"/rows/1/5","range":{"max":3}}
//|       - {"artifact":"fits","path":"/rows/1/8","approx":{"value":0.032249,"rtol":1e-4}}
//|   - case: no-outlier
//|     expect:
//|       - {"artifact":"fits","path":"/rows/0/7","range":{"min":0.01,"max":0.04}}
//|   - case: many-points
//|     expect:
//|       - {"artifact":"fits","path":"/rows/1/7","range":{"min":0.15,"max":0.2}}
use scioxide_core::RealScalar;
use scioxide_random::{Distribution, Normal, SeedableRng, SplitMix64, Uniform};
use scioxide_spatial::{
    PointSet, RigidEstimationOptions, RigidTransform, Rotation, estimate_rigid_transform,
    estimate_rigid_transform_with_options,
};

let n = point_count as usize;
let mut rng = SplitMix64::from_seed(seed as u64);
let cube = Uniform::new(-1.0_f64, 1.0).map_err(|e| e.to_string())?;
let normal = Normal::new(0.0, noise).map_err(|e| e.to_string())?;
let theta = RealScalar::to_radians(angle_degrees);
let rotation = Rotation::from_axis_angle([1.0, 2.0, 2.0], theta).map_err(|e| e.to_string())?;
let truth = RigidTransform::new(rotation, [10.0, 20.0, 30.0]).map_err(|e| e.to_string())?;
let mut source = Vec::with_capacity(n);
for _ in 0..n {
    let mut p = [0.0; 3];
    for x in &mut p {
        *x = cube.sample(&mut rng).map_err(|e| e.to_string())?;
    }
    source.push(p);
}
// 真の剛体変換で写し、正規ノイズと点 0 の外れ値を加える。
let mut target = Vec::with_capacity(n);
for p in &source {
    let mut q = truth.apply(*p).map_err(|e| e.to_string())?;
    for x in &mut q {
        *x += normal.sample(&mut rng).map_err(|e| e.to_string())?;
    }
    target.push(q);
}
target[0][0] += outlier;

// 一様の重み（既定の形）と、点 0 の重みを 0 にした推定（重みと選択肢を受け取る形）。
let source_points = PointSet::from_points(&source).map_err(|e| e.to_string())?;
let target_points = PointSet::from_points(&target).map_err(|e| e.to_string())?;
let mut weights = vec![1.0; n];
weights[0] = 0.0;
let uniform =
    estimate_rigid_transform(&source_points, &target_points).map_err(|e| e.to_string())?;
let weighted = estimate_rigid_transform_with_options(
    &source_points,
    &target_points,
    Some(&weights),
    RigidEstimationOptions::new(),
)
.map_err(|e| e.to_string())?;
// (重み, 推定, 重みが正の点の数)
let fits = [("一様", &uniform, n), ("点 0 の重みを 0", &weighted, n - 1)];
let mut rows = Vec::new();
for (label, result, active) in fits {
    let estimated = result.transform;
    // 真の回転との差の角 d(R_true, R) = ∠(R_true⁻¹ R) [rad]。
    let relative = truth
        .rotation()
        .inverse()
        .compose(estimated.rotation())
        .map_err(|e| e.to_string())?;
    let error = relative.as_axis_angle().1;
    let (shift, truth_shift) = (estimated.translation(), truth.translation());
    let gap = [0, 1, 2].map(|k| shift[k] - truth_shift[k]);
    let translation_error = RealScalar::hypot(RealScalar::hypot(gap[0], gap[1]), gap[2]);
    // ノイズだけのときの RMS 残差の期待値 σ √((3m − 6)/m)。
    let m = active as f64;
    let expected = noise * RealScalar::sqrt((3.0 * m - 6.0) / m);
    let s = result.singular_values;
    rows.push((
        label,
        result.rank,
        s[0],
        s[1],
        s[2],
        RealScalar::to_degrees(error),
        translation_error,
        result.rms_residual,
        expected,
    ));
}
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let fixed4 = serde_json::json!({ "significantDigits": 4 });
let columns = serde_json::json!([
    { "key": "0", "label": "重み" },
    { "key": "1", "label": "階数", "type": "integer" },
    { "key": "2", "label": "σ₁ [-]", "type": "number", "format": fixed4 },
    { "key": "3", "label": "σ₂ [-]", "type": "number", "format": fixed4 },
    { "key": "4", "label": "σ₃ [-]", "type": "number", "format": fixed4 },
    { "key": "5", "label": "回転の誤差 [deg]", "type": "number", "format": sci3 },
    { "key": "6", "label": "並進の誤差 [m]", "type": "number", "format": sci3 },
    { "key": "7", "label": "RMS 残差 [m]", "type": "number", "format": fixed4 },
    { "key": "8", "label": "ノイズだけの RMS の期待値 [m]", "type": "number", "format": fixed4 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "fits" })
);

// 元の点、目標の点、点 0 の重みを 0 にした推定で写した点（同じ単位 m）。
let mut points = Vec::new();
let mut edges = Vec::new();
for i in 0..n {
    let aligned = weighted
        .transform
        .apply(source[i])
        .map_err(|e| e.to_string())?;
    let groups = [
        ("source", source[i]),
        ("target", target[i]),
        ("aligned", aligned),
    ];
    for (group, position) in groups {
        points.push(serde_json::json!({
            "id": format!("{group}-{i}"),
            "position": position,
            "group": group
        }));
    }
    edges.push(
        serde_json::json!({ "from": format!("aligned-{i}"), "to": format!("target-{i}") }),
    );
}
emit_scene3d!(
    serde_json::json!({
        "points": points,
        "edges": edges,
        "groups": [
            { "id": "source", "label": "元の点 p" },
            { "id": "target", "label": "目標の点 q（ノイズと外れ値）" },
            { "id": "aligned", "label": "推定で写した点（点 0 の重み 0）" }
        ],
        "axes": {
            "x": { "label": "x", "unit": "m" },
            "y": { "label": "y", "unit": "m" },
            "z": { "label": "z", "unit": "m" }
        }
    }),
    metadata = serde_json::json!({ "id": "alignment", "title": "位置合わせの前と後" })
);
```

既定値（$\theta = 90°$、$\sigma = 0.02$ m、$n = 16$、$o = 0.5$ m、シード 7）では、一様の重みの RMS 残差は 0.119 m で、ノイズだけの期待値 0.0324 m の約 3.7 倍になる。
外れ値の 1 点が当てはめを引き寄せ、回転の誤差は 1.04°、並進の誤差は 0.036 m である。
点 0 の重みを 0 にすると、RMS 残差は 0.0331 m で期待値 0.0322 m に近づき、回転の誤差は 0.70°、並進の誤差は 0.0092 m に下がる。
外れ値を 0 にすると、一様の重みでも RMS 残差は 0.0328 m（期待値 0.0324 m）で、回転の誤差は 0.70° である。
RMS 残差が期待値を大きく上回るときは外れ値か対応の誤りが疑われ、重みを見直す手がかりになる。
$n = 64$、$\sigma = 0.1$ m では、点 0 の重みを 0 にした推定の RMS 残差は 0.180 m で、期待値 0.170 m に近い。
3 次元の図では、外れ値の点 0 だけが写した点から離れ、ほかの点は目標の点にほぼ重なる。

## まとめ

重み付きの剛体位置合わせでは、並進は重み付き重心を重ねるように決まり、回転は相互共分散 $H$ の SVD から $R = VU^\top$ として得られる。
$\det(VU^\top) = -1$ なら、最小の特異値の方向で鏡映を打ち消す。
`estimate_rigid_transform` は座標と重みを最大値で割り、中心化した点から $H$ を作るので、原点から遠い点群や大きな単位の座標でも桁落ちしない。
推定した行列は直交性の検査を通ってから回転になり、検査に落ちれば `NumericalInstability` を返す。
`rms_residual` をノイズの大きさと比べるときは、一様な重みで $\sigma\sqrt{(3m - 6)/m}$ を基準にし、それより大きければ外れ値や対応の誤りを疑って重みを見直す。
鏡像の点を与えても推定は回転に限られ、残差が 0 にならないことで鏡映に気づける。
