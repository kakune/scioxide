時刻とともに与えたキー姿勢をつなぐ姿勢の軌道は、宇宙機の姿勢変更、ロボットの手先の向き、コンピュータアニメーションのカメラの向きなどに使う。
[球面線形補間（Slerp）](oxref:spatial-slerp)は区間ごとに一定の角速度で回るが、節点で角速度が跳ぶ。
剛体をこの軌道に追従させると、節点でトルクの衝撃が要る。
このページでは、角速度と角加速度がどちらも連続になる `RotationSpline` を導き、Slerp と比べて、連続性の判定と反復の収束を数値で確かめる。

## 問題と記号

時刻 $t_0 < t_1 < \cdots < t_{n-1}$ に回転 $R_0, \ldots, R_{n-1}$ が与えられ、$\Delta t_i = t_{i+1} - t_i$ とする。
区間 $i$ の相対回転 $R_i^{-1}R_{i+1}$ の回転ベクトルを $v_i$（角 $\lvert v_i\rvert \le \pi$ の主値）と書く。
$\hat r$ はベクトル $r$ の外積行列（$\hat r\,x = r \times x$）、$\exp(\hat r)$ は軸 $r/\lvert r\rvert$ のまわりの角 $\lvert r\rvert$ の回転である。
姿勢 $R(t)$ の機体座標系の角速度 $\omega$ は $\dot R = R\,\hat\omega$ で定まり、角加速度は $\alpha = \dot\omega$ と書く。
回転の角、角速度、角加速度の単位は rad、rad/(時間の単位)、rad/(時間の単位)² とし、時間の単位には節点の時刻の単位を使う。

Slerp は $R(t) = R_i\exp(u\,\hat v_i)$（$u = (t - t_i)/\Delta t_i$）で、角速度は区間で一定の $v_i/\Delta t_i$ になる。
求めたいのは、すべての節点で与えた回転を通り、$\omega$ と $\alpha$ が $[t_0, t_{n-1}]$ 全体で連続な $R(t)$ である。
Euclid 空間の 3 次スプラインでは、節点の傾きを未知数にした三重対角の連立 1 次方程式から 2 階微分の連続性を得る。
回転スプラインはその $\mathrm{SO}(3)$ revision で、回転ベクトルの非線形性のために方程式が非線形になる。

## 区間ごとの 3 次の回転ベクトル

`RotationSpline` は、区間 $[t_i, t_{i+1}]$ で

$$
R(t) = R_i \exp\left(\widehat{r_i(u)}\right), \qquad r_i(u) = a_i u^3 + b_i u^2 + c_i u
$$

と表す。
$r_i(0) = 0$ と $r_i(1) = v_i$ により、節点では与えた回転を通る。
機体座標系の角速度は $\mathrm{SO}(3)$ の右ヤコビ行列

$$
J(r) = I - \frac{1 - \cos\lvert r\rvert}{\lvert r\rvert^2}\,\hat r + \frac{\lvert r\rvert - \sin\lvert r\rvert}{\lvert r\rvert^3}\,\hat r^2
$$

を使って $\omega = J(r)\,\dot r$ と書ける。
ここで $\dot r = r'(u)/\Delta t_i$ は時間微分で、$r'$ は $u$ についての微分である。
角加速度は

$$
\alpha = \dot\omega = J(r)\,\ddot r + \dot J(r)\,\dot r
$$

で、第 2 項は $\dot r$ について 2 次の非線形項である。
$J(r)$ と $\dot J(r)$ の係数は、$\lvert r\rvert \le 1$ では打ち切った Taylor 級数で、それより大きい角では三角関数で計算し、0 に近い角での桁落ちを避ける。
次の節で使う逆行列は、$\theta = \lvert r\rvert$ として

$$
J(r)^{-1} = I + \frac{1}{2}\hat r + \frac{1 - (\theta/2)\cot(\theta/2)}{\theta^2}\,\hat r^2
$$

である。
最後の係数も $\theta \to 0$ で桁落ちするので、$\theta < 0.1$ では Taylor 級数 $1/12 + \theta^2/720 + \theta^4/30240 + \theta^6/1209600$ で置き換える。

## Hermite 条件と角速度の連続性

節点 $t_i$ の角速度を $\omega_i$ とし、各区間の多項式を Hermite 条件

$$
r_i(0) = 0, \quad r_i(1) = v_i, \quad r_i'(0) = \Delta t_i\,\omega_i, \quad r_i'(1) = \Delta t_i\,J(v_i)^{-1}\omega_{i+1}
$$

で決める。
$J(0) = I$ なので区間の始点の角速度は $\omega_i$、終点の角速度は $J(v_i)\,J(v_i)^{-1}\omega_{i+1} = \omega_{i+1}$ になり、角速度は節点で自動的に連続になる。
3 次式を解くと、$c_i = \Delta t_i\,\omega_i$、$e_i = \Delta t_i\,J(v_i)^{-1}\omega_{i+1}$ として

$$
a_i = c_i + e_i - 2 v_i, \qquad b_i = 3 v_i - 2 c_i - e_i
$$

である。
両端の角速度は隣の区間の割線に固定する（$\omega_0 = v_0/\Delta t_0$、$\omega_{n-1} = v_{n-2}/\Delta t_{n-2}$）。
未知数は内部の節点の角速度 $\omega_1, \ldots, \omega_{n-2}$ である。

## 角加速度の連続条件とブロック三重対角系

内部の節点 $t_k$ で左の区間の終点と右の区間の始点の角加速度を等しくする。
$J(v)v = v$ と $\dot J(0)\,\dot r = 0$ を使って上の係数を代入すると、各 $k = 1, \ldots, n-2$ について

$$
\frac{2}{\Delta t_{k-1}} J(v_{k-1})\,\omega_{k-1} + 4\left(\frac{1}{\Delta t_{k-1}} + \frac{1}{\Delta t_k}\right)\omega_k + \frac{2}{\Delta t_k} J(v_k)^{-1}\omega_{k+1}
= \frac{6 v_{k-1}}{\Delta t_{k-1}^2} + \frac{6 v_k}{\Delta t_k^2} - N_{k-1}(\omega_k)
$$

を得る。
$N_{k-1}(\omega_k) = \dot J\,\dot r$ は左の区間の終点での非線形項で、$\omega_k$ に依存する。
左辺は 3×3 のブロックを持つ三重対角の線形系で、係数は節点の時刻と回転だけで決まる。

$J(v)$ の特異値は回転軸の方向で 1、それに垂直な面で $2\sin(\lvert v\rvert/2)/\lvert v\rvert \le 1$ である。
したがって $\lVert J(v)\rVert_2 \le 1$、$\lVert J(v)^{-1}\rVert_2 = \lvert v\rvert/(2\sin(\lvert v\rvert/2)) \le \pi/2$（$\lvert v\rvert \le \pi$）で、対角ブロックの $4(1/\Delta t_{k-1} + 1/\Delta t_k)$ は非対角ブロックのノルムの和 $2/\Delta t_{k-1} + \pi/\Delta t_k$ より大きい。
この線形系はブロック対角優位なので正則で、ブロックの間で行を入れ替えないブロック Thomas 法（ブロック LU 分解）で安定に解ける（Golub & Van Loan 2013、§4.5）。
消去の途中に現れる 3×3 の対角ブロックは、行と列を 2 のべきで尺度調整してから、部分ピボット選択付きの LU 分解で分解する。
ピボットがちょうど 0 になれば `Singular` を返す。

スプラインの準備（`RotationSpline::new`、`with_options`、`build`）は次の順に進む。

1. 初期値として、各内部節点の角速度をその節点に入る区間の割線 $v_{k-1}/\Delta t_{k-1}$ にする。
   この初期値で係数を作り、角加速度の跳びがすでに許容誤差を満たせば反復せずに止める。
2. 線形部分を一度だけ分解する。
3. 現在の $\omega_k$ で非線形項 $N_{k-1}(\omega_k)$ を評価し、右辺を作る。
4. 分解済みの線形系を前進消去と後退代入で解き、内部の角速度を更新して係数を作り直す。
5. 各内部節点で角加速度の跳びを測り、すべてが許容誤差を満たせば止める。
   満たさず、反復の上限にも達していなければ手順 3 に戻る。

1 回の反復は節点数 $n$ に比例する計算で、メモリ使用量も $O(n)$ である。
この反復が縮小写像であることは示されておらず、収束は保証されない。
非線形項はキーの間の回転角とともに大きくなり、角が大きいほど反復の回数が増える。

## 終了状態と連続性の残差

連続性は各内部節点の角加速度の跳び $\lvert\alpha(t_k^+) - \alpha(t_k^-)\rvert$（Euclid ノルム）で測る。
跳びが $\mathrm{atol} + \mathrm{rtol}\cdot s_k$ 以下ならその節点を受け入れる。
尺度 $s_k$ は左右の角加速度の大きさと、左右の区間で桁落ちの前の項の大きさ（$6\lvert v\rvert + 4\lvert c\rvert + 4\lvert e\rvert$ を $\Delta t^2$ で割った値）のうち最大のものである。
角速度がほぼ一定のときは角加速度そのものが打ち消し合って 0 に近くなり、丸めのノイズの尺度にならないので、後者を加えている。
`RotationSplineOptions::new()` の既定は反復の上限 32 回、$\mathrm{rtol} = \sqrt{\varepsilon}$、$\mathrm{atol} = 0$ である。
$\mathrm{atol}$ は rad/(時間の単位)² の量なので、既定では 0 にして、受け入れが時間の単位によらないようにしている。
時間の単位を変えると跳びも $s_k$ も同じ倍率で変わるので、相対の判定は変わらない。
`with_max_iterations` と `with_continuity_tolerance` で変えられる。
上限を 0 にすると、割線による初期値がすでに連続な場合だけ成功する。
節点が 2 つなら内部節点がないので、反復なしで `Converged` になる。

`RotationSpline::with_options(times, rotations, options)` と、実行コンテキストか求解コンテキストも受け取る `RotationSpline::build(times, rotations, options, cx)` は、結果を `RotationSplineResult` で返す。
`RotationSplineResult` は次のフィールドを持つ。

| フィールド | 内容 |
|---|---|
| `termination` | `RotationSplineTermination::Converged`（すべての内部節点で許容誤差を満たした）または `IterationLimit`（上限に先に達した） |
| `spline` | `Converged` のときだけ `Some(RotationSpline)`。`IterationLimit` ではスプラインを返さない |
| `iterations` | 行った不動点反復の回数 |
| `continuity_residual` | 内部節点での角加速度の跳びの最大値 [rad/(時間の単位)²]。節点が 2 つなら 0 |

`with_options` と `build` は `IterationLimit` をエラーにせず、終了状態として返す。
`RotationSpline::new(times, rotations)` は既定の選択肢で準備してスプラインそのものを返し、`IterationLimit` を `ConvergenceFailure` のエラーとして返す。
連続性は許容誤差の範囲で成り立つ性質で、スプラインが返されたときだけ成り立つ。
節点の検査は `Slerp::new` と同じで、線形系が特異なら `Singular`、途中の値が表せなければ `NumericalInstability`、`build` に渡したコンテキストの取り消しや期限で `ExecutionStopped` を返す。
`with_options` は取り消しのない逐次の実行コンテキストで `build` を呼ぶ。
`build` に求解コンテキスト（solve context）を渡すと、スプラインの準備はその中の入れ子の求解になり、不動点反復は外側の求解に入れ子の反復として記録される。
入れ子の反復は外側の求解の上限には数えないので、反復の上限は `max_iterations` だけで決まる（[入れ子の求解と回数の集計](oxref:core-nested-accounting)）。

`spline.evaluate(t)` は `RotationSplineSample` を返し、`rotation` に回転、`angular_velocity` に機体座標系の角速度 [rad/(時間の単位)]、`angular_acceleration` に角加速度 [rad/(時間の単位)²] が入る。
節点の時刻では与えた回転をそのまま返し、そこでの角速度と角加速度は右の区間（最後の節点では左の区間）の値である。
区間の外の時刻は `InvalidInput`、NaN や無限大の時刻は `NonFinite`、導関数が表せなければ `NumericalInstability` になる。
評価は $O(\log n)$ でメモリ領域を確保しない。
多数の時刻で回転だけが必要なときは、確保して返す `evaluate_rotations(&times)` か、事前確保した作業領域に書く `evaluate_rotations_into` を使う。
作業領域は[一括評価と作業領域](oxref:spatial-rotation-batches)のとおりに事前確保する。

## 比べるキー姿勢

このページの 3 つのセルは時刻 $t_i = i$ s（$i = 0, \ldots, 4$）に 5 つのキー姿勢（恒等回転、$x$ 軸・$y$ 軸・$z$ 軸まわりの角 $\theta$ の回転、恒等回転）を置く。
相対回転の軸が区間ごとに変わるので、Slerp の角速度は節点で向きも変える。
定義のブロックでは、`KEY_TIMES` が時刻、`key_rotations` がこの姿勢、`norm3` が 3 成分のベクトルの Euclid ノルムを与える。

```rust
//| id: spatial-rotation-keyframes
//| kind: definitions
//| title: 回転スプラインの比較に使うキー姿勢
//| crates: [scioxide-core, scioxide-spatial]
use scioxide_core::{SciOxideError, RealScalar};
use scioxide_spatial::Rotation;

/// キーの時刻 t_i = i [s]。
pub(crate) const KEY_TIMES: [f64; 5] = [0.0, 1.0, 2.0, 3.0, 4.0];

/// 恒等回転、x・y・z 軸まわりの角 theta [rad] の回転、恒等回転。
pub(crate) fn key_rotations(theta: f64) -> Result<[Rotation<f64>; 5], SciOxideError> {
    Ok([
        Rotation::identity(),
        Rotation::from_axis_angle([1.0, 0.0, 0.0], theta)?,
        Rotation::from_axis_angle([0.0, 1.0, 0.0], theta)?,
        Rotation::from_axis_angle([0.0, 0.0, 1.0], theta)?,
        Rotation::identity(),
    ])
}

/// 3 成分のベクトルの Euclid ノルム。
pub(crate) fn norm3(v: [f64; 3]) -> f64 {
    RealScalar::hypot(RealScalar::hypot(v[0], v[1]), v[2])
}
```

## 角速度と角加速度の比較

次のセルはキーの回転角 $\theta$ と反復の上限を入力に取り、`RotationSpline::build` でスプラインを作る。
Slerp の区間ごとの角速度は相対回転から $v_i/\Delta t_i$ として求める。
表 `knots` は内部の節点ごとに、Slerp の角速度の跳び $\lvert v_k/\Delta t_k - v_{k-1}/\Delta t_{k-1}\rvert$ と、スプラインの角速度と角加速度の跳びを示す。
スプラインの跳びは左極限と `evaluate(t_k)` の値（右の区間の始点）の差である。
左極限は節点の左側の 3 点 $t_k - jh$（$j = 1, 2, 3$、$h = 10^{-3}$ s）から 2 次の外挿 $3f(t_k - h) - 3f(t_k - 2h) + f(t_k - 3h)$ で求め、打ち切り誤差は $O(h^3)$ である。
この差は `build` の残差とは別の方法で連続性を確かめる検算になる。
最後に、終了状態を outcome で示す。
角速度と角加速度の時間変化は、このセルが渡す値から次のセルで描く。

```rust
//| id: spatial-rotation-spline-interpolation
//| ref: spatial-rotation-spline-interpolation
//| title: Slerp と回転スプラインの角速度・角加速度を比べる
//| run: reactive
//| uses: [spatial-rotation-keyframes]
//| crates: [scioxide-core, scioxide-spatial]
//| exports: [slerp_curve, speed, acceleration]
//| inputs:
//|   key_angle: {"type":"range","label":"キーの回転角 θ [deg]","description":"x・y・z 軸まわりのキー姿勢の角。","min":15,"max":150,"step":15,"value":60}
//|   max_iterations: {"type":"range","label":"不動点反復の上限 [回]","description":"既定は 32 回。","min":0,"max":32,"step":1,"value":32}
//| cases:
//|   - {"id":"large-angle","label":"θ = 150°","description":"キーの間の回転が大きく、角速度の跳びと反復の回数が増える。","inputs":{"key_angle":150}}
//|   - {"id":"one-iteration","label":"反復の上限 1 回","description":"1 回の反復では連続性の許容誤差に届かず、IterationLimit でスプラインが返らない。","inputs":{"max_iterations":1}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"knots","path":"/rows/0/1","range":{"min":0.5}}
//|       - {"artifact":"knots","path":"/rows/0/2","range":{"max":1e-6}}
//|       - {"artifact":"knots","path":"/rows/0/3","range":{"max":1e-5}}
//|       - {"path":"/outputs/1/state","equals":"satisfied"}
//|   - case: large-angle
//|     expect:
//|       - {"artifact":"knots","path":"/rows/0/1","range":{"min":4.0}}
//|       - {"path":"/outputs/1/state","equals":"satisfied"}
//|   - case: one-iteration
//|     expect:
//|       - {"artifact":"knots","path":"/rows/0/2","equals":null}
//|       - {"path":"/outputs/1/state","equals":"failed"}
use scioxide_core::{ExecutionContext, RealScalar};
use scioxide_spatial::{
    RotationSpline, RotationSplineOptions, RotationSplineSample, RotationSplineTermination,
};

let theta = RealScalar::to_radians(key_angle);
let rotations = key_rotations(theta).map_err(|e| e.to_string())?;
let options = RotationSplineOptions::new().with_max_iterations(max_iterations as usize);
let result = RotationSpline::build(
    &KEY_TIMES,
    &rotations,
    options,
    ExecutionContext::sequential(),
)
.map_err(|e| e.to_string())?;

// Slerp の区間 i の角速度 v_i / Δt_i（v_i は R_i⁻¹ R_{i+1} の回転ベクトル）。
let mut slerp_rates = Vec::new();
for (pair, step) in rotations.windows(2).zip(KEY_TIMES.windows(2)) {
    let relative = pair[0]
        .inverse()
        .compose(pair[1])
        .map_err(|e| e.to_string())?;
    slerp_rates.push(
        relative
            .as_rotation_vector()
            .map(|x| x / (step[1] - step[0])),
    );
}
let mut slerp_curve = Vec::new();
for (i, rate) in slerp_rates.iter().enumerate() {
    slerp_curve.push([KEY_TIMES[i], norm3(*rate)]);
    slerp_curve.push([KEY_TIMES[i + 1], norm3(*rate)]);
}

// スプラインの角速度と角加速度を 0.01 s ごとに評価する。
let (mut speed, mut acceleration) = (Vec::new(), Vec::new());
if let Some(spline) = &result.spline {
    for j in 0..=400 {
        let t = 0.01 * f64::from(j);
        let sample = spline.evaluate(t).map_err(|e| e.to_string())?;
        speed.push([t, norm3(sample.angular_velocity)]);
        acceleration.push([t, norm3(sample.angular_acceleration)]);
    }
}

// 節点の左極限: 3f(t − h) − 3f(t − 2h) + f(t − 3h)（2 次の外挿、誤差 O(h³)）。
let h = 1e-3;
let left_limit = |spline: &RotationSpline<f64>, t: f64| -> Result<[[f64; 3]; 2], String> {
    let at = |j: f64| -> Result<RotationSplineSample<f64>, String> {
        spline.evaluate(t - j * h).map_err(|e| e.to_string())
    };
    let (s1, s2, s3) = (at(1.0)?, at(2.0)?, at(3.0)?);
    let extrapolate = |a: [f64; 3], b: [f64; 3], c: [f64; 3]| {
        [0, 1, 2].map(|m| 3.0 * a[m] - 3.0 * b[m] + c[m])
    };
    Ok([
        extrapolate(
            s1.angular_velocity,
            s2.angular_velocity,
            s3.angular_velocity,
        ),
        extrapolate(
            s1.angular_acceleration,
            s2.angular_acceleration,
            s3.angular_acceleration,
        ),
    ])
};
let difference = |a: [f64; 3], b: [f64; 3]| norm3([a[0] - b[0], a[1] - b[1], a[2] - b[2]]);
let mut rows: Vec<(f64, f64, Option<f64>, Option<f64>)> = Vec::new();
for k in 1..KEY_TIMES.len() - 1 {
    let slerp_jump = difference(slerp_rates[k], slerp_rates[k - 1]);
    let (mut velocity_jump, mut acceleration_jump) = (None, None);
    if let Some(spline) = &result.spline {
        let [velocity, accel] = left_limit(spline, KEY_TIMES[k])?;
        let right = spline.evaluate(KEY_TIMES[k]).map_err(|e| e.to_string())?;
        velocity_jump = Some(difference(right.angular_velocity, velocity));
        acceleration_jump = Some(difference(right.angular_acceleration, accel));
    }
    rows.push((KEY_TIMES[k], slerp_jump, velocity_jump, acceleration_jump));
}

// 図は次のセルで描く。スプラインが返されなかったときは空の列を渡す。
export!(slerp_curve, slerp_curve);
export!(speed, speed);
export!(acceleration, acceleration);
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let columns = serde_json::json!([
    { "key": "0", "label": "節点 t_k [s]", "type": "number", "format": { "fractionDigits": 0 } },
    { "key": "1", "label": "Slerp の |Δω| [rad/s]", "type": "number", "format": sci3 },
    {
        "key": "2",
        "label": "スプラインの |Δω| [rad/s]",
        "type": "number",
        "format": sci3,
        "nullText": "スプラインなし"
    },
    {
        "key": "3",
        "label": "スプラインの |Δα| [rad/s²]",
        "type": "number",
        "format": sci3,
        "nullText": "スプラインなし"
    }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "knots" })
);

let outcome = match result.termination {
    RotationSplineTermination::Converged => {
        Outcome::satisfied("すべての内部節点で角加速度の跳びが連続性の許容誤差を満たした")
    }
    RotationSplineTermination::IterationLimit => Outcome::failed(
        "反復の上限までに角加速度の跳びが許容誤差に届かず、スプラインは返されない",
    )
    .explanation("反復の上限を上げるか、キーの間の回転角を小さくする。"),
};
emit_outcome!(
    outcome
        .status(format!("{:?}", result.termination))
        .diagnostic("不動点反復の回数", result.iterations as f64, None)
        .diagnostic("連続性の残差", result.continuity_residual, Some("rad/s²"))
);
```

既定値（$\theta = 60°$）では、`build` は 6 回の不動点反復で `Converged` になり、連続性の残差は $2.1 \times 10^{-7}$ rad/s² である。
Slerp の内部の節点では角速度ベクトルが 2.27〜2.44 rad/s 跳ぶ。
外挿で求めたスプラインの節点の跳びは、角速度で $2.2 \times 10^{-8}$ rad/s 以下、角加速度で $1.8 \times 10^{-7}$ rad/s² 以下で、`build` の残差と同じ桁である。
角速度の跳びが 0 にならないのは、外挿の打ち切り誤差による。

「θ = 150°」では反復が 16 回に増え、残差は $5.5 \times 10^{-7}$ rad/s²、Slerp の角速度の跳びは 4.4〜4.5 rad/s である。
「反復の上限 1 回」では残差 0.31 rad/s² で `IterationLimit` になる。
スプラインは返されないので、outcome は `failed` になり、表のスプラインの列は「スプラインなし」になる。

次のセルは、前のセルが渡す曲線を 2 つのグラフに描く。
上のグラフは角速度の大きさ $\lvert\omega\rvert(t)$ [rad/s]、下のグラフはスプラインの角加速度の大きさ $\lvert\alpha\rvert(t)$ [rad/s²] で、横軸の時刻は連動し、縦線が内部の節点である。
Slerp の角速度は相対回転の角を $\Delta t$ で割った値で、角加速度は区間の中で 0 なので下のグラフには描かない。
スプラインが返されなかったときは、上のグラフに Slerp だけを描き、下のグラフは描かない。

## 不動点反復の収束

次のセルは、同じキー姿勢で反復の上限 $m$ を 0 から 1 ずつ増やして `build` を呼び、各 $m$ の終了状態と `continuity_residual` を記録する。
反復は決定論的なので、上限 $m$ で止めたときの残差は、$m$ 回目の反復の後の残差である。
`Converged` になった $m$ で止める。
表 `history` は $m$、終了状態、残差と、一つ前の残差との比を示し、グラフは残差を対数軸で描く。
比がほぼ一定なら、不動点反復は 1 次収束していて、その比が縮小率の推定値になる。

```rust
//| id: spatial-rotation-spline-convergence
//| ref: spatial-rotation-spline-convergence
//| title: 回転スプラインの不動点反復で連続性の残差が減る速さを測る
//| run: reactive
//| uses: [spatial-rotation-keyframes]
//| crates: [scioxide-core, scioxide-spatial]
//| inputs:
//|   history_angle: {"type":"range","label":"キーの回転角 θ [deg]","description":"角が大きいほど非線形項が大きい。","min":15,"max":150,"step":15,"value":60}
//| cases:
//|   - {"id":"small-angle","label":"θ = 15°","description":"非線形項が小さく、少ない反復で連続になる。","inputs":{"history_angle":15}}
//|   - {"id":"large-angle","label":"θ = 150°","description":"残差の比が 0.2〜0.6 に大きくなり、反復の回数が増える。","inputs":{"history_angle":150}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"history","path":"/rows/0/1","equals":"IterationLimit"}
//|       - {"artifact":"history","path":"/rows/0/2","approx":{"value":9.0932,"rtol":1e-4}}
//|       - {"artifact":"history","path":"/rows/0/3","equals":null}
//|       - {"artifact":"history","path":"/rows/1/3","range":{"min":0.01,"max":0.1}}
//|       - {"artifact":"history","path":"/rows/6/1","equals":"Converged"}
//|       - {"artifact":"history","path":"/rows/6/2","range":{"max":1e-6}}
//|   - case: small-angle
//|     expect:
//|       - {"artifact":"history","path":"/rows/0/1","equals":"IterationLimit"}
//|       - {"artifact":"history","path":"/rows/1/3","range":{"max":0.01}}
//|       - {"artifact":"history","path":"/rows/3/1","equals":"Converged"}
//|   - case: large-angle
//|     expect:
//|       - {"artifact":"history","path":"/rows/0/1","equals":"IterationLimit"}
//|       - {"artifact":"history","path":"/rows/1/3","range":{"min":0.1,"max":0.9}}
//|       - {"artifact":"history","path":"/rows/16/1","equals":"Converged"}
use scioxide_core::{ExecutionContext, RealScalar};
use scioxide_spatial::{RotationSpline, RotationSplineOptions, RotationSplineTermination};

let rotations =
    key_rotations(RealScalar::to_radians(history_angle)).map_err(|e| e.to_string())?;
let mut rows: Vec<(usize, String, f64, Option<f64>)> = Vec::new();
let mut curve = Vec::new();
let mut previous: Option<f64> = None;
for limit in 0..=32 {
    let options = RotationSplineOptions::new().with_max_iterations(limit);
    let result = RotationSpline::build(
        &KEY_TIMES,
        &rotations,
        options,
        ExecutionContext::sequential(),
    )
    .map_err(|e| e.to_string())?;
    let residual = result.continuity_residual;
    let ratio = previous.filter(|&p| p > 0.0).map(|p| residual / p);
    rows.push((limit, format!("{:?}", result.termination), residual, ratio));
    if residual > 0.0 {
        curve.push([limit as f64, residual]);
    }
    previous = Some(residual);
    if result.termination == RotationSplineTermination::Converged {
        break;
    }
}
emit_chart!(serde_json::json!({
    "kind": "xy",
    "dataZoom": true,
    "tooltip": true,
    "xLabel": "反復の上限 m [回]",
    "yLabel": "連続性の残差 [rad/s²]",
    "yType": "log",
    "layers": [{
        "id": "residual",
        "kind": "line",
        "name": "角加速度の跳びの最大値",
        "points": curve,
        "style": { "showSymbol": true }
    }]
}));
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let columns = serde_json::json!([
    { "key": "0", "label": "反復の上限 m [回]", "type": "integer" },
    { "key": "1", "label": "終了状態" },
    { "key": "2", "label": "連続性の残差 [rad/s²]", "type": "number", "format": sci3 },
    {
        "key": "3",
        "label": "前の残差との比 [-]",
        "type": "number",
        "format": { "significantDigits": 3 },
        "nullText": "—"
    }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "history" })
);
```

既定値（$\theta = 60°$）では、残差は $m = 0$（割線による初期値）の 9.09 rad/s² から、0.31、0.015、$8.5 \times 10^{-4}$、$5.8 \times 10^{-5}$、$2.4 \times 10^{-6}$ と減り、$m = 6$ の $2.1 \times 10^{-7}$ rad/s² で `Converged` になる。
前の残差との比は 0.03〜0.09 で、反復は 1 次収束している。
$\theta = 15°$ では比が 0.002〜0.004 で、$m = 3$ で収束する。
$\theta = 150°$ では比が 0.2〜0.57 のあいだで交互に変わり、$m = 16$ まで要する。
この 3 つの角では、比はおよそ $\theta^2$ に比例して大きくなった。
キーの間の回転が大きいほど非線形項が大きく、上限 32 回で収束しないこともありうるので、そのときはキー姿勢を細かく置く。

## まとめ

`RotationSpline` は区間ごとの回転ベクトルを 3 次式にし、Hermite 条件で角速度を節点で連続にし、角加速度の連続性を内部の節点の角速度についての方程式として解く。
方程式の線形部分はブロック対角優位なブロック三重対角系で、一度だけ分解し、非線形項は不動点反復で右辺に取り込む。
受け入れは各内部節点の角加速度の跳びを尺度付きの相対許容誤差（既定 $\sqrt\varepsilon$）と比べて行い、満たせば `Converged` でスプラインを返し、反復の上限に先に達すれば `IterationLimit` でスプラインを返さない。
反復の縮小率はキーの間の回転角とともに大きくなるので、`IterationLimit` になったら上限を上げるか、キー姿勢を細かく置く。
端点の角速度は隣の区間の割線に固定され、端点の角加速度は 0 にならないので、静止から始めて静止で終える軌道にはそのままでは使えない。
