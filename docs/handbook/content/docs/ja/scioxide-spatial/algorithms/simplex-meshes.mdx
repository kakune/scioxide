有限要素法や有限体積法で曲がった境界や複雑な形の領域を扱うときは、構造格子の代わりに、区間・三角形・四面体を並べた単体メッシュを使う。
単体メッシュでは接続を入力の頂点番号で与えるので、向きの逆転、退化したセル、重なった面のような誤りが入力に入りうる。
誤った向きは面の流束の符号を反転させ、退化したセルは要素の写像の行列式を 0 にするので、離散化を組む前に見つけておく必要がある。
このページは、`SimplexMesh` が構築時に確かめる向きと接続の条件、面と辺の番号と向きの符号、境界タグ、区間メッシュの扱いを説明する。
点の型、場の位置、メッシュのトークンは[点・範囲・格子・メッシュの基礎](../geometry-grids-and-meshes/)で扱う。

## 単体メッシュの向きと境界タグ

`SimplexMesh<S, D>` は区間・三角形・四面体のメッシュで、別名を `IntervalMesh`、`TriangleMesh`、`TetrahedronMesh` という。
各セルは $D + 1$ 個の頂点番号で与え、正の向きでなければならない。
区間 $[a, b]$ は $x_a < x_b$、三角形 $[a, b, c]$ は反時計回りで `orient2d(a, b, c)` が `Positive` になる向き、四面体 $[a, b, c, d]$ は $\det(b - a, c - a, d - a) > 0$ の向きである。
四面体のこの向きは `orient3d(a, b, c, d)` が `Negative` になる向きにあたる（符号の規約は[厳密な幾何述語](../exact-predicates/)で説明する）。
向きは丸めた面積や体積ではなく厳密な述語の符号で判定するので、退化（面積 0）と時計回りを丸め誤差で取り違えない。

構築（`TriangleMesh::new(points, cells)` など）は次を確かめ、満たさなければ `InvalidInput` を返す。
`from_coordinates(&coordinates, cells)` は `Point` の代わりに `[S; D]` の座標の列を受け取り、非有限な座標を `NonFinite` で拒んでから同じ検査をする。

- 各セルの頂点が相異なり、向きが正であること。
- 同じセルが 2 度現れないこと（頂点の並びが違っても、頂点の集合が同じなら同じセルとみなす）。
- 1 つの面を共有するセルが 2 つまでで、その 2 つが面を互いに逆向きに使うこと。
- 使われない頂点がなく、各頂点のまわりのセルが多様体をなすこと（2 次元なら頂点のまわりのセルが 1 つの円板か扇形をなす）。
  3 次元では各辺のまわりのセルも、辺を一周する輪か、境界から境界へ続く 1 列でなければならない。

存在しない頂点番号は `OutOfBounds` になる。
大域的な埋め込みは調べないので、内部の頂点のまわりを 2 周する扇のように自分自身に重なるメッシュも受理され、そのセルの測度の和は重なった面積を数える。

頂点とセルは入力の順序のまま保たれ、面と辺は構築時に番号が付き、頂点番号の昇順で保存される。
`cell_faces(c)` はセル $c$ の面を `OrientedEntity` の列で返し、第 $i$ 面は局所頂点 $i$ の向かいの面である。
`OrientedEntity` は面の番号 `index()` と符号 `sign()` を持ち、セルから誘導される面の向きが昇順の向きと一致すれば $+1$、逆なら $-1$ である。
内部の面は 2 つのセルから逆の向きで使われるので、2 つの符号の和は 0 になる。
この符号は有限体積法で面の流束を両側のセルへ逆符号で配るときや、接続行列（離散的な境界作用素）を組むときにそのまま使える。
`cell_edges` は局所頂点の対 $(0, 1), (0, 2), \ldots$ の順に辺を返し、`face_cells`、`edge_cells`、`vertex_cells` は接するセルを昇順で返す。
接続は構築時に表として保存されるので、各問い合わせは結果 1 件あたり $O(1)$ である。

`boundary_faces()` は 1 つのセルにだけ属する面を昇順で返す。
`SimplexBoundaryTags::new(&mesh, pairs)` は境界の面に `u32` のタグを付け、境界条件を面の集まりごとに選べるようにする。
タグの値に特別な意味はなく（0 も普通の値）、タグのない境界の面も許される。
内部の面や重複した面にタグを付けると `InvalidInput`、範囲外の面は `OutOfBounds` になる。
`tag(&mesh, face)` は二分探索で $t$ 個のタグから $O(\log t)$ で引き、タグを作ったときと別の revision のメッシュ（`with_points` で世代が進んだものや、同じ親から別に作った兄弟の revision を含む）を渡すと `InvalidInput` を返す。

三角形と四面体の `cell_measure` は、辺ベクトルの行列式を厳密に累積してから 1 回だけ丸め、三角形では 2、四面体では 6 で割る。
座標の差を丸めてから掛け合わせないので、細いセルでも打ち消しで面積や体積の桁を失わない。
`f64` の三角形の面積は非正規化数にならない限り正しく丸めた値で、四面体の体積には 6 で割るときの丸めがもう 1 回加わる。
区間の長さは座標の差を丸めた値である。
測度がスカラー型で表せない（桁あふれする、または 0 に丸まる）ときは `NumericalInstability` になる。

`with_points` は接続を保って座標だけを替え、各セルの向きだけを調べ直して世代を 1 つ進める。
点の数が変われば `DimensionMismatch`、座標が変わらなければ同じトークンの複製を返す。
`with_cells` は座標を保って接続を替え、構築と同じ検査をやり直して世代を 1 つ進める。

次のセルは頂点 $0 = (0, 0)$、$1 = (1, 0)$、$2 = (1, 1)$、$3 = (t, 1)$ [m] と三角形 $[0, 1, 2]$、$[0, 2, 3]$ からなるメッシュを作る。
入力 $t$ を 1 に近づけると、三角形 $[0, 2, 3]$ の面積 $(1 - t)/2$ が 0 に近づき、$t = 1$ で退化、$t > 1$ で時計回りになる。
1 つ目の表は $[0, 2, 3]$ の `orient2d` の符号と、手で求めた符号付き面積 $(1 - t)/2$（独立な検算）を並べ、構築の結果と面積の和を閉形式 $1 - t/2$ と比べる。
符号付き面積の符号は `orient2d` の符号と一致するはずである。
構築が受理されたとき、2 つ目の表は各面（辺）の頂点、接するセル、各セルから見た符号、境界かどうか、タグを示す。
タグは底辺 $0$–$1$ に 1、ほかの境界の辺に 2 を付ける。
3 つ目の表は $t$ によらない固定の正方形 $(0, 0), (1, 0), (1, 1), (0, 1)$ で、接続を 1 つずつ壊した入力とその結果を示す。

```rust
//| id: spatial-simplex-mesh-orientation
//| ref: spatial-simplex-mesh-orientation
//| title: 三角形メッシュの向き、面の符号、境界タグ、拒まれる接続
//| run: reactive
//| crates: [scioxide-core, scioxide-spatial]
//| inputs:
//|   apex_x: {"type":"range","label":"頂点 3 の x 座標 t [m]","min":-1,"max":1.5,"step":0.25,"value":0}
//| cases:
//|   - {"id":"degenerate","label":"t = 1（退化）","description":"頂点 0、2、3 が同一直線上にあり、orient2d が Zero、構築が InvalidInput になる。","inputs":{"apex_x":1}}
//|   - {"id":"clockwise","label":"t = 1.5（時計回り）","description":"三角形 [0, 2, 3] が時計回りになり、構築が InvalidInput になる。","inputs":{"apex_x":1.5}}
//|   - {"id":"wide","label":"t = −1","description":"面積の和は 1.5 m² に増え、接続と符号は変わらない。","inputs":{"apex_x":-1}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"construction","path":"/rows/0/0","equals":"Positive"}
//|       - {"artifact":"construction","path":"/rows/0/1","approx":{"value":0.5,"atol":1e-15}}
//|       - {"artifact":"construction","path":"/rows/0/3","approx":{"value":1.0,"atol":1e-15}}
//|       - {"artifact":"faces","path":"/rows/1/2","equals":-1}
//|       - {"artifact":"faces","path":"/rows/1/3","equals":1}
//|       - {"artifact":"faces","path":"/rows/1/5","equals":null}
//|       - {"artifact":"faces","path":"/rows/0/5","equals":1}
//|       - {"artifact":"rejected","path":"/rows/0/1","equals":"InvalidInput"}
//|       - {"artifact":"rejected","path":"/rows/2/1","equals":"OutOfBounds"}
//|       - {"artifact":"rejected","path":"/rows/3/1","equals":"InvalidInput"}
//|   - case: degenerate
//|     expect:
//|       - {"artifact":"construction","path":"/rows/0/0","equals":"Zero"}
//|       - {"artifact":"construction","path":"/rows/0/1","approx":{"value":0.0,"atol":1e-15}}
//|       - {"artifact":"construction","path":"/rows/0/2","equals":"InvalidInput"}
//|       - {"artifact":"construction","path":"/rows/0/3","equals":null}
//|   - case: clockwise
//|     expect:
//|       - {"artifact":"construction","path":"/rows/0/0","equals":"Negative"}
//|       - {"artifact":"construction","path":"/rows/0/1","approx":{"value":-0.25,"atol":1e-15}}
//|       - {"artifact":"construction","path":"/rows/0/2","equals":"InvalidInput"}
//|   - case: wide
//|     expect:
//|       - {"artifact":"construction","path":"/rows/0/1","approx":{"value":1.0,"atol":1e-15}}
//|       - {"artifact":"construction","path":"/rows/0/3","approx":{"value":1.5,"atol":1e-15}}
//|       - {"artifact":"faces","path":"/rows/1/2","equals":-1}
use scioxide_spatial::{Point, SimplexBoundaryTags, TriangleMesh, orient2d};

let corners = [[0.0, 0.0], [1.0, 0.0], [1.0, 1.0], [apex_x, 1.0]];
let points: Vec<Point<f64, 2>> = corners
    .iter()
    .map(|&c| Point::new(c))
    .collect::<Result<_, _>>()
    .map_err(|e| e.to_string())?;
let sign = orient2d(&corners[0], &corners[2], &corners[3]).map_err(|e| e.to_string())?;
let built = TriangleMesh::new(points, vec![[0, 1, 2], [0, 2, 3]]);
let (result, area) = match &built {
    Ok(mesh) => {
        let total = (0..mesh.cell_count())
            .map(|c| mesh.cell_measure(c))
            .sum::<Result<f64, _>>()
            .map_err(|e| e.to_string())?;
        ("受理".to_string(), Some(total))
    }
    Err(error) => (format!("{:?}", error.kind()), None),
};
// 独立な検算: 三角形 [0, 2, 3] の符号付き面積 (1 − t)/2 と、受理されるときの面積の和 1 − t/2。
let signed_area = 0.5 * (1.0 - apex_x);
let exact_area = (apex_x < 1.0).then(|| 1.0 - 0.5 * apex_x);
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let fixed4 = serde_json::json!({ "fractionDigits": 4 });
let columns = serde_json::json!([
    { "key": "0", "label": "[0, 2, 3] の orient2d" },
    { "key": "1", "label": "符号付き面積 (1 − t)/2 [m²]", "type": "number", "format": fixed4 },
    { "key": "2", "label": "構築の結果" },
    { "key": "3", "label": "面積の和 [m²]", "type": "number", "format": fixed4, "nullText": "—" },
    { "key": "4", "label": "閉形式 [m²]", "type": "number", "format": fixed4, "nullText": "—" },
    { "key": "5", "label": "差 [m²]", "type": "number", "format": sci3, "nullText": "—" }
]);
let difference = area.zip(exact_area).map(|(a, b)| (a - b).abs());
let sign = format!("{sign:?}");
let row = (sign, signed_area, result, area, exact_area, difference);
emit_table_with_columns!(
    columns,
    vec![row],
    metadata = serde_json::json!({ "id": "construction" })
);

// 受理されたメッシュの各面（辺）: 頂点、接するセル、各セルから見た符号、境界、タグ。
if let Ok(mesh) = &built {
    let boundary: Vec<(usize, u32)> = mesh
        .boundary_faces()
        .map(|face| {
            let bottom = mesh.face_vertices(face).is_ok_and(|v| v == [0, 1]);
            (face, if bottom { 1 } else { 2 })
        })
        .collect();
    let tags = SimplexBoundaryTags::new(mesh, boundary).map_err(|e| e.to_string())?;
    let mut rows = Vec::new();
    for face in 0..mesh.face_count() {
        let vertices = mesh.face_vertices(face).map_err(|e| e.to_string())?;
        let cells = mesh.face_cells(face).map_err(|e| e.to_string())?;
        let mut signs = [None, None];
        for (slot, cell) in signs.iter_mut().zip(0..mesh.cell_count()) {
            let faces = mesh.cell_faces(cell).map_err(|e| e.to_string())?;
            *slot = faces.iter().find(|f| f.index() == face).map(|f| f.sign());
        }
        let on_boundary = mesh.is_boundary_face(face).map_err(|e| e.to_string())?;
        let tag = tags.tag(mesh, face).map_err(|e| e.to_string())?;
        let (vertices, cells) = (format!("{vertices:?}"), format!("{cells:?}"));
        rows.push((vertices, cells, signs[0], signs[1], on_boundary, tag));
    }
    let face_columns = serde_json::json!([
        { "key": "0", "label": "面の頂点" },
        { "key": "1", "label": "接するセル" },
        { "key": "2", "label": "セル 0 での符号", "type": "integer", "nullText": "—" },
        { "key": "3", "label": "セル 1 での符号", "type": "integer", "nullText": "—" },
        { "key": "4", "label": "境界", "type": "boolean" },
        { "key": "5", "label": "タグ", "type": "integer", "nullText": "なし" }
    ]);
    emit_table_with_columns!(
        face_columns,
        rows,
        metadata = serde_json::json!({ "id": "faces" })
    );
}

// 固定の正方形で接続を 1 つずつ壊し、構築かタグ付けの結果を読む。
let square: Vec<Point<f64, 2>> = [[0.0, 0.0], [1.0, 0.0], [1.0, 1.0], [0.0, 1.0]]
    .iter()
    .map(|&c| Point::new(c))
    .collect::<Result<_, _>>()
    .map_err(|e| e.to_string())?;
let classify = |cells: Vec<[usize; 3]>| match TriangleMesh::new(square.clone(), cells) {
    Ok(_) => "受理".to_string(),
    Err(error) => format!("{:?}", error.kind()),
};
let valid =
    TriangleMesh::new(square.clone(), vec![[0, 1, 2], [0, 2, 3]]).map_err(|e| e.to_string())?;
let diagonal = (0..valid.face_count())
    .find(|&f| valid.is_boundary_face(f).is_ok_and(|boundary| !boundary))
    .ok_or("内部の辺がない")?;
let interior_tag = match SimplexBoundaryTags::new(&valid, vec![(diagonal, 5)]) {
    Ok(_) => "受理".to_string(),
    Err(error) => format!("{:?}", error.kind()),
};
let same_direction = classify(vec![[0, 1, 2], [0, 1, 3]]);
let unused = classify(vec![[0, 1, 2]]);
let missing = classify(vec![[0, 1, 4], [0, 2, 3]]);
let rejected = vec![
    ("2 つの三角形が辺 0–1 を同じ向きに使う", same_direction),
    ("頂点 3 を使わない", unused),
    ("存在しない頂点 4 を指す", missing),
    ("内部の辺 0–2 にタグを付ける", interior_tag),
];
emit_table_with_columns!(
    ["壊した入力", "結果"],
    rejected,
    metadata = serde_json::json!({ "id": "rejected" })
);
```

既定値の $t = 0$ では、三角形 $[0, 2, 3]$ は反時計回りで、面積の和は閉形式どおり 1 m² になる。
対角線 $0$–$2$ は 2 つの三角形に共有され、セル 0 から $-1$、セル 1 から $+1$ の符号で使われ、和は 0 になる。
境界の 4 辺は 1 つのセルにだけ属し、底辺に 1、ほかに 2 のタグが付く。
$t = 1$ では 3 点が同一直線上にあり、符号付き面積は 0、`orient2d` は `Zero` を返して構築は `InvalidInput` になる。
$t = 1.5$ では符号付き面積が $-0.25$ m²、符号が `Negative` になり、やはり `InvalidInput` で拒まれる。
固定の正方形の表では、同じ向きの共有辺、使われない頂点、内部の辺へのタグが `InvalidInput`、存在しない頂点が `OutOfBounds` になる。

## 区間メッシュ

1 次元の `IntervalMesh` は `SimplexMesh<S, 1>` の別名で、三角形・四面体と同じ接続と境界の表現を数直線上の区間に使う。
各区間 $[a, b]$ は $x_a < x_b$ の向きで与え、座標の比較に丸めは入らないので、向きの判定は厳密である。
1 次元では面は頂点そのもので、面の測度 `face_measure` は 1、区間の測度 `cell_measure` は長さ $x_b - x_a$ である。
各区間は自分自身を唯一の辺とするので、辺の数は区間の数に等しい。
1 つの頂点で終わる区間と始まる区間はそれぞれ高々 1 つでなければならない。
逆向き・退化・重複した区間、使われない頂点、頂点から 2 つの区間が始まる枝分かれのようにそれ以外の形で頂点を共有する区間は、`InvalidInput` で拒まれる。

次のセルは長さ $L = 0.01$ m の境界層を、壁 $x = 0$ の近くが細かい $n$ 個の区間に分ける。
節点は $x_i = L\,(i/n)^p$（$i = 0, \ldots, n$）で、$p > 1$ なら壁に近い区間ほど短い。
区間の長さの和は $L$、最も短い区間は最初の $L\,n^{-p}$、最も長い区間は最後の $L\,\bigl(1 - (1 - 1/n)^p\bigr)$ で、これらを `f64` の `powf` で求めた独立な検算に使う。
1 つ目の表は長さの和・最小・最大を閉形式と比べ、2 つ目の表は境界の面の数と測度、辺の数を示す。
3 つ目の表は接続を 1 つずつ壊した入力を構築し、拒まれたときのエラーの分類を示す。

```rust
//| id: spatial-interval-mesh-grading
//| ref: spatial-interval-mesh-grading
//| title: 偏りのある区間メッシュの長さと拒まれる接続
//| run: reactive
//| crates: [scioxide-core, scioxide-spatial]
//| inputs:
//|   cells: {"type":"range","label":"区間の数 n","min":2,"max":40,"step":1,"value":8}
//|   grading: {"type":"range","label":"偏りの指数 p [-]","min":1,"max":3,"step":0.25,"value":2}
//| cases:
//|   - {"id":"uniform","label":"等間隔（p = 1）","description":"8 個の区間の長さはどれも 1.25×10⁻³ m になる。","inputs":{"grading":1}}
//|   - {"id":"strong-grading","label":"n = 40、p = 3","description":"最初の区間は 1.5625×10⁻⁷ m、最後の区間は 7.31×10⁻⁴ m で、長さの比は約 4681 になる。","inputs":{"cells":40,"grading":3}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"lengths","path":"/rows/0/1","approx":{"value":0.01,"atol":1e-17}}
//|       - {"artifact":"lengths","path":"/rows/1/1","approx":{"value":1.5625e-4,"rtol":1e-14}}
//|       - {"artifact":"lengths","path":"/rows/2/1","approx":{"value":2.34375e-3,"rtol":1e-14}}
//|       - {"artifact":"entities","path":"/rows/0/0","equals":2}
//|       - {"artifact":"entities","path":"/rows/0/1","equals":1}
//|       - {"artifact":"entities","path":"/rows/0/2","equals":8}
//|       - {"artifact":"rejected","path":"/rows/0/1","equals":"InvalidInput"}
//|       - {"artifact":"rejected","path":"/rows/1/1","equals":"InvalidInput"}
//|       - {"artifact":"rejected","path":"/rows/2/1","equals":"InvalidInput"}
//|       - {"artifact":"rejected","path":"/rows/3/1","equals":"OutOfBounds"}
//|   - case: uniform
//|     expect:
//|       - {"artifact":"lengths","path":"/rows/1/1","approx":{"value":1.25e-3,"rtol":1e-14}}
//|       - {"artifact":"lengths","path":"/rows/2/1","approx":{"value":1.25e-3,"rtol":1e-14}}
//|   - case: strong-grading
//|     expect:
//|       - {"artifact":"lengths","path":"/rows/0/1","approx":{"value":0.01,"atol":1e-17}}
//|       - {"artifact":"lengths","path":"/rows/1/1","approx":{"value":1.5625e-7,"rtol":1e-12}}
//|       - {"artifact":"lengths","path":"/rows/2/1","approx":{"value":7.3140625e-4,"rtol":1e-12}}
//|       - {"artifact":"entities","path":"/rows/0/2","equals":40}
use scioxide_spatial::{IntervalMesh, Point};

// 節点 x_i = L (i/n)^p は呼び出し側が作る入力で、p > 1 なら壁 x = 0 の近くが細かい。
let length = 0.01;
let n = cells as usize;
let points = (0..=n)
    .map(|i| Point::new([length * (i as f64 / n as f64).powf(grading)]))
    .collect::<Result<Vec<_>, _>>()
    .map_err(|e| e.to_string())?;
let intervals: Vec<[usize; 2]> = (0..n).map(|i| [i, i + 1]).collect();
let mesh = IntervalMesh::new(points.clone(), intervals.clone()).map_err(|e| e.to_string())?;

// 区間の長さは cell_measure で読み、和・最小・最大を閉形式（f64 の powf による検算）と比べる。
let measures = (0..mesh.cell_count())
    .map(|cell| mesh.cell_measure(cell))
    .collect::<Result<Vec<f64>, _>>()
    .map_err(|e| e.to_string())?;
let total: f64 = measures.iter().sum();
let shortest = measures.iter().copied().fold(f64::INFINITY, f64::min);
let longest = measures.iter().copied().fold(0.0, f64::max);
let first = length * (1.0 / n as f64).powf(grading);
let last = length * (1.0 - (1.0 - 1.0 / n as f64).powf(grading));
let sci6 = serde_json::json!({ "notation": "scientific", "significantDigits": 6 });
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let length_columns = serde_json::json!([
    { "key": "0", "label": "量" },
    { "key": "1", "label": "計算値 [m]", "type": "number", "format": sci6 },
    { "key": "2", "label": "閉形式 [m]", "type": "number", "format": sci6 },
    { "key": "3", "label": "相対差 [-]", "type": "number", "format": sci3 }
]);
let lengths: Vec<(&str, f64, f64, f64)> = [
    ("区間の長さの和", total, length),
    ("最も短い区間", shortest, first),
    ("最も長い区間", longest, last),
]
.into_iter()
.map(|(label, value, exact)| (label, value, exact, (value - exact).abs() / exact))
.collect();
emit_table_with_columns!(
    length_columns,
    lengths,
    metadata = serde_json::json!({ "id": "lengths" })
);

// 境界の面は両端の頂点で、0 次元の測度は 1 である。
let boundary: Vec<usize> = mesh.boundary_faces().collect();
let boundary_measure = mesh.face_measure(boundary[0]).map_err(|e| e.to_string())?;
let entity_columns = serde_json::json!([
    { "key": "0", "label": "境界の面の数", "type": "integer" },
    { "key": "1", "label": "境界の面の測度 [-]", "type": "number" },
    { "key": "2", "label": "辺の数", "type": "integer" }
]);
emit_table_with_columns!(
    entity_columns,
    vec![(boundary.len(), boundary_measure, mesh.edge_count())],
    metadata = serde_json::json!({ "id": "entities" })
);

// 接続を 1 つずつ壊し、構築が拒むときのエラーの分類を読む。
let mut branching = intervals.clone();
branching.push([0, 2]);
let mut inverted = intervals.clone();
inverted[0] = [1, 0];
let unused = intervals[..n - 1].to_vec();
let mut outside = intervals;
outside[0] = [0, n + 1];
let attempts = [
    ("頂点 0 から 2 つの区間が始まる", branching),
    ("最初の区間の向きが逆", inverted),
    ("最後の頂点を使わない", unused),
    ("存在しない頂点番号 n + 1", outside),
];
let rejected: Vec<(&str, String)> = attempts
    .into_iter()
    .map(
        |(label, cells)| match IntervalMesh::new(points.clone(), cells) {
            Ok(_) => (label, "受理".to_string()),
            Err(error) => (label, format!("{:?}", error.kind())),
        },
    )
    .collect();
emit_table_with_columns!(
    ["壊した接続", "構築の結果"],
    rejected,
    metadata = serde_json::json!({ "id": "rejected" })
```

既定値（$n = 8$、$p = 2$）では、長さの和は $L = 0.01$ m に、最も短い区間 $1.5625 \times 10^{-4}$ m と最も長い区間 $2.34375 \times 10^{-3}$ m は閉形式に丸め誤差の範囲で一致する。
$n = 40$、$p = 3$ では最初の区間が $1.5625 \times 10^{-7}$ m、最後の区間が $7.3140625 \times 10^{-4}$ m で、長さの比は約 4681 になる。
$p$ を大きくすると最も短い区間は $n^{-p}$ で縮み、区間の長さの比が広がる。
3 つ目の表で `InvalidInput` は接続の検証による拒否、`OutOfBounds` は範囲外の頂点番号による拒否である。

## まとめ

単体メッシュのセルは正の向きで与える。
構築は向きを厳密な述語の符号で、重複、共有面の向き、頂点のまわりの多様体の条件を頂点番号の組合せで確かめ、満たさなければ `InvalidInput` を返す。
大域的な埋め込みは調べないので、自分自身に重なるメッシュを作らないことは呼び出し側が保証する。
面と辺は頂点番号の昇順で保存され、`OrientedEntity` の符号は内部の面で和が 0 になるので、流束の向きや接続行列の符号にそのまま使える。
境界の面には `SimplexBoundaryTags` で `u32` のタグを付け、境界条件を面の集まりごとに選ぶ。
区間メッシュでも同じ表現を使い、偏りのある節点の区間の長さは `cell_measure` で読める。
