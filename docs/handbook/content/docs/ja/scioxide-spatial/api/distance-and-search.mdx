この表は任意次元の点集合の距離と近傍探索の項目をまとめる。
点集合は `PointSet` が固定長配列の列、行優先の平らな配列、または 2 階の `NdView` を借用して表し、全座標の有限性を構築時に一度だけ検査する。
距離は座標の型によらず `f64` の中間値で計算する。
Euclid 距離は関数 `distance`、`pairwise`、`condensed` で準備なしに求まり、他の距離は `PreparedDistance` のメソッドで求める。
一括の計算は結果を作業領域に書いてから出力へ写すので、エラーのとき出力は変わらない。
作業領域の要求量は距離では `DistanceWorkspace::workspace_requirements(request)`（関連関数）、探索では `KdTree::workspace_requirements(request)`（メソッド）で求める。

## まとめ

Euclid 距離は関数 `distance`、`pairwise`、`condensed` で求め、17 種類の名前付きの距離と標準化 Euclid 距離・Mahalanobis 距離は `PreparedDistance` で準備して使う。
1 つの点集合の全点対は圧縮表現（$n(n-1)/2$ 個）で持てばメモリが約半分になり、`condensed_index` で対の位置を引ける。
有向 Hausdorff 距離の最悪の計算コストは $O(mnd)$ で、早期打ち切りは典型的な入力で比較を減らすだけである。
KD 木は 4 種類の計量（Euclid、CityBlock、Chebyshev、$p \ge 1$ の Minkowski）に対応し、結果は距離の昇順、同じ距離なら添字の昇順に並ぶ。
距離の定義域は[距離と非類似度](../../algorithms/distances/)で、距離行列の持ち方は[距離行列と圧縮表現](../../algorithms/distance-matrices/)で、枝刈りと近似の意味は[KD 木による近傍探索](../../algorithms/spatial-trees-and-distance/)で確かめる。
