この表は 1〜3 次元の構造格子と単体メッシュ、その上の場を表す項目をまとめる。
添字は軸 0 が最も速く変わる順に並べ、範囲 $[n_x, n_y, n_z]$ の添字 $[x, y, z]$ の線形位置は $x + n_x (y + n_y z)$ である。
構造格子の接続は整数の添字から求め、隣接表を持たない。
単体メッシュは明示的な接続を持ち、構築時に向きと多様体の接続を検査するが、メッシュ全体が自己交差しないこと（埋め込み）は検査しない。
場とメッシュの組み合わせは `MeshToken` で照合し、revision が合わなければ `InvalidInput` を返す。

## まとめ

構造格子は座標軸の直積で、接続を添字から $O(1)$ で求めるので隣接表のメモリを持たない。
単体メッシュは構築時に向きと接続を検査し、境界は `SimplexBoundaryTags` で名前を付けて扱う。
場は位置の型（頂点、セル、面、辺）と作ったメッシュの revision を持ち、revision の違うメッシュと組み合わせると `InvalidInput` になる。
周期軸の継ぎ目は 2 つの面を対にして表し、`face_topology` の `Periodic` で対の面を引ける。
格子と場の使い方は[点・範囲・格子・メッシュの基礎](../../algorithms/geometry-grids-and-meshes/)で、細分したメッシュの扱いは[適応メッシュの API](../adaptive-meshes/)で確かめる。
