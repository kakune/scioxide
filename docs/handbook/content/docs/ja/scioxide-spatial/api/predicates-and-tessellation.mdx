この表は行列式の符号で決まる述語と、その述語で組合せを決める分割の項目をまとめる。
述語は浮動小数点のフィルタで符号を確かめ、確かめられなければ厳密に計算するので、有限な入力なら与えた値に対する正確な符号を返す。
凸包、Delaunay 分割、Voronoi 図、球面 Voronoi 図は母点を辞書式に並べ替えて一致する母点をまとめ、正準添字で結果を返す。
`ConvexHull` と `Delaunay` は `input_mapping` と `representatives` で入力の行と対応させ、`Voronoi` は `delaunay()` を通し、`SphericalVoronoi` は `input_mapping` だけを持つ。
外心、重心座標、頂点の座標、面積は丸めを含む構成値である。
Delaunay 分割と Voronoi 図では、信頼して計算できない項目を返すメソッドだけが `NumericalInstability` を返す。
半空間の交差は頂点ごとに誤差を構築時に証明し、球面 Voronoi 図は領域と面積を構築時に計算する。
この 2 つでは、1 つでも証明または計算できなければ構築全体が `NumericalInstability` になる。

## まとめ

述語の符号は入力として表現された浮動小数点数に対して正しく、`Zero` は行列式が厳密に 0 であることを表す。
分割の位相は厳密な符号で決まり、同点は並べ替えた母点の順の記号摂動で解く（`Strict` は重複母点と三角形分割が一意でない入力を `InvalidInput` で拒む）。
分割が返す添字は正準添字なので、入力の行へは `input_mapping` と `representatives` で戻す（`Voronoi` は `delaunay()` を通す）。
構成値のうち誤差の上界が証明されているのは半空間の交差の頂点だけで、ほかの構成値は独立な計算と比べて確かめる。
構築のリソースは `GeometryLimits` で制限し、使った計算量は `GeometryProvenance` で確かめる。
符号の決め方は[厳密な幾何述語](../../algorithms/exact-predicates/)で、分割と交差の作り方は[凸包・Delaunay 分割・Voronoi 図](../../algorithms/delaunay-voronoi-and-hulls/)と[半空間の交差](../../algorithms/halfspace-intersection/)で確かめる。
