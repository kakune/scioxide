この表は 3 次元の回転と剛体変換を表し、補間し、推定する項目をまとめる。
回転は能動的な右手系の回転で、角はラジアンで表す。
四元数はスカラー部を最後に置いた $[x, y, z, w]$ の順に格納し、$q$ と $-q$ は同じ回転なので符号を正準化する。
行列は行優先で列ベクトルに作用する。
多数の点や時刻をまとめて処理する `*_into` のメソッドは、事前確保した `TransformWorkspace` に結果を書いてから出力へ写す。
作業領域の要求量は関連関数 `TransformWorkspace::workspace_requirements(request)` で求める。

## まとめ

回転は単位四元数で表し、合成のたびに正規化し直すので、合成を繰り返しても単位ノルムからのずれは丸めの程度にとどまる。
Euler 角は 12 系列をそれぞれ内在・外在で扱え、中央の角が特異点に近いと `gimbal_lock` が真になる。
節点の間を一定の角速度で結ぶなら `Slerp`、角速度と角加速度を節点で連続にするなら `RotationSpline` を使う。
スプラインは終了状態が `Converged` のときだけ結果に入る。
対応点からの剛体変換は `estimate_rigid_transform`（重みと設定を与えるなら `estimate_rigid_transform_with_options`）で求め、点が一直線上のように回転が一意に決まらない配置は `InvalidInput` になる。
数理は[3 次元回転と姿勢補間](../../algorithms/rotations-and-transforms/)と[剛体の位置合わせ](../../algorithms/rigid-registration/)で確かめる。
