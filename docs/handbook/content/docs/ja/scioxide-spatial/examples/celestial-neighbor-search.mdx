スタートラッカーは撮影した星の並びを星表と照合して宇宙機の姿勢を決める。
その照合では、ある方向から角距離 $\theta_0$ 以内にある星表の星を何度も取り出す。
星の位置は天球上の点なので、近さは平面の距離ではなく大円に沿った角距離で測る。
この例題では天球を 3 次元の単位球として扱い、角距離の探索を 3 次元の KD 木の半径探索に置き換える。
後半では天球を各星に最も近い領域に分ける球面 Voronoi 図を作り、領域の面積（立体角）を調べる。

## 赤道座標と単位ベクトル

星の位置は赤経 $\alpha$ と赤緯 $\delta$ で表す。
$\alpha$ は春分点から東向きに測った角度、$\delta$ は天の赤道から北向きに測った角度である。
半径 1 の天球の上では、星は次の単位ベクトルに対応する。

$$
\boldsymbol{u}(\alpha, \delta) =
\begin{pmatrix} \cos\delta\cos\alpha \\ \cos\delta\sin\alpha \\ \sin\delta \end{pmatrix}
$$

$x$ 軸は春分点、$z$ 軸は天の北極を向く。
3 軸の長さの単位はどれも天球の半径である。

## 弦の長さと角距離

2 つの星 $\boldsymbol{u}_1$、$\boldsymbol{u}_2$ の角距離を $\theta \in [0, \pi]$ とする。
2 点を結ぶ線分（弦）の長さ $c = \|\boldsymbol{u}_1 - \boldsymbol{u}_2\|$ は、二等辺三角形の頂角の半分から

$$
c = 2\sin\frac{\theta}{2}, \qquad \theta = 2\arcsin\frac{c}{2}
$$

と決まる。
$c$ は $\theta$ の狭義単調増加関数なので、「角距離が $\theta_0$ 以下」と「弦の長さが $c_0 = 2\sin(\theta_0/2)$ 以下」は同じ条件である。
したがって、角距離の探索は単位ベクトルに作った KD 木で半径 $c_0$ の Euclid 距離の探索（`KdTree::radius_into`）を 1 回行えばよい。
三角関数は $c_0$ を作るときと、見つかった星の $c$ を角度に戻すときにだけ使う。

角度に戻す式の選び方は精度に影響する。
$\theta = 2\arcsin(c/2)$ は $\theta$ が小さいときも条件がよく、$c$ の相対誤差がほぼそのまま $\theta$ の相対誤差になる。
一方、内積から $\theta = \arccos(\boldsymbol{u}_1\cdot\boldsymbol{u}_2)$ と求めると、$\boldsymbol{u}_1\cdot\boldsymbol{u}_2 = 1 - \theta^2/2 + \cdots$ の丸め誤差 $\varepsilon \approx 1.1\times10^{-16}$ が $\theta$ に約 $\sqrt{2\varepsilon} \approx 1.5\times10^{-8}$ rad の誤差を生む。
角距離が 0 に近い星や、中心の星自身との距離を $\arccos$ で求めると、この大きさの差が現れる。

## haversine の式による検算

探索の結果は単位ベクトルも KD 木も使わない別の式で検算する。
半正矢関数 $\operatorname{hav}\theta = \sin^2(\theta/2)$ を使うと、球面三角法の余弦定理は

$$
\operatorname{hav}\theta = \operatorname{hav}(\delta_2 - \delta_1) + \cos\delta_1\cos\delta_2\,\operatorname{hav}(\alpha_2 - \alpha_1), \qquad
\theta = 2\arcsin\sqrt{\operatorname{hav}\theta}
$$

と書ける（haversine の式）。
右辺は差 $\delta_2 - \delta_1$、$\alpha_2 - \alpha_1$ から直接作るので、小さな角距離でも桁落ちしない。
$\sqrt{\operatorname{hav}\theta}$ が 1 に近い対蹠点の近くでは $\arcsin$ の条件が悪くなるが、この例題の探索半径（60° 以下）では問題にならない。

## 星表

星表は V 等級で 1.7 等より明るい恒星 29 個に北極星を加えた 30 個である。
座標は SIMBAD に収録された ICRS・元期 J2000.0 の値（主に Hipparcos 星表の再還元、van Leeuwen 2007）を、度単位の小数 3 桁に丸めた。
丸めによる誤差は赤経・赤緯それぞれ $\pm 0.0005°$（約 1.8″）以内である。
これは検算で比べる角距離の差（$10^{-16}$ rad 程度）よりずっと大きいが、2 通りの角距離はどちらも同じ丸めた座標から求めるので、検算の結果には影響しない。
並びは V 等級の明るい順で、後半のセルは先頭から $N$ 個を使う。
ケンタウルス座 α 星の順位は A・B 両星の合成等級（−0.27 等）で決め、座標は明るい A 星の値を使う。
そのため、A 星だけの等級（0.01 等）より明るいアークトゥルス（−0.05 等）の前に並ぶ。

次のブロックは 2 つのセルが共有する定義である。
`CATALOG` が星表、`unit_vector` が $\boldsymbol{u}(\alpha, \delta)$、`catalog_coordinates` が先頭 $N$ 個の単位ベクトルを並べた座標、`haversine_angle` が haversine の式に対応する。
`haversine_angle` は検算用の参照値で、`f64` の標準関数で計算する。

```rust
/// 赤経・赤緯 [deg] から単位ベクトル u = (cos δ cos α, cos δ sin α, sin δ) を作る。
pub(crate) fn unit_vector(ra_deg: f64, dec_deg: f64) -> [f64; 3] {
    let (sin_a, cos_a) = RealScalar::sin_cos(RealScalar::to_radians(ra_deg));
    let (sin_d, cos_d) = RealScalar::sin_cos(RealScalar::to_radians(dec_deg));
    [cos_d * cos_a, cos_d * sin_a, sin_d]
}

/// 先頭 n 個の星の単位ベクトルを、1 行に (x, y, z) の行優先で並べる。
pub(crate) fn catalog_coordinates(n: usize) -> Vec<f64> {
    CATALOG[..n]
        .iter()
        .flat_map(|&(_, ra, dec)| unit_vector(ra, dec))
        .collect()
}

/// haversine の式による角距離 [rad]。検算用の参照値（f64 の標準関数）。
pub(crate) fn haversine_angle(a: (f64, f64), b: (f64, f64)) -> f64 {
    let (ra1, dec1) = (a.0.to_radians(), a.1.to_radians());
    let (ra2, dec2) = (b.0.to_radians(), b.1.to_radians());
    let hav_dec = (0.5 * (dec2 - dec1)).sin().powi(2);
    let hav_ra = (0.5 * (ra2 - ra1)).sin().powi(2);
    let hav = hav_dec + dec1.cos() * dec2.cos() * hav_ra;
    2.0 * hav.sqrt().min(1.0).asin()
}
```

## 角距離の半径探索

次のセルは中心の星と角半径 $\theta_0$ [deg] を選び、30 個の星から角距離 $\theta_0$ 以内の星を探す。
KD 木は 30 個の単位ベクトルに作り、半径 $c_0 = 2\sin(\theta_0/2)$ で `radius_into` を呼ぶ。
`radius_into` は見つけた星を距離の近い順に出力に書き、その個数を返す。
出力の `Neighbor::index` は KD 木に渡した点集合の行番号、つまり星表の番号である。
`radius_into` は出力の配列か作業領域より多くの星を見つけると `ResourceLimit` を返すので、どちらも全 30 星が入る大きさで用意する。

中心の星自身も距離 0 で見つかるので、表と検算からは除く。
1 つ目の表は見つかった星ごとに、弦から戻した角距離、haversine の式の角距離、両者の差、弦の長さを示す。
2 つ目の表は探索で見つけた星の数と、haversine の式で全 29 星を総当たりして $\theta \le \theta_0$ となった星の数を並べる。
2 つの数が一致すれば、探索は条件を満たす星を漏らさず、余分な星も含めていない。

```rust
//| id: spatial-celestial-radius-search
//| ref: spatial-celestial-radius-search
//| title: 弦の長さを半径とする KD 木の探索で角距離の近傍を求める
//| run: reactive
//| uses: [spatial-celestial-catalog]
//| crates: [scioxide-core, scioxide-spatial]
//| exports: [center, search_angle, found]
//| inputs:
//|   center_star: {"type":"select","label":"中心の星","options":["シリウス","カノープス","ケンタウルス座 α 星 A","アークトゥルス","ベガ","カペラ","リゲル","プロキオン","アケルナル","ベテルギウス","ハダル","アルタイル","アクルックス","アルデバラン","アンタレス","スピカ","ポルックス","フォーマルハウト","デネブ","ミモザ","レグルス","アダーラ","カストル","シャウラ","ガクルックス","ベラトリックス","エルナト","ミアプラキドゥス","アルニラム","北極星"],"value":"ベテルギウス"}
//|   search_angle: {"type":"range","label":"角半径 θ₀ [deg]","description":"探索する小円の角半径。","min":1,"max":60,"step":1,"value":30}
//| cases:
//|   - {"id":"southern-cross","label":"アクルックス、θ₀ = 12°","description":"南十字の 2 星とハダルが近傍に入る。","inputs":{"center_star":"アクルックス","search_angle":12}}
//|   - {"id":"polaris-wide","label":"北極星、θ₀ = 60°","description":"天の北極の近くでも探索と検算が一致する。","inputs":{"center_star":"北極星","search_angle":60}}
//|   - {"id":"narrow","label":"θ₀ = 1°","description":"中心の星のほかに見つかる星がない。","inputs":{"search_angle":1}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"neighbors","path":"/rows/0/0","equals":"ベラトリックス"}
//|       - {"artifact":"neighbors","path":"/rows/0/1","approx":{"value":7.5303,"atol":1e-3}}
//|       - {"artifact":"summary","path":"/rows/0/1","equals":7}
//|       - {"artifact":"summary","path":"/rows/0/2","equals":7}
//|       - {"artifact":"summary","path":"/rows/0/3","range":{"max":1e-14}}
//|   - case: southern-cross
//|     expect:
//|       - {"artifact":"neighbors","path":"/rows/0/0","equals":"ミモザ"}
//|       - {"artifact":"neighbors","path":"/rows/0/2","approx":{"value":4.2420,"atol":1e-3}}
//|       - {"artifact":"summary","path":"/rows/0/2","equals":3}
//|   - case: polaris-wide
//|     expect:
//|       - {"artifact":"neighbors","path":"/rows/0/1","approx":{"value":43.4505,"atol":1e-3}}
//|       - {"artifact":"summary","path":"/rows/0/1","equals":4}
//|       - {"artifact":"summary","path":"/rows/0/3","range":{"max":1e-14}}
//|   - case: narrow
//|     expect:
//|       - {"artifact":"summary","path":"/rows/0/1","equals":0}
//|       - {"artifact":"summary","path":"/rows/0/3","equals":null}
use scioxide_core::{ExecutionContext, RealScalar};
use scioxide_spatial::{KdTree, Neighbor, PointSet, SearchOptions, SearchWorkspaceRequest};

let n = CATALOG.len();
let coordinates = catalog_coordinates(n);
let points = PointSet::from_rows(&coordinates, 3).map_err(|e| e.to_string())?;
let tree = KdTree::new(&points).map_err(|e| e.to_string())?;

// 角半径 θ₀ を弦の長さ c₀ = 2 sin(θ₀/2) に換える。
let center = CATALOG
    .iter()
    .position(|&(name, _, _)| name == center_star)
    .ok_or("中心の星が星表にない")?;
let theta0 = RealScalar::to_radians(search_angle);
let chord_radius = 2.0 * RealScalar::sin(0.5 * theta0);
let options = SearchOptions::new();
let mut workspace = tree
    .workspace(SearchWorkspaceRequest::new(n, options))
    .map_err(|e| e.to_string())?;
let mut found = vec![Neighbor::default(); n];
let query = &coordinates[3 * center..3 * center + 3];
let count = tree
    .radius_into(
        query,
        chord_radius,
        options,
        &mut found,
        &mut workspace,
        ExecutionContext::sequential(),
    )
    .map_err(|e| e.to_string())?;

// 弦から戻した角距離 2 asin(c/2) を haversine の式（参照値）と比べる。中心の星は除く。
let (_, ra0, dec0) = CATALOG[center];
let rows: Vec<(&str, f64, f64, f64, f64)> = found[..count]
    .iter()
    .filter(|item| item.index != center)
    .map(|item| {
        let (name, ra, dec) = CATALOG[item.index];
        let from_chord = 2.0 * RealScalar::asin(0.5 * item.distance);
        let reference = haversine_angle((ra0, dec0), (ra, dec));
        (
            name,
            RealScalar::to_degrees(from_chord),
            reference.to_degrees(),
            (from_chord - reference).abs(),
            item.distance,
        )
    })
    .collect();
let max_difference = rows.iter().map(|row| row.3).fold(0.0_f64, f64::max);
let brute_force = CATALOG
    .iter()
    .enumerate()
    .filter(|&(i, &(_, ra, dec))| {
        i != center && haversine_angle((ra0, dec0), (ra, dec)) <= theta0
    })
    .count();

let deg4 = serde_json::json!({ "fractionDigits": 4 });
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let neighbor_columns = serde_json::json!([
    { "key": "0", "label": "星" },
    { "key": "1", "label": "角距離 2 asin(c/2) [deg]", "type": "number", "format": deg4 },
    { "key": "2", "label": "角距離 haversine [deg]", "type": "number", "format": deg4 },
    { "key": "3", "label": "差 [rad]", "type": "number", "format": sci2 },
    { "key": "4", "label": "弦の長さ c [天球の半径]", "type": "number", "format": deg4 }
]);
emit_table_with_columns!(
    neighbor_columns,
    rows.clone(),
    metadata = serde_json::json!({ "id": "neighbors" })
);
let summary_columns = serde_json::json!([
    { "key": "0", "label": "弦の半径 c₀ [天球の半径]", "type": "number", "format": deg4 },
    { "key": "1", "label": "探索で見つけた星 [個]", "type": "integer" },
    { "key": "2", "label": "総当たりで θ ≤ θ₀ の星 [個]", "type": "integer" },
    { "key": "3", "label": "角距離の差の最大 [rad]", "type": "number", "format": sci2, "nullText": "近傍なし" }
]);
let max_difference = (!rows.is_empty()).then_some(max_difference);
let summary = (chord_radius, rows.len(), brute_force, max_difference);
emit_table_with_columns!(
    summary_columns,
    vec![summary],
    metadata = serde_json::json!({ "id": "summary" })
);

let found_rows: Vec<usize> = found[..count]
    .iter()
    .map(|item| item.index)
    .filter(|&i| i != center)
    .collect();
export!(center, center);
export!(search_angle, search_angle);
export!(found, found_rows);
```

既定の入力（ベテルギウス、$\theta_0 = 30°$）では、弦の半径は $c_0 = 0.5176$ で、近い順にベラトリックス（7.530°）、アルニラム（9.822°）、リゲル（18.606°）、アルデバラン、エルナト、プロキオン、シリウス（27.104°）の 7 星が見つかる。
haversine の式で総当たりした個数も 7 で、探索は条件を満たす星だけを返している。
弦から戻した角距離と haversine の式の差は最大 $5.6\times10^{-17}$ rad で、倍精度の丸めの大きさである。
内積の $\arccos$ で $10^{-8}$ rad 程度の誤差が出るのは角距離が 0 に近い場合で、表の角距離（7° 以上）では $\arccos$ の誤差も $\varepsilon/\sin\theta \approx 10^{-15}$ rad 程度にとどまる。

「アクルックス、θ₀ = 12°」の場合は、ミモザ（4.242°）、ガクルックス（6.013°）、ハダル（11.751°）の 3 星が見つかる。
「北極星、θ₀ = 60°」の場合は、カペラ（43.45°）、デネブ、ベガ、カストルの 4 星が見つかり、角距離の差は最大 $3.3\times10^{-16}$ rad である。
角距離が大きいほど差の絶対値は大きくなるが、相対誤差は $10^{-16}$ の桁にとどまる。
「θ₀ = 1°」の場合は中心の星しか見つからず、差の列は「近傍なし」になる。

次のセルは、探索のセルが渡す中心の星、角半径 $\theta_0$、見つかった星の番号を受け取り、天球上の 30 星と角半径 $\theta_0$ の小円を描く。
小円の点は中心の単位ベクトル $\boldsymbol{u}_0$ と、中心で東と北を向く単位ベクトル $\boldsymbol{e}$、$\boldsymbol{n}$ から $\cos\theta_0\,\boldsymbol{u}_0 + \sin\theta_0(\cos\varphi\,\boldsymbol{e} + \sin\varphi\,\boldsymbol{n})$ で作る。
星は中心の星、角半径 $\theta_0$ 以内の星、それ以外の星のグループに分ける。
3 軸の単位はどれも天球の半径なので、2 つの星を選ぶと表示される距離が弦の長さ $c$ になる。

```rust
//| id: spatial-celestial-sky-scene
//| ref: spatial-celestial-sky-scene
//| title: 天球上の星と角半径 θ₀ の小円を 3 次元で描く
//| run: reactive
//| uses: [spatial-celestial-catalog]
//| crates: [scioxide-core]
//| dependsOn:
//|   search: spatial-celestial-radius-search
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"sky","path":"/points/9/group","equals":"center"}
//|       - {"artifact":"sky","path":"/points/25/group","equals":"found"}
use scioxide_core::RealScalar;

let center = search["center"].as_u64().ok_or("中心の星がない")? as usize;
let search_angle = search["search_angle"].as_f64().ok_or("角半径がない")?;
let found: Vec<usize> =
    serde_json::from_value(search["found"].clone()).map_err(|e| e.to_string())?;
let coordinates = catalog_coordinates(CATALOG.len());
// 天球上の星と、中心から角半径 θ₀ の小円（東向き e、北向き n の基底で作る）。
let mut scene_points: Vec<serde_json::Value> = (0..CATALOG.len())
    .map(|i| {
        let group = if i == center {
            "center"
        } else if found.contains(&i) {
            "found"
        } else {
            "other"
        };
        serde_json::json!({
            "id": format!("star-{i}"),
            "position": &coordinates[3 * i..3 * i + 3],
            "label": CATALOG[i].0,
            "group": group
        })
    })
    .collect();
let (_, ra0, dec0) = CATALOG[center];
let query = &coordinates[3 * center..3 * center + 3];
let (sin_a, cos_a) = RealScalar::sin_cos(RealScalar::to_radians(ra0));
let (sin_d, cos_d) = RealScalar::sin_cos(RealScalar::to_radians(dec0));
let east = [-sin_a, cos_a, 0.0];
let north = [-sin_d * cos_a, -sin_d * sin_a, cos_d];
let (sin_t, cos_t) = RealScalar::sin_cos(RealScalar::to_radians(search_angle));
let mut edges = Vec::new();
for k in 0..72 {
    let (sin_p, cos_p) = RealScalar::sin_cos(core::f64::consts::TAU * f64::from(k) / 72.0);
    let position: Vec<f64> = (0..3)
        .map(|j| cos_t * query[j] + sin_t * (cos_p * east[j] + sin_p * north[j]))
        .collect();
    scene_points.push(serde_json::json!({
        "id": format!("circle-{k}"),
        "position": position,
        "group": "circle"
    }));
    edges.push(serde_json::json!({
        "from": format!("circle-{k}"),
        "to": format!("circle-{}", (k + 1) % 72)
    }));
}
let unit = |label: &str| serde_json::json!({ "label": label, "unit": "天球の半径" });
emit_scene3d!(
    serde_json::json!({
        "points": scene_points,
        "edges": edges,
        "groups": [
            { "id": "center", "label": "中心の星" },
            { "id": "found", "label": "角半径 θ₀ 以内の星" },
            { "id": "other", "label": "それ以外の星" },
            { "id": "circle", "label": "角半径 θ₀ の小円" }
        ],
        "axes": { "x": unit("x（春分点）"), "y": unit("y"), "z": unit("z（天の北極）") }
    }),
    metadata = serde_json::json!({ "id": "sky", "title": "天球上の星と探索の小円" })
);
```

## 天球の球面 Voronoi 図

単位球面上の母点 $\boldsymbol{u}_1, \ldots, \boldsymbol{u}_N$ に対し、母点 $i$ の領域を

$$
R_i = \{\boldsymbol{x} \in S^2 : \boldsymbol{x}\cdot\boldsymbol{u}_i \ge \boldsymbol{x}\cdot\boldsymbol{u}_j \ \text{for all}\ j\}
$$

とする。
内積が大きいほど角距離は小さいので、$R_i$ は角距離で $\boldsymbol{u}_i$ に最も近い点の集合である。
これが球面 Voronoi 図で、領域は大円の弧で囲まれた球面多角形になる。
天球の全面積は $4\pi$ sr なので、領域の面積 $A_i$ [sr] の和は

$$
\sum_{i=1}^N A_i = 4\pi
$$

を満たす。
領域の面積は、その星が最も近い星である方向の立体角で、星の分布が疎な方向ほど大きい。

`SphericalVoronoi::new` は、球面上の母点の凸包が球面 Delaunay 分割になることを使う。
凸包の各面の外向き法線の方向にある球面上の点が Voronoi の頂点で、領域の面積は母点と隣り合う 2 頂点が作る球面三角形の立体角（Van Oosterom–Strackee の式）の和として求める。
母点は球面の上にある必要があり、中心からの距離と半径 $r$ の差が許容誤差 `Tolerance` の閾値 $\tau = \mathrm{atol} + \mathrm{rtol}\cdot r$ を超えると `InvalidInput` になる。
単位ベクトルの長さの丸め誤差は $10^{-16}$ 程度なので、セルでは $\mathrm{atol} = 10^{-12}$、$\mathrm{rtol} = 0$ とする。

`SphericalVoronoi` は `Delaunay` などの分割と同じく、母点を座標の辞書式順に並べ替えて重複をまとめる。
`areas()`、`region(site)`、`neighbors(site)` の添字は並べ替えた母点の正準添字で、星表の番号ではない。
入力の行 $i$ の母点の番号は `input_mapping()[i]` で得る。
`SphericalVoronoi` には母点から入力の行へ戻す `representatives()` がないので、セルは星表の行 $i$ ごとに `input_mapping()[i]` で母点に写してから、面積と領域を引く。
星表の番号で `areas()` を直接引くと、別の星の面積を読む。

## 領域の面積と最大・最小の領域

次のセルは星表の明るい順に先頭 $N$ 個の星で球面 Voronoi 図を作る。
1 つ目の表は面積の大きい順に、各星の領域の面積、全天に占める割合、領域の頂点数、隣り合う領域の数を示す。
2 つ目の表は面積の和と $4\pi$ の相対誤差、平均の面積 $4\pi/N$、最大と最小の領域の星を示す。

最後の列は番号の対応を独立に確かめる量である。
星 $i$ の領域の各頂点 $\boldsymbol{v}$ について、星 $i$ までの弦の長さと、全 $N$ 星のうち最も近い星までの弦の長さの差を求め、その最大を示す。
Voronoi の頂点に最も近い星（同点を含む）は、その頂点を持つ領域の星なので、対応が正しければ差は丸め誤差の大きさになり、対応を誤ると、下で見るように丸め誤差よりはるかに大きくなる。

```rust
//| id: spatial-celestial-spherical-voronoi
//| ref: spatial-celestial-spherical-voronoi
//| title: 天球の球面 Voronoi 図の面積と、正準添字から星への対応
//| run: reactive
//| uses: [spatial-celestial-catalog]
//| crates: [scioxide-core, scioxide-spatial]
//| inputs:
//|   star_count: {"type":"range","label":"星の数 N [個]","description":"明るい順に先頭 N 個を母点にする。","min":4,"max":30,"step":1,"value":30}
//| cases:
//|   - {"id":"four-stars","label":"N = 4","description":"母点が四面体を作り、どの領域も 3 頂点の球面三角形になる。","inputs":{"star_count":4}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"areas","path":"/rows/0/2","range":{"max":1e-14}}
//|       - {"artifact":"areas","path":"/rows/0/4","equals":"フォーマルハウト"}
//|       - {"artifact":"areas","path":"/rows/0/5","equals":"ミモザ"}
//|       - {"artifact":"areas","path":"/rows/0/6","range":{"max":1e-13}}
//|       - {"artifact":"regions","path":"/rows/0/1","approx":{"value":1.13500,"atol":1e-4}}
//|   - case: four-stars
//|     expect:
//|       - {"artifact":"areas","path":"/rows/0/2","range":{"max":1e-14}}
//|       - {"artifact":"areas","path":"/rows/0/4","equals":"アークトゥルス"}
//|       - {"artifact":"regions","path":"/rows/3/3","equals":3}
use scioxide_core::{RealScalar, Tolerance};
use scioxide_spatial::{PointSet, SphericalVoronoi};

let n = star_count as usize;
let coordinates = catalog_coordinates(n);
let points = PointSet::from_rows(&coordinates, 3).map_err(|e| e.to_string())?;
let tolerance = Tolerance::new(1e-12, 0.0).map_err(|e| e.to_string())?;
let diagram =
    SphericalVoronoi::new(&points, [0.0; 3], 1.0, tolerance).map_err(|e| e.to_string())?;

// 入力の行 i（星表の番号）から正準添字へ写してから、面積と領域を引く。
let chord = |a: &[f64], b: &[f64]| -> f64 {
    let squared: f64 = a.iter().zip(b).map(|(x, y)| (x - y) * (x - y)).sum();
    RealScalar::sqrt(squared)
};
let mut rows = Vec::with_capacity(n);
let mut worst_violation = 0.0_f64;
for i in 0..n {
    let site = diagram.input_mapping()[i];
    let region = diagram.region(site).map_err(|e| e.to_string())?;
    let neighbors = diagram.neighbors(site).map_err(|e| e.to_string())?.count();
    // 対応の検算: 領域の頂点 v から見て、星 i は最も近い星（同点を含む）である。
    for &vertex in region {
        let v = &diagram.vertices()[3 * vertex..3 * vertex + 3];
        let own = chord(v, &coordinates[3 * i..3 * i + 3]);
        let nearest = coordinates
            .chunks_exact(3)
            .map(|u| chord(v, u))
            .fold(f64::INFINITY, f64::min);
        worst_violation = worst_violation.max(own - nearest);
    }
    let area = diagram.areas()[site];
    let share = 100.0 * area / (4.0 * core::f64::consts::PI);
    rows.push((CATALOG[i].0, area, share, region.len(), neighbors));
}
rows.sort_by(|a, b| b.1.total_cmp(&a.1));
let total: f64 = diagram.areas().iter().sum();
let four_pi = 4.0 * core::f64::consts::PI;

let fixed4 = serde_json::json!({ "fractionDigits": 4 });
let fixed2 = serde_json::json!({ "fractionDigits": 2 });
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let region_columns = serde_json::json!([
    { "key": "0", "label": "星" },
    { "key": "1", "label": "面積 A [sr]", "type": "number", "format": fixed4 },
    { "key": "2", "label": "全天に占める割合 [%]", "type": "number", "format": fixed2 },
    { "key": "3", "label": "頂点数 [個]", "type": "integer" },
    { "key": "4", "label": "隣り合う領域 [個]", "type": "integer" }
]);
emit_table_with_columns!(
    region_columns,
    rows.clone(),
    metadata = serde_json::json!({ "id": "regions" })
);
let summary_columns = serde_json::json!([
    { "key": "0", "label": "星の数 N [個]", "type": "integer" },
    { "key": "1", "label": "ΣA [sr]", "type": "number", "format": { "significantDigits": 15 } },
    { "key": "2", "label": "|ΣA − 4π| / 4π [-]", "type": "number", "format": sci2 },
    { "key": "3", "label": "平均 4π/N [sr]", "type": "number", "format": fixed4 },
    { "key": "4", "label": "最大の領域" },
    { "key": "5", "label": "最小の領域" },
    { "key": "6", "label": "頂点での距離の差の最大 [天球の半径]", "type": "number", "format": sci2 }
]);
let summary = (
    n,
    total,
    (total - four_pi).abs() / four_pi,
    four_pi / n as f64,
    rows[0].0,
    rows[n - 1].0,
    worst_violation,
);
emit_table_with_columns!(
    summary_columns,
    vec![summary],
    metadata = serde_json::json!({ "id": "areas" })
);
```

既定の $N = 30$ では、面積の和と $4\pi$ の相対誤差は $2.8\times10^{-16}$ で、面積の計算に系統的な欠けや重なりはない。
平均の面積 $4\pi/30 = 0.4189$ sr に対し、最大はフォーマルハウトの 1.1350 sr（全天の 9.03%）、最小はミモザの 0.0158 sr（0.13%）で、比は約 72 倍である。
星表の中でフォーマルハウトに最も近い星はアケルナルで、39.1° 離れている。
一方、ミモザから 10° 以内にはガクルックス（3.37°）、アクルックス（4.24°）、ハダル（9.50°）がある。
どちらの角距離も探索のセルで中心の星を選べば確かめられる。
頂点での距離の差は最大 $1.5\times10^{-15}$ で、番号の対応は正しい。
試しに `input_mapping()` を通さず星表の番号 $i$ で `region(i)` と `areas()[i]` を引くと、この差は 1.83 になり、最大の領域は北極星、最小はベガと誤って表示される。

「N = 4」の場合は、シリウス、カノープス、ケンタウルス座 α 星 A、アークトゥルスの 4 星が四面体を作り、どの領域も 3 頂点の球面三角形になる。
面積は 2.06 sr から 4.41 sr まで広がるが、和は $4\pi$ と $7.1\times10^{-16}$ の相対誤差で一致する。

## まとめ

天球上の角距離 $\theta_0$ 以内の星は、単位ベクトルに作った KD 木で弦の半径 $c_0 = 2\sin(\theta_0/2)$ の探索をすれば、漏れも余分もなく取り出せる。
見つけた星の角距離は $2\arcsin(c/2)$ で戻し、小さな角距離で精度を失う $\arccos$ の式は使わない。
探索の結果は単位ベクトルを使わない haversine の式の総当たりと個数・角距離の両方で照合でき、差は倍精度の丸めの大きさだった。
`SphericalVoronoi` の面積の和は $4\pi$ と $10^{-16}$ の桁で一致し、星の分布が疎な方向ほど領域が大きい。
`areas()` や `region()` の添字は正準添字なので、入力の行からは `input_mapping()` で写してから引く。
