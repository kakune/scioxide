`ConvexHull` は凸包の境界をファセットの集合として返し、2 次元でも辺を周の順には並べない。
凸包の面積や、周に沿った包含の判定には、ファセットの隣接関係をたどって頂点を周の順に並べ直す必要がある。
この例題では、正方形と円板の一様な点の凸包で周を復元し、面積を求める。
復元した周は頂点数と面積を結ぶ Efron の恒等式と、全点の包含、点の番号の対応で検算する。
頂点数の期待値そのものは[ランダム点群の凸包の頂点数](../convex-hull-random-points/)で扱う。

## 凸包のファセットと正準添字

凸包の境界をなす辺（3 次元以上では面）をファセットと呼ぶ。
`ConvexHull::new` は構成の最初に、点を座標の辞書式順序で整列し、座標が等しい点を 1 つにまとめる。
整列した点の番号を正準添字と呼ぶ。
`points()` は並べ替えた点の座標を正準添字の順に返し、`facet(i)` が返す番号も正準添字である。
入力の $i$ 行目は正準添字 `input_mapping()[i]` に移り、正準添字 $j$ の最初の入力行は `representatives()[j]` である。

2 次元の凸包のファセットは辺で、`facet(i)` は 2 つの番号を昇順に返すので、向きも周の順序も表さない。
`neighbors(i)` の $j$ 番目は、ファセット $i$ の $j$ 番目の頂点の向かいの稜を共有するファセットである。
2 次元では向かいの稜は他方の頂点なので、`neighbors(i)[j]` は、$j$ 番目でないほうの頂点を共有する隣の辺になる。
ある辺に頂点 $p$ から入ったら他方の頂点 $q$ へ進み、$q$ を共有する隣の辺へ移る。
これを繰り返すと、凸包の頂点を周に沿って並べられる。

`ConvexHull::build` は `new` と同じ構成を、実行コンテキストか求解コンテキストの下で行う。
取り消し、期限、外側の求解で数える節点数の上限を受け付ける点だけが違い、点を分けて追加する機能ではない。
得られる凸包は `new` と同じである。

## 面積の欠損と Efron の恒等式

凸な領域 $K$（面積 $A(K)$）に独立に一様な $n$ 点を置き、その凸包 $P_n$ の頂点数を $V_n$ とする。
凸包が覆わない部分の面積の割合を $D_n = 1 - A(P_n)/A(K)$ とする。
$n + 1$ 個目の点が凸包の頂点になるのは、それが残り $n$ 点の凸包の外にあるときである。
残りの $n$ 点を固定すると、その条件付き確率は $D_n$ に等しい。
$n + 1$ 点のどれも同じ立場にあるので、Efron（1965）の恒等式

$$
E[V_{n+1}] = (n + 1)\,E[D_n]
$$

が、どの凸領域でも厳密に成り立つ。
左辺は頂点の数、右辺は面積から求めるので、周の復元と面積の計算を頂点数と照らし合わせられる。
1 回ごとの差 $(n + 1)D_n - V_{n+1}$ の平均を標準誤差で割った $z$ が、0 から有意に離れないことを確かめる。

次のブロックはこのページのセルが共有する定義である。
`region_points` は正方形 $[0, 1)^2$ か単位円板の一様な点を $(x, y)$ の順で返す。
円板では半径を $\sqrt{u}$、角度を $2\pi v$（$u, v$ は $[0, 1)$ の一様乱数）とし、面積に比例した密度にする。
`region_area` は領域の面積を返す。
`construct_hull` は座標の先頭 `rows` 行の凸包を作り、`scoped` なら同じ構成を `build` で実行コンテキストの下で行う。
`hull_cycle` は `neighbors` をたどって凸包の頂点を周に沿って並べ、`site` は正準添字の座標を返す。
`shoelace_area` は周の列から、靴紐公式 $\tfrac12\sum_i (x_i y_{i+1} - x_{i+1} y_i)$ で符号付き面積を求める。

```rust
//| id: spatial-convex-hull-perimeter-model
//| kind: definitions
//| title: 一様な点と凸包の周
//| crates: [scioxide-core, scioxide-random, scioxide-spatial]
use scioxide_core::{ExecutionContext, SciOxideError, RealScalar};
use scioxide_random::{Rng, SplitMix64};
use scioxide_spatial::{ConvexHull, GeometryOptions, PointSet};

/// region が "disk" なら単位円板、それ以外なら単位正方形の一様な点 n 個を返す。
pub(crate) fn region_points(
    region: &str,
    n: usize,
    rng: &mut SplitMix64,
) -> Result<Vec<f64>, SciOxideError> {
    let mut coordinates = Vec::with_capacity(2 * n);
    for _ in 0..n {
        let (u, v): (f64, f64) = (rng.next_float()?, rng.next_float()?);
        if region == "disk" {
            let (radius, angle) = (RealScalar::sqrt(u), 2.0 * core::f64::consts::PI * v);
            coordinates.push(radius * RealScalar::cos(angle));
            coordinates.push(radius * RealScalar::sin(angle));
        } else {
            coordinates.push(u);
            coordinates.push(v);
        }
    }
    Ok(coordinates)
}

/// 領域の面積 A(K)。
pub(crate) fn region_area(region: &str) -> f64 {
    if region == "disk" {
        core::f64::consts::PI
    } else {
        1.0
    }
}

/// 座標の先頭 rows 行の凸包。scoped なら同じ構成を build で実行コンテキストの下で行う。
pub(crate) fn construct_hull(
    coordinates: &[f64],
    rows: usize,
    scoped: bool,
) -> Result<ConvexHull<f64>, SciOxideError> {
    let points = PointSet::from_rows(&coordinates[..2 * rows], 2)?;
    if scoped {
        ConvexHull::build(
            &points,
            GeometryOptions::new(),
            ExecutionContext::sequential(),
        )
    } else {
        ConvexHull::new(&points)
    }
}

/// 周に沿った頂点（正準添字）の列。ファセット f に頂点 prev から入ったら他方の頂点 next へ進み、
/// prev の向かいのファセット（next を共有するファセット）に移る。
pub(crate) fn hull_cycle(hull: &ConvexHull<f64>) -> Result<Vec<usize>, String> {
    let first = hull.facet(0).map_err(|e| e.to_string())?;
    let (start, mut prev, mut facet) = (first[0], first[0], 0);
    let mut order = vec![start];
    for _ in 0..hull.facet_count() {
        let ends = hull.facet(facet).map_err(|e| e.to_string())?;
        let slot = usize::from(ends[1] == prev);
        let next = ends[1 - slot];
        if next == start {
            break;
        }
        order.push(next);
        let across = hull.neighbors(facet).map_err(|e| e.to_string())?[slot];
        facet = across.ok_or("隣のファセットがない")?;
        prev = next;
    }
    Ok(order)
}

/// 正準添字 j の座標。
pub(crate) fn site(hull: &ConvexHull<f64>, j: usize) -> [f64; 2] {
    [hull.points()[2 * j], hull.points()[2 * j + 1]]
}

/// 靴紐公式による符号付き面積 ½ Σ (x_i y_{i+1} − x_{i+1} y_i)。正なら周は反時計回り。
pub(crate) fn shoelace_area(hull: &ConvexHull<f64>, order: &[usize]) -> f64 {
    (0..order.len())
        .map(|i| {
            let a = site(hull, order[i]);
            let b = site(hull, order[(i + 1) % order.len()]);
            0.5 * (a[0] * b[1] - b[0] * a[1])
        })
        .sum()
}
```

## Efron の恒等式の検算

次のセルは、領域、点の数 $n$、反復の回数 $M$、乱数のシードを選び、1 回ごとに $n + 1$ 点を作る。
最初の $n$ 点の凸包から頂点数 $V_n$ と面積の欠損 $D_n$ を、$n + 1$ 点すべての凸包から $V_{n+1}$ を求め、Efron の恒等式を確かめる。
凸包の面積は周に沿って並べた頂点から靴紐公式で求める。
表は $V_n$、$(n + 1)\bar D_n$、$V_{n+1}$ の平均と標準誤差、差 $(n + 1)D_n - V_{n+1}$ の $z$ を示す。
参考に、$V_n$ の平均と並べて Rényi–Sulanke の公式の値（正方形は $\tfrac83(\ln n + \gamma - \ln 2)$、円板は主要項 $3.3832\,n^{1/3}$）も示す。

```rust
//| id: spatial-convex-hull-efron
//| ref: spatial-convex-hull-efron
//| title: 面積の欠損と頂点数で Efron の恒等式を確かめる
//| run: reactive
//| uses: [spatial-convex-hull-perimeter-model]
//| crates: [scioxide-core, scioxide-random, scioxide-spatial]
//| inputs:
//|   region: {"type":"select","label":"領域","options":[{"label":"単位正方形","value":"square"},{"label":"単位円板","value":"disk"}],"value":"square"}
//|   point_count: {"type":"range","label":"点の数 n [個]","min":10,"max":1000,"step":10,"value":300}
//|   replicates: {"type":"range","label":"反復の回数 M","min":50,"max":400,"step":50,"value":200}
//|   seed: {"type":"range","label":"乱数のシード","min":1,"max":100,"step":1,"value":1}
//| cases:
//|   - {"id":"disk","label":"単位円板","description":"滑らかな境界では頂点が周全体に分布し、主要項は平均を上回る。","inputs":{"region":"disk"}}
//|   - {"id":"few-points","label":"n = 10","description":"点が少なくても Efron の恒等式は厳密に成り立つ。","inputs":{"point_count":10}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"efron","path":"/rows/0/2","approx":{"value":14.900935890661,"rtol":1e-10}}
//|       - {"artifact":"efron","path":"/rows/0/3","approx":{"value":15.009879682538,"rtol":1e-9}}
//|       - {"artifact":"efron","path":"/rows/0/7","range":{"min":-3,"max":3}}
//|   - case: disk
//|     expect:
//|       - {"artifact":"efron","path":"/rows/0/2","approx":{"value":22.648449473769,"rtol":1e-9}}
//|       - {"artifact":"efron","path":"/rows/0/7","range":{"min":-3,"max":3}}
//|   - case: few-points
//|     expect:
//|       - {"artifact":"efron","path":"/rows/0/5","approx":{"value":6.18,"atol":1e-9}}
//|       - {"artifact":"efron","path":"/rows/0/7","range":{"min":-3,"max":3}}
use scioxide_core::RealScalar;
use scioxide_random::{SeedableRng, SplitMix64};

let (n, m) = (point_count as usize, replicates as usize);
let mut rng = SplitMix64::from_seed(seed as u64);
let mut samples = Vec::with_capacity(m); // (V_n, D_n, V_{n+1})
for _ in 0..m {
    let coordinates = region_points(&region, n + 1, &mut rng).map_err(|e| e.to_string())?;
    let hull = construct_hull(&coordinates, n, false).map_err(|e| e.to_string())?;
    let order = hull_cycle(&hull)?;
    let deficit = 1.0 - shoelace_area(&hull, &order).abs() / region_area(&region);
    let larger = construct_hull(&coordinates, n + 1, false).map_err(|e| e.to_string())?;
    samples.push((
        hull.facet_count() as f64,
        deficit,
        larger.facet_count() as f64,
    ));
}

// 平均と標準誤差。差 (n + 1) D_n − V_{n+1} は同じ回の値どうしで作る。
let stats = |values: Vec<f64>| {
    let mean = values.iter().sum::<f64>() / m as f64;
    let variance = values.iter().map(|v| (v - mean) * (v - mean)).sum::<f64>() / (m - 1) as f64;
    (mean, RealScalar::sqrt(variance / m as f64))
};
let scale = (n + 1) as f64;
let (vertices, vertices_se) = stats(samples.iter().map(|s| s.0).collect());
let (efron, efron_se) = stats(samples.iter().map(|s| scale * s.1).collect());
let (next, next_se) = stats(samples.iter().map(|s| s.2).collect());
let (gap, gap_se) = stats(samples.iter().map(|s| scale * s.1 - s.2).collect());
// Rényi–Sulanke の値。Γ(5/3) と Euler の定数 γ は 16 桁の定数で与える。
let formula = if region == "disk" {
    2.0 * RealScalar::powf(core::f64::consts::PI, 2.0 / 3.0)
        * RealScalar::cbrt(2.0 / 3.0)
        * 0.902_745_292_950_933_6 // Γ(5/3)
        * RealScalar::cbrt(n as f64)
} else {
    8.0 / 3.0 * (RealScalar::ln(n as f64) + 0.577_215_664_901_532_9 - RealScalar::ln(2.0))
};
let fixed2 = serde_json::json!({ "fractionDigits": 2 });
let fixed3 = serde_json::json!({ "fractionDigits": 3 });
let columns = serde_json::json!([
    { "key": "0", "label": "V_n の平均 [個]", "type": "number", "format": fixed2 },
    { "key": "1", "label": "V_n の標準誤差 [個]", "type": "number", "format": fixed3 },
    { "key": "2", "label": "公式の値 [個]", "type": "number", "format": fixed2 },
    { "key": "3", "label": "(n + 1) D_n の平均 [個]", "type": "number", "format": fixed2 },
    { "key": "4", "label": "(n + 1) D_n の標準誤差 [個]", "type": "number", "format": fixed3 },
    { "key": "5", "label": "V_(n+1) の平均 [個]", "type": "number", "format": fixed2 },
    { "key": "6", "label": "V_(n+1) の標準誤差 [個]", "type": "number", "format": fixed3 },
    { "key": "7", "label": "Efron の差の z [-]", "type": "number", "format": fixed2 }
]);
let row = (
    vertices,
    vertices_se,
    formula,
    efron,
    efron_se,
    next,
    next_se,
    gap / gap_se,
);
emit_table_with_columns!(
    columns,
    vec![row],
    metadata = serde_json::json!({ "id": "efron" })
);
```

既定値（正方形、$n = 300$、$M = 200$、シード 1）では、$V_n$ の平均 $14.92 \pm 0.17$ が公式の $14.90$ と合う。
$(n + 1)\bar D_n = 15.01 \pm 0.26$ と $V_{n+1}$ の平均 $14.94 \pm 0.17$ の差は $z = 0.29$ で、Efron の恒等式と矛盾しない。
円板では $V_n$ の平均が $22.47$ で主要項 $22.65$ を下回り、Efron の差は $z = -0.63$ である。
$n = 10$ でも、$(n + 1)\bar D_n = 6.20 \pm 0.08$ と $V_{n+1}$ の平均 $6.18$ は恒等式どおりに合う。
周の復元か面積の計算に誤りがあれば、$(n + 1)\bar D_n$ だけがずれて $z$ が大きくなる。

## 包含と番号の対応の検査

次のセルは、領域、点の数 $n$、乱数のシードを選んで 1 組の点の凸包を作り、次の 3 つを確かめる。

- 入力のすべての点が凸包に含まれること。
  周に沿った各辺 $(a, b)$ と各点 $p$ について、`orient2d(a, b, p)` が周の向きと逆の符号になる点を数える。
- 凸包の頂点（正準添字 $j$）の座標が、入力の行 `representatives()[j]` の座標と等しく、その行が `input_mapping()` で $j$ に戻ること。
- `ConvexHull::build` に `ExecutionContext::sequential()` を渡した結果が、`new` と同じファセットを持つこと。

表は検査の結果で、どの数も 0 なら検査を通ったことになる。
グラフは入力の点と、周の順に結んだ凸包である。

```rust
//| id: spatial-convex-hull-checks
//| ref: spatial-convex-hull-checks
//| title: 凸包の包含と番号の対応を確かめる
//| run: reactive
//| uses: [spatial-convex-hull-perimeter-model]
//| crates: [scioxide-core, scioxide-random, scioxide-spatial]
//| inputs:
//|   region: {"type":"select","label":"領域","options":[{"label":"単位正方形","value":"square"},{"label":"単位円板","value":"disk"}],"value":"square"}
//|   point_count: {"type":"range","label":"点の数 n [個]","min":10,"max":1000,"step":10,"value":300}
//|   seed: {"type":"range","label":"乱数のシード","min":1,"max":100,"step":1,"value":1}
//| cases:
//|   - {"id":"disk","label":"単位円板","description":"滑らかな境界では頂点が周全体に分布する。","inputs":{"region":"disk"}}
//|   - {"id":"few-points","label":"n = 10","description":"点が少なくても包含と番号の対応は保たれる。","inputs":{"point_count":10}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"checks","path":"/rows/0/1","equals":16}
//|       - {"artifact":"checks","path":"/rows/0/2","equals":0}
//|       - {"artifact":"checks","path":"/rows/0/3","equals":0}
//|       - {"artifact":"checks","path":"/rows/0/4","equals":0}
//|   - case: disk
//|     expect:
//|       - {"artifact":"checks","path":"/rows/0/1","equals":22}
//|       - {"artifact":"checks","path":"/rows/0/2","equals":0}
//|       - {"artifact":"checks","path":"/rows/0/3","equals":0}
//|   - case: few-points
//|     expect:
//|       - {"artifact":"checks","path":"/rows/0/1","equals":4}
//|       - {"artifact":"checks","path":"/rows/0/2","equals":0}
//|       - {"artifact":"checks","path":"/rows/0/4","equals":0}
use scioxide_random::{SeedableRng, SplitMix64};
use scioxide_spatial::{PredicateSign, orient2d};

let n = point_count as usize;
let mut rng = SplitMix64::from_seed(seed as u64);
let coordinates = region_points(&region, n, &mut rng).map_err(|e| e.to_string())?;
let hull = construct_hull(&coordinates, n, false).map_err(|e| e.to_string())?;
let order = hull_cycle(&hull)?;
// 周が反時計回り（面積が正）なら、凸包の外の点は orient2d が負になる。
let wrong = if shoelace_area(&hull, &order) > 0.0 {
    PredicateSign::Negative
} else {
    PredicateSign::Positive
};
// 包含: 周のどれかの辺に対して逆向きの側にある点を数える。
let mut outside = 0;
for p in coordinates.chunks_exact(2) {
    let mut escaped = false;
    for i in 0..order.len() {
        let a = site(&hull, order[i]);
        let b = site(&hull, order[(i + 1) % order.len()]);
        let sign = orient2d(&a, &b, &[p[0], p[1]]).map_err(|e| e.to_string())?;
        escaped |= sign == wrong;
    }
    outside += usize::from(escaped);
}
// 番号の対応: 正準添字 j → 入力の行 representatives()[j] → input_mapping() で j に戻るか。
let mismatched = order
    .iter()
    .filter(|&&j| {
        let row = hull.representatives()[j];
        coordinates[2 * row..2 * row + 2] != site(&hull, j) || hull.input_mapping()[row] != j
    })
    .count();
let built = construct_hull(&coordinates, n, true).map_err(|e| e.to_string())?;
let differing = (0..hull.facet_count().max(built.facet_count()))
    .filter(|&i| hull.facet(i).ok() != built.facet(i).ok())
    .count();

let check_columns = serde_json::json!([
    { "key": "0", "label": "凸包のファセット [本]", "type": "integer" },
    { "key": "1", "label": "周に沿った頂点 [個]", "type": "integer" },
    { "key": "2", "label": "凸包の外に出た点 [個]", "type": "integer" },
    { "key": "3", "label": "番号の対応の不一致 [個]", "type": "integer" },
    { "key": "4", "label": "build と new で異なるファセット [本]", "type": "integer" }
]);
let summary = (
    hull.facet_count(),
    order.len(),
    outside,
    mismatched,
    differing,
);
emit_table_with_columns!(
    check_columns,
    vec![summary],
    metadata = serde_json::json!({ "id": "checks" })
);
let polygon: Vec<[f64; 2]> = order
    .iter()
    .chain(order.first())
    .map(|&j| site(&hull, j))
    .collect();
let cloud: Vec<[f64; 2]> = coordinates.chunks_exact(2).map(|p| [p[0], p[1]]).collect();
let (low, high) = if region == "disk" {
    (-1.05, 1.05)
} else {
    (-0.05, 1.05)
};
emit_chart!(
    serde_json::json!({
        "kind": "xy",
        "xLabel": "x [-]",
        "yLabel": "y [-]",
        "xMin": low,
        "xMax": high,
        "yMin": low,
        "yMax": high,
        "dataZoom": true,
        "tooltip": true,
        "layers": [
            { "id": "points", "kind": "scatter", "name": "点", "points": cloud },
            { "id": "hull", "kind": "line", "name": "凸包", "points": polygon }
```

既定値（正方形、$n = 300$、シード 1）の凸包は 16 本のファセットを持ち、周に沿ってたどった頂点も 16 個だった。
凸包の外に出た点、番号の対応の不一致、`build` と `new` で異なるファセットはどれも 0 である。
円板では 22 本、$n = 10$ では 4 本のファセットで、どちらも周の頂点の数がファセットの数に等しく、検査の数はすべて 0 になる。
グラフでは、点がすべて凸包の内側か周の上にある。

## まとめ

`ConvexHull` の 2 次元のファセットは昇順の番号の組で、周の順序は `neighbors` で隣の辺をたどって復元する。
復元した周の靴紐公式の面積は、Efron の恒等式 $E[V_{n+1}] = (n + 1)E[D_n]$ で頂点数と照らし合わせられ、この恒等式はどの凸領域でも厳密に成り立つ。
恒等式の比較は同じ回の差 $(n + 1)D_n - V_{n+1}$ の平均と標準誤差から求めた $z$ で判断する。
包含は周の各辺に対する `orient2d` の符号で厳密に判定でき、周の向きは面積の符号で決める。
`ConvexHull` の番号は並べ替えた点の正準添字なので、入力の行には `representatives` と `input_mapping` で戻す。
