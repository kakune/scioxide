平面の領域に一様に散らばった $n$ 点の凸包は、頂点が何個になるか。
答えは領域の境界の形で大きく変わり、多角形なら $\ln n$、滑らかな凸領域なら $n^{1/3}$ に比例して増える。
頂点数は凸包のアルゴリズムが出力する点の数で、出力の大きさに依存するアルゴリズムの計算量も左右する。
この例題では、`ConvexHull` で正方形と円板の一様な点の凸包を作り、頂点数の平均を Rényi–Sulanke の公式と比べる。

## 凸包の頂点数の期待値

凸な領域 $K$（面積 $A(K)$）に独立に一様な $n$ 点を置き、その凸包 $P_n$ の頂点数を $V_n$ とする。
Rényi と Sulanke（1963、1964）は、期待値 $E[V_n]$ の漸近形を境界の形に分けて求めた。

$K$ が $r$ 個の頂点を持つ凸多角形なら

$$
E[V_n] = \frac{2r}{3}\left(\ln n + \gamma\right) + \frac{2}{3}\sum_{i=1}^{r} \ln\frac{A(T_i)}{A(K)} + o(1)
$$

である。
$\gamma = 0.5772\ldots$ は Euler の定数、$T_i$ は多角形の連続する 3 頂点 $v_{i-1}, v_i, v_{i+1}$ を結ぶ三角形である。
凸包の頂点は多角形の角の近くに集まり、1 つの角あたり $\tfrac{2}{3}\ln n$ 個ずつ増える。
単位正方形では $r = 4$、$A(T_i)/A(K) = 1/2$ なので

$$
E[V_n] = \frac{8}{3}\left(\ln n + \gamma - \ln 2\right) + o(1)
$$

になり、$n = 300$ で $14.90$ である。

$K$ の境界が滑らかで曲率 $\kappa > 0$ を持つなら

$$
E[V_n] \sim \left(\frac{2}{3A(K)}\right)^{1/3} \Gamma\!\left(\tfrac{5}{3}\right) \left(\int_{\partial K} \kappa^{1/3}\,ds\right) n^{1/3}
$$

である。
$s$ は境界 $\partial K$ に沿った弧長である。
単位円板では $\kappa = 1$、$\int ds = 2\pi$、$A(K) = \pi$ なので、係数は $2\pi^{2/3}(2/3)^{1/3}\Gamma(5/3) = 3.3832$ になる。
この式は主要項だけである。
次の項は $n$ とともに相対的に小さくなるが、その減り方は遅い。
下のセルの既定値では $n = 2000$ までのどの $n$ でも、測った平均が主要項を下回る。
正方形の式も $o(1)$ の誤差を含むので、$n$ が小さいところでは実測とわずかにずれる。

次のブロックは、比較の 2 つのセルが共有する公式である。
`square_formula` は単位正方形の $\tfrac83(\ln n + \gamma - \ln 2)$、`disk_leading_term` は単位円板の主要項 $3.3832\,n^{1/3}$ を返す。
$\Gamma(5/3)$ と $\gamma$ は 16 桁の定数で与える。

```rust
//| id: spatial-convex-hull-formulas
//| kind: definitions
//| title: Rényi–Sulanke の公式
//| crates: [scioxide-core]
use scioxide_core::RealScalar;

/// Euler の定数 γ。
pub(crate) const EULER_GAMMA: f64 = 0.577_215_664_901_532_9;

/// Γ(5/3)。
pub(crate) const GAMMA_FIVE_THIRDS: f64 = 0.902_745_292_950_933_6;

/// 単位円板の主要項の係数 2π^(2/3) (2/3)^(1/3) Γ(5/3)。
pub(crate) fn disk_coefficient() -> f64 {
    let pi = core::f64::consts::PI;
    2.0 * RealScalar::powf(pi, 2.0 / 3.0) * RealScalar::cbrt(2.0 / 3.0) * GAMMA_FIVE_THIRDS
}

/// 単位正方形の E[V_n] ≈ (8/3)(ln n + γ − ln 2)。
pub(crate) fn square_formula(n: f64) -> f64 {
    8.0 / 3.0 * (RealScalar::ln(n) + EULER_GAMMA - RealScalar::ln(2.0))
}

/// 単位円板の E[V_n] の主要項 3.3832 n^(1/3)。
pub(crate) fn disk_leading_term(n: f64) -> f64 {
    disk_coefficient() * RealScalar::cbrt(n)
}
```

## 頂点数の数え方と構成の計算量

`ConvexHull::new` は、乱択逐次添加で凸包を作る。
凸包の境界をなす辺（3 次元以上では面）をファセットと呼ぶ。
各点の挿入では、その点から見えるファセットを `orient2d` と同じ厳密な向きの判定で見つけて取り除き、境界を張り直す。
挿入の順序は座標の辞書式順序で整列した点の番号から固定の擬似乱数で決める。
そのため、結果は入力の行の順序によらず、毎回同じになる。
Clarkson と Shor（1989）の解析では、平面での期待計算量は $O(n\log n)$ である。

2 次元の凸包ではファセット（辺）の数と頂点の数が等しいので、頂点数は `facet_count()` で数えられる。
`provenance().predicate_terms` は、構成で評価した述語の計算量を返す。
符号の評価 1 回を 1 処理単位とし、浮動小数点のフィルタで決まらず厳密に評価したときは、行列式の展開の項数を加える。
ファセットを周の順に並べる方法と、点の番号と入力の行の対応は、[凸包の周の復元と面積の欠損](../convex-hull-perimeter/)で扱う。

## 頂点数の平均と点の数

次のセルは、点の数 $n$ を 10 から上限まで 1–2–5 の刻みで増やし、各 $n$ と各領域で $M$ 回ずつ凸包を作って頂点数を数える。
正方形は $[0, 1)^2$ で、座標は $[0, 1)$ の一様乱数 $u, v$ をそのまま使う。
円板は単位円板で、半径を $\sqrt{u}$、角度を $2\pi v$ として、面積に比例した密度にする。
乱数は生成器 `SplitMix64` から `Rng::next_float` で直接引き、シードを変えると独立な標本になる。
表は $n$ ごとに、2 つの領域の頂点数の平均と標準誤差（$M$ 回の標本標準偏差 $/\sqrt{M}$）、1 点あたりの述語の計算量を示す。
計算は既定値でも数万個の凸包を作るので、ボタンで実行し、同じ入力の結果は保存して使い回す。
平均と標準誤差は、後の 2 つのセルに渡す。

```rust
//| id: spatial-convex-hull-renyi-sulanke
//| ref: spatial-convex-hull-renyi-sulanke
//| title: 点の数ごとに凸包の頂点数を数える

//| cache: inputs

//| exports: [square, disk]
//| inputs:
//|   largest: {"type":"range","label":"点の数の上限 [個]","min":1000,"max":10000,"step":1000,"value":5000}
//|   replicates: {"type":"range","label":"各 n の反復の回数 M","min":10,"max":200,"step":10,"value":100}
//|   seed: {"type":"range","label":"乱数のシード","min":1,"max":100,"step":1,"value":1}
//| cases:
//|   - {"id":"largest-1000","label":"上限 1000 点","description":"n = 1000 までの 7 行になり、同じシードの乱数列なので各行の値は既定値の表と同じになる。","inputs":{"largest":1000}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"sweep","path":"/rows/8/0","equals":5000}
//|       - {"artifact":"sweep","path":"/rows/4/1","approx":{"value":13.91,"atol":1e-9}}
//|       - {"artifact":"sweep","path":"/rows/8/3","approx":{"value":57.88,"atol":1e-9}}

//|   - case: largest-1000

//|       - {"artifact":"sweep","path":"/rowCount","equals":7}
//|       - {"artifact":"sweep","path":"/rows/6/1","approx":{"value":18.33,"atol":1e-9}}
use scioxide_core::{SciOxideError, RealScalar};
use scioxide_random::{Rng, SeedableRng, SplitMix64};
use scioxide_spatial::{ConvexHull, PointSet};

// region が "disk" なら単位円板、それ以外なら単位正方形の一様な点 n 個を (x, y) の順で書く。
fn region_points(
    region: &str,
    n: usize,
    rng: &mut SplitMix64,
    coordinates: &mut Vec<f64>,
) -> Result<(), SciOxideError> {
    coordinates.clear();
    for _ in 0..n {
        let (u, v): (f64, f64) = (rng.next_float()?, rng.next_float()?);
        if region == "disk" {
            let (radius, angle) = (RealScalar::sqrt(u), 2.0 * core::f64::consts::PI * v);
            coordinates.push(radius * RealScalar::cos(angle));
            coordinates.push(radius * RealScalar::sin(angle));
        } else {
            coordinates.push(u);
            coordinates.push(v);
        }
    }
    Ok(())
}

let m = replicates as usize;
let sizes = [10, 20, 50, 100, 200, 500, 1000, 2000, 5000, 10000];
let mut rng = SplitMix64::from_seed(seed as u64);

for n in sizes.into_iter().filter(|&n| n as f64 <= largest) {
    for (region, summary) in [("square", &mut square), ("disk", &mut disk)] {
        let (mut counts, mut work) = (Vec::with_capacity(m), 0.0);
        for _ in 0..m {
            region_points(region, n, &mut rng, &mut coordinates).map_err(|e| e.to_string())?;
            let points = PointSet::from_rows(&coordinates, 2).map_err(|e| e.to_string())?;
            let hull = ConvexHull::new(&points).map_err(|e| e.to_string())?;

            counts.push(hull.facet_count() as f64);
            work += hull.provenance().predicate_terms as f64 / n as f64;

        let mean = counts.iter().sum::<f64>() / m as f64;
        let variance =
            counts.iter().map(|v| (v - mean) * (v - mean)).sum::<f64>() / (m - 1) as f64;
        let se = RealScalar::sqrt(variance / m as f64);
        summary.push([n as f64, mean, se, work / m as f64]);
    }
}

]);
let rows: Vec<(usize, f64, f64, f64, f64, f64, f64)> = square
    .iter()
    .zip(&disk)
    .map(|(s, d)| (s[0] as usize, s[1], s[2], d[1], d[2], s[3], d[3]))
    .collect();
emit_table_with_columns!(

    metadata = serde_json::json!({ "id": "sweep" })
```

既定値（上限 5000 点、$M = 100$、シード 1）では、正方形の平均頂点数は $n = 10$ の $5.92$ から $n = 5000$ の $22.70$ まで増える。
$n$ が 10 倍になるごとに約 6 個ずつ増え、$\tfrac83\ln 10 = 6.14$ に近い。
円板では $6.13$ から $57.88$ まで増え、$n = 5000$ で正方形の 2.5 倍になる。
1 点あたりの述語の計算量は $n$ によらず 5〜9 処理単位で、一様な点では構成の計算量が $n$ にほぼ比例した。

## Rényi–Sulanke の公式との比較

次のセルは前のセルの平均と標準誤差を受け取り、Rényi–Sulanke の公式と比べる。
グラフの横軸は点の数 $n$ の対数軸で、実測の平均を記号、公式を破線で描く。
正方形の公式は $\ln n$ の 1 次式なので対数軸の上で直線になり、円板の主要項 $3.3832\,n^{1/3}$ は上に曲がる。
表は $n$ ごとに、正方形の $z = (\bar V - E[V_n])/\mathrm{SE}$ と、円板の平均と主要項の比を示す。
$\bar V$ は $M$ 回の平均、SE はその標準誤差である。
$|z|$ が 2 を大きく超える $n$ が続けば、公式か計数のどちらかに問題がある。

小さな $n$ では式の $o(1)$ の誤差も残る。
円板の平均と主要項の比は $n = 100$ の 0.969 から、0.956〜0.992 を経て $n = 5000$ の 1.000 に近づく。

## 増え方の傾き

点ごとの比較に加えて、増え方の係数そのものを確かめる。
次のセルは、正方形の平均を $x = \ln n$ に、円板の平均を $x = n^{1/3}$ に最小二乗で当てはめ、傾きを理論の係数 $8/3$ と $3.3832$ と比べる。
小さな $n$ の $o(1)$ の誤差を避けるため、$n \ge 100$ の点だけを使う。
傾き $\hat\beta = \sum_k (x_k - \bar x)(\bar V_k - \overline{V}) / \sum_k (x_k - \bar x)^2$ は平均 $\bar V_k$ の 1 次式なので、その標準誤差は各平均の標準誤差 $\mathrm{SE}_k$ から $\bigl(\sum_k w_k^2\,\mathrm{SE}_k^2\bigr)^{1/2}$、$w_k = (x_k - \bar x)/\sum_j (x_j - \bar x)^2$ で伝える。
$n \ge 100$ の点が 3 個に満たないときは、傾きを出さない。

```rust
//| id: spatial-convex-hull-slopes
//| ref: spatial-convex-hull-slopes
//| title: 頂点数の増え方の傾きを理論の係数と比べる
//| run: reactive
//| uses: [spatial-convex-hull-formulas]
//| crates: [scioxide-core]
//| dependsOn:
//|   sweep: spatial-convex-hull-renyi-sulanke
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"slopes","path":"/rows/0/1","range":{"min":2.4,"max":2.95}}
//|       - {"artifact":"slopes","path":"/rows/0/3","approx":{"value":2.666666666667,"rtol":1e-10}}
//|       - {"artifact":"slopes","path":"/rows/1/1","range":{"min":3.38,"max":3.5}}
//|       - {"artifact":"slopes","path":"/rows/1/3","approx":{"value":3.383228965797,"rtol":1e-10}}
use scioxide_core::RealScalar;

let square: Vec<[f64; 4]> =
    serde_json::from_value(sweep["square"].clone()).map_err(|e| e.to_string())?;
let disk: Vec<[f64; 4]> =
    serde_json::from_value(sweep["disk"].clone()).map_err(|e| e.to_string())?;

// n ≥ 100 の平均を x に最小二乗で当てはめた傾きと、平均の標準誤差から伝えた傾きの標準誤差。
let slope = |rows: &[[f64; 4]], x: fn(f64) -> f64| -> (Option<f64>, Option<f64>) {
    let used: Vec<[f64; 3]> = rows
        .iter()
        .filter(|r| r[0] >= 100.0)
        .map(|r| [x(r[0]), r[1], r[2]])
        .collect();
    if used.len() < 3 {
        return (None, None);
    }
    let k = used.len() as f64;
    let (mx, my) = used
        .iter()
        .fold((0.0, 0.0), |(a, b), r| (a + r[0] / k, b + r[1] / k));
    let sxx: f64 = used.iter().map(|r| (r[0] - mx) * (r[0] - mx)).sum();
    let sxy: f64 = used.iter().map(|r| (r[0] - mx) * (r[1] - my)).sum();
    let variance: f64 = used
        .iter()
        .map(|r| ((r[0] - mx) / sxx) * ((r[0] - mx) / sxx) * r[2] * r[2])
        .sum();
    (Some(sxy / sxx), Some(RealScalar::sqrt(variance)))
};
let (square_slope, square_se) = slope(&square, RealScalar::ln);
let (disk_slope, disk_se) = slope(&disk, RealScalar::cbrt);
let fits = vec![
    (
        "正方形: ln n に対する傾き",
        square_slope,
        square_se,
        8.0 / 3.0,
    ),
    (
        "円板: n^(1/3) に対する傾き",
        disk_slope,
        disk_se,
        disk_coefficient(),
    ),
];
let fixed4 = serde_json::json!({ "fractionDigits": 4 });
let fit_columns = serde_json::json!([
    { "key": "0", "label": "当てはめ" },
    { "key": "1", "label": "実測の傾き [個]", "type": "number", "format": fixed4, "nullText": "点が足りない" },
    { "key": "2", "label": "傾きの標準誤差 [個]", "type": "number", "format": fixed4, "nullText": "—" },
    { "key": "3", "label": "理論の係数 [個]", "type": "number", "format": fixed4 }
]);
emit_table_with_columns!(
    fit_columns,
    fits,
    metadata = serde_json::json!({ "id": "slopes" })
);
```

正方形の傾きは $2.72 \pm 0.08$ で、理論の $8/3$ と標準誤差の範囲で合う。
円板の傾き $3.437 \pm 0.029$ は係数 $3.3832$ より標準誤差の 1.8 倍大きい。
円板の平均は主要項より小さく、その差は $n = 200$ の 0.87 から $n = 5000$ の −0.03 へと大きな $n$ で縮むので、$n^{1/3}$ に対する傾きは係数より大きくなる。
傾きで係数を確かめるときは、この次の項による偏りも考える。

## まとめ

正方形の一様な点の凸包の頂点数は $\tfrac83(\ln n + \gamma - \ln 2)$ で増え、$n = 5000$ でも平均 23 個程度にとどまる。
円板では $3.3832\,n^{1/3}$ で増え、この主要項は $n = 100$〜$2000$ の実測の平均を 0.8〜4.6% 上回った。
頂点数に比例する後処理（周の走査、包含の判定）の計算コストを見積もるときは、領域の境界が多角形か滑らかかを先に確かめる。
期待値との比較は反復した平均の標準誤差と $z$ で判断し、傾きの比較では次の項による偏りも考える。
2 次元の凸包の頂点数は `facet_count()` で数えられ、`provenance().predicate_terms` は構成の計算量が一様な点で $n$ にほぼ比例することを示す。
