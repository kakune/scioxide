Voronoi 図は Delaunay 分割の双対で、Voronoi の頂点は Delaunay の三角形の外心である。
位相（どの三角形がどの頂点に対応するか）は厳密に決まるが、頂点の座標は丸めた値である。
この例題では、`Voronoi` の頂点を外心の独立な式と比べて座標の精度を測り、三角形と頂点の数を Euler の公式と照合する。
点の配置は[Delaunay 分割の最小角最大化](../delaunay-min-angle/)と同じ乱数で作り、ほぼ共円の点と厳密に共円の点での違いを見る。

## 外心と Voronoi の頂点

平面の $N$ 点の Delaunay 分割で、凸包の境界にある点の数を $h$ とすると、Euler の公式から三角形の数は $2N - h - 2$ である。
凸包の境界にある点（凸包の辺の途中にある点も含む）は、Voronoi 領域が有界でない点にちょうど一致する。
そこで、`region_is_unbounded` で数えた $h$ から三角形の数を予測し、`Delaunay` の三角形の数と比べる。

4 点以上が同じ円周上にあると、Delaunay 分割は記号摂動で三角形に分けられ、同じ外接円を持つ三角形が隣り合う。
`Voronoi` は、厳密に同じ円周上にある隣り合う三角形の組に頂点を 1 つだけ割り当て、`simplex_vertices()` が三角形ごとの頂点の番号を返す。
そのため、整数格子の正方形を 2 つに分けた三角形は、1 つの Voronoi の頂点を共有する。
入力の行と点の番号の対応は、`Voronoi` が持つ `Delaunay` の `input_mapping` で得る。

頂点の座標は構成のときに丸めて計算する。
三角形の頂点 $a$ を原点に移し、$a$ から出る 2 辺のベクトル $e_1, e_2$ を列に並べた $2\times 2$ 行列を $E$ とする。
外心 $c$ は $E^{\mathsf T} c = \tfrac12(|e_1|^2, |e_2|^2)^{\mathsf T}$ を満たすので、$E$ の逆行列から求める。
$E$ を最大の成分が 1 になるように縮めたうえで、逆行列の成分の最大の大きさを $\|E^{-1}\|$ とすると、$\|E^{-1}\|\,\varepsilon\,d^2 > \sqrt{\varepsilon}$（$\varepsilon$ は機械イプシロン、$d = 2$）の三角形は悪条件として外心を使わない。
外接円が同じ三角形の組では番号の最も小さい使える三角形の外心を頂点にし、組のどの三角形も悪条件なら、その頂点の `vertex` は `NumericalInstability` を返す。
そのときも、他の頂点と位相の情報は使える。
頂点の座標に誤差の上界は与えられていない。

参照の外心は、$b' = b - a$、$c' = c - a$、$D = 2(b'_x c'_y - b'_y c'_x)$ として

$$
u_x = \frac{c'_y |b'|^2 - b'_y |c'|^2}{D}, \qquad u_y = \frac{b'_x |c'|^2 - c'_x |b'|^2}{D}
$$

とおいた $a + u$ である。
これは Cramer の公式による解で、SciOxide の逆行列とは別の計算になる。
$|u|$ は外接円の半径なので、相対差 $|v - (a + u)|/|u|$ は半径に対する頂点 $v$ のずれを表す。

## 外心の照合

次のセルは、点の数 $N$、点の配置、乱数のシードを選んで `Voronoi::new` を作り、各三角形の外心を参照の式で求めて頂点と比べる。
配置は 3 通りである。
「一様」は単位正方形の一様な点、「円周上」は単位円の上の一様な角度の点（座標は `f64` に丸めるので、共円は丸めの範囲でしか成り立たない）、「整数格子」は $\lceil\sqrt{N}\,\rceil$ 列の整数格子の点である。
1 つ目の表は組合せの検算で、重複をまとめた点の数 $N$、凸包の境界の点の数 $h$、三角形の数と $2N - h - 2$、Voronoi の頂点の数、頂点を共有する三角形の数、入力の行と対応する正準添字とで座標が食い違う行の数、記号摂動の有無を示す。
2 つ目の表は、外心との相対差の最大値、頂点から三角形の 3 頂点までの距離の相対的なばらつき $(\max - \min)/\max$ の最大値、頂点を計算できなかった三角形の数を示す。
外心の計算は参照値の計算なので、`f64` の四則演算で書き、長さは `RealScalar::hypot` で求める。

```rust
//| id: spatial-delaunay-voronoi-circumcenters
//| ref: spatial-delaunay-voronoi-circumcenters
//| title: 外心と Voronoi の頂点を照合する
//| run: reactive
//| crates: [scioxide-core, scioxide-random, scioxide-spatial]
//| inputs:
//|   site_count: {"type":"range","label":"点の数 N","min":20,"max":400,"step":10,"value":100}
//|   configuration: {"type":"select","label":"点の配置","options":[{"label":"一様（単位正方形）","value":"uniform"},{"label":"円周上（ほぼ共円）","value":"circle"},{"label":"整数格子（厳密に共円）","value":"lattice"}],"value":"uniform"}
//|   seed: {"type":"range","label":"乱数のシード","min":1,"max":100,"step":1,"value":1}
//| cases:
//|   - {"id":"circle","label":"円周上の 100 点","description":"3 点が円周上で近い細い三角形では、外心との相対差が大きくなる。","inputs":{"configuration":"circle"}}
//|   - {"id":"lattice","label":"整数格子","description":"正方形を分けた 2 つの三角形が 1 つの頂点を共有し、記号摂動が働く。","inputs":{"configuration":"lattice"}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"combinatorics","path":"/rows/0/1","equals":14}
//|       - {"artifact":"combinatorics","path":"/rows/0/2","equals":184}
//|       - {"artifact":"combinatorics","path":"/rows/0/3","equals":184}
//|       - {"artifact":"combinatorics","path":"/rows/0/6","equals":0}
//|       - {"artifact":"circumcenters","path":"/rows/0/0","range":{"max":1e-12}}
//|       - {"artifact":"circumcenters","path":"/rows/0/2","equals":0}
//|   - case: circle
//|     expect:
//|       - {"artifact":"combinatorics","path":"/rows/0/1","equals":100}
//|       - {"artifact":"combinatorics","path":"/rows/0/2","equals":98}
//|       - {"artifact":"circumcenters","path":"/rows/0/0","range":{"max":1e-10}}
//|   - case: lattice
//|     expect:
//|       - {"artifact":"combinatorics","path":"/rows/0/1","equals":36}
//|       - {"artifact":"combinatorics","path":"/rows/0/2","equals":162}
//|       - {"artifact":"combinatorics","path":"/rows/0/4","equals":81}
//|       - {"artifact":"combinatorics","path":"/rows/0/5","equals":162}
//|       - {"artifact":"circumcenters","path":"/rows/0/0","equals":0}
use scioxide_core::{SciOxideError, RealScalar};
use scioxide_random::{Rng, SeedableRng, SplitMix64};
use scioxide_spatial::{PointSet, Voronoi};

// 配置 configuration の点 n 個を、1 行 1 点の (x, y) の順で返す。
fn sites(configuration: &str, n: usize, seed: u64) -> Result<Vec<f64>, SciOxideError> {
    let mut rng = SplitMix64::from_seed(seed);
    let mut coordinates: Vec<f64> = Vec::with_capacity(2 * n);
    if configuration == "lattice" {
        // ⌈√n⌉ 列の整数格子。正方形の 4 頂点は厳密に共円になる。
        let mut columns = 1;
        while columns * columns < n {
            columns += 1;
        }
        for i in 0..n {
            coordinates.push((i % columns) as f64);
            coordinates.push((i / columns) as f64);
        }
    } else if configuration == "circle" {
        for _ in 0..n {
            let uniform: f64 = rng.next_float()?;
            let angle = 2.0 * core::f64::consts::PI * uniform;
            coordinates.push(RealScalar::cos(angle));
            coordinates.push(RealScalar::sin(angle));
        }
    } else {
        for _ in 0..2 * n {
            coordinates.push(rng.next_float()?);
        }
    }
    Ok(coordinates)
}

let n = site_count as usize;
let coordinates = sites(&configuration, n, seed as u64).map_err(|e| e.to_string())?;
let points = PointSet::from_rows(&coordinates, 2).map_err(|e| e.to_string())?;
let voronoi = Voronoi::new(&points).map_err(|e| e.to_string())?;
let delaunay = voronoi.delaunay();
let canonical = delaunay.points();
let unique = canonical.len() / 2;

// 入力の行 i は正準添字 input_mapping()[i] に移る。座標が一致しない行を数える。
let mapping = delaunay.input_mapping();
let moved = (0..n)
    .filter(|&i| canonical[2 * mapping[i]..2 * mapping[i] + 2] != coordinates[2 * i..2 * i + 2])
    .count();
let mut hull = 0;
for site in 0..unique {
    let unbounded = voronoi
        .region_is_unbounded(site)
        .map_err(|e| e.to_string())?;
    hull += usize::from(unbounded);
}
let mut sharing = vec![0_usize; voronoi.vertex_count()];
for &vertex in voronoi.simplex_vertices() {
    sharing[vertex] += 1;
}
let shared = sharing.iter().filter(|&&c| c > 1).sum::<usize>();

// 参照の外心 a + u（Cramer の公式）と Voronoi の頂点の相対差、頂点から 3 頂点までの距離のばらつき。
let (mut center_gap, mut spread, mut failed) = (0.0_f64, 0.0_f64, 0);
for simplex in 0..delaunay.simplex_count() {
    let corner = |i: usize| -> Result<[f64; 2], String> {
        let site = delaunay.simplex(simplex).map_err(|e| e.to_string())?[i];
        Ok([canonical[2 * site], canonical[2 * site + 1]])
    };
    let [a, b, c] = [corner(0)?, corner(1)?, corner(2)?];
    let (bx, by, cx, cy) = (b[0] - a[0], b[1] - a[1], c[0] - a[0], c[1] - a[1]);
    let (b2, c2, det) = (
        bx * bx + by * by,
        cx * cx + cy * cy,
        2.0 * (bx * cy - by * cx),
    );
    let u = [(cy * b2 - by * c2) / det, (bx * c2 - cx * b2) / det];
    let radius = RealScalar::hypot(u[0], u[1]);
    let Ok(vertex) = voronoi.vertex(voronoi.simplex_vertices()[simplex]) else {
        failed += 1;
        continue;
    };
    let gap = RealScalar::hypot(vertex[0] - a[0] - u[0], vertex[1] - a[1] - u[1]);
    center_gap = center_gap.max(gap / radius);
    let reach = [a, b, c].map(|p| RealScalar::hypot(vertex[0] - p[0], vertex[1] - p[1]));
    let (low, high) = (
        reach.iter().copied().fold(f64::MAX, f64::min),
        reach.iter().copied().fold(0.0, f64::max),
    );
    spread = spread.max((high - low) / high);
}

let columns = serde_json::json!([
    { "key": "0", "label": "重複をまとめた点 N [個]", "type": "integer" },
    { "key": "1", "label": "凸包の境界の点 h [個]", "type": "integer" },
    { "key": "2", "label": "三角形 [個]", "type": "integer" },
    { "key": "3", "label": "2N − h − 2 [個]", "type": "integer" },
    { "key": "4", "label": "Voronoi の頂点 [個]", "type": "integer" },
    { "key": "5", "label": "頂点を共有する三角形 [個]", "type": "integer" },
    { "key": "6", "label": "座標が対応しない入力行 [行]", "type": "integer" },
    { "key": "7", "label": "記号摂動" }
]);
let ties = if delaunay.provenance().resolved_ties {
    "使った"
} else {
    "使わなかった"
};
let row = (
    unique,
    hull,
    delaunay.simplex_count(),
    2 * unique - hull - 2,
    voronoi.vertex_count(),
    shared,
    moved,
    ties,
);
emit_table_with_columns!(
    columns,
    vec![row],
    metadata = serde_json::json!({ "id": "combinatorics" })
);
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let accuracy = serde_json::json!([
    { "key": "0", "label": "外心との最大相対差 [-]", "type": "number", "format": sci3 },
    { "key": "1", "label": "3 頂点までの距離の最大相対差 [-]", "type": "number", "format": sci3 },
    { "key": "2", "label": "頂点を計算できなかった三角形 [個]", "type": "integer" }
]);
emit_table_with_columns!(
    accuracy,
    vec![(center_gap, spread, failed)],
    metadata = serde_json::json!({ "id": "circumcenters" })
);
```

既定値（一様な 100 点、シード 1）では、領域が有界でない点は 14 個で、凸包の境界の点の数と一致し、三角形の数 184 は $2N - h - 2$ に等しい。
Voronoi の頂点は 184 個で、頂点を共有する三角形はない。
外心との相対差の最大値は $4.4 \times 10^{-15}$、3 頂点までの距離の相対的なばらつきは $5.7 \times 10^{-15}$ で、丸めの水準にある。
円周上の配置では、3 点が円周上で近いと外心の計算が悪条件になり、外心との相対差は $1.4 \times 10^{-13}$ まで大きくなる。
一方、3 頂点までの距離の相対的なばらつきは $3.3 \times 10^{-16}$ と小さい。
3 点が近い細い三角形では、外心を 3 点の方向に少し動かしても 3 頂点までの距離はほぼ同じだけ変わるので、このばらつきは頂点の誤差を測る量にならない。
整数格子では 162 個の三角形が 2 個ずつ 81 個の頂点を共有し、記号摂動が使われる。
格子の座標は小さな整数なので、外心も丸めなしで求まり、相対差は 0 である。

## まとめ

Voronoi の頂点は Delaunay の三角形の外心を丸めて求めた値で、位相は厳密だが、座標に誤差の上界は与えられていない。
条件のよい三角形では、独立な Cramer の公式の外心と $10^{-14}$ 程度で一致する。
円周上で近い 3 点の細い三角形では相対差が $10^{-13}$ の桁まで大きくなるので、Voronoi の頂点の座標を後の計算に使うときは、三角形の形を確かめる。
厳密に共円の点では、隣り合う三角形が 1 つの頂点を共有するので、頂点の数は三角形の数より少なくなる。
`region_is_unbounded` で数えた凸包の境界の点の数 $h$ から $2N - h - 2$ を求めれば、三角形の数を独立に照合できる。
