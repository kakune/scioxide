有限要素法のメッシュや散在点の補間では、点を頂点とする三角形分割の質が誤差と条件数を左右する。
細い三角形（最小角が小さい三角形）は、剛性行列の条件数を大きくし、補間の誤差の上界に現れる定数も大きくする。
同じ点の集合にも三角形分割は多数あり、その中で Delaunay 分割は最小角を最大にする。
この例題では、`Delaunay` で作った分割の辺をランダムに反転して別の分割を作り、2 つの分割の最小角と局所的な Delaunay 条件を比べる。

## 三角形分割と辺の反転

平面の $N$ 点の三角形分割は、すべての点を頂点とし、凸包を重なりなく覆う三角形の集合である。
凸包の境界にある点の数を $h$ とすると、Euler の公式から三角形の数は $T = 2N - h - 2$、辺の数は $3N - h - 3$ で、どの三角形分割でも同じである。
このうち $h$ 本は凸包の辺で、内部の辺は $3N - 2h - 3$ 本になる。

内部の辺 $pq$ は 2 つの三角形 $pqr$ と $qps$ に挟まれている。
四角形 $p\,r\,q\,s$ が凸なら、辺 $pq$ を消してもう一方の対角線 $rs$ を引くと、別の三角形分割になる。
この操作を辺の反転（edge flip）という。
四角形が凸でないと $rs$ は四角形の外を通るので、反転できない。
凸であることは、$r$ と $s$ を結ぶ直線に対して $p$ と $q$ が反対側にあること、つまり `orient2d(r, s, p)` と `orient2d(r, s, q)` が 0 でない逆の符号を持つことで判定できる。

## Delaunay 分割の最小角最大化の性質

`incircle(a, b, c, d)` は、行が $(x, y, x^2 + y^2, 1)$ の 4×4 行列式の符号を返す。
$a, b, c$ が反時計回りなら、$d$ が 3 点を通る円の内側で正、外側で負、円周上で 0 になる。
内部の辺 $pq$ を挟む三角形の一方を反時計回りの $a, b, c$ とし、もう一方の三角形の対頂点を $d$ とする。
$d$ が円の内側にない（`incircle` が正でない）とき、辺 $pq$ は局所的に Delaunay であるという。

辺の反転と角度の関係は、円周角の定理から分かる。
凸な四角形の対角線 $pq$ が局所的に Delaunay でないとき、反転すると、2 つの三角形の 6 つの角を小さい順に並べた列は辞書式に大きくなる（de Berg ほか 2008、9 章）。
すべての内部辺が局所的に Delaunay な分割は Delaunay 分割で、どの三角形の外接円も他の点を内側に含まない（Delaunay の補題）。
同じ円周上にある 4 点がなければ Delaunay 分割は一意で、分割全体の角度を小さい順に並べた列を全三角形分割の中で辞書式に最大にする（Lawson 1977、Sibson 1978）。
特に最小角を最大にし、この性質は共円の点があっても、どの Delaunay 分割についても成り立つ（de Berg ほか 2008、定理 9.9）。

4 点以上が同じ円周上にあると、Delaunay 分割は一意でない。
円周上の点を頂点とする三角形の角は、円周角の定理により向かい合う弧の半分で決まる。
そのため、すべての点が同じ円周上にあれば、どの三角形分割も最小角は等しいが、それ以外の角は分割ごとに異なる。
また、最小角の最大化は最大角を小さくすることを意味しない。
1 次の要素で補間したときの勾配の誤差は最大角が $180°$ に近いと大きくなる（Babuška と Aziz 1976）が、Delaunay 分割は最大角を最小にするとは限らない。

## Delaunay 分割の構成と添字

`Delaunay::new` は、点を放物面 $z = x^2 + y^2$ に持ち上げた 3 次元の点の下側凸包を、乱択逐次添加で求める。
挿入の順序は点の正準添字（後述）から固定の擬似乱数で決めるので、結果は入力の順序によらず、毎回同じになる。
下側凸包の面を平面に戻すと Delaunay 分割になる（Brown 1979）。
面の判定には厳密な述語を使うので、与えた座標に対して分割の組合せは厳密である。
共円の 4 点のように行列式が厳密に 0 になる退化は、正準添字の順序に基づく記号摂動で決め、`provenance().resolved_ties` が少なくとも 1 回そうしたことを示す。

構成の最初に、点を座標の辞書式順序で整列し、座標が等しい点を 1 つにまとめる。
整列した点の番号を正準添字と呼ぶ。
`simplex(i)` が返す頂点の番号は並べ替えた母点の正準添字で、`points()` は座標を正準添字の順に返す。
入力の $i$ 行目の点は正準添字 `input_mapping()[i]` に対応し、正準添字 $j$ の最初の入力行は `representatives()[j]` である。
`simplex(i)` の 3 つの番号は昇順で、向きを表さない。
`triangle_mesh()` は正準添字の点を頂点とし、各三角形を反時計回りに並べた `TriangleMesh` を返すので、ここでは反転をこのメッシュの上で行う。

## 反転の手順と点の配置

反転した分割は次の手順で作る。

1. `Delaunay::triangle_mesh` で Delaunay 分割を `TriangleMesh` にする。
2. `uniform_index` で辺を 1 本選ぶ。
   `face_cells` が 2 つの三角形を返す内部の辺で、四角形が凸なら反転し、そうでなければ選び直す。
3. 反転した 2 つの三角形を `orient2d` で反時計回りに並べ直し、`with_cells` で新しいメッシュを作る。
   `with_cells` は三角形の向きと退化、重複、使われない頂点、共有する辺の向き、各頂点のまわりの多様体性を検査するので、反転の誤りはここでエラーになる。
4. 指定した回数だけ 2 と 3 を繰り返す。

点の配置は 4 通りである。
「一様」は単位正方形の一様な点、「塊」は 5 つの中心のまわりに標準偏差 0.04 の正規分布で散らした点である。
「円周上」は単位円の上の一様な角度の点で、座標は `f64` に丸めるので、共円は丸めの範囲でしか成り立たない。
「整数格子」は $\lceil\sqrt{N}\,\rceil$ 列の整数格子の点で、格子の正方形の 4 頂点は厳密に同じ円周上にある。

次のブロックは 2 つのセルが共有する定義である。
`sites` は配置ごとの点を、1 行 1 点の $(x, y)$ の順に並べた座標の列で返す。
各セルはこの列を `PointSet::from_rows` で借用して `Delaunay` に渡す。

```rust
//| id: spatial-delaunay-sites
//| kind: definitions
//| title: 4 通りの点の配置
//| crates: [scioxide-core, scioxide-random, scioxide-spatial]
use scioxide_core::{SciOxideError, RealScalar};
use scioxide_random::{Distribution, Normal, Rng, SeedableRng, SplitMix64};

/// 配置 configuration の点 n 個を、1 行 1 点の (x, y) の順で返す。
pub(crate) fn sites(configuration: &str, n: usize, seed: u64) -> Result<Vec<f64>, SciOxideError> {
    let mut rng = SplitMix64::from_seed(seed);
    let mut coordinates: Vec<f64> = Vec::with_capacity(2 * n);
    match configuration {
        "clustered" => {
            let centers = [
                [0.2, 0.2],
                [0.8, 0.25],
                [0.5, 0.55],
                [0.25, 0.8],
                [0.8, 0.8],
            ];
            let spread = Normal::new(0.0, 0.04)?;
            for i in 0..n {
                let [x, y] = centers[i % centers.len()];
                coordinates.push(x + spread.sample(&mut rng)?);
                coordinates.push(y + spread.sample(&mut rng)?);
            }
        }
        "circle" => {
            for _ in 0..n {
                let uniform: f64 = rng.next_float()?;
                let angle = 2.0 * core::f64::consts::PI * uniform;
                coordinates.push(RealScalar::cos(angle));
                coordinates.push(RealScalar::sin(angle));
            }
        }
        "lattice" => {
            // ⌈√n⌉ 列の整数格子。正方形の 4 頂点は厳密に共円になる。
            let mut columns = 1;
            while columns * columns < n {
                columns += 1;
            }
            for i in 0..n {
                coordinates.push((i % columns) as f64);
                coordinates.push((i / columns) as f64);
            }
        }
        _ => {
            for _ in 0..2 * n {
                coordinates.push(rng.next_float()?);
            }
        }
    }
    Ok(coordinates)
}
```

## ランダムな辺の反転とメッシュの世代

次のセルは、点の数 $N$、反転の回数、点の配置、乱数のシードを選び、Delaunay 分割から反転を重ねた分割を作る。
反転する辺は点とは別のシード（点のシード + 1000）で初期化した `SplitMix64` で選ぶ。
表は入力の点の数、正準添字の数（重複をまとめた点の数）、三角形の数、反転した辺と選んだ辺の数、反転後のメッシュの世代を示す。
`with_cells` で作ったメッシュは元のメッシュと同じ族に属し、反転のたびに世代が 1 つ進む。
このセルは反転後の三角形（頂点は正準添字）と $N$、配置、シードを、次のセルに渡す。

```rust
//| id: spatial-delaunay-flip-walk
//| ref: spatial-delaunay-flip-walk
//| title: Delaunay 分割の辺をランダムに反転する
//| run: reactive
//| uses: [spatial-delaunay-sites]
//| crates: [scioxide-core, scioxide-random, scioxide-spatial]
//| exports: [site_count, configuration, seed, flipped_cells]
//| inputs:
//|   site_count: {"type":"range","label":"点の数 N","min":20,"max":400,"step":10,"value":100}
//|   flips: {"type":"range","label":"反転の回数","min":0,"max":500,"step":10,"value":100}
//|   configuration: {"type":"select","label":"点の配置","options":[{"label":"一様（単位正方形）","value":"uniform"},{"label":"塊（5 個の正規分布）","value":"clustered"},{"label":"円周上（ほぼ共円）","value":"circle"},{"label":"整数格子（厳密に共円）","value":"lattice"}],"value":"uniform"}
//|   seed: {"type":"range","label":"乱数のシード","min":1,"max":100,"step":1,"value":1}
//| cases:
//|   - {"id":"circle","label":"円周上の 100 点","description":"すべての点が凸包の上にあり、三角形は N − 2 個になる。","inputs":{"configuration":"circle"}}
//|   - {"id":"lattice","label":"整数格子","description":"10 × 10 の格子では、正方形ごとに対角線を選ぶ記号摂動が働く。","inputs":{"configuration":"lattice"}}
//|   - {"id":"many-flips","label":"反転 500 回","description":"反転を重ねるほど、Delaunay 分割から離れた分割になる。","inputs":{"flips":500}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"flips","path":"/rows/0/2","equals":184}
//|       - {"artifact":"flips","path":"/rows/0/3","equals":100}
//|       - {"artifact":"flips","path":"/rows/0/5","equals":100}
//|   - case: circle
//|     expect:
//|       - {"artifact":"flips","path":"/rows/0/2","equals":98}
//|       - {"artifact":"flips","path":"/rows/0/3","equals":100}
//|   - case: lattice
//|     expect:
//|       - {"artifact":"flips","path":"/rows/0/2","equals":162}
//|   - case: many-flips
//|     expect:
//|       - {"artifact":"flips","path":"/rows/0/3","equals":500}
//|       - {"artifact":"flips","path":"/rows/0/5","equals":500}
use scioxide_random::{SeedableRng, SplitMix64, uniform_index};
use scioxide_spatial::{Delaunay, PointSet, PredicateSign, orient2d};

let n = site_count as usize;
let coordinates = sites(&configuration, n, seed as u64).map_err(|e| e.to_string())?;
let points = PointSet::from_rows(&coordinates, 2).map_err(|e| e.to_string())?;
let delaunay = Delaunay::new(&points).map_err(|e| e.to_string())?;
// メッシュの頂点は正準添字（整列した点の番号）で、各三角形は反時計回りに並ぶ。
let original = delaunay.triangle_mesh().map_err(|e| e.to_string())?;
let at = |v: usize| *original.points()[v].as_array();
let side =
    |a: usize, b: usize, c: usize| orient2d(&at(a), &at(b), &at(c)).map_err(|e| e.to_string());

// 凸な四角形の内部辺をランダムに選んで反転する。
let mut rng = SplitMix64::from_seed(seed as u64 + 1000);
let mut mesh = original.clone();
let target = flips as usize;
let (mut performed, mut attempts) = (0, 0);
while performed < target && attempts < 100 * target {
    attempts += 1;
    let face = uniform_index(mesh.face_count(), &mut rng).map_err(|e| e.to_string())?;
    let pair = mesh.face_cells(face).map_err(|e| e.to_string())?.to_vec();
    if pair.len() != 2 {
        continue; // 凸包の辺は反転できない。
    }
    let edge = mesh
        .face_vertices(face)
        .map_err(|e| e.to_string())?
        .to_vec();
    let mut apex = [0; 2];
    for (slot, &cell) in apex.iter_mut().zip(&pair) {
        let vertices = mesh.cell_vertices(cell).map_err(|e| e.to_string())?;
        *slot = vertices
            .iter()
            .copied()
            .find(|v| !edge.contains(v))
            .ok_or("対頂点がない")?;
    }
    let [r, s] = apex;
    // 四角形 p r q s が凸であることは、p と q が直線 rs の厳密に反対側にあることと同じ。
    let (side_p, side_q) = (side(r, s, edge[0])?, side(r, s, edge[1])?);
    if side_p == PredicateSign::Zero || side_q == PredicateSign::Zero || side_p == side_q {
        continue;
    }
    let mut cells: Vec<[usize; 3]> = mesh.cells().map(|c| [c[0], c[1], c[2]]).collect();
    for (cell, end, sign) in [(pair[0], edge[0], side_p), (pair[1], edge[1], side_q)] {
        // orient2d(r, s, end) が正なら (r, s, end) は反時計回り。
        cells[cell] = if sign == PredicateSign::Positive {
            [r, s, end]
        } else {
            [s, r, end]
        };
    }
    mesh = mesh.with_cells(cells).map_err(|e| e.to_string())?;
    performed += 1;
}

let columns = serde_json::json!([
    { "key": "0", "label": "入力の点 [個]", "type": "integer" },
    { "key": "1", "label": "重複をまとめた点 [個]", "type": "integer" },
    { "key": "2", "label": "三角形 [個]", "type": "integer" },
    { "key": "3", "label": "反転した辺 [本]", "type": "integer" },
    { "key": "4", "label": "選んだ辺 [本]", "type": "integer" },
    { "key": "5", "label": "反転後のメッシュの世代", "type": "integer" }
]);
let generation = mesh.mesh_token().generation().get();
emit_table_with_columns!(
    columns,
    vec![(
        n,
        mesh.vertex_count(),
        mesh.cell_count(),
        performed,
        attempts,
        generation
    )],
    metadata = serde_json::json!({ "id": "flips" })
);
let cell_list = |m: &scioxide_spatial::TriangleMesh<f64>| -> Vec<[usize; 3]> {
    m.cells().map(|c| [c[0], c[1], c[2]]).collect()
};
export!(site_count, &n);
export!(configuration, &configuration);
export!(seed, &(seed as u64));
export!(flipped_cells, &cell_list(&mesh));
```

既定値（一様な 100 点、反転 100 回、シード 1）では、凸包の上の点が 14 個で、三角形は $2 \cdot 100 - 14 - 2 = 184$ 個である。
選んだ 160 本の辺のうち 60 本は凸包の辺か凸でない四角形の対角線で、100 本を反転した。
反転後のメッシュは元のメッシュと同じ族で、世代は 100 である。
円周上の配置ではすべての点が凸包の上にあり、三角形は 98 個になる。

## 反転した分割の最小角と局所的な Delaunay 条件

次のセルは、前のセルの $N$、配置、シードから同じ点を作り直して Delaunay 分割を構成し直し、受け取った反転後の三角形を `with_cells` で同じ正準添字の点の上に組み直す。
座標そのものは受け渡さない。
セルの間の値は JSON で渡り、10 進表記から読み戻すと最後のビットが変わることがあり、ほぼ共円の点ではそれだけで `incircle` の符号が変わるからである。
そのうえで、2 つの分割の角度と内部辺の `incircle` の符号を調べる。
角度は各三角形の頂点で `RealScalar::atan2(|外積|, 内積)` から求め、度で表す。
表は 2 つの分割について、三角形の数、内部の辺の数、`incircle` が正の辺（局所的に Delaunay でない辺）と 0 の辺（共円の辺）の数、最小角、三角形ごとの最小角の平均、最大角を示す。
グラフは三角形ごとの最小角の度数を、2.5° 幅の階級で 2 つの分割について重ねる。

```rust
//| id: spatial-delaunay-min-angle-check
//| ref: spatial-delaunay-min-angle-check
//| title: Delaunay 分割と反転した分割の角度と局所条件を比べる
//| run: reactive
//| uses: [spatial-delaunay-sites]
//| crates: [scioxide-core, scioxide-random, scioxide-spatial]
//| dependsOn:
//|   walk: spatial-delaunay-flip-walk
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"angles","path":"/rows/0/3","equals":0}
//|       - {"artifact":"angles","path":"/rows/1/3","equals":53}
//|       - {"artifact":"angles","path":"/rows/0/5","approx":{"value":1.4134061048729,"rtol":1e-9}}
//|       - {"artifact":"angles","path":"/rows/1/5","approx":{"value":0.27616828917769,"rtol":1e-9}}
//|       - {"artifact":"histogram","path":"/spec/layers/1/points/0/1","equals":10}
use scioxide_core::RealScalar;
use scioxide_spatial::{Delaunay, PointSet, PredicateSign, incircle};

let n = walk["site_count"].as_u64().ok_or("点の数がない")? as usize;
let configuration = walk["configuration"].as_str().ok_or("配置がない")?;
let seed = walk["seed"].as_u64().ok_or("シードがない")?;
let flipped: Vec<[usize; 3]> =
    serde_json::from_value(walk["flipped_cells"].clone()).map_err(|e| e.to_string())?;
// 座標は受け渡さず、同じ点から Delaunay 分割を作り直す。
let coordinates = sites(configuration, n, seed).map_err(|e| e.to_string())?;
let points = PointSet::from_rows(&coordinates, 2).map_err(|e| e.to_string())?;
let delaunay = Delaunay::new(&points).map_err(|e| e.to_string())?;
let original = delaunay.triangle_mesh().map_err(|e| e.to_string())?;
let reflipped = original.with_cells(flipped).map_err(|e| e.to_string())?;
let mut rows = Vec::new();
let mut layers = Vec::new();
for (name, key, mesh) in [
    ("Delaunay 分割", "delaunay", &original),
    ("反転後の分割", "flipped", &reflipped),
] {
    let at = |v: usize| *mesh.points()[v].as_array();
    // 各三角形の 3 つの角 [deg] から、三角形ごとの最小角と全体の最大角を求める。
    let mut minima = Vec::with_capacity(mesh.cell_count());
    let mut largest = 0.0_f64;
    for cell in mesh.cells() {
        let corners = [at(cell[0]), at(cell[1]), at(cell[2])];
        let angles = (0..3).map(|i| {
            let [o, u, w] = [corners[i], corners[(i + 1) % 3], corners[(i + 2) % 3]];
            let (ux, uy, wx, wy) = (u[0] - o[0], u[1] - o[1], w[0] - o[0], w[1] - o[1]);
            let (cross, dot) = (ux * wy - uy * wx, ux * wx + uy * wy);
            RealScalar::to_degrees(RealScalar::atan2(cross.abs(), dot))
        });
        let (low, high) = angles.fold((180.0_f64, 0.0_f64), |(l, h), a| (l.min(a), h.max(a)));
        minima.push(low);
        largest = largest.max(high);
    }
    // 内部辺ごとに、一方の三角形 abc（反時計回り）の外接円と他方の対頂点 d を比べる。
    let (mut interior, mut inside, mut cocircular) = (0, 0, 0);
    for face in 0..mesh.face_count() {
        let pair = mesh.face_cells(face).map_err(|e| e.to_string())?;
        if pair.len() != 2 {
            continue;
        }
        interior += 1;
        let abc = mesh.cell_vertices(pair[0]).map_err(|e| e.to_string())?;
        let other = mesh.cell_vertices(pair[1]).map_err(|e| e.to_string())?;
        let d = *other
            .iter()
            .find(|v| !abc.contains(v))
            .ok_or("対頂点がない")?;
        let sign = incircle(&at(abc[0]), &at(abc[1]), &at(abc[2]), &at(d))
            .map_err(|e| e.to_string())?;
        match sign {
            PredicateSign::Positive => inside += 1,
            PredicateSign::Zero => cocircular += 1,
            PredicateSign::Negative => {}
        }
    }
    let smallest = minima.iter().copied().fold(180.0, f64::min);
    let mean = minima.iter().sum::<f64>() / minima.len() as f64;
    rows.push((
        name,
        mesh.cell_count(),
        interior,
        inside,
        cocircular,
        smallest,
        mean,
        largest,
    ));
    // 2.5° 幅の階級の度数を、階級の中央に置いた階段で描く。
    let mut counts = [0_usize; 24];
    for &angle in &minima {
        counts[((angle / 2.5) as usize).min(23)] += 1;
    }
    let steps: Vec<[f64; 2]> = counts
        .iter()
        .enumerate()
        .map(|(i, &c)| [2.5 * i as f64 + 1.25, c as f64])
        .collect();
    layers.push(serde_json::json!({
        "id": key,
        "kind": "line",
        "name": name,
        "points": steps,
        "style": { "step": "middle", "showSymbol": false }
    }));
}

let fixed2 = serde_json::json!({ "fractionDigits": 2 });
let columns = serde_json::json!([
    { "key": "0", "label": "分割" },
    { "key": "1", "label": "三角形 [個]", "type": "integer" },
    { "key": "2", "label": "内部の辺 [本]", "type": "integer" },
    { "key": "3", "label": "incircle が正の辺 [本]", "type": "integer" },
    { "key": "4", "label": "incircle が 0 の辺 [本]", "type": "integer" },
    { "key": "5", "label": "最小角 [deg]", "type": "number", "format": fixed2 },
    { "key": "6", "label": "三角形ごとの最小角の平均 [deg]", "type": "number", "format": fixed2 },
    { "key": "7", "label": "最大角 [deg]", "type": "number", "format": fixed2 }

emit_table_with_columns!(

    rows,
    metadata = serde_json::json!({ "id": "angles" })

emit_chart!(

    }),
```

既定値では、Delaunay 分割の 269 本の内部辺に `incircle` が正の辺はなく、反転後の分割では 53 本が局所的に Delaunay でない。
最小角は Delaunay 分割の $1.413°$ に対して反転後は $0.276°$ で、三角形ごとの最小角の平均も $28.16°$ から $21.18°$ に下がる。
一様な点では Delaunay 分割でも $1.4°$ 程度の細い三角形が残り、最小角の最大化は最小角が大きいことを意味しない。
最大角は Delaunay 分割で $175.52°$、反転後で $179.10°$ である。
グラフでは、反転後の分割の度数が $0$–$2.5°$ の階級で 3 個から 10 個に増え、分布が小さい角の側に移る。

配置を変えても、Delaunay 分割の最小角が反転後を下回ることはない。
塊の配置では $0.782°$ に対して $0.223°$ である。
円周上の配置では、2 つの分割の最小角はどちらも $0.01701°$ で一致し、三角形ごとの最小角の平均は $3.53°$ と $3.16°$ で異なる。
座標の丸めで点は厳密には共円でないので、反転後の分割には `incircle` が正の辺が 31 本ある。
どの対角線が Delaunay 辺になるかは座標の最後のビットで決まり、`cos` と `sin` の丸めが異なる x86_64 での実行では Delaunay 分割そのものが変わって、平均は $3.85°$ になった。
整数格子では Delaunay 分割の 81 本の対角線が共円の辺（`incircle` が 0）で、最小角は $45°$ である。
反転後は最小角が $7.13°$ に下がり、28 本の辺が局所的に Delaunay でなくなる。

## まとめ

辺の反転は凸な四角形の対角線を入れ替える操作で、凸性は `orient2d`、局所的な Delaunay 条件は反時計回りの三角形に対する `incircle` の符号で厳密に判定できる。
すべての内部辺で `incircle` が正でない分割が Delaunay 分割で、どの分割と比べても最小角は小さくならない。
同じ円周上の点では最小角だけが分割によらず、ほかの角は分割ごとに異なるので、「Delaunay 分割なら角度の分布が決まる」とは言えない。
Delaunay 分割は最大角を小さくするとは限らないので、1 次要素で求めた勾配の誤差のように最大角が効く用途では、最大角を別に確かめる。
`Delaunay` の頂点の番号は並べ替えた母点の正準添字で、入力の行とは `input_mapping` と `representatives` で対応づける。
