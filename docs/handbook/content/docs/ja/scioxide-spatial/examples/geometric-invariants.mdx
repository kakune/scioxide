有限体積法ではセル平均から質量を数え、姿勢計算では回転で物体の寸法を変えず、有限要素法では線形な場を要素の補間でそのまま表せることを前提にする。
この例題ではこの 3 つの前提を解析解と比べて確かめ、セル平均による質量、回転による長さ、重心座標による線形場の補間が丸めの水準で保たれることを示す。
比較のために置く中点則による質量の代用だけは離散化誤差を持ち、格子に応じた大きさで解析解からずれる。
丸めの水準を超える差がセル平均、回転、補間の側に出たら、入力の作り方か API の使い方に誤りがある。

## 非一様格子のセル平均と棒の質量

長さ 1 m の棒の線密度を $\rho(x) = \rho_0 x^2$（$\rho_0 = 1$ kg/m³、$x$ [m]）とする。
区間 $[0, 1]$ を $x_i = (i/n)^p$ で分割すると、$p > 1$ では原点の近くほど細かい格子になる。
セル $[x_i, x_{i+1}]$ の平均密度は

$$
\bar{\rho}_i = \frac{1}{x_{i+1} - x_i}\int_{x_i}^{x_{i+1}} x^2\,dx = \frac{x_i^2 + x_i x_{i+1} + x_{i+1}^2}{3}
$$

で、$\sum_i \bar{\rho}_i (x_{i+1} - x_i)$ は棒の質量 $M = 1/3$ kg に丸め誤差の範囲で一致する。
セルの中点の密度で代用すると、中点則の誤差 $\sum_i h_i^3/12$（$h_i = x_{i+1} - x_i$）が残る。
等間隔（$p = 1$）ではこれが $1/(12n^2)$ になる。

次のセルは不等間隔の座標軸から `SegmentMesh` を作り、セル平均を `CellField` に格納して、セル平均と中点の密度による 2 つの総和を比べる。
`CellField` は値をセルに結び付けるだけで、平均値の計算や保存の保証はしない。
表のメッシュの世代は、場が結び付いたメッシュの `MeshToken::generation` である。
世代は幾何か位相を変える revision ごとに 1 増える番号で、新しく作ったメッシュでは 0 である。
図はセル平均の階段と $\rho(x) = x^2$（破線）である。
表は質量と解析解 $1/3$ kg との差、中点の密度で代用した差、等間隔のときの理論値 $1/(12n^2)$、場の値の個数とメッシュの世代を示す。
等間隔でないときは理論値を定義しないので、その欄には「p ≠ 1」と示す。

```rust
//| id: spatial-cell-averages
//| ref: spatial-cell-averages
//| title: 非一様格子のセル平均から棒の質量を復元する
//| run: reactive
//| crates: [scioxide-spatial]
//| inputs:
//|   mesh_cells: {"type":"range","label":"セル数 n","min":16,"max":80,"step":8,"value":32}
//|   mesh_power: {"type":"range","label":"格子の偏りの指数 p [-]","min":1,"max":3,"step":0.25,"value":1.5}
//| cases:
//|   - {"id":"uniform","label":"p = 1","description":"等間隔では中点則の誤差が 1/(12n²) に一致する。","inputs":{"mesh_power":1}}
//|   - {"id":"strong-grading","label":"p = 3","description":"端の粗いセルで中点則の誤差が増える。","inputs":{"mesh_power":3}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"mass","path":"/rows/0/1","range":{"max":1e-15}}
//|       - {"artifact":"mass","path":"/rows/0/2","approx":{"value":1.1e-4,"rtol":0.05}}
//|       - {"artifact":"mass","path":"/rows/0/4","equals":32}
//|   - case: uniform
//|     expect:
//|       - {"artifact":"mass","path":"/rows/0/2","approx":{"value":8.138020833e-5,"rtol":1e-8}}
//|       - {"artifact":"mass","path":"/rows/0/3","approx":{"value":8.138020833e-5,"rtol":1e-8}}
//|   - case: strong-grading
//|     expect:
//|       - {"artifact":"mass","path":"/rows/0/1","range":{"max":1e-15}}
//|       - {"artifact":"mass","path":"/rows/0/2","approx":{"value":3.1e-4,"rtol":0.05}}
//|       - {"artifact":"mass","path":"/rows/0/3","equals":null}
use scioxide_spatial::{AxisTopology, CellField, CoordinateAxis, Grid1d, SegmentMesh};

let n = mesh_cells.round() as usize;
// 節点 x_i = (i/n)^p [m]（入力の生成なので f64 の固有メソッドを使う）。
let nodes: Vec<f64> = (0..=n)
    .map(|i| (i as f64 / n as f64).powf(mesh_power))
    .collect();
let axis = CoordinateAxis::explicit(nodes.clone()).map_err(|e| e.to_string())?;
let grid = Grid1d::new([axis], [AxisTopology::Bounded]).map_err(|e| e.to_string())?;
let mesh = SegmentMesh::new(grid).map_err(|e| e.to_string())?;

// 解析的な積分から求めたセル平均密度 [kg/m] を、セルに結び付けた場として持つ。
let averages: Vec<f64> = nodes
    .windows(2)
    .map(|p| (p[0] * p[0] + p[0] * p[1] + p[1] * p[1]) / 3.0)
    .collect();
let field = CellField::<f64, 1>::new(&mesh, averages).map_err(|e| e.to_string())?;
let mass: f64 = field
    .values()
    .iter()
    .zip(nodes.windows(2))
    .map(|(rho, p)| rho * (p[1] - p[0]))
    .sum();
let midpoint: f64 = nodes
    .windows(2)
    .map(|p| (0.5 * (p[0] + p[1])).powi(2) * (p[1] - p[0]))
    .sum();

// セル平均は各セルで一定なので、左端から次の節点まで水平に描く階段にする。
let mut steps: Vec<[f64; 2]> = field
    .values()
    .iter()
    .zip(&nodes)
    .map(|(&rho, &x)| [x, rho])
    .collect();
steps.push([nodes[n], field.values()[n - 1]]);
let exact: Vec<[f64; 2]> = (0..=100)
    .map(|i| {
        let x = i as f64 / 100.0;
        [x, x * x]
    })
    .collect();
emit_line_chart!(
    &vec![
        serde_json::json!({
            "name": "セル平均密度",
            "points": steps,
            "style": { "step": "end" }
        }),
        serde_json::json!({
            "name": "ρ(x) = x²",
            "points": exact,
            "style": { "lineType": "dashed" }
        }),
    ],
    options = &serde_json::json!({ "xLabel": "位置 x [m]", "yLabel": "線密度 ρ [kg/m]" })
);

let digits16 = serde_json::json!({ "significantDigits": 16 });
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let columns = serde_json::json!([
    { "key": "0", "label": "セル平均からの質量 [kg]", "type": "number", "format": digits16 },
    { "key": "1", "label": "|質量 − 1/3| [kg]", "type": "number", "format": sci3 },
    { "key": "2", "label": "中点の密度での |差| [kg]", "type": "number", "format": sci3 },
    { "key": "3", "label": "1/(12n²) [kg]", "type": "number", "format": sci3, "nullText": "p ≠ 1" },
    { "key": "4", "label": "場の値 [個]", "type": "integer" },
    { "key": "5", "label": "メッシュの世代", "type": "integer" }
]);
// 中点則の誤差の理論値 1/(12n²) は等間隔のときだけ定義する。
let uniform_error = (mesh_power == 1.0).then(|| 1.0 / (12.0 * (n * n) as f64));
let row = (
    mass,
    (mass - 1.0 / 3.0).abs(),
    (midpoint - 1.0 / 3.0).abs(),
    uniform_error,
    field.len(),
    field.mesh_token().generation().get(),
);
emit_table_with_columns!(
    columns,
    vec![row],
    metadata = serde_json::json!({ "id": "mass" })
);
```

既定の $n = 32$、$p = 1.5$ では、セル平均からの質量は $1/3$ kg と最後の桁まで一致し、中点の密度で代用した質量は $1.1 \times 10^{-4}$ kg ずれた。
「p = 1」の場合は中点則の誤差が $8.14 \times 10^{-5}$ kg で、理論値 $1/(12n^2)$ と一致する。
「p = 3」の場合は端の粗いセルの寄与が増えて $3.1 \times 10^{-4}$ kg になる。
セル平均の側の差は $p = 3$ でも $5.6 \times 10^{-17}$ kg で、総和の丸め誤差だけが残る。

## 回転による長さの保存と逆回転

回転行列 $R \in \mathrm{SO}(3)$ は長さを保ち（$\|Rx\| = \|x\|$）、逆回転で元に戻る（$R^{-1}Rx = x$）。
次のセルは $xy$ 平面の単位円上の 96 点を、軸 $(a, 1, 0.5)$ のまわりに角 $\theta$ 回転させる。
`Rotation::from_axis_angle` の軸は単位長さでなくてよく、軸の長さは結果に影響しない。
`Rotation::apply` は、通常の浮動小数点演算で作った回転行列とベクトルの積の各成分を、厳密な積和から 1 回だけ丸めて返す。
3 次元の図は元の円、回転後の円と回転軸を描き、3 軸の単位はどれも円の半径である。
表は回転の単位四元数 $[x, y, z, w]$ と、長さの変化 $\bigl|\|Rx\|^2 - 1\bigr|$ と、逆回転で戻した点の成分ごとの誤差の最大値を示す。

```rust
//| id: spatial-rotation-invariants
//| ref: spatial-rotation-invariants
//| title: 回転軸と角度を変えて長さと逆変換を検証する
//| run: reactive
//| crates: [scioxide-core, scioxide-spatial]
//| inputs:
//|   rotation_degrees: {"type":"range","label":"回転角 θ [deg]","min":-180,"max":180,"step":5,"value":60}
//|   axis_tilt: {"type":"range","label":"回転軸の x 成分 a [-]","min":0,"max":2,"step":0.1,"value":0.7}
//| cases:
//|   - {"id":"half-turn","label":"θ = 180°","description":"四元数のスカラー部 w が 0 に近くなる。","inputs":{"rotation_degrees":180}}
//|   - {"id":"axis-in-yz","label":"a = 0","description":"回転軸が yz 平面に入る。","inputs":{"axis_tilt":0}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"invariants","path":"/rows/0/4","range":{"max":1e-15}}
//|       - {"artifact":"invariants","path":"/rows/0/5","range":{"max":1e-15}}
//|   - case: half-turn
//|     expect:
//|       - {"artifact":"invariants","path":"/rows/0/3","range":{"min":0,"max":1e-15}}
//|       - {"artifact":"invariants","path":"/rows/0/4","range":{"max":1e-15}}
//|   - case: axis-in-yz
//|     expect:
//|       - {"artifact":"invariants","path":"/rows/0/0","approx":{"value":0,"atol":1e-15}}
//|       - {"artifact":"invariants","path":"/rows/0/5","range":{"max":1e-15}}
use scioxide_core::RealScalar;
use scioxide_spatial::Rotation;

let axis = [axis_tilt, 1.0, 0.5];
let angle = RealScalar::to_radians(rotation_degrees);
let rotation = Rotation::from_axis_angle(axis, angle).map_err(|e| e.to_string())?;
let inverse = rotation.inverse();
let mut points = Vec::new();
let mut edges = Vec::new();
let mut norm_error = 0.0_f64;
let mut inverse_error = 0.0_f64;
for i in 0..96 {
    // 単位円上の点 (cos φ, sin φ, 0)。
    let (sin_phi, cos_phi) = RealScalar::sin_cos(core::f64::consts::TAU * f64::from(i) / 96.0);
    let point = [cos_phi, sin_phi, 0.0];
    let rotated = rotation.apply(point).map_err(|e| e.to_string())?;
    let restored = inverse.apply(rotated).map_err(|e| e.to_string())?;
    // 長さの保存 |Rx|² = 1 と、逆回転による復元の誤差。
    let squared: f64 = rotated.iter().map(|x| x * x).sum();
    norm_error = norm_error.max((squared - 1.0).abs());
    for (r, p) in restored.iter().zip(point) {
        inverse_error = inverse_error.max((r - p).abs());
    }
    for (group, position) in [("original", point), ("rotated", rotated)] {
        points.push(serde_json::json!({
            "id": format!("{group}-{i}"),
            "position": position,
            "group": group
        }));
        edges.push(serde_json::json!({
            "from": format!("{group}-{i}"),
            "to": format!("{group}-{}", (i + 1) % 96)
        }));
    }
}
// 回転軸を、正規化した軸の ±1.3 倍の 2 点と辺で示す。
let length = RealScalar::sqrt(axis.iter().map(|x| x * x).sum::<f64>());
for (id, sign) in [("axis-plus", 1.3), ("axis-minus", -1.3)] {
    let position: Vec<f64> = axis.iter().map(|x| sign * x / length).collect();
    points.push(serde_json::json!({ "id": id, "position": position, "group": "axis" }));
}
edges.push(serde_json::json!({ "from": "axis-plus", "to": "axis-minus" }));
let unit = |label: &str| serde_json::json!({ "label": label, "unit": "円の半径" });
emit_scene3d!(
    serde_json::json!({
        "points": points,
        "edges": edges,
        "groups": [
            { "id": "original", "label": "元の単位円（xy 平面）" },
            { "id": "rotated", "label": "回転後の円" },
            { "id": "axis", "label": "回転軸" }
        ],
        "axes": { "x": unit("x"), "y": unit("y"), "z": unit("z") }
    }),
    metadata = serde_json::json!({ "id": "circles", "title": "単位円の回転" })
);

let q = rotation.as_quaternion();
let fixed6 = serde_json::json!({ "fractionDigits": 6 });
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let columns = serde_json::json!([
    { "key": "0", "label": "x [-]", "type": "number", "format": fixed6 },
    { "key": "1", "label": "y [-]", "type": "number", "format": fixed6 },
    { "key": "2", "label": "z [-]", "type": "number", "format": fixed6 },
    { "key": "3", "label": "w [-]", "type": "number", "format": fixed6 },
    { "key": "4", "label": "max | |Rx|² − 1 | [-]", "type": "number", "format": sci2 },
    { "key": "5", "label": "逆回転後の最大成分誤差 [-]", "type": "number", "format": sci2 }
]);
let row = (q[0], q[1], q[2], q[3], norm_error, inverse_error);
emit_table_with_columns!(
    columns,
    vec![row],
    metadata = serde_json::json!({ "id": "invariants" })
);
```

試したすべての入力（既定値と 2 つのケース）で、長さの変化は $4.4 \times 10^{-16}$ 以下、逆回転の復元誤差は $3.3 \times 10^{-16}$ 以下で、`f64` の丸めの数単位に収まる。
`Rotation` は同じ回転を表す $q$ と $-q$ のうち、$(w, x, y, z)$ の最初の 0 でない成分が正になる方を保持する。
「θ = 180°」の場合は $w = \cos 90°$ が丸めで $6.1 \times 10^{-17}$ になり、この規則で $w$ が正の側が選ばれる。
「a = 0」の場合は四元数の $x$ 成分が 0 になり、ベクトル部 $(x, y, z) = \sin(\theta/2)\,\hat{\boldsymbol{n}}$ が正規化した軸 $\hat{\boldsymbol{n}} = (0, 1, 0.5)/\sqrt{1.25}$ の向きを向く。

## 共円の 4 点と線形な温度場

一辺 $L$ の正方形の 4 頂点は同一円周上にあり、2 本の対角線のどちらで分割しても Delaunay 分割になる。
`scioxide-spatial` は座標の辞書式順に並べ替えた母点の正準添字の順に基づく[記号摂動](oxref:spatial-tessellation-sites)で一方を決定論的に選び、双対の Voronoi 頂点は 2 つの三角形に共通の外心 $(L/2, L/2)$ に統合される。

板の温度が線形 $T(x, y) = 1 + 2x + 3y$ [K]（$x, y$ [m]）なら、どの三角形の中でも重心座標 $\lambda$ による補間 $\sum_i \lambda_i T(\boldsymbol{p}_i)$ は $T$ を丸め誤差の範囲で再現する。
これは有限要素法のパッチ試験に当たる。
次のセルは照会点を含む三角形を `find_simplex` で求め、`barycentric_into` の重心座標で温度を補間する。
`simplex(s)` が返す頂点は正準添字なので、`representatives()` で入力の行（正方形の角の番号、0 から反時計回り）に戻して表に示す。
1 つ目の表は照会点、含む三角形の頂点、重心座標、補間温度と解析値の差、重心座標から組み立て直した点と照会点の距離 $|\sum_i \lambda_i \boldsymbol{p}_i - \boldsymbol{q}|$ を示す。
`barycentric_into` は $\lambda_0 = 1 - \lambda_1 - \lambda_2$ として返すので、$\sum\lambda = 1$ は検算にならず、頂点の座標を使う組み立て直しで重心座標を確かめる。
2 つ目の表は三角形の数、Voronoi 頂点の数、Voronoi 頂点と中心 $(L/2, L/2)$ の差と、記号摂動による同点の判定を使ったかを示す。

```rust
//| id: spatial-delaunay-affine-dual
//| ref: spatial-delaunay-affine-dual
//| title: 共円の 4 点で分割と線形場の再現を検算する
//| run: reactive
//| crates: [scioxide-core, scioxide-spatial]
//| inputs:
//|   square_side: {"type":"range","label":"正方形の辺長 L [m]","description":"座標を相似に拡大する。","min":0.5,"max":3,"step":0.25,"value":1}
//|   query_fraction: {"type":"range","label":"照会点の横位置 x/L [-]","description":"照会点を別の三角形へ移す。","min":0.1,"max":0.9,"step":0.1,"value":0.3}
//| cases:
//|   - {"id":"other-triangle","label":"x/L = 0.9","description":"照会点がもう一方の三角形に入る。","inputs":{"query_fraction":0.9}}
//|   - {"id":"large-square","label":"L = 3 m","description":"相似に拡大しても重心座標は変わらない。","inputs":{"square_side":3}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"interpolation","path":"/rows/0/3","approx":{"value":0.33,"atol":1e-12}}
//|       - {"artifact":"interpolation","path":"/rows/0/8","range":{"max":1e-14}}
//|       - {"artifact":"interpolation","path":"/rows/0/9","range":{"max":1e-15}}
//|       - {"artifact":"dual","path":"/rows/0/0","equals":2}
//|       - {"artifact":"dual","path":"/rows/0/1","equals":1}
//|       - {"artifact":"dual","path":"/rows/0/3","equals":"使った"}
//|   - case: other-triangle
//|     expect:
//|       - {"artifact":"interpolation","path":"/rows/0/8","range":{"max":1e-14}}
//|   - case: large-square
//|     expect:
//|       - {"artifact":"interpolation","path":"/rows/0/3","approx":{"value":0.33,"atol":1e-12}}
//|       - {"artifact":"dual","path":"/rows/0/2","range":{"max":1e-14}}
use scioxide_core::RealScalar;
use scioxide_spatial::{PointSet, Voronoi};

let side = square_side;
// 正方形の角を 0 から反時計回りに並べる（入力の行）。
let coordinates = [0.0, 0.0, side, 0.0, side, side, 0.0, side];
let points = PointSet::from_rows(&coordinates, 2).map_err(|e| e.to_string())?;
// Voronoi 図を作り、その内部の Delaunay 分割を位置決定と補間に使う。
let dual = Voronoi::new(&points).map_err(|e| e.to_string())?;
let geometry = dual.delaunay();

let query = [query_fraction * side, 0.37 * side];
let location = geometry
    .find_simplex(&query)
    .map_err(|e| e.to_string())?
    .ok_or("照会点が正方形の外にある")?;
let mut weights = [0.0; 3];
let mut scratch = [0.0; 3];
geometry
    .barycentric_into(location.simplex, &query, &mut weights, &mut scratch)
    .map_err(|e| e.to_string())?;

// 線形な温度場 T = 1 + 2x + 3y [K] を頂点の値から補間し、解析値と比べる。
let temperature = |p: &[f64]| 1.0 + 2.0 * p[0] + 3.0 * p[1];
let vertices = geometry
    .simplex(location.simplex)
    .map_err(|e| e.to_string())?;
let sites = geometry.points();
let interpolated: f64 = vertices
    .iter()
    .zip(weights)
    .map(|(&v, w)| w * temperature(&sites[2 * v..2 * v + 2]))
    .sum();
// 正準添字を入力の行（角の番号）に戻す。
let corners: Vec<String> = vertices
    .iter()
    .map(|&v| geometry.representatives()[v].to_string())
    .collect();
let voronoi_vertices = dual.vertices().map_err(|e| e.to_string())?;
let center_error = voronoi_vertices
    .iter()
    .map(|v| (v - side / 2.0).abs())
    .fold(0.0_f64, f64::max);

let fixed3 = serde_json::json!({ "fractionDigits": 3 });
let fixed6 = serde_json::json!({ "fractionDigits": 6 });
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let columns = serde_json::json!([
    { "key": "0", "label": "照会点 x [m]", "type": "number", "format": fixed3 },
```

分割は角 1 $(L, 0)$ と角 3 $(0, L)$ を結ぶ対角線を選んだ。
「x/L = 0.9」の場合は照会点が角 3、1、2 の三角形に入り、温度の差は $4.4 \times 10^{-16}$ K になる。
三角形は 2 個、Voronoi 頂点は共通の外心 1 個である。
同点の判定を「使った」は、厳密に 0 になった述語の符号を記号摂動が少なくとも 1 つ決めたことを示し、ここでは共円の 4 点の分割がそれに当たる。
「L = 3 m」の場合も重心座標は $(0.33, 0.37, 0.30)$ のままで、分割が相似変換と整合していることが分かる。

## まとめ

セル平均を正しく作れば非一様格子でも質量は丸め誤差の範囲で保存され、中点の値で代用すると格子の偏りに応じた離散化誤差が残る。
回転は長さを $10^{-16}$ の桁で保ち、逆回転で元の点に戻るので、これより大きな差が出たら入力か適用の順序を疑う。
共円の 4 点の Delaunay 分割は記号摂動で決定論的に選ばれ、Voronoi 頂点は共通の外心 1 個に統合される。
重心座標による補間は線形な場を丸め誤差の範囲で再現するので、補間の誤差が大きければ、頂点の正準添字と入力の行の対応を確かめる。
