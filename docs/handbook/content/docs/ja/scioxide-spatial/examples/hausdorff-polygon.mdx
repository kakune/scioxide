CAD や数値制御の工作機械では、円弧を短い線分の列で近似して加工経路を作る。
線分の数を決めるのは、近似した経路が本来の円からどれだけ離れるか、つまり最大のずれである。
2 つの図形の最大のずれは Hausdorff 距離で表され、`directed_hausdorff` は点の集合どうしについてそれを計算する。
この例題では半径 $R = 25$ mm の円と内接正 $n$ 角形の両方を点で標本化し、有向 Hausdorff 距離を閉形式の弦の高さと比べる。
頂点だけを標本にすると何を測ってしまうかと、外れ値 1 点が結果をどう変えるかも確かめる。

## 有向 Hausdorff 距離

点の集合 $A$ から $B$ への有向 Hausdorff 距離は

$$
h(A, B) = \max_{a \in A} \min_{b \in B} |a - b|
$$

である。
$A$ のどの点も $B$ から $h(A, B)$ 以内にあり、$h(A, B)$ を達成する点 $a^*$ とその最も近い点 $b^*$ を距離を与える点対（witness）と呼ぶ。
一般に $h(A, B) \ne h(B, A)$ で、両方向の大きい方 $H(A, B) = \max(h(A, B), h(B, A))$ が（対称な）Hausdorff 距離である。

`directed_hausdorff(&source, &target)` は Euclid 距離で $h(\text{source}, \text{target})$ を求め、距離 `distance` と距離を与える点対の番号 `source`、`target` を返す。
両方の集合を固定のシードで決めた乱数の順序で調べ、内側の探索は距離が現在の最大値を下回った時点で打ち切る（Taha と Hanbury 2015）。
最悪の計算量は $m$ 点と $n$ 点で $O(mnd)$ である。
乱択の順序の下での期待計算量はこれよりずっと小さいとされる（Taha–Hanbury）が、どれだけ減るかは点の配置による。
結果と距離を与える点対は調べる順序によらず、距離を与える点対の番号は最大を達成する点のうち最小の番号である。
どちらかの集合が空なら `DomainError`、次元が違えば `DimensionMismatch` を返す。

## 円と内接正多角形の Hausdorff 距離

半径 $R$ の円に内接する正 $n$ 角形の 1 辺は、中心角 $2\theta$（$\theta = \pi/n$）の弦である。
弦の中点は中心から $R\cos\theta$ の距離にあり、弧の中点との差

$$
H_n = R\,(1 - \cos\theta) = 2R\sin^2\frac{\pi}{2n} \approx \frac{\pi^2 R}{2n^2}
$$

が弦の高さ（sagitta）である。
円の各点から多角形までの距離は弧の中点で最大の $H_n$ になり、多角形の各点から円までの距離も弦の中点で最大の $H_n$ になる。
したがって円と多角形の Hausdorff 距離は両方向とも $H_n$ で、$n$ を 2 倍にすると約 1/4 になる。
$R = 25$ mm、$n = 12$ では $H_{12} = 0.8519$ mm である。

## 標本化による誤差

`directed_hausdorff` は有限の点の集合を扱うので、円と多角形の両方を点で表す。
ここでは辺ごとに $s$ 個ずつ、円は角度 $2\pi(i + t/s)/n$、多角形は辺 $v_i v_{i+1}$ を $s$ 等分した点 $v_i + (t/s)(v_{i+1} - v_i)$（$i = 0, \ldots, n - 1$、$t = 0, \ldots, s - 1$）で標本化する。
標本は頂点を含み、$s$ が偶数なら弧と辺の中点も含む。

$s$ が偶数なら、弧の中点から最も近い多角形の標本は辺の中点で、距離はちょうど $H_n$ である。
ほかの円の標本では連続な多角形までの距離が $H_n$ より小さく、下のセルで確かめるように、測った値は丸めの範囲で $H_n$ に一致する。
$s$ が奇数なら弧の中点が標本に入らず、最も近い標本は角度 $\varphi = \pi/(ns)$ だけずれる。
その点から弦までの距離 $R(\cos\varphi - \cos\theta) \approx H_n(1 - 1/s^2)$ が、測った値の近似になる。
相対誤差は $1/s^2$ 程度で $n$ によらないので、$n$ に対する収束の次数は標本化で変わらない。
どの $s$ でも、円から多角形への値は $\sqrt{H_n^2 + (\Delta/2)^2}$ を超えない。
$\Delta = 2R\sin\theta/s$ は辺の標本の間隔で、円の点から辺に下ろした垂線の足と最も近い標本の距離が $\Delta/2$ 以下だからである。

頂点だけを多角形の標本にすると、弧の中点から最も近い頂点までの距離 $2R\sin(\pi/(2n)) \approx \pi R/n$ を測ることになる。
これは辺の長さの半分ほどで、多角形の形ではなく頂点の間隔を表し、$n$ に対して $-1$ 次でしか減らない。

次のブロックは 2 つのセルが共有する定義である。
`circle_samples` と `polygon_samples` は上の標本を 1 行 1 点の $(x, y)$ の順で返す。
頂点だけの標本は `polygon_samples(radius, sides, 1)` である。
セルはこの座標を `PointSet::from_rows(&coordinates, 2)` で借用し、複製せずに `directed_hausdorff` に渡す。

```rust
//| id: spatial-hausdorff-polygon-model
//| kind: definitions
//| title: 円と内接正多角形の標本
//| crates: [scioxide-core]
use scioxide_core::RealScalar;

/// 円の上の点。辺ごとに s 個で、角度は 2π(i + t/s)/n。
pub(crate) fn circle_samples(radius: f64, sides: usize, per_edge: usize) -> Vec<f64> {
    let total = sides * per_edge;
    (0..total)
        .flat_map(|k| {
            let angle = 2.0 * core::f64::consts::PI * k as f64 / total as f64;
            [
                radius * RealScalar::cos(angle),
                radius * RealScalar::sin(angle),
            ]
        })
        .collect()
}

/// 内接正 n 角形の各辺を s 等分した点（頂点を含む）。
pub(crate) fn polygon_samples(radius: f64, sides: usize, per_edge: usize) -> Vec<f64> {
    let vertex = |i: usize| {
        let angle = 2.0 * core::f64::consts::PI * (i % sides) as f64 / sides as f64;
        [
            radius * RealScalar::cos(angle),
            radius * RealScalar::sin(angle),
        ]
    };
    (0..sides * per_edge)
        .flat_map(|k| {
            let (i, t) = (k / per_edge, (k % per_edge) as f64 / per_edge as f64);
            let (a, b) = (vertex(i), vertex(i + 1));
            [a[0] + t * (b[0] - a[0]), a[1] + t * (b[1] - a[1])]
        })
        .collect()
}
```

## 両方向の距離と外れ値

次のセルは辺の数 $n$、辺あたりの標本数 $s$、外れ値の距離 $\delta$ [mm] を選び、円の標本 $C$ と多角形の標本 $P$ の間の有向 Hausdorff 距離を両方向で求める。
$\delta > 0$ のときは、頂点 $v_0 = (R, 0)$ の外側 $(R + \delta, 0)$ に 1 点を加えた集合を $C$ として使う。
測定の誤りで円の外に 1 点が混じった状況にあたり、$h(C, P)$ は $\max(\text{標本化を考えた予想}, \delta)$ になるはずで、$h(P, C)$ は変わらない。
表は 2 つの方向について、測った距離、弦の高さ $H_n$、比、標本化を考えた予想（$s$ が奇数なら $R(\cos\varphi - \cos\theta)$）、距離を与える点対の 2 点の偏角を示す。
$C$ と $P$ の点の数の積が $1.1 \times 10^6$ 以下なら、`pairwise` で全点対の距離行列を作り、行と列の最小値の最大を総当たりの値として比べる。

```rust
//| id: spatial-hausdorff-polygon-approximation
//| ref: spatial-hausdorff-polygon-approximation
//| title: 円と内接正多角形の有向 Hausdorff 距離を両方向で測る
//| run: reactive
//| uses: [spatial-hausdorff-polygon-model]
//| crates: [scioxide-core, scioxide-spatial]
//| exports: [radius, per_edge]

//|   per_edge: {"type":"range","label":"辺あたりの標本数 s","min":2,"max":32,"step":1,"value":8}
//|   outlier: {"type":"range","label":"外れ値の距離 δ [mm]","min":0,"max":5,"step":0.1,"value":0}
//| cases:
//|   - {"id":"odd-samples","label":"s = 3","description":"弧の中点が標本に入らず、測った値は H_n の約 8/9 になる。","inputs":{"per_edge":3}}
//|   - {"id":"outlier","label":"δ = 2.5 mm","description":"円の側の外れ値 1 点で h(C, P) だけが δ に変わる。","inputs":{"outlier":2.5}}
//|   - {"id":"fine","label":"n = 128, s = 32","description":"点の数の積が大きく、総当たりの照合は省略される。","inputs":{"sides":128,"per_edge":32}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"directions","path":"/rows/0/1","approx":{"value":0.85185434277329,"rtol":1e-12}}

//|       - {"artifact":"directions","path":"/rows/0/5","approx":{"value":345.0,"atol":1e-9}}
//|       - {"artifact":"directions","path":"/rows/0/7","approx":{"value":0.85185434277329,"rtol":1e-12}}

//|   - case: odd-samples
//|     expect:
//|       - {"artifact":"directions","path":"/rows/0/1","approx":{"value":0.75704351279462,"rtol":1e-12}}
//|       - {"artifact":"directions","path":"/rows/0/4","approx":{"value":0.75672179506693,"rtol":1e-12}}
//|   - case: outlier
//|     expect:
//|       - {"artifact":"directions","path":"/rows/0/1","approx":{"value":2.5,"rtol":1e-14}}
//|       - {"artifact":"directions","path":"/rows/0/5","approx":{"value":0.0,"atol":1e-12}}
//|       - {"artifact":"directions","path":"/rows/1/1","approx":{"value":0.85185434277329,"rtol":1e-12}}
//|   - case: fine
//|     expect:
//|       - {"artifact":"directions","path":"/rows/0/3","approx":{"value":1.0,"atol":1e-11}}
//|       - {"artifact":"directions","path":"/rows/0/7","equals":null}
use scioxide_core::RealScalar;
use scioxide_spatial::{PointSet, directed_hausdorff, pairwise};

let radius = 25.0; // [mm]
let (n, s) = (sides as usize, per_edge as usize);
let mut circle = circle_samples(radius, n, s);
if outlier > 0.0 {
    circle.extend([radius + outlier, 0.0]);
}
let polygon = polygon_samples(radius, n, s);
let circle_set = PointSet::from_rows(&circle, 2).map_err(|e| e.to_string())?;
let polygon_set = PointSet::from_rows(&polygon, 2).map_err(|e| e.to_string())?;
let forward = directed_hausdorff(&circle_set, &polygon_set).map_err(|e| e.to_string())?;
let backward = directed_hausdorff(&polygon_set, &circle_set).map_err(|e| e.to_string())?;

// 弦の高さ H_n = 2R sin²(θ/2) と、s が奇数のときの予想 R(cos φ − cos θ)（φ = π/(ns)）。
// 1 − cos θ の桁落ちを避けるため、どちらも正弦の積の形で計算する。
let theta = core::f64::consts::PI / n as f64;
let sagitta = 2.0 * radius * RealScalar::sin(theta / 2.0) * RealScalar::sin(theta / 2.0);
let phi = if s % 2 == 0 { 0.0 } else { theta / s as f64 };
let sampled =
    2.0 * radius * RealScalar::sin((theta + phi) / 2.0) * RealScalar::sin((theta - phi) / 2.0);

// 総当たり: 距離行列の各行（円の点）の最小値の最大と、各列（多角形の点）の最小値の最大。
let (rows, columns) = (circle_set.len(), polygon_set.len());
let brute = if rows * columns <= 1_100_000 {
    let matrix = pairwise(&circle_set, &polygon_set).map_err(|e| e.to_string())?;
    let matrix = matrix.as_slice();
    let row_max = (0..rows)
        .map(|i| {
            matrix[i * columns..(i + 1) * columns]
                .iter()
                .copied()
                .fold(f64::MAX, f64::min)
        })
        .fold(0.0, f64::max);
    let column_max = (0..columns)
        .map(|j| {
            (0..rows)
                .map(|i| matrix[i * columns + j])
                .fold(f64::MAX, f64::min)
        })
        .fold(0.0, f64::max);
    Some((row_max, column_max))
} else {
    None
};

let degrees = |points: &[f64], k: usize| {
    let angle = RealScalar::atan2(points[2 * k + 1], points[2 * k]).to_degrees();
    if angle < 0.0 { angle + 360.0 } else { angle }
};
let table = vec![
    (
        "円 C → 多角形 P",
        forward.distance,
        sagitta,
        forward.distance / sagitta,
        sampled.max(outlier),
        degrees(&circle, forward.source),
        degrees(&polygon, forward.target),
        brute.map(|b| b.0),
    ),
    (
        "多角形 P → 円 C",
        backward.distance,
        sagitta,
        backward.distance / sagitta,
        sampled,
        degrees(&polygon, backward.source),
        degrees(&circle, backward.target),
        brute.map(|b| b.1),
    ),
];
let fixed6 = serde_json::json!({ "significantDigits": 6 });
let fixed4 = serde_json::json!({ "fractionDigits": 4 });
let fixed2 = serde_json::json!({ "fractionDigits": 2 });
let columns = serde_json::json!([
    { "key": "0", "label": "方向" },
    { "key": "1", "label": "有向 Hausdorff 距離 h [mm]", "type": "number", "format": fixed6 },
    { "key": "2", "label": "弦の高さ H_n [mm]", "type": "number", "format": fixed6 },
    { "key": "3", "label": "h / H_n [-]", "type": "number", "format": fixed4 },
    { "key": "4", "label": "標本化を考えた予想 [mm]", "type": "number", "format": fixed6 },
    { "key": "5", "label": "距離を与える点対の始点の偏角 [deg]", "type": "number", "format": fixed2 },
    { "key": "6", "label": "距離を与える点対の終点の偏角 [deg]", "type": "number", "format": fixed2 },
    { "key": "7", "label": "総当たりの値 [mm]", "type": "number", "format": fixed6, "nullText": "省略" }
]);
emit_table_with_columns!(
    columns,
    table,
    metadata = serde_json::json!({ "id": "directions" })
);
export!(radius, &radius);
export!(per_edge, &s);
```

既定値（$n = 12$、$s = 8$、外れ値なし）では、両方向の距離はどちらも $0.851854$ mm で、弦の高さ $H_{12}$ との比は $1 + 2 \times 10^{-15}$ である。
距離を与える点対の始点は偏角 $345°$ の点で、頂点 $330°$ と $360°$ の間の弧（または辺）の中点にあたる。
12 個の弧の中点は厳密には同じ距離にあるが、距離を与える点対は丸めた距離が最大の点のうち番号が最小の点なので、丸めの差で $345°$ の点が選ばれている。
`pairwise` の距離行列から求めた総当たりの値も同じ値になった。
$s = 3$ にすると弧の中点が標本から外れ、測った値は $0.757044$ mm（$H_{12}$ の 0.8887 倍）に下がる。
予想 $R(\cos\varphi - \cos\theta) = 0.756722$ mm との相対差は $4 \times 10^{-4}$ で、距離を与える点対の始点は中点から $5°$ ずれた偏角 $130°$ の標本である。

$\delta = 2.5$ mm の外れ値を加えると、$h(C, P)$ は外れ値を距離を与える点対の始点（偏角 $0°$）として $2.5$ mm になり、$H_{12}$ の 2.9 倍になる。
一方、$h(P, C)$ は $0.851854$ mm のままである。
対称な Hausdorff 距離は 1 点の外れ値でその距離まで上がる。
`scioxide-spatial` は最大の代わりに分位点をとる部分 Hausdorff 距離を提供しないので、測定値の集合を比べるときは外れ値を除いてから測る。
$n = 128$、$s = 32$ では点の数の積が $1.1 \times 10^6$ を超えるので、総当たりの照合は省略される。

## 辺の数に対する収束

次のセルは前のセルの $R$ と $s$ を受け取り、辺の数を $n = 4$ から $128$ まで増やして $h(C, P)$ を測る。
比べるために、多角形を頂点だけで標本化した $h(C, V)$ も測る。
グラフは両対数の軸で、実測を記号、閉形式の $H_n$ と $2R\sin(\pi/(2n))$ を破線で描く。
1 つ目の表は $n$ ごとの値で、2 つ目の表は $n \ge 8$ の $\ln h$ を $\ln n$ に最小二乗で当てはめた傾きを、理論の $-2$ と $-1$ と比べる。

```rust
//| id: spatial-hausdorff-polygon-convergence
//| ref: spatial-hausdorff-polygon-convergence
//| title: 辺の数に対する Hausdorff 距離の収束を測る
//| run: reactive
//| uses: [spatial-hausdorff-polygon-model]
//| crates: [scioxide-core, scioxide-spatial]
//| dependsOn:
//|   setup: spatial-hausdorff-polygon-approximation
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"slopes","path":"/rows/0/1","approx":{"value":-1.99636,"atol":1e-4}}
//|       - {"artifact":"slopes","path":"/rows/1/1","approx":{"value":-0.99818,"atol":1e-4}}
//|       - {"artifact":"convergence","path":"/rows/10/3","approx":{"value":1.0,"atol":1e-11}}
//|       - {"artifact":"convergence-chart","path":"/spec/series/1/points/0/1","approx":{"value":7.3223304703363,"rtol":1e-12}}
use scioxide_core::RealScalar;
use scioxide_spatial::{PointSet, directed_hausdorff};

let radius = setup["radius"].as_f64().ok_or("半径がない")?;
let s = setup["per_edge"].as_u64().ok_or("標本数がない")? as usize;
let sides = [4, 6, 8, 12, 16, 24, 32, 48, 64, 96, 128];
let mut rows = Vec::with_capacity(sides.len());
for n in sides {
    let circle = circle_samples(radius, n, s);
    let polygon = polygon_samples(radius, n, s);
    let vertices = polygon_samples(radius, n, 1);
    let circle_set = PointSet::from_rows(&circle, 2).map_err(|e| e.to_string())?;
    let polygon_set = PointSet::from_rows(&polygon, 2).map_err(|e| e.to_string())?;
    let vertex_set = PointSet::from_rows(&vertices, 2).map_err(|e| e.to_string())?;
    let edges = directed_hausdorff(&circle_set, &polygon_set).map_err(|e| e.to_string())?;
    let corners = directed_hausdorff(&circle_set, &vertex_set).map_err(|e| e.to_string())?;
    let half = core::f64::consts::PI / (2.0 * n as f64);
    let sagitta = 2.0 * radius * RealScalar::sin(half) * RealScalar::sin(half);
    let spacing = 2.0 * radius * RealScalar::sin(half);
    rows.push((
        n,
        sagitta,
        edges.distance,
        edges.distance / sagitta,
        spacing,
        corners.distance,
    ));
}

// n ≥ 8 の ln h を ln n に最小二乗で当てはめた傾き
let slope = |pick: &dyn Fn(&(usize, f64, f64, f64, f64, f64)) -> f64| {
    let points: Vec<(f64, f64)> = rows
        .iter()
        .filter(|r| r.0 >= 8)
        .map(|r| (RealScalar::ln(r.0 as f64), RealScalar::ln(pick(r))))
        .collect();
    let k = points.len() as f64;
    let (mx, my) = points
        .iter()
        .fold((0.0, 0.0), |(a, b), p| (a + p.0 / k, b + p.1 / k));
    let sxx: f64 = points.iter().map(|p| (p.0 - mx) * (p.0 - mx)).sum();
    let sxy: f64 = points.iter().map(|p| (p.0 - mx) * (p.1 - my)).sum();
    sxy / sxx
};
let fits = vec![
    ("辺の標本 h(C, P)", slope(&|r| r.2), -2.0),
    ("頂点だけ h(C, V)", slope(&|r| r.5), -1.0),
];

let series = |pick: &dyn Fn(&(usize, f64, f64, f64, f64, f64)) -> f64| -> Vec<[f64; 2]> {
    rows.iter().map(|r| [r.0 as f64, pick(r)]).collect()
};
let dashed = serde_json::json!({ "lineType": "dashed", "showSymbol": false });
let (circle_mark, diamond_mark) = (
    serde_json::json!({ "symbol": "circle" }),
```

既定値（$s = 8$）では、$h(C, P)$ と $H_n$ の比はすべての $n$ で 1 に $10^{-12}$ 以内で一致し、当てはめた傾きは $-1.9964$ である。
$H_n = 2R\sin^2(\pi/(2n))$ は $n^{-2}$ に厳密には比例しないので、$n \ge 8$ の範囲の傾きは $-2$ からわずかにずれる。
比の 1 からのずれは $n = 128$ で $6 \times 10^{-13}$ まで大きくなる。
距離は 25 mm 程度の座標の差から求めるので、丸め誤差は $\varepsilon R \approx 6 \times 10^{-15}$ mm 程度で、$H_{128} = 0.0075$ mm に対する相対誤差がその程度になるからである。
頂点だけの $h(C, V)$ は $2R\sin(\pi/(2n))$ に一致し、傾きは $-0.9982$ で、$n = 128$ でも $0.61$ mm と $H_{128}$ の約 80 倍である。
前のセルで $s$ を奇数にすると、$h(C, P)/H_n$ はほぼ一定の $1 - 1/s^2$（$s = 3$ なら 0.887〜0.889）になり、傾きは $-1.9962$ でほとんど変わらない。
このとき $h(C, V)$ も弧の中点を標本に含まないので $2R\sin(\pi/(2n))$ より小さくなるが、傾きは $-0.9992$ で $-1$ のままである。

## まとめ

円を内接正 $n$ 角形で近似したときの最大のずれは弦の高さ $2R\sin^2(\pi/(2n)) \approx \pi^2 R/(2n^2)$ で、$R = 25$ mm、$n = 12$ なら $0.85$ mm である。
有向 Hausdorff 距離でこれを測るには、多角形を頂点だけでなく辺の上でも標本化する。
頂点だけでは頂点の間隔 $\approx \pi R/n$ を測ってしまい、収束の次数も $-1$ に見える。
弧と辺の中点を標本に含めれば測った値は丸めの範囲で $H_n$ に一致し、含めない場合も相対誤差は $1/s^2$ 程度で次数は変わらない。
有向 Hausdorff 距離は方向で値が違い、外れ値 1 点で片方向の値がその距離まで上がるので、両方向の値と距離を与える点対の点を合わせて読む。
