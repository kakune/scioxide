各例題は天文学、水文学、統計、化学、宇宙工学、機械加工、ロボット工学の具体的な題材で `scioxide-spatial` を使い、結果を解析解、既知の値、総当たり、別の方法のどれかで確かめる。

| 例題 | 題材 | 主な API | 独立な検算 |

| [星表の角距離近傍探索](celestial-neighbor-search/) | 明るい恒星 30 個の角距離の近傍と、天球の球面 Voronoi 図 | `KdTree`、`radius_into`、`SphericalVoronoi` | haversine の式による角距離、全点の総当たり、領域の面積の和 $4\pi$ |

## まとめ

例題は 13 題で、どれも主計算とは別の方法による検算を同じページの中に持つ。
近傍探索と統計を確かめるには最近傍距離の統計と星表の例題を、分割の性質を確かめるには Delaunay 分割の最小角と外心、凸包の頂点数と周、Thiessen 領域とその格子点での照合の例題を読む。
回転と剛体変換の扱いは、分子の重ね合わせ、姿勢補間、ロボットアームの例題が示す。
各例題の操作入力を既定以外の値に変えると、理論値とのずれや、エラーになる配置がどう現れるかを確かめられる。
手法の数理は[数理と共通の規約](../algorithms/)から始まる各ページにある。
