二つの分子構造の違いは片方を回転・並進して重ねたあとの原子の位置の差、根平均二乗偏差（RMSD）で表すことが多い。
結晶構造と計算で最適化した構造の比較や、分子動力学の軌跡の各時刻と基準構造の比較に使う。
この例題では実験で決めた 4 つの小さな分子の構造に既知の剛体変換と測定誤差を模したノイズを加え、`estimate_rigid_transform_with_options` で重ね合わせる。
得られた RMSD をノイズの大きさから導いた期待値と比べ、平面の分子と直線の分子で何が起きるかを確かめる。

## 分子の座標と原子量

座標は NIST Computational Chemistry Comparison and Benchmark Database（CCCBDB）の実験構造の直交座標 [Å] を使う。
各分子の内部座標の出典と、座標から計算した結合距離は次のとおりである。

| 分子 | 原子数 | 形 | 座標から計算した結合距離 [Å] | 内部座標の出典（CCCBDB の引用） |
|---|---|---|---|---|
| ベンゼン C₆H₆ | 12 | 平面（$D_{6h}$） | C–C 1.397、C–H 1.084 | Herzberg (1966) |
| メタン CH₄ | 5 | 正四面体（$T_d$） | C–H 1.087 | Hirota (1979) |
| エタノール C₂H₅OH | 9 | トランス配座（C–C–O–H が 180°） | C–C 1.512、C–O 1.431、O–H 0.971、C–H 1.086〜1.098 | Coussan ら (1998) |
| 二酸化炭素 CO₂ | 3 | 直線（$D_{\infty h}$） | C–O 1.162 | Herzberg (1966) |

原子量は IUPAC の標準原子量の略値、H 1.008、C 12.011、O 15.999 を使う。
原子量で重みを付けると、重み付き重心は質量中心になる。

## 観測のモデルと RMSD

基準構造の原子の位置を $p_i$、観測した構造を

$$
q_i = R_{\text{true}}\, p_i + t_{\text{true}} + e_i, \qquad e_i \sim N(0, \sigma^2 I_3)
$$

とする。
$e_i$ は原子ごとに独立で、3 つの座標に同じ分散 $\sigma^2$ [Å²] を持つ等方的なノイズである。
重ね合わせは $\sum_i w_i \lvert R p_i + t - q_i\rvert^2$ を最小にする剛体変換を求め、RMSD はその最小値を重みの総和 $W$ で割った値の平方根で、`RigidEstimationResult::rms_residual` にあたる。
求め方は[剛体位置合わせと特異値分解](../../algorithms/rigid-registration/)で導いた Kabsch 法である。

## RMSD の期待値

ノイズが分子の大きさに比べて小さいとき、推定した剛体変換の真の値からのずれは 6 つの小さな量（並進 3、回転 3）で表せ、残差はノイズの線形な射影になる。
重み $w_i$ の最小二乗法で、残差の二乗和の期待値は

$$
\mathrm{E}\left[\sum_i w_i \lvert r_i\rvert^2\right] = \sigma^2\left(\operatorname{tr} D - \operatorname{tr}\!\left[(A^\top D A)^{-1} A^\top D^2 A\right]\right)
$$

である。
$r_i$ は原子 $i$ の残差、$A$ は剛体の微小変位を原子の変位へ写す $3n \times 6$ 行列、$D$ は各座標に $w_i$ を並べた $3n \times 3n$ の対角行列で、$\operatorname{tr} D = 3W$ である。
重み付き重心のまわりの座標 $x_i$ を使うと、$A^\top D A$ は並進のブロック $W I_3$ と回転のブロック（重み $w_i$ の慣性テンソル）

$$
I_w = \sum_i w_i\left(\lvert x_i\rvert^2 I_3 - x_i x_i^\top\right)
$$

のブロック対角になる。
したがって

$$
\frac{\mathrm{E}\left[\mathrm{RMSD}^2\right]}{\sigma^2} \approx 3 - \frac{1}{W}\left(\frac{3\sum_i w_i^2}{W} + \operatorname{tr}\!\left(I_w^{-1} I_{w^2}\right)\right)
$$

を得る。
$I_{w^2}$ は重みを $w_i^2$ にした慣性テンソル（同じ重心のまわり）である。
重みが一様なら $\sum_i w_i^2 / W = 1$、$I_{w^2} = I_w$ で、

$$
\mathrm{E}\left[\mathrm{RMSD}^2\right] \approx \frac{\sigma^2 (3n - 6)}{n}
$$

となる。
$3n$ 個の座標から 6 つの自由度を当てはめた残りが残差に残る、という自由度の数え方と一致する。
原子量の重みでは、並進の当てはめが重い原子のノイズをほぼ吸収するので、係数は一様の場合より小さくなる。
この式はノイズについて 1 次の近似である。
どの大きさのノイズまで当てはまるかは、下の反復のセルで確かめる。

直線の分子では、分子の軸まわりの回転で原子が動かないので $I_w$ が特異になり、上の式は使えない。
同じ理由で、回転は観測から決まらない（[一意性と階数の判定](oxref:spatial-kabsch-uniqueness)）。
平面の分子（ベンゼン）は、平面内のどの軸まわりの回転でも原子が動くので $I_w$ は正則で、相互共分散の階数は 2 になるが回転は一意に決まる。

次のブロックは 2 つのセルが共有する定義である。
`MOLECULES` が上の 4 分子の座標、`Element::mass` が原子量、`weights` が一様または原子量の重み、`bonds` が距離 1.6 Å 以下の原子の組（3 次元の図の結合）を返す。
`expected_rms_squared` は上で導いた係数 $c = \mathrm{E}[\mathrm{RMSD}^2]/\sigma^2$ を慣性テンソルから求め、$I_w$ が特異なら `None` を返す。
3×3 の逆行列は余因子で求め、この係数は検算のための参照値である。
`observe_and_fit` は観測 $q_i$ を作り、選んだ重みを `estimate_rigid_transform_with_options` に渡して重ね合わせる。

```rust
/// 一様（すべて 1）または原子量の重み。
pub(crate) fn weights(molecule: &Molecule, by_mass: bool) -> Vec<f64> {
    molecule
        .atoms
        .iter()
        .map(|(element, _)| if by_mass { element.mass() } else { 1.0 })
        .collect()
}

/// 距離 1.6 Å 以下の原子の組（結合）。
pub(crate) fn bonds(molecule: &Molecule) -> Vec<(usize, usize)> {
    let atoms = molecule.atoms;
    let mut pairs = Vec::new();
    for i in 0..atoms.len() {
        for j in i + 1..atoms.len() {
            let d2: f64 = (0..3)
                .map(|k| (atoms[i].1[k] - atoms[j].1[k]) * (atoms[i].1[k] - atoms[j].1[k]))
                .sum();
            if d2 <= 1.6 * 1.6 {
                pairs.push((i, j));
            }
        }
    }
    pairs
}

/// 重み付き重心のまわりの慣性テンソル Σ wᵢ (|xᵢ|² I − xᵢ xᵢᵀ)。
fn inertia(points: &[[f64; 3]], w: &[f64], centroid: [f64; 3]) -> [[f64; 3]; 3] {
    let mut tensor = [[0.0; 3]; 3];
    for (p, &wi) in points.iter().zip(w) {
        let x = [0, 1, 2].map(|k| p[k] - centroid[k]);
        let r2 = x[0] * x[0] + x[1] * x[1] + x[2] * x[2];
        for a in 0..3 {
            for b in 0..3 {
                let delta = if a == b { r2 } else { 0.0 };
                tensor[a][b] += wi * (delta - x[a] * x[b]);
            }
        }
    }
    tensor
}

/// 線形化した E[RMSD²]/σ² = 3 − (3 Σwᵢ²/W + tr(I_w⁻¹ I_{w²}))/W。
/// 慣性テンソル I_w が特異（直線分子）なら None。3×3 の逆行列は余因子で求める（参照値）。
pub(crate) fn expected_rms_squared(molecule: &Molecule, w: &[f64]) -> Option<f64> {
    let points: Vec<[f64; 3]> = molecule.atoms.iter().map(|(_, p)| *p).collect();
    let total: f64 = w.iter().sum();
    let centroid =
        [0, 1, 2].map(|k| points.iter().zip(w).map(|(p, wi)| wi * p[k]).sum::<f64>() / total);
    let squared: Vec<f64> = w.iter().map(|wi| wi * wi).collect();
    let a = inertia(&points, w, centroid);
    let b = inertia(&points, &squared, centroid);
    let cofactor = |i: usize, j: usize| {
        let (r0, r1) = ((j + 1) % 3, (j + 2) % 3);
        let (c0, c1) = ((i + 1) % 3, (i + 2) % 3);
        a[r0][c0] * a[r1][c1] - a[r0][c1] * a[r1][c0]
    };
    let det: f64 = (0..3).map(|j| a[0][j] * cofactor(j, 0)).sum();
    let scale = a[0][0] + a[1][1] + a[2][2];
    if det <= 1e-12 * scale * scale * scale {
        return None;
    }
    let trace: f64 = (0..3)
        .flat_map(|i| (0..3).map(move |j| (i, j)))
        .map(|(i, j)| cofactor(i, j) * b[j][i])
        .sum::<f64>()
        / det;
    Some(3.0 - (3.0 * squared.iter().sum::<f64>() / total + trace) / total)
}

/// 観測 qᵢ = R pᵢ + t + eᵢ（eᵢ の各成分は N(0, σ²)）を作り、重ね合わせる。
pub(crate) fn observe_and_fit(
    molecule: &Molecule,
    truth: RigidTransform<f64>,
    noise: &Normal<f64>,
    w: &[f64],
    rng: &mut SplitMix64,
) -> Result<(Vec<f64>, Result<RigidEstimationResult<f64>, SciOxideError>), SciOxideError> {
    let n = molecule.atoms.len();
    let mut source = Vec::with_capacity(3 * n);
    let mut target = Vec::with_capacity(3 * n);
    for (_, p) in molecule.atoms {
        source.extend_from_slice(p);
        for x in truth.apply(*p)? {
            target.push(x + noise.sample(rng)?);
        }
    }
    let p = PointSet::from_rows(&source, 3)?;
    let q = PointSet::from_rows(&target, 3)?;
    let fit = estimate_rigid_transform_with_options(&p, &q, Some(w), RigidEstimationOptions::new());
    Ok((target, fit))
}
```

## 1 回の観測での重ね合わせ

次のセルはシードから scioxide-random の `SpecialOrthogonalGroup` で一様な（Haar 測度の）回転行列を引き、`Rotation::from_matrix` で `Rotation` にして真の回転とする。
並進は $(5, -3, 2)$ Å に固定する。
各座標に `Normal` で $N(0, \sigma^2)$ のノイズを加えた観測を 4 つの分子について作り、選んだ重みで重ね合わせる。
表 `molecules` は原子数、階数、特異値、RMSD、上の期待値の平方根 $\sqrt{\mathrm{E}[\mathrm{RMSD}^2]}$、真の回転との差 $d(R_{\text{true}}, R)$ [deg]、失敗したときのエラーの分類を示す。
特異値は、相互共分散行列を絶対値が最大の成分で割ってから求めた無次元の値である。
1 回の観測の RMSD は期待値のまわりにばらつくので、期待値との照合は次のセルの反復の平均で行う。
3 次元の図は選んだ分子の基準構造と、推定した変換の逆 $T^{-1}$ で基準の座標系へ戻した観測構造を、同じ単位 [Å] で示す。
推定できない二酸化炭素では、観測構造をそのまま示す。

```rust
let (item, observed, aligned) = scene.ok_or("選んだ分子がない")?;
let (observed_group, observed_label) = if aligned {
    ("aligned", "T⁻¹ で戻した観測構造")
} else {
    ("observed", "観測構造（戻せない）")
};
let title = format!("{}の基準構造と観測構造", item.name);
let mut points = Vec::new();
let mut edges = Vec::new();
for (i, (_, p)) in item.atoms.iter().enumerate() {
    points.push(
        serde_json::json!({ "id": format!("ref-{i}"), "position": p, "group": "reference" }),
    );
    points.push(serde_json::json!({
        "id": format!("obs-{i}"),
        "position": observed[i],
        "group": observed_group
    }));
}
for (i, j) in bonds(item) {
    edges.push(serde_json::json!({ "from": format!("ref-{i}"), "to": format!("ref-{j}") }));
    edges.push(serde_json::json!({ "from": format!("obs-{i}"), "to": format!("obs-{j}") }));
}
emit_scene3d!(
    serde_json::json!({
        "points": points,
        "edges": edges,
        "groups": [
            { "id": "reference", "label": "基準構造" },
            { "id": observed_group, "label": observed_label }
        ],
        "axes": {
            "x": { "label": "x", "unit": "Å" },
            "y": { "label": "y", "unit": "Å" },
            "z": { "label": "z", "unit": "Å" }
        }
    }),
    metadata = serde_json::json!({ "id": "structure", "title": title })
);
```

既定値（$\sigma = 0.05$ Å、一様の重み、シード 11）では、ベンゼンは階数 2（$\sigma_3 = 0$）で、$\sigma_1 = 1.155$ と $\sigma_2 = 1.154$ がほぼ等しい。
六回対称の平面分子では平面内の広がりが等方的だからで、回転は一意に決まり、真の回転との差は 0.84° である。
メタンとエタノールは階数 3 で、回転の誤差は 2.45° と 1.61° である。
RMSD はベンゼン 0.0617 Å、メタン 0.0630 Å、エタノール 0.0798 Å で、期待値の平方根 0.0791 Å、0.0671 Å、0.0764 Å のまわりにある。
二酸化炭素は `InvalidInput` になり、RMSD と回転の誤差の欄は空欄になる。

原子量の重みにすると、期待値の平方根はベンゼン 0.0741 Å、メタン 0.0520 Å、エタノール 0.0638 Å に下がり、RMSD は 0.0717 Å、0.0473 Å、0.0651 Å になる。
メタンで下がり方が大きいのは、重みの 75% を持つ炭素のノイズを並進の当てはめがほぼ吸収し、重みで平均した残差から炭素の分がほとんど消えるからである。
3 次元の図では、$T^{-1}$ で戻したエタノールの観測構造が基準構造に重なり、原子ごとのずれはノイズの大きさ程度である。
二酸化炭素を選ぶと、観測構造は戻せず、真の回転と並進を受けた位置に描かれる。

## 反復の平均と期待値の比較

次のセルは同じ真の回転のもとでノイズだけを引き直して重ね合わせを $N$ 回繰り返し、RMSD² の標本平均 $\overline{\mathrm{RMSD}^2}$ とその標準誤差 $\mathrm{SE} = s/\sqrt{N}$（$s$ は標本標準偏差）を、一様と原子量の重みの両方で求める。
表 `statistics` は標本平均、標準誤差、線形化した期待値 $\sigma^2 c$ と、ずれを標準誤差で割った値 $z = (\overline{\mathrm{RMSD}^2} - \sigma^2 c)/\mathrm{SE}$ を示す。
近似が当てはまれば、$\lvert z\rvert$ はおおむね 2 以下になる。
$\sigma$ を分子の大きさと同じ程度まで上げると、近似の誤差が標準誤差を上回り、$\lvert z\rvert$ が大きくなる。
二酸化炭素はすべての反復で失敗するので、失敗の回数だけを示す。
反復の回数が多いと計算に時間がかかるので、このセルはボタンで実行する。

```rust
//| cases:
//|   - {"id":"moderate-noise","label":"σ = 2 Å","description":"ノイズが分子の大きさに近づいても、平均と期待値の差は標準誤差の程度にとどまる。","inputs":{"stat_noise":2}}

//|       - {"artifact":"statistics","path":"/rows/4/7","range":{"min":-3.5,"max":3.5}}

//|       - {"artifact":"statistics","path":"/rows/6/8","equals":500}
//|   - case: moderate-noise
//|     expect:
//|       - {"artifact":"statistics","path":"/rows/1/7","range":{"min":-3,"max":3}}
//|       - {"artifact":"statistics","path":"/rows/3/7","range":{"min":-3,"max":3}}
//|       - {"artifact":"statistics","path":"/rows/5/7","range":{"min":-3,"max":3}}
//|       - {"artifact":"statistics","path":"/rows/2/5","approx":{"value":7.2,"rtol":1e-12}}
//|   - case: visible-bias
//|     expect:
//|       - {"artifact":"statistics","path":"/rows/2/7","range":{"min":3}}
//|       - {"artifact":"statistics","path":"/rows/5/7","range":{"min":3}}
//|   - case: large-noise
//|     expect:
```

係数 $c$ は一様の重みでベンゼン 2.5、メタン 1.8、エタノール 2.33（$(3n - 6)/n$）、原子量の重みで 2.20、1.08、1.63 である。
二酸化炭素は 500 回すべてで失敗し、期待値は定義されない。
「σ = 2 Å」の場合も、二酸化炭素を除く 6 つの行の $z$ は −1.87〜1.64 で、平均と期待値の相対差は −3.4〜+3.7% である。
$N = 500$ の標準誤差は期待値の 1.1〜2.4% なので、この一致は 1 次の近似の偏りが数 % より小さいことを示すだけである。
「σ = 3 Å」の場合はメタン（一様）とエタノール（原子量）の $z$ が 3.6 と 3.9 になり、「σ = 5 Å」の場合はどちらも 6.9 になって、平均が期待値を上回る。

## まとめ

`estimate_rigid_transform_with_options` に原子の座標の組と重みを渡すと、RMSD は `rms_residual` として得られ、重みを原子量にすると重心は質量中心になる。
等方的なノイズ $\sigma$ に対する RMSD² の期待値は、一様な重みで $\sigma^2(3n - 6)/n$、一般の重みでは慣性テンソルを使った式で見積もれる。
二酸化炭素を除く 3 分子では $\sigma = 0.05$ Å と 2 Å のどちらでも、反復の平均と期待値の差は $N = 500$ の標準誤差（期待値の 1.1〜2.4%）では区別できなかった。
二つの構造の RMSD がこの期待値を大きく超えれば、測定誤差だけでは説明できない構造の違いがあると判断できる。
ベンゼンのような平面分子は階数 2 でも回転が一意に決まり、二酸化炭素のような直線分子は軸まわりの回転が決まらないので `InvalidInput` になる。
直線分子を比べるときは、原子間距離のような回転によらない量を使う。
