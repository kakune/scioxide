森林の樹木、組織の細胞核、地図上の店舗のような点の配置が一様にランダムかどうかは、各点から最も近い点までの距離（最近傍距離）で調べられる。
Clark と Evans（1954）は、平均最近傍距離を、点が一様にランダムなとき（完全空間ランダム性、CSR）の期待値で割った比 $R$ を指標にした。
$R < 1$ は点が集まっていることを、$R > 1$ は互いに避け合う規則的な配置を示す。
この例題では一様な点について $k$ 番目の近傍距離の分布と平均を閉形式で求め、`KdTree` の一括照会で測った値と標準誤差つきで比べる。
あわせて、KD 木の結果を総当たりの距離と照合し、$(1 + \varepsilon)$ 近似探索が距離をどれだけ大きく返すかを確かめる。

## 一様な点の k 番目の近傍距離

単位正方形の向かい合う辺を同一視したトーラス $T = [0, 1)^2$ に、$N$ 個の点を独立に一様に置く。
2 点 $x, y$ の距離は各座標の差を周期 1 で最も短くとった minimum image 距離

$$
d(x, y) = \sqrt{\sum_{i=1}^{2} \min\bigl(|x_i - y_i|,\ 1 - |x_i - y_i|\bigr)^2}
$$

とする。
点 $x$ から $k$ 番目に近い点までの距離を $R_k$ とする。

$r \le 1/2$ なら、$x$ を中心とする半径 $r$ の円板はトーラスの上で自分と重ならず、面積は $\pi r^2$ である。
残りの $N - 1$ 点のうち円板に入る点の数は、二項分布 $\mathrm{Bin}(N - 1, p)$、$p = \pi r^2$ に従う。
$R_k \le r$ は円板に $k$ 点以上が入ることなので、分布関数は

$$
F_k(r) = P(R_k \le r) = 1 - \sum_{j=0}^{k-1} \binom{N-1}{j} p^j (1 - p)^{N-1-j}, \qquad p = \pi r^2,\ 0 \le r \le \tfrac{1}{2}
$$

になる。
$k = 1$ では $F_1(r) = 1 - (1 - \pi r^2)^{N-1}$ で、点の密度 $\rho = N$（面積 1 あたりの点の数）を保って $N \to \infty$ とすると、Poisson 過程の分布 $1 - e^{-\rho \pi r^2}$ に近づく。

他の 1 点までの距離を $D$ とすると、$u \le \pi/4$ では $P(\pi D^2 \le u) = u$ で、$\pi D^2$ の分布関数はこの範囲で $[0, 1]$ の一様分布と一致する。
$U = \pi R_k^2$ は $N - 1$ 個のそのような値の $k$ 番目に小さい値（順序統計量）なので、ベータ分布 $\mathrm{Beta}(k, N - k)$ に従う。
$E[\sqrt{U}]$ をベータ関数で書くと、平均は

$$
E[R_k] = \frac{\Gamma(k + \tfrac{1}{2})\,\Gamma(N)}{\sqrt{\pi}\,\Gamma(k)\,\Gamma(N + \tfrac{1}{2})}
\approx \frac{\Gamma(k + \tfrac{1}{2})}{\Gamma(k)\sqrt{\pi \rho}}
$$

である。
近似の右辺は Poisson 過程の値で、$k = 1$ なら Clark–Evans の期待値 $1/(2\sqrt{\rho})$ になる。
二項モデルと Poisson 近似の比は $\sqrt{N}\,\Gamma(N)/\Gamma(N + \tfrac12) \approx 1 + 1/(8N)$ で、$N = 500$ では相対差が $2.5 \times 10^{-4}$ である。
これらの式は $r \le 1/2$ の範囲の式を全域で使うので、$R_k > 1/2$ となる確率 $P(\mathrm{Bin}(N - 1, \pi/4) < k)$ だけ誤差を含む。
この確率は $N \ge 100$、$k \le 10$ で $10^{-48}$ 未満なので無視できる。

Poisson 過程では $E[R_1^2] = 1/(\pi\rho)$ なので、最近傍距離の分散は $(4 - \pi)/(4\pi\rho) \approx 0.0683/\rho$ である。
Clark–Evans の比は、実測の平均 $\bar r$ を使って

$$
R = \frac{\bar r}{E[R_1]} = 2\bar r\sqrt{\rho}
$$

と書ける。
以下の表の比は Poisson 近似ではなく二項モデルの平均 $E[R_j]$ に対する比（実測平均 / $E[R_j]$）で、$j \ge 2$ の順位にも同じ形で示す。
$j = 1$ では、この比と Clark–Evans の $R$ は相対 $2.5 \times 10^{-4}$ だけ違う。

## 標準誤差と点どうしの相関

1 つの配置の $N$ 個の距離は独立ではない。
互いに最も近い 2 点（相互最近傍）は同じ距離を 2 回数え、平面の Poisson 過程では点の割合 $6\pi/(8\pi + 3\sqrt{3}) \approx 0.62$ がそのような対に属する（Cox 1981）。
そのため、1 つの配置の標本標準偏差を $\sqrt{N}$ で割った値は、平均の標準誤差を小さく見積もる。

ここでは $M$ 個の独立な配置を作り、配置ごとの平均 $m_1, \ldots, m_M$ から全体の平均 $\bar m$ と標準誤差 $\mathrm{SE} = s/\sqrt{M}$（$s$ は $m_i$ の標本標準偏差）を求める。
理論値が正しければ、$z = (\bar m - E[R_k])/\mathrm{SE}$ は近似的に自由度 $M - 1$ の $t$ 分布に従い、$M = 20$ では $|z| > 2.09$ となる確率が 5% である。
$z$ は統計的な比較であり、どの乱数のシードでも $|z| < 2$ になるわけではない。

## 周期境界と端の効果

`KdTreeOptions::with_periodic_box(Some(&[1.0, 1.0]))` は、各軸の長さ 1 の周期箱を与え、距離を minimum image 距離で測る。
座標は各軸 $i$ で箱の長さ $L_i$ に対して $[0, L_i)$ に入っている必要があり、外れた点は `InvalidInput` になる。
選択肢は `KdTree::with_options(&points, TreeMetric::Euclidean, options)` で木に渡す。
周期箱を与えない（`None`）と、普通の Euclid 距離で探索し、`KdTree::new(&points)` はこの既定の木を作る。

単位正方形の端に近い点は、円板の一部が正方形の外にはみ出し、その部分に近傍がない。
そのため周期境界を外すと、$R_k$ は理論値より大きくなる。
Donnelly（1978）は、面積 $A$、周長 $L$ の領域での最近傍距離の平均を、シミュレーションに当てはめた係数で

$$
E[R_1] \approx 0.5\sqrt{\frac{A}{N}} + \left(0.0514 + \frac{0.041}{\sqrt{N}}\right)\frac{L}{N}
$$

と近似した。
単位正方形（$A = 1$、$L = 4$）で $N = 500$ なら $0.02279$ で、トーラスの $0.02237$ より 1.9% 大きい。
$k$ が大きいほど探索する円板が広がり、はみ出す点の割合も増えるので、偏りは大きくなる。

## KD 木による一括照会

`KdTree` は、各節点で座標の広がりが最も大きい軸の中央値で点を二分し、深さは $\lceil \log_2 N \rceil$ 以下である。
構築の計算量は $O(dN\log N)$、メモリ使用量は $O(N + d)$ で、木は座標を複製せずに借用する。
最近傍の照会は、照会点から節点の箱までの距離が現在の $k$ 番目の距離を超える部分木を枝刈りする。
Friedman、Bentley、Finkel（1977）の解析では、低次元の一様な点で 1 回の照会の期待計算量は $O(\log N)$ である。

`KdTree::nearest_batch_into` に $k + 1$ を渡すと、すべての行について $k + 1$ 個の近傍を一度に求める。
照会する点は木に含まれているので、各行の先頭は自分自身（距離 0）で、$j$ 番目の近傍は行の $j$ 番目（0 から数える）に入る。
結果は距離の昇順、同じ距離では点の番号の昇順に並ぶ。
作業領域は `SearchWorkspaceRequest::new(k + 1, options).with_batch(N, N(k + 1), NonZeroUsize::MIN)` で確保し、照会そのものはメモリ領域を確保しない。
wasm では逐次に実行するので、ここでは `ExecutionContext::sequential()` を渡す。

次のブロックは 2 つのセルが共有する定義である。
`uniform_points` は `fill_uniforms` で単位正方形の一様な点を作り、$(x, y)$ の順で返す。
`fill_uniforms` の値は $[0, 1)$ に入るので、どの点も周期箱の条件を満たす。
`nearest_neighbors` は KD 木を作って全点の近傍を一括で求める。
`epsilon` は近似探索の許容 $\varepsilon$ で、0 なら厳密な探索になる。

```rust
//| id: spatial-nearest-neighbor-model
//| kind: definitions
//| title: 単位正方形の一様な点と KD 木の一括照会
//| crates: [scioxide-core, scioxide-random, scioxide-spatial]
use core::num::NonZeroUsize;
use scioxide_core::{ExecutionContext, SciOxideError};
use scioxide_random::{SplitMix64, fill_uniforms};
use scioxide_spatial::{
    KdTree, KdTreeOptions, Neighbor, PointSet, SearchOptions, SearchWorkspaceRequest, TreeMetric,
};

/// 単位正方形 [0, 1)² の一様な点 n 個を、1 行 1 点の (x, y) の順で返す。
pub(crate) fn uniform_points(rng: &mut SplitMix64, n: usize) -> Result<Vec<f64>, SciOxideError> {
    let mut coordinates = vec![0.0; 2 * n];
    let mut attempts = 0;
    fill_uniforms(rng, &mut coordinates, &mut attempts)?;
    Ok(coordinates)
}

/// 全点について近い順に neighbors 個の点を求める。各行の先頭は自分自身（距離 0）。
/// periodic なら単位正方形を周期箱にして minimum image 距離で測る。
pub(crate) fn nearest_neighbors(
    coordinates: &[f64],
    neighbors: usize,
    periodic: bool,
    epsilon: f64,
) -> Result<Vec<Neighbor<f64>>, SciOxideError> {
    let n = coordinates.len() / 2;
    let points = PointSet::from_rows(coordinates, 2)?;
    let side = [1.0, 1.0];
    let options = KdTreeOptions::default().with_periodic_box(periodic.then_some(&side[..]));
    let tree = KdTree::with_options(&points, TreeMetric::Euclidean, options)?;
    let search = SearchOptions::new().with_epsilon(epsilon);
    let request = SearchWorkspaceRequest::new(neighbors, search).with_batch(
        n,
        n * neighbors,
        NonZeroUsize::MIN,
    );
    let mut workspace = tree.workspace(request)?;
    let mut found = vec![Neighbor::default(); n * neighbors];
    tree.nearest_batch_into(
        &points,
        neighbors,
        search,
        &mut found,
        &mut workspace,
        ExecutionContext::sequential(),
    )?;
    Ok(found)
}
```

## k 番目の近傍距離の分布と平均

次のセルは点の数 $N$、近傍の順位 $k$、周期境界の有無、独立な配置の数 $M$、乱数のシードを選び、$M$ 個の配置で 1 番目から $k$ 番目までの近傍距離を測る。
乱数は生成器 `SplitMix64` から直接引き、同じシードからは同じ配置の列が出る。
グラフは全配置の $k$ 番目の距離を集めた経験分布関数（記号）と、二項モデルの $F_k$（破線）である。
横軸は距離に $\sqrt{\rho} = \sqrt{N}$ を掛けた無次元の距離 $r\sqrt{\rho}$ で、Poisson 近似の下では分布が $N$ によらなくなる。
表は順位 $j = 1, \ldots, k$ ごとに、二項モデルの平均、Poisson 近似、実測平均、標準誤差、$z$、実測平均と理論平均の比を示す。
このセルは $N$、$k$、周期境界の有無、シードを次のセルの照合にも渡す。

```rust
//| id: spatial-clark-evans-statistic
//| ref: spatial-clark-evans-statistic
//| title: 一様な点の k 番目の近傍距離を閉形式と比べる
//| run: reactive
//| uses: [spatial-nearest-neighbor-model]
//| crates: [scioxide-core, scioxide-random, scioxide-spatial]
//| exports: [point_count, neighbor_order, periodic, seed]
//| inputs:
//|   point_count: {"type":"range","label":"点の数 N","min":100,"max":2000,"step":100,"value":500}
//|   neighbor_order: {"type":"range","label":"近傍の順位 k","min":1,"max":10,"step":1,"value":3}
//|   periodic: {"type":"checkbox","label":"周期境界（トーラスの minimum image 距離）","value":true}
//|   replicates: {"type":"range","label":"独立な配置の数 M","min":5,"max":50,"step":5,"value":20}
//|   seed: {"type":"range","label":"乱数のシード","min":1,"max":100,"step":1,"value":1}
//| cases:
//|   - {"id":"open-square","label":"周期境界なし","description":"端に近い点の近傍が欠け、どの順位でも実測平均が理論値を上回る。","inputs":{"periodic":false}}
//|   - {"id":"many-points","label":"N = 2000, k = 10","description":"点を増やしても r√ρ で測った分布は変わらない。","inputs":{"point_count":2000,"neighbor_order":10}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"means","path":"/rows/0/1","approx":{"value":0.022366270642839,"rtol":1e-10}}
//|       - {"artifact":"means","path":"/rows/0/3","approx":{"value":0.022472403970250,"rtol":1e-9}}
//|       - {"artifact":"means","path":"/rows/2/6","range":{"min":0.99,"max":1.01}}
//|       - {"artifact":"cdf","path":"/spec/layers/0/points/100/1","approx":{"value":0.99639131095,"rtol":1e-8}}
//|   - case: open-square
//|     expect:
//|       - {"artifact":"means","path":"/rows/0/3","approx":{"value":0.022871657598803,"rtol":1e-9}}
//|       - {"artifact":"means","path":"/rows/2/6","range":{"min":1.02}}
//|       - {"artifact":"means","path":"/rows/2/5","range":{"min":4}}
//|   - case: many-points
//|     expect:
//|       - {"artifact":"means","path":"/rows/9/1","approx":{"value":0.039401321076731,"rtol":1e-10}}
//|       - {"artifact":"means","path":"/rows/9/6","range":{"min":0.99,"max":1.01}}
use scioxide_core::RealScalar;
use scioxide_random::{SeedableRng, SplitMix64};

let (n, k, m) = (
    point_count as usize,
    neighbor_order as usize,
    replicates as usize,
);
let pi = core::f64::consts::PI;
let mut rng = SplitMix64::from_seed(seed as u64);
// replicate_means[r][j − 1]: r 番目の配置での j 番目の近傍距離の平均
let mut replicate_means = Vec::with_capacity(m);
let mut pooled = Vec::with_capacity(m * n);
for _ in 0..m {
    let coordinates = uniform_points(&mut rng, n).map_err(|e| e.to_string())?;
    let found =
        nearest_neighbors(&coordinates, k + 1, periodic, 0.0).map_err(|e| e.to_string())?;
    // 各行の 0 番目は自分自身なので、j 番目の近傍は行の j 番目にある。
    let rows = found.chunks_exact(k + 1);
    let means: Vec<f64> = (1..=k)
        .map(|j| rows.clone().map(|row| row[j].distance).sum::<f64>() / n as f64)
        .collect();
    pooled.extend(rows.map(|row| row[k].distance * (n as f64).sqrt()));
    replicate_means.push(means);
}

// 二項モデルの平均 Γ(j + 1/2) Γ(N) / (√π Γ(j) Γ(N + 1/2)) を漸化式で求める。
let gamma_ratio_n = (1..n).fold(2.0 / RealScalar::sqrt(pi), |q, i| {
    q * i as f64 / (i as f64 + 0.5)
});
let gamma_ratio = |j: usize| {
    (1..j).fold(RealScalar::sqrt(pi) / 2.0, |q, i| {
        q * (i as f64 + 0.5) / i as f64
    })
};
let mut rows = Vec::with_capacity(k);
for j in 1..=k {
    let theory = gamma_ratio(j) * gamma_ratio_n / RealScalar::sqrt(pi);
    let poisson = gamma_ratio(j) / RealScalar::sqrt(pi * n as f64);
    let values: Vec<f64> = replicate_means.iter().map(|means| means[j - 1]).collect();
    let mean = values.iter().sum::<f64>() / m as f64;
    let variance = values.iter().map(|v| (v - mean) * (v - mean)).sum::<f64>() / (m - 1) as f64;
    let se = RealScalar::sqrt(variance / m as f64);
    rows.push((
        j,
        theory,
        poisson,
        mean,
        se,
        (mean - theory) / se,
        mean / theory,
    ));
}

// 経験分布関数（120 個の分位点）と二項モデルの F_k（r√ρ を横軸にする）
pooled.sort_by(f64::total_cmp);
let total = pooled.len();
let empirical: Vec<[f64; 2]> = (1..=120)
    .map(|q| q * total / 120 - 1)
    .map(|i| [pooled[i], (i + 1) as f64 / total as f64])
    .collect();
// F_k は上側の和 Σ_{j ≥ k} C(N − 1, j) pʲ (1 − p)^(N−1−j) で求め、F_k ≪ 1 での桁落ちを避ける。
let binomial_cdf = |scaled: f64| {
    let p = pi * scaled * scaled / n as f64;
    let mut term = RealScalar::powf(1.0 - p, (n - 1) as f64);
    let mut upper = 0.0;
    for j in 0..n {
        if j >= k {
            upper += term;
        }
        term *= (n - 1 - j) as f64 / (j + 1) as f64 * p / (1.0 - p);
    }
    upper
};
let theory_curve: Vec<[f64; 2]> = (0..=200)
    .map(|i| 3.5 * i as f64 / 200.0)
    .map(|s| [s, binomial_cdf(s)])
    .collect();
emit_chart!(
    serde_json::json!({
        "kind": "xy",
        "xLabel": "規格化した距離 r√ρ [-]",
        "yLabel": "分布関数 P(R_k ≤ r) [-]",
        "xMin": 0.0,
        "xMax": 3.5,
        "yMin": 0.0,
        "yMax": 1.0,
        "dataZoom": true,
        "tooltip": true,
        "layers": [
            {
                "id": "theory",
                "kind": "line",
                "name": "二項モデル F_k（閉形式）",
                "points": theory_curve,
                "style": { "lineType": "dashed", "showSymbol": false }
            },
            {
                "id": "empirical",
                "kind": "scatter",
                "name": "経験分布関数（KD 木）",
                "points": empirical,
                "style": { "symbol": "circle" }
            }
        ]
    }),
    metadata = serde_json::json!({ "id": "cdf" })
);

let fixed5 = serde_json::json!({ "significantDigits": 5 });
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let fixed2 = serde_json::json!({ "fractionDigits": 2 });
let fixed4 = serde_json::json!({ "fractionDigits": 4 });
let columns = serde_json::json!([
    { "key": "0", "label": "順位 j", "type": "integer" },
    { "key": "1", "label": "二項モデルの平均 E[R_j] [-]", "type": "number", "format": fixed5 },
    { "key": "2", "label": "Poisson 近似 [-]", "type": "number", "format": fixed5 },
    { "key": "3", "label": "実測平均 [-]", "type": "number", "format": fixed5 },
    { "key": "4", "label": "標準誤差 [-]", "type": "number", "format": sci3 },
    { "key": "5", "label": "z [-]", "type": "number", "format": fixed2 },
    { "key": "6", "label": "実測平均 / 二項モデルの平均 [-]", "type": "number", "format": fixed4 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "means" })
);
export!(point_count, &n);
export!(neighbor_order, &k);
export!(periodic, &periodic);
export!(seed, &(seed as u64));
```

既定値（$N = 500$、$k = 3$、$M = 20$、シード 1）では、最近傍（$j = 1$）の実測平均は $0.022472 \pm 0.000134$ で、二項モデルの $0.022366$ との差は $z = 0.79$ である。
表の比（二項モデルの平均に対する比）は 1.0047 で、Clark–Evans の比 $R = 2\bar r\sqrt{\rho}$ は 1.0050 である。
どちらも 1 との差は相対標準誤差 0.6% の範囲にある。
$j = 3$ では実測平均 $0.041936$ が理論値 $0.041937$ にほぼ重なり、グラフの経験分布関数も破線の $F_3$ の上にある。

周期境界を外すと、$j = 1$ の実測平均は $0.022872$（比 1.023、$z = 3.4$）に上がる。
これは Donnelly の近似値 $0.02279$ と、標準誤差 $0.00015$ の 0.6 倍の差で合う。
$j = 3$ では比が 1.031、$z = 6.4$ になり、順位が上がるほど端の効果が大きくなる。

$N = 2000$、$k = 10$ では、$j = 10$ の比は 0.9995（$z = -0.60$）で、横軸を $r\sqrt{\rho}$ にしたグラフの形は既定値の場合と変わらない。
このシードでは $j = 3$ の $z$ が $-3.1$ になるが、10 個の順位は同じ配置から求めるので互いに相関する。
シードを 2 から 7 に変えて $M = 50$ で測ると、10 個の順位の $|z|$ はすべて 2.4 以下だった。

## 総当たりとの照合と近似探索

KD 木の枝刈りが近傍を取りこぼしていないことは、全点対の距離を総当たりで計算すれば確かめられる。
総当たりは $O(N^2)$ の距離計算と、各点での $k$ 個の選択が必要で、KD 木の $O(N\log N)$ より大幅に重い。
次のセルは $N \le 1000$ のときだけ、セルの中で minimum image 距離（周期境界を外したときは Euclid 距離）を `f64` で直接計算し、$k$ 番目までの近傍の番号と距離を KD 木の結果と比べる。
この参照計算は SciOxide の距離関数を通らない独立な検算である。
継ぎ目越しの差は $1 - |\Delta|$ ではなく、KD 木と同じ $(1 - \max(a, b)) + \min(a, b)$ で求める（$a, b$ はその軸の 2 つの座標）。
$1 - |\Delta|$ は $|\Delta|$ がすでに丸められているので、同じ距離でも最後の桁が KD 木とずれることがある。

`SearchOptions::with_epsilon(ε)` を $\varepsilon > 0$ にすると、探索は現在の $k$ 番目の距離の $1/(1 + \varepsilon)$ 倍より遠い箱を枝刈りし、調べる節点を減らす。
その代わり、返される $i$ 番目の距離 $\tilde d_i$ は真の $i$ 番目の距離 $d_i$ に対して $d_i \le \tilde d_i \le (1 + \varepsilon) d_i$ を満たすだけになる。
最近傍距離の統計にこの距離を使うと、平均は上に偏り、Clark–Evans の比も 1 より大きく出る。

セルは前のセルの $N$、$k$、周期境界、シードを受け取り、1 つ目の配置と同じ点を作り直す。
表は順位 $j$ ごとに、総当たりと番号が一致しなかった点の数、距離の最大差、近似探索で番号が厳密な結果と異なった点の割合、比 $\tilde d_j / d_j$ の最大値と上限 $1 + \varepsilon$、上限を超えた点の数、平均距離の相対的な偏りを示す。

```rust
//| id: spatial-nearest-neighbor-search-check
//| ref: spatial-nearest-neighbor-search-check
//| title: KD 木の近傍を総当たりと近似探索で照合する
//| run: reactive
//| uses: [spatial-nearest-neighbor-model]
//| crates: [scioxide-core, scioxide-random, scioxide-spatial]
//| dependsOn:
//|   sample: spatial-clark-evans-statistic
//| inputs:
//|   epsilon: {"type":"range","label":"近似探索の許容 ε [-]","min":0,"max":2,"step":0.05,"value":0.5}
//| cases:
//|   - {"id":"exact","label":"ε = 0","description":"厳密な探索では番号の不一致も比の超過もない。","inputs":{"epsilon":0}}
//|   - {"id":"coarse","label":"ε = 2","description":"許容を広げると、平均距離の偏りが大きくなる。","inputs":{"epsilon":2}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"search","path":"/rows/2/1","equals":0}
//|       - {"artifact":"search","path":"/rows/2/2","range":{"max":1e-15}}
//|       - {"artifact":"search","path":"/rows/2/4","range":{"min":1.0,"max":1.5}}
//|       - {"artifact":"search","path":"/rows/2/6","equals":0}
//|       - {"artifact":"search","path":"/rows/2/7","approx":{"value":0.0074017647,"rtol":1e-6}}
//|   - case: exact
//|     expect:
//|       - {"artifact":"search","path":"/rows/2/3","equals":0}
//|       - {"artifact":"search","path":"/rows/2/7","equals":0}
//|   - case: coarse
//|     expect:
//|       - {"artifact":"search","path":"/rows/2/6","equals":0}
//|       - {"artifact":"search","path":"/rows/2/7","approx":{"value":0.056222785,"rtol":1e-6}}
use scioxide_random::{SeedableRng, SplitMix64};

let n = sample["point_count"].as_u64().ok_or("点の数がない")? as usize;
let k = sample["neighbor_order"].as_u64().ok_or("順位がない")? as usize;
let periodic = sample["periodic"].as_bool().ok_or("周期境界の指定がない")?;
let seed = sample["seed"].as_u64().ok_or("シードがない")?;
let mut rng = SplitMix64::from_seed(seed);
let coordinates = uniform_points(&mut rng, n).map_err(|e| e.to_string())?;
let exact = nearest_neighbors(&coordinates, k + 1, periodic, 0.0).map_err(|e| e.to_string())?;
let approximate =
    nearest_neighbors(&coordinates, k + 1, periodic, epsilon).map_err(|e| e.to_string())?;

// 総当たりの参照距離（f64 の直接計算）。周期境界では各軸の差を min(|Δ|, (1 − max) + min) にする。
// 継ぎ目越しの差を 1 − |Δ| ではなく (1 − max(a, b)) + min(a, b) で求め、KD 木と同じ丸めにそろえる。
let reference_distance = |i: usize, j: usize| {
    let squared: f64 = (0..2)
        .map(|axis| {
            let (a, b) = (coordinates[2 * i + axis], coordinates[2 * j + axis]);
            let delta = (a - b).abs();
            let wrapped = if periodic {
                delta.min((1.0 - a.max(b)) + a.min(b))
            } else {
                delta
            };
            wrapped * wrapped
        })
        .sum();
    squared.sqrt()
};
// KD 木と同じく、距離の昇順、同じ距離では番号の昇順に並べて k 個を残す。
let order = |a: &(f64, usize), b: &(f64, usize)| a.0.total_cmp(&b.0).then(a.1.cmp(&b.1));
let brute: Option<Vec<Vec<(f64, usize)>>> = (n <= 1000).then(|| {
    (0..n)
        .map(|i| {
            let mut all: Vec<(f64, usize)> = (0..n)
                .filter(|&j| j != i)
                .map(|j| (reference_distance(i, j), j))
                .collect();
            all.select_nth_unstable_by(k - 1, order);
            all.truncate(k);
            all.sort_by(order);
            all
        })
        .collect()
});

let mut rows = Vec::with_capacity(k);
for j in 1..=k {
    let pairs = || (0..n).map(|i| (exact[i * (k + 1) + j], approximate[i * (k + 1) + j]));
    let mismatches = brute.as_ref().map(|b| {
        (0..n)
            .filter(|&i| b[i][j - 1].1 != exact[i * (k + 1) + j].index)
            .count()
    });
    let largest_gap = brute.as_ref().map(|b| {
        (0..n)
            .map(|i| (b[i][j - 1].0 - exact[i * (k + 1) + j].distance).abs())
            .fold(0.0, f64::max)
    });
    let changed = pairs().filter(|(e, a)| e.index != a.index).count();
    let ratio_max = pairs()
        .map(|(e, a)| a.distance / e.distance)
        .fold(0.0, f64::max);
    let exceeded = pairs()
        .filter(|(e, a)| a.distance > (1.0 + epsilon) * e.distance)
        .count();
    let exact_mean = pairs().map(|(e, _)| e.distance).sum::<f64>();
    let approximate_mean = pairs().map(|(_, a)| a.distance).sum::<f64>();
    rows.push((
        j,
        mismatches,
        largest_gap,
        100.0 * changed as f64 / n as f64,
        ratio_max,
        1.0 + epsilon,
        exceeded,
        approximate_mean / exact_mean - 1.0,
    ));
}

let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let fixed1 = serde_json::json!({ "fractionDigits": 1 });
let fixed4 = serde_json::json!({ "fractionDigits": 4 });
let columns = serde_json::json!([
    { "key": "0", "label": "順位 j", "type": "integer" },
    { "key": "1", "label": "総当たりとの番号の不一致 [点]", "type": "integer", "nullText": "省略" },
    { "key": "2", "label": "総当たりとの最大距離差 [-]", "type": "number", "format": sci3, "nullText": "省略" },
    { "key": "3", "label": "近似で番号が変わった割合 [%]", "type": "number", "format": fixed1 },
    { "key": "4", "label": "比 d̃/d の最大値 [-]", "type": "number", "format": fixed4 },
    { "key": "5", "label": "上限 1 + ε [-]", "type": "number", "format": fixed4 },
    { "key": "6", "label": "上限を超えた点 [点]", "type": "integer" },
    { "key": "7", "label": "平均距離の相対偏り [-]", "type": "number", "format": sci3 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "search" })
);
```

既定値（$\varepsilon = 0.5$）では、総当たりとの番号の不一致はどの順位でも 0 で、この配置では距離の最大差も 0 だった。
近似探索では、番号が厳密な結果と変わった点は $j = 1, 2, 3$ で 0.2%、2.0%、6.8% で、比 $\tilde d_j/d_j$ の最大値は 1.12、1.20、1.46 と上限 1.5 の内側にある。
平均距離の相対偏りは $j = 3$ で $7.4 \times 10^{-3}$ で、前のセルの標準誤差（相対 0.4%）より大きい。
$\varepsilon = 2$ では $j = 3$ の 25% の点で番号が変わり、平均距離は 5.6% 大きくなる。
近似探索で得た距離を Clark–Evans の比に使うと、点の配置ではなく探索の近似によって $R > 1$ が出る。

## まとめ

単位トーラス上の一様な点では、$k$ 番目の近傍距離の分布は二項モデルの閉形式 $F_k$ で、平均は $\Gamma(k + \tfrac12)\Gamma(N)/(\sqrt{\pi}\Gamma(k)\Gamma(N + \tfrac12))$ で与えられる。
実測と比べるときは、独立な配置の平均から標準誤差を求め、$z$ で差の大きさを判断する。
1 つの配置の距離は相互最近傍の対で相関するので、その標準偏差を $\sqrt{N}$ で割っても標準誤差にはならない。
周期境界を外すと端の効果で平均が上に偏るので、有界な領域の点を検定するなら周期箱か Donnelly の補正のような端の扱いが要る。
`SearchOptions::with_epsilon` の近似探索は各距離を最大 $1 + \varepsilon$ 倍にするので、距離の統計を求める目的では $\varepsilon = 0$ を使う。
