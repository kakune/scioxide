ロボットアームの関節角から手先の位置と向きを求める計算を順運動学という。
各関節は親のリンクの座標系から子のリンクの座標系への剛体変換で、手先の位置はそれらの合成で決まる。
剛体変換の合成は順序で結果が変わるので、どの順に `compose` を呼ぶかが計算の要点になる。
この例題では平面内で動く 3 リンクのアームを `RigidTransform` で組み立て、閉形式の解と比べて合成の順序、逆変換、同次行列を確かめる。

## アームのモデルと閉形式

リンク $i$（$i = 1, 2, 3$）の長さを $l_i$ [m]、関節 $i$ の角を $\theta_i$ とする。
関節 1 は原点にあり、関節角はすべて $z$ 軸（紙面に垂直）まわりで、$\theta_1$ は $x$ 軸から、$\theta_2, \theta_3$ は一つ前のリンクから測る。
リンク $i$ の向きは $\Theta_i = \theta_1 + \cdots + \theta_i$ で、関節 2、関節 3、手先の位置は

$$
x_i = \sum_{j=1}^{i} l_j \cos\Theta_j, \qquad y_i = \sum_{j=1}^{i} l_j \sin\Theta_j
$$

である（$i = 1, 2, 3$ がそれぞれ関節 2、関節 3、手先）。
手先の向きは $\Theta_3 = \theta_1 + \theta_2 + \theta_3$ である。

## 関節の剛体変換と合成の順序

関節 $i$ の座標系からリンク $i$ の先端の座標系への変換は、$z$ 軸まわりに $\theta_i$ 回してから、回したリンクの方向に $l_i$ 進む写像

$$
T_i(p) = R_z(\theta_i)\,(p + l_i e_x) = R_z(\theta_i)\,p + R_z(\theta_i)\,l_i e_x
$$

で、回転 $R_z(\theta_i)$ と並進 $R_z(\theta_i)\,l_i e_x$ の `RigidTransform` である（$e_x = (1, 0, 0)$）。
手先（リンク 3 の先端）の位置を基準の座標系で求めるには、子の側から順に $T_3$、$T_2$、$T_1$ を適用する。

$$
p_{\text{手先}} = T_1\bigl(T_2\bigl(T_3(0)\bigr)\bigr) = (T_1 \circ T_2 \circ T_3)(0)
$$

`a.compose(b)` は `b` を先に適用する写像 $a \circ b$ を返すので、この合成は `t1.compose(t2)?.compose(t3)?` と書ける。
`compose` は回転の部分を四元数の積で合成して単位長さに正規化し直し、並進の部分 $R_a t_b + t_a$ は `apply` と同じく各成分を厳密な積和から 1 回だけ丸めて求める。
途中の $T_1(0)$ と $(T_1 \circ T_2)(0)$ が関節 2 と関節 3 の位置である。
展開すると $l_1 e(\Theta_1) + l_2 e(\Theta_2) + l_3 e(\Theta_3)$（$e(\phi) = (\cos\phi, \sin\phi, 0)$）になり、閉形式と一致する。

順序を入れ替えた $T_3 \circ T_2 \circ T_1$ は、長さ $l_3, l_2, l_1$ のリンクを角 $\theta_3, \theta_2, \theta_1$ でつないだ別のアームの手先にあたる。
回転の部分はどれも $z$ 軸まわりなので可換で、向きはどちらも $\theta_1 + \theta_2 + \theta_3$ になる。
並進の部分は可換でないので、手先の位置は一般に異なる。
回転と並進の組である剛体変換は、回転の軸がそろっていても可換ではない。

`RigidTransform::inverse` は $(R, t)^{-1} = (R^\top, -R^\top t)$ を返し、$T^{-1} \circ T$ と $T \circ T^{-1}$ は恒等写像になるはずである。
`as_matrix` は列ベクトル $[x, y, z, 1]^\top$ に作用する行優先の 4×4 同次行列

$$
\begin{pmatrix} R & t \\ 0 & 1 \end{pmatrix}
$$

を返し、合成は同次行列の積にあたる。

次のブロックは 2 つのセルが共有する定義である。
`joint` が $T_i$ を、`closed_form` が閉形式の関節と手先の位置を返す。
閉形式は検算のための参照値である。

```rust
//| id: spatial-robot-arm-model
//| kind: definitions
//| title: 平面 3 リンクのアームの関節変換と閉形式
//| crates: [scioxide-core, scioxide-spatial]
use scioxide_core::{SciOxideError, RealScalar};
use scioxide_spatial::{RigidTransform, Rotation};

/// T_i(p) = R_z(θ) (p + l e_x)。angle は度、length は m。
pub(crate) fn joint(angle: f64, length: f64) -> Result<RigidTransform<f64>, SciOxideError> {
    let rotation = Rotation::from_axis_angle([0.0, 0.0, 1.0], RealScalar::to_radians(angle))?;
    RigidTransform::new(rotation, rotation.apply([length, 0.0, 0.0])?)
}

/// 閉形式の関節 2、関節 3、手先の位置 (x_i, y_i) [m]（参照値）。
pub(crate) fn closed_form(angles: [f64; 3], lengths: [f64; 3]) -> [[f64; 2]; 3] {
    let mut heading = 0.0;
    let mut point = [0.0, 0.0];
    let mut out = [[0.0; 2]; 3];
    for i in 0..3 {
        heading += RealScalar::to_radians(angles[i]);
        point[0] += lengths[i] * RealScalar::cos(heading);
        point[1] += lengths[i] * RealScalar::sin(heading);
        out[i] = point;
    }
    out
}

/// z 軸まわりの回転の符号付きの角 [deg]（(−180°, 180°]）。
pub(crate) fn heading(rotation: Rotation<f64>) -> f64 {
    let (axis, angle) = rotation.as_axis_angle();
    let signed = if axis[2] < 0.0 { -angle } else { angle };
    RealScalar::to_degrees(signed)
}
```

## 閉形式との照合と順序を入れ替えた合成

次のセルは関節角 $\theta_1, \theta_2, \theta_3$ [deg] とリンクの長さ $l_1, l_2, l_3$ [m] を選び、各関節の `RigidTransform` を作って $T_1$、$T_1 \circ T_2$、$T_1 \circ T_2 \circ T_3$ で原点を写す。
表 `positions` は関節 2、関節 3、手先について、合成による位置、閉形式の位置、両者の距離、順序を入れ替えた $T_3$、$T_3 \circ T_2$、$T_3 \circ T_2 \circ T_1$ による位置を示す。
表 `heading` は二つの順序で合成した回転の向き（$z$ 軸まわりの符号付きの角）を $\theta_1 + \theta_2 + \theta_3$ と比べる。
グラフはアームを折れ線で描き、閉形式を破線、順序を入れ替えた合成を点線で重ねる。
軸の範囲はリンクの長さの上限から $x$ と $y$ のどちらも $\pm 3$ m に固定し、入力を変えても軸が動かないようにする。
このセルは角と長さを次のセルに渡す。

```rust

//| ref: spatial-robot-arm-kinematics

//| run: reactive

//| crates: [scioxide-core, scioxide-spatial]
//| exports: [angles, lengths]

//|   theta1: {"type":"range","label":"関節 1 の角 θ₁ [deg]","description":"x 軸から測ったリンク 1 の向き。","min":-180,"max":180,"step":5,"value":30}

//|   theta3: {"type":"range","label":"関節 3 の角 θ₃ [deg]","description":"リンク 2 から測ったリンク 3 の向き。","min":-180,"max":180,"step":5,"value":-60}

//|   - case: default

//|   - case: straight
//|     expect:
//|       - {"artifact":"positions","path":"/rows/2/1","approx":{"value":1.15,"atol":1e-15}}
//|       - {"artifact":"positions","path":"/rows/2/6","approx":{"value":1.15,"atol":1e-15}}
//|   - case: folded
//|     expect:
//|       - {"artifact":"positions","path":"/rows/2/1","approx":{"value":0.25,"atol":1e-15}}
//|       - {"artifact":"positions","path":"/rows/2/2","approx":{"value":0.1,"atol":1e-15}}
//|       - {"artifact":"positions","path":"/rows/2/5","range":{"max":1e-15}}
//|       - {"artifact":"positions","path":"/rows/2/6","approx":{"value":0.5,"atol":1e-15}}
//|       - {"artifact":"positions","path":"/rows/2/7","approx":{"value":-0.15,"atol":1e-15}}
//|       - {"artifact":"heading","path":"/rows/0/1","approx":{"value":0,"atol":1e-12}}
use scioxide_core::RealScalar;
use scioxide_spatial::RigidTransform;

let angles = [theta1, theta2, theta3];
let lengths = [length1, length2, length3];
let joints = [
    joint(theta1, length1).map_err(|e| e.to_string())?,
    joint(theta2, length2).map_err(|e| e.to_string())?,
    joint(theta3, length3).map_err(|e| e.to_string())?,
];
// 正しい順序: T₁, T₁∘T₂, T₁∘T₂∘T₃（compose の引数が先に適用される）。
let mut forward = Vec::new();
let mut chain = RigidTransform::identity();
for t in joints {
    chain = chain.compose(t).map_err(|e| e.to_string())?;
    forward.push(chain);
}
// 入れ替えた順序: T₃, T₃∘T₂, T₃∘T₂∘T₁。

    chain = chain.compose(*t).map_err(|e| e.to_string())?;

}

    let r = reversed[i].apply([0.0; 3]).map_err(|e| e.to_string())?;
    let c = reference[i];
    let gap = RealScalar::hypot(p[0] - c[0], p[1] - c[1]);
    rows.push((names[i], p[0], p[1], c[0], c[1], gap, r[0], r[1]));
}

let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let columns = serde_json::json!([

    { "key": "1", "label": "合成の x [m]", "type": "number", "format": fixed6 },

    { "key": "3", "label": "閉形式の x [m]", "type": "number", "format": fixed6 },
    { "key": "4", "label": "閉形式の y [m]", "type": "number", "format": fixed6 },
    { "key": "5", "label": "合成と閉形式の距離 [m]", "type": "number", "format": sci2 },
    { "key": "6", "label": "入れ替えた順序の x [m]", "type": "number", "format": fixed6 },
    { "key": "7", "label": "入れ替えた順序の y [m]", "type": "number", "format": fixed6 }

emit_table_with_columns!(

    rows,
    metadata = serde_json::json!({ "id": "positions" })
);

// 向き: 回転の部分は z 軸まわりで可換なので、どちらも θ₁ + θ₂ + θ₃ になる。
let total = theta1 + theta2 + theta3;
// (−180°, 180°] に折り返す。
let mut wrapped = total - 360.0 * RealScalar::round(total / 360.0);
if wrapped <= -180.0 {
    wrapped += 360.0;
}
let heading_rows = vec![
    ("T₁∘T₂∘T₃", heading(forward[2].rotation()), wrapped),
    ("T₃∘T₂∘T₁", heading(reversed[2].rotation()), wrapped),
];
let fixed9 = serde_json::json!({ "fractionDigits": 9 });
let heading_columns = serde_json::json!([
    { "key": "0", "label": "合成" },
    { "key": "1", "label": "回転の向き [deg]", "type": "number", "format": fixed9 },

]);
emit_table_with_columns!(
    heading_columns,
    heading_rows,
    metadata = serde_json::json!({ "id": "heading" })
);

let polyline = |points: &[[f64; 2]]| {
    let mut line = vec![[0.0, 0.0]];
    line.extend_from_slice(points);
    line
};
let arm: Vec<[f64; 2]> = rows.iter().map(|r| [r.1, r.2]).collect();
let swapped: Vec<[f64; 2]> = rows.iter().map(|r| [r.6, r.7]).collect();

    "layers": [
        {
            "id": "arm",
            "kind": "line",

            "style": { "showSymbol": true }
        },
        {
            "id": "closed-form",
            "kind": "line",
            "name": "閉形式",

export!(angles, angles);
```

既定値（$\theta = (30°, 45°, -60°)$、$l = (0.5, 0.4, 0.25)$ m）では、関節 2 は $(0.433013, 0.250000)$ m、関節 3 は $(0.536540, 0.636370)$ m、手先は $(0.778022, 0.701075)$ m で、閉形式との距離は $2.5 \times 10^{-16}$ m 以下である。
順序を入れ替えた $T_3 \circ T_2 \circ T_1$ の手先は $(0.994333, -0.190624)$ m で、0.92 m 離れた別の点になる。
回転の向きはどちらの順序でも 15°（$= 30° + 45° - 60°$）で、差は $10^{-14}$ 度の程度である。
$\theta = (0°, 0°, 0°)$ では、どちらの順序でも手先は $(1.15, 0)$ m になる。
並進がすべて $x$ 軸上にあり、回転が恒等なので、この場合は合成が可換になる。
$\theta = (90°, 180°, 90°)$ では、手先は $(0.25, 0.10)$ m と $(0.50, -0.15)$ m に分かれ、向きはどちらも 0° である。

## 逆変換と同次行列

次のセルは前のセルの角と長さで手先までの合成 $T = T_1 \circ T_2 \circ T_3$ を作り、逆変換 $T^{-1}$ との合成 $T^{-1} \circ T$ と $T \circ T^{-1}$ が恒等写像になるかを、回転の角 [rad] と並進の大きさ [m] で確かめる。
表 `matrix` は $T$ の 4×4 同次行列で、最後の列が手先の位置、左上の 3×3 が手先の向きの回転行列である。
列 1〜3 は回転行列と最下行の 0 で無次元、列 4 は上の 3 成分が並進 [m] で、最下行の 1 は無次元である。
同次行列から `RigidTransform::from_matrix` で変換を作り直し、元の $T$ との差も表 `inverse` に加える。

```rust
//| id: spatial-robot-arm-inverse
//| ref: spatial-robot-arm-inverse
//| title: 手先までの合成の逆変換と同次行列を確かめる
//| run: reactive
//| uses: [spatial-robot-arm-model]
//| crates: [scioxide-core, scioxide-spatial]
//| dependsOn:
//|   arm: spatial-robot-arm-kinematics
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"inverse","path":"/rows/0/1","range":{"max":1e-15}}
//|       - {"artifact":"inverse","path":"/rows/0/2","range":{"max":1e-15}}
//|       - {"artifact":"inverse","path":"/rows/1/2","range":{"max":1e-15}}
//|       - {"artifact":"inverse","path":"/rows/2/2","range":{"max":1e-15}}
//|       - {"artifact":"matrix","path":"/rows/0/4","approx":{"value":0.7780217765,"atol":1e-9}}
//|       - {"artifact":"matrix","path":"/rows/3/4","equals":1}
use scioxide_core::{RealScalar, Tolerance};
use scioxide_spatial::RigidTransform;

let read = |name: &str| -> Result<[f64; 3], String> {
    let values = arm[name].as_array().ok_or("配列がない")?;
    let mut out = [0.0; 3];
    for (o, v) in out.iter_mut().zip(values) {
        *o = v.as_f64().ok_or("数でない")?;
    }
    Ok(out)
};
let (angles, lengths) = (read("angles")?, read("lengths")?);
let mut tool = RigidTransform::identity();
for i in 0..3 {
    let t = joint(angles[i], lengths[i]).map_err(|e| e.to_string())?;
    tool = tool.compose(t).map_err(|e| e.to_string())?;
}
let inverse = tool.inverse().map_err(|e| e.to_string())?;
let matrix = tool.as_matrix();
let rebuilt = RigidTransform::from_matrix(matrix, Tolerance::from_sqrt_epsilon())
    .map_err(|e| e.to_string())?;
// 恒等写像からのずれ: 回転の角と並進の大きさ。
let deviation = |map: RigidTransform<f64>| {
    let t = map.translation();
    (
        map.rotation().as_axis_angle().1,
        RealScalar::hypot(RealScalar::hypot(t[0], t[1]), t[2]),
    )
};
let mut rows = Vec::new();
for (label, map) in [
    ("T⁻¹∘T", inverse.compose(tool).map_err(|e| e.to_string())?),
    ("T∘T⁻¹", tool.compose(inverse).map_err(|e| e.to_string())?),
    (
        "from_matrix(T)∘T⁻¹",
        rebuilt.compose(inverse).map_err(|e| e.to_string())?,
    ),
] {
    let (angle, shift) = deviation(map);
    rows.push((label, angle, shift));
}
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let columns = serde_json::json!([
    { "key": "0", "label": "合成" },
    { "key": "1", "label": "回転の角 [rad]", "type": "number", "format": sci2 },
    { "key": "2", "label": "並進の大きさ [m]", "type": "number", "format": sci2 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "inverse" })
);
let matrix_rows: Vec<(&str, f64, f64, f64, f64)> = ["1", "2", "3", "4"]
    .iter()
    .zip(matrix)
    .map(|(name, row)| (*name, row[0], row[1], row[2], row[3]))
    .collect();
let fixed6 = serde_json::json!({ "notation": "standard", "fractionDigits": 6 });
let matrix_columns = serde_json::json!([
    { "key": "0", "label": "行" },
    { "key": "1", "label": "列 1 [-]", "type": "number", "format": fixed6 },
    { "key": "2", "label": "列 2 [-]", "type": "number", "format": fixed6 },
    { "key": "3", "label": "列 3 [-]", "type": "number", "format": fixed6 },
    { "key": "4", "label": "列 4 [m]", "type": "number", "format": fixed6 }
]);
emit_table_with_columns!(
    matrix_columns,
    matrix_rows,
    metadata = serde_json::json!({ "id": "matrix" })
);
```

既定値では、$T^{-1} \circ T$ と $T \circ T^{-1}$ の回転の角はどちらも 0、並進の大きさは $2.9 \times 10^{-17}$ m と $8.2 \times 10^{-17}$ m で、恒等写像と丸めの水準で一致する。
同次行列の左上の 3×3 は $z$ 軸まわりの 15° の回転行列（$\cos 15° = 0.965926$、$\sin 15° = 0.258819$）で、最後の列は手先の位置 $(0.778022, 0.701075, 0)$ m、最後の行は $(0, 0, 0, 1)$ である。
`from_matrix` で作り直した変換と $T$ の差は、回転の角 $5.6 \times 10^{-17}$ rad、並進 $1.0 \times 10^{-16}$ m である。

## まとめ

関節を「回してからリンクの方向へ進む」`RigidTransform` で表し、`compose` の引数が先に適用されることに合わせて $T_1 \circ T_2 \circ T_3$ の順に合成すると、関節と手先の位置は閉形式と丸めの水準で一致する。
合成の順序を入れ替えると、平面のアームでは向き $\theta_1 + \theta_2 + \theta_3$ は変わらないが、並進が可換でないので手先の位置は変わる。
`inverse` との合成は恒等写像からの差が丸めの水準で、`as_matrix` の同次行列は最後の列に手先の位置、左上に向きの回転行列を持ち、`from_matrix` で元の変換に戻る。
空間内で動くアームでも、各関節を回転と並進の `RigidTransform` で表し、基準の側から順に `compose` すれば同じ手順で順運動学を計算できる。
