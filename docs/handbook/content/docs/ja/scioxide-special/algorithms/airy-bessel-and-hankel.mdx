円形膜の振動、円形の導波管、円柱の熱伝導のように円柱対称な領域の波や拡散の方程式を変数分離すると、動径方向に初等関数では書けない 2 階線形常微分方程式が現れる。
このページはその解である円柱 Bessel 関数 $J_\nu$、$Y_\nu$、$I_\nu$、$K_\nu$ と Hankel 関数 $H_\nu^{(1)}$、$H_\nu^{(2)}$ を扱う。
定義と性質に続いて、次数の三項漸化式を安定に使う向き、`scioxide-special` が引数と次数の領域ごとに使う方法、尺度化形・対数形・導関数、精度の保証、API の順に説明する。
大きな次数の転回点で使う Airy 関数は [Airy 関数と転回点](../airy-functions/) で、半整数次の球 Bessel 関数は [球 Bessel・球 Hankel・Riccati–Bessel 関数](../spherical-bessel-kelvin-and-riccati/) で、$e^{\mathrm{i}\pi/4}$ の向きの 0 次の Bessel 関数である Kelvin 関数は [Kelvin 関数と表皮効果](../kelvin-functions/) で扱う。
Bessel 関数の積分 `bessel_j0_integral` などは [Struve 関数と Bessel・Struve 関数の積分](../struve-parabolic-and-bessel-integrals/) で扱う。

## Bessel 方程式と解の分類

円柱座標 $(r, \theta, z)$ の Helmholtz 方程式 $\nabla^2\psi + k^2\psi = 0$ の解を $\psi = R(r)\,e^{\mathrm{i}\nu\theta}e^{\mathrm{i}k_z z}$ と分離すると、$x = k_r r$（$k_r^2 = k^2 - k_z^2$）の関数として $R$ は Bessel の微分方程式（DLMF 10.2.1）を満たす。

$$
x^2 y'' + x y' + (x^2 - \nu^2)\,y = 0.
$$

$\nu$ を次数、$x$ を引数と呼ぶ。

### 基本解の分類と物理的役割

第一種 Bessel 関数 $J_\nu$ は原点で正則な解で、定義の級数（DLMF 10.2.2）で表される。

$$
J_\nu(z) = \left(\frac{z}{2}\right)^{\nu}\sum_{k=0}^{\infty}\frac{(-z^2/4)^k}{k!\,\Gamma(\nu + k + 1)}.
$$

第二種 Bessel 関数 $Y_\nu$ は $Y_\nu = (J_\nu\cos\nu\pi - J_{-\nu})/\sin\nu\pi$（DLMF 10.2.3、整数次は極限）で定義され、$x \to 0$ で発散する（$Y_0(x) \sim \frac{2}{\pi}\ln x$）。
原点を含む領域（円形膜、円形の導波管）の解は $J_\nu$ だけで書け、原点を含まない環状の領域では $Y_\nu$ も必要になる。

変形 Bessel 関数 $I_\nu$、$K_\nu$ は $x^2 y'' + x y' - (x^2 + \nu^2)\,y = 0$ の解で、拡散方程式や静電・静磁場の円柱問題に現れる。

$$
I_\nu(z) = \left(\frac{z}{2}\right)^{\nu}\sum_{k=0}^{\infty}\frac{(z^2/4)^k}{k!\,\Gamma(\nu + k + 1)}, \qquad
K_\nu(z) = \frac{\pi}{2}\,\frac{I_{-\nu}(z) - I_\nu(z)}{\sin\nu\pi}.
$$

$I_\nu$ は原点で正則で $e^{x}/\sqrt{2\pi x}$ のように増大し、$K_\nu$ は $\sqrt{\pi/(2x)}\,e^{-x}$ のように減衰する（DLMF 10.40.1–2）。
$K_{-\nu} = K_\nu$ が成り立つ。

Hankel 関数は進行波を表す一次結合である（DLMF 10.4.3）。

$$
H_\nu^{(1)}(z) = J_\nu(z) + \mathrm{i}Y_\nu(z), \qquad H_\nu^{(2)}(z) = J_\nu(z) - \mathrm{i}Y_\nu(z), \qquad
H_\nu^{(1)}(x) \sim \sqrt{\frac{2}{\pi x}}\,e^{\mathrm{i}(x - \nu\pi/2 - \pi/4)}.
$$

時間因子を $e^{-\mathrm{i}\omega t}$ とすると、$H_\nu^{(1)}(kr)$ は外向きの円筒波で、Sommerfeld の放射条件を満たす。
`hankel_1`、`hankel_2` は実数の入力でも複素数 `Complex<T::Real>` を返し、実数の $x > 0$ では実部が `bessel_j`、虚部が $\pm$`bessel_y` に等しい。

Wronskian は次のとおりで（DLMF 10.5.2、10.5.5、10.28.2）、数値の検算に使える。

$$
\mathscr{W}\{J_\nu, Y_\nu\}(z) = \frac{2}{\pi z}, \qquad
\mathscr{W}\{H_\nu^{(1)}, H_\nu^{(2)}\}(z) = -\frac{4\mathrm{i}}{\pi z}, \qquad
\mathscr{W}\{K_\nu, I_\nu\}(z) = \frac{1}{z}.
$$

引数が実数のときの定義域は関数ごとに違う。
$J_\nu$ と $I_\nu$ は $x < 0$ を整数次に限って $J_n(-x) = (-1)^n J_n(x)$、$I_n(-x) = (-1)^n I_n(x)$ で受け付け、非整数次では `DomainError`（`OutsideDomain`）を返す。
負の非整数次の $J_\nu$、$I_\nu$ は $x = 0$ で発散するので、`DomainError`（`Pole`）を返す。
$Y_\nu$ と Hankel 関数は $x > 0$ だけを受け付け、$x = 0$ は `DomainError`（`Pole`）、$x < 0$ は `DomainError`（`OutsideDomain`）である。
$K_\nu$ は $x \ge 0$ を受け付け、$x = 0$ では極限の $+\infty$ を返す。
複素数の値は主枝で、切断は負の実軸に置き、切断上ではゼロの虚部の符号が上側と下側を選ぶ。

## 漸化式の向きと安定性

Bessel 関数は隣り合う次数の間で三項漸化式を満たす（DLMF 10.6.1、10.29.1）。

$$
C_{\nu-1}(z) + C_{\nu+1}(z) = \frac{2\nu}{z}C_\nu(z) \quad (C = J, Y, H^{(1)}, H^{(2)}), \qquad
I_{\nu-1}(z) - I_{\nu+1}(z) = \frac{2\nu}{z}I_\nu(z).
$$

$K_\nu$ は $K_{\nu+1} = K_{\nu-1} + (2\nu/z)K_\nu$ を満たす。
$\nu > x$ の範囲では、$J_\nu$ は次数とともに急に小さくなり、$Y_\nu$ は急に大きくなる。
このように一方の解が他方に比べて限りなく小さくなるとき、小さい方を極小解、大きい方を優越解と呼ぶ。

漸化式を次数の上がる向き（前進）に使うと、初期値の丸め誤差に含まれる優越解の成分が $Y_\nu/J_\nu$ の割合で増幅されるので、極小解 $J_\nu$ は前進の向きでは求まらない。
逆に次数の下がる向き（後退）では極小解が優越になるので、$J_\nu$ と $I_\nu$ は後退の向き、$Y_\nu$ と $K_\nu$ は前進の向きに安定である。
$\nu < x$ の振動領域では両解の大きさがそろうので、どちらの向きでも誤差は増幅されない。
下の [漸化式の向きによる誤差の増え方](#漸化式の向きによる誤差の増え方) のセルで、この違いを数値で確かめる。

### Miller の後退漸化式

Miller の方法は求めたい最大の次数より十分大きい次数 $M$ で $f_{M+1} = 0$、$f_M = 1$（任意の小さな値）と置いて後退の漸化式を回し、最後に既知の関係で全体を正規化する。
後退の向きでは極小解が優越になるので、$f_n$ は $M$ から離れるにつれて $J_n$ の定数倍に収束する。
正規化に使う関係は、$J_0(x) + 2\sum_{k\ge1}J_{2k}(x) = 1$（DLMF 10.12.4）、閉形式で求まる低次の値、Wronskian などである。
計算量は $M$ に比例し、$M$ は最大の次数と引数の大きいほうより少し大きく取る。

`scioxide-special` では、実数の球 Bessel 関数 $j_n$（$n > x$）と $i_n$、Riccati–Bessel 関数 $x\,j_n(x)$（$n > \lvert x\rvert$）が、閉形式の低次の値で正規化する Miller の方法を使う。
複素数の引数・次数の円柱 Bessel 関数は、中程度の $\lvert z\rvert$ で Wronskian で正規化する Miller の方法を使う。
引数と次数が実数の円柱 Bessel 関数は Miller の方法を使わない。

### Steed の方法と Temme の級数

実数の $J_\nu$、$Y_\nu$（$x > 2$）は Steed の方法（Barnett らの方法）で求める。
次数を $\nu = n + u$（$n$ は整数、$\lvert u\rvert \le 1/2$）に分け、まず連分数 CF1 で比 $J_{\nu+1}/J_\nu$ を求める。
この連分数は後退の漸化式と同じ極小解を選ぶので、比から後退の漸化式で $J_u$ までの比をたどれる。
次に、$u$ で連分数 CF2 により $p + \mathrm{i}q = (J_u' + \mathrm{i}Y_u')/(J_u + \mathrm{i}Y_u)$ を求める。
CF2 は $x \gtrsim 2$ で速く収束する。
二つの連分数と Wronskian $J_uY_u' - J_u'Y_u = 2/(\pi x)$ から $J_u$ と $Y_u$ の大きさが決まり、$Y$ は前進の漸化式で次数 $\nu$ まで上げる。
後退の漸化式は CF1 の比で正規化されるので、Miller の方法のように大きな次数から始める必要がない。

$x \le 2$ では CF2 の収束が遅くなるので、$Y_\nu$ と $K_\nu$ は Temme の級数で $\lvert u\rvert \le 1/2$ の 2 つの次数の値を求め、前進の漸化式で上げる。
Temme の級数は $u \to 0$ の極限を式の中で処理しているので、整数次で $1/\sin(u\pi)$ による見かけの特異点が現れない。
$K_\nu$ は $2 < x < 40$ では Steed の CF2 で、$x \ge 40$ では Hankel の漸近展開で $K_u$、$K_{u+1}$ を求め、前進の漸化式で上げる。

### 実数の評価領域

実数の次数と引数の円柱 Bessel 関数は `f64` の核で評価し、`f32` も `f64` で計算してから丸める。
打ち消しが起こる領域（$Y$ の零点の近く、級数の大きな項、位相の還元など）だけを2 ワードの算術で計算する。

| 関数と次数 | 領域 | 方法 |
|---|---|---|
| $J$、$Y$（$\nu = 0, 1$） | $x \le 8$ | 零点の因子を括り出した有理近似（Boost.Math 由来の係数） |
| $J$、$Y$（$\nu = 0, 1$） | $x > 8$ | $8/x$ の有理近似による振幅と、還元した位相 |
| $J$、$Y$（$\nu = 0, 1$） | $8 < x < 256$ で零点から $1/8$ 以内 | 各零点を中心とする Taylor 多項式 |
| $J$、$Y$ | $\nu \ge 1000$ かつ $\nu > 2\sqrt{x}$ | 一様漸近展開（転回点 $x = \nu$ から離れた所で Debye 展開、転回点を含む所で [Airy 関数](../airy-functions/) による Olver の展開、DLMF §10.19–10.20） |
| $J$ | $x \le 2$ | 定義の級数 |
| $Y$ | $x \le 2$ | Temme の級数と前進漸化式 |
| $J$、$Y$ | $x \ge 20$ かつ $\nu^2 \le 4x$（$x < 32$ では $\lvert 4\nu^2 - 1\rvert \le x/4$ のときだけ）、$x \ge 256$ では $\nu^2 \le 16x$ まで2 ワードの和で | Hankel の漸近展開（DLMF §10.17、項が `f64` の相対精度に達するときだけ） |
| $J$、$Y$ | それ以外の $x > 2$ | Steed の方法 |
| $I$（$\lvert\nu\rvert < 32$） | $x > 20$ | Hankel の漸近展開（DLMF §10.40、受理されるときだけ） |
| $I$（$\lvert\nu\rvert < 32$） | それ以外 | 定義の級数 |
| $K$（$\lvert\nu\rvert < 32$） | $x \le 2$、$2 < x < 40$、$x \ge 40$ | Temme の級数、Steed の CF2、Hankel の漸近展開のあと前進漸化式 |
| $I$、$K$ | $\lvert\nu\rvert \ge 32$ | Debye の一様漸近展開（DLMF §10.41） |
| 尺度化した $I_0$ | $[0, 8]$ と $[8, \infty)$ | Chebyshev 展開（Cephes の係数） |

$J$、$Y$ の負の次数 $\nu < -1/2$ は反転公式（DLMF §10.4）で正の次数に戻し、負の非整数次の $I$ は $I_{-\nu} = I_\nu + (2/\pi)\sin(\nu\pi)K_\nu$（DLMF 10.27.2）を使う。
Hankel の漸近展開は、項が発散し始める前に `f64` の相対精度まで小さくなるときだけ採用し、採用できないときは Steed の方法に戻る。

複素数の引数と次数では、原点の近くで定義の級数と Temme の級数を、中程度の $\lvert z\rvert$ で Wronskian で正規化した Miller の後退漸化式を、大きな $\lvert z\rvert$ で Hankel の漸近展開を使う。
$\lvert\nu\rvert \ge 64$ で Hankel の展開を採用できない場合は、右半平面で転回円の外側かつ $\lvert\arg z\rvert \le 3\pi/4$ の領域で、隣接する 2 つの次数の $K$ を Debye の展開で求め、項が丸めの水準まで減るときだけ採用する。
虚軸の近くでも転回円の外側の $I$ と $J$ はこの $K$ から接続するので、$\lvert z\rvert$ とともに深くなる Miller の漸化式を避けられる。
次数の位相 $e^{\mathrm{i}\pi\nu}$ は正確に還元し、引数による指数の尺度とは分けて持つ。

## 尺度化形・対数形・導関数

指数的に増大・減衰する関数は、値そのものが `f64` の範囲を超える前に、指数因子を除いた尺度化形で比べる。
尺度化形の因子は次のとおりで、実数の引数では $J$、$Y$ の因子は 1 である。

| 関数 | 返す値 | 範囲に収まる場面 |
|---|---|---|
| `bessel_j_scaled`、`bessel_y_scaled` | $e^{-\lvert\operatorname{Im}z\rvert}J_\nu(z)$、$e^{-\lvert\operatorname{Im}z\rvert}Y_\nu(z)$ | 虚部の大きい複素数の $z$ |
| `bessel_i_scaled` | $e^{-\lvert\operatorname{Re}z\rvert}I_\nu(z)$ | 大きな $\lvert\operatorname{Re}z\rvert$ |
| `bessel_k_scaled` | $e^{z}K_\nu(z)$（複素数では位相 $e^{\mathrm{i}\operatorname{Im}z}$ を含む） | 大きな $\operatorname{Re}z$ |
| `hankel_1_scaled`、`hankel_2_scaled` | $e^{-\mathrm{i}z}H_\nu^{(1)}(z)$、$e^{\mathrm{i}z}H_\nu^{(2)}(z)$ | 負または正の大きな $\operatorname{Im}z$ |

`bessel_k_log` は実数の $\nu$ と $x > 0$ で $\ln K_\nu(x)$ を返し、$K_\nu(x)$ があふれる小さな $x$・大きな $\lvert\nu\rvert$ や、アンダーフローする大きな $x$ でも有限の値を返す。
$\lvert\nu\rvert \ge 32$ では Debye の展開を対数のまま評価し、$x < 10^{-8}$ かつ $\lvert\nu\rvert \ge 3/2$ では主要項 $\ln(\Gamma(\lvert\nu\rvert)/2) - \lvert\nu\rvert\ln(x/2)$ を使う。
省いた補正項による対数の誤差（$K_\nu$ の相対誤差にほぼ等しい）は $x^2/(4(\lvert\nu\rvert - 1))$ 未満である。
`bessel_k` と違って $x = 0$ の極限値はなく、`DomainError`（`Pole`）を返す。

導関数の関数 `bessel_j_derivative` などは引数についての $k$ 階の導関数を `degree` に $k$ を渡して求める。
次数の違う関数の二項和（DLMF §10.6、§10.29）を使うので、計算量は $k$ に比例する。

$$
J_\nu^{(k)}(z) = 2^{-k}\sum_{m=0}^{k}(-1)^m\binom{k}{m}J_{\nu-k+2m}(z), \qquad
I_\nu^{(k)}(z) = 2^{-k}\sum_{m=0}^{k}\binom{k}{m}I_{\nu-k+2m}(z).
$$

$Y$ と Hankel 関数は $J$ と同じ符号、$K$ は $(-1)^k$ を掛けた $I$ と同じ形の和である。
`bessel_i_scaled_derivative` と `bessel_k_scaled_derivative` は尺度化しない関数の $k$ 階導関数に尺度の因子を掛けた値で、因子そのものは微分しない。
1 階の導関数だけでよければ、実数の $x > 0$、$\nu \ge -1/2$ では `bessel_j_with_options`、`bessel_y_with_options` の結果の `derivative()` も $J_\nu'$、$Y_\nu'$ を返し、隣の次数の計算を値と共有する。

### 正規化した J と重み付き積分

`bessel_lambda` は Jahnke–Emde の Lambda 関数 $\Lambda_\nu(x) = \Gamma(\nu + 1)(x/2)^{-\nu}J_\nu(x)$ を、実数の $\nu \ge 0$ と有限の $x$ で返す。

$$
\Lambda_\nu(x) = \sum_{k=0}^{\infty}\frac{(-x^2/4)^k}{k!\,(\nu + 1)_k}, \qquad \Lambda_\nu(0) = 1.
$$

$(\nu+1)_k$ は昇冪（Pochhammer 記号）である。
$\Gamma(\nu + 1)$ と $(x/2)^\nu$ を別々に作らないので、どちらかがあふれる大きな $\nu$ でも有限の値を返す。
$x^2 \le 16(\nu + 1)$ ではこの級数を足し、それより大きい $x$ では `bessel_j` に対数のガンマ因子を掛ける。

`bessel_weighted_integral` は $\int_0^1 t^\mu J_\nu(2at)\,dt$ を返す（引数の順は `a`、`exponent`（$\mu$）、`order`（$\nu$））。
積分は $\mu + \nu > -1$ で $t = 0$ で収束し、負の整数次は $\mu + \lvert\nu\rvert > -1$ を要する。
$a^2 \le 4(\nu + 1)$ では項別に積分した級数を足し、それより大きい $a$ では $t = u^q$ の変数変換で端点 $t = 0$ を滑らかにしてから、32 点の Gauss–Legendre 則の区分求積を二分して 2 段の値が一致するまで細かくする。
推定誤差は級数の打ち切りか求積の差から作る。
オプションは `BesselIntegralOptions` である。

## 精度の保証

ULP（unit in the last place）は、厳密な結果の位置での浮動小数点数の間隔である。
独立に生成した高精度の参照値で確かめた ULP の目標と、オプション付き形式が返す推定誤差を区別する。

実数の次数と引数の `bessel_j`、`bessel_y`、`bessel_i`、`bessel_k`、`bessel_i_scaled`、`bessel_k_scaled`、`hankel_1`、`hankel_2` は、`f64` と `f32` で 64 ULP 以内を目標とする。
この目標は試験した範囲で確かめたもので、受け付けるすべての引数で示したものではない。
$J$、$Y$ の試験範囲は 1000 未満の次数と $\sqrt{x}$ に近い次数で $x = 10^8$ までを含む。
零点の近くでは相対誤差が意味を持たないので、条件数から決めた絶対誤差の限界で判定する。
実数の `bessel_j_scaled`、`bessel_y_scaled` は `bessel_j`、`bessel_y` と同じ値なので同じ目標に従う。

複素数の引数と次数、`hankel_1_scaled`、`hankel_2_scaled`、導関数、`bessel_k_log`、`bessel_lambda`、`bessel_weighted_integral` には一様な ULP の仕様がない。
これらはオプション付き形式の推定誤差（`ValueWithError` の誤差。
包含区間ではない）を読み、族ごとの参照データで確かめた範囲を目安にする。

## API

どの関数にも値だけを返す標準形式、`SpecialFunctionResult` を返すオプション付き形式、求解スコープを受け取るスコープ付き API がある。
作業量の上限（`Budget`。
精度の要求ではない）は `BesselOptions`、`BesselIntegralOptions` で与え、既定はどちらも 65536 単位である。
円柱 Bessel・Hankel 関数は `NumericScalar` で、実数（`f32`、`f64`）と複素数を受け取る。
次数 `order` は `impl Parameter<T>` で、引数が複素数なら実数の次数も渡せる。

| 標準形式 | オプション付き形式 | スコープ付き API | 値 |
|---|---|---|---|

エラーの分類は族で共通である。
非有限な入力は `NonFinite`、定義域外と極は `DomainError`（`OutsideDomain`、`Pole`）、表せない値は `NumericalInstability`（`Overflow`）、作業量の上限で止まった評価は `ConvergenceFailure`（`IterationLimit`）を返す。
導関数の関数は、`degree` が残りの作業量を超えると `ConvergenceFailure` を返す。
`bessel_weighted_integral` は、端点で積分が収束しない指数（$\mu + \nu \le -1$、負の整数次では $\mu + \lvert\nu\rvert \le -1$）では `DomainError`（`Pole`）を、区分求積の区間をこれ以上二分できないときは `NumericalInstability`（`Breakdown`）を返す。

## 漸化式の向きによる誤差の増え方

次のセルは引数 $x$ と最大の次数 $N$ を選び、次数 $n = 0, \dots, N$ の $J_n(x)$、$Y_n(x)$ を三通りの漸化式で作って、`bessel_j`、`bessel_y` の値との相対誤差を比べる。
前進の $J$ と $Y$ は `bessel_j`、`bessel_y` が返す $n = 0, 1$ の値から始める。
Miller の $J$ は $M = \max(N, \lceil x\rceil) + 30$ の偶数から $f_{M+1} = 0$、$f_M = 10^{-200}$ で後退し、$J_0 + 2\sum J_{2k} = 1$ で正規化する。
漸化式そのものが説明の対象なので、セルの中で手で回し、`bessel_j`、`bessel_y` を参照値とする。
表は $n = N$ での三つの相対誤差と、API の値による Wronskian $J_{n+1}Y_n - J_nY_{n+1} = 2/(\pi x)$ の相対残差の最大を示す。

```rust
//| id: special-bessel-recurrence-direction
//| ref: special-bessel-recurrence-direction
//| title: 漸化式の向きで変わる J と Y の誤差
//| run: reactive
//| crates: [scioxide-special]
//| inputs:
//|   argument: {"type":"range","label":"引数 x [-]","description":"n > x の範囲で J は極小解になる。","min":1,"max":30,"step":1,"value":10}
//|   max_order: {"type":"range","label":"最大の次数 N [-]","description":"漸化式を回す最大の次数。","min":10,"max":60,"step":5,"value":40}
//| cases:
//|   - {"id":"oscillatory","label":"x = 30, N = 25","description":"すべての次数が n < x の振動領域にあり、前進の J も精度を保つ。","inputs":{"argument":30,"max_order":25}}
//|   - {"id":"small-argument","label":"x = 1, N = 60","description":"n > x がほぼ全域になり、前進の J は数次で桁を失う。","inputs":{"argument":1,"max_order":60}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"errors","path":"/rows/0/0","range":{"min":1e10}}
//|       - {"artifact":"errors","path":"/rows/0/1","range":{"max":1e-13}}
//|       - {"artifact":"errors","path":"/rows/0/2","range":{"max":1e-13}}
//|       - {"artifact":"errors","path":"/rows/0/3","range":{"max":1e-14}}
//|   - case: oscillatory
//|     expect:
//|       - {"artifact":"errors","path":"/rows/0/0","range":{"max":1e-12}}
//|       - {"artifact":"errors","path":"/rows/0/1","range":{"max":1e-12}}
//|   - case: small-argument
//|     expect:
//|       - {"artifact":"errors","path":"/rows/0/0","range":{"min":1e50}}
//|       - {"artifact":"errors","path":"/rows/0/1","range":{"max":1e-13}}
//|       - {"artifact":"errors","path":"/rows/0/3","range":{"max":1e-14}}
use scioxide_special::{bessel_j, bessel_y};

let x = argument;
let n_max = max_order as usize;
let mut reference_j = Vec::new();
let mut reference_y = Vec::new();
for n in 0..=n_max + 1 {
    reference_j.push(bessel_j(n as f64, x).map_err(|e| e.to_string())?);
    reference_y.push(bessel_y(n as f64, x).map_err(|e| e.to_string())?);
}

// 前進: C_{n+1} = (2n/x) C_n − C_{n−1}。初期値は API の n = 0, 1 の値。
let forward = |start: [f64; 2]| {
    let mut values = vec![start[0], start[1]];
    for n in 1..n_max {
        values.push(2.0 * n as f64 / x * values[n] - values[n - 1]);
    }
    values
};
let forward_j = forward([reference_j[0], reference_j[1]]);
let forward_y = forward([reference_y[0], reference_y[1]]);

// Miller: 偶数の M から後退し、J_0 + 2 Σ J_{2k} = 1 で正規化する。
let start = (n_max.max(x.ceil() as usize) + 30) / 2 * 2;
let mut miller = vec![0.0; start + 2];
miller[start] = 1e-200;
for n in (1..=start).rev() {
    miller[n - 1] = 2.0 * n as f64 / x * miller[n] - miller[n + 1];
}
let norm = miller[0] + 2.0 * miller[2..=start].iter().step_by(2).sum::<f64>();

let relative = |a: f64, b: f64| (a - b).abs() / b.abs();
let mut series = [Vec::new(), Vec::new(), Vec::new()];
let mut wronskian = 0.0_f64;
for n in 0..=n_max {
    let errors = [
        relative(forward_j[n], reference_j[n]),
        relative(miller[n] / norm, reference_j[n]),
        relative(forward_y[n], reference_y[n]),
    ];
    // 誤差が 0 の点は対数軸に描けないので除く。
    for (line, error) in series.iter_mut().zip(errors) {
        if error > 0.0 {
            line.push([n as f64, error]);
        }
    }
    let w = reference_j[n + 1] * reference_y[n] - reference_j[n] * reference_y[n + 1];
    let exact = 2.0 / (std::f64::consts::PI * x);
    wronskian = wronskian.max(relative(w, exact));
}
let [forward_j_line, miller_line, forward_y_line] = series;
emit_line_chart!(
    &vec![
        serde_json::json!({ "name": "前進の J", "points": forward_j_line }),
        serde_json::json!({ "name": "Miller の J", "points": miller_line }),
        serde_json::json!({ "name": "前進の Y", "points": forward_y_line }),
    ],
    options = &serde_json::json!({
        "xLabel": "次数 n [-]",
        "yLabel": "API の値との相対誤差 [-]",
        "yType": "log",
        "xMin": 0.0,
        "xMax": 60.0,
        "annotations": [{ "kind": "line", "axis": "x", "value": x, "label": "n = x" }]
    })
);

let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let columns = serde_json::json!([
    { "key": "0", "label": "前進の J の誤差 (n = N) [-]", "type": "number", "format": sci2 },
    { "key": "1", "label": "Miller の J の誤差 (n = N) [-]", "type": "number", "format": sci2 },
    { "key": "2", "label": "前進の Y の誤差 (n = N) [-]", "type": "number", "format": sci2 },
    { "key": "3", "label": "Wronskian の相対残差の最大 [-]", "type": "number", "format": sci2 }
]);
emit_table_with_columns!(
    columns,
    vec![(
        relative(forward_j[n_max], reference_j[n_max]),
        relative(miller[n_max] / norm, reference_j[n_max]),
        relative(forward_y[n_max], reference_y[n_max]),
        wronskian,
    )],
    metadata = serde_json::json!({ "id": "errors" })
);
```

既定の $x = 10$ では、前進の $J$ の誤差は $n \approx x$ までは丸めの水準にとどまり、$n > x$ で次数ごとに 1 桁前後ずつ増えて、$n = 26$ で値そのものより大きくなる。
同じ範囲で Miller の $J$ と前進の $Y$ の誤差は $10^{-13}$ 以下にとどまる。
$x = 30$、$N = 25$ のようにすべての次数が振動領域にあれば、前進の $J$ も精度を保つ。
このとき Miller の $J$ の誤差は $3 \times 10^{-14}$ 程度に増えるが、これは正規化の和 $J_0 + 2\sum J_{2k}$ の項の符号がそろわず、打ち消しが起こるためである。
$x = 1$ では前進の $J$ の相対誤差は $n = 7$ ですでに $10^{-6}$ に達し、有効数字は 6 桁ほどしか残らない。
これが、$J$ と $I$ を後退の向き、$Y$ と $K$ を前進の向きで使う理由である。
Wronskian の相対残差はどの入力でも $10^{-15}$ 以下で、API の $J_n$ と $Y_n$ が互いに整合していることを示す。

## まとめ

円柱座標の動径方向の解は、原点での正則性と放射条件に応じて $J$、$Y$、Hankel 関数から選ぶ。
指数的に変わる $I$、$K$ や虚部の大きな複素数の引数では、尺度化形か `bessel_k_log` を使う。
三項漸化式は極小解（$J$、$I$）には後退、優越解（$Y$、$K$）には前進の向きで使い、実数の $J$、$Y$ は Steed の方法、複素数の引数と球 Bessel 関数は Miller の方法でこの向きを守る。
実数の次数と引数の $J$、$Y$、$I$、$K$、Hankel 関数は試験した範囲で 64 ULP を目標とし、それ以外はオプション付き形式の推定誤差で精度を確かめる。
応用は [円形開口の Fraunhofer 回折と円筒波](../../examples/cylindrical-wave/) で強度とエネルギー流束を確かめる。
大きな次数の近似に使う転回点の関数は [Airy 関数と転回点](../airy-functions/) へ、半整数次は [球 Bessel・球 Hankel・Riccati–Bessel 関数](../spherical-bessel-kelvin-and-riccati/) へ、交流の表皮効果に現れる Kelvin 関数は [Kelvin 関数と表皮効果](../kelvin-functions/) へ進み、項目ごとの仕様は [Airy 関数・円柱 Bessel 関数・Hankel 関数](../../api/airy-and-bessel/) で確かめる。
