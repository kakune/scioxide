量子力学の WKB 近似や光学の焦線では、波が振動する領域と指数的に減衰する領域の境目（転回点）で、近似が破れる。
その境目の近くで方程式を一次まで展開すると、初等関数では書けない Airy 方程式が現れる。
このページは Airy 関数 $\operatorname{Ai}$、$\operatorname{Bi}$ の定義と性質、`scioxide-special` が実数と複素数の引数で使う評価法、尺度化形と導関数、精度の保証、API の順に説明する。
円柱座標の波動方程式から出る Bessel 関数は [円柱 Bessel 関数と Hankel 関数](../airy-bessel-and-hankel/) で扱い、そこでは大きな次数の転回点を Airy 関数で近似する。

## Airy 方程式と転回点

一次元の Schrödinger 方程式 $-\frac{\hbar^2}{2m}\psi'' + V(x)\psi = E\psi$ で、$V(x_0) = E$ となる古典的転回点 $x_0$ の近くを考える。
$V(x) - E \approx F\,(x - x_0)$ と一次まで展開し、長さを $(\hbar^2/(2mF))^{1/3}$ で無次元化すると、Airy 方程式（DLMF 9.2.1）が得られる。

$$
w''(z) = z\,w(z).
$$

$z < 0$ は古典的に許される領域で解は振動し、$z > 0$ は禁止された領域で解は指数的に減衰または増大する。
この方程式の具体的な応用は [重力場中の中性子の量子化と Airy 関数](../../examples/airy-turning-point/) で扱う。

二つの独立な解 $\operatorname{Ai}$ と $\operatorname{Bi}$ は、原点での値と傾き（DLMF §9.2）で決まる。

$$
\operatorname{Ai}(0) = \frac{3^{-2/3}}{\Gamma(2/3)}, \quad
\operatorname{Ai}'(0) = -\frac{3^{-1/3}}{\Gamma(1/3)}, \quad
\operatorname{Bi}(0) = \frac{3^{-1/6}}{\Gamma(2/3)}, \quad
\operatorname{Bi}'(0) = \frac{3^{1/6}}{\Gamma(1/3)}.
$$

両者は整関数なので、有限な実数・複素数の引数をすべて受け付け、分枝の切断はない。
Wronskian（二つの解 $f$、$g$ に対する $f g' - f' g$）は定数である（DLMF 9.2.7）。

$$
\mathscr{W}\{\operatorname{Ai}, \operatorname{Bi}\}(z) = \operatorname{Ai}(z)\operatorname{Bi}'(z) - \operatorname{Ai}'(z)\operatorname{Bi}(z) = \frac{1}{\pi}.
$$

$\zeta = \frac{2}{3}x^{3/2}$（$x > 0$）とおくと、主要項の漸近形は次のとおりである（DLMF 9.7.5、9.7.7、9.7.9、9.7.11）。

$$
\operatorname{Ai}(x) \sim \frac{e^{-\zeta}}{2\sqrt{\pi}\,x^{1/4}}, \qquad
\operatorname{Bi}(x) \sim \frac{e^{\zeta}}{\sqrt{\pi}\,x^{1/4}}, \qquad
\operatorname{Ai}(-x) \sim \frac{\cos(\zeta - \pi/4)}{\sqrt{\pi}\,x^{1/4}}, \qquad
\operatorname{Bi}(-x) \sim -\frac{\sin(\zeta - \pi/4)}{\sqrt{\pi}\,x^{1/4}}.
$$

束縛状態やトンネル効果の外側の解は $x \to +\infty$ で 0 に収束しなければならないので、$\operatorname{Ai}$ を選ぶ。

### Bessel 関数との関係

Airy 関数は次数 $\pm 1/3$ の Bessel 関数で書ける（DLMF §9.6）。
$\zeta = \frac{2}{3}z^{3/2}$ として、たとえば次の関係が成り立つ。

$$
\operatorname{Ai}(z) = \frac{1}{\pi}\sqrt{\frac{z}{3}}\,K_{1/3}(\zeta), \qquad
\operatorname{Bi}(z) = \sqrt{\frac{z}{3}}\left[I_{-1/3}(\zeta) + I_{1/3}(\zeta)\right].
$$

負の側では $K$、$I$ の代わりに $J_{\pm 1/3}$、$Y_{\pm 1/3}$ が現れる。
`scioxide-special` は、複素数の引数で $\lvert z\rvert$ が中程度のときにこの関係を使う。
逆向きに、大きな次数の Bessel 関数の転回点 $x = \nu$ の近くは Airy 関数で近似できる（DLMF §10.20）。

## 評価法

### 実数の Airy 関数の評価

`airy_ai` と `airy_bi` は実数の $\lvert x\rvert \le 16$ では最も近い整数 $m$ を中心とする 35 次の Taylor 多項式で評価する。
中心からの距離は $\lvert x - m\rvert \le 1/2$ なので、項は次数とともに速く小さくなる。
係数は微分方程式 $w'' = (m + h)\,w$（$h = x - m$）から決まる漸化式 $(k+2)(k+1)c_{k+2} = m\,c_k + c_{k-1}$ で前もって作り、中心での値 $c_0 = w(m)$、$c_1 = w'(m)$ とともに表にしてある。

低次の 8 項は2 ワードの算術（double-word、`f64` 二つで約 106 ビットを表す算術）を使う補償付きの Horner 法で、残りの高次の項は `f64` で足す。
丸め誤差の見積もりが値の $\varepsilon/16$（$\varepsilon$ は `f64` の機械イプシロン）を超えるとき、つまり関数か導関数の零点の近くでは、補償する項を 16 項、全項と増やして計算し直す。
打ち切った項の大きさは、係数の比が $(\lvert m\rvert + \lvert h\rvert)h^2/(36 \cdot 35)$ 程度で減ることから上から見積もり、推定誤差に加える。

$\lvert x\rvert > 16$ では DLMF §9.7 の漸近展開を使う。
負の実軸では振動の位相 $\zeta + \pi/4$ を2 ワードで持ち、$\zeta > 1024$ では $\zeta/(2\pi) = x^{3/2}/(3\pi)$ を固定小数点の $1/(3\pi)$ で計算して $2\pi$ を法として還元するので、$\lvert x\rvert$ が大きくても位相の丸め誤差が増えない。

$x \to +\infty$ では $\operatorname{Ai}(x)$ は `f64` で $x \approx 103.9$ から非正規化数になり、$x \approx 107.5$ で 0 に丸められる（エラーにはならない）。
$\operatorname{Bi}(x)$ は $x \approx 104.5$ からあふれて `NumericalInstability`（`Overflow`）になる。
どちらの場合も、尺度化形は有限の値を返す。

### 複素数の引数の評価

複素数の $z$ では、領域ごとに方法を変える。
表の上の行から順に、最初に当てはまる方法を使う。

| 領域 | 方法 |
|---|---|
| 実軸上（虚部が 0） | 実数と同じ方法 |
| $\lvert\operatorname{Re}z\rvert \ge 4$ かつ $\lvert\operatorname{Im}z\rvert\sqrt{\lvert\operatorname{Re}z\rvert} \le 1/4$ | 実軸上の値と導関数から、虚数方向へ Taylor 級数で移す |
| $\lvert z\rvert > 32$ | 漸近展開（DLMF §9.7）。二つの指数的な成分のうち、値に寄与するものだけを残す |
| $\lvert z\rvert \le 4$ | 原点での Maclaurin 級数（DLMF §9.4） |
| それ以外 | 次数 $1/3$、$2/3$ の Bessel 関数による関係（DLMF §9.6） |

$\operatorname{Bi}$ の零点が並ぶ $\arg z = \pm\pi/3$ の近くでは、Bessel 関数による関係が打ち消しで桁を失う。
そこで $\operatorname{Re}z > 0$、$\lvert z\rvert > 4$ かつ $\lvert\operatorname{Im}z/\operatorname{Re}z - \sqrt{3}\rvert < 0.6$ では、原点から $z$ まで微分方程式に沿って短い Taylor の刻みで値を運ぶ。
$\lvert\operatorname{Ai}(z)\rvert$ は $\pi/3 < \lvert\arg z\rvert < \pi$ の大きな $\lvert z\rvert$ で指数的に増大し、`f64` の範囲を超えると `NumericalInstability`（`Overflow`）を返す。

## 尺度化形と導関数

尺度化形は指数的に変わる因子を除いた値を返す。
実数の $x$ では、`airy_ai_scaled` は $e^{\zeta}\operatorname{Ai}(x)$ を、`airy_bi_scaled` は $e^{-\zeta}\operatorname{Bi}(x)$ を返し、$x \le 0$ では因子を掛けない。
複素数の $z$ では、`airy_ai_scaled` の因子は主値の平方根による $e^{\zeta}$（$\zeta = \frac{2}{3}z\sqrt{z}$）で、すべての $z$ で掛ける。
そのため負の実軸では、複素数として渡した結果が絶対値 1 の位相 $e^{\zeta}$ だけ実数の結果と違い、ゼロの虚部の符号が上側と下側を選ぶ。
`airy_bi_scaled` の複素数での因子は $e^{-\lvert\operatorname{Re}\zeta\rvert}$ である。

導関数を返す単独の関数はない。
オプション付き形式 `airy_ai_with_options`、`airy_bi_with_options` の結果の `derivative()` が $\operatorname{Ai}'$、$\operatorname{Bi}'$ を返す。
尺度化形のオプション付き形式は同じ因子を掛けた導関数を返し、因子そのものは微分しない。
値と導関数は同じ Taylor 多項式または展開から一緒に求めるので、導関数を加えても計算量はほとんど増えない。

## 精度の保証

ULP（unit in the last place）は、厳密な結果の位置での浮動小数点数の間隔である。
実数の `airy_ai`、`airy_bi`、`airy_ai_scaled`、`airy_bi_scaled` は、独立に生成した高精度の参照値と照合し、`f64` と `f32` で 64 ULP 以内を目標とする。
`f64` の照合データは $x = -10^{300}$ から $x = 110$ までを含む。
零点の近くでは相対誤差が意味を持たないので、条件数から決めた絶対誤差の限界で判定する。
この目標は試験した範囲で確かめたもので、受け付けるすべての引数で示したものではない。

複素数の引数には一様な ULP の仕様がない。
オプション付き形式の推定誤差（`ValueWithError` の誤差。
包含区間ではない）を読み、必要なら Wronskian $1/\pi$ のような恒等式で確かめる。

## API

どの関数にも値だけを返す標準形式、`SpecialFunctionResult` を返すオプション付き形式、求解スコープを受け取るスコープ付き API がある。
4 つの関数はどれも `NumericScalar` で、実数（`f32`、`f64`）と複素数を受け取る。
作業量の上限（`Budget`。
精度の要求ではない）は `AiryOptions` で与え、既定は 65536 単位である。

| 標準形式 | オプション付き形式 | スコープ付き API | 値 |
|---|---|---|---|
| `airy_ai` | `airy_ai_with_options` | `airy_ai_scoped` | $\operatorname{Ai}(z)$。オプション付き形式は $\operatorname{Ai}'(z)$ も返す |
| `airy_bi` | `airy_bi_with_options` | `airy_bi_scoped` | $\operatorname{Bi}(z)$。オプション付き形式は $\operatorname{Bi}'(z)$ も返す |
| `airy_ai_scaled` | `airy_ai_scaled_with_options` | `airy_ai_scaled_scoped` | $e^{\zeta}\operatorname{Ai}(z)$（実数の $x \le 0$ では因子なし） |
| `airy_bi_scaled` | `airy_bi_scaled_with_options` | `airy_bi_scaled_scoped` | $e^{-\lvert\operatorname{Re}\zeta\rvert}\operatorname{Bi}(z)$（実数の $x \le 0$ では因子なし） |

非有限な入力は `NonFinite` を返す。
尺度化しない値が表せないときは `NumericalInstability`（`Overflow`）を返す。
作業量の上限で止まった評価は、オプション付き形式では終了状態 `IterationLimit` の部分結果になり、推定値がなければ `ConvergenceFailure` を返す。

## 転回点の前後の Airy 関数

次のセルは幅 12 の観測区間の中心 $x_c$ を動かし、尺度化した Airy 関数 $e^{\zeta}\operatorname{Ai}(x)$ と $e^{-\zeta}\operatorname{Bi}(x)$（$x > 0$ で $\zeta = \frac{2}{3}x^{3/2}$、$x \le 0$ では尺度化なし）を描く。
尺度化しない $\operatorname{Bi}$ は $x = 10$ で $4.6 \times 10^8$ に達して振動側の形が読めなくなるが、尺度化形はウインドウの全体で 1 程度にとどまる。
破線は $x > 0$ の漸近形の主要項 $1/(2\sqrt{\pi}x^{1/4})$ と $1/(\sqrt{\pi}x^{1/4})$ で、`f64` の標準関数で計算した参照曲線である。
表はウインドウの中心での尺度化しない値と導関数、オプション付き形式の推定誤差、Wronskian と $1/\pi$ の差を示す。
導関数はオプション付き形式が返す値で、差分近似ではない。

```rust
//| id: special-airy-turning-window
//| ref: special-airy-turning-window
//| title: Airy 関数の観測区間を転回点の前後へ動かす
//| run: reactive
//| crates: [scioxide-special]
//| inputs:
//|   window_center: {"type":"range","label":"観測区間の中心 x_c [-]","description":"長さ 12 のウインドウを負側から正側へ動かす。","min":-6,"max":4,"step":0.5,"value":-1}
//| cases:
//|   - {"id":"forbidden","label":"x_c = 4","description":"禁止領域の中心では Ai が小さく Bi が大きいが、Wronskian は同じ 1/π になる。","inputs":{"window_center":4}}
//|   - {"id":"oscillatory","label":"x_c = −6","description":"ウインドウの全体が振動側に入り、二つの曲線は位相が π/2 ずれた振動になる。","inputs":{"window_center":-6}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"center","path":"/rows/0/1","approx":{"value":0.5355608832923521,"rtol":1e-14}}
//|       - {"artifact":"center","path":"/rows/0/2","approx":{"value":0.10399738949694461,"rtol":1e-14}}
//|       - {"artifact":"center","path":"/rows/0/6","range":{"max":1e-16}}
//|   - case: forbidden
//|     expect:
//|       - {"artifact":"center","path":"/rows/0/1","approx":{"value":9.515638512048008e-4,"rtol":1e-13}}
//|       - {"artifact":"center","path":"/rows/0/2","approx":{"value":83.84707140846553,"rtol":1e-13}}
//|       - {"artifact":"center","path":"/rows/0/6","range":{"max":1e-15}}
//|   - case: oscillatory
//|     expect:
//|       - {"artifact":"center","path":"/rows/0/6","range":{"max":1e-15}}
use scioxide_special::{
    AiryOptions, SpecialFunctionResult, airy_ai_scaled, airy_ai_with_options, airy_bi_scaled,
    airy_bi_with_options,
};

let left = window_center - 6.0;
let mut ai = Vec::new();
let mut bi = Vec::new();
let mut ai_theory = Vec::new();
let mut bi_theory = Vec::new();
for index in 0..=120 {
    let x = left + 12.0 * f64::from(index) / 120.0;
    ai.push([x, airy_ai_scaled(x).map_err(|e| e.to_string())?]);
    bi.push([x, airy_bi_scaled(x).map_err(|e| e.to_string())?]);
    if x >= 0.5 {
        // x > 0 の漸近形の主要項（f64 の標準関数による参照曲線）。
        let envelope = 1.0 / (std::f64::consts::PI.sqrt() * x.powf(0.25));
        ai_theory.push([x, 0.5 * envelope]);
        bi_theory.push([x, envelope]);
    }
}
let dashed = serde_json::json!({ "lineType": "dashed" });
emit_line_chart!(
    &vec![
        serde_json::json!({ "name": "e^ζ Ai(x)", "points": ai }),
        serde_json::json!({ "name": "e^−ζ Bi(x)", "points": bi }),
        serde_json::json!({ "name": "1/(2√π x^¼)", "points": ai_theory, "style": dashed }),
        serde_json::json!({ "name": "1/(√π x^¼)", "points": bi_theory, "style": dashed }),
    ],
    options = &serde_json::json!({
        "xLabel": "無次元座標 x [-]",
        "yLabel": "尺度化した Airy 関数 [-]",
        "xMin": -12.0,
        "xMax": 10.0,
        "yMin": -0.8,
        "yMax": 1.0,
        "annotations": [{ "kind": "line", "axis": "x", "value": 0.0, "label": "転回点 x = 0" }]
    })
);

// ウインドウの中心: 尺度化しない値、オプション付き形式の導関数と推定誤差、Wronskian。
let options = AiryOptions::default();
let a = airy_ai_with_options(window_center, options).map_err(|e| e.to_string())?;
let b = airy_bi_with_options(window_center, options).map_err(|e| e.to_string())?;
let value = |r: &SpecialFunctionResult<f64>| r.value().map(|v| *v.value()).ok_or("値がない");
let slope =
    |r: &SpecialFunctionResult<f64>| r.derivative().map(|v| *v.value()).ok_or("導関数がない");
let error =
    |r: &SpecialFunctionResult<f64>| r.value().map(|v| v.absolute_error()).ok_or("値がない");
let wronskian = value(&a)? * slope(&b)? - slope(&a)? * value(&b)?;
let sci6 = serde_json::json!({ "notation": "scientific", "significantDigits": 6 });
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let columns = serde_json::json!([
    { "key": "0", "label": "ウインドウの中心 x_c [-]", "type": "number" },
    { "key": "1", "label": "Ai(x_c) [-]", "type": "number", "format": sci6 },
    { "key": "2", "label": "Bi(x_c) [-]", "type": "number", "format": sci6 },
    { "key": "3", "label": "Ai′(x_c) [-]", "type": "number", "format": sci6 },
    { "key": "4", "label": "Bi′(x_c) [-]", "type": "number", "format": sci6 },
    { "key": "5", "label": "Ai の推定誤差 [-]", "type": "number", "format": sci2 },
    { "key": "6", "label": "|W − 1/π| [-]", "type": "number", "format": sci2 }
]);
emit_table_with_columns!(
    columns,
    vec![(
        window_center,
        value(&a)?,
        value(&b)?,
        slope(&a)?,
        slope(&b)?,
        error(&a)?,
        (wronskian - std::f64::consts::FRAC_1_PI).abs(),
    )],
    metadata = serde_json::json!({ "id": "center" })
);
```

$x < -2$ では二つの曲線は同じ包絡線 $\lvert x\rvert^{-1/4}/\sqrt{\pi}$ のもとで、位相が $\pi/2$ ずれた振動になる。
$x > 0$ では尺度化した $\operatorname{Ai}$ と $\operatorname{Bi}$ はそれぞれ破線に近づき、$x = 3$ での差はどちらも約 2 % である。
主要項との差は次の項 $\mp 5/(72\zeta)$ の大きさで、$x$ とともに $x^{-3/2}$ で減る。
Wronskian と $1/\pi$ との差が `f64` の丸めの水準（$10^{-16}$ 程度）を大きく超えたら、値か導関数のどちらかの精度が落ちている。
ただし値と導関数は同じ展開から求めているので、この残差が小さいことは参照値との照合の代わりにはならない。

## まとめ

Airy 関数は線形の転回点の解で、減衰する $\operatorname{Ai}$ と増大する $\operatorname{Bi}$ は Wronskian $1/\pi$ で結ばれる。
実数の $\lvert x\rvert \le 16$ は整数を中心とする 35 次の Taylor 多項式、それより外は位相を正確に還元した漸近展開で評価し、試験した範囲で 64 ULP を目標とする。
$x$ が 104 を超える正の側では $\operatorname{Bi}$ があふれ $\operatorname{Ai}$ が非正規化数になるので、`airy_ai_scaled`、`airy_bi_scaled` で比べる。
導関数はオプション付き形式の `derivative()` で値と一緒に得られ、複素数の引数では一様な ULP の仕様がないので推定誤差を読む。
エネルギー準位を零点から求める応用は [重力場中の中性子の量子化と Airy 関数](../../examples/airy-turning-point/) で、Airy 関数による Bessel 関数の大きな次数の近似は [円柱 Bessel 関数と Hankel 関数](../airy-bessel-and-hankel/) で確かめる。
