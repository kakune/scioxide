Student の $t$ 検定や $F$ 検定の有意確率、二項分布の裾、Bayes 推定の事後分布は、正則化不完全 Beta 関数で表される。
これは区間 $[0, 1]$ 上の積分を全体の積分 $B(a, b)$ で割った確率で、裾の小さな確率を 1 からの引き算で作ると有効数字が失われる。
このページは Beta 関数と対数 Beta 関数の評価法、正則化不完全 Beta 関数の評価法と、その相補形・対数形・逆関数を説明する。
Gamma 関数の評価は [Gamma 関数・polygamma 関数・Pochhammer 記号](../gamma-family/) で、不完全 Gamma 関数は [不完全 Gamma 関数](../incomplete-gamma/) で、誤差関数と逆誤差関数は [誤差関数・Dawson 積分・逆誤差関数](../error-functions/) で扱う。
ULP（unit in the last place）は真の値の位置での浮動小数点数の間隔、$\varepsilon = 2^{-52}$ は binary64 の計算機イプシロンである。

## Beta 関数と対数 Beta 関数

$a, b > 0$ に対する Beta 関数（Euler の第一種積分）は次の積分で定義される（DLMF 5.12.1）。

$$
B(a, b) = \int_0^1 t^{a-1} (1 - t)^{b-1} \, dt = \frac{\Gamma(a)\Gamma(b)}{\Gamma(a + b)}.
$$

置換 $t = 1 - u$ から対称性 $B(a, b) = B(b, a)$ が従い、Gamma 関数の商を通して複素数の $a, b$ へ解析接続される。
`beta` と `ln_beta` は実数と複素数（`NumericScalar`）を受け付ける。
実数では $a, b > 0$ を要求し、形状が 0 なら `DomainError`（`Pole`）、負なら `DomainError`（`OutsideDomain`）になる。
$B(a, b)$ が型の範囲を超える場合（形状の一方がほぼ $1/\text{最大値}$ より小さい場合）は `NumericalInstability`（`Overflow`）になり、オプション付き形式 `beta_with_options` は尺度化形と対数形を返す。
`ln_beta` は大きな形状でも小さな形状でもあふれない。

$a, b$ が 171 を超えると $\Gamma(a)$ 自身が binary64 の範囲を超えるので、Gamma 関数の積と商を直接作ることはできない。
対数をとって $\ln \Gamma(a) + \ln \Gamma(b) - \ln \Gamma(a + b)$ とすると、大きな形状では三つの大きな数の引き算になり、結果が小さいときは桁落ちする。
実数の `beta` と `ln_beta` は形状の大きさで方法を分ける。

- 一方の形状が 1 なら $B(1, b) = 1/b$ を使う。
- 両方が整数か半整数で $a + b \le 32$ なら、$B(1, 1) = 1$、$B(\tfrac12, \tfrac12) = \pi$ などから漸化式 $B(a + 1, b) = B(a, b)\, a/(a + b)$ の有限積で作る。
  因子を 2 倍した整数の積が $2^{53}$ 未満のうちは積が厳密なので、丸めは最後の 1 回だけになる。
- 両方が 64 未満（小さい方が $10^{-150}$ 以上）なら、各 Gamma 関数を漸化式 $\Gamma(x + 1) = x\Gamma(x)$ で引数 1 の近くへ下げて $1/\Gamma$ の級数で求め、比 $\Gamma(a)\Gamma(b)/\Gamma(a + b)$ を2 ワードの算術（2 つの binary64 の和で 1 つの値を表し、約 106 ビットの精度で計算する方法）で作る。
  安価な近似の丸めの不確かさが最終結果の丸めを変えうるときだけ、全体を2 ワードの算術でやり直す。
- それより大きい形状では、Stirling の公式 $\ln \Gamma(x) = (x - \tfrac12)\ln x - x + \tfrac12 \ln 2\pi + c(x)$ の主要部を先に打ち消し合わせる。
  $s = a + b$ とおくと、

$$
\ln B(a, b) = \left(a - \tfrac12\right)\ln\frac{a}{s} + \left(b - \tfrac12\right)\ln\frac{b}{s} - \tfrac12 \ln s + \tfrac12 \ln 2\pi + c(a) + c(b) - c(s)
$$

  となり、大きな項 $s \ln s$ が消える。
  $c(x)$ は Stirling 級数の補正項（$1/(12x) - 1/(360x^3) + \cdots$）で、$\ln(b/s) = -\ln(1 + a/b)$ は $a/b$ が小さいとき `ln_1p` の形で作る。
  小さい形状 $a < 32$ と大きい $b$ の組では、$\ln \Gamma(a)$ をそのまま使い、$-a \ln s$ と $(b - \tfrac12)\ln(b/s) + a$ の打ち消しを2 ワードの算術で行う。

$\ln B(a, b)$ が 0 に近い点（$B(a, b) = 1$ の近く）では、相殺する成分を厳密な累積で保ってから丸める。
複素数では Lanczos 近似の $\ln\Gamma$ で $\exp(\ln\Gamma(a) + \ln\Gamma(b) - \ln\Gamma(a + b))$ を作り、`ln_beta` の和は主値の分枝へ戻さない。

実数の `beta` と `ln_beta` は、独立に生成した参照値で確かめた範囲で binary64 は 4 ULP、binary32 は 1 ULP の誤差に収まる。
`ln_beta` の範囲には $\ln B$ の零点の近くも含まれ、4160 点の別の標本での最大誤差は `beta` が 1.0 ULP、`ln_beta` が 0.5 ULP である。
binary32 は binary64 で計算して一度だけ丸める。
複素数には一様な ULP の目標がなく、オプション付き形式の推定誤差で精度を判断する。
どちらも演算の量が引数によらず上限を持つので、スコープ付き API を持たない。

## 正則化不完全 Beta 関数

正則化不完全 Beta 関数は積分の上端を $x$ で打ち切って $B(a, b)$ で正規化した関数である（DLMF 8.17.1、8.17.2）。

$$
I_x(a, b) = \frac{1}{B(a, b)} \int_0^x t^{a-1} (1 - t)^{b-1} \, dt, \qquad 0 \le x \le 1.
$$

$I_x(a, b)$ は形状 $a, b$ の Beta 分布の累積分布関数で、$I_0 = 0$ から $I_1 = 1$ まで単調に増え、相補の対称性 $I_x(a, b) = 1 - I_{1-x}(b, a)$（DLMF 8.17.4）を持つ。
二項分布 $X \sim \mathrm{Bin}(n, p)$ の裾は $P(X \ge k) = I_p(k, n - k + 1)$、Student の $t$ 分布（自由度 $\nu$）の両側確率は $P(\lvert T \rvert \ge t) = I_{\nu/(\nu + t^2)}(\nu/2, 1/2)$ で与えられる。

実数の `beta_inc` は $a, b \ge 0$、$0 \le x \le 1$ を受け付ける。
形状が 0 の端では極限 $I_x(0, b) = 1$（$x > 0$）、$I_x(a, 0) = 0$（$x < 1$）を返し、オプション付き形式の終了状態は `Limit` になる。
$a = b = 0$、$a = 0$ かつ $x = 0$、$b = 0$ かつ $x = 1$ では向きによって極限が変わるので `DomainError`（`Undefined`）、負の形状と $[0, 1]$ の外の $x$ は `DomainError`（`OutsideDomain`）である。
複素数の $z$ では $I_z(a, b) = z^a\, {}_2F_1(a, 1 - b; a + 1; z)/(a B(a, b))$（DLMF 8.17.7）を主値の冪で計算し、分枝切断は $(-\infty, 0]$ と $[1, \infty)$ である。
形状を実数のまま、$z$ だけを複素数にしてもよい。

### 向きの選択

不完全 Beta 関数の評価では、まず $x$ と $1 - x$ のどちらの側で計算するかを決める。
連分数（下の式）は $x < (a + 1)/(a + b + 2)$ で速く収束し、$x$ がそれより大きいときは $I_{1-x}(b, a)$ を計算して対称性で戻すほうが速い（DLMF §8.17(v)）。
`beta_inc` はこの境目で向きを選ぶ。
境目は Beta 分布の平均 $a/(a + b)$ の近くにあるので、選んだ側の値 $J$ は多くの場合 $\tfrac12$ より小さいが、形状が大きく違うと 1 に近いこともある。
対称性で戻すときは $1 - J$ を $-\operatorname{expm1}(\ln J)$ の形で作り、$J$ が 1 に近い場合も丸めた指数関数からの引き算をしない。

### 有限和・冪級数・連分数

選んだ向きの $(a, b, x)$ について、次の順に方法を試す。

1. 両方の形状が整数で $a + b \le 33$ なら、二項分布の有限和 $I_x(a, b) = \sum_{j=a}^{n} \binom{n}{j} x^j (1 - x)^{n - j}$（$n = a + b - 1$）を補償和で足す。
   項数は $b$ 個で、途中の冪が非正規化数になる場合は次の方法へ移る。
2. $B(a, b)$ を binary64 で表せる範囲（半整数の格子か $a + b < 128$）では、冪級数を binary64 で足し、相対的な不確かさが $16\varepsilon$ 以下と見積もれたらその値を返す。
   冪級数は端点の級数 $I_x = x^a\, {}_2F_1(a, 1 - b; a + 1; x)/(a B)$（DLMF 8.17.7。
   $x \le 1/2$ かつ $b x \le 1/2$ で項の比が $1/2$ 以下）か、超幾何級数 $I_x = x^a (1 - x)^b\, {}_2F_1(a + b, 1; a + 1; x)/(a B)$（DLMF 8.17.8。
   正の項だけで、項の比が $0.8$ 以下なら 166 項以内で収束する）である。
3. それ以外では、前因子 $x^a (1 - x)^b / (a B(a, b))$ を対数で作り、端点の級数か次の連分数（DLMF §8.17(v)）を掛ける。

$$
I_x(a, b) = \frac{x^a (1 - x)^b}{a B(a, b)} \cfrac{1}{1 + \cfrac{d_1}{1 + \cfrac{d_2}{1 + \cdots}}}, \qquad
d_{2m} = \frac{m(b - m)x}{(a + 2m - 1)(a + 2m)}, \quad d_{2m+1} = -\frac{(a + m)(a + b + m)x}{(a + 2m)(a + 2m + 1)}.
$$

連分数は修正 Lentz 法で前から評価する。
修正 Lentz 法は連分数の近似値を二つの比の積で更新する方法で、途中の分母が 0 に近づいたら絶対値の小さな値に置き換えて 0 除算を避け、更新の比が 1 に $\varepsilon$ の程度まで近づいたら止める。
最初の分母 $1 - (a + b)x/(a + 1)$ は、向きの境目 $x = (a + 1)/(a + b + 2)$ で $2/(a + b + 2)$ まで小さくなる。
この分母が $1/2$ より小さいと、打ち消しで失われたビットがその後の更新で増幅されるので、連分数全体を2 ワードの算術で評価する。

### 大きな形状と前因子

形状が大きいと、前因子の指数 $a \ln x + b \ln(1 - x) - \ln B(a, b)$ は大きな項どうしの差になる。
たとえば $a = 100$、$b = 9901$、$x = 0.01$ では $a \ln x \approx -460.5$、$b \ln(1 - x) \approx -99.5$、$\ln B(a, b) \approx -561.4$ で、$\ln a$ を引いた指数は $-3.23$ になる。
各項を binary64 で丸めると $561 \varepsilon \approx 1.2 \times 10^{-13}$ の絶対誤差が指数に入り、それがそのまま前因子の相対誤差になる。
`beta_inc` はこの指数を2 ワードの算術で作り、$\ln B(a, b)$ には上の Stirling の形を使う。
$\ln(1 - x)$ は $x < \sqrt{\varepsilon}$ では $\operatorname{ln1p}(-x)$ の級数、それ以外では2 ワードの引き算 $1 - x$ の対数で作る。

`scioxide-special` は大きな形状のための一様漸近展開（Temme の展開など）を実装していない。
大きな形状でも連分数を使い、項数は平均の近くで形状とともにゆっくり増える。
下のセルの $n = 10^5$、$k = 1000$（$a = 1000$、$b = 99001$）では 89 回の反復で終わる。
作業量の上限（`BetaOptions` の `Budget`、既定 65536）は、この反復の回数と級数の項数を数える。

### 相補形・対数形・逆関数

上側の裾 $1 - I_x(a, b) = I_{1-x}(b, a)$ は `beta_inc_q` が直接計算し、小さな上側の裾も相対精度を保つ。
`beta_inc_log` と `beta_inc_log_q` は $\ln I_x(a, b)$ と $\ln(1 - I_x(a, b))$ を、確率を作らずに計算する。
確率が型の最小の非正規化数より小さくても、対数は有限の値で返る。
`beta_inc_log` は $x = 0$ で、`beta_inc_log_q` は $x = 1$ で $-\infty$ を値として返す。
これら 3 つは、binary64 の有限和か冪級数で相対的な不確かさ $16\varepsilon$ 以下を示せればその値を返し、示せなければ小さい側の裾の対数を2 ワードの算術で作って、要求された側をその相補として $\ln(1 - e^{\ell})$ の形で作る。

逆関数は 4 つある。
`beta_inc_inv` は $I_x(a, b) = p$、`beta_inc_q_inv` は $1 - I_x(a, b) = q$、`beta_inc_inv_log` は $\ln I_x(a, b) = \ln p$、`beta_inc_q_inv_log` は $\ln(1 - I_x(a, b)) = \ln q$ を満たす $x$ を返す。
どれも漸近形の初期値から、座標 $\ln(x/(1 - x))$ での Halley 法（3 次収束する Newton 法の変形）を、根を挟む区間で守りながら進め、最後の数歩を2 ワードの算術の裾で行って型の精度で止める。
逆関数は $a, b > 0$ を要求し、$a \le 0$、$b \le 0$、$[0, 1]$ の外の $p$、正の $\ln p$ は `DomainError`（`OutsideDomain`）、$\ln p = -\infty$ は `NonFinite` になる。
$p = 0$ には $x = 0$、$p = 1$ には $x = 1$ を返す（`beta_inc_q_inv` は逆）。
確率が型の範囲より小さいときは、対数の逆関数を使う。

### 不完全 Beta 関数の精度

実数の不完全 Beta 関数とその相補形・対数形・逆関数は、独立に生成した参照値で確かめた範囲で binary64 は 32 ULP、binary32 は 1 ULP の誤差に収まる。
4160 点の別の標本では `beta_inc` の最大誤差は 12 ULP である。
オプション付き形式の推定誤差は 32 ULP の包絡（参照値との比較で較正した大きさ）を値に当てはめたもので、包含が保証された区間ではない。
複素数の `beta_inc` には一様な ULP の目標がない。
反復を使う関数はすべてスコープ付き API を持つ。

## 対称 Beta 分布の四分位点

次のセルは形状 $a = b$ の対称 Beta 分布の第 1 四分位点 $x_1$（$I_{x_1}(a, a) = 1/4$）を、4 つの逆関数で別々の入力から求める。
`beta_inc_inv` には $p = 1/4$、`beta_inc_q_inv` には $q = 3/4$、対数の逆関数にはその対数を渡し、どれも同じ $x_1$ になるはずである。
表には $x_1$ を `beta_inc` に戻した残差も出す。
検算は 3 つで、第 3 四分位点との和が対称性から 1 になること、恒等式 $I_x(a, a) = \tfrac12 I_{4x(1-x)}(a, \tfrac12)$（$0 \le x \le \tfrac12$）、閉形式のある形状での四分位点との差である。
閉形式は $I_x(\tfrac12, \tfrac12) = (2/\pi)\arcsin\sqrt{x}$、$I_x(1, 1) = x$、$I_x(2, 2) = 3x^2 - 2x^3$ から解いた $\sin^2(\pi/8)$、$1/4$、$\tfrac12 - \sin(\pi/18)$ である。

emit_line_chart!(

);

既定の $a = b = 2$ では、4 つの逆関数がどれも $x_1 = 0.3263518223330697$ を返し（`beta_inc_q_inv_log` だけが 1 ULP 小さい 0.3263518223330696）、`beta_inc` に戻した残差は $\pm 1.1 \times 10^{-16}$ である。
閉形式 $\tfrac12 - \sin(\pi/18)$ との差は $5.6 \times 10^{-17}$、対称性の残差は 0、恒等式の残差は $2.2 \times 10^{-16}$ で、どれも binary64 の丸めの程度である。
$a = b = \tfrac12$ を選ぶと、累積曲線は両端で急に立ち上がって中央で平らになり、四分位点 $\sin^2(\pi/8) = 0.1464466094067262$ との差を含めてすべての残差が 0 になる。
$a = b = 100$ では分布が $\tfrac12$ の近くに集まり、$x_1 = 0.4761369702994594$、四分位範囲は 0.048 である。
このとき恒等式の残差は $5.1 \times 10^{-15}$ に増える。
$4x_1(1 - x_1) = 0.9977$ が 1 に近く、そこでの $I_y(100, \tfrac12)$ の傾き（密度で約 95）が座標 $y$ の丸めを増幅するためで、関数の誤差ではない。
4 つの逆関数が同じ点を返すことは整合性の確認で、独立な検算は閉形式と恒等式である。

## 二項分布の裾と引き算による桁落ち

工程の不良率を $p = 0.01$ とし、$n$ 個を抜き取り検査したときの不良数を $X \sim \mathrm{Bin}(n, p)$ とする。
不良が $k$ 個以上見つかる確率は $P(X \ge k) = I_p(k, n - k + 1)$、$k - 1$ 個以下の確率は $P(X < k) = 1 - I_p(k, n - k + 1)$ である。
次のセルは平均 $\mu = np$ から標準偏差 $\sqrt{\mu}$ の 0、3、6、10 倍だけ離れた $k$ と $k = 1$ で、両側の確率を `beta_inc` と `beta_inc_q` で、下側の対数を `beta_inc_log_q` で求める。
小さい方の裾について、直接計算した値と、大きい方の裾を 1 から引いた値の相対誤差を比べる。
参照値は確率質量の比 $P(X = j + 1)/P(X = j) = (n - j)p/((j + 1)(1 - p))$ から $\ln P(X = j)$ を補償和で積み上げ、全体の和で正規化して足した値である（f64 の固有メソッドだけを使う独立な計算）。
表の最後の 2 列は、`beta_inc_q_with_options` の結果が返すアルゴリズムの識別子と反復の回数である。

```rust
//| id: special-beta-binomial-tails
//| ref: special-beta-binomial-tails
//| title: 二項分布の裾を不完全 Beta 関数の両側と対数形で求める
//| run: reactive
//| crates: [scioxide-core, scioxide-special]
//| inputs:
//|   trials: {"type":"select","label":"検査数 n","options":["100","1000","10000","100000"],"value":"10000"}
//| cases:
//|   - {"id":"small","label":"n = 100","description":"形状の和が小さく、binary64 の冪級数で値が決まる。","inputs":{"trials":"100"}}
//|   - {"id":"large","label":"n = 100000","description":"P(X = 0) = 0.99¹⁰⁰⁰⁰⁰ が binary64 の範囲より小さく、対数形だけが値を持つ。","inputs":{"trials":"100000"}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"tails","path":"/rows/0/1","approx":{"value":2.2487748498164775e-44,"rtol":1e-14}}
//|       - {"artifact":"tails","path":"/rows/0/4","equals":null}
//|       - {"artifact":"tails","path":"/rows/0/5","approx":{"value":-100.50335853501441,"rtol":1e-14}}
//|       - {"artifact":"tails","path":"/rows/3/3","range":{"max":1e-13}}
//|       - {"artifact":"tails","path":"/rows/3/4","range":{"min":1e-10}}
//|       - {"artifact":"tails","path":"/rows/4/4","equals":null}
//|   - case: small
//|     expect:
//|       - {"artifact":"tails","path":"/rows/2/3","range":{"max":1e-14}}
//|       - {"artifact":"tails","path":"/rows/2/4","range":{"min":1e-13}}
//|       - {"artifact":"tails","path":"/rows/2/7","equals":"probability/upper_linear_tail@1"}
//|   - case: large
//|     expect:
//|       - {"artifact":"tails","path":"/rows/0/1","equals":0}
//|       - {"artifact":"tails","path":"/rows/0/5","approx":{"value":-1005.0335853501441,"rtol":1e-14}}
//|       - {"artifact":"tails","path":"/rows/4/3","range":{"max":1e-12}}
//|       - {"artifact":"tails","path":"/rows/4/4","equals":null}
use scioxide_core::RealScalar;
use scioxide_special::{BetaOptions, beta_inc, beta_inc_log_q, beta_inc_q_with_options};

let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let fixed3 = serde_json::json!({ "fractionDigits": 3 });
let n: usize = trials.parse().map_err(|_| "検査数を読めない")?;
let p = 0.01;
let mean = n as f64 * p;
// 参照値（独立検算）: 比の漸化式で ln P(X = j) を補償和で積み上げ、全体の和で正規化する。
// f64 の固有メソッドだけを使い、SciOxide の関数は通さない。
let mut log_pmf = vec![0.0_f64; n + 1];
let mut compensation = 0.0;
for j in 0..n {
    let step = (((n - j) as f64 * p) / ((j + 1) as f64 * (1.0 - p))).ln() - compensation;
    let next = log_pmf[j] + step;
    compensation = (next - log_pmf[j]) - step;
    log_pmf[j + 1] = next;
}
let log_sum = |terms: &[f64]| {
    let top = terms.iter().copied().fold(f64::NEG_INFINITY, f64::max);
    top + terms.iter().map(|t| (t - top).exp()).sum::<f64>().ln()
};
let log_total = log_sum(&log_pmf);
let mut ks: Vec<usize> = [0.0, 3.0, 6.0, 10.0]
    .iter()
    .map(|c| (mean + c * RealScalar::sqrt(mean)).ceil() as usize)
    .collect();
ks.insert(0, 1);
ks.dedup();
let mut rows = Vec::new();
for k in ks {
    // P(X ≥ k) = I_p(k, n − k + 1)、P(X < k) = 1 − I_p(k, n − k + 1)。
    let (a, b) = (k as f64, (n - k + 1) as f64);
    let upper = beta_inc(a, b, p).map_err(|e| e.to_string())?;
    let detailed =
        beta_inc_q_with_options(a, b, p, BetaOptions::default()).map_err(|e| e.to_string())?;
    let lower = detailed.clone().try_value().map_err(|e| e.to_string())?;
    let log_lower = beta_inc_log_q(a, b, p).map_err(|e| e.to_string())?;
    let ref_lower = log_sum(&log_pmf[..k]) - log_total;
    let ref_upper = log_sum(&log_pmf[k..]) - log_total;
    // 小さい方の裾と、大きい方の裾を 1 から引いた値。0 に丸められた値は誤差を定義しない。
    let (direct, subtracted, reference) = if ref_lower < ref_upper {
        (lower, 1.0 - upper, ref_lower)
    } else {
        (upper, 1.0 - lower, ref_upper)
    };
    let relative = |value: f64| (value > 0.0).then(|| (value / reference.exp() - 1.0).abs());
    // 大きい方が下側なら ln P(X < k) = ln1p(−P(X ≥ k)) で参照値を作る。
    let ref_log_lower = if ref_lower < ref_upper {
        ref_lower
    } else {
        (-ref_upper.exp()).ln_1p()
    };
    rows.push((
        k,
        lower,
        upper,
        relative(direct),
        relative(subtracted),
        log_lower,
        log_lower - ref_log_lower,
        detailed.algorithm().to_string(),
        detailed.counts().iterations(),
    ));
}
let columns = serde_json::json!([
    { "key": "0", "label": "k [個]", "type": "integer" },
    { "key": "1", "label": "P(X < k)（beta_inc_q） [-]", "type": "number", "format": sci3 },
    { "key": "2", "label": "P(X ≥ k)（beta_inc） [-]", "type": "number", "format": sci3 },
    { "key": "3", "label": "小さい裾の相対誤差 [-]", "type": "number", "format": sci3, "nullText": "0 に丸め" },
    { "key": "4", "label": "引き算の相対誤差 [-]", "type": "number", "format": sci3, "nullText": "0 に丸め" },
    { "key": "5", "label": "ln P(X < k)（beta_inc_log_q） [-]", "type": "number", "format": fixed3 },
    { "key": "6", "label": "対数形の絶対誤差 [-]", "type": "number", "format": sci3 },
    { "key": "7", "label": "beta_inc_q のアルゴリズム" },
    { "key": "8", "label": "反復 [回]", "type": "integer" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "tails" })
);
```

既定の $n = 10^4$（$\mu = 100$）では、$k = 1$ の行の $P(X < 1) = 0.99^{10000} = 2.249 \times 10^{-44}$ を `beta_inc_q` が相対誤差 $2.2 \times 10^{-16}$ で返す。
同じ確率を `beta_inc` の値から $1 - I_p(1, 10000)$ で作ると 0 になる。
$k = 160$ の上側の裾 $1.71 \times 10^{-8}$ は、`beta_inc` の値では相対誤差 $2.7 \times 10^{-15}$、下側の値 0.99999998 を 1 から引くと $2.3 \times 10^{-9}$ で、引き算で約 6 桁を失う。
$k = 200$ の上側の裾 $5.6 \times 10^{-19}$ は、引き算では 0 になる。
相対誤差の列の $10^{-15}$ から $10^{-14}$ の値は参照値の漸化式の丸め誤差の大きさで、この参照値ではそれより小さい誤差を区別できない。
アルゴリズムの列の `probability/lower_log_tail@1` と `upper_log_tail@1` は2 ワードの算術で小さい側の裾の対数を作る経路で、$a = 100$、$b = 9901$ の連分数は 42 回の反復で終わる。

$n = 100$ を選ぶと $a + b = 101 < 128$ なので、多くの行が binary64 の冪級数の経路（`upper_linear_tail`）で決まり、$k = 7$ の上側の裾 $7.1 \times 10^{-5}$ を引き算で作ると相対誤差は $5.6 \times 10^{-13}$ になる。
$n = 10^5$ では $P(X = 0) = e^{-1005.03}$ が binary64 の最小の非正規化数 $4.9 \times 10^{-324}$ より小さく、`beta_inc_q` は 0 を返すが、`beta_inc_log_q` は $\ln P(X < 1) = -1005.0336$ を返す。
同じ $n$ の $k = 1000$（$a = 1000$、$b = 99001$）でも、連分数は 89 回の反復で終わる。
この $n$ では参照値の丸め誤差が $7 \times 10^{-14}$ まで増え、表の相対誤差もその大きさになる。

## API

この族の関数は次のとおりである。
「複素数」の列は `NumericScalar` を受け付けて複素数の引数も計算できるかを示す。
オプション付き形式は `SpecialFunctionResult` を返し、推定誤差、終了状態、計算量の計数、アルゴリズムの識別子を持つ。
スコープ付き API `*_scoped(.., options, scope)` は、計算量が引数で変わる計算だけが持つ。

| 標準形式 | 計算するもの | 複素数 | オプション付き形式 | スコープ付き API |
|---|---|---|---|---|
| `beta` | $B(a, b)$ | 対応 | `beta_with_options` | なし |
| `ln_beta` | $\ln B(a, b)$ | 対応 | `ln_beta_with_options` | なし |
| `beta_inc` | $I_x(a, b)$ | 対応 | `beta_inc_with_options` | `beta_inc_scoped` |
| `beta_inc_q` | $1 - I_x(a, b)$ | 実数のみ | `beta_inc_q_with_options` | `beta_inc_q_scoped` |
| `beta_inc_log` | $\ln I_x(a, b)$ | 実数のみ | `beta_inc_log_with_options` | `beta_inc_log_scoped` |
| `beta_inc_log_q` | $\ln(1 - I_x(a, b))$ | 実数のみ | `beta_inc_log_q_with_options` | `beta_inc_log_q_scoped` |
| `beta_inc_inv` | $I_x(a, b) = p$ の $x$ | 実数のみ | `beta_inc_inv_with_options` | `beta_inc_inv_scoped` |
| `beta_inc_q_inv` | $1 - I_x(a, b) = q$ の $x$ | 実数のみ | `beta_inc_q_inv_with_options` | `beta_inc_q_inv_scoped` |
| `beta_inc_inv_log` | $\ln I_x(a, b) = \ln p$ の $x$ | 実数のみ | `beta_inc_inv_log_with_options` | `beta_inc_inv_log_scoped` |
| `beta_inc_q_inv_log` | $\ln(1 - I_x(a, b)) = \ln q$ の $x$ | 実数のみ | `beta_inc_q_inv_log_with_options` | `beta_inc_q_inv_log_scoped` |

オプションはどれも `BetaOptions` で、作業量の上限（`Budget`、既定 65536）だけを持つ。
精度は固定で、上限を大きくしても精度は上がらず、収束の遅い入力が終われるようになるだけである。
不完全 Beta 関数で上限に達すると、標準形式は `ConvergenceFailure`（`IterationLimit`）を返し、オプション付き形式は推定値が残れば終了状態 `IterationLimit` の結果を返す。

## まとめ

Beta 関数は整数・半整数の格子では漸化式の積、中程度の形状では Gamma 関数の比、大きな形状では主要部を打ち消した Stirling の形で評価され、`ln_beta` はあふれずに $\ln B$ の零点の近くでも 4 ULP の目標に収まる。
不完全 Beta 関数は $(a + 1)/(a + b + 2)$ を境に連分数が速く収束する向きを選び、有限和、binary64 の冪級数、2 ワードの算術の前因子と修正 Lentz 法の連分数を順に使う。
小さな裾は 1 からの引き算で作らず、上側には `beta_inc_q`、型の範囲より小さい確率には対数形と対数の逆関数を使う。
大きな形状でも連分数の反復は数十回で終わり、作業量の上限は既定値のままで足りる。
