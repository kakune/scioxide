特殊関数では、数学的に等しい式が浮動小数点でも同じ精度を持つとは限らない。
$F(x)$ が 1 に丸められたあとで $1 - F(x)$ を計算すると、小さな裾の確率は 0 になる。
複素数への解析接続では、同じ式でも分枝の切断のどちらの岸で評価するかで値が変わる。

このページはすべての関数族に共通する四つの規約を説明する。
実数と複素数の API、分枝の切断と岸の選び方、詳細な結果が持つ値の表現と終了状態、裾確率の表現である。
最後に、関数族ごとの API と表現を表にまとめ、各数理ページへ導く。

## 実数と複素数の API

関数の型引数には二種類ある。
`RealScalar` を取る関数は `f32` と `f64` だけを受け取り、`NumericScalar` を取る関数はさらに `Complex<f32>` と `Complex<f64>` も受け取って解析接続を評価する。
どちらでも、引数の型が結果の型を決める。
Kelvin 関数、Fermi–Dirac 積分、正規分布の関数、角運動量の係数などは実数だけを受け取り、Bessel・Gamma・誤差関数・超幾何関数・多重対数などは複素数も受け取る。
`faddeeva`、`lambert_w_complex`、`parabolic_d_complex` は複素数の引数だけを受け取り、`spherical_harmonic` と `voigt_complex` は実数の引数から複素数の値を返す。

次数、形状、母数のように引数と役割の違う量は、`Parameter` で受け取る。
`Parameter<T>` は引数の型 `T` 自身と、`T` が `Complex<R>` のときの実数 `R` に実装されている。
実数のパラメータは虚部が $+0$ の複素数として扱われ、その複素数を渡した呼び出しとビット単位で同じ値を返す。
たとえば `bessel_j(2.5, z)` は複素数の `z` で $J_{2.5}(z)$ を評価する。
逆に、複素数のパラメータには複素数の引数が要り、`bessel_j(Complex::new(0.5, 0.25), 1.0)` はコンパイルできない。
`Parameter` は sealed トレイトで、公開メソッドを持たない。

実数の API は実数の定義域とその規約を保つ。
非整数の次数の `bessel_j` に負の実数を渡すと `DomainError`（`OutsideDomain`）になり、整数の次数では偶奇性 $J_n(-x) = (-1)^n J_n(x)$ による値を返す。
`expint_e1` は $x < 0$ で複素数ではなく、切断の両岸の実部である主値 $-\operatorname{Ei}(-x)$ を返す。
`dilog` は実数の $x > 1$ で主値の実部を返し、`polylog` は実数の $z > 1$ を次数 $s = 2$ と非正の整数の次数でだけ受け付ける。
切断の上の複素数の値が欲しいときは、複素数の API に移って岸を選ぶ。

スカラーの関数に配列をまとめて渡す形はない。
多くの点では `iter().map(|&x| erf(x)).collect::<Result<Vec<_>, _>>()` のように評価する。
連続する次数の列を返す形は、Coulomb 波動関数の `coulomb_wave_sequence` などだけである。

### 正確な整数と一般の二項係数

浮動小数点の値ではなく正確な整数や有理数が要る場合のために、二つの関数がある。
`checked_bernoulli(n)` は Bernoulli 数 $B_n$ を既約分数 `(分子, 分母)` で返す。
規約は $t/(e^t - 1) = \sum_n B_n t^n/n!$ で $B_1 = -1/2$ になり、偶数の $n \le 34$ と $n = 38$ を表から返す。
$B_{36}$ の分子は 64 ビットに収まらないので、$n = 36$ と $n > 38$ の偶数は `SizeOverflow` になる。
`checked_euler(n)` は $\operatorname{sech} t = \sum_n E_n t^n/n!$ の Euler 数 $E_n$ を整数で返し、偶数の $n \le 22$ を受け付ける。
奇数の次数では `checked_euler` は `0` を返し、`checked_bernoulli` は $B_1$ の `(-1, 2)` を除いて `(0, 1)` を返す。
任意の次数の値を浮動小数点数で返すのは `bernoulli` と `euler` である。
整数の階乗と二項係数の正確な値は、`scioxide-core` の `checked_factorial` と `checked_binomial` が返す。

`generalized_binomial(z, k)` は、実数か複素数の $z$ と整数 $k \ge 0$ の二項係数 $C(z, k) = z(z-1)\cdots(z-k+1)/k!$ を返す。
$C(z, k)$ は $z$ の $k$ 次多項式なので、極も分枝の切断もない。
分子の積は 2 の冪の指数を別に持ちながら作るので、$k!$ で一度だけ割る前にあふれない。
計算量は $k$ に比例するので、オプション付き形式 `generalized_binomial_with_options` とスコープ付き API `generalized_binomial_scoped` を持ち、$k$ が作業量の上限を超えると `ConvergenceFailure` になる。
一様な ULP の目標はなく、オプション付き形式の推定誤差を読む。

## 分枝の切断と符号付きゼロ

対数や平方根、非整数の冪を含む関数は、複素平面で多価になる。
一価の関数にするために平面に切れ目（分枝の切断）を入れ、切れ目を除いた平面で連続な枝（主枝）を選ぶ。
`scioxide-special` では、対数に由来する関数の切断を負の実軸 $(-\infty, 0]$ に置き、それ以外の関数は DLMF の慣用の切断に従う。

切断の上の点では虚部の符号付きゼロで岸を選ぶ。
虚部が $+0$ なら上の岸、$-0$ なら下の岸の値を返す。
係数が実数なら、二つの岸の値は互いに複素共役になる。

| 関数 | 切断 |
|---|---|
| `bessel_y`、`bessel_k`、`hankel_1`、`hankel_2`、`ln_gamma`、`hyperu` | $(-\infty, 0]$ |
| `bessel_j`、`bessel_i`（非整数の次数。整数の次数では整関数） | $(-\infty, 0]$ |
| `gamma_p`、`gamma_q`（$z^a$ の主値の冪） | $(-\infty, 0]$ |
| `beta_inc` | $(-\infty, 0]$ と $[1, \infty)$ |
| `hyp2f1`、`polylog`、`dilog`、`lerch_phi` | $[1, \infty)$ |
| `lambert_w_complex` | 枝 0 は $(-\infty, -1/e]$、他の枝は $(-\infty, 0]$ |
| `wright_omega` | 二本の半直線 $\operatorname{Im} z = \pm\pi$、$\operatorname{Re} z \le -1$ |
| `log_erfc` | $\operatorname{erfc}(z)$ が負の実軸の上にある点 |
| `gamma`、`riemann_zeta`、`hyp1f1`、`faddeeva`、`generalized_binomial` | なし（有理型か整関数） |

Lambert W は多価関数の枝そのものを番号で選ぶ。
実数の `lambert_w0`（$W \ge -1$、$x \ge -1/e$）と `lambert_wm1`（$W \le -1$、$-1/e \le x < 0$）は別の関数で、複素数の `lambert_w_complex(z, branch)` は Corless らの番号の枝を引数で受け取る。
丸めた $-1/e$ ではどちらの実数の枝も厳密な $-1$ を返し、そのすぐ下の表せる数は `DomainError`（`OutsideDomain`）になる。
詳しくは [Lambert W 関数と Wright ω 関数](../lambert-w-and-wright-omega/) で扱う。

次のセルは非整数の次数 $\nu$ で、切断の上の点 $z = -x \pm 0\mathrm{i}$ の $J_\nu$ を接続公式 $J_\nu(x e^{\pm\mathrm{i}\pi}) = e^{\pm\mathrm{i}\pi\nu} J_\nu(x)$ と比べる。
右辺の $J_\nu(x)$ は実数の API で求め、位相 $e^{\pm\mathrm{i}\pi\nu}$ を掛ける。
あわせて、切断から離れた点 $z = x + \mathrm{i}$ で $H_\nu^{(1)} = J_\nu + \mathrm{i}Y_\nu$ を確かめる。
二つ目の表は同じ $x$ で実数の API に $\pm x$ を渡した結果を示す。

```rust
//| id: special-complex-branch-lips
//| ref: special-complex-branch-lips
//| title: 負の実軸の切断の上下の岸で Bessel J を比べる
//| run: reactive
//| crates: [scioxide-core, scioxide-special]
//| inputs:
//|   order: {"type":"range","label":"次数 ν","description":"非整数では負の実軸が切断になる。整数では二つの岸が一致する。","min":0,"max":3,"step":0.25,"value":0.5}
//|   x: {"type":"range","label":"距離 x（z = −x ± 0i）","description":"切断の上の点の原点からの距離。","min":0.5,"max":20,"step":0.5,"value":3}
//| cases:
//|   - {"id":"integer","label":"整数の次数","description":"ν = 1 では二つの岸が一致し、実数の API も偶奇性で負の引数を受け付ける。","inputs":{"order":1,"x":3}}
//|   - {"id":"far","label":"遠い点","description":"x = 20 では Hankel の漸近展開の領域に入る。","inputs":{"order":2.5,"x":20}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"lips","path":"/rows/0/2","approx":{"value":0.0650081828768,"rtol":1e-10}}
//|       - {"artifact":"lips","path":"/rows/1/2","approx":{"value":-0.0650081828768,"rtol":1e-10}}
//|       - {"artifact":"lips","path":"/rows/0/5","range":{"max":1e-15}}
//|       - {"artifact":"lips","path":"/rows/1/5","range":{"max":1e-15}}
//|       - {"artifact":"lips","path":"/rows/2/5","range":{"max":1e-15}}
//|       - {"artifact":"real","path":"/rows/1/2","equals":"DomainError"}
//|   - case: integer
//|     expect:
//|       - {"artifact":"lips","path":"/rows/0/2","range":{"min":-1e-15,"max":1e-15}}
//|       - {"artifact":"lips","path":"/rows/0/5","range":{"max":1e-15}}
//|       - {"artifact":"real","path":"/rows/1/2","equals":"なし"}
//|   - case: far
//|     expect:
//|       - {"artifact":"lips","path":"/rows/0/5","range":{"max":1e-15}}
//|       - {"artifact":"lips","path":"/rows/2/5","range":{"max":1e-15}}
use scioxide_core::Complex;
use scioxide_special::{bessel_j, bessel_y, hankel_1};

let nu = Complex::new(order, 0.0);
// 虚部の符号付きゼロで切断の岸を選ぶ。
let upper = bessel_j(nu, Complex::new(-x, 0.0)).map_err(|e| e.to_string())?;
let lower = bessel_j(nu, Complex::new(-x, -0.0)).map_err(|e| e.to_string())?;
// 接続公式の右辺: 実数の API の J_ν(x) に e^{±iπν} を掛ける。
let real = bessel_j(order, x).map_err(|e| e.to_string())?;
let phase = Complex::from_polar(1.0, std::f64::consts::PI * order);
// 切断から離れた点で H⁽¹⁾_ν と J + iY を比べる。
let z = Complex::new(x, 1.0);

let combination = bessel_j(nu, z).map_err(|e| e.to_string())?
    + Complex::new(0.0, 1.0) * bessel_y(nu, z).map_err(|e| e.to_string())?;

let lips = [
    ("J_ν(−x + 0i)", upper, phase * real),
    ("J_ν(−x − 0i)", lower, phase.conj() * real),
    ("H⁽¹⁾_ν(x + i) と J + iY", hankel, combination),
]
.map(|(name, value, expected)| {
    let difference = (value - expected).norm();
    (
        name,
        value.re,
        value.im,
        expected.re,
        expected.im,
        difference,
    )
});

    { "key": "0", "label": "量" },
    { "key": "1", "label": "実部 [-]", "type": "number", "format": sci10 },
    { "key": "2", "label": "虚部 [-]", "type": "number", "format": sci10 },
    { "key": "3", "label": "比べる値の実部 [-]", "type": "number", "format": sci10 },
    { "key": "4", "label": "比べる値の虚部 [-]", "type": "number", "format": sci10 },
    { "key": "5", "label": "差の絶対値 [-]", "type": "number", "format": sci2 }
]);
emit_table_with_columns!(

    lips,
    metadata = serde_json::json!({ "id": "lips" })
);

// 実数の API: 負の引数は非整数の次数で定義域の外になる。
let real_rows =
    [("bessel_j(ν, x)", x), ("bessel_j(ν, −x)", -x)].map(|(name, t)| {
        match bessel_j(order, t) {
            Ok(v) => (name, Some(v), "なし".to_string()),
            Err(e) => (name, None, format!("{:?}", e.kind())),
        }
    });
let real_columns = serde_json::json!([
    { "key": "0", "label": "実数の API の呼び出し" },
    { "key": "1", "label": "値 [-]", "type": "number", "format": sci10, "nullText": "エラー" },
    { "key": "2", "label": "エラーの分類" }
]);
emit_table_with_columns!(
    real_columns,
    real_rows,
    metadata = serde_json::json!({ "id": "real" })
);
```

既定の $\nu = 1/2$、$x = 3$ では、$J_{1/2}(z) = \sqrt{2/(\pi z)}\sin z$ から二つの岸の値は $\pm\mathrm{i}\sqrt{2/(3\pi)}\sin 3 \approx \pm 0.0650\mathrm{i}$ で、互いに共役になる。
`scioxide-special` の値は実部が厳密に 0 で、比べる値の実部 $4 \times 10^{-18}$ は $\cos(\pi/2)$ を丸めた位相の誤差である。
実数の API に $-x$ を渡すと `DomainError` になる。
$\nu$ を整数にすると $e^{\pm\mathrm{i}\pi\nu} = (-1)^\nu$ で二つの岸は一致し、実数の API も $J_n(-x) = (-1)^n J_n(x)$ による値を返す。
次数を 0.25 刻み、距離を 0.5 刻みで範囲全体に動かすと、接続公式との差は $6 \times 10^{-16}$ 以下、Hankel 関数の恒等式との差は $2 \times 10^{-15}$ 以下である。
複素数の Bessel 関数には一様な ULP の目標がないので、この差は二つの経路が整合していることを示すが、真の値からの誤差の上限ではない。

## 値の表現と終了状態

オプション付き形式 `*_with_options` とスコープ付き API `*_scoped` は `SpecialFunctionResult` を返す。
この型は一回の評価の結果を、次のアクセサで別々に持つ。

| アクセサ | 返す量 |
|---|---|
| `value()` | 通常値と推定誤差。値があふれると `None` で、文書化した極限は $\pm\infty$ |
| `scaled()` | 各成分を仮数と 2 の冪の指数に分けた値。値があふれても残る |
| `logarithmic()` | 位相（実数では符号）と大きさの自然対数。相対誤差が $1/2$ に達すると省かれる |
| `derivative()` | 引数についての導関数。関数が計算しないときは `None` |
| `scalar_representation()` | 通常値への射影の状態 `ScalarRepresentation` |
| `termination()` | 終了状態 `SpecialFunctionTermination` |
| `algorithm()`、`counts()` | アルゴリズムの識別子と、失敗した試みを含む計算量の計数 |
| `try_value()`、`try_derivative()` | 推定誤差を外した通常値と導関数。評価が完了していないか、値がないとエラー |

各形は `ValueWithError` で、`value()`（または所有権を移す `into_value()`）、`absolute_error()`、`relative_error()`、推定の根拠 `reliability()` を持つ。
推定誤差は区間の包含区間ではなく、根拠の三つの分類は [アルゴリズム](oxref:special-algorithms-error-estimates) で説明している。
オプション付き形式の通常値は標準形式の値とビット単位で同じである。
`SpecialFunctionResult::zero()` は、計算をせずに厳密な零と零の計数を持つ結果を作り、出力の配列を初期化するのに使う。

`ScalarRepresentation` は通常値への射影の状態で、`Finite`、`Overflow`、`InfiniteLimit` の三つである。
`Overflow` のとき `value()` は `None` だが、`scaled()` と `logarithmic()` は表せる範囲で値を保つ。
真の値が小さすぎて零に丸められるときは `Finite` で、標準形式は `Ok(±0)` を返す。

`SpecialFunctionTermination` は `Exact`、`Converged`、`Limit`、`IterationLimit` の四つで、`is_success()` は前の三つで真になる。
`IterationLimit` は作業量の上限に達したことを示し、結果はそれまでの推定値を持つ。
このとき `try_value()` と標準形式は `ConvergenceFailure` を返す。
有用な推定値ができないまま上限に達すると、オプション付き形式も `ConvergenceFailure` を返し、エラーは試みた反復回数を持つ。
終了状態は推定誤差が要求を満たしたかどうかを示さないので、精度は推定誤差で読む。

オプションは作業量の上限 `Budget` を持ち、`with_iteration_budget` で変える。
上限は要求する桁数ではない。
スコープ付き API `*_scoped(.., options, scope)` は `impl Into<SolveScope>` を受け取り、`ExecutionContext` を渡すと新しい評価を、親の `&mut SolveContext` を渡すと親の求解の中の評価を始める。
親の求解には計算量が入れ子の計数として渡り、親の取り消しと期限が評価にも及ぶ。

次のセルは作業量の上限を 1 から 24 まで変えて、値の分かっている三つの量をオプション付き形式で評価する。
Clausen 関数は $\operatorname{Cl}_2(\pi/2) = G$（Catalan の定数 $0.9159655941772190\ldots$）、Fermi–Dirac 積分は $F_{1/2}(0) = (1 - 2^{-1/2})\,\zeta(3/2) = 0.7651470246254079\ldots$ を参照にする。
Faddeeva 関数 $w(1 + \mathrm{i}/2)$ の参照は、Taylor 級数 $w(z) = \sum_{n \ge 0} (\mathrm{i}z)^n/\Gamma(n/2 + 1)$ を 80 項まで手で足した値である。

```rust
//|       - {"artifact":"sweep","path":"/rows/0/3","equals":"Heuristic"}
//|       - {"artifact":"sweep","path":"/rows/0/5","range":{"min":0.01}}
//|       - {"artifact":"sweep","path":"/rows/8/5","range":{"max":1e-15}}
//|       - {"path":"/outputs/1/state","equals":"partial"}
use scioxide_core::{Budget, Complex, NumericScalar};
use scioxide_special::{
    ClausenOptions, FermiDiracOptions, ProbabilityOptions, SpecialFunctionResult,
    clausen_with_options, faddeeva_with_options, fermi_dirac_half_with_options,
};

// 結果から (終了状態, 反復回数, 推定の根拠, 推定絶対誤差, 値) を取り出す。
type Summary = (
    String,
    usize,
    Option<String>,
    Option<f64>,
    Option<Complex<f64>>,
);
fn summarize<V: NumericScalar<Real = f64>>(r: SpecialFunctionResult<V>) -> Summary {
    let value = r.value();
    (
        format!("{:?}", r.termination()),
        r.counts().iterations(),
        value.map(|v| format!("{:?}", v.reliability())),
        value.map(|v| v.absolute_error()),
        value
            .map(|v| Complex::new(v.value().real_component(), v.value().imaginary_component())),
    )
}

let z = Complex::new(1.0, 0.5);
// 上限 n で評価する。上限までに推定値がなければオプション付き形式もエラーを返す。
let evaluate = |n: usize| -> Result<Summary, String> {
    let limit = Budget::try_from(n).map_err(|e| e.to_string())?;
    let result = match function.as_str() {
        "Clausen Cl₂(π/2)" => {
            let options = ClausenOptions::default().with_iteration_budget(limit);
            clausen_with_options(std::f64::consts::FRAC_PI_2, options).map(summarize)
        }
        "Fermi–Dirac F₁/₂(0)" => {
            let options = FermiDiracOptions::default().with_iteration_budget(limit);
            fermi_dirac_half_with_options(0.0, options).map(summarize)
        }
        _ => {
            let options = ProbabilityOptions::default().with_iteration_budget(limit);
            faddeeva_with_options(z, options).map(summarize)
        }
    };
    Ok(result.unwrap_or_else(|e| (format!("{:?}（エラー）", e.kind()), n, None, None, None)))
};
// 参照値。Faddeeva は Taylor 級数を手で足す独立な検算（Γ(n/2 + 1) は漸化式で作る）。
let reference = match function.as_str() {
    "Clausen Cl₂(π/2)" => Complex::new(0.9159655941772190150546035149, 0.0),
    "Fermi–Dirac F₁/₂(0)" => Complex::new(0.7651470246254079453672687586, 0.0),
    _ => {
        let iz = Complex::new(0.0, 1.0) * z;
        let mut gammas = [1.0, 0.5 * std::f64::consts::PI.sqrt()];
        let (mut power, mut sum) = (Complex::new(1.0, 0.0), Complex::new(1.0, 0.0));
        for n in 1..80 {
            power = power * iz;
            if n >= 2 {
                gammas[n % 2] *= n as f64 / 2.0;
            }
            sum = sum + power * (1.0 / gammas[n % 2]);
        }
        sum
    }
};

let mut rows = Vec::new();
for n in [1, 2, 3, 4, 6, 8, 12, 16, 24] {
    let (termination, iterations, reliability, estimate, value) = evaluate(n)?;
    let actual = value.map(|v| (v - reference).norm());
    rows.push((n, termination, iterations, reliability, estimate, actual));
}
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let columns = serde_json::json!([
    { "key": "0", "label": "上限 [回]", "type": "integer" },
    { "key": "1", "label": "終了状態" },
    { "key": "2", "label": "反復 [回]", "type": "integer" },
    { "key": "3", "label": "推定の根拠", "nullText": "なし" },
    { "key": "4", "label": "推定絶対誤差 [-]", "type": "number", "format": sci2, "nullText": "なし" },
    { "key": "5", "label": "実際の誤差 [-]", "type": "number", "format": sci2, "nullText": "なし" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "sweep" })
);

// 選んだ上限での終了状態を outcome にする（IterationLimit は partial）。
let (termination, iterations, _, estimate, value) = evaluate(budget as usize)?;
let outcome = match (termination.as_str(), value) {
    ("Exact" | "Converged" | "Limit", Some(_)) => {
        Outcome::satisfied("上限の中で評価が完了した")
    }
    (_, Some(_)) => Outcome::partial("上限に達し、値は途中の推定値である")
        .explanation("try_value と標準形式はこの結果に ConvergenceFailure を返す。"),
    _ => Outcome::failed("上限までに推定値ができず、オプション付き形式もエラーを返した"),
};
let mut outcome = outcome
    .status(termination)
    .diagnostic("反復回数", iterations as f64, None);
if let (Some(estimate), Some(value)) = (estimate, value) {
    outcome = outcome
        .diagnostic("推定絶対誤差", estimate, None)
        .diagnostic("実際の誤差", (value - reference).norm(), None);
}
emit_outcome!(outcome);
```

既定の Clausen 関数では、上限が 15 回に満たないと終了状態は `IterationLimit` で、推定の根拠は `Heuristic` になる。
それでも推定絶対誤差は実際の誤差の 1〜2.4 倍で（実際の誤差が 0 になる上限 12 回を除く）、上限 6 回では推定 $5.2 \times 10^{-9}$ に対して実際は $4.8 \times 10^{-9}$ である。
上限を 16 回にすると 15 回の反復で `Converged` になり、根拠は `ModelBased` に変わる。
outcome は選んだ上限での状態で、`IterationLimit` なら partial である。

Fermi–Dirac 積分では、上限で止まっても推定の根拠は `ModelBased` のままで、推定は省いた Chebyshev 展開の項を含めて実際の誤差を覆う。
23 回の反復で `Converged` になり、参照とビット単位で一致する。

Faddeeva 関数では事情が違う。
上限で止まった連分数には、完了した評価の包絡 $64\varepsilon|w|$ がそのまま `Heuristic` として付き、打ち切り誤差を含まない。
この点の推定は上限 1 回の $4.1 \times 10^{-15}$ から上限 12 回の $7.0 \times 10^{-15}$ までにとどまる。
実際の誤差は上限 1 回で 0.26、4 回で $5.6 \times 10^{-3}$ と大きく、推定はそれを覆わない。
14 回の反復で `Converged` になると根拠は `StatisticallyCalibrated` に変わり、推定 $7.0 \times 10^{-15}$ が実際の誤差 $3.7 \times 10^{-16}$ を覆う。
したがって `IterationLimit` の値は、根拠が `Heuristic` なら推定誤差を信用せず、上限を増やして評価し直す。

## 裾確率の表現

上側の裾の確率は相補形で直接評価する。
`normal_sf`、`gamma_q`、`beta_inc_q`、`erfc` は小さいほうの裾を引き算なしに作るので、下側の確率が 1 に丸められる所でも相対精度を保つ。
相補形そのものがスカラーの範囲を下回る裾（binary64 で `normal_sf` は $x > 38.5$）では、対数形を使う。
`normal_log_sf`、`gamma_log_q`、`beta_inc_log_q` は確率を作らずに対数を返す。
確率から分位点を求めるときは、裾の確率から直接逆算する `normal_isf`、`gamma_q_inv`、`beta_inc_q_inv` を使い、対数で与えた確率には `normal_inv_log_sf`、`gamma_q_inv_log`、`beta_inc_q_inv_log` を使う。

`log_erfc(z)` は $\ln\operatorname{erfc}(z)$ を返す。
実数の $x < 1/2$ では $\ln(1 - \operatorname{erf}(x))$ を `ln1p` で作り、それ以外では $\ln\operatorname{erfcx}(x) - x^2$ として作るので、$\operatorname{erfc}(x)$ が範囲を下回る所でも精度を保つ。
実数の引数では binary64 で 4 ULP、binary32 で 1 ULP を目標とし、$x^2$ があふれる $x > 1.3 \times 10^{154}$ では `NumericalInstability`（`Overflow`）になる。
複素数の $z$ では $\operatorname{erfc}(z)$ の主値の対数で、一様な目標はない。
オプション付き形式は `log_erfc_with_options` で、スコープ付き API `log_erfc_scoped` は複素数の引数だけを受け取る。
実数の評価は計算量が固定で、親の求解と計数を共有する意味がないからである。

次のセルは共通の引数 $x$ で三つの裾を、引き算・相補形・対数形の三つの方法で求める。
正規分布の上側確率 $1 - \Phi(x)$、形状 3 の Gamma 分布の上側確率 $Q(3, x)$、相補誤差関数 $\operatorname{erfc}(x)$ である。
正規分布と $\operatorname{erfc}$ の参照には、Laplace の連分数 $1 - \Phi(t) = \varphi(t)/(t + 1/(t + 2/(t + 3/(t + \cdots))))$ を 500 段まで後ろから評価した対数を使い、$\operatorname{erfc}(x) = 2(1 - \Phi(\sqrt2 x))$ で読み替える。
Gamma 分布の参照は、形状が整数のときの有限和 $\ln Q(3, x) = -x + \ln(1 + x + x^2/2)$ である。
整数の形状では実装も同じ有限和を使うので、この行は対数への組み立ての検算で、独立な方法との比較ではない。

```rust
//| id: special-tail-representations
//| ref: special-tail-representations
//| title: 裾の確率を引き算・相補形・対数形で比べる
//| run: reactive
//| crates: [scioxide-special]
//| inputs:
//|   x: {"type":"range","label":"引数 x","description":"三つの分布に共通の引数。","min":2,"max":800,"step":2,"value":10}
//| cases:
//|   - {"id":"deep","label":"x = 40","description":"正規分布の相補形も 0 に丸められ、対数形だけが値を保つ。","inputs":{"x":40}}
//|   - {"id":"far","label":"x = 800","description":"三つの相補形がすべて 0 に丸められる。","inputs":{"x":800}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"tails","path":"/rows/0/1","equals":0}
//|       - {"artifact":"tails","path":"/rows/0/2","approx":{"value":7.619853024e-24,"rtol":1e-9}}
//|       - {"artifact":"tails","path":"/rows/0/5","range":{"max":1e-14}}
//|       - {"artifact":"tails","path":"/rows/1/5","range":{"max":1e-14}}
//|       - {"artifact":"tails","path":"/rows/2/5","range":{"max":1e-14}}
//|   - case: deep
//|     expect:
//|       - {"artifact":"tails","path":"/rows/0/2","equals":0}
//|       - {"artifact":"tails","path":"/rows/0/5","range":{"max":1e-14}}
//|       - {"artifact":"tails","path":"/rows/2/5","range":{"max":1e-14}}
//|   - case: far
//|     expect:
//|       - {"artifact":"tails","path":"/rows/1/2","equals":0}
//|       - {"artifact":"tails","path":"/rows/0/3","approx":{"value":-320007.6,"rtol":1e-6}}
//|       - {"artifact":"tails","path":"/rows/0/5","range":{"max":1e-14}}
//|       - {"artifact":"tails","path":"/rows/1/5","range":{"max":1e-14}}
//|       - {"artifact":"tails","path":"/rows/2/5","range":{"max":1e-14}}
use scioxide_special::{
    erf, erfc, gamma_log_q, gamma_p, gamma_q, log_erfc, normal_cdf, normal_log_sf, normal_sf,
};

// 独立な参照: Laplace の連分数による ln(1 − Φ(t))（f64 の固有メソッド）。
let normal_log_tail = |t: f64| {
    let mut fraction = t;
    for k in (1..=500).rev() {
        fraction = t + k as f64 / fraction;
    }
    -0.5 * t * t - (2.0 * std::f64::consts::PI).sqrt().ln() - fraction.ln()
};
let normal = (
    "正規分布 1 − Φ(x)",
    1.0 - normal_cdf(x).map_err(|e| e.to_string())?,
    normal_sf(x).map_err(|e| e.to_string())?,
    normal_log_sf(x).map_err(|e| e.to_string())?,
    normal_log_tail(x),
);
// 整数の形状の有限和（実装と同じ式なので、対数への組み立ての検算）。
let gamma = (
    "Gamma 分布 Q(3, x)",
    1.0 - gamma_p(3.0, x).map_err(|e| e.to_string())?,
    gamma_q(3.0, x).map_err(|e| e.to_string())?,
    gamma_log_q(3.0, x).map_err(|e| e.to_string())?,
    -x + (1.0 + x + 0.5 * x * x).ln(),
);
// erfc(x) = 2 (1 − Φ(√2 x))。
let error_function = (
    "相補誤差関数 erfc(x)",
    1.0 - erf(x).map_err(|e| e.to_string())?,
    erfc(x).map_err(|e| e.to_string())?,
    log_erfc(x).map_err(|e| e.to_string())?,
    std::f64::consts::LN_2 + normal_log_tail(std::f64::consts::SQRT_2 * x),
);
let rows = [normal, gamma, error_function].map(|(name, subtracted, direct, log, reference)| {
    let difference = ((log - reference) / reference).abs();
    (name, subtracted, direct, log, reference, difference)
});
let sci6 = serde_json::json!({ "notation": "scientific", "significantDigits": 6 });
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let fixed6 = serde_json::json!({ "fractionDigits": 6 });
let columns = serde_json::json!([
    { "key": "0", "label": "裾" },
    { "key": "1", "label": "引き算 1 − F [-]", "type": "number", "format": sci6 },
    { "key": "2", "label": "相補形 [-]", "type": "number", "format": sci6 },
    { "key": "3", "label": "対数形 [-]", "type": "number", "format": fixed6 },
    { "key": "4", "label": "参照の対数 [-]", "type": "number", "format": fixed6 },
    { "key": "5", "label": "対数形と参照の相対差 [-]", "type": "number", "format": sci2 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "tails" })
);
```

既定の $x = 10$ では、$\Phi(10)$ と $\operatorname{erf}(10)$ が 1 に丸められ、引き算の値は 0 になる。
相補形は $1 - \Phi(10) \approx 7.62 \times 10^{-24}$、$\operatorname{erfc}(10) \approx 2.09 \times 10^{-45}$ を返す。
$Q(3, 10) \approx 2.77 \times 10^{-3}$ では引き算でも値は残るが、末尾の 2 桁ほどが違う。
$x = 40$ では $Q(3, 40) \approx 3.57 \times 10^{-15}$ に対して引き算は $3.55 \times 10^{-15}$ で、相対誤差は 0.6% に達し、正規分布と $\operatorname{erfc}$ は相補形も 0 に丸められる。
$x = 800$ では三つの相補形がすべて 0 になる。
対数形はどの $x$ でも有限の値を保ち、$x$ を 2 から 800 まで 2 刻みで動かしても参照との相対差は $6 \times 10^{-16}$ 以下である。
正規分布の対数形は $x = 800$ で $-320007.6$、$\ln\operatorname{erfc}(800)$ は $-640007.3$ になる。

## まとめと次に読むページ

引数の型が結果の型を決め、複素数の引数には実数の次数をそのまま渡せるが、複素数の次数には複素数の引数が要る。
切断の上では虚部の $+0$ と $-0$ で岸を選び、実数の API は実数の定義域だけを受け付ける。
オプション付き形式の結果は通常値・尺度化した値・対数形・導関数を推定誤差とともに持ち、終了状態が `IterationLimit` なら値は途中の推定値で、推定の根拠が `Heuristic` なら打ち切り誤差を含まないことがある。
裾の確率は相補形で直接、範囲を下回る裾は対数形で評価し、引き算 $1 - F$ は使わない。
各関数族の方法と精度の目標は上の表の数理ページで、どの表現を選ぶかの判断は [選び方](../../choosing/) で確かめる。
