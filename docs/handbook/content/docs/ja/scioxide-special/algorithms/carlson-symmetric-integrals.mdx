不完全楕円積分は振幅 $\phi$ と母数 $m$ の二つの変数を持ち、$\phi$ が $\pi/2$ を超える場合や $m$ が 1 に近い場合など、場合分けの多い関数である。
Carlson の対称形は、引数の入れ替えに対して対称な少数の積分ですべての楕円積分を表し、一つの反復（重複変換）で評価できるようにする。
このページは Carlson 対称形の定義、Legendre の積分の Carlson 形への帰着、重複変換のアルゴリズムと打ち切り、定義域と Cauchy の主値、精度と呼び出しの形を説明する。
楕円積分の定義、母数 $m = k^2$ の規約、完全楕円積分 $K$、$E$ の評価は [楕円積分の定義と完全楕円積分 K、E](../elliptic-and-legendre/) が扱う。

## Carlson 対称形

Carlson は引数の入れ替えに対して対称な積分

$$
R_F(x, y, z) = \frac{1}{2}\int_0^\infty \frac{dt}{\sqrt{(t + x)(t + y)(t + z)}}, \qquad
R_J(x, y, z, p) = \frac{3}{2}\int_0^\infty \frac{dt}{(t + p)\sqrt{(t + x)(t + y)(t + z)}}
$$

を導入した（DLMF §19.16）。
$R_D(x, y, z) = R_J(x, y, z, z)$、$R_C(x, y) = R_F(x, y, y)$ はその退化形で、$R_C$ は初等関数（$0 \le x < y$ では $\arccos(\sqrt{x/y})/\sqrt{y - x}$）である。
$R_G(x, y, z)$ は完全に対称な第二種の積分で、$z$ を 3 つの引数の中央値に選んで

$$
2 R_G(x, y, z) = z R_F(x, y, z) - \frac{(x - z)(y - z)}{3} R_D(x, y, z) + \sqrt{\frac{xy}{z}}
$$

（DLMF §19.21）から求める。
中央値を $z$ に置くと $(x - z)(y - z) \le 0$ になり、3 つの項がどれも非負になるので打ち消しが起こらない。
$R_F$ と $R_C$ は $-1/2$ 次、$R_D$ と $R_J$ は $-3/2$ 次、$R_G$ は $1/2$ 次の同次関数である。
`carlson_rf`、`carlson_rd`、`carlson_rj`、`carlson_rc`、`carlson_rg` がこれらを返す。

## Legendre の積分の Carlson 形

Legendre の積分は、$s = \sin\phi$、$c = \cos\phi$、$\Delta^2 = 1 - m s^2$ として次のように書ける（DLMF §19.25）。

$$
F(\phi \mid m) = s R_F(c^2, \Delta^2, 1), \qquad
E(\phi \mid m) = s R_F(c^2, \Delta^2, 1) - \frac{m}{3} s^3 R_D(c^2, \Delta^2, 1),
$$

$$
\Pi(n \mid m) = R_F(0, 1 - m, 1) + \frac{n}{3} R_J(0, 1 - m, 1, 1 - n), \qquad
K(m) = R_F(0, 1 - m, 1), \qquad E(m) = 2 R_G(0, 1 - m, 1).
$$

第三種の不完全楕円積分の関数は提供しないが、$|\phi| \le \pi/2$ では同じ記号で

$$
\Pi(n; \phi \mid m) = s R_F(c^2, \Delta^2, 1) + \frac{n}{3} s^3 R_J(c^2, \Delta^2, 1, 1 - n s^2)
$$

を `carlson_rf` と `carlson_rj` で組み立てられる。

`elliptic_f` と `elliptic_e_inc` は、まず符号と $F(\phi + j\pi \mid m) = F(\phi \mid m) + 2jK(m)$ の関係で振幅を $[0, \pi/2]$ へ還元する。
還元で足す完全楕円積分の項は、[完全楕円積分 K と E の評価](oxref:special-elliptic-k-e-evaluation) の固定計算コストの近似で求める。
還元後の振幅で上の式を評価し、$E$ は $R_F$ の重複変換の状態を $R_D$ と共有する。
`elliptic_pi` は閉じた形 $\Pi(0 \mid m) = K(m)$、$\Pi(m \mid m) = E(m)/(1 - m)$、$\Pi(n \mid 0) = \pi/(2\sqrt{1 - n})$ を先に使い、それ以外では $R_F$ と $R_J$ を同じ重複変換の状態で求める。

## 重複変換

重複定理は、$\lambda = \sqrt{x}\sqrt{y} + \sqrt{x}\sqrt{z} + \sqrt{y}\sqrt{z}$ として

$$
R_F(x, y, z) = R_F\!\left(\frac{x + \lambda}{4}, \frac{y + \lambda}{4}, \frac{z + \lambda}{4}\right)
$$

が成り立つことをいう（DLMF §19.26）。
1 回の変換で引数の平均からの相対的な広がりは約 4 分の 1 になり、引数は共通の値へ 1 次収束する。
広がりの最大値 $\delta$（各引数と平均の差を平均で割ったもの）が十分小さくなったら、5 次までの対称多項式の展開

$$
R_F \approx A^{-1/2}\left(1 - \frac{E_2}{10} + \frac{E_3}{14} + \frac{E_2^2}{24} - \frac{3 E_2 E_3}{44}\right)
$$

で打ち切る（Carlson 1995、DLMF §19.36(i)）。
$A$ は引数の平均、$E_2$ と $E_3$ は正規化した偏差の 2 次と 3 次の基本対称式である。
$R_D$ と $R_J$ は各段の寄与（$R_D$ では $4^{-k}/(\sqrt{z_k}(z_k + \lambda_k))$）を補償付きの和で足し、$R_J$ は各段で $R_C$ を 1 回入れ子で評価する。

実数の引数で、0 でない引数がすべて $2^{\pm 300}$ の範囲にあるときは、binary64 の演算で $\delta < 0.001$ まで変換を繰り返す。
省いた 6 次の項は $\delta^6 < 10^{-18}$ の程度で、binary64 の丸めより小さい。
$\delta$ が 1 程度から始まると $\log_4 1000 \approx 5$ 回で閾値に達し、引数に 0 を含む $R_F(0, 0.5, 1)$ も 7 回で止まる（[完全楕円積分の端点の実験](oxref:special-elliptic-endpoint-experiment)）。
binary32 の引数も binary64 に広げて同じ変換を行う。
それ以外の実数と複素数の引数は複素数の演算で同じ変換を行い、成分が $2^{\pm 100}$ の外にあるときや右半平面の外にあるときは指数の範囲を広げた演算に切り替える。
このときの打ち切りの目標は相対 $10^{-12}$ である。
変換の 1 段（$R_J$ では入れ子の $R_C$ の段も含む）が `EllipticOptions` の作業量の上限の 1 単位になる。

### 定義域、極、主値

実数の型では、$R_F$、$R_D$、$R_G$ の負の引数と、$R_J$ の $x$、$y$、$z$、$R_C$ の $x$ の負の値は `DomainError`（`OutsideDomain`）になる。
$R_F$ で 2 つ以上の引数が 0、$R_D$ で $z = 0$ か $x = y = 0$、$R_J$ で $p = 0$ か $x$、$y$、$z$ のうち 2 つ以上が 0、$R_C$ で $y = 0$ の場合は極で、`DomainError`（`Pole`）になる。
$R_C(x, y)$ の $y < 0$ と $R_J(x, y, z, p)$ の $p < 0$ は積分路上に極があり、Cauchy の主値（DLMF §19.20）を返す。
$R_C(0, y)$（$y < 0$）の主値は 0 である。
$R_G$ はすべての引数が 0 でもよく、$R_G(0, 0, 0) = 0$、$R_G(0, 0, z) = \sqrt{z}/2$ である。
複素数の引数は各因子の平方根に主値を使い、負の実軸上の引数は虚部の符号付きゼロで切断の岸を選ぶ。
複素数の $R_J$ で、負の実軸上の引数の符号付きゼロが互いに逆の岸を指すときは `DomainError`（`OutsideDomain`）になる。
右半平面の外にある複素数の $R_J$ は、積分路を右半平面へ移し、移した区間の寄与を求積で足す。

## 誤差・安定性・計算量

重複変換の推定誤差は、変換の段数に比例する丸めのモデルから作る（信頼度 `ModelBased`）。
binary64 の $R_F$ では、段数を $N$、打ち切ったときの広がりを $\delta$ として相対誤差を $8(N + 1)\varepsilon + 4\delta^6$ とする（$\varepsilon$ は binary64 の機械イプシロン）。
`elliptic_f`、`elliptic_e_inc`、`elliptic_pi` の binary64 の相対誤差は $12\varepsilon + 8(N + 1)\varepsilon$ である。
推定誤差は包含区間ではない。
段数は引数の広がりの対数で決まり、実数の引数では数段から数十段で、既定の `EllipticOptions` の上限（65536 単位）よりずっと小さい。
上限は、スコープ付き API で親の求解に作業量を数えるときや、計算を短く打ち切りたいときに使う。

$\phi$ が $\pi/2$ を超えると振幅の還元が入るが、還元は $\pi$ の倍数を引くだけで、完全楕円積分の項は固定計算コストなので段数は増えない。
$m$ が 1 に近い場合の $m$ の丸めの拡大は [誤差・安定性・計算量](oxref:special-elliptic-error-cost) で説明した条件数の問題で、$1 - m$ を正確に作れるときは Carlson 形に直接渡すとこれを避けられる。

## 精度の保証

精度は照合データ（独立に生成した高精度の参照値）で試験した範囲について次のとおりである。

| 関数（実数の引数） | binary64 | binary32 | 試験で確かめた内容 |
|---|---|---|---|
| `carlson_rf`、`carlson_rd`、`carlson_rj` | 64 ULP | 64 ULP | binary64 の測定の最大は 4.8 ULP |
| `elliptic_f`、`elliptic_e_inc` | 64 ULP | 64 ULP | binary64 の測定の最大は 5.7 ULP |
| `elliptic_pi`、`carlson_rc`、`carlson_rg` | 64 ULP | 64 ULP | 目標の 64 ULP |

複素数の引数と指数の範囲を広げた経路には一様な ULP の仕様はなく、オプション付き形式の推定誤差を使う。
照合データは複素数の場合も推定誤差が実際の誤差を覆うかを確かめており、第三種の完全楕円積分の打ち消しが起こる角の近くも含む。

## 関数と呼び出しの形

すべての関数は `NumericScalar`（`f32`、`f64`、`Complex<f32>`、`Complex<f64>`）を受け取り、実数と複素数で同じ名前を使う。
標準形式は値だけを返し、オプション付き形式 `*_with_options(.., options)` は `SpecialFunctionResult` を、スコープ付き API `*_scoped(.., options, scope)` は求解スコープの中で同じ結果を返す。

| 族 | 標準形式 | オプション付き形式 | スコープ付き API | 定義域（実数の型） |
|---|---|---|---|---|
| 不完全楕円積分 | `elliptic_f(phi, m)`、`elliptic_e_inc(phi, m)` | `elliptic_f_with_options`、`elliptic_e_inc_with_options` | `elliptic_f_scoped`、`elliptic_e_inc_scoped` | $m \le 1$、$\phi$ は有限の実数 |
| 第三種の完全楕円積分 | `elliptic_pi(n, m)` | `elliptic_pi_with_options` | `elliptic_pi_scoped` | $n \le 1$、$m \le 1$ |
| Carlson 対称形 | `carlson_rf(x, y, z)`、`carlson_rd(x, y, z)`、`carlson_rj(x, y, z, p)`、`carlson_rc(x, y)`、`carlson_rg(x, y, z)` | `carlson_rf_with_options`、`carlson_rd_with_options`、`carlson_rj_with_options`、`carlson_rc_with_options`、`carlson_rg_with_options` | `carlson_rf_scoped`、`carlson_rd_scoped`、`carlson_rj_scoped`、`carlson_rc_scoped`、`carlson_rg_scoped` | 上の節を参照 |

オプション付き形式とスコープ付き API は `EllipticOptions` を受け取る。
`EllipticOptions` は作業量の上限（`Budget`）だけを持ち、既定は 65536 単位で、`EllipticOptions::new(Budget::try_from(n)?)` で変える。
精度の要求は受け取らず、上限を大きくしても結果の精度は変わらない。
上限に達すると、標準形式もオプション付き形式も途中の値を返さずに `ConvergenceFailure`（`IterationLimit`）を返す。
オプション付き形式の結果は推定誤差、終了状態（`SpecialFunctionTermination`）、計算量の計数、アルゴリズムの識別子を持つ。
アルゴリズムの識別子は使った経路（`real_carlson_rf` は binary64 の重複変換、`period_reduction` は振幅の還元を通った不完全楕円積分）を示す。
`elliptic_f` と `elliptic_e_inc` の母数は、振幅が複素数なら実数のまま渡せる（`m: impl Parameter<T>`）。
`elliptic_pi` の $n$ と $m$、Carlson 形の引数は同じ型にそろえる。

## 不完全楕円積分と Jacobi 楕円関数の逆関係

次のセルは、振幅 $\phi$、母数 $m$、特性 $n$ を選び、`elliptic_f`、`elliptic_e_inc`、`elliptic_pi` を複合 Simpson 則（20000 区間）の求積と比べる。
Simpson 則の打ち切り誤差は丸めより小さく、この 3 行の差は求積の和の丸め（$10^{-14}$ の程度）で決まる。
続く行は、振幅を半周期ずらした差 $F(\phi + \pi \mid m) - F(\phi \mid m)$ と $2K(m)$、$u = F(\phi \mid m)$ に対する $\operatorname{am}(u \mid m)$ と $\phi$、$\operatorname{sn}(u \mid m)$ と $\sin\phi$、$\operatorname{dn}(u \mid m)$ と $\sqrt{1 - m\sin^2\phi}$ を比べる。
$F$ は Carlson の重複変換、$K$ は固定計算コストの近似、Jacobi 楕円関数（[Jacobi 楕円関数](../jacobi-elliptic-functions/)）は AGM と降下 Landen 変換で求めるので、これらは別々のアルゴリズムの間の検算である。
2 つ目の表はオプション付き形式の計算量と、$m = 1$、$n \ge 1$、極での極限とエラー、作業量の上限を 3 単位にした `carlson_rf_with_options` の結果を示す。

次のブロックは、このページのセルが使う補助関数である。
`detail_row` はオプション付き形式の結果かエラーを表の 1 行にし、`error_label` はエラーを `kind()` の分類名と `view()` の詳細で書く。

```rust
//| id: special-carlson-detail-rows
//| kind: definitions
//| title: オプション付き形式の結果とエラーを表の行にまとめる
//| crates: [scioxide-core, scioxide-special]
use scioxide_core::{SciOxideError, SciOxideErrorView};
use scioxide_special::SpecialFunctionResult;

/// 表の 1 行：呼び出し、値、推定誤差、信頼度、終了状態またはエラー、計算量、アルゴリズム。
pub(crate) type DetailRow = (
    String,
    Option<f64>,
    Option<f64>,
    String,
    String,
    Option<usize>,
    String,
);

/// エラーを kind() の分類名と view() の詳細で表す。
pub(crate) fn error_label(error: &SciOxideError) -> String {
    match error.view() {
        SciOxideErrorView::DomainError { reason, .. } => format!("DomainError（{reason:?}）"),
        SciOxideErrorView::InvalidInput { reason, .. } => format!("InvalidInput（{reason:?}）"),
        SciOxideErrorView::ConvergenceFailure { reason, .. } => {
            format!("ConvergenceFailure（{reason:?}）")
        }
        SciOxideErrorView::NumericalInstability { issue, .. } => {
            format!("NumericalInstability（{issue:?}）")
        }
        _ => format!("{:?}", error.kind()),
    }
}

/// オプション付き形式の結果かエラーを 1 行にする。無限大の極限は値の列を空にし、終了状態の列に書く。
pub(crate) fn detail_row(
    call: &str,
    result: Result<SpecialFunctionResult<f64>, SciOxideError>,
) -> DetailRow {
    let result = match result {
        Ok(result) => result,
        Err(error) => {
            let label = error_label(&error);
            return (
                call.into(),
                None,
                None,
                String::new(),
                label,
                None,
                String::new(),
            );
        }
    };
    let estimate = result.value();
    let value = estimate.map(|v| *v.value());
    let status = match value {
        Some(v) if v.is_infinite() => format!("{:?}（+∞）", result.termination()),
        _ => format!("{:?}", result.termination()),
    };
    (
        call.into(),
        value.filter(|v| v.is_finite()),
        estimate
            .map(|v| v.absolute_error())
            .filter(|e| e.is_finite()),
        estimate
            .map(|v| format!("{:?}", v.reliability()))
            .unwrap_or_default(),
        status,
        Some(result.counts().iterations()),
        result.algorithm().to_string(),
    )
}

/// オプション付き形式の表の列。
pub(crate) fn detail_columns() -> serde_json::Value {
    let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
    let digits16 = serde_json::json!({ "significantDigits": 16 });
    serde_json::json!([
        { "key": "0", "label": "呼び出し" },
        { "key": "1", "label": "値", "type": "number", "format": digits16, "nullText": "—" },
        { "key": "2", "label": "推定誤差", "type": "number", "format": sci3, "nullText": "—" },
        { "key": "3", "label": "信頼度" },
        { "key": "4", "label": "終了状態またはエラー" },
        { "key": "5", "label": "計算量", "type": "integer", "nullText": "—" },
        { "key": "6", "label": "アルゴリズム" }
    ])
}
```

```rust
// 独立な参照：複合 Simpson 則（f64 の固有メソッド、20000 区間）。
let simpson = |end: f64, f: &dyn Fn(f64) -> f64| {
    let intervals = 20_000;
    let h = end / f64::from(intervals);
    let mut sum = f(0.0) + f(end);
    for i in 1..intervals {
        let weight = if i % 2 == 1 { 4.0 } else { 2.0 };
        sum += weight * f(h * f64::from(i));
    }
    sum * h / 3.0
};
let delta = |t: f64| (1.0 - m * t.sin().powi(2)).sqrt();
```

既定の $\phi = 2.5$、$m = 0.7$、$n = 0.5$ では、$F = 3.476875190644892$、$E = 1.871329430383859$、$\Pi = 3.089663490480848$ で、求積との差は $1.7 \times 10^{-14}$ 以下である。
$\operatorname{am}(F(\phi \mid m) \mid m)$ は $\phi = 2.5$ に一致し、振幅が $\pi/2$ を超えても逆関係が保たれる。
オプション付き形式の表では、$F$ と $E$ が `period_reduction` の経路を通って重複変換 6 段、$\Pi$ と $R_J$ が入れ子の $R_C$ を含めて 17 段、`jacobi_sn` が 10 段である。
$F$ の推定誤差 $5.2 \times 10^{-14}$ は、上のモデルの $12\varepsilon + 8 \cdot 7\varepsilon = 68\varepsilon$ に $F$ の値を掛けたものである。
$F(\pi/2 \mid 1)$ と $\Pi(1 \mid m)$ は `Limit` の $+\infty$、$F(2 \mid 1)$ と $\Pi(1.5 \mid m)$ は `DomainError`（`Undefined`）、$R_F(0, 0, 1)$ は `DomainError`（`Pole`）になる。
$R_C(1, -1) = 0.6232252401402306$ は Cauchy の主値で、閉じた形 $\ln(1 + \sqrt{2})/\sqrt{2}$（DLMF §19.2）と一致する。
作業量の上限を 3 単位にした $R_F(0, 0.5, 1)$ は 7 段の途中で止まり、値を返さずに `ConvergenceFailure`（`IterationLimit`）になる。
$m = -2$ では虚数の法を通っても差は $1.6 \times 10^{-14}$ 以下で、$\phi = 10$、$m = 0.99$ では振幅を $\pi$ の 3 倍だけ還元し、差は $4.3 \times 10^{-14}$ 以下にとどまる。

## まとめと次に読むページ

不完全楕円積分 $F$、$E$ はすべての有限の実数の振幅を受け付け、振幅を $[0, \pi/2]$ へ還元してから Carlson 形 $s R_F(c^2, \Delta^2, 1)$ などで評価する。
第三種の完全楕円積分は $R_F$ と $R_J$ の組で、第三種の不完全楕円積分は提供しないので同じ Carlson 形から組み立てる。
重複変換は引数の広がりを 1 段で約 4 分の 1 にし、実数の引数では数段から数十段で止まり、推定誤差は段数に比例する丸めのモデル（`ModelBased`）である。
$R_C$ の $y < 0$ と $R_J$ の $p < 0$ は Cauchy の主値を返し、極は `DomainError`（`Pole`）、作業量の上限への到達は `ConvergenceFailure`（`IterationLimit`）になる。
楕円積分の逆関数は [Jacobi 楕円関数](../jacobi-elliptic-functions/) で、完全楕円積分の固定計算コストの近似は [楕円積分の定義と完全楕円積分 K、E](../elliptic-and-legendre/) で、各項目の仕様は [楕円積分の API](../../api/elliptic/) で確かめる。
