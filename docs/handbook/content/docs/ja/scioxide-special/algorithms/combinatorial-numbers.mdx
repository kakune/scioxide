階乗と二項係数は、数え上げだけでなく、確率分布の正規化定数、統計の尤度、級数の係数に現れる。
どちらも整数だが、引数とともに指数関数より速く増え、binary64 で正確に表せる整数（$2^{53} \approx 9.0 \times 10^{15}$ 以下）の範囲や、binary64 の最大値 $1.80 \times 10^{308}$ をすぐに超える。
`scioxide-special` はこれらを浮動小数点数で返し、値があふれる場合のために対数形の関数（`ln_*`）とオプション付き形式の対数形を用意する。
正確な整数が要るときは、`scioxide-core` の `checked_factorial` と `checked_binomial` を使う。
このページは各関数の定義、正確な値と近似値の境目、方法の切り替え、精度の保証、API の使い分けを説明する。
Stirling 数、Bernoulli 数、Euler 数は [Stirling 数・Bernoulli 数・Euler 数](../stirling-bernoulli-euler-numbers/) で扱う。

## 階乗と多重階乗

非負の整数 $n$ の階乗は $n! = 1 \cdot 2 \cdots n = \Gamma(n+1)$ で、$0! = 1$ である（DLMF 5.4.1）。
歩長 $k \ge 1$ の多重階乗は $n$ から $k$ ずつ減らした正の因子の積である。

$$
n!^{(k)} = n\,(n-k)\,(n-2k)\cdots r, \qquad m = \left\lceil \frac{n}{k} \right\rceil, \quad r = n - (m-1)k
$$

$m$ は因子の数、$r \in [1, k]$ は最小の因子である。
$k = 1$ は階乗、$k = 2$ は二重階乗 $n!! = n(n-2)(n-4)\cdots$ で、空積の $n = 0$ は 1 を返す。
$0!! = 1!! = 1$ である。
`multifactorial(n, 0)` は `InvalidInput`（`OutOfRange`）になる。

因子が多いとき、多重階乗は Gamma 関数で書ける。
因子を $k$ でくくると $n!^{(k)} = k^m \cdot (r/k)(r/k + 1)\cdots(r/k + m - 1)$ で、後ろの積は Pochhammer 記号 $(r/k)_m$ だから、

$$
n!^{(k)} = k^m \frac{\Gamma(m + r/k)}{\Gamma(r/k)}
$$

となる。

`factorial` は $n \le 20$ を正確な表から返す。
$20! \approx 2.43 \times 10^{18}$ は $2^{53}$ を超えるが、素因数 2 を多く含むので binary64 で正確に表せる。
$21 \le n \le 128$ は積を double-word（2 ワードの浮動小数点数で約 106 ビットの仮数を持つ数）で作って一度だけ丸め、$n > 128$ は $\ln\Gamma(n+1)$ を double-word で評価して指数を取る。
$n!$ は binary64 で $n > 170$、binary32 で $n > 34$ のとき `NumericalInstability`（`Overflow`）になる。
`double_factorial` と `multifactorial` は、因子が 128 個以下なら double-word の積、それより多ければ上の Gamma 関数の形を対数で評価する。
値が範囲を超えると `NumericalInstability`（`Overflow`）になる。

対数形 `ln_factorial`、`ln_double_factorial`、`ln_multifactorial` はどの $n$ でもあふれない。
`ln_factorial(n)` は $\ln\Gamma(n+1)$ を double-word で評価し、$n \le 1$ では 0 を返す。
整数の階乗そのものが必要なら、`scioxide-core` の `checked_factorial` が $n!$ を `usize` の正確な整数で返し、`usize` を超えると `SizeOverflow` になる。

## 二項係数

整数の二項係数は $\binom{n}{k} = \frac{n!}{k!\,(n-k)!}$（$0 \le k \le n$、DLMF 26.3.1）で、`binomial(n, k)` は $k > n$ を `InvalidInput`（`OutOfRange`）として拒む。
0 は返さない。
$\binom{n}{0} = \binom{n}{n} = 1$ で、対称性 $\binom{n}{k} = \binom{n}{n-k}$ から $k' = \min(k, n-k)$ だけを扱う。

$k' < 128$ では、積

$$
\binom{n}{k} = \prod_{i=1}^{k'} \frac{n - k' + i}{i}
$$

を double-word で作って一度だけ丸める。
途中の値は常に二項係数の整数なので、途中で大きな階乗を作ってあふれることはない。
$k' \ge 128$ か積があふれる場合は、Beta 関数の対数を使う。

$$
\binom{n}{k} = \frac{1}{(n+1)\,B(n-k+1,\ k+1)}
$$

結果は浮動小数点数に丸めるので、$2^{53}$ を超える係数は一般に正確な整数ではない。
値が範囲を超えると `NumericalInstability`（`Overflow`）になり、`ln_binomial` は係数を作らずに $\ln\binom{n}{k}$ を返す。
正確な整数が必要なら、`scioxide-core` の `checked_binomial` を使う。
`checked_binomial` は `usize` を超えると `SizeOverflow` になり、$k > n$ ではエラーでなく 0 を返す点が `binomial` と異なる。
実数・複素数の上の引数 $z$ に対する $\binom{z}{k} = z(z-1)\cdots(z-k+1)/k!$ は `generalized_binomial` が計算し、分枝と表現の扱いは [API・分枝・値の表現](oxref:special-entry-exact-integers) で説明する。

次のセルは階乗の表、double-word の積、$\ln\Gamma$ の 3 つの方法の境目と、二項係数・多重階乗の方法の切り替えを表にする。
独立な検算として、$n \le 34$ の階乗を `u128` の整数で正確に計算し、`factorial` の値との差を結果の ULP で出す。
対数形は因子の対数 $\sum \ln(\text{因子})$ を手で足した値と比べる。
手で足した和は項の数だけ丸め誤差が積もるので、その差は $10^{-13}$ 程度までを一致とみなす。

```rust
//| id: special-combinatorial-factorial-range
//| ref: special-combinatorial-factorial-range
//| title: 階乗・二項係数・多重階乗の方法の切り替えと正確な整数との比較
//| run: reactive
//| crates: [scioxide-special]
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"factorials","path":"/rows/3/4","equals":0}
//|       - {"artifact":"factorials","path":"/rows/7/4","range":{"max":4.5e-16}}
//|       - {"artifact":"factorials","path":"/rows/12/1","equals":null}
//|       - {"artifact":"factorials","path":"/rows/12/7","equals":"NumericalInstability"}
//|       - {"artifact":"factorials","path":"/rows/13/5","range":{"max":1e-13}}
//|       - {"artifact":"ratios","path":"/rows/2/4","range":{"max":1e-13}}
//|       - {"artifact":"ratios","path":"/rows/5/1","equals":null}
//|       - {"artifact":"ratios","path":"/rows/9/4","range":{"max":1e-13}}
use scioxide_special::{
    CombinatorialOptions, binomial, binomial_with_options, factorial, factorial_with_options,
    ln_binomial, ln_factorial, ln_multifactorial, multifactorial, multifactorial_with_options,
};

let sci4 = serde_json::json!({ "notation": "scientific", "significantDigits": 4 });
let sig10 = serde_json::json!({ "significantDigits": 10 });
let options = CombinatorialOptions::default();

let mut factorial_rows = Vec::new();
for n in [
    0_usize, 5, 18, 20, 21, 22, 25, 34, 100, 128, 129, 170, 171, 1000,
] {
    let value = factorial::<f64>(n);
    let method = factorial_with_options::<f64>(n, options)
        .map_err(|e| e.to_string())?
        .algorithm()
        .to_string();
    // 独立検算 1: n ≤ 34 の階乗を u128 で正確に掛ける（34! < 2^128）。
    let exact = (n <= 34).then(|| (1..=n as u128).product::<u128>() as f64);
    let exact_error = match (&value, exact) {
        (Ok(v), Some(e)) => Some((v - e).abs() / e),
        _ => None,
    };
    // 独立検算 2: ln n! を因子の対数の和で作る（f64 の固有メソッドによる参照値）。
    let log_sum: f64 = (2..=n).map(|k| (k as f64).ln()).sum();
    let log_value = ln_factorial::<f64>(n).map_err(|e| e.to_string())?;
    let kind = match &value {
        Ok(_) => "なし".to_string(),
        Err(e) => format!("{:?}", e.kind()),
    };
    factorial_rows.push((
        n,
        value.ok(),
        exact,
        log_value,
        exact_error,
        (log_value - log_sum).abs() / log_sum.max(1.0),
        method,
        kind,
    ));
}
let columns = serde_json::json!([
    { "key": "0", "label": "n", "type": "integer" },
    { "key": "1", "label": "factorial(n)", "type": "number", "format": sig10, "nullText": "エラー" },
    { "key": "2", "label": "正確な n!（u128）", "type": "number", "format": sig10, "nullText": "—" },
    { "key": "3", "label": "ln_factorial(n)", "type": "number", "format": sig10 },
    { "key": "4", "label": "正確な値との相対差 [-]", "type": "number", "format": sci4, "nullText": "—" },
    { "key": "5", "label": "Σ ln k との相対差 [-]", "type": "number", "format": sci4 },
    { "key": "6", "label": "方法" },
    { "key": "7", "label": "エラーの分類" }
]);
emit_table_with_columns!(
    columns,
    factorial_rows,
    metadata = serde_json::json!({ "id": "factorials" })
);

// (名前, 値, ln 値, 因子の対数の和, 方法)。因子の対数の和は f64 の固有メソッドによる参照値。
let mut ratio_rows = Vec::new();
for (n, k) in [
    (10_usize, 3_usize),
    (60, 30),
    (1000, 127),
    (1000, 128),
    (1000, 500),
    (1100, 550),
] {
    let value = binomial::<f64>(n, k);
    let method = binomial_with_options::<f64>(n, k, options)
        .map_err(|e| e.to_string())?
        .algorithm()
        .to_string();
    let log_value = ln_binomial::<f64>(n, k).map_err(|e| e.to_string())?;
    let log_sum: f64 = (1..=k)
        .map(|i| (((n - k + i) as f64) / i as f64).ln())
        .sum();
    ratio_rows.push((
        format!("C({n}, {k})"),
        value.ok(),
        log_value,
        log_sum,
        method,
    ));
}
for (n, step) in [(10_usize, 3_usize), (256, 2), (257, 2), (3000, 7)] {
    let value = multifactorial::<f64>(n, step);
    let method = multifactorial_with_options::<f64>(n, step, options)
        .map_err(|e| e.to_string())?
        .algorithm()
        .to_string();
    let log_value = ln_multifactorial::<f64>(n, step).map_err(|e| e.to_string())?;
    let log_sum: f64 = (0..n.div_ceil(step))
        .map(|i| ((n - i * step) as f64).ln())
        .sum();
    ratio_rows.push((
        format!("{n}!^({step})"),
        value.ok(),
        log_value,
        log_sum,
        method,
    ));
}
let rows: Vec<_> = ratio_rows
    .into_iter()
    .map(|(name, value, log_value, log_sum, method)| {
        let difference = (log_value - log_sum).abs() / log_sum.abs().max(1.0);
        (name, value, log_value, log_sum, difference, method)
    })
    .collect();
let columns = serde_json::json!([
    { "key": "0", "label": "量" },
    { "key": "1", "label": "値", "type": "number", "format": sig10, "nullText": "あふれ" },
    { "key": "2", "label": "対数形の値", "type": "number", "format": sig10 },
    { "key": "3", "label": "因子の対数の和", "type": "number", "format": sig10 },
    { "key": "4", "label": "相対差 [-]", "type": "number", "format": sci4 },
    { "key": "5", "label": "方法" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "ratios" })
);
```

一つ目の表では、$n \le 20$ が表（`combinatorial/factorial_table@1`）、$21 \le n \le 128$ が double-word の積（`multifactorial_product`）、$n \ge 129$ が $\ln\Gamma$（`multifactorial_gamma`）で計算される。
$n \le 34$ の行では、正確な整数を丸めた値との相対差がすべて 0 で、$2^{53}$ を超える $21!$ 以降も正しく丸めた値になっている。
$n = 171$ と $1000$ の標準形式は `NumericalInstability` を返すが、`ln_factorial` は $\ln 1000! \approx 5912.13$ を返す。
因子の対数の和との相対差は $1.4 \times 10^{-15}$ で、1000 項を手で足した側の丸め誤差の程度である。

二つ目の表では、二項係数の方法が $\min(k, n-k) = 127$ から $128$ への境で、double-word の積（`binomial_twofold`）から Beta 関数の対数（`binomial_combined_gamma`）へ切り替わる。
$\binom{1100}{550} \approx 10^{329.5}$ は binary64 の範囲を超えて値の列が「あふれ」になり、対数形だけが $758.73$ を返す。
多重階乗も、因子が 128 個の $256!!$ から 129 個の $257!!$ への境で、積から Gamma 関数の形へ切り替わる。
どの行でも、対数形と因子の対数の和の相対差は $2 \times 10^{-15}$ 以下である。

## 精度の保証

照合データ（独立に高精度で生成した参照値）で確かめた ULP の目標は次のとおりである。

| 関数 | binary64 | binary32 | 補足 |
|---|---|---|---|
| `factorial`、`ln_factorial`、`binomial` | 4 ULP | 1 ULP | $n! \le 20!$ は binary64 で正確 |
| `ln_binomial`、`double_factorial`、`ln_double_factorial`、`multifactorial`、`ln_multifactorial`、`generalized_binomial` | 一様な仕様なし | 一様な仕様なし | 独立な参照値と恒等式で試験し、オプション付き形式が推定誤差を返す |

一様な仕様のない関数でも、オプション付き形式の推定誤差（`ValueWithError` の誤差。
包含区間ではない）は、上のセルの独立な検算のように使う範囲で確かめられる。
Pochhammer 記号も一様な仕様を持たない（[Gamma 関数・polygamma 関数・Pochhammer 記号](oxref:special-gamma-pochhammer)）。

## API

| 関数 | 標準形式の引数 | オプション付き形式 | スコープ付き API | 値 |
|---|---|---|---|---|
| `factorial` | `n` | `factorial_with_options` | なし | $n!$ |
| `ln_factorial` | `n` | `ln_factorial_with_options` | なし | $\ln n!$ |
| `double_factorial` | `n` | `double_factorial_with_options` | なし | $n!!$ |
| `ln_double_factorial` | `n` | `ln_double_factorial_with_options` | なし | $\ln n!!$ |
| `multifactorial` | `n, step` | `multifactorial_with_options` | なし | $n!^{(k)}$ |
| `ln_multifactorial` | `n, step` | `ln_multifactorial_with_options` | なし | $\ln n!^{(k)}$ |
| `binomial` | `n, k` | `binomial_with_options` | なし | $\binom{n}{k}$ |
| `ln_binomial` | `n, k` | `ln_binomial_with_options` | なし | $\ln\binom{n}{k}$ |
| `generalized_binomial` | `z, k` | `generalized_binomial_with_options` | `generalized_binomial_scoped` | $\binom{z}{k}$（実数・複素数の $z$） |

引数 `n`、`k`、`step` はすべて `usize` で、浮動小数点の関数は結果の型 `S: RealScalar` を `factorial::<f64>(n)` のように型引数で選ぶ（`generalized_binomial` だけは引数 `z` の型で決まる）。
オプション付き形式は `CombinatorialOptions` を受け取り、通常値と推定誤差、尺度化した値、対数形、終了状態、アルゴリズムの識別子、計算量の計数を持つ `SpecialFunctionResult` を返す。
値があふれてもオプション付き形式はエラーにならず、通常値への射影の状態が `ScalarRepresentation::Overflow` になって、対数形が残る。
`CombinatorialOptions` は作業量の上限（`Budget`）だけを持ち、既定は 65 536 単位で、`CombinatorialOptions::new(budget)` か `with_iteration_budget` で変える。
同じオプションは `pochhammer`、`pochhammer_relative`、Stirling 数、Bernoulli 数、Euler 数のオプション付き形式でも使う。
このページの関数では、作業量が $k$ で増える `generalized_binomial` だけがスコープ付き API を持ち、スコープ付き API はオプション付き形式と同じ結果を返して、計算量を親の実行コンテキストに渡す。

## まとめと次に読むページ

階乗は $n \le 20$ で binary64 の正確な値、$n \le 170$ で丸めた値になり、それより大きい $n$ や比の計算では `ln_factorial`、`ln_binomial`、`ln_multifactorial` かオプション付き形式の対数形を使う。
二項係数は $k' = \min(k, n-k) < 128$ で double-word の積、それ以上で Beta 関数の対数を使い、$2^{53}$ を超える係数は丸めた値になる。
`binomial` は $k > n$ で 0 でなく `InvalidInput` を返すので、和の範囲を呼び出し側で $k \le n$ に制限する。
正確な整数が要るなら、`scioxide-core` の `checked_factorial` と `checked_binomial` を使う。
Stirling 数、Bernoulli 数、Euler 数は [Stirling 数・Bernoulli 数・Euler 数](../stirling-bernoulli-euler-numbers/) で、実数の引数の Gamma 関数と Pochhammer 記号は [Gamma 関数・polygamma 関数・Pochhammer 記号](../gamma-family/) で、二項係数の実数・複素数への拡張 `generalized_binomial` の扱いは [API・分枝・値の表現](oxref:special-entry-exact-integers) で確かめる。
