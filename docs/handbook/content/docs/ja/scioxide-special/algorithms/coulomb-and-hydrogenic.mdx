荷電粒子どうしの散乱では、ポテンシャル $Z_1Z_2e^2/(4\pi\varepsilon_0 r)$ が $1/r$ でしか減らないので、遠方でも波の位相がずれ続ける。
そのため、自由粒子の球 Bessel 関数の代わりに、Coulomb ポテンシャルの動径方程式の解である Coulomb 波動関数を使う。
同じポテンシャルの負のエネルギーの解は、水素様原子の束縛状態になる。

このページは正則な Coulomb 波動関数 $F_l(\eta, \rho)$、非正則な $G_l(\eta, \rho)$、その導関数と規格化定数 $C_l(\eta)$、水素様原子の動径関数 $R_{nl}(r)$ を扱う。
定義と性質のあとに、`scioxide-special` が動径の領域ごとに使う方法（Steed の方法、外向きの漸近展開、転回点の内側での延長）、次数の漸化式による列の計算、精度の保証、API を説明し、最後の二つのセルで Wronskian と球 Bessel 関数の極限を確かめる。
応用は [水素様原子の動径波動関数と期待値](../../examples/hydrogen-radial-states/) と [Coulomb 障壁の透過と Gamow 因子](../../examples/coulomb-barrier-penetration/) にある。

## Coulomb 波動方程式と解の規約

換算質量 $\mu$、エネルギー $E = \hbar^2k^2/(2\mu) > 0$ の相対運動を、軌道角運動量 $l$ の部分波に分ける。
無次元の動径 $\rho = kr$ を使うと、動径関数 $w(\rho)$ は Coulomb 波動方程式（DLMF 33.2.1）を満たす。

$$
w'' + \left(1 - \frac{2\eta}{\rho} - \frac{l(l+1)}{\rho^2}\right)w = 0, \qquad
\eta = \frac{Z_1Z_2e^2}{4\pi\varepsilon_0\hbar v} = \frac{Z_1Z_2\,\alpha c}{v}.
$$

$\eta$ は Sommerfeld パラメータで、$v$ は相対速度、$\alpha$ は微細構造定数である。
斥力（$Z_1Z_2 > 0$）では $\eta > 0$、引力では $\eta < 0$ で、エネルギーが下がると $\lvert\eta\rvert$ は $1/\sqrt{E}$ のように大きくなる。
`scioxide-special` では $\rho$ を引数 `z`、$l$ を引数 `l`（実数）、$\eta$ を引数 `eta` で渡す。

正則解 $F_l$ は原点で $F_l(\eta, \rho) \sim C_l(\eta)\,\rho^{l+1}$ のように振る舞う解で、規格化定数は次のとおりである（DLMF 33.2.5）。

$$
C_l(\eta) = \frac{2^l e^{-\pi\eta/2}\,\lvert\Gamma(l + 1 + i\eta)\rvert}{\Gamma(2l + 2)}, \qquad
C_0(\eta)^2 = \frac{2\pi\eta}{e^{2\pi\eta} - 1}.
$$

$C_0(\eta)^2$ は Gamow–Sommerfeld 因子と呼ばれ、$\eta \gg 1$ では $2\pi\eta\,e^{-2\pi\eta}$ になる。
これは斥力の Coulomb 障壁を原点まで通り抜ける確率を表し、低エネルギーの核反応率を支配する。

遠方では、二つの解は位相のずれた正弦波に近づく（DLMF 33.2.10、33.10.1）。

$$
F_l \sim \sin\theta_l, \quad G_l \sim \cos\theta_l, \qquad
\theta_l = \rho - \eta\ln(2\rho) - \frac{l\pi}{2} + \sigma_l(\eta), \quad
\sigma_l(\eta) = \arg\Gamma(l + 1 + i\eta).
$$

位相の項 $-\eta\ln(2\rho)$ が長距離のポテンシャルの効果で、$\sigma_l$ は Coulomb 位相のずれである。
非正則解 $G_l$ はこの漸近形で決まり、原点では $\rho^{-l}$ のように発散する。
外向きと内向きの波は $H_l^\pm = G_l \pm iF_l$（DLMF 33.2.7）で、Wronskian（二つの解 $f$、$g$ に対する $fg' - f'g$）は次の定数である（DLMF 33.2.12）。

$$
F_l'G_l - F_lG_l' = 1.
$$

$\eta = 0$ では Coulomb ポテンシャルが消え、解は球 Bessel 関数で書ける。
$F_l(0, \rho) = \rho\,j_l(\rho)$、$G_l(0, \rho) = -\rho\,y_l(\rho)$ で、$l = 0$ では $F_0 = \sin\rho$、$G_0 = \cos\rho$ である。

### 転回点と解の大きさ

方程式の係数 $1 - 2\eta/\rho - l(l+1)/\rho^2$ が 0 になる点

$$
\rho_{\mathrm{tp}} = \eta + \sqrt{\eta^2 + l(l+1)}
$$

が古典的な転回点である（DLMF 33.2.2）。
$\rho > \rho_{\mathrm{tp}}$ では解は振動し、$F_l$ と $G_l$ は同じ程度の大きさを持つ。
$\rho < \rho_{\mathrm{tp}}$ の障壁の内側では、$F_l$ は原点へ向かって指数的に小さくなり、$G_l$ は指数的に大きくなる。
$\eta = 20$、$l = 2$、$\rho = 0.1$ では $F_2 \approx 1.5 \times 10^{-28}$、$G_2 \approx 1.1 \times 10^{26}$ で、両者の積が Wronskian によって 1 程度に保たれる。
この大きさの差が、どの方向に解を延長すれば誤差が増えないかを決める。

## 正の実数の動径での評価法

実数の $\rho > 0$ では、次の順に方法を選ぶ。
内部の計算は2 ワードの算術（double-word、`f64` 二つで約 106 ビットを表す算術）で行い、値は「仮数 × $e^{\text{尺度}}$」の形で持つ。

1. $l = \eta = 0$ では $F_0 = \sin\rho$、$G_0 = \cos\rho$ を直接返す。
2. $\rho \ge 32$ では、外向きの波の漸近展開（DLMF 33.11.1） $H_l^+ \sim e^{i\theta_l}\sum_n (l + 1 + i\eta)_n(-l + i\eta)_n/(n!\,(2i\rho)^n)$ を試す。
   項ははじめ 1 段あたり約 $(l^2 + \eta^2)/(2n\rho)$ 倍に育つので、値と導関数の剰余が丸めの水準に収束し、育った項の2 ワードの算術での丸めが `f64` の 1 単位より小さいときだけ受理する。
   これは $(l^2 + \eta^2)/\rho$ がおよそ 59 より小さい範囲にあたり、固定の半径の閾値はない。
3. 受理されなければ Steed の方法を使う。
   転回点より外側の点 $\rho_a = \max(\rho, \eta + \sqrt{\eta^2 + (l + 1/2)^2} + 1)$ で二つの連分数を評価する。
4. $\rho < \rho_a$（転回点の内側）では、$G_l$ を $\rho_a$ から内向きに、$F_l$ を原点の級数から外向きに延長し、Wronskian で規格化する。

### Steed の方法

Steed の方法（Barnett 1981）は、二つの連分数と Wronskian から $F_l$、$G_l$、$F_l'$、$G_l'$ を同時に決める。
第 1 の連分数 CF1（DLMF 33.8.1）は対数微分 $f = F_l'/F_l$ を与える。
CF1 は $F_l$ が次数について極小解であることを使う連分数で、修正 Lentz の方法で評価し、分母の符号の変化から $F_l$ の符号も求める。
第 2 の連分数 CF2（DLMF 33.8.2）は、外向きの波の対数微分 $(H_l^+)'/H_l^+ = p + iq$ を与える。
CF2 は転回点の外側で収束するので、評価点を $\rho_a$ まで外へ動かす。

四つの未知数に対して、$f$、$p$、$q$ と Wronskian の四つの式があるので、解は次の閉じた形になる。

$$
F_l = \pm\sqrt{\frac{q}{(f - p)^2 + q^2}}, \quad F_l' = fF_l, \quad G_l = \frac{f - p}{q}F_l, \quad G_l' = pG_l - qF_l.
$$

符号は CF1 で求めた $F_l$ の符号に合わせる。
CF2 は増分が和の $2^{-64}$ 以下になるまで2 ワードの算術で進め、残りの裾を `f64` で足して、その丸めを推定誤差に含める。
CF1 と CF2 の項数はおよそ $\rho - \eta$ に比例して増えるので、Steed の方法の計算量も $\rho - \eta$ に比例する。
外向きの漸近展開が受理されない大きな $\rho$（大きな $l$ か $\lvert\eta\rvert$ で、$(l^2 + \eta^2)/\rho > 59$）では、この計算量が既定の作業量の上限を超えることがある。

### 転回点の内側

転回点の内側では CF2 の収束が遅くなり、$F_l$ と $G_l$ の大きさが大きく離れる。
そこで、$\rho_a$ で Steed の方法により求めた $G_l$ と $G_l'$ を初期値にして、微分方程式の Taylor 級数の刻みで $\rho$ まで内向きに延長する。
内向きには $G_l$ が増える解なので、延長の誤差は相対的に増えない。
$F_l$ は、原点まわりの Frobenius 級数 $F_l \propto \rho^{l+1}\sum_n a_n\rho^n$（DLMF 33.6）を、打ち消しが $2^{23}$ 倍以下に収まる半径まで足し、そこから外向きに Taylor 級数で延長する。
外向きには $F_l$ が増える解なので、こちらも安定である。
最後に、こうして作った $F_l$ を Wronskian $F_l'G_l - F_lG_l' = 1$ で規格化する。

`coulomb_f`、`coulomb_f_prime`、`coulomb_spherical_f` を単独で呼ぶと、$\rho < \rho_a$ では $G_l$ を作らず、原点の級数と外向きの延長で求めた $F_l$ を規格化定数 $C_l(\eta)$ で直接規格化する。
$\rho \ge \rho_a$ では `coulomb_wave` と同じ計算を使う。
したがって、転回点の内側では `coulomb_f` と `coulomb_wave` の $F_l$ は別の経路で計算され、丸めの程度で異なることがある（下のセルで比べる）。

### 複素数の動径

複素数の $z$ では、原点まわりの級数、微分方程式の Taylor 級数による延長、$H_l^\pm$ の漸近展開（$\lvert z\rvert > 8 + \lvert l\rvert + \lvert\eta\rvert$）と複素数の CF2 を組み合わせる。
分枝の切断は負の実軸に沿い、虚部が $\pm 0$ のときはその符号で切断のどちら側かを選ぶ。
実数の型で負の $z$ を渡すと定義域の外になる。

## 次数の漸化式と列

隣り合う次数の解は、次の昇降の関係式（DLMF 33.4.1、33.4.2 の形）で結ばれ、$u$ は $F$ と $G$ のどちらでもよい。

$$
R_{l+1}\,u_{l+1} = S_{l+1}u_l - u_l', \qquad
R_l\,u_{l-1} = S_lu_l + u_l', \qquad
S_l = \frac{l}{\rho} + \frac{\eta}{l}, \quad R_l = \sqrt{1 + \frac{\eta^2}{l^2}}.
$$

導関数は同じ式を解き直して次の次数の値から求めるので、列の各要素は値と導関数の組で進む。
$F_l$ は $l$ が増えると小さくなる極小解なので、高い次数から下向きに回すと誤差が増えない。
$G_l$ は $l$ とともに大きくなる優越解なので、上向きに回す。

`coulomb_sequence(component, l, eta, z, count)` は、`CoulombComponent` で選んだ成分（`F`、`G`、`FPrime`、`GPrime`、`SphericalF`）を次数 $l, l+1, \ldots, l + \text{count} - 1$ で返す。
$F$、$F'$、$F/z$ は最高次数で一度評価して下向きに、$G$、$G'$ は最低次数で評価して上向きに回すので、計算コストはスカラーの評価 1 回と $O(\text{count})$ 段の漸化式である。
`coulomb_wave_sequence(l, eta, z, count)` は、次数ごとに `[F, G, F′, G′]` を返す。
`coulomb_normalization_sequence(l, eta, count)` は、比 $C_{l+1}/C_l = \sqrt{(l+1)^2 + \eta^2}/((l+1)(2l+3))$ の対数を2 ワードの算術で積み重ねて $C_l(\eta), C_{l+1}(\eta), \ldots$ を返す。

この三つは結果の `Vec` を割り当てる所有値を返す API である。
`coulomb_sequence_into`、`coulomb_wave_sequence_into`、`coulomb_normalization_sequence_into` は、出力の配列 `output` と同じ長さ以上の作業用の配列 `staging` を受け取り、まず `staging` に詳細な結果を書き、すべての次数で成功したときだけ `output` に写す。
失敗したときは `output` を書き換えず、何も割り当てない。
`_into` 形は `CoulombOptions` と求解スコープを受け取り、すべての次数で一つの作業量の上限を共有する。
各要素が返す計算量の計数は、列全体の計数である。

## 規格化定数

`coulomb_normalization(l, eta)` は $C_l(\eta)$ を返す。
定義域は $l > -1$ で、波動関数の $l > -1/2$ より広い。
$\ln\lvert\Gamma(l + 1 + i\eta)\rvert$ を2 ワードの算術で求め、$\ln C_l$ として組み立てるので、大きな正の $\eta$ で $C_l$ が `f64` の範囲より小さくなるときも、オプション付き形式 `coulomb_normalization_with_options` は尺度化形と対数形を返す。
計算量が引数によらず有界なので、スコープ付き API はない。

## 水素様原子の動径関数

核電荷 $Z$ の水素様原子の束縛状態 $(n, l)$ の動径関数は、Bohr 半径 $a_0$ を長さの単位として次の式で定義される。

$$
R_{nl}(r) = \left(\frac{2Z}{n}\right)^{3/2}\sqrt{\frac{(n - l - 1)!}{2n\,(n + l)!}}\;e^{-\rho/2}\rho^l\,L_{n-l-1}^{(2l+1)}(\rho), \qquad \rho = \frac{2Zr}{n}.
$$

$n \ge 1$ は主量子数、$0 \le l < n$ は軌道量子数、$L_k^{(\alpha)}$ は一般化 Laguerre 多項式（DLMF §18.3）である。
規格化は $\int_0^\infty R_{nl}(r)^2 r^2\,dr = 1$ で、角度の因子（球面調和関数）は含まない。
この規約では原点の近くで $R_{nl} > 0$ になる。
Laguerre 多項式の古い記法 $L_{n+l}^{2l+1}$ と $[(n+l)!]^3$ を使う式とは、因子と符号が違うので注意する。

`hydrogenic_radial(n, l, charge, r)` は、$r$ を Bohr 半径の単位で受け取る。
$Z$（`charge`）は正の実数ならよく、整数でなくてもよい。
$r$ は実数の $r \ge 0$ か複素数で、$R_{nl}$ は $r$ について整関数である。
Laguerre 多項式は、項が有限個で終わる Kummer 関数 $U(-(n - l - 1), 2l + 2, \rho) = (-1)^{n-l-1}(n - l - 1)!\,L_{n-l-1}^{(2l+1)}(\rho)$ として評価し、規格化の階乗は対数ガンマ関数で計算する。
動径方向の節（$R_{nl} = 0$ となる $r > 0$）は $n - l - 1$ 個ある。
期待値や確率密度による検算は [水素様原子の動径波動関数と期待値](../../examples/hydrogen-radial-states/) で行う。

名前の似た `RadialKind` は Mathieu 関数と回転楕円体関数の動径関数の種類を選ぶ型で、Coulomb 波動関数と水素様の動径関数には関係しない（[Mathieu 関数とスペクトル法](../mathieu-and-spheroidal/)、[回転楕円体波動関数](../spheroidal-wave-functions/)）。

## 精度の保証

ULP は厳密な結果の位置での浮動小数点数の間隔である。
独立に生成した参照値で確かめた実数の $F_l$、$G_l$ とその導関数の目標は試験した範囲で `f64` と `f32` の 64 ULP で、零点の近くでは条件数から決めた絶対誤差の限界で判定する。
参照値の格子は $-1/2 < l \le 32$、$-100 \le \eta \le 250$、$10^{-4} \le \rho \le 10^6$ で、ほかに $\rho = 10^{12}$、$10^{30}$ のような個別の点を含む。
これより大きな $l$、$\lvert\eta\rvert$、$\rho$ には参照値との比較がない。
既定の作業量の上限での掃引は$l, \lvert\eta\rvert \le 1300$、$2 \times 10^4 \le \rho \le 10^8$ の組で、評価が成功し、Wronskian が相対 $10^{-13}$ 以内で 1 になり、推定誤差が振幅の $64\varepsilon$ 程度に収まることを確かめる。
$l$ か $\lvert\eta\rvert$ がこれより大きく、$\rho$ が約 $6 \times 10^4$ から $(l^2 + \eta^2)/59$ までの範囲では、Steed の方法の計算量が既定の上限を超えて `ConvergenceFailure`（`IterationLimit`）になる。
上限を約 $\rho - \eta$ 単位より大きくすれば評価できる（$l = \eta = 3000$、$\rho = 10^5$ は $2^{17}$ 単位で成功する）。

複素数の動径、規格化定数、水素様の動径関数には一様な ULP の仕様がない。
複素数の参照値は次数 50 まで、$\lvert\eta\rvert \le 100$、$10^{-3} \le \lvert z\rvert \le 10^4$ を含み、規格化定数の試験は $\lvert\eta\rvert \le 10^4$ まで行う。
これらの値の精度は漸化式、延長、規格化の誤差を含むオプション付き形式の推定誤差（`ValueWithError` の誤差。
包含区間ではない）で読む。

## API

`coulomb_f` などの波動関数と `hydrogenic_radial` は `NumericScalar` で、`z`・`r` に実数（`f32`、`f64`）と複素数を受け取り、`l`・`eta`・`charge` は実数（`T::Real`）である。
どれにも標準形式、`SpecialFunctionResult`（`coulomb_wave` では `CoulombWaveResult`）を返すオプション付き形式、求解スコープを受け取るスコープ付き API がある。
オプション `CoulombOptions` は作業量の上限（`Budget`。
精度の要求ではない）だけを持ち、既定は 65536 単位である。

| 標準形式 | オプション付き形式 | スコープ付き API | 値 |
|---|---|---|---|
| `coulomb_f` | `coulomb_f_with_options` | `coulomb_f_scoped` | $F_l(\eta, z)$ |
| `coulomb_g` | `coulomb_g_with_options` | `coulomb_g_scoped` | $G_l(\eta, z)$ |
| `coulomb_f_prime` | `coulomb_f_prime_with_options` | `coulomb_f_prime_scoped` | $dF_l/dz$ |
| `coulomb_g_prime` | `coulomb_g_prime_with_options` | `coulomb_g_prime_scoped` | $dG_l/dz$ |
| `coulomb_spherical_f` | `coulomb_spherical_f_with_options` | `coulomb_spherical_f_scoped` | $F_l(\eta, z)/z$（原点で有限） |
| `coulomb_wave` | `coulomb_wave_with_options` | `coulomb_wave_scoped` | `[F, G, F′, G′]` を一度の評価で |
| `coulomb_normalization` | `coulomb_normalization_with_options` | なし | $C_l(\eta)$（実数のみ） |
| `hydrogenic_radial` | `hydrogenic_radial_with_options` | `hydrogenic_radial_scoped` | $R_{nl}(r)$（`n`、`l` は `u32`） |

| 所有値を返す API（既定の上限、`Vec` を返す） | 書き込み形（オプションとスコープを取る） | 値 |
|---|---|---|
| `coulomb_sequence` | `coulomb_sequence_into` | 選んだ成分の次数 $l, \ldots, l + N - 1$ の列 |
| `coulomb_wave_sequence` | `coulomb_wave_sequence_into` | 次数ごとの `[F, G, F′, G′]`（書き込み形は `CoulombWaveResult`） |
| `coulomb_normalization_sequence` | `coulomb_normalization_sequence_into` | $C_l(\eta), \ldots, C_{l+N-1}(\eta)$ |

`coulomb_wave` の標準形式は配列 `[F, G, F′, G′]` を返し、一つでも通常値にできない成分があればエラーになる。
オプション付き形式の `CoulombWaveResult` は `f()`、`g()`、`f_prime()`、`g_prime()` で各成分の `SpecialFunctionResult` を返し、`is_success()` は四つすべての終了状態が成功のときだけ真になる。
四つの成分は同じ評価の計算量の計数を持つので、足し合わせない。
`CoulombWaveResult::zero()` は `coulomb_wave_sequence_into` の配列を初期化するための値で、評価の結果ではない。

エラーは `SciOxideError` の `kind()` で分類する。
$l \le -1/2$（規格化定数では $l \le -1$）と実数の負の $z$ は `DomainError`（`OutsideDomain`）である。
$z = 0$ では、$F$ はどの $l$ でも値を返し、$F'$、$F/z$ は $l \ge 0$ で値を返す。
$G$ は $l = 0$ でだけ $1/C_0(\eta)$ を返し、$G'$ と `coulomb_wave` は $l = \eta = 0$ でだけ値を返して、それ以外の $l \ge 0$ は `DomainError`（`Pole`）になる。
$-1/2 < l < 0$ の $z = 0$ は、$F$ を除いて `DomainError`（`OutsideDomain`）になる。
`hydrogenic_radial` は $n = 0$、$l \ge n$、$Z \le 0$、実数の負の $r$ で `DomainError`（`OutsideDomain`）を返す。
列の関数は、次数 $l + k$ が有限でないか前の次数と同じ値に丸められると、長さの引数（`count` か `output`）を指す `DomainError`（`OutsideDomain`）を返し、`_into` 形は `staging` が短いと `DimensionMismatch` を返す。
値が型の範囲を超えると `NumericalInstability`（`Overflow`）、作業量の上限で止まると `ConvergenceFailure`（`IterationLimit`）である。

## 転回点の前後での Wronskian

次のセルは$\eta$ と $l$ を選び、$\rho = 0.1$ から $10^5$ までの 10 点で `coulomb_wave_with_options` を評価する。
表は転回点 $\rho_{\mathrm{tp}}$ の内側か外側か、$F_l$ と $G_l$、Wronskian $F_l'G_l - F_lG_l'$ と 1 の差、`coulomb_f` が返す $F_l$ との相対差、オプション付き形式の計算量を示す。
Wronskian は四つの成分を同じ評価から取るので、値と導関数の整合を確かめる。
`coulomb_f` との比較は転回点の内側で $F_l$ を別の経路（規格化定数による規格化）で作るので、独立な検算になる。

```rust
//| id: special-coulomb-wronskian-check
//| ref: special-coulomb-wronskian-check
//| title: 転回点の前後での Coulomb 波動関数の Wronskian
//| run: reactive
//| crates: [scioxide-special]
//| inputs:
//|   eta: {"type":"range","label":"Sommerfeld パラメータ η [-]","description":"正は斥力、負は引力。","min":-10,"max":30,"step":1,"value":5}
//|   order: {"type":"range","label":"軌道角運動量 l [-]","min":0,"max":10,"step":1,"value":0}
//| cases:
//|   - {"id":"deep-barrier","label":"η = 20、l = 2","description":"ρ = 0.1 で F が 10⁻²⁸、G が 10²⁶ になる深い障壁の内側。","inputs":{"eta":20,"order":2}}
//|   - {"id":"attractive","label":"η = −3","description":"引力では転回点が原点に近く、ほぼ全域で振動する。","inputs":{"eta":-3}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"wronskian","path":"/rows/0/2","approx":{"value":1.3416431909850268e-7,"rtol":1e-13}}
//|       - {"artifact":"wronskian","path":"/rows/0/3","approx":{"value":333191.5307189955,"rtol":1e-13}}
//|       - {"artifact":"wronskian","path":"/rows/0/4","range":{"max":4}}
//|       - {"artifact":"wronskian","path":"/rows/1/5","range":{"max":4}}
//|       - {"artifact":"wronskian","path":"/rows/9/4","range":{"max":4}}
//|   - case: deep-barrier
//|     expect:
//|       - {"artifact":"wronskian","path":"/rows/0/2","approx":{"value":1.4673178434732155e-28,"rtol":1e-12}}
//|       - {"artifact":"wronskian","path":"/rows/0/4","range":{"max":4}}
//|       - {"artifact":"wronskian","path":"/rows/6/5","range":{"max":4}}
//|   - case: attractive
//|     expect:
//|       - {"artifact":"wronskian","path":"/rows/0/4","range":{"max":4}}
//|       - {"artifact":"wronskian","path":"/rows/8/4","range":{"max":4}}
use scioxide_special::{CoulombOptions, coulomb_f, coulomb_wave_with_options};

let l = f64::from(order);
let options = CoulombOptions::default();
let eps = f64::EPSILON;
// 転回点 ρ_tp と、Steed の方法の評価点 ρ_a の下限。
let turning = eta + (eta * eta + l * (l + 1.0)).sqrt();
let anchor = eta + eta.hypot(l + 0.5) + 1.0;
let radii = [
    0.1_f64, 0.5, 2.0, 5.0, 10.0, 20.0, 40.0, 100.0, 1.0e3, 1.0e5,
];
let mut rows = Vec::new();
for &rho in &radii {
    let waves = coulomb_wave_with_options(l, eta, rho, options).map_err(|e| e.to_string())?;
    let f = waves.f().try_value().map_err(|e| e.to_string())?;
    let g = waves.g().try_value().map_err(|e| e.to_string())?;
    let fp = waves.f_prime().try_value().map_err(|e| e.to_string())?;
    let gp = waves.g_prime().try_value().map_err(|e| e.to_string())?;
    let wronskian = fp * g - f * gp;
    // 単独の coulomb_f（内側では C_l(η) で規格化する別の経路）。
    let single = coulomb_f(l, eta, rho).map_err(|e| e.to_string())?;
    let region = if rho < turning {
        "内側"
    } else if rho < anchor {
        "外側（ρ_a より内）"
    } else {
        "外側"
    };
    rows.push((
        rho,
        region,
        f,
        g,
        (wronskian - 1.0).abs() / eps,
        (single - f).abs() / (eps * f.abs()),
        waves.f().counts().iterations(),
    ));
}
let sci6 = serde_json::json!({ "notation": "scientific", "significantDigits": 6 });
let fixed1 = serde_json::json!({ "fractionDigits": 1 });
let columns = serde_json::json!([
    { "key": "0", "label": "ρ [-]", "type": "number" },
    { "key": "1", "label": "転回点に対する位置" },
    { "key": "2", "label": "F_l [-]", "type": "number", "format": sci6 },
    { "key": "3", "label": "G_l [-]", "type": "number", "format": sci6 },
    { "key": "4", "label": "|W − 1| [ε 単位]", "type": "number", "format": fixed1 },
    { "key": "5", "label": "coulomb_f との相対差 [ε 単位]", "type": "number", "format": fixed1 },
    { "key": "6", "label": "計算量 [単位]", "type": "integer" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "wronskian" })
);
```

既定の $\eta = 5$、$l = 0$ では転回点は $\rho_{\mathrm{tp}} = 10$ で、$\rho = 0.1$ の $F_0 \approx 1.3 \times 10^{-7}$ と $G_0 \approx 3.3 \times 10^5$ から、外側の振幅 1 程度の振動まで変わる。
Wronskian の差はどの点でも 0 か 0.5 $\varepsilon$ 単位で、2 ワードの算術で作った四つの成分が丸めの水準で整合している。
`coulomb_f` との相対差も 1 $\varepsilon$ 単位以下で、転回点の内側の二つの経路が一致する。
計算量は内側の延長を使う $\rho \le 10$ で 300〜900 単位、外側では 78〜199 単位である。
$\eta = 20$、$l = 2$ では $\rho = 40$ まで内側に入り、$F_2$ と $G_2$ の比が $10^{54}$ に達しても、値を「仮数 × $e^{\text{尺度}}$」で持つので Wronskian は 1 に保たれる。
差が数十 $\varepsilon$ 単位を超えたら、引数の組が試験の範囲の外にないかを確かめ、オプション付き形式の推定誤差を読む。

## 球 Bessel 関数の極限と次数の列

$\eta = 0$ では $F_l(0, \rho) = \rho\,j_l(\rho)$、$G_l(0, \rho) = -\rho\,y_l(\rho)$、$C_l(0) = 2^l\,l!/(2l+1)!$ になる。
次のセルは$\rho$ を選び、$l = 0, \ldots, 8$ の `[F, G, F′, G′]` を `coulomb_wave_sequence` で一度に作って `spherical_jn`、`spherical_yn` と比べる。
同じ次数の $F_l/\rho$ を `coulomb_sequence`（`CoulombComponent::SphericalF`）で、$C_l(0)$ を `coulomb_normalization_sequence` で作り、それぞれ $j_l(\rho)$ と階乗の式と比べる。
列は $F$ を下向き、$G$ を上向きの漸化式で作るので、この表は漸化式の安定性の検算にもなる。

```rust
//| id: special-coulomb-bessel-limit
//| ref: special-coulomb-bessel-limit
//| title: η = 0 の Coulomb 波動関数の列と球 Bessel 関数
//| run: reactive
//| crates: [scioxide-special]
//| inputs:
//|   rho: {"type":"range","label":"動径 ρ [-]","description":"ρ < l では F_l が小さく G_l が大きい。","min":0.5,"max":20,"step":0.5,"value":3}
//| cases:
//|   - {"id":"small","label":"ρ = 0.5","description":"高い次数ほど F_l は小さく G_l は大きくなり、l = 8 で比 G/F は約 10¹⁹ になる。","inputs":{"rho":0.5}}
//|   - {"id":"large","label":"ρ = 20","description":"すべての次数が転回点の外側にあり、振動する。","inputs":{"rho":20}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"orders","path":"/rows/0/1","approx":{"value":0.14112000805986719,"rtol":1e-14}}
//|       - {"artifact":"orders","path":"/rows/8/3","range":{"max":16}}
//|       - {"artifact":"orders","path":"/rows/8/4","range":{"max":16}}
//|       - {"artifact":"orders","path":"/rows/8/6","range":{"max":4}}
//|   - case: small
//|     expect:
//|       - {"artifact":"orders","path":"/rows/8/1","approx":{"value":5.630719801060645e-11,"rtol":1e-13}}
//|       - {"artifact":"orders","path":"/rows/8/3","range":{"max":16}}
//|       - {"artifact":"orders","path":"/rows/8/4","range":{"max":16}}
//|   - case: large
//|     expect:
//|       - {"artifact":"orders","path":"/rows/8/3","range":{"max":16}}
//|       - {"artifact":"orders","path":"/rows/8/4","range":{"max":16}}
use scioxide_special::{
    CoulombComponent, coulomb_normalization_sequence, coulomb_sequence, coulomb_wave_sequence,
    spherical_jn, spherical_yn,
};

const COUNT: usize = 9;
let eps = f64::EPSILON;
let waves = coulomb_wave_sequence(0.0, 0.0, rho, COUNT).map_err(|e| e.to_string())?;
let spherical = coulomb_sequence(CoulombComponent::SphericalF, 0.0, 0.0, rho, COUNT)
    .map_err(|e| e.to_string())?;
let normalization =
    coulomb_normalization_sequence(0.0_f64, 0.0, COUNT).map_err(|e| e.to_string())?;
let relative = |a: f64, b: f64| (a - b).abs() / (eps * b.abs());
let mut rows = Vec::new();
// C_l(0) = 2^l l!/(2l+1)! を順に更新する（独立検算）。
let mut exact_c = 1.0_f64;
for (l, ([f, g, _, _], (&f_over_rho, &c))) in waves
    .iter()
    .zip(spherical.iter().zip(&normalization))
    .enumerate()
{
    let n = l as u32;
    if n > 0 {
        exact_c *= 2.0 * f64::from(n) / (f64::from(2 * n) * f64::from(2 * n + 1));
    }
    let j = spherical_jn(n, rho).map_err(|e| e.to_string())?;
    let y = spherical_yn(n, rho).map_err(|e| e.to_string())?;
    rows.push((
        n,
        *f,
        *g,
        relative(*f, rho * j),
        relative(*g, -rho * y),
        relative(f_over_rho, j),
        relative(c, exact_c),
    ));
}
let sci6 = serde_json::json!({ "notation": "scientific", "significantDigits": 6 });
let fixed1 = serde_json::json!({ "fractionDigits": 1 });
let columns = serde_json::json!([
    { "key": "0", "label": "l", "type": "integer" },
    { "key": "1", "label": "F_l(0, ρ) [-]", "type": "number", "format": sci6 },
    { "key": "2", "label": "G_l(0, ρ) [-]", "type": "number", "format": sci6 },
    { "key": "3", "label": "F と ρ j_l の相対差 [ε 単位]", "type": "number", "format": fixed1 },
    { "key": "4", "label": "G と −ρ y_l の相対差 [ε 単位]", "type": "number", "format": fixed1 },
    { "key": "5", "label": "F/ρ と j_l の相対差 [ε 単位]", "type": "number", "format": fixed1 },
    { "key": "6", "label": "C_l(0) の相対差 [ε 単位]", "type": "number", "format": fixed1 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "orders" })
);
```

既定の $\rho = 3$ では、$l \ge 3$ が転回点 $\sqrt{l(l+1)}$ の内側に入り、$F_l$ は $l$ とともに減り、$G_l$ は増える。
どの列の相対差も 5 $\varepsilon$ 単位以下で、下向きと上向きの漸化式が誤差を増やしていない。
$\rho = 0.5$ では $l = 8$ で $F_8 \approx 5.6 \times 10^{-11}$、$G_8 \approx 5.2 \times 10^8$ と比が約 $10^{19}$ になるが、相対差は 3 $\varepsilon$ 単位以下のままである。
漸化式を逆向き（$F$ を上向き）に回すと、この比の分だけ誤差が増えるので、極小解を下向きに回す設計がここで効いている。

## まとめ

Coulomb 波動関数は、$\rho \ge 32$ で外向きの漸近展開が受理されればそれを、されなければ転回点の外側で Steed の方法（CF1 と CF2 と Wronskian）を使い、転回点の内側では $G_l$ を内向きに、$F_l$ を原点から外向きに延長する。
計算量は Steed の方法で $\rho - \eta$ に比例するので、大きな $l$ や $\lvert\eta\rvert$ と大きな $\rho$ の組では `CoulombOptions` の上限を上げる。
多くの次数が要るときは、$F$ を下向き、$G$ を上向きに回す `coulomb_sequence` と `coulomb_wave_sequence` を使い、割り当てを避けたいときは `_into` 形を使う。
実数の動径の $F_l$、$G_l$ とその導関数は試験した範囲で 64 ULP を目標とし、複素数の動径、規格化定数、水素様の動径関数はオプション付き形式の推定誤差で精度を読む。
物理の単位を付けた計算は [Coulomb 障壁の透過と Gamow 因子](../../examples/coulomb-barrier-penetration/) と [水素様原子の動径波動関数と期待値](../../examples/hydrogen-radial-states/) で確かめ、項目ごとの仕様は [Coulomb・組合せ関数](../../api/coulomb-and-combinatorics/) で確かめる。
