3 軸の長さがすべて異なる楕円体（3 軸不等楕円体）の外側の重力ポテンシャルや、楕円体の導体のまわりの静電ポテンシャルは、楕円体座標で Laplace 方程式を分離して求める。
分離で現れる常微分方程式が Lamé 方程式で、その多項式型の解が Lamé 関数、それらの積が楕円体調和関数である。
回転楕円体や球は、2 つまたは 3 つの軸が等しくなる極限にあたる。
`scioxide-special` は、Lamé 関数の第 1 種 $E_n^p$、無限遠で減衰する第 2 種 $F_n^p$、楕円体面上の規格化定数 $\gamma_n^p$ を、係数を保持する Plan `EllipsoidalHarmonicPlan` とワンショット関数で提供する。
このページは、座標と方程式、4 つの類、係数の固有値問題、第 2 種と規格化定数の求積、精度の保証、API の順に説明する。
記号と定義は Dassios (2012) に従う。

## 楕円体座標と Lamé 方程式

半軸 $a_1 > a_2 > a_3 > 0$ の楕円体に対し、半焦点距離を $h^2 = a_1^2 - a_2^2$、$k^2 = a_1^2 - a_3^2$（$0 < h < k$）と定める。
楕円体座標 $(\rho, \mu, \nu)$ は $\rho \ge k \ge \mu \ge h \ge \nu \ge 0$ をとり、直交座標とは

$$
x^2 = \frac{\rho^2\mu^2\nu^2}{h^2k^2},\qquad
y^2 = \frac{(\rho^2 - h^2)(\mu^2 - h^2)(h^2 - \nu^2)}{h^2(k^2 - h^2)},\qquad
z^2 = \frac{(\rho^2 - k^2)(k^2 - \mu^2)(k^2 - \nu^2)}{k^2(k^2 - h^2)}
$$

で結ばれる。
$\rho$ が一定の面は半軸 $\rho$、$\sqrt{\rho^2 - h^2}$、$\sqrt{\rho^2 - k^2}$ の楕円体で、$\rho = a_1$ がはじめの楕円体である。
$\mu$ と $\nu$ が一定の面はそれぞれ 1 葉と 2 葉の双曲面で、楕円体の面上で角度座標の役割を果たす。

Laplace 方程式 $\nabla^2 V = 0$ に $V = E(\rho)E(\mu)E(\nu)$ を代入すると、3 つの因子はどれも同じ Lamé 方程式

$$
(s^2 - h^2)(s^2 - k^2)\,E''(s) + s\,(2s^2 - h^2 - k^2)\,E'(s) + \left(\Lambda - n(n+1)s^2\right)E(s) = 0
$$

を満たす。
$n$ は次数、$\Lambda$ は分離定数である（Dassios の記法では $\Lambda = (h^2 + k^2)p$）。
$\Lambda$ を適切に選ぶと、多項式と焦点の因子 $\sqrt{|s^2 - h^2|}$、$\sqrt{|s^2 - k^2|}$ の積の形の解が得られ、その数は各 $n$ にちょうど $2n + 1$ 個ある。
これを第 1 種の Lamé 関数 $E_n^p(s)$（$1 \le p \le 2n+1$）と呼ぶ。
内部の調和関数は $E_n^p(\rho)E_n^p(\mu)E_n^p(\nu)$ で、$x, y, z$ の $n$ 次の多項式になる。

## Lamé 関数の 4 つの類

$E_n^p$ は焦点の因子の有無で 4 つの類に分かれる（`LameClass`）。

| 類 | 形 | 個数（$r = \lfloor n/2 \rfloor$） |
|---|---|---|
| `K` | $n$ 次の多項式 | $r + 1$ |
| `L` | $\sqrt{\lvert s^2 - h^2\rvert}$ × $n-1$ 次の多項式 | $n - r$ |
| `M` | $\sqrt{\lvert s^2 - k^2\rvert}$ × $n-1$ 次の多項式 | $n - r$ |
| `N` | $\sqrt{\lvert s^2 - h^2\rvert}\sqrt{\lvert s^2 - k^2\rvert}$ × $n-2$ 次の多項式 | $r$ |

多項式は $s$ の偶関数か奇関数で、次数 $n$ の偶奇に合わせて決まる。
添字 $p$ は類 `K`、`L`、`M`、`N` の順に、各類の中では分離定数の小さい順に数える。
規格化は最高次の係数を 1 にする（$s \to \infty$ で $E_n^p(s) \sim s^n$）。
たとえば $n = 1$ では $E_1^1 = s$（`K`、$\Lambda = h^2 + k^2$）、$E_1^2 = \sqrt{|s^2 - h^2|}$（`L`、$\Lambda = k^2$）、$E_1^3 = \sqrt{|s^2 - k^2|}$（`M`、$\Lambda = h^2$）である。
実数の $s$ では焦点の因子を正にとり、`EllipsoidalSigns::new(negative_h, negative_k)` でそれぞれの符号を反転できる。
これは楕円体の座標が $x, y, z$ の 2 乗しか決めないので、象限ごとに符号を選ぶためである。
複素数の $s$ では焦点の因子を解析接続し、虚部が 0 のときはその符号で切断のどちら側かを選ぶ。

## 係数の固有値問題

`EllipsoidalHarmonicPlan::new(h2, k2, n, p, options)` は、引数に $h^2$ と $k^2$ をとる。
準備では $s = h\cos\phi$ と置き、類 `M`、`N` では因子 $(1 - s^2/k^2)^{1/2}$ を外したうえで、残りを $\cos j\phi$（`K`、`M`）または $\sin j\phi$（`L`、`N`）で展開する。
これは $s/h$ の Chebyshev 多項式 $T_j$、$U_{j-1}$ による展開と同じである。
Lamé 方程式は係数の三項漸化式になり、多項式解では有限の三重対角行列で終わる。
行列は非対称なので、副対角を上下の積の平方根に置き換えて対称化し、全固有値と固有ベクトルを `scioxide-linalg` の対称三重対角固有値ソルバー（大きさ 32 以下では陰的 QL 法、それより大きいと分割統治法）で求めて、$p$ に対応する固有値を選ぶ。
固有値は分離定数 $\Lambda/k^2$ で、`EllipsoidalHarmonicPlan::eigenvalue_over_k_squared` で読める。

QL 法の固有値と最大成分の位置は正確だが、端の小さい成分は相対精度が悪いことがある。
そこで、固有値を漸化式に入れて両端から最大成分へ向かって成分を組み直し、対称化の重みを戻して Chebyshev 係数にする。
対称化した固有方程式の相対残差が $10^{-12}$ を超えると `NumericalInstability`（`LossOfSignificance`）を返し、残差は `EllipsoidalHarmonicPlan::spectral_residual` で読める。
係数の推定誤差は $16\varepsilon(n+1)$ に、残差を隣の固有値との最小の間隔で割った値を加えたものである。
準備の計算量と一時的なメモリ使用量は $O(n^2)$、Plan が保持する係数は $O(n)$ である。

$n > 0$ では、もう一つの展開を準備する。
$h$ と $k$ の間の実数 $s$（$h < |s| < k$）では $s/h > 1$ となり、Chebyshev 級数は区間の外で項が大きくなって打ち消し合う。
この範囲では $t = \sqrt{k^2 - s^2}$ を変数とし、$h^2$ を $k^2 - h^2$ に置き換えた補の問題の展開を使う。
二つの問題の分離定数を $k^2$ で割った値の和は $n(n+1)$ になるはずで、相対 $10^{-12}$ を超えて外れると `NumericalInstability`（`LossOfSignificance`）を返す。

`EllipsoidalHarmonicPlan::first_kind(s, signs)` は、Clenshaw の漸化式で Chebyshev 級数を足し、焦点の因子を掛けて値と $s$ による導関数を返す。
計算量は係数 1 個につき 1 単位である。
推定誤差は係数の推定誤差に Clenshaw の和の条件数（項の絶対値の和と値の比）を掛けたものである。
$s = \pm h$ や $s = \pm k$ では値は有限だが、導関数が発散する類ではその点の導関数を省く。
第 1 種の精度は `EllipsoidalOptions` の許容誤差に依存しない。

### 第 1 種の検算

次のセルは、$h^2$、$k^2$、次数 $n$、座標 $s$ を選び、$p = 1, \dots, 2n+1$ の Plan を作る。
表は類、分離定数 $\Lambda/k^2$、$E_n^p(s)$ と導関数、Lamé 方程式の残差、最高次係数の検算を示す。
方程式の残差は、2 階導関数を API の導関数の中心差分（刻み $10^{-5}$）で作り、3 つの項の絶対値の和で割った相対値で、差分の誤差（$10^{-9}$ 程度）より小さければ方程式を満たしている。
最高次係数の検算は $E_n^p(10^3 k)/(10^3k)^n$ で、1 に近いことを確かめる。

```rust
//| id: special-ellipsoidal-lame-first-order
//| ref: special-ellipsoidal-lame-first-order
//| title: 第 1 種 Lamé 関数の分離定数と方程式の残差
//| run: reactive
//| crates: [scioxide-special]
//| inputs:
//|   h2: {"type":"range","label":"h²","description":"短いほうの半焦点距離の 2 乗。k² より小さくする。","min":0.1,"max":0.9,"step":0.05,"value":0.5}
//|   degree: {"type":"integer","label":"次数 n","min":0,"max":5,"value":1}
//|   s: {"type":"range","label":"座標 s","description":"h と k の間では補の展開を使う。","min":0.1,"max":3,"step":0.05,"value":1.5}
//| cases:
//|   - {"id":"degree-three","label":"n = 3、s = 0.8","description":"7 つの関数が K、L、M、N の 4 類に分かれ、h < s < k で補の展開を使う。","inputs":{"degree":3,"s":0.8}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"first-kind","path":"/rows/0/2","approx":{"value":1.5,"atol":1e-13}}
//|       - {"artifact":"first-kind","path":"/rows/1/3","approx":{"value":1.3228756555322954,"rtol":1e-13}}
//|       - {"artifact":"first-kind","path":"/rows/2/2","approx":{"value":0.5,"atol":1e-13}}
//|       - {"artifact":"first-kind","path":"/rows/2/5","range":{"max":1e-9}}
//|   - case: degree-three
//|     expect:
//|       - {"artifact":"first-kind","path":"/rows/6/1","equals":"N"}
//|       - {"artifact":"first-kind","path":"/rows/3/5","range":{"max":1e-8}}
//|       - {"artifact":"first-kind","path":"/rows/0/6","approx":{"value":1,"rtol":1e-5}}
use scioxide_special::{EllipsoidalHarmonicPlan, EllipsoidalOptions, EllipsoidalSigns};

let k2 = 1.0;
let n = degree as usize;
let signs = EllipsoidalSigns::default();
let mut rows = Vec::new();
for p in 1..=2 * n + 1 {
    let plan = EllipsoidalHarmonicPlan::new(h2, k2, n, p, EllipsoidalOptions::default())
        .map_err(|e| e.to_string())?;
    let evaluate = |x: f64| {
        plan.first_kind(x, signs)
            .and_then(|r| Ok((r.try_value()?, r.try_derivative()?)))
            .map_err(|e| e.to_string())
    };
    let (value, slope) = evaluate(s)?;
    // 2 階導関数は API の導関数の中心差分（独立な検算）
    let step = 1e-5;
    let curvature = (evaluate(s + step)?.1 - evaluate(s - step)?.1) / (2.0 * step);
    let lambda = plan.eigenvalue_over_k_squared() * k2;
    let terms = [
        (s * s - h2) * (s * s - k2) * curvature,
        s * (2.0 * s * s - h2 - k2) * slope,
        (lambda - (n * (n + 1)) as f64 * s * s) * value,
    ];
    let scale: f64 = terms.iter().map(|t| t.abs()).sum();
    let residual = terms.iter().sum::<f64>().abs() / scale;
    // 最高次の係数が 1（E ~ sⁿ）であることの検算
    let far = 1e3 * k2.sqrt();
    let leading = evaluate(far)?.0 / far.powi(n as i32);
    let class = format!("{:?}", plan.class());
    rows.push((
        p as u32,
        class,
        plan.eigenvalue_over_k_squared(),
        value,
        slope,
        residual,
        leading,
    ));
}
let fixed10 = serde_json::json!({ "fractionDigits": 10 });
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let columns = serde_json::json!([
    { "key": "0", "label": "p", "type": "integer" },
    { "key": "1", "label": "類" },
    { "key": "2", "label": "Λ/k²", "type": "number", "format": fixed10 },
    { "key": "3", "label": "Eₙᵖ(s)", "type": "number", "format": fixed10 },
    { "key": "4", "label": "dEₙᵖ/ds", "type": "number", "format": fixed10 },
    { "key": "5", "label": "方程式の相対残差", "type": "number", "format": sci3 },
    { "key": "6", "label": "E(10³k)/(10³k)ⁿ", "type": "number", "format": fixed10 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "first-kind" })
);
```

既定の $h^2 = 0.5$、$k^2 = 1$、$n = 1$、$s = 1.5$ では、3 つの関数が `K`、`L`、`M` の順に並び、分離定数は $\Lambda/k^2 = 1 + h^2/k^2 = 1.5$、$1$、$h^2/k^2 = 0.5$ になる。
値は $E_1^1 = s = 1.5$、$E_1^2 = \sqrt{s^2 - h^2} = 1.3229$、$E_1^3 = \sqrt{s^2 - k^2} = 1.1180$ で、上の閉形式と一致する。
方程式の相対残差は $5 \times 10^{-11}$ 以下で、差分で作った 2 階導関数が持つ誤差の水準である。
最高次係数の検算は $1 - 2.5 \times 10^{-7}$ などで、残りは低次の項（$\sqrt{s^2 - h^2} = s(1 - h^2/(2s^2) + \cdots)$ の $s^{-2}$ の項）の寄与である。
$n = 3$、$s = 0.8$ のケースでは、7 つの関数が `K` 2 個、`L` 2 個、`M` 2 個、`N` 1 個に分かれ、各類の中で $\Lambda/k^2$ が増える順に並ぶ。
$s = 0.8$ は $h \approx 0.707$ と $k = 1$ の間なので補の展開で評価され、方程式の残差は $2.4 \times 10^{-9}$ 以下にとどまる。


## 第 2 種の Lamé 関数と外部の調和関数

無限遠で減衰する外部の解には、第 2 種の Lamé 関数

$$
F_n^p(s) = (2n+1)\,E_n^p(s)\int_s^\infty \frac{dt}{E_n^p(t)^2\sqrt{t^2 - h^2}\sqrt{t^2 - k^2}}
$$

を使う。
$s \to \infty$ では $E_n^p(t)^2 \sim t^{2n}$ なので $F_n^p(s) \sim s^{-n-1}$ となり、最高次の係数 1 の規約のもとで $s^{n+1}F_n^p(s) \to 1$ である。
外部の調和関数は $F_n^p(\rho)E_n^p(\mu)E_n^p(\nu)$ で、楕円体の外側の重力ポテンシャルの展開に使う。
定義から $\frac{d}{ds}(F/E) = -(2n+1)/(E^2\sqrt{(s^2-h^2)(s^2-k^2)})$ となるので、Wronskian は

$$
E_n^p F_n^{p\prime} - E_n^{p\prime} F_n^p = -\frac{2n+1}{\sqrt{(s^2 - h^2)(s^2 - k^2)}}
$$

である。

`EllipsoidalHarmonicPlan::second_kind(s)` は、$t = s/u$ と置き換えた $u \in (0, 1]$ の積分

$$
\int_s^\infty \frac{dt}{E(t)^2\sqrt{t^2 - h^2}\sqrt{t^2 - k^2}} = \frac{1}{s}\int_0^1 \frac{du}{E(s/u)^2\sqrt{1 - h^2u^2/s^2}\sqrt{1 - k^2u^2/s^2}}
$$

を適応求積で求める。
被積分関数は $u = 0$ の近くで $u^{2n}$ のように振る舞い、なめらかである。
求積は 32 点の Gauss–Legendre 則の区間を 2 つに分けた値と比べ、差が許容誤差（`EllipsoidalOptions` の相対許容誤差の 0.05 倍、ただし $32\varepsilon$ 以上）に収まらない区間を二分し続ける。
$s$ は実数なら $s > k$、複素数なら $|s| > k$ でなければならず、外れると `DomainError`（`OutsideDomain`）になる。
$s$ が $k$ に近いほど $u = 1$ の近くで平方根の分母が小さくなり、二分の回数が増える。

低い次数では、積分を Carlson の対称形で書ける。
$u$ の積分に DLMF 19.29 型の置き換えを使い、$R_F$ と $R_D$ の同次性を使うと

$$
F_0^1(s) = R_F(s^2,\ s^2 - h^2,\ s^2 - k^2),\qquad
F_1^1(s) = s\,R_D(s^2 - h^2,\ s^2 - k^2,\ s^2)
$$

となる。
`carlson_rf` と `carlson_rd` は Carlson の倍加法で計算するので、適応求積とは独立な検算になる。

## 規格化定数

楕円体面上の調和関数 $E_n^p(\mu)E_n^p(\nu)$ の規格化定数は

$$
\gamma_n^p = 8\int_0^h\!\!\int_h^k \frac{E_n^p(\nu)^2E_n^p(\mu)^2\,(\mu^2 - \nu^2)}{\sqrt{(h^2 - \nu^2)(k^2 - \nu^2)(\mu^2 - h^2)(k^2 - \mu^2)}}\,d\mu\,d\nu
$$

である（8 は楕円体の 8 つの象限の分）。
被積分関数は 4 つの端点で逆平方根の特異性を持つが、積分は有限である。
`EllipsoidalHarmonicPlan::normalization` は、$\nu = h\,\operatorname{sn}(u \mid m)$、$\mu = h/\operatorname{dn}(v \mid 1 - m)$（$m = h^2/k^2$）と Jacobi の楕円関数で置き換えて特異性を除く。
$\mu^2 - \nu^2 = (\mu^2 - h^2) + (h^2 - \nu^2)$ と分けると、二重積分は 4 つの 1 次元の積分の積の和になり、それぞれを上と同じ適応求積で求める。
積分の上端は第 1 種の完全楕円積分で、Carlson の $R_F$ で求める。
低い次数では $\gamma_0^1 = 4\pi$、$\gamma_1^1 = \tfrac{4\pi}{3}h^2k^2$、$\gamma_1^2 = \tfrac{4\pi}{3}h^2(k^2 - h^2)$、$\gamma_1^3 = \tfrac{4\pi}{3}k^2(k^2 - h^2)$ である（Dassios 2012）。

### 第 2 種の検算

次のセルは、$h^2$、次数 $n$、添字 $p$、開始座標を選び（$k^2 = 1$）、$s$ を 2 倍ずつ大きくしながら $F_n^p(s)$ を求める。
表は、$n \le 1$、$p = 1$ のときの Carlson の対称形との相対差、$s^{n+1}F_n^p(s)$、Wronskian の相対誤差を示す。
グラフは $F_n^p(s)$ を両対数軸で描き、漸近形 $s^{-n-1}$ を破線で重ねる。

```rust
//| id: special-ellipsoidal-second-kind-decay
//| ref: special-ellipsoidal-second-kind-decay
//| title: 第 2 種 Lamé 関数の減衰と Carlson の対称形
//| run: reactive
//| crates: [scioxide-special]
//| inputs:
//|   h2: {"type":"range","label":"h²","min":0.1,"max":0.9,"step":0.05,"value":0.5}
//|   degree: {"type":"integer","label":"次数 n","min":0,"max":4,"value":1}
//|   order: {"type":"integer","label":"添字 p","description":"1 から 2n + 1 まで。","min":1,"max":9,"value":1}
//|   s_start: {"type":"range","label":"開始座標 s（s > k = 1）","min":1.05,"max":4,"step":0.05,"value":1.5}
//| cases:
//|   - {"id":"degree-zero","label":"n = 0、s = 1.05","description":"F₀¹ は R_F と一致し、s が k に近くても求積が収束する。","inputs":{"degree":0,"s_start":1.05}}
//|   - {"id":"degree-three","label":"n = 3、p = 5","description":"閉形式のない次数では Wronskian と漸近形で確かめる。","inputs":{"degree":3,"order":5}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"exterior","path":"/rows/0/1","approx":{"value":0.565108769080411,"rtol":1e-10}}
//|       - {"artifact":"exterior","path":"/rows/0/2","range":{"max":1e-13}}
//|       - {"artifact":"exterior","path":"/rows/0/4","range":{"max":1e-12}}
//|       - {"artifact":"exterior","path":"/rows/7/3","approx":{"value":1,"rtol":1e-4}}
//|   - case: degree-zero
//|     expect:
//|       - {"artifact":"exterior","path":"/rows/0/2","range":{"max":1e-12}}
//|   - case: degree-three
//|     expect:
//|       - {"artifact":"exterior","path":"/rows/0/2","equals":null}
//|       - {"artifact":"exterior","path":"/rows/0/4","range":{"max":1e-12}}
//|       - {"artifact":"exterior","path":"/rows/7/3","approx":{"value":1,"rtol":1e-4}}
use scioxide_special::{
    EllipsoidalHarmonicPlan, EllipsoidalOptions, EllipsoidalSigns, carlson_rd, carlson_rf,
};

let k2 = 1.0;
let n = degree as usize;
// p は 1 から 2n + 1 までに収める
let p = (order as usize).min(2 * n + 1);
let options = EllipsoidalOptions::default();
let plan = EllipsoidalHarmonicPlan::new(h2, k2, n, p, options).map_err(|e| e.to_string())?;
let mut rows = Vec::new();
let mut curve = Vec::new();
let mut asymptote = Vec::new();
for step in 0..8 {
    let s = s_start * 2.0_f64.powi(step);
    let pair = |r: scioxide_special::SpecialFunctionResult<f64>| -> Result<(f64, f64), String> {
        Ok((
            r.try_value().map_err(|e| e.to_string())?,
            r.try_derivative().map_err(|e| e.to_string())?,
        ))
    };
    let (f, df) = pair(plan.second_kind(s).map_err(|e| e.to_string())?)?;
    let (e, de) = pair(
        plan.first_kind(s, EllipsoidalSigns::default())
            .map_err(|e| e.to_string())?,
    )?;
    // Carlson の対称形による閉形式（n ≤ 1、p = 1 だけ。独立な検算）
    let (x, y, z) = (s * s, s * s - h2, s * s - k2);
    let closed = match (n, p) {
        (0, 1) => Some(carlson_rf(x, y, z).map_err(|e| e.to_string())?),
        (1, 1) => Some(s * carlson_rd(y, z, x).map_err(|e| e.to_string())?),
        _ => None,
    };
    let relative = closed.map(|c| (f - c).abs() / c.abs());
    let wronskian = e * df - de * f;
    let expected = -((2 * n + 1) as f64) / (y * z).sqrt();
    let wronskian_error = (wronskian - expected).abs() / expected.abs();
    rows.push((s, f, relative, f * s.powi(n as i32 + 1), wronskian_error));
    curve.push([s, f]);
    asymptote.push([s, s.powi(-(n as i32) - 1)]);
}
emit_line_chart!(
    &vec![
        serde_json::json!({ "name": "Fₙᵖ(s)", "points": curve }),
        serde_json::json!({ "name": "s⁻ⁿ⁻¹", "points": asymptote, "style": { "lineType": "dashed" } })
    ],
    options = &serde_json::json!({
        "xLabel": "座標 s [-]",
        "yLabel": "第 2 種 Fₙᵖ(s) [-]",
        "xType": "log",
        "yType": "log"
    })
);
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let fixed10 = serde_json::json!({ "fractionDigits": 10 });
let columns = serde_json::json!([
    { "key": "0", "label": "s [-]", "type": "number" },
    { "key": "1", "label": "Fₙᵖ(s)", "type": "number", "format": sci3 },
    { "key": "2", "label": "閉形式との相対差", "type": "number", "format": sci3, "nullText": "閉形式なし" },
    { "key": "3", "label": "sⁿ⁺¹ Fₙᵖ(s)", "type": "number", "format": fixed10 },
    { "key": "4", "label": "Wronskian の相対誤差", "type": "number", "format": sci3 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "exterior" })
);
```

既定の $n = 1$、$p = 1$ では、$F_1^1(1.5) = 0.5651087691$ で、$s\,R_D$ による閉形式との相対差は $4 \times 10^{-16}$ である。
$s^{2}F_1^1(s)$ は $s = 1.5$ の 1.27 から $s = 192$ の $1.0000122$ へ 1 に近づき、グラフの $F$ は大きい $s$ で破線の $s^{-2}$ に重なる。
Wronskian の相対誤差はどの $s$ でも $2 \times 10^{-16}$ 以下である。
$n = 0$、$s = 1.05$ のケースでは、$s$ が $k$ に近くても $F_0^1$ は $R_F$ と相対 $2 \times 10^{-16}$ で一致し、$s$ を 134.4 まで広げても相対差は $4 \times 10^{-16}$ 以下にとどまる。
閉形式のない $n = 3$、$p = 5$ でも、Wronskian と $s^4F_3^5 \to 1$ で結果を確かめられる。


次のセルは、$h^2$ を選び（$k^2 = 1$）、$n = 0, 1$ のすべての $p$ について `EllipsoidalHarmonicPlan::normalization` の値を上の閉形式と比べる。
表には、求積の終了状態と、詳細な結果が返す推定誤差（相対）も示す。

## 精度の保証

楕円体調和関数には、関数全体で一様な ULP の仕様はない。
`spectral_residual` は診断の値で、誤差の上界ではない。
各評価が返す推定誤差は、係数の推定誤差、Chebyshev の和の条件数、求積では許容誤差から作る推定で、包含区間ではない。

照合試験は独立に高精度で生成した参照値と次の幅で比べている。
`f64` では、$E_n^p$ とその導関数、$F_n^p$ とその導関数、$\gamma_n^p$、分離定数がどれも相対 $5 \times 10^{-11}$ 以内である（求積の許容誤差 $10^{-8}$ で試験）。
`f32` の Plan は相対 $2 \times 10^{-4}$ 以内である。
$n \le 8$ のすべての $p$ について、Wronskian を相対 $5 \times 10^{-10}$、Lamé 方程式の残差を差分の精度の範囲で試験している。
$F_0^1$ は `carlson_rf` と相対 $5 \times 10^{-11}$、$\gamma_1^p$ は閉形式と相対 $5 \times 10^{-11}$ 以内である。

## API

| 項目 | 役割 |
|---|---|
| `EllipsoidalHarmonicPlan::new(h2, k2, n, p, options)` | $E_n^p$ の係数（$n > 0$ では補の展開も）を準備する。`build(.., scope)` は同じ準備をスコープの中で行う |
| `EllipsoidalHarmonicPlan::first_kind(s, signs)`、`first_kind_scoped` | $E_n^p(s)$ と導関数の詳細な結果（実数・複素数の `s`） |
| `EllipsoidalHarmonicPlan::second_kind(s)`、`second_kind_scoped` | $F_n^p(s)$ と導関数の詳細な結果 |
| `EllipsoidalHarmonicPlan::normalization()`、`normalization_scoped` | 規格化定数 $\gamma_n^p$ の詳細な結果 |
| `EllipsoidalHarmonicPlan::eigenvalue_over_k_squared`、`spectral_residual`、`preparation_accounting` | 分離定数 $\Lambda/k^2$、固有方程式の相対残差、準備の計算量の計数 |
| `EllipsoidalHarmonicPlan::geometry`、`degree`、`order`、`class` | $(h^2, k^2)$、$n$、$p$、`LameClass` |
| `ellipsoidal_harmonic(h2, k2, n, p, s, signs)` | $E_n^p(s)$ のワンショット関数 |
| `ellipsoidal_harmonic_second_kind(h2, k2, n, p, s)` | $F_n^p(s)$ のワンショット関数 |
| `ellipsoidal_normalization(h2, k2, n, p)` | $\gamma_n^p$ のワンショット関数 |
| `LameClass` | 類 `K`、`L`、`M`、`N` |
| `EllipsoidalSigns::new(negative_h, negative_k)` | 焦点の因子の符号。既定はどちらも正 |
| `EllipsoidalOptions` | 求積の相対許容誤差（`with_relative_tolerance`、既定 `f64` で $10^{-12}$、`f32` で $10^{-5}$）と作業量の上限（`with_iteration_budget`、既定 262,144 単位） |

同じ楕円体と $(n, p)$ で多くの点を評価するときや、推定誤差・導関数・終了状態が必要なときは Plan を作る。
Plan は作ったときのオプションを保持し、準備と各評価はそれぞれ別の作業量の上限を持つ。
ワンショット関数は既定の `EllipsoidalOptions` で Plan を一つ作って一度だけ評価し、準備と評価で一つの上限を共有して、通常の値を返す。
ワンショット関数にはオプション付き形式 `*_with_options` とスコープ付き API `*_scoped` はなく、その用途には Plan とその `*_scoped` のメソッドを使う。

エラーは次のとおりである。
$h^2$、$k^2$、$s$ が NaN または無限大なら `NonFinite`、$0 < h^2 < k^2$ でなければ `DomainError`（`OutsideDomain`）、$1 \le p \le 2n+1$ でなければ `InvalidInput`（`OutOfRange`）である。
$n$ が大きすぎて固有値問題の大きさが桁あふれすると `SizeOverflow`、固有ベクトルや係数が `f64` で求まらないと `NumericalInstability`（`LossOfSignificance`）、作業量の上限を超えると `ConvergenceFailure`（`IterationLimit`）になる。
ワンショット関数は、値がスカラー型の範囲を超えると `NumericalInstability`（`Overflow`）を返す。
詳細な結果では、範囲を超えた値も尺度化形で読める。

## まとめ

楕円体調和関数は Lamé 方程式の多項式型の解 $E_n^p$ と、その積分で作る第 2 種 $F_n^p$ から組み立てる。
$E_n^p$ は有限の三重対角固有値問題から求まり、精度は許容誤差によらず、`spectral_residual` と Clenshaw の和の条件数で状態を確かめられる。
$F_n^p$ と $\gamma_n^p$ は適応求積の値なので、`EllipsoidalOptions` の許容誤差で精度と計算量が変わり、$s$ が $k$ に近いほど計算量が増える。
低い次数では Carlson の対称形と閉形式、どの次数でも Wronskian と $s^{n+1}F_n^p \to 1$ で結果を確かめられる。

2 つの軸が等しい回転楕円体では、Laplace 方程式の分離解は Legendre 関数の積になり、Helmholtz 方程式に進むと回転楕円体波動関数になる。
後者の特性値、角関数、動径関数は[回転楕円体波動関数](../spheroidal-wave-functions/)で確かめる。
第 2 種の検算に使った Carlson の対称形の計アルゴリズムは、[Carlson 対称形と不完全楕円積分](../carlson-symmetric-integrals/)で説明している。
