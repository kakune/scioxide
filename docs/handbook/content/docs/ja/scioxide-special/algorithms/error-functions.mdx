正規分布の確率、熱方程式の基本解、拡散の到達確率は、Gauss 関数 $e^{-t^2}$ の積分である誤差関数で表される。
$x$ が大きいと上側の裾 $\operatorname{erfc}(x)$ は $e^{-x^2}$ のように小さくなり、$1 - \operatorname{erf}(x)$ の引き算では有効数字が残らない。
このページは誤差関数の族（`erf`、`erfc`、`erfcx`、`log_erfc`、`erfi`、`dawson`）と逆誤差関数（`erfinv`、`erfcinv`）の領域ごとの評価法と精度を説明する。
標準正規分布の関数はここで説明する $\operatorname{erfcx}$ の核と逆誤差関数を使い、[正規分布の裾と Owen の T 関数](../normal-tails-and-faddeeva/) で扱う。
複素数を引数にしたときの評価は [Faddeeva 関数と Voigt プロファイル](../faddeeva-and-voigt/) で扱う。
ULP（unit in the last place）は真の値の位置での浮動小数点数の間隔、$\varepsilon = 2^{-52}$ は binary64 の計算機イプシロンである。

## 誤差関数と相補誤差関数

Gauss 積分から生じる誤差関数と相補誤差関数は次の式で定義される（DLMF 7.2.1、7.2.2）。

$$
\operatorname{erf}(z) = \frac{2}{\sqrt{\pi}} \int_0^z e^{-t^2} \, dt, \qquad \operatorname{erfc}(z) = 1 - \operatorname{erf}(z) = \frac{2}{\sqrt{\pi}} \int_z^\infty e^{-t^2} \, dt.
$$

どちらも整関数で、$\operatorname{erf}$ は奇関数、$\operatorname{erfc}(-z) = 2 - \operatorname{erfc}(z)$ である。
標準正規分布の分布関数は $\Phi(x) = \tfrac12 \operatorname{erfc}(-x/\sqrt{2})$ と書ける。
`erf`、`erfc`、`erfcx`、`log_erfc`、`erfi`、`dawson` は実数と複素数（`NumericScalar`）を受け付ける。
複素数は Faddeeva 関数を通して計算し、その方法は [Faddeeva 関数](oxref:special-faddeeva-definition) で説明する。
実数の `erf`、`erfc`、`dawson` は有限の引数に対してエラー条件を持たず、NaN と無限大の引数は `NonFinite` になる。

### 裾で引き算をしない理由

$x = 6$ では $\operatorname{erfc}(6) = 2.15 \times 10^{-17}$ で、$\operatorname{erf}(6) = 1 - 2.15 \times 10^{-17}$ は binary64 で 1 に丸められる。
上側の確率を `1.0 - erf(x)` で作ると 0 になり、$x = 3$ でもすでに上位 11 桁ほどしか正しくない。
1 に近い数の引き算では、引く前の丸め誤差（1 の近くで $\varepsilon/2$）を結果の大きさで割った値が相対誤差になるからである。
`erfc` は裾を 1 からの引き算を経ずに計算する。

### 実数の erf と erfc の評価

実数の `erf` と `erfc` は演算の回数が一定の近似で、binary64 で計算して binary32 には一度だけ丸める。

- $\lvert x \rvert \le 1$ の `erf` は、Cephes 由来の $x^2$ の有理関数 $x\,P(x^2)/Q(x^2)$ で計算する。
- $\lvert x \rvert < 1$ の `erfc` は、$\operatorname{erfc}(\tfrac12 + t)$（$\lvert t \rvert \le \tfrac12$）の 18 次の Chebyshev 補間を直接評価し、$1 - \operatorname{erf}$ の引き算をしない。
- $\lvert x \rvert \ge 1$ では $\operatorname{erfc}(x) = e^{-x^2}\operatorname{erfcx}(x)$ とし、$\operatorname{erf}(x) = 1 - \operatorname{erfc}(x)$ とする。
  $x^2$ の丸め誤差 $e$（$x \cdot x = s + e$ を誤差のない積で分けた下位のワード）を $e^{-s}(1 - e)$ で補正するので、指数の引数の丸めが結果の相対誤差に入らない。
- 負の $x$ では $\operatorname{erfc}(x) = 2 - \operatorname{erfc}(-x)$ を使う。

$\operatorname{erfc}(x)$ は $x \approx 26.54$ を超えると正規化数の範囲を下回って非正規化数になり、相対精度が下がる。
$x \approx 27.23$ を超えると最小の非正規化数の半分より小さくなって 0 に丸められ、$x > 27.3$ では計算せずに 0 を返す。
どちらもエラーにはしない。
その範囲の裾には `erfcx` か `log_erfc` を使う。
実数の `erf` と `erfc` には ULP の数値の目標がなく、定められているのは binary64 で計算して binary32 へ一度だけ丸めることである。
実数の評価は計算量が一定なので、`erf_scoped`、`erfc_scoped` などのスコープ付き API は複素数の引数だけを受け付け、実数を渡すとコンパイルできない。

### 尺度化相補誤差関数と log_erfc

尺度化相補誤差関数は $\operatorname{erfcx}(z) = e^{z^2}\operatorname{erfc}(z) = w(iz)$ で、$w$ は Faddeeva 関数である（DLMF 7.2.3）。
大きな正の $x$ では $\operatorname{erfcx}(x) \approx 1/(x\sqrt{\pi})$ とゆっくり減るので、$\operatorname{erfc}$ がアンダーフローする範囲でも値を持つ。
負の $x$ では $2e^{x^2}$ のように増え、binary64 では $x \approx -26.63$ より小さいとき、binary32 では $x < -9.38$ で `NumericalInstability`（`Overflow`）になる（オプション付き形式は尺度化形と対数形を返す）。

実数の $\operatorname{erfcx}$ は区間ごとに方法を分け、演算の回数は一定である。

- $[-1, 1)$ は幅 $1/16$ の 32 個の区間、$[1, 32)$ は各二進区間（$[2^k, 2^{k+1})$）を 16 個に分けた区間で、それぞれ 9 次の Chebyshev 補間を単項式の形で持つ。
  補間は区間の上で相対 $2^{-56}$ 以内の近似で、中心での値を 2 ワードで持つので、丸めは最後の 1 回だけである。
  二進区間では中心が $x$ と同じ二進区間と上位の仮数ビットを共有するので、差 $t = x - c$ は厳密に計算できる（Sterbenz の補題）。
- $x \ge 32$ では $\operatorname{erfcx}(x) = (1 + u S(u))/(\sqrt{\pi}x)$（$u = x^{-2}$）を補償付きの除算で評価する。
  $S$ は $u \in [0, 1/1024]$ で $(\sqrt{\pi}x\operatorname{erfcx}(x) - 1)/u$ を補間した 5 次の多項式で、$S(0) = -\tfrac12$ は DLMF 7.12.1 の漸近展開 $\operatorname{erfcx}(x) \sim \frac{1}{\sqrt{\pi}x}\sum_{m=0}^{\infty} (-1)^m \frac{(1/2)_m}{x^{2m}}$ の第 2 項の係数に一致する。
- $x < -1$ では $\operatorname{erfcx}(x) = 2e^{x^2} - \operatorname{erfcx}(-x)$ を、$x^2$ を厳密に分けて使う。

`log_erfc` は $\ln\operatorname{erfc}(x)$ を、$x < \tfrac12$ では $\operatorname{ln1p}(-\operatorname{erf}(x))$、それ以外では $\ln\operatorname{erfcx}(x) - x^2$ で計算する。
$\operatorname{erfc}(x)$ がアンダーフローする $x$ でも値を持ち、エラーになるのは $x^2$ があふれる $x > 1.3 \times 10^{154}$ だけである。
複素数では $\operatorname{erfc}(z)$ の主値の対数で、$\operatorname{erfc}(z)$ が負の実軸に乗る所に分枝切断がある。

実数の `erfcx` と `log_erfc` の誤差は、独立に生成した参照値で確かめた範囲で binary64 は 4 ULP、binary32 は 1 ULP の目標に収まる。
オプション付き形式の推定誤差は、`erfcx` が binary64 で 2 単位、`log_erfc` が 4 単位の包絡（値の ULP を単位にした幅）である。

### 虚誤差関数と Dawson 積分

虚誤差関数 $\operatorname{erfi}(z) = -i\operatorname{erf}(iz) = \frac{2}{\sqrt{\pi}}\int_0^z e^{t^2}\,dt$ は奇関数の整関数で、実数の $x$ では $e^{x^2}/(x\sqrt{\pi})$ のように増える。
Dawson 積分 $D(z) = e^{-z^2}\int_0^z e^{t^2}\,dt$（DLMF 7.2.5）は奇関数で、実軸上では $x^* = 0.92414$ で最大値 $0.54104$ をとり、$x \to \infty$ で $1/(2x)$ のように減る。
両者は実軸上で $\operatorname{erfi}(x) = \frac{2}{\sqrt{\pi}}e^{x^2}D(x)$ の関係にある。

実数の `dawson` は $\operatorname{erfcx}$ と同じ形の表を使う。
$\lvert x \rvert < \tfrac12$ では $D = x(1 + vQ(v))$（$v = x^2$、$Q$ は 8 次の多項式）、$[\tfrac12, 8)$ では二進区間を 16 個に分けた 9 次の Chebyshev 補間、$x \ge 8$ では $D = (1 + uT(u))/(2x)$（$u = x^{-2}$、$T$ は 15 次の多項式）を使う。
独立に生成した参照値で確かめた誤差の目標は binary64 で 4 ULP、binary32 で 1 ULP で、オプション付き形式の推定誤差は binary64 で 2 単位である。
オプション付き形式は導関数 $D'(x) = 1 - 2xD(x)$ も返し、漸近域では $D' = -uT(u)$ として打ち消しを避ける。

実数の `erfi` は `dawson` に $2/\sqrt{\pi}$ と $e^{x^2}$ を掛けて作る。
$e^{x^2}$ は別の尺度として保つので、$\lvert x \rvert > 26.7$ で値が binary64 の範囲を超えても、オプション付き形式 `erfi_with_options` は尺度化形（仮数と 2 の指数）と対数形を返す。
標準形式はそこで `NumericalInstability`（`Overflow`）になる。
`erfi` には一様な ULP の目標がなく、オプション付き形式は Dawson の核の誤差、最後の乗算、$x^2$ の丸めを合わせた推定誤差を返す。

### 逆誤差関数

正規分布の分位点や逆変換法による乱数生成では、$y = \operatorname{erf}(x)$ から $x$ を求める逆誤差関数 $x = \operatorname{erfinv}(y)$（$-1 \le y \le 1$）が要る。
$y \to \pm 1$ では $\operatorname{erf}'(x) = \frac{2}{\sqrt{\pi}}e^{-x^2} \to 0$ なので、逆関数は 1 との差 $1 - \lvert y \rvert$ に敏感で、$y$ を binary64 に丸めるだけで $x$ が大きく動く。
相補の確率 $q = 1 - \lvert y \rvert$ が分かっているときは、`erfcinv`（$\operatorname{erfc}(x) = q$ の解）に $q$ を直接渡す。

`erfinv` と `erfcinv` は実数専用（`RealScalar`）で、反復を使わない区分的な有理近似（Boost.Math の逆誤差関数の係数）で計算する。
以下では $p$ を `erfinv` の引数、$q = 1 - \lvert p \rvert$ をその相補とする。

- $\lvert p \rvert \le \tfrac12$ では $p(\lvert p \rvert + 10)(c + R(\lvert p \rvert))$ の形を使う（$R$ は有理関数、$c$ は定数）。
- $q \ge \tfrac14$ では $\sqrt{-2\ln q}/(c + R(q - \tfrac14))$ を使う。
- $q < \tfrac14$ では $t = \sqrt{-\ln q}$ を変数とし、$t < 3$、$t < 6$、$t < 18$、それ以上の 4 区間で別々の $t(c + R(t - t_0))$（$t_0 = 1.125$、3、6、18）を使う。

`erfcinv` は $q = \min(p, 2 - p)$ から $\ln q$ を直接作るので、裾の小さな確率が 1 との引き算で失われず、正の非正規化数の確率も扱える。
端点では `erfinv(±1) = ±∞`、`erfcinv(0) = +∞`、`erfcinv(2) = −∞` を返し、オプション付き形式の終了状態は `Limit` である。
$[-1, 1]$ や $[0, 2]$ の外は `DomainError`（`OutsideDomain`）になる。
どちらの誤差も binary64 で 4 ULP、binary32 で 1 ULP の目標に収まり、`erfcinv` ではこの範囲に非正規化数の $p$ も含まれる。
オプション付き形式の推定誤差も 4 単位（binary32 は 1 単位）である。
計算量は一定なので、スコープ付き API はない。

## 相補誤差関数の裾と漸近展開

次のセルは $x = 1$ から 28 までの 8 点で `erfc`、`1.0 - erf(x)`、`erfcx`、`log_erfc` を求め、`erfcinv` で $x$ に戻す。
独立検算として、DLMF 7.12.1 の漸近展開を $N$ 項で打ち切った和を f64 で足し、`erfcx` との相対差を出す。
漸近展開は発散級数なので、項数を増やしても $x$ が小さいと誤差は減らず、ある項数で最小になる。
操作入力の $N$ を変えると、漸近展開が `erfcx` と一致し始める $x$ が動く。
下の表は Dawson 積分の最大点 $x^* = 0.9241388730045918$ での $D(x^*)$ とオプション付き形式の導関数、binary64 の範囲を超える $\operatorname{erfi}(30)$ の尺度化形と対数形、その対数と漸近形の主項の対数（f64 で計算した参照値）との差である。

```rust
//| id: special-erfc-tail
//| ref: special-erfc-tail
//| title: 相補誤差関数の裾を漸近展開と比べる
//| run: reactive
//| crates: [scioxide-special]
//| inputs:
//|   terms: {"type":"range","label":"漸近展開の項数 N","min":1,"max":12,"step":1,"value":6}
//| cases:
//|   - {"id":"one-term","label":"N = 1","description":"主項 1/(x√π) だけ。相対差は 1/(2x²) の程度で、x = 28 でも 6 × 10⁻⁴ 残る。","inputs":{"terms":1}}
//|   - {"id":"many-terms","label":"N = 12","description":"x ≥ 10 では丸めの程度まで一致するが、x = 1 と 3 では項を増やしても相対差が 10⁻⁴ を下回らない。","inputs":{"terms":12}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"tail","path":"/rows/2/1","approx":{"value":2.1519736712498913e-17,"rtol":1e-14}}
//|       - {"artifact":"tail","path":"/rows/2/2","equals":0}
//|       - {"artifact":"tail","path":"/rows/4/1","approx":{"value":5.395865611607901e-176,"rtol":1e-14}}
//|       - {"artifact":"tail","path":"/rows/4/4","range":{"max":1e-13}}
//|       - {"artifact":"tail","path":"/rows/7/1","equals":0}
//|       - {"artifact":"tail","path":"/rows/7/5","approx":{"value":-787.9052061945577,"rtol":1e-14}}
//|       - {"artifact":"tail","path":"/rows/7/6","equals":null}
//|       - {"artifact":"dawson","path":"/rows/0/1","approx":{"value":0.5410442246351817,"rtol":1e-14}}
//|       - {"artifact":"dawson","path":"/rows/1/1","range":{"min":-1e-15,"max":1e-15}}
//|       - {"artifact":"dawson","path":"/rows/4/1","approx":{"value":896.0269940046969,"rtol":1e-14}}
//|       - {"artifact":"dawson","path":"/rows/5/1","range":{"min":5.55e-4,"max":5.57e-4}}
//|   - case: one-term
//|     expect:
//|       - {"artifact":"tail","path":"/rows/7/4","range":{"min":6e-4,"max":7e-4}}
//|   - case: many-terms
//|     expect:
//|       - {"artifact":"tail","path":"/rows/3/4","range":{"max":1e-15}}
//|       - {"artifact":"tail","path":"/rows/1/4","range":{"min":1e-5}}
use scioxide_special::{
    ErrorFunctionOptions, dawson_with_options, erf, erfc, erfcinv, erfcx, erfi_with_options,
    log_erfc,
};

let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let fixed4 = serde_json::json!({ "fractionDigits": 4 });
let digits10 = serde_json::json!({ "significantDigits": 10 });
let n_terms = terms as u32;
let mut rows = Vec::new();
for x in [1.0, 3.0, 6.0, 10.0, 20.0, 26.0, 27.0, 28.0] {
    let tail = erfc(x).map_err(|e| e.to_string())?;
    let naive = 1.0 - erf(x).map_err(|e| e.to_string())?;
    let scaled = erfcx(x).map_err(|e| e.to_string())?;
    let logarithm = log_erfc(x).map_err(|e| e.to_string())?;
    // 独立検算: erfcx(x) ~ (1/(x√π)) Σ_{m<N} (−1)^m (1/2)_m / x^{2m}（DLMF 7.12.1）を f64 で足す。
    let mut term = 1.0;
    let mut sum = 0.0;
    for m in 0..n_terms {
        sum += term;
        term *= -(f64::from(m) + 0.5) / (x * x);
    }
    let asymptotic = sum / (x * std::f64::consts::PI.sqrt());
    // erfcinv で x に戻す。erfc が 0 に丸められた点では戻せない。
    let back = if tail > 0.0 {
        Some(erfcinv(tail).map_err(|e| e.to_string())? - x)
    } else {
        None
    };
    let difference = (scaled / asymptotic - 1.0).abs();
    rows.push((x, tail, naive, scaled, difference, logarithm, back));
}
let columns = serde_json::json!([
    { "key": "0", "label": "x [-]", "type": "number", "format": fixed4 },
    { "key": "1", "label": "erfc(x) [-]", "type": "number", "format": sci3 },
    { "key": "2", "label": "1 − erf(x) [-]", "type": "number", "format": sci3 },
    { "key": "3", "label": "erfcx(x) [-]", "type": "number", "format": sci3 },
    { "key": "4", "label": "漸近展開との相対差 [-]", "type": "number", "format": sci3 },
    { "key": "5", "label": "log_erfc(x) [-]", "type": "number", "format": fixed4 },
    { "key": "6", "label": "erfcinv で戻した差 [-]", "type": "number", "format": sci3, "nullText": "戻せない" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "tail" })
);
// Dawson 積分の最大点 x* では D′(x*) = 1 − 2x* D(x*) = 0 になる。
let peak = 0.924_138_873_004_591_8;
let dawson =
    dawson_with_options(peak, ErrorFunctionOptions::default()).map_err(|e| e.to_string())?;
let slope = dawson.clone().try_derivative().map_err(|e| e.to_string())?;
let value = dawson.try_value().map_err(|e| e.to_string())?;
// erfi(30) は binary64 の範囲を超えるので、オプション付き形式の尺度化形と対数形を読む。
let erfi =
    erfi_with_options(30.0_f64, ErrorFunctionOptions::default()).map_err(|e| e.to_string())?;
let scaled = erfi.scaled().ok_or("尺度化形がない")?.value().real();
let log = erfi
    .logarithmic()
    .and_then(|l| l.value().log_magnitude())
    .ok_or("対数形がない")?;
let others = vec![
    ("D(x*)", value),
    ("D′(x*)（オプション付き形式の導関数）", slope),
    ("erfi(30) の仮数", scaled.significand()),
    ("erfi(30) の 2 の指数", scaled.exponent() as f64),
    ("ln erfi(30)", log),
    // 参照値（f64 の固有メソッド）: 漸近形の主項 erfi(x) ≈ e^{x²}/(x√π) の対数との差。
    // 次の項から 1/(2x²) = 5.56 × 10⁻⁴ になるはずである。
    (
        "ln erfi(30) − (x² − ln(x√π))",
        log - (900.0 - (30.0 * std::f64::consts::PI.sqrt()).ln()),
    ),
];
let other_columns = serde_json::json!([
    { "key": "0", "label": "量" },
    { "key": "1", "label": "値 [-]", "type": "number", "format": digits10 }
]);
emit_table_with_columns!(
    other_columns,
    others,
    metadata = serde_json::json!({ "id": "dawson" })
);
```

既定の $N = 6$ では、`1.0 - erf(x)` は $x = 3$ で 12 桁目から `erfc` と違い、$x \ge 6$ では 0 になる。
`erfc` は $x = 20$ で $5.40 \times 10^{-176}$、$x = 27$ で非正規化数 $5.2 \times 10^{-319}$ を返し、$x = 28$ では 0 になる。
`erfcx` と `log_erfc` は $x = 28$ でも 0.02014 と $-787.9052$ を返す。
漸近展開との相対差は $x = 1$ で 1.03 と漸近展開が使えず、$x = 6$ で $6.4 \times 10^{-8}$、$x = 20$ で $3.9 \times 10^{-14}$、$x \ge 26$ で $2 \times 10^{-15}$ 以下になる。
$N = 12$ では $x \ge 10$ の相対差が $1.1 \times 10^{-16}$ 以下になるが、$x = 3$ では $1.2 \times 10^{-4}$ にとどまる。
漸近展開の項は $m \approx x^2$ で最小になってから増えるので、$x = 3$ で到達できる誤差は $e^{-x^2} = 1.2 \times 10^{-4}$ の程度である。
`erfcinv` で戻した誤差は $x \le 26$ で 0 か $8.9 \times 10^{-16}$（1 ULP）で、非正規化数の $\operatorname{erfc}(27)$ からは有効数字が減って $8.8 \times 10^{-9}$ になる。

下の表では、$D(x^*) = 0.5410442246$ とオプション付き形式の導関数 $D'(x^*) = 0$ が最大点の性質に合う。
$\operatorname{erfi}(30)$ の尺度化形は $1.6174271718 \times 2^{1292} \approx 1.4 \times 10^{389}$、対数形は $896.0269940$ である。
漸近形の主項の対数 $900 - \ln(30\sqrt{\pi}) = 896.0264377$ との差 $5.56 \times 10^{-4}$ は、漸近展開 $\operatorname{erfi}(x) \sim \frac{e^{x^2}}{x\sqrt{\pi}}\bigl(1 + \frac{1}{2x^2} + \cdots\bigr)$ の次の項 $1/(2x^2) = 5.56 \times 10^{-4}$ に合う。

## API

この族の関数は次のとおりである。
「複素数」の列は `NumericScalar` を受け付けて複素数の引数も計算できるかを示す。
オプション付き形式は `SpecialFunctionResult` を返し、推定誤差、終了状態、計算量の計数、アルゴリズムの識別子を持つ。
スコープ付き API `*_scoped(.., options, scope)` は複素数の引数だけを受け付ける。

| 標準形式 | 計算するもの | 複素数 | オプション付き形式 | スコープ付き API |
|---|---|---|---|---|
| `erf` | $\operatorname{erf}(z)$ | 対応 | `erf_with_options` | `erf_scoped`（複素数のみ） |
| `erfc` | $\operatorname{erfc}(z)$ | 対応 | `erfc_with_options` | `erfc_scoped`（複素数のみ） |
| `erfcx` | $e^{z^2}\operatorname{erfc}(z)$ | 対応 | `erfcx_with_options` | `erfcx_scoped`（複素数のみ） |
| `log_erfc` | $\ln\operatorname{erfc}(z)$ | 対応 | `log_erfc_with_options` | `log_erfc_scoped`（複素数のみ） |
| `erfi` | $-i\operatorname{erf}(iz)$ | 対応 | `erfi_with_options` | `erfi_scoped`（複素数のみ） |
| `dawson` | $D(z)$ | 対応 | `dawson_with_options` | `dawson_scoped`（複素数のみ） |
| `erfinv` | $\operatorname{erf}(x) = p$ の $x$ | 実数のみ | `erfinv_with_options` | なし |
| `erfcinv` | $\operatorname{erfc}(x) = p$ の $x$ | 実数のみ | `erfcinv_with_options` | なし |

オプションはどれも `ErrorFunctionOptions` で、作業量の上限（`Budget`、既定 65536）だけを持つ。
実数の評価は 1 単位の処理で終わるので、上限が効くのは複素数の評価だけである。

## まとめ

誤差関数の裾は `erfc` が $e^{-x^2}\operatorname{erfcx}(x)$ として直接評価するので、`1.0 - erf(x)` の引き算は使わない。
$x > 26.54$ で $\operatorname{erfc}$ が非正規化数になり、$x > 27.23$ で 0 になる範囲は、`erfcx` か `log_erfc` で扱う。
`erfcx` と Dawson 積分は区間ごとの補間と漸近形の表で一定の演算回数で評価され、4 ULP の目標に収まる。
`erfi` は binary64 の範囲を超えても、オプション付き形式の尺度化形と対数形で値を読める。
逆誤差関数は反復のない有理近似で、裾の確率は `erfcinv` に相補の確率のまま渡す。
