指数積分と対数積分は、$e^{-t}/t$ や $1/\ln t$ のような初等関数の積分で定義される関数である。
放射輸送と中性子の遮蔽計算に $E_n$ が、井戸の揚水試験の Theis の解に $E_1$ が、素数の個数を近似する式に $\operatorname{li}$ が現れる。
$E_1(x)$ は上側不完全ガンマ関数の $a = 0$ の値 $\Gamma(0, x)$ でもある。
原点の対数特異性、大きな引数での指数的な増減、実数の零点の近くの打ち消しがあるので、`scioxide-special` は区間ごとに有理近似、級数、連分数、Chebyshev 展開を使い分け、指数因子を外した値で計算する。
このページは定義と性質、区間の分け方と評価法、精度の保証、API の使い分けを説明し、セルで $\operatorname{Ei}$ の零点の近くの相対精度を確かめる。
正弦・余弦積分、双曲線積分、Fresnel 積分は [三角積分・双曲線積分・Fresnel 積分](../trigonometric-integrals-and-fresnel/) で扱う。

## 定義と性質

### 指数積分

整数 $n \ge 0$ と $x > 0$ に対し、一般化指数積分を次の式で定義する（DLMF §8.19）。

$$
E_n(x) = \int_1^\infty \frac{e^{-xt}}{t^n}\,dt, \qquad E_1(x) = \int_x^\infty \frac{e^{-t}}{t}\,dt
$$

$E_0(x) = e^{-x}/x$ であり、$n \ge 2$ では $E_n(0) = 1/(n-1)$ が有限になる。
$E_1$ は原点に対数特異性 $E_1(x) = -\gamma - \ln x + x - x^2/4 + \cdots$ を持つ（$\gamma = 0.57721\ldots$ は Euler の定数）。
部分積分から漸化式 $n E_{n+1}(x) = e^{-x} - x E_n(x)$ が成り立つ。
$x \to \infty$ では $E_n(x)$ は $e^{-x}$ とともに減り、尺度化した値 $e^{x} E_n(x)$ は $1/(x+n)$ と $1/(x+n-1)$ の間にある（DLMF §8.19）。

指数積分 $\operatorname{Ei}$ は次の Cauchy の主値で定義する（DLMF §6.2）。

$$
\operatorname{Ei}(x) = \mathrm{PV}\!\int_{-\infty}^{x} \frac{e^{t}}{t}\,dt = \gamma + \ln|x| + \sum_{k=1}^{\infty} \frac{x^k}{k\,k!}
$$

$x < 0$ では $\operatorname{Ei}(x) = -E_1(-x)$ である。
$\operatorname{Ei}$ は $x \to \infty$ で $e^{x}/x$ のように増え、正の実軸にただ一つの零点 $x_0 = 0.37250\,74107\,81366\,63446\ldots$ を持つ（DLMF §6.13）。

`expint_e1(x)` と `expint_en(1, x)` は $x < 0$ で複素数ではなく実数の主値 $-\operatorname{Ei}(-x)$ を返す。
これは切断の両側の $E_1$ の実部である。
$n \ne 1$ の $E_n$ は $x < 0$ を受け付けない。

### 対数積分 li と Li

対数積分は $\operatorname{li}(x) = \mathrm{PV}\!\int_0^x dt/\ln t = \operatorname{Ei}(\ln x)$（$x \ge 0$）である（DLMF §6.2）。
$\operatorname{li}(0) = 0$ で、$x = 1$ に対数特異性を持ち、ただ一つの零点は $\mu = e^{x_0} = 1.45136\,92348\ldots$（Soldner の定数）である。
オフセット対数積分 $\operatorname{Li}(x) = \operatorname{li}(x) - \operatorname{li}(2)$ は、$x$ 以下の素数の個数 $\pi(x)$ を近似するのに使う。
$\operatorname{li}(2) = 1.04516\,37801\,17492\ldots$ であり、$\operatorname{Li}(2) = 0$ になる。

### 三次の指数積分

`expint_3(x)` は三次の指数積分 $\int_0^x e^{-t^3}\,dt = \gamma(1/3, x^3)/3$（$x \ge 0$）である。
$\gamma(a, z)$ は下側不完全ガンマ関数で、$x \to \infty$ で値は $\Gamma(4/3) = 0.89297\,95115\ldots$ に近づく。
名前は似ているが、$E_3(x)$（`expint_en(3, x)`）とは別の関数である。

## 区間の分割と評価法

一つの方法で全域を扱わないのは、それぞれの方法に得意な区間があるからである。
原点のまわりの級数は小さな $x$ で速く収束するが、$x$ が大きいと途中の項が $e^{x}$ 程度まで大きくなってから打ち消し合い、丸め誤差が残る。
連分数や漸近展開は大きな $x$ で少ない項数で済むが、小さな $x$ では収束が遅いか、精度が出ない。
その間の区間には、あらかじめ最大相対誤差を小さくするように係数を決めた固定次数の有理近似 $P(t)/Q(t)$ か、Chebyshev 展開 $\sum_k c_k T_k(t)$ を使う。
Chebyshev 展開は区間を $t \in [-1, 1]$ に写して Clenshaw の漸化式で和を取る方法で、計算コストは係数の数に比例し、入力によらない。

指数的に増減する関数では、指数因子を外した尺度化した値を計算し、最後に一度だけ指数因子を掛ける。
こうすると途中でアンダーフローやオーバーフローが起きず、通常の値が表せない範囲でも、オプション付き形式の `scaled()`（仮数と 2 の冪に分けた値）と対数形 `logarithmic()` に値が残る。

### E1 と Ei の評価

$x > 0$ の $E_1$ には Boost.Math の binary64 用の有理近似を使う（Maddock ほか）。
$x \le 1$ では $E_1(x) = -\ln x + x - c + R(x)$（$c$ は定数、$R$ は有理関数）の形で、対数特異性 $-\ln x$ を有理近似の外に出す。
$x > 1$ では尺度化した値を $e^{x}E_1(x) = (1 + R(1/x))/x$ の形で近似する。

$\operatorname{Ei}$ は区間 $(0, 6]$、$(6, 10]$、$(10, 20]$、$(20, 40]$、$(40, \infty)$ ごとの有理近似で、$x < 0$ は $-E_1(-x)$ に回す。
$(0, 6]$ では零点 $x_0$ を2 ワード（二つの binary64 の和で約 106 ビット）で持ち、次の形で評価する。

$$
\operatorname{Ei}(x) = \ln\frac{x}{x_0} + (x - x_0)\,R\!\left(\frac{x}{3} - 1\right)
$$

$x - x_0$ を2 ワードで引き、$|x - x_0| < 0.1$ では $\ln(x/x_0)$ を $\ln(1 + (x - x_0)/x_0)$ として `ln_1p` で求めるので、零点の近くでも打ち消しが起きず、相対誤差が小さく保たれる。
$x > 1$ の区間は尺度化した値 $e^{-x}\operatorname{Ei}(x)$ を返し、指数因子は最後に掛ける。
$\operatorname{Ei}$ の値は $x \approx 716$ を超えると binary64 の範囲を超えるので、標準形式は `NumericalInstability`（`Overflow`）を返し、オプション付き形式は `scaled()` と `logarithmic()` に値を残す。

### 次数 2 以上の En の評価

$n \ge 2$ の `expint_en` は $n$ と $x$ で次のように方法を切り替え、どれも尺度化した値 $e^{x}E_n(x)$ を作る。

| 条件 | 方法 |
|---|---|
| $x = 0$ | $1/(n-1)$ |
| $x \le 1$ | 級数（DLMF 8.19.8）を項は binary64、和は2 ワードで足す |
| $1 < x \le 2$、$n \le 32$ | $E_1$ から漸化式 $E_{m+1} = (e^{-x} - xE_m)/m$ を上向きに進める |
| $2 < x \le 8$、$n \le 32$ | 級数（DLMF 8.19.8）を2 ワードの算術で足す |
| それ以外 | 連分数（DLMF 8.19.17）の収束子を三項漸化式で求める |

級数は $E_n(x) = \frac{(-x)^{n-1}}{(n-1)!}(\psi(n) - \ln x) - \sum_{k \ne n-1} \frac{(-x)^k}{k!(1 - n + k)}$ で、$\psi(n) = 1 + 1/2 + \cdots + 1/(n-1) - \gamma$ はディガンマ関数である。
交代級数なので、項の絶対値の和がおよそ $e^{x}/x$ まで育つのに、和 $E_n(x)$ は $e^{-x}/(x+n)$ 程度しかなく、打ち消しで失う桁はおよそ $2x\log_{10}e$ 桁になる。
$x \le 8$ なら失うのは 7 桁ほどで、2 ワードの算術（約 32 桁）がそれを吸収する。
上向きの漸化式は、1 段ごとに絶対誤差が $x/m$ 倍になるので、$x \le 2$ では最初の段で高々 2 倍、$m \ge 2$ の段では増えない。
連分数 $e^{x}E_n(x) = \cfrac{1}{x + \cfrac{n}{1 + \cfrac{1}{x + \cfrac{n+1}{1 + \cdots}}}}$ は部分分子と部分分母がすべて正なので、収束子の分子と分母を三項漸化式で求めても引き算が起きない。
分母が $2^{500}$ を超えたら 4 つの状態を $2^{-512}$ で尺度化し、隣り合う収束子の差が相対 $\varepsilon/2$ 以下になったら止める（$\varepsilon = 2^{-52}$ は binary64 の機械イプシロン）。
最初の収束子 $1/(x+n)$ の相対補正は $n/(x+n)^2$ 以下なので、これが $\varepsilon$ を下回る大きな $x$ では反復せずに $1/(x+n)$ を返す。

### 三次の指数積分と対数積分

`expint_3` は $[0, 1]$、$[1, 2]$、$[2, 3]$、$[3, 4]$ の Chebyshev 展開に $x$ を掛けた形を使い、$x > 4$ では丸めた極限 $\Gamma(4/3)$ を返して、省いた裾の上界 $e^{-x^3}/(3x^2)$ を推定誤差に含める。
`logarithmic_integral` は $\operatorname{Ei}$ の核に $\ln x$ を渡し、$|x - 1| < 1/2$ では $\ln x$ を `ln_1p(x - 1)` で作る。
$x = 1$ の対数特異性の近くで $\ln x$ が相対誤差を保つので、$\operatorname{Ei}$ の小さな引数の核がそのまま使える。
`logarithmic_integral_offset` は、$[1.5, 2.5]$ で $x = 2$ のまわりの Chebyshev 展開 $\operatorname{Li}(x) = (x - 2)\,T(x)$ を使い、$\operatorname{li}(x) - \operatorname{li}(2)$ の打ち消しを避ける。
それ以外の $x$ では $\operatorname{li}(x)$ から $\operatorname{li}(2)$ を引く。

### 作業量の上限と計算コスト

`IntegralOptions` は作業量の上限だけを持ち、既定は 512 単位である。
三角積分、双曲線積分、Fresnel 積分も同じ `IntegralOptions` を使う。
有理近似と Chebyshev 展開は係数 1 個につき 1 単位、級数と連分数は 1 項につき 1 単位を使う。
評価は数十から百単位ほどで終わり、多いのは $E_n$ の級数や連分数の項数が増える場合（$n = 3$、$x = 7.9$ で 103 単位）である。
上限に達すると、オプション付き形式は終了状態 `IterationLimit` と打ち切った時点の値を返し、そのときの推定誤差はモデルの上限まで大きく示される。
標準形式は上限に達すると `ConvergenceFailure` を返す。

## 精度の保証と推定誤差

独立に生成した高精度の参照値（160 桁と 240 桁の照合データ）で確かめた精度の目標は、次のとおりである。

| 関数 | binary64 の目標 | 補足 |
|---|---|---|
| `expint_e1`、`expint_e2`、`expint_en`、`expint_ei`、`expint_3` | 8 ULP | 零点の近くでは絶対誤差で評価する |
| `expint_e1_scaled`、`expint_e2_scaled`、`expint_en_scaled`、`expint_ei_scaled` | 独立の目標なし | 照合試験では `expint_ei_scaled` と `expint_en_scaled` も 8 ULP 以内を確かめている |
| `logarithmic_integral`、`logarithmic_integral_offset` | 一様な目標なし | binary32 と binary64 で値と推定誤差を試験する |

ULP（unit in the last place）は、結果の型で隣り合う浮動小数点数の間隔を単位にした誤差である。
8 ULP の目標は binary64 についてのもので、binary32 には ULP の目標を定めていない。
零点の近くでは関数値が 0 に近づくので相対誤差は意味を失い、仕様は絶対誤差の上界になる。
$\operatorname{Ei}$ の零点 $x_0$ の近くは零点を明示的に引くので、下のセルで確かめるとおり相対誤差も小さい。
一様な目標のない関数について、照合試験は binary64 で相対 $5 \times 10^{-11}$（値が小さいときは絶対 $5 \times 10^{-13}$）、binary32 で相対 $2 \times 10^{-4}$（絶対 $5 \times 10^{-6}$）以内であることと、実際の誤差が推定誤差の範囲に入ることを確かめている。

オプション付き形式の推定誤差は区間ごとの誤差モデルから作る。
$E_1$、$E_n$、$\operatorname{Ei}$ の核では、照合データで包含を確かめた推定（`EstimateReliability::StatisticallyCalibrated`）として、核の誤差に相対 $2\varepsilon$ を加える。
それ以外の関数と上限で止まった評価は、誤差モデルによる推定（`ModelBased`）で、相対 $32\varepsilon$ を加える。
どちらも包含が保証された区間ではない。

## API

|---|---|---|---|---|
| `expint_e1` | $E_1(x)$、$x < 0$ では $-\operatorname{Ei}(-x)$ | $x = 0$ は `Pole` | `expint_e1_with_options` | なし |
| `expint_e1_scaled` | $e^{x}E_1(x)$ | $x = 0$ は `Pole` | `expint_e1_scaled_with_options` | なし |
| `expint_e2` | $E_2(x)$ | $x < 0$ は `OutsideDomain` | `expint_e2_with_options` | `expint_e2_scoped` |
| `expint_e2_scaled` | $e^{x}E_2(x)$ | $x < 0$ は `OutsideDomain` | `expint_e2_scaled_with_options` | `expint_e2_scaled_scoped` |
| `expint_en` | $E_n(x)$、`n: u32` | $x = 0$ かつ $n \le 1$ は `Pole`、$x < 0$ かつ $n \ne 1$ は `OutsideDomain` | `expint_en_with_options` | `expint_en_scoped` |
| `expint_en_scaled` | $e^{x}E_n(x)$ | `expint_en` と同じ | `expint_en_scaled_with_options` | `expint_en_scaled_scoped` |
| `expint_ei` | $\operatorname{Ei}(x)$ | $x = 0$ は `Pole` | `expint_ei_with_options` | なし |
| `expint_ei_scaled` | $e^{-x}\operatorname{Ei}(x)$ | $x = 0$ は `Pole` | `expint_ei_scaled_with_options` | なし |
| `expint_3` | $\int_0^x e^{-t^3}dt$ | $x < 0$ は `OutsideDomain` | `expint_3_with_options` | なし |
| `logarithmic_integral` | $\operatorname{li}(x)$ | $x = 1$ は `Pole`、$x < 0$ は `OutsideDomain` | `logarithmic_integral_with_options` | なし |
| `logarithmic_integral_offset` | $\operatorname{Li}(x) = \operatorname{li}(x) - \operatorname{li}(2)$ | `logarithmic_integral` と同じ | `logarithmic_integral_offset_with_options` | なし |

エラーは `SciOxideError` で返り、`kind()` が `DomainError` のとき `view()` の詳細が `Pole` か `OutsideDomain` になる。
入力が有限でなければ `NonFinite`、通常の値が型の範囲を超えれば `NumericalInstability`（`Overflow`）である。
どの関数も実数（`RealScalar`）だけを受け付け、複素数の指数積分は提供しない。
複素数の $E_1(z)$ が必要なら、`gamma_upper` の複素数の形で $\Gamma(0, z)$ を求める。

標準形式 `f(x)` は値だけを返す。
オプション付き形式 `f_with_options(x, options)` は `IntegralOptions` を受け取り、`SpecialFunctionResult` に通常の値 `value()`、2 の冪で表した値 `scaled()`、対数形 `logarithmic()`、$x$ についての導関数 `derivative()` をそれぞれの推定誤差とともに入れ、終了状態、計算量の計数、アルゴリズムの識別子を添える。
オプション付き形式の通常の値は標準形式の値とビット単位で等しい。
スコープ付き API `f_scoped(x, options, scope)` はオプション付き形式と同じ結果を計算し、そのとき呼び出し元の `SolveScope` の中で計算量を数え、取り消しと期限を確かめる。
スコープ付き API のない関数（表で「なし」）は、オプション付き形式を使う。

尺度化形は、値そのものが範囲の外に出る場面で使う。
光学的厚さ $\tau$ が数百を超える放射輸送では $E_n(\tau)$ が binary64 で 0 になるが、`expint_en_scaled(n, tau)` は $1/(\tau + n)$ 程度の値を返すので、指数因子 $e^{-\tau}$ を別に持って対数で組み合わせられる。
$\operatorname{Ei}$ の大きな引数では逆にオーバーフローが起きるので、`expint_ei_scaled` を使う。
名前付きの尺度化形（`_scaled`）は指数因子を外した別の関数で、オプション付き形式の `scaled()`（同じ値を 2 の冪で表し直したもの）とは違う。

## Ei の零点の近くの相対精度

次のセルは $\operatorname{Ei}$ の零点 $x_0$ から $\delta$ だけずれた点 $x = x_0 + \delta$ で、`expint_ei` の相対誤差を確かめる。
参照値は $x_0$ のまわりの Taylor 級数 $\operatorname{Ei}(x_0 + d) = e^{x_0}\int_0^d e^{u}/(x_0 + u)\,du$ を f64 の標準関数で足した値である。
$x_0$ は文献の桁から上位と下位の二つの f64 に分けて持ち、$d$ は真の零点からのずれを表す。
比べるために、定義の級数 $\gamma + \ln x + \sum x^k/(k\,k!)$ を f64 でそのまま足した値の相対誤差と、`logarithmic_integral(exp(x))` と $\operatorname{Ei}(x)$ の相対差を並べる。
入力で $\delta$ の符号と、最小の $|\delta|$ を選ぶ。

```rust

//| ref: special-expint-ei-li-identity
//| title: Ei の零点の近くの相対誤差と li(eˣ) = Ei(x)
//| run: reactive
//| crates: [scioxide-special, scioxide-core]
//| inputs:
//|   side: {"type":"select","label":"零点からのずれの向き","options":[{"label":"x₀ より大きい側（δ > 0）","value":"plus"},{"label":"x₀ より小さい側（δ < 0）","value":"minus"}],"value":"plus"}
//|   smallest_exponent: {"type":"range","label":"最小の |δ| の指数 p（|δ| = 10^p）","description":"零点にどこまで近づけるかを決める。","min":-15,"max":-4,"step":1,"value":-12}
//| cases:
//|   - {"id":"below-root","label":"δ < 0、|δ| ≥ 10⁻¹⁵","description":"零点の左側では Ei が負になり、|δ| = 10⁻¹⁵ まで近づける。","inputs":{"side":"minus","smallest_exponent":-15}}
//| tests:
//|   - case: default

//|       - {"artifact":"ei-zero","path":"/rows/11/2","range":{"max":1e-15}}
//|       - {"artifact":"ei-zero","path":"/rows/11/4","range":{"min":1e-6}}
//|   - case: below-root

//|       - {"artifact":"ei-zero","path":"/rows/14/1","range":{"max":0}}

use scioxide_special::{expint_ei, expint_ei_with_options, logarithmic_integral};

// Ei の零点 x₀ = 0.37250 74107 81366 63446 19918 66580…（DLMF §6.13）。
// root_hi は x₀ に最も近い f64、root_lo = x₀ − root_hi は文献の桁から求めた残り。
let root_hi = 0.372_507_410_781_366_63_f64;
let root_lo = 1.314_018_341_438_602_8e-17;
let euler_gamma = 0.577_215_664_901_532_9_f64;
let sign = if side == "minus" { -1.0 } else { 1.0 };
let decades = (-smallest_exponent).round() as i32;

// 参照値（f64 の標準関数）: e^u/(x₀ + u) = Σₘ cₘ uᵐ を項ごとに積分する。
// cₘ = Σ_{i+j=m} (1/i!)(−1)ʲ/x₀^(j+1)。収束半径は特異点 0 までの距離 x₀ で、|d| ≤ 0.1 なら 60 項で足りる。
let reference = |d: f64| {
    let mut total = 0.0;
    let mut power = d;
    for m in 0..60 {
        let mut coefficient = 0.0;
        let mut inverse_factorial = 1.0;
        for i in 0..=m {
            let j = (m - i) as i32;
            coefficient += inverse_factorial * (-1.0_f64).powi(j) / root_hi.powi(j + 1);
            inverse_factorial /= (i + 1) as f64;
        }
        total += coefficient * power / (m + 1) as f64;
        power *= d;
    }
    root_hi.exp() * total
};
// 比較用: 定義の級数 γ + ln x + Σ xᵏ/(k·k!) を f64 でそのまま足す（f64 の標準関数）。
let naive = |x: f64| {
    let mut sum = euler_gamma + x.ln();
    let mut term = 1.0;
    for k in 1..60 {
        term *= x / k as f64;
        sum += term / k as f64;
    }
    sum
};

let mut rows = Vec::new();
for k in 1..=decades {
    let x = root_hi + sign * 10.0_f64.powi(-k);
    // x − root_hi は Sterbenz の補題で正確。真の零点からのずれ d はそこから root_lo を引く。
    let d = (x - root_hi) - root_lo;
    let exact = reference(d);
    let value = expint_ei(x).map_err(|e| e.to_string())?;
    let detailed = expint_ei_with_options(x, Default::default()).map_err(|e| e.to_string())?;
    let estimate = detailed.value().and_then(|v| v.relative_error());
    let li = logarithmic_integral(RealScalar::exp(x)).map_err(|e| e.to_string())?;
    rows.push((
        x - root_hi,
        value,
        ((value - exact) / exact).abs(),
        estimate,
        ((naive(x) - exact) / exact).abs(),
        ((li - value) / value).abs(),
    ));
}

let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let sig6 = serde_json::json!({ "notation": "scientific", "significantDigits": 6 });
let columns = serde_json::json!([
    { "key": "0", "label": "δ = x − x₀ [-]", "type": "number", "format": sci3 },
    { "key": "1", "label": "Ei(x) [-]", "type": "number", "format": sig6 },
    { "key": "2", "label": "Ei の相対誤差 [-]", "type": "number", "format": sci3 },
    { "key": "3", "label": "推定した相対誤差 [-]", "type": "number", "format": sci3, "nullText": "なし" },
    { "key": "4", "label": "素朴な級数の相対誤差 [-]", "type": "number", "format": sci3 },
    { "key": "5", "label": "li(eˣ) と Ei(x) の相対差 [-]", "type": "number", "format": sci3 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "ei-zero" })
);
```

既定の入力では、`expint_ei` の相対誤差は $|\delta| = 10^{-12}$ まで全行で $5 \times 10^{-16}$ 以下で、$\operatorname{Ei}(x_0 + 10^{-12}) = 3.896 \times 10^{-12}$ も相対誤差 $2 \times 10^{-16}$ で求まる。
推定した相対誤差は全行で $8\varepsilon = 1.78 \times 10^{-15}$ で、零点に近づいても増えない。
この区間の誤差モデルは関数値に比例する形（核の $6\varepsilon|\operatorname{Ei}(x)|$ に較正の $2\varepsilon$ を加えた値）で、零点を2 ワードで引いて対数を `ln_1p` で作るので、実際の誤差もこの形に収まる。
素朴な級数の相対誤差は $|\delta|$ に反比例して増え、$|\delta| = 10^{-12}$ で $3.2 \times 10^{-6}$ になる。
$\gamma + \ln x$ と級数の和はどちらも絶対値が約 0.41 で、その差を取るときの丸め $10^{-17}$ 程度が、$3.9|\delta|$ しかない値に対する相対誤差になるからである。

最後の列は、恒等式 $\operatorname{li}(e^{x}) = \operatorname{Ei}(x)$ がこの領域では相対誤差として成り立たないことを示す。
$e^{x}$ を binary64 に丸めると、$\ln$ を取り直した引数が絶対値で $\varepsilon$ 程度ずれ、値は $\operatorname{Ei}'(x_0) = e^{x_0}/x_0$ を掛けた分だけ動くので、相対差は $\varepsilon/|\delta|$ 程度になる。
0 の行は、$e^{x}$ の丸めがたまたま $\ln$ で元の $x$ に戻った場合である。
これは `logarithmic_integral` の誤りではない。
$\operatorname{li}$ の零点 $\mu$ の近くでは、入力 $x$ の丸めだけで相対誤差がこの大きさになる（条件数が大きい）。
$\delta < 0$ の側（`below-root`）では値が負になり、$|\delta| = 10^{-15}$ でも `expint_ei` の相対誤差は $2 \times 10^{-16}$ にとどまる一方、素朴な級数は 1.6% ずれる。

## まとめ

$E_1$、$E_n$、$\operatorname{Ei}$、`expint_3` は binary64 で 8 ULP を目標にし、零点の近くは絶対誤差で評価するが、$\operatorname{Ei}$ の零点の近くは零点を明示的に引くので相対誤差も小さい。
$\operatorname{li}$ と $\operatorname{Li}$ には一様な ULP の目標がないので、精度が必要ならオプション付き形式の推定誤差を読む。
値が binary64 の範囲の外に出る大きな引数では、`expint_en_scaled`、`expint_ei_scaled` か、オプション付き形式の `scaled()` と `logarithmic()` を使う。
`expint_3` は $\int_0^x e^{-t^3}dt$ であり、$E_3$ が必要なら `expint_en(3, x)` を呼ぶ。
同じ $\operatorname{Ei}$ の核を使う $\operatorname{li}$ の零点の近くでは、入力の丸めだけで相対誤差が $\varepsilon/|\delta|$ 程度になることを、セルの最後の列で確かめた。

同じ有理近似と Chebyshev 展開の考え方を振動する積分に使う Si、Ci、Fresnel 積分と、$\operatorname{Ei}$ と $E_1$ を組み合わせる双曲線積分は [三角積分・双曲線積分・Fresnel 積分](../trigonometric-integrals-and-fresnel/) で確かめる。
$E_1 = \Gamma(0, x)$ を含む不完全ガンマ関数の評価は [不完全 Gamma 関数](../incomplete-gamma/) で、級数、変換、接続公式で領域を分ける合流型と Gauss の超幾何関数は [超幾何関数](../hypergeometric-and-zeta/) で確かめる。
