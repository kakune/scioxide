複素数を引数とする誤差関数と、分光学の吸収線の形を表す Voigt プロファイルは、どちらも Faddeeva 関数 $w(z)$ で計算する。
実数の誤差関数の族は [誤差関数・Dawson 積分・逆誤差関数](../error-functions/) で説明した区間ごとの表で評価する。
複素平面では $e^{-z^2}$ が方向によって増えも減りもするので、領域を分けた別の方法が要る。
このページは `faddeeva` の評価領域と方法、下半平面への反射とあふれの扱い、Voigt プロファイル `voigt_profile` と `voigt_complex` を説明する。
$\varepsilon = 2^{-52}$ は binary64 の計算機イプシロンで、「$n$ 単位」の推定誤差は値の大きさの $n\varepsilon$ 倍の幅を表す。

## Faddeeva 関数

Faddeeva 関数（複素誤差関数）は次の式で定義される整関数である（DLMF 7.2.3）。

$$
w(z) = e^{-z^2}\operatorname{erfc}(-iz) = e^{-z^2}\left(1 + \frac{2i}{\sqrt{\pi}}\int_0^z e^{t^2}\,dt\right).
$$

虚軸上では $w(iy) = \operatorname{erfcx}(y)$、実軸上では $\operatorname{Re} w(x) = e^{-x^2}$、$\operatorname{Im} w(x) = \frac{2}{\sqrt{\pi}}D(x)$（$D$ は Dawson 積分）である。
$\operatorname{erfc}(\zeta) = e^{-\zeta^2}w(i\zeta)$ なので、複素数の `erf`、`erfc`、`erfcx`、`erfi`、`dawson`、`log_erfc` はどれも $w$ を通して計算する。
`faddeeva` は複素数（`Complex<S>`）だけを受け付け、上半平面では値は有界で、$\lvert z \rvert \to \infty$ で $w(z) \approx i/(\sqrt{\pi}z)$ になる。

上半平面 $\operatorname{Im} z \ge 0$ の評価は、$z = x + iy$ の位置で方法を分ける（この節では $x$ を $\lvert \operatorname{Re} z \rvert$ の意味で使う）。

- 虚軸（$x = 0$）と実軸（$y = 0$）では、実数の $\operatorname{erfcx}$ と Dawson 積分の核を使う。
- $\lvert z \rvert$ が大きい所、つまり $y > 7$ の所と、$x > 6$ かつ $y > 0.1$ の所（$x > 8$ では $y > 10^{-10}$、$x > 28$ では $y > 0$ の全体）では、Laplace の連分数 $w(z) = \dfrac{i/\sqrt{\pi}}{z - \dfrac{1/2}{z - \dfrac{1}{z - \dfrac{3/2}{z - \cdots}}}}$ を、深さ $\lfloor 3.9 + 11.398/(0.08254x + 0.1421y + 0.2023)\rfloor$ で打ち切って後ろから評価する。
  $\max(x, y) > 10^7$ では第 1 項 $i/(\sqrt{\pi}z)$ を使う。
- それ以外では、Zaghloul と Ali（2011）の Algorithm 916 の級数を使う。
  刻み $a = 0.5183$ の Gauss 関数の和で、項の Gauss 因子を 1 つの指数関数と減衰因子の累乗で作り、項が和の $\varepsilon$ 倍以下になったら止める。
  主項 $e^{-x^2}\operatorname{erfcx}(y)$ には実数の核を使い、$x < 5 \times 10^{-4}$ では差の項を $\sinh$ で作って打ち消しを避ける。

下半平面では反射 $w(z) = 2e^{-z^2} - w(-z)$（DLMF §7.4）を使う。
$\lvert \operatorname{Im} z \rvert > \lvert \operatorname{Re} z \rvert$ の所では $e^{-z^2}$ が際限なく大きくなり、値が型の範囲を超えると標準形式は `NumericalInstability`（`Overflow`）を返し、オプション付き形式 `faddeeva_with_options` は対数形を返す。
$\operatorname{Re} z \cdot \operatorname{Im} z$ があふれて $e^{-z^2}$ の位相を作れないときは `NumericalInstability`（`LossOfSignificance`）になる。
級数と連分数の項は作業量の上限に数えられ、スコープ付き API `faddeeva_scoped` を持つ。
一様な ULP の目標はなく、オプション付き形式は値に 64 単位、導関数 $w'(z) = 2i/\sqrt{\pi} - 2zw(z)$ に 128 単位の推定誤差を返す。

## Voigt プロファイル

分光学の吸収線は、原子の熱運動による Doppler 広がり（標準偏差 $\sigma$ の正規分布）と、自然放出や衝突による広がり（半値半幅 $\gamma$ の Lorentz 分布）の畳み込みになる。
この畳み込みを Voigt プロファイルといい、Faddeeva 関数で次のように書ける。

$$
V(x; \sigma, \gamma) = \frac{w(z)}{\sigma\sqrt{2\pi}}, \qquad z = \frac{x + i\gamma}{\sigma\sqrt{2}}.
$$

$\operatorname{Re} V$ が Voigt プロファイルで、$x$ について積分すると 1 になる。
$\operatorname{Im} V$ は分散線形（屈折率の変化を表す形）である。
`voigt_profile` は実部だけを、`voigt_complex` は複素数の $V$ を返す。
$\sigma = 0$ では Lorentz 線形 $(\gamma + ix)/(\pi(x^2 + \gamma^2))$ になり、$\gamma = 0$ では実部が正規分布の密度になる。
$\sigma < \tfrac12\sqrt{\varepsilon}\max(\lvert x \rvert, \gamma)$ では Gauss の幅が結果の分解能より小さいので、Lorentz の極限の式を使う。
$\sigma < 0$、$\gamma < 0$、$\sigma = \gamma = 0$ は `DomainError`（`OutsideDomain`）である。
どちらも上半平面の Faddeeva 関数の評価を使い、スコープ付き API `voigt_profile_scoped`、`voigt_complex_scoped` を持つ。
一様な ULP の目標はなく、`voigt_profile` のオプション付き形式は 64 単位、`voigt_complex` のオプション付き形式は値と導関数に伝播させた推定誤差を返す。

Voigt プロファイルの半値全幅 $f_V$ には閉形式がない。
Gauss の半値全幅 $f_G = 2\sqrt{2\ln 2}\,\sigma$ と Lorentz の半値全幅 $f_L = 2\gamma$ から、Olivero と Longbothum（1977）の近似式 $f_V \approx 0.5346 f_L + \sqrt{0.2166 f_L^2 + f_G^2}$ が 0.02 % 程度の精度で与えられている。
中心から遠い翼では Lorentz 成分が支配し、$V(x) \approx \frac{\gamma}{\pi x^2}\left(1 + \frac{3\sigma^2 - \gamma^2}{x^2}\right)$ になる。

## Na の D2 線の Voigt プロファイル

次のセルは Na の D2 線（真空波長 589.16 nm、原子質量 22.990 u）の Doppler 幅 $\sigma = (\nu_0/c)\sqrt{k_B T/m}$ を温度 $T$ から求め、Lorentz の半値半幅 $\gamma$ と組み合わせた Voigt プロファイルを `voigt_profile` で描く。
横軸は線の中心からの離調 $\Delta$ [GHz]、縦軸は線形 $V(\Delta)$ [GHz⁻¹] で、同じ $\sigma$ の Gauss 線形と同じ $\gamma$ の Lorentz 線形を破線で重ねる。
表は 6 つの検算で、半値全幅（二分法）と Olivero–Longbothum の近似、面積（$[0, 20 f_V]$ の Simpson 則と翼の解析的な積分）と 1、$\Delta = 20 f_V$ での翼の比と漸近形、中心値と $\operatorname{erfcx}$ の関係、`faddeeva` の虚軸上の値と `erfcx`、`voigt_complex` の実部と `voigt_profile` を比べる。
最後の 3 つは関数どうしの関係式を確かめるもので、独立な検算は最初の 3 つである。

```rust
//| id: special-voigt-sodium-line
//| ref: special-voigt-sodium-line
//| title: Na の D2 線の Voigt プロファイルを Gauss と Lorentz の極限と比べる
//| run: reactive
//| crates: [scioxide-core, scioxide-special]
//| inputs:
//|   temperature: {"type":"range","label":"温度 T [K]","min":300,"max":1500,"step":100,"value":500}
//|   lorentz: {"type":"select","label":"Lorentz 半値半幅 γ [GHz]","options":["0.005","0.05","0.5","5"],"value":"0.5"}
//| cases:
//|   - {"id":"doppler","label":"T = 300 K、γ = 0.005 GHz","description":"Doppler 広がりが支配し、中心は Gauss 線形に重なる。","inputs":{"temperature":300,"lorentz":"0.005"}}
//|   - {"id":"pressure","label":"T = 1500 K、γ = 5 GHz","description":"Lorentz 広がりが支配し、線形は Lorentz 線形に近づく。","inputs":{"temperature":1500,"lorentz":"5"}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"voigt","path":"/rows/0/1","approx":{"value":2.296460217975133,"rtol":1e-10}}
//|       - {"artifact":"voigt","path":"/rows/0/3","range":{"max":2e-4}}
//|       - {"artifact":"voigt","path":"/rows/1/3","range":{"max":1e-8}}
//|       - {"artifact":"voigt","path":"/rows/2/3","range":{"max":1e-5}}
//|       - {"artifact":"voigt","path":"/rows/3/3","range":{"max":1e-15}}
//|       - {"artifact":"voigt","path":"/rows/4/3","range":{"max":1e-15}}
//|       - {"artifact":"voigt","path":"/rows/5/3","range":{"max":1e-15}}
//|   - case: doppler
//|     expect:
//|       - {"artifact":"voigt","path":"/rows/0/3","range":{"max":2e-4}}
//|       - {"artifact":"voigt","path":"/rows/1/3","range":{"max":1e-8}}
//|   - case: pressure
//|     expect:
//|       - {"artifact":"voigt","path":"/rows/0/3","range":{"max":2e-4}}
//|       - {"artifact":"voigt","path":"/rows/1/3","range":{"max":1e-8}}
use scioxide_core::{Complex, RealScalar};
use scioxide_special::{erfcx, faddeeva, voigt_complex, voigt_profile};
use std::f64::consts::{LN_2, PI};

let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let digits6 = serde_json::json!({ "significantDigits": 6 });
let gamma: f64 = lorentz.parse().map_err(|_| "半値半幅を読めない")?;
// Doppler 広がりの標準偏差 σ = ν₀ √(kT/m) / c [GHz]（真空波長 589.16 nm、質量 22.990 u）。
let (c, kb, mass) = (299_792_458.0, 1.380_649e-23, 22.990 * 1.660_539_066_6e-27);
let nu0 = c / 589.16e-9;
let sigma = nu0 * RealScalar::sqrt(kb * temperature / mass) / c * 1e-9;
let profile = |d: f64| voigt_profile(d, sigma, gamma).map_err(|e| e.to_string());
let peak = profile(0.0)?;
// 半値全幅: V(Δ) = V(0)/2 を二分法で解く（V は Δ > 0 で単調減少）。
let (mut lo, mut hi) = (0.0, 10.0 * (sigma + gamma));
for _ in 0..60 {
    let mid = 0.5 * (lo + hi);
    if profile(mid)? > 0.5 * peak {
        lo = mid
    } else {
        hi = mid
    }
}
let fwhm = lo + hi;
let (f_g, f_l) = (2.0 * RealScalar::sqrt(2.0 * LN_2) * sigma, 2.0 * gamma);
// Olivero と Longbothum (1977) の近似式（誤差 0.02 % 程度）。
let olivero = 0.5346 * f_l + RealScalar::sqrt(0.2166 * f_l * f_l + f_g * f_g);
// 面積: [0, L] の複合 Simpson 則と、L より外の Lorentz の翼 γ/(πL)(1 + (3σ² − γ²)/(3L²))。
let (length, n) = (20.0 * fwhm, 4000);
let step = length / n as f64;
let mut area = 0.0;
for i in 0..=n {
    let weight = if i == 0 || i == n {
        1.0
    } else if i % 2 == 1 {
        4.0
    } else {
        2.0
    };
    area += weight * profile(step * i as f64)?;
}
let tail = gamma / (PI * length)
    * (1.0 + (3.0 * sigma * sigma - gamma * gamma) / (3.0 * length * length));
let area = 2.0 * (area * step / 3.0 + tail);
// 翼の比 V(L) πL²/γ → 1 + (3σ² − γ²)/L²。
let wing = profile(length)? * PI * length * length / gamma;
let wing_theory = 1.0 + (3.0 * sigma * sigma - gamma * gamma) / (length * length);
// 虚軸上の関係 w(iy) = erfcx(y): V(0) σ√(2π) = Re w(iγ/(σ√2))。
let y = gamma / (sigma * 2.0_f64.sqrt());
let on_axis = faddeeva(Complex::new(0.0, y))
    .map_err(|e| e.to_string())?
    .re;
let scaled_peak = peak * sigma * (2.0 * PI).sqrt();
let complex = voigt_complex(0.5 * fwhm, sigma, gamma).map_err(|e| e.to_string())?;
let rows = vec![
    (
        "半値全幅 f_V [GHz] と Olivero–Longbothum の近似",
        fwhm,
        olivero,
    ),
    ("面積 ∫V dΔ [-] と 1", area, 1.0),
    (
        "翼の比 V(L)πL²/γ [-] と 1 + (3σ² − γ²)/L²",
        wing,
        wing_theory,
    ),
    (
        "V(0)σ√(2π) [-] と erfcx(γ/(σ√2))",
        scaled_peak,
        erfcx(y).map_err(|e| e.to_string())?,
    ),
    (
        "Re w(iy) [-] と erfcx(y)",
        on_axis,
        erfcx(y).map_err(|e| e.to_string())?,
    ),
    (
        "Re voigt_complex(f_V/2) と voigt_profile(f_V/2)",
        complex.re,
        0.5 * peak,
    ),
];
let rows: Vec<_> = rows
    .into_iter()
    .map(|(name, value, check)| (name, value, check, (value / check - 1.0).abs()))
    .collect();
let mut voigt = Vec::new();
let mut gauss = Vec::new();
let mut lorentzian = Vec::new();
for i in 0..=400 {
    let d = -8.0 + 0.04 * i as f64;
    voigt.push([d, profile(d)?]);
    gauss.push([
        d,
        (-0.5 * d * d / (sigma * sigma)).exp() / (sigma * (2.0 * PI).sqrt()),
    ]);
    lorentzian.push([d, gamma / (PI * (d * d + gamma * gamma))]);
}
emit_line_chart!(
    &vec![
        serde_json::json!({ "name": "Voigt", "points": voigt }),
        serde_json::json!({ "name": "Gauss（同じ σ）", "points": gauss, "dashed": true }),
        serde_json::json!({ "name": "Lorentz（同じ γ）", "points": lorentzian, "dashed": true })
    ],
    options = &serde_json::json!({
        "xLabel": "離調 Δ [GHz]",
        "yLabel": "線形 V(Δ) [GHz⁻¹]",
        "yType": "log",
        "yMin": 1e-4
    })
);
let columns = serde_json::json!([
    { "key": "0", "label": "検算" },
    { "key": "1", "label": "SciOxide の値", "type": "number", "format": digits6 },
    { "key": "2", "label": "比べる値", "type": "number", "format": digits6 },
    { "key": "3", "label": "相対差 [-]", "type": "number", "format": sci3 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "voigt" })
);
```

既定の $T = 500$ K では $\sigma = 0.722$ GHz（Gauss の半値全幅 1.700 GHz）、Lorentz の半値全幅は 1.0 GHz で、Voigt プロファイルの半値全幅は 2.2965 GHz になり、Olivero–Longbothum の近似 2.2968 GHz と $1.5 \times 10^{-4}$ の相対差で合う。
面積は 1 と $8.8 \times 10^{-10}$ の差で、翼の比は漸近形と $6.4 \times 10^{-7}$ の差で一致し、後者の差は漸近形で省いた $\Delta^{-4}$ の項の大きさである。
図の対数軸では、中心の近くは Gauss 線形に近く、$\lvert\Delta\rvert$ が 3 GHz を超えると Gauss 線形は急に減って、Voigt プロファイルは Lorentz 線形の翼に重なる。
後半の 3 行は中心値 $V(0)\sigma\sqrt{2\pi} = \operatorname{erfcx}(\gamma/(\sigma\sqrt{2})) = 0.62094$ などの関係が丸めの程度で成り立つことを示す。
$T = 300$ K、$\gamma = 0.005$ GHz を選ぶと線形はほぼ Gauss 線形になり、半値全幅 1.32187 GHz は近似式と $1.5 \times 10^{-5}$ の差で合う。
$T = 1500$ K、$\gamma = 5$ GHz では Lorentz 成分が支配し、半値全幅 10.855 GHz と近似式の差は $2.0 \times 10^{-4}$ で、近似式の精度 0.02 % の程度である。

## API

この族の関数は次のとおりである。
`faddeeva` は `Complex<S>` を受け取って返し、`voigt_profile` は実数を返し、`voigt_complex` は `Complex<S>` を返す。
オプションはすべて `ProbabilityOptions` で、作業量の上限（`Budget`、既定 65536）だけを持ち、精度の要求は持たない。
オプション付き形式は `SpecialFunctionResult` を返し、推定誤差、終了状態、計算量の計数、アルゴリズムの識別子を持つ。

| 標準形式 | 計算するもの | オプション付き形式 | スコープ付き API | オプション付き形式の推定誤差 |
|---|---|---|---|---|
| `faddeeva` | $w(z)$ | `faddeeva_with_options` | `faddeeva_scoped` | 値に 64 単位、導関数に 128 単位 |
| `voigt_profile` | $\operatorname{Re} V(x; \sigma, \gamma)$ | `voigt_profile_with_options` | `voigt_profile_scoped` | 64 単位 |
| `voigt_complex` | $V(x; \sigma, \gamma)$ | `voigt_complex_with_options` | `voigt_complex_scoped` | 値と導関数に伝播させた値 |

どれも一様な ULP の目標を持たない。
推定誤差はオプション付き形式が返す見積もりで、包含が保証された区間ではない。
上限に達した反復は標準形式では `ConvergenceFailure`（`IterationLimit`）、オプション付き形式とスコープ付き API では推定値が残れば終了状態 `IterationLimit` の結果になる。

## まとめ

Faddeeva 関数は軸上では実数の $\operatorname{erfcx}$ と Dawson の核、$\lvert z \rvert$ が大きい所では Laplace の連分数、それ以外では Algorithm 916 の級数で評価される。
下半平面は反射 $w(z) = 2e^{-z^2} - w(-z)$ で求め、$\lvert \operatorname{Im} z \rvert > \lvert \operatorname{Re} z \rvert$ で値が型の範囲を超える所はオプション付き形式の対数形で読む。
Voigt プロファイルは `voigt_profile` で求め、Gauss の幅が分解能より小さいときは Lorentz の極限の式に切り替わる。
一様な ULP の目標はないので、精度はオプション付き形式の推定誤差と、面積や翼の漸近形のような独立な検算で判断する。
