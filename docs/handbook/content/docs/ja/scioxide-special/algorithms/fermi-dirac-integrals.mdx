金属や半導体の電子の数、エネルギー、比熱を Fermi–Dirac 分布 $1/(e^{t-x} + 1)$ で数えると、$t^j$ を重みにした半無限区間の積分が現れる。
$x = \mu/k_BT$（$\mu$ は化学ポテンシャル、$k_B$ は Boltzmann 定数、$T$ は温度）が負で大きいと積分は指数関数のように小さく、正で大きいと冪 $x^{j+1}$ のように大きくなる。
一つの公式で全域を評価すると、級数の収束が遅くなる所や漸近級数が使えない所が必ず残る。
scioxide-special はこの積分を、引数の領域ごとに級数、Chebyshev 展開、Sommerfeld 展開、整数次数の反転公式に振り分けて評価する。
このページは規格化の規約、二つの極限、各領域の評価法、精度の保証と API を説明し、定義積分の求積と微分の関係で値を検算する。
電子気体の密度から化学ポテンシャルを求める使い方は[電子気体の化学ポテンシャル](../../examples/fermi-gas-chemical-potential/)にある。

## 定義と規約

scioxide-special の完全 Fermi–Dirac 積分は、Gamma 関数で規格化した形である（DLMF §25.12(iii)）。

$$
F_j(x) = \frac{1}{\Gamma(j+1)} \int_0^\infty \frac{t^j}{e^{t-x} + 1}\,dt = -\mathrm{Li}_{j+1}(-e^x), \qquad j > -1
$$

$\mathrm{Li}_s$ は多重対数関数である。
この規格化では、$x$ についての微分が次数を一つ下げる。

$$
\frac{d}{dx} F_j(x) = F_{j-1}(x)
$$

$j = -1$ はこの関係による解析接続で、ロジスティック関数 $F_{-1}(x) = 1/(1 + e^{-x})$ になる。
$j = 0$ は $F_0(x) = \ln(1 + e^x)$ である。
$j < -1$ の整数次数はロジスティック関数の $(-1-j)$ 階導関数で、$e^x$ の有理関数になる。
原点の値は Dirichlet のイータ関数 $\eta(s) = (1 - 2^{1-s})\zeta(s)$（$\zeta$ は Riemann ゼータ関数）で $F_j(0) = \eta(j+1)$ になる。

物理の文献には $1/\Gamma(j+1)$ を付けない積分 $\mathcal{F}_j(x) = \int_0^\infty t^j/(e^{t-x}+1)\,dt$ を Fermi–Dirac 積分と呼ぶものもある。
その場合は $\mathcal{F}_j = \Gamma(j+1)\,F_j$ で換算する。
たとえば $\mathcal{F}_{1/2} = (\sqrt{\pi}/2)\,F_{1/2}$ で、換算を忘れると電子密度が約 11% ずれる。

## 非縮退と縮退の極限

$x \to -\infty$（非縮退の極限）では、被積分関数の分母を $e^{x-t}$ の等比級数に展開して項別に積分し、
$$
F_j(x) = \sum_{k=1}^\infty (-1)^{k+1} \frac{e^{kx}}{k^{j+1}} = e^x - \frac{e^{2x}}{2^{j+1}} + \cdots
$$

を得る。
主要項 $e^x$ は Boltzmann 分布の値で、第 2 項が Pauli の排他律による最初の補正である。

$x \to +\infty$（強く縮退した極限）では、分布が $t = x$ の近くでだけ 0 と 1 の間を動くことを使う Sommerfeld 展開

$$
F_j(x) = \frac{x^{j+1}}{\Gamma(j+2)} \left[ 1 + \sum_{k=1}^{\infty} 2\eta(2k)\,\frac{(j+1)j\cdots(j+2-2k)}{x^{2k}} \right] + O(e^{-x})
$$

が成り立つ。
分子の積は $j+1$ から 1 ずつ下がる $2k$ 個の因子である。
$2\eta(2) = \pi^2/6$ なので、最初の補正は $(\pi^2/6)\,j(j+1)/x^2$ である。
整数の次数では積がどこかで 0 になって括弧の中は有限和になり、半整数の次数では収束しない漸近級数になる。

整数の次数 $j \ge 0$ では、多重対数の反転公式（DLMF §25.12）から、指数的に小さい項も含めた恒等式

$$
F_j(x) = 2\sum_{p} \eta(j+1-p)\,\frac{x^p}{p!} + (-1)^j F_j(-x)
$$

が得られる。
$p$ は $j + 1$ と偶奇が同じ $0 \le p \le j + 1$ を動くので、係数は $\eta(0) = 1/2$ と偶数の引数のイータ関数（$\pi^{2k}$ の有理数倍）だけである。
$j = 0$ では $F_0(x) - F_0(-x) = x$、$j = 1$ では $F_1(x) + F_1(-x) = x^2/2 + \pi^2/6$ になる。

## Fermi–Dirac 積分の評価法

| 次数 $j$ | 引数の範囲 | 方法 | 方法の識別子 |
|---|---|---|---|
| $-1$、$0$ | 全域 | 閉形式 $1/(1+e^{-x})$、$\max(x, 0) + \ln(1 + e^{-\lvert x\rvert})$ | `fermi_algebraic` |
| $-101 \le j \le -2$ の整数 | 全域 | $e^{-\lvert x\rvert}$ の有理関数（Eulerian 数を係数に持つ）。$-j \ge 11$ で $\lvert x\rvert \le -1-j$ のときは極の和 | `polylog_eulerian_rational`、`polylog_integer_poles` など |
| $j \ge -1/2$ | $x < -1$ | 級数 $e^x \sum_{k \ge 1} (-1)^{k+1} e^{(k-1)x}/k^{j+1}$ | `fermi_fugacity_series` |
| $-1/2, 1/2, 3/2, 1, 2$ | $-1 \le x < 30$ | 4 区間 $[-1,1)$、$[1,4)$、$[4,10)$、$[10,30)$ の Chebyshev 展開（最後の区間は $x^{j+1}$ を掛ける） | `fermi_central_expansion` |
| $-1/2, 1/2, 3/2$ | $x \ge 30$ | Sommerfeld 展開（最小項で打ち切る） | `fermi_sommerfeld` |
| 整数 $j \ge 1$ | $x > 0$（$j \le 2$ では $x \ge 30$） | 反転公式 | `fermi_integer_inversion` |
| 整数 $j \ge 3$ | $-1 \le x \le 0$ | 交代級数を Euler 変換で加速 | `fermi_euler_series` |

$x < -1$ の級数は公比 $e^x < e^{-1}$ の交代級数で、$x = -1$ でも 35 項以下で相対 $\varepsilon$（倍精度の機械イプシロン）に達する。
$e^x$ を外に括り出してから足すので、$e^x$ が通常値の範囲を下回る $x < -745$ でも、オプション付き形式の対数形 $\ln F_j(x) = x + \ln(\cdots)$ は値を保つ。

$-1 \le x < 30$ は、級数の公比が 1 に近づき、Sommerfeld 展開の項もまだ十分に小さくならない範囲である。
scioxide-special はここを、提供する 5 つの次数ごとに 4 区間の Chebyshev 展開で覆う。
Chebyshev 展開は区間全体で誤差がほぼ一様に分布する多項式近似で、係数の数が固定なので計算量も固定である。
最後の区間 $[10, 30)$ では $F_j(x)/x^{j+1}$ を展開して $x^{j+1}$ を掛け、Sommerfeld 展開の主要項の増え方を係数に負わせない。

$x \ge 30$ の半整数の次数では、Sommerfeld 展開の項を足し、項の大きさが前の項より減らなくなるか相対 $\varepsilon$ を下回ったところで止める。
項の大きさはおよそ $(2k)!/x^{2k}$ のように変わり、$2k \approx x$ で最小になるので、$x$ が小さいほど最小の項が大きく残る。
推定誤差には打ち切った最初の項の 4 倍と、展開が無視する $O(e^{-x})$ の項の上界 $4e^{-x}$ を入れる。
境目の $x = 30$ では推定相対誤差が $4 \times 10^{-13}$ 程度になり、参照値との差は $F_{-1/2}$ で $5 \times 10^{-15}$ である（下のセルで $x = 30$ を入力すると確かめられる）。

整数の次数 $j \ge 1$ の $x > 0$ では、反転公式の多項式の部分を低い次数から対数で足し、補正の $F_j(-x)$ を級数で加える。
補正は指数的に小さく、多項式の部分は有限和なので、漸近展開と違って打ち切りの誤差が残らない。
$x$ が $p$ に比べて小さくなった所で残りの項の和の上界が相対 $\varepsilon$ を下回れば、その先の項を省く。
多項式の項は最大で $(j+1)/2 + 1$ 個で、次数も $x$ も大きいと作業量の上限を超えて `ConvergenceFailure` になる（既定の上限では $j = 2 \times 10^5$、$x = 10^5$ で起きる）。

整数の次数 $j \ge 3$ の $-1 \le x \le 0$ には中央の Chebyshev 展開がない。
ここでは $F_j(x) = e^x \sum_{k \ge 0} (-1)^k e^{kx}/(k+1)^{j+1}$ の項が完全単調な列なので、Euler 変換で交代級数を足す。
Euler 変換は差分の列 $\Delta^n a_0$ を重み $2^{-(n+1)}$ で足す変換で、$n$ 行目の寄与は $2^{-n} a_0$ 以下になるので、約 53 行で相対 $\varepsilon$ に達する。
差分の表を毎行作り直すので、計算量は行数の 2 乗に比例し、行数は 64 を超えない。

負の整数の次数 $j = -1 - n$（$n \ge 1$）では、$F_j(x) = -\mathrm{Li}_{-n}(-e^x)$ を多重対数の核で評価する。
$\mathrm{Li}_{-n}(z) = z\,A_n(z)/(1 - z)^{n+1}$（$A_n$ は Eulerian 数 $A(n, k)$ を係数に持つ多項式）を、関係 $F_j(-x) = (-1)^{n+1} F_j(x)$ を使って常に $\lvert z\rvert = e^{-\lvert x\rvert} \le 1$ の側で評価する。
$n \ge 10$ で $\lvert x\rvert \le n$ のときは多項式の項の打ち消しが大きいので、代わりに極の和 $\mathrm{Li}_{-n}(e^\mu) = n! \sum_{k \in \mathbb{Z}} (2\pi i k - \mu)^{-n-1}$（$\mu = x + i\pi$）を足す。

## エラーと値の範囲

非有限の $x$ は `NonFinite` になる。
次数 $j \ge 1/2$ の通常値 $F_j(x) \approx x^{j+1}/\Gamma(j+2)$ がスカラー型の範囲を超えると、標準形式は `NumericalInstability`（`Overflow`）を返し、オプション付き形式は対数形と尺度化形に値を残す。
`f64` の `fermi_dirac_half` では $x \approx 4 \times 10^{205}$ まで通常値が得られる。
`fermi_dirac_mhalf`、`fermi_dirac_m1`、`fermi_dirac_0` は有限の $x$ であふれない。
$x$ が負で大きく通常値がアンダーフローしても、オプション付き形式の対数形は残る。
`fermi_dirac_int` は $j < -101$ を `DomainError`（`OutsideDomain`）とする。

## 0 次の不完全積分

不完全積分は次数 0 だけを提供する。

$$
F_0(x, b) = \int_b^\infty \frac{dt}{e^{t-x} + 1} = \ln\bigl(1 + e^{x-b}\bigr), \qquad b \ge 0
$$

`fermi_dirac_inc_0(x, b)` は $x - b$ を作って完全積分 $F_0$ と同じ閉形式（方法の識別子 `fermi_algebraic`）で評価し、$b = 0$ では `fermi_dirac_0` と一致する。
$b < 0$ は `DomainError`（`OutsideDomain`）、非有限の $x$ と $b$ は `NonFinite` になる。
$x - b$ が $-\infty$ にあふれる場合は、極限の 0 を終了状態 `Limit` で返す。
他の次数の不完全積分は提供しないので、必要なら被積分関数を scioxide-integrate の求積で積分する。

## 精度の保証

Fermi–Dirac 積分には一様な ULP の目標はない。
照合試験は独立に高精度で生成した参照値と比べて、次のことを確かめている。

- 値の誤差が `f64` では相対 $5 \times 10^{-11}$ と絶対 $5 \times 10^{-13}$ の和以下、`f32` では相対 $2 \times 10^{-4}$ と絶対 $5 \times 10^{-6}$ の和以下である（不完全積分を含む）。
- オプション付き形式の推定誤差が実際の誤差を覆う（参照値の丸めの幅を足して）。
  対数形と尺度化形の推定誤差も同じように確かめる。
- 結果が非正規数になる入力では、参照値との差が 8 ULP（`f32` では 16 ULP）以内である。

試験の許容誤差は仕様の上限であり、典型的な誤差はずっと小さい（下のセルで実測する）。
オプション付き形式の推定誤差は打ち切りと丸めから導いた評価にもとづく値（`ModelBased`）で、包含が保証された区間ではない。
推定誤差が要求を満たすかどうかは、利用者が `relative_error()` などで判断する。

## API

すべて実数の引数だけを受け付け、`f32` か `f64` の値を返す。
標準形式は値だけを返し、オプション付き形式 `*_with_options(.., options)` は推定誤差、対数形、尺度化形、終了状態、アルゴリズムの識別子を持つ `SpecialFunctionResult` を返す。
スコープ付き API `*_scoped(.., options, scope)` は親の求解の中で評価し、計算量を入れ子の計数として渡す（[三つの呼び出し形](oxref:special-api-call-forms)）。

| 標準形式 | オプション付き形式 | スコープ付き API | 計算する量 |
|---|---|---|---|
| `fermi_dirac_m1` | `fermi_dirac_m1_with_options` | なし | $F_{-1}(x) = 1/(1+e^{-x})$ |
| `fermi_dirac_mhalf` | `fermi_dirac_mhalf_with_options` | `fermi_dirac_mhalf_scoped` | $F_{-1/2}(x)$ |
| `fermi_dirac_0` | `fermi_dirac_0_with_options` | なし | $F_0(x) = \ln(1+e^x)$ |
| `fermi_dirac_half` | `fermi_dirac_half_with_options` | `fermi_dirac_half_scoped` | $F_{1/2}(x)$ |
| `fermi_dirac_1` | `fermi_dirac_1_with_options` | `fermi_dirac_1_scoped` | $F_1(x)$ |
| `fermi_dirac_3half` | `fermi_dirac_3half_with_options` | `fermi_dirac_3half_scoped` | $F_{3/2}(x)$ |
| `fermi_dirac_2` | `fermi_dirac_2_with_options` | `fermi_dirac_2_scoped` | $F_2(x)$ |
| `fermi_dirac_int(j, x)` | `fermi_dirac_int_with_options` | `fermi_dirac_int_scoped` | 整数次数 $j \ge -101$ の $F_j(x)$ |
| `fermi_dirac_inc_0(x, b)` | `fermi_dirac_inc_0_with_options` | なし | 不完全積分 $F_0(x, b)$ |

オプション型 `FermiDiracOptions` は作業量の上限 `Budget`（既定 65536）だけを持ち、精度の要求ではない。
上限は級数、展開、多項式の項と Chebyshev 係数の数で数える。
足りなければオプション付き形式は終了状態 `IterationLimit` の結果か `ConvergenceFailure` のエラーを返し、標準形式はどちらの場合も `ConvergenceFailure` を返す。
$F_{-1}$、$F_0$、$F_0(x, b)$ は閉形式で計算量が引数によらないので、スコープ付き API がない。
次数を固定した `fermi_dirac_1(x)` と `fermi_dirac_int(1, x)` は同じ方法で同じ量を返す。
半整数の次数は $-1/2$、$1/2$、$3/2$ だけを提供し、他の非整数の次数は提供しない。
その場合の代替は実数の次数を受け付ける多重対数 `polylog` による $-\mathrm{Li}_{j+1}(-e^x)$（$e^x$ があふれない $x < 709$ の範囲、[一般の位数の多重対数と Lerch の超越関数](../polylog-and-lerch/)）か、定義積分の求積である。

## Fermi–Dirac 積分の検算

次のセルは定義積分を合成 Boole 則で求めた値を独立な参照値にする。
合成 Boole 則は区間を 4 の倍数 $m$ 個に等分し、各点の値に重み $7, 32, 12, 32, 14, 32, 12, 32, 14, \dots, 32, 7$ を掛けて足し、刻み $h$ の $2/45$ 倍を掛ける。
これは刻み $h$ と $2h$ の合成 Simpson 則に Richardson 外挿を 1 回施したものと同じで、滑らかな被積分関数では誤差が $h^6$ で減る。
多数の項を足すときの丸め誤差を抑えるため、和は Neumaier の補償和（各加算で失われた下位の桁を別の変数にためて最後に戻す和）で取る。
この補助関数を次の定義のブロックに置く。

```rust
//| id: special-fermi-dirac-boole
//| kind: definitions
//| title: 合成 Boole 則と補償和
//| crates: [scioxide-core]
/// 合成 Boole 則で ∫ₐᵇ g(t) dt を求める独立な参照値。m は 4 の倍数の分割数。
/// 和は Neumaier の補償和で取り、g の失敗はそのまま返す。
pub(crate) fn boole(
    mut g: impl FnMut(f64) -> Result<f64, String>,
    a: f64,
    b: f64,
    m: usize,
) -> Result<f64, String> {
    let h = (b - a) / m as f64;
    let (mut sum, mut compensation) = (0.0_f64, 0.0_f64);
    for i in 0..=m {
        let weight = if i == 0 || i == m {
            7.0
        } else if i % 2 == 1 {
            32.0
        } else if i % 4 == 2 {
            12.0
        } else {
            14.0
        };
        let term = weight * g(a + i as f64 * h)?;
        let next = sum + term;
        compensation += if sum.abs() >= term.abs() {
            (sum - next) + term
        } else {
            (term - next) + sum
        };
        sum = next;
    }
    Ok((sum + compensation) * 2.0 * h / 45.0)
}
```

セルは入力 $x$ で次数 $j = -1, -1/2, 0, 1/2, 1, 3/2, 2, 3$ の $F_j(x)$ をオプション付き形式で評価し、推定相対誤差と方法の識別子を並べる。
参照値は $t = u^2$ と置き換えて端点の $t^{-1/2}$ を除いた定義積分 $\int_0^U 2u^{2j+1}/(e^{u^2 - x} + 1)\,du$（$U^2 = \max(x, 0) + 50$）を合成 Boole 則（20000 等分）で求め、$\Gamma(j+1)$ で割った値である。
上端より先の寄与は相対 $e^{-50} \approx 2 \times 10^{-22}$ 程度で無視できる。
$j = -1$ は積分で書けないので、ロジスティック関数の式を `f64` の固有メソッドで計算して参照値にする。
最後の列は微分の関係 $F_j' = F_{j-1}$ を、中心差分 $(F_j(x+h) - F_j(x-h))/(2h)$（$h = 10^{-4}$）と scioxide-special の $F_{j-1}$ の差で確かめる。
次数ごとに方法が違うので、この関係は隣り合う次数の実装を互いに検算する。
中心差分には打ち切り誤差 $h^2 F_j'''/6$ と丸め誤差 $\varepsilon F_j/h$ が残るので、差は $F_{j-1}$ と $F_j$ の大きい方で割る。
$F_{-3/2}$ は提供しないので、$j = -1/2$ の行は空欄になる。

```rust
//| id: special-thermal-fermi-dirac-limits
//| ref: special-thermal-fermi-dirac-limits
//| title: Fermi–Dirac 積分を定義積分と微分の関係で検算する
//| run: reactive
//| uses: [special-fermi-dirac-boole]
//| crates: [scioxide-core, scioxide-special]
//| inputs:
//|   x: {"type":"range","label":"引数 x（= μ/k_BT）","description":"負は非縮退、正で大きいほど強く縮退した電子気体に当たる。","min":-40,"max":60,"step":0.5,"value":2}
//| cases:
//|   - {"id":"boltzmann","label":"x = −8","description":"級数の領域。どの次数も e^x ≈ 3.35×10⁻⁴ に近い。","inputs":{"x":-8}}
//|   - {"id":"euler","label":"x = −0.5","description":"j = 3 は Euler 変換、j ≤ 2 は中央の Chebyshev 展開で評価する。","inputs":{"x":-0.5}}

type Detailed = fn(f64, FermiDiracOptions) -> Result<SpecialFunctionResult<f64>, SciOxideError>;
let options = FermiDiracOptions::default();
let order_3 = |x: f64, options: FermiDiracOptions| {
    scioxide_special::fermi_dirac_int_with_options(3, x, options)
};
let sqrt_pi = std::f64::consts::PI.sqrt();
// (次数 j, オプション付き形式, Γ(j + 1), F_{j−1} の行の番号)。
let orders: [(f64, Detailed, f64, Option<usize>); 8] = [
    (-1.0, fermi_dirac_m1_with_options, 1.0, None),
    (-0.5, fermi_dirac_mhalf_with_options, sqrt_pi, None),
    (0.0, fermi_dirac_0_with_options, 1.0, Some(0)),
```

既定の $x = 2$ では、$F_{-1}$ と $F_0$ は閉形式、$F_{-1/2}$ から $F_2$ は中央の Chebyshev 展開、$F_3$ は反転公式で評価され、参照値との相対差は $2.1 \times 10^{-16}$ 以下である。
推定相対誤差は閉形式の $1.8 \times 10^{-15}$ から反転公式の $9.6 \times 10^{-14}$ までで、実際の差より 1〜3 桁大きく見積もられている。
$x = -8$（`boltzmann`）では $j \ge -1/2$ が級数に切り替わる。
どの次数の値も $e^{-8} = 3.3546 \times 10^{-4}$ の少し下にあり、$F_j \approx e^x - e^{2x}/2^{j+1}$ のとおり次数が上がるほど $e^x$ に近づく。
$x = -0.5$（`euler`）では $F_3$ だけが Euler 変換に切り替わり、参照値との相対差は $1.9 \times 10^{-16}$ である。
$x = 40$（`degenerate`）では半整数の次数が `fermi_sommerfeld`、整数の次数が `fermi_integer_inversion` に切り替わり、参照値との相対差は $1.1 \times 10^{-15}$ 以下である。
この二つの方法の推定相対誤差は $4 \times 10^{-14}$ から $2.4 \times 10^{-13}$ で、閉形式の $F_{-1}$、$F_0$ の $1.8 \times 10^{-15}$ より大きい。
対数で組み立てる方法では、推定誤差に $\ln F_j$ の大きさに比例する丸めの分が入るので、値が大きいほど推定は大きくなる。
最後の列の微分の関係は、どのケースでも $2 \times 10^{-9}$ 以下の差で成り立つ。
この差は中心差分の打ち切り誤差 $h^2 F_j'''/6$ の大きさで、$F_j''' \approx F_j$ になる $x = -8$ では相対 $h^2/6 \approx 1.7 \times 10^{-9}$ になる。
相対差が推定相対誤差を大きく超える行があれば、実装か参照値の誤りを疑う。

## まとめ

scioxide-special の Fermi–Dirac 積分は $1/\Gamma(j+1)$ で規格化して $F_j' = F_{j-1}$ とするので、規格化のない $\mathcal{F}_j$ を使う文献の式は $\Gamma(j+1)$ を掛けて照合する。
評価は $x < -1$ の級数、$-1 \le x < 30$ の Chebyshev 展開、$x \ge 30$ の Sommerfeld 展開に分かれ、整数次数は $x > 0$ を反転公式の有限和で、$j \ge 3$ の $-1 \le x \le 0$ を Euler 変換で評価する。
一様な ULP の仕様はなく、照合試験は `f64` で相対 $5 \times 10^{-11}$ 程度の許容誤差と推定誤差の被覆を確かめるので、精度が問題になる計算ではオプション付き形式の推定相対誤差を読む。
$x$ が大きく値があふれるときや、負で大きく値がアンダーフローするときは、オプション付き形式の対数形を使う。
$F_{1/2}$ と導関数 $F_{-1/2}$ を求根に渡す使い方は[電子気体の化学ポテンシャル](../../examples/fermi-gas-chemical-potential/)で確かめ、同じ統計の重みを持つ Debye 関数と輸送積分は[Debye 関数・輸送積分・シンクロトロン関数](../thermal-and-radiation-integrals/)で確かめる。
