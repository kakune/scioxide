Gamma 関数 $\Gamma(x)$ は階乗を実数と複素数へ広げた関数で、確率分布の正規化定数、統計力学の分配関数、超幾何級数の係数に現れる。
引数が増えると値は指数関数より速く増え、非正の整数では極を持ち、負の実軸では区間ごとに符号が入れ替わる。
その対数微分である digamma 関数と polygamma 関数は級数の和や統計量の期待値に現れ、Gamma 関数の比である Pochhammer 記号は超幾何級数の係数になる。
このページは、これらの関数の定義と性質、`scioxide-special` が引数の領域ごとに使う評価法、精度の保証、API の使い分けを説明する。
積分を途中で区切った不完全 Gamma 関数と、Gamma 分布の累積確率・分位点は [不完全 Gamma 関数](../incomplete-gamma/) で扱う。

## 定義と基本的な性質

$\operatorname{Re} z > 0$ では、Gamma 関数は Euler の第二種積分で定義される（DLMF 5.2.1）。

$$
\Gamma(z) = \int_0^\infty t^{z-1} e^{-t} \, dt
$$

部分積分から基本漸化式 $\Gamma(z+1) = z\,\Gamma(z)$ が得られ、$\Gamma(1) = 1$ と合わせると、非負の整数 $n$ で $\Gamma(n+1) = n!$ になる。
漸化式を左へ使うと、$\Gamma$ は $z = 0, -1, -2, \dots$ の 1 位の極を除く複素平面全体へ解析接続される。
$\Gamma$ は零点を持たず、分枝切断もない。

負の側の値は Euler の反射公式（DLMF 5.5.3）で正の側の値に結びつく。

$$
\Gamma(z)\,\Gamma(1-z) = \frac{\pi}{\sin(\pi z)} \qquad (z \notin \mathbb{Z})
$$

実軸上の区間 $(-n, -n+1)$（$n = 1, 2, \dots$）で $\Gamma(x)$ の符号は $(-1)^n$ である。
`gamma` は負の非整数 $x$ でこの符号を付けた値を返し、非正の整数では `DomainError`（`Pole`）を返す。
NaN と無限大の入力は `NonFinite` になる。

binary64 の最大値はおよそ $1.80 \times 10^{308}$ で、$\Gamma(x)$ は $x \approx 171.62$ でこれを超える（binary32 では $x \approx 35.04$）。
その先の `gamma` は `NumericalInstability`（`Overflow`）を返すが、オプション付き形式 `gamma_with_options` は符号付きの対数形と 2 の冪で尺度化した値を結果に残す（[最初の計算](oxref:special-index-first-computation)）。

## 対数 Gamma 関数

尤度や分配関数のように大きな Gamma 関数の比を扱う計算では、値ではなく対数を直接扱う。
`ln_gamma(x)` は実数の $x$ で $\ln|\Gamma(x)|$ を返し、符号は捨てる。
$\ln\Gamma(1) = \ln\Gamma(2) = 0$ で、この二つの零点の近くでも相対精度を保つように評価する（次節）。
符号と対数を一緒に読むには、`gamma_with_options(x, options)?.logarithmic()` の `LogValue` から `sign()` と `log_magnitude()` を取り出す。

複素数の $z$ では、`ln_gamma` は正の実軸で実数になる解析的な $\log\Gamma(z)$ を返す。
これは $(-\infty, 0]$ を切断とし、虚部が $+0$ か $-0$ かで切断の上下の岸を選ぶ。
虚部は $(-\pi, \pi]$ に折り返さないので、$\Gamma(z)$ の値の主値の対数とは $2\pi i$ の整数倍だけ異なることがある。
たとえば $\log\Gamma(-2.5 + 0i)$ の虚部は $-3\pi$ である。

## Digamma 関数と polygamma 関数

Gamma 関数の対数微分を digamma 関数と呼ぶ（DLMF 5.2.2）。

$$
\psi(z) = \frac{d}{dz}\ln\Gamma(z) = \frac{\Gamma'(z)}{\Gamma(z)}, \qquad \psi(1) = -\gamma
$$

$\gamma \approx 0.5772$ は Euler–Mascheroni 定数である。
$\psi$ は漸化式 $\psi(z+1) = \psi(z) + 1/z$（DLMF 5.5.2）と反射公式 $\psi(1-z) - \psi(z) = \pi\cot(\pi z)$（DLMF 5.5.4）を満たし、$z = 0, -1, -2, \dots$ に 1 位の極を持つ。
正の実軸の零点は $x_0 \approx 1.4616$ の一つだけで、負の実軸では隣り合う極の間に一つずつ零点がある。

polygamma 関数 $\psi^{(n)}$ は digamma 関数の $n$ 階導関数で、$n \ge 1$ では Hurwitz zeta 関数 $\zeta(s, z) = \sum_{k \ge 0} (k + z)^{-s}$ で書ける（DLMF 5.15.1、25.11.12）。

$$
\psi^{(n)}(z) = \frac{d^{n+1}}{dz^{n+1}}\ln\Gamma(z) = (-1)^{n+1}\, n!\, \zeta(n+1, z)
$$

$\psi^{(n)}$ は非正の整数に $n+1$ 位の極を持ち、大きさは $n!$ の程度で増える。
`polygamma(order, z)` の `order` は $n$（`usize`）で、`order = 0` は `digamma` と同じ値を返す。
負の実軸では反射公式 $\psi^{(n)}(1-z) + (-1)^{n+1}\psi^{(n)}(z) = (-1)^n \pi \frac{d^n}{dz^n}\cot(\pi z)$（DLMF 5.15.6）を使う。

## Pochhammer 記号

上昇階乗（Pochhammer 記号）は Gamma 関数の比で定義される（DLMF 5.2.5）。

$$
(a)_x = \frac{\Gamma(a+x)}{\Gamma(a)}
$$

非負の整数 $x = n$ では多項式 $(a)_n = a(a+1)\cdots(a+n-1)$ で、$(a)_0 = 1$ である。
負の整数 $x = -n$ では $(a)_{-n} = 1/[(a-1)(a-2)\cdots(a-n)]$ になる。
$\Gamma(a)$ だけが極を持つ点（$a$ が非正の整数で $a + x$ はそうでない点）では、値は 0 である。
$a$ と $a + x$ がどちらも非正の整数のときは極が約分でき、$x$ が正の整数か $\lvert x\rvert \le 128$ の負の整数なら、上の積の値を返す。
それ以外で $a + x$ が非正の整数になる点は `DomainError`（`Pole`）である。

`pochhammer(a, x)` は $\lvert x\rvert \le 128$ の整数のずれを、2 ワードの浮動小数点数（double-word、約 106 ビットの仮数）の積で計算する。
それ以外のずれでは、Gamma 関数の比を対数の上で作る。
ずれ $x$ が $a$ から最も近い極までの距離（1 を上限とする）の 1 % 以下なら、$\ln\Gamma(a+x) - \ln\Gamma(a) = \int_a^{a+x} \psi(t)\,dt$ を 8 点の Gauss–Legendre 求積で計算する。
$a + x$ が丸めで $a$ に戻るほど小さな $x$ でも、この形なら $x$ が失われない。
実数の $a$ と $a + x$ がどちらも 32 以上なら、Stirling 級数の差を $x\ln a + (a + x - \tfrac{1}{2})\operatorname{log1p}(x/a) - x$ と補正項の差に組み直し、ずれ $x$ を基点 $a$ と分けて扱う。
大きな $a$ と小さな $x$ で $\ln\Gamma(a+x) - \ln\Gamma(a)$ をそのまま引くと、ほぼ等しい二つの大きな対数の差になって桁が落ちるからである。
それ以外の実数では $\ln\lvert\Gamma\rvert$ を double-word で評価して引き、負の側の符号を別に付ける。
複素数では、実部が小さいときに漸化式で $4.5$ 以上へ移してから、複素数の Lanczos 近似の差か上の求積を使う。

$x \to 0$ では $(a)_x \to 1$ なので、$((a)_x - 1)/x$ を引き算で作ると桁落ちで値が意味を失う。
`pochhammer_relative(a, x)` はこの量を $\exp$ の差 $\operatorname{expm1}$ などで打ち消しなしに計算し、$x = 0$ では極限 $\psi(a)$ を返す。
二つの関数のオプション付き形式は他の Gamma 関数族と違って、組合せ論の関数と同じ `CombinatorialOptions` を受け取る。
実数・複素数とも一様な ULP の仕様はなく、オプション付き形式が推定誤差を返す。

## 実数の Gamma 関数の評価法

実数の `gamma`、`ln_gamma`、`digamma` は、binary64 で評価して結果の型へ一度だけ丸める固定計算コストの核を使う。
binary32 の引数も binary64 で評価する。
固定計算コストなので、これらにはスコープ付き API がない。

`gamma` は引数の領域で方法を分ける。

| 引数の範囲 | 方法 |
|---|---|
| 整数 $x = 1, \dots, 21$ | 階乗の表の正確な値 |
| $0 < x < 0.5$ | 漸化式 $\Gamma(x) = \Gamma(x+1)/x$ |
| $0.5 \le x < 16$ | 漸化式で $[1, 2]$ へ移し、Cephes の有理近似を評価する |
| $16 \le x \le 171.625$ | Stirling 級数。補正 $\exp(\cdot) - 1$ の 18 次の多項式を使い、省いた最初の項は $2 \times 10^{-23}$ 未満 |
| $x > 171.625$ | オーバーフロー |
| $-0.5 < x < 0$ | 漸化式 $\Gamma(x) = \Gamma(x+1)/x$ |
| $-16 < x \le -0.5$ | 反射公式 $\Gamma(x) = \pi / [\sin(\pi x)\,(-x)\,\Gamma(-x)]$ |
| $-200 \le x \le -16$ | 反射公式。$\Gamma(-x)$ を Lanczos 近似の有理形で表し、冪と指数を 2 の冪で尺度化した積の比として作る |
| $x < -200$ | 値は binary64 の範囲を下回り、符号付きの 0 になる |

`ln_gamma` は値の大きさでなく零点の位置に合わせて分ける。
$x \ge 16$ では Stirling 級数を使う。
$1 \le x < 3$ へ漸化式で移したあとは $[1, 1.5]$、$(1.5, 2)$、$(2, 3)$ の三つの区間の有理近似を使い、区間に近い零点の因子（$[1, 2]$ では $(x-1)(x-2)$、$(2, 3)$ では $x - 2$）を括り出して相対精度を保つ。
$0.5 \le x < 1$ では零点 1 の近くの近似を $x - 1$ のまま評価し、$x < 0.5$ では $\ln\Gamma(x+1) - \ln x$、$x < 10^{-16}$ では $-\ln x$ を使う。
負の $x$ では、$x \le -8$ で反射公式の三つの項の打ち消しが小さいときだけ binary64 の反射公式を使う。
それ以外は double-word で計算し、$x > -32$ では漸化式で $[0, 1)$ へ移し、それより左では反射公式の $\sin$ を級数で作る。
$\ln|\Gamma(x)|$ の零点は負の軸にも並ぶので、反射公式の引き算をそこで避けるためである。

`digamma` は $x \ge 16$ で漸近展開 $\psi(x) \sim \ln x - \frac{1}{2x} - \sum_{k \ge 1} \frac{B_{2k}}{2k\,x^{2k}}$（DLMF 5.11.2）を 8 項まで使う。
それより小さい正の $x$ は漸化式で $[1, 2]$ へ移し、正の零点 $x_0 \approx 1.4616$ からの変位 $x - x_0$ を因子にした有理近似で評価する。
$x_0$ は 3 ワードに分けた定数で引くので、零点の近くでも相対精度を保つ。
負の $x$ では反射公式を使い、その誤差は $\psi$ の値でなく二つの項の大きさ $|\psi(1-x)| + |\pi\cot(\pi x)|$ に比例する。
したがって負の軸の零点の近くでは相対精度が落ちる。

`polygamma` は、正の $x$ では Hurwitz 級数の最初の項を直接足し、残りを Euler–Maclaurin の和公式で補う（いずれも double-word）。
直接足す項数は、$n \le 4$ では引数が 16 に届くまでの $\lceil 16 - x\rceil$ 項、それ以外では $n + 16$ 項である。
$n!$ を 2 の冪で尺度化して掛ける分も含めて計算量は次数 $n$ に比例して増え、`GammaOptions` の作業量の上限に数えられる。
負の $x$ では反射公式の $\frac{d^n}{dz^n}\cot(\pi z)$ を、$n \le 20$ では $\cot$ の多項式として、$n > 20$ では極に向けて対にした部分分数の和として作る。
どちらも作業領域の大きさは $n$ によらない。

### Stirling 級数

$x \ge 16$ で使う Stirling 級数は、Euler–Maclaurin の和公式から導かれる漸近展開である（DLMF 5.11.1）。

$$
\ln \Gamma(x) \sim \left( x - \frac{1}{2} \right) \ln x - x + \frac{1}{2} \ln(2\pi) + \sum_{k=1}^\infty \frac{B_{2k}}{2k(2k-1)\, x^{2k-1}}
$$

$B_{2k}$ は Bernoulli 数（$B_2 = 1/6$、$B_4 = -1/30$、$B_6 = 1/42$、…）で、最初の補正は次のとおりである。

$$
\ln \Gamma(x) = \left( x - \frac{1}{2} \right) \ln x - x + \frac{1}{2} \ln(2\pi) + \frac{1}{12x} - \frac{1}{360x^3} + \frac{1}{1260x^5} - \cdots
$$

この級数は発散する。
$x$ を固定して項を増やすと、項はいったん小さくなったあと増え始める。
$x > 0$ の実数では、打ち切ったあとの誤差は省いた最初の項より小さく、同じ符号を持つ（DLMF 5.11(ii)）。
$x$ が大きいほど少ない項で binary64 の精度に届くので、実装は $x \ge 16$ だけでこの級数を使い、それより左は漸化式で移す。
漸化式で $x$ を右へ移すと、乗算の丸め誤差が少し加わる代わりに、級数の打ち切り誤差が速く減る。

次のセルは Stirling 級数の部分和を手で計算し、`ln_gamma` の値を参照としてその誤差を描く。
入力は描画を始める $x_0$ で、横軸は $x_0$ から $x_0 + 40$ までの対数軸である。
表は $x = x_0, 2x_0, 4x_0, 8x_0$ での部分和の誤差と、省いた最初の項の大きさを並べる。
誤差が省いた最初の項より小さければ、上の誤差の評価と合う。

```rust
//| id: special-gamma-stirling
//| ref: special-gamma-stirling
//| title: Stirling 級数の部分和と ln Γ(x) の差を比べる
//| run: reactive
//| crates: [scioxide-core, scioxide-special]
//| inputs:
//|   minimum_x: {"type":"range","label":"描画を始める x₀ [-]","description":"部分和を比べる引数の範囲を右へ動かす。","min":1,"max":20,"step":1,"value":3}
//| cases:
//|   - {"id":"handoff","label":"x₀ = 16","description":"実装が Stirling 級数に切り替える位置から比べる。","inputs":{"minimum_x":16}}
//|   - {"id":"small","label":"x₀ = 1","description":"小さい x では補正を足しても誤差がなかなか減らない。","inputs":{"minimum_x":1}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"errors","path":"/rows/0/1","approx":{"value":2.7678e-2,"rtol":1e-3}}
//|       - {"artifact":"errors","path":"/rows/0/3","approx":{"value":9.9852e-5,"rtol":1e-3}}
//|       - {"artifact":"errors","path":"/rows/3/5","range":{"max":1e-10}}
//|   - case: handoff
//|     expect:
//|       - {"artifact":"errors","path":"/rows/0/5","range":{"max":1.3e-9}}
//|       - {"artifact":"errors","path":"/rows/0/6","approx":{"value":7.5688e-10,"rtol":1e-3}}
//|   - case: small
//|     expect:
//|       - {"artifact":"errors","path":"/rows/0/1","approx":{"value":8.1061e-2,"rtol":1e-3}}
use scioxide_core::RealScalar;
use scioxide_special::ln_gamma;

let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let half_log_two_pi = 0.5 * RealScalar::ln(2.0 * std::f64::consts::PI);
// 補正項の係数 B₂ₖ/(2k(2k−1)) = 1/12, −1/360, 1/1260, −1/1680。
let coefficients = [1.0 / 12.0, -1.0 / 360.0, 1.0 / 1260.0, -1.0 / 1680.0];
// 補正を terms 項まで足した部分和（手計算。ln_gamma と比べる対象）。
let partial = |x: f64, terms: usize| -> f64 {
    let mut value = (x - 0.5) * RealScalar::ln(x) - x + half_log_two_pi;
    for (k, c) in coefficients.iter().take(terms).enumerate() {
        value += c / RealScalar::powi(x, 2 * k as i32 + 1);
    }
    value
};
// 省いた最初の項の大きさ。
let omitted = |x: f64, terms: usize| -> f64 {
    coefficients[terms].abs() / RealScalar::powi(x, 2 * terms as i32 + 1)
};

let names = ["主部のみ", "1/(12x) まで", "1/(360x³) まで"];
let mut series = Vec::new();
let mut dropped = 0; // 誤差がちょうど 0 で対数軸に描けない点の数
for terms in 0..3 {
    let mut measured = Vec::new();
    let mut theory = Vec::new();
    for index in 0..=64 {
        let x = minimum_x + 40.0 * f64::from(index) / 64.0;
        let error = (partial(x, terms) - ln_gamma(x).map_err(|e| e.to_string())?).abs();
        if error > 0.0 {
            measured.push([x, error]);
        } else {
            dropped += 1;
        }
        theory.push([x, omitted(x, terms)]);
    }
    series.push(serde_json::json!({ "name": names[terms], "points": measured }));
    series.push(serde_json::json!({
        "name": format!("省いた項（{}）", names[terms]),
        "points": theory,
        "style": { "lineType": "dashed" }
    }));
}
emit_line_chart!(
    &series,
    options = &serde_json::json!({
        "xLabel": "引数 x [-]",
        "yLabel": "ln Γ(x) との差 [-]",
        "xType": "log",
        "yType": "log"
    })
);

let mut rows = Vec::new();
for scale in [1.0, 2.0, 4.0, 8.0] {
    let x = minimum_x * scale;
    let reference = ln_gamma(x).map_err(|e| e.to_string())?;
    let error = |terms: usize| (partial(x, terms) - reference).abs();
    rows.push((
        x,
        error(0),
        omitted(x, 0),
        error(1),
        omitted(x, 1),
        error(2),
        omitted(x, 2),
    ));
}
let columns = serde_json::json!([
    { "key": "0", "label": "x [-]", "type": "number", "format": { "significantDigits": 3 } },
    { "key": "1", "label": "主部の誤差 [-]", "type": "number", "format": sci3 },
    { "key": "2", "label": "1/(12x) [-]", "type": "number", "format": sci3 },
    { "key": "3", "label": "1 項補正の誤差 [-]", "type": "number", "format": sci3 },
    { "key": "4", "label": "1/(360x³) [-]", "type": "number", "format": sci3 },
    { "key": "5", "label": "2 項補正の誤差 [-]", "type": "number", "format": sci3 },
    { "key": "6", "label": "1/(1260x⁵) [-]", "type": "number", "format": sci3 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "errors" })
);
emit_text!(format!("誤差がちょうど 0 で図から除いた点: {dropped} 点"));
```

既定の $x_0 = 3$ では、主部の誤差 $2.77 \times 10^{-2}$ は $1/(12x) = 2.78 \times 10^{-2}$ とほぼ等しく、$1/(12x)$ まで足すと誤差は $9.99 \times 10^{-5}$ に下がって $1/(360x^3) = 1.03 \times 10^{-4}$ を下回る。
表のどの列でも誤差は省いた最初の項より小さく、$x$ を 2 倍にすると、三つの列の誤差はそれぞれ約 1/2、1/8、1/32 になる。
これは打ち切り誤差が $x^{-1}$、$x^{-3}$、$x^{-5}$ に比例することと合う。

$x_0 = 16$ から始めると、$x = 128$ の 2 項補正の誤差 $5.68 \times 10^{-14}$ が省いた項 $2.31 \times 10^{-14}$ を上回る。
この誤差は $\ln\Gamma(128) \approx 491.6$ の位置の 1 ULP（$2^{-44} \approx 5.68 \times 10^{-14}$）で、部分和と `ln_gamma` の丸めの差が打ち切り誤差より大きくなっている。
図の曲線も大きな $x$ ではこの丸めの高さで平らになる。
$x_0 = 1$ では、$x = 1$ の 2 項補正の誤差 $5.06 \times 10^{-4}$ は主部の誤差 $8.11 \times 10^{-2}$ の約 1/160 にとどまる。
小さい $x$ では項を足しても誤差が十分に減らないので、実装は漸化式で $x \ge 16$ へ移してから級数を使う。

## 複素数の Gamma 関数と Lanczos 近似

複素数の `gamma`、`ln_gamma`、`digamma` は、$\operatorname{Re} z \ge 1/2$ で Lanczos 近似を対数の形で評価する。
$y = z - 1$ とし、$g = 6.024680040776729583740234375$ と 13 個の係数 $c_0, \dots, c_{12}$ で

$$
\log\Gamma(y+1) = \tfrac{1}{2}\ln(2\pi) + \left(y + \tfrac{1}{2}\right)\log\left(y + g + \tfrac{1}{2}\right) - \left(y + g + \tfrac{1}{2}\right) + \log\left[c_0 + \sum_{k=1}^{12}\frac{c_k}{y + k}\right]
$$

と計算する。
この $g$ は Boost.Math の 13 項の近似（`lanczos13m53`）と同じ値で、係数 $c_k$ はその有理関数を部分分数に分けて $\sqrt{2\pi}$ で割ったものである。
実数の核の反射公式（$x \le -16$）と不完全 Gamma 関数の前因子は、同じ近似を有理関数の形で使う。
$\operatorname{Re} z < 1/2$ では反射公式を使い、$\log\sin(\pi z)$ は主値で丸めずに連続な分枝を保つ。
主値の対数を使うと、負の軸に沿って $\log\Gamma$ の $2\pi$ の回転が失われるからである。
`gamma` は $\exp(\log\Gamma(z))$ を返し、`digamma` は同じ近似の導関数を返す。
複素数の `polygamma` は Hurwitz zeta 関数を使う（[Riemann・Hurwitz ゼータ関数と Dirichlet eta 関数](../zeta-functions/)）。
複素数の引数には一様な ULP の仕様はなく、オプション付き形式が推定誤差を返す。

## 精度の保証

実数の引数について、照合データ（独立に高精度で生成した参照値）で確かめた ULP の目標は次のとおりである。
ULP は結果の位置での隣り合う浮動小数点数の間隔で、目標は試験した範囲で成り立つ。

| 関数（実数） | binary64 | binary32 | 補足 |
|---|---|---|---|
| `gamma`、`ln_gamma`、`digamma`、`polygamma` | 4 ULP | 1 ULP | 4 160 点の標本での最大は 3.7、1.9、2.1、0.7 ULP。`ln_gamma` は零点の近くも含む |
| `digamma`、`polygamma` の $x < 0$ | 項の大きさの 4 単位 | — | 反射公式の項の絶対値の和に対する絶対誤差。零点の近くで相対精度が落ちる |
| `pochhammer`、`pochhammer_relative` | 一様な仕様なし | 一様な仕様なし | 独立な参照値と恒等式で試験し、オプション付き形式が推定誤差を返す |

4 160 点の標本の最大値は試験した範囲で測った値であり、目標の範囲を広げるものではない。
不完全 Gamma 関数とその逆関数の目標は [不完全 Gamma 関数](oxref:special-incgamma-accuracy) にある。
複素数の引数には一様な ULP の仕様はなく、オプション付き形式の推定誤差（`ValueWithError` の誤差。
包含区間ではない）を使う。

## API

| 関数 | 標準形式の引数 | オプション付き形式 | スコープ付き API | 複素数 | 値 |
|---|---|---|---|---|---|
| `gamma` | `x` | `gamma_with_options` | なし | 可 | $\Gamma(x)$ |
| `ln_gamma` | `x` | `ln_gamma_with_options` | なし | 可 | $\ln\lvert\Gamma(x)\rvert$、複素数では $\log\Gamma(z)$ |
| `digamma` | `x` | `digamma_with_options` | なし | 可 | $\psi(x)$ |
| `polygamma` | `order: usize, z` | `polygamma_with_options` | `polygamma_scoped` | 可 | $\psi^{(n)}(z)$ |
| `pochhammer` | `a, x` | `pochhammer_with_options` | なし | 可 | $(a)_x$ |
| `pochhammer_relative` | `a, x` | `pochhammer_relative_with_options` | なし | 可 | $((a)_x - 1)/x$ |

標準形式は値だけを返し、オプション付き形式はオプションを受け取って `SpecialFunctionResult` を返す。
オプション付き形式の結果には、通常値と推定誤差、尺度化した値、対数形、終了状態、アルゴリズムの識別子、計算量の計数が入り、通常値は標準形式の値とビット単位で一致する。
スコープ付き API はオプション付き形式と同じ結果を返し、計算量を親の実行コンテキストに入れ子の計数として渡し、親の取り消しと期限に従う。
固定計算コストで評価する `gamma`、`ln_gamma`、`digamma`、`pochhammer`、`pochhammer_relative` にはスコープ付き API がない。

オプション付き形式のオプションは Gamma 関数と polygamma 関数では `GammaOptions`、Pochhammer 記号では `CombinatorialOptions` である。
どちらも作業量の上限（`Budget`）だけを持ち、既定は 65 536 単位で、`GammaOptions::new(budget)` か `with_iteration_budget` で変える。
上限は精度の要求ではなく、上限に達した評価は `ConvergenceFailure` になる。
固定計算コストの関数も、決まった計算量が上限を超えれば評価を始めずに同じエラーを返す。

## まとめと次に読むページ

$\Gamma(x)$ は binary64 で $x \approx 171.62$ を超えるとあふれるので、大きな引数や比の計算では `ln_gamma` かオプション付き形式の符号付きの対数形を使う。
実数の Gamma 関数族は零点と極の位置に合わせて有理近似、Stirling 級数、反射公式を使い分け、試験した範囲で binary64 の 4 ULP を目標にする。
負の実軸の digamma と polygamma は反射公式の項の打ち消しで零点の近くの相対精度が落ちるので、推定誤差を項の大きさに対する絶対誤差として解釈する。
Pochhammer 記号は $a + x$ を丸めずに Gamma 関数の比を対数の上で作り、$x \to 0$ の差 $((a)_x - 1)/x$ は `pochhammer_relative` で求める。
積分を区切った不完全 Gamma 関数と Gamma 分布の分位点は [不完全 Gamma 関数](../incomplete-gamma/) で、Beta 関数は [Beta 関数と正則化不完全 Beta 関数](../beta-and-error-functions/) で、引数が整数の階乗と二項係数は [階乗と二項係数](../combinatorial-numbers/) で確かめる。
