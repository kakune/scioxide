超幾何級数は、指数関数、対数、逆三角関数から Legendre 関数、Bessel 関数、不完全ベータ・ガンマ関数までの多くの関数を特別な場合として含む。
特殊関数の多くの公式を超幾何関数の形に直せるので、他のページで扱う関数の値を検算したり、専用の関数のない組み合わせを評価したりするときにこのページに来る。
定義の級数は限られた領域でしか収束しないか、収束が遅いか、項が打ち消し合うので、実装は変換公式、接続公式、微分方程式に沿った数値的な接続で領域を分ける。
このページは超幾何級数の構造と、関数ごとに領域をどう分けるか、精度の保証、API を説明し、二つのセルで $_2F_1$ の領域と $_1F_1$ の打ち消しを確かめる。
Riemann ゼータ関数と Hurwitz ゼータ関数は [Riemann・Hurwitz ゼータ関数と Dirichlet eta 関数](../zeta-functions/) で扱う。

## 一般化超幾何級数

一般化超幾何関数 $_pF_q$ は Pochhammer 記号（上昇階乗）$(a)_k = a(a+1)\cdots(a+k-1) = \Gamma(a+k)/\Gamma(a)$ を使った級数で定義される（DLMF 16.2.1）。

$$
{}_pF_q(a_1, \ldots, a_p; b_1, \ldots, b_q; z) = \sum_{k=0}^{\infty} \frac{(a_1)_k \cdots (a_p)_k}{(b_1)_k \cdots (b_q)_k}\,\frac{z^k}{k!}
$$

$a_i$ を分子のパラメータ、$b_j$ を分母のパラメータと呼ぶ。
隣り合う項の比は次の有理関数なので、各項を前の項から $O(p + q)$ の手間で作れる。

$$
\frac{t_{k+1}}{t_k} = \frac{(a_1 + k)\cdots(a_p + k)}{(b_1 + k)\cdots(b_q + k)}\,\frac{z}{k + 1}
$$

項比は $k \to \infty$ で $z\,k^{p-q-1}$ のように振る舞うので、終わらない級数は $p \le q$ ではすべての $z$ で収束し、$p = q + 1$ では $|z| < 1$ で収束し、$p > q + 1$ では $z \ne 0$ で発散する。
分子のパラメータに非正の整数 $-n$ があれば $(a_i)_k$ は $k > n$ で 0 になり、級数は $n$ 次の多項式で終わる。
分母のパラメータが非正の整数 $-m$ なら $(b_j)_k$ が途中で 0 になって項が定義できず、`DomainError`（`Pole`）になる。
ただし、分子に $-m$ より大きい非正の整数 $-n$ があり、級数が 0 の分母より前で終わる場合は、多項式として評価する。

`hyp_pfq(a, b, z)` は、項を前向きの漸化式で作って補償付きの和（Kahan の方法）で足し、残りの項を項比の上界で押さえた値が丸めの水準を下回ったら止める。
推定誤差は打ち切った裾と、足した項の絶対値の和 $\sum_k |t_k|$ に比例する丸め誤差を合わせたものである。
したがって、項が打ち消し合って和が項より何桁も小さくなると、推定誤差もその分だけ大きくなる。
級数が終わらず、$p = q + 1$ で $|z| \ge 1$ のとき、または $p > q + 1$（$_2F_0$ を除く）のときは `DomainError`（`OutsideDomain`）を返す。
$_0F_1$、$_1F_1$、$_2F_1$、$_2F_0$ の形では、下で説明する名前付きの関数と同じ接続を使うので、級数の収束域の外でも値が求まる。

## 名前付きの関数と関係式

実用上は、次の低次の族に専用の評価と解析接続がある。

| 関数 | 定義と主な関係 | 収束域と切断 |
|---|---|---|
| `hyp0f1(b, z)` | $_0F_1(;b;z)$。$J_\nu(x) = \frac{(x/2)^\nu}{\Gamma(\nu+1)}\,{}_0F_1(;\nu+1;-x^2/4)$（DLMF 10.16.9） | 整関数、切断なし |
| `hyp1f1(a, b, z)` | Kummer の関数 $M(a, b, z) = {}_1F_1(a;b;z)$。Kummer の変換 $M(a,b,z) = e^{z}M(b-a,b,-z)$（DLMF 13.2.39） | 整関数、切断なし |
| `hyperu(a, b, z)` | Tricomi の関数 $U(a,b,z) = \frac{1}{\Gamma(a)}\int_0^\infty e^{-zt}t^{a-1}(1+t)^{b-a-1}dt$（DLMF 13.4.4）。$U \sim z^{-a}$ | 切断 $(-\infty, 0]$ |
| `hyp2f0(a, b, z)` | $_2F_0(a,b;;z) = (-1/z)^{a}U(a, 1+a-b, -1/z)$（DLMF 13.6.21） | 級数は漸近級数。実数の型は $z < 0$ |
| `hyp2f1(a, b, c, z)` | Gauss の関数 $_2F_1(a,b;c;z)$。$z = 1$ で Gauss の和 $\frac{\Gamma(c)\Gamma(c-a-b)}{\Gamma(c-a)\Gamma(c-b)}$（$c - a - b > 0$） | $\lvert z\rvert < 1$、切断 $[1, \infty)$ |
| `hyp2f1_regularized(a, b, c, z)` | $_2F_1(a,b;c;z)/\Gamma(c)$。$c$ について整関数 | `hyp2f1` と同じ |

$U$ は Kummer の方程式 $zw'' + (b - z)w' - aw = 0$ の、$z \to +\infty$ で $z^{-a}$ のように振る舞う解で、$M$ と組になって一般解を作る。
$M$ が $e^{z}z^{a-b}$ のように増えるのに対し、$U$ は代数的にしか増減しないので、実の正の軸で減る解（極小解）として扱われる。
$U(a, b, 0)$ は $\operatorname{Re} b < 1$ で $\Gamma(1-b)/\Gamma(a-b+1)$ に等しく、$\operatorname{Re} b \ge 1$ では原点が特異点になる。

$_2F_1$ の正則化形は $c = 0, -1, -2, \ldots$ でも有限である。
$c = -m$ では先頭の $m + 1$ 項の係数 $1/\Gamma(c + k)$ が 0 になり、次の式で計算する（DLMF §15.2）。

$$
\frac{{}_2F_1(a, b; -m; z)}{\Gamma(-m)} = \frac{(a)_{m+1}(b)_{m+1}}{(m+1)!}\,z^{m+1}\,{}_2F_1(a+m+1, b+m+1; m+2; z)
$$

## Gauss の超幾何関数の領域の分割

$_2F_1$ の級数は $|z| < 1$ で収束するが、$z$ が 1 に近づくと項比が 1 に近づいて収束が遅くなり、$|z| \ge 1$ では発散する。
そこで、変換公式で原点に近い引数へ写すか、$1/z$ の級数の組に接続するか、微分方程式を数値的に解いて値を運ぶ。

Pfaff の変換（DLMF 15.8.1）は、引数を $w = z/(z-1)$ に写す。

$$
{}_2F_1(a, b; c; z) = (1-z)^{-a}\,{}_2F_1\!\left(a, c-b; c; \frac{z}{z-1}\right) = (1-z)^{-b}\,{}_2F_1\!\left(c-a, b; c; \frac{z}{z-1}\right)
$$

$z \in [-9, -1/2)$ は $w \in [1/3, 9/10)$ に写る。
$z$ が負の大きな値になるほど $w$ は 1 に近づき、変換後の級数も遅くなる。
$z < -9$ では、$1/z$ の級数二つに分ける接続公式（DLMF 15.8.2）を使う。

$$
\frac{{}_2F_1(a,b;c;z)}{\Gamma(c)} = \frac{\Gamma(b-a)\,(-z)^{-a}}{\Gamma(b)\Gamma(c-a)}\,\frac{{}_2F_1(a, a-c+1; a-b+1; 1/z)}{\Gamma(a-b+1)} + (a \leftrightarrow b)
$$

$|1/z| < 1/9$ なので級数は速く収束するが、$b - a$ が整数に近いと $\Gamma(b-a)$ と $\Gamma(a-b+1)$ の極が近づき、二つの項が大きな値の差になる。
$b - a$ がちょうど整数 $m$ のときは、極を解析的に打ち消した対数を含む極限の公式（DLMF 15.8.8）を使い、$\ln(-z)$ とディガンマ関数の項を、逆ガンマ関数の零と組にして計算する。

$z = 1$ の近くでは、項比が 1 に近づくうえ、$c - a - b$ が小さいと $z = 1$ での値そのものが大きくなる。
実数の型では、この領域を $1 - z$ の接続公式ではなく、超幾何微分方程式 $z(1-z)w'' + (c - (a+b+1)z)w' - abw = 0$ の Taylor 法による数値的な接続で扱う。
目標の $z$ と同じ符号の $z_0 = \pm 1/4$ で級数とその導関数（隣接関係式 $\frac{d}{dz}{}_2F_1 = \frac{ab}{c}\,{}_2F_1(a+1,b+1;c+1;z)$）を求め、Taylor 級数で値と導関数を2 ワードの算術で何段か進めて、目標の $z$ まで運ぶ。
刻みは特異点 $z = 1$ に近づくほど小さくなるので、$1 - z$ が小さいほど計算コストが増える。

実数の型の `hyp2f1` は次のように方法を選ぶ。
識別子はオプション付き形式の `algorithm().method()` が返す名前である。

| 条件 | 方法 | 識別子 |
|---|---|---|
| $a$ か $b$ が非正の整数 | 多項式（打ち消しが解けなければ補償付きの核） | `real_series` |
| $a = c$ または $b = c$ | $(1-z)^{-b}$ または $(1-z)^{-a}$ | `parameter_identity` |
| $a = b = 1$、$c = 2$、$z < 1$ | $-\ln(1-z)/z$ を `ln_1p` で作る | `logarithmic_identity` |
| $-1/2 \le z \le 0.9$ | 級数を2 ワードの算術で足す | `real_series` |
| $-9 \le z < -1/2$ | Pfaff の変換の後の級数 | `real_pfaff_series` |
| $z < -9$、$b - a$ が整数 | 対数を含む $1/z$ の接続（DLMF 15.8.8） | `real_integer_reciprocal` |
| $z < -9$、$\lvert\sin \pi(b-a)\rvert > 0.01$ | $1/z$ の接続（DLMF 15.8.2） | `real_reciprocal_connection` |
| $z < -9$、$b - a$ が整数に近い非整数 | 微分方程式の Taylor 接続 | `real_taylor_continuation` |
| $0.9 < z < 1$ | 微分方程式の Taylor 接続 | `real_taylor_continuation` |
| $z = 1$、$c - a - b > 0$ | Gauss の和 | `real_gauss_endpoint` |
| $z = 1$、$c - a - b \le 0$ | `DomainError`（`OutsideDomain`） | なし |
| $z > 1$、級数が終わらない | `DomainError`（`OutsideDomain`） | なし |

Pfaff の変換では、二つの形のうち変換したあと最初の項比が小さくなる方を選び、終わる形があればそれを使う。
級数は先頭の項を2 ワードの算術で足し、残りの項の丸めが結果に届かなくなったら binary64 に切り替えて、相対 $2^{-57}$ の裾まで足す。
2 ワードでも解けない打ち消しが残れば、同じ領域を補償付きの核（パラメータの方向も2 ワードで運ぶ核）で計算し直す。

実数の型で $z > 1$ の値が必要なら、複素数の型で呼ぶ。
複素数の $z$ は切断 $[1, \infty)$ を持つ平面に接続され、切断の上では虚部の 0 の符号が側を選ぶ（$2 + 0i$ と $2 - 0i$ で虚部の符号が逆の値になる）。
複素数の評価は $|1 - z| \le 0.1$ で $1 - z$ の接続公式（整数の $c - a - b$ では対数を含む極限）、$|z| > 4$ で $b - a$ が整数から離れていれば $1/z$ の接続、$|z| < 0.7$ で級数、それ以外で微分方程式の接続を使う。

## 合流型の関数

### 1F1

`hyp1f1` は、$a = b$ なら $e^{z}$ を返し、それ以外は級数を2 ワードの算術で足す。
$z < -1$ では、$M(a,b,z)$ の級数の項は符号が交互に変わり、途中の項が $e^{|z|}$ 程度まで育ってから打ち消し合う。
そこで Kummer の変換 $M(a,b,z) = e^{z}M(b-a,b,-z)$ で、正の引数の級数に直してから足す。
$b > a > 0$ なら変換後の級数の項はすべて正で、打ち消しが起きない。

$|z| > 40 + 2(|a| + |b|)$ では、補償付きの核が漸近展開（正の側は指数的な項と代数的な項の二つ、負の側は Kummer の変換の後の代数的な項）を試し、推定誤差が $8\varepsilon|M|$ 以下なら採用する。
2 ワードの算術でも打ち消しを解けないときは、4 ワード、8 ワード、16 ワードの展開の算術で級数を足し直し、それでも解けなければ `NumericalInstability`（`LossOfSignificance`）を返す。

### U と 2F0

実数の `hyperu` は次の順に方法を選ぶ。
$a$ が非正の整数なら $U$ は $z$ の多項式である。
$z = 0$ は $\operatorname{Re} b < 1$ のとき原点の値を返し、それ以外は `OutsideDomain` である。
$b = a + 1$ なら $U = z^{-a}$（DLMF 13.6.4）を返す。
大きな $z$ では漸近展開 $U \sim z^{-a}\sum_n (a)_n(a-b+1)_n(-1/z)^n/n!$（DLMF 13.7.3）を、最小の項が十分小さいときに採用する。
$z < 2$ で $b$ が整数でなければ、$M$ の二つの級数による接続 $U = \frac{\Gamma(1-b)}{\Gamma(a-b+1)}M(a,b,z) + \frac{\Gamma(b-1)}{\Gamma(a)}z^{1-b}M(a-b+1,2-b,z)$（DLMF 13.2.42）を試し、二つの項の絶対値の和が $|U|$ の 4 倍以下（打ち消しが小さい）なら採用する。
それ以外では、Kummer の変換 $U(a,b,z) = z^{1-b}U(1+a-b, 2-b, z)$（DLMF 13.2.40）で $b \ge 1$ にし、$a$ についての三項漸化式（DLMF 13.3.7）を後ろ向きに進めて極小解の比 $U(a+1)/U(a)$ を求め、$M$ と $U$ の Wronskian（DLMF 13.2.34）で正規化する。
前向きに進めると増える解 $M$ が混ざって誤差が育つが、後ろ向きなら極小解が支配的になるので安定である。
$z < 2$ では、微分方程式の Taylor 法で値と導関数を原点の側へ運ぶ。
$|a| > 64$、$b > 12$、$z < 2^{-40}$ のように漸化式と接続の範囲を外れる入力は、複素数の核（積分表示の数値積分など）に回す。

`hyp2f0` は、$a$ か $b$ が非正の整数なら多項式を足し、$z < 0$ では $(-1/z)^{a}U(a, 1+a-b, -1/z)$ を計算する。
このとき $-1/z$ と $1 + a - b$ の丸めが値を動かす分を、導関数による一次の感度で推定誤差に加える。
$|z|$ が `f64::MAX` の逆数より小さい負の数では $-1/z$ がオーバーフローするので、級数の先頭 $1 + abz$ を使い、それで足りないパラメータでは `LossOfSignificance` を返す。

### 0F1

`hyp0f1` は、$z \ge -128$ で級数を足し、打ち消しを解けない負の引数では Bessel 関数との関係 $_0F_1(;b;z) = \Gamma(b)(-z)^{(1-b)/2}J_{b-1}(2\sqrt{-z})$ を使う。
$b < 1/2$ では反射公式で負の次数を $J$ と $Y$ の組に直す。
$\sqrt{-z}$ を丸めると振動の位相がずれるので、$\sqrt{-z}$ の丸めの残差を Bessel 関数の導関数で補正してから値を作る。
この経路の推定誤差は Bessel 関数の核の照合データで包含を確かめた推定（`StatisticallyCalibrated`）である。

### 複素数の引数

複素数の $z$ では、$_0F_1$ は $\operatorname{Re} z < -8$ か $|\operatorname{Im} z| > 12$ で微分方程式を積分し、それ以外は級数を足す。
$_1F_1$ は大きな $|z|$ で漸近展開、$\operatorname{Re} z < -8$ で Kummer の変換、$|z| < 8$ か正の実軸の近くで級数、それ以外で微分方程式の接続を使う。
パラメータは実数のまま、$z$ だけ複素数で渡せる（`impl Parameter<T>`）。

## 精度の保証と推定誤差

独立に生成した高精度の参照値で確かめた精度の目標は次のとおりである。

| 関数 | 目標 | 補足 |
|---|---|---|
| 実数の `hyp0f1`、`hyp1f1`、`hyp2f1`、`hyperu` | binary32 と binary64 で 64 ULP | 零点の近くは絶対誤差の上界。$_1F_1$ は条件数 1000 以下の入力で相対誤差 $10^{-12}$ 未満 |
| `hyp_pfq`（上の形を除く）、`hyp2f0`、`hyp2f1_regularized` | 一様な目標なし | 推定誤差を独立な高精度の参照値と照合する |
| 複素数の引数、パラメータについての導関数 | 一様な目標なし | $_1F_1$ は $\lvert z\rvert = 10^4$ までの全位相、$_2F_1$ は $z = 1$ から $10^{-15}$ の距離までを試験する |

ULP は結果の型で隣り合う浮動小数点数の間隔を単位にした誤差で、零点の近くでは相対誤差が意味を失うので絶対誤差の上界で評価する。
推定誤差は、級数の打ち切り、2 ワードの算術の丸めのモデル、接続公式の各項の誤差を合計した推定で、包含が保証された区間ではない。
2 ワードの算術や展開の算術でも解けない打ち消しは、精度の落ちた値を返さずに `NumericalInstability`（`LossOfSignificance`）のエラーにする。

## 超幾何関数の API

| 項目 | 種類 | 内容 |
|---|---|---|
| `hyp0f1`、`hyp1f1`、`hyp2f1`、`hyp2f1_regularized`、`hyp2f0`、`hyperu` | 関数 | 標準形式。パラメータは `impl Parameter<T>`、引数は `T: NumericScalar` |
| `hyp0f1_with_options`、`hyp1f1_with_options`、`hyp2f1_with_options`、`hyp2f1_regularized_with_options`、`hyp2f0_with_options`、`hyperu_with_options` | 関数 | オプション付き形式。`HypergeometricOptions` を受け取り、値、推定誤差、$z$ についての導関数を返す |
| `hyp0f1_scoped`、`hyp1f1_scoped`、`hyp2f1_scoped`、`hyp2f1_regularized_scoped`、`hyp2f0_scoped`、`hyperu_scoped` | 関数 | スコープ付き API。`SolveScope` の中で計算量を数える |
| `hyp_pfq`、`hyp_pfq_with_options`、`hyp_pfq_scoped` | 関数 | 一般の $_pF_q$。パラメータを `&[T]` の切片で渡す。オプション付き形式は導関数を持たない |
| `HypergeometricFunction` | 構造体 | 検査済みのパラメータを保持して多くの $z$ で評価する。正則化した $_pF_q$ と一次の導関数を加える |
| `HypergeometricWorkspace` | 構造体 | `evaluate_scoped` が使う $O(p+q)$ の作業領域 |
| `HypergeometricFamily` | 列挙型 | `Pfq` か `U`。`HypergeometricFunction::family()` が返す |
| `HypergeometricDerivative` | 列挙型 | `None`、`Argument`、`Numerator(i)`、`Denominator(i)`（添字は 0 始まり） |
| `HypergeometricOptions` | 構造体 | 作業量の上限。既定は 65536 単位 |

名前付きの関数では、オプション付き形式 `f_with_options(.., options)` が標準形式と同じ値に推定誤差、終了状態、計算量の計数、アルゴリズムの識別子を添え、$z$ についての導関数を別に計算して加える。
実数の引数では導関数を隣接関係式（$_pF_q$ では $\frac{\prod a_i}{\prod b_j}\,{}_pF_q(a+1;b+1;z)$、$U$ では $-aU(a+1,b+1,z)$）で求め、複素数の引数では値と同じ核で $z$ 方向の微分を運ぶ。
導関数の定義域は値より狭いことがあり、$_2F_1$ の $z = 1$ の導関数は $c - a - b > 1$ を必要とする。
スコープ付き API `f_scoped(.., options, scope)` はオプション付き形式と同じ計算を呼び出し元の `SolveScope` の中で行い、取り消しと期限を確かめる。

一般の $_pF_q$ は Plan を作らずに `hyp_pfq(&a, &b, z)` で一回ずつ呼ぶ。
同じパラメータで多くの $z$ を評価するとき、正則化した $_pF_q$ が欲しいとき、パラメータについての導関数が欲しいときは、`HypergeometricFunction` を使う。
`HypergeometricFunction::pfq(&numerator, &denominator, regularized, options)` はパラメータを検査して $O(p+q)$ のメモリに保持するだけで、ほかに前計算はしない。
`HypergeometricFunction::u(a, b, options)` は Tricomi の $U$ を保持する。
`evaluate(z, derivative)` は呼び出しごとに作業領域を確保し、`workspace()` で作った `HypergeometricWorkspace` を `evaluate_scoped(z, derivative, &mut workspace, scope)` に渡すと確保をしない。
パラメータについての導関数は差分ではなく、値と一方向の微分を組にして同じ計算の中で運ぶ解析的な導関数（前進型の自動微分）である。
正則化形では分母の $(b_j)_k$ を $\Gamma(b_j + k)$ に置き換えるので、値は $\prod_j \Gamma(b_j)$ で割ったものになり、非正の整数の $b_j$ でも有限である。
導関数の添字がパラメータの数以上（添字は 0 始まり）か、作業領域の大きさがパラメータの数に合わなければ `InvalidInput`（`OutOfRange`）を返す。

## Gauss の 2F1 の領域と閉形式

次のセルは閉形式を持つ二つのパラメータの組で、$z$ を $-10^6$ から 1 の直前まで動かし、`hyp2f1_with_options` の値、選ばれた方法、推定誤差、計算量の計数を並べる。
一つ目の組は $_2F_1(\frac12, 1; \frac32; z)$ で、$z = -x^2$ では $\arctan x / x$、$z = x^2$ では $\operatorname{artanh} x / x$ になる（DLMF 15.4.2、15.4.3）。
$b - a = 1/2$ なので、$z < -9$ では通常の $1/z$ の接続が選ばれる。
二つ目の組は $_2F_1(1, 2; 3; z) = 2(-\ln(1-z) - z)/z^2$ で、$b - a = 1$ が整数なので対数を含む接続が選ばれる。
どちらも $c - a - b = 0$ なので $z = 1$ は定義域の外で、最後の行はそのエラーを示す。
閉形式は f64 の標準関数で計算し、$1 - z$ は入力から正確に作る（$z$ が 1 に近いとき、$\ln(1-z)$ の丸めを避けるため）。

```rust
//| id: special-hyp2f1-connection-regions
//| ref: special-hyp2f1-connection-regions
//| title: Gauss の 2F1 の領域ごとの方法と閉形式との差
//| run: reactive
//| crates: [scioxide-special, scioxide-core]
//| inputs:
//|   family: {"type":"select","label":"パラメータの組","options":[{"label":"(1/2, 1; 3/2)：arctan と artanh","value":"arctan"},{"label":"(1, 2; 3)：対数","value":"log"}],"value":"arctan"}
//|   nearest_exponent: {"type":"range","label":"1 − z の最小値の指数 p（1 − z = 10^p）","description":"最後の行の z を 1 にどこまで近づけるかを決める。","min":-12,"max":-2,"step":1,"value":-9}
//| cases:
//|   - {"id":"logarithmic","label":"(1, 2; 3)","description":"b − a が整数なので、z < −9 で対数を含む接続が選ばれる。","inputs":{"family":"log"}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"regions","path":"/rows/0/1","equals":"real_reciprocal_connection"}
//|       - {"artifact":"regions","path":"/rows/0/4","range":{"max":1e-14}}
//|       - {"artifact":"regions","path":"/rows/5/1","equals":"real_pfaff_series"}
//|       - {"artifact":"regions","path":"/rows/13/1","equals":"real_taylor_continuation"}
//|       - {"artifact":"regions","path":"/rows/13/4","range":{"max":1e-14}}
//|       - {"artifact":"regions","path":"/rows/14/1","equals":"DomainError（OutsideDomain）"}
//|       - {"artifact":"regions","path":"/rows/14/2","equals":null}
//|   - case: logarithmic
//|     expect:
//|       - {"artifact":"regions","path":"/rows/0/1","equals":"real_integer_reciprocal"}
//|       - {"artifact":"regions","path":"/rows/0/4","range":{"max":1e-14}}
//|       - {"artifact":"regions","path":"/rows/13/4","range":{"max":1e-14}}
use scioxide_core::SciOxideErrorView;
use scioxide_special::hyp2f1_with_options;

let (a, b, c) = if family == "log" {
    (1.0, 2.0, 3.0)
} else {
    (0.5, 1.0, 1.5)
};
// 閉形式（f64 の標準関数による参照値）。w = 1 − z は z ∈ [1/2, 2] なら Sterbenz の補題で正確。
let closed_form = |z: f64, w: f64| {
    if family == "log" {
        2.0 * (-w.ln() - z) / (z * z)
    } else if z < 0.0 {
        let t = (-z).sqrt();
        t.atan() / t
    } else {
        // artanh(s) = (ln(1 + s) − ln(1 − s))/2、1 − s = (1 − z)/(1 + s)。
        let s = z.sqrt();
        0.5 * (s.ln_1p() - (w / (1.0 + s)).ln()) / s
    }
};

let last = 10.0_f64.powf(nearest_exponent);
let mut points = vec![
    -1e6, -1e3, -50.0, -9.5, -9.0, -3.0, -0.75, -0.3, 0.3, 0.6, 0.9, 0.95, 0.99,
];
points.push(1.0 - last);

let mut rows = Vec::new();
for z in points {
    let result =
        hyp2f1_with_options(a, b, c, z, Default::default()).map_err(|e| e.to_string())?;
    let value = result.value().ok_or("値が通常の範囲にない")?;
    let exact = closed_form(z, 1.0 - z);
    rows.push((
        z,
        result.algorithm().method().to_string(),
        Some(*value.value()),
        Some(exact),
        Some(((value.value() - exact) / exact).abs()),
        Some(value.absolute_error() / value.value().abs()),
        Some(result.counts().iterations() as f64),
    ));
}
// z = 1 は c − a − b = 0 なので定義域の外。エラーの分類を表に残す。
let edge = match hyp2f1_with_options(a, b, c, 1.0, Default::default()) {
    Ok(_) => return Err("z = 1 で値が返った".to_string()),
    Err(e) => match e.view() {
        SciOxideErrorView::DomainError { reason, .. } => format!("{:?}（{reason:?}）", e.kind()),
        _ => return Err(e.to_string()),
    },
};
rows.push((1.0, edge, None, None, None, None, None));

let sig17 = serde_json::json!({ "significantDigits": 17 });
let sig6 = serde_json::json!({ "notation": "scientific", "significantDigits": 6 });
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let count = serde_json::json!({ "fractionDigits": 0 });
let columns = serde_json::json!([
    { "key": "0", "label": "z [-]", "type": "number", "format": sig17 },
    { "key": "1", "label": "方法" },
    { "key": "2", "label": "2F1 [-]", "type": "number", "format": sig6, "nullText": "なし" },
    { "key": "3", "label": "閉形式 [-]", "type": "number", "format": sig6, "nullText": "なし" },
    { "key": "4", "label": "相対差 [-]", "type": "number", "format": sci3, "nullText": "なし" },
    { "key": "5", "label": "推定した相対誤差 [-]", "type": "number", "format": sci3, "nullText": "なし" },
    { "key": "6", "label": "計算量 [単位]", "type": "number", "format": count, "nullText": "なし" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "regions" })
);
```

既定の組 $(\frac12, 1; \frac32)$ では、閉形式との相対差は全行で $1.5 \times 10^{-16}$ 以下で、$z = -10^6$ から $z = 1 - 10^{-9}$ まで方法が切り替わっても精度は変わらない。
方法の列は、$z \le -9.5$ で `real_reciprocal_connection`、$[-9, -0.75]$ で `real_pfaff_series`、$[-0.3, 0.9]$ で `real_series`、$z \ge 0.95$ で `real_taylor_continuation` になり、上の表の境界どおりである。
推定した相対誤差は、級数と Pfaff の変換で $2.3 \times 10^{-15}$、微分方程式の接続で $3.2 \times 10^{-15}$、$1/z$ の接続で $1.0$〜$1.4 \times 10^{-14}$ で、どの行でも実際の差を上回る。
計算量の列は計算コストの違いを示す。
級数は $z = 0.3$ で 63 単位だが、$z = 0.9$ では項比が 1 に近づいて 705 単位に増える。
$1/z$ の接続は級数自体は短いが、ガンマ関数とその対数を2 ワードで求めるので約 4200 単位かかり、$|z|$ を $10^6$ にしても計算コストはほとんど変わらない。
微分方程式の接続は、$1 - z$ が小さくなるほど刻みが細かくなり、$z = 1 - 10^{-9}$ で 7607 単位を使う。
最後の行は、$c - a - b = 0$ なので $z = 1$ が `DomainError`（`OutsideDomain`）になることを示す。

`logarithmic`（$(1, 2; 3)$）では、$b - a = 1$ が整数なので、$z \le -9.5$ の方法が `real_integer_reciprocal` に変わる。
通常の $1/z$ の接続は $\Gamma(b - a)\Gamma(a - b + 1)$ の極で使えないが、対数を含む極限の公式で、相対差は $2.2 \times 10^{-16}$ 以下に保たれる。
$z = 0.3$ の相対差 $1.4 \times 10^{-15}$ は、閉形式 $2(-\ln(1-z) - z)/z^2$ の引き算で参照値の側が 1 桁ほど失った分である。

## 1F1 の打ち消しと Kummer の変換

$M(a, b, -x)$（$x > 0$）の定義の級数は項の符号が交互に変わり、最大の項はおよそ $e^{x}$ の大きさになるのに、和は $x^{-a}$ 程度しかない。
binary64 で素朴に足すと、相対誤差はおよそ $\varepsilon\sum_k|t_k|/|M|$ になる。
この比 $\sum_k|t_k|/|M|$ を打ち消しの倍率と呼ぶ。

次のセルはパラメータ $a$、$b$ を選び、$z = -1, -5, -10, -20, -30, -40$ で `HypergeometricFunction` の値と $z$ についての導関数を求める。
参照値は Kummer の変換 $M(a,b,z) = e^{z}M(b-a,b,-z)$ の右辺の級数を f64 で足した値である（$b > a$ なら項がすべて正で、打ち消しが起きない）。
導関数の参照値も、同じ変換を微分した $e^{z}[M(b-a,b,-z) - \frac{b-a}{b}M(b-a+1,b+1,-z)]$ を f64 で足して作り、隣接関係式を使う SciOxide の導関数とは独立にする。
`HypergeometricFunction` はパラメータを一度だけ検査して保持し、作業領域を一つ作って `evaluate_scoped` で再利用するので、点ごとの確保は起きない。

```rust
//| id: special-hyp1f1-kummer-cancellation
//| ref: special-hyp1f1-kummer-cancellation
//| title: 1F1 の負の引数での打ち消しと Kummer の変換
//| run: reactive
//| crates: [scioxide-special, scioxide-core]
//| inputs:
//|   a: {"type":"range","label":"分子のパラメータ a","min":0.25,"max":3,"step":0.25,"value":0.5}
//|   b: {"type":"range","label":"分母のパラメータ b","min":0.5,"max":6,"step":0.5,"value":1.5}
//| cases:
//|   - {"id":"b-below-a","label":"a = 3、b = 0.5","description":"b < a では変換後の級数の先頭の項の符号が変わるが、打ち消しは小さい。","inputs":{"a":3,"b":0.5}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"kummer","path":"/rows/5/2","range":{"max":1e-14}}
//|       - {"artifact":"kummer","path":"/rows/5/3","range":{"min":1e-2}}
//|       - {"artifact":"kummer","path":"/rows/5/4","range":{"min":1e15}}
//|       - {"artifact":"kummer","path":"/rows/5/5","range":{"max":1e-12}}
//|   - case: b-below-a
//|     expect:
//|       - {"artifact":"kummer","path":"/rows/5/2","range":{"max":1e-13}}
//|       - {"artifact":"kummer","path":"/rows/5/5","range":{"max":1e-11}}
use scioxide_core::ExecutionContext;
use scioxide_special::{HypergeometricDerivative, HypergeometricFunction};

// 級数 Σ (α)ₖ yᵏ/((β)ₖ k!) を f64 でそのまま足し、和と |項| の和を返す（参照値と比較用）。
let series = |alpha: f64, beta: f64, y: f64| {
    let (mut term, mut sum, mut magnitude) = (1.0_f64, 1.0_f64, 1.0_f64);
    for k in 0..400 {
        let k = k as f64;
        term *= (alpha + k) * y / ((beta + k) * (k + 1.0));
        sum += term;
        magnitude += term.abs();
        if term.abs() <= 1e-18 * sum.abs() && k > y {
            break;
        }
    }
    (sum, magnitude)
};

let function = HypergeometricFunction::pfq(&[a], &[b], false, Default::default())
    .map_err(|e| e.to_string())?;
let mut workspace = function.workspace().map_err(|e| e.to_string())?;
let mut rows = Vec::new();
for x in [1.0_f64, 5.0, 10.0, 20.0, 30.0, 40.0] {
    let z = -x;
    let result = function
        .evaluate_scoped(
            z,
            HypergeometricDerivative::Argument,
            &mut workspace,
            ExecutionContext::sequential(),
        )
        .map_err(|e| e.to_string())?;
    let value = *result.value().ok_or("値がない")?.value();
    let slope = *result.derivative().ok_or("導関数がない")?.value();
    // 参照値: Kummer の変換の右辺（f64 の標準関数による）。
    let reference = z.exp() * series(b - a, b, x).0;
    let reference_slope =
        z.exp() * (series(b - a, b, x).0 - (b - a) / b * series(b - a + 1.0, b + 1.0, x).0);
    // 比較用: 定義の級数を f64 でそのまま足す。
    let (naive, magnitude) = series(a, b, z);
    rows.push((
        z,
        value,
        ((value - reference) / reference).abs(),
        ((naive - reference) / reference).abs(),
        magnitude / reference.abs(),
        ((slope - reference_slope) / reference_slope).abs(),
    ));
}

let sig8 = serde_json::json!({ "notation": "scientific", "significantDigits": 8 });
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let columns = serde_json::json!([
    { "key": "0", "label": "z [-]", "type": "number" },
    { "key": "1", "label": "M(a, b, z) [-]", "type": "number", "format": sig8 },
    { "key": "2", "label": "参照値との相対差 [-]", "type": "number", "format": sci3 },
    { "key": "3", "label": "素朴な級数の相対誤差 [-]", "type": "number", "format": sci3 },
    { "key": "4", "label": "打ち消しの倍率 [-]", "type": "number", "format": sci3 },
    { "key": "5", "label": "dM/dz の相対差 [-]", "type": "number", "format": sci3 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "kummer" })
);
```

既定の $a = 1/2$、$b = 3/2$ では、SciOxide の値の参照値との相対差は $z = -40$ まで $8 \times 10^{-16}$ 以下である。
素朴な級数の相対誤差は、打ち消しの倍率と $\varepsilon$ の積を目安に増え（倍率は $z = -40$ で $2.1 \times 10^{16}$）、$z = -20$ で $5.5 \times 10^{-10}$、$z = -40$ では 18% ずれる。
`hyp1f1` が $z < -1$ で Kummer の変換に切り替える理由は、この倍率である。
導関数の相対差は $z = -40$ で $5.6 \times 10^{-14}$ まで増えるが、これは参照値の側の引き算 $M(b-a,b,-z) - \frac{b-a}{b}M(b-a+1,b+1,-z)$ が $|z|$ 倍ほど桁を失うためで、`b-below-a` の組では同じ点で $1.8 \times 10^{-15}$ にとどまる。
`b-below-a`（$a = 3$、$b = 0.5$）では値が符号を変え、打ち消しの倍率は $z = -40$ で $6 \times 10^{25}$ に達し、素朴な級数は桁が全く残らない。
SciOxide の値の相対差は全行で $3.9 \times 10^{-16}$ 以下である。

## まとめ

実数の `hyp0f1`、`hyp1f1`、`hyp2f1`、`hyperu` は 64 ULP を目標にし、`hyp_pfq` の一般の形、`hyp2f0`、正則化形、複素数の引数には一様な目標がないので、オプション付き形式の推定誤差を読む。
$_2F_1$ は $z \in [-1/2, 0.9]$ で級数、$[-9, -1/2)$ で Pfaff の変換、$z < -9$ で $1/z$ の接続（$b - a$ が整数なら対数を含む形、整数に近ければ微分方程式の接続）、$0.9 < z < 1$ で微分方程式の Taylor 接続を使い、オプション付き形式の `algorithm().method()` で選ばれた方法を確かめられる。
実数の型で $z > 1$ の値が必要なら複素数の型で呼び、虚部の 0 の符号で切断の側を選ぶ。
$_1F_1$ の負の引数では定義の級数が $e^{|z|}$ 倍ほどの打ち消しを起こすので、`hyp1f1` は Kummer の変換で項が正の級数に直してから足す。
同じパラメータで多くの $z$ を評価するときや、正則化形、パラメータについての導関数が必要なときは、`HypergeometricFunction` と作業領域を使う。

Bessel 関数との関係で $_0F_1$ の背後にある漸化式の向きと Miller の方法を確かめるには [円柱 Bessel 関数と Hankel 関数](../airy-bessel-and-hankel/) に進む。
級数の遅い収束を Euler–Maclaurin の和公式と関数等式で扱う例は [Riemann・Hurwitz ゼータ関数と Dirichlet eta 関数](../zeta-functions/) で、項目ごとの仕様は API ガイドの [超幾何関数](../../api/hypergeometric/) で確かめる。
