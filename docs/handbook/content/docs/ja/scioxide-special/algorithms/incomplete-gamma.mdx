不完全 Gamma 関数は Gamma 関数を定義する積分の範囲を $x$ で区切った関数で、Gamma 分布、カイ二乗分布、Poisson 分布の累積確率を与える。
確率として使う正則化形 $P$ と $Q$ は和が 1 になるが、小さい方の確率を $1 - P$ のような引き算で作ると有効数字が失われるので、小さい方を直接計算する必要がある。
このページは不完全 Gamma 関数の定義と定義域、`scioxide-special` が形状 $a$ と比 $x/a$ で選ぶ評価法、非正則化形・対数形・逆関数・複素数の引数、精度の保証、API の使い分けを説明する。
完全な Gamma 関数 $\Gamma(a)$ と $\ln\Gamma(a)$ の評価法は [Gamma 関数・polygamma 関数・Pochhammer 記号](../gamma-family/) で扱い、このページはそれを前提にする。

## 定義と定義域

積分区間を $x$ で区切ると、下側不完全 Gamma 関数 $\gamma(a, x)$ と上側不完全 Gamma 関数 $\Gamma(a, x)$ が得られる（DLMF 8.2.1、8.2.2）。
$a$ を形状母数と呼ぶ。

$$
\gamma(a, x) = \int_0^x t^{a-1} e^{-t} \, dt, \qquad \Gamma(a, x) = \int_x^\infty t^{a-1} e^{-t} \, dt, \qquad \gamma(a, x) + \Gamma(a, x) = \Gamma(a)
$$

確率として使うのは、$\Gamma(a)$ で割った正則化不完全 Gamma 関数 $P$ と $Q$ である（DLMF 8.2.4）。

$$
P(a, x) = \frac{\gamma(a, x)}{\Gamma(a)}, \qquad Q(a, x) = \frac{\Gamma(a, x)}{\Gamma(a)}, \qquad P + Q = 1
$$

$P(a, x)$ は形状 $a$、尺度 1 の Gamma 分布の累積分布関数で、$Q(a, x)$ はその生存関数（上側確率）である。

実数の `gamma_p` と `gamma_q` は $a \ge 0$、$x \ge 0$ を受け付ける。
$a < 0$ か $x < 0$ は `DomainError`（`OutsideDomain`）、NaN と無限大は `NonFinite` になる。
$x = 0$ では $P = 0$、$Q = 1$ を返し、終了状態は `Exact` である。
$x > 0$ を固定した $a \to 0$ の極限 $P(0, x) = 1$、$Q(0, x) = 0$ を返し、このとき終了状態は `Limit` である。
原点 $(a, x) = (0, 0)$ では近づき方で極限が変わるので、`DomainError`（`Undefined`）になる。

非正則化の `gamma_lower(a, x)` は $\gamma(a, x)$、`gamma_upper(a, x)` は $\Gamma(a, x)$ を返す。
`gamma_lower` は実数の $a > 0$ を要求し、$a = 0$ は `DomainError`（`Pole`）、$a < 0$ と $x < 0$ は `DomainError`（`OutsideDomain`）になる。
`gamma_upper` は $a = 0$ も受け付け、$\Gamma(0, x) = E_1(x)$（指数積分、DLMF 8.4.4）を指数積分と同じ評価で返す（[指数積分と対数積分](../exponential-and-trigonometric-integrals/)）。
$\Gamma(0, 0)$ は `DomainError`（`Pole`）である。

## 小さい方の裾を直接計算する理由

$P + Q = 1$ は恒等式だが、$Q \ll 1$ の領域で $Q = 1 - P$ と引き算すると打ち消しが起きる。
$P$ の丸め誤差は $P$ の大きさ 1 に対して $2^{-53}$ の程度なので、$Q = 10^{-10}$ なら $1 - P$ の相対誤差は $10^{-6}$ の程度になり、$Q < 10^{-16}$ では 0 になる。
そこで実数の `gamma_p` と `gamma_q` は共通の評価器で一方の裾を直接計算し、もう一方だけを $1 - (\text{直接計算した裾})$ で作る。
直接計算するのは各方法が精度よく計算できる裾で、どの方法でも小さい側の裾になるように方法の領域を分けている。
大きい方は 1 に近いので、この引き算は精度を失わない。
オプション付き形式のアルゴリズムの識別子から方法が分かり、Temme の展開以外の方法は直接計算する裾が決まっている。
Temme の展開は $x < a$ なら $P$、$x \ge a$ なら $Q$ を直接計算する。

## 評価法の選択

評価器は次の順に条件を調べ、最初に当てはまる方法を使う。
括弧の中はオプション付き形式の `algorithm()` に残る識別子の後半である。

1. $a = 1$ では閉形式 $P = -\operatorname{expm1}(-x)$、$Q = e^{-x}$ を使う（`unit_exponential`）。
2. $a = 1/2$ では $P = \operatorname{erf}\sqrt{x}$、$Q = \operatorname{erfc}\sqrt{x}$ を使う（`half_integer_erf_erfc`）。
3. $a < 1$、$x \le 2$、$x^a > 1/2$ では、$1/a$ の極を解析的に打ち消した級数で $Q$ を計算する（`small_shape_upper_series`、DLMF 8.7.3 の変形）。

   $$
   \Gamma(a, x) = \frac{\Gamma(1+a) - x^a}{a} - x^a \sum_{k \ge 1} \frac{(-x)^k}{k!\,(a+k)}
   $$

   $a \to 0$ では $\Gamma(a)$ と $x^a/a$ がどちらも $1/a$ のように発散して打ち消すので、差 $\Gamma(1+a) - x^a$ を先に作ってから $a$ で割る。
4. $2a$ が 65 以下の整数（$a \le 32.5$ の整数と半整数）で、$a \le x \le -\ln(\text{MIN\_POSITIVE}) \approx 708.4$（$e^{-x}$ が正規化数の範囲）なら、有限和で $Q$ を計算する（`integer_upper_finite`、`half_integer_upper_finite`、DLMF §8.4 と漸化式 8.8.2）。

   $$
   Q(n, x) = e^{-x}\sum_{k=0}^{n-1}\frac{x^k}{k!}, \qquad Q\left(n + \tfrac{1}{2}, x\right) = \operatorname{erfc}\sqrt{x} + e^{-x}\sum_{k=0}^{n-1}\frac{x^{k+1/2}}{\Gamma\left(k + \tfrac{3}{2}\right)}
   $$

   すべての項が正なので、$Q$ の大きさによらず打ち消しが起きない。
   作業量の上限の残りが項数に足りないときは、この方法を飛ばして次へ進む。
5. $a > 20$ で $x$ が $a$ に近い遷移帯では、Temme の一様漸近展開（DLMF 8.12）で小さい方の裾を計算する（`temme_transition`）。
   帯は $-\ell a < x - a < 0.4a$ で、$\ell$ は $a < 100$ で $0.25$、$a \ge 100$ で $0.4$ である。
6. 残りの $x < a$ では、補償付きの和（Kahan の加算）で冪級数（DLMF 8.7.1 の形）を足して $P$ を計算する（`lower_compensated_series`）。

   $$
   P(a, x) = \frac{x^a e^{-x}}{\Gamma(a)} \sum_{n=0}^\infty \frac{x^n}{a(a+1)\cdots(a+n)}
   $$

7. 残りの $x \ge a$ では、Legendre の連分数（DLMF 8.9.2）を偶数次の部分で縮約した形を修正 Lentz 法で前から評価し、$Q$ を計算する（`upper_scaled_lentz`）。

   $$
   Q(a, x) = \frac{x^a e^{-x}}{\Gamma(a)} \cdot \cfrac{1}{x + 1 - a - \cfrac{1\cdot(1-a)}{x + 3 - a - \cfrac{2\cdot(2-a)}{x + 5 - a - \cdots}}}
   $$

冪級数の項の比は $x/(a+n)$ なので、$x < a$ では初めから項が減る。
連分数は $x \ge a$ で速く収束する。
両者だけで $a \approx x$ の大きな形状を扱うと項数が $\sqrt{a}$ に比例して増えるので、そこを Temme の展開が受け持つ。
Temme の展開は $\lambda = x/a$、$\eta = \operatorname{sign}(\lambda - 1)\sqrt{2(\lambda - 1 - \ln\lambda)}$ を使い、裾を $\frac{1}{2}\operatorname{erfc}(\lvert\eta\rvert\sqrt{a/2})$ と補正の級数で表す。
実装は $e^{a\eta^2/2}$ で尺度化した $\operatorname{erfcx}$ と、補正の係数 $c_k(\eta)$ の Taylor 多項式を使い、$1/a$ の冪の 10 項で打ち切る。
帯の下端を $a < 100$ で $x - a > -0.25a$ に狭めるのは、係数の Taylor 多項式の打ち切りを $\lvert\eta\rvert < 0.28$ の範囲に収めるためである。
$a > 20$ では、帯の外の冪級数は 170 項程度、連分数は 20 段程度で収束するので、計算量は $a$ とともに増えない。

冪級数と連分数に掛かる前因子 $x^a e^{-x}/\Gamma(a)$ は、$\Gamma(a)$ を Lanczos 近似の有理形 $L_g(a)$ で表し、$t = a + g - 1/2$ として

$$
\frac{x^a e^{-x}}{\Gamma(a)} = \left(\frac{x}{t}\right)^a e^{t - x} \frac{\sqrt{t}}{L_g(a)}
$$

の対数を作ってから指数を取る。
$g$ は完全な Gamma 関数の Lanczos 近似と同じ定数で、$L_g(a)$ は $\Gamma(a) = L_g(a)\,t^{a-1/2}e^{-t}$ を満たす有理関数である。
$a\ln x$ と $\ln\Gamma(a)$ を別々に計算して引くと、大きな $a$ で二つの大きな対数の差になって桁が落ちるが、比 $x/t$ の対数なら打ち消しがない。
$a \le 32$ で $a\lvert\ln(x/t)\rvert \le 16$ のときだけ対数を binary64 で取り、それ以外は 2 ワードの浮動小数点数（double-word）で作る。

修正 Lentz 法は、分母が 0 に近づいたときに小さな値（$\text{MIN\_POSITIVE}/\varepsilon$）で置き換えて 0 除算を避け、隣り合う近似の比が 1 から $\varepsilon/2$ 以内になったら止まる。
冪級数は、項が和の $\varepsilon$ 倍以下になり、残りの項を等比級数で抑えた上界も十分に小さくなったら止まる。

各方法の項と段は作業量として数えられ、`GammaOptions` の上限（既定 65 536）を超えると `ConvergenceFailure` になる。
選ばれた方法はオプション付き形式の `algorithm()` に `gamma/upper_scaled_lentz@1` のような識別子で残り、計算量は `counts().iterations()` で読める。

## 評価法の選択を確かめる

次のセルは形状 $a$ を選び、$x = 0.2a$ から $5a$ までの 9 点で `gamma_q_with_options` が選んだ方法、計算量の計数、$Q$、$\ln Q$ を表にする。
独立な検算として、上の評価法の境界をまたいで成り立つ漸化式（DLMF 8.8.6）

$$
Q(a + 1, x) = Q(a, x) + \frac{x^a e^{-x}}{\Gamma(a+1)}
$$

の相対残差を出す。
$Q(a+1, x)$ と $Q(a, x)$ は別の方法で評価されることが多いので、一方の誤りは残差に現れる。
右辺の第 2 項は `ln_gamma` で $\exp(a\ln x - x - \ln\Gamma(a+1))$ として手で計算するので、指数の各項の丸めで、この項には最大で $\varepsilon(\lvert a\ln x\rvert + x + \ln\Gamma(a+1))$ 程度の相対誤差が入り、残差はこの大きさまで増えうる。
図は $x/a$ を横軸、$Q$ を対数の縦軸にとり、方法ごとに点を分けて、評価法が切り替わる位置を示す。

```rust
//| id: special-gamma-incomplete-regions
//| ref: special-gamma-incomplete-regions
//| title: 不完全 Gamma の評価法の選択と漸化式による検算
//| run: reactive
//| crates: [scioxide-core, scioxide-special]
//| inputs:
//|   shape: {"type":"range","label":"形状 a [-]","description":"評価法の境界が x/a のどこにあるかを変える。","min":0.5,"max":200,"step":0.5,"value":40}
//| cases:
//|   - {"id":"lattice","label":"a = 4","description":"整数の形状では x ≥ a が有限和になる。","inputs":{"shape":4}}
//|   - {"id":"half","label":"a = 0.5","description":"P と Q は erf と erfc で計算される。","inputs":{"shape":0.5}}
//|   - {"id":"large","label":"a = 150","description":"Temme の帯が x − a > −0.4a まで広がる。","inputs":{"shape":150}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"regions","path":"/rows/2/2","equals":"gamma/lower_compensated_series@1"}
//|       - {"artifact":"regions","path":"/rows/3/2","equals":"gamma/temme_transition@1"}
//|       - {"artifact":"regions","path":"/rows/7/2","equals":"gamma/upper_scaled_lentz@1"}
//|       - {"artifact":"regions","path":"/rows/4/4","approx":{"value":4.789e-1,"rtol":1e-3}}
//|       - {"artifact":"regions","path":"/rows/8/7","range":{"max":1e-13}}
//|       - {"artifact":"regions","path":"/rows/4/7","range":{"max":1e-14}}
//|   - case: lattice
//|     expect:
//|       - {"artifact":"regions","path":"/rows/6/2","equals":"gamma/integer_upper_finite@1"}
//|       - {"artifact":"regions","path":"/rows/8/7","range":{"max":1e-14}}
//|   - case: half
//|     expect:
//|       - {"artifact":"regions","path":"/rows/0/2","equals":"gamma/half_integer_erf_erfc@1"}
//|       - {"artifact":"regions","path":"/rows/4/7","range":{"max":1e-15}}
//|   - case: large
//|     expect:
//|       - {"artifact":"regions","path":"/rows/2/2","equals":"gamma/temme_transition@1"}
//|       - {"artifact":"regions","path":"/rows/4/7","range":{"max":1e-13}}
//|       - {"artifact":"regions","path":"/rows/8/7","range":{"max":1e-12}}
use scioxide_core::RealScalar;
use scioxide_special::{GammaOptions, gamma_log_q, gamma_q, gamma_q_with_options, ln_gamma};

let a = shape;
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let fixed3 = serde_json::json!({ "significantDigits": 4 });
let log_shift = ln_gamma(a + 1.0).map_err(|e| e.to_string())?;
let mut rows = Vec::new();
for ratio in [0.2, 0.5, 0.7, 0.95, 1.0, 1.05, 1.3, 2.0, 5.0] {
    let x = ratio * a;
    let detailed =
        gamma_q_with_options(a, x, GammaOptions::default()).map_err(|e| e.to_string())?;
    let method = detailed.algorithm().to_string();
    let terms = detailed.counts().iterations();
    let q = detailed.try_value().map_err(|e| e.to_string())?;
    let log_q = gamma_log_q(a, x).map_err(|e| e.to_string())?;
    let next = gamma_q(a + 1.0, x).map_err(|e| e.to_string())?;
    // 漸化式の項 x^a e^(−x) / Γ(a + 1)（手計算の独立検算）。
    let step = RealScalar::exp(a * RealScalar::ln(x) - x - log_shift);
    let residual = (next - q - step).abs() / next;
    rows.push((ratio, x, method, terms, q, log_q, next, residual));

        .iter()
        .filter(|row| &row.2 == method && row.4 > 0.0)
        .map(|row| [row.0, row.4])
        .collect();
    layers.push(serde_json::json!({
        "id": method,
        "kind": "scatter",
        "name": method,
        "points": points
    }));
}
emit_chart!(serde_json::json!({

    "xLabel": "x / a [-]",
    "yLabel": "Q(a, x) [-]",
    "xType": "log",
    "yType": "log",

    "annotations": [{ "kind": "line", "axis": "x", "value": 1.0, "label": "x = a" }]
}));

let columns = serde_json::json!([
    { "key": "0", "label": "x / a [-]", "type": "number", "format": fixed3 },
    { "key": "1", "label": "x [-]", "type": "number", "format": fixed3 },
    { "key": "2", "label": "方法（Q のオプション付き形式）" },
    { "key": "3", "label": "計算量 [-]", "type": "integer" },
    { "key": "4", "label": "Q(a, x) [-]", "type": "number", "format": sci3 },
    { "key": "5", "label": "ln Q(a, x) [-]", "type": "number", "format": fixed3 },
    { "key": "6", "label": "Q(a+1, x) [-]", "type": "number", "format": sci3 },
    { "key": "7", "label": "漸化式の相対残差 [-]", "type": "number", "format": sci3 }

    metadata = serde_json::json!({ "id": "regions" })

```

既定の $a = 40$ では、$x/a = 0.2, 0.5, 0.7$ が冪級数、$0.95$ から $1.3$ が Temme の展開、$2$ と $5$ が連分数になり、$Q$ は 1 に近い値から $4.63 \times 10^{-44}$ まで下がる。
$x/a \le 0.7$ では冪級数で $P$ を直接計算し、$Q$ はその補数である。
計算量は冪級数と連分数では項と段の数で、Temme の展開では打ち切りの項数 10 がそのまま数えられる。
漸化式の相対残差はすべて $1.4 \times 10^{-14}$ 以下で、評価法の境界をまたいで組み合わせた $Q(a, x)$ と $Q(a+1, x)$ も丸め誤差の程度で一致する。
残差が $x/a$ とともに $10^{-17}$ から $10^{-14}$ の程度へ増えるのは、検算の指数 $a\ln x - x - \ln\Gamma(a+1)$ の大きさが増え、手計算の項の丸め誤差が増えるためである。

$a = 4$ では、$x \ge a$ の 5 点が 4 項の有限和（`gamma/integer_upper_finite@1`）になる。
$a = 0.5$ では、すべての点で $\operatorname{erf}$ と $\operatorname{erfc}$ を使う。
$a = 150$ では Temme の帯の下端が $x - a > -0.4a$ に広がり、$x/a = 0.7$ も Temme の展開になる。
このとき $x = 750$ の行の残差は $5.5 \times 10^{-14}$ まで増えるが、検算の指数に現れる項の大きさの和が $2.3 \times 10^3$ になるためで、見積もり $\varepsilon \cdot 2.3 \times 10^3 \approx 5 \times 10^{-13}$ を超えない。
残差がこの見積もりを桁で超えたら、評価法の選択か検算の式を疑う。

## 非正則化形

`gamma_lower` と `gamma_upper` は正則化した裾の対数 $\ln P$ か $\ln Q$ に $\ln\Gamma(a)$ を double-word で足し、最後に一度だけ指数を取る。
$\Gamma(a)$ が binary64 の範囲を超える大きな $a$ でも、値そのものが範囲に収まれば通常値を返す。
裾の対数には、上の評価器と別に用意した、対数の裾を作る共通の手続きを使う。
この手続きは Temme の帯では Temme の展開を使い、帯の外では $x < a + 1$ で冪級数（$\ln P$）、それ以外で連分数（$\ln Q$）を使う。
有限和と閉形式の近道は使わない。
求める側と反対の裾を計算したときは、$\ln(1 - e^{\ell})$ を打ち消しなしに計算して向きを変える。

例外が三つある。
$x = 0$ では $\gamma(a, 0) = 0$ と $\Gamma(a, 0) = \Gamma(a)$ を返す。
`gamma_upper` の $a \le 1/2$、$x \le 1$ では、評価法の選択の 3 番目と同じ $1/a$ の極を打ち消した級数で $\Gamma(a, x)$ を直接計算する（`upper_small_shape_series`）。
`gamma_upper` の $a = 0$ は上で述べた $E_1(x)$ である。

値が binary64 の範囲を超える場合は `NumericalInstability`（`Overflow`）になる。
オプション付き形式はこのときもエラーにならず、通常値への射影の状態がオーバーフローになって、対数形 `logarithmic()` に $\ln\Gamma(a, x)$ が残る。

## 対数形と逆関数

確率が binary64 の範囲を下回る裾には、$P$ や $Q$ を作らずに対数を返す `gamma_log_p(a, x)` と `gamma_log_q(a, x)` を使う。
二つはまず、対数を取らない binary64 の値で求める側の裾を計算する。
これは $a < 128$、$0 < x \le 708$ で前因子 $x^a e^{-x}/\Gamma(a)$ が正規化数の範囲にあるときに限る。
整数と半整数の形状（$a \le 32.5$）の $x \ge a$ では上の有限和、それ以外の $x < a + 1$ では正項の冪級数を使い、推定誤差が受け入れの基準を満たせばその対数を返す。
それができない形状と範囲では上の評価器の $P$ と $Q$ を使い、小さい方の対数を取り、大きい方は $\ln(1 - T)$ を $\operatorname{log1p}$ で打ち消しなしに計算する。
$P$ か $Q$ が正規化数の範囲を下回るときは、非正則化形と同じ対数の裾の手続きを double-word で使う。
オプション付き形式の識別子は `probability/upper_linear_tail@1` のように `probability` で始まる。
$\ln P(a, 0) = -\infty$ と $\ln Q(0, x) = -\infty$ はエラーでなく値として返す。

分位点は $P(a, x) = p$ を解く `gamma_p_inv(a, p)` と $Q(a, x) = q$ を解く `gamma_q_inv(a, q)` で求める。
対数の確率から解く `gamma_p_inv_log(a, ln p)` と `gamma_q_inv_log(a, ln q)` は、$p$ や $q$ が binary64 で表せないほど小さい場合に使う。
どれも $a > 0$ を要求し、$a \le 0$ や範囲外の確率（$[0, 1]$ の外、対数形では正の値）は `DomainError`（`OutsideDomain`）、NaN と無限大（対数形の $-\infty$ を含む）は `NonFinite` になる。
$p = 0$ と $p = 1$ は $x = 0$ と $x = +\infty$ を返す。

逆関数は次のように解く。
$p > 1/2$ なら、binary64 で正確に計算できる $1 - p$ を目標にして反対側の裾を解く。
対数形では $\ln p > -\ln 2$ のときに同じように反対側へ移る。
初期値は、$a > 1$ で目標の確率が $e^{-36}$ より大きいときは正規分布の分位点から作る DiDonato と Morris（1986）の漸近式を使い、それ以外では裾の主要項を解いた値を使う。
そこから $\ln x$ を変数とする Halley 法を、根を挟む区間で保護しながら進める。
最後の段では裾を double-word で評価し、結果の型で隣り合う浮動小数点数の間隔に達したら止まる。
$a = 1$ では閉形式 $x = -\ln(1 - p)$ を使う。
使い方は [待ち時間分布の分位点を逆算する](../../examples/gamma-quantiles/) で示す。

## 複素数の引数

`gamma_p`、`gamma_q`、`gamma_lower`、`gamma_upper` は複素数の引数も受け付け、形状 $a$ を実数、$z$ を複素数にすることもできる。
$z^a$ は主値の冪で、負の実軸を切断とし、虚部の符号で岸を選ぶ。
直接計算する裾は $\lvert z\rvert$ と $\lvert a\rvert$ で決める。
$\lvert z\rvert \le \lvert a\rvert + 1$ と、$\operatorname{Re} z \le 0$ の $\lvert z\rvert \le 40 + 2\lvert a\rvert$ では冪級数で下側の裾を計算する。
$\operatorname{Re} z < 0$ で項が大きく育つときは、Kummer の変換をした形の級数に切り替えて $e^{\lvert z\rvert}$ 程度の項の打ち消しを避ける。
それより外では上側の裾を、右半平面で $\lvert z\rvert > 1$ か $\lvert a\rvert > 1$ なら Legendre の連分数、それ以外では Tricomi の合流型超幾何関数 $U$ で計算する。
もう一方の裾は、引き算の打ち消しが 2 倍以下なら補数で作り、それより大きければ直接計算し直す。
$z \ne 0$ で $a = 0, -1, -2, \dots$ のときは、極限 $P = 1$、$Q = 0$ を返す。
$z = 0$ で $\operatorname{Re} a \le 0$ は `DomainError`（`Undefined`）、ただし $\Gamma(0, 0)$ は `DomainError`（`Pole`）である。
対数形と逆関数は実数だけを受け付ける。

## 精度の保証

実数の引数について、照合データ（独立に高精度で生成した参照値）で確かめた ULP の目標は次のとおりである。
ULP は結果の位置での隣り合う浮動小数点数の間隔で、目標は試験した範囲で成り立つ。

| 関数（実数） | binary64 | binary32 | 補足 |
|---|---|---|---|
| `gamma_p`、`gamma_q`、`gamma_lower`、`gamma_upper`、`gamma_log_p`、`gamma_log_q` | 32 ULP | 1 ULP | $20 < a \le 10^{10}$ の深い裾を含む。より広い 4 160 点の標本では $P$、$Q$ の最大が 90 ULP |
| `gamma_p_inv`、`gamma_q_inv`、`gamma_p_inv_log`、`gamma_q_inv_log` | 32 ULP | 1 ULP | $20 < a \le 10^{10}$ と、出力の浮動小数点数の格子の端の点を含む |

4 160 点の標本の最大値は目標の範囲を広げるものではなく、`gamma_p` と `gamma_q` の 90 ULP が示すように、試験した範囲の外では目標を超える点がある。
binary32 の引数は binary64 で評価して一度だけ丸める。
複素数の引数には一様な ULP の仕様はなく、オプション付き形式の推定誤差（`ValueWithError` の誤差。
包含区間ではない）を使う。

## API

| 関数 | 標準形式の引数 | オプション付き形式 | スコープ付き API | 複素数 | 値 |
|---|---|---|---|---|---|
| `gamma_lower` | `a, x` | `gamma_lower_with_options` | `gamma_lower_scoped` | 可 | $\gamma(a, x)$ |
| `gamma_upper` | `a, x` | `gamma_upper_with_options` | `gamma_upper_scoped` | 可 | $\Gamma(a, x)$ |
| `gamma_p` | `a, x` | `gamma_p_with_options` | `gamma_p_scoped` | 可 | $P(a, x)$ |
| `gamma_q` | `a, x` | `gamma_q_with_options` | `gamma_q_scoped` | 可 | $Q(a, x)$ |
| `gamma_log_p` | `a, x` | `gamma_log_p_with_options` | `gamma_log_p_scoped` | 不可 | $\ln P(a, x)$ |
| `gamma_log_q` | `a, x` | `gamma_log_q_with_options` | `gamma_log_q_scoped` | 不可 | $\ln Q(a, x)$ |
| `gamma_p_inv` | `a, p` | `gamma_p_inv_with_options` | `gamma_p_inv_scoped` | 不可 | $P(a, x) = p$ の $x$ |
| `gamma_q_inv` | `a, q` | `gamma_q_inv_with_options` | `gamma_q_inv_scoped` | 不可 | $Q(a, x) = q$ の $x$ |
| `gamma_p_inv_log` | `a, ln p` | `gamma_p_inv_log_with_options` | `gamma_p_inv_log_scoped` | 不可 | $\ln P(a, x) = \ln p$ の $x$ |
| `gamma_q_inv_log` | `a, ln q` | `gamma_q_inv_log_with_options` | `gamma_q_inv_log_scoped` | 不可 | $\ln Q(a, x) = \ln q$ の $x$ |

標準形式は値だけを返し、オプション付き形式は `GammaOptions` を受け取って `SpecialFunctionResult` を返す。
オプション付き形式の結果には、通常値と推定誤差、尺度化した値、対数形、終了状態、アルゴリズムの識別子、計算量の計数が入り、通常値は標準形式の値とビット単位で一致する。
評価の作業量が引数で変わるので、どの関数もスコープ付き API を持つ。
スコープ付き API はオプション付き形式と同じ結果を返し、計算量を親の実行コンテキストに入れ子の計数として渡し、親の取り消しと期限に従う。

`GammaOptions` は作業量の上限（`Budget`）だけを持ち、既定は 65 536 単位で、`GammaOptions::new(budget)` か `with_iteration_budget` で変える。
上限は精度の要求ではなく、上限に達した評価は `ConvergenceFailure` になる。
`gamma_lower`、`gamma_upper`、`gamma_p`、`gamma_q` の `a` は `impl Parameter<T>` で、実数の形状と複素数の `z` を組み合わせられる。
対数形と逆関数は実数の型 `S: RealScalar` だけを受け付ける。

## まとめと次に読むページ

不完全 Gamma 関数は形状 $a$ と比 $x/a$ で閉形式、有限和、Temme の展開、冪級数、連分数を選び、一方の裾を直接計算してもう一方を補数で作る。
上側の小さな確率は `gamma_q` か `gamma_log_q` で直接求め、$1 - P$ を作らない。
$\Gamma(a)$ があふれる大きな形状でも、`gamma_lower` と `gamma_upper` は対数の上で正規化を戻すので、値が範囲に収まれば通常値を返し、収まらなければオプション付き形式の対数形を使う。
分位点は `gamma_p_inv` と `gamma_q_inv` で求め、確率が binary64 で表せないほど小さい裾は対数形の逆関数に渡す。
分位点の使い方と $1 - q$ の丸めの影響は [待ち時間分布の分位点を逆算する](../../examples/gamma-quantiles/) で、Beta 分布の同じ問題は [Beta 関数と正則化不完全 Beta 関数](../beta-and-error-functions/) で、完全な Gamma 関数の評価法は [Gamma 関数・polygamma 関数・Pochhammer 記号](../gamma-family/) で確かめる。
