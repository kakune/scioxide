非線形振り子の振れ角、Duffing 振動子の自由振動、KdV 方程式の周期解（cnoidal 波）は、Jacobi 楕円関数で閉じた形に書ける。
Jacobi 楕円関数は第一種の不完全楕円積分の逆関数として定義され、母数 $m = 0$ で三角関数、$m = 1$ で双曲線関数になる。
このページは Jacobi 楕円関数の定義と周期、算術幾何平均（AGM）と降下 Landen 変換による評価、$[0, 1]$ の外の実数の母数と複素数の引数の扱い、精度と呼び出しの形を説明する。
母数の規約と完全楕円積分 $K(m)$ は [楕円積分の定義と完全楕円積分 K、E](../elliptic-and-legendre/) が、第一種の不完全楕円積分 $F(\phi \mid m)$ の評価は [Carlson 対称形と不完全楕円積分](../carlson-symmetric-integrals/) が扱う。

## 定義と周期

第一種の不完全楕円積分 $u = F(\phi \mid m)$ を $\phi$ について解いたものが振幅 $\phi = \operatorname{am}(u \mid m)$ で、Jacobi 楕円関数は

$$
\operatorname{sn}(u \mid m) = \sin\phi, \qquad
\operatorname{cn}(u \mid m) = \cos\phi, \qquad
\operatorname{dn}(u \mid m) = \sqrt{1 - m \sin^2\phi}
$$

で定義する（DLMF §22.2、§22.16）。
DLMF は法 $k$ を引数に書くが、`scioxide-special` の関数は母数 $m = k^2$ を受け取る。
$m = 0$ では $\operatorname{sn} = \sin u$、$\operatorname{cn} = \cos u$、$\operatorname{dn} = 1$、$\operatorname{am} = u$ になり、$m = 1$ では $\operatorname{sn} = \tanh u$、$\operatorname{cn} = \operatorname{dn} = \operatorname{sech} u$、$\operatorname{am} = \operatorname{gd} u$ になる。
定義から恒等式

$$
\operatorname{sn}^2 + \operatorname{cn}^2 = 1, \qquad \operatorname{dn}^2 + m \operatorname{sn}^2 = 1, \qquad
\frac{d}{du}\operatorname{sn}(u \mid m) = \operatorname{cn}(u \mid m)\operatorname{dn}(u \mid m)
$$

が成り立つ。
$0 \le m < 1$ の実軸上では $\operatorname{sn}$ と $\operatorname{cn}$ の周期は $4K(m)$、$\operatorname{dn}$ の周期は $2K(m)$ で、$\operatorname{sn}(K \mid m) = 1$、$\operatorname{cn}(K \mid m) = 0$、$\operatorname{dn}(K \mid m) = \sqrt{1 - m}$ である。
$m \le 1$ の $\operatorname{am}$ は連続で増加する実の枝で、$\operatorname{am}(u + 2K \mid m) = \operatorname{am}(u \mid m) + \pi$ を満たす。
`jacobi_sn`、`jacobi_cn`、`jacobi_dn`、`jacobi_amplitude` がこれらを返す。

## AGM と降下 Landen 変換による評価

実数の $0 < m < 1$ では、まず $a_0 = 1$、$b_0 = \sqrt{1 - m}$ の AGM（[算術幾何平均](oxref:special-elliptic-agm)）を $|c_N| \le 2\varepsilon a_N$ まで進め、途中の平均を保存する（$\varepsilon$ は binary64 の機械イプシロン）。
2 次収束なので $N$ は数回で、32 回を超えると `NumericalInstability` になる。
$2K = \pi/a_N$ なので、$u$ を半周期 $2K$ の倍数で還元し、奇数回の還元では $\operatorname{sn}$ と $\operatorname{cn}$ の符号を反転する。
還元後の角 $a_N u$ から、保存した平均を逆にたどる降下 Landen 変換で $\operatorname{sn}$、$\operatorname{cn}$、$\operatorname{dn}$ を復元する。
各段では DLMF 22.20 の逆正弦の式で振幅を戻す。
半周期内の引数をさらに $K/2$ で反射し、$\operatorname{cn}$ が小さい場合も相補的な値から復元する。
振幅は還元の回数 $j$ と $\operatorname{atan2}(\operatorname{sn}, \operatorname{cn})$ から $j\pi + \operatorname{atan2}(\operatorname{sn}, \operatorname{cn})$ として作る。
$m = 0$ と $m = 1$ は上の閉じた形を使い、$|u| < 10^{-154}$ では $\operatorname{sn} = u$ とする。
AGM と降下は binary64 で行い、binary32 の引数も binary64 に広げて評価する。

### すべての実数の母数

実数の母数はすべて受け付ける。
$m < 0$ と $m > 1$ は DLMF §22.17 の実数の変換で $[0, 1]$ の母数へ移す。
$\mu = -m/(1 - m)$ とすると $m < 0$ では

$$
\operatorname{sn}(u \mid m) = \frac{\operatorname{sn}(v \mid \mu)}{\sqrt{1 - m}\,\operatorname{dn}(v \mid \mu)}, \quad
\operatorname{cn}(u \mid m) = \frac{\operatorname{cn}(v \mid \mu)}{\operatorname{dn}(v \mid \mu)}, \quad
\operatorname{dn}(u \mid m) = \frac{1}{\operatorname{dn}(v \mid \mu)}, \qquad v = \sqrt{1 - m}\,u
$$

で、$m > 1$ では $w = \sqrt{m}\,u$ として

$$
\operatorname{sn}(u \mid m) = \frac{\operatorname{sn}(w \mid 1/m)}{\sqrt{m}}, \qquad
\operatorname{cn}(u \mid m) = \operatorname{dn}(w \mid 1/m), \qquad
\operatorname{dn}(u \mid m) = \operatorname{cn}(w \mid 1/m)
$$

である。
したがって $m > 1$ の $\operatorname{sn}$ の実周期は $4K(1/m)/\sqrt{m}$ で、$\operatorname{sn}$ の最大値は $1/\sqrt{m}$、$\operatorname{dn}$ は符号を変える。
$m > 1$ の $\operatorname{am}$ は、この変換が与える実の枝 $\arcsin(\operatorname{sn})$ で、値は $[-\pi/2, \pi/2]$ にとどまる。

### 複素数の引数

複素数の $u$ と実数の $m$ では、実部を母数 $m$、虚部を補母数 $1 - m$ の実数の評価に分け、加法定理（DLMF §22.8）と Jacobi の虚数変換で組み合わせる。
複素数の $m$ はモジュラー変換で母数を還元したあと Jacobi のテータ関数の商（DLMF §20.7、§22.2）で評価する。
複素数の $u$ の関数としては、$\operatorname{sn}$、$\operatorname{cn}$、$\operatorname{dn}$ は $u = 2jK + (2l + 1)iK'$（$K' = K(1 - m)$、$j, l$ は整数）に極を持つ。
極とその近くで値が決まらないときは `DomainError`（`Pole`）か `NumericalInstability`（`LossOfSignificance`）になる。
実数の $u$ と $m$ は有限であればすべて受け付ける。

## 誤差・計算量

実数の引数の計算量は、AGM の段数と降下の段数の和で、AGM の段数の 2 倍程度である。
$[0, 1]$ の外の母数は変換に 1 単位を加える。
数段から十数段で済み、既定の `EllipticOptions` の上限（65536 単位）よりずっと小さい。
推定誤差は、周期の還元の誤差が導関数を通って伝わる分と、降下の各段の丸めを段数に比例して数えたモデルから作り（信頼度 `ModelBased`）、包含区間ではない。
$|u|$ が大きいと、還元した周期の数に比例して推定誤差が増える。

## 精度の保証

| 関数（実数の引数） | binary64 | binary32 | 試験で確かめた内容 |
|---|---|---|---|
| `jacobi_sn`、`jacobi_cn`、`jacobi_dn`、`jacobi_amplitude` | 64 ULP | 64 ULP | `jacobi_sn` の binary64 の測定の中央値は 1.2 ULP 以下（最大値ではない） |

精度は照合データ（独立に生成した高精度の参照値）で試験した範囲についての目標である。
複素数の引数には一様な ULP の仕様はなく、オプション付き形式の推定誤差を使う。

## 関数と呼び出しの形

すべての関数は `NumericScalar`（`f32`、`f64`、`Complex<f32>`、`Complex<f64>`）を受け取り、実数と複素数で同じ名前を使う。
標準形式は値だけを返し、オプション付き形式 `*_with_options(.., options)` は `SpecialFunctionResult` を、スコープ付き API `*_scoped(.., options, scope)` は求解スコープの中で同じ結果を返す。

| 関数 | 標準形式 | オプション付き形式 | スコープ付き API | 定義域（実数の型） |
|---|---|---|---|---|
| $\operatorname{sn}$、$\operatorname{cn}$、$\operatorname{dn}$、$\operatorname{am}$ | `jacobi_sn(u, m)`、`jacobi_cn(u, m)`、`jacobi_dn(u, m)`、`jacobi_amplitude(u, m)` | `jacobi_sn_with_options`、`jacobi_cn_with_options`、`jacobi_dn_with_options`、`jacobi_amplitude_with_options` | `jacobi_sn_scoped`、`jacobi_cn_scoped`、`jacobi_dn_scoped`、`jacobi_amplitude_scoped` | 有限の実数すべて |

オプション付き形式とスコープ付き API は `EllipticOptions`（作業量の上限 `Budget` だけを持ち、既定は 65536 単位）を受け取る。
上限に達すると、途中の値は返らず `ConvergenceFailure`（`IterationLimit`）になる。
オプション付き形式の結果は推定誤差、終了状態（`SpecialFunctionTermination`）、計算量の計数、アルゴリズムの識別子を持つ。
母数は、引数 $u$ が複素数でも実数のまま渡せる（`m: impl Parameter<T>`）。
4 つの関数は同じ AGM と降下を別々に行うので、同じ $(u, m)$ で $\operatorname{sn}$、$\operatorname{cn}$、$\operatorname{dn}$ をすべて求めると、計算量は 3 倍になる。

## Jacobi 楕円関数の周期と母数の変換

次のセルは、母数 $m$ を $-3$ から $3$ まで動かし、$\operatorname{sn}$、$\operatorname{cn}$、$\operatorname{dn}$ を $\operatorname{sn}$ の 1 周期 $P$ にわたって描く。
$P$ は $m < 1$ で $4K(m)$、$m > 1$ で $4K(1/m)/\sqrt{m}$ で、`elliptic_k` から求める。
$m = 1$ では周期がないので、$0 \le u \le 8$ を描く。
縦線は $P/4$、$P/2$、$3P/4$ の位置である。
表は、$u = P/4$ での値を閉じた形（$m \le 1$ では $\operatorname{sn} = 1$、$\operatorname{cn} = 0$、$\operatorname{dn} = \sqrt{1 - m}$、$m > 1$ では $1/\sqrt{m}$、$\sqrt{1 - 1/m}$、$0$）と比べ、$m \le 1$ では $\operatorname{am}(P/2 \mid m) = \pi$ も確かめる。
$P$ は固定計算コストの近似で求めた $K$ から作るので、この比較は AGM による評価とは別のアルゴリズムとの検算になる。
残りの行は 401 点での恒等式の残差の最大と、$\operatorname{sn}$ の中心差分（刻み $10^{-5}$）と $\operatorname{cn}\,\operatorname{dn}$ の差の最大である。
中心差分の誤差は打ち切りの $h^2$ の項と丸めの $\varepsilon/h$ の項の和なので、最後の行は $10^{-10}$ 程度になれば正しい。

```rust
//| id: special-jacobi-periods
//| ref: special-jacobi-periods
//| title: Jacobi 楕円関数の周期と恒等式を母数ごとに確かめる
//| run: reactive
//| crates: [scioxide-special]
//| inputs:
//|   parameter: {"type":"range","label":"母数 m [-]","description":"負の値と 1 を超える値は実数の母数の変換を通る。","min":-3,"max":3,"step":0.05,"value":0.9}
//| cases:
//|   - {"id":"negative","label":"m = −3","description":"虚数の法の変換。dn は 1 から 2 まで増える。","inputs":{"parameter":-3}}
//|   - {"id":"hyperbolic","label":"m = 1","description":"周期がなく、sn = tanh、cn = dn = sech になる。","inputs":{"parameter":1}}
//|   - {"id":"reciprocal","label":"m = 3","description":"逆数の母数への変換。sn の最大は 1/√3 に下がる。","inputs":{"parameter":3}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"checks","path":"/rows/0/1","approx":{"value":10.312368453392693,"rtol":1e-14}}
//|       - {"artifact":"checks","path":"/rows/1/3","range":{"min":-1e-15,"max":1e-15}}
//|       - {"artifact":"checks","path":"/rows/3/3","range":{"min":-1e-15,"max":1e-15}}
//|       - {"artifact":"checks","path":"/rows/4/3","range":{"min":-1e-14,"max":1e-14}}
//|       - {"artifact":"checks","path":"/rows/5/1","range":{"max":1e-14}}
//|       - {"artifact":"checks","path":"/rows/7/1","range":{"max":1e-9}}
//|   - case: negative
//|     expect:
//|       - {"artifact":"checks","path":"/rows/3/1","approx":{"value":2,"rtol":1e-14}}
//|       - {"artifact":"checks","path":"/rows/6/1","range":{"max":1e-14}}
//|   - case: hyperbolic
//|     expect:
//|       - {"artifact":"checks","path":"/rows/0/1","range":{"max":1e-14}}
//|       - {"artifact":"checks","path":"/rows/2/1","range":{"max":1e-9}}
//|   - case: reciprocal
//|     expect:
//|       - {"artifact":"checks","path":"/rows/1/1","approx":{"value":0.5773502691896258,"rtol":1e-14}}
//|       - {"artifact":"checks","path":"/rows/2/3","range":{"min":-1e-15,"max":1e-15}}
//|       - {"artifact":"checks","path":"/rows/3/3","range":{"min":-1e-15,"max":1e-15}}
use scioxide_special::{elliptic_k, jacobi_amplitude, jacobi_cn, jacobi_dn, jacobi_sn};
use std::f64::consts::PI;

let m = parameter;
let digits16 = serde_json::json!({ "significantDigits": 16 });
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
// sn の実周期 P。m ≤ 1 では 4K(m)、m > 1 では 4K(1/m)/√m（逆数の母数への変換）。
// m = 1 では周期がなく、区間 [0, 8] を描く。
let period = if m < 1.0 {
    Some(4.0 * elliptic_k(m).map_err(|e| e.to_string())?)
} else if m > 1.0 {
    Some(4.0 * elliptic_k(1.0 / m).map_err(|e| e.to_string())? / m.sqrt())
} else {
    None
};
let span = period.unwrap_or(8.0);
let (mut sn_points, mut cn_points, mut dn_points) = (Vec::new(), Vec::new(), Vec::new());
let (mut pythagoras, mut modulus, mut derivative) = (0.0_f64, 0.0_f64, 0.0_f64);
let step = 1e-5;
for index in 0..=400 {
    let u = span * f64::from(index) / 400.0;
    let sn = jacobi_sn(u, m).map_err(|e| e.to_string())?;
    let cn = jacobi_cn(u, m).map_err(|e| e.to_string())?;
    let dn = jacobi_dn(u, m).map_err(|e| e.to_string())?;
    pythagoras = pythagoras.max((sn * sn + cn * cn - 1.0).abs());
    modulus = modulus.max((dn * dn + m * sn * sn - 1.0).abs());
    // d sn/du = cn dn を中心差分（誤差 O(h²)）で確かめる。
    let ahead = jacobi_sn(u + step, m).map_err(|e| e.to_string())?;
    let behind = jacobi_sn(u - step, m).map_err(|e| e.to_string())?;
    derivative = derivative.max(((ahead - behind) / (2.0 * step) - cn * dn).abs());
    sn_points.push([u, sn]);
    cn_points.push([u, cn]);
    dn_points.push([u, dn]);
}
let quarters: Vec<_> = (1..4)
    .filter_map(|q| period.map(|p| p * f64::from(q) / 4.0))
    .map(|u| serde_json::json!({ "kind": "line", "axis": "x", "value": u }))
    .collect();
emit_line_chart!(
    &vec![
        serde_json::json!({ "name": "sn(u|m)", "points": sn_points }),
        serde_json::json!({ "name": "cn(u|m)", "points": cn_points }),
        serde_json::json!({ "name": "dn(u|m)", "points": dn_points }),
    ],
    options = &serde_json::json!({
        "xLabel": "u [-]",
        "yLabel": "Jacobi 楕円関数 [-]",
        "xMin": 0.0,
        "xMax": span,
        "yMin": -2.0,
        "yMax": 2.0,
        "annotations": quarters
    })
);

// 4 分の 1 周期での値。期待値は m の範囲ごとの閉じた形。
let mut rows: Vec<(String, f64, Option<f64>, Option<f64>)> = Vec::new();
if let Some(p) = period {
    let quarter = p / 4.0;
    let expected_sn = if m > 1.0 { 1.0 / m.sqrt() } else { 1.0 };
    let expected_cn = if m > 1.0 { (1.0 - 1.0 / m).sqrt() } else { 0.0 };
    let expected_dn = if m > 1.0 { 0.0 } else { (1.0 - m).sqrt() };
    for (name, value, expected) in [
        ("周期 P", p, None),
        (
            "sn(P/4|m)",
            jacobi_sn(quarter, m).map_err(|e| e.to_string())?,
            Some(expected_sn),
        ),
        (
            "cn(P/4|m)",
            jacobi_cn(quarter, m).map_err(|e| e.to_string())?,
            Some(expected_cn),
        ),
        (
            "dn(P/4|m)",
            jacobi_dn(quarter, m).map_err(|e| e.to_string())?,
            Some(expected_dn),
        ),
    ] {
        rows.push((name.into(), value, expected, expected.map(|x| value - x)));
    }
    if m <= 1.0 {
        // am(2K|m) = π（m ≤ 1 の連続な実の枝）。
        let am = jacobi_amplitude(p / 2.0, m).map_err(|e| e.to_string())?;
        rows.push(("am(P/2|m)".into(), am, Some(PI), Some(am - PI)));
    }
}
rows.push(("max |sn² + cn² − 1|".into(), pythagoras, None, None));
rows.push(("max |dn² + m sn² − 1|".into(), modulus, None, None));
rows.push(("max |中心差分 − cn dn|".into(), derivative, None, None));
let columns = serde_json::json!([
    { "key": "0", "label": "量" },
    { "key": "1", "label": "SciOxide の値", "type": "number", "format": digits16 },
    { "key": "2", "label": "閉じた形", "type": "number", "format": digits16, "nullText": "—" },
    { "key": "3", "label": "差", "type": "number", "format": sci3, "nullText": "—" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "checks" })
);
```

既定の $m = 0.9$ では $P = 10.31236845339269$ で、$\operatorname{sn}$ は台形に近い形になり、$\operatorname{dn}$ は $\sqrt{0.1} \approx 0.316$ まで下がって $P/2$ で 1 に戻る。
4 分の 1 周期の値の差は $1.5 \times 10^{-16}$ 以下、$\operatorname{am}(P/2 \mid m)$ と $\pi$ の差は $8.9 \times 10^{-16}$、恒等式の残差は $6.7 \times 10^{-16}$ 以下、中心差分との差は $7.2 \times 10^{-11}$ である。
$m = -3$ では $\operatorname{dn}$ が 1 から $\sqrt{1 - m} = 2$ まで増え、$m = 3$ では $\operatorname{sn}$ の最大が $1/\sqrt{3} \approx 0.577$ に下がり、$\operatorname{dn}$ が符号を変えて $\operatorname{cn}$ の役割を持つ。
$m = 1$ では $\operatorname{sn} = \tanh u$ が 1 へ近づき、$\operatorname{cn}$ と $\operatorname{dn}$ が同じ曲線 $\operatorname{sech} u$ になる。
$\operatorname{dn}^2 + m\operatorname{sn}^2 = 1$ の残差はどの $m$ でも $1.4 \times 10^{-15}$ 以下で、母数の変換が三つの関数を整合したまま移している。

## まとめと次に読むページ

Jacobi 楕円関数には母数 $m = k^2$ を渡し、実数の $u$ と $m$ は有限であればすべて受け付ける。
$0 < m < 1$ は AGM と降下 Landen 変換で評価し、$m < 0$ と $m > 1$ は DLMF §22.17 の変換で $[0, 1]$ へ移す。
$m > 1$ では $\operatorname{sn}$ の最大が $1/\sqrt{m}$ に下がり、$\operatorname{am}$ は $[-\pi/2, \pi/2]$ の枝になるので、$m \le 1$ の連続な振幅とは振る舞いが違う。
実数の引数の仕様は 64 ULP の目標で、複素数の引数ではオプション付き形式の推定誤差を使う。
物理の問題への適用は [大振幅振り子の周期を求める](../../examples/pendulum-period/) で、逆関数である不完全楕円積分は [Carlson 対称形と不完全楕円積分](../carlson-symmetric-integrals/) で、各項目の仕様は [楕円積分の API](../../api/elliptic/) で確かめる。
