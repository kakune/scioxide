導体の円柱に交流電流を流すと、周波数が高いほど電流は表面の近くに集まる（表皮効果）。
その電流分布は引数を $e^{\mathrm{i}\pi/4}$ の向きに回した 0 次の変形 Bessel 関数で書け、その実部と虚部が Kelvin 関数 $\operatorname{ber}$、$\operatorname{bei}$、$\operatorname{ker}$、$\operatorname{kei}$ である。
このページは Kelvin 関数の定義と性質、`scioxide-special` の評価法、尺度化形と導関数、精度の扱い、API の順に説明し、最後に円柱導体の交流抵抗を求める。
$I_0$、$K_0$ の定義と、複素数の引数の Bessel 関数は [円柱 Bessel 関数と Hankel 関数](../airy-bessel-and-hankel/) で説明したものを使う。

## 表皮効果と Kelvin 関数の定義

角周波数 $\omega$ の交流電流が、導電率 $\sigma$、透磁率 $\mu$ の円柱導体を流れるとき、時間因子を $e^{\mathrm{i}\omega t}$（電気工学の慣習）とし、変位電流を無視すると、電流密度の複素振幅 $J(r)$ は次の方程式を満たす。

$$
J'' + \frac{1}{r}J' - \mathrm{i}\,\omega\mu\sigma\,J = 0.
$$

$\delta = \sqrt{2/(\omega\mu\sigma)}$ を表皮深さとすると、原点で正則な解は $J(r) \propto I_0(\sqrt{2}\,e^{\mathrm{i}\pi/4}r/\delta)$ である。
Kelvin 関数はこの 0 次の Bessel 関数の実部と虚部として定義される（DLMF 10.61.1–2）。

$$
\operatorname{ber}x + \mathrm{i}\operatorname{bei}x = I_0(x\,e^{\mathrm{i}\pi/4}) = J_0(x\,e^{3\mathrm{i}\pi/4}), \qquad
\operatorname{ker}x + \mathrm{i}\operatorname{kei}x = K_0(x\,e^{\mathrm{i}\pi/4}).
$$

`scioxide-special` は 0 次の Kelvin 関数だけを提供し、一般の次数 $\operatorname{ber}_\nu$ などは提供しない。
一般の次数が必要なら、$\operatorname{ber}_\nu x + \mathrm{i}\operatorname{bei}_\nu x = J_\nu(x\,e^{3\mathrm{i}\pi/4})$ と $\operatorname{ker}_\nu x + \mathrm{i}\operatorname{kei}_\nu x = e^{-\nu\pi\mathrm{i}/2} K_\nu(x\,e^{\mathrm{i}\pi/4})$（DLMF §10.61）により、複素数の引数の `bessel_j` と `bessel_k` から求める。

### 級数、漸近形、Wronskian

原点の近くでは級数（DLMF 10.65.1）が使える。

$$
\operatorname{ber}x = \sum_{m=0}^{\infty}\frac{(-1)^m (x/2)^{4m}}{[(2m)!]^2}, \qquad
\operatorname{bei}x = \sum_{m=0}^{\infty}\frac{(-1)^m (x/2)^{4m+2}}{[(2m+1)!]^2}.
$$

$\operatorname{ber}$、$\operatorname{bei}$ は偶の整関数で $\operatorname{ber}0 = 1$、$\operatorname{bei}0 = 0$ である。
$\operatorname{ker}$ は $x = 0$ に対数の特異点（$\operatorname{ker}x \sim -\ln(x/2) - \gamma$、$\gamma$ は Euler の定数）を持ち、$\operatorname{kei}$ は $x \ge 0$ で連続で $\operatorname{kei}0 = -\pi/4$ である。
大きな $x$ では、主要項が次の形になる（DLMF 10.67.1–2）。

$$
\operatorname{ber}x + \mathrm{i}\operatorname{bei}x \sim \frac{e^{x/\sqrt{2}}}{\sqrt{2\pi x}}\,e^{\mathrm{i}(x/\sqrt{2} - \pi/8)}, \qquad
\operatorname{ker}x + \mathrm{i}\operatorname{kei}x \sim \sqrt{\frac{\pi}{2x}}\,e^{-x/\sqrt{2}}\,e^{-\mathrm{i}(x/\sqrt{2} + \pi/8)}.
$$

$\operatorname{ber}$、$\operatorname{bei}$ は $e^{x/\sqrt{2}}$ で増大しながら振動し、$\operatorname{ker}$、$\operatorname{kei}$ は $e^{-x/\sqrt{2}}$ で減衰しながら振動する。
$\mathscr{W}\{I_0, K_0\}(z) = -1/z$（DLMF 10.28.2）を $z = x\,e^{\mathrm{i}\pi/4}$ に当てはめると、実部と虚部から次の恒等式が出る。

$$
\operatorname{ber}x\operatorname{ker}'x - \operatorname{ber}'x\operatorname{ker}x - \operatorname{bei}x\operatorname{kei}'x + \operatorname{bei}'x\operatorname{kei}x = -\frac{1}{x}, \qquad
\operatorname{ber}x\operatorname{kei}'x - \operatorname{ber}'x\operatorname{kei}x + \operatorname{bei}x\operatorname{ker}'x - \operatorname{bei}'x\operatorname{ker}x = 0.
$$

## Kelvin 関数の評価法

$\operatorname{ber}$、$\operatorname{bei}$ は $\lvert x\rvert \le 10$ で上の級数を2 ワードの算術（`f64` 二つで約 106 ビットを表す算術）で足す。
級数の項は符号が交互に変わり、$x = 10$ では最大の項が結果の 5〜12 倍に達し、零点の近くでは比がさらに大きくなるので、`f64` だけで足すと打ち消しで桁を失う。
$\lvert x\rvert > 10$ では $I_0(\lvert x\rvert e^{\mathrm{i}\pi/4})$ を、20 未満では級数、20 以上では漸近展開（DLMF 10.67）で求める。
$20 \le \lvert x\rvert < 28$ では、$I_0$ の漸近展開に $K_0$ に比例する指数的に小さい項（$e^{-\sqrt{2}\lvert x\rvert}$ 倍）も加える。
$\operatorname{ker}$、$\operatorname{kei}$ は $K_0(x\,e^{\mathrm{i}\pi/4})$ を、20 未満では対数項を含む級数（DLMF 10.31）を2 ワードの算術で、20 以上では漸近展開で求める。
$\lvert x\rvert < 10^{-150}$ では、複素数の引数の Bessel 関数の一般の核を使う。
導関数 $\operatorname{ber}'$ などは同じ展開から値と一緒に求める。
`berp_with_options` などの導関数のオプション付き形式は `derivative()` に 2 階導関数を返し、それは微分方程式から $\operatorname{ber}'' = -\operatorname{ber}'/x - \operatorname{bei}$、$\operatorname{bei}'' = -\operatorname{bei}'/x + \operatorname{ber}$（$\operatorname{ker}$、$\operatorname{kei}$ も同じ形）で作る。

### 尺度化形と一括評価

尺度化形は増大する関数に $e^{-\lvert x\rvert/\sqrt{2}}$、減衰する関数に $e^{x/\sqrt{2}}$ を掛けた値を返す。
`ber_scaled`、`bei_scaled`、`berp_scaled`、`beip_scaled` は $e^{-\lvert x\rvert/\sqrt{2}}$ を、`ker_scaled`、`kei_scaled`、`kerp_scaled`、`keip_scaled` は $e^{x/\sqrt{2}}$ を掛ける。
`berp_scaled` などは $\operatorname{ber}'$ に因子を掛けた値で、`ber_scaled` の導関数ではない。
$\operatorname{ber}$、$\operatorname{bei}$ と導関数は `f64` で $\lvert x\rvert$ が 1010 前後を超えるとあふれて `NumericalInstability`（`Overflow`）を返すが、尺度化形は有限の値を返す。

`kelvin` は $x > 0$ で $[\operatorname{ber}x, \operatorname{bei}x, \operatorname{ker}x, \operatorname{kei}x]$ を一度に返す。
$x\,e^{\mathrm{i}\pi/4}$ での 1 回の評価が $\operatorname{ber}$ と $\operatorname{bei}$ を、もう 1 回が $\operatorname{ker}$ と $\operatorname{kei}$ を与えるので、計算コストは `ber` と `ker` を 1 回ずつ呼ぶのと同程度である。
オプション付き形式 `kelvin_with_options` は 4 つの `SpecialFunctionResult` を返し、それぞれが導関数も持つ。
作業量は 4 つの成分で一つの上限を共有し、各対の計算量はその対の最初の成分に計上する。
`kelvin` は $\operatorname{ker}$ の特異点 $x = 0$ で `DomainError`（`Pole`）を、$x < 0$ で `DomainError`（`OutsideDomain`）を返す。

## 精度の扱い

Kelvin 関数には一様な ULP の仕様がない。
照合試験では、独立に生成した `f32` と `f64` の参照値と、値、導関数、2 階導関数を比べる。
誤差は対になる関数との大きさ（$\operatorname{ber}$ なら $\max(\lvert\operatorname{ber}x\rvert, \lvert\operatorname{bei}x\rvert)$）を単位にして測るので、片方の零点の近くでは相対誤差ではなく絶対誤差を見ていることになる。
照合データの点では、`f64` の誤差がこの単位の $512\varepsilon$ 以内にあり、オプション付き形式の推定誤差（`ValueWithError` の誤差。
包含区間ではない）が実際の誤差を覆うことを確かめている。
この限界は照合データの点で測った値で、受け付けるすべての引数に対する仕様ではないので、精度が必要な計算ではオプション付き形式の推定誤差を読む。

## API

どの関数にも標準形式、オプション付き形式、スコープ付き API がある。
Kelvin 関数は `RealScalar` で実数（`f32`、`f64`）だけを受け取る。
オプションは `KelvinOptions` で、作業量の上限（`Budget`。
精度の要求ではない。
既定 65536 単位）だけを持つ。

| 標準形式 | オプション付き形式 | スコープ付き API | 値 |

| `ker`、`kei` | `ker_with_options`、`kei_with_options` | `ker_scoped`、`kei_scoped` | $\operatorname{ker}x$、$\operatorname{kei}x$ |
| `ber_scaled`、`bei_scaled` | `ber_scaled_with_options`、`bei_scaled_with_options` | `ber_scaled_scoped`、`bei_scaled_scoped` | $e^{-\lvert x\rvert/\sqrt{2}}\operatorname{ber}x$ など |
| `ker_scaled`、`kei_scaled` | `ker_scaled_with_options`、`kei_scaled_with_options` | `ker_scaled_scoped`、`kei_scaled_scoped` | $e^{x/\sqrt{2}}\operatorname{ker}x$ など |

| `kerp_scaled`、`keip_scaled` | `kerp_scaled_with_options`、`keip_scaled_with_options` | `kerp_scaled_scoped`、`keip_scaled_scoped` | $e^{x/\sqrt{2}}\operatorname{ker}'x$ など |

非有限な入力は `NonFinite` を返す。
$\operatorname{ker}$、$\operatorname{kei}$ とその導関数・尺度化形は $x < 0$ で `DomainError`（`OutsideDomain`）を返し、$\operatorname{ker}$ と $\operatorname{ker}'$ は $x = 0$ で `DomainError`（`Pole`）を返す。
$\operatorname{ber}$、$\operatorname{bei}$ と導関数はすべての有限の $x$ を受け付け、尺度化しない値があふれるときだけ `NumericalInstability`（`Overflow`）を返す。

## 交流抵抗と表皮効果

半径 $a$ の円柱導体の単位長さあたりの交流抵抗 $R$ と直流抵抗 $R_0 = 1/(\pi a^2\sigma)$ の比は、$q = \sqrt{2}\,a/\delta$ として Kelvin 関数で書ける（Ramo, Whinnery and Van Duzer, 1994）。

$$
\frac{R}{R_0} = \frac{q}{2}\,\frac{\operatorname{ber}q\operatorname{bei}'q - \operatorname{bei}q\operatorname{ber}'q}{(\operatorname{ber}'q)^2 + (\operatorname{bei}'q)^2}.
$$

この式は上の級数と漸近形から、低周波と高周波の極限を独立に与える。

$$
\frac{R}{R_0} \approx 1 + \frac{q^4}{192} \quad (q \ll 1), \qquad
\frac{R}{R_0} \approx \frac{q}{2\sqrt{2}} + \frac{1}{4} = \frac{a}{2\delta} + \frac{1}{4} \quad (q \gg 1).
$$

高周波の極限で主となる項 $a/(2\delta)$ は、電流が表面から厚さ $\delta$ の層だけを流れるとした抵抗 $1/(2\pi a\delta\sigma)$ と $R_0$ の比である。
電流密度の分布は $\lvert J(r)/J(a)\rvert = \lvert\operatorname{ber}(qr/a) + \mathrm{i}\operatorname{bei}(qr/a)\rvert / \lvert\operatorname{ber}q + \mathrm{i}\operatorname{bei}q\rvert$ で、$q \gg 1$ では表面から $e^{-(a-r)/\delta}\sqrt{a/r}$ のように減る。

次のセルは $a/\delta$ を選び、`kelvin_with_options` の値と導関数から $R/R_0$ を求めて二つの極限と比べ、$\lvert J(r)/J(a)\rvert$ を描く。
半径 $a = 1$ mm の銅線（$\sigma = 5.8 \times 10^7$ S/m、$\mu = \mu_0$）に対応する周波数 $f = 1/(\pi\mu_0\sigma\delta^2)$ も示す。
表の最後の 2 列は同じ点での Kelvin 関数の Wronskian の 2 つの恒等式の残差（$x\,\times$ 左辺 $+ 1$ と $x\,\times$ 左辺）で、値と導関数が互いに整合しているかを確かめる。

```rust
//| id: special-kelvin-asymptotic-check
//| ref: special-kelvin-asymptotic-check
//| title: 円柱導体の交流抵抗と電流分布を Kelvin 関数で求める
//| run: reactive
//| crates: [scioxide-core, scioxide-special]
//| inputs:
//|   radius_over_depth: {"type":"range","label":"半径と表皮深さの比 a/δ [-]","description":"周波数の平方根に比例する。","min":0.2,"max":20,"step":0.2,"value":3}
//| cases:
//|   - {"id":"low-frequency","label":"a/δ = 0.6","description":"電流はほぼ一様に流れ、R/R₀ は 1 + q⁴/192 に近い。","inputs":{"radius_over_depth":0.6}}
//|   - {"id":"high-frequency","label":"a/δ = 20","description":"電流は表面の薄い層に集まり、R/R₀ は a/(2δ) + 1/4 に近い。","inputs":{"radius_over_depth":20}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"resistance","path":"/rows/0/1","approx":{"value":1.768131652509737,"rtol":1e-12}}
//|       - {"artifact":"resistance","path":"/rows/0/5","range":{"max":1e-13}}
//|       - {"artifact":"resistance","path":"/rows/0/6","range":{"max":1e-13}}
//|   - case: low-frequency
//|     expect:
//|       - {"artifact":"resistance","path":"/rows/0/1","approx":{"value":1.0026941818853217,"rtol":1e-12}}
//|       - {"artifact":"resistance","path":"/rows/0/2","approx":{"value":1.0027,"rtol":1e-12}}
//|   - case: high-frequency
//|     expect:
//|       - {"artifact":"resistance","path":"/rows/0/1","approx":{"value":10.254679114660355,"rtol":1e-11}}
//|       - {"artifact":"resistance","path":"/rows/0/3","approx":{"value":10.25,"rtol":1e-12}}
//|       - {"artifact":"resistance","path":"/rows/0/5","range":{"max":1e-12}}
use scioxide_core::RealScalar;
use scioxide_special::{KelvinOptions, SpecialFunctionResult, kelvin_with_options};

let q = std::f64::consts::SQRT_2 * radius_over_depth;
let parts = |x: f64| -> Result<[(f64, f64); 4], String> {
    let results =
        kelvin_with_options(x, KelvinOptions::default()).map_err(|e| e.to_string())?;
    let pair = |r: &SpecialFunctionResult<f64>| -> Result<(f64, f64), String> {
        let value = r.value().ok_or("値がない")?;
        let slope = r.derivative().ok_or("導関数がない")?;
        Ok((*value.value(), *slope.value()))
    };
    Ok([
        pair(&results[0])?,
        pair(&results[1])?,
        pair(&results[2])?,
        pair(&results[3])?,
    ])
};
let [(ber, dber), (bei, dbei), (ker, dker), (kei, dkei)] = parts(q)?;
let ratio = 0.5 * q * (ber * dbei - bei * dber) / (dber * dber + dbei * dbei);
// 低周波と高周波の極限（級数と漸近形から導いた独立な検算）。
let low = 1.0 + q.powi(4) / 192.0;
let high = q / (2.0 * std::f64::consts::SQRT_2) + 0.25;
// Kelvin 関数の Wronskian の恒等式（I₀ と K₀ の Wronskian の実部と虚部）。
let real_part = q * (ber * dker - dber * ker - bei * dkei + dbei * kei) + 1.0;
let imaginary_part = q * (ber * dkei - dber * kei + bei * dker - dbei * ker);
// 銅線 a = 1 mm の周波数 f = 1/(π μ₀ σ δ²)。
let depth = 1.0e-3 / radius_over_depth;
let mu0_sigma = 4.0e-7 * std::f64::consts::PI * 5.8e7;
let frequency = 1.0 / (std::f64::consts::PI * mu0_sigma * depth * depth);

let surface = RealScalar::hypot(ber, bei);
let mut profile = Vec::new();
let mut skin = Vec::new();
for index in 1..=100 {
    let s = f64::from(index) / 100.0;
    let [(b, _), (c, _), _, _] = parts(q * s)?;
    profile.push([s, RealScalar::hypot(b, c) / surface]);
    // 表面近くの近似 e^{−(a−r)/δ} √(a/r)（f64 の標準関数による参照曲線）。
    skin.push([s, (-(1.0 - s) * radius_over_depth).exp() / s.sqrt()]);
}
emit_line_chart!(
    &vec![
        serde_json::json!({ "name": "|J(r)/J(a)|（Kelvin 関数）", "points": profile }),
        serde_json::json!({
            "name": "e^{−(a−r)/δ} √(a/r)",
            "points": skin,
            "style": { "lineType": "dashed" }
        }),
    ],
    options = &serde_json::json!({
        "xLabel": "半径方向の位置 r/a [-]",
        "yLabel": "電流密度の振幅比 [-]",
        "yType": "log",
        "xMin": 0.0,
        "xMax": 1.0,
        "yMin": 1e-9,
        "yMax": 10.0
    })
);

let sig6 = serde_json::json!({ "significantDigits": 6 });
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let columns = serde_json::json!([
    { "key": "0", "label": "銅線 a = 1 mm の周波数 f [Hz]", "type": "number", "format": sci3 },
    { "key": "1", "label": "R/R₀（Kelvin 関数）[-]", "type": "number", "format": sig6 },
    { "key": "2", "label": "1 + q⁴/192 [-]", "type": "number", "format": sig6 },
    { "key": "3", "label": "a/(2δ) + 1/4 [-]", "type": "number", "format": sig6 },
    { "key": "4", "label": "q = √2 a/δ [-]", "type": "number", "format": sig6 },
    { "key": "5", "label": "Wronskian の実部の残差 [-]", "type": "number", "format": sci2 },
    { "key": "6", "label": "Wronskian の虚部の残差 [-]", "type": "number", "format": sci2 }
]);
emit_table_with_columns!(
    columns,
    vec![(
        frequency,
        ratio,
        low,
        high,
        q,
        real_part.abs(),
        imaginary_part.abs(),
    )],
    metadata = serde_json::json!({ "id": "resistance" })
);
```

既定の $a/\delta = 3$（銅線で約 39 kHz）では $R/R_0 = 1.7681$ で、高周波の極限 $1.75$ との差は 1 % である。
$a/\delta = 0.6$ では $R/R_0 = 1.002694$ と低周波の極限 $1.0027$ の相対差は $6 \times 10^{-6}$、$a/\delta = 20$ では $10.2547$ と高周波の極限 $10.25$ の相対差は $5 \times 10^{-4}$ で、どちらの差も $q \to 0$、$q \to \infty$ に近づくほど小さくなる。
二つの極限は Kelvin 関数の級数と漸近形から独立に導いたので、値と導関数を低周波と高周波の両側から照合したことになる。
電流密度の図では、$a/\delta$ を大きくすると電流が表面の厚さ $\delta$ 程度の層に集まり、破線の近似と表面近くで重なる。
$a/\delta$ が小さいと分布はほぼ一様で、破線の近似は使えない。
Wronskian の 2 つの残差はどの入力でも $10^{-15}$ 程度以下である。

## まとめ

Kelvin 関数は $e^{\mathrm{i}\pi/4}$ の向きの $I_0$、$K_0$ の実部と虚部で、`scioxide-special` は 0 次だけを提供し、一般の次数には複素数の引数の `bessel_j`、`bessel_k` を使う。
$\lvert x\rvert \le 10$ の $\operatorname{ber}$、$\operatorname{bei}$ と 20 未満の $\operatorname{ker}$、$\operatorname{kei}$ は打ち消しを2 ワードの算術で抑えた級数で、それより大きい引数は漸近展開で求める。
$\lvert x\rvert$ が 1010 前後を超えると $\operatorname{ber}$、$\operatorname{bei}$ があふれるので尺度化形を使い、4 つの値がまとめて要れば `kelvin` で計算コストを半分にする。
一様な ULP の仕様はないので、オプション付き形式の推定誤差と、Wronskian の恒等式や既知の極限で精度を確かめる。
円柱対称な波の放射と回折は [円形開口の Fraunhofer 回折と円筒波](../../examples/cylindrical-wave/) で、項目ごとの仕様は [Kelvin・Struve・放物柱関数と Bessel 積分](../../api/kelvin-struve-parabolic/) で確かめる。
