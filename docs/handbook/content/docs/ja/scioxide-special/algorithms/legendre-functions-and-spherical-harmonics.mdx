重力場や静電場の多重極展開、球対称な問題の角度部分、Gauss–Legendre 求積の節点には、球座標で変数分離した Laplace 方程式の解として Legendre 関数が現れる。
次数が数千を超えると、陪関数 $P_l^m$ の値は位数 $m$ とともに binary64 の範囲を外れ、Legendre 多項式 $P_l$ は零点の近くで打ち消しの大きい和になる。
このページは第一種・第二種の Legendre 関数、Legendre 陪関数、双曲空間の動径固有関数 $H_l$ の定義と規約、評価に使う漸化式とその安定性、作業量の上限、精度と呼び出しの形を説明する。
陪関数を単位球面上で正規化した球面調和関数は [球面調和関数](../spherical-harmonics/) が、角運動量の結合係数は [角運動量結合係数と Wigner 記号](../angular-momentum-coupling/) が扱う。

## Legendre 関数の定義

Legendre の微分方程式

$$
(1 - x^2) y'' - 2x y' + l(l + 1) y = 0
$$

は、整数の次数 $l \ge 0$ に対して多項式の解 $P_l(x)$ を持つ。
$P_l$ は Rodrigues の公式 $P_l(x) = \frac{1}{2^l l!}\frac{d^l}{dx^l}(x^2 - 1)^l$ で定義し、$P_l(1) = 1$、$P_l(-1) = (-1)^l$ に規格化する（DLMF §18.5）。
$[-1, 1]$ での直交関係は $\int_{-1}^1 P_l P_k \, dx = \frac{2}{2l + 1}\delta_{lk}$ である。
`legendre_p(l, x)` は $|x| > 1$ を含むすべての実数の $x$ で $P_l(x)$ を返す。

もう一つの独立な解として、`legendre_q(l, x)` は $-1 \le x \le 1$ の第二種の Ferrers 関数

$$
Q_0(x) = \operatorname{artanh} x = \frac{1}{2}\ln\frac{1 + x}{1 - x}, \qquad Q_1(x) = x \operatorname{artanh} x - 1
$$

を返す（DLMF §14.5）。
$Q_l$ は $x = \pm 1$ に対数特異点を持ち、$x = 1$ では $+\infty$、$x = -1$ では偶数の $l$ で $-\infty$、奇数の $l$ で $+\infty$ を値として返す。
$|x| > 1$ は `DomainError`（`OutsideDomain`）である。
$|x| > 1$ で使われる第二種の Legendre 関数（Ferrers 関数ではない $Q_l$）は提供しない。
$P_l$ と $Q_l$ は同じ三項漸化式（Bonnet の漸化式）

$$
(l + 1) F_{l+1}(x) = (2l + 1) x F_l(x) - l F_{l-1}(x)
$$

を満たし、二つの解の Casorati 行列式は $P_l Q_{l-1} - P_{l-1} Q_l = 1/l$ である（DLMF §14.10）。

### Legendre 陪関数

整数の次数 $l \ge 0$ と位数 $|m| \le l$ に対し、`legendre_p_assoc(l, m, x)` は $-1 \le x \le 1$ の第一種の Ferrers 関数

$$
P_l^m(x) = (-1)^m (1 - x^2)^{m/2}\frac{d^m}{dx^m}P_l(x) \quad (0 \le m \le l), \qquad
P_l^{-m}(x) = (-1)^m \frac{(l - m)!}{(l + m)!} P_l^m(x)
$$

を返す（DLMF §14.6、§14.9）。
因子 $(-1)^m$ は Condon–Shortley の位相で、`legendre_p_assoc` はこれを含む。
たとえば $P_1^1(x) = -\sqrt{1 - x^2}$ である。
Condon–Shortley の位相を含まない規約（地球物理の一部の文献や、`(1 − x²)^{m/2} dᵐP_l/dxᵐ` をそのまま使う流儀）と比べるときは、奇数の $m$ で符号を反転する。
$m \ne 0$ では $x = \pm 1$ で 0 になる。
位数 $m$ を固定した直交関係は

$$
\int_{-1}^1 P_l^m(x) P_k^m(x)\, dx = \frac{2}{2l + 1}\frac{(l + m)!}{(l - m)!}\delta_{lk}
$$

である。

### 双曲空間の動径固有関数

3 次元の双曲空間の Laplace 作用素の動径固有関数 $H_l(\lambda, \eta)$ は、開いた Robertson–Walker 宇宙での場の展開に現れる。
`legendre_h3d(l, lambda, eta)` は、非負の整数 $l$、実数の波数 $\lambda$、動径座標 $\eta \ge 0$ に対して

$$
H_0 = \frac{\sin(\lambda\eta)}{\lambda \sinh\eta}, \qquad
H_1 = \frac{\coth\eta \, H_0 - \cos(\lambda\eta)/\sinh\eta}{\sqrt{1 + \lambda^2}},
$$

$$
\sqrt{\lambda^2 + (l + 1)^2}\, H_{l+1} = (2l + 1)\coth\eta\, H_l - \sqrt{\lambda^2 + l^2}\, H_{l-1}
$$

で規格化した関数を返す。
$\lambda\eta$ を固定して $\eta \to 0$ とすると $H_l(\lambda, \eta) \to j_l(\lambda\eta)$（球 Bessel 関数）になり、$\lambda$ と $l$ だけによる因子を除けば円錐関数 $(\sinh\eta)^{-1/2} P^{-1/2-l}_{-1/2+i\lambda}(\cosh\eta)$ に等しい（DLMF §14.20）。
$H_l$ は $\lambda$ について偶関数で、$\lambda = 0$ は連続な極限を取り、$\eta = 0$ では $H_0 = 1$、$l \ge 1$ で $H_l = 0$ である。
$\eta < 0$ は `DomainError`（`OutsideDomain`）、$\lambda\eta$ が桁あふれすると `NumericalInstability`（`LossOfSignificance`）になる。

## 漸化式による評価と安定性

### Legendre 関数の前進の漸化式

三項漸化式には増える解と減る解があり、求める解が他の解より速く減る（劣勢な）場合、前進の漸化式は丸め誤差を増幅する。
$|x| < 1$ では $P_l$ と $Q_l$ はどちらも振幅 $O(l^{-1/2})$ で振動し、どちらも劣勢ではないので、$l$ を増やす向きの漸化式で誤差は指数的に増えない。
`legendre_p` は $P_0 = 1$、$P_1 = x$ から Bonnet の漸化式を binary64 で $l - 1$ 段進める。
各段の積と除算の丸め誤差を融合積和（FMA）で取り出し、同じ線形の漸化式に乗せて値と一緒に伝える（残差補正）。
零点の近くでは補正が答えの大部分になるので、倍精度の二つの数で一つの値を表す二重語の演算に切り替える。
$|x| > 1$ では $P_l$ は $l$ とともに指数的に増え、状態を 2 の冪で尺度化しながら二重語の演算で進め、結果が binary64 の範囲を超えると `NumericalInstability`（`Overflow`）になる。
`legendre_q` は $Q_0$ を補償付きの対数で作り、$Q_1 = xQ_0 - 1$ から二重語の演算で同じ漸化式を進める。
$x = \pm 1$ の $P_l$ は閉じた形で、計算量は 0 である。

漸化式の係数 $2l - 1$ が binary64 の整数として正確であるために、$l > 2^{52}$ は `InvalidInput`（`OutOfRange`）にする（$P_l$ の $x = \pm 1$ を除く）。
1 段が `LegendreOptions` の作業量の上限の 1 単位で、既定の上限 65536 では $l$ はおよそ 65537 までになる。
それより高い次数では上限を `LegendreOptions::new(Budget::try_from(n)?)` で増やす。
上限が足りないと、漸化式は途中の値を返さずに `ConvergenceFailure`（`IterationLimit`）になる。

### 陪関数と尺度化

`legendre_p_assoc` は対角の値 $P_m^m(x) = (-1)^m (2m - 1)!!\,(1 - x^2)^{m/2}$ を補償付きの演算で作り、$P_{m+1}^m = (2m + 1) x P_m^m$ から

$$
(l - m + 1) P_{l+1}^m = (2l + 1) x P_l^m - (l + m) P_{l-1}^m
$$

を $l$ の向きに進める。
$(2m - 1)!!$ は $m$ とともに急に増え、$(1 - x^2)^{m/2}$ は急に減るので、状態を仮数と 2 の冪の指数に分けて持ち、最後に一度だけ通常の値へ丸める。
binary64 の範囲を外れる値は、オプション付き形式の `scaled()` の値（2 の冪の指数を別に持つ形）と対数形として残り、標準形式は `NumericalInstability`（`Overflow`）になる。
負の位数は上の関係で $m > 0$ から作り、因子 $(l - m)!/(l + m)!$ を 1 段に 1 つずつ割り込む。
計算量は $m \ge 0$ で $l$ 段（対角の $m$ 段と次数を上げる $l - m$ 段）、負の位数ではさらに $2|m|$ 段で、$l + |m| > 2^{53}$ は `SizeOverflow` になる。
$x = \pm 1$ と $l = 0$ は閉じた値で、終了状態は `Exact` である。
オプション付き形式の推定誤差は、漸化式の項の大きさの和に $64\varepsilon(1 + l + 2|m|)^2$ を掛けた丸めのモデルで、包含区間ではない。

### 双曲空間の関数の漸化式の向き

$H_l$ の漸化式は、$l \le |\lambda|\sinh\eta$ では振動する領域にあって前進が安定で、それより大きな $l$ では $H_l$ が劣勢な解になる。
`legendre_h3d` は $\eta \le 1$ かつ $|\lambda|\eta \le 1$ で超幾何級数を和で求め、それ以外では $H_0$、$H_1$ から、$l \le |\lambda|\sinh\eta$ か $\eta > \ln(l + 1) + 2$ のとき前進の漸化式、それ以外は Miller の後退の漸化式（大きな次数から逆向きに進め、既知の $H_0$ で規格化し直す方法）を使う。
計算コストは $l$ に比例し、作業量の上限は `SphericalBesselOptions`（既定 65536 単位）で決める。
Miller の後退の漸化式を使った場合の推定誤差は経験的なもの（信頼度 `Heuristic`）である。

## 精度の保証

| 関数（実数の引数） | binary64 | binary32 | 試験で確かめた内容 |
|---|---|---|---|
| `legendre_p` | 64 ULP | 64 ULP | binary64 の測定の最大は 0.5 ULP。次数 0 から 10000 までの代表的な格子、端点、零点の近く、次数 20000 の照合データ |
| `legendre_q` | 64 ULP | 64 ULP | 次数 20000 までの照合データ |
| `legendre_p_assoc` | 64 ULP | 64 ULP | 陪関数の照合データ |
| `legendre_h3d` | 仕様なし | 仕様なし | 値と推定誤差を照合データと比べる。零点の近くは絶対誤差で比べる |

零点の近くでは、64 ULP の代わりに絶対誤差の上界を使う。
`legendre_p` の照合データは、160 桁と 240 桁の独立な高精度計算で作った参照値である。
`legendre_p` と `legendre_q` のオプション付き形式は、64 ULP の包絡を推定誤差として返す。
`legendre_p_assoc` のオプション付き形式の推定誤差は上の丸めのモデルで、64 ULP の仕様より大きく出ることがある。

## 関数と呼び出しの形

すべての関数は実数の型（`f32`、`f64`）を受け取り、実数を返す。
次数と位数の型は関数ごとに決まっている。

| 関数 | 引数 | オプション付き形式 | スコープ付き API | オプション |
|---|---|---|---|---|
| `legendre_p` | `degree: usize`, `x: S` | `legendre_p_with_options` | `legendre_p_scoped` | `LegendreOptions` |
| `legendre_q` | `degree: usize`, `x: S` | `legendre_q_with_options` | `legendre_q_scoped` | `LegendreOptions` |
| `legendre_p_assoc` | `degree: usize`, `order: i32`, `x: S` | `legendre_p_assoc_with_options` | `legendre_p_assoc_scoped` | `LegendreOptions` |
| `legendre_h3d` | `order: u32`, `lambda: S`, `eta: S` | `legendre_h3d_with_options` | `legendre_h3d_scoped` | `SphericalBesselOptions` |

オプション付き形式 `*_with_options(.., options)` は `SpecialFunctionResult` を返し、推定誤差、終了状態、計算量の計数、アルゴリズムの識別子を持つ。
`legendre_p_assoc` のオプション付き形式は、値が binary64 の範囲を外れても `scaled()` の値と対数形を持つ。
スコープ付き API `*_scoped(.., options, scope)` は、オプション付き形式と同じ結果を求解スコープの中で返す。
`LegendreOptions` と `SphericalBesselOptions` は作業量の上限（`Budget`）だけを持ち、精度は変わらない。
多数の点で評価するときは、関数を写像して集める。
次数をまとめて返す列の関数はない。

## 陪関数の直交性と位相の規約

次のセルは、位数 $m$ を選び、$l = m, \dots, m + 4$ の $P_l^m$ の直交関係を複合 Simpson 則（$N$ 区間、手計算）で確かめる。
$P_l^m P_k^m$ は $(1 - x^2)^m$ と多項式の積で $x$ の多項式になるので、Simpson 則の誤差は $N^{-4}$ で減る。
1 つ目の表は、$\int (P_l^m)^2 dx$ と規格化定数 $N_l = \frac{2}{2l+1}\frac{(l+m)!}{(l-m)!}$ の相対差と、非対角の積分を $\sqrt{N_l N_k}$ で割った値の最大を出す。
2 つ目の表は、$x = 0.5$ の $P_1^1$、$P_2^1$、$P_2^2$、$P_1^{-1}$、$Q_0$、$Q_2$ を閉じた形と比べ、Condon–Shortley の位相と負の位数の規約を確かめる。

```rust
//| id: special-legendre-orthogonality-check
//| ref: special-legendre-orthogonality-check
//| title: Legendre 陪関数の直交性と位相の規約を確かめる
//| run: reactive
//| crates: [scioxide-special]
//| inputs:
//|   order: {"type":"range","label":"位数 m","description":"P_l^m の位数。次数は l = m, …, m + 4 を調べる。","min":0,"max":8,"step":1,"value":2}
//|   intervals: {"type":"range","label":"Simpson 則の区間数 N","description":"求積の刻み 2/N を変える。誤差は N⁻⁴ で減る。","min":200,"max":4000,"step":200,"value":2000}
//| cases:
//|   - {"id":"high-order","label":"m = 8","description":"規格化定数が 10¹⁵ を超えても相対差は丸めの程度にとどまる。","inputs":{"order":8}}
//|   - {"id":"coarse","label":"N = 200","description":"区間を 10 分の 1 にすると、求積の誤差が約 10⁴ 倍になる。","inputs":{"intervals":200}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"gram","path":"/rows/0/3","range":{"min":-1e-12,"max":1e-12}}
//|       - {"artifact":"gram","path":"/rows/4/3","range":{"min":-1e-9,"max":1e-9}}
//|       - {"artifact":"gram","path":"/rows/4/4","range":{"max":1e-9}}
//|       - {"artifact":"conventions","path":"/rows/0/1","approx":{"value":-0.8660254037844386,"rtol":1e-15}}
//|       - {"artifact":"conventions","path":"/rows/3/3","range":{"min":-1e-15,"max":1e-15}}
//|       - {"artifact":"conventions","path":"/rows/5/3","range":{"min":-1e-15,"max":1e-15}}
//|   - case: high-order
//|     expect:
//|       - {"artifact":"gram","path":"/rows/4/2","approx":{"value":8109673360588800,"rtol":1e-14}}
//|       - {"artifact":"gram","path":"/rows/4/3","range":{"min":-1e-14,"max":1e-14}}
//|   - case: coarse
//|     expect:
//|       - {"artifact":"gram","path":"/rows/0/3","approx":{"value":2.5e-9,"rtol":0.01}}
use scioxide_special::{legendre_p_assoc, legendre_q};

let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let digits16 = serde_json::json!({ "significantDigits": 16 });
let m = order as i32;
let n = intervals as usize;
let degrees: Vec<usize> = (0..5).map(|k| order as usize + k).collect();
// [−1, 1] の Simpson 則の節点での P_l^m の値（行が次数）。
let h = 2.0 / n as f64;
let mut values = Vec::new();
for &l in &degrees {
    let column = (0..=n)
        .map(|i| legendre_p_assoc(l, m, -1.0 + h * i as f64))
        .collect::<Result<Vec<f64>, _>>()
        .map_err(|e| e.to_string())?;
    values.push(column);
}
// 独立な検算：複合 Simpson 則（手計算）による ∫ P_l^m P_k^m dx。
let integral = |a: &[f64], b: &[f64]| {
    let mut sum = a[0] * b[0] + a[n] * b[n];
    for i in 1..n {
        sum += if i % 2 == 1 { 4.0 } else { 2.0 } * a[i] * b[i];
    }
    sum * h / 3.0
};
// 規格化定数 N_l = 2/(2l + 1) · (l + m)!/(l − m)!。
let norm = |l: usize| {
    let ratio: f64 = ((l - order as usize + 1)..=(l + order as usize))
        .map(|k| k as f64)
        .product();
    2.0 / (2.0 * l as f64 + 1.0) * ratio
};
let mut rows = Vec::new();
for (a, &l) in degrees.iter().enumerate() {
    let diagonal = integral(&values[a], &values[a]);
    let off_diagonal = degrees
        .iter()
        .enumerate()
        .filter(|&(b, _)| b != a)
        .map(|(b, &k)| (integral(&values[a], &values[b]) / (norm(l) * norm(k)).sqrt()).abs())
        .fold(0.0, f64::max);
    rows.push((l, diagonal, norm(l), diagonal / norm(l) - 1.0, off_diagonal));
}
let columns = serde_json::json!([
    { "key": "0", "label": "次数 l", "type": "integer" },
    { "key": "1", "label": "∫ (P_l^m)² dx（Simpson）", "type": "number", "format": digits16 },
    { "key": "2", "label": "規格化定数 N_l", "type": "number", "format": digits16 },
    { "key": "3", "label": "相対差", "type": "number", "format": sci3 },
    { "key": "4", "label": "非対角の最大（N で割る）", "type": "number", "format": sci3 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "gram" })
);

// 位相の規約：x = 0.5 で閉じた形（f64 の固有メソッドで計算する参照値）と比べる。
let x = 0.5_f64;
let s = (1.0 - x * x).sqrt();
let p = |l: usize, m: i32| legendre_p_assoc(l, m, x).map_err(|e| e.to_string());
let q = |l: usize| legendre_q(l, x).map_err(|e| e.to_string());
let atanh = 0.5 * ((1.0 + x) / (1.0 - x)).ln();
let conventions = vec![
    ("P_1^1(x) = −√(1 − x²)", p(1, 1)?, -s),
    ("P_2^1(x) = −3x√(1 − x²)", p(2, 1)?, -3.0 * x * s),
    ("P_2^2(x) = 3(1 − x²)", p(2, 2)?, 3.0 * s * s),
    ("P_1^(−1)(x) = ½√(1 − x²)", p(1, -1)?, 0.5 * s),
    ("Q_0(x) = artanh x", q(0)?, atanh),
    (
        "Q_2(x) = P_2(x) artanh x − 3x/2",
        q(2)?,
        0.5 * (3.0 * x * x - 1.0) * atanh - 1.5 * x,
    ),
];
let conventions: Vec<_> = conventions
    .into_iter()
    .map(|(name, value, exact)| (name, value, exact, value - exact))
    .collect();
let columns = serde_json::json!([
    { "key": "0", "label": "関数（x = 0.5）" },
    { "key": "1", "label": "SciOxide の値", "type": "number", "format": digits16 },
    { "key": "2", "label": "閉じた形", "type": "number", "format": digits16 },
    { "key": "3", "label": "差", "type": "number", "format": sci3 }
]);
emit_table_with_columns!(
    columns,
    conventions,
    metadata = serde_json::json!({ "id": "conventions" })
);
```
既定の $m = 2$、$N = 2000$ では、相対差は $l = 2$ の $2.5 \times 10^{-13}$ から $l = 6$ の $5.9 \times 10^{-10}$ まで増え、非対角は $1.6 \times 10^{-10}$ 以下である。
次数が高いほど被積分関数の高階導関数が大きく、Simpson 則の誤差が増える。
$N$ を 200 にすると相対差は約 $10^4$ 倍（$N^{-4}$）になり、4000 にすると約 16 分の 1 になるので、差は求積の誤差であって `legendre_p_assoc` の誤差ではない。
$m = 8$ では $N_{12} \approx 8.1 \times 10^{15}$ まで増えるが、相対差は $10^{-15}$ の程度にとどまる。
2 つ目の表の差は $1.1 \times 10^{-16}$ 以下で、$P_1^1 = -\sqrt{1 - x^2}$ の負の符号が Condon–Shortley の位相を示す。

## 高い次数と双曲空間の関数

次のセルは、次数 $l$ と角 $\theta$（$x = \cos\theta$）を選び、$P_l$ と $Q_l$ を大きな $l$ の漸近形（DLMF §14.15）

$$
P_l(\cos\theta) \approx \sqrt{\frac{2}{\pi l \sin\theta}}\cos\Bigl(\bigl(l + \tfrac{1}{2}\bigr)\theta - \frac{\pi}{4}\Bigr), \qquad
Q_l(\cos\theta) \approx -\sqrt{\frac{\pi}{2 l \sin\theta}}\sin\Bigl(\bigl(l + \tfrac{1}{2}\bigr)\theta - \frac{\pi}{4}\Bigr)
$$

と比べる。
漸近形の相対誤差は $O(1/l)$ なので、この行の差は漸近形の誤差で決まる。
Casorati 行列式 $l(P_l Q_{l-1} - P_{l-1} Q_l) = 1$ は、$P$ と $Q$ を別々の漸化式で求めた値の組み合わせで、丸めの程度で 1 になるはずである。
$P_l^0$ は陪関数の別の経路で求めた $P_l$ である。
2 つ目の表は、$\lambda = 1.5$、$\eta = 0.5$（超幾何級数の領域）の $H_0$、$H_1$ を閉じた形と、$H_2$ を漸化式と比べ、$\lambda\eta = 1.5$ を固定した $\eta = 10^{-3}$ の $H_3$ を球 Bessel 関数 $j_3(1.5)$（`spherical_jn`）と比べる。
最後の行の差には極限への近づき $O(\eta^2)$ が残る。
3 つ目の表は、作業量の上限を $l - 1$ と $(l - 1)/2$ にした `legendre_p_with_options` の結果である。

```rust

//| ref: special-legendre-high-degree
//| title: 高い次数の P_l と Q_l、双曲空間の H_l を確かめる
//| run: reactive
//| crates: [scioxide-core, scioxide-special]
//| inputs:
//|   degree: {"type":"range","label":"次数 l","description":"漸化式の段数 l − 1 を変える。","min":10,"max":20000,"step":10,"value":1000}

//| cases:
//|   - {"id":"low-degree","label":"l = 10","description":"漸近形の相対誤差 O(1/l) が 10⁻² に増える。","inputs":{"degree":10}}
//|   - {"id":"degree-20000","label":"l = 20000","description":"2 万段の漸化式でも Casorati 行列式が 1 に保たれる。","inputs":{"degree":20000}}
//| tests:
//|   - case: default

//|       - {"artifact":"degree","path":"/rows/0/3","approx":{"value":3.41e-6,"rtol":1e-2}}
//|       - {"artifact":"degree","path":"/rows/2/3","range":{"min":-1e-14,"max":1e-14}}
//|       - {"artifact":"degree","path":"/rows/3/3","range":{"min":-1e-16,"max":1e-16}}
//|       - {"artifact":"h3d","path":"/rows/1/3","range":{"min":-1e-15,"max":1e-15}}
//|       - {"artifact":"h3d","path":"/rows/2/3","range":{"min":-1e-15,"max":1e-15}}
//|       - {"artifact":"h3d","path":"/rows/3/3","range":{"min":-1e-6,"max":1e-6}}
//|       - {"artifact":"budget","path":"/rows/0/2","equals":999}
//|       - {"artifact":"budget","path":"/rows/1/3","equals":"ConvergenceFailure（IterationLimit）"}
//|   - case: low-degree
//|     expect:
//|       - {"artifact":"degree","path":"/rows/0/3","approx":{"value":3.488e-3,"rtol":1e-2}}
//|   - case: degree-20000
//|     expect:
//|       - {"artifact":"degree","path":"/rows/2/3","range":{"min":-1e-13,"max":1e-13}}
//|       - {"artifact":"degree","path":"/rows/0/3","range":{"min":-1e-7,"max":1e-7}}
//|       - {"artifact":"budget","path":"/rows/0/2","equals":19999}
use scioxide_core::{Budget, SciOxideErrorView};
use scioxide_special::{
    LegendreOptions, legendre_h3d, legendre_p, legendre_p_assoc, legendre_p_with_options,
    legendre_q, spherical_jn,
};
use std::f64::consts::{FRAC_PI_4, PI};

let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let digits16 = serde_json::json!({ "significantDigits": 16 });
let l = degree as usize;
let theta = theta_deg.to_radians();
let x = theta.cos();
let p = legendre_p(l, x).map_err(|e| e.to_string())?;
let q = legendre_q(l, x).map_err(|e| e.to_string())?;
let p_previous = legendre_p(l - 1, x).map_err(|e| e.to_string())?;
let q_previous = legendre_q(l - 1, x).map_err(|e| e.to_string())?;
let associated = legendre_p_assoc(l, 0, x).map_err(|e| e.to_string())?;
// 大きな l の漸近形（Laplace 型、相対誤差 O(1/l)）。f64 の固有メソッドで計算する参照値。
let lf = l as f64;
let amplitude = (2.0 / (PI * lf * theta.sin())).sqrt();
let phase = (lf + 0.5) * theta - FRAC_PI_4;
let rows = vec![
    ("P_l(cos θ)", p, amplitude * phase.cos()),
    ("Q_l(cos θ)", q, -0.5 * PI * amplitude * phase.sin()),
    (
        "l (P_l Q_(l−1) − P_(l−1) Q_l)",
        lf * (p * q_previous - p_previous * q),
        1.0,
    ),
    ("P_l^0(cos θ)", associated, p),
];
let rows: Vec<_> = rows
    .into_iter()
    .map(|(name, value, reference)| (name, value, reference, value - reference))
    .collect();
let columns = serde_json::json!([
    { "key": "0", "label": "量" },
    { "key": "1", "label": "SciOxide の値", "type": "number", "format": digits16 },
    { "key": "2", "label": "参照", "type": "number", "format": digits16 },
    { "key": "3", "label": "差", "type": "number", "format": sci3 }
]);

    columns,
    rows,
    metadata = serde_json::json!({ "id": "degree" })
);

let h3d = |order: u32, lambda: f64, eta: f64| {
    legendre_h3d(order, lambda, eta).map_err(|e| e.to_string())
};
let (lambda, eta) = (1.5_f64, 0.5_f64);
let coth = 1.0 / eta.tanh();
let h0_exact = (lambda * eta).sin() / (lambda * eta.sinh());
let h1_exact =
    (coth * h0_exact - (lambda * eta).cos() / eta.sinh()) / (1.0 + lambda * lambda).sqrt();
let (h0, h1, h2) = (
    h3d(0, lambda, eta)?,
    h3d(1, lambda, eta)?,
    h3d(2, lambda, eta)?,
);
let h2_recurrence =
    (3.0 * coth * h1 - (lambda * lambda + 1.0).sqrt() * h0) / (lambda * lambda + 4.0).sqrt();

let hyperbolic = vec![
    ("H_0(1.5, 0.5)", h0, h0_exact),
    ("H_1(1.5, 0.5)", h1, h1_exact),
    ("H_2(1.5, 0.5)", h2, h2_recurrence),
    ("H_3(1500, 0.001)", h3d(3, 1500.0, 1e-3)?, limit),
];
let hyperbolic: Vec<_> = hyperbolic
    .into_iter()
    .map(|(name, value, reference)| (name, value, reference, value - reference))
    .collect();

    { "key": "0", "label": "量" },
    { "key": "1", "label": "SciOxide の値", "type": "number", "format": digits16 },
    { "key": "2", "label": "閉じた形・漸化式・j_3(1.5)", "type": "number", "format": digits16 },
    { "key": "3", "label": "差", "type": "number", "format": sci3 }
]);
emit_table_with_columns!(
    columns,
    hyperbolic,
    metadata = serde_json::json!({ "id": "h3d" })
);

// 作業量の上限：漸化式は l − 1 段で、上限が足りないと ConvergenceFailure になる。
let mut budgets = Vec::new();
for limit in [l - 1, (l - 1) / 2] {
    let options =
        LegendreOptions::new(Budget::try_from(limit.max(1)).map_err(|e| e.to_string())?);
    let row = match legendre_p_with_options(l, x, options) {
        Ok(result) => {
            let work = result.counts().iterations();
            let termination = format!("{:?}", result.termination());
            (
                limit,
                Some(result.try_value().map_err(|e| e.to_string())?),
                Some(work),
                termination,
            )
        }
        Err(error) => match error.view() {
            SciOxideErrorView::ConvergenceFailure { reason, .. } => (
                limit,
                None,
                None,
                format!("ConvergenceFailure（{reason:?}）"),
            ),
            _ => (limit, None, None, format!("{:?}", error.kind())),
        },
    };
    budgets.push(row);
}
let columns = serde_json::json!([
    { "key": "0", "label": "作業量の上限", "type": "integer" },
    { "key": "1", "label": "P_l(cos θ)", "type": "number", "format": digits16, "nullText": "—" },
    { "key": "2", "label": "計算量", "type": "integer", "nullText": "—" },
    { "key": "3", "label": "終了状態またはエラー" }
]);
emit_table_with_columns!(
    columns,
    budgets,
    metadata = serde_json::json!({ "id": "budget" })
);
```

$l = 10$ では差は $3.5 \times 10^{-3}$、$l = 20000$ では $4.1 \times 10^{-8}$ になり、$l$ とともに漸近形が良くなる。
Casorati 行列式は $l = 20000$ でも 1 と $10^{-16}$ の程度で一致し、2 万段の前進の漸化式でも誤差が増えていないことを示す。
$P_l^0$ は $P_l$ とビット単位で一致する。
$H_l$ の閉じた形と漸化式との差は $10^{-16}$ の程度で、$\eta \to 0$ の極限との差 $7.7 \times 10^{-8}$ は $\eta^2 = 10^{-6}$ と同じ程度の打ち切りである。
上限が $l - 1$ なら計算量はちょうど $l - 1 = 999$ で `Converged`、半分なら `ConvergenceFailure`（`IterationLimit`）になる。

## まとめと次に読むページ

`legendre_p` は $|x| > 1$ を含む実数で、`legendre_q` と `legendre_p_assoc` は $[-1, 1]$ で評価し、陪関数は Condon–Shortley の位相を含む。
$P_l$、$Q_l$、$P_l^m$ は前進の漸化式で求め、試験した範囲で 64 ULP（$P_l$ の測定の最大は 0.5 ULP）の仕様がある。
漸化式は 1 段が作業量の 1 単位なので、次数 65537 を超えるときは `LegendreOptions` の上限を増やし、上限が足りないと値は返らず `ConvergenceFailure`（`IterationLimit`）になる。
binary64 の範囲を外れる陪関数は、オプション付き形式の `scaled()` の値と対数形で受け取る。
多重極展開の正規化した基底は [球面調和関数](../spherical-harmonics/) で、球面調和関数の積の積分（Gaunt 係数）や角運動量の合成は [角運動量結合係数と Wigner 記号](../angular-momentum-coupling/) で、各項目の仕様は [Legendre・角運動量・スペクトル関数の API](../../api/legendre-angular-spectral/) で確かめる。
