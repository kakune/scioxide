楕円の断面を持つ領域で 2 次元の波動方程式を楕円柱座標に分離すると、角度方向と動径方向に Mathieu 方程式が現れる。
楕円形の膜や導波路の固有振動、楕円柱による散乱、周期的に駆動される振動子の安定性（[Paul トラップの安定領域](../../examples/paul-trap-stability/)）がこの方程式で書ける。
周期解の Fourier 係数は三項漸化式を満たし、特性値はその係数の対称三重対角行列の固有値になる。
`scioxide-special` は、この固有値問題を打ち切って解き、係数を保持する Plan `MathieuPlan` を作る。
打ち切りの決め方（スペクトル法の設定）は、Ferrers 関数で展開する[回転楕円体波動関数](../spheroidal-wave-functions/)の Plan `SpheroidalPlan` と共通で、このページで説明する。
このページは、方程式と規約、固有値問題への帰着と打ち切りの決め方、角関数と動径関数の評価法、精度の保証、API の順に説明する。

## Mathieu 方程式と特性値

Mathieu 方程式（DLMF 28.2.1）は、実のパラメータ $q$ と $a$ を持つ周期係数の線形方程式

$$
w''(z) + (a - 2q\cos 2z)\,w(z) = 0
$$

である。
係数は周期 $\pi$ を持つので、Floquet の定理により、解は $w(z+\pi) = e^{i\nu\pi} w(z)$ を満たす解の組で表せる（$\nu$ は特性指数）。
周期 $\pi$ または $2\pi$ の解が存在するのは、$q$ ごとに決まる離散的な $a$ の値に限られる。
これを特性値と呼び、偶関数の解 $\operatorname{ce}_n(z,q)$ に対応するものを $a_n(q)$（$n \ge 0$）、奇関数の解 $\operatorname{se}_n(z,q)$ に対応するものを $b_n(q)$（$n \ge 1$）と書く。

$q = 0$ では方程式が $w'' + a w = 0$ になり、$a_n(0) = b_n(0) = n^2$、$\operatorname{ce}_n(z,0) = \cos nz$（$n \ge 1$）、$\operatorname{ce}_0(z,0) = 1/\sqrt2$、$\operatorname{se}_n(z,0) = \sin nz$ である。
小さい $q$ では特性値を $q$ の冪級数に展開できる（DLMF 28.6.1–28.6.5）。

$$
\begin{aligned}
a_0(q) &= -\tfrac{1}{2}q^2 + \tfrac{7}{128}q^4 - \tfrac{29}{2304}q^6 + \tfrac{68687}{18874368}q^8 + O(q^{10}), \\
a_1(q) &= 1 + q - \tfrac{1}{8}q^2 - \tfrac{1}{64}q^3 - \tfrac{1}{1536}q^4 + \tfrac{11}{36864}q^5 + \tfrac{49}{589824}q^6 + O(q^7), \\
b_1(q) &= 1 - q - \tfrac{1}{8}q^2 + \tfrac{1}{64}q^3 - \tfrac{1}{1536}q^4 - \tfrac{11}{36864}q^5 + \tfrac{49}{589824}q^6 + O(q^7), \\
a_2(q) &= 4 + \tfrac{5}{12}q^2 - \tfrac{763}{13824}q^4 + \tfrac{1002401}{79626240}q^6 + O(q^8), \\
b_2(q) &= 4 - \tfrac{1}{12}q^2 + \tfrac{5}{13824}q^4 - \tfrac{289}{79626240}q^6 + O(q^8).
\end{aligned}
$$

これらの級数の収束半径は有限で、$q$ が 1 を大きく超えると使えない。
$q > 0$ では $a_0 < b_1 < a_1 < b_2 < a_2 < \cdots$ の順に並び、$q \to \infty$ では $a_n$ と $b_{n+1}$ が $-2q + 2(2n+1)\sqrt q$ に漸近して互いに指数的に近づく（DLMF 28.8.1）。
$q < 0$ の値は $a_{2r}(-q) = a_{2r}(q)$、$a_{2r+1}(-q) = b_{2r+1}(q)$、$b_{2r+2}(-q) = b_{2r+2}(q)$ で $q > 0$ に移せる（DLMF 28.2.26）。

規格化は DLMF §28.2 に従い、$\int_0^{2\pi}\operatorname{ce}_n(z,q)^2\,dz = \int_0^{2\pi}\operatorname{se}_n(z,q)^2\,dz = \pi$ とする。
符号は $q \to 0$ で $\cos nz$、$\sin nz$ に連続につながるように選ぶ。
実装は、周波数がいちばん低い係数を $q > 0$ で正にとり、$q < 0$ では類の中の番号 $r$（次の節）が奇数のとき負にとる。

## Fourier 係数の三項漸化式と固有値問題

周期解を Fourier 級数で表すと、$\operatorname{ce}_n$ と $\operatorname{se}_n$ はそれぞれ周波数の偶奇がそろった 4 つの類に分かれる。

$$
\operatorname{ce}_{2r} = \sum_{k\ge0} A_{2k}\cos 2kz,\quad
\operatorname{ce}_{2r+1} = \sum_{k\ge0} A_{2k+1}\cos(2k+1)z,\quad
\operatorname{se}_{2r+1} = \sum_{k\ge0} B_{2k+1}\sin(2k+1)z,\quad
\operatorname{se}_{2r+2} = \sum_{k\ge0} B_{2k+2}\sin(2k+2)z.
$$

方程式に代入すると、係数は三項漸化式（DLMF 28.4.5–28.4.8）

$$
(a - f_k^2)\,c_k = q\,(c_{k-1} + c_{k+1}),\qquad f_k = 2k + p
$$

を満たす。
$p$ は最低周波数で、$\operatorname{ce}_{2r}$ が 0、$\operatorname{ce}_{2r+1}$ と $\operatorname{se}_{2r+1}$ が 1、$\operatorname{se}_{2r+2}$ が 2 である。
最初の行の近くだけ形が変わり、$\operatorname{ce}_{2r}$ では $k = 1$ の行の $c_0$ に係数 2 が付き、$\operatorname{ce}_{2r+1}$ と $\operatorname{se}_{2r+1}$ では対角に $+q$ と $-q$ が加わる。
$\operatorname{ce}_{2r}$ では $\tilde c_0 = \sqrt2\,c_0$ と置き直すと、どの類も対角が $f_k^2$（と最初の行の $\pm q$）、副対角が $q$（$\operatorname{ce}_{2r}$ の最初だけ $\sqrt2\,q$）の対称三重対角行列 $T$ の固有値問題 $T\boldsymbol c = a\boldsymbol c$ になる。
類の中の番号 $r$ の特性値は $T$ の小さいほうから $r$ 番目（0 から数える）の固有値である。

無限行列をそのまま扱うことはできないので、$N$ 行で打ち切る。
打ち切りが効くのは係数が急速に減るからである。
$f_k^2 \gg |a|, |q|$ の行では漸化式から $c_{k+1}/c_k \approx -q/f_{k+1}^2$ となり、$|c_k|$ はおよそ $(|q|/4)^k/(k!)^2$ の速さで、指数関数より速く減る。
減り始める位置は $f_k^2$ が $|q|$ を超える所なので、必要な行数は $\sqrt{|q|}$ に比例して増える。

### 係数の求め方

`MathieuPlan::new` は、打ち切った各行列について、求める番号の固有値だけを Sturm 列による二分法で求め、逆反復で固有ベクトルの最大成分の位置を決める（`SpheroidalPlan::new` も同じ手順を使う）。
二分法の 1 段と逆反復の 1 回はどちらも $O(N)$ の演算で、メモリ使用量も $O(N)$ である。
係数そのものは求めた固有値を漸化式に入れ、両端から最大成分の位置へ向かって尺度化した算術で組み直す。
最大成分より先では係数が急速に減る解（最小解）が欲しいが、前向きの漸化式は増大する解（優越解）を拾うので不安定である。
後ろ向きに回すと最小解が支配的になり、相対誤差が増えない。
組み直した係数は Euclid ノルムが 1 になるように正規化し、規約の符号に合わせる。

`SpectralNormalization::Standard` は上の $\int\operatorname{ce}_n^2 = \pi$ の規格化、`SpectralNormalization::UnitL2` は $[0, 2\pi]$ で $L^2$ ノルムが 1 の規格化を選ぶ。
二つの違いは定数倍 $1/\sqrt\pi$ だけである。
$q = 0$ では行列が対角なので固有値問題を解かず、$a = n^2$ と単位ベクトルの係数を返す。

### 打ち切りの倍加と受け入れ条件

打ち切りの行数は `SpectralOptions` の `SpectralTerms`（既定は最小 16、最大 256）で決まる。
この節の規則は `MathieuPlan` と `SpheroidalPlan` に共通で、回転楕円体では $a$ を $\lambda_{mn}$、$q$ を $c$ に読み替える。
最初の行数は $\max(\text{最小}, j + 8)$ で、$j$ は類の中の番号（Mathieu 関数では $r$、回転楕円体では $\lfloor (n - m)/2 \rfloor$）である。
ここから行数を 2 倍にしながら解き直し、直前の打ち切りとの比較で次の 4 つがすべて満たされたら受け入れる。

1. 特性値の変化が $\max(\varepsilon_{\mathrm{abs}}, \varepsilon_{\mathrm{rel}}|a|)$ 以下である。
2. 打ち切った固有方程式の残差（最初に省いた行を含む）が $\sqrt{\varepsilon}\max(|a|, 1)$ 以下である。
   $\varepsilon$ はスカラー型の機械イプシロンで、これを超えると行列の丸めでは説明できない破綻とみなす。
3. 係数の変化の最大値が $\max(\varepsilon_{\mathrm{abs}}, \varepsilon_{\mathrm{rel}})$ 以下である。
4. 省いた係数の絶対値の和を見積もった値が $\max(\varepsilon_{\mathrm{abs}}, \varepsilon_{\mathrm{rel}})$ 以下である。

許容誤差 $\varepsilon_{\mathrm{abs}}$、$\varepsilon_{\mathrm{rel}}$ は `SpectralOptions::with_tolerance` で与え、既定は `f64` と `f32` のどちらでも $10^{-13}$ である。
係数と特性値はどちらのスカラー型でも `f64` で計算し、条件 1、3、4 はスカラー型によらない。
条件 2 の $\sqrt{\varepsilon}$ だけは `f32` で大きくなるので、`f32` の Plan は同じか少ない行数で受け入れられる。
比較する直前の打ち切りが必要なので、$q \ne 0$ では少なくとも 1 回は倍加する。

省いた係数の推定は、省いた行で対角が $f_k^2$ 以上、副対角が $|q|$ 以下であることを使う（回転楕円体では対角の下界と副対角の上界を $l(l+1)$ と $x^2$ の行列要素から作る）。
対角と特性値の差の下界を $G$、副対角の上界を $E$ とし、$t = E/G < 1/2$ のとき、最小解の隣り合う比は $\rho = 2t/(1 + \sqrt{1 - 4t^2})$ 以下になる（$\rho = t(1+\rho^2)$ の小さいほうの解）。
省いた係数の和は最後に残した係数に $\rho/(1-\rho)$ を掛けた等比級数で見積もる。
これは推定であり、厳密な上界ではない。

最大の行数に達しても受け入れられなければ、`ConvergenceFailure`（`TruncationLimit`）を返し、残差と計算量の計数を付ける。
最大の行数は次数やパラメータに合わせて自動では増えないので、このときは `SpectralTerms::new(minimum, maximum)` で最大を上げ、`SpectralOptions::with_terms` で渡す。
$q \ne 0$ では二つの打ち切りを比べる余地として $\max(\text{最小}, j + 8) < \text{最大}$ が必要で、満たさない番号は準備の前に `InvalidInput`（`OutOfRange`）になる。
準備のメモリ使用量は最大の行数を $N_{\max}$ として $32N_{\max}^2 + 512N_{\max} + 4096$ バイトを上限として先に確かめ、`SpectralOptions::with_preparation_bytes`（既定 64 MiB）を超えると `ResourceLimit` を返す。
準備と各評価の計算量は、それぞれ `SpectralOptions::with_iteration_budget`（既定 2,097,152 単位）で上限を決め、超えると `ConvergenceFailure`（`IterationLimit`）になる。

`MathieuPlan::diagnostics` と `SpheroidalPlan::diagnostics` が返す `SpectralDiagnostics` は、残した係数の数（`terms`）、倍加の回数（`refinements`）、固有方程式の残差（`eigen_residual`）、最後の二つの打ち切りの間の係数の変化（`coefficient_change`）、省いた係数の推定（`truncation_bound`）、準備の計算量（`work`）、メモリ使用量の上界（`preparation_bytes`）を持つ。
残差・変化・推定は Plan のスカラー型によらず `f64` で計算した絶対値である。

### 特性値と打ち切りの検算

次のセルは、$q$ と打ち切りの最大の行数を選び、$a_0, b_1, a_1, b_2, a_2$ の Plan を作る。
表は特性値、上の小さい $q$ の級数の値、その差、`SpectralDiagnostics` の項目を示す。
級数は独立な検算で、差は $q$ の次の冪の大きさで減るはずである。
グラフは $\operatorname{ce}_0$ の Fourier 係数の絶対値 $|A_{2k}|$ を周波数 $2k$ に対して対数軸で描き、受け入れの許容誤差 $10^{-13}$ を横線で示す。
最大の行数を小さくすると、大きい $q$ で `TruncationLimit` が表の状態の列に現れる。

```rust
//| id: special-mathieu-characteristic-limit
//| ref: special-mathieu-characteristic-limit
//| title: Mathieu の特性値、小さい q の級数と打ち切りの診断
//| run: reactive
//| crates: [scioxide-core, scioxide-special]
//| inputs:
//|   q: {"type":"range","label":"パラメータ q","description":"Mathieu 方程式の q。0 では固有値問題を解かない。","min":0,"max":400,"step":0.05,"value":1}
//|   maximum: {"type":"select","label":"最大の行数","description":"SpectralTerms の最大。最小は 16。","options":["32","64","256"],"value":"256"}
//| cases:
//|   - {"id":"zero","label":"q = 0","description":"特性値は n² に一致し、倍加は 0 回になる。","inputs":{"q":0}}
//|   - {"id":"small","label":"q = 0.1","description":"級数との差が丸めの水準まで下がる。","inputs":{"q":0.1}}
//|   - {"id":"large","label":"q = 300","description":"係数の数が 64 に増え、a₀ と b₁ が一致して見える。","inputs":{"q":300}}
//|   - {"id":"truncated","label":"q = 300、最大 32 行","description":"32 行では受け入れられず TruncationLimit になる。","inputs":{"q":300,"maximum":"32"}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"characteristics","path":"/rows/0/1","approx":{"value":-0.45513860410741364,"rtol":1e-12}}
//|       - {"artifact":"characteristics","path":"/rows/2/1","approx":{"value":1.8591080725143634,"rtol":1e-12}}
//|       - {"artifact":"characteristics","path":"/rows/0/5","equals":1}
//|   - case: zero
//|     expect:
//|       - {"artifact":"characteristics","path":"/rows/4/1","approx":{"value":4,"atol":1e-15}}
//|       - {"artifact":"characteristics","path":"/rows/4/5","equals":0}
//|   - case: small
//|     expect:
//|       - {"artifact":"characteristics","path":"/rows/0/3","range":{"max":1e-12}}
//|       - {"artifact":"characteristics","path":"/rows/2/3","range":{"max":1e-12}}
//|       - {"artifact":"characteristics","path":"/rows/4/3","range":{"max":1e-10}}
//|   - case: large
//|     expect:
//|       - {"artifact":"characteristics","path":"/rows/0/1","approx":{"value":-565.6108284287334,"rtol":1e-12}}
//|       - {"artifact":"characteristics","path":"/rows/0/4","equals":64}
//|   - case: truncated
//|     expect:
//|       - {"artifact":"characteristics","path":"/rows/0/8","equals":"TruncationLimit"}
//|       - {"artifact":"characteristics","path":"/rows/0/1","equals":null}
use scioxide_core::SciOxideErrorView;
use scioxide_special::{
    MathieuParity, MathieuPlan, SpectralNormalization, SpectralOptions, SpectralTerms,
};

let maximum: usize = maximum.parse().map_err(|_| "最大の行数が読めない")?;
let terms = SpectralTerms::new(16, maximum).map_err(|e| e.to_string())?;
let options = SpectralOptions::<f64>::default().with_terms(terms);
// DLMF 28.6.1–28.6.5 の級数（独立な検算）。Horner 法で q² の多項式を評価する。
let q2 = q * q;
let a0 = q2 * (-0.5 + q2 * (7.0 / 128.0 + q2 * (-29.0 / 2304.0 + q2 * 68687.0 / 18874368.0)));
let even = 1.0 + q2 * (-1.0 / 8.0 + q2 * (-1.0 / 1536.0 + q2 * 49.0 / 589824.0));
let odd = q * (1.0 + q2 * (-1.0 / 64.0 + q2 * 11.0 / 36864.0));
let (b1, a1) = (even - odd, even + odd);
let b2 = 4.0 + q2 * (-1.0 / 12.0 + q2 * (5.0 / 13824.0 - q2 * 289.0 / 79626240.0));
let a2 = 4.0 + q2 * (5.0 / 12.0 + q2 * (-763.0 / 13824.0 + q2 * 1002401.0 / 79626240.0));
let modes = [
    ("a₀", 0, MathieuParity::Even, a0),
    ("b₁", 1, MathieuParity::Odd, b1),
    ("a₁", 1, MathieuParity::Even, a1),
    ("b₂", 2, MathieuParity::Odd, b2),
    ("a₂", 2, MathieuParity::Even, a2),
];
let mut rows = Vec::new();
let mut coefficients = Vec::new();
for (name, order, parity, expected) in modes {
    // 級数は q ≤ 1 でだけ比べる（収束半径が有限）
    let expected = (q <= 1.0).then_some(expected);
    let plan = MathieuPlan::new(order, parity, q, SpectralNormalization::Standard, options);
    match plan {
        Ok(plan) => {
            let a = plan.characteristic_value().map_err(|e| e.to_string())?;
            let d = plan.diagnostics();
            rows.push((
                name,
                Some(a),
                expected,
                expected.map(|value| (a - value).abs()),
                Some(d.terms() as u32),
                Some(d.refinements() as u32),
                Some(d.eigen_residual()),
                Some(d.truncation_bound()),
                "受け入れ".to_string(),
            ));
            if order == 0 {
                for k in 0..plan.coefficient_count() {
                    let value = plan.coefficient(k).map_err(|e| e.to_string())?;
                    let magnitude = value.round().map_err(|e| e.to_string())?.abs();
                    // 0 は対数軸に描けないので除く（q = 0 では A₀ 以外が 0）
                    if magnitude > 0.0 {
                        coefficients.push([2.0 * k as f64, magnitude]);
                    }
                }
            }
        }
        Err(e) => {
            // 失敗の分類と、打ち切りの失敗ならその理由を状態の列に出す
            let status = match e.view() {
                SciOxideErrorView::ConvergenceFailure { reason, .. } => format!("{reason:?}"),
                _ => format!("{:?}", e.kind()),
            };
            rows.push((name, None, expected, None, None, None, None, None, status));
        }
    }
}
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let fixed12 = serde_json::json!({ "fractionDigits": 12 });
let columns = serde_json::json!([
    { "key": "0", "label": "特性値" },
    { "key": "1", "label": "Plan の値", "type": "number", "format": fixed12, "nullText": "—" },
    { "key": "2", "label": "級数の値", "type": "number", "format": fixed12, "nullText": "q > 1" },
    { "key": "3", "label": "差の絶対値", "type": "number", "format": sci3, "nullText": "—" },
    { "key": "4", "label": "係数の数 N", "type": "integer", "nullText": "—" },
    { "key": "5", "label": "倍加の回数", "type": "integer", "nullText": "—" },
    { "key": "6", "label": "固有残差", "type": "number", "format": sci3, "nullText": "—" },
    { "key": "7", "label": "省いた係数の推定", "type": "number", "format": sci3, "nullText": "—" },
    { "key": "8", "label": "状態" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "characteristics" })
);
emit_chart!(serde_json::json!({
    "kind": "scatter",
    "series": [{ "name": "|A₂ₖ|（ce₀）", "points": coefficients }],
    "xLabel": "周波数 2k [-]",
    "yLabel": "係数の絶対値 |A₂ₖ| [-]",
    "yType": "log",
    "annotations": [{ "kind": "line", "axis": "y", "value": 1e-13, "label": "許容誤差 10⁻¹³" }],
    "dataZoom": true,
    "tooltip": true
}));
```

既定の $q = 1$ では、5 つの特性値はどれも 32 行（16 行からの倍加 1 回）で受け入れられ、固有残差は $10^{-14}$ 程度である。
$a_0(1) = -0.455138604107414$ と $a_1(1) = 1.859108072514363$ は、参照値と 12 桁以上一致する。
$q = 1$ では級数がまだ収束しきらず、差は $a_0$ で $9 \times 10^{-4}$、$a_2$ で $3 \times 10^{-3}$ と大きい。
$q = 0.1$ に下げると差は $a_0$ で $1.2 \times 10^{-13}$、$a_1$ と $b_1$ で $6 \times 10^{-13}$、$a_2$ で $3.6 \times 10^{-11}$ になり、どれも級数の次の冪の項（$a_2$ なら $q^8$ の項 $\approx 3.6 \times 10^{-11}$）の大きさにそろう。
差が次の項の大きさで説明できるので、Plan の値は級数の打ち切りより正確である。
$q = 0$ では固有値問題を解かず、倍加の回数が 0、特性値が厳密に $n^2$ になる。

グラフの $|A_{2k}|$ は、$q = 1$ では周波数 16 で $10^{-14}$ まで下がり、その先は指数関数より速く減る。
$q = 300$ では係数が周波数 2 で最大（0.59）になり、周波数 10 でも 0.14 とゆっくり減ってから、周波数 50 の付近で $10^{-14}$ を下回る。
受け入れまでには 64 行（倍加 2 回）を使う。
このとき $a_0$ と $b_1$、$a_1$ と $b_2$ は表示の桁ですべて一致し、$a_0 = -565.61$ は漸近形 $-2q + 2\sqrt q = -565.36$ に近い。
最大の行数を 32 にすると、$q = 300$ ではどのモードも二つの打ち切りが一致する前に上限に達し、状態の列に `TruncationLimit` が出る。
このとき値は返らず、表の値の列は空になる。


## 角関数と動径関数の評価

`MathieuPlan::angular(z)` は、保持した係数で Fourier 級数を足し、$\operatorname{ce}_n(z,q)$ または $\operatorname{se}_n(z,q)$ とその $z$ による導関数を返す。
$z$ は有限の実数または複素数（ラジアン）で、角関数は整関数である。
位相は $\cos 2z$ や $\sin 2z$ を項ごとに計算せず、$e^{2iz}$ を掛けて進める。
大きい $|z|$ で $2z$ を作ると桁が落ちるので、増分は $\sin z$、$\cos z$ から作る。
推定誤差は位相の漸化の丸め、係数の誤差、省いた係数の推定を含む。
複素数の $z$ では、周波数 $\nu$ の項が $e^{\nu|\operatorname{Im}z|}$ 倍に増えるので、省いた係数の寄与も同じ割合で増える。
省いた係数の比 $\rho$ と $e^{2|\operatorname{Im}z|}$ の積が 1 に達すると、級数が収束しないので `NumericalInstability`（`LossOfSignificance`）を返す。
計算量は係数 1 個につき 1 単位である。

動径（変形）Mathieu 方程式は $z \to iz$ と置いた $w'' - (a - 2q\cosh 2z)\,w = 0$（DLMF 28.20.1）で、楕円柱座標の動径方向に現れる。
その解 $\operatorname{Mc}_n^{(j)}(z,q)$、$\operatorname{Ms}_n^{(j)}(z,q)$ は、角関数と同じ係数を使った Bessel 関数の積の級数（DLMF 28.24.1–28.24.4）

$$
\operatorname{Mc}_{2r}^{(j)}(z,q) = \frac{1}{\varepsilon_s A_{2s}}\sum_{k\ge0} (-1)^{r+k} A_{2k}\left[J_{k-s}(u)\,\mathcal C^{(j)}_{k+s}(v) + J_{k+s}(u)\,\mathcal C^{(j)}_{k-s}(v)\right],\qquad u = \sqrt q\,e^{-z},\ v = \sqrt q\,e^{z}
$$

で計算する（ほかの 3 類も同じ形）。
$\mathcal C^{(1)} = J$、$\mathcal C^{(2)} = Y$、$\mathcal C^{(3)} = H^{(1)}$、$\mathcal C^{(4)} = H^{(2)}$ で、`RadialKind` の `First`、`Second`、`Third`、`Fourth` がこれを選ぶ。
$s$ は任意に選べる添字で、実装は係数の絶対値が最大の位置を選び、$A_{2s}$ で割ることの誤差を最小にする（$\varepsilon_0 = 2$、それ以外は 1）。
この級数が動径関数の規格化を決めるので、角関数の規格化をどちらに選んでも動径関数は変わらない。
第 3 種と第 4 種は第 1 種 $\pm i \cdot$ 第 2 種で、$z$ の実部が大きいとき外向き・内向きの波を表す。
$q < 0$ では $\sqrt q$ を主値の平方根にとるので、実数の $z$ でも値は複素数になる。
$q = 0$ では第 1 種が $n = 0$ で 1、それ以外で 0 になり、第 2〜4 種類は発散するので `DomainError`（`Pole`）を返す。
計算量は係数 1 個につき Bessel 関数の値と導関数の組を 2 つで、省いた項の寄与は係数の推定に Bessel 関数の次数と座標による増大を掛けて見積もる。
これも推定で、上界ではない。

第 1 種と第 2 種の Wronskian は $q$ と $z$ によらず

$$
\operatorname{Mc}_n^{(1)}\,\frac{d}{dz}\operatorname{Mc}_n^{(2)} - \frac{d}{dz}\operatorname{Mc}_n^{(1)}\,\operatorname{Mc}_n^{(2)} = \frac{2}{\pi}
$$

である（DLMF 28.20.21、$\operatorname{Ms}$ も同じ）。
これは二つの級数を独立に足した結果の検算になる。

次のセルは、次数 $n$、偶奇、$q > 0$ を選び、Plan を一つ作って角関数を $[0, \pi]$ で描き、$q = 0$ の $\cos nz$ または $\sin nz$ を破線で重ねる。
表は、角関数の規格化 $\int_0^{2\pi} w^2\,dz$ を 64 点の台形則（周期関数では指数的に収束する独立な求積）で求めた値と $\pi$ の差、いくつかの $z$ での動径関数の Wronskian と $2/\pi$ の差、第 3 種と第 1 種 $+ i\cdot$ 第 2 種の差を示す。

```rust
//| id: special-mathieu-functions
//| ref: special-mathieu-functions
//| title: Mathieu の角関数の規格化と動径関数の Wronskian
//| run: reactive
//| crates: [scioxide-core, scioxide-special]
//| inputs:
//|   order: {"type":"integer","label":"次数 n","description":"奇関数では 1 以上。","min":0,"max":8,"value":2}
//|   odd: {"type":"checkbox","label":"奇関数 seₙ と Msₙ を使う","value":false}
//|   q: {"type":"range","label":"パラメータ q","min":0.5,"max":30,"step":0.5,"value":5}
//| cases:
//|   - {"id":"odd-large-q","label":"se₃、q = 30","description":"q を大きくすると角関数は z = π/2 の付近に集まる。","inputs":{"order":3,"odd":true,"q":30}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"checks","path":"/rows/0/2","range":{"min":-1e-12,"max":1e-12}}
//|       - {"artifact":"checks","path":"/rows/1/2","range":{"min":-1e-12,"max":1e-12}}
//|       - {"artifact":"checks","path":"/rows/6/2","range":{"max":1e-12}}
//|   - case: odd-large-q
//|     expect:
//|       - {"artifact":"checks","path":"/rows/0/2","range":{"min":-1e-12,"max":1e-12}}
//|       - {"artifact":"checks","path":"/rows/5/2","range":{"min":-1e-12,"max":1e-12}}
use scioxide_core::Complex;
use scioxide_special::{
    MathieuParity, MathieuPlan, RadialKind, SpectralNormalization, SpectralOptions,
};
use std::f64::consts::{FRAC_1_SQRT_2, PI};

let n = order as u32;
let parity = if odd {
    MathieuParity::Odd
} else {
    MathieuParity::Even
};
let normalization = SpectralNormalization::Standard;
let plan = MathieuPlan::new(n, parity, q, normalization, SpectralOptions::default())
    .map_err(|e| e.to_string())?;
let angular = |z: f64| {
    plan.angular(z)
        .and_then(|r| r.try_value())
        .map_err(|e| e.to_string())
};
// 動径関数の値と z による導関数
let radial = |z: f64, kind| {
    plan.radial(z, kind)
        .and_then(|r| Ok((r.try_value()?, r.try_derivative()?)))
        .map_err(|e| e.to_string())
};
let mut curve = Vec::new();
let mut limit = Vec::new();
for i in 0..=120 {
    let z = PI * f64::from(i) / 120.0;
    curve.push([z, angular(z)?]);
    // q = 0 の極限（参照値、f64 の標準関数）
    let reference = match (odd, n) {
        (true, _) => (f64::from(n) * z).sin(),
        (false, 0) => FRAC_1_SQRT_2,
        (false, _) => (f64::from(n) * z).cos(),
    };
    limit.push([z, reference]);
}
// 台形則による ∫₀^{2π} w² dz（独立な求積）
let mut norm = 0.0;
for i in 0..64 {
    norm += angular(2.0 * PI * f64::from(i) / 64.0)?.powi(2) * 2.0 * PI / 64.0;
}
let mut rows = vec![("∫₀^{2π} w² dz − π", None, norm - PI)];
for z in [0.0, 0.5, 1.5] {
    let (m1, d1) = radial(z, RadialKind::First)?;
    let (m2, d2) = radial(z, RadialKind::Second)?;
    let (m3, _) = radial(z, RadialKind::Third)?;
    let wronskian = (m1 * d2 - d1 * m2).re;
    rows.push(("W{M⁽¹⁾, M⁽²⁾} − 2/π", Some(z), wronskian - 2.0 / PI));
    let combined = m3 - (m1 + m2 * Complex::new(0.0, 1.0));
    rows.push(("|M⁽³⁾ − (M⁽¹⁾ + iM⁽²⁾)|", Some(z), combined.norm()));
}
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let columns = serde_json::json!([
    { "key": "0", "label": "検算" },
    { "key": "1", "label": "動径座標 z [-]", "type": "number", "nullText": "—" },
    { "key": "2", "label": "差 [-]", "type": "number", "format": sci3 }
]);
emit_line_chart!(
    &vec![
        serde_json::json!({ "name": "Plan の角関数", "points": curve }),
        serde_json::json!({ "name": "q = 0 の極限", "points": limit, "style": { "lineType": "dashed" } })
    ],
    options = &serde_json::json!({ "xLabel": "角度 z [rad]", "yLabel": "角関数 w(z) [-]" })
);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "checks" })
);
```

既定の $\operatorname{ce}_2$、$q = 5$ では、$z = 0$ の値が $\cos 0 = 1$ から 0.735 に下がり、最大は $z \approx 0.21\pi$ の 0.92、$z = \pi/2$ の値は $-0.72$ になる。
方程式を $w'' + (a - V(z))w = 0$、$V(z) = 2q\cos 2z$ と見ると、$q > 0$ のポテンシャル $V$ は $z = \pi/2$ で最小になるので、$q$ を大きくすると関数はその付近に集まる。
$\operatorname{se}_3$、$q = 30$ のケースでは、値は $z = \pi/8$ で 0.06 しかなく、$|w| > 0.5$ の範囲は $z = 0.23\pi$ から $0.77\pi$ の間に限られる。
台形則で求めた $\int_0^{2\pi} w^2\,dz$ と $\pi$ の差は $4 \times 10^{-16}$ 以下で、規格化 `Standard` が DLMF の規約どおりであることがわかる。
動径関数の Wronskian と $2/\pi$ の差は、$z = 0$、0.5、1.5 のどれでも $4 \times 10^{-16}$ 以下である。
第 1 種と第 2 種は別々の Bessel 関数の級数なので、この一致は二つの級数と係数の両方の検算になる。
第 3 種と第 1 種 $+ i\cdot$ 第 2 種の差も丸めの水準である。


## 精度の保証

Mathieu 関数には、関数全体で一様な ULP の仕様はない。
許容誤差は打ち切りの受け入れ条件を決めるもので、出力の精度を約束するものではない。
`SpectralDiagnostics` の残差と、各評価が返す推定誤差（`SpecialFunctionResult` の誤差）は計算の状態を表す推定で、包含区間ではない。

照合試験は独立に生成した参照値との差を次の幅で確かめている。
特性値は $q = 1$ の 5 つのモードで参照値と $2 \times 10^{-12}$ 以内である。
$q = 10^{-4}$ から $1000$ と $q = -1$ の範囲で、角関数と動径関数（第 1 種と第 2 種）の値と導関数は、実数と複素数の $z$ で独立な参照値と、`f64` では相対 $5 \times 10^{-9}$ または絶対 $5 \times 10^{-12}$ の大きいほう、`f32` では相対 $10^{-3}$ または絶対 $2 \times 10^{-5}$ の大きいほうの範囲で一致する。
Wronskian は $q = 2$ の $n = 1, 2, 3, 6$ と両方の偶奇で、$2/\pi$ との差を絶対 $10^{-8}$ の範囲で試験している。
`f32` の Plan も内部は `f64` で計算し、最後に `f32` へ丸める。

## API

| 項目 | 役割 |
|---|---|
| `MathieuPlan::new(order, parity, q, normalization, options)` | 特性値と Fourier 係数を準備する。`build(.., scope)` は同じ準備をスコープの中で行う |
| `MathieuPlan::characteristic_value`、`diagnostics` | $a_n(q)$ または $b_n(q)$、打ち切りの診断 |
| `MathieuPlan::angular(z)`、`angular_scoped(z, scope)` | $\operatorname{ce}_n$、$\operatorname{se}_n$ と導関数の詳細な結果 |
| `MathieuPlan::radial(z, kind)`、`radial_scoped(z, kind, scope)` | $\operatorname{Mc}_n^{(j)}$、$\operatorname{Ms}_n^{(j)}$ と導関数の詳細な結果（複素数） |
| `MathieuPlan::coefficient(k)`、`coefficient_count` | 選んだ規格化での Fourier 係数（尺度化した値）とその個数 |
| `MathieuPlan::order`、`parity`、`parameter`、`normalization` | 準備に使った値 |
| `mathieu_a(n, q)`、`mathieu_b(n, q)` | 特性値のワンショット関数 |
| `mathieu_ce(n, q, z)`、`mathieu_se(n, q, z)` | 角関数のワンショット関数（実数・複素数の `z`） |
| `mathieu_mc(n, q, z, kind)`、`mathieu_ms(n, q, z, kind)` | 動径関数のワンショット関数（複素数の値） |
| `MathieuParity` | `Even`（$\operatorname{ce}$、$\operatorname{Mc}$）と `Odd`（$\operatorname{se}$、$\operatorname{Ms}$） |
| `RadialKind` | 動径関数の種類 `First`、`Second`、`Third`、`Fourth`（回転楕円体関数と共通） |
| `SpectralNormalization` | 角関数の規格化 `Standard`、`UnitL2`（回転楕円体関数と共通） |
| `SpectralOptions` | 許容誤差（`with_tolerance`）、打ち切りの範囲（`with_terms`）、作業量の上限（`with_iteration_budget`）、メモリ使用量の上限（`with_preparation_bytes`） |
| `SpectralTerms::new(minimum, maximum)` | 打ち切りの最小と最大の行数。$2 \le$ 最小 $\le$ 最大でなければ `InvalidInput`（`OutOfRange`） |
| `SpectralDiagnostics` | `terms`、`refinements`、`eigen_residual`、`coefficient_change`、`truncation_bound`、`work`、`preparation_bytes` |

回転楕円体波動関数の Plan と関数は[回転楕円体波動関数の API](oxref:special-spheroidal-api) にまとめている。

多くの点で評価するときや、推定誤差・導関数・終了状態が必要なときは Plan を作る。
Plan は不変で、作った後は何度評価しても係数を作り直さない。
ワンショット関数 `mathieu_a`、`mathieu_ce`、`mathieu_mc` などは、既定の `SpectralOptions` と `Standard` の規格化で Plan を内部に一つ作り、一度だけ評価して通常の値を返す。
準備と評価は一つの作業量の上限（2,097,152 単位）を共有し、結果は同じ引数の Plan の評価とビット単位で同じである。
ワンショット関数にはオプション付き形式 `*_with_options` とスコープ付き API `*_scoped` はなく、その用途には Plan の `build` と `*_scoped` のメソッドを使う。
スコープ付き API の評価の意味（取り消し、期限、親の計数への加算）は[詳細な結果とオプション](../../api/results-and-options/)で説明している。

エラーは次のとおりである。
$q$ が NaN または無限大なら `NonFinite`、奇関数で $n = 0$ や、打ち切りの範囲に収まらない番号なら `InvalidInput`（`OutOfRange`）である。
ワンショット関数では、この範囲は偶関数で $n \ge 496$、奇関数で $n \ge 497$（$q = 0$ ではそれぞれ 512 と 513）になる。
$q = 0$ の第 2〜4 種類の動径関数は `DomainError`（`Pole`）である。
行列の要素や係数が `f64` の範囲を外れたとき、$|\operatorname{Im} z|$ が大きすぎて角関数の級数が収束しないとき、$\sqrt q\,e^{\pm z}$ があふれるか 0 になるとき、残した係数で動径関数の級数が収束しないときは `NumericalInstability`（`LossOfSignificance`）を返す。
ワンショット関数の値がスカラー型の範囲を超えると `NumericalInstability`（`Overflow`）、Plan の `characteristic_value` では `NumericalInstability`（`LossOfSignificance`）になる。

## まとめ

Mathieu 関数の特性値は Fourier 係数の対称三重対角行列の固有値として求まり、打ち切りの行数は二つの打ち切りの比較と省いた係数の推定で決まる。
`SpectralDiagnostics` の係数の数と倍加の回数を見れば、$q$ に対して打ち切りがどれだけ大きくなったかがわかり、`TruncationLimit` が出たら `SpectralTerms` の最大を上げる。
同じ $q$ で多くの点を評価するときは Plan を作り、一回だけ値が欲しいときはワンショット関数を使う。
推定誤差は包含区間ではないので、重要な値は Wronskian や小さい $q$ の級数のような独立な関係で確かめる。

同じ打ち切りの規則で Ferrers 関数の展開を解く回転楕円体の場合は、[回転楕円体波動関数](../spheroidal-wave-functions/)で特性値の球極限と動径関数の接続を確かめる。
特性値で安定図を描く応用は[Paul トラップの安定領域](../../examples/paul-trap-stability/)にある。
