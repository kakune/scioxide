標準正規分布の分布関数 $\Phi(x)$ と上側の裾 $Q(x) = 1 - \Phi(x)$ は、仮説検定の $p$ 値、信頼区間、Black–Scholes 公式、極値統計に現れる。
$x$ が大きいと $Q(x)$ は $e^{-x^2/2}$ のように減り、binary64 では $x > 8.29$ で $\Phi(x)$ が 1 に丸められるので、$1 - \Phi(x)$ の引き算では裾の値が残らない。
このページは `scioxide-special` の正規分布の関数（分布関数、上側の裾、その対数形、分位点、対数確率からの逆関数）と、二変量正規分布の象限確率を与える Owen の $T$ 関数を説明する。
正規分布の関数が使う尺度化相補誤差関数 $\operatorname{erfcx}(x) = e^{x^2}\operatorname{erfc}(x)$ の核と逆誤差関数は、[誤差関数・Dawson 積分・逆誤差関数](../error-functions/) で説明する。
ULP は真の値の位置での浮動小数点数の間隔、$\varepsilon = 2^{-52}$ は binary64 の計算機イプシロンである。

## 標準正規分布の分布関数と裾

標準正規分布の確率密度を $\varphi(x) = e^{-x^2/2}/\sqrt{2\pi}$ とすると、分布関数と上側の裾は次のとおりである。

$$
\Phi(x) = \int_{-\infty}^x \varphi(t)\,dt = \tfrac12 \operatorname{erfc}\!\left(-\frac{x}{\sqrt{2}}\right), \qquad
Q(x) = 1 - \Phi(x) = \tfrac12 \operatorname{erfc}\!\left(\frac{x}{\sqrt{2}}\right) = \Phi(-x).
$$

`normal_cdf` は $\Phi(x)$、`normal_sf` は $Q(x)$ を返し、どちらも実数（`RealScalar`）のすべての有限な $x$ を受け付けてエラー条件を持たない。
$Q(x)$ は $x > 37.52$ で正規化数の範囲を下回って非正規化数になり、$x > 38.48$ では 0 に丸められる。
`normal_sf` は $\lvert x \rvert > 39$ では計算せずに 0（`normal_cdf` では $x < -39$ で 0）を返す。

### 裾の直接評価

`normal_sf` は、どちらの裾も 1 からの引き算をせずに次の式で計算する。

$$
Q(\lvert x \rvert) = \tfrac12 \operatorname{erfcx}\!\left(\frac{\lvert x \rvert}{\sqrt{2}}\right) e^{-x^2/2}.
$$

$\operatorname{erfcx}$ はゆっくり変わる因子で、引数 $\lvert x \rvert/\sqrt{2}$ の丸めは結果にほとんど効かない。
一方、指数 $x^2/2$ は $x = 38$ で 722 に達し、その丸め誤差 $\delta$ は結果の相対誤差 $\delta$ になる（$\mathrm{ulp}(722) = 1.1 \times 10^{-13}$）。
そこで $x^2/2 = s + e$ を誤差のない積（2 ワードに分ける積）で厳密に分け、$e^{-s}(1 - e)$ として下位のワード $e$ を補正する。
$x \ge 0$ の $\Phi(x)$ は $1 - Q(x)$ で作り、$x < 0$ の $\Phi(x)$ は $Q(-x)$ を直接返す。
演算の回数は一定で、`normal_cdf` と `normal_sf` はスコープ付き API を持たない。

精度は独立に生成した参照値で確かめた $-38 \le x \le 38$ の範囲で、binary64 が 8 ULP、binary32 が 1 ULP である（binary32 は binary64 で計算して一度だけ丸める）。
オプション付き形式 `normal_cdf_with_options`、`normal_sf_with_options` が返す推定誤差は値の 64 単位（$64\varepsilon\lvert v\rvert$）の包絡で、ULP の目標より大きく見積もった値である。

### Mills 比と漸近展開

上側の裾を密度で割った比 $R(x) = Q(x)/\varphi(x)$ を Mills 比という。
$\operatorname{erfcx}$ を使うと $R(x) = \sqrt{\pi/2}\,\operatorname{erfcx}(x/\sqrt{2})$ で、$e^{-x^2/2}$ を含まないので、裾が型の範囲を下回っても値を持つ。
大きな $x$ では DLMF 7.12.1 から次の漸近展開が従う。

$$
R(x) \sim \frac{1}{x}\left(1 - \frac{1}{x^2} + \frac{1 \cdot 3}{x^4} - \frac{1 \cdot 3 \cdot 5}{x^6} + \cdots\right) = \frac{1}{x}\sum_{m=0}^{\infty} (-1)^m \frac{(2m - 1)!!}{x^{2m}}.
$$

この級数は発散級数で、項は $m \approx x^2/2$ で最小になってから増える。
打ち切った和の誤差は最初に捨てた項より小さく、$x$ が大きいほど少ない項で精度が上がる。
また、$x > 0$ では Gordon（1941）の不等式 $x/(1 + x^2) < R(x) < 1/x$ が成り立ち、$x \to \infty$ で $R(x)$ は下限に近づく。

### 対数形

$Q(x)$ が型の範囲を下回る裾や、確率の積を和で扱う尤度計算には、対数形を使う。
`normal_log_cdf` は $\ln\Phi(x)$ を、$x \le 0$ では $\ln\bigl(\tfrac12 \operatorname{erfcx}(-x/\sqrt{2})\bigr) - x^2/2$（$x^2/2$ は 2 ワードで厳密に作る）、$x > 0$ では $\operatorname{ln1p}(-Q(x))$ で計算し、確率そのものを作らない。
`normal_log_sf(x)` は $\ln Q(x) = \ln\Phi(-x)$ で、同じ計算を $-x$ で行う。
エラーになるのは $x^2/2$ があふれる所（`normal_log_cdf` では $x < -1.9 \times 10^{154}$、`normal_log_sf` では $x > 1.9 \times 10^{154}$）だけで、`NumericalInstability`（`Overflow`）を返す。
反対側の裾では $\ln(1 - Q)$ が 0 に近づくだけなので、エラーにならない。
精度は分布関数と同じで、$-38 \le x \le 38$ の binary64 で 8 ULP、binary32 で 1 ULP である。

対数形の値から確率に戻すときの相対精度には限界がある。
$\ln Q$ の絶対誤差 $\delta$ は $Q$ の相対誤差 $\delta$ になり、$\ln Q = -804.6$（$x = 40$）を binary64 で表すだけで $\mathrm{ulp}(804.6)/2 = 5.7 \times 10^{-14}$ の丸めが入る。
裾の深いところでは、確率の相対誤差は $\varepsilon \lvert \ln Q \rvert$ の程度になると考えて使う。

### 分位点と対数確率からの逆関数

分位点 $\Phi^{-1}(p)$ は `normal_quantile`、上側の分位点 $Q^{-1}(p) = -\Phi^{-1}(p)$ は `normal_isf` が返す。
どちらも $\Phi^{-1}(p) = -\sqrt{2}\operatorname{erfcinv}(2p)$ を、小さい側の裾 $\min(p, 1 - p)$ を 2 倍して（2 倍は厳密）逆誤差関数の有理近似に渡すことで計算し、反復を使わない。
正の非正規化数の $p$ でも、binary64 で 4 ULP、binary32 で 1 ULP に収まる。
`normal_quantile` は $p = 0$ で $-\infty$、$p = 1$ で $+\infty$ を返し、$[0, 1]$ の外は `DomainError`（`OutsideDomain`）になる。

確率が型の最小の非正規化数より小さいときは、対数確率 $\ln p$ を受け取る `normal_inv_log_cdf`（$\ln\Phi(x) = \ln p$ の $x$）と `normal_inv_log_sf`（$\ln Q(x) = \ln q$ の $x$、前者の符号を反転した値）を使う。
$\ln p$ の大きさで方法を分ける。

- $\tfrac14 \le p \le 2^{-1/2}$ では、$1 - 2p$ を $-\operatorname{expm1}(\ln p + \ln 2)$ で作って `erfinv` に渡す。
  中央値の近くで $1 - 2p$ の小さなずれを丸めで失わないためである。
- $p > 2^{-1/2}$ では $\ln(1 - p) = \ln(1 - e^{\ln p})$ を作って反対側の裾に移す。
- $-36 < \ln p < \ln\tfrac14$ では $-\sqrt{2}\operatorname{erfcinv}(2e^{\ln p})$ を使う。
- $\ln p \le -36$ では、漸近形の初期値 $x_0 = -\sqrt{-2\ln p}$ から $\ln\Phi(x) - \ln p = 0$ に Newton 法を使う。
  導関数は $\varphi(x)/\Phi(x) = \sqrt{2/\pi}/\operatorname{erfcx}(-x/\sqrt{2})$ で、更新幅が 2 ULP 以下になったら止める。
  $\ln p < -\varepsilon^{-2}$ では初期値との差が 1 ULP 未満なので、初期値を返す。

Newton 法の 1 歩は `ProbabilityOptions` の作業量の上限（既定 65536）に数えられるので、この 2 つだけがスコープ付き API `normal_inv_log_cdf_scoped`、`normal_inv_log_sf_scoped` を持つ。
正の $\ln p$ は `DomainError`（`OutsideDomain`）、$\ln p = -\infty$ は `NonFinite` になる（確率 0 の極限は `normal_quantile(0)` を使う）。
$\ln p = 0$ には `normal_inv_log_cdf` が $+\infty$、`normal_inv_log_sf` が $-\infty$ を返す。
この 2 つには ULP の目標がなく、オプション付き形式は 64 単位の推定誤差を返す。

## 正規分布の上側の裾と Mills 比

次のセルは $x = 1$ から 40 までの 9 点で `normal_sf`、`1.0 - normal_cdf(x)`、`normal_log_sf` を求める。
Mills 比は `erfcx` から $R(x) = \sqrt{\pi/2}\operatorname{erfcx}(x/\sqrt{2})$ で作り、Gordon の不等式の上下限の間での位置 $(R - L)/(U - L)$（$L = x/(1 + x^2)$、$U = 1/x$）を出す。
この位置が 0 と 1 の間にあれば不等式を満たす。
独立検算として、Mills 比の漸近展開を $N$ 項で打ち切った和から $\ln\varphi(x) + \ln R_N(x)$ を f64 で作り、`normal_log_sf` との差を出す。
最後の列は `normal_inv_log_sf` で $\ln Q(x)$ から $x$ に戻した差である。

```rust
//| id: special-normal-log-sf-mills-check
//| ref: special-normal-log-sf-mills-check
//| title: 正規分布の上側の裾を Mills 比の漸近展開と比べる
//| run: reactive
//| crates: [scioxide-core, scioxide-special]
//| inputs:
//|   terms: {"type":"range","label":"漸近展開の項数 N","min":1,"max":8,"step":1,"value":4}
//| cases:
//|   - {"id":"one-term","label":"N = 1","description":"主項 1/x だけ。ln Q の差は 1/x² の程度で、x = 40 でも 6 × 10⁻⁴ 残る。","inputs":{"terms":1}}
//|   - {"id":"eight-terms","label":"N = 8","description":"x ≥ 20 では差が ln Q の丸めの程度まで下がり、x ≤ 2 では打ち切った和が負になって比べられない。","inputs":{"terms":8}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"tails","path":"/rows/3/1","approx":{"value":6.220960574271784e-16,"rtol":1e-14}}
//|       - {"artifact":"tails","path":"/rows/3/2","range":{"min":6.6e-16,"max":6.7e-16}}
//|       - {"artifact":"tails","path":"/rows/4/2","equals":0}
//|       - {"artifact":"tails","path":"/rows/7/1","approx":{"value":2.8854283600687843e-316,"rtol":1e-7}}
//|       - {"artifact":"tails","path":"/rows/8/1","equals":0}
//|       - {"artifact":"tails","path":"/rows/8/3","approx":{"value":-804.6084420137538,"rtol":1e-14}}
//|       - {"artifact":"tails","path":"/rows/8/4","approx":{"value":0.024984404205720571,"rtol":1e-14}}
//|       - {"artifact":"tails","path":"/rows/8/5","range":{"min":0,"max":1}}
//|       - {"artifact":"tails","path":"/rows/0/6","equals":null}
//|       - {"artifact":"tails","path":"/rows/8/6","range":{"min":1e-11,"max":3e-11}}
//|       - {"artifact":"tails","path":"/rows/8/7","range":{"min":-1e-12,"max":1e-12}}
//|   - case: one-term
//|     expect:
//|       - {"artifact":"tails","path":"/rows/8/6","range":{"min":6e-4,"max":6.5e-4}}

//|       - {"artifact":"tails","path":"/rows/1/6","equals":null}
//|       - {"artifact":"tails","path":"/rows/8/6","range":{"max":2e-13}}
use scioxide_core::RealScalar;
use scioxide_special::{erfcx, normal_cdf, normal_inv_log_sf, normal_log_sf, normal_sf};
use std::f64::consts::{FRAC_2_SQRT_PI, PI, SQRT_2};

let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let fixed4 = serde_json::json!({ "fractionDigits": 4 });
let n_terms = terms as u32;
let mut rows = Vec::new();
for x in [1.0, 2.0, 4.0, 8.0, 10.0, 20.0, 30.0, 38.0, 40.0] {
    let tail = normal_sf(x).map_err(|e| e.to_string())?;
    let naive = 1.0 - normal_cdf(x).map_err(|e| e.to_string())?;
    let log_tail = normal_log_sf(x).map_err(|e| e.to_string())?;
    // Mills 比 R = Q/φ = √(π/2) erfcx(x/√2)。√(π/2) = 1/(FRAC_2_SQRT_PI/√2)。
    let mills = erfcx(x / SQRT_2).map_err(|e| e.to_string())? * SQRT_2 / FRAC_2_SQRT_PI;
    // Gordon (1941) の不等式 x/(1 + x²) < R < 1/x の中での位置（0 から 1 の間に入る）。
    let (low, high) = (x / (1.0 + x * x), 1.0 / x);

    let mut term = 1.0;

        sum += term;
        term *= -(2.0 * f64::from(m) + 1.0) / (x * x);

    let log_phi = -0.5 * x * x - 0.5 * RealScalar::ln(2.0 * PI);
    // 打ち切った和が正でない（x が小さい）ときは比べない。
    let difference = (sum > 0.0).then(|| (log_tail - log_phi - RealScalar::ln(sum / x)).abs());

}

    { "key": "2", "label": "1 − Φ(x) [-]", "type": "number", "format": sci3 },
    { "key": "3", "label": "ln Q(x)（normal_log_sf） [-]", "type": "number", "format": fixed4 },
    { "key": "4", "label": "Mills 比 R(x) [-]", "type": "number", "format": sci3 },
    { "key": "5", "label": "Gordon の上下限での位置 [-]", "type": "number", "format": fixed4 },
    { "key": "6", "label": "漸近展開との差 [-]", "type": "number", "format": sci3, "nullText": "和が負" },
    { "key": "7", "label": "逆関数で戻した差 [-]", "type": "number", "format": sci3 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "tails" })
);
```

既定の $N = 4$ では、`normal_sf` は $x = 8$ で $6.221 \times 10^{-16}$、$x = 38$ で非正規化数 $2.885 \times 10^{-316}$ を返し、$x = 40$ では 0 になる。
`1.0 - normal_cdf(x)` は $x = 8$ で $6.66 \times 10^{-16}$（相対誤差 7 %）、$x \ge 10$ では 0 である。
`normal_log_sf` は $x = 40$ でも $\ln Q = -804.6084$ を返し、`normal_inv_log_sf` で戻した差は $x = 8$ の $1.8 \times 10^{-15}$ が最大である。
Mills 比の位置はどの行でも 0 と 1 の間にあり、$x$ が大きくなると $2/x^2$ のように 0 に近づく（$x = 40$ で 0.00125）。
漸近展開との差は $x = 2$ で 0.18、$x = 10$ で $9.7 \times 10^{-7}$、$x = 40$ で $1.6 \times 10^{-11}$ で、最初に捨てた項 $105/x^8$ の大きさにそろう。
$x = 1$ では打ち切った和 $1 - 1 + 3 - 15$ が負なので比べない。
$N = 8$ を選ぶと $x \ge 20$ の差は $9 \times 10^{-15}$ から $7 \times 10^{-14}$ に下がり、$\ln Q$ の丸め（$x = 38$ で $\mathrm{ulp}(726.6) = 1.1 \times 10^{-13}$）の程度で止まる。
$N = 1$ では主項 $1/x$ だけになり、差は $x = 40$ でも $6.2 \times 10^{-4} \approx 1/x^2$ 残る。

## Owen の T 関数

Owen の $T$ 関数は次の積分で定義される（Owen 1956）。

$$
T(h, a) = \frac{1}{2\pi}\int_0^a \frac{\exp\!\left(-\tfrac12 h^2(1 + t^2)\right)}{1 + t^2}\,dt.
$$

$T$ は $h$ について偶関数、$a$ について奇関数で、$T(0, a) = \arctan(a)/(2\pi)$、$T(h, 0) = 0$、$T(h, 1) = \tfrac12\Phi(h)(1 - \Phi(h))$、$h \ge 0$ で $T(h, \infty) = \tfrac12 Q(h)$ を満たす。
相関係数 $\rho$ の標準二変量正規分布 $(X, Y)$ の象限確率は、$h, k \ne 0$ について

$$
P(X > h, Y > k) = \tfrac12 Q(h) + \tfrac12 Q(k) - T(h, a_h) - T(k, a_k) - \beta, \qquad
a_h = \frac{k - \rho h}{h\sqrt{1 - \rho^2}}, \quad a_k = \frac{h - \rho k}{k\sqrt{1 - \rho^2}}
$$

で与えられる（Owen 1956）。
$\beta$ は $hk > 0$ なら 0、$hk < 0$ なら $\tfrac12$ である。
角度の扇形上の二変量正規確率も同じ $T$ で書ける。

`owens_t` は Patefield と Tandy（2000）の方法 T5 を使う。
$\lvert a \rvert \le 1$ では、区間 $[0, \min(\lvert a \rvert, 12/\lvert h \rvert)]$ で 32 点 Gauss–Legendre 求積を 1 回行う。
被積分関数の極 $t = \pm i$ は求積の収束域（Bernstein の楕円）の外にあり、$ht > 12$ から先の Gauss の裾は $2 \times 10^{-33}$ より小さいので、打ち切りと求積の誤差は binary64 の丸めより小さい。
$\lvert a \rvert > 1$ では、$h, a \ge 0$ について

$$
T(h, a) + T(ah, 1/a) = \tfrac12\bigl(Q(h) + Q(ah)\bigr) - Q(h)\,Q(ah)
$$

で $1/a \le 1$ の問題へ移す。
$h = 0$ では $\arctan(a)/(2\pi)$ を直接返し、$e^{-h^2/2}$ が 0 になる $h$ では 0 を返す。
32 個の節点は作業量の上限に数えられるが、計算量は引数によらず上限を持つので、スコープ付き API はない。
すべての有限な $h, a$ を受け付けてエラー条件を持たず、binary32 は binary64 で計算して一度だけ丸める。
一様な ULP の目標はなく、オプション付き形式 `owens_t_with_options` は求積と正規分布の裾の誤差を合わせた推定誤差を返す。

象限確率の式は、結果が各項より小さいとき引き算で相対精度を失う。
たとえば $\rho = -0.9$、$h = 3$、$k = -1$ の確率 $1.8 \times 10^{-8}$ は $\tfrac12 Q(k) \approx 0.42$ などの項の差で、絶対誤差は $2 \times 10^{-18}$ でも相対誤差は $10^{-10}$ になる（下のセルの負の相関の場合）。

## 二変量正規分布の象限確率

次のセルは相関 $\rho$ の二変量正規分布で $P(X > h, Y > k)$ を Owen の式で求め、別の式の数値積分と比べる。
検算の式は $P = \int_h^\infty \varphi(x)\,Q\bigl((k - \rho x)/\sqrt{1 - \rho^2}\bigr)\,dx$ で、$[h, \max(h, 0) + 12]$ を 10000 区間の複合 Simpson 則で積分する（$Q$ には `normal_sf` を使うが、$T$ 関数は使わない）。
最後の列は恒等式 $T(h, 1) = \tfrac12\Phi(h)(1 - \Phi(h))$ の残差である。
$h$ は $-2$ から 3 までの 7 点で、$h$ と $k$ の符号が違う行では $\beta = \tfrac12$ が入る。

```rust
//| id: special-owens-t-identity
//| ref: special-owens-t-identity
//| title: 二変量正規分布の象限確率を Owen の T 関数で求める
//| run: reactive
//| crates: [scioxide-special]
//| inputs:
//|   rho: {"type":"range","label":"相関係数 ρ","min":-0.9,"max":0.9,"step":0.1,"value":0.5}
//|   k: {"type":"select","label":"Y のしきい値 k","options":["-1","0.5","1.5"],"value":"1.5"}
//| cases:
//|   - {"id":"negative","label":"ρ = −0.9、k = −1","description":"強い負の相関。h > 0 の行では X が大きいと Y が小さくなり、確率が急に減る。","inputs":{"rho":-0.9,"k":"-1"}}
//|   - {"id":"positive","label":"ρ = 0.9、k = 0.5","description":"強い正の相関。h ≤ −1 では X > h がほぼ確実なので、確率は Q(0.5) = 0.3085 に近づく。","inputs":{"rho":0.9,"k":"0.5"}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"orthant","path":"/rows/4/1","approx":{"value":0.03241757863227539,"rtol":1e-13}}
//|       - {"artifact":"orthant","path":"/rows/0/3","range":{"min":-1e-13,"max":1e-13}}
//|       - {"artifact":"orthant","path":"/rows/3/3","range":{"min":-1e-13,"max":1e-13}}
//|       - {"artifact":"orthant","path":"/rows/6/3","range":{"min":-1e-13,"max":1e-13}}
//|       - {"artifact":"orthant","path":"/rows/5/4","range":{"min":-1e-16,"max":1e-16}}
//|   - case: negative
//|     expect:
//|       - {"artifact":"orthant","path":"/rows/6/1","approx":{"value":1.784813386146e-8,"rtol":1e-9}}
//|       - {"artifact":"orthant","path":"/rows/4/3","range":{"min":-1e-13,"max":1e-13}}
//|   - case: positive
//|     expect:
//|       - {"artifact":"orthant","path":"/rows/0/1","approx":{"value":0.3085375384652758,"rtol":1e-13}}
//|       - {"artifact":"orthant","path":"/rows/3/3","range":{"min":-1e-13,"max":1e-13}}
use scioxide_special::{normal_cdf, normal_sf, owens_t};
use std::f64::consts::PI;

let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let fixed2 = serde_json::json!({ "fractionDigits": 2 });
let k: f64 = k.parse().map_err(|_| "しきい値を読めない")?;
let root = (1.0 - rho * rho).sqrt();
// Owen (1956): P(X > h, Y > k) = ½Q(h) + ½Q(k) − T(h, a_h) − T(k, a_k) − β（h, k ≠ 0）。
let orthant = |h: f64| -> Result<f64, String> {
    let a_h = (k - rho * h) / (h * root);
    let a_k = (h - rho * k) / (k * root);
    let beta = if h * k > 0.0 { 0.0 } else { 0.5 };
    let q =
        normal_sf(h).map_err(|e| e.to_string())? + normal_sf(k).map_err(|e| e.to_string())?;
    let t = owens_t(h, a_h).map_err(|e| e.to_string())?
        + owens_t(k, a_k).map_err(|e| e.to_string())?;
    Ok(0.5 * q - t - beta)
};
// 独立検算: P = ∫_h^∞ φ(x) Q((k − ρx)/√(1 − ρ²)) dx を複合 Simpson 則（10000 区間）で求める。
let quadrature = |h: f64| -> Result<f64, String> {
    let (end, n) = (h.max(0.0) + 12.0, 10000);
    let step = (end - h) / n as f64;
    let mut sum = 0.0;
    for i in 0..=n {
        let x = h + step * i as f64;
        let weight = if i == 0 || i == n {
            1.0
        } else if i % 2 == 1 {
            4.0
        } else {
            2.0
        };
        let density = (-0.5 * x * x).exp() / (2.0 * PI).sqrt();
        sum += weight * density * normal_sf((k - rho * x) / root).map_err(|e| e.to_string())?;
    }
    Ok(sum * step / 3.0)
};
let mut rows = Vec::new();
for h in [-2.0, -1.0, -0.5, 0.5, 1.0, 2.0, 3.0] {
    let owen = orthant(h)?;
    let reference = quadrature(h)?;
    // T(h, 1) = ½ Φ(h)(1 − Φ(h))（Owen 1956）の残差。
    let p = normal_cdf(h).map_err(|e| e.to_string())?;
    let identity = owens_t(h, 1.0).map_err(|e| e.to_string())? - 0.5 * p * (1.0 - p);
    rows.push((h, owen, reference, owen - reference, identity));
}
let columns = serde_json::json!([
    { "key": "0", "label": "h [-]", "type": "number", "format": fixed2 },
    { "key": "1", "label": "P(X > h, Y > k)（Owen の式） [-]", "type": "number", "format": sci3 },
    { "key": "2", "label": "Simpson 則の値 [-]", "type": "number", "format": sci3 },
    { "key": "3", "label": "差 [-]", "type": "number", "format": sci3 },
    { "key": "4", "label": "T(h, 1) − ½Φ(h)(1 − Φ(h)) [-]", "type": "number", "format": sci3 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "orthant" })
);
```

既定の $\rho = 0.5$、$k = 1.5$ では、Owen の式と Simpson 則の差は 7 行すべてで $10^{-15}$ 以下である。
$h < 0$ の行では $\beta = \tfrac12$ が入り、$h$ が小さくなると確率は $Q(1.5) = 0.0668$ に近づく。
恒等式 $T(h, 1) = \tfrac12\Phi(h)(1 - \Phi(h))$ の残差は $1.4 \times 10^{-17}$ 以下である。
$\rho = -0.9$、$k = -1$ を選ぶと差は $1.6 \times 10^{-14}$ まで増えるが、これは被積分関数が急に変わることによる Simpson 則の誤差である。
この場合の $h = 3$ の確率 $1.7848133860 \times 10^{-8}$ は、多倍長の数値積分（40 桁）で求めた $1.7848133861 \times 10^{-8}$ と相対 $9.6 \times 10^{-11}$ の差で、上で述べた引き算による相対精度の低下の大きさに合う。
同じ多倍長の値と比べると、Owen の式の相対誤差は $h = 0.5$ と $h = 1$ でも $5 \times 10^{-16}$ 程度で、表の差の $10^{-14}$ は Simpson 則の側の誤差である。
$\rho = 0.9$、$k = 0.5$ では、$h \le -1$ の行は $Q(0.5) = 0.3085$ に近づく。

## API

この族の関数は次のとおりである。
どれも実数専用（`RealScalar`）である。
オプションはすべて `ProbabilityOptions` で、作業量の上限（`Budget`、既定 65536）だけを持ち、精度の要求は持たない。
オプション付き形式は `SpecialFunctionResult` を返し、推定誤差、終了状態、計算量の計数、アルゴリズムの識別子を持つ。

| 標準形式 | 計算するもの | オプション付き形式 | スコープ付き API |
|---|---|---|---|
| `normal_cdf` | $\Phi(x)$ | `normal_cdf_with_options` | なし |
| `normal_sf` | $Q(x) = 1 - \Phi(x)$ | `normal_sf_with_options` | なし |
| `normal_log_cdf` | $\ln\Phi(x)$ | `normal_log_cdf_with_options` | なし |
| `normal_log_sf` | $\ln Q(x)$ | `normal_log_sf_with_options` | なし |
| `normal_quantile` | $\Phi(x) = p$ の $x$ | `normal_quantile_with_options` | なし |
| `normal_isf` | $Q(x) = p$ の $x$ | `normal_isf_with_options` | なし |
| `normal_inv_log_cdf` | $\ln\Phi(x) = \ln p$ の $x$ | `normal_inv_log_cdf_with_options` | `normal_inv_log_cdf_scoped` |
| `normal_inv_log_sf` | $\ln Q(x) = \ln q$ の $x$ | `normal_inv_log_sf_with_options` | `normal_inv_log_sf_scoped` |
| `owens_t` | $T(h, a)$ | `owens_t_with_options` | なし |

精度の目標は次のようにまとめられる。
ULP の値は独立に生成した参照値で確かめた範囲のもので、推定誤差はオプション付き形式が返す見積もりであり、どちらも包含が保証された区間ではない。

| 関数 | binary64 | binary32 | オプション付き形式の推定誤差 |
|---|---|---|---|
| `normal_cdf`、`normal_sf`、`normal_log_cdf`、`normal_log_sf` | $-38 \le x \le 38$ で 8 ULP | 1 ULP | 64 単位 |
| `normal_quantile`、`normal_isf` | 4 ULP（非正規化数の $p$ を含む） | 1 ULP | 64 単位 |
| `normal_inv_log_cdf`、`normal_inv_log_sf` | 目標なし | 目標なし | 64 単位 |
| `owens_t` | 目標なし | 目標なし | 求積と裾の誤差から導いた値 |

上限に達した反復は標準形式では `ConvergenceFailure`（`IterationLimit`）、オプション付き形式とスコープ付き API では推定値が残れば終了状態 `IterationLimit` の結果になる。

## まとめ

正規分布の裾は `normal_sf` と `normal_log_sf` で直接求め、$1 - \Phi(x)$ の引き算は $x > 8.29$ で 0 になるので使わない。
$x > 37.52$ で $Q(x)$ が非正規化数になる範囲や尤度の計算では対数形を使い、そこから戻した確率の相対精度は $\varepsilon\lvert\ln Q\rvert$ の程度だと考える。
分位点は `normal_quantile` と `normal_isf` が反復なしで 4 ULP の目標に収め、型の範囲より小さい確率には対数確率の逆関数を使う。
二変量正規分布の象限確率は Owen の $T$ 関数で求まるが、結果が各項より小さいときは引き算で相対精度が下がる。
