調和振動子のポテンシャルに一様な場を加えた問題や、放物線形の障壁を通る波の問題を放物柱座標で変数分離すると、Weber 方程式が現れる。
その解が放物柱関数で、量子調和振動子の固有関数（Hermite 関数）は非負の整数の次数の特別な場合にあたる。

このページは放物柱関数 $D_\nu$、$V_\nu$、$W(a, x)$ と、複素数の引数の $D_n$ を扱う。
定義と性質のあとに、`scioxide-special` が次数と引数の領域ごとに使う評価法とその理由、精度の扱い、API を説明し、最後のセルで Wronskian（二つの解 $f$、$g$ に対する $fg' - f'g$）と Hermite 多項式で値を検算する。
同じ「非斉次の項や二次のポテンシャルを持つ Bessel 型の方程式」の仲間である Struve 関数は [Struve 関数と Bessel・Struve 関数の積分](../struve-parabolic-and-bessel-integrals/) にある。

## Weber の方程式と放物柱関数

Weber の方程式（DLMF 12.2.2）

$$
w'' - \left(\frac{x^2}{4} + a\right)w = 0
$$

の解のうち、$x \to +\infty$ で減衰する解を $U(a, x)$、増大する解を $V(a, x)$ と書く（DLMF §12.2）。
`scioxide-special` は Whittaker の記法 $D_\nu(x) = U(-\nu - 1/2, x)$ を使い、`parabolic_d(order, x)` の `order` は $\nu$ である。
$D_\nu$ は $y'' + (\nu + 1/2 - x^2/4)\,y = 0$ を満たし、$x \to +\infty$ で $D_\nu(x) \sim x^\nu e^{-x^2/4}$ になる（DLMF 12.9.1）。
$\nu$ と $x$ について整関数なので、有限な値ならどれでも受け付ける。
非負の整数 $n$ では Hermite 多項式 $\mathrm{He}_n$ で $D_n(x) = e^{-x^2/4}\mathrm{He}_n(x)$ と書け（DLMF 12.7.2）、これは量子調和振動子の固有関数である。

`parabolic_v(order, x)` は同じ記法の $V_\nu(x) = V(-\nu - 1/2, x)$ を返す。
$V_\nu(x) \sim \sqrt{2/\pi}\,x^{-\nu-1}e^{x^2/4}$ と増大し、原点の値は次のとおりである。

$$
D_\nu(0) = \frac{2^{\nu/2}\sqrt{\pi}}{\Gamma((1 - \nu)/2)}, \qquad
V_\nu(0) = -\frac{2^{-\nu/2}\sin(\pi\nu/2)}{\Gamma(1 + \nu/2)}, \qquad
V_\nu'(0) = \frac{2^{(1-\nu)/2}\cos(\pi\nu/2)}{\Gamma((\nu + 1)/2)}.
$$

ここで $1/\Gamma$ は $\Gamma$ の極で 0 とみなす。
二つの解の Wronskian は定数である（DLMF 12.2.11、12.2.20）。

$$
\mathscr{W}\{D_\nu(x), D_\nu(-x)\} = \frac{\sqrt{2\pi}}{\Gamma(-\nu)}, \qquad
\mathscr{W}\{D_\nu(x), V_\nu(x)\} = \sqrt{2/\pi}.
$$

$\nu$ が非負の整数のとき $1/\Gamma(-\nu) = 0$ で、$D_n(x)$ と $D_n(-x)$ は一次従属になる（$D_n(-x) = (-1)^n D_n(x)$）。
そのため、負の $x$ の値はどの $\nu$ でも一次独立な $D_\nu$ と $V_\nu$ の組から接続公式（DLMF 12.2.15 と §12.2 の $V$ の公式を $\nu$ の記法に書き直したもの）で作る。

$$
D_\nu(-x) = \cos(\pi\nu)\,D_\nu(x) + \frac{\pi}{\Gamma(-\nu)}V_\nu(x), \qquad
V_\nu(-x) = -\cos(\pi\nu)\,V_\nu(x) - \frac{\sin(\pi\nu)}{\Gamma(\nu + 1)}D_\nu(x).
$$

`parabolic_w(order, x)` は、もう一つの方程式 $w'' + (x^2/4 - a)\,w = 0$ の実数解 $W(a, x)$（DLMF §12.14）を返す。
この関数の `order` は $\nu$ ではなく係数 $a$ である。
$W(a, x)$ は放物線形の障壁 $-x^2/4$ を通る波を表し、原点での規格化は次のとおりである。

$$
W(a, 0) = 2^{-3/4}\left\lvert\frac{\Gamma(1/4 + ia/2)}{\Gamma(3/4 + ia/2)}\right\rvert^{1/2}, \qquad
W'(a, 0) = -\frac{1}{2W(a, 0)}.
$$

`parabolic_d_complex(n, z)` は、非負の整数の次数 $n$（`u32`）と複素数の $z$ に対する $D_n(z) = e^{-z^2/4}\mathrm{He}_n(z)$ を返す。
実数の非整数の次数は `parabolic_d` を使い、複素数の $z$ と非整数の次数の組は提供しない。

## 放物柱関数の評価法

$D_\nu$ は $\nu$ と $x$ の領域で方法を切り替える。
どの方法が使われたかは、オプション付き形式のアルゴリズムの識別子（原点の級数、大きな引数の漸近展開、漸化式と積分表示の三つ）で分かる。

- $x = 0$ では、上の原点の値 $D_\nu(0)$ と傾き $D_\nu'(0)$ を Gamma 関数から直接計算する。
- $\lvert\nu\rvert \le 2$、$0 < \lvert x\rvert \le 3$ では、非負の整数の $\nu$ を除き、原点まわりの偶・奇の冪級数（DLMF 12.4）を補償和（丸めの誤差を別に足し込む和）で足す。
  この矩形では偶・奇の二つの級数の打ち消しが小さく、外では打ち消しが大きくなる。
- $\lvert x\rvert \ge \max(32, 2(\lvert\nu\rvert + 1))$ では、漸近展開（DLMF 12.9.1）を足す。
  この境界では項が `f64` の丸めの水準まで十分に減るので、打ち切りの誤差は問題にならない。
  項が途中で減らなくなったときはエラーを返す。

その間の領域で、$\nu < 0$ のときは積分表示（DLMF 12.5.1）

$$
D_{-\alpha}(x) = \frac{e^{-x^2/4}}{\Gamma(\alpha)}\int_0^\infty t^{\alpha - 1}e^{-t^2/2 - xt}\,dt, \qquad \alpha = -\nu > 0
$$

を求積する。
$0 < \alpha < 1$ では $t = u^4$ と置き換えて原点の特異性をならし、積分が $\Gamma(\alpha)$ になる密度 $t^{\alpha-1}e^{-t}$ を引いてから、刻みを半分にしながら複合 Simpson 則を適用する。
$\alpha \ge 1$ では被積分関数の峰（鞍点）を中心に対数の変数を取り直してから同じ求積を行い、捨てた裾は被積分関数の対数が凹であることから抑える。
どちらも、刻みを半分にした二つの値の差が丸めの水準に下がったところで止める。

$\nu > 0$ では、$\nu$ より 1 以上小さい負の次数（整数の $\nu$ では $D_0 = e^{-x^2/4}$、$D_1 = xe^{-x^2/4}$）から次数の漸化式（DLMF 12.8.1 の $\nu$ の記法）

$$
D_{\nu+1}(x) = x\,D_\nu(x) - \nu\,D_{\nu-1}(x)
$$

を上向きに回す。
$x$ が転回点 $2\sqrt{\nu + 1/2}$ より十分外では $D_\nu(x)$ が漸化式の優勢な解（1 段ごとにおよそ $x$ 倍になり、もう一つの解は $\nu/x$ 倍）で、転回点の内側では二つの解が同程度の大きさで振動するので、上向きに回しても誤差が指数的に増えることはない。
計算量は約 $\nu$ 段で、既定の作業量の上限（262144 単位）では、非常に大きな正の次数は漸近展開の領域 $\lvert x\rvert \ge 2(\nu + 1)$ でしか評価できない。
負の $x$ には上の接続公式を使い、$V_\nu(\lvert x\rvert)$ も計算する。

$V_\nu$ は $\lvert x\rvert \ge \max(32, 2(\lvert\nu\rvert + 1))$ では漸近展開を足し、それより小さい $x$ では原点の値から微分方程式の Taylor 級数の刻みで $x$ まで解を延長する。
延長するのは増大因子を除いた $e^{-x^2/4}V_\nu$ で、因子 $e^{x^2/4}$ は対数の尺度に分けて持つ。
位置 $x_0$ からの刻みの幅は $0.5/(1 + x_0 + \sqrt{\lvert\nu\rvert})$ 以下で、1 刻みで $h^{25}$ の項までを足す。
負の $x$ には $D_\nu$ との接続公式を使う。

$W(a, x)$ は $W(a, 0)$ を $\lvert a\rvert$ の 5 区間（区切りは 0、0.5、1、2、3.5、5）ごとの 64 項の Chebyshev 展開で求め、同じ形の Taylor 級数の刻みで $x$ まで延長する。
各刻みでは二つの単位の解を進めて遷移行列を作り、それまでの誤差もこの行列で運ぶ。
Chebyshev 展開を作った範囲に合わせて、$\lvert a\rvert \le 5$、$\lvert x\rvert \le 5$ だけを受け付ける。

`parabolic_d_complex` は三項漸化式 $\mathrm{He}_{k+1}(z) = z\,\mathrm{He}_k(z) - k\,\mathrm{He}_{k-1}(z)$ を途中で尺度を付け直しながら回し、$e^{-z^2/4}$ の位相 $-\operatorname{Im}(z^2)/4$ を上位と下位の二つに分けて掛ける。
計算量は $n + 1$ 段である。

$D_\nu$ と $V_\nu$ はどの方法でも値を「仮数 × $e^{\text{尺度}}$」の形で持つ。
$\lvert x\rvert$ が大きく値が型の範囲を超えるときも、オプション付き形式は尺度化形と対数形を返し、通常値への射影の状態を `Overflow` にする（標準形式はエラーを返す）。
`parabolic_d_complex` のオプション付き形式も、値があふれるときは尺度化形を返す。
通常値は $e^{\ln\lvert\text{仮数}\rvert + \text{尺度}}$ として作るので、指数の大きさが $L$ のとき、指数の丸めが相対誤差 $L\varepsilon$ 程度（$\varepsilon$ は機械イプシロン）として値に移る。
推定誤差はどの関数でも発見的（heuristic）で、包含区間ではない。

## 放物柱関数の精度

放物柱関数には一様な ULP（厳密な結果の位置での浮動小数点数の間隔）の仕様がない。
$D_\nu$ と $V_\nu$ の照合試験は、独立に生成した参照値と `f32`・`f64` の値・導関数・推定誤差を比べ、$\lvert\nu\rvert \le 20$、$\lvert x\rvert \le 10^4$ の範囲で、値があふれて尺度化形と対数形だけが残る場合も含む。
零点の近くでは絶対誤差で判定する。
$W(a, x)$ の参照値は $a$ と $x$ を受け付ける矩形全体（$a = -5, \ldots, 5$、$x = -5, \ldots, 5$ の格子）にある。
`parabolic_d_complex` の試験は小さい次数での閉形式 $e^{-z^2/4}\mathrm{He}_n(z)$ との比較と、複素平面の標本で結果が有限であることの確認に限られる。
個々の値の精度はオプション付き形式の推定誤差（`ValueWithError` の誤差）と、下のセルのような恒等式で確かめる。

## API

どの関数にも、値だけを返す標準形式 `f(..)`、`SpecialFunctionResult` を返すオプション付き形式 `f_with_options(.., options)`、求解スコープを受け取るスコープ付き API `f_scoped(.., options, scope)` がある。
オプション `ParabolicCylinderOptions` は作業量の上限（`Budget`。
精度の要求ではない）だけを持ち、既定は 262144 単位である。
引数は実数（`f32`、`f64`）で、`parabolic_d_complex` だけが `Complex<S>` を受け取る。
実数の三つの関数のオプション付き形式は、値に加えて導関数、尺度化形、対数形を返す。

| 標準形式 | オプション付き形式 | スコープ付き API | 値 |
|---|---|---|---|
| `parabolic_d` | `parabolic_d_with_options` | `parabolic_d_scoped` | $D_\nu(x)$ |
| `parabolic_v` | `parabolic_v_with_options` | `parabolic_v_scoped` | $V_\nu(x)$ |
| `parabolic_w` | `parabolic_w_with_options` | `parabolic_w_scoped` | $W(a, x)$（$\lvert a\rvert, \lvert x\rvert \le 5$） |
| `parabolic_d_complex` | `parabolic_d_complex_with_options` | `parabolic_d_complex_scoped` | $D_n(z)$（$n$ は `u32`、$z$ は複素数） |

エラーは `SciOxideError` の `kind()` で分類する。
非有限な入力は `NonFinite` である。
`parabolic_w` は $\lvert a\rvert > 5$ で引数 `order` を、$\lvert x\rvert > 5$ で引数 `x` を指す `DomainError`（`OutsideDomain`）を返す。
値が型の範囲を超えると標準形式は `NumericalInstability`（`Overflow`）を返し、作業量の上限で止まると `ConvergenceFailure`（`IterationLimit`）を返す。
漸近展開の項が減らなくなったときや原点の級数が収束しないときは `NumericalInstability`（`LossOfSignificance`）を返す。
`parabolic_d_complex` は、$z^2/4$ が `f64` で表せず（$\lvert z\rvert > 10^{154}$ 程度）、結果が 0 へのアンダーフローでもないとき、`NumericalInstability`（`LossOfSignificance`）を返す。
オプション付き形式が成功したときの終了状態（`SpecialFunctionTermination`）は `Converged` である。

## 放物柱関数の Wronskian と Hermite 多項式

次のセルは次数 $\nu$ を選び、$D_\nu(\pm x)$ と $V_\nu(x)$ のオプション付き形式が返す値と導関数から二つの Wronskian を作って、定数 $\sqrt{2\pi}/\Gamma(-\nu)$ と $\sqrt{2/\pi}$ と比べる。
評価点 $x = 0.5, 2$ は原点の級数（$\lvert\nu\rvert \le 2$ で非負の整数でないとき）、$x = 3.5, 5, 10, 20$ は積分表示の求積か漸化式、$x = 40$ は漸近展開の区間に入る。
$D_\nu(-x)$ は接続公式で $D_\nu(x)$ と $V_\nu(x)$ から作るので、一つ目の Wronskian は接続公式の検算にもなる。
Wronskian は値と導関数の積の差なので、誤差は積の大きさ $\lvert D_\nu(x)D_\nu'(-x)\rvert + \lvert D_\nu'(x)D_\nu(-x)\rvert$ に対する比（$\varepsilon$ 単位）で測る。
$\nu$ が非負の整数のときは、Hermite 多項式の三項漸化式で手計算した $e^{-x^2/4}\mathrm{He}_n(x)$ との相対誤差も示す（他の $\nu$ では空欄）。

```rust
//| id: special-parabolic-d-hermite-check
//| ref: special-parabolic-d-hermite-check
//| title: 放物柱関数の Wronskian と Hermite 多項式による検算
//| run: reactive
//| crates: [scioxide-special]
//| inputs:
//|   order: {"type":"range","label":"次数 ν [-]","description":"非負の整数では Hermite 多項式との比較も行う。","min":-4,"max":8,"step":0.1,"value":0.3}
//| cases:
//|   - {"id":"negative","label":"ν = −2.5","description":"原点の級数の外では積分表示の求積を使う負の次数。","inputs":{"order":-2.5}}
//|   - {"id":"integer","label":"ν = 3","description":"1/Γ(−ν) = 0 で D_ν(x) と D_ν(−x) が一次従属になる。Hermite 多項式と比べる。","inputs":{"order":3}}
//|   - {"id":"recurrence","label":"ν = 6.7","description":"負の次数から 7 段の上向き漸化式で作る。","inputs":{"order":6.7}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"wronskians","path":"/rows/0/1","approx":{"value":0.8788645270258308,"rtol":1e-13}}
//|       - {"artifact":"wronskians","path":"/rows/3/2","range":{"max":64}}
//|       - {"artifact":"wronskians","path":"/rows/3/3","range":{"max":64}}
//|       - {"artifact":"wronskians","path":"/rows/6/2","range":{"max":512}}
//|   - case: negative
//|     expect:
//|       - {"artifact":"wronskians","path":"/rows/4/2","range":{"max":64}}
//|       - {"artifact":"wronskians","path":"/rows/6/3","range":{"max":512}}
//|   - case: integer
//|     expect:
//|       - {"artifact":"wronskians","path":"/rows/2/2","equals":null}
//|       - {"artifact":"wronskians","path":"/rows/3/4","range":{"max":16}}
//|       - {"artifact":"wronskians","path":"/rows/3/3","range":{"max":64}}
//|   - case: recurrence
//|     expect:
//|       - {"artifact":"wronskians","path":"/rows/4/2","range":{"max":64}}
//|       - {"artifact":"wronskians","path":"/rows/4/3","range":{"max":64}}
use scioxide_special::{
    ParabolicCylinderOptions, SpecialFunctionResult, gamma, parabolic_d_with_options,
    parabolic_v_with_options,
};

let options = ParabolicCylinderOptions::default();
let pi = std::f64::consts::PI;
let eps = f64::EPSILON;
let nu = (order * 10.0).round() / 10.0;
let integer = nu >= 0.0 && nu == nu.round();
// √(2π)/Γ(−ν)。非負の整数では 1/Γ(−ν) = 0。
let w_dd = if integer {
    0.0
} else {
    (2.0 * pi).sqrt() / gamma(-nu).map_err(|e| e.to_string())?
};
let w_dv = (2.0 / pi).sqrt();
let pair = |r: &SpecialFunctionResult<f64>| -> Result<(f64, f64), String> {
    let v = r.try_value().map_err(|e| e.to_string())?;
    let d = r.try_derivative().map_err(|e| e.to_string())?;
    Ok((v, d))
};
let mut rows = Vec::new();
for &x in &[0.5_f64, 2.0, 3.5, 5.0, 10.0, 20.0, 40.0] {
    let plus = parabolic_d_with_options(nu, x, options).map_err(|e| e.to_string())?;
    let minus = parabolic_d_with_options(nu, -x, options).map_err(|e| e.to_string())?;
    let v = parabolic_v_with_options(nu, x, options).map_err(|e| e.to_string())?;
    let ((d, dp), (m, mp), (vv, vp)) = (pair(&plus)?, pair(&minus)?, pair(&v)?);
    // d/dx D_ν(−x) = −D_ν′(−x)。
    let first = d * (-mp) - dp * m;
    let first_scale = (d * mp).abs() + (dp * m).abs();
    let second = d * vp - dp * vv;
    let second_scale = (d * vp).abs() + (dp * vv).abs();
    // 非負の整数 n では e^{−x²/4} He_n(x) を三項漸化式で手計算する（独立検算）。
    let hermite = integer.then(|| {
        let (mut previous, mut current) = (0.0_f64, 1.0_f64);
        for k in 0..(nu as u32) {
            let next = x * current - f64::from(k) * previous;
            previous = current;
            current = next;
        }
        let exact = (-0.25 * x * x).exp() * current;
        (d - exact).abs() / (eps * exact.abs())
    });
    rows.push((
        x,
        d,
        (!integer).then(|| (first - w_dd).abs() / (eps * first_scale)),
        (second - w_dv).abs() / (eps * second_scale),
        hermite,
        plus.counts().iterations(),
    ));
}
let sci6 = serde_json::json!({ "notation": "scientific", "significantDigits": 6 });
let fixed1 = serde_json::json!({ "fractionDigits": 1 });
let columns = serde_json::json!([
    { "key": "0", "label": "x [-]", "type": "number" },
    { "key": "1", "label": "D_ν(x) [-]", "type": "number", "format": sci6 },
    { "key": "2", "label": "W{D_ν(x), D_ν(−x)} の誤差 [ε 単位]", "type": "number", "format": fixed1, "nullText": "—" },
    { "key": "3", "label": "W{D_ν, V_ν} の誤差 [ε 単位]", "type": "number", "format": fixed1 },
    { "key": "4", "label": "Hermite との相対誤差 [ε 単位]", "type": "number", "format": fixed1, "nullText": "—" },
    { "key": "5", "label": "D_ν(x) の計算量 [単位]", "type": "integer" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "wronskians" })
);
```

既定の $\nu = 0.3$ では、二つの Wronskian の誤差は $x \le 10$ で 15 $\varepsilon$ 単位以下、$x = 20$ で 73〜75、漸近展開の $x = 40$ で 97〜98 $\varepsilon$ 単位である。
$\nu = -2.5$ では $x \le 20$ で 17 $\varepsilon$ 単位以下だが、$x = 40$ では 199〜260 $\varepsilon$ 単位になる。
$x = 40$ では $D_\nu(40) \approx 6 \times 10^{-174}$ と、$10^{171}$ 程度の $D_\nu(-40)$ の積を作るが、値を「仮数 × $e^{\text{尺度}}$」で持つので積は正しく 1 程度になる。
このとき尺度は約 $\pm 400$ で、通常値に戻すときの指数の丸めが相対誤差 $400\varepsilon$ 程度まで値に移りうる。
大きな $x$ で誤差が数百 $\varepsilon$ 単位に増えるのは、この丸めの範囲に収まっている。

計算量の列は方法の違いを示す。
原点の級数（$\nu = 0.3$ の $x \le 2$）は 11〜24 単位、漸近展開は 5〜8 単位、$\nu = -2.5$ の鞍点まわりの求積は 1990 単位、$\nu = 0.3$ と $6.7$ の負の次数の求積と漸化式は 961〜4039 単位を使う。
$\nu$ を非負の整数にすると Wronskian の定数は 0 になるので、その列は空欄にし、Hermite 多項式との相対誤差で比べる。
$\nu = 3$ では $D_0$、$D_1$ から 2 段の漸化式で作るので計算量は 2 単位で、Hermite との相対誤差は $x \le 10$ で 5 $\varepsilon$ 単位以下、$x = 40$ で 90 $\varepsilon$ 単位である。
$x = 40$ の誤差は漸化式ではなく、$e^{-400}$ の尺度を通常値に戻すときの指数の丸めから来る。
誤差がこの水準を大きく超えたら、引数が照合試験の範囲（$\lvert\nu\rvert \le 20$、$\lvert x\rvert \le 10^4$）の内側にあるかと、オプション付き形式の推定誤差を確かめる。

## まとめ

放物柱関数 $D_\nu$ は原点の矩形 $\lvert\nu\rvert \le 2$、$\lvert x\rvert \le 3$ で冪級数、$\lvert x\rvert \ge \max(32, 2(\lvert\nu\rvert + 1))$ で漸近展開、その間では負の次数の積分表示の求積と正の次数の上向きの漸化式を使い、負の $x$ は $V_\nu$ との接続公式で作る。
$V_\nu$ と $W(a, x)$ は原点の値から Taylor 級数で延長し、$W$ は $\lvert a\rvert, \lvert x\rvert \le 5$ だけを受け付ける。
値は「仮数 × $e^{\text{尺度}}$」で持つので、`f64` の範囲を超える値もオプション付き形式の尺度化形と対数形で使える。
一様な ULP の仕様はなく、推定誤差は発見的なので、大切な値は Wronskian や Hermite 多項式のような恒等式で確かめる。
次数の規約と各項目の仕様は [Kelvin・Struve・放物柱関数](../../api/kelvin-struve-parabolic/) で、非斉次の Bessel 方程式の解は [Struve 関数と Bessel・Struve 関数の積分](../struve-parabolic-and-bessel-integrals/) で確かめる。
