多重対数 $\operatorname{Li}_s(z)$ は、Bose–Einstein 分布と Fermi–Dirac 分布の積分に現れる。
理想 Bose 気体の粒子数密度はフガシティ $z$ の関数として $\operatorname{Li}_{3/2}(z)$ に比例し、完全 Fermi–Dirac 積分は $F_j(\eta) = -\operatorname{Li}_{j+1}(-e^{\eta})$ と書ける。
Lerch の超越関数 $\Phi(z, s, a)$ は、多重対数と Hurwitz ゼータ関数を一つの級数にまとめた関数である。

このページは、位数 $s$ が一般の値のときの多重対数と Lerch の超越関数の定義と切断、scioxide-special が位数と引数の位置で選ぶ評価法、作業量とスコープ付き API、精度の保証、API の使い分けを説明する。
位数 2 の二重対数は決まった項数の別の核で評価するので、[二重対数・Spence 関数・Clausen 関数](../polylog-lerch-and-clausen/) で扱う。
Riemann と Hurwitz のゼータ関数の評価は [Riemann・Hurwitz ゼータ関数と Dirichlet eta 関数](../zeta-functions/) で扱い、$z = 1$ の値はその核で求める。
最後のセルで、多重対数の乗法公式、Lerch の超越関数の $a$ のずらし、$\operatorname{Li}_s(1) = \zeta(s)$ を数値で確かめ、引数ごとに選ばれた評価法を表示する。

## 定義と切断

### 多重対数

位数 $s$ と $|z| < 1$ の $z$ に対して、多重対数は次の冪級数で定義される（DLMF 25.12.10）。

$$
\operatorname{Li}_s(z) = \sum_{k=1}^{\infty} \frac{z^k}{k^s}
$$

$z$ について解析接続すると、$\operatorname{Li}_s$ は $[1, \infty)$ を切断とする平面で一価の関数になる。
冪は主値 $k^{-s} = e^{-s \ln k}$ で取り、切断の上では虚部の符号付きゼロ（$+0$ か $-0$）で上下どちらの岸の値かを選ぶ。

微分は $z \, \frac{d}{dz}\operatorname{Li}_s(z) = \operatorname{Li}_{s-1}(z)$ で位数を一つ下げる。
整数の位数では初等関数になり、$\operatorname{Li}_1(z) = -\ln(1 - z)$、$\operatorname{Li}_0(z) = z/(1 - z)$ である。
$s = -n$（$n = 1, 2, \dots$）では $z \, d/dz$ を繰り返して、次の有理関数になる。

$$
\operatorname{Li}_{-n}(z) = \frac{z\,A_n(z)}{(1 - z)^{n+1}}, \qquad A_n(z) = \sum_{k=0}^{n-1} A(n, k)\, z^k
$$

$A(n, k)$ は Eulerian 数で、$A(n, k) = (k + 1)A(n - 1, k) + (n - k)A(n - 1, k - 1)$ の漸化式で求まる。
$z = 1$ では $s \ne 1$ のとき $\operatorname{Li}_s(1) = \zeta(s)$ で、$\operatorname{Re} s \le 1$ では発散級数の極限ではなく、$\zeta$ の解析接続の値を取る。
$s = 1$、$z = 1$ は極である。

$m$ 個の $m$ 乗根で $z$ を回して足すと、乗法公式 $\sum_{j=0}^{m-1} \operatorname{Li}_s(z\,e^{2\pi i j/m}) = m^{1-s}\operatorname{Li}_s(z^m)$ が成り立つ。
$m = 2$ の場合は次の式で、定義の級数の偶数番目の項を取り出すと得られる。

$$
\operatorname{Li}_s(z) + \operatorname{Li}_s(-z) = 2^{1-s} \operatorname{Li}_s(z^2)
$$

### Lerch の超越関数

Lerch の超越関数は次の級数で定義される（DLMF 25.14.1）。

$$
\Phi(z, s, a) = \sum_{n=0}^{\infty} \frac{z^n}{(a + n)^s}, \qquad |z| < 1
$$

$z$ について $[1, \infty)$ を切断とする平面へ接続し、冪は主値 $(a + n)^{-s} = e^{-s \ln(a + n)}$ で取る。
特別な場合として、$\Phi(1, s, a) = \zeta(s, a)$（Hurwitz ゼータ関数）、$z\,\Phi(z, s, 1) = \operatorname{Li}_s(z)$、$\Phi(z, 0, a) = 1/(1 - z)$ がある。
$a$ をずらす次の関係は、定義の級数から最初の項を取り出すだけで得られる。

$$
\Phi(z, s, a) = z\,\Phi(z, s, a + 1) + a^{-s}
$$

$a = 0, -1, -2, \dots$ は極である。
ただし $s$ が 0 以下の整数なら、その項は $a + n$ の多項式になって極は生じない。
$a = 1/2$、$z = -1$ では Dirichlet のベータ関数 $\beta(s) = 2^{-s}\Phi(-1, s, 1/2)$ になり、$\beta(2)$ は Catalan の定数 $G = 0.9159655941\ldots$ である。

## 評価法

### 位数と引数による振り分け

`polylog(s, z)` は、位数と引数で次の核に振り分ける。

1. $s = 2$ は二重対数の核を使う。
2. $z = 0$ は 0、$z = 1$ は Riemann ゼータ関数の核で $\zeta(s)$ を返す。
3. $s = 1$ は $-\ln(1 - z)$ を、$z$ が小さいときは $\ln(1 + \cdot)$ の形で桁落ちを避けて求める。
4. $s = 0$ は $z/(1 - z)$ で、$|z| > 2$ では $1/z$ で書き直す。
5. $s = -n$（$n \ge 1$）は、$|z| > 2$ なら $\operatorname{Li}_{-n}(1/z) = (-1)^{n+1}\operatorname{Li}_{-n}(z)$ で単位円の側へ移してから、Eulerian 数の有理関数で求める。
   $n \ge 10$ で $|\ln z| \le n$ のときは、高次の多項式の打ち消しを避けるため、$\operatorname{Li}_0$ を $\mu = \ln z$ の関数として部分分数に展開して $n$ 回微分した極の和 $\operatorname{Li}_{-n}(z) = n!\sum_{k \in \mathbb{Z}} (2\pi i k - \ln z)^{-n-1}$ を使う。
   $n > 100$ でこの条件を満たさないときは、定義の級数を使う。
6. $s$ が負の非整数で $|z| \ge 0.95$ のときは、$|\ln z| \le 3.5$ なら下の $\ln z$ の級数、それより外は Jonquière の反転公式（DLMF 25.12.12–25.12.13）で $\operatorname{Li}_s(1/z)$ と Hurwitz ゼータ関数に移す。
7. それ以外は $\operatorname{Li}_s(z) = z\,\Phi(z, s, 1)$ として Lerch の超越関数の核で求める。

### Lerch の超越関数の核

`lerch_phi(z, s, a)` の核は、まず $a$ が 0 以下の整数で $s$ が 0 以下の整数でないときを極として拒む。
$z = 0$ は $a^{-s}$、$z = 1$ は Hurwitz ゼータ関数（$a = 1$ なら Riemann ゼータ関数）、$s = 0$ は $1/(1 - z)$ を返す。
$a = 1$ で上の 5 か 6 に当たる位数は、多重対数の同じ経路を使う。

残りは $\operatorname{Re}(a + n) < 1$ の項を直接足し、ずらした $a' = a + n$（$\operatorname{Re} a' \ge 1$）で上のずらしの関係を使って $\Phi(z, s, a')$ に移す。
$\Phi(z, s, a')$ の評価は $z$ の位置で三つに分かれる。

1. $|z| < 0.95$ では定義の級数を補償和（丸めの誤差を別の変数に蓄えて次の項に戻す Kahan の和）で足す。
   各項は $\exp(-s\ln(a' + n) + n\ln z)$ の形で作り、指数が倍精度の範囲を超えそうなときは共通の尺度を外して和を取る。
   打ち切りでは、それ以降のすべての項の比の上界から裾を等比級数で見積もり、裾が和の $2 \times 10^{-15}$ 倍より小さくなったところで行う。
2. $|\ln z| < 1$ で、$\operatorname{Re} s < 1/2$、$s$ が整数でなく、$\lvert a' - 1\rvert < 0.75$ のときは、$\ln z$ の冪級数を使う（Erdélyi ほか 1953、§1.11）。

   $$
   \Phi(z, s, a) = z^{-a}\left[\Gamma(1 - s)\,(-\ln z)^{s-1} + \sum_{n=0}^{\infty} \zeta(s - n, a)\,\frac{(\ln z)^n}{n!}\right], \qquad \lvert\ln z\rvert < 2\pi
   $$

   $z \to 1$ では定義の級数の項の減り方が遅くなるが、この級数の項はおよそ $(\lvert\ln z\rvert/2\pi)^n$ で減る。
   各項で Hurwitz ゼータ関数 $\zeta(s - n, a)$ を評価するので、その作業も単位数に入る。
   $\lvert a' - 1\rvert < 0.75$ の条件は、位数 $s - n$ が負に大きくなるとき Hurwitz ゼータ関数が桁を失わない範囲に限るためである。
3. それ以外（1 から離れた $|z| \ge 0.95$ の点、$\operatorname{Re} s \ge 1/2$ の位数、$a'$ が 1 から離れた場合）は、積分表示を使う（DLMF 25.14.5）。

   $$
   \Phi(z, s, a) = \frac{1}{\Gamma(s)} \int_0^{\infty} \frac{t^{s-1} e^{-at}}{1 - z e^{-t}}\, dt, \qquad \operatorname{Re} s > 0,\ \operatorname{Re} a > 0
   $$

   被積分関数の極 $t = \ln z + 2\pi i k$ を避けるように積分路を最大 0.35 ラジアン回転し、32 点の Gauss–Legendre 則を区間の二分で適応的に使い、区間の長さを倍々に伸ばしながら足す。
   原点の近くは Taylor 展開で積分し、$1/\Gamma(s)$ を別に掛けることで $\operatorname{Re} s \le 0$ の位数へ解析接続し、$s = 0, -1, -2, \dots$ での見かけの極を除く。
   推定誤差は各区間の粗い則と細かい則の差と、和の丸めの見積もりの和である。

### 作業量とスコープ付き API

どの経路でも、級数の 1 項、求積の 1 節点、漸化の 1 回ごとに作業量の上限を 1 単位使い、入れ子で呼ぶゼータ関数とガンマ関数の作業も同じ上限から引く。
作業量は経路によって 0 単位（$s = 1$ の対数）から数千単位（積分表示）まで変わるので、`polylog` と `lerch_phi` にはスコープ付き API `polylog_scoped` と `lerch_phi_scoped` がある。
スコープ付き API は親の求解の作業量と取り消しをこの評価にも適用する。
上限に達すると、標準形式もオプション付き形式も途中の値を返さずに `ConvergenceFailure` になる。

## 誤差と精度の保証

| 関数 | 実数の引数 | 複素数の引数 |
|---|---|---|
| `polylog` | $s = 2$ は `dilog` と同じで、`f32`、`f64` とも 64 ULP を目標とする。他の位数は一様な ULP の上限がない | 一様な上限はない |
| `lerch_phi` | 一様な上限はない | 一様な上限はない |

一様な上限がない範囲では、オプション付き形式の推定誤差を見て使う。
推定誤差は打ち切りと丸めから導いた値で、包含区間（真の値を必ず含む区間）ではない。
照合試験では値と導関数を独立な参照値と比べ、複素数の引数では相対 $5 \times 10^{-9}$ か絶対 $5 \times 10^{-12}$ の大きい方以内（`f64`）であることを確かめている。

下のセルでは、積分表示の経路の推定誤差は値のおよそ $5 \times 10^{-15}$ 倍である。
$\ln z$ の級数の経路では Hurwitz ゼータ関数の誤差が累積し、下のセルの $s = 0.3$、$z = 0.98$ では推定誤差が値の $1.7 \times 10^{-14}$ 倍になる。

## API

| 関数 | スカラー | オプション付き形式 | スコープ付き API | オプション |
|---|---|---|---|---|
| `polylog(s, z)` | `NumericScalar`。`s` は実数のまま `z` を複素数にでき、`s` も複素数にできる | `polylog_with_options` | `polylog_scoped` | `PolylogOptions` |
| `lerch_phi(z, s, a)` | `NumericScalar`。`s`、`a` は実数のまま `z` を複素数にでき、どちらも複素数にできる | `lerch_phi_with_options` | `lerch_phi_scoped` | `LerchOptions` |

引数の順序は関数によって違う。
`polylog` は位数を先に `polylog(s, z)` と書き、`lerch_phi` は引数を先に `lerch_phi(z, s, a)` と書く。

エラーの分類は次のとおりである。

- `polylog` は、$s = 1$、$z = 1$ で `DomainError`（`Pole`）になる。
  実数の型の $z > 1$ は $s = 2$（実部を返す）と 0 以下の整数の $s$ のほかは `DomainError`（`OutsideDomain`）になる。
- `lerch_phi` は、$a$ が 0 以下の整数で $s$ が 0 以下の整数でないとき、`a` の `DomainError`（`Pole`）になる。
  ただし実数の型では、$a \le 0$ で $s$ が整数でない入力を先に `a` の `DomainError`（`OutsideDomain`）として拒むので、`Pole` になるのは $s$ が正の整数のときである。
  複素数の型では整数でない負の $a$ を主値の冪で評価する。
  $z = 1$、$s = 1$ は `s` の `Pole`、実数の型の $z > 1$ は $s$ が 0 以下の整数のときのほかは `z` の `OutsideDomain` になる。
- どちらも、非有限の入力は `NonFinite` になり、解析接続が有限の推定を作れないときは `NumericalInstability` になる。

`PolylogOptions` と `LerchOptions` の既定の作業量の上限は 65536 単位で、精度の要求ではなく、収束の遅い場合を最後まで計算させるための上限である。
多重対数の実数の値を $z > 1$ で求められるのは $s = 2$（実部）と 0 以下の整数の位数だけで、他の位数の切断の上の値は複素数の型で岸を選んで求める。
負の位数が大きいと値が型の範囲を超える。
このとき複素数の型のオプション付き形式は、通常値への射影の状態を `Overflow` にして対数形を返す。
実数の型の `polylog` は同じ場合（$s = -200$、$z = 0.5$ など）にスカラー変換のエラー（`kind()` が `ScalarConversion`）を返す。
範囲を超える値が必要なら、複素数の型のオプション付き形式を使う。

## 乗法公式と Lerch の核の経路

次のセルは位数 $s$ と引数 $z$ を入力にとり、一般の位数での三つの関係を確かめる。
一つ目は乗法公式 $\operatorname{Li}_s(z) + \operatorname{Li}_s(-z) = 2^{1-s}\operatorname{Li}_s(z^2)$ で、$z$、$-z$、$z^2$ は Lerch の核の別々の経路に入ることがある。
二つ目は $a$ のずらしの関係 $\Phi(z, s, 3/2) = z\,\Phi(z, s, 5/2) + (3/2)^{-s}$ で、三つ目は $\operatorname{Li}_s(1)$ と実数の `riemann_zeta` の比較である。
左辺と右辺は別の引数と別の経路で評価するので、一致は経路ごとの実装の独立な検算になる。
二つ目の表は、オプション付き形式 `polylog_with_options` が $z$ と $\pm 0.97$ でどの方法を選んだか（アルゴリズムの識別子）と、推定誤差、作業の単位数を示す。

既定の $s = 2.5$、$z = 0.5$ では、ずらしの関係の相対差は $7.8 \times 10^{-16}$、$\zeta(s)$ との相対差は $1.7 \times 10^{-16}$ である。
乗法公式の相対差は $5.4 \times 10^{-15}$ とやや大きく、これは左辺の $\operatorname{Li}_s(0.5) = 0.555$ と $\operatorname{Li}_s(-0.5) = -0.462$ が打ち消し合って $0.093$ になる桁落ちによる。
経路の表では、$z = 0.5$ は定義の級数（`lerch_compensated_series`、37 単位）、$z = \pm 0.97$ は積分表示（`lerch_regularized_mellin`、1596〜2172 単位）に入り、作業は級数の項数から積分の節点の数へ大きく増える。
ケース near-one（$s = 0.3$、$z = 0.98$）では $z = 0.98$ と $0.97$ が $\ln z$ の級数（`lerch_logarithmic_series`）に切り替わり、推定誤差は $3 \times 10^{-13}$ で、値 19 に対する相対誤差は $1.7 \times 10^{-14}$ である。
ケース negative-order（$s = -1.5$、$z = -0.97$）は負の非整数の位数の経路で、$z = \pm 0.97$ のどちらも $\ln z$ の級数を使い、$\operatorname{Li}_{-1.5}(0.97) \approx 8210$ のような大きな値でも乗法公式の相対差は $1.3 \times 10^{-15}$ にとどまる。
位数に整数を選ぶと、$s = 1$ は対数（`polylog_logarithm`、0 単位）、$s = 0$ は `polylog_geometric`（1 単位）、負の整数は Eulerian 数の有理関数（`polylog_eulerian_rational`、$s = -2$ で 4 単位）の経路が表に出る。
$s = 1$ では $z = 1$ が極なので、比較の 3 行目は「極」と表示される。
推定誤差は包含区間ではないが、値に比べて大きければ、その経路では丸めの累積か打ち切りが支配していることを示す。

## まとめ

`polylog` と `lerch_phi` は $z$ の位置で定義の級数、$\ln z$ の級数、積分表示を切り替え、整数と負の位数には有理関数、極の和、Jonquière の反転公式を使う。
作業量は経路によって 0 単位から数千単位まで変わるので、反復の中で呼ぶときはスコープ付き API で親の作業量に含め、オプション付き形式でアルゴリズムの識別子と作業の単位数を確かめる。
$s = 2$ 以外の位数には一様な ULP の上限がないので、オプション付き形式の推定誤差を値と比べて使い、乗法公式やずらしの関係のような独立な関係で検算する。
実数の型で $z > 1$ を渡せるのは $s = 2$ と 0 以下の整数の位数だけで、他の位数の切断の上の値は複素数の型で岸を選んで求める。

位数 2 の二重対数と、単位円上の二重対数の虚部である Clausen 関数の評価は、[二重対数・Spence 関数・Clausen 関数](../polylog-lerch-and-clausen/) で確かめる。
多重対数で書ける Fermi–Dirac 積分の評価と漸近形は、[Fermi–Dirac 積分](../fermi-dirac-integrals/) で確かめる。
