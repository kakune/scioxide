二重対数 $\operatorname{Li}_2(z)$ は、対数を含む積分 $-\int_0^z \ln(1 - t)/t\,dt$ の値として、Feynman 図のループ積分、統計力学の格子モデル、ゼータ関数の特殊値の計算に現れる。
Spence 関数は同じ関数を引数 $1 - z$ で書いた形で、放射補正の公式などで使われる。
Clausen 関数 $\operatorname{Cl}_2(\theta)$ は単位円上の二重対数の虚部で、双曲幾何の体積や格子和に現れる。

このページは、三つの関数の定義と切断、scioxide-special が使う関数等式と級数、精度の保証、API の使い分けを説明する。
三つの関数はどれも決まった数の項で評価するので、作業量は引数によってほとんど変わらず、スコープ付き API を持たない。
一般の位数 $s$ の多重対数 $\operatorname{Li}_s(z)$ と Lerch の超越関数は、引数によって作業量が大きく変わる別の評価法を使うので、[一般の位数の多重対数と Lerch の超越関数](../polylog-and-lerch/) で扱う。
最後の二つのセルで、二重対数の関数等式と Clausen 関数の特殊値を数値で確かめる。

## 定義と切断

### 二重対数

多重対数 $\operatorname{Li}_s(z) = \sum_{k \ge 1} z^k/k^s$ の位数 $s = 2$ の場合を二重対数と呼ぶ（DLMF 25.12.1–25.12.2）。

$$
\operatorname{Li}_2(z) = \sum_{k=1}^{\infty} \frac{z^k}{k^2} = -\int_0^z \frac{\ln(1 - t)}{t} \, dt, \qquad \lvert z\rvert \le 1
$$

積分の表示を $z$ について解析接続すると、$\operatorname{Li}_2$ は $[1, \infty)$ を切断とする平面で一価の関数になる。
切断の上では虚部の符号付きゼロ（$+0$ か $-0$）で上下どちらの岸の値かを選ぶ。

$\operatorname{Li}_2(0) = 0$、$\operatorname{Li}_2(1) = \pi^2/6$、$\operatorname{Li}_2(-1) = -\pi^2/12$ である。
実数の $x > 1$ は切断の上にあり、上下の岸で虚部が $\pm\pi \ln x$ になる。
scioxide-special の実数の `dilog` は、この場合に主値の実部 $\operatorname{Re}\operatorname{Li}_2(x)$ を返す。

二重対数には、引数を別の領域へ移す関数等式がある。
次の式で、$z$ はそれぞれの式の右に書いた範囲の複素数である。

$$
\begin{aligned}
\operatorname{Li}_2(z) + \operatorname{Li}_2(1 - z) &= \frac{\pi^2}{6} - \ln z \, \ln(1 - z) && \text{（反射公式、DLMF 25.12.6）} \\
\operatorname{Li}_2(z) + \operatorname{Li}_2(1/z) &= -\frac{\pi^2}{6} - \frac{1}{2}\ln^2(-z) && z \notin [0, \infty) \text{（反転公式、DLMF 25.12.4）} \\
\operatorname{Li}_2(z) + \operatorname{Li}_2\!\left(\frac{z}{z - 1}\right) &= -\frac{1}{2}\ln^2(1 - z) && z \notin [1, \infty) \text{（Landen の公式、DLMF 25.12.3）}
\end{aligned}
$$

反転公式を実数の $x > 1$ に当てはめ、$\ln(-1/x) = -\ln x \pm i\pi$ を代入して実部を取ると、$\operatorname{Re}\operatorname{Li}_2(x) + \operatorname{Li}_2(1/x) = \pi^2/3 - \frac{1}{2}\ln^2 x$ になる。
右辺は $x$ とともに減るので、$\operatorname{Re}\operatorname{Li}_2(x)$ は $x \approx 12.595$ で 0 を横切って負になる。

### Spence 関数

Spence 関数は二重対数を $1 - z$ で評価した関数である。

$$
\operatorname{Li}_2(1 - z) = \int_1^z \frac{\ln t}{1 - t} \, dt
$$

`spence(x)` はこの値 $\operatorname{Li}_2(1 - x)$ を返し、$x = 0$ で $\pi^2/6$、$x = 1$ で 0 になる。
文献によっては $\operatorname{Li}_2(x)$ そのものや符号を変えた関数を Spence 関数と呼ぶので、他のライブラリと比べるときは定義をそろえる。
実数の `spence` は $x \ge 0$ だけを受け付ける。
複素数では切断が $(-\infty, 0]$ に移り、$z \mapsto 1 - z$ が虚部の符号を反転するので、符号付きゼロによる岸の選び方は `dilog` と逆になる。

### Clausen 関数

2 次の Clausen 関数は次の級数と積分で定義される（Abramowitz–Stegun §27.8）。

$$
\operatorname{Cl}_2(\theta) = \sum_{k=1}^{\infty} \frac{\sin k\theta}{k^2} = -\int_0^{\theta} \ln\left\lvert 2 \sin\frac{t}{2} \right\rvert \, dt
$$

$\theta$ はラジアンで、$\operatorname{Cl}_2$ は奇関数で周期 $2\pi$ を持ち、連続で極を持たない。
単位円上の二重対数とは $\operatorname{Cl}_2(\theta) = \operatorname{Im}\operatorname{Li}_2(e^{i\theta})$ の関係にある。
導関数 $-\ln\lvert 2\sin(\theta/2)\rvert$ が 0 になる $\theta = \pi/3$ で最大値 $1.0149416064\ldots$ を取り、これは双曲空間の正則な理想四面体の体積に等しい。
$\theta = \pi/2$ では Catalan の定数 $G = 0.9159655941\ldots$ になり、倍角の公式 $\operatorname{Cl}_2(2\theta) = 2\operatorname{Cl}_2(\theta) - 2\operatorname{Cl}_2(\pi - \theta)$ が成り立つ。
原点の近くでは $\operatorname{Cl}_2(\theta) \approx \theta(1 - \ln\lvert\theta\rvert)$ で、傾きは対数的に発散する。

## 評価法

### 実数の二重対数と Spence 関数

実数の `dilog` と `spence` は関数等式で引数を $[-1, 1/2]$ に移してから、$w = -\ln(1 - x)$ の級数で値を求める。
$\operatorname{Li}_2$ の積分の表示で $t = 1 - e^{-u}$ と置き換えると、$\operatorname{Li}_2(x) = \int_0^{w} u/(e^u - 1)\, du$ になる。
被積分関数の Bernoulli 数による展開 $u/(e^u - 1) = \sum_{n \ge 0} B_n u^n/n!$ を項ごとに積分すると、次の級数になる。

$$
\operatorname{Li}_2(x) = w - \frac{w^2}{4} + \sum_{k=1}^{\infty} \frac{B_{2k}}{(2k+1)\,(2k)!}\, w^{2k+1}
$$

$B_{2k}$ は Bernoulli 数である。
この級数は $|w| < 2\pi$ で収束し、$[-1, 1/2]$ では $|w| \le \ln 2$ なので、項はおよそ $(\ln 2/2\pi)^{2k}$ の速さで減る。
実装は $k = 13$ までの 13 項で打ち切り、打ち切り誤差は $8 \times 10^{-29}$ 未満になる。
定義の冪級数 $\sum x^k/k^2$ は、$x = 1/2$ でも倍精度の丸めの大きさまで下げるのに 50 項ほど要し、$x \to 1$ では収束がさらに遅くなる。

区間の割り当ては次のとおりである。
$-1 \le x \le 1/2$ は級数をそのまま使い、$1/2 < x < 2$ は反射公式、$x < -1$ と $x \ge 2$ は反転公式で $[-1, 1/2]$ へ移す。
$1 < x < 2$ の反射では $\ln(1 - x)$ の代わりに $\ln\lvert 1 - x\rvert$ を使って実部を求める。
反射と反転では、定数 $\pi^2/6$ または $\pi^2/3$、対数の積、級数の値の三つが打ち消し合うことがあるので、この和を倍々精度（二つの倍精度数の和で一つの値を表す方法）で組み立てる。
$\operatorname{Re}\operatorname{Li}_2(x)$ の零点 $x \approx 12.595$ を含む $12 \le x \le 13$ では、$1/x$ の定義の級数を倍々精度で足し、$8 \le x \le 24$ では $\ln x$ も倍々精度で求めて、零点の近くでも絶対誤差を丸めの大きさに保つ。
`spence` も同じ核を使い、$x < 1/2$ を反射、$1/2 \le x \le 2$ を級数、$x > 2$ を反転に割り当てる。

作業は区間の選択に 1 単位、Bernoulli 級数の 1 項に 1 単位を使い、ほとんどの引数で 14 単位になる。
$12 \le x \le 13$ では Bernoulli 級数の代わりに定義の級数を最大 32 項まで足すので、30 単位程度になり、$x = 0$ のような厳密な値は 0 単位で返る。
作業量は引数によらずこの範囲にとどまるので、`dilog` と `spence` にはスコープ付き API がない。
`f32` の入力も倍精度に広げて同じ核で計算し、最後に一度だけ丸める。

### 複素数の二重対数

複素数の `dilog` も同じ変換を使う。
$|z| > 1$ は反転公式で単位円の内側へ、$|z| \le 1$ で $\operatorname{Re} z > 1/2$ の点は反射公式で $1 - z$ へ移し、残りを同じ Bernoulli 級数で求める。
$|z| \le 1$ かつ $\operatorname{Re} z > 1/2$ なら $\lvert 1 - z\rvert < 1$ なので、変換は高々 2 回で終わり、変換後の $w$ は級数の収束円 $|w| < 2\pi$ に入る。
作業は変換の 1 回ごとに 1 単位と級数の 13 単位で、14〜16 単位になる。
オプション付き形式は最後の項と和の大きさから推定誤差を求め、変換の対数の項の丸めをそれに加える。
複素数の `spence(z)` は `dilog(1 − z)` を同じ核で求める。

### Clausen 関数

`clausen` は $\lvert\theta\rvert \le \pi/2$ ならそのまま、それより大きければ $\sin\theta$ と $\cos\theta$ を全範囲の角度簡約で求め、$\operatorname{atan2}$ で最も近い $2\pi$ の倍数か $\pi$ の奇数倍からの符号付きの距離 $u$（$|u| \le \pi/2$）を取り出す。
$\theta$ から $2\pi k$ を引き算しないので、最大の有限値に近い $\theta$ でも簡約で桁を失わない。

$2\pi$ の倍数の近くでは、対数の特異性を分けた形 $\operatorname{Cl}_2(u) = u\,(c(u) - \ln|u|)$ を使い、正則な部分 $c(u)$ を $t = 2(u/\pi)^2 - 1$ の 15 項の Chebyshev 展開で求める。
$\pi$ の奇数倍の近くでは $\operatorname{Cl}_2$ が正則なので、$u\,(\ln 2 - \sum_{k=1}^{32} c_k\,(u/\pi)^{2k})$ の 32 項の冪級数で求める。
どちらも項の数が決まっているので、スコープ付き API はない。
オプション付き形式は評価した係数ごとに `ClausenOptions` の作業を 1 単位使い、既定の上限 128 は最も長い 32 項より大きい。
上限を項の数より小さくすると、オプション付き形式は途中で打ち切った値を終了状態 `IterationLimit` で返し、推定誤差は省いた項から見積もった大きさになる。
標準形式 `clausen(x)` は既定の上限で評価するので、この打ち切りは起こらない。

## 誤差と精度の保証

精度は三種類に分けて読む。
一つ目は照合データ（独立に高精度で生成した参照値）の点で試験した ULP の目標である。
二つ目は、オプション付き形式が返す推定誤差で、打ち切りと丸めから導いた値だが、包含区間（真の値を必ず含む区間）ではない。
三つ目は一様な上限がない範囲で、推定誤差を見て使う。

| 関数 | 実数の引数 | 複素数の引数 |
|---|---|---|
| `dilog`、`spence` | `f32`、`f64` とも 64 ULP を目標とし、照合データの全点で確かめる | 一様な ULP の上限はなく、推定誤差を返す |
| `clausen` | 一様な ULP の上限はなく、オプション付き形式が導いた誤差の大きさを返す | 提供しない |

照合試験では、無作為に選んだ点で `spence` の `f64` の誤差が 2.8 ULP 以内、`dilog` の `f64` の誤差が 99% の点で 31 ULP 以内、`f32` はどちらも 1 ULP 以内であることを確かめている。
同じ試験は、境界の近くの点を含むすべての点で実際の誤差がオプション付き形式の推定誤差を超えないことも確かめている。
複素数の引数は独立な参照値と比べて相対 $5 \times 10^{-11}$ か絶対 $5 \times 10^{-13}$ の大きい方以内（`f64`）であることを試験している。
`clausen` は、`f32`、`f64`、非正規化数の引数で値と誤差の見積もりを試験している。

関数の値が 0 に近い所では、ULP で測った誤差は大きくなりうる。
$\operatorname{Re}\operatorname{Li}_2(x)$ の零点 $x \approx 12.595$ の近くでは、照合試験は絶対誤差が $5 \times 10^{-16}$ 以下であることを確かめている。
$\operatorname{Cl}_2$ の $\theta = \pi$ の近くでも、値が 0 に近づくので相対誤差は大きくなりうる。

## API

| 関数 | スカラー | オプション付き形式 | スコープ付き API | オプション | 定義域のエラー |
|---|---|---|---|---|---|
| `dilog(x)` | `NumericScalar`（実数と複素数） | `dilog_with_options` | なし | `PolylogOptions` | なし |
| `spence(x)` | `NumericScalar` | `spence_with_options` | なし | `PolylogOptions` | 実数の $x < 0$ は `DomainError`（`OutsideDomain`） |
| `clausen(x)` | `RealScalar` だけ | `clausen_with_options` | なし | `ClausenOptions` | なし |

どの関数も、非有限の入力は `NonFinite` になる。
`PolylogOptions` の既定の作業量の上限は 65536 単位、`ClausenOptions` は 128 単位で、どちらも精度の要求ではない。
`dilog_with_options` と `spence_with_options` で上限を評価に必要な単位数（上の 14〜30 単位程度）より小さくすると、実数の引数でも値を返さずに `ConvergenceFailure` になる。
`clausen_with_options` は上で述べたとおり、打ち切った値を `IterationLimit` で返す。

位数 2 の `polylog(2.0, x)` は `dilog(x)` と同じ核を使い、実数の $x > 1$ でも同じ実部の規約で値を返す。
Clausen 関数の複素数版は提供しない。
複素数の $\theta$ が必要なら、実数の $\theta$ で成り立つ $\operatorname{Cl}_2(\theta) = \frac{1}{2i}\left[\operatorname{Li}_2(e^{i\theta}) - \operatorname{Li}_2(e^{-i\theta})\right]$ の右辺を、複素数の `dilog` で計算する。
高次の Clausen 関数 $\operatorname{Cl}_n$ も提供しないので、$n$ が偶数なら $\operatorname{Im}\operatorname{Li}_n(e^{i\theta})$、奇数なら $\operatorname{Re}\operatorname{Li}_n(e^{i\theta})$ を複素数の `polylog` で求める。

## 二重対数の関数等式による検算

次のセルは $0 < x < 1$ の入力 $x$ から、反射公式、Landen の公式、二つの反転公式の両辺を作って比べる。
左辺は `dilog` の値の和で、右辺は対数と $\pi^2$ だけの初等的な式である。
$x = 0.3$ では、$1 - x$ は反射の区間、$x/(x - 1)$ と $x$ は級数の区間、$-1/x$ と $1/x$ は反転の区間に入るので、一つの $x$ で三つの区間を通る。
Spence 関数の行は、`spence(1 − x)` が `dilog(x)` と同じ値になることを確かめる。
二つ目の表はオプション付き形式 `dilog_with_options` の結果で、推定誤差、終了状態、作業の単位数を示す。

```rust
//| id: special-dilog-euler-reflection
//| ref: special-dilog-euler-reflection
//| title: 二重対数の反射・Landen・反転の公式
//| run: reactive
//| crates: [scioxide-special, scioxide-core]
//| inputs:
//|   x: {"type":"range","label":"引数 x [-]","description":"0 < x < 1。1 − x、x/(x − 1)、−1/x、1/x が別々の区間に入る。","min":0.02,"max":0.98,"step":0.01,"value":0.3}
//| cases:
//|   - {"id":"near-one","label":"x = 0.98","description":"1 − x が小さく、ln(1 − x) が大きい。x/(x − 1) = −49 は反転の区間に入る。","inputs":{"x":0.98}}
//|   - {"id":"inverse-zero","label":"x = 0.08","description":"1/x = 12.5 が Re Li₂ の零点 12.595 の近くの区間に入る。","inputs":{"x":0.08}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"identities","path":"/rows/0/3","range":{"max":1e-15}}
//|       - {"artifact":"identities","path":"/rows/1/3","range":{"max":1e-15}}
//|       - {"artifact":"identities","path":"/rows/2/3","range":{"max":1e-15}}
//|       - {"artifact":"identities","path":"/rows/3/3","range":{"max":1e-15}}
//|       - {"artifact":"identities","path":"/rows/4/3","range":{"max":1e-15}}
//|       - {"artifact":"detail","path":"/rows/0/0","approx":{"value":0.326129510075476,"rtol":1e-14}}
//|       - {"artifact":"detail","path":"/rows/0/2","equals":"Converged"}
//|   - case: near-one
//|     expect:
//|       - {"artifact":"identities","path":"/rows/0/3","range":{"max":1e-14}}
//|       - {"artifact":"identities","path":"/rows/1/3","range":{"max":1e-14}}
//|       - {"artifact":"identities","path":"/rows/3/3","range":{"max":1e-14}}
//|   - case: inverse-zero
//|     expect:
//|       - {"artifact":"identities","path":"/rows/2/3","range":{"max":1e-15}}
//|       - {"artifact":"identities","path":"/rows/3/3","range":{"max":2e-15}}
use core::f64::consts::PI;
use scioxide_core::RealScalar;
use scioxide_special::{PolylogOptions, dilog, dilog_with_options, spence};

let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let fixed15 = serde_json::json!({ "fractionDigits": 15 });
let li2 = |t: f64| dilog(t).map_err(|e| e.to_string());
let ln_x = RealScalar::ln(x);
let ln_1mx = RealScalar::ln(1.0 - x);
let zeta2 = PI * PI / 6.0;

// (公式, 左辺, 右辺)。右辺は対数と π² だけで書いた独立な式。
let identities = vec![
    (
        "反射 Li₂(x) + Li₂(1 − x)",
        li2(x)? + li2(1.0 - x)?,
        zeta2 - ln_x * ln_1mx,
    ),
    (
        "Landen Li₂(x) + Li₂(x/(x − 1))",
        li2(x)? + li2(x / (x - 1.0))?,
        -0.5 * ln_1mx * ln_1mx,
    ),
    (
        "反転 Li₂(−x) + Li₂(−1/x)",
        li2(-x)? + li2(-1.0 / x)?,
        -zeta2 - 0.5 * ln_x * ln_x,
    ),
    (
        "反転の実部 Li₂(x) + Re Li₂(1/x)",
        li2(x)? + li2(1.0 / x)?,
        2.0 * zeta2 - 0.5 * ln_x * ln_x,
    ),
    (
        "Spence spence(1 − x) と Li₂(x)",
        spence(1.0 - x).map_err(|e| e.to_string())?,
        li2(x)?,
    ),
];
let rows: Vec<(&str, f64, f64, f64)> = identities
    .into_iter()
    .map(|(name, lhs, rhs)| (name, lhs, rhs, (lhs - rhs).abs()))
    .collect();
let columns = serde_json::json!([
    { "key": "0", "label": "公式" },
    { "key": "1", "label": "左辺 [-]", "type": "number", "format": fixed15 },
    { "key": "2", "label": "右辺 [-]", "type": "number", "format": fixed15 },
    { "key": "3", "label": "残差 |左辺 − 右辺| [-]", "type": "number", "format": sci3 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "identities" })
);

// オプション付き形式: 値、推定誤差、終了状態、作業の単位数（固定の項数）。
let result = dilog_with_options(x, PolylogOptions::default()).map_err(|e| e.to_string())?;
let value = result.value().ok_or("値がない")?;
let detail = vec![(
    *value.value(),
    value.absolute_error(),
    format!("{:?}", result.termination()),
    result.counts().iterations(),
)];
let detail_columns = serde_json::json!([
    { "key": "0", "label": "Li₂(x) [-]", "type": "number", "format": fixed15 },
    { "key": "1", "label": "推定誤差 [-]", "type": "number", "format": sci3 },
    { "key": "2", "label": "終了状態" },
    { "key": "3", "label": "作業 [単位]", "type": "integer" }
]);
emit_table_with_columns!(
    detail_columns,
    detail,
    metadata = serde_json::json!({ "id": "detail" })
);
```

既定の $x = 0.3$ では、五つの公式の残差は 0 から $4.4 \times 10^{-16}$ で、倍精度の丸めの大きさにとどまる。
左辺の二つの値はそれぞれ違う区間の式で求めているので、どれかの区間の実装に誤りがあれば、残差は丸めより桁違いに大きくなる。
ケース near-one（$x = 0.98$）では $\ln(1 - x) \approx -3.9$ と大きく、$x/(x - 1) = -49$ は反転の区間に入るが、残差はやはり $4.4 \times 10^{-16}$ 以下である。
ケース inverse-zero（$x = 0.08$）では $1/x = 12.5$ が零点の近くの区間に入り、反転の実部の行の差は $6.1 \times 10^{-16}$ である。
この行の右辺は $\pi^2/3 \approx 3.29$ と $\frac{1}{2}\ln^2 x \approx 3.19$ の引き算で 0.100 になるので、差は右辺の引き算の丸めと同じ大きさにとどまる。
オプション付き形式の値は $\operatorname{Li}_2(0.3) = 0.326129510075476$、推定誤差は $5.8 \times 10^{-16}$ で、作業はどの $x$ でも 14 単位（区間の選択と 13 項）であり、評価が決まった項数で終わることを示す。

## Clausen 関数の特殊値と単位円上の二重対数

次のセルは入力の角度 $\theta$ で、`clausen` を複素数の `dilog` の虚部 $\operatorname{Im}\operatorname{Li}_2(e^{i\theta})$ と比べ、倍角の公式も確かめる。
続く三行は角度によらない特殊値で、$\operatorname{Cl}_2(\pi/2)$、Lerch の超越関数による $\Phi(-1, 2, 1/2)/4$、$\operatorname{Im}\operatorname{Li}_2(i)$ が、どれも Catalan の定数 $G$ に一致することを確かめる。
$\Phi(-1, 2, 1/2)/4 = \sum_{n \ge 0} (-1)^n/(2n+1)^2 = G$ は Dirichlet のベータ関数の値 $\beta(2)$ で、`lerch_phi` の評価法は [一般の位数の多重対数と Lerch の超越関数](../polylog-and-lerch/) で説明する。
$G$ と最大値 $\operatorname{Cl}_2(\pi/3)$ の参照値は、別の任意精度計算による有効数字 18 桁以上の定数である。
図は $[0, 2\pi]$ の $\operatorname{Cl}_2$ で、縦線は選んだ $\theta$ と最大の位置 $\pi/3$ である。

```rust
//| id: special-clausen-dilog-imag-identity
//| ref: special-clausen-dilog-imag-identity
//| title: Clausen 関数と単位円上の二重対数
//| run: reactive
//| crates: [scioxide-special, scioxide-core]
//| inputs:
//|   theta_deg: {"type":"range","label":"角度 θ [deg]","description":"表の 1、2 行目と図の縦線の位置。","min":1,"max":359,"step":1,"value":60}
//| cases:
//|   - {"id":"near-pi","label":"θ = 179°","description":"π の近くの冪級数の区間。Cl₂ は 0 に近い。","inputs":{"theta_deg":179}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"clausen","path":"/rows/0/1","approx":{"value":1.0149416064096536,"rtol":1e-14}}
//|       - {"artifact":"clausen","path":"/rows/0/3","range":{"max":1e-15}}
//|       - {"artifact":"clausen","path":"/rows/1/3","range":{"max":1e-15}}
//|       - {"artifact":"clausen","path":"/rows/2/3","range":{"max":1e-15}}
//|       - {"artifact":"clausen","path":"/rows/3/3","range":{"max":1e-15}}
//|       - {"artifact":"clausen","path":"/rows/4/3","range":{"max":1e-15}}
//|       - {"artifact":"clausen","path":"/rows/5/3","range":{"max":1e-15}}
//|   - case: near-pi
//|     expect:
//|       - {"artifact":"clausen","path":"/rows/0/1","approx":{"value":0.012097478975960675,"rtol":1e-13}}
//|       - {"artifact":"clausen","path":"/rows/0/3","range":{"max":1e-16}}
//|       - {"artifact":"clausen","path":"/rows/1/3","range":{"max":4e-15}}
use core::f64::consts::PI;
use scioxide_core::{Complex, RealScalar};
use scioxide_special::{clausen, dilog, lerch_phi, polylog};

let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let fixed15 = serde_json::json!({ "fractionDigits": 15 });
// 参照値（別の任意精度計算による定数）: Catalan の定数 G と最大値 Cl₂(π/3)。
let catalan = 0.915_965_594_177_219_015_f64;
let clausen_max = 1.014_941_606_409_653_625_f64;
let cl2 = |t: f64| clausen(t).map_err(|e| e.to_string());
let theta = theta_deg as f64 * PI / 180.0;
let unit = Complex::new(RealScalar::cos(theta), RealScalar::sin(theta));
let on_circle = dilog(unit).map_err(|e| e.to_string())?;
let lerch = lerch_phi(-1.0, 2.0, 0.5).map_err(|e| e.to_string())?;
let li2_i = polylog(2.0, Complex::new(0.0, 1.0)).map_err(|e| e.to_string())?;

let checks = vec![
    ("Cl₂(θ) と Im Li₂(e^{iθ})", cl2(theta)?, on_circle.im),
    (
        "Cl₂(2θ) と 2Cl₂(θ) − 2Cl₂(π − θ)",
        cl2(2.0 * theta)?,
        2.0 * cl2(theta)? - 2.0 * cl2(PI - theta)?,
    ),
    ("Cl₂(π/2) と G", cl2(PI / 2.0)?, catalan),
    ("Φ(−1, 2, 1/2)/4 と G", lerch / 4.0, catalan),
    ("Im Li₂(i) と G", li2_i.im, catalan),
    ("Cl₂(π/3) と最大値", cl2(PI / 3.0)?, clausen_max),
];
// 既定の θ = 60° では 1 行目が最大値 Cl₂(π/3) になる。
let rows: Vec<(&str, f64, f64, f64)> = checks
    .into_iter()
    .map(|(name, lhs, rhs)| (name, lhs, rhs, (lhs - rhs).abs()))
    .collect();
let columns = serde_json::json!([
    { "key": "0", "label": "比較" },
    { "key": "1", "label": "左 [-]", "type": "number", "format": fixed15 },
    { "key": "2", "label": "右 [-]", "type": "number", "format": fixed15 },
    { "key": "3", "label": "差の絶対値 [-]", "type": "number", "format": sci3 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "clausen" })
);

let mut curve = Vec::new();
for i in 0..=360 {
    let t = 2.0 * PI * i as f64 / 360.0;
    curve.push([t, cl2(t)?]);
}
emit_line_chart!(
    &vec![serde_json::json!({ "name": "Cl₂(θ)", "points": curve })],
    options = &serde_json::json!({
        "xLabel": "角度 θ [rad]",
        "yLabel": "Cl₂(θ) [-]",
        "xMin": 0.0,
        "xMax": 2.0 * PI,
        "yMin": -1.1,
        "yMax": 1.1,
        "annotations": [
            { "kind": "line", "axis": "x", "value": theta, "label": "選んだ θ" },
            { "kind": "line", "axis": "x", "value": PI / 3.0, "label": "最大 π/3" }
        ]
    })
);
```

既定の $\theta = 60°$ では 1 行目が最大値 $1.0149416064\ldots$ になり、最後の行の参照値と一致する。
六つの比較の差はどれも $2.3 \times 10^{-16}$ 以下で、`clausen` の二つの区間（$2\pi$ の倍数の近くの Chebyshev 展開と $\pi$ の近くの冪級数）、複素数の `dilog`、`lerch_phi`、複素数の `polylog` が同じ値を与える。
倍角の公式の行は、$\theta$、$2\theta$、$\pi - \theta$ が別々の区間に入ることが多く、区間の境目の食い違いを見つけるのに向く。
ケース near-pi（$\theta = 179°$）では、倍角の行の差が $1.0 \times 10^{-15}$ になる。
右辺の $\pi - \theta$ は倍精度の $\pi$（真の値との差 $1.2 \times 10^{-16}$）から引くので、その誤差に $\pi - \theta = 1°$ での傾き $-\ln\lvert 2\sin(0.5°)\rvert \approx 4.05$ と係数 2 が掛かり、差はおよそ $1.0 \times 10^{-15}$ になる。
これは引数を作るときの丸めによるもので、関数の評価の誤差ではない。
図は奇関数で周期 $2\pi$ の形で、$\theta = \pi$ を中心に点対称になり、原点の近くでは傾きが対数的に急になる。

## まとめ

二重対数と Spence 関数は反射公式と反転公式で引数を $[-1, 1/2]$ に移し、$w = -\ln(1 - x)$ の Bernoulli 級数を 13 項で評価するので、作業量はほぼ一定でスコープ付き API がなく、実数では照合データで 64 ULP の目標を確かめている。
実数の $x > 1$ の `dilog` は主値の実部であり、虚部が必要なら複素数の型で、符号付きゼロで切断の岸を選んで呼ぶ。
Spence 関数は文献によって定義が違うので、`spence(x)` が $\operatorname{Li}_2(1 - x)$ であることを確かめてから他の値と比べる。
`clausen` は実数だけを受け付け、全範囲の角度簡約と固定項数の展開で評価し、複素数の角度や高次の $\operatorname{Cl}_n$ は複素数の `dilog` と `polylog` で代える。

一般の位数の多重対数と Lerch の超越関数の評価法と作業量は、[一般の位数の多重対数と Lerch の超越関数](../polylog-and-lerch/) で確かめる。
方程式 $w e^w = z$ の解を枝ごとに求める方法は、[Lambert W 関数と Wright ω 関数](../lambert-w-and-wright-omega/) で確かめる。
