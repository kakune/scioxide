球座標の Helmholtz 方程式 $\nabla^2\psi + k^2\psi = 0$ を変数分離すると、動径の関数は半整数次の Bessel 関数で書ける。
これが球 Bessel 関数 $j_n$、$y_n$ と、その変形 $i_n$、$k_n$、進行波を表す球 Hankel 関数 $h_n^{(1)}$、$h_n^{(2)}$ で、散乱の部分波展開、音響と電磁波の多重極展開、Mie 散乱に現れる。
動径の関数に $x$ を掛けた Riccati–Bessel 関数は、Schrödinger 方程式の動径部分を 1 次元の形にしたときの解である。
このページはこれらの定義と性質、`scioxide-special` の評価法、精度の扱い、API の順に説明し、最後に漸化式の向きと Wronskian を数値で確かめる。
円柱 Bessel 関数と漸化式の安定な向きは [円柱 Bessel 関数と Hankel 関数](../airy-bessel-and-hankel/) で説明したものを使う。

## 球 Bessel 関数と球 Hankel 関数

$\psi = R(r)\,Y_\ell^m(\theta, \phi)$ と分離すると、$x = kr$ の関数として $R$ は球 Bessel の方程式（DLMF 10.47.1）を満たす。

$$
x^2 w'' + 2x w' + \left[x^2 - n(n+1)\right]w = 0, \qquad n = 0, 1, 2, \dots
$$

その解は半整数次の円柱 Bessel 関数で書ける（DLMF §10.47）。

$$
j_n(z) = \sqrt{\frac{\pi}{2z}}\,J_{n+1/2}(z), \qquad
y_n(z) = \sqrt{\frac{\pi}{2z}}\,Y_{n+1/2}(z), \qquad
h_n^{(1,2)}(z) = j_n(z) \pm \mathrm{i}\,y_n(z).
$$

変形の方程式 $x^2 w'' + 2x w' - [x^2 + n(n+1)]w = 0$ の解として、`scioxide-special` は DLMF §10.47 の規約で $i_n$ と $k_n$ を定義する。

$$
i_n(z) = \sqrt{\frac{\pi}{2z}}\,I_{n+1/2}(z), \qquad
k_n(z) = \sqrt{\frac{\pi}{2z}}\,K_{n+1/2}(z).
$$

$k_n$ の正規化は文献によって違い、$\sqrt{2/(\pi z)}\,K_{n+1/2}$ を使う本もあるので、他の実装と比べるときは $k_0$ で確かめる。
半整数次の Bessel 関数は初等関数で閉じた形になり、低次の値は次のとおりである（DLMF §10.49）。

$$
j_0(x) = \frac{\sin x}{x}, \quad j_1(x) = \frac{\sin x}{x^2} - \frac{\cos x}{x}, \quad
y_0(x) = -\frac{\cos x}{x}, \quad i_0(x) = \frac{\sinh x}{x}, \quad k_0(x) = \frac{\pi}{2x}e^{-x}.
$$

$j_n$ と $i_n$ は整関数で、$j_0(0) = i_0(0) = 1$、$n \ge 1$ では原点で 0 になり、$j_n(-z) = (-1)^n j_n(z)$ を満たす。
$y_n$、$k_n$、$h_n^{(1,2)}$ は原点に極を持つ。
$y_n$ と $h_n^{(1,2)}$ は負の実数の引数も受け付け（$y_n(-z) = (-1)^{n+1}y_n(z)$）、$k_n$ は実数では $x > 0$ だけを受け付ける。

$j_n$、$y_n$、$h_n^{(1,2)}$ は三項漸化式と導関数の式（DLMF 10.51.1–2）を満たす。

$$
f_{n-1}(z) + f_{n+1}(z) = \frac{2n+1}{z}f_n(z), \qquad
f_n'(z) = f_{n-1}(z) - \frac{n+1}{z}f_n(z).
$$

Wronskian は $\mathscr{W}\{j_n, y_n\}(z) = j_n y_n' - j_n' y_n = z^{-2}$（DLMF 10.50.1）で、下のセルで数値の検算に使う。
$x \to \infty$ では $j_n(x) \sim \sin(x - n\pi/2)/x$、$h_n^{(1)}(x) \sim (-\mathrm{i})^{n+1}e^{\mathrm{i}x}/x$ で、$h_n^{(1)}(kr)$ は時間因子 $e^{-\mathrm{i}\omega t}$ のもとで外向きの球面波を表す。
$e^{-\mathrm{i}x}h_n^{(1)}(x)$ は $1/x$ の $n+1$ 次の多項式なので、尺度化形 `spherical_hankel_1_scaled` は実軸上で振動しない。

## 球 Bessel 関数の評価法

実数の引数では、$j_n$ と $i_n$ は $\lvert x\rvert \le 1$ で定義の級数を足す。
それ以外では、閉形式の $f_0$、$f_1$ から漸化式で次数を動かす。
[漸化式の向き](oxref:special-bessel-recurrence-stability) の議論と同じく、$n > x$ では $j_n$ が極小解なので前進の漸化式は使えない。
そこで $j_n$（$n > x$）と $i_n$（$x < 4(n+1)^2$）は Miller の後退漸化式で求め、閉形式の $f_0$、$f_1$ のうち大きいほうで正規化する。
$y_n$ と $k_n$ は優越解なので、常に前進の漸化式で求める。
変形関数の漸化式は全体を指数因子で尺度化して回すので、途中の値があふれない。
計算量は次数 $n$ に比例し、`SphericalBesselOptions` の作業量の上限（既定 65536 単位）を超えると `ConvergenceFailure` になる。

複素数の引数では、$\lvert z\rvert < 1/4$ で級数を足し、それ以外では次数 $n + 1/2$ の円柱 Bessel 関数を使う。
平方根 $\sqrt{z}$ と円柱関数は主枝をとる。
球 Hankel 関数は実軸の外では次数 $n + 1/2$ の変形関数から求める。

指数的に変わる関数には尺度化形がある。
`spherical_in_scaled` は $e^{-\lvert\operatorname{Re}z\rvert}i_n(z)$、`spherical_kn_scaled` は $e^{z}k_n(z)$ を返す。
`spherical_hankel_1_scaled` は $e^{-\mathrm{i}z}h_n^{(1)}(z)$、`spherical_hankel_2_scaled` は $e^{\mathrm{i}z}h_n^{(2)}(z)$ を返し、それぞれ負または正の大きな $\operatorname{Im}z$ で範囲に収まる。
オプション付き形式の導関数は尺度化しない関数の導関数に同じ因子を掛けた値で、因子そのものは微分しない。

## Riccati–Bessel 関数

球対称なポテンシャルでの Schrödinger 方程式の動径部分は、$u(r) = r R(r)$ と置くと $u'' + [k^2 - \ell(\ell+1)/r^2 - 2mV/\hbar^2]u = 0$ の 1 次元の形になる。
$V = 0$ の自由な解が Riccati–Bessel 関数で、`scioxide-special` は次の 2 つを実数の引数で提供する。

$$
\texttt{riccati\_jn}(n, x) = x\,j_n(x), \qquad \texttt{riccati\_yn}(n, x) = x\,y_n(x).
$$

どちらも $u'' + [1 - n(n+1)/x^2]u = 0$ を満たし、$x\,j_0(x) = \sin x$、$x\,y_0(x) = -\cos x$ である。
Abramowitz–Stegun の $C_n(x) = -x\,y_n(x)$ とは符号が逆なので、Mie 散乱の公式に使うときは符号の規約を確かめる。

`riccati_jn` は有限の $x$ をすべて受け付け、$\lvert x\rvert \le 1$ で級数（DLMF 10.53.1）を足す。
それ以外では閉形式 $\sin x$、$\sin x/x - \cos x$ から、$n \le \lvert x\rvert$ では前進、$n > \lvert x\rvert$ では大きいほうの閉形式で正規化した Miller の後退漸化式で次数を動かす。
`riccati_yn` は閉形式 $-\cos x$、$-\cos x/x - \sin x$ から前進の漸化式で求める。
`riccati_yn` は $x = 0$ で、$n = 0$ なら極限値 $-1$ を返し、$n \ge 1$ なら `DomainError`（`Pole`）を返す。
$n$ が $\lvert x\rvert$ に比べて大きいと $\lvert x\,y_n(x)\rvert$ があふれ、`NumericalInstability`（`Overflow`）になる。

## 精度の扱い

球 Bessel 関数、球 Hankel 関数、Riccati–Bessel 関数には、一様な ULP の仕様がない。
照合試験では、実数の引数について独立に生成した `f32` と `f64` の参照値と値・導関数を比べ、零点の近くでも意味を持つように、絶対と相対を混ぜた単位 $\varepsilon\max(1, \lvert\text{参照値}\rvert)$ で誤差を測る。
照合データの点では、`f64` の誤差がこの単位の 1024 倍以内にあり、オプション付き形式の推定誤差（`ValueWithError` の誤差。
包含区間ではない）が実際の誤差を覆うことを確かめている。
この限界は照合データの点で測った値で、受け付けるすべての引数に対する仕様ではないので、精度が必要な計算ではオプション付き形式の推定誤差を読む。
閉形式と前進の漸化式による推定誤差は丸め誤差の伝播から導いたもの（`Derived`）で、Miller の後退漸化式による推定誤差は打ち切りの深さを変えた 2 回の結果の差による経験的なもの（`Heuristic`）であり、上界ではない。

## API

どの関数にも標準形式、オプション付き形式、スコープ付き API がある。
球 Bessel 関数と球 Hankel 関数は `NumericScalar` で実数と複素数を受け取り、Riccati–Bessel 関数は `RealScalar` で実数だけを受け取る。
次数 `order` は `u32` の非負整数である。
オプションは `SphericalBesselOptions` で、作業量の上限（`Budget`。
精度の要求ではない。
既定 65536 単位）だけを持つ。

| 標準形式 | オプション付き形式 | スコープ付き API | 値 |
|---|---|---|---|
| `spherical_jn`、`spherical_yn` | `spherical_jn_with_options`、`spherical_yn_with_options` | `spherical_jn_scoped`、`spherical_yn_scoped` | $j_n(z)$、$y_n(z)$ |
| `spherical_in`、`spherical_kn` | `spherical_in_with_options`、`spherical_kn_with_options` | `spherical_in_scoped`、`spherical_kn_scoped` | $i_n(z)$、$k_n(z)$ |
| `spherical_in_scaled`、`spherical_kn_scaled` | `spherical_in_scaled_with_options`、`spherical_kn_scaled_with_options` | `spherical_in_scaled_scoped`、`spherical_kn_scaled_scoped` | $e^{-\lvert\operatorname{Re}z\rvert}i_n(z)$、$e^{z}k_n(z)$ |
| `spherical_hankel_1`、`spherical_hankel_2` | `spherical_hankel_1_with_options`、`spherical_hankel_2_with_options` | `spherical_hankel_1_scoped`、`spherical_hankel_2_scoped` | $h_n^{(1)}(z)$、$h_n^{(2)}(z)$（複素数） |
| `spherical_hankel_1_scaled`、`spherical_hankel_2_scaled` | `spherical_hankel_1_scaled_with_options`、`spherical_hankel_2_scaled_with_options` | `spherical_hankel_1_scaled_scoped`、`spherical_hankel_2_scaled_scoped` | $e^{-\mathrm{i}z}h_n^{(1)}(z)$、$e^{\mathrm{i}z}h_n^{(2)}(z)$（複素数） |
| `riccati_jn`、`riccati_yn` | `riccati_jn_with_options`、`riccati_yn_with_options` | `riccati_jn_scoped`、`riccati_yn_scoped` | $x\,j_n(x)$、$x\,y_n(x)$ |

非有限な入力は `NonFinite` を返す。
$y_n$、$h_n^{(1,2)}$、$n \ge 1$ の `riccati_yn` は $x = 0$ で `DomainError`（`Pole`）を返し、$k_n$ は実数の $x = 0$ で `DomainError`（`Pole`）、$x < 0$ で `DomainError`（`OutsideDomain`）を返す。
作業量の上限で止まった評価は、オプション付き形式では終了状態 `IterationLimit` の部分結果になり、推定値がなければ `ConvergenceFailure` を返す。
球面調和関数は [球面調和関数](../spherical-harmonics/) で扱う。

## 球 Bessel 関数の漸化式と Wronskian

次のセルは引数 $x$ と最大の次数 $N$ を選び、$n = 0, \dots, N$ の $\lvert j_n(x)\rvert$、$\lvert y_n(x)\rvert$ を `spherical_jn`、`spherical_yn` で求めて対数軸に描く。
比較のため、閉形式の $j_0$、$j_1$ から前進の漸化式で作った $j_n$ も描く。
この前進の漸化式は、$n > x$ で $j_n$ が極小解になることを見せるための手計算である。
表は 5 次ごとに、API の $j_n$、前進の漸化式で作った値の相対誤差、Wronskian の残差 $\lvert x^2(j_n y_n' - j_n' y_n) - 1\rvert$、`riccati_jn` と `riccati_yn` の $x\,j_n$、$x\,y_n$ との相対差を示す。
導関数は $f_n' = f_{n-1} - (n+1)f_n/x$（$n = 0$ では $f_0' = -f_1$）で API の値から作る。

```rust
//| id: special-spherical-bessel-wronskian
//| ref: special-spherical-bessel-wronskian
//| title: 球 Bessel 関数の漸化式の向きと Wronskian
//| run: reactive
//| crates: [scioxide-special]
//| inputs:
//|   argument: {"type":"range","label":"引数 x [-]","description":"n > x で j_n は極小解、y_n は優越解になる。","min":0.5,"max":20,"step":0.5,"value":5}
//|   max_order: {"type":"range","label":"最大の次数 N [-]","description":"描く次数の上限。","min":5,"max":40,"step":5,"value":25}
//| cases:
//|   - {"id":"large-argument","label":"x = 20, N = 15","description":"すべての次数が n < x の振動領域に入り、前進の漸化式も精度を保つ。","inputs":{"argument":20,"max_order":15}}
//|   - {"id":"small-argument","label":"x = 0.5, N = 40","description":"|y_40| は 10^71 を超え、j_40 は 10^−72 を下回るが、Wronskian は保たれる。","inputs":{"argument":0.5,"max_order":40}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"orders","path":"/rows/0/1","approx":{"value":-0.1917848549326277,"rtol":1e-13}}
//|       - {"artifact":"orders","path":"/rows/5/2","range":{"min":1}}
//|       - {"artifact":"orders","path":"/rows/5/3","range":{"max":1e-13}}
//|       - {"artifact":"orders","path":"/rows/5/4","range":{"max":1e-13}}
//|   - case: large-argument
//|     expect:
//|       - {"artifact":"orders","path":"/rows/3/2","range":{"max":1e-12}}
//|       - {"artifact":"orders","path":"/rows/3/3","range":{"max":1e-13}}
//|   - case: small-argument
//|     expect:
//|       - {"artifact":"orders","path":"/rows/8/3","range":{"max":1e-13}}
//|       - {"artifact":"orders","path":"/rows/8/2","range":{"min":1e100}}
use scioxide_special::{riccati_jn, riccati_yn, spherical_jn, spherical_yn};

let x = argument;
let n_max = max_order as u32;
let mut j = Vec::new();
let mut y = Vec::new();
for n in 0..=n_max + 1 {
    j.push(spherical_jn(n, x).map_err(|e| e.to_string())?);
    y.push(spherical_yn(n, x).map_err(|e| e.to_string())?);
}

// 閉形式の j_0, j_1 から前進の漸化式 f_{n+1} = (2n+1)/x f_n − f_{n−1}（手計算、f64 の標準関数）。
let mut forward = vec![x.sin() / x, x.sin() / (x * x) - x.cos() / x];
for n in 1..n_max as usize {
    forward.push((2 * n + 1) as f64 / x * forward[n] - forward[n - 1]);
}

let points = |values: &[f64]| -> Vec<[f64; 2]> {
    values[..=n_max as usize]
        .iter()
        .enumerate()
        .map(|(n, v)| [n as f64, v.abs()])
        .filter(|p| p[1] > 0.0)
        .collect()
};
emit_line_chart!(
    &vec![
        serde_json::json!({ "name": "|j_n(x)|（API）", "points": points(&j) }),
        serde_json::json!({ "name": "|y_n(x)|（API）", "points": points(&y) }),
        serde_json::json!({
            "name": "|j_n(x)|（前進の漸化式）",
            "points": points(&forward),
            "style": { "lineType": "dashed" }
        }),
    ],
    options = &serde_json::json!({
        "xLabel": "次数 n [-]",
        "yLabel": "絶対値 [-]",
        "yType": "log",
        "xMin": 0.0,
        "xMax": 40.0,
        "annotations": [{ "kind": "line", "axis": "x", "value": x, "label": "n = x" }]
    })
);

// f_n' = f_{n−1} − (n+1)/x f_n、f_0' = −f_1。
let derivative = |f: &[f64], n: usize| {
    if n == 0 {
        -f[1]
    } else {
        f[n - 1] - (n + 1) as f64 / x * f[n]
    }
};
let mut rows = Vec::new();
for n in (0..=n_max).step_by(5) {
    let k = n as usize;
    let wronskian = x * x * (j[k] * derivative(&y, k) - derivative(&j, k) * y[k]) - 1.0;
    let rj = riccati_jn(n, x).map_err(|e| e.to_string())?;
    let ry = riccati_yn(n, x).map_err(|e| e.to_string())?;
    let riccati = ((rj - x * j[k]) / (x * j[k]))
        .abs()
        .max(((ry - x * y[k]) / (x * y[k])).abs());
    rows.push((
        n,
        j[k],
        ((forward[k] - j[k]) / j[k]).abs(),
        wronskian.abs(),
        riccati,
    ));
}
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let columns = serde_json::json!([
    { "key": "0", "label": "次数 n", "type": "integer" },
    { "key": "1", "label": "j_n(x) [-]", "type": "number", "format": sci3 },
    { "key": "2", "label": "前進の漸化式の相対誤差 [-]", "type": "number", "format": sci2 },
    { "key": "3", "label": "|x²W − 1| [-]", "type": "number", "format": sci2 },
    { "key": "4", "label": "Riccati との相対差 [-]", "type": "number", "format": sci2 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "orders" })
);
```

既定の $x = 5$ では、$n < x$ の範囲で三つの曲線は重なり、$n > x$ で $\lvert j_n\rvert$ は次数ごとに 1 桁近く減り、$\lvert y_n\rvert$ は同じ割合で増える。
前進の漸化式で作った $j_n$ は $n \approx 17$ から API の値を離れ、$\lvert y_n\rvert$ に比例して増えて、$n = 25$ では相対誤差が $3 \times 10^{13}$ になる。
丸め誤差に含まれる優越解 $y_n$ の成分が増幅されるためで、`spherical_jn` が $n > x$ で Miller の後退漸化式を使うのはこのためである。
Wronskian の残差と Riccati–Bessel 関数との相対差は、既定の入力ではどの次数でも $10^{-15}$ 程度である。
$x = 5$ のまま $N = 40$ にすると、$j_n$ が $10^{-27}$ 程度以下になる $n = 35, 40$ で、Wronskian の残差と Riccati–Bessel 関数との相対差が $10^{-14}$ 程度（最大 $5 \times 10^{-14}$）に増える。
極小解を後退漸化式で求めた値の相対誤差は、この程度まで増えることがあり、その推定誤差は経験的なものである。

## まとめ

球 Bessel 関数は半整数次の円柱 Bessel 関数で、閉形式の $f_0$、$f_1$ から、極小解の $j_n$（$n > x$）と $i_n$ には Miller の後退漸化式、$y_n$ と $k_n$ には前進の漸化式を使って求める。
$k_n$ は $\sqrt{\pi/(2z)}\,K_{n+1/2}$、`riccati_yn` は $x\,y_n$ という規約なので、他の文献や実装と比べるときは $k_0$ と $x\,y_0 = -\cos x$ で正規化と符号を確かめる。
大きな $\lvert z\rvert$ で指数的に変わる $i_n$、$k_n$、$h_n^{(1,2)}$ は尺度化形で比べる。
これらの族には一様な ULP の仕様がないので、オプション付き形式の推定誤差と、Wronskian のような恒等式で精度を確かめ、Miller の方法による推定誤差は経験的なものとして解釈する。
部分波展開の角度部分は [Legendre 関数](../legendre-functions-and-spherical-harmonics/) と [球面調和関数](../spherical-harmonics/) で、Coulomb ポテンシャルのある散乱の動径関数は [Coulomb 波動関数と水素様動径状態](../coulomb-and-hydrogenic/) で確かめる。
