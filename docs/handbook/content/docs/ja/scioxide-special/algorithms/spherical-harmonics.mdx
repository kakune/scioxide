重力場や地磁気の球面調和解析、量子力学の軌道角運動量の固有状態、球面上の関数の展開には、単位球面上で正規直交な球面調和関数 $Y_l^m$ を使う。
$Y_l^m$ は Legendre 陪関数 $P_l^m$ に規格化因子 $\sqrt{(l - m)!/(l + m)!}$ を掛けた形なので、陪関数を求めてから因子を掛けると、高い次数で途中の値が binary64 の範囲を外れる。
このページは複素数と実数の球面調和関数の定義と位相の規約、加法定理、規格化因子を含めた漸化式による評価、推定誤差のモデルと呼び出しの形を説明する。
Legendre 陪関数 $P_l^m$ の定義と Condon–Shortley の位相は [Legendre 関数](oxref:special-legendre-associated) が扱う。

## 定義と位相の規約

極角 $\theta \in [0, \pi]$ と方位角 $\phi$（ともにラジアン）に対し、`spherical_harmonic(l, m, theta, phi)` は単位球面上で正規直交な複素数の球面調和関数

$$
Y_l^m(\theta, \phi) = \sqrt{\frac{2l + 1}{4\pi}\frac{(l - m)!}{(l + m)!}}\, P_l^m(\cos\theta)\, e^{im\phi} \quad (0 \le m \le l), \qquad
Y_l^{-m} = (-1)^m \overline{Y_l^m}
$$

を返す（DLMF §14.30）。
$P_l^m$ は Condon–Shortley の位相 $(-1)^m$ を含む Ferrers 関数（`legendre_p_assoc` と同じ規約）なので、$Y_1^1 = -\sqrt{3/(8\pi)}\sin\theta\, e^{i\phi}$ である。
戻り値の型は `Complex<S>` である。
`spherical_harmonic_real(l, m, theta, phi)` は実数の（tesseral）球面調和関数

$$
Y_{lm} = \begin{cases}
\sqrt{2}\,(-1)^m \operatorname{Re} Y_l^m & (m > 0) \\
Y_l^0 & (m = 0) \\
\sqrt{2}\,(-1)^{|m|} \operatorname{Im} Y_l^{|m|} & (m < 0)
\end{cases}
$$

を返し、因子 $(-1)^m$ が Condon–Shortley の位相を打ち消す。
実数形も単位球面上で正規直交である。

球面調和関数は二つの方向 $\Omega_1$、$\Omega_2$ のなす角 $\gamma$ について加法定理

$$
\sum_{m=-l}^{l} Y_l^m(\Omega_1)\,\overline{Y_l^m(\Omega_2)} = \sum_{m=-l}^{l} Y_{lm}(\Omega_1) Y_{lm}(\Omega_2) = \frac{2l + 1}{4\pi} P_l(\cos\gamma)
$$

を満たし、$\Omega_1 = \Omega_2$ では Unsöld の定理 $\sum_m |Y_l^m|^2 = (2l + 1)/(4\pi)$ になる。
$\cos\gamma = \cos\theta_1\cos\theta_2 + \sin\theta_1\sin\theta_2\cos(\phi_1 - \phi_2)$ である。

$|m| > l$ は `InvalidInput`（`OutOfRange`）、$\theta < 0$ か $\theta > \pi$ は `DomainError`（`OutsideDomain`）、有限でない角は `NonFinite` で、$\phi$ は有限の実数ならすべて受け付ける。

## 正規化した漸化式による評価

`spherical_harmonic` は、$P_l^m$ そのものではなく、規格化因子を含めた $\bar P_l^m(\theta) = \sqrt{\frac{2l+1}{4\pi}\frac{(l-m)!}{(l+m)!}}P_l^m(\cos\theta)$ を漸化式で求める。
$\bar P_0^0 = 1/\sqrt{4\pi}$ から $\bar P_k^k = -\sin\theta\sqrt{(2k + 1)/(2k)}\,\bar P_{k-1}^{k-1}$ で対角を進め、$\bar P_{m+1}^m = \sqrt{2m + 3}\cos\theta\,\bar P_m^m$ のあと

$$
\bar P_k^m = a_k \cos\theta\, \bar P_{k-1}^m - b_k \bar P_{k-2}^m, \qquad
a_k = \sqrt{\frac{4k^2 - 1}{k^2 - m^2}}, \quad
b_k = \sqrt{\frac{(2k + 1)\bigl((k - 1)^2 - m^2\bigr)}{(2k - 3)(k^2 - m^2)}}
$$

で次数を上げる。
正規化した値の大きさは高々 $\sqrt{(2l + 1)/(4\pi)}$ なので、$(l + m)!/(l - m)!$ の桁あふれが起こらない。
極の近くで $\sin^m\theta$ が binary64 の範囲を下回ることは、値を仮数と 2 の冪の指数に分けて持つ尺度化で扱う。
$\sin\theta$ は $\cos\theta$ から作らず別に渡すので、極の近くでも正確である。
$e^{im\phi}$ は $e^{i\phi}$ の繰り返し二乗で作り、積 $m\phi$ の丸めを避ける。
計算量はおよそ $l + \log_2|m|$ 単位で、上限は `LegendreOptions` で決める。
オプション付き形式の推定誤差は正規化した漸化式の丸めのモデル $32\varepsilon(1 + l + |m|)^2$ を項の大きさに掛けたもので、包含区間ではない。

## 精度の保証

`spherical_harmonic` と `spherical_harmonic_real` には一様な ULP の仕様はない。
照合データ（独立に生成した参照値）は binary64 と binary32 の両方で値と推定誤差を確かめている。
オプション付き形式の推定誤差は上の丸めのモデルで、包含区間ではない。
高い次数で精度を確かめるには、下の実験のように加法定理や Unsöld の定理の残差を見る。

## 関数と呼び出しの形

二つの関数は実数の型 `S`（`f32`、`f64`）の角を受け取り、複素数形は `Complex<S>`、実数形は `S` を返す。

| 関数 | 引数 | オプション付き形式 | スコープ付き API | オプション |
|---|---|---|---|---|
| `spherical_harmonic` | `degree: usize`, `order: i32`, `theta: S`, `phi: S` | `spherical_harmonic_with_options` | `spherical_harmonic_scoped` | `LegendreOptions` |
| `spherical_harmonic_real` | `degree: usize`, `order: i32`, `theta: S`, `phi: S` | `spherical_harmonic_real_with_options` | `spherical_harmonic_real_scoped` | `LegendreOptions` |

オプション付き形式 `*_with_options(.., options)` は `SpecialFunctionResult` を返し、推定誤差、終了状態、計算量の計数、アルゴリズムの識別子を持つ。
極の近くの高い位数で値が binary64 の範囲を下回ると、標準形式は 0 を返し、オプション付き形式は尺度化形と対数形に値を残す（$l = m = 1000$、$\theta = 10^{-3}$ で $Y_l^m \approx 1.96 \times 2^{-9966}$）。
スコープ付き API `*_scoped(.., options, scope)` は、オプション付き形式と同じ結果を求解スコープの中で返す。
`LegendreOptions` は作業量の上限（`Budget`）だけを持ち、既定は 65536 単位で、精度は変わらない。
上限が足りないと値は返らず `ConvergenceFailure`（`IterationLimit`）になる。
すべての $m$ の $Y_l^m$ をまとめて返す関数はないので、展開の係数を求めるときは $m = -l, \dots, l$ について関数を呼ぶ。

## 球面調和関数の加法定理

次のセルは、次数 $l$ と二つの方向 $\Omega_1 = (\theta_1, 0.3)$、$\Omega_2 = (\theta_2, 0.3 + \Delta\phi)$ を選び、$2l + 1$ 個の位数の和で加法定理と Unsöld の定理を確かめる。
右辺の $P_l(\cos\gamma)$ は `legendre_p` で求め、`spherical_harmonic` の正規化した漸化式とは別の経路である。
複素数形と実数形の和はどちらも同じ右辺に一致し、複素数形の和の虚部は 0 になるはずである。
最後の行は $Y_1^1$ の実部を Condon–Shortley の位相を含む閉じた形と比べる。

```rust
//| id: special-spherical-harmonics-addition-theorem
//| ref: special-spherical-harmonics-addition-theorem
//| title: 球面調和関数の加法定理と位相の規約を確かめる
//| run: reactive
//| crates: [scioxide-special, scioxide-core]
//| inputs:
//|   degree: {"type":"range","label":"次数 l","description":"和を取る位数は m = −l, …, l の 2l + 1 個。","min":0,"max":200,"step":1,"value":3}
//|   theta_deg: {"type":"range","label":"方向 1 の極角 θ₁ [deg]","min":0,"max":180,"step":5,"value":50}
//|   second_theta_deg: {"type":"range","label":"方向 2 の極角 θ₂ [deg]","min":0,"max":180,"step":5,"value":120}
//|   azimuth_gap_deg: {"type":"range","label":"方位角の差 φ₂ − φ₁ [deg]","min":0,"max":360,"step":5,"value":75}
//| cases:
//|   - {"id":"high-degree","label":"l = 200","description":"401 項の和でも加法定理が丸めの程度で成り立つ。","inputs":{"degree":200}}
//|   - {"id":"pole","label":"θ₁ = 0","description":"極では m ≠ 0 の項が 0 になる。","inputs":{"theta_deg":0}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"addition","path":"/rows/0/3","range":{"min":-1e-15,"max":1e-15}}
//|       - {"artifact":"addition","path":"/rows/1/1","approx":{"value":0.12040426179377522,"rtol":1e-14}}
//|       - {"artifact":"addition","path":"/rows/1/3","range":{"min":-1e-15,"max":1e-15}}
//|       - {"artifact":"addition","path":"/rows/2/3","range":{"min":-1e-15,"max":1e-15}}
//|       - {"artifact":"addition","path":"/rows/3/3","range":{"min":-1e-15,"max":1e-15}}
//|       - {"artifact":"addition","path":"/rows/4/3","range":{"min":-1e-15,"max":1e-15}}
//|   - case: high-degree
//|     expect:
//|       - {"artifact":"addition","path":"/rows/0/3","range":{"min":-1e-12,"max":1e-12}}
//|       - {"artifact":"addition","path":"/rows/1/3","range":{"min":-1e-13,"max":1e-13}}
//|   - case: pole
//|     expect:
//|       - {"artifact":"addition","path":"/rows/1/3","range":{"min":-1e-15,"max":1e-15}}
use scioxide_core::Complex;
use scioxide_special::{legendre_p, spherical_harmonic, spherical_harmonic_real};
use std::f64::consts::PI;

let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let digits16 = serde_json::json!({ "significantDigits": 16 });
let l = degree as usize;
let (theta1, theta2) = (theta_deg.to_radians(), second_theta_deg.to_radians());
let phi1 = 0.3_f64;
let phi2 = phi1 + azimuth_gap_deg.to_radians();
// 2 方向のなす角 γ（球面三角法の余弦定理。f64 の固有メソッドで計算する参照値）。
let cos_gamma = theta1.cos() * theta2.cos() + theta1.sin() * theta2.sin() * (phi2 - phi1).cos();
let mut unsold = 0.0_f64;
let mut complex_sum = Complex::new(0.0_f64, 0.0);
let mut real_sum = 0.0_f64;
for m in -(degree as i32)..=(degree as i32) {
    let first = spherical_harmonic(l, m, theta1, phi1).map_err(|e| e.to_string())?;
    let second = spherical_harmonic(l, m, theta2, phi2).map_err(|e| e.to_string())?;
    unsold += first.norm_sqr();
    complex_sum += first * second.conj();
    let real_first = spherical_harmonic_real(l, m, theta1, phi1).map_err(|e| e.to_string())?;
    let real_second = spherical_harmonic_real(l, m, theta2, phi2).map_err(|e| e.to_string())?;
    real_sum += real_first * real_second;
}
let weight = (2.0 * l as f64 + 1.0) / (4.0 * PI);
let addition = weight * legendre_p(l, cos_gamma.clamp(-1.0, 1.0)).map_err(|e| e.to_string())?;
// Condon–Shortley の位相：Y_1^1 = −√(3/(8π)) sin θ e^{iφ}。
let y11 = spherical_harmonic(1, 1, theta1, phi1).map_err(|e| e.to_string())?;
let y11_exact = -(3.0 / (8.0 * PI)).sqrt() * theta1.sin() * phi1.cos();
let rows = vec![
    ("Σ |Y_l^m(Ω₁)|²", unsold, weight),
    ("Re Σ Y_l^m(Ω₁) Y_l^m(Ω₂)*", complex_sum.re, addition),
    ("Im Σ Y_l^m(Ω₁) Y_l^m(Ω₂)*", complex_sum.im, 0.0),
    ("Σ Y_lm(Ω₁) Y_lm(Ω₂)（実数形）", real_sum, addition),
    ("Re Y_1^1(Ω₁)", y11.re, y11_exact),
];
let rows: Vec<_> = rows
    .into_iter()
    .map(|(name, value, reference)| (name, value, reference, value - reference))
    .collect();
let columns = serde_json::json!([
    { "key": "0", "label": "量" },
    { "key": "1", "label": "SciOxide の値", "type": "number", "format": digits16 },
    { "key": "2", "label": "参照", "type": "number", "format": digits16 },
    { "key": "3", "label": "差", "type": "number", "format": sci3 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "addition" })
);
```
既定の $l = 3$ では、$\sum_m |Y_3^m|^2 = 0.5570423008216336$ が $7/(4\pi)$ と、加法定理の和 $0.1204042617937752$ が $\frac{7}{4\pi}P_3(\cos\gamma)$ と $10^{-16}$ の程度で一致する。
$l = 200$ でも 401 個の項の和の相対差は Unsöld の定理で $1.3 \times 10^{-15}$、加法定理で $4.6 \times 10^{-15}$ で、正規化した漸化式が高い次数でも規格化を保っている。
$\theta_1 = 0$ や $180^\circ$ では極で $m \ne 0$ の項が 0 になり、和は $m = 0$ の項だけで決まる。

## まとめと次に読むページ

`spherical_harmonic` は Condon–Shortley の位相を含む複素数の $Y_l^m$ を、`spherical_harmonic_real` はその位相を打ち消した実数形 $Y_{lm}$ を返し、どちらも単位球面上で正規直交である。
極角 $\theta$ は $[0, \pi]$ のラジアン、方位角 $\phi$ は有限の実数で、$|m| > l$ は `InvalidInput`（`OutOfRange`）になる。
規格化因子を含めた漸化式で求めるので、次数が高くても途中で桁あふれせず、計算量は $l + \log_2|m|$ 程度である。
一様な ULP の仕様はないので、オプション付き形式の推定誤差と、加法定理や Unsöld の定理の残差で精度を確かめる。
陪関数そのものの値と規約は [Legendre 関数](../legendre-functions-and-spherical-harmonics/) で、三つの球面調和関数の積の積分（Gaunt 係数）は [角運動量結合係数と Wigner 記号](../angular-momentum-coupling/) で、各項目の仕様は [Legendre・角運動量・スペクトル関数の API](../../api/legendre-angular-spectral/) で確かめる。
