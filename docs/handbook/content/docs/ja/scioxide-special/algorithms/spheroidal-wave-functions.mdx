回転楕円体の座標で 3 次元の Helmholtz 方程式 $\nabla^2 u + k^2 u = 0$ を分離すると、角度と動径の因子がどちらも回転楕円体波動方程式を満たす。
回転楕円体による音波や電磁波の散乱、回転楕円体の空洞の固有振動、2 原子分子の 1 電子状態がこの方程式で書ける。
`scioxide-special` は、角関数を正規化 Ferrers 関数で展開し、その係数の対称三重対角固有値問題を打ち切って解いて、係数を保持する Plan `SpheroidalPlan` を作る。
固有値問題の打ち切りの決め方は Mathieu 関数と共通なので、[Mathieu 関数とスペクトル法](../mathieu-and-spheroidal/)を先に読むと流れを追いやすい。
このページは、方程式と規約、Ferrers 関数による展開、角関数と動径関数の評価法、精度の保証、API の順に説明する。

## 回転楕円体波動方程式と規約

回転楕円体の座標で変数を分離すると、角度と動径の因子はどちらも

$$
(1 - x^2)\,w'' - 2x\,w' + \left(\lambda_{mn} - s\,c^2x^2 - \frac{m^2}{1 - x^2}\right) w = 0
$$

を満たす（Flammer 1957 の規約）。
$m \ge 0$ は方位の次数、$n \ge m$ は次数、$c$ は焦点間の半距離と波数の積である実の大きさのパラメータ、$\lambda_{mn}$ は特性値である。
$s = +1$ が扁長（`SpheroidalKind::Prolate`、葉巻形）、$s = -1$ が扁平（`SpheroidalKind::Oblate`、円盤形）を表す。
DLMF 30.2.1 の記法とは $\gamma^2 = s\,c^2$、$\lambda_{mn} = \lambda_n^m(\gamma^2) + \gamma^2$ の関係にある。

角関数 $S_{mn}(c, x)$ は $[-1, 1]$ で有界な解である。
$c = 0$ では方程式が Legendre の陪微分方程式になり、$S_{mn}$ は Ferrers 関数 $P_n^m(x)$（Condon–Shortley の位相を含む）、特性値は $\lambda_{mn}(0) = n(n+1)$ になる。
動径関数 $R_{mn}^{(j)}(c, x)$ は同じ方程式の解で、物理的な範囲は扁長で $x \ge 1$、扁平で $x \ge 0$ である。
$j = 1, 2, 3, 4$ は第 1 種から第 4 種を表し、`RadialKind` の `First`、`Second`、`Third`、`Fourth` がこれを選ぶ。

`SpectralNormalization::Standard` は Ferrers 関数と同じ $\int_{-1}^1 S_{mn}^2\,dx = 2(n+m)!/((2n+1)(n-m)!)$、`UnitL2` は $[-1, 1]$ で $L^2$ ノルムが 1 の規格化を選ぶ。
符号は $c \to 0$ で $P_n^m$ に連続につながるように選ぶ。
動径関数の規格化は次の節の展開で決まり、角関数の規格化をどう選んでも変わらない。

## Ferrers 関数による展開と固有値問題

角関数は Ferrers 関数で展開する。
$p = (n - m) \bmod 2$ とし、$\bar P_l^m$ を $[-1, 1]$ で $L^2$ ノルムが 1 の Ferrers 関数として

$$
S_{mn}(c, x) \propto \sum_{k\ge0} d_k\,\bar P_{m+2k+p}^m(x)
$$

と置く。
$x^2 \bar P_l^m$ は $\bar P_{l-2}^m$、$\bar P_l^m$、$\bar P_{l+2}^m$ の和で書けるので、方程式に代入すると係数 $d_k$ は三項漸化式を満たす。
$(x^2)_{ll}$、$(x^2)_{l,l+2}$ を正規化 Ferrers 関数での $x^2$ の行列要素とすると、$\boldsymbol d$ は対角 $l(l+1) + \gamma^2 (x^2)_{ll}$、副対角 $\gamma^2 (x^2)_{l,l+2}$（$l = m + 2k + p$）の対称三重対角行列の固有ベクトルで、固有値が $\lambda_{mn}$ である（DLMF §30.8）。
$\lambda_{mn}$ は、この行列の固有値を小さいほうから数えて $\kappa = \lfloor (n - m)/2 \rfloor$ 番目（0 から数える）の固有値である。

固有値の求め方、係数の組み直し、打ち切りの倍加と受け入れ条件、`SpectralOptions` と `SpectralDiagnostics` の読み方は Mathieu 関数と共通で、[係数の求め方](oxref:special-mathieu-coefficients)と[打ち切りの倍加と受け入れ条件](oxref:special-mathieu-truncation)で説明している。
係数は対角の $l(l+1)$ が $c^2$ を超える所から減り始めるので、$c$ が大きいほど遠くまで広がり、必要な行数はおよそ $c$ に比例して増える。
$c = 0$ では行列が対角なので固有値問題を解かず、$\lambda_{mn} = n(n+1)$ と単位ベクトルの係数を返す。
準備は固有値問題のほかに、評価で使う Legendre の漸化の係数 $2N$ 組と、動径関数の展開を規格化する定数を求める。
準備の演算量は $O(N + m)$、メモリ使用量は $O(N)$ で、$N \le 256$ は受け入れた係数の数である。

$c$ の小さい極限では、1 次の摂動で

$$
\lambda_{mn}(c) = n(n+1) + s\,c^2\,\frac{2n(n+1) - 2m^2 - 1}{(2n-1)(2n+3)} + O(c^4)
$$

となる。
右辺の分数は正規化 Ferrers 関数での $x^2$ の期待値 $(x^2)_{nn}$ で、DLMF 30.3.8 を $\lambda_{mn} = \lambda_n^m + \gamma^2$ に書き直したものと同じである。
$c^4$ の項は $\gamma^4 = c^4$ に比例するので、同じ $(m, n)$ なら扁長と扁平で係数が等しく、符号が分かれるのは $c^2$ と $c^6$ の項である。

## 角関数の評価

`SpheroidalPlan::angular(x)` は、準備で保存した Legendre の漸化の係数で $\bar P_l^m(x)/(1 - x^2)^{m/2}$ を上向きの漸化で作りながら展開を足し、最後に $(1 - x^2)^{m/2}$ と規格化の定数を掛けて、値と $x$ による導関数を返す。
Ferrers 関数を次数の上向きに作る漸化は、$[-1, 1]$ で安定である。
計算量は係数 1 個と次数の 1 段につき 1 単位である。
`SpheroidalPlan::coefficient(k)` は正規化 Ferrers 関数での係数 $d_k$ を Euclid ノルム 1 で返し、規格化の定数は評価のときに掛ける。

実数の $x$ は $[-1, 1]$ に限り、外れると `DomainError`（`OutsideDomain`）になる。
複素数の $x$ では因子 $(1 - x^2)^{m/2}$ に主値の平方根を使った解析接続を返す。
このとき Ferrers 関数は $x$ を通る Bernstein の楕円（焦点 $\pm1$）の大きさ $\rho = \max|x \pm \sqrt{x^2 - 1}|$ に応じて $\rho^l$ のように増えるので、省いた係数の比に $\rho^2$ を掛けて寄与を見積もる。
その積が 1 に達すると展開が収束しないので、`NumericalInstability`（`LossOfSignificance`）を返す。
$x = \pm1$ では値は有限だが、$m = 1$ では導関数が発散するので、値だけを返して導関数を省く。

次のセルは、扁長か扁平か、$m$、$n$、$c$ を選び、角関数 $S_{mn}(c, x)$ を $[-1, 1]$ で描いて、$c = 0$ の極限 $P_n^m(x)$ を破線で重ねる。
破線は `legendre_p_assoc` で求めた Ferrers 関数で、回転楕円体の Plan とは別の実装である。
表は、Clenshaw–Curtis 則（Chebyshev 点での補間型の求積で、なめらかな関数では指数的に収束する）で求めた $\int_{-1}^1 S_{mn}^2\,dx$ と規格化の値 $2(n+m)!/((2n+1)(n-m)!)$ の相対差、$c = 0$ の Plan と `legendre_p_assoc` の差を示す。
被積分関数 $S_{mn}^2$ は $(1 - x^2)^m$ と多項式の級数の積で端点でもなめらかなので、128 区間の Clenshaw–Curtis 則で丸めの水準まで求まる。

```rust
//| id: special-spheroidal-angular-normalization
//| ref: special-spheroidal-angular-normalization
//| title: 回転楕円体の角関数の規格化と Ferrers 関数の極限
//| run: reactive
//| crates: [scioxide-special]
//| inputs:
//|   kind: {"type":"select","label":"回転楕円体","options":["扁長","扁平"],"value":"扁長"}
//|   m: {"type":"integer","label":"次数 m","min":0,"max":4,"value":1}
//|   degree_offset: {"type":"integer","label":"n − m","min":0,"max":6,"value":2}
//|   c: {"type":"range","label":"大きさのパラメータ c","min":0,"max":10,"step":0.5,"value":4}
//| cases:
//|   - {"id":"oblate","label":"扁平、c = 4","description":"扁平では零点と山が両端 x = ±1 の側へ動く。","inputs":{"kind":"扁平"}}
//|   - {"id":"sphere","label":"c = 0","description":"角関数は Ferrers 関数そのものになる。","inputs":{"c":0}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"angular","path":"/rows/0/3","range":{"max":1e-13}}
//|       - {"artifact":"angular","path":"/rows/1/3","range":{"max":1e-14}}
//|   - case: oblate
//|     expect:
//|       - {"artifact":"angular","path":"/rows/0/3","range":{"max":1e-13}}
//|   - case: sphere
//|     expect:
//|       - {"artifact":"angular","path":"/rows/0/3","range":{"max":1e-13}}
//|       - {"artifact":"angular","path":"/rows/1/1","approx":{"value":0.7869998411689801,"rtol":1e-13}}
use scioxide_special::{
    SpectralNormalization, SpectralOptions, SpheroidalKind, SpheroidalPlan, legendre_p_assoc,
};
use std::f64::consts::PI;

let spheroid = match kind.as_str() {
    "扁平" => SpheroidalKind::Oblate,
    _ => SpheroidalKind::Prolate,
};
let (m, n) = (m as u32, (m + degree_offset) as u32);
let prepare = |size: f64| {
    let normalization = SpectralNormalization::Standard;
    SpheroidalPlan::new(
        spheroid,
        m,
        n,
        size,
        normalization,
        SpectralOptions::default(),
    )
    .map_err(|e| e.to_string())
};
let plan = prepare(c)?;
let angular = |x: f64| {
    plan.angular(x)
        .and_then(|r| r.try_value())
        .map_err(|e| e.to_string())
};
// Ferrers 関数 Pₙᵐ（c = 0 の極限、別の実装）
let ferrers = |x: f64| legendre_p_assoc(n as usize, m as i32, x).map_err(|e| e.to_string());
let mut curve = Vec::new();
let mut limit = Vec::new();
for i in 0..=100 {
    let x = -1.0 + 2.0 * f64::from(i) / 100.0;
    curve.push([x, angular(x)?]);
    limit.push([x, ferrers(x)?]);
}
// Clenshaw–Curtis 則（N = 128）で ∫₋₁¹ S² dx を求める（独立な求積）
let points = 128;
let mut integral = 0.0;
for j in 0..=points {
    let theta = PI * j as f64 / points as f64;
    let mut weight = 1.0;
    for k in 1..=points / 2 {
        let b = if 2 * k == points { 1.0 } else { 2.0 };
        weight -= b * (2.0 * k as f64 * theta).cos() / (4.0 * (k * k) as f64 - 1.0);
    }
    let end = if j == 0 || j == points { 1.0 } else { 2.0 };
    integral += end / points as f64 * weight * angular(theta.cos())?.powi(2);
}
// 規格化の値 2(n+m)!/((2n+1)(n−m)!)
let mut norm = 2.0 / (2.0 * f64::from(n) + 1.0);
for factor in (n - m + 1)..=(n + m) {
    norm *= f64::from(factor);
}
let x0 = 0.3;
let sphere = prepare(0.0)?;
let s0 = sphere
    .angular(x0)
    .and_then(|r| r.try_value())
    .map_err(|e| e.to_string())?;
let p0 = ferrers(x0)?;
let rows = vec![
    ("∫₋₁¹ S² dx", integral, norm, (integral - norm).abs() / norm),
    ("c = 0 の S(0.3)", s0, p0, (s0 - p0).abs()),
];
emit_line_chart!(
    &vec![
        serde_json::json!({ "name": "Sₘₙ(c, x)", "points": curve }),
        serde_json::json!({ "name": "Pₙᵐ(x)（c = 0）", "points": limit, "style": { "lineType": "dashed" } })
    ],
    options = &serde_json::json!({ "xLabel": "角度座標 x [-]", "yLabel": "角関数 [-]" })
);
let fixed12 = serde_json::json!({ "fractionDigits": 12 });
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let columns = serde_json::json!([
    { "key": "0", "label": "検算" },
    { "key": "1", "label": "Plan の値", "type": "number", "format": fixed12 },
    { "key": "2", "label": "参照値", "type": "number", "format": fixed12 },
    { "key": "3", "label": "差（1 行目は相対）", "type": "number", "format": sci3 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "angular" })
);
```

既定の扁長、$m = 1$、$n = 3$、$c = 4$ では、$\int_{-1}^1 S_{13}^2\,dx = 3.428571428571424$ が規格化の値 $24/7$ と相対 $1.3 \times 10^{-15}$ で一致する。
グラフでは、零点が $P_3^1$ の $\pm0.447$ から $\pm0.35$ の付近へ、両側の山が $\pm0.86$ から $\pm0.78$ へ原点の側に寄り、$x = 0$ の値は 1.5 から 1.39 に下がる。
方程式を $-((1 - x^2)w')' + (m^2/(1 - x^2) + s\,c^2x^2)\,w = \lambda_{mn}w$ と書くと、扁長の項 $+c^2x^2$ は $|x|$ の大きい所で大きくなる位置エネルギーのように働くので、関数は $x = 0$ の側へ押し込まれる。
扁平では項が $-c^2x^2$ になって向きが逆になり、零点が $\pm0.61$ の付近へ、両側の山が $\pm0.92$ へ外側に動いて、関数は両端 $x = \pm1$ の側へ広がる。
$c = 0$ では曲線が破線の $P_3^1$ に重なり、$x = 0.3$ での差は $1.1 \times 10^{-16}$ である。
規格化の積分は、$m = 0$ から 4、$n - m = 0$ から 6、$c = 10$ まで、どの組でも相対 $1.3 \times 10^{-15}$ 以下にとどまる。

## 動径関数の評価

`SpheroidalPlan::radial(x, kind)` は、角関数と同じ係数 $d_k$ を使った、Ferrers 関数と球 Bessel 関数の積の展開（DLMF §30.11）で動径関数を求める。
角度座標の一点 $\eta$ を選び、$r = \sqrt{x^2 - s(1 - \eta^2)}$、$w = \eta x/r$ と置くと

$$
R_{mn}^{(j)}(c, x) = \frac{1}{\tilde S(\eta)}\left(\frac{x^2 - s}{r^2}\right)^{m/2}\sum_{k\ge0} (-1)^{k-\kappa}\,d_k\,\tilde P_{m+2k+p}(w)\,z_{m+2k+p}^{(j)}(c\,r)
$$

である。
$\tilde P_l = \bar P_l^m/(1 - x^2)^{m/2}$ は Ferrers 関数から端点の因子を除いた多項式、$\tilde S(\eta) = \sum_k d_k\,\tilde P_{m+2k+p}(\eta)$ は同じ因子を除いた角関数の値で、$\kappa = \lfloor (n - m)/2 \rfloor$ である。
$z^{(1)} = j_l$、$z^{(2)} = y_l$、$z^{(3)} = h_l^{(1)}$、$z^{(4)} = h_l^{(2)}$ は球 Bessel 関数で、第 3 種と第 4 種は第 1 種 $\pm i \cdot$ 第 2 種になり、外向き・内向きの波を表す。
$x \to \infty$ では $r \to x$、$w \to \eta$ となって和が $\tilde S(\eta)$ で割り切れ、$R_{mn}^{(1)} \sim \cos(cx - (n+1)\pi/2)/(cx)$ になる。
この漸近形が動径関数の規格化を決めるので、$\eta$ の選び方と角関数の規格化には左右されない。
$n - m$ が奇数で $\eta = 0$ を選ぶと $\tilde S(0) = 0$ になるので、そのときは両辺を $\eta$ で微分した形を使う。

$\eta$ は準備のときに $0, 0.25, 0.5, 0.75, 0.9, 1$ のうち、$\tilde S(\eta)$ の推定誤差と値の比が最も小さいものを選び、`SpheroidalPlan::radial_normalization_point` で読める。
第 1 種で $|r| \le 0.2$ になる点では、展開の収束を保つために $\eta$ を 0 か 1 に選び直す。
第 2〜4 種類の展開は次数とともに増える $y_l$ を含み、省いた項の比を $1/|r|^2$ で見積もるので、$|r| \le 1$ では使えない。
そこで第 2〜4 種類は、$|r| < 1.5$ のとき（扁平では $\operatorname{Re} x < 0$ のときも）、$x = 3$ の値から出発し、動径方程式を Taylor 級数で積分して目標の点まで接続する。
接続の経路は焦点 $x = \pm1$（扁長）、$x = \pm i$（扁平）を避け、刻みは焦点までの距離の 0.2 倍以下にとる。
第 2〜4 種類は焦点で発散するので、そこでは `DomainError`（`Pole`）を返す。
$c = 0$ では第 1 種が $n = 0$ で 1、それ以外で 0 になり、第 2〜4 種類は `DomainError`（`Pole`）である。

第 1 種と第 2 種の Wronskian は

$$
R_{mn}^{(1)}\,\frac{dR_{mn}^{(2)}}{dx} - \frac{dR_{mn}^{(1)}}{dx}\,R_{mn}^{(2)} = \frac{1}{c\,(x^2 - s)}
$$

である（扁長で $1/(c(x^2-1))$、扁平で $1/(c(x^2+1))$）。
二つの種類は別々の Bessel 関数の級数か、Taylor 級数による接続で求まるので、この関係で展開と接続をどちらも確かめられる。

### 特性値の球極限と Wronskian の検算

次のセルは、扁長か扁平か、$m$、$n$、$c$ を選び、$c$ を半分ずつ小さくしながら特性値を求めて、上の 1 次の摂動との差を $c^4$ で割った値を示す。
この値が一定に近づけば、差が $O(c^4)$ で減っていることになる。
二つ目の表は、選んだ $c$ で、扁長では $x = 1.5$、扁平では $x = 0.5$ の動径関数の Wronskian を理論値と比べる。

```rust
//| id: special-spheroidal-sphere-limit
//| ref: special-spheroidal-sphere-limit
//| title: 回転楕円体の特性値の球極限と動径関数の Wronskian
//| run: reactive
//| crates: [scioxide-special]
//| inputs:
//|   kind: {"type":"select","label":"回転楕円体","options":["扁長","扁平"],"value":"扁長"}
//|   m: {"type":"integer","label":"次数 m","min":0,"max":4,"value":1}
//|   degree_offset: {"type":"integer","label":"n − m","min":0,"max":6,"value":1}
//|   c: {"type":"range","label":"大きさのパラメータ c","min":0.1,"max":8,"step":0.1,"value":2}
//| cases:
//|   - {"id":"oblate","label":"扁平、m = 0、n = 0","description":"1 次の項の符号が逆になる。","inputs":{"kind":"扁平","m":0,"degree_offset":0}}
//|   - {"id":"prolate-ground","label":"扁長、m = 0、n = 0","description":"c⁴ の係数が扁平と同じになる。","inputs":{"m":0,"degree_offset":0}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"limit","path":"/rows/0/1","approx":{"value":7.653149562003568,"rtol":1e-11}}
//|       - {"artifact":"limit","path":"/rows/4/3","approx":{"value":-0.003887,"rtol":1e-3}}
//|       - {"artifact":"wronskian","path":"/rows/0/4","range":{"max":1e-12}}
//|   - case: oblate
//|     expect:
//|       - {"artifact":"limit","path":"/rows/4/3","approx":{"value":-0.014822,"rtol":1e-3}}
//|       - {"artifact":"wronskian","path":"/rows/0/4","range":{"max":1e-12}}
//|   - case: prolate-ground
//|     expect:
//|       - {"artifact":"limit","path":"/rows/4/3","approx":{"value":-0.014822,"rtol":2e-3}}
//|       - {"artifact":"wronskian","path":"/rows/0/4","range":{"max":1e-12}}
use scioxide_special::{
    RadialKind, SpectralNormalization, SpectralOptions, SpheroidalKind, SpheroidalPlan,
};

let (spheroid, s, x) = match kind.as_str() {
    "扁平" => (SpheroidalKind::Oblate, -1.0, 0.5),
    _ => (SpheroidalKind::Prolate, 1.0, 1.5),
};
let (m, n) = (m as u32, (m + degree_offset) as u32);
let (mf, nf) = (f64::from(m), f64::from(n));
// 正規化 Ferrers 関数での x² の期待値（1 次の摂動の係数）
let moment =
    (2.0 * nf * (nf + 1.0) - 2.0 * mf * mf - 1.0) / ((2.0 * nf - 1.0) * (2.0 * nf + 3.0));
let prepare = |size: f64| {
    let normalization = SpectralNormalization::Standard;
    SpheroidalPlan::new(
        spheroid,
        m,
        n,
        size,
        normalization,
        SpectralOptions::default(),
    )
    .map_err(|e| e.to_string())
};
// 選んだ c の Plan は Wronskian の検算でも使う
let plan = prepare(c)?;
let mut rows = Vec::new();
for step in 0..5 {
    let size = c * 0.5_f64.powi(step);
    let lambda = if step == 0 {
        plan.characteristic_value()
    } else {
        prepare(size)?.characteristic_value()
    }
    .map_err(|e| e.to_string())?;
    let first_order = nf * (nf + 1.0) + s * size * size * moment;
    let scaled_difference = (lambda - first_order) / size.powi(4);
    rows.push((size, lambda, first_order, scaled_difference));
}
// 選んだ c での動径関数の値と x による導関数
let radial = |kind| {
    plan.radial(x, kind)
        .and_then(|r| Ok((r.try_value()?, r.try_derivative()?)))
        .map_err(|e| e.to_string())
};
let (r1, d1) = radial(RadialKind::First)?;
let (r2, d2) = radial(RadialKind::Second)?;
let wronskian = (r1 * d2 - d1 * r2).re;
let expected = 1.0 / (c * (x * x - s));
let fixed10 = serde_json::json!({ "fractionDigits": 10 });
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let columns = serde_json::json!([
    { "key": "0", "label": "c [-]", "type": "number" },
    { "key": "1", "label": "特性値 λₘₙ", "type": "number", "format": fixed10 },
    { "key": "2", "label": "1 次の摂動", "type": "number", "format": fixed10 },
    { "key": "3", "label": "差 / c⁴", "type": "number", "format": sci3 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "limit" })
);
let columns = serde_json::json!([
    { "key": "0", "label": "動径座標 x [-]", "type": "number" },
    { "key": "1", "label": "R⁽¹⁾", "type": "number", "format": fixed10 },
    { "key": "2", "label": "R⁽²⁾", "type": "number", "format": fixed10 },
    { "key": "3", "label": "Wronskian", "type": "number", "format": fixed10 },
    { "key": "4", "label": "相対差", "type": "number", "format": sci3 },
    { "key": "5", "label": "係数の数 N", "type": "integer" },
    { "key": "6", "label": "規格化の点 η", "type": "number" }
]);
let relative = (wronskian - expected).abs() / expected.abs();
let terms = plan.diagnostics().terms() as u32;
let eta = plan.radial_normalization_point();
let row = (x, r1.re, r2.re, wronskian, relative, terms, eta);
emit_table_with_columns!(
    columns,
    vec![row],
    metadata = serde_json::json!({ "id": "wronskian" })
);
```

既定の扁長、$m = 1$、$n = 2$、$c = 2$ では、差を $c^4$ で割った値は $c = 2$ の $-0.00382$ から $c = 0.125$ の $-0.003887$ へ一定に近づく。
差が $c^4$ に比例して減っているので、1 次の摂動の係数 $3/7$ と Plan の特性値が整合している。
扁平の $m = n = 0$ では 1 次の項の符号が逆になり、$\lambda_{00}$ は負の側へ動く。
このときの $c^4$ の係数は $-0.01482$ で、扁長の $m = n = 0$ の $-0.01481$ と一致し、$\gamma^4 = c^4$ の項が $s$ によらないことと合う。
$c = 8$ では 1 次の摂動（33.4）が特性値（23.4）から大きく外れ、摂動の展開は使えないが、係数の数は 32 のままである。
動径関数の Wronskian は、扁長の $x = 1.5$ で理論値 $1/(2 \cdot 1.25) = 0.4$、扁平の $x = 0.5$ で $1/(2 \cdot 1.25) = 0.4$ と、相対差 $10^{-15}$ 程度で一致する。
どちらの点も積の展開の半径が $|r| < 1.5$ なので、第 2 種は $x = 3$ からの Taylor 級数による接続で求まり、この一致は接続の検算にもなる。
$m = 1$、$n = 7$ のように第 2 種の値が大きい（$R^{(2)} \approx -88$）組でも、相対差は $8 \times 10^{-15}$ にとどまる。
規格化の点 $\eta$ は組ごとに 0.25 から 0.9 の間で選ばれ、表の最後の列に出る。

## 精度の保証

回転楕円体波動関数には、関数全体で一様な ULP の仕様はない。
`SpectralOptions` の許容誤差は打ち切りの受け入れ条件を決めるもので、出力の精度を約束するものではない。
`SpectralDiagnostics` の残差と、各評価が返す推定誤差（`SpecialFunctionResult` の誤差）は計算の状態を表す推定で、包含区間ではない。
複素数の座標では、省いた係数の寄与と接続の誤差が増えることがある。

照合試験は独立に生成した参照値との差を次の幅で確かめている。
外部の点（扁長 $x > 1$、扁平 $x > 0$）では、特性値が参照値と $10^{-12}(1 + |\lambda|)$ 以内、第 1 種と第 2 種の値と導関数が $2 \times 10^{-9}(1 + |R|)$ 以内である。
独立な参照値とは、実数と複素数の座標で、角関数と第 1〜4 種類の動径関数の値と導関数が `f64` で $2 \times 10^{-9}(1 + |\text{参照値}|)$、`f32` で $2 \times 10^{-5}(1 + |\text{参照値}|)$ 以内である。
内部の点（扁長 $x = 1.1, 1.5$、扁平 $x = 0, 0.5$）では、Wronskian を相対 $10^{-8}$ の範囲で試験している。
`f32` の Plan も内部は `f64` で計算し、最後に `f32` へ丸める。

## API

| 項目 | 役割 |
|---|---|
| `SpheroidalPlan::new(kind, m, n, c, normalization, options)` | 特性値、Ferrers 係数、Legendre の漸化の係数、動径展開の規格化を準備する。`build(.., scope)` は同じ準備をスコープの中で行う |
| `SpheroidalPlan::characteristic_value`、`diagnostics` | $\lambda_{mn}$、打ち切りの診断 |
| `SpheroidalPlan::coefficient(k)`、`coefficient_count` | 正規化 Ferrers 関数での係数 $d_k$（尺度化した値）とその個数 |
| `SpheroidalPlan::radial_normalization_point` | 動径展開を規格化した角度座標 $\eta$ |
| `SpheroidalPlan::angular(x)`、`angular_scoped(x, scope)` | $S_{mn}$ と導関数の詳細な結果（実数・複素数の `x`） |
| `SpheroidalPlan::radial(x, kind)`、`radial_scoped(x, kind, scope)` | $R_{mn}^{(j)}$ と導関数の詳細な結果（複素数の値） |
| `SpheroidalPlan::kind`、`order`、`degree`、`parameter`、`normalization` | 準備に使った値 |
| `spheroidal_characteristic_value(kind, m, n, c)` | $\lambda_{mn}$ のワンショット関数 |
| `spheroidal_angular(kind, m, n, c, x)` | $S_{mn}(c, x)$ のワンショット関数（実数・複素数の `x`） |
| `spheroidal_radial(kind, m, n, c, x, radial_kind)` | $R_{mn}^{(j)}(c, x)$ のワンショット関数（複素数の値） |
| `SpheroidalKind` | `Prolate`（$s = +1$）と `Oblate`（$s = -1$） |

`RadialKind`、`SpectralNormalization`、`SpectralOptions`、`SpectralTerms`、`SpectralDiagnostics` は Mathieu 関数と共通で、[Mathieu 関数とスペクトル法の API](oxref:special-mathieu-api) にまとめている。

同じ $(m, n, c)$ で多くの点を評価するときや、推定誤差・導関数・終了状態が必要なときは Plan を作る。
Plan は不変で、作った後は何度評価しても係数を作り直さない。
ワンショット関数は、既定の `SpectralOptions` と `Standard` の規格化で Plan を内部に一つ作り、一度だけ評価して通常の値を返す。
準備と評価は一つの作業量の上限（2,097,152 単位）を共有し、結果は同じ引数の Plan の評価とビット単位で同じである。
ワンショット関数にはオプション付き形式 `*_with_options` とスコープ付き API `*_scoped` はなく、その用途には Plan の `build` と `*_scoped` のメソッドを使う。

エラーは次のとおりである。
$c$ が NaN または無限大なら `NonFinite`、$n < m$ や打ち切りの範囲に収まらない番号なら `InvalidInput`（`OutOfRange`）である。
ワンショット関数では、この範囲は $n - m \ge 496$（$c = 0$ では 512）になる。
$c^2$ や行列の要素が `f64` の範囲を外れたとき、動径展開の規格化の点がどれも解像できないとき、展開や接続が $x$ を解像できないときは `NumericalInstability`（`LossOfSignificance`）を返す。
ワンショット関数の値がスカラー型の範囲を超えると `NumericalInstability`（`Overflow`）、Plan の `characteristic_value` では `NumericalInstability`（`LossOfSignificance`）になる。

## まとめ

回転楕円体波動関数の特性値 $\lambda_{mn}$ と角関数は、正規化 Ferrers 関数による展開係数の対称三重対角固有値問題から求まり、打ち切りは Mathieu 関数と同じ倍加と受け入れ条件で決まる。
$c$ が大きいほど必要な係数が増えるので、`SpectralDiagnostics::terms` を見て、`TruncationLimit` が出たら `SpectralTerms` の最大を上げる。
動径関数は Ferrers 関数と球 Bessel 関数の積の展開で求まり、焦点に近い点の第 2〜4 種類は $x = 3$ からの Taylor 級数による接続になる。
推定誤差は包含区間ではないので、重要な値は小さい $c$ の摂動、角関数の規格化、動径関数の Wronskian のような独立な関係で確かめる。

打ち切りの受け入れ条件と診断の詳しい読み方は [Mathieu 関数とスペクトル法](../mathieu-and-spheroidal/)で確かめる。
3 軸の長さがすべて異なる楕円体の Laplace 方程式は、[楕円体調和関数と Lamé 関数](../ellipsoidal-harmonics/)で Lamé 関数の分類と外部解の求積を確かめる。
$c = 0$ の極限の Ferrers 関数そのものの性質は [Legendre 関数](../legendre-functions-and-spherical-harmonics/)で説明している。
