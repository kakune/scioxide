Stirling 数、Bernoulli 数、Euler 数は、数え上げと級数の係数に現れる整数・有理数の列である。
Stirling 数は冪と下降階乗冪のあいだの基底の変換係数で、Bernoulli 数は Euler–Maclaurin の和公式や Gamma 関数の Stirling 級数の係数に現れる。
どれも次数とともに階乗のように増え、binary64 で正確に表せる整数の範囲（$2^{53} \approx 9.0 \times 10^{15}$ 以下）をすぐに超える。
このページは各列の定義、`scioxide-special` の評価法（三角漸化式、正確な表、zeta 関数と beta 関数の恒等式）、正確な値を返す `checked_bernoulli` と `checked_euler`、精度の保証、API の使い分けを説明する。
階乗と二項係数、その対数形と方法の切り替えは [階乗と二項係数](../combinatorial-numbers/) で扱う。

## Stirling 数

Stirling 数は冪 $x^n$ と下降階乗冪 $(x)_n^{\downarrow} = x(x-1)\cdots(x-n+1)$ のあいだの基底の変換係数である（DLMF §26.8）。
符号付きの第一種 Stirling 数 $s(n, k)$ と第二種 Stirling 数 $S(n, k)$ は

$$
x(x-1)\cdots(x-n+1) = \sum_{k=0}^n s(n, k)\, x^k, \qquad x^n = \sum_{k=0}^n S(n, k)\, x(x-1)\cdots(x-k+1)
$$

で定まる。
$S(n, k)$ は $n$ 個の区別できる要素を $k$ 個の空でない部分集合に分ける方法の数で、$|s(n, k)|$ は $n$ 個の要素の置換のうち $k$ 個の巡回を持つものの数である。
$s(n, k)$ の符号は $(-1)^{n-k}$ である。
二つの変換は互いに逆なので、下三角行列 $[s(n, j)]$ と $[S(j, m)]$ の積は単位行列になる（DLMF §26.8）。

$$
\sum_{j=m}^{n} s(n, j)\, S(j, m) = \delta_{nm}
$$

`stirling_first_kind` と `stirling_second_kind` は、三角漸化式

$$
|s(n+1, k)| = |s(n, k-1)| + n\,|s(n, k)|, \qquad S(n+1, k) = S(n, k-1) + k\,S(n, k)
$$

を 1 列分（$k+1$ 個）の作業領域で回し、最後に $s$ の符号を付ける。
符号のない漸化式は正の項の和なので、打ち消しが起きない。
列の各値は binary64 の仮数と整数の指数に分けて持つので、途中であふれることはない。
計算量は $O(k(n-k))$ 回の演算で、呼び出しのたびに列を確保する。
$s(n, n) = S(n, n) = 1$、$k > n$ と $k = 0 < n$ では 0、$S(n, 1) = 1$ は漸化式を回さずに返す。

仮数は binary64 なので、値が $2^{53}$ を超えると正確な整数ではなくなり、相対誤差は漸化式の段数に比例して積もる。
オプション付き形式はこれを $8n\varepsilon$ の相対誤差の推定として返す。
漸化式の処理は `CombinatorialOptions` の作業量の上限に数えられ、$O(k(n-k))$ が上限を超えると `ConvergenceFailure` になる。
$0 < k < n$ で $n$ が上限（既定 65 536）以上なら、漸化式を始めずに `InvalidInput`（`OutOfRange`）を返す。
列を確保できなければ `SizeOverflow` か `AllocationFailure`、値が範囲を超えれば `NumericalInstability`（`Overflow`）になる。
二つの関数は作業量が引数で増えるので、スコープ付き API `stirling_first_kind_scoped`、`stirling_second_kind_scoped` を持つ。

次のセルは最大次数 $N$ までの $s(n, k)$ と $S(n, k)$ を浮動小数点で求め、二つの独立な検算をする。
一つは、同じ漸化式を `i128` の整数で手で回した正確な値との相対差である。
`i128` は $33! \approx 8.7 \times 10^{36}$ まで正確に扱えるので、$N \le 30$ の範囲を正確に比べられる。
もう一つは逆行列の関係の残差で、和は符号の交互に変わる大きな項の打ち消しになるので、項の大きさ $\sum_j |s(n, j)|\,S(j, m)$ で割った値も出す。

```rust
//| id: special-combinatorial-stirling-orthogonality
//| ref: special-combinatorial-stirling-orthogonality
//| title: Stirling 数を正確な整数と逆行列の関係で確かめる
//| run: reactive
//| crates: [scioxide-special]
//| inputs:
//|   max_n: {"type":"range","label":"最大次数 N [-]","description":"値が 2^53 を超える次数まで比べる範囲を広げる。","min":4,"max":30,"step":1,"value":12}
//| cases:
//|   - {"id":"large","label":"N = 30","description":"|s(30, 1)| = 29! ≈ 8.8 × 10³⁰ まで、値が正確な整数でなくなる範囲を含む。","inputs":{"max_n":30}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"stirling","path":"/rows/11/1","equals":0}
//|       - {"artifact":"stirling","path":"/rows/11/2","equals":0}
//|       - {"artifact":"stirling","path":"/rows/11/5","range":{"max":1e-15}}
//|   - case: large
//|     expect:
//|       - {"artifact":"stirling","path":"/rows/29/1","range":{"max":1e-15}}
//|       - {"artifact":"stirling","path":"/rows/29/2","range":{"max":1e-15}}
//|       - {"artifact":"stirling","path":"/rows/29/4","range":{"min":1e18}}
//|       - {"artifact":"stirling","path":"/rows/29/5","range":{"max":1e-15}}
use scioxide_special::{stirling_first_kind, stirling_second_kind};

let size = max_n as usize + 1;
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
// 独立検算用: |s(n, k)| と S(n, k) の漸化式を i128 で正確に回す。
let mut first_exact = vec![vec![0_i128; size]; size];
let mut second_exact = vec![vec![0_i128; size]; size];
first_exact[0][0] = 1;
second_exact[0][0] = 1;
for n in 1..size {
    for k in 1..=n {
        first_exact[n][k] = first_exact[n - 1][k - 1] + (n as i128 - 1) * first_exact[n - 1][k];
        second_exact[n][k] = second_exact[n - 1][k - 1] + k as i128 * second_exact[n - 1][k];
    }
}

// 浮動小数点の値（SciOxide）。
let mut first = vec![vec![0.0_f64; size]; size];
let mut second = vec![vec![0.0_f64; size]; size];
for n in 0..size {
    for k in 0..=n {
        first[n][k] = stirling_first_kind::<f64>(n, k).map_err(|e| e.to_string())?;
        second[n][k] = stirling_second_kind::<f64>(n, k).map_err(|e| e.to_string())?;
    }
}

let mut rows = Vec::new();
for n in 1..size {
    let mut first_error = 0.0_f64;
    let mut second_error = 0.0_f64;
    for k in 1..=n {
        let sign = if (n - k) % 2 == 0 { 1.0 } else { -1.0 };
        let exact_first = sign * first_exact[n][k] as f64;
        let exact_second = second_exact[n][k] as f64;
        first_error = first_error.max((first[n][k] - exact_first).abs() / exact_first.abs());
        second_error = second_error.max((second[n][k] - exact_second).abs() / exact_second);
    }
    // 逆行列の関係の残差と、打ち消す項の大きさ。
    let mut residual = 0.0_f64;
    let mut relative = 0.0_f64;
    for m in 0..=n {
        let sum: f64 = (m..=n).map(|j| first[n][j] * second[j][m]).sum();
        let scale: f64 = (m..=n).map(|j| (first[n][j] * second[j][m]).abs()).sum();
        let delta = if m == n { 1.0 } else { 0.0 };
        residual = residual.max((sum - delta).abs());
        relative = relative.max((sum - delta).abs() / scale);
    }
    let largest = (1..=n)
        .map(|k| first_exact[n][k].max(second_exact[n][k]))
        .max()
        .unwrap_or(1);
    rows.push((
        n,
        first_error,
        second_error,
        largest as f64,
        residual,
        relative,
    ));
}
let columns = serde_json::json!([
    { "key": "0", "label": "n", "type": "integer" },
    { "key": "1", "label": "s(n, ·) の最大相対差 [-]", "type": "number", "format": sci3 },
    { "key": "2", "label": "S(n, ·) の最大相対差 [-]", "type": "number", "format": sci3 },
    { "key": "3", "label": "行の最大の大きさ [-]", "type": "number", "format": sci3 },
    { "key": "4", "label": "逆行列の関係の残差 [-]", "type": "number", "format": sci3 },
    { "key": "5", "label": "残差 / 項の大きさ [-]", "type": "number", "format": sci3 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "stirling" })
);
```

既定の $N = 12$ では、すべての値が正確な整数と一致し、逆行列の関係の残差も 0 である。
$N = 30$ にすると、$s(n, \cdot)$ は $n = 21$、$S(n, \cdot)$ は $n = 24$ から正確な整数とわずかに食い違い始めるが、相対差は最大で $3.2 \times 10^{-16}$ である。
これは推定誤差の $8n\varepsilon = 5.3 \times 10^{-14}$ よりずっと小さい。

逆行列の関係の残差は $n = 18$ から 0 でなくなり、$n = 30$ では $1.7 \times 10^{18}$ に達する。
ただし打ち消す項の大きさで割ると $1.5 \times 10^{-16}$ で、binary64 の丸めの程度にとどまる。
大きな残差は値の誤りではなく、符号が交互に変わる $10^{30}$ を超える項の和で起きる打ち消しである。
相対差か、項の大きさで割った残差が $\varepsilon$ の数十倍を超えたら、値か検算の式を疑う。

## Bernoulli 数と Euler 数

Bernoulli 数 $B_n$ と Euler 数 $E_n$ は、指数型の母関数で定義される（DLMF 24.2.1、24.2.6）。

$$
\frac{t}{e^t - 1} = \sum_{n=0}^\infty B_n \frac{t^n}{n!}, \qquad \operatorname{sech} t = \frac{2}{e^t + e^{-t}} = \sum_{n=0}^\infty E_n \frac{t^n}{n!}
$$

$B_0 = 1$、$B_1 = -1/2$、$B_2 = 1/6$、$B_4 = -1/30$ で、$n \ge 3$ の奇数では $B_n = 0$ である。
$B_1$ の符号は母関数 $t/(e^t - 1)$ の規約によるもので、$t/(1 - e^{-t})$ を使う文献では $+1/2$ になる。
$E_0 = 1$、$E_2 = -1$、$E_4 = 5$、$E_6 = -61$ で、奇数の $n$ では $E_n = 0$、偶数の $E_n$ は整数で符号が交互に変わる。

偶数次の値は zeta 関数と Dirichlet の beta 関数 $\beta(s) = \sum_{j \ge 0} (-1)^j (2j+1)^{-s}$ で書ける（DLMF 25.6.2 ほか）。

$$
B_{2m} = (-1)^{m+1}\frac{2\,(2m)!}{(2\pi)^{2m}}\,\zeta(2m), \qquad E_{2m} = (-1)^m \frac{2^{2m+2}\,(2m)!}{\pi^{2m+1}}\,\beta(2m+1)
$$

$\zeta(2m) \to 1$ なので、$|B_{2m}|$ は $2(2m)!/(2\pi)^{2m}$ の程度で増え、$m$ が大きいと階乗のように増える。

`bernoulli` は $n \le 34$ の偶数を正確な有理数の表から丸め、それより大きい偶数は上の恒等式の $\zeta(2m)$ と $\beta(2m+1)$ の級数を直接足して、$\ln(2m)!$ と合わせて対数で評価する。
`euler` は $n \le 22$ の偶数を正確な整数の表から丸め、それより大きい偶数を同じように評価する。
級数は $2m$ が大きいほど速く収束し、省いた項の上界が $\varepsilon/4$ を下回ったところで止まる。
値が範囲を超えると `NumericalInstability`（`Overflow`）になり、オプション付き形式は対数形を残す。

正確な値は `checked_bernoulli(n)` と `checked_euler(n)` で得る。
`checked_bernoulli` は既約分数（分子 `isize`、分母 `usize`）を返し、表にある偶数 $n \le 34$ と $n = 38$ に対応する。
$B_{36}$ の分子は 64 ビットに収まらないが、$B_{38}$ の分子は収まるので、$n = 36$ と $n > 38$ だけが `SizeOverflow` になる。
`checked_euler` は $n \le 22$ の偶数を `isize` の整数で返し、それより大きい偶数は `SizeOverflow` になる。
`isize` の幅は環境で変わり、32 ビットの環境（wasm32 を含む）では分子が $2^{31}$ を超える $B_{28}$ 以降と $E_{16}$ 以降も `SizeOverflow` になる。

次のセルは最大次数までの偶数の $B_n$ を、正確な有理数、`riemann_zeta` を使った恒等式と比べる。
恒等式の側は $\zeta(2m)$ を `riemann_zeta` から取り、$(2m)!$ と $(2\pi)^{2m}$ を対数の上で手で組み立てる。
表の範囲（$n \le 34$）では `bernoulli` と独立な経路で、$n \ge 36$ では `bernoulli` も同じ恒等式を使うが、$\zeta(2m)$ の評価（`bernoulli` は級数を直接足す）と組み立ての丸めが異なる。
$E_n$ は母関数の関係 $\operatorname{sech} t \cdot \cosh t = 1$ から出る恒等式

$$
\sum_{j=0}^{m} \binom{2m}{2j} E_{2j} = 0 \qquad (m \ge 1)
$$

の残差を、項の大きさ $\sum_j \binom{2m}{2j}\lvert E_{2j}\rvert$ で割って出す。
32 ビットの環境で `checked_bernoulli` が `SizeOverflow` を返す行は、正確な値の列を空欄にする。

```rust
//| id: special-combinatorial-bernoulli-zeta
//| ref: special-combinatorial-bernoulli-zeta
//| title: Bernoulli 数と Euler 数を正確な値と恒等式で確かめる
//| run: reactive
//| crates: [scioxide-core, scioxide-special]
//| inputs:
//|   max_order: {"type":"range","label":"最大次数 n [-]","description":"表から恒等式の評価へ切り替わる次数を越えて比べる。","min":4,"max":80,"step":2,"value":40}
//| cases:
//|   - {"id":"table-only","label":"n ≤ 12","description":"表の正確な値の範囲だけを比べる。","inputs":{"max_order":12}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"bernoulli","path":"/rows/5/1","approx":{"value":-0.25311355311355315,"rtol":1e-15}}
//|       - {"artifact":"bernoulli","path":"/rows/19/4","range":{"max":3e-14}}
//|       - {"artifact":"bernoulli","path":"/rows/19/5","equals":"combinatorial/bernoulli_zeta_identity@1"}
//|       - {"artifact":"euler","path":"/rows/19/2","range":{"max":1e-15}}
//|   - case: table-only
//|     expect:
//|       - {"artifact":"bernoulli","path":"/rows/5/3","equals":0}
//|       - {"artifact":"bernoulli","path":"/rows/5/4","range":{"max":1e-14}}
//|       - {"artifact":"euler","path":"/rows/5/2","range":{"max":1e-15}}
use scioxide_core::RealScalar;
use scioxide_special::{
    CombinatorialOptions, bernoulli, bernoulli_with_options, binomial, checked_bernoulli,
    euler, euler_with_options, ln_factorial, riemann_zeta,
};

let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let sig12 = serde_json::json!({ "notation": "scientific", "significantDigits": 12 });
let options = CombinatorialOptions::default();
let half = max_order as usize / 2;
let log_two_pi = RealScalar::ln(2.0 * std::f64::consts::PI);

let mut rows = Vec::new();
for m in 1..=half {
    let n = 2 * m;
    let value = bernoulli::<f64>(n).map_err(|e| e.to_string())?;
    let method = bernoulli_with_options::<f64>(n, options)
        .map_err(|e| e.to_string())?
        .algorithm()
        .to_string();
    // 正確な有理数（isize に収まらないときは None）。
    let exact = checked_bernoulli(n).ok().map(|(p, q)| p as f64 / q as f64);
    let exact_error = exact.map(|e| (value - e).abs() / e.abs());
    // 恒等式 B₂ₘ = (−1)^(m+1) 2 (2m)! ζ(2m) / (2π)^(2m) を対数の上で手で組み立てる。
    let sign = if m % 2 == 1 { 1.0 } else { -1.0 };
    let zeta = riemann_zeta(n as f64).map_err(|e| e.to_string())?;
    let log_magnitude = RealScalar::ln(2.0 * zeta)
        + ln_factorial::<f64>(n).map_err(|e| e.to_string())?
        - n as f64 * log_two_pi;
    let identity = sign * RealScalar::exp(log_magnitude);
    rows.push((
        n,
        value,
        exact,
        exact_error,
        (value - identity).abs() / value.abs(),
        method,
    ));
}
let columns = serde_json::json!([
    { "key": "0", "label": "n", "type": "integer" },
    { "key": "1", "label": "bernoulli(n)", "type": "number", "format": sig12 },
    { "key": "2", "label": "正確な有理数", "type": "number", "format": sig12, "nullText": "isize に収まらない" },
    { "key": "3", "label": "有理数との相対差 [-]", "type": "number", "format": sci3, "nullText": "—" },
    { "key": "4", "label": "ζ の恒等式との相対差 [-]", "type": "number", "format": sci3 },
    { "key": "5", "label": "方法" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "bernoulli" })
);

let values: Vec<f64> = (0..=half)
    .map(|m| euler::<f64>(2 * m))
    .collect::<Result<_, _>>()
    .map_err(|e| e.to_string())?;
let mut euler_rows = Vec::new();
for m in 1..=half {
    let n = 2 * m;
    // Σ_j C(2m, 2j) E₂ⱼ = 0 の残差と項の大きさ。
    let mut sum = 0.0;
    let mut scale = 0.0;
    for j in 0..=m {
        let weight = binomial::<f64>(n, 2 * j).map_err(|e| e.to_string())?;
        sum += weight * values[j];
        scale += weight * values[j].abs();
    }
    let method = euler_with_options::<f64>(n, options)
        .map_err(|e| e.to_string())?
        .algorithm()
        .to_string();
    euler_rows.push((n, values[m], sum.abs() / scale, method));
}
let columns = serde_json::json!([
    { "key": "0", "label": "n", "type": "integer" },
    { "key": "1", "label": "euler(n)", "type": "number", "format": sig12 },
    { "key": "2", "label": "恒等式の残差 / 項の大きさ [-]", "type": "number", "format": sci3 },
    { "key": "3", "label": "方法" }
]);
emit_table_with_columns!(
    columns,
    euler_rows,
    metadata = serde_json::json!({ "id": "euler" })
);
```

既定の最大次数 40 では、$n \le 34$ が表（`bernoulli_rational_table`）、$n \ge 36$ が恒等式（`bernoulli_zeta_identity`）で評価される。
64 ビットの環境では、表の範囲で正確な有理数との相対差は 0 である。
wasm32 では `checked_bernoulli` が $n \ge 28$ で `SizeOverflow` を返すので、その行の正確な値の列は空欄になる。
$B_{38}$ は $B_{36}$ と違って分子が 64 ビットに収まるので、64 ビットの環境ではこの行にも正確な値が入る。

ζ の恒等式との相対差は最大 $1.2 \times 10^{-14}$ である。
手で組み立てた $\exp(\ln 2\zeta(2m) + \ln(2m)! - 2m\ln 2\pi)$ の指数では $\ln 40! \approx 110$ と $40\ln 2\pi \approx 74$ が打ち消すので、差はその丸め $110\,\varepsilon \approx 2.4 \times 10^{-14}$ の程度に収まり、`bernoulli` の誤差を示すものではない。
Euler 数は $n \le 22$ が表、$n \ge 24$ が β の恒等式で、母関数の恒等式の残差は項の大きさの $1.1 \times 10^{-16}$ 以下である。
次数を上げると値は階乗のように増え、$B_{40} \approx -1.93 \times 10^{16}$、$E_{40} \approx 1.49 \times 10^{40}$ になる。

## 精度の保証

この節の関数には、照合データ（独立に高精度で生成した参照値）で確かめた一様な ULP の目標はない。
独立な参照値と正確な恒等式で試験し、オプション付き形式が推定誤差を返す。

| 関数 | binary64 | binary32 | 補足 |
|---|---|---|---|

## API

| 関数 | 標準形式の引数 | オプション付き形式 | スコープ付き API | 値 |
|---|---|---|---|---|
| `stirling_first_kind` | `n, k` | `stirling_first_kind_with_options` | `stirling_first_kind_scoped` | $s(n, k)$ |
| `stirling_second_kind` | `n, k` | `stirling_second_kind_with_options` | `stirling_second_kind_scoped` | $S(n, k)$ |
| `bernoulli` | `n` | `bernoulli_with_options` | なし | $B_n$ |
| `euler` | `n` | `euler_with_options` | なし | $E_n$ |
| `checked_bernoulli` | `n` | なし | なし | $B_n$ の既約分数 `(isize, usize)` |
| `checked_euler` | `n` | なし | なし | $E_n$ の整数 `isize` |

引数 `n`、`k` は `usize` で、浮動小数点の関数は結果の型 `S: RealScalar` を `bernoulli::<f64>(n)` のように型引数で選ぶ。
オプション付き形式は `CombinatorialOptions` を受け取り、通常値と推定誤差、尺度化した値、対数形、終了状態、アルゴリズムの識別子、計算量の計数を持つ `SpecialFunctionResult` を返す。
値があふれてもオプション付き形式はエラーにならず、通常値への射影の状態が `ScalarRepresentation::Overflow` になって、対数形が残る。
`CombinatorialOptions` は作業量の上限（`Budget`）だけを持ち、既定は 65 536 単位で、`CombinatorialOptions::new(budget)` か `with_iteration_budget` で変える。
作業量が引数で増える Stirling 数だけがスコープ付き API を持ち、スコープ付き API はオプション付き形式と同じ結果を返して、計算量を親の実行コンテキストに渡す。
`bernoulli` と `euler` は表か、次数が大きいほど速く収束する級数で評価し、計算量が引数によらず抑えられるので、スコープ付き API を持たない。

## まとめと次に読むページ

Stirling 数は符号のない三角漸化式で打ち消しなく計算されるが、$2^{53}$ を超える値は丸めた値で、作業量は $O(k(n-k))$ で増え、$n$ が作業量の上限以上なら評価を始めずに `InvalidInput` を返す。
逆行列の関係のように符号が交互に変わる和の残差は、項の大きさで割ってから丸めの程度と比べる。
Bernoulli 数と Euler 数は小さい次数を正確な表から、大きい次数を zeta 関数と beta 関数の恒等式から求め、値が binary64 を超える次数ではオプション付き形式の対数形を使う。
正確な有理数や整数が必要なら `checked_bernoulli` と `checked_euler` を使い、32 ビットの環境では `isize` の範囲が狭いことに注意する。
階乗と二項係数は [階乗と二項係数](../combinatorial-numbers/) で、Bernoulli 数が係数として現れる Stirling 級数は [Gamma 関数・polygamma 関数・Pochhammer 記号](oxref:special-gamma-stirling-series) で、zeta 関数の評価法は [Riemann・Hurwitz ゼータ関数と Dirichlet eta 関数](../zeta-functions/) で確かめる。
