円柱 Bessel 関数の方程式に右辺が付くと、解は Bessel 関数と Struve 関数の和になる。
平面の壁にはめ込んだ半径 $a$ の円形ピストンが波数 $k$ の音を放射するとき、放射インピーダンスの実部は $1 - 2J_1(2ka)/(2ka)$、虚部は $2\mathbf{H}_1(2ka)/(2ka)$ に比例し、虚部に Struve 関数 $\mathbf{H}_1$ が現れる。
回折や熱伝導の解を閉じた形で書くと、$\int_0^x J_0(t)\,dt$ のような Bessel 関数の積分が残る。

このページは Struve 関数 $\mathbf{H}_\nu$ と変形 Struve 関数 $\mathbf{L}_\nu$、0 次の Bessel 関数と Struve 関数の積分を扱う。
各族について定義と性質、`scioxide-special` が引数の領域ごとに使う評価法とその理由、精度の保証、API を説明し、最後の二つのセルで初等関数と Struve 関数による閉形式で値を検算する。
Bessel 関数そのものの定義と評価は [円柱 Bessel 関数と Hankel 関数](../airy-bessel-and-hankel/) に、二次のポテンシャルを持つ Weber 方程式の解は [放物柱関数](../parabolic-cylinder-functions/) にある。

## Struve 関数と変形 Struve 関数

Struve 関数 $\mathbf{H}_\nu(x)$ は、非斉次の Bessel 方程式（DLMF 11.2.7）

$$
w'' + \frac{1}{x}w' + \left(1 - \frac{\nu^2}{x^2}\right)w = \frac{(x/2)^{\nu - 1}}{\sqrt{\pi}\,\Gamma(\nu + 1/2)}
$$

の特解で、次の冪級数（DLMF 11.2.1）で定義される。

$$
\mathbf{H}_\nu(x) = \sum_{k=0}^{\infty} \frac{(-1)^k (x/2)^{\nu + 2k + 1}}{\Gamma(k + 3/2)\,\Gamma(k + \nu + 3/2)}.
$$

変形 Struve 関数 $\mathbf{L}_\nu(x) = -i e^{-i\nu\pi/2}\mathbf{H}_\nu(ix)$ は、同じ級数の符号 $(-1)^k$ を取り除いたもの（DLMF 11.2.2）で、すべての項が同じ符号を持つ。
$\Gamma(k + \nu + 3/2)$ が極になる項は 0 とみなす。
$\nu$ は有限な実数ならどれでもよい。

$x < 0$ は次数が整数 $n$ のときだけ定義し、$\mathbf{H}_n(-x) = (-1)^{n+1}\mathbf{H}_n(x)$、$\mathbf{L}_n(-x) = (-1)^{n+1}\mathbf{L}_n(x)$ を使う。
$x = 0$ では、$\nu > -1$ と $\nu = -3/2, -5/2, \ldots$ で値は 0、$\nu = -1$ で $2/\pi$ になり、それ以外の次数は極になる。
半整数次は初等関数で書ける（DLMF §11.4）。
たとえば $\mathbf{H}_{1/2}(x) = \sqrt{2/(\pi x)}\,(1 - \cos x)$、$\mathbf{L}_{1/2}(x) = \sqrt{2/(\pi x)}\,(\cosh x - 1)$ で、$\nu = -(n + 1/2)$ では $\mathbf{H}_\nu(x) = (-1)^n J_{n+1/2}(x)$、$\mathbf{L}_\nu(x) = I_{n+1/2}(x)$ になる（DLMF 11.4.4、11.4.5）。

大きな $x$ では、Struve 関数は Bessel 関数とゆっくり変わる関数の和に分かれる（DLMF 11.6.1、11.6.2）。

$$
\mathbf{H}_\nu(x) = Y_\nu(x) + \mathbf{K}_\nu(x), \qquad
\mathbf{L}_\nu(x) = I_\nu(x) + \mathbf{M}_\nu(x),
$$

$$
\mathbf{K}_\nu(x) \sim \frac{1}{\pi}\sum_{k=0}^{\infty} \frac{\Gamma(k + 1/2)\,(x/2)^{\nu - 2k - 1}}{\Gamma(\nu + 1/2 - k)}.
$$

$\mathbf{M}_\nu$ は同じ和の項の符号を $(-1)^{k+1}$ にしたものである。
$\mathbf{H}_\nu$ は $Y_\nu$ の振動に $\mathbf{K}_\nu \approx (x/2)^{\nu-1}/(\sqrt{\pi}\,\Gamma(\nu + 1/2))$ が重なった形になり、$\mathbf{L}_\nu$ は $I_\nu$ と同じく $e^x/\sqrt{2\pi x}$ のように増える。

### 級数と漸近展開の使い分け

`struve` と `modstruve` は $x \ge 20$ で漸近展開を試し、受理できなければ定義の級数を足す。
$\nu = -(n + 1/2)$ の次数は、上の Bessel 関数による表示で評価する。

漸近展開は $\mathbf{K}_\nu$ の和を $\nu - 1/2$ 項以上進めてから、項が増え始めるか和に対して無視できる大きさになったところで打ち切る。
実数の $\nu$ と $x > 0$ では、$\nu - 1/2$ 項より先で打ち切った $\mathbf{K}_\nu$ の剰余は最初に捨てた項と同じ符号を持ち、その項より小さい（DLMF §11.6(i)）。
実装はその項の半分を和に加えるので、打ち切り誤差は捨てた項の半分以下になる。
この半分が $Y_\nu$ の振幅 $\sqrt{2/(\pi x)}$ と $\lvert\mathbf{K}_\nu\rvert$ の大きいほうの $\varepsilon/2$ 倍（$\varepsilon$ は `f64` の機械イプシロン）以下のときに受理し、$Y_\nu$ を加える。
$\lvert Y_\nu\rvert + \lvert\mathbf{K}_\nu\rvert$ が和と振幅の大きいほうの 64 倍を超えるとき（$\nu$ が $x$ より大きいと起こる打ち消し）も受理せず、級数に回す。
最小の項は先頭の項のおよそ $e^{-x}$ 倍なので、一般の次数では受理されるのは $x$ が 26〜35 程度を超えてからで（次数が大きいほど早い）、それまでは $x \ge 20$ でも級数を使う。
半整数次 $\nu = 1/2, 3/2, \ldots$ では $\mathbf{K}_\nu$ の和が有限個の項で終わる（$\Gamma(\nu + 1/2 - k)$ が極になる）ので、打ち切り誤差がなく、$x = 20$ から受理される。

$\mathbf{L}_\nu$ の展開には、DLMF が剰余の限界を与えていない。
そこで、最初に捨てた項の $x$ 倍を打ち切り誤差の見積もりとし、DLMF の式が $\mathbf{L}_\nu - I_\nu$ と $\mathbf{L}_\nu - I_{-\nu}$ を区別しないこと（差 $I_\nu - I_{-\nu}$ は $I_\nu$ の $e^{-2x}$ 倍程度）の見積もりと足して、和が $\varepsilon\lvert I_\nu\rvert/16$ 以下のときだけ受理する。
$\mathbf{M}_\nu$ は $I_\nu$ に比べて $e^{-x}$ 程度に小さいので、$\mathbf{L}_\nu$ の展開は $\mathbf{H}_\nu$ より小さい $x$ で受理される。

級数は2 ワードの算術（double-word、`f64` 二つで約 106 ビットを表す算術）で足す。
$\mathbf{H}_\nu$ の級数は交代級数で、項の大きさは $x$ とともに $\mathbf{L}_\nu \sim e^x/\sqrt{2\pi x}$ の程度まで育ち、和はそれより桁違いに小さい。
和が $\sqrt{2/(\pi x)}$ 程度なら打ち消しで失う桁は約 $e^x/2$ 倍で、$x = 20$ で 28 ビット、漸近展開が受理され始める $x = 35$ で 50 ビットになり、2 ワードの算術の 106 ビットから引いても `f64` の 53 ビットが残る。
漸近展開を $x \ge 20$ で初めて試すのは、それより小さい $x$ では $Y_\nu$ と $\mathbf{K}_\nu$ の打ち消しや $I_\nu - I_{-\nu}$ が無視できないからである。
係数 $(x/2)^{\nu+1}/\Gamma(\nu + 3/2)$ は、あふれる場合には対数で持ち、最後に一度だけ通常値へ射影する。
級数の剰余は、項の比が 1 より小さくなった後は等比級数で抑える。

オプション付き形式 `struve_with_options`、`modstruve_with_options` は、値と推定誤差に加えて導関数 $\mathbf{H}_\nu'(x)$、$\mathbf{L}_\nu'(x)$ を返す（$x = 0$ で $-1 < \nu < 0$ のときは無限大なので返さない）。
値の推定誤差は打ち切りと丸めから導いた値で、Bessel 関数を使う経路（漸近展開と $\nu = -(n + 1/2)$）では Bessel 関数の照合試験で測った誤差の幅を加える。
導関数の推定誤差は発見的（heuristic）である。

### Struve 関数の精度

独立に生成した参照値で確かめた `f64` の目標は、$\nu \in [-5, 10]$、$x \in [10^{-3}, 100]$ で 64 ULP（ULP は厳密な結果の位置での浮動小数点数の間隔）である。
$\mathbf{H}_\nu$ の零点の近くでは相対誤差が意味を持たないので、絶対誤差 $4\varepsilon\max(1, \lvert\mathbf{H}_\nu(x)\rvert)$ を目標にする。
この範囲の外と `f32` には一様な ULP の仕様がなく、試験は参照値との差と推定誤差を族ごとの限界で確かめる。
その範囲ではオプション付き形式の推定誤差を読む。

## Bessel 関数と Struve 関数の積分

0 次の Bessel 関数と Struve 関数について、次の 11 個の積分を関数として提供する。
被積分関数が原点で $\ln t$ のように特異になる $Y_0$、$K_0$ と、$1/t$ の重みが付いた積分は、定数を取り除いた形や裾の形にして有限にしてある。

| 関数 | 値 | 定義域 | 性質 |
|---|---|---|---|
| `bessel_j0_integral` | $\int_0^x J_0(t)\,dt$ | すべての $x$ | 奇関数、$x \to \infty$ で 1 |
| `bessel_j0_complement_integral` | $\int_0^x \frac{1 - J_0(t)}{t}\,dt$ | すべての $x$ | 偶関数、$x \to \infty$ で $\ln(x/2) + \gamma$ のように増える |
| `bessel_y0_integral` | $\int_0^x Y_0(t)\,dt$ | $x \ge 0$ | $x \to \infty$ で 0 |
| `bessel_y0_tail_integral` | $\int_x^\infty \frac{Y_0(t)}{t}\,dt$ | $x > 0$ | $x \to 0^+$ で発散 |
| `bessel_i0_integral` | $\int_0^x I_0(t)\,dt$ | すべての $x$ | 奇関数、$e^{\lvert x\rvert}/\sqrt{2\pi\lvert x\rvert}$ のように増える |
| `bessel_i0_remainder_integral` | $\int_0^x \frac{I_0(t) - 1}{t}\,dt$ | すべての $x$ | 偶関数、$e^{\lvert x\rvert}/(\lvert x\rvert\sqrt{2\pi\lvert x\rvert})$ のように増える |
| `bessel_k0_integral` | $\int_0^x K_0(t)\,dt$ | $x \ge 0$ | $x \to \infty$ で $\pi/2$ |
| `bessel_k0_tail_integral` | $\int_x^\infty \frac{K_0(t)}{t}\,dt$ | $x > 0$ | $e^{-x}/x^{3/2}$ のように減る |
| `struve_h0_integral` | $\int_0^x \mathbf{H}_0(t)\,dt$ | すべての $x$ | 偶関数 |
| `struve_h0_tail_integral` | $\int_x^\infty \frac{\mathbf{H}_0(t)}{t}\,dt$ | すべての $x$ | $x = 0$ で $\pi/2$、$\int_{-x}^\infty = \pi - \int_x^\infty$ |
| `struve_l0_integral` | $\int_0^x \mathbf{L}_0(t)\,dt$ | すべての $x$ | 偶関数、$e^{\lvert x\rvert}/\sqrt{2\pi\lvert x\rvert}$ のように増える |

$\gamma$ は Euler の定数である。
`bessel_j0_complement_integral` の「complement」は被積分関数 $1 - J_0$ を、`bessel_i0_remainder_integral` の「remainder」は $I_0 - 1$ を指し、どちらも $\int_x^\infty$ の裾ではない。
裾 $\int_x^\infty J_0(t)\,dt$ が要るときは $1 - $ `bessel_j0_integral(x)` を使うが、$x$ が大きいと 1 に近い数の引き算になり、相対誤差は大きくなる。

### 積分の評価法

$\lvert x\rvert \le 12$ では、被積分関数の冪級数を項別に積分した級数を足す。
$Y_0$、$K_0$ の級数は $\ln(x/2)$ を含み、積分の定数は Mellin 変換の有限部分から決める（DLMF §10.22）。
$12 < \lvert x\rvert < 32$ では、区間 $[12, 16]$、$[16, 24]$、$[24, 32]$ ごとに前もって作った 64 項の Chebyshev 展開を Clenshaw の方法で評価する。
$\lvert x\rvert \ge 32$ では、$J_0$、$Y_0$ を含む積分は裾の積分 $\int_x^\infty$ の漸近展開（振動を $\cos x$、$\sin x$ の位相に分けた Hankel 型の展開）を極限値から引き、Struve 関数の積分では $\mathbf{H}_0 - Y_0$ の漸近展開を項別に積分した和を加える。
$K_0$ の積分は $\pi/2$ から裾の漸近展開を引き、裾の積分はその展開をそのまま使う。
$I_0$、$\mathbf{L}_0$ を含む積分は、積分そのものの $e^x$ に比例する漸近展開を足す。

$J_0$、$Y_0$、$\mathbf{H}_0$ の級数は交代級数で、$x = 12$ では項の絶対値の和が $\int_0^{12} I_0(t)\,dt \approx 2.0 \times 10^4$ の程度になる。
値は 1 程度で、`f64` で足すので、この打ち消しで約 4 桁を失う。
$x = 12$ で Chebyshev 展開に切り替えるのはこのためで、境界のすぐ下では誤差が `f64` の丸めより大きくなる（下のセルで確かめる）。
$I_0$、$\mathbf{L}_0$ を含む積分は項の符号がそろうので打ち消しがなく、$\lvert x\rvert < 32$ の全体で級数を使う。

負の $x$ は奇関数・偶関数の性質で正の $x$ に戻す。
オプション付き形式はどの積分でも $x$ についての導関数を返し、$\int_0^x$ の形では被積分関数の値、裾の積分 $\int_x^\infty$ では被積分関数の符号を変えた値になる。
$x = 0$ の `bessel_y0_integral` と `bessel_k0_integral` では被積分関数が無限大なので、導関数は返さない。
値の推定誤差は打ち切りと丸めから導いたもので、導関数の推定誤差は発見的（heuristic）である。

### 積分の精度

Bessel 関数と Struve 関数の積分には一様な ULP の仕様がない。
試験は `f32` と `f64` で独立に生成した参照値と値・推定誤差を比べ、零点の近くでは $\varepsilon\max(1, \lvert\text{参照値}\rvert)$ の尺度で絶対誤差を抑える。
個々の評価の精度はオプション付き形式の推定誤差（`ValueWithError` の誤差。
包含区間ではない）で読む。

重み付きの積分 $\int_0^1 t^\mu J_\nu(2at)\,dt$（`bessel_weighted_integral`）と Jahnke–Emde の関数 $\Lambda_\nu(x)$（`bessel_lambda`）は [正規化した J と重み付き積分](oxref:special-bessel-lambda-weighted) で扱う。

## API

どの関数にも、値だけを返す標準形式 `f(..)`、`SpecialFunctionResult` を返すオプション付き形式 `f_with_options(.., options)`、求解スコープを受け取るスコープ付き API `f_scoped(.., options, scope)` がある。
オプションは作業量の上限（`Budget`。
精度の要求ではない）だけを持つ。
既定は `StruveOptions` が 262144 単位、`BesselIntegralOptions` が 65536 単位である。
引数は実数（`f32`、`f64`）である。

エラーは `SciOxideError` の `kind()` で分類する。
非有限な入力は `NonFinite` である。
`DomainError`（`OutsideDomain`）になるのは、非整数の次数での負の $x$（Struve 関数）と、負の $x$（`bessel_y0_integral`、`bessel_k0_integral`、`bessel_y0_tail_integral`、`bessel_k0_tail_integral`）である。
Struve 関数の原点の極（$\nu < -1$ で $\nu \ne -3/2, -5/2, \ldots$）と、二つの裾の積分の $x = 0$ では `DomainError`（`Pole`）を返す。
値が `f64` の範囲を超えると `NumericalInstability`（`Overflow`）を返す（`f32` の Struve 関数で値が `f32` の範囲を超えるときは型の変換のエラーになる）。
作業量の上限で止まり、値の見積もりがないときは `ConvergenceFailure`（`IterationLimit`）を返す。
オプション付き形式の終了状態（`SpecialFunctionTermination`）は、成功すれば `Converged` か、処理をせずに厳密な値（原点の値など）を返したときの `Exact` である。

## 級数から漸近展開への切り替え

次のセルは半整数次 $\nu = 1/2, 3/2$ の $\mathbf{H}_\nu$ と $\mathbf{L}_\nu$ を $x = 1$ から $60$ まで評価し、初等関数による閉形式と比べる。
閉形式は DLMF §11.4 の半整数次の表示と漸化式（DLMF 11.4.23）から作った次の式で、`f64` の標準関数で計算した参照値である。

$$
\mathbf{H}_{3/2}(x) = \sqrt{\frac{2}{\pi x}}\left(\frac{1 - \cos x}{x} - \sin x\right) + \sqrt{\frac{x}{2\pi}}, \qquad
\mathbf{L}_{3/2}(x) = \sqrt{\frac{2}{\pi x}}\left(\sinh x - \frac{\cosh x - 1}{x}\right) - \sqrt{\frac{x}{2\pi}}.
$$

誤差は、零点の近くで相対誤差が意味を失わないよう、$\lvert\Delta\rvert / (\varepsilon\max(1, \lvert\text{参照値}\rvert))$ で測る。
$\mathbf{L}_\nu$ は 1 より大きいので、これは相対誤差を $\varepsilon$ で割った値に等しい。
半整数次では $\mathbf{K}_\nu$ の和が有限個の項で終わるので、$x < 20$ では級数を、$x \ge 20$ では漸近展開を使う。
表は二つの区間に分けて最大の誤差と推定誤差、オプション付き形式の計算量（作業量の上限に数える単位）の最大を示す。

```rust
//| inputs:
//|   function: {"type":"select","label":"関数","options":["H_ν（Struve）","L_ν（変形 Struve）"],"value":"H_ν（Struve）"}
//|   order: {"type":"select","label":"次数 ν","options":["1/2","3/2"],"value":"3/2"}
//| cases:
//|   - {"id":"modified","label":"L_{3/2}","description":"項の符号がそろう変形 Struve 関数。x = 60 で 10²⁴ を超える値でも相対誤差は数 ε にとどまる。","inputs":{"function":"L_ν（変形 Struve）"}}
//|   - {"id":"half","label":"H_{1/2}","description":"x = 2πk に零点を持つ。絶対誤差の尺度で零点の近くも誤差が増えない。","inputs":{"order":"1/2"}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"regions","path":"/rows/0/1","range":{"max":4}}
//|       - {"artifact":"regions","path":"/rows/1/1","range":{"max":4}}
//|       - {"artifact":"regions","path":"/rows/1/2","range":{"min":4,"max":64}}
//|   - case: modified
//|     expect:
//|       - {"artifact":"regions","path":"/rows/0/1","range":{"max":4}}
//|       - {"artifact":"regions","path":"/rows/1/1","range":{"max":4}}
//|   - case: half
//|     expect:
//|       - {"artifact":"regions","path":"/rows/0/1","range":{"max":4}}
//|       - {"artifact":"regions","path":"/rows/1/1","range":{"max":4}}
use scioxide_special::{StruveOptions, modstruve_with_options, struve_with_options};

let modified = function != "H_ν（Struve）";
let nu = if order == "1/2" { 0.5 } else { 1.5 };
let pi = std::f64::consts::PI;
let eps = f64::EPSILON;
let options = StruveOptions::default();
// 半整数次の閉形式（f64 の標準関数による参照値）。
let reference = |x: f64| {
    let a = (2.0 / (pi * x)).sqrt();
    let b = (x / (2.0 * pi)).sqrt();
    match (modified, order == "1/2") {
        (false, true) => a * (1.0 - x.cos()),
        (false, false) => a * ((1.0 - x.cos()) / x - x.sin()) + b,
        (true, true) => a * (x.cosh() - 1.0),
        (true, false) => a * (x.sinh() - (x.cosh() - 1.0) / x) - b,
    }
};
let mut points = Vec::new();
// 区間ごとの [最大の誤差, 最大の推定誤差, 最大の計算量]。
let mut summary = [[0.0_f64; 3]; 2];
for index in 0..=236 {
    let x = 1.0 + 0.25 * f64::from(index);
    let result = if modified {
        modstruve_with_options(nu, x, options)
    } else {
        struve_with_options(nu, x, options)
    }
    .map_err(|e| e.to_string())?;
    let value = result.value().ok_or("通常値がない")?;
    let exact = reference(x);
    let scale = eps * exact.abs().max(1.0);
    let error = (value.value() - exact).abs() / scale;
    points.push([x, error]);
    let row = &mut summary[usize::from(x >= 20.0)];
    row[0] = row[0].max(error);
    row[1] = row[1].max(value.absolute_error() / scale);
    row[2] = row[2].max(result.counts().iterations() as f64);
}
emit_line_chart!(
    &vec![serde_json::json!({ "name": "|Δ| / (ε max(1, |参照値|))", "points": points })],
    options = &serde_json::json!({
        "xLabel": "引数 x [-]",
        "yLabel": "誤差 [ε 単位]",
        "xMin": 1.0,
        "xMax": 60.0,
        "yMin": 0.0,
        "annotations": [{ "kind": "line", "axis": "x", "value": 20.0, "label": "漸近展開を試す x = 20" }]
    })
);
let fixed1 = serde_json::json!({ "fractionDigits": 1 });
let columns = serde_json::json!([
    { "key": "0", "label": "区間" },
    { "key": "1", "label": "最大の誤差 [ε 単位]", "type": "number", "format": fixed1 },
    { "key": "2", "label": "最大の推定誤差 [ε 単位]", "type": "number", "format": fixed1 },
    { "key": "3", "label": "最大の計算量 [単位]", "type": "integer" }
]);
let rows: Vec<(&str, f64, f64, f64)> = vec![
    ("1 ≤ x < 20", summary[0][0], summary[0][1], summary[0][2]),
    ("20 ≤ x ≤ 60", summary[1][0], summary[1][1], summary[1][2]),
];
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "regions" })
);
```

既定の $\mathbf{H}_{3/2}$ では、最大の誤差は $x < 20$ で 1.2、$x \ge 20$ で 1.8 $\varepsilon$ 単位で、$x = 20$ を境に段差がない。
級数と漸近展開が、切り替えの前後で同じ精度の値を返していることが分かる。
推定誤差は 6〜13 $\varepsilon$ 単位で実際の誤差より大きく、丸めと打ち切りを上から見積もっている。
計算量は級数の区間で最大 41 単位、漸近展開の区間では導関数のための $Y_{\nu+1}$ を含む Bessel 関数の評価があるので最大 209 単位になる。
一般の次数（たとえば $\nu = 0.3$）では、漸近展開が受理されるのは $x$ が 30 を超えてからで、$x = 20$ から 30 の間は級数の項が増えて計算量も増える。
$\mathbf{L}_{3/2}$ と $\mathbf{H}_{1/2}$ でも最大の誤差は 2 $\varepsilon$ 単位以下である。
誤差が数十 $\varepsilon$ を超える点が現れたら、参照値の打ち消し（$\mathbf{H}_{3/2}$ の小さな $x$）か評価の誤りを疑い、推定誤差と比べる。

## Struve 関数による積分の検算

$\int_0^x J_0(t)\,dt$ と $\int_0^x Y_0(t)\,dt$ には、Bessel 関数と Struve 関数による閉形式がある（DLMF 10.22.2 の $\nu = 0$、$\mathbf{H}_{-1} = 2/\pi - \mathbf{H}_1$ を使う）。

$$
\int_0^x \mathscr{C}_0(t)\,dt = x\,\mathscr{C}_0(x) + \frac{\pi x}{2}\left(\mathscr{C}_1(x)\,\mathbf{H}_0(x) - \mathscr{C}_0(x)\,\mathbf{H}_1(x)\right), \qquad \mathscr{C} = J, Y.
$$

次のセルは `bessel_j0_integral` と `bessel_y0_integral` の値をこの式と比べる。
式の右辺は `bessel_j`、`bessel_y`、`struve` で計算するので、積分の実装とは別の経路である。
評価点は三つの方法の区間（級数 $x \le 12$、Chebyshev 展開 $12 < x < 32$、漸近展開 $x \ge 32$）とその境界の両側に置いた。
表の「導関数との差」は、オプション付き形式が返す導関数と被積分関数 $\mathscr{C}_0(x)$ の差である。

```rust
//| id: special-bessel-j0-integral-completeness
//| ref: special-bessel-j0-integral-completeness
//| title: J₀・Y₀ の積分を Struve 関数による閉形式と比べる
//| run: reactive
//| crates: [scioxide-special]
//| inputs:
//|   integrand: {"type":"select","label":"被積分関数","options":["J₀","Y₀"],"value":"J₀"}
//| cases:
//|   - {"id":"y0","label":"Y₀","description":"原点で対数特異性を持つ Y₀ の積分。x → ∞ で 0 に近づく。","inputs":{"integrand":"Y₀"}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"identity","path":"/rows/0/2","approx":{"value":0.4896805066460451,"rtol":1e-14}}
//|       - {"artifact":"identity","path":"/rows/4/4","range":{"min":100,"max":10000}}
//|       - {"artifact":"identity","path":"/rows/4/5","range":{"min":10000}}
//|       - {"artifact":"identity","path":"/rows/5/4","range":{"max":16}}
//|       - {"artifact":"identity","path":"/rows/8/4","range":{"max":16}}
//|       - {"artifact":"identity","path":"/rows/10/4","range":{"max":16}}
//|   - case: y0
//|     expect:
//|       - {"artifact":"identity","path":"/rows/0/2","approx":{"value":-0.5617954559146402,"rtol":1e-14}}
//|       - {"artifact":"identity","path":"/rows/4/5","range":{"min":10000}}
//|       - {"artifact":"identity","path":"/rows/5/4","range":{"max":16}}
//|       - {"artifact":"identity","path":"/rows/10/4","range":{"max":16}}
use scioxide_special::{
    BesselIntegralOptions, bessel_j, bessel_j0_integral_with_options, bessel_y,
    bessel_y0_integral_with_options, struve,
};

let first_kind = integrand == "J₀";
let options = BesselIntegralOptions::default();
let pi = std::f64::consts::PI;
let eps = f64::EPSILON;
let cylinder = |order: f64, x: f64| {
    if first_kind {
        bessel_j(order, x)
    } else {
        bessel_y(order, x)
    }
};
let points = [
    0.5_f64, 3.0, 8.0, 11.5, 11.9, 12.1, 20.0, 31.9, 32.1, 60.0, 300.0,
];
let mut rows = Vec::new();
for &x in &points {
    let result = if first_kind {
        bessel_j0_integral_with_options(x, options)
    } else {
        bessel_y0_integral_with_options(x, options)
    }
    .map_err(|e| e.to_string())?;
    let value = result.value().ok_or("通常値がない")?;
    let c0 = cylinder(0.0, x).map_err(|e| e.to_string())?;
    let c1 = cylinder(1.0, x).map_err(|e| e.to_string())?;
    let h0 = struve(0.0, x).map_err(|e| e.to_string())?;
    let h1 = struve(1.0, x).map_err(|e| e.to_string())?;
    // DLMF 10.22.2（ν = 0）による閉形式。
    let closed = x * c0 + 0.5 * pi * x * (c1 * h0 - c0 * h1);
    let scale = eps * closed.abs().max(1.0);
    let slope = result.derivative().ok_or("導関数がない")?;
    let method = if x <= 12.0 {
        "級数"
    } else if x < 32.0 {
        "Chebyshev 展開"
    } else {
        "漸近展開"
    };
    rows.push((
        x,
        method,
        *value.value(),
        closed,
        (value.value() - closed).abs() / scale,
        value.absolute_error() / scale,
        (slope.value() - c0).abs() / (eps * c0.abs().max(1.0)),
    ));
}
let sci10 = serde_json::json!({ "notation": "scientific", "significantDigits": 10 });
let fixed1 = serde_json::json!({ "fractionDigits": 1 });
let columns = serde_json::json!([
    { "key": "0", "label": "x [-]", "type": "number" },
    { "key": "1", "label": "方法" },
    { "key": "2", "label": "積分 [-]", "type": "number", "format": sci10 },
    { "key": "3", "label": "閉形式 [-]", "type": "number", "format": sci10 },
    { "key": "4", "label": "差 [ε 単位]", "type": "number", "format": fixed1 },
    { "key": "5", "label": "推定誤差 [ε 単位]", "type": "number", "format": fixed1 },
    { "key": "6", "label": "導関数との差 [ε 単位]", "type": "number", "format": fixed1 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "identity" })
);
```

差の尺度は $\varepsilon\max(1, \lvert\text{閉形式}\rvert)$ で、閉形式自身も 4 つの関数値の丸めを含むので、数 $\varepsilon$ の差は一致とみなす。
$J_0$ の差は $x = 8$ で 58、$x = 11.9$ で 1743 $\varepsilon$ 単位に増え、境界の上の $x = 12.1$ で 0.5 に戻る。
$Y_0$ でも $x = 11.9$ で 2249 $\varepsilon$ 単位になる。
これは前節で述べた級数の打ち消しである。
オプション付き形式の推定誤差は同じ点で $5.8 \times 10^5$ $\varepsilon$ 単位と、実際の差よりさらに大きく、劣化を安全側に返している。
差は絶対誤差で $4 \times 10^{-13}$ 程度なので多くの用途では問題にならないが、`f64` の丸めの水準を要するときは推定誤差を確かめる。
Chebyshev 展開と漸近展開の区間では、差は 10 $\varepsilon$ 単位以下である。

## まとめ

Struve 関数 $\mathbf{H}_\nu$、$\mathbf{L}_\nu$ は2 ワードの算術の級数と、$x \ge 20$ で受理されたときの Bessel 関数と漸近展開の和で評価する。
漸近展開が受理されるのは一般の次数では $x$ が 30 前後を超えてから、半整数次では $x = 20$ からである。
`f64` の $\mathbf{H}_\nu$、$\mathbf{L}_\nu$ は $\nu \in [-5, 10]$、$x \in [10^{-3}, 100]$ で 64 ULP を目標にし、その外と `f32` ではオプション付き形式の推定誤差を読む。
0 次の Bessel・Struve 関数の積分は、級数、Chebyshev 展開、漸近展開を $x = 12$ と $32$ で切り替え、$x = 12$ のすぐ下では級数の打ち消しで誤差が $10^3\varepsilon$ 程度まで増える。
`complement` と `remainder` は被積分関数から定数を引いた形の積分であって裾ではないので、裾が要るときは `_tail_integral` の関数か極限値からの差を使う。
Coulomb の長距離ポテンシャルの散乱は [Coulomb 波動関数と水素様動径状態](../coulomb-and-hydrogenic/) で、二次のポテンシャルの解は [放物柱関数](../parabolic-cylinder-functions/) で、項目ごとの仕様は [Kelvin・Struve・放物柱関数](../../api/kelvin-struve-parabolic/) で確かめる。
