正弦積分、余弦積分、Fresnel 積分は、$\sin t/t$、$\cos t/t$、$\cos(\pi t^2/2)$ のような振動する初等関数の積分で定義される関数である。
アンテナ理論と Fourier 級数の Gibbs 現象に $\operatorname{Si}$ と $\operatorname{Ci}$ が、波動光学の回折と道路や線路の緩和曲線（クロソイド）に Fresnel 積分が現れる。
双曲線正弦積分 $\operatorname{Shi}$ と双曲線余弦積分 $\operatorname{Chi}$ は、被積分関数の $\sin$ と $\cos$ を $\sinh$ と $\cosh$ に替えた積分で、指数積分 $\operatorname{Ei}$ と $E_1$ の和と差で書ける。
大きな引数では値が振動しながら極限に近づくので、`scioxide-special` は振動を補助関数で分け、原点の近くでは Chebyshev 展開、遠くでは漸近展開を使う。
このページは定義と性質、区間の分け方と評価法、精度の保証、API の使い分けを説明し、二つのセルで方形波の Gibbs 現象と直線の縁による回折を確かめる。
$\operatorname{Shi}$ と $\operatorname{Chi}$ が使う $\operatorname{Ei}$ と $E_1$ の評価は [指数積分と対数積分](../exponential-and-trigonometric-integrals/) で扱う。

## 定義と性質

### 正弦積分と余弦積分

正弦積分と余弦積分を次の式で定義する（DLMF §6.2）。

$$
\operatorname{Si}(x) = \int_0^x \frac{\sin t}{t}\,dt, \qquad
\operatorname{Ci}(x) = \gamma + \ln x + \int_0^x \frac{\cos t - 1}{t}\,dt \quad (x > 0)
$$

$\gamma = 0.57721\ldots$ は Euler の定数である。
$\operatorname{Si}$ は奇関数で整関数であり、$x \to \infty$ で $\pi/2$ に近づく。
最大値は $x = \pi$ の $\operatorname{Si}(\pi) = 1.85193\,70519\ldots$ で、これが Gibbs 現象の行き過ぎの大きさを決める。
$\operatorname{Ci}$ は原点で $\gamma + \ln x$ のように発散し、$x \to \infty$ で振動しながら 0 に近づく。
正の零点は $0.61650\ldots$、$3.38418\ldots$、$6.42704\ldots$ と続き、しだいに $k\pi$ に近づく。

大きな $x$ では、補助関数 $f$、$g$ を使って振動を分けて書く（DLMF §6.2、§6.12）。

$$
\operatorname{Si}(x) = \frac{\pi}{2} - f(x)\cos x - g(x)\sin x, \qquad
\operatorname{Ci}(x) = f(x)\sin x - g(x)\cos x
$$

ここで $f(x) \sim \frac{1}{x}\sum_k (-1)^k \frac{(2k)!}{x^{2k}}$、$g(x) \sim \frac{1}{x^2}\sum_k (-1)^k \frac{(2k+1)!}{x^{2k}}$ は滑らかに減る関数で、級数は漸近展開である。
漸近展開は発散級数だが、項がいちばん小さくなる所で打ち切ると、その項の大きさ程度の誤差で値を与える。

### 双曲線正弦積分と双曲線余弦積分

双曲線正弦積分と双曲線余弦積分は、$x > 0$ で次の式になる（DLMF §6.2）。

$$
\operatorname{Shi}(x) = \int_0^x \frac{\sinh t}{t}\,dt = \frac{\operatorname{Ei}(x) + E_1(x)}{2}, \qquad
\operatorname{Chi}(x) = \gamma + \ln x + \int_0^x \frac{\cosh t - 1}{t}\,dt = \frac{\operatorname{Ei}(x) - E_1(x)}{2}
$$

$\operatorname{Shi}$ は奇関数で整関数、$\operatorname{Chi}$ は原点に対数特異性を持ち、どちらも $e^{x}/(2x)$ のように増える。

### 逆正接積分

逆正接積分は $\operatorname{Ti}_2(x) = \int_0^x \arctan t / t\,dt$ である。
奇関数で、$\operatorname{Ti}_2(1)$ は Catalan の定数 $G = 0.91596\,55941\ldots$ に等しい。
$x > 0$ では反転公式 $\operatorname{Ti}_2(x) = \operatorname{Ti}_2(1/x) + \frac{\pi}{2}\ln x$ が成り立つ（Lewin 1981）。

### Fresnel 積分

Fresnel 積分を次の式で定義する（DLMF 7.2.7、7.2.8）。

$$
C(z) = \int_0^z \cos\!\left(\frac{\pi t^2}{2}\right)dt, \qquad S(z) = \int_0^z \sin\!\left(\frac{\pi t^2}{2}\right)dt
$$

どちらも奇関数で整関数であり、$x \to +\infty$ で $1/2$ に近づく。
平面上の点 $(C(x), S(x))$ が描く曲線は Cornu 螺旋（クロソイド）と呼ばれ、弧長 $x$ に比例して曲率が増える。
大きな $x$ では補助関数で振動を分ける（DLMF §7.5）。

$$
C(x) = \frac12 + f(x)\sin\frac{\pi x^2}{2} - g(x)\cos\frac{\pi x^2}{2}, \qquad
S(x) = \frac12 - f(x)\cos\frac{\pi x^2}{2} - g(x)\sin\frac{\pi x^2}{2}
$$

$f(x) \sim 1/(\pi x)$、$g(x) \sim 1/(\pi^2 x^3)$ なので、螺旋は半径およそ $1/(\pi x)$ で中心 $(1/2, 1/2)$ に巻き込む。
複素数の $z$ では、誤差関数との関係 $C(z) + iS(z) = \frac{1+i}{2}\operatorname{erf}\!\left(\frac{\sqrt\pi}{2}(1-i)z\right)$ が成り立つ（DLMF §7.5）。

## 区間の分割と評価法

原点のまわりの級数は小さな $x$ で速く収束するが、$x$ が大きいと項が大きく育ってから打ち消し合い、丸め誤差が残る。
漸近展開は大きな $x$ で少ない項数で済むが、小さな $x$ では最小の項が大きく、精度が出ない。
その間の区間には、あらかじめ最大相対誤差を小さくするように係数を決めた固定次数の有理近似 $P(t)/Q(t)$ か、Chebyshev 展開 $\sum_k c_k T_k(t)$ を使う。
Chebyshev 展開は区間を $t \in [-1, 1]$ に写して Clenshaw の漸化式で和を取る方法で、計算コストは係数の数に比例し、入力によらない。

### Si と Ci

$|x| \le 4$ では、$t = (x^2 - 8)/8$ についての Chebyshev 展開 $T_{\mathrm{Si}}$、$T_{\mathrm{Ci}}$ を使い、次の形で値を作る。

$$
\operatorname{Si}(x) = x\left(\frac34 + T_{\mathrm{Si}}(t)\right), \qquad
\operatorname{Ci}(x) = \ln x - \frac12 + T_{\mathrm{Ci}}(t)
$$

$\operatorname{Ci}$ の対数特異性は $\ln x$ として展開の外に出してあり、展開が近似するのは $x^2$ の滑らかな関数だけである。
$|\operatorname{Ci}(x)| < 1/4$ になる二つの零点のまわりでは、係数の下位の桁まで含めて2 ワード（二つの binary64 の和で約 106 ビット）で和を取り直す。
このとき対数は、近くの中心 $c = 3/4$ または $c = 3$ を使い、$\ln x = \ln c + \ln(1 + (x - c)/c)$ と分けて丸め誤差を小さくする。

$4 < x < 48$ では補助関数 $f$、$g$ を $1/x^2$ の有理近似で求め（$(4, 8)$ と $[8, 48)$ で係数が異なる）、$x \ge 48$ では漸近展開を足す。
$x \ge 48$ では漸近展開の最小の項が binary64 の丸めより小さいので、項が $\varepsilon/4$ を下回った所で止めれば足りる（$\varepsilon = 2^{-52}$ は binary64 の機械イプシロン）。
この領域の $\operatorname{Ci}$ は $f\sin x$ と $g\cos x$ の差なので、推定誤差は絶対誤差で $\varepsilon/x$ の十数倍程度になり、零点の近くでは相対誤差が大きくなる。

### Shi と Chi

$|x| \le 1$ では原点のまわりの級数（$\operatorname{Chi}$ は $\gamma + \ln x$ を加える）を足す。
$|x| > 1$ では $\operatorname{Ei}$ と $E_1$ の尺度化した核を使い、$e^{-x}\operatorname{Shi}(x) = \frac12\left(e^{-x}\operatorname{Ei}(x) + e^{-2x}\,e^{x}E_1(x)\right)$ のように指数因子を外したまま組み合わせる。
二つの核の評価は [E1 と Ei の評価](oxref:special-expint-e1-ei) で説明する。
`shi_scaled` は $e^{-|x|}\operatorname{Shi}(x)$、`chi_scaled` は $e^{-x}\operatorname{Chi}(x)$ で、どちらも大きな $x$ で $1/(2x)$ に近づく。
通常の $\operatorname{Shi}$、$\operatorname{Chi}$ は $|x| \approx 717$ を超えるとオーバーフローする。

### 逆正接積分

`atanint` は $[0, 1]$ の Chebyshev 展開に $t$ を掛けた形を使い、$|x| > 1$ では反転公式で $1/|x|$ に写す。
奇関数なので、負の $x$ は $|x|$ の値の符号を変えて返す。

### Fresnel 積分の評価

実数の $x$ では、$[0, 1]$、$[1, 2]$、$[2, 4]$、$[4, 8]$ の各区間の Chebyshev 展開を使い、$C(x) = x\,T_C(x)$、$S(x) = x^3\,T_S(x)$ の形で原点での振る舞い $C \approx x$、$S \approx \pi x^3/6$ を外に出す。
$x > 8$ では $f$、$g$ の漸近展開を、項が増え始めるか $\varepsilon$ を下回るまで足す。

位相 $\pi x^2/2$ をそのまま binary64 で作ると、丸め誤差が $\varepsilon x^2$ に比例して増え、大きな $x$ では $\sin$ と $\cos$ の値が意味を失う。
実装は $x \cdot (x/2)$ を融合積和で上位と下位の二つの binary64 に正確に分け、それぞれの $\sin(\pi h)$、$\cos(\pi h)$ を $\pi$ の倍数として正確に還元してから加法定理で合わせる。
$|x| \ge 2^{53}$ では表せる $x$ がすべて偶数なので、$x^2/2$ は偶数で、位相は $2\pi$ の倍数になる。

複素数の $z$ では、$|z| \le 1.5$ で原点のまわりの級数を足し、それ以外では誤差関数との関係を複素誤差関数の核で評価する。
$\exp(\pi|\operatorname{Im} z^2|/2)$ のように増える値は、オプション付き形式では尺度化した形で持つ。
ただし位相 $\pi z^2/2$ やその正弦と余弦が binary64 の範囲を超えると、`NumericalInstability`（`Overflow`）を返す。

### 作業量の上限

`IntegralOptions` は作業量の上限だけを持ち、既定は 512 単位である。
有理近似と Chebyshev 展開は係数 1 個につき 1 単位、級数と漸近展開は 1 項につき 1 単位を使い、このページの関数はどれも数十単位で終わる。
上限の扱いは指数積分と共通で、[作業量の上限と計算コスト](oxref:special-expint-budget) で説明する。

## 精度の保証と推定誤差

独立に生成した高精度の参照値（160 桁と 240 桁の照合データ）で確かめた精度の目標は、次のとおりである。

| 関数 | binary64 の目標 | 補足 |
|---|---|---|
| `si`、`ci` | 8 ULP | $\lvert\operatorname{Ci}(x)\rvert < 1/(8(1+x))$ の零点の近くは絶対誤差で評価する |
| `shi`、`chi`、`shi_scaled`、`chi_scaled`、`atanint` | 一様な目標なし | binary32 と binary64 で値と推定誤差を試験する |
| `fresnel_c`、`fresnel_s`（実数・複素数） | 一様な目標なし | binary32 と binary64 で値と推定誤差を試験する |

ULP（unit in the last place）は、結果の型で隣り合う浮動小数点数の間隔を単位にした誤差である。
8 ULP の目標は binary64 についてのもので、binary32 には ULP の目標を定めていない。
零点の近くでは関数値が 0 に近づくので相対誤差は意味を失い、仕様は絶対誤差の上界になる。
$\operatorname{Ci}$ の $[0, 4]$ の零点の近くは2 ワードで計算し直して絶対誤差を小さくするが、相対誤差の目標はない。
一様な目標のない関数について、照合試験は binary64 で相対 $5 \times 10^{-11}$（値が小さいときは絶対 $5 \times 10^{-13}$）、binary32 で相対 $2 \times 10^{-4}$（絶対 $5 \times 10^{-6}$）以内であることと、実際の誤差が推定誤差の範囲に入ることを確かめている。

オプション付き形式の推定誤差は区間ごとの誤差モデルから作る。
$\operatorname{Si}$ と $\operatorname{Ci}$ の核では、照合データで包含を確かめた推定（`EstimateReliability::StatisticallyCalibrated`）として、核の誤差に相対 $2\varepsilon$ を加える。
それ以外の関数と上限で止まった評価は、誤差モデルによる推定（`ModelBased`）で、相対 $32\varepsilon$ を加える。
どちらも包含が保証された区間ではない。

## API

| 関数 | 計算する量 | 定義域と主なエラー | オプション付き形式 | スコープ付き API |
|---|---|---|---|---|
| `si` | $\operatorname{Si}(x)$ | すべての有限の $x$ | `si_with_options` | `si_scoped` |
| `ci` | $\operatorname{Ci}(x)$ | $x = 0$ は `Pole`、$x < 0$ は `OutsideDomain` | `ci_with_options` | `ci_scoped` |
| `shi` | $\operatorname{Shi}(x)$ | すべての有限の $x$ | `shi_with_options` | `shi_scoped` |
| `shi_scaled` | $e^{-\lvert x\rvert}\operatorname{Shi}(x)$ | すべての有限の $x$ | `shi_scaled_with_options` | `shi_scaled_scoped` |
| `chi` | $\operatorname{Chi}(x)$ | $x = 0$ は `Pole`、$x < 0$ は `OutsideDomain` | `chi_with_options` | `chi_scoped` |
| `chi_scaled` | $e^{-x}\operatorname{Chi}(x)$ | `chi` と同じ | `chi_scaled_with_options` | `chi_scaled_scoped` |
| `atanint` | $\operatorname{Ti}_2(x)$ | すべての有限の $x$ | `atanint_with_options` | なし |
| `fresnel_c` | $C(z)$、実数と複素数 | 複素数で値が範囲を超えると `Overflow` | `fresnel_c_with_options` | `fresnel_c_scoped` |
| `fresnel_s` | $S(z)$、実数と複素数 | 複素数で値が範囲を超えると `Overflow` | `fresnel_s_with_options` | `fresnel_s_scoped` |

エラーは `SciOxideError` で返り、`kind()` が `DomainError` のとき `view()` の詳細が `Pole` か `OutsideDomain` になる。
入力が有限でなければ `NonFinite`、通常の値が型の範囲を超えれば `NumericalInstability`（`Overflow`）である。
`fresnel_c` と `fresnel_s` だけが `NumericScalar` を受け付け、ほかの関数は実数（`RealScalar`）だけを受け付ける。

標準形式 `f(x)` は値だけを返す。
オプション付き形式 `f_with_options(x, options)` は `IntegralOptions` を受け取り、`SpecialFunctionResult` に通常の値 `value()`、2 の冪で表した値 `scaled()`、対数形 `logarithmic()`、$x$ についての導関数 `derivative()` をそれぞれの推定誤差とともに入れ、終了状態、計算量の計数、アルゴリズムの識別子を添える。
オプション付き形式の通常の値は標準形式の値とビット単位で等しい。
スコープ付き API `f_scoped(x, options, scope)` はオプション付き形式と同じ結果を計算し、そのとき呼び出し元の `SolveScope` の中で計算量を数え、取り消しと期限を確かめる。
`atanint` にはスコープ付き API がないので、オプション付き形式を使う。

$\operatorname{Shi}$ と $\operatorname{Chi}$ の大きな引数では値がオーバーフローするので、`shi_scaled`、`chi_scaled` を使う。
名前付きの尺度化形（`_scaled`）は指数因子を外した別の関数で、オプション付き形式の `scaled()`（同じ値を 2 の冪で表し直したもの）とは違う。

## 方形波の Gibbs 現象と Si(π)

方形波 $\operatorname{sgn}(\sin x)$ の Fourier 級数を奇数次の $M$ 項で打ち切った部分和は次の式である。

$$
S_M(x) = \frac{4}{\pi}\sum_{k=1}^{M}\frac{\sin((2k-1)x)}{2k-1}
$$

$S_M'(x) = \frac{2\sin(2Mx)}{\pi\sin x}$ なので、不連続点 $x = 0$ の右の最初の極大は $x_M = \pi/(2M)$ にある。
和を $t_k = (2k-1)x$ の刻み $2x$ の中点則と見ると $S_M(x) \approx \frac{2}{\pi}\operatorname{Si}(2Mx)$ であり、極大値は $M \to \infty$ で $\frac{2}{\pi}\operatorname{Si}(\pi) = 1.17897\ldots$ に近づく。
跳びの大きさ 2 に対して行き過ぎは約 $0.179$、すなわち跳びの約 9% で、項を増やしても減らない。
これが Gibbs 現象である。
中点則の誤差の主要項 $-\frac{h^2}{24}(f'(\pi) - f'(0))$（$f(t) = \sin t/t$、$h = \pi/M$、$f'(\pi) = -1/\pi$）から、$S_M(x_M) - \frac{2}{\pi}\operatorname{Si}(\pi) \approx \frac{1}{12M^2}$ も分かる。

次のセルは $S_M(x_M)$ を f64 の標準関数で直接足し、`si(π)` から作った極限との差に $12M^2$ を掛けた値が 1 に近づくことを確かめる。
これは $\operatorname{Si}(\pi)$ を、`si` とは独立な和で $O(M^{-4})$ まで検算することになる。
図には入力の $M$ の部分和と $\frac{2}{\pi}\operatorname{Si}(2Mx)$（破線）を不連続点の近くで重ねて描く。

//| ref: special-si-gibbs-overshoot

//| run: reactive
//| crates: [scioxide-special]
//| inputs:

//| cases:
//|   - {"id":"few-terms","label":"M = 2","description":"項が少ないと 12M² × 差は 1 から離れる。","inputs":{"harmonics":2}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"gibbs","path":"/rows/0/3","approx":{"value":1.1789797444721672,"rtol":1e-14}}

//|       - {"artifact":"gibbs","path":"/rows/3/5","approx":{"value":1.0,"atol":2e-5}}

// 部分和 S_M(x) を f64 の標準関数で直接足す（si とは独立な検算）。
let partial_sum = |m: usize, x: f64| {
    let sum: f64 = (1..=m)
        .map(|k| {
            let n = (2 * k - 1) as f64;
            (n * x).sin() / n
        })
        .sum();

    let gap = value - limit;
    rows.push((
        m as u32,
        peak,
        value,
        limit,
        gap,
        12.0 * (m * m) as f64 * gap,
    ));
}

既定の $M = 8$ では極大値 $S_8(x_8) = 1.18028$ が極限 $\frac{2}{\pi}\operatorname{Si}(\pi) = 1.1789797444721672$ より $1.3 \times 10^{-3}$ 大きく、$12M^2 \times$ 差は 1.0018 である。
$M$ を 4 倍するごとに差は約 1/16 になり、$M = 512$ で $12M^2 \times$ 差は $1 + 4.4 \times 10^{-7}$ になる。
差から $1/(12M^2)$ を引いた残りは $M = 512$ で $1.4 \times 10^{-13}$ で、中点則の次の項 $O(M^{-4})$ の大きさにとどまるので、`si(π)` の値は独立な直接和とこの桁まで整合する。

$M = 2$ のような少ない項では、二つの曲線のずれが目で見え、表の 1 行目の $12M^2 \times$ 差も 1.03 に離れる。
逆に $M = 64$ を選ぶと最後の行は 4096 項になり、差 $5 \times 10^{-9}$ に直接和の丸め $10^{-15}$ 程度が効いて、$12M^2 \times$ 差は $1 - 3.3 \times 10^{-7}$ と 1 の下にずれる。

## 直線の縁による Fresnel 回折

半平面の遮蔽板の縁に平面波（波長 $\lambda$）が当たると、距離 $z$ の観測面の強度は、縁からの位置 $x$ を無次元の Fresnel 変数 $v = x\sqrt{2/(\lambda z)}$ に直して次の式になる（Born & Wolf 1999、§8.7）。

$$
\frac{I(v)}{I_0} = \frac12\left[\left(C(v) + \frac12\right)^2 + \left(S(v) + \frac12\right)^2\right]
$$

$I_0$ は遮蔽板がないときの強度で、$v < 0$ が幾何光学の影、$v > 0$ が照らされた側である。
縁の真上 $v = 0$ では $I/I_0 = 1/4$ が正確に成り立つ。
照らされた側の最初の極大は $dI/dv = (C + \frac12)\cos\frac{\pi v^2}{2} + (S + \frac12)\sin\frac{\pi v^2}{2} = 0$ の最初の正の根で、強度は $I_0$ の約 1.37 倍になる（Born & Wolf 1999）。

次のセルは波長 $\lambda$ と距離 $z$ を選び、強度分布を観測面の位置 $x \in [-2, 4]$ mm の固定した軸で描き、最初の極大を二分法で求める。
二つ目の図は Cornu 螺旋 $(C(v), S(v))$ で、表の最後の列は、大きな $v$ での中心 $(1/2, 1/2)$ からの距離に $\pi v$ を掛けた値が 1 に近づくこと（補助関数 $f \sim 1/(\pi v)$ の検算）を示す。

```rust
//| id: special-fresnel-clothoid-limit
//| ref: special-fresnel-clothoid-limit
//| title: 直線の縁による Fresnel 回折と Cornu 螺旋
//| run: reactive
//| crates: [scioxide-special]
//| inputs:
//|   wavelength_nm: {"type":"range","label":"波長 λ [nm]","min":400,"max":700,"step":1,"value":633}
//|   distance_m: {"type":"range","label":"縁から観測面までの距離 z [m]","min":0.1,"max":5,"step":0.1,"value":1}
//|   spiral_end: {"type":"range","label":"螺旋を描く |v| の上限","min":2,"max":8,"step":0.5,"value":4}
//| cases:
//|   - {"id":"blue-near","label":"λ = 400 nm、z = 0.1 m","description":"λz が小さいと縞の間隔が狭くなる。強度の値は変わらない。","inputs":{"wavelength_nm":400,"distance_m":0.1}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"edge","path":"/rows/0/0","approx":{"value":1.2172,"atol":1e-3}}
//|       - {"artifact":"edge","path":"/rows/0/1","approx":{"value":0.6848,"atol":1e-3}}
//|       - {"artifact":"edge","path":"/rows/0/2","approx":{"value":1.3704,"atol":1e-3}}
//|       - {"artifact":"edge","path":"/rows/0/3","approx":{"value":0.25,"atol":1e-15}}
//|       - {"artifact":"edge","path":"/rows/0/4","approx":{"value":1.0,"atol":1e-3}}
//|   - case: blue-near
//|     expect:
//|       - {"artifact":"edge","path":"/rows/0/1","approx":{"value":0.1721,"atol":1e-3}}
//|       - {"artifact":"edge","path":"/rows/0/2","approx":{"value":1.3704,"atol":1e-3}}
use scioxide_special::{fresnel_c, fresnel_s};
use std::f64::consts::PI;

// 位置 x [m] と Fresnel 変数 v の換算係数 √(λz/2)。
let scale = (wavelength_nm * 1e-9 * distance_m / 2.0).sqrt();
let intensity = |v: f64| -> Result<f64, String> {
    let c = fresnel_c(v).map_err(|e| e.to_string())? + 0.5;
    let s = fresnel_s(v).map_err(|e| e.to_string())? + 0.5;
    Ok(0.5 * (c * c + s * s))
};
// dI/dv（位相の cos と sin は f64 の標準関数による）。
let slope = |v: f64| -> Result<f64, String> {
    let phase = 0.5 * PI * v * v;
    let c = fresnel_c(v).map_err(|e| e.to_string())? + 0.5;
    let s = fresnel_s(v).map_err(|e| e.to_string())? + 0.5;
    Ok(c * phase.cos() + s * phase.sin())
};

// 最初の極大を二分法で求める。dI/dv は v = 1 で正、v = 1.5 で負。
let (mut lo, mut hi) = (1.0_f64, 1.5_f64);
for _ in 0..60 {
    let mid = 0.5 * (lo + hi);
    if slope(mid)? > 0.0 {
        lo = mid;
    } else {
        hi = mid;
    }
}
let v_peak = 0.5 * (lo + hi);
// 中心 (1/2, 1/2) からの距離 × πv（大きな v での補助関数の検算）。
let far = 50.0;
let dc = fresnel_c(far).map_err(|e| e.to_string())? - 0.5;
let ds = fresnel_s(far).map_err(|e| e.to_string())? - 0.5;
let rows = vec![(
    v_peak,
    v_peak * scale * 1e3,
    intensity(v_peak)?,
    intensity(0.0)?,
    PI * far * (dc * dc + ds * ds).sqrt(),
)];
let sig5 = serde_json::json!({ "significantDigits": 5 });
let sig16 = serde_json::json!({ "significantDigits": 16 });
let columns = serde_json::json!([
    { "key": "0", "label": "極大の v [-]", "type": "number", "format": sig5 },
    { "key": "1", "label": "極大の位置 x [mm]", "type": "number", "format": sig5 },
    { "key": "2", "label": "極大の I/I₀ [-]", "type": "number", "format": sig5 },
    { "key": "3", "label": "縁の上の I/I₀ [-]", "type": "number", "format": sig16 },
    { "key": "4", "label": "v = 50 の πv × 中心からの距離 [-]", "type": "number", "format": sig5 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "edge" })
);

// 強度分布: 観測面の x ∈ [−2, 4] mm を固定した軸で描き、λz による縞の伸縮を見せる。
let mut profile = Vec::new();
for i in 0..=2400 {
    let x_mm = -2.0 + 6.0 * i as f64 / 2400.0;
    profile.push([x_mm, intensity(x_mm * 1e-3 / scale)?]);
}
emit_line_chart!(
    &vec![serde_json::json!({ "name": "I/I₀", "points": profile })],
    options = &serde_json::json!({
        "xLabel": "縁からの位置 x [mm]",
        "yLabel": "相対強度 I/I₀ [-]",
        "xMin": -2.0,
        "xMax": 4.0,
        "yMin": 0.0,
        "yMax": 1.5,
        "annotations": [
            { "kind": "line", "axis": "y", "value": 1.0, "label": "遮蔽なし" },
            { "kind": "line", "axis": "x", "value": 0.0, "label": "縁" }
        ]
    })
);

// Cornu 螺旋 (C(v), S(v))、v ∈ [−v_max, v_max]。
let mut spiral = Vec::new();
for i in 0..=1200 {
    let v = spiral_end * (2.0 * i as f64 / 1200.0 - 1.0);
    spiral.push([
        fresnel_c(v).map_err(|e| e.to_string())?,
        fresnel_s(v).map_err(|e| e.to_string())?,
    ]);
}
emit_line_chart!(
    &vec![serde_json::json!({ "name": "(C(v), S(v))", "points": spiral })],
    options = &serde_json::json!({
        "xLabel": "C(v) [-]",
        "yLabel": "S(v) [-]",
        "xMin": -0.8,
        "xMax": 0.8,
        "yMin": -0.8,
        "yMax": 0.8
    })
);
```

既定の $\lambda = 633$ nm、$z = 1$ m では、最初の極大は $v = 1.2172$、観測面の位置で縁から $0.685$ mm にあり、強度は $I/I_0 = 1.3704$ である。
これは Born & Wolf の約 1.37 倍と一致し、縁の上の値は 0.25 に丸めの範囲で一致する。
$v$ の値と強度は $\lambda$ と $z$ によらず、位置だけが $\sqrt{\lambda z/2}$ に比例して動く。
`blue-near`（$\lambda = 400$ nm、$z = 0.1$ m）では極大の位置が $0.172$ mm に縮み、強度は 1.3704 のままである。
最後の列は $v = 50$ で $1 - 4 \times 10^{-8}$ で、中心からの距離が漸近形 $1/(\pi v)$ にこの精度で従うことを示す。
正しい図では、影の側（$x < 0$）で強度が単調に 0 へ減り、照らされた側で 1 のまわりを振動しながら振幅が減る。
照らされた側の振動が 1 を中心にしない図が出たら、$C$ と $S$ の符号か位相の扱いを疑う。

## まとめ

`si` と `ci` は binary64 で 8 ULP を目標にし、$\operatorname{Ci}$ の零点の近くは絶対誤差で評価する。
$\operatorname{Shi}$、$\operatorname{Chi}$、逆正接積分、Fresnel 積分には一様な ULP の目標がないので、精度が必要ならオプション付き形式の推定誤差を読む。
大きな引数で値が binary64 の範囲を超える $\operatorname{Shi}$ と $\operatorname{Chi}$ には、`shi_scaled`、`chi_scaled` か、オプション付き形式の `scaled()` と `logarithmic()` を使う。
Fresnel 積分は位相 $\pi x^2/2$ を正確に還元するので、大きな $x$ でも $C$ と $S$ が $1/2$ のまわりで正しく振動することを、Cornu 螺旋の半径 $1/(\pi v)$ で確かめた。

$\operatorname{Shi}$ と $\operatorname{Chi}$ が使う $\operatorname{Ei}$ と $E_1$ の領域の分け方と零点の近くの精度を確かめるには [指数積分と対数積分](../exponential-and-trigonometric-integrals/) に戻る。
複素数の Fresnel 積分が使う複素誤差関数と Faddeeva 関数の扱いは [Faddeeva 関数と Voigt プロファイル](../faddeeva-and-voigt/) で確かめる。
