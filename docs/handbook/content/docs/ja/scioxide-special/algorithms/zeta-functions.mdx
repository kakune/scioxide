Riemann ゼータ関数は素数の分布を表す関数として知られ、物理では Bose–Einstein 統計と黒体放射の積分（$\int_0^\infty x^3/(e^x - 1)\,dx = \pi^4/15 = 6\zeta(4)$）や、Casimir 効果の正則化に現れる。
Hurwitz ゼータ関数は和の始まりをずらした一般化で、ポリガンマ関数 $\psi^{(m)}(q) = (-1)^{m+1} m!\,\zeta(m+1, q)$ や、格子和、離散分布の裾の和に使われる。
定義の Dirichlet 級数は $\operatorname{Re} s > 1$ でしか収束せず、収束しても遅いので、`scioxide-special` は定義の級数を直接は足さず、区間ごとの Chebyshev 展開、関数等式、Euler–Maclaurin の和公式、$q = 1$ のまわりの Taylor 級数を使い分ける。
このページは定義と性質、評価法、精度の保証、API を説明し、セルで定義の級数の遅い収束と Euler–Maclaurin の補正の効果を確かめる。
ゼータ関数を一般化する多重対数と Lerch の超越関数は [一般の位数の多重対数と Lerch の超越関数](../polylog-and-lerch/) で扱う。

## 定義と性質

### Riemann ゼータ関数

Riemann ゼータ関数は $\operatorname{Re} s > 1$ で Dirichlet 級数として定義される（DLMF 25.2.1）。

$$
\zeta(s) = \sum_{n=1}^\infty \frac{1}{n^s}
$$

$s = 1$ に留数 1 の 1 位の極を持ち、それ以外の複素平面へ有理型関数として解析接続される。
接続した関数は関数等式 $\zeta(s) = 2^{s}\pi^{s-1}\sin(\pi s/2)\Gamma(1-s)\zeta(1-s)$（DLMF §25.4）を満たし、$s = -2, -4, \ldots$ に自明な零点を持つ。
既知の値には $\zeta(2) = \pi^2/6$、$\zeta(0) = -1/2$、$\zeta(-1) = -1/12$ がある。
`riemann_zeta(1.0)` は `DomainError`（`Pole`）を返し、負の偶数では正確に 0 を返す。

### Dirichlet eta 関数

符号を交互にした Dirichlet eta 関数は次の式で定義される（DLMF §25.2）。

$$
\eta(s) = \sum_{n=1}^\infty \frac{(-1)^{n-1}}{n^s} = \left(1 - 2^{1-s}\right)\zeta(s)
$$

交代級数は $\operatorname{Re} s > 0$ で収束し、$\eta$ は整関数に接続される。
$s = 1$ では $\zeta$ の極と $1 - 2^{1-s}$ の零が打ち消し合い、$\eta(1) = \ln 2$ になる。
`dirichlet_eta` は極を持たず、$\eta(0) = 1/2$ を返す。

### Hurwitz ゼータ関数

Hurwitz ゼータ関数は $\operatorname{Re} s > 1$、$q > 0$ で次の式で定義され（DLMF 25.11.1）、$s = 1$ に極を持つ有理型関数に接続される。

$$
\zeta(s, q) = \sum_{n=0}^\infty \frac{1}{(n+q)^{s}}
$$

$\zeta(s, 1) = \zeta(s)$、$\zeta(s, 1/2) = (2^s - 1)\zeta(s)$ で、シフトの漸化式 $\zeta(s, q) = \zeta(s, q+1) + q^{-s}$ が成り立つ。
$s = 0$ と $s = -1$ では Bernoulli 多項式による閉形式 $\zeta(0, q) = 1/2 - q$、$\zeta(-1, q) = -(q^2 - q + 1/6)/2$ になる（DLMF 25.11.14）。

## 評価法

### 実数の Riemann ゼータ関数と eta 関数

実数の `riemann_zeta` は定義の級数を使わず、次の区間ごとの方法で評価する。

| $s$ の範囲 | 方法 |
|---|---|
| $0 < s \le 2$ | 極を除いた $(s-1)\zeta(s)$ の Chebyshev 展開を $s - 1$ で割る |
| $2 < s \le 24$ | $\zeta(s) - 1$ の Chebyshev 展開（$[2, 4]$、$[4, 8]$、$[8, 16]$、$[16, 24]$） |
| $s > 24$ | $1 + 2^{-s} + 3^{-s} + 4^{-s}$。省いた裾は $4^{1-s}/(s-1)$ 以下 |
| $s = 0$ | $-1/2$ |
| $-1 \le s < 0$ | Chebyshev 展開 |
| $s < -1$ | 関数等式の各因子の対数を2 ワード（二つの binary64 の和で約 106 ビット）で足し、最後に指数を取る。負の偶数は 0 |

$0 < s \le 2$ で $(s-1)\zeta(s)$ を近似するのは、極 $1/(s-1)$ を展開の外に出すと、残りが $s$ の滑らかな関数になり、少ない係数で近似できるからである。
$s < -1$ で関数等式を対数の形で組み合わせるのは、$\Gamma(1-s)$ と $(2\pi)^{s}$ が別々には範囲を超えても、積は表せる場合があるからである。
$s$ が負で大きいと $\Gamma(1-s)$ が支配して $|\zeta(s)|$ が増え、binary64 では $s$ がおよそ $-260$ より小さいと（負の偶数を除き）`NumericalInstability`（`Overflow`）になる。

実数の `dirichlet_eta` は $0 < s \le 2$ と $-1 \le s < 0$ で専用の Chebyshev 展開を使い、$s > 2$ では $1 - 2^{1-s}$ を `expm1` で作って $\zeta(s)$ に掛け、$s < -1$ では関数等式の対数の形に $\ln(2^{1-s} - 1)$ を加える。
$\eta$ は $\zeta$ より $2^{1-s}$ 倍ほど大きくなるので、binary64 では $s$ がおよそ $-218$ より小さいとオーバーフローする。
binary32 の $s \le 0$ は binary64 で計算して丸める。

### 複素数の Riemann ゼータ関数

複素数の $\zeta(s)$ は $\operatorname{Re} s \ge -1/2$ で Euler–Maclaurin の和公式、$\operatorname{Re} s < -1/2$ で $\pi s/2$ の位相を正確に還元した関数等式を使う。
関数等式の推定誤差には対数の形で組み合わせた因子の丸めを含める。
複素数の $\eta(s)$ は $-\operatorname{expm1}((1-s)\ln 2)$ を $\zeta(s)$ に掛ける。

### Euler–Maclaurin の和公式

Euler–Maclaurin の和公式は、和の最初の $N$ 項だけを直接足し、残りの裾を積分と Bernoulli 数 $B_{2k}$ の補正で置き換える（DLMF 2.10.1）。

$$
\sum_{n=N}^{\infty} f(n) = \int_N^\infty f(x)\,dx + \frac{f(N)}{2} - \sum_{k=1}^{K} \frac{B_{2k}}{(2k)!} f^{(2k-1)}(N) + R_K
$$

$f(x) = (x + q)^{-s}$ では $f^{(2k-1)}$ が閉じた形で書け、補正の項は $N$ が大きいほど速く減る。
ただし補正の級数そのものは発散級数なので、項が増え始める前に止め、最後の項の大きさを剰余 $R_K$ の推定に使う。

### 実数の Hurwitz ゼータ関数

$s > 1$ の実数の `hurwitz_zeta` は先頭の $q^{-s}$ を外に出して正規化した和に Euler–Maclaurin の和公式を使う。
$s > 1$ では全項が正なので、`hurwitz_zeta_log` は同じ和から $\ln\zeta(s, q)$ を、$\zeta(s, q)$ を作らずに求める。
$\zeta(1000, 2) \approx 2^{-1000}$ のように値がアンダーフローする場合でも、対数は表せる。

$s < 1$ の実数の `hurwitz_zeta` は次の順に方法を選ぶ。
$q = 1$ では `riemann_zeta` と同じ値を返し、$s = 0$ と $s = -1$ では上の閉形式を使う。
$s > -23$ で $q \ge \max(16, 2|s|)$ なら、裾の積分が支配して打ち消しが起きないので、先頭を引かずに Euler–Maclaurin の和を使う。
$s \le -8$ では、絶対収束する Hurwitz の Fourier 級数（DLMF 25.11.9）を使う。
それ以外では、$q = 1$ のまわりの Taylor 級数（DLMF 25.11.10）$\zeta(s, 1 + \delta) = \sum_k \binom{-s}{k}\zeta(s+k)\delta^k$（$|\delta| \le 1/2$）で求め、シフトの漸化式で $q$ に戻す。
推定誤差は、打ち切り、各成分の誤差、打ち消しを含めて導いた絶対誤差である。

### 複素数の Hurwitz ゼータ関数

複素数の `hurwitz_zeta` は、$s$ と $q$ がともに実数で $q > 0$ なら実数の経路を使う。
$\operatorname{Re} s \le 0$ では、シフトした $q$ が 1 の近く（距離 0.75 未満）にあれば同じ Taylor 級数を使い、それ以外は Hermite の積分表示（DLMF 25.11.29）を適応的な Gauss–Legendre の区間分割で積分する。
$\operatorname{Re} s > 0$ では Euler–Maclaurin の和公式を使う。
冪は主値 $(n + q)^{-s} = \exp(-s\ln(n + q))$ なので、$q$ の負の実軸が切断で、虚部の符号付きゼロが側を選び、$q = 0, -1, -2, \ldots$ が極である。

## 精度の保証と推定誤差

独立に生成した高精度の参照値（160 桁と 240 桁の照合データ）で確かめた精度の目標は次のとおりである。

| 関数 | 目標 | 補足 |
|---|---|---|
| 実数の `riemann_zeta`、`dirichlet_eta` | binary32 と binary64 で 64 ULP | 照合データは $\zeta$ で $s \in [-31.5, 64]$、$\eta$ で $s \in [-12.5, 20]$ |
| 実数の `hurwitz_zeta`（$s > 1$） | binary32 と binary64 で 64 ULP | 照合データは $q \in [0.1, 64]$ |
| 実数の `hurwitz_zeta`（$s < 1$） | 導出した絶対誤差の上界 | $s \in [-60, 1)$、$q \in (0, 1000]$ を試験する。零点の近くでは相対誤差が大きくなる |
| `hurwitz_zeta_log` | 独立の目標なし | 自然対数の単位で $\varepsilon(64 + \lvert\ln\zeta(s,q)\rvert)$ の絶対誤差を返す |
| 複素数の `riemann_zeta`、`dirichlet_eta`、`hurwitz_zeta` | 一様な目標なし | $\lvert\operatorname{Im} s\rvert$ が大きいと推定誤差が値と同じ大きさになり得る |

ULP（unit in the last place）は、結果の型で隣り合う浮動小数点数の間隔を単位にした誤差である。
64 ULP の目標を持つ実数の関数では、オプション付き形式の推定誤差は値の 64 ULP（照合データで包含を確かめた推定、`StatisticallyCalibrated`）である。
$s < 1$ の Hurwitz ゼータ関数の推定誤差は、打ち切りと丸めから導いた絶対誤差（誤差モデルによる推定、`ModelBased`）で、零点の近くで相対誤差が大きくなっても失敗としない。
どの推定誤差も包含が保証された区間ではない。

## API

| 関数 | 計算する量 | 定義域と主なエラー | オプション付き形式 | スコープ付き API |
|---|---|---|---|---|
| `riemann_zeta` | $\zeta(s)$、実数と複素数 | $s = 1$ は `Pole`、大きな負の $s$ は `Overflow` | `riemann_zeta_with_options` | `riemann_zeta_scoped` |
| `dirichlet_eta` | $\eta(s)$、実数と複素数 | 大きな負の $s$ は `Overflow` | `dirichlet_eta_with_options` | `dirichlet_eta_scoped` |
| `hurwitz_zeta` | $\zeta(s, q)$、実数と複素数 | $s = 1$ と $q = 0$ は `Pole`、実数で $q < 0$ は `OutsideDomain`、複素数で $q = -1, -2, \ldots$ は `Pole` | `hurwitz_zeta_with_options` | `hurwitz_zeta_scoped` |
| `hurwitz_zeta_log` | $\ln\zeta(s, q)$、$s > 1$、$q > 0$ の実数 | $s = 1$ と $q = 0$ は `Pole`、$s < 1$ と $q < 0$ は `OutsideDomain` | `hurwitz_zeta_log_with_options` | `hurwitz_zeta_log_scoped` |

エラーは `SciOxideError` で返り、`kind()` が `DomainError` のとき `view()` の詳細が `Pole` か `OutsideDomain` になる。
入力が有限でなければ `NonFinite`、値が型の範囲を超えれば `NumericalInstability`（`Overflow`）である。
`ZetaOptions` は作業量の上限だけを持ち、既定は 65536 単位である。
上限に達すると、標準形式もオプション付き形式も `ConvergenceFailure` を返す。
`riemann_zeta` と `dirichlet_eta` の引数はシグネチャの上では `x` という名前である。
`hurwitz_zeta` の $q$ は `impl Parameter<T>` なので、実数の $q$ と複素数の $s$ を組み合わせられる。

標準形式 `f(..)` は値だけを返す。
オプション付き形式 `f_with_options(.., options)` は同じ値に推定誤差、終了状態、計算量の計数、アルゴリズムの識別子を添える。
スコープ付き API `f_scoped(.., options, scope)` はオプション付き形式と同じ計算を呼び出し元の `SolveScope` の中で行い、取り消しと期限を確かめる。
値がアンダーフローする $s > 1$ の Hurwitz ゼータ関数や、尤度の計算のように対数が欲しい場面では `hurwitz_zeta_log` を使う。

## 定義の級数の遅い収束と Euler–Maclaurin の補正

定義の級数は遅く収束する。
部分和 $S_N = \sum_{n=1}^{N} n^{-s}$ の誤差は裾 $\sum_{n > N} n^{-s} \approx N^{1-s}/(s-1)$ で、$s = 2$ でも $N = 10^6$ 項で $10^{-6}$ が残る。
Euler–Maclaurin の和公式の最初の三項（積分、端の半分、$B_2$ の補正）を加えた $S_N + \frac{N^{1-s}}{s-1} - \frac12 N^{-s} + \frac{s}{12}N^{-s-1}$ は、次の補正 $-\frac{s(s+1)(s+2)}{720}N^{-s-3}$ の大きさの誤差しか残さない。

次のセルは $s$ を選び、$N = 1, 2, 4, \ldots, 32768$ の部分和の誤差を、`riemann_zeta(s)` との差として描く。
破線は積分による裾の推定 $N^{1-s}/(s-1)$ で、もう一つの系列は Euler–Maclaurin の三項を加えた和の誤差である。
部分和と補正は f64 の標準関数で足すので、補正後の誤差が丸めの水準まで下がれば、`riemann_zeta` の値を独立な計算で検算したことになる。
$s$ を極 $s = 1$ に近づけると、裾の推定がほとんど減らなくなる。

```rust
//| id: special-zeta-partial-sum
//| ref: special-zeta-partial-sum
//| title: ゼータ関数の定義級数の収束と Euler–Maclaurin の補正
//| run: reactive
//| crates: [scioxide-special]
//| inputs:
//|   exponent_s: {"type":"range","label":"指数 s","description":"極 s = 1 からの距離を変える。","min":1.1,"max":4,"step":0.1,"value":2}
//| cases:
//|   - {"id":"near-pole","label":"s = 1.1","description":"極の近くでは部分和の誤差がほとんど減らない。","inputs":{"exponent_s":1.1}}
//|   - {"id":"steep","label":"s = 4","description":"裾が小さく、部分和の誤差は足し算の丸めで止まる。","inputs":{"exponent_s":4}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"partial","path":"/rows/5/1","approx":{"value":3.0517e-5,"rtol":1e-3}}
//|       - {"artifact":"partial","path":"/rows/3/3","range":{"max":1e-14}}
//|   - case: near-pole
//|     expect:
//|       - {"artifact":"partial","path":"/rows/5/1","range":{"min":3}}
//|       - {"artifact":"partial","path":"/rows/5/3","range":{"max":1e-12}}
//|   - case: steep
//|     expect:
//|       - {"artifact":"partial","path":"/rows/2/3","range":{"max":1e-13}}
//|       - {"artifact":"partial","path":"/rows/5/2","approx":{"value":9.4739e-15,"rtol":1e-3}}
use scioxide_special::riemann_zeta;

let s = exponent_s;
let reference = riemann_zeta(s).map_err(|e| e.to_string())?;
let (mut plain, mut tail, mut corrected) = (Vec::new(), Vec::new(), Vec::new());
let mut rows = Vec::new();
let (mut sum, mut previous) = (0.0_f64, 0_usize);
for power in 0..=15 {
    let terms = 1_usize << power;
    // 部分和を n の昇順に足す（f64 の標準関数）。
    for n in previous + 1..=terms {
        sum += (n as f64).powf(-s);
    }
    previous = terms;
    let big_n = terms as f64;
    // 裾の推定（積分項）と Euler–Maclaurin の 3 項（f64 の標準関数）。
    let integral = big_n.powf(1.0 - s) / (s - 1.0);
    let euler_maclaurin =
        sum + integral - 0.5 * big_n.powf(-s) + s / 12.0 * big_n.powf(-s - 1.0);
    let plain_error = (reference - sum).abs();
    let corrected_error = (reference - euler_maclaurin).abs();
    // 誤差 0 の点は対数軸に描けないので図から除き、表では「0」と示す。
    if plain_error > 0.0 {
        plain.push([big_n, plain_error]);
    }
    if corrected_error > 0.0 {
        corrected.push([big_n, corrected_error]);
    }
    tail.push([big_n, integral]);
    if power % 3 == 0 {
        rows.push((
            terms as u32,
            Some(plain_error).filter(|e| *e > 0.0),
            integral,
            Some(corrected_error).filter(|e| *e > 0.0),
        ));
    }
}
emit_line_chart!(
    &vec![
        serde_json::json!({ "name": "部分和の誤差", "points": plain }),
        serde_json::json!({
            "name": "積分による裾の推定",
            "points": tail,
            "style": { "lineType": "dashed" }
        }),
        serde_json::json!({ "name": "Euler–Maclaurin 3 項を加えた誤差", "points": corrected })
    ],
    options = &serde_json::json!({
        "xLabel": "項数 N [-]",
        "yLabel": "ζ(s) との差の絶対値 [-]",
        "xType": "log",
        "yType": "log"
    })
);
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let columns = serde_json::json!([
    { "key": "0", "label": "N", "type": "integer" },
    { "key": "1", "label": "部分和の誤差 [-]", "type": "number", "format": sci3, "nullText": "0" },
    { "key": "2", "label": "N^(1−s)/(s−1) [-]", "type": "number", "format": sci3 },
    { "key": "3", "label": "補正後の誤差 [-]", "type": "number", "format": sci3, "nullText": "0" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "partial" })
);
```

$s = 2$ では、部分和の誤差は傾き $-1$ の直線で破線の裾の推定 $N^{-1}$ に重なり、$N = 32768$ でも $3.05 \times 10^{-5}$ が残る。
Euler–Maclaurin の三項を加えると、誤差は $N^{-s-3}$ の速さで減り、$N = 512$ で $6.7 \times 10^{-16}$ と丸めの水準に達するので、`riemann_zeta(2)` はこの独立な和と $10^{-15}$ の桁で一致する。
それより先では、部分和そのものの丸め誤差（$N = 4096$ で $9.8 \times 10^{-15}$）が残る。
`near-pole`（$s = 1.1$）では裾の推定 $N^{-0.1}/0.1$ がほとんど減らず、$N = 32768$ でも部分和の誤差は 3.5 である。
極の近くでは、定義の級数を足すだけでは値が求まらないが、補正を加えると $N = 512$ で誤差は $8.7 \times 10^{-14}$ になる。
`steep`（$s = 4$）では裾 $N^{-3}/3$ が小さく、$N = 32768$ の部分和の誤差 $2.8 \times 10^{-13}$ は裾の推定 $9.5 \times 10^{-15}$ より大きい。
これは $n^{-s}$ を大きい項から順に足したときの丸め誤差の蓄積で、級数の打ち切り誤差ではない。
表の「0」は誤差が binary64 でちょうど 0 になった点で、対数軸の図からは除いている。

## まとめ

実数の `riemann_zeta` と `dirichlet_eta`、$s > 1$ の `hurwitz_zeta` は binary32 と binary64 で 64 ULP を目標にし、$s < 1$ の `hurwitz_zeta` は導出した絶対誤差を推定誤差として返す。
ゼータ関数は定義の級数を使わず、区間ごとの Chebyshev 展開、関数等式、Euler–Maclaurin の和公式で評価するので、極 $s = 1$ の近くでも値が求まる。
大きな負の $s$ では値が binary64 の範囲を超え、$\zeta$ は $s \approx -260$、$\eta$ は $s \approx -218$ より先で `Overflow` になる。
値がアンダーフローする $s > 1$ の Hurwitz ゼータ関数には `hurwitz_zeta_log` を使う。
定義の級数を直接足すと極の近くでは何万項でも桁が出ないが、Euler–Maclaurin の三項の補正で数百項でも丸めの水準に届くことを、セルで確かめた。

ゼータ関数を一般化する多重対数と Lerch の超越関数の評価は [一般の位数の多重対数と Lerch の超越関数](../polylog-and-lerch/) で、Hurwitz ゼータ関数を使う複素数のポリガンマ関数は [Gamma 関数・polygamma 関数・Pochhammer 記号](../gamma-family/) で確かめる。
同じように級数の領域を変換と接続公式で分ける超幾何関数は [超幾何関数](../hypergeometric-and-zeta/) で扱う。
