このページはAiry 関数、円柱 Bessel 関数 $J_\nu, Y_\nu, I_\nu, K_\nu$、Hankel 関数、それらの引数についての導関数と指数尺度化形、および $K_\nu$ の対数、Jahnke–Emden の Lambda 関数、重み付き Bessel 積分の項目をまとめる。
Airy・Bessel・Hankel の演算は `NumericScalar` の一つの関数名で実数（`f32`、`f64`）と複素数（`Complex<f32>`、`Complex<f64>`）を受け取る。
Bessel・Hankel の次数 $\nu$ は引数 $z$ と同じ型か、$z$ が複素数なら実数で渡す（[`Parameter`](oxref:special-api-argument-types)）。
各行は値だけを返す標準形式、`SpecialFunctionResult` を返すオプション付き形式 `*_with_options`、求解スコープを受け取るスコープ付き API `*_scoped(.., options, scope)` を並べる（[三つの呼び出し形](oxref:special-api-call-forms)）。
計算量が引数と次数によって変わるので、このページの関数はすべてスコープ付き API を持つ。
作業量の上限は `AiryOptions`、`BesselOptions`、`BesselIntegralOptions`（いずれも既定 65536 単位）で与え、これらの型は[結果型とオプション](../results-and-options/)にある。
複数の次数をまとめて返す次数列の関数は提供しないので、次数ごとに呼ぶ。

## Airy 関数

Airy 関数は $y''(z) - z\,y(z) = 0$ の解で、整関数なので極はなく、有限な引数をすべて受け付ける。
非有限な入力は `NonFinite`、表せない結果は `NumericalInstability`（`Overflow`）、作業量の上限までに終わらない評価は `ConvergenceFailure` になる。
実数の $\lvert x\rvert \le 16$ は最寄りの整数のまわりの 35 次の Taylor 多項式（微分方程式から作り、打ち消しが起きる所では補償和で評価）、それより外は DLMF §9.7 の漸近展開を使う。
負の軸では位相を正確に縮約する。
実数の Ai・Bi とその尺度化形は、照合データ上で両精度とも 64 ULP を目標とし、零点の近くは条件数から求めた絶対誤差で判定する。
複素引数には一様な ULP の仕様はない。
オプション付き形式は表せる場合に導関数 $\operatorname{Ai}'(z)$、$\operatorname{Bi}'(z)$（尺度化形では同じ因子を掛けた導関数）も返す。

## 円柱 Bessel 関数 J・Y

ここで述べる規約は、この節から「導関数」の節までの円柱 Bessel 関数と Hankel 関数に共通し、オプションはどれも `BesselOptions` である。
複素数の次数と引数は主値の冪を使い、負の実軸に切断を置く。
虚部の符号付きゼロ（`+0i` と `-0i`）が切断の上側と下側を選び、複素数の原点は次数ごとの極限に従って特異な値を拒否する。
エラーの分類は、非有限な入力が `NonFinite`、定義域外と極が `DomainError`、表せない結果や破綻が `NumericalInstability`、上限内に終わらない計算が `ConvergenceFailure` である。
実数の次数と引数での J・Y・I・K（尺度化形を含む）と Hankel 関数は、照合データ上で両精度とも 64 ULP を目標とし、零点の近くは条件数から求めた絶対誤差で判定する。
J・Y の照合データは、次数 1000 未満で $x \le 10^8$ と、次数が $\sqrt{x}$ に近い場合を含む。
複素の次数・引数には一様な ULP の仕様はなく、オプション付き形式が推定誤差を返す。
複素数の次数と引数では、J は原点の近くで冪級数と Temme 級数、中程度の $\lvert z\rvert$ で Wronskian で正規化した Miller の後退漸化式、大きな $\lvert z\rvert$ で Hankel の漸近展開、$\lvert\nu\rvert \ge 64$ で Debye 展開を使う。
Y は原点の近くで Temme 級数、より大きな $\lvert z\rvert$ で尺度化した漸化式と接続公式を使う。

## 導関数

導関数は引数 $z$ についての $k$ 階（引数 `degree: u32`）の導関数で、次数 $\nu$ は固定し、引数の順は `(order, z, degree)` である。
階数 0 は関数値を返す。
$k$ 階の導関数は隣接次数の関数値の二項係数の和（$J$ では $2^{-k}\sum_m (-1)^m \binom{k}{m} J_{\nu-k+2m}$）で作るので、計算コストは $k$ に比例する。
Y・K・Hankel の導関数（尺度化形を含む）は階数 0 でも原点を `DomainError`（`Pole`）とする。
したがって `bessel_k_derivative(ν, 0.0, 0)` は、`bessel_k` の `Ok(+∞)` と異なりエラーになる。
J・I の導関数は、非整数の実次数で $\nu < k$ のとき、または複素次数で $\operatorname{Re}\nu \le k$ のとき、原点で導関数が有界でないので `Pole` になる。
$k$ が残りの上限を超えると `ConvergenceFailure`（`IterationLimit`）、導関数がスカラーの範囲を超えると `NumericalInstability`（`Overflow`）になる。
導関数には一様な ULP の仕様がなく、オプション付き形式は二項和の丸めを含む推定誤差を返す。

## 複素引数の指数尺度化形

J・Y・Hankel の尺度化形も `NumericScalar` を受け取り、次数の型の規則は元の関数と同じである。
J・Y は入力と同じスカラー型、Hankel は `Complex<T::Real>` を返す。
実数の J・Y では尺度因子は 1 で、定義域も元の実数関数に従う。
オプションは `BesselOptions` である。
次数・定義域・正規化・負の実軸の切断の側は元の関数に従う。
オプション付き形式の導関数は元の関数の導関数に同じ因子を掛けたもので、尺度因子そのものは微分しない。
実数の J・Y の尺度化形は元の関数と同じ精度を持つ。
複素数の J・Y の尺度化形と、実数を含む Hankel の尺度化形には一様な ULP の仕様がない。
