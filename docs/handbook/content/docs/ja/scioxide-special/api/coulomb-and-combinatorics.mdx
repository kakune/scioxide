この表は Coulomb 波動関数と水素様原子の動径関数、および階乗、二項係数、Stirling 数などの組合せ関数をまとめる。
Coulomb 波動関数、`hydrogenic_radial` と、実数と複素数を受け付ける組合せ関数（`generalized_binomial`、`pochhammer`、`pochhammer_relative`）は、一つの関数で `NumericScalar`（`f32`、`f64`、`Complex<f32>`、`Complex<f64>`）を受け取る。
`coulomb_normalization` とその列、整数の添字だけを受け取る組合せ関数は `RealScalar`（`f32`、`f64`）の値を返す。
各行は値だけを返す標準形式、`SpecialFunctionResult` を返すオプション付き形式 `*_with_options`、求解のスコープの中で評価するスコープ付き API `*_scoped(.., options, scope)` を並べる（[三つの呼び出し形](oxref:special-api-call-forms)）。
計算量が引数によらず有界な `coulomb_normalization`、階乗と二項係数とその対数、Pochhammer 記号、Bernoulli 数、Euler 数には、スコープ付き API がない。
オプション型は `CoulombOptions` と `CombinatorialOptions` で、どちらも作業量の上限（既定 65536）だけを持ち、[結果型とオプション](../results-and-options/)に載せる。

## Coulomb 波動関数

Coulomb 波動関数は動径 Coulomb 方程式 $w'' + [1 - 2\eta/z - \ell(\ell+1)/z^2]\,w = 0$（DLMF 33.2.1）の解である。
$\ell$ は次数、$\eta$ は電荷（Sommerfeld）パラメータ、$z$ は半径を表す。
正則解は $z \to 0$ で $F_\ell \sim C_\ell(\eta)z^{\ell+1}$ と振る舞い、$C_\ell(\eta)$ は `coulomb_normalization` の正規化定数である。
大きい実数の $z$ では $F_\ell \sim \sin\theta$、$G_\ell \sim \cos\theta$（$\theta = z - \eta\ln(2z) - \ell\pi/2 + \sigma_\ell(\eta)$、$\sigma_\ell(\eta) = \arg\Gamma(\ell+1+\mathrm{i}\eta)$）で、Wronskian は $F'G - FG' = 1$ である。

引数は $\ell$、$\eta$、$z$ の順である。
次数 $\ell > -1/2$ と $\eta$ は実数で、半径が複素数でも実数の型 `T::Real` で渡す。
半径は 0 以上の実数か複素数で、複素数の半径は負の実軸に切断を置き、虚部の符号付きゼロで岸を選ぶ。
$\ell \le -1/2$ と負の実数の半径は `DomainError`（`OutsideDomain`）になる。
正の実数の半径では、$(\ell^2 + \eta^2)/z$ がおよそ 59 未満の範囲で外向きの漸近展開（DLMF 33.11.1）を使い、作業量は数百単位である。
それ以外では Steed の方法で DLMF 33.8 の連分数を評価し、作業量は約 $z - \eta$ 単位である。
既定の上限 65536 は $2\times 10^4$ 以上のすべての半径で $\ell, \lvert\eta\rvert \le 1300$ を扱え、それより大きい次数や電荷で半径が約 $6\times 10^4$ から $(\ell^2 + \eta^2)/59$ のあいだにあるときは上限を上げる必要がある。
複素数の半径では、原点の級数、方程式の Taylor 級数による接続、$H^\pm = G \pm \mathrm{i}F$ の漸近展開と連分数を組み合わせる。

すべての行に共通して、非有限の入力は `NonFinite`、値がスカラー型の範囲を超えると `NumericalInstability`（`Overflow`）、作業量の上限に達すると `ConvergenceFailure`（`IterationLimit`）になる。
実数の引数は照合した範囲で両精度とも 64 ULP を目標とし、波の零点の近くでは絶対誤差で照合する。
複素数の半径には一様な ULP の仕様がなく、次数 50 まで、$\lvert\eta\rvert \le 100$、$10^{-3} \le \lvert z\rvert \le 10^4$ で試験している。

## Coulomb 関数の列

次数 $\ell, \ell+1, \dots$ の列は、隣接する次数の漸化式（DLMF 33.4）を再利用する場合に限って出力に反映する。
$F$、$F'$、$F/z$ は最高次数から下向きに、$G$、$G'$ は次数 $\ell$ から上向きに漸化式をたどり、どちらの向きも数値的に安定である。
計算コストはスカラーの評価一回と $O(\mathrm{count})$ 段の漸化式である。

所有値を返す API `coulomb_sequence`、`coulomb_wave_sequence`、`coulomb_normalization_sequence` は個数 `count` を受け取り、次数 $\ell, \dots, \ell+\mathrm{count}-1$ の値を `Vec` で返す。
全要素で既定の `CoulombOptions`（65536 単位）を共有し、`count` 個の要素のベクトルを二つ確保する（確保の失敗は `AllocationFailure`）。
`*_into` 形はオプション、出力 `output`、一時領域 `staging`、スコープの順に受け取り、`output` の長さの数だけ詳細結果を書いて `Result<(), SciOxideError>` を返し、確保しない。
各要素はまず `staging` に書かれ、全要素が成功した後にだけ `output` へ写されるので、失敗したときは `output` を変えない。
`staging` が `output` より短いと `DimensionMismatch` になる。
`output` と `staging` は呼び出し側が用意し、`SpecialFunctionResult::zero()` か `CoulombWaveResult::zero()` で初期化する。
`*_into` 形では全要素が `options` の上限を共有し、各要素は列全体の計数を持ち、上限に達すると試行した計数付きの `ConvergenceFailure` になる。
次数 $\ell + k$ が有限でないか一つ前の次数に丸まる場合は、所有値を返す API では引数 `count`、`*_into` 形では引数 `output` の `DomainError`（`OutsideDomain`）になる。
個数が 0 でも、出力が空でも、パラメータは検査する。

## 階乗と多重階乗

整数の添字を受け取る関数は `RealScalar` の値を返し、添字は `usize` なので負の値は型で表せない。
値がスカラー型の範囲を超えると、標準形式は `NumericalInstability`（`Overflow`）を返し、オプション付き形式は尺度化形と対数形を残す。
`factorial`、`ln_factorial`、`binomial` は照合した範囲で binary64 は 4 ULP、binary32 は 1 ULP を目標とする。
この節と次の三節のほかの関数には一様な ULP の仕様がなく、オプション付き形式の推定誤差を独立な参照値と正確な恒等式で試験している。

階乗の解析接続 $\Gamma(z+1)$ は `gamma(z + 1)`、整数回の上昇階乗は `pochhammer(a, n)` で求める。
`pochhammer` は整数刻みの除去可能な特異点を扱うので、二つの Gamma 関数を別々に割らない。
