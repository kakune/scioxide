この表は Legendre 形の楕円積分、Carlson の対称積分、Jacobi の楕円関数の公開項目をまとめる。
すべての関数は `NumericScalar`（`f32`、`f64`、`Complex<f32>`、`Complex<f64>`）を受け取り、実数と複素数で同じ名前を使う。
各行は値だけを返す標準形式、`EllipticOptions` を受け取って `SpecialFunctionResult` を返すオプション付き形式 `*_with_options`、求解のスコープの中で評価するスコープ付き API `*_scoped(.., options, scope)` を並べる（[三つの呼び出し形](oxref:special-api-call-forms)）。
`EllipticOptions` は作業量の上限（既定 65536）だけを持ち、[結果型とオプション](../results-and-options/)に載せる。

母数は $m = k^2$（法 $k$ の二乗）で、DLMF が法 $k$ で書く $K(k)$ などと同じ関数を $m$ で表す。
振幅 $\phi$ はラジアンである。
不完全楕円積分 `elliptic_f`、`elliptic_e_inc` と Jacobi 関数の母数は、振幅や $u$ が複素数なら実数でも渡せる（`Parameter`）。
すべての行に共通して、非有限の入力は `NonFinite`、表せない結果や計算の破綻は `NumericalInstability`、作業量の上限に達すると、標準形式もオプション付き形式も途中の値を返さずに `ConvergenceFailure`（`IterationLimit`）になる。
複素数の引数では被積分関数の各因子に主値の平方根を使い、切断の上の引数は虚部の符号付きゼロ（`+0i` が上側、`-0i` が下側）で岸を選ぶ。
切断は完全楕円積分では母数の $[1, \infty)$ に、Carlson 積分では各座標の負の実軸にある。
複素数の評価には一様な ULP の仕様はない。

## 不完全楕円積分

不完全積分は振幅 $\phi$、母数 $m$ の順に受け取る。
実数の振幅は被積分関数の周期 $\pi$ を使って $[0, \pi/2]$ に簡約し、簡約した周期 1 つごとに完全積分の 2 倍を足す。
不完全な第三種積分は提供しない。
必要なら $s = \sin\phi$、$c = \cos\phi$、$\Delta^2 = 1 - ms^2$ として $\Pi(n; \phi \mid m) = s\,R_F(c^2, \Delta^2, 1) + \tfrac{n}{3}s^3 R_J(c^2, \Delta^2, 1, 1 - ns^2)$（DLMF §19.25）を `carlson_rf` と `carlson_rj` で組み立てる。

## Carlson 対称形

Carlson の対称積分は引数の入れ替えに対して対称な標準形で、Legendre 形の積分はこれらに帰着する（例えば $K(m) = R_F(0, 1 - m, 1)$）。
評価は Carlson の倍角法（DLMF §19.36(i)）による。
1 段ごとに引数の相対的な広がりが約 1/4 になり、広がりが 0.001 を下回ると 5 次の級数で和を仕上げる。
各段を `EllipticOptions` の作業量に数える。
実数の引数では負の座標は `DomainError`（`OutsideDomain`）になり、例外は Cauchy 主値を返す $R_J$ の $p < 0$ と $R_C$ の $y < 0$ だけである。
実数は照合した範囲で 64 ULP を目標とし、$R_F$、$R_D$、$R_J$ の binary64 の最大の測定誤差は 4.8 ULP である。

## Jacobi 楕円関数

引数は $u$ と母数 $m$ で、$m$ は $u$ と同じ型か、$u$ が複素数なら実数で渡す（[`Parameter`](oxref:special-api-argument-types)）。
複素数の $m$ には複素数の $u$ が要る。
$\operatorname{sn}(u \mid m) = \sin\operatorname{am}(u \mid m)$、$\operatorname{cn}(u \mid m) = \cos\operatorname{am}(u \mid m)$、$\operatorname{dn}^2 = 1 - m\operatorname{sn}^2$ で、$u = 0$ の値は $(0, 1, 1)$ である。
実数の $u$ と $m$ はすべての有限な組を受け付け、$m < 0$ と $m > 1$ は実数の変換（DLMF §22.17）で扱う。
実数の $m$ では実周期で簡約したあと、算術幾何平均と逆正弦による振幅の降下（DLMF 22.20）で評価する。
複素数の $m$ ではモジュラー変換で簡約したあと、Jacobi のテータ関数の商（DLMF §20.7、§22.2）で評価する。
複素数の $u$ について sn、cn、dn は有理型で、極は $u = 2jK + (2l + 1)\mathrm{i}K'$（$K = K(m)$、$K' = K(1 - m)$、$j, l$ は整数）にある。
極の上かそのすぐ近くで簡約が値を決められないときは、`DomainError`（`Pole`）か `NumericalInstability`（`LossOfSignificance`）になる。
実数は照合した範囲で 64 ULP を目標とし、binary64 の sn の誤差の中央値は 1.2 ULP 以下である（最大値ではない）。
