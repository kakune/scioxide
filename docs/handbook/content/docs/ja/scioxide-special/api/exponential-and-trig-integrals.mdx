このページは指数積分、三角積分と双曲線積分、対数積分、逆正接積分、Dawson 積分、Fresnel 積分の API をまとめる。
Fresnel 積分と Dawson 積分だけが `NumericScalar`（`f32`、`f64`、`Complex<f32>`、`Complex<f64>`）を受け取り、他は `RealScalar`（`f32`、`f64`）の実関数である。
各行は値だけを返す標準形式、`SpecialFunctionResult` を返すオプション付き形式 `*_with_options`、求解スコープを受け取るスコープ付き API `*_scoped(.., options, scope)` を並べる（[三つの呼び出し形](oxref:special-api-call-forms)）。
オプション型は Dawson 積分が誤差関数の族と共有する `ErrorFunctionOptions`、他が `IntegralOptions` で、どちらも作業量の上限（`Budget`）だけを持ち、[結果型とオプション](../results-and-options/)に載せる。
演算の回数が引数によらず一定の関数（$E_1$、$\operatorname{Ei}$ とその尺度化形、`expint_3`、対数積分、逆正接積分）はスコープ付き API を持たない。
実数の Dawson 積分も演算の回数が一定なので、`dawson_scoped` は計算量が引数によって変わる複素数の引数だけを受け付ける。

このページのすべての関数は非有限の入力を `NonFinite`、表せない結果や数値的な破綻を `NumericalInstability`、上限内に終わらない計算を `ConvergenceFailure` で返す。
表には関数ごとの `DomainError` と規約を書く。
binary64 の実数の $E_1$、$\operatorname{Ei}$、$E_n$（$E_2$ を含む）、`expint_3`、$\operatorname{Si}$、$\operatorname{Ci}$ は、160 桁と 240 桁で独立に生成した照合データ上で、零点から離れた所では 8 ULP を目標とし、零点の近くでは打ち消しを考慮した絶対誤差の限界で判定する。
$E_1$、$\operatorname{Ei}$、$E_n$（それぞれの尺度化形を含む）、$\operatorname{Si}$、$\operatorname{Ci}$ のオプション付き形式の推定誤差は、計算が完了したときは照合データで較正した包絡（`StatisticallyCalibrated`）、途中で止まったときはモデルによる保守的な限界（`ModelBased`）である。
`expint_3`、双曲線積分、対数積分、逆正接積分、Fresnel 積分のオプション付き形式の推定誤差は、つねにモデルによる限界（`ModelBased`）である。
尺度化形、双曲線積分、対数積分、逆正接積分、Fresnel 積分（実数と複素数）には一様な ULP の仕様がなく、オプション付き形式が推定誤差を返す。

## 指数積分

$E_1$ と $\operatorname{Ei}$ は尺度化した区分的な有理近似で評価し、指数因子を最後に一度だけ掛ける。
$n \ge 2$ の $E_n$ は、$x \le 1$ で補償和の冪級数、それより大きな $x$ で連分数を、尺度化形 $e^x E_n(x)$ で評価する。
尺度化形は支配的な指数因子を核の中で除いた値を返すので、元の関数があふれるか下位あふれする引数でも使える。
指数積分の尺度化形では、オプション付き形式が返す導関数は尺度化した関数そのものの導関数（たとえば $\tfrac{d}{dx}(e^x E_n(x)) = e^x(E_n(x) - E_{n-1}(x))$）である。

## 三角積分と双曲線積分

$\operatorname{Si}$ と $\operatorname{Ci}$ は、$\lvert x\rvert \le 4$ では $t = (x^2 - 8)/8$ の Chebyshev 展開、$4 < \lvert x\rvert < 48$ では補助関数 $f$、$g$ の $1/x^2$ の有理近似、$\lvert x\rvert \ge 48$ では補助関数の漸近展開で評価する。
$\operatorname{Shi}$ と $\operatorname{Chi}$ は $\lvert x\rvert \le 1$ で冪級数、その外で `expint_ei` と `expint_e1` の尺度化した核を組み合わせて評価する。
$\lvert x\rvert$ とともに $e^{\lvert x\rvert}/(2\lvert x\rvert)$ の速さで増大し、binary64 では $\lvert x\rvert > 717$ 付近で標準形式が `NumericalInstability`（`Overflow`）になる（オプション付き形式は尺度化形と対数形を残す）ので、その範囲では尺度化形を使う。
