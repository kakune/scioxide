この表はGamma 関数 $\Gamma$ と Beta 関数 $B$ の完全形、正則化した不完全形 $P(a,x)$・$Q(a,x)$・$I_x(a,b)$、それらの対数形と逆関数をまとめる。
`NumericScalar` を受け取る関数は実数（`f32`、`f64`）と複素数（`Complex<f32>`、`Complex<f64>`）で同じ名前を使い、`RealScalar` だけを受け取る関数は実数専用である。
各行には標準形式、`SpecialFunctionResult` を返すオプション付き形式 `*_with_options`、持つ関数ではスコープ付き API `*_scoped(.., options, scope)` を並べる（[三つの呼び出し形](oxref:special-api-call-forms)）。
スコープ付き API は計算量が引数によって変わる関数だけが持つ。
オプションは不完全形・対数形・逆関数を含めて Gamma 関数族が `GammaOptions`、Beta 関数族が `BetaOptions` で、どちらも作業量の上限（`Budget`）だけを持つ（[結果型とオプション](../results-and-options/)）。

どの関数も非有限の入力を `NonFinite`、表せない結果や計算の破綻を `NumericalInstability` で返す。
反復する関数では、上限内に終わらない計算が標準形式では `ConvergenceFailure` になり、オプション付き形式とスコープ付き API では推定値が残る場合に `IterationLimit` の終了状態で返る（推定値がなければ `ConvergenceFailure`）。

## 完全 Gamma 関数と対数形

実数の Gamma・対数 Gamma・ディガンマ・ポリガンマは、照合データ（独立に生成した参照値）上で binary64 4 ULP、binary32 1 ULP を目標とする。
複素数の解析接続には固定の ULP 仕様はない。
Gamma、対数 Gamma、ディガンマは演算の回数が引数によらず一定なので、スコープ付き API を持たない。
ポリガンマは計算量が次数に比例して増えるので、スコープ付き API を持つ。

## Beta 関数

実数の Beta 関数とその対数は、照合データ上で binary64 4 ULP、binary32 1 ULP を目標とする。
`ln_beta` の目標は $\ln B$ の零点の近くでも変わらない。
どちらも演算の回数が引数によらず一定なので、スコープ付き API を持たない。

## 不完全 Gamma 関数

実数では有限の $a \ge 0$、$x \ge 0$ を受け付け、負の $a$ や $x < 0$ は `DomainError`（`OutsideDomain`）になる。
形状 $a = 0$ の扱いは関数で異なる。
`gamma_lower` は $a > 0$ を要求して $a = 0$ を `DomainError`（`Pole`）とし、他の関数は $x > 0$ で極限値 $P(0, x) = 1$、$Q(0, x) = 0$、$\Gamma(0, x) = E_1(x)$ を返す。
原点 $(a, x) = (0, 0)$ は、正則化形とその対数形では値が一つに決まらないので `DomainError`（`Undefined`）、`gamma_upper` では極として `DomainError`（`Pole`）になる。
複素数では $z$ の主値の冪を使い、負の実軸を切断として虚部の符号付きゼロで岸を選ぶ。
$z = 0$ で $\operatorname{Re} a \le 0$ は `DomainError`（`Undefined`）である（`gamma_upper` の $a = 0$ は極）。
`gamma_lower`、`gamma_upper`、`gamma_p`、`gamma_q` は形状 $a$ を `Parameter<T>` で受け取るので、複素数の $z$ に実数の $a$ を渡せる。
対数形 `gamma_log_p`、`gamma_log_q` は実数専用である。
実数の不完全形は、形状 $20 < a \le 10^{10}$ と深い裾を含む境界の照合データで binary64 32 ULP、binary32 1 ULP を目標とする（より広い 4,160 点の binary64 標本での最大誤差は 90 ULP）。
複素数の不完全形には一様な ULP の仕様がなく、オプション付き形式が推定誤差を返す。
複素数のオプション付き形式は 4 関数とも $z$ についての導関数を `derivative()` に持ち、実数のオプション付き形式は導関数を持たない。

## 不完全 Gamma 関数の逆関数

逆関数は実数専用（`RealScalar`）で、引数の順は `(a, p)` である。
$a \le 0$ と範囲外の $p$ は `DomainError`（`OutsideDomain`）になる。
漸近展開の初期値から、座標 $\ln x$ での Halley 法を区間で保護して進め、最後の数歩は倍々精度の裾で評価してスカラーの精度に達したところで止める。
$a = 1$ は閉形式で解く。
形状 $20 < a \le 10^{10}$ を含む照合データ上で binary64 32 ULP、binary32 1 ULP を目標とする。

## 不完全 Beta 関数と裾

実数では有限の $a, b \ge 0$ と $0 \le x \le 1$ を受け付け、負の形状や区間外の $x$ は `DomainError`（`OutsideDomain`）になる。
形状 0 は極限として扱い、$a = 0$、$b > 0$、$x > 0$ で $I_x = 1$、$b = 0$、$a > 0$、$x < 1$ で $I_x = 0$ を返す。
両方の形状が 0 の場合と、$(a, x) = (0, 0)$、$(b, x) = (0, 1)$ の角は値が一つに決まらないので `DomainError`（`Undefined`）になる。
裾・対数形の関数も同じ規則に従う。
複素数を受け付けるのは `beta_inc` だけで、形状 $a$、$b$ を `Parameter<T>` で受け取る。
裾と対数形は実数専用である。
実数の不完全 Beta とその裾・対数形は、照合データ上で binary64 32 ULP、binary32 1 ULP を目標とし、binary64 の推定誤差も 32 単位で返す（より広い 4,160 点の binary64 標本での最大誤差は 12 ULP）。
整数の形状に使う有限和は、先頭の冪が正規化数の範囲で精度を失う前に一般のアルゴリズムへ切り替えるので、表せる非正規化数の裾も失わない。

## 不完全 Beta 関数の逆関数

逆関数は実数専用（`RealScalar`）で、引数の順は `(a, b, p)` である。
$a \le 0$、$b \le 0$ と範囲外の $p$ は `DomainError`（`OutsideDomain`）になる。
漸近展開の初期値から、座標 $\ln(x/(1-x))$ での Halley 法を区間で保護して進め、最後の数歩は倍々精度の裾で評価してスカラーの精度に達したところで止める。
照合データ上で binary64 32 ULP、binary32 1 ULP を目標とする。
