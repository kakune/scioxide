このページはBessel 関数から派生する実関数のうち、Kelvin 関数、Struve 関数、放物柱関数、次数 0 の Bessel 関数と Struve 関数の積分を扱う。
引数と次数は `RealScalar`（`f32`、`f64`）で、例外は整数次数 `u32` と複素引数 `Complex<S>` を取る `parabolic_d_complex` だけである。
次数を取る関数の引数の順は `(order, x)` である。
各行は値だけを返す標準形式、`SpecialFunctionResult` を返すオプション付き形式 `*_with_options`、求解スコープを受け取るスコープ付き API `*_scoped(.., options, scope)` を並べる（[三つの呼び出し形](oxref:special-api-call-forms)）。
計算量が引数と次数によって変わるので、このページの関数はすべてスコープ付き API を持つ。
オプション型 `KelvinOptions`、`StruveOptions`、`ParabolicCylinderOptions`、`BesselIntegralOptions` は作業量の上限（`Budget`）だけを持ち、[結果型とオプション](../results-and-options/)に載せる。

このページのすべての関数は非有限の入力を `NonFinite`、表せない結果や数値的な破綻を `NumericalInstability`、上限内に終わらない計算を `ConvergenceFailure` で返す。
表には関数ごとの `DomainError` と規約を書く。
一様な ULP の仕様を持つのは binary64 の Struve 関数だけである。
Kelvin 関数、放物柱関数、積分は、独立な参照値と値・導関数・推定誤差を比べる試験で確かめているが、一様な ULP の目標はない。

## Kelvin 関数

Kelvin 関数は $I_0$ と $K_0$ を半直線 $x e^{\mathrm{i}\pi/4}$ 上で評価した実部と虚部で、$\operatorname{ber} x + \mathrm{i}\operatorname{bei} x = I_0(x e^{\mathrm{i}\pi/4})$、$\operatorname{ker} x + \mathrm{i}\operatorname{kei} x = K_0(x e^{\mathrm{i}\pi/4})$ である（DLMF 10.61）。
ber・bei は $\lvert x\rvert \le 10$ で冪級数（DLMF 10.65）を倍々精度で足し、それより大きな $\lvert x\rvert$ では $I_0(\lvert x\rvert e^{\mathrm{i}\pi/4})$ を 20 未満で冪級数、20 以上で漸近展開（DLMF 10.67）から求める。
ker・kei は $K_0(x e^{\mathrm{i}\pi/4})$ を 20 未満で倍々精度の冪級数、20 以上で漸近展開から求める。
値と導関数は同じ展開から作る。
ber・bei は $\lvert x\rvert$ とともに $e^{\lvert x\rvert/\sqrt{2}}$ の速さで増大してあふれると `NumericalInstability`（`Overflow`）になり、ker・kei は $e^{-x/\sqrt{2}}$ の速さで減衰する。
通常値が表せない範囲では、指数因子を掛けた名前付きの関数 `ber_scaled`、`ker_scaled` など（導関数は `berp_scaled` など）を使う。

## Struve 関数

Struve 関数 $\mathbf{H}_\nu$、$\mathbf{L}_\nu$ は非斉次の Bessel 方程式・変形 Bessel 方程式の特解である。
$x \ge 20$ では $\mathbf{H}_\nu = Y_\nu + \mathbf{K}_\nu$、$\mathbf{L}_\nu = I_\nu + \mathbf{M}_\nu$ の $\mathbf{K}_\nu$、$\mathbf{M}_\nu$ を漸近展開（DLMF 11.6）で足して試し、打ち切り誤差（$\mathbf{L}_\nu$ では指数的に小さい差 $I_\nu - I_{-\nu}$ も）が binary64 の丸めより小さいときだけ採用する。
それ以外では定義級数を倍々精度で足すので、項の間の打ち消しで失うのは倍々精度の丸めだけである。
次数 $\nu = -(n + 1/2)$ は Bessel 関数の閉形式（DLMF 11.4.4、11.4.5）を使う。
binary64 では $\nu \in [-5, 10]$、$x \in [10^{-3}, 100]$ の照合データで 64 ULP を目標とし、$\mathbf{H}_\nu$ の零点の近くでは絶対誤差 $4\varepsilon\max(1, \lvert\mathbf{H}_\nu\rvert)$ 以下を目標とする。
この範囲の外と binary32 には一様な ULP の目標がない。
値は binary64 で計算するので、binary64 の範囲を超えると `NumericalInstability`（`Overflow`）、binary32 の範囲だけを超えると `ScalarConversion` になる。

## 放物柱関数

放物柱関数は $y'' + (\nu + \tfrac12 - \tfrac{x^2}{4}) y = 0$（$D_\nu$、$V$）と $y'' + (\tfrac{x^2}{4} - a) y = 0$（$W$）の解である（DLMF 12）。
$D_\nu$ は $\lvert\nu\rvert \le 2$、$\lvert x\rvert \le 3$ で原点のまわりの冪級数を補償和で足し、$\lvert x\rvert \ge \max(32, 2(\lvert\nu\rvert + 1))$ で漸近展開（DLMF 12.9）を使う。
その間では、負の次数は積分表示（DLMF 12.5）の求積、正の次数は次数の前進漸化式（DLMF 12.8、約 $\nu$ 歩）を使い、負の $x$ は $V$ との接続公式で求める。
$V_\nu$ と $W$ は原点の値から微分方程式の Taylor 法で解を延ばす（$V_\nu$ は大きな $\lvert x\rvert$ で漸近展開）。
実関数のオプション付き形式は経験的な推定誤差（`Heuristic`）を返す。
$D_\nu$ と $V_\nu$ の試験は $\lvert\nu\rvert \le 20$、$\lvert x\rvert \le 10^4$ の参照値と比べる。

## Bessel 関数と Struve 関数の積分

次数 0 の Bessel 関数・Struve 関数の積分を、$\lvert x\rvert \le 12$ で項別に積分した冪級数、$12 < \lvert x\rvert < 32$ で Chebyshev 展開、$\lvert x\rvert \ge 32$ で裾の積分の漸近展開により評価する（$I_0$ と $\mathbf{L}_0$ の積分は $\lvert x\rvert < 32$ で冪級数、それ以上で漸近展開）。
オプション付き形式は推定誤差と、$x$ についての導関数を返す。
導関数は $\int_0^x$ の形では被積分関数の値、$\int_x^\infty$ の形ではその符号を変えた値である。
対数的な積分定数は Mellin 変換の有限部分で定める（DLMF 10.22）。
被積分関数の正規化は、名前の付いた次数 0 の関数に従う。
