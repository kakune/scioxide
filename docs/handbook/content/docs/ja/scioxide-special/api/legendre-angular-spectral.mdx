この表は角度方向の固有関数に関わる公開項目をまとめる。
Legendre 関数と球面調和関数は値を返す関数で、各行は値だけを返す標準形式、オプションを受け取って `SpecialFunctionResult` を返すオプション付き形式 `*_with_options`、求解のスコープの中で評価するスコープ付き API `*_scoped(.., options, scope)` を並べる（[三つの呼び出し形](oxref:special-api-call-forms)）。
角運動量の結合係数、Mathieu 関数、回転楕円体関数、楕円体調和関数は、係数を準備した Plan（`*Plan`）か、Plan を内部で一つ作って一度だけ評価するワンショット関数で評価する。
Plan は既定の実行で準備する `new` と、求解のスコープの中で準備する `build(.., scope)` を持ち、評価メソッドには通常の形と `*_scoped` の形がある。
準備と各評価は、それぞれ別に作業量の上限を受ける。
ワンショット関数は呼び出しごとに確保し（確保の失敗は `AllocationFailure`）、準備と評価で一つの既定の上限を共有し、値だけを返す。
推定誤差や診断が要るときは Plan を作る。
Legendre 関数と球面調和関数の `LegendreOptions` は[結果型とオプション](../results-and-options/)に載せ、角運動量とスペクトル型の関数のオプションはこのページに載せる。

すべての行に共通して、非有限の入力は `NonFinite`、表せない結果や計算の破綻は `NumericalInstability`、作業量の上限に達すると `ConvergenceFailure` になる。

## Legendre 関数

実数の Legendre 関数 $P$、$Q$ と陪関数は、照合した範囲で両精度とも 64 ULP を目標とし、零点の近くでは絶対誤差で照合する。
binary64 の $P$ の最大の測定誤差は 0.5 ULP で、試験は 20,000 次までを含む。
次数は非負の整数 `degree: usize` で、漸化式は 1 段ごとに作業量を 1 単位使う。
既定の上限 65536 で足りない次数は `ConvergenceFailure`（`IterationLimit`）になる。

## 球面調和関数

オプションは Legendre 関数と共有する `LegendreOptions`（既定 65536 単位）である。
正規化した陪 Legendre 関数を二進の尺度調整つきの漸化式で求めるので、大きな次数でもあふれもアンダーフローもしない。
$e^{\mathrm{i}m\phi}$ は $e^{\mathrm{i}\phi}$ の繰り返し二乗で作り、積 $m\phi$ の丸めを避ける。
計算コストは約 $\ell + \log_2\lvert m\rvert$ 単位である。
一様な ULP の仕様はない。
オプション付き形式の推定誤差は正規化した漸化式の丸め誤差のモデルで、項の大きさに対して $32\varepsilon(1 + \ell + \lvert m\rvert)^2$ のように増える。

## 角運動量の結合係数

角運動量 $j \in \{0, 1/2, 1, 3/2, \dots\}$ は 2 倍した整数 $2j$ で正確に表す。
結合係数は Racah の公式（DLMF §34.2、§34.4）の階乗の比の和で、各階乗を素数のべきの積として扱い、項を正確な多語の整数で足す（Johansson and Forssén, 2016）。
丸めはスカラー型への最後の変換だけで起こる。
三角条件、偶奇、磁気量子数の和の選択則を先に確かめ、禁じられた係数は正確な 0 を返す。
一様な ULP の仕様はなく、Plan の詳細結果の相対推定誤差は最後の変換の浮動小数点演算の回数の $8\varepsilon$ 倍である。

ワンショット関数は 2 倍した量子数の整数配列（`gaunt` は 2 倍しない次数と位数）を受け取り、最大の角運動量に合わせた Plan と作業領域を呼び出しごとに確保する。
繰り返し評価するときは `AngularPlan` を一度作る。
Plan の所有値を返す API のメソッドは呼び出しごとに作業領域を確保し、`*_scoped` メソッドは `AngularWorkspace` を使い回して確保せずに評価する。

## Mathieu 関数と回転楕円体関数

Mathieu 関数と回転楕円体関数の Plan は、展開係数の三項漸化式を打ち切った対称三重対角の固有値問題を解き、求めるモードの固有対だけを Sturm の二分法と逆反復で求めて係数を保持する。
係数の個数は $\max(\text{minimum}, \text{モードの番号} + 8)$ から始め、連続する二つの打ち切りが許容誤差の内で一致するまで倍にする。
一致しなければ Plan を出力に反映しない。
準備と評価は、どちらのスカラー型でも binary64 で行う。
`SpectralOptions` の許容誤差は特性値と係数の変化と省いた裾の推定を抑え、緩めると作業が減る。
固定の ULP の限界はない。
`diagnostics()` の残差と裾の推定、各評価の推定誤差（打ち切り誤差を含む）が評価の目安で、保証された限界ではない。
複素数の座標では、保持しない係数の裾が増幅され得る。

ワンショット関数 `mathieu_a` などは標準の正規化（`SpectralNormalization::Standard`）と既定の `SpectralOptions` で Plan を一つ作り、準備と評価で 2,097,152 単位の作業量の上限を共有する。
既定の打ち切りの範囲に収まらないモードは、Mathieu のワンショット関数では引数 `order`、回転楕円体のワンショット関数では引数 `n` の `InvalidInput`（`OutOfRange`）になる。
二つの打ち切りが既定の最大の 256 係数までに一致しなければ `ConvergenceFailure`（`TruncationLimit`）になる。
多くの点で評価するとき、別の正規化やオプションを使うとき、推定誤差が要るときは Plan を作る。

## 楕円体調和関数

Lamé 関数による楕円体調和関数は `EllipsoidalHarmonicPlan` で準備し、半焦点距離 $0 < h < k$ の三軸の楕円体座標で評価する。
第一種の Lamé 関数 $E_n^p(s)$ は、Lamé 方程式の解のうち多項式と焦点因子の積になる $p$ 番目の解で、最高次の係数を 1 にとる。
準備は両精度とも binary64 で行い、$s/h$ の Chebyshev 係数の対称三重対角の固有値問題を解いたあと、固有ベクトルを三項漸化式から最大成分に向けて計算し直す。
作業量と一時メモリ領域は $O(n^2)$、Plan が保持する係数は $O(n)$ である。
第一種の値は Chebyshev 和を Clenshaw の漸化式で求め、第二種の値と正規化定数は `EllipsoidalOptions` の相対許容誤差で制御する適応求積で求める。
第二種の関数と正規化定数は Dassios (2012) の定義に従う。
固定の ULP の限界はない。
`spectral_residual()` は固有値問題の残差で、各評価の推定誤差は係数の誤差、Chebyshev 和の条件、求積の許容誤差から導く。
どちらも保証された限界ではない。
