この表はすべての関数族に共通する結果の型と引数の型の規則、関数族ごとのオプション型をまとめる。
オプション付き形式 `*_with_options` とスコープ付き API `*_scoped` は `SpecialFunctionResult` を返し、標準形式はその通常値だけを返す（[三つの呼び出し形](oxref:special-api-call-forms)）。
オプション型は精度の要求ではなく計算量の上限を表す。
打ち切りや求積を許容誤差で決める `SpectralOptions`、`EllipsoidalOptions` と、メモリ領域の上限も持つ `AngularOptions` は、Plan の型とともに [Legendre 関数・角運動量・スペクトル型の関数](../legendre-angular-spectral/)にある。

## 詳細結果と推定誤差

`SpecialFunctionResult` と `ValueWithError` は読み取り専用で、利用者が作るのはメモリ領域を初期化する `SpecialFunctionResult::zero()` だけである。
推定誤差はどれも区間の包含区間（証明付きの上下限）ではなく、`EstimateReliability`（scioxide-core）がその根拠を示す。

## 関数族ごとの反復の上限

どのオプション型も `new(budget)`、`iteration_budget()`、`with_iteration_budget(budget)` と `Default` を持つ不変の値で、反復や係数の評価の回数の上限 `Budget` だけを保持する。
上限の単位は関数族の核が数える処理（級数の項、連分数の段、漸化式の一歩など）で、関数族の間で比べられない。
入れ子の評価（逆関数の中の順方向の評価、Coulomb 関数の漸化式など）は同じ上限を共有する。
スコープ付き API では、この上限がその評価の局所の反復の上限になり、消費は外側の求解に入れ子の計数として渡る。

## 引数とパラメータの型

次数や形状などのパラメータは、引数と同じ型のほか、引数が複素数のときは実数でも受け付ける。
たとえば複素数の $z$ に対して `bessel_j(2.5, z)` は $J_{2.5}(z)$ を返す。

| 項目 | 種別 | 役割 | 仕様の要点 | 解説節 | 実行例 |
|---|---|---|---|---|---|
| [`Parameter`](https://docs.rs/scioxide-special/0.1.0/scioxide_special/trait.Parameter.html) | トレイト | 引数の型 `T` とともに、次数や形状などのパラメータとして受け付ける値の型 | `T` 自身と、`T` が `Complex<R>` のときの `R` に実装される。実数のパラメータは虚部 $+0$ の複素数として扱われ、その複素数を渡した呼び出しとビット単位で同じ値を返す。引数の型が `T` と結果の型を決め、複素数のパラメータには複素数の引数が要る（実数の引数に複素数のパラメータを渡す呼び出しはコンパイルできない）。`bessel_j` などの Bessel・Hankel 関数とその導関数・尺度化形の次数、`gamma_p`・`gamma_q`・`gamma_lower`・`gamma_upper`・`beta_inc` の形状、`hyp0f1`・`hyp1f1`・`hyp2f1`・`hyp2f0`・`hyperu`・`hyp2f1_regularized` のパラメータ、`hurwitz_zeta` の $q$、`polylog` の位数、`lerch_phi` の $s$・$a$、`elliptic_f`・`elliptic_e_inc` と Jacobi 楕円関数の $m$ が受け付ける。sealed トレイトで、公開メソッドはない | [実数と複素数の API](oxref:special-entry-real-complex) | - |
