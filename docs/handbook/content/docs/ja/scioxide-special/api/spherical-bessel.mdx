このページは整数次数 $n$ の球 Bessel 関数 $j_n, y_n, i_n, k_n$、球 Hankel 関数、Riccati–Bessel 関数、双曲空間の球関数 $H_\ell(\lambda, \eta)$ の項目をまとめる。
球 Bessel 関数と球 Hankel 関数は `NumericScalar` の一つの関数名で実数（`f32`、`f64`）と複素数（`Complex<f32>`、`Complex<f64>`）の引数を受け取り、次数は `u32` で渡す。
Riccati–Bessel 関数と H3d は実数（`RealScalar`）だけを受け付ける。
各行は値だけを返す標準形式、`SpecialFunctionResult` を返すオプション付き形式 `*_with_options`、求解スコープを受け取るスコープ付き API `*_scoped(.., options, scope)` を並べる（[三つの呼び出し形](oxref:special-api-call-forms)）。
計算量が次数に比例して増えるので、このページの関数はすべてスコープ付き API を持つ。
引数の順は `(order, z)`（H3d は `(order, lambda, eta)`）である。
作業量の上限はすべて `SphericalBesselOptions`（漸化式と級数の作業の合計、既定 65536 単位）で与え、この型は[結果型とオプション](../results-and-options/)にある。
複数の次数をまとめて返す次数列の関数は提供しないので、次数ごとに呼ぶ。
非有限な入力は `NonFinite`、定義域外と極は `DomainError`、表せない結果や破綻は `NumericalInstability`、作業量の上限までに終わらない評価は `ConvergenceFailure` になる。
これらの関数には一様な ULP の仕様がない。
試験は独立な参照値と値・推定誤差を比べ、零点の近くでは絶対誤差と相対誤差を混ぜた許容誤差を使う。

## 球 Bessel 関数

球 Bessel 関数は半整数次数の円柱関数から $f_n(z) = \sqrt{\pi/(2z)}\,F_{n+1/2}(z)$（$F = J, Y, I, K$）で定める。
複素数の値は $\sqrt{z}$ と円柱関数の主値の枝から作る。
実数の $j_n$、$i_n$ は $\lvert x\rvert \le 1$ で冪級数、それ以外で次数の漸化式（前進漸化式が不安定な所では Miller の後退漸化式）を使い、$y_n$、$k_n$ は前進漸化式を使う。
複素数は $\lvert z\rvert < 1/4$ で冪級数、それ以外で次数 $n + 1/2$ の円柱関数を使う。
$k_n$ の正規化は $\pi/2$ を含み、$k_0(x) = \pi e^{-x} / (2x)$ となる。

## 球 Hankel 関数と複素尺度化形

球 Hankel 関数とその尺度化形は `NumericScalar` の実数または複素数の引数を受け取り、実数の引数でも複素数 `Complex<T::Real>` を返す。
実軸の外では次数 $n + 1/2$ の変形 Bessel 関数を通して計算する。
尺度化形では、オプション付き形式が返す導関数は元の関数の導関数に同じ因子を掛けたもので、尺度因子そのものは微分しない。
