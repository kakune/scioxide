この表は比熱、縮退した電子気体、金属の輸送、シンクロトロン放射に現れる熱的な積分をまとめる。
すべての関数は実数だけを受け取り、`RealScalar`（`f32`、`f64`）の値を返す。
各行は値だけを返す標準形式、`SpecialFunctionResult` を返すオプション付き形式 `*_with_options`、求解のスコープの中で評価するスコープ付き API `*_scoped(.., options, scope)` を並べる（[三つの呼び出し形](oxref:special-api-call-forms)）。
計算量が引数によらず有界な `fermi_dirac_m1`、`fermi_dirac_0`、`fermi_dirac_inc_0` とシンクロトロン関数には、スコープ付き API がない。
オプション型は `DebyeOptions`、`FermiDiracOptions`、`TransportOptions`、`SynchrotronOptions` で、どれも作業量の上限だけを持ち（`TransportOptions` と `SynchrotronOptions` は既定 128、ほかは 65536）、[結果型とオプション](../results-and-options/)に載せる。

すべての行に共通して、非有限の入力は `NonFinite`、表せない結果や計算の破綻は `NumericalInstability`、作業量の上限に達すると `ConvergenceFailure` になる。
これらの関数には一様な ULP の仕様がない。
オプション付き形式は導いた誤差の限界を返し、両精度の試験は値、返した誤差の限界、尺度化形と対数形を確かめる。
非常に小さい値は 0 か非正規化数にアンダーフローするが、オプション付き形式は対数形を保つ。

## Debye 関数

規格化した Debye 関数は $D_n(x) = \dfrac{n}{x^n}\displaystyle\int_0^x \frac{t^n}{e^t - 1}\,dt$（$x \ge 0$）で、$D_n(0) = 1$ から減り、大きい $x$ では $n \cdot n!\,\zeta(n+1)/x^n$ のように振る舞う。
定義域は有限の $x \ge 0$ で、負の $x$ は `DomainError`（`OutsideDomain`）になる。
極はない。
$x \le 4$ では $x^2/8$ の Chebyshev 展開を使い、$x > 4$ では大きい $x$ の極限から指数的に収束する裾 $\sum_k e^{-kx}\,(1/(kx)$ の多項式$)$ を引く。
$n \ge 2$ では対数を使い、$x^n$ を直接作らない。

## Fermi–Dirac 積分

Gamma 関数で規格化した Fermi–Dirac 積分は $F_j(x) = \dfrac{1}{\Gamma(j+1)}\displaystyle\int_0^\infty \frac{t^j}{e^{t-x} + 1}\,dt = -\operatorname{Li}_{j+1}(-e^x)$（$j > -1$、DLMF §25.12(iii)）で、$F_j' = F_{j-1}$ を満たす。
$j = -1$ はその解析接続のロジスティック関数 $1/(1 + e^{-x})$ である。
有限の実数 $x$ はすべて受け付け、極も切断もない。
負の側では値が 0 にアンダーフローし得る（binary64 では約 $x < -745$）。
正の側で $F_j(x) \approx x^{j+1}/\Gamma(j+2)$ がスカラー型の範囲を超えると `NumericalInstability`（`Overflow`）になり、オプション付き形式は対数形で値を返す。
半整数と 1、2 の次数は、$x < -1$ で $\sum_k (-1)^{k+1}e^{kx}/k^{j+1}$ の級数、$-1 \le x < 30$ で四つの区間の Chebyshev 展開を使う。
$x \ge 30$ では、半整数の次数は Sommerfeld の漸近展開、整数の次数は正確な反転公式 $F_j(x) = (\text{多項式}) \pm F_j(-x)$ を使う。

## 輸送積分

輸送積分は $J_n(x) = \displaystyle\int_0^x \frac{t^n e^t}{(e^t - 1)^2}\,dt$（$n = 2, \dots, 5$）で、金属の電気・熱伝導の Bloch–Grüneisen 型の式に現れる。
定義域は有限の $x \ge 0$ で、負の $x$ は `DomainError`（`OutsideDomain`）になる。
$J_n(0) = 0$ で、$x \to \infty$ で増加して $n!\,\zeta(n)$ に近づく。
有限の極はない。
$x \le 4$ では $x^2/8$ の Chebyshev 展開に $x^{n-1}$ を掛け、$x > 4$ では極限から指数的に収束する裾を引く。

## シンクロトロン関数

シンクロトロン関数は第二種変形 Bessel 関数 $K_\nu$ で表され（Rybicki and Lightman, 1979, 6 章）、定義域は有限の $x \ge 0$、負の $x$ は `DomainError`（`OutsideDomain`）である。
原点の値は 0 で、大きい $x$ では $\sqrt{\pi x/2}\,e^{-x}$ のように減り、binary64 では約 $x > 745$ でアンダーフローする。
尺度化形は $e^x$ を掛けた値を返し、この裾でも範囲に収まる。
$x \le 1$ では $x$ の分数べきを括り出した $x^2/8$ の Chebyshev 展開、$(1, 4]$ では別の Chebyshev 展開、$x > 4$ では尺度化した裾の $1/(x + c)$ の Chebyshev 展開を使い、計算コストは固定である。
そのため、どの形にもスコープ付き API はない。
