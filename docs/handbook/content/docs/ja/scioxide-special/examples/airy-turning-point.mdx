量子力学の束縛状態は原子の中だけでなく、地球の重力場の中にもできる。
水平な鏡の上に落ちる中性子は、下を鏡、上を重力にはさまれた井戸に閉じ込められ、高さ方向のエネルギーがとびとびの値をとる。
Nesvizhevsky ら（2002）は、Institut Laue-Langevin の超冷中性子（速さが数 m/s の中性子）を鏡と吸収体のすき間に通し、この量子状態の証拠を観測した。
線形のポテンシャル $mgz$ の Schrödinger 方程式は Airy 方程式になるので、エネルギー準位は Airy 関数 $\operatorname{Ai}$ の零点で決まる。
この例題では、`scioxide-special` の `airy_ai_with_options` と `airy_bi_with_options` が返す値と導関数で零点、波動関数、規格化、Wronskian を計算し、論文の値と WKB 近似と比べる。
Airy 関数の定義と評価法は [Airy 関数](../../algorithms/airy-functions/)で説明している。

## 重力の井戸と Airy 方程式

鉛直上向きに $z$ 軸をとり、$z = 0$ に鏡を置く。
質量 $m$ の中性子のポテンシャルは、$z > 0$ で $V(z) = mgz$、鏡の位置で無限大の壁とする。
鏡は中性子を全反射するので、波動関数は $\psi(0) = 0$ を満たす。
$z > 0$ の定常状態の Schrödinger 方程式は

$$
-\frac{\hbar^2}{2m}\,\psi''(z) + mgz\,\psi(z) = E\,\psi(z)
$$

である。
長さとエネルギーを

$$
\ell = \left(\frac{\hbar^2}{2m^2g}\right)^{1/3},\qquad
\varepsilon = mg\ell = \left(\frac{\hbar^2mg^2}{2}\right)^{1/3}
$$

で無次元化し、$\zeta = z/\ell - E/\varepsilon$ と置くと、方程式は Airy 方程式 $\psi''(\zeta) = \zeta\,\psi(\zeta)$ になる。
CODATA 2018 の値 $\hbar = 1.054571817 \times 10^{-34}$ J s、中性子の質量 $m = 1.67492749804 \times 10^{-27}$ kg と標準重力 $g = 9.80665$ m/s² を使うと、$\ell \approx 5.87$ μm、$\varepsilon \approx 0.602$ peV（$1\ \text{peV} = 10^{-12}$ eV）になる。

$z \to \infty$ で有界な解は $\operatorname{Ai}$ だけで、$\operatorname{Bi}$ は指数的に増えるので除かれる。
鏡の条件 $\psi(0) = 0$ は $\operatorname{Ai}(-E/\varepsilon) = 0$ になり、$\operatorname{Ai}$ の零点を $0 > a_1 > a_2 > \cdots$ とすると

$$
E_n = \varepsilon\,|a_n|,\qquad z_n = \frac{E_n}{mg} = \ell\,|a_n|,\qquad
\psi_n(z) = \frac{\operatorname{Ai}(z/\ell + a_n)}{\sqrt{\ell}\,|\operatorname{Ai}'(a_n)|}
$$

が得られる。
$z_n$ は古典的な転回点の高さで、それより上では波動関数が指数的に減衰する。
規格化の定数は $\operatorname{Ai}^2$ の原始関数 $x\operatorname{Ai}(x)^2 - \operatorname{Ai}'(x)^2$（DLMF §9.11）から $\int_{a_n}^\infty \operatorname{Ai}(x)^2dx = \operatorname{Ai}'(a_n)^2$ となることで決まる。

## 零点の求め方と WKB 近似

Bohr–Sommerfeld の量子化条件に、鏡での反射による位相のずれ $\pi$ と線形の転回点での $\pi/2$ を加えると

$$
\int_0^{z_n}\sqrt{2m(E_n - mgz)}\,dz = \pi\hbar\left(n - \tfrac{1}{4}\right)
$$

となり、零点の近似

$$
|a_n| \approx t_n^{2/3},\qquad t_n = \frac{3\pi}{8}(4n - 1)
$$

が得られる（WKB 近似）。
これは DLMF 9.9.6 の漸近展開 $|a_n| = t_n^{2/3}\left(1 + \tfrac{5}{48}t_n^{-2} - \cdots\right)$ の主要項で、相対誤差は $n$ が大きいほど $\tfrac{5}{48}t_n^{-2}$ に近づく。

このページのセルは WKB 近似を初期値にして Newton 法 $x \leftarrow x - \operatorname{Ai}(x)/\operatorname{Ai}'(x)$ を数回繰り返し、零点を求める。
$\operatorname{Ai}$ と $\operatorname{Ai}'$ はどちらも `airy_ai_with_options` の 1 回の評価から得る（`try_value` と `try_derivative`）。
実数の $\operatorname{Ai}$ は試験した範囲で 64 ULP 以内で、零点の近くでは絶対誤差で試験されている。
零点を番号付きで系統的に求めるには、`scioxide-rootfind` の [特殊関数の零点](../../../scioxide-rootfind/algorithms/special-function-zeros/) にある `special_zeros_with_options`（族 `SpecialZeroFamily::AiryAi`）を使う。
この関数は表の値か番号についての漸近展開から出発し、符号の変わる区間で二分法に守られた Newton 法で仕上げて、各零点を元の方程式で確かめる。

## 準位、波動関数、Wronskian

次のセルは、天体（重力加速度 $g$）と描く準位の数を選び、$n = 1, \dots, 5$ の零点、エネルギー、転回点の高さを求める。
表は、Newton 法の零点と DLMF Table 9.9.1 の値の差、零点での $\operatorname{Ai}$ の残差、$E_n$ と Nesvizhevsky ら（2002）が示した理論値 1.41、2.46、3.32、4.08 peV、転回点の高さ、Wronskian $\operatorname{Ai}\operatorname{Bi}' - \operatorname{Ai}'\operatorname{Bi}$ と $1/\pi$ の差、台形則で求めた $\int_0^\infty|\psi_n|^2dz$ を示す。
Wronskian は API が返す 4 つの値と導関数だけで作るので、値と導関数を両方とも確かめる検算になる。
グラフは規格化した波動関数 $\psi_n(z)$ [μm⁻¹ᐟ²] で、転回点の高さを縦線で示す。
$g$ を月面の 1.62 m/s² に変えると、$\ell \propto g^{-1/3}$ と $\varepsilon \propto g^{2/3}$ に従って準位が下がり、波動関数が高く広がる。

```rust
//| id: special-airy-neutron-gravity-quantization
//| ref: special-airy-neutron-gravity-quantization
//| title: 重力に束縛された中性子の準位、波動関数、Wronskian
//| run: reactive
//| crates: [scioxide-special]
//| inputs:
//|   body: {"type":"select","label":"天体（重力加速度）","options":["地球（9.80665 m/s²）","火星（3.721 m/s²）","月（1.62 m/s²）"],"value":"地球（9.80665 m/s²）"}
//|   levels: {"type":"integer","label":"描く準位の数","min":1,"max":5,"value":3}
//| cases:
//|   - {"id":"moon","label":"月面 g = 1.62 m/s²","description":"準位は 0.30 倍に下がり、転回点は 1.82 倍の高さになる。","inputs":{"body":"月（1.62 m/s²）"}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"levels","path":"/rows/0/1","approx":{"value":-2.338107410459767,"atol":1e-14}}
//|       - {"artifact":"levels","path":"/rows/0/4","approx":{"value":1.41,"atol":0.005}}
//|       - {"artifact":"levels","path":"/rows/0/4","approx":{"value":1.4067188095476253,"rtol":1e-9}}
//|       - {"artifact":"levels","path":"/rows/0/6","approx":{"value":13.72,"atol":0.01}}
//|       - {"artifact":"levels","path":"/rows/2/7","range":{"min":-1e-15,"max":1e-15}}
//|       - {"artifact":"levels","path":"/rows/0/8","approx":{"value":1,"atol":1e-9}}
//|   - case: moon
//|     expect:
//|       - {"artifact":"levels","path":"/rows/0/4","approx":{"value":0.42351635595277426,"rtol":1e-9}}
//|       - {"artifact":"levels","path":"/rows/0/5","equals":null}
use scioxide_special::{AiryOptions, airy_ai_with_options, airy_bi_with_options};

let gravity: f64 = match body.as_str() {
    "火星（3.721 m/s²）" => 3.721,
    "月（1.62 m/s²）" => 1.62,
    _ => 9.80665,
};
// CODATA 2018: ħ [J s]、中性子の質量 [kg]、電気素量 [C]
let (hbar, mass, charge) = (1.054571817e-34, 1.67492749804e-27, 1.602176634e-19);
let length = (hbar * hbar / (2.0 * mass * mass * gravity)).cbrt(); // ℓ [m]
let energy = mass * gravity * length / charge * 1e12; // ε [peV]
let ai = |x: f64| {
    airy_ai_with_options(x, AiryOptions::default())
        .and_then(|r| Ok((r.try_value()?, r.try_derivative()?)))
        .map_err(|e| e.to_string())
};
let bi = |x: f64| {
    airy_bi_with_options(x, AiryOptions::default())
        .and_then(|r| Ok((r.try_value()?, r.try_derivative()?)))
        .map_err(|e| e.to_string())
};
// DLMF Table 9.9.1 の零点と Nesvizhevsky ら（2002）の理論値 [peV]
let table = [
    -2.338107410459767,
    -4.087949444130971,
    -5.520559828095551,
    -6.786708090071759,
];
let paper = [1.41, 2.46, 3.32, 4.08];
let mut rows = Vec::new();
let mut curves = Vec::new();
let mut marks = Vec::new();
for n in 1..=5_usize {
    // WKB 近似を初期値に Newton 法で Ai の零点を求める
    let t = 3.0 * std::f64::consts::PI / 8.0 * (4.0 * n as f64 - 1.0);
    let mut zero = -t.powf(2.0 / 3.0);
    for _ in 0..4 {
        let (value, slope) = ai(zero)?;
        zero -= value / slope;
    }
    let (residual, slope) = ai(zero)?;
    let (b, b_slope) = bi(zero)?;
    let wronskian = residual * b_slope - slope * b - 1.0 / std::f64::consts::PI;
    // 波動関数 ψₙ(z) = Ai(z/ℓ + aₙ)/(√ℓ |Ai′(aₙ)|)（z は μm、ψ は μm^(−1/2)）
    let norm = 1.0 / ((length * 1e6).sqrt() * slope.abs());
    // 描く範囲は地球の 80 μm を g^(−1/3) で伸ばし、台形則で ∫|ψ|² dz を求める（独立な検算）
    let top = 80.0 * (9.80665 / gravity).cbrt();
    let dz = top / 600.0;
    let mut points = Vec::new();
    let mut probability = 0.0;
    for i in 0..=600 {
        let z = dz * f64::from(i);
        let psi = norm * ai(z * 1e-6 / length + zero)?.0;
        let weight = if i == 0 || i == 600 { 0.5 } else { 1.0 };
        probability += weight * psi * psi * dz;
        points.push([z, psi]);
    }
    let height = length * zero.abs() * 1e6; // zₙ [μm]
    if n <= levels as usize {
        curves.push(serde_json::json!({ "name": format!("n = {n}"), "points": points }));
        marks.push(serde_json::json!({ "kind": "line", "axis": "x", "value": height, "label": format!("z{n}") }));
    }
    let difference = table.get(n - 1).map(|reference| zero - reference);
    let energy_n = energy * zero.abs();
    // 論文の値は地球の重力だけに対応する
    let reference = paper.get(n - 1).copied().filter(|_| gravity == 9.80665);
    rows.push((
        n as u32,
        zero,
        difference,
        residual,
        energy_n,
        reference,
        height,
        wronskian,
        probability,
    ));
}
emit_line_chart!(
    &curves,
    options = &serde_json::json!({
        "xLabel": "鏡からの高さ z [μm]",
        "yLabel": "波動関数 ψₙ(z) [μm^(−1/2)]",
        "annotations": marks
    })
);
let fixed3 = serde_json::json!({ "fractionDigits": 3 });
let fixed12 = serde_json::json!({ "fractionDigits": 12 });
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let columns = serde_json::json!([
    { "key": "0", "label": "n", "type": "integer" },
    { "key": "1", "label": "零点 aₙ", "type": "number", "format": fixed12 },
    { "key": "2", "label": "DLMF の表との差", "type": "number", "format": sci2, "nullText": "—" },
    { "key": "3", "label": "Ai(aₙ)", "type": "number", "format": sci2 },
    { "key": "4", "label": "Eₙ [peV]", "type": "number", "format": fixed3 },
    { "key": "5", "label": "論文の Eₙ [peV]", "type": "number", "nullText": "—" },
    { "key": "6", "label": "転回点 zₙ [μm]", "type": "number", "format": fixed3 },
    { "key": "7", "label": "Wronskian − 1/π", "type": "number", "format": sci2 },
    { "key": "8", "label": "∫|ψₙ|² dz", "type": "number", "format": fixed3 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "levels" })
);
```

地球の重力では $\ell = 5.869$ μm、$\varepsilon = 0.6016$ peV で、$E_1 = 1.407$、$E_2 = 2.460$、$E_3 = 3.321$、$E_4 = 4.083$ peV になり、Nesvizhevsky ら（2002）の 1.41、2.46、3.32、4.08 peV と表示の桁で一致する。
転回点の高さは $z_1 = 13.7$ μm、$z_2 = 24.0$ μm、$z_3 = 32.4$ μm である。
論文では、鏡と吸収体のすき間が約 15 μm より狭いと中性子がほとんど通らず、それを超えると通り始めた。
$z_1$ より少し広いのは、波動関数が転回点の上の禁止された領域へ指数的にしみ出すからである。

Newton 法の零点は DLMF の表の値と $n = 1, 3, 4$ で一致し、$n = 2$ で $9 \times 10^{-16}$ 違う。
零点での $\operatorname{Ai}$ の残差は $3 \times 10^{-16}$ 以下で、Wronskian と $1/\pi$ の差は $6 \times 10^{-17}$ 以下である。
台形則の $\int|\psi_n|^2dz$ は $n = 1$ から 4 で 1 との差が $4 \times 10^{-13}$ 以下になり、規格化の定数 $1/(\sqrt\ell|\operatorname{Ai}'(a_n)|)$ が正しいことがわかる。
$n = 5$ では差が $1.0 \times 10^{-10}$ に増えるが、これは転回点 $z_5 = 46.6$ μm の上で減衰しきらない裾が、積分の上端 80 μm の外に残るためである。
月の重力（1.62 m/s²）では準位が地球の $(1.62/9.80665)^{2/3} = 0.30$ 倍、転回点が $(9.80665/1.62)^{1/3} = 1.82$ 倍になる。
論文の値は地球の重力に対するものなので、この場合は表に出さない。


## WKB 近似の精度

次のセルは、$n = 1, \dots, N$ の零点を同じ方法で求め、WKB 近似の相対誤差を両対数軸で描く。
破線は DLMF 9.9.6 の次の項から予想される $\tfrac{5}{48}t_n^{-2}$ である。
二つが重なれば、零点の計算と漸近展開が整合していることになる。

```rust
//| id: special-airy-wkb-zeros
//| ref: special-airy-wkb-zeros
//| title: Airy 関数の零点と WKB 近似の相対誤差
//| run: reactive
//| crates: [scioxide-special]
//| inputs:
//|   count: {"type":"integer","label":"零点の数 N","min":5,"max":200,"value":40}
//| cases:
//|   - {"id":"many","label":"N = 200","description":"n = 200 では相対誤差が 10⁻⁷ 程度まで下がる。","inputs":{"count":200}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"wkb","path":"/rows/0/3","approx":{"value":0.007637209338536672,"rtol":1e-9}}
//|       - {"artifact":"wkb","path":"/rows/2/3","approx":{"value":2.9687e-6,"rtol":1e-3}}
//|   - case: many
//|     expect:
//|       - {"artifact":"wkb","path":"/rows/2/3","approx":{"value":1.17563e-7,"rtol":1e-3}}
use scioxide_special::{AiryOptions, airy_ai_with_options};

let ai = |x: f64| {
    airy_ai_with_options(x, AiryOptions::default())
        .and_then(|r| Ok((r.try_value()?, r.try_derivative()?)))
        .map_err(|e| e.to_string())
};
let mut errors = Vec::new();
let mut predicted = Vec::new();
let mut rows = Vec::new();
for n in 1..=count as usize {
    let t = 3.0 * std::f64::consts::PI / 8.0 * (4.0 * n as f64 - 1.0);
    let wkb = t.powf(2.0 / 3.0);
    let mut zero = -wkb;
    for _ in 0..4 {
        let (value, slope) = ai(zero)?;
        zero -= value / slope;
    }
    let relative = (wkb - zero.abs()).abs() / zero.abs();
    // DLMF 9.9.6 の次の項による予想（独立な検算）
    let next_term = 5.0 / 48.0 / (t * t);
    errors.push([n as f64, relative]);
    predicted.push([n as f64, next_term]);
    if n == 1 || n == 4 || n == count as usize {
        rows.push((n as u32, zero, wkb, relative, next_term));
    }
}
emit_line_chart!(
    &vec![
        serde_json::json!({ "name": "WKB の相対誤差", "points": errors }),
        serde_json::json!({ "name": "(5/48) tₙ⁻²", "points": predicted, "style": { "lineType": "dashed" } })
    ],
    options = &serde_json::json!({
        "xLabel": "零点の番号 n [-]",
        "yLabel": "相対誤差 [-]",
        "xType": "log",
        "yType": "log"
    })
);
let fixed10 = serde_json::json!({ "fractionDigits": 10 });
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let columns = serde_json::json!([
    { "key": "0", "label": "n", "type": "integer" },
    { "key": "1", "label": "零点 aₙ", "type": "number", "format": fixed10 },
    { "key": "2", "label": "WKB の |aₙ|", "type": "number", "format": fixed10 },
    { "key": "3", "label": "相対誤差", "type": "number", "format": sci3 },
    { "key": "4", "label": "(5/48) tₙ⁻²", "type": "number", "format": sci3 }
]);
emit_table_with_columns!(columns, rows, metadata = serde_json::json!({ "id": "wkb" }));
```

WKB 近似の相対誤差は $n = 1$ で $7.6 \times 10^{-3}$、$n = 4$ で $3.3 \times 10^{-4}$、$n = 40$ で $3.0 \times 10^{-6}$ と減る。
予想 $\tfrac{5}{48}t_n^{-2}$ との比は $n = 1$ で 0.92、$n = 40$ で 0.99996 で、$n$ が大きいほど次の項だけで誤差が説明できる。
グラフでは二つの線が傾き $-2$ の直線に重なる。
$n = 200$ では相対誤差が $1.18 \times 10^{-7}$ まで下がり、WKB 近似の初期値から Newton 法を 4 回繰り返せば零点が丸めの水準まで求まる。


## まとめ

線形のポテンシャルの束縛状態では、Airy 関数 $\operatorname{Ai}$ の零点 $a_n$ でエネルギー $E_n = \varepsilon|a_n|$ と転回点の高さ $z_n = \ell|a_n|$ が決まる。
`airy_ai_with_options` は値と導関数を一度に返すので、Newton 法による零点、規格化の定数 $|\operatorname{Ai}'(a_n)|$、Wronskian の検算がすべて同じ評価から作れる。
地球の重力では $E_1 = 1.41$ peV、$z_1 = 13.7$ μm で、Nesvizhevsky ら（2002）の値と一致する。
WKB 近似は $n = 1$ でも相対誤差 0.8% 以下で、誤差は $t_n^{-2}$ に比例して減るので、大きい $n$ の初期値として十分である。

零点を番号付きで多数求める汎用の方法は [特殊関数の零点](../../../scioxide-rootfind/algorithms/special-function-zeros/)で確かめる。
周期的な駆動による束縛と安定性の例は [Paul トラップの安定領域と Mathieu 関数](../paul-trap-stability/)にある。
