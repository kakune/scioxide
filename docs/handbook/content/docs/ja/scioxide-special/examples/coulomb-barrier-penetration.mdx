正の電荷を持つ二つの原子核が反応するには、両者の間の Coulomb 斥力の障壁を通り抜けなければならない。
恒星内部での水素の燃焼や制御核融合では、障壁の高さより 1〜3 桁低いエネルギーで反応が起こり、反応率はトンネル効果の確率でほぼ決まる。
Gamow（1928）は、この確率が $e^{-2\pi\eta}$（Gamow 因子）に支配されることを示し、$\alpha$ 崩壊のライフタイムが崩壊エネルギーに極端に敏感であることを説明した。
この例では、原子核の表面にあたる半径で Coulomb 波動関数を評価して障壁の透過率を求め、低エネルギーの極限式、Gamow 因子、中性子の場合の球 Bessel 関数の式、Wronskian で確かめる。
関数の定義と評価法は [Coulomb 波動関数と水素様動径状態](../../algorithms/coulomb-and-hydrogenic/) にある。

## モデルと単位

質量数 $A_1$、$A_2$、電荷 $Z_1e$、$Z_2e$ の二つの原子核の相対運動を考える。
換算質量は $\mu c^2 = A_1A_2/(A_1 + A_2) \cdot uc^2$ で近似し（核の質量を質量数 × 原子質量単位で置き換えると 0.1 % 程度の差が出る）、重心系のエネルギー $E$ を MeV、長さを fm で測る。
定数は CODATA 2018 の推奨値（Tiesinga ほか 2021）の $\hbar c = 197.3269804$ MeV fm、$e^2/(4\pi\varepsilon_0) = \alpha\hbar c = 1.439964548$ MeV fm、$uc^2 = 931.49410242$ MeV を使う。

波数 $k$、Sommerfeld パラメータ $\eta$、無次元の動径 $\rho = kR$ は次の式で決まる。

$$
k = \frac{\sqrt{2\mu c^2 E}}{\hbar c}, \qquad
\eta = \frac{Z_1Z_2\,\alpha\hbar c\,\mu c^2}{(\hbar c)^2 k} = Z_1Z_2\,\alpha\sqrt{\frac{\mu c^2}{2E}}, \qquad
\rho = kR.
$$

核力の届く半径は $R = r_0(A_1^{1/3} + A_2^{1/3})$ とし、$r_0$ を入力にする。
半径 $R$ での Coulomb 障壁の高さは $B = Z_1Z_2\,\alpha\hbar c/R$ で、$E/B = \rho/(2\eta)$ である。
$\eta\rho = Z_1Z_2\,\alpha\hbar c\,\mu c^2 R/(\hbar c)^2$ はエネルギーによらず、$R$ と系だけで決まる。

## 透過率

$R$ の外側では Coulomb 力だけが働くので、部分波 $l$ の動径関数は $F_l$ と $G_l$ の一次結合である。
外向きの波 $H_l^+ = G_l + iF_l$ の流束と、$R$ での振幅の 2 乗の比から、障壁の透過率（R 行列理論の penetration factor、Lane・Thomas 1958）が定まる。

$$
P_l(E) = \frac{\rho}{F_l(\eta, \rho)^2 + G_l(\eta, \rho)^2}.
$$

障壁の上（$E \gg B$）では $F_l^2 + G_l^2 \to 1$ で $P_l \approx \rho$ になる。
障壁の下では $G_l$ が指数的に大きくなり、$P_l$ は急に小さくなる。
中性子（$Z_1 = 0$）では $\eta = 0$ で、$F_l = \rho j_l(\rho)$、$G_l = -\rho y_l(\rho)$ から $P_l = 1/(\rho(j_l^2 + y_l^2))$ になり、$P_0 = 1$、$P_1 = \rho^2/(1 + \rho^2)$ のように遠心力の障壁だけが残る。

### 低エネルギーの極限と Gamow 因子

$\eta \to \infty$ で $\eta\rho$ を固定した極限（エネルギーを下げて $R$ を固定した極限）では、Coulomb 波動関数は変形 Bessel 関数で書ける（DLMF 33.10.3）。

$$
G_l(\eta, \rho) \sim \frac{2(2\eta)^l}{(2l+1)!\,C_l(\eta)}\sqrt{2\eta\rho}\;K_{2l+1}\!\left(\sqrt{8\eta\rho}\right).
$$

$F_l$ は同じ極限で $C_l(\eta)$ に比例して小さくなるので、透過率は $P_l \approx \rho/G_l^2$ で近似できる。
$l = 0$ では $C_0(\eta)^2 \approx 2\pi\eta\,e^{-2\pi\eta}$ を使うと、次の式になる。

$$
P_0 \approx \frac{\pi}{4K_1\!\left(\sqrt{8\eta\rho}\right)^2}\,e^{-2\pi\eta}.
$$

$\sqrt{8\eta\rho}$ は $R$ と系だけで決まるので、$R$ を固定してエネルギーを下げると、$P_0$ のエネルギー依存性はすべて Gamow 因子 $e^{-2\pi\eta}$ に入る。
天体核反応で断面積 $\sigma(E)$ を $S(E) = \sigma(E)\,E\,e^{2\pi\eta}$（天体物理の S 因子）に直して滑らかな関数として外挿するのは、この性質による。

## 透過率のエネルギー依存性

次のセルは、系、軌道角運動量 $l$、半径の係数 $r_0$ を選び、$E = 0.01B$ から $2B$ までの 201 点で `coulomb_wave` を評価して $P_l(E)$ を描く（中性子では $B$ の代わりに 1 MeV を目安のエネルギーにする）。
破線は、荷電粒子では DLMF 33.10.3 の極限式、中性子では球 Bessel 関数の式 $1/(\rho(j_l^2 + y_l^2))$ で、どちらも `coulomb_normalization`、`bessel_k`、`spherical_jn`、`spherical_yn` で計算する独立な参照である。
表は $E/B = 0.01, 0.03, 0.1, 0.3, 1$ の 5 点で、$\eta$、$\rho$、$P_l$、参照の式との比、Gamow 因子を掛けた $P_l\,e^{2\pi\eta}$、Wronskian と 1 の差を示す。

```rust
//| id: special-coulomb-barrier-model
//| kind: definitions
//| title: 二体系の運動学と透過率
//| crates: [scioxide-special]
use scioxide_special::{bessel_k, coulomb_normalization, coulomb_wave, spherical_jn, spherical_yn};

/// ħc [MeV fm]、αħc = e²/(4πε₀) [MeV fm]、uc² [MeV]（CODATA 2018）。
pub(crate) const HBAR_C: f64 = 197.326_980_4;
pub(crate) const ALPHA_HBAR_C: f64 = 1.439_964_548;
pub(crate) const AMU: f64 = 931.494_102_42;

/// 二つの原子核の電荷と質量数。
pub(crate) struct Pair {
    pub(crate) z: f64,
    pub(crate) mass: f64,
    pub(crate) radius: f64,
}

/// 系の名前から、電荷の積 Z₁Z₂、換算質量 μc² [MeV]、半径 R = r₀(A₁^⅓ + A₂^⅓) [fm] を作る。
pub(crate) fn pair(name: &str, r0: f64) -> Pair {
    let (z1, a1, z2, a2) = match name {
        "d + t" => (1.0, 2.0, 1.0, 3.0),
        "α + ²⁰⁸Pb" => (2.0, 4.0, 82.0, 208.0),
        "n + ¹²C（η = 0）" => (0.0, 1.0, 6.0, 12.0),
        _ => (1.0, 1.0, 6.0, 12.0),
    };
    Pair {
        z: z1 * z2,
        mass: a1 * a2 / (a1 + a2) * AMU,
        radius: r0 * (f64::cbrt(a1) + f64::cbrt(a2)),
    }
}

impl Pair {
    /// 障壁の高さ B [MeV]。中性子では目安の 1 MeV を返す。
    pub(crate) fn scale(&self) -> f64 {
        if self.z == 0.0 {
            1.0
        } else {
            self.z * ALPHA_HBAR_C / self.radius
        }
    }

    /// エネルギー E [MeV] での (η, ρ)。
    pub(crate) fn kinematics(&self, energy: f64) -> (f64, f64) {
        let k = (2.0 * self.mass * energy).sqrt() / HBAR_C;
        let eta = self.z * ALPHA_HBAR_C * self.mass / (HBAR_C * HBAR_C * k);
        (eta, k * self.radius)
    }
}

/// 透過率 P_l = ρ/(F² + G²) と Wronskian F′G − FG′。
pub(crate) fn penetrability(l: f64, eta: f64, rho: f64) -> Result<(f64, f64), String> {
    let [f, g, fp, gp] = coulomb_wave(l, eta, rho).map_err(|e| e.to_string())?;
    Ok((rho / (f * f + g * g), fp * g - f * gp))
}

/// 独立な参照: η = 0 では 1/(ρ(j_l² + y_l²))、η > 0 では DLMF 33.10.3 の G_l による ρ/G_l²。
pub(crate) fn reference(l: u32, eta: f64, rho: f64) -> Result<f64, String> {
    if eta == 0.0 {
        let j = spherical_jn(l, rho).map_err(|e| e.to_string())?;
        let y = spherical_yn(l, rho).map_err(|e| e.to_string())?;
        return Ok(1.0 / (rho * (j * j + y * y)));
    }
    let lf = f64::from(l);
    let c = coulomb_normalization(lf, eta).map_err(|e| e.to_string())?;
    let x = (8.0 * eta * rho).sqrt();
    let k = bessel_k(2.0 * lf + 1.0, x).map_err(|e| e.to_string())?;
    let factorial: f64 = (1..=2 * l + 1).map(f64::from).product();
    let g = 2.0 * (2.0 * eta).powi(l as i32) / (factorial * c) * (2.0 * eta * rho).sqrt() * k;
    Ok(rho / (g * g))
}
```

既定の p + ¹²C（$R = 3.95$ fm、$B = 2.19$ MeV）では、$P_0$ は $E = B$ の $0.68$ から $E = 0.01B$ の $2.3 \times 10^{-15}$ まで 14 桁下がる。
参照の式との比は $E/B = 0.01$ で $0.986$、$0.1$ で $0.86$、$1$ で $0.25$ で、極限式が低エネルギーで透過率に近づくことが分かる。
$P_0\,e^{2\pi\eta}$ は同じ範囲で $127$、$111$、$32$ と変わり、低エネルギーでは一定値 $\pi/(4K_1(\sqrt{8\eta\rho})^2) \approx 128$（$\eta\rho = 0.753$）に近づく。
14 桁の変化のほとんどを $e^{-2\pi\eta}$ が受け持っていることになる。
Wronskian と 1 の差はどの点でも 0.5 $\varepsilon$ 単位以下である。

α + ²⁰⁸Pb では障壁は $B = 26.2$ MeV で、$\alpha$ 崩壊のエネルギーに近い $E = 7.86$ MeV（$0.3B$）で $P_0 = 2.1 \times 10^{-16}$、$E = 0.01B$ では $10^{-237}$ まで下がる。
ここでは $\eta\rho = 200$ と大きく、$\rho$ も 1 より大きいので、$E = 0.01B$ でも極限式との比は $0.87$ にとどまる。
極限式は $\rho \ll 1$ の目安であり、正確な透過率には $F_l$ と $G_l$ そのものを使う。
中性子の $l = 1$ では、比は丸めの範囲で 1 になり、$P_1 = \rho^2/(1 + \rho^2)$ がどのエネルギーでも再現される。

## 部分波ごとの透過率

障壁の下では、遠心力の障壁 $l(l+1)/\rho^2$ が Coulomb の障壁に加わるので、高い部分波ほど透過率が小さい。
次のセルは、系と $E/B$ を選び、$r_0 = 1.2$ fm で $l = 0, \ldots, 6$ の `[F, G, F′, G′]` を `coulomb_wave_sequence` で一度に作って、$P_l$ と $P_l/P_0$ を示す。
列は $F$ を下向き、$G$ を上向きの次数の漸化式で作るので、次数ごとに `coulomb_wave` を呼んだ値との相対差も示し、Wronskian と合わせて漸化式の精度を確かめる。

```rust
//| id: special-coulomb-barrier-partial-waves
//| ref: special-coulomb-barrier-partial-waves
//| title: 部分波ごとの Coulomb 障壁の透過率
//| run: reactive
//| uses: [special-coulomb-barrier-model]
//| crates: [scioxide-special]

//| cases:
//|   - {"id":"above","label":"E = 1.5B","description":"障壁の上では低い部分波の透過率は ρ 程度にそろい、遠心力の障壁だけが高い l を抑える。","inputs":{"fraction":1.5}}

//|   - case: default

//|     expect:
//|       - {"artifact":"partial-waves","path":"/rows/0/1","approx":{"value":14.20893438411238,"rtol":1e-12}}

//|     expect:
//|       - {"artifact":"partial-waves","path":"/rows/1/2","approx":{"value":0.09922974945837255,"rtol":1e-10}}
//|       - {"artifact":"partial-waves","path":"/rows/6/4","range":{"max":8}}

    rows.push((
        l as u32,
        p,
        p / p0,
        (fp * g - f * gp - 1.0).abs() / f64::EPSILON,
        difference / f64::EPSILON,

    { "key": "2", "label": "P_l / P_0 [-]", "type": "number", "format": sci4 },
    { "key": "3", "label": "|W − 1| [ε 単位]", "type": "number", "format": fixed1 },
    { "key": "4", "label": "スカラー評価との相対差 [ε 単位]", "type": "number", "format": fixed1 }
]);

    "E = {energy:.4} MeV、R = {:.3} fm、η = {eta:.4}、ρ = {rho:.4}",
    nuclei.radius
));
```

既定の α + ²⁰⁸Pb、$E = 0.3B = 7.86$ MeV では $\rho = 11$ と大きいので、$P_l/P_0$ は $l = 6$ でも $0.034$ で、遠心力の障壁の効果は緩やかである。
p + ¹²C の $E = 0.1B$ では $\rho = 0.39$ と小さく、$P_l/P_0$ は $l = 1$ で $0.099$、$l = 6$ で $1.2 \times 10^{-13}$ まで下がる。
低エネルギーの反応で $s$ 波（場合によっては $p$ 波まで）だけを考えればよいのは、このためである。
Wronskian と 1 の差は 1 $\varepsilon$ 単位以下、次数ごとの `coulomb_wave` との相対差は 1.5 $\varepsilon$ 単位以下で、列の漸化式はスカラー評価と同じ精度を保つ。

## まとめ

障壁の透過率は、核の表面の半径 $\rho = kR$ で `coulomb_wave` が返す $F_l$、$G_l$ から $P_l = \rho/(F_l^2 + G_l^2)$ として求まり、$E/B$ が小さいほど指数的に小さくなる。
$R$ を固定した低エネルギーの極限では DLMF 33.10.3 の変形 Bessel 関数の式が $P_l$ を近似し、$P_0$ のエネルギー依存性は Gamow 因子 $e^{-2\pi\eta}$ に集まる。
中性子では $\eta = 0$ で球 Bessel 関数の式に一致し、遠心力の障壁だけが透過率を下げる。
多くの部分波が要るときは `coulomb_wave_sequence` を使えば、次数ごとに評価するのと同じ精度で一度に求まる。
Coulomb 波動関数の評価法と精度の保証は [Coulomb 波動関数と水素様動径状態](../../algorithms/coulomb-and-hydrogenic/) で、束縛状態の側の計算は [水素様原子の動径波動関数と期待値](../hydrogen-radial-states/) で確かめる。
