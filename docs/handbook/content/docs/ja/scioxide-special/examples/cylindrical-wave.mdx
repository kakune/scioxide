円柱対称な波は、直交座標の平面波を三角関数が表すように、円柱 Bessel 関数で表される。
原点を含む領域の定在波や開口の回折像は第一種 Bessel 関数 $J_\nu$ で、無限遠へ広がる進行波は第一種 Hankel 関数 $H_\nu^{(1)}$ で書ける。
この例題では、望遠鏡の円形開口による Fraunhofer 回折像（Airy 円盤）の強度と囲い込みエネルギーを求め、暗環の位置と分解能を確かめる。
続いて、空気中の線音源から出る円筒波の振幅を Hankel 関数の漸近形と比べ、半径によらないエネルギー流束を Wronskian で確かめる。
関数の定義と評価法は [円柱 Bessel 関数と Hankel 関数](../../algorithms/airy-bessel-and-hankel/) で説明した。
円形膜の固有振動数（$J_\nu$ の零点）は [円形膜の固有振動数と Bessel 関数の零点](../../../scioxide-rootfind/examples/circular-membrane/) で扱う。

## 円形開口の回折像

波長 $\lambda$ の平面波が直径 $D$（半径 $a = D/2$）の円形の開口に垂直に入射し、十分遠方（または焦点面）で回折像を観測する。
Fraunhofer 回折の振幅は開口面で位相因子を積分した値で、開口面の極座標 $(\rho, \varphi)$ と回折角 $\theta$ を使うと次のようになる。

$$
U(\theta) \propto \int_0^a \int_0^{2\pi} e^{-\mathrm{i}k\rho\sin\theta\cos\varphi}\,d\varphi\,\rho\,d\rho
= 2\pi\int_0^a J_0(k\rho\sin\theta)\,\rho\,d\rho
= 2\pi a^2\,\frac{J_1(x)}{x}.
$$

ここで $k = 2\pi/\lambda$、$x = ka\sin\theta = \pi D\sin\theta/\lambda$ である。
1 つ目の等号は $J_0$ の積分表示 $J_0(z) = \frac{1}{2\pi}\int_0^{2\pi}e^{-\mathrm{i}z\cos\varphi}\,d\varphi$（DLMF §10.9）、2 つ目は $(tJ_1(t))' = tJ_0(t)$（DLMF §10.6）による。
中心の強度 $I_0$ で割った強度は

$$
\frac{I(x)}{I_0} = \left[\frac{2J_1(x)}{x}\right]^2 = \Lambda_1(x)^2, \qquad
\frac{2J_1(x)}{x} = 1 - \frac{x^2}{8} + \frac{x^4}{192} - \cdots
$$

である。
$\Lambda_1$ は Jahnke–Emde の Lambda 関数で、`bessel_lambda(1.0, x)` は $x = 0$ でも 0 による割り算をせずに $2J_1(x)/x$ を返す。

暗環は $J_1$ の正の零点 $x = j_{1,n}$ にでき、最初の 4 つは $j_{1,1} = 3.8317060$、$j_{1,2} = 7.0155867$、$j_{1,3} = 10.1734681$、$j_{1,4} = 13.3236919$ である（Abramowitz and Stegun, 1964, Table 9.5）。
零点を任意の桁数で求めるには `scioxide-rootfind` の `special_zeros` を使い、その使い方は [円形膜の固有振動数と Bessel 関数の零点](../../../scioxide-rootfind/examples/circular-membrane/) にある。
最初の暗環の角度半径 $\theta_1$ は

$$
\sin\theta_1 = \frac{j_{1,1}}{\pi}\,\frac{\lambda}{D} = 1.2197\,\frac{\lambda}{D}
$$

で、二つの点光源の像の中心が $\theta_1$ だけ離れれば分離して見えるとする基準が Rayleigh の分解能 $\theta_R \approx 1.22\lambda/D$ である。
直径 100 mm の望遠鏡で $\lambda = 550$ nm なら、$\theta_1 = 6.71 \times 10^{-6}$ rad $= 1.38$ 秒角になる。

## 囲い込みエネルギー

中心から角度半径 $x$ の円の内側に入る光の割合を囲い込みエネルギーと呼ぶ。
強度を像面の面積で積分すると、$x\,dx$ の重みで

$$
E(x) = \frac{\int_0^x [2J_1(t)/t]^2\,t\,dt}{\int_0^\infty [2J_1(t)/t]^2\,t\,dt} = 2\int_0^x \frac{J_1(t)^2}{t}\,dt = 1 - J_0(x)^2 - J_1(x)^2
$$

となる（Rayleigh, 1881）。
最後の等号は $J_0' = -J_1$ と $J_1' = J_0 - J_1/x$（DLMF 10.6.2）から $\frac{d}{dx}[1 - J_0^2 - J_1^2] = 2J_1^2/x$ となり、$x = 0$ で両辺が 0 になることで確かめられる。
暗環では $J_1 = 0$ なので $E(j_{1,n}) = 1 - J_0(j_{1,n})^2$ で、最初の暗環の内側（Airy 円盤）に全体の約 84 % が入る。

## 回折像の計算

次のセルは波長 $\lambda$ [nm] と開口の直径 $D$ [mm] を選び、回折角 $\theta$ を 0 から 6 秒角まで動かして、相対強度 $\Lambda_1(x)^2$ と囲い込みエネルギー $1 - J_0^2 - J_1^2$ を描く。
二つの図は同じ $\theta$ を横軸に持つので連動し、縦線は Rayleigh の分解能 $1.22\lambda/D$ を示す。
強度は 1 から $10^{-4}$ 以下まで変わるので対数軸で描き、暗環は谷として見える。

1 つ目の表は暗環ごとに、文献の零点 $j_{1,n}$、$x$ を 0.05 刻みで走査して $J_1$ の符号が変わった区間、文献の零点での $\lvert J_1\rvert$、囲い込みエネルギー、角度半径 $\theta_n$ を示す。
2 つ目の表は独立な検算で、$\theta_1$ の厳密な値と $1.22\lambda/D$、Simpson 則で $2\int_0^{j_{1,1}} J_1(t)^2/t\,dt$ を数値積分した値と閉形式 $1 - J_0^2$ の差、$x = 0.1$ での $\Lambda_1$ と級数 $1 - x^2/8 + x^4/192$ の差を示す。
この差は打ち切った次の項 $x^6/9216 \approx 1.09 \times 10^{-10}$ とほぼ等しくなる。
Simpson 則と級数は検算のための手計算で、被積分関数の値は API から取る。

```rust
//| id: special-airy-disk-diffraction
//| ref: special-airy-disk-diffraction
//| title: 円形開口の回折像の強度と囲い込みエネルギー
//| run: reactive
//| crates: [scioxide-core, scioxide-special]
//| inputs:
//|   wavelength: {"type":"range","label":"波長 λ [nm]","description":"可視光の範囲で変える。","min":400,"max":700,"step":10,"value":550}
//|   diameter: {"type":"range","label":"開口の直径 D [mm]","description":"像の広がりは 1/D に比例する。","min":50,"max":500,"step":10,"value":100}
//| cases:
//|   - {"id":"large-aperture","label":"D = 400 mm","description":"直径を 4 倍にすると、暗環の角度は 4 分の 1 になる。","inputs":{"diameter":400}}

//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"rings","path":"/rows/0/2","range":{"min":3.78,"max":3.8317}}
//|       - {"artifact":"rings","path":"/rows/0/3","range":{"min":3.8318,"max":3.89}}
//|       - {"artifact":"rings","path":"/rows/0/4","range":{"max":1e-15}}
//|       - {"artifact":"rings","path":"/rows/0/5","approx":{"value":0.8378,"atol":1e-4}}
//|       - {"artifact":"rings","path":"/rows/0/6","approx":{"value":1.383662355951642,"rtol":1e-12}}
//|       - {"artifact":"checks","path":"/rows/0/3","range":{"max":1e-12}}
//|       - {"artifact":"checks","path":"/rows/0/4","approx":{"value":1.085e-10,"rtol":2e-3}}
//|   - case: large-aperture
//|     expect:
//|       - {"artifact":"rings","path":"/rows/0/6","approx":{"value":0.34591558898547825,"rtol":1e-12}}
//|   - case: red-light
//|     expect:
//|       - {"artifact":"rings","path":"/rows/0/6","approx":{"value":3.52204963347619,"rtol":1e-12}}
use scioxide_core::RealScalar;
use scioxide_special::{bessel_j, bessel_lambda};

// x = πD sinθ/λ。D [mm] と λ [nm] を m にそろえる。
let arcsec = std::f64::consts::PI / (180.0 * 3600.0);
let scale = std::f64::consts::PI * (diameter * 1e-3) / (wavelength * 1e-9);
let x_of = |theta_arcsec: f64| scale * RealScalar::sin(theta_arcsec * arcsec);
let encircled = |x: f64| -> Result<f64, String> {
    let j0 = bessel_j(0.0, x).map_err(|e| e.to_string())?;
    let j1 = bessel_j(1.0, x).map_err(|e| e.to_string())?;
    Ok(1.0 - j0 * j0 - j1 * j1)
};

let mut intensity = Vec::new();
let mut energy = Vec::new();
for index in 0..=600 {
    let theta = 6.0 * f64::from(index) / 600.0;
    let x = x_of(theta);
    // Λ₁(x) = 2J₁(x)/x は x = 0 でも定義される。
    let amplitude = bessel_lambda(1.0, x).map_err(|e| e.to_string())?;
    if amplitude != 0.0 {
        intensity.push([theta, amplitude * amplitude]);
    }
    energy.push([theta, encircled(x)?]);
}
let rayleigh = 1.22 * (wavelength * 1e-9) / (diameter * 1e-3) / arcsec;
let marker = serde_json::json!([{
    "kind": "line",
    "axis": "x",
    "value": rayleigh,
    "label": "1.22λ/D"
}]);
emit_line_chart!(
    &vec![serde_json::json!({ "name": "I/I₀ = Λ₁(x)²", "points": intensity })],
    options = &serde_json::json!({
        "link": { "group": "airy-angle" },
        "xLabel": "回折角 θ [秒角]",
        "yLabel": "相対強度 I/I₀ [-]",
        "yType": "log",
        "xMin": 0.0,
        "xMax": 6.0,
        "yMin": 1e-6,
        "yMax": 1.0,
        "annotations": marker
    })
);
emit_line_chart!(
    &vec![serde_json::json!({ "name": "1 − J₀² − J₁²", "points": energy })],
    options = &serde_json::json!({
        "link": { "group": "airy-angle" },
        "xLabel": "回折角 θ [秒角]",
        "yLabel": "囲い込みエネルギー E [-]",
        "xMin": 0.0,
        "xMax": 6.0,
        "yMin": 0.0,
        "yMax": 1.0,
        "annotations": marker
    })
);

// 暗環: 文献の零点（Abramowitz and Stegun, Table 9.5）と、走査で見つけた符号の変化。
let zeros: [f64; 4] = [
    3.8317059702075123,
    7.0155866698156188,
    10.173468135062722,
    13.323691936314223,
];
let mut brackets = Vec::new();
let mut previous = (0.05, bessel_j(1.0, 0.05).map_err(|e| e.to_string())?);
for step in 2..=300 {
    let x = 0.05 * f64::from(step);
    let value = bessel_j(1.0, x).map_err(|e| e.to_string())?;
    if value.signum() != previous.1.signum() {
        brackets.push((previous.0, x));
    }
    previous = (x, value);
}
let mut rings = Vec::new();
for (n, (&zero, &(left, right))) in zeros.iter().zip(&brackets).enumerate() {
    let residual = bessel_j(1.0, zero).map_err(|e| e.to_string())?.abs();
    let theta = RealScalar::asin(zero / scale) / arcsec;
    rings.push((n + 1, zero, left, right, residual, encircled(zero)?, theta));
}

let sig5 = serde_json::json!({ "significantDigits": 5 });
let columns = serde_json::json!([
    { "key": "0", "label": "暗環 n", "type": "integer" },
    { "key": "1", "label": "文献の零点 j₁,ₙ [-]", "type": "number", "format": sig5 },
    { "key": "2", "label": "符号変化の左端 [-]", "type": "number", "format": sig5 },
    { "key": "3", "label": "符号変化の右端 [-]", "type": "number", "format": sig5 },
    { "key": "4", "label": "|J₁(j₁,ₙ)| [-]", "type": "number", "format": sci2 },
    { "key": "5", "label": "囲い込みエネルギー [-]", "type": "number", "format": sig5 },
    { "key": "6", "label": "角度半径 θₙ [秒角]", "type": "number", "format": sig5 }
]);
emit_table_with_columns!(
    columns,
    rings,
    metadata = serde_json::json!({ "id": "rings" })
);

// 検算 1: Simpson 則で 2∫₀^{j₁,₁} J₁(t)²/t dt = ∫ t Λ₁(t)²/2 dt（手計算）。
let (upper, panels) = (zeros[0], 2000);
let h = upper / f64::from(panels);
let mut simpson = 0.0;
for i in 0..=panels {
    let t = h * f64::from(i);
    let lambda = bessel_lambda(1.0, t).map_err(|e| e.to_string())?;
    let weight = if i == 0 || i == panels {
        1.0
    } else if i % 2 == 1 {
        4.0
    } else {
        2.0
    };
    simpson += weight * 0.5 * t * lambda * lambda;
}
simpson *= h / 3.0;
// 検算 2: x = 0.1 の級数 1 − x²/8 + x⁴/192。打ち切った次の項は x⁶/9216 ≈ 1.09 × 10⁻¹⁰。
let small = 0.1_f64;
let series = 1.0 - small * small / 8.0 + small.powi(4) / 192.0;
let lambda_small = bessel_lambda(1.0, small).map_err(|e| e.to_string())?;
let exact_theta = rings[0].6;
let columns = serde_json::json!([
    { "key": "0", "label": "θ₁（厳密）[秒角]", "type": "number", "format": sig5 },
    { "key": "1", "label": "1.22λ/D [秒角]", "type": "number", "format": sig5 },
    { "key": "2", "label": "Simpson 則の E(j₁,₁) [-]", "type": "number", "format": sig5 },
    { "key": "3", "label": "閉形式との差 [-]", "type": "number", "format": sci2 },
    { "key": "4", "label": "x = 0.1 の級数との差 [-]", "type": "number", "format": sci2 }
]);
emit_table_with_columns!(
    columns,
    vec![(
        exact_theta,
        rayleigh,
        simpson,
        (simpson - encircled(upper)?).abs(),
        (lambda_small - series).abs(),
    )],
    metadata = serde_json::json!({ "id": "checks" })
);
```

既定の $\lambda = 550$ nm、$D = 100$ mm では、最初の暗環は $\theta_1 = 1.3837$ 秒角にある。
$1.22\lambda/D = 1.3840$ 秒角との相対差 $3 \times 10^{-4}$ は、係数 1.22 が $j_{1,1}/\pi = 1.2197$ を丸めた値であることによる。
走査で見つけた 4 つの符号変化の区間は、どれも文献の零点を含み、文献の零点での $\lvert J_1\rvert$ は $10^{-16}$ 程度である。
囲い込みエネルギーは暗環で 0.838、0.910、0.938、0.952 と段状に増え、暗環と暗環の間の明るい輪がそれぞれ数 % ずつを担う。
Simpson 則の値と閉形式の差は $3.5 \times 10^{-14}$ で、閉形式 $1 - J_0^2 - J_1^2$ が強度の積分に等しいことを数値で確かめている。
級数との差は $1.08 \times 10^{-10}$ で、打ち切った項の大きさと一致する。
直径を 4 倍にすると角度はすべて 4 分の 1 になり、強度と囲い込みエネルギーの形は $x$ の関数として変わらない。

## 線音源の円筒波

次に、無限に長い線音源が角周波数 $\omega$ で振動するとき、空気中に広がる音圧を考える。
音圧 $p(r, t) = \operatorname{Re}[P\,H_0^{(1)}(kr)\,e^{-\mathrm{i}\omega t}]$ は 2 次元の Helmholtz 方程式を満たし、時間因子 $e^{-\mathrm{i}\omega t}$ のもとで $H_0^{(1)}(kr)$ は外向きの波を表す（Sommerfeld の放射条件）。
波数は $k = \omega/c = 2\pi f/c$ で、音速は $c = 343$ m/s（20 °C の空気）とする。

$kr$ が大きい遠方では、Hankel の漸近展開（DLMF 10.17.5）が使える。

$$
H_0^{(1)}(x) \sim \sqrt{\frac{2}{\pi x}}\,e^{\mathrm{i}(x - \pi/4)}\left(1 - \frac{\mathrm{i}}{8x} - \frac{9}{128x^2} + \cdots\right).
$$

振幅は $\sqrt{2/(\pi kr)}$、つまり $r^{-1/2}$ で減り、主要項だけを使った相対誤差は $1/(8x)$、3 項までなら $x^{-3}$ の割合で減る。

振幅が $r^{-1/2}$ で減るのはエネルギーの保存による。
粒子速度は $v = (\partial p/\partial r)/(\mathrm{i}\omega\rho)$（$\rho$ は空気の密度）で、時間平均の強度は $\bar{I} = \frac{\lvert P\rvert^2 k}{2\omega\rho}\operatorname{Im}[\overline{H_0^{(1)}}\,H_0^{(1)\prime}](kr)$ になる。
$H_0^{(1)} = J_0 + \mathrm{i}Y_0$ を代入すると、虚部は Wronskian $J_0Y_0' - J_0'Y_0 = 2/(\pi kr)$ に等しい。
したがって

$$
F(r) = kr\,\operatorname{Im}\left[\overline{H_0^{(1)}(kr)}\,H_0^{(1)\prime}(kr)\right] = \frac{2}{\pi}, \qquad
2\pi r\,\bar{I} = \frac{2\lvert P\rvert^2}{\omega\rho}
$$

となり、半径 $r$ の円筒面を通る単位長さあたりの仕事率は $r$ によらない。
近距離で振幅が $r^{-1/2}$ から外れても、この流束は保存する。

## 円筒波の計算

次のセルは周波数 $f$ [Hz] を選び、$r = 0.02$ m から 20 m までの $\lvert H_0^{(1)}(kr)\rvert$ を `hankel_1` で求めて、主要項の振幅 $\sqrt{2/(\pi kr)}$ と両対数の図で比べる。
2 つ目の図は、`hankel_1_scaled` が返す $e^{-\mathrm{i}kr}H_0^{(1)}(kr)$ と、漸近展開の主要項、3 項までの和との相対誤差である。
二つの図は同じ $r$ を横軸に持つので連動する。
表は $r = 0.1, 1, 10$ m で、$kr$、$\lvert H_0^{(1)}\rvert$、二つの相対誤差、流束 $F$ の $2/\pi$ との相対差、`bessel_j_derivative` と `bessel_y_derivative` による Wronskian の相対残差を示す。
流束は `hankel_1` と `hankel_1_derivative` から作る。

```rust

//| ref: special-hankel-cylindrical-radiation

//| run: reactive
//| crates: [scioxide-core, scioxide-special]

//|   frequency: {"type":"range","label":"周波数 f [Hz]","description":"波数 k = 2πf/c を変える。","min":100,"max":2000,"step":50,"value":500}
//| cases:
//|   - {"id":"low-frequency","label":"f = 100 Hz","description":"波長 3.4 m では 1 m の点も近距離で、主要項の誤差は 5 % を超える。","inputs":{"frequency":100}}

//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"radiation","path":"/rows/1/1","approx":{"value":9.159162255363828,"rtol":1e-14}}
//|       - {"artifact":"radiation","path":"/rows/1/2","approx":{"value":0.2634477792037513,"rtol":1e-12}}
//|       - {"artifact":"radiation","path":"/rows/1/3","approx":{"value":0.01359,"rtol":1e-3}}
//|       - {"artifact":"radiation","path":"/rows/1/5","range":{"max":1e-14}}
//|       - {"artifact":"radiation","path":"/rows/1/6","range":{"max":1e-14}}
//|       - {"artifact":"radiation","path":"/rows/0/5","range":{"max":1e-14}}
//|   - case: low-frequency
//|     expect:
//|       - {"artifact":"radiation","path":"/rows/1/3","range":{"min":0.05}}
//|       - {"artifact":"radiation","path":"/rows/2/5","range":{"max":1e-14}}
//|   - case: high-frequency
//|     expect:
//|       - {"artifact":"radiation","path":"/rows/1/3","range":{"max":0.01}}
//|       - {"artifact":"radiation","path":"/rows/2/4","range":{"max":1e-8}}
use scioxide_core::{Complex, RealScalar};
use scioxide_special::{
    bessel_j, bessel_j_derivative, bessel_y, bessel_y_derivative, hankel_1,
    hankel_1_derivative, hankel_1_scaled,
};

let sound_speed = 343.0;
let k = 2.0 * std::f64::consts::PI * frequency / sound_speed;
let pi = std::f64::consts::PI;
// 漸近展開の主要項と 3 項までの和（DLMF 10.17.5）。e^{ix} を除いた形。
let leading = |x: f64| Complex::new(1.0, -1.0).scale((1.0 / (pi * x)).sqrt());
let three_terms =
    |x: f64| leading(x) * Complex::new(1.0 - 9.0 / (128.0 * x * x), -1.0 / (8.0 * x));

let mut amplitude = Vec::new();
let mut envelope = Vec::new();
let mut first_error = Vec::new();
let mut third_error = Vec::new();
for index in 0..=300 {
    // r = 0.02 m から 20 m まで対数等間隔。
    let r = 0.02 * RealScalar::powf(1000.0_f64, f64::from(index) / 300.0);
    let x = k * r;
    let h = hankel_1(0.0, x).map_err(|e| e.to_string())?;
    let scaled = hankel_1_scaled(0.0, x).map_err(|e| e.to_string())?;
    amplitude.push([r, h.norm()]);
    envelope.push([r, (2.0 / (pi * x)).sqrt()]);
    first_error.push([r, (scaled - leading(x)).norm() / scaled.norm()]);
    third_error.push([r, (scaled - three_terms(x)).norm() / scaled.norm()]);
}
emit_line_chart!(
    &vec![
        serde_json::json!({ "name": "|H₀⁽¹⁾(kr)|", "points": amplitude }),
        serde_json::json!({
            "name": "√(2/(πkr))",
            "points": envelope,
            "style": { "lineType": "dashed" }
        }),
    ],
    options = &serde_json::json!({
        "link": { "group": "radial-distance" },
        "xLabel": "距離 r [m]",
        "yLabel": "音圧の振幅 |p|/|P| [-]",
        "xType": "log",
        "yType": "log",
        "xMin": 0.02,
        "xMax": 20.0,
        "yMin": 0.01,
        "yMax": 10.0
    })
);
emit_line_chart!(
    &vec![
        serde_json::json!({ "name": "主要項", "points": first_error }),
        serde_json::json!({ "name": "3 項までの和", "points": third_error }),
    ],
    options = &serde_json::json!({
        "link": { "group": "radial-distance" },
        "xLabel": "距離 r [m]",
        "yLabel": "漸近展開の相対誤差 [-]",
        "xType": "log",
        "yType": "log",
        "xMin": 0.02,
        "xMax": 20.0,
        "yMin": 1e-12,
        "yMax": 10.0
    })
);

let mut rows = Vec::new();
for r in [0.1, 1.0, 10.0] {
    let x = k * r;
    let h = hankel_1(0.0, x).map_err(|e| e.to_string())?;
    let dh = hankel_1_derivative(0.0, x, 1).map_err(|e| e.to_string())?;
    let scaled = hankel_1_scaled(0.0, x).map_err(|e| e.to_string())?;
    // エネルギー流束 F = x Im(conj(H) H') は 2/π に等しい。
    let flux = x * (h.conj() * dh).im;
    let j = bessel_j(0.0, x).map_err(|e| e.to_string())?;
    let y = bessel_y(0.0, x).map_err(|e| e.to_string())?;
    let dj = bessel_j_derivative(0.0, x, 1).map_err(|e| e.to_string())?;
    let dy = bessel_y_derivative(0.0, x, 1).map_err(|e| e.to_string())?;
    let wronskian = (j * dy - dj * y) * pi * x / 2.0 - 1.0;
    rows.push((
        r,
        x,
        h.norm(),
        (scaled - leading(x)).norm() / scaled.norm(),
        (scaled - three_terms(x)).norm() / scaled.norm(),
        (flux * pi / 2.0 - 1.0).abs(),
        wronskian.abs(),
    ));
}
let sig4 = serde_json::json!({ "significantDigits": 4 });
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let columns = serde_json::json!([
    { "key": "0", "label": "距離 r [m]", "type": "number" },
    { "key": "1", "label": "kr [-]", "type": "number", "format": sig4 },
    { "key": "2", "label": "|H₀⁽¹⁾(kr)| [-]", "type": "number", "format": sig4 },
    { "key": "3", "label": "主要項の相対誤差 [-]", "type": "number", "format": sci2 },
    { "key": "4", "label": "3 項の相対誤差 [-]", "type": "number", "format": sci2 },
    { "key": "5", "label": "|F/(2/π) − 1| [-]", "type": "number", "format": sci2 },
    { "key": "6", "label": "Wronskian の相対残差 [-]", "type": "number", "format": sci2 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "radiation" })
);
```

既定の $f = 500$ Hz（波長 0.69 m）では、$r = 1$ m で $kr = 9.16$、$\lvert H_0^{(1)}\rvert = 0.264$ で、主要項の相対誤差は $1/(8kr) \approx 1.4 \times 10^{-2}$ である。
両対数の図で振幅は遠方で傾き $-1/2$ の直線に乗り、近距離では直線より小さくなる。
$kr \to 0$ で $\lvert H_0^{(1)}\rvert$ は $\lvert Y_0(kr)\rvert \approx (2/\pi)\lvert\ln(kr/2) + \gamma\rvert$（$\gamma$ は Euler の定数）のように対数でしか増えず、$(kr)^{-1/2}$ より遅いからである。
相対誤差の図で、主要項の誤差は傾き $-1$、3 項までの和の誤差は傾き $-3$ で減り、$kr$ が小さい近距離ではどちらの展開も使えない。
流束 $F$ と Wronskian の相対残差は、近距離でも遠方でも $5 \times 10^{-16}$ 以下で、振幅が $r^{-1/2}$ から外れる近距離でも流束が保存することを示す。
周波数を変えると、図は $kr$ が同じになる位置へ横にずれるだけで、誤差の大きさは $kr$ だけで決まる。

## まとめ

円形開口による回折像の振幅は $2J_1(x)/x$ で、`bessel_lambda(1.0, x)` を使えば $x = 0$ を特別に扱わずに強度 $\Lambda_1(x)^2$ を計算できる。
囲い込みエネルギーは閉形式 $1 - J_0^2 - J_1^2$ で求まり、最初の暗環 $j_{1,1} = 3.8317$ の内側に約 84 % が入り、その角度半径 $1.22\lambda/D$ が Rayleigh の分解能になる。
零点の値そのものが必要なら `scioxide-rootfind` の `special_zeros` で求め、セルの中では符号の変化と $\lvert J_1\rvert$ の小ささで確かめられる。
円筒波 $H_0^{(1)}(kr)$ の振幅は遠方で $\sqrt{2/(\pi kr)}$ に近づき、主要項の誤差はおよそ $1/(8kr)$ なので、近距離では漸近形ではなく `hankel_1` の値を使う。
エネルギー流束 $kr\operatorname{Im}[\overline{H}H'] = 2/\pi$ は Wronskian そのもので、値と導関数の整合を確かめる検算になる。
三次元の球面波は [球 Bessel・球 Hankel・Riccati–Bessel 関数](../../algorithms/spherical-bessel-kelvin-and-riccati/) で、転回点を持つ波は [重力場中の中性子の量子化と Airy 関数](../airy-turning-point/) で確かめる。
