単原子の固体のモル比熱は、室温ではおおむね $3R \approx 24.94$ J/(mol·K) になる（Dulong–Petit の法則）。
古典力学の等分配則はこの値を全温度で予言するが、低温の比熱は 0 に向かって減り、ダイヤモンドのように硬く軽い結晶では室温でも $3R$ を大きく下回る。
Debye（1912）は格子振動を、最高の振動数で打ち切った音波の集まりとして量子化し、比熱の温度依存性を一つの関数 $D_3$ で表した。
この例題では Debye モデルの比熱を scioxide-special の `debye_3` と `transport_4` の二通りで評価し、両極限の法則と高温展開がどの温度まで使えるかを数値で確かめる。

## Debye モデルの比熱

原子数 $N$ の結晶の格子振動を、振動数 $\omega$ の調和振動子の集まりとみなす。
Debye モデルは振動数の分布（状態密度）を連続体の音波の $g(\omega) \propto \omega^2$ とし、自由度の総数が $3N$ になる振動数 $\omega_D$ で打ち切る。

$$
g(\omega) = \frac{9N}{\omega_D^3}\,\omega^2 \quad (0 \le \omega \le \omega_D), \qquad \int_0^{\omega_D} g(\omega)\,d\omega = 3N
$$

Debye 温度 $\Theta_D$ は $k_B\Theta_D = \hbar\omega_D$ で定める（$k_B$ は Boltzmann 定数、$\hbar$ は換算 Planck 定数）。
振動数 $\omega$ の振動子の熱エネルギーの平均は $\hbar\omega/(e^{\hbar\omega/k_BT} - 1)$ なので、$t = \hbar\omega/k_BT$、$x_D = \Theta_D/T$ と置くと、格子の内部エネルギーは

$$
U(T) = \int_0^{\omega_D} \frac{\hbar\omega\, g(\omega)}{e^{\hbar\omega/k_BT} - 1}\,d\omega
= 9Nk_BT \left(\frac{T}{\Theta_D}\right)^3 \int_0^{x_D} \frac{t^3}{e^t - 1}\,dt
= 3Nk_BT\,D_3(x_D)
$$

になる。
零点振動のエネルギー $\tfrac{9}{8}Nk_B\Theta_D$ は温度によらないので省いた。
$D_3(x) = (3/x^3)\int_0^x t^3/(e^t - 1)\,dt$ は 3 次の Debye 関数で、scioxide-special の `debye_3` はこの規格化（$D_3(0) = 1$）で値を返す（[Debye 関数](oxref:special-thermal-debye)）。

定積比熱 $C_V = dU/dT$ は、$D_3'(x) = -3D_3(x)/x + 3/(e^x - 1)$ を使って

$$
\frac{C_V}{3Nk_B} = D_3(x_D) - x_D D_3'(x_D) = 4D_3(x_D) - \frac{3x_D}{e^{x_D} - 1}
$$

になる。
同じ量は、$U$ を $T$ で微分してから積分しても得られ、輸送積分 $J_4(x) = \int_0^x t^4 e^t/(e^t - 1)^2\,dt$ で

$$
\frac{C_V}{3Nk_B} = \frac{3J_4(x_D)}{x_D^3}
$$

とも書ける。
二つの式は部分積分で結ばれる恒等式だが、scioxide-special の `debye_3` と `transport_4` は別々の係数表と裾の和で実装されているので、二通りの値の一致は実装の検算になる。
1 mol の原子では $3Nk_B = 3R$（$R = 8.314462618$ J/(mol·K) は気体定数）である。

## 二つの極限

高温（$x_D \to 0$）では、$D_3$ の級数を代入して

$$
\frac{C_V}{3R} = 1 - \frac{x_D^2}{20} + \frac{x_D^4}{560} - \cdots
$$

を得る。
極限の 1 が Dulong–Petit の法則 $C_V = 3R$ で、級数は $x_D < 2\pi$ で収束する。

低温（$x_D \to \infty$）では、$J_4(\infty) = 4!\,\zeta(4) = 4\pi^4/15$ から

$$
\frac{C_V}{3R} \approx \frac{4\pi^4}{5x_D^3}, \qquad C_V \approx \frac{12\pi^4}{5}\,R \left(\frac{T}{\Theta_D}\right)^3 \approx 1943.8 \left(\frac{T}{\Theta_D}\right)^3 \text{ J/(mol·K)}
$$

になる（Debye の $T^3$ 則）。
省いた裾 $\int_{x_D}^\infty t^4 e^t/(e^t - 1)^2\,dt$ は $x_D^4 e^{-x_D}$ の速さで小さくなるので、$T^3$ 則の相対誤差は温度を下げると指数的に減る。

金属では、低温で伝導電子の比熱（温度に比例する）が格子の比熱 $\propto T^3$ を上回る温度域があり、この例題のモデルは格子の寄与だけを扱う。

## 物質の Debye 温度

下の表の $\Theta_D$ は Kittel, *Introduction to Solid State Physics*（8th ed., 2005）5 章の表の値で、低温の比熱の測定から求めた値である。

| 物質 | $\Theta_D$ [K] | 室温 300 K での $x_D$ |
|---|---|---|
| 鉛 Pb | 105 | 0.35 |
| 銅 Cu | 343 | 1.14 |
| アルミニウム Al | 428 | 1.43 |
| ダイヤモンド C | 2230 | 7.43 |

実在の結晶の振動数分布は $\omega^2$ からずれるので、各温度の比熱に合う $\Theta_D$ は温度によって少しずつ変わる。
低温の値で決めた $\Theta_D$ を室温に当てはめると、比熱の測定値からずれることがある。
この例題は一つの $\Theta_D$ で決まる Debye モデルそのものの性質を調べる。

## 比熱曲線と二通りの評価

次のセルは 4 物質の $C_V(T)$ を 1〜1000 K で描き、入力の温度 $T$ で各物質の $C_V$ を表にする。
表は $4D_3 - 3x_D/(e^{x_D} - 1)$（`debye_3`）と $3J_4/x_D^3$（`transport_4`）の二通りの値とその相対差、$T^3$ 則の値、高温展開の 3 項 $1 - x_D^2/20 + x_D^4/560$ の値を並べる。
高温展開は収束半径 $2\pi$ の外では意味がないので、$x_D \ge 2\pi$ の行は空欄にする。

```rust
//| id: special-debye-heat-capacity-materials
//| ref: special-debye-heat-capacity-materials
//| title: 4 物質の Debye 比熱を debye_3 と transport_4 で評価する
//| run: reactive
//| crates: [scioxide-core, scioxide-special]
//| inputs:
//|   temperature: {"type":"range","label":"温度 T [K]","description":"表で比べる温度。図には縦線で示す。","min":1,"max":1000,"step":1,"value":300}
//| cases:
//|   - {"id":"cold","label":"T = 20 K","description":"Pb 以外は x_D ≥ 17 で、T³ 則との相対差は 2×10⁻⁴ 以下になる。Pb は x_D = 5.25 で T³ 則から大きく外れる。","inputs":{"temperature":20}}
//|   - {"id":"hot","label":"T = 1000 K","description":"ダイヤモンド以外は高温展開の 3 項との相対差が 10⁻⁶ 以下になり、C_V は 3R の 99 % を超える。","inputs":{"temperature":1000}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"heat","path":"/rows/1/3","approx":{"value":23.39,"atol":0.01}}
//|       - {"artifact":"heat","path":"/rows/1/5","range":{"max":1e-14}}
//|       - {"artifact":"heat","path":"/rows/3/3","approx":{"value":4.1332,"atol":1e-3}}
//|       - {"artifact":"heat","path":"/rows/3/7","equals":null}
//|   - case: cold
//|     expect:
//|       - {"artifact":"heat","path":"/rows/1/5","range":{"max":1e-14}}
//|       - {"artifact":"heat","path":"/rows/1/3","approx":{"value":0.385289,"rtol":1e-5}}
//|       - {"artifact":"heat","path":"/rows/3/3","approx":{"value":1.40223e-3,"rtol":1e-5}}
//|       - {"artifact":"heat","path":"/rows/3/6","approx":{"value":1.40223e-3,"rtol":1e-5}}
//|   - case: hot
//|     expect:
//|       - {"artifact":"heat","path":"/rows/0/8","approx":{"value":0.99945,"atol":1e-4}}
//|       - {"artifact":"heat","path":"/rows/3/3","approx":{"value":19.695,"atol":1e-3}}
use scioxide_core::RealScalar;
use scioxide_special::{debye_3, transport_4};

let gas_constant = 8.314462618; // R [J/(mol·K)]
let three_r = 3.0 * gas_constant;
// Debye 温度 [K]（Kittel 2005, 5 章の表）。
let materials = [
    ("鉛 Pb", 105.0),
    ("銅 Cu", 343.0),
    ("アルミニウム Al", 428.0),
    ("ダイヤモンド C", 2230.0),
];
// C_V/(3R) = 4D₃(x) − 3x/(eˣ − 1)。x/(eˣ − 1) は exp_m1 で打ち消しなしに求める。
let ratio = |x: f64| -> Result<f64, String> {
    let d3 = debye_3(x).map_err(|e| e.to_string())?;
    Ok(4.0 * d3 - 3.0 * x / RealScalar::exp_m1(x))
};
let mut series = Vec::new();
for (name, theta) in materials {
    let mut points = Vec::new();
    for i in 0..=200 {
        let t = 1.0 + 999.0 * i as f64 / 200.0;
        points.push([t, three_r * ratio(theta / t)?]);
    }
    series.push(serde_json::json!({ "name": name, "points": points }));
}
emit_line_chart!(
    &series,
    options = &serde_json::json!({
        "xLabel": "温度 T [K]",
        "yLabel": "定積モル比熱 C_V [J/(mol·K)]",
        "xMin": 0.0,
        "xMax": 1000.0,
        "yMin": 0.0,
        "yMax": 27.0,
        "annotations": [
            { "kind": "line", "axis": "y", "value": three_r, "label": "3R（Dulong–Petit）" },
            { "kind": "line", "axis": "x", "value": temperature, "label": "入力 T" }
        ]
    })
);

let pi4 = std::f64::consts::PI.powi(4);
let mut rows = Vec::new();
for (name, theta) in materials {
    let x = theta / temperature;
    let via_debye = three_r * ratio(x)?;
    // 独立な経路: C_V/(3R) = 3J₄(x)/x³（別の係数表と裾の和で実装されている）。
    let via_transport = three_r * 3.0 * transport_4(x).map_err(|e| e.to_string())? / x.powi(3);
    // 参照: 低温の T³ 則と高温展開の 3 項（手計算）。
    let cubic = three_r * 4.0 * pi4 / (5.0 * x.powi(3));
    let high = (x < 2.0 * std::f64::consts::PI)
        .then(|| three_r * (1.0 - x * x / 20.0 + x.powi(4) / 560.0));
    rows.push((
        name,
        theta,
        x,
        via_debye,
        via_transport,
        (via_debye - via_transport).abs() / via_debye,
        cubic,
        high,
        via_debye / three_r,
    ));
}
let fixed2 = serde_json::json!({ "fractionDigits": 2 });
let sig6 = serde_json::json!({ "significantDigits": 6 });
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let columns = serde_json::json!([
    { "key": "0", "label": "物質" },
    { "key": "1", "label": "Θ_D [K]", "type": "number", "format": { "fractionDigits": 0 } },
    { "key": "2", "label": "x_D = Θ_D/T [-]", "type": "number", "format": fixed2 },
    { "key": "3", "label": "C_V（debye_3）[J/(mol·K)]", "type": "number", "format": sig6 },
    { "key": "4", "label": "C_V（transport_4）[J/(mol·K)]", "type": "number", "format": sig6 },
    { "key": "5", "label": "二通りの相対差", "type": "number", "format": sci3 },
    { "key": "6", "label": "T³ 則 [J/(mol·K)]", "type": "number", "format": sig6 },
    { "key": "7", "label": "高温展開 3 項 [J/(mol·K)]", "type": "number", "format": sig6, "nullText": "x_D ≥ 2π" },
    { "key": "8", "label": "C_V/3R [-]", "type": "number", "format": { "fractionDigits": 4 } }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "heat" })
);
```

図の 4 本の曲線は同じ形をしていて、$\Theta_D$ に比例して横に引き伸ばされている。
既定の 300 K では、$C_V$ は鉛で 24.79 J/(mol·K)（$3R$ の 99.4 %）、銅で 23.39（93.8 %）、アルミニウムで 22.58（90.5 %）、ダイヤモンドで 4.13（16.6 %）である。
`debye_3` と `transport_4` による二通りの値の相対差はどの行も $5 \times 10^{-16}$ 以下で、倍精度の丸めの水準で一致する。
ダイヤモンドは $x_D = 7.43$ でも $T^3$ 則の値 4.73 がモデルの値を 14 % 上回り、室温はまだ $T^3$ 則の範囲ではない。

20 K（`cold`）では、銅の $C_V = 0.3853$ J/(mol·K) と $T^3$ 則の相対差は $1.5 \times 10^{-4}$ で、ダイヤモンドの $1.402 \times 10^{-3}$ J/(mol·K) は $T^3$ 則と丸めの水準で一致する。
$\Theta_D$ の低い鉛は $x_D = 5.25$ で、$T^3$ 則（13.4）はモデルの値（8.48）を 58 % 上回る。
1000 K（`hot`）では鉛、銅、アルミニウムの $C_V/3R$ が 0.99 を超え、ダイヤモンドは 0.790 にとどまり、高温展開の 3 項もダイヤモンド（$x_D = 2.23$）では 0.75 % ずれる。
二通りの値は同じ $x_D$ から計算するので、丸めの水準を超えて食い違えば実装の誤りを示す。
一方で $x_D = \Theta_D/T$ と $T/\Theta_D$ の取り違えのような入力の誤りは二通りの一致では見つからないので、$T^3$ 則や $3R$ の極限と比べて確かめる。

## 極限の法則が使える温度

$C_V/3R$ は $T/\Theta_D$ だけの関数なので、どの物質にも同じ曲線が使える。
次のセルは $T/\Theta_D$ を $10^{-2}$ から $10$ まで対数の格子で動かし、$T^3$ 則と高温展開の 3 項、Dulong–Petit の 1 のそれぞれが、`debye_3` による値からどれだけずれるかを両対数で描く。
入力の許容相対誤差に対し、各近似が許容内に入る $T/\Theta_D$ の範囲の端を、格子の上の線形補間で求めて表にする。
同じ格子で、`debye_3` と `transport_4` の二通りの値の相対差の最大も表に出す。

```rust
//| id: special-debye-heat-capacity-limits
//| ref: special-debye-heat-capacity-limits
//| title: T³ 則・高温展開・Dulong–Petit 則が使える温度の範囲
//| run: reactive
//| crates: [scioxide-core, scioxide-special]
//| inputs:
//|   tolerance_percent: {"type":"select","label":"許容相対誤差","description":"近似が Debye モデルの値からずれてよい割合。","options":[{"label":"10 %","value":"10"},{"label":"1 %","value":"1"},{"label":"0.1 %","value":"0.1"}],"value":"1"}
//| cases:
//|   - {"id":"loose","label":"10 %","description":"T³ 則は T/Θ_D ≈ 0.12 まで、Dulong–Petit の値は T/Θ_D ≈ 0.72 から使える。","inputs":{"tolerance_percent":"10"}}
//|   - {"id":"strict","label":"0.1 %","description":"T³ 則の範囲は T/Θ_D ≈ 0.068 まで縮み、Dulong–Petit の値は T/Θ_D ≈ 7 まで上げないと許容内に入らない。","inputs":{"tolerance_percent":"0.1"}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"ranges","path":"/rows/0/1","approx":{"value":0.0869,"atol":5e-4}}
//|       - {"artifact":"ranges","path":"/rows/2/1","approx":{"value":2.24,"atol":0.01}}
//|       - {"artifact":"ranges","path":"/rows/3/1","range":{"max":1e-14}}
//|   - case: loose
//|     expect:
//|       - {"artifact":"ranges","path":"/rows/0/1","approx":{"value":0.1246,"atol":5e-4}}
//|       - {"artifact":"ranges","path":"/rows/2/1","approx":{"value":0.717,"atol":0.005}}
//|   - case: strict
//|     expect:
//|       - {"artifact":"ranges","path":"/rows/0/1","approx":{"value":0.0680,"atol":5e-4}}
use scioxide_core::RealScalar;
use scioxide_special::{debye_3, transport_4};

let tolerance = tolerance_percent
    .parse::<f64>()
    .map_err(|e| e.to_string())?
    / 100.0;
let pi4 = std::f64::consts::PI.powi(4);
let mut cubic_error = Vec::new();
let mut series_error = Vec::new();
let mut classical_error = Vec::new();
let mut identity = 0.0_f64;
let mut exact_zeros = 0;
for i in 0..=300 {
    let reduced = 1e-2 * 1e3_f64.powf(i as f64 / 300.0); // T/Θ_D
    let x = 1.0 / reduced;
    let exact = 4.0 * debye_3(x).map_err(|e| e.to_string())? - 3.0 * x / RealScalar::exp_m1(x);
    let via_transport = 3.0 * transport_4(x).map_err(|e| e.to_string())? / x.powi(3);
    identity = identity.max((exact - via_transport).abs() / exact);
    // 参照の近似式（手計算）と Debye モデルの値の相対差。
    // 相対差がちょうど 0 の点は対数軸に描けないので、図から除いて数える。
    let cubic = (4.0 * pi4 / (5.0 * x.powi(3)) - exact).abs() / exact;
    if cubic > 0.0 {
        cubic_error.push([reduced, cubic]);
    } else {
        exact_zeros += 1;
    }
    if x < 2.0 * std::f64::consts::PI {
        let series = 1.0 - x * x / 20.0 + x.powi(4) / 560.0;
        series_error.push([reduced, (series - exact).abs() / exact]);
    }
    classical_error.push([reduced, (1.0 - exact).abs() / exact]);
}
emit_line_chart!(
    &vec![
        serde_json::json!({ "name": "T³ 則", "points": cubic_error }),
        serde_json::json!({ "name": "高温展開 3 項", "points": series_error }),
        serde_json::json!({ "name": "Dulong–Petit（1）", "points": classical_error })
    ],
    options = &serde_json::json!({
        "xLabel": "T/Θ_D [-]",
        "yLabel": "Debye モデルの値との相対差 [-]",
        "xType": "log",
        "yType": "log",
        "yMin": 1e-16,
        "yMax": 1e5,
        "annotations": [{ "kind": "line", "axis": "y", "value": tolerance, "label": "許容相対誤差" }]
    })
);

// 相対差が許容値を横切る T/Θ_D を、格子の隣り合う 2 点の線形補間で求める。
let crossing = |points: &[[f64; 2]]| {
    points.windows(2).find_map(|pair| {
        let ([x0, e0], [x1, e1]) = (pair[0], pair[1]);
        ((e0 - tolerance) * (e1 - tolerance) <= 0.0)
            .then(|| x0 + (tolerance - e0) * (x1 - x0) / (e1 - e0))
    })
};
let rows = vec![
    ("T³ 則が許容内に入る上端", crossing(&cubic_error)),
    ("高温展開 3 項が許容内に入る下端", crossing(&series_error)),
    (
        "Dulong–Petit が許容内に入る下端",
        crossing(&classical_error),
    ),
    ("debye_3 と transport_4 の相対差の最大", Some(identity)),
    (
        "T³ 則の相対差が 0 で図から除いた点の数",
        Some(exact_zeros as f64),
    ),
];
let columns = serde_json::json!([
    { "key": "0", "label": "量" },
    { "key": "1", "label": "値 [-]", "type": "number", "format": { "significantDigits": 3 }, "nullText": "格子内で横切らない" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "ranges" })
);
```

既定の許容相対誤差 1 % では、$T^3$ 則は $T/\Theta_D \le 0.087$、高温展開の 3 項は $T/\Theta_D \ge 0.43$、Dulong–Petit の値は $T/\Theta_D \ge 2.24$ で許容内に入る。
銅（$\Theta_D = 343$ K）に当てはめると、$T^3$ 則は約 30 K まで、Dulong–Petit の値は約 770 K から使える。
図の $T^3$ 則の相対差は、$T/\Theta_D$ を下げると指数的に減り、$T/\Theta_D \approx 0.02$ より下では $10^{-16}$ 程度の丸めの水準で頭打ちになる。
相対差がちょうど 0 になった点は対数軸に描けないので、図から除いて表に数を示す（点の数は実行環境の丸めで変わり、ブラウザの wasm では 17 点）。
`debye_3` と `transport_4` の相対差は格子の全 301 点で $1.2 \times 10^{-15}$ 以下である。

許容誤差を 10 %（`loose`）に緩めると $T^3$ 則の上端は 0.125、Dulong–Petit の下端は 0.717 に広がり、0.1 %（`strict`）に絞ると $T^3$ 則は 0.068 まで、Dulong–Petit は 7.07 からに狭まる。
Dulong–Petit の下端が許容誤差に強く依存するのは、高温側の差が $x_D^2/20 = (\Theta_D/T)^2/20$ のように冪でしか減らないためである。
$T^3$ 則の上端の動きが小さいのは、その誤差が $x_D^4 e^{-x_D}$ のように指数的に変わるためである。

## まとめ

Debye モデルの定積比熱は $C_V/3R = 4D_3(\Theta_D/T) - 3x_D/(e^{x_D} - 1)$ で、`debye_3` の値と `exp_m1` だけで全温度を評価でき、$3J_4(x_D)/x_D^3$（`transport_4`）と照合できる。
比熱は $T/\Theta_D$ だけで決まるので、物質の違いは $\Theta_D$ の違いとして現れ、室温で鉛は $3R$ に近く、ダイヤモンドは $3R$ の約 6 分の 1 にとどまる。
$T^3$ 則は許容相対誤差 1 % なら $T \lesssim 0.087\,\Theta_D$、Dulong–Petit の値は $T \gtrsim 2.2\,\Theta_D$ で使え、その間の温度では Debye 関数の値そのものが要る。
Debye 関数の評価法と精度の保証は[Debye 関数・輸送積分・シンクロトロン関数](../../algorithms/thermal-and-radiation-integrals/)で、同じ被積分関数を半無限区間で積分する黒体放射は scioxide-integrate の[黒体放射の例題](../../../scioxide-integrate/examples/blackbody-radiation/)で確かめる。
