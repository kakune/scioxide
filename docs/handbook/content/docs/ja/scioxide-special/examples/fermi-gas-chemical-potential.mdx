金属の伝導電子や高濃度にドープした半導体の電子は、Pauli の排他律のため、低温でも高いエネルギーの準位まで詰まっている（縮退している）。
電子の数密度 $n$ と温度 $T$ が決まると、Fermi–Dirac 分布の化学ポテンシャル $\mu$ は、分布の全体で数えた電子の数が $n$ に一致する条件から決まる。
この条件は Fermi–Dirac 積分 $F_{1/2}$ を含む方程式で、$\mu$ について閉じた形には解けない。
この例題では scioxide-special の `fermi_dirac_half` とその導関数 `fermi_dirac_mhalf` を scioxide-rootfind の区間保護付き Newton 法に渡して $\mu$ を求め、低温の Sommerfeld 展開と高温の古典極限で検算する。

## 粒子数の条件と Fermi–Dirac 積分

質量 $m$、スピン $1/2$ の自由電子の 3 次元の状態密度は、体積あたり $g(\epsilon) = \dfrac{1}{2\pi^2}\left(\dfrac{2m}{\hbar^2}\right)^{3/2}\epsilon^{1/2}$ である（スピンの 2 状態を含む）。
温度 $T$、化学ポテンシャル $\mu$ の Fermi–Dirac 分布 $f(\epsilon) = 1/(e^{(\epsilon - \mu)/k_BT} + 1)$ で占有を数えると、$t = \epsilon/k_BT$、$\eta = \mu/k_BT$ として

$$
n = \int_0^\infty g(\epsilon) f(\epsilon)\,d\epsilon
= \frac{1}{2\pi^2}\left(\frac{2mk_BT}{\hbar^2}\right)^{3/2} \int_0^\infty \frac{t^{1/2}}{e^{t-\eta} + 1}\,dt
$$

になる。
scioxide-special の Fermi–Dirac 積分は $F_j(\eta) = \frac{1}{\Gamma(j+1)}\int_0^\infty t^j/(e^{t-\eta}+1)\,dt$ と $\Gamma(j+1)$ で規格化してある（[Fermi–Dirac 積分の定義と規約](oxref:special-fermi-dirac-definition)）。
$\Gamma(3/2) = \sqrt{\pi}/2$ を使い、熱的 de Broglie 波長 $\lambda = h/\sqrt{2\pi m k_BT}$ で書くと、密度の式は

$$
n = \frac{2}{\lambda^3}\,F_{1/2}(\eta)
$$

という簡潔な形になる。
係数の 2 はスピンの縮重度である。
規格化のない積分 $\int_0^\infty t^{1/2}/(e^{t-\eta}+1)\,dt = (\sqrt{\pi}/2)\,F_{1/2}(\eta)$ を `fermi_dirac_half` の値と取り違えると、右辺が約 11 % ずれ、$\mu$ も誤る。

$T = 0$ では、分布は $\epsilon = \mu$ で切れる階段になり、Fermi エネルギー $E_F = \dfrac{\hbar^2}{2m}(3\pi^2 n)^{2/3}$ まで詰まる。
無次元の温度 $\theta = k_BT/E_F$ を使うと、密度の条件は物質によらない形

$$
F_{1/2}(\eta) = \frac{n\lambda^3}{2} = \frac{4}{3\sqrt{\pi}}\,\theta^{-3/2}
$$

に書ける。
右辺の $n\lambda^3/2$ は、熱的波長の立方体に入る電子の数の目安で、1 より十分大きいと縮退し、十分小さいと古典的な気体になる。
この方程式を $\eta$ について解けば、$\mu/E_F = \theta\,\eta(\theta)$ が得られる。

## 二つの極限

$\theta \ll 1$（強く縮退した気体）では、$F_{1/2}$ の Sommerfeld 展開 $F_{1/2}(\eta) = \frac{4}{3\sqrt\pi}\eta^{3/2}\bigl[1 + \frac{\pi^2}{8}\eta^{-2} + \frac{7\pi^4}{640}\eta^{-4} + \cdots\bigr]$ を方程式に代入して $\eta$ を $\theta$ の級数で解くと、

$$
\frac{\mu}{E_F} = 1 - \frac{\pi^2}{12}\,\theta^2 - \frac{\pi^4}{80}\,\theta^4 + O(\theta^6)
$$

を得る。
$\theta \gg 1$（古典的な気体）では $\eta \to -\infty$ で、$F_{1/2}(\eta) = e^\eta - e^{2\eta}/2^{3/2} + \cdots$ から、$y = \frac{4}{3\sqrt\pi}\theta^{-3/2}$ として

$$
\eta = \ln y + \frac{y}{2^{3/2}} + O(y^2), \qquad \frac{\mu}{E_F} = \theta\,\eta
$$

になる。
主要項 $\eta = \ln y$ は Boltzmann 分布の化学ポテンシャルで、補正 $y/2^{3/2}$ は Pauli の排他律による最初の量子補正である。

白色矮星の内部のように $n \gtrsim 6 \times 10^{35}$ m⁻³ になると、Fermi 運動量 $\hbar(3\pi^2 n)^{1/3}$ が $m_ec$ を超え、相対論的な分散が要るので、このモデルは使えない。

## 区間保護付き Newton 法による求根

残差 $\Phi(\eta) = F_{1/2}(\eta) - y$ の導関数は、規格化した Fermi–Dirac 積分の微分の関係 $F_j' = F_{j-1}$ から $\Phi'(\eta) = F_{-1/2}(\eta)$ で、scioxide-special の `fermi_dirac_mhalf` がそのまま与える。
$F_{1/2}$ は単調に増えるので根は一つで、次の二つの不等式が根を挟む区間を与える。
一つは、$1/(e^{t-\eta}+1) < e^{\eta - t}$ から全域で $F_{1/2}(\eta) < e^\eta$ が成り立つことで、下端 $\eta_- = \ln y$ では $\Phi(\eta_-) < 0$ になる。
もう一つは、$\eta > 0$ で $F_{1/2}(\eta) > \frac{4}{3\sqrt\pi}\eta^{3/2}$ が成り立つことで、$\eta_+ = \max\bigl((\tfrac{3\sqrt\pi}{4}y)^{2/3}, 0\bigr) + 1$ では $\Phi(\eta_+) > 0$ になる。
この不等式は、分布 $1/(e^{t-\eta}+1)$ が $t = \eta + s$ に残す占有と $t = \eta - s$ で欠ける占有が等しく、上側の重み $(\eta + s)^{1/2}$ の方が下側の $(\eta - s)^{1/2}$ より大きいことから従う。

scioxide-rootfind の `SafeguardedNewton` は、この区間と初期値を受け取り、Newton の更新が区間の外に出るか進みが遅いときは区間を二分して、評価のたびに区間を縮める（[区間による保護](oxref:rootfind-safeguarded-newton)）。
初期値は $y < 1$ なら古典極限の $\ln y$、$y \ge 1$ なら縮退極限の $(\tfrac{3\sqrt\pi}{4}y)^{2/3}$ にする。
停止は、区間の幅が既定の座標の許容誤差（相対・絶対とも $4\varepsilon$）を満たしたとき（終了状態 `BracketTolerance`）か、評価した残差がちょうど 0 になったとき（`ResidualTolerance`）である。
次の定義のブロックはこの求根と密度の条件の右辺 $y(\theta)$ を二つのセルで共有する。

```rust
//| id: special-fermi-gas-model
//| kind: definitions
//| title: 密度の条件 F_{1/2}(η) = y を解く区間保護付き Newton 法
//| crates: [scioxide-core, scioxide-rootfind, scioxide-special]
use scioxide_core::{SciOxideError, Interval, RealScalar};
use scioxide_rootfind::{
    RootResult, SafeguardedInitialGuess, SafeguardedNewton, ScalarFn, ScalarRootOptions,
    ScalarRootSolver,
};
use scioxide_special::{fermi_dirac_half, fermi_dirac_mhalf};

/// 密度の条件の右辺 y = nλ³/2 = (4/(3√π)) θ^(−3/2)。θ = k_BT/E_F。
pub(crate) fn degeneracy(theta: f64) -> f64 {
    4.0 / (3.0 * RealScalar::sqrt(std::f64::consts::PI)) * RealScalar::powf(theta, -1.5)
}

/// F_{1/2}(η) = y を η = μ/k_BT について解く。導関数は F_{1/2}' = F_{−1/2}。
pub(crate) fn solve_eta(y: f64) -> Result<RootResult<f64>, String> {
    let value = move |eta: f64| -> Result<f64, SciOxideError> { Ok(fermi_dirac_half(eta)? - y) };
    let residual = ScalarFn::new(value).with_derivative(|eta: f64| fermi_dirac_mhalf(eta));
    // 根を挟む区間: F_{1/2}(η) < e^η から下端 ln y、F_{1/2}(η) > (4/(3√π)) η^(3/2) から上端。
    let lower = RealScalar::ln(y);
    let degenerate = RealScalar::powf(0.75 * RealScalar::sqrt(std::f64::consts::PI) * y, 2.0 / 3.0);
    let upper = degenerate.max(0.0) + 1.0;
    let guess = if y < 1.0 { lower } else { degenerate };
    let interval = Interval::new(lower, upper).map_err(|e| e.to_string())?;
    let start = SafeguardedInitialGuess::new(interval, guess).map_err(|e| e.to_string())?;
    SafeguardedNewton::default()
        .solve(&residual, start, &ScalarRootOptions::default())
        .map_err(|e| e.to_string())
}
```

## 化学ポテンシャルの温度依存性

次のセルは $\theta$ を $10^{-2}$ から $10$ まで対数の格子で動かして $\mu/E_F$ を求め、二つの極限の式と重ねて描く。
表は代表の $\theta$ で、求めた $\eta$ と $\mu/E_F$、極限の式との差、求根の終了状態と反復回数を並べる。
入力で極限の式の項数を選ぶと、Sommerfeld 展開の誤差が $O(\theta^4)$ から $O(\theta^6)$ に、古典極限の誤差が $O(y)$ から $O(y^2)$ に変わることを確かめられる。

```rust
//| id: special-fermi-gas-chemical-potential
//| ref: special-fermi-gas-chemical-potential
//| title: 電子気体の化学ポテンシャル μ/E_F を θ = k_BT/E_F の関数として求める
//| run: reactive
//| uses: [special-fermi-gas-model]
//| crates: [scioxide-core, scioxide-rootfind, scioxide-special]
//| inputs:
//|   terms: {"type":"select","label":"極限の式の項","description":"主要項だけか、次の補正項まで含めるか。","options":[{"label":"主要項だけ","value":"leading"},{"label":"補正項まで","value":"corrected"}],"value":"corrected"}
//| cases:
//|   - {"id":"leading","label":"主要項だけ","description":"Sommerfeld は 1 − (π²/12)θ²、古典極限は θ ln y だけで比べる。","inputs":{"terms":"leading"}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"potential","path":"/rows/1/2","approx":{"value":0.99164124,"atol":1e-7}}
//|       - {"artifact":"potential","path":"/rows/1/4","approx":{"value":1.23e-5,"rtol":0.02}}
//|       - {"artifact":"potential","path":"/rows/4/2","approx":{"value":-0.0214608,"atol":1e-6}}
//|       - {"artifact":"potential","path":"/rows/6/5","approx":{"value":1.12e-4,"rtol":0.02}}
//|   - case: leading
//|     expect:
//|       - {"artifact":"potential","path":"/rows/1/4","approx":{"value":1.341e-4,"rtol":0.01}}
//|       - {"artifact":"potential","path":"/rows/6/5","approx":{"value":0.1188,"rtol":0.01}}
use std::f64::consts::PI;

let corrected = terms == "corrected";
// 極限の式（手計算の参照）。μ/E_F の値を返す。
let sommerfeld = |theta: f64| {
    let quartic = if corrected {
        PI.powi(4) / 80.0 * theta.powi(4)
    } else {
        0.0
    };
    1.0 - PI * PI / 12.0 * theta * theta - quartic
};
let classical = |theta: f64| {
    let y = degeneracy(theta);
    let correction = if corrected {
        y / 2.0_f64.powf(1.5)
    } else {
        0.0
    };
    theta * (y.ln() + correction)
};
let mut exact = Vec::new();
let mut low = Vec::new();
let mut high = Vec::new();
for i in 0..=120 {
    let theta = 1e-2 * 1e3_f64.powf(i as f64 / 120.0);
    let eta = solve_eta(degeneracy(theta))?.point();
    exact.push([theta, theta * eta]);
    if theta <= 1.0 {
        low.push([theta, sommerfeld(theta)]);
    }
    if theta >= 0.5 {
        high.push([theta, classical(theta)]);
    }
}
let dashed = serde_json::json!({ "lineType": "dashed" });
emit_line_chart!(
    &vec![
        serde_json::json!({ "name": "求根による μ/E_F", "points": exact }),
        serde_json::json!({ "name": "Sommerfeld 展開", "points": low, "style": dashed }),
        serde_json::json!({ "name": "古典極限", "points": high, "style": dashed })
    ],
    options = &serde_json::json!({
        "xLabel": "θ = k_BT/E_F [-]",
        "yLabel": "μ/E_F [-]",
        "xType": "log",
        "yMin": -40.0,
        "yMax": 2.0,
        "annotations": [{ "kind": "line", "axis": "y", "value": 0.0, "label": "μ = 0" }]
    })
);

let mut rows = Vec::new();
for theta in [0.05, 0.1, 0.2, 0.5, 1.0, 2.0, 5.0] {
    let result = solve_eta(degeneracy(theta))?;
    let mu = theta * result.point();
    // 各極限の式は、その極限の側の θ だけで比べる。
    let low_error = (theta <= 0.5).then(|| (mu - sommerfeld(theta)).abs());
    let high_error = (theta >= 1.0).then(|| (mu - classical(theta)).abs());
    rows.push((
        theta,
        result.point(),
        mu,
        sommerfeld(theta),
        low_error,
        high_error,
        format!("{:?}", result.termination()),
        result.counts().iterations(),
    ));
}
let sig8 = serde_json::json!({ "significantDigits": 8 });
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let columns = serde_json::json!([
    { "key": "0", "label": "θ [-]", "type": "number", "format": { "significantDigits": 2 } },
    { "key": "1", "label": "η = μ/k_BT [-]", "type": "number", "format": sig8 },
    { "key": "2", "label": "μ/E_F [-]", "type": "number", "format": sig8 },
    { "key": "3", "label": "Sommerfeld の値 [-]", "type": "number", "format": sig8 },
    { "key": "4", "label": "|μ/E_F − Sommerfeld| [-]", "type": "number", "format": sci2, "nullText": "—" },
    { "key": "5", "label": "|μ/E_F − 古典極限| [-]", "type": "number", "format": sci2, "nullText": "—" },
    { "key": "6", "label": "終了状態" },
    { "key": "7", "label": "反復 [回]", "type": "integer" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "potential" })
);
```

図の $\mu/E_F$ は、$\theta \to 0$ で 1 から $\theta^2$ に比例して下がり、$\theta \approx 0.989$ で 0 を横切って負になり、高温では $-\tfrac{3}{2}\theta\ln\theta$ のように負の側へ大きくなる。
0 を横切る点は $F_{1/2}(0) = (1 - 2^{-1/2})\zeta(3/2) = 0.765147$ を密度の条件に入れた $\theta_0 = \bigl(4/(3\sqrt\pi\,F_{1/2}(0))\bigr)^{2/3} = 0.98873$ と合う。
既定（補正項まで）では、Sommerfeld 展開との差は $\theta = 0.05$ で $1.5 \times 10^{-7}$、$\theta = 0.1$ で $1.2 \times 10^{-5}$ である。
$\theta$ を半分にすると差は約 80 分の 1 になり、残りの項が $\theta^6$ の速さ（64 分の 1）で減ることとおおむね合う。
古典極限との差は $\theta = 1, 2, 5$ で $2.7 \times 10^{-3}$、$6.9 \times 10^{-4}$、$1.1 \times 10^{-4}$ と、$y$ が小さくなるにつれて減る。

主要項だけ（`leading`）にすると、$\theta = 0.1$ の Sommerfeld との差は $1.34 \times 10^{-4}$ になり、省いた項 $\pi^4\theta^4/80 = 1.22 \times 10^{-4}$ とほぼ等しい。
$\theta = 5$ の古典極限との差は 0.119 で、省いた補正 $\theta y/2^{3/2} = 0.119$ とほぼ等しい。
$\theta = 0.5$ では Sommerfeld の 2 項でも 0.025 ずれ、$\theta = 1$ では補正付きの古典極限でも $2.7 \times 10^{-3}$ ずれるので、$0.5 \lesssim \theta \lesssim 2$ は数値解が要る範囲である。
求根はどの $\theta$ でも 3〜5 回の反復で終わり、終了状態は `BracketTolerance` か `ResidualTolerance` である。

## 密度と温度から化学ポテンシャルを求める

次のセルは電子の数密度 $n$ [m⁻³] と温度 $T$ [K] を入力にとり、$E_F$、$T_F = E_F/k_B$、熱的波長 $\lambda$、縮退の目安 $n\lambda^3/2$ を求めてから、$\mu$ を eV 単位で求める。
物理定数は CODATA 2018 の値（$h$、$k_B$、電気素量は定義値、電子の質量は $9.1093837015 \times 10^{-31}$ kg）を使う。
既定の $n = 10^{26}$ m⁻³ は $T_F \approx 900$ K で、室温では部分的に縮退している。
ケースの銅は伝導電子の密度 $n = 8.47 \times 10^{28}$ m⁻³（Ashcroft & Mermin 1976, 1 章の表）を 1 原子あたり 1 個の自由電子とみなした値である。
求根の終了状態がこのセルの結論なので、最後に outcome で示す。

```rust
//| id: special-fermi-gas-physical
//| ref: special-fermi-gas-physical
//| title: 電子の密度と温度から化学ポテンシャル μ [eV] を求める
//| run: reactive
//| uses: [special-fermi-gas-model]
//| crates: [scioxide-core, scioxide-rootfind, scioxide-special]
//| inputs:
//|   log10_density: {"type":"range","label":"log₁₀ n（n [m⁻³]）","description":"電子の数密度の常用対数。","min":22,"max":30,"step":0.001,"value":26}
//|   temperature: {"type":"range","label":"温度 T [K]","min":1,"max":5000,"step":1,"value":300}
//| cases:
//|   - {"id":"copper","label":"銅の伝導電子、300 K","description":"n = 8.47×10²⁸ m⁻³ で E_F ≈ 7.0 eV、θ ≈ 0.0037。μ は E_F より相対 10⁻⁵ だけ低い。","inputs":{"log10_density":28.928,"temperature":300}}
//|   - {"id":"dilute","label":"n = 10²² m⁻³、1000 K","description":"nλ³/2 ≈ 10⁻⁴ の古典的な気体。μ は負で、Boltzmann の式 k_BT ln(nλ³/2) とほぼ一致する。","inputs":{"log10_density":22,"temperature":1000}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"state","path":"/rows/0/1","approx":{"value":0.0785604,"rtol":1e-5}}
//|       - {"artifact":"state","path":"/rows/6/1","approx":{"value":0.0703487,"rtol":1e-5}}
//|       - {"artifact":"state","path":"/rows/7/1","range":{"max":1e-13}}
//|       - {"path":"/outputs/1/state","equals":"satisfied"}
//|   - case: copper
//|     expect:
//|       - {"artifact":"state","path":"/rows/0/1","approx":{"value":7.03402,"rtol":1e-5}}
//|       - {"artifact":"state","path":"/rows/6/1","approx":{"value":7.03394,"rtol":1e-5}}
//|       - {"artifact":"state","path":"/rows/8/1","range":{"max":1e-12}}
//|       - {"path":"/outputs/1/state","equals":"satisfied"}
//|   - case: dilute
//|     expect:
//|       - {"artifact":"state","path":"/rows/6/1","approx":{"value":-0.830171,"rtol":1e-5}}
//|       - {"artifact":"state","path":"/rows/9/1","range":{"max":1e-7}}
//|       - {"path":"/outputs/1/state","equals":"satisfied"}
use scioxide_core::RealScalar;
use std::f64::consts::PI;

// CODATA 2018 の物理定数（SI）。
let planck = 6.62607015e-34; // h [J·s]
let hbar = planck / (2.0 * PI);
let boltzmann = 1.380649e-23; // k_B [J/K]
let electron_volt = 1.602176634e-19; // [J]
let mass = 9.1093837015e-31; // 電子の質量 m_e [kg]

let density = RealScalar::powf(10.0, log10_density);
let fermi_energy =
    hbar * hbar / (2.0 * mass) * RealScalar::powf(3.0 * PI * PI * density, 2.0 / 3.0);
let thermal = boltzmann * temperature;
let theta = thermal / fermi_energy;
let wavelength = planck / RealScalar::sqrt(2.0 * PI * mass * thermal);
let y = density * RealScalar::powi(wavelength, 3) / 2.0;
let result = solve_eta(y)?;
let eta = result.point();
let mu = eta * thermal / electron_volt;
// 検算（手計算）: y の二つの式の一致、低温の Sommerfeld 展開、高温の古典極限。
let consistency = (y - degeneracy(theta)).abs() / y;
let sommerfeld = 1.0 - PI * PI / 12.0 * theta * theta - PI.powi(4) / 80.0 * theta.powi(4);
let classical = theta * (y.ln() + y / 2.0_f64.powf(1.5));
let rows = vec![
    ("E_F [eV]", Some(fermi_energy / electron_volt)),
    ("T_F = E_F/k_B [K]", Some(fermi_energy / boltzmann)),
    ("θ = k_BT/E_F [-]", Some(theta)),
    ("熱的波長 λ [nm]", Some(wavelength * 1e9)),
    ("nλ³/2 = F_{1/2}(η) [-]", Some(y)),
    ("η = μ/k_BT [-]", Some(eta)),
    ("μ [eV]", Some(mu)),
    ("y の二つの式の相対差 [-]", Some(consistency)),
    (
        "|μ/E_F − Sommerfeld|（θ ≤ 0.5）[-]",
        (theta <= 0.5).then(|| (theta * eta - sommerfeld).abs()),
    ),
    (
        "|μ/E_F − 古典極限|（θ ≥ 1）[-]",
        (theta >= 1.0).then(|| (theta * eta - classical).abs()),
    ),
];
let columns = serde_json::json!([
    { "key": "0", "label": "量" },
    { "key": "1", "label": "値", "type": "number", "format": { "significantDigits": 6 }, "nullText": "適用外" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "state" })
);

let termination = result.termination();
let outcome = if termination.is_success() {
    Outcome::satisfied("F_{1/2}(η) = nλ³/2 の根を停止の基準まで求めた")
} else {
    Outcome::partial("求根が基準に達する前に止まった。最後の点は推定値")
};
emit_outcome!(
    outcome
        .status(format!("{termination:?}"))
        .diagnostic("残差 F_{1/2}(η) − y", result.residual(), None)
        .diagnostic("反復回数", result.counts().iterations() as f64, None)
);
```

既定の $n = 10^{26}$ m⁻³ では $E_F = 0.0786$ eV、$T_F = 912$ K で、300 K では $\theta = 0.329$、$n\lambda^3/2 = 3.98$ である。
求根は $\eta = 2.72$、$\mu = 0.0703$ eV を与え、$\mu$ は $E_F$ より約 10 % 低い。
Sommerfeld 展開の 2 項との差は $\mu/E_F$ で $1.2 \times 10^{-3}$ で、この温度では展開の打ち切りが見える。
$n\lambda^3/2$ を物理定数から直接計算した値と $(4/(3\sqrt\pi))\theta^{-3/2}$ の相対差は $3 \times 10^{-15}$ で、単位の換算が正しいことを確かめる。

銅（`copper`）では $E_F = 7.034$ eV、$T_F = 8.16 \times 10^4$ K、$\theta = 0.0037$ で、$\mu = 7.03394$ eV は $E_F$ より相対 $1.1 \times 10^{-5}$ だけ低い。
Sommerfeld 展開との差は $2 \times 10^{-14}$ で、倍精度の丸めの水準である。
希薄な気体（`dilute`）では $\theta = 509$、$n\lambda^3/2 = 6.5 \times 10^{-5}$ で、$\mu = -0.830$ eV は補正付きの古典極限と $1.1 \times 10^{-8}$ の差で一致する。
どのケースでも outcome は satisfied で、残差はちょうど 0（終了状態 `ResidualTolerance`）、反復は 2〜5 回である。
入力の端の $n = 10^{30}$ m⁻³、300 K（$\eta \approx 1410$）では反復が 37 回に増えるが、終了状態は `BracketTolerance` で、outcome は satisfied のままである。
反復回数が上限の 100 回に近づくか outcome が partial になる場合は、区間の端点か導関数の渡し方を見直す。

## まとめ

自由電子気体の密度の式は Gamma で規格化した scioxide-special の Fermi–Dirac 積分で $n = (2/\lambda^3)F_{1/2}(\mu/k_BT)$ と書け、規格化のない積分と混ぜると密度が $\sqrt{\pi}/2$ 倍ずれる。
規格化した積分では導関数が $F_{1/2}' = F_{-1/2}$ になるので、`fermi_dirac_mhalf` を導関数として `SafeguardedNewton` に渡し、$\ln y$ と Sommerfeld の主要項から作った区間で根を挟めば、縮退から古典まで同じ手続きで解ける。
求めた $\mu/E_F$ は、$\theta \le 0.1$ では Sommerfeld 展開の 2 項と $10^{-5}$ 程度以下の差で、$\theta \ge 2$ では補正付きの古典極限と $10^{-3}$ 程度以下の差で一致し、その間の $0.5 \lesssim \theta \lesssim 2$ では数値解が要る。
金属の伝導電子は室温で $\theta \sim 10^{-3}$ なので $\mu \approx E_F$ とみなせるが、密度の低い半導体の電子では温度とともに $\mu$ が大きく動く。
$F_{1/2}$ の評価法と精度は[Fermi–Dirac 積分](../../algorithms/fermi-dirac-integrals/)で、区間法と Newton 法の選び方は scioxide-rootfind の[開いた反復法](../../../scioxide-rootfind/algorithms/open-scalar-methods/)で確かめる。
