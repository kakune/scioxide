要求が不規則に届くサービスで、要求を $a$ 件ためてからまとめて処理するとき、バッチがそろうまでの待ち時間は Gamma 分布に従う。
放射線の計数で $a$ 個目の崩壊を待つ時間や、部品が $a$ 回目の故障で止まるまでの時間も同じ分布になる。
「バッチの 99.9 % が $t$ 秒以内にそろう」という目標から $t$ を決めるには、累積分布関数を逆に解いて確率 $p$ から時間を求める分位点の計算が要る。
この例題は待ち時間の分布を導き、`gamma_p_inv` と `gamma_q_inv` で分位点を求め、Poisson 分布の有限和、上側の確率の丸めの解析、カイ二乗分布の閉形式で結果を確かめる。

## Poisson 到着と Gamma 分布

要求が平均 $\lambda$ [件/s] の割合で互いに独立に届く Poisson 過程を考える。
時間 $[0, t]$ に届く件数 $N(t)$ は平均 $\lambda t$ の Poisson 分布に従う。

$$
\Pr[N(t) = k] = e^{-\lambda t}\frac{(\lambda t)^k}{k!}
$$

$a$ 件目の到着時刻を $T_a$ とすると、「$T_a \le t$」と「$N(t) \ge a$」は同じ事象である。
したがって、無次元の時間 $x = \lambda t$ を使うと

$$
\Pr[T_a \le t] = 1 - e^{-x}\sum_{k=0}^{a-1}\frac{x^k}{k!} = P(a, x)
$$

となり、待ち時間の累積分布関数は正則化下側不完全 Gamma 関数 $P(a, x)$ である（[不完全 Gamma 関数](oxref:special-incgamma-definition)）。
右辺の和は整数の $a$ について DLMF 8.4.10 の有限和 $Q(a, x) = e^{-x}\sum_{k<a} x^k/k!$ と一致する。
$x$ で微分すると密度

$$
f(x) = \frac{x^{a-1}e^{-x}}{\Gamma(a)}
$$

が得られ、平均と分散はどちらも $a$ である。
秒に戻すと、待ち時間の平均は $a/\lambda$、標準偏差は $\sqrt{a}/\lambda$ になる。

確率 $p$ の分位点 $t_p$ は非線形方程式 $P(a, \lambda t_p) = p$ の解である。

$$
x_p = P^{-1}(a, p), \qquad t_p = \frac{x_p}{\lambda}
$$

## 分位点の感度

逆関数の微分は密度の逆数 $dx/dp = 1/f(x)$ である。
$p$ の相対的な変化が $x_p$ の相対的な変化に何倍で伝わるかを表す条件数は

$$
\kappa_p = \left|\frac{p}{x}\frac{dx}{dp}\right| = \frac{p}{x\, f(x)}
$$

で、上側の確率 $q = 1 - p$ で指定するときの条件数は $\kappa_q = q/(x f(x))$ である。
右の裾では $f(x)$ も $q$ も指数的に小さくなるが、$x$ が $a$ より十分大きければ比 $q/f(x)$ はおよそ 1 にとどまるので、$\kappa_q$ は $1/x$ の程度で小さい。
一方、$p$ が 1 に近いと $\kappa_p \approx 1/(x f(x))$ は大きくなり、$p$ のわずかな違いが分位点を大きく動かす。

この違いは目標を $p$ で渡すか $q$ で渡すかの選択に直結する。
$p = 1 - q$ を binary64 で作ると、丸めで $q$ に絶対誤差 $\delta \le 2^{-53}$ の程度が入る。
これは $q$ の相対誤差 $\delta/q$ になり、$q = 10^{-9}$ では $10^{-7}$ の程度である。
`gamma_p_inv(a, p)` は $p > 1/2$ を内部で正確に $1 - p$ へ移して上側の裾を解くが、渡された $p$ がすでに丸めた値なので、この誤差は取り除けない。
上側の確率で目標を決めるなら、`gamma_q_inv(a, q)` に $q$ を直接渡す。
$q$ が binary64 で表せないほど小さければ、対数 $\ln q$ を `gamma_q_inv_log` に渡す。

逆関数は漸近式から作った初期値から $\ln x$ を変数とする Halley 法を、根を挟む区間で保護しながら進め、結果の型の精度に達したところで止まる。
試験した範囲での精度の目標は binary64 で 32 ULP である。
方法の詳細は [対数形と逆関数](oxref:special-incgamma-log-inverse) にある。

## バッチ処理の待ち時間の分位点

次のセルはバッチの大きさ $a$ [件]、到着率 $\lambda$ [件/s]、目標の確率 $p$ から、待ち時間の分位点を求める。
図は $p \in [0.01, 0.99]$ の分位点 $t_p$ の曲線で、目標の確率と分位点を補助線で示す。
表は平均 $a/\lambda$、中央値、目標の分位点 $t_p$、条件数 $\kappa_p$、往復の誤差 $|P(a, x_p) - p|$ を並べる。
独立な検算として、上で導いた Poisson 分布の有限和 $1 - e^{-x}\sum_{k<a} x^k/k!$ を `f64` の標準関数で手で足し、目標の $p$ との差を出す。
往復の誤差は逆関数と `gamma_p` の整合を見るだけなので、別の式で作る有限和の差を検算の本体とする。

```rust
//| id: special-gamma-quantiles
//| ref: special-gamma-quantiles
//| title: バッチがそろうまでの待ち時間の分位点を求める
//| run: reactive
//| crates: [scioxide-special]
//| inputs:
//|   batch_size: {"type":"range","label":"バッチの大きさ a [件]","description":"何件目の到着を待つかを変える。","min":1,"max":100,"step":1,"value":20}
//|   arrival_rate: {"type":"range","label":"到着率 λ [件/s]","description":"1 秒あたりに届く要求の平均件数。","min":1,"max":100,"step":1,"value":10}
//|   target_probability: {"type":"range","label":"目標の確率 p [-]","description":"この確率でバッチがそろう時間を求める。","min":0.5,"max":0.999,"step":0.001,"value":0.999}
//| cases:
//|   - {"id":"median","label":"p = 0.5","description":"中央値は平均 a/λ より少し短い。","inputs":{"target_probability":0.5}}
//|   - {"id":"single","label":"a = 1","description":"1 件目までの待ち時間は指数分布で、x_p = −ln(1 − p) になる。","inputs":{"batch_size":1}}
//|   - {"id":"large","label":"a = 100","description":"大きなバッチでは分布が平均のまわりに集まり、相対的なばらつきが減る。","inputs":{"batch_size":100}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"quantiles","path":"/rows/0/2","approx":{"value":1.966767242,"rtol":1e-8}}
//|       - {"artifact":"quantiles","path":"/rows/0/3","approx":{"value":3.670097876,"rtol":1e-8}}
//|       - {"artifact":"quantiles","path":"/rows/0/4","approx":{"value":53.72,"rtol":1e-3}}
//|       - {"artifact":"quantiles","path":"/rows/0/5","range":{"max":1e-15}}
//|       - {"artifact":"quantiles","path":"/rows/0/6","range":{"max":1e-14}}
//|   - case: median
//|     expect:
//|       - {"artifact":"quantiles","path":"/rows/0/3","approx":{"value":1.966767242,"rtol":1e-8}}
//|       - {"artifact":"quantiles","path":"/rows/0/6","range":{"max":1e-14}}
//|   - case: single
//|     expect:
//|       - {"artifact":"quantiles","path":"/rows/0/3","approx":{"value":0.690775527898214,"rtol":1e-14}}
//|       - {"artifact":"quantiles","path":"/rows/0/6","range":{"max":1e-15}}
//|   - case: large
//|     expect:
//|       - {"artifact":"quantiles","path":"/rows/0/3","approx":{"value":13.377026391,"rtol":1e-8}}
//|       - {"artifact":"quantiles","path":"/rows/0/6","range":{"max":1e-15}}
use scioxide_special::{gamma_p, gamma_p_inv, ln_gamma};

let a = batch_size;
let lambda = arrival_rate;
let p = target_probability;
let fixed4 = serde_json::json!({ "significantDigits": 5 });
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });

// 分位点の曲線（時間に戻して秒で描く）。
let curve = (1..=99)
    .map(|index| {
        let probability = f64::from(index) / 100.0;
        gamma_p_inv(a, probability).map(|x| [probability, x / lambda])
    })
    .collect::<Result<Vec<_>, _>>()
    .map_err(|e| e.to_string())?;
let median = gamma_p_inv(a, 0.5).map_err(|e| e.to_string())?;
let x = gamma_p_inv(a, p).map_err(|e| e.to_string())?;
let roundtrip = (gamma_p(a, x).map_err(|e| e.to_string())? - p).abs();

// 独立検算: Poisson 分布の有限和 1 − e^(−x) Σ_{k<a} x^k / k!（f64 の標準関数で手計算）。
let mut term = (-x).exp();
let mut below = term;
for k in 1..a as usize {
    term *= x / k as f64;
    below += term;
}
let poisson_error = ((1.0 - below) - p).abs();
// 条件数 κ_p = p / (x f(x))、f(x) = x^(a−1) e^(−x) / Γ(a)（ln Γ 以外は f64 の標準関数で手計算）。
let log_density = (a - 1.0) * x.ln() - x - ln_gamma(a).map_err(|e| e.to_string())?;
let condition = p / (x * log_density.exp());

emit_line_chart!(
    &vec![serde_json::json!({ "name": "分位点 t_p", "points": curve })],
    options = &serde_json::json!({
        "xLabel": "確率 p [-]",
        "yLabel": "待ち時間 t [s]",
        "xMin": 0.0,
        "xMax": 1.0,
        "annotations": [
            { "kind": "line", "axis": "x", "value": p, "label": "目標の確率" },
            { "kind": "line", "axis": "y", "value": x / lambda, "label": "目標の分位点" },
            { "kind": "line", "axis": "y", "value": a / lambda, "label": "平均 a/λ" }
        ]
    })
);
let columns = serde_json::json!([
    { "key": "0", "label": "a [件]", "type": "integer" },
    { "key": "1", "label": "平均 a/λ [s]", "type": "number", "format": fixed4 },
    { "key": "2", "label": "中央値 [s]", "type": "number", "format": fixed4 },
    { "key": "3", "label": "分位点 t_p [s]", "type": "number", "format": fixed4 },
    { "key": "4", "label": "条件数 κ_p [-]", "type": "number", "format": fixed4 },
    { "key": "5", "label": "往復の誤差 |P − p| [-]", "type": "number", "format": sci3 },
    { "key": "6", "label": "Poisson 和との差 [-]", "type": "number", "format": sci3 }
]);
emit_table_with_columns!(
    columns,
    vec![(
        a as u32,
        a / lambda,
        median / lambda,
        x / lambda,
        condition,
        roundtrip,
        poisson_error
    )],
    metadata = serde_json::json!({ "id": "quantiles" })
);
```

既定の $a = 20$ 件、$\lambda = 10$ 件/s では、待ち時間の平均は 2 s、中央値は 1.967 s で、99.9 % のバッチは 3.670 s 以内にそろう。
目標を 0.5 から 0.999 へ上げると、確率は 2 倍に満たないが、分位点は 1.87 倍に伸び、条件数 $\kappa_p$ は 0.28 から 53.7 に増える。
$a = 1$ では指数分布になり、99.9 % 点は $x = -\ln 0.001 = 6.908$、すなわち 0.691 s で、条件数は 145 まで大きくなる。
$a = 100$ では平均 10 s に対して 99.9 % 点が 13.38 s で、平均に対する比は $a = 20$ の 1.84 から 1.34 に縮む。
これは標準偏差 $\sqrt{a}/\lambda$ が平均 $a/\lambda$ より遅く増えるためである。

往復の誤差と Poisson 和との差は、どの入力でも $10^{-15}$ 以下で、binary64 の丸めの程度である。
差が $10^{-12}$ を超えたら、到着率で割る前の無次元の $x$ と秒の $t$ を取り違えていないかを確かめる。

## 上側の確率で目標を渡す

次のセルはバッチの大きさ $a$ を選び、上側の確率 $q = 10^{-k}$ を $k = 1$ から $400$ まで変えて、三つの方法で分位点 $x_q$ を求める。
一つは `gamma_q_inv(a, q)`、一つは丸めた $p = 1 - q$ を渡す `gamma_p_inv(a, p)`、一つは $\ln q = -k \ln 10$ を渡す `gamma_q_inv_log(a, ln q)` である。
$q = 10^{-400}$ は binary64 で表せないので、その行は対数形だけで解く。
表は二つ目の方法の相対差と、丸めの解析から予想される相対差 $\delta/(x f(x))$ を並べる。
$\delta = (1 - p) - q$ は $p$ を丸めたときに $q$ に入った誤差で、$p \ge 1/2$ では $1 - p$ が正確に計算できるので、$\delta$ も binary64 で正確に求まる。
予想と実測が合えば、二つ目の方法の差は逆関数の誤差でなく、入力の丸めによることが分かる。
最後の列は `gamma_log_q` で順方向に戻した $\ln Q(a, x_q)$ と $\ln q$ の差である。

```rust
//| id: special-gamma-quantile-tails
//| ref: special-gamma-quantile-tails
//| title: 上側の確率から分位点を求め、1 − q の丸めの影響を見る
//| run: reactive
//| crates: [scioxide-special]
//| inputs:
//|   batch_size: {"type":"range","label":"バッチの大きさ a [件]","description":"分布の形を変える。","min":1,"max":100,"step":1,"value":20}
//| cases:
//|   - {"id":"single","label":"a = 1","description":"指数分布では x_q = −ln q が閉形式で求まる。","inputs":{"batch_size":1}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"tails","path":"/rows/2/3","range":{"max":1e-15}}
//|       - {"artifact":"tails","path":"/rows/4/3","approx":{"value":6.935e-10,"rtol":1e-3}}
//|       - {"artifact":"tails","path":"/rows/4/4","approx":{"value":6.935e-10,"rtol":1e-3}}
//|       - {"artifact":"tails","path":"/rows/7/2","equals":null}
//|       - {"artifact":"tails","path":"/rows/8/6","range":{"max":1e-14}}
//|       - {"artifact":"tails","path":"/rows/9/1","equals":null}
//|       - {"artifact":"tails","path":"/rows/9/6","range":{"max":1e-12}}
//|   - case: single
//|     expect:
//|       - {"artifact":"tails","path":"/rows/8/1","approx":{"value":690.7755278982137,"rtol":1e-14}}
//|       - {"artifact":"tails","path":"/rows/9/5","approx":{"value":921.0340371976183,"rtol":1e-14}}
use scioxide_special::{gamma_log_q, gamma_p_inv, gamma_q_inv, gamma_q_inv_log, ln_gamma};

let a = batch_size;
let sig10 = serde_json::json!({ "significantDigits": 10 });
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let log_gamma_a = ln_gamma(a).map_err(|e| e.to_string())?;
let mut rows = Vec::new();
let mut direct_points = Vec::new();
let mut rounded_points = Vec::new();
for k in [1_u32, 2, 3, 6, 9, 12, 16, 17, 300, 400] {
    let log_q = -f64::from(k) * std::f64::consts::LN_10;
    // 10^(−400) は binary64 の範囲外なので None。
    let q = (k <= 300).then(|| 10.0_f64.powi(-(k as i32)));
    let from_log = gamma_q_inv_log(a, log_q).map_err(|e| e.to_string())?;
    let direct = match q {
        Some(q) => Some(gamma_q_inv(a, q).map_err(|e| e.to_string())?),
        None => None,
    };
    // 丸めた p = 1 − q を渡す。1 − q が 1 に丸まると分位点は +∞ になる。
    let rounded = match q {
        Some(q) => {
            Some(gamma_p_inv(a, 1.0 - q).map_err(|e| e.to_string())?).filter(|x| x.is_finite())
        }
        None => None,
    };
    let rounded_error = match (direct, rounded) {
        (Some(x), Some(y)) => Some((y - x).abs() / x),
        _ => None,
    };
    // 丸めの解析による予想: δ / (x f(x))、δ = (1 − p) − q（p ≥ 1/2 では 1 − p は正確）。
    let predicted = match (q, direct) {
        (Some(q), Some(x)) if 1.0 - q < 1.0 => {
            let delta = (1.0 - (1.0 - q)) - q;
            let log_density = (a - 1.0) * x.ln() - x - log_gamma_a;
            Some(delta.abs() / (x * log_density.exp()))
        }
        _ => None,
    };
    let back = gamma_log_q(a, from_log).map_err(|e| e.to_string())?;
    if let Some(x) = direct {
        direct_points.push([f64::from(k), x]);
    }
    if let Some(y) = rounded {
        rounded_points.push([f64::from(k), y]);
    }
    rows.push((
        k,
        direct,
        rounded,
        rounded_error,
        predicted,
        from_log,
        (back - log_q).abs() / log_q.abs(),
    ));
}

emit_line_chart!(
    &vec![
        serde_json::json!({ "name": "gamma_q_inv(a, q)", "points": direct_points }),
        serde_json::json!({
            "name": "gamma_p_inv(a, 1 − q)",
            "points": rounded_points,
            "style": { "lineType": "dashed" }
        })
    ],
    options = &serde_json::json!({
        "xLabel": "k（q = 10^−k）[-]",
        "yLabel": "分位点 x_q [-]",
        "xType": "log",
        "yType": "log"
    })
);
let columns = serde_json::json!([
    { "key": "0", "label": "k（q = 10^−k）", "type": "integer" },
    { "key": "1", "label": "gamma_q_inv [-]", "type": "number", "format": sig10, "nullText": "q を表せない" },
    { "key": "2", "label": "gamma_p_inv(1 − q) [-]", "type": "number", "format": sig10, "nullText": "1 − q = 1" },
    { "key": "3", "label": "相対差 [-]", "type": "number", "format": sci3, "nullText": "—" },
    { "key": "4", "label": "丸めからの予想 [-]", "type": "number", "format": sci3, "nullText": "—" },
    { "key": "5", "label": "gamma_q_inv_log [-]", "type": "number", "format": sig10 },
    { "key": "6", "label": "ln Q の相対残差 [-]", "type": "number", "format": sci3 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "tails" })
);
```

既定の $a = 20$ では、$k \le 3$ で三つの手法オブジェクトが一致する。
$k = 6$ から `gamma_p_inv(a, 1 − q)` の値がずれ始め、相対差は $k = 6$ で $9.5 \times 10^{-13}$、$k = 9$ で $6.9 \times 10^{-10}$、$k = 12$ で $4.4 \times 10^{-7}$ に増える。
$k = 6$ から $12$ の行では、丸めの解析から予想した $\delta/(x f(x))$ が実測の相対差と 3 桁以上一致するので、ずれは逆関数の誤差でなく、$p = 1 - q$ を作ったときの丸めによる。
$k = 16$ では $1 - q$ が 1 の一つ手前の数 $1 - 2^{-53}$ に丸まって $q$ が 11 % 変わり、相対差は $1.7 \times 10^{-3}$ に達する。
この行では $q$ の変化が大きく、線形の予想 $1.8 \times 10^{-3}$ からわずかに外れる。
$k = 17$ では $1 - q$ が 1 に丸まり、`gamma_p_inv` は $+\infty$ を返す（表では空欄）。

`gamma_q_inv` と `gamma_q_inv_log` は $k = 300$ まで一致し、$q = 10^{-400}$ では対数形だけが $x = 1013.2$ を返す。
`gamma_log_q` で戻した $\ln Q$ の相対残差はすべて $10^{-15}$ 以下である。
$a = 1$ では $x_q = k\ln 10$ になり、$k = 300$ で 690.78、$k = 400$ で 921.03 と閉形式に一致する。

## 検算：カイ二乗分布の分位点

自由度 $\nu$ のカイ二乗分布は形状 $\nu/2$、尺度 2 の Gamma 分布なので、その分位点は $\chi^2_p = 2P^{-1}(\nu/2, p)$ である。
三つの自由度では、`gamma_p_inv` と別の式で分位点を確かめられる。
$\nu = 2$ は指数分布で、閉形式 $\chi^2_p = -2\ln(1 - p)$ がある。
$\nu = 1$ は $P(1/2, x) = \operatorname{erf}\sqrt{x}$ から $\chi^2_p = 2\,[\operatorname{erfc}^{-1}(1 - p)]^2$ で、逆相補誤差関数 `erfcinv` という別の関数で計算できる。
$\nu = 10$ は形状 5 の整数で、上の Poisson 分布の有限和に分位点を代入して $p$ との差を見る。
$\nu = 1$ の 95 % 点は正規分布の両側 95 % 点 $1.95996$ の 2 乗 $3.84146$ である。

```rust
//| id: special-gamma-chi-square
//| ref: special-gamma-chi-square
//| title: カイ二乗分布の分位点を閉形式と別の関数で確かめる
//| run: reactive
//| crates: [scioxide-special]
//| tests:
//|   - case: default
//|     expect:

use scioxide_special::{erfcinv, gamma_p_inv};

let sig10 = serde_json::json!({ "significantDigits": 10 });
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let mut rows = Vec::new();
for nu in [1_u32, 2, 10] {
    for p in [0.95, 0.99, 0.999] {
        let chi_square =
            2.0 * gamma_p_inv(f64::from(nu) / 2.0, p).map_err(|e| e.to_string())?;
        // 独立な検算。ν = 1, 2 は別の式の分位点、ν = 10 は有限和の P と p の差。
        let (method, reference, error) = match nu {
            1 => {
                let root = erfcinv(1.0 - p).map_err(|e| e.to_string())?;
                let value = 2.0 * root * root;
                (
                    "2 erfcinv(1 − p)²",
                    Some(value),
                    (chi_square - value).abs() / value,
                )
            }
            2 => {
                // 閉形式 −2 ln(1 − p)（f64 の標準関数による参照値）。
                let value = -2.0 * (-p).ln_1p();
                (
                    "−2 ln(1 − p)",
                    Some(value),
                    (chi_square - value).abs() / value,
                )
            }
            _ => {
                // P(5, x) = 1 − e^(−x) Σ_{k<5} x^k / k!（手計算）。
                let x = chi_square / 2.0;
                let mut term = (-x).exp();
                let mut below = term;
                for k in 1..5 {
                    term *= x / f64::from(k);
                    below += term;
                }
                ("Poisson 和の P − p", None, ((1.0 - below) - p).abs())
            }
        };
        rows.push((nu, p, chi_square, reference, error, method));
    }
}
```

$\nu = 10$ の 3 行では、Poisson 和の $P$ と $p$ の差が $1.1 \times 10^{-16}$ 以下である。
どの差も binary64 の丸めの程度で、逆関数が目標とする 32 ULP（相対誤差で $7 \times 10^{-15}$ 程度）よりずっと小さい。

## まとめと次に読むページ

Poisson 到着で $a$ 件目までの待ち時間は形状 $a$ の Gamma 分布に従い、その分位点は $t_p = P^{-1}(a, p)/\lambda$ で、`gamma_p_inv` が直接求める。
$p$ が 1 に近い右の裾では条件数 $\kappa_p$ が大きく、目標の確率のわずかな違いが分位点を大きく動かす。
目標を上側の確率 $q$ で決めるなら `gamma_q_inv(a, q)` に $q$ をそのまま渡し、$1 - q$ を作らない。
$q$ が binary64 で表せないほど小さい裾では、`gamma_q_inv_log` に $\ln q$ を渡す。
評価法と逆関数の仕組みは [不完全 Gamma 関数](../../algorithms/incomplete-gamma/) で、関数ごとの仕様は [Gamma・Beta 関数と確率の裾](../../api/gamma-and-beta/) で確かめる。
