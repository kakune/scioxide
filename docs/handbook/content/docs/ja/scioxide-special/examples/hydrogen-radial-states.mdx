核電荷 $Ze$ の原子核のまわりを電子が 1 個だけ回る系（水素原子、He⁺、Li²⁺ など）は、Schrödinger 方程式が閉じた形で解ける。
波動関数は動径関数 $R_{nl}(r)$ と球面調和関数の積に分かれ、原子の大きさ、遷移の強さ、超微細構造などの量は $R_{nl}$ の積分で決まる。
この例では、`hydrogenic_radial` で $R_{nl}$ を評価し、動径確率密度を描いて、規格化と期待値の閉形式、節の数と位置を独立な数値積分で確かめる。
関数の定義と評価法は [Coulomb 波動関数と水素様動径状態](oxref:special-coulomb-hydrogenic) にある。

## モデルと単位

原子核の質量を無限大とみなし、ポテンシャル $V(r) = -Ze^2/(4\pi\varepsilon_0 r)$ の中の電子を考える。
長さを Bohr 半径 $a_0 = 4\pi\varepsilon_0\hbar^2/(m_e e^2) = 5.29177210903 \times 10^{-11}\,\mathrm{m}$（CODATA 2018 の推奨値、Tiesinga ほか 2021）で測ると、束縛状態のエネルギーは $E_n = -Z^2/(2n^2)$ Hartree（1 Hartree $= 27.211$ eV）で、動径関数は次の式になる。

$$
R_{nl}(r) = \left(\frac{2Z}{n}\right)^{3/2}\sqrt{\frac{(n - l - 1)!}{2n\,(n + l)!}}\;e^{-\rho/2}\rho^l\,L_{n-l-1}^{(2l+1)}(\rho), \qquad \rho = \frac{2Zr}{n}.
$$

$L_k^{(\alpha)}$ は一般化 Laguerre 多項式で、その性質と三項漸化式は [直交多項式の族](../../../scioxide-poly/algorithms/orthogonal-families/) にある。
`hydrogenic_radial(n, l, charge, r)` は $r$ を $a_0$ の単位で受け取り、$\int_0^\infty R_{nl}^2r^2\,dr = 1$ に規格化した値を返す。
実際の水素原子では換算質量 $\mu = m_em_p/(m_e + m_p)$ のために長さが $m_e/\mu \approx 1.000545$ 倍になるが、この例では無視する。

$P_{nl}(r) = r^2R_{nl}(r)^2$ は、半径 $r$ と $r + dr$ の間の球殻に電子を見いだす確率密度である。
動径関数は $0 < r < \infty$ に $n - l - 1$ 個の節（$R_{nl} = 0$ となる点）を持ち、原点では $R_{nl} \sim r^l$ のように振る舞う。
$l = 0$ だけが原点で 0 にならず、$R_{n0}(0) = 2(Z/n)^{3/2}$ である。

## 期待値の閉形式

$r$ の冪の期待値 $\langle r^k\rangle = \int_0^\infty r^k P_{nl}(r)\,dr$ には、次の閉形式がある（Bethe・Salpeter 1957 などの量子力学の標準的な教科書にある結果）。

$$
\langle r\rangle = \frac{3n^2 - l(l+1)}{2Z}, \qquad
\langle r^2\rangle = \frac{n^2\left(5n^2 + 1 - 3l(l+1)\right)}{2Z^2},
$$

$$
\langle r^{-1}\rangle = \frac{Z}{n^2}, \qquad
\langle r^{-2}\rangle = \frac{Z^2}{n^3(l + 1/2)}.
$$

単位はそれぞれ $a_0$、$a_0^2$、$a_0^{-1}$、$a_0^{-2}$ である。
$\langle r^{-1}\rangle$ はビリアル定理 $\langle V\rangle = 2E_n$ と同じ内容で、主量子数だけで決まる。
$\langle r\rangle$ は同じ $n$ でも $l$ が大きいほど小さく、$l = n - 1$ の状態は節を持たない一つの山になる。
$Z$ を変えると長さはすべて $1/Z$ 倍になるので、He⁺（$Z = 2$）の $1s$ の $\langle r\rangle$ は水素の半分の $0.75\,a_0$ である。

## 動径確率密度と期待値の検算

次のセルは、$n$、$l$、$Z$ を選び、$0 \le r \le r_{\max}$ の等間隔の 8001 点で `hydrogenic_radial` を評価して $P_{nl}(r)$ を描く。
$r_{\max} = (n/Z)(2n + 40)$ では $e^{-\rho}$ が $e^{-4n-80}$ まで小さくなり、裾を捨てる誤差は無視できる。
同じ点の値から、規格化と四つの期待値を複合 Simpson 則で手計算し（独立検算）、閉形式と比べる。
$\langle r^{-1}\rangle$、$\langle r^{-2}\rangle$ の被積分関数 $rR^2$、$R^2$ は原点でも有限なので、同じ規則で積分できる。
節は $R_{nl}$ の符号の変化から数え、隣り合う 2 点の間を一次補間して位置を求める。
$l \ge n$ の組は `hydrogenic_radial` が `DomainError`（`OutsideDomain`）で拒むので、セルは $l$ を $n - 1$ に制限してから呼び、実際に計算した $(n, l)$ を節の表に示す。

```rust
//| id: special-hydrogen-radial-states
//| ref: special-hydrogen-radial-states
//| title: 水素様原子の動径確率密度と期待値
//| run: reactive
//| crates: [scioxide-special]
//| inputs:
//|   n: {"type":"range","label":"主量子数 n","min":1,"max":6,"step":1,"value":3}
//|   l: {"type":"range","label":"軌道量子数 l（l < n）","min":0,"max":5,"step":1,"value":0}
//|   charge: {"type":"range","label":"核電荷 Z","min":1,"max":10,"step":1,"value":1}
//| cases:
//|   - {"id":"circular","label":"3d（n = 3、l = 2）","description":"l = n − 1 の状態は節がなく、一つの山が r = n² = 9 a₀ にある。","inputs":{"l":2}}
//|   - {"id":"helium-ion","label":"He⁺ の 2s","description":"Z = 2 では長さがすべて半分になり、節は r = 1 a₀ に移る。","inputs":{"n":2,"charge":2}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"moments","path":"/rows/0/3","range":{"max":1e-7}}
//|       - {"artifact":"moments","path":"/rows/1/3","range":{"max":1e-7}}
//|       - {"artifact":"moments","path":"/rows/2/3","range":{"max":1e-7}}
//|       - {"artifact":"moments","path":"/rows/3/3","range":{"max":1e-7}}
//|       - {"artifact":"moments","path":"/rows/4/3","range":{"max":1e-7}}
//|       - {"artifact":"nodes","path":"/rows/0/1","equals":2}
//|       - {"artifact":"nodes","path":"/rows/0/3","approx":{"value":1.9019237886466844,"atol":1e-4}}
//|   - case: circular
//|     expect:
//|       - {"artifact":"moments","path":"/rows/1/3","range":{"max":1e-12}}
//|       - {"artifact":"moments","path":"/rows/4/3","range":{"max":1e-12}}
//|       - {"artifact":"nodes","path":"/rows/0/1","equals":0}
//|       - {"artifact":"nodes","path":"/rows/0/3","equals":null}
//|   - case: helium-ion
//|     expect:
//|       - {"artifact":"moments","path":"/rows/1/1","approx":{"value":3.0,"rtol":1e-8}}
//|       - {"artifact":"moments","path":"/rows/3/1","approx":{"value":0.5,"rtol":1e-7}}
//|       - {"artifact":"nodes","path":"/rows/0/3","approx":{"value":1.0,"atol":1e-4}}
use scioxide_special::hydrogenic_radial;

// 入力は整数値の f64。API の量子数は u32 で渡す。
// l ≥ n は API が DomainError で拒むので、l = n − 1 に制限してから呼ぶ。
let n = n as u32;
let (l, z) = ((l as u32).min(n - 1), charge);
let (nf, lf) = (f64::from(n), f64::from(l));
let r_max = nf / z * (2.0 * nf + 40.0);
const INTERVALS: usize = 8000;
let h = r_max / INTERVALS as f64;
let mut radial = Vec::with_capacity(INTERVALS + 1);
for i in 0..=INTERVALS {
    let r = h * i as f64;
    radial.push((r, hydrogenic_radial(n, l, z, r).map_err(|e| e.to_string())?));
}
// 複合 Simpson 則（手計算の独立検算）。k は r の冪。
let moment = |k: i32| {
    let mut sum = 0.0;
    for (i, &(r, value)) in radial.iter().enumerate() {
        let weight = match i {
            0 | INTERVALS => 1.0,
            _ if i % 2 == 1 => 4.0,
            _ => 2.0,
        };
        // r^k · r² R² を、k < 0 でも原点で有限な形で作る。
        sum += weight * r.powi(k + 2) * value * value;
    }
    sum * h / 3.0
};
let quantities = [
    ("∫ P(r) dr [-]", moment(0), 1.0),
    (
        "⟨r⟩ [a₀]",
        moment(1),
        (3.0 * nf * nf - lf * (lf + 1.0)) / (2.0 * z),
    ),
    (
        "⟨r²⟩ [a₀²]",
        moment(2),
        nf * nf * (5.0 * nf * nf + 1.0 - 3.0 * lf * (lf + 1.0)) / (2.0 * z * z),
    ),
    ("⟨1/r⟩ [1/a₀]", moment(-1), z / (nf * nf)),
    (
        "⟨1/r²⟩ [1/a₀²]",
        moment(-2),
        z * z / (nf.powi(3) * (lf + 0.5)),
    ),
];
let rows: Vec<(&str, f64, f64, f64)> = quantities
    .iter()
    .map(|&(name, numeric, exact)| (name, numeric, exact, (numeric - exact).abs() / exact))
    .collect();
// 節: 原点を除き、R の符号が変わる区間を一次補間する。
let mut nodes = Vec::new();
for pair in radial[1..].windows(2) {
    let ((r0, v0), (r1, v1)) = (pair[0], pair[1]);
    if v0 * v1 < 0.0 {
        nodes.push(r0 - v0 * (r1 - r0) / (v1 - v0));
    }
}
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let sig10 = serde_json::json!({ "significantDigits": 10 });
let columns = serde_json::json!([
    { "key": "0", "label": "量" },
    { "key": "1", "label": "Simpson 則", "type": "number", "format": sig10 },
    { "key": "2", "label": "閉形式", "type": "number", "format": sig10 },
    { "key": "3", "label": "相対差 [-]", "type": "number", "format": sci3 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "moments" })
);
let node_rows: Vec<(String, usize, u32, Option<f64>)> = vec![(
    format!("{n},{l}"),
    nodes.len(),
    n - l - 1,
    nodes.first().copied(),
)];
let node_columns = serde_json::json!([
    { "key": "0", "label": "状態 (n, l)" },
    { "key": "1", "label": "数えた節 [個]", "type": "integer" },
    { "key": "2", "label": "n − l − 1 [個]", "type": "integer" },
    { "key": "3", "label": "最初の節 [a₀]", "type": "number", "format": sig10, "nullText": "節なし" }
]);
emit_table_with_columns!(
    node_columns,
    node_rows,
    metadata = serde_json::json!({ "id": "nodes" })
);
let points: Vec<[f64; 2]> = radial
    .iter()
    .step_by(10)
    .map(|&(r, value)| [r, r * r * value * value])
    .collect();
let mean = rows[1].2;
let mut marks =
    vec![serde_json::json!({ "kind": "line", "axis": "x", "value": mean, "label": "⟨r⟩" })];
for &node in &nodes {
    marks
        .push(serde_json::json!({ "kind": "line", "axis": "x", "value": node, "label": "節" }));
}
emit_line_chart!(
    &vec![serde_json::json!({ "name": "P(r) = r² R(r)²", "points": points })],
    options = &serde_json::json!({
        "xLabel": "動径 r [a₀]",
        "yLabel": "動径確率密度 P(r) [1/a₀]",
        "xMin": 0.0,
        "xMax": 2.5 * mean + 2.0 / z,
        "yMin": 0.0,
        "annotations": marks
    })
);
```

既定の $3s$（$n = 3$、$l = 0$、$Z = 1$）では、規格化と四つの期待値の相対差は $7 \times 10^{-9}$ 以下で、`hydrogenic_radial` の値が閉形式と合う。
この差は Simpson 則の打ち切り誤差 $O(h^4)$（刻み $h \approx 0.017\,a_0$）で、$l = 0$ では被積分関数の原点での 3 階導関数が 0 でないために残る。
$3d$ のように $l \ge 1$ では被積分関数が原点の近くで $r^{2l+2}$ のように平らになるので、相対差は $10^{-14}$ の丸めの水準まで下がる。
節は 2 個数えられる。
$3s$ の節の厳密な位置は $\rho^2 - 6\rho + 6 = 0$ の根 $\rho = 3 \mp \sqrt{3}$ から $r = (3 \mp \sqrt{3})\,n/(2Z) = 1.901924\ldots$、$7.098076\ldots$ で、表の最初の節 $1.901954$ は一次補間の誤差 $3 \times 10^{-5}$ の範囲で一致する。
$\langle r\rangle = 13.5\,a_0 \approx 714$ pm は、基底状態の $1.5\,a_0$ の 9 倍で、$n^2$ に比例する広がりを示す。

$3d$ に切り替えると節が消え、$\langle r\rangle = 10.5\,a_0$ と $3s$ より内側に一つの山が立つ。
$l$ が大きいほど遠心力の障壁 $l(l+1)/r^2$ が電子を原点から遠ざけるが、同時に外側の裾も短くなり、平均の半径は小さくなる。
He⁺ の $2s$ では、節の位置が水素の $2\,a_0$ から $1\,a_0$（表では $1.0000045$）へ、$\langle 1/r\rangle$ が $1/4$ から $1/2$ へと $Z$ 倍に変わる。
$r_{\max}$ と刻みは $n/Z$ に比例させてあるので、$Z$ を変えても相対差は変わらない。
$n = 6$ の $s$ 状態では刻みが $0.039\,a_0$ まで広がり、$\langle 1/r^2\rangle$ の相対差は $1.2 \times 10^{-7}$ まで増える。
相対差が $10^{-6}$ を超えるようなら、`hydrogenic_radial` を疑う前に、点の数を増やして Simpson 則の誤差が $h^4$ で減るかを確かめる。

## まとめ

`hydrogenic_radial` は Bohr 半径の単位の $r$ で規格化済みの $R_{nl}$ を返し、$l \ge n$ や $Z \le 0$ は `DomainError` で拒む。
動径確率密度 $r^2R_{nl}^2$ を数値積分すると、規格化と $\langle r^k\rangle$（$k = -2, -1, 1, 2$）の閉形式が数値積分の誤差の範囲で再現され、節の数は $n - l - 1$ になる。
長さは $1/Z$ 倍、平均の半径は $n^2$ に比例して変わるので、別の $Z$ や $n$ の値は単位の換算で見積もれる。
適応求積で期待値を求める方法は [scioxide-integrate の章](../../../scioxide-integrate/) で、正のエネルギーの Coulomb 散乱は [Coulomb 障壁の透過と Gamow 因子](../coulomb-barrier-penetration/) で確かめる。
