特殊関数は、波動方程式や Schrödinger 方程式を変数分離して解くとき、確率分布の累積を求めるとき、統計力学の分布を積分するときに現れる。
関数の値を求めるだけでは計算は終わらず、物理量を無次元の引数に直し、結果を閉形式、極限、保存則、別のアルゴリズムと比べて確かめる必要がある。
この節の例題はどれも具体的な題材とパラメータから関数を導き、scioxide-special で評価し、実装とは独立な方法で検算する。

## 例題に共通する手順

### 無次元の引数を作る

特殊関数の引数は無次元の量である。
次元を持つ変数は問題に固有の長さ、時間、エネルギー、温度で割ってから渡す。
円形開口では半径 $a$ と波数 $k$ から $x = ka\sin\theta$ を作り、単振り子では最大の振れ角 $\theta_0$ から母数 $m = \sin^2(\theta_0/2)$ を作る。
固体比熱では Debye 温度で $x_D = \Theta_D/T$ を作り、電子気体では $\mu/k_BT$ を未知数にし、$\theta = k_BT/E_F$ を入力にする。
無次元にすると、物理の尺度が変わっても同じ関数の値が使え、比熱の $C_V/3R$ のように物質によらない曲線が見える。

### 規約と規格化を照合する

同じ名前の関数でも、文献によって規格化や引数の規約が違う。
楕円積分は母数 $m = k^2$ を受け取り、Fermi–Dirac 積分は $1/\Gamma(j+1)$ で規格化し、Debye 関数は $D_n(0) = 1$ と規格化する。
文献の式を写すときは、まず既知の一点（$F_{1/2}(0)$、$D_3$ の大きな $x$ の漸近形など）で規約が合っていることを確かめる。

### 順問題と逆問題を往復する

分位点や化学ポテンシャルのような逆問題では、得た解を順方向の関数に戻して残差を見る。
往復の残差が小さいことは、逆関数と順方向の関数が整合していることを示すだけで、両者に共通する誤り（規格化の取り違えなど）は見つけられない。
確率の裾では密度が小さく、分位点の条件数（入力の相対誤差が出力の相対誤差に何倍で伝わるかの比）が大きいので、往復の残差が小さくても分位点の相対誤差は大きくなりうる。

### 極限と別のアルゴリズムで照合する

実装とは別の式やアルゴリズムの値と比べる。
小角で単振り子の周期比が $1 + \theta_0^2/16$ に近づくこと、低温で Debye 比熱が $T^3$ 則に近づくこと、低エネルギーで Coulomb 障壁の透過率のエネルギー依存性が Gamow 因子 $\exp(-2\pi\eta)$ に支配され、$s$ 波の $P_0\,e^{2\pi\eta}$ が一定に近づくことを確かめる。
Brent 法の数値解と Lambert W の閉形式、`debye_3` と `transport_4` の二通りの比熱のように、別のアルゴリズムの値も比べる。
どの検算も比べた値の誤差の上限を証明するものではない。
差を表に出し、その大きさが何に由来するか（打ち切り、丸め、条件数、モデルの近似）を本文で説明する。

## まとめ

例題は、題材の物理量から無次元の引数を作り、scioxide-special の関数で評価し、閉形式、極限、保存則、別のアルゴリズムのどれかで検算する、という同じ手順で進む。
自分の問題に当てはめるときは、まず関数の規約と規格化を既知の一点で照合し、次に極限の式との差が予想どおりの速さで減ることを確かめる。
逆問題では往復の残差だけで済ませず、極限や別のアルゴリズムの値とも比べる。
各関数の評価法と精度の保証は[特殊関数のアルゴリズム](../algorithms/)の各ページで、呼び出しの形とエラーの分類は[特殊関数の API ガイド](../api/)で確かめる。
