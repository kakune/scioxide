未知数が多項式と指数関数の両方に現れる方程式は、一般に初等関数の逆関数では解けない。
そのうち $x = a + b\,e^{cx}$ の形に直せるものは、Lambert W 関数 $W$（$W e^W = z$ の解）で閉じた形に書ける。
この例題では、黒体放射のスペクトルのピークを決める方程式と、直列抵抗を持つダイオードの電流の方程式をこの形に直し、`lambert_w0` で解く。
どちらの解も scioxide-rootfind の Brent 法で同じ方程式を直接解いた値と照合し、Wien の変位則は CODATA の定数とも照合する。

Lambert W 関数の枝、分岐点、評価法は [Lambert W 関数と Wright ω 関数](../../algorithms/lambert-w-and-wright-omega/) で説明している。

## Wien の変位則と超越方程式の厳密解

温度 $T$ の黒体が単位波長あたりに放射するエネルギー（分光放射輝度）は、Planck の法則で次のように書ける。

$$
B_\lambda(\lambda, T) = \frac{2 h c^2}{\lambda^5}\,\frac{1}{e^{hc/(\lambda k_B T)} - 1}
$$

$h$ は Planck 定数、$c$ は真空中の光速、$k_B$ は Boltzmann 定数である。
無次元の量 $x = hc/(\lambda k_B T)$ を使うと、$B_\lambda$ は $T$ を固定したとき $x^5/(e^x - 1)$ に比例する。
これを $x$ で微分して 0 とおくと、次の方程式になる。

$$
\frac{d}{dx}\,\frac{x^n}{e^x - 1} = 0 \quad\Longleftrightarrow\quad x = n\,(1 - e^{-x})
$$

波長あたりのエネルギーでは $n = 5$ である。
同じ形の方程式は、周波数あたりのエネルギー $B_\nu \propto x^3/(e^x - 1)$ で $n = 3$、波長あたりの光子数で $n = 4$、周波数あたりの光子数で $n = 2$ になる。
ピークの位置はスペクトルを何あたりの密度で表すかによって変わる。

### Lambert W の形への変換

$x = n(1 - e^{-x})$ で $w = x - n$ とおくと、$w = -n e^{-x} = -n e^{-n} e^{-w}$ なので、次の形になる。

$$
w\,e^{w} = -n\,e^{-n}
$$

右辺の $-n e^{-n}$ は $n \ge 2$ で $(-1/e, 0)$ にあるので、実数解が二つある。
$W_{-1}$ の側の解は $w = -n$、つまり $x = 0$ で、これは自明な解である。
ピークを与えるのは主枝の解で、次の閉じた形になる。

$$
x_n = n + W_0\!\left(-n\,e^{-n}\right)
$$

$n = 5$ の $x_5 = 4.965114231744276\ldots$ から、ピーク波長と温度の積は定数になる。

$$
\lambda_{\max} T = \frac{hc}{k_B\,x_5} = b
$$

これが Wien の変位則で、$b$ を Wien の変位則定数と呼ぶ。
2019 年の SI 改定で $h$、$c$、$k_B$ は定義値になったので、$b$ は計算で決まる。
CODATA 2018（Tiesinga ほか 2021）の値は $b = 2.897\,771\,955 \times 10^{-3}\ \mathrm{m\,K}$ で、周波数のピークの定数（$n = 3$）は $b' = k_B x_3/h = 5.878\,925\,757 \times 10^{10}\ \mathrm{Hz\,K^{-1}}$ である。

### ピークの位置の計算と照合

次のセルは $n = 2, 3, 4, 5$ について $x_n = n + W_0(-n e^{-n})$ を `lambert_w0` で求める。
独立な検算として、同じ方程式 $g(x) = x - n(1 - e^{-x}) = 0$ を、scioxide-rootfind の Brent 法で区間 $[n - 1, n]$ から解く。
$g(n - 1) = n e^{1-n} - 1 < 0$、$g(n) = n e^{-n} > 0$ なので、この区間は自明な解 $x = 0$ を含まずにピークの解だけを挟む。
二つ目の表は入力の温度 $T$ でのピークの位置を波長と周波数で示す。
既定の $T = 5772\ \mathrm{K}$ は、IAU 2015 の決議 B3 が定めた太陽の有効温度の公称値である。

```rust
//| id: special-lambert-wien-diode
//| ref: special-lambert-wien-diode
//| title: Wien の変位則の根と Brent 法による照合
//| run: reactive
//| uses: [special-lambert-si-constants]
//| crates: [scioxide-special, scioxide-rootfind, scioxide-core]
//| inputs:
//|   temperature: {"type":"range","label":"温度 T [K]","description":"ピークの波長と周波数を求める温度。5772 K は太陽の有効温度、2.7255 K は宇宙マイクロ波背景放射。","min":2.7255,"max":10000,"step":0.0005,"value":5772}
//| cases:
//|   - {"id":"cmb","label":"T = 2.7255 K","description":"宇宙マイクロ波背景放射。ピークはミリ波に移る。","inputs":{"temperature":2.7255}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"roots","path":"/rows/3/2","approx":{"value":4.965114231744276,"rtol":1e-15}}
//|       - {"artifact":"roots","path":"/rows/3/4","range":{"max":1e-15}}
//|       - {"artifact":"roots","path":"/rows/1/4","range":{"max":1e-15}}
//|       - {"artifact":"roots","path":"/rows/3/6","equals":"ResidualTolerance"}
//|       - {"artifact":"peaks","path":"/rows/3/2","approx":{"value":2897.771955,"rtol":1e-9}}
//|       - {"artifact":"peaks","path":"/rows/1/3","approx":{"value":58.78925757,"rtol":1e-9}}
//|       - {"artifact":"peaks","path":"/rows/3/4","approx":{"value":0.502038,"rtol":1e-5}}
//|   - case: cmb
//|     expect:
//|       - {"artifact":"peaks","path":"/rows/3/4","approx":{"value":1063.2,"rtol":1e-4}}
use scioxide_core::{Interval, RealScalar};
use scioxide_rootfind::{Brent, ScalarFn, ScalarRootOptions, ScalarRootSolver};
use scioxide_special::lambert_w0;

let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let sig16 = serde_json::json!({ "significantDigits": 16 });
let sig10 = serde_json::json!({ "significantDigits": 10 });
let forms = [
    (2_u32, "光子数・周波数あたり"),
    (3, "エネルギー・周波数あたり"),
    (4, "光子数・波長あたり"),
    (5, "エネルギー・波長あたり"),
];
let mut roots = Vec::new();
let mut peaks = Vec::new();
for (n, name) in forms {
    let n_real = f64::from(n);
    // 閉じた形 x_n = n + W₀(−n e^{−n})。
    let closed =
        n_real + lambert_w0(-n_real * RealScalar::exp(-n_real)).map_err(|e| e.to_string())?;
    // 独立な検算: g(x) = x − n(1 − e^{−x}) を [n − 1, n] で Brent 法により解く。
    let g = ScalarFn::new(move |x: f64| Ok(x - n_real * (1.0 - RealScalar::exp(-x))));
    let bracket = Interval::new(n_real - 1.0, n_real).map_err(|e| e.to_string())?;
    let solved = Brent
        .solve(&g, bracket, &ScalarRootOptions::default())
        .map_err(|e| e.to_string())?;
    let brent = solved.point();
    roots.push((
        n,
        name,
        closed,
        brent,
        (closed - brent).abs() / closed,
        solved.iterations(),
        format!("{:?}", solved.termination()),
    ));
    // hc/(k x) [μm K] と k x/h [GHz/K]、温度 T でのピークの波長 [μm] と周波数 [THz]。
    let wavelength_constant = PLANCK * LIGHT_SPEED / (BOLTZMANN * closed) * 1e6;
    let frequency_constant = BOLTZMANN * closed / PLANCK * 1e-9;
    peaks.push((
        n,
        name,
        wavelength_constant,
        frequency_constant,
        wavelength_constant / temperature,
        frequency_constant * temperature * 1e-3,
    ));
}

    { "key": "0", "label": "n", "type": "integer" },
    { "key": "1", "label": "スペクトルの表し方" },
    { "key": "2", "label": "x（W₀）[-]", "type": "number", "format": sig16 },
    { "key": "3", "label": "x（Brent 法）[-]", "type": "number", "format": sig16 },
    { "key": "4", "label": "相対差 [-]", "type": "number", "format": sci3 },
    { "key": "5", "label": "Brent 法の反復", "type": "integer" },
    { "key": "6", "label": "終了状態" }
]);
emit_table_with_columns!(
    root_columns,
    roots,
    metadata = serde_json::json!({ "id": "roots" })
);
let peak_columns = serde_json::json!([
    { "key": "0", "label": "n", "type": "integer" },
    { "key": "1", "label": "スペクトルの表し方" },
    { "key": "2", "label": "hc/(k x) [μm·K]", "type": "number", "format": sig10 },
    { "key": "3", "label": "k x/h [GHz/K]", "type": "number", "format": sig10 },
    { "key": "4", "label": "ピークの波長 [μm]", "type": "number", "format": { "significantDigits": 6 } },
    { "key": "5", "label": "ピークの周波数 [THz]", "type": "number", "format": { "significantDigits": 6 } }
]);
emit_table_with_columns!(
    peak_columns,
    peaks,
    metadata = serde_json::json!({ "id": "peaks" })
);
```

一つ目の表では、四つの $n$ のどれでも、閉じた形の $x_n$ と Brent 法の解の相対差が $1.8 \times 10^{-16}$ 以下で、倍精度の丸めの大きさで一致する。
Brent 法は 4〜6 回の反復で、返した点の残差が許容値を満たしたことを示す終了状態 `ResidualTolerance` で止まる。
$n = 5$ の $x_5 = 4.965114231744276$ から求めた $hc/(k_B x_5) = 2897.771955\ \mu\mathrm{m\,K}$ は CODATA の $b$ と 10 桁一致する。
$n = 3$ の $k_B x_3/h = 58.789257576\ \mathrm{GHz/K}$ も、CODATA が示す $b'$ の 10 桁 $5.878\,925\,757 \times 10^{10}\ \mathrm{Hz\,K^{-1}}$ と一致する。

二つ目の表では、既定の $T = 5772\ \mathrm{K}$ で、波長あたりのエネルギーのピークは $0.50204\ \mu\mathrm{m}$（緑）にある。
一方、周波数あたりのエネルギーのピークは $339.3\ \mathrm{THz}$ で、波長に直すと $0.8835\ \mu\mathrm{m}$（近赤外）になる。
二つのピークが違うのは誤りではなく、$B_\lambda\,d\lambda = B_\nu\,d\nu$ の換算に $d\nu/d\lambda = -c/\lambda^2$ が入り、密度の形が変わるからである。
ケース cmb（$T = 2.7255\ \mathrm{K}$、Fixsen 2009 による宇宙マイクロ波背景放射の温度）では、波長のピークは $1.063\ \mathrm{mm}$、周波数のピークは $160.2\ \mathrm{GHz}$ になる。
$x_n$ は温度によらないので、温度を変えても一つ目の表は変わらず、ピークの周波数は $T$ に比例し、ピークの波長は $T$ に反比例して動く。

## 直列抵抗を持つダイオードの電流

半導体ダイオードの電流 $I$ と接合にかかる電圧 $V_D$ は、Shockley の式 $I = I_s\,[e^{V_D/(n V_T)} - 1]$ に従う。
$I_s$ は飽和電流、$n$ は理想係数、$V_T = k_B T/e$ は熱電圧（$T = 300\ \mathrm{K}$ で $25.85\ \mathrm{mV}$）である。
実際の素子には電極や半導体の抵抗が直列に入るので、端子に電圧 $V$ をかけると $V_D = V - I R_s$ になり、電流は次の方程式を満たす。

$$
I = I_s\left[\exp\!\left(\frac{V - I R_s}{n V_T}\right) - 1\right]
$$

$I$ が指数の肩と左辺の両方に現れるので、$V$ から $I$ を初等関数で求めることはできない。

### Lambert W の形への変換

両辺に $I_s$ を加え、$y = (I + I_s) R_s/(n V_T)$ とおく。
$V - I R_s = (V + I_s R_s) - (I + I_s) R_s$ を使うと、方程式は次の形になる。

$$
y\,e^{y} = \frac{I_s R_s}{n V_T}\exp\!\left(\frac{V + I_s R_s}{n V_T}\right)
$$

右辺は正なので、$W_0$ を当てはめて電流が閉じた形で求まる。

$$
I(V) = \frac{n V_T}{R_s}\,W_0\!\left[\frac{I_s R_s}{n V_T}\exp\!\left(\frac{V + I_s R_s}{n V_T}\right)\right] - I_s
$$

$V$ が大きいと、右辺の引数の指数が倍精度の範囲を超える（指数の肩がおよそ 709.8 を超えるとき）。
引数の対数 $\ell = \ln(I_s R_s/(n V_T)) + (V + I_s R_s)/(n V_T)$ を使えば、$W_0(e^\ell) = \omega(\ell)$ なので、Wright ω 関数で同じ値をあふれずに求められる。

$R_s \to 0$ ではこの式は Shockley の式に戻る。
大電流では、接合の電圧 $V_D = n V_T \ln(I/I_s + 1)$ が $I$ の対数でしか増えないので、$I = (V - V_D)/R_s$ はほぼ $V/R_s$ に比例し、抵抗が電流を決める。
片対数のグラフでは、小電流の側は Shockley の式の直線に沿い、大電流の側で直線から下に曲がる。

### 電流の計算と照合

次のセルは例として選んだ $I_s = 2.5\ \mathrm{nA}$、$n = 1.8$、$T = 300\ \mathrm{K}$（特定の素子の値ではない）の素子で、入力の $R_s$ と電圧 $V$ での電流を三つの方法で求める。
一つ目は上の閉じた形の `lambert_w0`、二つ目は Wright ω を使う `wright_omega`、三つ目は scioxide-rootfind の Brent 法である。
Brent 法は方程式を対数の形 $h(I) = \ln(I/I_s + 1) - (V - I R_s)/(n V_T) = 0$ に直して区間 $[0, V/R_s]$ で解く。
$h$ は $I$ について単調に増え、$h(0) < 0$、$h(V/R_s) > 0$ なので、区間は解を一つだけ挟み、指数があふれることもない。
表の最後の行の $V = 40\ \mathrm{V}$ は、`lambert_w0` の引数があふれる例である。
図は $V = 0.05$〜$1.19\ \mathrm{V}$ の電流を片対数で描き、破線は $R_s = 0$ の Shockley の式である。

```rust
//| id: special-lambert-diode-series-resistance
//| ref: special-lambert-diode-series-resistance
//| title: 直列抵抗を持つダイオードの電流
//| run: reactive
//| uses: [special-lambert-si-constants]
//| crates: [scioxide-special, scioxide-rootfind, scioxide-core]
//| inputs:
//|   series_resistance: {"type":"range","label":"直列抵抗 R_s [Ω]","description":"大きいほど、大電流の側で電流が抵抗で制限される。","min":0.05,"max":10,"step":0.05,"value":0.5}
//|   voltage: {"type":"range","label":"端子電圧 V [V]","description":"表の 2 行目と図の縦線の位置。","min":0.3,"max":1.2,"step":0.01,"value":0.8}
//| cases:
//|   - {"id":"large-resistance","label":"R_s = 10 Ω","description":"抵抗が電流を決める範囲が低い電圧から始まる。","inputs":{"series_resistance":10}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"currents","path":"/rows/1/4","range":{"max":1e-14}}
//|       - {"artifact":"currents","path":"/rows/1/5","range":{"max":1e-14}}
//|       - {"artifact":"currents","path":"/rows/4/1","equals":null}
//|       - {"artifact":"currents","path":"/rows/4/5","range":{"max":1e-14}}
//|   - case: large-resistance
//|     expect:
//|       - {"artifact":"currents","path":"/rows/1/5","range":{"max":1e-14}}
//|       - {"artifact":"currents","path":"/rows/4/5","range":{"max":1e-14}}
use scioxide_core::{Interval, RealScalar};
use scioxide_rootfind::{Brent, ScalarFn, ScalarRootOptions, ScalarRootSolver};
use scioxide_special::{lambert_w0, wright_omega};

let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let sig10 = serde_json::json!({ "significantDigits": 10 });
let saturation = 2.5e-9; // I_s [A]
let ideality = 1.8; // n [-]
let thermal = ideality * BOLTZMANN * 300.0 / ELEMENTARY_CHARGE; // n V_T [V]
let rs = series_resistance;
// 閉じた形の W₀ の引数の対数 ℓ。e^ℓ が範囲外でも ℓ は有限である。
let log_argument =
    |v: f64| RealScalar::ln(saturation * rs / thermal) + (v + saturation * rs) / thermal;
let current_w0 = |v: f64| {
    lambert_w0(RealScalar::exp(log_argument(v)))
        .ok()
        .map(|w| thermal / rs * w - saturation)
};
let current_omega = |v: f64| {
    wright_omega(log_argument(v))
        .map(|w| thermal / rs * w - saturation)
        .map_err(|e| e.to_string())
};

let mut rows = Vec::new();
for v in [0.4, voltage, 1.0, 2.0, 40.0] {
    let by_omega = current_omega(v)?;
    // 独立な検算: h(I) = ln(I/I_s + 1) − (V − I R_s)/(n V_T) を [0, V/R_s] で解く。
    let h = ScalarFn::new(move |i: f64| {
        Ok(RealScalar::ln_1p(i / saturation) - (v - i * rs) / thermal)
    });
    let bracket = Interval::new(0.0, v / rs).map_err(|e| e.to_string())?;
    let solved = Brent
        .solve(&h, bracket, &ScalarRootOptions::default())
        .map_err(|e| e.to_string())?;
    let by_brent = solved.point();
    let by_w0 = current_w0(v);
    rows.push((
        v,
        by_w0,
        by_omega,
        by_brent,
        by_w0.map(|i| (i - by_brent).abs() / by_brent),
        (by_omega - by_brent).abs() / by_brent,
        by_omega * rs,
    ));
}
let columns = serde_json::json!([
    { "key": "0", "label": "V [V]", "type": "number", "format": { "significantDigits": 3 } },
    { "key": "1", "label": "I（W₀）[A]", "type": "number", "format": sig10, "nullText": "引数が範囲外" },
    { "key": "2", "label": "I（ω）[A]", "type": "number", "format": sig10 },
    { "key": "3", "label": "I（Brent 法）[A]", "type": "number", "format": sig10 },
    { "key": "4", "label": "W₀ と Brent の相対差 [-]", "type": "number", "format": sci3, "nullText": "-" },
    { "key": "5", "label": "ω と Brent の相対差 [-]", "type": "number", "format": sci3 },
    { "key": "6", "label": "抵抗での電圧降下 I R_s [V]", "type": "number", "format": sig10 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "currents" })
);

let mut with_resistance = Vec::new();
let mut ideal = Vec::new();
for k in 1..=115 {
    let v = 0.05 + 0.01 * (k - 1) as f64;
    with_resistance.push([v, current_omega(v)?]);
    // R_s = 0 の Shockley の式（参照曲線）。
    ideal.push([v, saturation * RealScalar::exp_m1(v / thermal)]);
}
emit_line_chart!(
    &vec![
        serde_json::json!({ "name": "直列抵抗あり", "points": with_resistance }),
        serde_json::json!({
            "name": "R_s = 0（Shockley の式）",
            "points": ideal,
            "style": { "lineType": "dashed" }
        })
    ],
    options = &serde_json::json!({
        "xLabel": "端子電圧 V [V]",
        "yLabel": "電流 I [A]",
        "yType": "log",
        "xMin": 0.05,
        "xMax": 1.2,
        "yMin": 1e-9,
        "yMax": 100.0,
        "annotations": [{ "kind": "line", "axis": "x", "value": voltage, "label": "選んだ V" }]
    })
);
```

既定の $R_s = 0.5\ \Omega$ では、三つの方法の相対差がどの電圧でも $1.4 \times 10^{-15}$ 以下である。
$V = 0.4\ \mathrm{V}$ の電流は $13.5\ \mu\mathrm{A}$ で、抵抗での電圧降下は $6.8\ \mu\mathrm{V}$ と小さく、Shockley の式とほぼ同じ値になる。
$V = 0.8\ \mathrm{V}$ では $45.1\ \mathrm{mA}$、降下は $22.5\ \mathrm{mV}$ で、$2\ \mathrm{V}$ では $2.09\ \mathrm{A}$ のうち端子電圧の半分を超える $1.04\ \mathrm{V}$ が抵抗にかかる。
$V = 40\ \mathrm{V}$ では `lambert_w0` の引数 $e^\ell$ が範囲外になって空欄になるが、Wright ω と Brent 法はどちらも $77.75\ \mathrm{A}$ を返し、接合の電圧は $40 - 38.88 = 1.12\ \mathrm{V}$ にとどまる。

図の破線（Shockley の式）は片対数で直線になり、直列抵抗のある曲線は電流がおよそ $n V_T/R_s$ を超えたあたりから下へ離れる。
既定の $R_s = 0.5\ \Omega$ ではこの目安は $93\ \mathrm{mA}$ で、ケース large-resistance（$R_s = 10\ \Omega$）では $4.7\ \mathrm{mA}$ に下がり、$V = 0.8\ \mathrm{V}$ の電流は $9.50\ \mathrm{mA}$ に減る。
閉じた形と Brent 法の一致は、変形 $y\,e^y = \ldots$ に誤りがないことの検算であり、どちらの値も同じ物理モデルの解である。
実際の素子の特性と比べるには、$I_s$、$n$、$R_s$ を測定から決める必要がある。

## まとめ

$x = a + b\,e^{cx}$ の形の方程式は、未知数をずらして $w e^w = z$ に直すと、`lambert_w0` で閉じた形の解になる。
二つの実数解があるときは、どちらが求める解かを枝で選び、Wien の変位則では自明な解 $x = 0$ が $W_{-1}$ の側、ピークが $W_0$ の側にある。
閉じた形の値は同じ方程式を Brent 法で区間から解いた値と丸めの大きさで一致し、$n = 5$ と $n = 3$ の定数は CODATA の $b$ と $b'$ を再現する。
ダイオードの式のように $W_0$ の引数が指数であふれるときは、引数の対数を `wright_omega` に渡すと、大電流でも同じ値を求められる。

Lambert W 関数の分岐点の近くの条件数と端点の規約は [Lambert W 関数と Wright ω 関数](../../algorithms/lambert-w-and-wright-omega/) で確かめる。
黒体放射の帯域の割合を求積で求める計算は、[黒体放射の Stefan–Boltzmann 定数と帯域率](../../../scioxide-integrate/examples/blackbody-radiation/) で確かめる。
次の例題 [Paul トラップの安定領域と Mathieu 関数](../paul-trap-stability/) では、周期的な係数を持つ方程式の安定性を Mathieu 関数の特性値から判定する。
