四重極の電極に直流電圧と高周波電圧を加えると、電場が軸からの距離に比例する復元力と押し出す力を交互に与え、条件によってはイオンを軸の近くに閉じ込められる。
これが Paul トラップ（高周波イオントラップ）の原理で、線形 Paul トラップや四重極質量分析計（質量フィルター）の基礎である（Paul 1990）。
イオンの運動方程式は無次元化すると Mathieu 方程式になり、運動が有界にとどまるかどうかは 2 つのパラメータ $(q, a)$ だけで決まる。
この例題では、`scioxide-special` の Mathieu の特性値 $a_r(q)$、$b_r(q)$ で安定図を描き、第一安定領域の頂点を求めて、1 周期の数値積分による Floquet の判定で確かめる。
特性値の計アルゴリズムは [Mathieu 関数とスペクトル法](../../algorithms/mathieu-and-spheroidal/)で説明している。

## 四重極の電場と Mathieu 方程式

軸を $z$ 方向にとった 4 本の電極に、直流電圧 $U$ [V] と振幅 $V$ [V]、角周波数 $\Omega$ [rad/s] の高周波電圧を加えると、軸の近くの電位は

$$
\Phi(x, y, t) = \frac{U + V\cos\Omega t}{2r_0^2}\,(x^2 - y^2)
$$

で近似できる。
$r_0$ [m] は軸から電極までの距離である。
電荷 $e$、質量 $m$ のイオンの運動方程式は $m\ddot x = -e\,\partial_x\Phi$、$m\ddot y = -e\,\partial_y\Phi$ で、$x$ と $y$ が分離する。
無次元の時刻 $\tau = \Omega t/2$ を使い、高周波の位相の原点を半周期ずらすと、

$$
\frac{d^2u}{d\tau^2} + (a_u - 2q_u\cos 2\tau)\,u = 0,\qquad
a_x = -a_y = \frac{4eU}{mr_0^2\Omega^2},\qquad
q_x = -q_y = \frac{2eV}{mr_0^2\Omega^2}
$$

となる（$u = x, y$）。
これは Mathieu 方程式そのもので、以下では $a = a_x$、$q = q_x \ge 0$ と書く。
$z$ 方向には力が働かないので、閉じ込めは $x$ と $y$ の 2 方向の問題である。

## Floquet の定理と安定性

Mathieu 方程式の係数は周期 $\pi$ を持つ。
初期値 $(u, u') = (1, 0)$ と $(0, 1)$ から出発する 2 つの解 $u_1$、$u_2$ を 1 周期進める写像（モノドロミー行列）の跡を

$$
\Delta(a, q) = u_1(\pi) + u_2'(\pi)
$$

とすると、行列式は 1（Wronskian の保存）なので固有値は $\lambda^2 - \Delta\lambda + 1 = 0$ の根である。
$|\Delta| < 2$ なら固有値は単位円上の共役な対 $e^{\pm i\pi\nu}$ で、解はすべて有界（安定）である。
$|\Delta| > 2$ なら一方の固有値の絶対値が 1 を超え、解は周期ごとに指数的に増える（不安定）。
$\nu$ は特性指数で、$\cos\pi\nu = \Delta/2$ から求まる。

境界 $|\Delta| = 2$ では周期 $\pi$ または $2\pi$ の解があり、そこでの $a$ が特性値 $a_r(q)$、$b_r(q)$ である。
$q > 0$ では特性値が $a_0 < b_1 < a_1 < b_2 < a_2 < \cdots$ の順に並び、$x$ 方向の運動が安定な $a$ は

$$
a_0(q) < a < b_1(q),\qquad a_1(q) < a < b_2(q),\qquad a_2(q) < a < b_3(q),\ \dots
$$

の区間である。
$-q$ の方程式は $\tau$ を $\pi/2$ ずらすと $q$ の方程式に戻るので、安定性は $|q|$ だけで決まる。
したがって $y$ 方向（$a_y = -a$、$q_y = -q$）は、$-a$ が上の区間のどれかに入るとき安定である。
イオンが閉じ込められるのは、$x$ と $y$ の両方が安定なときである。

## 第一安定領域と頂点

原点に接する第一安定領域は、$a_0(q) < a < b_1(q)$ と $a_0(q) < -a < b_1(q)$ の共通部分である。
$a \ge 0$ の側では、上の境界は $b_1(q)$ と $-a_0(q)$ の小さいほうで、二つが交わる点が領域の頂点になる。
小さい $q$ では級数 $a_0(q) = -q^2/2 + O(q^4)$、$b_1(q) = 1 - q - q^2/8 + O(q^3)$（DLMF 28.6.1、28.6.3）から境界の形がわかるが、頂点の付近では $q$ が 0.7 に近く、級数の打ち切りは使えない。
頂点の座標 $(q, a) \approx (0.706, 0.237)$ は四重極質量分析の文献で広く使われる値で、次のセルでは $b_1(q) + a_0(q) = 0$ を特性値から解いて再現する。

質量フィルターでは、$U/V$ の比を一定にして電圧を掃引する。
すると $a/q = 2U/V$ が一定になり、どの質量のイオンも $(q, a)$ 平面で原点を通る同じ直線（走査線）の上にのる。
走査線が頂点のすぐ下を通るように $U/V$ を選ぶと、安定領域を通過する $q$ の幅が狭くなり、狭い質量の範囲のイオンだけが通り抜ける。
頂点を通る走査線の傾きは $a/q \approx 0.336$、すなわち $U/V \approx 0.168$ である。

## 安定図と頂点の計算

次のセルは、$q \in [0, q_{\max}]$ と $a \in [-a_{\max}, a_{\max}]$ の格子の各点で、$x$ と $y$ のどちらが安定かを判定する。
各 $q$ で `mathieu_a` と `mathieu_b` から $a_0, b_1, \dots, a_3, b_4$ を求め、$a$ と $-a$ が安定な区間に入るかを数える。
heatmap の値は安定な方向の数で、2 が閉じ込め、1 が一方向だけの安定、0 が両方向とも不安定である。
第一安定領域の頂点は $b_1(q) + a_0(q)$ の符号の変化を $q \in [0.5, 0.9]$ の二分法で追って求める（各点の値は `scioxide-special` の特性値）。
表は頂点の座標、走査線の傾き、質量 $M$ [u] のイオンを $r_0$ = 4 mm、$\Omega/2\pi$ = 1 MHz の質量フィルターで頂点に置く電圧と、$q \to 0$ で $a_r, b_r \to r^2$ になることの検算を示す。

```rust
//| id: special-paul-trap-mathieu-stability
//| ref: special-paul-trap-mathieu-stability
//| title: Paul トラップの安定図と第一安定領域の頂点
//| run: reactive
//| crates: [scioxide-special]
//| inputs:
//|   q_max: {"type":"range","label":"q の上限","min":1,"max":8,"step":0.5,"value":2}
//|   a_max: {"type":"range","label":"|a| の上限","min":0.5,"max":8,"step":0.5,"value":1.5}
//|   mass: {"type":"range","label":"イオンの質量 M [u]","min":10,"max":500,"step":10,"value":100}
//| cases:
//|   - {"id":"wide","label":"q ≤ 8、|a| ≤ 8","description":"一方向だけ安定な帯が高い a まで続き、両方向が安定な点はごくわずかになる。","inputs":{"q_max":8,"a_max":8}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"apex","path":"/rows/0/1","approx":{"value":0.706,"atol":5e-4}}
//|       - {"artifact":"apex","path":"/rows/1/1","approx":{"value":0.237,"atol":5e-4}}
//|       - {"artifact":"apex","path":"/rows/0/1","approx":{"value":0.7059960697133707,"rtol":1e-9}}
//|       - {"artifact":"apex","path":"/rows/6/1","approx":{"value":-8.333333312293689e-8,"rtol":1e-6}}
//|   - case: wide
//|     expect:
//|       - {"artifact":"apex","path":"/rows/1/1","approx":{"value":0.23699399311247382,"rtol":1e-9}}
use scioxide_special::{mathieu_a, mathieu_b};

// q での特性値 [a₀, b₁, a₁, b₂, a₂, b₃, a₃, b₄]（|a| ≤ 8 の範囲の帯をすべて含む）
let characteristic = |q: f64| -> Result<[f64; 8], String> {
    let a = |r| mathieu_a(r, q).map_err(|e| e.to_string());
    let b = |r| mathieu_b(r, q).map_err(|e| e.to_string());
    Ok([a(0)?, b(1)?, a(1)?, b(2)?, a(2)?, b(3)?, a(3)?, b(4)?])
};
// 安定な区間 (a_r, b_{r+1}) のどれかに入るか
let stable = |c: &[f64; 8], value: f64| c.chunks(2).any(|w| w[0] < value && value < w[1]);
let mut map = Vec::new();
for i in 0..=80 {
    let q = q_max * f64::from(i) / 80.0;
    let c = characteristic(q)?;
    for j in 0..=80 {
        let a = a_max * (2.0 * f64::from(j) / 80.0 - 1.0);
        let count = u8::from(stable(&c, a)) + u8::from(stable(&c, -a));
        map.push([q, a, f64::from(count)]);
    }
}
emit_chart!(serde_json::json!({
    "kind": "heatmap",
    "data": map,
    "xLabel": "高周波のパラメータ q [-]",
    "yLabel": "直流のパラメータ a [-]",
    "title": "安定な方向の数（2 で閉じ込め）",
    "colorMin": 0.0,
    "colorMax": 2.0,
    "tooltip": true
}));

// 頂点: b₁(q) + a₀(q) = 0 を二分法で解く
let gap = |q: f64| -> Result<f64, String> {
    let c = characteristic(q)?;
    Ok(c[1] + c[0])
};
let (mut low, mut high) = (0.5, 0.9);
for _ in 0..50 {
    let middle = 0.5 * (low + high);
    if gap(middle)? > 0.0 {
        low = middle;
    } else {
        high = middle;
    }
}
let q_apex = 0.5 * (low + high);
let a_apex = mathieu_b(1, q_apex).map_err(|e| e.to_string())?;
// 質量フィルター（r₀ = 4 mm、Ω/2π = 1 MHz）で頂点に置く電圧
let (charge, unit_mass) = (1.602176634e-19, 1.66053906660e-27);
let omega = 2.0 * std::f64::consts::PI * 1.0e6;
let scale = mass * unit_mass * 4.0e-3_f64.powi(2) * omega * omega / charge;
let rows = vec![
    ("頂点の q", q_apex, Some(0.706)),
    ("頂点の a", a_apex, Some(0.237)),
    ("走査線の傾き a/q", a_apex / q_apex, None),
    ("高周波の振幅 V [V]", q_apex * scale / 2.0, None),
    ("直流電圧 U [V]", a_apex * scale / 4.0, None),
    (
        "a₁(10⁻³) − 1",
        mathieu_a(1, 1e-3).map_err(|e| e.to_string())? - 1.0,
        Some(1e-3),
    ),
    (
        "b₂(10⁻³) − 4",
        mathieu_b(2, 1e-3).map_err(|e| e.to_string())? - 4.0,
        Some(-1e-6 / 12.0),
    ),
];
let fixed6 = serde_json::json!({ "significantDigits": 6 });
let columns = serde_json::json!([
    { "key": "0", "label": "量" },
    { "key": "1", "label": "計算値", "type": "number", "format": fixed6 },
    { "key": "2", "label": "文献値・級数の主要項", "type": "number", "format": fixed6, "nullText": "—" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "apex" })
);
```

heatmap では、値 2（閉じ込め）の領域が原点から $q \approx 0.91$ まで $a = 0$ の線に沿って伸び、上下が $a = \pm 0.237$ の頂点でとがる三角形に近い形になる。
$a = 0$ の線では $q$ が 0.908 を超えると $b_1(q) < 0$ となって $x$ 方向が不安定になり、値が 0 に落ちる。
値 1 の帯は一方向だけが安定な領域で、$x$ の帯は $a > 0$ の側、$y$ の帯は $a < 0$ の側に、特性値の曲線に沿って斜めに伸びる。
$q, |a| \le 8$ に広げると、一方向だけ安定な帯は高い $a$ まで続くが、両方向が安定な点は格子の 6561 点のうち 13 点しかない。
第二以降の閉じ込めの領域はこの格子では解像できないほど細い。

表の頂点は $(q, a) = (0.705996, 0.236994)$ で、文献でよく使われる $(0.706, 0.237)$ と表示の桁で一致する。
走査線の傾きは $a/q = 0.3357$ で、$U/V = 0.168$ にあたる。
質量 100 u のイオンを $r_0$ = 4 mm、1 MHz の質量フィルターで頂点に置くには、$V \approx 231$ V、$U \approx 38.8$ V が要る。
$V$ と $U$ は質量に比例するので、比を保って電圧を掃引すると、質量の順にイオンが頂点を通過する。
$q = 10^{-3}$ の特性値は、$a_1 - 1 = 0.00099987$（主要項 $q$ との差は $-q^2/8$）、$b_2 - 4 = -8.3333 \times 10^{-8}$（主要項 $-q^2/12$）で、$q \to 0$ で $r^2$ に近づく。


## Floquet の判定による確認

安定図は特性値の順序に頼っているので、別の方法で確かめる。
次のセルは、選んだ $(q, a)$ で Mathieu 方程式を古典的な 4 次の Runge–Kutta 法で 1 周期 $[0, \pi]$ 積分し、モノドロミー行列の跡 $\Delta$ を求める。
この積分はセルの中で手で書いた独立な検算で、`scioxide-special` を使わない。
同じ点を特性値の区間でも判定し、二つの判定が一致するかを表で示す。
安定なら特性指数 $\nu = \arccos(\Delta/2)/\pi$ を求め、小さい $a$、$q$ での近似 $\nu \approx \sqrt{a + q^2/2}$（Dehmelt の近似）と比べる。
$\nu$ はイオンの永年運動（高周波より遅いゆっくりした振動）の角周波数 $\omega = \nu\Omega/2$ を与える。
グラフは $x(\tau)$ を 10 周期積分した軌道で、安定なら振幅が有界にとどまり、不安定なら指数的に増える。
ODE の汎用の積分法は `scioxide-ode` の章で扱う。

```rust
//| id: special-paul-trap-floquet
//| ref: special-paul-trap-floquet
//| title: 1 周期の積分による Floquet の判定と特性値の区間の比較
//| run: reactive
//| crates: [scioxide-special]
//| inputs:
//|   q: {"type":"range","label":"q","min":0,"max":1.2,"step":0.01,"value":0.4}
//|   a: {"type":"range","label":"a","min":-0.5,"max":0.5,"step":0.01,"value":0.05}
//| cases:
//|   - {"id":"near-apex","label":"q = 0.70、a = 0.23","description":"頂点のすぐ内側で x と y の両方が安定。","inputs":{"q":0.7,"a":0.23}}
//|   - {"id":"unstable","label":"q = 1.0、a = 0","description":"q が 0.908 を超えると x 方向が不安定になる。","inputs":{"q":1.0,"a":0.0}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"floquet","path":"/rows/0/2","equals":true}
//|       - {"artifact":"floquet","path":"/rows/0/3","equals":true}
//|       - {"artifact":"floquet","path":"/rows/0/4","approx":{"value":0.3751312339480702,"rtol":1e-6}}
//|   - case: near-apex
//|     expect:
//|       - {"artifact":"floquet","path":"/rows/1/2","equals":true}
//|       - {"artifact":"floquet","path":"/rows/1/3","equals":true}
//|   - case: unstable
//|     expect:
//|       - {"artifact":"floquet","path":"/rows/0/2","equals":false}
//|       - {"artifact":"floquet","path":"/rows/0/3","equals":false}
//|       - {"artifact":"floquet","path":"/rows/0/1","approx":{"value":-2.8333904963392245,"rtol":1e-6}}
use scioxide_special::{mathieu_a, mathieu_b};

// 4 次の Runge–Kutta 法で u'' = −(a − 2q cos 2τ)u を積分する（独立な検算）
let force = |t: f64, u: f64, a: f64| -(a - 2.0 * q * (2.0 * t).cos()) * u;
let propagate = |state: [f64; 2], start: f64, steps: usize, a: f64| -> [f64; 2] {
    let h = std::f64::consts::PI / 2000.0;
    let [mut u, mut v] = state;
    for k in 0..steps {
        let t = start + h * k as f64;
        let (k1u, k1v) = (v, force(t, u, a));
        let (k2u, k2v) = (v + 0.5 * h * k1v, force(t + 0.5 * h, u + 0.5 * h * k1u, a));
        let (k3u, k3v) = (v + 0.5 * h * k2v, force(t + 0.5 * h, u + 0.5 * h * k2u, a));
        let (k4u, k4v) = (v + h * k3v, force(t + h, u + h * k3u, a));
        u += h / 6.0 * (k1u + 2.0 * k2u + 2.0 * k3u + k4u);
        v += h / 6.0 * (k1v + 2.0 * k2v + 2.0 * k3v + k4v);
    }
    [u, v]
};
let characteristic = [
    mathieu_a(0, q).map_err(|e| e.to_string())?,
    mathieu_b(1, q).map_err(|e| e.to_string())?,
    mathieu_a(1, q).map_err(|e| e.to_string())?,
    mathieu_b(2, q).map_err(|e| e.to_string())?,
];
let mut rows = Vec::new();
for (direction, value) in [("x", a), ("y", -a)] {
    let first = propagate([1.0, 0.0], 0.0, 2000, value);
    let second = propagate([0.0, 1.0], 0.0, 2000, value);
    let trace = first[0] + second[1];
    let by_trace = trace.abs() < 2.0;
    let by_values = characteristic
        .chunks(2)
        .any(|w| w[0] < value && value < w[1]);
    let nu = by_trace.then(|| (trace / 2.0).acos() / std::f64::consts::PI);
    let dehmelt = (value + q * q / 2.0 > 0.0).then(|| (value + q * q / 2.0).sqrt());
    rows.push((direction, trace, by_trace, by_values, nu, dehmelt));
}
// x(τ) の軌道を 10 周期描く（初期値 x = 1、x' = 0）
let mut orbit = vec![[0.0, 1.0]];
let mut state = [1.0, 0.0];
for k in 0..400 {
    let start = std::f64::consts::PI * f64::from(k) / 40.0;
    state = propagate(state, start, 50, a);
    orbit.push([start + std::f64::consts::PI / 40.0, state[0]]);
}
emit_line_chart!(
    &vec![serde_json::json!({ "name": "x(τ)", "points": orbit })],
    options =
        &serde_json::json!({ "xLabel": "無次元時刻 τ = Ωt/2 [-]", "yLabel": "変位 x/x₀ [-]" })
);
let fixed6 = serde_json::json!({ "significantDigits": 6 });
let columns = serde_json::json!([
    { "key": "0", "label": "方向" },
    { "key": "1", "label": "跡 Δ", "type": "number", "format": fixed6 },
    { "key": "2", "label": "|Δ| < 2", "type": "boolean" },
    { "key": "3", "label": "特性値の区間で安定", "type": "boolean" },
    { "key": "4", "label": "特性指数 ν", "type": "number", "format": fixed6, "nullText": "不安定" },
    { "key": "5", "label": "√(a + q²/2)", "type": "number", "format": fixed6, "nullText": "—" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "floquet" })
);
```

既定の $q = 0.4$、$a = 0.05$ では、$x$ 方向の跡は $\Delta = 0.765$、$y$ 方向は $1.701$ で、どちらも $|\Delta| < 2$ を満たし、特性値の区間による判定と一致する。
特性指数は $x$ で $\nu = 0.3751$、$y$ で $0.1762$ で、Dehmelt の近似 $0.3606$、$0.1732$ とは $x$ で 4%、$y$ で 2% 違う。
近似は $q^2$ の主要項だけを残したもので、$q$ が大きくなるほど外れる。
頂点のすぐ内側の $q = 0.70$、$a = 0.23$ では、$x$ の跡が $-1.929$、$y$ の跡が $1.961$ と、どちらも境界の $\mp 2$ に近い。
近似の $\nu$ は $x$ で 0.69（積分では 0.915）、$y$ で 0.12（積分では 0.063）と大きく外れるので、頂点の付近では特性値か積分を使う。
$q = 1.0$、$a = 0$ では跡が $-2.833$ で $|\Delta| > 2$ となり、二つの判定がどちらも不安定を示す。
グラフの $x(\tau)$ は、安定な点では包絡線が一定の振動になり、不安定な点では 1 周期ごとに $|\lambda| \approx 2.4$ 倍の割合で増える。


## まとめ

線形の四重極の中のイオンの運動は Mathieu 方程式で書け、閉じ込めの条件は $(q, a)$ が $x$ と $y$ の両方で特性値の安定な区間に入ることである。
特性値 $a_r(q)$、$b_r(q)$ は `mathieu_a` と `mathieu_b` で求まり、その順序だけで安定図が描ける。
第一安定領域の頂点は $b_1(q) = -a_0(q)$ の解で、$(q, a) = (0.706, 0.237)$ になり、質量フィルターの電圧の比 $U/V \approx 0.168$ を決める。
特性値による判定は 1 周期の積分によるモノドロミー行列の跡 $|\Delta| < 2$ と一致し、境界から離れた点では二つの判定が食い違わない。

特性値の固有値問題と打ち切りの決め方は [Mathieu 関数とスペクトル法](../../algorithms/mathieu-and-spheroidal/)で確かめる。
線形のポテンシャルに束縛された量子状態の準位を特殊関数の零点から求める例は[重力場中の中性子の量子化と Airy 関数](../airy-turning-point/)にある。
