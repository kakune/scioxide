偏微分方程式を変数分離すると、円柱座標からは Bessel 関数、線形ポテンシャルの転回点からは Airy 関数、大振幅の振り子からは楕円積分が現れる。
確率分布の正規化定数と累積確率は Gamma・Beta 関数とその不完全形で書け、正規分布の裾は誤差関数で書ける。
初等関数の有限回の合成では書けないこれらの関数を、まとめて特殊関数と呼ぶ。

`scioxide-special` は、Gamma・Beta 関数と確率の裾、誤差関数と Faddeeva 関数、Airy・Bessel・Hankel・Kelvin・Struve・放物柱関数、指数積分などの特殊積分、楕円積分と Jacobi 楕円関数、超幾何関数、ゼータ関数・多重対数・Lambert W、Coulomb 波動関数、組合せ数、Legendre 関数と角運動量の結合係数、Mathieu・回転楕円体・楕円体調和関数、Debye・Fermi–Dirac・輸送積分を評価する。
定義と記号は NIST の DLMF に従い、各関数の rustdoc が実装した式の番号を挙げる。
実数だけの関数は `f32` と `f64` を受け取り、複素数も扱う関数は同じ名前で `Complex<f32>` と `Complex<f64>` も受け取る。
`faddeeva`、`lambert_w_complex`、`parabolic_d_complex` は複素数の引数だけを受け取り、`spherical_harmonic` と `voigt_complex` は実数の引数から複素数の値を返す。

## 最初の計算：Γ(x) のオーバーフローと対数形

特殊関数の値は、引数が少し変わるだけで浮動小数点数の範囲を超えることがある。
binary64 の最大値はおよそ $1.8 \times 10^{308}$ で、$\Gamma(x)$ は $x \approx 171.62$ でこれを超える。

次のセルは選んだ $x$ と負の側の $t = -(x + 1/4)$ で、Gamma 関数を三つの形で評価する。
値だけを返す標準形式 `gamma`、推定誤差と別の表現を持つ結果を返すオプション付き形式 `gamma_with_options`、符号を捨てて $\ln|\Gamma|$ を返す `ln_gamma` である。
一つ目の表は標準形式の値とエラー、オプション付き形式が示す通常値への射影の状態、$\Gamma$ の符号を出す。
二つ目の表はオプション付き形式の対数形と `ln_gamma` を、独立に計算した参照値と比べる。
参照値は、正の側では Stirling 級数 $\ln\Gamma(t) \approx (t - \tfrac12)\ln t - t + \tfrac12\ln(2\pi) + \tfrac{1}{12t} - \tfrac{1}{360t^3} + \tfrac{1}{1260t^5}$、負の側では反射公式 $\Gamma(-s)\,\Gamma(1+s) = -\pi/\sin(\pi s)$ から得る。
$t \ge 160$ では、Stirling 級数の打ち切り誤差は $10^{-18}$ より小さい。

```rust
//| id: special-first-gamma-overflow
//| ref: special-first-gamma-overflow
//| title: Γ(x) があふれる前後で通常値と対数形を比べる
//| run: reactive
//| crates: [scioxide-special]
//| inputs:
//|   x: {"type":"range","label":"引数 x","description":"binary64 の Γ(x) は x ≈ 171.62 を超えるとあふれる。負の側は −(x + 1/4) を評価する。","min":160,"max":200,"step":0.5,"value":172}
//| cases:
//|   - {"id":"finite","label":"x = 171.5","description":"Γ(171.5) は binary64 の範囲に収まり、通常値が返る。","inputs":{"x":171.5}}
//|   - {"id":"far","label":"x = 200","description":"Γ(−200.25) は非正規化数の範囲も下回り、通常値は符号付きの零になる。","inputs":{"x":200}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"plain","path":"/rows/0/1","equals":null}
//|       - {"artifact":"plain","path":"/rows/0/2","equals":"NumericalInstability"}
//|       - {"artifact":"plain","path":"/rows/0/3","equals":"Overflow"}
//|       - {"artifact":"log","path":"/rows/0/1","approx":{"value":711.71472580229,"rtol":1e-12}}
//|       - {"artifact":"log","path":"/rows/0/4","range":{"max":1e-12}}
//|       - {"artifact":"log","path":"/rows/1/4","range":{"max":1e-12}}
//|   - case: finite
//|     expect:
//|       - {"artifact":"plain","path":"/rows/0/3","equals":"Finite"}
//|       - {"artifact":"log","path":"/rows/0/4","range":{"max":1e-12}}
//|   - case: far
//|     expect:
//|       - {"artifact":"plain","path":"/rows/1/1","equals":0}
//|       - {"artifact":"plain","path":"/rows/1/4","equals":-1}
//|       - {"artifact":"log","path":"/rows/1/4","range":{"max":1e-12}}
use scioxide_special::{GammaOptions, gamma, gamma_with_options, ln_gamma};

// 独立な参照: Stirling 級数と反射公式による ln|Γ(t)| と符号（f64 の固有メソッド）。
let stirling = |t: f64| {
    let (t2, ln_2pi) = (t * t, (2.0 * std::f64::consts::PI).ln());
    (t - 0.5) * t.ln() - t + 0.5 * ln_2pi + 1.0 / (12.0 * t) - 1.0 / (360.0 * t * t2)
        + 1.0 / (1260.0 * t * t2 * t2)
};
let reference = |t: f64| {
    if t > 0.0 {
        return (stirling(t), 1.0);
    }
    // Γ(−s) = −π / (sin(πs) Γ(1 + s))。s を 2 で割った余りに落としてから sin を取る。
    let s = -t;
    let sine = (std::f64::consts::PI * (s - 2.0 * (s / 2.0).floor())).sin();
    let ln_abs = std::f64::consts::PI.ln() - sine.abs().ln() - stirling(1.0 + s);
    (ln_abs, -sine.signum())
};

let mut plain_rows = Vec::new();
let mut log_rows = Vec::new();
for t in [x, -(x + 0.25)] {
    // 標準形式: 範囲外ならエラーの分類を表に出す。
    let plain = gamma(t);
    let failure = match &plain {
        Ok(_) => "なし".to_string(),
        Err(e) => format!("{:?}", e.kind()),
    };
    // オプション付き形式: 通常値への射影の状態と、符号付きの対数形を読む。
    let detailed = gamma_with_options(t, GammaOptions::default()).map_err(|e| e.to_string())?;
    let log = detailed.logarithmic().map(|l| *l.value());
    let log_magnitude = log.and_then(|l| l.log_magnitude());
    let ln_abs = ln_gamma(t).map_err(|e| e.to_string())?;
    let (expected, expected_sign) = reference(t);
    plain_rows.push((
        t,
        plain.ok(),
        failure,
        format!("{:?}", detailed.scalar_representation()),
        log.map(|l| l.sign()),
        expected_sign,
    ));
    let difference = log_magnitude.map(|l| (l - expected).abs() / expected.abs());
    log_rows.push((t, log_magnitude, ln_abs, expected, difference));
}

let sci6 = serde_json::json!({ "notation": "scientific", "significantDigits": 6 });
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let fixed6 = serde_json::json!({ "fractionDigits": 6 });
let plain_columns = serde_json::json!([
    { "key": "0", "label": "t [-]", "type": "number" },
    { "key": "1", "label": "gamma(t) [-]", "type": "number", "format": sci6, "nullText": "エラー" },
    { "key": "2", "label": "標準形式のエラー", "type": "string" },
    { "key": "3", "label": "通常値の状態", "type": "string" },
    { "key": "4", "label": "オプション付き形式の符号 [-]", "type": "number", "nullText": "なし" },
    { "key": "5", "label": "参照の符号 [-]", "type": "number" }
]);
emit_table_with_columns!(
    plain_columns,
    plain_rows,
    metadata = serde_json::json!({ "id": "plain" })
);
let log_columns = serde_json::json!([
    { "key": "0", "label": "t [-]", "type": "number" },
    { "key": "1", "label": "ln|Γ(t)|（オプション付き形式） [-]", "type": "number", "format": fixed6, "nullText": "なし" },
    { "key": "2", "label": "ln_gamma(t) [-]", "type": "number", "format": fixed6 },
    { "key": "3", "label": "参照 [-]", "type": "number", "format": fixed6 },
    { "key": "4", "label": "オプション付き形式と参照の相対差 [-]", "type": "number", "format": sci2, "nullText": "なし" }
]);

    log_columns,
    log_rows,
    metadata = serde_json::json!({ "id": "log" })

```

既定の $x = 172$ では、標準形式は `NumericalInstability` を返し、オプション付き形式の通常値の状態は `Overflow` になる。
それでもオプション付き形式の対数形は $\ln|\Gamma(172)| \approx 711.714726$ と符号 $+1$ を保ち、`ln_gamma` の値とも参照値とも一致する。
入力を 160 から 200 まで 0.5 刻みで動かしても、対数形と参照値の相対差は $3 \times 10^{-16}$ 以下である。
$x$ を 171.5 以下にすると通常値が得られ、状態は `Finite` になる。

負の側の $\Gamma(-172.25)$ は反射公式により非常に小さく、符号は $(-n-1, -n)$ の区間ごとに入れ替わる。
既定では $\Gamma(-172.25) \approx -5.74 \times 10^{-312}$ が非正規化数として返る。
これは丸めて得た有効な値で、エラーではない。
$x = 200$ では $\Gamma(-200.25)$ が非正規化数の範囲も下回り、標準形式は符号付きの零 $-0$ を返し（表には 0 と出る）、状態は `Finite` のままである。
このときも対数形は $\ln|\Gamma(-200.25)| \approx -863.07$ と符号 $-1$ を保つ。
`ln_gamma` は符号を捨てた $\ln|\Gamma|$ だけを返すので、符号が要るときはオプション付き形式の対数形を読む。

## 結果とエラーの読み方

この計算は章を通した三つの読み方を示している。

一つ目はエラーの分類である。
失敗は `SciOxideError` で返り、`kind()` で次の分類を区別する。
`NonFinite` は NaN や無限大の入力で、無限遠での極限はどの関数も評価しない。
`DomainError` は極（`Pole`、たとえば $\Gamma(0)$）、実数の定義域の外（`OutsideDomain`）、近づく向きで極限が変わる点（`Undefined`）である。
`InvalidInput` は次数や階数のような整数の引数が範囲外（`OutOfRange`）のときに返る。
`SizeOverflow` は、正確な整数の結果（`checked_bernoulli` など）や、次数から決まる配列の大きさが表せないときに返る。
`NumericalInstability` は値のオーバーフロー（`Overflow`）や、方法で解消できない打ち消し（`LossOfSignificance`）である。
`ConvergenceFailure` は作業量の上限（`Budget`）に達したことを示し、試みた計算量の計数を持つ。
Mathieu・回転楕円体関数の Plan では、打ち切りの上限までに展開が収束しないことも `ConvergenceFailure`（`TruncationLimit`）で示す。
スコープ付き API の評価が取り消されたか期限を過ぎたときは `ExecutionStopped` になる。
値が小さすぎて表せないことはエラーにならず、符号付きの零か非正規化数が返る。

二つ目は詳細な結果である。
オプション付き形式 `*_with_options` は `SpecialFunctionResult` を返し、通常値、尺度化した値、対数形、導関数のそれぞれに推定誤差を付け、終了状態、計算量の計数、アルゴリズムの識別子を持つ。
推定誤差は区間の包含区間ではなく、証明付きの上下限が要るときは `scioxide-validated` を使う。
オプション付き形式の通常値は標準形式の値とビット単位で同じである。

三つ目は表現の選択である。
数学的には同じ量でも、対数形・相補形・尺度化形で評価すると範囲外や打ち消しを避けられる。

## 同じ量の別の表現

| 表現 | 代表的な関数 | 避けられる問題 |
|---|---|---|
| 対数形 | `ln_gamma`、`ln_beta`、`ln_factorial`、`gamma_log_q`、`normal_log_sf`、`log_erfc` | 大きな階乗や小さな確率の範囲外 |
| 相補形 | `erfc`、`gamma_q`、`beta_inc_q`、`normal_sf` | $1 - F(x)$ の打ち消し（$F(x)$ が 1 に丸められると裾が 0 になる） |
| 尺度化形 | `bessel_k_scaled`、`airy_ai_scaled`、`erfcx`、`expint_e1_scaled` | 指数因子による範囲外。返る値は指数因子を掛けた別の量 |
| 逆関数 | `gamma_p_inv`、`beta_inc_inv`、`erfcinv`、`normal_quantile` | 確率から分位点を求める求根を自分で組むこと |

どの問題でどの表現を選ぶかは [選び方](choosing/) で扱う。

## 評価の方法と精度の範囲

一つの級数や積分表示で全定義域を評価すると、大きな引数での打ち消しや遅い収束に出会う。
そのため実装は引数の領域ごとに方法を選ぶ。
原点の近くでは定義の級数や有理近似、中間では連分数や漸化式、大きな引数では漸近展開を使い、選んだ方法はアルゴリズムの識別子として詳細な結果に残る。

計算量が引数にも収束にもよらない関数は、固定の表、有理近似や Chebyshev 近似、固定の求積点で評価する。
`gamma`、`ln_gamma`、`digamma`、`beta`、`ln_beta`、`erfinv`、`erfcinv`、`normal_cdf`、`normal_sf`、`normal_quantile`、整数の階乗と `binomial` などがこれに当たり、スコープ付き API を持たない。
級数、連分数、次数の漸化式、根の反復で評価する関数は、オプションの作業量の上限の中で反復し、スコープ付き API を持つ。

精度の目標は、crate の試験が照合データ（独立に生成した高精度の参照値）で確かめた範囲で定められている。
binary64 の実数の引数で、完全 Gamma・Beta 関数と `digamma`、`polygamma` は 4 ULP、不完全 Gamma・Beta 関数とその逆関数は 32 ULP、実数の Bessel・Airy 関数、超幾何関数 ${}_0F_1$・${}_1F_1$・${}_2F_1$・$U$、Legendre 関数、Lambert W は 64 ULP を目標とする。
不完全 Gamma の 32 ULP は試験した範囲での値で、より広い 4160 点の標本では最大 90 ULP が観測されている。
実数の `riemann_zeta`、`dirichlet_eta`、$s > 1$ の `hurwitz_zeta` は ULP の目標を持たず、推定誤差が $64\varepsilon|\text{値}|$ 以下であることを返す。
複素数の引数と、精度の表にない関数（Kelvin・放物柱・角運動量・スペクトル型の関数など）には一様な ULP の仕様がなく、オプション付き形式の推定誤差が手がかりになる。
零点・極・分枝点の近くでは、絶対誤差が小さくても相対誤差が大きくなることがある。

## まとめと次に読むページ

`scioxide-special` の関数は値だけを返す標準形式と、推定誤差・終了状態・別の表現を返すオプション付き形式を持つ。
通常値が範囲を超えてもオプション付き形式の対数形や尺度化形は値を保てるので、エラーの分類を読んでから表現を選び直す。
小さすぎる値はエラーではなく、符号付きの零か非正規化数として返る。
精度の目標は関数族ごとに、試験した範囲で定められており、全定義域で一様な保証ではない。
問題に合う表現は [選び方](choosing/) で、結果の型と共通の仕様は [アルゴリズム](algorithms/) で、項目ごとの仕様は [API ガイド](api/) で確かめる。
