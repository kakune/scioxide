ベイズ推論では未知の母数 $\theta$ の不確かさを確率分布で表す。
観測 $y$ を得る前の知識を事前分布 $p(\theta)$、観測のモデルを尤度 $p(y \mid \theta)$ とすると、観測後の分布（事後分布）はベイズの定理から

$$
p(\theta \mid y) = \frac{p(y \mid \theta)\, p(\theta)}{\int p(y \mid \theta')\, p(\theta')\, d\theta'} \;\propto\; p(y \mid \theta)\, p(\theta)
$$

となる。
分母の正規化定数（周辺尤度）は一般に積分でしか求まらないが、尤度に対して特別な形の事前分布を選ぶと、事後分布が事前分布と同じ族に入り、母数の足し算だけで更新できる。
この性質を共役性（conjugacy）と呼ぶ。
このページでは、`scioxide-stats` が提供する三つの共役な組（Beta–二項、Gamma–Poisson、正規–逆ガンマ）を導出し、事後分布の要約（事後平均、等裾の信用区間）と、将来の観測の分布（事後予測分布）を求める。
共役な組が使えないモデルではマルコフ連鎖モンテカルロ法（MCMC）で事後分布から標本を引くが、`scioxide-stats` はその標本器を提供せず、引いた連鎖の診断と要約だけを提供する。
それは[MCMC の収束診断と事後要約](../mcmc-diagnostics/)で扱う。

## 共役更新と事後分布の要約

共役な組では、事後分布が観測の十分統計量（二項なら成功数と試行数、正規なら件数・平均・偏差平方和）だけで決まる。
そのため、観測を一度にまとめて更新しても、一つずつ順に更新しても、同じ事後分布になる。
`scioxide-stats` の事前分布の型（`BetaBinomialPrior`、`GammaPoissonPrior`、`NormalInverseGammaPrior`）は、事前分布と事後分布の両方を表す値で、更新のメソッドは新しい値を返し、元の値を変えない。
母数は指数の範囲を広げた拡張範囲の値で保持し、`parameters()` で読むときに `S` へ丸める。
丸めた値が `S` であふれる場合は `NumericalInstability` を返す。
更新の計算量は観測一つあたり $O(1)$ である。

事前分布の密度が積分して 1 にならない（正規化できない）ものを非正則な事前分布と呼ぶ。
非正則な事前分布でも、十分な観測があれば事後分布は正則になる。
各型の `is_proper()` は母数が正則な分布を表すかを返し、非正則な状態で事後分布や予測分布を求めると `InvalidInput` を返す。

事後分布の要約として、事後平均と信用区間を使う。
確率 $c$ の等裾の信用区間は事後分布の下側と上側の裾にそれぞれ $(1-c)/2$ を残す区間 $[q_{(1-c)/2},\, q_{(1+c)/2}]$ で、観測を与えたもとで $\theta$ がこの区間に入る事後確率が $c$ である。
これに対し、頻度論の信頼区間は、同じ手順を標本の取り直しで繰り返したときに真の値を含む割合が $c$ という区間で、意味が違う。
次の節で見るように、特定の事前分布では二つの区間が数値として一致することがあるが、解釈は変わらない。

`credible_interval(law, probability, options)` は、`scioxide-random` の分布 `law`（下側と上側の裾の対数と台を持つもの）の等裾の信用区間を返す。
下端は $\ln F(x) = \ln\frac{1-c}{2}$、上端は $\ln S(x) = \ln\frac{1-c}{2}$（$S = 1 - F$ は生存関数）を `InversionOptions` の設定で逆算する。
上端を $F$ の $1 - (1-c)/2$ 分位点ではなく生存関数から求めるので、上側の裾での桁落ちがない。
端点ごとに `options` の評価回数の上限を別々に使うので、全体の作業は計算回数の上限の 2 倍以内である。
逆算が収束しなければ `ConvergenceFailure`、端点が無限大なら `NonFinite` を返す。
結果の `CredibleInterval` は区間 `bounds()` と確率 `probability()` を持つ。

`InversionOptions` の評価回数の上限（既定 65,536）は、二分法の評価回数だけでなく、裾の確率を評価する特殊関数の内部の反復も数える。
ベータ分布 $\mathrm{Beta}(5.5, 25.5)$ の上端のように、上側の裾の評価が連分数で多くの反復を使う場合も、既定の計算回数の上限は `scioxide-random` の分布の 1 回の操作と同じ作業量なので足りる。
このページのセルは既定の `InversionOptions` を使う。

事後分布の最も密度の高い区間（最高事後密度区間、HPD 区間）は提供しない。
単峰の事後分布なら、`scioxide-random` の分位点関数で $[Q(u), Q(u + c)]$ の幅を $u \in (0, 1-c)$ について最小にすれば求まる。
事後最頻値（最大事後確率推定値）を返す関数もないので、下の閉形式で計算する。

## ベルヌーイ・二項観測と Beta-二項共役更新

成功確率 $p$ の試行を $n$ 回行って $k$ 回成功したとき、尤度は $p^k(1-p)^{n-k}$ に比例する。
事前分布をベータ分布 $\mathrm{Beta}(\alpha, \beta)$、密度 $\propto p^{\alpha-1}(1-p)^{\beta-1}$ にすると、事後分布は

$$
p \mid k \;\sim\; \mathrm{Beta}(\alpha + k,\; \beta + n - k)
$$

である。
$\alpha$ と $\beta$ は、事前に観測した成功と失敗の擬似的な件数とみなせる。
事後分布 $\mathrm{Beta}(a, b)$ の平均、分散、最頻値は

$$
E[p] = \frac{a}{a+b}, \qquad
\mathrm{Var}[p] = \frac{ab}{(a+b)^2(a+b+1)}, \qquad
\mathrm{mode} = \frac{a-1}{a+b-2}\ (a, b > 1)
$$

で、事後平均 $\frac{\alpha + k}{\alpha + \beta + n}$ は事前平均 $\frac{\alpha}{\alpha+\beta}$ と標本比率 $k/n$ を重み $\alpha+\beta$ と $n$ で平均したものになる。
$a \le 1$ か $b \le 1$ では密度が端で発散するか単調になり、内部の最頻値はない。

将来の $m$ 回の試行の成功数 $Y$ の事後予測分布は、二項分布を事後分布で平均したベータ二項分布 $\mathrm{BetaBinomial}(m, a, b)$ で、

$$
E[Y] = m\frac{a}{a+b}, \qquad
\mathrm{Var}[Y] = \frac{m\,ab\,(a+b+m)}{(a+b)^2(a+b+1)}
$$

である。
分散は $p$ を事後平均に固定した二項分布の分散 $m\,\bar p(1-\bar p)$ の $(a+b+m)/(a+b+1)$ 倍で、$p$ の不確かさの分だけ広い。

よく使う事前分布は次の三つである。
一様分布 $\mathrm{Beta}(1, 1)$、Jeffreys の事前分布 $\mathrm{Beta}(1/2, 1/2)$（Fisher 情報量の平方根に比例し、母数の変換に対して不変）、Haldane の事前分布 $\mathrm{Beta}(0, 0)$（密度 $\propto p^{-1}(1-p)^{-1}$ で非正則）である。
Haldane の事前分布の事後平均は標本比率 $k/n$ に等しいが、$k = 0$ か $k = n$ では事後分布も非正則のままである。

`BetaBinomialPrior::new(alpha, beta)` は正則な事前分布を作り、母数が NaN か無限大なら `NonFinite`、正でなければ `InvalidInput` を返す。
`BetaBinomialPrior::improper(alpha, beta)` は少なくとも一方が 0 の非正則な事前分布を作り、どちらも正なら `InvalidInput` を返す。
`update(successes, trials)` は事後分布を返し、試行 0 回なら分布を変えず、成功が試行を超えると `InvalidInput` を返す。
`update_frequency(successes, trials, frequency)` は同じ観測を $f$ 回繰り返した更新 $\mathrm{Beta}(\alpha + fk, \beta + f(n-k))$ で、集計済みのデータに使う。
`update_batch(&[(successes, trials)])` は観測の列を順に取り込む。
`posterior_law()` は `scioxide-random` の `Beta` を、`predictive(m)` は `BetaBinomial` を返す。

次のセルは事前分布を選んで $n$ 回中 $k$ 回の成功で更新し、事後分布の要約と、将来の $m$ 回の試行の成功数の事後予測分布を求める。
表の「検算」の列は独立な計算である。
事後の母数は 1 試行ずつの逐次更新 `update_batch` の結果、事後平均・標準偏差・予測の平均と標準偏差は上の閉形式、信用区間の端点は `scioxide-random` の `Beta::quantile`（逆算とは別のアルゴリズム）で求める。
図は事後予測分布と、$p$ を事後平均に固定した二項分布（参照）の確率を並べる。
事後分布が非正則なら、要約の行は空欄になり、図は描かない。

## ポアソン観測と Gamma-Poisson 共役更新

単位時間あたりの率 $\lambda$ で起こる事象を暴露量 $t$（時間、面積、人数×時間など）の間数えると、件数 $k$ は $\mathrm{Poisson}(\lambda t)$ に従い、尤度は $\lambda^k e^{-\lambda t}$ に比例する。
事前分布を形状 $a$、率 $\beta$ のガンマ分布 $\mathrm{Gamma}(a, \beta)$、密度 $\propto \lambda^{a-1}e^{-\beta\lambda}$ にすると、事後分布は

$$
\lambda \mid k \;\sim\; \mathrm{Gamma}(a + k,\; \beta + t)
$$

で、$a$ は事前の擬似的な件数、$\beta$ は擬似的な暴露量とみなせる。
事後平均は $(a+k)/(\beta+t)$、事後分散は $(a+k)/(\beta+t)^2$ である。
将来の暴露量 $t'$ の件数 $Y$ の事後予測分布は、成功確率 $\beta/(\beta + t')$、成功数 $a$ の負の二項分布で、

$$
E[Y] = \frac{a\,t'}{\beta}, \qquad
\mathrm{Var}[Y] = \frac{a\,t'(\beta + t')}{\beta^2}
$$

となり、分散が平均より大きい（過分散）。
ここでの $a$、$\beta$ は事後の母数である。

Poisson の率の Jeffreys の事前分布は $p(\lambda) \propto \lambda^{-1/2}$ で、$\mathrm{Gamma}(1/2, 0)$ に当たる非正則な分布である。
非正則な $\mathrm{Gamma}(0, 0)$ と $\mathrm{Gamma}(1, 0)$ には頻度論との対応がある。
$P(X \ge k;\, \lambda t) = P(G_k \le \lambda t)$（$G_k \sim \mathrm{Gamma}(k, 1)$）という Poisson 過程の待ち時間の関係から、Garwood の信頼限界（[裾確率による母数の逆算と正確な信頼限界](oxref:stats-inversion-confidence-limit-computation)）の下限は事後分布 $\mathrm{Gamma}(k, t)$ の $(1-c)/2$ 分位点、上限は $\mathrm{Gamma}(k+1, t)$ の $(1+c)/2$ 分位点に等しい。
Jeffreys の事後分布 $\mathrm{Gamma}(k + 1/2, t)$ の信用区間は、この二つの間に入る。

`GammaPoissonPrior::new(shape, rate)` の `rate` は尺度ではなく率（尺度の逆数）である。
`GammaPoissonPrior::improper(shape, rate)` は少なくとも一方が 0 の非正則な事前分布を作る。
`update(count, exposure)` は暴露量が NaN か無限大なら `NonFinite`、負か、件数が正なのに 0 なら `InvalidInput` を返す。
暴露量の単位は呼び出し側が固定し、$\lambda$ はその単位あたりの率になる。
`update_frequency(count, exposure, frequency)` と `update_batch(&[(count, exposure)])` は二項の場合と同じ意味である。
`posterior_law()` は `scioxide-random` の `Gamma`（形状 $a$、尺度 $1/\beta$）を返す。
`predictive(exposure)` は `NegativeBinomial` を返し、暴露量 0 なら 0 に集中した分布になる。
正の暴露量が小さすぎて $\beta/(\beta + t')$ が 1 に丸められる場合は `InvalidInput` を返す。

次のセルは暴露量 $t$ [h] の間に $k$ 件の故障を観測したとして、Jeffreys の事前分布と、情報のある事前分布 $\mathrm{Gamma}(2, 1000\ \mathrm{h})$（1000 h で 2 件に相当する過去の記録）で更新する。

## 正規観測と正規-逆ガンマ共役更新

平均 $\mu$ と分散 $\sigma^2$ がともに未知の正規分布 $N(\mu, \sigma^2)$ からの観測には、正規–逆ガンマ分布 $\mathrm{NIG}(m, \kappa, a, b)$

$$
\sigma^2 \sim \mathrm{InvGamma}(a, b), \qquad \mu \mid \sigma^2 \sim N\!\left(m,\; \frac{\sigma^2}{\kappa}\right)
$$

が共役である。
$m$ は位置、$\kappa$ は平均についての擬似的な観測数（精度の倍率）、$a$ は分散の形状、$b$ は分散の尺度で、$2a$ は分散についての擬似的な観測数に当たる。
$n$ 個の観測の平均を $\bar x$、偏差平方和を $Q = \sum_i (x_i - \bar x)^2$ とすると、事後分布は

$$
\kappa_n = \kappa + n, \quad
m_n = \frac{\kappa m + n\bar x}{\kappa_n}, \quad
a_n = a + \frac{n}{2}, \quad
b_n = b + \frac{Q}{2} + \frac{\kappa n (\bar x - m)^2}{2\kappa_n}
$$

である（Gelman ら BDA 3 版 §3.3）。
$b_n$ の最後の項は事前の位置 $m$ と標本平均 $\bar x$ の食い違いが分散の推定を大きくする分である。

事後分布の周辺分布は次のとおりである。

- 平均：$\mu = m_n + \sqrt{b_n/(a_n\kappa_n)}\; T$、$T$ は自由度 $2a_n$ の Student の t 分布。
- 分散：$\sigma^2 \sim \mathrm{InvGamma}(a_n, b_n)$。
  事後平均 $b_n/(a_n - 1)$ は $a_n > 1$ のときだけ存在する。
- 標準偏差：$\sigma = \sqrt{\sigma^2}$。
  事後平均 $\sqrt{b_n}\,\Gamma(a_n - 1/2)/\Gamma(a_n)$ は $a_n > 1/2$ のときだけ存在する。
- 精度の倍率 $w$ の新しい観測（分散 $\sigma^2/w$）の予測分布：自由度 $2a_n$、位置 $m_n$、尺度 $\sqrt{(b_n/a_n)(1/w + 1/\kappa_n)}$ の t 分布。

参照事前分布 $p(\mu, \sigma^2) \propto 1/\sigma^2$ は、$m = 0$、$\kappa = 0$、$a = -1/2$、$b = 0$ の非正則な分布に当たる。
このとき事後分布は $\kappa_n = n$、$m_n = \bar x$、$a_n = (n-1)/2$、$b_n = Q/2$ で、$n \ge 2$ かつ $Q > 0$ なら正則になる。
標本分散を $s^2 = Q/(n-1)$ と書くと、平均の事後分布は $\bar x + (s/\sqrt n)\,T_{n-1}$、分散の事後分布は $Q/\chi^2_{n-1}$ の分布になる。
したがって、参照事前分布による $\mu$ の等裾の信用区間は Student の t による信頼区間 $\bar x \pm t_{n-1,(1+c)/2}\, s/\sqrt n$ と、$\sigma^2$ の信用区間は $\chi^2$ による信頼区間 $[Q/\chi^2_{n-1,(1+c)/2},\, Q/\chi^2_{n-1,(1-c)/2}]$ と数値として一致する。

`NormalInverseGammaPrior::new(location, precision, shape, scale)` は正則な事前分布を作り、位置が NaN か無限大なら `NonFinite`、ほかの母数が正でなければ `InvalidInput`（NaN か無限大なら `NonFinite`）を返す。
`reference()` は参照事前分布を返す。
`parameters()` は $(m, \kappa, a, b)$ の順に返す。
観測の取り込みには次のメソッドがある。

- `update(value)` は観測一つ、`update_batch(values)` はスライスを取り込み、$O(n)$ の時間と $O(1)$ のメモリ使用量を使う。
  値が NaN か無限大なら `NonFinite` を返す。
- `update_moments(&OnlineMoments)` と `update_snapshot(MomentsSnapshot)` は、[逐次平均・分散・高次モーメント・共分散の数理](../online-moments-and-covariance/)の累積器が持つ件数・平均・偏差平方和から $O(1)$ で更新する。
  累積器は併合できるので、分散した集計の結果をまとめてから事後分布を作れる。
- `update_weighted(&OnlineWeightedMoments)` と `update_weighted_snapshot` は重み付きの累積器から更新する。
  頻度の重み（`Frequency`）は観測をその回数だけ数える。
  解析的な重み（`Analytic`）は観測 $x_i$ の分散を $\sigma^2/w_i$ とみなし、$\bar x$ と $Q$ を重み付きにして、$\kappa$ を $\sum w_i$ だけ、$a$ を観測の個数の半分だけ増やす。
  解析的な重みを一律に定数倍するとモデルが変わる。
  信頼度の重み（`Reliability`）は尤度を定めないので、型 `ConjugateWeights` の制約で受け付けない（コンパイルできない）。

`posterior_law()` は `scioxide-random` の同時分布 `NormalInverseGamma` を返す。
`marginals()` は周辺分布をまとめた `NormalPosteriorMarginals` を返し、`mean_law()` が平均の t 分布（`Affine<StudentT>`）、`variance_law()` が分散の逆ガンマ分布、`standard_deviation_law()` が標準偏差の分布（どちらも `Affine<GeneralizedGamma>`）を返す。
各分布は密度、裾確率、分位点、モーメント、標本の生成を持つ。
`predictive(precision_multiplier)` は新しい観測の予測分布（`Affine<StudentT>`）を返し、データと同じ精度の観測には $w = 1$ を渡す。
どれも事後分布が非正則なら `InvalidInput` を返す。

`NormalPosteriorMarginals::credible_summary(probability, options)` は、平均・分散・標準偏差のそれぞれについて事後平均と等裾の信用区間を求め、`NormalCredibleSummary { mean, variance, standard_deviation }` を返す。
各成分は `CredibleSummary { mean, interval }` で、事後平均が存在しなければ `mean` は `None` になる。
参照事前分布で直接データから求める関数として、周辺分布の `normal_posterior_marginals(values)` と、要約の `normal_credible_summary(values, probability, options)` がある。
後者は六つの区間の端点にそれぞれ `options` の計算回数の上限を使う。
値が 2 個未満かすべて等しいと `InvalidInput` を返す。

次のセルは抵抗器 8 本の抵抗値 [Ω] を正規分布の観測とみなし、事前分布を選んで更新する。
参照事前分布のほかに、同じ型の抵抗器の過去の記録から作った情報のある事前分布 $\mathrm{NIG}(100\ \Omega, 4, 3, 2\ \Omega^2)$（平均は 4 本分の重みで 100 Ω、分散の事前平均は $b/(a-1) = 1\ \Omega^2$）を選べる。
1 つ目の表は事前分布と事後分布の母数である。
2 つ目の表は $\mu$、$\sigma^2$、$\sigma$、次の観測について、事後平均と信用区間を、頻度論の区間と並べる。
頻度論の区間は、平均が `confidence_interval_of_mean_with_options`（Student の t）、分散が `normal_variance_confidence_limits_with_options`、標準偏差がその平方根、次の観測が予測区間 $\bar x \pm t_{n-1,(1+c)/2}\, s\sqrt{1 + 1/n}$ で、どれも事前分布によらない。
このセルは標本と事後分布の母数を次のセルに渡す。

let (m, kappa, a, b) = posterior.parameters().map_err(|e| e.to_string())?;

    .map_err(|e| e.to_string())?
    .snapshot();

平均の信用区間 $[99.5581, 100.8919]$ Ω、分散の信用区間 $[0.2782, 2.6363]$ Ω²、次の観測の予測区間 $[98.2242, 102.2258]$ Ω は、どれも頻度論の区間と 12 桁以上一致する。
「c = 0.99」でも二つの区間は一致し、平均の区間は $[99.2380, 101.2120]$ Ω に広がる。
数値が同じでも、信用区間は「このデータのもとで $\mu$ が区間に入る確率が $c$」、信頼区間は「手順を繰り返すと区間が $\mu$ を含む割合が $c$」で、読み方が違う。
情報のある事前分布では事後分布が $\mathrm{NIG}(100.15, 12, 7, 4.295)$ になり、平均の区間は $[99.6650, 100.6350]$ Ω に、分散の区間は $[0.3289, 1.5261]$ Ω² に狭まる。
事前の 4 本分の平均の情報と、$2a = 6$ 本分の分散の情報が加わったためで、事前分布が実際の工程と合っていなければ区間は偏る。
分散の事後平均 $b/(a-1)$ は参照事前分布で 0.891、情報のある事前分布で 0.716 Ω² で、標本分散 $Q/(n-1) = 0.636$ Ω² とはどちらも違う。

### 行列ビューによる一括更新

多数の独立な系列（製造ロットごと、センサーごとの観測など）の事後分布を一度に求めるには、`normal_posteriors_into(requests, execution, output, staging, context)` を使う。
要求 `NormalPosteriorRequest::new(prior, values)` は事前分布と `scioxide-linalg` の行列ビューを組にし、行列のすべての要素を行優先の順に観測として解釈する。
ビューはストライド付きでも転置でもよく、行列の形は事後分布に影響しない。
`with_weights(Weights::<_, M>::new(view))` は観測と同じ形の頻度の重みか解析的な重みを付け、`prior()`、`values()`、`weights()` で中身を読める。
要求は `execution`（`ExecutionPolicy`）のもとで最大 64 のワーカーが並列に処理し、各要求は自分の観測を決まった順序で読むので、結果はワーカーの数によらない。
`staging` は要求の数以上の長さの作業用の配列で、成功すると `output` のすべての要素が `Some` になる。
計算量は観測の総数に比例する。
`output` と `staging` の長さ、重みと観測の形が合わなければ `InvalidInput`、観測か重みが NaN か無限大なら `NonFinite`、負の重みは `InvalidInput`、整数でない頻度の重みは `ScalarConversion` を返す。

次のセルは前のセルから標本と事前分布の選択を受け取り、同じ事後分布を一括更新で求め直す。
1 行目と 2 行目は同じ 8 個の値を $1 \times 8$ と $2 \times 4$ の行列ビューで渡し、前のセルの事後分布と比べる。
3 行目は頻度の重み 2 で、標本を 2 回並べた `update_batch` と比べる。
4 行目は解析的な重み 2 で、上の更新式に重み付きの $\bar x$ と $Q_w = \sum_i w_i (x_i - \bar x_w)^2$ を入れた手計算と比べる。
5 行目は前半 4 個と後半 4 個の `OnlineMoments` を併合して `update_moments` に渡す。
表の最後の列は四つの母数の差の絶対値の最大である。

```rust
//| id: stats-bayesian-conjugate-updates-api-5
//| ref: stats-bayesian-conjugate-updates-api-5
//| title: 行列ビューと重みで正規–逆ガンマの事後分布を一括で求め直す
//| run: reactive
//| crates: [scioxide-core, scioxide-linalg, scioxide-stats]
//| dependsOn:
//|   normal: stats-bayesian-conjugate-updates-api-3
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"batch","path":"/rows/0/5","range":{"max":1e-12}}
//|       - {"artifact":"batch","path":"/rows/1/5","range":{"max":1e-12}}
//|       - {"artifact":"batch","path":"/rows/2/2","equals":16}
//|       - {"artifact":"batch","path":"/rows/2/3","equals":7.5}
//|       - {"artifact":"batch","path":"/rows/2/5","range":{"max":1e-12}}
//|       - {"artifact":"batch","path":"/rows/3/3","equals":3.5}
//|       - {"artifact":"batch","path":"/rows/3/5","range":{"max":1e-12}}
//|       - {"artifact":"batch","path":"/rows/4/5","range":{"max":1e-12}}
use scioxide_core::{ExecutionContext, ExecutionPolicy};
use scioxide_linalg::MatrixView;
use scioxide_stats::{
    Analytic, Frequency, MomentOrder, NormalInverseGammaPrior, NormalPosteriorRequest,
    OnlineMoments, Weights, normal_posteriors_into,
};

let values: Vec<f64> =
    serde_json::from_value(normal["values"].clone()).map_err(|e| e.to_string())?;
let reference: [f64; 4] =
    serde_json::from_value(normal["posterior"].clone()).map_err(|e| e.to_string())?;
let start = if normal["prior"] == "reference" {
    NormalInverseGammaPrior::reference()
} else {
    NormalInverseGammaPrior::new(100.0, 4.0, 3.0, 2.0).map_err(|e| e.to_string())?
};
let count = values.len();
let row = MatrixView::from_slice(1, count, &values).map_err(|e| e.to_string())?;
let square = MatrixView::from_slice(2, count / 2, &values).map_err(|e| e.to_string())?;
let twos = vec![2.0; count];
let twos_view = MatrixView::from_slice(1, count, &twos).map_err(|e| e.to_string())?;
let requests = [
    NormalPosteriorRequest::new(start, row),
    NormalPosteriorRequest::new(start, square),
    NormalPosteriorRequest::new(start, row)
        .with_weights(Weights::<_, Frequency>::new(twos_view)),
    NormalPosteriorRequest::new(start, row)
        .with_weights(Weights::<_, Analytic>::new(twos_view)),
];
let mut output = [None; 4];
let mut staging = [None; 4];
normal_posteriors_into(
    &requests,
    ExecutionPolicy::Sequential,
    &mut output,
    &mut staging,
    ExecutionContext::sequential(),
)
.map_err(|e| e.to_string())?;
// 検算 1：標本を 2 回並べた逐次更新（頻度の重み 2 と同じ）
let doubled: Vec<f64> = values.iter().chain(&values).copied().collect();
let duplicated = start.update_batch(&doubled).map_err(|e| e.to_string())?;
let duplicated = duplicated.parameters().map_err(|e| e.to_string())?;
// 検算 2：解析的な重み w = 2 の更新式（手計算）
let (m0, k0, a0, b0) = start.parameters().map_err(|e| e.to_string())?;
let weight_sum = 2.0 * count as f64;
let mean = values.iter().sum::<f64>() / count as f64;
let weighted_scatter: f64 = values.iter().map(|x| 2.0 * (x - mean) * (x - mean)).sum();
let kappa = k0 + weight_sum;
let analytic = (
    (k0 * m0 + weight_sum * mean) / kappa,
    kappa,
    a0 + count as f64 / 2.0,
    b0 + weighted_scatter / 2.0 + k0 * weight_sum * (mean - m0) * (mean - m0) / (2.0 * kappa),
);
// 前半と後半の累積器を併合して更新する
let mut merged = OnlineMoments::from_slice(&values[..count / 2], MomentOrder::Second)
    .map_err(|e| e.to_string())?;
let second = OnlineMoments::from_slice(&values[count / 2..], MomentOrder::Second)
    .map_err(|e| e.to_string())?;
merged.merge(&second).map_err(|e| e.to_string())?;
let from_moments = start.update_moments(&merged).map_err(|e| e.to_string())?;
let (rm, rk, ra, rb) = (reference[0], reference[1], reference[2], reference[3]);
let checks = [
    ("1 × 8 のビュー", output[0], (rm, rk, ra, rb)),
    ("2 × 4 のビュー", output[1], (rm, rk, ra, rb)),
    ("頻度の重み 2", output[2], duplicated),
    ("解析的な重み 2", output[3], analytic),
    ("OnlineMoments の併合", Some(from_moments), (rm, rk, ra, rb)),
];
let mut rows = Vec::new();
for (name, result, (cm, ck, ca, cb)) in checks {
    let posterior = result.ok_or("事後分布がない")?;
    let (m, kappa, a, b) = posterior.parameters().map_err(|e| e.to_string())?;
    let gap = [m - cm, kappa - ck, a - ca, b - cb]
        .iter()
        .fold(0.0_f64, |g, d| g.max(d.abs()));
    rows.push((name, m, kappa, a, b, gap));
}
let fixed4 = serde_json::json!({ "fractionDigits": 4 });
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let columns = serde_json::json!([
    { "key": "0", "label": "要求" },
    { "key": "1", "label": "位置 m [Ω]", "type": "number", "format": fixed4 },
    { "key": "2", "label": "精度の倍率 κ [-]", "type": "number", "format": fixed4 },
    { "key": "3", "label": "形状 a [-]", "type": "number", "format": fixed4 },
    { "key": "4", "label": "尺度 b [Ω²]", "type": "number", "format": fixed4 },
    { "key": "5", "label": "検算との差", "type": "number", "format": sci2 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "batch" })
);
```

行列の形を変えた 2 行と `OnlineMoments` の併合は、前のセルの事後分布と丸めの水準（差 $10^{-13}$ 以下）で一致する。
頻度の重み 2 は標本を 2 回並べた更新と一致し、$\kappa = 16$、$a = 7.5$ になる。
解析的な重み 2 では $\kappa = 16$ と $b = 4.455$ Ω² は同じだが、$a$ は観測の個数 8 だけで決まり 3.5 のままである。
解析的な重みは観測の精度を表し、観測の個数を増やさないので、分散の事後分布の形状は変わらない。
情報のある事前分布を前のセルで選ぶと、このセルも同じ事前分布で計算し直し、どの行の差も $10^{-13}$ 以下になる。

## まとめ

二項・Poisson・正規の観測は、`BetaBinomialPrior`、`GammaPoissonPrior`、`NormalInverseGammaPrior` の更新で、観測一つあたり $O(1)$ の足し算だけで事後分布を求められる。
事後分布の要約は `posterior_law()` か `marginals()` で `scioxide-random` の分布を取り出し、`credible_interval` で等裾の信用区間を求める。
評価回数の上限は特殊関数の内部の反復も数え、計算回数の上限を変えるときはこの分を見込む。
非正則な事前分布（Haldane、Jeffreys の Poisson、参照事前分布）は、`is_proper()` で事後分布が正則になったことを確かめてから要約する。
将来の観測の分布は `predictive` で求め、母数の不確かさの分だけ母数を固定した分布より広いことを使って判断する。
参照事前分布の信用区間は t と $\chi^2$ の信頼区間と数値として一致し、Jeffreys の事前分布の区間は Clopper–Pearson や Garwood の正確な限界より狭いので、目的に合わせて区間の意味を選ぶ。
