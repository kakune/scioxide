このページの 3 つの話題はどれも平均や分散のような通常のモーメントでは扱えない標本の要約である。
角度は周期的なので、算術平均は周期の切れ目の位置によって変わる。
確率分布の不確かさ（エントロピー）や 2 つの分布の違い（KL 情報量、Wasserstein 距離）は、標本の値そのものではなく分布関数や密度の汎関数として定義される。
それぞれについて定義、推定量とその偏り、`scioxide-stats` の API を説明し、理論値が分かる分布で推定値を確かめる。

## 円周統計と多次元方向統計量

### 合成ベクトルによる平均方向

角度 $\theta_i$ の算術平均は、周期の切れ目をどこに置くかで変わる。
たとえば $0.1$ と $2\pi-0.1$ はどちらも 0 の近くの方向だが、$[0,2\pi)$ で表した値の算術平均は $\pi$、つまり反対の方向になる。
円周統計では、各角度を単位円上の点 $(\cos\theta_i,\sin\theta_i)$ に写し、その平均の向きと長さで要約する（Mardia と Jupp, 2000）。

重み $w_i\ge0$、重みの和 $W=\sum_iw_i>0$ に対し、平均合成ベクトルの成分を

$$
\bar C=\frac1W\sum_{i=1}^nw_i\cos\theta_i,\qquad \bar S=\frac1W\sum_{i=1}^nw_i\sin\theta_i
$$

とし、平均合成ベクトル長 $\bar R$、平均方向 $\bar\theta$、円周分散 $V$、円周標準偏差 $\sigma_{\mathrm c}$ を

$$
\bar R=\sqrt{\bar C^2+\bar S^2},\qquad \bar\theta=\operatorname{atan2}(\bar S,\bar C),\qquad V=1-\bar R,\qquad \sigma_{\mathrm c}=\sqrt{-2\ln\bar R}
$$

と定義する。
$0\le\bar R\le1$ で、すべての角度が一致すると $\bar R=1$、円周上に均等に散らばると $\bar R$ は 0 に近づく。
$\bar R=0$ のときは平均方向が定まらない。
標準偏差 $\sigma$ の正規分布を円周に巻き付けた分布（wrapped normal）では $\bar R$ の母集団の値が $e^{-\sigma^2/2}$ なので、$\sigma_{\mathrm c}$ は $\sigma$ に一致する。
角度が集中しているときの $\sigma_{\mathrm c}$ は、通常の標準偏差と同じ尺度で読める。

`Statistic::circular(options)` がこの要約を選び、`statistic` で計算すると `StatisticValue::Circular(CircularSummary)` が返る。
`CircularSummary` は平均方向 `mean`、平均合成ベクトル長 `resultant_length`、円周分散 `variance`、円周標準偏差 `standard_deviation` を持つ。
重みは `Unweighted`、`Frequency`、`Mass` を受け付ける。
`CircularOptions` は周期の区間 $[\mathrm{low},\mathrm{high})$ を指定し、値 $x$ を角度 $\theta=2\pi(x-\mathrm{low})/(\mathrm{high}-\mathrm{low})$ に写す。
既定は弧度法の $[0,2\pi)$ で、度なら $[0,360)$、1 日の時刻なら $[0,24)$ を `with_low` と `with_high` で与える。
平均方向は同じ区間 $[\mathrm{low},\mathrm{high})$ で、円周標準偏差は周期と同じ単位で返る。

計算は $O(n)$ で、$\sin$ と $\cos$ の和を補償加算で累積する。
重み付きの項の範囲が `f64` に収まらないときは、指数の範囲を広げた算術でやり直す。
$\bar R$ は 2 乗の和ではなく尺度を合わせた hypot で求めるので、成分の 2 乗がアンダーフローする場合でも 0 にならない。
$\bar R\le8\varepsilon$（$\varepsilon$ はスカラー型の計算機イプシロン）なら平均方向は丸めの誤差で決まるので、`mean` は `None` になる。
`standard_deviation` は $\bar R=0$ のとき `None` である。
重みの和が 0、周期の区間が正で有限でない、角度が NaN・無限大のときはエラーを返す。

### von Mises 分布での理論値

円周上の正規分布にあたる von Mises 分布 $\mathrm{vM}(\mu,\kappa)$ の密度は

$$
f(\theta)=\frac{\exp\{\kappa\cos(\theta-\mu)\}}{2\pi I_0(\kappa)}
$$

で、$I_\nu$ は第 1 種の変形 Bessel 関数、$\kappa\ge0$ は集中度である。
$\mathrm E\cos(\theta-\mu)=A_1(\kappa)=I_1(\kappa)/I_0(\kappa)$、$\mathrm E\sin(\theta-\mu)=0$ なので、母集団の平均合成ベクトル長は $A_1(\kappa)$、平均方向は $\mu$ である。
漸化式 $I_2(\kappa)=I_0(\kappa)-2I_1(\kappa)/\kappa$ から $\mathrm E\cos2(\theta-\mu)=1-2A_1/\kappa$ となり、$\mu=0$ のとき

$$
\operatorname{Var}\cos\theta=1-\frac{A_1}{\kappa}-A_1^2,\qquad \operatorname{Var}\sin\theta=\frac{A_1}{\kappa}
$$

が得られる。
$n$ 個の独立な標本では、$\bar R\approx\bar C+\bar S^2/(2\bar C)$ と展開して、$\bar R$ の期待値と標準誤差（SE）の 1 次の近似

$$
\mathrm E\bar R\approx A_1+\frac{1}{2n\kappa},\qquad \operatorname{SE}(\bar R)\approx\sqrt{\frac{1-A_1/\kappa-A_1^2}{n}},\qquad \operatorname{SE}(\bar\theta)\approx\frac{1}{\sqrt{n\kappa A_1}}
$$

を得る。
$\bar R$ は $\bar S^2$ の分だけ $A_1$ より大きく出る偏りを持ち、その大きさは $1/(2n\kappa)$ である。
この近似は $nA_1^2$ が 1 より十分大きいときに使え、$\kappa$ が小さく $A_1$ が SE と同程度になると、$\bar R$ の分布は Rice 分布に近くなって正規近似が崩れる。

3 次元の単位球面上の von Mises–Fisher 分布 $\mathrm{vMF}(\boldsymbol\mu,\kappa)$ では、$t=\mathbf u^{\mathsf T}\boldsymbol\mu$ の期待値が $A_3(\kappa)=\coth\kappa-1/\kappa$、$\mathrm Et^2=1-2A_3/\kappa$ である。
同じ展開で $\mathrm E\bar R\approx A_3+1/(n\kappa)$、$\operatorname{SE}(\bar R)\approx\sqrt{(1-2A_3/\kappa-A_3^2)/n}$ となる。

### 多次元の方向ベクトル

$\mathbb R^d$ の方向データ（風向の 3 次元ベクトル、結晶の方位、球面上の観測点）は、各ベクトルを単位ベクトル $\mathbf u_i=\mathbf x_i/\lVert\mathbf x_i\rVert$ にして平均合成ベクトル $\bar{\mathbf R}=W^{-1}\sum_iw_i\mathbf u_i$ を作る。
その長さ $\lVert\bar{\mathbf R}\rVert$ が集中の程度、$\bar{\mathbf R}/\lVert\bar{\mathbf R}\rVert$ が平均方向である。
`directional_statistics_into(view, normalization, options, directions, reports, workspace, context)` は、`BatchView::with_coordinates` でベクトルの成分の軸を指定したビューの各一括処理について、平均方向を `directions` に $d$ 成分ずつ、`DirectionalSummary`（長さ `resultant_length` と、方向が定まるかを示す `direction_defined`）を `reports` に書く。
`DirectionNormalization::Normalize` は各ベクトルをあふれずに正規化し、零ベクトルをエラーにする。
`DirectionNormalization::RequireUnit(t)` は $\lvert\lVert\mathbf x\rVert-1\rvert\le t$ を要求してから正規化する。
長さが $8\varepsilon$ 以下なら平均方向はすべて 0 になり、`direction_defined` が偽になる。
作業領域は `DirectionalWorkspace::workspace_requirements(view, options, context)` が返す `DirectionalRequirements` で確保し、各一括処理の計算量は $O(nd)$ である。

### von Mises 標本で理論値と照合する

次のセルは $\mathrm{vM}(0,\kappa)$ から 500 個の角度を引き、$[-\pi,\pi]$ の値を $[0,2\pi)$ に写してから要約する。
算術平均は周期の切れ目のせいで $\pi$ の近くになり、平均方向は 0 の近くになる。
$\bar R$、平均方向、円周標準偏差を、`scioxide-special` の `bessel_i` で求めた $A_1(\kappa)$ からの理論値と SE で比べ、同じ角度を時刻の周期 $[0,24)$ で表したときの平均方向が換算と一致することも確かめる。
さらに $\mathrm{vMF}((0,0,1),\kappa)$ から 500 個の 3 次元ベクトルを引き、`directional_statistics_into` の長さを $A_3(\kappa)$ と比べる。

## エントロピーと情報理論的尺度

### Shannon エントロピーと KL 情報量

離散分布 $P=(p_1,\dots,p_k)$ の Shannon エントロピーと、参照分布 $Q=(q_1,\dots,q_k)$ に対する Kullback–Leibler（KL）情報量は、対数の底 $b>1$ のもとで

$$
H(P)=-\sum_{i:\,p_i>0}p_i\log_bp_i,\qquad D_{\mathrm{KL}}(P\,\Vert\,Q)=\sum_{i:\,p_i>0}p_i\log_b\frac{p_i}{q_i}
$$

と定義する（Cover と Thomas, 2006, §2.1, §2.3）。
底が $e$ なら単位は nat、2 なら bit である。
$0\le H(P)\le\log_bk$ で、上限は一様分布で達する。
$D_{\mathrm{KL}}\ge0$ で、等号は $P=Q$ のときに限る（Gibbs の不等式）。
$D_{\mathrm{KL}}$ は対称でなく三角不等式も満たさないので、距離ではない。
$p_i>0$ で $q_i=0$ の成分があると $D_{\mathrm{KL}}=+\infty$ で、これは $Q$ のもとで起こりえない事象を $P$ が起こすことを表す。

`entropy(p)` は既定の底 $e$ で $H(P)$ を、`relative_entropy(p, q)` は $D_{\mathrm{KL}}(P\Vert Q)$ を返す。
オプション付き形式 `entropy_with_options(p, q, options)` は、`q` に `None` を渡すとエントロピー、`Some(q)` を渡すと KL 情報量を計算し、`EntropyOptions` で底（`with_base`）と質量の扱い（`with_normalization`）を選ぶ。
`MassNormalization::Normalize`（既定）は非負の質量を和で割って確率にし、`MassNormalization::RequireUnit(t)` は和が 1 から $t$ 以内であることを求めてから和で割る。
軸に沿った集約では、セレクター `Statistic::entropy(options)` で同じ量を選ぶ（観測を確率の質量として解釈する）。
計算は $O(k)$ で、和は補償加算で累積し、質量が全体の半分を超える成分では $-\ln p_i$ を $\ln\{1+(1-p_i)/p_i\}$ として計算し、1 に近い $p_i$ でも相対精度を保つ。

結果は拡張実数の値 `InformationValue` で、有限の `Finite(S)`、KL 情報量の発散を表す `PositiveInfinity`、微分エントロピーの推定量で同順位の観測によって間隔が 0 になったことを表す `NegativeInfinity` を区別する。
無限大はあふれではなく数学的に正しい値である。
底が有限で 1 より大きくないとき、`p` と `q` の長さが違うとき、質量が負・NaN・無限大のとき、質量の和が 0 のとき（空の入力を含む）、`RequireUnit` の条件を満たさないときは `InvalidInput` を返す。

### 間隔による微分エントロピーの推定

連続分布の密度 $f$ の微分エントロピーは $h(f)=-\int f(x)\ln f(x)\,dx$ である。
分位点関数 $Q=F^{-1}$ を使うと $h=\int_0^1\ln Q'(u)\,du$ と書け、$Q'(u)$ は順序統計量の間隔で近似できる。
Vasicek（1976）は、整列した標本 $x_{(1)}\le\cdots\le x_{(n)}$ とウインドウの半幅 $m<n/2$ から

$$
\hat h_{\mathrm V}=\frac1n\sum_{i=1}^n\ln\left\{\frac{n}{2m}\left(x_{(i+m)}-x_{(i-m)}\right)\right\}
$$

を作った（添字が範囲を出たときは $x_{(1)}$ と $x_{(n)}$ を使う）。
端では間隔がウインドウの半分しかないのに $2m$ で割るので、$\hat h_{\mathrm V}$ は小さい標本で下に偏る。
`DifferentialEntropyMethod` は次の推定量を選ぶ。

- `Vasicek` は上の式である。
- `Ebrahimi` は端の $2m$ を、実際に使った間隔の数に合わせた $c_im$（$i\le m$ で $c_i=1+(i-1)/m$、$i>n-m$ で $c_i=1+(n-i)/m$、それ以外は 2）に置き換え、端の偏りを減らす（Ebrahimi ら, 1994）。
- `VanEs` は前向きの間隔 $x_{(i+m)}-x_{(i)}$ の対数の平均に、調和数の補正 $\sum_{k=m}^n1/k+\ln\{m/(n+1)\}$ を加える（van Es, 1992）。
- `Correa` は各間隔を、$x_{(i-m)},\dots,x_{(i+m)}$ に対する順位の最小 2 乗回帰の傾きに置き換え、間隔の揺らぎを平滑化する（Correa, 1995）。
- `Auto`（既定）は $n\le10$ で `VanEs`、$n\le1000$ で `Ebrahimi`、それより大きい標本で `Vasicek` を選ぶ。

ウインドウの半幅の既定は $m=\lfloor\sqrt n+1/2\rfloor$ である。
`differential_entropy(values)` は既定の設定で、オプション付き形式 `differential_entropy_with_options(values, options)` は `DifferentialEntropyOptions` の推定量（`with_method`）、ウインドウ（`with_window`）、底（`with_base`）で推定する。
軸に沿った集約のセレクターは `Statistic::differential_entropy(options)` である。
計算は整列の $O(n\log n)$ と推定の $O(n)$（`Correa` は $O(nm)$）で、標本の写しを 1 つ確保する。
空の標本、$0<2m<n$ を満たさないウインドウ（既定のウインドウでは $n\ge5$ が必要）、不正な底、`Correa` の局所回帰の傾きが正でない場合は `InvalidInput`、NaN・無限大は `NonFinite` を返す。
同じ値の観測で間隔が 0 になると、推定値は `NegativeInfinity` になる。
推定量は重みを受け付けない。

10\left\{p\ln(2p)+(1-p)\ln(2(1-p))\right\}

## 1 次元確率距離と最適輸送問題

### Wasserstein-1 距離とエネルギー距離

2 つの確率分布 $\mu,\nu$ の Wasserstein-$p$ 距離は、$\mu$ を $\nu$ へ移す結合（同時分布）$\pi$ の中で輸送費用を最小にした値

$$
W_p(\mu,\nu)=\left(\inf_{\pi\in\Pi(\mu,\nu)}\int\lVert x-y\rVert^p\,d\pi(x,y)\right)^{1/p}
$$

である（Villani, 2009）。
$p=1$ の $W_1$ は earth mover's distance とも呼ばれる。
実数直線上では、最適な結合は分位点どうしを組にする単調な結合で、分布関数 $F,G$ を使って

$$
W_1(F,G)=\int_{-\infty}^{\infty}\lvert F(x)-G(x)\rvert\,dx=\int_0^1\lvert F^{-1}(u)-G^{-1}(u)\rvert\,du
$$

と書ける（Vallender, 1973）。
エネルギー距離（Székely と Rizzo, 2013）は、$X,X'\sim F$、$Y,Y'\sim G$ を独立として

$$
D(F,G)^2=2\,\mathrm E\lvert X-Y\rvert-\mathrm E\lvert X-X'\rvert-\mathrm E\lvert Y-Y'\rvert=2\int_{-\infty}^\infty\{F(x)-G(x)\}^2\,dx
$$

で定義する。
$D=0$ と $F=G$ は同値で、$D$ は分布の間の距離になる。

正規分布 $N(0,1)$ と $N(\Delta,\sigma^2)$ では、$F^{-1}(u)=z_u$、$G^{-1}(u)=\Delta+\sigma z_u$ なので $W_1=\mathrm E\lvert\Delta+(\sigma-1)Z\rvert$（$Z\sim N(0,1)$）である。
$a+bZ$ の絶対値の期待値（折り返し正規分布の平均）

$$
\mathrm E\lvert a+bZ\rvert=b\sqrt{2/\pi}\,e^{-a^2/(2b^2)}+a\{1-2\Phi(-a/b)\}\qquad(b>0)
$$

を使うと、$W_1$ は $a=\Delta$、$b=\lvert\sigma-1\rvert$（$b=0$ なら $\lvert\Delta\rvert$）で求まる。
エネルギー距離は $X-Y\sim N(-\Delta,1+\sigma^2)$、$\mathrm E\lvert X-X'\rvert=2/\sqrt\pi$、$\mathrm E\lvert Y-Y'\rvert=2\sigma/\sqrt\pi$ から求まる。
参考に、$W_2=\sqrt{\Delta^2+(\sigma-1)^2}$ である。

### 経験分布の距離と偏り

`distribution_distance(left, right, metric)` は、2 つの標本の経験分布の間の距離を、`DistributionDistance::Wasserstein`（$W_1$）か `DistributionDistance::Energy`（$D$）で計算する。
2 つの標本をまとめて整列し、隣り合う点の間で階段関数 $F_n-G_m$ が一定であることを使って積分を区間ごとの和として厳密に求める。
計算量は $O((n+m)\log(n+m))$ で、和は補償加算で累積する。
重みや欠測の方針はオプション付き形式 `distribution_distance_with_options(left, left_weights, right, right_weights, metric, options)` で与え、各側に重みなし・頻度・相対質量を独立に使える。
重みは和で割って確率にし、重み 0 の点は無視する。
整列の領域を再利用するときは、`DistanceWorkspace::workspace_requirements(n, m, options)` が返す `DistanceRequirements` で作業領域を確保し、`DistanceWorkspace::evaluate` を呼ぶ。
重みの長さの不一致、負・非有限の重み、総重み 0（空の標本を含む）、正の重みを持つ点の NaN・無限大は `InvalidInput`、整列の領域が上限を超えると `ResourceLimit` を返す。

経験分布の距離は母集団の距離の推定量として偏りを持つ。
エネルギー距離の 2 乗では、$n^{-2}\sum_{i,j}\lvert x_i-x_j\rvert$ が $i=j$ の 0 を含むので、期待値が

$$
\mathrm E\hat D^2=D^2+\frac{\mathrm E\lvert X-X'\rvert}{n}+\frac{\mathrm E\lvert Y-Y'\rvert}{m}
$$

となる。
$W_1$ の偏りに簡単な式はないが、各点で $\mathrm E\lvert F_n-G_m\rvert\ge\lvert F-G\rvert$ なので偏りは非負で、2 つの分布が重なる部分では $O(n^{-1/2})$ の大きさになる。
$F=G$ でも $\hat W_1$ は 0 にならない。

`scioxide-stats` は 1 次元の $W_p$（$p\ne1$）を提供しない。
同じ大きさ $n$ の 2 つの重みなし標本なら、整列した値を組にした $\bigl(n^{-1}\sum_i\lvert x_{(i)}-y_{(i)}\rvert^p\bigr)^{1/p}$ が経験分布の間の $W_p$ に等しいので、整列した標本から直接計算できる。

### 多次元の最適輸送

$\mathbb R^d$ の点群 $\{\mathbf x_i\}$（確率 $a_i$）と $\{\mathbf y_j\}$（確率 $b_j$）の間の $W_1$ は、計算コスト $c_{ij}=\lVert\mathbf x_i-\mathbf y_j\rVert_2$ の輸送問題という線形計画

$$
\min_{\pi\ge0}\sum_{ij}c_{ij}\pi_{ij}\quad\text{subject to}\quad\sum_j\pi_{ij}=a_i,\quad\sum_i\pi_{ij}=b_j
$$

の最適値である。
その双対問題は $u_i+v_j\le c_{ij}$ のもとで $\sum_ia_iu_i+\sum_jb_jv_j$ を最大にし、最適値は主問題と一致する。

`wasserstein_distance_nd(left, right, admission, options, solver)` は、各 1 個の一括処理を持つ 2 つの `BatchView`（`with_coordinates` で成分の軸を指定する）から費用行列を $O(nmd)$ で作り、利用者が渡す `TransportSolver` を 1 回呼ぶ。
`scioxide-stats` 自身は線形計画の解法を持たず、たとえば `scioxide-optimize` の `SimplexTransportSolver`（疎な改訂単体法）を渡せる。
ソルバーは `TransportProblem`（確率 `source`・`target`、正規化した計算コスト `costs`、尺度 `cost_scale`）を受け取り、`TransportCandidate` の結合と双対変数に解を書いて、`StatsTermination` の `Converged`・`BudgetExhausted`・`Stopped` のどれかを返す。
計算コストは座標の最大の絶対値 $s$ で割って正規化し、距離は $s$ 倍して元の単位に戻す。
返った解は $O(nm)$ で独立に検証され、`TransportResult` に周辺制約の残差 `marginal_residual`、双対制約の違反 `dual_residual`、双対ギャップ `normalized_duality_gap` が入る。
`Converged` と提示した解は、`TransportOptions` の許容誤差（周辺制約は `feasibility`、双対の違反と双対ギャップは `optimality`）を満たさなければ `InvalidInput` になる。
`distance` は結合が周辺制約を満たすときだけ `Some` で、`Converged` でない場合は最小とは限らない結合の計算コストである。
作業領域を再利用するときは `TransportWorkspace::reserve(rows, cols, options)` で $O(nm)$ の領域を確保し、スコープ付き API `wasserstein_distance_nd_scoped` に渡す。
スコープ付き API はソルバーの呼び出しを親の計算の評価 1 回として数え、計算回数の上限がなければ距離なしの `BudgetExhausted` か `Stopped` を返す。

### 閉形式と平行移動で確かめる

次のセルは $N(0,1)$ と $N(\Delta,\sigma^2)$ から 200 個ずつ引いた標本の $\hat W_1$ と $\hat D^2$ を 40 回計算し、平均と SE を閉形式と比べる。
$\hat D^2$ は偏りを含む期待値 $D^2+2(1+\sigma)/(n\sqrt\pi)$ とも比べる。
後半は `wasserstein_distance_nd` と `SimplexTransportSolver` で、2 次元の 10 点の点群とそれを $(\Delta,0)$ だけ平行移動した点群の $W_1$ を求める。
平行移動 $T(\mathbf x)=\mathbf x+\mathbf t$ では、移動そのものが計算コスト $\lVert\mathbf t\rVert$ の結合を与え、1-Lipschitz 関数 $f(\mathbf x)=\mathbf t^{\mathsf T}\mathbf x/\lVert\mathbf t\rVert$ に対する Kantorovich–Rubinstein の双対表現から下界も $\lVert\mathbf t\rVert$ になるので、$W_1=\lVert\mathbf t\rVert=\Delta$ が厳密に成り立つ。
さらに 1 次元の 10 点どうしで、線形計画の $W_1$ が `distribution_distance` の値と一致することを確かめる。

```rust
//| id: stats-circular-information-and-distances-api-3
//| ref: stats-circular-information-and-distances-api-3
//| title: 正規分布の間の Wasserstein 距離とエネルギー距離を閉形式と照合する
//| run: reactive
//| crates: [scioxide-core, scioxide-optimize, scioxide-random, scioxide-stats]
//| inputs:
//|   shift: {"type":"range","label":"平均の差 Δ [-]","description":"2 つ目の分布 N(Δ, σ²) の平均。2 次元の点群の平行移動の量にも使う。","min":0,"max":3,"step":0.1,"value":1}
//|   scale: {"type":"range","label":"2 つ目の標準偏差 σ [-]","description":"1 から離れるほど W₁ に形の違いの寄与が加わる。","min":0.5,"max":2,"step":0.1,"value":1}
//|   sampling_seed: {"type":"integer","label":"乱数のシード","min":0,"max":100000,"value":31}
//| cases:
//|   - {"id":"same-law","label":"Δ = 0","description":"同じ分布どうしでも経験分布の W₁ は 0 にならず、正の偏りが SE の何倍にもなる。","inputs":{"shift":0}}
//|   - {"id":"wide","label":"σ = 2","description":"平均と広がりの両方が違う 2 つの分布。","inputs":{"scale":2}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"distances","path":"/rows/0/3","approx":{"value":1.0,"atol":1e-12}}
//|       - {"artifact":"transport","path":"/rows/0/4","range":{"min":0,"max":1e-9}}
//|       - {"artifact":"transport","path":"/rows/1/4","range":{"min":0,"max":1e-9}}
//|       - {"path":"/outputs/3/state","equals":"satisfied"}
//|   - case: same-law
//|     expect:
//|       - {"artifact":"distances","path":"/rows/0/3","approx":{"value":0,"atol":1e-12}}
use scioxide_core::{RealScalar, StridedLayout};
use scioxide_optimize::{SimplexSolver, SimplexTransportSolver};
use scioxide_random::{Cdf, Distribution, Normal, SeedableRng, SplitMix64};
use scioxide_stats::{
    Axis, BatchView, DistributionDistance, StatisticsOptions, TransportOptions,
    distribution_distance, mean, sample_standard_deviation, wasserstein_distance_nd,
};

let (n, replicates) = (200_usize, 40_usize);
let mut rng = SplitMix64::from_seed(sampling_seed as u64);
let standard = Normal::<f64>::new(0.0, 1.0).map_err(|e| e.to_string())?;
let mut draw = |count: usize| -> Result<Vec<f64>, String> {
    (0..count)
        .map(|_| standard.sample(&mut rng).map_err(|e| e.to_string()))
        .collect()
};
let (mut w1, mut energy2) = (Vec::new(), Vec::new());
for _ in 0..replicates {
    let x = draw(n)?;
    let y: Vec<f64> = draw(n)?.iter().map(|z| shift + scale * z).collect();
    w1.push(
        distribution_distance(&x, &y, DistributionDistance::Wasserstein)
            .map_err(|e| e.to_string())?,
    );
    let d = distribution_distance(&x, &y, DistributionDistance::Energy)
        .map_err(|e| e.to_string())?;
    energy2.push(d * d);
}

// 閉形式（参照値）: E|a + bZ| = b√(2/π) exp(−a²/(2b²)) + a(1 − 2Φ(−a/b))。
let folded = |a: f64, b: f64| -> Result<f64, String> {
    if b == 0.0 {
        return Ok(a.abs());
    }
    let tail = standard.cdf(-a / b).map_err(|e| e.to_string())?;
    Ok(
        b * (2.0 / core::f64::consts::PI).sqrt() * (-a * a / (2.0 * b * b)).exp()
            + a * (1.0 - 2.0 * tail),
    )
};
let root_pi = core::f64::consts::PI.sqrt();
let w1_exact = folded(shift, (scale - 1.0).abs())?;
let energy2_exact =
    2.0 * folded(shift, (1.0 + scale * scale).sqrt())? - 2.0 / root_pi - 2.0 * scale / root_pi;
let energy2_expected = energy2_exact + 2.0 * (1.0 + scale) / (root_pi * n as f64);
let summary = |values: &[f64]| -> Result<(f64, f64), String> {
    let se = sample_standard_deviation(values).map_err(|e| e.to_string())?
        / RealScalar::sqrt(values.len() as f64);
    Ok((mean(values).map_err(|e| e.to_string())?, se))
};
let (w1_mean, w1_se) = summary(&w1)?;
let (e2_mean, e2_se) = summary(&energy2)?;
let distances = vec![
    ("W₁", w1_mean, w1_se, w1_exact, (w1_mean - w1_exact) / w1_se),
    (
        "D²（母集団の値）",
        e2_mean,
        e2_se,
        energy2_exact,
        (e2_mean - energy2_exact) / e2_se,
    ),
    (
        "D²（偏りを含む期待値）",
        e2_mean,
        e2_se,
        energy2_expected,
        (e2_mean - energy2_expected) / e2_se,
    ),
];
let fixed4 = serde_json::json!({ "fractionDigits": 4 });
let columns = serde_json::json!([
    { "key": "0", "label": "量" },
    { "key": "1", "label": "40 回の平均 [-]", "type": "number", "format": fixed4 },
    { "key": "2", "label": "平均の SE [-]", "type": "number", "format": fixed4 },
    { "key": "3", "label": "閉形式 [-]", "type": "number", "format": fixed4 },
    {
        "key": "4",
        "label": "(平均 − 閉形式)/SE [-]",
        "type": "number",
        "format": { "fractionDigits": 1 }
    }
]);
emit_table_with_columns!(
    columns,
    distances,
    metadata = serde_json::json!({ "id": "distances" })
);

// 2 次元の 10 点（行優先 10 × 2）と、それを (Δ, 0) だけ平行移動した点群。
let k = 10_usize;
let left = draw(2 * k)?;
let right: Vec<f64> = left.chunks(2).flat_map(|p| [p[0] + shift, p[1]]).collect();
let (shape, strides) = ([k, 2_usize], [2_usize, 1_usize]);
let planar = StridedLayout::new(&shape, &strides).map_err(|e| e.to_string())?;
let left_view = BatchView::new(&left, planar, Axis::Index(0))
    .and_then(|v| v.with_coordinates(Axis::Index(1)))
    .map_err(|e| e.to_string())?;
let right_view = BatchView::new(&right, planar, Axis::Index(0))
    .and_then(|v| v.with_coordinates(Axis::Index(1)))
    .map_err(|e| e.to_string())?;
let bytes =
    SimplexTransportSolver::<f64>::required_model_bytes(k, k).map_err(|e| e.to_string())?;
let mut solver = SimplexTransportSolver::new(SimplexSolver::default(), k * k, bytes);
let options = StatisticsOptions::new();
let shifted = wasserstein_distance_nd(
    left_view,
    right_view,
    options,
    TransportOptions::new(),
    &mut solver,
)
.map_err(|e| e.to_string())?;
// 1 次元の 10 点どうし。線形計画の値と整列による値を比べる。
let x = draw(k)?;
let y: Vec<f64> = draw(k)?.iter().map(|z| shift + scale * z).collect();
let line = StridedLayout::new(&shape[..1], &strides[1..]).map_err(|e| e.to_string())?;
let x_view = BatchView::new(&x, line, Axis::Index(0)).map_err(|e| e.to_string())?;
let y_view = BatchView::new(&y, line, Axis::Index(0)).map_err(|e| e.to_string())?;
let linear = wasserstein_distance_nd(
    x_view,
    y_view,
    options,
    TransportOptions::new(),
    &mut solver,
)
.map_err(|e| e.to_string())?;
let sorted = distribution_distance(&x, &y, DistributionDistance::Wasserstein)
    .map_err(|e| e.to_string())?;
let mut transport = Vec::new();
let mut solved = true;
for (name, result, reference) in [
    ("2 次元の平行移動", shifted, shift),
    ("1 次元（整列との比較）", linear, sorted),
] {
    solved &= result.termination.is_success();
    let gap = result.distance.map(|d| (d - reference).abs());
    let duality = result.original_duality_gap().map_err(|e| e.to_string())?;
    transport.push((
        name,
        format!("{:?}", result.termination),
        result.distance,
        reference,
        gap,
        result.marginal_residual,
        duality,
    ));
}
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let columns = serde_json::json!([
    { "key": "0", "label": "検算" },
    { "key": "1", "label": "終了状態" },
    {
        "key": "2",
        "label": "W₁（線形計画）[-]",
        "type": "number",
        "format": { "fractionDigits": 6 },
        "nullText": "なし"
    },
    { "key": "3", "label": "基準値 [-]", "type": "number", "format": { "fractionDigits": 6 } },
    { "key": "4", "label": "差 [-]", "type": "number", "format": sci2, "nullText": "なし" },
    { "key": "5", "label": "周辺制約の残差 [-]", "type": "number", "format": sci2 },
    {
        "key": "6",
        "label": "双対ギャップ [-]",
        "type": "number",
        "format": sci2,
        "nullText": "なし"
    }
]);
emit_table_with_columns!(
    columns,
    transport,
    metadata = serde_json::json!({ "id": "transport" })
);

let curve: Vec<[f64; 2]> = (0..=30)
    .map(|i| {
        let delta = 0.1 * f64::from(i);
        folded(delta, (scale - 1.0).abs()).map(|w| [delta, w])
    })
    .collect::<Result<_, _>>()?;
emit_chart!(
    serde_json::json!({
        "kind": "xy",
        "dataZoom": true,
        "tooltip": true,
        "xLabel": "平均の差 Δ [-]",
        "yLabel": "Wasserstein-1 距離 W₁ [-]",
        "layers": [
            {
                "id": "exact",
                "kind": "line",
                "name": "閉形式 E|Δ + (σ − 1)Z|",
                "points": curve,
                "style": { "lineType": "dashed", "showSymbol": false }
            },
            {
                "id": "estimate",
                "kind": "scatter",
                "name": "経験分布の W₁（40 回の平均）",
                "points": [[shift, w1_mean]]
            }
        ]
    }),
    metadata = serde_json::json!({ "id": "wasserstein" })
);
let outcome = if solved {
    Outcome::satisfied("2 つの輸送問題が収束し、解の検証を通った")
} else {
    Outcome::partial("輸送問題の求解が収束せずに止まった")
};
emit_outcome!(
    outcome
        .status(format!("{:?}", shifted.termination))
        .diagnostic("周辺制約の残差", shifted.marginal_residual, None)
);
```

既定の $\Delta=1$、$\sigma=1$ では、$\hat W_1$ の 40 回の平均 1.0142 と閉形式 1 の差は SE 0.0153 の 0.9 倍である。
$\hat D^2$ の平均 0.5726 は母集団の値 0.5418 より SE の 2.1 倍大きく、偏りを含む期待値 0.5531 との差は SE の 1.3 倍である。
$\Delta=0$ では母集団の $W_1$ と $D^2$ は 0 だが、経験分布の $\hat W_1$ は 0.123（SE の 17 倍）になり、$\hat D^2=0.0105$ は偏りの式の値 0.0113 と SE の 0.6 倍の差で合う。
$\sigma=2$ では $W_1$ の閉形式が 1.1666 になり、平均 1.1950 との差は SE の 1.3 倍である。
線形計画の $W_1$ は、2 次元では平行移動の量 $\Delta$ と、1 次元では整列による値と $10^{-16}$ 程度で一致し、周辺制約の残差と双対ギャップも $10^{-16}$ 以下である。

## まとめ

角度は単位円上の点に写して平均し、平均合成ベクトル長 $\bar R$ と平均方向を `Statistic::circular` で、$\mathbb R^d$ の方向ベクトルは `directional_statistics_into` で要約する。
von Mises 標本の $\bar R$ は $A_1(\kappa)=I_1/I_0$ より $1/(2n\kappa)$ だけ大きく出るので、理論値との比較ではこの偏りと SE を合わせて見る。
離散分布のエントロピーと KL 情報量は `entropy`・`relative_entropy` と `Statistic::entropy` で求め、発散と同順位による無限大は `InformationValue` の列挙子で区別される。
微分エントロピーの間隔推定量は小さい標本で下に偏り、端の間隔の数を補正した `Ebrahimi` で偏りが減るが、$n=10$ では `VanEs` の偏りが最も小さい。
1 次元の $W_1$ とエネルギー距離は `distribution_distance` で経験分布から厳密に計算でき、多次元の $W_1$ は `TransportSolver` を渡した `wasserstein_distance_nd` が解を検証したうえで返す。
