仮説検定は、帰無仮説 $H_0$ のもとで観測した統計量がどれほど極端かを確率で表し、データが $H_0$ と矛盾するかを判断する手続きである。
その確率（p 値）は統計量の帰無分布から求める。
帰無分布を導くときには、観測の独立性、正規性、等分散性などを前提にする。
前提が成り立たないと、名目の有意水準 $\alpha$ と実際に $H_0$ を棄却する確率（実際の第 1 種の過誤率、以下では実際の棄却率と呼ぶ）がずれる。
このずれを較正の誤差と呼ぶ。

このページは scioxide-stats の古典的検定（結果型 `ClassicalTestResult` を返す検定）について、前提、統計量、帰無分布の求め方、`TestCalibration` の `Auto` が選ぶ帰無分布、効果量と区間を説明し、セルで実際の棄却率を測って較正の誤差を確かめる。
分布の形・正規性・分散の等質性の検定は[分布適合度検定と分散等質性検定](../distribution-and-variance-tests/)、分割表の検定と多重比較は[分割表検定・多重比較・p 値統合](../contingency-and-multiple-testing/)で扱う。

## 検定の結果と共通の設定

### 結果に含まれる量

古典的検定はどれも次の量を区別して `ClassicalTestResult<S>` に入れて返す。

| 量 | 定義 | 取り出し方 |
|---|---|---|
| 検定統計量 | 帰無分布と比べる標本の関数。向き（大きいほどどちらの群が大きいか）は各検定が決めている | `statistic()` |
| p 値 | $H_0$ のもとで、観測値と同じかそれより極端な統計量が出る確率。極端の向きは対立仮説が決める | `p_value()`（`f64`、$[0, 1]$） |
| 効果量 | 母集団の差や関連の大きさの推定値。標本の大きさが増えても縮まない量で、p 値とは別に返す | `effect()`（`Option<(ClassicalEffect, S)>`） |
| 信頼区間 | 効果量の両側区間。統計的な推定で、数値的な包含区間ではない | `interval()` と `confidence()`（区間がある検定だけ `Some`） |
| 使った帰無分布 | p 値をどの分布から求めたか | `method()`（`ClassicalMethod`） |
| 仮定した標本設計 | 検定が前提にしている観測の取り方 | `sample_policy()`（`TestSamplePolicy`） |

`ClassicalEffect` は効果量の意味を表し、`MeanDifference`（平均の差、または平均と帰無値の差）、`Proportion`（成功確率）、`Quantile`（母集団の分位点）、`RateDifference`（率の差）、`Association`（相関・関連の係数）、`Superiority`（優越確率 $P(X > Y) + P(X = Y)/2$）、`RankBiserial`（対応のある順位二系列相関 $(W^+ - W^-)/(W^+ + W^-)$）のどれかである。
`ClassicalMethod` は実際に使った帰無分布で、`StudentT { degrees_of_freedom }`、`Normal`、`Exact`、`PoissonE`、`Permutation { exact, replicates }` のどれかである。
このほか、`retained()` は検定に使った標本の大きさ、`omitted()` は欠測などで除いた観測の数、`omitted_null_mass()` は和を打ち切った帰無確率（Poisson の E 検定だけが 0 以外を返す）、`missing_policy()` と `non_finite_policy()` は入力に当てた欠測・非有限値の方針を返す。
`into_parts()` はこれらを上の順に 1 つのタプルへ分ける。

### 標本設計

`TestSamplePolicy` は、検定が前提にしている標本設計を記録する列挙型である。
`Independent`（独立な 1 標本）、`IndependentGroups`（独立な 2 群）、`Paired`（対になった観測の独立な行）、`Blocks`（処理を繰り返した独立な完全ブロック）、`Counts`（事象の数とその試行数・観測量）、`Summary`（平均・不偏分散・標本の大きさの要約）がある。
設計は検定の仮定であり、scioxide-stats はデータがその設計から得られたかを確かめない。
たとえば対応のあるデータに `t_test_independent` を使っても、結果の `sample_policy()` は `IndependentGroups` を返し、p 値は対の相関を無視した値になる。

### ワンショット呼び出しとオプション付き形式

各検定には、標本だけを受け取るワンショット関数（`t_test_independent(&x, &y)` など）と、設定を最後に受け取るオプション付き形式 `_with_options` がある（[呼び出しの形](oxref:stats-execution-forms)）。
ワンショット関数はオプション付き形式に既定の設定を渡したものと同じ計算をする。
古典的検定のオプション付き形式が受け取る設定は、次の 3 種類に分かれる。

- `ClassicalOptions` だけを受け取るオプション付き形式は、`t_test_one_sample_with_options`、`t_test_paired_with_options`、`mann_whitney_test_with_options`、`rank_sum_test_with_options`、`bws_test_with_options`、`page_trend_test_with_options`、`pearson_test_with_options`、`point_biserial_test_with_options`、`spearman_test_with_options`、`chatterjee_test_with_options`、`somers_test_with_options`、`somers_contingency_test_with_options`、`binomial_test_with_options`、`quantile_test_with_options`、`poisson_means_test_with_options` である。
  ワンショット呼び出しとの違いは `ClassicalOptions` の値だけで、変えられるのは対立仮説、較正、区間の信頼水準、正確な計算の上限、作業領域の上限、連続性補正である。
- 手法の選択と `ClassicalOptions` を受け取るオプション付き形式は、`t_test_independent_with_options` と `t_test_from_summaries_with_options`（分散の扱い `TTestVariance`）、`wilcoxon_test_with_options`（零の差の扱い `SignedRankZeros`）、`brunner_munzel_test_with_options`（参照分布 `BrunnerMunzelCalibration`）である。
  `kendall_test` はワンショット呼び出しでも正規化の型 `KendallVariant` を受け取り、`kendall_test_with_options` はそれに `ClassicalOptions` を加える。
- `kruskal_wallis_test_with_options` と `friedman_test_with_options` は `ClassicalOptions` ではなく `StatisticsOptions` を受け取る。
  使うのは作業領域のバイト数の上限 `max_bytes()` だけで、対立仮説と較正は選べない（帰無分布はカイ二乗近似だけ）。

`ClassicalOptions` の既定値と、変えたときに何が変わるかを次の表にまとめる。
フィールドは非公開で、`with_*` で値を変えた新しい設定を作る。

| 設定 | 既定値 | 意味 |
|---|---|---|
| `with_alternative`（`TestAlternative`） | `TwoSided` | 対立仮説の向き。`Less` は下側、`Greater` は上側の裾を p 値にし、`TwoSided` は $\min(1, 2\min(p_-, p_+))$ にする。Chatterjee と Page の検定は `Greater` しか受け付けず、ワンショット呼び出しも `Greater` を使う |
| `with_calibration`（`TestCalibration`） | `Auto` | 帰無分布の求め方（次の節） |
| `with_confidence`（`ConfidenceProbability`） | 0.95 | 効果量の両側区間の被覆確率。p 値には影響しない |
| `with_max_work` | 100 000 | 正確な帰無分布で数え上げる状態（ラベルの割り当てや動的計画法の更新）の上限。Poisson の E 検定では同時確率を評価する回数の上限 |
| `with_max_workspace_bytes` | `usize::MAX`（上限なし） | 正確な分布と置換分布の作業領域のバイト数の上限 |
| `with_continuity`（`ContinuityCorrection`） | `HalfUnit` | 離散的な順位統計量を正規近似するときの連続性補正。`None` で補正しない |

## 帰無分布の求め方と較正

### 正確な帰無分布・漸近近似・連続性補正

p 値の求め方は 3 通りある。

- 正確な帰無分布は、$H_0$ のもとで等確率になるラベルの割り当て（2 群の入れ替え、対の符号の反転、対の組み合わせの並べ替え、ブロック内の順位の並べ替え）をすべて数え上げて得る。
  観測した順位（同順位があれば中間順位）のまま数え上げるので、同順位があっても正確である。
  ただし状態の数は標本の大きさとともに組合せ的に増える。
- 漸近近似は、大標本で統計量が従う分布（正規分布、Student の t 分布、カイ二乗分布）で p 値を求める。
  計算量は小さいが、小標本では実際の棄却率が $\alpha$ からずれる。
- 置換による p 値は、ラベルを乱数で入れ替えた標本で統計量の分布を作る（`classical_permutation_test`、[リサンプリング](../resampling/)）。
  Monte Carlo の誤差を持つが、正確な数え上げが大きすぎる場合や、漸近分布がない統計量に使える。

離散的な順位統計量 $T$ を正規近似するときは、中心からの距離を半単位縮めてから標準化する連続性補正を使う。
scioxide-stats は Mann–Whitney 検定と Wilcoxon の符号付き順位検定の正規近似で、`ContinuityCorrection::HalfUnit` のときに $|T - E T|$ から 0.5 を引く（片側では裾の向きに 0.5 ずらす）。

### Auto の選び方

`TestCalibration` は要求する帰無分布の求め方で、次の 3 つがある。

- `Auto`（既定）は、正確な帰無分布の状態数が `max_work` 以下なら正確な分布を使い、超えれば漸近近似を使う。
  手法が 1 つしかない検定ではその手法を使う。
- `Exact` は正確な分布を要求する。
  状態数が `max_work` を超えると `ConvergenceFailure` を返し、正確な分布を持たない検定は `InvalidInput` を返す。
- `Asymptotic` は各検定が文書化した漸近分布または解析的な参照分布を要求する。
  それを持たない検定は `InvalidInput` を返す。

指定した手法を使えない検定は、別の手法に切り替えずにエラーを返す。
実際に使った手法は結果の `method()` で確かめる。
各検定の状態数と、既定の `max_work = 100 000` で正確な分布を使う大きさを次の表にまとめる（$n$、$m$ は各群の大きさ、$b$ はブロック数、$k$ は処理数）。

| 関数 | 正確な分布の状態数 | 既定の上限で正確になる大きさ | Auto で上限を超えたとき | `Exact` | `Asymptotic` | 効果量 / 区間 |
|---|---|---|---|---|---|---|
| `t_test_one_sample`・`t_test_paired` | （Student の t 分布） | 常に t 分布 | — | 指定を使わない | 指定を使わない | `MeanDifference` / t 区間 |
| `t_test_independent`（`Pooled`） | （Student の t 分布） | 常に t 分布 | — | t 分布 | t 分布 | `MeanDifference` / t 区間 |
| `t_test_independent`（`Welch`） | （近似の t 分布） | 常に近似 | — | `InvalidInput` | t 分布 | `MeanDifference` / t 区間 |
| `mann_whitney_test` | $\binom{n+m}{n}$ | $n = m \le 9$ | 正規近似（同順位補正、連続性補正） | 正確 | 正規近似 | `Superiority` / なし |
| `rank_sum_test` | — | 常に正規近似 | — | `InvalidInput` | 正規近似 | `Superiority` / なし |
| `wilcoxon_test` | $K n$（$K$ は 2 倍した順位の和） | 同順位がなければ $n \le 46$ | 正規近似（連続性補正） | 正確 | 正規近似 | `RankBiserial` / なし |
| `brunner_munzel_test` | — | 常に近似 | — | `InvalidInput` | `BrunnerMunzelCalibration` の分布 | `Superiority` / なし |
| `bws_test` | $\binom{n+m}{n}$ | $n = m \le 9$ | `ConvergenceFailure`（近似を持たない） | 正確 | `InvalidInput` | なし / なし |
| `pearson_test`・`point_biserial_test` | （Student の t 分布、`Exact` とレポート） | 常に t 分布 | — | 指定を使わない | 指定を使わない | `Association` / Fisher の z 区間（$n > 3$） |
| `spearman_test` | $n!$ | $n \le 8$ | t 近似 | 正確 | t 近似 | `Association` / なし |
| `kendall_test` | $n!$ | $n \le 8$ | 正規近似（同順位補正） | 正確 | 正規近似 | `Association` / なし |
| `chatterjee_test` | $n!$ | $n \le 8$ | 正規近似 | 正確 | 正規近似 | `Association` / なし |
| `somers_test`・`somers_contingency_test` | — | 常に正規近似 | — | `InvalidInput` | 正規近似 | `Association` / なし |
| `page_trend_test` | $(k!)^b$ | $k = 3$ なら $b \le 6$ | 正規近似（同順位補正） | 正確 | 正規近似 | なし / なし |
| `binomial_test` | （二項分布の裾） | 常に正確 | — | 正確 | `InvalidInput` | `Proportion` / Clopper–Pearson 区間 |
| `quantile_test` | （二項分布の裾） | 常に正確 | — | 正確 | `InvalidInput` | `Quantile` / 順序統計量の区間 |
| `poisson_means_test` | 和を取る格子の点数 | — | `ConvergenceFailure` | `InvalidInput` | E 検定 | `RateDifference` / なし |
| `kruskal_wallis_test`・`friedman_test` | — | 常にカイ二乗近似 | — | （選べない） | （選べない） | なし（`GroupTest` を返す） |

「指定を使わない」検定はどの `TestCalibration` を渡しても同じ参照分布を使う。
正規標本では t 分布が正確な帰無分布なので、`Exact` を拒む理由がないためである。
状態数の上限は計算時間の上限でもある。
Spearman、Kendall、Chatterjee の正確な分布は $n!$ 通りの組み合わせのそれぞれで統計量を計算するので、$n = 9$ で $9! = 362\,880$ 通りになり、既定の上限を超える。

次のセルは、同じ乱数のデータ（$n$ 組の対 $(x_i, y_i)$）に 18 個の検定を 3 通りの較正で当て、`Auto` が選んだ帰無分布と、`Exact`・`Asymptotic` を指定したときの p 値またはエラーの種類を並べる。
入力は標本の大きさ $n$ と乱数のシードである。
$n$ を 9 にすると $n!$ が上限を超え、Spearman・Kendall・Chatterjee・Page の `Auto` が漸近近似に切り替わる。
$n$ を 10 以上にすると $\binom{2n}{n}$ が上限を超え、Mann–Whitney 検定は正規近似に切り替わり、BWS 検定は近似を持たないので `Auto` でもエラーになる。

//|   seed: {"type":"integer","label":"乱数のシード","min":0,"max":100000,"value":7}
//| cases:
//|   - {"id":"factorial-limit","label":"n = 9","description":"n! が max_work を超え、順位相関と Page の検定が漸近近似に切り替わる。","inputs":{"sample_size":9}}

//|   - case: default
//|     expect:
//|       - {"artifact":"calibration","path":"/rows/11/3","approx":{"value":0.1361111111111111,"rtol":1e-12}}

//|   - case: binomial-limit
//|     expect:
//|       - {"artifact":"calibration","path":"/rows/3/2","equals":"Normal"}

## Student および Welch の t 検定族

### 統計量と帰無分布

1 標本の t 検定は、独立な観測 $x_1, \dots, x_n$ が正規分布 $N(\mu, \sigma^2)$ に従うと仮定し、$H_0: \mu = \mu_0$ を検定する。
標本平均 $\bar x$ と不偏分散 $s^2 = \sum_i (x_i - \bar x)^2/(n-1)$ から

$$
t = \frac{\bar x - \mu_0}{s/\sqrt{n}}, \qquad \nu = n - 1
$$

を作ると、$H_0$ のもとで $t$ は自由度 $\nu$ の Student の t 分布に正確に従う。
`t_test_one_sample(x, null_mean)` がこの検定で、効果量は $\bar x - \mu_0$、区間は $\bar x - \mu_0 \pm t_{\nu,\,1-\gamma/2}\, s/\sqrt n$（$1 - \gamma$ は信頼水準）である。
対応のある 2 標本の検定 `t_test_paired(x, y)` は、差 $d_i = x_i - y_i$ に 1 標本の検定を当てたもので、差は拡張した指数範囲で作るので桁あふれしない。

独立な 2 標本 $X = (x_1, \dots, x_n)$ と $Y = (y_1, \dots, y_m)$ の平均の差には `t_test_independent` を使う。
分散が等しいと仮定しない Welch の検定（`TTestVariance::Welch`、ワンショット呼び出しの既定）の統計量は

$$
t = \frac{\bar X - \bar Y}{\sqrt{s_X^2/n + s_Y^2/m}}
$$

で、自由度は Welch–Satterthwaite の近似

$$
\nu = \frac{\left(s_X^2/n + s_Y^2/m\right)^2}{\dfrac{(s_X^2/n)^2}{n - 1} + \dfrac{(s_Y^2/m)^2}{m - 1}}
$$

で決める（整数とは限らない）。
Welch の t の帰無分布は近似なので、`TestCalibration::Exact` を渡すと `InvalidInput` を返す。
共通の分散を仮定する Student の検定（`TTestVariance::Pooled`）は、併合分散 $s_p^2 = ((n-1)s_X^2 + (m-1)s_Y^2)/(n+m-2)$ を使い、自由度 $n + m - 2$ の t 分布が正確な帰無分布になる。
分散の等しさを正当化できない限り Welch の検定を使う。
等分散を仮定した検定は、小さい群の分散が大きいときに実際の棄却率が $\alpha$ を大きく超える（下のセル）。

平均・不偏分散・標本の大きさしか手元にないときは、`TTestSummary { mean, variance, count }` を 2 つ作って `t_test_from_summaries`（Welch）か `t_test_from_summaries_with_options`（分散の扱いを選ぶ）に渡す。
結果の `sample_policy()` は `Summary` になる。

平均と分散は `OnlineMoments` と同じ拡張範囲の累積で求めるので、計算量は $O(n + m)$、作業領域は $O(1)$ である。
標準誤差が 0（全観測が等しい）のときは `NumericalInstability`（`Breakdown`）を返し、どちらかの群の観測が 2 個未満なら `InvalidInput` を返す。
Cohen の $d$ のような標準化した効果量は提供しない。
必要なら効果量 `effect()` を標本標準偏差（`sample_standard_deviation`）で割って作る。

### 正規性と等分散性が成り立たないときの棄却率

t 検定の前提（正規性と等分散性）が成り立たないときに実際の棄却率がどう変わるかを、$H_0$ が真のデータを繰り返し生成して確かめる。
次のセルは、平均 0 の母集団から大きさ $n$ の標本 $x$ と大きさ $3n$ の標本 $y$ を引き、$\mu_0 = 0$ の 1 標本の t 検定（両側と片側 2 通り）、等分散の t 検定、Welch の t 検定を $\alpha = 0.05$ で行うことを $R$ 回繰り返す。
$x$ の標準偏差は $y$ の $\sigma_x/\sigma_y$ 倍にする。
棄却した割合が実際の棄却率の推定値で、その 95% 区間は `binomial_test_with_options` の Clopper–Pearson 区間で求める。
同じ二項検定の p 値は、実際の棄却率が名目の $\alpha$ に等しいという仮説の p 値である。
最後の行は、Welch の 95% 区間が真の差 0 を含んだ割合（被覆率）で、名目値は 0.95 である。

正規母集団・$\sigma_x = \sigma_y$（既定）では、5 つの検定の棄却率は 0.040 から 0.053 の範囲にあり、被覆率は 0.9545 である。
`Greater` の区間 [0.032, 0.050] はわずかに 0.05 を外れるが、6 つの 95% 区間のどれかが真値を外れることは、区間が独立なら確率 $1 - 0.95^6 \approx 0.26$ で起きる。
1 つの区間の外れだけで較正の誤りと判断しないことは、[多重比較](oxref:stats-multiple-comparisons-and-adjustment)と同じ考え方である。
標準偏差の比を 2 にすると、等分散の検定の棄却率は 0.156 になり、Welch の検定は 0.053 にとどまる。
指数分布（$\mathrm{Exp}(1) - 1$、右に歪んだ平均 0 の分布）にすると、1 標本の検定の両側の棄却率は $n = 10$ で 0.095 になり、`Less` は 0.125、`Greater` は 0.011 と、片側の棄却率が逆向きにずれる。
歪んだ母集団では $\bar x$ と $s$ が正に相関し、$t$ の分布が左に歪むためである。
群の大きさが違う 2 標本の Welch の検定も、この母集団では棄却率が 0.076 になる。
$n$ を大きくすると中心極限定理によってずれは小さくなるが、$n = 60$ でも `Less` は 0.094、`Greater` は 0.025 で、片側の棄却率は名目値から区間の幅を超えて離れる。

## 順位検定と非母数位置検定

観測を順位 $R_i$（同順位には中間順位）に置き換えると、統計量は単調増加変換で変わらず、外れ値の影響は最大の順位で頭打ちになる。
順位検定は、帰無仮説のもとで群のラベル（または対の符号）が交換可能であることだけを前提にするので、正規性を仮定しない。
その代わり、帰無仮説は「2 つの分布が等しい」のような分布全体の主張になり、平均の差の検定とは帰無仮説の意味が違う。

### Mann–Whitney 検定と Wilcoxon の順位和検定

独立な 2 群の比較には `mann_whitney_test` を使う。
2 群を合わせた標本の中間順位のうち $x$ の順位の和を $R_1$ として

$$
U = R_1 - \frac{n(n+1)}{2}
$$

を統計量にする。
$U$ が大きいほど $x$ が大きい傾向を表し、効果量 $U/(nm)$ は優越確率 $P(X > Y) + P(X = Y)/2$ の推定値（`ClassicalEffect::Superiority`）である。
帰無仮説は 2 群が同じ連続分布に従うことで、そのもとでは $\binom{n+m}{n}$ 通りのラベルの割り当てが等確率になる。
`Auto` はこの数が `max_work` 以下なら全割り当てを数え上げ、超えれば同順位で補正した分散

$$
\operatorname{Var} U = \frac{nm}{(n+m)(n+m-1)} \sum_{i=1}^{n+m}\left(R_i - \frac{n+m+1}{2}\right)^2
$$

と連続性補正による正規近似を使う。
順位付けの計算量は $O(N \log N)$、$N = n + m$ である。

`rank_sum_test` は、同じ $U$ を同順位補正も連続性補正もない分散 $nm(n+m+1)/12$ で標準化した $z$ を統計量にし、正規近似だけで p 値を求める。
`mann_whitney_test` の別名ではなく、同順位のある標本には `InvalidInput` を返し、`Exact` も拒む。
同順位のあるデータや正確な p 値が必要なときは `mann_whitney_test` を使う。

Hodges–Lehmann の位置ずれの推定量とその区間は提供しない。
位置ずれを推定するときは、全組の差 $x_i - y_j$ を作って `median` で中央値を求め、区間は[リサンプリング](../resampling/)で求める。

### Wilcoxon の符号付き順位検定

対応のある観測の差 $d_i$ が 0 の周りに対称な分布に従うという帰無仮説には、`wilcoxon_test(differences)` を使う。
差の絶対値に中間順位を付け、正の差の順位の和を $W^+$、負の差の順位の和を $W^-$ とする。
統計量は両側なら $\min(W^+, W^-)$、片側なら $W^+$ で、効果量は順位二系列相関 $(W^+ - W^-)/(W^+ + W^-)$（`ClassicalEffect::RankBiserial`）である。
帰無仮説のもとでは各差の符号が独立に確率 1/2 で正負になるので、正確な分布は 2 倍した順位を重みとする部分和の数え上げ（動的計画法）で求まり、同順位があっても正確である。
2 倍した順位の和を $K$（同順位がなければ $n(n+1)$）とすると、この計算は $O(Kn)$ の時間と $O(K)$ の作業領域を使う。
`Auto` は $Kn$ が `max_work` 以下なら正確な分布を使い、超えれば連続性補正付きの正規近似を使う。

差が 0 の観測の扱いは `SignedRankZeros` で選ぶ。
`Discard`（ワンショット呼び出しの既定、Wilcoxon の方法）は 0 を除いてから順位を付ける。
`Pratt` は 0 も含めて順位を付け、その順位を両方の和から除く。
`Split` は 0 の順位の和の半分ずつを $W^+$ と $W^-$ に加える。
全部の差が 0 なら p 値は 1 になる。
ほかの扱いは `wilcoxon_test_with_options(differences, zeros, options)` で選ぶ。

### Brunner–Munzel 検定と BWS 検定

Mann–Whitney 検定の帰無仮説は 2 群の分布が等しいことなので、分布の形や広がりが違うと、優越確率が 1/2 でも棄却率が $\alpha$ を超える。
`brunner_munzel_test` は、帰無仮説を $p = P(X > Y) + P(X = Y)/2 = 1/2$ だけにし、形と広がりの違いを許す（ノンパラメトリックな Behrens–Fisher 問題）。
統計量は $(\hat p - 1/2)/\hat\sigma$ で、$\hat\sigma$ は配置（placement）から求めた標準誤差である。
参照分布は `BrunnerMunzelCalibration` で選び、`Student`（ワンショット呼び出しの既定）は Satterthwaite 型の自由度の t 分布、`Normal` は標準正規分布を使う。
正確なラベルの割り当てによる分布は帰無仮説と合わないので、`Exact` は `InvalidInput` になる。
2 群の配置がまったく重ならず $\hat\sigma^2 = 0$ になるときも `InvalidInput` を返す。

`bws_test` は Baumgartner–Weiß–Schindler の統計量 $B$ で、各群の順位と、その順位が期待される位置との差を、裾ほど重くして 2 乗で足し合わせる。
位置の差にも形の差にも反応する。
漸近分布を使わず、$\binom{n+m}{n}$ 通りの割り当てを数え上げる正確な p 値だけを求めるので、`Asymptotic` は `InvalidInput` になり、`Auto` でも状態数が `max_work` を超えるとエラーを返す。
大きな標本では `BwsPlan` で順位を準備し、Monte Carlo の置換で p 値を求める（[リサンプリング](../resampling/)）。

中央値の検定（`median_test`）と尺度の順位検定（`mood_scale_test`、`ansari_bradley_test`）は[分布適合度検定と分散等質性検定](../distribution-and-variance-tests/)で扱う。

## 相関と関連性の検定

対になった観測 $(x_i, y_i)$ の独立性を、相関係数が 0 であるという形で検定する。
係数ごとに、検出できる関連の形が違う。

- `pearson_test` は標本相関 $r$ を統計量にし、$t = r\sqrt{(n-2)/(1-r^2)}$ が 2 変量正規分布のもとで自由度 $n - 2$ の t 分布に正確に従うことから p 値を求める。
  結果の `method()` は `Exact` を返す。
  $n > 3$ なら Fisher の z 変換による近似区間 $\tanh(\operatorname{atanh} r \pm z_{1-\gamma/2}/\sqrt{n-3})$ を付ける。
  どちらかの標本が定数なら `InvalidInput` を返す。
- `point_biserial_test(binary, values)` は 0/1 の変数と連続変数の Pearson 相関（点双列相関）で、`binary` に 0 と 1 以外があると `InvalidInput` を返す。
- `spearman_test` は中間順位の Pearson 相関 $\rho$ を統計量にする。
  `Auto` は $n!$ が `max_work` 以下なら全組み合わせを数え上げ、超えれば $\rho$ に Pearson と同じ t 近似を当てる。
- `kendall_test(x, y, variant)` は一致する対と不一致の対の差 $S$ を数え（$O(n \log n)$）、`KendallVariant::TauB`（$\tau_b = S/\sqrt{(n_0 - n_1)(n_0 - n_2)}$、正方の分割表向き）か `TauC`（Stuart の $\tau_c = 2S/(n^2 (m-1)/m)$、長方形の分割表向き）で正規化する。
  `Auto` は $n!$ が上限以下なら数え上げ、超えれば同順位で補正した $S$ の分散による正規近似を使う。
- `weighted_kendall_tau(x, y, importance, combination)` は、対ごとに重みを付けた Kendall の係数（Vigna の重み付き $\tau$）を返し、帰無分布の計算はしない。
  重みの組み合わせは `KendallWeightCombination` の `Additive`（$w_i + w_j$）か `Multiplicative`（$w_i w_j$）で選び、`importance = None` なら順位の上位ほど重い双曲的な重み $1/(r+1)$ を使う。
- `chatterjee_test` は Chatterjee の $\xi_n$ で、$y$ が $x$ の可測関数なら 1、独立なら 0 に近づく。
  単調でない関連（$y = x^2$ など）も検出するが、$\xi_n$ は正の向きにしか大きくならないので、対立仮説は `Greater` だけを受け付ける。
  `Auto` は $n!$ が上限以下なら数え上げ、超えれば同順位のある $y$ にも使える分散の正規近似を使う。
- `somers_test` は $x$ を説明変数、$y$ を応答とする Somers の $D(Y|X) = S/(n(n-1)/2 - T_x)$ を統計量にし、Brown–Benedetti の漸近分散による正規近似だけで p 値を求める（$O(n^2)$）。
  `somers_contingency_test(table)` は順序カテゴリの分割表（行が説明変数、列が応答）から、観測を展開せずに同じ統計量を求める（$O((RC)^2)$）。
  どちらも `Exact` を拒む。

相関の検定の帰無仮説は独立性（Pearson は相関 0）であり、相関の大きさの区間は Pearson の検定だけが返す。
Spearman・Kendall の係数の区間が必要なときは、[リサンプリング](../resampling/)の bootstrap を使う。

## 計数と分位点の検定

- `binomial_test(successes, trials, null_probability)` は成功確率 $\pi = \pi_0$ の正確な二項検定である。
  片側の p 値は二項分布の裾の確率で、両側の p 値は観測した $k$ 以下の確率を持つ結果の確率をすべて足したもの（比較には相対許容誤差 $64\varepsilon$ を使う）である。
  効果量は $k/n$、区間は Clopper–Pearson 区間で、`Asymptotic` は `InvalidInput` になる。
- `quantile_test(x, null_quantile, p)` は母集団の $p$ 分位点が `null_quantile` に等しいという正確な検定である。
  `null_quantile` より小さい観測の数 $T_1$ と以下の観測の数 $T_2$ を二項分布 $B(n, p)$ と比べ、`Less` は $T_1$、`Greater` は $T_2$、両側は裾の小さいほうを使う。
  効果量は順序統計量 $x_{(\lceil np \rceil)}$ で、区間の端点も順序統計量である。
  どの順序統計量の組でも指定の被覆確率に届かないとき、区間は `None` になる。
- `poisson_means_test(counts, exposures, difference)` は、観測量 $t_1, t_2$ で数えた事象数 $k_1, k_2$ から、率の差 $\lambda_1 - \lambda_2 = d$ を Krishnamoorthy–Thomson の E 検定で検定する。
  帰無仮説のもとで推定した共通の率で、観測より極端な結果の同時 Poisson 確率を足すので、正確な検定ではない（`ClassicalMethod::PoissonE`）。
  和は各周辺の $10^{-13}$ 分位点から $1 - 10^{-13}$ 分位点までの格子に限り、外した確率（高々約 $4 \times 10^{-13}$）を `omitted_null_mass()` で返す。
  格子の点数が `max_work` を超えると `ConvergenceFailure` を返し、`Exact` は `InvalidInput` になる。

割合や率の信頼限界だけが必要なときは、[分布の当てはめと信頼限界](../distribution-fitting-and-confidence-limits/)の `binomial_confidence_limits` などを使う。

## ブロック Plan と 3 群以上の比較

- `page_trend_test(data, treatment_order)` は、乱塊法（各ブロックで全処理を 1 回ずつ観測する Plan）で、処理の効果が `treatment_order` の順に増えるという順序のある対立仮説を検定する。
  `data` の行がブロック、列が処理で、各ブロック内の中間順位の処理ごとの和を $R_j$ として $L = \sum_j j R_j$ を統計量にする。
  `Auto` は $(k!)^b$ 通りのブロック内の並べ替えが上限以下なら数え上げ、超えれば同順位で補正した正規近似を使う。
  対立仮説は `Greater` だけを受け付ける。
- `friedman_test(samples)` は同じ乱塊法で、$k$ 個の処理の効果が等しいことを検定する。
  ブロックごとに順位を付け、処理ごとの順位和 $R_j$ から同順位で補正した $Q$ を求め、自由度 $k - 1$ のカイ二乗分布の上側確率を p 値にする。
  ブロックが 2 個未満か処理が 3 個未満なら `InvalidInput` を返す。
- `kruskal_wallis_test(groups)` は、$k$ 個の独立な群が同じ分布に従うことを、全観測の順位和から作る同順位補正付きの $H$ で検定する。
  p 値は自由度 $k - 1$ のカイ二乗近似で、小標本では正確ではない。
  正確な p 値が必要なら、$H$ を統計量にして置換で p 値を求める。

Friedman と Kruskal–Wallis の検定は `GroupTest`（統計量、p 値、自由度、`GroupTestMethod`）を返し、オプション付き形式は作業領域の上限 `StatisticsOptions::max_bytes()` だけを変えられる。
正規母集団の一元配置分散分析（`PreparedGroups::anova` の `GroupTestMethod::Anova` と `Welch`、`PreparedGroups::alexander_govern`）と事後比較（`PostHocComparison`）は[回帰・分散分析・GLM](../regression-anova-and-glm/)で扱う。

## 一括実行と置換による p 値

同じ検定を多数の行に当てるときは、`classical_tests_into` に検定の種類 `ClassicalBatchTest`、行列のビュー `BatchView`、出力の領域、`ClassicalBatchWorkspace` を渡す。
各行の結果は `Option<ClassicalTestResult>` で、欠測の方針（`MissingPolicy::Skip` など）で除いた観測の数は `omitted()` に入る。
多数の p 値を得たあとの多重性の調整は[分割表検定・多重比較・p 値統合](../contingency-and-multiple-testing/)で扱う。

既存の検定の p 値を置換分布の p 値に置き換えるときは、`classical_permutation_test` に検定の結果と、同じ統計量を置換した添字から計算する関数と `ResamplingPlan` を渡す。
結果の `ClassicalPermutationResult` は、置換の実行が終わったときだけ `ClassicalMethod::Permutation` の検定結果を持つ。
出力先を指定する API `classical_permutation_test_into` とリサンプリングの Plan の作り方は[リサンプリング](../resampling/)にある。

## 実行例：外れ値混入下における t 検定と順位和検定のロバスト性比較

2 群に平均の差 $\Delta\mu$ を与え、第 1 群に外れ値 $x_{\text{out}}$ を 1 つ加えたとき、Welch の t 検定、Mann–Whitney 検定、Brunner–Munzel 検定の p 値がどう変わるかを比べる。
第 1 群は外れ値を含めて 11 点、第 2 群は 10 点で、$\binom{21}{11} = 352\,716$ が既定の `max_work` を超えるので、Mann–Whitney 検定は正規近似を使う。
図は外れ値を 0 から 25 まで動かしたときの p 値（対数軸）で、表は入力の外れ値での統計量、p 値、効果量、区間である。

外れ値を大きくすると、第 1 群の不偏分散が外れ値の 2 乗に比例して増え、Welch の t の分母が大きくなる。
同時に平均の差も縮み、$x_{\text{out}} = 17$ 付近でほぼ 0 になり、それを超えると符号が逆になる。
そのため t の p 値は $x_{\text{out}} = 4$ で 0.043、5 で 0.089 と 0.05 を超え、17 では 0.985 まで上がって真の差を見逃す（第 2 種の過誤）。
Mann–Whitney 検定では、外れ値が第 2 群の最大値（3.23）を超えると、その大きさによらず最大の順位 21 として数えられるので、$x_{\text{out}} \ge 4$ で統計量も p 値（0.022）も変わらない。
Brunner–Munzel 検定も順位（配置）だけを使うので、同じく p 値は 0.012 で一定になる。
順位検定の効果量（優越確率 0.2）は、平均の差が外れ値で変わる場面でも 2 群の重なりの程度を表す。

## まとめ

古典的検定の結果は、統計量、p 値、効果量、区間、使った帰無分布、仮定した標本設計を別々に返すので、p 値だけでなく `method()` と `effect()` を合わせて読む。
`TestCalibration::Auto` は正確な帰無分布の状態数が `max_work` 以下なら数え上げを使い、超えれば漸近近似に切り替えるが、BWS 検定のように近似を持たない検定はエラーを返す。
正規性と等分散性が成り立たないと、t 検定の実際の棄却率は名目の $\alpha$ から離れ、等分散の t 検定は小さい群の分散が大きいときに過大に棄却し、歪んだ母集団では片側検定の棄却率が逆向きにずれる。
順位検定は外れ値に対して p 値が安定するが、帰無仮説は分布の一致（Brunner–Munzel 検定は優越確率 1/2）であり、平均の差の検定とは主張が違う。
