度数のデータでは、2 つのカテゴリ変数が独立か、2 群の割合が等しいかを分割表で検定する。
期待度数が大きい表ではカイ二乗分布の近似で p 値を求められるが、小さい表や疎な表では近似の誤差が大きくなり、正確検定が必要になる。
正確検定には、周辺和をどこまで固定するか（標本設計）によって条件付きの Fisher 検定と無条件の Barnard・Boschloo 検定がある。
多数の仮説を同時に検定すると、個々の検定の $\alpha$ では偽陽性の数を制御できないので、p 値を調整する。
独立な複数の研究が同じ帰無仮説を検定したときは、p 値を 1 つに統合する。
このページでは、これらの手法の前提と帰無分布を説明し、実際の棄却率と誤り率をセルで測って確かめる。

## 分割表の表現と基本統計量

$R$ 行 $C$ 列の分割表を、行優先の度数の列 `&[usize]` を借用する `ContingencyView::new(counts, rows, columns)` で表す。
写しは作らず、`rows()`、`columns()`、`counts()` で形と中身を返す。
`margins_into(row, column)` は行和 $r_i$ と列和 $c_j$ を呼び出し側の `u128` の領域に書き、総数 $N$ を返す。
`expected_into(output, rows, columns)` は独立のもとでの期待度数

$$
E_{ij} = \frac{r_i c_j}{N}
$$

を書く。
どちらも計算量は $O(RC)$ で、度数の和は整数で正確に求める。

連関の強さは、Pearson のカイ二乗統計量 $X^2$（連続性補正なし）から作る名義尺度の連関係数 `contingency_association(table, measure)` で測る。
`AssociationMeasure` は次の 3 つである。

- `CramerV`：$V = \sqrt{X^2/(N\min(R-1, C-1))}$ で、$[0, 1]$ に入る。
- `TschuprowT`：$T = \sqrt{X^2/(N\sqrt{(R-1)(C-1)})}$ で、$[0, 1]$ に入り、正方でない表では 1 に届かない。
- `Pearson`：一致係数 $C = \sqrt{X^2/(X^2 + N)}$ で、最大値は表の大きさで決まり 1 より小さい。

$2 \times 2$ の表 $\begin{pmatrix} a & b \\ c & d \end{pmatrix}$ では、`odds_ratio(table)` が標本オッズ比 $ad/(bc)$ を返す。
$ad = 0$ なら 0、$bc = 0$ なら $+\infty$ を返し、両方 0 なら `InvalidInput` になる。
`relative_risk(table)` は行を曝露の群、1 列目を事象として、相対リスク $(a/(a+b))/(c/(c+d))$ を返す。
オッズ比は表を転置しても変わらないが、相対リスクは行と列の役割で値が変わる。
オッズ比と相対リスクの信頼区間は提供しない。
対数オッズ比の近似区間は Woolf の標準誤差 $\sqrt{1/a + 1/b + 1/c + 1/d}$ から作るか、[GLM](../regression-anova-and-glm/) のロジスティック回帰の係数の区間で求める。

## 独立性のカイ二乗検定と Cressie–Read 統計量

観測度数 $O_{ij}$ と期待度数 $E_{ij}$ の離れ方は、Cressie–Read の冪発散統計量の族で測る。

$$
2NI^{\lambda} = \frac{2}{\lambda(\lambda+1)}\sum_{i,j} O_{ij}\left[\left(\frac{O_{ij}}{E_{ij}}\right)^{\lambda} - 1\right]
$$

$\lambda = 1$ は Pearson のカイ二乗統計量 $X^2 = \sum (O_{ij} - E_{ij})^2/E_{ij}$、$\lambda \to 0$ の極限は尤度比統計量（G 検定）$G^2 = 2\sum O_{ij}\ln(O_{ij}/E_{ij})$ である。
ほかに $\lambda = -1/2$（Freeman–Tukey）、$\lambda = -1$（修正対数尤度）、$\lambda = 2/3$（Cressie と Read が推奨する値）がよく使われる。
独立の帰無仮説のもとで、どの $\lambda$ でも統計量は $N \to \infty$ で自由度 $(R-1)(C-1)$ のカイ二乗分布に近づく。
$\lambda$ は `CressieReadParameter::new(lambda)` で作り、定数 `PEARSON`（$\lambda = 1$）と `G_TEST`（$\lambda = 0$）がある。

`power_divergence_contingency_test(table, divergence, correction)` は、この統計量とカイ二乗分布の上側確率を `ChiSquareResult`（`statistic()`、`p_value()`、`degrees_of_freedom()`）で返す。
$2 \times 2$ の表に Pearson の統計量を使うときは、`ContinuityCorrection::HalfUnit` で Yates の連続性補正 $\sum (|O - E| - 1/2)_+^2/E$ を掛ける。
補正は離散的な統計量を連続分布で近似するときの補正で、$2 \times 2$ より大きい表には効果がなく、Pearson 以外の統計量に指定すると `InvalidInput` になる。
ワンショット呼び出しの `chi2_contingency_test(table)` は Pearson の統計量を使い、$2 \times 2$ の表にだけ Yates の補正を掛ける。
行和か列和に 0 があると期待度数が 0 になるので、どちらも `InvalidInput` を返す。

度数の列 1 本が指定の分布に従うかの適合度検定には、`power_divergence_test(observed, expected, divergence, ddof)` を使う。
`expected` が `None` なら等確率を帰無仮説にし、期待度数を作るのに推定した母数の数 `ddof` だけ自由度 $k - 1$ を減らす。
観測と期待の総数が相対 $64\varepsilon$ を超えて違うと `InvalidInput` になる。

カイ二乗分布は大標本の近似で、`ChiSquareResult` の p 値は正確な確率ではない。
近似の目安としてよく使われるのは、期待度数が 1 未満のセルがなく、5 未満のセルが全体の 20% 以下という Cochran の基準である。

## 正確検定

### Fisher の条件付き正確検定

行和と列和の両方を固定すると、独立の帰無仮説のもとで表は（多変量）超幾何分布に従う。
$2 \times 2$ の表では左上の度数 $a$ だけが自由で、行和 $r_1, r_2$、列和 $c_1$、総数 $N$ のもとで

$$
P(a) = \frac{\dbinom{r_1}{a}\dbinom{r_2}{c_1 - a}}{\dbinom{N}{c_1}}, \qquad \max(0, c_1 - r_2) \le a \le \min(r_1, c_1)
$$

である。
`fisher_exact_test(table)` は、観測した表と周辺和が同じ表のうち、確率が観測した表以下のもの（比較の相対許容誤差は $64\varepsilon$）の確率をすべて足して両側の p 値にする。
$2 \times 2$ の表では、オプション付き形式 `fisher_exact_test_with_options` の `Less` と `Greater` が左上の度数の下側と上側の裾を使う。
統計量は $2 \times 2$ では標本オッズ比、それより大きい表では観測した表の確率である。
$R \times C$ の表では周辺和が同じ表をすべて列挙し（Freeman–Halton の拡張）、両側の検定だけを受け付ける。
列挙する表の数は `max_work` で、作業領域は `max_workspace_bytes` で上限を決め、超えるとそれぞれ `ConvergenceFailure` と `ResourceLimit` を返す。
`Asymptotic` は `InvalidInput` になる。

周辺和を固定した条件付き分布は帰無仮説の母数（共通の成功確率）を含まないので、正確な p 値が作れる。
ただし $a$ が取る値は少数で、p 値は離散的な値しか取らないので、$\alpha$ ちょうどの大きさの検定は作れない。
その結果、Fisher 検定の実際の棄却率は $\alpha$ を下回り（保守的）、片方の周辺だけが固定された設計では無条件検定より検出力が低い。

### Barnard と Boschloo の無条件正確検定

2 群の比較試験のように、各群の大きさ（列和 $n_1, n_2$）だけを設計で固定し、成功の合計は確率的に決まる場合がある。
列が独立な 2 つの二項標本 $X_1 \sim B(n_1, \pi_1)$、$X_2 \sim B(n_2, \pi_2)$ で、1 行目が成功の数である。
帰無仮説 $\pi_1 = \pi_2 = \pi$ のもとで、観測した表と同じかより極端な表の確率

$$
p(\pi) = \sum_{(x_1, x_2):\, T(x_1, x_2) \ge T_{\text{obs}}} \binom{n_1}{x_1}\binom{n_2}{x_2}\pi^{x_1 + x_2}(1-\pi)^{N - x_1 - x_2}
$$

は未知の局外母数 $\pi$ に依存する。
無条件正確検定は $\sup_{\pi \in [0,1]} p(\pi)$ を p 値にするので、どの $\pi$ でも実際の棄却率が $\alpha$ を超えない。

- `barnard_exact_test(table)` は表を Wald 統計量 $T = (\hat p_1 - \hat p_2)/\hat\sigma$ で並べる。
  分散の推定は `UnconditionalOptions::with_pooled(VariancePooling)` で、`Pooled`（既定、共通の割合）か `Unpooled`（群ごとの割合）を選ぶ。
- `boschloo_exact_test(table)` は表を片側の Fisher の p 値で並べる。
  Fisher の片側検定より一様に検出力が高く、両側の p 値は小さいほうの片側の p 値の 2 倍（1 で頭打ち）である。

$\sup_\pi p(\pi)$ は、裾の確率を $\pi$ の多項式として Bernstein 形式で表し、分枝限定法で幅 `UnconditionalOptions::tolerance()`（既定 $10^{-9}$）まで挟み込む。
結果の `ExactContingencyResult` は、この挟み込み $p_{\text{lower}} \le p \le p_{\text{upper}}$ の上端を `p_value()`（保守的な値）、下端を `p_value_lower()` で返す。
挟み込みは分枝限定の打ち切りだけを考慮し、丸め誤差は含まない。
`(n₁ + 1)(n₂ + 1)` 個の表の評価と分枝限定の手数が `max_work` を超えると `ConvergenceFailure` を返す。
対立仮説と作業の上限は、`UnconditionalOptions::with_classical(ClassicalOptions)` で渡す。
`Asymptotic` と、$(0, 1)$ の外の `tolerance` は `InvalidInput` になる。
オプション付き形式は `barnard_exact_test_with_options` と `boschloo_exact_test_with_options` である。

`ExactContingencyResult` の `design()` は、検定が条件にした標本設計を `ContingencyDesign` で返す。
`FixedMargins` は行和と列和の両方を固定した設計（Fisher 検定）、`FixedColumns` は列和だけを固定した 2 つの独立な二項標本の設計（Barnard と Boschloo の検定）である。
`statistic()` は Fisher の $2 \times 2$ ではオッズ比、$R \times C$ では観測した表の確率、Barnard では Wald 統計量、Boschloo では Fisher の p 値で、`tables()` は評価した表の数である。

対応のある 2 値データの McNemar 検定と、層別した $2 \times 2$ 表の Cochran–Mantel–Haenszel 検定は提供しない。
McNemar の正確検定は、不一致の対 $b$ と $c$ に対する `binomial_test(b, b + c, 0.5)` と同じである。
層で調整したオッズ比は、層を説明変数に入れたロジスティック回帰（[GLM](../regression-anova-and-glm/)）で求める。

### 希薄表における検定選択基準

検定の実際の大きさは、帰無仮説のもとで棄却する表の確率の和である。
列和 $n_1, n_2$ を固定した $2 \times 2$ 表は $(n_1 + 1)(n_2 + 1)$ 通りしかないので、各検定がどの表を $\alpha$ で棄却するかを全部調べ、共通の成功確率 $\pi$ のもとでの二項確率で重み付けすれば、実際の棄却率を Monte Carlo の誤差なしに求められる。

$$
\text{実際の棄却率}(\pi) = \sum_{(x_1, x_2) \in \text{棄却域}} \binom{n_1}{x_1}\binom{n_2}{x_2}\pi^{x_1+x_2}(1-\pi)^{n_1+n_2-x_1-x_2}
$$

次のセルは、この和を $\pi = 0.01, 0.02, \dots, 0.99$ で計算し（二項確率は `Binomial` の `pmf`）、補正なしの Pearson、Yates の補正、Fisher、Barnard、Boschloo の検定を $\alpha = 0.05$ で比べる。
成功の合計か失敗の合計が 0 の表は周辺和が 0 で検定できないので、棄却しない表として数える。

## 多重比較と p 値の調整

### 誤り率の定義

$m$ 個の帰無仮説 $H_1, \dots, H_m$ を同時に検定し、そのうち $m_0$ 個が真であるとする。
棄却した数を $R$、真の帰無仮説を棄却した数（偽陽性）を $V$ とする。
各検定を水準 $\alpha$ で行うと、独立な場合に少なくとも 1 つ偽陽性が出る確率は $1 - (1 - \alpha)^{m_0}$ で、$m_0 = 20$ なら約 0.64 になる。
多重性の制御には 2 つの基準がある。

- 族全体の誤り率（FWER）$P(V \ge 1)$ は、偽陽性が 1 つでも出る確率である。
- 偽発見率（FDR）$E[V/\max(R, 1)]$ は、棄却した仮説に占める偽陽性の割合の期待値である。
  すべての帰無仮説が真（$m_0 = m$）なら FDR と FWER は等しく、そうでなければ FDR $\le$ FWER である。

scioxide-stats は、各 p 値を調整した p 値 $\tilde p_i$ に置き換え、$\tilde p_i \le \alpha$ の仮説を棄却する形で手法を提供する。
以下、$p_{(1)} \le \dots \le p_{(m)}$ は整列した p 値である。

### FWER の制御

`FamilywiseMethod` で選ぶ。

- `Bonferroni`：$\tilde p_i = \min(1, m p_i)$。
  Boole の不等式 $P(\bigcup A_i) \le \sum P(A_i)$ だけを使うので、検定の依存の仕方によらず FWER $\le \alpha$ が成り立つ。
- `Holm`：$\tilde p_{(i)} = \min\bigl(1, \max_{j \le i} (m - j + 1)\, p_{(j)}\bigr)$ のステップダウン法。
  閉検定手続きから導かれ、任意の依存のもとで FWER を制御し、調整した p 値は Bonferroni 以下になる。

Šidák、Hochberg、Hommel の方法は提供しない。
任意の依存のもとで FWER を制御するには Holm の方法を使う。

### FDR の制御

`FalseDiscoveryMethod` で選ぶ。

- `BenjaminiHochberg`：$\tilde p_{(i)} = \min\bigl(1, \min_{j \ge i} m\, p_{(j)}/j\bigr)$ のステップアップ法。
  検定が独立か、正の回帰依存（PRDS：真の帰無仮説の各検定統計量を条件にしたとき、統計量の組が増加集合に入る確率がその値とともに増える条件）を満たすとき、FDR $\le (m_0/m)\alpha \le \alpha$ が成り立つ。
- `BenjaminiYekutieli`：BH の値に $c(m) = \sum_{k=1}^m 1/k \approx \ln m + 0.577$ を掛ける。
  任意の依存のもとで FDR を制御するが、$m = 20$ で約 3.6 倍の補正になり、検出力は大きく下がる。

$m_0$ を推定して BH を強める適応的な方法（Storey の q 値など）は提供しない。

### p 値の調整の API

`adjust_pvalues(&p, method)` は 1 本の p 値の列を 1 つの族として調整し、入力と同じ順の `Vec<f64>` を返す。
手法は `PValueAdjustment::Familywise(FamilywiseMethod)` か `PValueAdjustment::FalseDiscovery(FalseDiscoveryMethod)` で指定する。
整列の作業領域を確保するので計算量は $O(m \log m)$ で、作業領域のバイト数の上限を変えるときはオプション付き形式 `adjust_pvalues_with_options(&p, method, options)` に `StatisticsOptions` を渡す。
p 値が空か $[0, 1]$ の外にあると `InvalidInput` を返し、欠測と非有限値は受け付けない。

多数の族（レーン）を同じ幅で調整するときは、`PValueAdjustmentWorkspace::new(lanes, width, options, context)` で作業領域を一度確保し、`adjust_pvalues_into(pvalues, width, method, options, output, workspace, context)` を呼ぶ。
`pvalues` と `output` は幅 `width` のレーンを順に並べた列で、各レーンを別々に調整する。
作業領域を作ったときと同じ `options` と `context` を渡し、レーンはそれらが許す範囲で並列に処理される。

## 独立な p 値の統合

同じ帰無仮説を独立な $k$ 個の研究で検定したとき、その p 値 $p_1, \dots, p_k$ を 1 つの検定にまとめる。
帰無仮説のもとで連続な統計量の p 値は一様分布に従うので、その関数の分布から統合した p 値が求まる。
`combine_pvalues(&p, method, weights)` は `PValueCombination` で次の方法を選び、`CombinedPValue`（`statistic()`、`p_value()`）を返す。

| 方法 | 統計量 | 帰無分布と p 値 |
|---|---|---|
| `Fisher` | $X = -2\sum_i \ln p_i$ | 自由度 $2k$ のカイ二乗分布の上側確率 |
| `Pearson` | $X = 2\sum_i \ln(1 - p_i)$ | $P(\chi^2_{2k} \le -X)$。$p_i$ が 0 に近いと小さくなる |
| `Tippett` | $X = \min_i p_i$ | $1 - (1 - X)^k$ |
| `Stouffer` | $Z = \sum_i w_i \Phi^{-1}(1 - p_i)/\sqrt{\sum_i w_i^2}$ | 標準正規分布の上側確率。重みを受け付ける唯一の方法 |
| `MudholkarGeorge` | $L = \sum_i \ln((1 - p_i)/p_i)$ | $L\sqrt{3(5k+4)/(k\pi^2(5k+2))}$ を自由度 $5k + 4$ の t 分布と比べた上側確率 |

Fisher の方法は 1 つの研究の非常に小さい p 値に強く反応し、Stouffer の方法は多数の研究にわたる弱い効果をまとめるのに向く。
Stouffer の重みは研究の大きさの平方根などで、非負の有限値でなければならず、すべて 0 なら `InvalidInput` を返す。
p 値が 0 か 1 だと統計量が無限大になることがあり、Stouffer とロジット法で 0 と 1 が同時にあると `InvalidInput` を返す。
帰無分布は独立な一様の p 値を前提にするので、離散的な検定の p 値や依存した p 値では較正されない（次のセル）。

## 実行例：多重比較の誤り率と p 値統合の棄却率

次のセルは、$m$ 個の片側の z 検定を $R$ 回繰り返して、各調整法の FWER、FDR、検出力と、p 値統合の棄却率を測る。
$m_0 = \lceil \pi_0 m \rceil$ 個の帰無仮説が真で、残りは平均 $\mu$ だけずれている。
統計量は $z_i = \sqrt{\rho}\, W + \sqrt{1 - \rho}\, e_i + \mu\,\mathbf 1\{i > m_0\}$（$W$、$e_i$ は独立な標準正規変量）で、$\rho$ はすべての対の相関（等相関）である。
p 値は $p_i = 1 - \Phi(z_i)$ で、正規分布の生存関数で求める。
$\rho > 0$ の等相関は PRDS を満たすので、BH は依存があっても FDR を制御するはずである。
p 値統合の帰無仮説は全体の帰無仮説（すべての $H_i$ が真）で、真の帰無仮説の割合を 1 にしたときの棄却率がその大きさになる。
表の FWER と統合の棄却率の区間は Clopper–Pearson の 95% 区間、FDR の欄の誤差は反復の標準誤差である。

use scioxide_core::RealScalar;
use scioxide_random::{Distribution, Normal, SeedableRng, SplitMix64, Survival};
use scioxide_stats::{
    ClassicalOptions, FalseDiscoveryMethod, FamilywiseMethod, PValueAdjustment,
    PValueCombination, adjust_pvalues, binomial_test_with_options, combine_pvalues,
};

let (alpha, m, replicates) = (0.05, hypotheses as usize, replicate_count as usize);
let m0 = (null_fraction * m as f64).ceil() as usize;
let normal = Normal::<f64>::new(0.0, 1.0).map_err(|e| e.to_string())?;
let (shared, own) = (
    RealScalar::sqrt(correlation),
    RealScalar::sqrt(1.0 - correlation),
);
let adjustments = [
    ("調整なし", None),
    (
        "Bonferroni",
        Some(PValueAdjustment::Familywise(FamilywiseMethod::Bonferroni)),
    ),
    (
        "Holm",
        Some(PValueAdjustment::Familywise(FamilywiseMethod::Holm)),
    ),
    (
        "Benjamini–Hochberg",
        Some(PValueAdjustment::FalseDiscovery(
            FalseDiscoveryMethod::BenjaminiHochberg,
        )),
    ),
    (
        "Benjamini–Yekutieli",
        Some(PValueAdjustment::FalseDiscovery(
            FalseDiscoveryMethod::BenjaminiYekutieli,
        )),
    ),
];
let combinations = [
    PValueCombination::Fisher,
    PValueCombination::Pearson,
    PValueCombination::Tippett,
    PValueCombination::Stouffer,
    PValueCombination::MudholkarGeorge,
];
let mut rng = SplitMix64::from_seed(seed as u64);
let mut p = vec![0.0; m];
// 調整法ごとの [V ≥ 1 の回数, FDP の和, FDP² の和, 真の発見の割合の和]
let mut tally = [[0.0_f64; 4]; 5];
let mut combined = [0_usize; 5];
for _ in 0..replicates {
    let common = normal.sample(&mut rng).map_err(|e| e.to_string())?;
    for (i, value) in p.iter_mut().enumerate() {
        let own_part = normal.sample(&mut rng).map_err(|e| e.to_string())?;
        let mean = if i < m0 { 0.0 } else { shift };
        *value = normal
            .sf(shared * common + own * own_part + mean)
            .map_err(|e| e.to_string())?;

        let adjusted = match method {
            Some(method) => adjust_pvalues(&p, *method).map_err(|e| e.to_string())?,
            None => p.clone(),

        let false_hits = adjusted[..m0].iter().filter(|&&v| v <= alpha).count();
        let true_hits = adjusted[m0..].iter().filter(|&&v| v <= alpha).count();

        if false_hits > 0 {
            t[0] += 1.0;
        }
        t[1] += fdp;
        t[2] += fdp * fdp;
        t[3] += if m > m0 {
            true_hits as f64 / (m - m0) as f64
        } else {
            0.0
        };

        let result = combine_pvalues(&p, method, None).map_err(|e| e.to_string())?;
        *count += usize::from(result.p_value() <= alpha);
    }

    let power = (m > m0).then(|| t[3] / r);
    rows.push((

        t[0] / r,
        interval.lower(),
        interval.upper(),
        fdr,
        fdr_se,
        power,
    ));
}

既定の設定（$m = 20$、$\pi_0 = 0.8$、$\mu = 2.5$、独立）では、調整なしの FWER は 0.5 を超え、Bonferroni と Holm の FWER は 0.05 以下にとどまる。
BH の FDR は $(m_0/m)\alpha = 0.04$ の近くにあり、FWER は 0.05 を超えるが、検出力は Bonferroni と Holm より高い。
BY の FDR は 0.01 前後で、制御は保守的になる。
$\pi_0 = 1$ にすると FDR と FWER は一致し、独立な p 値の統合法はどれも 0.05 の近くで全体の帰無仮説を棄却する。
$\rho = 0.6$ にすると、調整法の FWER と FDR は 0.05 以下に保たれる一方、Tippett 以外の統合法の棄却率は名目値の数倍になる。
Tippett の方法は最小の p 値だけを使うので、正の相関のもとでは保守的になる。
統合法の帰無分布は独立性を使っているので、相関した研究や同じデータの複数の検定の p 値を統合してはいけない。

## まとめ

分割表の独立性は、期待度数が大きければ Cressie–Read 族のカイ二乗近似で検定し、小さい表では正確検定を使う。
正確検定は標本設計で選び、行和と列和の両方を条件にするなら Fisher 検定、列和（群の大きさ）だけが固定されているなら Barnard か Boschloo の検定を使う。
列和を固定した $2 \times 2$ 表では、補正なしのカイ二乗検定は大きさを超え、Fisher 検定は名目の 3 分の 1 程度しか棄却しないが、無条件検定は大きさを守って $\alpha$ の近くまで棄却する。
多重比較では、偽陽性を 1 つも許さないなら Bonferroni か Holm（任意の依存で有効）、発見の中の偽陽性の割合を抑えるなら BH（独立か PRDS）か BY（任意の依存）を選ぶ。
p 値の統合は独立な連続の p 値を前提にし、依存した p 値では全体の帰無仮説を過大に棄却する。
