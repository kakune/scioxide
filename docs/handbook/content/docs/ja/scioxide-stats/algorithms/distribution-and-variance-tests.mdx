t 検定や分散分析は、標本が正規分布に従うことや、群の分散が等しいことを前提にする。
このページの検定はその前提そのものを帰無仮説にする。
適合度検定は「標本が指定した分布 $F$ に従う」、正規性検定は「標本が何らかの正規分布に従う」、2 標本・k 標本の検定は「群が同じ分布に従う」、等分散性の検定は「群の分散（尺度）が等しい」を帰無仮説にする。
帰無仮説を棄却しないことは前提が成り立つ証拠にはならず、小標本では前提からのずれを検出する確率（検出力）が低い。
このページでは、各検定の帰無分布の求め方と、母数を推定したときや分布の形が違うときに実際の棄却率が名目の $\alpha$ からどうずれるかを、セルで測って確かめる。

結果はどれも `DistributionTestResult<S>` で返る。
`statistic()` と `p_value()` のほか、`method()` は p 値を求めた帰無分布（`DistributionMethod` の `Exact`、`Asymptotic`、`Permutation { exact, replicates }`、`MonteCarlo { replicates }`）、`null_parameters()` は帰無分布の母数の扱い（`NullParameters` の `Known`、`Estimated`、`Exchangeable`）、`observations()` と `groups()` は観測の総数と群の数を返す。
`monte_carlo_interval()` は Monte Carlo と乱数による置換の p 値にだけ付く、上側確率の 95% Wilson 区間である。
検定の共通の設定 `ClassicalOptions`、`TestCalibration` の規則、ワンショット呼び出しとオプション付き形式の関係は[古典的検定](oxref:stats-classical-results-and-common-settings)と同じである。

## 経験分布関数に基づく適合度検定

独立な標本 $x_1, \dots, x_n$ の経験分布関数（ECDF）は

$$
F_n(x) = \frac{1}{n}\sum_{i=1}^n \mathbf 1\{x_i \le x\}
$$

である。
帰無仮説の分布関数 $F$ が連続で、母数をデータから推定していなければ、$U_i = F(x_i)$ は一様分布 $U(0, 1)$ に従う。
そのため $F_n$ と $F$ の差から作る統計量の帰無分布は $F$ によらず、一度求めればどの連続分布の検定にも使える（分布によらない性質）。
以下では $x_{(1)} \le \dots \le x_{(n)}$ を整列した標本とする。

### Kolmogorov–Smirnov 検定

Kolmogorov–Smirnov（KS）統計量は、$F_n$ と $F$ の差の最大値である。

$$
D^+ = \max_i\left(\frac{i}{n} - F(x_{(i)})\right), \qquad
D^- = \max_i\left(F(x_{(i)}) - \frac{i-1}{n}\right), \qquad
D = \max(D^+, D^-)
$$

`ks_one_sample_statistic(x, cdf)` は $(D^+, D^-)$ の組を返す。
オプション付き形式 `ks_one_sample_statistic_with_options` が `ClassicalOptions` から使うのは、整列した写しの作業領域の上限 `max_workspace_bytes` だけである。
`cdf` が $[0, 1]$ の外の値を返すか、整列した標本に沿って減少すると `InvalidInput` を返す。

`ks_one_sample_test(x, cdf)` は対立仮説に応じて `Greater` なら $D^+$、`Less` なら $D^-$、両側なら $D$ を統計量にする。
正確な帰無分布は、片側では Birnbaum–Tingey の和、両側では Durbin 行列のべき乗（Marsaglia–Tsang–Wang の方法）で求める。
`Auto` は $n^2$ が `max_work` 以下（既定では $n \le 316$）なら正確な分布を使い、それより大きい標本では両側に $\sqrt n D$ の Kolmogorov 分布、片側に $\exp(-2nD^2)$ の漸近近似を使う。
両側の正確な分布の計算は、Durbin 行列の大きさ $m = 2\lfloor nD \rfloor + 1$ に対して $O(m^3 \log n)$ の手数がかかり、この手数も `max_work` で制限する。
そのため `Auto` が正確な分布を選んでも、$nD$ が大きいと手数が上限を超えることがある（既定の上限では $n = 200$、$D \approx 0.12$ の標本などで起きる）。
`Auto` では、正確な分布の評価が `max_work` か `max_workspace_bytes` を使い切ると漸近近似に切り替え、結果の `method()` が `Asymptotic` を返す。
$nD$ が大きいとき p 値は小さいので、漸近近似に切り替えても検定の結論はほとんど変わらない。
`Exact` を指定した場合は切り替えず、`ConvergenceFailure` か `ResourceLimit` を返すので、オプション付き形式 `ks_one_sample_test_with_options` で `with_max_work` の上限を上げる。
オプション付き形式では、ほかに対立仮説と較正を変えられる。
帰無分布は連続な $F$ を前提にするので、同順位のある標本は `InvalidInput` になる。

### Cramér–von Mises 検定と Anderson–Darling 検定

KS 統計量は差の最大値だけを見るので、分布の中央付近のずれに反応しやすく、裾のずれには反応しにくい。
差の 2 乗を分布全体で積分する統計量は

$$
T = n\int_{-\infty}^{\infty} \bigl(F_n(x) - F(x)\bigr)^2\, \psi\bigl(F(x)\bigr)\, dF(x)
$$

で、重み $\psi(u) = 1$ が Cramér–von Mises（CvM）統計量 $W^2$、$\psi(u) = 1/(u(1-u))$ が Anderson–Darling（AD）統計量 $A^2$ である。
整列した標本では次の形になる。

$$
W^2 = \frac{1}{12n} + \sum_{i=1}^n \left(F(x_{(i)}) - \frac{2i-1}{2n}\right)^2, \qquad
A^2 = -n - \frac1n\sum_{i=1}^n (2i-1)\left[\ln F(x_{(i)}) + \ln\bigl(1 - F(x_{(n+1-i)})\bigr)\right]
$$

`cramer_von_mises_statistic(x, cdf)` は $W^2$ を返し、`cramer_von_mises_test(x, cdf)` は $W^2$ の極限分布を Csörgő–Faraway の級数で足して p 値を求める。
級数は項が $10^{-12}$ を下回るまで足し、項数が `max_work` を超えると `ConvergenceFailure` を返す。
正確な有限標本の分布は使わないので `Exact` は `InvalidInput` になり、対立仮説は両側だけである。
オプション付き形式 `cramer_von_mises_statistic_with_options` は作業領域の上限だけを、`cramer_von_mises_test_with_options` はそれに加えて級数の項数の上限 `max_work` を変える。

`anderson_darling_statistic(x, log_cdf, log_survival)` は $A^2$ を返す。
$\ln F$ と $\ln(1 - F)$ を直接受け取るのは、裾で $F$ が 0 や 1 に丸められて対数が発散するのを避けるためで、どちらもすべての観測で有限でなければならない。
AD 統計量の p 値を返す関数はなく、p 値は次の節の `goodness_of_fit_test_into` で求める。
オプション付き形式 `anderson_darling_statistic_with_options` が使う設定は作業領域の上限だけである。

### 母数を推定したときの較正

$F$ の母数（正規分布の平均と分散など）を同じ標本から推定すると、$F$ が標本に寄るので $F_n$ との差は小さくなり、母数を固定したときの帰無分布は使えない。
推定した母数で KS 検定を行うと p 値は大きすぎ、実際の棄却率は名目の $\alpha$ を大きく下回る（Lilliefors の問題）。
下の正規性検定のセルでは、$n = 40$ の正規標本で平均と標準偏差を推定した KS 検定の棄却率が 0.05 ではなく 0 に近くなる。

母数を推定する適合度検定には、`goodness_of_fit_test_into` を使う。
この関数は母数の族を `GoodnessOfFitModel`（対数分布関数、対数生存関数、標本を引く関数、母数を推定する関数 `fit`）で受け取り、統計量を `GoodnessOfFitStatistic` の `KolmogorovSmirnov`、`CramerVonMises`、`AndersonDarling` から選ぶ。
観測から母数 $\hat\theta$ を推定し、$F(\cdot\,; \hat\theta)$ から同じ大きさの標本を引いて母数を推定し直し、統計量を計算することを繰り返す（パラメトリック bootstrap）。
繰り返しの統計量が観測値以上になる割合が p 値で、各反復で推定し直すので、推定の影響を含めた帰無分布になる。
結果の `GoodnessOfFitResult` は、全反復が終わったときだけ `DistributionTestResult`（`method()` が `MonteCarlo`、`null_parameters()` が `Estimated`）を持ち、反復のレポートも返す。
Plan `ResamplingPlan`、出力、作業領域、実行コンテキストは呼び出し側が渡し、ワンショット呼び出しの形はない。
Plan の作り方は[リサンプリング](../resampling/)にある。

## 正規性の専用検定

正規性の検定は帰無仮説を「平均と分散が未知の正規分布」に絞ることで、一般の適合度検定より高い検出力を持つ。
どの検定も母数を推定した帰無分布を使い、`null_parameters()` は `Estimated` を返す。

### Shapiro–Wilk 検定

Shapiro–Wilk の統計量は、整列した標本 $x_{(i)}$ の重み付き和の 2 乗を偏差平方和で割ったものである。

$$
W = \frac{\left(\sum_{i=1}^n a_i x_{(i)}\right)^2}{\sum_{i=1}^n (x_i - \bar x)^2}
$$

重み $a_i$ は、標準正規分布の順序統計量の期待値 $m$ と共分散行列 $V$ から $a = m^\top V^{-1}/\lVert m^\top V^{-1}\rVert$ で決まる。
分子は正規確率プロット（$x_{(i)}$ を $m_i$ に対してプロットした図）の傾きの最良線形不偏推定量の 2 乗に比例し、分母は分散の推定量に比例するので、$W$ は 2 つの分散の推定量の比である。
正規標本では $W$ は 1 に近く、歪みや裾の重さがあると小さくなる。
`shapiro_wilk_statistic(x)` は Royston の近似した重み $a_i$ で $W$ を求め、$(0, 1]$ の値を返す。
標本は最小値を引いて範囲で割ってから計算するので、桁あふれの近くの値でも $W$ は平行移動と定数倍で変わらない。
計算量は $O(n \log n)$ で、`shapiro_wilk_statistic_with_options` は $n$ 個の値と $n/2$ 個の重みの作業領域の上限だけを変える。

`shapiro_wilk_test(x)` は Royston（1992）の正規化変換で $W$ を近似的な標準正規変量に移し、p 値を求める。
$n = 3$ では $W$ の帰無分布が閉じた形 $p = 1 - (6/\pi)\arccos\sqrt W$ で求まり、その式を使う。
変換は $3 \le n \le 5000$ で有効で、範囲外は `InvalidInput` になる。
$n > 5000$ では `shapiro_wilk_statistic` で $W$ を求め、正規標本を引いて $W$ の帰無分布を Monte Carlo で作る。
`Exact` と片側の対立仮説は `InvalidInput` になる。
同順位のある標本も受け付けるが、丸めて記録したデータのように同順位が多いと $W$ は小さくなり、正規性を過大に棄却する。

### 歪度・尖度検定と Jarque–Bera 検定

$k$ 次の標本中心積率を $m_k$ とし、標本歪度 $\sqrt{b_1} = m_3/m_2^{3/2}$ と標本尖度 $b_2 = m_4/m_2^2$ を使う検定がある。
正規分布では $\sqrt{b_1}$ の母数は 0、$b_2$ の母数は 3 である。

- `skew_test(x)` は D'Agostino の変換で $\sqrt{b_1}$ を近似的な標準正規変量 $Z_s$ に移し、正規分布の裾の確率を p 値にする。
  $n \ge 8$ が必要で、片側の対立仮説も受け付ける。
- `kurtosis_test(x)` は $b_2$ を正規標本での正確な平均と分散で標準化し、Anscombe–Glynn の変換で $Z_k$ に移す。
  $n \ge 5$ が必要で、近似は $n \ge 20$ で使うことが推奨されている。
- `normality_test(x)` は D'Agostino–Pearson の総合検定で、$K^2 = Z_s^2 + Z_k^2$ を自由度 2 のカイ二乗分布と比べる。
  $n \ge 8$ が必要である。
- `jarque_bera_test(x)` は $\mathrm{JB} = \frac n6\left(b_1 + (b_2 - 3)^2/4\right)$ を自由度 2 のカイ二乗分布と比べる。
  この漸近分布は大標本でしか正確でなく、$n = 40$ 程度では棄却率が名目値を下回る。

オプション付き形式 `skew_test_with_options`、`kurtosis_test_with_options`、`normality_test_with_options`、`jarque_bera_test_with_options`、`shapiro_wilk_test_with_options` が変えられるのは、対立仮説（歪度と尖度の検定だけ）と作業領域の上限で、どれも漸近分布だけを持つので `Exact` を拒む。

### 正規性検定の棄却率と検出力

次のセルは、標準正規分布と中心化した指数分布を混ぜた

$$
X = \sqrt{1 - p}\, Z + \sqrt{p}\,(E - 1), \qquad Z \sim N(0, 1),\ E \sim \mathrm{Exp}(1)
$$

から大きさ $n$ の標本を $R$ 回引き、$\alpha = 0.05$ で正規性を棄却した割合を混合率 $p = 0, 0.1, \dots, 0.6$ ごとに求める。
$X$ の平均は 0、分散は 1 で、歪度は $2p^{3/2}$、過剰尖度は $6p^2$ である。
$p = 0$ では帰無仮説が真なので、棄却率は検定の実際の大きさ（サイズ）を表す。
$p > 0$ では棄却率は検出力で、母数を固定した KS 検定と CvM 検定の帰無仮説 $N(0, 1)$ も平均と分散は合っていて、形だけが違う。
KS 検定はワンショット呼び出しの `ks_one_sample_test` で行い、Durbin 行列の手数が既定の上限を超えた反復では漸近近似の p 値を使う。
比べる検定は Shapiro–Wilk、D'Agostino–Pearson の $K^2$、Jarque–Bera、歪度検定、尖度検定、$N(0, 1)$ を指定した KS 検定と CvM 検定、平均と標準偏差を標本から推定した $N(\bar x, s^2)$ に対する KS 検定である。
表は入力の混合率での棄却率と、その Clopper–Pearson の 95% 区間（`binomial_test` の区間）である。

```rust
            kurtosis_test(&sample),
            ks_one_sample_test(&sample, |v| normal.cdf(v)),
            cramer_von_mises_test(&sample, |v| normal.cdf(v)),
            ks_one_sample_test(&sample, |v| fitted.cdf(v)),
        ];
        for (c, result) in count.iter_mut().zip(results) {
            let p_value = result.map_err(|e| e.to_string())?.p_value();
            *c += usize::from(p_value < alpha);
        }
    }
}
let rate = |c: usize| c as f64 / replicates as f64;
let series: Vec<serde_json::Value> = [0_usize, 1, 2, 5, 7]
    .iter()
    .map(|&t| {
        let points: Vec<[f64; 2]> = (0..7)
            .map(|l| [l as f64 * 0.1, rate(counts[l][t])])
            .collect();
        serde_json::json!({ "name": names[t], "points": points })
    })
    .collect();
emit_chart!(
    serde_json::json!({
        "kind": "line",
        "series": series,
        "xLabel": "指数分布の混合率 p [-]",
        "yLabel": "正規性を棄却した割合 [-]",
        "yMin": 0.0,
        "dataZoom": true,
        "tooltip": true,
        "annotations": [
            { "kind": "line", "axis": "y", "value": alpha, "label": "名目の α = 0.05" },
            { "kind": "line", "axis": "x", "value": p_cont, "label": "表の混合率" }
        ]
    }),
    metadata = serde_json::json!({ "id": "power" })
);
let level = (p_cont * 10.0).round() as usize;
let mut rows = Vec::new();
for (t, name) in names.iter().enumerate() {
    let check = binomial_test_with_options(
        counts[level][t],
        replicates,
        alpha,
        ClassicalOptions::default(),
    )
    .map_err(|e| e.to_string())?;
    let interval = check.interval().ok_or("区間がない")?;
    rows.push((
        *name,
        rate(counts[level][t]),
        interval.lower(),
        interval.upper(),
    ));
}
let f3 = serde_json::json!({ "fractionDigits": 3 });
let columns = serde_json::json!([
    { "key": "0", "label": "検定" },
    { "key": "1", "label": "棄却した割合 [-]", "type": "number", "format": f3 },
    { "key": "2", "label": "95% 区間の下端 [-]", "type": "number", "format": f3 },
    { "key": "3", "label": "95% 区間の上端 [-]", "type": "number", "format": f3 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "rates" })

```

$p = 0$ の行は検定のサイズで、Shapiro–Wilk、母数を固定した KS と CvM の区間は 0.05 を含む。
$K^2$ はやや大きめ、Jarque–Bera はやや小さめの割合で棄却し、漸近分布の近似の誤差がこの大きさの標本でも残る。
平均と標準偏差を推定した KS 検定の棄却率は 0 に近く、母数を固定した帰無分布を推定した母数に流用すると、検定は帰無仮説をほとんど棄却しない。
$p$ を増やすと、Shapiro–Wilk と $K^2$ の棄却率は母数を固定した KS 検定より速く上がり、$p = 0.6$（歪度 0.93）では 0.41 と 0.39 に対して KS 検定は 0.10 である。
KS 検定は分布の中央の差を主に見るので、裾の形の違い（歪度・尖度）への検出力が低い。

## 2 標本と k 標本の分布の比較

独立な群が同じ分布に従うかの検定では、帰無仮説のもとで群のラベルが交換可能なので、ラベルの割り当てを数え上げる正確な分布が作れる。
結果の `null_parameters()` は `Exchangeable` を返す。

- `ks_two_sample_test(x, y)` は 2 つの ECDF $F_n$ と $G_m$ の差の最大値を統計量にする（`Greater` は $\max_t(F_n - G_m)$、`Less` は $\max_t(G_m - F_n)$、両側はその大きいほう）。
  正確な p 値は格子の経路を数えて $O(nm)$ の時間と $O(m)$ の作業領域で求め、`Auto` は $nm$ が `max_work` 以下なら使う。
  超えると、両側は $\sqrt{nm/(n+m)}\,D$ の Kolmogorov 分布、片側は $\exp(-2nmD^2/(n+m))$ で近似する。
  どちらも連続分布を前提にするので、同順位があると `InvalidInput` を返す。
  同順位のあるデータや離散データには、ラベルの置換で p 値を求める `ks_two_sample_permutation_test`（出力先を指定する API `ks_two_sample_permutation_test_into`、結果は `KsPermutationResult`）を使う。
- `cramer_von_mises_two_sample_test(x, y)` は 2 標本の CvM 統計量 $T = U/(nmN) - (4nm - 1)/(6N)$（$U$ は各群の整列した中間順位と期待位置の差の 2 乗和、$N = n + m$）を統計量にする。
  `Auto` は $\binom{N}{n}$ が上限以下なら全割り当てを数え上げ（同順位があっても正確）、超えれば Anderson の極限分布の近似を使う。
  近似は同順位のないデータを前提にし、同順位があると `InvalidInput` を返す。
  対立仮説は両側だけである。
- `epps_singleton_two_sample_test(x, y, points)` は、併合標本の四分位偏差で割った 2 つの周波数 `points`（通常は `[0.4, 0.8]`）で、2 群の経験特性関数の実部と虚部の差を比べる。
  統計量は差の推定共分散の逆行列による 2 次形式で、自由度 4 のカイ二乗分布を参照し、両群とも 25 未満のときは Epps–Singleton の小標本補正を掛ける。
  順位を使わないので、同順位の多い離散データにも使える。
  各群 5 個以上の観測が必要で、推定共分散が数値的に特異なら `Singular` を返す。
- `anderson_k_sample_test(groups)` は Scholz–Stephens の k 標本 Anderson–Darling 検定で、統計量は $(A^2 - (k-1))/\sigma_n$（$\sigma_n^2$ は有限標本の帰無分散）である。
  p 値は有意水準 0.25、0.1、0.05、0.025、0.01、0.005、0.001 の臨界値の表を対数線形に補間したもので、$[0.001, 0.25]$ に切り詰める。
  そのため両端の値は p 値の範囲を表すだけで、正確な p 値が必要なら置換で求める。
  同順位の扱いは `AndersonKVariant` で選び、`Midrank`（ワンショット呼び出しの既定、連続と離散の両方に使える）、`Right`（右連続の ECDF、離散分布向け）、`Continuous`（同順位があると `InvalidInput`）がある。

オプション付き形式 `ks_two_sample_test_with_options` と `cramer_von_mises_two_sample_test_with_options` は対立仮説（CvM は両側だけ）、較正、`max_work`、作業領域の上限を変え、`epps_singleton_two_sample_test_with_options` と `anderson_k_sample_test_with_options` は漸近分布だけを持つので `Exact` を拒む。

## 尺度と分散の等質性の検定

群の分散（尺度）が等しいかを検定する方法は、正規性を仮定するかどうかで分かれる。

- `bartlett_test(groups)` は、正規母集団のもとでの尤度比検定を補正した統計量

  $$
  B = \frac{(N-k)\ln s_p^2 - \sum_i (n_i - 1)\ln s_i^2}{1 + \dfrac{1}{3(k-1)}\left(\sum_i \dfrac{1}{n_i - 1} - \dfrac{1}{N-k}\right)}
  $$

  を自由度 $k - 1$ のカイ二乗分布と比べる。
  $s_i^2$ は群 $i$ の不偏分散、$s_p^2$ は併合分散、$N = \sum_i n_i$ である。
  $B$ の帰無分布は正規分布の 4 次積率に依存するので、裾の重い分布や歪んだ分布では分散が等しくても実際の棄却率が $\alpha$ を大きく超える（下のセル）。
- `levene_test(groups)` は、各観測の群の中心からの絶対偏差 $|x_{ij} - c_i|$ に一元配置分散分析の F 検定を当て、自由度 $(k-1, N-k)$ の F 分布の上側確率を p 値にする。
  中心は `VarianceCenter` で選ぶ。
  `Mean`（Levene の元の検定）は対称で裾の軽い分布向き、`Median`（Brown–Forsythe の検定、ワンショット呼び出しの既定）は歪んだ分布に対しても棄却率が安定する。
  `Trimmed { proportion }` は各群の両端から $\lfloor pn \rfloor$ 個を除いた残りの平均を中心にし、除いた観測は偏差の計算と自由度からも外す。
  中央値とトリム平均は線形時間の選択で求めるので、計算量は $O(N)$ である。
- `fligner_test(groups)` は Fligner–Killeen の検定で、群の中心からの絶対偏差に全群を通した順位 $r$ を付け、正規スコア $a = \Phi^{-1}(1/2 + r/(2(N+1)))$ に置き換えてから、スコアの群平均のばらつき $X^2 = \sum_i n_i(\bar a_i - \bar a)^2/s^2$ を自由度 $k - 1$ のカイ二乗分布と比べる。
  中心は Levene と同じ `VarianceCenter` で選ぶ。
  Conover–Johnson–Johnson（1981）の比較で、非正規分布に対して棄却率が安定し検出力も高い検定とされる。
- `mood_scale_test(x, y)` と `ansari_bradley_test(x, y)` は 2 群の尺度の順位検定である。
  併合した中間順位 $r$ に、Mood は $(r - (N+1)/2)^2$、Ansari–Bradley は $\min(r, N+1-r)$ のスコアを付け、$x$ のスコアの和を実際のスコアから求めた帰無平均と分散で標準化した $z$ を統計量にする。
  $z > 0$ は $x$ のほうが散らばっていることを表し、片側の対立仮説もこの向きで決まる。
  `Auto` は $\binom{N}{n}$ が上限以下なら全割り当てを数え上げ、超えれば $z$ の正規近似を使う。
  どちらも 2 群の位置（中央値）が等しいことを前提にし、位置がずれていると尺度の違いと区別できない。

オプション付き形式 `bartlett_test_with_options`、`levene_test_with_options(groups, center, options)`、`fligner_test_with_options(groups, center, options)` はカイ二乗または F の近似だけを持ち、`Exact` と片側の対立仮説を拒む。
`mood_scale_test_with_options` と `ansari_bradley_test_with_options` は対立仮説、較正、`max_work` を変えられる。

## 中央値検定

`median_test(groups)` は Mood の中央値検定で、$k$ 個の独立な群の中央値が等しいという帰無仮説を検定する。
全観測を併合した中央値より上か下かで各観測を分類して $2 \times k$ の分割表を作り、Pearson のカイ二乗統計量を自由度 $k - 1$ のカイ二乗分布と比べる。
併合した中央値に等しい観測の扱いは `MedianTies` で選び、`Below`（ワンショット呼び出しの既定）は下、`Above` は上に数え、`Ignore` は表から除く。
2 群のときは、`ClassicalOptions::continuity` が `HalfUnit` なら Yates の連続性補正を掛ける。
オプション付き形式 `median_test_with_options(groups, ties, options)` で同順位の扱いと連続性補正を変えられ、`Exact` と片側の対立仮説は拒む。
結果の `MedianTestOutcome` は、カイ二乗検定の結果 `test`、併合した中央値 `grand_median`、各群の `[上, 下]` の数 `table` を公開フィールドで持つ。
中央値検定は位置だけを比べるが、観測を 2 値に縮めるので、正規分布のもとでは順位検定より検出力が低い。

## 一括実行と結果の型

同じ分布の検定を多数の行に当てるときは、`distribution_tests_into` に検定の種類 `DistributionBatchTest`、行列のビュー（2 標本の検定は 2 つ目のビュー `y`）、出力、`DistributionBatchWorkspace` を渡す。
`DistributionBatchTest` は `Skew`、`Kurtosis`、`Normality`、`JarqueBera`、`Shapiro`、`KsOne(cdf)`、`CramerVonMisesOne(cdf)`、`KsTwo`、`CramerVonMisesTwo`、`EppsSingleton(points)`、`Mood`、`AnsariBradley`、`Bartlett`、`Levene(center)`、`Fligner(center)`、`AndersonK(variant)` で、それぞれ同名の検定のオプション付き形式を呼ぶ。
等分散性と k 標本の検定は一括実行では 2 群（`x` と `y` の行）に限られる。
作業領域は行の写しと結果を持つが、各検定はその中でも自分の作業領域を確保する。

## 実行例：同じ分布から引いた群での棄却率

分散の等質性や分布の一致の検定が、前提の崩れにどれほど影響されるかを、帰無仮説が真のデータで測る。
次のセルは、同じ分布から大きさ $n$ の 3 群を $R$ 回引き、各検定が $\alpha = 0.05$ で棄却した割合を求める。
3 群とも同じ分布なので、どの検定の帰無仮説も真であり、較正された検定の棄却率は 0.05 に近くなる。
2 標本の検定は最初の 2 群に当てる。
母集団は正規分布、指数分布（右に歪む）、自由度 3 の t 分布（裾が重く、4 次積率が存在しない）から選ぶ。
表の「帰無分布」は最初の反復で使った `DistributionMethod` で、正確な分布を使った検定は `Exact` になる。

```rust

//| ref: stats-distribution-and-variance-tests-api-1
//| title: 同じ分布から引いた群で、等分散性と分布の比較の検定の棄却率を測る
//| run: button
//| crates: [scioxide-random, scioxide-stats]
//| inputs:
//|   population: {"type":"select","label":"母集団","options":[{"label":"正規分布 N(0, 1)","value":"normal"},{"label":"指数分布 Exp(1)","value":"exponential"},{"label":"t 分布（自由度 3）","value":"student"}],"value":"normal"}

//|   replicate_count: {"type":"range","label":"反復回数 R [回]","min":500,"max":2000,"step":500,"value":1000}
//|   seed: {"type":"integer","label":"乱数のシード","min":0,"max":100000,"value":5}
//| cases:
//|   - {"id":"skewed","label":"指数分布","description":"歪んだ分布では、分散が等しくても Bartlett と平均中心の Levene が名目の数倍の割合で棄却する。","inputs":{"population":"exponential"}}
//|   - {"id":"heavy-tail","label":"t 分布（自由度 3）","description":"裾の重い分布では Bartlett の棄却率が 0.3 を超え、中央値中心の Levene と Fligner–Killeen は名目値の近くにとどまる。","inputs":{"population":"student"}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"sizes","path":"/rows/0/3","approx":{"value":0.044,"atol":1e-12}}
//|       - {"artifact":"sizes","path":"/rows/3/3","approx":{"value":0.123,"atol":1e-12}}

//|       - {"artifact":"sizes","path":"/rows/0/3","approx":{"value":0.318,"atol":1e-12}}
//|       - {"artifact":"sizes","path":"/rows/1/3","approx":{"value":0.171,"atol":1e-12}}
//|   - case: heavy-tail
//|     expect:
//|       - {"artifact":"sizes","path":"/rows/0/3","approx":{"value":0.388,"atol":1e-12}}
//|       - {"artifact":"sizes","path":"/rows/2/3","approx":{"value":0.043,"atol":1e-12}}

let student = StudentT::<f64>::new(3.0).map_err(|e| e.to_string())?;
let mut rng = SplitMix64::from_seed(seed as u64);
let names = [
    ("bartlett_test", "分散が等しい"),
    ("levene_test（Mean）", "分散が等しい"),
    ("levene_test（Median）", "分散が等しい"),
    ("levene_test（Trimmed 0.1）", "分散が等しい"),
    ("fligner_test（Median）", "分散が等しい"),
    ("mood_scale_test", "尺度が等しい"),
    ("ansari_bradley_test", "尺度が等しい"),
    ("median_test", "中央値が等しい"),
    ("ks_two_sample_test", "分布が等しい"),
    ("cramer_von_mises_two_sample_test", "分布が等しい"),

];

        bartlett_test_with_options(&k, o),

        name,
        null,
        methods[t].clone(),

    { "key": "1", "label": "帰無仮説" },
    { "key": "2", "label": "帰無分布" },
    { "key": "3", "label": "棄却した割合 [-]", "type": "number", "format": f3 },
    { "key": "4", "label": "95% 区間の下端 [-]", "type": "number", "format": f3 },
    { "key": "5", "label": "95% 区間の上端 [-]", "type": "number", "format": f3 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "sizes" })
);
```

正規分布では、Bartlett 検定を含めてほとんどの検定の区間が 0.05 を含むか、0.05 を下回る（保守的）。
中央値を中心にした Levene 検定と Fligner–Killeen 検定は $n = 15$ で 0.03 前後に下がり、正確な 2 標本 KS 検定は統計量が離散的なので棄却率が名目値を下回る。
両端から観測を除く `Trimmed` の Levene 検定は、正規分布でも名目値の 2 倍を超える割合で棄却する。
この変種は除いた観測を偏差の計算と自由度からも外す。
Brown–Forsythe（1974）のトリム平均の変種は中心だけをトリム平均にして全観測の偏差を使うが、scioxide-stats はその変種を提供しない。
指数分布と t 分布では、Bartlett 検定の棄却率は 0.3 を超え（0.32 と 0.39）、平均を中心にした Levene 検定も 0.17 と 0.08 になる。
中央値を中心にした Levene 検定と Fligner–Killeen 検定の棄却率は母集団の形によらず 0.07 以下で、順位に基づく Mood と Ansari–Bradley の検定、中央値検定、分布の一致の検定も名目値の近くか下にとどまる。

## まとめ

ECDF に基づく適合度検定の帰無分布は、連続で母数を固定した $F$ のときだけ分布によらず、母数を標本から推定するとその分布は使えず、`goodness_of_fit_test_into` のパラメトリック bootstrap で較正する。
正規性の検定では Shapiro–Wilk と $K^2$ が歪みと裾の重さに高い検出力を持ち、Jarque–Bera の漸近分布は数十点の標本では棄却率が名目値を下回る。
2 標本・k 標本の検定は、`Auto` が状態数に応じて正確な数え上げと漸近近似を切り替え、同順位のあるデータには置換や中間順位の変種を使う。
分散の等質性の検定では、Bartlett 検定は非正規分布で過大に棄却するので、正規性を確かめられない場合は中央値を中心にした Levene 検定か Fligner–Killeen 検定を使う。
