母集団の分布関数 $F$ の逆関数 $Q(p) = F^{-1}(p)$ は一意に定まるが、有限の標本から作る分位点には複数の定義がある。
統計ソフトウェアの既定値もそれぞれ違い、小さな標本では定義の違いが結果に表れる。
このページは、経験分布関数、Hyndman と Fan が整理した九つの分位点の定義、選択による計算量、同順位の扱い、エクスペクタイルを説明する。
scioxide-stats がどの定義を使ったかを結果に記録する理由を示し、九つの定義の偏りと散らばりを実験で比べる。

## 経験分布関数

標本 $X_1, \dots, X_n$ の**経験分布関数**（empirical CDF）は、各観測で $1/n$ ずつ跳ぶ右連続の階段関数である。

$$
F_n(x) = \frac{1}{n} \sum_{i=1}^n \mathbf 1\{X_i \le x\}
$$

独立同分布の標本では、$n \to \infty$ で $\sup_x |F_n(x) - F(x)| \to 0$ がほとんど確実に成り立つ（Glivenko–Cantelli の定理）。
収束の速さは Dvoretzky–Kiefer–Wolfowitz の不等式 $P(\sup_x |F_n(x) - F(x)| > \varepsilon) \le 2e^{-2n\varepsilon^2}$ で表され、ずれはおよそ $1/\sqrt n$ の大きさである。

分位点の推定量 $\hat Q_n(p)$ は、$F$ が $Q(p)$ で正の連続な密度 $f$ を持てば、次の漸近正規性を持つ。

$$
\sqrt n \bigl(\hat Q_n(p) - Q(p)\bigr) \xrightarrow{d} \mathcal N\!\left(0,\; \frac{p(1-p)}{f(Q(p))^2}\right)
$$

密度が小さい裾（$p$ が 0 や 1 に近い）では分散が大きくなり、同じ標本数でも分位点の推定は不安定になる。
この極限は九つの定義のどれでも同じで、定義の違いは $O(1/n)$ の偏りとして現れる。

`EmpiricalDistribution::new(values, weights)` は標本を複製して $O(n \log n)$ で整列し、空の標本を `InvalidInput`、非有限値を `NonFinite` で拒む。
`weights` は `Unweighted`、`Weights::<_, Frequency>`（整数の度数）、`Weights::<_, Mass>`（相対的な質量）のどれかで、重み 0 の観測はどの照会でも無視する。
`cdf(x)` は $P(X \le x)$ を $O(\log n)$ で返す。
`survival(x)` は $P(X > x)$ を 1 から引かずに上側の重みを直接足すので、裾の小さい確率でも相対精度を保つ。
NaN の照会は `InvalidInput`、無限大の照会はそれぞれの極限の確率 0 か 1 を返す。
`estimated_cdf(x, rule)` は、分位点の定義に対応する分布関数の推定値を返す。
型 4〜9 では区分線形の分位点関数を反転した値で、`(h − α)/(n + 1 − α − β)` の形のプロット位置になる。
`total_weight()` は総重み $W$（件数、質量の和、度数の和）を返す。

多数の照会点と、配列のバッチとして並んだ独立な標本の組をまとめて評価するには、`cdf` を使う。
`cdf(view, queries, method)` は既定の設定で、`cdf_with_options` は `StatisticsOptions`（欠測と非有限値の方針、上限のバイト数）を受け取る。
`method` は `CdfMethod::Empirical`（$P(X \le x)$）、`Survival`（$P(X > x)$）、`Estimated(rule)`（`estimated_cdf` と同じ推定）から選ぶ。
各バッチは $O(n \log n)$ で整列し、照会には二分探索で答える。
質量の重みでは整列した照会点と標本を 1 回ずつ並行してたどる。
結果は `output[b·m + j]`（バッチ $b$、照会点 $j$、照会点の数 $m$）の順に並ぶ。
同じ形の照会を繰り返すときは、`CdfWorkspace::workspace_requirements(view, m, options, context)` で `CdfRequirements` を問い合わせ、`CdfWorkspace::workspace(&req)` で作った作業領域を `cdf_into` に渡して使い回すと、2 回目以降は確保をしない。
頻度重みは観測を展開せずに複製と同じ結果を与え、質量の重みは `Empirical`、`Survival` と、型 1 に当たる `Estimated` だけに対応する。

## Hyndman と Fan の九つの定義

昇順の順序統計量を $X_{(1)} \le \dots \le X_{(n)}$ とする。
Hyndman と Fan（1996）は、1 始まりの位置 $h = np + m$ の整数部 $j = \lfloor h \rfloor$ と端数 $g = h - j$ を使い、分位点を次の形にまとめた。

$$
\hat Q(p) = (1 - \gamma) X_{(j)} + \gamma X_{(j+1)}
$$

添字が 1 未満なら $X_{(1)}$、$n$ を超えれば $X_{(n)}$ に置き換える。
型 1〜3 は $p$ について不連続で、観測値か隣り合う観測値の平均を返す。
型 4〜9 は $\gamma = g$ で隣り合う順序統計量を線形補間する。
表の最後の列は、$\hat Q(p_k) = X_{(k)}$ となる確率の位置 $p_k$（プロット位置）である。

| 型 | `QuantileMethod` | $m$ | $\gamma$ | 位置 $p_k$ |
|---|---|---|---|---|
| 1 | `NearestRank` | $0$ | $g > 0$ で 1、$g = 0$ で 0 | 逆経験分布関数 |
| 2 | `AveragedInverseCdf` | $0$ | $g > 0$ で 1、$g = 0$ で 1/2 | 跳びで隣の観測と平均 |
| 3 | `ClosestObservation` | $-1/2$ | $g = 0$ かつ $j$ が偶数で 0、ほかは 1 | 最も近い観測（等距離なら偶数の順位） |
| 4 | `InterpolatedInverseCdf` | $0$ | $g$ | $k/n$ |
| 5 | `Hazen` | $1/2$ | $g$ | $(k - 1/2)/n$ |
| 6 | `Weibull` | $p$ | $g$ | $k/(n+1)$ |
| 7 | `Linear` | $1 - p$ | $g$ | $(k-1)/(n-1)$ |
| 8 | `MedianUnbiased` | $(p+1)/3$ | $g$ | $(k - 1/3)/(n + 1/3)$ |
| 9 | `NormalUnbiased` | $p/4 + 3/8$ | $g$ | $(k - 3/8)/(n + 1/4)$ |

型 6 の位置 $k/(n+1)$ は、連続分布で $F(X_{(k)})$ の期待値に等しい。
型 8 は、分布の形によらず $\hat Q(p)$ の中央値がほぼ $Q(p)$ に等しくなる（中央値不偏）定義で、Hyndman と Fan が推奨した。
型 9 は正規母集団で $\hat Q(p)$ の期待値がほぼ $Q(p)$ に等しくなる（平均不偏）定義である。
[九つの定義の偏りと散らばり](#九つの定義の偏りと散らばり)の節で、この二つの性質を正規標本で確かめる。

scioxide-stats は九つの定義に共通の位置の核を使い、$p$ の f64 の値を 2 進の有理数として正確に掛けて $j$ を求め、端数 $g$ だけを丸める。
そのため、$np$ が整数になるかどうかの判定が丸めで揺れない。
どの定義でも、$p = 0$ は最小値、$p = 1$ は最大値を返す。
確率は `QuantileProbability::new(p)` で作り、$[0, 1]$ の外を `InvalidInput`、非有限を `NonFinite` で拒む。

定義は `QuantileRule` で渡す。
`QuantileRule::new(method)` は九つの定義のどれかを選び、重みの型が trait `InterpolatedQuantiles`（`Unweighted` と `Frequency`）を実装するときだけ作れる。
頻度重みでは、各観測を度数の回数だけ繰り返した標本に定義を当てはめるが、その標本を作らない。
質量の重みは標本の大きさ $n$ を持たないので、補間の位置 $h = np + m$ が定まらない。
そのため質量には `QuantileRule::inverse_ecdf()`（重み付き経験分布関数の左連続な逆関数で、型 1 に当たる）だけがあり、`QuantileRule::<Mass>::new` はコンパイルできない。
結果の `QuantileResult` は値 `value`、確率 `probability`、定義 `convention` を持つ。
`QuantileConvention` は、重みなしの `Unweighted(QuantileMethod)`、質量の `MassInverseEcdf`、度数の `Frequency(QuantileMethod)` を区別するので、他のソフトウェアの値と比べるときに型の番号をそろえられる。

## 選択による分位点の計算

1 個の分位点のために全体を整列する必要はない。
`quantile_in_place(samples, p, rule)` は、呼び出し側の作業用の配列を並べ替えて分位点を選ぶ。
受け付ける配列の形は trait `SelectionSamples` が決め、形によってアルゴリズムと計算量が変わる。

| 作業用の配列 | 定義 | アルゴリズム | 計算量 |
|---|---|---|---|
| `&mut [S]`（重みなし） | 九つすべて | Rust 標準の `select_nth_unstable_by` で $j$ 番目を選び、補間が必要なら下側の区画の最大値を隣の順序統計量に使う | 平均 $O(n)$ |
| `Weights<&mut [(S, S)], Mass>`（観測と質量の組） | 逆経験分布関数 | 決定論的な三方向の introselect | 最悪 $O(n)$ |
| `Weights<&mut [(S, u64)], Frequency>`（観測と度数の組） | 九つすべて | 整列 | $O(n \log n)$ |

組は一つの単位として動く。
どの形でも確保をしない。
検査と添字の事前計算が済むまで配列は変えず、失敗したときの配列は入力のままである。
成功すると、配列は入力の並べ替えになる。
質量の累積は内部で正確な整数演算として足し合わせ、目標の質量 $pW$ との比較が丸めで揺れないようにしている。
同じ標本に何度も照会するなら、$O(n \log n)$ で一度整列し、重みなしの分位点の照会を $O(1)$ にする `EmpiricalDistribution` が向く。

`statistic(values, Unweighted, Statistic::quantile(p, rule))` や `Statistic::iqr(method)`（四分位範囲 $Q(3/4) - Q(1/4)$）も、内部の作業領域で同じ選択を使い、全体を整列しない。
値以下の観測の割合（percentile-of-score）は 1 回の走査で数える。
最頻値と同順位の補正は、同じ値の連なりを見つけるために整列する。

## 同順位と順位付け

`rank_slice(values, method)` は観測に 1 始まりの順位を付ける。
同じ値（同順位、tie）の扱いは `RankMethod` で選ぶ。
標本 $[1, 2, 2, 4]$ では次のようになる。

| `RankMethod` | 順位 | 用途の例 |
|---|---|---|
| `Average` | $[1, 2.5, 2.5, 4]$ | 順位検定（Wilcoxon、Spearman）の通常の規約 |
| `Minimum` | $[1, 2, 2, 4]$ | 競技の順位 |
| `Maximum` | $[1, 3, 3, 4]$ | 同順位の群が占める最大の順位 |
| `Dense` | $[1, 2, 2, 3]$ | 異なる値の通し番号 |
| `Ordinal` | $[1, 2, 3, 4]$ | 入力順で同点を解消 |

順位は `Rank` で返り、平均順位の半整数も二つの整数の組（下限と上限）として正確に保持する。
f64 への変換 `to_f64` は、正確に表せないとき（$2^{53}$ を超える整数、$2^{52}$ 以上の半整数）`Err` になる。
事前に確保した出力へ書き込む形として、1 本のスライスの `rank_slice_into` と、`BatchView` の各バッチを順位付けする `rank_axes_into` がある。
どちらも `StatisticsWorkspace` を使い回し、反復的な順位付けで確保をしない。
`rank_axes_into` で欠測や非有限の方針により除いた観測は `None` になり、順位に数えない。

値 $s$ の百分位の位置（percentile of score）は、`Statistic::percentile_of_score(s, kind)` で求める。
$s$ より小さい観測の数を $L$、$s$ 以下の観測の数を $U$ とすると、`PercentileKind` は百分率 $100\,c/n$ の $c$ を次のように選ぶ。
`Strict` は $c = L$、`Weak` は $c = U$、`Mean` は $c = (L + U)/2$ である。
`Rank` は、$s$ が標本にあれば同じ値の観測の平均順位 $c = (L + U + 1)/2$、なければ $c = L$ を使う。

同順位の群の大きさを $t_g$ とすると、順位の分散は次の係数の倍に減る。

$$
T = 1 - \frac{\sum_g (t_g^3 - t_g)}{n^3 - n}
$$

この補正係数は `Statistic::tie_correction()` で求まり、順位検定の正規近似の分散の補正に使う。

## エクスペクタイル

分位点 $Q(p)$ は、非対称な絶対損失 $\sum_i |p - \mathbf 1\{x_i \le q\}|\,|x_i - q|$ の最小点である。
損失を 2 乗に替えた最小点を**エクスペクタイル**（expectile）と呼ぶ（Newey と Powell, 1987）。

$$
e_\tau = \arg\min_e \sum_{i=1}^n \bigl|\tau - \mathbf 1\{x_i \le e\}\bigr|\,(x_i - e)^2
$$

最小点では $(1-\tau)\sum_{x_i \le e}(e - x_i) = \tau \sum_{x_i > e}(x_i - e)$ が釣り合い、$\tau = 1/2$ で算術平均になる。
分位点と違って、裾の観測の大きさそのものに反応する。

`Statistic::expectile(p)` は、重みなし（`Unweighted`）と質量（`Mass`）の標本で定義される（trait `ExpectileWeights`）。
釣り合いの式の左辺から右辺を引いた関数は $e$ について狭義単調減少で、隣り合う観測の間では 1 次式である。
scioxide-stats は、中央値の選択で順序統計量を二分して根を挟む区間を絞り、各ピボットでの関数の符号を正確に判定する。
最後の区間で 1 次式の根を閉じた形で求めるので、反復の停止許容誤差を使わない。
計算コストは平均 $O(n)$ で、標本を整列しない。
$p = 0$ と $p = 1$ では正の重みを持つ最小と最大の観測を返す。
結果の `ExpectileResult` は値と、丸めた結果での釣り合いの残差を重み付きの絶対偏差で割った `relative_balance_residual` を持つ。
この残差は計算の検算の目安で、誤差の上限ではない。

## 二つの規約の比較

固定した標本 $[1, 2, 4, 10]$ について、累積確率 $p$ を 0 から 1 まで動かし、型 1（逆経験分布関数）と型 7（線形補間）の分位点を `EmpiricalDistribution::quantile` で求めて描く。
二つの型は位置の式を直接評価した値とも比べ（f64 の算術による独立な検算）、その差の最大を出す。
選んだ $p$ での九つの定義の値も表にする。

```rust
//| id: stats-quantile-methods
//| ref: stats-quantile-methods
//| title: 確率の位置を動かして二つの標本分位点の規約を比べる
//| run: reactive
//| crates: [scioxide-stats]
//| inputs:
//|   probability: {"type":"range","label":"累積確率 p [-]","description":"経験分布の上で読む確率の位置を変える。","min":0,"max":1,"step":0.01,"value":0.75}
//| cases:
//|   - {"id":"median","label":"p = 0.5","description":"np = 2 が整数で、型 1 は 2、型 2 は 3 を返す。","inputs":{"probability":0.5}}
//|   - {"id":"between","label":"p = 0.6","description":"np = 2.4 は整数でなく、型 3 だけが一つ下の観測 2 を返し、補間する型は 2.8 から 4 に広がる。","inputs":{"probability":0.6}}
//|   - {"id":"maximum","label":"p = 1","description":"九つの定義がすべて最大値を返す。","inputs":{"probability":1}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"methods","path":"/rows/0/2","equals":4}
//|       - {"artifact":"methods","path":"/rows/1/2","equals":7}
//|       - {"artifact":"methods","path":"/rows/5/2","approx":{"value":8.5,"atol":1e-14}}
//|       - {"artifact":"methods","path":"/rows/6/2","approx":{"value":5.5,"atol":1e-14}}
//|       - {"artifact":"methods","path":"/rows/8/2","approx":{"value":7.375,"atol":1e-14}}
//|   - case: median
//|     expect:
//|       - {"artifact":"methods","path":"/rows/0/2","equals":2}
//|       - {"artifact":"methods","path":"/rows/6/2","approx":{"value":3.0,"atol":1e-14}}
//|   - case: between
//|     expect:
//|       - {"artifact":"methods","path":"/rows/2/2","equals":2}
//|       - {"artifact":"methods","path":"/rows/3/2","approx":{"value":2.8,"atol":1e-13}}
//|       - {"artifact":"methods","path":"/rows/7/2","approx":{"value":3.8666666666666667,"atol":1e-13}}
//|   - case: maximum
//|     expect:
//|       - {"artifact":"methods","path":"/rows/6/2","equals":10}
//|       - {"artifact":"methods","path":"/rows/8/2","equals":10}
use scioxide_stats::{
    EmpiricalDistribution, QuantileMethod, QuantileProbability, QuantileRule, Unweighted,
};

let sample = [1.0_f64, 2.0, 4.0, 10.0];
let law = EmpiricalDistribution::new(&sample, Unweighted).map_err(|e| e.to_string())?;
let quantile = |p: f64, method: QuantileMethod| -> Result<f64, String> {
    let p = QuantileProbability::new(p).map_err(|e| e.to_string())?;
    Ok(law
        .quantile(p, QuantileRule::new(method))
        .map_err(|e| e.to_string())?
        .value())
};
// 独立な検算: 型 1 は順位 ceil(np)、型 7 は 0 始まりの位置 (n-1)p の線形補間。
let n = sample.len();
let type1 = |p: f64| {
    if p == 0.0 {
        sample[0]
    } else {
        sample[((n as f64 * p).ceil() as usize).clamp(1, n) - 1]
    }
};
let type7 = |p: f64| {
    let h = (n - 1) as f64 * p;
    let j = (h.floor() as usize).min(n - 1);
    sample[j] + (h - j as f64) * (sample[(j + 1).min(n - 1)] - sample[j])
};
let (mut first, mut seventh, mut worst) = (Vec::new(), Vec::new(), 0.0_f64);
for i in 0..=200 {
    let p = f64::from(i) / 200.0;
    let a = quantile(p, QuantileMethod::NearestRank)?;
    let b = quantile(p, QuantileMethod::Linear)?;
    worst = worst.max((a - type1(p)).abs()).max((b - type7(p)).abs());
    first.push([p, a]);
    seventh.push([p, b]);
}

    { "key": "2", "label": "分位点 [-]", "type": "number", "format": fixed4 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "methods" })
);
emit_text!(format!(
    "型 1 と型 7 の、位置の式による検算との差の最大（201 点）: {worst:.1e}"
));
```

既定の $p = 0.75$（第 3 四分位数）では、$np = 3$ がちょうど整数なので型 1・3・4 は観測値 4 を返し、型 2 は跳びの両側の平均 7 を返す。
補間する型は位置の定数 $m$ の違いで 5.5（型 7）から 8.5（型 6）まで広がり、型 5 は 7、型 8 は 7.5、型 9 は 7.375 である。
4 個の標本では、第 3 四分位数の値が定義によって 4 から 8.5 まで変わる。
$p = 0.6$ では $np = 2.4$ が整数でないので、型 1 と型 2 はどちらも 3 番目の観測 4 を返し、型 3 は 2 番目の観測 2 を返す。
$p = 0$ と $p = 1$ では、九つの定義がすべて最小値 1 と最大値 10 を返す。
型 1 と型 7 の値は 201 点のすべてで位置の式による検算と $1.8 \times 10^{-15}$ 以内で一致し、差は補間の式の書き方による丸めの違いである。

## 九つの定義の偏りと散らばり

小さな標本では、九つの定義は同じ $p$ に対して系統的に違う値を返す。
どの定義が「正しい」かは、推定量に何を求めるかで決まる。
平均が真値に近いこと（平均不偏）を求めるか、真値を下回る確率が 1/2 であること（中央値不偏）を求めるかで、選ぶ定義が変わる。

次のセルは、標準正規分布から大きさ $n$ の標本を $R = 4000$ 回作り、各標本で九つの定義の $\hat Q(p)$ を求める。
真の分位点 $Q(p) = \Phi^{-1}(p)$ は、`ConfidenceProbability::new(2p − 1)` の両側の臨界値 $\Phi^{-1}((1 + (2p-1))/2)$ として求める。
表は、偏り $E[\hat Q] - Q$ とその Monte Carlo 標準誤差、$P(\hat Q < Q)$ の推定値、標準偏差を出す。
最後の列は、前節の漸近分散から求めた標準偏差 $\sqrt{p(1-p)/n}\,/\,\varphi(Q(p))$（$\varphi$ は標準正規密度）である。

```rust
//| id: stats-quantile-bias
//| ref: stats-quantile-bias
//| title: 正規標本で九つの分位点の定義の偏りと散らばりを比べる
//| run: button
//| crates: [scioxide-stats, scioxide-random, scioxide-core]
//| inputs:
//|   sample_size: {"type":"range","label":"標本の大きさ n","description":"各反復で正規分布から引く観測の数。","min":5,"max":50,"step":1,"value":10}
//|   probability: {"type":"range","label":"累積確率 p [-]","description":"推定する分位点の確率。","min":0.55,"max":0.99,"step":0.01,"value":0.9}
//|   sampling_seed: {"type":"integer","label":"乱数のシード","min":0,"max":100000,"value":11}
//| cases:
//|   - {"id":"large-sample","label":"n = 50","description":"偏りが小さくなり、定義の差が縮む。","inputs":{"sample_size":50}}
//|   - {"id":"extreme-tail","label":"p = 0.99","description":"位置 h が n を超え、七つの定義が最大値を返す。最大値でも Q(0.99) を下回ることが多い。","inputs":{"probability":0.99}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"bias","path":"/rows/0/6","approx":{"value":0.5405654216790318,"rtol":1e-9}}
//|       - {"artifact":"bias","path":"/rows/6/2","approx":{"value":-0.236,"atol":0.003}}
//|       - {"artifact":"bias","path":"/rows/6/4","approx":{"value":0.7045,"atol":0.005}}
//|       - {"artifact":"bias","path":"/rows/7/4","approx":{"value":0.478,"atol":0.005}}
//|       - {"artifact":"bias","path":"/rows/8/2","approx":{"value":0.031,"atol":0.003}}
//|   - case: large-sample
//|     expect:
//|       - {"artifact":"bias","path":"/rows/8/2","range":{"min":-0.008,"max":0.012}}
//|       - {"artifact":"bias","path":"/rows/6/2","approx":{"value":-0.051,"atol":0.003}}
//|   - case: extreme-tail
//|     expect:
//|       - {"artifact":"bias","path":"/rows/0/2","approx":{"value":-0.801,"atol":0.003}}
//|       - {"artifact":"bias","path":"/rows/8/4","approx":{"value":0.906,"atol":0.005}}
use scioxide_core::RealScalar;
use scioxide_random::{Distribution, Normal, SeedableRng, SplitMix64};
use scioxide_stats::{
    ConfidenceProbability, EmpiricalDistribution, QuantileMethod, QuantileProbability,
    QuantileRule, Unweighted,
};

const REPLICATES: usize = 4000;
let methods = [
    QuantileMethod::NearestRank,
    QuantileMethod::AveragedInverseCdf,
    QuantileMethod::ClosestObservation,
    QuantileMethod::InterpolatedInverseCdf,
    QuantileMethod::Hazen,
    QuantileMethod::Weibull,
    QuantileMethod::Linear,
    QuantileMethod::MedianUnbiased,
    QuantileMethod::NormalUnbiased,
];
let n = sample_size as usize;
let p = QuantileProbability::new(probability).map_err(|e| e.to_string())?;
// 真の分位点 Φ⁻¹(p) は、両側の確率 2p − 1 の正規の臨界値に等しい。
let truth: f64 = ConfidenceProbability::new(2.0 * probability - 1.0)
    .map_err(|e| e.to_string())?
    .normal_critical_value()
    .map_err(|e| e.to_string())?;
let density =
    RealScalar::exp(-0.5 * truth * truth) / RealScalar::sqrt(2.0 * core::f64::consts::PI);
let asymptotic_sd = RealScalar::sqrt(probability * (1.0 - probability) / n as f64) / density;

let standard = Normal::new(0.0_f64, 1.0).map_err(|e| e.to_string())?;
let mut rng = SplitMix64::from_seed(sampling_seed as u64);
let mut sums = [0.0_f64; 9];
let mut squares = [0.0_f64; 9];
let mut below = [0_usize; 9];
let mut sample = vec![0.0_f64; n];
for _ in 0..REPLICATES {
    for x in sample.iter_mut() {
        *x = standard.sample(&mut rng).map_err(|e| e.to_string())?;
    }
    // 一度整列すれば、九つの定義の照会はそれぞれ O(1)。
    let law = EmpiricalDistribution::new(&sample, Unweighted).map_err(|e| e.to_string())?;
    for (j, &method) in methods.iter().enumerate() {
        let q = law
            .quantile(p, QuantileRule::new(method))
            .map_err(|e| e.to_string())?
            .value();
        sums[j] += q - truth;
        squares[j] += (q - truth) * (q - truth);
        below[j] += usize::from(q < truth);
    }
}
let r = REPLICATES as f64;
let mut rows = Vec::new();
for (j, method) in methods.iter().enumerate() {
    let bias = sums[j] / r;
    let variance = (squares[j] / r - bias * bias) * r / (r - 1.0);
    let sd = RealScalar::sqrt(variance);
    rows.push((
        j as u32 + 1,
        format!("{method:?}"),
        bias,
        sd / RealScalar::sqrt(r),
        below[j] as f64 / r,
        sd,
        asymptotic_sd,
    ));
}
let fixed3 = serde_json::json!({ "fractionDigits": 3 });
let fixed4 = serde_json::json!({ "fractionDigits": 4 });
let columns = serde_json::json!([
    { "key": "0", "label": "型", "type": "integer" },
    { "key": "1", "label": "QuantileMethod", "type": "string" },
    { "key": "2", "label": "偏り E[Q̂] − Q [-]", "type": "number", "format": fixed4 },
    { "key": "3", "label": "偏りの標準誤差 [-]", "type": "number", "format": fixed4 },
    { "key": "4", "label": "P(Q̂ < Q) [-]", "type": "number", "format": fixed3 },
    { "key": "5", "label": "標準偏差 [-]", "type": "number", "format": fixed4 },
    { "key": "6", "label": "漸近の標準偏差 [-]", "type": "number", "format": fixed4 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "bias" })
);
```

既定の $n = 10$、$p = 0.9$ では、真の分位点は $Q(0.9) = 1.2816$ である。
型 7 は偏り $-0.236$（標準誤差 0.007）で、$P(\hat Q < Q) = 0.705$ と、真値を下回ることが多い。
型 6 は逆に $+0.191$ で、$P(\hat Q < Q) = 0.382$ である。
型 8 は $P(\hat Q < Q) = 0.478$、型 9 は偏り $+0.031$（標準誤差 0.008）で、それぞれ中央値不偏と平均不偏に最も近い。
ただし、どちらも $n = 10$ では Monte Carlo 標準誤差の 3〜4 倍のずれが残り、性質は近似である。
f64 の 0.9 は $9/10$ よりわずかに大きいので、$np$ は整数にならず、型 1 と型 2 はどちらも最大値 $X_{(10)}$ を返す（偏り $+0.244$）。
scioxide-stats は $np$ を正確に計算するのでこうなり、$p$ を 10 進で考えて $np = 9$ を期待すると値が食い違う。
標準偏差は型によって 0.46 から 0.59 まで違い、漸近の値 0.54 はその中間にある。

$n = 50$ にすると偏りは小さくなり、型 7 は $-0.051$、型 8 は $+0.009$、型 9 は $+0.005$ になる。
標準偏差は 0.23〜0.25 で、漸近の値 0.242 に近づく。
$p = 0.99$ では位置 $h$ が $n = 10$ を超え、型 4 と型 7 以外の七つの定義が最大値 $X_{(10)}$ を返す。
最大値でも $P(\hat Q < Q) = 0.906$ と真値を下回ることが多く、偏りは $-0.80$ になる。
標本の大きさに比べて裾の深い分位点は、どの定義でもよく推定できない。

## まとめ

標本分位点には九つの定義があり、小さな標本では定義の違いが中央値や四分位数を目に見えて変える。
定義の違いは $O(1/n)$ の偏りとして現れ、正規標本では型 9 の平均がほぼ真値に、型 8 の中央値がほぼ真値に一致する。
scioxide-stats は定義を `QuantileRule` で明示させ、結果の `QuantileConvention` にそれを記録するので、他のソフトウェアの値と比べるときは型の番号をそろえる。
質量の重みには逆経験分布関数（型 1 に当たる）だけがあり、他の定義はコンパイルできない。
1 回だけの照会には選択による `quantile_in_place`、繰り返しの照会には整列済みの `EmpiricalDistribution`、多数のバッチと照会点には `cdf_into` を使い分ける。
同順位の扱いは `RankMethod`、裾の大きさに反応する位置の尺度にはエクスペクタイルを使う。
