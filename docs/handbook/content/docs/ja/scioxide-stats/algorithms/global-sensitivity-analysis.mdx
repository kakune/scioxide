計算機モデルの入力が不確かなとき、出力のばらつきのどれだけがどの入力から来るのかを知りたい場面がある。
ある点の偏微分で測る局所感度は、その点の近くの線形な振る舞いしか表さない。
入力の分布の全体にわたって、非線形性と入力どうしの相互作用を含めて寄与を測る方法を大域的感度解析（global sensitivity analysis）と呼ぶ。
このページでは、出力の分散を入力ごとに分ける Sobol 指数を定義し、モデルの評価から推定する pick-freeze 法の推定量、その誤差、`scioxide-stats` の API を説明する。
数値例には、指数の閉形式が分かっている Ishigami 関数を使う。

## 分散分解と Sobol 指数

入力 $X=(X_1,\dots,X_d)$ の各成分は互いに独立で、出力 $Y=f(X)$ は二乗可積分とする。
このとき $f$ は、成分の部分集合ごとの項に一意に分解できる（Hoeffding 分解、Sobol の ANOVA 分解）。

$$
f(X) = f_0 + \sum_{i} f_i(X_i) + \sum_{i<j} f_{ij}(X_i,X_j) + \cdots + f_{1\cdots d}(X_1,\dots,X_d)
$$

ここで $f_0=E[Y]$、$f_i(X_i)=E[Y\mid X_i]-f_0$ で、高次の項も条件付き期待値から順に定まる。
各項は、自分が含むどの変数について平均しても 0 になるので、互いに直交する。
したがって出力の分散 $V=\mathrm{Var}(Y)$ は各項の分散の和になる。

$$
V = \sum_i V_i + \sum_{i<j} V_{ij} + \cdots + V_{1\cdots d},
\qquad V_i = \mathrm{Var}\bigl(E[Y\mid X_i]\bigr)
$$

$X_i$ の 1 次の Sobol 指数（first-order index）と総合指数（total-order index）を

$$
S_i = \frac{V_i}{V},
\qquad
S_{Ti} = \frac{E\bigl[\mathrm{Var}(Y\mid X_{\sim i})\bigr]}{V} = 1 - \frac{\mathrm{Var}\bigl(E[Y\mid X_{\sim i}]\bigr)}{V}
$$

と定義する（Sobol 1993、2001）。
$X_{\sim i}$ は $X_i$ を除くすべての成分である。
$S_i$ は $X_i$ だけで説明できる分散の割合で、$X_i$ を真の値に固定できたときに減る分散の期待値の割合にあたる。
$S_{Ti}$ は $X_i$ を含むすべての項の分散の和の割合で、$X_i$ 以外をすべて固定しても残る分散の期待値の割合にあたる。

二つの指数には次の性質がある。

- $0\le S_i\le S_{Ti}\le1$ で、$S_{Ti}-S_i$ は $X_i$ が関わる相互作用の割合である。
- $\sum_i S_i\le1$ で、等号は $f$ が加法的（相互作用の項がない）ときに限る。
  $\sum_i S_{Ti}\ge1$ で、相互作用の項は関わる変数の数だけ重複して数えられる。
- $S_{Ti}=0$ なら $X_i$ は出力に影響しないので、その入力を定数に固定してよい（factor fixing）。
  1 つの入力を真の値に固定したときに減る分散の期待値は $S_i$ の大きい入力ほど大きいので、$S_i$ は不確かさを先に減らす入力の順位になる（factor prioritization）。

入力が独立でないと、上の分解の項は直交せず、指数の分け方が一意でなくなる。
`scioxide-stats` は独立な入力の Sobol 指数だけを扱い、従属な入力の感度指数（Shapley 効果など）や、Morris 法のようなスクリーニング、モーメントに依らない指数は提供しない。
従属な入力は、独立な変数からの変換（Rosenblatt 変換など）で書けるなら、その独立な変数について指数を求める。

## Ishigami 関数の閉形式

Ishigami と Homma（1990）の関数は、3 つの独立な一様変数 $X_j\sim U(-\pi,\pi)$ に対する

$$
f(X) = \sin X_1 + a\sin^2 X_2 + b\,X_3^4\sin X_1
$$

で、感度解析の推定量を検証する標準の題材である。
$E[\sin X_1]=0$、$E[\sin^2 X_1]=1/2$、$E[X_3^4]=\pi^4/5$、$\mathrm{Var}(X_3^4)=\pi^8/9-\pi^8/25=16\pi^8/225$ を使うと、分散の成分は

$$
V_1 = \frac12\left(1+\frac{b\pi^4}{5}\right)^2,
\qquad V_2 = \frac{a^2}{8},
\qquad V_{13} = \frac{8b^2\pi^8}{225},
\qquad V_3=V_{12}=V_{23}=V_{123}=0
$$

で、全分散は $V=\frac12+\frac{a^2}{8}+\frac{b\pi^4}{5}+\frac{b^2\pi^8}{18}$ になる（Saltelli ら 2008）。
$a=7$、$b=0.1$ の値は次のとおりである。

| 入力 | $S_i$ | $S_{Ti}$ |
|---|---|---|
| $X_1$ | 0.3139 | 0.5576 |
| $X_2$ | 0.4424 | 0.4424 |
| $X_3$ | 0 | 0.2437 |

$X_3$ は 1 次の指数が 0 なので、主効果だけを見ると影響がないように見える。
しかし $X_1$ との積の項を通して出力の分散の 24% に関わり、$S_{T3}$ にだけ現れる。
$X_2$ は加法的な項だけなので $S_2=S_{T2}$ である。

次のブロックは、このページの三つのセルが共有する定義である。
`ishigami` が $f$、`to_input` が単位区間の座標 $u\in[0,1)$ を $X_j=\pi(2u-1)$ に写す変換、`ishigami_exact` が上の閉形式の指数に対応する。
`ishigami` の正弦は SciOxide の `RealScalar::sin` で計算する。

```rust
//| id: stats-sobol-ishigami-model
//| kind: definitions
//| title: Ishigami 関数と Sobol 指数の閉形式
//| crates: [scioxide-core]
use core::f64::consts::PI;
use scioxide_core::{SciOxideError, RealScalar};

/// Ishigami 関数の係数 a と b
pub(crate) const ISHIGAMI_A: f64 = 7.0;
pub(crate) const ISHIGAMI_B: f64 = 0.1;

/// 単位区間の座標 u ∈ [0, 1) を X = π(2u − 1) ∈ [−π, π) に写す
pub(crate) fn to_input(u: f64) -> f64 {
    PI * (2.0 * u - 1.0)
}

/// f(x) = sin x₁ + a sin² x₂ + b x₃⁴ sin x₁
pub(crate) fn ishigami(x: &[f64]) -> Result<f64, SciOxideError> {
    let (sin1, sin2) = (RealScalar::sin(x[0]), RealScalar::sin(x[1]));
    let square3 = x[2] * x[2];
    Ok(sin1 + ISHIGAMI_A * sin2 * sin2 + ISHIGAMI_B * square3 * square3 * sin1)
}

/// 閉形式の 1 次の指数 (S₁, S₂, S₃) と総合指数 (S_T1, S_T2, S_T3)
pub(crate) fn ishigami_exact() -> ([f64; 3], [f64; 3]) {
    let (a, b) = (ISHIGAMI_A, ISHIGAMI_B);
    let pi4 = PI * PI * PI * PI;
    let main1 = 1.0 + b * pi4 / 5.0;
    let v1 = 0.5 * main1 * main1;
    let v2 = a * a / 8.0;
    let v13 = 8.0 * b * b * pi4 * pi4 / 225.0;
    let v = v1 + v2 + v13;
    ([v1 / v, v2 / v, 0.0], [(v1 + v13) / v, v2 / v, v13 / v])
}
```

## pick-freeze Plan と推定量

$V_i$ と $S_{Ti}$ の分子は、入力の一部を共有する 2 点の出力の積や差の期待値として書ける。
互いに独立な $n\times d$ の標本行列 $A$ と $B$ を作り、$A$ の第 $i$ 列だけを $B$ の第 $i$ 列に置き換えた行列を $A_B^{(i)}$ と書く。
行 $k$ で、$B_k$ と $A_{B,k}^{(i)}$ は $X_i$ だけを共有し、$A_k$ と $A_{B,k}^{(i)}$ は $X_i$ 以外を共有する。
共有した成分を固定（freeze）し、残りを引き直す（pick）ので、pick-freeze 法と呼ぶ。
このとき

$$
\mathrm{Cov}\bigl(f(B),\,f(A_B^{(i)})\bigr) = V_i,
\qquad
\tfrac12 E\Bigl[\bigl(f(A)-f(A_B^{(i)})\bigr)^2\Bigr] = E\bigl[\mathrm{Var}(Y\mid X_{\sim i})\bigr]
$$

が成り立つ。
1 回の推定に要るモデルの評価は $A$、$B$、$d$ 個の $A_B^{(i)}$ の行で、合計 $n(d+2)$ 回である。

同じ期待値を推定する式はいくつもあり、分散が大きく違う。
$f_0$ と $V$ は $f(A)$ と $f(B)$ の $2n$ 個の出力をまとめた平均 $m$ と分散 $\hat V=\frac{1}{2n}\sum_k\bigl[(f(A_k)-m)^2+(f(B_k)-m)^2\bigr]$ で推定する。
古典的な推定量（Sobol 1993、Homma と Saltelli 1996）は、積の平均から $f_0^2$ を引く。

$$
\hat S_i^{\text{Sobol}} = \frac{\frac1n\sum_k f(B_k)\,f(A_{B,k}^{(i)}) - m^2}{\hat V},
\qquad
\hat S_{Ti}^{\text{HS}} = 1-\frac{\frac1n\sum_k f(A_k)\,f(A_{B,k}^{(i)}) - m^2}{\hat V}
$$

この形は、出力の平均 $|f_0|$ が標準偏差に比べて大きいと、二つの大きな量の差になって桁落ちし、$m^2$ の推定誤差も指数に入る。
`scioxide-stats` は、1 次の指数に Saltelli ら（2010）の推定量、総合指数に Jansen（1999）の推定量を使う。

$$
\hat S_i = \frac{1}{n\hat V}\sum_k \bigl(f(B_k)-m\bigr)\bigl(f(A_{B,k}^{(i)})-f(A_k)\bigr),
\qquad
\hat S_{Ti} = \frac{1}{2n\hat V}\sum_k \bigl(f(A_k)-f(A_{B,k}^{(i)})\bigr)^2
$$

1 次の式は、$f(A_k)$ が $B_k$ と独立なので期待値を変えずに引ける項を引いた形で、$f_0^2$ を推定せずに済む。
`scioxide-stats` は Saltelli らの式の $f(B_k)$ から $m$ を引いて使う。
$f(A_B^{(i)})-f(A)$ の期待値は 0 なので期待値は変わらず、出力に定数を足しても式の値は変わらない。
$f(A_{B}^{(i)})-f(A)$ は $X_i$ を共有しない部分を打ち消すので、制御変量と同じ働きで分散が下がる。
総合指数の Jansen の式は差の二乗の平均なので、負にならず、$f_0$ に依存しない。
Saltelli ら（2010）は試験関数での比較から、総合指数に Jansen の式、1 次の指数にこの形の式を勧めている。
どちらの推定量も一致推定量で、標準誤差は $O(n^{-1/2})$ で減る。
有限の $n$ では、推定値が負になったり 1 を超えたりすることがあり、`scioxide-stats` は $[0,1]$ に切り詰めない。

## 出力から指数を計算する API

`SobolEvaluations` は、pick-freeze Plan の出力を借用で持つ構造体である。
`a[k]` が $f(A_k)$、`b[k]` が $f(B_k)$ で、`hybrids` は行 $k$、成分 $i$ の $f(A_{B,k}^{(i)})$ を `hybrids[k * d + i]` に置く長さ $nd$ の配列である。
`dimensions` には $d$ を入れる。
モデルの評価を自分で並べる場合（外部のシミュレーターの結果を読み込む場合など）は、この形に詰めて `sobol_indices` に渡す。

`sobol_indices(evaluations)` は上の Saltelli と Jansen の推定量を計算し、`SobolIndices` を返す。
計算量は $O(nd)$ で、和は指数部の範囲を広げた累積で取る。
そのため、出力に定数を足しても、0 でない定数を掛けても、推定値は丸めの範囲でしか変わらない。
次の場合はエラーを返す。

- `dimensions` が 0、$n<4$、`b` の長さが $n$ でない、`hybrids` の長さが $nd$ でないときは `InvalidInput` を返す。
- 出力に NaN か無限大があると `NonFinite` を返す。
- まとめた出力の分散が 0 なら、指数が定義できないので `NumericalInstability` を返す。

`SobolIndices` は推定の結果で、`first_order()` が $\hat S_i$、`total_order()` が $\hat S_{Ti}$ を入力の順に返す。
`rows()` は Plan の行数 $n$（乱択準モンテカルロ法では全反復の行数の和）を返す。
`randomized_standard_error()` は乱択準モンテカルロ法の反復から求めた $(\hat S_i, \hat S_{Ti})$ の標準誤差の組を返し、それ以外の方法では `None` を返す。

## モンテカルロ法による推定

`sobol_indices_monte_carlo(dimensions, rows, root, sampler, model)` は、$A$ と $B$ を独立な乱数で生成し、モデルを評価して指数を求める。

- 行 $k$ の乱数は `root.split(k)` の子の乱数列から作るので、結果は実行の分割によらず、`root` 自体は進まない。
  子の乱数列からは、成分 $j=0,1,\dots$ の順に `sampler(j, rng)` で $A_{k,j}$、$B_{k,j}$ を交互に引く。
- `sampler(j, rng)` は成分 $j$ の周辺分布から 1 個を返す。
  一様分布なら `rng.next_float()` を写し、一般の分布なら逆累積分布関数か `scioxide-random` の分布の `sample` を使う。
- `model` は $A_k$、$B_k$、各 $A_{B,k}^{(i)}$ で呼ばれ、合計 $n(d+2)$ 回になる。
  出力はすべて保存するので、メモリ使用量は $O(nd)$ である。
- `dimensions` が 0、`rows` が 4 未満か `u64` に収まらないときは `InvalidInput` を返す。
  `sampler` か `model` が非有限の値を返すと `NonFinite`、出力の分散が 0 なら `NumericalInstability` を返し、コールバックのエラーはそのまま返す。

戻り値の `SobolMonteCarloResult` は、`indices()` で `SobolIndices` を、`evaluations()` で保存した出力を `SobolEvaluations` として返す。
出力を残すのは、モデルを評価し直さずにブートストラップ区間や別の推定量を計算するためである。
ワーカーの数、メモリ使用量の上限（`StatisticsOptions::max_bytes`）、取り消しを指定するときは、`StatisticsOptions` と実行コンテキストを受け取るスコープ付き API `sobol_indices_monte_carlo_scoped` を使う。
ほかの計算の内側で呼ぶと、モデルの評価回数が親の作業量の上限から差し引かれる。
保存する出力が上限を超えると `ResourceLimit`、取り消されると `ExecutionStopped` を返す。

次のセルは、Ishigami 関数の指数を行数 $n$ のモンテカルロ法で推定し、閉形式と比べる。
入力は行数 $n$ と乱数のシードで、モデルの評価は $5n$ 回である。
保存した出力 $f(A)$、$f(B)$、$f(A_B^{(i)})$ と乱数のシードは、次の節のセルに渡す。

```rust
//| id: stats-sobol-monte-carlo
//| ref: stats-sobol-monte-carlo
//| title: Ishigami 関数の Sobol 指数をモンテカルロ法で推定して閉形式と比べる
//| run: button
//| cache: inputs
//| uses: [stats-sobol-ishigami-model]
//| crates: [scioxide-core, scioxide-random, scioxide-stats]
//| exports: [a, b, hybrids, seed]
//| inputs:
//|   rows: {"type":"integer","label":"行数 n","description":"モデルの評価は 5n 回。","min":64,"max":8192,"value":2048}
//|   seed: {"type":"integer","label":"乱数のシード","min":0,"max":100000,"value":42}
//| cases:
//|   - {"id":"few-rows","label":"n = 64","description":"行が少ないと推定値が閉形式から大きく外れる。","inputs":{"rows":64}}
//|   - {"id":"many-rows","label":"n = 8192","description":"行を 4 倍にすると誤差の標準偏差は半分になる。","inputs":{"rows":8192}}
//|   - {"id":"other-seed","label":"シード = 7","description":"別の乱数列での推定値のばらつきを見る。","inputs":{"seed":7}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"indices","path":"/rows/0/1","approx":{"value":0.313905191,"atol":1e-8}}
//|       - {"artifact":"indices","path":"/rows/2/3","approx":{"value":0.243683664,"atol":1e-8}}
//|       - {"artifact":"indices","path":"/rows/0/2","approx":{"value":0.35288,"atol":1e-4}}
//|       - {"artifact":"indices","path":"/rows/0/4","approx":{"value":0.61207,"atol":1e-4}}
//|       - {"artifact":"indices","path":"/rows/1/2","range":{"min":0.40,"max":0.49}}
//|       - {"artifact":"indices","path":"/rows/2/4","range":{"min":0.20,"max":0.29}}
//|   - case: few-rows
//|     expect:
//|       - {"artifact":"indices","path":"/rows/0/4","approx":{"value":0.66502,"atol":1e-4}}
//|   - case: many-rows
//|     expect:
//|       - {"artifact":"indices","path":"/rows/2/2","approx":{"value":-0.00185,"atol":1e-4}}
//|       - {"artifact":"indices","path":"/rows/0/4","approx":{"value":0.56913,"atol":1e-4}}
//|   - case: other-seed
//|     expect:
//|       - {"artifact":"indices","path":"/rows/0/2","approx":{"value":0.29497,"atol":1e-4}}
use scioxide_core::SciOxideError;
use scioxide_random::{Pcg64, Rng, SeedableRng};
use scioxide_stats::sobol_indices_monte_carlo;

let root = Pcg64::from_seed(seed as u64);
// 各成分は U(−π, π)。単位区間の一様乱数を to_input で写す
let sampler = |_j: usize, rng: &mut Pcg64| -> Result<f64, SciOxideError> {
    Ok(to_input(rng.next_float()?))
};
let result = sobol_indices_monte_carlo(3, rows as usize, &root, sampler, ishigami)
    .map_err(|e| e.to_string())?;
let indices = result.indices();
let (exact_first, exact_total) = ishigami_exact();
let rows_out: Vec<_> = ["X₁", "X₂", "X₃"]
    .iter()
    .enumerate()
    .map(|(i, name)| {
        (
            *name,
            exact_first[i],
            indices.first_order()[i],
            exact_total[i],
            indices.total_order()[i],
        )
    })
    .collect();
let fixed4 = serde_json::json!({ "fractionDigits": 4 });
let columns = serde_json::json!([
    { "key": "0", "label": "入力" },
    { "key": "1", "label": "Sᵢ 閉形式 [-]", "type": "number", "format": fixed4 },
    { "key": "2", "label": "Sᵢ 推定 [-]", "type": "number", "format": fixed4 },
    { "key": "3", "label": "S_Tᵢ 閉形式 [-]", "type": "number", "format": fixed4 },
    { "key": "4", "label": "S_Tᵢ 推定 [-]", "type": "number", "format": fixed4 }
]);
emit_table_with_columns!(
    columns,
    rows_out,
    metadata = serde_json::json!({ "id": "indices" })
);
emit_text!(&format!(
    "行数 n = {}、モデルの評価 {} 回",
    indices.rows(),
    indices.rows() * 5
));

let evaluations = result.evaluations();
export!(a, &evaluations.a);
export!(b, &evaluations.b);
export!(hybrids, &evaluations.hybrids);
export!(seed, &seed);
```

既定の $n=2048$（評価 10240 回）では、推定値は $\hat S_1=0.353$、$\hat S_2=0.460$、$\hat S_3=0.020$、$\hat S_{T1}=0.612$、$\hat S_{T2}=0.446$、$\hat S_{T3}=0.228$ である。
閉形式との差は $S_{T1}$ の 0.054 が最も大きく、$S_2$ と $S_{T2}$ の差は 0.02 以下である。
1 次の指数の順位 $S_2>S_1>S_3$ と総合指数の順位 $S_{T1}>S_{T2}>S_{T3}$ は閉形式と同じで、$X_3$ が総合指数にだけ現れることも読み取れる。
$n=64$ では $\hat S_{T1}=0.665$ まで外れ、$n=8192$ では $\hat S_{T1}=0.569$ に近づき、$\hat S_3=-0.0019$ は負になる。
推定値は $[0,1]$ に切り詰めないので、真の値が 0 に近い指数は負の推定値になりうる。
シードを 7 にすると $\hat S_1=0.295$ になり、1 回の推定値の誤差は乱数でばらつく。
誤差の大きさは、次の節のブートストラップ区間で見積もる。

## 推定量の比較とブートストラップ区間

モンテカルロ法の推定値の不確かさは、Plan の行を単位とするリサンプリングで見積もれる。
行 $k$ の出力 $\bigl(f(A_k), f(B_k), f(A_{B,k}^{(1)}),\dots,f(A_{B,k}^{(d)})\bigr)$ は、行どうしで独立で同じ分布に従う。
そこで行の番号を $n$ 個復元抽出し、同じ行の出力を組のまま使って指数を計算し直すことを $R$ 回繰り返す。
リサンプリングした指数の分布の $(1-c)/2$ 点から $(1+c)/2$ 点までを、信頼水準 $c$ のパーセンタイル区間とする（Efron と Tibshirani 1993、第 13 章）。

`sobol_bootstrap(evaluations, root, replicates, confidence)` はこの区間を計算し、`SobolBootstrap` を返す。

- 再標本 $r$ の乱数は、`root` の部分乱数列のうち $r$ だけで決まるものを使う。
- 分位点は Hyndman と Fan の第 7 種（線形補間）で求める。
- 計算は逐次で、計算量は $O(Rnd)$、メモリ使用量は行番号 $n$ 個と再標本の指数 $2Rd$ 個である。
- `evaluations` が `sobol_indices` の条件を満たさないときはそのエラー、`replicates < 2` なら `InvalidInput`、再標本の出力の分散が 0 なら `NumericalInstability` を返す。
- メモリ使用量の上限と取り消しを指定するときは、スコープ付き API `sobol_bootstrap_scoped` を使う。

`SobolBootstrap` の `first_order()` と `total_order()` は、入力ごとの区間を `(下限, 上限)` の組で返す。
`confidence()` は信頼水準、`replicates()` は再標本の数を返す。
この区間は行が独立であることを前提にしている。
1 本の準乱数列の点は互いに依存するので、その行を復元抽出しても区間は正しくならない。
準モンテカルロ法では、次の節の独立な乱択の反復から標準誤差を求める。

次のセルは、上のセルの出力を受け取り、`SobolEvaluations` に詰め直して `sobol_indices` で指数を計算する。
同じ出力から古典的な推定量（Sobol の 1 次、Homma–Saltelli の総合）を f64 の四則演算で計算し、Saltelli と Jansen の式を同じく手で計算した値と `sobol_indices` の差も示す。
入力の「出力に足す定数 $c$」は、すべての出力に $c$ を足してから計算する。
$c$ は指数の真の値を変えないので、推定値が $c$ で動くなら、その推定量は平均の大きさに弱い。
2 つ目の表は、再標本 $R$ 回のパーセンタイル 95% 区間と、区間が閉形式の値を含むかどうかである。

```rust
//| id: stats-sobol-estimators
//| ref: stats-sobol-estimators
//| title: Saltelli・Jansen の推定量と古典的な推定量を比べ、ブートストラップ区間を求める
//| run: button
//| timeoutMs: 120000
//| uses: [stats-sobol-ishigami-model]
//| crates: [scioxide-random, scioxide-stats]
//| dependsOn:
//|   design: stats-sobol-monte-carlo
//| inputs:
//|   offset: {"type":"range","label":"出力に足す定数 c","min":0,"max":1000,"step":10,"value":0}
//|   resamples: {"type":"integer","label":"再標本の数 R","min":50,"max":500,"value":200}
//| cases:
//|   - {"id":"large-offset","label":"c = 1000","description":"古典的な推定量が平均の大きさで崩れる。","inputs":{"offset":1000}}
//|   - {"id":"few-resamples","label":"R = 50","description":"再標本が少ないと区間の端がばらつく。","inputs":{"resamples":50}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"estimators","path":"/rows/0/2","approx":{"value":0.35288,"atol":1e-4}}
//|       - {"artifact":"estimators","path":"/rows/0/4","range":{"min":0,"max":1e-13}}
//|       - {"artifact":"estimators","path":"/rows/5/4","range":{"min":0,"max":1e-13}}
//|       - {"artifact":"estimators","path":"/rows/0/3","approx":{"value":0.32733,"atol":1e-4}}
//|       - {"artifact":"bootstrap","path":"/rows/0/2","approx":{"value":0.31275,"atol":1e-4}}
//|       - {"artifact":"bootstrap","path":"/rows/5/3","approx":{"value":0.24375,"atol":1e-4}}
//|       - {"artifact":"bootstrap","path":"/rows/4/4","equals":"含む"}
//|   - case: large-offset
//|     expect:
//|       - {"artifact":"estimators","path":"/rows/0/2","approx":{"value":0.35288,"atol":1e-4}}
//|       - {"artifact":"estimators","path":"/rows/5/3","range":{"min":2}}
//|       - {"artifact":"bootstrap","path":"/rows/0/2","approx":{"value":0.31275,"atol":1e-4}}
//|   - case: few-resamples
//|     expect:
//|       - {"artifact":"bootstrap","path":"/rows/0/2","approx":{"value":0.32320,"atol":1e-4}}
//|       - {"artifact":"bootstrap","path":"/rows/0/4","equals":"含まない"}

use scioxide_stats::{ConfidenceProbability, SobolEvaluations, sobol_bootstrap, sobol_indices};

let read = |key: &str| -> Result<Vec<f64>, String> {
    let values = design[key].as_array().ok_or(format!("{key} がない"))?;
    values
        .iter()
        .map(|v| {
            v.as_f64()
                .map(|y| y + offset)
                .ok_or(format!("{key} に数でない値"))
        })
        .collect()
};
let (a, b, hybrids) = (read("a")?, read("b")?, read("hybrids")?);
let seed = design["seed"].as_u64().ok_or("乱数のシードがない")?;
let evaluations = SobolEvaluations {
    a: &a,
    b: &b,
    hybrids: &hybrids,
    dimensions: 3,
};
let indices = sobol_indices(evaluations).map_err(|e| e.to_string())?;

// 独立検算: f64 の四則演算で推定量を計算する。m と V は f(A), f(B) の 2n 個から求める
let n = a.len() as f64;
let m = a.iter().chain(&b).sum::<f64>() / (2.0 * n);
let v = a.iter().chain(&b).map(|y| (y - m) * (y - m)).sum::<f64>() / (2.0 * n);
let (exact_first, exact_total) = ishigami_exact();
let mut rows = Vec::new();
for i in 0..3 {
    let ab = |k: usize| hybrids[k * 3 + i];
    let (mut saltelli, mut jansen, mut sobol, mut homma) = (0.0, 0.0, 0.0, 0.0);
    for k in 0..a.len() {
        saltelli += (b[k] - m) * (ab(k) - a[k]);
        jansen += (a[k] - ab(k)) * (a[k] - ab(k));
        sobol += b[k] * ab(k);
        homma += a[k] * ab(k);
    }
    let (s, t) = (indices.first_order()[i], indices.total_order()[i]);
    let classical_first = (sobol / n - m * m) / v;
    let classical_total = 1.0 - (homma / n - m * m) / v;
    let first_gap = (s - saltelli / (n * v)).abs();
    let total_gap = (t - jansen / (2.0 * n * v)).abs();
    rows.push((
        format!("S{}", i + 1),
        exact_first[i],
        s,
        classical_first,
        first_gap,
    ));
    rows.push((
        format!("S_T{}", i + 1),
        exact_total[i],
        t,
        classical_total,
        total_gap,
    ));
}

let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });

    { "key": "1", "label": "閉形式 [-]", "type": "number", "format": fixed4 },
    { "key": "2", "label": "Saltelli・Jansen [-]", "type": "number", "format": fixed4 },
    { "key": "3", "label": "Sobol・Homma–Saltelli [-]", "type": "number", "format": fixed4 },
    { "key": "4", "label": "手計算との差 [-]", "type": "number", "format": sci2 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "estimators" })
);

let confidence = ConfidenceProbability::new(0.95).map_err(|e| e.to_string())?;
let boot = sobol_bootstrap(evaluations, &root, resamples as usize, confidence)
    .map_err(|e| e.to_string())?;
let mut bounds = Vec::new();
for i in 0..3 {
    for (name, exact, (lower, upper)) in [
        (format!("S{}", i + 1), exact_first[i], boot.first_order()[i]),
        (
            format!("S_T{}", i + 1),
            exact_total[i],
            boot.total_order()[i],
        ),
    ] {
        let covers = if lower <= exact && exact <= upper {
            "含む"
        } else {
            "含まない"
        };
        bounds.push((name, exact, lower, upper, covers));
    }
}
let columns = serde_json::json!([
    { "key": "0", "label": "指数" },
    { "key": "1", "label": "閉形式 [-]", "type": "number", "format": fixed4 },
    { "key": "2", "label": "95% 下限 [-]", "type": "number", "format": fixed4 },
    { "key": "3", "label": "95% 上限 [-]", "type": "number", "format": fixed4 },
    { "key": "4", "label": "閉形式を" }
]);
emit_table_with_columns!(
    columns,
    bounds,
    metadata = serde_json::json!({ "id": "bootstrap" })
);
```

既定では、`sobol_indices` の推定値と同じ式を f64 の和で計算した値の差は $2.5\times10^{-15}$ 以下で、`sobol_indices` が上の Saltelli と Jansen の式を計算していることを確かめられる。
$c=0$ では、古典的な推定量（$\hat S_1=0.327$、$\hat S_3=-0.031$、$\hat S_{T3}=0.281$）も閉形式から 0.04 以内にある。
$c=1000$ にすると、Saltelli・Jansen の推定値は $10^{-14}$ より小さい差でしか変わらない。
一方、古典的な推定量は $\hat S_1=3.50$、$\hat S_3=-4.04$、$\hat S_{T3}=8.06$ となり、$[0,1]$ から大きく外れる。
$m^2\approx10^6$ と積の平均の差で約 14 の分散を取り出すので、積の平均の標本誤差（$|f_0|$ に比例する）が指数の誤差になる。

$R=200$ のパーセンタイル 95% 区間は、6 個の指数のすべてで閉形式の値を含む。
ただし $S_1$ の区間 $[0.313, 0.399]$ と $S_{T3}$ の区間 $[0.211, 0.244]$ は、端がちょうど閉形式の値の近くにある。
$R=50$ では区間の端の推定がばらつき、$S_1$、$S_{T1}$、$S_{T3}$ の 3 個で閉形式の値を外れる。
区間の端は少数の極端な再標本で決まるので、95% 区間には数百回以上の再標本を使う。
区間は出力に足した定数 $c$ によらない。
wasm での計算時間は、$n=2048$、$R=200$ で約 5 秒、$R=500$ で約 13 秒である。

## 乱択準モンテカルロ法

準モンテカルロ法（QMC）は、乱数の代わりに超一様分布列（低ディスクレパンシー列）の点を使う。
Sobol 列の最初の $2^k$ 点は単位立方体の基本区間に均等に入るので、滑らかな被積分関数の平均の誤差は $O(n^{-1}(\log n)^{s})$（$s$ は次元）まで下がりうる。
決定論的な点列だけでは誤差の大きさを推定できないので、点列を独立に $R$ 回乱択化（スクランブル）し、各反復の推定値のばらつきから標準誤差を求める（L'Ecuyer と Lemieux 2002）。

`sobol_indices_qmc(plan, dimensions, points, transform, model)` は、乱択準モンテカルロ法で pick-freeze Plan を作る。

- `plan` は `QmcReplicatePlan` で、$2d$ 次元の点列を $R$ 回独立に乱択化したものである。
  Sobol 列は線形行列スクランブルとデジタルシフト（Matoušek 1998）で乱択化し、反復ごとの点の数は 2 の冪にする。
- 各点の前半 $d$ 個の座標が $A$ の行、後半 $d$ 個が $B$ の行になる。
  `transform(j, u)` は単位座標 $u$ を成分 $j$ の入力に写す関数で、周辺分布の逆累積分布関数などを使う。
- 反復 $r$ ごとに `sobol_indices` と同じ推定量で $\hat S^{(r)}$ を計算し、結果はその平均、標準誤差は標準偏差を $\sqrt R$ で割った値である。
  `randomized_standard_error()` がこの標準誤差を返す。
  標準誤差は反復のばらつきから求めた推定値で、誤差の上限ではない。
- `model` は $R\cdot N(d+2)$ 回呼ばれる（$N$ は反復ごとの点の数）。
- `dimensions` が 0、`points` が 4 未満か `plan` の点の数と違う、反復が 2 未満、`plan` の次元が $2d$ でないときは `InvalidInput` を返す。
  `transform` が非有限の値を返すときも `InvalidInput`、`model` が非有限の値を返すと `NonFinite`、ある反復の出力の分散が 0 なら `NumericalInstability` を返す。

反復を並列に走らせるとき、メモリ使用量の上限と取り消しを指定するときは、スコープ付き API `sobol_indices_qmc_scoped` を使う。
推定値は反復の割り当て方によらない。

次のセルは、Ishigami 関数の指数を $N=2^k$ 点、$R$ 反復の乱択準モンテカルロ法で推定する。
比較のため、同じ評価回数（行数 $RN$）のモンテカルロ法でも推定し、両者の閉形式からの誤差を並べる。
最後の列は乱択準モンテカルロ法の誤差を標準誤差で割った値で、絶対値がおおむね 2 以下なら標準誤差が誤差の大きさを表している。
反復数 $R$ が小さいと標準誤差そのものが不確かになり、この比がばらつく。

```rust
//| id: stats-sobol-qmc
//| ref: stats-sobol-qmc

    Ok(to_input(rng.next_float()?))

    .map_err(|e| e.to_string())?;

            exact_first[i],
            qmc.first_order()[i],

            "S_T",
            exact_total[i],
            qmc.total_order()[i],
            total_se[i],
            mc.indices().total_order()[i],

    ] {
        let error = estimate - exact;
        rows.push((
            format!("{name}{}", i + 1),
            exact,
            estimate,
            se,
            (plain - exact).abs(),
            error / se,
        ));
    }

let fixed4 = serde_json::json!({ "fractionDigits": 4 });
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });

    { "key": "1", "label": "閉形式 [-]", "type": "number", "format": fixed4 },
    { "key": "2", "label": "RQMC 推定 [-]", "type": "number", "format": fixed4 },

]);
emit_table_with_columns!(columns, rows, metadata = serde_json::json!({ "id": "qmc" }));
```

既定の $N=1024$、$R=8$（行数 8192、評価 40960 回）では、乱択準モンテカルロ法の標準誤差は 0.0004〜0.0037 である。
同じ評価回数のモンテカルロ法の誤差は $S_1$ で 0.024、$S_{T1}$ で 0.012 で、乱択準モンテカルロ法の誤差（0.0003 と 0.0033）より大きい。
1 回の比較では、$S_3$ のようにモンテカルロ法の誤差の方が小さい指数もあるので、シードを変えて比べる。
シードを 42、7、0、100000 にした 24 個の推定では、モンテカルロ法の誤差の中央値が 0.0093、乱択準モンテカルロ法の誤差の中央値が 0.0019 だった。

反復数 $R=2$ の標準誤差は自由度 1 の推定なので、$S_3$ の比が 5.9 になるように、誤差を大きく過小評価することがある。
$N=64$ では標準誤差が 0.018〜0.042 に広がる。

## まとめ

Sobol 指数は出力の分散を入力ごとに分け、1 次の指数 $S_i$ は単独の寄与、総合指数 $S_{Ti}$ は相互作用を含む寄与を表す。
`scioxide-stats` は pick-freeze Plan の $n(d+2)$ 回の評価から、1 次の指数を Saltelli（2010）、総合指数を Jansen（1999）の推定量で計算し、出力の平均の大きさに左右されない。
独立な乱数で Plan を作るなら `sobol_indices_monte_carlo` を使い、保存した出力を `sobol_bootstrap` に渡して行の組のリサンプリングで区間を求める。
滑らかなモデルでは `sobol_indices_qmc` の乱択準モンテカルロ法が同じ評価回数でより小さい誤差を与え、標準誤差は独立な乱択化の反復から求める。
入力が従属な場合の指数は提供しないので、独立な変数への変換で書き直してから使う。
