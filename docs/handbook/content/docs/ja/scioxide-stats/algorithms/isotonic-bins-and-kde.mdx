このページは母数を持つ分布のモデルを仮定せずに、標本から関数の形を推定する 3 つの方法を扱う。
単調回帰は「増加する」という形の制約だけを課した回帰、ビン集計は格子の各区画に標本を数えて度数や密度を作る方法、核密度推定は各観測に滑らかな核を置いて重ねる密度の推定である。
どの方法も、推定値と一緒に、どの観測を使い、どの観測を除いたかを示す診断を返す。
各節で定義とアルゴリズムを説明し、閉形式や独立な求積で結果を確かめる。

## 単調回帰と PAVA

### 問題と解の形

観測 $y_1,\dots,y_n$ と重み $w_i\ge0$ に対し、非減少の列の中で重み付き 2 乗誤差を最小にする問題

$$
\min_{f_1\le f_2\le\cdots\le f_n}\ \sum_{i=1}^nw_i(y_i-f_i)^2
$$

を単調回帰（isotonic regression）と呼ぶ。
用量と反応率、格付けと不履行率のように、関係が単調であることは理論から分かっているが、関数の形は分からない場合に使う。
制約の集合は閉じた凸錐で、目的関数は（正の重みについて）狭義凸なので、解は一意に存在する。
解は定数の区間（ブロック）を並べた階段関数で、各ブロックの値はそのブロックに含まれる観測の重み付き平均になる（Barlow ら, 1972）。

### PAVA のアルゴリズム

PAVA（pool adjacent violators algorithm）は、観測を左から順に 1 個ずつブロックとして積み、直前のブロックの値が新しいブロックの値より大きい（順序に違反する）間、2 つのブロックを併合して値を重み付き平均

$$
\bar y_{A\cup B}=\frac{W_A\bar y_A+W_B\bar y_B}{W_A+W_B}
$$

に置き換える。
$W_A,W_B$ はブロックの重みの和である。
併合した値は 2 つの値の間にあるので、併合によって左隣との違反が新しく生じることがあり、その場合は併合を続ける。
ブロックはスタックに積み、各観測は高々 1 回しか併合されないので、計算量とメモリ使用量はどちらも $O(n)$ である。
反復最適化と違って有限回の手順で厳密解に達し、停止の許容誤差を持たない。
解が最適であることは Karush–Kuhn–Tucker 条件から示せる。
増加の制約では、各ブロックの先頭から数えた重み付き残差の部分和 $\sum w_i(y_i-f_i)$ がどれも非負（ブロックの前の部分の平均がブロックの値以上）で、ブロックの値が狭義に増加することが最適性の条件になる。

### 関数・結果・作業領域

`isotonic_regression(values)` は、重みなしの観測に観測の順で増加の当てはめを行い、`IsotonicResult` を返す。
重み、方向、欠測の方針はオプション付き形式 `isotonic_regression_with_options(values, weights, direction, options)` で与え、減少の制約には `IsotonicDirection::Decreasing` を指定する。
どちらの方向も非狭義で、隣り合う当てはめ値が等しくてよい。
重みのモデルはトレイト `IsotonicWeights` で制限され、重みなしの `Unweighted` と相対質量の `Mass` だけを受け付ける。
頻度の重み `Frequency` を渡すとコンパイルエラーになる。

`IsotonicResult` は、当てはめ値 `fitted()`、極大な定数区間 `blocks()`、診断 `diagnostics()` を返す。
`IsotonicBlock` は開始の添字 `start`（含む）、終了の添字 `end`（含まない）、値 `value`、重みの和 `weight` を持つ。
`IsotonicDiagnostics` はブロック数 `block_count`、使った観測の数 `retained`、除いた観測の数 `excluded`、重みの和 `weight`、当てはめでの重み付き 2 乗誤差 `squared_error` を持ち、重みの和と 2 乗誤差はスカラー型であふれると `None` になる。
重み 0 の観測は値を読む前に除くので、値が NaN でもよい。
除いた位置には直前の位置の当てはめ値を入れ、先頭が除かれたときは最初に当てはめた位置の値を入れるので、出力の全体が単調になる。
空でない入力で重みの和が 0、重みが負か NaN・無限大、正の重みを持つ観測が非有限で方針が拒否のときはエラーを返す。

確保を伴わずに繰り返し当てはめるときは、`IsotonicWorkspace::scalar_requirements(n, options)` で長さ $n$ までの `IsotonicRequirements` を求めて `IsotonicWorkspace::workspace` で作業領域を作り、`isotonic_regression_into` に当てはめの出力 `output` と `blocks` の領域を渡す。
多次元配列の各レーン（標本の軸に沿った 1 本の列）を当てはめるときは、`IsotonicWorkspace::workspace_requirements(view, options, context)` で見積もり、`isotonic_regression_axes_into` を使う。
出力は `IsotonicBatchOutput` にまとめ、`fitted` に入力と同じ形の当てはめ値、`blocks` にレーンごとの区間、`lanes` にレーンごとの `IsotonicLaneResult`（ブロックの開始位置 `block_offset` と診断）が入る。
レーンは独立で、並列に実行しても結果は同じである。

### 区間の併合を閉形式と照合する

次のセルは 5 点の観測 $(0,a,1,4,\mathrm{NaN})$ に重み $(1,w,1,1,0)$ を付けて増加の当てはめを行う。
$a>1$ なので 2 点目と 3 点目が順序に違反し、PAVA はこの 2 点を値 $(wa+1)/(w+1)$ の 1 つのブロックに併合する。
5 点目は重み 0 なので値を読まずに除き、直前の当てはめ値 4 を入れる。
重み付き 2 乗誤差の閉形式は $w\{a-(wa+1)/(w+1)\}^2+\{1-(wa+1)/(w+1)\}^2=w(a-1)^2/(w+1)$ である。

```rust
//| id: stats-isotonic-calibration
//| ref: stats-isotonic-calibration
//| title: 単調回帰の区間の併合を重み付き平均と照合する
//| run: reactive
//| crates: [scioxide-stats]
//| inputs:
//|   calibration_peak: {"type":"range","label":"2 点目の観測値 a [-]","description":"3 点目の 1 より大きいので順序の違反になる。","min":2,"max":3.8,"step":0.1,"value":3}
//|   calibration_weight: {"type":"range","label":"2 点目の重み w [-]","description":"併合したブロックの値を 2 点目へ引き寄せる強さ。","min":0.2,"max":5,"step":0.2,"value":1}
//| cases:
//|   - {"id":"heavy","label":"w = 5","description":"併合した値が 2 点目の a に近づく。","inputs":{"calibration_weight":5}}
//|   - {"id":"light","label":"w = 0.2","description":"併合した値が 3 点目の 1 に近づく。","inputs":{"calibration_weight":0.2}}
//|   - {"id":"small-violation","label":"a = 2","description":"違反が小さくなり、2 乗誤差も小さくなる。","inputs":{"calibration_peak":2}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"fit","path":"/rows/1/3","approx":{"value":2,"atol":1e-15}}
//|       - {"artifact":"fit","path":"/rows/4/3","approx":{"value":4,"atol":1e-15}}
//|       - {"artifact":"blocks","path":"/rows/1/1","equals":3}
//|       - {"artifact":"diagnostics","path":"/rows/0/1","equals":3}
//|       - {"artifact":"diagnostics","path":"/rows/0/3","equals":1}
//|       - {"artifact":"diagnostics","path":"/rows/0/4","approx":{"value":2,"atol":1e-14}}
//|   - case: heavy
//|     expect:
//|       - {"artifact":"fit","path":"/rows/1/3","approx":{"value":2.6666666666666665,"atol":1e-14}}
//|   - case: light
//|     expect:
//|       - {"artifact":"fit","path":"/rows/1/3","approx":{"value":1.3333333333333333,"atol":1e-14}}
use scioxide_stats::{
    IsotonicDirection, Mass, StatisticsOptions, Weights, isotonic_regression_with_options,
};

let (a, w) = (calibration_peak, calibration_weight);
// 5 点目は重み 0 なので、値（NaN）は読まれない。
let observed = [0.0_f64, a, 1.0, 4.0, f64::NAN];
let weights = [1.0_f64, w, 1.0, 1.0, 0.0];
let result = isotonic_regression_with_options(
    &observed,
    Weights::<_, Mass>::new(&weights),
    IsotonicDirection::Increasing,
    StatisticsOptions::new(),
)
.map_err(|e| e.to_string())?;
// 独立な検算: 違反する 2 点を重み付き平均で置き換え、5 点目に直前の値を入れた列。
let pooled = (w * a + 1.0) / (w + 1.0);
let expected = [0.0, pooled, pooled, 4.0, 4.0];
let fit: Vec<_> = (0..observed.len())
    .map(|i| {
        let value = (!observed[i].is_nan()).then_some(observed[i]);
        let fitted = result.fitted()[i];
        (
            i + 1,
            value,
            weights[i],
            fitted,
            (fitted - expected[i]).abs(),
        )
    })
    .collect();
let fixed4 = serde_json::json!({ "fractionDigits": 4 });
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let columns = serde_json::json!([
    { "key": "0", "label": "位置 i", "type": "integer" },
    { "key": "1", "label": "観測 y_i [-]", "type": "number", "format": fixed4, "nullText": "NaN" },
    { "key": "2", "label": "重み w_i [-]", "type": "number", "format": fixed4 },
    { "key": "3", "label": "当てはめ f̂_i [-]", "type": "number", "format": fixed4 },
    { "key": "4", "label": "閉形式との差 [-]", "type": "number", "format": sci2 }
]);
emit_table_with_columns!(columns, fit, metadata = serde_json::json!({ "id": "fit" }));
let blocks: Vec<_> = result
    .blocks()
    .iter()
    .map(|b| (b.start, b.end, b.value, b.weight))
    .collect();
let columns = serde_json::json!([
    { "key": "0", "label": "開始 start（含む）", "type": "integer" },
    { "key": "1", "label": "終了 end（含まない）", "type": "integer" },
    { "key": "2", "label": "値 [-]", "type": "number", "format": fixed4 },
    {
        "key": "3",
        "label": "重みの和 [-]",
        "type": "number",
        "format": fixed4,
        "nullText": "あふれ"
    }
]);
emit_table_with_columns!(
    columns,
    blocks,
    metadata = serde_json::json!({ "id": "blocks" })
);
let d = result.diagnostics();
let closed = w * (a - 1.0) * (a - 1.0) / (w + 1.0);
let columns = serde_json::json!([
    { "key": "0", "label": "量" },
    { "key": "1", "label": "ブロック数", "type": "integer" },
    { "key": "2", "label": "使った観測", "type": "integer" },
    { "key": "3", "label": "除いた観測", "type": "integer" },
    {
        "key": "4",
        "label": "重み付き 2 乗誤差 [-]",
        "type": "number",
        "format": fixed4,
        "nullText": "あふれ"
    },
    { "key": "5", "label": "閉形式 w(a − 1)²/(w + 1) [-]", "type": "number", "format": fixed4 }
]);
emit_table_with_columns!(
    columns,
    vec![(
        "診断",
        d.block_count,

```

既定の $a=3$、$w=1$ では、2 点目と 3 点目が値 2 のブロック $[1,3)$（重みの和 2）に併合され、ブロックは 3 個、重み付き 2 乗誤差は閉形式の $1\cdot2^2/2=2$ と一致する。
ブロックの添字は 0 から数えるので、表の位置 $i$ とは 1 ずれる。
5 点目の NaN は重み 0 なので読まれず、除いた観測の数が 1 になり、当てはめには直前の値 4 が入って最後のブロックは $[3,5)$ になる。
$w=5$ では併合した値が $(5\cdot3+1)/6=2.6667$ と 2 点目に近づき、$w=0.2$ では $1.3333$ と 3 点目に近づく。
$a$ を 2 から 3.8 に変えてもブロックの区切りは変わらず、値だけが重み付き平均として動く。
当てはめと閉形式の差は、どの入力でも 0 である。

## 直交格子のビン集計

### 格子と位置

`BinPlan` は、各座標軸の境界の列から直交格子を作る。
`BinPlan::new(edges)` は軸ごとに 2 個以上の有限で狭義に増加する境界を受け取り、`BinPlan::uniform(axes)` は軸ごとの $(\mathrm{low},\mathrm{high},m)$ から等間隔の $m$ 個のビンを作る（端の境界は `low` と `high` をそのまま使う）。
各ビンは半開区間 $[e_k,e_{k+1})$ で、各軸の最後のビンだけが上端 $e_m$ を含む。
ビンは行優先（最後の軸が最も速く変わる）に番号を付ける。

`BinPlan::locate(point)` は点の位置を `BinLocation` で返す。
格子の中の点は `BinLocation::Inside(index)`、ある軸の下端より小さい点は `Underflow(axis)`、上端より大きい点は `Overflow(axis)` である。
複数の軸で外れた点は最初に外れた軸で分類するので、各点はちょうど 1 か所に数えられる。

### 度数と密度の正規化

`BinnedStatistic` はビンごとに求める量を選ぶ。
`Count` は観測の数（頻度の重みでは独立反復数を数え、質量の重みでは正の重みの観測を数える）、`Mass` は重みの和である。
観測 $i$ の質量 $m_i$ は、重みなしなら 1、頻度の重みなら独立反復数、質量の重みなら重みである。
`RelativeFrequency` と `Density` は正規化の基準が違う。

$$
\text{相対度数}_k=\frac{M_k}{M_{\mathrm{admitted}}},\qquad \text{密度}_k=\frac{M_k}{M_{\mathrm{retained}}\,V_k}
$$

$M_k$ はビン $k$ に入った観測の質量 $m_i$ の和、$V_k$ はビンの体積（1 次元では幅）、$M_{\mathrm{admitted}}$ は格子の外も含めて受理したすべての観測の質量、$M_{\mathrm{retained}}$ は格子の中の質量である。
相対度数の和は格子の中に入った割合 $M_{\mathrm{retained}}/M_{\mathrm{admitted}}$ になり、範囲外の観測があれば 1 より小さい。
密度は $\sum_k\text{密度}_kV_k=1$ を満たし、格子の上の確率密度になる。
このほか、1 次元の格子だけで使える累積の質量 `CumulativeFrequency` と、観測ごとの別の値を要約する `Sum`、`Mean`、`StandardDeviation`（重み付きの母標準偏差）、`Minimum`、`Maximum`、`Median` がある。

結果の `BinEstimate` は数 `count`、質量 `mass: Option<S>`、求めた量 `value: Option<S>` を持つ。
空のビンで定義されない平均・標準偏差・最小・最大・中央値は `None` で、NaN にはならない。
空のビンの数・質量・和・度数は 0 である。
`BinnedDiagnostics` は一括処理ごとに、受理した質量 `admitted_mass`、格子の中の質量 `retained_mass`、下側と上側に外れた質量 `underflow_mass` と `overflow_mass`、除いた観測の数 `skipped` を返す。

`binned_statistics(plan, view, values, statistic, options)` は出力と作業領域を確保して `BinnedResult`（`bins` と `diagnostics`）を返す。
繰り返し集計するときは、`BinnedWorkspace::workspace_requirements` が返す `BinnedRequirements` で `BinnedWorkspace::workspace` を作り、`binned_statistics_into` に呼び出し側の出力を渡す。
値を必要とする量で値がないとき、形の不一致、容量不足、正規化の質量が 0 のときはエラーを返し、出力を変えない。

1 次元の度数だけが欲しいときは、`histogram(values, bins)` が標本の最小値から最大値までを等間隔の `bins` 個のビンに分けて数え、`Histogram` を返す。
`Histogram::edges()` は $b+1$ 個の境界（最後のビンは右端を含む）、`counts()` は各ビンの整数の度数で、`into_parts()` で両方を取り出せる。
計算量は $O(n\log b+b)$ で、空の標本、非有限値、定数の標本（最小値と最大値が一致する）、ビンの数 0 はエラーになる。
ビンの数を標本から決める規則（Sturges、Scott、Freedman–Diaconis）は提供しないので、ビンの数か `BinPlan` の境界を呼び出し側で決める。

範囲外と境界上の観測を数え上げで確かめる例は[同値と範囲外を含む標本の分布関数とビン集計](../../examples/ecdf-and-bins/)にある。

## ガウス核密度推定

### 推定量と帯域幅

$d$ 次元の観測 $\mathbf x_1,\dots,\mathbf x_n$ と重み $w_i$（和 $W$）に対するガウス核密度推定量は

$$
\hat f(\mathbf x)=\sum_{i=1}^n\frac{w_i}{W}\,\phi_{\mathbf H}(\mathbf x-\mathbf x_i),\qquad
\phi_{\mathbf H}(\mathbf u)=\frac{\exp\!\bigl(-\tfrac12\mathbf u^{\mathsf T}\mathbf H^{-1}\mathbf u\bigr)}{(2\pi)^{d/2}\sqrt{\det\mathbf H}}
$$

である。
核の共分散 $\mathbf H$（帯域幅行列）が推定の滑らかさを決める。
$\mathbf H$ が小さいと各観測の位置に鋭い山ができて分散が大きくなり、大きいと山がならされて偏りが大きくなる。
1 次元で $\mathbf H=h^2$ のとき、平均積分 2 乗誤差 $\mathrm{MISE}=\mathrm E\int(\hat f-f)^2$ の主要項は

$$
\mathrm{AMISE}(h)=\frac{1}{2\sqrt\pi\,nh}+\frac{h^4}{4}\int f''(x)^2\,dx
$$

で、これを最小にする $h$ は $n^{-1/5}$ に比例する（Silverman, 1986, §3.3）。
$\int f''^2$ は未知の $f$ に依存するので、帯域幅の規則は $f$ を正規分布と仮定してこの量を置き換える。

`KdeBandwidth` は帯域幅の決め方を選ぶ。
`Scott`、`Silverman`、`Factor(c)` は、重み付きの不偏な標本共分散 $\hat{\boldsymbol\Sigma}$ を倍率 $c$ で拡大した $\mathbf H=c^2\hat{\boldsymbol\Sigma}$ を使う。
倍率は標準偏差に掛かるので、共分散は $c^2$ 倍になる。
`KdeCovariance::Full` は $\hat{\boldsymbol\Sigma}$ をそのまま使って座標の相関を保ち、`KdeCovariance::Diagonal` は対角成分だけを使って座標ごとに独立な核にする。
倍率は、`Scott` が $c=n_{\mathrm{eff}}^{-1/(d+4)}$、`Silverman` が $c=\{n_{\mathrm{eff}}(d+2)/4\}^{-1/(d+4)}$ である。
1 次元の `Silverman` は $c=(4/(3n))^{1/5}\approx1.06\,n^{-1/5}$ で、$f$ が正規分布のときの AMISE の最適値 $h=1.06\,\sigma n^{-1/5}$ に一致する。
Silverman（1986）のロバストな規則 $0.9\min(\hat\sigma,\mathrm{IQR}/1.34)\,n^{-1/5}$ は提供しない。
その帯域幅を使うときは、呼び出し側で計算して `StandardDeviations` で渡す。
交差検証や plug-in 法（Sheather–Jones）による帯域幅の選択も提供しないので、必要なら呼び出し側で候補の倍率を評価して選ぶ。
$n_{\mathrm{eff}}$ は、重みなしと頻度の重みでは複製を含めた数、質量の重みでは Kish の有効標本数 $(\sum w_i)^2/\sum w_i^2$ である。
`StandardDeviations(s)` は対角の $\mathbf H$ を標準偏差で、`Covariance(H)` は対称正定値の $\mathbf H$ そのものを行優先で与える。
倍率の規則は $\hat{\boldsymbol\Sigma}$ が特異なとき（観測が 1 個、定数の標本など）失敗するが、絶対的な指定ならそのような標本でも推定量を作れる。

倍率の規則は、母集団が単峰で正規分布に近いときに合うように作られている。
2 つの山を持つ分布では、標本の分散が山の間隔を含んで大きくなるので、規則の帯域幅は大きすぎて山がならされる。

### 準備と評価

`GaussianKde::new(values)` は 1 次元の重みなしの標本から `Scott` の帯域幅で推定量を準備する。
`GaussianKde::with_options(view, batch, options)` は `BatchView` の 1 つの一括処理から `KdeOptions` の帯域幅・共分散の構造・支持区間・受理の方針で準備し、`GaussianKde::build(view, batch, options, context)` は実行コンテキストも受け取る。
正の重みを持つ観測を核の中心として写すので、準備のメモリ使用量は $O(nd)$ である。
`bandwidth_factor()` は使った倍率 $c$（絶対的な指定では `None`）、`effective_size()` は $n_{\mathrm{eff}}$ を返す。

1 点の密度は `pdf(point)`、対数密度は `log_pdf(point)` で求め、どちらも $d$ 個の作業用の値を確保する。
`log_pdf` は $\ln\hat f$ を和の対数として直接計算するので、$\hat f$ がアンダーフローする遠い点でも有限の値を返す。
`evaluate(points)` は行優先に並べた複数の点をまとめて評価し、1 点あたり $O(nd^2)$ かかる。
確保を伴わずに大量の点を評価するときは、`KdeWorkspace::workspace_requirements(kde, queries, options, context)` が返す `KdeRequirements` で `KdeWorkspace::workspace` を作り、`kde_into(kde, queries, scale, options, output, workspace, context)` を呼ぶ。
`scale` の `KdeScale::Density` は密度 $\hat f$ を、`KdeScale::LogDensity` は $\ln\hat f$ を出力に書く。

積分は閉形式で求められる。
`integrate_kde(other)` は 2 つの推定量の積の積分 $\int\hat f\hat g$ を中心の組ごとの正規密度の和として $O(nm)$ で、`integrate_gaussian(mean, covariance)` は正規密度との積の積分 $\int\hat f\phi$ を $O(n)$ で求める。
どちらも支持区間を持たない推定量に限る。
真の密度が正規分布の混合なら、積分 2 乗誤差 $\mathrm{ISE}=\int(\hat f-f)^2=\int\hat f^2-2\int\hat ff+\int f^2$ が求積なしで厳密に計算できる。

### 帯域幅と積分 2 乗誤差

次のセルは平均 $\pm\Delta/2$、分散 1 の 2 つの正規分布を等しい割合で混ぜた分布 $f$ から、各成分 $n/2$ 個ずつの標本を引く。
倍率 $c$ を 0.1 から 1 まで 0.05 刻みで動かし、`kde_into` で $[-12,12]$ の刻み $1/20$ の格子に評価した $\hat f$ から、$\mathrm{ISE}(c)$ を複合 Simpson 則で求める。
`Scott` と `Silverman` の倍率と、ISE を最小にする倍率を表と図で比べる。
`Scott` の ISE は、`integrate_kde` と `integrate_gaussian` による閉形式でも求めて、Simpson 則の値と照合する。
$\int f^2$ は正規密度の積の積分 $\int\phi(x-\mu_1)\phi(x-\mu_2)\,dx=\phi_{\sqrt2}(\mu_1-\mu_2)$（$\phi_{\sqrt2}$ は標準偏差 $\sqrt2$ の正規密度）から求める。
密度の図は `kde_into` で評価した `Scott` の推定量と、`histogram` の度数を $n$ とビンの幅で割った密度、真の密度（破線）を重ねる。

## 支持区間で切断した核密度

物理量が有界な区間 $[a,b]$ に限られる場合、通常の核密度推定は区間の外へ質量を漏らし、区間の中の積分が 1 より小さくなる。
`KdeOptions::with_support` で支持区間（各座標の `Interval`）を与えると、各核を区間に切断して区間の中の質量で割り直し、区間の外の密度を 0 にする。

$$
\hat f(\mathbf x)=\sum_i\frac{w_i}{W}\,\frac{\phi_{\mathbf H}(\mathbf x-\mathbf x_i)\,\mathbf 1\{\mathbf x\in B\}}{\int_B\phi_{\mathbf H}(\mathbf u-\mathbf x_i)\,d\mathbf u}
$$

分母は直方体 $B$ の上の正規分布の確率で、座標ごとの正規分布の分布関数の差の積として閉形式で求まる。
そのため切断は対角の $\mathbf H$ に限り、相関を持つ核と支持区間を組み合わせるとエラーになる。
すべての核の中心は支持区間の中になければならない。
`integrate_box(lower, upper)` は対角の核の推定量の直方体の上の確率を、同じく分布関数の差から求める（境界は無限大でもよい）。

切断と正規化によって区間の中の質量は 1 になるが、境界の近くの偏りは消えない。
境界で $f'\ne0$ のとき、この方法の境界での偏りは $O(h)$ で、内部の $O(h^2)$ より大きい（Jones, 1993）。
反射法や境界核のような、境界での偏りを $O(h^2)$ にする補正は提供しない。

次のセルは単位区間 $[0,1]$ の 5 つの中心 $0.1,0.25,0.5,0.75,0.9$ に、標準偏差 $h$ を指定した切断核を置く。
`integrate_box` による $[0,1]$ の質量を、1024 分割の複合 Simpson 則で `pdf` を積分した値と比べ、区間の外 $x=-0.1$ の密度が 0 になることを確かめる。

```rust
//| id: stats-truncated-kde-normalization
//| ref: stats-truncated-kde-normalization
//| title: 切断した核密度を独立な格子求積で積分する
//| run: reactive
//| crates: [scioxide-core, scioxide-stats]
//| inputs:
//|   bandwidth: {"type":"range","label":"核の標準偏差 h [-]","description":"大きいほど切断で割り直す質量が増える。","min":0.05,"max":0.4,"step":0.05,"value":0.15}
//| cases:
//|   - {"id":"narrow","label":"h = 0.05","description":"中心ごとの山が分かれ、Simpson 則の誤差が増える。","inputs":{"bandwidth":0.05}}
//|   - {"id":"wide","label":"h = 0.4","description":"どの核も区間の外へ大きくはみ出すが、質量は 1 に保たれる。","inputs":{"bandwidth":0.4}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"mass","path":"/rows/0/1","approx":{"value":1,"atol":1e-14}}
//|       - {"artifact":"mass","path":"/rows/2/1","range":{"min":0,"max":1e-9}}
//|       - {"artifact":"mass","path":"/rows/3/1","equals":0}
//|   - case: wide
//|     expect:
//|       - {"artifact":"mass","path":"/rows/0/1","approx":{"value":1,"atol":1e-14}}

use scioxide_stats::{Axis, BatchView, GaussianKde, KdeBandwidth, KdeCovariance, KdeOptions};

let (shape, strides) = ([5_usize], [1_usize]);

let view = BatchView::new(&centers, layout, Axis::Index(0)).map_err(|e| e.to_string())?;

let support = [Interval::new(0.0, 1.0).map_err(|e| e.to_string())?];

    .with_bandwidth(KdeBandwidth::StandardDeviations(&widths))
    .with_covariance(KdeCovariance::Diagonal)
    .with_support(Some(&support));

let n = 1024_usize;

    let x = i as f64 / n as f64;
    let value = kde.pdf(&[x]).map_err(|e| e.to_string())?;
    let weight = if i == 0 || i == n {
        1.0
    } else if i % 2 == 0 {
        2.0
    } else {
        4.0
    };
    sum += weight * value;
    if i % 8 == 0 {
        curve.push([x, value]);
    }
}
let simpson = sum / (3 * n) as f64;
let analytic = kde
    .integrate_box(&[0.0], &[1.0])
    .map_err(|e| e.to_string())?;
let outside = kde.pdf(&[-0.1]).map_err(|e| e.to_string())?;
let (lowest, highest) = curve.iter().fold((f64::INFINITY, 0.0_f64), |(lo, hi), p| {
    (lo.min(p[1]), hi.max(p[1]))
});
emit_line_chart!(
    &vec![serde_json::json!({ "name": "切断した核密度", "points": curve })],
    options = &serde_json::json!({
        "xLabel": "座標 x [-]",
        "yLabel": "確率密度 [1/単位]",
        "xMin": 0.0,
        "xMax": 1.0,
        "yMin": 0.0,
        "yMax": 3.0,
        "annotations": [{ "kind": "line", "axis": "y", "value": 1.0, "label": "一様分布の密度" }]
    })
);
let fixed15 = serde_json::json!({ "fractionDigits": 15 });
let columns = serde_json::json!([
    { "key": "0", "label": "量" },
    { "key": "1", "label": "値 [-]", "type": "number", "format": fixed15 }
]);
let rows = vec![
    ("integrate_box による [0, 1] の質量", analytic),
    ("Simpson 則による [0, 1] の質量", simpson),
    ("2 つの質量の差の絶対値", (simpson - analytic).abs()),
    ("区間の外 x = −0.1 の密度", outside),
    ("格子の上の密度の最小値", lowest),
    ("格子の上の密度の最大値", highest),
];
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "mass" })
);
```

既定の $h=0.15$ では、`integrate_box` の質量は 1、Simpson 則の質量との差は $2.9\times10^{-12}$ で、区間の外 $x=-0.1$ の密度は 0 である。
密度は 0.711 から 1.174 の範囲にある。
$h=0.05$ では中心ごとの山が分かれて密度の範囲が 0.140 から 1.652 に広がり、Simpson 則との差は $3.6\times10^{-11}$ に増える。
$h=0.4$ ではどの核も区間から大きくはみ出すが、割り直しによって質量は 1 のままである。

## まとめ

単調回帰は PAVA によって $O(n)$ の有限の手順で厳密解に達し、各ブロックの値は重み付き平均として閉形式で確かめられる。
重み 0 の観測は値を読まずに除かれ、除いた数は `IsotonicDiagnostics::excluded` に残る。
ビン集計の相対度数は範囲外を含む受理した質量で、密度は格子の中の質量とビンの体積で割るので、範囲外の観測がある標本では 2 つの和が異なる。
核密度推定の `Scott` と `Silverman` の倍率は単峰の正規分布に合わせた規則で、2 峰の分布では大きすぎるので、多峰が疑われるときは帯域幅を `Factor` や `StandardDeviations` で指定し直す。
有界な区間の量には支持区間で切断した核を使うと質量が 1 になるが、境界の近くの $O(h)$ の偏りは残る。
