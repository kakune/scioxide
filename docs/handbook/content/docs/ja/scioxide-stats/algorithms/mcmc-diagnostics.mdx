事後分布が共役な組で閉じた形にならないモデルでは、マルコフ連鎖モンテカルロ法（MCMC）で事後分布から標本を引き、その標本で期待値や分位点を推定する。
MCMC の標本は、定常分布が事後分布になるように作ったマルコフ連鎖の状態の列で、互いに独立ではない。
連鎖が初期値の影響を抜けて定常分布に達したか、隣り合う標本の相関のために独立な標本何個分の情報しかないかを、標本だけから確かめる必要がある。
このページは、`scioxide-stats` の `posterior_summary` が計算する事後要約と収束診断（R̂、有効標本数、モンテカルロ標準誤差）を導出し、その入力と出力を説明する。
共役な組で事後分布を閉じた形で求める方法は[共役事前分布とベイズ更新](../bayesian-conjugate-updates/)で扱う。

## MCMC 事後連鎖の診断と要約

### 提供するものと提供しないもの

`scioxide-stats` は MCMC の標本器（Metropolis–Hastings 法、Gibbs サンプリング、Hamiltonian Monte Carlo、NUTS）を提供しない。
連鎖は `scioxide-random` の乱数生成器と分布から標本を引いて自分で作るか、外部の確率的プログラミングの道具で作り、`scioxide-linalg` の行列ビューとして渡す。
`scioxide-stats` が受け持つのは、ウォームアップ（バーンイン）を除いた後の連鎖の要約と診断である。
ウォームアップの自動の判定と除去、間引き、最高事後密度（HPD）区間、分位点のモンテカルロ標準誤差、多変量の R̂ と有効標本数は提供しない。
連鎖の自己相関関数そのものを見たいときは、[時系列解析](../time-series/)の自己相関の推定を各連鎖に使う。

### モンテカルロ標準誤差と有効標本数

定常な連鎖 $x_1, \dots, x_N$ の平均 $\bar x$ で事後平均 $E[\theta]$ を推定するとき、標本が独立なら $\mathrm{Var}(\bar x) = \sigma^2/N$ だが、相関があると

$$
\mathrm{Var}(\bar x) \approx \frac{\sigma^2}{N}\,\tau, \qquad
\tau = 1 + 2\sum_{t=1}^{\infty} \rho_t
$$

になる。
$\sigma^2$ は事後分散、$\rho_t$ はラグ $t$ の自己相関、$\tau$ を積分自己相関時間と呼ぶ。
有効標本数 $\mathrm{ESS} = N/\tau$ は、同じ精度を与える独立な標本の数で、モンテカルロ標準誤差（MCSE）は $\sqrt{\sigma^2/\mathrm{ESS}}$ である。
例えば自己回帰係数 $\phi$ の AR(1) 過程では $\rho_t = \phi^t$ なので $\tau = (1+\phi)/(1-\phi)$ で、$\phi = 0.81$ なら $\tau \approx 9.5$、10 個の標本が独立な標本 1 個分に近い。

### 分割した連鎖と R̂

$M$ 本の連鎖を異なる初期値から走らせ、それぞれの $D$ 個の標本を前半と後半の $\lfloor D/2 \rfloor$ 個ずつに分ける（$D$ が奇数なら中央の 1 個を除く）。
分割した $2M$ 本の連鎖をそれぞれ長さ $n = \lfloor D/2 \rfloor$ の連鎖とみなし、連鎖内の分散の平均 $W$ と、連鎖の平均の分散 $B/n$ から

$$
\hat V = \frac{n-1}{n} W + \frac{B}{n}, \qquad \hat R = \sqrt{\hat V / W}
$$

を作る。
連鎖がどれも同じ定常分布から引かれていれば $\hat V$ と $W$ はどちらも $\sigma^2$ に近づき、$\hat R \to 1$ になる。
初期値の影響が残っているか、連鎖が分布の別の部分にとどまっていると、連鎖の平均がばらついて $\hat R > 1$ になる。
連鎖を前後に分けるのは、1 本の連鎖の中で分布がずれていく（定常でない）場合も連鎖間の違いとして検出するためである。

Vehtari ら（2021）はこの $\hat R$ を二つの変換の後の標本に適用する。
順位正規化は分割したすべての標本 $S = 2Mn$ 個の中での平均順位 $r$ を $z = \Phi^{-1}\!\left((r - 3/8)/(S + 1/4)\right)$ に置き換える（$\Phi^{-1}$ は標準正規分布の分位点関数）。
これにより、裾の重い分布や分散が存在しない分布でも $\hat R$ が定義され、位置のずれを検出できる。
折り返しは標本 $x$ を中央値からの距離 $|x - \mathrm{median}|$ に置き換えてから順位正規化し、尺度（広がり）の違いを検出する。
返す $\hat R$ は二つの値の大きいほうで、1 未満の値を 1 に丸めない。
同じ論文は $\hat R < 1.01$ と、4 本以上の連鎖で中央部と裾の有効標本数がそれぞれ 400 以上を、事後要約を使う目安として推奨している。
これは診断であり、$\hat R$ が 1 に近く有効標本数が大きくても、連鎖が収束したことの証明にはならない。
どの連鎖も分布の同じ一部しか訪れていなければ、どの診断も問題を検出できない。

### 自己相関と Geyer の初期単調列

自己相関は、分割した連鎖ごとのラグ $t$ の自己共分散の平均 $\bar c_t$ から

$$
\hat\rho_t = 1 - \frac{W - \bar c_t}{\hat V}
$$

で推定する（Stan と ArviZ と同じ推定量）。
ラグが大きいと $\hat\rho_t$ はノイズに支配されるので、和を途中で打ち切る。
Geyer（1992）の初期正値列は、隣り合う二つの和 $P_k = \hat\rho_{2k} + \hat\rho_{2k+1}$ が負になる手前までを使い、初期単調列はさらに $P_k$ が増えないように均す。
こうして作った $\hat\tau$ には下限 $1/\log_{10} S$ を設けるので、負の相関を持つ連鎖（反対称な連鎖）では有効標本数が $S$ を超えうる。
計算量は最大のラグを $L$ として $O(SL)$、メモリ使用量は $O(MD)$ である。

### 事後要約の出力

`PosteriorSummary` は、1 個の実数の母数について次の公開フィールドを持つ。

| フィールド | 内容 |
|---|---|
| `mean` | 全標本 $N = MD$ 個の平均 |
| `variance` | 全標本の標本分散（除数 $N-1$） |
| `quantiles` | 全標本の 5%、50%、95% 分位点（Hyndman–Fan の型 7） |
| `rhat` | 順位正規化と折り返しの分割 $\hat R$ の大きいほう |
| `bulk_ess` | 中央部の有効標本数：順位正規化した分割連鎖の有効標本数 |
| `tail_ess` | 裾の有効標本数：指示関数 $\mathbf 1\{x \le q_{0.05}\}$ と $\mathbf 1\{x \le q_{0.95}\}$ の有効標本数の小さいほう |
| `mean_mcse` | 平均のモンテカルロ標準誤差 $\sqrt{\mathrm{variance}/\mathrm{ESS}}$。ESS は変換しない分割連鎖のもの |
| `chains`、`draws_per_chain` | 連鎖の本数 $M$ と 1 本あたりの標本数 $D$ |

`rhat`、`bulk_ess`、`tail_ess`、`mean_mcse` は `Option<f64>` で、依存する標本が変化しない（連鎖内の分散が 0 など）ために定義されない場合は `None` になる。
平均と分散と分位点は全標本から、診断は分割した連鎖から求めるので、$D$ が奇数なら診断は中央の標本を使わない。
出力は入力の型によらず `f64` である。

### 入力と呼び出しの形

連鎖は行列ビュー `MatrixView` で渡し、行 $i$ が連鎖 $i$ のウォームアップ後の $D$ 個の標本である。
連鎖が 2 本未満か 1 本あたり 4 個未満なら `InvalidInput`、標本に NaN か無限大があれば `NonFinite` を返す。

`PosteriorOptions` は三つの上限を持ち、既定ではどれも制限しない。
`with_max_workspace_bytes` は入力と結果を除く作業領域のメモリ使用量の上限で、超えると `ResourceLimit` を返す。
`with_max_lag` は有効標本数に使う最大のラグで、0 ならすべてのラグを使う。
上限を設けると Geyer の列をそのラグで打ち切るが、有効標本数の正規化には分割した標本の総数を使う。
`with_max_lag_work` は自己相関の積の評価回数の上限で、計算には $5 \cdot 2M\lfloor D/2\rfloor\,(L+1)$ 回が必要である。
これを超える場合は、計算を始める前に `ConvergenceFailure`（`EvaluationLimit`）を返す。

ワンショット関数 `posterior_summary(chains)` は既定の `PosteriorOptions` を使い、オプション付き形式 `posterior_summary_with_options(chains, options)` は上限を受け取る。
出力先を指定する API `posterior_summaries_into(parameters, options, output, context)` は、母数ごとの行列ビューのスライスを受け取り、`output[i]` に各母数の要約を書く。
母数ごとの計算は実行コンテキストが許せば並列に行い、結果はワーカーの数によらない。
メモリ使用量の上限は同時に動くワーカーの作業領域の合計に適用する。
`output` の長さが母数の数と違えば `InvalidInput`、取り消されると `ExecutionStopped` を返す。

## 二変量正規分布の Gibbs サンプリング

相関 $\rho$ の二変量標準正規分布 $(x, y)$ を、条件付き分布

$$
x \mid y \sim N(\rho y,\; 1 - \rho^2), \qquad y \mid x \sim N(\rho x,\; 1 - \rho^2)
$$

から交互に引く Gibbs サンプリングで標本化する（Gelman ら BDA 3 版 §11.1）。
$x$ の列は $x_{t+1} = \rho^2 x_t + (\text{独立なノイズ})$ という係数 $\phi = \rho^2$ の AR(1) 過程になるので、

$$
\mathrm{ESS}_{\text{理論}} = N \frac{1 - \rho^2}{1 + \rho^2}, \qquad
\mathrm{MCSE}_{\text{理論}} = \sqrt{\frac{1}{N} \cdot \frac{1 + \rho^2}{1 - \rho^2}}
$$

と理論値が分かり、推定した有効標本数と MCSE を確かめられる（周辺分布の分散は 1）。
$y$ の列も同じ AR(1) 過程である。
相関 $\rho$ が 1 に近いほど、条件付き分布の幅 $\sqrt{1-\rho^2}$ が狭くなり、連鎖は分布の中をゆっくりしか動けない。

次のセルは 4 本の連鎖を、$y$ の初期値を $+s$、$-s$、$+s$、$-s$ にして走らせ、ウォームアップを捨てずに `posterior_summaries_into` で $x$ と $y$ の要約を一度に求める。
入力は相関 $\rho$、1 本あたりの標本数 $D$、初期値のずれ $s$、乱数のシードである。
表の $z$ は $\bar x / \mathrm{MCSE}$ で、真の平均 0 からのずれを推定した MCSE で測る。
図は $x$ の 4 本の連鎖の軌跡（トレースプロット）で、初期値の影響が残っていれば連鎖が分かれて見える。
重い計算なので、ボタンで実行する。

```rust
//| id: stats-bayesian-conjugate-updates-api-6
//| ref: stats-bayesian-conjugate-updates-api-6
//| title: 二変量正規分布の Gibbs サンプリングで R̂ と有効標本数を理論値と比べる
//| run: button
//| crates: [scioxide-core, scioxide-linalg, scioxide-random, scioxide-stats]
//| inputs:
//|   rho: {"type":"range","label":"相関 ρ [-]","min":0,"max":0.95,"step":0.01,"value":0.9}
//|   draws: {"type":"range","label":"1 本あたりの標本数 D","min":100,"max":500,"step":50,"value":500}
//|   start: {"type":"range","label":"初期値のずれ s [-]","min":0,"max":10,"step":0.5,"value":0}
//|   seed: {"type":"range","label":"乱数のシード","min":1,"max":100,"step":1,"value":1}
//| cases:
//|   - {"id":"independent","label":"ρ = 0","description":"標本が独立で、有効標本数は標本の総数に近い。","inputs":{"rho":0}}
//|   - {"id":"stuck","label":"ρ = 0.95、s = 10、D = 100","description":"初期値の影響が抜けず、R̂ が 1 を大きく超える。","inputs":{"rho":0.95,"start":10,"draws":100}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"summary","path":"/rows/0/5","approx":{"value":1.02196207,"rtol":1e-6}}
//|       - {"artifact":"summary","path":"/rows/0/6","approx":{"value":220.151447,"rtol":1e-6}}
//|       - {"artifact":"summary","path":"/rows/0/6","range":{"min":150,"max":300}}
//|       - {"artifact":"summary","path":"/rows/0/8","approx":{"value":0.0675258953,"rtol":1e-6}}
//|       - {"artifact":"summary","path":"/rows/2/6","approx":{"value":209.944751381215,"rtol":1e-12}}
//|       - {"artifact":"summary","path":"/rows/2/8","approx":{"value":0.0690156351469494,"rtol":1e-12}}
//|   - case: independent
//|     expect:
//|       - {"artifact":"summary","path":"/rows/0/6","range":{"min":1800,"max":2200}}
//|       - {"artifact":"summary","path":"/rows/2/6","equals":2000}
//|       - {"artifact":"summary","path":"/rows/0/5","range":{"max":1.01}}
//|   - case: stuck
//|     expect:
//|       - {"artifact":"summary","path":"/rows/0/5","range":{"min":1.1}}
//|       - {"artifact":"summary","path":"/rows/0/2","range":{"min":2}}
use scioxide_core::{ExecutionContext, RealScalar};
use scioxide_linalg::MatrixView;
use scioxide_random::{Distribution, Normal, Quantile, SeedableRng, SplitMix64};
use scioxide_stats::{PosteriorOptions, posterior_summaries_into};

let (chains, length) = (4, draws as usize);
let mut rng = SplitMix64::from_seed(seed as u64);
let noise = Normal::new(0.0, RealScalar::sqrt(1.0 - rho * rho)).map_err(|e| e.to_string())?;
let mut xs = vec![0.0; chains * length];
let mut ys = vec![0.0; chains * length];
for chain in 0..chains {
    // 連鎖ごとに y の初期値を ±s に置き、x と y を条件付き分布から交互に引く
    let mut y = if chain % 2 == 0 { start } else { -start };
    for step in 0..length {
        let x = rho * y + noise.sample(&mut rng).map_err(|e| e.to_string())?;
        y = rho * x + noise.sample(&mut rng).map_err(|e| e.to_string())?;
        xs[chain * length + step] = x;
        ys[chain * length + step] = y;
    }
}
let views = [
    MatrixView::from_slice(chains, length, &xs).map_err(|e| e.to_string())?,
    MatrixView::from_slice(chains, length, &ys).map_err(|e| e.to_string())?,
];
let mut output = [None, None];
let context = ExecutionContext::sequential();
posterior_summaries_into(&views, PosteriorOptions::default(), &mut output, context)
    .map_err(|e| e.to_string())?;
// AR(1)（係数 ρ²）の理論値
let total = (chains * length) as f64;
let phi = rho * rho;
let ess_theory = total * (1.0 - phi) / (1.0 + phi);
let mcse_theory = RealScalar::sqrt(1.0 / ess_theory);
let mut rows = Vec::new();
for (name, summary) in ["x", "y"].iter().zip(output) {
    let s = summary.ok_or("要約がない")?;
    let z = s.mean_mcse.map(|mcse| s.mean / mcse);
    rows.push((
        *name,
        s.mean,
        s.variance,
        s.quantiles[0],
        s.quantiles[2],
        s.rhat,
        s.bulk_ess,
        s.tail_ess,
        s.mean_mcse,
        z,
    ));
}
let z95 = Normal::new(0.0, 1.0)
    .and_then(|law| law.quantile(0.95))
    .map_err(|e| e.to_string())?;
rows.push((
    "理論値",
    0.0,
    1.0,
    -z95,
    z95,
    Some(1.0),
    Some(ess_theory),
    None,
    Some(mcse_theory),
    None,
));
let fixed3 = serde_json::json!({ "fractionDigits": 3 });
let fixed4 = serde_json::json!({ "fractionDigits": 4 });
let fixed0 = serde_json::json!({ "fractionDigits": 0 });
let columns = serde_json::json!([
    { "key": "0", "label": "母数" },
    { "key": "1", "label": "平均 [-]", "type": "number", "format": fixed4 },
    { "key": "2", "label": "分散 [-]", "type": "number", "format": fixed4 },
    { "key": "3", "label": "5% 分位点 [-]", "type": "number", "format": fixed3 },
    { "key": "4", "label": "95% 分位点 [-]", "type": "number", "format": fixed3 },
    { "key": "5", "label": "R̂ [-]", "type": "number", "format": fixed4, "nullText": "－" },
    { "key": "6", "label": "中央部の ESS", "type": "number", "format": fixed0, "nullText": "－" },
    { "key": "7", "label": "裾の ESS", "type": "number", "format": fixed0, "nullText": "－" },
    { "key": "8", "label": "MCSE [-]", "type": "number", "format": fixed4, "nullText": "－" },
    { "key": "9", "label": "z = 平均/MCSE [-]", "type": "number", "format": fixed3, "nullText": "－" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "summary" })
);
let series: Vec<_> = (0..chains)
    .map(|chain| {
        let points: Vec<[f64; 2]> = (0..length)
            .map(|step| [step as f64, xs[chain * length + step]])
            .collect();
        serde_json::json!({ "name": format!("連鎖 {}", chain + 1), "points": points })
    })
    .collect();
emit_line_chart!(
    &series,
    options = &serde_json::json!({ "xLabel": "反復 t [-]", "yLabel": "x の標本 [-]" })
);
```

既定（$\rho = 0.9$、$D = 500$、$s = 0$）では、$x$ の中央部の有効標本数は 220 で、理論値 210 と 5% の差で合い、MCSE 0.0675 も理論値 0.0690 に近い。
標本の総数 2000 のうち、独立な標本 200 個分ほどの情報しかない。
平均 $-0.067$ は MCSE で測って $z = -1.0$ で、真の値 0 と矛盾しない。
一方、$\hat R = 1.022$ は Vehtari らの目安 1.01 を超え、有効標本数も 400 に届かないので、この長さでは要約を使う前に連鎖を延ばすべきだと判断する。
裾の有効標本数 450 が中央部より大きいのは、5% と 95% の分位点の指示関数のほうが自己相関が速く減るためである。
「ρ = 0」では標本が独立になり、有効標本数は 2025（理論値 2000）、$\hat R = 0.9998$ である。
$\hat R$ は 1 を下回ることがあり、1 に丸めない。
「ρ = 0.95、s = 10、D = 100」では、初期値 $\pm 10$ の影響が 100 反復では抜けず、トレースプロットで連鎖が上下に分かれ、$\hat R = 1.29$ になる。
分散は 5.18 と真の値 1 の 5 倍に膨らみ、推定した MCSE 0.63 も理論値 0.22 の 3 倍になるので、この連鎖の要約は使えない。
ウォームアップを除いて連鎖を延ばせば、$\hat R$ は 1 に近づく。

## まとめ

`scioxide-stats` は MCMC の標本器を提供しないので、連鎖は `scioxide-random` などで自分で作り、ウォームアップを除いてから行を連鎖、列を標本とする行列ビューで `posterior_summary` に渡す。
要約を使う前に、`rhat` が 1.01 未満で、`bulk_ess` と `tail_ess` が十分に大きい（4 本の連鎖でそれぞれ 400 以上）ことを確かめ、満たさなければ連鎖を延ばす。
事後平均の不確かさは `mean_mcse` で測り、分位点は 5%、50%、95% だけが返るので、ほかの分位点や HPD 区間は標本から自分で求める。
複数の母数は `posterior_summaries_into` で一度に要約でき、長い連鎖では `PosteriorOptions` でメモリ使用量と自己相関の計算量に上限を設ける。
これらは診断であり、どの連鎖も分布の同じ一部しか訪れていない場合は検出できないので、初期値を散らした複数の連鎖で確かめる。
