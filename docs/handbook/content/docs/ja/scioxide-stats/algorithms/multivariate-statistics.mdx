同じ個体について複数の量を測ったデータ（多変量データ）では、各変数の平均と分散に加えて、変数どうしがどう一緒に動くかが分析の対象になる。
その基本の量は共分散行列で、主成分分析、正準相関分析、多変量の回帰や判別は、どれも共分散行列の推定から始まる。
変数の数 $p$ が標本の大きさ $n$ に比べて小さくないと、標本共分散行列は固有値が広がり、逆行列が不安定になる。

このページは、`scioxide-stats` が提供する次の 4 つを、定義、推定法、誤差と計算量、API、実験の順に説明する。

- 標本共分散行列と、度数の重みを付けた共分散行列
- Ledoit–Wolf の縮小推定（shrinkage）
- 主成分分析（PCA）と白色化
- 正準相関分析（CCA）

行列の行が観測（個体）、列が変数である。
$n \times p$ のデータ行列を $X$、その第 $i$ 行を $x_i^{\mathsf T}$ と書く。
行は互いに独立で、同じ分布に従うと仮定する。
時系列のように行が依存するデータでは、このページの推定量の分散の式は成り立たない。

## 標本共分散行列

### 定義と中心化

列 $j$ の平均を $\bar x_j = \frac1n \sum_i x_{ij}$ とすると、標本共分散行列 $S$ の成分は

$$
S_{jk} = \frac{1}{n - 1} \sum_{i=1}^{n} (x_{ij} - \bar x_j)(x_{ik} - \bar x_k)
$$

である。
除数 $n - 1$ は平均を推定したことによる自由度の減少を補い、$E[S] = \Sigma$ にする。
複素数のデータでは、最初の因子を共役にして $S$ をエルミート行列にする。
$S$ は半正定値で、そのランクは $\min(n - 1, p)$ 以下である。
したがって $p \ge n$ なら $S$ は必ず特異になり、逆行列を持たない。

平均を先に求めて引く 2 パスの計算は、和を 1 回で求める $\sum x^2 - n\bar x^2$ の形より安定だが、丸めた平均 $\mathrm{fl}(\bar x_j)$ を引くと、大きな共通のずれ（たとえば $10^{8}$ の周りの小さな変動）を持つ列では偏差の下位の桁が失われる。
`scioxide-stats` は列の平均を補償付きの和で求め、丸めた平均ではなく補償付きの平均（2 つの `f64` の和）を各値から引いて中心化する。
実数の積は補償付きで足し、打ち消しが大きい成分や `f64` の指数の範囲を外れる成分は指数部の範囲を広げた表現で計算し直す。
返す平均ベクトルはスカラー型に丸めた値だが、共分散はその丸めの影響を受けない。

計算量は $O(np^2)$ の時間と $O(np + p^2)$ のメモリ使用量である。

### 度数の重み

同じ値の行が繰り返し現れるデータは、異なる行と、その出現回数 $c_i$（度数の重み）で表せる。
$N = \sum_i c_i \ge 2$ として

$$
\bar x_j = \frac{1}{N} \sum_i c_i\, x_{ij},
\qquad
C_{jk} = \frac{1}{N - 1} \sum_i c_i\, (x_{ij} - \bar x_j)(x_{ik} - \bar x_k)
$$

は、行を $c_i$ 回ずつ並べたデータの標本共分散行列と一致する。
除数 $N - 1$ は度数の重みでだけ正しい。
信頼度や精度を表す重み（解析的な重み）では有効な標本の大きさが $\sum c_i$ と違うので、この式を使わない。
`frequency_covariance(data, weights)` と、メモリ使用量の上限を渡す `frequency_covariance_with_options(data, weights, options)` は `Weights<_, Frequency>` だけを受け付け、他の重みのモデルはコンパイル時に拒む。
重みの数が行数と違うとき、重みが整数として表せないとき、$N < 2$ のときは `InvalidInput` を返す。
重み 0 の行は寄与しないが、値は有限でなければならない。

## Ledoit–Wolf の縮小推定

### 高次元での標本共分散の問題

$p/n$ が 0 に近くないとき、$S$ の固有値は真の共分散 $\Sigma$ の固有値より大きく広がる。
たとえば $\Sigma = I$、$p/n \to c \in (0, 1)$ では、$S$ の固有値の分布は Marchenko–Pastur 分布に近づき、その台は $[(1 - \sqrt c)^2, (1 + \sqrt c)^2]$ である。
$c = 1/2$ でも固有値は 0.09 から 2.9 までに散らばり、真の値 1 のまわりに集まらない。
最大の固有値は大きすぎ、最小の固有値は小さすぎるので、$S$ の条件数は真の値より大きく、$S^{-1}$ を使う推定（Mahalanobis 距離、判別分析、ポートフォリオの重み）の誤差が大きくなる。

### 縮小推定量と最適な強度

縮小推定は $S$ を構造の簡単な目標の行列に向かって引き寄せる。
Ledoit–Wolf の推定量は目標を単位行列の定数倍 $\mu I$（$\mu = \mathrm{tr}\,S/p$）にとり、

$$
\hat\Sigma = (1 - \alpha)\, S + \alpha\, \mu I,
\qquad 0 \le \alpha \le 1
$$

とする。
固有ベクトルは $S$ と同じで、各固有値 $\lambda$ を $(1 - \alpha)\lambda + \alpha\mu$ に置き換える。
固有値は平均 $\mu$ に向かって縮み、$\alpha > 0$ かつ $\mu > 0$ なら $\hat\Sigma$ は正定値になる。

強度 $\alpha$ は Frobenius ノルムの二乗誤差の期待値 $E\|\hat\Sigma - \Sigma\|_F^2$ を最小にするように選ぶ。
その最適値は $\Sigma$ に依存するので、Ledoit と Wolf (2004) はデータから一致的に推定できる量に置き換えた。
`scioxide-stats` は、中心化した行 $x_i$ から

$$
S_n = \frac{1}{n} \sum_i x_i x_i^{\mathsf T},
\quad
\mu = \frac{\mathrm{tr}\,S_n}{p},
\quad
\delta = \|S_n - \mu I\|_F^2,
\quad
\bar\beta = \frac{1}{n^2} \sum_i \|x_i x_i^{\mathsf T} - S_n\|_F^2,
\quad
\alpha = \min\!\left(\frac{\bar\beta}{\delta},\, 1\right)
$$

を計算する（$\delta = 0$ なら $\alpha = 1$）。
$\delta$ は $S$ が目標からどれだけ離れているか、$\bar\beta$ は $S$ 自身の推定誤差の大きさで、推定誤差が大きいほど強く縮める。
$\bar\beta \ge 0$ なので $\alpha$ は負にならず、上側だけを 1 で切る。
返す行列は除数を $n - 1$ に戻した $\frac{n}{n-1}\bigl[(1 - \alpha) S_n + \alpha\mu I\bigr]$ で、これは $S$ を同じ $\alpha$ で縮めた行列に等しい。
この推定は正規分布を仮定せず、4 次のモーメントが有限であることだけを使う。
定数のデータや、すべての方向に同じ分散を持つデータでは $\alpha = 1$ になる。
4 次の和と比は指数部の範囲を広げて計算するので、データ全体を定数倍しても $\alpha$ は変わらない。

目標は $\mu I$ だけで、対角行列や一定の相関を目標にする縮小、非線形の縮小、Oracle Approximating Shrinkage（OAS）、疎な精度行列を推定する graphical lasso は提供しない。
強度を交差検証などで別に決めたときは、`shrink_covariance(covariance, intensity)` で既知の共分散行列を $\mu I$ に向かって縮める。
外れ値にロバストな共分散には `PreparedHuberScatter`（Huber の M 推定）を使う。

## 共分散の推定と縮小の API

| 関数 | 返す値 | 計算量 |
|---|---|---|
| `sample_covariance(data)` | （列の平均、$S$） | $O(np^2)$ |
| `ledoit_wolf_covariance(data)` | （$\alpha$、$\hat\Sigma$） | $O(np^2)$ |
| `shrink_covariance(covariance, intensity)` | $(1 - \alpha) S + \alpha\mu I$ | $O(p^2)$ |
| `frequency_covariance(data, weights)` | （重み付きの平均、$C$） | $O(np^2)$ |

`sample_covariance` と `ledoit_wolf_covariance` は `MatrixView` を受け取るワンショット呼び出しの形で、メモリ使用量の上限と数値ランクの方針を [`MultivariateOptions`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/struct.MultivariateOptions.html) で渡すには `sample_covariance_with_options` と `ledoit_wolf_covariance_with_options` を使う。
共分散の推定はランクの方針を使わず、メモリ使用量の上限だけを使う。
行が 2 未満、列がない、行数がスカラー型で正確に数えられない（`f64` で $2^{53}$ を超える）ときは `InvalidInput`、NaN や無限大があれば `NonFinite`、成分がスカラー型であふれれば `NumericalInstability`、メモリ使用量が上限を超えれば `ResourceLimit` を返す。
`shrink_covariance` は、行列が正方でないか、正確にエルミートでないか、対角成分が負か、強度が $[0, 1]$ の外にあるときに `InvalidInput` を返す。
$\alpha = 0$ では元の行列をそのまま返し、$\alpha = 1$ では $\mu I$ を返す。

### 縮小推定の実験

次のブロックは、このページの最初の 2 つのセルが共有するモデルである。
$p$ 個のセンサーを一列に並べ、隣り合うセンサーの値ほど強く相関する状況を、相関行列 $\Sigma_{jk} = \rho^{|j-k|}$ の多変量正規分布で表す。
`correlated_rows` は、各行を変数方向の AR(1) 再帰 $z_1 = e_1$、$z_j = \rho z_{j-1} + \sqrt{1 - \rho^2}\, e_j$（$e_j$ は独立な標準正規）で作り、この再帰の共分散がちょうど $\rho^{|j-k|}$ になる。
値は標準化した単位で、分散は 1 である。
`toeplitz` は真の $\Sigma$ を返す。

```rust
//| id: stats-multivariate-model
//| kind: definitions
//| title: 隣り合う変数ほど相関するデータのモデル
//| crates: [scioxide-core, scioxide-linalg, scioxide-random]
use scioxide_core::{SciOxideError, RealScalar};
use scioxide_linalg::Matrix;
use scioxide_random::{Distribution, Normal, SeedableRng, Xoshiro256StarStar};

/// Σ_jk = ρ^|j−k| の正規分布から n 行 p 列を引く（行が観測）。
pub(crate) fn correlated_rows(
    seed: u64,
    n: usize,
    p: usize,
    rho: f64,
) -> Result<Matrix<f64>, SciOxideError> {
    let mut rng = Xoshiro256StarStar::from_seed(seed);
    let normal = Normal::new(0.0, 1.0)?;
    let innovation = RealScalar::sqrt(1.0 - rho * rho);
    let mut data = Vec::with_capacity(n * p);
    for _ in 0..n {
        let mut z = normal.sample(&mut rng)?;
        data.push(z);
        for _ in 1..p {
            z = rho * z + innovation * normal.sample(&mut rng)?;
            data.push(z);
        }
    }
    Matrix::from_vec(n, p, data)
}

/// 真の共分散 Σ_jk = ρ^|j−k|。
pub(crate) fn toeplitz(p: usize, rho: f64) -> Result<Matrix<f64>, SciOxideError> {
    let entries = (0..p * p).map(|i| RealScalar::powi(rho, (i / p).abs_diff(i % p) as i32));
    Matrix::from_vec(p, p, entries.collect())
}
```

次のセルは標本の大きさ $n$、変数の数 $p$、相関 $\rho$、乱数のシードを入力として、`sample_covariance` と `ledoit_wolf_covariance` で $S$ と $\hat\Sigma$ を求め、真の $\Sigma$ と比べる。
固有値は `scioxide-linalg` の `HermitianEigenDecomposition` で求める。
1 つ目の表は真の $\Sigma$、$S$、$\hat\Sigma$ の最大・最小の固有値、条件数、$\Sigma$ との Frobenius ノルムの差である。
2 つ目の表は 3 つの独立な検算である。
$\alpha$ を上の式どおりに計算した値、`shrink_covariance(S, α)` と $\hat\Sigma$ の差、1 行目を 2 回並べたデータの $S$ と度数の重み $(2, 1, \dots, 1)$ の `frequency_covariance_with_options` の差を示す。
図は 3 つの行列の固有値を大きい順に並べたもので、縦軸は対数である。
$p \ge n$ では $S$ の固有値のうち $p - n + 1$ 個が 0（丸め誤差の範囲）になり、対数軸には描かない。
このセルの入力は次の PCA のセルに渡す。

```rust
//| id: stats-multivariate-shrinkage
//| ref: stats-multivariate-shrinkage
//| title: 標本共分散と Ledoit–Wolf の縮小推定を真の共分散と比べる
//| run: reactive
//| uses: [stats-multivariate-model]
//| crates: [scioxide-core, scioxide-linalg, scioxide-stats]
//| exports: [seed, rows, variables, rho]
//| inputs:
//|   seed: {"type":"integer","label":"乱数のシード","min":0,"max":100000,"value":7}
//|   rows: {"type":"range","label":"標本の大きさ n [行]","min":10,"max":200,"step":5,"value":40}
//|   variables: {"type":"integer","label":"変数の数 p","min":2,"max":40,"value":20}
//|   rho: {"type":"range","label":"隣り合う変数の相関 ρ [-]","min":0,"max":0.9,"step":0.1,"value":0.5}
//| cases:
//|   - {"id":"identity","label":"ρ = 0","description":"Σ = I で、S の固有値が Marchenko–Pastur の範囲に広がり、α が上限の 1 になる。","inputs":{"rho":0}}
//|   - {"id":"large-sample","label":"n = 200","description":"p/n = 0.1 で S の誤差が小さく、α も小さい。","inputs":{"rows":200}}
//|   - {"id":"wide","label":"p = 40、n = 20","description":"p > n で S が特異になり、条件数を定義できない。","inputs":{"rows":20,"variables":40}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"checks","path":"/rows/0/2","range":{"max":1e-12}}
//|       - {"artifact":"checks","path":"/rows/1/1","range":{"max":1e-12}}
//|       - {"artifact":"checks","path":"/rows/2/1","range":{"max":1e-12}}
//|       - {"artifact":"checks","path":"/rows/0/1","approx":{"value":0.494323,"atol":1e-6}}
//|   - case: identity
//|     expect:
//|       - {"artifact":"checks","path":"/rows/0/1","equals":1}
//|   - case: large-sample
//|     expect:
//|       - {"artifact":"checks","path":"/rows/0/1","approx":{"value":0.147007,"atol":1e-6}}
//|   - case: wide
//|     expect:
//|       - {"artifact":"spectrum","path":"/rows/1/3","equals":null}
use scioxide_core::RealScalar;
use scioxide_linalg::{HermitianEigenDecomposition, HermitianInput, Matrix, MatrixView};
use scioxide_stats::{
    Frequency, MultivariateOptions, Weights, frequency_covariance_with_options,
    ledoit_wolf_covariance, sample_covariance, shrink_covariance,
};

let (n, p) = (rows as usize, variables as usize);
let data = correlated_rows(seed as u64, n, p, rho).map_err(|e| e.to_string())?;
let truth = toeplitz(p, rho).map_err(|e| e.to_string())?;
let (_, sample) = sample_covariance(data.view()).map_err(|e| e.to_string())?;
let (alpha, shrunk) = ledoit_wolf_covariance(data.view()).map_err(|e| e.to_string())?;

// 固有値を大きい順に並べる
let spectrum = |m: &Matrix<f64>| -> Result<Vec<f64>, String> {
    let eigen = HermitianEigenDecomposition::decompose(m, HermitianInput::Exact)
        .map_err(|e| e.to_string())?;
    let mut values = eigen.eigenvalues().to_vec();
    values.sort_by(|a, b| b.total_cmp(a));
    Ok(values)
};
let frobenius = |a: &Matrix<f64>, b: &Matrix<f64>| {
    let squares = a
        .as_slice()
        .iter()
        .zip(b.as_slice())
        .map(|(x, y)| (x - y) * (x - y));
    RealScalar::sqrt(squares.sum::<f64>())
};
let (mut table, mut series) = (vec![], vec![]);
for (name, matrix) in [
    ("真の Σ", &truth),
    ("標本共分散 S", &sample),
    ("Ledoit–Wolf Σ̂", &shrunk),
] {
    let values = spectrum(matrix)?;
    let (largest, smallest) = (values[0], values[p - 1]);
    // 最小固有値が丸め誤差の大きさ以下なら特異とみなし、条件数を定義しない
    let condition = (smallest > 1e-12 * largest).then(|| largest / smallest);
    table.push((
        name,
        largest,
        smallest,
        condition,
        frobenius(matrix, &truth),
    ));
    let points: Vec<[f64; 2]> = values
        .iter()
        .enumerate()
        .filter(|(_, v)| **v > 1e-12 * largest)
        .map(|(k, v)| [(k + 1) as f64, *v])
        .collect();
    series.push(
        serde_json::json!({ "name": name, "points": points, "style": { "showSymbol": true } }),
    );
}
let sig3 = serde_json::json!({ "significantDigits": 3 });
let columns = serde_json::json!([
    { "key": "0", "label": "行列" },
    { "key": "1", "label": "最大固有値 [-]", "type": "number", "format": sig3 },
    { "key": "2", "label": "最小固有値 [-]", "type": "number", "format": sig3 },
    { "key": "3", "label": "条件数 [-]", "type": "number", "format": sig3, "nullText": "特異" },
    { "key": "4", "label": "‖· − Σ‖_F [-]", "type": "number", "format": sig3 }
]);
emit_table_with_columns!(
    columns,
    table,
    metadata = serde_json::json!({ "id": "spectrum" })
);

// 独立な検算 1: α = min(β̄/δ, 1) を中心化した行から直接計算する
let at = |i: usize, j: usize| data.as_slice()[i * p + j];
let means: Vec<f64> = (0..p)
    .map(|j| (0..n).map(|i| at(i, j)).sum::<f64>() / n as f64)
    .collect();
let centered = |i: usize, j: usize| at(i, j) - means[j];
let s_n = |j: usize, k: usize| {
    (0..n).map(|i| centered(i, j) * centered(i, k)).sum::<f64>() / n as f64
};
let s_n: Vec<f64> = (0..p * p).map(|e| s_n(e / p, e % p)).collect();
let mu = (0..p).map(|j| s_n[j * p + j]).sum::<f64>() / p as f64;
let delta: f64 = (0..p * p)
    .map(|e| s_n[e] - if e / p == e % p { mu } else { 0.0 })
    .map(|d| d * d)
    .sum();
let beta: f64 = (0..n)
    .map(|i| {
        (0..p * p)
            .map(|e| centered(i, e / p) * centered(i, e % p) - s_n[e])
            .map(|d| d * d)
            .sum::<f64>()
    })
    .sum::<f64>()
    / (n * n) as f64;
let alpha_hand = if delta > 0.0 {
    (beta / delta).min(1.0)
} else {
    1.0
};
// 検算 2: shrink_covariance(S, α) は Σ̂ に等しい
let reshrunk = shrink_covariance(sample.view(), alpha).map_err(|e| e.to_string())?;
let max_gap = |a: &Matrix<f64>, b: &Matrix<f64>| {
    a.as_slice()
        .iter()
        .zip(b.as_slice())
        .map(|(x, y)| (x - y).abs())
        .fold(0.0, f64::max)
};
// 検算 3: 1 行目を 2 回並べたデータの S と、度数の重み (2, 1, …, 1) の共分散
let mut repeated = data.as_slice()[..p].to_vec();
repeated.extend_from_slice(data.as_slice());
let (_, repeated_cov) =
    sample_covariance(MatrixView::from_slice(n + 1, p, &repeated).map_err(|e| e.to_string())?)
        .map_err(|e| e.to_string())?;
let mut counts = vec![1_u64; n];
counts[0] = 2;
let (_, weighted) = frequency_covariance_with_options(
    data.view(),
    Weights::<_, Frequency>::new(&counts[..]),
    MultivariateOptions::new(),
)
.map_err(|e| e.to_string())?;
let checks = vec![
    (
        "縮小の強度 α と手計算",
        alpha,
        Some((alpha - alpha_hand).abs()),
    ),
    (
        "shrink_covariance(S, α) − Σ̂ の最大差",
        max_gap(&reshrunk, &shrunk),
        None,
    ),
    (
        "度数の重み − 複製した行の最大差",
        max_gap(&weighted, &repeated_cov),
        None,
    ),
];

    { "key": "0", "label": "量" },

emit_table_with_columns!(
```

既定の $n = 40$、$p = 20$、$\rho = 0.5$ では、真の $\Sigma$ の固有値は 0.335 から 2.89 まで（条件数 8.6）である。
標本共分散 $S$ の固有値は 0.095 から 3.61 までに広がり、条件数は 38 になる。
Ledoit–Wolf 推定の強度は $\alpha = 0.494$ で、固有値は 0.522 から 2.30 までに縮み、条件数は 4.4 になる。
$\Sigma$ との Frobenius ノルムの差は $S$ の 2.78 に対して $\hat\Sigma$ は 2.31 で、縮小で誤差が 17 % 減る。
縮小推定の条件数 4.4 は真の 8.6 より小さく、両端の固有値を縮めすぎている。
Ledoit–Wolf 推定は Frobenius ノルムの誤差を小さくする強度を選ぶので、条件数や個々の固有値を正しく推定するとは限らない。
3 つの検算の値はどれも $3 \times 10^{-16}$ 以下で、$\alpha$ の式、$\hat\Sigma = $ `shrink_covariance(S, α)`、度数の重みと行の複製の一致が確かめられる。

$\rho = 0$（`identity`）では真の $\Sigma$ は単位行列だが、$S$ の固有値は 0.17 から 2.42 までに散らばる。
これは $c = p/n = 0.5$ の Marchenko–Pastur 分布の台 $[0.086, 2.91]$ の中にある。
このとき $\alpha$ は上限の 1 になり、$\hat\Sigma = \mu I$（$\mu = 0.974$）で、誤差は $S$ の 2.90 から 0.118 まで下がる。
$n = 200$（`large-sample`）では $\alpha = 0.147$ と小さくなり、$S$ の条件数 12.9 に対して $\hat\Sigma$ は 7.96 で、真の 8.6 に近い。
$p = 40$、$n = 20$（`wide`）では $S$ のランクは 19 以下で、最小固有値は $-10^{-15}$ の大きさになり、条件数を定義できない。
縮小推定は $\alpha = 0.755$ で正定値になり、条件数は 3.1 である。

## 主成分分析

### 分散を最大にする方向

主成分分析（PCA）は中心化したデータ $X_c = X - \mathbf 1 \bar x^{\mathsf T}$ を、分散が大きい順に並べた直交する方向に射影する。
第 1 主成分の方向 $v_1$ は、単位ベクトルの中で射影 $X_c v$ の標本分散 $v^{\mathsf T} S v$ を最大にするもので、$S$ の最大固有値の固有ベクトルになる。
第 $k$ 主成分はそれまでの方向と直交する中での最大で、$S = V \Lambda V^{\mathsf T}$ の固有ベクトルを固有値の大きい順に並べたものが主成分の方向（負荷量）である。
第 $k$ 主成分の分散は $\lambda_k$ で、$\sum_k \lambda_k = \mathrm{tr}\,S$（各変数の分散の和）が成り立つ。
$\lambda_k/\mathrm{tr}\,S$ を寄与率と呼ぶ。

$X_c$ の上位 $k$ 個の主成分による再構成 $\hat X_k = X_c V_k V_k^{\mathsf T}$ は、ランク $k$ の行列の中で Frobenius ノルムの誤差を最小にし（Eckart–Young の定理）、その誤差は

$$
\|X_c - \hat X_k\|_F^2 = (n - 1) \sum_{j > k} \lambda_j
$$

である。
主成分の方向は符号が決まらず、$v_k$ と $-v_k$ はどちらも解である。
PCA は変数の単位に依存し、分散の大きい変数が上位の主成分を占める。
単位の違う変数を同じ重みで扱うには、先に各列を標準化（相関行列の PCA）する。

### 特異値分解による計算

`scioxide-stats` の [`PreparedPca`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/struct.PreparedPca.html) は、$S$ を作って固有値分解するのではなく、$X_c$ の薄い特異値分解 $X_c = U D V^{\mathsf T}$（$D = \mathrm{diag}(\sigma_1, \sigma_2, \dots)$、$\sigma_1 \ge \sigma_2 \ge \dots \ge 0$）を計算する。
主成分の方向は $V$ の列、分散は $\lambda_k = \sigma_k^2/(n - 1)$ である。
$S \propto X_c^{\mathsf T} X_c$ を作ると条件数が二乗になり、$\lambda_1$ に比べて小さい分散の主成分の相対精度が失われる。
特異値分解は $X_c$ に直接働くので、この損失がない。
計算量は $O(np\min(n, p))$ である。

保持する成分の数 $r$ は、`MultivariateOptions` の数値ランクの方針（既定は `RankPolicy::DimensionScaledEpsilon`）が特異値から決める。
中心化した行列のランクは $\min(n - 1, p)$ 以下なので、$p \ge n$ では最大でも $n - 1$ 個の成分を保持する。
保持した成分の分散が 0 になると `NumericalInstability` を返す。
主成分の個数を寄与率などで選ぶ機能はないので、再構成では使わない成分のスコアを 0 にする。

白色化（`PcaScaling::Whitened`）は、各スコアを成分の標準偏差 $\sigma_k/\sqrt{n - 1}$ で割り、当てはめたデータ上でスコアの標本共分散を（丸め誤差の範囲で）単位行列にする。
白色化した値は Mahalanobis 距離 $\sqrt{(x - \bar x)^{\mathsf T} S^{+} (x - \bar x)}$ をふつうのユークリッド距離にする。
分散の小さい成分を大きく拡大するので、ノイズの多い下位の成分を落としてから使う。

### PCA の API

`PreparedPca::new(data)` と `PreparedPca::with_options(data, options)` が当てはめ、`PreparedPca::build(data, options, context)` は実行コンテキストを受け取る。
当てはめた値は列の平均 `mean()`、$p \times r$ の方向の行列 `components()`、分散 `variances()`、数値ランクのレポート `rank()` で読む。
`transform(data, scaling)` は新しいデータのスコア $(Z - \mathbf 1 \bar x^{\mathsf T}) V$ を、`reconstruct(scores, scaling)` はスコア行列 $T$ から元の変数 $\mathbf 1 \bar x^{\mathsf T} + T V^{\mathsf T}$ を返す。
変換は丸めた `mean()` ではなく補償付きの平均を引く。
すべての成分を保持していれば、`reconstruct` は `transform` の逆写像になる（丸め誤差の範囲で）。

多くの行を繰り返し変換するときは、作業領域を渡す `transform_into(data, scaling, &mut output, &mut ws, context)` と `reconstruct_into` を使う。
`pca.workspace_requirements(rows, columns)` が [`MultivariateRequirements`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/struct.MultivariateRequirements.html)（`required_bytes()` が出力を除いた作業用のバイト数）を返し、`pca.workspace(rows, columns)` が [`PcaWorkspace`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/struct.PcaWorkspace.html) を作る。
`columns` は `transform_into` では保持した成分の数、`reconstruct_into` では変数の数である。
作業領域が足りなければ、確保せずに `ResourceLimit` を返す。
`PcaWorkspace::try_reserve` に CCA 用の要求を渡すと `InvalidInput` になる。

### PCA の実験

次のセルは上のセルと同じデータに `PreparedPca` を当てはめる。
最初の表には 4 つの検算と再構成の相対誤差を出す。
検算は、分散 `variances()` と $S$ の固有値の最大相対差、$\sum_k \lambda_k$ と $\mathrm{tr}\,S$ の相対差、白色化したスコアの標本共分散と単位行列の最大差である。
4 つ目は、上位 $k$ 個の成分で再構成した誤差 $\|X - \hat X_k\|_F^2$ と Eckart–Young の値 $(n - 1)\sum_{j>k}\lambda_j$ の差である。
2 つ目の表には、保持した成分の数 $r$、再構成に使った成分の数 $k$、作業領域の大きさを出す。
スコアは `transform_into` に `PcaWorkspace` を渡して求め、白色化しないスコアと白色化したスコアで同じ作業領域を使う。
2 つの図は各成分の分散と真の $\Sigma$ の固有値（破線）、累積の寄与率で、横軸は連動する。

```rust
    .fold(0.0, f64::max);

    .workspace_requirements(n, r)
    .map_err(|e| e.to_string())?;

// 白色化したスコアの標本共分散（平均は 0）を直接足して単位行列と比べる

    (0..n).map(|i| w[i * r + a] * w[i * r + b]).sum::<f64>() / (n - 1) as f64
};

    .map(|e| (white_entry(e / r, e % r) - if e / r == e % r { 1.0 } else { 0.0 }).abs())
    .fold(0.0, f64::max);

// 上位 k 個の成分による再構成と Eckart–Young の誤差 (n − 1) Σ_{j>k} λ_j
let k = (kept as usize).min(r);
let mut truncated = scores.as_slice().to_vec();
truncated
    .iter_mut()
    .enumerate()
    .filter(|(i, _)| i % r >= k)
    .for_each(|(_, v)| *v = 0.0);
let truncated = Matrix::from_vec(n, r, truncated).map_err(|e| e.to_string())?;
let rebuilt = pca
    .reconstruct(truncated.view(), PcaScaling::Unwhitened)
    .map_err(|e| e.to_string())?;
let error: f64 = x
    .as_slice()
    .iter()
    .zip(rebuilt.as_slice())
    .map(|(a, b)| (a - b) * (a - b))
    .sum();

    ("variances() と S の固有値の最大相対差", variance_gap),
    ("Σλ_k と tr S の相対差", trace_gap),

    (
        "再構成の誤差 − Eckart–Young の値（(n − 1) tr S で割る）",
        (error - predicted).abs() / scale,
    ),
    (
        "再構成の相対誤差 ‖X − X̂_k‖²_F / ((n − 1) tr S)",
        error / scale,
    ),
];
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let columns = serde_json::json!([
    { "key": "0", "label": "量" },
    { "key": "1", "label": "値 [-]", "type": "number", "format": sci3 }

let sizes = vec![(r, k, req.required_bytes())];

emit_table_with_columns!(

    sizes,
    metadata = serde_json::json!({ "id": "sizes" })
```

## 正準相関分析

### 2 組の変数の相関

正準相関分析（CCA）は同じ $n$ 個の個体で測った 2 組の変数 $X$（$p$ 列）と $Y$（$q$ 列）の関係を、それぞれの線形結合 $u = Xa$ と $v = Yb$ の相関で表す。
第 1 正準相関 $\rho_1$ は $\mathrm{Corr}(Xa, Yb)$ の最大値で、第 $k$ 正準相関は、それまでの正準変量と無相関な結合の中での最大値である。
正準相関は $\rho_1 \ge \rho_2 \ge \dots \ge \rho_r \ge 0$（$r \le \min(p, q)$）で、各組の変数の正則な線形変換で変わらない。
$p = q = 1$ なら $\rho_1$ は 2 変数の相関係数の絶対値に、$q = 1$ なら重回帰の決定係数の平方根に一致する。

共分散行列で書くと、$\rho_k^2$ は $S_{xx}^{-1} S_{xy} S_{yy}^{-1} S_{yx}$ の固有値である。
この式どおりに逆行列を作ると、$S_{xx}$ や $S_{yy}$ の条件数の二乗が誤差に効く。

### Björck–Golub の方法

[`PreparedCca`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/struct.PreparedCca.html) は、中心化した $X$ と $Y$ の薄い特異値分解

$$
X = U_x D_x V_x^{\mathsf T},
\qquad
Y = U_y D_y V_y^{\mathsf T},
\qquad
U_x^{\mathsf T} U_y = P\, C\, Q^{\mathsf T}
$$

から正準相関を求める（Björck–Golub）。
$U_x$ と $U_y$ は 2 つの列空間の正規直交基底で、$C$ の対角成分（基底どうしの主角の余弦）が正準相関である。
重みは $A = \sqrt{n - 1}\, V_x D_x^{-1} P$、$B = \sqrt{n - 1}\, V_y D_y^{-1} Q$ で、正準変量 $XA$ と $YB$ は当てはめたデータ上で標本分散が 1、相互共分散が $\mathrm{diag}(\rho_1, \dots, \rho_r)$ になる。
$X$、$Y$ の特異値分解は数値ランク $r_x$、$r_y$ で打ち切り、$r = \min(r_x, r_y)$ 組を保持する。
したがって線形従属な列があってもよい。
計算量は特異値分解 3 回（$X$、$Y$、$r_x \times r_y$ の積）である。

標本の正準相関は、上に偏る。
$\rho_1$ は多くの方向の中の最大値なので、真の相関が 0 でも $n$ が $p + q$ に比べて小さいと大きな値になる。
母集団で 0 の正準相関も、標本では正の値になる。
正準相関の有意性の検定（Bartlett の近似、Wilks の Λ）や、正則化した CCA は提供しない。

### CCA の API

`PreparedCca::new(x, y)`、`with_options(x, y, options)`、`build(x, y, options, context)` が当てはめる。
行数が違う、行が 2 未満、列がない、どちらかの数値ランクが 0（定数の列だけなど）のときは `InvalidInput` を返す。
`correlations()` が正準相関、`x_weights()` と `y_weights()` が $p \times r$ と $q \times r$ の重み、`ranks()` が 2 つの数値ランクのレポート、`means()` が 2 組の列の平均を返す。
`scores(x, y)` は新しいデータの正準変量 $(XA, YB)$ を返す。
作業領域を渡す `scores_into(x, y, &mut x_out, &mut y_out, &mut ws, context)` は、`cca.workspace_requirements(rows)` と `cca.workspace(rows)` で作る [`CcaWorkspace`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/struct.CcaWorkspace.html) を使う。
作業領域はスコアの形の行列 2 つ分で、足りなければ確保せずに `ResourceLimit` を返す。

### CCA の実験

次のセルは、共通の潜在変数 $z \sim \mathrm{N}(0, 1)$ を持つ 2 組の変数を作る。
$X$ の 3 列のうち $x_1 = a z + e_1$、$Y$ の 2 列のうち $y_1 = a z + f_1$ で、残りの列と $e_1$、$f_1$ は独立な標準正規ノイズである。
母集団の正準相関は $\rho_1 = a^2/(a^2 + 1)$、$\rho_2 = 0$ である。
表には標本の正準相関と母集団の値、$\rho_1$ の漸近標準誤差 $(1 - \rho_1^2)/\sqrt n$、2 つの独立な検算を出す。
検算は、`scores_into` で求めた正準変量の標本分散と 1 の最大差と、各組の正準変量の標本相関と $\hat\rho_k$ の最大差である。
図は第 1 正準変量の散布図で、相関が強いほど点が対角線に集まる。

```rust
//| id: stats-multivariate-statistics-api-4
//| ref: stats-multivariate-statistics-api-4
//| title: 潜在変数を共有する 2 組の変数の正準相関を母集団の値と比べる
//| run: reactive
//| crates: [scioxide-core, scioxide-linalg, scioxide-random, scioxide-stats]
//| inputs:
//|   seed: {"type":"integer","label":"乱数のシード","min":0,"max":100000,"value":11}
//|   samples: {"type":"range","label":"標本の大きさ n [個体]","min":10,"max":1000,"step":10,"value":100}
//|   loading: {"type":"range","label":"潜在変数の係数 a [-]","min":0,"max":3,"step":0.25,"value":1.5}
//| cases:
//|   - {"id":"no-signal","label":"a = 0","description":"母集団の正準相関はすべて 0 だが、標本の ρ̂₁ は 0 にならない。","inputs":{"loading":0}}
//|   - {"id":"small-sample","label":"n = 10","description":"ρ̂₂ まで大きくなり、上への偏りが目立つ。","inputs":{"samples":10}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"cca","path":"/rows/0/2","approx":{"value":0.692308,"atol":1e-6}}
//|       - {"artifact":"cca","path":"/rows/0/4","range":{"max":1e-12}}
//|       - {"artifact":"cca","path":"/rows/0/5","range":{"max":1e-12}}
//|       - {"artifact":"cca","path":"/rows/0/1","approx":{"value":0.671629,"atol":1e-6}}
//|   - case: no-signal
//|     expect:
//|       - {"artifact":"cca","path":"/rows/0/1","approx":{"value":0.211086,"atol":1e-6}}
//|   - case: small-sample
//|     expect:
//|       - {"artifact":"cca","path":"/rows/1/1","approx":{"value":0.338708,"atol":1e-6}}
use scioxide_core::{ExecutionContext, RealScalar};
use scioxide_linalg::Matrix;
use scioxide_random::{Distribution, Normal, SeedableRng, Xoshiro256StarStar};
use scioxide_stats::PreparedCca;

let n = samples as usize;
let mut rng = Xoshiro256StarStar::from_seed(seed as u64);
let normal = Normal::new(0.0, 1.0).map_err(|e| e.to_string())?;
let mut draw = || normal.sample(&mut rng).map_err(|e| e.to_string());
let (mut x, mut y) = (Vec::with_capacity(3 * n), Vec::with_capacity(2 * n));
for _ in 0..n {
    let z = draw()?;
    x.extend([loading * z + draw()?, draw()?, draw()?]);
    y.extend([loading * z + draw()?, draw()?]);
}
let x = Matrix::from_vec(n, 3, x).map_err(|e| e.to_string())?;
let y = Matrix::from_vec(n, 2, y).map_err(|e| e.to_string())?;
let cca = PreparedCca::new(x.view(), y.view()).map_err(|e| e.to_string())?;
let rho = cca.correlations();
let r = rho.len();

// 正準変量を作業領域に書き、標本分散と組ごとの相関を直接計算する
let context = ExecutionContext::sequential();
let mut ws = cca.workspace(n).map_err(|e| e.to_string())?;
let (mut u, mut v) = (
    Matrix::zeros(n, r).map_err(|e| e.to_string())?,
    Matrix::zeros(n, r).map_err(|e| e.to_string())?,
);
cca.scores_into(x.view(), y.view(), &mut u, &mut v, &mut ws, context)
    .map_err(|e| e.to_string())?;
let column = |m: &Matrix<f64>, k: usize| -> Vec<f64> {
    (0..n).map(|i| m.as_slice()[i * r + k]).collect()
};
let covariance = |a: &[f64], b: &[f64]| {
    let (ma, mb) = (
        a.iter().sum::<f64>() / n as f64,
        b.iter().sum::<f64>() / n as f64,
    );
    a.iter()
        .zip(b)
        .map(|(s, t)| (s - ma) * (t - mb))
        .sum::<f64>()
        / (n - 1) as f64
};
let population = loading * loading / (loading * loading + 1.0);
let rows: Vec<_> = (0..r)
    .map(|k| {
        let (uk, vk) = (column(&u, k), column(&v, k));
        let unit = (covariance(&uk, &uk) - 1.0)
            .abs()
            .max((covariance(&vk, &vk) - 1.0).abs());
        let correlation = covariance(&uk, &vk)
            / RealScalar::sqrt(covariance(&uk, &uk) * covariance(&vk, &vk));
        let truth = if k == 0 { population } else { 0.0 };
        let se = (k == 0).then(|| (1.0 - truth * truth) / RealScalar::sqrt(n as f64));
        (k + 1, rho[k], truth, se, unit, (correlation - rho[k]).abs())
    })
    .collect();
let fixed4 = serde_json::json!({ "fractionDigits": 4 });
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let columns = serde_json::json!([
    { "key": "0", "label": "k", "type": "integer" },
    { "key": "1", "label": "標本 ρ̂_k [-]", "type": "number", "format": fixed4 },
    { "key": "2", "label": "母集団 ρ_k [-]", "type": "number", "format": fixed4 },
    { "key": "3", "label": "漸近 SE [-]", "type": "number", "format": fixed4, "nullText": "—" },
    { "key": "4", "label": "|分散 − 1| [-]", "type": "number", "format": sci2 },
    { "key": "5", "label": "|相関 − ρ̂_k| [-]", "type": "number", "format": sci2 }
]);
emit_table_with_columns!(columns, rows, metadata = serde_json::json!({ "id": "cca" }));
let points: Vec<[f64; 2]> = (0..n)
    .map(|i| [u.as_slice()[i * r], v.as_slice()[i * r]])
    .collect();
emit_scatter_chart!(
    &vec![serde_json::json!({ "name": "個体", "points": points })],
    options = &serde_json::json!({
        "xLabel": "第 1 正準変量 u₁ = X a₁ [-]",
        "yLabel": "第 1 正準変量 v₁ = Y b₁ [-]"
    })
);
```

既定の $n = 100$、$a = 1.5$ では、母集団の第 1 正準相関 $\rho_1 = 2.25/3.25 = 0.692$ に対して標本の値は $\hat\rho_1 = 0.672$ で、漸近標準誤差 0.052 の範囲にある。
母集団で 0 の第 2 正準相関は $\hat\rho_2 = 0.097$ になる。
正準変量の標本分散と 1 の差、正準変量の組の相関と $\hat\rho_k$ の差は、どちらも $10^{-15}$ 以下である。
$a = 0$（`no-signal`）では母集団の正準相関はすべて 0 だが、$\hat\rho_1 = 0.211$、$\hat\rho_2 = 0.095$ になる。
$n = 10$（`small-sample`）では $\hat\rho_1 = 0.840$、$\hat\rho_2 = 0.339$ まで大きくなり、少ない個体で多くの方向から最大の相関を選んだことによる上への偏りが目立つ。

## まとめ

`sample_covariance` は補償付きの平均を引いて中心化するので、大きな共通のずれを持つ列でも偏差の桁を保つ。
$p/n$ が小さくないときは標本共分散の固有値が広がるので、逆行列や条件数を使う前に `ledoit_wolf_covariance` で縮め、返る強度 $\alpha$ が 1 に近ければ、$S$ と目標 $\mu I$ の違いが $S$ の推定誤差に埋もれていると読む。
`PreparedPca` は中心化したデータの特異値分解で主成分を求め、分散の和は $\mathrm{tr}\,S$、上位 $k$ 成分の再構成の誤差は残りの分散の和 $(n - 1)\sum_{j>k}\lambda_j$ で確かめられる。
`PreparedCca` の正準相関は上に偏るので、$n$ が $p + q$ に比べて小さいときは母集団で 0 の相関も大きく見えることを踏まえて読む。
