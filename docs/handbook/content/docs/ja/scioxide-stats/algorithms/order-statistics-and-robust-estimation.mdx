標本平均と標本分散は、正規分布に従う測定では最良の推定量である。
しかし、裾の重い分布や外れ値（outlier）を含むデータでは、2 乗誤差に基づく推定量は少数の極端な値に大きく動かされる。
観測の順序を使う推定量（中央値、トリム平均）と、極端な観測の影響を有界に抑える推定量（Huber の M-推定量）は、この影響を抑える。
このページは、順序統計量の分布、崩壊点、トリム平均、Huber の推定量、多変量の散布行列、シグマクリッピング、移動ウインドウの統計量を説明する。
そのうえで、外れ値の大きさと混入の割合を変えて、推定量の偏りと分散を実験で比べる。

## 順序統計量と最頻値

独立同分布に従う連続確率変数 $X_1, \dots, X_n$ を昇順に並べた列 $X_{(1)} \le X_{(2)} \le \dots \le X_{(n)}$ を**順序統計量**と呼ぶ。
母集団の分布関数を $F$、密度を $f$ とすると、$k$ 番目の順序統計量 $X_{(k)}$ の密度は次の式で与えられる。

$$
f_{(k)}(x) = \frac{n!}{(k-1)!\,(n-k)!} \, F(x)^{k-1} \, \bigl(1 - F(x)\bigr)^{n-k} \, f(x)
$$

$k-1$ 個が $x$ より下、1 個が $x$ の近く、$n-k$ 個が $x$ より上にある確率を数えた式である。
$U_{(k)} = F(X_{(k)})$ はベータ分布 $\mathrm{Beta}(k, n-k+1)$ に従い、その期待値 $k/(n+1)$ は分位点の型 6 のプロット位置になる。
最小値と最大値の分布関数は $F_{(1)}(x) = 1 - (1 - F(x))^n$、$F_{(n)}(x) = F(x)^n$ である。
最大値の分布は $n$ とともに裾の方へ動くので、極値の統計量は標本の大きさを明示して読む。

scioxide-stats の順序に基づく推定量は `Statistic` の構成子で選び、`statistic(values, weights, request)` で評価する。
結果の `StatisticValue::Order` は列挙型 `OrderResult` を持ち、分位点（`QuantileResult`）、最頻値（`ModeResult`）、エクスペクタイル、四分位範囲、百分位の位置、同順位の補正係数を区別する。
`StatisticValue::scalar()` はどの場合も値を実数として返す。
`Statistic::mode()` が返す `ModeResult` は、最も度数の大きい値 `value` とその度数 `count` を持つ。
度数が等しい値が複数あるときは最小の値を返し、$-0.0$ と $+0.0$ は一つの値（$+0.0$）として数える。
最小値・最大値は `Statistic::minimum()`・`maximum()`、中央値は `Statistic::quantile(QuantileProbability::new(0.5)?, rule)` で求める。
分位点と四分位範囲は全体を整列せずに選択で求め、平均 $O(n)$ である（[選択による分位点の計算](oxref:stats-quantile-selected-computation)）。
最頻値は同じ値の連なりを見つけるために整列し、$O(n \log n)$ である。

## 崩壊点とトリム平均

推定量のロバスト性を測る指標の一つが**崩壊点**（breakdown point）である。
有限標本の崩壊点は、$n$ 個の観測のうち $m$ 個を任意の値に置き換えたとき、推定値をいくらでも大きく（または小さく）できる最小の割合 $m/n$ である。
標本平均は 1 個の観測を無限大へ動かすだけで無限大へ動くので、崩壊点は $1/n$ で、$n \to \infty$ で 0 になる。
中央値は半数近くを置き換えるまで有界にとどまり、崩壊点は約 1/2 である。

**トリム平均**（trimmed mean）は、昇順に並べた標本の両端からそれぞれ割合 $\alpha$ の観測を除き、残りの算術平均をとる。
$\lfloor \alpha n \rfloor$ 個ずつ除くので、上側の外れ値が $\lfloor \alpha n \rfloor$ 個までなら除かれ、崩壊点は $(\lfloor \alpha n \rfloor + 1)/n$、漸近的に $\alpha$ である。
$\alpha \to 1/2$ の極限は中央値である。
正規分布でのトリム平均の漸近分散は、$\xi = \Phi^{-1}(1 - \alpha)$ として次の式になる。

$$
n\,\mathrm{Var}(\bar X_\alpha) \to \frac{\int_{-\xi}^{\xi} x^2\,\varphi(x)\,dx + 2\alpha\xi^2}{(1 - 2\alpha)^2}
$$

分子は両端の観測を $\pm\xi$ に置き換えた（Winsor 化した）分布の分散である。
$\alpha = 0.2$ でこの値は約 1.14 で、正規分布での相対効率は約 0.87 になる。

scioxide-stats のトリム平均は `Statistic::trimmed_mean(proportion, side)` で選ぶ。
`proportion` は $[0, 1)$ の割合で、`TrimSide` で除く端を選ぶ。
`Both` は両端から、`Lower` は小さい側だけから、`Upper` は大きい側だけから $\lfloor \text{proportion} \cdot n \rfloor$ 個を除く。
割合が範囲外なら `InvalidInput` になり、すべての観測を除く割合もエラーになる。
刈り込んだ標本そのものが必要なら、`StatisticsWorkspace::trim_into(values, proportion, side, output)` が残った観測を整列して出力の先頭に書き、その個数を返す。
Winsor 化した平均（両端の観測を除かずに境界の値に置き換える平均）は提供しない。
必要なら、整列した標本の両端を境界の値で置き換えてから平均を求める。

割合ではなく値の範囲で観測を除くときは `TrimLimits` を使う。
`TrimLimits::new(lower, upper)` は下限と上限（`None` は制限なし）を受け取り、$\text{lower} \le x \le \text{upper}$ の観測を残す。
境界は既定で閉じており、`with_inclusive(TrimInclusion::Exclusive, TrimInclusion::Inclusive)` のように端ごとに開いた境界（`Exclusive`）にできる。
NaN や無限大の境界は `NonFinite`、下限が上限を超えると `InvalidInput` で拒む。
`reduce_trimmed_moments` は行列ビューの各バッチから範囲内の観測だけのモーメントを求める（[行列ビューの一括集約](oxref:stats-online-matrix-view-reduction)）。

尺度のロバストな推定量には、中央値絶対偏差 `Statistic::median_absolute_deviation(method, scale)` と四分位範囲 `Statistic::iqr(method)` がある。
中央値絶対偏差は $\mathrm{median}_i |x_i - \mathrm{median}(x)| / \text{scale}$ で、`scale = 1` で生の値になる。
正規分布の標準偏差と一致させるには、`scale` に $\Phi^{-1}(3/4) \approx 0.6745$ を渡す。
中央値絶対偏差の崩壊点は約 1/2、四分位範囲の崩壊点は約 1/4 である。

## Huber の M-推定量とロバスト散布

トリム平均は除いた観測の情報を捨てる。
Huber（1964）の **M-推定量**は、観測を捨てずに、残差が大きい観測の影響を滑らかに抑える。
位置 $\mu$、尺度 $\sigma$ に対し、正規化した残差を $u_i = (x_i - \mu)/\sigma$ とする。
Huber の位置推定量は、次の損失 $\rho_c$ の和を最小にする $\mu$ である。

$$
\rho_c(u) = \begin{cases}
\frac{1}{2} u^2 & (|u| \le c) \\
c |u| - \frac{1}{2} c^2 & (|u| > c)
\end{cases}
$$

$\rho_c$ は $|u| \le c$ で 2 乗損失、外側で絶対損失に等しく、境目で 1 階微分まで連続である。
その導関数 $\psi_c(u) = \rho_c'(u) = \max(-c, \min(c, u))$ を**影響関数**（$\psi$ 関数）と呼ぶ。
$\psi_c$ は $|u| \le c$ で $u$ に等しく、外側では $\pm c$ で頭打ちになるので、1 個の観測が推定値に与える影響は有界である。
推定方程式 $\sum_i \psi_c((x_i - \mu)/\sigma) = 0$ は閉じた形の解を持たない。
重み $w_i = \psi_c(u_i)/u_i = \min(1, c/|u_i|)$ を使うと方程式は $\sum_i w_i (x_i - \mu) = 0$ と書けるので、重みを固定して加重平均を求め、新しい残差から重みを計算し直す反復で解く。
これを**反復再重み付け最小二乗法**（IRLS）と呼ぶ。
$\rho_c$ は凸なので、尺度を固定すれば解は一意で、IRLS は収束する。

正規分布での漸近分散は $E[\psi_c^2]/(E[\psi_c'])^2$ で、$c = 1.345$ のとき標本平均に対する相対効率が 95% になる。
$c \to \infty$ で標本平均、$c \to 0$ で中央値に近づく。
尺度を中央値絶対偏差のような崩壊点 1/2 の推定量で決めると、位置の推定量の崩壊点も約 1/2 になる。

scioxide-stats の `huber_location(&x)` は、同調定数 1.345 と、重み付き最小二乗の解を 100 回までとする既定の設定で、この反復を行う。
最初の反復は重みなしの最小二乗、つまり標本平均である。
各反復で、残差の中央値絶対偏差を 0.6745 で割った値を尺度 $\hat\sigma$ とし、重み $\min(1, c\hat\sigma/|r_i|)$ で次の重み付き最小二乗を解く。
位置の推定では、残差の中央値絶対偏差は $\mu$ によらずデータの中央値絶対偏差に等しいので、尺度は反復の間一定である。
係数の変化が `scioxide_core::StepTolerance` の許容誤差以下になると `Converged` で止まる。
残差がすべて丸めの範囲で 0 なら、尺度 0 の `ExactFit` で止まる。
中央値絶対偏差が 0 なのに残差が 0 でないとき（半数を超える観測が同じ値のときなど）は、重みを決められないので `InvalidInput` を返す。
ワンショット呼び出しの `huber_location` は、反復の上限で止まると値を返さず、`ConvergenceFailure`（`IterationLimit`）を返す。

設定を変えるときは `huber_location_with_options(&x, options)` に `HuberOptions` を渡す。
`HuberOptions::default()` から、`with_tuning(c)`、`with_tolerance(step_tolerance)`、`with_iterations(budget)`（重み付き最小二乗の解の回数の上限）、`with_factor_iterations(budget)`（各特異値分解の反復の上限）、`with_max_bytes(bytes)` で変える。
オプション付き形式は上限で止まっても最後に受理した反復を `HuberFit` で返し、終了状態 `termination()` を `BudgetExhausted` にする。
`HuberFit` は係数 `coefficients()`（位置の推定では 1 成分）、残差 `residuals()`、最後の重み `weights()`、尺度 `scale()`、解の回数 `iterations()` と、レポート `report()` を持つ。
`HuberReport` は終了状態、反復と評価の回数 `counts()`、受理した反復の数 `accepted_iterations()` を持つ。
終了状態 `StatsTermination` は `is_success()`（`Completed`、`Converged`、`ExactFit` で真）で成否を判定する。
同じ反復で回帰係数を求める `PreparedHuber` は、[回帰・分散分析・一般化線形モデル](../regression-anova-and-glm/)で説明する。

多変量データ $\mathbf x_i \in \mathbb R^p$ の位置と散布行列には、`PreparedHuberScatter` が Huber 型の M-推定量（Maronna, 1976）を与える。
標本平均と標本共分散から始め、各反復で Mahalanobis 距離 $d_i = \sqrt{(\mathbf x_i - \boldsymbol\mu)^\top \Sigma^{-1} (\mathbf x_i - \boldsymbol\mu)}$ と重み $w_i = \min(1, c/d_i)$ を求め、次の式で推定を更新する。

$$
\boldsymbol\mu = \frac{\sum_i w_i \mathbf x_i}{\sum_i w_i}, \qquad
\Sigma = \frac{\sum_i w_i (\mathbf x_i - \boldsymbol\mu)(\mathbf x_i - \boldsymbol\mu)^\top}{\sum_i w_i}
$$

$\boldsymbol\mu$ と $\Sigma$ の成分の変化の最大を、成分の絶対値の最大（1 以上）で割った値が許容誤差以下になると収束とする。
各反復は対称固有値分解 1 回の $O(p^3)$ と、距離と新しい散布の $O(np^2)$ の演算である。
散布行列は総重みで正規化し、正規分布での一致性の補正をしない。
この推定量の崩壊点は高くなく（次元 $p$ とともに $1/(p+1)$ 程度まで下がる）、最小共分散行列式（MCD）のような高崩壊点の推定量は提供しない。

`PreparedHuberScatter::new(data, options)` は $n \times p$ の行列を受け取り、列がない、または行の数が列の数以下なら `InvalidInput`、非有限値は `NonFinite` で拒む。
`HuberScatterOptions` の既定は、閾値 $c = 2$、相対変化の許容誤差 $\sqrt\varepsilon$、反復 100 回である。
`fit()` は逐次に実行し、`fit_scoped(scope)` は実行コンテキストを受け取り、どちらも `HuberScatterFit` を返す。
`fit_into(&mut output, &mut workspace, scope)` は、`output()` と `workspace()` で作った `HuberScatterOutput` と `HuberScatterWorkspace` を使い回し、`HuberScatterReport`（終了状態、反復の数、最後の相対変化、回数）を返す。
`workspace()` は、標本共分散の最小の固有値が $p\varepsilon\lambda_{\max}$ 以下（数値的に特異）なら `InvalidInput` を返す。
反復の上限、取り消し、期限で止まったときも呼び出しは `Ok` を返し、終了状態を `BudgetExhausted` か `Stopped` にして、最後に受理した推定（出発点の標本平均と共分散のこともある）を残す。
`HuberScatterOutput::fit()` は直前の成功した呼び出しの `HuberScatterFit`（位置 `location`、散布行列 `scatter`、反復の数、相対変化、終了状態）を返す。
`HuberScatterWorkspace::last_accepted()` は直前の呼び出しで最後に受理した推定を `HuberScatterAccepted` で返し、`last_attempt()` は失敗した呼び出しも含む試行の記録を返す。

## シグマクリッピングと移動ウインドウ統計量

**シグマクリッピング**（sigma clipping）は、天文学の測光や信号処理で使う外れ値の除去法である。
残っている観測の平均 $\bar x$ と標準偏差 $s$ を求め、区間 $[\bar x - c_{\mathrm{low}} s,\ \bar x + c_{\mathrm{high}} s]$ の外の観測を除く。
除いたあとの標本で $\bar x$ と $s$ を計算し直し、除く観測がなくなるか、反復の上限に達するまで繰り返す。
大きな外れ値は最初の $\bar x$ と $s$ を自分の方へ引き、$s$ を大きくするので、小さめの外れ値を隠す。
これを**マスキング**と呼び、反復はこの隠れた外れ値を後の回で取り除く。

`sigma_clip_into(values, low, high, options, output, indices, workspace, scope)` は、各回で残っている観測の平均と母標準偏差（除数 $n$）を使う。
`SigmaClipOptions::new()` は反復の上限 100 回で、`with_max_iterations` で変える。
残った観測は入力の順に `output` の先頭へ、その入力の添字は `indices` の先頭へ書く。
結果の `SigmaClipResult` は、残った数 `retained()`、完了した回数 `iterations()`、最後の回の境界 `lower()`・`upper()`、終了状態 `termination()` を持つ。
ある回で何も除かなければ `Converged`、上限に達すれば `BudgetExhausted` で、上限で止まっても最後の回の結果は使える。
`low` か `high` が負か非有限なら `InvalidInput`、すべての観測を除く回があれば `InvalidInput` を返す。
作業領域は `StatisticsWorkspace::scalar_requirements(n, options)` で大きさを問い合わせて事前確保する。
中央値と中央値絶対偏差を中心と尺度に使うクリッピングは提供しない。
必要なら `Statistic::quantile` と `Statistic::median_absolute_deviation` で中心と尺度を求め、範囲外の観測を除く。

時系列やストリームの局所的な要約には、移動ウインドウの統計量を使う。
`RollingWindow::new(left, right)` は各観測の前 `left` 個から後 `right` 個までのウインドウを表し、`RollingBoundary` で系列の端の扱いを選ぶ。
`Truncate`（既定）は系列の外を除いてウインドウを短くし、`Repeat` は最初か最後の観測を繰り返し、`ZeroPad` は 0 で埋める（重みなしのビューだけ）。
`rolling_statistics(view, statistic, window)` は既定の設定で、`rolling_statistics_with_options` は `StatisticsOptions` を受け取る。
事前に確保した出力と作業領域に書く `rolling_statistics_into` は、確保をしない。
重みなしの平均・分散・標準偏差は補償付きの和でウインドウを逐次に更新し、1 ウインドウあたり償却 $O(1)$ である。
丸め誤差の見積もりが $64\varepsilon$ を超えたときと、ウインドウ幅 $w$ ごとに、ウインドウを直接計算し直す。
重みなしの中央値はウインドウを整列したまま保ち、1 ウインドウあたり $O(w)$ である。
他の統計量はウインドウごとに直接計算する。

## 外れ値の大きさと推定量

//|       - {"artifact":"estimates","path":"/rows/0/1","approx":{"value":0.0,"atol":1e-12}}
//|       - {"artifact":"estimates","path":"/rows/3/1","approx":{"value":0.020384,"atol":1e-5}}
//|   - case: far-outlier
//|     expect:
//|       - {"artifact":"estimates","path":"/rows/0/1","approx":{"value":5.0,"atol":1e-12}}
//|       - {"artifact":"estimates","path":"/rows/3/1","approx":{"value":0.16875,"atol":1e-6}}

    HuberOptions, QuantileMethod, QuantileProbability, QuantileRule, Statistic, TrimSide,
    Unweighted, huber_location_with_options, statistic,
};

let base = [-1.35_f64, -0.92, -0.55, -0.18, 0.05, 0.28, 0.62, 0.88, 1.17];
let half = QuantileProbability::new(0.5).map_err(|e| e.to_string())?;
// 外れ値 out を加えた 10 個の標本で、四つの推定量と Huber の終了状態を求める。
let estimate = |out: f64| -> Result<([f64; 4], String, usize), String> {

    let value = |request: Statistic<f64>| -> Result<f64, String> {

            .and_then(|v| v.scalar())

    let fit =

    let huber = fit.coefficients().as_slice()[0];
    Ok((
        [mean, median, trimmed, huber],
        format!("{:?}", fit.termination()),

};
let mut curves = vec![Vec::new(); 4];
for i in 0..=50 {
    let out = f64::from(i);
    let (values, _, _) = estimate(out)?;
    for (curve, value) in curves.iter_mut().zip(values) {

    }
}
let names = [
    "標本平均",
    "中央値（型 7）",
    "20% トリム平均",
    "Huber（c = 1.345）",
];

        "yLabel": "位置の推定値 [-]",
        "xMin": 0.0,
        "xMax": 50.0,
        "annotations": [
            {"kind": "line", "axis": "x", "value": outlier_magnitude, "label": "選んだ x_out"},
            {"kind": "line", "axis": "y", "value": 0.0, "label": "9 個の観測の平均 0"}
        ]
    })
);
let (values, termination, iterations) = estimate(outlier_magnitude)?;
// n = 10 での有限標本の崩壊点（本文の式）。
let breakdown = [0.1, 0.5, 0.3, 0.5];
let rows: Vec<_> = (0..4)
    .map(|j| {
        let huber = j == 3;
        (
            names[j],
            values[j],
            breakdown[j],
            huber.then(|| termination.clone()),
            huber.then_some(iterations),
        )
    })
    .collect();
let fixed4 = serde_json::json!({ "fractionDigits": 4 });
let fixed1 = serde_json::json!({ "fractionDigits": 1 });
let columns = serde_json::json!([
    { "key": "0", "label": "推定量", "type": "string" },
    { "key": "1", "label": "推定値 [-]", "type": "number", "format": fixed4 },

    { "key": "3", "label": "終了状態", "type": "string", "nullText": "—" },
    { "key": "4", "label": "解の回数", "type": "integer", "nullText": "—" }

外れ値が 0 のとき、四つの推定量は 0 の近くにそろう（標本平均 0、中央値 0.025、トリム平均 0.037、Huber 0.020）。
既定の $x_{\mathrm{out}} = 10$ では、標本平均は $(0 + 10)/10 = 1.0$ まで動き、$x_{\mathrm{out}} = 50$ では 5.0 になる。
中央値（0.165）とトリム平均（0.183）は、外れ値が最大の観測になった時点（$x_{\mathrm{out}} > 1.17$）から動かない。
外れ値は順位でしか効かず、その大きさは推定値に入らないからである。
Huber の推定量は $x_{\mathrm{out}}$ が残差の閾値 $c\hat\sigma$ を超えるまで滑らかに増え、その先は 0.16875 で一定になる。
閾値を超えた観測の $\psi$ は $c$ で頭打ちになり、影響が有界だからである。
Huber の解の回数は、$x_{\mathrm{out}} = 0$ で 8 回、10 と 50 で 11 回で、どれも `Converged` で止まった。
崩壊点の列は $n = 10$ での値で、標本平均は 1/10、20% トリム平均は $(\lfloor 0.2 \cdot 10 \rfloor + 1)/10 = 0.3$、中央値と Huber（中央値絶対偏差を尺度に使う）は 5/10 である。

## 汚染された標本での偏りと分散

前節は 1 個の外れ値への反応を見た。
次に、外れ値が確率的に混ざるときの偏りと分散を比べる。
大きさ $n = 20$ の標本のうち $k$ 個を $N(\delta, 1)$、残りを $N(0, 1)$ から引く汚染モデルを考える。
真の位置は 0 なので、推定値の平均が偏り、2 乗平均の平方根（RMSE）が偏りと分散を合わせた誤差になる。

次のセルは、この標本を $R = 2000$ 回作り、四つの推定量の偏り、標準偏差、RMSE を求める。
偏りの Monte Carlo 標準誤差は $\mathrm{SD}/\sqrt R$ である。
$k = 0$ では、$n$ 倍した分散を正規分布での漸近分散と比べる。
漸近分散は、標本平均で 1、中央値で $\pi/2$、20% トリム平均で前節の式、Huber で $E[\psi_c^2]/(E[\psi_c'])^2$ である。
Huber の式の $E[\psi_c'] = 2\Phi(c) - 1$ と $E[\psi_c^2] = 2\Phi(c) - 1 - 2c\varphi(c) + 2c^2(1 - \Phi(c))$ は、`scioxide_special::erf` と `erfc` で求める。
$n$ 倍した分散の標準誤差は、正規近似 $n\,\mathrm{Var}\sqrt{2/(R-1)}$ で示す。

```rust
//| id: stats-robust-contamination
//| ref: stats-robust-contamination
//| title: 外れ値の混入数とずれを変えて四つの位置推定量の偏りと分散を測る
//| run: button
//| crates: [scioxide-stats, scioxide-random, scioxide-special, scioxide-core]
//| inputs:
//|   contaminated: {"type":"range","label":"外れ値の数 k（n = 20 のうち）","description":"N(δ, 1) から引く観測の数。","min":0,"max":8,"step":1,"value":2}
//|   shift: {"type":"range","label":"外れ値の中心 δ [-]","description":"外れ値の分布の平均。","min":2,"max":20,"step":1,"value":8}
//|   sampling_seed: {"type":"integer","label":"乱数のシード","min":0,"max":100000,"value":31}
//| cases:
//|   - {"id":"clean","label":"k = 0","description":"汚染がなく、n 倍した分散を漸近分散と比べられる。","inputs":{"contaminated":0}}
//|   - {"id":"heavy","label":"k = 8","description":"40% の汚染で、トリム平均の崩壊点を超える。","inputs":{"contaminated":8}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"contamination","path":"/rows/0/1","approx":{"value":0.80,"atol":0.01}}
//|       - {"artifact":"contamination","path":"/rows/1/1","approx":{"value":0.138,"atol":0.01}}
//|       - {"artifact":"contamination","path":"/rows/3/4","approx":{"value":0.311,"atol":0.01}}
//|       - {"artifact":"contamination","path":"/rows/3/7","approx":{"value":1.0526312911880376,"rtol":1e-9}}
//|       - {"artifact":"contamination","path":"/rows/2/7","approx":{"value":1.1446853519616507,"rtol":1e-9}}
//|   - case: clean
//|     expect:
//|       - {"artifact":"contamination","path":"/rows/0/5","approx":{"value":1.0,"atol":0.07}}
//|       - {"artifact":"contamination","path":"/rows/1/5","approx":{"value":1.5708,"atol":0.15}}
//|       - {"artifact":"contamination","path":"/rows/3/5","approx":{"value":1.0526,"atol":0.1}}
//|   - case: heavy
//|     expect:
//|       - {"artifact":"contamination","path":"/rows/2/1","range":{"min":2.0}}
//|       - {"artifact":"contamination","path":"/rows/1/1","range":{"max":1.2}}
use scioxide_core::RealScalar;
use scioxide_random::{Distribution, Normal, SeedableRng, SplitMix64};
use scioxide_stats::{
    HuberOptions, QuantileMethod, QuantileProbability, QuantileRule, Statistic, TrimSide,
    Unweighted, huber_location_with_options, statistic,
};

const N: usize = 20;
const REPLICATES: usize = 2000;
let k = contaminated as usize;
let half = QuantileProbability::new(0.5).map_err(|e| e.to_string())?;
let standard = Normal::new(0.0_f64, 1.0).map_err(|e| e.to_string())?;
let mut rng = SplitMix64::from_seed(sampling_seed as u64);
let (mut sums, mut squares) = ([0.0_f64; 4], [0.0_f64; 4]);
let mut not_converged = 0_usize;
let mut x = [0.0_f64; N];
for _ in 0..REPLICATES {
    for (i, xi) in x.iter_mut().enumerate() {
        let z = standard.sample(&mut rng).map_err(|e| e.to_string())?;
        *xi = if i < k { shift + z } else { z };
    }
    let value = |request: Statistic<f64>| -> Result<f64, String> {
        statistic(&x, Unweighted, request)
            .and_then(|v| v.scalar())
            .map_err(|e| e.to_string())
    };
    let fit =
        huber_location_with_options(&x, HuberOptions::default()).map_err(|e| e.to_string())?;
    not_converged += usize::from(!fit.termination().is_success());
    let estimates = [
        value(Statistic::mean())?,
        value(Statistic::quantile(
            half,
            QuantileRule::new(QuantileMethod::Linear),
        ))?,
        value(Statistic::trimmed_mean(0.2, TrimSide::Both))?,
        fit.coefficients().as_slice()[0],
    ];
    for (j, e) in estimates.into_iter().enumerate() {
        sums[j] += e;
        squares[j] += e * e;
    }
}
// 正規分布での漸近分散 n·Var（本文の式）。
let c = 1.345_f64;
let sqrt2 = RealScalar::sqrt(2.0_f64);
let pdf =
    |x: f64| RealScalar::exp(-0.5 * x * x) / RealScalar::sqrt(2.0 * core::f64::consts::PI);
let central = scioxide_special::erf(c / sqrt2).map_err(|e| e.to_string())?;
let upper_tail = 0.5 * scioxide_special::erfc(c / sqrt2).map_err(|e| e.to_string())?;
let huber_variance =
    (central - 2.0 * c * pdf(c) + 2.0 * c * c * upper_tail) / (central * central);
let xi = 0.8416212335729143_f64; // Φ⁻¹(0.8)
let winsorized = 0.6 - 2.0 * xi * pdf(xi) + 0.4 * xi * xi;
let asymptotic = [
    1.0,
    core::f64::consts::FRAC_PI_2,
    winsorized / 0.36,
    huber_variance,
];
let names = [
    "標本平均",
    "中央値（型 7）",
    "20% トリム平均",
    "Huber（c = 1.345）",
];
let r = REPLICATES as f64;
let rows: Vec<_> = (0..4)
    .map(|j| {
        let bias = sums[j] / r;
        let variance = (squares[j] / r - bias * bias) * r / (r - 1.0);
        let sd = RealScalar::sqrt(variance);
        let scaled = N as f64 * variance;
        let rmse = RealScalar::sqrt(bias * bias + variance);
        (
            names[j],
            bias,
            sd / RealScalar::sqrt(r),
            sd,
            rmse,
            scaled,
            scaled * RealScalar::sqrt(2.0 / (r - 1.0)),
            asymptotic[j],
        )
    })
    .collect();
let fixed4 = serde_json::json!({ "fractionDigits": 4 });
let fixed3 = serde_json::json!({ "fractionDigits": 3 });
let columns = serde_json::json!([
    { "key": "0", "label": "推定量", "type": "string" },
    { "key": "1", "label": "偏り [-]", "type": "number", "format": fixed4 },
    { "key": "2", "label": "偏りの標準誤差 [-]", "type": "number", "format": fixed4 },
    { "key": "3", "label": "標準偏差 [-]", "type": "number", "format": fixed4 },
    { "key": "4", "label": "RMSE [-]", "type": "number", "format": fixed4 },
    { "key": "5", "label": "n × 分散 [-]", "type": "number", "format": fixed3 },
    { "key": "6", "label": "n × 分散の標準誤差 [-]", "type": "number", "format": fixed3 },
    { "key": "7", "label": "漸近分散（k = 0） [-]", "type": "number", "format": fixed3 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "contamination" })
);
emit_text!(format!(
    "Huber の反復が上限で止まった標本: {not_converged} / {REPLICATES}"
));
```

汚染のない $k = 0$（シード 31）では、$n$ 倍した分散は標本平均 1.035、中央値 1.513、トリム平均 1.187、Huber 1.112 で、漸近分散 1、1.571、1.145、1.053 と標準誤差（0.03〜0.05）の 2 倍以内で一致する。
正規分布では標本平均が最も効率がよく、Huber、トリム平均、中央値の順に分散が大きい。
四つとも偏りは標準誤差の範囲で 0 である。

既定の $k = 2$、$\delta = 8$（10% の汚染）では、標本平均の偏りは $k\delta/n = 0.8$ のとおり 0.80 になり、RMSE 0.83 の大半を占める。
中央値の偏りは 0.14、トリム平均は 0.16、Huber は 0.19 で、RMSE は 0.30〜0.32 にとどまる。
$\delta$ を 20 に上げても、この三つの偏りと RMSE はほとんど変わらないが、標本平均の偏りは 2.0 に増える。
$k = 8$（40% の汚染）では、20% トリム平均は両端から 4 個ずつしか除かないので外れ値が 4 個残り、偏りは 2.77 になる。
Huber の偏りも 2.47 まで増え、中央値（0.95）だけが比較的小さい。
崩壊点は外れ値を無限大に動かしたときの限界を表すので、有限の $\delta$ での偏りは、汚染の割合と外れ値の位置の両方で決まる。
どの条件でも、Huber の反復が上限で止まった標本はなかった。

## シグマクリッピングの反復とマスキング

$N(10, 1)$ から引いた 30 個の観測に、外れ値 16、17.5、25 を加えた 33 個の標本をシグマクリッピングにかける。
大きな外れ値 25 は最初の回の $s$ を大きくし、16 と 17.5 を範囲の内側に隠す。
次のセルは、反復の上限を 1 回から選んだ回数まで増やして `sigma_clip_into` を呼び、各回の後の境界と残った数を表にする。
終了状態はセルの結論なので、選んだ上限での `SigmaClipResult::termination()` を outcome で示す。

```rust
//| id: stats-sigma-clip-passes
//| ref: stats-sigma-clip-passes
//| title: 反復の上限を変えてシグマクリッピングの境界と残る観測を追う
//| run: reactive
//| crates: [scioxide-stats, scioxide-random, scioxide-core]
//| inputs:
//|   clip_multiplier: {"type":"range","label":"クリッピングの倍率 c [-]","description":"下側と上側の両方に使う倍率 c（境界 x̄ ± c s）。","min":1.5,"max":4,"step":0.1,"value":2.5}
//|   max_passes: {"type":"range","label":"反復の上限 [回]","description":"sigma_clip_into に渡す反復の上限。","min":1,"max":10,"step":1,"value":5}
//|   sampling_seed: {"type":"integer","label":"乱数のシード","min":0,"max":100000,"value":5}
//| cases:
//|   - {"id":"one-pass","label":"上限 1 回","description":"最初の回では 25 だけが除かれ、上限で止まる。","inputs":{"max_passes":1}}
//|   - {"id":"loose","label":"c = 4","description":"境界が広く、マスキングされた外れ値が残る。","inputs":{"clip_multiplier":4}}
//|   - {"id":"tight","label":"c = 1.5","description":"境界が狭すぎ、正常な観測も削られ続ける。","inputs":{"clip_multiplier":1.5,"max_passes":10}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"passes","path":"/rows/0/2","equals":32}
//|       - {"artifact":"passes","path":"/rows/0/3","equals":2}
//|       - {"artifact":"passes","path":"/rows/1/3","equals":0}
//|       - {"artifact":"passes","path":"/rows/2/6","equals":"Converged"}
//|       - {"path":"/outputs/1/state","equals":"satisfied"}
//|   - case: one-pass
//|     expect:
//|       - {"path":"/outputs/1/state","equals":"partial"}
//|       - {"artifact":"passes","path":"/rows/0/6","equals":"BudgetExhausted"}
//|   - case: loose
//|     expect:
//|       - {"artifact":"passes","path":"/rows/4/3","equals":2}
//|       - {"path":"/outputs/1/state","equals":"satisfied"}
//|   - case: tight
//|     expect:
//|       - {"artifact":"passes","path":"/rows/9/2","equals":18}
use scioxide_core::ExecutionContext;
use scioxide_random::{Distribution, Normal, SeedableRng, SplitMix64};
use scioxide_stats::{SigmaClipOptions, StatisticsOptions, StatisticsWorkspace, sigma_clip_into};

let law = Normal::new(10.0_f64, 1.0).map_err(|e| e.to_string())?;
let mut rng = SplitMix64::from_seed(sampling_seed as u64);
let mut values = Vec::with_capacity(33);
for _ in 0..30 {
    values.push(law.sample(&mut rng).map_err(|e| e.to_string())?);
}
values.extend_from_slice(&[16.0, 17.5, 25.0]);
let n = values.len();
let mut workspace = StatisticsWorkspace::default();
let requirements = StatisticsWorkspace::scalar_requirements(n, StatisticsOptions::new())
    .map_err(|e| e.to_string())?;
workspace
    .try_reserve(&requirements)
    .map_err(|e| e.to_string())?;
let (mut output, mut indices) = (vec![0.0_f64; n], vec![0_usize; n]);
let mut rows = Vec::new();
let mut last = None;
for passes in 1..=max_passes as usize {
    let options = SigmaClipOptions::new().with_max_iterations(passes);
    let result = sigma_clip_into(
        &values,
        clip_multiplier,
        clip_multiplier,
        options,
        &mut output,
        &mut indices,
        &mut workspace,
        ExecutionContext::sequential(),
    )
    .map_err(|e| e.to_string())?;
    // 残った観測に外れ値（添字 30, 31, 32）がいくつあるか。
    let outliers_left = indices[..result.retained()]
        .iter()
        .filter(|&&i| i >= 30)
        .count();
    rows.push((
        passes as u32,
        result.iterations() as u32,
        result.retained() as u32,
        outliers_left as u32,
        result.lower(),
        result.upper(),
        format!("{:?}", result.termination()),
    ));
    last = Some(result);
}
let fixed3 = serde_json::json!({ "fractionDigits": 3 });
let columns = serde_json::json!([
    { "key": "0", "label": "上限 [回]", "type": "integer" },
    { "key": "1", "label": "完了した回数", "type": "integer" },
    { "key": "2", "label": "残った数", "type": "integer" },
    { "key": "3", "label": "残った外れ値の数", "type": "integer" },
    { "key": "4", "label": "下側の境界 [-]", "type": "number", "format": fixed3, "nullText": "—" },
    { "key": "5", "label": "上側の境界 [-]", "type": "number", "format": fixed3, "nullText": "—" },
    { "key": "6", "label": "終了状態", "type": "string" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "passes" })
);
let result = last.ok_or("反復の上限が 0")?;
let outcome = if result.termination().is_success() {
    Outcome::satisfied("最後の回で除く観測がなくなり、クリッピングが収束した")
} else {
    Outcome::partial("除く観測が残ったまま反復の上限で止まった。最後の回の結果は使える")
};
emit_outcome!(
    outcome
        .status(format!("{:?}", result.termination()))
        .diagnostic("完了した回数", result.iterations() as f64, None)
        .diagnostic("残った数", result.retained() as f64, None)
);
```

既定の $c = 2.5$（シード 5）では、1 回目の境界は $[2.74, 18.66]$ で、25 だけが除かれ、16 と 17.5 は残る。
25 が平均と標準偏差を引き上げ、他の二つの外れ値を範囲の内側に隠したのである。
2 回目は境界が $[5.34, 15.16]$ に縮み、16 と 17.5 も除かれて 30 個の正常な観測が残る。
3 回目は何も除かないので `Converged` で止まり、そのときの境界は $[7.22, 12.41]$ である。
上限を 1 回にすると、除く観測が残ったまま `BudgetExhausted` で止まり、outcome は partial になる。

$c = 4$ では 2 回目の境界 $[2.39, 18.11]$ に 16 と 17.5 が収まり、二つの外れ値を残したまま収束する。
$c = 1.5$ では外れ値を除いたあとも正常な観測が削られ続け、6 回目に 18 個で収束する。
正規分布では 1 回の範囲 $\pm 1.5 s$ の外に約 13% の観測があり、除くたびに $s$ が小さくなるからである。
倍率が小さすぎると正常な観測を失い、大きすぎるとマスキングされた外れ値を残すので、倍率は 2.5〜3 程度を選び、残った数と境界を確かめる。

## まとめ

標本平均の崩壊点は $1/n$ で、1 個の観測が推定値をいくらでも動かせる。
トリム平均は両端を割合 $\alpha$ で除いて崩壊点を約 $\alpha$ に上げ、中央値は約 1/2 に上げるが、正規分布では効率を失う。
Huber の推定量は観測を捨てずに影響を $\pm c$ で頭打ちにし、$c = 1.345$ で正規分布での効率 95% と崩壊点約 1/2 を両立する。
`huber_location_with_options` の終了状態と、汚染を混ぜた実験の偏り・RMSE を合わせて、推定量を選ぶ。
多変量の散布には `PreparedHuberScatter`、外れ値の除去には反復するシグマクリッピング、局所的な要約には `RollingWindow` の移動ウインドウを使うが、どれも崩壊点の高い多変量推定量の代わりにはならない。
