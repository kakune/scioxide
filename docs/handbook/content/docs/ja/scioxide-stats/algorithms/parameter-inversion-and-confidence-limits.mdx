分布の裾確率 $P_\theta(X \le x)$ は、$x$ の関数としてだけでなく、母数 $\theta$ の関数としても使う。
「観測した件数がこれ以下になる確率が 2.5% になる率はいくつか」「不良を 95% の確率で見つけるには何個検査すればよいか」という問いは、どちらも裾確率を母数について解く方程式である。
このページではまずこの逆算を連続の母数と整数の母数について定式化し、解の一意性を決める単調性と、解がない場合や決まらない場合の扱いを説明する。
次に、逆算を使って検定を反転し、二項の成功確率（Clopper–Pearson）、Poisson の率（Garwood）、正規分布の分散、非心分布の非心度の信頼限界を求める。
離散分布では「正確な」限界が保守的になることを、被覆確率を厳密に計算して確かめる。
分布の母数を標本に当てはめて点推定と漸近的な標準誤差を求める方法は[分布の当てはめと観測情報行列](../distribution-fitting-and-confidence-limits/)で扱う。
呼び出しの形（ワンショット関数、オプション付き形式、スコープ付き API）の定義は[呼び出しの形](oxref:stats-execution-forms)にある。

## 確率による母数の逆算

分布の裾確率は分布の母数の関数としても見られる。
「$P(X \le x) = p$ となる母数はいくつか」という問いは、分位点の逆問題（$x$ を求める）とは別の、母数についての方程式である。
検定の反転による信頼限界、検出力が目標に届く標本数、指定した確率を与える自由度などが、この形の方程式になる。

### 連続の母数

関数 $g(\theta) = \ln P_\theta(\text{裾})$ と目標 $p$ について、有限の区間 $[\theta_a, \theta_b]$ で

$$
g(\theta) = \ln p
$$

を解く。
目標は `ParameterProbability` で表し、`new(p, side)` は $p \in (0, 1)$ を、`from_log(ln_p, side)` は負の有限の対数を受け取る。
対数で保持するので、$10^{-300}$ より小さい裾確率も目標にできる。
`side` は `TailSide` で、`Lower` が下側の裾 $P(X \le x)$、`Upper` が上側の裾 $P(X > x)$ を表す。

解の一意性は $g$ の単調性で決まる。
`ParameterMonotonicity` は区間全体での $g$ の向き（`Increasing`、`Decreasing`、`Constant`、`Unknown`）を宣言する型で、ソルバーはこの宣言を信じ、端点でだけ矛盾を調べる。
宣言は解析的に示したものでなければならず、試し評価から推定してはいけない。

`invert_parameter_scoped(log_tail, bracket, target, monotonicity, options, scope)` は次のように進む。

1. `Unknown` なら $g$ を評価せずに `Inconclusive` を返す。
2. 両端で $g$ を評価する。
   `Constant` なら、両端の値が違えば `InvalidInput`、目標に等しければ区間全体 `Multiple(interval)`、そうでなければ `NoSolution` を返す。
3. 両端の値が等しければ `Inconclusive`、端点の大小が宣言と逆なら `InvalidInput`、目標が両端の値の外なら `NoSolution` を返す。
4. $g(\theta) - \ln p$ の符号だけを厳密に比べる二分法で区間を縮める。
5. 収束したら、解と最終区間の両端で $g$ を評価し、対数の残差 $g(\hat\theta) - \ln p$ と区間での差分商（傾き）を求める。

二分法は符号しか使わないので、裾確率が 0 に丸められて $g = -\infty$ になる点でも進められる。
二分法の停止は `scioxide-random` の `InversionOptions` の根の設定（区間幅の許容誤差、既定は絶対・相対とも $\varepsilon$、反復の上限 4096）に従い、評価の総数は `InversionOptions::work_budget`（既定 65,536）で制限される。
この計算回数の上限は $g$ の呼び出しの回数を数え、$g$ の内部の反復は数えない。
F 分布や非心分布の裾のように内部で反復を使う評価の上限は、名前の付いた母数では `LawOptions` で別に決める（次の節）。

結果の `ParameterInversionReport` は、解の集合 `solution()`、二分法の結果 `root()`（`scioxide-rootfind` の `RootResult`、二分法を使わずに決まれば `None`）、裾の評価回数 `evaluations()` を持つ。
解の集合 `ParameterSolution` は次の四つである。

- `Unique { value, bracket, log_residual, log_tail_slope }`：一意の解、または二分法が途中で止まったときの最良の近似。
  `bracket` は最終の区間だが、裾の丸め誤差で真の解がその外に出ることがあり、保証付きの包含区間ではない。
  `log_residual` と `log_tail_slope` は二分法が収束したときだけ `Some` で、傾きは 0 か非有限なら `None` になる。
- `Multiple(interval)`：裾が一定で目標に等しく、区間のすべての母数が解である。
- `NoSolution`：目標が区間での裾の値域の外にある。
- `Inconclusive`：単調性が `Unknown` か、両端の裾の値が等しい。

`Unique` でも、`root()` の終了状態が成功でなければ収束していない近似である。
残差と傾きから $|\hat\theta - \theta^*| \approx |\text{残差}/\text{傾き}|$ と誤差の大きさを見積もれるが、最終区間の幅が丸めの水準まで縮むと差分商そのものが丸め誤差に支配されるので、桁の目安にとどめる。

エラーは、区間の端が無限大、$g$ が NaN か正の値を返す、端点の値が単調性の宣言と矛盾する場合の `InvalidInput`、端点か最後の評価で計算回数の上限に達した場合の `ConvergenceFailure`（`EvaluationLimit`）、二分法の開始前の取り消しや期限による `ExecutionStopped` である。
二分法の途中で計算回数の上限に達するか取り消されると、エラーではなく、最後の区間と成功条件を満たしていない終了状態を持つ `Unique` を返す。

呼び出しの形は次の三つである。
ワンショット関数 `invert_parameter(log_tail, lower, upper, target, monotonicity)` は区間を二つの数で受け取り、既定の `InversionOptions` を使い、二分法が収束しなければ `ConvergenceFailure` を返す。
オプション付き形式 `invert_parameter_with_options(log_tail, bracket, target, monotonicity, options)` は `Interval` と `InversionOptions` を受け取り、収束前に停止した二分法もレポートで返す。
スコープ付き API `invert_parameter_scoped(…, options, scope)` は最後に実行コンテキストか親の `SolveContext` を受け取り、評価を親の計算回数の上限に数える。

### 名前の付いた分布の母数

よく使う分布の母数は `ProbabilityParameter` で名前を付けて表せる。
各列挙子は未知の母数を一つ選び、他の母数と評価点を固定する。
`log_tail(parameter, side, resources)` は裾の対数を返し、`resources`（`scioxide-random` の `LawOptions`）は F 分布と非心分布の評価の上限を決める。
`monotonicity(side)` は、下の表の向きを、選んだ裾について返す（上側の裾は逆向き）。
評価点が台の外（ガンマ分布の $x \le 0$ など）なら裾は一定なので `Constant` を返す。

| 列挙子 | 未知の母数 | 下側の裾 $P(X \le x)$ の向き |
|---|---|---|
| `GammaShape { x, scale }` | ガンマ分布の形状 | $x > 0$ で減少 |
| `GammaScale { x, shape }` | ガンマ分布の尺度 | $x > 0$ で減少 |
| `GammaRate { x, shape }` | ガンマ分布の率（尺度の逆数） | $x > 0$ で増加 |
| `BetaAlpha { x, beta }` | ベータ分布の第 1 形状 $\alpha$ | $0 < x < 1$ で減少 |
| `BetaBeta { x, alpha }` | ベータ分布の第 2 形状 $\beta$ | $0 < x < 1$ で増加 |
| `ChiSquaredDegrees { x }` | $\chi^2$ 分布の自由度 | $x > 0$ で減少 |
| `StudentTDegrees { x }` | t 分布の自由度 | $x > 0$ で増加、$x < 0$ で減少、$x = 0$ で一定 |
| `FNumeratorDegrees { x, denominator }` | F 分布の分子の自由度 | 分母の自由度が 2 のとき減少、ほかは `Unknown` |
| `FDenominatorDegrees { x, numerator }` | F 分布の分母の自由度 | 分子の自由度が 2 のとき増加、ほかは `Unknown` |
| `ChiSquaredNoncentrality { x, degrees }` | 非心 $\chi^2$ の非心度 $\lambda \ge 0$ | $x > 0$ で減少 |
| `FNoncentrality { x, numerator, denominator }` | 非心 F の非心度 | $x > 0$ で減少 |
| `StudentTNoncentrality { x, degrees }` | 非心 t の非心度 $\delta \in \mathbb{R}$ | 減少 |
| `BinomialProbability { count, trials }` | 二項分布の成功確率 | `count < trials` で減少 |
| `PoissonMean { count }` | Poisson 分布の平均（単位暴露量あたりの率ではない） | 減少 |

F 分布の自由度は、相手の自由度が 2 のときだけ単調性が証明されているので、ほかの場合は `Unknown` で解は `Inconclusive` になる。
自分の区間で単調性を示せるなら、`invert_parameter_scoped` に向きを渡して解く。

`ParameterInversionRequest { model, bracket, target, options, tail_options }` は、名前の付いた方程式を一つにまとめた要求である。
`solve()` は逐次に、`solve_scoped(scope)` は渡したコンテキストで `invert_parameter_scoped` を呼び、単調性は `model.monotonicity` から取る。
区間が有限でないか、母数の定義域（非心 t 以外は負の値を含まない、形状・尺度・率・自由度は 0 を含まない、二項の確率は 1 を超えない）をはみ出すと `InvalidInput` を返す。
隠れた区間の探索はせず、`bracket` の中だけを探す。
`invert_parameters_into(requests, execution, output, staging, context)` は独立な要求を並列に解き、`output[i]` にレポートを書く。
各要求は自分の評価の上限を持ち、解なしや区間解、`Inconclusive` は正常なレポートとして返るが、二分法が収束しなかった要求があると `ConvergenceFailure`（`EvaluationLimit`）になる。
`output` と `staging` の長さが要求の数と合わなければ `InvalidInput` である。

### 整数の母数

試行回数のような整数の母数 $n$ では、等号が成り立つとは限らないので、不等式を満たす最小の整数を探す。
増加する裾なら $g(n) \ge \ln p$、減少する裾なら $g(n) \le \ln p$ を満たす最小の $n$ を、整数の区間 `domain.0..=domain.1` で求める。
裾は弱い単調性（平らな部分を含む）でよい。
両端を評価してから二分するので、評価は高々 $\lceil \log_2(\text{区間の整数の数}) \rceil + 2$ 回である。

結果の `IntegerParameterReport` は、公開フィールドの解 `solution` と評価回数 `evaluations` を持つ。
解 `IntegerParameterSolution` は、最小の整数とその一つ前（区間の中にあれば）を持つ `Threshold { first, previous }`、区間のすべてが満たす `All { lower, upper }`、どれも満たさない `None`、単調性が分からない `Inconclusive` である。
呼び出しの形は、ワンショット関数 `invert_integer_parameter(log_tail, domain, target, monotonicity)`、`InversionOptions` を受け取るオプション付き形式 `invert_integer_parameter_with_options`、スコープ付き API `invert_integer_parameter_scoped` である。
連続の場合と違い、`InversionOptions` の根の設定は使わず、評価の上限だけを使う。
区間が逆順なら `InvalidInput`、計算回数の上限に達すると `ConvergenceFailure`（`EvaluationLimit`）になる。

名前の付いた整数の母数は `IntegerProbabilityParameter` で表す。
`BinomialTrials { count, probability }` は二項分布の試行回数、`NegativeBinomialShape { count, probability }` は $r$ 回目の成功までの失敗の数の分布の $r$ である。
どちらも下側の裾 $P(X \le \mathrm{count})$ は整数の母数が増えると減少するので、下側の目標では $P(X \le \mathrm{count}) \le p$、上側の目標では $P(X > \mathrm{count}) \ge p$ を満たす最小の母数を求める。
例えば、不良率 $q$ の工程で「少なくとも 1 個の不良を確率 $1-\beta$ 以上で見つける」のに必要な検査数は、`BinomialTrials { count: 0, probability: q }` と下側の目標 $\beta$ で求まり、閉形式 $\lceil \ln\beta / \ln(1-q) \rceil$ と一致する。
メソッドは `solve(domain, target)`（既定の `InversionOptions`）、`solve_with_options(domain, target, options)`、`solve_scoped(domain, target, options, scope)` である。
確率が $[0, 1]$ の外なら `InvalidInput`、負の二項では確率 0、`domain.0 = 0`、または $2/\varepsilon$（f64 で $2^{53}$）を超える `domain.1` も `InvalidInput` である。
`IntegerParameterInversionRequest { model, domain, target, options }` と `invert_integer_parameters_into` は、独立な整数の要求を並列に解く。

### 逆算の例と閉形式

次のセルは逆算の関数を直接使い、閉形式と比べる。
1 行目は `ParameterInversionRequest` で `PoissonMean { count: k }` の方程式 $P(X \le k; \mu) = (1-c)/2$ を区間 $[0, 1000]$ で解く。
この解は $\chi^2$ 分布の分位点を使う閉形式 $\mu = \chi^2_{(1+c)/2}(2k+2)/2$ に等しく（下の Garwood の上限に暴露量を掛けたもの）、傾きの参照値は $\frac{d}{d\mu}\ln P(X \le k;\mu) = -P(X = k;\mu)/P(X \le k;\mu)$ である。
2 行目は `IntegerProbabilityParameter::BinomialTrials` で、不良率 1% の工程から少なくとも 1 個の不良を確率 $c$ 以上で見つけるのに必要な検査数を、整数の区間 $[1, 10^6]$ で求め、$\lceil \ln(1-c)/\ln 0.99 \rceil$ と比べる。
表にはレポートの対数の残差、傾き、評価回数、終了状態を示す。

```rust
//| id: stats-parameter-inversion-checks
//| ref: stats-parameter-inversion-checks
//| title: Poisson の平均と必要な検査数を逆算し、閉形式と比べる
//| run: reactive
//| crates: [scioxide-core, scioxide-random, scioxide-stats]
//| inputs:
//|   k: {"type":"range","label":"故障の件数 k [件]","min":0,"max":20,"step":1,"value":3}
//|   conf: {"type":"range","label":"確率 c [-]","min":0.8,"max":0.99,"step":0.01,"value":0.95}
//| cases:
//|   - {"id":"zero","label":"k = 0","description":"P(X ≤ 0; μ) = e^(−μ) なので、傾きが参照値 −1 に一致する。","inputs":{"k":0}}
//|   - {"id":"high","label":"c = 0.99","description":"解が大きくなり、必要な検査数が増える。","inputs":{"conf":0.99}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"inversion","path":"/rows/0/1","approx":{"value":8.767273069742,"rtol":1e-12}}
//|       - {"artifact":"inversion","path":"/rows/0/2","approx":{"value":8.767273069742,"rtol":1e-12}}
//|       - {"artifact":"inversion","path":"/rows/0/3","range":{"min":-1e-14,"max":1e-14}}
//|       - {"artifact":"inversion","path":"/rows/1/1","equals":299}
//|       - {"artifact":"inversion","path":"/rows/1/2","equals":299}
//|       - {"artifact":"inversion","path":"/rows/1/6","range":{"max":22}}
//|   - case: zero
//|     expect:
//|       - {"artifact":"inversion","path":"/rows/0/1","approx":{"value":3.688879454114,"rtol":1e-12}}
//|       - {"artifact":"inversion","path":"/rows/0/5","approx":{"value":-1,"rtol":1e-12}}
//|   - case: high
//|     expect:
//|       - {"artifact":"inversion","path":"/rows/0/1","approx":{"value":10.97747749533,"rtol":1e-12}}
//|       - {"artifact":"inversion","path":"/rows/1/1","equals":459}
use scioxide_core::{Interval, RealScalar};
use scioxide_random::{ChiSquared, LogCdf, LogMass, Poisson, Quantile};
use scioxide_stats::{
    IntegerParameterSolution, IntegerProbabilityParameter, ParameterInversionRequest,
    ParameterProbability, ParameterSolution, ProbabilityParameter, TailSide,
};

let count = k as usize;
let half_alpha = (1.0 - conf) / 2.0;
// Poisson の平均 μ について P(X ≤ k; μ) = (1 − c)/2 を区間 [0, 1000] で解く
let request = ParameterInversionRequest {
    model: ProbabilityParameter::PoissonMean { count },
    bracket: Interval::new(0.0, 1000.0).map_err(|e| e.to_string())?,
    target: ParameterProbability::new(half_alpha, TailSide::Lower)
        .map_err(|e| e.to_string())?,
    options: Default::default(),
    tail_options: Default::default(),
};
let report = request.solve().map_err(|e| e.to_string())?;
let ParameterSolution::Unique {
    value,
    log_residual,
    log_tail_slope,
    ..
} = report.solution()
else {
    return Err(format!("一意の解がない: {:?}", report.solution()));
};
let root = report.root().ok_or("二分法の結果がない")?;
// 閉形式：χ² 分布の分位点と、ln P(X ≤ k; μ) の導関数 −P(X = k)/P(X ≤ k)
let chi = ChiSquared::new(2.0 * k + 2.0).map_err(|e| e.to_string())?;
let closed_mean = chi.quantile(1.0 - half_alpha).map_err(|e| e.to_string())? / 2.0;
let at = Poisson::new(value).map_err(|e| e.to_string())?;
let log_mass = at.log_pmf(count).map_err(|e| e.to_string())?;
let log_tail = at.log_cdf(count).map_err(|e| e.to_string())?;
let reference_slope = -RealScalar::exp(log_mass - log_tail);
// 少なくとも 1 個の不良を確率 c 以上で見つける検査数：P(X ≤ 0) ≤ 1 − c の最小の n
let defect = 0.01;
let target =
    ParameterProbability::new(1.0 - conf, TailSide::Lower).map_err(|e| e.to_string())?;
let model = IntegerProbabilityParameter::BinomialTrials {
    count: 0,
    probability: defect,
};
let trials = model
    .solve((1, 1_000_000), target)
    .map_err(|e| e.to_string())?;
let IntegerParameterSolution::Threshold { first, .. } = trials.solution else {
    return Err(format!("しきい値がない: {:?}", trials.solution));
};
let closed_trials = RealScalar::ceil(RealScalar::ln(1.0 - conf) / RealScalar::ln_1p(-defect));
let status = format!("{:?}", root.termination());
let rows = vec![
    (
        "Poisson の平均 μ",
        value,
        closed_mean,
        log_residual,
        log_tail_slope,
        Some(reference_slope),
        report.evaluations(),
        status,
    ),
    (
        "必要な検査数 n",
        first as f64,
        closed_trials,
        None,
        None,
        None,
        trials.evaluations,
        "Threshold".to_string(),
    ),
];
let sci6 = serde_json::json!({ "notation": "scientific", "significantDigits": 6 });
let columns = serde_json::json!([
    { "key": "0", "label": "未知の母数" },
    { "key": "1", "label": "解", "type": "number", "format": sci6 },
    { "key": "2", "label": "閉形式", "type": "number", "format": sci6 },
    { "key": "3", "label": "対数の残差", "type": "number", "format": sci6, "nullText": "－" },
    { "key": "4", "label": "傾き", "type": "number", "format": sci6, "nullText": "－" },
    { "key": "5", "label": "傾きの参照値", "type": "number", "format": sci6, "nullText": "－" },
    { "key": "6", "label": "評価回数", "type": "integer" },
    { "key": "7", "label": "終了状態" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "inversion" })
);
```

既定（$k = 3$、$c = 0.95$）では、Poisson の平均の解 8.76727 が閉形式と 13 桁以上一致し、対数の残差は $8.9 \times 10^{-16}$ である。
一方、傾き $-0.75$ は参照値 $-0.6997$ と 7% 違う。
最終区間の幅が $2 \times 10^{-15}$ まで縮み、両端の裾の対数の差が丸めの単位程度しかないので、差分商が丸め誤差に支配されるからである。
レポートの傾きは誤差の桁の目安としてだけ使う。
必要な検査数は 299 で閉形式と一致し、評価は 22 回で上限 $\lceil\log_2 10^6\rceil + 2 = 22$ に収まる。
「k = 0」では $P(X \le 0;\mu) = e^{-\mu}$ なので解は $-\ln 0.025 = 3.68888$ で、傾きは参照値 $-1$ にちょうど一致する。
「c = 0.99」では解が 10.9775 に、必要な検査数が 459 に増える。

## 母数反転信頼限界の計算

### 検定の反転

信頼集合は帰無仮説 $H_0: \theta = \theta_0$ の水準 $\alpha$ の検定を各 $\theta_0$ で行い、棄却されない $\theta_0$ を集めたものとして作れる（Casella–Berger §9.2）。
検定がどの $\theta_0$ でも第 1 種の誤りの確率を $\alpha$ 以下に保つなら、こうして作った集合は真の $\theta$ を確率 $1-\alpha$ 以上で含む。

統計量 $T$ の分布関数 $F(t;\theta)$ が $\theta$ について単調に減少する場合（$\theta$ が大きいほど $T$ が大きくなりやすい場合）、観測値 $t$ に対する両側の信頼集合 $[\theta_L, \theta_U]$ の端点は、確率 $\alpha/2$ ずつを裾に置く方程式

$$
P_{\theta_L}(T \ge t) = \frac{\alpha}{2}, \qquad P_{\theta_U}(T \le t) = \frac{\alpha}{2}
$$

の解である。
信頼係数を $c = 1 - \alpha$ と書くと、`TestAlternative::TwoSided` は各裾に $(1-c)/2$ を置く。
`Greater` は下側の信頼限界だけを求め、集合は母数の定義域の上端まで延びる。
`Less` は上側の信頼限界だけを求め、集合は下端まで延びる。
片側では裾の確率は $1-c$ である。

連続の統計量では方程式の解で被覆確率がちょうど $c$ になるが、二項や Poisson のような離散の統計量では $P_\theta(T \ge t)$ が $t$ について飛び飛びの値しか取らない。
そのため、正確な（exact）限界と呼ばれる検定の反転による区間は、被覆確率がどの $\theta$ でも $c$ 以上になる代わりに、多くの $\theta$ で $c$ を上回る保守的な区間になる。
ここでの「正確」は近似を使わずに標本の分布から作るという意味で、被覆確率がちょうど $c$ という意味ではない。

### 信頼限界の関数

結果の `ParameterConfidenceLimits` は、信頼集合 `set()`（`scioxide-core` の `ExtendedInterval`。
端点を含み、空や非有界もありうる）、名目の信頼係数 `confidence()`、反転した検定の対立仮説 `alternative()`、両端点の裾の評価回数の合計 `evaluations()`、端点ごとの逆算のレポート `lower_report()` と `upper_report()` を持つ。
端点が定義域の端（例えば成功 0 回の下限 0）であるか集合が空なら、その端点のレポートは `None` である。
被覆確率は仮定した標本抽出の分布のもとでの名目値である。

一般の関数は統計量の分布関数の対数 `log_cdf(θ)` $= \ln F(t;\theta)$ を受け取る。
`log_cdf` は定義域 `domain` で狭義単調でなければならず、その向きを `direction`（`Increasing` か `Decreasing`）で渡す。
探索区間 `bracket` は定義域の端でない限界をすべて含む必要があり、限界が区間の外で定義域の中にあると、境界とみなさずに `InvalidInput` を返す。
端点の方程式が定義域の中に解を持たなければ、限界は定義域の端になるか、集合が空になる。
一意の解が得られないか二分法が収束しない端点は `ConvergenceFailure` である。
評価回数の上限は両端点で共有する。

| 呼び出し | 信頼係数と対立仮説 | 区間の渡し方 |
|---|---|---|
| `invert_confidence_limits(log_cdf, domain, lower, upper, direction)` | 両側 95% | 二つの数 |
| `invert_confidence_limits_with_options(log_cdf, domain, bracket, confidence, alternative, direction, options)` | 指定 | `Interval` |
| `invert_confidence_limits_scoped(…, options, scope)` | 指定 | `Interval`、最後にコンテキスト |

よく使うモデルには専用の関数がある。
どれもワンショット関数は両側 95% と既定の `InversionOptions` を使い、オプション付き形式 `*_with_options` は `ConfidenceProbability`、`TestAlternative`、`InversionOptions` を受け取り、スコープ付き API `*_scoped`（`binomial_confidence_limits_scoped`、`poisson_rate_confidence_limits_scoped`、`normal_variance_confidence_limits_scoped`、`noncentrality_confidence_limits_scoped`）は最後に実行コンテキストを受け取る。

- 二項の成功確率（Clopper–Pearson）：`binomial_confidence_limits(successes, trials)`。
  $X \sim \mathrm{Bin}(n, p)$ で $k$ 回成功したとき、下限は $P(X \ge k; p_L) = \alpha/2$、上限は $P(X \le k; p_U) = \alpha/2$ の解である。
  $k = 0$ の下限は 0、$k = n$ の上限は 1 で、これらは方程式を解かない。
  ベータ分布の分位点を使うと $p_L = B^{-1}(\alpha/2; k, n-k+1)$、$p_U = B^{-1}(1-\alpha/2; k+1, n-k)$ と書ける。
  区間は $[0, 1]$ に固定で、試行 0 か成功が試行を超えると `InvalidInput` である。
- Poisson の率（Garwood）：`poisson_rate_confidence_limits(count, exposure, lower, upper)`。
  暴露量 $E$ の間に $k$ 件起きたとき $X \sim \mathrm{Poisson}(\lambda E)$ として、率 $\lambda$ の限界は $P(X \ge k; \lambda_L E) = \alpha/2$、$P(X \le k; \lambda_U E) = \alpha/2$ の解で、$\chi^2$ 分布の分位点で $\lambda_L = \chi^2_{\alpha/2}(2k)/(2E)$、$\lambda_U = \chi^2_{1-\alpha/2}(2k+2)/(2E)$ と書ける。
  $k = 0$ の下限は 0 である。
  率の探索区間 `[lower, upper]` は限界を含むように呼び出し側が選ぶ。
  暴露量が正の有限値でなければ `InvalidInput` である。
- 正規分布の分散：`normal_variance_confidence_limits(scatter, degrees, lower, upper)`。
  偏差平方和 $Q = \sum (x_i - \bar x)^2$ と自由度 $\nu$（通常 $n-1$）について $Q/\sigma^2 \sim \chi^2(\nu)$ なので、限界は $[Q/\chi^2_{1-\alpha/2}(\nu),\; Q/\chi^2_{\alpha/2}(\nu)]$ である。
  $Q$ が正の有限値でないか、区間の下端が 0 以下なら `InvalidInput` である。
- 非心度：`noncentrality_confidence_limits(model, lower, upper)`。
  `model` は `ProbabilityParameter` の `StudentTNoncentrality`、`ChiSquaredNoncentrality`、`FNoncentrality` のどれかで、観測した統計量と自由度を持つ。
  定義域は非心 t で実数全体、ほかで $[0, \infty)$ である。
  オプション付き形式とスコープ付き API は、各裾の評価の上限を決める `LawOptions` も受け取る。
  効果量の信頼区間（観測した t 値から標準化平均差の区間を作るなど）に使う。

Wilson 区間、Agresti–Coull 区間、mid-p による補正、尤度比による区間など、検定の反転以外の近似区間は、この関数群では提供しない。
被覆確率が平均的に名目値に近い区間が必要なら、下で比べる Jeffreys の事前分布による等裾の信用区間を[共役事前分布とベイズ更新](../bayesian-conjugate-updates/)の `credible_interval` で作れる。

### 離散分布の被覆率

二項の成功確率について、Clopper–Pearson 区間、正規近似の Wald 区間 $\hat p \pm z_{1-\alpha/2}\sqrt{\hat p(1-\hat p)/n}$、Jeffreys の事前分布 $\mathrm{Beta}(1/2, 1/2)$ による等裾の信用区間を比べる。
区間 $C(k)$ の被覆確率は、真の $p$ のもとで

$$
\mathrm{cov}(p) = \sum_{k=0}^{n} \binom{n}{k} p^k (1-p)^{n-k}\, \mathbf{1}\{p \in C(k)\}
$$

で、模擬実験なしに厳密に計算できる（Brown・Cai・DasGupta 2001）。
次のセルは入力の $k$ と $n$ で三つの区間を表に出し、$k = 0, \dots, n$ のすべての区間を作って、$p = 0.005, 0.010, \dots, 0.995$ の被覆確率を描く。
Clopper–Pearson の検算として、ベータ分布の分位点 $B^{-1}(\alpha/2; k, n-k+1)$ と $B^{-1}(1-\alpha/2; k+1, n-k)$ を `scioxide-random` の `Beta::quantile` で独立に求めて並べる。
Wald の区間は $[0, 1]$ に切り詰めずに示す。

```rust
//| id: stats-confidence-inversion
//| ref: stats-confidence-inversion
//| title: 二項の成功確率の Clopper–Pearson 限界と被覆確率を Wald・Jeffreys と比べる
//| run: reactive
//| crates: [scioxide-core, scioxide-random, scioxide-stats]

//|   n: {"type":"range","label":"試行回数 n [回]","min":30,"max":100,"step":1,"value":30}
//|   conf: {"type":"range","label":"信頼係数 c [-]","min":0.8,"max":0.99,"step":0.01,"value":0.95}
//| cases:
//|   - {"id":"zero","label":"k = 0","description":"Clopper–Pearson の下限は 0 で、Wald の区間は幅 0 につぶれる。","inputs":{"k":0}}

//|   - {"id":"large","label":"n = 100、c = 0.9","description":"Wald の被覆の不足は n が大きくても端の p で残る。","inputs":{"n":100,"conf":0.9}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"intervals","path":"/rows/0/1","approx":{"value":0.0993378649580198,"rtol":1e-9}}
//|       - {"artifact":"intervals","path":"/rows/0/4","approx":{"value":0.0993378649580198,"rtol":1e-9}}
//|       - {"artifact":"intervals","path":"/rows/0/2","approx":{"value":0.422836522978220,"rtol":1e-9}}
//|       - {"artifact":"intervals","path":"/rows/2/1","approx":{"value":0.110920907158253,"rtol":1e-9}}
//|       - {"artifact":"coverage","path":"/rows/0/1","range":{"min":0.95}}
//|       - {"artifact":"coverage","path":"/rows/1/2","approx":{"value":0.879254152714465,"rtol":1e-9}}
//|       - {"artifact":"coverage","path":"/rows/2/2","approx":{"value":0.950832660908552,"rtol":1e-9}}
//|   - case: zero
//|     expect:
//|       - {"artifact":"intervals","path":"/rows/0/1","equals":0}
//|       - {"artifact":"intervals","path":"/rows/0/2","approx":{"value":0.115703308222028,"rtol":1e-9}}
//|       - {"artifact":"intervals","path":"/rows/1/3","equals":0}
//|   - case: all
//|     expect:

//|       - {"artifact":"intervals","path":"/rows/0/2","equals":1}
//|   - case: large
//|     expect:
//|       - {"artifact":"coverage","path":"/rows/0/1","range":{"min":0.9}}
//|       - {"artifact":"coverage","path":"/rows/1/1","approx":{"value":0.392556295986216,"rtol":1e-9}}
use scioxide_random::{Beta, Binomial, InversionOptions, Mass, Quantile};
use scioxide_stats::{
    BetaBinomialPrior, ConfidenceProbability, TestAlternative,
    binomial_confidence_limits_with_options, credible_interval,
};

let (k, n) = (k as usize, n as usize);
let c = ConfidenceProbability::new(conf).map_err(|e| e.to_string())?;
let options = InversionOptions::<f64>::default();
let z: f64 = c.normal_critical_value().map_err(|e| e.to_string())?;
// k = 0, …, n のすべての区間（下限, 上限）と、Clopper–Pearson の評価回数
let mut clopper = Vec::with_capacity(n + 1);
let mut wald = Vec::with_capacity(n + 1);
let mut jeffreys = Vec::with_capacity(n + 1);
for j in 0..=n {
    let limits =
        binomial_confidence_limits_with_options(j, n, c, TestAlternative::TwoSided, &options)
            .map_err(|e| e.to_string())?;
    let (lower, upper) = limits.set().bounds().ok_or("信頼集合が空")?;
    let (lower, upper) = (lower.ok_or("下限がない")?, upper.ok_or("上限がない")?);
    clopper.push((lower, upper, limits.evaluations()));
    let p_hat = j as f64 / n as f64;
    let half = z * scioxide_core::RealScalar::sqrt(p_hat * (1.0 - p_hat) / n as f64);
    wald.push((p_hat - half, p_hat + half));
    let posterior = BetaBinomialPrior::new(0.5, 0.5).and_then(|prior| prior.update(j, n));
    let law = posterior
        .and_then(|post| post.posterior_law())
        .map_err(|e| e.to_string())?;
    let bounds = credible_interval(&law, c, &options)
        .map_err(|e| e.to_string())?
        .bounds();
    jeffreys.push((bounds.lower(), bounds.upper()));
}
// 検算：Clopper–Pearson はベータ分布の分位点で書ける（k = 0 と k = n の端は定義域の端）
let half_alpha = (1.0 - conf) / 2.0;
let beta_quantile = |a: f64, b: f64, p: f64| Beta::new(a, b).and_then(|law| law.quantile(p));
let reference_lower = if k == 0 {
    0.0
} else {
    beta_quantile(k as f64, (n - k + 1) as f64, half_alpha).map_err(|e| e.to_string())?
};
let reference_upper = if k == n {
    1.0
} else {
    beta_quantile((k + 1) as f64, (n - k) as f64, 1.0 - half_alpha)
        .map_err(|e| e.to_string())?
};

        cp.1,

        Some(reference_upper),

    ("Jeffreys", jf.0, jf.1, jf.1 - jf.0, None, None, None),
];
let fixed5 = serde_json::json!({ "fractionDigits": 5 });
let columns = serde_json::json!([
    { "key": "0", "label": "区間" },
    { "key": "1", "label": "下限 [-]", "type": "number", "format": fixed5 },
    { "key": "2", "label": "上限 [-]", "type": "number", "format": fixed5 },
    { "key": "3", "label": "幅 [-]", "type": "number", "format": fixed5 },
    { "key": "4", "label": "ベータ分位点の下限 [-]", "type": "number", "format": fixed5, "nullText": "－" },
    { "key": "5", "label": "ベータ分位点の上限 [-]", "type": "number", "format": fixed5, "nullText": "－" },
    { "key": "6", "label": "裾の評価回数", "type": "integer", "nullText": "－" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "intervals" })
);

// 厳密な被覆確率 cov(p) = Σ_k P(X = k; p) 1{p ∈ C(k)}
let mut curves = [Vec::new(), Vec::new(), Vec::new()];
for i in 1..200 {
    let p = i as f64 / 200.0;
    let law = Binomial::new(n, p).map_err(|e| e.to_string())?;
    let mut coverage = [0.0; 3];
    for j in 0..=n {
        let mass = law.pmf(j).map_err(|e| e.to_string())?;

            if lower <= p && p <= upper {
                *sum += mass;
            }
        }
    }
    for (curve, value) in curves.iter_mut().zip(coverage) {
        curve.push([p, value]);
    }
}

    .iter()
    .zip(&curves)
    .map(|(name, curve)| {
        let low = curve.iter().fold(1.0_f64, |m, point| m.min(point[1]));

        (*name, low, mean)
    })
    .collect();
let summary_columns = serde_json::json!([
    { "key": "0", "label": "区間" },
    { "key": "1", "label": "最小の被覆確率 [-]", "type": "number", "format": fixed5 },
    { "key": "2", "label": "p で平均した被覆確率 [-]", "type": "number", "format": fixed5 }

    summary,
    metadata = serde_json::json!({ "id": "coverage" })
);

    .iter()
    .zip(&curves)
    .map(|(name, curve)| serde_json::json!({ "name": name, "points": curve }))
    .collect();
emit_line_chart!(
    &series,
    options = &serde_json::json!({
        "xLabel": "真の成功確率 p [-]",
        "yLabel": "被覆確率 [-]",
```

Wald 区間 $[0.0820, 0.3847]$ と Jeffreys 区間 $[0.1109, 0.4044]$ はどちらも Clopper–Pearson 区間より狭い。
被覆確率の図では、Clopper–Pearson の曲線がどの $p$ でも名目値の線より上にあり、最小値は 0.9538、$p$ で平均した値は 0.9737 である。
Wald 区間の被覆確率は平均 0.879 で、$p$ が 0 や 1 に近いと 0.14 まで下がる。
Jeffreys 区間は平均 0.951 で名目値に近いが、端では 0.889 まで下がり、どの $p$ でも名目値を保証するわけではない。
被覆確率の曲線が鋸歯状になるのは、$p$ を動かすと区間に入る $k$ の集合が飛び飛びに変わるからである。

「k = 0」では Clopper–Pearson の下限が定義域の端 0 になり、逆算するのは上限 0.1157 だけなので、評価回数は 61 回に半減する。
Wald 区間は $\hat p = 0$ で標準誤差が 0 になり、幅 0 の区間 $[0, 0]$ につぶれる。
「k = n = 30」では逆に上限が 1 になる。
「n = 100、c = 0.9」でも Wald 区間の最小の被覆確率は 0.39 で、標本を増やしても端の $p$ での不足は残る。
名目の被覆確率をすべての $p$ で保証したいときは Clopper–Pearson 区間を、平均的な被覆確率と幅のつり合いを重視するときは Jeffreys 区間を選ぶ。
Wald 区間は、$n\hat p(1-\hat p)$ が十分大きい場合の近似としてだけ使う。

### 閉形式との照合

次のセルは Poisson の率、正規分布の分散、非心 t の非心度の両側の限界を求め、閉形式と端点の裾確率で確かめる。
Poisson は暴露量 $E = 1000$ h の間に $k$ 件の故障を観測した場合で、率の探索区間は $[0, 1]$ /h とする。
正規分散は 10 個の測定の偏差平方和 $Q = 12$ mm²（$\nu = 9$）、非心 t は自由度 10 で観測した $t = 2.5$ の場合で、探索区間はそれぞれ $[0.01, 100]$ mm² と $[-10, 10]$ である。
表の「下限での上側確率」は $P_{\theta_L}(T \ge t)$、「上限での下側確率」は $P_{\theta_U}(T \le t)$ で、どちらも $(1-c)/2$ になるはずである。
閉形式の参照値は $\chi^2$ 分布の分位点を `ChiSquared::quantile` で求めたもので、非心 t には閉形式がない。

```rust
//| id: stats-distribution-fitting-and-confidence-limits-api-2
//| ref: stats-distribution-fitting-and-confidence-limits-api-2
//| title: Poisson の率・正規分散・非心度の信頼限界を閉形式と端点の裾確率で確かめる
//| run: reactive
//| crates: [scioxide-core, scioxide-random, scioxide-stats]
//| inputs:
//|   k: {"type":"range","label":"故障の件数 k [件]","min":0,"max":20,"step":1,"value":3}
//|   conf: {"type":"range","label":"信頼係数 c [-]","min":0.8,"max":0.99,"step":0.01,"value":0.95}
//| cases:
//|   - {"id":"zero","label":"k = 0","description":"Poisson の下限は定義域の端 0 になり、方程式を解かない。","inputs":{"k":0}}
//|   - {"id":"high","label":"c = 0.99","description":"どの区間も広がる。","inputs":{"conf":0.99}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"limits","path":"/rows/0/1","approx":{"value":6.186721228956e-4,"rtol":1e-9}}
//|       - {"artifact":"limits","path":"/rows/0/3","approx":{"value":6.186721228956e-4,"rtol":1e-9}}
//|       - {"artifact":"limits","path":"/rows/0/5","approx":{"value":0.025,"rtol":1e-9}}
//|       - {"artifact":"limits","path":"/rows/1/2","approx":{"value":4.443803384692,"rtol":1e-9}}
//|       - {"artifact":"limits","path":"/rows/2/1","approx":{"value":0.2145640243388,"rtol":1e-6}}
//|       - {"artifact":"limits","path":"/rows/2/6","approx":{"value":0.025,"rtol":1e-9}}
//|   - case: zero
//|     expect:
//|       - {"artifact":"limits","path":"/rows/0/1","equals":0}
//|       - {"artifact":"limits","path":"/rows/0/5","equals":null}
//|       - {"artifact":"limits","path":"/rows/0/2","approx":{"value":3.688879454114e-3,"rtol":1e-9}}
//|   - case: high
//|     expect:
//|       - {"artifact":"limits","path":"/rows/1/1","approx":{"value":0.5087041229441,"rtol":1e-9}}
use scioxide_core::Interval;
use scioxide_random::{
    ChiSquared, InversionOptions, LawOptions, LogCdf, LogMass, LogSurvival, NoncentralStudentT,
    Poisson, Quantile,
};
use scioxide_stats::{
    ConfidenceProbability, IntegerParameterSolution, IntegerProbabilityParameter,
    ParameterConfidenceLimits, ParameterInversionRequest, ParameterProbability,
    ParameterSolution, ProbabilityParameter, TailSide, TestAlternative,
    noncentrality_confidence_limits_with_options,
    normal_variance_confidence_limits_with_options,
    poisson_rate_confidence_limits_with_options,
};

let count = k as usize;
let c = ConfidenceProbability::new(conf).map_err(|e| e.to_string())?;
let options = InversionOptions::<f64>::default();
let two_sided = TestAlternative::TwoSided;
let half_alpha = (1.0 - conf) / 2.0;
let (exposure, scatter, nu, t_obs, t_nu) = (1000.0, 12.0, 9.0, 2.5, 10.0);
let interval = |a: f64, b: f64| Interval::new(a, b).map_err(|e| e.to_string());
let poisson = poisson_rate_confidence_limits_with_options(
    count,
    exposure,
    interval(0.0, 1.0)?,
    c,
    two_sided,
    &options,
)
.map_err(|e| e.to_string())?;
let variance = normal_variance_confidence_limits_with_options(
    scatter,
    nu,
    interval(0.01, 100.0)?,
    c,
    two_sided,
    &options,
)
.map_err(|e| e.to_string())?;
let model = ProbabilityParameter::StudentTNoncentrality {
    x: t_obs,
    degrees: t_nu,
};
let law_options = LawOptions::default();
let delta = noncentrality_confidence_limits_with_options(
    model,
    interval(-10.0, 10.0)?,
    c,
    two_sided,
    &options,
    law_options,
)
.map_err(|e| e.to_string())?;
let ends = |limits: &ParameterConfidenceLimits<f64>| -> Result<(f64, f64), String> {
    let (lower, upper) = limits.set().bounds().ok_or("信頼集合が空")?;
    Ok((lower.ok_or("下限がない")?, upper.ok_or("上限がない")?))
};
let ((pl, pu), (vl, vu), (dl, du)) = (ends(&poisson)?, ends(&variance)?, ends(&delta)?);
// 端点の裾確率：下限では上側 P(T ≥ t)、上限では下側 P(T ≤ t)
let poisson_tail = |rate: f64, upper_tail: bool| -> Result<Option<f64>, String> {
    let law = Poisson::new(rate * exposure).map_err(|e| e.to_string())?;
    let value = if upper_tail {
        if count == 0 {
            return Ok(None);
        } // 下限は定義域の端で、方程式を解かない
        law.log_sf(count - 1)
    } else {
        law.log_cdf(count)
    };
    value
        .map(|v| Some(scioxide_core::RealScalar::exp(v)))
        .map_err(|e| e.to_string())
};
let chi = ChiSquared::new(nu).map_err(|e| e.to_string())?;
let chi_cdf = |var: f64| {
    chi.log_cdf(scatter / var)
        .map(scioxide_core::RealScalar::exp)
        .map_err(|e| e.to_string())
};
let nct_cdf = |d: f64| {
    let law =
        NoncentralStudentT::with_options(t_nu, d, law_options).map_err(|e| e.to_string())?;
    law.log_cdf(t_obs)
        .map(scioxide_core::RealScalar::exp)
        .map_err(|e| e.to_string())
};
// 閉形式の参照値（χ² 分布の分位点）
let chi_quantile = |df: f64, p: f64| {
    ChiSquared::new(df)
        .and_then(|law| law.quantile(p))
        .map_err(|e| e.to_string())
};
let garwood_lower = if count == 0 {
    0.0
} else {
    chi_quantile(2.0 * k, half_alpha)? / (2.0 * exposure)
};
let garwood_upper = chi_quantile(2.0 * k + 2.0, 1.0 - half_alpha)? / (2.0 * exposure);
let rows = vec![
    (
        "Poisson の率 [1/h]",
        pl,
        pu,
        Some(garwood_lower),
        Some(garwood_upper),
        poisson_tail(pl, true)?,
        poisson_tail(pu, false)?,
        poisson.evaluations(),
    ),
    (
        "正規分散 [mm²]",
        vl,
        vu,
        Some(scatter / chi_quantile(nu, 1.0 - half_alpha)?),
        Some(scatter / chi_quantile(nu, half_alpha)?),
        Some(1.0 - chi_cdf(vl)?),
        Some(chi_cdf(vu)?),
        variance.evaluations(),
    ),
    (
        "非心 t の非心度 [-]",
        dl,
        du,
        None,
        None,
        Some(1.0 - nct_cdf(dl)?),
        Some(nct_cdf(du)?),
        delta.evaluations(),
    ),
];
let sci6 = serde_json::json!({ "notation": "scientific", "significantDigits": 6 });
let columns = serde_json::json!([
    { "key": "0", "label": "母数" },
    { "key": "1", "label": "下限", "type": "number", "format": sci6 },
    { "key": "2", "label": "上限", "type": "number", "format": sci6 },
    { "key": "3", "label": "閉形式の下限", "type": "number", "format": sci6, "nullText": "閉形式なし" },
    { "key": "4", "label": "閉形式の上限", "type": "number", "format": sci6, "nullText": "閉形式なし" },
    { "key": "5", "label": "下限での上側確率 [-]", "type": "number", "format": sci6, "nullText": "定義域の端" },
    { "key": "6", "label": "上限での下側確率 [-]", "type": "number", "format": sci6 },
    { "key": "7", "label": "裾の評価回数", "type": "integer" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "limits" })
);
```

既定（$k = 3$、$c = 0.95$）では、Poisson の率の限界 $[6.187 \times 10^{-4}, 8.767 \times 10^{-3}]$ /h と正規分散の限界 $[0.6308, 4.4438]$ mm² が、$\chi^2$ 分布の分位点による閉形式と 13 桁以上一致する。
非心度の限界 $[0.2146, 4.6912]$ には閉形式がないが、端点での裾確率はどの行も $(1-c)/2 = 0.025$ に 12 桁以上一致し、方程式を解けていることが分かる。
評価回数は端点一つあたり 60 回前後で、区間を半分にする二分法が $\varepsilon$ の水準の区間幅に達するまで続くためである。
「k = 0」では Poisson の率の下限が定義域の端 0 になり、方程式を解かないので、端点の裾確率の列は空欄で、評価回数は 61 回になる。
上限 $3.689 \times 10^{-3}$ /h は $-\ln 0.025 / 1000$ に等しい。
「c = 0.99」ではどの区間も広がり、正規分散の下限は 0.5087 mm² に下がる。

## まとめ

裾確率を母数について解くには、連続の母数なら `invert_parameter`（計算回数の上限やコンテキストを渡すなら `_with_options`・`_scoped`）、整数の母数なら `invert_integer_parameter` を使い、単調性は解析的に示した向きを `ParameterMonotonicity` で渡す。
名前の付いた分布の母数は `ProbabilityParameter` と `ParameterInversionRequest`、`IntegerProbabilityParameter` で、単調性を自分で示さずに解ける。
結果の `ParameterSolution` が `Unique` でも、`root()` の終了状態が成功でなければ近似にすぎないので、使う前に確かめる。
二項・Poisson・正規分散・非心度の信頼限界は検定の反転で求まり、探索区間は定義域の端でない限界を含むように選ぶ。
離散分布の Clopper–Pearson と Garwood の限界は、どの母数でも名目の被覆確率を下回らない代わりに保守的で、平均的な被覆確率を重視するなら Jeffreys の信用区間を比べる。
