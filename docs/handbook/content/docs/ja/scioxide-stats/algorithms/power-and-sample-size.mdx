実験を計画するときは、想定した大きさの効果が実際にあるなら、それを検定で見つけられる確率を前もって見積もる。
この確率を検出力（statistical power）と呼ぶ。
標本が少なすぎると、効果があっても検定は棄却せず、実験は結論を出せない。
標本が多すぎると、必要以上の計算コストと時間を使う。
このページでは正規母集団の平均の検定について検出力を導出し、`scioxide-stats` の `power` で計算し、`sample_size` で必要な標本数を求める。
最後に、検出力を模擬実験で推定する `simulated_power` で解析値を確かめ、式のない検定へ同じ考え方を広げる。

## 検出力と二種類の誤り

帰無仮説 $H_0$ を棄却するかどうかを決める検定には、二種類の誤りがある。
$H_0$ が正しいのに棄却する誤りを第 1 種の誤り、$H_0$ が誤っているのに棄却しない誤りを第 2 種の誤りと呼ぶ。
有意水準 $\alpha$ は第 1 種の誤りの確率の上限で、第 2 種の誤りの確率を $\beta$ と書く。
検出力は対立仮説のもとで棄却する確率

$$
\pi = 1-\beta = P_{H_1}(\text{棄却})
$$

である。
母数 $\theta$ の関数とみた $\pi(\theta)=P_\theta(\text{棄却})$ を検出力関数と呼び、$H_0$ の上では $\pi(\theta)\le\alpha$ になる。

検出力は、効果の大きさ、観測のばらつき、標本数 $n$、有意水準 $\alpha$、対立仮説の向き（片側か両側か）で決まる。
平均の差 $\Delta$ を標準偏差 $\sigma$ で割った

$$
d = \frac{\Delta}{\sigma}
$$

を標準化効果量（Cohen の $d$）と呼ぶ。
Cohen（1988）は $d=0.2,\ 0.5,\ 0.8$ を小・中・大の目安とした。
ただし、どの大きさの効果を見つけたいかは分野の知識から決めるもので、この目安は代わりにならない。

設計に使う $\Delta$ と $\sigma$ は、先行研究や予備実験から決める想定値である。
得られたデータの推定値を代入して事後に検出力を計算しても、その値は p 値の単調な関数にすぎず、新しい情報を加えない（Hoenig と Heisey 2001）。
有意でなかった結果を解釈するときは、事後の検出力ではなく効果の信頼区間を見る。

## 平均の検定の検出力

観測は互いに独立で、正規分布 $N(\mu,\sigma^2)$ に従うと仮定する。
検定するのは $H_0:\mu-\mu_0=0$ で、1 標本の場合は $\mu_0$ が既知の基準値、2 標本の場合は対照群の平均である。
各群の標本数を $n$ とし、平均（または平均の差）の標準誤差を $\sigma\sqrt{c/n}$ と書く。
1 標本では $c=1$、各群 $n$ 個の独立 2 群では $c=2$ である。
対応のある 2 標本（同じ個体の前後の測定など）は、差 $D_i=X_i-Y_i$ の 1 標本として扱い、$\sigma$ に差の標準偏差を使う。
検定統計量を標準誤差で割ったときの平均のずれ

$$
\delta = \frac{\Delta}{\sigma\sqrt{c/n}} = d\sqrt{\frac{n}{c}}
$$

を非心度（noncentrality）と呼ぶ。
$n$ を 4 倍にすると $\delta$ は 2 倍になる。

### 分散が既知の z 検定

$\sigma$ が既知なら、検定統計量 $Z=(\bar X-\mu_0)/(\sigma\sqrt{c/n})$ は対立仮説のもとで $N(\delta,1)$ に従う。
標準正規分布の分布関数を $\Phi$、上側 $p$ 点を $z_p=\Phi^{-1}(1-p)$ と書くと、上側の片側検定は $Z>z_\alpha$ で棄却し、検出力は

$$
\pi_{\text{上側}} = 1-\Phi(z_\alpha-\delta) = \Phi(\delta-z_\alpha)
$$

になる。
両側検定は $|Z|>z_{\alpha/2}$ で棄却するので、反対側の裾も加えて

$$
\pi_{\text{両側}} = \Phi(-z_{\alpha/2}-\delta) + 1-\Phi(z_{\alpha/2}-\delta)
$$

になる。
$\delta>0$ では第 1 項がすぐに無視できる大きさになるので、$\pi=1-\beta$ を満たす $n$ は近似的に

$$
n \approx \frac{c\,(z_{\alpha/2}+z_\beta)^2}{d^2}
$$

で求まる（片側検定では $z_{\alpha/2}$ を $z_\alpha$ にする）。
$d=0.5$、$\alpha=0.05$（両側）、$\pi=0.8$ の 2 群では $2(1.960+0.842)^2/0.25=62.8$ なので、各群 63 になる。

### 分散を推定する t 検定

$\sigma$ を不偏標本標準偏差 $S$ で置き換えた $T=(\bar X-\mu_0)/(S\sqrt{c/n})$ は、自由度 $\nu$ の非心 t 分布に従う。
非心 t 分布は、独立な $Z\sim N(0,1)$ と自由度 $\nu$ のカイ二乗変数 $W$ から

$$
T = \frac{Z+\delta}{\sqrt{W/\nu}}
$$

で定まる分布である。
自由度は 1 標本で $\nu=n-1$、合併分散を使う 2 群の Student の t 検定で $\nu=2(n-1)$ である。
$H_0$ のもとでは $\delta=0$ で中心 t 分布になるので、棄却の境界は自由度 $\nu$ の t 分布の上側 $\alpha$ 点 $t_{\alpha,\nu}$ である。
上側の片側検定の検出力は非心 t 分布の上側確率

$$
\pi_{\text{上側}} = P(T_{\nu,\delta} > t_{\alpha,\nu})
$$

で、両側検定は $P(T_{\nu,\delta}<-t_{\alpha/2,\nu})+P(T_{\nu,\delta}>t_{\alpha/2,\nu})$ である。
同じ $n$ では、分母の $S$ がばらつくぶん t 検定の検出力は z 検定より小さく、差は $\nu$ が大きくなると縮む。
したがって t 検定の必要数は z 検定の必要数以上になり、z 検定の近似式の $n$ は t 検定の探索の出発点に使える。
正確な値は Lehmann と Romano（2005）、Cohen（1988、第 2 章）の表と一致する。
たとえば $d=0.5$、$\alpha=0.05$（両側）、$\pi=0.8$ の 2 群 t 検定は各群 64 で、z 検定の近似より 1 多い。

これらの式は正規性と独立性を前提にしている。
裾の重い分布や外れ値があると、t 検定の実際の棄却率と検出力は式の値からずれる。
2 群で分散が異なる場合、各群の標本数が等しければ合併分散の t 検定の第 1 種の誤りは名目の水準に近いが、標本数が違うと大きくずれる。
そのような設計の検出力は、下の模擬実験で見積もる。

## 検出力の計算と標本サイズの探索の API

`MeanPowerModel` は検定の設計をまとめた構造体で、次のフィールドを持つ。

- `effect` は $\Delta=\mu-\mu_0$、`standard_deviation` は $\sigma>0$ である。
  $d$ を直接与えるときは $\sigma=1$ にする。
- `design` は `MeanPowerDesign::OneSample`（1 標本または対応のある差、$c=1$）か `MeanPowerDesign::EqualGroups`（各群 $n$ 個の独立 2 群、$c=2$）である。
- `reference` は `MeanPowerReference::KnownVariance`（z 検定）か `MeanPowerReference::EstimatedVariance`（合併分散の t 検定）である。
- `alternative` は棄却域の向きで、`TestAlternative::Greater`、`Less`、`TwoSided` のどれかである。
  両側検定は $\alpha$ を両側に半分ずつ割り当て、両方の裾の確率を足す。
- `significance` は有意水準 $\alpha$ そのものを持つ `ConfidenceProbability` である。
  型の名前は信頼係数と同じだが、ここでは $1-\alpha$ ではなく $\alpha$ を渡す。

`power(model, n)` は上の式で検出力を計算し、`PowerEstimate` を返す。
z 検定は標準正規分布の分位点と分布関数、t 検定は Student の t 分布の分位点と非心 t 分布 `NoncentralStudentT` の上側確率を使う。
非心 t 分布の裾は Benton と Krishnamoorthy（2003）の級数で計算し、桁落ちするときは求積に切り替える（[検定統計量の確率分布](../../../scioxide-random/algorithms/test-statistic-laws/)）。
1 回の呼び出しは分位点 1 個と裾の確率 1〜2 個の評価で、作業領域を確保しない。
正規データに対しては厳密な値で、区間を持たない。
次の場合はエラーを返す。

- $n<2$、$n>2^{53}$、`effect` か `standard_deviation` が有限でない、または $\sigma\le0$ のときは `InvalidInput` を返す。
- $\delta$ が表現できない（あふれる）ときは `NumericalInstability`（`NumericalIssue::Breakdown`）を返す。
- 分布の評価で起きたエラーはそのまま返す。

`PowerEstimate` は解析値と模擬実験の推定値の両方を表す型である。
`probability()` が検出力、`interval()` が模擬実験の Wilson 95% 区間、`replicates()` と `rejections()` が反復回数と棄却数を返す。
解析値では `interval()` が `None`、二つの回数が 0 になる。
自分で計算した検出力は `PowerEstimate::analytic(p)` で包む（$p$ が有限でなければ `NonFinite`、$[0,1]$ の外なら `InvalidInput`）。

`sample_size(minimum, maximum, target, evaluate)` は、`minimum` から 1 ずつ $n$ を増やして `evaluate(n)` を呼び、検出力が `target` に届いた最初の $n$ を返す。
解析値は $\pi\ge$ `target` で、模擬実験の推定値は Wilson 区間の下限が `target` 以上で合格とする。
戻り値は `Option<SampleSizeResult>` で、範囲に合格する $n$ がなければ `None` を返す。
範囲の外のより大きな $n$ なら合格する可能性があるので、`None` は「範囲を広げる」という意味に読む。
`SampleSizeResult` は合格した `size`、その $n$ での `estimate`、評価した $n$ の個数 `evaluated`（`size` を含む）を持つ。
探索は線形なので、呼び出しは最大で `maximum − minimum + 1` 回になる。
上の z 検定の近似式で `minimum` を決めると、t 検定の探索は数回で終わる。
`target` が $(0,1)$ の外なら `InvalidInput`（非有限なら `NonFinite`）、`minimum < 2` か `maximum < minimum` なら `InvalidInput` を返し、`evaluate` のエラーは最初のものをそのまま返す。

`scioxide-stats` が検出力の式を提供するのは、正規母集団の平均の z 検定と合併分散の t 検定だけである。
比率の検定、分散分析の F 検定、順位検定、Welch の t 検定、群の大きさが異なる 2 群の検出力の式は提供しない。
式が分かっている場合はその値を `PowerEstimate::analytic` で包んで `sample_size` に渡し、式がない場合は次の節の `simulated_power` を使う。

## 検出力曲線と必要な各群の標本数

次のセルは、各群 $n$ 個の 2 群で平均の差を検定する設計について、t 検定と z 検定の検出力を $n=2$ から 2000 まで計算する。
入力は標準化効果量 $d$、有意水準 $\alpha$、対立仮説の向きで、$\sigma=1$ に固定するので `effect` が $d$ になる。
表は目標の検出力 0.8 に届く最小の各群の標本数を `sample_size` で求めた結果である。
3 行目は検算で、z 検定の近似式に正規分布の分位点 `Normal::quantile` を代入して f64 の演算で計算する。
図は横軸を対数目盛にした検出力曲線で、横の線が目標の 0.8、縦の線が t 検定の必要数である。
z 検定の曲線（破線）は分散が既知という理想化した基準で、t 検定の曲線は常にその下にある。
このセルの $d$、$\alpha$、向き、t 検定の必要数と検出力は、次の節の模擬実験のセルに渡す。

```rust
//| id: stats-power-sample-size
//| ref: stats-power-sample-size
//| title: 2 群の平均の差の検出力曲線と必要な各群の標本数
//| run: reactive
//| crates: [scioxide-random, scioxide-stats]
//| exports: [effect, alpha, alternative, size, power]
//| inputs:
//|   effect: {"type":"range","label":"標準化効果量 d = Δ/σ [-]","min":0.2,"max":1.2,"step":0.05,"value":0.5}
//|   alpha: {"type":"range","label":"有意水準 α [-]","min":0.01,"max":0.1,"step":0.01,"value":0.05}
//|   alternative: {"type":"select","label":"対立仮説","options":[{"label":"両側（μ₁ ≠ μ₂）","value":"two-sided"},{"label":"上側（μ₁ > μ₂）","value":"greater"}],"value":"two-sided"}
//| cases:
//|   - {"id":"small-effect","label":"d = 0.2","description":"小さい効果では各群 400 近くが必要になる。","inputs":{"effect":0.2}}
//|   - {"id":"large-effect","label":"d = 1.2","description":"大きい効果では n が小さく、t 検定と z 検定の差が開く。","inputs":{"effect":1.2}}
//|   - {"id":"strict-alpha","label":"α = 0.01","description":"有意水準を厳しくすると必要数が増える。","inputs":{"alpha":0.01}}
//|   - {"id":"one-sided","label":"上側の片側検定","description":"棄却域を片側に集めるので必要数が減る。","inputs":{"alternative":"greater"}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"sizes","path":"/rows/0/1","equals":64}
//|       - {"artifact":"sizes","path":"/rows/0/2","approx":{"value":0.80146,"atol":1e-4}}
//|       - {"artifact":"sizes","path":"/rows/0/3","equals":63}
//|       - {"artifact":"sizes","path":"/rows/1/1","equals":63}
//|       - {"artifact":"sizes","path":"/rows/2/1","equals":63}
//|       - {"artifact":"curve","path":"/spec/series/0/points/0/1","approx":{"value":0.06151,"atol":1e-4}}
//|   - case: small-effect
//|     expect:
//|       - {"artifact":"sizes","path":"/rows/0/1","equals":394}
//|       - {"artifact":"sizes","path":"/rows/2/1","equals":393}
//|   - case: large-effect
//|     expect:
//|       - {"artifact":"sizes","path":"/rows/0/1","equals":12}
//|       - {"artifact":"sizes","path":"/rows/1/1","equals":11}
//|   - case: strict-alpha
//|     expect:
//|       - {"artifact":"sizes","path":"/rows/0/1","equals":96}
//|       - {"artifact":"sizes","path":"/rows/1/1","equals":94}
//|   - case: one-sided
//|     expect:
//|       - {"artifact":"sizes","path":"/rows/0/1","equals":51}
//|       - {"artifact":"sizes","path":"/rows/1/1","equals":50}
//|       - {"artifact":"sizes","path":"/rows/1/2","approx":{"value":0.8037659,"atol":1e-6}}
use scioxide_random::{Normal, Quantile};
use scioxide_stats::{
    ConfidenceProbability, MeanPowerDesign, MeanPowerModel, MeanPowerReference,
    TestAlternative, power, sample_size,
};

let (tail, sides) = match alternative.as_str() {
    "greater" => (TestAlternative::Greater, 1.0),
    _ => (TestAlternative::TwoSided, 2.0),
};
let significance = ConfidenceProbability::new(alpha).map_err(|e| e.to_string())?;
let model = |reference| MeanPowerModel {
    effect,
    standard_deviation: 1.0_f64,
    design: MeanPowerDesign::EqualGroups,
    reference,
    alternative: tail,
    significance,
};
let t_model = model(MeanPowerReference::EstimatedVariance);
let z_model = model(MeanPowerReference::KnownVariance);

// 目標 0.8 に届く最小の各群の標本数を 2..=4000 から線形に探す
let t_size = sample_size(2, 4000, 0.8, |n| power(t_model, n)).map_err(|e| e.to_string())?;
let z_size = sample_size(2, 4000, 0.8, |n| power(z_model, n)).map_err(|e| e.to_string())?;
// 独立検算: 遠い側の裾を無視した近似 n = 2 (z_{α/k} + z_{0.2})² / d²（k は片側 1、両側 2）
let normal = Normal::<f64>::new(0.0, 1.0).map_err(|e| e.to_string())?;
let z_alpha = normal
    .quantile(1.0 - alpha / sides)
    .map_err(|e| e.to_string())?;
let z_beta = normal.quantile(0.8).map_err(|e| e.to_string())?;
let approximate = 2.0 * (z_alpha + z_beta) * (z_alpha + z_beta) / (effect * effect);
let mut rows = Vec::new();
for (name, found) in [("t 検定（非心 t）", t_size), ("z 検定（正規）", z_size)] {
    let reached = found.map(|r| r.estimate.probability());
    rows.push((
        name,
        found.map(|r| r.size),
        reached,
        found.map(|r| r.evaluated),
    ));
}
// 近似式の行は ceil で切り上げた値（f64 の固有メソッドは検算にだけ使う）
rows.push((
    "z 検定の近似式",
    Some(approximate.ceil() as usize),
    None,
    None,
));
let fixed4 = serde_json::json!({ "fractionDigits": 4 });
let columns = serde_json::json!([
    { "key": "0", "label": "計算" },
    { "key": "1", "label": "各群の標本数 n", "type": "integer", "nullText": "範囲内で未達" },
    { "key": "2", "label": "その n での検出力 [-]", "type": "number", "format": fixed4, "nullText": "-" },
    { "key": "3", "label": "評価した n の数", "type": "integer", "nullText": "-" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "sizes" })
);

// n = 2..2000 をほぼ等比（公比 9/8）に並べた検出力曲線
let (mut t_curve, mut z_curve) = (Vec::new(), Vec::new());
let mut n = 2;
while n <= 2000 {
    let probability = |m| power(m, n).map(|e| e.probability());
    t_curve.push([n as f64, probability(t_model).map_err(|e| e.to_string())?]);
    z_curve.push([n as f64, probability(z_model).map_err(|e| e.to_string())?]);
    n = (n * 9 / 8).max(n + 1);
}
let mut annotations =
    vec![serde_json::json!({ "kind": "line", "axis": "y", "value": 0.8, "label": "目標 0.8" })];
if let Some(found) = t_size {
    let label = format!("t 検定の必要数 n = {}", found.size);
    annotations.push(
        serde_json::json!({ "kind": "line", "axis": "x", "value": found.size, "label": label }),
    );
}
emit_chart!(
    serde_json::json!({
        "kind": "line",
        "dataZoom": true,
        "tooltip": true,
        "series": [
            { "name": "t 検定（分散を推定）", "points": t_curve },
            { "name": "z 検定（分散が既知）", "points": z_curve, "style": { "lineType": "dashed" } }
        ],
        "xType": "log",
        "xMin": 2,
        "xMax": 2000,
        "yMin": 0,
        "yMax": 1,
        "xLabel": "各群の標本数 n [個]",
        "yLabel": "検出力 1 − β [-]",
        "annotations": annotations
    }),
    metadata = serde_json::json!({ "id": "curve" })
);
export!(effect, &effect);
export!(alpha, &alpha);
export!(alternative, &alternative);
export!(size, &t_size.map(|r| r.size));
export!(power, &t_size.map(|r| r.estimate.probability()));
```

既定の $d=0.5$、$\alpha=0.05$（両側）では、t 検定の必要数は各群 64（検出力 0.8015）、z 検定は 63（0.8013）で、近似式も 63 になる。
各群 64 は Cohen（1988）の表の値と一致する。
t 検定の探索は $n=2$ から 63 個の $n$ を評価したが、近似式の 63 を `minimum` にすれば 2 回の評価で終わる。
$d=0.2$ では t 検定が 394、z 検定が 393 で、効果量を $1/2.5$ にすると必要数はおよそ $2.5^2=6.25$ 倍になる。
$d=1.2$ では t 検定が 12、z 検定が 11 である。
$n$ が小さいほど自由度 $2(n-1)$ の t 分布の裾が重いので、二つの必要数の比は大きくなる。
$\alpha=0.01$ では t 検定が 96、z 検定が 94 に増え、上側の片側検定では t 検定が 51、z 検定が 50 に減る。
片側の z 検定の $n=50$ は $\delta=0.5\sqrt{50/2}=2.5$ なので、検出力は $\Phi(2.5-1.6449)=0.80377$ で、表の値と一致する。
図の左端 $n=2$ の t 検定の検出力は 0.0615 で、効果がほとんど見えず、棄却の確率は $\alpha$ に近い。

## 模擬実験による検出力

式のない検定では、データの生成と検定を何度も繰り返し、棄却した割合で検出力を推定する。
反復 $m$ 回のうち棄却が $r$ 回なら、$r$ は二項分布 $\mathrm{Bin}(m,\pi)$ に従い、推定値は $\hat\pi=r/m$、標準誤差は $\sqrt{\pi(1-\pi)/m}$ である。
$\pi=0.8$、$m=4000$ の標準誤差は 0.0063 なので、小数第 2 位まで読むには数千回の反復が要る。

区間には Wilson のスコア区間

$$
\frac{\hat\pi+\dfrac{z^2}{2m}\pm z\sqrt{\dfrac{\hat\pi(1-\hat\pi)}{m}+\dfrac{z^2}{4m^2}}}{1+\dfrac{z^2}{m}},\qquad z=z_{0.025}=1.959964
$$

を使う。
$\hat\pi\pm z\sqrt{\hat\pi(1-\hat\pi)/m}$ の Wald 区間は、$\hat\pi$ が 0 や 1 に近いと被覆確率が名目より大きく下がり、$r=0$ では幅が 0 になる（Brown、Cai、DasGupta 2001）。
Wilson 区間はスコア検定を反転した区間で、端に近くても被覆確率が名目に近い。
$r=0$ のとき下限を 0、$r=m$ のとき上限を 1 にする。
この区間は模擬実験の標本誤差を表し、丸め誤差の上限ではない。

`simulated_power(sampler, test, first_size, second_size, significance, replicates, root)` は、この模擬実験を 1 回の呼び出しで行う。

- `sampler(rng, sample)` は、長さ `first_size + second_size` の `sample` に 1 回分の標本を書く。
  `test(x, y)` はその前半 `x` と後半 `y` を受け取って p 値を返し、`p < α` のとき棄却と数える。
- 反復 $k$ の乱数は `root.split(k)` の子の乱数列から作るので、結果は実行の分割やワーカーの数によらず、`root` 自体は進まない。
  同じ `root` で $n$ だけを変えると、各反復は同じ乱数列から始まる（共通乱数）ので、$n$ ごとの推定値の差のばらつきが小さくなる。
- `first_size` が 0 か `replicates < 2` なら `InvalidInput`、標本に非有限の値があると `NonFinite`、p 値が $[0,1]$ の外なら `InvalidInput` を返す。
  `sampler` と `test` のエラーはそのまま返す。
- 戻り値は Wilson 区間を持つ `PowerEstimate` である。
  棄却数と反復回数が分かっていれば、`PowerEstimate::simulated(rejections, replicates)` で同じ推定値を作れる（`replicates < 2` か `rejections > replicates` なら `InvalidInput`）。

反復ごとの p 値を残したいとき、ワーカーの数やメモリ使用量の上限を `StatisticsOptions` で指定したいときは、出力先を指定する API `simulated_power_into(sampler, test, first_size, second_size, significance, root, options, &mut output, context)` を使う。
反復回数は `output` の長さで決まり、p 値はすべての反復が成功してから `output` に書く。
作業領域はワーカー 1 つあたり標本 1 個ぶんと p 値の配列で、合計が `max_bytes` を超えると `ResourceLimit` を返す。
計算量は `sampler` と `test` を反復回数だけ呼ぶ量である。

模擬実験の推定値を `sample_size` に渡すと、Wilson 区間の下限が目標を超えた最初の $n$ が選ばれる。
点推定で判定すると、標本誤差で目標をたまたま超えた小さすぎる $n$ を選ぶことがあるので、下限で判定する。
その代わり、選ばれる $n$ は真の必要数より大きめになり、反復回数を増やすほど真の値に近づく。
$n$ の候補ごとに模擬実験を繰り返すので、式で範囲の見当を付けてから探索する。

## 解析値を模擬実験で確かめる

次のセルは上のセルから $d$、$\alpha$、向き、t 検定の必要数 $n$ とその検出力を受け取り、同じ設計の正規標本を `simulated_power` で生成する。
処置群は $N(d,1)$、対照群は $N(0,1)$ で、棄却の判定には合併分散の t 検定と Welch の t 検定の両方を使う（`t_test_independent_with_options` の `TTestVariance::Pooled` と `Welch`）。
二つの検定は同じ `root` を使うので、同じ標本に対する判定を比べる。
表の最後の列は、模擬の推定値と解析値の差を解析値の標準誤差 $\sqrt{\pi(1-\pi)/m}$ で割った値で、絶対値がおおむね 2 以下なら解析値と矛盾しない。

```rust
//| id: stats-power-simulation
//| ref: stats-power-simulation
//| title: 解析的な検出力を t 検定の模擬実験と Wilson 区間で確かめる
//| run: button
//| crates: [scioxide-core, scioxide-random, scioxide-stats]
//| dependsOn:
//|   design: stats-power-sample-size
//| inputs:
//|   replicates: {"type":"integer","label":"反復回数 m","min":200,"max":10000,"value":4000}
//|   seed: {"type":"integer","label":"乱数のシード","min":0,"max":100000,"value":2024}
//| cases:
//|   - {"id":"few-replicates","label":"m = 200","description":"反復が少ないと Wilson 区間が広がる。","inputs":{"replicates":200}}
//|   - {"id":"other-seed","label":"シード = 7","description":"別の乱数列でも解析値は区間に入る。","inputs":{"seed":7}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"simulation","path":"/rows/0/2","approx":{"value":0.80146,"atol":1e-4}}
//|       - {"artifact":"simulation","path":"/rows/1/1","equals":3197}
//|       - {"artifact":"simulation","path":"/rows/1/5","range":{"min":-2.5,"max":2.5}}
//|       - {"artifact":"simulation","path":"/rows/2/1","equals":3197}
//|   - case: few-replicates
//|     expect:
//|       - {"artifact":"simulation","path":"/rows/1/1","equals":160}
//|       - {"artifact":"simulation","path":"/rows/1/3","approx":{"value":0.73914,"atol":1e-4}}
//|   - case: other-seed
//|     expect:
//|       - {"artifact":"simulation","path":"/rows/1/1","equals":3213}
//|       - {"artifact":"simulation","path":"/rows/2/1","equals":3212}
use scioxide_core::{SciOxideError, RealScalar};
use scioxide_random::{Distribution, Normal, Pcg64, SeedableRng};
use scioxide_stats::{
    ClassicalOptions, ConfidenceProbability, TTestVariance, TestAlternative, simulated_power,
    t_test_independent_with_options,
};

let effect = design["effect"].as_f64().ok_or("効果量がない")?;
let alpha = design["alpha"].as_f64().ok_or("有意水準がない")?;
let size = design["size"].as_u64().ok_or("探索範囲に必要数がない")? as usize;
let analytic = design["power"].as_f64().ok_or("解析的な検出力がない")?;
let tail = match design["alternative"].as_str() {
    Some("greater") => TestAlternative::Greater,
    _ => TestAlternative::TwoSided,
};
let significance = ConfidenceProbability::new(alpha).map_err(|e| e.to_string())?;
let treated = Normal::<f64>::new(effect, 1.0).map_err(|e| e.to_string())?;
let control = Normal::<f64>::new(0.0, 1.0).map_err(|e| e.to_string())?;
let root = Pcg64::from_seed(seed as u64);
// 1 回分の標本: 前半 n 個が処置群、後半 n 個が対照群
let sampler = |rng: &mut Pcg64, sample: &mut [f64]| {
    let (x, y) = sample.split_at_mut(size);
    for value in x {
        *value = treated.sample(rng)?;
    }
    for value in y {
        *value = control.sample(rng)?;
    }
    Ok::<(), SciOxideError>(())
};
let m = replicates as usize;
let standard_error = RealScalar::sqrt(analytic * (1.0 - analytic) / m as f64);
let mut rows = vec![("解析値（非心 t）", None, analytic, None, None, None)];
for (name, variance) in [
    ("模擬: 合併分散の t 検定", TTestVariance::Pooled),
    ("模擬: Welch の t 検定", TTestVariance::Welch),
] {
    let options = ClassicalOptions::default().with_alternative(tail);
    let test = |x: &[f64], y: &[f64]| {
        Ok::<f64, SciOxideError>(
            t_test_independent_with_options(x, y, variance, options)?.p_value(),
        )
    };
    let estimate = simulated_power(&sampler, test, size, size, significance, m, &root)
        .map_err(|e| e.to_string())?;
    let interval = estimate.interval().ok_or("模擬の推定値に区間がない")?;
    let p = estimate.probability();
    rows.push((
        name,
        Some(estimate.rejections()),
        p,
        Some(interval.lower()),
        Some(interval.upper()),
        Some((p - analytic) / standard_error),
    ));
}
let fixed4 = serde_json::json!({ "fractionDigits": 4 });
let fixed2 = serde_json::json!({ "fractionDigits": 2 });
let columns = serde_json::json!([
    { "key": "0", "label": "計算" },
    { "key": "1", "label": "棄却数 r", "type": "integer", "nullText": "-" },
    { "key": "2", "label": "検出力 [-]", "type": "number", "format": fixed4 },
    { "key": "3", "label": "Wilson 下限 [-]", "type": "number", "format": fixed4, "nullText": "-" },
    { "key": "4", "label": "Wilson 上限 [-]", "type": "number", "format": fixed4, "nullText": "-" },
    { "key": "5", "label": "(π̂ − π)/SE [-]", "type": "number", "format": fixed2, "nullText": "-" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "simulation" })
);
```

既定の $n=64$、$m=4000$ では、合併分散の t 検定は 3197 回棄却し、推定値 0.7993 の Wilson 区間 $[0.7866, 0.8114]$ は解析値 0.8015 を含む。
解析値との差は標準誤差の $-0.35$ 倍で、非心 t 分布による計算と矛盾しない。
シードを 7 にすると 3213 回（0.8033、差は標準誤差の 0.28 倍）になる。
$m=200$ では 160 回の棄却で、区間は $[0.7391, 0.8495]$ まで広がり、模擬実験からは小数第 1 位しか読めない。

各群の大きさが等しいとき、Welch の t 統計量は合併分散の t 統計量と同じ値になり、違いは自由度だけである。
Welch–Satterthwaite の自由度は $2(n-1)$ 以下なので、p 値はわずかに大きく、棄却は同じか少なくなる。
既定のシードでは二つの棄却数は同じ 3197 で、シード 7 では Welch の方が 1 回少ない。
群の大きさや分散が違う設計では二つの検定の検出力が離れるので、`sampler` を変えて同じ方法で確かめる。

## まとめ

検出力は、想定した効果があるときに検定が棄却する確率で、効果量 $d$、標本数 $n$、有意水準 $\alpha$、対立仮説の向きで決まる。
正規母集団の平均の検定では、`MeanPowerModel` に設計を書いて `power` を呼ぶと、z 検定は正規分布、t 検定は非心 t 分布で厳密な検出力が得られる。
必要な標本数は `sample_size` で線形に探し、z 検定の近似式 $n\approx c(z_{\alpha/2}+z_\beta)^2/d^2$ で探索の出発点を決める。
式のない検定や、正規性・等分散の仮定が成り立たない設計では、`simulated_power` で棄却率を推定し、Wilson 区間で模擬実験の誤差を示す。
`sample_size` は模擬の推定値を区間の下限で判定するので、標本誤差で小さすぎる $n$ を選ぶことはない。
