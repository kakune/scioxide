回帰分析は、応答 $y$ の平均が説明変数 $x$ にどう依存するかをモデルで表し、その係数を推定して不確かさを評価する。
このページは scioxide-stats の回帰を 5 つの系統に分けて説明する。
線形回帰は最小二乗法で係数を求め、古典的な共分散か不均一分散にロバストな HC3 共分散で検定する。
分散分析（ANOVA）は、群の指示変数を説明変数にした線形回帰の入れ子モデルの比較として扱う。
一般化線形モデル（GLM）は、計数や割合のように正規分布に従わない応答を、連結関数と分散関数で扱う。
ロバスト回帰は外れ値の影響を抑え、直交距離回帰（ODR）は説明変数にも測定誤差がある場合を扱う。

どの系統も、モデルと設計を前もって準備する Plan の型（`Prepared*`）と、応答を当てはめる `fit` を持つ。
同じ設計で応答だけが変わる計算では、準備を 1 回にして当てはめを繰り返す。
系統と型の対応は次のとおりである。

| 系統 | Plan | 主な結果 | ワンショット呼び出し |
|---|---|---|---|
| 線形回帰（密な設計） | `PreparedRegression` | `LinearRegressionFit`、`RegressionContrast` | `ordinary_least_squares`、`linear_regression` |
| 線形回帰（作用素の設計） | `PreparedOperatorRegression` | `OperatorRegressionResult` | なし |
| 群の比較 | `PreparedGroups` | `GroupTest`、`PostHocResult` | `kruskal_wallis_test`、`friedman_test` |
| GLM | `PreparedGlm`、`PreparedOperatorGlm` | `GlmResult`、`GlmCoefficientInference` | `glm_fit` |
| ロバスト回帰 | `PreparedHuber`、`RobustSlopeWorkspace` | `HuberFit`、`RobustSlope` | `huber_location`、`robust_slope` |
| 直交距離回帰 | `PreparedOdr` | `OdrFit` | `linear_odr` |

## 最小二乗回帰とランク落ち設計行列

$n$ 個の観測の応答を $y\in\mathbb R^n$、説明変数を並べた設計行列を $X\in\mathbb R^{n\times p}$、行の重みを $w_i\ge0$、$W=\mathrm{diag}(w_1,\dots,w_n)$ とする。
重み付き最小二乗法は次の問題を解く。

$$
\hat\beta=\arg\min_{\beta}\ \|W^{1/2}(y-X\beta)\|_2
$$

誤差 $\varepsilon=y-X\beta$ が平均 0、分散 $\sigma^2W^{-1}$ で無相関なら、$\hat\beta$ は線形不偏推定量の中で分散が最小である（Gauss–Markov の定理）。
誤差が正規分布に従えば、$\hat\beta$ は最尤推定量でもあり、後で述べる $t$ 検定と $F$ 検定が正確になる。
モデルは切片を自動では含まないので、切片が要るときは 1 の列を設計に入れる。
重みは [`Unweighted`](../weighted-estimation-and-confidence/)、`Frequency`（整数の反復回数）、`Analytic`（相対的な分散の逆数）から選び、重み 0 の行は当てはめに影響しない。

[`PreparedRegression`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/struct.PreparedRegression.html) は設計を複製し、$A=W^{1/2}X$ を 1 回だけ分解する。
正規方程式 $A^{\mathsf T}A\beta=A^{\mathsf T}W^{1/2}y$ は作らない。
$A^{\mathsf T}A$ の条件数は $\kappa(A)^2$ なので、正規方程式を解くと丸め誤差が $\kappa(A)^2$ 倍に拡大するためである。
分解は [`RegressionFactorization`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/enum.RegressionFactorization.html) で選ぶ。
既定の `Auto` は列の交換を伴う Householder QR 分解を使い、$p>n$ のときと数値的にランク落ちしているときは薄い特異値分解（SVD）に切り替える。
`Svd` は常に SVD を使う。
準備の計算量は QR で $O(np^2)$、その後の当てはめは 1 回 $O(np)$ である。

数値的なランクは [`RankPolicy`](https://docs.rs/scioxide-linalg/0.1.0/scioxide_linalg/enum.RankPolicy.html) が決める閾値で判定し、既定は次元に比例した $\varepsilon$ の倍数（`DimensionScaledEpsilon`）である。
ランクが $r<p$ のとき、最小二乗解は 1 つに決まらず、$\hat\beta+\ker A$ のすべてが同じ残差を与える。
scioxide-stats は閾値より小さい特異値を 0 とみなし、解の集合の中でノルム $\|\beta\|_2$ が最小のもの（擬似逆行列 $A^{+}$ による解）を返す。
係数そのものは一意でなくても、当てはめ値 $X\hat\beta$、残差、そして推定可能な線形結合 $c^{\mathsf T}\beta$（$c$ が $A$ の行空間にあるもの）は一意に決まる。

QR と SVD による最小二乗解は後退安定である。
係数の相対誤差は、おおよそ $\varepsilon\,\kappa(A)$ に、残差が大きい場合の項 $\varepsilon\,\kappa(A)^2\tan\theta$（$\theta$ は $y$ と $A$ の列空間のなす角）を加えた大きさになる（Golub and Van Loan 2013、5.3 節）。
[`PreparedRegression::condition`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/struct.PreparedRegression.html#method.condition) は QR なら 1 ノルムの条件数の推定を、SVD なら最大と最小の特異値の比を返す。
これは推定値で、上界ではない。

当てはめの結果 [`LinearRegressionFit`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/struct.LinearRegressionFit.html) は、係数 `coefficients`、当てはめ値 `fitted`（重み 0 の行も含む）、残差 `residuals`、重み付き残差 `weighted_residuals`、ランクと閾値 `rank`、残差の自由度 `degrees_of_freedom`（$n_{\text{eff}}-r$）、残差のノルム `residual_norm` と `weighted_residual_norm` を持つ。
`normal_residual_norm` は $\|X^{\mathsf H}W(y-X\hat\beta)\|_2$ で、正確な最小二乗解では 0 になるので、計算した $\hat\beta$ が最適性の条件をどれだけ満たすかの目安になる。
$n_{\text{eff}}$ は、重みなしなら行数、`Frequency` なら回数の和、`Analytic` なら正の重みの行数である。

呼び出しの形は 4 つある。
`ordinary_least_squares(design, &y)` は重みなし・既定の設定のワンショット呼び出しである。
`plan.fit(&y)` は出力と作業領域を確保して当てはめ、`plan.fit_into(&y, &mut output, &mut workspace, context)` は `output()` と `workspace()` で作った [`RegressionWorkspace`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/struct.RegressionWorkspace.html) に書くので、作業領域があれば確保をしない。
[`regression_batch_into`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/fn.regression_batch_into.html) は同じ Plan で複数の応答を当てはめ、実行コンテキストが許せば並列に動く。
説明変数が 1 つの直線 $y=\beta_0+\beta_1x$ には [`linear_regression`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/fn.linear_regression.html) があり、$\hat\beta_1=S_{xy}/S_{xx}$ と $\hat\beta_0=\bar y-\hat\beta_1\bar x$ を拡張した指数の範囲で $O(n)$ で計算する。
結果の [`LinearRegression`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/struct.LinearRegression.html) は、`line()` で傾き・切片・相関係数を返す。
`slope_inference` と `intercept_inference` は自由度 $n-2$ の $t$ 検定と区間を返し、観測が 2 点のとき（自由度 0）は `None` を返す。

### 係数の検定と共分散（古典と HC3）

[`PreparedRegression::contrast`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/struct.PreparedRegression.html#method.contrast) は、対比ベクトル $c$ と帰無値 $c_0$ について $H_0:c^{\mathsf T}\beta=c_0$ を検定し、[`RegressionContrast`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/struct.RegressionContrast.html) で推定値 $c^{\mathsf T}\hat\beta-c_0$、標準誤差、p 値、両側の信頼区間（帰無値を引かない $c^{\mathsf T}\beta$ の区間）を返す。
`coefficient_inference` は単位ベクトルの対比を列ごとに当てた $p$ 個の結果を返す。
標準誤差の推定は [`RegressionCovariance`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/enum.RegressionCovariance.html) で選ぶ。

$$
\widehat{\mathrm{Var}}_{\text{古典}}(\hat\beta)=\hat\sigma^2(A^{\mathsf T}A)^{-1},\quad \hat\sigma^2=\frac{\mathrm{RSS}}{n_{\text{eff}}-r},\qquad
\widehat{\mathrm{Var}}_{\text{HC3}}(\hat\beta)=(A^{\mathsf T}A)^{-1}\Big(\sum_i\frac{e_i^2}{(1-h_i)^2}a_ia_i^{\mathsf T}\Big)(A^{\mathsf T}A)^{-1}
$$

ここで $a_i^{\mathsf T}$ は $A$ の第 $i$ 行、$e_i$ は重み付き残差、$h_i=a_i^{\mathsf T}(A^{\mathsf T}A)^{-1}a_i$ はてこ比（leverage）である。
古典的な推定は誤差の分散が全観測で等しいこと（等分散）を仮定し、$t$ 分布（自由度 $n_{\text{eff}}-r$）で p 値と区間を出す。
誤差が正規で等分散なら、この検定は正確である。

誤差の分散が観測ごとに違う不均一分散（heteroskedasticity）では、古典的な推定は偏り、とくに分散の大きい観測がてこ比の大きい位置にあると標準誤差を過小に見積もる。
サンドイッチ型の推定（White 1980）は、中央の行列を各観測の $e_i^2$ で推定することで、分散の形を仮定せずに一致性を持つ。
$e_i^2$ はてこ比の大きい観測で真の分散より小さくなりやすいので、HC3（MacKinnon and White 1985）は $(1-h_i)^{-2}$ を掛けて補う。
HC3 の推論は漸近的な正規分布を使うので、小標本では区間の被覆率が名目値からずれることがあり、下のセルの例でも名目値をやや下回る。
Long and Ervin（2000）は、$n<250$ では HC0〜HC2 より HC3 が名目の水準に近いことを模擬実験で示している。
HC3 は `Frequency` の重みが 1 以外の値を含むとき（行を展開して渡す）と、てこ比 1 の行があるときに `InvalidInput` を返す。

対比 $c$ が推定可能でない（$A$ の行空間にない）と `InvalidInput` になる。
残差の自由度 $n_{\text{eff}}-r$ が 0 以下のときも `InvalidInput` である。
`contrast` と `compare_nested` は実数の設計に限られ、当てはめ自体は複素数の設計も受け付ける。

自己相関と不均一分散の両方にロバストな HAC 共分散（Newey–West など）、クラスタにロバストな共分散、HC0〜HC2 は、線形回帰では提供しない。
誤差に自己相関がある時系列の回帰では、$(x_t,y_t)$ の組を [リサンプリング](../resampling/) の `MovingBlock` の設計でリサンプリングして係数の標準誤差を求めるか、誤差の自己相関を [ARIMA モデル](../time-series/)で表す。

## 不均一分散のもとでの区間の被覆率

次のセルは HC3 の効果を被覆率で確かめる。
説明変数を $x_i=1+9u_i^3$（$u_i$ は $[0,1]$ の等間隔）とし、右端に少数のてこ比の大きい点を置く。
応答は $y_i=2+0.5x_i+\sigma(x_i)\varepsilon_i$、誤差の標準偏差は $\sigma(x)=0.5x^h$、$\varepsilon_i$ は標準正規である。
$h=0$ なら等分散で、$h$ を大きくするほど、てこ比の大きい右端で分散が大きくなる。

設計は固定なので、`PreparedRegression` を 1 回だけ作り、2000 組の応答を同じ分解で当てはめる。
最初の表は 1 組の応答での傾きの推定と、2 つの標準誤差である。
独立な検算として、古典的な標準誤差を単回帰の閉形式 $s/\sqrt{S_{xx}}$（`linear_regression`）と、HC3 の標準誤差を単回帰の式 $\sqrt{\sum_i d_i^2e_i^2/(1-h_i)^2}\,/S_{xx}$（$d_i=x_i-\bar x$、$h_i=1/n+d_i^2/S_{xx}$）と比べる。
2 つ目の表は、2000 組での傾きの 95% 区間が真値 0.5 を含んだ割合と、その二項分布の標準誤差である。
図は 1 組目の残差で、$h$ が大きいと右へ行くほど残差の幅が広がる。

```rust
//| id: stats-regression-anova-and-glm-api-2
//| ref: stats-regression-anova-and-glm-api-2
//| title: 不均一分散のもとでの古典と HC3 の標準誤差と区間の被覆率
//| run: button
//| crates: [scioxide-core, scioxide-linalg, scioxide-random, scioxide-stats]
//| inputs:
//|   hetero: {"type":"range","label":"分散の指数 h（σ = 0.5 x^h）[-]","min":0,"max":1.5,"step":0.25,"value":1}
//|   sample_size: {"type":"select","label":"標本の大きさ n","options":["30","100"],"value":"30"}
//|   sampling_seed: {"type":"integer","label":"乱数のシード","min":0,"max":100000,"value":2024}
//| cases:
//|   - {"id":"homoskedastic","label":"h = 0","description":"等分散なので古典的な区間の被覆率が 0.95 の近くになり、HC3 はやや下回る。","inputs":{"hetero":0}}
//|   - {"id":"large-n","label":"n = 100","description":"HC3 の被覆率が 0.95 に近づく。古典的な区間は n を増やしても被覆率が戻らない。","inputs":{"sample_size":"100"}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"single","path":"/rows/0/2","approx":{"value":0.16708488095625784,"rtol":1e-09}}
//|       - {"artifact":"single","path":"/rows/0/3","approx":{"value":0.16708488095625784,"rtol":1e-12}}
//|       - {"artifact":"single","path":"/rows/1/2","approx":{"value":0.3277176003213589,"rtol":1e-09}}
//|       - {"artifact":"single","path":"/rows/1/3","approx":{"value":0.3277176003213589,"rtol":1e-12}}
//|       - {"artifact":"coverage","path":"/rows/0/1","approx":{"value":0.7355,"atol":1e-12}}
//|       - {"artifact":"coverage","path":"/rows/1/1","approx":{"value":0.9085,"atol":1e-12}}
//|   - case: homoskedastic
//|     expect:
//|       - {"artifact":"coverage","path":"/rows/0/1","range":{"min":0.935,"max":0.965}}
//|       - {"artifact":"coverage","path":"/rows/1/1","approx":{"value":0.939,"atol":1e-12}}
//|       - {"artifact":"single","path":"/rows/0/3","approx":{"value":0.03803391052370588,"rtol":1e-12}}
//|   - case: large-n
//|     expect:
//|       - {"artifact":"coverage","path":"/rows/0/1","approx":{"value":0.7555,"atol":1e-12}}
//|       - {"artifact":"coverage","path":"/rows/1/1","approx":{"value":0.9345,"atol":1e-12}}
//|       - {"artifact":"single","path":"/rows/1/3","approx":{"value":0.16272319784443662,"rtol":1e-12}}
use scioxide_core::RealScalar;
use scioxide_linalg::Matrix;
use scioxide_random::{Distribution, Normal, SeedableRng, SplitMix64};
use scioxide_stats::{
    ConfidenceProbability, LinearRegressionOptions, PreparedRegression, RegressionCovariance,
    TestAlternative, Unweighted, linear_regression,
};

let n: usize = sample_size.parse().map_err(|_| "n が整数でない")?;
let (beta0, beta1) = (2.0, 0.5);
// 固定した説明変数 x = 1 + 9u³ と誤差の標準偏差 σ(x) = 0.5 x^h
let x: Vec<f64> = (0..n)
    .map(|i| 1.0 + 9.0 * RealScalar::powi(i as f64 / (n - 1) as f64, 3))
    .collect();
let sigma: Vec<f64> = x
    .iter()
    .map(|&v| 0.5 * RealScalar::powf(v, hetero))
    .collect();
let mut rows = Vec::with_capacity(2 * n);
for &v in &x {
    rows.extend([1.0, v]);
}
let design = Matrix::from_vec(n, 2, rows).map_err(|e| e.to_string())?;
// 設計は固定なので、分解は 1 回だけ行う。
let plan = PreparedRegression::new(
    design.view(),
    Unweighted,
    LinearRegressionOptions::default(),
)
.map_err(|e| e.to_string())?;
let normal = Normal::<f64>::new(0.0, 1.0).map_err(|e| e.to_string())?;
let mut rng = SplitMix64::from_seed(sampling_seed as u64);
let mut draw = |y: &mut Vec<f64>| -> Result<(), String> {
    y.clear();
    for (&v, &s) in x.iter().zip(&sigma) {
        let e = normal.sample(&mut rng).map_err(|e| e.to_string())?;
        y.push(beta0 + beta1 * v + s * e);
    }
    Ok(())
};
let level = ConfidenceProbability::default();
let slope_test = |y: &[f64], covariance| {
    plan.contrast(
        y,
        &[0.0, 1.0],
        0.0,
        covariance,
        level,
        TestAlternative::TwoSided,
    )
    .map_err(|e| e.to_string())
};
let mut y = Vec::with_capacity(n);
draw(&mut y)?;
let classical = slope_test(&y, RegressionCovariance::Classical)?;
let hc3 = slope_test(&y, RegressionCovariance::Hc3)?;
// 独立な検算: 単回帰の閉形式 s/√Sxx と、HC3 の √(Σ dᵢ² eᵢ² / (1 − hᵢ)²) / Sxx
let simple = linear_regression(&x, &y).map_err(|e| e.to_string())?;
let simple_se = simple
    .slope_inference(level, TestAlternative::TwoSided)
    .map_err(|e| e.to_string())?
    .ok_or("観測が 2 点")?
    .standard_error();
let fit = plan.fit(&y).map_err(|e| e.to_string())?;
let xbar = x.iter().sum::<f64>() / n as f64;
let sxx: f64 = x.iter().map(|v| (v - xbar) * (v - xbar)).sum();
let mut meat = 0.0;
let mut residuals = Vec::with_capacity(n);
for (&v, &e) in x.iter().zip(fit.residuals().as_slice()) {
    let (d, h) = (v - xbar, 1.0 / n as f64 + (v - xbar) * (v - xbar) / sxx);
    meat += d * d * e * e / ((1.0 - h) * (1.0 - h));
    residuals.push([v, e]);
}
let single = vec![
    (
        "古典（t 分布）",
        classical.estimate(),
        classical.standard_error(),
        simple_se,
    ),
    (
        "HC3（正規分布）",
        hc3.estimate(),
        hc3.standard_error(),
        RealScalar::sqrt(meat) / sxx,
    ),
];
// 被覆率の模擬: 同じ Plan で M 組の応答を当てはめる
let m = 2000;
let (mut cover_classical, mut cover_hc3) = (0usize, 0usize);
for _ in 0..m {
    draw(&mut y)?;
    let ci = slope_test(&y, RegressionCovariance::Classical)?.interval();
    cover_classical += usize::from(ci.contains(beta1));
    cover_hc3 += usize::from(
        slope_test(&y, RegressionCovariance::Hc3)?
            .interval()
            .contains(beta1),
    );
}
let rate = |c: usize| c as f64 / m as f64;
```

## 分散分析（ANOVA）と群間比較

$k$ 群の大きさを $n_g$、平均を $\bar y_g$、分散を $s_g^2$、全体の大きさを $N$、全体の平均を $\bar y$ とする。
一元配置分散分析（one-way ANOVA）は、全群の平均が等しいという帰無仮説を次の $F$ 統計量で検定する。

$$
F=\frac{\sum_g n_g(\bar y_g-\bar y)^2/(k-1)}{\sum_g(n_g-1)s_g^2/(N-k)}
$$

各群が等分散の正規分布に従えば、帰無仮説のもとで $F$ は自由度 $(k-1,N-k)$ の $F$ 分布に従う。
この検定は、群の指示変数を説明変数にした線形回帰の入れ子モデルの比較と同じである。
完全なモデル $y_{gi}=\mu+\alpha_g+\varepsilon_{gi}$ と、切片だけの縮小モデル $y_{gi}=\mu+\varepsilon_{gi}$ の残差平方和を $\mathrm{RSS}_f$、$\mathrm{RSS}_r$、ランクを $r_f$、$r_r$ とすると、次の $F$ が上の $F$ に一致する。

$$
F=\frac{(\mathrm{RSS}_r-\mathrm{RSS}_f)/(r_f-r_r)}{\mathrm{RSS}_f/(n_{\text{eff}}-r_f)}
$$

[`PreparedRegression::compare_nested`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/struct.PreparedRegression.html#method.compare_nested) はこの $F$ 検定を行い、縮小モデルの各列が完全なモデルの列空間にあることを確かめてから計算する。
自由度はランクから取るので、完全なモデルの設計がランク落ちしていてもよい。
二元配置以上の分散分析表（逐次平方和、Type II・III の平方和）を作る関数はないが、項を 1 つずつ加えた設計の列を作り、`compare_nested` を順に呼べば逐次平方和の $F$ 検定になる。

[`PreparedGroups`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/struct.PreparedGroups.html) は各群の大きさ・平均・分散だけを拡張した指数の範囲で保持し、次の検定を行う。
`anova(GroupTestMethod::Anova)` は上の $F$ 検定、`anova(GroupTestMethod::Welch)` は分散が等しいことを仮定しない Welch（1951）の近似 $F$ 検定、`alexander_govern()` は各群の $t$ 統計量を正規化変換した値の 2 乗を足す Alexander–Govern（1994）の近似 $\chi^2$ 検定である。
結果の `GroupTest` は統計量、上側の p 値、自由度（$F$ 検定では分母の自由度 `denominator_degrees` も）を持つ。
[`group_tests_into`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/fn.group_tests_into.html) は複数の群の組に同じ検定を行う。
順位に基づく Kruskal–Wallis 検定と Friedman 検定は [古典的な検定と順位検定](../classical-tests/) で扱う。

全体の検定で差が見つかったあと、どの群の対に差があるかは多重比較で調べる。
`pairwise(PostHocMethod::TukeyKramer)` は等分散を仮定してすべての対を比べ、`pairwise(PostHocMethod::GamesHowell)` は対ごとに Welch–Satterthwaite の自由度を使う。
どちらもスチューデント化された範囲の分布で p 値を調整する。
Tukey–Kramer の方法は、等分散の正規分布のもとで全体の第 1 種の過誤の確率（familywise error rate）を名目の水準以下に保ち（Hayter 1984）、Games–Howell の方法はその近似である。
`compare_control(control, alternative)` は各群を対照群と比べる Dunnett の方法で、多変量 $t$ 分布の確率を数値積分で求める。
数値積分の許容誤差と評価回数の上限は `PostHocOptions` で決め、各比較の `probability_error` が p 値の誤差の推定（上界ではない）を返す。

### 作用素による回帰（LSQR・LSMR）

設計が大きく疎な行列や、行列を作らずに積だけを計算できる作用素のときは、QR や SVD で分解できない。
[`PreparedOperatorRegression`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/struct.PreparedOperatorRegression.html) は設計を `AdjointOperator`（積 $Xv$ と $X^{\mathsf H}u$ だけを持つ作用素）として借用し、Krylov 部分空間法で最小二乗問題を解く。
[`OperatorRegressionMethod`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/enum.OperatorRegressionMethod.html) の `Lsqr`（Paige and Saunders 1982）は正規方程式に共役勾配法を当てるのと同等で、残差 $\|r\|_2$ が単調に減る。
`Lsmr`（Fong and Saunders 2011）は正規方程式に MINRES を当てるのと同等で、$\|A^{\mathsf H}r\|_2$ が単調に減る。
どちらも Golub–Kahan の二重対角化を使い、1 回の反復は $X$ と $X^{\mathsf H}$ の積を 1 回ずつと $O(n+p)$ の演算である。

[`OperatorRegressionOptions`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/struct.OperatorRegressionOptions.html) の既定は LSMR、スカラーの精度から決めた残差と正規方程式の残差の許容誤差、反復 4096 回、バイト数の上限なしである。
$\beta=0$ から始めるので、反復は $A^{\mathsf H}$ の値域（$A$ の行空間）の中にとどまり、設計がランク落ちしていても最小ノルム解へ収束する。
作用素の回帰はランクを計算しないので、結果の `LinearRegressionFit` は `rank` と `degrees_of_freedom` が `None` で、`contrast` のような推論はない。

[`OperatorRegressionResult`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/struct.OperatorRegressionResult.html) は当てはめ `fit()` とレポート `report()` を持つ。
[`OperatorRegressionReport`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/struct.OperatorRegressionReport.html) の終了状態 `termination` は scioxide-linalg の `LinearSolveTermination` で、`is_success()` は `Converged` と `LeastSquaresConverged` で真になる。
`iterations` は反復の回数、`krylov` は射影した問題の条件数とランク落ちの推定で、設計のランクではない。
`output_committed` は結果を出力に書いたかどうかで、実行が止められたか評価の上限で残差を計算する 2 回の積が残らなかったときに偽になり、そのとき `fit()` は `None` である。
反復の上限に達した場合も最後の反復を書くので、`output_committed` は収束を意味しない。
作業領域は [`OperatorRegressionWorkspace`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/struct.OperatorRegressionWorkspace.html) で、大きさは $O(n+p+s)$（$s$ は作用素が求める作業用の長さ）である。

## 植物の乾燥重量の分散分析

次の 3 つのブロックは、R の `PlantGrowth`（Dobson 1983）のデータで、対照群と 2 種類の処理群（各 10 株）の乾燥重量 [g] を比べる。
最初のブロックは 2 つのセルが共有する定義で、`GROUPS` が 3 群の観測、`response()` が 30 株を群の順に並べた応答、`indicator_design(overparameterized)` が群の指示変数の設計である。
`overparameterized` が真なら、設計は切片と 3 群すべての指示変数の 4 列で、1 の列が指示変数の和に等しいのでランクは 3 である。
偽なら、対照群を基準にした切片と処理 1・処理 2 の指示変数の 3 列で、フルランクである。

```rust

use scioxide_core::SciOxideError;
use scioxide_linalg::Matrix;

/// 対照群、処理 1、処理 2 の乾燥重量 [g]（各 10 株）。

}

    let p = if overparameterized { 4 } else { 3 };

        for _ in 0..10 {
            let dummy = |j: usize| f64::from(u8::from(g == j));

                cells.extend([1.0, dummy(0), dummy(1), dummy(2)]);
            } else {
                cells.extend([1.0, dummy(1), dummy(2)]);
            }
        }
    }
    Matrix::from_vec(30, p, cells)
}
```

```rust
    .map(|g| g.iter().sum::<f64>() / 10.0)
    .collect();
let (closed, labels) = if over {

    (

    )
};

    .map(|j| {
        let qr = fit.coefficients().as_slice()[j];

    })
    .collect();
// 推定可能な対比（処理 2 − 処理 1）と、第 2 列の係数だけの対比

    (vec![0.0, 0.0, -1.0, 1.0], vec![0.0, 1.0, 0.0, 0.0])
} else {
    (vec![0.0, -1.0, 1.0], vec![0.0, 1.0, 0.0])
};
```

入れ子モデルの $F$ はどちらの符号化でも ANOVA の $F=4.846$ と丸め誤差の範囲で一致する。
過剰パラメータ化の設計では、`Auto` の分解がランク落ちを検出して SVD に切り替え、その解と LSMR の解が閉形式の最小ノルム解 $\hat\mu=3.80475$ と一致する。
LSMR は $\beta=0$ から 2 回の反復で `LeastSquaresConverged` になる。
処理 2 − 処理 1 の対比はどちらの符号化でも 0.865 g で、標準誤差は 0.2788（両側 $p=0.0045$）である。
この p 値は 3 つの対から 1 つを選んだことを調整していないので、Tukey–Kramer の 0.012 より小さい。
第 2 列の係数だけの対比は、過剰パラメータ化では対照群の効果 $\alpha_{\text{対照}}$ で、行空間にないので `InvalidInput` になる。
基準群の符号化では同じ対比が処理 1 と対照群の差 $\hat\beta_1=-0.371$ g という別の量になり、推定できる。
係数そのものは符号化で意味が変わるので、係数を返すときは符号化も示す。

## 一般化線形モデル（GLM）

一般化線形モデル（McCullagh and Nelder 1989）は、応答 $y_i$ が指数型分散族に従い、平均 $\mu_i$ が線形予測子 $\eta_i$ と単調な連結関数 $g$ で結ばれるモデルである。

$$
g(\mu_i)=\eta_i=x_i^{\mathsf T}\beta+o_i,\qquad \mathrm E[y_i]=\mu_i,\qquad \mathrm{Var}[y_i]=\frac{\phi\,V(\mu_i)}{w_im_i}
$$

ここで $V$ は分散関数、$o_i$ はオフセット、$w_i$ は行の重み、$m_i$ は二項分布の試行回数（他の族では 1）、$\phi$ は分散パラメータ（dispersion）である。
[`GlmFamily`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/enum.GlmFamily.html) の 5 つの族と、[`GlmLink`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/enum.GlmLink.html) の連結関数の対応は次のとおりである。

| 族 | 応答の定義域 | $V(\mu)$ | 連結 $g(\mu)$ | 単位逸脱度 $d(y,\mu)$ |
|---|---|---|---|---|
| `Gaussian` | $y\in\mathbb R$ | $1$ | `Identity`: $\mu$ | $(y-\mu)^2$ |
| `Binomial` | $0\le y\le1$（成功の割合） | $\mu(1-\mu)$ | `Logit`: $\ln\{\mu/(1-\mu)\}$ | $2[y\ln(y/\mu)+(1-y)\ln\{(1-y)/(1-\mu)\}]$ |
| `Poisson` | $y\ge0$ | $\mu$ | `Log`: $\ln\mu$ | $2[y\ln(y/\mu)-(y-\mu)]$ |
| `Gamma` | $y>0$ | $\mu^2$ | `Inverse`: $1/\mu$ | $2[(y-\mu)/\mu-\ln(y/\mu)]$ |
| `InverseGaussian` | $y>0$ | $\mu^3$ | `InverseSquared`: $1/\mu^2$ | $(y-\mu)^2/(y\mu^2)$ |

連結関数は各族の正準連結関数（符号を除く）に固定されていて、族を選ぶと連結が決まる（`GlmFamily::link`）。
Gamma と逆 Gauss の連結は $\eta>0$ を必要とする。
プロビット連結、補対数対数連結、Gamma の対数連結のような正準でない連結関数、負の二項分布、Tweedie 分布、準尤度の族、一般化推定方程式（GEE）、混合モデル、ペナルティ付きの GLM は提供しない。
これらが必要なときは、対数尤度を [`FitObjective`](../distribution-fitting-and-confidence-limits/) として書き、最適化法を `FitSolver` で渡して `fit_into` で最小化する。

[`PreparedGlm::new`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/struct.PreparedGlm.html#method.new) は設計、族、重み、試行回数 `trials`（二項だけ、既定 1）、オフセット `offsets`（既定 0）、曝露 `exposure`（Poisson だけ、対数をオフセットに加える）を受け取る。
重みは `Unweighted`、`Frequency`、`Analytic` で、尤度を定義しない `Reliability` の重みはコンパイルできない。
有効標本の大きさ $n_{\text{eff}}$ が列の数以下だと `InvalidInput` になる。

### 反復重み付き最小二乗法

最尤推定量は逸脱度 $D(\beta)=\sum_iw_im_id(y_i,\mu_i)$ を最小にする。
正準連結では対数尤度の観測情報量と期待情報量が等しいので、Fisher のスコア法は Newton 法に一致し、各反復は次の重み付き最小二乗問題になる（反復重み付き最小二乗法、IRLS）。

$$
z_i=\eta_i+(y_i-\mu_i)\,g'(\mu_i),\qquad
W_i=\frac{w_im_i}{V(\mu_i)\,g'(\mu_i)^2},\qquad
\beta^{\text{new}}=\arg\min_\beta\sum_iW_i(z_i-x_i^{\mathsf T}\beta-o_i)^2
$$

scioxide-stats の IRLS は、応答の重み付き平均を初期の平均として始め（二項では $[4\sqrt\varepsilon,1-4\sqrt\varepsilon]$ に、Poisson・Gamma・逆 Gauss では $4\sqrt\varepsilon$ 以上に収める）、各反復の重み付き最小二乗問題を薄い SVD で $O(np^2)$ で解く。
逸脱度が増えればステップ幅を最大 32 回半分にする。
係数の変化の許容誤差（最大の係数の大きさに対する相対値）と、スコア $\nabla\ell(\beta)$ のノルムの許容誤差（$1+D$ に対する相対値）の両方を満たすと収束とする。
既定の反復の上限は 100 回、各 SVD の反復の上限は 4096 回で、[`GlmOptions`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/struct.GlmOptions.html) で変えられる。

### 終了状態とその条件

レポート [`GlmReport`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/struct.GlmReport.html) の `termination` フィールドが、`StatsTermination` の終了状態を持つ。
`is_success()` が真なのは `Converged` だけである。
各状態になる条件は次のとおりである。

| 状態 | 条件 | 当てはめ |
|---|---|---|
| `Converged` | 2 回目以降の反復で、係数の変化とスコアの両方が許容誤差を満たした | 最後の反復 |
| `BudgetExhausted` | 反復の上限、または解いているコンテキストの反復・評価の上限に達した | 最後に受け入れた反復（なければなし） |
| `Stopped(_)` | 取り消しか期限で止まった | 同上 |
| `RankDeficient` | ある反復の重み付き設計 $W^{1/2}X$ の数値的なランクが $p$ より小さい | 同上 |
| `Separated` | 二項族で、係数の絶対値の最大が 32 を超え、どれかの当てはめ値が $4\sqrt\varepsilon$ より 0 か 1 に近い。または二項族で、32 回の半減でも逸脱度が下がらない | 同上 |
| `NoProgress` | 二項以外の族で、32 回の半減でも逸脱度が下がらない | 同上 |

`RankDeficient` は設計の列が線形従属のときに最初の反復で起こるほか、反復の途中でも起こる。
Poisson 族である群の計数がすべて 0 だと、その群の最尤推定は $\mu=0$、つまり $\eta=-\infty$ で、反復のたびに当てはめ値が 0 に近づき、重み $W_i=\mu_i$ が 0 に近づいてその列が数値的に消える。
二項族の同じ状況（完全分離や準完全分離、Albert and Anderson 1984）は、係数の発散と当てはめ値の飽和から `Separated` として検出する。
`NotConverged` は IRLS では起こらず、注入した最適化法が収束を返しなかったときに使う。

当てはめは [`GlmResult`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/struct.GlmResult.html) の `fit()` が返す [`GlmFitView`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/struct.GlmFitView.html) で読み、1 回も反復を受け入れなかった場合は `None` である。
`GlmFitView` と所有型の [`GlmFit`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/struct.GlmFit.html) は、係数、当てはめた平均 $\hat\mu_i$、応答の残差 $y_i-\hat\mu_i$、線形予測子 $\hat\eta_i$（オフセットを含む）、逸脱度 $D$、Pearson 統計量 $X^2=\sum w_im_i(y_i-\hat\mu_i)^2/V(\hat\mu_i)$、スコアのノルム、Pearson の分散パラメータの推定 $X^2/(n_{\text{eff}}-p)$、残差の自由度、最後の反復の数値的なランクを持つ。
逸脱度は飽和モデルとの対数尤度比の 2 倍で、正規近似が成り立つ範囲では自由度 $n_{\text{eff}}-p$ の $\chi^2$ 分布で当てはまりを測れる。
Poisson と二項で $X^2/(n_{\text{eff}}-p)$ が 1 より大きく離れるときは過分散を疑う。

### 係数の共分散と Wald 検定

収束してフルランクの当てはめでは、[`GlmCovariance`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/enum.GlmCovariance.html) で共分散の推定を選ぶ。
最後の IRLS の重みで重み付けた設計を $A$、$B=A^{\mathsf T}A$（分散パラメータ 1 での Fisher 情報量）とする。
`Model` は $\phi B^{-1}$ で、$\phi$ は二項と Poisson では 1、他の族では Pearson の推定である。
`Hc0` はスコアの寄与 $s_i$ によるサンドイッチ $B^{-1}(\sum_is_is_i^{\mathsf T})B^{-1}$、`Hc3` はさらに $(1-h_i)^{-2}$ を掛けたもので、どちらも分散関数が誤っていても一致性を持つ。
`PreparedGlm::covariance` は共分散行列を、`coefficient_inference` は [`GlmCoefficientInference`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/struct.GlmCoefficientInference.html) の列で各係数の推定・標準誤差・Wald 検定の両側 p 値 $2\{1-\Phi(|\hat\beta_j|/\mathrm{se})\}$・区間 $\hat\beta_j\pm z\,\mathrm{se}$ を返す。
どちらも漸近的な結果で、計算量は $O(n^2p+np^2)$ である。
収束していない当てはめ、ランク落ち、応答と当てはめが合わない場合は `InvalidInput` を返す。
尤度比検定と係数のプロファイル尤度区間は提供しないが、入れ子モデルをそれぞれ当てはめて逸脱度の差 $D_r-D_f$ を自由度 $p_f-p_r$ の $\chi^2$ 分布と比べれば、尤度比検定になる（$\phi$ が既知の族の場合）。

### 呼び出しの形と関連する型

[`GlmInputs`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/struct.GlmInputs.html) は応答、`GlmOptions`、求解法をまとめる。
求解法 [`GlmSolver`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/enum.GlmSolver.html) の既定は `Irls` で、`Injected` は利用者の `FitSolver` に [`GlmObjective`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/struct.GlmObjective.html)（逸脱度の半分 $\tfrac12\sum w_im_id(y_i,\mu_i(\beta))$ とその勾配、評価 1 回 $O(np)$）を最小化させる。
`Injected` では係数の上下限と整数の制約も渡せ、最適化法の最後の点を検査して 1 回の受け入れた反復として数える。

| 形 | 呼び出し | 確保 |
|---|---|---|
| ワンショット呼び出し | `glm_fit(design, family, &y)` | Plan・出力・作業領域。収束しなければエラー |
| 標準形式 | `plan.fit(inputs)` | 出力と作業領域 |
| スコープ付き API | `plan.fit_scoped(inputs, scope)` | 出力と作業領域。計算回数の上限を親の計算と共有する |
| 出力先を指定する API | `plan.fit_into(inputs, &mut output, &mut workspace, scope)` | なし |
| 一括 | `glm_batch_into(inputs, outputs, workspace, context)` | なし |

出力先を指定する API の [`GlmOutput`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/struct.GlmOutput.html) は `plan.output()` で作り、最後に受け入れた反復だけを保持する。
[`GlmWorkspace`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/struct.GlmWorkspace.html) は `plan.workspace(options)` で作り、`last_attempt()` で最後の実行の記録を、`last_accepted()` で最後に受け入れた反復 [`GlmAccepted`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/struct.GlmAccepted.html) を返す。
ワンショット呼び出しがエラーを返した場合も、作業領域を使う形なら `last_accepted()` で途中の反復を調べられる。
[`glm_batch_into`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/fn.glm_batch_into.html) は 1 つの `PreparedGlm` で複数の応答を IRLS で当てはめ、入力 `GlmBatchInputs`、応答ごとの出力 `GlmBatchOutput`（出力とレポート）、ワーカーごとの作業領域 `GlmBatchWorkspace`（`plan.batch_workspace` で作る）を使う。

設計が疎な行列や作用素なら [`PreparedOperatorGlm`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/struct.PreparedOperatorGlm.html) を使う。
モデルと IRLS は同じだが、各反復の重み付き最小二乗問題を前の係数から始める LSMR で解き、反復の上限は `GlmOptions::factor_iterations` である。
LSMR はランクを求めないので、結果にランク・分散パラメータ・自由度はなく、共分散も計算しない。
作業領域は [`GlmOperatorWorkspace`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/struct.GlmOperatorWorkspace.html) で、`Injected` の求解法は `NotImplemented` になる。

## 交差点の事故件数の Poisson 回帰

次のセルは、3 か所の交差点で 1 日の事故件数を 5 日ずつ数えた計数に、Poisson 回帰を当てはめる。
設計は切片と交差点 2・3 の指示変数で、$\ln\mu_g=\beta_0+\beta_g$ である。
この 1 因子の対数線形モデルでは、各群のスコア方程式が $\sum_{i\in g}(y_i-\mu_g)=0$ になるので、最尤推定は群の平均 $\hat\mu_g=\bar y_g$ で、係数は $\hat\beta_0=\ln\bar y_1$、$\hat\beta_g=\ln(\bar y_g/\bar y_1)$ である。
Fisher 情報量から、`Model` の標準誤差も $\mathrm{se}(\hat\beta_0)=1/\sqrt{n_1\bar y_1}$、$\mathrm{se}(\hat\beta_g)=\sqrt{1/(n_1\bar y_1)+1/(n_g\bar y_g)}$ という閉形式になる。
逸脱度は $D=2\sum_i y_i\ln(y_i/\bar y_{g(i)})$ である（群の中で $\sum(y_i-\bar y_g)=0$）。

入力の場面を変えると、終了状態の各場合を再現する。
「反復の上限 3 回」は収束の前に止め、「交差点 3 の計数がすべて 0」は Poisson の最尤推定が存在しない場合、「二項で群 3 がすべて失敗」は同じ配置の 0/1 応答をロジスティック回帰で当てはめた準完全分離、「列が線形従属」は交差点 2 と 3 の指示変数の和をもう 1 列加えた設計である。

## ロバスト回帰と傾き

最小二乗推定は、1 つの観測を任意に動かすだけで推定値をいくらでも動かせる（崩壊点 $1/n$、漸近的に 0）。
ロバスト回帰は外れ値の影響に上限を設けた推定である。

### Huber の M 推定

Huber（1964）の M 推定は、残差を尺度で割った値に次の損失を当てて和を最小にする。

$$
\hat\beta=\arg\min_\beta\sum_i\rho_c\!\left(\frac{y_i-x_i^{\mathsf T}\beta}{\hat\sigma}\right),\qquad
\rho_c(u)=\begin{cases}u^2/2&(|u|\le c)\\ c|u|-c^2/2&(|u|>c)\end{cases}
$$

損失の導関数 $\psi_c(u)=\max(-c,\min(c,u))$ が有界なので、大きな残差の影響は $c\hat\sigma$ で頭打ちになる。
[`PreparedHuber`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/struct.PreparedHuber.html) は IRLS（Holland and Welsch 1977）で解く。
最初の反復は通常の最小二乗で、以降は前の残差から重み $w_i=\min(1,c\hat\sigma/|r_i|)$ を作って重み付き最小二乗を薄い SVD で解き、尺度 $\hat\sigma=\mathrm{MAD}(r)/0.6745$（残差の中央値からの絶対偏差の中央値を正規分布で較正したもの）を反復ごとに推定し直す。
係数の最大の変化が許容誤差を満たすと `Converged`、すべての残差が丸めの範囲で 0 になると `ExactFit`（尺度 0）で止まる。
1 回の反復は $O(np^2)$ である。

[`HuberOptions`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/struct.HuberOptions.html) の既定は、正規分布のもとで漸近効率 95% になる $c=1.345$、反復 100 回、各 SVD の反復 4096 回である。
重み付き設計が数値的にランク落ちしたとき、および完全な当てはめでないのに MAD が 0 のときは、終了状態ではなく `InvalidInput` のエラーになる。
M 推定は応答の外れ値には強いが、説明変数の外れ値（てこ比の大きい点）には弱く、そのような点が 1 つあれば推定を壊せる。

結果は [`HuberFit`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/struct.HuberFit.html)（`plan.fit(&y)` の所有型）か、出力先を指定する API `fit_into` の [`HuberOutput`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/struct.HuberOutput.html) が返す [`HuberFitView`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/struct.HuberFitView.html) で読み、係数、残差、最後の重み、尺度、反復の数、ランク、レポート `HuberReport`（終了状態、計数、受け入れた反復の数）を持つ。
[`HuberWorkspace`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/struct.HuberWorkspace.html) の `last_accepted()` は、最後に受け入れた反復を [`HuberAccepted`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/struct.HuberAccepted.html) で返す。
`huber_location(&x)` は 1 の列だけの設計による位置の M 推定である。

### Theil–Sen と Siegel の傾き

説明変数が 1 つの直線には、順位に基づく傾きの推定がある。
Theil–Sen 推定（Theil 1950、Sen 1968）は $x_i\ne x_j$ のすべての対の傾き $(y_j-y_i)/(x_j-x_i)$ の中央値で、崩壊点は $1-1/\sqrt2\approx29\%$ である。
Sen の信頼区間は、Kendall の統計量の分散 $\mathrm{Var}(S)$（$x$ と $y$ の同順位を補正）から $C=z\sqrt{\mathrm{Var}(S)}$ を求め、$N$ 個の対の傾きの $(N-C)/2$ 番目と $(N+C)/2+1$ 番目の順序統計量を端点にする。
Siegel（1982）の繰り返し中央値は $\mathrm{median}_i\,\mathrm{median}_{j\ne i}(y_j-y_i)/(x_j-x_i)$ で、崩壊点は 50% だが、区間は返さない。
どちらも計算量は $O(n^2)$ で、中央値は並べ替えではなく選択で求める。
Theil–Sen は $n(n-1)/2$ 個の傾きを保持するので $O(n^2)$ のメモリを使い、Siegel は $O(n)$ である。

[`RobustIntercept`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/enum.RobustIntercept.html) で切片の推定を選ぶ。
既定の `Joint` は $\mathrm{median}_i(y_i-\hat\beta_1x_i)$、`Separate` は Theil–Sen では $\mathrm{median}(y)-\hat\beta_1\mathrm{median}(x)$、Siegel では切片の繰り返し中央値である。
`robust_slope(&x, &y, method)` は `Joint` と 95% のワンショット呼び出しで、`robust_slope_with_options` で切片の推定と信頼係数を選べる。
同じ大きさの問題を繰り返すときは [`RobustSlopeWorkspace`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/struct.RobustSlopeWorkspace.html) を `RobustSlopeWorkspace::new(n, method, options)` で作り、`evaluate` を呼ぶ。
結果の [`RobustSlope`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/struct.RobustSlope.html) は傾き、切片、Sen の区間（Siegel では `None`）、推定の種類を持つ。

最小トリム二乗（LTS）、最小メディアン二乗（LMS）、MM 推定、S 推定、Tukey の双重み、分位点回帰は提供しない。
説明変数が複数あって説明変数の外れ値も疑われる場合は、scioxide-stats の推定では崩壊点を高くできないので、外れ値の診断（残差とてこ比）を先に行う。

## 直交距離回帰（ODR）

説明変数にも測定誤差があるモデル（errors-in-variables）を考える。
真の値 $t_i$ に対して $x_i=t_i+\delta_i$、$y_i=\beta_0+\beta_1t_i+\varepsilon_i$ で、$\delta_i$ と $\varepsilon_i$ は独立に標準偏差 $\sigma_x$、$\sigma_y$ の正規分布に従うとする。
$y$ を $x$ に最小二乗で回帰すると、傾きは $\beta_1$ ではなく、信頼性比 $\kappa=\sigma_t^2/(\sigma_t^2+\sigma_x^2)$（$\sigma_t^2$ は真の値の分散）を掛けた $\kappa\beta_1$ に近づく（希釈、attenuation、Fuller 1987）。
この偏りは $n$ を増やしても消えない。

直交距離回帰は、説明変数の補正 $\delta_i$ も未知数にして、次の重み付き距離の和を最小にする。

$$
S(\beta,\delta)=\sum_i\left[\sum_j\left(\frac{\delta_{ij}}{\sigma_{x,ij}}\right)^2+\sum_j\left(\frac{f_j(\beta,x_i+\delta_i)-y_{ij}}{\sigma_{y,ij}}\right)^2\right]
$$

誤差が正規なら、これは $(\beta,\delta)$ の最尤推定である。
アフィンモデル $y=\beta_0+\beta_1x_1+\dots+\beta_px_p$ で、標準偏差が観測によらないとき、[`linear_odr_with_options`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/fn.linear_odr_with_options.html) は閉形式で解く。
中心化した $[X\ y]$ の各列を標準偏差で割り、薄い SVD の最小特異値 $\sigma_{\min}$ の右特異ベクトル $v$ を超平面の法線とする（尺度を合わせた全最小二乗、Golub and Van Loan 1980）。
傾きは $\beta_j=-\sigma_yv_j/(\sigma_jv_y)$、最小の目的関数は $\sigma_{\min}^2$ で、計算量は $O(n(p+1)^2)$、最適化法は使わない。
説明変数が 1 つなら、これは誤差分散の比 $\lambda=\sigma_y^2/\sigma_x^2$ が既知の Deming 回帰で、傾きは次の閉形式になる。

$$
\hat\beta_1=\frac{S_{yy}-\lambda S_{xx}+\sqrt{(S_{yy}-\lambda S_{xx})^2+4\lambda S_{xy}^2}}{2S_{xy}}
$$

傾きは $\sigma_x$ と $\sigma_y$ の比だけで決まり、両方を同じ倍率で変えても変わらない。
目的関数の値は倍率の 2 乗に反比例する。
比を誤って与えると推定は偏るので、反復測定などで誤差の標準偏差を別に見積もってから使う。

`linear_odr_with_options` は、最小の 2 つの特異値の差が $\varepsilon\max(n,p+1)\sigma_1$ 以下（超平面が一意でない）のときと、超平面が応答の軸とほぼ平行（$|v_y|\le(p+1)\varepsilon$）のときに `InvalidInput` を返す。
結果の [`OdrFit`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/struct.OdrFit.html) は係数（切片、傾きの順）、観測ごとの補正 $\delta$、レポート [`OdrReport`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/struct.OdrReport.html) を持つ。
レポートは終了状態（閉形式では常に `Converged`）、目的関数の値 `chi_square`、計数（閉形式では 0）、識別可能性の診断 [`OdrIdentifiabilityDiagnostic`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/enum.OdrIdentifiabilityDiagnostic.html) を持つ。
閉形式の診断は `SingularGap { gap, threshold }` で、最小の 2 つの特異値の差と閾値である。
`linear_odr` は `OdrOptions`（バイト数の上限だけを持つ）を既定にしたワンショット呼び出しである。

非線形のモデルには [`PreparedOdr`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/struct.PreparedOdr.html) を使う。
モデルは [`OdrModel`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/trait.OdrModel.html) の実装で与え、パラメータの数・説明変数の数・応答の数と、応答 $f_r(\beta,x)$、その $\beta_j$ と $x_j$ についての偏導関数を返す。
補正後の説明変数 $x+\delta$ は [`OdrPredictors`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/struct.OdrPredictors.html) で受け取る。
[`AffineOdrModel`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/struct.AffineOdrModel.html) はアフィンモデルの実装で、観測ごとに標準偏差が違う直線の ODR に使える。
`PreparedOdr` は scioxide-stats の中に最適化法を持たず、`FitObjective` と `FitDerivatives`（$n(p+q)$ 個の残差とその Jacobi 行列）を実装した目的関数として、利用者の `FitSolver`（Levenberg–Marquardt 法など、Boggs, Byrd and Schnabel 1987）に渡す。
[`OdrInputs`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/struct.OdrInputs.html) は初期点 $z=[\beta,\delta]$（`initial_parameters` で作れる）、上下限、整数の制約、求解法をまとめ、`fit_into` は [`OdrOutput`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/struct.OdrOutput.html) と [`OdrWorkspace`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/struct.OdrWorkspace.html) に書く。
終了状態は求解法が返した `StatsTermination` である。
`local_identifiability(z)` は点 $z$ での残差の Jacobi 行列（$n(p+q)$ 行、$k+np$ 列）の数値的なランクを薄い SVD で求め、[`OdrIdentifiability`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/struct.OdrIdentifiability.html) で返す。
補正の $np$ 列は常にフルランクなので、ランクから $np$ を引いた `coefficient_rank` がパラメータの数 $k$ より小さければ、その点の近くでデータがパラメータを決めていない。
`gaussian_negative_log_likelihood(z)` は正規の誤差モデルの負の対数尤度を、定数項を含めて返す。

相関のある誤差と陰的なモデルは提供しない。
係数の標準誤差も返さないので、必要なら観測の組を [リサンプリング](../resampling/) のブートストラップでリサンプリングして求める。

## 2 つの測定法の比較での外れ値と測定誤差

次のセルは同じ試料を 2 つの方法で測った方法比較の場面を作る。
真の値 $t_i$ は $[2,10]$ に等間隔の 20 点で、対照法の測定は $x_i=t_i+\delta_i$（$\sigma_x=1$）、新しい方法の測定は $y_i=0.5+1.1t_i+\varepsilon_i$（$\sigma_y=\sigma_x\sqrt\lambda$）である。
入力の外れ値の大きさは 19 番目の試料の $y$ に加える値である。
1 組のデータに、最小二乗、Huber、Theil–Sen、Siegel、ODR（既知の $\lambda$）を当てはめ、ODR の傾きを Deming の閉形式と、Theil–Sen の傾きを対の傾きの中央値の手計算と比べる。
さらに同じ設定のデータを 300 組作り、各推定の傾きの平均とその標準誤差を、真の傾き 1.1 と、外れ値がないときの最小二乗の傾きの期待値と比べる。
最小二乗の傾き $b=S_{xy}/S_{xx}$ について、$S_{tt}=\sum_i(t_i-\bar t)^2$、$D=S_{xx}$ とおくと $\mathrm E[S_{xy}]=\beta_1S_{tt}$、$\mathrm E[D]=S_{tt}+(n-1)\sigma_x^2$、$\mathrm{Var}(D)=4\sigma_x^2S_{tt}+2(n-1)\sigma_x^4$、$\mathrm{Cov}(S_{xy},D)=2\beta_1\sigma_x^2S_{tt}$ である。
比の期待値をデルタ法で 2 次まで展開すると、次の近似になる。

$$
\mathrm E[b]\approx\frac{\beta_1S_{tt}}{\mathrm E[D]}\left(1-\frac{2\sigma_x^2}{\mathrm E[D]}+\frac{\mathrm{Var}(D)}{\mathrm E[D]^2}\right)
$$

この設定では 1 次の項 $\beta_1S_{tt}/\mathrm E[D]$ が 0.947、2 次の近似が 0.959 である。

```rust
//| id: stats-regression-comparison
//| ref: stats-regression-comparison
//| title: 方法比較のデータでの最小二乗・Huber・Theil–Sen・Siegel・ODR の傾き
//| run: button
//| crates: [scioxide-core, scioxide-linalg, scioxide-random, scioxide-stats]
//| inputs:
//|   outlier: {"type":"range","label":"19 番目の y に加える外れ値 [-]","min":0,"max":20,"step":2,"value":0}
//|   ratio: {"type":"select","label":"誤差分散の比 λ = σ_y² / σ_x²","options":["0.25","1","4"],"value":"1"}
//|   sampling_seed: {"type":"integer","label":"乱数のシード","min":0,"max":100000,"value":7}
//| cases:
//|   - {"id":"outlier","label":"外れ値 12","description":"最小二乗と ODR の傾きが大きく動き、Huber・Theil–Sen・Siegel はほとんど動かない。","inputs":{"outlier":12}}
//|   - {"id":"precise-y","label":"λ = 0.25","description":"y の誤差が小さい。ODR は最小二乗より急な傾きを返し、希釈を補正する。","inputs":{"ratio":"0.25"}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"slopes","path":"/rows/4/1","approx":{"value":1.0310822957963381,"rtol":1e-09}}
//|       - {"artifact":"slopes","path":"/rows/4/3","approx":{"value":1.0310822957963381,"rtol":1e-09}}
//|       - {"artifact":"slopes","path":"/rows/2/3","approx":{"value":0.9241637563233183,"rtol":1e-09}}
//|       - {"artifact":"slopes","path":"/rows/2/1","approx":{"value":0.9241637563233183,"rtol":1e-09}}
//|       - {"artifact":"slopes","path":"/rows/0/4","range":{"min":0.935,"max":0.975}}
//|       - {"artifact":"slopes","path":"/rows/4/4","range":{"min":1.08,"max":1.12}}
//|       - {"artifact":"slopes","path":"/rows/5/4","approx":{"value":0.9592,"atol":0.0005}}
//|   - case: outlier
//|     expect:
//|       - {"artifact":"slopes","path":"/rows/0/4","approx":{"value":1.2661562549666567,"rtol":1e-06}}
//|       - {"artifact":"slopes","path":"/rows/1/4","approx":{"value":1.0170539805512073,"rtol":1e-06}}
//|       - {"artifact":"slopes","path":"/rows/4/4","approx":{"value":1.985066757597699,"rtol":1e-06}}
//|   - case: precise-y
//|     expect:
//|       - {"artifact":"slopes","path":"/rows/4/4","approx":{"value":1.0974951464685623,"rtol":1e-06}}
//|       - {"artifact":"slopes","path":"/rows/4/3","approx":{"value":1.0351768832191592,"rtol":1e-09}}
use scioxide_core::RealScalar;
use scioxide_linalg::Matrix;
use scioxide_random::{Distribution, Normal, SeedableRng, SplitMix64};
use scioxide_stats::{
    HuberOptions, PreparedHuber, RobustSlopeMethod, linear_odr, ordinary_least_squares,
    robust_slope,
};

let n = 20;
let lambda: f64 = ratio.parse().map_err(|_| "λ が数でない")?;
let (sx, sy) = (1.0, RealScalar::sqrt(lambda));
let t: Vec<f64> = (0..n)
    .map(|i| 2.0 + 8.0 * i as f64 / (n - 1) as f64)
    .collect();
let normal = Normal::<f64>::new(0.0, 1.0).map_err(|e| e.to_string())?;
let mut rng = SplitMix64::from_seed(sampling_seed as u64);
let mut draw = || -> Result<(Vec<f64>, Vec<f64>), String> {
    let (mut x, mut y) = (Vec::with_capacity(n), Vec::with_capacity(n));
    for &ti in &t {
        x.push(ti + sx * normal.sample(&mut rng).map_err(|e| e.to_string())?);
        y.push(0.5 + 1.1 * ti + sy * normal.sample(&mut rng).map_err(|e| e.to_string())?);
    }
    y[n - 2] += outlier;
    Ok((x, y))
};
// 5 つの推定の (傾き, 切片)
let estimate = |x: &[f64], y: &[f64]| -> Result<[(f64, f64); 5], String> {
    let rows: Vec<f64> = x.iter().flat_map(|&v| [1.0, v]).collect();
    let design = Matrix::from_vec(n, 2, rows).map_err(|e| e.to_string())?;
    let ols = ordinary_least_squares(design.view(), y).map_err(|e| e.to_string())?;
    let huber = PreparedHuber::new(design.view(), HuberOptions::default())
        .map_err(|e| e.to_string())?
        .fit(y)
        .map_err(|e| e.to_string())?;
    let ts = robust_slope(x, y, RobustSlopeMethod::TheilSen).map_err(|e| e.to_string())?;
    let sg = robust_slope(x, y, RobustSlopeMethod::Siegel).map_err(|e| e.to_string())?;
    let predictors = Matrix::from_vec(n, 1, x.to_vec()).map_err(|e| e.to_string())?;
    let odr = linear_odr(predictors.view(), y, &[sx], sy).map_err(|e| e.to_string())?;
    let (b, h, o) = (
        ols.coefficients().as_slice(),
        huber.coefficients().as_slice(),
        odr.coefficients(),
    );
    Ok([
        (b[1], b[0]),
        (h[1], h[0]),
        (ts.slope(), ts.intercept()),
        (sg.slope(), sg.intercept()),
        (o[1], o[0]),
    ])
};
let (x, y) = draw()?;
let single = estimate(&x, &y)?;
// 独立な検算: Deming の閉形式と、対の傾きの中央値
let (mx, my) = (
    x.iter().sum::<f64>() / n as f64,
    y.iter().sum::<f64>() / n as f64,
);
let sxx: f64 = x.iter().map(|v| (v - mx) * (v - mx)).sum();
let syy: f64 = y.iter().map(|v| (v - my) * (v - my)).sum();
let sxy: f64 = x.iter().zip(&y).map(|(a, b)| (a - mx) * (b - my)).sum();
let gap = syy - lambda * sxx;
let deming = (gap + RealScalar::sqrt(gap * gap + 4.0 * lambda * sxy * sxy)) / (2.0 * sxy);
let mut slopes = Vec::new();
for i in 0..n {
    for j in i + 1..n {
        slopes.push((y[j] - y[i]) / (x[j] - x[i]));
    }
}
slopes.sort_by(f64::total_cmp);
let theil_sen = 0.5 * (slopes[slopes.len() / 2 - 1] + slopes[slopes.len() / 2]);
let names = [
    "最小二乗",
    "Huber",
    "Theil–Sen",
    "Siegel",
    "ODR（既知の λ）",
];
let checks = [None, None, Some(theil_sen), None, Some(deming)];
// 300 組の模擬: 傾きの平均と標準誤差
let m = 300;
let mut sum = [0.0; 5];
let mut sum2 = [0.0; 5];
for _ in 0..m {
    let (x, y) = draw()?;
    for (k, (slope, _)) in estimate(&x, &y)?.into_iter().enumerate() {
        sum[k] += slope;
        sum2[k] += slope * slope;
    }
}
let mut rows: Vec<_> = (0..5)
    .map(|k| {
        let mean = sum[k] / m as f64;
        let var = (sum2[k] - m as f64 * mean * mean) / (m as f64 - 1.0);
        let se = RealScalar::sqrt(var / m as f64);
        let (slope, intercept) = single[k];
        (
            names[k],
            Some(slope),
            Some(intercept),
            checks[k],
            mean,
            Some(se),
        )
    })
    .collect();
// 外れ値がないときの最小二乗の傾きの期待値の 2 次の近似（デルタ法）
// D = S_xx として E[D] = S_tt + (n − 1)σ_x²、Var(D) = 4σ_x² S_tt + 2(n − 1)σ_x⁴、
// E[b] ≈ β₁ S_tt / E[D] · (1 − 2σ_x² / E[D] + Var(D) / E[D]²)
let tbar = t.iter().sum::<f64>() / n as f64;
let stt: f64 = t.iter().map(|v| (v - tbar) * (v - tbar)).sum();
let (s2, nm1) = (sx * sx, n as f64 - 1.0);
let mean_d = stt + nm1 * s2;
let var_d = 4.0 * s2 * stt + 2.0 * nm1 * s2 * s2;
let first = 1.1 * stt / mean_d;
let second = first * (1.0 - 2.0 * s2 / mean_d + var_d / (mean_d * mean_d));
rows.push((
    "最小二乗の期待値（2 次の近似）",
    None,
    None,
    None,
    second,
    None,
));
let fixed4 = serde_json::json!({ "fractionDigits": 4 });
let columns = serde_json::json!([
    { "key": "0", "label": "推定" },
    { "key": "1", "label": "傾き [-]", "type": "number", "format": fixed4, "nullText": "—" },
    { "key": "2", "label": "切片 [-]", "type": "number", "format": fixed4, "nullText": "—" },
    { "key": "3", "label": "傾きの検算 [-]", "type": "number", "format": fixed4, "nullText": "—" },
    { "key": "4", "label": "300 組の傾きの平均 [-]", "type": "number", "format": fixed4 },
    {
        "key": "5",
        "label": "平均の標準誤差 [-]",
        "type": "number",
        "format": fixed4,
        "nullText": "—"
    }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "slopes" })
);
let points: Vec<[f64; 2]> = x.iter().zip(&y).map(|(&a, &b)| [a, b]).collect();
let line = |slope: f64, intercept: f64| -> Vec<[f64; 2]> {
    [0.0, 12.0]
        .iter()
        .map(|&v| [v, intercept + slope * v])
        .collect()
};
emit_chart!(serde_json::json!({
    "kind": "xy",
    "xLabel": "対照法の測定 x [-]",
    "yLabel": "新しい方法の測定 y [-]",
    "dataZoom": true,
    "tooltip": true,
    "layers": [
        { "id": "data", "kind": "scatter", "name": "測定", "points": points },
        {
            "id": "truth",
            "kind": "line",
            "name": "真の関係 y = 0.5 + 1.1t",
            "points": line(1.1, 0.5),
            "style": { "lineType": "dashed" }
        },
        {
            "id": "ols",
            "kind": "line",
            "name": "最小二乗",
            "points": line(single[0].0, single[0].1)
        },
        {
            "id": "huber",
            "kind": "line",
            "name": "Huber",
            "points": line(single[1].0, single[1].1)
        },
        {
            "id": "theil-sen",
            "kind": "line",
            "name": "Theil–Sen",
            "points": line(single[2].0, single[2].1)
        },
        { "id": "odr", "kind": "line", "name": "ODR", "points": line(single[4].0, single[4].1) }
    ]
}));
```

外れ値のない既定の入力（$\lambda=1$、シード 7）では、300 組の平均で最小二乗の傾きは $0.953\pm0.007$ で、2 次の近似 0.959 と標準誤差の範囲で一致し、真の 1.1 より 13% 小さい。
ODR の傾きの平均は $1.100\pm0.009$ で、既知の $\lambda$ を与えれば希釈が補正される。
Huber（0.952）、Theil–Sen（0.967）、Siegel（0.990）は応答の外れ値に備えた推定で、説明変数の誤差は扱わないので、程度の差はあっても希釈される。
1 組目のデータでは、ODR の傾きは Deming の閉形式と、Theil–Sen の傾きは手計算の中央値と、丸め誤差の範囲で一致する。

外れ値 12 を加えると、300 組の平均で最小二乗の傾きは 1.266、ODR は 1.985 へ動き、Huber（1.017）、Theil–Sen（1.039）、Siegel（1.041）はほとんど動かない。
ODR は二乗の損失を使うので、外れ値には最小二乗と同じく弱く、この例では最小二乗より大きく動く。
$\lambda=0.25$（$y$ の誤差が小さい）でも ODR の平均は 1.097 で 1.1 に近く、$\lambda$ を正しく与えれば比によらず補正できる。
説明変数の誤差と外れ値が同時にある場合は、外れ値を診断で取り除いてから ODR を当てはめる。

## まとめ

線形回帰は `PreparedRegression` で設計を 1 回分解し、応答ごとに $O(np)$ で当てはめる。
ランク落ちの設計でも最小ノルム解と、当てはめ値・推定可能な対比は一意に決まり、推定可能でない対比は `InvalidInput` になる。
不均一分散が疑われるときは `RegressionCovariance::Hc3` を使い、自己相関には HAC を提供しないので塊のブートストラップか時系列モデルを使う。
一元配置分散分析は `PreparedGroups` と `compare_nested` のどちらでも同じ $F$ になり、多重比較は `pairwise` と `compare_control` で行う。
GLM は `GlmReport` の `termination` を `is_success()` で確かめ、`RankDeficient` と `Separated` では最尤推定が存在しないことを疑う。
応答の外れ値には Huber、Theil–Sen、Siegel を、説明変数の測定誤差には誤差分散の比を与えた ODR を使う。
