分位点 $Q(p)$ は確率 $p$ の点がどこにあるかを表すが、その先の裾にどれだけ大きな値があるかは表さない。
**裾平均**（tail mean）は、確率 $p$ より上側（または $p$ までの下側）の質量の平均で、金融では Expected Shortfall（ES）や CVaR と呼ぶ。
このページは、重み付きの経験分布関数と分位点、裾平均の定義と性質、同じ値の観測が境界に重なるときの質量の按分を説明する。
そのうえで、scioxide-stats の裾平均が返す情報の読み方を示し、分位点と裾平均の劣加法性を離散分布の例で確かめる。

## 重み付き経験分布関数

値 $x_i$ と非負の重み $w_i$（総重み $W = \sum w_i > 0$）の組に対し、重み付きの経験分布関数を次のように定める。

$$
F_w(x) = \frac{1}{W} \sum_{i=1}^n w_i\, \mathbf 1\{x_i \le x\}
$$

その左連続な逆関数は、累積重みが初めて $pW$ に達する観測を返す。

$$
Q_w(p) = \inf\{x : F_w(x) \ge p\}
$$

重みがすべて等しければ、これは型 1（`NearestRank`）の分位点と一致する。

相対的な質量の重みは `Weights::<_, Mass>` で渡す。
`EmpiricalDistribution::new(values, Weights::<_, Mass>::new(&masses))` は値と質量を複製して整列し、空の入力と負の質量と総質量 0 を `InvalidInput`、非有限値を `NonFinite` で拒む。
質量 0 の組は受け付けるが、台にも質量にも入らない。
`quantile` に `QuantileRule::inverse_ecdf()` を渡すと $Q_w(p)$ を返し、$p = 0$ では正の質量を持つ最小の観測を返す。
1 回だけの照会には、観測と質量の組の配列 `Weights<&mut [(S, S)], Mass>` を `quantile_in_place` に渡す。
呼び出し側の配列の上で決定論的な三方向の introselect を行うので、最悪 $O(n)$ で、確保をしない。
累積の質量は内部で正確な整数演算として足し合わせ、目標の質量 $pW$ との比較が丸めで揺れないようにしている。

質量の重みに対して定義できる分位点は、この逆関数（型 1 に当たる）だけである。
質量は標本の大きさを持たないので、補間の位置 $np + m$ が定まらないからである。
整数の度数なら、`Weights::<_, Frequency>` で九つの定義すべてを使える（[経験分布・標本分位点・補間規約の数理](oxref:stats-quantile-hyndman-fan-definitions)）。

## 裾平均の定義と性質

確率 $p \in (0, 1)$ の上側と下側の裾平均を、分位点関数の積分で次のように定める。

$$
\mathrm{ES}^{\mathrm{upper}}_p = \frac{1}{1-p} \int_p^1 Q(u)\,du, \qquad
\mathrm{ES}^{\mathrm{lower}}_p = \frac{1}{p} \int_0^p Q(u)\,du
$$

連続分布では $\mathrm{ES}^{\mathrm{upper}}_p = E[X \mid X \ge Q(p)]$ に等しい。
上側は損失や遅延のように大きいほど困る量、下側は強度や残量のように小さいほど困る量に使う。
`TailSide::Upper` と `TailSide::Lower` がこの二つを選ぶ。

上側の裾平均は、次の最小化問題の最小値としても表せる（Rockafellar と Uryasev, 2002）。

$$
\mathrm{ES}^{\mathrm{upper}}_p = \min_{c \in \mathbb R}\Bigl\{ c + \frac{1}{1-p} E\bigl[(X - c)_+\bigr] \Bigr\}
$$

最小点の一つが $c = Q(p)$ である。
この表現は、裾平均を目的関数に含む最適化（ポートフォリオの選択など）を線形計画に直すときに使う。
scioxide-stats はこの最小化を解かず、次節のとおり積分を直接評価する。

リスクの尺度 $\rho$ について、Artzner ら（1999）は次の四つの性質を満たすものを**コヒーレント**と呼んだ。
劣加法性 $\rho(X + Y) \le \rho(X) + \rho(Y)$、正の斉次性 $\rho(\lambda X) = \lambda \rho(X)$（$\lambda \ge 0$）、単調性（$X \le Y$ なら $\rho(X) \le \rho(Y)$）、平行移動に対する不変性 $\rho(X + c) = \rho(X) + c$ である。
劣加法性は、二つのリスクをまとめたときの尺度が個別の尺度の和を超えないこと、つまり分散投資で尺度が増えないことを表す。
分位点そのもの（金融では VaR と呼ぶ）は劣加法性を満たさない例があり、その例は[分位点の劣加法性が破れる例](#分位点の劣加法性が破れる例)の節で計算する。
分位点関数の積分で定めた裾平均は、四つの性質をすべて満たす（Acerbi と Tasche, 2002）。

この性質は分布の汎関数としてのもので、有限標本の推定値の精度とは別の話である。
裾の質量 $n(1-p)$ が小さいと、裾平均の推定値は少数の観測で決まり、標本ごとのばらつきが大きい。

## 境界の質量の按分

有限の標本では、上側の裾に入れるべき質量 $n(1-p)$ が整数とは限らず、境界の値に同じ値の観測が重なることもある。
境界の観測をすべて含めるかすべて除くと、裾の質量が $1-p$ からずれ、$p$ を少し動かしただけで裾平均が跳ぶ。
`TailMeanConvention::FractionalInverseEcdf` は、上の積分を経験分布の逆関数に対して正確に評価する。
重み付きの一般形で書くと、上側の目標の質量を $W_{\mathrm{tail}} = (1-p)W$、境界の値を $q$ として、次の手順になる。

1. $q$ より大きい観測の質量 $W_{>} = \sum_{x_i > q} w_i$ と、値の重み付きの和 $S_{>} = \sum_{x_i > q} w_i x_i$ を求める。
2. 境界の値 $q$ から取る質量を $\Delta = W_{\mathrm{tail}} - W_{>}$ とする。
   $q$ は $0 < \Delta \le \sum_{x_i = q} w_i$ となるように選ばれている。
3. 裾平均を次の式で求める。

$$
\mathrm{ES}^{\mathrm{upper}}_p = \frac{S_{>} + \Delta\, q}{W_{\mathrm{tail}}}
$$

分子は超過部分の和 $S_{>}$ と、境界の値から按分した質量の寄与 $\Delta q$ の和である。
分母を目標の質量 $W_{\mathrm{tail}}$ にそろえるので、写像 $p \mapsto \mathrm{ES}_p$ は連続になる。
下側の裾も同じように $pW$ の質量で求める。
下側の $p = 0$ と上側の $p = 1$ は空の裾なので `InvalidInput` になり、反対側の端点（下側の $p = 1$、上側の $p = 0$）は標本全体の平均を返す。

結果の `TailMeanResult` は、平均 `mean` のほかに、確率 `probability`、裾の側 `side`、規約 `convention`、裾の質量 `tail_mass`、境界の値 `boundary_value`、境界から取った質量 `boundary_mass`、その分子への寄与 `boundary_contribution` を持つ。
質量の単位は、重みなしでは観測の件数、質量の重みでは呼び出し側の重みの単位である。
補助の質量と寄与は、`S` で表せないとき `None` を返す。
平均が `S` で表せないときは、結果ではなく `Err` が返る。
質量の重みで、空でない裾の質量が 0 に丸まるときは `NumericalInstability` を返す。

裾平均を受け付ける重みは、trait `TailWeights` を実装する `Unweighted` と `Mass` である。
頻度重みの標本は度数を質量として渡せば同じ裾平均になる。
所有する配列をその場で整列する `tail_mean_in_place` は、重みなしの配列か観測と質量の組の配列を受け取り、一時領域を確保せずに $O(n \log n)$ で求める。
検査は配列を並べ替える前に済ませるので、失敗したときの配列は入力のままである。
整列済みの `EmpiricalDistribution::tail_mean` は $O(n)$ で求めるので、同じ標本に複数の水準を照会するときに向く。

## 水準を動かしたときの閾値と裾平均

右に長い裾を持つ 8 個の標本 $[1, 2, 3, 4, 7, 12, 20, 35]$ について、水準 $\alpha$ を 0.50 から 0.95 まで動かし、型 1 の分位点（閾値）と上側の裾平均を `quantile_in_place` と `tail_mean_in_place` で求める。
二つの関数は作業用の配列を並べ替えるので、各水準で同じ標本の複製を渡す。
裾平均は、整列した標本の上位 $\lfloor m \rfloor$ 個に次の観測の端数 $m - \lfloor m \rfloor$ を加える式（$m = 8(1-\alpha)$）で手計算した値と比べる（独立な検算）。
選んだ水準での境界の情報を表に出す。

```rust
//| id: stats-tail-mean-level
//| ref: stats-tail-mean-level
//| title: 分位点の水準を動かして閾値と上側の裾平均を比べる
//| run: reactive
//| crates: [scioxide-stats]
//| inputs:
//|   quantile_level: {"type":"range","label":"分位点の水準 α [-]","description":"上側に残す経験質量 1−α を変える。","min":0.5,"max":0.95,"step":0.01,"value":0.75}
//| cases:
//|   - {"id":"half","label":"α = 0.5","description":"裾の質量 4 件がちょうど上位 4 個に一致する。","inputs":{"quantile_level":0.5}}
//|   - {"id":"fractional","label":"α = 0.8","description":"裾の質量 1.6 件のうち 0.6 件を境界の値 20 から取る。","inputs":{"quantile_level":0.8}}
//|   - {"id":"thin-tail","label":"α = 0.95","description":"裾の質量が 0.4 件しかなく、最大値だけで決まる。","inputs":{"quantile_level":0.95}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"tail","path":"/rows/0/0","equals":12}
//|       - {"artifact":"tail","path":"/rows/0/1","approx":{"value":27.5,"atol":1e-13}}
//|       - {"artifact":"tail","path":"/rows/0/2","approx":{"value":2.0,"atol":1e-13}}
//|       - {"artifact":"tail","path":"/rows/0/3","equals":20}
//|       - {"artifact":"tail","path":"/rows/0/5","range":{"max":1e-13}}
//|   - case: half
//|     expect:
//|       - {"artifact":"tail","path":"/rows/0/1","approx":{"value":18.5,"atol":1e-13}}
//|       - {"artifact":"tail","path":"/rows/0/3","equals":7}
//|   - case: fractional
//|     expect:
//|       - {"artifact":"tail","path":"/rows/0/1","approx":{"value":29.375,"atol":1e-12}}
//|       - {"artifact":"tail","path":"/rows/0/4","approx":{"value":0.6,"atol":1e-12}}
//|   - case: thin-tail
//|     expect:
//|       - {"artifact":"tail","path":"/rows/0/1","approx":{"value":35.0,"atol":1e-12}}
//|       - {"artifact":"tail","path":"/rows/0/2","approx":{"value":0.4,"atol":1e-12}}
use scioxide_stats::{
    QuantileMethod, QuantileProbability, QuantileRule, TailMeanResult, TailSide,
    quantile_in_place, tail_mean_in_place,
};

// 右に長い裾を持つ標本（整列済み、単位なし）。
let sample = [1.0_f64, 2.0, 3.0, 4.0, 7.0, 12.0, 20.0, 35.0];
let evaluate = |alpha: f64| -> Result<(f64, TailMeanResult<f64>), String> {
    let p = QuantileProbability::new(alpha).map_err(|e| e.to_string())?;
    // 作業用の配列は呼び出しごとに複製する（関数が並べ替えるため）。
    let mut work = sample;
    let threshold =
        quantile_in_place(&mut work, p, QuantileRule::new(QuantileMethod::NearestRank))
            .map_err(|e| e.to_string())?
            .value();
    let mut work = sample;
    let tail = tail_mean_in_place(&mut work, p, TailSide::Upper).map_err(|e| e.to_string())?;
    Ok((threshold, tail))
};
// 独立な検算: 上位 floor(m) 個と次の観測の端数 m − floor(m) の平均（m = n(1 − α)）。
let by_hand = |alpha: f64| {
    let m = (1.0 - alpha) * sample.len() as f64;
    let whole = m.floor() as usize;
    let top: f64 = sample.iter().rev().take(whole).sum();
    let edge = if whole < sample.len() {
        (m - whole as f64) * sample[sample.len() - 1 - whole]
    } else {
        0.0
    };
    (top + edge) / m
};
let (mut thresholds, mut means, mut worst) = (Vec::new(), Vec::new(), 0.0_f64);
for i in 50..=95 {
    let alpha = f64::from(i) / 100.0;
    let (threshold, tail) = evaluate(alpha)?;
    worst = worst.max((tail.mean() - by_hand(alpha)).abs());
    thresholds.push([alpha, threshold]);
    means.push([alpha, tail.mean()]);
}
let (threshold, tail) = evaluate(quantile_level)?;
emit_line_chart!(
    &vec![
        serde_json::json!({"name": "型 1 の分位点（閾値）", "points": thresholds, "style": {"step": "end"}}),
        serde_json::json!({"name": "上側の裾平均", "points": means}),
    ],
    options = &serde_json::json!({
        "xLabel": "分位点の水準 α [-]",
        "yLabel": "標本の値 [-]",
        "xMin": 0.5,
        "xMax": 0.95,
        "yMin": 0.0,
        "yMax": 36.0,
        "annotations": [{"kind": "line", "axis": "x", "value": quantile_level, "label": "選んだ α"}]
    })
);
let fixed4 = serde_json::json!({ "fractionDigits": 4 });
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let columns = serde_json::json!([
    { "key": "0", "label": "閾値（型 1 の分位点） [-]", "type": "number", "format": fixed4 },
    { "key": "1", "label": "上側の裾平均 [-]", "type": "number", "format": fixed4 },
    { "key": "2", "label": "裾の質量 [件]", "type": "number", "format": fixed4, "nullText": "—" },
    { "key": "3", "label": "境界の値 [-]", "type": "number", "format": fixed4 },
    { "key": "4", "label": "境界から取った質量 [件]", "type": "number", "format": fixed4, "nullText": "—" },
    { "key": "5", "label": "手計算との差の最大（46 水準） [-]", "type": "number", "format": sci2 }
]);
let row = (
    threshold,
    tail.mean(),
    tail.tail_mass(),
    tail.boundary_value(),
    tail.boundary_mass(),
    worst,
);
emit_table_with_columns!(
    columns,
    vec![row],
    metadata = serde_json::json!({ "id": "tail" })
);
```

閾値（型 1 の分位点）は標本の値の間を跳ぶ階段になり、裾平均は水準について連続な折れ線になる。
既定の $\alpha = 0.75$ では裾の質量が $8 \times 0.25 = 2$ 件で、閾値は 12、裾平均は上位 2 個 35 と 20 の平均 27.5 である。
境界の値は 20 で、そこから質量 1 件をすべて取る。
閾値の 12 は裾の外にあり、裾平均は閾値を超えた観測だけの平均になっている。
$\alpha = 0.8$ では裾の質量が 1.6 件で、35 を 1 件と境界の値 20 を 0.6 件取り、裾平均は $(35 + 0.6 \cdot 20)/1.6 = 29.375$ になる。
$\alpha = 0.5$ では閾値 4 に対して裾平均 18.5（上位 4 個の平均）、$\alpha = 0.95$ では裾の質量が 0.4 件しかなく、裾平均は最大値 35 の端数だけで決まって閾値と同じ 35 になる。
46 個の水準のすべてで、裾平均は手計算の式と $7.1 \times 10^{-15}$ 以内で一致する。

## 分位点の劣加法性が破れる例

独立な二つの貸付 $X$、$Y$ が、それぞれ確率 $q$ で損失 100、確率 $1-q$ で損失 0 を生むとする。
合計 $X + Y$ は、損失 0、100、200 を確率 $(1-q)^2$、$2q(1-q)$、$q^2$ でとる。
$q \le 1 - \alpha < 1 - (1-q)^2$ のとき、$X$ と $Y$ の水準 $\alpha$ の分位点はどちらも 0 だが、合計の分位点は 100 になる。
二つをまとめると分位点が個別の和より大きくなり、劣加法性が破れる。
裾平均では、個別の値 $100\,q/(1-\alpha)$ の和が合計の値以上になる。

次のセルは、三つの分布を値と確率の組として `Weights::<_, Mass>` で `EmpiricalDistribution` に渡し、上側の水準 $\alpha$ の分位点（`QuantileRule::inverse_ecdf`）と上側の裾平均（`tail_mean`）を求める。
裾平均は、分位点関数の積分 $\frac{1}{1-\alpha}\int_\alpha^1 Q(u)\,du$ を各値の確率の区間ごとに足した値と比べる（独立な検算）。
最後の行は「個別の和 − 合計」で、負なら劣加法性が破れている。

```rust
//| id: stats-tail-subadditivity
//| ref: stats-tail-subadditivity
//| title: 二つの貸付の損失で分位点と裾平均の劣加法性を比べる
//| run: reactive
//| crates: [scioxide-stats]
//| inputs:
//|   default_probability: {"type":"range","label":"損失の確率 q [-]","description":"それぞれの貸付が損失 100 を生む確率。","min":0.01,"max":0.1,"step":0.01,"value":0.04}
//|   tail_level: {"type":"range","label":"水準 α [-]","description":"上側の裾に残す確率 1−α を決める。","min":0.9,"max":0.99,"step":0.01,"value":0.95}
//| cases:
//|   - {"id":"rare-loss","label":"q = 0.01","description":"(1 − q)² ≥ α なので、合計の分位点も 0 で、劣加法性は破れない。","inputs":{"default_probability":0.01}}
//|   - {"id":"high-level","label":"α = 0.99","description":"q ≥ 1 − α なので個別の分位点が 100 になり、劣加法性は破れない。","inputs":{"tail_level":0.99}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"risk","path":"/rows/0/1","equals":0}
//|       - {"artifact":"risk","path":"/rows/2/1","equals":100}
//|       - {"artifact":"risk","path":"/rows/0/2","approx":{"value":80.0,"atol":1e-9}}
//|       - {"artifact":"risk","path":"/rows/2/2","approx":{"value":103.2,"atol":1e-9}}
//|       - {"artifact":"risk","path":"/rows/2/3","range":{"min":-1e-11,"max":1e-11}}
//|       - {"artifact":"risk","path":"/rows/3/1","equals":-100}
//|   - case: rare-loss
//|     expect:
//|       - {"artifact":"risk","path":"/rows/2/1","equals":0}
//|       - {"artifact":"risk","path":"/rows/3/2","approx":{"value":0.0,"atol":1e-9}}
//|   - case: high-level
//|     expect:
//|       - {"artifact":"risk","path":"/rows/3/1","equals":100}
//|       - {"artifact":"risk","path":"/rows/2/2","approx":{"value":116.0,"atol":1e-9}}
use scioxide_stats::{
    EmpiricalDistribution, Mass, QuantileProbability, QuantileRule, TailSide, Weights,
};

let q = default_probability;
let alpha = QuantileProbability::new(tail_level).map_err(|e| e.to_string())?;
let single = (vec![0.0_f64, 100.0], vec![1.0 - q, q]);
let total = (
    vec![0.0_f64, 100.0, 200.0],
    vec![(1.0 - q) * (1.0 - q), 2.0 * q * (1.0 - q), q * q],
);
// 独立な検算: Q(u) は値 x_k を確率の区間 [F(x_{k−1}), F(x_k)) でとるので、[α, 1] との重なりを足す。
let by_hand = |values: &[f64], masses: &[f64]| {
    let (mut lower, mut integral) = (0.0_f64, 0.0_f64);
    for (&x, &m) in values.iter().zip(masses) {
        let upper = lower + m;
        integral += x * (upper.min(1.0) - lower.max(tail_level)).max(0.0);
        lower = upper;
    }
    integral / (1.0 - tail_level)
};
let measure = |(values, masses): &(Vec<f64>, Vec<f64>)| -> Result<(f64, f64, f64), String> {
    let law = EmpiricalDistribution::new(values, Weights::<_, Mass>::new(masses))
        .map_err(|e| e.to_string())?;
    let var = law
        .quantile(alpha, QuantileRule::inverse_ecdf())
        .map_err(|e| e.to_string())?
        .value();
    let es = law
        .tail_mean(alpha, TailSide::Upper)
        .map_err(|e| e.to_string())?
        .mean();
    Ok((var, es, es - by_hand(values, masses)))
};
let (single_var, single_es, single_check) = measure(&single)?;
let (total_var, total_es, total_check) = measure(&total)?;
let rows = vec![
    (
        "X（一つ目の貸付）",
        single_var,
        single_es,
        Some(single_check),
    ),
    (
        "Y（二つ目の貸付）",
        single_var,
        single_es,
        Some(single_check),
    ),
    ("X + Y", total_var, total_es, Some(total_check)),
    (
        "個別の和 − 合計",
        2.0 * single_var - total_var,
        2.0 * single_es - total_es,
        None,
    ),
];
let fixed2 = serde_json::json!({ "fractionDigits": 2 });
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let columns = serde_json::json!([
    { "key": "0", "label": "損失", "type": "string" },
    { "key": "1", "label": "分位点（VaR） [-]", "type": "number", "format": fixed2 },
    { "key": "2", "label": "上側の裾平均（ES） [-]", "type": "number", "format": fixed2 },
    { "key": "3", "label": "裾平均と積分の差 [-]", "type": "number", "format": sci2, "nullText": "—" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "risk" })

```

既定の $q = 0.04$、$\alpha = 0.95$ では、個別の分位点はどちらも 0 で、合計の分位点は 100 になり、個別の和から合計を引いた値は $-100$ である。
裾平均は個別に $100 \times 0.04/0.05 = 80$、合計で 103.2 で、個別の和 160 から合計を引いた値は 56.8 と正である。
合計の裾平均 103.2 は、損失 200 の確率 0.0016 と、損失 100 から取る確率 0.0484 を、裾の確率 0.05 で割った値 $(0.0016 \cdot 200 + 0.0484 \cdot 100)/0.05$ に等しい。
`tail_mean` の値と分位点関数の積分の差は $10^{-13}$ 以下で、差は確率の値の丸めによる。

$q = 0.01$ では $(1-q)^2 = 0.9801 \ge 0.95$ なので合計の分位点も 0 になり、分位点の劣加法性は破れない。
このとき裾平均は個別に 20、合計で 40 で、二つの裾が同じ事象（損失 100）の範囲に入るので、丸めを除いて等号が成り立つ。
$\alpha = 0.99$ では個別の分位点が 100 になり、個別の和 200 は合計の分位点 100 より大きい。
分位点が劣加法性を破るのは、まれな損失の確率が $1 - \alpha$ を下回り、個別には裾の外に隠れるが、合計すると裾に入る場合である。

## まとめ

裾平均は分位点の先の質量全体の平均で、分位点関数の積分として定めると劣加法性を持ち、水準について連続になる。
分位点そのものは劣加法性を持たず、まれな損失を二つまとめると個別の和より大きくなることがある。
離散の標本では境界の観測を端数の質量だけ含めることで積分を正確に評価でき、`FractionalInverseEcdf` の規約はこの按分を行う。
結果の `TailMeanResult` は裾の質量と境界の情報を残すので、裾に実際に何件分の質量が入ったかを確かめてから値を読む。
裾の質量が 1 件に満たない水準では、推定値は最大値に近い少数の観測で決まる。
