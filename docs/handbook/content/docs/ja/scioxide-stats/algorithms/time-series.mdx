1 時間ごとの室温、毎日の売上、センサーの出力のように、等間隔の時刻で観測した値の列を時系列と呼ぶ。
時系列の隣り合う値は互いに独立ではなく、今の値は直前の値に似ていることが多い。
独立な標本を前提にした標準誤差や検定をそのまま使うと、この依存を無視して不確かさを小さく見積もる。
時系列解析では、まず依存の構造を自己相関で測り、次にその構造を表すモデル（ARIMA モデル）を当てはめて、予測とその不確かさを求める。

このページは、`scioxide-stats` が提供する次の 3 つを、定義、推定法、API、実験の順に説明する。

- 標本自己共分散、自己相関（ACF）、偏自己相関（PACF）
- ペリオドグラムによるスペクトルの記述
- ARIMA モデルの正確な正規尤度、その最尤推定、予測と予測区間

## 定常性と自己相関

### 弱定常過程

時系列 $\{x_t\}$ が弱定常（2 次定常）であるとは、平均 $E[x_t] = \mu$ が $t$ によらず、共分散 $\mathrm{Cov}(x_t, x_{t-k})$ が時刻の差 $k$ だけで決まることをいう。
このときの $\gamma(k) = \mathrm{Cov}(x_t, x_{t-k})$ を自己共分散関数、$\rho(k) = \gamma(k)/\gamma(0)$ を自己相関関数（ACF）と呼ぶ。
自己共分散関数は半正定値である。
つまり、任意の $m$ について Toeplitz 行列 $\Gamma_m = [\gamma(i - j)]_{i,j=1}^{m}$ が半正定値になる。
傾向（トレンド）や季節変動のある系列は定常でないので、差分や回帰でそれを除いてから自己相関を測る。

### 標本自己共分散と除数の選び方

観測 $x_1, \dots, x_n$ と中心 $\bar x$ から、標本自己共分散を

$$
\hat\gamma(k) = \frac{1}{D_k} \sum_{t=k+1}^{n} (x_t - \bar x)(x_{t-k} - \bar x)
$$

で計算する。
除数 $D_k$ には 2 つの選び方があり、[`LagNormalization`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/enum.LagNormalization.html) で選ぶ。

- `ObservationCount`（既定）: すべてのラグで $D_k = n$ とする。
  $\hat\gamma(k)$ は 0 に向かって偏るが、列 $\hat\gamma(0), \hat\gamma(1), \dots$ が半正定値になる。
  Yule–Walker 方程式や Levinson–Durbin 再帰の係数行列が正定値になることを保証するので、モデルの同定にはこちらを使う（Brockwell–Davis §7.2）。
- `PairCount`: ラグ $k$ の組の数 $D_k = n - k$ で割る。
  大きなラグでの偏りは小さいが、列が半正定値になるとは限らず、大きなラグの値の分散は大きい。

中心は [`TimeSeriesCentering`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/enum.TimeSeriesCentering.html) で選ぶ。
既定の `SampleMean` は標本平均を引き、`KnownZero` は平均が 0 と分かっている系列（差分した系列や、モデルの一期先予測誤差の列など）で何も引かない。
平均が 0 でない系列に `KnownZero` を使うと、$\hat\gamma(k)$ に $\mu^2$ が加わり、すべてのラグの自己相関が 1 に近くなる。

標本自己相関 $\hat\rho(k) = \hat\gamma(k)/\hat\gamma(0)$ の不確かさは、Bartlett の公式で近似できる。
系列が白色雑音（すべての $k \ge 1$ で $\rho(k) = 0$）なら、$\hat\rho(k)$ は近似的に $\mathrm{N}(0, 1/n)$ に従う。
ACF の図に $\pm 1.96/\sqrt{n}$ の線を引くのはこのためで、これは各ラグの点ごとの 95 % の範囲であり、20 個のラグを見れば 1 個ははみ出すのがふつうである。

### 偏自己相関と Levinson–Durbin 再帰

$\rho(k)$ は、間にある $x_{t-1}, \dots, x_{t-k+1}$ を経由した相関も含む。
偏自己相関 $\phi_{kk}$ は、間の値で線形に予測した残りどうしの相関で、次数 $k$ の自己回帰 $x_t = \phi_{k1}x_{t-1} + \dots + \phi_{kk}x_{t-k} + e_t$ を Yule–Walker 方程式

$$
\begin{bmatrix} \rho(0) & \cdots & \rho(k-1) \\ \vdots & \ddots & \vdots \\ \rho(k-1) & \cdots & \rho(0) \end{bmatrix}
\begin{bmatrix} \phi_{k1} \\ \vdots \\ \phi_{kk} \end{bmatrix}
=
\begin{bmatrix} \rho(1) \\ \vdots \\ \rho(k) \end{bmatrix}
$$

で当てはめたときの最後の係数に等しい。
係数行列は Toeplitz 行列なので、Levinson–Durbin 再帰で次数 1 から順に解ける。
次数 $k$ の解は次数 $k - 1$ の解から

$$
\phi_{kk} = \frac{\rho(k) - \sum_{j=1}^{k-1} \phi_{k-1,j}\,\rho(k-j)}{v_{k-1}},
\qquad
\phi_{kj} = \phi_{k-1,j} - \phi_{kk}\,\phi_{k-1,k-j},
\qquad
v_k = v_{k-1}(1 - \phi_{kk}^2)
$$

で作れ（$v_0 = 1$）、$L$ 個のラグまでの計算量は $O(L^2)$ である。
$v_k$ は標準化した予測誤差の分散で、$|\phi_{kk}| < 1$ である限り正のまま減っていく。
`scioxide-stats` は、$|\phi_{kk}| \ge 1$ になったとき、または $v_k$ が機械イプシロンを下回ったときに `InvalidInput` を返す。
`ObservationCount` の除数ではこれは起こらないはずで、起きるのは `PairCount` で列が半正定値でなくなったときか、系列がほぼ決定論的なときである。

### 自己回帰過程の自己相関

1 次の自己回帰過程 AR(1)

$$
x_t - \mu = \phi\,(x_{t-1} - \mu) + \varepsilon_t,
\qquad
\varepsilon_t \sim \mathrm{N}(0, \sigma^2)\ \text{独立},
\qquad
|\phi| < 1
$$

は定常で、$\gamma(0) = \sigma^2/(1 - \phi^2)$、$\rho(k) = \phi^k$ となる。
偏自己相関は $\phi_{11} = \phi$、$k \ge 2$ で $\phi_{kk} = 0$ である。
一般に AR($p$) の PACF は次数 $p$ より先で 0 になり、MA($q$) の ACF は $q$ より先で 0 になる。
この切れ方が、Box–Jenkins の方法でモデルの次数を決める手がかりになる。
$k > p$ の $\hat\phi_{kk}$ は近似的に $\mathrm{N}(0, 1/n)$ に従う（Quenouille）。

AR(1) の Yule–Walker 推定は $\hat\phi = \hat\rho(1)$、$\hat\sigma^2 = \hat\gamma(0)(1 - \hat\phi^2)$ で、その漸近分散は $\mathrm{Var}\,\hat\phi \approx (1 - \phi^2)/n$ である。
`scioxide-stats` は Yule–Walker 推定量を関数としては提供せず、ACF と PACF から上の式で組み立てる。

## 自己相関および偏自己相関の計算

[`time_series_summary`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/fn.time_series_summary.html)`(&x, statistic, max_lag)` は、統計量 [`TimeSeriesStatistic`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/enum.TimeSeriesStatistic.html)（`Covariance`、`Acf`、`Pacf`）をラグ $0, \dots, \mathrm{max\_lag}$ で計算し、`max_lag + 1` 個の [`TimeSeriesLag`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/struct.TimeSeriesLag.html) を返す。
各要素は値 `value` と、そのラグで両方の観測がそろった組の数 `pairs` を持つ。
ラグ 0 の ACF と PACF は 1 である。
ワンショット呼び出しの形は標本平均で中心化し、`ObservationCount` で割る。

オプション付き形式 `time_series_summary_with_options(values, validity, statistic, max_lag, summary, options)` は、欠測マスク `validity`、除数と中心化の [`TimeSeriesOptions`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/struct.TimeSeriesOptions.html)、欠測と非有限値の方針とメモリ使用量の上限の `StatisticsOptions` を受け取る。
欠測を `MissingPolicy::Skip` で飛ばすと、その位置は時間の格子に空いたまま残り、後の観測をずらさない。
欠測はそれを含む組をすべてのラグから除き、`pairs` を減らす。
`MissingPolicy::Reject`（既定）では、欠測があると `InvalidInput` を返す。

作業領域を渡す形 [`time_series_summary_into`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/fn.time_series_summary_into.html)`(values, validity, statistic, max_lag, summary, options, &mut output, &mut ws, context)` は、出力と [`TimeSeriesWorkspace`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/struct.TimeSeriesWorkspace.html) を呼び出し側が持つ。
`TimeSeriesWorkspace::scalar_requirements(samples, max_lag, options)` が [`TimeSeriesRequirements`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/struct.TimeSeriesRequirements.html) を返し、`workspace(&req)` が作業領域を作る。
実数の系列では、必要なバイト数 `required_bytes()` は系列の長さによらず、ラグの数で決まる。
同じ作業領域で、ACF と PACF のように統計量を変えて何度でも計算できる。
複数の系列（多チャネルのセンサーなど）を `BatchView` の各レコードとしてまとめて計算するには `time_series_summaries_into` を使い、実行の方針が許せばレコードを並列に処理する。
結果はワーカーの数によらない。

計算量は $n$ 個の観測と $L = \mathrm{max\_lag} + 1$ 個のラグに対して $O(nL + L^2)$ である。
実数の系列は補償付きの和で集計し、打ち消しの大きいラグの和は誤差のない積で計算し直す。
空の系列、`max_lag` が長さ以上のとき、組が 1 つもないラグがあるとき、ACF や PACF を求めて $\hat\gamma(0) = 0$ のときは `InvalidInput` を返す。

### AR(1) 過程の自己相関の実験

次のブロックは、このページの 3 つのセルが共有するモデルである。
`simulate_ar1` は、平均 $\mu$、係数 $\phi$、イノベーション（各時刻に新しく加わる誤差 $\varepsilon_t$）の標準偏差 $\sigma$ の AR(1) 過程を $n$ 点作る。
最初の値を定常分布 $\mathrm{N}(\mu, \sigma^2/(1 - \phi^2))$ から引くので、系列は最初から定常である。
題材は平均 22 °C のまわりを $\sigma = 0.5$ °C のイノベーションで揺らぐ 1 時間ごとの室温とする。

```rust
//| id: stats-time-series-ar1
//| kind: definitions
//| title: AR(1) 過程の室温のモデル
//| crates: [scioxide-core, scioxide-random]
use scioxide_core::{SciOxideError, RealScalar};
use scioxide_random::{Distribution, Normal, SeedableRng, Xoshiro256StarStar};

/// 室温の平均 μ [°C]。
pub(crate) const MEAN: f64 = 22.0;
/// イノベーションの標準偏差 σ [°C]。
pub(crate) const SIGMA: f64 = 0.5;

/// x_t − μ = φ (x_{t−1} − μ) + ε_t、ε_t ~ N(0, σ²) の n 点。x_1 は定常分布から引く。
pub(crate) fn simulate_ar1(seed: u64, n: usize, phi: f64) -> Result<Vec<f64>, SciOxideError> {
    let mut rng = Xoshiro256StarStar::from_seed(seed);
    let noise = Normal::new(0.0, SIGMA)?;
    let start = Normal::new(0.0, SIGMA / RealScalar::sqrt(1.0 - phi * phi))?;
    let mut deviation = start.sample(&mut rng)?;
    let mut series = Vec::with_capacity(n);
    for _ in 0..n {
        series.push(MEAN + deviation);
        deviation = phi * deviation + noise.sample(&mut rng)?;
    }
    Ok(series)
}
```

次のセルは係数 $\phi$、系列の長さ $n$、乱数のシードを入力として系列を作り、1 つの `TimeSeriesWorkspace` で ACF と PACF を `time_series_summary_into` で計算する。
比較のために、除数を `PairCount` にした ACF と、中心を `KnownZero` にした ACF を `time_series_summary_with_options` で求める。
表は理論値 $\phi^k$ との比較で、図の破線が理論値、網かけの範囲が白色雑音の $\pm 1.96/\sqrt{n}$ である。
2 つ目の表は Yule–Walker 推定で、$\hat\phi - \phi$ を漸近標準誤差 $\sqrt{(1 - \phi^2)/n}$ で割った $z$ を示す。
このセルのシード、$n$、$\phi$ と Yule–Walker 推定は、下の 2 つのセルに渡す。

```rust
let phi_hat = acf[1].value;

        ],
        options = &serde_json::json!({
            "link": { "group": "lag" },
            "xLabel": "ラグ k [時間]",
            "yLabel": label,
            "yMin": -1.0,
            "yMax": 1.0,
            "annotations": [
                { "kind": "range", "axis": "y", "from": -band, "to": band, "label": "±1.96/√n" }
            ]
        })
    );
}
export!(seed, seed);
export!(observations, observations);
export!(phi, phi);
export!(yule_walker, [phi_hat, mean_hat, variance_hat]);
```

既定の $\phi = 0.8$、$n = 240$、シード 101 では、$\hat\rho(1) = 0.787$、$\hat\rho(2) = 0.623$ で、理論値 0.8、0.64 に近い。
ラグ 5 では $\hat\rho(5) = 0.248$ と理論値 0.328 より小さいが、AR(1) の Bartlett の公式から求めたこのラグの標準誤差は約 0.11 で、その範囲に収まる。
隣り合うラグの $\hat\rho(k)$ は互いに強く相関するので、理論値からのずれは何個ものラグで同じ向きに続く。
除数を $n - k$ にした ACF はどのラグでも少しだけ大きく、$k = 5$ で 0.253 である。
平均 0 を仮定した ACF は平均 22 °C を引かないので、すべてのラグで 0.95 を超え、系列の依存の構造を何も表さない。
PACF は $\hat\phi_{11} = 0.787$ のあと、ラグ 2 から 10 までのすべてで $\pm 1.96/\sqrt{240} = \pm 0.127$ の範囲に入る。
Yule–Walker 推定 $\hat\phi = 0.787$ は真の値から漸近標準誤差 0.039 の $-0.34$ 倍だけ離れている。

$\phi = -0.6$（`negative`）では ACF の符号がラグごとに入れ替わり、PACF はラグ 1 の $-0.632$ だけが範囲の外に出る。
$n = 1200$（`long`）では範囲が $\pm 0.057$ に狭まり、$\hat\phi = 0.780$、$z = -1.17$ になる。
$\phi = 0.95$（`near-unit-root`）では ACF の減衰が遅く、ラグ 10 でも 0.60 が残る。

## ペリオドグラム

### スペクトル密度とペリオドグラム

定常過程の自己共分散はスペクトル密度 $f(\nu)$ とフーリエ変換の対になる（Wiener–Khinchin の定理）。
標本間隔を 1、周波数 $\nu$ を 1 標本あたりの周期数 $[-1/2, 1/2]$ で測ると

$$
f(\nu) = \sum_{k=-\infty}^{\infty} \gamma(k)\, e^{-2\pi i k \nu},
\qquad
\gamma(0) = \int_{-1/2}^{1/2} f(\nu)\, d\nu
$$

である。
AR(1) 過程では $f(\nu) = \sigma^2/|1 - \phi e^{-2\pi i \nu}|^2 = \sigma^2/(1 - 2\phi\cos 2\pi\nu + \phi^2)$ で、$\phi > 0$ なら低い周波数に、$\phi < 0$ なら高い周波数に分散が集まる。
一般の ARMA 過程では $f(\nu) = \sigma^2 |\theta(e^{-2\pi i\nu})|^2/|\phi(e^{-2\pi i\nu})|^2$ となる。

ペリオドグラムは長さ $n$ の系列の離散フーリエ変換 $X_j$ から作る $I(\nu_j) = |X_j|^2/n$（$\nu_j = j/n$）で、$f$ の素朴な推定である。
Parseval の等式から、平均を引いた系列のペリオドグラムを全周波数で積分すると $\frac{1}{n}\sum_t (x_t - \bar x)^2 = \hat\gamma(0)$ に一致する。
一方、$I(\nu_j)/f(\nu_j)$ は $n$ を増やしても 1 に近づかず、近似的に平均 1 の指数分布（自由度 2 のカイ二乗分布の半分）に従う。
ペリオドグラムは不偏に近いが一致推定量ではなく、各周波数の値は $f$ と同じ大きさの標準偏差でばらつく。
滑らかなスペクトル推定には、隣り合う周波数の平均や、区間に分けて平均する Welch の方法が要る。

### ペリオドグラムの計算

[`periodogram_diagnostics_into`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/fn.periodogram_diagnostics_into.html)`(&plan, &values, &mut bins, &mut ws, context)` は、`scioxide-signal` の `SpectralEstimatePlan` が決めるウインドウ、トレンド除去、標本化周波数、周波数の並びで、1 区間のペリオドグラムを計算する。
`plan` は密度の尺度（`SpectralScaling::Density`、既定）でなければならず、`values` の長さは `plan.segment_len()` でなければならない。
既定の `SpectralEstimateOptions` はウインドウの長さの FFT、定数のトレンド除去（平均を引く）、両側の周波数の並び（`StftPacking::Full`）、標本化周波数 1 である。
結果は周波数ごとの [`PeriodogramBin`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/struct.PeriodogramBin.html)（`frequency`、`density`、累積の割合 `cumulative_power`）と、要約の [`PeriodogramDiagnostics`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/struct.PeriodogramDiagnostics.html) である。
要約は全周波数での積分 `integrated_power` $= \sum_j I(\nu_j)\,\Delta\nu$、密度が最大の周波数 `peak_frequency`（全体の強さが 0 なら `None`）、周波数の間隔 `bin_width` $= f_s/N$ を持つ。
これらは記述のための値で、定常性やピークの有意性を検定しない。

[`PeriodogramWorkspace`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/struct.PeriodogramWorkspace.html)`::new(&plan, options)` は、`options` の欠測と非有限値の方針がどちらも `Reject` でなければ `InvalidInput` を返す。
ペリオドグラムは等間隔で欠けのない記録を前提にし、欠測を抜くと後の標本が時間の格子からずれるからである。
欠測のある系列では、先に補間などで埋めてから計算する。
Welch の方法（区間の平均）や DPSS ウインドウによるマルチテーパー法の滑らかなスペクトル推定は `scioxide-signal` が提供する。

### ペリオドグラムの実験

次のセルは、上のセルの系列について、`periodogram_diagnostics_into` でペリオドグラムを求める。
理論のスペクトル密度は、真の母数 $[\phi, \mu, \sigma^2]$ を渡した `PreparedArimaFit::model` の `ArimaModel::spectral_density` で計算する。
独立な検算は 2 つある。
1 つ目は、`integrated_power` と `time_series_summary` で求めた $\hat\gamma(0)$ の比較で、Parseval の等式から丸め誤差の範囲で一致する。
2 つ目は、`spectral_density` と閉形式 $\sigma^2/(1 - 2\phi\cos 2\pi\nu + \phi^2)$ の最大の相対差である。
最後の行は、$0 < \nu < 1/2$ の周波数での比 $I/f$ の平均とその標準誤差で、平均が 1 の近くにあることを確かめる。
図は縦軸が対数で、ペリオドグラムの点（$\nu \ge 0$ の側）と理論の密度（破線）を描く。
平均を引いたので $\nu = 0$ の値は 0 になり、対数軸には描かない。

```rust
//| id: stats-time-series-api-3
//| ref: stats-time-series-api-3
//| title: AR(1) 過程のペリオドグラムを理論のスペクトル密度と比べる
//| run: reactive
//| uses: [stats-time-series-ar1]
//| crates: [scioxide-core, scioxide-signal, scioxide-stats]
//| dependsOn:
//|   acf: stats-timeseries-acf-pacf
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"spectrum","path":"/rows/2/1","range":{"max":1e-12}}
//|       - {"artifact":"spectrum","path":"/rows/3/1","range":{"max":1e-12}}
//|       - {"artifact":"spectrum","path":"/rows/4/1","range":{"min":0.7,"max":1.3}}
use scioxide_core::{ExecutionContext, RealScalar};
use scioxide_signal::{SpectralEstimateOptions, SpectralEstimatePlan};
use scioxide_stats::{
    ArimaOrder, ArimaTrend, PeriodogramBin, PeriodogramWorkspace, PreparedArimaFit,
    StatisticsOptions, TimeSeriesStatistic, periodogram_diagnostics_into, time_series_summary,
};

let number = |name: &str| acf[name].as_f64().ok_or(format!("{name} がない"));
let (seed, n, phi) = (
    number("seed")? as u64,
    number("observations")? as usize,
    number("phi")?,
);
let series = simulate_ar1(seed, n, phi).map_err(|e| e.to_string())?;
let context = ExecutionContext::sequential();
let plan = SpectralEstimatePlan::new(&vec![1.0; n], SpectralEstimateOptions::new())
    .map_err(|e| e.to_string())?;
let options = StatisticsOptions::new();
let mut ws = PeriodogramWorkspace::new(&plan, options).map_err(|e| e.to_string())?;
let mut bins = vec![PeriodogramBin::default(); plan.bins()];
let report = periodogram_diagnostics_into(&plan, &series, &mut bins, &mut ws, context)
    .map_err(|e| e.to_string())?;

// 真の母数 [φ, μ, σ²] の AR(1) モデルの理論スペクトル密度（標本化周波数 1/時間）
let order = ArimaOrder { p: 1, d: 0, q: 0 };
let problem = PreparedArimaFit::new(&series, None, order, ArimaTrend::Constant, options)
    .map_err(|e| e.to_string())?;
let mut arima_ws = problem.workspace().map_err(|e| e.to_string())?;
let model = problem
    .model(&[phi, MEAN, SIGMA * SIGMA], &mut arima_ws, context)
    .map_err(|e| e.to_string())?;
let (mut ratios, mut observed, mut theory, mut formula_gap) = (vec![], vec![], vec![], 0.0_f64);
for bin in bins.iter().filter(|b| b.frequency >= 0.0) {
    let density = model
        .spectral_density(bin.frequency, 1.0)
        .map_err(|e| e.to_string())?;
    // 独立な検算: f(ν) = σ² / (1 − 2φ cos 2πν + φ²)
    let cosine = RealScalar::cos(2.0 * std::f64::consts::PI * bin.frequency);
    let formula = SIGMA * SIGMA / (1.0 - 2.0 * phi * cosine + phi * phi);
    formula_gap = formula_gap.max((density - formula).abs() / formula);
    theory.push([bin.frequency, density]);
    if bin.density > 0.0 {
        observed.push([bin.frequency, bin.density]);
    }
    if bin.frequency > 0.0 && bin.frequency < 0.5 {
        ratios.push(bin.density / density);
    }
}
let m = ratios.len() as f64;
let mean_ratio = ratios.iter().sum::<f64>() / m;
let spread = ratios
    .iter()
    .map(|r| (r - mean_ratio) * (r - mean_ratio))
    .sum::<f64>()
    / (m - 1.0);
let gamma0 = time_series_summary(&series, TimeSeriesStatistic::Covariance, 0)
    .map_err(|e| e.to_string())?[0]
    .value;
let rows = vec![
    ("integrated_power [°C²]", report.integrated_power),
    ("γ̂(0)（除数 n）[°C²]", gamma0),
    (
        "|integrated_power − γ̂(0)| / γ̂(0) [-]",
        (report.integrated_power - gamma0).abs() / gamma0,
    ),
    ("spectral_density と閉形式の最大相対差 [-]", formula_gap),
    ("I/f の平均（0 < ν < 1/2）[-]", mean_ratio),
    ("I/f の平均の標準誤差 [-]", RealScalar::sqrt(spread / m)),
    ("周波数の間隔 bin_width [1/時間]", report.bin_width),
];
let columns = serde_json::json!([
    { "key": "0", "label": "量" },
    { "key": "1", "label": "値", "type": "number", "format": { "significantDigits": 4 } }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "spectrum" })
);
let dotted = serde_json::json!({ "lineType": "dotted", "showSymbol": true });
let dashed = serde_json::json!({ "lineType": "dashed" });
emit_line_chart!(
    &vec![
        serde_json::json!({ "name": "ペリオドグラム I(ν)", "points": observed, "style": dotted }),
        serde_json::json!({ "name": "AR(1) の f(ν)", "points": theory, "style": dashed }),
    ],
    options = &serde_json::json!({
        "xLabel": "周波数 ν [1/時間]",
        "yLabel": "スペクトル密度 [°C²·時間]",
        "yType": "log",
        "xMin": 0.0,
        "xMax": 0.5
    })
);
```

既定の系列では `integrated_power` と $\hat\gamma(0)$ はどちらも 0.6573 °C² で、相対差は $10^{-16}$ の大きさである。
真の分散 $\gamma(0) = \sigma^2/(1 - \phi^2) = 0.694$ °C² との違いは推定のばらつきで、Parseval の等式は標本の値どうしの恒等式である。
`spectral_density` と閉形式の相対差も $4 \times 10^{-15}$ 以下に収まる。
$0 < \nu < 1/2$ の 119 個の周波数での $I/f$ の平均は 1.015、その標準誤差は 0.084 で、平均 1 と整合する。
図のペリオドグラムの点は理論の曲線の上下に大きく散らばる。
比 $I/f$ が平均 1 の指数分布に従うなら、5 % の点は 0.05 倍以下、5 % の点は 3 倍以上になり、$n$ を増やしてもこのばらつきは小さくならない。
最初のセルで $n = 1200$ にすると、周波数の間隔は $1/1200$ になり、$I/f$ の平均は $1.026 \pm 0.042$ と標準誤差だけが小さくなる。

## ARIMA モデル

### 差分と ARMA 過程

非季節の ARIMA($p, d, q$) モデルは、$d$ 回の差分 $(1 - B)^d$ で定常にした系列が ARMA($p, q$) 過程に従うモデルである。
$B$ は後退作用素 $B x_t = x_{t-1}$ で、確定的なトレンド $\mu_t$ を除いた系列について

$$
\phi(B)\,(1 - B)^d\,(x_t - \mu_t) = \theta(B)\,\varepsilon_t,
\qquad
\varepsilon_t \sim \mathrm{N}(0, \sigma^2)\ \text{独立}
$$

$$
\phi(z) = 1 - \phi_1 z - \dots - \phi_p z^p,
\qquad
\theta(z) = 1 + \theta_1 z + \dots + \theta_q z^q
$$

と書く。
AR 部分は定常（$\phi(z)$ の根がすべて単位円の外）、MA 部分は反転可能（$\theta(z)$ の根がすべて単位円の外）であることを要求する。
反転可能性は、同じ自己相関を持つ MA モデルの中から 1 つを選ぶ条件である。

トレンド [`ArimaTrend`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/enum.ArimaTrend.html) は、元の系列の 0 から数えた添字 $t$ について次の 4 つから選ぶ。

| `ArimaTrend` | $\mu_t$ | 使える $d$ |
|---|---|---|
| `None`（既定） | $0$ | すべて |
| `Constant` | $c$（定常な系列の平均） | $d = 0$ |
| `Linear` | $b\,t$（$d = 1$ ではドリフト） | $d \le 1$ |
| `ConstantAndLinear` | $c + b\,t$ | $d = 0$ |

差分で消えるトレンド（$d \ge 1$ の定数など）は `InvalidInput` で拒む。
季節 ARIMA（SARIMA）、外生変数を持つ ARIMAX、多変量の VAR、条件付き分散の ARCH・GARCH、単位根の検定（ADF、KPSS）、次数の自動選択は提供しない。
季節変動は、季節差分した系列を作るか、季節の項を回帰で除いてから当てはめる。

### 正確な正規尤度とイノベーション

時刻 $t$ までの観測から作る $x_t$ の一期先予測を $\hat x_t$、その誤差 $v_t = x_t - \hat x_t$ をイノベーション、その分散を $f_t$ とする。
正規過程の同時密度は予測誤差の分解で書け、負の対数尤度は

$$
-\ln L = \frac{1}{2} \sum_t \left( \frac{v_t^2}{f_t} + \ln f_t + \ln 2\pi \right)
$$

となる。
[`PreparedArimaFit`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/struct.PreparedArimaFit.html) は、次元 $m = p + d + q$ の状態空間表現に Kalman フィルタを当てて $v_t$ と $f_t$ を求める。
フィルタは ARMA 部分の定常な共分散（次数 $p + 1$ の連立 1 次方程式の解）から始めるので、ARMA 部分については最初の観測まで含めた正確な尤度になる。
$d > 0$ では最初の $d$ 個の観測で条件付け、それらは欠測であってはならない。
1 回の評価の計算量は $O(n\, m^3)$ である。
欠測の位置ではフィルタが予測だけを進め、時間の格子を保つ（Jones の方法）。
どの値を欠測とみなすかは、構築時に渡した `StatisticsOptions` の欠測と非有限値の方針で決まる。

AR(1) で $\mu$ を推定する場合、最初のイノベーションは $v_1 = x_1 - \mu$、$f_1 = \sigma^2/(1 - \phi^2)$ で、以降は $\hat x_t = \mu + \phi(x_{t-1} - \mu)$、$f_t = \sigma^2$ になる。
最初の観測を条件にして捨てる条件付き最小二乗法と違い、正確な尤度は最初の観測の情報も使う。
2 つの推定の差は、$n$ が小さいときや $\phi$ が 1 に近いときに大きくなる。

### 最尤推定の漸近分散と予測区間

AR(1) の最尤推定量は漸近的に正規で、その分散は

$$
\mathrm{Var}\,\hat\phi \approx \frac{1 - \phi^2}{n},
\qquad
\mathrm{Var}\,\hat\mu \approx \frac{\sigma^2}{n(1 - \phi)^2},
\qquad
\mathrm{Var}\,\hat\sigma^2 \approx \frac{2\sigma^4}{n}
$$

である（Brockwell–Davis §8.8）。
$\hat\phi$ の分散は Yule–Walker 推定と同じで、AR モデルでは両者は漸近的に同等である。
$\hat\mu$ の分散は独立な標本の $\sigma_x^2/n$ より $(1 + \phi)/(1 - \phi)$ 倍大きく、$\phi = 0.8$ では 9 倍になる。
正の自己相関がある系列の平均は、見かけの標本数ほど正確ではない。
モデルを仮定せずにこの不確かさを見積もるには、[リサンプリング](../resampling/)の移動ブロック・ブートストラップ（`BootstrapDesign::MovingBlock`、`CircularBlock`）を使う。

最後の観測 $x_n$ から $h$ 時刻先の予測の平均と誤差の分散は

$$
\hat x_{n+h} = \mu + \phi^h (x_n - \mu),
\qquad
\mathrm{Var}(x_{n+h} - \hat x_{n+h}) = \sigma^2 \frac{1 - \phi^{2h}}{1 - \phi^2}
$$

で、$h \to \infty$ で平均は $\mu$、分散は $\gamma(0)$ に近づく。
正規性を仮定した 95 % 予測区間は $\hat x_{n+h} \pm 1.96\sqrt{\mathrm{Var}}$ である。
この分散は母数を既知として扱い、推定の誤差を含まない。
$n$ が小さいときや $\phi$ が 1 に近いとき、区間は名目の水準より狭くなりやすい。
$d \ge 1$ では差分を戻す積分の不確かさが加わり、予測の分散は $h$ とともに際限なく増える。

### 残差の白色性の確かめ方

当てはめたモデルが正しければ、標準化したイノベーション $v_t/\sqrt{f_t}$ は互いに独立な $\mathrm{N}(0, 1)$ に近い。
Ljung–Box 検定はその自己相関 $r_k$ から

$$
Q = n(n + 2) \sum_{k=1}^{m} \frac{r_k^2}{n - k}
$$

を作り、自由度 $m - p - q$ のカイ二乗分布と比べる。
`scioxide-stats` は Ljung–Box 検定（と Box–Pierce 検定）を関数としては提供しない。
次のセルのように、イノベーションの ACF を `time_series_summary` で求め、`scioxide-random` の `ChiSquared` の上側確率で p 値を出せば組み立てられる。
系列の相関にロバストな回帰の標準誤差（HAC、Newey–West）も提供しない。
相関のある系列から作る統計量の標準誤差は、上の移動ブロック・ブートストラップで代わりに見積もれる。

### ARIMA の当てはめと予測の API

`PreparedArimaFit::new(values, validity, order, trend, options)` が問題を作る。
次数は [`ArimaOrder`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/struct.ArimaOrder.html)`{ p, d, q }` で、母数の並びは $[\phi_1, \dots, \phi_p, \theta_1, \dots, \theta_q, \text{トレンド}, \sigma^2]$（トレンドは $c$、$b$ の順）である。
系列が $d$ 個以下のとき、最初の $d$ 個に欠測があるとき、$d$ 個の後に観測がないときは `InvalidInput` を返す。
`PreparedArimaFit::from_view` は `BatchView` の 1 レコードを複製せずに使う。
尤度の評価と予測に使う作業領域 `ArimaWorkspace` は、`PreparedArimaFit::workspace()` か、当てはめたモデルの `ArimaModel::workspace(horizon)`（`horizon` 段先までの予測用）で作る。
評価の結果は作業領域の前の中身によらないので、同じ作業領域を母数を変えた評価に使い回せる。

- `evaluate_into(&params, &mut innovations, &mut ws, context)` は、母数での負の対数尤度を [`ArimaLikelihood`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/struct.ArimaLikelihood.html) として返し、時刻ごとの予測 `prediction`、分散 `variance`、イノベーション `residual` を `ArimaInnovation` の列に書く。
  `ArimaLikelihood` は `negative_log_likelihood`（$\ln 2\pi$ の定数を含む）、尤度に入ったイノベーションの数 `observations`、定常な共分散を解いた連立方程式の相対残差 `covariance_residual` を持つ。
  最初の $d$ 個の時刻では 3 つの値がどれも `None` で、欠測の時刻では `residual` が `None` である。
  母数の数が違うと `InvalidInput`、$\sigma^2 \le 0$、AR 部分が非定常、MA 部分が反転不能のときも `InvalidInput` を返す。
  多項式の判定には反射係数（Levinson–Durbin の偏自己相関）を使い、絶対値が $1 - 64\varepsilon$ を超える母数を拒む。
- `model(&params, &mut ws, context)` は、母数を固定して最後の時刻までフィルタを進めた `ArimaModel` を返す。
- `fit(&initial, &bounds, &mut solver)` は、注入したソルバーで負の対数尤度を最小化する。
  解析的な導関数は渡さないので、ソルバーは導関数を使わない方法か、差分で勾配を近似する方法でなければならない。
  `scioxide-optimize` の `LbfgsBFitSolver` は、解析的な勾配がなければ `LbfgsBOptions` の `DerivativeStrategy` に従って差分で近似する。
  ソルバーが止まった後に尤度を 1 回評価し直し、その状態からモデルを作る。
  `fit_scoped` は実行コンテキストを受け取る。

結果の [`ArimaFitReport`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/struct.ArimaFitReport.html) は、`report()` で共通の `FitReport`（終了状態 `termination()`、最後の負の対数尤度 `objective()`、反復と評価の回数 `counts()`）を、`model()` で当てはめた `ArimaModel` を返す。
`model()` が `None` になるのは、取り消しや評価回数の上限で最後の評価の前に止まったときだけである。
ソルバーが自分の反復の上限で止まった（`BudgetExhausted`）ときもモデルは返るので、使う前に終了状態を確かめる。

[`ArimaModel`](https://docs.rs/scioxide-stats/0.1.0/scioxide_stats/struct.ArimaModel.html) の `forecast(h)` と `forecast_into(&mut out, &mut ws, context)` は、系列の後の $h$ 時刻の予測の平均と誤差の分散を `ArimaForecast`（`mean`、`variance`）で返す。
`spectral_density(ν, fs)` は ARMA 部分の両側のスペクトル密度 $(\sigma^2/f_s)\,|\theta(z)|^2/|\phi(z)|^2$（$z = e^{2\pi i\nu/f_s}$）を返し、$|\nu| > f_s/2$ では `InvalidInput` を返す。

### ARIMA の当てはめの実験

次のセルは、最初のセルと同じ系列に ARIMA(1, 0, 0) と定数のトレンドを当てはめ、母数 $[\phi, \mu, \sigma^2]$ を推定する。
ソルバーは `scioxide-optimize` の `LbfgsBFitSolver` で、勾配を中心差分（`DerivativeStrategy::Central`）で近似する。
射影勾配が既定の許容誤差を満たしたら `Converged`、入力の反復の上限に達したら `BudgetExhausted` を返す。
定常性や $\sigma^2 > 0$ を外れた点は目的関数の検査（`FitObjective::validate`）が `InvalidInput` で拒み、L-BFGS-B の直線探索はその点を定義域の外として段を縮めるので、母数に範囲の制約は付けない。
初期値は最初のセルの Yule–Walker 推定である。

1 つ目の表は、真の母数、Yule–Walker 推定、最尤推定、その漸近標準誤差と $z$ である。
2 つ目の表は予測で、`forecast` の平均と標準偏差を上の閉形式と比べる。
3 つ目の表は、`evaluate_into` で求めた負の対数尤度と `FitReport::objective()` の差と、標準化したイノベーションの Ljung–Box 統計量（$m = 10$、自由度 9）である。
図は最後の 48 時間の観測と、予測の平均と 95 % 予測区間（帯）で、破線は推定した平均 $\hat\mu$ である。

```rust
//| id: stats-time-series-api-4
//| ref: stats-time-series-api-4
//| title: L-BFGS-B で AR(1) を最尤推定し、予測区間を閉形式と比べる
//| run: reactive
//| uses: [stats-time-series-ar1]
//| crates: [scioxide-core, scioxide-differentiate, scioxide-optimize, scioxide-random, scioxide-stats]
//| dependsOn:
//|   acf: stats-timeseries-acf-pacf
//| inputs:
//|   horizon: {"type":"range","label":"予測の時刻数 H [時間]","min":1,"max":24,"step":1,"value":12}
//|   max_iterations: {"type":"integer","label":"L-BFGS-B の反復の上限 [回]","min":1,"max":100,"value":100}
//| cases:
//|   - {"id":"few-iterations","label":"反復 1 回","description":"上限で止まり、母数は Yule–Walker 推定から少ししか動かない。","inputs":{"max_iterations":1}}
//|   - {"id":"short-horizon","label":"H = 1","description":"1 時刻先の予測の標準偏差が σ̂ に等しい。","inputs":{"horizon":1}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"forecast","path":"/rows/0/5","range":{"max":1e-12}}
//|       - {"artifact":"likelihood","path":"/rows/0/1","range":{"max":1e-10}}
//|       - {"artifact":"estimates","path":"/rows/0/3","approx":{"value":0.788474,"atol":1e-5}}
//|       - {"artifact":"likelihood","path":"/rows/0/3","approx":{"value":9.2849,"atol":1e-3}}
//|       - {"path":"/outputs/4/state","equals":"satisfied"}
//|   - case: few-iterations
//|     expect:
//|       - {"path":"/outputs/4/state","equals":"partial"}
//|       - {"artifact":"likelihood","path":"/rows/0/0","approx":{"value":173.621995,"atol":1e-5}}
//|   - case: short-horizon
//|     expect:
//|       - {"artifact":"forecast","path":"/rows/0/2","approx":{"value":0.497791,"atol":1e-5}}
use scioxide_core::{Bounds, Budget, ExecutionContext, RealScalar};
use scioxide_differentiate::DerivativeStrategy;
use scioxide_optimize::{LbfgsB, LbfgsBFitSolver, LbfgsBOptions};
use scioxide_random::{ChiSquared, Survival};
use scioxide_stats::{
    ArimaInnovation, ArimaOrder, ArimaTrend, PreparedArimaFit, StatisticsOptions,
    TimeSeriesStatistic, time_series_summary,
};

let number = |name: &str| acf[name].as_f64().ok_or(format!("{name} がない"));
let (seed, n, phi) = (
    number("seed")? as u64,
    number("observations")? as usize,
    number("phi")?,
);
let series = simulate_ar1(seed, n, phi).map_err(|e| e.to_string())?;
let initial: Vec<f64> = (0..3)
    .map(|i| acf["yule_walker"][i].as_f64().unwrap_or(0.0))
    .collect();
let order = ArimaOrder { p: 1, d: 0, q: 0 };
let problem = PreparedArimaFit::new(
    &series,
    None,
    order,
    ArimaTrend::Constant,
    StatisticsOptions::new(),
)
.map_err(|e| e.to_string())?;
// 制約なし。定常でない点と σ² ≤ 0 の点は直線探索が退ける。勾配は中心差分で近似する
let bounds = Bounds::new(vec![(None, None); 3]).map_err(|e| e.to_string())?;
let limit = Budget::try_from(max_iterations as usize).map_err(|e| e.to_string())?;
let lbfgsb = LbfgsBOptions::default()
    .with_max_iterations(limit)
    .with_derivative_strategy(DerivativeStrategy::Central);
let mut solver = LbfgsBFitSolver::new(LbfgsB::new(lbfgsb), 3).map_err(|e| e.to_string())?;
let fit = problem
    .fit(&initial, &bounds, &mut solver)
    .map_err(|e| e.to_string())?;
let termination = fit.report().termination();
let model = fit.model().ok_or("最後の尤度の評価の前に止まった")?;
let (phi_hat, mean_hat, variance_hat) = (
    model.parameters()[0],
    model.parameters()[1],
    model.parameters()[2],
);

// 推定と漸近標準誤差 √((1 − φ²)/n)、σ/((1 − φ)√n)、σ²√(2/n)
let root_n = RealScalar::sqrt(n as f64);
let rows = vec![
    (
        "φ",
        phi,
        initial[0],
        phi_hat,
        RealScalar::sqrt(1.0 - phi * phi) / root_n,
    ),
    (
        "μ [°C]",
        MEAN,
        initial[1],
        mean_hat,
        SIGMA / ((1.0 - phi) * root_n),
    ),
    (
        "σ² [°C²]",
        SIGMA * SIGMA,
        initial[2],
        variance_hat,
        SIGMA * SIGMA * RealScalar::sqrt(2.0) / root_n,
    ),
];
let rows: Vec<_> = rows
    .into_iter()
    .map(|(name, truth, yw, ml, se)| (name, truth, yw, ml, se, (ml - truth) / se))
    .collect();
let (sig4, fixed2) = (
    serde_json::json!({ "significantDigits": 4 }),
    serde_json::json!({ "fractionDigits": 2 }),
);
let columns = serde_json::json!([
    { "key": "0", "label": "母数" },
    { "key": "1", "label": "真の値", "type": "number", "format": sig4 },
    { "key": "2", "label": "Yule–Walker", "type": "number", "format": sig4 },
    { "key": "3", "label": "最尤推定", "type": "number", "format": sig4 },
    { "key": "4", "label": "漸近 SE", "type": "number", "format": sig4 },
    { "key": "5", "label": "z = (最尤 − 真)/SE [-]", "type": "number", "format": fixed2 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "estimates" })
);

// 予測と、閉形式 μ̂ + φ̂ʰ(x_n − μ̂)、σ̂²(1 − φ̂²ʰ)/(1 − φ̂²) との比較
let forecasts = model
    .forecast(horizon as usize)
    .map_err(|e| e.to_string())?;
let last = series[n - 1];
let (mut rows, mut band) = (vec![], vec![]);
for (i, f) in forecasts.iter().enumerate() {
    let h = (i + 1) as i32;
    let mean = mean_hat + RealScalar::powi(phi_hat, h) * (last - mean_hat);
    let variance =
        variance_hat * (1.0 - RealScalar::powi(phi_hat, 2 * h)) / (1.0 - phi_hat * phi_hat);
    let sd = RealScalar::sqrt(f.variance);
    let gap = ((f.mean - mean).abs()).max((f.variance - variance).abs() / variance);
    rows.push((h, f.mean, sd, f.mean - 1.96 * sd, f.mean + 1.96 * sd, gap));
    band.push(serde_json::json!([
        (n + i) as f64,
        f.mean,
        f.mean - 1.96 * sd,
        f.mean + 1.96 * sd
    ]));
}
let fixed3 = serde_json::json!({ "fractionDigits": 3 });
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let columns = serde_json::json!([
    { "key": "0", "label": "h [時間]", "type": "integer" },
    { "key": "1", "label": "予測の平均 [°C]", "type": "number", "format": fixed3 },
    { "key": "2", "label": "予測の標準偏差 [°C]", "type": "number", "format": fixed3 },
    { "key": "3", "label": "95 % 下限 [°C]", "type": "number", "format": fixed3 },
    { "key": "4", "label": "95 % 上限 [°C]", "type": "number", "format": fixed3 },
    { "key": "5", "label": "閉形式との差 [-]", "type": "number", "format": sci2 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "forecast" })
);

// 当てはめた母数での尤度と、標準化イノベーションの Ljung–Box 統計量（m = 10、自由度 9）
let mut ws = problem.workspace().map_err(|e| e.to_string())?;
let mut innovations = vec![ArimaInnovation::default(); n];
let likelihood = problem
    .evaluate_into(
        model.parameters(),
        &mut innovations,
        &mut ws,
        ExecutionContext::sequential(),
    )
    .map_err(|e| e.to_string())?;
let objective = fit.report().objective().ok_or("目的関数の値がない")?;
let standardized: Vec<f64> = innovations
    .iter()
    .filter_map(|v| Some(v.residual? / RealScalar::sqrt(v.variance?)))
    .collect();
let r = time_series_summary(&standardized, TimeSeriesStatistic::Acf, 10)
    .map_err(|e| e.to_string())?;
let size = standardized.len() as f64;
let q = size
    * (size + 2.0)
    * (1..=10)
        .map(|k| r[k].value * r[k].value / (size - k as f64))
        .sum::<f64>();
let p_value = ChiSquared::<f64>::new(9.0)
    .map_err(|e| e.to_string())?
    .sf(q)
    .map_err(|e| e.to_string())?;
let checks = vec![(
    likelihood.negative_log_likelihood,
    (likelihood.negative_log_likelihood - objective).abs(),
    likelihood.observations,
    q,
    p_value,
)];
let columns = serde_json::json!([
    { "key": "0", "label": "−ln L [-]", "type": "number", "format": { "fractionDigits": 4 } },
    { "key": "1", "label": "|−ln L − objective()| [-]", "type": "number", "format": sci2 },
    { "key": "2", "label": "イノベーションの数", "type": "integer" },
    { "key": "3", "label": "Ljung–Box Q [-]", "type": "number", "format": fixed2 },
    { "key": "4", "label": "p 値 [-]", "type": "number", "format": fixed3 }
]);
emit_table_with_columns!(
    columns,
    checks,
    metadata = serde_json::json!({ "id": "likelihood" })
);

let start = n.saturating_sub(48);
let observed: Vec<[f64; 2]> = (start..n).map(|t| [t as f64, series[t]]).collect();
emit_chart!(
    serde_json::json!({
        "kind": "xy",
        "layers": [
            { "id": "observed", "kind": "line", "name": "観測", "points": observed },
            { "id": "forecast", "kind": "band", "name": "予測の平均と 95 % 予測区間", "points": band }
        ],
        "xLabel": "時刻 t [時間]",
        "yLabel": "室温 x_t [°C]",
        "annotations": [{
            "kind": "line",
            "axis": "y",
            "value": mean_hat,
            "label": "μ̂",
            "style": { "lineType": "dashed" }
        }],
        "dataZoom": true,
        "tooltip": true
    }),
    metadata = serde_json::json!({ "id": "forecast-chart" })
);

let iterations = fit
    .report()
    .counts()
    .total()
    .map_err(|e| e.to_string())?
    .iterations();
let outcome = if termination.is_success() {
    Outcome::satisfied("L-BFGS-B が射影勾配の許容誤差を満たした")
} else {
    Outcome::partial("L-BFGS-B が射影勾配の許容誤差を満たす前に止まった").explanation(
        "モデルは最後に受け入れた反復の母数で作った。予測は使えるが、最尤推定ではない。",
    )
};
emit_outcome!(
    outcome
        .status(format!("{termination:?}"))
        .diagnostic("反復", iterations as f64, None)
        .diagnostic("−ln L", objective, None)
);
```

既定では L-BFGS-B は 12 回の反復で `Converged` になり、outcome は `satisfied` である。
最尤推定は $\hat\phi = 0.7885$、$\hat\mu = 21.845$ °C、$\hat\sigma^2 = 0.2478$ °C² で、Yule–Walker 推定（0.7869、標本平均 21.834 °C、0.2503 °C²）との差はどれも漸近標準誤差よりずっと小さい。
$\hat\mu$ の漸近標準誤差は 0.161 °C で、真の平均 22 °C は $z = -0.96$ の位置にある。
1 時刻先の予測は 22.598 °C、標準偏差 0.498 °C（$= \hat\sigma$）で、95 % 予測区間は $[21.62, 23.57]$ °C である。
12 時刻先では平均が 21.900 °C まで $\hat\mu$ に戻り、標準偏差は 0.808 °C で、定常分布の標準偏差 $\sqrt{\hat\sigma^2/(1 - \hat\phi^2)} = 0.809$ °C に近づく。
`forecast` と閉形式の差はすべての $h$ で $4 \times 10^{-16}$ 以下である。
`evaluate_into` で計算し直した $-\ln L = 173.614$ は `FitReport::objective()` と一致する。
標準化したイノベーションの Ljung–Box 統計量は $Q = 9.28$（自由度 9、$p = 0.41$）で、残差に自己相関は見られない。

反復の上限を 1 にする（`few-iterations`）と、`BudgetExhausted` で止まって outcome は `partial` になる。
1 回の反復で母数は $\hat\phi = 0.7878$、$\hat\sigma^2 = 0.2456$ °C² まで動き、$-\ln L$ は 173.622 で、最小値 173.614 にまだ届かない。
最初のセルで $\phi = 0.95$ にすると、Yule–Walker 推定は $\hat\phi = 0.942$、$\hat\sigma^2 = 0.289$ °C² に対して、最尤推定は $\hat\phi = 0.954$、$\hat\sigma^2 = 0.248$ °C² で、真の値 0.95、0.25 °C² に近い。
Yule–Walker 推定は $\phi$ が 1 に近いと 0 の側に偏りやすいことが知られていて（Tjøstheim–Paulsen）、この 1 つの標本でもその傾向が表れている。

## まとめ

自己相関は `time_series_summary` で求め、モデルの同定には半正定値性を保つ既定の除数 $n$ を使う。
PACF は Levinson–Durbin 再帰で求まり、AR($p$) では次数 $p$ より先の値が $\pm 1.96/\sqrt n$ の範囲に収まることが次数の目安になる。
ペリオドグラムは各周波数で理論の密度と同じ大きさにばらつくので、ピークの位置と全体の形だけを読み、滑らかな推定には Welch の方法を使う。
ARIMA は `PreparedArimaFit` で正確な正規尤度を作り、導関数を使わないソルバーか差分で勾配を近似するソルバー（`LbfgsBFitSolver` など）を渡して当てはめ、終了状態が `Converged` かを確かめてから予測を使う。
予測区間は母数を既知とした区間なので、短い系列では名目の水準より狭くなりやすいことを踏まえて読む。
