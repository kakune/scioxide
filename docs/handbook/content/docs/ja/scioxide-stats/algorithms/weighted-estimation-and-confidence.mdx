重み $w_i \ge 0$ の付いた観測 $x_i$ の加重平均 $\bar x_w = \sum w_i x_i / \sum w_i$ は、重みが何を表すかによらず同じ式で計算できる。
しかし、平均の標準誤差と分散の自由度は、重みが「同じ値を何回観測したか」「標本の代表性」「測定の精度」のどれを表すかで変わる。
scioxide-stats は重みの意味を型 `Frequency`・`Reliability`・`Analytic` で指定させ、意味ごとに除数・自由度・区間の仮定を決める。
このページは三つの意味の分散の推定量と自由度を導き、重みの型と使える推定量の対応を整理する。
そのうえで、平均の信頼区間の作り方と、その区間が何を保証しないかを説明し、重みの意味を取り違えたときの被覆率を実験で確かめる。

## 重みの三つの意味

$n$ 個の記録 $(x_i, w_i)$ について、総重み $W = \sum w_i$、重みの 2 乗和 $Q = \sum w_i^2$、重み付きの偏差平方和 $S_w = \sum w_i (x_i - \bar x_w)^2$ と置く。
重み 0 の記録は件数 $n$ にも入れない。

**頻度重み**（`Frequency`）は、値 $x_i$ を $w_i$ 回観測したことを表す。
重みは整数に限り、複製した標本の大きさは $N = W$ である。
展開した $N$ 個の観測の通常の推定量と一致するように、分散と平均の分散を次の式で推定する。

$$
s^2 = \frac{S_w}{N-1}, \qquad \widehat{\mathrm{Var}}(\bar x_w) = \frac{s^2}{N}
$$

重みをすべて $c$ 倍すると標本が $c$ 倍に増えたとみなすので、標準誤差はおよそ $1/\sqrt c$ 倍になる。

**信頼度重み**（`Reliability`）は、標本の代表性や抽出確率の逆数のような相対的な重要度を表す。
観測は共通の分散 $\sigma^2$ を持つ独立な値で、重みは観測の分散と関係しないと仮定する。
このとき $\mathrm{Var}(\bar x_w) = \sigma^2 Q/W^2$ であり、$E[S_w] = \sigma^2 (W - Q/W)$ が成り立つので、分散と平均の分散を次の式で推定する。

$$
s^2 = \frac{S_w}{W - Q/W}, \qquad \widehat{\mathrm{Var}}(\bar x_w) = s^2 \frac{Q}{W^2}
$$

$s^2$ は $\sigma^2$ の不偏推定量で、重みを定数倍しても平均・分散・標準誤差は変わらない。

**解析的重み**（`Analytic`）は、$\mathrm{Var}(x_i) = \tau^2 / w_i$ のように測定ごとに精度が違うことを表す。
$\tau^2$ は未知の共通の尺度で、ノイズの尺度（noise scale）と呼ぶ。
重みが真の精度に比例するとき、加重平均は線形不偏推定量の中で分散が最小になる（Gauss–Markov の定理）。
このモデルでは $\mathrm{Var}(\bar x_w) = \tau^2/W$、$E[S_w] = (n-1)\tau^2$ なので、次の推定量を使う。

$$
\hat\tau^2 = \frac{S_w}{n-1}, \qquad \widehat{\mathrm{Var}}(\bar x_w) = \frac{\hat\tau^2}{W}
$$

自由度は正の重みを持つ記録の数 $n$ から 1 を引いた値である。
重みを $c$ 倍すると $\hat\tau^2$ も $c$ 倍になり、平均の分散は変わらない。

| 重みの意味 | 分散の除数 | 平均の分散 | 自由度 | 重みを $c$ 倍したとき |
|---|---|---|---|---|
| 頻度 | $N - 1$ | $s^2/N$ | $N - 1$ | 標準誤差が約 $1/\sqrt c$ 倍 |
| 信頼度 | $W - Q/W$ | $s^2 Q/W^2$ | $W^2/Q - 1$ | 変わらない |
| 解析的 | $n - 1$（$\hat\tau^2$） | $\hat\tau^2/W$ | $n - 1$ | 変わらない |

三つの推定量は、それぞれのモデルの下でだけ平均の分散を正しく推定する。
別のモデルで生成されたデータに当てはめると、平均の分散を系統的に過大か過小に見積もる。
その大きさは[重みの意味と被覆率](#重みの意味と被覆率)の節で導き、実験で確かめる。

## 重みの型と使える推定量

scioxide-stats の重みは意味を表す 5 つの型（重みのモデル）のどれかに属する。
`Unweighted` は重みなし、`Frequency` は整数の独立反復数、`Mass` は離散分布を定める相対的な質量、`Reliability` は信頼度重み、`Analytic` は解析的重みである。
`Mass` は分布の要約（加重平均、分位点、裾平均）だけを定め、標本のモデルを持たないので、標本分散と標準誤差を定めない。
この 5 つの型はどれも trait `WeightModel` を実装する。
`WeightModel` は外部の型が実装できない sealed トレイト で、重みの意味の一覧を固定する。

関数は受け付ける重みの型を trait の境界で表すので、定義されない組み合わせはコンパイルの段階で拒まれる。

| trait | 実装する型 | 受け付ける主な API |
|---|---|---|
| `BatchWeights` | `Unweighted`、`Weights<&[u64], Frequency>`、`Weights<&[S], M>`（`M` は `Mass`・`Reliability`・`Analytic`） | `BatchView::with_weights`、`statistic`、`EmpiricalDistribution::new` に渡す重みの格納 |
| `EmpiricalWeights` | `Unweighted`、`Frequency`、`Mass` | 経験分布、分位点、経験分布関数などの順序に基づく推定量 |
| `MomentWeights` | `Frequency`、`Reliability`、`Analytic` | `OnlineWeightedMoments`、`OnlineWeightedCovariance`、`reduce_weighted_moments` |
| `ConjugateWeights` | `Frequency`、`Analytic` | 正規モデルの共役更新（`NormalInverseGammaPrior::update_weighted`） |
| `RegressionWeights` | `Unweighted`、`Weights<&[S], Frequency>`、`Weights<&[S], Analytic>` | 線形回帰・作用素回帰・一般化線形モデルの行の重み |

`ConjugateWeights` が `Reliability` を含まないのは、信頼度重みが尤度を定めないからである。
回帰も同じ理由で、信頼度重みと質量を受け付けない。
`BatchWeights` は重みの格納の形も決め、頻度重みは `u64` の配列、他の重みは観測と同じ実数型の配列で渡す。
重みの値は、それを読む関数が検査する。
負の重み、非有限の重み、頻度重みの整数でない値は、そのときにエラーになる。
分位点の定義と裾平均の対応は、さらに細かい trait（`InterpolatedQuantiles`、`TailWeights`）で表す（[経験分布・標本分位点・補間規約の数理](../empirical-quantiles/)、[重み付き経験分布と裾平均の数理](../tail-means-and-weighted-empirical/)）。

`WeightSemantics` は列挙型で、累積器や区間がどのモデルで計算されたかを返すために使う。
重みの意味を選ぶのは型の引数であり、`WeightSemantics` を渡して選ぶ API はない。

質量は確率の質量としてエントロピーにも使う。
`entropy_with_options` は `EntropyOptions` の `MassNormalization` で質量の扱いを選ぶ。
`Normalize` は和が正の非負の質量を受け付け、`RequireUnit(t)` は $|\sum_i p_i - 1| \le t$ を要求する。
どちらでも、質量は和で割ってから使う（[円周統計・情報量・分布間距離](../circular-information-and-distances/)）。

## 重み付き累積器

`OnlineWeightedMoments<S, M>` は、モデル `M`（`MomentWeights` を実装する型）の重み付きの平均と中心モーメントを逐次に集計する。
`observe(x, w)` は観測を 1 個足し、`merge(&other)` は互いに素な区画の累積器を結合する。
更新と結合は、重みなしの累積器と同じ Pébay らの結合公式を重み付きに一般化したもので、1 回あたり $O(1)$ の演算である。
`from_slices(values, Weights::<_, M>::new(&weights), order)` はスライス全体から累積器を作り、値と重みが f64 の通常の範囲にあれば補償付きの 2 回の走査で求める。

モデルが違う累積器は型が違うので、結合しようとするとコンパイルできない。
保持する次数が違う累積器の結合は、一方が空でも `InvalidInput` になる。
`observe` は、値か重みが非有限なら `NonFinite`、重みが負なら `InvalidInput`、頻度重みが `usize` に収まる整数でなければ `ScalarConversion` を返す。
重みの状態や偶数次の中心モーメントが桁落ちで壊れたときは `NumericalInstability` を返す。
どの失敗でも状態は変わらない。

`snapshot()` が返す `WeightedMomentsSnapshot` は、次の量を照会のたびに丸めて返す。

- `observation_count()` は正の重みを持つ記録の数 $n$、`frequency_count()` は頻度重みの複製した件数 $N$（他のモデルでは `None`）を返す。
- `total_weight()` は $W$、`effective_sample_size()` は有効標本サイズ、`degrees_of_freedom()` は自由度、`variance_divisor()` は分散の除数を返す。
- `mean()`、`weighted_population_variance()`（$S_w/W$）、`sample_variance()`、`variance_of_weighted_mean()`、`standard_error_of_weighted_mean()` は上の表の推定量を返す。
  解析的重みでは `sample_variance` はつねに `Ok(None)` で、代わりに `noise_scale()` で $\hat\tau^2$ を読む。
- `central_moment(k)`、`skewness`、`kurtosis` は重み付きの中心モーメント $m_k = \sum w_i (x_i - \bar x_w)^k / W$ とその比を返す。

補正した歪度・尖度（`BiasCorrection::Corrected`）は、展開した独立な観測として意味を持つ頻度重みでだけ定義し、他の重みでは `NotImplemented` を返す。
k 統計量 `k_statistic` と `k_statistic_variance` は頻度重みのスナップショットにだけあり、`noise_scale` は解析的重みのスナップショットにだけある。
どちらも他のモデルで呼ぶとコンパイルできない。

二変量の `OnlineWeightedCovariance` と `WeightedCovarianceSnapshot` も同じ規約に従う。
解析的重みでは標本共分散が定義されず（`validity()` が `PopulationOnly` を返す）、代わりに共通のノイズの共分散 `noise_covariance` を返す。
加重平均どうしの共分散 `covariance_of_weighted_means` は、`variance_of_weighted_mean` と同じ係数を共偏差に掛けた値である。
重み付きの相関 `correlation` は分散の除数によらない。

行列ビューの各バッチを重み付きで集約するときは、`BatchView::with_weights` で重みを付けたビューを `reduce_weighted_moments`・`reduce_weighted_covariance` に渡す（[行列ビューの一括集約](oxref:stats-online-matrix-view-reduction)）。
重み付きの累積器はつねに推定した平均のまわりで中心化する。
既知の中心 $c$ のまわりのモーメント $\sum_i (x_i - c)^k / n$ が必要なら、重みなしの `reduce_moment` の `center` に `Some(c)` を渡す。

## 有効標本サイズと自由度

信頼度重みの平均の分散 $s^2 Q/W^2$ を、独立な $n_{\mathrm{eff}}$ 個の観測の平均の分散 $s^2/n_{\mathrm{eff}}$ と比べると、次の量を得る。

$$
n_{\mathrm{eff}} = \frac{W^2}{Q} = \frac{\bigl(\sum w_i\bigr)^2}{\sum w_i^2}
$$

これを Kish の**有効標本サイズ**と呼ぶ（Kish, 1965）。
Cauchy–Schwarz の不等式から $1 \le n_{\mathrm{eff}} \le n$ で、重みが均一なら $n_{\mathrm{eff}} = n$、一つの記録に重みが集中すると 1 に近づく。
分散の除数 $W - Q/W = W(1 - 1/n_{\mathrm{eff}})$ もこの量で書ける。

`effective_sample_size` は、頻度重みでは複製した件数 $N$、他の重みでは $W^2/Q$ を返す。
`degrees_of_freedom` は頻度で $N - 1$、信頼度で $n_{\mathrm{eff}} - 1$、解析的で $n - 1$ を返す。
解析的重みの推論は $n_{\mathrm{eff}}$ ではなく記録の数を使う。
信頼度重みの $n_{\mathrm{eff}} - 1$ を自由度とする t 分布は近似であり、正規独立標本の t 分布のような正確な分布ではない。

## 平均の信頼区間の構成

推定値 $\hat\theta$ と標準誤差 $\mathrm{SE}$ から、両側の信頼度 $1 - \alpha$ の区間を $\hat\theta \pm c\,\mathrm{SE}$ で作る。
臨界値 $c$ の分布は `MeanIntervalMethod` で選ぶ。

- `StudentT`（既定）は、独立な正規標本で分散を推定した場合の区間である。
  $(\bar X - \mu)/(S/\sqrt n)$ は自由度 $\nu = n-1$ の t 分布に従うので、$c = t_{\nu,\,1-\alpha/2}$ とする。
- `NormalKnownVariance` は、標準誤差が既知の場合の正規の臨界値 $z_{1-\alpha/2}$ を使う。
- `NormalAsymptotic` は、推定した標準誤差に中心極限定理を当てはめる大標本の近似で、同じ $z_{1-\alpha/2}$ を使う。
  有限標本の被覆率を主張しない。

信頼度は `ConfidenceProbability::new(p)` で作り、$p \in (0, 1)$ でなければ `InvalidInput`、非有限なら `NonFinite` を返す。
既定値は 0.95 である。
正規の臨界値 $z_{1-\alpha/2} = \sqrt 2\,\mathrm{erf}^{-1}(p)$ は、`normal_critical_value` が $p \le 1/2$ では $\mathrm{erf}^{-1}(p)$、それより大きいときは $\mathrm{erfc}^{-1}(1 - p)$ から求める。
$1 - p$ は $p \ge 1/2$ の f64 では正確に計算できるので、信頼度が 1 に近くても $\alpha$ の情報を失わない。
t の臨界値 `student_t_critical_value(ν)` は、$\nu < 4096$ では $P(|T| \le t) = I_x(1/2, \nu/2)$、$x = t^2/(\nu + t^2)$ を正則化不完全ベータ関数の逆関数で解く。
このとき $(1 + p)/2$ を作らずに中心側か補側の形を反転するので、ここでも $\alpha$ の情報を失わない。
$\nu \ge 4096$ では、正規の臨界値のまわりの $1/\nu$ の冪の展開を $\nu^{-4}$ の項まで使う（Abramowitz と Stegun 26.7.5）。
その相対打ち切り誤差は $10^{-17}$ 未満である。
`student_t_critical_value_with_options` に渡す `scioxide_special::BetaOptions` は、逆関数の反復の上限と許容誤差を決める。

`MomentsSnapshot::confidence_interval_of_mean()` と `WeightedMomentsSnapshot::confidence_interval_of_weighted_mean()` は、両側 95% の Student の t 区間を返す。
信頼度と方法は `confidence_interval_of_mean_with_options`、`confidence_interval_of_weighted_mean_with_options` で選ぶ。
分散を推定しているので、`NormalKnownVariance` を渡すと `InvalidInput` になる。
結果の `MeanConfidenceInterval` は、端点 `bounds`、推定値 `estimate`、標準誤差 `standard_error`、自由度 `degrees_of_freedom`、方法 `method`、信頼度 `confidence` を持つ。
`assumptions()` は被覆率が名目値になる仮定を `MeanIntervalAssumptions` で返す。
重みなしの t 区間は `IndependentNormal`、頻度重みは `FrequencyNormal`、解析的重みは `AnalyticNormal`、信頼度重みは近似を表す `EffectiveSampleApproximation` を記録し、正規近似の方法では `AsymptoticNormal` を記録する。
`weight_semantics()` は重み付きのスナップショットから作った区間でだけモデルを返す。
これらの仮定はデータで検定したものではなく、記録するだけである。
標準誤差が定義されないとき（$n < 2$ など）は `Ok(None)` を返す。
重みのないスライスから直接求めるなら、ワンショット呼び出しの `mean_confidence_interval(&x)` が同じ両側 95% の t 区間を返し、2 点未満の標本は `InvalidInput` で拒む。

推定値と標準誤差を別に持っている場合は、`MeanIntervalPlan::new(confidence, method, degrees, options)` で臨界値を一度だけ計算する。
`StudentT` には `degrees = Some(ν)`（有限の $\nu > 0$）、正規の方法には `None` を渡し、合わなければ `InvalidInput` になる。
そのあと `interval(estimate, standard_error)` が、臨界値を計算し直さずに任意のスカラー型の区間を $O(1)$ で作る。
推定値が非有限なら `NonFinite`、標準誤差が負なら `InvalidInput` を返す。

区間の端点は結果のスカラーに丸めた値で、外向きの丸めをした包含区間ではない。
`is_degenerate()` は丸めた二つの端点が一致するときに真になる。
信頼度は同じ手続きを繰り返したときに区間が真値を含む割合の目標であり、一つの区間が真値を含む確率ではない。

### 拡張範囲の標準誤差

平均の分散 $s^2/n$ は、データの尺度の 2 乗で大きさが変わる。
データの尺度が $2^{\pm 512}$ を超えると、標準誤差 $s/\sqrt n$ は f64 で表せても、分散は f64 であふれるか 0 に丸まる。
`variance_of_sample_mean()` は分散を f64 に丸めて返すので、このとき `Err`（あふれ）か 0 になる。
`standard_error_of_sample_mean()` は丸める前に平方根を取るので、標準誤差が表せる範囲なら正しい値を返す。

`MomentsSnapshot::scaled_variance_of_sample_mean()` は、平均の分散を 2 進の指数を別に持つ `scioxide_core::Scaled<S>` で返す。
仮数だけを `S` に丸め（誤差は半 ulp 以下）、指数は丸めないので、分散があふれも 0 への丸めも起こさない。
計算コストは $O(1)$ で確保をしない。
返した値の `sqrt()` が拡張範囲の標準誤差になり、`add` で複数の推定量の分散を足してから平方根を取ることもできる。

`MeanIntervalPlan::interval_scaled(estimate, standard_error)` は、`Scaled` の標準誤差を `S` に丸めずに臨界値と掛け、端点を `S` に 1 回だけ丸める。
`interval` は標準誤差を先に `S` に丸めるので、標準誤差が非正規化数の範囲にあると、丸めた標準誤差と臨界値の積をもう一度丸めることになる。
標準誤差が `S` の最小の非正規化数より小さければ、`interval` では 0 に丸めた標準誤差から幅 0 の区間ができるが、`interval_scaled` は 0 でない端点を返しうる。
区間の `standard_error()` は標準誤差を `S` に丸めた値を返すが、端点の計算には丸める前の値を使う。

次のセルは、偏差 $[-1.5, -0.5, 0.5, 1.5]$ を $2^k$ 倍した 4 点（$2^k$ 倍は f64 で正確）で、二つの経路を比べる。
$k = 0$ の平均の分散は $5/12$、標準誤差は $\sqrt{5/12}$、95% の t 区間（自由度 3）の半幅は $t_{3,\,0.975}\sqrt{5/12}$ である。

既定の $k = -540$ では、平均の分散 $\tfrac{5}{12} \cdot 2^{-1080}$ は f64 の最小の非正規化数 $2^{-1074}$ より小さいので、`variance_of_sample_mean` は 0 を返し、相対誤差は 1 になる。
`scaled_variance_of_sample_mean` は同じ量を正確に保ち、標準誤差と二つの区間の上端も参照値と一致する。
$k = 600$ では、平均の分散 $\tfrac{5}{12} \cdot 2^{1200}$ が f64 であふれて `Err` になるが、他の経路は参照値と一致する。

$k = -1073$ では、標準誤差 $\sqrt{5/12} \cdot 2^{-1073} \approx 1.29 \cdot 2^{-1074}$ が非正規化数の最小単位 $2^{-1074}$ の近くまで小さくなる。
`standard_error_of_sample_mean` はこれを $2^{-1074}$ に丸め、相対誤差は 23% になる。
丸めた標準誤差から作る `confidence_interval_of_mean` の上端は $3 \cdot 2^{-1074}$（$2^{-1073}$ で割ると 1.5）で、参照値 2.054 から 27% ずれる。
`interval_scaled` は丸める前の標準誤差に臨界値を掛けてから 1 回だけ丸めるので、上端は真の値 $4.11 \cdot 2^{-1074}$ に最も近い $4 \cdot 2^{-1074}$（割ると 2.0）になり、ずれは 2.6% にとどまる。
この残りのずれは、f64 で表せる最も近い値への丸めによるもので、これより小さくはできない。

## 信頼度と区間幅

振り子で測った重力加速度 6 個 $[9.78, 9.81, 9.80, 9.83, 9.79, 9.82]$ m/s² に重み $[1, 2, 3, 1, 2, 1]$ を付け、同じ値と重みを三つの意味で集計する。
重みは回数・代表性・相対精度のどれとしても読める。
次の定義のブロックは、この測定値と重みと、モデル `M` の要約を作る補助関数をまとめる。
このページの二つのセルが使う。

```rust

/// 重みのモデル M で値と重みを集計したスナップショット。

    weights: &[f64],

}
```

## 重みの意味と被覆率

重みの意味を取り違えると、平均の分散の推定量の期待値は真の分散からずれる。
真のモデルごとに、三つの推定量の期待値と真の分散の比を求めておく。

真のモデルが信頼度のモデル（$x_i$ は独立で共通の分散 $\sigma^2$、重みは分散と無関係）のときは、$\mathrm{Var}(\bar x_w) = \sigma^2 Q/W^2$、$E[S_w] = \sigma^2(W - Q/W)$ である。
解析的重みの推定量 $S_w/((n-1)W)$ の期待値と真の分散の比は $(n_{\mathrm{eff}} - 1)/(n - 1) \le 1$ になり、重みが不均一なほど分散を過小に見積もる。
頻度重みの推定量 $S_w/((W-1)W)$ の比は $(n_{\mathrm{eff}} - 1)/(W - 1)$ で、重みの和 $W$ が大きいほど分散を過小に見積もる。

真のモデルが解析的なモデル（$\mathrm{Var}(x_i) = \tau^2/w_i$）のときは、$\mathrm{Var}(\bar x_w) = \tau^2/W$、$E[S_w] = (n-1)\tau^2$ である。
信頼度重みの推定量 $S_w Q/(W^2 (W - Q/W))$ の比は $(n-1)/(n_{\mathrm{eff}} - 1) \ge 1$ で、区間は広すぎる（保守的になる）。
頻度重みの推定量の比は $(n-1)/(W-1)$ で、やはり重みの尺度に依存する。

分散の推定量の偏りは、区間の被覆率のずれとして現れる。
次のセルは、選んだ真のモデルから振り子の測定値を乱数で $R = 4000$ 回作り直し、三つの重みの意味の 95% t 区間が真の平均 $\mu = 9.80$ m/s² を含んだ割合を数える。
重みは前のセルと同じ $[1, 2, 3, 1, 2, 1]$ の $c$ 倍で、標準偏差は重み 1 の測定で $\sigma = 0.02$ m/s² とする。
被覆率の Monte Carlo 標準誤差は $\sqrt{\hat p(1-\hat p)/R}$ である。
表の「分散の比」の列は、上で導いた期待値の比を重みから計算した値で、被覆率のずれの向きを予測する。

```rust

//| ref: stats-weight-coverage
//| title: 真のモデルを選んで三つの重みの意味の区間の被覆率を測る
//| run: reactive
//| crates: [scioxide-stats, scioxide-random]
//| uses: [stats-pendulum-weights]
//| inputs:
//|   true_model: {"type":"select","label":"データを作る真のモデル","options":["解析的（精度が重みに比例）","信頼度（分散は共通）"],"value":"解析的（精度が重みに比例）"}
//|   weight_scale: {"type":"range","label":"重みの倍率 c [-]","description":"すべての重みを c 倍する。","min":1,"max":4,"step":1,"value":1}
//|   sampling_seed: {"type":"integer","label":"乱数のシード","min":0,"max":100000,"value":7}
//| cases:
//|   - {"id":"reliability-truth","label":"真のモデルが信頼度","description":"解析的重みの区間が名目値より狭くなる。","inputs":{"true_model":"信頼度（分散は共通）"}}
//|   - {"id":"scaled-weights","label":"c = 4","description":"頻度重みの区間だけが倍率で変わる。","inputs":{"weight_scale":4}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"coverage","path":"/rows/0/1","approx":{"value":0.5555555555555556,"rtol":1e-12}}
//|       - {"artifact":"coverage","path":"/rows/1/1","approx":{"value":1.25,"rtol":1e-12}}
//|       - {"artifact":"coverage","path":"/rows/2/2","approx":{"value":0.95,"atol":0.012}}
//|       - {"artifact":"coverage","path":"/rows/0/2","range":{"max":0.9}}
//|       - {"artifact":"coverage","path":"/rows/1/2","range":{"min":0.96}}
//|   - case: reliability-truth
//|     expect:
//|       - {"artifact":"coverage","path":"/rows/2/1","approx":{"value":0.8,"rtol":1e-12}}
//|       - {"artifact":"coverage","path":"/rows/2/2","range":{"max":0.947}}
//|       - {"artifact":"coverage","path":"/rows/1/2","range":{"min":0.95}}
//|   - case: scaled-weights
//|     expect:
//|       - {"artifact":"coverage","path":"/rows/0/1","approx":{"value":0.1282051282051282,"rtol":1e-12}}
//|       - {"artifact":"coverage","path":"/rows/0/2","range":{"max":0.6}}
//|       - {"artifact":"coverage","path":"/rows/2/2","approx":{"value":0.95,"atol":0.012}}
use scioxide_random::{Distribution, Normal, SeedableRng, SplitMix64};
use scioxide_stats::{
    Analytic, ConfidenceProbability, Frequency, MeanIntervalMethod, MeanIntervalPlan,
    MomentWeights, Reliability,
};

const REPLICATES: usize = 4000;
let (mu, sigma) = (9.80_f64, 0.02_f64);
let weights = pendulum_weights().map(|w| w * weight_scale);
let analytic_truth = true_model.starts_with("解析的");
let (n, w, q) = (
    weights.len() as f64,
    weights.iter().sum::<f64>(),
    weights.iter().map(|w| w * w).sum::<f64>(),
);
let n_eff = w * w / q;
// 期待値の比 E[推定した平均の分散] / Var(加重平均)（本文の式）。順に頻度・信頼度・解析的。
let ratios = if analytic_truth {
    [(n - 1.0) / (w - 1.0), (n - 1.0) / (n_eff - 1.0), 1.0]
} else {
    [(n_eff - 1.0) / (w - 1.0), 1.0, (n_eff - 1.0) / (n - 1.0)]
};
// 自由度は重みだけで決まるので、臨界値はモデルごとに一度だけ計算する。
fn plan_for<M: MomentWeights>(weights: &[f64]) -> Result<MeanIntervalPlan, String> {
    let snapshot = weighted_snapshot::<M>(&pendulum_values(), weights)?;
    let degrees = snapshot
        .degrees_of_freedom()
        .map_err(|e| e.to_string())?
        .ok_or("自由度が未定義")?;
    MeanIntervalPlan::new(
        ConfidenceProbability::default(),
        MeanIntervalMethod::StudentT,
        Some(degrees),
        Default::default(),
    )
    .map_err(|e| e.to_string())
}
fn covers<M: MomentWeights>(
    values: &[f64],
    weights: &[f64],
    plan: MeanIntervalPlan,
    mu: f64,
) -> Result<bool, String> {
    let snapshot = weighted_snapshot::<M>(values, weights)?;
    let mean = snapshot
        .mean()
        .map_err(|e| e.to_string())?
        .ok_or("平均が未定義")?;
    let se = snapshot
        .standard_error_of_weighted_mean()
        .map_err(|e| e.to_string())?
        .ok_or("標準誤差が未定義")?;
    let bounds = plan.interval(mean, se).map_err(|e| e.to_string())?.bounds();
    Ok(bounds.lower() <= mu && mu <= bounds.upper())
}
let plans = [
    plan_for::<Frequency>(&weights)?,
    plan_for::<Reliability>(&weights)?,
    plan_for::<Analytic>(&weights)?,
];
let standard = Normal::new(0.0_f64, 1.0).map_err(|e| e.to_string())?;
let mut rng = SplitMix64::from_seed(sampling_seed as u64);
let mut hits = [0_usize; 3];
let mut values = [0.0_f64; 6];
for _ in 0..REPLICATES {
    for (x, &wi) in values.iter_mut().zip(&weights) {
        let z = standard.sample(&mut rng).map_err(|e| e.to_string())?;
        // 解析的: 標準偏差 σ/√(w/c)（重み 1 の測定で σ）。信頼度: 共通の σ。平方根は f64 の参照値。
        let sd = if analytic_truth {
            sigma / (wi / weight_scale).sqrt()
        } else {
            sigma
        };
        *x = mu + sd * z;
    }
    hits[0] += usize::from(covers::<Frequency>(&values, &weights, plans[0], mu)?);
    hits[1] += usize::from(covers::<Reliability>(&values, &weights, plans[1], mu)?);
    hits[2] += usize::from(covers::<Analytic>(&values, &weights, plans[2], mu)?);
}
let names = ["頻度", "信頼度", "解析的"];
let rows: Vec<_> = (0..3)
    .map(|j| {
        let p = hits[j] as f64 / REPLICATES as f64;
        (
            names[j],
            ratios[j],
            p,
            (p * (1.0 - p) / REPLICATES as f64).sqrt(),
        )
    })
    .collect();
let fixed3 = serde_json::json!({ "fractionDigits": 3 });
let fixed4 = serde_json::json!({ "fractionDigits": 4 });
let columns = serde_json::json!([
    { "key": "0", "label": "重みの意味", "type": "string" },
    { "key": "1", "label": "分散の比（期待値）[-]", "type": "number", "format": fixed3 },
    { "key": "2", "label": "被覆率 [-]", "type": "number", "format": fixed4 },
    { "key": "3", "label": "被覆率の標準誤差 [-]", "type": "number", "format": fixed4 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "coverage" })
);
```

既定の真のモデル（解析的）、シード 7 では、解析的重みの区間の被覆率は 0.954（標準誤差 0.003）で、名目の 0.95 と標準誤差の 2 倍以内で一致する。
信頼度重みの区間は 0.974 で広すぎ、分散の比 1.25 の予測どおり保守的である。
頻度重みの区間は 0.849 で、分散の比 0.56 のとおり狭すぎる。

真のモデルを信頼度にすると、信頼度重みの区間は 0.967、解析的重みの区間は 0.939 になる。
解析的重みの分散の比は 0.8 で、区間は名目値より狭い。
信頼度重みの区間は 0.95 を標準誤差の 6 倍ほど上回り、自由度 $n_{\mathrm{eff}} - 1 = 4$ の t 分布による近似（`EffectiveSampleApproximation`）がこの重みでは保守的に働いたことを示す。
頻度重みは 0.810 で、倍率 $c = 4$ にすると、どちらの真のモデルでも分散の比が 0.13 以下に下がり、被覆率は 0.5 を下回る。
頻度重みの区間は、重みが本当に同じ値の反復回数であるときにだけ使う。

## まとめ

加重平均の値は重みの意味によらないが、標準誤差と自由度は意味ごとに違う。
頻度重みは展開した標本と同じ推定量を与え、重みの倍率で標準誤差が変わる。
信頼度重みと解析的重みは倍率に対して不変で、それぞれ Kish の有効標本サイズと記録の数を自由度の基礎にする。
重みの意味は型 `Frequency`・`Reliability`・`Analytic` で選び、要約の `effective_sample_size`・`degrees_of_freedom`・`noise_scale` と、区間に記録された `MeanIntervalAssumptions` を合わせて読む。
重みの意味を取り違えると区間の被覆率は名目値から外れ、独立性や正規性が破れたときも同じように外れる。
データの尺度が f64 の範囲の端に近いときは、`scaled_variance_of_sample_mean` と `interval_scaled` で平均の分散を丸めずに区間まで運ぶ。
