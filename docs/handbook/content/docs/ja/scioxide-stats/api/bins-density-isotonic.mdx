このページは、標本全体を保持して分布や回帰関数の形を推定する三つの手法（ビン集計、ガウス核密度推定、単調回帰）と、その入力の共通の型をまとめる。
ビン集計と核密度推定は、経験分布関数と同じく `BatchView`（標本の軸・座標の軸・残りの一括処理の軸を持つ借用した N 次元配列）と `StatisticsOptions` を受け取る。
単調回帰の軸ごとの形は順序統計と同じ `BatchView` を使う。
`_into` の関数は、要件を求めて作業領域を `try_reserve` したあとは確保せず、エラーのときは呼び出し側の出力をすべて変えない。
所有値を返す API の関数は新しい作業領域で同じ計算を逐次に実行し、出力を確保して返す。
重みなしの 1 次元の標本には、ワンショット関数 `histogram(values, bins)`、`GaussianKde::new(values)`、`isotonic_regression(values)` を既定の設定で使える。

## 統計評価の入力と方針

ビン集計・核密度推定・軸ごとの単調回帰は、共有の `BatchView`・`StatisticsOptions` と事前確保済みの作業領域を使う。
[共通の入力と出力の仕様](oxref:stats-input-validation-and-missing)を参照する。
