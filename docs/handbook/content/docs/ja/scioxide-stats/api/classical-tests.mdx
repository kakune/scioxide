このページは独立な標本、対応のある組、完全なブロックに対する古典的な検定と、それらが共有する設定と結果の型をまとめる。
`weighted_kendall_tau` を除く各検定はワンショット関数 `f(data)` とオプション付き形式 `f_with_options(data, options)` を持ち、どちらも共通の `ClassicalTestResult` を返す。
ワンショット関数は `ClassicalOptions::default()`（両側の対立仮説、較正 `Auto`、95% の区間、正確法の状態数 100 000 まで、半単位の連続性補正）でオプション付き形式を呼び、Chatterjee と Page の検定だけは対立仮説を `Greater` にする。
独立二標本の $t$ 検定は `Welch`、符号付き順位検定は差 0 の `Discard`、Brunner–Munzel 検定は参照分布 `Student` をワンショット呼び出しの既定値にする。
結果の `method` には、要求した較正ではなく実際に使った参照分布（Student の $t$ 分布、正規近似、正確な帰無分布、置換）が入り、`p_value()` はつねに $[0,1]$ の数値を返す。
長さや有限性の検査に通らない入力、定数標本のように統計量が定義されない場合、検定が対応しない較正の明示的な要求は `Err` を返し、別の方法に切り替えない。
分類は `InvalidInput` が基本で、非有限値は `NonFinite`、長さの不一致は `DimensionMismatch`、$t$ 検定の標準誤差 0 は `NumericalInstability`、`Exact` を要求して正確法が `max_work` を超える場合は `ConvergenceFailure`、作業領域が `max_workspace_bytes` を超える場合は `ResourceLimit` である。
返す区間は統計的な推定であり、真値を含むことを保証する包含区間ではない。
