このページは整数の度数で表したデータの検定と、多数の検定の p 値を扱う手続きをまとめる。
分割表は `ContingencyView`（行優先の `usize` の度数の借用）で検査してから渡し、度数を個々の観測へ展開しない。
周辺和と総数は `u128` の整数で数え、あふれると `SizeOverflow` になる。
ワンショット関数 `chi2_contingency_test(table)`、`fisher_exact_test(table)`、`barnard_exact_test(table)`、`boschloo_exact_test(table)` は既定の設定で検定する。
設定を選ぶときは `power_divergence_contingency_test` かオプション付き形式 `…_with_options` を使う。
カイ二乗の p 値は大標本での漸近分布による近似で、有限の帰無分布の正確な確率ではない。
正確検定は近似へ切り替えず、`ClassicalOptions` の上限に従って、調べる表の数が `max_work` を超えると `ConvergenceFailure`、作業領域が `max_workspace_bytes` を超えると `ResourceLimit` を返す。
多重検定の調整は結果を元の仮説の順に返し、すべての p 値の調整が成功してから出力に書く。
