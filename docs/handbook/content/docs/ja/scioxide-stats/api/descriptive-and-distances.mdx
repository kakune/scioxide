このページは標本の位置・ばらつき・形・情報量と、二つの分布の隔たりを測る記述統計をまとめる。
`mean`・`sample_variance`・`median`・`quantile` などのワンショット関数は重みなしの標本を受け取り、除数 $n-1$、Hyndman–Fan の第 7 種の分位点、欠測・非有限値の拒否という既定の規約で計算する。
スカラーの統計量を求める `statistic` は、和・平均・分散・極値・円周統計・エントロピーなどを作業領域なしで計算し、ほかの統計量では作業領域を一度だけ確保する。
軸ごとの統計はワンショット関数 `statistics`・`rolling_statistics`、`StatisticsOptions` を受け取るオプション付き形式 `…_with_options`、出力と作業領域と実行コンテキストを受け取る出力先を指定する API `…_into` の順に、選べる設定が増える。
出力先を指定する API は `BatchView` と `StatisticsOptions` を受け取り、すべての一括処理が成功してから出力に書く。
平均方向のように定義されない量は `None` で表し、0 や NaN で置き換えない。
発散する情報量は `InformationValue` の無限大で表す。
統計量が定義されないスカラー型と重みの組は `Statistic` のコンストラクターがないので、コンパイルできない。
