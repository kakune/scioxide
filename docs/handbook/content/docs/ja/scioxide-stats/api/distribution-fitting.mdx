このページはパラメトリックな分布の当てはめと、べき変換のパラメータ選択をまとめる。
scioxide-stats は目的関数（負の対数尤度、モーメントや分位点の一致の残差平方和）を準備するだけで、最適化のアルゴリズムを持たない。
最小化は呼び出し側が渡す `FitSolver` の実装が行う。
scioxide-stats はソルバーの機能を呼び出しの前に検査し、ソルバーが返した候補で目的関数を評価し直してから出力へ書く。
当てはめの API（`fit`、`ppcc_max`、`power_transform_normmax`）は、ワンショット呼び出し形、オプション付き形式、スコープ付き API の三つの形を持ち、`fit` にはさらに出力先を指定する API `fit_into` がある。
ワンショット呼び出し形はワンショット呼び出しの既定値（`StatisticsOptions::default()`）で逐次に実行し、成功の終了（`Converged`）だけを受け付ける。
`BudgetExhausted` と `NotConverged` は `NestedSolver` の `ConvergenceFailure`、`Stopped` は `ExecutionStopped` のエラーになる。
オプション付き形式 `…_with_options` は `StatisticsOptions` を受け取り、スコープ付き API `…_scoped` はさらに実行コンテキストか親の `SolveContext` を受け取る。
どちらも成功以外の終了を `Ok` のレポートで返す。
出力先を指定する API `fit_into` は呼び出し側の出力と `FitWorkspace` へ書く。
ソルバーは自分に設定した反復の上限と、共有の評価回数の上限と停止の要求に従い、親の反復の上限には縛られない。
成否は `StatsTermination` だけで判定する。
`Converged` はソルバーの停止条件を満たしたという提示内容で、統計的な識別可能性や大域的最適性の保証ではない。
