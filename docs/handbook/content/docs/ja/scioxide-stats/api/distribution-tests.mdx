この表は分布の形、正規性、尺度の等しさ、中央値を調べる検定をまとめる。
結果は共通の `DistributionTestResult` で、p 値に実際に使った較正（`DistributionMethod`）と、帰無分布のパラメータを固定したか標本から推定したか（`NullParameters`）を明示する。
各検定はワンショット関数 `f(data)` と、`ClassicalOptions` を受け取るオプション付き形式 `f_with_options(data, …, options)` を持つ。
ワンショット関数は `ClassicalOptions::default()` を使う。
そのうえで `levene_test`・`fligner_test` は中心 `Median`、`anderson_k_sample_test` は `Midrank`、`median_test` は同順位 `Below` を使い、`median_test` の 2 群の Yates の補正は既定の `ClassicalOptions::continuity`（`HalfUnit`）で掛かる。
パラメータを推定した帰無仮説では、パラメータを固定した検定の帰無分布は正しい p 値を与えないので、複製ごとにパラメータを推定し直す `goodness_of_fit_test_into` のパラメトリックブートストラップを使う。
総括（omnibus）の検定は `ClassicalOptions` の対立仮説に `TwoSided` を要求して上側確率を返し、近似の較正だけを持つ検定は `TestCalibration::Exact` の要求を拒否する。
これらの拒否は `InvalidInput`、非有限値は `NonFinite` になる。
`Exact` を要求して正確法が `max_work` を超えると `ConvergenceFailure`、作業領域が `max_workspace_bytes` を超えると `ResourceLimit` になる。
