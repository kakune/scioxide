このページは、標本を整列または選択して求める統計量をまとめる。
分位点・裾平均・順位・最頻値・エクスペクタイル・経験分布関数がこれに当たる。
どの結果も使った規約（`QuantileConvention`、`TailMeanConvention`、`RankMethod` など）を値と一緒に返すので、呼び出し側はそれを記録できる。
`_in_place` の関数は呼び出し側の作業用の配列をその場で並べ替え、複製しない。
配列は並べ替える前に検査するので、不正な入力では配列を変えない。
成功すると配列は入力の置換になる。
軸ごとの `_into` の関数は作業領域を `try_reserve` で事前確保したあとは確保せず、エラーのときは出力を変えない。
