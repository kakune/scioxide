`scioxide-stats` は、標本から統計量を推定し、その不確かさを返すクレートである。
出力に反映する手続きは、標本を保持しない逐次のモーメントと共分散、整列と選択による分位点と裾平均、ビン集計・核密度推定・単調回帰、記述統計と分布間の距離、古典的な検定と分布の検定、分割表と多重検定、回帰と一般化線形モデル、分布の当てはめ、リサンプリングと検出力、確率によるパラメータの逆算と共役事後分布、生存時間解析と時系列、多変量の推定である。
このガイドは目的ごとに API となる項目を示し、公開されている 635 項目を用途別の表にまとめる。
表の項目名のリンクは、docs.rs の 0.1.0 の API リファレンスを指す。

## 型の関係

### 累積器と要約

`OnlineMoments` などの累積器は `observe` で観測を 1 つずつ加え、`merge` で別の累積器の状態を合わせる。
`snapshot` は状態を複製した不変な要約を返し、失敗しない。
要約は平均・分散・標準誤差を照会のたびに丸め、`Result<Option<S>, SciOxideError>` で返す。
`S` の範囲に収まらない量を丸めずに読むには、`MomentsSnapshot::scaled_variance_of_sample_mean` で平均の分散 $s^2/n$ を拡張指数の `Scaled<S>` として受け取る。

### 借用ビューと方針

一括の関数は、値の配置を表す借用のビュー（`BatchView`）と、欠測・非有限値・実行の方針（`StatisticsOptions`）を受け取る。
ビューは軸（`Axis`）で標本の軸を選び、残りの軸は独立な一括処理の番号になる。
欠測マスクと重みは、物理的なストライドによらず、一括処理の番号を外側、標本の番号を内側にした観測順で与える。

### 呼び出しの形

多くの手続きは設定を選べる範囲の狭い順に次の形を持つ。

- ワンショット関数 `f(data)` は問題のデータだけを受け取り、作業領域と出力を確保して、逐次のネイティブ実行で答える（`mean`、`t_test_one_sample`、`kaplan_meier`、`bootstrap`）。
  設定は下の表の既定値に固定される。
- オプション付き形式 `f_with_options(data, …, options)` は `Default` を実装した設定（`ClassicalOptions`、`StatisticsOptions`、`MultivariateOptions` など）や規約の引数を受け取る。
  準備の型では、`new(data)` が準備を一括して行うコンストラクター、`with_options` がオプション付き形式にあたる（`PreparedPca`、`PreparedCca`、`GaussianKde`）。
- 準備の型（`Prepared…`、`…Plan`）は、検査と前処理を一度だけ行う。
  所有値を返す API の `fit`・`evaluate`・`test` は結果を確保して返す。
- スコープ付き API `f_scoped(…, scope)` と準備の型の `fit_scoped` は根の実行コンテキスト（`ExecutionContext`）か親の求解の `SolveContext` を受け取り、評価回数の上限と取り消しを親と共有する。
- 出力先を指定する API `f_into(…, output, workspace, context)` は要求量を問い合わせて事前確保した作業領域（`…Workspace`、`…Requirements`）と呼び出し側の出力を使い、事前確保の後は確保しない。

ワンショット関数が固定する設定は次のとおりである。

| 選択 | ワンショット呼び出しの値 |
|---|---|
| 重み | 重みなし（重みのモデルを主題とする関数を除く） |
| 標本の散らばりの除数 | $n-1$ |
| 分位点 | Hyndman–Fan の第 7 種（線形補間） |
| 平均の区間 | 両側 95% の Student の t 区間、自由度 $n-1$ |
| 検定の対立仮説 | 両側（Chatterjee と Page は `Greater`） |
| 検定の較正 | `Auto` |
| 連続性補正 | 半単位（2×2 の表の Pearson の統計量では Yates の補正） |
| 独立二標本の t 検定 | Welch（分散が等しいと仮定しない） |
| 符号付き順位検定の差 0 | 除く（`Discard`） |
| Brunner–Munzel の参照分布 | Student の t |
| 分散の検定の中心 | 中央値 |
| Anderson–Darling の k 標本の同順位 | 中央順位 |
| 中央値の検定で併合中央値に等しい観測 | 中央値より下に数える（`Below`） |
| 単調回帰の向き | 増加 |
| ロバストな傾きの切片 | 残差の切片 $y_i - \hat\beta_1 x_i$ の中央値（`Joint`） |
| 核密度推定の帯域幅 | Scott の規則、全共分散 |
| 欠測と非有限値 | 拒否 |
| ブートストラップ | 独立な BCa、9999 回、95% |
| 置換 | 独立な乱択の割り当て、9999 回 |

乱数を使うワンショット関数も生成器を引数で受け取り、内部でシードを決めない。
jackknife は生成器を使わない。
設定の型はフィールドを公開せず、失敗しない設定のメソッドと `Default` を持ち、準備か実行のときに値を検査する。

### 注入するソルバーと生成器

分布の当てはめ、Cox 回帰、ARIMA、非線形の直交距離回帰、最適輸送は最適化法を内蔵しない。
scioxide-stats が目的関数を準備し、呼び出し側が渡す `FitSolver` や `TransportSolver` が解く。
GLM は内蔵の反復重み付き最小二乗法で解き、`GlmSolver::Injected` を選ぶと、内蔵の反復の代わりに渡した `FitSolver` が目的関数を最小化する。
乱数を使う手続きは scioxide-random の生成器を引数で受け取り、環境の暗黙の乱数を使わない。
取り消しと期限は scioxide-core の `ExecutionContext` か親の `SolveContext` で伝える。
注入したソルバー、リサンプリング、σ クリッピングの反復の上限は呼び出しごとの設定（ソルバーの上限、複製の数、通過の上限）で決まり、親の反復の上限には縛られない。
子の評価と生成器の呼び出しは、親が共有するすべての計算回数の上限に数える。

### 規約を持つ結果

分位点・裾平均・信頼区間・検定の結果は、使った規約（`QuantileConvention`、`TailMeanConvention`、`MeanIntervalMethod`、`ClassicalMethod` など）と仮定を値と一緒に返す。

## 最小の実行例：分けた集計の結合と 2 パスの検算

8 個の観測を前半 $k$ 個と後半に分け、別々の `OnlineMoments` で集計してから `merge` で結合する。
最初の表は結合する前の 2 つの部分の要約で、$k$ を変えると件数と値が変わる。
観測が 0 個の部分の平均と、1 個以下の部分の標本分散は定義されないので `None` になり、「未定義」と表示される。
2 つ目の表は結合した要約の平均・分散・歪度・超過尖度を、平均を先に求めてから偏差の冪和を取る 2 パスの計算と比べる。
2 パスの計算は f64 の固有メソッドによる独立な参照値である。
続いて `confidence_interval_of_mean()` で平均の両側 95% 区間を読み、NaN を渡したときのエラーの分類と、エラーの後に累積器が変わらないことを確かめる。

```rust
//| id: stats-api-split-moments
//| ref: stats-api-split-moments
//| title: 分けて集計したモーメントを結合して 2 パスの計算と照合する
//| run: reactive
//| crates: [scioxide-stats]
//| inputs:
//|   split: {"type":"range","label":"前半に入れる観測数 k [個]","description":"前半と後半を別々に集計する境目。0 と 8 では片方が空になる。","min":0,"max":8,"step":1,"value":3}
//| cases:
//|   - {"id":"empty-left","label":"k = 0","description":"前半が空なので、前半の平均と標本分散は未定義になり、結合は後半の要約そのものになる。","inputs":{"split":0}}
//|   - {"id":"singleton-left","label":"k = 1","description":"前半は 1 個なので、平均は定義されるが標本分散は未定義になる。","inputs":{"split":1}}
//|   - {"id":"empty-right","label":"k = 8","description":"後半が空なので、空の累積器との結合は恒等になる。","inputs":{"split":8}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"parts","path":"/rows/0/1","equals":3}
//|       - {"artifact":"parts","path":"/rows/0/2","approx":{"value":3.3333333333333335,"rtol":1e-14}}
//|       - {"artifact":"parts","path":"/rows/1/2","approx":{"value":12.4,"rtol":1e-14}}
//|       - {"artifact":"moments","path":"/rows/0/1","approx":{"value":9,"rtol":1e-15}}
//|       - {"artifact":"moments","path":"/rows/2/1","approx":{"value":80.57142857142857,"rtol":1e-14}}
//|       - {"artifact":"moments","path":"/rows/3/3","range":{"max":1e-14}}
//|       - {"artifact":"moments","path":"/rows/4/3","range":{"max":1e-14}}
//|       - {"artifact":"interval","path":"/rows/0/2","equals":7}
//|       - {"artifact":"interval","path":"/rows/0/3","approx":{"value":1.4958,"atol":1e-3}}
//|       - {"artifact":"interval","path":"/rows/0/4","approx":{"value":16.5042,"atol":1e-3}}
//|       - {"artifact":"interval","path":"/rows/0/5","equals":"StudentT"}
//|       - {"artifact":"error","path":"/rows/0/1","equals":"NonFinite"}
//|       - {"artifact":"error","path":"/rows/0/2","equals":1}
//|   - case: empty-left
//|     expect:
//|       - {"artifact":"parts","path":"/rows/0/1","equals":0}
//|       - {"artifact":"parts","path":"/rows/0/2","equals":null}
//|       - {"artifact":"parts","path":"/rows/0/3","equals":null}
//|       - {"artifact":"moments","path":"/rows/0/1","approx":{"value":9,"rtol":1e-15}}
//|       - {"artifact":"moments","path":"/rows/4/3","range":{"max":1e-14}}
//|   - case: singleton-left
//|     expect:
//|       - {"artifact":"parts","path":"/rows/0/2","approx":{"value":2,"rtol":1e-15}}
//|       - {"artifact":"parts","path":"/rows/0/3","equals":null}
//|       - {"artifact":"moments","path":"/rows/2/1","approx":{"value":80.57142857142857,"rtol":1e-14}}
//|       - {"artifact":"moments","path":"/rows/2/3","range":{"max":1e-13}}
//|   - case: empty-right
//|     expect:
//|       - {"artifact":"parts","path":"/rows/1/1","equals":0}
//|       - {"artifact":"parts","path":"/rows/1/2","equals":null}
//|       - {"artifact":"moments","path":"/rows/3/1","approx":{"value":1.8169,"atol":1e-4}}
use scioxide_stats::{BiasCorrection, KurtosisConvention, MomentOrder, OnlineMoments};

// 単位のない 8 個の観測。最後の 30 が右の裾を作る。
let data = [2.0_f64, 4.0, 4.0, 5.0, 7.0, 9.0, 11.0, 30.0];
let k = split as usize;
// 前半と後半を、4 次の中心モーメントまで保持する別々の累積器で集計する。
let mut left = OnlineMoments::new(MomentOrder::Fourth);
let mut right = OnlineMoments::new(MomentOrder::Fourth);
for &x in &data[..k] {
    left.observe(x).map_err(|e| e.to_string())?;
}
for &x in &data[k..] {
    right.observe(x).map_err(|e| e.to_string())?;
}

let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let digits = serde_json::json!({ "significantDigits": 15 });
let fixed4 = serde_json::json!({ "fractionDigits": 4 });

// 結合する前の部分の要約。0 個の平均と 1 個以下の標本分散は None になる。
let mut parts = Vec::new();
for (name, part) in [("前半", &left), ("後半", &right)] {
    let s = part.snapshot();
    let mean = s.mean().map_err(|e| e.to_string())?;
    let variance = s.sample_variance().map_err(|e| e.to_string())?;
    parts.push((name, s.count(), mean, variance));
}
emit_table_with_columns!(
    serde_json::json!([
        { "key": "0", "label": "部分" },
        { "key": "1", "label": "件数 [個]", "type": "integer" },
        { "key": "2", "label": "平均 [-]", "type": "number", "format": digits, "nullText": "未定義" },
        { "key": "3", "label": "標本分散 [-]", "type": "number", "format": digits, "nullText": "未定義" }
    ]),
    parts,
    metadata = serde_json::json!({ "id": "parts" })
);

left.merge(&right).map_err(|e| e.to_string())?;
let s = left.snapshot();

// 独立な検算: 平均を先に求め、偏差の冪和を取る 2 パスの計算（f64 の固有メソッドによる参照値）。
let n = data.len() as f64;
let mean = data.iter().sum::<f64>() / n;
let central = |p: i32| data.iter().map(|x| (x - mean).powi(p)).sum::<f64>() / n;
let (m2, m3, m4) = (central(2), central(3), central(4));

// 8 個の観測ではどの量も定義されるので、None は理由を付けたエラーにする。
let undefined = || "8 個の観測では定義されるはずの量が未定義だった".to_string();
let rows = [
    ("平均", s.mean(), mean),
    ("母分散（除数 n）", s.population_variance(), m2),
    ("標本分散（除数 n-1）", s.sample_variance(), m2 * n / (n - 1.0)),
    ("歪度（補正なし）", s.skewness(BiasCorrection::None), m3 / m2.powf(1.5)),
    (
        "超過尖度（補正なし）",
        s.kurtosis(BiasCorrection::None, KurtosisConvention::Fisher),
        m4 / (m2 * m2) - 3.0,
    ),
];
let mut checks = Vec::new();
for (name, computed, reference) in rows {
    let c = computed.map_err(|e| e.to_string())?.ok_or_else(undefined)?;
    checks.push((name, c, reference, (c - reference).abs()));
}
emit_table_with_columns!(
    serde_json::json!([
        { "key": "0", "label": "量" },
        { "key": "1", "label": "結合した要約 [-]", "type": "number", "format": digits },
        { "key": "2", "label": "2 パスの検算 [-]", "type": "number", "format": digits },
        { "key": "3", "label": "差の絶対値 [-]", "type": "number", "format": sci3 }
    ]),
    checks,
    metadata = serde_json::json!({ "id": "moments" })
);

// 両側 95% の Student の t 区間。標本分散が未定義なら Ok(None) になる。
let interval = s
    .confidence_interval_of_mean()
    .map_err(|e| e.to_string())?
    .ok_or_else(undefined)?;
let method = format!("{:?}", interval.method());
let assumptions = format!("{:?}", interval.assumptions());
let bounds = interval.bounds();
emit_table_with_columns!(
    serde_json::json!([
        { "key": "0", "label": "推定値 [-]", "type": "number", "format": fixed4 },
        { "key": "1", "label": "標準誤差 [-]", "type": "number", "format": fixed4 },
        { "key": "2", "label": "自由度 [-]", "type": "number", "format": fixed4, "nullText": "なし" },
        { "key": "3", "label": "下端 [-]", "type": "number", "format": fixed4 },
        { "key": "4", "label": "上端 [-]", "type": "number", "format": fixed4 },
        { "key": "5", "label": "方法" },
        { "key": "6", "label": "仮定" }
    ]),
    vec![(
        interval.estimate(),
        interval.standard_error(),
        interval.degrees_of_freedom(),
        bounds.lower(),
        bounds.upper(),
        method,
        assumptions,

    metadata = serde_json::json!({ "id": "interval" })
);

// NaN はエラーになり、エラーの後も累積器の件数は変わらない。
let mut probe = OnlineMoments::<f64>::new(MomentOrder::Second);
probe.observe(1.0).map_err(|e| e.to_string())?;
let kind = match probe.observe(f64::NAN) {
    Ok(()) => return Err("NaN が受理された".to_string()),
    Err(error) => format!("{:?}", error.kind()),
};
emit_table_with_columns!(
    serde_json::json!([
        { "key": "0", "label": "渡した値" },
        { "key": "1", "label": "エラーの分類" },
        { "key": "2", "label": "エラーの後の件数 [個]", "type": "integer" }
    ]),
    vec![("NaN", kind, probe.count())],
    metadata = serde_json::json!({ "id": "error" })
);
```

既定の $k = 3$ では、前半の平均は $10/3 \approx 3.333$、後半の平均は $62/5 = 12.4$ である。
$k = 0$ では前半の平均と標本分散が、$k = 1$ では前半の標本分散が未定義になり、$k = 8$ では後半が空になる。

結合した要約の平均は 9、母分散は $564/8 = 70.5$、標本分散は $564/7 \approx 80.571$、補正なしの歪度は 1.8169、超過尖度は 1.9902 である。
既定の $k = 3$ では、差は歪度で $2.2 \times 10^{-16}$、超過尖度で $8.9 \times 10^{-16}$ で、ほかの量は一致する。
差が最も大きいのは $k = 1$ の母分散と標本分散の $1.4 \times 10^{-14}$ で、値に対する相対差は $2 \times 10^{-16}$ 程度である。
$k$ を変えても差は丸めの大きさにとどまり、結合の順序は丸めにだけ影響する。
空の部分を結合しても値は変わらず、$k = 0$ と $k = 8$ の結合は片方の要約そのものになる。

95% 区間は $[1.496, 16.504]$ で、方法は自由度 7 の `StudentT`、仮定は `IndependentNormal` と記録される。
この区間は独立な正規標本を仮定した名目上のものである。
外れた値 30 を含む 8 個の観測でその仮定が成り立つかは、この計算では確かめていない。
NaN を渡すと分類は `NonFinite` になり、エラーの後も件数は 1 のままである。

## 結果・エラー・診断の読み方

### 未定義と失敗の区別

逐次の要約での空の標本の平均や 1 点の標本分散、定数列の相関のように、数学的に定義されない量は `Option` の `None` で返す。
検定の結果はつねに数値の p 値を持つ。
入力の不正、表現できない結果、計算の破綻は `Err` で返し、0 や NaN で置き換えない。
要約の照会は量ごとに `Result<Option<S>, SciOxideError>` を返すので、ある量があふれて `Err` になっても、同じ要約のほかの量は読める。

### エラーの分類

失敗は scioxide-core の `SciOxideError` で返り、`kind()` で分類を読む。
このクレートで主に現れる分類は次のとおりである。

| 分類 | 主な原因 |
|---|---|
| `InvalidInput` | 統計量に足りない観測数、範囲外の確率や信頼水準、モデルが許さない負や非整数の重み、`MissingPolicy::Reject` の下の欠測、手法に当てはまらない設定 |
| `NonFinite` | `NonFinitePolicy::Reject` の下の NaN や無限大の観測、非有限の重みやパラメータ、呼び出し側の関数が返した非有限の値 |
| `DimensionMismatch` | データと長さが合わない欠測マスク・重み・出力・作業領域 |
| `NumericalInstability` | 標準誤差で割る検定での分散 0 のような退化した標本、出力の型の範囲を超える結果 |
| `ConvergenceFailure` | 正確検定・置換の列挙・反復が設定した作業量の上限（`ClassicalOptions::max_work` など）を超えたとき。ワンショット関数の未完了の終了（下の表） |
| `ResourceLimit`、`SizeOverflow`、`AllocationFailure` | 作業領域が `StatisticsOptions::max_bytes` などのバイト数の上限を超えるか、確保できないとき |
| `Singular` | ワンショット関数で、反復重み付き最小二乗法の計画行列が階数落ちしたとき |
| `ExecutionStopped` | ワンショット関数が取り消しや期限で止まったとき |
| `NotImplemented` | `FitDerivatives` が提供していない導関数をソルバーが要求したとき |
| `DomainError` | 分布の当てはめで確率 0 の観測があるとき（`PreparedFit`）など |

各関数の rustdoc がその関数の条件を挙げる。
呼び出し側の関数と標本抽出器が返したエラーは、そのまま伝わる。
エラーは何が失敗したか（分類、`Argument` か `Quantity`、詳細）を表し、呼び出し元の識別子を持たない。

### 出力の確定

すべての関数は出力に書く前に入力を検査する。
累積器の更新と出力先を指定する API の関数は、`Err` のとき状態や出力を変えない。
作業領域はエラーのときに変わることがあるが、そのまま再利用できる。
呼び出し側の関数と乱数の生成器は、エラーの前に呼ばれて状態が進んでいることがある。
`_in_place` の関数は、検査に失敗したときは配列を変えず、成功すると配列の順を変える。

### 終了理由

反復や上限を持つ手続き（GLM、Huber 回帰、分布の当てはめ、Cox 回帰、リサンプリング、模擬による検出力、パラメータの逆算など）のオプション付き形式・スコープ付き API・出力先を指定する API は、成否を 1 つの `StatsTermination` で返す。
上限・取り消し・期限で止まった場合も `Ok` でレポートを返す。
`StatsTermination::is_success()` は `Completed`、`Converged`、`ExactFit` で真になる。
これが偽のレポートの値を、収束した推定や完了した計算として扱わない。

ワンショット関数は未完了の推定を返さない。
成功の終了では答えを返し、ほかの終了理由は次のエラーにする。

| 終了理由 | ワンショット関数のエラー |
|---|---|
| `BudgetExhausted` | `ConvergenceFailure`。理由は GLM と Huber 回帰で `IterationLimit`、注入したソルバー（分布の当てはめ、`ppcc_max`、`power_transform_normmax`、Cox 回帰）で `NestedSolver`、リサンプリングで標本数のリソースの上限 |
| `Stopped` | `ExecutionStopped` |
| `NotConverged` | `ConvergenceFailure`（`NestedSolver`） |
| `NoProgress` | `ConvergenceFailure`（`Stagnation`） |
| `Separated` | `ConvergenceFailure`（`Divergence`） |
| `RankDeficient` | `Singular` |

### 三種類の不確かさ

浮動小数点の丸め誤差、統計的な不確かさ（標準誤差・信頼区間・p 値）、Monte Carlo の誤差（リサンプリングや模擬の反復数による）を区別する。
信頼区間・信用区間・検定の p 値は記録された仮定の下での推定であり、数値的な包含区間でも被覆率の保証でもない。

### 規約の記録

分位点の定義、裾平均の境界の扱い、区間の方法と自由度、検定で実際に使った較正は、結果に含まれる。
異なる規約の結果を比べるときは、値と一緒に規約を記録する。

## まとめ

API の表で目的に合う関数か型を選び、ワンショット関数で答えを得てから、設定が必要になったらオプション付き形式・準備の型・出力先を指定する API へ進む。
ワンショット関数は上の表の既定値を固定し、未完了の推定を返さずにエラーにする。
オプション付き形式以下は終了理由を `StatsTermination` で返すので、`is_success()` を確かめてから値を使う。
定義されない量は `None`、入力の不正や計算の破綻は `Err` で返り、結果は使った規約と仮定を記録する。
実行例では、分けて集計した累積器の結合が 2 パスの計算と丸めの範囲で一致し、空の部分との結合が恒等になることを確かめた。
