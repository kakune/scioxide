このページは、標本を保持せずに平均・分散・高次の中心モーメント・共分散を更新する累積器と、その結果から作る平均の信頼区間、ストライド付き配列のビュー（`BatchView`）の軸に沿った一括集約をまとめる。
累積器の `observe` と `merge` は確保せず、検査がすべて通ってから状態を書き換える。
エラーのときは状態を変えない。
定義されない統計量（空の標本の平均、1 点の標本分散、定数列の相関など）は `None` で表し、表現できない値や計算の破綻は `Err` で返す。
内部の状態は、値が `f64` の通常の範囲にある間は `f64` で持ち、範囲を外れると 2 進の指数を別に持つ拡張範囲の演算に切り替える。
平均は上位と下位の二つの部分からなる補償付きの値で持つ。
`snapshot` はこの状態を複製するだけで失敗しない。
要約の平均・分散・標準誤差は照会のたびに独立に丸め、`Result<Option<S>, SciOxideError>` で返す。
`S` で表せない（あふれる）量はその照会だけが `Err` になり、ほかの量の照会には影響しない。
`MomentsSnapshot::scaled_variance_of_sample_mean` は標本平均の推定分散 $s^2/n$ を拡張指数付きの `Scaled<S>` で返すので、`S` に丸めるとあふれる値やアンダーフローする値も保てる。
