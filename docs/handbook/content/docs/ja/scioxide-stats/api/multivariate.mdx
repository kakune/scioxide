このページは行を観測、列を変数とする密な行列から多変量の量を推定する手続きをまとめる。
入力は scioxide-linalg の `MatrixView`（連続またはストライド付きの借用）で、疎行列や作用素を暗黙に密にしない。
分解には scioxide-linalg の SVD と Hermite 固有値分解を使い、数値ランクは `RankPolicy` で明示した規約に依存する推定であって保証ではない。
`sample_covariance(data)` や `PreparedPca::new(data)` のようなワンショット関数と構築関数は既定の `MultivariateOptions` を使い、オプション付き形式 `…_with_options` で数値ランクの規約とメモリ使用量の上限を渡す。
`max_bytes` は準備に使うメモリ使用量、結果、要求する作業領域を制限し、超えると `ResourceLimit` を返す。
PCA と CCA はランクが決まる前に、完全な thin SVD の大きさで上限を確かめる。
