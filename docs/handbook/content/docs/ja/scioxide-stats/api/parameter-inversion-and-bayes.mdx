このページは確率分布のパラメータを確率から逆に求める手続きと、Bayes の事後分布の要約をまとめる。
逆算は「固定した観測で、裾確率 $P(X \le x)$ または $P(X > x)$ が目標値になるパラメータ」を、明示した区間の中で探す。
裾確率は scioxide-random の分布で対数のまま評価し、根の精度改善には scioxide-rootfind を使う。
単調性が保証されない場合や裾で区別できない場合は、根を推測せずに `Inconclusive` を返す。
逆算と信頼限界の関数は三つの形を持つ。
ワンショット関数は区間の端点を値で受け取り、既定の `InversionOptions` と、信頼限界では両側 95% を使う。
オプション付き形式 `…_with_options` は `InversionOptions` と、関数に応じて `Interval` の区間、信頼度、対立仮説を受け取って逐次に実行し、スコープ付き API `…_scoped` はさらに実行コンテキストか、評価回数の上限と取り消しを共有する親の `SolveContext` を受け取る。
信頼限界は標本抽出のモデルの下での頻度論的な集合で、信用区間は事後分布の質量であり、互いに置き換えない。
どちらも数値的な包含区間ではない。
