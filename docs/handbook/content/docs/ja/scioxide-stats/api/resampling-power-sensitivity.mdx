このページは乱数や列挙で標本分布を近似する手続きをまとめる。
乱数は呼び出し側が scioxide-random の生成器として渡し、環境の暗黙の乱数は使わない。
`SamplingPolicy` で、エラーのときに生成器の状態を進めたままにするか戻すかと、出力をまとめて書くか複製ごとに書くかを選ぶ。
添字付きの流れ（`ReplicateOptions::indexed`）はルート生成器を進めず、複製ごとに分割した流れを使うので、結果はワーカーの数によらない。
ワンショット関数 `bootstrap`・`jackknife`・`permutation_test`・`monte_carlo_test` は、統計量の関数と標本と（`jackknife` 以外は）生成器を受け取り、ワンショット呼び出しの既定値で Plan を作って推論だけを返す。
既定値は、`bootstrap` が独立な設計の両側 95% の BCa 区間で 9999 回、`permutation_test` が独立な 2 群の乱択の置換で 9999 回の両側検定、`monte_carlo_test` が 9999 個の帰無標本による両側検定である。
ワンショット関数は、すべての複製が完了しなければエラーを返す。
設計・方法・回数を選ぶときは `ResamplingPlan` を作り、出力と作業領域を確保する `evaluate` か、呼び出し側の出力と `workspace()` の作業領域を使う出力先を指定する API の `evaluate_into` で実行する。
Plan の実行は計算回数の上限・取り消し・期限で止まっても `Ok` のレポートを返し、完了したかは `StatsTermination` で判定する。
途中で止まったレポートには推論を付けない。
区間と p 値は統計的な推定で、保証付きの包含区間ではない。
