このページは時刻の順序に意味を持つデータの推定をまとめる。
生存時間は `SurvivalObservation`（区間 $(\text{参入}, \text{時刻}]$ で観測した独立な対象）で表し、同じ時刻の事象と打切りはどちらもその直前のリスク集合に含める。
区間はいずれも点ごとの漸近近似で、同時の帯ではない。
生存曲線と log-rank 検定のワンショット関数は観測だけを受け取り、既定の `SurvivalOptions` を使い、生存曲線の区間は両側 95% にする。
Cox 回帰と ARIMA は scioxide-stats が目的関数を準備し、`FitSolver` を実装した注入のソルバーが最小化する。
ワンショット呼び出しの `cox_fit` は既定の設定で成功の終了だけを受け付け、ほかの終了をエラーにする。
オプション付き形式 `cox_fit_with_options` とスコープ付き API `cox_fit_scoped` は上限で止まっても当てはめを返す。
成否は `FitReport` の終了理由だけで判定し、推論や予測のモデルは検証済みの候補からだけ作る。
時系列の要約は欠測を元の時刻の格子に残し、欠測を詰めて時刻の間隔を変えることはしない。
