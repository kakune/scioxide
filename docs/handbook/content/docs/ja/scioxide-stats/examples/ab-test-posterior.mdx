ウェブページの 2 つの案 A と B を訪問者に無作為に割り当て、購入や登録に至った割合（成功率）を比べることを A/B テストという。
頻度論の検定は「差がないとしたら、観測以上の差が出る確率」（p 値）を答える。
意思決定では、B の成功率が A を上回る確率や、B を採用して損をする量の期待値を知りたいことが多い。
ベイズ推論では、成功率に事前分布を置き、観測で更新した事後分布からこれらを計算する。
このページは成功率の共役事前分布である Beta 分布を使って事後分布と意思決定の量を求め、その値を 3 通りの方法で照合する。
最後に、データを集めながら何度も判定すると、差がないのに B を勝ちと判定する割合がどれだけ増えるかを反復実験で測る。

## ベータ二項モデル

案 A の成功率を $p_A$、B の成功率を $p_B$ とし、A に割り当てた $n_A$ 人のうち $k_A$ 人、B の $n_B$ 人のうち $k_B$ 人が成功したとする。
訪問者が独立に一定の確率で成功するなら、$k_A\sim\mathrm{Bin}(n_A,p_A)$、$k_B\sim\mathrm{Bin}(n_B,p_B)$ である。
事前分布を $p\sim\mathrm{Beta}(\alpha_0,\beta_0)$（密度 $\propto p^{\alpha_0-1}(1-p)^{\beta_0-1}$）とすると、Bayes の定理から事後分布は

$$
p\mid k,n\sim\mathrm{Beta}(\alpha_0+k,\ \beta_0+n-k)
$$

になる。
事前分布と事後分布が同じ族に属するので、Beta 分布を二項分布の共役事前分布という。
$\alpha_0$ と $\beta_0$ は、観測の前に見込んでいる成功と失敗の数（擬似的な観測数）として読める。
事後平均は $(\alpha_0+k)/(\alpha_0+\beta_0+n)$ で、標本の成功割合 $k/n$ と事前平均 $\alpha_0/(\alpha_0+\beta_0)$ を、観測数と擬似的な観測数の比で重み付けた平均である。
事後分散は $\alpha\beta/\bigl((\alpha+\beta)^2(\alpha+\beta+1)\bigr)$（$\alpha$、$\beta$ は事後のパラメータ）で、ほぼ $n$ に反比例して小さくなる。

よく使う事前分布は、一様分布 $\mathrm{Beta}(1,1)$、Jeffreys の事前分布 $\mathrm{Beta}(1/2,1/2)$、過去の実績を反映した情報のある事前分布である。
$\mathrm{Beta}(0,0)$（Haldane の事前分布）は正規化できない非正則な分布で、成功と失敗がそれぞれ 1 回以上観測されると事後分布が正則になる。
$n$ が数百を超えると、$\alpha_0+\beta_0$ が数程度の事前分布の差は事後分布にほとんど現れない。
情報のある事前分布の擬似的な観測数が $n$ と同じ程度なら、事後分布は事前平均に大きく引き寄せられる。

## 意思決定の量

$p_A$ と $p_B$ の事後分布は独立なので、B が A を上回る事後確率は

$$
P(p_B>p_A)=\int_0^1 f_B(x)\,F_A(x)\,dx
$$

で、$f_B$ は B の事後密度、$F_A$ は A の事後分布関数である。
$\alpha_B$ が整数なら、Cook（2005）の閉形式

$$
P(p_B>p_A)=\sum_{i=0}^{\alpha_B-1}\frac{B(\alpha_A+i,\ \beta_A+\beta_B)}{(\beta_B+i)\,B(1+i,\ \beta_B)\,B(\alpha_A,\ \beta_A)}
$$

がある（$B$ はベータ関数）。
隣り合う項の比は $(\alpha_A+i)(\beta_B+i)/\bigl((\alpha_A+\beta_A+\beta_B+i)(1+i)\bigr)$ なので、初項 $B(\alpha_A,\beta_A+\beta_B)/B(\alpha_A,\beta_A)$ を `scioxide_special::ln_beta` で求めれば、残りの $\alpha_B-1$ 項は掛け算だけで足せる。

B を採用したときの期待損失（成功率の差のうち、B が劣っていた分の期待値）は

$$
L_B=E\bigl[\max(p_A-p_B,0)\bigr],\qquad L_A=E\bigl[\max(p_B-p_A,0)\bigr]
$$

である。
「$L_B$ が許容できる損失 $\varepsilon$ より小さければ B を採用する」という規則は、勝つ確率だけでなく、負けたときの損の大きさも考慮する。
$P(p_B>p_A)$ が同じでも、差の分布の裾が長ければ $L_B$ は大きくなる。

## scioxide-stats の API

`BetaBinomialPrior::new(alpha, beta)` は正則な事前分布を作り、正でないパラメータは `InvalidInput`、NaN や無限大は `NonFinite` で拒む。
`BetaBinomialPrior::improper(alpha, beta)` は一方が 0 の非正則な事前分布（Haldane の事前分布など）を作る。
`update(successes, trials)` は $\mathrm{Beta}(\alpha+k,\beta+n-k)$ を返し、$k>n$ なら `InvalidInput` を返す。
`update_frequency` は同じ観測を $f$ 回繰り返したときの更新、`update_batch` は観測の列による更新で、どれも $O(1)$ の加算である。
パラメータは拡張指数の範囲で保持し、`parameters()` で読むときに `f64` に丸める。
`posterior_law()` は scioxide-random の `Beta` を返し、密度、分布関数、分位点、平均、分散、標本抽出がそのまま使える。
非正則なまま呼ぶと `InvalidInput` を返す。
`predictive(m)` は、将来の $m$ 人のうちの成功数の事後予測分布 `BetaBinomial` を返す。

`credible_interval(law, probability, options)` は、両側の裾にそれぞれ $(1-c)/2$ の事後確率を残す等裾の信用区間を返す。
下端は $\ln F(x)=\ln((1-c)/2)$、上端は $\ln S(x)=\ln((1-c)/2)$（$S$ は生存関数）を解く。
上側の裾を $1-(1-c)/2$ の分位点ではなく生存関数で解くので、裾の確率が小さくても桁落ちしない。
信用区間は「事後確率 $c$ で真の値を含む」区間で、頻度論の信頼区間（同じ手続きを繰り返したときの被覆率が $c$）とは意味が違う。

`posterior_summary(chains)` は、行を鎖とする標本の行列から、平均、分散、5%・50%・95% の分位点、分割 $\hat R$、有効標本数、平均の Monte Carlo 標準誤差 `mean_mcse` を返す。
MCMC の出力の診断のための関数だが、独立な標本にも使え、そのときは有効標本数が標本数に近くなる。

## 事後分布と照合

次のセルは入力の訪問者数と観測した成功割合（成功数はその積を丸めた整数）から 2 つの事後分布を作る。
1 つ目の表は事後分布のパラメータ、事後平均、95% 等裾信用区間である。
2 つ目の表は $P(p_B>p_A)$ を 3 通りに求めて比べ、3 つ目の表は期待損失と差 $p_B-p_A$ の事後分布の要約を示す。
Monte Carlo は 2 つの事後分布から 1 万組を抽出し、4 本の鎖に分けて `posterior_summary` で差 $p_B-p_A$ を要約する。
数値積分は $\int f_BF_A$ を、$f_B$ の質量の $1-2\times10^{-10}$ を含む区間で Simpson の公式（400 区間）により手計算した独立検算で、区間を半分にした値との差を誤差の目安にする。
Cook の閉形式は $\alpha_B$ が整数のときだけ計算し、そうでなければ空欄にする。
4 つ目の表は頻度論の比較で、Pearson の $\chi^2$ 検定（連続補正なし）、Fisher の正確検定、差の Wald 区間（90%）を、事後分布の差の 90% 区間（5% と 95% の分位点）と並べる。
図は 2 つの事後密度と、差 $p_B-p_A$ の事後標本のヒストグラムである。

```rust
//| id: stats-ab-test-model
//| kind: definitions
//| title: Cook の閉形式による P(p_B > p_A)
//| crates: [scioxide-core, scioxide-special]
use scioxide_core::{SciOxideError, RealScalar};

/// α_B が整数のときの P(p_B > p_A)（Cook 2005）。項の比で順に足す。整数でなければ None。
pub(crate) fn exact_superiority(
    alpha_a: f64,
    beta_a: f64,
    alpha_b: f64,
    beta_b: f64,
) -> Result<Option<f64>, SciOxideError> {
    if alpha_b.fract() != 0.0 {
        return Ok(None);
    }
    let first = scioxide_special::ln_beta(alpha_a, beta_a + beta_b)?
        - scioxide_special::ln_beta(alpha_a, beta_a)?;
    let mut term = RealScalar::exp(first);
    let mut sum = term;
    for i in 0..(alpha_b as usize - 1) {
        let i = i as f64;
        term *= (alpha_a + i) * (beta_b + i) / ((alpha_a + beta_a + beta_b + i) * (1.0 + i));
        sum += term;
    }
    Ok(Some(sum))
}
```

```rust
        { "key": "0", "label": "量" },
        { "key": "1", "label": "値 [-]", "type": "number", "format": { "significantDigits": 5 } },
        { "key": "2", "label": "両側 p 値 [-]", "type": "number", "format": fixed4, "nullText": "—" }
    ]),
    frequentist,
    metadata = serde_json::json!({ "id": "frequentist" })
);

let low = law_a
    .quantile(1e-4)
    .map_err(|e| e.to_string())?
    .min(law_b.quantile(1e-4).map_err(|e| e.to_string())?);
let high = law_a
    .quantile(1.0 - 1e-4)
    .map_err(|e| e.to_string())?
    .max(law_b.quantile(1.0 - 1e-4).map_err(|e| e.to_string())?);
let density = |law: &scioxide_random::Beta<f64>| -> Result<Vec<[f64; 2]>, String> {
    (0..=200)
        .map(|j| {
            let x = low + (high - low) * j as f64 / 200.0;
            Ok([x, law.pdf(x).map_err(|e| e.to_string())?])
        })
        .collect()
};
emit_chart!(serde_json::json!({
    "kind": "line",
    "xLabel": "成功率 p [-]",
    "yLabel": "事後密度 [-]",
    "dataZoom": true,
    "tooltip": true,
    "series": [
        { "name": "A の事後分布", "points": density(&law_a)?, "style": { "showSymbol": false } },
        { "name": "B の事後分布", "points": density(&law_b)?, "style": { "showSymbol": false } }
    ]
}));
let (dmin, dmax) = difference
    .iter()
    .fold((f64::MAX, f64::MIN), |(a, b), &v| (a.min(v), b.max(v)));
let width = (dmax - dmin) / 40.0;
let mut bins = vec![[0.0; 3]; 40];
for (j, bin) in bins.iter_mut().enumerate() {
    bin[0] = dmin + j as f64 * width;
    bin[1] = dmin + (j + 1) as f64 * width;
}
for &d in &difference {
    bins[(((d - dmin) / width) as usize).min(39)][2] += 1.0;
}
emit_chart!(serde_json::json!({
    "kind": "histogram",
    "xLabel": "差 p_B − p_A [-]",
    "yLabel": "度数 [組]",
    "bins": bins,
    "tooltip": true,
    "annotations": [{ "kind": "line", "axis": "x", "value": 0.0, "label": "差 0" }]
}));
```

既定の入力（A は 1000 人中 120 人、B は 1000 人中 145 人、一様の事前分布、シード 8）では、事後分布は $\mathrm{Beta}(121,881)$ と $\mathrm{Beta}(146,856)$ で、事後平均は 0.1208 と 0.1457 である。
$P(p_B>p_A)$ は数値積分と Cook の閉形式がどちらも 0.950197 で、表示の桁まで一致する。
数値積分は区間数を半分にしても値が $10^{-14}$ の水準でしか変わらず、閉形式との差も丸めの水準である。
Monte Carlo の推定値 0.9534 は標準誤差 0.0021 の約 1.5 倍だけ離れており、1 万組の抽出の誤差として説明できる。
3 つの方法は計算の仕組みが違うので、この一致が事後分布の計算と照合の両方の確認になる。
期待損失 $L_B$ は 0.00029 で、B を採用して損をするとしても、成功率で平均 0.03 ポイント程度である。

頻度論の比較では、Pearson の $X^2=2.719$ と併合した $z$ の二乗が丸めの水準で一致する。
2 × 2 表の連続補正なしの $\chi^2$ 検定は、2 つの割合の差の z 検定と同じものである。
両側の p 値は 0.099（Fisher の正確検定では 0.113）で、水準 0.05 では「差がない」という帰無仮説を棄却しない。
一方、$1-P(p_B>p_A)=0.0498$ は、片側の p 値（$X^2$ の両側の p 値の半分、0.0496）に近い。
一様の事前分布と大きい $n$ では、事後分布が正規分布に近く、$P(p_B\le p_A)$ と片側の p 値がほぼ一致する。
事後分布の差の 90% 区間 $[0.0004,0.0496]$ と、差の Wald の 90% 区間 $[0.0001,0.0499]$ もほぼ同じ端点を持つ。
数値が近くても、前者は事後確率の主張、後者は手続きの被覆率の主張で、意味は異なる。

Jeffreys の事前分布では $\alpha_B=145.5$ が整数でないので、閉形式の欄が空になり、数値積分の 0.95048 だけが検算になる。
一様の事前分布との差は $3\times10^{-4}$ で、$n=1000$ では事前分布の違いがほとんど現れない。
情報のある事前分布 $\mathrm{Beta}(24,176)$ は 200 人分の擬似的な観測で、事後平均を 0.120 と 0.141 に引き寄せる。
B の事後平均の下がり方が大きいので、$P(p_B>p_A)$ は 0.935 に下がる。
訪問者数を 200 人ずつにすると（成功数は 24 人と 29 人）、事後分布が広がって $P(p_B>p_A)$ は 0.768 になり、期待損失 $L_B$ も 0.0045 と 15 倍に増える。

## 途中で何度も判定したとき

A/B テストでは、データが集まるたびに結果を見て、差がはっきりした時点で止めたくなる。
毎日 $P(p_B>p_A)$ を計算し、閾値 $c$（たとえば 0.95）を超えたら B を勝ちとして止める規則を考える。
事後確率はどの時点でも観測にもとづく正しい事後確率だが、この規則を差のない状況で繰り返し使ったときに B を勝ちと判定する割合（頻度論の第 1 種の誤り）は別の問題である。
1 回だけの判定なら、一様の事前分布ではこの割合は片側検定の水準 $1-c$ に近い。
判定の回数を増やすと、偶然の揺らぎで一度でも閾値を超える機会が増えるので、割合は $1-c$ より大きくなる。

次のセルは $p_A=p_B=p$ の状況で、毎回の判定ごとに各案へ $m$ 人ずつ追加し、$K$ 回まで判定することを $R$ 回繰り返す。
成功数は scioxide-random の二項分布から抽出し、$P(p_B>p_A)$ は一様の事前分布の事後分布から Cook の閉形式で計算する。
図は $k$ 回目の判定までに一度でも閾値を超えた割合（累積の誤判定率）と Wilson の 95% 区間を、1 回だけ判定する場合の参照値 $1-c$（破線）と比べる。
表は最後の 1 回だけで判定した場合と、毎回判定した場合の誤判定率である。

```rust
//| id: stats-ab-test-peeking
//| ref: stats-ab-test-peeking
//| title: 差がない A/B テストで判定を繰り返したときの誤判定率を数える
//| run: reactive
//| uses: [stats-ab-test-model]
//| crates: [scioxide-random, scioxide-stats]
//| inputs:
//|   rate: {"type":"range","label":"共通の成功率 p [-]","min":0.05,"max":0.3,"step":0.05,"value":0.1}
//|   batch: {"type":"range","label":"1 回の判定ごとに各案へ追加する人数 m","min":50,"max":500,"step":50,"value":200}
//|   looks: {"type":"range","label":"判定の回数 K","min":1,"max":30,"step":1,"value":20}
//|   threshold: {"type":"range","label":"判定の閾値 c [-]","min":0.9,"max":0.99,"step":0.01,"value":0.95}
//|   replicates: {"type":"range","label":"反復数 R","min":200,"max":2000,"step":200,"value":1000}
//|   seed: {"type":"range","label":"乱数のシード","min":1,"max":100,"step":1,"value":3}
//| cases:
//|   - {"id":"single-look","label":"K = 1","description":"誤判定率が 1 − c の近くに戻る。","inputs":{"looks":1}}
//|   - {"id":"strict","label":"c = 0.99","description":"閾値を上げても、判定を繰り返すと 1 − c を超える。","inputs":{"threshold":0.99}}
//| tests:
//|   - case: single-look
//|     expect:
//|       - {"artifact":"peeking","path":"/rows/0/1","approx":{"value":0.042,"atol":1e-9}}
//|   - case: default
//|     expect:
//|       - {"artifact":"peeking","path":"/rows/0/1","approx":{"value":0.046,"atol":1e-9}}
//|       - {"artifact":"peeking","path":"/rows/1/1","approx":{"value":0.213,"atol":1e-9}}
use scioxide_random::{Binomial, CountDistribution, SeedableRng, SplitMix64};
use scioxide_stats::BetaBinomialPrior;

let m = batch as usize;
let k_max = looks as usize;
let r = replicates as usize;
let sampler = Binomial::new(m, rate)
    .map_err(|e| e.to_string())?
    .prepare_sampler()
    .map_err(|e| e.to_string())?;
let mut rng = SplitMix64::from_seed(seed as u64);
let start = BetaBinomialPrior::new(1.0_f64, 1.0).map_err(|e| e.to_string())?;
// first[k] = k + 1 回目に初めて閾値を超えた回数、last = 最後の 1 回だけで超えた回数
let mut first = vec![0_usize; k_max];
let mut last = 0_usize;
for _ in 0..r {
    let (mut post_a, mut post_b) = (start, start);
    let mut stopped = false;
    for k in 0..k_max {
        post_a = post_a
            .update(sampler.sample(&mut rng).map_err(|e| e.to_string())?, m)
            .map_err(|e| e.to_string())?;
        post_b = post_b
            .update(sampler.sample(&mut rng).map_err(|e| e.to_string())?, m)
            .map_err(|e| e.to_string())?;
        let (alpha_a, beta_a) = post_a.parameters().map_err(|e| e.to_string())?;
        let (alpha_b, beta_b) = post_b.parameters().map_err(|e| e.to_string())?;
        let superiority = exact_superiority(alpha_a, beta_a, alpha_b, beta_b)
            .map_err(|e| e.to_string())?
            .ok_or("α_B が整数でない")?;
        let exceeded = superiority > threshold;
        if exceeded && !stopped {
            first[k] += 1;
            stopped = true;
        }
        if k + 1 == k_max {
            last += usize::from(exceeded);
        }
    }
}
// Wilson のスコア区間（95%）
let wilson = |count: usize| {
    let (p, n, z) = (count as f64 / r as f64, r as f64, 1.96_f64);
    let center = (p + z * z / (2.0 * n)) / (1.0 + z * z / n);
    let radius = z * (p * (1.0 - p) / n + z * z / (4.0 * n * n)).sqrt() / (1.0 + z * z / n);
    (p, center - radius, center + radius)
};
let mut cumulative = 0;
let mut points = Vec::with_capacity(k_max);
for (k, &count) in first.iter().enumerate() {
    cumulative += count;
    let (p, low, high) = wilson(cumulative);
    points.push([(k + 1) as f64, p, low, high]);
}
emit_chart!(serde_json::json!({
    "kind": "errorbar",
    "xLabel": "判定の回数 k [回]",
    "yLabel": "差がないのに B を勝ちとした割合 [-]",
    "xMin": 0.5,
    "xMax": looks + 0.5,
    "yMin": 0.0,
    "tooltip": true,
    "series": [{ "name": "累積の誤判定率と Wilson 区間", "points": points }],
    "annotations": [{
        "kind": "line",
        "axis": "y",
        "value": 1.0 - threshold,
        "label": "1 回だけの判定の参照値 1 − c",
        "style": { "lineType": "dashed" }
    }]
}));
let (single, single_low, single_high) = wilson(last);
let (any, any_low, any_high) = wilson(cumulative);
let fixed3 = serde_json::json!({ "fractionDigits": 3 });
emit_table_with_columns!(
    serde_json::json!([
        { "key": "0", "label": "判定の仕方" },
        { "key": "1", "label": "誤判定率 [-]", "type": "number", "format": fixed3 },
        { "key": "2", "label": "Wilson 区間の下端 [-]", "type": "number", "format": fixed3 },
        { "key": "3", "label": "Wilson 区間の上端 [-]", "type": "number", "format": fixed3 }
    ]),
    vec![
        ("最後の 1 回だけ判定", single, single_low, single_high),
        ("毎回判定して最初に超えたら止める", any, any_low, any_high),
    ],
    metadata = serde_json::json!({ "id": "peeking" })
);
```

既定の入力（$p=0.1$、$m=200$、$K=20$、$c=0.95$、$R=1000$、シード 3）では、最後の 1 回だけで判定した誤判定率は 0.046（Wilson 区間 0.035〜0.061）で、区間が 0.05 を含む。
毎回判定すると、累積の誤判定率は 1 回目の 0.060 から増え続け、20 回目には 0.213（0.189〜0.239）と 1 回だけの判定の約 4 倍になる。
$K=1$ にすると 2 つの判定の仕方が同じになり、誤判定率は 0.042（0.031〜0.056）と $1-c$ の近くに戻る。
$c=0.99$ では最後の 1 回だけの判定が 0.012 なのに対し、20 回繰り返すと 0.058 と 0.01 の約 6 倍になる。

事後確率 $P(p_B>p_A)$ は、いつ計算しても観測にもとづく事後確率として正しい。
ただし「閾値を超えたら止める」規則の頻度論的な誤判定率は、判定の回数とともに増える。
途中で止める運用をするなら、閾値をより厳しくする、判定の回数をあらかじめ決める、期待損失の規則と事前分布の選び方を反復実験で確かめる、などの手当てが要る。
頻度論の逐次検定（O'Brien–Fleming の境界など）や、任意の時点で止めてよい検定は scioxide-stats では提供しない。

## まとめ

Beta 事前分布と二項観測の組では、事後分布が $\mathrm{Beta}(\alpha_0+k,\beta_0+n-k)$ と閉形式で求まり、`BetaBinomialPrior::update` と `posterior_law` で scioxide-random の `Beta` として扱える。
$P(p_B>p_A)$ は Monte Carlo、$\int f_BF_A$ の数値積分、$\alpha_B$ が整数のときの Cook の閉形式の 3 通りで照合でき、Monte Carlo の差は標準誤差と比べて読む。
一様の事前分布と大きい標本では、$1-P(p_B>p_A)$ は片側の p 値に近いが、事後確率と p 値は答える問いが違う。
`credible_interval` の等裾の信用区間は、裾の確率を生存関数で解くので、小さい確率でも桁落ちしない。
途中で何度も判定して止める運用では、差がないのに勝ちとする割合が増えるので、判定の規則そのものを反復実験で確かめてから使う。
