平均、分散、相関係数、回帰直線だけではデータの形は決まらない。
[Anscombe の 1973 年の論文](https://doi.org/10.1080/00031305.1973.10478966)は、この限界を印象的な例で示した。
このページでは、同じ統計的な原理を SciOxide 用に新たに構成した 4 組のデータで調べる。
各座標は以下の式から生成しており、Anscombe の原データではない。
出典と利用条件は[ライセンスとデータの出典](../../../reference/licenses/)に記載している。

## 構成した 4 組のデータ

各組は 13 個の点からなる。
組 I〜III は $i=0,\ldots,12$ に対する $x_i=i-6$ を使う。
組 IV は $a=\sqrt{7/6}$ として、12 個の $-a$ と 1 個の $12a$ を使う。
どちらも平均は 0、$S_{xx}=\sum_i x_i^2=182$ である。

$y$ を作るには、種となるベクトル $z$ から定数成分と一次成分を除き、残ったベクトルの長さをそろえる。

$$
u_i=z_i-\bar z-x_i\frac{\sum_j x_j(z_j-\bar z)}{182},\qquad
 e_i=u_i\sqrt{\frac{45.5}{\sum_j u_j^2}},\qquad y_i=3+0.5x_i+e_i.
$$

この構成により $\sum_i e_i=\sum_i x_i e_i=0$、$\sum_i e_i^2=45.5$ となる。
この例のために、次の 4 種類の $z$ を用意する。

- 組 I：$z_i=((17i+7i^2+3)\bmod23)-11$。
  直線から不規則にずれる。
- 組 II：$z_i=x_i^2$。
  2 次曲線に沿う。
- 組 III：$z_{10}=1$、ほかは 0。
  12 点が一直線に並び、$x=4$ の 1 点が応答の外れ値となる。
- 組 IV：$z=(-6,-5,-4,-3,-2,-1,1,2,3,4,5,6,0)$。
  縦の点列と、てこ比が 1 の点を作る。

4 組とも $\bar x=0$、$\bar y=3$、標本分散 $s_x^2=182/12$、$s_y^2=91/12$、最小二乗の直線 $y=3+0.5x$、$r=1/\sqrt2$、$R^2=1/2$、残差平方和 45.5 となる。
傾きの標準誤差は $1/\sqrt{44}$、残差の自由度は 11 である。
これらは丸め前には恒等式であり、保存した binary64 の座標でも浮動小数点の精度で一致する。
種の値は診断を示すための決定的な構成で、観測誤差の正規性を主張するものではない。

## 要約統計の一致と散布図

単回帰 $y = \beta_0 + \beta_1 x + \varepsilon$ の最小二乗推定は

$$
\hat\beta_1 = \frac{S_{xy}}{S_{xx}},\qquad \hat\beta_0 = \bar y - \hat\beta_1 \bar x,\qquad
S_{xx} = \sum_i (x_i-\bar x)^2,\quad S_{xy} = \sum_i (x_i-\bar x)(y_i-\bar y)
$$

である。
誤差 $\varepsilon_i$ が独立に $N(0, \sigma^2)$ に従うと仮定すると、傾きの標準誤差は $\mathrm{SE}(\hat\beta_1) = s/\sqrt{S_{xx}}$、$s^2 = \mathrm{RSS}/(n-2)$ であり、$t = \hat\beta_1/\mathrm{SE}$ は自由度 $n-2$ の t 分布に従う。
決定係数は $R^2 = r^2$（$r$ は Pearson の相関係数）である。

`linear_regression(x, y)` はこの直線を $O(n)$ の 1 回の走査で求め、和を平均の周りで指数部の範囲を広げた表現に累積するので、大きな定数が乗ったデータでも桁落ちしない。
`line()` が返す `ProbabilityPlotFit` は `slope`、`intercept`、`correlation`（$y$ が定数なら `None`）を持つ。
`slope_inference(confidence, alternative)` は傾きの t 検定と両側の信頼区間を `RegressionContrast` で返し、$n = 2$（自由度 0）では `None` を返す。
平均と標本分散（除数 $n-1$）は `mean` と `sample_variance` で求める。

4 枚の図は $x \in [-7,14]$、$y \in [-2,12]$ に軸を固定し、x 軸を連動させる。

## 残差、てこ比、Cook の距離

散布図が読めない多変数の回帰では、残差 $e_i = y_i - \hat y_i$ を調べる。
単回帰のハット行列 $H = X(X^\top X)^{-1}X^\top$ の対角成分（てこ比）は

$$
h_i = \frac{1}{n} + \frac{(x_i-\bar x)^2}{S_{xx}},\qquad \frac{1}{n} \le h_i \le 1,\qquad \sum_i h_i = 2
$$

であり、$x$ が平均から離れた点ほど大きい。
$\operatorname{Var}(e_i) = \sigma^2(1-h_i)$ なので、残差を比べるときは内部スチューデント化残差 $r_i = e_i / (s\sqrt{1-h_i})$ を使う。
1 点を除いたときの当てはめ値の変化をまとめた Cook の距離は、係数の数を $p = 2$ として

$$
D_i = \frac{r_i^2}{p}\,\frac{h_i}{1-h_i}
$$

である。
$D_i$ が 1 程度を超える点は、その 1 点で直線が大きく変わることを示す目安として使われる（Cook and Weisberg, *Residuals and Influence in Regression*, 1982）。
$h_i = 1$ の点では $e_i = 0$ になり、$r_i$ と $D_i$ は定義されない。
組 IV の $x=12\sqrt{7/6}$ の点がこれに当たり、この点を除くと $x$ が一定になって傾きが決まらない。

`scioxide-stats` は、てこ比、スチューデント化残差、Cook の距離を返す関数を提供しない。

てこ比は、`PreparedRegression` の `contrast` の HC3 共分散と GLM の HC3 共分散の内部で使われるが、値としては出力に反映されない。

## ロバストな直線の当てはめ

外れ値に引かれにくい当てはめとして、`scioxide-stats` は次の 3 つを提供する。

- `PreparedHuber` は Huber の M 推定である。
  残差を尺度 $\hat\sigma = \mathrm{MAD}(r)/0.6745$ で割った値 $u$ に、$|u| \le c$ では $u^2/2$、それより外では $c|u| - c^2/2$ の損失を課し、反復重み付き最小二乗（IRLS）で解く。
  初回は通常の最小二乗で、以降は重み $w_i = \min(1, c\hat\sigma/|r_i|)$ の重み付き最小二乗を薄い SVD で解き、係数の変化が `HuberOptions` の刻みの許容誤差を満たすと `Converged` で止まる。
  既定は $c = 1.345$（正規誤差での漸近効率 95%）、最大 100 回の反復であり、1 回の反復は $O(np^2)$ である。
  計画行列は切片の列を含めて渡す。
  rustdoc が注意するとおり、応答の外れ値には強いが、計画行列のてこ比の大きい点には強くない。
- `robust_slope(x, y, RobustSlopeMethod::TheilSen)` は、$x_i \ne x_j$ のすべての組の傾き $(y_j-y_i)/(x_j-x_i)$ の中央値（Theil–Sen 推定、破綻点 約 29%）と、Kendall の統計量の分散から作る Sen の傾きの信頼区間を返す。
- `RobustSlopeMethod::Siegel` は、各点について他の点との傾きの中央値を取り、その中央値を取る（反復中央値、破綻点 50%）。
  信頼区間は返さない。

どちらの順位推定も $O(n^2)$ の時間で、切片は既定の `RobustIntercept::Joint`（$y_i - \hat\beta_1 x_i$ の中央値）で求める。

下のセルは、選んだ組について点ごとの診断と 4 つの直線を表にし、残差を $x$ に対して描く。
入力の組を変えると、診断のどの量が異常を示すかが変わる。
組 I には Cook の距離が 1 を超える点がない。
組 II では残差が曲線に沿い、両端の点の影響が大きい。
組 III の $x=4$ の外れ値は、スチューデント化残差 $\sqrt{11}$、Cook の距離 約 1.086 を持つ。
組 IV の孤立した点はてこ比が 1、残差が 0 であり、除くと傾きを決める情報が失われる。

let x_bar = mean(x).map_err(|e| e.to_string())?;
let sxx: f64 = x.iter().map(|&a| (a - x_bar) * (a - x_bar)).sum();
let fitted: Vec<f64> = x.iter().map(|&a| line.intercept + line.slope * a).collect();
let residuals: Vec<f64> = y.iter().zip(&fitted).map(|(&b, &f)| b - f).collect();
let s2 = residuals.iter().map(|e| e * e).sum::<f64>() / (n - 2.0);
let mut points = Vec::new();
for i in 0..x.len() {
    let h = 1.0 / n + (x[i] - x_bar) * (x[i] - x_bar) / sxx;
    // h = 1 の点では r と D が定義されない（0/0）
    let studentized =
        (1.0 - h > 1e-12).then(|| residuals[i] / RealScalar::sqrt(s2 * (1.0 - h)));

        i + 1,
        x[i],
        y[i],
        fitted[i],
        residuals[i],
        h,
        studentized,
        cook,
    ));

## 誤差と計算量

- `linear_regression` は平均の周りの和を指数部の範囲を広げた表現に累積するので、要約統計の相対誤差は倍精度の丸めの水準である。
  表の微小な差は、データの構成と評価の浮動小数点演算に由来する。
- てこ比は $S_{xx}$ で割るので、$x$ がほぼ一定の組では $h_i$ が 1 に近づき、$1 - h_i$ が桁落ちする。
  セルは $1 - h_i \le 10^{-12}$ を $h_i = 1$ とみなし、$r_i$ と $D_i$ を出さない。
- 最小二乗は $O(n)$、Theil–Sen は $O(n^2)$ の組の傾きを保持し、Siegel は $O(n^2)$ の時間で $O(n)$ のメモリを使う。
  Huber は 1 回の反復が $O(np^2)$ である。
  係数を解釈する前に、出力された終了理由を確認する。

## まとめ

構成した 4 組では、要約統計が一致していても点の配置が大きく異なる。
回帰の結果を返す前に、散布図と、残差、てこ比、Cook の距離を確かめる。
Theil–Sen と Siegel は組 III の多数の点に沿う直線を回復する。
Huber には使用可能な残差尺度も必要なので、エラーや終了理由を確認する。
組 IV の計画行列の情報不足を補うには、測定点を増やす必要がある。
`scioxide-stats` は影響の診断量を返さないので、ここで示した単回帰の閉形式で計算する。
曲線の関係（組 II）は推定量ではなく、モデルを直す問題である。
