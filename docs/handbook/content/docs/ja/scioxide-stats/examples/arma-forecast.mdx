月ごとの需要、気温の偏差、在庫の変動のように、前の値と前の衝撃の影響が少しずつ残る系列は、自己回帰移動平均（ARMA）モデルで表せることが多い。
このページは、性質がすべて閉形式で分かる ARMA(1,1) 過程の模擬系列を使い、Box–Jenkins の手順を scioxide-stats で一通りたどる。
手順は、標本自己相関による次数の同定、Kalman フィルタによる厳密尤度の最大化、観測情報量による標準誤差、残差の白色性の確認、予測と予測区間である。
各段階の結果を理論の自己相関関数、推定量の漸近分散、予測誤差の分散と比べ、最後に予測区間の被覆率を反復実験で確かめる。

## ARMA(1,1) 過程

平均 0 の ARMA(1,1) 過程は

$$
x_t=\phi\,x_{t-1}+\varepsilon_t+\theta\,\varepsilon_{t-1},\qquad \varepsilon_t\sim N(0,\sigma^2)\ \text{独立}
$$

で定める。
$\phi$ は自己回帰（AR）係数、$\theta$ は移動平均（MA）係数、$\varepsilon_t$ は革新（innovation）と呼ばれる白色雑音である。
後退作用素 $Bx_t=x_{t-1}$ を使うと $(1-\phi B)x_t=(1+\theta B)\varepsilon_t$ と書ける。
$|\phi|<1$ なら過程は定常で因果的（現在の値が過去の革新だけで決まる）であり、$|\theta|<1$ なら可逆（革新を過去の観測から復元できる）である。
定常で因果的な過程は MA(∞) 表現

$$
x_t=\sum_{j=0}^\infty\psi_j\varepsilon_{t-j},\qquad \psi_0=1,\quad \psi_j=(\phi+\theta)\,\phi^{\,j-1}\ (j\ge1)
$$

を持つ。

自己相関関数（ACF）$\rho(k)=\mathrm{Cov}(x_t,x_{t+k})/\mathrm{Var}(x_t)$ は

$$
\rho(1)=\frac{(1+\phi\theta)(\phi+\theta)}{1+2\phi\theta+\theta^2},\qquad \rho(k)=\phi^{\,k-1}\rho(1)\quad(k\ge1)
$$

である（Brockwell–Davis 1991, §3.3）。
ラグ 1 の値は $\phi$ と $\theta$ の両方で決まり、ラグ 2 以降は $\phi$ の比で幾何級数的に減る。
MA の項の影響は、ラグ 1 の値が AR(1) の $\phi$ からずれることに現れる。
偏自己相関関数（PACF）$\phi_{kk}$ は、中間の $k-1$ 個の値の影響を除いた $x_t$ と $x_{t+k}$ の相関で、AR(1) ならラグ 2 以降が 0、MA(1) なら減衰を続ける。
ARMA(1,1) では ACF も PACF もラグ 1 で切れずに減衰し、この両方の減衰が ARMA を示す手がかりになる。

$\phi+\theta=0$ のときは $\psi_j=0$（$j\ge1$）となり、過程は白色雑音そのものになる。
AR の根と MA の根が打ち消し合い、$\phi$ と $\theta$ を別々に決められない。
この近くでは尤度がほとんど平らになり、推定値のばらつきが大きくなる。

## 同定：標本自己相関

`time_series_summary(values, statistic, max_lag)` は、ラグ 0 から `max_lag` までの標本自己共分散（`TimeSeriesStatistic::Covariance`）、自己相関（`Acf`）、偏自己相関（`Pacf`）を `TimeSeriesLag { value, pairs }` の配列で返す。
ワンショット呼び出しは標本平均で中心化し、すべてのラグで除数を観測数 $n$ にする（`LagNormalization::ObservationCount`）。
除数を $n$ にすると自己共分散の行列が半正定値に保たれ、Levinson–Durbin の再帰で PACF を求められる。
欠測マスクや組の数による除数は `time_series_summary_with_options` で指定し、多数の系列は `time_series_summaries_into` でまとめて計算する。
計算量は $O(nK)$（$K$ は最大ラグ）である。

系列が白色雑音なら、標本自己相関 $\hat\rho(k)$（$k\ge1$）は近似的に独立な $N(0,1/n)$ に従う（Bartlett の公式の特別な場合）。
$\pm1.96/\sqrt n$ の帯を大きく超えるラグが、白色雑音でない証拠になる。
この帯は白色雑音のもとでの帯であり、正の相関を持つ過程の $\hat\rho(k)$ の分散は、Bartlett の公式から分かるように一般にこれより大きい。

次の定義のブロックは、ページのすべてのセルが使うモデルと補助関数である。
`simulate` は $\sigma=1$ の ARMA(1,1) を 500 点の助走の後から `length` 点作る。
`arma_acf` が上の ACF の閉形式、`psi_variance` が後で使う予測誤差の分散の閉形式である。
`fit_arma` は当てはめと観測情報量をまとめた手順で、後の節で説明する。

```rust
//| id: stats-arma-forecast-model
//| kind: definitions
//| title: ARMA(1,1) の模擬系列、理論値、最尤推定の手順
//| crates: [scioxide-core, scioxide-differentiate, scioxide-linalg, scioxide-optimize, scioxide-random, scioxide-stats]
use scioxide_core::{Bounds, ExecutionContext, SciOxideError, RankThreshold, RealScalar};
use scioxide_differentiate::DerivativeStrategy;
use scioxide_linalg::HermitianEigenOptions;
use scioxide_optimize::{LbfgsB, LbfgsBFitSolver, LbfgsBOptions};
use scioxide_random::{Distribution, Normal, SeedableRng, SplitMix64};
use scioxide_stats::{
    ArimaInnovation, ArimaModel, ArimaOrder, ArimaTrend, FitInformation, FitObjective, FitReport,
    PreparedArimaFit, StatisticsOptions, TimeSeriesStatistic, fit_information,
    time_series_summary,
};

/// x_t = φ x_{t−1} + ε_t + θ ε_{t−1}、ε_t ~ N(0, 1)。助走 500 点の後の length 点。
pub(crate) fn simulate(
    phi: f64,
    theta: f64,
    length: usize,
    seed: u64,
) -> Result<Vec<f64>, SciOxideError> {
    let normal = Normal::new(0.0_f64, 1.0)?;
    let mut rng = SplitMix64::from_seed(seed);
    let (mut x, mut previous) = (0.0, 0.0);
    let mut series = Vec::with_capacity(length);
    for t in 0..length + 500 {
        let shock = normal.sample(&mut rng)?;
        x = phi * x + shock + theta * previous;
        previous = shock;
        if t >= 500 {
            series.push(x);
        }
    }
    Ok(series)
}

/// 理論の自己相関 ρ(k)。ρ(1) = (1 + φθ)(φ + θ)/(1 + 2φθ + θ²)、ρ(k) = φ^(k−1) ρ(1)。
pub(crate) fn arma_acf(phi: f64, theta: f64, lag: usize) -> f64 {
    if lag == 0 {
        return 1.0;
    }
    let first = (1.0 + phi * theta) * (phi + theta) / (1.0 + 2.0 * phi * theta + theta * theta);
    first * RealScalar::powi(phi, lag as i32 - 1)
}

/// h 期先の予測誤差の分散 σ² Σ_{j<h} ψ_j²、ψ_0 = 1、ψ_j = (φ + θ) φ^(j−1)。
pub(crate) fn psi_variance(phi: f64, theta: f64, sigma2: f64, horizon: usize) -> f64 {
    let tail: f64 = (1..horizon)
        .map(|j| RealScalar::powi((phi + theta) * RealScalar::powi(phi, j as i32 - 1), 2))
        .sum();
    sigma2 * (1.0 + tail)
}

/// 当てはめの結果: ソルバーのレポート、モデル、観測情報量、標準化した革新 v_t/√f_t。
pub(crate) struct ArmaFit {
    pub(crate) report: FitReport<f64>,
    pub(crate) model: ArimaModel<f64>,
    pub(crate) information: FitInformation<f64>,
    pub(crate) standardized: Vec<f64>,
}

/// ARMA(1,1)（トレンドなし）を最尤法で当てはめる。初期値は φ₀ = ρ̂(2)/ρ̂(1)、θ₀ = 0。
pub(crate) fn fit_arma(series: &[f64]) -> Result<ArmaFit, SciOxideError> {
    let order = ArimaOrder { p: 1, d: 0, q: 1 };
    let options = StatisticsOptions::new();
    let problem = PreparedArimaFit::new(series, None, order, ArimaTrend::None, options)?;
    let acf = time_series_summary(series, TimeSeriesStatistic::Acf, 2)?;
    let phi0 = (acf[2].value / acf[1].value).clamp(-0.9, 0.9);
    let variance = time_series_summary(series, TimeSeriesStatistic::Covariance, 0)?[0].value;
    let initial = [phi0, 0.0, variance * (1.0 - phi0 * phi0)];
    let bounds = Bounds::new(vec![(None, None); 3])?;
    // 導関数は中心差分で近似する。定常・可逆でない点は直線探索が退ける。
    let lbfgsb = LbfgsBOptions::default().with_derivative_strategy(DerivativeStrategy::Central);
    let mut solver = LbfgsBFitSolver::new(LbfgsB::new(lbfgsb), 3)?;
    let fitted = problem.fit(&initial, &bounds, &mut solver)?;
    let report = *fitted.report();
    let model = fitted
        .into_model()
        .ok_or_else(|| SciOxideError::external("モデルがない"))?;
    let parameters = model.parameters().to_vec();
    // 負の対数尤度のヘッセ行列（中心差分）から観測情報量を作る。
    let nll = |p: &[f64]| {
        let mut work = problem.workspace()?;
        FitObjective::value(&problem, p, &mut work)
    };
    let hessian = scioxide_differentiate::hessian(nll, &parameters)?;
    let information = fit_information(
        &parameters,
        &bounds,
        &[false; 3],
        &hessian,
        RankThreshold::new(0.0, 1e-10)?,
        &HermitianEigenOptions::default(),
    )?;
    let mut work = problem.workspace()?;
    let mut innovations = vec![ArimaInnovation::default(); series.len()];
    let context = ExecutionContext::sequential();
    problem.evaluate_into(&parameters, &mut innovations, &mut work, context)?;
    let standardized = innovations
        .iter()
        .filter_map(|i| Some(i.residual? / RealScalar::sqrt(i.variance?)))
        .collect();
    Ok(ArmaFit {
        report,
        model,
        information,
        standardized,
    })
}
```

既定の入力（$\phi=0.6$、$\theta=0.3$、$n=200$、シード 4）では、理論の $\rho(1)=1.18\times0.9/1.45\approx0.732$ で、ACF は $0.6$ の比で減る。
標本 ACF は 0.722、0.407、0.236、0.123 とラグ 1 から 4 まで理論の破線（0.732、0.439、0.264、0.158）に沿い、その先は帯の中で揺らぐ。
PACF はラグ 1 で 0.722、ラグ 2 で $-0.237$ と帯（半幅 0.139）を外れ、その後は帯の中で符号を変えながら小さくなる。
AR(1) ならラグ 2 以降の PACF は帯の中に収まるはずなので、ラグ 2 の外れと減衰の続き方が MA の項の存在を示す。
標本 ACF の隣り合うラグの値は互いに相関するので、帯の外れが連続しても、それぞれが独立な証拠とは限らない。

$\phi=0.5$、$\theta=-0.4$ では $\phi+\theta=0.1$ と打ち消しに近く、理論の $\rho(1)$ は $0.8\times0.1/0.76\approx0.105$ しかない。
$n=200$ の帯の半幅 0.139 より小さいので、標本 ACF（ラグ 1 で 0.120）だけでは白色雑音と区別できない。
$\phi=0.9$ では ACF がゆっくり減り、このシードでは標本 ACF も理論の値（ラグ 6 で 0.552）に近い 0.571 を保つ。
ただし、標本平均で中心化した自己相関は持続性の強い過程で下向きに偏るので、シードを変えると理論より速く減って見えることがある。
$\phi=-0.7$ では ACF がラグごとに符号を変える。

## 推定：Kalman フィルタの厳密尤度

`PreparedArimaFit::new(values, validity, order, trend, options)` は ARIMA$(p,d,q)$ の Gauss 尤度の問題を準備する。
パラメータの並びは $[\phi_1,\dots,\phi_p,\theta_1,\dots,\theta_q,\text{トレンドの係数},\sigma^2]$ で、ARMA(1,1) でトレンドがなければ $[\phi,\theta,\sigma^2]$ である。
尤度は状態空間表現に Kalman フィルタを当てはめて計算する。
1 期先の予測 $\hat x_{t|t-1}$ とその誤差分散 $f_t$（$\sigma^2$ を含む）から、革新 $v_t=x_t-\hat x_{t|t-1}$ を作り、負の対数尤度

$$
\ell(\phi,\theta,\sigma^2)=\frac12\sum_t\left(\frac{v_t^2}{f_t}+\ln f_t+\ln2\pi\right)
$$

を返す。
初期の状態は定常分布から始めるので、条件付き最小二乗ではなく、ARMA の部分について厳密な尤度になる。
状態の次元を $m=p+d+q$ とすると 1 回の評価は $O(nm^3)$ で、欠測は時間の格子に位置を残したまま飛ばす。
AR 多項式の反射係数（偏自己相関）の絶対値が $1-64\varepsilon$ 以上の点、MA 多項式で同じ条件の点、$\sigma^2\le0$ の点は `InvalidInput` で拒否される。
`evaluate_into` は与えたパラメータでの尤度 `ArimaLikelihood` と各時点の `ArimaInnovation { prediction, variance, residual }` を書き込む。

scioxide-stats は尤度を最小化する最適化法を持たず、`FitSolver` を実装したソルバーを `PreparedArimaFit::fit(initial, bounds, solver)` に渡す。
上の定義のブロックは、scioxide-optimize の `LbfgsBFitSolver`（L-BFGS-B）を渡す。
ARIMA の尤度は解析的な導関数を渡さないので、勾配は `LbfgsBOptions::with_derivative_strategy` で選んだ中心差分（`DerivativeStrategy::Central`）で近似する。
射影勾配が既定の許容誤差を満たしたら `Converged`、反復の上限（既定 1000）か評価回数の上限に達したら `BudgetExhausted` を返す。
定常・可逆でない点は目的関数の検査が `InvalidInput` で拒み、L-BFGS-B の直線探索はその点を定義域の外として段を縮めるので、パラメータに範囲の制約は付けない。
`fit` はソルバーの結果を範囲と有限性で検査し、尤度を評価し直してから `ArimaFitReport` を返す。
`report()` は終了状態、最終の目的関数値、反復と評価の回数を、`model()` は予測用の `ArimaModel` を返す。
ソルバーが最終の評価の前に止まると、モデルは `None` になる。

推定値の標準誤差は負の対数尤度のヘッセ行列（観測情報量）$I(\hat\vartheta)$ の逆行列から求める。
`fit_information` は自由なパラメータの $I$ の固有値を調べ、正定値なら `FitIdentifiability::Identifiable` として共分散 $I^{-1}$ を返す。
階数が落ちていれば `RankDeficient`、負の固有値があれば `Indefinite`（極小でない）、パラメータが範囲の境界にあれば `Nonregular` で、共分散は `None` になる。
ヘッセ行列は scioxide-differentiate の中心差分 `hessian` で作り、$1+2\cdot3^2=19$ 回の尤度の評価がかかる。
大きい $n$ での理論の漸近共分散は

$$
n\,\mathrm{Cov}(\hat\phi,\hat\theta)\to\frac{1+\phi\theta}{(\phi+\theta)^2}
\begin{pmatrix}(1-\phi^2)(1+\phi\theta)&-(1-\phi^2)(1-\theta^2)\\-(1-\phi^2)(1-\theta^2)&(1-\theta^2)(1+\phi\theta)\end{pmatrix},
\qquad n\,\mathrm{Var}(\hat\sigma^2)\to2\sigma^4
$$

である（Brockwell–Davis 1991, Example 8.8.3）。
$(\phi+\theta)^2$ が分母にあるので、打ち消しの近くでは標準誤差が大きくなる。

## 残差の白色性

モデルが正しければ、標準化した革新 $e_t=v_t/\sqrt{f_t}$ は独立な $N(0,1)$ に従う。
残差に自己相関が残るかどうかを、ラグ $K$ までまとめて調べるのが Ljung–Box の統計量

$$
Q=n(n+2)\sum_{k=1}^K\frac{\hat r_k^2}{n-k}
$$

である（$\hat r_k$ は残差の標本自己相関）。
モデルが正しければ $Q$ は近似的に自由度 $K-p-q$ の $\chi^2$ 分布に従う（Ljung–Box 1978）。
scioxide-stats は Ljung–Box と Box–Pierce の検定を提供しないので、下のセルでは `time_series_summary` で $\hat r_k$ を求め、scioxide-random の `ChiSquared` の上側確率から p 値を計算する。
$\chi^2$ 近似は $n$ が小さいと粗く、$K$ の選び方で結果が変わる。

## 予測と予測区間

`ArimaModel::forecast(h)` は系列の最後の時点の後の $h$ 期分の条件付き平均と予測誤差の分散 `ArimaForecast { mean, variance }` を返す。
`forecast_into` は作業領域 `ArimaModel::workspace(h)` を受け取り、確保なしで同じ計算をする。
定常な ARMA では、$h$ 期先の予測誤差の分散は $\sigma^2\sum_{j<h}\psi_j^2$ で、$h\to\infty$ で過程の分散に近づく。
差分 $d\ge1$ を含むモデルでは、分散は $h$ とともに際限なく増える。
`variance` はパラメータを既知とみなした値で、推定の誤差を含まない。
そのため推定したパラメータで作った区間 $\hat x_{n+h|n}\pm1.96\sqrt{\text{variance}}$ の被覆率は、名目よりわずかに低くなる。

次のセルは前のセルの系列の最初の $n$ 点に ARMA(1,1) を当てはめ、終了状態、推定値、標準誤差、残差の検定、予測を示す。
パラメータの表は真値、推定値、観測情報量による標準誤差と 95% 区間、真値での漸近標準誤差を並べる。
予測の表はモデルの予測分散と、推定したパラメータで計算した $\sigma^2\sum\psi_j^2$（独立検算）を比べる。
図は系列の最後の 60 点、予測の平均と 95% 区間の帯、当てはめに使わなかった 12 点の実際の値である。

```rust
//| id: stats-arma-forecast-calc
//| ref: stats-arma-forecast-calc
//| title: ARMA(1,1) を最尤法で当てはめ、残差を調べて予測する
//| run: reactive
//| uses: [stats-arma-forecast-model]
//| crates: [scioxide-core, scioxide-random, scioxide-stats]
//| dependsOn:
//|   data: stats-arma-forecast-api-1
//| inputs:
//|   max_lag: {"type":"range","label":"Ljung–Box のラグ数 K","description":"自由度は K − 2。","min":5,"max":30,"step":5,"value":10}
//| cases:
//|   - {"id":"long-lag","label":"K = 30","description":"多くのラグを足すと、個々のラグの相関に対する感度は下がる。","inputs":{"max_lag":30}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"parameters","path":"/rows/0/2","approx":{"value":0.6,"atol":0.15}}
//|       - {"artifact":"forecast","path":"/rows/0/3","range":{"max":1e-6}}
//|       - {"artifact":"forecast","path":"/rows/3/3","range":{"max":1e-6}}
//|       - {"path":"/outputs/4/state","equals":"satisfied"}
use scioxide_core::RealScalar;
use scioxide_random::{ChiSquared, Survival};
use scioxide_stats::{FitIdentifiability, TimeSeriesStatistic, time_series_summary};

let phi = data["phi"].as_f64().ok_or("φ がない")?;
let theta = data["theta"].as_f64().ok_or("θ がない")?;
let n = data["points"].as_u64().ok_or("長さがない")? as usize;
let series: Vec<f64> =
    serde_json::from_value(data["series"].clone()).map_err(|e| e.to_string())?;
let fit = fit_arma(&series[..n]).map_err(|e| e.to_string())?;
let p = fit.model.parameters().to_vec();
let covariance = fit.information.covariance();
let se = |i: usize| covariance.map(|c| RealScalar::sqrt(c[i * 3 + i]));
// 真値での漸近標準誤差（Brockwell–Davis, Example 8.8.3）
let scale = (1.0 + phi * theta) / ((phi + theta) * (phi + theta) * n as f64);
let theory = [
    RealScalar::sqrt(scale * (1.0 - phi * phi) * (1.0 + phi * theta)),
    RealScalar::sqrt(scale * (1.0 - theta * theta) * (1.0 + phi * theta)),
    RealScalar::sqrt(2.0 / n as f64),
];
let names = ["AR 係数 φ", "MA 係数 θ", "革新の分散 σ²"];
let rows: Vec<_> = (0..3)
    .map(|i| {
        let interval = se(i).map(|s| (p[i] - 1.96 * s, p[i] + 1.96 * s));
        let truth = [phi, theta, 1.0][i];
        (
            names[i],
            truth,
            p[i],
            se(i),
            interval.map(|v| v.0),
            interval.map(|v| v.1),
            theory[i],
        )
    })
    .collect();
let fixed4 = serde_json::json!({ "fractionDigits": 4 });
let columns = serde_json::json!([
    { "key": "0", "label": "パラメータ" },
    { "key": "1", "label": "真値 [-]", "type": "number", "format": fixed4 },
    { "key": "2", "label": "推定値 [-]", "type": "number", "format": fixed4 },
    {
        "key": "3",
        "label": "標準誤差（観測情報量）[-]",
        "type": "number",
        "format": fixed4,
        "nullText": "定まらない"
    },
    { "key": "4", "label": "95% 区間の下端 [-]", "type": "number", "format": fixed4, "nullText": "—" },
    { "key": "5", "label": "95% 区間の上端 [-]", "type": "number", "format": fixed4, "nullText": "—" },
    { "key": "6", "label": "漸近標準誤差（真値）[-]", "type": "number", "format": fixed4 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "parameters" })
);

// Ljung–Box（scioxide-stats は提供しない）: 標準化した革新の自己相関から Q と p 値を計算する。
let k = max_lag as usize;
let residuals = &fit.standardized;
let r =
    time_series_summary(residuals, TimeSeriesStatistic::Acf, k).map_err(|e| e.to_string())?;
let m = residuals.len() as f64;
let q: f64 = (1..=k)
    .map(|j| r[j].value * r[j].value / (m - j as f64))
    .sum::<f64>()
    * m
    * (m + 2.0);
let chi = ChiSquared::new((k - 2) as f64).map_err(|e| e.to_string())?;
let pvalue = chi.sf(q).map_err(|e| e.to_string())?;
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let diagnostics = vec![(
    format!("{:?}", fit.information.identifiability()),
    fit.information.condition(),
    q,
    k - 2,
    pvalue,
)];
let diagnostic_columns = serde_json::json!([
    { "key": "0", "label": "情報量の分類" },
    { "key": "1", "label": "情報量の条件数 [-]", "type": "number", "format": sci3, "nullText": "—" },
    { "key": "2", "label": "Ljung–Box Q [-]", "type": "number", "format": fixed4 },
    { "key": "3", "label": "自由度 K − 2", "type": "integer" },
    { "key": "4", "label": "p 値 [-]", "type": "number", "format": fixed4 }
]);
emit_table_with_columns!(
    diagnostic_columns,
    diagnostics,
    metadata = serde_json::json!({ "id": "residuals" })
);

// 予測: モデルの分散と、推定値で計算した σ² Σ ψ_j²（独立検算）
let horizon = 12;
let forecasts = fit.model.forecast(horizon).map_err(|e| e.to_string())?;
let forecast_rows: Vec<_> = [1_usize, 2, 5, 12]
    .iter()
    .map(|&h| {
        let check = psi_variance(p[0], p[1], p[2], h);
        let f = forecasts[h - 1];
        (
            h,
            f.mean,
            f.variance,
            ((f.variance - check) / check).abs(),
            series[n + h - 1],
        )
    })
    .collect();
let forecast_columns = serde_json::json!([
    { "key": "0", "label": "先の期 h", "type": "integer" },
    { "key": "1", "label": "予測の平均 [-]", "type": "number", "format": fixed4 },
    { "key": "2", "label": "予測誤差の分散 [-]", "type": "number", "format": fixed4 },
    { "key": "3", "label": "σ²Σψ² との相対差 [-]", "type": "number", "format": sci3 },
    { "key": "4", "label": "実際の値 [-]", "type": "number", "format": fixed4 }
]);
emit_table_with_columns!(
    forecast_columns,
    forecast_rows,
    metadata = serde_json::json!({ "id": "forecast" })
);

let history: Vec<[f64; 2]> = (n - 60..n).map(|t| [t as f64, series[t]]).collect();
let mean: Vec<[f64; 2]> = (0..horizon)
    .map(|h| [(n + h) as f64, forecasts[h].mean])
    .collect();
let band: Vec<[f64; 4]> = (0..horizon)
    .map(|h| {
        let half = 1.96 * RealScalar::sqrt(forecasts[h].variance);
        [
            (n + h) as f64,
            forecasts[h].mean,
            forecasts[h].mean - half,
            forecasts[h].mean + half,
        ]
    })
    .collect();
let actual: Vec<[f64; 2]> = (n..n + horizon).map(|t| [t as f64, series[t]]).collect();
emit_chart!(serde_json::json!({
    "kind": "xy",
    "xLabel": "時点 t [期]",
    "yLabel": "x_t [-]",
    "dataZoom": true,
    "tooltip": true,
    "layers": [
        { "id": "history", "kind": "line", "name": "当てはめに使った系列", "points": history },
        { "id": "band", "kind": "band", "name": "95% 予測区間", "points": band },
        { "id": "mean", "kind": "line", "name": "予測の平均", "points": mean },
        { "id": "actual", "kind": "scatter", "name": "実際の値（未使用）", "points": actual }
    ],
    "annotations": [{ "kind": "line", "axis": "x", "value": n as f64 - 0.5, "label": "予測の起点" }]
}));

let termination = fit.report.termination();
let identifiable = fit.information.identifiability() == FitIdentifiability::Identifiable;
let outcome = if termination.is_success() && identifiable {
    Outcome::satisfied("尤度の最小化が収束し、観測情報量が正定値")
} else if termination.is_success() {
    Outcome::partial("収束したが、観測情報量から標準誤差が定まらない")
        .explanation("AR と MA の根の打ち消しなどで、パラメータが識別できない可能性がある。")
} else {
    Outcome::partial("ソルバーが収束の判定を満たす前に止まった")
        .explanation("推定値は最後の点の値として解釈する。")
};
// ソルバーの反復は入れ子の解法に数えられるので、全体の回数を読む
let iterations = fit
    .report
    .counts()
    .total()
    .map_err(|e| e.to_string())?
    .iterations();
emit_outcome!(
    outcome
        .status(format!("{termination:?}"))
        .diagnostic("負の対数尤度", fit.report.objective().unwrap_or(0.0), None)
        .diagnostic("反復回数", iterations as f64, None)
);
```

既定の入力では、ソルバーは 12 回の反復で `Converged` に達し、観測情報量は正定値（`Identifiable`、条件数 5.9）になる。
$\hat\phi=0.583$ と $\hat\theta=0.359$ は真値から標準誤差の 0.2 倍と 0.7 倍の位置にあり、観測情報量による標準誤差（0.075 と 0.089）は真値での漸近標準誤差（0.074 と 0.088）とよく合う。
$\hat\sigma^2=1.164$ は真値 1 から標準誤差の 1.4 倍離れているが、95% 区間 $[0.936,1.392]$ は真値を含む。
Ljung–Box の統計量は $Q=8.36$（自由度 8）、p 値は 0.40 で、残差に自己相関が残っている証拠はない。
予測誤差の分散は $\sigma^2\sum\psi_j^2$ と丸めの水準（相対 $2\times10^{-16}$ 以下）で一致する。
系列の長さ 200 のうちに Kalman フィルタの状態の誤差分散が定常値に収束しているので、有限の系列による予測と無限の過去による予測の差が見えない。
予測の平均は $h$ とともに $\hat\phi^{\,h-1}$ の比で 0 に近づき、分散は過程の分散の推定値 2.73 に近づく。

$\phi=0.5$、$\theta=-0.4$ では、真値での漸近標準誤差が 0.49 と 0.52 に増える。
シード 4 の推定値は $\hat\phi=-0.057$、$\hat\theta=0.187$ と真値から大きく離れ、観測情報量による標準誤差は約 1.1 に達するが、和 $\hat\phi+\hat\theta=0.13$ は真値の 0.1 に近い。
尤度は $\phi+\theta$ が一定の方向にほとんど平らなので、和だけがよく決まる。
情報量の条件数は約 1000 に増える。
分類は `Identifiable` のままで outcome も satisfied だが、標準誤差の大きさと条件数は、モデルの次数を下げて白色雑音や AR(1) と比べる合図になる。
観測情報量の階数が落ちたり負の固有値が出たりすると、標準誤差の欄が「定まらない」になり、outcome は partial になる。
$K=30$ では $Q=22.8$（自由度 28）、p 値 0.74 で、自由度が増えるぶん、少数のラグに集中した相関に対する感度は下がる。

## 予測区間の被覆率

1 本の系列では、12 点の実際の値が区間に入るかどうかは偶然に左右される。
次のセルは最初のセルの $\phi$、$\theta$、$n$ を受け取り、別のシードで作った $R$ 本の系列のそれぞれに当てはめと予測を繰り返す。
数えるのは、$h=1,\dots,12$ の各期で実際の値が 95% 予測区間に入った回数と、$\phi$ と $\theta$ の 95% 区間（観測情報量による）が真値を含んだ回数である。
推定値の平均と標本標準偏差も記録し、漸近標準誤差と比べる。
1 本ごとに勾配と観測情報量を差分で求めるために尤度を何度も評価し、$R=30$ では wasm で 8 秒ほどかかるので、ボタンで実行し、同じ入力の結果は再利用する。

```rust
//| id: stats-arma-forecast-coverage
//| ref: stats-arma-forecast-coverage
//| title: 系列を作り直して当てはめと予測を繰り返し、区間の被覆を数える
//| run: button
//| cache: inputs
//| uses: [stats-arma-forecast-model]
//| crates: [scioxide-core, scioxide-stats]
//| dependsOn:
//|   data: stats-arma-forecast-api-1
//| exports: [phi, theta, points, replicates, covered, parameters]
//| inputs:
//|   replicates: {"type":"range","label":"系列の本数 R","description":"被覆率の Monte Carlo 誤差を変える。","min":10,"max":30,"step":10,"value":30}
//|   seed: {"type":"range","label":"乱数のシード","min":1,"max":100,"step":1,"value":1}
//| cases:
//|   - {"id":"few-series","label":"R = 10","description":"Wilson 区間が広がる。","inputs":{"replicates":10}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"path":"/exports/replicates","equals":30}
use scioxide_core::RealScalar;
use scioxide_stats::FitIdentifiability;

let phi = data["phi"].as_f64().ok_or("φ がない")?;
let theta = data["theta"].as_f64().ok_or("θ がない")?;
let n = data["points"].as_u64().ok_or("長さがない")? as usize;
let horizon = 12;
let r = replicates as usize;
// covered[h] = h + 1 期先で区間に入った回数。parameters[i] = [区間が真値を含んだ回数、
// 標準誤差が定まった回数、推定値の和、推定値の二乗和]（i = 0 が φ、1 が θ）
let mut covered = vec![0_usize; horizon];
let mut parameters = [[0.0_f64; 4]; 2];
for j in 0..r {
    let series = simulate(phi, theta, n + horizon, 100_000 * seed as u64 + j as u64)
        .map_err(|e| e.to_string())?;
    let fit = fit_arma(&series[..n]).map_err(|e| e.to_string())?;
    let p = fit.model.parameters().to_vec();
    let forecasts = fit.model.forecast(horizon).map_err(|e| e.to_string())?;
    for (h, f) in forecasts.iter().enumerate() {
        let half = 1.96 * RealScalar::sqrt(f.variance);
        covered[h] += usize::from((series[n + h] - f.mean).abs() <= half);
    }
    let covariance = fit.information.covariance();
    let identifiable = fit.information.identifiability() == FitIdentifiability::Identifiable;
    for (i, truth) in [phi, theta].into_iter().enumerate() {
        let cell = &mut parameters[i];
        cell[2] += p[i];
        cell[3] += p[i] * p[i];
        if let (true, Some(c)) = (identifiable, covariance) {
            let s = RealScalar::sqrt(c[i * 3 + i]);
            cell[0] += f64::from(u8::from((p[i] - truth).abs() <= 1.96 * s));
            cell[1] += 1.0;
        }
    }
}
export!(phi, phi);
export!(theta, theta);
export!(points, n);
export!(replicates, r);
export!(covered, covered);
export!(parameters, parameters);
```

表示のセルは各期の被覆率を Wilson の 95% 区間と一緒に描き、名目の 0.95 と比べる。
表は $\phi$ と $\theta$ について、推定値の平均、反復での標準偏差、漸近標準誤差、区間の被覆率とその Wilson 区間を示す。
被覆率の分母は、観測情報量から標準誤差が定まった系列の数である。

```rust
//| id: stats-arma-forecast-coverage-display
//| ref: stats-arma-forecast-coverage-display
//| title: 予測区間とパラメータの区間の被覆率を名目の水準と比べる
//| run: reactive
//| crates: []
//| dependsOn:
//|   run: stats-arma-forecast-coverage
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"parameters","path":"/rows/0/0","equals":"AR 係数 φ"}
//|       - {"artifact":"pooled","path":"/rows/0/0","equals":360}
let phi = run["phi"].as_f64().ok_or("φ がない")?;
let theta = run["theta"].as_f64().ok_or("θ がない")?;
let n = run["points"].as_f64().ok_or("長さがない")?;
let r = run["replicates"].as_f64().ok_or("本数がない")?;
let covered: Vec<f64> =
    serde_json::from_value(run["covered"].clone()).map_err(|e| e.to_string())?;
let parameters: [[f64; 4]; 2] =
    serde_json::from_value(run["parameters"].clone()).map_err(|e| e.to_string())?;
// Wilson のスコア区間（95%）
let wilson = |p: f64, total: f64| {
    let z = 1.96_f64;
    let center = (p + z * z / (2.0 * total)) / (1.0 + z * z / total);
    let radius = z * (p * (1.0 - p) / total + z * z / (4.0 * total * total)).sqrt()
        / (1.0 + z * z / total);
    (center - radius, center + radius)
};
let points: Vec<[f64; 4]> = covered
    .iter()
    .enumerate()
    .map(|(h, &c)| {
        let rate = c / r;
        let (low, high) = wilson(rate, r);
        [(h + 1) as f64, rate, low, high]
    })
    .collect();
emit_chart!(serde_json::json!({
    "kind": "errorbar",
    "xLabel": "先の期 h [期]",
    "yLabel": "95% 予測区間の被覆率 [-]",
    "xMin": 0.5,
    "xMax": 12.5,
    "yMin": 0.8,
    "yMax": 1.0,
    "tooltip": true,
    "series": [{ "name": "被覆率と Wilson 区間", "points": points }],
    "annotations": [{ "kind": "line", "axis": "y", "value": 0.95, "label": "名目 0.95" }]
}));
// 12 期をまとめた被覆率（同じ系列の期どうしは独立でないので、区間は目安）
let total = covered.len() as f64 * r;
let pooled = covered.iter().sum::<f64>() / total;
let (pooled_low, pooled_high) = wilson(pooled, total);
let fixed3 = serde_json::json!({ "fractionDigits": 3 });
emit_table_with_columns!(
    serde_json::json!([
        { "key": "0", "label": "予測区間の判定の数", "type": "integer" },
        { "key": "1", "label": "まとめた被覆率 [-]", "type": "number", "format": fixed3 },
        { "key": "2", "label": "Wilson 区間の下端 [-]", "type": "number", "format": fixed3 },
        { "key": "3", "label": "Wilson 区間の上端 [-]", "type": "number", "format": fixed3 }
    ]),
    vec![(total as usize, pooled, pooled_low, pooled_high)],
    metadata = serde_json::json!({ "id": "pooled" })
);
// 真値での漸近標準誤差（参照値）
let scale = (1.0 + phi * theta) / ((phi + theta) * (phi + theta) * n);
let theory = [
    (scale * (1.0 - phi * phi) * (1.0 + phi * theta)).sqrt(),
    (scale * (1.0 - theta * theta) * (1.0 + phi * theta)).sqrt(),
];
let rows: Vec<_> = (0..2)
    .map(|i| {
        let [hits, defined, sum, square] = parameters[i];
        let average = sum / r;
        let spread = ((square - r * average * average) / (r - 1.0)).sqrt();
        let rate = (defined > 0.0).then(|| hits / defined);
        let interval = rate.map(|c| wilson(c, defined));
        let name = ["AR 係数 φ", "MA 係数 θ"][i];
        (
            name,
            [phi, theta][i],
            average,
            spread,
            theory[i],
            rate,
            interval.map(|v| v.0),
            interval.map(|v| v.1),
        )
    })
    .collect();
let columns = serde_json::json!([
    { "key": "0", "label": "パラメータ" },
    { "key": "1", "label": "真値 [-]", "type": "number", "format": fixed3 },
    { "key": "2", "label": "推定値の平均 [-]", "type": "number", "format": fixed3 },
    { "key": "3", "label": "推定値の標準偏差 [-]", "type": "number", "format": fixed3 },
    { "key": "4", "label": "漸近標準誤差 [-]", "type": "number", "format": fixed3 },
    { "key": "5", "label": "区間の被覆率 [-]", "type": "number", "format": fixed3, "nullText": "—" },
    {
        "key": "6",
        "label": "Wilson 区間の下端 [-]",
        "type": "number",
        "format": fixed3,
        "nullText": "—"
    },
    { "key": "7", "label": "Wilson 区間の上端 [-]", "type": "number", "format": fixed3, "nullText": "—" }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "parameters" })
);
```

既定の入力（$R=30$、シード 1）では、各期の被覆率は 0.87〜1.0 に散らばり、どの期でも Wilson 区間が 0.95 を含む。
1 期あたり 30 本では Wilson 区間の幅が 0.2 を超え、期ごとの違いは読み取れない。
12 期をまとめた 360 回の判定では被覆率 0.933（Wilson 区間 0.903〜0.955）で、名目の 0.95 を区間に含む。
同じ系列の期どうしの判定は独立でないので、まとめた区間は目安である。
パラメータの推定誤差を無視した区間なので、被覆率は名目をわずかに下回る傾向があるが、$n=200$ ではその差はこの反復数の Monte Carlo 誤差より小さい。
推定値の反復での標準偏差（$\phi$ で 0.068、$\theta$ で 0.073）は漸近標準誤差（0.074 と 0.088）と同じ程度で、観測情報量による区間の被覆率も 0.90 と 0.97 で、どちらも Wilson 区間が 0.95 を含む。
$\phi=0.5$、$\theta=-0.4$ のように打ち消しに近い組では、推定値の分布が漸近正規から離れるので、最初のセルの入力を変えて同じ実験を繰り返すと、区間の被覆が崩れるかどうかを確かめられる。

## まとめ

ARMA(1,1) の ACF はラグ 1 の値が $\phi$ と $\theta$ で決まり、その後 $\phi$ の比で減るので、ACF と PACF がどちらも切れずに減衰することが同定の手がかりになる。
`PreparedArimaFit` は Kalman フィルタで厳密な Gauss 尤度を評価し、最小化は `FitSolver` を実装したソルバーが行うので、終了状態は `ArimaFitReport::report()` で確かめる。
標準誤差は観測情報量を `fit_information` に渡して求め、`Identifiable` でなければ推定値の解釈を控え、次数を見直す。
scioxide-stats は Ljung–Box の検定を提供しないが、`time_series_summary` の残差の自己相関と $\chi^2$ 分布から同じ統計量を作れる。
`ArimaModel::forecast` の分散は推定の誤差を含まないので、短い系列では予測区間の被覆率を反復実験で確かめる。
