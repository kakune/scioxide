母平均の信頼区間は、データの分布が歪んでいるときに名目の水準を保ちにくい。
所得、反応時間、粒径、保険金のように右に長い裾を持つデータでは、標本平均の分布も右に歪み、平均と標本分散が連動して動く。
bootstrap は標本から復元抽出した再標本で統計量の分布を近似し、正規性を仮定せずに区間を作る。
ただし、区間の作り方によって有限の標本での被覆率は異なる。
このページは対数正規分布の平均に対して t 区間と 3 種類の bootstrap 区間を作り、区間が真の平均を含む割合（被覆率）を反復実験で測る。
被覆率の推定値は二項分布の信頼区間と一緒に示し、名目の 95% との差を Monte Carlo 誤差の大きさで判断する。

## 対数正規分布の平均

$Z\sim N(0,1)$ に対して $X=e^{\sigma Z}$ の分布を対数正規分布 $\mathrm{LogNormal}(0,\sigma)$ という。
推定の対象は母平均

$$
\theta=E[X]=e^{\sigma^2/2}
$$

である。
分散は $\mathrm{Var}(X)=(e^{\sigma^2}-1)e^{\sigma^2}$、歪度は $\gamma=(e^{\sigma^2}+2)\sqrt{e^{\sigma^2}-1}$ である。
$\sigma=1$ では $\theta\approx1.6487$、$\gamma\approx6.18$ で、$\sigma=1.5$ では $\gamma\approx33.5$ に達する。
独立な $n$ 個の観測の標本平均 $\bar X$ の歪度は $\gamma/\sqrt n$ で、$\sigma=1$、$n=20$ でも約 1.38 残る。
観測 $x_1,\dots,x_n$ から $\theta$ の両側 95% 区間を作り、その区間が $\theta$ を含むかどうかを調べる。

## 4 つの区間

Student の t 区間は $\bar x\pm t_{0.975,n-1}\,s/\sqrt n$ である（$s$ は除数 $n-1$ の標本標準偏差）。
観測が独立な正規分布に従うなら正確だが、歪んだ分布では $\bar X$ と $s$ が正に相関する。
$\bar x$ が小さい標本ほど $s$ も小さくなるので、区間全体が $\theta$ より下に来やすい。

bootstrap は観測の経験分布 $\hat F$ を母集団の代わりに使う。
$\hat F$ から大きさ $n$ の再標本を $B$ 回抽出し（観測の復元抽出）、再標本ごとの統計量 $\hat\theta^*_1,\dots,\hat\theta^*_B$ を計算する。
その標本分位点を $q(p)$（Hyndman–Fan の第 7 種）、$\alpha=0.05$ とすると、scioxide-stats の 3 つの区間は次のとおりである。

| 方法 | 区間 | 考え方 |
|---|---|---|
| percentile | $[q(\alpha/2),\ q(1-\alpha/2)]$ | 再標本の統計量の分布をそのまま $\hat\theta$ の分布とみなす |
| basic | $[2\hat\theta-q(1-\alpha/2),\ 2\hat\theta-q(\alpha/2)]$ | $\hat\theta^*-\hat\theta$ の分布で $\hat\theta-\theta$ の分布を近似し、反転する |
| BCa | $[q(\alpha_1),\ q(\alpha_2)]$ | percentile の確率水準を偏りと加速で補正する |

BCa の確率水準は

$$
\alpha_i=\Phi\!\left(z_0+\frac{z_0+z^{(i)}}{1-a\,(z_0+z^{(i)})}\right),\qquad z^{(1)}=\Phi^{-1}(\alpha/2),\ z^{(2)}=\Phi^{-1}(1-\alpha/2)
$$

である。
$\Phi$ は標準正規分布関数、偏りの補正 $z_0=\Phi^{-1}\bigl((\#\{\hat\theta^*<\hat\theta\}+\#\{\hat\theta^*=\hat\theta\}/2)/B\bigr)$ は再標本の統計量が観測値を下回る割合から決まる。
加速 $a=\sum_iU_i^3/\bigl(6(\sum_iU_i^2)^{3/2}\bigr)$ は、観測を 1 つずつ除いた jackknife の統計量 $\hat\theta_{(i)}$ から作る影響値 $U_i=\bar\theta_{(\cdot)}-\hat\theta_{(i)}$ で計算する。
標本平均では $U_i=(x_i-\bar x)/(n-1)$ なので、$a=\sum_i(x_i-\bar x)^3/\bigl(6(\sum_i(x_i-\bar x)^2)^{3/2}\bigr)$ は標本の歪度を $6\sqrt n$ で割った値になる。
$z_0=a=0$ なら BCa は percentile と同じになる。

区間の正確さは、片側の外れ確率が名目の $\alpha/2$ からどれだけずれるかで測る。
Edgeworth 展開による解析では、t 区間、percentile、basic の片側の誤差は $O(n^{-1/2})$、BCa は $O(n^{-1})$ である（Efron 1987、Hall 1988）。
両側の区間では左右の $O(n^{-1/2})$ の項が打ち消し合い、どの方法も被覆率の誤差は $O(n^{-1})$ になる。
ただし、強く歪んだ分布では $n^{-1}$ の項の係数が大きく、打ち消し合いも不完全なので、実用的な $n$ での差は反復実験で確かめる必要がある。
$B$ は区間の端点の Monte Carlo 誤差を決める。
2.5% と 97.5% の分位点を安定させるには $B\ge1000$ 程度が目安で（Davison–Hinkley 1997, 5 章）、BCa ではさらに $n$ 回の jackknife の評価が加わる。

## API と結果の構造

`ResamplingPlan::new(&[n], method, options)` がリサンプリングの Plan を作る。
`method` に `ResamplingMethod::Bootstrap { design, method, confidence }` を渡し、`BootstrapMethod::{Percentile, Basic, Bca}` と名目の信頼度 `ConfidenceProbability` を選ぶ。
`design` は再標本の作り方で、群ごとに独立に復元抽出する `BootstrapDesign::Independent`、行をそろえて抽出する `Paired`、層の大きさを固定する `Stratified`、時系列の連続したブロックを抽出する `MovingBlock { length }` と `CircularBlock { length }` がある。
ブロックの設計では BCa を使えず、`ResamplingPlan::new` が `InvalidInput` を返す。
`ResamplingOptions::with_replicates(B)` で再標本の数を決める（既定 9999）。

統計量は再標本の添字 `ResampledIndices` から値を返す関数として `ResamplingProblem::Indexed` に渡す。
`ResamplingPlan::evaluate(problem, replicates)` は作業領域と出力を確保して実行し、`ResamplingOutput` を返す。
`ReplicateOptions::sequential(&mut rng, policy)` は 1 つの生成器から再標本を順に抽出し、`ReplicateOptions::indexed` は再標本ごとに分割した乱数の流れを使って並列でも結果が変わらないようにする。
同じ Plan を多数のデータで使うときは、`ResamplingPlan::workspace` で作業領域を一度作り、`evaluate_into` に出力の配列と一緒に渡すと、実行ごとの確保が起きない。

結果の `ResamplingResult` は終了状態 `termination()` と推論 `inference()` を持つ。
推論があるのは終了状態が `StatsTermination::Completed` のときだけで、計算回数の上限や中止で止まると `None` になる。
bootstrap の推論 `ResamplingInference::Bootstrap(BootstrapInterval)` は、区間 `bounds`、再標本の標準偏差 `standard_error`、再標本の平均の Monte Carlo 誤差 `mean_monte_carlo_error`（$s^*/\sqrt B$）、偏りの推定 `bias`（$\bar\theta^*-\hat\theta$）、すべての再標本が等しいことを示す `degenerate`、BCa の `bias_correction`（$z_0$）と `acceleration`（$a$）を持つ。
`mean_monte_carlo_error` は区間の端点の誤差ではない。
jackknife の統計量がすべて等しくて $a$ が定まらないとき、BCa は `NumericalInstability` を返す。

ワンショット呼び出しの `bootstrap(statistic, sample, rng)` は、スライスを受け取る統計量（`mean` など）に対して、9999 回の BCa による両側 95% 区間を返す。
`jackknife(statistic, sample)` は、1 つずつ除いた $n$ 個の統計量から偏りと標準誤差を返す。

## 1 つの標本での区間

次のセルは対数正規分布から大きさ $n$ の標本を 1 つ抽出し、t 区間と 3 種類の bootstrap 区間を作る。
3 つの Plan は同じシードから始めるので、同じ再標本を使い、区間の作り方だけが違う。
1 つ目の表は各区間の端点、幅、$\bar x$ から左右の端までの距離、$\theta$ を含むかを示す。
2 つ目の表は bootstrap の診断値を独立な検算と並べる。
標本平均の理想的な bootstrap 標準誤差（$B\to\infty$）は $\sqrt{(n-1)/n}\,s/\sqrt n$ に等しく、jackknife の標準誤差は $s/\sqrt n$ に正確に等しい。
加速 $a$ は上の閉形式で手計算する。
図は再標本の平均のヒストグラムで、$\bar x$ と $\theta$ を縦線で示す。

```rust
//| id: stats-bootstrap-coverage-api-1
//| ref: stats-bootstrap-coverage-api-1
//| title: 対数正規分布の 1 つの標本に 4 つの区間を作る
//| run: reactive
//| crates: [scioxide-core, scioxide-random, scioxide-stats]
//| inputs:
//|   samples: {"type":"range","label":"標本の大きさ n","min":10,"max":80,"step":10,"value":20}
//|   sigma: {"type":"range","label":"対数の標準偏差 σ [-]","description":"大きいほど右の裾が長くなる。","min":0.25,"max":1.5,"step":0.25,"value":1.0}
//|   resamples: {"type":"range","label":"再標本の数 B","min":199,"max":3999,"step":200,"value":1999}
//|   seed: {"type":"range","label":"乱数のシード","min":1,"max":100,"step":1,"value":3}
//| cases:
//|   - {"id":"heavy-tail","label":"σ = 1.5","description":"加速 a と偏りの補正 z₀ が大きくなり、BCa の区間が右へ伸びる。","inputs":{"sigma":1.5}}
//|   - {"id":"mild-skew","label":"σ = 0.25、n = 80","description":"歪みが小さく、4 つの区間がほぼ一致する。","inputs":{"sigma":0.25,"samples":80}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"intervals","path":"/rows/3/2","approx":{"value":3.39318,"atol":1e-4}}
//|       - {"artifact":"diagnostics","path":"/rows/0/2","range":{"max":0.05}}
//|       - {"artifact":"diagnostics","path":"/rows/1/2","range":{"max":1e-12}}
//|       - {"artifact":"diagnostics","path":"/rows/3/2","range":{"max":1e-12}}
//|       - {"path":"/outputs/3/state","equals":"satisfied"}
//|   - case: heavy-tail
//|     expect:
//|       - {"artifact":"diagnostics","path":"/rows/3/2","range":{"max":1e-12}}
//|   - case: mild-skew
//|     expect:
//|       - {"artifact":"diagnostics","path":"/rows/1/2","range":{"max":1e-12}}
use scioxide_core::RealScalar;
use scioxide_random::SplitMix64;
use scioxide_random::{Distribution, LogNormal, Mean, OutputPolicy, SamplingPolicy, SeedableRng};
use scioxide_stats::{
    BootstrapDesign, BootstrapMethod, ConfidenceProbability, ReplicateOptions,
    ResampledIndices, ResamplingInference, ResamplingMethod, ResamplingOptions, ResamplingPlan,
    ResamplingProblem, jackknife, mean, mean_confidence_interval,
};

let n = samples as usize;
let law = LogNormal::new(0.0_f64, sigma).map_err(|e| e.to_string())?;
let theta = law.mean().map_err(|e| e.to_string())?;
let mut rng = SplitMix64::from_seed(seed as u64);
let mut data = Vec::with_capacity(n);
for _ in 0..n {
    data.push(law.sample(&mut rng).map_err(|e| e.to_string())?);
}
let xbar = mean(&data).map_err(|e| e.to_string())?;
let t = mean_confidence_interval(&data).map_err(|e| e.to_string())?;
let statistic = |sample: ResampledIndices<'_>| {
    let idx = sample.indices();
    Ok(idx.iter().map(|&i| data[i]).sum::<f64>() / idx.len() as f64)
};
let confidence = ConfidenceProbability::new(0.95).map_err(|e| e.to_string())?;
let options = ResamplingOptions::default().with_replicates(resamples as usize);
let mut rows = vec![("Student の t", t.bounds().lower(), t.bounds().upper())];
let mut bca = None;
let mut distribution = Vec::new();
for (name, method) in [
    ("percentile", BootstrapMethod::Percentile),
    ("basic", BootstrapMethod::Basic),
    ("BCa", BootstrapMethod::Bca),
] {
    let design = BootstrapDesign::Independent;
    let kind = ResamplingMethod::Bootstrap {
        design,
        method,
        confidence,
    };
    let plan = ResamplingPlan::new(&[n], kind, options).map_err(|e| e.to_string())?;
    // 3 つの Plan は同じシードから始め、同じ再標本を使う。
    let mut generator = SplitMix64::from_seed(seed as u64 + 1000);
    let policy = SamplingPolicy::rollback(OutputPolicy::Atomic);
    let output = plan
        .evaluate(
            ResamplingProblem::Indexed(&statistic),
            ReplicateOptions::sequential(&mut generator, policy),
        )
        .map_err(|e| e.to_string())?;
    let Some(ResamplingInference::Bootstrap(interval)) = output.report().inference() else {
        return Err(format!("{:?} で止まった", output.report().termination()));
    };
    rows.push((name, interval.bounds.lower(), interval.bounds.upper()));
    if method == BootstrapMethod::Bca {
        bca = Some((interval, output.report().termination()));
        distribution = output.distribution().to_vec();
    }
}
let (bca, termination) = bca.ok_or("BCa の結果がない")?;
let interval_rows: Vec<_> = rows
    .iter()
    .map(|&(name, low, high)| {
        (
            name,
            low,
            high,
            high - low,
            xbar - low,
            high - xbar,
            low <= theta && theta <= high,
        )
    })
    .collect();
let fixed4 = serde_json::json!({ "fractionDigits": 4 });
let columns = serde_json::json!([
    { "key": "0", "label": "区間" },
    { "key": "1", "label": "下端 [-]", "type": "number", "format": fixed4 },
    { "key": "2", "label": "上端 [-]", "type": "number", "format": fixed4 },
    { "key": "3", "label": "幅 [-]", "type": "number", "format": fixed4 },
    { "key": "4", "label": "x̄ − 下端 [-]", "type": "number", "format": fixed4 },
    { "key": "5", "label": "上端 − x̄ [-]", "type": "number", "format": fixed4 },
    { "key": "6", "label": "θ を含む", "type": "boolean" }
]);
emit_table_with_columns!(
    columns,
    interval_rows,
    metadata = serde_json::json!({ "id": "intervals" })
);

// 独立検算: 理想的な bootstrap 標準誤差、jackknife の標準誤差、平均の加速 a の閉形式
let s = t.standard_error() * RealScalar::sqrt(n as f64);
let ideal = RealScalar::sqrt((n as f64 - 1.0) / n as f64) * s / RealScalar::sqrt(n as f64);
let jack = jackknife(mean, &data).map_err(|e| e.to_string())?;
let (m2, m3) = data.iter().fold((0.0, 0.0), |(a, b), &x| {
    let d = x - xbar;
    (a + d * d, b + d * d * d)
});
let closed_a = m3 / (6.0 * RealScalar::powf(m2, 1.5));
let a = bca.acceleration.ok_or("加速がない")?;
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let diagnostic_columns = serde_json::json!([
    { "key": "0", "label": "量" },
    {
        "key": "1",
        "label": "scioxide-stats [-]",
        "type": "number",
        "format": { "significantDigits": 6 }
    },
    { "key": "2", "label": "検算との相対差 [-]", "type": "number", "format": sci3, "nullText": "—" }
]);
let relative = |value: f64, check: f64| ((value - check) / check).abs();
let diagnostics = vec![
    (
        "bootstrap 標準誤差 / 理想値",
        bca.standard_error,
        Some(relative(bca.standard_error, ideal)),
    ),
    (
        "jackknife 標準誤差 / s/√n",
        jack.standard_error,
        Some(relative(
            jack.standard_error,
            s / RealScalar::sqrt(n as f64),
        )),
    ),
    (
        "偏りの補正 z₀",
        bca.bias_correction.ok_or("z₀ がない")?,
        None,
    ),
    ("加速 a / 閉形式", a, Some(relative(a, closed_a))),
    ("偏りの推定 θ̄* − θ̂", bca.bias, None),
    (
        "再標本の平均の Monte Carlo 誤差",
        bca.mean_monte_carlo_error,
        None,
    ),
];
emit_table_with_columns!(
    diagnostic_columns,
    diagnostics,
    metadata = serde_json::json!({ "id": "diagnostics" })
);

// 再標本の平均のヒストグラム（表示用に 30 区間で数える）
let (low, high) = distribution
    .iter()
    .fold((f64::MAX, f64::MIN), |(a, b), &v| (a.min(v), b.max(v)));
let width = (high - low) / 30.0;
let mut counts = [0_usize; 30];
for &v in &distribution {
    counts[(((v - low) / width) as usize).min(29)] += 1;
}
let bins: Vec<[f64; 3]> = (0..30)
    .map(|k| {
        [
            low + k as f64 * width,
            low + (k + 1) as f64 * width,
            counts[k] as f64,
        ]
    })
    .collect();
emit_chart!(serde_json::json!({
    "kind": "histogram",
    "xLabel": "再標本の平均 θ̂* [-]",
    "yLabel": "度数 [回]",
    "bins": bins,
    "tooltip": true,
    "annotations": [
        { "kind": "line", "axis": "x", "value": xbar, "label": "x̄" },
        {
            "kind": "line",
            "axis": "x",
            "value": theta,
            "label": "θ",
            "style": { "lineType": "dashed" }
        },
        {
            "kind": "range",
            "axis": "x",
            "from": bca.bounds.lower(),
            "to": bca.bounds.upper(),
            "label": "BCa 区間"
        }
    ]
}));

let outcome = if termination.is_success() {
    Outcome::satisfied("すべての再標本を評価した")
        .explanation("区間は統計的な推定であり、精度の主張はない。")
} else {
    Outcome::partial("再標本の評価が途中で止まった")
};
emit_outcome!(
    outcome
        .status(format!("{termination:?}"))
        .diagnostic("再標本の数", resamples, None)
        .diagnostic("真の平均 θ", theta, None)
);
```

既定の入力（$n=20$、$\sigma=1$、$B=1999$、シード 3）では、標本平均は $\bar x\approx1.663$ で $\theta\approx1.649$ に近く、4 つの区間はどれも $\theta$ を含む。
区間の違いは $\bar x$ から両端までの距離に現れる。
t 区間は左右に 1.143 ずつ対称に広がり、percentile は左 0.858・右 1.213、BCa は左 0.682・右 1.731 と右へ長い。
basic は左 1.213・右 0.858 で、percentile の左右を入れ替えた形になる。
basic は $\hat\theta^*-\hat\theta$ の右に長い分布を反転するので、裾の向きが逆になる。
標本平均の分布は右に歪んでいるので、真の $\theta$ が区間の右に外れる危険を減らすには、上端を右へ伸ばす percentile と BCa のほうが向きとして合っている。

診断値の表では、bootstrap 標準誤差 0.5307 が理想値と 0.3% の差で一致する。
この差は $B$ が有限であることによる Monte Carlo 誤差で、$B$ を増やすと縮む。
jackknife の標準誤差と $s/\sqrt n$、BCa の加速 $a=0.103$ と閉形式は丸めの水準で一致する。
偏りの補正は $z_0=0.145$ で、再標本の平均の 56% が観測した $\bar x$ より小さい。
$\sigma=1.5$ では $a=0.133$、$z_0=0.180$ と大きくなり、BCa の上端は 10.1 と percentile の 7.26 よりさらに右へ移る。
このとき t 区間と basic の下端は負になり、正の量の平均の区間として意味を持たない。
$\sigma=0.25$、$n=80$ では歪みが小さく、4 つの区間の端点の差は 0.01 以下になる。

## 被覆率の反復実験

1 つの標本で区間が $\theta$ を含むかどうかは、その標本の偶然で決まる。
被覆率は同じ手続きを多数の標本に繰り返したときの割合である。
次のセルは $n=10,20,40,80$ のそれぞれで $R$ 個の標本を抽出し、各標本に 4 つの区間を作る。
数えるのは、$\theta$ を含んだ回数、$\theta$ が区間の下端より小さかった回数（左に外れる）、上端より大きかった回数（右に外れる）と、区間の幅の平均である。
4 つの区間は同じ標本を使うので、方法の間の差は標本のばらつきの影響を受けにくい（共通乱数）。
3 つの bootstrap の Plan は標本の大きさごとに 1 回だけ作り、作業領域と出力の配列を使い回して `evaluate_into` を呼ぶ。
計算量は $O(R\,B\sum n)$ で、既定値でも数秒かかるので、ボタンで実行し、同じ入力の結果は再利用する。
計算量を抑えるため $B$ の既定値を 399 にしており、区間の端点には $B=1000$ 程度の場合より大きい Monte Carlo 誤差が加わる。

```rust
//| id: stats-bootstrap-coverage-calc
//| ref: stats-bootstrap-coverage-calc
//| title: 標本の大きさごとに 4 つの区間の被覆率と左右の外れ率を数える
//| run: button
//| cache: inputs
//| crates: [scioxide-core, scioxide-random, scioxide-stats]
//| exports: [sizes, theta, replicates, counts]
//| inputs:
//|   sigma: {"type":"range","label":"対数の標準偏差 σ [-]","description":"大きいほど右の裾が長くなる。","min":0.25,"max":1.5,"step":0.25,"value":1.0}
//|   resamples: {"type":"range","label":"再標本の数 B","min":199,"max":599,"step":100,"value":399}
//|   replicates: {"type":"range","label":"反復する標本の数 R","description":"被覆率の Monte Carlo 誤差を変える。","min":100,"max":300,"step":50,"value":200}
//|   seed: {"type":"range","label":"乱数のシード","min":1,"max":100,"step":1,"value":5}
//| cases:
//|   - {"id":"mild-skew","label":"σ = 0.5","description":"歪みが小さく、n = 20 で 4 つとも名目に近づく。","inputs":{"sigma":0.5}}
//|   - {"id":"heavy-tail","label":"σ = 1.5","description":"n = 80 でもどの区間も大きく下回る。","inputs":{"sigma":1.5}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"path":"/exports/sizes/3","equals":80}
//|       - {"path":"/exports/replicates","equals":200}
use scioxide_core::ExecutionContext;
use scioxide_random::SplitMix64;
use scioxide_random::{Distribution, LogNormal, Mean, OutputPolicy, SamplingPolicy, SeedableRng};
use scioxide_stats::{
    BootstrapDesign, BootstrapMethod, ConfidenceProbability, ReplicateOptions,
    ResampledIndices, ResamplingInference, ResamplingMethod, ResamplingOptions, ResamplingPlan,
    ResamplingProblem, mean_confidence_interval,
};

let law = LogNormal::new(0.0_f64, sigma).map_err(|e| e.to_string())?;
let theta = law.mean().map_err(|e| e.to_string())?;
let confidence = ConfidenceProbability::new(0.95).map_err(|e| e.to_string())?;
let options = ResamplingOptions::default().with_replicates(resamples as usize);
let methods = [
    BootstrapMethod::Percentile,
    BootstrapMethod::Basic,
    BootstrapMethod::Bca,
];
let sizes = [10_usize, 20, 40, 80];
let mut rng = SplitMix64::from_seed(seed as u64);
let mut boot = SplitMix64::from_seed(seed as u64 + 1000);
let policy = SamplingPolicy::rollback(OutputPolicy::Atomic);
// counts[標本の大きさ][方法] = [含んだ回数, 左に外れた回数, 右に外れた回数, 幅の和]（方法 0 が t 区間）
let mut counts = vec![[[0.0_f64; 4]; 4]; sizes.len()];
let mut data = Vec::new();
for (k, &n) in sizes.iter().enumerate() {
    let mut plans = Vec::with_capacity(methods.len());
    for method in methods {
        let design = BootstrapDesign::Independent;
        let kind = ResamplingMethod::Bootstrap {
            design,
            method,
            confidence,
        };
        let plan = ResamplingPlan::new(&[n], kind, options).map_err(|e| e.to_string())?;
        let workspace = plan.workspace().map_err(|e| e.to_string())?;
        plans.push((plan, workspace, vec![0.0_f64; resamples as usize]));
    }
    for _ in 0..replicates as usize {
        data.clear();
        for _ in 0..n {
            data.push(law.sample(&mut rng).map_err(|e| e.to_string())?);
        }
        let t = mean_confidence_interval(&data).map_err(|e| e.to_string())?;
        let mut bounds = vec![(t.bounds().lower(), t.bounds().upper())];
        let statistic = |sample: ResampledIndices<'_>| {
            let idx = sample.indices();
            Ok(idx.iter().map(|&i| data[i]).sum::<f64>() / idx.len() as f64)
        };
        // 3 つの方法が同じ再標本を使うように、生成器の状態を写してから使う。
        let start = boot.clone();
        for (plan, workspace, output) in plans.iter_mut() {
            let mut generator = start.clone();
            let report = plan
                .evaluate_into(
                    ResamplingProblem::Indexed(&statistic),
                    ReplicateOptions::sequential(&mut generator, policy),
                    output,
                    workspace,
                    ExecutionContext::sequential_native(),
                )
                .map_err(|e| e.to_string())?;
            let Some(ResamplingInference::Bootstrap(interval)) = report.inference() else {
                return Err(format!("{:?} で止まった", report.termination()));
            };
            bounds.push((interval.bounds.lower(), interval.bounds.upper()));
            boot = generator;
        }
        for (j, &(low, high)) in bounds.iter().enumerate() {
            let cell = &mut counts[k][j];
            cell[0] += f64::from(u8::from(low <= theta && theta <= high));
            cell[1] += f64::from(u8::from(theta < low));
            cell[2] += f64::from(u8::from(theta > high));
            cell[3] += high - low;
        }
    }
}
export!(sizes, sizes);
export!(theta, theta);
export!(replicates, replicates as usize);
export!(counts, counts);
```

## 被覆率の読み方

表示のセルは前のセルの数え上げから被覆率とその 95% Wilson 区間を計算し、標本の大きさに対して描く。
4 つの方法の点は重ならないように横に少しずらしてある。
棒グラフは選んだ標本の大きさでの左右の外れ率を名目の $\alpha/2=0.025$ と比べる。
表は被覆率、Wilson 区間、左右の外れ率、平均の幅である。
$R$ 回の判定は独立なベルヌーイ試行なので、被覆率の推定値 $\hat c$ の標準誤差は $\sqrt{\hat c(1-\hat c)/R}$ で、$R=200$、$\hat c=0.9$ では約 0.021 である。
名目の 0.95 が Wilson 区間の外にあれば、その区間の被覆率は名目と異なると判断できる。

```rust
//| id: stats-bootstrap-coverage-display
//| ref: stats-bootstrap-coverage-display
//| title: 被覆率を標本の大きさに対して描き、左右の外れ率を比べる
//| run: reactive
//| crates: []
//| dependsOn:
//|   run: stats-bootstrap-coverage-calc
//| inputs:
//|   table_size: {"type":"select","label":"表と棒グラフの標本の大きさ n","options":["10","20","40","80"],"value":"20"}
//| cases:
//|   - {"id":"small-sample","label":"n = 10","description":"右に外れる率が名目の数倍になる。","inputs":{"table_size":"10"}}
//|   - {"id":"large-sample","label":"n = 80","description":"外れ率の左右の差が縮む。","inputs":{"table_size":"80"}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"coverage","path":"/rows/0/0","equals":"Student の t"}
//|       - {"artifact":"coverage","path":"/rows/0/1","approx":{"value":0.875,"atol":1e-9}}
//|       - {"artifact":"coverage","path":"/rows/2/5","approx":{"value":0.17,"atol":1e-9}}
//|   - case: small-sample
//|     expect:
//|       - {"artifact":"coverage","path":"/rows/3/1","approx":{"value":0.785,"atol":1e-9}}
let sizes: Vec<usize> =
    serde_json::from_value(run["sizes"].clone()).map_err(|e| e.to_string())?;
let counts: Vec<[[f64; 4]; 4]> =
    serde_json::from_value(run["counts"].clone()).map_err(|e| e.to_string())?;
let r = run["replicates"].as_f64().ok_or("反復数がない")?;
let chosen: usize = table_size.parse().map_err(|_| "標本の大きさを読めない")?;
let k = sizes
    .iter()
    .position(|&n| n == chosen)
    .ok_or("標本の大きさが格子にない")?;
let names = ["Student の t", "percentile", "basic", "BCa"];
// Wilson のスコア区間（95%）
let wilson = |p: f64| {
    let z = 1.96_f64;
    let center = (p + z * z / (2.0 * r)) / (1.0 + z * z / r);
    let radius = z * (p * (1.0 - p) / r + z * z / (4.0 * r * r)).sqrt() / (1.0 + z * z / r);
    (center - radius, center + radius)
};
let mut series = Vec::new();
for (j, name) in names.iter().enumerate() {
    let points: Vec<[f64; 4]> = sizes
        .iter()
        .enumerate()
        .map(|(i, &n)| {
            let c = counts[i][j][0] / r;
            let (low, high) = wilson(c);
            [n as f64 * (0.955 + 0.03 * j as f64), c, low, high]
        })
        .collect();
    series.push(serde_json::json!({ "name": name, "points": points }));
}
emit_chart!(serde_json::json!({
    "kind": "errorbar",
    "xLabel": "標本の大きさ n [個]",
    "yLabel": "被覆率 [-]",
    "xType": "log",
    "xMin": 8.0,
    "xMax": 100.0,
    "yMin": 0.6,
    "yMax": 1.0,
    "tooltip": true,
    "series": series,
    "annotations": [{ "kind": "line", "axis": "y", "value": 0.95, "label": "名目 0.95" }]
}));

let rows: Vec<_> = names
    .iter()
    .enumerate()
    .map(|(j, &name)| {
        let cell = counts[k][j];
        let c = cell[0] / r;
        let (low, high) = wilson(c);
        (name, c, low, high, cell[1] / r, cell[2] / r, cell[3] / r)
    })
    .collect();
let fixed3 = serde_json::json!({ "fractionDigits": 3 });
let columns = serde_json::json!([
    { "key": "0", "label": "区間" },
    { "key": "1", "label": "被覆率 [-]", "type": "number", "format": fixed3 },
    { "key": "2", "label": "Wilson 区間の下端 [-]", "type": "number", "format": fixed3 },
    { "key": "3", "label": "Wilson 区間の上端 [-]", "type": "number", "format": fixed3 },
    { "key": "4", "label": "左に外れた率 θ < L [-]", "type": "number", "format": fixed3 },

]);

    "categories": names,
    "tooltip": true,

        { "name": "右に外れる（θ > U）", "values": right }

```

既定の入力（$\sigma=1$、$B=399$、$R=200$、シード 5）の結果を、標本の大きさが小さい順に読む。
$n=10$ の被覆率は t が 0.815、percentile が 0.765、basic が 0.755、BCa が 0.785 で、どれも Wilson 区間の上端（0.82〜0.86）が名目の 0.95 に届かない。
外れのほとんどは $\theta$ が上端より大きい側（右）に起き、右に外れる率は 0.17〜0.24 と名目の 0.025 の 7〜9 倍である。
標本平均と標本分散が一緒に小さくなる標本で、区間全体が $\theta$ の左に収まるからである。
左に外れる率は 0〜0.045 で、名目の 0.025 の前後にとどまる。
$n$ を増やすと被覆率は上がるが、$n=80$ でも 0.875〜0.91 にとどまり、Wilson 区間（上端 0.91〜0.94）は 0.95 を含まない。
$O(n^{-1})$ という収束の次数は漸近的な主張であり、歪度 6 の分布では係数が大きいことを示している。

方法の間では、どの $n$ でも basic が最も低い。
basic は右に長い裾を左に向けて反転するので、右に外れる率が最も大きい（$n=80$ で 0.12）。
BCa は加速で上端を右へ伸ばし、右に外れる率を 4 つの中で最も小さくする（$n=80$ で 0.07）が、それでも名目の 0.025 には届かない。
t 区間は $n=10$ では bootstrap の 3 つより高く、$n\ge40$ では percentile・BCa と同じ程度になる。
BCa の片側の誤差が $O(n^{-1})$ であることは、有限の $n$ で外れ率が名目に一致することを意味しない。
4 つの区間は同じ標本を使っているので、Wilson 区間が重なっていても、方法の間の差は独立な実験どうしの差より確かである。

$\sigma=0.5$（歪度 1.75）では、$n=20$ で被覆率が 0.915〜0.935 に上がり、$n=40$ の t 区間は 0.955 と名目に達する。
それでも右に外れる率は左より大きく、歪みの向きの偏りは残る。
$\sigma=1.5$（歪度 33.5）では、$n=80$ でも 0.77〜0.85 にとどまる。
裾が極端に長いと、まれな大きな観測がその標本に入るかどうかで平均が決まり、どの区間もそれを補えない。
このような分布では、平均の代わりに中央値や分位点を推定するか、対数をとった尺度で区間を作って変換し直すことを検討する。

時系列のように観測が独立でない場合は、上のどの区間も前提を満たさない。
`BootstrapDesign::MovingBlock` か `CircularBlock` で連続したブロックを再抽出すると依存を保てるが、BCa は使えず、ブロックの長さの選択が結果を左右する。
独立性を仮定した区間が自己相関のある列で被覆率を失う様子は[信頼区間の被覆率を反復実験で確かめる](../confidence-coverage/)で確かめられる。

## まとめ

対数正規分布の平均では、t 区間と 3 種類の bootstrap 区間のどれも、小さい標本で名目の 95% を下回り、外れのほとんどは真の平均が上端を超える側で起きる。
`ResamplingPlan` と `BootstrapMethod` で同じ再標本から percentile・basic・BCa の区間を作り、`BootstrapInterval` の `standard_error`・`bias`・`bias_correction`・`acceleration` で再標本の分布の形を確かめられる。
多数のデータで同じ Plan を使うときは、`workspace` で作った作業領域を `evaluate_into` に渡して確保を避ける。
被覆率の比較は二項分布の信頼区間と一緒に行い、左右の外れ率を分けて読むと、区間がどちらの向きに偏っているかが分かる。
BCa の漸近的な利点は強く歪んだ分布の小さい標本では限られるので、標本の大きさと歪みに応じて反復実験で確かめる。
