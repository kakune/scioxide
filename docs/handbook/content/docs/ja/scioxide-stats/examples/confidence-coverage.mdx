平均の信頼区間 $\bar X \pm t\,S/\sqrt n$ は、観測が独立であることを仮定している。
センサーの連続測定やシミュレーションの出力のように隣り合う観測が似た値を取る列では、この仮定が破れる。
このページは自己相関を持つ列に独立性を仮定した区間を使うと、区間が真の平均を含む割合（**被覆率**）が名目の信頼度からどれだけ下がるかを、scioxide-random の乱数による反復実験で測り、解析的な予測と比べる。
さらに、推定した自己相関で標準誤差を補正した区間を作り、被覆率がどこまで戻るかを確かめる。

## 頻度論的な信頼区間の意味

区間 $[L(X), U(X)]$ の信頼度 $1-\alpha$ は

$$
P_\mu\bigl(L(X) \le \mu \le U(X)\bigr) = 1 - \alpha
$$

を意味する。
確率変数なのはデータから作る端点で、母平均 $\mu$ は未知の定数である。
観測した後の一つの区間について「$\mu$ がこの中にある確率が 95%」と読むのは誤りで、同じ手続きを繰り返したときに区間が $\mu$ を含む割合が 95% という意味である。
この割合は反復実験で直接測れる。

独立な正規標本では、$T = (\bar X - \mu)/(S/\sqrt n)$ が自由度 $n-1$ の Student の t 分布に従うので、$\bar X \pm t_{1-\alpha/2,\,n-1}\,S/\sqrt n$ の被覆率は名目の $1-\alpha$ に正確に一致する（Casella–Berger §9.2）。
`MomentsSnapshot::confidence_interval_of_mean` は信頼度 0.95 のこの区間を返し、`confidence_interval_of_mean_with_options` は信頼度、臨界値の分布（`MeanIntervalMethod`）、t 分布の分位点を求める不完全ベータ関数の逆関数の設定を受け取る。
`MeanIntervalMethod::StudentT` は自由度 $n-1$ の t 分布、`NormalAsymptotic` は標準正規分布の臨界値を使う。
標本の分散から区間を作るので、既知の分散を前提にする `NormalKnownVariance` を渡すと `InvalidInput` になり、観測が 2 個未満なら `Ok(None)` を返す。
返す `MeanConfidenceInterval` は、端点 `bounds`、推定値 `estimate`、標準誤差 `standard_error`、自由度 `degrees_of_freedom` と、被覆率が名目どおりになるための仮定 `assumptions`（ここでは `MeanIntervalAssumptions::IndependentNormal`）を持つ。
仮定は記録されるだけで、データに対して検定されるわけではない。

## AR(1) 列の分散膨張

定常な 1 次の自己回帰過程

$$
X_t - \mu = \rho\,(X_{t-1} - \mu) + \sigma\sqrt{1-\rho^2}\, Z_t, \qquad Z_t \sim \mathcal N(0, 1)\ \text{独立}, \quad |\rho| < 1
$$

は、周辺分散が $\sigma^2$、遅れ $k$ の自己共分散が $\gamma_k = \sigma^2 \rho^{|k|}$ である（Brockwell–Davis §3.1）。
初期値 $X_1$ を周辺分布 $\mathcal N(\mu, \sigma^2)$ から引けば、列は最初から定常になる。
標本平均の分散はすべての組の共分散の和なので

$$
\mathrm{Var}(\bar X) = \frac{\sigma^2}{n}\,g_n(\rho), \qquad
g_n(\rho) = 1 + 2\sum_{k=1}^{n-1}\Bigl(1 - \frac{k}{n}\Bigr)\rho^k \;\xrightarrow{n\to\infty}\; \frac{1+\rho}{1-\rho}
$$

となる。
$g_n$ を**分散膨張係数**、$n/g_n$ を**有効標本数**と呼ぶ。
$\rho = 0.8$ では $g_\infty = 9$ で、標準誤差は独立の場合の 3 倍、有効標本数は名目の約 1/9 になる。

| $\rho$ | $g_\infty$ | $n_{\mathrm{eff}}/n$ | 標準誤差の比 $\sqrt{g_\infty}$ |
|---|---|---|---|
| 0.0 | 1.00 | 100% | 1.00 |
| 0.3 | 1.86 | 53.8% | 1.36 |
| 0.5 | 3.00 | 33.3% | 1.73 |
| 0.8 | 9.00 | 11.1% | 3.00 |
| 0.9 | 19.00 | 5.26% | 4.36 |

偏差平方和の期待値は $E\bigl[\sum_t (X_t - \bar X)^2\bigr] = n\sigma^2 - n\,\mathrm{Var}(\bar X)$ なので、標本分散も

$$
E[S^2] = \sigma^2\,\frac{n - g_n}{n - 1}
$$

と小さくなる。
独立性を仮定した区間は、標準誤差の式 $S/\sqrt n$ が $g_n$ を落とすことと、$S^2$ 自体が $\sigma^2$ より小さいことの二重の理由で狭くなる。
$S^2$ をその期待値で置き換え、$\bar X$ を正規分布とみなすと、独立性を仮定した区間の被覆率は

$$
c_{\mathrm{pred}} = P\!\left(|Z| \le t_{1-\alpha/2,\,n-1}\sqrt{\frac{n - g_n}{(n-1)\,g_n}}\right) = \operatorname{erf}\!\left(\frac{t_{1-\alpha/2,\,n-1}}{\sqrt 2}\sqrt{\frac{n - g_n}{(n-1)\,g_n}}\right)
$$

と予測できる。
$S^2$ のばらつきを無視した近似なので、$\rho = 0$ でも名目値ではなく正規近似の値（$n = 64$、95% で 0.9545）になる。

## 推定した自己相関による補正

$\rho$ が分かれば、$\sigma^2$ を $S^2 (n-1)/(n - g_n)$ で推定し、平均の分散を

$$
\widehat{\mathrm{Var}}(\bar X) = \frac{S^2}{n}\cdot\frac{(n-1)\,g_n(\hat\rho)}{n - g_n(\hat\rho)}
$$

で補正できる。
実際には $\rho$ は未知なので、隣り合う組 $(X_{t-1}, X_t)$ の相関係数 $\hat\rho$ で置き換える。
このページはこの組を `OnlineCovariance` で逐次集計し、`correlation` を $\hat\rho$ に使う。
$\hat\rho$ は $n$ が小さいと 0 の側に偏り（$\rho = 0.8$、$n = 64$ で平均 0.75 程度）、そのぶん補正が足りなくなる。
区間の臨界値には、有効標本数から決めた自由度 $\nu = \lfloor \max(n/g_n(\hat\rho) - 1,\ 1) \rfloor$ の t 分布を使う。
整数に切り捨てるのは、自由度ごとに臨界値を一度だけ求めて使い回すためで、臨界値は少し大きく（区間は少し広く）なる。
この自由度は経験的な選び方で、補正した区間の被覆率は近似である。

補正した標準誤差から区間を作るには、`MeanIntervalPlan` を使う。
`MeanIntervalPlan::new(信頼度, MeanIntervalMethod::StudentT, Some(ν), 設定)` が臨界値 $c$ を 1 回だけ求め、`interval(推定値, 標準誤差)` が $\bar X \pm c\,\mathrm{se}$ を返す。
`confidence_interval_of_mean_with_options` は呼ぶたびに t 分布の分位点を不完全ベータ関数の逆関数で求めるので、同じ自由度の区間を何千回も作る反復実験では、Plan を作って使い回すほうが速い。
自由度 $n-1$ の Plan に $\bar X$ と `standard_error_of_sample_mean` を渡すと、`confidence_interval_of_mean_with_options` の `StudentT` と同じ区間になる。
`interval_scaled` は標準誤差を `scioxide_core::Scaled`（仮数と 2 進の指数を別に持つ拡張範囲の値）で受け取り、$c$ を掛ける前に `f64` へ丸めない。
`MomentsSnapshot::scaled_variance_of_sample_mean` は $S^2/n$ を同じ `Scaled` で返すので、補正係数を掛けて平方根を取るまで、`f64` で下位にあふれる（または上位にあふれる）分散も失わない。
この例の値は `f64` の範囲に十分収まるので、丸めない経路は結果を変えないが、平均の分散を別の係数で補正するときに使う経路を示す。
`variance_of_sample_mean` と `standard_error_of_sample_mean` は $S^2/n$ と $S/\sqrt n$ を `f64` に丸めて返し、観測が 2 個未満ならどちらも `None` になる。
`interval_scaled` は推定値が非有限なら `NonFinite`、標準誤差が負なら `InvalidInput` を返す。

## 被覆率の反復実験

次のセルは平均 $\mu = 50$、周辺標準偏差 $\sigma = 4$ の AR(1) 列を $R$ 本作り、各列に独立性を仮定した t 区間と、$\hat\rho$ で補正した区間を作る。
自由度 1 から $n-1$ までの `MeanIntervalPlan` を先に作り、独立性を仮定した区間には自由度 $n-1$ の Plan、補正した区間には自由度 $\nu$ の Plan を使う。
反復の数が多いので、セルはボタンで実行する。
区間が $\mu$ を含んだ割合 $\hat c$ を、自己相関 $\rho$ を 0 から $\rho_{\max}$ まで 13 点で動かして描く。
各 $\rho$ は同じシードから始めるので、$\rho$ の違いだけを比べられる（共通乱数）。

被覆率の推定値 $\hat c = k/R$ は、成功確率 $c$ の二項試行 $R$ 回の成功割合である。
帯は `binomial_confidence_limits` が返す Clopper–Pearson の 95% 区間で、この区間が名目の信頼度を含まなければ、被覆率が名目値と違うと判断できる。
破線は分散膨張係数による予測 $c_{\mathrm{pred}}$、横線は名目の信頼度である。
表の上段は 4 点おきの被覆率と区間、下段は解析的な $g_n$ と有効標本数、$\hat\rho$ の平均、平均の区間幅である。

//|       - {"artifact":"coverage","path":"/rows/0/2","approx":{"value":0.8984375,"atol":1e-06}}
use scioxide_core::{RealScalar, Scaled};
use scioxide_random::{Distribution, Normal, SeedableRng, SplitMix64};
use scioxide_stats::{
    ConfidenceProbability, MeanIntervalMethod, MeanIntervalPlan, MomentOrder, OnlineCovariance,
    OnlineMoments, binomial_confidence_limits,
};

let (n, reps) = (
    coverage_sample_count as usize,
    coverage_replications as usize,
);
let count = n as f64;
let level = ConfidenceProbability::new(nominal_confidence).map_err(|e| e.to_string())?;
let normal = Normal::new(0.0_f64, 1.0).map_err(|e| e.to_string())?;
let (mu, sigma) = (50.0_f64, 4.0_f64);
// 有限長の分散膨張係数 g_n(ρ) = 1 + 2 Σ_{k=1}^{n−1} (1 − k/n) ρᵏ。
let inflation = |rho: f64| {
    let weights = (1..n).map(|k| (1.0 - k as f64 / count) * RealScalar::powi(rho, k as i32));
    1.0 + 2.0 * weights.sum::<f64>()
};
// 自由度 1..n−1 の t 分布の臨界値を一度だけ求める。plans[k − 1] が自由度 k。
let plans = (1..n)
    .map(|k| {
        let degrees = Some(k as f64);
        MeanIntervalPlan::new(
            level,
            MeanIntervalMethod::StudentT,
            degrees,
            Default::default(),
        )
    })
    .collect::<Result<Vec<_>, _>>()
    .map_err(|e| e.to_string())?;
// 1 本の列: 独立性を仮定した区間と、ρ̂ で補正した区間が μ を含むか、その幅と ρ̂。
let replicate = |rho: f64, rng: &mut SplitMix64| -> Result<[f64; 5], String> {
    let mut state = normal.sample(rng).map_err(|e| e.to_string())?;
    let mut moments = OnlineMoments::new(MomentOrder::Second);
    let mut lagged = OnlineCovariance::new(MomentOrder::Second);
    let mut previous = None;
    for i in 0..n {
        if i > 0 {
            let shock = normal.sample(rng).map_err(|e| e.to_string())?;
            state = rho * state + RealScalar::sqrt(1.0 - rho * rho) * shock;
        }
        let x = mu + sigma * state;
        moments.observe(x).map_err(|e| e.to_string())?;
        if let Some(last) = previous {
            lagged.observe(last, x).map_err(|e| e.to_string())?;
        }
        previous = Some(x);
    }
    // 独立性を仮定した区間: 自由度 n − 1 の t 区間 x̄ ± t s/√n。
    let snapshot = moments.snapshot();
    let mean = snapshot.mean().map_err(|e| e.to_string())?;
    let mean = mean.ok_or("平均が未定義")?;
    let se = snapshot
        .standard_error_of_sample_mean()
        .map_err(|e| e.to_string())?;
    let naive = plans[n - 2]
        .interval(mean, se.ok_or("標準誤差が未定義")?)
        .map_err(|e| e.to_string())?;
    // 補正: s²/n に (n − 1) g / (n − g) を掛け、自由度 ⌊n/g − 1⌋ の t 区間にする。
    let correlation = lagged.snapshot().correlation().map_err(|e| e.to_string())?;
    let rho_hat = RealScalar::clamp(correlation.unwrap_or(0.0), -0.99, 0.99);
    let g = inflation(rho_hat);
    let factor =
        Scaled::from_value((count - 1.0) * g / (count - g)).map_err(|e| e.to_string())?;
    let variance = snapshot
        .scaled_variance_of_sample_mean()
        .map_err(|e| e.to_string())?;
    let variance = variance.ok_or("平均の分散が未定義")?;
    let error = variance
        .mul(factor)
        .and_then(|v| v.sqrt())
        .map_err(|e| e.to_string())?;
    let degrees = RealScalar::floor(RealScalar::max(count / g - 1.0, 1.0)) as usize;
    let corrected = plans[degrees.min(n - 1) - 1]
        .interval_scaled(mean, error)
        .map_err(|e| e.to_string())?;
    let covers = |bounds: scioxide_core::Interval<f64>| f64::from(u8::from(bounds.contains(mu)));
    let width = |bounds: scioxide_core::Interval<f64>| bounds.width().map_err(|e| e.to_string());
    Ok([
        covers(naive.bounds()),
        covers(corrected.bounds()),
        width(naive.bounds())?,
        width(corrected.bounds())?,
        rho_hat,
    ])
};
// 二項の Clopper–Pearson 95% 区間 [下限, 上限]。
let clopper_pearson = |hits: f64| -> Result<(f64, f64), String> {
    let limits =
        binomial_confidence_limits::<f64>(hits as usize, reps).map_err(|e| e.to_string())?;
    let (lower, upper) = limits.set().bounds().ok_or("区間が空")?;
    Ok((lower.unwrap_or(0.0), upper.unwrap_or(1.0)))
};
let t = level
    .student_t_critical_value(count - 1.0)
    .map_err(|e| e.to_string())?;
let (mut naive_band, mut corrected_band, mut predicted) = (Vec::new(), Vec::new(), Vec::new());
let (mut coverage_rows, mut inflation_rows) = (Vec::new(), Vec::new());
for step in 0..=12 {
    let rho = maximum_autocorrelation * f64::from(step) / 12.0;
    let mut rng = SplitMix64::from_seed(seed as u64);
    let mut totals = [0.0_f64; 5];
    for _ in 0..reps {
        let result = replicate(rho, &mut rng)?;
        for (total, value) in totals.iter_mut().zip(result) {
            *total += value;
        }
    }
    let [
        naive_hits,
        corrected_hits,
        naive_width,
        corrected_width,
        rho_sum,
    ] = totals;
    let (naive_rate, corrected_rate) = (naive_hits / reps as f64, corrected_hits / reps as f64);
    let (naive_low, naive_high) = clopper_pearson(naive_hits)?;
    let (corrected_low, corrected_high) = clopper_pearson(corrected_hits)?;
    // 予測: S² をその期待値で置き換えた正規近似 erf(t √((n − g)/((n − 1) g)) / √2)。
    let g = inflation(rho);
    let scale = RealScalar::sqrt((count - g) / ((count - 1.0) * g));
    let prediction =
        scioxide_special::erf(t * scale / std::f64::consts::SQRT_2).map_err(|e| e.to_string())?;
    naive_band.push([rho, naive_rate, naive_low, naive_high]);
    corrected_band.push([rho, corrected_rate, corrected_low, corrected_high]);
    predicted.push([rho, prediction]);
    if step % 4 == 0 {
        coverage_rows.push((
            rho,
            prediction,
            naive_rate,

既定の $n = 64$、$R = 384$、名目 0.95、シード 7 では、$\rho = 0$ の独立仮定の被覆率は 0.958 で、Clopper–Pearson の 95% 区間 $[0.933, 0.976]$ は名目の 0.95 を含む。
独立な正規標本では t 区間が正確であることと、Monte Carlo の誤差の範囲で合っている。
シードを 1 と 20 に変えると 0.945 と 0.966、$R = 768$ では 0.947 $[0.928, 0.961]$ になり、どの区間も 0.95 を含む。

$\rho$ を上げると、独立仮定の被覆率は 0.872（$\rho = 0.267$）、0.737（0.533）、0.490（0.8）と下がる。
予測 $c_{\mathrm{pred}}$ は 0.871、0.727、0.484 で、どれも測った被覆率の区間 $[0.835, 0.904]$、$[0.690, 0.780]$、$[0.439, 0.541]$ に入る。
被覆率が下がっても、独立仮定の平均の区間幅は 2.00 から 1.87 へとむしろ狭くなる。
$E[S^2]$ が $\sigma^2 (n - g_n)/(n-1)$ に縮むからで、区間の幅だけを見ても依存は分からない。

$\hat\rho$ で補正した区間の被覆率は 0.938、0.930、0.922、0.919 と名目値の近くに戻り、区間幅は $\rho = 0.8$ で 6.88 に広がる。
ただし $\rho \ge 0.533$ では Clopper–Pearson の区間の上限（0.947、0.944）が 0.95 に届かず、補正は足りない。
$\hat\rho$ の平均は $\rho = 0.8$ で 0.749 と 0 の側に偏り、$g_n(\hat\rho)$ が真の $g_n = 8.375$ より小さくなるからである。

$n = 16$ では、$\rho = 0.8$ の $\hat\rho$ の平均が 0.568 まで偏り、補正した被覆率も 0.823 にとどまる。
$\rho = 0$ でも $\hat\rho$ の平均が $-0.070$ になって区間を狭めるので、補正した被覆率は 0.911 $[0.879, 0.938]$ と名目値を下回る。
独立仮定の被覆率 0.432 $[0.382, 0.484]$ は予測 0.490 を含まず、$S^2$ のばらつきを無視した予測は短い列で粗くなる。
$n = 128$ では、独立仮定の被覆率が $\rho = 0.8$ で 0.471 と、標本数を増やしても戻らないのに対し、補正した被覆率は 0.935 $[0.905, 0.957]$ まで戻る。
$\rho_{\max} = 0.9$ では独立仮定の被覆率が 0.323 まで下がり、有効標本数は 64 個のうち 4.0 個分しかない。
名目の信頼度を 0.9 にすると、$\rho = 0$ の被覆率は 0.898 $[0.864, 0.927]$ になり、曲線全体が下がる。

## 時系列の平均の区間を作る方法

自己相関を無視した区間の狭さは、反復数 $R$ や標本数 $n$ を増やしても解消しない。
相関の長さに比べて観測期間が短ければ、標本を細かく取っても有効標本数はほとんど増えない。
依存を考慮するには、上の補正のほかに次の方法がある。

- ブロック bootstrap は相関の長さを超える長さのブロックごとに再抽出し、依存を保ったまま標本分布を近似する。
  scioxide-stats では `ResamplingPlan` に `BootstrapDesign::MovingBlock` か `CircularBlock` を指定する（[リサンプリング・検定](../../algorithms/resampling/)）。
  ブロックの長さの選び方が結果を左右する。
- 自己相関関数を推定して $g_n$ を求める方法は、`time_series_summary` で標本の自己相関関数を求め、AR モデルなどから $g_n$ を推定して標準誤差を補正する。
  上のセルの補正はその最も簡単な形で、補正に使う $\hat\rho$ 自体も推定誤差と偏りを持つ。
- 自己共分散の重み付き和で長期分散 $\sum_k \gamma_k$ を推定する Newey–West などの HAC 推定量は、scioxide-stats では提供しない。
  必要なら、`time_series_summary` の自己共分散に Bartlett の重みを掛けて足し、上のセルと同じように `MeanIntervalPlan::interval_scaled` へ渡す。

## まとめ

独立な正規標本では、Student の t 区間の被覆率は名目の信頼度に Monte Carlo 誤差の範囲で一致する。
正の自己相関があると、標準誤差の式が $g_n$ を落とすことと標本分散の偏りが重なって区間が狭くなり、被覆率は分散膨張係数による予測どおりに名目値を大きく下回る。
被覆率の推定値自体も $R$ 回の二項試行の推定なので、Clopper–Pearson の区間が名目値を含むかで判断する。
推定した $\hat\rho$ で標準誤差を補正すると被覆率は名目値に近づくが、$\hat\rho$ の偏りのため強い自己相関と短い列では届かない。
時系列の平均には補正した標準誤差を `MeanIntervalPlan::interval_scaled` に渡すか、依存を保つブロック bootstrap を使う。
