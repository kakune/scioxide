測定器の分解能で丸めた値には同じ値（同値）が現れ、公差のウインドウで区切ったヒストグラムにはウインドウの外の値が現れる。
どちらも境界の扱いを決めないと、数え方が一意に定まらない。
このページは部品の長さの公称値からのずれ（単位 mm）を例に、scioxide-stats の経験分布関数とビン集計が境界上の観測と範囲外の観測をどう数えるかを、手で数えた値と照合する。

## 同値を含む標本の分布関数

$n$ 個の観測 $x_1, \dots, x_n$ の経験分布関数と生存関数は

$$
F_n(x) = \frac{\#\{i : x_i \le x\}}{n}, \qquad S_n(x) = \frac{\#\{i : x_i > x\}}{n}
$$

である。
$F_n$ は観測の値で跳ぶ右連続の階段関数で、同じ値の観測が $m$ 個あれば、その値で $m/n$ だけ跳ぶ。
分解能 1 mm で読んだずれ $[1, 2, 2, 4]$ mm には値 2 の同値があり、$x = 2$ では値 2 の観測を両方含むので

$$
F_4(2) = \frac{3}{4}, \qquad S_4(2) = \frac{1}{4}
$$

になる。
$F_n(x) + S_n(x) = 1$ はどの $x$ でも成り立つ。
`EmpiricalDistribution::survival` は $1 - F_n$ を計算せずに $x$ より大きい観測を直接数える。
小さな裾の確率で 1 からの引き算による桁落ちを避けるためで、同値の扱いは `cdf` と同じ規約に従う。
整列した標本に対する照会は二分探索で $O(\log n)$ である。
照会点が NaN なら `InvalidInput` を返し、$\pm\infty$ には 0 か 1 を返す。

分位点の定義によって、同値の扱いが変わる。
型 1（`NearestRank`）の分位点は順位 $\lceil np \rceil$ の観測で、$F_n$ の左連続な逆関数 $\inf\{x : F_n(x) \ge p\}$ に当たる。
型 7（`Linear`）は 0 始まりの位置 $h = (n-1)p$ の両側の順序統計量を線形補間する。
$p = 0.75$ では、型 1 が順位 3 の観測 2 mm を返し、型 7 は位置 $h = 2.25$ で $x_{(2)} = 2$ と $x_{(3)} = 4$（0 始まり）を補間して 2.5 mm を返す。

`EmpiricalDistribution::estimated_cdf` は、選んだ分位点の定義を逆にした CDF の推定を返す。
型 7 では、$x$ 以下の観測の数を $k$、$x_{(k)} \le x \le x_{(k+1)}$（1 始まり）として $h = k + (x - x_{(k)})/(x_{(k+1)} - x_{(k)})$ と置き、$(h-1)/(n-1)$ を返す。
観測の間を線形に結ぶので、$F_n$ の階段と違って連続である。
$x = 2$ では $k = 3$、$h = 3$ なので $2/3$ になり、型 7 の分位点関数で $Q_7(2/3) = 2$ に戻る。

多数の照会点や、独立な複数の標本をまとめて評価するときは、関数 `cdf` に `BatchView` と照会点の列と `CdfMethod` を渡す。
`CdfMethod::Empirical` は $F_n$、`Survival` は $S_n$、`Estimated(rule)` は `estimated_cdf` と同じ値を返す。
各バッチを $O(n \log n)$ で整列し、照会点を二分探索で答える。
戻り値はバッチごとに照会点を並べたベクトルで、バッチ $b$、照会点 $j$ の値は位置 $b m + j$（$m$ は照会点の数）にある。

次のセルは照会点 $x$ を動かし、整列済みの `EmpiricalDistribution` と一括の `cdf` の両方で $F_4(x)$、$S_4(x)$、型 7 の CDF の推定を求め、観測を数えた値と比べる。
図は一括の `cdf` で 0 mm から 5 mm までの 101 点を評価した $F_4$、$S_4$、型 7 の推定である。
$p = 0.75$ の型 1 と型 7 の分位点も、順位と位置から手で求めた値と並べる。

```rust
//| id: stats-cdf-tied-support
//| ref: stats-cdf-tied-support
//| title: 同値標本を含む CDF と生存確率を数え上げる
//| run: reactive
//| crates: [scioxide-core, scioxide-stats]
//| inputs:
//|   query: {"type":"range","label":"照会点 x [mm]","description":"同値の 2 mm や観測のない 3 mm を含めて動かす。","min":0,"max":5,"step":0.5,"value":2}
//| cases:
//|   - {"id":"gap","label":"x = 3 mm","description":"観測のない値では F が平らで、型 7 の推定だけが変わる。","inputs":{"query":3}}
//|   - {"id":"below","label":"x = 0 mm","description":"最小値より下では F = 0、S = 1。","inputs":{"query":0}}
//|   - {"id":"above","label":"x = 5 mm","description":"最大値より上では F = 1、S = 0。","inputs":{"query":5}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"probabilities","path":"/rows/0/1","equals":0.75}
//|       - {"artifact":"probabilities","path":"/rows/1/2","equals":0.25}
//|       - {"artifact":"probabilities","path":"/rows/2/3","equals":1}
//|       - {"artifact":"probabilities","path":"/rows/0/4","approx":{"value":0.6666666666666666,"rtol":1e-12}}
//|       - {"artifact":"quantiles","path":"/rows/0/1","equals":2}
//|       - {"artifact":"quantiles","path":"/rows/1/1","approx":{"value":2.5,"rtol":1e-12}}
//|   - case: gap
//|     expect:
//|       - {"artifact":"probabilities","path":"/rows/0/1","equals":0.75}
//|       - {"artifact":"probabilities","path":"/rows/1/4","approx":{"value":0.8333333333333334,"rtol":1e-12}}
//|   - case: below
//|     expect:
//|       - {"artifact":"probabilities","path":"/rows/0/1","equals":0}
//|       - {"artifact":"probabilities","path":"/rows/0/2","equals":1}
//|   - case: above
//|     expect:
//|       - {"artifact":"probabilities","path":"/rows/1/1","equals":1}
//|       - {"artifact":"probabilities","path":"/rows/1/2","equals":0}
use scioxide_core::{RealScalar, StridedLayout};
use scioxide_stats::{
    Axis, BatchView, CdfMethod, EmpiricalDistribution, QuantileMethod, QuantileProbability,
    QuantileRule, Unweighted, cdf,
};

// 分解能 1 mm で読んだずれ [mm]。値 2 が二つある（整列済み）。
let sample = [1.0_f64, 2.0, 2.0, 4.0];
let n = sample.len() as f64;
let law = EmpiricalDistribution::new(&sample, Unweighted).map_err(|e| e.to_string())?;
let type7 = QuantileRule::new(QuantileMethod::Linear);
let cumulative = law.cdf(query).map_err(|e| e.to_string())?;
let survival = law.survival(query).map_err(|e| e.to_string())?;
let estimated = law.estimated_cdf(query, type7).map_err(|e| e.to_string())?;
// 同じ標本を一括の cdf に渡す。照会点は x と、図の 101 点。
let (shape, strides) = ([4_usize], [1_usize]);
let layout = StridedLayout::new(&shape, &strides).map_err(|e| e.to_string())?;
let view = BatchView::new(&sample, layout, Axis::Index(0)).map_err(|e| e.to_string())?;
let grid: Vec<f64> = (0..=100).map(|i| 0.05 * f64::from(i)).collect();
let batch = |points: &[f64], method| cdf(view, points, method).map_err(|e| e.to_string());
let batch_cdf = batch(&[query], CdfMethod::Empirical)?[0];
let batch_survival = batch(&[query], CdfMethod::Survival)?[0];
let batch_estimated = batch(&[query], CdfMethod::Estimated(type7))?[0];
// 独立な検算: x 以下と x より大きい観測を数える。
let below = sample.iter().filter(|&&v| v <= query).count() as f64 / n;
let above = sample.iter().filter(|&&v| v > query).count() as f64 / n;
let curve = |values: Vec<f64>| -> Vec<[f64; 2]> {
    grid.iter().zip(values).map(|(&x, y)| [x, y]).collect()
};
let empirical_curve = curve(batch(&grid, CdfMethod::Empirical)?);
let survival_curve = curve(batch(&grid, CdfMethod::Survival)?);
let estimated_curve = curve(batch(&grid, CdfMethod::Estimated(type7))?);
let step = serde_json::json!({ "step": "end" });
emit_line_chart!(
    &vec![
        serde_json::json!({ "name": "F₄(x) = P(X ≤ x)", "points": empirical_curve, "style": step }),
        serde_json::json!({ "name": "S₄(x) = P(X > x)", "points": survival_curve, "style": step }),
        serde_json::json!({ "name": "型 7 の CDF の推定", "points": estimated_curve })
    ],
    options = &serde_json::json!({
        "xLabel": "公称値からのずれ x [mm]",
        "yLabel": "確率 [-]",
        "annotations": [{ "kind": "line", "axis": "x", "value": query, "label": "照会点 x" }]
    })
);
let fixed4 = serde_json::json!({ "fractionDigits": 4 });
let columns = serde_json::json!([
    { "key": "0", "label": "経路" },
    { "key": "1", "label": "F(x) [-]", "type": "number", "format": fixed4 },
    { "key": "2", "label": "S(x) [-]", "type": "number", "format": fixed4 },
    { "key": "3", "label": "F(x) + S(x) [-]", "type": "number", "format": fixed4 },
    { "key": "4", "label": "型 7 の推定 [-]", "type": "number", "format": fixed4, "nullText": "—" }
]);
let rows = vec![
    (
        "EmpiricalDistribution",
        cumulative,
        survival,
        cumulative + survival,
        Some(estimated),
    ),
    (
        "一括の cdf",
        batch_cdf,
        batch_survival,
        batch_cdf + batch_survival,
        Some(batch_estimated),
    ),
    ("数え上げ", below, above, below + above, None),
];
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "probabilities" })
);
// p = 0.75 の分位点と、順位・位置からの手計算。
let p = QuantileProbability::new(0.75).map_err(|e| e.to_string())?;
let q1 = law.quantile(p, QuantileRule::new(QuantileMethod::NearestRank));
let q1 = q1.map_err(|e| e.to_string())?.value();
let q7 = law.quantile(p, type7).map_err(|e| e.to_string())?.value();
let rank = RealScalar::ceil(n * 0.75) as usize; // 型 1: 1 始まりの順位 ⌈np⌉
let h = (n - 1.0) * 0.75; // 型 7: 0 始まりの位置 (n − 1)p
let low = RealScalar::floor(h) as usize;
let by_hand7 = sample[low] + (h - low as f64) * (sample[low + 1] - sample[low]);
let fixed2 = serde_json::json!({ "fractionDigits": 2 });
let quantile_columns = serde_json::json!([
    { "key": "0", "label": "p = 0.75 の分位点" },
    { "key": "1", "label": "API の値 [mm]", "type": "number", "format": fixed2 },
    { "key": "2", "label": "手計算 [mm]", "type": "number", "format": fixed2 }
]);
let quantiles = vec![
    ("型 1（NearestRank）", q1, sample[rank - 1]),
    ("型 7（Linear）", q7, by_hand7),
];
emit_table_with_columns!(
    quantile_columns,
    quantiles,
    metadata = serde_json::json!({ "id": "quantiles" })
);
```

既定の $x = 2$ mm では、三つの経路がそろって $F = 0.75$、$S = 0.25$ を返し、和は 1 である。
同値の二つの観測はどちらも $F$ の側に入る。
型 7 の CDF の推定は `EmpiricalDistribution` と一括の `cdf` のどちらでも $2/3 \approx 0.6667$ である。

観測のない $x = 3$ mm では $F$ と $S$ は $x = 2$ と同じ値のまま平らで、型 7 の推定だけが $h = 3.5$ から $2.5/3 \approx 0.8333$ に上がる。
$x = 0$ では $F = 0$、$S = 1$、$x = 5$ では $F = 1$、$S = 0$ で、型 7 の推定も 0 と 1 になる。
図の階段は値 2 で 0.25 から 0.75 へ 2 段分跳び、同値の観測の数だけ跳びが大きくなることが分かる。

$p = 0.75$ の分位点は、型 1 が順位 $\lceil 4 \times 0.75 \rceil = 3$ の観測 2 mm、型 7 が位置 $3 \times 0.75 = 2.25$（0 始まり）の線形補間で 2.5 mm を返し、手計算と一致する。
型 1 は同値の値に留まり、型 7 は同値の上の観測 4 mm の側へ補間する。

## 範囲外と境界上の標本のビン集計

公差のウインドウ $[0, b]$ mm を 2 個の等しいビンに分け、7 個のずれ $[-0.25, 0, 0.25, 0.5, 0.75, 1.0, 1.25]$ mm を数える。
`BinPlan::uniform(&[(下端, 上端, ビンの数)])` は各軸を等しい幅のビンに分け、端の辺は指定した値そのもの、内部の辺 $i$ は $\text{下端}\cdot(n-i)/n + \text{上端}\cdot i/n$ を丸めた値になる。
ビンは左閉右開 $[e_i, e_{i+1})$ で、最後のビンだけ上端 $e_m$ を含む。
ウインドウの下端より小さい値は下側、上端より大きい値は上側の範囲外として数え、どのビンにも入れない。
下端が上端以上、ビンの数が 0、隣の辺が丸めで同じ値になる場合は `InvalidInput` になる。

関数 `binned_statistics(&plan, view, values, statistic, options)` は、`BatchView` の各バッチの観測をビンに振り分け、ビンごとに `BinnedStatistic` が選ぶ量を求める。
観測の質量は重みなしでは 1、頻度の重みでは件数、質量の重みでは重みである。

- `Count` はビンの観測の数、`Mass` はビンの質量の和である。
- `RelativeFrequency` はビンの質量を、範囲外も含めて受け付けたすべての観測の質量で割る。
  したがって、ビンの和はウインドウに入った割合になり、1 にはならない。
- `Density` はビンの質量を、ウインドウの中の質量とビンの幅で割る。
  ビンの幅を掛けて足すと 1 になり、ウインドウの中の分布の形を表す。
- `CumulativeFrequency` は左から累積した質量、`Sum`、`Mean`、`StandardDeviation`、`Minimum`、`Maximum`、`Median` は観測ごとに別に渡す値 `values` をビンの中で要約する。

結果の `BinnedResult` は、ビンごとの `BinEstimate`（`count`、`mass`、`value`）を `bins` に、バッチごとの `BinnedDiagnostics` を `diagnostics` に持つ。
診断は受け付けた質量 `admitted_mass`、ウインドウの中の質量 `retained_mass`、下側と上側の範囲外の質量 `underflow_mass`、`overflow_mass`、方針で飛ばした観測の数 `skipped` である。
質量が `f64` であふれるときはその値が `None` になる。
空のビンの平均や中央値のように定義できない値は、NaN ではなく `None` になる。

次のセルは上端 $b$ を動かして件数、相対度数、密度を求め、左閉右開で最後のビンだけ上端を含む規則で手で数えた件数と比べる。
上端 $b$ を動かすと、1.0 mm と 1.25 mm の観測が、境界上、ウインドウの中、ウインドウの外の間を移る。

```rust
//| id: stats-bin-boundary-normalization
//| ref: stats-bin-boundary-normalization
//| title: 範囲外も含む相対度数と範囲内密度を区別する
//| run: reactive
//| crates: [scioxide-core, scioxide-stats]
//| inputs:
//|   upper_edge: {"type":"range","label":"公差のウインドウの上端 b [mm]","description":"1.0 mm の観測は b = 1.0 で最後のビンの上端に乗る。","min":0.75,"max":1.5,"step":0.25,"value":1}
//| cases:
//|   - {"id":"narrow","label":"b = 0.75 mm","description":"0.75 mm が上端に乗ってウインドウに残り、1.0 mm と 1.25 mm が上側の範囲外になる。","inputs":{"upper_edge":0.75}}
//|   - {"id":"edge-125","label":"b = 1.25 mm","description":"1.25 mm が上端に乗り、内部の辺 0.625 mm が 0.5 mm と 0.75 mm の間に入る。","inputs":{"upper_edge":1.25}}
//|   - {"id":"wide","label":"b = 1.5 mm","description":"上側の範囲外がなくなる。","inputs":{"upper_edge":1.5}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"bins","path":"/rows/1/2","equals":3}
//|       - {"artifact":"bins","path":"/rows/1/3","equals":3}
//|       - {"artifact":"bins","path":"/rows/0/5","approx":{"value":0.8,"rtol":1e-12}}
//|       - {"artifact":"totals","path":"/rows/0/1","approx":{"value":0.7142857142857143,"rtol":1e-12}}
//|       - {"artifact":"totals","path":"/rows/1/1","approx":{"value":1.0,"rtol":1e-12}}
//|       - {"artifact":"totals","path":"/rows/5/1","equals":1}
//|   - case: narrow
//|     expect:
//|       - {"artifact":"totals","path":"/rows/3/1","equals":4}
//|       - {"artifact":"totals","path":"/rows/5/1","equals":2}
//|   - case: edge-125
//|     expect:
//|       - {"artifact":"bins","path":"/rows/0/2","equals":3}
//|       - {"artifact":"bins","path":"/rows/0/1","approx":{"value":0.625,"rtol":1e-12}}
//|   - case: wide
//|     expect:
//|       - {"artifact":"totals","path":"/rows/5/1","equals":0}
//|       - {"artifact":"totals","path":"/rows/0/1","approx":{"value":0.8571428571428571,"rtol":1e-12}}
use scioxide_core::StridedLayout;
use scioxide_stats::{
    Axis, BatchView, BinPlan, BinnedResult, BinnedStatistic, StatisticsOptions,
    binned_statistics,
};

// 公称値からのずれ [mm]。−0.25 はウインドウの下、1.25 は b < 1.25 のときウインドウの上に出る。
let samples = [-0.25_f64, 0.0, 0.25, 0.5, 0.75, 1.0, 1.25];
let (shape, strides) = ([7_usize], [1_usize]);
let layout = StridedLayout::new(&shape, &strides).map_err(|e| e.to_string())?;
let view = BatchView::new(&samples, layout, Axis::Index(0)).map_err(|e| e.to_string())?;
let plan = BinPlan::uniform(&[(0.0, upper_edge, 2)]).map_err(|e| e.to_string())?;
let run = |statistic| {
    binned_statistics(&plan, view, None, statistic, StatisticsOptions::default())
        .map_err(|e| e.to_string())
};
let counts = run(BinnedStatistic::Count)?;
let relative = run(BinnedStatistic::RelativeFrequency)?;
let density = run(BinnedStatistic::Density)?;
let width = upper_edge / 2.0;
// 独立な検算: 左閉右開で、最後のビンだけ上端を含む規則で数える。
let by_hand = |k: usize| {
    let (lo, hi) = (k as f64 * width, (k + 1) as f64 * width);
    let inside = |x: f64| x >= lo && (x < hi || (k == 1 && x == upper_edge));
    samples.iter().filter(|&&x| inside(x)).count()
};
let value = |result: &BinnedResult<f64>, k: usize| {
    result.bins[k]
        .value
        .ok_or_else(|| "ビンの値が未定義".to_string())
};
let mut rows = Vec::new();
for k in 0..2 {
    let (lo, hi) = (k as f64 * width, (k + 1) as f64 * width);
    let (r, d) = (value(&relative, k)?, value(&density, k)?);
    rows.push((lo, hi, counts.bins[k].count, by_hand(k), r, d));
}
let fixed4 = serde_json::json!({ "fractionDigits": 4 });
let columns = serde_json::json!([
    { "key": "0", "label": "下端 [mm]", "type": "number", "format": fixed4 },
    { "key": "1", "label": "上端 [mm]", "type": "number", "format": fixed4 },
    { "key": "2", "label": "件数 [個]", "type": "integer" },
    { "key": "3", "label": "数え上げ [個]", "type": "integer" },
    { "key": "4", "label": "相対度数 [-]", "type": "number", "format": fixed4 },
    { "key": "5", "label": "密度 [1/mm]", "type": "number", "format": fixed4 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "bins" })
);
let d = &relative.diagnostics[0];
let relative_sum = value(&relative, 0)? + value(&relative, 1)?;
let density_sum = width * (value(&density, 0)? + value(&density, 1)?);
let totals = vec![
    ("相対度数の和 [-]", Some(relative_sum)),
    ("密度 × 幅の和 [-]", Some(density_sum)),
    ("受け付けた質量 admitted_mass [個]", d.admitted_mass),
    ("ウインドウの中の質量 retained_mass [個]", d.retained_mass),
    ("下側の範囲外の質量 underflow_mass [個]", d.underflow_mass),
    ("上側の範囲外の質量 overflow_mass [個]", d.overflow_mass),
];
let total_columns = serde_json::json!([
    { "key": "0", "label": "量" },
    { "key": "1", "label": "値", "type": "number", "format": fixed4, "nullText": "あふれ" }
]);
emit_table_with_columns!(
    total_columns,
    totals,
    metadata = serde_json::json!({ "id": "totals" })
);
```

既定の $b = 1.0$ mm では、ビン $[0, 0.5)$ に 0 と 0.25 の 2 個、最後のビン $[0.5, 1.0]$ に 0.5、0.75、上端に乗った 1.0 の 3 個が入り、件数は数え上げと一致する。
$-0.25$ は下側、1.25 は上側の範囲外で、受け付けた質量 7 のうちウインドウの中は 5 である。
相対度数は $2/7$ と $3/7$ で和は $5/7 \approx 0.7143$、密度は $2/(5 \times 0.5) = 0.8$ と $3/(5 \times 0.5) = 1.2$ で、幅を掛けた和は 1 になる。

$b = 0.75$ では 0.75 が最後のビンの上端に乗ってウインドウの中に残り、1.0 と 1.25 が上側の範囲外になる（ウインドウの中の質量 4、相対度数の和 0.5714）。
$b = 1.25$ では内部の辺が 0.625 mm になり、0.5 mm が最初のビン、0.75 mm が最後のビンに入って、件数は 3 と 3 になる。
上側の範囲外は 0 になり、相対度数の和は 0.8571 である。
$b = 1.5$ でもウインドウの中の質量は 6 で、上側の範囲外は 0、相対度数の和は 0.8571 になる。
どの場合も密度 × 幅の和は 1 で、相対度数の和はウインドウの中の質量 ÷ 受け付けた質量に等しい。

## まとめ

同値を含む標本では、経験分布関数は境界の値の観測をすべて $P(X \le x)$ に含め、生存関数は境界より大きい観測だけを数えるので、両者の和はどの $x$ でも 1 になる。
分位点の定義によって同値の扱いが変わり、型 1 は同値の値に留まり、型 7 は隣の観測との間を補間する。
CDF を連続に推定したいときは `estimated_cdf` か `CdfMethod::Estimated` を使い、どの分位点の定義を逆にした値かを添える。
ビン集計では、左閉右開の規則と最後のビンの上端の扱いで境界上の観測の行き先が決まり、範囲外の観測は診断の質量として残る。
ウインドウの外の割合を知りたいときは相対度数、ウインドウの中の分布の形を知りたいときは密度を読む。
