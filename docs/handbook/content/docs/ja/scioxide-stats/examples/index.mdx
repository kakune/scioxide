統計の計算では、アルゴリズムの数値的な正しさと、統計モデルとしての妥当性を別々に確かめる。
アルゴリズムの正しさは、丸め誤差や桁落ちに耐えて、定義どおりの量を計算できているかである。
モデルの妥当性は、標本の独立性や母集団の分布など、推論が置いた仮定がデータに合っているかである。
Welford の漸化式が正確でも、自己相関を無視した平均の信頼区間は狭すぎ、範囲外の観測を数えないヒストグラムは割合を誤る。
この節の実例は、具体的な題材を `scioxide-stats` で計算し、その結果を解析解、数え上げ、文献の値、別のアルゴリズムのどれかで独立に検算する。

## 題材の分け方

最初の 5 つの実例は、記述統計の計算そのものの正しさを扱う。
センサー列、通信遅延、分割集計、分布関数とビン集計では、基準値による桁落ち、裾の観測の少なさ、結合の順序、同値と範囲外の数え方が、計算した値をどう変えるかを確かめる。
信頼区間の被覆率の実例は、アルゴリズムが正確でも独立性の仮定が崩れると区間が名目の水準を守らないことを示す。

次の 3 つは、回帰、分割表、生存時間のモデルを扱う。
自作の回帰例は、構成から導いた恒等式を使って要約統計の限界を示す。
Simpson のパラドックスは層別と合算の違いを、白血病の寛解期間は打ち切りのあるデータの推定と検定を、文献の値と照合する。

残りの 5 つは、多数の検定、リサンプリング、時系列、感度解析、ベイズ推論を扱う。
いずれも反復実験や閉形式の値を使い、推定した誤り率・被覆率・指数を、理論値と標準誤差か信頼区間で比べる。

## まとめ

各実例は、具体的な題材を `scioxide-stats` で計算し、解析解・数え上げ・文献の値・別のアルゴリズムのどれかで独立に検算する。
数値の正しさは解析値や数え上げとの差で、推論の妥当性は反復実験で測った被覆率や誤り率と名目の水準との比較で確かめる。
操作入力で基準値、裾の観測、自己相関、標本数などを動かすと、仮定が崩れたときに推定値や区間がどう変わるかを数値で読める。
手法の前提と導出はアルゴリズムのページに、型と関数の約束事は API ガイドにある。
