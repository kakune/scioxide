シミュレーションの入力が不確かなとき、出力のばらつきのうちどれだけがどの入力から来るかを知りたいことがある。
分散に基づく大域的感度解析は、出力の分散を入力ごとの寄与と交互作用の寄与に分け、その割合を Sobol 指数として数える。
推定には Monte Carlo 法を使うので、指数の推定値には統計的な誤差が付く。
このページは、指数が閉形式で分かる Ishigami 関数を使い、scioxide-stats の推定値を閉形式の値と比べる。
比較は推定値の誤差を bootstrap 区間や反復の標準誤差と並べて行い、標本数を増やしたときの誤差の減り方も調べる。

## Ishigami 関数と分散分解

Ishigami 関数（Ishigami–Homma 1990）は、独立な一様乱数 $X_1,X_2,X_3\sim U(-\pi,\pi)$ に対して

$$
Y=f(X_1,X_2,X_3)=\sin X_1+a\sin^2X_2+b\,X_3^4\sin X_1
$$

で定める。
感度解析の検証では $a=7$、$b=0.1$ がよく使われる（Saltelli ら 2000）。
$X_2$ は単独で効き、$X_3$ は $X_1$ との積を通してだけ効き、$X_1$ は単独でも積でも効く。

入力が独立なら、二乗可積分な $f$ は互いに直交する成分の和

$$
f=f_0+\sum_if_i(X_i)+\sum_{i<j}f_{ij}(X_i,X_j)+f_{123}(X_1,X_2,X_3)
$$

に一意に分解できる（Sobol の分解、ANOVA 分解）。
各成分は、それより低次の成分を除いた条件付き期待値で、たとえば $f_i=E[Y\mid X_i]-f_0$ である。
成分が直交するので、出力の分散も $V=\sum_iV_i+\sum_{i<j}V_{ij}+V_{123}$ と分かれる。
一次の指数 $S_i=V_i/V$ は $X_i$ 単独の寄与の割合、全効果の指数 $S_{Ti}$ は $X_i$ を含むすべての項の寄与の割合で、

$$
S_i=\frac{\mathrm{Var}(E[Y\mid X_i])}{V},\qquad S_{Ti}=\frac{E[\mathrm{Var}(Y\mid X_{\sim i})]}{V}=1-\frac{\mathrm{Var}(E[Y\mid X_{\sim i}])}{V}
$$

と書ける。
$X_{\sim i}$ は $X_i$ 以外の入力である。
$S_{Ti}-S_i$ は $X_i$ が関わる交互作用の大きさを表し、$S_{Ti}=0$ なら $X_i$ を固定しても出力の分散は変わらない。

Ishigami 関数では、三角関数の直交性と $E[X_3^4]=\pi^4/5$、$E[X_3^8]=\pi^8/9$ から、各成分の分散が

$$
V_1=\frac12\left(1+\frac{b\pi^4}{5}\right)^2,\qquad V_2=\frac{a^2}{8},\qquad V_{13}=b^2\pi^8\left(\frac1{18}-\frac1{50}\right)=\frac{8b^2\pi^8}{225},
$$

$$
V_3=V_{12}=V_{23}=V_{123}=0,\qquad V=\frac12+\frac{a^2}8+\frac{b\pi^4}5+\frac{b^2\pi^8}{18}
$$

と求まる。
指数は $S_1=V_1/V$、$S_2=V_2/V$、$S_3=0$、$S_{T1}=(V_1+V_{13})/V$、$S_{T2}=S_2$、$S_{T3}=V_{13}/V$ である。
$a=7$、$b=0.1$ では $V\approx13.845$ で、$S_1\approx0.3139$、$S_2\approx0.4424$、$S_{T1}\approx0.5576$、$S_{T3}\approx0.2437$ になる。
$X_3$ の一次の指数は 0 だが、全効果は 0.24 ある。
一次の指数だけを見ると $X_3$ は効かない入力に見えるが、$X_1$ と $X_2$ を固定しても、$X_3$ の変動だけで平均して出力の分散の 24% が残る。
$X_3$ を定数に置き換える簡略化は、$S_{T3}$ が小さいときにだけ許される。

## pick-freeze 法による推定

条件付き期待値の分散は同じ $X_i$ を共有する 2 つの点の出力の共分散として推定できる。
独立な $n\times d$ の標本の行列 $A$、$B$ を用意し、$A$ の第 $i$ 列だけを $B$ の第 $i$ 列に置き換えた行列を $A_B^{(i)}$ と書く。
$A$、$B$、$d$ 個の $A_B^{(i)}$ の各行でモデルを評価するので、評価の回数は $n(d+2)$ である。
$f(A)$ と $f(B)$ の $2n$ 個の出力の平均を $m$、分散を $\hat V$ として、scioxide-stats は

$$
\hat S_i=\frac1{n\hat V}\sum_{k=1}^n\bigl(f(B)_k-m\bigr)\bigl(f(A_B^{(i)})_k-f(A)_k\bigr),\qquad
\hat S_{Ti}=\frac1{2n\hat V}\sum_{k=1}^n\bigl(f(A)_k-f(A_B^{(i)})_k\bigr)^2
$$

を使う。
一次は Saltelli ら（2010）の推定量、全効果は Jansen（1999）の推定量である。
$f(A_B^{(i)})_k$ と $f(B)_k$ は $X_i$ だけを共有し、$f(A_B^{(i)})_k$ と $f(A)_k$ は $X_i$ 以外を共有するので、前者の共分散が $V_i$、後者の差の二乗の期待値の半分が $E[\mathrm{Var}(Y\mid X_{\sim i})]$ になる。
分子と分母を同じ標本で推定する比なので、推定量は一般に不偏ではなく、偏りは $O(1/n)$ である。
推定値は $[0,1]$ に切り詰めないので、真値が 0 の $S_3$ は負の値にもなる。
和は拡張指数の累積で計算するので、出力に定数を足したり定数倍したりしても、推定値は丸めの範囲でしか変わらない。

`sobol_indices_monte_carlo(d, n, root, sampler, model)` は Monte Carlo 法でこの設計を作る。
行 $k$ の $A_k$ と $B_k$ は生成器 `root.split(k)` から引くので、結果は実行の並列度に依らない。
`sampler(j, rng)` は座標 $j$ の周辺分布から 1 つの値を返し、入力は互いに独立であることを前提にする。
返り値の `SobolMonteCarloResult` は指数 `indices()` と、すべての出力 `evaluations()` を持つ。
出力の保存に $O(nd)$ のメモリ領域を使う。

`sobol_bootstrap(evaluations, root, replicates, confidence)` は、行を復元抽出して指数を計算し直し、percentile 法の区間を返す。
1 つの行の $f(A)$、$f(B)$、$f(A_B^{(i)})$ は一緒に抽出する。
計算量は $O(Bnd)$ で、行が独立なときだけ有効なので、準 Monte Carlo の点には使わない。

`sobol_indices_qmc(plan, d, points, transform, model)` は乱択準 Monte Carlo（RQMC）法を使う。
`QmcReplicatePlan` は $2d$ 次元の Sobol 点列を独立に $R$ 回スクランブルし、各点の前半の $d$ 座標を $A$ の行、後半を $B$ の行にする。
`transform(j, u)` は $[0,1)$ の座標を入力の座標に写す（ここでは $-\pi+2\pi u$）。
返す指数は $R$ 個の複製の推定値の平均で、`randomized_standard_error()` が複製の標準偏差を $\sqrt R$ で割った標準誤差を返す。
評価の回数は $R\cdot\text{points}\cdot(d+2)$ である。
点列の生成とスクランブルは scioxide-random が受け持つ（[準乱数と Brownian bridge](../../../scioxide-random/algorithms/quasi-random-and-brownian-bridges/)）。

被積分関数が滑らかなら、RQMC の誤差は Monte Carlo の $O(n^{-1/2})$ より速く減る。
実際の利点は被積分関数と指数ごとに異なるので、下の反復実験で確かめる。
モデルの評価コストが大きい場合は、Morris 法などで効かない入力を先に除くことが多い。
scioxide-stats は Morris 法、FAST、Sobol の二次の指数 $S_{ij}$ を提供しない。
二次の指数が必要なら、$B$ の第 $j$ 列を $A$ の列に置き換えた行列でもモデルを評価し、Saltelli（2002）の推定量を自分で計算する。

次の定義のブロックは、ページの 2 つのセルが使うモデルである。
`ishigami` がモデル、`exact_indices` が閉形式の指数（$S_1,S_2,S_3,S_{T1},S_{T2},S_{T3}$ の順）、`uniform` が座標の写像 $u\mapsto-\pi+2\pi u$ に対応する。
`monte_carlo` は $n$ 行の Monte Carlo 推定、`randomized` は 8 個の複製で合計 $n$ 点の RQMC 推定で、どちらもモデルを $5n$ 回評価する。
`ordered` は推定結果を閉形式と同じ順の配列にする。

```rust
//| id: stats-ishigami-model
//| kind: definitions
//| title: Ishigami 関数、閉形式の指数、2 つの推定法
//| crates: [scioxide-core, scioxide-random, scioxide-stats]
use scioxide_core::{SciOxideError, RealScalar};
use scioxide_random::{Philox4x64, QmcPlan, QmcReplicateOptions, QmcReplicatePlan, Rng, SeedableRng};
use scioxide_stats::{
    SobolIndices, SobolMonteCarloResult, sobol_indices_monte_carlo, sobol_indices_qmc,
};

/// f(x) = sin x₁ + a sin² x₂ + b x₃⁴ sin x₁
pub(crate) fn ishigami(x: &[f64], a: f64, b: f64) -> Result<f64, SciOxideError> {
    let s1 = RealScalar::sin(x[0]);
    let s2 = RealScalar::sin(x[1]);
    Ok(s1 + a * s2 * s2 + b * RealScalar::powi(x[2], 4) * s1)
}

/// 閉形式の [S₁, S₂, S₃, S_T1, S_T2, S_T3] と全分散 V
pub(crate) fn exact_indices(a: f64, b: f64) -> ([f64; 6], f64) {
    let pi4 = RealScalar::powi(core::f64::consts::PI, 4);
    let v1 = 0.5 * RealScalar::powi(1.0 + b * pi4 / 5.0, 2);
    let v2 = a * a / 8.0;
    let v13 = 8.0 * b * b * pi4 * pi4 / 225.0;
    let v = 0.5 + a * a / 8.0 + b * pi4 / 5.0 + b * b * pi4 * pi4 / 18.0;
    ([v1 / v, v2 / v, 0.0, (v1 + v13) / v, v2 / v, v13 / v], v)
}

/// [0, 1) の座標を U(−π, π) に写す。
pub(crate) fn uniform(u: f64) -> f64 {
    -core::f64::consts::PI + 2.0 * core::f64::consts::PI * u
}

/// n 行の Monte Carlo 推定。行 k は Philox4x64(seed) の分割 k から引く。
pub(crate) fn monte_carlo(
    rows: usize,
    a: f64,
    b: f64,
    seed: u64,
) -> Result<SobolMonteCarloResult, SciOxideError> {
    let root = Philox4x64::from_seed(seed);
    let sampler = |_: usize, rng: &mut Philox4x64| -> Result<f64, SciOxideError> {
        let u: f64 = rng.next_float()?;
        Ok(uniform(u))
    };
    sobol_indices_monte_carlo(3, rows, &root, sampler, |x: &[f64]| ishigami(x, a, b))
}

/// 6 次元 Sobol 点列を 8 回スクランブルし、各複製 rows/8 点で推定した平均。
pub(crate) fn randomized(
    rows: usize,
    a: f64,
    b: f64,
    seed: u64,
) -> Result<SobolIndices, SciOxideError> {
    let root = Philox4x64::from_seed(seed);
    let options = QmcReplicateOptions::default()
        .with_replicates(8)
        .with_points_per_replicate(rows / 8);
    let plan = QmcReplicatePlan::new(&QmcPlan::sobol(6)?, &root, options)?;
    let transform = |_: usize, u: f64| -> Result<f64, SciOxideError> { Ok(uniform(u)) };
    sobol_indices_qmc(&plan, 3, rows / 8, transform, |x: &[f64]| ishigami(x, a, b))
}

/// [S₁, S₂, S₃, S_T1, S_T2, S_T3] の順に並べる。
pub(crate) fn ordered(first: &[f64], total: &[f64]) -> [f64; 6] {
    [first[0], first[1], first[2], total[0], total[1], total[2]]
}
```

## 1 回の推定

次のセルは選んだ方法と行数で指数を推定し、閉形式の値と比べる。
Monte Carlo では `sobol_bootstrap` による 100 回の再標本の percentile 区間、RQMC では 8 個の複製の平均 $\pm t_{0.975,7}\times$ 標準誤差を 95% 区間とする（$t_{0.975,7}\approx2.365$）。
どちらもモデルの評価は $5n$ 回で、計算の量をそろえてある。
表は各指数の閉形式の値、推定値、区間、区間が閉形式の値を含むかを示す。
棒グラフは推定値と閉形式の値を並べ、エラーバーの図は推定値と閉形式の値の差を区間と一緒に示す。
差の図の横線 0 からエラーバーが離れていれば、その差は推定の誤差では説明しにくい。
bootstrap の計算量が $O(Bnd)$ なので、ボタンで実行する。

```rust
//| id: stats-ishigami-sensitivity-api-1
//| ref: stats-ishigami-sensitivity-api-1
//| title: Ishigami 関数の Sobol 指数を推定し、閉形式の値と比べる
//| run: button
//| uses: [stats-ishigami-model]
//| crates: [scioxide-random, scioxide-stats]
//| inputs:
//|   method: {"type":"select","label":"推定法","options":[{"label":"Monte Carlo（bootstrap 区間）","value":"mc"},{"label":"乱択準 Monte Carlo（8 複製）","value":"rqmc"}],"value":"mc"}
//|   rows: {"type":"select","label":"行数 n（評価は 5n 回）","options":["256","1024","4096"],"value":"1024"}
//|   param_b: {"type":"range","label":"交互作用の係数 b [-]","description":"0 にすると X₃ が効かなくなる。","min":0.0,"max":0.2,"step":0.05,"value":0.1}
//|   seed: {"type":"range","label":"乱数のシード","min":1,"max":100,"step":1,"value":2}
//| cases:
//|   - {"id":"rqmc","label":"RQMC","description":"同じ評価回数で区間が狭くなる。","inputs":{"method":"rqmc"}}
//|   - {"id":"few-rows","label":"n = 256","description":"区間が広がる。","inputs":{"rows":"256"}}
//|   - {"id":"no-interaction","label":"b = 0","description":"X₃ の全効果も 0 になる。","inputs":{"param_b":0.0}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"indices","path":"/rows/0/1","approx":{"value":0.313905,"atol":1e-6}}
//|       - {"artifact":"indices","path":"/rows/5/1","approx":{"value":0.243684,"atol":1e-6}}
//|       - {"artifact":"indices","path":"/rows/5/2","approx":{"value":0.2437,"atol":0.05}}
//|   - case: rqmc
//|     expect:
//|       - {"artifact":"indices","path":"/rows/1/2","approx":{"value":0.4424,"atol":0.02}}
//|   - case: no-interaction
//|     expect:
//|       - {"artifact":"indices","path":"/rows/5/1","equals":0}
//|       - {"artifact":"indices","path":"/rows/5/2","approx":{"value":0.0,"atol":1e-12}}
use scioxide_random::{Philox4x64, SeedableRng};
use scioxide_stats::{ConfidenceProbability, sobol_bootstrap};

let a = 7.0;
let n: usize = rows.parse().map_err(|_| "行数を読めない")?;
let (exact, variance) = exact_indices(a, param_b);
let confidence = ConfidenceProbability::new(0.95).map_err(|e| e.to_string())?;
let (values, lower, upper) = if method == "rqmc" {
    let indices = randomized(n, a, param_b, seed as u64).map_err(|e| e.to_string())?;
    let (first, total) = indices
        .randomized_standard_error()
        .ok_or("標準誤差がない")?;
    let t = confidence
        .student_t_critical_value(7.0)
        .map_err(|e| e.to_string())?;
    let values = ordered(indices.first_order(), indices.total_order());
    let se = ordered(first, total);
    let lower: Vec<f64> = (0..6).map(|k| values[k] - t * se[k]).collect();
    let upper: Vec<f64> = (0..6).map(|k| values[k] + t * se[k]).collect();
    (values, lower, upper)
} else {
    let result = monte_carlo(n, a, param_b, seed as u64).map_err(|e| e.to_string())?;
    let root = Philox4x64::from_seed(seed as u64 + 1_000_000);
    let boot = sobol_bootstrap(result.evaluations(), &root, 100, confidence)
        .map_err(|e| e.to_string())?;
    let intervals: Vec<(f64, f64)> = boot
        .first_order()
        .iter()
        .chain(boot.total_order())
        .copied()
        .collect();
    let values = ordered(
        result.indices().first_order(),
        result.indices().total_order(),
    );
    (
        values,
        intervals.iter().map(|v| v.0).collect(),
        intervals.iter().map(|v| v.1).collect(),
    )
};
let names = ["S₁", "S₂", "S₃", "S_T1", "S_T2", "S_T3"];
let table: Vec<_> = (0..6)
    .map(|k| {
        (
            names[k],
            exact[k],
            values[k],
            lower[k],
            upper[k],
            lower[k] <= exact[k] && exact[k] <= upper[k],
        )
    })
    .collect();
let fixed4 = serde_json::json!({ "fractionDigits": 4 });
let columns = serde_json::json!([
    { "key": "0", "label": "指数" },
    { "key": "1", "label": "閉形式 [-]", "type": "number", "format": fixed4 },
    { "key": "2", "label": "推定値 [-]", "type": "number", "format": fixed4 },
    { "key": "3", "label": "95% 区間の下端 [-]", "type": "number", "format": fixed4 },
    { "key": "4", "label": "95% 区間の上端 [-]", "type": "number", "format": fixed4 },
    { "key": "5", "label": "閉形式を含む", "type": "boolean" }
]);
emit_table_with_columns!(
    columns,
    table,
    metadata = serde_json::json!({ "id": "indices" })
);
emit_chart!(serde_json::json!({
    "kind": "bar",
    "xLabel": "指数",
    "yLabel": "分散の割合 [-]",
    "categories": names,
    "yMin": -0.1,
    "yMax": 1.0,
    "tooltip": true,
    "series": [
        { "name": "推定値", "values": values },
        { "name": "閉形式", "values": exact }
    ]
}));
let differences: Vec<_> = (0..6)
    .map(|k| {
        serde_json::json!([
            names[k],
            values[k] - exact[k],
            lower[k] - exact[k],
            upper[k] - exact[k]
        ])
    })
    .collect();
emit_chart!(serde_json::json!({
    "kind": "errorbar",
    "xLabel": "指数",
    "yLabel": "推定値 − 閉形式 [-]",
    "tooltip": true,
    "series": [{ "name": "差と 95% 区間", "points": differences }],
    "annotations": [{ "kind": "line", "axis": "y", "value": 0.0, "label": "差 0" }]
}));
let sig5 = serde_json::json!({ "significantDigits": 5 });
emit_table_with_columns!(
    serde_json::json!([
        { "key": "0", "label": "全分散 V（閉形式）[-]", "type": "number", "format": sig5 },
        { "key": "1", "label": "モデルの評価回数", "type": "integer" }
    ]),
    vec![(variance, 5 * n)],
    metadata = serde_json::json!({ "id": "budget" })
);
```

既定の入力（Monte Carlo、$n=1024$、$b=0.1$、シード 2）では、6 つの推定値は閉形式の値から 0.06 以内にあり、bootstrap 区間の幅は 0.05〜0.14 である。
区間は 6 つのうち 5 つで閉形式の値を含み、$S_{T3}$ の区間は下端 0.243687 が閉形式の 0.243684 をわずかに上回って外れる（表の 4 桁ではどちらも 0.2437 に見える）。
95% 区間を 6 つ並べると、1 つが外れることは珍しくない。
$S_3$ の推定値は $-0.052$ と負になるが、区間は 0 を含む。
$S_1+S_2+S_3$ は 1 より小さく、閉形式では残りの約 0.24 が $X_1$ と $X_3$ の交互作用である。

RQMC に切り替えると、同じ $5n$ 回の評価で $S_2$ の区間の幅は Monte Carlo の約 1/5、$S_{T2}$ は約 1/2、$S_{T3}$ は約 0.8 倍になり、推定値も閉形式の値に近づく。
一方、$S_1$ と $S_{T1}$ の区間はむしろ広くなる。
RQMC の区間は 1 複製 128 点の推定値 8 個のばらつきから作るので、複製ごとのばらつきが大きい指数では、自由度 7 の $t$ 値と合わせて区間が広がる。
RQMC の利点は指数ごとに異なり、1 回の結果だけで方法の優劣を決めずに、次の反復実験で誤差の大きさを比べる。
$n=256$ の Monte Carlo では区間の幅が 0.10〜0.37 に広がる。
$b=0$ では $f=\sin X_1+a\sin^2X_2$ と加法的になり、$S_{T3}=S_3=0$、$S_1=S_{T1}$ になる。
推定値の $S_3$ と $S_{T3}$ は区間も含めて厳密に 0 になる。
$f(A)$ と $f(A_B^{(3)})$ は $X_3$ にしか違いがなく、$X_3$ が出力に入らないので、差が厳密に 0 になるからである。

## 標本数と誤差の減り方

1 回の推定では、区間が閉形式の値を含むかどうかは偶然に左右される。
次のセルは行数 $n=256,1024,4096$ のそれぞれで、別のシードによる推定を Monte Carlo と RQMC で $R$ 回ずつ繰り返す。
記録するのは、各指数の推定誤差の二乗の和（二乗平均平方根 RMSE の計算に使う）と、RQMC の 95% 区間が閉形式の値を含んだ回数である。
Monte Carlo の bootstrap 区間は 1 回あたり $O(Bnd)$ の計算がかかるので、反復実験では区間を作らず、誤差だけを比べる。
既定の $R=20$ でモデルを合計 100 万回程度評価するので、ボタンで実行し、同じ入力の結果は再利用する。

```rust
//| id: stats-ishigami-convergence
//| ref: stats-ishigami-convergence
//| title: 行数を変えて推定を繰り返し、誤差と RQMC の区間の被覆を数える
//| run: button
//| cache: inputs
//| uses: [stats-ishigami-model]
//| crates: [scioxide-stats]
//| exports: [sizes, replicates, errors, covered]
//| inputs:
//|   replicates: {"type":"range","label":"反復数 R","description":"RMSE と被覆率の Monte Carlo 誤差を変える。","min":10,"max":50,"step":10,"value":20}
//|   seed: {"type":"range","label":"乱数のシード","min":1,"max":100,"step":1,"value":1}
//| cases:
//|   - {"id":"few","label":"R = 10","description":"被覆率の Wilson 区間が広がる。","inputs":{"replicates":10}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"path":"/exports/sizes/2","equals":4096}
use scioxide_stats::ConfidenceProbability;

let (a, b) = (7.0, 0.1);
let (exact, _) = exact_indices(a, b);
let t = ConfidenceProbability::new(0.95)
    .and_then(|c| c.student_t_critical_value(7.0))
    .map_err(|e| e.to_string())?;
let sizes = [256_usize, 1024, 4096];
// errors[方法][行数][指数] = 二乗誤差の和（方法 0 が Monte Carlo、1 が RQMC）
// covered[行数][指数] = RQMC の区間が閉形式を含んだ回数
let mut errors = [[[0.0_f64; 6]; 3]; 2];
let mut covered = [[0.0_f64; 6]; 3];
for (s, &n) in sizes.iter().enumerate() {
    for j in 0..replicates as usize {
        let replicate_seed = 1_000 * seed as u64 + j as u64;
        let mc = monte_carlo(n, a, b, replicate_seed).map_err(|e| e.to_string())?;
        let mc_values = ordered(mc.indices().first_order(), mc.indices().total_order());
        let qmc = randomized(n, a, b, replicate_seed).map_err(|e| e.to_string())?;
        let qmc_values = ordered(qmc.first_order(), qmc.total_order());
        let (first, total) = qmc.randomized_standard_error().ok_or("標準誤差がない")?;
        let se = ordered(first, total);
        for k in 0..6 {
            errors[0][s][k] += (mc_values[k] - exact[k]) * (mc_values[k] - exact[k]);
            errors[1][s][k] += (qmc_values[k] - exact[k]) * (qmc_values[k] - exact[k]);
            covered[s][k] += f64::from(u8::from((qmc_values[k] - exact[k]).abs() <= t * se[k]));
        }
    }
}
export!(sizes, sizes);
export!(replicates, replicates as usize);
export!(errors, errors);
export!(covered, covered);
```

表示のセルは 6 つの指数の RMSE の平均を行数に対して両対数で描き、$n^{-1/2}$ と $n^{-1}$ の傾きの参照線（破線）と比べる。
参照線は Monte Carlo の $n=256$ の点を通るように置く。
表は選んだ指数について、行数ごとの 2 つの方法の RMSE と、RQMC の区間の被覆率と Wilson の 95% 区間を示す。

```rust
//| id: stats-ishigami-convergence-display
//| ref: stats-ishigami-convergence-display
//| title: RMSE の減り方と RQMC の区間の被覆率を比べる
//| run: reactive
//| crates: []
//| dependsOn:
//|   run: stats-ishigami-convergence
//| inputs:
//|   index: {"type":"select","label":"表に出す指数","options":["S₁","S₂","S₃","S_T1","S_T2","S_T3"],"value":"S_T1"}
//| cases:
//|   - {"id":"main-effect-2","label":"S₂","description":"滑らかな主効果では RQMC の誤差が速く減る。","inputs":{"index":"S₂"}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"rmse","path":"/rows/0/0","equals":256}
//|       - {"artifact":"rmse","path":"/rows/2/1","approx":{"value":0.026389,"atol":1e-5}}
let sizes: Vec<f64> =
    serde_json::from_value(run["sizes"].clone()).map_err(|e| e.to_string())?;
let r = run["replicates"].as_f64().ok_or("反復数がない")?;
let errors: [[[f64; 6]; 3]; 2] =
    serde_json::from_value(run["errors"].clone()).map_err(|e| e.to_string())?;
let covered: [[f64; 6]; 3] =
    serde_json::from_value(run["covered"].clone()).map_err(|e| e.to_string())?;
let names = ["S₁", "S₂", "S₃", "S_T1", "S_T2", "S_T3"];
let k = names
    .iter()
    .position(|&name| name == index)
    .ok_or("指数の名前が違う")?;
// RMSE = √(二乗誤差の和 / R)
let rmse = |m: usize, s: usize, i: usize| (errors[m][s][i] / r).sqrt();
let average = |m: usize, s: usize| (0..6).map(|i| rmse(m, s, i)).sum::<f64>() / 6.0;
let curve = |m: usize| -> Vec<[f64; 2]> {
    (0..sizes.len())
        .map(|s| [sizes[s], average(m, s)])
        .collect()
};
let reference = |power: f64| -> Vec<[f64; 2]> {
    sizes
        .iter()
        .map(|&n| [n, average(0, 0) * (sizes[0] / n).powf(power)])
        .collect()
};
let dashed = serde_json::json!({ "lineType": "dashed", "showSymbol": false });
emit_chart!(serde_json::json!({
    "kind": "line",
    "xLabel": "行数 n（評価は 5n 回）[-]",
    "yLabel": "6 つの指数の RMSE の平均 [-]",
    "xType": "log",
    "yType": "log",
    "dataZoom": true,
    "tooltip": true,
    "series": [
        { "name": "Monte Carlo", "points": curve(0) },
        { "name": "RQMC（8 複製）", "points": curve(1) },
        { "name": "n^(−1/2) の参照線", "points": reference(0.5), "style": dashed },
        { "name": "n^(−1) の参照線", "points": reference(1.0), "style": dashed }
    ]
}));
// Wilson のスコア区間（95%）
let wilson = |p: f64| {
    let z = 1.96_f64;
    let center = (p + z * z / (2.0 * r)) / (1.0 + z * z / r);
    let radius = z * (p * (1.0 - p) / r + z * z / (4.0 * r * r)).sqrt() / (1.0 + z * z / r);
    (center - radius, center + radius)
};
let rows: Vec<_> = (0..sizes.len())
    .map(|s| {
        let rate = covered[s][k] / r;
        let (low, high) = wilson(rate);
        (
            sizes[s] as usize,
            rmse(0, s, k),
            rmse(1, s, k),
            rate,
            low,
            high,
        )
    })
    .collect();
let fixed3 = serde_json::json!({ "fractionDigits": 3 });
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let columns = serde_json::json!([
    { "key": "0", "label": "行数 n", "type": "integer" },
    { "key": "1", "label": "Monte Carlo の RMSE [-]", "type": "number", "format": sci3 },
    { "key": "2", "label": "RQMC の RMSE [-]", "type": "number", "format": sci3 },
    { "key": "3", "label": "RQMC の区間の被覆率 [-]", "type": "number", "format": fixed3 },
    { "key": "4", "label": "Wilson 区間の下端 [-]", "type": "number", "format": fixed3 },
    { "key": "5", "label": "Wilson 区間の上端 [-]", "type": "number", "format": fixed3 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "rmse" })
);
```

既定の入力（$R=20$、シード 1）では、6 つの指数の RMSE の平均は Monte Carlo で 0.052、0.027、0.013 と、$n$ を 4 倍にするごとにほぼ半分になり、$n^{-1/2}$ の参照線に重なる。
RQMC は 0.048、0.016、0.0069 で、$n=256$ では Monte Carlo と変わらないが、その後は $n^{-1/2}$ より速く減り、$n=4096$ では Monte Carlo の約半分になる。
減り方は指数によって違い、$S_2$ の RMSE は RQMC で 0.065、0.012、0.0024 と $n^{-1}$ の参照線より速く減るが、$S_{T1}$ は 0.052、0.021、0.016 と Monte Carlo（0.076、0.046、0.026）の 0.5〜0.7 倍にとどまり、減り方は $n^{-1/2}$ に近い。
RQMC の誤差の減り方は推定量の被積分関数の滑らかさと有効次元で決まるので、同じ点列でも指数ごとに利点の大きさが違う。
RQMC の区間の被覆率は 0.9〜1 で、$R=20$ の Wilson 区間（下端 0.70〜0.84）はどれも 0.95 を含む。
被覆率の差を見分けるには $R$ が足りないので、ここでは区間が大きく外れていないことの確認にとどまる。

## まとめ

Sobol 指数は出力の分散を入力ごとの寄与と交互作用に分けた割合で、Ishigami 関数では $S_3=0$ でも $S_{T3}\approx0.24$ となり、一次の指数だけでは入力の重要さを見誤る。
`sobol_indices_monte_carlo` は pick-freeze 法の $n(d+2)$ 回の評価で一次と全効果の指数を推定し、`sobol_bootstrap` が行の復元抽出による区間を付ける。
`sobol_indices_qmc` は同じ評価回数で多くの指数の誤差を小さくし、複製の標準誤差 `randomized_standard_error` を返す。
推定値は $[0,1]$ に切り詰められないので、0 に近い指数は区間と一緒に読む。
閉形式の値との差は区間の幅と比べ、1 回の推定で外れた区間だけで方法の良し悪しを判断しない。
