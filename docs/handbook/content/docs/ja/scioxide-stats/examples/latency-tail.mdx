サービスの応答遅延では、多くの要求が短い時間で終わる一方で、少数の要求がガベージコレクションや待ち行列の混雑で大きく遅れる。
平均だけでは少数の遅い要求が見えず、P95 や P99 のような分位点だけでは、その先の裾にどれだけ遅い要求があるかが見えない。
このページは混雑の強さと観測数を変えた遅延の標本について、分位点と上側の裾平均（expected shortfall）を `EmpiricalDistribution` で求め、裾の質量が 1 件に満たない水準での推定の限界を確かめる。
後半では遅延をバケットごとの件数に集約した場合に、頻度の重みと質量の重みで何が求まるかを確かめる。

## 分位点と裾平均

観測数 $n$ の遅延の標本で、水準 $p$ の分位点 $q_p$ は、要求の割合 $p$ 以上がこの時間以内に終わる境界である。
有限の標本では分位点の定義が一つに決まらず、Hyndman と Fan（1996）が整理した 9 通りの定義がある。
型 1（`QuantileMethod::NearestRank`）は順位 $\lceil np \rceil$ の観測そのものを返す階段関数で、型 7（`QuantileMethod::Linear`）は 0 始まりの位置 $h = (n-1)p$ の両側の順序統計量を線形補間する。
二つの型は、隣り合う順序統計量が大きく離れた裾で値が分かれる。

分位点関数を $Q(u)$ とすると、上側の裾平均は

$$
\mathrm{ES}_p = \frac{1}{1-p}\int_p^1 Q(u)\,du
$$

で、その先の割合 $1-p$ の要求の平均の遅延である。
分位点が同じでも、裾に極端に遅い要求があれば $\mathrm{ES}_p$ は大きくなる。
有限の標本では、上側の質量 $m = n(1-p)$ が整数とは限らない。
`EmpiricalDistribution::tail_mean` は経験分布の分位点関数で上の積分を正確に評価するので、上位 $\lfloor m \rfloor$ 個の観測をすべて含め、次の観測を端数 $m - \lfloor m \rfloor$ の分だけ含める（[境界の質量の按分](oxref:stats-tail-boundary-mass-apportioning)）。
そのため、裾平均は $p$ について連続に変わる。
境界の値に同じ値の観測が重なるときは、それらをまとめて一つの境界として扱い、必要な質量だけを取る。

`tail_mean` は `TailMeanResult` を返し、平均 `mean` のほかに、裾の質量 `tail_mass`、境界の値 `boundary_value`、境界から取った質量 `boundary_mass` を持つ。
上側の裾で $p = 1$ を求めると裾が空になるので `InvalidInput` を返す。
`EmpiricalDistribution::new` は標本を複製して $O(n \log n)$ で整列し、その後の分位点は $O(1)$、裾平均は $O(n)$ で求まる。

## 遅延の標本と実験

24 ms を中心に周期 17 の正弦で ±4 ms 変わる通常の応答に、4 か所の混雑を加えた標本を作る。
混雑の遅れは強さ `congestion_scale_ms` の 0.55、1.35、0.75、2.0 倍で、位置は観測数 $n$ に比例させて $n/6$、$5n/12$、$3n/4$、$n-3$ 番目に置く。
乱数を使わない決定論的な標本なので、結果は入力だけで決まる。

次のセルは型 1 と型 7 の分位点曲線を描き、選んだ水準の上側の裾を網掛けで示す。
表の上段は代表的な水準の分位点と裾平均、下段は選んだ水準の裾の情報である。
独立な検算として、整列した標本から上位 $\lfloor m \rfloor$ 個と端数の観測の平均を手で計算し、`tail_mean` との差を出す。
型 7 の分位点も整列した標本で位置 $h$ の両側を線形補間して手で求め、差を出す。

```rust
let n = latency_sample_count as usize;
// (位置, 混雑の強さに掛ける倍率)

    (n / 6, 0.55_f64),
    (5 * n / 12, 1.35),
    (3 * n / 4, 0.75),
    (n - 3, 2.0),
];

    { "key": "2", "label": "型 1 [ms]", "type": "number", "format": fixed2 },
```

既定の混雑の強さ 120 ms、$n = 64$ では、P90 は型 1、型 7 とも 27.98 ms で通常の応答の範囲にあるが、上側 10% の裾平均は 111.35 ms になる。
4 件の混雑の遅延はどれも通常の応答より大きく、裾の 6.4 件にすべて入るからである。
P95 では型 1 が 4 番目に遅い要求の 87.89 ms、型 7 が通常の応答との間を補間した 78.91 ms と分かれ、裾平均は 179.74 ms である。
$p = 0.95$ の裾に入れる質量は $64 \times 0.05 = 3.2$ 件で、上位 3 件と境界 87.89 ms の 0.2 件分の平均になる。
手計算との差は 0、型 7 の手計算との差は $2 \times 10^{-13}$ ms で、どちらも丸めの程度である。

$p = 0.99$ にすると、裾の質量は 0.64 件しかなく、裾平均は最大値 261.89 ms そのもので、型 1 の分位点とも一致する。
境界から取った質量も 0.64 件で、この水準の推定値は最も遅い 1 件の値だけで決まる。
型 7 は最大値と 2 番目の値の間を補間して 213.62 ms を返す。

混雑を 0 にすると、分位点も裾平均も 28 ms 以下に収まる。
周期 17 の正弦は同じ値を繰り返すので、$p = 0.95$ の裾の 3.2 件はすべて同値の最大値 27.98 ms から取られ、境界の質量が裾の質量全体の 3.2 件になる。
混雑を 240 ms にすると、P95 の裾平均は 337.61 ms、最大値は 501.89 ms になり、混雑の強さにほぼ比例して伸びる。

観測数を 256 にすると、4 件の混雑の割合が下がるので、P95 の型 1 は 27.98 ms に戻り、裾の 12.8 件のうち 6.8 件を同値の境界から取って裾平均は 70.79 ms になる。
分位点は通常の応答の範囲に戻っても、裾平均には混雑の 4 件がそのまま残る。
観測数 32 では P95 の裾に 1.6 件しか入らず、裾平均 230.85 ms は最大値と 2 番目の値（182.02 ms の 0.6 件分）だけで決まる。

## バケットに集約した遅延の裾平均

可観測性の基盤ではすべての要求の遅延を個別に保存せず、遅延のバケットごとの件数に集約して保管することが多い。
件数をそのまま重みにした標本は、各バケットの代表値を件数だけ並べた標本と同じ経験分布を持つ。
scioxide-stats の重みの型は、この標本の意味を二通りに区別する。

- `Frequency`（`Weights::<_, Frequency>::new(&counts)`、`u64` の件数）は、件数を観測の独立反復数とみなす。
  分位点は複製した標本に対する Hyndman–Fan の 9 通りの定義をすべて受け付ける。
  一方、`tail_mean` は `TailWeights`（`Unweighted` と `Mass`）にしか定義されておらず、`Frequency` の分布では呼べない。
- `Mass`（`Weights::<_, Mass>::new(&masses)`、`f64` の質量）は、重みを確率質量の相対値とみなす。
  分位点は重み付き経験分布の逆関数（`QuantileRule::<Mass>::inverse_ecdf()`、型 1 に当たる）だけを受け付け、`tail_mean` は上と同じ按分で求まる。

したがって、件数から裾平均を求めるには、件数を `f64` の質量に変換して `Mass` の分布を作る。
整数の件数を質量にしても経験分布は変わらないので、裾平均は複製した標本の値と一致する。
構築はバケット数 $K$ について $O(K \log K)$ の整列で、裾平均は $O(K)$ で求まり、要求の件数 $W$ には依存しない。

次のセルは 5 個のバケット（代表値 12、25、48、120、350 ms、件数 8500、1200、250、45、5、合計 $W = 10000$ 件）について、選んだ水準の分位点と上側の裾平均を三つの経路で求める。
件数を複製した 10000 件の標本を `Unweighted` で扱う経路は、重みの扱いを別の方法で確かめる検算である。
さらに、上側の質量 $(1-p)W$ を最も遅いバケットから順に取る計算を手で書き、裾平均と比べる。
`Frequency` の行の裾平均と `Mass` の行の型 7 は、API が提供しないので未定義として表示する。

```rust
let p = QuantileProbability::new(bucket_tail_probability).map_err(|e| e.to_string())?;
let (first, seventh) = (QuantileMethod::NearestRank, QuantileMethod::Linear);
// 頻度の重み: 分位点は 9 通りの定義を受け付けるが、裾平均は定義されていない。
let by_count =
    EmpiricalDistribution::new(&latencies, Weights::<_, Frequency>::new(&counts[..]))
        .map_err(|e| e.to_string())?;
let count_q1 = by_count.quantile(p, QuantileRule::new(first));
let count_q1 = count_q1.map_err(|e| e.to_string())?.value();
let count_q7 = by_count.quantile(p, QuantileRule::new(seventh));
let count_q7 = count_q7.map_err(|e| e.to_string())?.value();
// 質量の重み: 件数を f64 の質量にすると裾平均が求まる。
let masses: Vec<f64> = counts.iter().map(|&c| c as f64).collect();
let by_mass = EmpiricalDistribution::new(&latencies, Weights::<_, Mass>::new(&masses[..]))
    .map_err(|e| e.to_string())?;
let mass_q = by_mass.quantile(p, QuantileRule::<Mass>::inverse_ecdf());
let mass_q = mass_q.map_err(|e| e.to_string())?.value();
let mass_tail = by_mass
    .tail_mean(p, TailSide::Upper)
    .map_err(|e| e.to_string())?;
// 検算 1: 件数だけ複製した標本を重みなしで扱う。
let expanded: Vec<f64> = latencies
    .iter()
    .zip(counts)
    .flat_map(|(&x, c)| std::iter::repeat_n(x, c as usize))
    .collect();
let plain = EmpiricalDistribution::new(&expanded, Unweighted).map_err(|e| e.to_string())?;
let plain_q1 = plain.quantile(p, QuantileRule::new(first));
let plain_q1 = plain_q1.map_err(|e| e.to_string())?.value();
let plain_q7 = plain.quantile(p, QuantileRule::new(seventh));
let plain_q7 = plain_q7.map_err(|e| e.to_string())?.value();
let plain_tail = plain
    .tail_mean(p, TailSide::Upper)
    .map_err(|e| e.to_string())?;
// 検算 2: 上側の質量 (1 − p)W を最も遅いバケットから順に取る。
let mut remaining = (1.0 - bucket_tail_probability) * masses.iter().sum::<f64>();
let tail_weight = remaining;
let mut tail_sum = 0.0;
for (&x, &w) in latencies.iter().zip(&masses).rev() {
    let take = w.min(remaining);
    tail_sum += take * x;
    remaining -= take;
}
let fixed2 = serde_json::json!({ "fractionDigits": 2 });
let columns = serde_json::json!([
    { "key": "0", "label": "経路" },
    { "key": "1", "label": "型 1 [ms]", "type": "number", "format": fixed2, "nullText": "—" },
    { "key": "2", "label": "型 7 [ms]", "type": "number", "format": fixed2, "nullText": "—" },
    { "key": "3", "label": "裾平均 [ms]", "type": "number", "format": fixed2, "nullText": "—" },
    { "key": "4", "label": "境界の値 [ms]", "type": "number", "format": fixed2, "nullText": "—" },
    { "key": "5", "label": "境界の質量 [件]", "type": "number", "format": fixed2, "nullText": "—" }
]);
let rows = vec![
    (
        "Frequency（件数）",
        Some(count_q1),
        Some(count_q7),
        None,
        None,
        None,
    ),
    (
        "Mass（件数を質量に変換）",
        Some(mass_q),
        None,
        Some(mass_tail.mean()),
        Some(mass_tail.boundary_value()),
        mass_tail.boundary_mass(),
    ),
    (
        "複製した標本（Unweighted）",
        Some(plain_q1),
        Some(plain_q7),
        Some(plain_tail.mean()),
        Some(plain_tail.boundary_value()),
        plain_tail.boundary_mass(),
    ),
    (
        "手計算（遅いバケットから）",
        None,
        None,
        Some(tail_sum / tail_weight),
        None,
        None,
    ),
];
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "buckets" })
);
```

既定の $p = 0.99$ では、裾は $(1-p)W = 100$ 件で、350 ms の 5 件、120 ms の 45 件、48 ms のバケットの 50 件から成る。
裾平均は $(5 \times 350 + 45 \times 120 + 50 \times 48)/100 = 95.50$ ms で、`Mass` の経路、複製した 10000 件の標本、手計算の三つが表示した桁で一致する。
P99 は型 1、型 7 とも 48 ms で、一つのバケットの中に分位点の位置が入るので二つの型は分かれない。

$p = 0.999$ では裾が 10 件になり、350 ms の 5 件と 120 ms の 5 件の平均 235.00 ms、P99.9 は 120 ms になる。
$p = 0.9$ では裾の 1000 件が 25 ms のバケットの 700 件まで及び、裾平均は 36.65 ms である。

$p = 0.85$ では、型 7 の位置 $h = 9999 \times 0.85 = 8499.15$ が 12 ms のバケットの最後の観測と 25 ms のバケットの最初の観測の間に入り、型 7 は 13.95 ms、型 1 は 12 ms と分かれる。
このとき `Mass` の経路の境界は 12 ms で、境界の質量は $2.2 \times 10^{-13}$ 件になる。
$1 - 0.85$ は 2 進の浮動小数点で $0.15000000000000002$ に丸められ、裾の質量が 1500 件をわずかに超えるので、その超過分を 12 ms のバケットから取っている。
裾平均 32.77 ms への影響は丸めの程度である。

バケットの代表値は、本来はバケットの区間に広がる遅延を一つの値に置き換えたものである。
代表値に区間の上端を使えば各遅延を大きめに、下端を使えば小さめに置き換えるので、裾平均はその向きに偏る。
バケットの幅が裾の値に比べて広いときは、代表値の選び方による違いも併せて返す。

## まとめ

分位点は裾の始まりの位置、裾平均はその先の平均の大きさを表し、少数の極端に遅い要求は分位点より裾平均に強く現れる。
返す分位点には型の番号を添え、型 1 と型 7 で値が大きく違う水準では、観測の間を補間しているかどうかを確かめる。
裾に入る質量 $n(1-p)$ が数件しかない水準では、裾平均は最大値付近の少数の観測で決まり、標本ごとのばらつきが大きいので、その水準で十分な件数が裾に入るだけの観測数を集める。
バケットに集約した件数から裾平均を求めるときは、件数を `Mass` の質量に変換し、結果がバケットの代表値の選び方に依存することを添えて返す。
