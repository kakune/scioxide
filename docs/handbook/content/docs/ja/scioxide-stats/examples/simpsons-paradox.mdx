2 つの治療の成功率を比べるとき、患者の背景で層に分けるとどの層でも治療 A が良いのに、層を合算すると治療 B が良く見えることがある。
この逆転を Simpson のパラドックスと呼ぶ（E. H. Simpson, *J. R. Stat. Soc. B* 13 (1951), 238–241）。
逆転が起きるのは、結果に影響する第 3 の変数（交絡因子）が、治療の割り付けとも関係しているときである。
このページでは、腎結石の治療成績の実データで逆転を再現し、層ごとのオッズ比、層をまたいだ共通オッズ比、割り付けを変えた仮想の実験で、どの比較が何を答えるかを調べる。

## 腎結石の治療成績

C. R. Charig, D. R. Webb, S. R. Payne and J. E. A. Wickham, "Comparison of treatment of renal calculi by open surgery, percutaneous nephrolithotomy, and extracorporeal shockwave lithotripsy", *BMJ* 292 (1986), 879–882 は、腎結石の治療成績を結石の直径 2 cm で層に分けて返した。
S. A. Julious and M. A. Mullee, *BMJ* 309 (1994), 1480–1481 がこの表を Simpson のパラドックスの例として取り上げた。
以下では開腹手術を治療 A、経皮的腎砕石術（PCNL）を治療 B と呼ぶ。

| 層 | 治療 A（開腹手術） | 治療 B（PCNL） |
|---|---|---|
| 小さい結石（2 cm 未満） | 81/87（93%） | 234/270（87%） |
| 大きい結石（2 cm 以上） | 192/263（73%） | 55/80（69%） |
| 合算 | 273/350（78%） | 289/350（83%） |

どちらの層でも A の成功率が高いが、合算では B が高い。
A は治療の難しい大きい結石に多く使われ（350 人中 263 人）、B は易しい小さい結石に多く使われた（350 人中 270 人）。
結石の大きさは成功率にも割り付けにも関係するので、交絡因子である。

この研究は無作為化試験ではなく、治療は医師が選んだ。
結石の大きさ以外の交絡因子（結石の位置や数、患者の状態）は表にないので、層別しても治療の因果効果が得られるとは限らない。
以下で求める調整済みの値は、「結石の大きさをそろえて比べた関連」である。

定義のブロックには表を行優先の 2 × 2 の度数（行が治療 A・B、列が成功・失敗）で置く。
共通オッズ比の Mantel–Haenszel 推定と Woolf の標準誤差は、`scioxide-stats` が提供しないので、閉形式で計算する補助関数として置く。

```rust
//| id: stats-simpsons-paradox-data
//| kind: definitions
//| title: Charig ら（1986）の腎結石の表と閉形式の補助関数
//| crates: [scioxide-core, scioxide-stats]
use scioxide_core::RealScalar;

/// 小さい結石の層: [A 成功, A 失敗, B 成功, B 失敗]。
pub(crate) const SMALL: [usize; 4] = [81, 6, 234, 36];
/// 大きい結石の層。
pub(crate) const LARGE: [usize; 4] = [192, 71, 55, 25];

/// 層の度数を足し合わせた表。
pub(crate) fn pooled(strata: &[[usize; 4]]) -> [usize; 4] {
    let mut total = [0; 4];
    for table in strata {
        for (sum, &count) in total.iter_mut().zip(table) {
            *sum += count;
        }
    }
    total
}

/// Woolf の対数オッズ比の標準誤差 √(1/a + 1/b + 1/c + 1/d)。
pub(crate) fn woolf_se(table: &[usize; 4]) -> f64 {
    let sum: f64 = table.iter().map(|&count| 1.0 / count as f64).sum();
    RealScalar::sqrt(sum)
}

/// Mantel–Haenszel の共通オッズ比 Σ aᵢdᵢ/nᵢ ÷ Σ bᵢcᵢ/nᵢ。
pub(crate) fn mantel_haenszel(strata: &[[usize; 4]]) -> f64 {
    let (mut numerator, mut denominator) = (0.0, 0.0);
    for &[a, b, c, d] in strata {
        let n = (a + b + c + d) as f64;
        numerator += (a * d) as f64 / n;
        denominator += (b * c) as f64 / n;
    }
    numerator / denominator
}
```

## 層ごとの比較と合算の比較

2 × 2 表 $\begin{pmatrix} a & b \\ c & d \end{pmatrix}$（行が治療 A・B、列が成功・失敗）の成功率は $p_A = a/(a+b)$、$p_B = c/(c+d)$ である。
効果の尺度として、次の 3 つを使う。

- 成功率の差 $p_A - p_B$。
- 成功率の比（相対リスク）$\mathrm{RR} = p_A / p_B$。
  `relative_risk` が返す。
- オッズ比 $\mathrm{OR} = ad/(bc)$。
  `odds_ratio` が返し、$ad = 0$ なら 0、$bc = 0$ なら $+\infty$、両方 0 なら `InvalidInput` である。

対数オッズ比の標準誤差は、Woolf の式 $\sqrt{1/a + 1/b + 1/c + 1/d}$ で近似でき、95% 区間は $\exp(\ln\mathrm{OR} \pm 1.96\,\mathrm{SE})$ になる。
`scioxide-stats` はオッズ比の区間を返さないので、Woolf の区間は補助関数で計算し、次の節でロジスティック回帰の Wald 区間と照合する。

独立性の検定には 2 つを使う。
`power_divergence_contingency_test(table, CressieReadParameter::PEARSON, ContinuityCorrection::None)` は Pearson の $\chi^2 = n(ad-bc)^2 / \{(a+b)(c+d)(a+c)(b+d)\}$ を求め、自由度 1 の $\chi^2$ 分布の上側確率（漸近）を p 値にする。
ワンショット呼び出しの `chi2_contingency_test` は同じ統計量に Yates の連続性補正（`ContinuityCorrection::HalfUnit`）を掛けるので、閉形式と照合するこのページでは補正しない形を使う。
`fisher_exact_test(table)` は、行と列の合計を固定した超幾何分布で、観測した表以下の確率を持つ表の確率を合計した両側の正確な p 値を返す。

下のセルは、2 つの層と合算の表について、成功率、3 つの効果の尺度、Woolf の区間、2 つの検定を表にし、成功率を棒グラフで並べる。

```rust
//| id: stats-simpsons-paradox-api-1
//| ref: stats-simpsons-paradox-api-1
//| title: 層ごとと合算の分割表
//| run: reactive
//| uses: [stats-simpsons-paradox-data]
//| crates: [scioxide-core, scioxide-stats]
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"tables","path":"/rows/0/2","approx":{"value":0.931034,"atol":1e-6}}
//|       - {"artifact":"tables","path":"/rows/2/3","approx":{"value":0.825714,"atol":1e-6}}
//|       - {"artifact":"tables","path":"/rows/0/6","approx":{"value":2.076923,"atol":1e-6}}
//|       - {"artifact":"tables","path":"/rows/1/6","approx":{"value":1.229193,"atol":1e-6}}
//|       - {"artifact":"tables","path":"/rows/2/6","approx":{"value":0.748349,"atol":1e-6}}
//|       - {"artifact":"tables","path":"/rows/0/7","approx":{"value":0.84404,"atol":1e-5}}
//|       - {"artifact":"tables","path":"/rows/0/8","approx":{"value":5.11065,"atol":1e-4}}
//|       - {"artifact":"tables","path":"/rows/0/9","approx":{"value":2.626207,"atol":1e-6}}
//|       - {"artifact":"tables","path":"/rows/2/9","approx":{"value":2.310588,"atol":1e-6}}
use scioxide_stats::{
    ContingencyView, ContinuityCorrection, CressieReadParameter, fisher_exact_test, odds_ratio,
    power_divergence_contingency_test, relative_risk,
};

let total = pooled(&[SMALL, LARGE]);
let tables = [
    ("小さい結石", SMALL),
    ("大きい結石", LARGE),
    ("合算", total),
];
let mut rows = Vec::new();
let mut rates = [Vec::new(), Vec::new()];
for (name, counts) in tables {
    let table = ContingencyView::new(&counts, 2, 2).map_err(|e| e.to_string())?;
    let [a, b, c, d] = counts.map(|count| count as f64);
    let (p_a, p_b) = (a / (a + b), c / (c + d));
    let or = odds_ratio(table).map_err(|e| e.to_string())?;
    // 独立検算: Woolf の 95% 区間 exp(ln OR ± 1.96 SE)（閉形式）
    let half = 1.959964 * woolf_se(&counts);
    let pearson = power_divergence_contingency_test(
        table,
        CressieReadParameter::PEARSON,
        ContinuityCorrection::None,
    )
    .map_err(|e| e.to_string())?;
    let fisher = fisher_exact_test(table).map_err(|e| e.to_string())?;
    rows.push((
        name,
        counts[0] + counts[1],
        p_a,
        p_b,
        p_a - p_b,
        relative_risk(table).map_err(|e| e.to_string())?,
        or,
        or * scioxide_core::RealScalar::exp(-half),
        or * scioxide_core::RealScalar::exp(half),
        pearson.statistic(),
        pearson.p_value(),
        fisher.p_value(),
    ));
    rates[0].push(p_a);
    rates[1].push(p_b);
}

let fixed4 = serde_json::json!({ "fractionDigits": 4 });
let columns = serde_json::json!([
    { "key": "0", "label": "表" },
    { "key": "1", "label": "A の人数 [人]", "type": "integer" },
    { "key": "2", "label": "A の成功率 [-]", "type": "number", "format": fixed3 },
    { "key": "3", "label": "B の成功率 [-]", "type": "number", "format": fixed3 },
    { "key": "4", "label": "成功率の差 [-]", "type": "number", "format": fixed3 },
    { "key": "5", "label": "相対リスク [-]", "type": "number", "format": fixed3 },
    { "key": "6", "label": "オッズ比 [-]", "type": "number", "format": fixed3 },
    { "key": "7", "label": "Woolf 95% 区間の下端 [-]", "type": "number", "format": fixed3 },
    { "key": "8", "label": "Woolf 95% 区間の上端 [-]", "type": "number", "format": fixed3 },
    { "key": "9", "label": "Pearson χ² [-]", "type": "number", "format": fixed3 },
    { "key": "10", "label": "χ² の p 値 [-]", "type": "number", "format": fixed4 },
    { "key": "11", "label": "Fisher の p 値 [-]", "type": "number", "format": fixed4 }
]);
emit_table_with_columns!(

    rows,
    metadata = serde_json::json!({ "id": "tables" })
);
emit_chart!(serde_json::json!({
    "kind": "bar",
    "xLabel": "表",
    "yLabel": "成功率 [-]",
    "yMin": 0.0,
    "yMax": 1.0,
    "tooltip": true,
    "categories": ["小さい結石", "大きい結石", "合算"],
    "series": [

    ]

```

小さい結石の層のオッズ比は $81 \cdot 36 / (6 \cdot 234) = 2.077$、大きい結石の層は $192 \cdot 25 / (71 \cdot 55) = 1.229$ で、どちらも 1 を超える（A が良い）。
合算の表のオッズ比は $273 \cdot 61 / (77 \cdot 289) = 0.748$ で、1 を下回る（B が良い）。
表の値はこの手計算と小数第 6 位まで一致する。

どの表でも Woolf の 95% 区間は 1 を含む（小さい結石 0.84〜5.11、大きい結石 0.71〜2.12、合算 0.51〜1.09）。
Pearson の $\chi^2$ は 2.63、0.55、2.31（p 値 0.105、0.458、0.128）で、Fisher の正確検定の p 値も 0.127、0.479、0.154 である。
つまり、この表では層ごとの差も合算の差も、それだけでは偶然の範囲と区別できない。
Simpson のパラドックスは有意性の問題ではなく、どの比較を問うかの問題である。
合算の比較は「A を受けた患者と B を受けた患者の成績の違い」に答え、層ごとの比較は「同じ大きさの結石で治療を変えたときの違い」に答える。
治療の選択に必要なのは後者である。

## 結石の大きさで調整したオッズ比

層をまたいで共通のオッズ比を推定する方法は 2 つある。

1 つは Mantel–Haenszel 推定 $\widehat{\mathrm{OR}}_{\mathrm{MH}} = \sum_k a_k d_k / n_k \big/ \sum_k b_k c_k / n_k$ で、層 $k$ の表の度数だけから閉形式で求まる。
この表では $(8.168 + 13.994) / (3.933 + 11.385) = 1.447$ である。
Robins–Breslow–Greenland の分散で作る 95% 区間は 0.92〜2.29、Cochran–Mantel–Haenszel 検定の統計量は 2.43（自由度 1、p = 0.12）になる（Agresti, *Categorical Data Analysis*, 3rd ed., 2013, §6.4）。
`scioxide-stats` は Mantel–Haenszel の推定と検定、Breslow–Day の均一性検定を提供しない。

もう 1 つは、層を説明変数に入れたロジスティック回帰である。
治療 A の指示変数を $z_A$、大きい結石の指示変数を $z_L$ として

$$
\operatorname{logit} P(\text{成功}) = \beta_0 + \beta_A z_A + \beta_L z_L
$$

を当てはめると、$\exp(\beta_A)$ は、結石の大きさを固定したときのオッズ比（層の間で等しいと仮定した共通オッズ比）の最尤推定になる。
`PreparedGlm` に `GlmFamily::Binomial` を指定し、4 つの（層、治療）の組を 1 行ずつ、応答を成功の割合、`trials` を人数として渡す。
GLM は反復重み付き最小二乗（IRLS）で解き、収束すると `GlmReport::termination` が `Converged` になる。
`coefficient_inference` は Fisher 情報の逆行列から Wald の標準誤差、両側 p 値 $2\{1-\Phi(|\hat\beta|/\mathrm{SE})\}$、区間 $\hat\beta \pm z\,\mathrm{SE}$ を返す（漸近）。

このモデルの残差逸脱度は、層ごとにオッズ比が違う飽和モデル（4 行に 4 係数）との尤度比統計量である。
自由度 $4 - 3 = 1$ の $\chi^2$ と比べると、オッズ比が層の間で等しいかの検定になる。
`GlmFitView::degrees_of_freedom` は有効標本数から係数の数を引いた値を返し、二項分布の行では有効標本数が試行数の和（ここでは 700）になる。
この値は Pearson の散らばりの推定 $X^2/(n_{\mathrm{eff}} - p)$ に使う自由度で、まとめた行の逸脱度を比べる自由度（行数 − 係数の数）とは違うので、セルでは後者を直接計算する。
$z_L$ を除いたモデル（治療だけ）は、合算した表と同じ十分統計量を持つので、$\exp(\hat\beta_A)$ は合算の表のオッズ比 0.748 に、標準誤差は合算の表の Woolf の値に一致する。
下のセルはこの 2 つのモデルを当てはめ、閉形式の値と並べる。

```rust
//| id: stats-simpsons-paradox-api-2
//| ref: stats-simpsons-paradox-api-2
//| title: ロジスティック回帰で結石の大きさを調整する
//| run: reactive
//| uses: [stats-simpsons-paradox-data]
//| crates: [scioxide-core, scioxide-linalg, scioxide-random, scioxide-stats]
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"models","path":"/rows/0/1","approx":{"value":0.748349,"atol":1e-6}}
//|       - {"artifact":"models","path":"/rows/0/2","approx":{"value":0.514605,"atol":1e-5}}
//|       - {"artifact":"models","path":"/rows/1/1","range":{"min":1.3,"max":1.6}}
//|       - {"artifact":"models","path":"/rows/1/1","approx":{"value":1.429363,"atol":1e-5}}
//|       - {"artifact":"models","path":"/rows/0/6","range":{"max":1e-6}}
//|       - {"artifact":"models","path":"/rows/1/6","approx":{"value":0.3153,"atol":1e-3}}
//|       - {"artifact":"models","path":"/rows/1/7","equals":"Converged"}
//|       - {"artifact":"checks","path":"/rows/0/3","range":{"max":1e-8}}
//|       - {"artifact":"checks","path":"/rows/1/3","range":{"max":1e-6}}
//|       - {"artifact":"checks","path":"/rows/2/2","approx":{"value":1.446847,"atol":1e-6}}
//|       - {"path":"/outputs/2/state","equals":"satisfied"}
use scioxide_linalg::Matrix;
use scioxide_random::{ChiSquared, Survival};
use scioxide_stats::{
    ConfidenceProbability, ContingencyView, GlmCovariance, GlmFamily, GlmInputs, GlmOptions,
    GlmStorageOptions, PreparedGlm, Unweighted, odds_ratio,
};

// 行: (小, A), (小, B), (大, A), (大, B)。列: 切片, z_A, z_L
let layout = [
    (SMALL, 0, 1.0, 0.0),
    (SMALL, 2, 0.0, 0.0),
    (LARGE, 0, 1.0, 1.0),
    (LARGE, 2, 0.0, 1.0),
];
let trials: Vec<u64> = layout
    .iter()
    .map(|&(t, row, _, _)| (t[row] + t[row + 1]) as u64)
    .collect();
let response: Vec<f64> = layout
    .iter()
    .map(|&(t, row, _, _)| t[row] as f64 / (t[row] + t[row + 1]) as f64)
    .collect();
let confidence = ConfidenceProbability::new(0.95).map_err(|e| e.to_string())?;
let options = GlmOptions::default();
let mut rows = Vec::new();
let mut estimates = Vec::new();
let mut adjusted_report = None;
for (name, columns) in [("治療のみ", 2), ("治療 + 結石の大きさ", 3)] {
    let mut values = Vec::new();
    for &(_, _, z_a, z_l) in &layout {
        values.extend_from_slice(&[1.0, z_a, z_l][..columns]);
    }
    let design = Matrix::from_vec(4, columns, values).map_err(|e| e.to_string())?;
    let plan = PreparedGlm::new(
        design.view(),
        GlmFamily::Binomial,
        Unweighted,
        Some(trials.as_slice()),
        None,
        None,
        GlmStorageOptions::new(),
    )
    .map_err(|e| e.to_string())?;
    let result = plan
        .fit(GlmInputs::new(&response, options))
        .map_err(|e| e.to_string())?;
    let report = *result.report();
    let fit = result.fit().ok_or("当てはめの値がない")?;
    let inference = plan
        .coefficient_inference(&response, &fit, GlmCovariance::Model, confidence)
        .map_err(|e| e.to_string())?;
    let treatment = inference[1];
    // 逸脱度の自由度は行数 − 係数の数。degrees_of_freedom() は Σ 試行数 − 係数の数を返す
    let df = (4 - columns) as f64;
    let deviance_p = ChiSquared::<f64>::new(df)
        .and_then(|law| law.sf(fit.deviance()))
        .map_err(|e| e.to_string())?;
    rows.push((
        name,
        scioxide_core::RealScalar::exp(treatment.estimate()),
        scioxide_core::RealScalar::exp(treatment.interval().lower()),
        scioxide_core::RealScalar::exp(treatment.interval().upper()),
        treatment.p_value(),
        fit.deviance(),
        deviance_p,
        format!("{:?}", report.termination),
    ));
    estimates.push((treatment.estimate(), treatment.standard_error()));
    adjusted_report = Some(report);
}

// 独立検算: 合算の表の ln OR と Woolf の SE、Mantel–Haenszel の共通オッズ比（閉形式）
let total = pooled(&[SMALL, LARGE]);
let pooled_or = odds_ratio(ContingencyView::new(&total, 2, 2).map_err(|e| e.to_string())?)
    .map_err(|e| e.to_string())?;
let mh = mantel_haenszel(&[SMALL, LARGE]);
let adjusted_or = scioxide_core::RealScalar::exp(estimates[1].0);
let checks = vec![
    (
        "治療のみの β̂_A と ln（合算の OR）",
        estimates[0].0,
        scioxide_core::RealScalar::ln(pooled_or),
    ),
    (
        "治療のみの SE と合算の表の Woolf の SE",
        estimates[0].1,
        woolf_se(&total),
    ),
    (
        "調整済み OR（最尤）と Mantel–Haenszel の OR",
        adjusted_or,
        mh,
    ),
];
let checks: Vec<_> = checks
    .into_iter()
    .map(|(name, glm, closed)| (name, glm, closed, (glm - closed).abs()))
    .collect();

let fixed3 = serde_json::json!({ "fractionDigits": 3 });
let fixed4 = serde_json::json!({ "fractionDigits": 4 });
let sci3 = serde_json::json!({ "notation": "scientific", "significantDigits": 3 });
let model_columns = serde_json::json!([
    { "key": "0", "label": "モデル" },
    { "key": "1", "label": "A のオッズ比 exp(β̂_A) [-]", "type": "number", "format": fixed4 },
```

治療だけのモデルのオッズ比は合算の表の 0.748 と一致し、標準誤差 0.1911 も Woolf の式と丸めの水準（差 $10^{-15}$ 程度）で一致する。
このモデルの残差逸脱度は 30.8（自由度 2）で、結石の大きさを無視したモデルは 4 行の成功率を説明できない。
結石の大きさを加えると、A のオッズ比は 1.429（95% 区間 0.91〜2.24、p = 0.119）になり、1 を超える側へ移る。
Mantel–Haenszel 推定 1.447 との差は 0.017 である。
2 つは同じ共通オッズ比を別の方法（最尤推定と層の重み付きの比）で推定するので、値は一致しない。
調整済みの区間も 1 を含むので、この表だけからは「大きさをそろえると A が良い」とも断定できない。

調整したモデルの残差逸脱度 1.01（自由度 1、p = 0.32）は、層ごとのオッズ比 2.08 と 1.23 の違いを検定する。
p 値が大きいことは、共通オッズ比の仮定と矛盾しないことを示すだけで、オッズ比が等しいことの証明ではない。

## 割り付けを変えると合算はどう動くか

逆転の原因が割り付けの偏りであることは、割り付けだけを変える仮想の実験で確かめられる。
下のセルは、治療 B の割り付け（小さい結石 270 人、大きい結石 80 人）と、各層・各治療の成功率を表のまま固定し、治療 A の 350 人のうち小さい結石の人数 $m$ だけを変える。
各層の成功数は人数に表の成功率を掛けて四捨五入する。

$m$ を変えても層ごとの成功率は変わらないが、A の合算の成功率は $p_A(m) = \{m \cdot 81/87 + (350-m) \cdot 192/263\}/350$ と動く。
観測された $m = 87$ では合算のオッズ比が 1 を下回る。
$m = 270$（A と B で結石の大きさの構成が同じ）では交絡がなくなり、合算の成功率の差は層ごとの差の重み付き平均になる。
ただし、オッズ比は合算すると層ごとの値の平均にならない（非崩壊性、Greenland, Robins and Pearl, *Statistical Science* 14 (1999), 29–46）。
交絡がなくても、合算のオッズ比は層ごとのオッズ比より 1 に近い値になりうる。

```rust
//| id: stats-simpsons-paradox-calc
//| ref: stats-simpsons-paradox-calc
//| title: A の割り付けと合算のオッズ比
//| run: reactive
//| uses: [stats-simpsons-paradox-data]
//| crates: [scioxide-stats]
//| inputs:
//|   small_a: {"type":"range","label":"A のうち小さい結石の人数 m [人]","description":"A の合計 350 人のうち、小さい結石の患者の数。観測値は 87。","min":10,"max":340,"step":1,"value":87}
//| cases:
//|   - {"id":"balanced","label":"m = 270（B と同じ構成）","description":"交絡がなく、合算でも A が良い。","inputs":{"small_a":270}}
//|   - {"id":"threshold","label":"m = 170","description":"合算の成功率が A と B で等しくなり、合算のオッズ比が 1 になる。","inputs":{"small_a":170}}
//|   - {"id":"extreme","label":"m = 10","description":"A がほぼ大きい結石だけになり、逆転が強まる。","inputs":{"small_a":10}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"allocation","path":"/rows/0/4","approx":{"value":0.748349,"atol":1e-6}}
//|       - {"artifact":"allocation","path":"/rows/0/2","approx":{"value":2.076923,"atol":1e-6}}
//|   - case: balanced
//|     expect:
//|       - {"artifact":"allocation","path":"/rows/0/4","approx":{"value":1.590767,"atol":1e-5}}
//|       - {"artifact":"allocation","path":"/rows/0/5","approx":{"value":0.057143,"atol":1e-5}}
//|   - case: threshold
//|     expect:
//|       - {"artifact":"allocation","path":"/rows/0/4","approx":{"value":1.0,"atol":1e-12}}
//|       - {"artifact":"allocation","path":"/rows/0/5","approx":{"value":0.0,"atol":1e-12}}
//|   - case: extreme
//|     expect:
//|       - {"artifact":"allocation","path":"/rows/0/4","approx":{"value":0.583287,"atol":1e-5}}
//|       - {"artifact":"allocation","path":"/rows/0/2","approx":{"value":1.384615,"atol":1e-5}}
use scioxide_stats::{ContingencyView, odds_ratio};

// m 人を小さい結石に割り付けたときの A の層別の表と、B の層を合わせた合算の表
let tables = |m: usize| -> Result<[[usize; 4]; 3], String> {
    let small_success = (m as f64 * 81.0 / 87.0).round() as usize;
    let large = 350 - m;
    let large_success = (large as f64 * 192.0 / 263.0).round() as usize;
    let small = [small_success, m - small_success, SMALL[2], SMALL[3]];
    let large = [large_success, large - large_success, LARGE[2], LARGE[3]];
    Ok([small, large, pooled(&[small, large])])
};
let ratio = |counts: &[usize; 4]| -> Result<f64, String> {
    let table = ContingencyView::new(counts, 2, 2).map_err(|e| e.to_string())?;
    odds_ratio(table).map_err(|e| e.to_string())
};

let m = small_a as usize;
let [small, large, total] = tables(m)?;
let rate = |t: &[usize; 4], row: usize| t[row] as f64 / (t[row] + t[row + 1]) as f64;
let rows = vec![(
    m,
    rate(&total, 0),
    ratio(&small)?,
    ratio(&large)?,
    ratio(&total)?,
    rate(&total, 0) - rate(&total, 2),
)];
let fixed3 = serde_json::json!({ "fractionDigits": 3 });
let columns = serde_json::json!([
    { "key": "0", "label": "m [人]", "type": "integer" },
    { "key": "1", "label": "A の合算の成功率 [-]", "type": "number", "format": fixed3 },
    { "key": "2", "label": "小さい結石の OR [-]", "type": "number", "format": fixed3 },
    { "key": "3", "label": "大きい結石の OR [-]", "type": "number", "format": fixed3 },
    { "key": "4", "label": "合算の OR [-]", "type": "number", "format": fixed3 },
    { "key": "5", "label": "合算の成功率の差 A − B [-]", "type": "number", "format": fixed3 }
]);
emit_table_with_columns!(
    columns,
    rows,
    metadata = serde_json::json!({ "id": "allocation" })
);

let mut curve = Vec::new();
for value in 10..=340 {
    let [_, _, pooled_table] = tables(value)?;
    curve.push([value as f64, ratio(&pooled_table)?]);
}
let crossing = curve
    .iter()
    .find(|point| point[1] >= 1.0)
    .map(|point| point[0])
    .ok_or("合算の OR が 1 を超えない")?;
emit_chart!(serde_json::json!({

    "dataZoom": true,

    "layers": [
        {
            "id": "pooled",
            "kind": "line",
            "name": "合算の OR",
            "points": curve,
            "style": { "showSymbol": false }
        },

            "points": [[m as f64, ratio(&total)?]]
        }

        { "kind": "line", "axis": "y", "value": 1.0, "label": "OR = 1" },

            "kind": "line",
```

既定の $m = 87$ では、合算のオッズ比は表と同じ 0.748 である。
$m$ を増やすと合算のオッズ比はほぼ単調に増え、$m = 170$ で 1（合算の成功率がともに 0.826）になり、それより大きい $m$ では 1 を超える。
$m = 270$ では合算のオッズ比が 1.59、合算の成功率の差が 0.057 になり、逆転は消える。
このとき合算のオッズ比は層ごとの 2.03 と 1.20 の間にある。
$m = 10$ では合算のオッズ比が 0.58 まで下がる。
層ごとのオッズ比は四捨五入のために $m$ によって揺れ、A の小さい結石が 10 人しかいない $m = 10$ では失敗が 1 人になって、小さい結石の層のオッズ比は 1.38 になる。

## まとめ

Charig らの腎結石の表では、結石の大きさの 2 つの層でどちらも開腹手術のオッズ比が 1 を超え（2.08 と 1.23）、合算すると 0.748 に逆転する。
逆転の原因は割り付けの偏りであり、A の構成を B にそろえる仮想の実験で逆転が消えることを確かめた。
治療の比較には、層ごとの比較か、結石の大きさで調整した共通オッズ比（Mantel–Haenszel 1.447、ロジスティック回帰の最尤推定 1.429）を使う。
`scioxide-stats` は Mantel–Haenszel の推定と検定を提供しないので、閉形式で計算するか、`PreparedGlm` で層を説明変数に入れる。
この表ではどの区間も 1 を含み、観察研究なので測っていない交絡因子も残る。
