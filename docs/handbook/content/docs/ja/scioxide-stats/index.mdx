`scioxide-stats` は、観測から統計量を推定し、その不確かさを返すクレートである。
扱う計算は大きく二つの様式に分かれる。
一つは標本を保持しない**逐次集計**で、平均・分散・高次の中心モーメント・共分散を観測ごとに更新し、別々に集計した結果を結合する。
もう一つは標本を保持する**経験分布**の計算で、整列や選択によって分位点・順位・裾平均・経験分布関数・核密度を求める。

その上に、平均の信頼区間、古典的な検定と分布の検定、分割表と多重検定、回帰と一般化線形モデル、リサンプリングと検出力、分布の当てはめ、裾確率による母数の逆算と正確な信頼限界、共役事後分布と MCMC の診断、生存時間解析、時系列、多変量の推定、大域的感度解析が載る。
確率分布と乱数は scioxide-random、行列の分解と反復法は scioxide-linalg、根の精度改善は scioxide-rootfind、スペクトル推定は scioxide-signal を使う。

## 最初の計算と測定値の要約

公称 100 Ω の抵抗を 12 回測った値を要約する。
入力は 12 回目の測定値で、これを動かすと、外れた 1 回の測定が平均と分位点にどう効くかが分かる。
次のセルは逐次集計の `OnlineMoments` で平均・標準偏差・平均の 95% 区間を求め、経験分布の `EmpiricalDistribution` で中央値・四分位範囲・上側 10% の裾平均を求める。
スライスを一度だけ要約するなら、ワンショット関数 `mean`、`median`、`mean_confidence_interval` が同じ値を直接返す。
二つ目の表は検算で、中央値を整列した値の中央の二つの平均（`f64` の算術で書いた比較用の経路）と比べ、ワンショット関数との差を示す。

```rust
//| id: stats-first-summary
//| ref: stats-first-summary
//| title: 抵抗の測定値を逐次集計と経験分布で要約する
//| run: reactive
//| crates: [scioxide-stats]
//| inputs:
//|   last_reading: {"type":"range","label":"12 回目の測定値 [Ω]","description":"外れた測定を一つ入れたときの変化を見る。","min":99.5,"max":110,"step":0.5,"value":100}
//| cases:
//|   - {"id":"outlier","label":"12 回目が 110 Ω","description":"外れた 1 回で平均と標準偏差は大きく動き、中央値と四分位範囲はほとんど動かない。","inputs":{"last_reading":110}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"summary","path":"/rows/0/1","approx":{"value":100.0,"atol":1e-12}}
//|       - {"artifact":"summary","path":"/rows/1/1","approx":{"value":0.165144564768953,"atol":1e-9}}
//|       - {"artifact":"summary","path":"/rows/2/1","approx":{"value":99.8950721495184,"atol":1e-9}}
//|       - {"artifact":"summary","path":"/rows/3/1","approx":{"value":100.104927850482,"atol":1e-9}}
//|       - {"artifact":"summary","path":"/rows/4/1","approx":{"value":100.0,"atol":1e-12}}
//|       - {"artifact":"summary","path":"/rows/5/1","approx":{"value":0.2,"atol":1e-12}}
//|       - {"artifact":"summary","path":"/rows/6/1","approx":{"value":100.283333333333,"atol":1e-9}}
//|       - {"artifact":"checks","path":"/rows/0/1","range":{"max":1e-12}}
//|       - {"artifact":"checks","path":"/rows/1/1","range":{"max":1e-12}}
//|   - case: outlier
//|     expect:
//|       - {"artifact":"summary","path":"/rows/0/1","approx":{"value":100.833333333333,"atol":1e-9}}
//|       - {"artifact":"summary","path":"/rows/1/1","approx":{"value":2.89147126228259,"atol":1e-9}}
//|       - {"artifact":"summary","path":"/rows/2/1","approx":{"value":98.9961801414913,"atol":1e-9}}
//|       - {"artifact":"summary","path":"/rows/3/1","approx":{"value":102.670486525175,"atol":1e-9}}
//|       - {"artifact":"summary","path":"/rows/4/1","approx":{"value":100.0,"atol":1e-12}}
//|       - {"artifact":"summary","path":"/rows/5/1","approx":{"value":0.225,"atol":1e-12}}
//|       - {"artifact":"summary","path":"/rows/6/1","approx":{"value":108.383333333333,"atol":1e-9}}
//|       - {"artifact":"checks","path":"/rows/0/1","range":{"max":1e-12}}
//|       - {"artifact":"checks","path":"/rows/1/1","range":{"max":1e-12}}
use scioxide_stats::{
    EmpiricalDistribution, MomentOrder, OnlineMoments, QuantileMethod, QuantileProbability,
    QuantileRule, TailSide, Unweighted,
};

let readings = [
    99.8_f64,
    100.1,
    100.0,
    99.9,
    100.2,
    100.0,
    99.7,
    100.3,
    100.1,
    99.9,
    100.0,
    last_reading,
];
// 逐次集計: 観測を一つずつ加え、要約から平均・標準偏差・区間を読む。
let mut moments = OnlineMoments::new(MomentOrder::Second);
for &r in &readings {
    moments.observe(r).map_err(|e| e.to_string())?;
}
let s = moments.snapshot();
let undefined = || "12 個の観測では定義されるはずの量が未定義だった".to_string();
let mean = s.mean().map_err(|e| e.to_string())?.ok_or_else(undefined)?;
let sd = s
    .standard_deviation(1)
    .map_err(|e| e.to_string())?
    .ok_or_else(undefined)?;
// 既定の区間は両側 95%、自由度 n − 1 の Student の t 区間。
let ci = s
    .confidence_interval_of_mean()
    .map_err(|e| e.to_string())?
    .ok_or_else(undefined)?;
// 経験分布: 標本を複製して整列し、型 7 の分位点と上側の裾平均を求める。
let law = EmpiricalDistribution::new(&readings, Unweighted).map_err(|e| e.to_string())?;
let q = |p: f64| -> Result<f64, String> {
    let p = QuantileProbability::new(p).map_err(|e| e.to_string())?;
    let rule = QuantileRule::new(QuantileMethod::Linear);
    Ok(law.quantile(p, rule).map_err(|e| e.to_string())?.value())
};
let p90 = QuantileProbability::new(0.9).map_err(|e| e.to_string())?;
let tail = law
    .tail_mean(p90, TailSide::Upper)
    .map_err(|e| e.to_string())?;
let median = q(0.5)?;
// ワンショット関数: 同じ量をスライスから直接求める。
let one_shot_mean = scioxide_stats::mean(&readings).map_err(|e| e.to_string())?;
let one_shot_median = scioxide_stats::median(&readings).map_err(|e| e.to_string())?;
let one_shot_ci =
    scioxide_stats::mean_confidence_interval(&readings).map_err(|e| e.to_string())?;
// 独立な検算: 整列した 12 個の中央の二つの平均（f64 の算術）。
let mut sorted = readings;
sorted.sort_by(f64::total_cmp);
let median_by_hand = (sorted[5] + sorted[6]) / 2.0;
let one_shot_gap = [
    (one_shot_mean - mean).abs(),
    (one_shot_median - median).abs(),
    (one_shot_ci.bounds().lower() - ci.bounds().lower()).abs(),
    (one_shot_ci.bounds().upper() - ci.bounds().upper()).abs(),
]
.into_iter()
.fold(0.0, f64::max);
let fixed4 = serde_json::json!({ "fractionDigits": 4 });
let sci2 = serde_json::json!({ "notation": "scientific", "significantDigits": 2 });
let summary_columns = serde_json::json!([
    { "key": "0", "label": "量" },
    { "key": "1", "label": "値 [Ω]", "type": "number", "format": fixed4 },
    { "key": "2", "label": "計算様式" }
]);
emit_table_with_columns!(
    summary_columns,
    vec![
        ("平均", mean, "逐次集計"),
        ("標本標準偏差", sd, "逐次集計"),
        ("平均の 95% 区間の下端", ci.bounds().lower(), "逐次集計"),
        ("平均の 95% 区間の上端", ci.bounds().upper(), "逐次集計"),
        ("中央値（型 7）", median, "経験分布"),
        ("四分位範囲 Q(0.75) − Q(0.25)（型 7）", q(0.75)? - q(0.25)?, "経験分布"),
        ("上側 10% の裾平均", tail.mean(), "経験分布"),
    ],
    metadata = serde_json::json!({ "id": "summary" })
);
let check_columns = serde_json::json!([
    { "key": "0", "label": "検算" },
    { "key": "1", "label": "差 [Ω]", "type": "number", "format": sci2 }
]);
emit_table_with_columns!(
    check_columns,
    vec![
        ("中央値と手計算の差", (median - median_by_hand).abs()),
        ("平均・中央値・区間の端点とワンショット呼び出しの差の最大", one_shot_gap),
    ],
    metadata = serde_json::json!({ "id": "checks" })
);
```

既定の 12 回目が 100.0 Ω のとき、平均と中央値はどちらも 100.0000 Ω、標本標準偏差は 0.1651 Ω、平均の 95% 区間は $[99.8951, 100.1049]$ Ω、四分位範囲は 0.2000 Ω である。
上側 10% の裾平均は上位 1.2 件分の質量の平均で、100.2833 Ω になる。
中央値は手計算と一致し、ワンショット関数との差は 0 である。

12 回目を 110 Ω にする（入力の組「12 回目が 110 Ω」）と、平均は 100.8333 Ω、標準偏差は 2.8915 Ω に増え、平均の区間は $[98.9962, 102.6705]$ Ω と公称値を挟む広い区間になる。
中央値は 100.0000 Ω、四分位範囲は 0.2250 Ω でほとんど変わらず、外れた 1 回の影響は上側の裾平均 108.3833 Ω に集まる。
平均と分散は一つの外れた値に強く引かれ、順序に基づく中央値と四分位範囲は引かれにくい。
どちらを返すかは、外れた測定を母集団の一部とみなすかどうかで決まり、計算の手法だけでは決まらない。

## 結果の読み方

累積器の要約の各量は `Result<Option<S>, SciOxideError>` で返る。
数学的に定義されない量は `Ok(None)` であり、1 点の標本分散や定数列の相関がこれに当たる。
ワンショット関数 `mean`、`sample_variance` などは `Result<S, SciOxideError>` を返し、定義されない量（1 点の標本分散など）は `Err` にする。
入力の不正、計算の破綻、`S` で表せない値は `Err` で返り、エラーの分類は `kind()` で読める。

信頼区間や p 値は、記録された仮定の下での統計的な推論の結果である。
区間の構成法と仮定は `MeanConfidenceInterval::method()` と `assumptions()` で確かめられる。
分位点や裾平均は、使った定義の規約を結果に持つ（`QuantileResult::convention()`、`TailMeanResult::convention()`）。
他の統計ソフトウェアの出力と比べるときは、この規約をそろえる。

## まとめ

`scioxide-stats` は、標本を保持せずに更新する逐次集計と、標本全体を保持して整列や選択を行う経験分布の二つの計算様式を持つ。
既定の設定で一度だけ計算するなら、データだけを受け取るワンショット関数（`mean`、`median`、`t_test_independent`、`bootstrap` など）を使い、設定を変えるときは `_with_options` のオプション付き形式を使う。
平均や分散は外れた値に強く引かれ、中央値や四分位範囲は引かれにくい。
要約の照会は `Result<Option<S>, SciOxideError>` を返し、数学的に定義されない量（`None`）と計算の失敗（`Err`）を分けて返す。
信頼区間や p 値は記録された較正の規約と仮定を持つので、その前提と合わせて読む。
