区間 $X$ に含まれるすべての実数について $f(X)=\{f(x):x\in X\}$ を含む区間を求める問題は、両端点で関数を評価する問題とは異なる。
たとえば $X=[0,\pi]$ に対する正弦の最大値は内部の $\pi/2$ にある。
また、$X=[1,2]$ は正接の極 $\pi/2$ をまたぐ。
この違いを表現するのが `DecoratedInterval` の初等関数と `ElementaryEnclosure` である。

## 単調性、臨界点、定義されない入力

指数関数は単調増加なので、外向きに丸めた両端の指数値で値域を含む区間を求められる。
正弦・余弦では周期と内部の極値も調べる。
対数や逆三角関数では実数の定義域との交わりを調べ、元の入力区間全体で定義されるのか、一部だけなのかを区別する。

`DecoratedInterval` の初等関数は次のとおりで、どれも `ElementaryEnclosure` を返す。

| 種類 | メソッド | 包含区間の作り方 |
|---|---|---|
| 単調な一変数関数 | `exp`、`exp2`、`exp10`、`exp_m1`、`ln`、`log2`、`log10`、`ln_1p`、`asin`、`acos`、`atan`、`sinh`、`tanh`、`asinh`、`acosh`、`atanh`、`cbrt` | 定義域との交わりの両端で評価する。`ln` は $x>0$、`ln_1p` は $x>-1$、`asin`・`acos` は $[-1,1]$、`acosh` は $[1,\infty)$、`atanh` は $(-1,1)$ が定義域 |
| 極値を持つ関数 | `cosh`、`sin`、`cos` | `cosh` は $\lvert x \rvert$ に対して単調。`sin`・`cos` は区間内の極値の位置を調べ、幅 6 以上または非有界なら $[-1,1]$ |
| 極を持つ関数 | `tan` | 極を一つまたぐと二つの片を保つ。極を二つ含む区間、幅 4 以上の区間、非有界な区間では全実数を返す |
| 二変数・べき | `hypot`、`atan2`、`powi`、`powf`、`log` | `hypot` は被演算子を 2 のべきで拡大縮小するので、真の値が桁あふれもアンダーフローもしなければ結果もしない。`atan2` は原点を除外し、値は $(-\pi, \pi]$ で、負の実軸をまたぐ箱では $-\pi$ 付近と $+\pi$ 付近の二つの片を返す。`powi` の負の奇数乗が両符号を含む場合と、`log` の底が 1 をまたぐ場合も二つの片を保つ。`powf` の負の底と多くの整数の指数は結果の符号ごとの片を返し、`gaps_filled` を立てる |

各端点は引数の還元（三角関数では Payne–Hanek の還元）の後に固定次数の多項式近似で求め、近似誤差と丸め誤差の上界を加えてから外向きに丸める。
点の引数に対する包含区間の幅は浮動小数点数の 2 刻み以下で、21 個の一変数関数について `f32` と `f64` で正しく丸めた参照値と照合して確かめてある。
どのメソッドも定数時間で、確保しない。
外向き丸めの環境の検査に失敗すると `InvalidInput`、包含区間を作る内部の手順が破綻すると `NumericalInstability` のエラーになる。

`EnclosureStatus` は定義域の分類で、`EmptyInput`（入力が空）、`Defined`（入力全体で定義）、`PartiallyDefined`（一部だけ定義）、`Undefined`（どの点も定義域外）、`Inconclusive`（包含区間は正しいが、固定精度の範囲で定義域や分枝の分類を決められなかった）の五つである。
`Defined` 以外では区間片の decoration は `Trv` になる。
数値区間が得られたことだけで入力全体に連続な関数が定義されたとは限らない。
空の値域と計算上の失敗も別である。
返された状態と区間片を合わせて読む。

## 正接の極を凸包で隠さない

$1<\pi/2<2$ なので、正接の像は二つの無限区間に分かれる。
全実数へ凸包化すると、本来像に含まれない零まで含めてしまう。
`ElementaryEnclosure::pieces` は最大二つの閉じた分枝の包含区間を保持し、`contains` はその合併への包含を判定する。

次の実験では、$X=[1,2]$ に対する指数と正接の包含区間を、関数ごとに最大二つの区間片として表に出す。
指数の値域 $[e, e^2]$ は $3$ を含み、正接の像 $(-\infty, \tan 2] \cup [\tan 1, +\infty)$ は二つの片に分かれて零を含まない。
表の f(1) と f(2) の列は f64 の固有メソッドで求めた端点での参照値（$e \approx 2.718$、$e^2 \approx 7.389$、$\tan 1 \approx 1.557$、$\tan 2 \approx -2.185$）で、丸めの保証はない。
参照値の列はどの環境でも出る。
丸め環境の前提を確かめられない環境（wasm32 を含む）では包含区間の列を「未実行」と表示し、参照値で置き換えない。

```rust
//| id: validated-elementary-branches
//| ref: validated-elementary-branches
//| title: 指数の包含区間と正接の二分枝
//| run: button
//| crates: [scioxide-core, scioxide-validated]
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"table-0","path":"/rows/0/0","equals":"exp"}
//|       - {"artifact":"table-0","path":"/rows/0/1","approx":{"value":2.718281828459045,"atol":1e-14}}
//|       - {"artifact":"table-0","path":"/rows/0/2","approx":{"value":7.38905609893065,"atol":1e-14}}
//|       - {"artifact":"table-0","path":"/rows/1/0","equals":"tan"}
//|       - {"artifact":"table-0","path":"/rows/1/1","approx":{"value":1.5574077246549023,"atol":1e-14}}
//|       - {"artifact":"table-0","path":"/rows/1/2","approx":{"value":-2.185039863261519,"atol":1e-14}}
use scioxide_core::{SciOxideError, SciOxideErrorView, InvalidInputReason};
use scioxide_validated::DecoratedInterval;

// 1. X = [1, 2] の指数と正接を含む区間を求める。丸め環境のエラーはそのまま受け取る。
let calculation = || -> Result<_, SciOxideError> {
    let input = DecoratedInterval::new(1.0_f64, 2.0)?;
    Ok([input.exp()?, input.tan()?])
};
let unsupported = |error: &SciOxideError| {
    matches!(
        error.view(),
        SciOxideErrorView::InvalidInput {
            argument,
            reason: InvalidInputReason::UnsupportedConfiguration,
            ..
        } if argument == scioxide_core::argument!("rounding_environment")
    )
};
let enclosures = match calculation() {
    Ok(results) => Some(results),
    Err(error) if unsupported(&error) => None,
    Err(error) => return Err(error.to_string()),
};
use serde_json::json;
let references = [
    ("exp", 1.0_f64.exp(), 2.0_f64.exp()),
    ("tan", 1.0_f64.tan(), 2.0_f64.tan()),
];
emit_table_with_columns!(
    json!([
        {"key":"0","label":"関数"},
        {"key":"1","label":"f(1)（保証なし）","type":"number"},
        {"key":"2","label":"f(2)（保証なし）","type":"number"}
    ]),
    references,
    metadata = json!({"id":"table-0"})
);
let mut rows = Vec::new();
if let Some(results) = &enclosures {
    for (i, result) in results.iter().enumerate() {
        for (j, piece) in result.pieces().iter().enumerate() {
            let (lo, hi) = piece.set().bounds().unwrap();
            rows.push((
                references[i].0,
                j + 1,
                lo,
                hi,
                format!("{:?}", result.status()),
                result.contains(0.0),
            ));
        }
    }
}
let fmt = json!({"significantDigits":8});
emit_table_with_columns!(
    json!([
        {"key":"0","label":"関数"},
        {"key":"1","label":"区間片","type":"integer"},
        {"key":"2","label":"下端","type":"number","format":fmt,"nullText":"−∞"},
        {"key":"3","label":"上端","type":"number","format":fmt,"nullText":"+∞"},
        {"key":"4","label":"定義域の分類"},
        {"key":"5","label":"合併が零を含む"}
    ]),
    rows,
    metadata = json!({"id":"pieces"})
);
emit_outcome!(if enclosures.is_some() {
    Outcome::satisfied("分枝の包含区間を計算した")
} else {
    Outcome::unavailable("この環境では証明計算は未実行")
});
```

ネイティブ環境では指数は一つの区間片になり、decoration `Com`・分類 `Defined` で端点の参照値 $e$ と $e^2$ を含む。
正接は二つの非有界な区間片になり、有限な端点はそれぞれ $\tan 2$ と $\tan 1$ を外向きに丸めて包む。
表の数値表示は読みやすさのために丸めており、表示した桁を新たな保証付き端点として使わない。
`contains(3.0)` は指数で真、`contains(0.0)` は正接で偽、正接の凸包への `contains(0.0)` は真になる。
正接の区間片はどちらも `Trv` の decoration を持ち、定義域の分類は `PartiallyDefined` になる（極 $\pi/2$ が定義域から外れるため）。
`hull()` で凸包を取ると全実数になり、零を含む。
`gaps_filled()` は、分枝の凸包を作る過程で像の隙間を埋めた可能性があるかを保守的に示す。

## 数値誤差とモデルの不確かさ

区間包含区間には依存性による過大評価が残る。
たとえば同じ $x\in[0,1]$ を二回独立の区間として引けば $x-x$ の包含区間は広がる。
外向き丸めの正しさはこの過大評価を取り除かない。
入力区間の分割、数学的な式変形、単調性の利用、雑音記号を共有するアフィン演算（`AffineForm`）を検討する。

初等関数の包含区間を通常のソルバーの誤差推定と混同しない。
区間関数が正しくても、反復解法全体の存在・一意性の証明には別の条件が必要であり、それは `roots`・`ScalarRootVerifier`・`SystemRootVerifier` の検証が扱う。

## まとめと次に読むページ

初等関数の包含区間は、単調性・内部の極値・極の位置を調べて作られ、最大二つの区間片で返る。
`contains` は区間片の合併への所属を判定するので、正接の極をまたぐ区間でも像に含まれない零を誤って含めない。
定義域の一部だけで定義される入力は `EnclosureStatus` と `Trv` の decoration で区別される。
包含区間が得られるのは丸め環境の検査に通ったネイティブ環境だけである。
