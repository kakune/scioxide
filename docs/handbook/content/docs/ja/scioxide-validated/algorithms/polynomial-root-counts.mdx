多項式の近似根が密集していると、一つずつ分離するより集まり全体の個数を証明するほうが適している。
ここでいう個数は重複度込みで、二重根は 2 個と数える。
円板内の個数の証明と、全根を覆う円板の集合の証明を分けて説明する。

## 証明の条件

対象は $p(z)=a_0+a_1z+\cdots+a_dz^d$ で、係数は実数でも複素数でもよい。
中心 $c$、半径 $r>0$ の閉円板を $D(c,r)=\{z:|z-c|\le r\}$ とする。
Rouché の定理は、境界上で一つの項が残りを厳密に上回ると、残りを取り除いても内側の零点数が変わらないという定理である。
SciOxide の証明はこの厳密な優越を外向き丸めで確認する。
成功すれば境界上に根がないことも分かるため、閉円板と開円板の個数は一致する。

### 単根を検出する判定

$z=c+w$ として中心で Taylor 展開すると

$$
p(c+w)=p(c)+p'(c)w+\mathcal R_2(w),\qquad
|\mathcal R_2(w)|\le M_2|w|^2
$$

と書ける。
$M_2$ は円板上の $|p''(z)|/2$ の上界である。
境界 $|w|=r$ で $|p(c)|+r^2M_2<r|p'(c)|$ なら、一次項 $p'(c)w$ が他の項の和より大きい。
一次項は円板内にちょうど一つの根を持つので、元の多項式も同じ個数を持つ。
この判定は中心が単根の良い近似であると成立しやすいが、$p'(c)$ が小さい多重根には向かない。

$p(c)$ と $p'(c)$ は Horner 法で同時に評価でき、次数 $d$ に対して $O(d)$ の演算で済む。
実装は中心と半径で表す複素円板を使い、実部・虚部を毎回独立な区間として広げる過大評価を抑える。
ここでの半径は多項式評価の丸めの包含区間であり、根を囲む円板の半径 $r$ と混同しない。

### Taylor シフトと Pellet の判定

単根の判定で決まらない場合は、円板を単位円板へ変換して

$$
p(c+rz)=\sum_{j=0}^{d}b_jz^j,\qquad
b_j=r^j\sum_{\ell=j}^{d}{\ell\choose j}a_\ell c^{\ell-j}
$$

を区間演算で求める。
この変換が Taylor シフトで、全係数を求めるには $O(d^2)$ の演算が必要になる。
$|z|=1$ で $|b_kz^k|=|b_k|$、残りの絶対値は $\sum_{j\ne k}|b_j|$ 以下なので

$$
|b_k|>\sum_{j\ne k}|b_j|
$$

が成り立てば円板内の根はちょうど $k$ 個である。
$k=0$ なら根の不在、$k>1$ なら多重根または複数の根の集まりも扱える。
左辺には絶対値の下界、右辺には上界を使い、等号を成功として扱わない。
不等式が成り立たないことから根の個数は決まらず、十分条件の限界として `Inconclusive` になる。

## API と結果の解釈

`PolynomialRootPlan::new(coefficients, options)` は係数を定数項から昇順で受け取り、末尾の厳密な零を取り除いて次数を決める。
全て零の多項式は孤立した根の個数を定められないため `InvalidInput` になる。
係数は保存された浮動小数点数そのものを厳密な入力とし、元の式から係数を作る際の誤差は自動で補わない。
準備では係数を 2 のべきで拡大縮小して保持するが、零点は変わらない。

`PolynomialRootCertificate` は `RootDisk` と主張する `count` を組にした値であり、その構築自体には証明は伴わない。
`verify` が返す `PolynomialVerificationReport` では、`status()` が主張への判定、`count()` が実際に証明した個数である。
異なる個数を証明できれば `Refuted`、何も決まらなければ `Inconclusive` になる。
円板の半径を増やすと不等式の優越項が変わるので、個数が単調に増えても判定の容易さが単調に変わるとは限らない。

### 二重根と境界上の根の実験

$p(z)=(z-1)^2(z+2)=2-3z+z^3$ を中心 $c=1$ で展開すると $p(1+w)=3w^2+w^3$ になる。
従って $b_2=3r^2$、$b_3=r^3$ で、$0<r<3$ なら二次項が優越して個数 2 を証明できる。
$r>3$ なら三次項が優越して個数 3 となり、$r=3$ では根 $-2$ が境界上に来る。
この等号の場合は、閉円板の個数が解析的に分かっていても、境界に根がないことを前提とする判定は使えない。

セルは円板の半径と主張する個数を独立に変更し、解析的な個数と検証の状態を比較する。
座標と半径は無次元で、参照の根 $1$ と $-2$ はどちらも正確に表せる。
wasm では解析値だけを表示し、個数の証明は未実行になる。

```rust
//| id: validated-pellet-multiplicity
//| ref: validated-pellet-multiplicity
//| title: 円板の半径と重複度込みの個数
//| run: button
//| crates: [scioxide-core, scioxide-validated]
//| inputs:
//|   radius: {"type":"range","label":"中心 1 の円板の半径 r [-]","min":0.125,"max":4,"step":0.125,"value":0.5}
//|   count: {"type":"range","label":"主張する根の個数","min":0,"max":3,"step":1,"value":2}
//| cases:
//|   - {"id":"boundary","label":"境界に根","inputs":{"radius":3}}
//|   - {"id":"refuted","label":"誤った単根の主張","inputs":{"count":1}}
//|   - {"id":"all-roots","label":"三つの根を含む円板","inputs":{"radius":4,"count":3}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"reference","path":"/rows/0/1","equals":2}
//|   - case: boundary
//|     expect:
//|       - {"artifact":"reference","path":"/rows/0/2","equals":true}
//|   - case: all-roots
//|     expect:
//|       - {"artifact":"reference","path":"/rows/0/1","equals":3}
//|   - case: refuted
//|     expect:
//|       - {"artifact":"reference","path":"/rows/0/3","equals":1}
use scioxide_core::{SciOxideError, SciOxideErrorView, InvalidInputReason};
use serde_json::json;
let unsupported = |error: &SciOxideError| {
    matches!(error.view(),
SciOxideErrorView::InvalidInput { argument, reason: InvalidInputReason::UnsupportedConfiguration, .. }
if argument == scioxide_core::argument!("rounding_environment"))
};
use scioxide_core::Complex;
use scioxide_validated::{
    PolynomialRootCertificate, PolynomialRootPlan, RootDisk, RootVerificationStatus,
    ValidatedOptions,
};
let exact = if radius < 3.0 { 2 } else { 3 };
let claimed = count.round() as usize;
emit_table_with_columns!(
    [
        "半径",
        "閉円板内の既知の個数",
        "境界に既知の根がある",
        "主張する個数"
    ],
    vec![(radius, exact, radius == 3.0, claimed)],
    metadata = json!({"id":"reference"})
);
let proof = (|| -> Result<_, SciOxideError> {
    let plan = PolynomialRootPlan::new(&[2.0_f64, -3.0, 0.0, 1.0], ValidatedOptions::new())?;
    plan.verify(PolynomialRootCertificate {
        disk: RootDisk {
            center: Complex::new(1.0, 0.0),
            radius,
        },
        count: claimed,
    })
})();
let outcome = match proof {
    Ok(report) => {
        emit_table_with_columns!(
            json!([
                {"key":"0","label":"証明した個数","type":"integer","nullText":"未確定"},
                {"key":"1","label":"状態"}
            ]),
            vec![(report.count(), format!("{:?}", report.status()))],
            metadata = json!({"id":"proof"})
        );
        match report.status() {
            RootVerificationStatus::Proved => Outcome::satisfied("円板の根の個数を証明した"),
            RootVerificationStatus::Refuted => Outcome::failed("主張と異なる個数を証明した"),
            _ => Outcome::partial("この円板では個数が未確定"),
        }
        .status(format!("{:?}", report.status()))
    }
    Err(e) if unsupported(&e) => Outcome::unavailable("この環境では証明計算は未実行"),
    Err(e) => return Err(e.to_string()),
};
emit_outcome!(outcome);
```


半径 $1/2$ で単根の主張を選ぶと、検証器は個数 2 を証明して主張を反証する。
半径 3 の未確定は数値的な偶然ではなく、厳密な境界条件と対応する。
ただし一般の多項式で未確定になった場合に、必ず境界に根があるとはいえない。
係数包含区間の幅や、複数項の大きさが拮抗することでも判定不能になる。

## 全根の被覆と Plan の再利用

個々の円板で根を数えただけでは、円板の外に根が残る可能性がある。
`verify_cover` は各円板の主張に加えて、円板が互いに交わらないことと、個数の和が次数に等しいことを確かめる。
全体が証明されれば代数学の基本定理により他の根が残っていない。
零個の円板を多数並べても、全根を覆ったことにはならない。

`isolate` は近似根の周囲の円板を初期値とし、判定不能なら半径を広げ、重なる円板を併合する。
`PolynomialRootCover` は得られた証明用データ群を所有し、`PolynomialIsolationReport` の終了状態が完成度を示す。
近接した根は一つの円板にまとめて数えられるため、一つの円板に一つの根という形式は保証されない。
ワンショット呼び出しの `polynomial_roots` はこの手順を既定の半径から始め、完全な被覆だけを返す。

準備は $O(d)$ の演算とメモリ領域、円板一つの一般的な判定は $O(d^2)$ の演算を使う。
`RootWorkspace` を `ProofRequest::proofs(k)` または円板容量に対応する要求で事前確保すると、繰り返す検証で作業領域を再利用できる。
同じ Plan が表すのは同じ係数であり、係数の摂動を変えたら Plan も作り直す。
[Wilkinson 多項式](../../examples/wilkinson-root-counts/)で、入力係数の丸めと個数の判定の違いを確認できる。

## まとめ

円板内の個数は境界上での項の厳密な優越から証明する。
単根向けの判定と、Taylor シフト後に複数の根を数える判定を使い分ける。
`count()` と主張への `status()` を別々に読み、未確定を零個と扱わない。
全根を調べたと結論するには、個々の円板の証明に加えて被覆全体を検証する。

Rouché の定理と根の包含については Henrici, *Applied and Computational Complex Analysis*, Vol. 1（Wiley, 1974）の第 6 章を参照できる。
