区間の API は集合の表現、算術による包含区間、初等関数の分枝、相関を保持するアフィン形式を使い分ける。
型を選ぶ前に、入力が一点なのか不確かさを持つ集合なのか、同じ変数の相関を使う必要があるかを決める。

## 構築と変換

`DecoratedInterval::point(v)` は保存された値 $v$ の一点区間を作る。
例えば `point(0.1_f64)` が表すのは二進数へ丸めた値で、十進数の $1/10$ そのものの保証ではない。
$1/10$ を包むなら点区間 1 と 10 の区間除算を使う。
`new(lower, upper)` の端点は有限で順序付きであり、空集合や無限端は `ExtendedInterval` からの変換、`empty()`、`entire()` で表す。

`Interval::try_from` は有界で空でない結果を必要とし、非有界な包含区間を通常の有限区間へ黙って切り詰めない。
`set().bounds()` は空なら外側の `None`、無限端ならその端点の `None` を返す。
この二種類の `None` を区別すると、空集合と全実数を同じ表示にせずに済む。

## 区間片と相関の選択

`ElementaryEnclosure::pieces()` は最大二つの分枝を保持し、`contains()` はその合併への所属を判定する。
`hull()` は隙間を埋めて一つの区間にするので、正接の極のような不連続性を調べる用途では先に区間片と状態を読む。
`EnclosureStatus` は定義域の分類、`Decoration` は定義・連続性の情報であり、区間幅の良否を表す値ではない。

アフィン形式は同じ入力の相関を追跡するため、演算中は `AffineForm` を保持する。
`report().real()` や `imaginary()` を取り出して区間として演算すると、記号の共有情報は後の演算へ渡らない。
コンテキストの共有、項のバッファー、縮約の診断は [アフィン演算の数理](../../algorithms/affine-arithmetic/) で説明する。
[二次の剰余の実験](oxref:validated-affine-quadratic)では区間の積と相関を保存した積を比較できる。
