線形系の API では問題の係数を包む作用素、近似逆行列を作用させる前処理、解の中心と半径を持つ証明用データを分けて用意する。
点係数の密行列だけなら [ワンショット呼び出しの `solve`](../) で済むが、入力の不確かさを含めたい場合は `LinearVerifier` を使う。

## 入力を組み立てる順序

1. 点行列なら `DenseIntervalOperator::point`、成分ごとの上下限があるなら `new(lower, upper)` を作る。
   `MatrixView` は元のメモリ領域を借用するので、検証器の使用中は行列を保持する。
2. 前処理の作用素を用意する。
   通常は LU 分解から `LuIntervalInverse` を作るが、別の固定行列の作用でもよく、検証器がその精度を確かめる。
3. 右辺を `IntervalBox` の配列にする。
   `point_enclosure` は保存した点、`interval_enclosure` は指定した上下限を表す。
4. `LinearVerifier::new(&system, &inverse, options)` を作り、解く・近似解を提案する・証明用データを検証する操作を選ぶ。

| 操作 | 呼出側が与えるもの | 出力の意味 |
|---|---|---|
| `solve` | 右辺 | 検証済みの中心と半径、または証明なし |
| `propose` | 右辺と自分の近似解 | その近似解に対する保証半径 |
| `verify` | 右辺と中心・半径の借用 | 提案の包含区間を受理できるかの状態 |
| `bounds` | 検証器に結び付いた行列 | 正則性と行列ノルム・条件数の上界 |

`solve` の所有値を返す API は `(report, Option<certificate>)` を返し、レポートが `Verified` のときに証明用データがある。
`solve_into` は既存の証明用データへ書くが、成功しなかった呼び出しでは出力を変えない。
以前の証明用データが残っていても、今回の成功を表すとは限らないので必ずレポートを先に読む。

## 再利用と検算

同じ問題で繰り返す場合は `workspace(右辺の列数)` で一時領域を事前確保し、`*_into` に出力と実行スコープを渡す。
係数の証明を永続的に使い回すわけではなく、各呼び出しで元の問題から境界を再計算する。
複数右辺の `solve_block_into` は一回の呼び出しの中で行列の走査を共有する。

[区間係数の実行例](oxref:validated-linear-uncertainty)は入力幅と縮小率を、[有理数の Hilbert 行列](oxref:validated-hilbert-rational-system)は丸めを含む係数の作り方を示す。
証明不等式の導出は [線形系の数理](../../algorithms/verified-linear-systems/) にある。

### 区間作用素と線形系の証明
