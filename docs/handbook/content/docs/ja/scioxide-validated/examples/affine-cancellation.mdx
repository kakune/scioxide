同じ不確かさを共有する $x-x$ は厳密に零である。
通常の区間減算は二つの出現を独立に扱うため、$x\in[1-r,1+r]$ に対して $[-2r,2r]$ を返す。
セルは同じアフィン形式を二回渡して相殺し、通常の区間減算と比べる。
半幅 $r$ は無次元である。

## 共有する記号と独立な記号

$x=1+r\varepsilon$、$\varepsilon\in[-1,1]$ と書けば、同じ形式の差は係数 $r-r$ が零になり、$x-x=0$ がそのまま残る。
一方、同じ区間に属しても $x_1=1+r\varepsilon_1$、$x_2=1+r\varepsilon_2$ の二つの入力なら、差の真の値域は $[-2r,2r]$ である。
この違いは入力区間の端点だけからは分からない。
アフィン形式の記号が同じ入力に由来することを表している。

セルの `from_coefficients(&context, 1.0, &[radius])` は中心 1 と一つの入力記号の係数を指定する。
その同じ `x` を二回 `binary` に渡すことで相関を保存する。
二つの別のコンテキストで同じ係数を構築する方法は相関を表さず、そもそも混在がエラーになる。

```rust
//| id: validated-affine-cancellation
//| ref: validated-affine-cancellation
//| title: アフィン形式の相関と相殺
//| run: button
//| crates: [scioxide-core, scioxide-validated, scioxide-linalg]
//| inputs:
//|   radius: {"type":"range","label":"半幅 r","min":0.01,"max":0.5,"step":0.005,"value":0.125}
//| cases:
//|   - {"id":"wide","label":"r = 0.5","inputs":{"radius":0.5}}
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"reference","path":"/rows/0/1","approx":{"value":0,"atol":1e-13}}
//|   - case: wide
//|     expect:
//|       - {"artifact":"reference","path":"/rows/0/1","approx":{"value":0,"atol":1e-13}}
use scioxide_core::{SciOxideError, SciOxideErrorView, InvalidInputReason};
use scioxide_validated::DecoratedInterval as D;
use serde_json::json;
let unsupported = |error: &SciOxideError| {
    matches!(error.view(),
SciOxideErrorView::InvalidInput { argument,
reason: InvalidInputReason::UnsupportedConfiguration, .. }
if argument == scioxide_core::argument!("rounding_environment"))
};
use scioxide_validated::{AffineBinary, AffineContext, AffineForm, AffineOptions};
emit_table_with_columns!(
    ["半幅 r", "厳密な x − x"],
    vec![(radius, 0.0)],
    metadata = json!({"id":"reference"})
);
let result = (|| -> Result<_, SciOxideError> {
    let context = AffineContext::new(1, AffineOptions::new())?;
    let mut work = context.workspace::<f64>()?;
    let x = AffineForm::from_coefficients(&context, 1.0, &[radius])?;
    let affine = x.binary(&x, AffineBinary::Sub, &mut work)?.report().real();
    let interval = x.report().real();
    let independent = interval.sub(&interval)?;
    let rows = [("区間減算", independent), ("アフィン減算", affine)].map(|(name, x)| {
        let (lo, hi) = x.set().bounds().unwrap();
        (name, lo, hi)
    });
    Ok(rows)
})();
let outcome = match result {
    Ok(rows) => {
        emit_table_with_columns!(
            json!([
                {"key":"0","label":"方法"},
                {"key":"1","label":"下端","type":"number"},
                {"key":"2","label":"上端","type":"number"}
            ]),
            rows,
            metadata = json!({"id":"cancellation"})
        );
        Outcome::satisfied("包含区間の計算が完了した")
    }
    Err(error) if unsupported(&error) => Outcome::unavailable("この環境では証明計算は未実行")
        .explanation("対応するネイティブ環境で証明を実行する。"),
    Err(error) => return Err(error.to_string()),
};
emit_outcome!(outcome);
```

## 結果と一般の式への適用

半幅を増やすと区間減算の幅は $4r$ に比例して増えるが、同じ形式のアフィン減算は零のままである。
零が厳密に得られるのは、二つの入力が同一で係数の相殺が成立するためである。
異なる非線形計算の途中結果を引くと、同じ入力から始めてもそれぞれに新しい誤差項があるため、同様の厳密な相殺を期待できない。

演算後に `report().real()` だけを保存すると周辺区間になり、記号の共有は失われる。
相関を後の計算にも使うなら `AffineForm` のまま保持し、区間への変換は表示や外部 API への受け渡しで必要になった時点にする。
[二次式の実験](oxref:validated-affine-quadratic)は、一次の相関を保存しながら非線形の剰余が残る場合を扱う。

## まとめ

共有する雑音記号は、同じ不確かさが複数回現れたことを表す。
相殺には同じコンテキストと同じ記号を使う。
[アフィン演算の数理](../../algorithms/affine-arithmetic/)では非線形演算と記号の縮約も扱う。
