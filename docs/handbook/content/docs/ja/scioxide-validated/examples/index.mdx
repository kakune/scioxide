各例題では証明する対象と独立な参照値を区別する。
wasm では丸め環境の検査により証明計算が拒否されるため、参照値と入力だけを表示し、証明は未実行と示す。

| 例題 | API | 独立検算と学ぶこと |
|---|---|---|
| [区間の依存性](interval-dependency/) | `DecoratedInterval` | 既知の値域、同じ写像の異なる式 |
| [Rump の式](rump-polynomial/) | 四則演算 | i128 の相殺と有理数の値 |
| [Kepler 方程式](kepler-uniqueness/) | `ScalarRootVerifier` | 単調性、存在と一意性、狭すぎる提案 |
| [Hilbert 行列](hilbert-verified-solve/) | `solve` | 有理数の行列と丸めた行列の違い |
| [誤差関数](erf-certified-quadrature/) | `integrate` | 級数との比較、定数の包含区間 |
| [Wilkinson 多項式](wilkinson-root-counts/) | `PolynomialRootPlan` | 係数の丸めと根の個数の判定限界 |
| [アフィン形式の相殺](affine-cancellation/) | `AffineForm` | 同一変数の差が厳密に零になること |
| [円と直線の交点](nonlinear-system-proof/) | `SystemRootVerifier` | 解析的な交点、箱の包含と縮小率、四つの作用素の実装 |
