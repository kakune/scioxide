`scioxide-validated` は外向き丸めによる区間演算と、線形系・根・積分の検証を提供する。
近似値が一つの数を返すのに対し、保証付きの包含区間は真値を含む集合を返す。
区間演算は入力の不確かさの伝播にも、計算済みの近似解の事後誤差評価にも使える。
事前評価か事後評価かという区別と、誤差が推定値か証明された上界かという区別は別である。

## 近似値と保証付きの包含区間

最初に $X=[-1,1]$ の積と自乗を比べる。
独立に動く $x,y\in X$ の積の値域は $[-1,1]$ だが、同じ変数の自乗の値域は $[0,1]$ である。
`x.mul(&x)` は二つの出現を独立に扱い、`x.square()` は同じ変数の自乗として評価する。

セルは格子点 $k/10$ の標本と区間包含区間を並べる。
標本の最小・最大は保証のない参照値であり、一般には標本だけで値域の包含を証明できない。
wasm では外向き丸めの環境を検査できないため、標本だけを表示し、証明は未実行と示す。

```rust
//| id: validated-square-dependency
//| ref: validated-square-dependency
//| title: 区間の依存性と自乗
//| run: button
//| crates: [scioxide-validated, scioxide-core]
//| tests:
//|   - case: default
//|     expect:
//|       - {"artifact":"table-0","path":"/rows/0/0","equals":"x.mul(&x)"}
//|       - {"artifact":"table-0","path":"/rows/0/1","approx":{"value":-1,"atol":1e-15}}
//|       - {"artifact":"table-0","path":"/rows/0/2","approx":{"value":1,"atol":1e-15}}
//|       - {"artifact":"table-0","path":"/rows/1/0","equals":"x.square()"}
//|       - {"artifact":"table-0","path":"/rows/1/1","approx":{"value":0,"atol":1e-15}}
//|       - {"artifact":"table-0","path":"/rows/1/2","approx":{"value":1,"atol":1e-15}}
use scioxide_core::{SciOxideError, SciOxideErrorView, InvalidInputReason};
use scioxide_validated::DecoratedInterval;
use serde_json::json;

// 1. 独立な参照: X = [-1, 1] の格子点 k/10 での f64 の標本（保証のない値）
let grid: Vec<f64> = (-10..=10).map(|k| f64::from(k) / 10.0).collect();
let products: Vec<f64> = grid
    .iter()
    .flat_map(|&x| grid.iter().map(move |&y| x * y))
    .collect();
let squares: Vec<f64> = grid.iter().map(|&x| x * x).collect();
let range = |values: &[f64]| {
    let lo = values.iter().copied().fold(f64::INFINITY, f64::min);
    let hi = values.iter().copied().fold(f64::NEG_INFINITY, f64::max);
    (lo, hi)
};
// 2. 外向き丸めの包含区間: 汎用乗算は二つのオペランドを独立とみなし、自乗は同じ変数であることを使う
let calculation = || -> Result<_, SciOxideError> {
    let x = DecoratedInterval::new(-1.0_f64, 1.0)?;
    Ok([x.mul(&x)?, x.square()?])
};
let unsupported = |error: &SciOxideError| {
    matches!(
        error.view(),
        SciOxideErrorView::InvalidInput {
            argument,
            reason: InvalidInputReason::UnsupportedConfiguration,
            ..
        } if argument == scioxide_core::argument!("rounding_environment")
    )
};
let enclosures = match calculation() {
    Ok(results) => Some(results),
    Err(error) if unsupported(&error) => None,
    Err(error) => return Err(error.to_string()),
};
let samples = [
    ("x.mul(&x)", range(&products)),
    ("x.square()", range(&squares)),
];
let rows: Vec<_> = samples
    .iter()
    .enumerate()
    .map(|(i, &(name, (lo, hi)))| {
        let y = enclosures.as_ref().map(|v| v[i]);
        let bounds = y.and_then(|v| v.set().bounds());
        (
            name,
            lo,
            hi,
            bounds.and_then(|b| b.0),
            bounds.and_then(|b| b.1),
            y.map(|v| format!("{:?}", v.decoration())),
        )
    })
    .collect();
let fmt = json!({"significantDigits":8});
let missing = if enclosures.is_none() {
    "未実行"
} else {
    "非有界"
};
emit_table_with_columns!(
    json!([
        {"key":"0","label":"式"},
        {"key":"1","label":"標本の最小（保証なし）","type":"number","format":fmt},
        {"key":"2","label":"標本の最大（保証なし）","type":"number","format":fmt},
        {"key":"3","label":"下端","type":"number","format":fmt,"nullText":missing},
        {"key":"4","label":"上端","type":"number","format":fmt,"nullText":missing},
        {"key":"5","label":"decoration","nullText":"未実行"}
    ]),
    rows,
    metadata = json!({"id":"table-0"})
);
emit_outcome!(if enclosures.is_some() {
    Outcome::satisfied("像の包含区間を計算した")
} else {
    Outcome::unavailable("この環境では証明計算は未実行")
});
```

対応するネイティブ環境では、積の包含区間は $[-1,1]$、自乗の包含区間は $[0,1]$ になり、decoration はどちらも `Com` である。
この例では端点を正確に表せるので、丸めによる広がりはない。
積の包含区間が広い理由は、式の中の二つの出現の相関を使わないことである。
この過大評価を区間の依存性の問題という。

## 集合表現と精度保証の三層境界

SciOxide の区間型は扱う集合と算術の保証が異なる。

| 型 | 所属 | 集合と用途 |
|---|---|---|
| `Interval<S>` | `scioxide-core` | 有界で空でない閉区間。探索領域などに使う |
| `ExtendedInterval<S>` | `scioxide-core` | 空集合と非有界区間も扱う。集合の交差や凸包を取る |
| `DecoratedInterval<S>` | `scioxide-validated` | 集合に `Decoration` を付け、外向き丸めの算術を行う |

端点の型は `f32` または `f64` である。
`Decoration` は入力全体で定義され連続であるかを保守的に記録する。
decoration の強さは区間の狭さを意味しない。
初等関数の結果 `ElementaryEnclosure` は、極をまたぐ値域などを最大二つの区間片で返す。

## 式の依存性と幾何学的過大評価

同じ変数が複数回現れる式では、丸め誤差がなくても過大評価が起こる。
例えば $X-X=[-2,2]$ に対し、同じ実数の差 $x-x$ は零である。
代数的な式変形、`square`、共通の雑音記号を保持する `AffineForm` を使うと、この過大評価を減らせる。
入力区間そのものの幅、問題の感度、丸めによる幅とは区別する。

## 提供する範囲と前提

| 目的 | 最初に使う API | 設定や再利用が必要な場合 |
|---|---|---|
| 算術式の値域 | `DecoratedInterval` | 相関を保つには `AffineContext` と `AffineForm` |
| 密な点行列の解 | `solve` | 区間係数・疎行列・複数右辺には `LinearVerifier` |
| 実関数の全根の分離 | `roots` | 主張の検証には `ScalarRootVerifier`、連立系には `SystemRootVerifier` |
| 多項式の根の個数 | `polynomial_roots` | 円板と個数を指定するには `PolynomialRootPlan` |
| 有限区間の積分 | `integrate` | 許容誤差・特異点・無限区間には `QuadratureVerifier` |

ワンショット関数は証明が成り立った結果だけを `Ok` で返す。
検証器は結論なしもレポートで返すので、`Ok` だけで成功と判断せず状態を読む。
証明用データのメモリ領域を構築しただけでは、記録した主張は証明されない。

除算の零の分母や平方根の負の入力は定義域から除かれ、定義できる部分の像を含む区間を求める。
この除外はエラーではなく `Trv` の decoration で示される。
一方、非対応の丸め環境では包含区間を返さず、`InvalidInput` の `UnsupportedConfiguration` になる。
外向き丸めには最近接偶数丸め、段階的アンダーフロー、例外トラップの無効化が必要で、x86（SSE2）・x86_64・AArch64 で検査する。
構築・所属判定・交差・凸包は丸めを使わず、wasm でも実行できる。

## まとめと次に読むページ

包含が正しいことと包含区間が狭いことを分けて読む。
同じ変数の自乗には `square` を使い、一般の相関には式変形やアフィン演算を検討する。
検証器の終了状態を読み、結論なしを反証と取り違えない。
[選び方](choosing/)から API を選び、[数理](algorithms/)で証明の条件を、[例題](examples/)で結果の解釈を確かめられる。
